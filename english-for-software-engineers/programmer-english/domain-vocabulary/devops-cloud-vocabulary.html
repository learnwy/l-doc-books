DevOps 与云计算词汇

CI/CD 与自动化

持续集成和持续部署是现代软件工程的核心实践。掌握这些术语是参与 DevOps 讨论和阅读 pipeline 配置文件的基础。

CI/CD 核心术语

术语 释义 例句
CI (Continuous Integration) 频繁合并代码并自动验证 "CI runs unit tests on every push to catch regressions early."
CD (Continuous Delivery) 代码随时可部署到生产环境 "Continuous delivery means every merged commit is release-ready."
CD (Continuous Deployment) 自动部署到生产环境 "With continuous deployment, merging to main triggers production release."
Pipeline 自动化构建-测试-部署的流水线 "The pipeline takes about 8 minutes from push to production."
Build Artifact 构建过程产生的可部署产物 "Docker images are our primary build artifacts."
Stage / Step 流水线中的一个阶段 "The deploy stage only runs on the main branch."
Gate / Quality Gate 流水线中的质量检查关卡 "Code coverage below 80% fails the quality gate."
Rollback 回退到之前的稳定版本 "We rolled back within 5 minutes when the canary showed errors."
Blue-Green Deployment 双环境切换式部署 "Blue-green deployment eliminates downtime during releases."
Canary Release 先部署给小比例用户验证 "The canary release serves 5% of traffic for 30 minutes."
Feature Toggle 运行时开关控制功能启停 "Feature toggles decouple deployment from release."
GitOps 用 Git 作为部署的唯一真相来源 "GitOps means the desired state is always defined in Git."

构建与测试术语

术语 释义 例句
Lint / Linting 静态代码检查 "ESLint catches style violations and potential bugs."
Static Analysis 不执行代码的分析方法 "Static analysis detected a potential null pointer dereference."
Unit Test 测试最小代码单元 "Unit tests should be fast, isolated, and deterministic."
Integration Test 测试多个模块的交互 "Integration tests verify the API layer with a real database."
E2E Test (End-to-End) 模拟完整用户流程的测试 "E2E tests use Playwright to simulate user interactions."
Smoke Test 基本功能快速验证 "Smoke tests confirm the app starts and responds to health checks."
Regression Test 验证修改未引入新问题 "Regression tests run on every PR to prevent breaking changes."
Flaky Test 结果不确定的不稳定测试 "We quarantine flaky tests to keep the pipeline reliable."
Code Coverage 测试覆盖代码的比例 "We target 80% code coverage for critical business logic."

容器化与编排

Docker 与容器

术语 释义 例句
Container 轻量级隔离的应用运行环境 "Each service runs in its own container with isolated dependencies."
Image 容器的只读模板 "Build the Docker image once, deploy it anywhere."
Dockerfile 定义镜像构建步骤的文件 "Multi-stage Dockerfiles reduce final image size."
Layer 镜像中的一个构建步骤缓存 "Ordering Dockerfile instructions to maximize layer caching."
Volume 持久化存储，生命周期独立于容器 "Database data is stored in a persistent volume."
Registry 存储和分发容器镜像的服务 "Push images to the private registry after CI passes."
Compose 定义多容器应用的工具 "Docker Compose spins up the entire dev stack locally."
Ephemeral 短暂存在的、一次性的 "Containers are ephemeral — they can be destroyed and recreated."
Sidecar 与主容器一同部署的辅助容器 "The logging sidecar forwards logs to the aggregation service."

Kubernetes 核心概念

术语 释义 例句
Pod Kubernetes 最小部署单元 "A pod contains one or more tightly coupled containers."
Node 运行 Pod 的物理或虚拟机 "The cluster has 12 nodes across 3 availability zones."
Cluster 一组 Node 构成的计算资源池 "We manage separate clusters for staging and production."
Deployment 声明式地管理 Pod 副本集 "The deployment maintains 3 replicas of the API service."
Service 为 Pod 提供稳定网络访问的抽象 "A ClusterIP service exposes the database internally."
Ingress 管理外部访问集群服务的规则 "Ingress routes traffic based on hostname and path."
Namespace 集群内的逻辑隔离分区 "Each team deploys to their own namespace."
ConfigMap 存储非敏感配置数据 "ConfigMaps inject environment-specific settings into pods."
Secret 存储敏感数据（密码、密钥） "Kubernetes Secrets are base64 encoded, not encrypted."
HPA (Horizontal Pod Autoscaler) 根据指标自动调整 Pod 数量 "HPA scales our API from 3 to 20 pods based on CPU usage."
Helm Chart Kubernetes 应用的包管理格式 "We package all services as Helm charts for consistent deploys."
CRD (Custom Resource Definition) 扩展 Kubernetes API 的自定义资源 "Our operator uses CRDs to manage database instances."

可观测性与监控

三大支柱

术语 释义 例句
Observability 通过外部输出推断系统内部状态 "Observability goes beyond monitoring — it answers novel questions."
Metrics 时间序列数值数据 "Prometheus collects metrics from all services every 15 seconds."
Logs 离散的事件记录 "Structured JSON logs enable efficient searching in Elasticsearch."
Traces 请求在分布式系统中的完整路径 "Distributed traces show where latency accumulates across services."
Span Trace 中的单个操作段 "Each span records the operation name, duration, and metadata."

监控与告警

术语 释义 例句
Dashboard 可视化指标的面板 "The Grafana dashboard shows request rate, errors, and latency."
Alert 指标超阈值时的自动通知 "Alerts fire when error rate exceeds 1% for 5 minutes."
On-call 值班响应生产问题 "I'm on-call this week — reachable 24/7 for incidents."
Incident 影响用户的生产故障 "The incident was escalated to P1 due to data loss risk."
Runbook 处理特定问题的标准操作手册 "The runbook describes steps to recover from database failover."
Post-mortem 事故后的复盘分析 "The post-mortem identified 3 action items to prevent recurrence."
SLO Burn Rate SLO 预算消耗速度 "A burn rate of 10x means we'll exhaust the error budget in 3 days."
Percentile (p50/p95/p99) 百分位延迟 "p99 latency of 500ms means 99% of requests are faster."

云服务与基础设施

云计算基础

术语 释义 例句
IaaS (Infrastructure as a Service) 虚拟化计算资源 "EC2 is AWS's IaaS offering for virtual machines."
PaaS (Platform as a Service) 托管的应用运行平台 "Heroku is a PaaS — you deploy code, they manage servers."
SaaS (Software as a Service) 完整的托管软件应用 "Slack is a SaaS product — no installation needed."
Serverless 按需执行代码，无需管理服务器 "Serverless functions scale to zero when there's no traffic."
Function as a Service (FaaS) 事件驱动的无服务器函数 "AWS Lambda is the most popular FaaS platform."
CDN (Content Delivery Network) 全球分布的内容分发网络 "Static assets are served from the CDN edge location."
Edge Computing 在网络边缘靠近用户处计算 "Edge functions run at the CDN edge for minimal latency."
Multi-tenancy 多租户共享基础设施 "Our SaaS platform uses multi-tenancy with logical isolation."
Availability Zone (AZ) 云区域中独立的数据中心 "Deploy across at least 2 AZs for high availability."
Region 地理上独立的云基础设施区域 "We have deployments in us-east-1 and eu-west-1 regions."

Infrastructure as Code

术语 释义 例句
IaC (Infrastructure as Code) 用代码定义和管理基础设施 "Terraform manages our IaC across multiple cloud providers."
Terraform 跨云的基础设施声明式管理工具 "Terraform plans show what will change before applying."
State File IaC 工具追踪资源状态的文件 "Never manually edit the Terraform state file."
Drift 实际状态与声明状态的偏差 "Configuration drift means manual changes went untracked."
Provisioning 创建和配置基础设施资源 "Provisioning a new environment takes under 10 minutes."
Immutable Infrastructure 不变基础设施——替换而非修改 "With immutable infrastructure, we replace instances instead of patching."

常用 DevOps 缩写速查

缩写 全称 含义
K8s Kubernetes 容器编排平台
EKS / GKE / AKS Elastic/Google/Azure Kubernetes Service 托管 Kubernetes
VPC Virtual Private Cloud 虚拟私有网络
IAM Identity and Access Management 身份与权限管理
ALB / NLB Application/Network Load Balancer 负载均衡器
EBS / EFS Elastic Block/File Storage 块/文件存储
RDS Relational Database Service 托管关系数据库
SNS / SQS Simple Notification/Queue Service 消息服务
ACL Access Control List 访问控制列表
DNS Domain Name System 域名解析系统
TLS / SSL Transport Layer Security 传输层加密
SSH Secure Shell 安全远程连接
VPN Virtual Private Network 虚拟专用网络

DevOps 和云计算的术语更新速度极快——几乎每年都有新的工具和概念出现。建议关注 CNCF（Cloud Native Computing Foundation）的技术雷达和主要云厂商的年度发布，持续更新你的技术词汇库。在日常工作中遇到不确定的术语时，养成立即查阅官方文档定义的习惯，避免在团队沟通中使用不准确的含义。
