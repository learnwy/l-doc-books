UI/UX 设计关键词

设计原则

词汇 词性 含义 常用搭配
usability n. 易用性 usability testing, improve usability
accessibility n. 无障碍 accessibility standards, WCAG compliance
consistency n. 一致性 design consistency, consistent UI
affordance n. 功能可见性 visual affordance, button affordance
hierarchy n. 层次结构 visual hierarchy, information hierarchy
responsive adj. 响应式的 responsive design, responsive layout

听说例句

A: Is the design responsive across all screen sizes? B: Yes, we've tested on mobile, tablet, and desktop. The visual hierarchy adapts well.

A: Are we meeting accessibility standards? B: We're WCAG 2.1 AA compliant. All interactive elements have proper affordance and keyboard navigation.

写作表达

  • Maintaining design consistency across all touchpoints reinforces brand identity and reduces cognitive load.
  • Responsive design ensures an optimal user experience regardless of device or screen size.

设计流程

词汇 词性 含义 常用搭配
wireframe n. 线框图 create wireframes, low-fidelity wireframe
mockup n. 模型图 high-fidelity mockup, design mockup
prototype n. 原型 interactive prototype, build a prototype
user flow n. 用户流 map user flow, user flow diagram
design system n. 设计系统 build a design system, component library
handoff n. 设计交付 design handoff, developer handoff

听说例句

A: Do we have wireframes ready for the new feature? B: Yes, low-fidelity wireframes are done. I'm working on the high-fidelity mockup in Figma.

A: When is the design handoff? B: Thursday. I'll walk through the prototype and share the user flow documentation with the devs.

写作表达

  • The design process begins with user flow mapping, followed by wireframes, mockups, and interactive prototypes.
  • A well-maintained design system accelerates the handoff process and ensures consistency across all product surfaces.

用户体验研究

词汇 词性 含义 常用搭配
user testing n. 用户测试 conduct user testing, user testing session
heuristic evaluation n. 启发式评估 perform heuristic evaluation, Nielsen heuristics
persona n. 用户画像 create personas, persona-driven design
journey map n. 用户旅程图 customer journey map, map the journey
pain point n. 痛点 identify pain points, address pain points
task completion rate n. 任务完成率 measure task completion, high completion rate

听说例句

A: What did the user testing reveal? B: The main pain point is the navigation structure. Task completion rate for the search function was only 60%.

A: Should we update the personas? B: Yes, our user base has shifted. The journey map needs to reflect the new onboarding flow too.

写作表达

  • User testing with 20 participants identified three critical pain points in the checkout experience.
  • The customer journey map visualizes every touchpoint from awareness to purchase, highlighting moments of friction.

设计工具

词汇 词性 含义 常用搭配
Figma n. Figma设计工具 design in Figma, Figma components
component n. 组件 reusable component, component variants
auto layout n. 自动布局 use auto layout, auto layout constraints
token n. 设计令牌 design token, color token
plugin n. 插件 Figma plugin, design plugin
version control n. 版本控制 design version control, branch and merge

听说例句

A: Are all the components updated in Figma? B: Yes, I've added auto layout to the card components and updated the design tokens for the new theme.

A: Is there a plugin for exporting design specs? B: We use a handoff plugin that generates CSS and asset links directly from Figma.

写作表达

  • The design system in Figma includes over 200 reusable components with consistent design tokens for color, spacing, and typography.
  • Auto layout ensures that components adapt dynamically to content changes, reducing manual adjustments.
