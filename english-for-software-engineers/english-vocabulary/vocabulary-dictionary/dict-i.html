词典 I

职场与商务

词汇 词性 含义 常见搭配 例句
implement v. 实施、实现 implement a plan/feature We implemented the new pricing strategy last month.
incentive n. 激励 financial incentive The company offers incentives for early goal completion.
initiative n. 倡议、主动性 take the initiative She took the initiative to organize the team offsite.
inventory n. 库存 inventory management Real-time inventory tracking reduces overstock issues.
invoice n. 发票 issue/send an invoice Please send the invoice before the end of the month.
iterate v. 迭代 iterate on a design/product We iterate quickly based on user feedback.
insight n. 洞察 valuable insight, data insight The analytics report provided actionable insights.
interim adj./n. 临时的/过渡期 interim solution/report This is an interim fix until the full refactor is done.
indispensable adj. 不可或缺的 indispensable member/tool A good project manager is indispensable for large teams.
increment n./v. 增量 incremental improvement We adopt an incremental approach to product development.
inbound adj. 入站的 inbound traffic/marketing Inbound marketing attracts customers through valuable content.

日常与社交

词汇 词性 含义 常见搭配 例句
impression n. 印象 first impression First impressions matter in job interviews.
independence n. 独立 financial independence Many young people strive for financial independence.
ingredient n. 食材、成分 key ingredient Fresh ingredients make a big difference in cooking.
insurance n. 保险 health/car insurance The company provides comprehensive health insurance.
interact v. 互动 interact with Children learn by interacting with their peers.
involve v. 涉及、参与 be involved in The project involves teams from three different offices.
isolate v. 隔离、孤立 isolate a problem Working remotely can sometimes make you feel isolated.
intuitive adj. 直觉的 intuitive design/interface The app has a very intuitive user interface.
inevitable adj. 不可避免的 inevitable outcome Bugs in complex software are almost inevitable.
itinerary n. 行程表 travel itinerary Please share the itinerary for the business trip.

技术相关

词汇 词性 含义 常见搭配 例句
IDE n. 集成开发环境 code in an IDE VS Code is the most popular IDE among web developers.
immutable adj. 不可变的 immutable data/object Using immutable state helps prevent unexpected bugs.
index n./v. 索引/建索引 database index, array index Adding an index on the email column sped up queries.
infrastructure n. 基础设施 cloud infrastructure We manage our infrastructure using Terraform.
inject v. 注入 dependency injection, SQL injection The framework supports constructor-based dependency injection.

interface n. 接口 user interface, API interface The TypeScript interface defines the shape of the data.
integration n. 集成 continuous integration, third-party integration Continuous integration catches bugs early in the pipeline.
idempotent adj. 幂等的 idempotent operation/API PUT requests should be idempotent by design.
interpolation n. 插值 string interpolation Template literals in JavaScript use string interpolation.

易混淆词辨析

词组 区别说明
its vs. it's its 物主代词「它的」，it's 是 it is 缩写。The dog wagged its tail. / It's raining.
imply vs. infer imply「暗示（说话者）」，infer「推断（听者）」。He implied that... / I inferred from his words...
insure vs. ensure insure「投保」，ensure「确保」。Insure the package. / Ensure code quality.
in vs. into in 表示「在……里面（状态）」，into 表示「进入（动作）」。He is in the room. / He walked into the room.
issue vs. problem issue 较正式/中性「议题」，problem 偏负面「问题」。Raise an issue. / Fix the problem.

高频短语

短语 含义 例句
in terms of 在……方面 In terms of performance, the new version is much faster.
in charge of 负责 Who is in charge of the deployment process?
iron out 解决、消除 We need to iron out a few issues before the launch.
in the loop 知情 Please keep me in the loop on any status changes.
in line with 与……一致 The results are in line with our expectations.
in hindsight 事后看来 In hindsight, we should have added more test coverage.
in the meantime 与此同时 The fix is being reviewed; in the meantime, use the workaround.
in a nutshell 简而言之 In a nutshell, we need to refactor the auth module.
