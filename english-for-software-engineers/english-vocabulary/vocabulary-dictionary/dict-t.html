词典 T

职场与商务

词汇 词性 含义 常见搭配 例句
transaction n. 交易，事务 financial transaction, complete a transaction Each transaction is recorded in the system.
target n./v. 目标；瞄准 sales target, target audience We exceeded our quarterly sales target.
terminate v. 终止，解除 terminate a contract, terminate employment The company terminated the vendor agreement.
turnover n. 营业额；人员流动率 employee turnover, annual turnover High turnover is costly for any organization.
timeline n. 时间线，进度表 project timeline, tight timeline The timeline for delivery has been moved up.
thorough adj. 彻底的，详尽的 thorough review, thorough investigation Please do a thorough check before submitting.
transparent adj. 透明的，公开的 transparent process, transparent communication Management should be transparent about changes.
transition n./v. 过渡；转变 smooth transition, transition period The transition to the new system took three months.
task n./v. 任务；分派任务 assign a task, task management She was tasked with leading the migration project.
traction n. 牵引力；进展 gain traction, market traction The new product is gaining traction in Asia.
tenure n. 任期，任职 long tenure, during his tenure During her tenure, the team doubled in size.
tariff n. 关税，费率 import tariff, tariff rate New tariffs on imported goods took effect this month.

日常与社交

词汇 词性 含义 常见搭配 例句
tremendous adj. 巨大的，极大的 tremendous effort, tremendous progress She made tremendous progress in her studies.
trivial adj. 琐碎的，不重要的 trivial matter, trivial issue Don't waste time on trivial details.
tolerance n. 容忍，宽容 zero tolerance, tolerance for risk The school has a zero tolerance policy on bullying.
tentative adj. 暂定的，试探性的 tentative plan, tentative date We set a tentative date for the dinner.
thrive v. 繁荣，茁壮成长 thrive in, thrive under pressure Some people thrive in fast-paced environments.
thoughtful adj. 体贴的；深思熟虑的 thoughtful gift, thoughtful approach That was a very thoughtful birthday surprise.
tangible adj. 有形的，可触摸的 tangible results, tangible evidence We need tangible proof before making a claim.
tedious adj. 乏味的，冗长的 tedious task, tedious process Data entry can be a tedious task.
tempting adj. 诱人的，吸引人的 tempting offer, tempting idea The dessert menu was incredibly tempting.
trait n. 特征，特点 personality trait, character trait Honesty is a trait I admire most in people.
trek n./v. 长途跋涉 trek through, mountain trek They trekked through the forest for three days.

技术相关

词汇 词性 含义 常见搭配 例句
template n. 模板 project template, email template Use the standard template to create the page.
thread n. 线程；帖子 main thread, background thread Heavy tasks should run on a background thread.
token n. 令牌，标记 access token, authentication token The API requires a valid access token.
throughput n. 吞吐量 high throughput, network throughput We need to improve the throughput of the pipeline.
trigger n./v. 触发器；触发 trigger an event, trigger a build Pushing to main will trigger the CI pipeline.
timestamp n. 时间戳 Unix timestamp, timestamp format Each log entry includes a timestamp.
tuple n. 元组 tuple type, return a tuple The function returns a tuple of two values.
throttle v./n. 节流；限流 throttle requests, API throttle We throttle API requests to 100 per minute.
transpile v. 转译 transpile TypeScript, transpile to ES5 Babel transpiles modern JavaScript for older browsers.
truncate v. 截断，截取 truncate the string, truncate the table Truncate long text to fit in the preview card.
telemetry n. 遥测，数据采集 telemetry data, send telemetry The app collects anonymous telemetry for improvement.
TLS n. 传输层安全协议 TLS handshake, TLS certificate Upgrade to TLS 1.3 for better security.
TCP n. 传输控制协议 TCP connection, TCP/IP TCP ensures reliable data delivery over the network.

易混淆辨析

词组 区别说明
terminate vs. end terminate 更正式，常用于合同或雇佣关系；end 更通用
thorough vs. complete thorough 强调仔细不遗漏，complete 强调全部完成
trivial vs. minor trivial 含有不值一提的贬义，minor 只表示程度较小
transparent vs. clear transparent 侧重信息公开透明，clear 侧重表达清晰
tangible vs. concrete tangible 指可触摸的有形事物，concrete 指具体而非抽象的
trait vs. characteristic trait 多指性格特征，characteristic 更广泛，可指任何显著特点
