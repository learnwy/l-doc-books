RD-PM 协作

需求对接

词汇 词性 含义 常用搭配
requirement n. 需求 clarify requirements, requirement change
spec n. 规格说明 tech spec, product spec
scope n. 范围 define scope, scope creep
trade-off n. 权衡 technical trade-off, discuss trade-offs
feasibility n. 可行性 feasibility study, technical feasibility
alignment n. 对齐 team alignment, align on priorities

听说例句

A: The PM wants to add three more features before launch. B: That's scope creep. Let's discuss the trade-offs and feasibility before committing.

A: Are we aligned on the requirements for this sprint? B: Mostly. I need the PM to clarify the acceptance criteria in the spec before I start coding.

写作表达

  • Early alignment between product and engineering ensures that technical feasibility is considered during scope definition.
  • Frequent requirement changes without proper trade-off analysis are a leading cause of schedule delays.

技术评审

词汇 词性 含义 常用搭配
tech review n. 技术评审 schedule a tech review, tech review meeting
RFC (Request for Comments) n. 征求意见稿 write an RFC, RFC review
design doc n. 设计文档 draft a design doc, review the design doc
risk n. 风险 technical risk, identify risks
dependency n. 依赖 external dependency, dependency mapping
estimate n./v. 估算 effort estimate, estimate the work

听说例句

A: Have you submitted the design doc for the tech review? B: Yes, it includes the RFC, dependency mapping, and risk assessment. The team will review it tomorrow.

A: What's your effort estimate for this feature? B: About 3 sprints, assuming no external dependency delays.

写作表达

  • The tech review process requires a design doc with risk assessment and dependency analysis before implementation begins.
  • Accurate effort estimation helps PMs set realistic timelines and manage stakeholder expectations.

发布协调

词汇 词性 含义 常用搭配
release n./v. 发布 release plan, schedule a release
go/no-go n. 上线/不上线决定 go/no-go decision, go/no-go meeting
checklist n. 检查清单 release checklist, pre-launch checklist
rollback n. 回滚 rollback plan, trigger a rollback
sign-off n. 签收 PM sign-off, get stakeholder sign-off
hotfix n. 紧急修复 deploy a hotfix, hotfix branch

听说例句

A: Do we have PM sign-off for the release? B: Not yet. We're waiting for the go/no-go meeting after QA completes the release checklist.

A: What if something goes wrong after launch? B: We have a rollback plan ready and a hotfix branch pre-created just in case.

写作表达

  • The go/no-go meeting ensures that all stakeholders review the release checklist before the product goes live.
  • A well-prepared rollback plan and hotfix process are essential components of a reliable release strategy.

沟通节奏

词汇 词性 含义 常用搭配
standup n. 站会 daily standup, standup update
sync n./v. 同步 weekly sync, sync with PM
blocker n. 阻断问题 raise a blocker, remove blockers
status update n. 状态更新 send a status update, daily status
async communication n. 异步沟通 async updates, prefer async
decision log n. 决策日志 maintain a decision log, log the decision

听说例句

A: Should we move this discussion to an async channel? B: Good idea. I'll post a status update in the thread and log the decision for reference.

A: I have a blocker — the API spec isn't finalized. B: I'll sync with the PM today and get the spec updated. Raise it again in tomorrow's standup if it's not resolved.

写作表达

  • Effective RD-PM collaboration balances synchronous meetings for urgent decisions with async communication for updates.
  • Maintaining a decision log ensures transparency and provides a traceable record of all key product-engineering agreements.
