简洁性技巧

核心概念

简洁性（conciseness）是英文技术写作的核心品质之一。William Strunk 在《The Elements of Style》中写道：Omit needless words。在职场沟通中，简洁不仅是风格偏好，更是对他人时间的尊重。每多一个不必要的词，读者就多花一点认知能量去解析它——当这种浪费累积到整封邮件或整篇文档时，影响就显著了。

简洁与简短不同——简洁是用更少的词传达同样的信息，简短则可能丢失信息：

核心原则是 Every word must earn its place — 文本中的每个词都必须有存在的理由。

一封典型的冗余邮件与简化后的对比：


冗余版：




I am writing to you in order to inform you that due to the fact that we encountered a large number of issues during the testing phase, we have made the decision to postpone the release that was originally scheduled for this coming Friday.




简洁版：




We're postponing Friday's release because testing uncovered many issues.




从 42 词压缩到 10 词，信息完全相同。


名词化还原为动词
名词化（nominalization）是将动词或形容词转化为名词的过程。过度名词化是技术写作中最常见的冗余来源。

技术写作中的实际案例：


冗余: We performed an analysis of the system performance and reached the conclusion that the implementation of a caching layer would result in significant improvement of response times.


简洁: We analyzed system performance and concluded that implementing a caching layer would significantly improve response times.


从 30 词压缩到 17 词，信息密度几乎翻倍。


被动语态转主动语态
被动语态是另一个常见的冗余来源。主动语态通常比被动语态更简洁、更直接。






被动（冗余）
主动（简洁）
节省词数





The bug was fixed by David.
David fixed the bug.
1 词




The decision was made to postpone.
We decided to postpone.
2 词




The feature was implemented by the team.
The team implemented the feature.
1 词




It was determined that the API should be updated.
We determined the API needs updating.
3 词





但被动语态并非总是错误的。在以下场景中被动语态更合适：


    

  • 强调动作而非行动者：The server was rebooted at 3am.（不需要说谁做的）
    • 

  • 动作者未知：The configuration file was corrupted.（不知道怎么损坏的）
    • 

  • 正式报告：The vulnerability was patched within 24 hours.（安全报告的惯例）
    • 



判断标准是：Does the reader need to know who did it? 如果需要，用主动语态。


句子层面的压缩技巧
在更高层面上，整个句子有时可以被显著压缩：


合并重复信息：


冗余:




The API returns a JSON response. The JSON response contains the user data. The user data includes the user's name and email.




简洁:




The API returns a JSON response containing the user's name and email.




删除不必要的 "there is/are"：


冗余: There are three issues that need to be addressed.


简洁: Three issues need addressing.


用强动词替代弱动词 + 副词：






弱表达
强表达





moved quickly
rushed / sprinted




said loudly
shouted / announced




went up
rose / increased




look at carefully
examine / inspect





删除显而易见的内容：


冗余: In this email, I am writing to request your approval.


简洁: I'm requesting your approval.（读者已经知道这是一封邮件）


使用破折号或冒号替代从句：


冗余: The reason we chose Redis is that it offers both speed and simplicity.


简洁: We chose Redis for two reasons: speed and simplicity.


实战演练：邮件精简
将以上所有技巧综合应用到一封真实的邮件中。


精简前（87 词）：




Dear Team,


I am writing this email to let you all know that after we performed a thorough analysis of the current situation with regard to the deployment pipeline, we have reached the conclusion that there are a number of improvements that need to be made. Due to the fact that the current pipeline is slow, we have made the decision to carry out the implementation of a new CI/CD system. I would like to request that each of you is able to attend a meeting on Friday.




精简后（32 词）：




Hi Team,


After analyzing our deployment pipeline, we've decided to implement a new CI/CD system to address the speed issues. Please join Friday's meeting to discuss the rollout plan.

小结
    

  • 核心原则 Omit needless words — 每个词都必须有存在的理由
    • 

  • 删除填充词：basically、actually、very、really、just
    • 

  • 替换废话短语：in order to → to，due to the fact that → because
    • 

  • 名词化还原：perform an analysis → analyze，make a decision → decide
    • 

  • 被动语态转主动语态，除非有意强调动作而非行动者
    • 

  • 合并重复信息，删除 there is/are，用强动词替代弱动词+副词
    • 

  • 简洁不等于简短——目标是不丢信息地压缩表达
    •
