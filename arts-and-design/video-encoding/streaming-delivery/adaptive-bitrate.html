自适应码率流媒体技术

自适应码率的核心原理

自适应码率（Adaptive Bitrate Streaming，ABR）是现代流媒体分发的基石技术。其核心思想是：将同一内容编码为多个质量档次（Bitrate Ladder），客户端根据实时网络状况和设备能力动态切换最合适的档次，在画质和流畅性之间寻求最优平衡。

ABR 的关键创新在于将"一次性传输"变为"逐片协商"：每下载一个分片后，客户端都可以根据最新的网络反馈重新决策下一个分片的质量档次。这种细粒度的自适应能力是传统渐进式下载所不具备的。

CMAF 统一格式
Common Media Application Format
CMAF（ISO/IEC 23000-19）是 Apple 和 Microsoft 于 2017 年联合提出的统一分片格式，旨在解决 HLS 和 DASH 使用不同分片格式导致的存储冗余：


CMAF 的核心约束：


    

  • 容器：fMP4（ISO BMFF）
    • 

  • 视频编码：H.264 / H.265 / AV1
    • 

  • 音频编码：AAC / E-AC-3 / Opus
    • 

  • 分片对齐：所有档次的 IDR 帧必须在相同时间点
    • 



CMAF 使得同一套编码分片可以同时通过 HLS 和 DASH 清单分发，CDN 存储空间节省约 50%。
