建筑历史

建筑是人类文明最持久的物质载体。从尼罗河畔的金字塔到 2026 年封顶的圣家族大教堂，每一座建筑都凝结着特定时代的技术能力、审美理想和社会结构。理解建筑历史，不仅是认识砖石与空间的演变，更是透过物质形态阅读人类文明的精神脉络。

本知识中心按时间线索将世界建筑史划分为四个章节：古代与古典时期、中世纪与文艺复兴、现代运动、当代建筑。每个章节聚焦关键文明区域的代表性建筑类型、结构创新与美学突破，同时关注不同文化圈之间的交流与影响。贯穿全书的核心问题是「为什么这样建」——技术条件、宗教信仰、政治权力与经济基础如何共同塑造了我们今天看到的建成环境。

本 hub 与兄弟 hub 的分工

「建筑历史」回答的是纵向的「何时、为何演变」——风格、流派、结构范式如何在时间中递进。它与同属「建筑与城市」的兄弟 hub 在视角上互补，不重复展开：

Hub 视角 与本 hub 的分工
建筑设计 如何做设计 本 hub 讲历史范式，设计 hub 讲当代方法论
结构与材料 力学怎样成立 本 hub 讲穹顶/拱券/框架的历史，结构 hub 讲其力学原理
城市规划 城市尺度 本 hub 讲单体与广场，城市 hub 讲区域与政策
可持续与净零建筑 碳与能源 本 hub 讲材料史，可持续 hub 讲全生命周期碳核算
遗产保护 如何保存 本 hub 讲建筑本体，遗产 hub 讲修复理论与技术
计算性设计与数字建造 数字工具 本 hub 讲参数化的历史脉络，数字 hub 讲算法与建造细节

凡涉及力学原理、修复技术、能耗核算、算法实现等纵深内容，本 hub 仅点到为止并以相对路径链接到对应兄弟 hub，避免内容重复。

  • 结构演化线：埃及与两河流域 → 希腊罗马 → 哥特式 → 工业革命 → 21世纪趋势
  • 东方/非西方线：中国传统建筑 → 伊斯兰建筑 → 地域主义与乡土建筑

前置知识

本 hub 面向通识读者，无硬性前置要求。若希望读得更深：

  • 想理解「为什么这样能立住」，可并读 结构与材料 · 结构体系（拱、券、穹顶、框架的力学）
  • 想理解材料革命的工程细节，可并读 结构与材料 · 建筑材料

建筑史为什么仍然重要

建筑史的价值不仅在于回顾过去，更在于为当代设计提供参照系。当我们讨论可持续建筑、地域性表达或数字化建造时，历史中积累的智慧——材料的诚实使用、结构与形式的统一、建筑与环境的对话——依然是最根本的设计原则。两河流域在材料匮乏中发明拱券、中国木构「过程优于永恒」的态度、哥特「形式追随结构」的骨架逻辑，都在当代议程（隐含碳、循环材料、参数化）中获得了新的生命。
