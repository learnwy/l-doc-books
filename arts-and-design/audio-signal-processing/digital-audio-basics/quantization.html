量化精度与动态范围

量化的数学本质

量化（Quantization）是将连续的模拟振幅值映射为有限个离散级别的过程。若使用 NNN 位（bit）表示每个采样值，则可用的量化级别数为 2N2^N2N：

16-bit：216=65536 个级别\text{16-bit：} 2^{16} = 65536 \text{ 个级别}16-bit：216=65536 个级别
24-bit：224=16777216 个级别\text{24-bit：} 2^{24} = 16777216 \text{ 个级别}24-bit：224=16777216 个级别

量化过程本质上是一种"取整"操作——真实振幅值被四舍五入到最近的量化级别。这个取整误差就是量化噪声（Quantization Noise），其最大值为半个量化步长。

量化步长=满刻度范围2N\text{量化步长} = \frac{\text{满刻度范围}}{2^N}量化步长=2N满刻度范围​
最大量化误差=±步长2\text{最大量化误差} = \pm \frac{\text{步长}}{2}最大量化误差=±2步长​
SNR 与位深度的经典关系
信噪比（Signal-to-Noise Ratio, SNR）是衡量音频质量的核心指标。对于均匀量化的 PCM 编码，理论最大 SNR 与位深度的关系为：


SNRmax=6.02N+1.76 dB\text{SNR}_{max} = 6.02N + 1.76 \text{ dB}SNRmax​=6.02N+1.76 dB

动态范围（Dynamic Range）是最大不失真电平与本底噪声之间的 dB 差。16-bit 提供约 96 dB 的动态范围，足以覆盖从最安静的耳语到最响亮的管弦乐全奏。24-bit 的 144 dB 动态范围远超任何物理环境的实际需求（宇宙射线辐射的噪声约为 -120 dBFS），但为后期处理提供了充裕的余量。


Dithering 技术
当从高位深降低到低位深时（如 24-bit → 16-bit 母带制作），直接截断（truncation）会引入相关性量化失真——表现为与信号相关的不自然谐波畸变。


Dithering 通过在截断前添加极低电平的随机噪声来消除这种相关性：


xdithered[n]=x[n]+d[n](d[n] 为随机噪声)x_{dithered}[n] = x[n] + d[n] \quad (d[n] \text{ 为随机噪声})xdithered​[n]=x[n]+d[n](d[n] 为随机噪声)
Dithering 的代价是轻微抬升了本底噪声，但换来了量化失真的完全消除。对于音乐信号而言，均匀的白噪声底底远比信号相关的谐波失真更容易被人耳忽略。

浮点数与定点数
现代 DAW 内部几乎全部使用 32-bit 浮点或 64-bit 浮点进行音频计算。浮点数的优势在于其巨大的动态范围——即使信号在处理过程中暂时超过 0 dBFS（Full Scale），也不会产生硬削波，因为浮点数可以表示远超 ±1.0\pm 1.0±1.0 的值。


32-bit float=1 位符号+8 位指数+23 位尾数\text{32-bit float} = \text{1 位符号} + \text{8 位指数} + \text{23 位尾数}32-bit float=1 位符号+8 位指数+23 位尾数
有效精度≈24 bit（在任何信号电平下）\text{有效精度} \approx 24 \text{ bit（在任何信号电平下）}有效精度≈24 bit（在任何信号电平下）
浮点的关键优势：精度随信号电平自适应。无论信号是 0 dBFS 还是 -100 dBFS，浮点格式都保持约 24-bit 的有效精度。而定点 16-bit 在 -60 dBFS 时仅剩约 6-bit 有效精度。

音频编码格式生态
数字音频的存储与传输格式分为三大类：


无损格式（Lossless）：完全保留原始 PCM 数据，仅做可逆压缩。


    

  • WAV/AIFF：无压缩 PCM 容器，录音棚标准
    • 

  • FLAC：开源无损压缩，压缩率约 50-60%
    • 

  • ALAC：Apple 生态无损压缩
    • 



有损格式（Lossy）：利用心理声学模型去除人耳不敏感的信息。


    

  • MP3：历史最悠久，兼容性最强
    • 

  • AAC：MP3 的继任者，同比特率音质更优
    • 

  • Opus：开源，低延迟，适应性强
    • 



高解析格式：


    

  • DSD：1-bit/2.8-5.6 MHz，SACD 格式
    • 

  • MQA：有争议的"折叠"高解析编码
    •
