音频编解码与传输

PCM 编码基础

PCM（Pulse Code Modulation，脉冲编码调制）是数字音频最基本的编码方式。它以固定时间间隔对模拟信号采样，将每个采样值量化为固定位数的整数，按时间顺序存储。PCM 数据是"生的"（raw）数字音频——没有任何压缩或变换，是所有其他编码格式的基础。

PCM 数据流的参数三元组：

PCM=(fs,N,C)=(采样率, 位深度, 通道数)\text{PCM} = (f_s, N, C) = (\text{采样率, 位深度, 通道数})PCM=(fs​,N,C)=(采样率, 位深度, 通道数)

有损压缩的心理声学原理
有损音频编码（MP3、AAC、Opus）的核心思想是：利用人耳感知的局限性，移除那些"人耳听不到或不敏感"的信息。这些局限性被统称为心理声学模型（Psychoacoustic Model）。


三大心理声学现象：


频率掩蔽（Frequency Masking）：一个强的频率成分会"遮盖"其附近较弱的频率成分。被遮盖的成分即使被移除，人耳也察觉不到。


时间掩蔽（Temporal Masking）：一个响亮的瞬态（如鼓击）之后约 5-20ms 内，较弱的声音会被掩蔽（后掩蔽）；瞬态之前约 2-5ms 也存在预掩蔽。


绝对听觉阈值（Absolute Threshold of Hearing）：不同频率下人耳的最低可感知响度不同。4 kHz 附近最灵敏，低频和极高频处阈值显著升高。

Opus 是 2020 年代综合性能最强的有损编码器——它在语音（低比特率）和音乐（高比特率）场景中都表现出色，延迟极低（最低 2.5ms），是 WebRTC、Discord、Zoom 等实时通信的默认音频编码。

音频容器格式
编码数据需要封装在容器格式（Container Format）中才能成为完整的文件：


容器与编码的区别：WAV 是容器（可以装 PCM、也可以装 ADPCM），AAC 是编码（可以装在 MP4 容器中，也可以装在 ADTS 裸流中）。


流媒体传输协议
2025 年的音频流媒体涉及多种传输协议：


HLS (HTTP Live Streaming)：Apple 主导，将音频分割为小片段（通常 6-10 秒）通过 HTTP 传输。自适应比特率切换。


DASH (Dynamic Adaptive Streaming over HTTP)：开放标准，与 HLS 类似但更灵活。


WebRTC：点对点实时通信，延迟可低至 50ms。使用 Opus 编码。


AES67/Dante：专业音频网络传输，延迟低于 1ms，用于录音棚、演出场所。
