DaVinci Resolve 节点系统

节点架构设计理念

DaVinci Resolve 的节点系统（Node-Based System）是其调色引擎的核心架构，也是区别于其他 NLE 内置调色工具（如 Premiere Pro 的 Lumetri）的根本特征。节点系统将调色流程抽象为有向无环图（DAG），每个节点代表一个独立的处理步骤，节点之间通过连线定义信号流向。

外部节点（Outside Node）
当一个节点包含 Qualifier 或 Power Window 选区时，Outside Node 自动获得该选区的反转——处理选区之外的所有区域。这避免了手动创建反向遮罩。


Outside Mask=1−Inside Mask\text{Outside Mask} = 1 - \text{Inside Mask}Outside Mask=1−Inside Mask

Key 输出与 Alpha 传递
每个节点有两对输入/输出：RGB 信号（绿色三角）和 Key/Alpha 信号（蓝色三角）。Key 输出允许将一个节点的选区传递给后续节点：


这种分离设计的优势：


    

  • 选区创建和色彩调整分离为独立节点
    • 

  • 一个选区可被多个调整节点复用
    • 

  • 选区可被模糊/腐蚀/膨胀后再传递
    •
