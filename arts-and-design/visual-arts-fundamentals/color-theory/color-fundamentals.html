色彩基础

核心概念

色彩是人类视觉体验中最具情感冲击力的元素。从物理学角度看，色彩是不同波长的电磁辐射在视网膜上引起的神经反应；从心理学角度看，色彩是主观感知与文化记忆的复合产物。对于视觉创作者而言，理解色彩的科学基础与感知机制，是从"凭感觉选色"走向"有逻辑用色"的关键跃迁。

色彩的三大属性构成了所有色彩讨论的基础框架：色相（Hue）是色彩的"名字"——红、橙、黄、绿、蓝、紫；饱和度（Saturation）是色彩的"纯度"——从鲜艳到灰暗；明度（Value/Brightness）是色彩的"亮度"——从亮到暗。这三个维度构成了一个三维色彩空间，任何一个具体的颜色都可以在这个空间中找到唯一的位置。

色彩模型与色彩空间
色彩模型（Color Model）是用数学方式描述颜色的系统。不同的色彩模型适用于不同的应用场景，理解它们的差异是避免"屏幕上的颜色和打印出来不一样"问题的关键。


RGB（Red-Green-Blue）是加色模型，适用于发光显示设备（屏幕、LED）。三种光色叠加，越加越亮，三色全满（255, 255, 255）得到白色。这是前端开发中最常用的色彩模型，CSS 的 rgb() 函数直接对应。


CMYK（Cyan-Magenta-Yellow-Key/Black）是减色模型，适用于印刷。四种油墨叠加，越加越暗，理论上三色全满得到黑色（实际偏褐色，所以加了 K 黑色通道）。设计师做印刷品时必须在 CMYK 模式下校色，因为某些屏幕上鲜艳的 RGB 颜色（如荧光绿）在 CMYK 中根本无法再现。


HSL/HSV 是基于人类感知的色彩模型。HSL（Hue-Saturation-Lightness）和 HSV（Hue-Saturation-Value）用色相环加上饱和度和亮度两个轴来描述颜色，更接近人们"先选颜色，再调深浅和鲜艳"的直觉操作。CSS 的 hsl() 函数支持这种模型，在生成和谐配色方案时特别好用。


LAB（CIELAB）是感知均匀的色彩空间，其中 L 代表亮度，a 代表红绿轴，b 代表蓝黄轴。LAB 的独特价值在于：两个颜色在 LAB 空间中的数学距离（ΔE）与人眼感知的差异程度成正比。这使它成为色彩管理和颜色匹配的标准工具。CSS Color Level 4 已支持 lab() 和 lch() 函数。

色轮与色彩关系
色轮（Color Wheel）是理解色彩关系的核心工具。标准的 12 色色轮由三原色（红、黄、蓝——传统颜料体系）或（红、绿、蓝——光色体系）出发，通过混合生成二次色和三次色。色轮上颜色的相对位置决定了它们之间的关系类型。


互补色（Complementary）是色轮上直径两端的颜色，如红与绿、蓝与橙。互补色并置产生最强烈的对比，互相增强彼此的鲜艳度。但直接大面积并置互补色会产生"振动"感，视觉上令人不适。解决方法是让一个互补色占主导，另一个作为点缀，或者使用近似互补色降低对比强度。


类似色（Analogous）是色轮上相邻的 2-4 个颜色，如蓝、蓝绿、绿。类似色天然和谐，因为它们共享相近的波长和温度特征。类似色配色适合营造统一、和谐的氛围，但如果没有足够的明度和饱和度差异，容易显得单调。


三等分色（Triadic）是色轮上等距的三个颜色，如红、黄、蓝。三等分配色活泼而平衡，适合需要丰富色彩又要保持和谐的场景。补色分裂（Split-Complementary）是互补色的变体——选一个主色，然后用其互补色两侧的颜色，比纯互补更柔和。

色深、色域与显示技术
色深（Color Depth/Bit Depth）决定了一个通道能表示多少个色彩等级。8-bit 色彩（最常见）每通道 256 级，RGB 总共约 1670 万色。10-bit 色彩每通道 1024 级，总共超过 10 亿色。在日常 Web 开发中 8-bit 足够，但在视频制作、HDR 内容和专业摄影中，10-bit 或更高色深是避免色带（Banding）——渐变中出现可见阶梯——的关键。


色域（Gamut）是一个色彩模型或设备能再现的颜色范围。sRGB 是 Web 和大多数消费级显示器的标准色域，覆盖了可见光谱中约 35% 的颜色。Display P3 是 Apple 设备普及的广色域标准，覆盖约 45% 的可见光谱，能显示更鲜艳的红色和绿色。Adobe RGB 覆盖约 50%，主要用于专业摄影和印刷。


在 Web 开发中，广色域的应用正在成为前沿话题。CSS Color Level 4 的 color() 函数支持指定色域，@media (color-gamut: p3) 可以检测设备是否支持 P3。这意味着设计师可以为支持广色域的设备提供更鲜艳的配色方案，同时为 sRGB 设备提供回退方案。

小结
    

  • 色彩由色相、饱和度、明度三大属性定义，构成三维色彩空间
    • 

  • RGB 适用于屏幕显示，CMYK 适用于印刷，HSL 更接近人的直觉操作
    • 

  • LAB 和 OKLCH 是感知均匀的色彩空间，在色彩管理和现代 CSS 中日益重要
    • 

  • 色轮是理解色彩关系的核心工具，互补、类似、三等分等关系各有特点
    • 

  • 色深决定渐变的平滑度，色域决定可显示颜色的鲜艳范围
    • 

  • 广色域（Display P3）正在通过 CSS Color Level 4 进入 Web 开发实践
    • 

  • 色彩科学知识是暗色模式、设计系统和可访问性设计的基础能力
    •
