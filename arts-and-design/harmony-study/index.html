Part III · 音乐与音频和声学 简介

和声学 简介

和声（Harmony）是多个音同时发响时产生的纵向音响关系。如果说旋律是音乐的"水平线条"，和声就是支撑这条线条的"垂直骨架"。本 Hub 聚焦一件事：和弦如何构成、如何连接、如何写好声部——从巴洛克数字低音到当代爵士与非功能和声的完整逻辑链。

本 Hub 讲什么、不讲什么

和声学不是孤立的学科，它处在乐理与编曲之间。理解边界能帮你在正确的 Hub 里找正确的内容，避免重复学习：

主题 归属 Hub 与本 Hub 的分工
音程、音阶、调式、转调、记谱 乐理基础 前置：和声学假设你已会读这些；本 Hub 不重讲音阶构成
和弦构成 / 进行 / 声部连接 / 现代和声 本 Hub 纵向音响关系与连接逻辑本身
把和声分配给乐器、音域音色平衡、织体 编曲与配器 下游：和声是"写什么和弦"，配器是"谁来奏、怎么铺"
和弦的协和/泛音/频谱基础 音频信号处理 声学解释（为何五度协和），本 Hub 只用结论
让 AI 生成和声进行 AI 音乐生成 模型与表示，本 Hub 提供其学习的"和声语法"

一句话：乐理给你音符，和声学教你把音符叠成和弦并连接成句，编曲再把和弦交给乐器。

前置知识

阅读本 Hub 前，你应当已经掌握（否则先到 乐理基础）：

  • 音程：能识别大小三度、纯五度、七度等——这是和弦叠置的原材料（见 音程体系）
  • 大小调音阶：调内各级和弦的性质直接由音阶决定（见 大小调音阶）
  • 调式与转调的基本概念：现代和声章节会频繁借用（见 调式基础）

不需要任何乐器演奏基础，但强烈建议边学边在钢琴或 DAW 上弹奏每个和弦与进行。

推荐学习路径

本 Hub 四章呈递进关系，但不同人群可走不同路线：

作曲 / 编曲入门者（按顺序通读）

  1. 第一章 和弦构建：三和弦 → 七和弦 → 延伸和弦，建立"和弦从哪来"的直觉
  2. 第二章 和声进行：功能和声 → 常用进行 → 和声节奏，学会把和弦连成句子
  3. 第三章 声部连接：把进行写成多声部、避开平行禁忌
  4. 第四章 现代和声：进阶色彩

流行 / 编曲速成者（最短可用路径）

  • 直接读 三和弦 + 七和弦 → 功能和声 → 常用进行，即可写出主流流行作品的和声框架，需要时再补 调式互换

爵士 / R&B 方向

  • 通读第一、二章后，重点攻第四章 爵士和声（ii-V-I、三全音替代、voicing），并回看 延伸和弦

音乐分析 / 学术方向

  • 第二章 功能和声 + 第三章全章 + 第四章 新和声语言（Neo-Riemannian、非功能体系）是分析工具的核心

四章概览

  • 第一章「和弦构建」：三度叠置原理，三和弦、七和弦、延伸和弦的构成与标记系统。
  • 第二章「和声进行」：功能和声三分法、终止式、常用进行套路、二次属和弦与和声节奏。
  • 第三章「声部连接」：四部和声写作、平行五八度禁忌、非和弦音与对位入门。
  • 第四章「现代和声」：爵士和声体系、调式互换、印象派与 20 世纪非功能和声语言。
