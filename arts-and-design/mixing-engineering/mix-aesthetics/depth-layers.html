深度层次与前后定位技术

前后定位的声学心理学

人耳判断声源距离的机制与判断方向的机制不同——距离感知主要依赖单耳线索（而非双耳差异），包括：绝对声压级、直达声与混响的比率、频谱变化和熟悉度。这使得在立体声混音中创造深度层次完全可行，不需要多声道系统。

感知距离∝1D/R Ratio⋅1HF Content⋅1Level\text{感知距离} \propto \frac{1}{\text{D/R Ratio}} \cdot \frac{1}{\text{HF Content}} \cdot \frac{1}{\text{Level}}感知距离∝D/R Ratio1​⋅HF Content1​⋅Level1​
距离线索 物理基础 感知强度 可控性
电平（Level） 能量扩散 强 推子直控
D/R 比 反射积累 极强 混响/早期反射
高频衰减 空气吸收 中等 EQ/LPF
瞬态清晰度 传播模糊 中等 Attack/饱和
频谱复杂度 多路径叠加 弱 Chorus/Saturation

D/R（Direct-to-Reverberant）比是最有效的深度控制工具：

D/R(dB)=20log⁡10(EdirectEreverb)\text{D/R}(\text{dB}) = 20\log_{10}\left(\frac{E_{direct}}{E_{reverb}}\right)D/R(dB)=20log10​(Ereverb​Edirect​​)

EQ 处理混响返回——混响信号的高频和低频通常需要控制：


Reverb Return EQ:HPF 200 Hz+LPF 8 kHz\text{Reverb Return EQ:} \quad \text{HPF 200 Hz} + \text{LPF 8 kHz}Reverb Return EQ:HPF 200 Hz+LPF 8 kHz
去除混响的低频防止"浑浊"；去除极高频防止混响过于明亮产生"嘶嘶"感。

同步改变这些参数创造连贯的距离变化。仅改变一个参数（如只加混响但不降电平）会产生不自然的感觉——声音"在远处但很大声"。

频率与深度的交互作用
频率分布会影响元素的感知"位置"——这不仅是心理声学效应，也有物理基础：


高频空气吸收系数随距离增加：


α(f)=α0⋅f2(简化模型, f 以 kHz 计)\alpha(f) = \alpha_0 \cdot f^2 \quad \text{(简化模型, f 以 kHz 计)}α(f)=α0​⋅f2(简化模型, f 以 kHz 计)
10 kHz 信号在 20 米距离上衰减约 2–3 dB（相对于 1 kHz）。这意味着远处声源的高频自然偏弱。
