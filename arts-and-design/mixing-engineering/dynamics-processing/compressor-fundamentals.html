压缩器原理与参数精解

压缩器的基本工作模型

压缩器（Compressor）是一种自动增益控制设备，当输入信号超过设定阈值时降低输出增益。其核心行为可用分段线性传递函数描述：

ydB={xdBif xdB≤TT+xdB−TRif xdB>Ty_{dB} = \begin{cases} x_{dB} & \text{if } x_{dB} \leq T \\ T + \frac{x_{dB} - T}{R} & \text{if } x_{dB} > T \end{cases}ydB​={xdB​T+RxdB​−T​​if xdB​≤Tif xdB​>T​

其中 TTT 为阈值（Threshold），RRR 为压缩比（Ratio），xdBx_{dB}xdB​ 为输入电平，ydBy_{dB}ydB​ 为输出电平。当 R=4:1R = 4:1R=4:1 且信号超过阈值 12 dB 时：

输出=T+124=T+3 dB(增益压缩了 9 dB)\text{输出} = T + \frac{12}{4} = T + 3\ \text{dB} \quad \text{(增益压缩了 9 dB)}输出=T+412​=T+3 dB(增益压缩了 9 dB)

增益压缩量（Gain Reduction, GR）：

GR=xdB−ydB=(xdB−T)⋅(1−1R)(当 x>T)\text{GR} = x_{dB} - y_{dB} = (x_{dB} - T) \cdot \left(1 - \frac{1}{R}\right) \quad \text{(当 } x > T\text{)}GR=xdB​−ydB​=(xdB​−T)⋅(1−R1​)(当 x>T)

Attack 与 Release 的时间常数
Attack 和 Release 是压缩器的灵魂参数——它们决定压缩器对信号动态变化的"反应速度"，直接塑造声音的瞬态特征和节奏感。


Attack Time 定义为增益从 0 dB 衰减到目标 GR 值约 63%（或 2/3）所需的时间（不同厂商定义有差异）：


G(t)=Gtarget⋅(1−e−t/τa)G(t) = G_{target} \cdot (1 - e^{-t/\tau_a})G(t)=Gtarget​⋅(1−e−t/τa​)
τa=tattack−ln⁡(1−0.63)=tattack\tau_a = \frac{t_{attack}}{-\ln(1 - 0.63)} = t_{attack}τa​=−ln(1−0.63)tattack​​=tattack​

Knee 与压缩曲线形状
Knee（膝点）定义了压缩器在阈值附近的过渡方式。Hard Knee 在阈值处急剧转折；Soft Knee 提供渐进过渡，使低电平信号也开始接受轻微压缩。


Soft Knee:y=x+(1/R−1)⋅(x−T+W/2)22W在 T−W/2≤x≤T+W/2\text{Soft Knee:} \quad y = x + \frac{(1/R - 1) \cdot (x - T + W/2)^2}{2W} \quad \text{在 } T-W/2 \leq x \leq T+W/2Soft Knee:y=x+2W(1/R−1)⋅(x−T+W/2)2​在 T−W/2≤x≤T+W/2
其中 WWW 为 Knee 宽度（dB）。

Soft Knee 的实际效果：信号在到达标称阈值之前已经开始接受轻微压缩，在超过阈值后逐渐达到设定比率。这种行为模拟了光电压缩器（如 LA-2A）的自然特性。


补偿增益与 A/B 对比方法论
压缩必然降低信号的峰值电平（和感知响度）。Makeup Gain 补偿这一衰减，使压缩后的信号与原始信号在主观响度上匹配。


Makeup Gain≈Average GR×0.5 至 0.7\text{Makeup Gain} \approx \text{Average GR} \times 0.5 \text{ 至 } 0.7Makeup Gain≈Average GR×0.5 至 0.7
为什么不完全补偿？因为 GR 是动态变化的——峰值处压缩多、均值处压缩少——完全补偿峰值 GR 会使平均电平过热。
