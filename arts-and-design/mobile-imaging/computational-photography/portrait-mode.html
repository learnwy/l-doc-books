人像模式与景深计算

景深模拟的动机

传统相机通过大光圈镜头（如 f/1.4、f/2.0）实现浅景深效果——主体清晰而背景自然虚化（Bokeh），这是人像摄影的核心美学要素。然而智能手机的镜头等效光圈通常仅为 f/1.8—f/2.8，且传感器面积远小于全画幅相机，导致物理景深极深——几乎一切都在焦内。人像模式（Portrait Mode）通过计算手段模拟大光圈的浅景深效果，是计算摄影中最具用户感知度的功能之一。

深度估计方法
双目立体视觉（Stereo Vision）
iPhone 7 Plus 于 2016 年开创的双摄人像模式，本质上是双目立体视觉的工程应用。两颗相机（广角 + 长焦）以已知的基线距离（Baseline）同时拍摄场景，通过以下步骤估计深度：


    

  1. 极线矫正（Rectification）：将两幅图像对齐到共同的极线几何，使对应点搜索简化为一维扫描
    2. 

  2. 立体匹配（Stereo Matching）：对每个像素搜索左右图像中的最佳对应点，计算视差（Disparity）
    3. 

  3. 深度计算：利用三角测量公式 depth = baseline × focal_length / disparity 将视差转换为绝对深度
    4. 



双目方法的优势是有物理几何基础，深度精度随基线增大而提升。局限在于：


    

  • 无纹理区域（白墙、天空）难以匹配
    • 

  • 重复纹理导致匹配歧义
    • 

  • 遮挡区域缺乏对应点
    • 

  • 手机基线短（约 1—2cm），远距离深度精度快速下降
    • 



ToF 传感器（Time-of-Flight）
ToF 传感器通过发射红外光脉冲并测量返回时间来直接获取深度信息。分为两类：


dToF（Direct ToF）：测量光子飞行的绝对时间差，精度高但传感器成本高。Apple 的 LiDAR Scanner（用于 iPad Pro 和 iPhone Pro 系列）即为 dToF 方案，最远探测距离 5 米，深度分辨率可达 2mm。


iToF（Indirect ToF）：通过相位差间接计算距离，成本较低但易受多路径干扰（Multipath Interference）。早期 Android 旗舰（如 Samsung Galaxy S20 Ultra）多采用此方案。


ToF 的核心优势是不依赖纹理信息，在暗光和无纹理场景中仍能提供可靠深度。但其空间分辨率较低（通常仅 VGA 级别或更低），需要与 RGB 图像融合才能获得像素级深度图。


单目深度估计（Monocular Depth Estimation）
当设备仅配备单颗相机时（如 iPhone SE、中低端安卓机），深度估计完全依赖机器学习模型。网络通过大规模标注数据学习「从单张 2D 图像推断 3D 深度」的映射关系。

Apple 的 DepthPro（2024）实现了 0.3 秒内生成 2.25M 像素的高精度深度图，且无需相机内参信息。其核心创新是多尺度视觉 Transformer 架构，在全局几何一致性和局部细节锐利度之间取得平衡。


多源融合策略
现代旗舰手机不使用单一深度估计方法，而是融合多个信号源：


iPhone 16 Pro 同时利用双摄视差、LiDAR 深度点云、PDAF 相位信息和 ML 模型预测，通过置信度加权融合生成最终深度图。LiDAR 提供骨架级深度约束，双摄填充中距离细节，ML 模型处理远景和遮挡区域。


主体分割（Subject Segmentation）
语义分割与实例分割
人像模式需要精确区分「主体」与「背景」。现代方案使用实例分割（Instance Segmentation）而非简单的前景/背景二分类，能够同时处理多个人物和非人物主体（宠物、物体）。


关键模型特点：


    

  • 输入：RGB 图像 + 初始深度图
    • 

  • 输出：每个实例的像素级 Alpha Matte
    • 

  • 推理时间：NPU 加速后 <20ms
    • 

  • 支持类别：人、猫、狗、食物、花卉等 20+ 类
    • 



Alpha Matting 精细化
粗分割的边缘通常存在锯齿和误判（尤其在头发、毛发区域），需要精细化处理：


三元图（Trimap）方法：将图像分为确定前景、确定背景、不确定区域三类，在不确定区域内精确估计每个像素的 Alpha 值（0.0—1.0 的连续值）。


深度学习 Matting：端到端网络直接预测高精度 Alpha Matte，代表方法包括 MODNet（轻量级实时方案）和 ViTMatte（Transformer 架构高精度方案）。Apple 在 A18 Pro 上部署了优化的 Matting 网络，可在 Neural Engine 上以 60fps 运行。


边缘优化技术
即使有了高精度 Alpha Matte，在景深渲染后仍可能出现「光晕」（Halo）或「色泄」（Color Bleeding）伪影。优化手段包括：


    

  • 引导滤波（Guided Filter）：以原始图像为引导信号，对 Alpha Matte 进行边缘感知平滑
    • 

  • KNN Matting：基于颜色空间 K 近邻传播 Alpha 值
    • 

  • 深度感知边缘检测：在深度不连续处（深度梯度大的位置）强制锐利化 Alpha 边界
    • 

  • 时序一致性：在视频人像模式中维护帧间 Alpha 的平滑过渡
    • 



Bokeh 渲染
物理 Bokeh 模型
真实相机的虚化效果由以下物理参数决定：


    

  • 光圈形状：六角形、八角形或圆形光圈叶片决定了焦外光斑（Bokeh Ball）的形状
    • 

  • 弥散圆直径（Circle of Confusion, CoC）：与物距、焦距、光圈大小的关系为 CoC = (f² × |d - d_f|) / (N × d × d_f)，其中 f 为焦距，N 为光圈值，d 为物距，d_f 为对焦距离
    • 

  • 口径蚀（Vignetting）：画面边缘的 Bokeh 呈现椭圆形（Cat-eye Bokeh）
    • 

  • 色差（Chromatic Aberration）：焦外高对比边缘出现紫/绿色边
    • 



计算 Bokeh 实现
手机人像模式模拟 Bokeh 的典型管线：


    

  1. 深度到 CoC 映射：根据用户选择的虚拟光圈值和对焦距离，将深度图转换为每像素 CoC 尺寸
    2. 

  2. 分层渲染：将场景按深度分为多层，对每层应用不同模糊半径的卷积
    3. 

  3. 散点渲染（Scatter-based Rendering）：对高亮度小光源应用光圈形状的散射核，模拟真实 Bokeh Ball
    4. 

  4. 前后景处理：前景虚化需要特殊处理——前景物体遮挡背景但自身也需虚化
    5. 

  5. Alpha 合成：利用精细分割的 Alpha 通道进行前景/背景混合
    6. 



后期焦点调整
iPhone 自 iPhone 13 起支持「后期调焦」——拍摄时保存完整的深度图数据，用户可在照片编辑中重新选择对焦点和光圈值。这要求：


    

  • 原始图像以全焦深（全部清晰）方式保存
    • 

  • 深度图以 16-bit 精度与图像同步存储
    • 

  • 渲染引擎在编辑时实时重新计算 Bokeh
    •

人像光效（Portrait Lighting）
Apple 人像光效将景深计算扩展到光照模拟领域：


3D 面部建模：利用 LiDAR 和 TrueDepth 传感器构建面部 3D 网格，结合面部标志点检测（68 个特征点）确定五官位置和朝向。


虚拟布光：基于面部 3D 模型应用虚拟光源，模拟摄影棚打光效果——自然光、摄影室光、轮廓光、舞台光、高调单色光。每种光效对应不同的光照模型：


    

  • 自然光：柔和的环境光 + 方向性主光
    • 

  • 摄影室光：正面平光降低阴影对比
    • 

  • 轮廓光：侧逆光勾勒面部轮廓
    • 

  • 舞台光：点光源聚焦面部，背景纯黑
    • 



实时预览：借助 Neural Engine 的实时推理能力，用户在取景器中即可看到光效变化，调整光源方向和强度。


技术挑战与伦理考量
技术挑战
    

  • 透明/半透明物体：眼镜、玻璃杯、婚纱等半透明物体的深度和分割极为困难
    • 

  • 细微结构：蕾丝、铁栅栏、草丛等精细结构容易被误分割
    • 

  • 距离限制：大多数人像模式要求主体在 0.5—2.5 米范围内
    • 

  • 多人场景：多人处于不同深度时的分层虚化策略
    • 



伦理考量
人像模式中的美颜处理引发了关于审美标准和身体形象的讨论。2025 年起，多家厂商开始提供「真实人像」选项——保留皮肤纹理和自然瑕疵，仅进行景深渲染而不做美颜处理。Google 的 Real Tone 技术确保不同肤色在人像模式下获得准确还原，避免肤色偏白或过度平滑的问题。
