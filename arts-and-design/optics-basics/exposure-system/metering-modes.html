测光模式

概述

测光是相机确定正确曝光的核心决策过程。无论多么先进的传感器，如果曝光错误——信号都被裁切或淹没在噪底中——画质就无从谈起。本文系统解析各种测光模式的算法原理、适用场景与局限性，帮助你在自动测光与手动补偿之间做出精准判断。



测光的物理基础
18% 灰——测光基准
所有测光系统都假设场景的平均反射率为 18%（中性灰）。18% 灰对应的反射率使得在标准照明下，测光表给出的曝光值能让该灰度正确还原。


Lgray=0.18⋅Eillumination/πL_{gray} = 0.18 \cdot E_{illumination} / \piLgray​=0.18⋅Eillumination​/π
这一假设在大多数自然场景中成立（森林、城市街景等统计平均确实接近 18%），但在极端场景（雪地、黑猫）中会导致系统性误差。

相机内置的测光系统均为反射式——它测的是"物体看起来有多亮"，而不是"照在物体上的光有多强"。




矩阵测光（Matrix / Evaluative Metering）
工作原理
矩阵测光将画面划分为多个区域（现代相机 1000–30,000+ 区域），分别测量每个区域的亮度，然后通过复杂的算法决定最终曝光：


    

  1. 场景分区亮度检测
    2. 

  2. 对焦点位置加权（假设主体在对焦区域）
    3. 

  3. 色彩信息分析（天空蓝 → 可能是户外高反差场景）
    4. 

  4. 数据库匹配（与数万张已知场景的曝光数据对比）
    5. 

  5. 计算最终曝光值
    6.

中央重点测光（Center-Weighted Metering）
工作原理
以画面中央区域（直径约 8–15mm 的圆形）为主要测光依据，边缘区域的贡献递减。典型权重分布：


    

  • 中央区域：60%–80% 权重
    • 

  • 边缘区域：20%–40% 权重
    • 



适用场景
    

  • 主体位于画面中央的人像摄影
    • 

  • 需要可预测、一致的测光结果
    • 

  • 连拍中需要曝光稳定（不因构图微调而跳变）
    • 



与矩阵测光的差异
中央重点测光的行为更"可预测"——结果主要取决于中央区域的亮度，不会因为边缘进入一片亮区或暗区而大幅跳变。这在需要连续稳定曝光的视频拍摄中尤为有用。




点测光（Spot Metering）
工作原理
只测量画面中极小区域（通常 1%–5% 面积，对应对焦点附近）的亮度。测光结果完全取决于这个小区域。


EVspot=log⁡2LspotKEV_{spot} = \log_2\frac{L_{spot}}{K}EVspot​=log2​KLspot​​
其中 KKK 为校准常数（约 12.5 cd/m²）。

高光加权测光（Highlight-Weighted Metering）
工作原理
专门保护高光区域不溢出的测光模式。算法检测画面中最亮的区域，确保这些区域不超过传感器的满阱容量。


适用场景
    

  • 舞台摄影（聚光灯+黑暗背景）
    • 

  • 拍摄白色物体/婚纱
    • 

  • 需要 ETTR 但不想手动判断的场景
    • 

  • 逆光场景中保护天空高光
    •

包围曝光（Exposure Bracketing）
原理
以当前测光值为中心，自动拍摄多张不同曝光的照片：


EVi=EVcenter+Δ⋅i,i=−n,…,0,…,+nEV_i = EV_{center} + \Delta \cdot i, \quad i = -n, \ldots, 0, \ldots, +nEVi​=EVcenter​+Δ⋅i,i=−n,…,0,…,+n
常用设置：±1 EV × 3 张 或 ±2 EV × 5 张。


应用
    

  • HDR 合成：将多张包围曝光合并为高动态范围图像
    • 

  • 曝光保险：在不确定的光线条件下确保至少一张正确
    • 

  • Focus Stacking 辅助：某些场景同时需要曝光和焦点包围
    •

本章小结
测光是将物理光量转化为曝光决策的桥梁。矩阵测光覆盖 80% 的日常场景，但在高反差、特殊反射率的条件下需要手动介入——点测光+Zone System 思维是最精确的手动测光方法。理解每种测光模式的算法逻辑和假设条件，你就能预判它何时会失准，并提前做出正确的曝光补偿。
