像素与感光能力

概述

像素是图像传感器的最小感光单元。每个像素的物理结构——光电二极管面积、微透镜形状、色彩滤波器特性——直接决定了传感器的信噪比、分辨率与色彩精度。在"像素大战"的喧嚣背后，真正影响画质的是每个像素能收集多少光子、以多高的效率将其转化为有用信号。

填充因子
填充因子（Fill Factor）是有效感光面积占总像素面积的比例。理想值为 100%。影响因素：


    

  • 像素间隙（死区）
    • 

  • 读出电路占用面积
    • 

  • 传输门面积
    • 



BSI 技术将填充因子从 FSI 的 ~50% 提升至 ~80%，微透镜进一步将等效填充因子提升至接近 95%。

色彩滤波阵列
Bayer 阵列
1976 年，Bryce Bayer 发明了至今最广泛使用的色彩滤波阵列：每 2×2 像素组包含 1R+2G+1B。绿色占 50% 是因为人眼对绿光最敏感，绿色通道承载了大部分亮度信息。


去马赛克（Demosaicing）算法从 Bayer 原始数据还原出全彩色图像，常用方法包括双线性插值、AHD、AMaZE 等。去马赛克的质量直接影响细节保留与摩尔纹抑制。

微透镜技术
聚光作用
微透镜（On-Chip Microlens）位于每个像素正上方，将入射到非感光区的光线折向光电二极管中心。没有微透镜的像素，大量落在间隙和电路区域的光子将被浪费。


微透镜设计的关键参数：


    

  • 焦距：需要精确匹配像素深度
    • 

  • 间隙：相邻微透镜之间的间隙（Gap-less 设计追求零间隙）
    • 

  • 偏移：边缘像素的微透镜需要向中心偏移（CRA 匹配）以适应主光线角度
    • 



相位检测自动对焦（PDAF）像素
部分像素的微透镜被遮蔽一半，只接收来自透镜左半或右半的光线。通过比较左右 PDAF 像素的信号差异，相机可以计算散焦量和方向——这就是片上相位检测 AF 的原理。


现代全像素双核 PDAF（Dual Pixel AF）将每个像素分为左右两个子光电二极管，在不牺牲分辨率的情况下实现全画面相位对焦。




量子效率深度分析
量子效率（QE）是波长的函数，其曲线形状取决于：


    

  1. 短波端截止：受微透镜/CFA 材料吸收和光电二极管浅层复合影响
    2. 

  2. 长波端截止：硅的吸收系数随波长增大而减小，深红/近红外需更深的光电二极管
    3. 

  3. 峰值位置：BSI 传感器峰值通常在 500–600 nm
    4. 



实际应用意义：


    

  • QE 高 → 同等曝光下信号更强 → 噪声更低
    • 

  • QE 曲线平坦 → 色彩一致性好
    • 

  • 红外响应 → 需要 IR-cut 滤镜（否则色彩偏暖）
    • 





本章小结
像素是传感器画质的最小构成单元。从物理面积决定的信噪比上限，到色彩滤波阵列的设计哲学，再到微透镜的聚光优化，每一个工程决策都在分辨率、噪声、动态范围之间做出取舍。理解这些权衡，你就能看穿"亿级像素"的营销噱头，关注真正决定画质的核心指标——像素尺寸、满阱电荷与读出噪声。
