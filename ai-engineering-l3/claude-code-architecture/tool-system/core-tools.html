核心工具实现

BashTool 命令执行

BashTool 是 Claude Code 中最复杂的工具之一，它负责在用户系统上执行 Shell 命令。安全性是首要考虑——命令在执行前需要经过分类、AST 解析和沙箱检查。

type CommandCategory = 'search' | 'read' | 'list' | 'silent' | 'neutral' | 'write' | 'dangerous';

function classifyCommand(command: string): CommandCategory {
  const parsed = parseShellAST(command);

  if (isSearchCommand(parsed)) return 'search';
  if (isReadCommand(parsed)) return 'read';
  if (isListCommand(parsed)) return 'list';
  if (isSilentCommand(parsed)) return 'silent';
  if (isDangerousCommand(parsed)) return 'dangerous';

  return 'neutral';
}

命令分类决定了权限检查和沙箱策略：

| 分类 | 示例命令 | 权限需求 | 沙箱行为 | | ----------- | --------------------- | -------- | -------- | ------ | | search | grep -r "pattern" . | 自动允许 | 只读沙箱 | | read | cat file.txt | 自动允许 | 只读沙箱 | | list | ls -la, find . | 自动允许 | 只读沙箱 | | silent | echo "test" | 自动允许 | 无限制 | | neutral | npm install | 需要确认 | 受限沙箱 | | write | rm -rf node_modules | 需要确认 | 受限沙箱 | | dangerous | curl | bash | 明确拒绝 | 不执行 |

BashTool 还支持 AST 级别的 sed 命令解析，用于识别和跟踪通过 sed -i 进行的文件修改。




提示： BashTool 的自动后台机制会在命令执行超过 15 秒时将其转为后台任务（LocalShellTask），避免阻塞主对话流。






FileReadTool 读取去重
FileReadTool 实现了一个精巧的读取去重优化：当同一文件在对话中被多次读取且内容未变（mtime 相同）时，返回 file_unchanged 存根而非完整内容。


interface ReadDeduplication {
  path: string;
  range?: { start: number; end: number };
  mtime: number;
}

async function fileReadCall(
  input: { path: string; offset?: number; limit?: number },
  context: ToolUseContext,
): Promise<ToolResult<FileReadOutput>> {
  const stat = await fsStat(input.path);
  const cacheKey = buildCacheKey(input.path, input.offset, input.limit);
  const cached = context.readFileState.get(cacheKey);

  if (cached && cached.mtime === stat.mtimeMs) {
    return successResult({
      content: 'file_unchanged',
      isDeduped: true,
    });
  }

  const content = await readFileContent(input.path, input.offset, input.limit);

  context.readFileState.set(cacheKey, {
    content,
    mtime: stat.mtimeMs,
    encoding: 'utf-8',
  });

  return successResult({ content, isDeduped: false });
}

FileEditTool 字符串替换模型
FileEditTool 采用基于字符串替换的编辑模型（old_string → new_string），而非传统的行号 + diff 方式。这种设计降低了模型出错的概率。


interface FileEditInput {
  path: string;
  old_string: string;
  new_string: string;
}

async function fileEditCall(input: FileEditInput, context: ToolUseContext): Promise<ToolResult<FileEditOutput>> {
  const cached = context.readFileState.get(input.path);
  if (!cached) {
    return errorResult({ success: false }, 'File must be read before editing');
  }

  const stat = await fsStat(input.path);
  if (stat.mtimeMs !== cached.mtime) {
    return errorResult({ success: false }, 'File has been modified since last read (concurrent modification)');
  }

  const content = await readFile(input.path, detectEncoding(input.path));
  const index = content.indexOf(input.old_string);

  if (index === -1) {
    return errorResult({ success: false }, 'old_string not found in file');
  }

  const newContent = content.replace(input.old_string, input.new_string);
  await writeFile(input.path, newContent, detectEncoding(input.path));

  return successResult({ success: true });
}

Glob 与 Grep 工具
Glob 和 Grep 工具底层都使用 ripgrep (rg) 作为搜索引擎，并自动排除版本控制目录和插件缓存。


async function grepCall(
  input: { pattern: string; path?: string; include?: string },
  context: ToolUseContext,
): Promise<ToolResult<GrepOutput>> {
  const args = buildRipgrepArgs(input);
  const result = await execCommand('rg', args, {
    timeout: 30000,
    maxBuffer: 1024 * 1024,
  });

  return successResult(parseRipgrepOutput(result.stdout));
}

function buildRipgrepArgs(input: GrepInput): string[] {
  const args = [input.pattern, '--json', '--max-count=50'];

  if (input.path) args.push(input.path);
  if (input.include) args.push('--glob', input.include);

  args.push('--glob', '!.git');
  args.push('--glob', '!node_modules');
  args.push('--glob', '!*.lock');

  return args;
}

SandboxManager 集成
BashTool 通过 SandboxManager 实现文件系统和网络的沙箱隔离。


interface SandboxConfig {
  filesystem: {
    allow: string[];
    deny: string[];
  };
  network: {
    allowedHosts: string[];
  };
}

class SandboxManager {
  constructor(private config: SandboxConfig) {}

  canAccessPath(path: string): boolean {
    for (const denied of this.config.filesystem.deny) {
      if (path.startsWith(denied)) return false;
    }

    for (const allowed of this.config.filesystem.allow) {
      if (path.startsWith(allowed)) return true;
    }

    return false;
  }

  canAccessNetwork(host: string): boolean {
    return this.config.network.allowedHosts.some((allowed) => host === allowed || host.endsWith(`.${allowed}`));
  }
}

小结
    

  • BashTool 将命令分为 7 类（search/read/list/silent/neutral/write/dangerous），不同分类有不同的权限和沙箱策略。
    • 

  • FileReadTool 通过 mtime 比较实现读取去重，重复读取未变文件返回 file_unchanged 存根，节省约 18% token。
    • 

  • FileEditTool 采用字符串替换模型（old_string → new_string），强制"先读后改"并通过 mtime 防止并发修改。
    • 

  • Glob/Grep 工具底层使用 ripgrep，自动排除 .git/、node_modules/ 等目录。
    • 

  • SandboxManager 对 BashTool 实施 deny-by-default 的文件系统和网络隔离。
