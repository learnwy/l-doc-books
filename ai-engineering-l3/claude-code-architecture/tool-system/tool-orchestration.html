工具编排

StreamingToolExecutor 并行执行

StreamingToolExecutor 是工具编排的核心组件，它在 API 流式响应过程中并行执行多个工具调用。当模型在一次响应中发出多个 tool_use 块时，executor 会根据并发安全性决定是否并行执行。

class StreamingToolExecutor {
  private running: Map<string, Promise<ToolResult<unknown>>> = new Map();
  private completed: Map<string, ToolResult<unknown>> = new Map();

  async executeToolUse(
    toolUse: ToolUseBlock,
    tools: Tool<unknown, unknown>[],
    context: ToolUseContext,
  ): Promise<ToolResult<unknown>> {
    const tool = tools.find((t) => t.name === toolUse.name);
    if (!tool) return errorResult(null, `Unknown tool: ${toolUse.name}`);

    const canParallel = this.canRunInParallel(tool);

    if (canParallel) {
      const promise = this.executeSingle(tool, toolUse.input, context);
      this.running.set(toolUse.id, promise);
      return promise;
    }

    await this.waitForRunning();
    return this.executeSingle(tool, toolUse.input, context);
  }

  private canRunInParallel(tool: Tool<unknown, unknown>): boolean {
    return tool.isConcurrencySafe === true;
  }
}

提示： isConcurrencySafe 采用 fail-closed 设计——只有显式声明为 true 的工具才能并行执行。undefined 或 false 都会导致串行执行。






并发安全控制
并发安全性的判定不仅基于工具的静态声明，还需要考虑运行时上下文。例如，两个 FileReadTool 调用可以并行（只读），但一个 FileReadTool 和一个 FileEditTool 对同一文件的调用则不能并行。


interface ConcurrencyPolicy {
  isConcurrencySafe: boolean;
  conflictsWith?: string[];
}

function canExecuteInParallel(
  tool: Tool<unknown, unknown>,
  runningTools: Map<string, Tool<unknown, unknown>>,
): boolean {
  if (!tool.isConcurrencySafe) return false;

  for (const [, running] of runningTools) {
    if (!running.isConcurrencySafe) return false;
  }

  return true;
}

工具结果持久化
当工具返回的结果超过 maxResultSizeChars 阈值时，结果会被写入磁盘文件而非内联返回。这防止了大型工具输出膨胀 API 请求。


const MAX_RESULT_SIZE_CHARS = 50000;

async function persistLargeResult(result: ToolResult<unknown>, toolUseId: string): Promise<ToolResult<unknown>> {
  const serialized = JSON.stringify(result.data);

  if (serialized.length <= MAX_RESULT_SIZE_CHARS) {
    return result;
  }

  const outputPath = path.join(tmpdir(), 'claude-code', 'tool-results', `${toolUseId}.json`);

  await mkdirp(path.dirname(outputPath));
  await writeFile(outputPath, serialized, 'utf-8');

  return {
    ...result,
    data: null,
    resultForAssistant: `Result too large (${serialized.length} chars). Written to: ${outputPath}`,
  };
}

runTools 执行管线
runTools() 是工具执行的完整管线，依次执行验证、权限检查、用户确认和工具调用。


async function runTools(
  toolUse: ToolUseBlock,
  tool: Tool<unknown, unknown>,
  context: ToolUseContext,
): Promise<ToolResult<unknown>> {
  const parsed = tool.inputSchema.safeParse(toolUse.input);
  if (!parsed.success) {
    return errorResult(null, `Invalid input: ${parsed.error.message}`);
  }

  const validation = await tool.validateInput(parsed.data, context);
  if (!validation.valid) {
    return errorResult(null, validation.reason);
  }

  const permission = await tool.checkPermissions(parsed.data, context);
  if (permission.result === 'deny') {
    return errorResult(null, permission.reason);
  }

  if (permission.result === 'ask') {
    const approved = await tool.canUseTool(parsed.data, context);
    if (!approved) {
      return errorResult(null, 'User denied tool execution');
    }
  }

  const result = await tool.call(parsed.data, context);
  return tool.mapToolResultToToolResultBlockParam(result);
}

提示： 管线中的每个阶段都是独立的检查点——前一个阶段失败时会立即返回错误，不会执行后续阶段。这种"快速失败"模式减少了不必要的计算。






ToolSearchTool 按需加载
ToolSearchTool 实现了延迟工具发现机制：不常用的工具在启动时不加载，只有当模型通过关键词搜索时才按需加载。


interface DeferredTool {
  name: string;
  keywords: string[];
  loader: () => Promise<Tool<unknown, unknown>>;
}

class ToolSearchTool {
  private deferred: DeferredTool[] = [];
  private loaded: Map<string, Tool<unknown, unknown>> = new Map();

  register(deferred: DeferredTool): void {
    this.deferred.push(deferred);
  }

  async search(query: string): Promise<Tool<unknown, unknown>[]> {
    const matches = this.deferred.filter((d) =>
      d.keywords.some((kw) => kw.toLowerCase().includes(query.toLowerCase())),
    );

    const tools = await Promise.all(
      matches.map(async (m) => {
        if (!this.loaded.has(m.name)) {
          const tool = await m.loader();
          this.loaded.set(m.name, tool);
        }
        return this.loaded.get(m.name)!;
      }),
    );

    return tools;
  }
}

小结
    

  • StreamingToolExecutor 在 API 流式过程中并行执行标记为 isConcurrencySafe 的工具，非安全工具串行等待。
    • 

  • 并发安全采用 fail-closed 策略：isConcurrencySafe 默认 false，混合安全/不安全工具时自动降级为串行。
    • 

  • 超过 50,000 字符的工具结果持久化到磁盘，避免膨胀 API 请求体积。
    • 

  • runTools() 管线包含 6 个检查点（Schema → 验证 → 权限 → 确认 → 执行 → 映射），采用快速失败模式。
    • 

  • ToolSearchTool 通过关键词匹配 + 延迟加载实现按需工具发现，核心工具预加载，扩展工具按需加载。
