MCP 客户端

传输类型体系

services/mcp/client.ts 实现了 Claude Code 的 MCP 客户端核心，支持 7 种传输类型以适配不同的服务器部署模式。

type McpTransportType = 'stdio' | 'sse' | 'sse-ide' | 'ws-ide' | 'http' | 'ws' | 'sdk' | 'claudeai-proxy';

function createTransport(config: McpServerConfig): Transport {
  switch (config.type) {
    case 'stdio':
      return new StdioClientTransport({
        command: config.command,
        args: config.args,
        env: { ...process.env, ...config.env },
      });
    case 'sse':
      return new SSEClientTransport(new URL(config.url), {
        requestInit: { headers: buildAuthHeaders(config) },
      });
    case 'http':
      return new StreamableHTTPClientTransport(new URL(config.url), {
        requestInit: { headers: buildAuthHeaders(config) },
      });
    case 'ws':
      return new WebSocketClientTransport(new URL(config.url));
    case 'sdk':
      return config.createTransport();
    default:
      throw new Error(`Unsupported transport: ${config.type}`);
  }
}

提示： 本地传输（stdio）并发限制为 3，远程传输限制为 20。这是因为本地进程的资源开销更大，需要控制同时运行的进程数量。






连接管理与缓存
connectToServer() 是客户端的核心入口，使用 memoization 缓存连接实例，避免重复建连。


const connectToServer = memoize(
  async (serverName: string, config: McpServerConfig): Promise<McpSession> => {
    const transport = createTransport(config);
    const client = new Client({ name: 'claude-code', version: VERSION });

    await client.connect(transport);

    const capabilities = await client.initialize({
      protocolVersion: LATEST_PROTOCOL_VERSION,
      capabilities: { tools: {}, resources: {} },
    });

    return {
      client,
      transport,
      capabilities,
      connectedAt: Date.now(),
      consecutiveErrors: 0,
    };
  },
  { cacheKey: (name: string) => name },
);

function invalidateConnection(serverName: string): void {
  connectToServer.cache.delete(serverName);
}

会话过期检测
MCP 会话可能因服务器重启或超时而失效。客户端通过 HTTP 状态码和 JSON-RPC 错误码双重检测。


function isSessionExpired(error: unknown): boolean {
  if (error instanceof HTTPError && error.statusCode === 404) {
    return true;
  }
  if (isJsonRpcError(error) && error.code === -32001) {
    return true;
  }
  return false;
}

async function withSessionRetry<T>(serverName: string, fn: (session: McpSession) => Promise<T>): Promise<T> {
  try {
    const session = await connectToServer(serverName);
    return await fn(session);
  } catch (error) {
    if (isSessionExpired(error)) {
      invalidateConnection(serverName);
      const session = await connectToServer(serverName);
      return await fn(session);
    }
    throw error;
  }
}


连续错误追踪
客户端维护每个服务器的连续终端错误计数器，达到阈值时触发重连。


interface McpSession {
  client: Client;
  transport: Transport;
  consecutiveErrors: number;
}

const MAX_CONSECUTIVE_ERRORS = 3;

async function callWithErrorTracking(
  serverName: string,
  toolName: string,
  args: Record<string, unknown>,
): Promise<McpResult> {
  const session = await connectToServer(serverName);

  try {
    const result = await session.client.callTool({ name: toolName, arguments: args });
    session.consecutiveErrors = 0;
    return result;
  } catch (error) {
    session.consecutiveErrors++;

    if (session.consecutiveErrors >= MAX_CONSECUTIVE_ERRORS) {
      invalidateConnection(serverName);
      updateConnectionState(serverName, 'Failed');
    }

    throw error;
  }
}

OAuth 认证与 401 重试
远程 MCP 服务器可能需要 OAuth Bearer Token 认证。客户端实现了 401 自动重试逻辑。


async function buildAuthHeaders(config: McpServerConfig): Promise<Record<string, string>> {
  const headers: Record<string, string> = {};

  if (config.bearerToken) {
    headers['Authorization'] = `Bearer ${config.bearerToken}`;
  } else if (config.oauthConfig) {
    const token = await getOAuthToken(config.oauthConfig);
    headers['Authorization'] = `Bearer ${token}`;
  }

  return headers;
}

async function callWithAuthRetry(serverName: string, request: McpRequest): Promise<McpResponse> {
  try {
    return await sendRequest(serverName, request);
  } catch (error) {
    if (error instanceof HTTPError && error.statusCode === 401) {
      await refreshOAuthToken(serverName);
      return await sendRequest(serverName, request);
    }
    throw error;
  }
}


提示： OAuth 令牌刷新只尝试一次。如果刷新后仍然返回 401，则将连接状态标记为 NeedsAuth，等待用户重新授权。






工具发现与 LRU 缓存
fetchToolsForClient() 从 MCP 服务器获取可用工具列表，并通过 LRU 缓存避免重复请求。


const toolsCache = new LRUCache<string, Tool[]>({ maxSize: 20 });

async function fetchToolsForClient(serverName: string): Promise<Tool[]> {
  const cached = toolsCache.get(serverName);
  if (cached) return cached;

  const session = await connectToServer(serverName);
  const response = await session.client.listTools();

  const tools = response.tools.map((mcpTool) => convertToInternalTool(mcpTool, serverName));

  toolsCache.set(serverName, tools);
  return tools;
}

function convertToInternalTool(mcpTool: McpToolDefinition, serverName: string): Tool {
  return {
    name: `mcp__${serverName}__${mcpTool.name}`,
    description: mcpTool.description,
    inputSchema: mcpTool.inputSchema,
    annotations: {
      readOnlyHint: mcpTool.annotations?.readOnlyHint ?? false,
      destructiveHint: mcpTool.annotations?.destructiveHint ?? true,
      openWorldHint: mcpTool.annotations?.openWorldHint ?? true,
    },
  };
}

工具调用与超时
callMCPTool() 执行实际的工具调用，设置 100M 毫秒超时并支持进度日志。


const TOOL_CALL_TIMEOUT = 100_000_000;

async function callMCPTool(
  serverName: string,
  toolName: string,
  args: Record<string, unknown>,
  onProgress?: (progress: McpProgress) => void,
): Promise<McpResult> {
  return withSessionRetry(serverName, async (session) => {
    const result = await Promise.race([
      session.client.callTool({ name: toolName, arguments: args }, { onProgress }),
      timeout(TOOL_CALL_TIMEOUT),
    ]);

    return processMCPResult(result, serverName);
  });
}


结果处理
processMCPResult() 处理工具返回结果，包括大输出持久化、文本截断和图片处理。


const MAX_INLINE_SIZE = 100_000;

function processMCPResult(result: McpCallResult, serverName: string): ProcessedResult {
  const contents = result.content ?? [];
  const processed: ProcessedContent[] = [];

  for (const item of contents) {
    if (item.type === 'text') {
      if (item.text.length > MAX_INLINE_SIZE) {
        const filePath = persistLargeOutput(item.text, serverName);
        processed.push({
          type: 'text',
          text: item.text.slice(0, MAX_INLINE_SIZE) + `\n[Output truncated. Full output saved to ${filePath}]`,
        });
      } else {
        processed.push(item);
      }
    } else if (item.type === 'image') {
      processed.push({
        type: 'image',
        data: item.data,
        mimeType: item.mimeType,
      });
    }
  }

  return { content: processed, isError: result.isError ?? false };
}

小结
    

  • MCP 客户端支持 7 种传输类型，本地进程（stdio）并发限制为 3，远程服务限制为 20。
    • 

  • 连接缓存通过 memoize 避免重复建连，会话过期（404 / -32001）和连续错误（≥3）触发缓存失效。
    • 

  • OAuth 认证支持 Bearer Token 和自动刷新，401 响应触发一次重试。
    • 

  • 工具发现使用 LRU 缓存（容量 20），将 MCP 工具定义转换为内部 Tool 格式，保留注解语义。
    • 

  • 结果处理对超过 100KB 的输出执行持久化截断，支持文本和图片两种内容类型。
