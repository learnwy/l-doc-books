MCP 配置系统

八层配置作用域

services/mcp/config.ts 实现了 MCP 服务器的配置管理，采用 8 层作用域优先级体系，确保从插件到企业级的配置粒度控制。

enum McpConfigScope {
  Plugin = 0,
  User = 1,
  Project = 2,
  Local = 3,
  Dynamic = 4,
  Enterprise = 5,
  ClaudeAI = 6,
  Managed = 7,
}

function mergeConfigs(scopes: Map<McpConfigScope, McpServerConfig[]>): McpServerConfig[] {
  const merged = new Map<string, McpServerConfig>();

  const orderedScopes = [
    McpConfigScope.Plugin,
    McpConfigScope.User,
    McpConfigScope.Project,
    McpConfigScope.Local,
    McpConfigScope.Dynamic,
    McpConfigScope.Enterprise,
    McpConfigScope.ClaudeAI,
    McpConfigScope.Managed,
  ];

  for (const scope of orderedScopes) {
    const configs = scopes.get(scope) ?? [];
    for (const config of configs) {
      merged.set(config.name, { ...config, scope });
    }
  }

  return Array.from(merged.values());
}

策略过滤机制
企业部署中，管理员可以通过白名单和黑名单控制允许的 MCP 服务器。


interface McpPolicy {
  allowlist?: McpPolicyRule[];
  denylist?: McpPolicyRule[];
}

interface McpPolicyRule {
  name?: string | RegExp;
  command?: string | RegExp;
  url?: string | RegExp;
}

function isMcpServerAllowedByPolicy(config: McpServerConfig, policy: McpPolicy): boolean {
  if (!policy.allowlist || policy.allowlist.length === 0) {
    return true;
  }

  return policy.allowlist.some((rule) => matchesPolicyRule(config, rule));
}

function isMcpServerDenied(config: McpServerConfig, policy: McpPolicy): boolean {
  if (!policy.denylist || policy.denylist.length === 0) {
    return false;
  }

  return policy.denylist.some((rule) => matchesPolicyRule(config, rule));
}

function matchesPolicyRule(config: McpServerConfig, rule: McpPolicyRule): boolean {
  if (rule.name && !matches(config.name, rule.name)) return false;
  if (rule.command && config.type === 'stdio' && !matches(config.command, rule.command)) return false;
  if (rule.url && 'url' in config && !matches(config.url, rule.url)) return false;
  return true;
}




策略组合
行为





无白名单 + 无黑名单
允许所有服务器




有白名单 + 无黑名单
仅允许白名单中的服务器




无白名单 + 有黑名单
阻止黑名单中的服务器，允许其余




有白名单 + 有黑名单
黑名单优先，再检查白名单







提示： 策略规则支持正则表达式，可以用 command: /^npx\s/ 这样的模式匹配所有以 npx 开头的命令。






内容签名去重
当多个配置源声明了相同的 MCP 服务器时，需要基于内容进行去重，而非仅依赖名称。


function getMcpServerSignature(config: McpServerConfig): string {
  if (config.type === 'stdio') {
    const parts = [config.command, ...(config.args ?? [])];
    return `stdio:${parts.join(' ')}`;
  }

  if ('url' in config) {
    return `url:${config.url}`;
  }

  return `name:${config.name}`;
}

function dedupPluginMcpServers(servers: McpServerConfig[]): McpServerConfig[] {
  const seen = new Set<string>();
  return servers.filter((server) => {
    const sig = getMcpServerSignature(server);
    if (seen.has(sig)) return false;
    seen.add(sig);
    return true;
  });
}

function dedupClaudeAiMcpServers(servers: McpServerConfig[], existingServers: McpServerConfig[]): McpServerConfig[] {
  const existingSigs = new Set(existingServers.map(getMcpServerSignature));

  return servers.filter((server) => {
    const sig = getMcpServerSignature(server);
    return !existingSigs.has(sig);
  });
}

企业托管模式
managed-mcp.json 提供企业级独占控制，管理员可以强制注册或禁用 MCP 服务器。


interface ManagedMcpConfig {
  servers: ManagedMcpServer[];
  version: number;
}

interface ManagedMcpServer {
  name: string;
  config: McpServerConfig;
  exclusive?: boolean;
  disabled?: boolean;
}

function applyManagedConfig(servers: McpServerConfig[], managed: ManagedMcpConfig): McpServerConfig[] {
  const result = [...servers];

  for (const managedServer of managed.servers) {
    const existingIndex = result.findIndex((s) => s.name === managedServer.name);

    if (managedServer.disabled) {
      if (existingIndex !== -1) {
        result.splice(existingIndex, 1);
      }
      continue;
    }

    if (managedServer.exclusive) {
      if (existingIndex !== -1) {
        result[existingIndex] = managedServer.config;
      } else {
        result.push(managedServer.config);
      }
    }
  }

  return result;
}




托管选项
行为





exclusive
强制使用托管配置，覆盖用户/项目级同名配置




disabled
强制禁用指定服务器，从配置列表中移除




默认
作为最高优先级追加，不覆盖已有配置







连接状态管理
每个 MCP 服务器维护独立的连接状态，驱动 UI 显示和重连逻辑。


enum McpConnectionState {
  Connected = 'Connected',
  Failed = 'Failed',
  NeedsAuth = 'NeedsAuth',
  Pending = 'Pending',
  Disabled = 'Disabled',
}

interface McpServerStatus {
  name: string;
  state: McpConnectionState;
  config: McpServerConfig;
  toolCount: number;
  lastError?: string;
  connectedAt?: number;
}

function getConnectionStateIcon(state: McpConnectionState): string {
  const icons: Record<McpConnectionState, string> = {
    Connected: '●',
    Failed: '✗',
    NeedsAuth: '🔑',
    Pending: '◌',
    Disabled: '○',
  };
  return icons[state];
}

小结
    

  • MCP 配置采用 8 层作用域优先级体系，从 Plugin（最低）到 Managed（最高），高优先级覆盖低优先级。
    • 

  • 5 种服务器配置类型对应不同传输协议，每种有专属的必填和可选字段。
    • 

  • 策略过滤通过白名单和黑名单控制允许的服务器，支持名称、命令和 URL 的正则匹配。
    • 

  • 内容签名去重基于 stdio 的 command+args 或远程 URL 计算签名，消除多配置源的重复声明。
    • 

  • 企业托管模式通过 managed-mcp.json 实现独占控制和强制禁用，连接状态机驱动 UI 和重连逻辑。
    •
