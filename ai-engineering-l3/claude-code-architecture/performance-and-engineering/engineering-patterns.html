工程模式

AsyncGenerator 组合原语

AsyncGenerator 是 Claude Code 的通用组合原语。retry 在错误时 yield 重试事件而非阻塞，query 在流式处理时 yield 每条消息，submitMessage yield SDK 事件供 UI 消费。

async function* orchestrate(userMessage: string, conversation: Conversation): AsyncGenerator<OrchestratorEvent> {
  yield { type: 'thinking', message: 'Processing...' };

  const messageGen = submitMessage(userMessage, conversation);

  for await (const event of messageGen) {
    if (event.type === 'retry') {
      yield { type: 'warning', message: `Retry attempt ${event.attempt}` };
      continue;
    }

    if (event.type === 'content_block_delta') {
      yield { type: 'text', delta: event.delta.text };
    }

    if (event.type === 'tool_use') {
      yield { type: 'tool_start', name: event.name };
      const result = await executeTool(event.name, event.input);
      yield { type: 'tool_result', name: event.name, result };
    }
  }

  yield { type: 'done' };
}

async function renderStream(gen: AsyncGenerator<OrchestratorEvent>): Promise<void> {
  for await (const event of gen) {
    switch (event.type) {
      case 'thinking':
        showSpinner(event.message);
        break;
      case 'text':
        appendText(event.delta);
        break;
      case 'tool_start':
        showToolIndicator(event.name);
        break;
      case 'tool_result':
        showToolResult(event);
        break;
      case 'warning':
        showWarning(event.message);
        break;
      case 'done':
        hideSpinner();
        break;
    }
  }
}

declare function feature(flag: string): boolean;

function getExperimentalTools(): Tool[] {

内容寻址去重
文件读取和历史粘贴使用内容签名去重，减少 API 调用中的重复 token。


const contentHashMap = new Map<string, string>();

function deduplicateFileContent(filePath: string, content: string): { content: string; deduplicated: boolean } {
  const hash = computeHash(content);
  const existing = contentHashMap.get(hash);

  if (existing) {
    return {
      content: `[Same content as ${existing}]`,
      deduplicated: true,
    };
  }

  contentHashMap.set(hash, filePath);
  return { content, deduplicated: false };
}

function deduplicatePasteInHistory(messages: Message[], newContent: string): string {
  const hash = computeHash(newContent);

  for (const msg of messages) {
    if (msg.contentHash === hash) {
      return `[Content identical to message #${msg.id}, omitted to save tokens]`;
    }
  }

  return newContent;
}

function computeHash(content: string): string {
  return createHash('sha256').update(content).digest('hex').slice(0, 16);
}

生代计数器
生代计数器（Generation Counter）是防止过期异步操作的通用模式，用于 LSP 管理器和 MCP 连接等场景。


let generation = 0;

async function reinitialize(): Promise<void> {
  generation++;
  const currentGeneration = generation;

  const result = await expensiveAsyncOperation();

  if (generation !== currentGeneration) {
    return;
  }

  applyResult(result);

多级 Memoization
函数在多个级别进行 memoize，形成级联缓存架构。


const perSessionCache = new Map<string, unknown>();
const perTurnCache = new Map<string, unknown>();

function memoizePerSession<T>(key: string, fn: () => T): T {
  if (perSessionCache.has(key)) return perSessionCache.get(key) as T;
  const result = fn();
  perSessionCache.set(key, result);
  return result;
}

function memoizePerTurn<T>(key: string, fn: () => T): T {
  if (perTurnCache.has(key)) return perTurnCache.get(key) as T;
  const result = fn();
  perTurnCache.set(key, result);
  return result;
}

function clearTurnCache(): void {
  perTurnCache.clear();
}

async function getAvailableTools(): Promise<Tool[]> {
  return memoizePerSession('tools:base', async () => {
    const coreTools = await loadCoreTools();
    const mcpTools = await memoizePerTurn('tools:mcp', () => fetchAllMCPTools());
    return [...coreTools, ...mcpTools];
  });
}

安全模式
文件操作遵循严格的安全模式，防止路径遍历、符号链接攻击和注入攻击。


import { constants } from 'fs';

async function safeWriteFile(filePath: string, content: string): Promise<void> {
  if (filePath.includes('\0')) {
    throw new Error('Null byte in file path');
  }

  const resolved = await resolveSymlinksAtEveryLevel(filePath);

  const fd = await fs.open(resolved, constants.O_WRONLY | constants.O_CREAT | constants.O_EXCL | constants.O_NOFOLLOW);

  try {
    await fd.writeFile(content, 'utf-8');
  } finally {
    await fd.close();
  }
}

async function resolveSymlinksAtEveryLevel(filePath: string): Promise<string> {
  const parts = filePath.split('/').filter(Boolean);
  let current = '/';

  for (const part of parts) {
    current = path.join(current, part);

    try {
      const stats = await fs.lstat(current);
      if (stats.isSymbolicLink()) {
        const target = await fs.readlink(current);
        current = path.resolve(path.dirname(current), target);
      }
    } catch {
      break;
    }
  }

  return current;
}

小结
    

  • AsyncGenerator 作为通用组合原语，支持多层 yield* 委托构建流式管道，从 API 到 UI 全链路流式。
    • 

  • Feature Flag 通过 bun:bundle 常量折叠在构建时消除死代码，区分内部功能和开源版本。
    • 

  • 内容寻址去重使用 SHA-256 哈希实现文件读取去重，节省约 18% 的 cache_creation token。
    • 

  • 生代计数器是防止过期异步操作的简洁模式，广泛用于 LSP、MCP 和上下文折叠等场景。
    • 

  • 多级 Memoization 在 Per-Call、Per-Turn、Per-Session 三个级别构建级联缓存。
    • 

  • 安全模式通过 null-byte 检查、逐级符号链接解析和 O_NOFOLLOW|O_EXCL flag 防御文件系统攻击。
