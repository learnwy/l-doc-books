渲染管线

渲染流程概览

从 React 状态变更到终端屏幕输出，经过 6 个阶段：reconciler 处理虚拟 DOM 变更、Yoga 计算布局、paint 生成字符矩阵、diff 比较差异、编码 ANSI 序列、写入终端。

function renderFrame(root: DOMElement, screen: Screen, prevFrame: string[][]): string[][] {
  calculateLayout(root, screen.cols, screen.rows);

  const currentFrame = paint(root, screen.cols, screen.rows);

  const patches = diff(prevFrame, currentFrame);

  const ansiOutput = encodePatches(patches);
  screen.write(ansiOutput);

  return currentFrame;
}

termio 终端控制序列库
termio/ 目录实现了完整的终端控制序列库，将底层 ANSI 操作封装为类型安全的函数。


const ansi = {
  cursorTo: (row: number, col: number): string => `\x1b[${row + 1};${col + 1}H`,

  cursorUp: (n: number): string => `\x1b[${n}A`,
  cursorDown: (n: number): string => `\x1b[${n}B`,
  cursorForward: (n: number): string => `\x1b[${n}C`,
  cursorBack: (n: number): string => `\x1b[${n}D`,

  eraseToEndOfLine: (): string => `\x1b[K`,
  eraseLine: (): string => `\x1b[2K`,
  eraseScreen: (): string => `\x1b[2J`,

  saveCursor: (): string => `\x1b7`,
  restoreCursor: (): string => `\x1b8`,

  hideCursor: (): string => `\x1b[?25l`,
  showCursor: (): string => `\x1b[?25h`,
};

SGR 文本样式
sgr.ts 实现 Select Graphic Rendition，控制终端文本的视觉样式。


interface TextStyle {
  color?: string;
  bgColor?: string;
  bold?: boolean;
  italic?: boolean;
  underline?: boolean;
  strikethrough?: boolean;
  dimColor?: boolean;
  inverse?: boolean;
}

function applyStyle(text: string, style: TextStyle): string {
  const codes: number[] = [];

  if (style.bold) codes.push(1);
  if (style.dimColor) codes.push(2);
  if (style.italic) codes.push(3);
  if (style.underline) codes.push(4);
  if (style.inverse) codes.push(7);
  if (style.strikethrough) codes.push(9);

  if (style.color) codes.push(...colorToSGR(style.color, false));
  if (style.bgColor) codes.push(...colorToSGR(style.bgColor, true));

  if (codes.length === 0) return text;

  return `\x1b[${codes.join(';')}m${text}\x1b[0m`;
}

function colorToSGR(color: string, isBackground: boolean): number[] {
  const base = isBackground ? 40 : 30;
  const colorMap: Record<string, number> = {
    black: 0,
    red: 1,
    green: 2,
    yellow: 3,
    blue: 4,
    magenta: 5,
    cyan: 6,
    white: 7,
  };

  if (color in colorMap) return [base + colorMap[color]];
  if (color.startsWith('#')) return [isBackground ? 48 : 38, 2, ...hexToRGB(color)];
  return [];
}

帧调度
frame.ts 实现了类似浏览器 requestAnimationFrame 的帧调度机制，合并多次状态更新为单次渲染。


type FrameCallback = () => void;

let pendingCallbacks: FrameCallback[] = [];
let frameId: ReturnType<typeof setTimeout> | null = null;
const TARGET_FPS = 30;
const FRAME_INTERVAL = Math.floor(1000 / TARGET_FPS);

function requestAnimationFrame(callback: FrameCallback): void {
  pendingCallbacks.push(callback);

  if (frameId === null) {
    frameId = setTimeout(flushFrame, FRAME_INTERVAL);
  }
}

function flushFrame(): void {
  frameId = null;
  const callbacks = pendingCallbacks;
  pendingCallbacks = [];

  for (const cb of callbacks) {
    cb();
  }
}

function cancelAnimationFrame(): void {
  if (frameId !== null) {
    clearTimeout(frameId);
    frameId = null;
  }
  pendingCallbacks = [];
}


提示： 帧调度是终端 UI 性能的关键。如果每次 React setState 都触发渲染，在高频更新场景（如流式输出）下会导致终端闪烁和性能下降。






差分渲染
渲染器只重绘发生变化的行，避免全屏重绘的性能开销。


interface RenderPatch {
  row: number;
  col: number;
  content: string;
}

function diff(prevFrame: string[][], currentFrame: string[][]): RenderPatch[] {
  const patches: RenderPatch[] = [];

  for (let row = 0; row < currentFrame.length; row++) {
    const prevRow = prevFrame[row];
    const currRow = currentFrame[row];

    if (!prevRow || prevRow.join('') !== currRow.join('')) {
      patches.push({
        row,
        col: 0,
        content: currRow.join(''),
      });
    }
  }

  return patches;
}

function encodePatches(patches: RenderPatch[]): string {
  let output = '';
  for (const patch of patches) {
    output += ansi.cursorTo(patch.row, patch.col);
    output += ansi.eraseToEndOfLine();
    output += patch.content;
  }
  return output;
}

备用屏幕缓冲区
全屏模式使用 DEC 私有模式切换到备用屏幕缓冲区，退出时恢复原始内容。


function enterAlternateScreen(screen: Screen): void {
  screen.write('\x1b[?1049h');
  screen.write(ansi.hideCursor());
  screen.write(ansi.eraseScreen());
  screen.write(ansi.cursorTo(0, 0));
}

function exitAlternateScreen(screen: Screen): void {
  screen.write(ansi.showCursor());
  screen.write('\x1b[?1049l');
}

小结
    

  • 渲染管线分为 6 个阶段：Reconciler → Yoga → Paint → Diff → ANSI → Terminal。
    • 

  • termio 库封装了 7 个终端控制序列模块，提供类型安全的 ANSI 操作接口。
    • 

  • SGR 文本样式支持颜色、粗体、斜体等视觉效果，兼容 24 位真彩色。
    • 

  • 帧调度器以 30fps 为目标合并多次状态更新，避免高频渲染导致的终端闪烁。
    • 

  • 差分渲染只重绘变化的行，备用屏幕缓冲区实现全屏模式的无损切换。
