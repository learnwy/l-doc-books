Ink 架构

自定义 React 终端框架

Claude Code 的终端 UI 位于 ink/ 目录，是一个完全自定义的实现，而非 npm 上的 ink 包。它基于 React 的 reconciler API 构建，将 React 的声明式编程模型带入终端环境。

import Reconciler from 'react-reconciler';

const reconciler = Reconciler<
  DOMNodeType,
  Record<string, unknown>,
  DOMElement,
  DOMElement,
  DOMText,
  DOMElement,
  unknown,
  unknown,
  unknown,
  unknown,
  unknown,
  unknown,
  unknown
>({
  supportsMutation: true,
  supportsPersistence: false,
  supportsHydration: false,

  createInstance(type, props) {
    return createDOMElement(type, props);
  },

  createTextInstance(text) {
    return createDOMText(text);
  },

  appendChild(parent, child) {
    parent.children.push(child);
    child.parent = parent;
    markDirty(parent);
  },

  removeChild(parent, child) {
    const index = parent.children.indexOf(child);
    if (index !== -1) parent.children.splice(index, 1);
    child.parent = null;
    markDirty(parent);
  },

  commitUpdate(instance, _updatePayload, _type, _oldProps, newProps) {
    updateDOMElement(instance, newProps);
    markDirty(instance);
  },
});

DOM 节点体系
dom.ts 定义了终端 DOM 的节点类型，模拟浏览器 DOM 的树形结构。


interface DOMNode {
  type: string;
  parent: DOMElement | null;
  yogaNode: YogaNode | null;
}

interface DOMElement extends DOMNode {
  type: 'element';
  tagName: string;
  props: Record<string, unknown>;
  children: DOMNode[];
  style: YogaStyle;
}

interface DOMText extends DOMNode {
  type: 'text';
  value: string;
}

function createDOMElement(tagName: string, props: Record<string, unknown>): DOMElement {
  const yogaNode = Yoga.Node.create();
  const element: DOMElement = {
    type: 'element',
    tagName,
    props,
    children: [],
    parent: null,
    yogaNode,
    style: {},
  };

  applyStyles(yogaNode, props.style ?? {});
  return element;
}

function createDOMText(value: string): DOMText {
  return { type: 'text', value, parent: null, yogaNode: null };
}

Yoga 布局引擎
Yoga 是 Facebook 开源的 flexbox 布局引擎，Claude Code 用它在终端中实现灵活的布局。


function applyStyles(yogaNode: YogaNode, style: BoxStyle): void {
  if (style.flexDirection) {
    yogaNode.setFlexDirection(style.flexDirection === 'row' ? Yoga.FLEX_DIRECTION_ROW : Yoga.FLEX_DIRECTION_COLUMN);
  }

  if (style.width !== undefined) yogaNode.setWidth(style.width);
  if (style.height !== undefined) yogaNode.setHeight(style.height);
  if (style.padding !== undefined) yogaNode.setPadding(Yoga.EDGE_ALL, style.padding);
  if (style.margin !== undefined) yogaNode.setMargin(Yoga.EDGE_ALL, style.margin);
  if (style.flexGrow !== undefined) yogaNode.setFlexGrow(style.flexGrow);
  if (style.flexShrink !== undefined) yogaNode.setFlexShrink(style.flexShrink);
  if (style.alignItems) yogaNode.setAlignItems(mapAlignItems(style.alignItems));
  if (style.justifyContent) yogaNode.setJustifyContent(mapJustifyContent(style.justifyContent));
}

function calculateLayout(root: DOMElement, width: number, height: number): void {
  root.yogaNode!.calculateLayout(width, height, Yoga.DIRECTION_LTR);
}

Root 与 Frame 调度
Root.ts 管理整个组件树的生命周期，frame.ts 实现类似浏览器 requestAnimationFrame 的帧调度。


class Root {
  private container: Reconciler.FiberRoot;
  private screen: Screen;
  private frameScheduled = false;

  constructor(screen: Screen) {
    this.screen = screen;
    this.container = reconciler.createContainer(createDOMElement('root', {}), 0, null, false, null, '', () => {}, null);
  }

  render(element: React.ReactElement): void {
    reconciler.updateContainer(element, this.container, null, () => {
      this.scheduleFrame();
    });
  }

  private scheduleFrame(): void {
    if (this.frameScheduled) return;
    this.frameScheduled = true;

    requestAnimationFrame(() => {
      this.frameScheduled = false;
      const rootNode = this.container.containerInfo as DOMElement;
      calculateLayout(rootNode, this.screen.cols, this.screen.rows);
      const output = paint(rootNode);
      this.screen.write(output);
    });
  }
}


Screen 抽象
screen.ts 封装终端输出，提供行列信息和写入接口。


interface Screen {
  rows: number;
  cols: number;
  write(output: string): void;
  clear(): void;
  moveCursor(row: number, col: number): void;
  onResize(handler: (rows: number, cols: number) => void): void;
}

function createScreen(stdout: NodeJS.WriteStream): Screen {
  let rows = stdout.rows ?? 24;
  let cols = stdout.columns ?? 80;
  const resizeHandlers: Array<(r: number, c: number) => void> = [];

  stdout.on('resize', () => {
    rows = stdout.rows;
    cols = stdout.columns;
    resizeHandlers.forEach((h) => h(rows, cols));
  });

  return {
    get rows() {
      return rows;
    },
    get cols() {
      return cols;
    },
    write: (output) => stdout.write(output),
    clear: () => stdout.write('\x1b[2J\x1b[H'),
    moveCursor: (row, col) => stdout.write(`\x1b[${row};${col}H`),
    onResize: (handler) => resizeHandlers.push(handler),
  };
}


核心组件
框架提供了一组基础组件，对应终端 UI 的常见需求。


function Box(props: BoxProps): React.ReactElement {
  return <ink-box style={props.style}>{props.children}</ink-box>;
}

function Text(props: TextProps): React.ReactElement {
  const style = {
    color: props.color,
    bold: props.bold,
    italic: props.italic,
    underline: props.underline,
    dimColor: props.dimColor,
  };
  return <ink-text style={style}>{props.children}</ink-text>;
}

function Button(props: ButtonProps): React.ReactElement {
  return (
    <Box style={{ paddingX: 1, borderStyle: "round" }}>
      <Text bold={props.focused} color={props.focused ? "blue" : undefined}>
        {props.label}
      </Text>
    </Box>
  );
}

function Spacer(): React.ReactElement {
  return <Box style={{ flexGrow: 1 }} />;
}

小结
    

  • 终端 UI 基于自定义 React reconciler，将 React 组件映射到终端 DOM 节点。
    • 

  • DOMElement 和 DOMText 构成终端 DOM 树，DOMElement 持有 Yoga 节点用于布局计算。
    • 

  • Yoga 布局引擎在终端中实现 flexbox，以字符为单位计算宽高、边距和对齐。
    • 

  • Root 管理组件树生命周期，帧调度器合并多次状态更新为单次渲染，避免频繁输出。
    • 

  • Screen 抽象封装终端 I/O，提供行列尺寸、写入和光标移动等基础能力。
