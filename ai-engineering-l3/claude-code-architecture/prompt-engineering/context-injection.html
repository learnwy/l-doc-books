上下文注入

上下文注入概览

src/context/context.ts（188 行）负责将运行时环境信息注入到每一轮对话中。上下文注入分为两个主要函数：getSystemContext() 提供系统环境信息（git 状态、分支、提交历史），getUserContext() 提供用户级上下文（CLAUDE.md 内容、日期信息）。

// src/context/context.ts — 上下文接口（简化）
interface SystemContext {
  gitBranch: string | null;
  gitStatus: string | null;
  gitRecentCommits: string | null;
  gitUser: string | null;
  cwd: string;
  os: string;
  nodeVersion: string;
}

interface UserContext {
  claudeMdContent: string | null;
  date: string;
  timezone: string;
}

async function getSystemContext(cwd: string): Promise<SystemContext>;
async function getUserContext(cwd: string): Promise<UserContext>;


getSystemContext
getSystemContext() 收集 git 仓库和系统环境信息，结果会被 memoize 缓存以避免重复执行 git 命令。


// src/context/context.ts — getSystemContext()（简化）
import { memoize } from '../utils/memoize';

const getSystemContext = memoize(
  async (cwd: string): Promise<SystemContext> => {
    const [branch, status, commits, user] = await Promise.all([
      execGit(cwd, ['branch', '--show-current']),
      execGit(cwd, ['status', '--porcelain', '-b']),
      execGit(cwd, ['log', '--oneline', '-5']),
      execGit(cwd, ['config', 'user.name']),
    ]);

    return {
      gitBranch: branch?.trim() || null,
      gitStatus: truncateStatus(status, 2000),
      gitRecentCommits: commits?.trim() || null,
      gitUser: user?.trim() || null,
      cwd,
      os: `${process.platform} ${process.arch}`,
      nodeVersion: process.version,
    };
  },
  { ttl: 30_000 },
);
Git Status 截断
git status 输出可能非常长（大型仓库可能有数千行变更）。truncateStatus() 将输出限制在 2000 字符以内：


// src/context/context.ts — 状态截断（简化）
function truncateStatus(status: string | null, maxChars: number): string | null {
  if (!status) return null;
  if (status.length <= maxChars) return status;

  const lines = status.split('\n');
  let result = '';
  let lineCount = 0;

  for (const line of lines) {
    if (result.length + line.length + 1 > maxChars - 50) {
      result += `\n... (${lines.length - lineCount} more files)`;
      break;
    }
    result += (lineCount > 0 ? '\n' : '') + line;
    lineCount++;
  }

  return result;
}

getUserContext 与 CLAUDE.md
getUserContext() 的核心功能是加载 CLAUDE.md 文件。CLAUDE.md 是 Claude Code 的记忆文件系统——用户可以在其中记录项目约定、偏好和上下文信息。


// src/context/context.ts — getUserContext()（简化）
async function getUserContext(cwd: string): Promise<UserContext> {
  const claudeMdContent = await loadClaudeMdChain(cwd);
  const now = new Date();

  return {
    claudeMdContent,
    date: now.toISOString().split('T')[0],
    timezone: Intl.DateTimeFormat().resolvedOptions().timeZone,
  };
}
CLAUDE.md 向上遍历
Claude Code 从当前工作目录开始向上遍历，收集所有层级的 CLAUDE.md 文件：


// src/memdir/claude-md.ts — CLAUDE.md 链加载（简化）
async function loadClaudeMdChain(cwd: string): Promise<string | null> {
  const files: { path: string; content: string }[] = [];
  let current = cwd;

  while (true) {
    const candidates = [path.join(current, 'CLAUDE.md'), path.join(current, '.claude', 'CLAUDE.md')];

    for (const candidate of candidates) {
      if (await exists(candidate)) {
        const content = await readFile(candidate, 'utf-8');
        files.push({ path: candidate, content });
      }
    }

    const parent = path.dirname(current);
    if (parent === current) break;
    current = parent;
  }

  const homeClaude = path.join(os.homedir(), '.claude', 'CLAUDE.md');
  if (await exists(homeClaude)) {
    const content = await readFile(homeClaude, 'utf-8');
    files.push({ path: homeClaude, content });
  }

  if (files.length === 0) return null;

  return files.map((f) => `<!-- From: ${f.path} -->\n${f.content}`).join('\n\n---\n\n');
}

提示： CLAUDE.md 文件的向上遍历设计让你可以在不同目录层级设置不同的上下文。例如，项目根目录的 CLAUDE.md 设置全局编码规范，而 src/tests/ 目录下的 CLAUDE.md 可以添加测试相关的特殊指导。






Attachment 注入
上下文信息通过 Attachment 系统注入到每轮对话中。与直接修改系统提示词不同，Attachment 是独立的消息，不影响提示词缓存。


// src/query/QueryEngine.ts — Attachment 注入（简化）
class QueryEngine {
  private async injectContextAttachments(): Promise<SDKMessage[]> {
    const attachments: SDKMessage[] = [];

    const userCtx = await getUserContext(this.config.cwd);

    if (userCtx.claudeMdContent) {
      attachments.push({
        type: 'attachment',
        content: `# Memory Files (CLAUDE.md)\n\n${userCtx.claudeMdContent}`,
        timestamp: Date.now(),
        metadata: { source: 'claude-md', priority: 100 },
      });
    }

    const sysCtx = await getSystemContext(this.config.cwd);

    if (this.hasNewFileChanges()) {
      const changes = this.fileWatcher.getAndClearChanges();
      attachments.push({
        type: 'attachment',
        content: formatFileChangeNotification(changes),
        timestamp: Date.now(),
        metadata: { source: 'file-watcher', priority: 60 },
      });
    }

    if (this.hasQueuedCommands()) {
      const cmds = this.dequeueCommands();
      attachments.push({
        type: 'attachment',
        content: formatQueuedCommands(cmds),
        timestamp: Date.now(),
        metadata: { source: 'queued-commands', priority: 40 },
      });
    }

    return attachments;
  }
}


环境信息注入
系统环境信息注入到系统提示词的动态段落中：


// src/context/context.ts — 环境信息格式化（简化）
function buildEnvInfo(sysCtx: SystemContext, userCtx: UserContext): string {
  const lines: string[] = [];

  lines.push(`Date: ${userCtx.date}`);
  lines.push(`Timezone: ${userCtx.timezone}`);
  lines.push(`CWD: ${sysCtx.cwd}`);
  lines.push(`OS: ${sysCtx.os}`);

  if (sysCtx.gitBranch) {
    lines.push(`Git Branch: ${sysCtx.gitBranch}`);
  }

  if (sysCtx.gitRecentCommits) {
    lines.push(`Recent Commits:\n${sysCtx.gitRecentCommits}`);
  }

  if (sysCtx.gitStatus) {
    lines.push(`Git Status:\n${sysCtx.gitStatus}`);
  }

  return lines.join('\n');
}

小结
    

  • context.ts（188 行）提供 getSystemContext() 和 getUserContext() 两个核心函数收集运行时上下文。
    • 

  • git 状态通过 memoize 缓存（30s TTL），status 输出截断在 2000 字符以内。
    • 

  • CLAUDE.md 向上遍历从当前目录到根目录再到 ~/.claude/，收集所有层级的记忆文件。
    • 

  • 上下文信息分两路注入：环境信息进入系统提示词动态段，CLAUDE.md 和文件变更作为 Attachment 消息。
    • 

  • 设计核心原则：不影响提示词缓存——动态内容放在 DYNAMIC BOUNDARY 之后或 Attachment 中。
