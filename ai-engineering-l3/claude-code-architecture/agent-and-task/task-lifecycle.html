任务生命周期

Task.ts 数据模型

Task.ts（125 行）定义了 Claude Code 任务系统的核心抽象。每个任务都有明确的类型、状态和生命周期元数据，从创建到终结都受到统一管理。

type TaskType =
  | 'local_bash'
  | 'local_agent'
  | 'remote_agent'
  | 'in_process_teammate'
  | 'local_workflow'
  | 'monitor_mcp'
  | 'dream';

type TaskStatus = 'pending' | 'running' | 'completed' | 'failed' | 'killed';

interface TaskStateBase {
  id: string;
  type: TaskType;
  status: TaskStatus;
  description: string;
  startTime: number;
  endTime?: number;
  outputFile?: string;
}

7 种任务类型覆盖了所有执行场景：

任务类型 执行环境 创建来源 典型用途
local_bash 本地 Shell BashTool 后台 长时间 Shell 命令
local_agent 本地子进程 AgentTool fork 通用子 agent 任务
remote_agent 远程 CCR AgentTool remote 远程沙箱执行
in_process_teammate 同进程 Coordinator 内联 teammate 协作
local_workflow 本地工作流 工作流引擎 多步骤自动化
monitor_mcp MCP 监控 MCP 服务端 外部服务监控
dream 后台推理 系统内部 空闲时预测性推理 


提示： dream 任务类型是 Claude Code 中一个独特的设计——它在用户空闲时触发后台推理，预先探索可能的用户意图和代码变更。






五种任务状态
任务状态机定义了 5 种状态和它们之间的合法转换，其中 3 种是终态。


function isTerminalTaskStatus(status: TaskStatus): boolean {
  return status === 'completed' || status === 'failed' || status === 'killed';
}

function transitionTask(task: TaskStateBase, newStatus: TaskStatus): TaskStateBase {
  const validTransitions: Record<TaskStatus, TaskStatus[]> = {
    pending: ['running', 'killed'],
    running: ['completed', 'failed', 'killed'],
    completed: [],
    failed: [],
    killed: [],
  };

  if (!validTransitions[task.status].includes(newStatus)) {
    throw new Error(`Invalid transition: ${task.status} → ${newStatus}`);
  }

  return {
    ...task,
    status: newStatus,
    endTime: isTerminalTaskStatus(newStatus) ? Date.now() : undefined,
  };
}

终态检测函数 isTerminalTaskStatus() 在任务管理器的轮询和清理逻辑中频繁使用——只有非终态的任务才需要继续监控。




任务 ID 生成
任务 ID 由类型前缀和 8 个随机字母数字字符组成，前缀使得从 ID 即可推断任务类型。


const TYPE_PREFIXES: Record<string, string> = {
  local_bash: 'b',
  local_agent: 'a',
  remote_agent: 'r',
  in_process_teammate: 't',
  local_workflow: 'w',
  monitor_mcp: 'm',
  dream: 'd',
};

function generateTaskId(type: TaskType): string {
  const prefix = TYPE_PREFIXES[type] || 'x';
  const random = Array.from(
    { length: 8 },
    () => 'abcdefghijklmnopqrstuvwxyz0123456789'[Math.floor(Math.random() * 36)],
  ).join('');
  return `${prefix}-${random}`;
}

TaskHandle 与清理
TaskHandle 是任务的外部引用句柄，它将 taskId 与 cleanup 函数绑定在一起，确保任务资源在不再需要时被正确释放。


interface TaskHandle {
  taskId: string;
  cleanup: () => Promise<void>;
}

function createTaskHandle(type: TaskType, process: ChildProcess): TaskHandle {
  const taskId = generateTaskId(type);

  return {
    taskId,
    cleanup: async () => {
      if (process.exitCode === null) {
        process.kill('SIGTERM');
        await waitForExit(process, 5000);
        if (process.exitCode === null) {
          process.kill('SIGKILL');
        }
      }
    },
  };
}

输出持久化
任务的输出通过 getTaskOutputPath() 持久化到磁盘文件，使得后台任务完成后仍可查看结果。


function getTaskOutputPath(taskId: string): string {
  return path.join(homedir(), '.claude', 'tasks', `${taskId}.output.json`);
}

interface TaskOutput {
  taskId: string;
  status: TaskStatus;
  result?: unknown;
  error?: string;
  startTime: number;
  endTime: number;
  logs: string[];
}

async function persistTaskOutput(task: TaskStateBase, result: unknown): Promise<void> {
  const outputPath = getTaskOutputPath(task.id);
  await mkdirp(path.dirname(outputPath));
  const output: TaskOutput = {
    taskId: task.id,
    status: task.status,
    result,
    startTime: task.startTime,
    endTime: task.endTime ?? Date.now(),
    logs: [],
  };
  await writeFile(outputPath, JSON.stringify(output, null, 2), 'utf-8');
}

BashTool 后台任务集成
BashTool 的后台任务通过 LocalShellTask 实现，当命令执行时间超过 15 秒时自动转为后台。


const BASH_AUTO_BACKGROUND_MS = 15 * 1000;

class LocalShellTask {
  private process: ChildProcess;
  private output: string[] = [];

  constructor(
    command: string,
    private taskId: string,
  ) {
    this.process = spawn('sh', ['-c', command]);
    this.process.stdout?.on('data', (data) => this.output.push(data.toString()));
    this.process.stderr?.on('data', (data) => this.output.push(`[stderr] ${data}`));
  }

  async waitOrBackground(timeout: number = BASH_AUTO_BACKGROUND_MS) {
    const result = await Promise.race([this.waitForExit(), sleep(timeout).then(() => 'timeout' as const)]);
    if (result === 'timeout') return { backgrounded: true };
    return { backgrounded: false, output: this.output.join('') };
  }
}

提示： BashTool 的 15 秒阈值远低于 AgentTool 的 120 秒，因为 Shell 命令通常要么很快完成，要么需要很长时间（如 build、test 命令）。短阈值让用户更快地获得后台任务的反馈。






小结
    

  • Task 系统定义了 7 种任务类型（local_bash 到 dream）和 5 种状态（pending/running/completed/failed/killed）。
    • 

  • 状态机有 3 种终态，isTerminalTaskStatus() 用于判断任务是否需要继续监控。
    • 

  • 任务 ID 由类型前缀 + 8 位随机字符组成（如 b-a3f7k2m9），前缀使类型可从 ID 推断。
    • 

  • TaskHandle 通过 SIGTERM → 5s 等待 → SIGKILL 优雅退出模式清理子进程资源。
    •
