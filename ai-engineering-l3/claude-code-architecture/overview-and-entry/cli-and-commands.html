CLI 与命令体系

Commander.js 集成

Claude Code 使用 commander 配合 @commander-js/extra-typings 包实现类型安全的 CLI 命令注册。核心 CLI 定义位于 src/main.tsx，而斜杠命令的注册和发现分布在多个模块中。

// src/main.tsx — Commander 类型安全定义（简化）
import { Command, Option } from '@commander-js/extra-typings';

const program = new Command()
  .name('claude')
  .version(VERSION)
  .argument('[prompt...]', '提示词参数')
  .addOption(new Option('-p, --print', '非交互模式').conflicts('resume'))
  .addOption(
    new Option('--model <model>', '模型选择').choices(['claude-sonnet-4-20250514', 'claude-opus-4-20250514'] as const),
  )
  .addOption(
    new Option('--permission-mode <mode>', '权限模式')
      .choices(['default', 'plan', 'bypassPermissions'] as const)
      .default('default' as const),
  );

type CLIOptions = ReturnType<typeof program.opts>;

提示： @commander-js/extra-typings 包让 program.opts() 的返回类型自动从选项定义中推导，无需手动维护类型定义。

Command 接口
所有斜杠命令都实现统一的 Command 接口：


// src/commands/types.ts — Command 接口（简化）
interface Command {
  name: string;
  description: string;
  aliases?: string[];
  args?: CommandArg[];

  isAvailable: (ctx: CommandContext) => boolean;
  isEnabled: (ctx: CommandContext) => boolean;
  call: (args: string[], ctx: CommandContext) => Promise<CommandResult>;

  source: CommandSource;
  priority: number;
  hidden?: boolean;
}

type CommandSource = 'bundled' | 'builtin' | 'skill' | 'workflow' | 'plugin';

interface CommandContext {
  queryEngine: QueryEngine;
  permissionManager: PermissionManager;
  cwd: string;
  isRemote: boolean;
  isBridge: boolean;
}

interface CommandResult {
  success: boolean;
  output?: string;
  messages?: SDKMessage[];
}


命令注册与发现
命令注册分为静态注册和动态发现两种机制。


静态注册
内置命令在模块加载时通过装饰器模式注册：


// src/commands/builtin/help.ts — 内置命令示例（简化）
import { defineCommand } from '../registry';

export default defineCommand({
  name: 'help',
  description: '显示可用命令列表',
  aliases: ['h', '?'],
  isAvailable: () => true,
  isEnabled: () => true,

  async call(args, ctx) {
    const commands = ctx.queryEngine.getAvailableCommands();
    const grouped = groupBySource(commands);
    return {
      success: true,
      output: formatCommandHelp(grouped),
    };
  },
});
动态发现
技能和工作流命令在运行时通过目录扫描发现：


// src/commands/discovery.ts — 动态命令发现（简化）
async function discoverCommands(config: AppConfig): Promise<Command[]> {
  const commands: Command[] = [];

  const skillDirs = [path.join(config.cwd, '.claude', 'skills'), path.join(os.homedir(), '.claude', 'skills')];

  for (const dir of skillDirs) {
    if (await exists(dir)) {
      const entries = await readdir(dir);
      for (const entry of entries) {
        const manifest = await loadSkillManifest(path.join(dir, entry));
        if (manifest?.commands) {
          commands.push(...manifest.commands.map(toCommand));
        }
      }
    }
  }

  const workflowDir = path.join(config.cwd, '.claude', 'workflows');
  if (await exists(workflowDir)) {
    const workflows = await loadWorkflows(workflowDir);
    commands.push(...workflows.map(workflowToCommand));
  }

  return commands;
}


命令过滤与安全
在远程和桥接场景下，命令需要经过安全过滤。


// src/commands/filter.ts — 命令安全过滤（简化）
function filterCommands(commands: Command[], ctx: CommandContext): Command[] {
  return commands.filter((cmd) => {
    if (!cmd.isAvailable(ctx)) return false;

    if (ctx.isRemote || ctx.isBridge) {
      return isBridgeSafe(cmd);
    }

    if (!cmd.isEnabled(ctx)) return false;

    return true;
  });
}

function isBridgeSafe(cmd: Command): boolean {
  const unsafeSources: CommandSource[] = ['plugin', 'workflow'];
  if (unsafeSources.includes(cmd.source)) return false;

  const unsafeCommands = ['config', 'install', 'uninstall'];
  if (unsafeCommands.includes(cmd.name)) return false;

  return true;
}

斜杠命令处理流程
用户在 REPL 中输入斜杠命令后，QueryEngine 负责拦截和分发：


// src/query/QueryEngine.ts — 斜杠命令处理（简化）
class QueryEngine {
  async processInput(input: string): Promise<void> {
    if (input.startsWith('/')) {
      const result = await this.handleSlashCommand(input);
      if (result.handled) return;
    }

    await this.submitMessage(input);
  }

  private async handleSlashCommand(input: string): Promise<{ handled: boolean }> {
    const [cmdName, ...args] = input.slice(1).split(/\s+/);

    const command = this.commandRegistry.resolve(cmdName);
    if (!command) {
      this.emit('message', {
        type: 'system',
        content: `未知命令: /${cmdName}。输入 /help 查看可用命令。`,
      });
      return { handled: true };
    }

    const ctx = this.createCommandContext();
    const result = await command.call(args, ctx);

    if (result.messages) {
      for (const msg of result.messages) {
        this.appendMessage(msg);
      }
    }

    return { handled: true };
  }
}

// src/commands/builtin/compact.ts — /compact 命令（简化）
export default defineCommand({
  name: 'compact',
  description: '压缩对话上下文以释放 token 空间',

  isAvailable: () => true,
  isEnabled: () => true,

  async call(args, ctx) {
    const summary = await ctx.queryEngine.compactConversation({
      force: true,
      customPrompt: args.join(' ') || undefined,
    });

    return {
      success: true,
      output: `上下文已压缩。摘要：${summary.slice(0, 200)}...`,
    };
  },
});


小结
    

  • Claude Code 使用 Commander.js + extra-typings 实现类型安全的 CLI 参数定义，opts() 返回类型自动推导。
    • 

  • 支持 80+ 斜杠命令，从捆绑技能、内置插件、技能目录、工作流和外部插件五大来源聚合。
    • 

  • 所有命令实现统一的 Command 接口，包含 isAvailable、isEnabled、call 三个核心方法。
    • 

  • 远程/桥接场景下，安全过滤会禁用 plugin 和 workflow 来源的命令，防止执行不受信任的代码。
    • 

  • 斜杠命令在 QueryEngine 层拦截处理，未匹配的输入才会进入正常的 API 调用流程。
