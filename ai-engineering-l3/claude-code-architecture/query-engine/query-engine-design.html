QueryEngine 设计

类概览

QueryEngine 是 Claude Code 的核心协调器，位于 src/query/QueryEngine.ts（1295 行）。它封装了完整的对话生命周期管理：从接收用户输入到产出结构化消息流，中间经历 API 调用、工具执行、上下文压缩等多个阶段。

提示： mutableMessages 是可变数组，上下文压缩操作会直接修改它（替换、删除元素）。这是一个有意的设计选择——避免在每次压缩后创建新数组的性能开销。






AsyncGenerator 消息流
submitMessage() 是 QueryEngine 的核心方法，它返回一个 AsyncGenerator，通过 yield 逐个产出消息。这种设计让 UI 层可以流式消费消息，而不需要等待完整的对话循环结束。


// src/query/QueryEngine.ts — submitMessage()（简化）
class QueryEngine {
  async *submitMessage(input: string): AsyncGenerator<SDKMessage> {
    const userMessage: SDKMessage = {
      type: 'user',
      content: input,
      timestamp: Date.now(),
    };
    this.mutableMessages.push(userMessage);
    yield userMessage;

    const attachments = await this.gatherAttachments();
    if (attachments.length > 0) {
      for (const attachment of attachments) {
        this.mutableMessages.push(attachment);
        yield attachment;
      }
    }

    yield* this.runQueryLoop();
  }

  private async *runQueryLoop(): AsyncGenerator<SDKMessage> {
    const { queryLoop } = await import('./query');
    yield* queryLoop({
      messages: this.mutableMessages,
      config: this.config,
      usage: this.totalUsage,
      permissionDenials: this.permissionDenials,
      readFileState: this.readFileState,
      stopHooks: this.stopHooks,
    });
  }
}


SDK 消息类型
Claude Code 定义了丰富的消息类型系统，扩展了 Anthropic SDK 的基础消息模型：


// src/messages/types.ts — 消息类型定义（简化）
type SDKMessageType =
  | 'user'
  | 'assistant'
  | 'system'
  | 'tool_use'
  | 'tool_result'
  | 'stream_event'
  | 'attachment'
  | 'progress'
  | 'tool_use_summary'
  | 'tombstone';

interface SDKMessage {
  type: SDKMessageType;
  content: string | ContentBlock[];
  timestamp: number;
  metadata?: MessageMetadata;
}

interface AssistantMessage extends SDKMessage {
  type: 'assistant';
  content: ContentBlock[];
  model: string;
  usage: { input_tokens: number; output_tokens: number };
  stop_reason: 'end_turn' | 'tool_use' | 'max_tokens';
}

interface ToolUseMessage extends SDKMessage {
  type: 'tool_use';
  tool_name: string;
  tool_input: Record<string, unknown>;
  tool_use_id: string;
}

interface ToolResultMessage extends SDKMessage {
  type: 'tool_result';
  tool_use_id: string;
  content: string;
  is_error: boolean;
}

interface TombstoneMessage extends SDKMessage {
  type: 'tombstone';
  original_type: SDKMessageType;
  reason: 'compacted' | 'snipped' | 'collapsed';
}

会话状态管理
QueryEngine 维护了丰富的会话状态，支持会话持久化和恢复：


// src/query/QueryEngine.ts — 状态管理（简化）
interface SessionState {
  sessionId: string;
  messages: SDKMessage[];
  usage: TokenUsage;
  startTime: number;
  lastActivityTime: number;
  compactCount: number;
  turnCount: number;
}

class QueryEngine {
  serializeSession(): SessionState {
    return {
      sessionId: this.sessionId,
      messages: this.mutableMessages,
      usage: this.totalUsage,
      startTime: this.startTime,
      lastActivityTime: Date.now(),
      compactCount: this.compactCount,
      turnCount: this.turnCount,
    };
  }

  static async restoreSession(state: SessionState, config: QueryEngineConfig): Promise<QueryEngine> {
    const engine = new QueryEngine({
      ...config,
      sessionId: state.sessionId,
    });
    engine.mutableMessages = state.messages;
    engine.totalUsage = state.usage;
    engine.startTime = state.startTime;
    engine.compactCount = state.compactCount;
    engine.turnCount = state.turnCount;
    return engine;
  }
}


Attachment 系统
每轮 API 调用前，QueryEngine 会收集并注入上下文附件。附件是临时的——不会持久化到消息历史中。


// src/query/QueryEngine.ts — Attachment 收集（简化）
interface Attachment {
  type: 'memory' | 'skill' | 'file_change' | 'queued_command' | 'context';
  content: string;
  priority: number;
}

class QueryEngine {
  private async gatherAttachments(): Promise<Attachment[]> {
    const attachments: Attachment[] = [];

    const memoryContent = await loadMemoryFiles(this.config.cwd);
    if (memoryContent) {
      attachments.push({
        type: 'memory',
        content: memoryContent,
        priority: 100,
      });
    }

    const newSkills = await discoverNewSkills(this.discoveredSkillNames);
    if (newSkills.length > 0) {
      attachments.push({
        type: 'skill',
        content: formatSkillDiscovery(newSkills),
        priority: 80,
      });
    }

    const fileChanges = this.config.fileWatcher?.getChanges();
    if (fileChanges?.length) {
      attachments.push({
        type: 'file_change',
        content: formatFileChanges(fileChanges),
        priority: 60,
      });
    }

    return attachments.sort((a, b) => b.priority - a.priority);
  }
}

小结
    

  • QueryEngine 是 1295 行的核心类，通过 AsyncGenerator 的 submitMessage() 方法驱动整个对话流程。
    • 

  • 消息类型系统定义了 10 种 SDKMessage，其中 tombstone 是上下文压缩的占位符，stream_event 用于流式 UI 更新。
    • 

  • mutableMessages 是可变数组，压缩操作直接修改它以避免拷贝开销。
    • 

  • 会话状态支持序列化和恢复，实现 --resume 和 --continue 功能。
    • 

  • Attachment 系统在每轮 API 调用前动态注入记忆文件、技能发现、文件变更等上下文信息。
