Token 预算与成本

CostTracker 架构

src/services/cost-tracker.ts（323 行）实现了 Claude Code 的成本追踪系统。它按模型维度跟踪每次 API 调用的 token 用量，计算 USD 成本，并在查询循环中执行预算限制。

// src/services/cost-tracker.ts — CostTracker 类（简化）
interface ModelUsage {
  inputTokens: number;
  outputTokens: number;
  cacheReadTokens: number;
  cacheWriteTokens: number;
  webSearchCount: number;
  contextWindowUsed: number;
}

interface TokenUsage {
  input: number;
  output: number;
  cacheRead: number;
  cacheWrite: number;
}

class CostTracker {
  private modelUsage: Map<string, ModelUsage> = new Map();
  private sessionId: string;
  private budget: number | undefined;
  private startTime: number;

  constructor(config: CostTrackerConfig) {
    this.sessionId = config.sessionId;
    this.budget = config.budget;
    this.startTime = Date.now();
  }

  recordUsage(model: string, usage: TokenUsage): void {
    const current = this.modelUsage.get(model) ?? createEmptyUsage();
    current.inputTokens += usage.input;
    current.outputTokens += usage.output;
    current.cacheReadTokens += usage.cacheRead;
    current.cacheWriteTokens += usage.cacheWrite;
    this.modelUsage.set(model, current);
  }

  getTotalCost(): number {
    let total = 0;
    for (const [model, usage] of this.modelUsage) {
      total += calculateUSDCost(model, usage);
    }
    return total;
  }

  isBudgetExceeded(): boolean {
    if (this.budget === undefined) return false;
    return this.getTotalCost() >= this.budget;
  }
}


成本计算模型
Claude Code 维护了每个模型的详细定价表，用于计算 USD 成本：


// src/services/cost-tracker.ts — 定价计算（简化）
interface ModelPricing {
  inputPerMillion: number;
  outputPerMillion: number;
  cacheReadPerMillion: number;
  cacheWritePerMillion: number;
  webSearchPerQuery: number;
}

const MODEL_PRICING: Record<string, ModelPricing> = {
  'claude-sonnet-4-20250514': {
    inputPerMillion: 3.0,
    outputPerMillion: 15.0,
    cacheReadPerMillion: 0.3,
    cacheWritePerMillion: 3.75,
    webSearchPerQuery: 0.01,
  },
  'claude-opus-4-20250514': {
    inputPerMillion: 15.0,
    outputPerMillion: 75.0,
    cacheReadPerMillion: 1.5,
    cacheWritePerMillion: 18.75,
    webSearchPerQuery: 0.01,
  },
  'claude-haiku-3-20241022': {
    inputPerMillion: 0.8,
    outputPerMillion: 4.0,
    cacheReadPerMillion: 0.08,
    cacheWritePerMillion: 1.0,
    webSearchPerQuery: 0.005,
  },
};

function calculateUSDCost(model: string, usage: ModelUsage): number {
  const pricing = MODEL_PRICING[model];
  if (!pricing) return 0;

  const inputCost = (usage.inputTokens / 1_000_000) * pricing.inputPerMillion;
  const outputCost = (usage.outputTokens / 1_000_000) * pricing.outputPerMillion;
  const cacheReadCost = (usage.cacheReadTokens / 1_000_000) * pricing.cacheReadPerMillion;
  const cacheWriteCost = (usage.cacheWriteTokens / 1_000_000) * pricing.cacheWritePerMillion;
  const searchCost = usage.webSearchCount * pricing.webSearchPerQuery;

  return inputCost + outputCost + cacheReadCost + cacheWriteCost + searchCost;
}

async function* queryLoop(params: QueryLoopParams): AsyncGenerator<SDKMessage> {
  const { costTracker } = params;

  while (true) {
    if (costTracker.isBudgetExceeded()) {
      yield {
        type: 'system',
        content: `成本已达到预算上限 $${costTracker.budget?.toFixed(2)}。当前花费: $${costTracker.getTotalCost().toFixed(4)}`,

      break;

      cacheWrite: response.usage.cache_creation_input_tokens ?? 0,
    });

  }
}


成本持久化
CostTracker 将成本数据持久化到项目级状态文件，支持会话恢复时继续累计：


// src/services/cost-tracker.ts — 持久化（简化）
class CostTracker {
  async persistToProject(cwd: string): Promise<void> {
    const projectPath = getProjectStatePath(cwd);
    const state = await readProjectState(projectPath);

    state.totalCost = (state.totalCost ?? 0) + this.getTotalCost();
    state.totalTokens = {
      input: (state.totalTokens?.input ?? 0) + this.getTotalInput(),
      output: (state.totalTokens?.output ?? 0) + this.getTotalOutput(),
    };
    state.sessions = state.sessions ?? [];
    state.sessions.push({
      id: this.sessionId,
      cost: this.getTotalCost(),
      tokens: this.getSessionTokens(),
      startTime: this.startTime,
      endTime: Date.now(),
    });

    await writeProjectState(projectPath, state);
  }

  static async restoreFromProject(cwd: string, sessionId: string): Promise<CostTracker | null> {
    const projectPath = getProjectStatePath(cwd);
    const state = await readProjectState(projectPath);
    const session = state.sessions?.find((s) => s.id === sessionId);

    if (!session) return null;

    const tracker = new CostTracker({ sessionId, budget: undefined });
    tracker.restoreFromSession(session);
    return tracker;
  }
}

成本显示
formatTotalCost() 使用 chalk 为终端输出着色：


// src/services/cost-tracker.ts — 显示格式化（简化）
import chalk from 'chalk';

function formatTotalCost(tracker: CostTracker): string {
  const cost = tracker.getTotalCost();
  const usage = tracker.getTotalUsage();

  const costColor = cost > 1.0 ? chalk.red : cost > 0.1 ? chalk.yellow : chalk.green;
  const costStr = costColor(`$${cost.toFixed(4)}`);

  const inputStr = chalk.cyan(formatTokenCount(usage.input));
  const outputStr = chalk.magenta(formatTokenCount(usage.output));
  const cacheStr = chalk.gray(formatTokenCount(usage.cacheRead));

  return `${costStr} | 输入: ${inputStr} 输出: ${outputStr} 缓存: ${cacheStr}`;
}

function formatTokenCount(count: number): string {
  if (count >= 1_000_000) return `${(count / 1_000_000).toFixed(1)}M`;
  if (count >= 1_000) return `${(count / 1_000).toFixed(1)}k`;
  return `${count}`;
}


提示： /cost 斜杠命令可以在任何时候查看当前会话的成本明细。在长时间会话中，定期检查成本可以避免意外的高额花费。

小结
    

  • CostTracker（323 行）按模型维度追踪 5 种 token 用量（输入/输出/缓存读/缓存写/搜索）。
    • 

  • 成本计算基于每模型独立定价表，缓存读取仅为正常输入价格的 1/10。
    • 

  • 预算检查在查询循环每次迭代中执行，超预算时立即终止循环。
    • 

  • 成本数据持久化到项目级状态文件，支持会话恢复时继续累计。
    • 

  • 通过 OpenTelemetry 上报 token 消耗、USD 成本和 API 调用次数，支持外部监控。
    • 

  • 综合运用提示词缓存、四层压缩和 Brief 模式，可节省 70%+ 的 API 成本。
