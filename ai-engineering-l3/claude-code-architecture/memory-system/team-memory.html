团队记忆

双目录架构

teamMemPaths.ts（292 行）实现了团队记忆的核心架构：私有记忆目录 memory/ 和共享记忆目录 memory/team/ 并存。这种双目录设计让每个开发者既有私人记忆空间，又能与团队共享项目约定。

interface TeamMemoryPaths {
  privateDir: string;
  teamDir: string;
}

function resolveTeamMemoryPaths(projectDir: string): TeamMemoryPaths {
  return {
    privateDir: path.join(projectDir, 'memory'),
    teamDir: path.join(projectDir, 'memory', 'team'),
  };
}

提示： 团队目录通常通过 Git 管理并随项目代码一起版本控制，而私有目录保持在 .gitignore 中，不进入版本库。






PathTraversalError 安全防护
团队记忆目录面临的首要安全威胁是路径遍历攻击——恶意构造的路径可能试图跳出 memory/team/ 目录访问系统文件。系统定义了专门的错误类型来处理此类攻击。


class PathTraversalError extends Error {
  constructor(
    public readonly attemptedPath: string,
    public readonly resolvedPath: string,
    public readonly allowedDir: string,
  ) {
    super(
      `Path traversal detected: ${attemptedPath} resolved to ${resolvedPath}, ` +
        `which is outside allowed directory ${allowedDir}`,
    );
    this.name = 'PathTraversalError';
  }
}

realpathDeepestExisting 符号链接解析
路径验证中最复杂的部分是处理符号链接。realpathDeepestExisting() 采用逐级解析策略：从路径的最深层开始，逐级向上查找实际存在的目录，对每一级都执行 realpath() 解析符号链接。


async function realpathDeepestExisting(targetPath: string): Promise<string> {
  let current = targetPath;
  const remaining: string[] = [];

  while (current !== path.dirname(current)) {
    try {
      const resolved = await fs.realpath(current);
      const tail = remaining.reverse().join(path.sep);
      return tail ? path.join(resolved, tail) : resolved;
    } catch {
      remaining.push(path.basename(current));
      current = path.dirname(current);
    }
  }

  return path.join(current, ...remaining.reverse());
}

这种逐级解析避免了一个常见的安全漏洞：攻击者可能创建一个中间目录的符号链接指向敏感位置，而简单的字符串检查无法发现此类间接引用。




提示： realpathDeepestExisting() 是一个"尽力而为"的函数——即使目标路径不完全存在，也能解析已存在部分的真实路径，确保安全验证不会因文件不存在而被绕过。






validateTeamMemWritePath 两阶段验证
写入团队记忆是最高安全级别的操作，validateTeamMemWritePath() 实现了两阶段验证流程：先进行字符串级别的包含检查，再进行完整的符号链接解析验证。


async function validateTeamMemWritePath(requestedPath: string, teamDir: string): Promise<string> {
  const normalized = path.normalize(path.join(teamDir, requestedPath));

  if (!normalized.startsWith(teamDir + path.sep) && normalized !== teamDir) {
    throw new PathTraversalError(requestedPath, normalized, teamDir);
  }

  const resolved = await realpathDeepestExisting(normalized);

  if (!resolved.startsWith(teamDir + path.sep) && resolved !== teamDir) {
    throw new PathTraversalError(requestedPath, resolved, teamDir);
  }

  return resolved;
}

两阶段设计的原理：第一阶段是廉价的快速拒绝（fast-reject），可以在不触发任何 I/O 的情况下拦截大部分恶意路径；只有通过第一阶段的路径才需要执行开销更大的 realpath 解析。




validateTeamMemKey 键名验证
除了路径验证，记忆文件的键名（文件名）本身也需要安全检查。validateTeamMemKey() 拒绝三类危险输入。


function validateTeamMemKey(key: string): void {
  if (key.includes('..')) {
    throw new PathTraversalError(key, key, 'team memory key');
  }

  if (path.isAbsolute(key)) {
    throw new PathTraversalError(key, key, 'team memory key');
  }

  if (key.includes('\0')) {
    throw new PathTraversalError(key, key, 'team memory key (null byte)');
  }
}

teamMemPrompts 与 scope 标签
teamMemPrompts.ts 定义了团队记忆的 prompt 模板，使用 <scope> 标签明确区分私有记忆和团队记忆的来源。


const TYPES_SECTION_COMBINED = `
<memory-types>
  <scope type="private">
    These are your personal memories. Only you can see them.
    Store personal preferences and individual corrections here.
  </scope>
  <scope type="team">
    These are shared team memories. All team members can see them.
    Store coding conventions, architecture decisions, and shared context here.
  </scope>
</memory-types>
`;
buildCombinedMemoryPrompt() 将两个目录的内容合并为统一的 prompt：


function buildCombinedMemoryPrompt(projectDir: string): string {
  const paths = resolveTeamMemoryPaths(projectDir);
  const sections: string[] = [];

  sections.push(TYPES_SECTION_COMBINED);

  const privateMemories = scanMemoryDirectory(paths.privateDir);
  if (privateMemories.length > 0) {
    sections.push('<private-memories>\n' + formatMemoryList(privateMemories) + '\n</private-memories>');
  }

  const teamMemories = scanMemoryDirectory(paths.teamDir);
  if (teamMemories.length > 0) {
    sections.push('<team-memories>\n' + formatMemoryList(teamMemories) + '\n</team-memories>');
  }

  return sections.join('\n\n');
}
