可观测性与追踪

为什么 Agent 需要可观测性

Agent 系统的执行过程是非确定性的——相同的输入可能产生不同的执行路径。当出现问题时，你需要能够回溯 Agent 的每一步决策：它在想什么、为什么选择了这个工具、工具返回了什么、它如何处理了错误。可观测性是调试和优化 Agent 的基础。



追踪系统
追踪（Tracing）记录 Agent 执行的完整轨迹，包括每次 LLM 调用、工具调用及其输入输出：


from dataclasses import dataclass, field
from datetime import datetime
import uuid

@dataclass
class Span:
    span_id: str
    parent_id: str | None
    name: str
    span_type: str
    start_time: datetime
    end_time: datetime | None = None
    inputs: dict = field(default_factory=dict)
    outputs: dict = field(default_factory=dict)
    metadata: dict = field(default_factory=dict)
    status: str = "running"
    error: str | None = None

class Tracer:
    def __init__(self):
        self.spans: list[Span] = []
        self._stack: list[str] = []

    def start_span(self, name: str, span_type: str, inputs: dict = None) -> str:
        span_id = str(uuid.uuid4())[:8]
        parent_id = self._stack[-1] if self._stack else None

        span = Span(
            span_id=span_id,
            parent_id=parent_id,
            name=name,
            span_type=span_type,
            start_time=datetime.now(),
            inputs=inputs or {}
        )

        self.spans.append(span)
        self._stack.append(span_id)
        return span_id

    def end_span(self, span_id: str, outputs: dict = None, error: str = None):
        span = next(s for s in self.spans if s.span_id == span_id)
        span.end_time = datetime.now()
        span.outputs = outputs or {}
        span.status = "error" if error else "completed"
        span.error = error
        if self._stack and self._stack[-1] == span_id:
            self._stack.pop()

    def get_trace(self) -> list[dict]:
        return [
            {
                "id": s.span_id,
                "parent": s.parent_id,
                "name": s.name,
                "type": s.span_type,
                "duration_ms": (
                    (s.end_time - s.start_time).total_seconds() * 1000
                    if s.end_time else None
                ),
                "status": s.status
            }
            for s in self.spans
        ]


LangSmith 集成
LangSmith 是 LangChain 团队提供的可观测性平台，支持追踪、评估和监控 LLM 应用：


import os
os.environ["LANGCHAIN_TRACING_V2"] = "true"
os.environ["LANGCHAIN_API_KEY"] = "your-api-key"
os.environ["LANGCHAIN_PROJECT"] = "my-agent-project"

from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

llm = ChatOpenAI(model="gpt-4o")
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个有用的助手"),
    ("user", "{input}")
])

chain = prompt | llm
result = chain.invoke({"input": "什么是 AI Agent？"})

日志策略
结构化日志是 Agent 调试的基础设施。Agent 的日志需要特别记录决策过程：


interface AgentLogEntry {
  timestamp: string;
  level: 'debug' | 'info' | 'warn' | 'error';
  component: 'llm' | 'tool' | 'memory' | 'orchestrator';
  event: string;
  data: Record<string, unknown>;
  traceId: string;
  spanId: string;
}

class AgentLogger {
  private logs: AgentLogEntry[] = [];

  log(entry: Omit<AgentLogEntry, 'timestamp'>): void {
    this.logs.push({
      ...entry,
      timestamp: new Date().toISOString(),
    });
  }

  llmCall(model: string, inputTokens: number, outputTokens: number, latencyMs: number): void {
    this.log({
      level: 'info',
      component: 'llm',
      event: 'llm_call',
      data: { model, inputTokens, outputTokens, latencyMs },
      traceId: '',
      spanId: '',
    });
  }

  toolCall(toolName: string, args: unknown, result: unknown, success: boolean): void {
    this.log({
      level: success ? 'info' : 'warn',
      component: 'tool',
      event: 'tool_call',
      data: { toolName, args, result, success },
      traceId: '',
      spanId: '',
    });
  }
}


成本追踪
LLM 调用成本在 Agent 系统中可能快速累积。实时成本追踪帮助控制预算：


@dataclass
class CostTracker:
    model_prices: dict = field(default_factory=lambda: {
        "gpt-4o": {"input": 2.5, "output": 10.0},
        "gpt-4o-mini": {"input": 0.15, "output": 0.6},
        "claude-3-5-sonnet": {"input": 3.0, "output": 15.0}
    })
    total_cost: float = 0.0
    calls: list[dict] = field(default_factory=list)

    def record(self, model: str, input_tokens: int, output_tokens: int):
        prices = self.model_prices.get(model, {"input": 0, "output": 0})
        cost = (
            input_tokens / 1_000_000 * prices["input"] +
            output_tokens / 1_000_000 * prices["output"]
        )
        self.total_cost += cost
        self.calls.append({
            "model": model,
            "input_tokens": input_tokens,
            "output_tokens": output_tokens,
            "cost": cost
        })
        return cost

    def summary(self) -> dict:
        return {
            "total_cost": f"${self.total_cost:.4f}",
            "total_calls": len(self.calls),
            "avg_cost_per_call": f"${self.total_cost / len(self.calls):.4f}" if self.calls else "$0",
            "total_input_tokens": sum(c["input_tokens"] for c in self.calls),
            "total_output_tokens": sum(c["output_tokens"] for c in self.calls)
        }


提示： 在生产环境中，建议为每个用户/任务设置成本上限。当累计成本接近阈值时发出警告，达到上限时终止执行。这能防止 Agent 陷入无限循环导致的成本爆炸。






小结
    

  • 可观测性是调试和优化 Agent 系统的基础，包含追踪、日志和指标三大支柱。
    • 

  • 追踪系统通过 Span 树记录完整执行轨迹，支持回放和分析。
    • 

  • LangSmith 提供了开箱即用的 LLM 应用可观测性，自动捕获调用链路。
    • 

  • 结构化日志需要特别关注 Agent 的决策过程、工具调用和错误信息。
    • 

  • 成本追踪是 Agent 运营的刚需，需要实时监控和预算告警机制。
