MCP 协议

什么是 Model Context Protocol

Model Context Protocol（MCP）是由 Anthropic 于 2024 年推出的开放协议，旨在标准化 LLM 应用与外部数据源和工具之间的交互方式。MCP 定义了统一的客户端-服务器架构，让 AI 应用能够以一致的方式连接到各种工具和数据源。

MCP 的设计理念类似于 USB——定义一个通用接口，让任何工具或数据源都能以标准方式接入 AI 应用。




核心概念：Tools / Resources / Prompts
MCP 协议定义了三种核心原语（Primitive），分别服务于不同的交互需求：

interface McpTool {
  name: string;
  description: string;
  inputSchema: {
    type: 'object';
    properties: Record<string, unknown>;
    required?: string[];
  };
}

interface McpResource {
  uri: string;
  name: string;
  description?: string;
  mimeType?: string;
}

interface McpPrompt {
  name: string;
  description?: string;
  arguments?: Array<{
    name: string;
    description?: string;
    required?: boolean;
  }>;
}
from mcp.server import Server
from mcp.types import Tool, Resource, TextContent

server = Server("demo-server")

@server.list_tools()
async def list_tools() -> list[Tool]:
    return [
        Tool(
            name="query_database",
            description="在数据库中执行 SQL 查询",
            inputSchema={
                "type": "object",
                "properties": {
                    "sql": {"type": "string", "description": "SQL 查询语句"},
                    "database": {"type": "string", "description": "数据库名称"}
                },
                "required": ["sql"]
            }
        )
    ]

@server.call_tool()
async def call_tool(name: str, arguments: dict) -> list[TextContent]:
    if name == "query_database":
        result = await execute_sql(arguments["sql"])
        return [TextContent(type="text", text=str(result))]
    raise ValueError(f"未知工具: {name}")

import asyncio
from mcp.server import Server
from mcp.server.stdio import stdio_server

server = Server("local-tools")

async def main():
    async with stdio_server() as (read_stream, write_stream):
        await server.run(read_stream, write_stream)

asyncio.run(main())
import { McpServer } from '@modelcontextprotocol/sdk/server/mcp.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';

const server = new McpServer({
  name: 'local-tools',
  version: '1.0.0',
});

server.tool('read_file', { path: { type: 'string', description: '文件路径' } }, async ({ path }) => {
  const content = await readFile(path, 'utf-8');
  return { content: [{ type: 'text', text: content }] };
});

const transport = new StdioServerTransport();
await server.connect(transport);


MCP 服务器开发实践
一个完整的 MCP 服务器通常包含以下结构：


from mcp.server import Server
from mcp.types import Tool, Resource, TextContent, Prompt, PromptMessage

server = Server("knowledge-base")

KNOWLEDGE = {
    "python": "Python 是一种高级编程语言...",
    "typescript": "TypeScript 是 JavaScript 的超集..."
}

@server.list_resources()
async def list_resources() -> list[Resource]:
    return [
        Resource(
            uri=f"kb://{topic}",
            name=f"{topic} 知识文档",
            mimeType="text/plain"
        )
        for topic in KNOWLEDGE
    ]

@server.read_resource()
async def read_resource(uri: str) -> str:
    topic = uri.replace("kb://", "")
    return KNOWLEDGE.get(topic, "未找到相关知识")

@server.list_prompts()
async def list_prompts() -> list[Prompt]:
    return [
        Prompt(
            name="explain_concept",
            description="用简单语言解释技术概念",
            arguments=[
                {"name": "concept", "required": True, "description": "要解释的概念"}
            ]
        )
    ]


提示： MCP 的生态正在快速发展。目前已有文件系统、GitHub、Slack、数据库等多种官方和社区 MCP 服务器。在开发自己的 MCP 服务器之前，先查看是否已有现成的实现。

MCP 可以看作是 Function Calling 的标准化和扩展。它不仅标准化了工具调用，还增加了资源访问和提示模板两个维度。




小结
    

  • MCP 是 Anthropic 推出的开放协议，标准化了 LLM 应用与外部工具/数据的交互。
    • 

  • MCP 定义了 Tools（工具）、Resources（资源）、Prompts（模板）三种核心原语。
    • 

  • 支持 Stdio 和 SSE 两种传输方式，分别适用于本地和远程场景。
    • 

  • MCP 服务器通过实现标准的请求处理器来暴露工具和数据。
    • 

  • MCP 是 Function Calling 的标准化演进，提供了更完整的工具交互框架。
