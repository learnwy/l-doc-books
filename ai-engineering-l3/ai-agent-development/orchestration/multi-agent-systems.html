Part II · Agent EngineeringAI Agent 开发 简介编排 简介多 Agent 系统

多 Agent 系统

从单 Agent 到多 Agent

当任务复杂度超过单个 Agent 的能力范围时，可以将多个专业化的 Agent 组合成协作系统。每个 Agent 专注于特定领域，通过协作完成更复杂的任务。



Supervisor 模式
Supervisor（监督者）模式是最常见的多 Agent 架构。一个中心 Agent 作为协调者，负责将任务分配给专业 Agent，收集结果并做出最终决策。


from dataclasses import dataclass

@dataclass
class AgentProfile:
    name: str
    role: str
    system_prompt: str
    tools: list[dict]

class SupervisorAgent:
    def __init__(self, agents: list[AgentProfile]):
        self.agents = {a.name: a for a in agents}

    def run(self, task: str) -> str:
        routing_prompt = self._build_routing_prompt(task)
        plan = call_llm(routing_prompt)
        assignments = self._parse_plan(plan)

        results = {}
        for agent_name, sub_task in assignments.items():
            agent = self.agents[agent_name]
            result = self._run_agent(agent, sub_task)
            results[agent_name] = result

        synthesis_prompt = (
            f"原始任务: {task}\n\n各 Agent 的结果:\n"
            + "\n".join(f"[{name}]: {result}" for name, result in results.items())
            + "\n\n请综合以上结果，生成最终答案。"
        )
        return call_llm(synthesis_prompt)

    def _build_routing_prompt(self, task: str) -> str:
        agent_list = "\n".join(
            f"- {a.name} ({a.role})" for a in self.agents.values()
        )
        return (
            f"你是一个任务协调者。\n可用的 Agent:\n{agent_list}\n\n"
            f"任务: {task}\n\n请为每个相关 Agent 分配子任务。"
        )

    def _run_agent(self, agent: AgentProfile, task: str) -> str:
        return call_llm(f"{agent.system_prompt}\n\n任务: {task}")

    def _parse_plan(self, plan: str) -> dict[str, str]:
        pass

supervisor = SupervisorAgent([
    AgentProfile("researcher", "研究员", "你是一个专业的研究员，擅长信息搜集和分析。", []),
    AgentProfile("coder", "程序员", "你是一个专业的程序员，擅长编写高质量代码。", []),
    AgentProfile("reviewer", "审查员", "你是一个严格的代码审查员，擅长发现问题。", [])
])


辩论模式
辩论（Debate）模式让多个 Agent 就同一问题进行辩论，通过多个视角的碰撞得出更准确的结论。


interface DebateRound {
  round: number;
  agentA: string;
  agentB: string;
}

class DebateSystem {
  private rounds: DebateRound[] = [];

  async debate(question: string, maxRounds: number = 3): Promise<string> {
    let agentAPosition = await this.generatePosition('Agent A', question);
    let agentBPosition = await this.generatePosition('Agent B', question);

    for (let round = 0; round < maxRounds; round++) {
      const agentARebuttal = await this.rebut('Agent A', agentAPosition, agentBPosition, question);
      const agentBRebuttal = await this.rebut('Agent B', agentBPosition, agentAPosition, question);

      this.rounds.push({
        round: round + 1,
        agentA: agentARebuttal,
        agentB: agentBRebuttal,
      });

      agentAPosition = agentARebuttal;
      agentBPosition = agentBRebuttal;
    }

    return this.judge(question, this.rounds);
  }

  private async generatePosition(agent: string, question: string): Promise<string> {
    return callLLM(`作为 ${agent}，请对以下问题给出你的分析和观点:\n${question}`);
  }

  private async rebut(agent: string, myPosition: string, opponentPosition: string, question: string): Promise<string> {
    return callLLM(
      `问题: ${question}\n你的观点: ${myPosition}\n对方观点: ${opponentPosition}\n` +
        `请反驳对方的观点，同时完善自己的论点。`,
    );
  }

  private async judge(question: string, rounds: DebateRound[]): Promise<string> {
    return callLLM(`作为裁判，综合以下辩论内容做出最终判断:\n${JSON.stringify(rounds)}`);
  }
}


协作模式
与辩论不同，协作（Collaboration）模式让多个 Agent 分工合作，每个 Agent 负责任务的一个阶段或一个方面：

class PipelineCollaboration:
    def __init__(self, agents: list[AgentProfile]):
        self.pipeline = agents

    def run(self, initial_input: str) -> str:
        current_output = initial_input
        for agent in self.pipeline:
            prompt = (
                f"{agent.system_prompt}\n\n"
                f"输入:\n{current_output}\n\n"
                f"请处理以上输入并输出结果。"
            )
            current_output = call_llm(prompt)
        return current_output

pipeline = PipelineCollaboration([
    AgentProfile("drafter", "初稿撰写", "你负责撰写技术文档的初稿。", []),
    AgentProfile("editor", "编辑", "你负责润色文档，改进结构和表达。", []),
    AgentProfile("fact_checker", "事实核查", "你负责验证文档中的技术细节是否准确。", [])
])


Agent 专业化
专业化（Specialization）是多 Agent 系统高效运作的关键。每个 Agent 应该有明确的职责边界、专属的工具集和针对性的系统提示：


research_agent = AgentProfile(
    name="researcher",
    role="研究分析师",
    system_prompt=(
        "你是一个专业的研究分析师。你的职责是:\n"
        "1. 搜集和整理相关信息\n"
        "2. 分析数据趋势和模式\n"
        "3. 提供有数据支撑的洞察\n"
        "你只负责信息搜集和分析，不负责编写代码或执行操作。"
    ),
    tools=["web_search", "document_retrieval", "data_analysis"]
)

coding_agent = AgentProfile(
    name="developer",
    role="软件开发者",
    system_prompt=(
        "你是一个专业的软件开发者。你的职责是:\n"
        "1. 根据需求编写高质量代码\n"
        "2. 编写和运行测试\n"
        "3. 修复 Bug 并优化代码\n"
        "你只负责编码工作，不负责信息搜集或文档撰写。"
    ),
    tools=["code_executor", "file_manager", "test_runner"]
)


提示： 多 Agent 系统的最大挑战不是技术实现，而是任务分配和通信设计。过于精细的分工会导致通信开销过大，过于粗粒度的分工则失去了多 Agent 的优势。建议从 2-3 个 Agent 开始，根据需要逐步增加。






小结
    

  • 多 Agent 系统通过专业化分工和协作完成单 Agent 无法胜任的复杂任务。
    • 

  • Supervisor 模式使用中心协调者分配任务、收集结果、综合决策。
    • 

  • 辩论模式通过多视角碰撞提高决策质量，适合需要审慎判断的场景。
    • 

  • 协作模式包括流水线、专家团队、对等协作等形式，适用于不同类型的任务。
    • 

  • Agent 专业化通过明确的职责边界、专属工具和针对性提示来提升效率。
