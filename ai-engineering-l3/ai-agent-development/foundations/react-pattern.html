ReAct 模式

推理与行动的结合

ReAct（Reasoning + Acting）是一种将思维链推理与工具调用相结合的 Agent 模式。它由 Yao 等人在 2022 年提出，核心思想是让 LLM 在采取行动之前先进行显式推理，形成 Thought → Action → Observation 的三步循环。

与直接让 LLM 生成答案相比，ReAct 模式有三个关键优势：

Thought-Action-Observation 循环
ReAct 的核心是严格的三步循环结构。每一步都有明确的职责：


Thought（思考）：Agent 分析当前状态，决定下一步策略。这一步不产生外部效果，仅在内部进行推理。


Action（行动）：Agent 基于思考结果选择并执行一个工具调用。行动必须是具体、可执行的。


Observation（观察）：工具返回的结果。Agent 将这一结果纳入上下文，作为下一轮思考的输入。


REACT_PROMPT = """你是一个能使用工具的智能助手。请严格按照以下格式回答：

Thought: <你的思考过程>
Action: <工具名称>[<参数>]

问题: 2024 年诺贝尔物理学奖得主的年龄之和是多少？

Answer: 2024 年诺贝尔物理学奖得主 John Hopfield（91 岁）和 Geoffrey Hinton（76 岁）的年龄之和为 167 岁。


ReAct Agent 实现
以下是一个基于 LLM 的 ReAct Agent 完整实现：


import re
from openai import OpenAI

client = OpenAI()

class ReActAgent:
    def __init__(self, tools: dict, max_steps: int = 8):
        self.tools = tools
        self.max_steps = max_steps

    def run(self, question: str) -> str:
        prompt = self._build_prompt(question)
        trajectory = ""

        for step in range(self.max_steps):
            response = client.chat.completions.create(
                model="gpt-4o",
                messages=[{"role": "user", "content": prompt + trajectory}],
                stop=["Observation:"]
            )

            text = response.choices[0].message.content
            trajectory += text

            if "Answer:" in text:
                return text.split("Answer:")[-1].strip()

            action_match = re.search(r"Action:\s*(\w+)\[(.+?)\]", text)
            if action_match:
                tool_name = action_match.group(1)
                tool_input = action_match.group(2)

                if tool_name in self.tools:
                    observation = self.tools[tool_name](tool_input)
                else:
                    observation = f"错误: 未知工具 {tool_name}"

                trajectory += f"\nObservation: {observation}\n"

        return "达到最大步数限制，未能得出答案"

    def _build_prompt(self, question: str) -> str:
        tool_desc = "\n".join(
            f"- {name}: {func.__doc__}" for name, func in self.tools.items()
        )
        return f"可用工具:\n{tool_desc}\n\n问题: {question}\n"
使用示例：


def search(query: str) -> str:

    """计算数学表达式"""
    return str(eval(expression))

agent = ReActAgent(tools={"search": search, "calculator": calculator})

ReAct 与其他模式的对比

小结
    

  • ReAct 将推理（Reasoning）与行动（Acting）结合，形成 Thought-Action-Observation 循环。
    • 

  • 与纯推理或纯行动相比，ReAct 在可解释性和准确性上都有优势。
    • 

  • ReAct Agent 的实现核心是解析 LLM 输出中的 Action 指令并路由到对应工具。
    • 

  • 推理循环、工具选择错误、过早终止是常见问题，需要通过步数限制和重复检测来防范。
    • 

  • ReAct 是现代 Agent 框架的基础范式，理解它对掌握 Agent 开发至关重要。
