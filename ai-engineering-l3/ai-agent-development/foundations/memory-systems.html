记忆系统

为什么 Agent 需要记忆

LLM 本身是无状态的——每次调用都是独立的，没有对之前交互的记忆。Agent 的记忆系统弥补了这一缺陷，使其能够在长时间的任务执行中保持上下文连贯性，并从过去的经验中学习。



短期记忆与长期记忆
Agent 的记忆系统分为短期记忆和长期记忆，类似于人类的工作记忆和长期记忆：

from dataclasses import dataclass, field
from datetime import datetime

@dataclass
class MemoryEntry:
    content: str
    timestamp: datetime
    importance: float
    memory_type: str
    metadata: dict = field(default_factory=dict)

class MemorySystem:
    def __init__(self, short_term_limit: int = 20):
        self.short_term: list[MemoryEntry] = []
        self.long_term: list[MemoryEntry] = []
        self.short_term_limit = short_term_limit

    def add_short_term(self, content: str, importance: float = 0.5):
        entry = MemoryEntry(
            content=content,
            timestamp=datetime.now(),
            importance=importance,
            memory_type="short_term"
        )
        self.short_term.append(entry)
        if len(self.short_term) > self.short_term_limit:
            self._consolidate()

    def _consolidate(self):
        high_importance = [
            m for m in self.short_term if m.importance > 0.7
        ]
        for entry in high_importance:
            entry.memory_type = "long_term"
            self.long_term.append(entry)
        self.short_term = self.short_term[-self.short_term_limit:]

记忆检索
记忆的价值在于检索。当 Agent 面对新任务时，需要从记忆库中找到最相关的信息。有效的检索策略通常结合多个维度：


import numpy as np
from datetime import datetime, timedelta

class MemoryRetriever:
    def __init__(self, decay_factor: float = 0.995):
        self.decay_factor = decay_factor

    def retrieve(
        self,
        query_embedding: np.ndarray,
        memories: list[MemoryEntry],
        top_k: int = 5,
        weights: dict = None
    ) -> list[MemoryEntry]:
        if weights is None:
            weights = {"relevance": 0.5, "recency": 0.3, "importance": 0.2}

        scored = []
        now = datetime.now()

        for memory in memories:
            relevance = self._cosine_similarity(
                query_embedding, memory.metadata.get("embedding", [])
            )

            hours_ago = (now - memory.timestamp).total_seconds() / 3600
            recency = self.decay_factor ** hours_ago

            score = (
                weights["relevance"] * relevance +
                weights["recency"] * recency +
                weights["importance"] * memory.importance
            )
            scored.append((score, memory))

        scored.sort(key=lambda x: x[0], reverse=True)
        return [m for _, m in scored[:top_k]]

    def _cosine_similarity(self, a: np.ndarray, b: np.ndarray) -> float:
        if len(a) == 0 or len(b) == 0:
            return 0.0
        return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))


提示： Google DeepMind 的 Generative Agents 论文采用了「相关性 + 时效性 + 重要性」的三因子检索公式，这已成为 Agent 记忆检索的经典范式。根据具体场景调整三个因子的权重可以显著影响 Agent 的行为特征。

class MemoryManager:
    def __init__(self, max_short_term: int = 50, summary_threshold: int = 30):
        self.max_short_term = max_short_term
        self.summary_threshold = summary_threshold

    def compress(self, memories: list[MemoryEntry]) -> list[MemoryEntry]:
        if len(memories) <= self.summary_threshold:
            return memories

        old_memories = memories[:-10]
        recent_memories = memories[-10:]

        summary_content = self._summarize(old_memories)
        summary_entry = MemoryEntry(
            content=summary_content,
            timestamp=old_memories[-1].timestamp,
            importance=0.8,
            memory_type="summary"
        )

        return [summary_entry] + recent_memories

    def _summarize(self, memories: list[MemoryEntry]) -> str:

小结
    

  • Agent 记忆系统弥补了 LLM 无状态的缺陷，分为短期记忆和长期记忆两大类。
    • 

  • 长期记忆借鉴认知科学分为情景记忆、语义记忆和程序记忆三种类型。
    • 

  • 记忆检索通常采用相关性、时效性、重要性的三因子综合评分策略。
    • 

  • 随着记忆积累，需要滑动窗口、摘要压缩、重要性过滤等管理策略来控制规模。
    • 

  • 有效的记忆系统是 Agent 持续学习和长期任务执行的基础。
