上下文窗口管理

上下文窗口的核心约束

LLM 的上下文窗口（Context Window）是 Agent 系统面临的最关键约束之一。每个模型都有固定的 Token 上限，所有的系统提示、对话历史、工具调用记录和工具结果都必须在这个窗口内。超出限制将导致信息丢失或 API 调用失败。

Token 预算分配
有效的上下文管理始于合理的 Token 预算分配。将上下文窗口划分为固定区和动态区：


from dataclasses import dataclass

@dataclass
class TokenBudget:
    total_limit: int
    system_prompt: int
    tool_definitions: int
    reserved_for_output: int

    @property
    def available_for_history(self) -> int:
        return (
            self.total_limit
            - self.system_prompt
            - self.tool_definitions
            - self.reserved_for_output
        )

budget = TokenBudget(
    total_limit=128000,
    system_prompt=800,
    tool_definitions=1500,
    reserved_for_output=4096
)

print(f"可用于对话历史的 Token: {budget.available_for_history}")
interface TokenBudget {
  totalLimit: number;
  systemPrompt: number;
  toolDefinitions: number;
  reservedForOutput: number;
}

function calculateAvailable(budget: TokenBudget): number {
  return budget.totalLimit - budget.systemPrompt - budget.toolDefinitions - budget.reservedForOutput;
}

const budget: TokenBudget = {
  totalLimit: 128000,
  systemPrompt: 800,
  toolDefinitions: 1500,
  reservedForOutput: 4096,
};

console.log(`可用 Token: ${calculateAvailable(budget)}`);


截断策略
当对话历史超出预算时，截断（Truncation）是最简单直接的策略——移除最早的消息：


import tiktoken

class TruncationStrategy:
    def __init__(self, model: str = "gpt-4o", max_tokens: int = 120000):
        self.encoder = tiktoken.encoding_for_model(model)
        self.max_tokens = max_tokens

    def count(self, text: str) -> int:
        return len(self.encoder.encode(text))

    def truncate(self, messages: list[dict]) -> list[dict]:
        total = sum(self.count(m.get("content", "") or "") + 4 for m in messages)
        if total <= self.max_tokens:
            return messages

        protected = []
        removable = []
        for i, msg in enumerate(messages):
            if i == 0 and msg["role"] == "system":
                protected.append(msg)
            elif i <= 1 and msg["role"] == "user":
                protected.append(msg)
            else:
                removable.append(msg)

        result = list(protected)
        current_tokens = sum(self.count(m.get("content", "") or "") + 4 for m in result)

        for msg in reversed(removable):
            msg_tokens = self.count(msg.get("content", "") or "") + 4
            if current_tokens + msg_tokens <= self.max_tokens:
                result.insert(len(protected), msg)
                current_tokens += msg_tokens
            else:
                break

        return result


摘要压缩策略
摘要（Summarization）策略比简单截断更智能——将旧的对话历史压缩为摘要，保留关键信息的同时大幅减少 Token 消耗：


class SummarizationStrategy:
    def __init__(self, llm_client, summary_threshold: int = 30):
        self.llm = llm_client
        self.threshold = summary_threshold
        self.cached_summary: str | None = None

    def compress(self, messages: list[dict]) -> list[dict]:
        if len(messages) <= self.threshold:
            return messages

        system = messages[0] if messages[0]["role"] == "system" else None
        to_summarize = messages[1:-10] if system else messages[:-10]
        recent = messages[-10:]

        summary = self._summarize(to_summarize)

        result = []
        if system:
            result.append(system)
        result.append({
            "role": "system",
            "content": f"以下是之前对话的摘要:\n{summary}"
        })
        result.extend(recent)

        return result

    def _summarize(self, messages: list[dict]) -> str:
        conversation = "\n".join(
            f"{m['role']}: {m.get('content', '')}" for m in messages
        )
        return self.llm.chat([{
            "role": "user",
            "content": f"请简洁地总结以下对话的关键信息和结论:\n\n{conversation}"
        }])


滑动窗口策略
滑动窗口（Sliding Window）是截断和摘要的混合方案——维护一个固定大小的窗口，只保留窗口内的消息：

class SlidingWindowStrategy:
    def __init__(self, window_size: int = 20):
        self.window_size = window_size

    def apply(self, messages: list[dict]) -> list[dict]:
        if len(messages) <= self.window_size:
            return messages

        system = []
        if messages[0]["role"] == "system":
            system = [messages[0]]

        non_system = [m for m in messages if m["role"] != "system"]
        windowed = non_system[-self.window_size:]

        return system + windowed


提示： 在实际项目中，推荐组合使用多种策略：滑动窗口作为基础保护层，摘要压缩在窗口移动时保存上下文，智能选择用于关键的工具调用结果。关键原则是永远保留系统提示和用户原始请求。






小结
    

  • 上下文窗口是 Agent 系统的核心约束，所有交互内容必须在 Token 上限内。
    • 

  • Token 预算分配应将窗口分为固定区（系统提示、工具定义、输出预留）和动态区（对话历史）。
    • 

  • 截断策略最简单，保留最新消息但丢失早期上下文。
    • 

  • 摘要压缩用 LLM 总结旧消息，在信息保留和 Token 节省间取得平衡。
    • 

  • 滑动窗口是截断的改进版，结合多种策略使用效果最佳。
