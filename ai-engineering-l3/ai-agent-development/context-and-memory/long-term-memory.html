长期记忆

超越上下文窗口

上下文窗口内的信息是 Agent 的「工作记忆」，但其容量有限且生命周期短。长期记忆（Long-term Memory）系统让 Agent 能够跨会话保持知识，从历史经验中学习，并在相关时刻回忆起重要信息。



向量存储记忆
向量存储是最常用的长期记忆实现方式。将交互内容编码为向量，通过相似性搜索检索相关记忆：


from openai import OpenAI
import numpy as np
from datetime import datetime
from dataclasses import dataclass

client = OpenAI()

@dataclass
class Memory:
    content: str
    embedding: list[float]
    timestamp: datetime
    metadata: dict

class VectorMemory:
    def __init__(self):
        self.memories: list[Memory] = []

    def add(self, content: str, metadata: dict | None = None):
        embedding = self._embed(content)
        self.memories.append(Memory(
            content=content,
            embedding=embedding,
            timestamp=datetime.now(),
            metadata=metadata or {}
        ))

    def search(self, query: str, top_k: int = 5) -> list[Memory]:
        query_embedding = self._embed(query)
        scored = []
        for memory in self.memories:
            similarity = self._cosine_sim(query_embedding, memory.embedding)
            scored.append((similarity, memory))
        scored.sort(key=lambda x: x[0], reverse=True)
        return [m for _, m in scored[:top_k]]

    def _embed(self, text: str) -> list[float]:
        response = client.embeddings.create(
            model="text-embedding-3-small",
            input=text
        )
        return response.data[0].embedding

    def _cosine_sim(self, a: list[float], b: list[float]) -> float:
        a_arr, b_arr = np.array(a), np.array(b)
        return float(np.dot(a_arr, b_arr) / (np.linalg.norm(a_arr) * np.linalg.norm(b_arr)))

结构化记忆
并非所有记忆都适合向量存储。用户偏好、任务历史、学到的规则等结构化信息更适合用明确的数据结构存储：


interface UserProfile {
  name: string;
  preferences: {
    language: string;
    responseStyle: 'concise' | 'detailed';
    codeLanguage: string;
  };
  history: {
    totalInteractions: number;
    topTopics: string[];
    lastActive: Date;
  };
}

interface LearnedRule {
  condition: string;
  action: string;
  confidence: number;
  learnedFrom: string;
  usageCount: number;
}

class StructuredMemory {
  private userProfile: UserProfile;
  private rules: LearnedRule[] = [];

  updatePreference(key: string, value: unknown): void {
    (this.userProfile.preferences as any)[key] = value;
  }

  addRule(rule: LearnedRule): void {
    const existing = this.rules.find((r) => r.condition === rule.condition);
    if (existing) {
      existing.confidence = (existing.confidence + rule.confidence) / 2;
      existing.usageCount++;
    } else {
      this.rules.push(rule);
    }
  }

  getRelevantRules(context: string): LearnedRule[] {
    return this.rules.filter((r) => context.includes(r.condition)).sort((a, b) => b.confidence - a.confidence);
  }
}


记忆整合
记忆整合（Memory Consolidation）是将短期的交互记忆转化为长期知识的过程，类似于人类在睡眠中整合记忆：


class MemoryConsolidator:
    def __init__(self, vector_memory: VectorMemory, structured_memory):
        self.vector = vector_memory
        self.structured = structured_memory

    def consolidate(self, session_messages: list[dict]):
        important_moments = self._extract_important(session_messages)
        for moment in important_moments:
            self.vector.add(
                content=moment["content"],
                metadata={"type": moment["type"], "importance": moment["importance"]}
            )

        preferences = self._extract_preferences(session_messages)
        for pref in preferences:
            self.structured.updatePreference(pref["key"], pref["value"])

        lessons = self._extract_lessons(session_messages)
        for lesson in lessons:
            self.structured.addRule(lesson)

    def _extract_important(self, messages: list[dict]) -> list[dict]:
        conversation = "\n".join(f"{m['role']}: {m.get('content', '')}" for m in messages)
        result = call_llm(
            f"从以下对话中提取值得长期记忆的关键信息。"
            f"按重要性排序，返回 JSON 数组。\n\n{conversation}"
        )
        return parse_json(result)

    def _extract_preferences(self, messages: list[dict]) -> list[dict]:
        conversation = "\n".join(f"{m['role']}: {m.get('content', '')}" for m in messages)
        result = call_llm(
            f"从对话中提取用户偏好信息（如编程语言偏好、回答风格偏好等）。\n\n{conversation}"
        )
        return parse_json(result)

    def _extract_lessons(self, messages: list[dict]) -> list[dict]:
        return []


提示： 记忆整合应该在会话结束后异步执行，避免影响实时交互性能。可以设定定时任务或在检测到会话空闲时触发。

class HybridMemory:
    def __init__(self):
        self.cache = {}
        self.vector = VectorMemory()
        self.structured = StructuredMemory()

    def recall(self, query: str, context: dict) -> dict:
        cache_hit = self.cache.get(query)
        if cache_hit:
            return cache_hit

        vector_results = self.vector.search(query, top_k=3)
        rules = self.structured.getRelevantRules(query)
        user_prefs = self.structured.getUserProfile()

        result = {
            "relevant_memories": [m.content for m in vector_results],
            "applicable_rules": rules,
            "user_preferences": user_prefs
        }

        self.cache[query] = result
        return result


小结
    

  • 长期记忆让 Agent 跨会话保持知识、从经验中学习，超越上下文窗口的限制。
    • 

  • 向量存储记忆通过嵌入和相似性搜索实现语义检索，适合经验和事件类记忆。
    • 

  • 结构化记忆适合用户偏好、学习规则等需要精确查询的信息。
    • 

  • 记忆整合在会话结束后将短期记忆转化为长期知识，需异步执行。
    • 

  • 混合记忆架构组合缓存、向量、结构化和归档四个层次，覆盖不同访问需求。
