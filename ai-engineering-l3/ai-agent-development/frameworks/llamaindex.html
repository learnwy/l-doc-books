LlamaIndex 索引框架

LlamaIndex 定位与核心理念

LlamaIndex 专注于数据驱动的 LLM 应用，核心理念是帮助开发者高效地将私有数据与 LLM 连接起来。与 LangChain 侧重于通用编排不同，LlamaIndex 在数据索引、检索和查询方面有更深入的抽象。

from llama_index.core import VectorStoreIndex, SimpleDirectoryReader, Settings
from llama_index.llms.openai import OpenAI
from llama_index.embeddings.openai import OpenAIEmbedding

Settings.llm = OpenAI(model="gpt-4o")
Settings.embed_model = OpenAIEmbedding(model="text-embedding-3-small")

documents = SimpleDirectoryReader("./data").load_data()
index = VectorStoreIndex.from_documents(documents)

query_engine = index.as_query_engine(similarity_top_k=5)
response = query_engine.query("这个项目的主要架构是什么？")
print(response)


查询引擎
查询引擎（Query Engine）是 LlamaIndex 的核心抽象之一，将检索和生成整合为一步操作：


from llama_index.core import VectorStoreIndex
from llama_index.core.query_engine import RetrieverQueryEngine
from llama_index.core.response_synthesizers import get_response_synthesizer

index = VectorStoreIndex.from_documents(documents)
retriever = index.as_retriever(similarity_top_k=10)

synthesizer = get_response_synthesizer(
    response_mode="tree_summarize",
    use_async=True
)

query_engine = RetrieverQueryEngine(
    retriever=retriever,
    response_synthesizer=synthesizer
)

response = query_engine.query("系统的性能瓶颈在哪里？")
print(f"回答: {response}")
print(f"引用来源: {[n.node.metadata for n in response.source_nodes]}")

LlamaIndex Agent
LlamaIndex 的 Agent 将查询引擎和工具结合，实现数据驱动的智能体：


from llama_index.core.agent import ReActAgent
from llama_index.core.tools import QueryEngineTool, FunctionTool

project_tool = QueryEngineTool.from_defaults(
    query_engine=project_query_engine,
    name="project_docs",
    description="搜索项目文档，获取架构设计、API 规范等信息"
)

api_tool = QueryEngineTool.from_defaults(
    query_engine=api_query_engine,
    name="api_reference",
    description="搜索 API 参考文档，获取接口定义和使用方法"
)

def calculate_cost(tokens: int, model: str = "gpt-4o") -> str:
    """计算 LLM 调用成本"""
    prices = {"gpt-4o": 0.005, "gpt-4o-mini": 0.00015}
    cost = tokens / 1000 * prices.get(model, 0)
    return f"预估成本: ${cost:.4f}"

cost_tool = FunctionTool.from_defaults(fn=calculate_cost)

agent = ReActAgent.from_tools(
    [project_tool, api_tool, cost_tool],
    llm=OpenAI(model="gpt-4o"),
    verbose=True
)

response = agent.chat("项目中的用户认证模块是怎么设计的？预估查询 10000 次的成本。")
print(response)


数据连接器
LlamaIndex 提供了丰富的数据连接器（Data Connectors），支持从各种来源加载数据：


from llama_index.core import SimpleDirectoryReader
from llama_index.readers.web import SimpleWebPageReader

file_docs = SimpleDirectoryReader(
    input_dir="./data",
    recursive=True,
    required_exts=[".md", ".txt", ".pdf"]
).load_data()

web_docs = SimpleWebPageReader(html_to_text=True).load_data(
    ["https://docs.example.com/guide"]
)

all_docs = file_docs + web_docs
index = VectorStoreIndex.from_documents(all_docs)


提示： LlamaIndex Hub（llamahub.ai）提供了超过 300 个社区贡献的数据连接器。在自行开发连接器之前，先检查 Hub 中是否已有现成的实现。






小结
    

  • LlamaIndex 专注于数据驱动的 LLM 应用，核心优势在于数据索引和检索抽象。
    • 

  • 提供 VectorStore、Summary、Tree、KnowledgeGraph 等多种索引类型，覆盖不同查询场景。
    • 

  • 查询引擎整合了检索和响应合成，支持 refine、tree_summarize 等多种合成模式。
    • 

  • LlamaIndex Agent 将查询引擎封装为工具，实现数据感知的智能体。
    • 

  • 数据连接器生态丰富，支持文件、数据库、网页、API 等多种数据源。
