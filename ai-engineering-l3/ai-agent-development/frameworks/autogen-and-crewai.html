AutoGen 与 CrewAI

多 Agent 框架概览

AutoGen（微软）和 CrewAI 是两个代表性的多 Agent 框架。它们的核心目标相同——让多个 AI Agent 协作完成任务，但在设计哲学和使用方式上各有特色。

AutoGen：对话驱动
AutoGen 的核心抽象是 ConversableAgent——每个 Agent 都是一个可以参与对话的实体。多 Agent 协作通过 Agent 之间的消息传递来实现。


from autogen import ConversableAgent, AssistantAgent, UserProxyAgent

config_list = [{"model": "gpt-4o", "api_key": "your-key"}]

assistant = AssistantAgent(
    name="coding_assistant",
    system_message="你是一个专业的 Python 程序员。编写高质量代码并解释你的实现。",
    llm_config={"config_list": config_list}
)

reviewer = AssistantAgent(
    name="code_reviewer",
    system_message=(
        "你是一个严格的代码审查员。审查代码的正确性、性能和可读性。"
        "指出所有问题并给出改进建议。"
    ),
    llm_config={"config_list": config_list}
)

user_proxy = UserProxyAgent(
    name="user",
    human_input_mode="NEVER",
    code_execution_config={"work_dir": "workspace", "use_docker": False},
    max_consecutive_auto_reply=5
)

user_proxy.initiate_chat(
    assistant,
    message="实现一个 LRU 缓存，支持 get 和 put 操作，时间复杂度 O(1)。"
)
AutoGen 支持多种对话模式：


from autogen import GroupChat, GroupChatManager

agents = [user_proxy, assistant, reviewer]

group_chat = GroupChat(
    agents=agents,
    messages=[],
    max_round=10,
    speaker_selection_method="auto"
)

manager = GroupChatManager(
    groupchat=group_chat,
    llm_config={"config_list": config_list}
)

user_proxy.initiate_chat(
    manager,
    message="实现一个 Web 爬虫，支持深度限制和并发控制，然后审查代码质量。"
)


CrewAI：角色扮演
CrewAI 采用更直观的「团队」隐喻——定义角色（Role）、分配任务（Task）、编排流程（Process）：


from crewai import Agent, Task, Crew, Process

researcher = Agent(
    role="高级研究分析师",
    goal="深入研究最新的 AI Agent 技术趋势",
    backstory="你是一位拥有 10 年经验的 AI 研究员，擅长分析技术趋势。",
    verbose=True,
    allow_delegation=True,
    tools=[search_tool]
)

writer = Agent(
    role="技术文档撰写专家",
    goal="撰写清晰、准确的技术文档",
    backstory="你是一位资深技术作家，擅长将复杂概念转化为易懂的文档。",
    verbose=True,
    tools=[file_tool]
)

reviewer = Agent(
    role="质量审查员",
    goal="确保文档的技术准确性和内容完整性",
    backstory="你是一位严谨的技术审查员，对细节要求极高。",
    verbose=True
)
CrewAI 的任务定义包含明确的期望输出：


research_task = Task(
    description="研究 2024-2025 年 AI Agent 框架的最新发展，包括 LangGraph、AutoGen、CrewAI 的版本更新和新特性。",
    expected_output="一份包含各框架最新特性对比的研究报告",
    agent=researcher
)

writing_task = Task(
    description="基于研究报告，撰写一篇关于 AI Agent 框架选型的技术博客。",
    expected_output="一篇 1500 字左右的技术博客，包含代码示例和对比表格",
    agent=writer,
    context=[research_task]
)

review_task = Task(
    description="审查技术博客的准确性和完整性，提出修改建议。",
    expected_output="审查意见列表和修改后的最终版本",
    agent=reviewer,
    context=[writing_task]
)

crew = Crew(
    agents=[researcher, writer, reviewer],
    tasks=[research_task, writing_task, review_task],
    process=Process.sequential,
    verbose=True
)

result = crew.kickoff()
print(result)

提示： 如果你的场景是「多个角色按流程完成任务」（如研究→写作→审查），CrewAI 的直觉性更强。如果需要灵活的 Agent 间对话和动态路由，AutoGen 更适合。两者都可以与 LangChain 工具生态集成。






框架选型建议
def recommend_framework(requirements: dict) -> str:
    complexity = requirements.get("complexity", "medium")
    interaction_type = requirements.get("interaction", "task")
    code_execution = requirements.get("code_execution", False)
    customization = requirements.get("customization", "medium")

    if interaction_type == "conversation" and customization == "high":
        return "AutoGen - 灵活的对话驱动编排"
    elif interaction_type == "task" and complexity in ("low", "medium"):
        return "CrewAI - 直观的角色和任务定义"
    elif code_execution:
        return "AutoGen - 内置代码执行沙箱"
    else:
        return "根据团队经验选择，两者都可胜任"


小结
    

  • AutoGen 和 CrewAI 是两个主流的多 Agent 框架，分别采用对话驱动和角色扮演的设计哲学。
    • 

  • AutoGen 的核心是 ConversableAgent，通过消息传递实现灵活的 Agent 协作。
    • 

  • CrewAI 使用 Role-Goal-Backstory 定义 Agent，通过 Task 和 Process 编排流程。
    • 

  • AutoGen 适合需要灵活对话和代码执行的场景，CrewAI 适合结构化的团队协作任务。
    • 

  • 两者都可以与 LangChain 工具生态集成，选型应基于具体场景需求。
