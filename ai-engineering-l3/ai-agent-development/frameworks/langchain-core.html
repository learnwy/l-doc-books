LangChain 核心

LangChain 架构概览

LangChain 是目前最流行的 LLM 应用开发框架，提供了从基础模型调用到复杂 Agent 编排的完整工具链。其核心设计理念是组合性——通过将小的、可复用的组件串联起来构建复杂应用。



Chains 与 LCEL
LangChain Expression Language（LCEL）是 LangChain 的核心编程模型。它通过 | 管道操作符将组件串联，形成声明式的数据处理链：


from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个专业的{domain}助手。"),
    ("user", "{question}")
])

model = ChatOpenAI(model="gpt-4o")
parser = StrOutputParser()

chain = prompt | model | parser

result = chain.invoke({
    "domain": "Python 编程",
    "question": "如何实现一个二叉搜索树？"
})
print(result)

Runnables 组合
LCEL 提供了丰富的组合原语，支持顺序、并行、条件等多种编排模式：


from langchain_core.runnables import RunnableParallel, RunnablePassthrough, RunnableLambda

parallel_chain = RunnableParallel(
    summary=prompt_summary | model | parser,
    keywords=prompt_keywords | model | parser,
    sentiment=prompt_sentiment | model | parser
)

result = parallel_chain.invoke({"text": "LangChain 是一个强大的 LLM 框架..."})

chain_with_context = RunnableParallel(
    context=retriever,
    question=RunnablePassthrough()

def route(input_data):
    if "code" in input_data["question"].lower():
        return code_chain

routed_chain = RunnableLambda(route)


Callbacks 系统
LangChain 的 Callbacks 系统提供了在链路执行过程中插入自定义逻辑的能力，用于日志、追踪、监控等：


from langchain_core.callbacks import BaseCallbackHandler

class TokenCounterCallback(BaseCallbackHandler):
    def __init__(self):
        self.total_tokens = 0

    def on_llm_end(self, response, **kwargs):
        if response.llm_output and "token_usage" in response.llm_output:
            self.total_tokens += response.llm_output["token_usage"]["total_tokens"]

    def on_tool_start(self, serialized, input_str, **kwargs):
        print(f"工具调用: {serialized.get('name', 'unknown')}")

    def on_tool_end(self, output, **kwargs):
        print(f"工具结果: {output[:100]}...")

counter = TokenCounterCallback()
result = chain.invoke(
    {"domain": "AI", "question": "什么是 LangChain？"},
    config={"callbacks": [counter]}
)
print(f"总 Token 消耗: {counter.total_tokens}")


Agent Executors
LangChain 的 Agent 系统将 LLM 的推理能力与工具调用能力结合：


from langchain_openai import ChatOpenAI
from langchain.agents import create_tool_calling_agent, AgentExecutor
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.tools import tool

@tool
def search_web(query: str) -> str:
    """在互联网上搜索信息。当需要获取最新信息时使用。"""
    return f"搜索结果: {query}..."

@tool
def calculate(expression: str) -> str:
    """计算数学表达式。支持基本的四则运算。"""
    return str(eval(expression))

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个有用的助手，可以使用工具帮助用户。"),
    ("placeholder", "{chat_history}"),
    ("user", "{input}"),
    ("placeholder", "{agent_scratchpad}")
])

llm = ChatOpenAI(model="gpt-4o")
agent = create_tool_calling_agent(llm, [search_web, calculate], prompt)
executor = AgentExecutor(agent=agent, tools=[search_web, calculate], verbose=True)

result = executor.invoke({"input": "Python 3.12 发布于哪年？距今多少年？", "chat_history": []})
print(result["output"])


提示： LangChain 团队推荐使用 LangGraph 来构建更复杂的 Agent 工作流。AgentExecutor 适合简单的 ReAct 循环，而 LangGraph 提供了更精细的状态管理和流程控制。






小结
    

  • LangChain 以组合性为核心设计理念，通过 LCEL 管道操作符串联组件构建应用。
    • 

  • Runnable 协议统一了所有组件的接口，支持 invoke、batch、stream 等多种调用方式。
    • 

  • RunnableParallel、RunnablePassthrough 等原语支持并行、路由等复杂编排。
    • 

  • Callbacks 系统提供了链路级别的监控、日志和追踪能力。
    • 

  • AgentExecutor 实现了基础的 ReAct Agent 循环，更复杂的场景建议使用 LangGraph。
