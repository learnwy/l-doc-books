工具与能力 简介

大语言模型本身只能处理文本——它无法读取文件、执行命令或访问互联网。当你在 AI IDE 中看到助手自动搜索代码库、编辑文件、运行测试时，这些能力并非来自模型本身，而是来自围绕模型构建的外部系统。

赋予 AI 编程助手真正行动力的，是工具（Tool）、技能（Skill）和规则（Rule）三大体系。理解这三者如何定义、如何协作、如何在不同产品中落地，是掌握现代 AI 编程工具工作原理的关键所在。

本章第一节介绍工具系统（Tool Systems）。工具是 AI Agent 与外部世界交互的基本单元，从文件读写、终端命令到代码搜索和网页抓取，每一种能力都被抽象为一个可调用的函数。你将了解 Function Calling 的工作机制——模型如何生成结构化的调用请求，执行引擎如何返回结果。你还将认识 MCP（Model Context Protocol）协议的设计理念，理解工具如何被注册、发现和动态加载。此外，工具执行的安全性——权限分级、沙箱隔离、路径约束——也是本节的重要主题。

第二节聚焦技能系统（Skill Systems）。如果说工具是原子操作，那么技能就是将多个工具编排起来完成特定领域任务的可复用方案。技能以 SKILL.md 文件的形式存在，包含名称、描述、适用条件和执行指令等结构化信息。一个好的技能能够将团队的最佳实践沉淀为可重复执行的流程，确保 AI 在不同上下文中都能输出一致且高质量的结果。你将学会如何发现已有技能、编写自定义技能，以及在项目级和全局级之间做出合理选择。

第三节探讨规则系统（Rule Systems）。规则定义了 AI Agent 的行为边界——应该遵守哪些代码风格、使用什么语言、在何种条件下触发特定约束。规则以声明式的方式表达，Agent 在每次生成内容时都会自动遵守已加载的规则。

不同的 AI 编程工具对规则的实现各有差异：Trae 使用 .trae/rules 目录下的 Markdown 文件，Cursor 使用 .cursor/rules，Claude Code 使用项目根目录的 CLAUDE.md，GitHub Copilot 使用 .github/copilot-instructions.md。尽管表达形式不同，核心思想是一致的——用声明式的方式约束 AI 的输出行为。本节将对比这些工具的实现方式，帮助你在不同环境中灵活应用规则机制。

工具提供能力，技能封装经验，规则设定边界。这三个层次并非孤立存在——工具是基础设施，技能是建立在工具之上的领域方案，规则是贯穿始终的行为约束。它们共同构成了 AI 编程助手的能力骨架。

理解这套体系，不仅能帮助你更高效地使用现有 AI 编程工具，还能让你在需要时定制自己的工具集、编写专属技能、设定精确规则。无论你是在使用现成的 AI IDE 提升日常开发效率，还是在构建自己的 Agent 系统探索前沿能力，本章都将为你提供清晰的概念框架和实用的操作指南。
