AutoML 系统

核心概念

AutoML（Automated Machine Learning）是自动化机器学习全流程或部分流程的技术体系。它的目标是降低 ML 开发的门槛和成本，让数据科学家从繁琐的超参调优和架构搜索中解放出来，专注于更高价值的工作——问题定义、数据理解和业务解读。

AutoML 系统的自动化程度和覆盖范围各不相同，从简单的超参数搜索到端到端的全自动 ML 流水线。

超参数优化算法
超参数优化（Hyperparameter Optimization, HPO）是 AutoML 中最成熟的技术领域。核心挑战是在高维超参数空间中用最少的试验次数找到最优配置。


贝叶斯优化是当前最高效的 HPO 策略。它维护一个代理模型（Surrogate Model）来近似超参数到性能指标的映射关系，通过采集函数（Acquisition Function）在"探索"（尝试信息不足的区域）和"利用"（聚焦已知有潜力的区域）之间平衡。TPE（Tree-structured Parzen Estimator）是 Optuna 使用的默认贝叶斯优化算法，它通过建模"好参数"和"差参数"的条件密度来指导搜索。


import optuna

def create_model(trial):
    n_layers = trial.suggest_int("n_layers", 2, 8)
    layers = []
    in_features = 784

    for i in range(n_layers):
        out_features = trial.suggest_int(f"n_units_l{i}", 32, 512, log=True)
        layers.append(torch.nn.Linear(in_features, out_features))
        layers.append(torch.nn.ReLU())

        dropout = trial.suggest_float(f"dropout_l{i}", 0.1, 0.5)
        layers.append(torch.nn.Dropout(dropout))
        in_features = out_features

    layers.append(torch.nn.Linear(in_features, 10))
    return torch.nn.Sequential(*layers)

def objective(trial):
    model = create_model(trial)
    lr = trial.suggest_float("lr", 1e-5, 1e-1, log=True)
    optimizer_name = trial.suggest_categorical("optimizer", ["Adam", "SGD", "AdamW"])
    optimizer = getattr(torch.optim, optimizer_name)(model.parameters(), lr=lr)

    accuracy = train_and_evaluate(model, optimizer, epochs=20)
    return accuracy

study = optuna.create_study(direction="maximize")
study.optimize(objective, n_trials=100, n_jobs=4)
多保真度优化（Multi-Fidelity Optimization）利用低成本的近似评估来加速搜索。Hyperband 算法将计算预算分配为多个 Bracket，每个 Bracket 中启动大量配置但只训练少量 epoch，根据中间结果逐轮淘汰表现差的配置。ASHA（Asynchronous Successive Halving）是 Hyperband 的异步版本，可以在分布式环境中并行运行。


神经架构搜索
神经架构搜索（Neural Architecture Search, NAS）自动设计神经网络结构，是 AutoML 中最具挑战性也最有潜力的方向。NAS 的搜索空间包括层类型（卷积、池化、全连接）、连接方式（跳跃连接、密集连接）、通道数、核大小等。


早期的 NAS（如 NASNet）使用强化学习控制器从搜索空间中采样架构，评估每个架构需要完整训练一次模型，计算成本极高（数千 GPU 天）。后续的高效 NAS 方法大幅降低了搜索成本。


DARTS（Differentiable Architecture Search）将离散的架构搜索转化为连续优化问题。它在搜索空间中为每条候选边分配一个可学习的权重，通过梯度下降同时优化架构权重和模型权重。搜索完成后，保留权重最大的操作形成最终架构。DARTS 只需要单 GPU 几天即可完成搜索。


One-Shot NAS 训练一个包含所有候选架构的超网络（Supernet），搜索时从超网络中采样子网络并评估性能。由于子网络共享超网络的权重，评估不需要重新训练，搜索效率极高。


class SearchSpace:
    OPS = {
        "conv_3x3": lambda C: nn.Conv2d(C, C, 3, padding=1),
        "conv_5x5": lambda C: nn.Conv2d(C, C, 5, padding=2),
        "max_pool": lambda C: nn.MaxPool2d(3, stride=1, padding=1),
        "skip": lambda C: nn.Identity(),
        "none": lambda C: Zero(),
    }

class MixedOp(nn.Module):
    def __init__(self, C):
        super().__init__()
        self.ops = nn.ModuleList([
            SearchSpace.OPS[name](C) for name in SearchSpace.OPS
        ])
        self.weights = nn.Parameter(torch.randn(len(self.ops)))

    def forward(self, x):
        probs = F.softmax(self.weights, dim=0)
        return sum(p * op(x) for p, op in zip(probs, self.ops))

自动特征工程
自动特征工程（Automated Feature Engineering）自动化特征的生成、选择和转换过程。对于结构化数据（表格数据），特征工程通常是决定模型性能的关键因素，好的特征可以让简单模型超越复杂模型。


Featuretools 是开源的自动特征工程库，它通过深度特征合成（Deep Feature Synthesis, DFS）自动从关系型数据中生成特征。DFS 将原始数据中的实体关系和聚合操作组合为多层特征：一阶特征是对原始列的简单变换，二阶特征是通过实体关系进行聚合后再变换，以此类推。


特征选择自动化同样重要。当自动特征工程生成了数百甚至数千个特征后，需要自动筛选出对模型性能有正向贡献的特征子集。常用方法包括基于重要性的选择（如 Random Forest Feature Importance）、基于相关性的过滤（去除高度相关的冗余特征）和包装法（如 Recursive Feature Elimination）。


端到端 AutoML 框架
端到端 AutoML 框架将特征工程、模型选择、超参优化和模型集成统一为一个自动化流水线。用户只需提供数据和目标列，框架自动完成剩余所有工作。


AutoGluon 是 AWS 开源的端到端 AutoML 框架，在表格数据上表现尤为出色。它的核心策略是多模型集成——同时训练多种模型（LightGBM、XGBoost、CatBoost、神经网络、K-近邻等），然后通过多层 Stacking 将它们的预测集成为最终输出。AutoGluon 在多个 Kaggle 竞赛数据集上取得了与人类专家相当的成绩。


from autogluon.tabular import TabularPredictor

predictor = TabularPredictor(
    label="target",
    eval_metric="roc_auc",
    problem_type="binary",

    train_data=train_df,

predictions = predictor.predict(test_df)

H2O AutoML 是另一个成熟的端到端方案，支持表格数据和时序数据。FLAML（Fast and Lightweight AutoML）由微软研究院开发，专注于低计算预算下的高效搜索，适合资源受限的场景。

  • 贝叶斯优化 + Hyperband 是当前最高效的超参搜索策略组合
