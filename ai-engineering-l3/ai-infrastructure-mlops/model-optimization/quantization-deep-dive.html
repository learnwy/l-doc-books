量化深入

核心概念

量化（Quantization）是将模型权重和激活值从高精度浮点数（如 FP32）映射到低比特整数（如 INT8、INT4）的技术。量化的直接效果是减小模型大小（INT8 相比 FP32 缩小 4 倍）和加速推理（整数运算比浮点运算快且能效更高）。在大模型时代，量化已成为将数百亿参数的模型部署到消费级硬件上的必备技术。

量化的核心挑战是如何在降低精度的同时最小化模型性能损失。

对称量化与非对称量化
量化的数学本质是建立浮点数与整数之间的映射关系。对称量化（Symmetric Quantization）假设浮点值域关于零点对称，使用单一缩放因子 s 将浮点值映射到整数：q = round(x / s)，反量化 x̂ = q × s。非对称量化（Asymmetric Quantization）引入零点偏移 z：q = round(x / s) + z，适用于浮点值域不对称的情况（如 ReLU 后的激活值全为正数）。


缩放因子 s 的确定方法直接影响量化精度。Min-Max 方法取权重/激活的最大最小值确定映射范围，简单但对异常值敏感。百分位方法忽略一定比例的异常值（如取 99.9% 分位数），减少异常值对大多数正常值的精度影响。MSE 最优方法通过最小化量化前后的均方误差来搜索最优缩放因子。


import torch

def symmetric_quantize(tensor, num_bits=8):
    qmax = 2 ** (num_bits - 1) - 1
    qmin = -qmax

    abs_max = tensor.abs().max()
    scale = abs_max / qmax

    quantized = torch.clamp(torch.round(tensor / scale), qmin, qmax).to(torch.int8)
    return quantized, scale

def asymmetric_quantize(tensor, num_bits=8):
    qmax = 2 ** num_bits - 1
    qmin = 0

    min_val = tensor.min()
    max_val = tensor.max()
    scale = (max_val - min_val) / (qmax - qmin)
    zero_point = torch.round(-min_val / scale).to(torch.int8)

    quantized = torch.clamp(torch.round(tensor / scale) + zero_point, qmin, qmax)
    return quantized.to(torch.uint8), scale, zero_point
量化粒度是另一个关键设计选择。Per-Tensor 量化整个张量共用一个缩放因子，实现简单但精度较差。Per-Channel 量化每个输出通道有独立的缩放因子，精度更高但需要更多元数据。Per-Group 量化（如 GPTQ 使用的 group_size=128）将每个通道进一步划分为组，每组独立量化，在精度和开销之间取得最佳平衡。


训练后量化技术
训练后量化（Post-Training Quantization, PTQ）不需要重新训练模型，只需要一小批校准数据即可完成量化。PTQ 是最实用的量化方案，因为大模型的重训练成本极高。


GPTQ 是当前大模型 PTQ 的标准方法。它基于最优脑损伤（Optimal Brain Quantization）理论，逐列量化权重矩阵，并利用 Hessian 矩阵的信息来补偿量化误差。GPTQ 可以在数小时内将 175B 模型量化到 INT4 精度，同时保持与 FP16 接近的 Perplexity。


AWQ（Activation-Aware Weight Quantization）是另一种高效的 PTQ 方法。它的核心观察是：权重的重要性不是均匀的，那些乘以大激活值的权重对输出的影响更大。AWQ 通过分析激活值的分布来识别"重要"权重，对重要权重使用更高精度或更精细的缩放，在相同比特数下获得更低的量化误差。


from transformers import AutoModelForCausalLM, AutoTokenizer, GPTQConfig

tokenizer = AutoTokenizer.from_pretrained("meta-llama/Llama-3-8B")

gptq_config = GPTQConfig(
    bits=4,
    group_size=128,
    dataset="c4",
    desc_act=True,
)

model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3-8B",
    quantization_config=gptq_config,
    device_map="auto",
)
SmoothQuant 专门解决激活值量化的难题。Transformer 中某些通道的激活值存在显著的异常值（Outlier），直接量化会导致严重的精度损失。SmoothQuant 通过数学等价变换，将激活值的异常程度"平滑"转移到权重上——权重对异常值更鲁棒，从而使激活值可以安全地使用 INT8 量化。


量化感知训练
量化感知训练（Quantization-Aware Training, QAT）在训练过程中模拟量化效果，让模型学习适应低精度带来的噪声。QAT 的核心机制是在前向传播中插入伪量化（Fake Quantization）操作：先将浮点值量化为整数，再立即反量化回浮点值。这个"量化-反量化"过程引入了量化噪声，反向传播通过直通估计器（Straight-Through Estimator, STE）将梯度直接传过伪量化操作。


QAT 的精度通常优于 PTQ，特别是在极低比特（INT4、INT2）量化时。但 QAT 的计算成本远高于 PTQ——对于大模型，QAT 需要与全量微调相当的计算资源。因此，QLoRA 提出了一种折中方案：使用 4 位量化冻结基础模型权重，只在低秩适配器上进行全精度训练。


import torch.ao.quantization as quant

model.train()
model.qconfig = quant.get_default_qat_qconfig("x86")
model_prepared = quant.prepare_qat(model)

for epoch in range(num_epochs):
    for batch in train_loader:
        loss = model_prepared(batch)
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()

model_quantized = quant.convert(model_prepared)

混合精度与 FP8 量化
混合精度训练（Mixed Precision Training）是在训练过程中同时使用不同精度的数据类型。标准做法是：权重主副本保持 FP32 精度以保证梯度更新的数值稳定性，前向和反向传播使用 FP16/BF16 以加速计算，梯度累积使用 FP32 避免数值溢出。


FP8（8 位浮点）是 NVIDIA H100 GPU 引入的新数据类型，有两种格式：E4M3（4 位指数 + 3 位尾数，更大动态范围）和 E5M2（5 位指数 + 2 位尾数，更高精度）。FP8 结合了整数量化的效率和浮点数的灵活性，可以在训练和推理中同时使用，且无需校准数据。


NVIDIA Transformer Engine 自动管理 FP8 训练中的精度转换和缩放，开发者无需手动处理 FP8 的数值范围问题。在 H100 上使用 FP8 训练相比 BF16 可以获得约 2 倍的吞吐量提升，且模型质量与 BF16 基本一致。


小结
    

  • 量化通过降低数值精度实现模型压缩和推理加速，INT8 是生产部署的标准精度
    • 

  • 量化粒度从 Per-Tensor 到 Per-Group 精度递增，Per-Group 是大模型量化的最佳实践
    • 

  • GPTQ 和 AWQ 是大模型 PTQ 的两大标准方法，可在数小时内完成 4-bit 量化
    • 

  • QAT 精度最佳但成本最高，QLoRA 是大模型场景的实用折中方案
    • 

  • FP8 量化是新一代 GPU 的原生能力，有望统一训练和推理的量化方案
