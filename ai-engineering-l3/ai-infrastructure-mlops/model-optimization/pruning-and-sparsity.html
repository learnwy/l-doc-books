剪枝与稀疏化

核心概念

剪枝（Pruning）是通过移除神经网络中冗余参数来减小模型规模的技术。其理论基础是彩票假设（Lottery Ticket Hypothesis）：在随机初始化的密集网络中，存在一个稀疏子网络（"中奖彩票"），它从相同的初始化点训练后可以达到与密集网络相当的性能。这意味着密集网络中的大量参数是冗余的，可以被安全移除。

剪枝技术的核心区分是结构化与非结构化两种范式，它们在实际加速效果和实现复杂度上有本质差异。

重要性评估方法
剪枝的关键步骤是评估每个参数（或参数组）的重要性，移除最不重要的部分。重要性评估方法分为数据无关和数据依赖两类。


权重幅值（Weight Magnitude）是最简单的数据无关方法——直接以权重的绝对值作为重要性度量。这个看似朴素的方法在实践中效果出奇地好，因为训练过程中不重要的连接往往会被优化为接近零的值。L1 范数剪枝移除绝对值最小的权重，L2 范数剪枝则基于权重向量的欧氏范数。


基于梯度的重要性评估考虑了参数的变化对损失函数的影响。Taylor 展开方法将移除参数 w 对损失的影响近似为 |w × ∂L/∂w|，即权重值与梯度的乘积。这比单纯看权重幅值更准确，因为一个绝对值小但梯度大的参数可能对模型性能很重要。


import torch

def magnitude_pruning(model, sparsity):
    all_weights = []
    for name, param in model.named_parameters():
        if 'weight' in name and param.dim() >= 2:
            all_weights.append(param.abs().flatten())

    all_weights = torch.cat(all_weights)
    threshold = torch.quantile(all_weights, sparsity)

    masks = {}
    for name, param in model.named_parameters():
        if 'weight' in name and param.dim() >= 2:
            masks[name] = (param.abs() >= threshold).float()
            param.data *= masks[name]
    return masks

def taylor_importance(model, dataloader, num_batches=10):
    importance = {}
    for name, param in model.named_parameters():
        importance[name] = torch.zeros_like(param)

    for i, batch in enumerate(dataloader):
        if i >= num_batches:
            break
        loss = model(batch)
        loss.backward()
        for name, param in model.named_parameters():
            importance[name] += (param * param.grad).abs()

    return importance
Fisher 信息矩阵方法利用 Fisher 信息来度量参数重要性。Fisher 信息的对角近似 F_ii = E[(∂L/∂w_i)²] 度量了参数 w_i 在统计意义上的信息量。Fisher 信息大的参数对模型的预测分布影响大，应该被保留。


结构化剪枝
结构化剪枝移除整个结构单元（通道、层、注意力头），剪枝后的模型仍然是密集的，可以直接在通用硬件上加速而无需稀疏运算支持。


通道剪枝（Channel Pruning）移除卷积层或全连接层中不重要的输出通道。一个通道被剪枝后，当前层的对应输出滤波器和下一层的对应输入通道都要同时移除。通道重要性可以用 L1 范数、BN 层的缩放因子（Network Slimming 方法）或 Taylor 展开来评估。


def channel_pruning(model, prune_ratio=0.3):
    for name, module in model.named_modules():
        if isinstance(module, torch.nn.Conv2d):
            weight = module.weight.data
            num_channels = weight.shape[0]
            num_prune = int(num_channels * prune_ratio)

            importance = weight.abs().sum(dim=(1, 2, 3))
            _, indices = importance.sort()
            prune_indices = indices[:num_prune]
            keep_indices = indices[num_prune:]

            module.weight.data = weight[keep_indices]
            if module.bias is not None:
                module.bias.data = module.bias.data[keep_indices]
对于 Transformer 模型，注意力头剪枝（Head Pruning）是最自然的结构化剪枝方式。研究发现，大型 Transformer 中许多注意力头是冗余的——移除一半的注意力头后模型性能只有轻微下降。注意力头的重要性可以通过计算头输出对最终损失的梯度贡献来评估。


层剪枝（Layer Pruning）移除整个 Transformer 层或残差块，这是最粗粒度的结构化剪枝。研究表明，深层 Transformer 的中间层往往具有较高的冗余度，移除 20-30% 的中间层对性能影响有限。


非结构化剪枝与稀疏训练
非结构化剪枝（Unstructured Pruning）在单个权重元素级别操作，可以实现更高的稀疏率（90-99%），因为它可以精确地移除每个不重要的参数。但非结构化稀疏的权重矩阵具有不规则的稀疏模式，通用硬件难以加速，需要专门的稀疏矩阵运算库或硬件支持。


NVIDIA 的 2:4 结构化稀疏（Semi-Structured Sparsity）是一种折中方案。每 4 个连续权重中必须恰好有 2 个为零，这种规则的稀疏模式可以被 A100/H100 GPU 的 Sparse Tensor Core 直接加速，实现接近 2 倍的推理加速。


动态稀疏训练（Dynamic Sparse Training）在训练过程中动态调整哪些参数被保留或剪枝。与传统的"训练→剪枝→微调"三阶段流程不同，动态稀疏训练从一开始就维护一个稀疏网络，并周期性地进行"死亡-再生"操作：移除一些已有的连接，同时激活一些之前被剪枝的连接。RigL 算法通过梯度信息指导连接的再生，使稀疏网络的结构持续优化。


class SparseTrainer:
    def __init__(self, model, initial_sparsity=0.5, final_sparsity=0.9):
        self.model = model
        self.initial_sparsity = initial_sparsity
        self.final_sparsity = final_sparsity
        self.masks = self._init_masks()

    def _compute_sparsity(self, step, total_steps):
        progress = step / total_steps
        return self.final_sparsity + (self.initial_sparsity - self.final_sparsity) * (
            1 - progress
        ) ** 3

    def update_masks(self, step, total_steps):
        target_sparsity = self._compute_sparsity(step, total_steps)
        for name, param in self.model.named_parameters():
            if name in self.masks:
                importance = param.abs()
                threshold = torch.quantile(importance.flatten(), target_sparsity)
                self.masks[name] = (importance >= threshold).float()

    def apply_masks(self):
        for name, param in self.model.named_parameters():
            if name in self.masks:
                param.data *= self.masks[name]

小结
    

  • 剪枝的理论基础是彩票假设——密集网络中存在性能相当的稀疏子网络
    • 

  • 结构化剪枝直接减少模型维度，可在通用硬件上加速，是最实用的剪枝方案
    • 

  • 非结构化剪枝可以达到更高稀疏率，但需要稀疏硬件支持才能真正加速
    • 

  • 2:4 半结构化稀疏是当前工程实践中精度和加速效果的最佳平衡点
    • 

  • 动态稀疏训练通过持续优化稀疏结构，在相同稀疏率下实现更高精度
    •
