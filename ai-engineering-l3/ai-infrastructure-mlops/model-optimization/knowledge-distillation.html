知识蒸馏

核心概念

知识蒸馏（Knowledge Distillation）是将大模型（教师网络）的知识迁移到小模型（学生网络）的训练技术。其核心思想是教师模型的软标签（Soft Labels）——即输出概率分布——包含了比硬标签更丰富的信息，比如类别之间的相似性关系。学生模型通过学习教师的软标签，可以获得超越直接在硬标签上训练的性能。

蒸馏的效果取决于教师与学生之间的"知识差距"。差距过大，学生无法有效学习；差距过小，蒸馏收益有限。

温度缩放与蒸馏损失
Hinton 在 2015 年提出的经典蒸馏框架引入了温度参数 T（Temperature）。标准 Softmax 输出的概率分布通常非常尖锐——最高概率接近 1，其他类别接近 0。提高温度 T 可以使分布更平滑，暴露出类别之间的相对关系（即"暗知识"）。


蒸馏损失是 KL 散度损失和标准交叉熵损失的加权组合。KL 散度度量学生的软标签分布与教师的软标签分布之间的差异，交叉熵损失确保学生在硬标签上也有合理的表现。温度 T 通常设置为 4-20，α（蒸馏损失权重）设置为 0.5-0.9。


import torch
import torch.nn.functional as F

def distillation_loss(student_logits, teacher_logits, labels, T=4.0, alpha=0.7):
    soft_student = F.log_softmax(student_logits / T, dim=-1)
    soft_teacher = F.softmax(teacher_logits / T, dim=-1)

    kd_loss = F.kl_div(soft_student, soft_teacher, reduction="batchmean") * (T * T)

    ce_loss = F.cross_entropy(student_logits, labels)

    return alpha * kd_loss + (1 - alpha) * ce_loss

class DistillationTrainer:
    def __init__(self, teacher, student, T=4.0, alpha=0.7):
        self.teacher = teacher.eval()
        self.student = student
        self.T = T
        self.alpha = alpha

    def train_step(self, batch, labels):
        with torch.no_grad():
            teacher_logits = self.teacher(batch)

        student_logits = self.student(batch)
        loss = distillation_loss(
            student_logits, teacher_logits, labels, self.T, self.alpha
        )
        return loss
温度的选择对蒸馏效果有显著影响。低温度（T=2-4）保留更多教师的置信度信息，适合教师模型置信度本身有意义的场景。高温度（T=10-20）产生更均匀的分布，适合需要学习类别间精细关系的场景。实践中建议以 T=4 为基线，通过小规模实验调优。


特征层蒸馏
经典蒸馏只在输出层匹配教师和学生的概率分布，但教师模型中间层的特征表示同样包含丰富的知识。特征层蒸馏（Feature-Level Distillation）让学生模型的中间特征层也学习教师对应层的表示。


FitNets 是最早的特征层蒸馏方法，它选择教师和学生的中间层建立配对关系，通过 MSE 损失最小化对应层特征的差异。由于教师和学生的中间层维度通常不同，需要在学生侧插入一个投影层（Projector）进行维度对齐。


class FeatureDistillationLoss(torch.nn.Module):
    def __init__(self, teacher_dims, student_dims):
        super().__init__()
        self.projectors = torch.nn.ModuleList([
            torch.nn.Linear(s_dim, t_dim)
            for t_dim, s_dim in zip(teacher_dims, student_dims)
        ])

    def forward(self, teacher_features, student_features):
        total_loss = 0
        for proj, t_feat, s_feat in zip(
            self.projectors, teacher_features, student_features
        ):
            projected = proj(s_feat)
            total_loss += F.mse_loss(projected, t_feat.detach())
        return total_loss
注意力迁移（Attention Transfer）是特征层蒸馏的一个变体，它不直接匹配特征值，而是匹配特征图的注意力图（Attention Map）。注意力图定义为特征图沿通道维度的 L2 范数，它编码了"模型关注输入的哪些空间位置"。相比直接匹配特征值，注意力迁移对教师-学生架构差异更鲁棒。


自蒸馏与在线蒸馏
自蒸馏（Self-Distillation）不需要额外的教师模型，而是利用模型自身的知识来提升性能。最简单的自蒸馏方式是用模型在当前 epoch 的预测作为下一 epoch 的软标签。Born-Again Networks 研究发现，通过多代自蒸馏（Generation 1 → Generation 2 → ...），即使架构完全相同，后代模型的性能也可以持续提升。


在线蒸馏（Online Distillation）让教师和学生同时训练，而非先训练教师再蒸馏学生。Deep Mutual Learning（DML）让两个或多个网络互相学习——每个网络既是教师也是学生。这种方式的优势是不需要预训练大型教师模型，节省了训练时间和计算资源。


对于大模型场景，TinyLLaMA 和 Phi 系列模型展示了有效的 LLM 蒸馏策略。它们不是从单个教师模型蒸馏，而是使用教师模型生成的高质量训练数据来训练小模型。这种"数据蒸馏"方式绕过了传统蒸馏中软标签计算的高昂成本。

多教师与任务特定蒸馏
多教师蒸馏使用多个不同的教师模型同时指导一个学生模型。每个教师可能在不同方面有专长——一个教师擅长理解文本语义，另一个擅长处理数值推理。学生通过融合多个教师的知识，可以获得超越任何单个教师的综合能力。


多教师蒸馏的关键设计选择是教师输出的融合策略：简单平均、加权平均（权重可以是静态的或根据教师在特定样本上的置信度动态调整的）、或注意力机制融合。


class MultiTeacherDistillation:
    def __init__(self, teachers, student, weights=None):
        self.teachers = [t.eval() for t in teachers]
        self.student = student
        self.weights = weights or [1.0 / len(teachers)] * len(teachers)

    def compute_loss(self, batch, labels, T=4.0):
        teacher_logits_list = []
        with torch.no_grad():
            for teacher in self.teachers:
                teacher_logits_list.append(teacher(batch))

        student_logits = self.student(batch)
        soft_student = F.log_softmax(student_logits / T, dim=-1)

        kd_loss = 0
        for w, t_logits in zip(self.weights, teacher_logits_list):
            soft_teacher = F.softmax(t_logits / T, dim=-1)
            kd_loss += w * F.kl_div(soft_student, soft_teacher, reduction="batchmean")

        kd_loss *= T * T
        ce_loss = F.cross_entropy(student_logits, labels)
        return 0.7 * kd_loss + 0.3 * ce_loss
任务特定蒸馏（Task-Specific Distillation）针对特定下游任务定制蒸馏策略。对于序列标注任务，需要在 Token 级别匹配教师和学生的输出分布。对于生成任务，需要使用序列级蒸馏——让学生模型学习教师生成的完整序列，而非只匹配每个位置的概率分布。


小结
    

  • 知识蒸馏的核心是教师模型的软标签包含了"暗知识"——类别之间的相似性关系
    • 

  • 温度参数控制知识迁移的粒度，特征层蒸馏提供了更丰富的中间层知识
    • 

  • 自蒸馏和在线蒸馏消除了对预训练教师的依赖，降低了蒸馏的整体成本
    • 

  • 大模型场景下数据蒸馏是更实用的方案，通过教师生成训练数据间接迁移知识
    • 

  • 多教师蒸馏可以融合不同专长教师的知识，产出能力更全面的学生模型
    •
