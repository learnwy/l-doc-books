混合搜索

核心概念

混合搜索是结合向量搜索（语义搜索）和关键词搜索（词法搜索）的技术，取长补短，提升整体检索质量。

为什么需要混合搜索

向量搜索的问题 关键词搜索的问题
对精确术语匹配不好 不理解语义
"同义"但不同词效果好 "同义"但不同词效果差
可能漏过精确匹配 可能返回字面匹配但语义不相关

混合搜索的优势:

  • 语义 + 词法，双重保障
  • 召回率更高
  • 精度更好
  • 适用场景更广

混合搜索方法

1. 结果重排 (Reranking)

核心思想: 分别做向量搜索和关键词搜索，然后用模型重排。

步骤:


    

  1. 向量搜索返回 top-100
    2. 

  2. 关键词搜索返回 top-100
    3. 

  3. 合并两个列表，去重
    4. 

  4. 用重排模型给每个候选打分
    5. 

  5. 返回分数最高的 top-k
    6. 



常用重排模型:


    

  • Cross-Encoder (如 BGE-Reranker)
    • 

  • Cohere Rerank
    • 

  • OpenAI 也可以用作重排
    • 







优点
缺点





效果通常最好
多一次模型调用




灵活
增加延迟




可以不断优化重排模型
增加成本





适用场景: 追求最佳效果、可以接受稍高的延迟和成本。


2. 倒数融合 (Reciprocal Rank Fusion, RRF)
核心思想: 不训练模型，用排名的倒数加权融合。


公式:


RRF 分数 = Σ (1 / (k + 排名))
通常 k=60。


示例:


候选 A: 向量搜索第 1 名，关键词搜索第 3 名
分数 = 1/(60+1) + 1/(60+3) ≈ 0.0164 + 0.0159 = 0.0323

候选 B: 向量搜索第 5 名，关键词搜索第 1 名
分数 = 1/(60+5) + 1/(60+1) ≈ 0.0154 + 0.0164 = 0.0318

→ 候选 A 排在候选 B 前面




优点
缺点





无需训练
效果比重排稍差




计算快
不够灵活




实现简单
假设两个搜索同等重要





适用场景: 快速实现、没有重排模型、预算有限。


3. 线性插值 (Linear Interpolation)
核心思想: 给向量分数和关键词分数加权相加。


公式:


最终分数 = α * 向量分数 + (1-α) * 关键词分数
α 是权重，0 ≤ α ≤ 1。


调优 α:


    

  • α = 1: 只用向量搜索
    • 

  • α = 0: 只用关键词搜索
    • 

  • α = 0.5: 同等重要
    • 

  • 根据数据调优 α
    • 







优点
缺点





实现简单
需要调优权重




计算快
假设分数可以比较




直观
可能需要归一化分数





适用场景: 简单场景、快速原型。


4. 管道过滤 (Pipeline Filtering)
核心思想: 先用一种搜索过滤，再用另一种搜索。


变体 1: 先关键词过滤，再向量搜索


查询 → 关键词搜索 → 过滤出 top-100 → 在这 100 个中向量搜索 → 返回 top-k
变体 2: 先向量搜索，再关键词重排


查询 → 向量搜索 → 返回 top-100 → 用关键词匹配度重排 → 返回 top-k




优点
缺点





可以优化性能
第一步可能漏过好结果




实现灵活
误差会累积





适用场景: 需要优化性能、其中一种搜索很快。

常见误区
❌ 误区 1：混合搜索总是更好
不一定:


    

  • 如果你的场景向量搜索已经足够好，混合搜索可能不会提升
    • 

  • 反而会增加复杂度和成本
    • 

  • 先测单独的向量搜索效果
    • 



❌ 误区 2：两种搜索同等重要
不一定:


    

  • 有些场景向量搜索更重要
    • 

  • 有些场景关键词搜索更重要
    • 

  • 需要调优权重，不是默认对半分
    • 



❌ 误区 3：只看 top-1 准确率
混合搜索的提升可能在:


    

  • top-5 或 top-10 准确率
    • 

  • 召回率
    • 

  • 整体相关性分布
    • 

  • 不要只看 top-1
    • 



小结
    

  • 结果重排通常效果最好，但成本和延迟高
    • 

  • RRF 简单快速，是好起点
    • 

  • 线性插值直观，需要调优权重
    • 

  • 先测单独的向量搜索效果
    • 

  • 根据效果、成本、延迟权衡
    • 

  • 大多数情况下，混合搜索有提升
    •
