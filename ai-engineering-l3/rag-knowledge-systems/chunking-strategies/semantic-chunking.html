语义分块

核心概念

语义分块（Semantic Chunking）是利用嵌入模型或 NLP 技术，根据文本的语义边界而非固定字符数来分割文档的方法。与机械分块（固定长度、按段落等）相比，语义分块能确保每个文档块在主题上的完整性和连贯性，从而显著提升 RAG 系统的检索质量。

为什么语义分块更优

机械分块的根本问题是：文本的语义边界与物理边界（字符数、段落符号）不一致。一个完整的论点可能跨越两个段落，而一个段落内可能包含两个不同的话题。

语义分块方法详解
方法 1：基于嵌入相似度的分块
这是最常用的语义分块方法。核心思想是：比较相邻句子/段落的嵌入向量相似度，当相似度骤降时在此处分割。


关键步骤详解：


    

  1. 句子分割：用标点符号或 NLP 工具将文档切成句子
    2. 

  2. 窗口分组：用滑动窗口将连续句子组合成片段，避免单句语义不完整
    3. 

  3. 嵌入计算：为每个片段生成嵌入向量
    4. 

  4. 相似度计算：计算相邻片段的余弦相似度
    5. 

  5. 断点检测：相似度低于阈值（或局部最低点）的位置即为分割点
    6. 

  6. 后处理：合并过小的块，拆分过大的块
    7. 



TypeScript 实现
interface SemanticChunk {
  text: string;
  startSentence: number;
  endSentence: number;
  tokenCount: number;
}

interface ChunkingConfig {
  similarityThreshold: number;
  minChunkSize: number;
  maxChunkSize: number;
  windowSize: number;
}

async function semanticChunking(
  sentences: string[],
  embeddings: number[][],
  config: ChunkingConfig,
): Promise<SemanticChunk[]> {
  const similarities: number[] = [];
  for (let i = 0; i < embeddings.length - config.windowSize; i++) {
    const windowA = averageVectors(embeddings.slice(i, i + config.windowSize));
    const windowB = averageVectors(embeddings.slice(i + config.windowSize, i + config.windowSize * 2));
    similarities.push(cosineSimilarity(windowA, windowB));
  }

  const breakpoints: number[] = [];
  for (let i = 0; i < similarities.length; i++) {
    if (similarities[i] < config.similarityThreshold) {
      breakpoints.push(i + config.windowSize);
    }
  }

  const chunks: SemanticChunk[] = [];
  let start = 0;

  for (const bp of breakpoints) {
    const chunkText = sentences.slice(start, bp).join('');
    const tokenCount = estimateTokens(chunkText);

    if (tokenCount >= config.minChunkSize) {
      if (tokenCount > config.maxChunkSize) {
        const subChunks = splitOversizedChunk(sentences.slice(start, bp), config.maxChunkSize);
        chunks.push(...subChunks);
      } else {
        chunks.push({
          text: chunkText,
          startSentence: start,
          endSentence: bp,
          tokenCount,
        });
      }
      start = bp;
    }
  }

  if (start < sentences.length) {
    chunks.push({
      text: sentences.slice(start).join(''),
      startSentence: start,
      endSentence: sentences.length,
      tokenCount: estimateTokens(sentences.slice(start).join('')),
    });
  }

  return chunks;
}

function averageVectors(vectors: number[][]): number[] {
  const dim = vectors[0].length;
  const avg = new Array(dim).fill(0);
  for (const vec of vectors) {
    for (let i = 0; i < dim; i++) {
      avg[i] += vec[i] / vectors.length;
    }
  }
  return avg;
}

function cosineSimilarity(a: number[], b: number[]): number {
  let dot = 0,
    normA = 0,
    normB = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    normA += a[i] * a[i];
    normB += b[i] * b[i];
  }
  return dot / (Math.sqrt(normA) * Math.sqrt(normB));
}
Python 实现
import numpy as np
from sentence_transformers import SentenceTransformer
from dataclasses import dataclass

@dataclass
class SemanticChunk:
    text: str
    start_idx: int
    end_idx: int
    avg_similarity: float

class SemanticChunker:
    def __init__(
        self,
        model_name: str = "BAAI/bge-base-zh-v1.5",
        threshold: float = 0.82,
        window_size: int = 3,
        min_chunk_tokens: int = 100,
        max_chunk_tokens: int = 1000,
    ):
        self.model = SentenceTransformer(model_name)
        self.threshold = threshold
        self.window_size = window_size
        self.min_chunk_tokens = min_chunk_tokens
        self.max_chunk_tokens = max_chunk_tokens

    def chunk(self, sentences: list[str]) -> list[SemanticChunk]:
        embeddings = self.model.encode(sentences, normalize_embeddings=True)

        similarities = self._compute_window_similarities(embeddings)

        breakpoints = self._detect_breakpoints(similarities)

        chunks = self._create_chunks(sentences, breakpoints, similarities)

        return self._post_process(chunks)

    def _compute_window_similarities(
        self, embeddings: np.ndarray
    ) -> np.ndarray:
        n = len(embeddings)
        w = self.window_size
        similarities = np.zeros(n - 1)

        for i in range(n - 1):
            left_start = max(0, i - w + 1)
            left_end = i + 1
            right_start = i + 1
            right_end = min(n, i + 1 + w)

            left_avg = embeddings[left_start:left_end].mean(axis=0)
            right_avg = embeddings[right_start:right_end].mean(axis=0)

            similarities[i] = np.dot(left_avg, right_avg) / (
                np.linalg.norm(left_avg) * np.linalg.norm(right_avg)
            )

        return similarities

    def _detect_breakpoints(self, similarities: np.ndarray) -> list[int]:
        breakpoints = []
        for i in range(len(similarities)):
            if similarities[i] < self.threshold:
                breakpoints.append(i + 1)
        return breakpoints

    def _create_chunks(
        self,
        sentences: list[str],
        breakpoints: list[int],
        similarities: np.ndarray,
    ) -> list[SemanticChunk]:
        chunks = []
        starts = [0] + breakpoints
        ends = breakpoints + [len(sentences)]

        for start, end in zip(starts, ends):
            text = "".join(sentences[start:end])
            if start < end - 1:
                avg_sim = float(similarities[start:end - 1].mean())
            else:
                avg_sim = 1.0
            chunks.append(SemanticChunk(text, start, end, avg_sim))

        return chunks

    def _post_process(self, chunks: list[SemanticChunk]) -> list[SemanticChunk]:
        merged = []
        buffer = None

        for chunk in chunks:
            token_count = len(chunk.text) // 2
            if buffer is not None:
                buffer_tokens = len(buffer.text) // 2
                if buffer_tokens + token_count <= self.max_chunk_tokens:
                    buffer = SemanticChunk(
                        text=buffer.text + chunk.text,
                        start_idx=buffer.start_idx,
                        end_idx=chunk.end_idx,
                        avg_similarity=(buffer.avg_similarity + chunk.avg_similarity) / 2,
                    )
                    continue
                else:
                    merged.append(buffer)
                    buffer = chunk
            elif token_count < self.min_chunk_tokens:
                buffer = chunk
            else:
                merged.append(chunk)

        if buffer is not None:
            merged.append(buffer)

        return merged

方法 3：递归分块（Recursive Chunking）
递归分块按层级分隔符逐步分割文档，是 LangChain 默认使用的策略。它不是纯语义方法，但结合了文档结构信息，效果优于简单的固定长度分块。


分隔符优先级：


    

  1. \n\n（段落）
    2. 

  2. \n（行）
    3. 

  3. 。 / .（句子）
    4. 

  4. ， / ,（子句）
    5. 

  5.  （词）

方法 4：基于 LLM 的智能分块
直接让 LLM 分析文档结构，决定最佳分割点。效果最好但成本最高。


from openai import OpenAI

client = OpenAI()

def llm_based_chunking(document: str, target_chunk_size: int = 800) -> list[str]:
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {
                "role": "system",
                "content": (
                    f"你是一个文档分割专家。将以下文档分割成多个语义完整的块。"
                    f"每个块大约 {target_chunk_size} 字符。"
                    f"在主题变化处分割。不要切断句子。"
                    f"用 '---SPLIT---' 标记分割点。"
                ),
            },
            {"role": "user", "content": document},
        ],
        temperature=0,
    )

    content = response.choices[0].message.content or ""
    chunks = [c.strip() for c in content.split("---SPLIT---") if c.strip()]
    return chunks

相似度阈值的影响
自适应阈值策略
不同文档特征需要不同的阈值。使用统计方法自动确定阈值：


import numpy as np

def adaptive_threshold(
    similarities: np.ndarray,
    method: str = "percentile",
    percentile: int = 25,
) -> float:
    if method == "percentile":
        return float(np.percentile(similarities, percentile))

    if method == "mean_std":
        mean = np.mean(similarities)
        std = np.std(similarities)
        return float(mean - std)

    if method == "gradient":
        gradient = np.abs(np.diff(similarities))
        threshold_idx = np.argmax(gradient > np.percentile(gradient, 75))
        return float(similarities[threshold_idx])

    raise ValueError(f"Unknown method: {method}")

成本优化策略
分层处理策略
这种分层策略可以在保持效果的同时大幅降低计算成本：


    

  • 80% 的文档用递归分块已经足够好
    • 

  • 只对低质量块进行语义分块
    • 

  • 整体成本降低 60-80%
    • 



常见误区
❌ 误区 1：语义分块总是优于机械分块
语义分块不是万能的：


    

  • 结构良好的 Markdown/HTML 文档，按标题层级分块效果就很好
    • 

  • 每句都是独立知识点的 FAQ 文档，按条目分块更合理
    • 

  • 语义分块的计算成本高 10-100 倍，要评估 ROI
    • 



❌ 误区 2：阈值越低越好
阈值太低导致过度分割：


    

  • 每个块只有 1-2 句话，语义信息严重不足
    • 

  • 检索时噪声增加，相关块被大量无关小块淹没
    • 

  • LLM 需要更多块才能获得完整上下文
    • 



❌ 误区 3：所有文档用同一阈值
不同类型的文档内在相似度分布不同：


    

  • 技术文档：主题切换频繁，阈值可以低一些（0.75-0.80）
    • 

  • 叙事性文本：主题连贯，阈值应高一些（0.85-0.90）
    • 

  • 对话记录：话题跳跃大，阈值应中等（0.80-0.85）
    • 

  • 推荐使用自适应阈值策略，根据文档特征动态调整
    • 



❌ 误区 4：忽视块的上下文补充
即使语义分块做得再好，单个块的信息可能仍然不完整。常见的补充策略：


    

  • 父子块关系：保存块的上下文（前后块引用）
    • 

  • 块摘要：为每个块生成摘要，用摘要向量检索，返回完整块
    • 

  • 滑动窗口重叠：分块时保留一定的重叠区域（10-20%）
    • 



小结
语义分块是提升 RAG 检索质量的关键技术，通过理解文本的语义边界来生成主题连贯、大小自适应的文档块。


核心要点回顾：


    

  • 基于嵌入相似度的分块是最通用的方法，推荐作为默认策略
    • 

  • 阈值选择至关重要：0.80-0.85 是通用起点，建议使用自适应策略
    • 

  • 递归分块是性价比最高的"准语义"方法，适合结构清晰的文档
    • 

  • LLM 分块效果最好但成本最高，仅适用于小批量高价值文档
    • 

  • 分层处理策略可以在保持效果的同时大幅降低计算成本
    • 

  • 用下游检索指标（Hit Rate、MRR）而非分块本身的指标来评估最终效果
    • 

  • 分块后记得添加上下文补充机制（重叠、父子关系、摘要）
    •
