Agentic RAG 智能体检索增强生成

核心概念

Agentic RAG（智能体 RAG）是将 RAG 与 AI Agent 结合，让系统可以自主规划、多步推理、使用工具。与传统 RAG 的"检索-生成"固定两步流程不同，Agentic RAG 引入了一个决策循环：Agent 在每一步根据当前信息决定下一步行动——可能是再次检索、调用外部工具、反思已有答案或直接输出结果。

为什么需要 Agentic RAG

普通 RAG 的局限 Agentic RAG 的能力
单步检索 多步检索、动态规划
固定流程 自适应流程
无法使用工具 可以使用多种工具
无法处理复杂任务 可以分解复杂任务

Agentic RAG 的核心能力

1. 任务规划 (Task Planning)

核心思想: 将复杂任务分解成多个步骤。

示例:


任务: "对比 LangChain 和 LlamaIndex 的优缺点，并给出选择建议"

计划:
1. 检索 LangChain 的介绍和特点
2. 检索 LlamaIndex 的介绍和特点
3. 检索两者的对比资料
4. 综合分析，给出建议
2. 工具使用 (Tool Usage)
核心思想: Agent 可以调用各种工具来完成任务。


常见工具:


    

  • 检索工具: 搜索知识库
    • 

  • 网络搜索: 搜索互联网
    • 

  • 计算器: 数学计算
    • 

  • 代码执行: 运行代码
    • 

  • 数据库查询: 查询 SQL
    • 

  • API 调用: 调用外部服务
    • 



示例:


用户: "2023年全球 GDP 是多少？按购买力平价计算。"

Agent 思考:
- 知识库可能没有最新数据
- 需要用网络搜索工具
- 然后用计算器转换（如果需要）

执行:
1. 调用网络搜索: "2023全球 GDP PPP"
2. 从搜索结果提取数据
3. 返回答案
3. 反思与迭代 (Reflection & Iteration)
核心思想: Agent 可以反思自己的答案，不满意就重新来。


反思提示词示例:


请评估你刚才生成的答案：
1. 答案是否准确？
2. 是否有遗漏的信息？
3. 是否需要进一步检索？
4. 是否需要重新组织答案？

如果不满意，请重新生成答案。
收益:


    

  • 更高的答案质量
    • 

  • 自动修复错误
    • 

  • 更全面的信息
    • 



4. 多步检索 (Multi-Hop Retrieval)
核心思想: 第一次检索的结果作为第二次检索的线索。


示例:


查询: "谁发明了 Python 语言？他还发明了什么？"

检索 1: "Python 发明者" → 结果: "Guido van Rossum"
检索 2: "Guido van Rossum 发明" → 结果: "Python, ABC 语言的贡献, ..."
综合: 给出完整答案

    • 

  • 管理状态
    • 

  • 处理终止条件
    • 



2. 任务规划器
职责:


    

  • 理解任务
    • 

  • 制定计划
    • 

  • 调整计划
    • 



3. 工具执行器
职责:


    

  • 选择合适的工具
    • 

  • 调用工具
    • 

  • 解析工具输出
    • 



4. 反思模块
职责:


    

  • 评估当前结果
    • 

  • 决定是否继续
    • 

  • 提供改进建议
    •

什么时候用 Agentic RAG
✅ 适合场景:


    

  • 复杂的多步骤问题
    • 

  • 需要网络搜索等外部工具
    • 

  • 需要深度推理
    • 

  • 研究任务
    • 

  • 探索性查询
    • 



❌ 不适合场景:


    

  • 简单的问答
    • 

  • 性能要求极高（低延迟）
    • 

  • 成本敏感
    • 

  • 可预测的简单任务
    •
