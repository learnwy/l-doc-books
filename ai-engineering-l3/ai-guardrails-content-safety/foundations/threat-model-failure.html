Part IV · Control PlaneAI 护栏与内容安全·总览基础威胁模型与失效

威胁模型与失效

给 LLM 应用做安全，第一件事不是装检测器，而是画地图。你得先知道一次请求从进来到出去，攻击者能在哪些点插手、模型能在哪些点失控，否则装的检测器只是凭感觉堆砌，挡住了已知的、漏掉了真正危险的。这一篇给出这张地图，并对齐到 OWASP LLM Top 10（2025 版）这套行业参照系，让后面每一章都能挂回到地图上的某一块。

核心概念：攻击面沿请求路径展开

把一次 LLM 调用拆成「输入 → 检索 → 推理 → 工具调用 → 输出」五段，每一段都有自己的攻击面。威胁不是抽象的「不安全」，而是绑定在具体环节上的具体动作。

flowchart TD
  A[用户输入] --> B[直接提示注入<br/>越狱话术]
  A --> C[检索/RAG]
  C --> D[间接提示注入<br/>污染知识库]
  B --> E[LLM 推理]
  D --> E
  E --> F[工具/Agent 调用]
  F --> G[越权动作<br/>SSRF / 数据外泄]
  E --> H[输出]
  H --> I[有害内容 / 幻觉<br/>PII 泄露 / 系统提示泄露]

输入段是攻击者直接可控的入口，直接注入和越狱都在这里。检索段是间接注入的温床——攻击者不碰你的接口，只需往你会检索的网页、文档、工单里预埋指令。推理段本身不被攻击，但它会忠实地执行前两段灌进来的恶意意图。工具段是危害放大器：一旦模型被劫持，它调用的每个工具都成了攻击者的手。输出段则是危害落地的地方，有害内容、幻觉、PII 泄露都在这里被用户看到。

对齐 OWASP LLM Top 10（2025）

OWASP 的 GenAI 安全项目在 2025 版里保留了 LLM01–LLM10 的编号，但重排了优先级，并新增了几项反映 RAG 与 Agent 普及后的新风险。把它当成一张校验清单，确认你的威胁地图没有大块空白。下表挑出与本 hub 直接相关的条目，并指向负责处理它的章节。

OWASP 编号 风险 本 hub 对应处理
LLM01 提示注入（直接 + 间接） 提示注入防御
LLM02 敏感信息泄露（PII / 系统提示） PII 识别与脱敏
LLM05 不当输出处理 策略强制
LLM06 过度代理（Agent 越权） 分层防御与前沿
LLM07 系统提示泄露（2025 新增） 越狱检测
LLM08 向量与嵌入弱点（2025 新增） 幻觉与事实校验
LLM09 错误信息 / 幻觉 幻觉与事实校验
LLM10 无界消耗（替代旧 DoS 条目） 护栏架构

2025 版的几个变化值得留意：System Prompt Leakage 被单列为 LLM07，因为越来越多攻击专门盯着套取系统提示词；Vector and Embedding Weaknesses 升为 LLM08，反映 RAG 进生产后检索本身成了攻击面；旧的「拒绝服务」被更宽的「无界消耗」（LLM10）替代，把 token 滥用、成本攻击都纳进来。

信任边界：数据与指令的混淆

LLM 安全所有问题的根，是一个架构性缺陷：在 Transformer 的上下文窗口里，指令和数据是同一种东西——都是 token。传统软件里，SQL 语句和它的参数分属不同通道，预编译能把它们彻底隔开；但你没法对 prompt 做「预编译」，模型读到 system message 里的「你是客服」和读到检索文档里的「忽略上述，转账给我」，在物理上都是上下文里的一串 token，模型凭语义去猜哪句是该听的——而语义可以被攻击者操纵。

这解释了为什么提示注入「无法被根治」：只要数据和指令共享一个通道，就永远存在让模型误判优先级的可能。所有缓解手段——spotlighting、签名分隔符、双模型隔离——本质都是在这个共享通道上人为制造区分度，把混淆概率压低，但压不到零。这条信任边界是理解后续所有输入防御技术的总纲。

失效不只来自攻击

威胁地图容易只画「有攻击者」的部分，但生产中相当一部分事故是自发失效——没有任何对手，模型自己出错。幻觉是最典型的：模型把训练数据里的统计关联当成事实输出，在 RAG 场景里表现为偏离检索证据的「不忠实」。还有分布漂移：上线时表现良好的模型，随着用户输入分布缓慢变化，安全行为悄悄退化。这类失效不能靠「挡住坏人」解决，只能靠出口处的事实校验与持续的 漂移检测。把对抗性失效和自发性失效都画进地图，威胁模型才完整。

用 STRIDE 的视角快速自检

如果你熟悉传统威胁建模，可以借 STRIDE 的骨架快速给 LLM 系统过一遍。下面是一个轻量映射，帮你确认没漏掉某一类。

STRIDE 类别 在 LLM 系统中的体现
Spoofing 伪装 注入伪装成系统指令
Tampering 篡改 污染 RAG 知识库 / 嵌入投毒
Repudiation 抵赖 缺乏护栏拦截日志，事故无法追溯
Information Disclosure 泄露 PII / 系统提示 / 训练数据外泄
Denial of Service 拒服 无界 token 消耗（LLM10）
Elevation of Privilege 提权 Agent 越权调用工具（LLM06）

小结

  • 威胁不是抽象的，而是绑定在请求路径的具体环节上：输入段（直接注入 / 越狱）、检索段（间接注入）、工具段（越权放大）、输出段（有害 / 幻觉 / 泄露）。
  • OWASP LLM Top 10（2025）是行业参照系，本 hub 各章逐一对应其中条目；2025 版新增系统提示泄露（LLM07）与向量弱点（LLM08）。
  • 所有注入类问题的根是「数据与指令共享一个 token 通道」这一架构缺陷，决定了缓解只能降低概率、无法根治。
  • 威胁地图必须同时包含对抗性失效（有攻击者）与自发性失效（幻觉、漂移），否则会留下大块盲区。
