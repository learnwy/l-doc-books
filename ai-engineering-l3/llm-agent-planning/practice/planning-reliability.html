Part II · Agent Construction智能体规划与任务分解实践长程可靠性

长程可靠性

为何需要规划埋下过一个直觉：误差沿步数复利累积，单步 95% 的成功率在二十步后只剩三成多。规划评测又用 pass^k 把这道鸿沟量化了。这一篇把它做成一个可操作的可靠性框架：衰减到底有多快、为什么基准分不能直接换算成生产可靠性、以及有哪些工程手段能把衰减压住。这是把一个能在 demo 里跑通的智能体，变成敢交给真实用户的智能体，最硬的一道关。

核心概念

长程可靠性指智能体在多步、长时任务上稳定达成目标的能力。它的核心敌人是误差复利（error compounding）：每一步都有失败概率，而长任务要求步步不踏空，于是失败概率沿步数累积放大。

最简模型：设各步独立、单步成功率均为 ppp，则 nnn 步任务全程成功的概率为

Psuccess(n)=pnP_{\text{success}}(n) = p^nPsuccess​(n)=pn

这个指数衰减的残酷在于它对 ppp 极其敏感。下表给出几组 ppp 在不同步数下的全程成功率，触目惊心：

单步成功率 ppp 5 步 10 步 20 步 50 步
0.99 95% 90% 82% 61%
0.95 77% 60% 36% 8%
0.90 59% 35% 12% 0.5%
0.80 33% 11% 1% ~0%

读这张表能纠正一个普遍误判：把单步从 90% 提到 95% 看似只是"小改进"，但在 20 步任务上把成功率从 12% 抬到 36%——翻了三倍。可靠性工程的杠杆在单步质量上，是非线性的。

    POW --> DECAY[随步数 n 指数衰减]

基准分不能直接换算成生产可靠性

不存在「基准 90 分必然等于生产 70 分」这样的通用换算。基准分是模型、脚手架、任务分布、资源预算和判定器共同产生的条件结果；换一个工具版本、网站状态或用户表达，成功率就可能变化。

生产落差通常来自三处叠加：(1) 单次平均成功率没有暴露重复运行的一致性；(2) 基准任务往往比真实任务短、边界更清楚；(3) 真实环境有版本漂移、限流、超时、脏数据和权限差异。正确做法不是给基准分乘一个拍脑袋折扣，而是在与生产相同的脚手架上按任务长度、风险和环境噪声分层回放，并同时报告 pass^k、成本、时延与副作用错误率。

METR 的 50%/80% 时间视界提供了一个比平均分更有解释力的长度视角：按人类专家完成任务所需时间分桶，再拟合智能体成功概率随任务难度的变化。它能告诉你可靠性从哪个任务长度开始明显坍塌，但仍受任务域限制，不能从软件工程自动外推到商务流程或开放世界行动。

三条压制衰减的工程杠杆

既然敌人是 pnp^npn，缓解就从这个式子的三个变量下手。

杠杆一：提高单步成功率 ppp。 如上所述收益非线性。手段包括更强的模型、更好的提示、给关键步骤加反思校准。这是最直接但也最受模型能力天花板限制的一条。

杠杆二：减少有效步数 nnn。 步数越少，复利空间越小。任务分解把任务结构化、技能库把多步固化成一个高层动作，都在压 nnn。ReWOO 把工具调用并行化也间接降低了"串行步数"。

杠杆三：打破"各步独立"假设。 pnp^npn 成立的前提是失败不可恢复且各步独立。在每步后插入校验点（checkpoint） 和重试，就把一个会失败的步骤变成"多次机会"，等效单步成功率升到 1−(1−p)r1-(1-p)^r1−(1−p)r（rrr 次重试）。这正是重规划与恢复的用武之地。

下表把三条杠杆与具体技术对应：

杠杆 数学效果 具体技术 主讲篇
提高 ppp 底数变大 反思校准、更强模型、主动校验 反思
减少 nnn 指数变小 分解、技能库、并行化 任务分解、规划与记忆
破独立假设 单步可重试 校验点、重试退避、子目标隔离 重规划与恢复

子目标隔离与幂等：让失败不扩散

第三条杠杆里有两个工程原语值得单独讲，它们决定了失败会不会"扩散"。

子目标隔离（subgoal isolation）：把长任务切成若干独立的检查段，每段完成即固化（持久化中间结果），后续段失败不会污染已完成段。这样重试只需从最近检查点开始，而非从头。它把一个 nnn 步任务的失败半径从"全程"缩到"一段"。

幂等（idempotency）：让动作可安全重复执行而不产生副作用——重试"订票"不会订成两张。没有幂等，重试本身就是新的风险源。对涉及金钱、外发、删除的动作，幂等是重试的前提，否则只能升级到人在回路而不能自动重试。

# 子目标隔离 + 幂等重试的骨架
def run_long_task(subgoals):
    checkpoint = load_checkpoint()          # 从已完成处续跑, 不从头
    for sg in subgoals[checkpoint.idx:]:
        for attempt in range(MAX_RETRY):
            if sg.is_done(checkpoint):      # 幂等检查: 已做过就跳过
                break
            ok = execute_idempotent(sg)     # 幂等执行, 重试安全
            if ok:
                save_checkpoint(sg)         # 固化, 失败不回退此段
                break
        else:
            return escalate(sg)             # 重试耗尽, 升级求助

这套"隔离+幂等+有界重试+超限升级"是 2026 年长程智能体的标准可靠性骨架，也是重规划护栏在可靠性视角下的复述。

小结

  • 长程可靠性的核心敌人是误差复利 P=pnP=p^nP=pn，指数衰减对单步成功率极敏感：把单步 0.90 提到 0.95，20 步任务成功率从 12% 翻到 36%——可靠性杠杆在单步质量上且非线性。
  • 基准分不能直接换算成生产可靠性；应在同脚手架上按任务长度、风险与环境噪声分层回放，报告一致成功、成本、时延和副作用错误。
  • 三条压制衰减的杠杆：提高单步 ppp、减少步数 nnn、打破各步独立假设（校验点+重试把单步变多次机会）。
  • 子目标隔离把失败半径从全程缩到一段，幂等让重试安全；二者加有界重试与超限升级，是 2026 年标准可靠性骨架。
