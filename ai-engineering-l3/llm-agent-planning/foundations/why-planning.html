Part II · Agent Construction智能体规划与任务分解基础为何需要规划

为何需要规划

给 GPT-4o 一道数学题，让它"一步步想"，正确率会显著上升——这是思维链的功劳。但把同一个模型放进一个需要订机票、查日历、比价、确认的真实流程里，让它"一步步做"，事情就没那么乐观了。思维链让模型想得对，却不保证它做得成：想对一道题只需一条正确的推理链，做成一个任务却要在十几个相互依赖的动作里步步不踏空，还要在工具返回意外时及时调整。规划，就是补上"想"与"做"之间这道鸿沟的那套能力。

核心概念

规划（planning）指智能体从一个高层目标出发，推导出一串能够达成该目标的有序行动，并在执行过程中维护、修正这串行动的过程。它至少包含三件事：分解（把"安排一次出差"拆成查航班、订票、加日历等子目标）、排序（先订票才能拿到行程号才能加日历）、适应（航班售罄了就改候选）。

把规划与相邻概念区分清楚很重要。下表对照四个常被混为一谈的术语：

概念 关注点 输出 在本 hub 的归属
推理（reasoning） 单个问题怎么想对 一条推理链/答案 规划的底层燃料
工具调用（tool use） 怎么正确调用一个外部函数 一次合法的函数调用 规划的执行手段
规划（planning） 调哪些工具、按什么顺序、错了怎么办 有序行动序列 + 修正 本 hub 主线
执行（execution） 把单步动作落地 一次环境交互 规划的下游与事实来源

一句话：推理是"想清楚一步"，工具调用是"做成一步"，而规划是"把多步串成能达成目标的整体并在偏航时校正"。

没有规划，长任务为何系统性崩溃

最有说服力的证据来自单次成功与重复一致成功的鸿沟。τ-bench 原始论文用真实领域策略、数据库和 API 模拟航空与零售客服；当时评测的强函数调用智能体整体成功率仍低于 50%，零售域 pass^8 低于 25%（τ-bench, arXiv 2406.12045）。这些是特定论文版本与模型快照的结果，不应改写成永久排行榜；真正可迁移的结论是，同一任务偶尔做对不等于稳定做对。

根因是误差沿步数复利累积。设单步成功率为 ppp，各步独立，则一个 nnn 步任务全程不出错的概率为 pnp^npn。p=0.95p=0.95p=0.95 看似很高，但：

Psuccess(n)=pn,0.9520≈0.36P_{\text{success}}(n) = p^n,\quad 0.95^{20} \approx 0.36Psuccess​(n)=pn,0.9520≈0.36

二十步之后，成功率跌到三成多。这不是模型不够聪明，而是任意"无全局结构、走一步看一步"的执行方式都逃不过的算术。2026 年的一项分析直接以《为什么推理不等于会规划》为题指出：强推理模型在长程决策上依然系统性失误，因为它们缺的是对整体行动结构的把握，而非单步智力（Why Reasoning Fails to Plan, arXiv 2601.22311）。这个 pnp^npn 衰减是贯穿全 hub 的母题，定量框架与缓解手段见长程可靠性。

规划带来的三个杠杆

显式规划之所以能压住上面的崩溃，靠的是三个杠杆。

全局视野替代局部贪心。 走一步看一步的智能体每步都做局部最优选择，容易陷入"为了眼前子目标牺牲整体"的陷阱——比如订了不可退的早班机后才发现会议改到下午。先把整条路径摊开再执行，能提前发现这类冲突。这正是任务分解与 Plan-and-Execute 范式的核心卖点。

错误隔离与可恢复性。 有了显式计划，失败就能被定位到"第几步"，从而局部修补而非从头再来。没有计划结构，一次工具报错往往让整个轨迹失稳。失败检测与局部/全局重规划的策略见重规划与恢复。

可审查性。 一个写出来的计划是人类可读的中间产物，能在执行高风险动作前被审批。对于涉及金钱、删除、外发邮件的场景，这一点是上线的硬门槛，详见人在回路规划。这条也解释了为什么"先出计划再执行"在企业场景越来越成为标配。

规划不是银弹：何时不该重度规划

把所有任务都套上重型规划同样是错的。对单步即可完成的任务（"今天天气怎样"），规划层纯属开销与额外失败点。对环境高度不可预测的任务（开放网页导航），过早把整条路径定死反而不如走一步看一步灵活——这是 ReAct 式交错推理更占优的地形。

判断要不要重度规划，可看三个维度：

维度 倾向轻规划（ReAct） 倾向重规划（分解/搜索）
任务步数 少（< 5 步） 多（长程）
环境可预测性 低、强反馈依赖 高、可提前推演
单步代价/风险 低 高（需提前审查）

这张取舍表是规划范式谱系一篇的预告——那里会把所有范式按"何时规划"和"是否搜索"两轴铺成完整地图。

小结

  • 思维链解决"想得对"，规划解决"多步做得成"，二者不可互相替代。
  • 长程任务的崩溃源于误差复利 pnp^npn：单步 95% 的成功率在二十步后只剩约 36%，这是算术决定的，不是智力问题。
  • τ-bench 原始评测中整体成功率低于 50%、零售域 pass^8 低于 25%，说明单次可用与重复可靠是两种能力。
  • 显式规划提供三个杠杆：全局视野、错误隔离与可恢复、可审查。
  • 规划有适用边界：单步任务和高度不可预测的环境更适合轻量的 ReAct，判据见范式谱系。
