Part II · Agent Construction智能体规划与任务分解自适应反思与自我批评

反思与自我批评

一个智能体把任务搞砸之后，最浪费的做法是原封不动地再试一遍——它会以同样的方式再砸一遍。人类不这样：我们会复盘"刚才哪步错了、下次该怎么改"，把失败转成一条经验。让 LLM 智能体学会这种复盘，就是反思（reflection）。它是自适应闭环里的"诊断"环节——先看清自己错在哪，重规划与恢复才知道该改什么。

核心概念

反思指智能体审视自己的行为轨迹（thought-action-observation 序列）或最终结果，生成一段关于"哪里做得不好、如何改进"的自然语言批评，并把这段批评注入下一次尝试的上下文。它与思维树里的节点评估有别：评估是给候选打分以指导搜索，反思是对已发生轨迹的事后诊断以指导重试。

反思有几个关键设计维度：

  • 触发时机：每步反思（细粒度、贵）还是任务结束才反思（粗粒度、省）。
  • 反馈来源：纯自评（模型自己判断对错）还是外部信号（单元测试、环境奖励、人类反馈）接地。
  • 记忆跨度：反思只用于当次重试，还是沉淀进长期规划与记忆供未来复用。
flowchart TD
    A[执行轨迹<br/>thought-action-obs] --> R[反思器<br/>诊断哪步错了]
    F[反馈信号<br/>测试/奖励/人类] --> R
    R --> C[语言化批评<br/>下次应先校验输入再调用]
    C --> M[写入短期/长期记忆]
    M --> Retry[带批评的下一次尝试]
    Retry --> A

Reflexion：把失败语言化为可复用经验

反思范式的奠基工作是 Reflexion。它的洞见是：与其用梯度更新模型权重（昂贵且需训练），不如把失败教训写成自然语言存进记忆，下次尝试时连同任务一起喂回去——相当于用"语言反馈"替代"参数反馈"做在线学习。

一个 Reflexion 循环是这样的：智能体执行任务 → 得到一个评估信号（成功/失败，可来自环境或自评）→ 若失败，反思器生成一段"为什么失败、下次怎么改"的文字 → 这段文字存入情景记忆 → 下次尝试带着它重来。下表对比反思与传统微调这两条"从失败学习"的路：

维度 Reflexion 语言反馈 微调参数反馈
更新对象 上下文中的文字记忆 模型权重
成本 一次推理 训练流程
生效速度 即时（下次尝试） 需重训+部署
可解释性 高（人能读批评） 低
持久性 随上下文/记忆存续 永久入权重

正因为成本极低、即时生效，反思成了 2026 年几乎所有严肃智能体的标配组件。但它有个硬前提下一节就要讲。

自评的可靠性陷阱

反思的致命弱点是：当反馈完全来自模型自评时，模型可能"自信地错"——它既没发现自己错了，反思也就无从谈起，甚至可能把对的改成错的。这与思维树评估函数不可靠是同一类困难：一个不可靠的自我评判者，既毁搜索也毁反思。

缓解的核心思路是给反思接地（grounding）——让批评建立在可验证的外部信号上，而非纯凭模型直觉：

反馈来源 可靠性 适用场景
纯自评 低，易自信地错 无外部信号的开放任务（兜底）
单元测试/编译器 高，客观 代码生成（最理想）
环境奖励 中-高 有明确成败信号的任务（游戏、表单）
人类反馈 高，但贵 高风险、需人在回路的场景

经验法则：有客观信号（测试、奖励）就优先用，纯自评只当兜底。代码智能体之所以是反思的最佳试验场，正因为它天然带"单元测试"这个免费、可靠的接地信号。

ReflAct：从"事后反思"到"持续状态对齐"

2025 年的 ReflAct 把反思从"任务做完才复盘"推进到"每一步都校准"。它针对的是ReAct 交错推理的老毛病——朴素 ReAct 的 Thought 常常脱离真实世界状态在空谈。ReflAct 让模型在每一步都显式反思"我当前对世界的信念是否还与目标对齐"，把推理持续锚定在状态空间上，从而同时提升效率与可靠性（ReflAct, arXiv 2505.15182）。

这与规划问题形式化里 POMDP 的"信念状态"概念严丝合缝：ReflAct 本质是在显式维护并修正信念 b(s)b(s)b(s)。下表把三代反思放在时间轴上看：

方法 反思粒度 接地方式 解决的痛点
Reflexion 任务结束 评估信号/自评 重复犯同样的错
每步自评 ReAct 每步 自评 局部漂移
ReflAct 每步 信念—目标对齐 Thought 脱离世界状态

趋势很清楚：反思正从"低频粗粒度的事后诊断"走向"高频细粒度的持续状态校准"，代价是更多 LLM 调用，收益是长链上更不容易跑偏。

小结

  • 反思是自适应闭环的"诊断"环节：审视轨迹/结果，生成语言化批评，注入下次尝试；区别于思维树评估（指导搜索）的事后诊断（指导重试）。
  • Reflexion 用"语言反馈"替代"参数反馈"，成本低、即时生效，是 2026 年智能体标配。
  • 自评不可靠是核心陷阱——模型会自信地错；缓解靠接地：测试/编译器最可靠，环境奖励次之，纯自评仅作兜底，代码智能体是最佳试验场。
  • ReflAct 把反思从事后复盘推进到每步信念—目标对齐，与 POMDP 信念状态对应，缓解 ReAct 的 Thought 脱离世界状态问题。
  • 趋势：反思从低频事后诊断走向高频持续校准。
