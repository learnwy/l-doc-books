Prompt 基础原理 简介

Prompt Engineering 是一门新兴的技能，但要真正掌握它，必须先理解底层的基础原理。本章从概念定义出发，逐层深入到模型机制和 Prompt 结构，为后续的技巧学习和高级模式打下坚实的认知地基。

第一节"什么是 Prompt Engineering"定义了这一领域的核心概念。你将了解 Prompt Engineering 的本质——它不是简单的"提问技巧"，而是一种新的人机交互范式。这一节梳理了从普通用户到 Prompt 工程师再到系统架构师的技能光谱，并通过客服、代码生成、内容创作等真实场景展示 Prompt Engineering 的实际影响力。

第二节"LLM 如何处理 Prompt"揭开大语言模型处理输入的黑盒。你将理解 Tokenization 如何将文字转化为模型可处理的数字序列、注意力机制如何捕捉词与词之间的关系、Next-Token Prediction 如何驱动文本生成，以及 Temperature 和采样策略如何影响输出的确定性与创造性。这些知识直接决定了你设计 Prompt 时的决策依据。

第三节"Token 与上下文窗口"聚焦于 LLM 最核心的资源约束。Token 是 LLM 的"计费单位"和"记忆单位"，理解 Token 的计数规则、中英文差异、主流模型的上下文窗口大小，以及"迷失在中间"等注意力退化现象，将帮助你在有限的资源内最大化 Prompt 的效果。

第四节"Prompt 解剖学"将 Prompt 拆解为可操作的结构组件。你将掌握指令、上下文、输入、输出格式、示例这五大核心组件的作用与组合方式，学习 CRISPE 和 RISEN 等结构化框架，并识别常见的结构性反模式。这一节是从"凭感觉写 Prompt"到"系统化设计 Prompt"的关键转折点。

四个主题层层递进：先明确是什么，再理解为什么，然后掌握核心约束，最后学会如何组织。完成本章后，你将具备扎实的理论基础，能够带着原理性理解去学习后续章节中的核心技巧、系统提示设计和高级模式。
