短期记忆

什么是短期记忆

短期记忆（Short-Term Memory）是 Agent 在单次会话中维护的临时信息存储。它包括对话历史缓冲区、工作记忆（当前任务状态）和临时草稿本（中间推理结果）。短期记忆使 Agent 能够在多轮对话中保持连贯性，理解上下文中的指代关系和隐含意图。



三种缓冲策略
短期记忆的核心挑战在于：对话历史会不断增长，但上下文窗口是有限的。需要选择合适的策略来管理缓冲区。






策略
原理
优点
缺点
适用场景





全量缓冲
保留所有消息
信息无损
会超出上下文窗口
短对话、小窗口模型




滑动窗口
仅保留最近 N 轮消息
实现简单、内存可控
丢失早期重要信息
中等长度对话




Token 截断
按 Token 上限从最近消息向前保留
精确控制上下文用量
需要 Token 计数器
长对话、Token 敏感







核心类型定义
import type { CoreMessage } from 'ai';

type BufferStrategy = 'full' | 'sliding-window' | 'token-based';

interface ShortTermMemoryConfig {
  strategy: BufferStrategy;
  maxMessages?: number;
  maxTokens?: number;
  estimateTokens?: (message: CoreMessage) => number;
}


ShortTermMemory 实现
import type { CoreMessage } from 'ai';

class ShortTermMemory {
  private messages: CoreMessage[] = [];
  private workingMemory: Map<string, string> = new Map();
  private scratchpad: string[] = [];
  private config: ShortTermMemoryConfig;

  constructor(config: ShortTermMemoryConfig) {
    this.config = config;
  }

  append(message: CoreMessage): void {
    this.messages.push(message);
  }

  getMessages(): CoreMessage[] {
    switch (this.config.strategy) {
      case 'full':
        return this.fullBuffer();
      case 'sliding-window':
        return this.slidingWindow();
      case 'token-based':
        return this.tokenBased();
    }
  }

  private fullBuffer(): CoreMessage[] {
    return [...this.messages];
  }

  private slidingWindow(): CoreMessage[] {
    const max = this.config.maxMessages ?? 20;
    if (this.messages.length <= max) {
      return [...this.messages];
    }
    const system = this.messages.filter((m) => m.role === 'system');
    const nonSystem = this.messages.filter((m) => m.role !== 'system');
    return [...system, ...nonSystem.slice(-max)];
  }

  private tokenBased(): CoreMessage[] {
    const maxTokens = this.config.maxTokens ?? 4096;
    const estimate = this.config.estimateTokens ?? defaultEstimateTokens;

    const system = this.messages.filter((m) => m.role === 'system');
    const nonSystem = this.messages.filter((m) => m.role !== 'system');

    let usedTokens = system.reduce((sum, m) => sum + estimate(m), 0);
    const selected: CoreMessage[] = [];

    for (let i = nonSystem.length - 1; i >= 0; i--) {
      const tokens = estimate(nonSystem[i]);
      if (usedTokens + tokens > maxTokens) break;
      selected.unshift(nonSystem[i]);
      usedTokens += tokens;
    }

    return [...system, ...selected];
  }

  setWorkingMemory(key: string, value: string): void {
    this.workingMemory.set(key, value);
  }

  getWorkingMemory(key: string): string | undefined {
    return this.workingMemory.get(key);
  }

  appendToScratchpad(note: string): void {
    this.scratchpad.push(note);
  }

  getScratchpadContent(): string {
    return this.scratchpad.join('\n');
  }

  getContextSnapshot(): CoreMessage[] {
    const messages = this.getMessages();

    const extras: string[] = [];
    if (this.workingMemory.size > 0) {
      const entries = [...this.workingMemory.entries()].map(([k, v]) => `${k}: ${v}`).join('\n');
      extras.push(`当前任务状态:\n${entries}`);
    }
    if (this.scratchpad.length > 0) {
      extras.push(`推理草稿:\n${this.getScratchpadContent()}`);
    }

    if (extras.length > 0) {
      return [{ role: 'system' as const, content: extras.join('\n\n') }, ...messages];
    }
    return messages;
  }

  clear(): void {
    this.messages = [];
    this.workingMemory.clear();
    this.scratchpad = [];
  }
}

function defaultEstimateTokens(message: CoreMessage): number {
  const content = typeof message.content === 'string' ? message.content : JSON.stringify(message.content);
  return Math.ceil(content.length / 4);
}


在 Agent 中集成
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const memory = new ShortTermMemory({
  strategy: 'token-based',
  maxTokens: 8000,
});

async function chat(userInput: string): Promise<string> {
  memory.append({ role: 'user', content: userInput });

  const messages = memory.getContextSnapshot();

  const result = await generateText({
    model: openai('gpt-4o'),
    messages,
  });

  memory.append({ role: 'assistant', content: result.text });

  return result.text;
}

工作记忆与草稿本
对话缓冲区之外，短期记忆还包含两个重要组件：


工作记忆用于跟踪当前任务的关键状态。当 Agent 执行多步骤任务时，需要记住已完成的步骤、待执行的操作和中间变量：


memory.setWorkingMemory('currentTask', '重构 UserService');
memory.setWorkingMemory('completedSteps', '1. 提取接口 2. 分离数据层');
memory.setWorkingMemory('nextStep', '3. 编写单元测试');
草稿本用于存储中间推理结果。Agent 在分析问题时可以将思考过程记录到草稿本，供后续步骤参考：


memory.appendToScratchpad('用户代码中发现 3 处类型错误');
memory.appendToScratchpad('错误集中在 UserService.ts 的第 45-67 行');
memory.appendToScratchpad('根因是 User 接口缺少 email 字段');


小结
    

  • 短期记忆是 Agent 在单次会话中维护连贯性的基础设施，包括对话缓冲区、工作记忆和草稿本。
    • 

  • 三种缓冲策略各有适用场景：全量缓冲适合短对话，滑动窗口平衡信息量和成本，Token 截断提供精确控制。
    • 

  • ShortTermMemory 类封装了策略选择逻辑，通过配置切换不同的缓冲行为。
    • 

  • 工作记忆跟踪多步骤任务的中间状态，草稿本记录推理过程中的关键发现。
    • 

  • 所有 system 消息始终保留，确保 Agent 身份和规则不会因截断而丢失。
    • 

  • 短期记忆是上下文工程中最基础的组件，为长期记忆和摘要压缩提供输入。
    •
