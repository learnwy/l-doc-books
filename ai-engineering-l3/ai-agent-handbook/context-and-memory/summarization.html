摘要与压缩

为什么需要摘要

当对话持续增长，直接截断会丢失关键信息，而全量保留会超出上下文窗口。摘要与压缩技术提供了第三条路径：用更少的 Token 保留更多的语义信息。通过自动摘要，Agent 可以将冗长的对话历史压缩为精炼的概述，在有限的上下文空间内最大化信息密度。

滚动摘要
滚动摘要是最实用的压缩策略。当对话超过阈值时，将早期消息压缩为一段摘要，然后用摘要替代原始消息继续对话：




Summarizer 实现
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';
import type { CoreMessage } from 'ai';

interface SummarizerConfig {
  model?: Parameters<typeof openai>[0];
  threshold: number;
  keepRecent: number;
}

class Summarizer {
  private config: SummarizerConfig;
  private currentSummary: string | null = null;

  constructor(config: SummarizerConfig) {
    this.config = config;
  }

  async process(messages: CoreMessage[]): Promise<CoreMessage[]> {
    const nonSystem = messages.filter((m) => m.role !== 'system');
    const system = messages.filter((m) => m.role === 'system');

    if (nonSystem.length <= this.config.threshold) {
      return messages;
    }

    const toSummarize = nonSystem.slice(0, -this.config.keepRecent);
    const toKeep = nonSystem.slice(-this.config.keepRecent);

    this.currentSummary = await this.rollingSummary(toSummarize);

    return [...system, { role: 'system' as const, content: `对话摘要:\n${this.currentSummary}` }, ...toKeep];
  }

  private async rollingSummary(messages: CoreMessage[]): Promise<string> {
    const conversation = messages
      .map((m) => `${m.role}: ${typeof m.content === 'string' ? m.content : JSON.stringify(m.content)}`)
      .join('\n');

    const prompt = this.currentSummary
      ? `已有摘要:\n${this.currentSummary}\n\n新的对话内容:\n${conversation}\n\n请将已有摘要与新对话合并，生成更新后的摘要。保留关键决策、事实和用户偏好。`
      : `请总结以下对话的关键信息。保留重要决策、事实、用户偏好和任务进展。\n\n${conversation}`;

    const result = await generateText({
      model: openai(this.config.model ?? 'gpt-4o-mini'),
      system: '你是一个对话摘要助手。生成简洁、信息密集的摘要，保留关键上下文。',
      prompt,
    });

    return result.text;
  }

  getSummary(): string | null {
    return this.currentSummary;
  }
}


Map-Reduce 摘要
当历史记录极长时，单次摘要可能超出模型输入限制。Map-Reduce 策略先将历史分段摘要（Map），再将多段摘要合并为一个总摘要（Reduce）：


class MapReduceSummarizer {
  private chunkSize: number;

  constructor(chunkSize: number = 10) {
    this.chunkSize = chunkSize;
  }

  async summarize(messages: CoreMessage[]): Promise<string> {
    const chunks = this.splitIntoChunks(messages);
    const chunkSummaries = await this.mapPhase(chunks);
    const finalSummary = await this.reducePhase(chunkSummaries);
    return finalSummary;
  }

  private splitIntoChunks(messages: CoreMessage[]): CoreMessage[][] {
    const chunks: CoreMessage[][] = [];
    for (let i = 0; i < messages.length; i += this.chunkSize) {
      chunks.push(messages.slice(i, i + this.chunkSize));
    }
    return chunks;
  }

  private async mapPhase(chunks: CoreMessage[][]): Promise<string[]> {
    const summaries: string[] = [];
    for (const chunk of chunks) {
      const conversation = chunk
        .map((m) => `${m.role}: ${typeof m.content === 'string' ? m.content : JSON.stringify(m.content)}`)
        .join('\n');

      const result = await generateText({
        model: openai('gpt-4o-mini'),
        prompt: `总结以下对话片段的要点:\n\n${conversation}`,
      });
      summaries.push(result.text);
    }
    return summaries;
  }

  private async reducePhase(summaries: string[]): Promise<string> {
    const combined = summaries.map((s, i) => `片段 ${i + 1}:\n${s}`).join('\n\n');

    const result = await generateText({
      model: openai('gpt-4o-mini'),
      prompt: `将以下多个对话片段的摘要合并为一个连贯的总摘要:\n\n${combined}`,
    });

    return result.text;
  }
}


实体提取
实体提取将对话压缩为结构化的键值信息，以极高压缩比保留核心事实：


import { generateObject } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const entitySchema = z.object({
  entities: z.array(
    z.object({
      name: z.string().describe('实体名称'),
      type: z.enum(['person', 'project', 'technology', 'preference', 'decision']),
      attributes: z.record(z.string()).describe('实体属性'),
    }),
  ),
});

async function extractEntities(messages: CoreMessage[]) {
  const conversation = messages
    .map((m) => `${m.role}: ${typeof m.content === 'string' ? m.content : JSON.stringify(m.content)}`)
    .join('\n');

  const { object } = await generateObject({
    model: openai('gpt-4o-mini'),
    schema: entitySchema,
    prompt: `从以下对话中提取关键实体及其属性:\n\n${conversation}`,
  });

  return object.entities;
}

在 Agent 中集成摘要
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const summarizer = new Summarizer({
  threshold: 20,
  keepRecent: 10,
  model: 'gpt-4o-mini',
});

async function chatWithSummarization(
  messages: CoreMessage[],
  userInput: string,
): Promise<{ reply: string; messages: CoreMessage[] }> {
  messages.push({ role: 'user', content: userInput });

  const compressed = await summarizer.process(messages);

  const result = await generateText({
    model: openai('gpt-4o'),
    messages: compressed,
  });

  compressed.push({ role: 'assistant', content: result.text });

  return { reply: result.text, messages: compressed };
}


小结
    

  • 摘要与压缩是解决上下文窗口有限性的关键技术，在截断和全量保留之间提供了高信息密度的折中方案。
    • 

  • 四种核心策略各有侧重：滚动摘要适合持续对话，Map-Reduce 处理超长历史，实体提取生成结构化知识，对话蒸馏保留决策链。
    • 

  • Summarizer 类通过 AI SDK 6 的 generateText 实现自动摘要，支持增量更新（滚动模式）。
    • 

  • 是否摘要取决于信息价值和成本平衡——闲聊直接截断，关键决策链则值得付出摘要成本。
    • 

  • 实体提取配合 generateObject 可将对话压缩为结构化数据，适合写入长期记忆。
    • 

  • 在生产环境中建议使用轻量模型（如 gpt-4o-mini）执行摘要任务，降低延迟和成本。
    •
