长期记忆与向量存储

什么是长期记忆

长期记忆（Long-Term Memory）是 Agent 跨会话持久化信息的能力。短期记忆在会话结束后消失，而长期记忆通过文本嵌入（Embedding）和向量数据库将信息持久化存储，并在后续会话中通过语义搜索检索相关内容。这使 Agent 能够"记住"用户偏好、历史决策和领域知识。



文本嵌入原理
文本嵌入将自然语言转换为高维向量，语义相似的文本在向量空间中距离更近。Agent 利用这一特性实现语义级别的记忆检索，而非关键词匹配。

const { embeddings } = await embedMany({

相似度计算
向量检索的核心是计算查询向量与存储向量之间的相似度。余弦相似度是最常用的度量方式：


function cosineSimilarity(a: number[], b: number[]): number {
  let dotProduct = 0;
  let normA = 0;
  let normB = 0;

  for (let i = 0; i < a.length; i++) {
    dotProduct += a[i] * b[i];
    normA += a[i] * a[i];
    normB += b[i] * b[i];
  }

  return dotProduct / (Math.sqrt(normA) * Math.sqrt(normB));
}


LongTermMemory 实现
import { embed } from 'ai';
import { openai } from '@ai-sdk/openai';

interface MemoryEntry {
  id: string;
  content: string;
  embedding: number[];
  metadata: Record<string, string>;
  createdAt: Date;
}

interface SearchResult {
  entry: MemoryEntry;
  score: number;
}

class LongTermMemory {
  private entries: MemoryEntry[] = [];
  private embeddingModel = openai.embedding('text-embedding-3-small');

  async add(content: string, metadata: Record<string, string> = {}): Promise<string> {
    const { embedding } = await embed({
      model: this.embeddingModel,
      value: content,
    });

    const entry: MemoryEntry = {
      id: crypto.randomUUID(),
      content,
      embedding,
      metadata,
      createdAt: new Date(),
    };

    this.entries.push(entry);
    return entry.id;
  }

  async search(query: string, topK: number = 5): Promise<SearchResult[]> {
    const { embedding: queryEmbedding } = await embed({
      model: this.embeddingModel,
      value: query,
    });

    const scored = this.entries.map((entry) => ({
      entry,
      score: cosineSimilarity(queryEmbedding, entry.embedding),
    }));

    return scored
      .sort((a, b) => b.score - a.score)
      .slice(0, topK)
      .filter((r) => r.score > 0.7);
  }

  async addMany(items: { content: string; metadata?: Record<string, string> }[]): Promise<string[]> {
    const ids: string[] = [];
    for (const item of items) {
      const id = await this.add(item.content, item.metadata ?? {});
      ids.push(id);
    }
    return ids;
  }

  remove(id: string): boolean {
    const index = this.entries.findIndex((e) => e.id === id);
    if (index === -1) return false;
    this.entries.splice(index, 1);
    return true;
  }

  getStats(): { totalEntries: number; oldestEntry: Date | null } {
    return {
      totalEntries: this.entries.length,
      oldestEntry: this.entries.length > 0 ? this.entries[0].createdAt : null,
    };
  }
}


文件持久化扩展
内存存储在进程重启后丢失。通过文件持久化将向量数据保存到磁盘：


import { readFile, writeFile } from 'node:fs/promises';

class PersistentLongTermMemory extends LongTermMemory {
  private filePath: string;

  constructor(filePath: string) {
    super();
    this.filePath = filePath;
  }

  async load(): Promise<void> {
    try {
      const data = await readFile(this.filePath, 'utf-8');
      const parsed = JSON.parse(data) as MemoryEntry[];
      for (const entry of parsed) {
        entry.createdAt = new Date(entry.createdAt);
      }
      this.entries = parsed;
    } catch {
      this.entries = [];
    }
  }

  async save(): Promise<void> {
    await writeFile(this.filePath, JSON.stringify(this.entries, null, 2));
  }

  async add(content: string, metadata: Record<string, string> = {}): Promise<string> {
    const id = await super.add(content, metadata);
    await this.save();
    return id;
  }
}


检索增强生成（RAG）流水线
长期记忆最典型的应用场景是检索增强生成（RAG），将检索到的记忆作为上下文注入给 LLM：


import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

async function ragChat(userMessage: string, memory: LongTermMemory): Promise<string> {
  const results = await memory.search(userMessage, 3);

  const context = results.map((r) => r.entry.content).join('\n---\n');

  const messages = [
    {
      role: 'system' as const,
      content: context ? `参考以下相关信息:\n${context}` : '没有找到相关的历史记忆。',
    },
    { role: 'user' as const, content: userMessage },
  ];

  const result = await generateText({
    model: openai('gpt-4o'),
    messages,
  });

  return result.text;
}


小结
    

  • 长期记忆通过文本嵌入和向量存储实现跨会话的信息持久化与语义检索。
    • 

  • AI SDK 6 的 embed 和 embedMany API 简化了嵌入生成流程。
    • 

  • 向量存储方案从内存到云服务有多种选择，根据规模和部署需求灵活切换。
    • 

  • 余弦相似度是语义搜索的核心度量，相似度阈值过滤确保检索结果的质量。
    • 

  • LongTermMemory 类封装了嵌入、存储和检索的完整逻辑，可扩展为文件持久化或对接外部数据库。
    • 

  • RAG 流水线将检索到的记忆注入上下文，使 Agent 能基于历史知识生成更精准的回复。
