结构化输出

为什么需要结构化输出

LLM 默认以自然语言形式输出文本，但在实际应用中，我们通常需要将模型输出解析为程序可处理的数据结构。手动解析自由文本既脆弱又容易出错。结构化输出让模型直接生成符合预定义 Schema 的 JSON 对象，确保输出结果类型安全、格式可靠。



JSON Mode vs Structured Output Mode
模型提供两种结构化输出模式，它们在约束强度上有本质区别：






维度
JSON Mode
Structured Output Mode





格式保证
保证输出合法 JSON
保证输出符合指定 Schema




Schema 约束
无，模型自由决定结构
严格遵循提供的 JSON Schema




字段完整性
不保证包含所有必需字段
保证包含所有 required 字段




类型安全
不保证字段类型正确
保证字段类型与 Schema 一致




适用场景
简单的键值对提取
复杂对象生成、API 响应构建





在 AI SDK 6 中，generateObject 默认使用 Structured Output Mode，配合 Zod Schema 实现端到端类型安全。




Zod Schema 定义
Zod 是 AI SDK 6 的默认 Schema 定义方案。它同时提供 TypeScript 类型推断和运行时验证能力，一套定义同时用于类型检查和模型约束：


import { z } from 'zod';

const WeatherResponseSchema = z.object({
  city: z.string().describe('查询的城市名称'),
  temperature: z.number().describe('当前温度'),
  unit: z.enum(['celsius', 'fahrenheit']).describe('温度单位'),
  condition: z.enum(['sunny', 'cloudy', 'rainy', 'snowy']).describe('天气状况'),
  humidity: z.number().min(0).max(100).describe('湿度百分比'),
  forecast: z
    .array(
      z.object({
        date: z.string().describe('日期，YYYY-MM-DD 格式'),
        high: z.number().describe('最高温度'),
        low: z.number().describe('最低温度'),
        condition: z.string().describe('天气状况'),
      }),
    )
    .describe('未来几天的天气预报'),
});

type WeatherResponse = z.infer<typeof WeatherResponseSchema>;
Zod 的 .describe() 方法会被 AI SDK 转换为 JSON Schema 的 description 字段，帮助模型理解每个字段的含义。

generateObject 基本用法
generateObject 是 AI SDK 6 提供的结构化输出核心函数，直接返回类型安全的对象：


import { generateObject } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const BookReviewSchema = z.object({
  title: z.string().describe('书名'),
  author: z.string().describe('作者'),
  rating: z.number().min(1).max(5).describe('评分，1-5 分'),
  summary: z.string().describe('一句话摘要'),
  pros: z.array(z.string()).describe('优点列表'),
  cons: z.array(z.string()).describe('缺点列表'),
  recommendTo: z.enum(['beginner', 'intermediate', 'advanced']).describe('推荐人群'),
});

const { object } = await generateObject({
  model: openai('gpt-4o'),
  schema: BookReviewSchema,
  prompt: '请为《Designing Data-Intensive Applications》写一篇书评',
});

console.log(object.title);
console.log(object.rating);
console.log(object.pros);
返回的 object 具有完整的 TypeScript 类型推断，IDE 可以提供自动补全和类型检查。




在 Hono API 中使用
将结构化输出集成到 Hono 后端，构建类型安全的 API 端点：


import { Hono } from 'hono';
import { generateObject } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const app = new Hono();

const TaskExtractionSchema = z.object({
  tasks: z
    .array(
      z.object({
        title: z.string().describe('任务标题'),
        priority: z.enum(['high', 'medium', 'low']).describe('优先级'),
        dueDate: z.string().optional().describe('截止日期'),
        assignee: z.string().optional().describe('负责人'),
      }),
    )
    .describe('从文本中提取的任务列表'),
  summary: z.string().describe('整体摘要'),
});

app.post('/api/extract-tasks', async (c) => {
  const { text } = await c.req.json();

  const { object } = await generateObject({
    model: openai('gpt-4o'),
    schema: TaskExtractionSchema,
    prompt: `从以下会议记录中提取任务：\n\n${text}`,
  });

  return c.json(object);
});

export default app;


Schema 验证与错误处理
即使使用 Structured Output Mode，也应当添加运行时验证作为安全网：


import { generateObject } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const ResponseSchema = z.object({
  answer: z.string(),
  confidence: z.number().min(0).max(1),
  sources: z.array(z.string().url()),
});

async function safeGenerateObject(prompt: string) {
  try {
    const { object } = await generateObject({
      model: openai('gpt-4o'),
      schema: ResponseSchema,
      prompt,
    });

    const validated = ResponseSchema.parse(object);
    return { success: true as const, data: validated };
  } catch (error) {
    if (error instanceof z.ZodError) {
      return {
        success: false as const,
        errors: error.errors.map((e) => ({
          path: e.path.join('.'),
          message: e.message,
        })),
      };
    }
    throw error;
  }
}


enum 输出模式
当输出只需要一个枚举分类值时，可以使用 enum 模式代替完整的 Schema：


import { generateObject } from 'ai';
import { openai } from '@ai-sdk/openai';

const { object } = await generateObject({
  model: openai('gpt-4o'),
  output: 'enum',
  enum: ['positive', 'negative', 'neutral'],
  prompt: '分析以下评论的情感倾向：这款产品质量很好，物流也很快',
});

console.log(object);


小结
结构化输出将 LLM 的自由文本转化为程序可直接消费的类型安全数据。AI SDK 6 的 generateObject 配合 Zod Schema，提供了从定义到验证的完整方案：Zod 的 .describe() 帮助模型理解字段语义，Structured Output Mode 保证输出严格符合 Schema，TypeScript 类型推断让开发体验无缝衔接。在实际项目中，结构化输出广泛应用于信息提取、内容分类、数据转换等场景，是构建可靠 AI 应用的基础能力。
