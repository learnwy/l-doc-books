Function Calling 简介

对话能力让 AI 能够交流，而函数调用能力让 AI 能够行动。Function Calling 是 Agent 从"会说"到"会做"的关键转折点——模型不再仅仅生成文本，而是能够识别用户意图、选择合适的工具、构造结构化参数并触发真实操作。本章将带你深入函数调用的完整技术栈，从规范理解到多步执行，构建 Agent 与外部世界交互的核心能力。

第一节"函数调用规范"从 OpenAI 的 Function Calling 协议出发，系统讲解函数调用的工作原理。你将理解模型如何在生成过程中决定调用函数而非输出文本、函数描述如何影响模型的调用决策、请求与响应的消息格式设计，以及不同模型提供商在函数调用协议上的差异与兼容性处理方案。

第二节"结构化输出"解决函数调用中参数可靠性的问题。大语言模型的输出本质上是非结构化的文本，而工具调用需要严格的类型和格式。你将使用 Zod Schema 定义参数结构，利用 AI SDK 的结构化输出能力确保模型返回符合预期的 JSON 数据，学习如何处理校验失败、类型不匹配等边界情况。

第三节"Tool 定义与执行"进入实际编码阶段。你将使用 AI SDK 的 tool() 函数定义工具，包括工具描述、参数 Schema 和执行逻辑。你将理解工具注册的流程、执行上下文的传递、返回值的处理，以及如何设计清晰的工具描述让模型能够准确理解何时该调用哪个工具。

第四节"多步工具调用"释放 Agent 的真正潜力。现实任务很少能通过一次工具调用完成，Agent 需要在多个工具调用之间进行推理、组合结果并决定下一步行动。你将利用 AI SDK 的 maxSteps 机制实现自动多步执行，理解工具调用链的执行流程，处理中间状态和错误传播，为后续构建完整的 Agent Loop 打下基础。

四个主题循序渐进：先理解规范，再确保输出可靠，然后实现单次调用，最后扩展到多步执行。Function Calling 是 Agent 开发的分水岭，掌握本章内容后，你的系统将具备与外部世界真实交互的能力，从单纯的对话系统进化为能够执行任务的智能体。
