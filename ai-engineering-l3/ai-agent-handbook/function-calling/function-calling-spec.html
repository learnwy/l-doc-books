函数调用规范

什么是 Function Calling

Function Calling 是 LLM 与外部世界交互的核心机制。模型本身无法执行代码、查询数据库或调用 API，但它可以生成结构化的函数调用请求，由应用程序代理执行后将结果返回给模型继续推理。这一机制将 LLM 从"只会说话"升级为"能做事情"的智能体。



Function 与 Tool 的区别
OpenAI 在早期使用 functions 参数，后来统一迁移到 tools 参数。两者的核心区别：






维度
functions（已废弃）
tools（当前标准）





API 参数
functions + function_call
tools + tool_choice




调用方式
单次调用
支持并行多次调用




返回格式
function_call 字段
tool_calls 数组




类型标识
无
每个 tool 有 type: "function"





在 AI SDK 6 中，统一使用 tools 概念，不再区分 function 与 tool。




API 请求格式
一个完整的 Function Calling 请求需要在 tools 中声明可用工具，每个工具包含名称、描述和 JSON Schema 参数定义：


{
  "model": "gpt-4o",
  "messages": [
    {
      "role": "user",
      "content": "北京今天天气怎么样？"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "getWeather",
        "description": "获取指定城市的当前天气信息",
        "parameters": {
          "type": "object",
          "properties": {
            "city": {
              "type": "string",
              "description": "城市名称，例如：北京、上海"
            },
            "unit": {
              "type": "string",
              "enum": ["celsius", "fahrenheit"],
              "description": "温度单位"
            }
          },
          "required": ["city"]
        }
      }
    }
  ],
  "tool_choice": "auto"
}
模型返回的响应中包含 tool_calls 数组：


{
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": null,
        "tool_calls": [
          {
            "id": "call_abc123",
            "type": "function",
            "function": {
              "name": "getWeather",
              "arguments": "{\"city\":\"北京\",\"unit\":\"celsius\"}"
            }
          }
        ]
      },
      "finish_reason": "tool_calls"
    }
  ]
}


tool_choice 控制策略
tool_choice 参数决定模型如何选择是否调用工具：






值
行为
适用场景





"auto"
模型自主决定是否调用工具
通用对话场景




"none"
禁止调用任何工具
纯文本回复




"required"
必须调用至少一个工具
强制执行操作




{"type":"function","function":{"name":"getWeather"}}
强制调用指定工具
明确知道需要哪个工具





在 AI SDK 6 中使用 toolChoice 参数：


import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: openai('gpt-4o'),
  prompt: '北京今天天气怎么样？',
  tools: {
    /* ... */
  },
  toolChoice: 'required',
});


JSON Schema 参数定义
工具参数通过 JSON Schema 定义，模型依据 Schema 生成符合要求的参数。常用的 Schema 类型：


const searchToolSchema = {
  type: 'object' as const,
  properties: {
    query: {
      type: 'string',
      description: '搜索关键词',
    },
    maxResults: {
      type: 'number',
      description: '最大返回条数',
      minimum: 1,
      maximum: 50,
    },
    filters: {
      type: 'object',
      properties: {
        dateRange: {
          type: 'string',
          enum: ['today', 'week', 'month', 'year'],
        },
        language: {
          type: 'string',
          description: '结果语言，ISO 639-1 编码',
        },
      },
    },
    tags: {
      type: 'array',
      items: { type: 'string' },
      description: '过滤标签列表',
    },
  },
  required: ['query'],
};


提示： description 字段极为关键。模型依赖描述信息理解参数含义，清晰的描述能显著提高参数生成的准确性。






模型如何决策调用
LLM 决定是否调用函数的过程并非规则匹配，而是基于训练中学习到的模式。模型会综合考量以下因素：


影响模型决策的关键因素：






因素
说明





工具描述质量
清晰的 description 让模型更准确地判断何时调用




参数描述
每个参数的描述帮助模型提取正确的值




用户意图匹配
用户消息与工具功能的语义相关性




tool_choice
显式控制覆盖模型的自主判断




工具数量
工具过多会增加选择难度，建议控制在 20 个以内







完整调用流程示例
在 Hono 后端中实现一个完整的 Function Calling 流程：


import { Hono } from 'hono';
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';
import { tool } from 'ai';

const app = new Hono();

app.post('/api/chat', async (c) => {
  const { messages } = await c.req.json();

  const result = await generateText({
    model: openai('gpt-4o'),
    messages,
    tools: {
      getWeather: tool({
        description: '获取指定城市的当前天气信息',
        parameters: z.object({
          city: z.string().describe('城市名称'),
          unit: z.enum(['celsius', 'fahrenheit']).optional().describe('温度单位'),
        }),
        execute: async ({ city, unit = 'celsius' }) => {
          const response = await fetch(`https://api.weather.example/v1/current?city=${city}&unit=${unit}`);
          return response.json();
        },
      }),
    },
  });

  return c.json({ text: result.text, toolResults: result.toolResults });
});

export default app;


小结
Function Calling 是 LLM 从对话系统迈向智能体的关键能力。OpenAI 规范通过 tools 参数声明可用工具，用 JSON Schema 定义参数结构，用 tool_choice 控制调用策略。模型根据工具描述和用户意图自主决定是否调用函数，并生成结构化的 tool_calls 响应。在 AI SDK 6 中，这一过程被进一步简化——通过 tool() 函数将参数定义、描述和执行逻辑封装在一起，开发者只需关注业务逻辑本身。理解这套规范是构建可靠工具调用系统的基础。
