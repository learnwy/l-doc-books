Tool 定义与执行

tool() 函数概览

AI SDK 6 的 tool() 函数是定义工具的核心 API，它将工具描述、参数 Schema 和执行逻辑封装在一个统一的对象中。模型根据工具描述决定何时调用，根据参数 Schema 生成入参，应用程序执行 execute 回调并将结果反馈给模型。



基本工具定义
一个 tool() 定义包含三个核心要素：description 告诉模型工具的用途，parameters 用 Zod 定义输入参数，execute 是实际执行逻辑：


import { tool } from 'ai';
import { z } from 'zod';

const weatherTool = tool({
  description: '获取指定城市的当前天气信息，包括温度、湿度和天气状况',
  parameters: z.object({
    city: z.string().describe('城市名称，例如：北京、上海、广州'),
    unit: z.enum(['celsius', 'fahrenheit']).default('celsius').describe('温度单位'),
  }),
  execute: async ({ city, unit }) => {
    const response = await fetch(
      `https://api.weather.example/v1/current?city=${encodeURIComponent(city)}&unit=${unit}`,
    );
    if (!response.ok) {
      throw new Error(`天气查询失败：${response.statusText}`);
    }
    const data = await response.json();
    return {
      city,
      temperature: data.temp,
      unit,
      condition: data.condition,
      humidity: data.humidity,
    };
  },
});


工具注册与调用
工具通过 tools 参数传入 generateText 或 streamText，键名即为工具标识：


import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: openai('gpt-4o'),
  prompt: '北京和上海今天哪个更热？',
  tools: {
    getWeather: weatherTool,
  },
});

console.log(result.text);
console.log(result.toolCalls);
console.log(result.toolResults);

计算器工具示例
数学计算是工具调用的经典场景。LLM 的数学能力有限，交给代码执行更可靠：


import { tool } from 'ai';
import { z } from 'zod';

const calculatorTool = tool({
  description: '执行数学计算，支持基本算术运算和常用数学函数',
  parameters: z.object({
    expression: z.string().describe('数学表达式，例如：2 + 3 * 4、sqrt(16)、sin(PI/2)'),
  }),
  execute: async ({ expression }) => {
    const sanitized = expression.replace(/[^0-9+\-*/().%\s]|sqrt|sin|cos|tan|log|PI|E/g, '');
    const prepared = sanitized
      .replace(/PI/g, String(Math.PI))
      .replace(/E/g, String(Math.E))
      .replace(/sqrt\(([^)]+)\)/g, 'Math.sqrt($1)')
      .replace(/sin\(([^)]+)\)/g, 'Math.sin($1)')
      .replace(/cos\(([^)]+)\)/g, 'Math.cos($1)')
      .replace(/tan\(([^)]+)\)/g, 'Math.tan($1)')
      .replace(/log\(([^)]+)\)/g, 'Math.log($1)');

    const result = new Function(`return ${prepared}`)();

    if (typeof result !== 'number' || !isFinite(result)) {
      throw new Error(`无法计算表达式：${expression}`);
    }

    return { expression, result: Math.round(result * 1e10) / 1e10 };
  },
});


搜索工具示例
搜索工具让模型具备信息检索能力，是 RAG 系统的基础组件：


import { tool } from 'ai';
import { z } from 'zod';

interface SearchResult {
  title: string;
  url: string;
  snippet: string;
}

const searchTool = tool({
  description: '在知识库中搜索相关文档，返回最匹配的结果列表',
  parameters: z.object({
    query: z.string().describe('搜索关键词'),
    limit: z.number().min(1).max(10).default(5).describe('返回结果数量上限'),
    category: z.enum(['docs', 'api', 'blog', 'all']).default('all').describe('搜索范围'),
  }),
  execute: async ({ query, limit, category }): Promise<SearchResult[]> => {
    const params = new URLSearchParams({
      q: query,
      limit: String(limit),
      ...(category !== 'all' && { category }),
    });

    const response = await fetch(`https://api.search.example/v1/search?${params}`);
    if (!response.ok) {
      throw new Error(`搜索失败：${response.statusText}`);
    }

    const data = await response.json();
    return data.results.map((item: Record<string, string>) => ({
      title: item.title,
      url: item.url,
      snippet: item.snippet,
    }));
  },
});


工具错误处理
工具执行过程中的错误需要妥善处理。AI SDK 提供了两种错误处理策略：


import { tool } from 'ai';
import { z } from 'zod';

const robustTool = tool({
  description: '查询数据库中的用户信息',
  parameters: z.object({
    userId: z.string().describe('用户 ID'),
  }),
  execute: async ({ userId }) => {
    try {
      const response = await fetch(`https://api.example/users/${userId}`);

      if (response.status === 404) {
        return { error: '用户不存在', userId };
      }

      if (!response.ok) {
        return { error: `查询失败：HTTP ${response.status}`, userId };
      }

      const user = await response.json();
      return { success: true, user };
    } catch (error) {
      return {
        error: error instanceof Error ? error.message : '未知错误',
        userId,
      };
    }
  },
});

提示： 优先使用"返回错误信息"策略。这让模型有机会理解错误原因并调整策略（如换一个参数重试），而抛出异常会直接终止整个调用链。






多工具组合注册
实际应用中通常需要注册多个工具，让模型根据场景自主选择：


import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: openai('gpt-4o'),
  prompt: '帮我查一下北京的天气，然后计算华氏度和摄氏度之间的差值',
  tools: {
    getWeather: weatherTool,
    calculate: calculatorTool,
    search: searchTool,
  },
  maxSteps: 5,
});
工具描述的质量直接影响模型的选择准确性。描述应当明确说明工具的用途、适用场景和输入要求，避免工具之间职责重叠导致模型困惑。




小结
AI SDK 6 的 tool() 函数提供了声明式的工具定义方式：description 引导模型理解工具用途，parameters 通过 Zod Schema 保证参数类型安全，execute 回调实现具体业务逻辑。在错误处理上，优先返回包含错误信息的结果对象而非抛出异常，给模型提供错误恢复的机会。通过组合多个工具并注册到 generateText 或 streamText，模型能够根据用户意图自主选择和调用合适的工具，这是构建 Agent 系统的核心能力。
