多步工具调用

为什么需要多步调用

大多数真实任务无法通过一次工具调用完成。用户问"北京和东京的天气对比"，模型需要先分别查询两个城市的天气，再综合结果生成对比分析。maxSteps 机制让模型在一次请求中自动执行多轮"调用工具→获取结果→继续推理"的循环，直到任务完成或达到步数上限。



maxSteps 配置
maxSteps 参数控制模型最多可以执行的步骤数。每个步骤是一次完整的 LLM 调用，可能产生文本回复或工具调用：


import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';
import { tool } from 'ai';
import { z } from 'zod';

const result = await generateText({
  model: openai('gpt-4o'),
  prompt: '帮我对比北京和东京的天气，并计算温差',
  tools: {
    getWeather: tool({
      description: '获取指定城市的当前天气',
      parameters: z.object({
        city: z.string().describe('城市名称'),
      }),
      execute: async ({ city }) => {
        const data: Record<string, number> = { 北京: 28, 东京: 32, 纽约: 25 };
        return { city, temperature: data[city] ?? 20, unit: 'celsius' };
      },
    }),
    calculate: tool({
      description: '执行数学计算',
      parameters: z.object({
        expression: z.string().describe('数学表达式'),
      }),
      execute: async ({ expression }) => {
        const result = new Function(`return ${expression}`)();
        return { expression, result };
      },
    }),
  },
  maxSteps: 5,
});

console.log(result.text);
console.log(`总步骤数：${result.steps.length}`);

steps 结果分析
result.steps 数组记录了每一步的详细信息，用于调试和可观测性：


import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: openai('gpt-4o'),
  prompt: '查询北京天气并转换为华氏度',
  tools: {
    /* ... */
  },
  maxSteps: 5,
});

for (const [index, step] of result.steps.entries()) {
  console.log(`--- Step ${index + 1} ---`);
  console.log(`完成原因：${step.finishReason}`);
  console.log(`Token 用量：${JSON.stringify(step.usage)}`);

  if (step.toolCalls.length > 0) {
    for (const call of step.toolCalls) {
      console.log(`工具调用：${call.toolName}(${JSON.stringify(call.args)})`);
    }
  }

  if (step.toolResults.length > 0) {
    for (const result of step.toolResults) {
      console.log(`工具结果：${JSON.stringify(result.result)}`);
    }
  }

  if (step.text) {
    console.log(`文本输出：${step.text}`);
  }
}


并行工具调用
部分模型支持在单个步骤中同时调用多个工具。当任务中的多个工具调用相互独立时，并行执行可以显著提升效率：


AI SDK 自动处理并行工具调用。当模型在一个步骤中返回多个 tool_calls 时，SDK 会并发执行所有工具，等待全部完成后将结果一并返回给模型：


import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: openai('gpt-4o'),
  prompt: '对比北京、东京和纽约三个城市的天气',
  tools: {
    getWeather: tool({
      description: '获取指定城市的当前天气',
      parameters: z.object({
        city: z.string().describe('城市名称'),
      }),
      execute: async ({ city }) => {
        const data: Record<string, { temp: number; condition: string }> = {
          北京: { temp: 28, condition: 'sunny' },
          东京: { temp: 32, condition: 'cloudy' },
          纽约: { temp: 25, condition: 'rainy' },
        };
        return data[city] ?? { temp: 20, condition: 'unknown' };
      },
    }),
  },
  maxSteps: 3,
});
在上述场景中，模型可能在 Step 1 同时发出三个 getWeather 调用，SDK 并行执行后在 Step 2 模型即可获得所有结果并生成对比分析。




流式多步调用
在前端交互中，流式输出配合多步调用可以实时展示工具执行进度：


import { streamText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = streamText({
  model: openai('gpt-4o'),
  prompt: '分析最近的科技新闻趋势',
  tools: {
    /* ... */
  },
  maxSteps: 5,
  onStepFinish: ({ stepType, toolCalls, toolResults, text, usage }) => {
    console.log(`步骤类型：${stepType}`);

    if (toolCalls) {
      toolCalls.forEach((call) => {
        console.log(`调用工具：${call.toolName}`);
      });
    }

    console.log(`本步 Token：${usage.totalTokens}`);
  },
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}
onStepFinish 回调在每个步骤完成时触发，可以用来更新 UI 中的工具执行状态指示器。在 React 前端中，配合 useChat Hook 可以自动处理多步流式渲染。




多步调用的成本控制
每一步都会消耗 Token，多步执行的总成本需要关注：


import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: openai('gpt-4o'),
  prompt: '执行复杂的数据分析任务',
  tools: {
    /* ... */
  },
  maxSteps: 10,
});

let totalInputTokens = 0;
let totalOutputTokens = 0;

for (const step of result.steps) {
  totalInputTokens += step.usage.promptTokens;
  totalOutputTokens += step.usage.completionTokens;
}

console.log(`总输入 Token：${totalInputTokens}`);
console.log(`总输出 Token：${totalOutputTokens}`);
console.log(`总步骤数：${result.steps.length}`);


提示： 上下文会随步骤数累积。第 N 步的输入包含前 N-1 步的所有工具调用和结果，因此 Token 消耗呈递增趋势。合理设置 maxSteps 可以避免不必要的成本。






小结
多步工具调用通过 maxSteps 机制让模型在一次请求中自动完成"调用工具→获取结果→继续推理"的循环。模型在返回纯文本时自动停止，达到步数上限时强制停止。并行工具调用由 SDK 自动处理，多个独立的工具请求可以并发执行以提升效率。result.steps 提供了每步的详细信息用于调试和成本分析。流式模式下的 onStepFinish 回调可以实时追踪执行进度。多步调用是从单次工具调用到完整 Agent Loop 的关键过渡，掌握它意味着你的系统已经具备了自主推理和行动的基本能力。
