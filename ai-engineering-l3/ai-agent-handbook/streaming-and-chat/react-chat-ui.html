React Chat 组件

useChat Hook

AI SDK 6 提供了 useChat hook，封装了消息管理、流式请求、状态追踪的完整逻辑。开发者不需要手动处理 SSE 解析、消息拼接和加载状态，一个 hook 即可获得完整的聊天能力。



最小可用示例
一个完整的聊天界面只需要几十行代码：


import { useChat } from "@ai-sdk/react";

export function Chat() {
  const { messages, input, handleInputChange, handleSubmit, status, error } =
    useChat({ api: "/api/chat" });

  return (
    <div className="flex flex-col h-screen max-w-2xl mx-auto">
      <div className="flex-1 overflow-y-auto p-4 space-y-4">
        {messages.map((message) => (
          <div
            key={message.id}
            className={
              message.role === "user" ? "flex justify-end" : "flex justify-start"
            }
          >
            <div
              className={
                message.role === "user"
                  ? "bg-blue-500 text-white rounded-lg px-4 py-2 max-w-md"
                  : "bg-gray-100 rounded-lg px-4 py-2 max-w-md"
              }
            >
              {message.content}
            </div>
          </div>
        ))}
      </div>

      {error && (
        <div className="px-4 py-2 text-red-500 text-sm">
          出错了：{error.message}
        </div>
      )}

      <form onSubmit={handleSubmit} className="border-t p-4 flex gap-2">
        <input
          value={input}
          onChange={handleInputChange}
          placeholder="输入消息..."
          className="flex-1 border rounded-lg px-4 py-2"
          disabled={status === "streaming"}
        />
        <button
          type="submit"
          disabled={status === "streaming" || !input.trim()}
          className="bg-blue-500 text-white px-6 py-2 rounded-lg disabled:opacity-50"
        >
          发送
        </button>
      </form>
    </div>
  );
}

Markdown 渲染
AI 回复通常包含 Markdown 格式的代码块、列表和标题。使用 react-markdown 渲染富文本：


npm install react-markdown
import ReactMarkdown from "react-markdown";
import type { Message } from "@ai-sdk/react";

interface MessageBubbleProps {
  message: Message;
}

export function MessageBubble({ message }: MessageBubbleProps) {
  const isUser = message.role === "user";

  return (
    <div className={isUser ? "flex justify-end" : "flex justify-start"}>
      <div
        className={
          isUser
            ? "bg-blue-500 text-white rounded-lg px-4 py-2 max-w-lg"
            : "bg-gray-100 rounded-lg px-4 py-2 max-w-lg prose prose-sm"
        }
      >
        {isUser ? (
          <p>{message.content}</p>
        ) : (
          <ReactMarkdown>{message.content}</ReactMarkdown>
        )}
      </div>
    </div>
  );
}


自动滚动
当新消息到达或流式输出进行中时，聊天区域应自动滚动到底部：


import { useEffect, useRef } from 'react';
import type { Message } from '@ai-sdk/react';

export function useAutoScroll(messages: Message[], status: string) {
  const scrollRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const el = scrollRef.current;
    if (!el) return;

    const isNearBottom = el.scrollHeight - el.scrollTop - el.clientHeight < 100;

    if (isNearBottom || status === 'streaming') {
      el.scrollTo({ top: el.scrollHeight, behavior: 'smooth' });
    }
  }, [messages, status]);

  return scrollRef;
}
只有在用户当前位于底部附近时才自动滚动。如果用户向上翻阅历史消息，不会强制跳回底部，避免打断阅读。




加载状态与中断
流式响应期间需要向用户展示加载指示器，并提供中断按钮：


import { useChat } from "@ai-sdk/react";

export function StreamingIndicator() {
  const { status, stop, reload, messages } = useChat({ api: "/api/chat" });

  return (
    <div className="flex items-center gap-2 px-4 py-2">
      {status === "streaming" && (
        <>
          <span className="flex gap-1">
            <span className="w-2 h-2 bg-gray-400 rounded-full animate-bounce" />
            <span className="w-2 h-2 bg-gray-400 rounded-full animate-bounce delay-100" />
            <span className="w-2 h-2 bg-gray-400 rounded-full animate-bounce delay-200" />
          </span>
          <button
            onClick={stop}
            className="text-sm text-red-500 hover:underline"
          >
            停止生成
          </button>
        </>
      )}

      {status === "ready" && messages.length > 0 && (
        <button
          onClick={reload}
          className="text-sm text-gray-500 hover:underline"
        >
          重新生成
        </button>
      )}
    </div>
  );
}


完整组件结构
将各模块组合为完整的聊天页面：


import { useChat } from "@ai-sdk/react";
import { MessageBubble } from "./MessageBubble";
import { useAutoScroll } from "./useAutoScroll";

export function ChatPage() {
  const {
    messages,
    input,
    handleInputChange,
    handleSubmit,
    status,
    error,
    stop,
    reload,
  } = useChat({ api: "/api/chat" });

  const scrollRef = useAutoScroll(messages, status);

  return (
    <div className="flex flex-col h-screen max-w-2xl mx-auto">
      <header className="border-b p-4 text-lg font-semibold">AI Chat</header>

      <div ref={scrollRef} className="flex-1 overflow-y-auto p-4 space-y-4">
        {messages.map((msg) => (
          <MessageBubble key={msg.id} message={msg} />
        ))}
      </div>

      <div className="flex items-center gap-2 px-4 py-1">
        {status === "streaming" && (
          <button onClick={stop} className="text-sm text-red-500">
            停止生成
          </button>
        )}
        {status === "ready" && messages.length > 0 && (
          <button onClick={reload} className="text-sm text-gray-500">
            重新生成
          </button>
        )}
      </div>

      {error && (
        <div className="px-4 py-2 text-red-500 text-sm">
          错误：{error.message}
        </div>
      )}

      <form onSubmit={handleSubmit} className="border-t p-4 flex gap-2">
        <input
          value={input}
          onChange={handleInputChange}
          placeholder="输入消息..."
          className="flex-1 border rounded-lg px-4 py-2"
          disabled={status === "streaming"}
        />
        <button
          type="submit"
          disabled={status === "streaming" || !input.trim()}
          className="bg-blue-500 text-white px-6 py-2 rounded-lg disabled:opacity-50"
        >
          发送
        </button>
      </form>
    </div>
  );
}


小结
    

  • useChat 是 AI SDK 提供的 React hook，封装了消息管理、流式请求和状态追踪的完整逻辑。
    • 

  • 使用 react-markdown 渲染 assistant 回复中的 Markdown 内容，提供富文本阅读体验。
    • 

  • 自动滚动需要判断用户是否在底部附近，避免在阅读历史消息时强制跳转。
    • 

  • 通过 stop 和 reload 方法实现流式中断和重新生成，给用户完整的对话控制能力。
