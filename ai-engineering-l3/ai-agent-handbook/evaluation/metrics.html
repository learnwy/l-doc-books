指标与报告

评估指标体系

Agent 评估不能只看"答对没有"，需要从多个维度量化质量。核心指标分为四大类：准确性（回答是否正确）、安全性（是否拒绝有害请求）、延迟（响应速度）、成本（资源消耗）。每个维度下有具体的量化指标。



指标数据结构
interface AccuracyMetrics {
  exactMatchRate: number;
  containsMatchRate: number;
  semanticSimilarityMean: number;
  toolCallAccuracy: number;
}

interface SafetyMetrics {
  harmfulContentRejectionRate: number;
  privacyLeakDetected: number;
  totalSafetyCases: number;
}

interface LatencyMetrics {
  meanLatencyMs: number;
  p50LatencyMs: number;
  p95LatencyMs: number;
  p99LatencyMs: number;
  meanStepLatencyMs: number;
}

interface CostMetrics {
  totalInputTokens: number;
  totalOutputTokens: number;
  totalTokens: number;
  totalApiCalls: number;
  estimatedCostUsd: number;
}

interface EvalMetrics {
  accuracy: AccuracyMetrics;
  safety: SafetyMetrics;
  latency: LatencyMetrics;
  cost: CostMetrics;
}


MetricsCollector 实现
MetricsCollector 从评估结果中提取并汇总各维度指标：


interface EvalResult {
  testCaseId: string;
  category: string;
  passed: boolean;
  matchScore: number;
  latencyMs: number;
  totalTokens: number;
  inputTokens: number;
  outputTokens: number;
  toolCallCount: number;
  toolCallCorrect: boolean;
  steps: { durationMs: number }[];
}

class MetricsCollector {
  private results: EvalResult[] = [];

  add(result: EvalResult): void {
    this.results.push(result);
  }

  addBatch(results: EvalResult[]): void {
    this.results.push(...results);
  }

  compute(): EvalMetrics {
    return {
      accuracy: this.computeAccuracy(),
      safety: this.computeSafety(),
      latency: this.computeLatency(),
      cost: this.computeCost(),
    };
  }

  private computeAccuracy(): AccuracyMetrics {
    const accuracyCases = this.results.filter((r) => r.category === 'accuracy');
    const toolCases = this.results.filter((r) => r.category === 'tool-usage');
    const allNonSafety = this.results.filter((r) => r.category !== 'safety');

    return {
      exactMatchRate: this.rate(accuracyCases, (r) => r.matchScore === 1.0),
      containsMatchRate: this.rate(accuracyCases, (r) => r.passed),
      semanticSimilarityMean: this.mean(allNonSafety, (r) => r.matchScore),
      toolCallAccuracy: this.rate(toolCases, (r) => r.toolCallCorrect),
    };
  }

  private computeSafety(): SafetyMetrics {
    const safetyCases = this.results.filter((r) => r.category === 'safety');
    return {
      harmfulContentRejectionRate: this.rate(safetyCases, (r) => r.passed),
      privacyLeakDetected: safetyCases.filter((r) => !r.passed).length,
      totalSafetyCases: safetyCases.length,
    };
  }

  private computeLatency(): LatencyMetrics {
    const latencies = this.results.map((r) => r.latencyMs).sort((a, b) => a - b);
    const stepLatencies = this.results.flatMap((r) => r.steps.map((s) => s.durationMs));

    return {
      meanLatencyMs: this.mean(this.results, (r) => r.latencyMs),
      p50LatencyMs: this.percentile(latencies, 50),
      p95LatencyMs: this.percentile(latencies, 95),
      p99LatencyMs: this.percentile(latencies, 99),
      meanStepLatencyMs: stepLatencies.length > 0 ? stepLatencies.reduce((a, b) => a + b, 0) / stepLatencies.length : 0,
    };
  }

  private computeCost(): CostMetrics {
    const totalInput = this.results.reduce((s, r) => s + r.inputTokens, 0);
    const totalOutput = this.results.reduce((s, r) => s + r.outputTokens, 0);

    return {
      totalInputTokens: totalInput,
      totalOutputTokens: totalOutput,
      totalTokens: totalInput + totalOutput,
      totalApiCalls: this.results.reduce((s, r) => s + r.toolCallCount + 1, 0),
      estimatedCostUsd: (totalInput * 2.5 + totalOutput * 10) / 1_000_000,
    };
  }

  private rate(items: EvalResult[], predicate: (r: EvalResult) => boolean): number {
    if (items.length === 0) return 0;
    return items.filter(predicate).length / items.length;
  }

  private mean(items: EvalResult[], accessor: (r: EvalResult) => number): number {
    if (items.length === 0) return 0;
    return items.reduce((sum, r) => sum + accessor(r), 0) / items.length;
  }

  private percentile(sorted: number[], p: number): number {
    if (sorted.length === 0) return 0;
    const index = Math.ceil((p / 100) * sorted.length) - 1;
    return sorted[Math.max(0, index)];
  }
}


报告生成
将 EvalMetrics 输出为结构化的 JSON 报告：


import { writeFile } from 'node:fs/promises';

interface EvalReport {
  runId: string;
  timestamp: string;
  model: string;
  totalCases: number;
  metrics: EvalMetrics;
  categoryBreakdown: Record<string, { total: number; passed: number; rate: number }>;
}

async function generateReport(
  runId: string,
  model: string,
  results: EvalResult[],
  metrics: EvalMetrics,
): Promise<EvalReport> {
  const breakdown: Record<string, { total: number; passed: number; rate: number }> = {};

  for (const r of results) {
    if (!breakdown[r.category]) {
      breakdown[r.category] = { total: 0, passed: 0, rate: 0 };
    }
    breakdown[r.category].total++;
    if (r.passed) breakdown[r.category].passed++;
  }

  for (const cat of Object.values(breakdown)) {
    cat.rate = cat.total > 0 ? cat.passed / cat.total : 0;
  }

  const report: EvalReport = {
    runId,
    timestamp: new Date().toISOString(),
    model,
    totalCases: results.length,
    metrics,
    categoryBreakdown: breakdown,
  };

  await writeFile(`eval-report-${runId}.json`, JSON.stringify(report, null, 2), 'utf-8');

  return report;
}


报告摘要打印
在终端打印可读的评估摘要：


function printReportSummary(report: EvalReport): void {
  console.log(`\n${'='.repeat(50)}`);
  console.log(`评估报告 — ${report.model}`);
  console.log(`运行 ID: ${report.runId}`);
  console.log(`时间: ${report.timestamp}`);
  console.log(`${'='.repeat(50)}\n`);

  console.log(`总用例数: ${report.totalCases}`);
  console.log(`准确性 — 精确匹配: ${fmt(report.metrics.accuracy.exactMatchRate)}`);
  console.log(`准确性 — 包含匹配: ${fmt(report.metrics.accuracy.containsMatchRate)}`);
  console.log(`安全性 — 拒绝率: ${fmt(report.metrics.safety.harmfulContentRejectionRate)}`);
  console.log(`延迟 — P50: ${report.metrics.latency.p50LatencyMs}ms`);
  console.log(`延迟 — P95: ${report.metrics.latency.p95LatencyMs}ms`);
  console.log(`成本 — 总 Token: ${report.metrics.cost.totalTokens}`);
  console.log(`成本 — 估算费用: $${report.metrics.cost.estimatedCostUsd.toFixed(4)}`);

  console.log(`\n分类明细:`);
  for (const [cat, data] of Object.entries(report.categoryBreakdown)) {
    console.log(`  ${cat}: ${data.passed}/${data.total} (${fmt(data.rate)})`);
  }
}

function fmt(rate: number): string {
  return `${(rate * 100).toFixed(1)}%`;
}

小结
Agent 评估指标覆盖四个维度：准确性（精确匹配率、语义相似度、工具调用正确率）、安全性（有害内容拒绝率、隐私泄露检测）、延迟（P50/P95/P99 响应时间）、成本（Token 消耗和估算费用）。MetricsCollector 从原始评估结果中提取并汇总这些指标，generateReport 将指标输出为 JSON 报告，printReportSummary 在终端打印可读摘要。对比表在多模型评估场景中快速定位质量、速度和成本的差异，为模型选型和配置优化提供数据支撑。
