消息网关

为什么需要消息网关

当多 Agent 系统从三五个 Agent 扩展到十几个时，点对点的直接调用会产生 N×N 的通信复杂度。消息网关（Message Gateway）作为统一的通信中枢，将 Agent 之间的交互从网状结构简化为星形拓扑。所有消息经由网关路由，实现发布/订阅、请求/响应和广播等通信模式，同时为全局可观测性提供天然的采集点。



消息格式
统一的消息格式是网关的基础。每条消息包含来源、目标、类型和负载：


interface AgentMessage {
  id: string;
  timestamp: number;
  from: string;
  to: string | '*';
  type: 'request' | 'response' | 'event' | 'heartbeat';
  topic: string;
  payload: unknown;
  correlationId?: string;
}

function createMessage(
  from: string,
  to: string | '*',
  type: AgentMessage['type'],
  topic: string,
  payload: unknown,
  correlationId?: string,
): AgentMessage {
  return {
    id: crypto.randomUUID(),
    timestamp: Date.now(),
    from,
    to,
    type,
    topic,
    payload,
    correlationId,
  };
}

MessageGateway 实现
网关维护 Agent 注册表和主题订阅关系，负责消息路由和投递：


type MessageHandler = (message: AgentMessage) => void | Promise<void>;

interface AgentRegistration {
  name: string;
  handler: MessageHandler;
  topics: Set<string>;
  lastHeartbeat: number;
}

class MessageGateway {
  private agents: Map<string, AgentRegistration> = new Map();
  private messageLog: AgentMessage[] = [];

  register(name: string, handler: MessageHandler, topics: string[] = []) {
    this.agents.set(name, {
      name,
      handler,
      topics: new Set(topics),
      lastHeartbeat: Date.now(),
    });
  }

  unregister(name: string) {
    this.agents.delete(name);
  }

  subscribe(agentName: string, topic: string) {
    const agent = this.agents.get(agentName);
    if (agent) agent.topics.add(topic);
  }

  async publish(message: AgentMessage) {
    this.messageLog.push(message);

    if (message.to === '*') {
      await this.broadcast(message);
    } else {
      await this.unicast(message);
    }
  }

  private async broadcast(message: AgentMessage) {
    const targets = Array.from(this.agents.values()).filter(
      (a) => a.name !== message.from && a.topics.has(message.topic),
    );

    await Promise.allSettled(targets.map((agent) => agent.handler(message)));
  }

  private async unicast(message: AgentMessage) {
    const target = this.agents.get(message.to as string);
    if (!target) {
      console.warn(`[Gateway] Agent 不存在: ${message.to}`);
      return;
    }
    await target.handler(message);
  }

  getLog(filter?: { from?: string; to?: string; topic?: string }): AgentMessage[] {
    return this.messageLog.filter((m) => {
      if (filter?.from && m.from !== filter.from) return false;
      if (filter?.to && m.to !== filter.to) return false;
      if (filter?.topic && m.topic !== filter.topic) return false;
      return true;
    });
  }
}


请求/响应模式
Agent 之间常需要同步式的请求/响应交互。通过 correlationId 关联请求与响应，配合 Promise 封装为异步调用：


class GatewayClient {
  private gateway: MessageGateway;
  private agentName: string;
  private pendingRequests: Map<
    string,
    {
      resolve: (msg: AgentMessage) => void;
      timer: ReturnType<typeof setTimeout>;
    }
  > = new Map();

  constructor(gateway: MessageGateway, agentName: string, topics: string[]) {
    this.gateway = gateway;
    this.agentName = agentName;
    this.gateway.register(agentName, (msg) => this.onMessage(msg), topics);
  }

  async request(to: string, topic: string, payload: unknown, timeoutMs: number = 10_000): Promise<AgentMessage> {
    const msg = createMessage(this.agentName, to, 'request', topic, payload);

    return new Promise((resolve, reject) => {
      const timer = setTimeout(() => {
        this.pendingRequests.delete(msg.id);
        reject(new Error(`请求超时: ${to}/${topic}`));
      }, timeoutMs);

      this.pendingRequests.set(msg.id, { resolve, timer });
      this.gateway.publish(msg);
    });
  }

  async respond(original: AgentMessage, payload: unknown) {
    const reply = createMessage(this.agentName, original.from, 'response', original.topic, payload, original.id);
    await this.gateway.publish(reply);
  }

  private onMessage(msg: AgentMessage) {
    if (msg.type === 'response' && msg.correlationId) {
      const pending = this.pendingRequests.get(msg.correlationId);
      if (pending) {
        clearTimeout(pending.timer);
        this.pendingRequests.delete(msg.correlationId);
        pending.resolve(msg);
      }
    }
  }
}

Agent 发现与健康检查
网关负责维护 Agent 注册表，提供服务发现和健康状态监测：


class HealthMonitor {
  private gateway: MessageGateway;
  private interval: ReturnType<typeof setInterval> | null = null;

  constructor(gateway: MessageGateway) {
    this.gateway = gateway;
  }

  start(checkIntervalMs: number = 5_000, timeoutMs: number = 15_000) {
    this.interval = setInterval(() => {
      const now = Date.now();
      const agents = this.gateway.getLog().reduce((acc, msg) => {
        acc.set(msg.from, Math.max(acc.get(msg.from) ?? 0, msg.timestamp));
        return acc;
      }, new Map<string, number>());

      for (const [name, lastSeen] of agents) {
        if (now - lastSeen > timeoutMs) {
          console.warn(`[Health] Agent ${name} 可能已离线 (${now - lastSeen}ms)`);
        }
      }
    }, checkIntervalMs);
  }

  stop() {
    if (this.interval) clearInterval(this.interval);
  }
}


集成使用示例
将网关集成到 Hono 服务中，通过 HTTP 接口暴露消息能力：


import { Hono } from 'hono';

const app = new Hono();
const gateway = new MessageGateway();

const supervisorClient = new GatewayClient(gateway, 'supervisor', ['progress', 'result']);
const researchClient = new GatewayClient(gateway, 'research', ['task']);
const codingClient = new GatewayClient(gateway, 'coding', ['task']);

app.post('/api/task', async (c) => {
  const { task } = await c.req.json<{ task: string }>();

  const researchResult = await supervisorClient.request('research', 'task', { task });

  const codingResult = await supervisorClient.request('coding', 'task', {
    task: '根据调研结果编写代码',
    context: researchResult.payload,
  });

  return c.json({
    research: researchResult.payload,
    coding: codingResult.payload,
  });
});

app.get('/api/messages', (c) => {
  const from = c.req.query('from');
  const topic = c.req.query('topic');
  return c.json(gateway.getLog({ from: from ?? undefined, topic: topic ?? undefined }));
});

小结
消息网关将多 Agent 系统的通信从 N×N 的网状结构简化为星形拓扑，降低了系统复杂度。MessageGateway 类维护 Agent 注册表和主题订阅，支持单播和广播两种投递方式。GatewayClient 封装了请求/响应模式，通过 correlationId 和 Promise 实现同步式的 Agent 间调用。健康检查基于消息时间戳监测 Agent 存活状态。所有经过网关的消息自动记录，为调试和可观测性提供完整的通信日志。将网关集成到 Hono 服务后，可通过 HTTP 接口查询消息流转记录，实现多 Agent 系统的运行时监控。
