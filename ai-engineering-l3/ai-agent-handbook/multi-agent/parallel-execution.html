并行执行

为什么需要并行

Supervisor 按依赖顺序逐个调度子 Agent 时，独立的子任务被串行执行，浪费了并发能力。当三个子任务互不依赖时，串行执行的总耗时等于三者之和，而并行执行只需等待最慢的那一个。Fan-out/Fan-in 模式将独立任务同时分发（Fan-out），等待全部或部分完成后收集汇总（Fan-in）。

ParallelExecutor 核心实现
ParallelExecutor 封装了 Promise.allSettled 的 Fan-out/Fan-in 语义，支持超时控制和部分失败处理：


interface ParallelTask<T> {
  id: string;
  name: string;
  execute: () => Promise<T>;
}

interface TaskResult<T> {
  id: string;
  name: string;
  status: 'fulfilled' | 'rejected' | 'timeout';
  value?: T;
  error?: string;
  duration: number;
}

class ParallelExecutor {
  private timeoutMs: number;

  constructor(timeoutMs: number = 30_000) {
    this.timeoutMs = timeoutMs;
  }

  async runAll<T>(tasks: ParallelTask<T>[]): Promise<TaskResult<T>[]> {
    const wrapped = tasks.map((task) => this.wrapWithTimeout(task));
    const settled = await Promise.allSettled(wrapped);

    return settled.map((result, i) => {
      const task = tasks[i];
      if (result.status === 'fulfilled') {
        return result.value;
      }
      return {
        id: task.id,
        name: task.name,
        status: 'rejected' as const,
        error: result.reason instanceof Error ? result.reason.message : String(result.reason),
        duration: 0,
      };
    });
  }

  private wrapWithTimeout<T>(task: ParallelTask<T>): Promise<TaskResult<T>> {
    return new Promise((resolve, reject) => {
      const start = Date.now();
      let settled = false;

      const timer = setTimeout(() => {
        if (!settled) {
          settled = true;
          resolve({
            id: task.id,
            name: task.name,
            status: 'timeout',
            error: `超时: ${this.timeoutMs}ms`,
            duration: this.timeoutMs,
          });
        }
      }, this.timeoutMs);

      task
        .execute()
        .then((value) => {
          if (!settled) {
            settled = true;
            clearTimeout(timer);
            resolve({
              id: task.id,
              name: task.name,
              status: 'fulfilled',
              value,
              duration: Date.now() - start,
            });
          }
        })
        .catch((err) => {
          if (!settled) {
            settled = true;
            clearTimeout(timer);
            reject(err);
          }
        });
    });
  }
}


结果汇总策略
Fan-in 阶段需要将多个子 Agent 的结果合并。根据任务特性选择不同的汇总策略：


import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

type MergeStrategy = 'concatenate' | 'llm-synthesis' | 'vote';

async function mergeResults<T>(results: TaskResult<T>[], strategy: MergeStrategy): Promise<string> {
  const succeeded = results.filter((r) => r.status === 'fulfilled');
  const failed = results.filter((r) => r.status !== 'fulfilled');

  if (strategy === 'concatenate') {
    return succeeded.map((r) => `### ${r.name}\n${JSON.stringify(r.value, null, 2)}`).join('\n\n');
  }

  if (strategy === 'llm-synthesis') {
    const sections = succeeded.map((r) => `[${r.name}]\n${JSON.stringify(r.value)}`).join('\n\n');

    const failInfo =
      failed.length > 0 ? `\n\n注意：以下任务未成功: ${failed.map((r) => `${r.name}(${r.status})`).join(', ')}` : '';

    const { text } = await generateText({
      model: openai('gpt-4o'),
      prompt: `将以下多个来源的结果综合为一份连贯的报告:${failInfo}\n\n${sections}`,
    });
    return text;
  }

  if (strategy === 'vote') {
    const values = succeeded.map((r) => JSON.stringify(r.value));
    const counts = new Map<string, number>();
    for (const v of values) {
      counts.set(v, (counts.get(v) ?? 0) + 1);
    }
    const winner = [...counts.entries()].sort((a, b) => b[1] - a[1])[0];
    return winner?.[0] ?? '无有效结果';
  }

  return '未知策略';
}

依赖感知的并行调度
实际任务中，部分子任务有依赖关系，部分可以并行。按拓扑层级分组，同一层级内并行执行，层级间串行：


interface DependentTask<T> extends ParallelTask<T> {
  dependencies: string[];
}

async function executeByLayers<T>(
  tasks: DependentTask<T>[],
  executor: ParallelExecutor,
): Promise<Map<string, TaskResult<T>>> {
  const resultMap = new Map<string, TaskResult<T>>();
  const remaining = new Set(tasks.map((t) => t.id));

  while (remaining.size > 0) {
    const ready = tasks.filter((t) => remaining.has(t.id) && t.dependencies.every((dep) => !remaining.has(dep)));

    if (ready.length === 0) {
      throw new Error('检测到循环依赖');
    }

    const layerResults = await executor.runAll(ready);

    for (const result of layerResults) {
      resultMap.set(result.id, result);
      remaining.delete(result.id);
    }
  }

  return resultMap;
}


部分失败处理
并行执行中某个分支失败不应阻塞整个流程。定义失败策略来控制系统行为：


type FailurePolicy = 'fail-fast' | 'continue' | 'retry';

interface ParallelConfig {
  timeoutMs: number;
  failurePolicy: FailurePolicy;
  maxRetries: number;
}

async function executeWithPolicy<T>(tasks: ParallelTask<T>[], config: ParallelConfig): Promise<TaskResult<T>[]> {
  const executor = new ParallelExecutor(config.timeoutMs);
  let results = await executor.runAll(tasks);

  if (config.failurePolicy === 'fail-fast') {
    const failed = results.find((r) => r.status !== 'fulfilled');
    if (failed) throw new Error(`任务 ${failed.name} 失败: ${failed.error}`);
  }

  if (config.failurePolicy === 'retry') {
    for (let attempt = 0; attempt < config.maxRetries; attempt++) {
      const failedTasks = results
        .filter((r) => r.status !== 'fulfilled')
        .map((r) => tasks.find((t) => t.id === r.id)!)
        .filter(Boolean);

      if (failedTasks.length === 0) break;

      const retryResults = await executor.runAll(failedTasks);
      for (const retry of retryResults) {
        const idx = results.findIndex((r) => r.id === retry.id);
        if (idx !== -1) results[idx] = retry;
      }
    }
  }

  return results;
}

小结
并行执行通过 Fan-out/Fan-in 模式大幅缩短多 Agent 协作的端到端延迟。ParallelExecutor 基于 Promise.allSettled 实现并发分发和结果收集，配合超时控制防止单个任务阻塞全局。结果汇总支持拼接、LLM 综合和投票三种策略，根据任务特性选择。依赖感知的分层调度确保有依赖的任务按正确顺序执行，同层级内最大化并行度。部分失败处理提供 fail-fast、continue 和 retry 三种策略，在可靠性和效率之间灵活权衡。设计并行方案时，首先分析任务依赖图谱，将无依赖的任务分到同一层级并行执行。
