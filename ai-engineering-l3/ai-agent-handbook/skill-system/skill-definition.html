SKILL.md 格式定义

什么是 SKILL.md

SKILL.md 是 AI Agent 技能系统的核心配置文件。每个技能通过一个独立的 SKILL.md 文件声明其身份、触发条件、所需工具和执行指令。Agent 在运行时扫描并解析这些文件，将匹配的技能指令注入到系统提示词中。



Frontmatter 字段规范
SKILL.md 的头部使用 YAML frontmatter 声明技能元数据。以下是全部字段定义：

TypeScript 类型定义：


interface SkillFrontmatter {
  name: string;
  version: string;
  description: string;
  trigger: string[];
  category?: string;
  requiredTools?: string[];
  toolcalls?: boolean;
  priority?: number;
  enabled?: boolean;
}


Markdown Body 结构
Frontmatter 之后的 Markdown 正文按照固定的 section 组织技能指令。Agent 在匹配到技能后会将这些 section 的内容注入到提示词中。

完整示例：web-search 技能
---
name: web-search
version: 1.2.0
description: 使用搜索引擎获取实时信息并总结结果
trigger:
  - 搜索
  - 查找
  - 最新信息
  - search
  - look up
category: search
requiredTools:
  - WebSearch
  - WebFetch
toolcalls: true
priority: 10
---

## Purpose

当用户需要获取实时信息、验证事实或查找最新文档时，使用 Web 搜索工具获取结果并进行总结。

## Trigger Patterns

- "帮我搜索 X 的最新版本"
- "查一下 Y 的官方文档"
- "X 和 Y 有什么区别？"（需要实时数据时）

## Usage

1. 分析用户意图，提取搜索关键词
2. 调用 WebSearch 获取结果列表
3. 对相关结果调用 WebFetch 获取详情
4. 总结并以结构化格式呈现

## Implementation

- 搜索查询控制在 5-10 个关键词
- 最多获取 5 条搜索结果
- 优先选择官方文档和权威来源
- 结果中必须标注信息来源 URL

## Safety

- 不搜索涉及用户隐私的信息
- 不将用户的私有代码内容作为搜索词
- 搜索频率控制在每轮对话不超过 3 次

## Testing

- 输入 "查一下 Hono 框架的最新版本" → 应调用 WebSearch 并返回版本号
- 输入 "今天天气怎么样" → 应触发搜索并返回天气信息


完整示例：file-manager 技能
---
name: file-manager
version: 1.0.0
description: 管理项目文件的创建、移动、重命名和删除操作
trigger:
  - 创建文件
  - 删除文件
  - 重命名
  - 移动文件
  - create file
  - rename
category: file
requiredTools:
  - Read
  - Write
  - DeleteFile
  - RunCommand
toolcalls: true
priority: 5
---

## Purpose

处理用户的文件管理请求，包括创建新文件、移动文件位置、重命名和删除操作。确保操作安全且符合项目约定。

## Trigger Patterns

- "创建一个新的组件文件 Button.tsx"
- "把 utils.ts 移动到 shared/ 目录下"
- "删除 temp/ 下的所有临时文件"

## Usage

1. 解析用户请求中的文件路径和操作类型
2. 验证目标路径的合法性
3. 执行文件操作
4. 确认操作结果

## Implementation

- 创建文件前检查是否已存在同名文件
- 删除操作前先读取文件内容作为确认
- 移动文件时保留 git 历史（使用 git mv）
- 遵循项目的目录结构约定

## Safety

- 禁止删除 .git 目录和配置文件
- 禁止操作项目根目录之外的文件
- 批量删除超过 5 个文件时需要用户确认


Frontmatter 解析实现
使用 gray-matter 库解析 SKILL.md 的 frontmatter 和正文：


import matter from 'gray-matter';
import { z } from 'zod';

const skillFrontmatterSchema = z.object({
  name: z.string().regex(/^[a-z][a-z0-9-]*$/),
  version: z.string().regex(/^\d+\.\d+\.\d+$/),
  description: z.string().min(1),
  trigger: z.array(z.string()).min(1),
  category: z.string().optional(),
  requiredTools: z.array(z.string()).optional(),
  toolcalls: z.boolean().optional().default(false),
  priority: z.number().optional().default(0),
  enabled: z.boolean().optional().default(true),
});

function parseSkillFile(filePath: string, content: string) {
  const { data, content: body } = matter(content);
  const frontmatter = skillFrontmatterSchema.parse(data);

  const sections = extractSections(body);

  return { filePath, frontmatter, sections };
}

function extractSections(body: string): Record<string, string> {
  const sections: Record<string, string> = {};
  const regex = /^## (.+)$/gm;
  const headings: { title: string; index: number }[] = [];

  let match: RegExpExecArray | null;
  while ((match = regex.exec(body)) !== null) {
    headings.push({ title: match[1].trim(), index: match.index });
  }

  for (let i = 0; i < headings.length; i++) {
    const start = headings[i].index + headings[i].title.length + 4;
    const end = i + 1 < headings.length ? headings[i + 1].index : body.length;
    sections[headings[i].title] = body.slice(start, end).trim();
  }

  return sections;
}


小结
    

  • SKILL.md 由 YAML frontmatter（元数据）和 Markdown body（执行指令）两部分组成。
    • 

  • Frontmatter 定义技能的身份信息：名称、版本、触发词、依赖工具、优先级。
    • 

  • Body 按照 Purpose → Trigger Patterns → Usage → Implementation → Safety → Testing 的固定结构组织。
    • 

  • 使用 gray-matter + zod 实现类型安全的解析和校验。
    • 

  • 每个技能目录下放置一个 SKILL.md 文件，Agent 在启动时递归扫描并加载。
