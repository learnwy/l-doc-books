Skill 系统 简介

当 Agent 具备了工具调用能力后，下一个问题是如何组织和管理这些能力。Skill 系统是对 Agent 能力的高层抽象——它将工具、提示词、执行逻辑封装为可声明、可发现、可组合的能力单元。本章将设计并实现一套完整的 Skill 系统，从格式定义到运行时注入，让 Agent 的能力管理从硬编码走向声明式配置。

第一节"SKILL.md 格式定义"设计 Skill 的声明规范。你将定义一套 Markdown 格式的 Skill 描述文件，涵盖 Skill 的元信息、能力描述、依赖工具、触发条件和使用示例。这个格式既是人类可读的文档，又是机器可解析的配置，实现了"代码即文档"的理念。良好的格式设计决定了整个 Skill 系统的表达力上限。

第二节"Skill 加载与发现"实现文件系统级的自动扫描机制。你将构建一个 Skill 加载器，能够递归扫描指定目录、解析 SKILL.md 文件、提取结构化信息。加载器需要处理文件变更监听、增量加载、格式校验等工程细节，确保 Skill 的添加和修改能够即时生效而无需重启服务。

第三节"Skill 注册表"构建 Skill 的运行时管理中心。注册表维护所有已发现 Skill 的索引，提供按名称、标签、能力类型的查询接口，管理 Skill 之间的依赖关系。你将设计注册表的数据结构和生命周期管理策略，让 Agent 能够在运行时动态了解自己拥有哪些能力、每种能力适用于什么场景。

第四节"Prompt 注入"将 Skill 信息转化为模型可理解的上下文。注册表中的 Skill 元数据需要被智能地注入到系统提示词中，让大语言模型知道自己能做什么、该怎么做。你将设计提示词组合策略，处理 Skill 数量增长带来的上下文膨胀问题，实现基于任务相关性的动态 Skill 选择与注入。

四个主题构成完整的 Skill 生命周期：定义、发现、注册、注入。这套系统让 Agent 的能力扩展变得像添加一个 Markdown 文件一样简单，同时保持了工程上的可维护性和运行时的灵活性。完成本章后，你将拥有一个声明式的能力管理框架，为后续构建更复杂的工具生态和 MCP 集成提供坚实支撑。
