Skill 注册表

注册表的角色

Skill Registry 是技能系统的运行时核心。SkillLoader 将 SKILL.md 文件解析为元数据对象后，这些对象被注册到 Registry 中。当用户发送消息时，Registry 负责根据触发词和意图进行匹配，返回最相关的技能列表。



核心接口定义
interface SkillMetadata {
  name: string;
  version: string;
  description: string;
  trigger: string[];
  category: string;
  requiredTools: string[];
  toolcalls: boolean;
  priority: number;
  enabled: boolean;
  sections: Record<string, string>;
  filePath: string;
  loadedAt: Date;
}

interface MatchResult {
  skill: SkillMetadata;
  score: number;
  matchedTriggers: string[];
}

interface RegistryOptions {
  maxMatches: number;
  minScore: number;
  categoryLimit: number;
}


SkillRegistry 实现
const DEFAULT_OPTIONS: RegistryOptions = {
  maxMatches: 5,
  minScore: 0.3,
  categoryLimit: 2,
};

class SkillRegistry {
  private skills = new Map<string, SkillMetadata>();
  private options: RegistryOptions;

  constructor(options: Partial<RegistryOptions> = {}) {
    this.options = { ...DEFAULT_OPTIONS, ...options };
  }

  register(skill: SkillMetadata): void {
    if (this.skills.has(skill.name)) {
      const existing = this.skills.get(skill.name)!;
      if (skill.priority >= existing.priority) {
        this.skills.set(skill.name, skill);
      }
      return;
    }
    this.skills.set(skill.name, skill);
  }

  registerAll(skills: SkillMetadata[]): void {
    for (const skill of skills) {
      this.register(skill);
    }
  }

  unregister(name: string): boolean {
    return this.skills.delete(name);
  }

  match(userMessage: string): MatchResult[] {
    const results: MatchResult[] = [];
    const normalizedInput = userMessage.toLowerCase();

    for (const skill of this.skills.values()) {
      const matchResult = this.calculateMatch(normalizedInput, skill);
      if (matchResult.score >= this.options.minScore) {
        results.push(matchResult);
      }
    }

    return this.resolveConflicts(results.sort((a, b) => b.score - a.score));
  }

  list(): SkillMetadata[] {
    return Array.from(this.skills.values()).sort((a, b) => b.priority - a.priority);
  }

  get(name: string): SkillMetadata | undefined {
    return this.skills.get(name);
  }

  get size(): number {
    return this.skills.size;
  }

  private calculateMatch(input: string, skill: SkillMetadata): MatchResult {
    const matchedTriggers: string[] = [];
    let totalScore = 0;

    for (const trigger of skill.trigger) {
      const normalizedTrigger = trigger.toLowerCase();
      if (input.includes(normalizedTrigger)) {
        matchedTriggers.push(trigger);
        totalScore += normalizedTrigger.length / input.length;
      }
    }

    const priorityBonus = skill.priority * 0.01;
    const score = Math.min(totalScore + priorityBonus, 1);

    return { skill, score, matchedTriggers };
  }

  private resolveConflicts(results: MatchResult[]): MatchResult[] {
    const categoryCount = new Map<string, number>();
    const resolved: MatchResult[] = [];

    for (const result of results) {
      if (resolved.length >= this.options.maxMatches) break;

      const cat = result.skill.category;
      const count = categoryCount.get(cat) ?? 0;

      if (count < this.options.categoryLimit) {
        resolved.push(result);
        categoryCount.set(cat, count + 1);
      }
    }

    return resolved;
  }
}

冲突解决策略
当多个技能匹配到同一条消息时，Registry 通过以下策略解决冲突：


const conflictResolutionRules = {

  versionBreaker: true,

使用示例
将 SkillLoader 和 SkillRegistry 串联使用的完整流程：


import { Hono } from 'hono';

const app = new Hono();

const loader = new SkillLoader(['./.trae/skills', `${process.env.HOME}/.trae-cn/skills`]);

const registry = new SkillRegistry({ maxMatches: 3 });

const skills = await loader.loadAll();
registry.registerAll(skills);

app.post('/chat', async (c) => {
  const { message } = await c.req.json<{ message: string }>();

  const matched = registry.match(message);

  const skillInstructions = matched.map((r) => r.skill.sections['Implementation'] ?? '').filter(Boolean);

  return c.json({
    matchedSkills: matched.map((r) => ({
      name: r.skill.name,
      score: r.score,
      triggers: r.matchedTriggers,
    })),
    instructionCount: skillInstructions.length,
  });
});

export default app;


小结
    

  • SkillRegistry 是技能系统的运行时核心，负责注册、匹配和冲突解决。
    • 

  • 匹配基于触发词的子串包含检测，分数由关键词长度占比和优先级加成计算。
    • 

  • 冲突解决通过分数排序 + 同类别数量限制 + 总数限制三层策略实现。
    • 

  • register 方法在同名技能冲突时保留优先级更高的版本。
    • 

  • 与 Hono 路由集成后，每次请求自动匹配技能并提取指令。
