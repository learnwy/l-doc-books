Skill 加载与发现

加载流程概览

Skill Loader 负责在 Agent 启动时递归扫描文件系统，发现所有 SKILL.md 文件，解析其 YAML frontmatter 和 Markdown body，构建结构化的技能元数据对象。这个过程是技能系统的第一步——从磁盘文件到内存对象的转换。



技能元数据类型
加载后的每个技能被表示为一个 SkillMetadata 对象，包含来源路径、frontmatter 数据和正文 sections：


interface SkillMetadata {
  filePath: string;
  name: string;
  version: string;
  description: string;
  trigger: string[];
  category: string;
  requiredTools: string[];
  toolcalls: boolean;
  priority: number;
  enabled: boolean;
  sections: Record<string, string>;
  loadedAt: Date;
}


SkillLoader 实现
import { glob } from 'glob';
import { readFile } from 'node:fs/promises';
import { resolve } from 'node:path';
import matter from 'gray-matter';
import { z } from 'zod';

const frontmatterSchema = z.object({
  name: z.string(),
  version: z.string(),
  description: z.string(),
  trigger: z.array(z.string()).min(1),
  category: z.string().optional().default('general'),
  requiredTools: z.array(z.string()).optional().default([]),
  toolcalls: z.boolean().optional().default(false),
  priority: z.number().optional().default(0),
  enabled: z.boolean().optional().default(true),
});

class SkillLoader {
  private searchPaths: string[];

  constructor(searchPaths: string[]) {
    this.searchPaths = searchPaths.map((p) => resolve(p));
  }

  async loadAll(): Promise<SkillMetadata[]> {
    const files = await this.discover();
    const skills: SkillMetadata[] = [];

    for (const filePath of files) {
      try {
        const skill = await this.loadOne(filePath);
        if (skill.enabled) {
          skills.push(skill);
        }
      } catch (error) {
        console.warn(`跳过无效技能文件: ${filePath}`, error);
      }
    }

    return skills.sort((a, b) => b.priority - a.priority);
  }

  async discover(): Promise<string[]> {
    const allFiles: string[] = [];

    for (const basePath of this.searchPaths) {
      const pattern = `${basePath}/**/SKILL.md`;
      const found = await glob(pattern, { absolute: true });
      allFiles.push(...found);
    }

    return [...new Set(allFiles)];
  }

  async loadOne(filePath: string): Promise<SkillMetadata> {
    const raw = await readFile(filePath, 'utf-8');
    const { data, content } = matter(raw);
    const frontmatter = frontmatterSchema.parse(data);
    const sections = this.parseSections(content);

    return {
      filePath,
      ...frontmatter,
      sections,
      loadedAt: new Date(),
    };
  }

  private parseSections(body: string): Record<string, string> {
    const sections: Record<string, string> = {};
    const parts = body.split(/^## /m).filter(Boolean);

    for (const part of parts) {
      const newlineIdx = part.indexOf('\n');
      if (newlineIdx === -1) continue;

      const title = part.slice(0, newlineIdx).trim();
      const content = part.slice(newlineIdx + 1).trim();
      sections[title] = content;
    }

    return sections;
  }
}


多级搜索路径
技能文件可以存放在多个位置。SkillLoader 支持配置多级搜索路径，按优先级从高到低依次扫描：

const loader = new SkillLoader([
  resolve(projectRoot, '.trae/skills'),
  resolve(homeDir, '.trae-cn/skills'),
  resolve(__dirname, '../built-in/skills'),
]);

const skills = await loader.loadAll();
当同名技能出现在多个路径中时，优先级高的路径覆盖低的：


function deduplicateSkills(skills: SkillMetadata[]): SkillMetadata[] {
  const seen = new Map<string, SkillMetadata>();

  for (const skill of skills) {
    if (!seen.has(skill.name)) {
      seen.set(skill.name, skill);
    }
  }

  return Array.from(seen.values());
}


热重载支持
在开发模式下，可以使用文件监听实现技能的热重载，无需重启 Agent：


import { watch } from 'chokidar';

function watchSkills(loader: SkillLoader, onReload: (skills: SkillMetadata[]) => void) {
  const watcher = watch('**/SKILL.md', {
    cwd: loader['searchPaths'][0],
    ignoreInitial: true,
  });

  const reload = async () => {
    const skills = await loader.loadAll();
    onReload(skills);
  };

  watcher.on('add', reload);
  watcher.on('change', reload);
  watcher.on('unlink', reload);

  return () => watcher.close();
}

小结
    

  • SkillLoader 通过 glob 模式递归扫描多级目录，发现所有 SKILL.md 文件。
    • 

  • 使用 gray-matter 分离 frontmatter 和正文，zod 校验 frontmatter 结构。
    • 

  • 多级搜索路径（项目级 > 用户级 > 内置级）支持技能覆盖和定制。
    • 

  • 同名技能按路径优先级去重，确保高优先级路径的技能生效。
    • 

  • 开发模式下通过 chokidar 监听文件变更实现热重载。
