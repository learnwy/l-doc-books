工具组合与路由

从单工具到工具生态

当 Agent 只有 3-5 个工具时，直接全部注册就够了。但当工具数量增长到数十个时，全部注册会导致模型的上下文窗口被大量工具描述占满，工具选择准确率下降。解决方案是引入工具注册表、动态路由和按需组合。



工具注册表
所有工具集中注册到一个 Map 中，支持按名称查找、按分类过滤和动态增删：


import { tool, type CoreTool } from 'ai';
import { z } from 'zod';

interface ToolEntry {
  tool: CoreTool;
  category: string;
  description: string;
  tags: string[];
}

class ToolRegistry {
  private tools = new Map<string, ToolEntry>();

  register(name: string, entry: ToolEntry): void {
    this.tools.set(name, entry);
  }

  unregister(name: string): boolean {
    return this.tools.delete(name);
  }

  get(name: string): ToolEntry | undefined {
    return this.tools.get(name);
  }

  getByCategory(category: string): Record<string, CoreTool> {
    const result: Record<string, CoreTool> = {};
    for (const [name, entry] of this.tools) {
      if (entry.category === category) {
        result[name] = entry.tool;
      }
    }
    return result;
  }

  getByTags(tags: string[]): Record<string, CoreTool> {
    const result: Record<string, CoreTool> = {};
    for (const [name, entry] of this.tools) {
      if (tags.some((tag) => entry.tags.includes(tag))) {
        result[name] = entry.tool;
      }
    }
    return result;
  }

  listAll(): string[] {
    return [...this.tools.keys()];
  }

  toToolsObject(): Record<string, CoreTool> {
    const result: Record<string, CoreTool> = {};
    for (const [name, entry] of this.tools) {
      result[name] = entry.tool;
    }
    return result;
  }
}

工具路由器
ToolRouter 根据用户输入的意图自动选择合适的工具集，避免将全部工具塞给模型：


import { generateObject } from 'ai';
import { openai } from '@ai-sdk/openai';

interface RouteResult {
  categories: string[];
  confidence: number;
}

class ToolRouter {
  constructor(private registry: ToolRegistry) {}

  async route(userMessage: string): Promise<Record<string, CoreTool>> {
    const result = await generateObject({
      model: openai('gpt-4o-mini'),
      schema: z.object({
        categories: z.array(z.enum(['file', 'web', 'database', 'code', 'general'])),
        confidence: z.number().min(0).max(1),
      }),
      prompt: `分析以下用户消息需要使用哪些类别的工具。
可选类别：file（文件操作）、web（网络请求）、database（数据库）、code（代码执行）、general（通用）。

用户消息：${userMessage}`,
    });

    const tools: Record<string, CoreTool> = {};
    for (const category of result.object.categories) {
      Object.assign(tools, this.registry.getByCategory(category));
    }
    return tools;
  }

  routeByKeywords(userMessage: string): Record<string, CoreTool> {
    const keywordMap: Record<string, string[]> = {
      file: ['文件', '读取', '写入', '目录', 'file', 'read', 'write'],
      web: ['搜索', '网页', 'URL', 'HTTP', 'fetch', 'search'],
      database: ['查询', 'SQL', '数据库', 'query', 'database'],
      code: ['运行', '执行', '测试', 'run', 'exec', 'test'],
    };

    const matched = new Set<string>();
    const lower = userMessage.toLowerCase();

    for (const [category, keywords] of Object.entries(keywordMap)) {
      if (keywords.some((kw) => lower.includes(kw.toLowerCase()))) {
        matched.add(category);
      }
    }

    if (matched.size === 0) {
      return this.registry.toToolsObject();
    }

    const tools: Record<string, CoreTool> = {};
    for (const category of matched) {
      Object.assign(tools, this.registry.getByCategory(category));
    }
    return tools;
  }
}

工具集预设
为常见的 Agent 模式定义预设工具集，简化配置：


type AgentMode = 'coder' | 'researcher' | 'analyst' | 'general';

function getToolSet(registry: ToolRegistry, mode: AgentMode): Record<string, CoreTool> {
  const presets: Record<AgentMode, string[]> = {
    coder: ['file', 'code'],
    researcher: ['web', 'file'],
    analyst: ['database', 'file'],
    general: ['file', 'web', 'database', 'code'],
  };

  const categories = presets[mode];
  const tools: Record<string, CoreTool> = {};
  for (const category of categories) {
    Object.assign(tools, registry.getByCategory(category));
  }
  return tools;
}
在 Hono 路由中使用工具集：


import { Hono } from 'hono';
import { streamText } from 'ai';
import { openai } from '@ai-sdk/openai';

const app = new Hono();

app.post('/api/chat', async (c) => {
  const { messages, mode = 'general' } = await c.req.json<{
    messages: Array<{ role: string; content: string }>;
    mode?: AgentMode;
  }>();

  const tools = getToolSet(registry, mode);

  const result = streamText({
    model: openai('gpt-4o'),
    messages,
    tools,
    maxSteps: 10,
  });

  return result.toDataStreamResponse();
});


动态工具加载
运行时根据配置文件动态加载工具，无需重启服务：


import { readFile } from 'node:fs/promises';

interface ToolConfig {
  name: string;
  module: string;
  category: string;
  tags: string[];
  enabled: boolean;
}

async function loadToolsFromConfig(registry: ToolRegistry, configPath: string): Promise<void> {
  const raw = await readFile(configPath, 'utf-8');
  const configs: ToolConfig[] = JSON.parse(raw);

  for (const config of configs) {
    if (!config.enabled) continue;
    const mod = await import(config.module);
    registry.register(config.name, {
      tool: mod.default,
      category: config.category,
      description: mod.description ?? config.name,
      tags: config.tags,
    });
  }
}

小结
工具注册表（ToolRegistry）集中管理所有工具的元数据和实例，支持按名称、分类、标签查找。工具路由器（ToolRouter）根据用户意图动态筛选工具集——先用关键词快速匹配，匹配失败再用 LLM 分析意图。工具集预设为常见 Agent 模式（coder / researcher / analyst）提供开箱即用的配置。动态加载机制通过配置文件实现运行时工具增删，无需重启服务。这套组合拳让工具生态在规模增长时依然保持选择精准和性能可控。
