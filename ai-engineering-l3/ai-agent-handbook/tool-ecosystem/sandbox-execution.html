安全沙箱

为什么需要沙箱

Agent 自主调用工具意味着代码可以读写文件、发起网络请求、执行系统命令。如果没有安全边界，一次错误的工具调用可能删除关键文件、泄露敏感数据或耗尽服务器资源。沙箱为工具执行提供隔离层：权限控制决定"能做什么"，资源限制决定"能用多少"，结果审查决定"能返回什么"。



权限模型
定义四类权限维度，每个工具声明所需的权限集合：


type Permission = 'file:read' | 'file:write' | 'net:fetch' | 'net:search' | 'exec:run' | 'db:query' | 'db:write';

interface ToolPermissions {
  toolName: string;
  required: Permission[];
}

interface SandboxPolicy {
  allowed: Permission[];
  deniedPaths: string[];
  allowedHosts: string[];
  maxExecutionMs: number;
  maxOutputBytes: number;
}

SandboxExecutor 实现
class SandboxExecutor {
  constructor(private policy: SandboxPolicy) {}

  async execute<T>(
    toolName: string,
    permissions: Permission[],
    fn: () => Promise<T>,
  ): Promise<{ success: boolean; data?: T; error?: string }> {
    const denied = this.checkPermissions(permissions);
    if (denied.length > 0) {
      return { success: false, error: `权限不足: ${denied.join(', ')}` };
    }

    try {
      const result = await this.withTimeout(fn, this.policy.maxExecutionMs, toolName);
      const sanitized = this.sanitizeOutput(result);
      return { success: true, data: sanitized };
    } catch (err) {
      return { success: false, error: err instanceof Error ? err.message : '执行失败' };
    }
  }

  private checkPermissions(required: Permission[]): Permission[] {
    return required.filter((p) => !this.policy.allowed.includes(p));
  }

  private withTimeout<T>(fn: () => Promise<T>, ms: number, name: string): Promise<T> {
    return Promise.race([
      fn(),
      new Promise<never>((_, reject) => setTimeout(() => reject(new Error(`工具 ${name} 超时 (${ms}ms)`)), ms)),
    ]);
  }

  private sanitizeOutput<T>(output: T): T {
    const json = JSON.stringify(output);
    if (json.length > this.policy.maxOutputBytes) {
      throw new Error(`输出超过大小限制 (${this.policy.maxOutputBytes} bytes)`);
    }
    return JSON.parse(this.redactSecrets(json));
  }

  private redactSecrets(text: string): string {
    return text
      .replace(/(?:api[_-]?key|token|secret|password)\s*[:=]\s*["']?[\w\-\.]+["']?/gi, '[REDACTED]')
      .replace(/eyJ[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}/g, '[JWT_REDACTED]');
  }
}


路径安全检查
文件工具需要额外的路径安全验证，防止路径遍历攻击：


import { resolve, relative } from 'node:path';

class PathGuard {
  constructor(
    private allowedRoot: string,
    private deniedPatterns: string[],
  ) {}

  validate(inputPath: string): { safe: boolean; resolved: string; error?: string } {
    const resolved = resolve(this.allowedRoot, inputPath);
    const rel = relative(this.allowedRoot, resolved);

    if (rel.startsWith('..') || resolve(resolved) !== resolved) {
      return { safe: false, resolved, error: '路径超出允许范围' };
    }

    for (const pattern of this.deniedPatterns) {
      if (resolved.includes(pattern)) {
        return { safe: false, resolved, error: `禁止访问路径: ${pattern}` };
      }
    }

    return { safe: true, resolved };
  }
}

const pathGuard = new PathGuard('/workspace/project', ['.env', '.git', 'node_modules', '/etc/', '/root/']);


网络域名白名单
class NetworkGuard {
  constructor(private allowedHosts: string[]) {}

  validate(url: string): { allowed: boolean; error?: string } {
    try {
      const parsed = new URL(url);
      const isAllowed = this.allowedHosts.some(
        (host) => parsed.hostname === host || parsed.hostname.endsWith(`.${host}`),
      );
      if (!isAllowed) {
        return { allowed: false, error: `域名 ${parsed.hostname} 不在白名单中` };
      }
      if (parsed.protocol !== 'https:') {
        return { allowed: false, error: '仅允许 HTTPS 请求' };
      }
      return { allowed: true };
    } catch {
      return { allowed: false, error: '无效的 URL' };
    }
  }
}

const networkGuard = new NetworkGuard(['api.openai.com', 'api.anthropic.com', 'github.com', 'api.github.com']);

审计日志
记录每次工具调用的完整信息，用于事后审查和异常检测：


interface AuditEntry {
  timestamp: string;
  toolName: string;
  permissions: Permission[];
  allowed: boolean;
  duration: number;
  success: boolean;
  error?: string;
}

class AuditLogger {
  private entries: AuditEntry[] = [];

  log(entry: AuditEntry): void {
    this.entries.push(entry);
    if (this.entries.length > 10000) {
      this.entries = this.entries.slice(-5000);
    }
  }

  getRecent(count: number): AuditEntry[] {
    return this.entries.slice(-count);
  }

  getDenied(): AuditEntry[] {
    return this.entries.filter((e) => !e.allowed);
  }
}


完整集成示例
将沙箱集成到工具执行流程中：


import { tool } from 'ai';
import { z } from 'zod';

function createSandboxedTool(sandbox: SandboxExecutor, pathGuard: PathGuard, audit: AuditLogger) {
  return tool({
    description: '在安全沙箱中读取文件内容',
    parameters: z.object({
      path: z.string().describe('文件路径'),
    }),
    execute: async ({ path }) => {
      const start = Date.now();
      const pathCheck = pathGuard.validate(path);
      if (!pathCheck.safe) {
        audit.log({
          timestamp: new Date().toISOString(),
          toolName: 'readFile',
          permissions: ['file:read'],
          allowed: false,
          duration: 0,
          success: false,
          error: pathCheck.error,
        });
        return { success: false, error: pathCheck.error };
      }
      const result = await sandbox.execute('readFile', ['file:read'], async () => {
        const { readFile } = await import('node:fs/promises');
        return readFile(pathCheck.resolved, 'utf-8');
      });
      audit.log({
        timestamp: new Date().toISOString(),
        toolName: 'readFile',
        permissions: ['file:read'],
        allowed: true,
        duration: Date.now() - start,
        success: result.success,
        error: result.error,
      });
      return result;
    },
  });
}


小结
安全沙箱是工具生态的基础设施，不是可选项。权限模型（Permission）定义工具能做什么，PathGuard 阻止路径遍历攻击，NetworkGuard 限制外部网络访问范围，超时控制防止工具无限阻塞，输出审查自动脱敏密钥和 Token。SandboxExecutor 将这些安全机制统一封装，每次工具调用都经过权限检查 → 隔离执行 → 结果审查的完整流程。审计日志记录全量调用信息，支持事后分析和异常告警。只有在安全可控的前提下，Agent 才能被赋予更大的行动自由。
