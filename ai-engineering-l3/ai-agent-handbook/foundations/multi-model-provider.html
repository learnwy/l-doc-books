多模型 Provider

Provider 架构

AI SDK 的 Provider 是一个将模型 API 适配为统一接口的抽象层。每个 Provider 包装对应厂商的 HTTP API，暴露出一致的 LanguageModel 接口供 Core API 调用。这意味着切换模型只需替换 Provider 实例，应用代码无需任何修改。



环境变量配置
所有 API Key 通过环境变量注入，绝不硬编码到代码中。创建 .env 文件：


OPENAI_API_KEY=sk-xxx
OPENAI_BASE_URL=https://api.openai.com/v1

ANTHROPIC_API_KEY=sk-ant-xxx

DEEPSEEK_API_KEY=sk-xxx
DEEPSEEK_BASE_URL=https://api.deepseek.com

DOUBAO_API_KEY=xxx
DOUBAO_BASE_URL=https://ark.cn-beijing.volces.com/api/v3

GLM_API_KEY=xxx
GLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4

QWEN_API_KEY=sk-xxx
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1

MINIMAX_API_KEY=xxx
MINIMAX_BASE_URL=https://api.minimax.chat/v1

OLLAMA_BASE_URL=http://localhost:11434/v1


将 .env 加入 .gitignore，避免密钥泄漏。






Provider 安装
pnpm add @ai-sdk/openai @ai-sdk/anthropic
对于兼容 OpenAI API 格式的国产模型（DeepSeek、豆包、GLM、Qwen、MiniMax），可直接使用 @ai-sdk/openai 的 createOpenAI 配合自定义 baseURL。Ollama 同理。

import { openai } from '@ai-sdk/openai';

const model = openai('gpt-4o');
SDK 自动读取 OPENAI_API_KEY 环境变量。

Provider 注册表
将所有 Provider 集中管理，通过模型标识符动态选择：


import { createOpenAI } from '@ai-sdk/openai';
import { anthropic } from '@ai-sdk/anthropic';
import type { LanguageModel } from 'ai';

const deepseek = createOpenAI({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: process.env.DEEPSEEK_BASE_URL,
});

const ollama = createOpenAI({
  apiKey: 'ollama',
  baseURL: process.env.OLLAMA_BASE_URL,
});

const providers: Record<string, () => LanguageModel> = {
  'gpt-4o': () => createOpenAI({})('gpt-4o'),
  'claude-4-sonnet': () => anthropic('claude-4-sonnet-20260514'),
  'deepseek-chat': () => deepseek('deepseek-chat'),
  'ollama/qwen3': () => ollama('qwen3:8b'),
};

export function getModel(modelId: string): LanguageModel {
  const factory = providers[modelId];
  if (!factory) {
    throw new Error(`Unknown model: ${modelId}`);
  }
  return factory();
}

在路由中使用
将 Provider 注册表集成到 Hono 路由：


import { Hono } from 'hono';
import { generateText } from 'ai';
import { getModel } from '../providers/index.js';

const chat = new Hono();

chat.post('/chat', async (c) => {
  const { messages, model: modelId = 'gpt-4o' } = await c.req.json();

  const { text, usage } = await generateText({
    model: getModel(modelId),
    messages,
  });

  return c.json({ text, usage });
});

export default chat;
请求时通过 model 字段切换模型：


curl -X POST http://localhost:3000/chat \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "你好"}]
  }'


小结
    

  • AI SDK 的 Provider 层将不同厂商 API 统一为 LanguageModel 接口，实现一行代码切换模型。
    • 

  • 大量国产模型兼容 OpenAI API 格式，使用 createOpenAI + 自定义 baseURL 即可接入。
    • 

  • 所有 API Key 通过环境变量管理，绝不硬编码，务必将 .env 加入 .gitignore。
    • 

  • 通过 Provider 注册表集中管理模型实例，在路由中通过模型标识符动态选择。
    • 

  • Ollama 支持本地模型运行，适用于离线开发和隐私敏感场景。
