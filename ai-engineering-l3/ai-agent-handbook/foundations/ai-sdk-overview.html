AI SDK 6 概览

为什么选择 AI SDK

Vercel AI SDK 是一个面向 TypeScript 生态的 AI 应用框架，它将不同模型提供商的 API 抽象为统一接口，同时提供流式处理、工具调用、Agent 循环等开箱即用的能力。从 v4（AI SDK 6 品牌名）开始，SDK 完成了一次重大架构升级，引入了 Provider 模型、中间件系统和声明式 Agent 接口。



核心模块
AI SDK 分为三个层次：Core（核心 API）、Provider（模型适配）、UI（前端集成）。

核心 API
generateText
一次性生成完整文本，适用于后端处理、批量任务等不需要流式输出的场景：


import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const { text, usage, finishReason } = await generateText({
  model: openai('gpt-4o'),
  system: '你是一个专业的技术助手。',
  prompt: '用一句话解释什么是 Agent。',
});
streamText
流式生成文本，逐 token 输出，适用于聊天界面的实时响应：


import { streamText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = streamText({
  model: openai('gpt-4o'),
  messages: [{ role: 'user', content: '写一首关于编程的诗' }],
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}
generateObject
让模型输出结构化数据，通过 Zod Schema 约束输出格式：


import { generateObject } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const { object } = await generateObject({
  model: openai('gpt-4o'),
  schema: z.object({
    name: z.string(),
    description: z.string(),
    difficulty: z.enum(['easy', 'medium', 'hard']),
  }),
  prompt: '生成一个 TypeScript 编程练习题。',
});


工具调用
AI SDK 通过 tool() 函数定义工具，模型可以在对话中主动调用这些工具：


import { generateText, tool } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const { text } = await generateText({
  model: openai('gpt-4o'),
  tools: {
    getWeather: tool({
      description: '获取指定城市的天气',
      parameters: z.object({
        city: z.string().describe('城市名称'),
      }),
      execute: async ({ city }) => {
        return { city, temperature: 22, condition: '晴' };
      },
    }),
  },
  maxSteps: 5,
  prompt: '北京今天天气怎么样？',
});
maxSteps 控制工具调用的最大轮数。模型会根据需要自主决定是否调用工具，并将工具返回结果纳入后续推理。




Agent 循环
AI SDK 的 Agent 循环建立在 maxSteps 之上。当设置 maxSteps > 1 时，SDK 自动实现 ReAct（Reasoning + Acting）模式：


每一步的执行结果都通过 steps 数组暴露：


const { text, steps } = await generateText({
  model: openai('gpt-4o'),
  tools: {
    /* ... */
  },
  maxSteps: 10,
  prompt: '查询北京天气并给出穿衣建议',
});

for (const step of steps) {
  console.log(`Step: ${step.finishReason}`);
  if (step.toolCalls) {
    for (const call of step.toolCalls) {
      console.log(`  Tool: ${call.toolName}(${JSON.stringify(call.args)})`);
    }
  }
}


中间件
AI SDK 支持通过中间件拦截和增强模型调用：


import { wrapLanguageModel } from 'ai';
import { openai } from '@ai-sdk/openai';

const enhancedModel = wrapLanguageModel({
  model: openai('gpt-4o'),
  middleware: {
    transformParams: async ({ params }) => {
      console.log('Request params:', params);
      return params;
    },
    wrapGenerate: async ({ doGenerate }) => {
      const start = Date.now();
      const result = await doGenerate();
      console.log(`Duration: ${Date.now() - start}ms`);
      return result;
    },
  },
});

AI SDK 6 对应 npm 包 ai 的 v4.x 版本。品牌命名为 AI SDK 6，但 npm 版本号从 4.0 开始。






小结
    

  • AI SDK 分为 Core、Provider、UI 三层，职责清晰，按需引入。
    • 

  • generateText 用于一次性生成，streamText 用于流式输出，generateObject 用于结构化输出。
    • 

  • 工具调用通过声明式 tool() 定义，模型自主决定何时调用。
    • 

  • Agent 循环基于 maxSteps 实现 ReAct 模式，自动处理多轮工具调用。
    • 

  • 中间件系统支持日志、缓存、监控等横切关注点的注入。
    • 

  • 相比 LangChain.js 和直接调用 API，AI SDK 在类型安全、流式处理和前端集成方面优势明显。
