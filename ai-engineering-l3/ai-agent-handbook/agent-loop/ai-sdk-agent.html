AI SDK 6 Agent/ToolLoopAgent 工具循环代理

从手动循环到框架抽象

上一节从零构建了完整的 ReAct 循环。AI SDK 6 将这些步骤封装为声明式 API：generateText 配合 tools + maxSteps 就是完整的 ReAct 循环。本节将手动实现迁移到 AI SDK 的内置机制，并深入理解框架在背后做了什么。



generateText + maxSteps：内置 ReAct 循环
AI SDK 的 generateText 在设置 maxSteps 后自动执行 ReAct 循环——执行工具、回填结果、继续推理，直到模型返回纯文本或达到步数上限：


import { generateText, tool } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const result = await generateText({
  model: openai('gpt-4o'),
  system: '你是一个有用的助手，可以查询天气和进行数学计算。',
  prompt: '北京和东京的温差是多少度？',
  tools: {
    weather: tool({
      description: '获取指定城市的当前天气',
      parameters: z.object({ city: z.string().describe('城市名称') }),
      execute: async ({ city }) => {
        const db: Record<string, number> = { 北京: 28, 东京: 32 };
        return { city, temp: db[city] ?? 20 };
      },
    }),
    calculator: tool({
      description: '执行数学计算',
      parameters: z.object({ expression: z.string() }),
      execute: async ({ expression }) => ({
        expression,
        result: new Function(`return ${expression}`)(),
      }),
    }),
  },
  maxSteps: 10,
});

console.log(result.text);
对比上一节 ~100 行的 ReActAgent 类，SDK 版本用 ~30 行完成了相同功能。

关键差异在错误处理。SDK 默认工具抛异常则整个 generateText 抛出。要实现优雅降级，需在 execute 内部捕获：


const robustTool = tool({
  description: '带错误恢复的工具',
  parameters: z.object({ query: z.string() }),
  execute: async ({ query }) => {
    try {
      return await riskyOperation(query);
    } catch (err) {
      return { error: err instanceof Error ? err.message : '执行失败' };
    }
  },
});


steps 追踪与 onStepFinish 监听
result.steps 提供每一步的详细信息，onStepFinish 回调实现实时监听：


const result = await generateText({
  model: openai('gpt-4o'),
  prompt: '分析北京和东京的天气差异',
  tools: {
    /* ... */
  },
  maxSteps: 10,
  onStepFinish: ({ stepType, toolCalls, usage }) => {
    if (stepType === 'tool-result') {
      for (const call of toolCalls) {
        console.log(`[Agent] 调用工具: ${call.toolName}`);
      }
    }
    console.log(`[Agent] 本步消耗 ${usage.totalTokens} tokens`);
  },
});

for (const [i, step] of result.steps.entries()) {
  console.log(`Step ${i + 1}: ${step.finishReason}`);
  for (const call of step.toolCalls) {
    console.log(`  Action: ${call.toolName}(${JSON.stringify(call.args)})`);
  }
}


迁移清单
迁移前后对比：


const agent = new ReActAgent({
  model: openai('gpt-4o'),
  tools,
  systemPrompt: '你是一个有用的助手',
  maxSteps: 10,
});
const answer = await agent.run('北京天气如何？');

const result = await generateText({
  model: openai('gpt-4o'),
  system: '你是一个有用的助手',
  prompt: '北京天气如何？',
  tools,
  maxSteps: 10,
});
const answer = result.text;

小结
AI SDK 6 的 generateText + tools + maxSteps 是 ReAct 循环的工程化封装，自动完成模型调用、工具执行、结果回填和循环控制。从手动 ReActAgent 迁移到 SDK 的核心改动是：删除循环管理代码，将错误处理下沉到 tool.execute 内部，用 onStepFinish 替代手动日志，用 result.steps 获取执行轨迹。SDK 覆盖了绝大多数场景，但自定义终止逻辑、步骤间状态管理、人机协作等高级需求仍可能需要手动循环。理解底层实现，才能在使用框架时准确判断其能力边界。
