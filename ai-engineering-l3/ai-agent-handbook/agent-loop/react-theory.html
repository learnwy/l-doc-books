ReAct 原理

从推理到行动

大语言模型擅长推理，但推理本身无法改变外部世界。Chain-of-Thought（CoT）让模型通过逐步思考提升推理质量，却仍然局限在纯文本空间内——模型无法验证自己的推理是否正确，也无法获取实时信息。ReAct（Reasoning + Acting）框架正是为了解决这一根本限制而提出的：让模型在推理的同时执行行动，用行动的结果来锚定和修正推理过程。

Yao et al. 在 2022 年的论文 "ReAct: Synergizing Reasoning and Acting in Language Models" 中首次提出了这一框架。核心观察是：人类在解决问题时从来不是先完成全部思考再行动，而是在思考与行动之间不断交替——查看信息、形成假设、执行操作、观察结果、调整计划。ReAct 将这一人类认知模式形式化为三段式循环。

Thought-Action-Observation 循环

ReAct 的每一轮迭代由三个阶段组成：





阶段
角色
说明





Thought
推理
模型分析当前状态，决定下一步做什么、为什么这样做




Action
行动
模型选择并调用一个外部工具，传入具体参数




Observation
观察
工具返回执行结果，成为下一轮推理的输入





这个循环会持续进行，直到模型判断任务已经完成（输出最终答案）或达到最大步数限制。




一个具体的 ReAct 轨迹
以"查询 Hono 框架最新版本并与 Express 对比性能"为例：


Thought 1: 用户需要 Hono 最新版本号，我需要先搜索获取这个信息。
Action 1: search("Hono framework latest version 2026")
Observation 1: Hono v4.7.2 发布于 2026-03-15...

Thought 2: 已获得版本号。接下来需要对比性能数据，搜索基准测试。
Action 2: search("Hono vs Express benchmark 2026")
Observation 2: 在 TechEmpower 基准测试中，Hono 请求/秒为 120k，Express 为 45k...

Thought 3: 已有足够信息，可以生成对比分析。
Action 3: finish("Hono 最新版本为 v4.7.2。性能对比：Hono 120k req/s vs Express 45k req/s，Hono 约快 2.7 倍...")
每一步的 Thought 都基于前一步的 Observation，形成了一条有依据的推理链。

为什么 ReAct 有效：行动锚定推理
ReAct 的核心优势在于 grounding——将推理锚定在真实的行动结果中。纯推理模式下，模型容易产生"幻觉"，因为没有外部信号来验证推理是否正确。ReAct 通过引入 Observation 打破了这一封闭循环：


每次 Observation 都是来自外部世界的真实反馈，它迫使模型在事实的基础上推理而非凭空猜测。这种机制带来三个关键好处：


    

  1. 事实校验 — 模型的每一步推理都可以被下一步的行动结果验证
    2. 

  2. 自我修正 — 当 Observation 与预期不符时，模型可以在 Thought 中调整策略
    3. 

  3. 可追溯性 — 完整的 Thought-Action-Observation 轨迹提供了透明的决策过程
    4. 





ReAct 与现代 Agent 架构的关系
在实际的 Agent 系统中，ReAct 模式通常不需要模型显式输出 "Thought: ..." 这样的文本标记。现代 LLM API 的 function calling 机制天然对应了 ReAct 的三个阶段：


interface ReActMapping {
  thought: '模型内部推理（隐含在生成过程中）';
  action: 'function_call / tool_use（API 结构化输出）';
  observation: 'tool_result（工具执行结果回填）';
}
AI SDK 的 generateText + tools + maxSteps 实质上就是 ReAct 循环的工程化实现。下一节将从零构建这个循环，让你深入理解每一个环节的实现细节。




小结
ReAct 框架将推理（Reasoning）和行动（Acting）统一到 Thought-Action-Observation 的三段式循环中。与 Chain-of-Thought 相比，ReAct 通过外部工具调用将推理锚定在真实数据上，有效减少幻觉；与 Plan-Execute 相比，ReAct 的逐步决策机制提供了更高的适应性。ReAct 的核心价值在于 grounding——每一步推理都有真实的 Observation 作为依据，形成可追溯、可验证的决策链。现代 LLM 的 function calling API 天然映射了 ReAct 的三个阶段，使得 ReAct 成为构建 AI Agent 最主流的运行模式。
