中间件链

横切关注点与中间件模式

Agent 的每一轮循环不仅仅是调用模型和执行工具。日志记录、速率限制、缓存、安全防护——这些横切关注点贯穿每一次模型调用。AI SDK 6 的 LanguageModelMiddleware 提供了洋葱式的中间件机制，允许在不修改核心逻辑的前提下灵活组合这些关注点。



LanguageModelMiddleware 接口
中间件通过 wrapGenerate 和 wrapStream 两个钩子拦截模型调用：


import type { LanguageModelMiddleware } from 'ai';

const exampleMiddleware: LanguageModelMiddleware = {
  wrapGenerate: async ({ doGenerate, params }) => {
    const result = await doGenerate();
    return result;
  },
  wrapStream: async ({ doStream, params }) => {
    const { stream, ...rest } = await doStream();
    return { stream, ...rest };
  },
};

日志中间件
import type { LanguageModelMiddleware } from 'ai';

const loggingMiddleware: LanguageModelMiddleware = {
  wrapGenerate: async ({ doGenerate, params }) => {
    const start = Date.now();
    console.log(`[LLM] 开始调用`);

    const result = await doGenerate();

    console.log(`[LLM] 完成`, {
      duration: `${Date.now() - start}ms`,
      finishReason: result.finishReason,
      usage: result.usage,
    });
    return result;
  },
};


速率限制中间件
基于滑动窗口限制调用频率，防止 API 配额耗尽：


import type { LanguageModelMiddleware } from 'ai';

function createRateLimitMiddleware(maxReq: number, windowMs: number): LanguageModelMiddleware {
  const timestamps: number[] = [];

  return {
    wrapGenerate: async ({ doGenerate }) => {
      const now = Date.now();
      while (timestamps.length > 0 && timestamps[0] < now - windowMs) {
        timestamps.shift();
      }
      if (timestamps.length >= maxReq) {
        const wait = timestamps[0] + windowMs - now;
        await new Promise((r) => setTimeout(r, wait));
      }
      timestamps.push(Date.now());
      return doGenerate();
    },
  };
}


缓存中间件
import type { LanguageModelMiddleware } from 'ai';

function createCacheMiddleware(ttlMs: number): LanguageModelMiddleware {
  const cache = new Map<string, { result: unknown; expiry: number }>();

  return {
    wrapGenerate: async ({ doGenerate, params }) => {
      const key = JSON.stringify(params.prompt);
      const cached = cache.get(key);

      if (cached && cached.expiry > Date.now()) {
        return cached.result as Awaited<ReturnType<typeof doGenerate>>;
      }

      const result = await doGenerate();
      cache.set(key, { result, expiry: Date.now() + ttlMs });

      if (cache.size > 1000) {
        cache.delete(cache.keys().next().value!);
      }
      return result;
    },
  };
}


安全防护中间件
import type { LanguageModelMiddleware } from 'ai';

const BLOCKED = [/ignore previous instructions/i, /system prompt/i];

const guardrailMiddleware: LanguageModelMiddleware = {
  wrapGenerate: async ({ doGenerate, params }) => {
    const text = params.prompt
      .filter((m) => m.role === 'user')
      .flatMap((m) => m.content.filter((p): p is { type: 'text'; text: string } => p.type === 'text'))
      .map((p) => p.text)
      .join(' ');

    for (const pattern of BLOCKED) {
      if (pattern.test(text)) throw new Error('输入触发安全规则，请求已拦截');
    }
    return doGenerate();
  },
};


中间件组合与执行顺序
使用 wrapLanguageModel 按顺序组合中间件——先注册的在最外层：


import { wrapLanguageModel } from 'ai';
import { openai } from '@ai-sdk/openai';

const enhancedModel = wrapLanguageModel({
  model: openai('gpt-4o'),
  middleware: [
    loggingMiddleware,
    createRateLimitMiddleware(10, 60_000),
    guardrailMiddleware,
    createCacheMiddleware(300_000),
  ],
});

增强后的模型直接用于 Agent 循环，每一步模型调用都经过完整中间件链：


import { generateText, tool } from 'ai';
import { z } from 'zod';

const result = await generateText({
  model: enhancedModel,
  system: '你是一个有用的助手',
  prompt: '北京和东京的温差是多少？',
  tools: {
    weather: tool({
      description: '获取城市天气',
      parameters: z.object({ city: z.string() }),
      execute: async ({ city }) => {
        const db: Record<string, number> = { 北京: 28, 东京: 32 };
        return { city, temp: db[city] ?? 20 };
      },
    }),
  },
  maxSteps: 5,
});


小结
AI SDK 6 的 LanguageModelMiddleware 通过 wrapGenerate 和 wrapStream 两个钩子提供洋葱式中间件机制。每个中间件只关注单一职责：日志记录耗时和 Token 用量，速率限制基于滑动窗口控制频率，缓存避免重复消耗，安全防护拦截有害内容。通过 wrapLanguageModel 按顺序组合到模型上，增强后的模型可直接用于 generateText，对 Agent 循环的每一步自动生效。推荐顺序：日志 → 速率限制 → 安全防护 → 缓存。
