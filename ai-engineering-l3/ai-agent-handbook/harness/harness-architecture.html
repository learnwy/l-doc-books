Harness 架构

从零散脚本到运行时外壳

单个 Agent 用 generateText + tools + maxSteps 就能跑起来。但一个生产级 Agent 系统需要管理多个模型提供者、动态工具注册、MCP 服务发现、记忆存储、中间件链、子 Agent 编排——这些能力散落在各处时，系统会迅速失控。Agent Harness 是统一的运行时外壳，它将所有组件纳入一个可配置、可观测、可扩展的容器中，类似 ByteDance DeerFlow 的 SuperAgent 架构。



核心接口定义
Harness 的核心是组件注册表和声明式配置。所有组件通过统一接口注册，运行时按需解析依赖：


import type { LanguageModel, CoreTool } from 'ai';

interface HarnessComponent {
  name: string;
  version: string;
  initialize(): Promise<void>;
  shutdown(): Promise<void>;
}

interface ModelProvider extends HarnessComponent {
  getModel(modelId: string): LanguageModel;
  listModels(): string[];
}

interface ToolProvider extends HarnessComponent {
  getTools(): Record<string, CoreTool>;
}

interface MemoryProvider extends HarnessComponent {
  store(key: string, value: unknown): Promise<void>;
  retrieve(key: string): Promise<unknown | null>;
}

interface HarnessConfig {
  models: ModelProvider[];
  tools: ToolProvider[];
  memory: MemoryProvider;
  middleware: HarnessMiddleware[];
  plugins: HarnessPlugin[];
  maxConcurrentAgents: number;
}


AgentHarness 实现
import { generateText, type CoreTool } from 'ai';

class AgentHarness {
  private registry = new Map<string, HarnessComponent>();
  private models = new Map<string, ModelProvider>();
  private tools: Record<string, CoreTool> = {};
  private middlewareChain: HarnessMiddleware[] = [];
  private state: HarnessState = 'created';

  constructor(private config: HarnessConfig) {}

  async initialize(): Promise<void> {
    this.state = 'initializing';

    for (const provider of this.config.models) {
      await provider.initialize();
      this.models.set(provider.name, provider);
      this.registry.set(`model:${provider.name}`, provider);
    }

    for (const provider of this.config.tools) {
      await provider.initialize();
      Object.assign(this.tools, provider.getTools());
      this.registry.set(`tool:${provider.name}`, provider);
    }

    await this.config.memory.initialize();
    this.registry.set('memory', this.config.memory);

    for (const plugin of this.config.plugins) {
      await plugin.install(this);
    }

    this.middlewareChain = [...this.config.middleware].sort((a, b) => a.priority - b.priority);

    this.state = 'ready';
  }

  async execute(task: AgentTask): Promise<AgentResult> {
    this.state = 'running';
    const context: ExecutionContext = {
      task,
      harness: this,
      tools: { ...this.tools },
      startTime: Date.now(),
      traceId: crypto.randomUUID(),
    };

    const handler = this.buildMiddlewareChain(context);
    return handler();
  }

  getModel(providerId: string, modelId: string): ReturnType<ModelProvider['getModel']> {
    const provider = this.models.get(providerId);
    if (!provider) throw new Error(`模型提供者 ${providerId} 未注册`);
    return provider.getModel(modelId);
  }

  getComponent<T extends HarnessComponent>(key: string): T {
    const component = this.registry.get(key);
    if (!component) throw new Error(`组件 ${key} 未注册`);
    return component as T;
  }

  async shutdown(): Promise<void> {
    this.state = 'shutting-down';
    const components = [...this.registry.values()].reverse();
    for (const component of components) {
      await component.shutdown();
    }
    this.state = 'terminated';
  }
}

插件系统
Harness 通过插件机制实现无侵入式扩展。插件在初始化阶段安装，可以注册新组件、添加中间件、挂载生命周期钩子：


interface HarnessPlugin {
  name: string;
  install(harness: AgentHarness): Promise<void>;
}

const mcpPlugin: HarnessPlugin = {
  name: 'mcp-discovery',
  install: async (harness) => {
    const mcpTools = await discoverMcpTools('http://localhost:3001');
    for (const [name, tool] of Object.entries(mcpTools)) {
      harness.registerTool(name, tool);
    }
  },
};

const memoryPlugin: HarnessPlugin = {
  name: 'persistent-memory',
  install: async (harness) => {
    harness.addMiddleware({
      name: 'memory-sync',
      priority: 100,
      before: async (ctx) => {
        ctx.memory = await harness.getComponent<MemoryProvider>('memory').retrieve(ctx.task.sessionId);
      },
      after: async (ctx, result) => {
        await harness.getComponent<MemoryProvider>('memory').store(ctx.task.sessionId, result.messages);
      },
    });
  },
};


声明式配置启动
const harness = new AgentHarness({
  models: [new OpenAIProvider({ apiKey: process.env.OPENAI_API_KEY! })],
  tools: [new BuiltinToolProvider(), new McpToolProvider('http://localhost:3001')],
  memory: new RedisMemoryProvider({ url: process.env.REDIS_URL! }),
  middleware: [loggingMiddleware, tracingMiddleware, rateLimitMiddleware],
  plugins: [mcpPlugin, memoryPlugin],
  maxConcurrentAgents: 5,
});

await harness.initialize();

const result = await harness.execute({
  sessionId: 'session-001',
  modelId: 'openai:gpt-4o',
  prompt: '分析最近的销售数据并生成报告',
});

await harness.shutdown();


小结
Agent Harness 是 Agent 系统的运行时外壳，通过组件注册表统一管理模型提供者、工具集、记忆存储和 MCP 服务。与单体 Agent 相比，Harness 架构将组件管理从硬编码变为声明式配置，将扩展方式从代码修改变为插件安装，将运行过程从黑盒变为全链路可观测。核心设计原则是：组件通过接口而非实现耦合，运行时通过注册表而非硬编码解析依赖，横切关注点通过中间件而非侵入式修改实现。这种架构使得 Agent 系统的每个部分都可以独立开发、测试和替换，为后续的生命周期管理、中间件编排和可观测性提供了坚实的基础设施。
