完整生命周期

为什么需要生命周期管理

一个生产级 Agent 系统不是"启动后永远运行"。它需要优雅地初始化资源、响应暂停恢复指令、在关闭时释放连接和持久化状态。没有明确的生命周期阶段定义，资源泄漏、状态不一致和关闭时数据丢失将成为常态。Harness 通过有限状态机管理完整的生命周期，每个状态转换都有明确的前置条件、执行动作和钩子回调。



状态定义与转换规则
type HarnessState =
  | 'created'
  | 'initializing'
  | 'ready'
  | 'running'
  | 'pausing'
  | 'paused'
  | 'resuming'
  | 'shutting-down'
  | 'failed'
  | 'terminated';

const VALID_TRANSITIONS: Record<HarnessState, HarnessState[]> = {
  created: ['initializing'],
  initializing: ['ready', 'failed'],
  ready: ['running', 'shutting-down'],
  running: ['pausing', 'shutting-down'],
  pausing: ['paused'],
  paused: ['resuming', 'shutting-down'],
  resuming: ['running'],
  'shutting-down': ['terminated'],
  failed: ['terminated'],
  terminated: [],
};

生命周期管理器实现
type LifecycleHook = (state: HarnessState) => Promise<void>;

class LifecycleManager {
  private state: HarnessState = 'created';
  private hooks = new Map<string, LifecycleHook[]>();
  private activeTaskCount = 0;

  async transition(target: HarnessState): Promise<void> {
    const allowed = VALID_TRANSITIONS[this.state];
    if (!allowed.includes(target)) {
      throw new Error(`非法状态转换: ${this.state} → ${target}`);
    }

    await this.fireHooks(`before:${target}`);
    const previous = this.state;
    this.state = target;
    await this.fireHooks(`after:${target}`);

    console.log(`[Lifecycle] ${previous} → ${target}`);
  }

  on(event: string, hook: LifecycleHook): void {
    const list = this.hooks.get(event) ?? [];
    list.push(hook);
    this.hooks.set(event, list);
  }

  private async fireHooks(event: string): Promise<void> {
    const hooks = this.hooks.get(event) ?? [];
    for (const hook of hooks) {
      await hook(this.state);
    }
  }

  get currentState(): HarnessState {
    return this.state;
  }

  trackTask(): () => void {
    this.activeTaskCount++;
    return () => {
      this.activeTaskCount--;
    };
  }

  get hasPendingTasks(): boolean {
    return this.activeTaskCount > 0;
  }
}


各阶段详解
初始化阶段
初始化按依赖顺序加载组件。任何组件失败都会触发已初始化组件的回滚：


async function initializeHarness(harness: AgentHarness, lifecycle: LifecycleManager): Promise<void> {
  await lifecycle.transition('initializing');
  const initialized: HarnessComponent[] = [];

  try {
    for (const component of harness.getComponents()) {
      await component.initialize();
      initialized.push(component);
    }
    await lifecycle.transition('ready');
  } catch (err) {
    for (const component of initialized.reverse()) {
      await component.shutdown().catch(() => {});
    }
    await lifecycle.transition('failed');
    throw err;
  }
}
暂停与恢复
暂停不会中断正在执行的 Agent 步骤，而是等待当前步骤到达安全点后停止接受新任务：


async function pauseHarness(lifecycle: LifecycleManager): Promise<void> {
  await lifecycle.transition('pausing');

  await waitUntil(() => !lifecycle.hasPendingTasks, {
    timeout: 30_000,
    interval: 100,
  });

  await lifecycle.transition('paused');
}

async function resumeHarness(lifecycle: LifecycleManager): Promise<void> {
  await lifecycle.transition('resuming');
  await lifecycle.transition('running');
}
优雅关闭
关闭阶段的核心是确保资源按初始化的逆序释放，且每个组件的关闭失败不影响其他组件：


async function shutdownHarness(harness: AgentHarness, lifecycle: LifecycleManager): Promise<void> {
  await lifecycle.transition('shutting-down');

  const timeout = setTimeout(() => {
    console.error('[Lifecycle] 关闭超时，强制终止');
    process.exit(1);
  }, 30_000);

  const components = harness.getComponents().reverse();
  for (const component of components) {
    try {
      await component.shutdown();
    } catch (err) {
      console.error(`[Lifecycle] ${component.name} 关闭失败:`, err);
    }
  }

  clearTimeout(timeout);
  await lifecycle.transition('terminated');
}


与 Hono 服务集成
import { Hono } from 'hono';

function createHarnessServer(harness: AgentHarness, lifecycle: LifecycleManager): Hono {
  const app = new Hono();

  app.get('/health', (c) => {
    const state = lifecycle.currentState;
    const healthy = state === 'ready' || state === 'running';
    return c.json({ state, healthy }, healthy ? 200 : 503);
  });

  app.post('/task', async (c) => {
    if (lifecycle.currentState !== 'running' && lifecycle.currentState !== 'ready') {
      return c.json({ error: `当前状态 ${lifecycle.currentState} 不可接受任务` }, 503);
    }
    const release = lifecycle.trackTask();
    try {
      const body = await c.req.json();
      const result = await harness.execute(body);
      return c.json(result);
    } finally {
      release();
    }
  });

  app.post('/pause', async (c) => {
    await pauseHarness(lifecycle);
    return c.json({ state: lifecycle.currentState });
  });

  app.post('/resume', async (c) => {
    await resumeHarness(lifecycle);
    return c.json({ state: lifecycle.currentState });
  });

  return app;
}


信号处理与进程级生命周期
function registerSignalHandlers(harness: AgentHarness, lifecycle: LifecycleManager): void {
  const shutdown = async (signal: string) => {
    console.log(`[Lifecycle] 收到 ${signal}，开始优雅关闭`);
    await shutdownHarness(harness, lifecycle);
    process.exit(0);
  };

  process.on('SIGTERM', () => shutdown('SIGTERM'));
  process.on('SIGINT', () => shutdown('SIGINT'));

  process.on('uncaughtException', async (err) => {
    console.error('[Lifecycle] 未捕获异常:', err);
    await shutdownHarness(harness, lifecycle);
    process.exit(1);
  });
}


小结
Harness 生命周期通过有限状态机管理十个阶段：created → initializing → ready → running → pausing → paused → resuming → running → shutting-down → terminated。每个状态转换都有严格的前置条件校验和 before/after 钩子回调。初始化阶段按依赖顺序加载组件并支持失败回滚，暂停阶段等待活跃任务到达安全点，优雅关闭按逆序释放资源并设置超时兜底。LifecycleManager 维护状态机和任务计数器，通过 /health 端点暴露健康状态，通过信号处理实现进程级生命周期管理。明确的生命周期是系统稳定运行的基本保障，也是实现零停机部署和热更新的前提条件。
