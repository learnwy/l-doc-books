可观测性与追踪

Agent 系统为什么难以调试

Agent 的一次执行可能包含多轮模型调用、多次工具执行、子 Agent 派发和记忆读写。当输出不符合预期时，仅靠 console.log 几乎无法定位问题出在哪一轮、哪一步。可观测性的三大支柱——日志（Logs）、追踪（Traces）、指标（Metrics）——为 Agent 系统提供了系统化的诊断能力。Harness 将这三者统一集成，为每次执行生成完整的观测数据。



结构化日志
Agent 系统的日志必须是结构化的 JSON 格式，而非自由文本。结构化日志可被日志系统索引和查询，便于在海量日志中快速定位特定执行：


interface AgentLogEntry {
  timestamp: string;
  level: 'debug' | 'info' | 'warn' | 'error';
  traceId: string;
  spanId: string;
  event: string;
  data: Record<string, unknown>;
}

class StructuredLogger {
  private traceId: string;

  constructor(traceId: string) {
    this.traceId = traceId;
  }

  log(level: AgentLogEntry['level'], event: string, data: Record<string, unknown> = {}): void {
    const entry: AgentLogEntry = {
      timestamp: new Date().toISOString(),
      level,
      traceId: this.traceId,
      spanId: crypto.randomUUID().slice(0, 8),
      event,
      data,
    };
    console.log(JSON.stringify(entry));
  }

  info(event: string, data?: Record<string, unknown>): void {
    this.log('info', event, data);
  }

  error(event: string, data?: Record<string, unknown>): void {
    this.log('error', event, data);
  }
}

分布式追踪
OpenTelemetry 为 Agent 的每次执行创建 Trace，每个步骤（模型调用、工具执行）作为子 Span。Span 之间的父子关系形成完整的调用树：


interface Span {
  traceId: string;
  spanId: string;
  parentSpanId: string | null;
  name: string;
  startTime: number;
  endTime?: number;
  attributes: Record<string, string | number | boolean>;
  status: 'ok' | 'error';
}

class TraceCollector {
  private spans: Span[] = [];
  private traceId: string;

  constructor(traceId: string) {
    this.traceId = traceId;
  }

  startSpan(name: string, parentSpanId: string | null = null): Span {
    const span: Span = {
      traceId: this.traceId,
      spanId: crypto.randomUUID().slice(0, 16),
      parentSpanId,
      name,
      startTime: Date.now(),
      attributes: {},
      status: 'ok',
    };
    this.spans.push(span);
    return span;
  }

  endSpan(span: Span, status: Span['status'] = 'ok'): void {
    span.endTime = Date.now();
    span.status = status;
  }

  getSpans(): Span[] {
    return [...this.spans];
  }
}


TracingMiddleware 实现
将追踪能力封装为 Harness 中间件，自动为每次执行创建 Trace 和 Span：


function createTracingMiddleware(): HarnessMiddleware {
  return {
    name: 'tracing',
    priority: 20,
    execute: async (ctx, next) => {
      const collector = new TraceCollector(ctx.traceId);
      const rootSpan = collector.startSpan('agent.execute');
      ctx.metadata.traceCollector = collector;
      ctx.metadata.rootSpan = rootSpan;

      for (const [name, tool] of Object.entries(ctx.tools)) {
        if ('execute' in tool && tool.execute) {
          const original = tool.execute;
          (tool as { execute: typeof original }).execute = async (args, options) => {
            const span = collector.startSpan(`tool.${name}`, rootSpan.spanId);
            span.attributes['tool.name'] = name;
            span.attributes['tool.args'] = JSON.stringify(args);
            try {
              const result = await original(args, options);
              collector.endSpan(span, 'ok');
              return result;
            } catch (err) {
              collector.endSpan(span, 'error');
              throw err;
            }
          };
        }
      }

      try {
        const result = await next();
        collector.endSpan(rootSpan, 'ok');
        result.traces = collector.getSpans();
        return result;
      } catch (err) {
        collector.endSpan(rootSpan, 'error');
        throw err;
      }
    },
  };
}


指标采集
MetricsCollector 记录 Agent 系统的关键运行指标，为容量规划和性能优化提供数据基础：


interface MetricEntry {
  name: string;
  value: number;
  labels: Record<string, string>;
  timestamp: number;
}

class MetricsCollector {
  private metrics: MetricEntry[] = [];

  record(name: string, value: number, labels: Record<string, string> = {}): void {
    this.metrics.push({ name, value, labels, timestamp: Date.now() });
  }

  flush(): MetricEntry[] {
    const batch = [...this.metrics];
    this.metrics = [];
    return batch;
  }
}

function createMetricsMiddleware(collector: MetricsCollector): HarnessMiddleware {
  return {
    name: 'metrics',
    priority: 25,
    execute: async (ctx, next) => {
      const start = Date.now();
      try {
        const result = await next();

        collector.record('agent.duration_ms', Date.now() - start, { status: 'success' });
        collector.record('agent.tokens_total', result.usage.totalTokens);
        collector.record('agent.tokens_prompt', result.usage.promptTokens);
        collector.record('agent.tokens_completion', result.usage.completionTokens);

        return result;
      } catch (err) {
        collector.record('agent.duration_ms', Date.now() - start, { status: 'error' });
        collector.record('agent.errors_total', 1, {
          error: err instanceof Error ? err.message : 'unknown',
        });
        throw err;
      }
    },
  };
}

观测数据暴露
通过 Hono 路由暴露观测端点，供 Dashboard 和监控系统消费：


import { Hono } from 'hono';

function createObservabilityRoutes(collector: MetricsCollector): Hono {
  const app = new Hono();

  app.get('/metrics', (c) => {
    const metrics = collector.flush();
    return c.json({ metrics });
  });

  app.get('/traces/:traceId', async (c) => {
    const traceId = c.req.param('traceId');
    const spans = await loadSpansByTraceId(traceId);
    return c.json({ traceId, spans });
  });

  app.get('/dashboard', (c) => {
    return c.json({
      avgLatency: '计算自 agent.duration_ms',
      tokenUsage: '聚合自 agent.tokens_total',
      errorRate: 'agent.errors_total / 总请求数',
      toolCallDistribution: '按 tool.name 分组的调用次数',
    });
  });

  return app;
}


小结
可观测性是 Agent 系统从原型走向生产的必备能力。结构化日志将自由文本转为可索引的 JSON 格式，通过 traceId 关联同一次执行的所有日志条目。分布式追踪通过 TraceCollector 为每次执行创建 Span 树，精确记录每轮模型调用和工具执行的耗时与状态。指标采集通过 MetricsCollector 持续记录延迟、Token 用量、错误率等关键运行指标。三者均封装为 Harness 中间件，通过 MiddlewareChain 无侵入式接入。观测数据通过 /metrics 和 /traces/:traceId 端点暴露，供可视化面板和告警系统消费。完善的可观测性不仅服务于调试，更是持续优化 Agent 表现、控制成本和保障 SLA 的数据基础。
