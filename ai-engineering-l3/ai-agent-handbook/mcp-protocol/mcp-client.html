实现 MCP Client

Client 的职责

MCP Client 负责与 MCP Server 建立连接、发现可用工具、调用工具并获取结果。在 Agent 架构中，Client 是连接 LLM 推理层和 MCP 工具层的桥梁。



创建 Client 实例
使用 @modelcontextprotocol/sdk 的 Client 类建立连接。connect() 内部完成完整握手：发送 initialize、接收服务器能力、发送 initialized 通知。


import { Client } from '@modelcontextprotocol/sdk/client/index.js';
import { StdioClientTransport } from '@modelcontextprotocol/sdk/client/stdio.js';

async function createMCPClient(command: string, args: string[]) {
  const transport = new StdioClientTransport({ command, args });
  const client = new Client({ name: 'hono-agent', version: '1.0.0' });
  await client.connect(transport);
  return client;
}


工具发现与调用
连接建立后，通过 listTools() 获取工具列表，通过 callTool() 执行调用：


async function discoverTools(client: Client) {
  const { tools } = await client.listTools();
  return tools.map((tool) => ({
    name: tool.name,
    description: tool.description ?? '',
    inputSchema: tool.inputSchema,
  }));
}

async function callTool(client: Client, name: string, args: Record<string, unknown>) {
  const result = await client.callTool({ name, arguments: args });
  const textContent = result.content
    .filter((c): c is { type: 'text'; text: string } => c.type === 'text')
    .map((c) => c.text)
    .join('\n');
  return { content: textContent, isError: result.isError ?? false };
}


转换为 AI SDK 工具格式
MCP 工具的参数是 JSON Schema 格式，AI SDK 的 tool() 默认接受 zod schema。jsonSchema() 桥接了这个差异：


import { tool, jsonSchema } from 'ai';
import type { Client } from '@modelcontextprotocol/sdk/client/index.js';

function mcpToolsToAISDK(
  client: Client,
  mcpTools: Array<{
    name: string;
    description: string;
    inputSchema: Record<string, unknown>;
  }>,
) {
  const tools: Record<string, ReturnType<typeof tool>> = {};

  for (const mcpTool of mcpTools) {
    tools[mcpTool.name] = tool({
      description: mcpTool.description,
      parameters: jsonSchema(mcpTool.inputSchema),
      execute: async (args) => {
        const result = await client.callTool({
          name: mcpTool.name,
          arguments: args as Record<string, unknown>,
        });
        const text = result.content
          .filter((c): c is { type: 'text'; text: string } => c.type === 'text')
          .map((c) => c.text)
          .join('\n');
        if (result.isError) throw new Error(text);
        return text;
      },
    });
  }

  return tools;
}


集成到 Hono Agent
将 MCP Client 集成到 Hono 后端，实现完整的工具发现和调用流程：


import { Hono } from 'hono';
import { streamText } from 'ai';
import { openai } from '@ai-sdk/openai';

const app = new Hono();

let mcpClient: Client | null = null;
let aiTools: Record<string, ReturnType<typeof tool>> = {};

async function initMCP() {
  const transport = new StdioClientTransport({
    command: 'node',
    args: ['./mcp-servers/fs-server/dist/index.js'],
  });
  mcpClient = new Client({ name: 'hono-agent', version: '1.0.0' });
  await mcpClient.connect(transport);

  const mcpTools = await discoverTools(mcpClient);
  aiTools = mcpToolsToAISDK(mcpClient, mcpTools);
  console.log(`已加载 ${Object.keys(aiTools).length} 个 MCP 工具`);
}

app.post('/api/chat', async (c) => {
  const { messages } = await c.req.json();
  const result = streamText({
    model: openai('gpt-4o'),
    messages,
    tools: aiTools,
    maxSteps: 10,
  });
  return result.toDataStreamResponse();
});

initMCP().then(() => console.log('MCP 初始化完成'));

export default app;


连接管理与清理
MCP Client 需要妥善管理连接生命周期，在应用关闭时释放子进程资源：


class MCPConnection {
  private client: Client;
  private connected = false;

  constructor(private name: string) {
    this.client = new Client({ name: 'hono-agent', version: '1.0.0' });
  }

  async connect(transport: StdioClientTransport) {
    await this.client.connect(transport);
    this.connected = true;
  }

  async disconnect() {
    if (this.connected) {
      await this.client.close();
      this.connected = false;
    }
  }

  getClient() {
    if (!this.connected) throw new Error(`${this.name} 未连接`);
    return this.client;
  }
}

process.on('SIGINT', async () => {
  await connection.disconnect();
  process.exit(0);
});


小结
    

  • MCP Client 通过 @modelcontextprotocol/sdk 的 Client 类创建，connect() 方法自动完成协议握手。
    • 

  • listTools() 发现 Server 暴露的工具，callTool() 执行工具调用。
    • 

  • 使用 jsonSchema() 将 MCP 的 JSON Schema 参数转换为 AI SDK 兼容格式，通过 tool() 包装后传给 streamText。
    • 

  • 支持 stdio（本地进程）和 SSE（远程 HTTP）两种传输方式连接 Server。
    • 

  • 连接生命周期需要显式管理：应用启动时初始化，关闭时调用 close() 释放资源。
