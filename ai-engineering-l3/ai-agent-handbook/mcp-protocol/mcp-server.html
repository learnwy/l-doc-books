实现 MCP Server

Server 架构概览

MCP Server 是一个独立运行的进程，通过 MCP 协议向 Client 暴露工具、资源和提示模板。使用 @modelcontextprotocol/sdk 可以快速构建 TypeScript MCP Server。



项目初始化
创建一个文件系统 MCP Server 项目：


mkdir mcp-fs-server && cd mcp-fs-server
npm init -y
npm install @modelcontextprotocol/sdk zod
npm install -D typescript @types/node
npx tsc --init --target ES2022 --module NodeNext --moduleResolution NodeNext --outDir dist
在 package.json 中配置入口：


{
  "name": "mcp-fs-server",
  "version": "1.0.0",
  "type": "module",
  "bin": { "mcp-fs-server": "./dist/index.js" },
  "scripts": { "build": "tsc", "start": "node dist/index.js" }
}


注册工具
使用 server.tool() 方法注册工具。每个工具需要名称、描述、参数 Schema 和执行函数：


import { McpServer } from '@modelcontextprotocol/sdk/server/mcp.js';
import { z } from 'zod';
import { readFile, writeFile, readdir } from 'fs/promises';
import { resolve } from 'path';

const BASE_DIR = resolve(process.env.MCP_BASE_DIR ?? process.cwd());
const server = new McpServer({ name: 'fs-server', version: '1.0.0' });

function safePath(inputPath: string): string {
  const resolved = resolve(BASE_DIR, inputPath);
  if (!resolved.startsWith(BASE_DIR)) {
    throw new Error(`路径越界: ${inputPath}`);
  }
  return resolved;
}

server.tool('readFile', '读取指定路径的文件内容', { path: z.string().describe('文件的相对路径') }, async ({ path }) => {
  const content = await readFile(safePath(path), 'utf-8');
  return { content: [{ type: 'text', text: content }] };
});

server.tool(
  'writeFile',
  '将内容写入指定路径的文件',
  {
    path: z.string().describe('文件的相对路径'),
    content: z.string().describe('要写入的文件内容'),
  },
  async ({ path, content }) => {
    await writeFile(safePath(path), content, 'utf-8');
    return { content: [{ type: 'text', text: `已写入 ${path}` }] };
  },
);

server.tool(
  'listFiles',
  '列出指定目录下的文件和子目录',
  { path: z.string().default('.').describe('目录的相对路径') },
  async ({ path: dirPath }) => {
    const entries = await readdir(safePath(dirPath), { withFileTypes: true });
    const items = entries.map((e) => ({
      name: e.name,
      type: e.isDirectory() ? 'directory' : 'file',
    }));
    return { content: [{ type: 'text', text: JSON.stringify(items, null, 2) }] };
  },
);


暴露资源
资源让 Client 可以读取服务器管理的数据。与工具不同，资源是被动读取的，不产生副作用：


import { join } from 'path';

server.resource('project-config', 'config://package.json', async (uri) => {
  const content = await readFile(join(BASE_DIR, 'package.json'), 'utf-8');
  return {
    contents: [{ uri: uri.href, mimeType: 'application/json', text: content }],
  };
});


连接传输层
stdio 模式适合本地工具，SSE 模式适合远程服务：


import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';

async function main() {
  const transport = new StdioServerTransport();
  await server.connect(transport);
  console.error('[fs-server] MCP Server 已启动（stdio 模式）');
}

main().catch(console.error);
SSE 模式与 Hono 集成：


import { Hono } from 'hono';
import { SSEServerTransport } from '@modelcontextprotocol/sdk/server/sse.js';
import { serve } from '@hono/node-server';

const app = new Hono();
let sseTransport: SSEServerTransport | null = null;

app.get('/sse', async (c) => {
  sseTransport = new SSEServerTransport('/messages', c.res);
  await server.connect(sseTransport);
  return c.body(null);
});

app.post('/messages', async (c) => {
  if (!sseTransport) return c.json({ error: '未建立 SSE 连接' }, 400);
  await sseTransport.handlePostMessage(await c.req.json());
  return c.json({ ok: true });
});

serve({ fetch: app.fetch, port: 3001 });


测试 Server
使用 MCP Inspector 工具验证 Server 是否正常工作：


npm run build
npx @modelcontextprotocol/inspector node dist/index.js
也可以在 Claude Desktop 或 Cursor 的配置文件中直接注册：


{
  "mcpServers": {
    "fs-server": {
      "command": "node",
      "args": ["/path/to/mcp-fs-server/dist/index.js"],
      "env": { "MCP_BASE_DIR": "/path/to/workspace" }
    }
  }
}


小结
    

  • MCP Server 通过 @modelcontextprotocol/sdk 的 McpServer 类创建，自动处理协议握手和能力协商。
    • 

  • 使用 server.tool() 注册工具，每个工具包含名称、描述、zod 参数 Schema 和异步执行函数。
    • 

  • 使用 server.resource() 暴露只读数据资源，Client 通过 URI 访问。
    • 

  • 传输层支持 StdioServerTransport（本地进程）和 SSEServerTransport（HTTP 远程），可与 Hono 集成。
    • 

  • 路径安全校验（safePath）是文件系统 Server 的必要防护，防止路径遍历攻击。
