速率限制与成本

为什么需要速率限制与成本控制

LLM API 按 token 计费，单次请求可能消耗数千 token。没有速率限制，突发流量会触发上游 429 错误；没有成本追踪，一次 prompt 注入攻击就可能消耗掉整月预算。生产 Agent 必须在请求入口实施流控，在响应出口统计成本。



令牌桶算法
令牌桶是最常用的限流算法：桶以固定速率填充令牌，每次请求消耗一个令牌。桶满时多余令牌丢弃，桶空时请求被拒绝。天然支持突发流量——桶中积累的令牌允许短时间内的请求峰值。


class TokenBucketLimiter {
  private tokens: number;
  private lastRefill: number;

  constructor(
    private capacity: number,
    private refillRate: number,
  ) {
    this.tokens = capacity;
    this.lastRefill = Date.now();
  }

  private refill(): void {
    const now = Date.now();
    const elapsed = (now - this.lastRefill) / 1000;
    this.tokens = Math.min(this.capacity, this.tokens + elapsed * this.refillRate);
    this.lastRefill = now;
  }

  consume(count: number = 1): boolean {
    this.refill();
    if (this.tokens >= count) {
      this.tokens -= count;
      return true;
    }
    return false;
  }

  getRemaining(): number {
    this.refill();
    return Math.floor(this.tokens);
  }
}


滑动窗口限流
滑动窗口按时间段统计请求数，比固定窗口更平滑。适合对每用户、每 API Key 做精细化限制：


class SlidingWindowLimiter {
  private timestamps: Map<string, number[]> = new Map();

  constructor(
    private windowMs: number,
    private maxRequests: number,
  ) {}

  isAllowed(key: string): boolean {
    const now = Date.now();
    const windowStart = now - this.windowMs;

    const entries = this.timestamps.get(key) ?? [];
    const valid = entries.filter((t) => t > windowStart);

    if (valid.length >= this.maxRequests) {
      this.timestamps.set(key, valid);
      return false;
    }

    valid.push(now);
    this.timestamps.set(key, valid);
    return true;
  }

  getRemainingRequests(key: string): number {
    const now = Date.now();
    const entries = this.timestamps.get(key) ?? [];
    const valid = entries.filter((t) => t > now - this.windowMs);
    return Math.max(0, this.maxRequests - valid.length);
  }
}


Hono 限流中间件
将限流器集成为 Hono 中间件，对所有 AI 路由生效：


import { Hono } from 'hono';
import type { MiddlewareHandler } from 'hono';

function rateLimitMiddleware(limiter: SlidingWindowLimiter): MiddlewareHandler {
  return async (c, next) => {
    const key = c.req.header('x-api-key') ?? c.req.header('x-forwarded-for') ?? 'anonymous';

    if (!limiter.isAllowed(key)) {
      const remaining = limiter.getRemainingRequests(key);
      c.header('X-RateLimit-Remaining', String(remaining));
      c.header('Retry-After', '60');
      return c.json({ error: '请求过于频繁，请稍后重试' }, 429);
    }

    c.header('X-RateLimit-Remaining', String(limiter.getRemainingRequests(key)));
    await next();
  };
}

const app = new Hono();
const limiter = new SlidingWindowLimiter(60_000, 30);

app.use('/api/*', rateLimitMiddleware(limiter));


成本追踪
每次 LLM 调用后记录 token 用量，按模型定价计算实际成本。当累计成本逼近预算时触发告警：


interface UsageRecord {
  model: string;
  promptTokens: number;
  completionTokens: number;
  cost: number;
  timestamp: number;
}

const MODEL_PRICING: Record<string, { prompt: number; completion: number }> = {
  'gpt-4o': { prompt: 2.5, completion: 10.0 },
  'gpt-4o-mini': { prompt: 0.15, completion: 0.6 },
  'claude-sonnet-4-20250514': { prompt: 3.0, completion: 15.0 },
};

class CostTracker {
  private records: UsageRecord[] = [];
  private budgetUsd: number;
  private alertThreshold: number;

  constructor(budgetUsd: number, alertThreshold: number = 0.8) {
    this.budgetUsd = budgetUsd;
    this.alertThreshold = alertThreshold;
  }

  record(model: string, promptTokens: number, completionTokens: number): UsageRecord {
    const pricing = MODEL_PRICING[model] ?? { prompt: 1.0, completion: 2.0 };
    const cost = (promptTokens / 1_000_000) * pricing.prompt + (completionTokens / 1_000_000) * pricing.completion;

    const entry: UsageRecord = {
      model,
      promptTokens,
      completionTokens,
      cost,
      timestamp: Date.now(),
    };

    this.records.push(entry);
    this.checkBudget();
    return entry;
  }

  private checkBudget(): void {
    const total = this.getTotalCost();
    const ratio = total / this.budgetUsd;

    if (ratio >= 1.0) {
      console.error(`[Cost] 预算已耗尽！当前 $${total.toFixed(4)} / $${this.budgetUsd}`);
    } else if (ratio >= this.alertThreshold) {
      console.warn(`[Cost] 预算使用 ${(ratio * 100).toFixed(1)}%`);
    }
  }

  getTotalCost(): number {
    return this.records.reduce((sum, r) => sum + r.cost, 0);
  }

  isOverBudget(): boolean {
    return this.getTotalCost() >= this.budgetUsd;
  }

  getStats(): { totalCost: number; totalRequests: number; byModel: Record<string, number> } {
    const byModel: Record<string, number> = {};
    for (const r of this.records) {
      byModel[r.model] = (byModel[r.model] ?? 0) + r.cost;
    }
    return {
      totalCost: this.getTotalCost(),
      totalRequests: this.records.length,
      byModel,
    };
  }
}

成本仪表盘路由
const costTracker = new CostTracker(100);

app.get('/api/cost/dashboard', (c) => {
  const stats = costTracker.getStats();
  return c.json({
    budget: 100,
    ...stats,
    budgetUsage: `${((stats.totalCost / 100) * 100).toFixed(1)}%`,
  });
});

app.use('/api/chat', async (c, next) => {
  if (costTracker.isOverBudget()) {
    return c.json({ error: '月度预算已耗尽' }, 402);
  }
  await next();
});


小结
    

  • 令牌桶算法天然支持突发流量，适合全局 API 限流；滑动窗口按时间段精确统计，适合按用户维度控制。
    • 

  • Hono 中间件在请求入口统一拦截，通过 X-RateLimit-Remaining 和 Retry-After 头部向客户端传达限流状态。
    • 

  • CostTracker 按模型定价实时计算每次请求成本，累计消耗逼近预算时自动触发告警。
    • 

  • 成本仪表盘路由提供总消耗、请求次数、按模型分布等数据，支持运维监控。
    • 

  • 预算耗尽时直接返回 402，从源头阻断成本溢出。
