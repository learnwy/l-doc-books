错误处理与重试

生产环境中的失败现实

AI Agent 调用外部 LLM API 时，网络超时、速率限制、模型服务不可用是常态而非例外。生产系统必须在每个环节植入容错机制：重试策略应对瞬时故障，熔断器防止雪崩效应，降级模型保障服务可用，死信队列兜底不可恢复的任务。



重试策略：指数退避与抖动
核心原则：每次重试间隔按指数增长，附加随机抖动避免多个客户端同步重试导致的"惊群效应"。


interface RetryConfig {
  maxRetries: number;
  baseDelay: number;
  maxDelay: number;
  jitterFactor: number;
}

class RetryPolicy {
  private config: RetryConfig;

  constructor(config: Partial<RetryConfig> = {}) {
    this.config = {
      maxRetries: 3,
      baseDelay: 1000,
      maxDelay: 30000,
      jitterFactor: 0.5,
      ...config,
    };
  }

  calculateDelay(attempt: number): number {
    const exponential = this.config.baseDelay * Math.pow(2, attempt);
    const capped = Math.min(exponential, this.config.maxDelay);
    const jitter = capped * this.config.jitterFactor * Math.random();
    return capped + jitter;
  }

  async execute<T>(fn: () => Promise<T>): Promise<T> {
    let lastError: Error | undefined;

    for (let attempt = 0; attempt <= this.config.maxRetries; attempt++) {
      try {
        return await fn();
      } catch (err) {
        lastError = err instanceof Error ? err : new Error(String(err));

        if (attempt === this.config.maxRetries) break;
        if (!this.isRetryable(lastError)) break;

        const delay = this.calculateDelay(attempt);
        console.log(`[Retry] 第 ${attempt + 1} 次重试，等待 ${delay}ms`);
        await new Promise((r) => setTimeout(r, delay));
      }
    }

    throw lastError;
  }

  private isRetryable(error: Error): boolean {
    const retryablePatterns = ['429', '503', 'ECONNRESET', 'ETIMEDOUT'];
    return retryablePatterns.some((p) => error.message.includes(p));
  }
}


熔断器：防止级联故障
当目标服务持续失败时，熔断器自动"断路"，跳过实际调用直接返回错误，避免无意义的等待和资源消耗。经过冷却期后进入半开状态，允许少量请求试探服务是否恢复。


type CircuitState = 'closed' | 'open' | 'half-open';

class CircuitBreaker {
  private state: CircuitState = 'closed';
  private failureCount = 0;
  private lastFailureTime = 0;
  private successCount = 0;

  constructor(
    private failureThreshold: number = 5,
    private cooldownMs: number = 60000,
    private halfOpenMax: number = 3,
  ) {}

  async call<T>(fn: () => Promise<T>): Promise<T> {
    if (this.state === 'open') {
      if (Date.now() - this.lastFailureTime > this.cooldownMs) {
        this.state = 'half-open';
        this.successCount = 0;
      } else {
        throw new Error('CircuitBreaker is OPEN');
      }
    }

    try {
      const result = await fn();
      this.onSuccess();
      return result;
    } catch (err) {
      this.onFailure();
      throw err;
    }
  }

  private onSuccess(): void {
    if (this.state === 'half-open') {
      this.successCount++;
      if (this.successCount >= this.halfOpenMax) {
        this.state = 'closed';
        this.failureCount = 0;
      }
    } else {
      this.failureCount = 0;
    }
  }

  private onFailure(): void {
    this.failureCount++;
    this.lastFailureTime = Date.now();
    if (this.failureCount >= this.failureThreshold) {
      this.state = 'open';
    }
  }

  getState(): CircuitState {
    return this.state;
  }
}


降级模型：多模型容错链
当主模型不可用时，自动切换到备选模型，确保服务不中断。按优先级排列的模型链是生产 Agent 的标准实践。


import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';
import { anthropic } from '@ai-sdk/anthropic';
import type { LanguageModel, CoreMessage } from 'ai';

interface FallbackModel {
  provider: string;
  model: LanguageModel;
}

const modelChain: FallbackModel[] = [
  { provider: 'openai', model: openai('gpt-4o') },
  { provider: 'anthropic', model: anthropic('claude-sonnet-4-20250514') },
  { provider: 'openai', model: openai('gpt-4o-mini') },
];

async function generateWithFallback(
  messages: CoreMessage[],
  system: string,
): Promise<{ text: string; provider: string }> {
  const retry = new RetryPolicy({ maxRetries: 2 });

  for (const { provider, model } of modelChain) {
    try {
      const result = await retry.execute(() => generateText({ model, messages, system, maxSteps: 1 }));
      return { text: result.text, provider };
    } catch (err) {
      console.warn(`[Fallback] ${provider} 失败，尝试下一个模型`);
    }
  }

  return { text: '服务暂时不可用，请稍后重试。', provider: 'fallback' };
}


死信队列：兜底不可恢复任务
所有模型均失败后，将任务写入死信队列（DLQ），由后台任务定期重试或交给人工处理：


interface DeadLetterEntry {
  id: string;
  task: { messages: CoreMessage[]; system: string };
  error: string;
  attempts: number;
  createdAt: number;
}

class DeadLetterQueue {
  private queue: DeadLetterEntry[] = [];

  push(task: DeadLetterEntry['task'], error: string, attempts: number): string {
    const id = crypto.randomUUID();
    this.queue.push({ id, task, error, attempts, createdAt: Date.now() });
    console.error(`[DLQ] 任务 ${id} 进入死信队列: ${error}`);
    return id;
  }

  async processQueue(handler: (entry: DeadLetterEntry) => Promise<boolean>): Promise<void> {
    const pending = [...this.queue];
    for (const entry of pending) {
      const success = await handler(entry);
      if (success) {
        this.queue = this.queue.filter((e) => e.id !== entry.id);
      }
    }
  }

  size(): number {
    return this.queue.length;
  }
}


在 Hono 路由中整合
import { Hono } from 'hono';

const app = new Hono();
const breaker = new CircuitBreaker(5, 60000);
const dlq = new DeadLetterQueue();

app.post('/api/chat', async (c) => {
  const { messages, system } = await c.req.json();

  try {
    const result = await breaker.call(() => generateWithFallback(messages, system));
    return c.json({ text: result.text, provider: result.provider });
  } catch (err) {
    const error = err instanceof Error ? err.message : 'Unknown error';
    const taskId = dlq.push({ messages, system }, error, 0);
    return c.json({ error: '服务暂时不可用', taskId }, 503);
  }
});

app.get('/api/dlq/stats', (c) => {
  return c.json({ pending: dlq.size() });
});


小结
    

  • 重试策略采用指数退避加随机抖动，避免惊群效应，RetryPolicy 类封装延迟计算和可重试判断。
    • 

  • 熔断器通过关闭→打开→半开三态转换，在服务持续故障时快速失败，冷却后自动试探恢复。
    • 

  • 降级模型链按优先级依次尝试 GPT-4o → Claude → GPT-4o-mini，确保至少一个模型能响应。
    • 

  • 死信队列收集所有模型均失败的任务，支持后台批量重试或人工介入。
    • 

  • Hono 路由层将重试、熔断、降级、死信队列串联，形成完整的生产容错链路。
