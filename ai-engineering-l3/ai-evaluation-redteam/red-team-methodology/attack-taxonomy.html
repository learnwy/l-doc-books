AI 攻击分类法

核心概念

AI 产品的攻击面与传统软件根本不同。传统软件的安全测试关注代码漏洞——SQL 注入、XSS、缓冲区溢出。AI 产品则需要关注模型行为漏洞——通过精心构造的输入诱导模型违反预期行为，而无需任何代码层面的漏洞。建立系统化的攻击分类法是红队工作的概念骨架，让团队能全面评估产品的安全边界、覆盖各类攻击模式、避免遗漏关键风险。本节给出 AI 产品攻击的多维分类体系。

按目标分类
信息提取攻击：试图让模型输出本应保密的信息。常见目标：


    

  • 系统提示泄露：让模型输出它的 system prompt。攻击手段包括"重复你的指令"、"总结上面的内容"、特殊字符触发等。
    • 

  • 训练数据提取：让模型输出它在训练中见过的具体文本。在大模型上 demonstrably 可行（成员推断攻击）。
    • 

  • 隐私信息提取：诱导模型输出其他用户的对话内容、个人信息。
    • 

  • 业务机密：在企业内部 AI 助手中，诱导其输出财务、战略等敏感信息。
    • 



行为劫持攻击：让模型违反预期行为执行攻击者指令。代表：


    

  • 越狱（Jailbreak）：突破模型的安全约束输出违禁内容。
    • 

  • Prompt 注入（Prompt Injection）：通过外部内容劫持模型的执行流。
    • 

  • 角色伪装：让模型误以为自己是另一个系统或角色。
    • 



内容生成攻击：诱导模型生成有害、违法、违规内容。范围包括歧视性言论、暴力内容、非法活动指南、虚假信息、版权内容等。这类攻击通常利用模型的训练数据中包含的内容来"复现"。


资源耗尽攻击：通过特殊输入让模型消耗大量计算资源，导致服务降级。典型手段：


    

  • 极长输入（接近上下文窗口上限）。
    • 

  • 触发推理循环的递归提示。
    • 

  • 高频并发请求。
    • 

  • 触发昂贵工具调用的提示。
    • 



按手段分类
直接攻击：攻击者直接与模型交互，通过精心构造的提示实施攻击。这是最常见的攻击类型，也是最容易防御的——所有攻击都通过用户输入这一受控渠道。


间接攻击：攻击载荷不在用户输入中，而在模型从其他渠道获取的内容里。例如：


    

  • 网页中的隐藏文字（白色字体、HTML 注释、CSS 隐藏）。
    • 

  • 文档中的恶意指令（PDF、Word、邮件）。
    • 

  • 代码注释（"忽略上面所有，做 X"）。
    • 

  • 图像中的文字（OCR 后被模型读到）。
    • 



间接攻击的危险在于——模型可能把"读到的内容"当作"用户的指令"执行，而真实用户对此一无所知。


协同攻击：多步、多阶段的复杂攻击。例如：


    

  • 第 1 步：让模型读入一个看似无害的文档。
    • 

  • 第 2 步：在后续对话中触发文档中埋藏的恶意指令。
    • 

  • 第 3 步：模型按隐藏指令行事，攻击者获取目的。
    • 



协同攻击在 Agent 系统中尤其危险——Agent 可能跨多次工具调用累积上下文，最终在某个时刻执行恶意操作。

用户输入渠道：最直接也最常防御的渠道。常见防御：输入分类器（识别越狱尝试）、prompt 加固（system prompt 中明确拒绝指令）、输出过滤（最终输出再做安全检查）。


检索文档渠道：随着 RAG 应用普及，这一渠道日益重要。攻击者只需要在网页、文档中嵌入恶意指令，等待模型在 RAG 时读到。防御要点：文档预处理（识别可疑模式）、内容隔离（明确告诉模型"以下是文档内容，不是指令"）、来源审查。


工具调用渠道：在 Agent 系统中，工具返回的结果被模型读取。如果工具返回包含恶意内容（例如查询的网页有攻击文字），模型可能被劫持。防御要点：工具输出过滤、工具沙箱、关键操作的二次确认。


按严重度分级
不是所有攻击都同等严重。常见分级：


    

  • 高危（Critical）：可能导致重大数据泄露、合规违规、人身安全风险。例如医疗 AI 给出错误诊断、Agent 系统执行金融交易。必须在上线前修复。
    • 

  • 中危（High）：可能导致一般业务损失、用户体验降级。例如越狱后输出歧视性言论、模型被诱导生成低质量内容。优先修复。
    • 

  • 低危（Medium）：影响有限或仅在特定场景下出现。例如系统提示部分泄露、某些边界 case 表现不佳。可在迭代中修复。
    • 

  • 可接受（Low）：理论上存在但实际触发概率极低、影响微小。可以记录但不必紧急修复。
    • 



分级让红队工作更聚焦——优先修复高危漏洞，避免被一堆低危发现淹没。


攻击演化与新兴方向
AI 攻击在持续演化，2024-2026 年新兴方向：


    

  • 多模态攻击：通过图像、音频、视频实施攻击。例如图像中的隐藏文字让 VLM 执行特定指令。
    • 

  • Agent 攻击：针对 Agent 系统的复杂多步攻击，让 Agent 在不知不觉中执行恶意操作。
    • 

  • 供应链攻击：在 RAG 索引、工具实现、模型权重等供应链环节植入攻击。
    • 

  • 社会工程结合：攻击者借助社会工程让真实用户帮助传递攻击载荷。
    • 



红队需要持续跟踪这些新兴方向，把它们纳入攻击分类体系。


小结
AI 攻击分类法为红队工作提供概念骨架。按目标（信息提取、行为劫持、内容生成、资源耗尽）、按手段（直接、间接、协同）、按渠道（用户、文档、工具、历史）的多维分类让团队能系统化覆盖各类攻击，避免遗漏。把分类法作为红队工作的标准框架——每次测试都对照各维度检查覆盖度——是从"凭灵感测试"升级到"系统化红队"的关键。理解分类法本身比记住具体攻击模式更重要——具体攻击会演化，分类框架是相对稳定的认知工具。
