文档分块策略

为什么分块很重要

分块（Chunking）是将长文档切分为适合嵌入和检索的小片段的过程。分块策略直接影响检索精度——切得太大会引入噪声，切得太小会丢失上下文。



固定大小分块
最简单的策略是按固定字符数或 token 数切分，通常加入重叠（overlap）以保留边界上下文：


def fixed_size_chunking(text, chunk_size=500, overlap=50):
    chunks = []
    start = 0
    while start < len(text):
        end = start + chunk_size
        chunk = text[start:end]
        chunks.append({
            "content": chunk,
            "start": start,
            "end": min(end, len(text)),
        })
        start += chunk_size - overlap
    return chunks

sample_text = "这是一段示例文本。" * 100
chunks = fixed_size_chunking(sample_text, chunk_size=200, overlap=30)
print(f"文本长度: {len(sample_text)}")
print(f"块数量: {len(chunks)}")
print(f"第一块长度: {len(chunks[0]['content'])}")
print(f"重叠示例: 块1尾部 = '...{chunks[0]['content'][-20:]}'")
print(f"         块2头部 = '{chunks[1]['content'][:20]}...'")

递归分块
递归分块（Recursive Chunking）按文档结构逐层分割，优先使用高级分隔符（如段落），只在块过大时才使用低级分隔符（如句子）：


def recursive_chunking(text, chunk_size=500, separators=None):
    if separators is None:
        separators = ["\n\n", "\n", "。", ".", " ", ""]

    if len(text) <= chunk_size:
        return [text]

    chunks = []
    for sep in separators:
        if sep in text:
            parts = text.split(sep)
            current_chunk = ""
            for part in parts:
                candidate = current_chunk + sep + part if current_chunk else part
                if len(candidate) <= chunk_size:
                    current_chunk = candidate
                else:
                    if current_chunk:
                        chunks.append(current_chunk)
                    current_chunk = part
            if current_chunk:
                chunks.append(current_chunk)
            break

    final_chunks = []
    for chunk in chunks:
        if len(chunk) > chunk_size:
            final_chunks.extend(
                recursive_chunking(chunk, chunk_size, separators[1:])
            )
        else:
            final_chunks.append(chunk)

    return final_chunks

text = """第一章 引言

这是引言的内容。这里讨论了背景和动机。

第二章 方法

本章介绍了我们使用的方法。首先描述数据收集。然后介绍模型架构。"""

chunks = recursive_chunking(text, chunk_size=80)
for i, chunk in enumerate(chunks):
    print(f"块 {i}: [{len(chunk)} chars] {chunk[:50]}...")


语义分块
语义分块（Semantic Chunking）通过嵌入相似度来判断分割点，确保每个块内的内容语义连贯：


import numpy as np

def semantic_chunking(sentences, embeddings, threshold=0.5):
    chunks = []
    current_chunk = [sentences[0]]
    current_embedding = embeddings[0]

    for i in range(1, len(sentences)):
        similarity = np.dot(current_embedding, embeddings[i]) / (
            np.linalg.norm(current_embedding) * np.linalg.norm(embeddings[i])
        )

        if similarity >= threshold:
            current_chunk.append(sentences[i])
            current_embedding = np.mean(
                [current_embedding, embeddings[i]], axis=0
            )
        else:
            chunks.append(" ".join(current_chunk))
            current_chunk = [sentences[i]]
            current_embedding = embeddings[i]

    if current_chunk:
        chunks.append(" ".join(current_chunk))

    return chunks

np.random.seed(42)
sentences = ["机器学习概述", "监督学习方法", "深度学习技术", "今日股市大涨", "投资策略分析"]
embeddings = np.random.randn(5, 64)
embeddings[0:3] += 1.0
embeddings[3:5] -= 1.0

chunks = semantic_chunking(sentences, embeddings, threshold=0.3)
for i, chunk in enumerate(chunks):
    print(f"语义块 {i}: {chunk}")


父子分块
父子分块（Parent-Child Chunking）使用小块进行检索，但返回包含更多上下文的大块给 LLM：


class ParentChildChunker:
    def __init__(self, parent_size=512, child_size=128):
        self.parent_size = parent_size
        self.child_size = child_size

    def create_chunks(self, text):
        parent_chunks = []
        for i in range(0, len(text), self.parent_size):
            parent = text[i:i + self.parent_size]
            parent_id = f"parent_{i}"

            children = []
            for j in range(0, len(parent), self.child_size):
                child = parent[j:j + self.child_size]
                children.append({
                    "id": f"child_{i}_{j}",
                    "parent_id": parent_id,
                    "content": child,
                })

            parent_chunks.append({
                "id": parent_id,
                "content": parent,
                "children": children,
            })

        return parent_chunks

chunker = ParentChildChunker(parent_size=200, child_size=50)
text = "这是一个关于大语言模型的长文档内容。" * 30
result = chunker.create_chunks(text)
print(f"父块数量: {len(result)}")
print(f"第一个父块的子块数量: {len(result[0]['children'])}")

提示： 对于大多数 RAG 应用，递归分块 + 重叠是最稳妥的起点。如果检索精度不够，再考虑升级到语义分块或父子分块。






小结
    

  • 分块策略直接影响检索精度，是 RAG 系统的关键设计决策。
    • 

  • 固定大小分块简单但语义割裂，递归分块是更好的默认选择。
    • 

  • 语义分块根据内容相似度自动切分，保持块内语义连贯。
    • 

  • 父子分块用小块精准检索、大块完整上下文，兼顾精度和信息量。
    • 

  • 块大小需要与嵌入模型的最大长度匹配，通常 256-1024 tokens。
