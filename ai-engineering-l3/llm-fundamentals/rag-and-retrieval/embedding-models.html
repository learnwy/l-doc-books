嵌入模型的作用

嵌入模型（Embedding Model）将文本转换为稠密向量，使得语义相似的文本在向量空间中距离更近。它是 RAG 系统中连接自然语言查询和向量检索的桥梁。

Sentence Transformers
Sentence Transformers 是最流行的开源嵌入模型框架，基于 Hugging Face Transformers 构建：


from sentence_transformers import SentenceTransformer

model = SentenceTransformer('BAAI/bge-large-zh-v1.5')

sentences = [
    "什么是机器学习？",
    "机器学习是人工智能的一个子领域",
    "今天天气怎么样？",
    "深度学习使用神经网络来学习数据表示",
]

embeddings = model.encode(sentences, normalize_embeddings=True)
print(f"嵌入形状: {embeddings.shape}")

import numpy as np
similarity_matrix = np.inner(embeddings, embeddings)
print("\n相似度矩阵:")
for i, s1 in enumerate(sentences):
    for j, s2 in enumerate(sentences):
        if i < j:
            print(f"  '{s1[:15]}...' vs '{s2[:15]}...': {similarity_matrix[i][j]:.4f}")

import numpy as np

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

def dot_product(a, b):
    return np.dot(a, b)

def l2_distance(a, b):
    return np.linalg.norm(a - b)

a = np.random.randn(768)
b = np.random.randn(768)

a_norm = a / np.linalg.norm(a)
b_norm = b / np.linalg.norm(b)

print(f"余弦相似度: {cosine_similarity(a, b):.4f}")
print(f"归一化后点积: {dot_product(a_norm, b_norm):.4f}")
print(f"L2 距离: {l2_distance(a_norm, b_norm):.4f}")
print(f"余弦 = 归一化点积: {np.isclose(cosine_similarity(a, b), dot_product(a_norm, b_norm))}")

selection_criteria = {
    "中文 RAG 系统": {
        "推荐": "BGE-M3 / GTE-Qwen2",
        "理由": "中文性能强，支持长文本",
    },
    "英文通用场景": {
        "推荐": "text-embedding-3-small",

    "多语言场景": {

        "理由": "跨语言检索能力强",

    "超长文档": {

小结
    

  • 嵌入模型将文本映射为稠密向量，是 RAG 系统的语义理解核心。
    • 

  • BGE-M3 和 GTE-Qwen2 是当前中文场景下的最佳开源选择。
    • 

  • 归一化嵌入下余弦相似度等价于点积，选择哪种对结果无影响。
    • 

  • text-embedding-3 系列支持维度裁剪，适合在性能和存储之间灵活调整。
    • 

  • 选择嵌入模型需要综合考虑语言支持、最大长度、维度和部署成本。
