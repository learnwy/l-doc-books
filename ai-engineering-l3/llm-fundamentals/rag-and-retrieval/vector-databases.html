向量数据库

为什么需要向量数据库

向量数据库是 RAG（检索增强生成）系统的核心基础设施。它专门用于存储和检索高维向量（嵌入），支持高效的相似度搜索。传统数据库按精确匹配查询，向量数据库则按语义相似性查询。

import numpy as np

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

def brute_force_search(query, vectors, top_k=5):
    similarities = [
        (i, cosine_similarity(query, v))
        for i, v in enumerate(vectors)
    ]
    similarities.sort(key=lambda x: x[1], reverse=True)
    return similarities[:top_k]

np.random.seed(42)
vectors = np.random.randn(1000, 768)
query = np.random.randn(768)

results = brute_force_search(query, vectors, top_k=3)
for idx, score in results:
    print(f"  文档 {idx}: 相似度 = {score:.4f}")

小结
    

  • 向量数据库是 RAG 系统的存储和检索核心，支持语义级别的相似度搜索。
    • 

  • HNSW 是最常用的 ANN 索引算法，在查询速度和召回率之间表现优异。
    • 

  • 选择向量数据库需要综合考虑部署方式、规模需求、元数据过滤和生态集成。
    • 

  • Chroma 适合原型开发，Milvus/Qdrant 适合生产环境，FAISS 适合纯向量搜索场景。
    • 

  • 元数据过滤能力是生产环境中的关键需求，可以显著提升检索精度。
