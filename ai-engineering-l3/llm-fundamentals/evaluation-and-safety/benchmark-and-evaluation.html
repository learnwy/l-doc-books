基准测试与评估

为什么评估很重要

评估是 LLM 开发中不可或缺的环节。没有可靠的评估，就无法判断模型改进的效果、比较不同方案的优劣，也无法确保模型在生产环境中的可靠性。

自动评估指标
import numpy as np

def pass_at_k(n, c, k):
    if n - c < k:
        return 1.0
    return 1.0 - np.prod(1.0 - k / np.arange(n - c + 1, n + 1))

for k in [1, 5, 10]:
    score = pass_at_k(n=20, c=5, k=k)
    print(f"pass@{k} (20 次采样, 5 次通过): {score:.4f}")

def accuracy(predictions, labels):
    correct = sum(p == l for p, l in zip(predictions, labels))
    return correct / len(labels)

preds = ["A", "B", "C", "A", "B"]
labels = ["A", "B", "B", "A", "B"]
print(f"\n准确率: {accuracy(preds, labels):.2f}")

LLM-as-Judge
使用强大的 LLM 作为评估者来评估其他模型的输出质量，已成为主流的评估方法：


judge_prompt = """你是一个公平的评判者。请评估以下 AI 助手的回答质量。

评估维度：
1. 准确性 (1-5)：信息是否正确
2. 完整性 (1-5)：是否充分回答了问题
3. 清晰度 (1-5)：表达是否清晰易懂
4. 有用性 (1-5)：对用户是否有实际帮助

用户问题：{question}

AI 回答：{answer}

请按以下格式输出：
准确性: X/5
完整性: X/5
清晰度: X/5
有用性: X/5
总分: X/20
评语: ..."""

print(judge_prompt.format(
    question="什么是 LoRA？",
    answer="LoRA 是一种参数高效的微调方法..."
))


提示： LLM-as-Judge 存在固有偏见：倾向于给更长的回答更高分、偏好与自己风格相似的输出。使用时应配合人工抽检来校准评分标准。






自定义评估
实际业务场景往往需要自定义评估：


class CustomEvaluator:
    def __init__(self, test_cases):
        self.test_cases = test_cases
        self.results = []

    def evaluate(self, model):
        for case in self.test_cases:
            output = model.generate(case["input"])
            result = {
                "input": case["input"],
                "expected": case["expected"],
                "output": output,
                "pass": self.check(output, case),
            }
            self.results.append(result)

        passed = sum(r["pass"] for r in self.results)
        total = len(self.results)
        return {
            "pass_rate": passed / total,
            "passed": passed,
            "total": total,
        }

    def check(self, output, case):
        if "contains" in case:
            return all(kw in output for kw in case["contains"])
        if "format" in case:
            return case["format"](output)
        return output.strip() == case["expected"].strip()

test_cases = [
    {
        "input": "1+1=?",
        "expected": "2",
        "contains": ["2"],
    },
    {
        "input": "Python 的创始人是谁？",
        "expected": "Guido van Rossum",
        "contains": ["Guido"],
    },
]

print(f"自定义测试集: {len(test_cases)} 个用例")


小结
    

  • 评估是 LLM 开发的核心环节，需要自动化基准 + 人工评估相结合。
    • 

  • MMLU 评估知识广度，HumanEval 评估编程能力，MT-Bench 评估对话质量。
    • 

  • LLM-as-Judge 是高效的评估方法，但需注意评分偏见。
    • 

  • 自定义评估应贴合实际业务场景，覆盖准确性、格式和边界情况。
    • 

  • 评估结果应持续跟踪，建立模型质量的量化基线。
