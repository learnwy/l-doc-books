幻觉缓解

什么是幻觉

幻觉（Hallucination）是 LLM 生成看似合理但实际不正确或无依据内容的现象。这是当前 LLM 面临的最大可靠性挑战之一。

检测方法
class HallucinationDetector:
    def __init__(self, fact_checker, nli_model):
        self.fact_checker = fact_checker
        self.nli_model = nli_model

    def check_factuality(self, claim):
        evidence = self.fact_checker.search(claim)
        result = self.nli_model.predict(evidence, claim)
        return result

    def check_consistency(self, source, generated):
        sentences = generated.split("。")
        inconsistent = []
        for sent in sentences:
            if sent.strip():
                label = self.nli_model.predict(source, sent)
                if label == "contradiction":
                    inconsistent.append(sent)
        return inconsistent

detection_methods = {
    "基于 NLI": "用自然语言推理模型检查文本蕴含关系",

置信度校准
def assess_confidence(logprobs, threshold=0.7):
    avg_prob = sum(logprobs) / len(logprobs)
    min_prob = min(logprobs)

    if avg_prob > threshold and min_prob > 0.5:
        return "高置信度", avg_prob
    elif avg_prob > 0.4:
        return "中等置信度 - 建议验证", avg_prob
    else:
        return "低置信度 - 可能包含幻觉", avg_prob

simulated_probs = [0.95, 0.88, 0.72, 0.91, 0.85]
level, score = assess_confidence(simulated_probs)
print(f"置信度评估: {level} (平均概率: {score:.2f})")

提示： 最有效的幻觉缓解通常是多种策略的组合：RAG 提供知识锚点 + 引用标注增加可追溯性 + 置信度校准识别不确定区域。






小结
    

  • 幻觉是 LLM 生成不准确内容的现象，分为事实错误、编造引用和逻辑矛盾等类型。
    • 

  • 根本原因包括训练数据噪声、优化目标偏差和自回归误差累积。
    • 

  • RAG 是最有效的幻觉缓解手段，通过外部知识"锚定"模型输出。
    • 

  • 引用标注和置信度校准提供了输出可靠性的量化信号。
    • 

  • 幻觉无法完全消除，但通过多策略组合可以将其控制在可接受范围内。
