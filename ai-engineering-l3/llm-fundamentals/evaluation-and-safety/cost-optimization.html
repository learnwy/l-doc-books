Token 经济学

    "GPT-4o": {"input": 2.50, "output": 10.00},
    "GPT-4o-mini": {"input": 0.15, "output": 0.60},
    "Claude 3.5 Sonnet": {"input": 3.00, "output": 15.00},

}

print(f"{'模型':<25} {'输入 ($/M tokens)':>18} {'输出 ($/M tokens)':>18}")
print("-" * 65)
for model, price in pricing.items():
    print(f"{model:<25} ${price['input']:>16.2f} ${price['output']:>16.2f}")

def estimate_monthly_cost(model_pricing, daily_requests, avg_input_tokens, avg_output_tokens):
    monthly_requests = daily_requests * 30
    input_cost = (monthly_requests * avg_input_tokens / 1e6) * model_pricing["input"]
    output_cost = (monthly_requests * avg_output_tokens / 1e6) * model_pricing["output"]
    return input_cost + output_cost

cost = estimate_monthly_cost(
    pricing["GPT-4o"],
    daily_requests=10000,
    avg_input_tokens=1000,
    avg_output_tokens=500
)
print(f"\nGPT-4o 月成本估算 (10K 请求/天): ${cost:,.2f}")


缓存策略
缓存是最直接的成本优化手段——对相同或相似查询直接返回缓存结果：


import hashlib
import json

class LLMCache:
    def __init__(self):
        self.exact_cache = {}
        self.semantic_cache = None
        self.stats = {"hits": 0, "misses": 0}

    def get_key(self, messages, model, temperature):
        content = json.dumps({"messages": messages, "model": model, "temp": temperature})
        return hashlib.sha256(content.encode()).hexdigest()

    def get(self, messages, model, temperature=0):
        if temperature > 0:
            self.stats["misses"] += 1
            return None

        key = self.get_key(messages, model, temperature)
        if key in self.exact_cache:
            self.stats["hits"] += 1
            return self.exact_cache[key]

        self.stats["misses"] += 1
        return None

    def set(self, messages, model, temperature, response):
        if temperature == 0:
            key = self.get_key(messages, model, temperature)
            self.exact_cache[key] = response

    @property
    def hit_rate(self):
        total = self.stats["hits"] + self.stats["misses"]
        return self.stats["hits"] / total if total > 0 else 0

cache = LLMCache()
print(f"缓存命中率: {cache.hit_rate:.0%}")
print("注意: 只有确定性输出 (temperature=0) 才适合精确缓存")

模型路由
模型路由（Model Routing）根据查询的复杂度自动选择合适的模型，用小模型处理简单问题，只在必要时使用大模型：


class ModelRouter:
    def __init__(self):
        self.models = {
            "simple": {"name": "gpt-4o-mini", "cost_per_1m": 0.15},
            "medium": {"name": "claude-3.5-haiku", "cost_per_1m": 0.80},
            "complex": {"name": "gpt-4o", "cost_per_1m": 2.50},
        }

    def classify_complexity(self, query):
        if len(query) < 50 and "?" in query:
            return "simple"
        elif any(kw in query for kw in ["分析", "比较", "设计", "优化"]):
            return "complex"
        else:
            return "medium"

    def route(self, query):
        complexity = self.classify_complexity(query)
        model = self.models[complexity]
        return model

router = ModelRouter()
test_queries = [
    "1+1=?",
    "帮我写一段 Python 排序代码",
    "分析 Transformer 架构与 Mamba 架构的优缺点并设计混合方案",
]

for q in test_queries:
    model = router.route(q)
    print(f"查询: {q[:30]}...")
    print(f"  → 路由到: {model['name']} (${model['cost_per_1m']}/M tokens)\n")

小结
    

  • LLM 成本主要来自 token 计费和 GPU 推理，需要从多个维度优化。
    • 

  • Token 经济学是成本规划的基础，不同模型的性价比差异巨大。
    • 

  • 缓存（精确 + 语义 + Prompt）是投入产出比最高的优化策略。
    • 

  • 模型路由根据复杂度动态选择模型，在质量和成本之间取得平衡。
    • 

  • 当请求量足够大时，自部署开源模型比 API 调用更经济。
