端侧部署

为什么要端侧部署

端侧部署（On-device / Edge Deployment）指将 LLM 运行在本地设备上（PC、手机、嵌入式设备），而非依赖云端服务。它在隐私保护、离线可用性和延迟控制方面具有不可替代的优势。

llama.cpp 是最流行的端侧 LLM 推理引擎，纯 C/C++ 实现，无需 GPU 即可运行：

Apple MLX
MLX 是 Apple 专为 Apple Silicon 优化的机器学习框架，在 M 系列芯片上提供高效的 LLM 推理：

提示： Apple Silicon 的统一内存架构使其在运行大模型时具有独特优势——不像 NVIDIA GPU 受限于显存大小，M 系列芯片可以利用全部系统内存。

端侧部署权衡
tradeoffs = {
    "模型大小 vs 质量": {
        "说明": "更小的模型质量更差，但运行更快",
        "建议": "7B Q4 是桌面端的甜点配置",
    },
    "量化程度 vs 精度": {
        "说明": "更激进的量化会损失更多精度",
        "建议": "Q4_K_M 是最佳平衡点",
    },
    "上下文长度 vs 内存": {
        "说明": "更长的上下文需要更多 KV 缓存内存",
        "建议": "根据可用内存动态调整",
    },
    "速度 vs 功耗": {
        "说明": "移动设备需要关注电池续航",
        "建议": "使用 Neural Engine 降低功耗",
    },
}

for topic, info in tradeoffs.items():
    print(f"权衡: {topic}")
    print(f"  说明: {info['说明']}")
    print(f"  建议: {info['建议']}\n")


小结
    

  • 端侧部署在隐私保护、离线可用和延迟控制方面具有不可替代的优势。
    • 

  • llama.cpp 是最通用的端侧推理引擎，支持 CPU、Metal、CUDA 等多种后端。
    • 

  • Apple MLX 利用统一内存架构，在 Apple Silicon 上实现高效推理。
    • 

  • 7B Q4 是桌面端的推荐配置，3B Q4 适合移动端。
    • 

  • 端侧部署需要在模型大小、质量、速度和功耗之间找到平衡。
    •
