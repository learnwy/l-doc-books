模型量化

什么是量化

量化（Quantization）是将模型权重和/或激活值从高精度（如 FP32/BF16）转换为低精度（如 INT8/INT4）表示的技术。它能显著减少模型大小和推理时的显存占用，同时在一定程度上加速推理。

GPTQ
GPTQ 是一种基于二阶信息的训练后量化方法（Post-Training Quantization），逐层对权重进行量化，使用 Hessian 矩阵信息来最小化量化误差：


# from transformers import AutoModelForCausalLM, GPTQConfig

gptq_config = {
    "bits": 4,
    "group_size": 128,
    "desc_act": True,
    "dataset": "c4",
    "damp_percent": 0.1,
}

print("GPTQ 量化配置:")

AWQ
AWQ（Activation-aware Weight Quantization）基于一个关键观察：并非所有权重同等重要。保护那些对应于大激活值的"显著"权重通道，可以显著降低量化损失：


awq_config = {
    "bits": 4,
    "group_size": 128,
    "zero_point": True,
    "version": "GEMM",
}

# from awq import AutoAWQForCausalLM
# model = AutoAWQForCausalLM.from_pretrained("meta-llama/Llama-3.1-8B")
# model.quantize(
#     tokenizer,
#     quant_config={"w_bit": 4, "q_group_size": 128, "zero_point": True}
# )

print("AWQ: 保护显著权重通道，降低量化损失")
for k, v in awq_config.items():
    print(f"  {k}: {v}")

GGUF 格式
GGUF（GPT-Generated Unified Format）是 llama.cpp 使用的量化格式，专为 CPU 推理优化。它支持混合精度量化——不同层使用不同的位宽：


gguf_quant_types = {
    "Q2_K": {"bits": 2.5, "quality": "★★☆☆☆", "size_7b": "2.8 GB"},
    "Q3_K_M": {"bits": 3.3, "quality": "★★★☆☆", "size_7b": "3.5 GB"},
    "Q4_K_M": {"bits": 4.8, "quality": "★★★★☆", "size_7b": "4.4 GB"},
    "Q5_K_M": {"bits": 5.7, "quality": "★★★★☆", "size_7b": "5.1 GB"},
    "Q6_K": {"bits": 6.6, "quality": "★★★★★", "size_7b": "5.9 GB"},
    "Q8_0": {"bits": 8.5, "quality": "★★★★★", "size_7b": "7.7 GB"},
    "F16": {"bits": 16.0, "quality": "★★★★★", "size_7b": "14.0 GB"},
}

print(f"{'量化类型':<12} {'位宽':>6} {'7B 大小':>10} {'质量':>8}")
print("-" * 40)
for name, info in gguf_quant_types.items():
    print(f"{name:<12} {info['bits']:>5.1f}b {info['size_7b']:>10} {info['quality']:>8}")


提示： 对于消费级硬件，Q4_K_M 是推荐的默认选择——在文件大小和输出质量之间取得了最佳平衡。Q5_K_M 和 Q6_K 在质量上进一步提升，但需要更多内存。

小结
    

  • 量化将模型从高精度转为低精度，显著减少显存占用和模型大小。
    • 

  • GPTQ 使用 Hessian 信息逐层量化，AWQ 保护显著权重通道，两者都是优秀的 4-bit 方案。
    • 

  • GGUF 格式专为 CPU 推理设计，支持灵活的混合精度量化。
    • 

  • Q4_K_M 是消费级硬件上的推荐默认量化方案。
    • 

  • 量化感知训练在训练时模拟量化效果，适合对质量要求极高的场景。
