服务框架

LLM 服务化挑战

将 LLM 部署为可靠的在线服务面临独特挑战：模型体积大、推理延迟高、显存管理复杂、并发处理困难。专用的服务框架提供了开箱即用的解决方案。

vLLM
vLLM 是当前最流行的高性能 LLM 服务框架。其核心创新是 PagedAttention——借鉴操作系统虚拟内存的思想管理 KV 缓存：


# vLLM 启动服务
# python -m vllm.entrypoints.openai.api_server \
#     --model meta-llama/Llama-3.1-8B-Instruct \
#     --tensor-parallel-size 1 \
#     --max-model-len 8192 \
#     --gpu-memory-utilization 0.9

vllm_config = {
    "model": "meta-llama/Llama-3.1-8B-Instruct",
    "tensor_parallel_size": 1,
    "max_model_len": 8192,
    "gpu_memory_utilization": 0.9,
    "dtype": "auto",
    "quantization": None,
    "max_num_seqs": 256,
}

print("vLLM 服务配置:")
for k, v in vllm_config.items():
    print(f"  {k}: {v}")

TGI (Text Generation Inference)
TGI 是 Hugging Face 官方的推理服务器，与 HF 生态深度集成：


# Docker 启动 TGI
# docker run --gpus all -p 8080:80 \
#     -v $PWD/data:/data \
#     ghcr.io/huggingface/text-generation-inference:latest \
#     --model-id meta-llama/Llama-3.1-8B-Instruct \
#     --quantize gptq \
#     --max-input-length 4096 \
#     --max-total-tokens 8192

tgi_features = {

Ollama
Ollama 是面向本地部署的轻量级工具，一条命令即可运行各种开源模型：


# 安装和使用
# curl -fsSL https://ollama.com/install.sh | sh
# ollama run llama3.1:8b
# ollama run qwen2.5:7b

ollama_commands = {
    "下载并运行": "ollama run llama3.1:8b",
    "列出本地模型": "ollama list",
    "拉取模型": "ollama pull qwen2.5:7b",
    "API 调用": "curl http://localhost:11434/api/generate -d '{\"model\": \"llama3.1:8b\", \"prompt\": \"hello\"}'",
    "自定义模型": "ollama create mymodel -f Modelfile",
}

print("Ollama 常用命令:")
for action, cmd in ollama_commands.items():
    print(f"  {action}: {cmd}")


提示： Ollama 适合个人开发和体验，但不适合高并发生产环境。对于需要高吞吐的场景，应选择 vLLM 或 TGI。

小结
    

  • vLLM 以 PagedAttention 为核心，是当前最高吞吐的开源推理框架。
    • 

  • TGI 与 Hugging Face 生态深度集成，适合快速部署 HF 模型。
    • 

  • Ollama 一键运行，是本地开发和体验的最佳选择。
    • 

  • 框架选型需要综合考虑吞吐需求、部署环境和生态集成。
    • 

  • 所有主流框架都提供 OpenAI 兼容的 API，方便迁移和集成。
