推理性能瓶颈

LLM 推理面临独特的性能挑战：模型体积大、自回归生成逐 token 顺序执行、长序列的 KV 缓存占用大量显存。理解这些瓶颈是优化的第一步。

KV 缓存优化
KV 缓存是推理中最大的显存消耗来源之一。以下技术用于减少 KV 缓存的开销：


def estimate_kv_cache_size(
    num_layers, num_kv_heads, head_dim, seq_len, batch_size, dtype_bytes=2
):
    total = 2 * num_layers * num_kv_heads * head_dim * seq_len * batch_size * dtype_bytes
    return total

configs = {
    "LLaMA-3.1-8B": {"layers": 32, "kv_heads": 8, "head_dim": 128},
    "LLaMA-3.1-70B": {"layers": 80, "kv_heads": 8, "head_dim": 128},
    "Qwen2.5-72B": {"layers": 80, "kv_heads": 8, "head_dim": 128},
}

for name, cfg in configs.items():
    for seq_len in [4096, 32768, 131072]:
        size = estimate_kv_cache_size(
            cfg["layers"], cfg["kv_heads"], cfg["head_dim"],
            seq_len, batch_size=1
        )
        print(f"{name:20s} seq={seq_len:>7,}: KV Cache = {size / 1e9:.2f} GB")
    print()

投机解码
投机解码（Speculative Decoding）使用一个小型"草稿模型"快速生成多个候选 token，然后用大模型并行验证。被接受的 token 直接使用，被拒绝的从大模型重新采样：


def speculative_decode(draft_model, target_model, prompt, gamma=5):
    accepted = 0
    total = 0

    draft_tokens = draft_model.generate(prompt, num_tokens=gamma)
    target_probs = target_model.get_probs(prompt + draft_tokens)

    for i, token in enumerate(draft_tokens):
        draft_prob = draft_model.get_prob(token)
        target_prob = target_probs[i]

        acceptance_ratio = min(1, target_prob / draft_prob)
        if random.random() < acceptance_ratio:
            accepted += 1
        else:
            break

    return accepted, gamma

print("投机解码效果:")
acceptance_rates = {"代码生成": 0.85, "创意写作": 0.60, "数学推理": 0.70}
for task, rate in acceptance_rates.items():
    speedup = 1 / (1 - rate + rate / 5)
    print(f"  {task}: 接受率 {rate:.0%} → 约 {speedup:.1f}x 加速")


提示： 投机解码在草稿模型与目标模型输出分布相似时效果最好。同一系列的小大模型对（如 LLaMA-1B + LLaMA-70B）通常是最佳搭配。

小结
    

  • LLM 推理分为 Prefill（计算密集）和 Decode（带宽密集）两个阶段。
    • 

  • KV 缓存是主要显存消耗来源，GQA、PagedAttention 和 KV 量化是关键优化手段。
    • 

  • 投机解码用小模型预测+大模型验证，在不损失质量的情况下加速 1.5-3x。
    • 

  • 连续批处理替代静态批处理可显著提升吞吐量。
    • 

  • TensorRT-LLM 提供从算子融合到量化推理的全栈优化。
