分词与嵌入

为什么需要分词

大语言模型不能直接处理原始文本，需要先将文本转换为数值表示。分词（Tokenization）是这个过程的第一步：将文本切分为模型可以理解的基本单元（token），然后通过嵌入层将每个 token 映射为稠密向量。

分词粒度的选择直接影响模型的词表大小、序列长度和语义表达能力：

提示： 现代 LLM 几乎全部采用子词（subword）分词方案，在词表大小和序列长度之间取得最佳平衡。






BPE 算法
字节对编码（Byte Pair Encoding, BPE）是最广泛使用的子词分词算法。GPT 系列模型均采用 BPE 的变体。


核心思路：从字符级别出发，反复合并出现频率最高的相邻 token 对，直到达到目标词表大小。


from collections import Counter

def learn_bpe(corpus, num_merges):
    words = [list(word) + ['</w>'] for word in corpus]
    merges = []

    for i in range(num_merges):
        pairs = Counter()
        for word in words:
            for j in range(len(word) - 1):
                pairs[(word[j], word[j + 1])] += 1

        if not pairs:
            break

        best_pair = pairs.most_common(1)[0][0]
        merges.append(best_pair)

        new_words = []
        for word in words:
            new_word = []
            j = 0
            while j < len(word):
                if j < len(word) - 1 and (word[j], word[j + 1]) == best_pair:
                    new_word.append(word[j] + word[j + 1])
                    j += 2
                else:
                    new_word.append(word[j])
                    j += 1
            new_words.append(new_word)
        words = new_words

        print(f"合并 {i + 1}: {best_pair[0]} + {best_pair[1]} → {best_pair[0] + best_pair[1]}")

    return merges, words

corpus = ["low", "lower", "newest", "widest", "low", "low"]
merges, result = learn_bpe(corpus, num_merges=5)


WordPiece 与 SentencePiece
WordPiece
WordPiece 是 BERT 使用的分词算法，与 BPE 类似但使用不同的合并策略——选择使语言模型似然最大化的 token 对进行合并：


score(a,b)=freq(ab)freq(a)×freq(b)\text{score}(a, b) = \frac{\text{freq}(ab)}{\text{freq}(a) \times \text{freq}(b)}score(a,b)=freq(a)×freq(b)freq(ab)​
WordPiece 使用 ## 前缀标记非首子词：


from transformers import BertTokenizer

tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
tokens = tokenizer.tokenize("unbelievable transformers")
print(f"WordPiece 分词: {tokens}")
# ['un', '##bel', '##ie', '##va', '##ble', 'transform', '##ers']

词嵌入基础
分词后的 token ID 需要映射为稠密的低维向量，这就是嵌入（Embedding）。嵌入层本质上是一个可学习的查找表：


import torch
import torch.nn as nn

vocab_size = 32000
d_model = 768
embedding = nn.Embedding(vocab_size, d_model)

token_ids = torch.tensor([101, 2054, 2003, 1996, 102])
vectors = embedding(token_ids)
print(f"输入形状: {token_ids.shape}")
print(f"嵌入输出形状: {vectors.shape}")
print(f"每个 token 的向量维度: {d_model}")
Word2Vec 的启示
在 Transformer 之前，Word2Vec 是最有影响力的词嵌入方法。它通过预测上下文（CBOW）或中心词（Skip-gram）来学习词向量：


Word2Vec 的局限在于每个词只有一个固定向量，无法处理一词多义。




上下文嵌入
与 Word2Vec 的静态嵌入不同，Transformer 产生的嵌入是上下文相关的——同一个词在不同句子中有不同的向量表示：

from transformers import AutoTokenizer, AutoModel
import torch

tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")
model = AutoModel.from_pretrained("bert-base-uncased")

sentences = ["bank of the river", "bank account balance"]
for sent in sentences:
    inputs = tokenizer(sent, return_tensors="pt")
    with torch.no_grad():
        outputs = model(**inputs)
    bank_idx = (inputs['input_ids'][0] == tokenizer.convert_tokens_to_ids('bank')).nonzero()[0]
    bank_vec = outputs.last_hidden_state[0, bank_idx]
    print(f"'{sent}' 中 'bank' 的嵌入范数: {bank_vec.norm().item():.4f}")
在 LLM 中，输入 token 经过嵌入层后会加上位置编码，然后送入多层 Transformer。每一层的输出都是更高层次的上下文嵌入，最后一层的输出被用于预测下一个 token。




小结
    

  • 子词分词（BPE、WordPiece、SentencePiece）在词表大小和序列长度之间取得最佳平衡。
    • 

  • BPE 通过频率驱动的合并策略构建词表，是 GPT 和 LLaMA 的基础。
    • 

  • SentencePiece 提供语言无关的分词方案，直接在原始文本上训练。
    • 

  • 嵌入层将离散 token 映射为稠密向量，是模型理解文本的第一步。
    • 

  • 上下文嵌入是 Transformer 相比静态嵌入的核心优势，使模型能够区分一词多义。
    •
