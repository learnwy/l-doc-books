神经网络基础

从感知机到深度网络

神经网络是大语言模型的基石。理解其基本构造——从最简单的感知机到多层深度网络——是掌握 LLM 原理的第一步。

感知机（Perceptron）是最基本的神经元模型，它接收多个输入，通过加权求和后经过激活函数产生输出：

y=f(∑i=1nwixi+b)y = f\left(\sum_{i=1}^{n} w_i x_i + b\right)y=f(i=1∑n​wi​xi​+b)
单个感知机只能解决线性可分问题。通过将多个神经元组合成多层结构，就形成了能够拟合任意复杂函数的深度神经网络。




激活函数
激活函数为神经网络引入非线性，使网络能够学习复杂的模式。以下是常用的几种激活函数：

import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def relu(x):
    return np.maximum(0, x)

def gelu(x):
    return 0.5 * x * (1 + np.tanh(np.sqrt(2 / np.pi) * (x + 0.044715 * x**3)))

x = np.linspace(-5, 5, 100)
print(f"Sigmoid(-2) = {sigmoid(-2):.4f}")
print(f"ReLU(-2)    = {relu(-2):.4f}")
print(f"GELU(-2)    = {gelu(-2):.4f}")


提示： 现代 Transformer 架构（如 GPT、LLaMA）普遍采用 GELU 或 SwiGLU 作为激活函数，而非传统的 ReLU。






前向传播
前向传播是指数据从输入层逐层传递到输出层的过程。每一层执行线性变换加激活函数：


h(l)=f(W(l)h(l−1)+b(l))\mathbf{h}^{(l)} = f\left(\mathbf{W}^{(l)} \mathbf{h}^{(l-1)} + \mathbf{b}^{(l)}\right)h(l)=f(W(l)h(l−1)+b(l))
import numpy as np

def forward(X, weights, biases):
    activations = [X]
    for W, b in zip(weights, biases):
        z = activations[-1] @ W + b
        a = np.maximum(0, z)  # ReLU
        activations.append(a)
    return activations

np.random.seed(42)
X = np.random.randn(4, 2)
W1 = np.random.randn(2, 3) * 0.01
b1 = np.zeros(3)
W2 = np.random.randn(3, 1) * 0.01
b2 = np.zeros(1)

result = forward(X, [W1, W2], [b1, b2])
print(f"输入形状: {X.shape}, 输出形状: {result[-1].shape}")


反向传播与梯度下降
反向传播（Backpropagation）利用链式法则，从输出层向输入层逐层计算损失函数对每个参数的梯度。然后通过梯度下降更新参数：


W←W−η∂L∂W\mathbf{W} \leftarrow \mathbf{W} - \eta \frac{\partial \mathcal{L}}{\partial \mathbf{W}}W←W−η∂W∂L​
链式法则的核心思想：


∂L∂wij(l)=∂L∂aj(l)⋅∂aj(l)∂zj(l)⋅∂zj(l)∂wij(l)\frac{\partial \mathcal{L}}{\partial w_{ij}^{(l)}} = \frac{\partial \mathcal{L}}{\partial a_j^{(l)}} \cdot \frac{\partial a_j^{(l)}}{\partial z_j^{(l)}} \cdot \frac{\partial z_j^{(l)}}{\partial w_{ij}^{(l)}}∂wij(l)​∂L​=∂aj(l)​∂L​⋅∂zj(l)​∂aj(l)​​⋅∂wij(l)​∂zj(l)​​
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(2, 16),
    nn.GELU(),
    nn.Linear(16, 1)
)

X = torch.randn(32, 2)
y = torch.randn(32, 1)

criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

for epoch in range(100):
    pred = model(X)
    loss = criterion(pred, y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

print(f"最终损失: {loss.item():.4f}")

提示： 在 LLM 的预训练中，最核心的损失函数就是交叉熵损失——模型预测下一个 token 的概率分布与真实 token 的 one-hot 分布之间的交叉熵。




import torch
import torch.nn.functional as F

logits = torch.tensor([[2.0, 1.0, 0.1]])
target = torch.tensor([0])

loss = F.cross_entropy(logits, target)
print(f"交叉熵损失: {loss.item():.4f}")

probs = F.softmax(logits, dim=-1)
print(f"预测概率分布: {probs.detach().numpy()}")


从全连接到现代架构

Transformer 通过自注意力机制彻底解决了并行计算和长距离依赖问题，成为现代 LLM 的基础架构。




小结
    

  • 感知机是神经网络的基本单元，多层组合形成深度网络。
    • 

  • 激活函数引入非线性能力，GELU 和 SwiGLU 是 LLM 中的主流选择。
    • 

  • 前向传播执行逐层计算，反向传播通过链式法则计算梯度。
    • 

  • 交叉熵损失是 LLM 预训练的核心目标函数。
    • 

  • 从 MLP 到 Transformer 的演进解决了序列建模的并行性和长距离依赖问题。
