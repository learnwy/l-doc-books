Transformer 架构

核心概念

Transformer 的每一层都由几个固定的积木拼成，理解它们的职责就理解了整篇：

  • 自注意力：让序列中每个位置直接关注其他所有位置，用 softmax(QKT/dk)V\text{softmax}(QK^T/\sqrt{d_k})Vsoftmax(QKT/dk​​)V 计算全局依赖，是 Transformer 的核心。
  • 位置编码：注意力本身不含顺序信息，需要显式注入位置；RoPE 是现代 LLM 的主流方案，外推能力更好。
  • 层归一化：对隐藏维度归一化以稳定训练；Pre-LN（先归一化再计算）是当前标准做法，LLaMA 进一步用 RMSNorm。
  • 前馈网络（FFN）：对注意力输出做非线性变换，标准结构是两层全连接，现代 LLM 普遍换成 SwiGLU 变体。
  • 残差连接：每个子层都套一层 Add，使梯度能跨层直通，是深层堆叠可行的前提。

三者的组合方式决定了架构类型：仅编码器（BERT）、仅解码器（GPT/LLaMA）、编码器-解码器（T5）。当前旗舰文本模型几乎全是仅解码器的直系后代，并在其上叠加 GQA/MLA 压缩 KV cache、稀疏 MoE 替换稠密 FFN。

架构总览

Transformer 由 Vaswani 等人在 2017 年的论文《Attention Is All You Need》中提出，彻底改变了自然语言处理领域。它摒弃了 RNN 的循环结构，完全依赖注意力机制来捕获序列中的依赖关系。

根据使用编码器、解码器或两者的不同组合，衍生出三类主流架构：

架构类型 代表模型 适用任务
仅编码器 BERT, RoBERTa 文本分类、NER、问答
仅解码器 GPT, LLaMA, Qwen 文本生成、对话
编码器-解码器 T5, BART 翻译、摘要

提示： 截至写作时（2026 年年中），从 GPT-5、Claude、Gemini 到开源权重的 LLaMA、Qwen、DeepSeek，旗舰文本模型的主干仍延续仅解码器架构——它天然适合自回归生成任务。但「仅解码器」早已不等于原版结构：稀疏 MoE 前馈、GQA/MLA 等注意力变体与超长上下文改造已成旗舰标配，详见下文「现代架构演进」一节。

自注意力机制

自注意力（Self-Attention）是 Transformer 的核心。它让序列中的每个位置都能直接关注其他所有位置，从而捕获全局依赖：

Attention(Q,K,V)=softmax(QKTdk)V\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) VAttention(Q,K,V)=softmax(dk​​QKT​)V

其中 QQQ（Query）、KKK（Key）、VVV（Value）由输入经线性变换得到。

import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / (d_k ** 0.5)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    weights = F.softmax(scores, dim=-1)
    return torch.matmul(weights, V), weights

seq_len, d_model = 8, 64
Q = K = V = torch.randn(1, seq_len, d_model)
output, attn_weights = scaled_dot_product_attention(Q, K, V)
print(f"输出形状: {output.shape}")
print(f"注意力权重形状: {attn_weights.shape}")

位置编码

Transformer 不像 RNN 那样具有内在的序列顺序感知能力，因此需要通过位置编码（Positional Encoding）注入位置信息。

正弦位置编码

原始 Transformer 使用正弦和余弦函数生成固定位置编码：

PE(pos,2i)=sin⁡(pos100002i/d)PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d}}\right)PE(pos,2i)​=sin(100002i/dpos​)

PE(pos,2i+1)=cos⁡(pos100002i/d)PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d}}\right)PE(pos,2i+1)​=cos(100002i/dpos​)
import numpy as np

def sinusoidal_encoding(max_len, d_model):
    pe = np.zeros((max_len, d_model))
    position = np.arange(max_len)[:, np.newaxis]
    div_term = np.exp(np.arange(0, d_model, 2) * -(np.log(10000.0) / d_model))
    pe[:, 0::2] = np.sin(position * div_term)
    pe[:, 1::2] = np.cos(position * div_term)
    return pe

pe = sinusoidal_encoding(128, 64)
print(f"位置编码形状: {pe.shape}")
print(f"位置 0 前 8 维: {pe[0, :8].round(3)}")

旋转位置编码（RoPE）

现代 LLM 普遍采用旋转位置编码（RoPE），它将位置信息编码为旋转矩阵，具有更好的外推能力：

位置编码方法 最大长度 外推能力 代表模型
正弦编码 固定 弱 原始 Transformer
可学习编码 固定 弱 BERT, GPT-2
ALiBi 无限 强 BLOOM
RoPE 可扩展 强 LLaMA, Qwen, Mistral

层归一化

层归一化（Layer Normalization）在 Transformer 中起关键的稳定训练作用。它对每个样本的隐藏维度进行归一化：

LayerNorm(x)=x−μσ2+ϵ⋅γ+β\text{LayerNorm}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \cdot \gamma + \betaLayerNorm(x)=σ2+ϵ​x−μ​⋅γ+β
import torch
import torch.nn as nn

class LayerNorm(nn.Module):
    def __init__(self, d_model, eps=1e-6):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(d_model))
        self.beta = nn.Parameter(torch.zeros(d_model))
        self.eps = eps

    def forward(self, x):
        mean = x.mean(-1, keepdim=True)
        std = x.std(-1, keepdim=True)
        return self.gamma * (x - mean) / (std + self.eps) + self.beta

ln = LayerNorm(64)
x = torch.randn(2, 8, 64)
output = ln(x)
print(f"归一化后均值: {output.mean(-1)[0, 0]:.6f}")

提示： Pre-LN（先归一化再计算）是当前 LLM 的标准做法，它能显著提升训练稳定性。LLaMA 还进一步使用 RMSNorm 替代标准 LayerNorm。

前馈网络

每个 Transformer 层中的前馈网络（FFN）对注意力输出进行非线性变换。标准结构是两层全连接网络：

FFN(x)=W2⋅GELU(W1x+b1)+b2\text{FFN}(x) = W_2 \cdot \text{GELU}(W_1 x + b_1) + b_2FFN(x)=W2​⋅GELU(W1​x+b1​)+b2​

现代 LLM 中广泛使用 SwiGLU 变体：

SwiGLU(x)=(Swish(xW1)⊙xV)W2\text{SwiGLU}(x) = (\text{Swish}(xW_1) \odot xV) W_2SwiGLU(x)=(Swish(xW1​)⊙xV)W2​
import torch
import torch.nn as nn
import torch.nn.functional as F

class SwiGLU(nn.Module):
    def __init__(self, d_model, d_ff):
        super().__init__()
        self.w1 = nn.Linear(d_model, d_ff, bias=False)
        self.v = nn.Linear(d_model, d_ff, bias=False)
        self.w2 = nn.Linear(d_ff, d_model, bias=False)

    def forward(self, x):
        return self.w2(F.silu(self.w1(x)) * self.v(x))

ffn = SwiGLU(d_model=64, d_ff=172)
x = torch.randn(2, 8, 64)
output = ffn(x)
print(f"FFN 输出形状: {output.shape}")

现代架构演进：MoE、MLA 与 GQA

原版 Transformer 是「稠密」的：每个 token 都要经过全部参数。2024 年以来的旗舰模型几乎都在三个方向上做了稀疏化与缓存压缩改造。

注意力变体：从 MHA 到 GQA 与 MLA

自回归解码的瓶颈之一是 KV cache：序列越长、并发越高，需要缓存的 K/V 越多。主流解法是减少「键值头的数量」或压缩其表示：

变体 核心思路 KV cache 开销 代表模型
MHA 每个 query 头配独立 K/V 头 基准 原始 Transformer
MQA 所有头共享一组 K/V 最低 PaLM（早期）
GQA query 头分组、组内共享 K/V 低 LLaMA 3 全系、Mistral
MLA K/V 压缩为低秩潜向量再重建 低且质量更稳 DeepSeek-V2/V3、DeepSeek-R1

MLA（Multi-head Latent Attention，DeepSeek-V2 于 2024 年提出）将每个位置的 K/V 投影到一个低秩潜向量 cKVc_{KV}cKV​ 并只缓存它，注意力计算时再通过上投影矩阵重建 K/V——以极小的缓存空间保留接近 MHA 的效果。

稀疏混合专家（MoE）

MoE 把 FFN 替换为 NNN 个「专家」子网络加一个门控路由器，每个 token 只激活其中 Top-K 个专家：

y=∑i∈TopK(g(x))gi(x)⋅Ei(x),g(x)=softmax(Wgx)y = \sum_{i \in \text{TopK}(g(x))} g_i(x) \cdot E_i(x), \qquad g(x) = \text{softmax}(W_g x)y=i∈TopK(g(x))∑​gi​(x)⋅Ei​(x),g(x)=softmax(Wg​x)

由此产生了两个必须区分的参数口径：总参数量（容量上限）与激活参数量（每 token 实际参与计算的 FLOPs）。截至写作时，公开报道的旗舰开源权重模型几乎全部走这条路线：

flowchart TB
    subgraph Dense["稠密 FFN"]
        X1["token x"] --> F1["单一 FFN<br/>全部参数参与计算"]
    end
    subgraph MoE["稀疏 MoE FFN"]
        X2["token x"] --> Gate["门控路由<br/>softmax(W_g x)"]
        Gate -->|"Top-K 选中"| E1["专家 1"]
        Gate -->|"Top-K 选中"| E3["专家 3"]
        Gate -.->|"未选中,跳过"| E2["专家 2"]
        E1 --> Sum["加权求和 Σ g_i·E_i(x)"]
        E3 --> Sum
    end

提示： 读模型规格时先分清「总参 vs 激活参」。一个 671B 总参、37B 激活的 MoE，推理成本接近 40B 级稠密模型，但知识容量远超后者——这正是 2025 年以来旗舰模型「越大越便宜」悖论的技术来源。MoE 的训练稳定性、负载均衡与专家并行是独立的大话题。

小结

  • Transformer 由编码器和解码器组成，当前旗舰 LLM 的文本主干仍是仅解码器架构的直系后代。
  • 现代旗舰在原版结构上叠加了三类改造：GQA/MLA 压缩 KV cache、稀疏 MoE 替换稠密 FFN，形成「大总参、小激活」的主流形态。
  • 自注意力机制通过 Q、K、V 计算全局依赖关系，dk\sqrt{d_k}dk​​ 缩放防止梯度问题。
  • RoPE 是现代 LLM 最常用的位置编码方案，具有良好的长度外推能力。
  • Pre-LN 和 RMSNorm 是当前训练稳定性的标准做法。
  • SwiGLU 替代了传统 FFN 中的 ReLU/GELU，在主流 LLM 中广泛使用。
