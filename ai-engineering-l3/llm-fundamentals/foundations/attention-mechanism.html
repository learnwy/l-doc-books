注意力机制

注意力的直觉

注意力机制的核心思想是：在处理序列中某个位置时，不是平等对待所有输入，而是有选择地"关注"最相关的部分。这类似于人类阅读时，理解一个词需要重点关注上下文中的某些关键词。



缩放点积注意力
缩放点积注意力（Scaled Dot-Product Attention）是 Transformer 中的基本注意力计算单元：


Attention(Q,K,V)=softmax(QKTdk)V\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) VAttention(Q,K,V)=softmax(dk​​QKT​)V
缩放因子 dk\sqrt{d_k}dk​​ 的作用至关重要——当 dkd_kdk​ 较大时，点积值的方差会很大，导致 softmax 输出趋近 one-hot 分布，梯度极小。除以 dk\sqrt{d_k}dk​​ 能将方差归一。


import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None, dropout=None):
    d_k = Q.size(-1)
    attn_scores = torch.matmul(Q, K.transpose(-2, -1)) / (d_k ** 0.5)

    if mask is not None:
        attn_scores = attn_scores.masked_fill(mask == 0, float('-inf'))

    attn_weights = F.softmax(attn_scores, dim=-1)

    if dropout is not None:
        attn_weights = dropout(attn_weights)

    output = torch.matmul(attn_weights, V)
    return output, attn_weights

batch, heads, seq_len, d_k = 2, 8, 16, 64
Q = torch.randn(batch, heads, seq_len, d_k)
K = torch.randn(batch, heads, seq_len, d_k)
V = torch.randn(batch, heads, seq_len, d_k)

output, weights = scaled_dot_product_attention(Q, K, V)
print(f"输出形状: {output.shape}")
print(f"注意力权重求和（应为 1）: {weights[0, 0, 0].sum().item():.4f}")


多头注意力
多头注意力（Multi-Head Attention）将 Q、K、V 分成多个头并行计算注意力，然后拼接结果。不同头可以关注不同类型的语义关系：


MultiHead(Q,K,V)=Concat(head1,…,headh)WO\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^OMultiHead(Q,K,V)=Concat(head1​,…,headh​)WO
 


headi=Attention(QWiQ,KWiK,VWiV)\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)headi​=Attention(QWiQ​,KWiK​,VWiV​)
import torch
import torch.nn as nn

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        assert d_model % n_heads == 0
        self.d_k = d_model // n_heads
        self.n_heads = n_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, Q, K, V, mask=None):
        batch = Q.size(0)
        Q = self.W_q(Q).view(batch, -1, self.n_heads, self.d_k).transpose(1, 2)
        K = self.W_k(K).view(batch, -1, self.n_heads, self.d_k).transpose(1, 2)
        V = self.W_v(V).view(batch, -1, self.n_heads, self.d_k).transpose(1, 2)

        scores = torch.matmul(Q, K.transpose(-2, -1)) / (self.d_k ** 0.5)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))
        weights = torch.softmax(scores, dim=-1)
        attn = torch.matmul(weights, V)

        attn = attn.transpose(1, 2).contiguous().view(batch, -1, self.n_heads * self.d_k)
        return self.W_o(attn)

mha = MultiHeadAttention(d_model=512, n_heads=8)
x = torch.randn(2, 16, 512)
output = mha(x, x, x)
print(f"多头注意力输出形状: {output.shape}")


分组查询注意力
标准多头注意力中每个头都有独立的 K 和 V 投影，参数量和显存占用较大。分组查询注意力（Grouped-Query Attention, GQA）通过让多个查询头共享同一组 K/V 来降低开销：

KV 缓存
在自回归生成中，每生成一个新 token，都需要计算它与所有之前 token 的注意力。KV 缓存（KV Cache）通过保存已计算的 K 和 V 矩阵，避免重复计算：


import torch

class KVCache:
    def __init__(self):
        self.k_cache = None
        self.v_cache = None

    def update(self, k_new, v_new):
        if self.k_cache is None:
            self.k_cache = k_new
            self.v_cache = v_new
        else:
            self.k_cache = torch.cat([self.k_cache, k_new], dim=-2)
            self.v_cache = torch.cat([self.v_cache, v_new], dim=-2)
        return self.k_cache, self.v_cache

cache = KVCache()
for step in range(5):
    k_new = torch.randn(1, 8, 1, 64)
    v_new = torch.randn(1, 8, 1, 64)
    k_full, v_full = cache.update(k_new, v_new)
    print(f"步骤 {step + 1}: KV 缓存序列长度 = {k_full.size(-2)}")
KV 缓存的显存开销公式为：


内存=2×nlayers×nkv_heads×dhead×seq_len×batch×dtype_bytes\text{内存} = 2 \times n_{\text{layers}} \times n_{\text{kv\_heads}} \times d_{\text{head}} \times \text{seq\_len} \times \text{batch} \times \text{dtype\_bytes}内存=2×nlayers​×nkv_heads​×dhead​×seq_len×batch×dtype_bytes


Flash Attention
标准注意力的显存复杂度为 O(n2)O(n^2)O(n2)（需要存储完整的注意力矩阵）。Flash Attention 通过 IO 感知的分块计算（tiling），避免在 HBM 中实际构建 n×nn \times nn×n 的注意力矩阵：

小结
    

  • 缩放点积注意力通过 dk\sqrt{d_k}dk​​ 缩放保持梯度稳定，是注意力机制的基本形式。
    • 

  • 多头注意力让不同头关注不同语义维度，增强模型表达力。
    • 

  • GQA 通过共享 KV 头在推理效率和质量之间取得平衡，是主流 LLM 的标配。
    • 

  • KV 缓存消除自回归生成中的重复计算，但显存开销随序列长度线性增长。
    • 

  • Flash Attention 通过分块计算将显存复杂度从 O(n2)O(n^2)O(n2) 降到 O(n)O(n)O(n)，显著提升长序列处理性能。
    •
