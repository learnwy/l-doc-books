少样本学习

什么是少样本学习

少样本学习（Few-shot Learning）也称上下文学习（In-Context Learning, ICL），是 LLM 最强大的能力之一——通过在提示中提供少量示例，模型就能理解并执行新任务，无需任何参数更新。

上下文学习原理
上下文学习的工作机制仍是活跃的研究领域。主流假说认为，预训练让模型内化了大量"任务模板"，few-shot 示例帮助模型"定位"到正确的任务模板：


def format_few_shot(examples, query, task_description=""):
    prompt = ""
    if task_description:
        prompt += f"{task_description}\n\n"

    for inp, out in examples:
        prompt += f"输入: {inp}\n输出: {out}\n\n"

    prompt += f"输入: {query}\n输出:"
    return prompt

sentiment_examples = [
    ("这家餐厅的菜太好吃了！", "正面"),
    ("等了一个小时才上菜，服务太差了", "负面"),
    ("价格还行，味道一般般", "中性"),
]

prompt = format_few_shot(
    sentiment_examples,
    "环境很好但菜品让人失望",
    task_description="判断以下评论的情感倾向（正面/负面/中性）："
)
print(prompt)

import numpy as np

def select_by_similarity(query_embedding, example_embeddings, examples, k=3):
    similarities = np.dot(example_embeddings, query_embedding)
    top_indices = np.argsort(similarities)[-k:][::-1]
    return [examples[i] for i in top_indices]

def select_by_diversity(examples, k=3):
    selected = [examples[0]]
    remaining = list(range(1, len(examples)))

    while len(selected) < k and remaining:
        best_idx = remaining[0]
        remaining.remove(best_idx)
        selected.append(examples[best_idx])

    return selected

np.random.seed(42)
query_emb = np.random.randn(768)
example_embs = np.random.randn(20, 768)
examples = [f"示例_{i}" for i in range(20)]

similar = select_by_similarity(query_emb, example_embs, examples, k=3)
print(f"相似度选择: {similar}")


检索增强提示
检索增强提示（Retrieval-Augmented Prompts）将 RAG 的检索能力与 few-shot 结合，动态检索与当前查询最相关的示例：


class DynamicFewShot:
    def __init__(self, example_pool, embedder):
        self.examples = example_pool
        self.embedder = embedder
        self.example_embeddings = embedder.encode(
            [e["input"] for e in example_pool]
        )

    def get_prompt(self, query, k=3):
        query_emb = self.embedder.encode([query])[0]
        similarities = np.dot(self.example_embeddings, query_emb)
        top_k = np.argsort(similarities)[-k:][::-1]

        prompt = ""
        for idx in top_k:
            ex = self.examples[idx]
            prompt += f"输入: {ex['input']}\n输出: {ex['output']}\n\n"

        prompt += f"输入: {query}\n输出:"
        return prompt

example_pool = [
    {"input": "苹果是什么颜色？", "output": "红色、绿色或黄色"},
    {"input": "Python 的创始人是谁？", "output": "Guido van Rossum"},
    {"input": "地球到月球的距离？", "output": "约 38.4 万公里"},
    {"input": "什么是递归？", "output": "函数调用自身的编程技术"},
]

print(f"示例池大小: {len(example_pool)}")
print("动态 Few-shot 根据查询相似度检索最相关的示例")


最佳实践
best_practices = {
    "示例数量": "3-5 个通常足够，过多反而会消耗上下文窗口",
    "示例质量": "确保示例准确、典型、无歧义",
    "示例顺序": "最相关的示例放在最后（接近查询位置）",
    "格式一致": "所有示例必须使用完全相同的输入输出格式",
    "覆盖边界": "包含边界情况和特殊情况的示例",
    "避免偏差": "确保示例中各类别分布均衡",
}

for practice, detail in best_practices.items():
    print(f"  ✅ {practice}: {detail}")


提示： 示例的顺序会影响模型输出。研究表明，将最相关的示例放在最后（最接近查询的位置）通常效果最好，因为 LLM 对近期上下文的注意力更强。






小结
    

  • 少样本学习让 LLM 通过提示中的示例理解新任务，无需参数更新。
    • 

  • 示例选择策略（相似度、多样性、难度递进）显著影响效果。
    • 

  • 检索增强提示动态选择与查询最相关的示例，是 few-shot 的最佳实践。
    • 

  • 示例数量 3-5 个通常足够，质量比数量更重要。
    • 

  • 示例的排列顺序影响输出，最相关的示例应放在最接近查询的位置。
