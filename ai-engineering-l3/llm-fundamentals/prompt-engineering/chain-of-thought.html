思维链

什么是思维链

思维链（Chain of Thought, CoT）是一种让 LLM 在给出最终答案前，先展示中间推理步骤的提示技术。它显著提升了模型在数学、逻辑和多步推理任务上的表现。



标准 CoT
标准 CoT 通过在 few-shot 示例中包含推理过程来引导模型：


standard_cot_prompt = """解答以下数学问题，请展示你的思考步骤。

问题：小明有 15 个苹果，他给了小红 3 个，又买了 7 个。小明现在有多少个苹果？

思考过程：
1. 小明初始有 15 个苹果
2. 给了小红 3 个: 15 - 3 = 12 个
3. 又买了 7 个: 12 + 7 = 19 个

答案：19 个苹果

问题：一个班有 40 名学生，其中 60% 选了数学课，选数学课的学生中有 75% 同时选了物理课。同时选了数学和物理的学生有多少人？

思考过程："""

print(standard_cot_prompt)

Zero-shot CoT
Zero-shot CoT 不需要提供示例，只需在提示末尾添加魔法短语"让我们一步步思考"（Let's think step by step）：


zero_shot_cot_prompts = {
    "中文触发": "请一步一步地思考这个问题。",
    "英文触发": "Let's think step by step.",
    "结构化触发": "请按以下方式分析：1) 识别关键信息 2) 列出推理步骤 3) 得出结论",
}

def apply_zero_shot_cot(question, trigger="请一步一步地思考这个问题。"):
    return f"{question}\n\n{trigger}"

question = "如果训练一个 7B 模型需要 8 张 A100 GPU 跑 3 天，那么训练一个 70B 模型大约需要多少 GPU 天？"
prompt = apply_zero_shot_cot(question)
print(prompt)


提示： Zero-shot CoT 的效果在大模型（>10B 参数）上最为显著。在小模型上，推理步骤可能不连贯反而降低准确率。






思维树
思维树（Tree of Thought, ToT）扩展了 CoT 的线性推理为树状搜索，模型可以探索多条推理路径并评估每条路径的前景：


def tree_of_thought_prompt(question, num_paths=3):
    return f"""问题：{question}

请用以下思维树方法解决：

第一步：生成 {num_paths} 种不同的解题思路
思路 1:
思路 2:
思路 3:

第二步：评估每种思路
- 思路 1 评估: [有前景/无前景] 理由:
- 思路 2 评估: [有前景/无前景] 理由:
- 思路 3 评估: [有前景/无前景] 理由:

第三步：深入最有前景的思路，完成推理

第四步：给出最终答案"""

prompt = tree_of_thought_prompt("如何设计一个支持百万级文档的 RAG 系统？")
print(prompt)


自一致性
自一致性（Self-Consistency）通过多次采样不同的推理路径，然后对最终答案进行多数投票来提高准确率：


import random
from collections import Counter

def self_consistency(question, llm, num_samples=5, temperature=0.7):
    answers = []
    for i in range(num_samples):
        prompt = f"{question}\n\n请一步一步地思考这个问题。"
        response = llm.generate(prompt, temperature=temperature)
        answer = extract_answer(response)
        answers.append(answer)

    vote = Counter(answers)
    best_answer = vote.most_common(1)[0]
    confidence = best_answer[1] / num_samples

    return best_answer[0], confidence

def extract_answer(response):
    return response.strip().split("\n")[-1]

simulated_answers = ["42", "42", "40", "42", "41"]
vote = Counter(simulated_answers)
best = vote.most_common(1)[0]
print(f"采样答案: {simulated_answers}")
print(f"最终答案: {best[0]} (一致率: {best[1]/len(simulated_answers)*100:.0f}%)")

提示： 在实际应用中，Zero-shot CoT 的"性价比"最高——只需添加一句话就能显著提升推理能力。对于关键决策场景，Self-Consistency 以适度的成本换取更高的可靠性。






小结
    

  • CoT 通过展示中间推理步骤显著提升 LLM 在复杂推理任务上的表现。
    • 

  • Zero-shot CoT 只需添加"让我们一步步思考"即可触发推理能力。
    • 

  • 思维树（ToT）将线性推理扩展为树状搜索，适合复杂决策问题。
    • 

  • 自一致性通过多次采样和投票提高答案可靠性。
    • 

  • CoT 方法的效果与模型规模正相关，在大模型上效果最显著。
