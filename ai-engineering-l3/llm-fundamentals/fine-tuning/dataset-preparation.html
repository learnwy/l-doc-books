数据集准备

数据是微调的关键

模型微调的效果很大程度上取决于训练数据的质量。即使是最先进的模型架构和训练算法，面对低质量数据也无法产出好的结果。数据集准备涵盖数据收集、清洗、格式化和质量控制的完整流程。



数据格式
SFT 数据通常采用对话格式，主流框架支持以下格式：


alpaca_format = {
    "instruction": "解释什么是机器学习中的过拟合",
    "input": "",
    "output": "过拟合是指模型在训练数据上表现优秀，但在新数据上表现差的现象。"
              "这通常是因为模型过度学习了训练数据中的噪声和细节，而非真正的模式。"
}

sharegpt_format = {
    "conversations": [
        {"from": "human", "value": "解释什么是机器学习中的过拟合"},

数据清洗
数据清洗是保证数据质量的基础步骤：


import re

def clean_text(text):
    text = re.sub(r'http[s]?://\S+', '[URL]', text)
    text = re.sub(r'\S+@\S+', '[EMAIL]', text)
    text = re.sub(r'\n{3,}', '\n\n', text)
    text = re.sub(r' {2,}', ' ', text)
    text = text.strip()
    return text

def validate_conversation(conv):
    if not conv.get("messages"):
        return False, "空对话"

    for msg in conv["messages"]:
        if msg["role"] not in ("system", "user", "assistant"):
            return False, f"非法角色: {msg['role']}"
        if len(msg["content"].strip()) == 0:
            return False, "空消息"

    roles = [m["role"] for m in conv["messages"] if m["role"] != "system"]
    for i in range(len(roles) - 1):
        if roles[i] == roles[i + 1]:
            return False, "连续相同角色"

    return True, "通过"

test_data = [
    {"messages": [
        {"role": "user", "content": "你好"},
        {"role": "assistant", "content": "你好！有什么可以帮助你的？"}
    ]},
    {"messages": [
        {"role": "user", "content": ""},
        {"role": "assistant", "content": "回答"}
    ]},
    {"messages": []},
]

for i, conv in enumerate(test_data):
    valid, reason = validate_conversation(conv)
    print(f"样本 {i}: {'✅' if valid else '❌'} {reason}")


质量过滤
高质量数据应满足以下标准：


def quality_filter(sample, min_len=50, max_len=4096):
    assistant_msgs = [
        m["content"] for m in sample["messages"]
        if m["role"] == "assistant"
    ]

    for msg in assistant_msgs:
        if len(msg) < min_len:
            return False, "回答过短"
        if len(msg) > max_len:
            return False, "回答过长"

    refusal_patterns = [
        "作为一个 AI", "我无法", "我不能提供",
        "As an AI", "I cannot", "I'm sorry"
    ]
    for msg in assistant_msgs:
        for pattern in refusal_patterns:
            if pattern in msg:
                return False, f"包含拒绝模式: {pattern}"

    return True, "通过质量检查"

sample = {"messages": [
    {"role": "user", "content": "如何优化 Python 代码性能？"},
    {"role": "assistant", "content": "优化 Python 代码性能有多种策略：" + "详细内容" * 20}
]}
valid, reason = quality_filter(sample)
print(f"质量检查: {'✅' if valid else '❌'} {reason}")

数据增强
当原始数据不足时，可以通过以下方法扩充数据集：


def augment_with_rephrasing(original_instruction):
    rephrasing_prompts = [
        f"请用不同的方式重新表述这个问题：{original_instruction}",
        f"将以下问题改写为更正式的表达：{original_instruction}",
        f"简化以下问题：{original_instruction}",
    ]
    return rephrasing_prompts

def create_multi_turn(single_turn_data):
    follow_up_templates = [
        "你能举一个具体的例子吗？",
        "这个概念在实际应用中是怎样的？",
        "有什么常见的误区需要注意？",
        "这和 {related_concept} 有什么区别？",
    ]
    return follow_up_templates

original = "解释什么是梯度消失问题"
rephrasings = augment_with_rephrasing(original)
for r in rephrasings:
    print(f"  → {r}")


提示： Self-Instruct 方法使用 LLM 自身来生成训练数据，是当前最常用的数据增强策略。但需要注意模型生成数据可能包含幻觉，需要人工验证。






数据划分与最终检查
import random

def split_dataset(data, train_ratio=0.9, val_ratio=0.05, test_ratio=0.05, seed=42):
    random.seed(seed)
    random.shuffle(data)

    n = len(data)
    train_end = int(n * train_ratio)
    val_end = train_end + int(n * val_ratio)

    return {
        "train": data[:train_end],
        "validation": data[train_end:val_end],
        "test": data[val_end:],
    }

mock_data = list(range(10000))
splits = split_dataset(mock_data)
for name, subset in splits.items():
    print(f"{name:12s}: {len(subset):,} 条 ({len(subset)/len(mock_data)*100:.0f}%)")

checklist = [
    "格式统一（所有样本使用相同的对话格式）",
    "无重复（train/val/test 无交叉）",
    "无泄露（test 中的问题未出现在 train 中）",
    "长度分布合理（统计 token 分布）",
    "任务多样性（覆盖目标任务类型）",
]
print("\n最终检查清单:")
for item in checklist:
    print(f"  ☐ {item}")


小结
    

  • 数据质量是微调成功的第一要素，远比数据数量重要。
    • 

  • SFT 数据推荐使用 Messages 格式（OpenAI 格式），兼容性最好。
    • 

  • 数据清洗需要覆盖格式验证、去重、长度过滤和毒性检测。
    • 

  • Self-Instruct 是高效的数据增强策略，但生成数据需要质量验证。
    • 

  • 数据划分后需确认无泄露、无重复、分布合理。
