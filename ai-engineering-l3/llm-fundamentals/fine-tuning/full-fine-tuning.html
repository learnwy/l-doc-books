全量微调

什么是全量微调

全量微调（Full Fine-Tuning）是指更新模型的全部参数以适应特定任务或领域。与参数高效微调（PEFT）不同，全量微调不冻结任何层，理论上能够最大化模型对目标任务的适应能力。



何时使用全量微调
全量微调并非总是最佳选择。以下是决策参考：

import numpy as np

def cosine_schedule(step, total_steps, warmup_steps, lr_max, lr_min=0):
    if step < warmup_steps:
        return lr_max * step / warmup_steps
    progress = (step - warmup_steps) / (total_steps - warmup_steps)
    return lr_min + 0.5 * (lr_max - lr_min) * (1 + np.cos(np.pi * progress))

total_steps = 1000
warmup_steps = 100
lr_max = 2e-5

for step in [0, 50, 100, 500, 900, 1000]:
    lr = cosine_schedule(step, total_steps, warmup_steps, lr_max)
    print(f"Step {step:4d}: lr = {lr:.2e}")

args = TrainingArguments(
    output_dir="./output",
    per_device_train_batch_size=4,
    gradient_accumulation_steps=8,
    learning_rate=2e-5,
    num_train_epochs=3,
    warmup_ratio=0.1,

    lr_scheduler_type="cosine",
    bf16=True,
    gradient_checkpointing=True,
    max_grad_norm=1.0,

    save_steps=500,
    evaluation_strategy="steps",
    eval_steps=500,
    logging_steps=10,

print(f"训练配置:")

print(f"  学习率: {args.learning_rate}")

提示： 梯度检查点（Gradient Checkpointing）可以用约 30% 的速度代价换取 60-70% 的激活值显存节省。对于 7B+ 模型的全量微调，几乎是必须开启的选项。






小结
    

  • 全量微调更新所有参数，理论上能达到最佳适配效果。
    • 

  • 适用于数据充足、追求最佳性能、且计算资源允许的场景。
    • 

  • 灾难性遗忘是核心挑战，需要通过低学习率、数据混合和正则化来缓解。
    • 

  • 7B 模型的全量微调需要约 100GB 显存，通常需要多卡并行。
    • 

  • 对于大多数实际应用，LoRA/QLoRA 是更实用的选择。
