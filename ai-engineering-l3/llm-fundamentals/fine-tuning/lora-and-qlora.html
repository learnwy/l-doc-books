LoRA 与 QLoRA

低秩适配原理

LoRA（Low-Rank Adaptation）的核心思想是：微调时权重的变化矩阵 ΔW\Delta WΔW 是低秩的。因此不需要更新完整的 d×dd \times dd×d 矩阵，只需要学习两个低秩矩阵 AAA 和 BBB：

W′=W+ΔW=W+BAW' = W + \Delta W = W + BAW′=W+ΔW=W+BA

其中 B∈Rd×rB \in \mathbb{R}^{d \times r}B∈Rd×r，A∈Rr×dA \in \mathbb{R}^{r \times d}A∈Rr×d，秩 r≪dr \ll dr≪d。

LoRA 实现
import torch
import torch.nn as nn

class LoRALayer(nn.Module):
    def __init__(self, in_features, out_features, rank=16, alpha=32):
        super().__init__()
        self.rank = rank
        self.alpha = alpha
        self.scaling = alpha / rank

        self.lora_A = nn.Parameter(torch.randn(in_features, rank) * 0.01)
        self.lora_B = nn.Parameter(torch.zeros(rank, out_features))

    def forward(self, x):
        return (x @ self.lora_A @ self.lora_B) * self.scaling

class LinearWithLoRA(nn.Module):
    def __init__(self, linear, rank=16, alpha=32):
        super().__init__()
        self.linear = linear
        self.linear.weight.requires_grad = False
        self.lora = LoRALayer(
            linear.in_features, linear.out_features, rank, alpha
        )

    def forward(self, x):
        return self.linear(x) + self.lora(x)

original = nn.Linear(4096, 4096)
lora_linear = LinearWithLoRA(original, rank=16)

total = sum(p.numel() for p in lora_linear.parameters())
trainable = sum(p.numel() for p in lora_linear.parameters() if p.requires_grad)
print(f"总参数: {total:,}")
print(f"可训练参数: {trainable:,}")
print(f"可训练比例: {trainable / total * 100:.2f}%")


提示： LoRA 的 A 矩阵通常用高斯初始化，B 矩阵用零初始化。这确保训练开始时 ΔW=BA=0\Delta W = BA = 0ΔW=BA=0，模型行为与预训练模型完全一致。

小结
    

  • LoRA 通过低秩分解将可训练参数量减少到原模型的 0.1-1%。
    • 

  • A 矩阵高斯初始化、B 矩阵零初始化确保训练起始时模型行为不变。
    • 

  • QLoRA 在 4-bit 量化基础上应用 LoRA，使 7B 模型在 6GB 显存内可训练。
    • 

  • target_modules 建议包含所有注意力投影和 FFN 投影层以获得最佳效果。
    • 

  • 训练完成后可将 LoRA 权重合并到基础模型，推理时无额外开销。
