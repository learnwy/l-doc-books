参数高效微调

PEFT 方法概览

参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）是一类只训练少量参数就能达到接近全量微调效果的方法。它们通过在模型中插入小型可训练模块或优化输入，大幅降低微调成本。



Prefix Tuning
Prefix Tuning 在每层 Transformer 的 Key 和 Value 前面添加可学习的"前缀"向量，相当于给模型的注意力添加了额外的虚拟上下文：


headi=Attention([PK;K]WiK,[PV;V]WiV,QWiQ)\text{head}_i = \text{Attention}([P_K; K]W_i^K, [P_V; V]W_i^V, QW_i^Q)headi​=Attention([PK​;K]WiK​,[PV​;V]WiV​,QWiQ​)
import torch
import torch.nn as nn

class PrefixTuning(nn.Module):
    def __init__(self, num_layers, num_heads, d_head, prefix_len=20):
        super().__init__()
        self.prefix_len = prefix_len
        self.prefix_keys = nn.Parameter(
            torch.randn(num_layers, prefix_len, num_heads, d_head) * 0.01
        )
        self.prefix_values = nn.Parameter(
            torch.randn(num_layers, prefix_len, num_heads, d_head) * 0.01
        )

    def get_prefix(self, layer_idx, batch_size):
        k = self.prefix_keys[layer_idx].unsqueeze(0).expand(batch_size, -1, -1, -1)
        v = self.prefix_values[layer_idx].unsqueeze(0).expand(batch_size, -1, -1, -1)
        return k, v

pt = PrefixTuning(num_layers=32, num_heads=32, d_head=128, prefix_len=20)
total = sum(p.numel() for p in pt.parameters())
print(f"Prefix Tuning 参数量: {total:,} ({total / 1e6:.1f}M)")


Prompt Tuning
Prompt Tuning 是 Prefix Tuning 的简化版本，只在输入嵌入层前面添加可学习的"软提示"向量：


import torch
import torch.nn as nn

class PromptTuning(nn.Module):
    def __init__(self, num_tokens, d_model):
        super().__init__()
        self.soft_prompts = nn.Parameter(
            torch.randn(num_tokens, d_model) * 0.01
        )

    def forward(self, input_embeds):
        batch_size = input_embeds.size(0)
        prompts = self.soft_prompts.unsqueeze(0).expand(batch_size, -1, -1)
        return torch.cat([prompts, input_embeds], dim=1)

pt = PromptTuning(num_tokens=20, d_model=4096)
total = sum(p.numel() for p in pt.parameters())
print(f"Prompt Tuning 参数量: {total:,} ({total / 1e3:.0f}K)")


提示： Prompt Tuning 的参数量极少（通常 <100K），但效果通常不如 LoRA。它更适合超大模型（100B+）上的轻量适配。






Adapters
Adapter 方法在 Transformer 的每层中插入小型的瓶颈网络（bottleneck），只训练这些插入的模块：


import torch
import torch.nn as nn

class Adapter(nn.Module):
    def __init__(self, d_model, bottleneck_dim=64):
        super().__init__()
        self.down_proj = nn.Linear(d_model, bottleneck_dim)
        self.activation = nn.GELU()
        self.up_proj = nn.Linear(bottleneck_dim, d_model)
        nn.init.zeros_(self.up_proj.weight)
        nn.init.zeros_(self.up_proj.bias)

    def forward(self, x):
        residual = x
        x = self.down_proj(x)
        x = self.activation(x)
        x = self.up_proj(x)
        return residual + x

adapter = Adapter(d_model=4096, bottleneck_dim=64)
trainable = sum(p.numel() for p in adapter.parameters())
print(f"单个 Adapter 参数量: {trainable:,}")

num_layers = 32
total_adapter_params = trainable * num_layers * 2
print(f"全模型 Adapter 参数量: {total_adapter_params:,} ({total_adapter_params / 1e6:.1f}M)")


IA3
IA3（Infused Adapter by Inhibiting and Amplifying Inner Activations）通过学习三个缩放向量来调节注意力的 Key、Value 和 FFN 的激活值：


K′=lK⊙K,V′=lV⊙V,FFN′=lFF⊙FFNK' = l_K \odot K, \quad V' = l_V \odot V, \quad \text{FFN}' = l_{FF} \odot \text{FFN}K′=lK​⊙K,V′=lV​⊙V,FFN′=lFF​⊙FFN
import torch
import torch.nn as nn

class IA3Layer(nn.Module):
    def __init__(self, d_model):
        super().__init__()
        self.l_k = nn.Parameter(torch.ones(d_model))
        self.l_v = nn.Parameter(torch.ones(d_model))
        self.l_ff = nn.Parameter(torch.ones(d_model))

    def scale_key(self, K):
        return self.l_k * K

    def scale_value(self, V):
        return self.l_v * V

    def scale_ff(self, ff_output):
        return self.l_ff * ff_output

ia3 = IA3Layer(d_model=4096)
params = sum(p.numel() for p in ia3.parameters())
print(f"单层 IA3 参数量: {params:,}")
print(f"32 层总量: {params * 32:,} ({params * 32 / 1e3:.0f}K)")

小结
    

  • PEFT 方法分为加法式（LoRA、Adapter）、前缀式（Prefix/Prompt Tuning）和重参数化（IA3）三大类。
    • 

  • LoRA 是当前最主流的 PEFT 方法，兼顾效率和效果，且推理时无额外开销。
    • 

  • Prefix Tuning 和 Prompt Tuning 适合多任务快速切换，但效果上限不如 LoRA。
    • 

  • Adapter 引入了推理延迟，但具有良好的模块化特性。
    • 

  • 选择 PEFT 方法时需要综合考虑参数效率、推理开销和任务效果。
