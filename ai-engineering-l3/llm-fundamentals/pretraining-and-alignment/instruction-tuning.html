指令微调

从语言模型到对话助手

预训练后的语言模型虽然具备强大的语言能力，但它本质上只是一个文本补全器——给它一段文字，它续写下去。指令微调（Instruction Tuning）通过在指令-回答数据对上进行监督微调（SFT），让模型学会理解并遵循人类指令。

SFT 训练过程
监督微调（Supervised Fine-Tuning）在指令数据集上用标准的交叉熵损失进行训练。关键区别是：只在回答部分计算损失，指令部分作为上下文但不参与损失计算。


import torch
import torch.nn.functional as F

def sft_loss_with_mask(logits, labels, loss_mask):
    shift_logits = logits[..., :-1, :].contiguous()
    shift_labels = labels[..., 1:].contiguous()
    shift_mask = loss_mask[..., 1:].contiguous()

    loss = F.cross_entropy(
        shift_logits.view(-1, shift_logits.size(-1)),
        shift_labels.view(-1),
        reduction='none'
    )
    loss = (loss * shift_mask.view(-1)).sum() / shift_mask.sum()
    return loss

batch_size, seq_len, vocab_size = 2, 20, 32000
logits = torch.randn(batch_size, seq_len, vocab_size)
labels = torch.randint(0, vocab_size, (batch_size, seq_len))
loss_mask = torch.zeros(batch_size, seq_len)
loss_mask[:, 10:] = 1.0

loss = sft_loss_with_mask(logits, labels, loss_mask)
print(f"SFT 损失（仅回答部分）: {loss.item():.4f}")

Chat 模板
不同模型使用不同的聊天模板（Chat Template）来组织多轮对话。模板定义了系统提示、用户消息和助手回复的格式：


templates = {
    "ChatML (Qwen)": (
        "<|im_start|>system\n你是一个助手<|im_end|>\n"
        "<|im_start|>user\n你好<|im_end|>\n"
        "<|im_start|>assistant\n"
    ),
    "LLaMA 3": (
        "<|begin_of_text|><|start_header_id|>system<|end_header_id|>\n"
        "你是一个助手<|eot_id|>"
        "<|start_header_id|>user<|end_header_id|>\n"
        "你好<|eot_id|>"
        "<|start_header_id|>assistant<|end_header_id|>\n"
    ),
    "Mistral": (
        "<s>[INST] 你好 [/INST]"
    ),
}

for name, tpl in templates.items():
    print(f"--- {name} ---")
    print(tpl)
    print()

系统提示
系统提示（System Prompt）是指令微调中的重要组成部分，它定义了模型的角色、行为约束和输出格式：


system_prompts = {
    "通用助手": "你是一个乐于助人的 AI 助手。请用简洁、准确的方式回答问题。",
    "代码助手": (
        "你是一个高级编程助手。遵循以下规则：\n"
        "1. 优先使用 Python 编写代码\n"
        "2. 代码必须包含类型注解\n"
        "3. 提供简要的代码注释\n"
        "4. 如果有多种方案，列出优缺点"
    ),
    "安全助手": (
        "你是一个遵守安全准则的 AI 助手。\n"
        "- 不提供任何有害、非法或不道德的内容\n"
        "- 对不确定的信息明确标注\n"
        "- 拒绝执行越权操作"
    ),
}

for role, prompt in system_prompts.items():
    print(f"[{role}]\n{prompt}\n")


提示： 系统提示的效果在指令微调阶段就需要被纳入训练。如果训练数据中没有包含系统提示，模型在推理时对系统提示的遵循能力会大打折扣。






小结
    

  • 指令微调（SFT）是将预训练模型转变为对话助手的关键步骤。
    • 

  • SFT 只在回答部分计算损失，指令部分作为上下文但不参与梯度更新。
    • 

  • 数据质量比数量更重要，少量高质量数据可以取得优异效果。
    • 

  • Chat 模板定义了多轮对话的格式，不同模型使用不同的模板标准。
    • 

  • 系统提示在训练阶段就需要被纳入，以确保模型在推理时能有效遵循。
