预训练目标

语言建模范式

预训练是大语言模型获得通用语言能力的核心阶段。模型在海量文本数据上通过自监督学习，掌握语法、语义和世界知识。不同的预训练目标决定了模型的能力特点和适用场景。



因果语言建模（CLM）
因果语言建模（Causal Language Modeling）是当前主流 LLM 的预训练目标。模型从左到右逐个预测下一个 token，每个位置只能看到它之前的 token：


P(x1,x2,…,xn)=∏t=1nP(xt∣x1,…,xt−1)P(x_1, x_2, \dots, x_n) = \prod_{t=1}^{n} P(x_t | x_1, \dots, x_{t-1})P(x1​,x2​,…,xn​)=t=1∏n​P(xt​∣x1​,…,xt−1​)
import torch
import torch.nn.functional as F

vocab_size = 32000
seq_len = 10
logits = torch.randn(1, seq_len, vocab_size)

target = torch.randint(0, vocab_size, (1, seq_len))

loss = F.cross_entropy(
    logits.view(-1, vocab_size),
    target.view(-1)
)
print(f"CLM 损失: {loss.item():.4f}")

probs = F.softmax(logits[0, -1], dim=-1)
next_token = torch.argmax(probs)
print(f"预测的下一个 token ID: {next_token.item()}")
CLM 使用因果掩码确保模型在预测位置 ttt 时只能关注位置 111 到 t−1t-1t−1：




提示： CLM 的核心优势是生成能力——模型天然学会了如何续写文本。这也是为什么 GPT 系列能够出色完成对话、写作等生成任务。






掩码语言建模（MLM）
掩码语言建模（Masked Language Modeling）是 BERT 的预训练目标。随机掩盖输入中约 15% 的 token，让模型预测被掩盖的部分：


import torch
import random

def create_mlm_data(token_ids, mask_prob=0.15, vocab_size=30522, mask_token_id=103):
    labels = token_ids.clone()
    masked_indices = torch.bernoulli(
        torch.full(token_ids.shape, mask_prob)
    ).bool()

    labels[~masked_indices] = -100

    input_ids = token_ids.clone()
    replace_mask = torch.bernoulli(torch.full(token_ids.shape, 0.8)).bool() & masked_indices
    input_ids[replace_mask] = mask_token_id

    random_mask = torch.bernoulli(torch.full(token_ids.shape, 0.5)).bool() & masked_indices & ~replace_mask
    random_tokens = torch.randint(0, vocab_size, token_ids.shape)
    input_ids[random_mask] = random_tokens[random_mask]

    return input_ids, labels

tokens = torch.randint(100, 30000, (1, 20))
masked_input, labels = create_mlm_data(tokens)
print(f"原始 token 数: {(labels != -100).sum().item()}")

下一个 Token 预测的本质
下一个 token 预测（Next Token Prediction）看似简单，实际上蕴含了极其丰富的学习信号。模型需要理解语法、语义、逻辑推理甚至世界知识才能准确预测：

小结
    

  • CLM（因果语言建模）是当前主流 LLM 的预训练目标，通过下一个 token 预测学习语言能力。
    • 

  • MLM（掩码语言建模）适合编码器模型，擅长理解任务但不适合生成。
    • 

  • 下一个 token 预测看似简单，实际上隐含了语法、语义、推理和世界知识的学习。
    • 

  • 预训练数据的质量、多样性和规模共同决定了模型的能力上限。
    • 

  • 数据预处理（去重、过滤、清洗）是预训练成功的关键环节。
