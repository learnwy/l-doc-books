缩放定律

什么是缩放定律

缩放定律（Scaling Laws）描述了模型性能如何随模型大小、数据量和计算量的增加而可预测地提升。这一发现使研究者能够在小规模实验中预测大规模训练的结果，从而大幅降低试错成本。

OpenAI 在 2020 年发现，语言模型的损失与模型参数量、数据量和计算量之间存在幂律关系：


L(N)≈(NcN)αNL(N) \approx \left(\frac{N_c}{N}\right)^{\alpha_N}L(N)≈(NNc​​)αN​
L(D)≈(DcD)αDL(D) \approx \left(\frac{D_c}{D}\right)^{\alpha_D}L(D)≈(DDc​​)αD​
L(C)≈(CcC)αCL(C) \approx \left(\frac{C_c}{C}\right)^{\alpha_C}L(C)≈(CCc​​)αC​


Chinchilla 缩放定律
2022 年 DeepMind 的 Chinchilla 论文提出了更精确的缩放关系，核心发现是：最优训练需要模型大小和数据量同步增长。






研究
核心观点

Chinchilla 定律的核心公式：


L(N,D)=E+ANα+BDβL(N, D) = E + \frac{A}{N^\alpha} + \frac{B}{D^\beta}L(N,D)=E+NαA​+DβB​
其中 EEE 是不可约损失，A/NαA/N^\alphaA/Nα 是欠拟合项（模型太小），B/DβB/D^\betaB/Dβ 是数据不足项。


import numpy as np

def chinchilla_loss(N, D, E=1.69, A=406.4, B=410.7, alpha=0.34, beta=0.28):
    return E + A / (N ** alpha) + B / (D ** beta)

configs = [
    ("1B 模型, 20B tokens", 1e9, 20e9),
    ("7B 模型, 140B tokens", 7e9, 140e9),
    ("70B 模型, 1.4T tokens", 70e9, 1.4e12),
    ("7B 模型, 2T tokens (过训练)", 7e9, 2e12),
]

for name, N, D in configs:
    loss = chinchilla_loss(N, D)
    ratio = D / N
    print(f"{name:35s} | 损失: {loss:.3f} | tokens/param: {ratio:.0f}")


计算最优训练
给定固定的计算预算 CCC，如何分配模型大小 NNN 和数据量 DDD？


C≈6NDC \approx 6NDC≈6ND
（其中 6 是 FLOPs 近似系数：前向 2ND + 反向 4ND）


import numpy as np

def optimal_allocation(compute_budget, alpha=0.34, beta=0.28):
    ratio = alpha / beta
    N_optimal = (compute_budget / 6) ** (beta / (alpha + beta))
    D_optimal = compute_budget / (6 * N_optimal)
    return N_optimal, D_optimal

budgets = {
    "A100 1台 1天": 3.1e17,
    "A100 8台 1周": 1.7e19,
    "A100 256台 3月": 5.9e22,
    "A100 2048台 6月": 9.5e23,
}

for name, C in budgets.items():
    N, D = optimal_allocation(C)
    print(f"{name:20s} → 最优模型: {N/1e9:.1f}B 参数, 数据: {D/1e9:.0f}B tokens")


提示： 实际工业界训练中，LLaMA 等模型选择了远超 Chinchilla 最优比例的训练数据量。虽然训练不是计算最优的，但更小的模型配合更长的训练可以获得更好的推理效率——这在部署时更经济。






涌现能力
当模型规模超过某个阈值时，会突然展现出在小规模模型中完全不存在的能力，这就是涌现能力（Emergent Abilities）：

大致阈值
说明





少样本学习
~1B
通过示例学习新任务




思维链推理
~10B

代码生成
~10B
编写可执行代码




多步数学推理
~100B
解决多步骤数学题




指令遵循
~1B (对齐后)
按指令完成任务





关于涌现能力存在争议——部分研究认为"涌现"可能是评估指标不连续造成的假象，如果使用连续指标（如 Brier Score），能力的增长实际上是平滑的。

import numpy as np

def predict_scaling(small_loss, small_N, target_N, alpha=0.34):
    scaling_factor = (small_N / target_N) ** alpha
    predicted_loss = small_loss * scaling_factor
    return predicted_loss

loss_1b = 2.5
for target in [7, 13, 70, 405]:
    predicted = predict_scaling(loss_1b, 1, target, alpha=0.076)
    improvement = (1 - predicted / loss_1b) * 100
    print(f"1B → {target:3d}B: 预测损失 {predicted:.3f} (提升 {improvement:.1f}%)")


小结
    

  • 缩放定律揭示了模型性能与参数量、数据量、计算量之间的幂律关系。
    • 

  • Chinchilla 定律指出计算最优训练需要模型大小与数据量同步增长，约 20 tokens/parameter。
    • 

  • 实践中常采用"过训练"策略（如 LLaMA），牺牲训练效率换取更好的推理效率。
    • 

  • 涌现能力是规模化带来的重要现象，但其本质仍有争议。
    • 

  • 缩放定律使得从小规模实验预测大规模结果成为可能，极大降低了试错成本。
