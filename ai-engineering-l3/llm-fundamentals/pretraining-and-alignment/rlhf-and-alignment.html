RLHF 与对齐

为什么需要对齐

预训练后的语言模型擅长预测下一个 token，但并不天然知道如何"有用、诚实且无害"地回答问题。对齐（Alignment）就是将模型的行为与人类期望对齐的过程。

奖励模型
RLHF 的第一步是训练一个奖励模型（Reward Model, RM）。奖励模型学习人类对不同回答的偏好，为后续的强化学习提供信号。


训练数据格式：给定同一个提示，人类标注者对多个回答进行排序。


import torch
import torch.nn as nn

class RewardModel(nn.Module):
    def __init__(self, base_model, hidden_size):
        super().__init__()
        self.backbone = base_model
        self.reward_head = nn.Linear(hidden_size, 1)

    def forward(self, input_ids, attention_mask):
        outputs = self.backbone(input_ids, attention_mask=attention_mask)
        last_hidden = outputs.last_hidden_state[:, -1, :]
        reward = self.reward_head(last_hidden)
        return reward

def reward_loss(reward_chosen, reward_rejected):
    return -torch.log(torch.sigmoid(reward_chosen - reward_rejected)).mean()

r_chosen = torch.tensor([2.5])
r_rejected = torch.tensor([1.0])
loss = reward_loss(r_chosen, r_rejected)
print(f"奖励模型损失: {loss.item():.4f}")
print(f"正确排序概率: {torch.sigmoid(r_chosen - r_rejected).item():.4f}")


PPO 算法
PPO（Proximal Policy Optimization）是 RLHF 中最常用的强化学习算法。它通过限制策略更新的幅度来保持训练稳定性：


LPPO=E[min⁡(rt(θ)A^t,clip(rt(θ),1−ϵ,1+ϵ)A^t)]\mathcal{L}_{\text{PPO}} = \mathbb{E}\left[\min\left(r_t(\theta)\hat{A}_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t\right)\right]LPPO​=E[min(rt​(θ)A^t​,clip(rt​(θ),1−ϵ,1+ϵ)A^t​)]
其中 rt(θ)=πθ(at∣st)πθold(at∣st)r_t(\theta) = \frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_{\text{old}}}(a_t|s_t)}rt​(θ)=πθold​​(at​∣st​)πθ​(at​∣st​)​ 是新旧策略的概率比。


RLHF 的完整损失函数还包含 KL 散度惩罚，防止模型偏离 SFT 后的分布太远：


L=E[R(x,y)]−β⋅DKL[πθ(y∣x)∥πref(y∣x)]\mathcal{L} = \mathbb{E}[R(x, y)] - \beta \cdot D_{\text{KL}}[\pi_\theta(y|x) \| \pi_{\text{ref}}(y|x)]L=E[R(x,y)]−β⋅DKL​[πθ​(y∣x)∥πref​(y∣x)]
import torch
import torch.nn.functional as F

def compute_ppo_loss(logprobs, old_logprobs, advantages, clip_eps=0.2):
    ratio = torch.exp(logprobs - old_logprobs)
    clipped_ratio = torch.clamp(ratio, 1 - clip_eps, 1 + clip_eps)
    loss = -torch.min(ratio * advantages, clipped_ratio * advantages).mean()
    return loss

def kl_penalty(logprobs_policy, logprobs_ref, beta=0.1):
    kl = logprobs_policy - logprobs_ref
    return beta * kl.mean()

logprobs = torch.tensor([-1.2, -0.8, -1.5])
old_logprobs = torch.tensor([-1.3, -0.9, -1.4])
ref_logprobs = torch.tensor([-1.5, -1.0, -1.6])
advantages = torch.tensor([1.0, -0.5, 0.8])

ppo_loss = compute_ppo_loss(logprobs, old_logprobs, advantages)
kl = kl_penalty(logprobs, ref_logprobs)
total = ppo_loss + kl
print(f"PPO 损失: {ppo_loss.item():.4f}, KL 惩罚: {kl.item():.4f}, 总损失: {total.item():.4f}")


提示： RLHF-PPO 训练需要同时维护四个模型：策略模型、参考模型、奖励模型和价值模型，显存需求巨大。这是 DPO 等替代方案兴起的重要原因。






DPO：直接偏好优化
DPO（Direct Preference Optimization）绕过了奖励模型和强化学习，直接在偏好数据上优化策略：


LDPO=−E[log⁡σ(βlog⁡πθ(yw∣x)πref(yw∣x)−βlog⁡πθ(yl∣x)πref(yl∣x))]\mathcal{L}_{\text{DPO}} = -\mathbb{E}\left[\log\sigma\left(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta\log\frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)\right]LDPO​=−E[logσ(βlogπref​(yw​∣x)πθ​(yw​∣x)​−βlogπref​(yl​∣x)πθ​(yl​∣x)​)]

import torch
import torch.nn.functional as F

def dpo_loss(policy_chosen_logps, policy_rejected_logps,
             ref_chosen_logps, ref_rejected_logps, beta=0.1):
    chosen_rewards = beta * (policy_chosen_logps - ref_chosen_logps)
    rejected_rewards = beta * (policy_rejected_logps - ref_rejected_logps)
    loss = -F.logsigmoid(chosen_rewards - rejected_rewards).mean()
    return loss

loss = dpo_loss(
    policy_chosen_logps=torch.tensor([-2.0]),
    policy_rejected_logps=torch.tensor([-3.5]),
    ref_chosen_logps=torch.tensor([-2.5]),
    ref_rejected_logps=torch.tensor([-3.0]),
    beta=0.1
)
print(f"DPO 损失: {loss.item():.4f}")


Constitutional AI
Constitutional AI（CAI）由 Anthropic 提出，通过一组明确的"宪法规则"来引导模型的自我改进：


宪法规则示例：


    

  1. 选择最有帮助、最准确、最无害的回答
    2. 

  2. 选择不鼓励非法行为的回答
    3. 

  3. 选择最诚实、不具欺骗性的回答

这种方法减少了对人类标注的依赖，同时保持了良好的对齐效果。




小结
    

  • 对齐是将预训练模型的行为与人类期望（有用、诚实、无害）匹配的关键步骤。
    • 

  • 奖励模型通过学习人类偏好排序来提供训练信号。
    • 

  • PPO 是经典的 RLHF 算法，但需要四个模型且训练复杂。
    • 

  • DPO 简化了对齐流程，直接在偏好数据上优化，降低了训练门槛。
    • 

  • Constitutional AI 通过规则驱动的自我改进减少了对人类标注的依赖。
