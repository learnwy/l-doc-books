学习排序

核心概念

学习排序（Learning to Rank, LTR）是利用机器学习方法自动学习文档排序函数的技术，是搜索引擎排序的核心范式。与手工调参的排序规则不同，LTR 从大规模标注数据中学习特征与相关性之间的复杂映射关系，能够处理数百个排序特征的非线性组合。

排序特征工程
排序特征是 LTR 模型的输入，直接决定了模型的表达能力上界。排序特征通常分为查询特征、文档特征和查询-文档交互特征三类。


interface RankingFeatures {
  queryFeatures: QueryFeatures;
  docFeatures: DocFeatures;
  interactionFeatures: InteractionFeatures;
}

interface QueryFeatures {
  queryLength: number;
  queryTermCount: number;
  avgIDF: number;
  queryEntropy: number;
  isNavigational: boolean;
  queryEmbedding: Float32Array;
}

interface DocFeatures {
  docLength: number;
  pageRank: number;
  clickCount: number;
  freshness: number;
  domainAuthority: number;
  titleLength: number;
  urlDepth: number;
}

interface InteractionFeatures {
  bm25Score: number;
  tfidfCosine: number;
  titleBM25: number;
  queryTermCoverage: number;
  exactMatchCount: number;
  proximityScore: number;
  embedSimilarity: number;
  queryTermInTitle: boolean;
  queryTermInUrl: boolean;
}

function extractFeatures(query: string, doc: Document, index: InvertedIndex): RankingFeatures {
  const queryTokens = tokenize(query);
  const docTokens = tokenize(doc.content);

  return {
    queryFeatures: {
      queryLength: query.length,
      queryTermCount: queryTokens.length,
      avgIDF: queryTokens.reduce((s, t) => s + getIDF(t, index), 0) / queryTokens.length,
      queryEntropy: calculateEntropy(queryTokens, index),
      isNavigational: detectNavigationalIntent(query),
      queryEmbedding: new Float32Array(768),
    },
    docFeatures: {
      docLength: docTokens.length,
      pageRank: doc.pageRank,
      clickCount: doc.clickStats.total,
      freshness: Date.now() - doc.lastModified,
      domainAuthority: doc.domainAuthority,
      titleLength: doc.title.length,
      urlDepth: doc.url.split('/').length - 3,
    },
    interactionFeatures: {
      bm25Score: calculateBM25(queryTokens, docTokens, index),
      tfidfCosine: calculateTFIDFCosine(queryTokens, docTokens, index),
      titleBM25: calculateBM25(queryTokens, tokenize(doc.title), index),
      queryTermCoverage: queryTokens.filter((t) => docTokens.includes(t)).length / queryTokens.length,
      exactMatchCount: countExactMatches(query, doc.content),
      proximityScore: calculateProximity(queryTokens, docTokens),
      embedSimilarity: cosineSim(query, doc.content),
      queryTermInTitle: queryTokens.some((t) => doc.title.includes(t)),
      queryTermInUrl: queryTokens.some((t) => doc.url.includes(t)),
    },
  };
}
特征工程是 LTR 中最耗时但最有价值的环节。经验表明，BM25 分数、点击率、PageRank 和嵌入相似度是最重要的四类特征。在实际系统中，排序特征数量通常在 200-1000 之间。


LambdaMART 与梯度提升排序
LambdaMART 是工业界最广泛使用的 LTR 模型，它结合了 LambdaRank 的梯度计算方法和 MART（Multiple Additive Regression Trees，即 GBDT）的集成学习框架。


LambdaMART 的核心创新是 Lambda 梯度：它不直接优化不可微的排序指标（如 NDCG），而是定义了一个隐式的梯度函数 λ，使得每棵树的分裂方向都朝着改善排序指标的方向进行。


interface LambdaMARTConfig {
  numTrees: number;
  maxDepth: number;
  learningRate: number;
  minDataInLeaf: number;
  numLeaves: number;
  metric: 'ndcg' | 'map' | 'mrr';
  ndcgTruncation: number;
}

interface LambdaGradient {
  docIdx: number;
  gradient: number;
  hessian: number;
}

function computeLambdaGradients(scores: number[], labels: number[], config: LambdaMARTConfig): LambdaGradient[] {
  const gradients: LambdaGradient[] = scores.map((_, i) => ({
    docIdx: i,
    gradient: 0,
    hessian: 0,
  }));

  for (let i = 0; i < scores.length; i++) {
    for (let j = i + 1; j < scores.length; j++) {
      if (labels[i] === labels[j]) continue;

      const highIdx = labels[i] > labels[j] ? i : j;
      const lowIdx = labels[i] > labels[j] ? j : i;

      const scoreDiff = scores[highIdx] - scores[lowIdx];
      const rho = 1 / (1 + Math.exp(scoreDiff));

      const deltaNDCG = computeDeltaNDCG(highIdx, lowIdx, labels, scores, config.ndcgTruncation);
      const lambda = Math.abs(deltaNDCG) * rho;

      gradients[highIdx].gradient += lambda;
      gradients[lowIdx].gradient -= lambda;
      gradients[highIdx].hessian += lambda * (1 - rho);
      gradients[lowIdx].hessian += lambda * (1 - rho);
    }
  }

  return gradients;
}
LambdaMART 在搜索引擎、推荐系统和广告排序中有广泛应用。它的优势包括：训练速度快、可解释性较好（可以输出特征重要性）、处理稀疏特征和缺失值的能力强。


深度学习排序模型
深度学习排序模型直接从原始文本或特征向量中学习排序函数，无需手工设计交互特征。它们在处理语义匹配和捕获复杂特征交互方面优于传统的 GBDT 模型。

深度学习排序模型的部署挑战主要在于推理延迟。BERT-Ranker 对每个查询-文档对都需要一次完整的 Transformer 前向传播，在线延迟高。常见的优化策略包括模型蒸馏（将 BERT 知识蒸馏到轻量级模型）、预计算（离线计算文档特征向量）和缓存（缓存高频查询的排序结果）。


小结
    

  • 学习排序（LTR）通过机器学习自动学习排序函数，是搜索引擎排序的核心范式
    • 

  • Pairwise（尤其是 LambdaMART）是工业界最主流的方法，兼顾效果和效率
    • 

  • 排序特征工程是 LTR 中最关键的环节，BM25、点击率、PageRank 和嵌入相似度是核心特征
    • 

  • LambdaMART 通过 Lambda 梯度间接优化 NDCG 等不可微的排序指标
    • 

  • 深度学习排序模型在语义匹配方面有优势，但需要通过蒸馏和缓存解决在线延迟问题
    •
