嵌入模型

核心概念

嵌入模型（Embedding Model）是将文本映射为固定维度数值向量的神经网络，是稠密检索、语义搜索和 RAG 系统的基础组件。一个好的嵌入模型应该使语义相近的文本在向量空间中距离更近，语义无关的文本距离更远。

对比学习训练框架
对比学习（Contrastive Learning）是训练嵌入模型的核心方法。基本思想是拉近正样本对（语义相似的文本）的向量距离，推远负样本对（语义不相关的文本）的向量距离。


InfoNCE 是最常用的对比学习损失函数。给定一个 anchor、一个正样本和 N-1 个负样本，InfoNCE 损失将正样本识别问题转化为 N 分类问题：


interface ContrastiveBatch {
  anchors: Float32Array[];
  positives: Float32Array[];
  negatives: Float32Array[][];
  temperature: number;
}

function infoNCELoss(batch: ContrastiveBatch): number {
  const { anchors, positives, negatives, temperature } = batch;
  let totalLoss = 0;

  for (let i = 0; i < anchors.length; i++) {
    const posSim = cosineSimilarity(anchors[i], positives[i]) / temperature;
    let logSumExp = Math.exp(posSim);

    for (const neg of negatives[i]) {
      const negSim = cosineSimilarity(anchors[i], neg) / temperature;
      logSumExp += Math.exp(negSim);
    }

    totalLoss += -posSim + Math.log(logSumExp);
  }

  return totalLoss / anchors.length;
}

function cosineSimilarity(a: Float32Array, b: Float32Array): number {
  let dot = 0,
    normA = 0,
    normB = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    normA += a[i] * a[i];
    normB += b[i] * b[i];
  }
  return dot / (Math.sqrt(normA) * Math.sqrt(normB) + 1e-8);
}
训练数据的构造策略对模型质量至关重要。高质量的训练对包括：查询-文档对（搜索日志）、问题-答案对（QA 数据集）、前提-蕴含对（NLI 数据集）、标题-正文对（百科/论文）。大规模弱监督数据（如网页标题-内容对）可以用于预训练阶段，精标数据用于微调阶段。


指令感知嵌入
传统嵌入模型对所有任务使用相同的编码方式，无法区分检索、分类、聚类等不同任务的语义需求。指令感知嵌入（Instruction-aware Embedding）通过在输入文本前添加任务指令（Task Instruction），让模型根据不同任务生成不同的向量表示。


interface TaskInstruction {
  retrieval: string;
  classification: string;
  clustering: string;
  sts: string;
}

const E5_INSTRUCTIONS: TaskInstruction = {
  retrieval: 'query: ',
  classification: 'classify: ',
  clustering: 'cluster: ',
  sts: 'similarity: ',
};

const BGE_INSTRUCTIONS: TaskInstruction = {
  retrieval: 'Represent this sentence for searching relevant passages: ',
  classification: 'Represent this sentence for classifying: ',
  clustering: 'Represent this sentence for clustering: ',
  sts: 'Represent this sentence: ',
};

interface InstructionAwareEncoder {
  encode(text: string, instruction: string): Promise<Float32Array>;
  encodeBatch(texts: string[], instruction: string): Promise<Float32Array[]>;
}
E5 系列模型（E5、E5-mistral）是指令感知嵌入的先驱。E5-mistral-7b 基于 Mistral-7B 进行对比学习微调，支持长达 32768 tokens 的输入，在 MTEB 基准上取得了当时最优的结果。BGE 系列提供了从 small（33M）到 large（326M）的多种规格，特别在中文场景有显著优势。


Matryoshka 表示学习
Matryoshka Representation Learning（MRL）是一种训练嵌入模型的方法，使得模型生成的向量可以在不同维度上截断使用，而不需要重新训练。这种"套娃"式的表示允许用户根据存储和计算预算灵活选择向量维度。


interface MatryoshkaConfig {
  fullDimension: number;
  subDimensions: number[];
  lossWeights: number[];
}

function matryoshkaLoss(embeddings: Float32Array[], labels: number[], config: MatryoshkaConfig): number {
  let totalLoss = 0;

  for (let i = 0; i < config.subDimensions.length; i++) {
    const dim = config.subDimensions[i];
    const weight = config.lossWeights[i];

    const truncated = embeddings.map((e) => e.slice(0, dim));
    const normalized = truncated.map(l2Normalize);
    totalLoss += weight * contrastiveLoss(normalized, labels);
  }

  return totalLoss;
}

function truncateEmbedding(embedding: Float32Array, targetDim: number): Float32Array {
  const truncated = embedding.slice(0, targetDim);
  return l2Normalize(truncated);
}

OpenAI 的 text-embedding-3 系列原生支持 MRL，用户可以通过 API 参数指定输出维度。这种灵活性使得同一个模型可以适配不同的部署场景。


多语言与跨语言嵌入
多语言嵌入模型将不同语言的文本映射到同一个向量空间，使得跨语言的语义搜索和文档匹配成为可能。核心挑战是在缺少跨语言平行语料的情况下实现高质量的语言对齐。


训练多语言嵌入模型的主要策略包括：翻译对齐法（将平行语料的翻译对作为正样本进行对比学习）、教师蒸馏法（用高质量的英文嵌入模型作为教师，训练多语言学生模型模仿教师的向量输出）以及多语言对比学习（在多语言混合数据上直接进行对比学习）。


多语言嵌入的评估需要关注单语检索质量和跨语言迁移质量两个维度。MIRACL（Multilingual Information Retrieval Across a Continuum of Languages）和 MTEB 多语言子集是常用的评估基准。


小结
    

  • 嵌入模型是语义搜索的基础，通过对比学习将文本映射到连续向量空间，实现语义级别的相似度计算
    • 

  • 指令感知嵌入（E5、BGE）通过任务指令让同一模型适配不同任务，显著提升多任务泛化能力
    • 

  • Matryoshka 表示学习允许向量维度灵活截断，一个模型适配多种存储和计算约束
    • 

  • 多语言嵌入通过翻译对齐、知识蒸馏等方法实现跨语言语义搜索
    • 

  • 选择嵌入模型需综合考虑维度、最大长度、多语言支持、推理速度和下游任务适配性
    •
