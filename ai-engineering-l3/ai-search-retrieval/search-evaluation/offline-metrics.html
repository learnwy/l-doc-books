离线评估指标

核心概念

离线评估指标（Offline Evaluation Metrics）是衡量搜索系统排序质量的量化标准，在模型训练、迭代优化和上线前验证中发挥核心作用。离线评估基于预先构建的标注数据集，无需真实用户参与，能够快速、低成本地评估模型变更的影响。

精确率、召回率与 F1
精确率（Precision）和召回率（Recall）是信息检索中最基本的评估指标。P@k 衡量前 k 个结果中相关文档的比例，R@k 衡量所有相关文档中被检索到的比例。


interface BinaryLabel {
  docId: string;
  relevant: boolean;
}

interface RankedResult {
  docId: string;
  rank: number;
  score: number;
}

function precisionAtK(results: RankedResult[], labels: BinaryLabel[], k: number): number {
  const topK = results.slice(0, k);
  const labelMap = new Map(labels.map((l) => [l.docId, l.relevant]));
  const relevantCount = topK.filter((r) => labelMap.get(r.docId) === true).length;
  return relevantCount / k;
}

function recallAtK(results: RankedResult[], labels: BinaryLabel[], k: number): number {
  const topK = results.slice(0, k);
  const labelMap = new Map(labels.map((l) => [l.docId, l.relevant]));
  const totalRelevant = labels.filter((l) => l.relevant).length;
  if (totalRelevant === 0) return 0;
  const foundRelevant = topK.filter((r) => labelMap.get(r.docId) === true).length;
  return foundRelevant / totalRelevant;
}

function f1Score(precision: number, recall: number): number {
  if (precision + recall === 0) return 0;
  return (2 * precision * recall) / (precision + recall);
}

function meanReciprocalRank(queries: Array<{ results: RankedResult[]; labels: BinaryLabel[] }>): number {
  let totalRR = 0;
  for (const { results, labels } of queries) {
    const labelMap = new Map(labels.map((l) => [l.docId, l.relevant]));
    const firstRelevantRank = results.findIndex((r) => labelMap.get(r.docId) === true) + 1;
    totalRR += firstRelevantRank > 0 ? 1 / firstRelevantRank : 0;
  }
  return totalRR / queries.length;
}
MRR（Mean Reciprocal Rank）关注第一个相关结果出现的位置，适用于导航型查询（用户通常只需要一个正确答案）。MAP（Mean Average Precision）是对所有相关文档位置的平均精确率求均值，综合考虑了精确率和召回率。


NDCG 与分级相关性
NDCG（Normalized Discounted Cumulative Gain）是搜索评估中最常用的指标，它支持多级别的相关性标注（如 0-4 分），并通过位置折扣（Discounting）给靠前位置更高的权重。


interface GradedLabel {
  docId: string;
  relevance: number;
}

function dcgAtK(results: RankedResult[], labels: GradedLabel[], k: number): number {
  const labelMap = new Map(labels.map((l) => [l.docId, l.relevance]));
  let dcg = 0;

  for (let i = 0; i < Math.min(k, results.length); i++) {
    const rel = labelMap.get(results[i].docId) ?? 0;
    dcg += (Math.pow(2, rel) - 1) / Math.log2(i + 2);
  }

  return dcg;
}

function idealDCGAtK(labels: GradedLabel[], k: number): number {
  const sortedLabels = [...labels].sort((a, b) => b.relevance - a.relevance);
  let idcg = 0;

  for (let i = 0; i < Math.min(k, sortedLabels.length); i++) {
    const rel = sortedLabels[i].relevance;
    idcg += (Math.pow(2, rel) - 1) / Math.log2(i + 2);
  }

  return idcg;
}

function ndcgAtK(results: RankedResult[], labels: GradedLabel[], k: number): number {
  const dcg = dcgAtK(results, labels, k);
  const idcg = idealDCGAtK(labels, k);
  return idcg === 0 ? 0 : dcg / idcg;
}

function meanNDCG(queries: Array<{ results: RankedResult[]; labels: GradedLabel[] }>, k: number): number {
  const ndcgValues = queries.map((q) => ndcgAtK(q.results, q.labels, k));
  return ndcgValues.reduce((sum, v) => sum + v, 0) / ndcgValues.length;
}
NDCG 的关键优势是：支持分级标注（比二元标注更细粒度）、位置敏感（对排序顶部的错误惩罚更重）、归一化后可跨查询比较。NDCG@10 是搜索引擎评估中最常用的指标。

点击推断（Click-through Data）利用用户的搜索点击行为自动生成相关性标签。常见的假设包括：被点击的文档比未被点击的更相关（Skip-Above 假设）、点击后停留时间长的更相关（Dwell Time 假设）。这些推断存在位置偏差（Position Bias），需要通过 IPW（Inverse Propensity Weighting）等方法进行校正。


统计显著性检验
单次评估的 NDCG 差异可能只是随机波动。统计显著性检验帮助判断两个系统之间的效果差异是否具有统计意义。


常用的检验方法包括配对 t 检验（适用于正态分布的指标差异）、Wilcoxon 符号秩检验（非参数方法，不假设正态分布）和 Bootstrap 置信区间。在搜索评估中，通常设定 p < 0.05 为显著性阈值，并使用 Bonferroni 校正来控制多重比较的假阳性率。


interface SignificanceTest {
  method: 'paired_t' | 'wilcoxon' | 'bootstrap';
  confidence: number;
  nBootstrap?: number;
}

function pairedTTest(systemA: number[], systemB: number[]): { tStatistic: number; pValue: number } {
  const n = systemA.length;
  const diffs = systemA.map((a, i) => a - systemB[i]);
  const meanDiff = diffs.reduce((s, d) => s + d, 0) / n;
  const variance = diffs.reduce((s, d) => s + (d - meanDiff) ** 2, 0) / (n - 1);
  const stdError = Math.sqrt(variance / n);
  const tStat = meanDiff / stdError;
  return { tStatistic: tStat, pValue: twoTailedPValue(tStat, n - 1) };
}
小结
    

  • P@k、R@k 和 F1 是基础的二元评估指标，MRR 适合单答案场景，MAP 综合衡量排序和召回
    • 

  • NDCG 是搜索评估的核心指标，支持分级标注和位置折扣，NDCG@10 最常用
    • 

  • 评估数据集可通过专家标注、众包、点击推断或 LLM 标注获取，各有成本-质量权衡
    • 

  • 点击推断需要校正位置偏差（IPW 方法），否则评估结果会系统性偏向高位置文档
    • 

  • 统计显著性检验是确认模型改进真实有效的必要步骤，建议使用配对 t 检验或 Bootstrap
    •
