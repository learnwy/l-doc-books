人工评估

核心概念

人工评估（Human Evaluation）是由人类评估员对搜索结果的相关性和质量进行主观判断的评估方法。尽管自动化指标和在线实验日益成熟，人工评估仍然是搜索质量评估不可替代的组成部分，尤其在评估语义理解深度、内容质量和用户满意度等难以量化的维度。

评估标准设计
制定清晰、一致的评估标准（Annotation Guideline）是人工评估质量的基础。好的评估标准需要定义明确的等级划分、提供充分的示例，并覆盖边界情况。


interface RelevanceGuideline {
  levels: RelevanceLevel[];
  examples: AnnotationExample[];
  edgeCases: EdgeCase[];
  queryTypes: QueryTypeGuideline[];
}

interface RelevanceLevel {
  score: number;
  label: string;
  description: string;
  criteria: string[];
}

const FIVE_POINT_SCALE: RelevanceLevel[] = [
  {
    score: 4,
    label: '完美匹配',
    description: '完全满足查询需求，信息准确、全面、权威',
    criteria: ['直接回答查询问题', '信息完整无遗漏', '来源权威可信'],
  },
  {
    score: 3,
    label: '高度相关',
    description: '大部分满足查询需求，信息准确但可能不完整',
    criteria: ['回答了主要问题', '信息基本准确', '可能缺少细节'],
  },
  {
    score: 2,
    label: '部分相关',
    description: '与查询主题相关但未直接回答问题',
    criteria: ['主题相关', '提供背景信息', '未直接解决用户需求'],
  },
  {
    score: 1,
    label: '勉强相关',
    description: '与查询有微弱关联，信息价值低',
    criteria: ['仅在某个词匹配', '信息过时或不可靠', '需要大量额外搜索'],
  },
  {
    score: 0,
    label: '不相关',
    description: '与查询完全无关或有害',
    criteria: ['完全无关', '误导性信息', '垃圾内容'],
  },
];

interface AnnotationExample {
  query: string;
  document: string;
  score: number;
  reasoning: string;
}

interface EdgeCase {
  scenario: string;
  guideline: string;
  example: AnnotationExample;
}
评估标准的设计需要针对不同查询类型进行差异化。导航型查询的 "完美匹配" 是目标页面本身；信息型查询的 "完美匹配" 是完整准确回答问题的内容；交易型查询的 "完美匹配" 是包含价格、可购买链接的商品页面。


评估员管理与质量控制
人工评估的质量高度依赖评估员的能力和一致性。需要通过培训、校准和质量监控机制确保标注结果的可靠性。


interface AnnotatorMetrics {
  annotatorId: string;
  interAnnotatorAgreement: number;
  goldAccuracy: number;
  completionRate: number;
  avgTime: number;
  flaggedCount: number;
}

interface QualityControlConfig {
  goldRatio: number;
  overlapRatio: number;
  minAgreementKappa: number;
  maxAnnotationTime: number;
  minAnnotationTime: number;
  rejectThreshold: number;
}

function calculateKappa(annotatorA: number[], annotatorB: number[], numLabels: number): number {
  const n = annotatorA.length;
  let observed = 0;
  const countA = new Array(numLabels).fill(0);
  const countB = new Array(numLabels).fill(0);

  for (let i = 0; i < n; i++) {
    if (annotatorA[i] === annotatorB[i]) observed++;
    countA[annotatorA[i]]++;
    countB[annotatorB[i]]++;
  }

  const po = observed / n;
  let pe = 0;
  for (let k = 0; k < numLabels; k++) {
    pe += (countA[k] / n) * (countB[k] / n);
  }

  return (po - pe) / (1 - pe);
}

function qualityCheck(
  annotations: Map<string, number[]>,
  goldLabels: Map<string, number>,
  config: QualityControlConfig,
): AnnotatorMetrics[] {
  const metrics: AnnotatorMetrics[] = [];

  for (const [annotatorId, labels] of annotations) {
    let goldCorrect = 0;
    let goldTotal = 0;

    for (let i = 0; i < labels.length; i++) {
      const gold = goldLabels.get(`item_${i}`);
      if (gold !== undefined) {
        goldTotal++;
        if (labels[i] === gold) goldCorrect++;
      }
    }

    metrics.push({
      annotatorId,
      interAnnotatorAgreement: 0,
      goldAccuracy: goldTotal > 0 ? goldCorrect / goldTotal : 0,
      completionRate: 1.0,
      avgTime: 0,
      flaggedCount: 0,
    });
  }

  return metrics;
}
Gold Question（黄金问题）是质量控制的核心手段。在任务中随机插入预先标注好答案的题目，如果评估员在 Gold Question 上的准确率低于阈值，则标记为不可靠。Inter-Annotator Agreement（评估员间一致性，通常用 Cohen's Kappa 衡量）反映了评估标准的清晰度和评估员的理解一致性。


LLM 辅助评估
大语言模型为人工评估提供了新的可能性。LLM 可以作为评估员的辅助工具、替代方案或校准参考。

研究表明，GPT-4 在搜索相关性标注任务上的一致性已经接近人类评估员间的一致性水平。但 LLM 评估仍存在系统性偏差，如倾向于给更长的文档更高分数、对特定表达风格有偏好等。最佳实践是将 LLM 评估与人工评估结合，用 LLM 做初筛，人工处理困难案例。


小结
    

  • 人工评估是衡量搜索语义理解和内容质量的不可替代方法，尤其在自动指标难以覆盖的维度
    • 

  • 清晰的评估标准是标注质量的基础，需要明确的等级定义、丰富的示例和边界 case 说明
    • 

  • Gold Question 和 Inter-Annotator Agreement 是核心质量控制手段，Kappa ≥ 0.6 表示合理一致
    • 

  • LLM 辅助评估可以大幅降低成本，但需要人工校准和偏差检测
    • 

  • 并排比较（Side-by-Side）是最高效的系统间比较方式，结合绝对评分可以全面评估系统质量
    •
