Function Calling 机制

核心概念

Function Calling 是 LLM 与外部系统交互的标准化接口。它允许开发者向 LLM 描述一组可调用的函数，LLM 根据用户请求自主决定调用哪个函数以及传入什么参数。这种机制不是 LLM 直接执行函数，而是 LLM 输出结构化的调用意图，由应用层负责实际执行。这种"意图-执行分离"的设计是构建安全可控 Agent 系统的基础。

OpenAI Function Calling 实现
OpenAI 的 Function Calling 通过 tools 参数定义可用函数，LLM 返回 tool_calls 字段表示调用意图。应用层需要在执行函数后将结果作为 tool 类型消息反馈给 LLM：


import OpenAI from 'openai';

const client = new OpenAI();

const tools: OpenAI.Chat.Completions.ChatCompletionTool[] = [
  {
    type: 'function',
    function: {
      name: 'get_stock_price',
      description: '获取指定股票的实时价格和涨跌幅',
      parameters: {
        type: 'object',
        properties: {
          symbol: {
            type: 'string',
            description: '股票代码，如 AAPL、GOOGL',
          },
          market: {
            type: 'string',
            enum: ['US', 'HK', 'CN'],
            description: '交易市场',
          },
        },
        required: ['symbol'],
      },
    },
  },
  {
    type: 'function',
    function: {
      name: 'calculate_portfolio',
      description: '计算投资组合的收益率和风险指标',
      parameters: {
        type: 'object',
        properties: {
          holdings: {
            type: 'array',
            items: {
              type: 'object',
              properties: {
                symbol: { type: 'string' },
                shares: { type: 'number' },
                avgCost: { type: 'number' },
              },
            },
            description: '持仓列表',
          },
        },
        required: ['holdings'],
      },
    },
  },
];

const messages: OpenAI.Chat.Completions.ChatCompletionMessageParam[] = [
  { role: 'user', content: '帮我查一下苹果和谷歌的股价，然后计算我的组合收益' },
];

const response = await client.chat.completions.create({
  model: 'gpt-4-turbo',
  messages,
  tools,
  tool_choice: 'auto',
});

const toolCalls = response.choices[0].message.tool_calls;
if (toolCalls) {
  messages.push(response.choices[0].message);

  for (const call of toolCalls) {
    const args = JSON.parse(call.function.arguments);
    let result: string;

    if (call.function.name === 'get_stock_price') {
      result = JSON.stringify({ symbol: args.symbol, price: 185.5, change: '+2.3%' });
    } else {
      result = JSON.stringify({ totalReturn: '12.5%', sharpeRatio: 1.8 });
    }

    messages.push({ role: 'tool', tool_call_id: call.id, content: result });
  }

  const finalResponse = await client.chat.completions.create({
    model: 'gpt-4-turbo',
    messages,
  });
}
并行 Function Calling 是 OpenAI 的重要能力——LLM 可以在单次响应中返回多个 tool_calls，应用层并行执行后统一反馈结果。这大幅减少了多工具场景下的交互轮次。


Anthropic Tool Use 对比
Anthropic 的 Tool Use 接口在概念上与 OpenAI 类似，但在实现细节上有显著差异。理解这些差异对于构建跨模型的 Agent 系统至关重要：


import Anthropic from '@anthropic-ai/sdk';

const anthropic = new Anthropic();

const response = await anthropic.messages.create({
  model: 'claude-3-sonnet-20240229',
  max_tokens: 1024,
  tools: [
    {
      name: 'search_database',
      description: '在产品数据库中搜索匹配的商品',
      input_schema: {
        type: 'object',
        properties: {
          query: { type: 'string', description: '搜索关键词' },
          category: { type: 'string', description: '商品类目' },
          maxPrice: { type: 'number', description: '最高价格' },
        },
        required: ['query'],
      },
    },
  ],
  messages: [{ role: 'user', content: '搜索价格在 500 元以内的蓝牙耳机' }],
});

for (const block of response.content) {
  if (block.type === 'tool_use') {
    const toolResult = await executeFunction(block.name, block.input);
    const followUp = await anthropic.messages.create({
      model: 'claude-3-sonnet-20240229',
      max_tokens: 1024,
      tools: [
        /* same tools */
      ],
      messages: [
        { role: 'user', content: '搜索价格在 500 元以内的蓝牙耳机' },
        { role: 'assistant', content: response.content },
        {
          role: 'user',
          content: [{ type: 'tool_result', tool_use_id: block.id, content: toolResult }],
        },
      ],
    });
  }
}

函数描述优化
函数描述的质量直接决定了 LLM 的调用准确性。优秀的描述应当清晰、具体、无歧义，并包含边界条件说明：


const wellDesignedTools: OpenAI.Chat.Completions.ChatCompletionTool[] = [
  {
    type: 'function',
    function: {
      name: 'create_jira_ticket',
      description: `创建 Jira 工单。使用场景：用户明确要求创建任务、Bug 或需求时调用。
        不要在用户只是讨论问题但未明确要求创建工单时调用。
        成功返回工单 ID，失败返回错误信息。`,
      parameters: {
        type: 'object',
        properties: {
          title: {
            type: 'string',
            description: '工单标题，应简洁描述问题或需求，不超过 100 字符',
          },
          type: {
            type: 'string',
            enum: ['Bug', 'Task', 'Story', 'Epic'],
            description: '工单类型：Bug（缺陷）、Task（任务）、Story（用户故事）、Epic（史诗）',
          },
          priority: {
            type: 'string',
            enum: ['Critical', 'High', 'Medium', 'Low'],
            description: '优先级。Critical 用于线上故障，High 用于影响核心功能的问题',
          },
          description: {
            type: 'string',
            description: '详细描述，包括复现步骤（Bug）或验收标准（Story）',
          },
          assignee: {
            type: 'string',
            description: '指派人的用户名。如未指定，留空由项目负责人分配',
          },
        },
        required: ['title', 'type', 'priority'],
      },
    },
  },
];
函数描述的关键原则：说明"何时调用"和"何时不调用"，为枚举值提供中文释义，为可选参数说明默认行为，描述返回值的格式和可能的错误情况。


多轮工具调用循环
复杂任务通常需要多轮工具调用——LLM 根据前一轮工具的返回结果决定下一步操作。实现健壮的多轮循环需要处理最大轮次限制、错误恢复和上下文管理：


const runToolLoop = async (
  client: OpenAI,
  initialMessages: OpenAI.Chat.Completions.ChatCompletionMessageParam[],
  tools: OpenAI.Chat.Completions.ChatCompletionTool[],
  maxIterations = 10,
): Promise<string> => {
  const messages = [...initialMessages];

  for (let i = 0; i < maxIterations; i++) {
    const response = await client.chat.completions.create({
      model: 'gpt-4-turbo',
      messages,
      tools,
    });

    const choice = response.choices[0];
    messages.push(choice.message);

    if (choice.finish_reason !== 'tool_calls' || !choice.message.tool_calls) {
      return choice.message.content ?? '';
    }

    const toolResults = await Promise.all(
      choice.message.tool_calls.map(async (call) => {
        try {
          const result = await executeFunction(call.function.name, JSON.parse(call.function.arguments));
          return { role: 'tool' as const, tool_call_id: call.id, content: JSON.stringify(result) };
        } catch (error) {
          return { role: 'tool' as const, tool_call_id: call.id, content: `执行错误: ${(error as Error).message}` };
        }
      }),
    );

    messages.push(...toolResults);
  }

  return '达到最大迭代次数限制';
};
小结
    

  • Function Calling 是 LLM 与外部系统的标准化接口，实现了"意图-执行分离"
    • 

  • OpenAI 和 Anthropic 的接口设计理念相同但实现细节不同，跨模型系统需要适配层
    • 

  • 函数描述的质量直接决定调用准确性，应包含调用时机、参数释义和返回值说明
    • 

  • 并行 Function Calling 显著减少多工具场景的交互轮次
    • 

  • 多轮工具循环需要设置最大迭代、错误处理和上下文管理机制
