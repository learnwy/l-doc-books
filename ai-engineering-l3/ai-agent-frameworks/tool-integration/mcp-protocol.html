MCP 协议

核心概念

Model Context Protocol（MCP）是 Anthropic 提出的开放协议标准，旨在解决 AI 应用与外部数据源和工具之间的互操作性问题。MCP 定义了一套标准化的通信协议，使得任何 LLM 应用都能以统一的方式连接到任意数据源和工具，类似于 USB 协议统一了硬件连接标准。

服务器开发
MCP 服务器暴露三种核心原语：工具（Tools）、资源（Resources）和提示模板（Prompts）。服务器通过 JSON-RPC 2.0 协议与客户端通信：


import { McpServer } from '@modelcontextprotocol/sdk/server/mcp.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import { z } from 'zod';

const server = new McpServer({
  name: 'project-knowledge-server',
  version: '1.0.0',
});

server.tool(
  'search_codebase',
  '在代码库中搜索文件和符号，支持正则表达式和语义搜索',
  {
    query: z.string().describe('搜索查询，支持正则表达式'),
    filePattern: z.string().optional().describe('文件名匹配模式，如 *.ts'),
    searchType: z.enum(['regex', 'semantic']).default('regex'),
    maxResults: z.number().default(10).describe('最大返回结果数'),
  },
  async ({ query, filePattern, searchType, maxResults }) => {
    const results = await performSearch(query, { filePattern, searchType, maxResults });
    return {
      content: [
        {
          type: 'text',
          text: JSON.stringify(results, null, 2),
        },
      ],
    };
  },
);

server.tool(
  'run_tests',
  '执行指定目录的测试用例，返回测试结果和覆盖率',
  {
    testPath: z.string().describe('测试文件或目录路径'),
    coverage: z.boolean().default(false).describe('是否生成覆盖率报告'),
  },
  async ({ testPath, coverage }) => {
    const result = await executeTests(testPath, { coverage });
    return {
      content: [{ type: 'text', text: result.summary }],
      isError: result.failed > 0,
    };
  },
);

server.resource('project://architecture', '项目架构文档', 'text/markdown', async () => {
  const content = await readFile('./ARCHITECTURE.md', 'utf-8');
  return { content: [{ type: 'text', text: content }] };
});

server.prompt(
  'code_review',
  '代码评审提示模板',
  { filePath: z.string().describe('要评审的文件路径') },
  async ({ filePath }) => {
    const code = await readFile(filePath, 'utf-8');
    return {
      messages: [
        {
          role: 'user',
          content: {
            type: 'text',
            text: `请评审以下代码，关注安全性、性能和可维护性：\n\n\`\`\`\n${code}\n\`\`\``,
          },
        },
      ],
    };
  },
);

const transport = new StdioServerTransport();
await server.connect(transport);
MCP 服务器的三种原语各有定位：工具用于执行操作（写入、搜索、计算），资源用于提供只读数据（文档、配置），提示模板用于封装可复用的交互模式。


客户端集成
MCP 客户端负责发现和调用 MCP 服务器的能力。客户端通过协议协商获取服务器的工具列表，然后将这些工具暴露给 LLM：


import { McpClient } from '@modelcontextprotocol/sdk/client/mcp.js';
import { StdioClientTransport } from '@modelcontextprotocol/sdk/client/stdio.js';

const transport = new StdioClientTransport({
  command: 'node',
  args: ['./mcp-servers/project-server.mjs'],
});

const client = new McpClient({
  name: 'ai-assistant',
  version: '1.0.0',
});

await client.connect(transport);

const { tools } = await client.listTools();
console.log(
  '可用工具:',
  tools.map((t) => t.name),
);

const { resources } = await client.listResources();
console.log(
  '可用资源:',
  resources.map((r) => r.name),
);

const result = await client.callTool('search_codebase', {
  query: 'async function',
  filePattern: '*.ts',
  maxResults: 5,
});

const architectureDoc = await client.readResource('project://architecture');

const convertToOpenAITools = (mcpTools: typeof tools) =>
  mcpTools.map((tool) => ({
    type: 'function' as const,
    function: {
      name: tool.name,
      description: tool.description ?? '',
      parameters: tool.inputSchema,
    },
  }));

const openaiTools = convertToOpenAITools(tools);
客户端的关键设计是适配层——将 MCP 的工具定义转换为特定 LLM 提供商的格式（OpenAI Tools、Anthropic Tool Use 等），使 MCP 服务器可以被任何 LLM 应用使用。


传输层与通信
MCP 支持多种传输层协议，适应不同的部署场景。传输层的选择影响延迟、可靠性和部署复杂度：


import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import { SSEServerTransport } from '@modelcontextprotocol/sdk/server/sse.js';

const stdioTransport = new StdioServerTransport();

const sseTransport = new SSEServerTransport('/mcp', response);

Stdio 传输最适合本地开发工具（如 IDE 插件连接本地分析服务），SSE 适合云端部署的 MCP 服务器（如数据库代理、API 网关）。


安全性与生产部署
MCP 的安全模型基于最小权限原则——每个 MCP 服务器只暴露必要的能力，客户端通过配置选择信任哪些服务器：


const createSecureMcpServer = (config: {
  allowedOperations: string[];
  rateLimitPerMinute: number;
  auditLog: (event: Record<string, unknown>) => void;
}) => {
  const server = new McpServer({
    name: 'secure-server',
    version: '1.0.0',
  });

  let callCount = 0;
  const resetInterval = setInterval(() => {
    callCount = 0;
  }, 60000);

  const withSecurity = (handler: (args: Record<string, unknown>) => Promise<Record<string, unknown>>) => {
    return async (args: Record<string, unknown>) => {
      if (++callCount > config.rateLimitPerMinute) {
        return {
          content: [{ type: 'text', text: '速率限制：请求过于频繁' }],
          isError: true,
        };
      }

      config.auditLog({
        timestamp: new Date().toISOString(),
        args,
        callCount,
      });

      return handler(args);
    };
  };

  return { server, withSecurity, cleanup: () => clearInterval(resetInterval) };
};
小结
    

  • MCP 是 AI 应用与外部系统的标准化互操作协议，类似 USB 之于硬件
    • 

  • 服务器暴露三种原语：工具（操作）、资源（数据）、提示模板（交互模式）
    • 

  • 客户端通过适配层将 MCP 能力转换为特定 LLM 格式，实现一次开发到处可用
    • 

  • Stdio 适合本地工具集成，SSE 适合远程服务部署
    • 

  • 生产部署需关注速率限制、操作审计和最小权限控制
