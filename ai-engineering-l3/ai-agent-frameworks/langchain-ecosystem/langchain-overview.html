LangChain 框架全景

核心概念

LangChain 是一个用于构建大语言模型（LLM）应用的开源框架，它通过模块化设计将 LLM 的能力与外部数据源、工具和工作流进行组合。LangChain 的核心理念是"链式组合"——将简单的组件串联成复杂的应用流水线，使开发者能够快速构建从简单问答到复杂推理代理的各类 AI 应用。

LCEL 表达式语言
LangChain Expression Language（LCEL）是 LangChain 的核心编程范式，它通过 | 管道运算符将组件连接成链，类似于 Unix 管道的设计哲学。LCEL 的优势在于：自动支持流式输出、批量处理、异步调用和容错重试，无需开发者手动实现这些能力。


import { ChatOpenAI } from '@langchain/openai';
import { ChatPromptTemplate } from '@langchain/core/prompts';
import { StringOutputParser } from '@langchain/core/output_parsers';

const model = new ChatOpenAI({ modelName: 'gpt-4' });
const prompt = ChatPromptTemplate.fromTemplate('用简洁的中文解释 {concept} 的核心原理');
const outputParser = new StringOutputParser();

const chain = prompt.pipe(model).pipe(outputParser);

const result = await chain.invoke({ concept: '向量数据库' });

const stream = await chain.stream({ concept: '注意力机制' });
for await (const chunk of stream) {
  process.stdout.write(chunk);
}

const batchResults = await chain.batch([{ concept: '梯度下降' }, { concept: '反向传播' }, { concept: 'Transformer' }]);
LCEL 链中每个组件都实现了 Runnable 接口，这意味着它们都具备以下标准方法：

模型抽象与集成
LangChain 对 LLM 的抽象分为三个层次：语言模型（LLM）、聊天模型（ChatModel）和嵌入模型（Embeddings）。这种分层设计使得切换不同厂商的模型变得几乎零成本。


import { ChatOpenAI } from '@langchain/openai';
import { ChatAnthropic } from '@langchain/anthropic';
import { ChatOllama } from '@langchain/ollama';

const openai = new ChatOpenAI({
  modelName: 'gpt-4-turbo',
  temperature: 0.7,
  maxTokens: 2000,
});

const claude = new ChatAnthropic({
  modelName: 'claude-3-sonnet-20240229',
  temperature: 0.7,
});

const local = new ChatOllama({
  model: 'llama3',
  baseUrl: 'http://localhost:11434',
});

const chainWithFallback = prompt.pipe(openai.withFallbacks({ fallbacks: [claude, local] })).pipe(outputParser);
LangChain 的模型集成遵循统一接口，每个模型提供者都实现了 BaseChatModel 抽象类。模型配置支持缓存、速率限制和回调，这些横切关注点在框架层面统一处理，开发者无需在业务逻辑中重复实现。


文档加载与检索增强
LangChain 提供了丰富的文档加载器（DocumentLoader）和文本分割器（TextSplitter），是构建 RAG 应用的基础设施。文档从加载到可检索索引的完整流程包含四个阶段：


import { PDFLoader } from '@langchain/community/document_loaders/fs/pdf';
import { RecursiveCharacterTextSplitter } from 'langchain/text_splitter';
import { OpenAIEmbeddings } from '@langchain/openai';
import { MemoryVectorStore } from 'langchain/vectorstores/memory';

const loader = new PDFLoader('knowledge-base.pdf');
const docs = await loader.load();

const splitter = new RecursiveCharacterTextSplitter({
  chunkSize: 1000,
  chunkOverlap: 200,
  separators: ['\n\n', '\n', '。', '，', ' '],
});
const splits = await splitter.splitDocuments(docs);

const embeddings = new OpenAIEmbeddings();
const vectorStore = await MemoryVectorStore.fromDocuments(splits, embeddings);

const retriever = vectorStore.asRetriever({
  k: 4,
  searchType: 'similarity',
});
const relevantDocs = await retriever.invoke('什么是注意力机制？');
文本分割策略的选择直接影响检索质量。RecursiveCharacterTextSplitter 通过分隔符优先级递归分割，在保持语义完整性和控制块大小之间取得平衡。对于代码文档，LangChain 还提供了语言感知的分割器，能够按函数或类边界分割。


输出解析与结构化
LangChain 的输出解析器将 LLM 的自由文本输出转换为结构化数据，这是将 LLM 集成到工程系统中的关键环节。框架提供了从简单字符串到复杂 JSON Schema 的多种解析策略：


import { z } from 'zod';
import { StructuredOutputParser } from 'langchain/output_parsers';
import { ChatPromptTemplate } from '@langchain/core/prompts';

const schema = z.object({
  summary: z.string().describe('技术概念的一句话总结'),
  keyPoints: z.array(z.string()).describe('3-5 个核心要点'),
  difficulty: z.enum(['入门', '中级', '高级']).describe('难度等级'),
  relatedTopics: z.array(z.string()).describe('相关技术主题'),
});

const parser = StructuredOutputParser.fromZodSchema(schema);

const prompt = ChatPromptTemplate.fromTemplate(
  '分析以下技术概念并提供结构化总结：\n{concept}\n\n{format_instructions}',
);

const chain = prompt.pipe(model).pipe(parser);
const result = await chain.invoke({
  concept: '微服务架构',
  format_instructions: parser.getFormatInstructions(),
});
对于支持 Function Calling 的模型，LangChain 还提供了 withStructuredOutput 方法，直接利用模型的原生结构化能力，避免了格式指令注入和输出解析可能带来的不稳定性。


小结
    

  • LangChain 通过模块化设计和 LCEL 表达式语言，将 LLM 应用开发从"黑盒调用"提升为"工程化构建"
    • 

  • LCEL 管道范式自动提供流式、批量、异步和容错能力，是 LangChain 编程的核心范式
    • 

  • 模型抽象层实现了厂商无关性，通过 withFallbacks 机制保障服务可靠性
    • 

  • 文档加载和检索增强是 RAG 应用的基础，文本分割策略直接影响检索质量
    • 

  • 输出解析器将自由文本转为结构化数据，是 LLM 与工程系统集成的桥梁
    • 

  • LangChain 生态已从单一框架演变为 Core + LangGraph + LangServe + LangSmith 的完整平台
    •
