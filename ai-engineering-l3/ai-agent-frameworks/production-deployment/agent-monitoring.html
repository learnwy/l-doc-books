Agent 监控与可观测性

核心概念

Agent 监控是保障 AI 应用质量和可靠性的基础设施。与传统 Web 服务监控不同，Agent 系统的监控需要覆盖 LLM 推理过程、工具调用链路、成本消耗和输出质量四个维度。可观测性的目标是让开发者能够回答"Agent 为什么做了这个决定"和"这个决定的结果是否符合预期"。

LangSmith 追踪集成
LangSmith 是 LangChain 官方的可观测性平台，提供了对 Agent 执行过程的完整追踪能力。每次 Agent 运行都会生成一棵追踪树，展示从输入到输出的每个步骤：


import { Client } from 'langsmith';
import { ChatOpenAI } from '@langchain/openai';
import { traceable } from 'langsmith/traceable';
import { wrapOpenAI } from 'langsmith/wrappers';

const client = new Client({
  apiUrl: 'https://api.smith.langchain.com',
  apiKey: process.env.LANGSMITH_API_KEY,
});

const tracedModel = wrapOpenAI(
  new ChatOpenAI({
    modelName: 'gpt-4-turbo',
  }),
);

const analyzeDocument = traceable(
  async (document: string) => {
    const result = await tracedModel.invoke([
      { role: 'system', content: '分析文档的关键主题' },
      { role: 'user', content: document },
    ]);
    return result.content;
  },
  { name: 'analyze_document', metadata: { version: '1.0' } },
);

const generateReport = traceable(
  async (analysis: string) => {
    const result = await tracedModel.invoke([
      { role: 'system', content: '基于分析生成报告' },
      { role: 'user', content: analysis },
    ]);
    return result.content;
  },
  { name: 'generate_report' },
);

const pipeline = traceable(
  async (input: string) => {
    const analysis = await analyzeDocument(input);
    const report = await generateReport(analysis as string);
    return report;
  },
  { name: 'document_pipeline', tags: ['production'] },
);
LangSmith 追踪的核心价值在于因果链可视化——当 Agent 输出不符合预期时，可以在追踪树中定位到具体哪个步骤出了问题，是 prompt 不当、工具返回异常还是推理逻辑偏差。


自定义指标收集
生产环境通常需要将 Agent 指标集成到现有的监控基础设施中。通过 LangChain 的回调机制可以实现自定义指标采集：


import { BaseCallbackHandler } from '@langchain/core/callbacks/base';
import type { Serialized } from '@langchain/core/load/serializable';

interface AgentMetrics {
  totalCalls: number;
  totalTokens: number;
  totalCost: number;
  avgLatency: number;
  errorRate: number;
  toolCallCounts: Map<string, number>;
}

class MetricsCollector extends BaseCallbackHandler {
  name = 'metrics_collector';
  private metrics: AgentMetrics = {
    totalCalls: 0,
    totalTokens: 0,
    totalCost: 0,
    avgLatency: 0,
    errorRate: 0,
    toolCallCounts: new Map(),
  };
  private startTimes = new Map<string, number>();
  private latencies: number[] = [];
  private errors = 0;

  async handleLLMStart(_llm: Serialized, _prompts: string[], runId: string) {
    this.startTimes.set(runId, Date.now());
    this.metrics.totalCalls++;
  }

  async handleLLMEnd(output: { llmOutput?: { tokenUsage?: { totalTokens?: number } } }, runId: string) {
    const start = this.startTimes.get(runId);
    if (start) {
      this.latencies.push(Date.now() - start);
      this.startTimes.delete(runId);
    }

    const tokens = output.llmOutput?.tokenUsage?.totalTokens ?? 0;
    this.metrics.totalTokens += tokens;
    this.metrics.totalCost += tokens * 0.00003;
  }

  async handleLLMError(_error: Error, runId: string) {
    this.errors++;
    this.startTimes.delete(runId);
  }

  async handleToolStart(_tool: Serialized, _input: string, runId: string) {
    this.startTimes.set(runId, Date.now());
  }

  async handleToolEnd(output: string, runId: string) {
    const toolName = runId.split('-')[0];
    const count = this.metrics.toolCallCounts.get(toolName) ?? 0;
    this.metrics.toolCallCounts.set(toolName, count + 1);
    this.startTimes.delete(runId);
  }

  getMetrics(): AgentMetrics {
    return {
      ...this.metrics,
      avgLatency: this.latencies.length > 0 ? this.latencies.reduce((a, b) => a + b, 0) / this.latencies.length : 0,
      errorRate: this.metrics.totalCalls > 0 ? this.errors / this.metrics.totalCalls : 0,
    };
  }
}
指标收集器应该是轻量级的——采集操作不应该影响 Agent 的响应延迟。对于高频指标（如 Token 计数），建议在内存中聚合后定期批量发送到监控后端。


评估管道
Agent 输出质量的评估需要系统化的方法。评估管道结合自动化指标和人工评分，持续监控 Agent 的表现趋势：


interface EvalResult {
  relevance: number;
  coherence: number;
  factuality: number;
  overall: number;
}

const createEvalPipeline = (evaluatorModel: {
  invoke: (messages: Array<{ role: string; content: string }>) => Promise<{ content: string }>;
}) => {
  const evaluateOutput = async (input: string, output: string, groundTruth?: string): Promise<EvalResult> => {
    const evalPrompt = `评估以下 AI 回答的质量（1-5 分）：
      问题：${input}
      AI 回答：${output}
      ${groundTruth ? `参考答案：${groundTruth}` : ''}
      请以 JSON 格式输出评分：
      {"relevance": 分数, "coherence": 分数, "factuality": 分数, "overall": 分数}`;

    const result = await evaluatorModel.invoke([{ role: 'user', content: evalPrompt }]);

    return JSON.parse(result.content as string);
  };

  const runBatchEval = async (
    testCases: Array<{ input: string; expectedOutput?: string }>,
    agent: { invoke: (input: string) => Promise<string> },
  ) => {
    const results: Array<{ input: string; output: string; eval: EvalResult }> = [];

    for (const testCase of testCases) {
      const output = await agent.invoke(testCase.input);
      const evalResult = await evaluateOutput(testCase.input, output, testCase.expectedOutput);
      results.push({ input: testCase.input, output, eval: evalResult });
    }

    const avgScores = {
      relevance: results.reduce((s, r) => s + r.eval.relevance, 0) / results.length,
      coherence: results.reduce((s, r) => s + r.eval.coherence, 0) / results.length,
      factuality: results.reduce((s, r) => s + r.eval.factuality, 0) / results.length,
      overall: results.reduce((s, r) => s + r.eval.overall, 0) / results.length,
    };

    return { results, avgScores };
  };

  return { evaluateOutput, runBatchEval };
};
告警与异常检测
Agent 系统的告警需要覆盖性能退化、成本异常和安全风险三个层面：


interface AlertRule {
  name: string;
  condition: (metrics: AgentMetrics) => boolean;
  severity: 'critical' | 'warning' | 'info';
  message: (metrics: AgentMetrics) => string;
}

const defaultAlertRules: AlertRule[] = [
  {
    name: 'high_error_rate',
    condition: (m) => m.errorRate > 0.1,
    severity: 'critical',
    message: (m) => `Agent 错误率 ${(m.errorRate * 100).toFixed(1)}% 超过阈值 10%`,
  },
  {
    name: 'high_latency',
    condition: (m) => m.avgLatency > 30000,
    severity: 'warning',
    message: (m) => `平均延迟 ${(m.avgLatency / 1000).toFixed(1)}s 超过阈值 30s`,
  },
  {
    name: 'cost_spike',
    condition: (m) => m.totalCost > 10,
    severity: 'warning',
    message: (m) => `累计成本 $${m.totalCost.toFixed(2)} 超过阈值 $10`,
  },
];

const checkAlerts = (metrics: AgentMetrics, rules: AlertRule[]) => {
  return rules
    .filter((rule) => rule.condition(metrics))
    .map((rule) => ({
      name: rule.name,
      severity: rule.severity,
      message: rule.message(metrics),
      timestamp: new Date().toISOString(),
    }));
};
小结
    

  • Agent 可观测性需要覆盖追踪、指标和日志三个支柱，重点关注推理链路和工具调用
    • 

  • LangSmith 提供因果链可视化，是定位 Agent 行为异常的最有效工具
    • 

  • 自定义指标收集应轻量级实现，在内存中聚合后批量发送到监控后端
    • 

  • 评估管道结合自动化评分和人工反馈，持续监控 Agent 输出质量趋势
    • 

  • 告警覆盖性能退化、成本异常和安全风险三个层面，使用分级策略避免告警疲劳
