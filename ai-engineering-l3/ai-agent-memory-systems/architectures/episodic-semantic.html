情景与语义记忆

「上周二下午用户取消了那笔订单」和「用户偏好深色模式」都是长期记忆，但它们的脾气完全不同：前者是一段带时间地点的具体经历，旧了可以淡忘；后者是一条沉淀下来的事实，要长期成立、出现冲突时该更新而非堆叠。把这两类记忆用同一种结构去存，必然两头不讨好。这一篇讲它们各自该长成什么样——是记忆类型分类在存储层的具体落地。

核心概念：经历 vs 事实

情景记忆（episodic）记录带上下文的具体事件：什么时间、在哪次会话、发生了什么。它保留原始细节和时间线，回答的是「那次到底怎么回事」。

语义记忆（semantic）是脱离具体发生时刻的事实与概念：用户是谁、偏好什么、世界是怎样的。它不关心这条事实何时被说出口，只关心它当前是否成立，回答的是「现在情况如何」。

两者最深刻的联系是：语义记忆往往是情景记忆沉淀的产物。从「用户连续三次都点了素菜」（三条情景）提炼出「用户吃素」（一条语义），正是智能体积累经验的核心机制。

核心内容 时间 + 摘要 + 细节 实体 + 属性/关系
关键字段 时间戳、会话 ID 主语、谓语、值

情景记忆：保留经历的原貌

情景记忆的设计原则是保真。既然它记录的是「真实发生过什么」，就不该随意改写或合并——两次相似但不同的经历都是有效记录，强行去重会丢失信息。

典型的情景记忆条目带三类字段：时间戳（何时发生）、会话/上下文标识（在哪次交互里）、内容摘要与细节（发生了什么）。这种结构天然支持两类查询：按时间回溯（「上个月发生过什么」）和按会话定位（「那次客服对话里他说了什么」）。

存储上，情景记忆通常落在向量库里以支持语义检索，同时辅以时间线索引以支持时序查询。这就是为什么长期记忆与向量存储里提到「向量 + 时间线」的组合——纯向量答不了「按时间排序」这类问题。

情景记忆的另一个特点是允许衰减：很久以前的、再没被用到的浏览记录，留着只会膨胀存储、稀释检索。基于时间和访问频率的淘汰策略见遗忘与压缩。

语义记忆：维护事实的当下

语义记忆的设计原则与情景记忆几乎相反，是收敛。它要把分散的、重复的、甚至矛盾的信息，收敛成一组干净、当前有效的事实。

这带来两条特有的操作规则。去重合并：用户说过五次「我喜欢深色模式」，语义记忆里只该有一条，而不是五条。冲突更新：用户上个月说「我吃素」，这个月说「我开始吃肉了」——语义记忆该用新事实覆盖旧事实，而不是让两条矛盾记忆并存（这恰恰和情景记忆相反，那边两次发言都该保留为历史）。

结构上，语义记忆很适合用「实体 + 属性」或知识图谱的「实体 + 关系」来组织。「用户—偏好—深色模式」「公司—退款窗口—14 天」都是天然的三元组。这也是 Zep 的 Graphiti 等时序知识图谱方案的用武之地：它们能在图上直接做「这条事实从何时起成立、被何时的新事实取代」的时序管理，相关框架对比见记忆框架与实现。

情景到语义的巩固通道

把这两类记忆连起来的，是一条巩固通道——这是整个记忆系统里最像「学习」的部分。

机制大致是：智能体先把每次交互存为情景记忆（流水账）；当某种模式在多条情景里反复出现，或定期回顾时，触发一次抽象，把这些零散经历提炼成一条语义事实。「三次都点素菜」→「偏好素食」，「多次在深夜活跃」→「夜间用户」。

这正是生成式智能体（Generative Agents）里「反思」（reflection）机制的内核：定期回看近期情景记忆，归纳出更高层的洞察存为语义记忆，让智能体的行为越来越显得有「人格」和连贯判断。2026 年的 MIRIX 等多管理器系统也把情景与语义设为独立管理器，并在它们之间设置路由与巩固，详见多智能体共享记忆。

巩固的具体触发时机与抽取方法，属于写入操作的范畴，在写入与巩固里完整展开——本篇只确立「为什么需要两类记忆、它们如何衔接」。

来源：arXiv: Memory in LLM-based Multi-agent Systems。

程序性记忆：补完三元结构

为完整起见再补一类：程序性记忆，编码「如何完成某类任务」。它不像情景那样带时间、也不像语义那样是静态事实，而是可执行的步骤、技能、工具用法。

在工程实现里，程序性记忆常体现为学到的工作流模板、可复用的提示词、或封装好的工具调用序列。「处理退款的标准步骤」「组装支付 API 请求的方式」都属此类。它的更新逻辑更接近语义记忆（用更好的流程覆盖旧流程），但内容是「怎么做」而非「是什么」。三类记忆合起来，才覆盖了智能体长期记忆的完整谱系。

小结

  • 情景记忆记「带上下文的具体经历」，语义记忆记「脱时刻的当下事实」，两者脾气相反。
  • 情景记忆保真：保留原貌、不去重、冲突并存、允许衰减；语义记忆收敛：去重合并、冲突更新覆盖、长期保留。
  • 情景记忆配「向量 + 时间线」存储支持时序查询，语义记忆适合「实体 + 属性/关系」或知识图谱。
  • 巩固通道把反复出现的情景经历抽象成语义事实，是生成式智能体「反思」机制与积累经验的内核。
  • 程序性记忆编码「怎么做」，补完情景-语义-程序性的长期记忆三元结构。
