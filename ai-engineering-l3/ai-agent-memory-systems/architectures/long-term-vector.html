长期记忆与向量存储

要让智能体记住三个月前你说过的一句偏好，靠的不是关键词匹配——你当时说「我不爱吃辣」，今天问「推荐个川菜馆」，没有任何字面词重合，关键词检索会两手空空。让这两句对上的，是把文本编码成向量、按语义相近度检索的向量存储。它是 2026 年长期记忆事实上的标准基础设施。这一篇讲它怎么运作、取舍在哪。

核心概念：把意义变成坐标

向量存储的核心思想是：用一个嵌入模型把任意文本映射成一个高维向量（比如 1024 维或 1536 维），让语义相近的文本，向量也相近。「我不爱吃辣」和「推荐不辣的菜」在字面上毫无交集，但它们的向量在空间里靠得很近。

于是「检索相关记忆」就变成了一道几何题：把查询也编码成向量，找出存储里离它最近的几个向量，对应的原文就是最相关的记忆。

flowchart TD
    A[原始记忆文本] --> B[嵌入模型]
    B --> C[向量 1024+ 维]
    C --> D[向量数据库<br/>建索引]
    E[当前查询] --> F[嵌入模型 同一个]
    F --> G[查询向量]
    G --> H[相似度检索<br/>找最近的 K 个]
    D --> H
    H --> I[返回 top-K 记忆原文]

下表对比向量检索与传统关键词检索：

维度 关键词检索 向量语义检索
匹配依据 字面词重合 语义相近
处理同义改写 失败 成功
索引结构 倒排索引 向量索引 ANN
典型短板 漏掉换说法的相关项 漏掉精确关键词/专名
长期记忆适配度 低 高

正因两者短板互补，实践中常把它们结合成混合检索，这部分在检索与相关性里展开；本篇聚焦向量存储这一侧的结构。

嵌入：相似度的数学定义

「向量相近」需要一个精确度量。最常用的是余弦相似度：两个向量 a⃗\vec{a}a 与 b⃗\vec{b}b 的相似度定义为

sim(a⃗,b⃗)=a⃗⋅b⃗∥a⃗∥ ∥b⃗∥\text{sim}(\vec{a}, \vec{b}) = \frac{\vec{a} \cdot \vec{b}}{\|\vec{a}\| \, \|\vec{b}\|}sim(a,b)=∥a∥∥b∥a⋅b​

它衡量的是两个向量的方向夹角，取值在 −1-1−1 到 111 之间，越接近 111 越相似。之所以用夹角而非欧氏距离，是因为我们关心语义方向是否一致，而不在意向量长度。

嵌入模型的选择直接决定检索质量：维度、训练语料、是否支持多语言、是否针对检索任务微调，都会影响同义改写能否被正确召回。一个粗糙的嵌入模型会让整个长期记忆系统「近视」。维度 ddd 也是成本变量——维度越高，表达力越强，但存储和计算开销越大。

分块：记忆的存储粒度

存进向量库的不该是「整段对话」，而是恰当大小的记忆单元。这个切分动作叫分块（chunking），粒度的选择是个关键权衡。

块太大，一个向量要同时代表多个不相关的事实，语义被「平均」得模糊，检索时既不精准、塞回上下文又浪费 token。块太小，单个事实被切碎，丢失了必要的上下文，检索回来可能不知所云。

在智能体记忆里，分块往往不是机械地按字数切，而是按语义单元切——一条偏好、一个事实、一次经历各成一块。很多记忆框架在写入时会先用一个 LLM 把原始对话抽取成若干条结构化的原子记忆，再分别嵌入入库。这个抽取过程属于写入操作，详见写入与巩固。

向量索引：让检索在毫秒级完成

当记忆膨胀到几十万、上百万条，逐个计算查询向量与每条记忆的相似度（暴力检索）会慢到不可用。复杂度是 O(N⋅d)O(N \cdot d)O(N⋅d)，NNN 是记忆条数。

解决办法是近似最近邻（ANN）索引。它用图结构（如 HNSW）或量化等技术，牺牲极小的精度换来对数级的检索速度，让百万级记忆库也能在毫秒内返回 top-K。2026 年主流的向量数据库——Pinecone、Redis、Qdrant、pgvector 等——都内置了成熟的 ANN 索引；在生产里，记忆框架常把存储委托给这类向量库，相关框架见记忆框架与实现。

需要权衡的是召回率与速度：ANN 是近似的，可能漏掉真正的最近邻。索引参数（如 HNSW 的连接数）就是在「快」和「准」之间调旋钮。

不止向量：图与混合存储

向量存储擅长「语义相似」，但有它够不着的地方，所以 2026 年的长期记忆越来越走向混合存储。

向量库的短板是不擅长表达关系和精确事实。「张三是李四的经理」「这家公司的总部在上海」这类带结构的事实，用知识图谱（实体 + 关系）来存更自然，也更便于做多跳推理和时序更新。Zep 的 Graphiti 正是走时序知识图谱路线，在需要「事实随时间变化」的场景里表现突出——它在 LongMemEval 上得分 63.8%（基于 GPT-4o），明显高于纯记忆层方案的 49.0%，相关对比见记忆框架与实现。

因此 2026 年的成熟长期记忆常是向量 + 图 + 键值的组合：向量管语义相似检索，图管关系与时序，键值管精确查找。Mem0 这类框架就采用了向量加图的混合存储。不同的存储形态如何对应情景记忆与语义记忆，见情景与语义记忆。

来源：Vectorize: Best AI Agent Memory Systems、Particula: Agent Memory Frameworks Tested。

小结

  • 长期记忆靠向量存储实现语义检索：把文本嵌入成高维向量，语义相近则向量相近。
  • 相似度常用余弦相似度衡量向量方向夹角，嵌入模型质量直接决定检索能否召回同义改写。
  • 分块决定记忆的存储粒度，智能体记忆倾向按语义单元（一条事实一块）切分，常配合 LLM 抽取。
  • ANN 索引（如 HNSW）让百万级记忆库毫秒级检索，需在召回率与速度间权衡。
  • 2026 年长期记忆走向向量 + 图 + 键值的混合存储，图擅长关系与时序，与向量互补。
