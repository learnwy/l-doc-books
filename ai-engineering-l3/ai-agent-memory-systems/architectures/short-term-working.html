短期与工作记忆

短期与工作记忆是智能体每一次思考时「眼前摊着的桌面」：当前对话的最近几轮、正在执行任务的中间笔记、刚检索回来的资料，全都临时摆在这块桌面上。桌面就那么大（上下文窗口），摆什么、怎么摆、满了先撤谁，直接决定智能体这一步能不能想清楚。这一篇讲这块易失桌面的结构与组装策略。

核心概念：易失桌面与窗口预算

短期记忆和工作记忆在认知科学里有细微区别，但在智能体工程里通常合并处理：它们都是易失、容量受限、服务于当前任务的记忆，物理上活在上下文窗口里。这与跨会话持久的长期记忆形成对比——后者见长期记忆与向量存储。

工作记忆的核心约束是窗口预算。一次调用的 token 总量是固定的，要在这个预算内分配给系统提示、对话历史、检索记忆、工具输出和当前问题。组装工作记忆，本质就是一道预算分配题。

对话缓冲：最朴素也最常用的短期记忆

最基础的短期记忆就是一个对话缓冲区：把最近的若干轮用户-智能体往返原样保留在上下文里。它实现简单、保真度高，是几乎所有聊天式智能体的默认配置。

缓冲区有两种常见策略。滑动窗口只保留最近 NNN 轮，超出的直接丢弃——简单，但会突然失忆，第 N+1N+1N+1 轮之前说的全没了。token 上限缓冲则保留尽可能多的最近内容直到逼近某个 token 阈值，比按轮数更贴合真实预算。

缓冲区的根本局限是它和窗口一样会满。当对话变长，要么截断（丢信息），要么压缩——把旧对话摘要成几句话腾出空间。这个压缩动作属于记忆操作的范畴，详见遗忘与压缩。

草稿板：智能体的思考纸

除了存对话，工作记忆还要存智能体自己的思考过程。这就是草稿板（scratchpad）：在多步推理或工具调用中，智能体把中间结论、计划、待验证假设写在这里，下一步再读回来。

草稿板是 ReAct、计划-执行这类智能体范式的物理载体。比如解一道多步数学题，智能体把每一步的中间结果写进草稿板，避免在脑中（窗口里）一次性扛住所有状态。它把「工作记忆」从被动的对话存储，变成了主动的认知工作区。

草稿板内容通常随任务结束即清空——它是临时的。但若某条中间结论值得长期保留（比如学到的一个有用模式），就需要触发写入操作沉淀到长期记忆，这个判定见写入与巩固。

上下文组装：把桌面摆对

工作记忆设计里最被低估、却最影响效果的环节，是上下文组装——在窗口预算内，决定放哪些内容、以什么顺序放。

顺序为什么重要？因为上下文窗口与局限里讲过的中间迷失效应：放在开头和结尾的信息被利用得最充分，中间的容易被忽略。所以组装的经验法则是：把系统指令放最前、把当前问题和最关键的检索记忆放最后（靠近生成位置），把次要历史放中间。

可以把组装看成一个带优先级的装箱问题。设每条候选内容 iii 有重要性 wiw_iwi​ 和 token 成本 cic_ici​，预算为 BBB，目标是选出子集 SSS 使 ∑i∈Swi\sum_{i \in S} w_i∑i∈S​wi​ 最大且 ∑i∈Sci≤B\sum_{i \in S} c_i \le B∑i∈S​ci​≤B。实践中不会真去解背包，而是用启发式：固定开销先扣除，剩余预算按「当前输入 > 高分检索记忆 > 近期对话 > 远期摘要」的优先级填充。

哪些检索记忆值得进这个预算，由相关性打分决定，见检索与相关性。

工作记忆与长期记忆的接力

工作记忆不是孤岛，它和长期记忆之间有持续的双向接力，理解这个接力是理解整个记忆架构的关键。

读方向：每一轮，系统从长期记忆里检索出与当前最相关的几条，临时放进工作记忆（窗口）参与本轮推理。这些检索片段用完即走，下一轮重新检索。

写方向：工作记忆里产生的新信息——用户刚说的偏好、任务中学到的事实——若被判定值得保留，就写入长期记忆持久化。

这条接力线把易失的当下和持久的过往连成一体：长期记忆是仓库，工作记忆是当前从仓库取货、又往仓库回存的操作台。仓库的结构见长期记忆与向量存储，操作台向仓库回存的规则见写入与巩固。

小结

  • 短期与工作记忆是易失、容量受限、服务当前任务的记忆，物理上活在上下文窗口里。
  • 组装工作记忆本质是窗口预算分配题，要在固定 token 内安排系统提示、对话、检索记忆与当前输入。
  • 对话缓冲（滑动窗口或 token 上限）是最常用的短期记忆，满了就靠截断或摘要。
  • 草稿板是智能体的主动认知工作区，承载多步推理的中间状态，随任务清空。
  • 上下文组装要顺应中间迷失效应，把关键内容放在开头与结尾；工作记忆与长期记忆持续做读写接力。
