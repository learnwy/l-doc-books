写入与巩固

一段三十轮的对话里，真正值得记一辈子的可能只有一句「我对花生过敏」，其余全是寒暄、纠正和噪声。检索再厉害，也只能在「已经写进去的东西」里挑；要是该写的没写、不该写的写一堆，整个记忆系统从源头就坏了。写入比检索更难、也更少被研究——2026 年的共识是：决定「写什么」才是记忆系统真正的分水岭。这一篇讲怎么写得对。

核心概念：从噪声里捞出信号

写入操作要解决一个本质上是「信息抽取 + 决策」的问题：从一段大部分是噪声的交互里，判断哪些信息值得保留，并以恰当的结构存进长期记忆。

它包含三个递进的子问题：写什么（从对话里抽出值得记的原子事实）、何时写（每轮即写还是会话结束批量写）、怎么演进（把零散情景巩固成抽象语义、处理重复与矛盾）。这三步做好了，长期记忆才会是一座干净有序的仓库，而非越堆越乱的垃圾场。

flowchart TD
    A[原始对话] --> B[LLM 抽取<br/>候选原子记忆]
    B --> C{值得记?<br/>重要性判定}
    C -->|否| D[丢弃]
    C -->|是| E{已有相似记忆?}
    E -->|无| F[新增 ADD]
    E -->|有·一致| G[强化/合并 UPDATE]
    E -->|有·矛盾| H[更新覆盖 UPDATE]
    F --> I[入库]
    G --> I
    H --> I
    I -.定期.-> J[巩固<br/>情景→语义抽象]

下表对比写入操作的几种基本动作，它直接对应许多框架内部的记忆更新机制：

动作 触发条件 例子 对应记忆类型
ADD 全新信息 首次得知「用户吃素」 新建语义/情景
UPDATE 已有但需修正 「吃素」改为「开始吃肉」 覆盖语义事实
MERGE 重复或同义 多次说「喜欢深色」合一 去重语义
NOOP 无价值/已存在 寒暄、闲聊 不写

写什么：信息抽取

直接把整段对话原文存进去是个常见错误——既臃肿又难检索。正确做法是先抽取：用一个 LLM 把对话读一遍，提炼出若干条结构化的原子记忆，每条只承载一个事实或一次经历。

「我下周要去上海出差，顺便想见见老同学，对了我不吃辣」这一句话，应抽取成至少两到三条原子记忆：一条出差行程（情景）、一条社交意图（情景）、一条饮食偏好（语义）。原子化的好处是检索时能精准命中——查「饮食偏好」不会被「出差」干扰。

抽取的粒度呼应了长期记忆与向量存储里讲的分块：一条原子记忆就是一个语义块，独立嵌入入库。Mem0 这类框架的核心价值之一，正是把这套「LLM 抽取 + 结构化入库」做成了开箱即用的管线，框架细节见记忆框架与实现。

何时写：时机与重要性

抽取出候选后，还要决定是否真的写和什么时候写。

重要性判定是一道过滤闸。不是每条候选都值得占用长期记忆——寒暄、临时的、一次性的信息应被判为低价值而丢弃。常见做法是让 LLM 或一个轻量打分器给候选打重要性分，低于阈值就 NOOP。这一步是抵御记忆膨胀的第一道防线，和遗忘与压缩里的事后淘汰形成「事前不写 + 事后清理」的双重防御。

写入时机有两种策略。即时写入：每轮交互后立刻抽取入库，记忆始终最新，但频繁调用 LLM 抽取成本高。批量写入：会话结束或攒够若干轮后一次性抽取，更省、且能看到更完整上下文做更好的抽取判断，代价是会话进行中记忆暂时滞后。生产里常折中：会话内用短期缓冲扛着，结束时批量巩固进长期记忆——这正衔接了短期与工作记忆里讲的工作记忆向长期记忆的写方向接力。

怎么演进：去重与矛盾消解

写入不是只管「加」，更难的是处理新信息与已有记忆的关系。这是写入操作里最考验设计的部分。

抽出一条候选后，先检索库里有没有相似记忆，然后分三种情况处置（即上表的动作）。无相似：直接 ADD。有且一致：MERGE 或强化——不要让「喜欢深色模式」存五遍。有且矛盾：这是关键分叉。对语义记忆，新事实通常该 UPDATE 覆盖旧事实（用户改了偏好，旧的作废）；但对情景记忆，两条都该保留，因为它们都是真实发生过的历史。这条区别规则的来源见情景与语义记忆。

矛盾消解做不好会出现两类典型故障：要么旧事实赖着不走，智能体拿过期信息答题；要么盲目覆盖，把本该并存的历史抹掉。时序知识图谱（如 Zep 的 Graphiti）专门为此设计——它在图上显式记录每条事实的生效与失效时间，让「这条事实从何时起被取代」可追溯，相关对比见记忆框架与实现。

巩固：把经历熬成知识

写入操作的最高形态是巩固（consolidation）——把大量零散的情景记忆，定期提炼成更抽象、更可复用的语义记忆。这是智能体真正「积累经验」而非「记流水账」的关键。

机制在情景与语义记忆里已勾勒过：当某模式在多条情景里反复出现（「连续三次点素菜」），触发一次抽象，归纳出一条语义事实（「偏好素食」）。生成式智能体的「反思」机制就是定时跑这个巩固循环，让智能体的判断越来越连贯。

巩固通常是异步的批处理：不必在每轮对话里实时做，而是定期（如每晚、或每积累 N 条情景后）回看近期记忆，做归纳、去重、抽象。这和人类睡眠中巩固记忆的类比恰到好处——白天记情景，「夜里」熬成语义。2026 年研究反复指出，公开基准几乎只评检索，对这一步「写入与巩固」的评测仍是空白，这也是评估章节要直面的缺口，见评估与挑战。

来源：Mem0: State of AI Agent Memory 2026。

小结

  • 写入比检索更难也更关键：从大部分是噪声的对话里捞出值得记的信号，是记忆系统的源头。
  • 写什么靠 LLM 抽取成结构化原子记忆，一条只承载一个事实，呼应向量存储的语义分块。
  • 何时写靠重要性判定（事前过滤膨胀）与时机选择（即时 vs 批量，生产常折中为会话结束巩固）。
  • 怎么演进靠 ADD/UPDATE/MERGE/NOOP 四动作；语义记忆冲突时覆盖、情景记忆冲突时并存。
  • 巩固把反复出现的情景异步提炼成抽象语义，是积累经验的内核；这一步至今缺乏公开基准评测。
