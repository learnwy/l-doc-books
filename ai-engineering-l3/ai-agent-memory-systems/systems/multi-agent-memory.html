多智能体共享记忆

一个智能体的记忆是它的私有日记，那一群协作的智能体呢？让一个调研智能体把发现写下来、另一个写作智能体读到它、第三个审校智能体在两者基础上修改——这时记忆不再是私有状态，而成了团队协作的媒介。但共享记忆也带来了单体记忆没有的新问题：谁能读谁的、写冲突怎么办、信息怎么不串味。这一篇把前面的记忆概念从单体扩展到群体。

核心概念：记忆作为协作媒介

单智能体里，记忆服务于「我自己跨时间的连贯」；多智能体里，记忆多了一重身份——智能体之间跨空间的协调。它从私有日记变成了公共白板。

这带来两个维度的设计选择。共享范围：记忆是全员共享，还是各有私有、按需暴露？一致性：多个智能体并发读写同一份记忆，如何避免冲突与脏读？这两个维度，是单智能体记忆从未遇到、却是分布式系统的老问题在记忆层的重演。

黑板架构：经典 AI 的回归

多智能体共享记忆最经典的范式，是从上世纪经典 AI 借来的黑板架构（blackboard）。

它的比喻很直观：一群专家围着一块黑板，每个专家把自己能贡献的局部结果写上去，其他专家读到后在此基础上接着推进，直到问题解决。落到 LLM 多智能体里，黑板就是一块所有智能体都能读写的共享记忆空间——它既是通信信道，也是协作记忆。

黑板的好处是解耦：智能体之间不必直接点对点通信，只需「往黑板写、从黑板读」，新增或替换一个专家智能体不影响其他人。这本质上是短期与工作记忆里「工作记忆」概念的群体版——一块大家共享的、围绕当前任务的工作台。2026 年有不少工作在探索基于黑板架构的高级 LLM 多智能体系统。

它的代价是并发治理：多个智能体同时往黑板写，需要规则来排序、避免互相覆盖。

来源：arXiv: Exploring Advanced LLM Multi-Agent Systems Based on Blackboard Architecture。

私有与共享：范围的边界

不是所有记忆都该全员可见。一个成熟的多智能体记忆系统要在私有和共享之间划清边界。

私有记忆是单个智能体自己的状态——它的中间推理、它独有的检索结果。这部分若全公开，会让黑板被噪声淹没，也让智能体间互相干扰。共享记忆则是协作所必需的公共事实——任务目标、已确认的发现、团队共识。

实践中的模式常是「私有为主、按需提升」：智能体平时在私有空间工作，只把经过提炼、确认有价值的结论提升到共享空间。这恰好复用了写入与巩固里的重要性判定——只不过这里判定的是「值不值得让队友看到」。范围控制也是隔离故障的手段：一个智能体记忆被污染，不该立刻拖垮全队。

MIRIX：多管理器的记忆操作系统

2026 年一个有代表性的方向是 MIRIX——把记忆按类型拆成多个专门的管理器，每个管理器各司其职。

MIRIX 为不同记忆类型设独立管理器：核心记忆、情景记忆、语义记忆、程序性记忆、资源记忆、知识库（knowledge vault）六类，每一类都通过一个路由与检索机制被访问和更新。这其实是记忆类型分类那套分类的工程极致——不再用一个大杂烩存储装所有类型，而是让每类记忆有专属的、规则适配的管理器。

这种「多管理器 + 路由」的设计天然契合多智能体：不同智能体、不同记忆类型各有专管，路由机制决定一次查询该问哪个管理器、一次写入该落到哪里。它把单体记忆里隐含的类型边界，升级成了可治理的模块边界。

来源：arXiv: MIRIX: Multi-Agent Memory System for LLM-Based Agents。

治理：共享记忆的硬骨头

共享记忆最难的不是怎么存，而是怎么治理。三个问题最棘手。

并发写冲突：两个智能体同时更新同一条共享事实，谁赢？这需要类似分布式系统的协调——加锁、版本、或让一个协调者智能体仲裁。它比写入与巩固里的单体矛盾消解更难，因为冲突源自不同主体的并发，而非同一主体的时序。

来源与出处（provenance）：共享记忆里一条事实是哪个智能体、基于什么写入的？没有出处，错误信息会在团队里悄悄传播且无法追溯。2026 年的研究普遍把「在多智能体协作中系统性地集成验证与出处」列为关键未来方向。

视角一致性：不同智能体对同一事件可能有不同记录，强行合并会失真，全部并存又会矛盾。这把情景与语义记忆里的「情景并存 vs 语义覆盖」问题，进一步复杂化为「多主体视角」问题。

这些治理难题大多尚未有公认的成熟解法，它们和单体记忆里写入、遗忘评测的空白一起，构成了这个领域待解的前沿——全貌见评估与挑战。

来源：ResearchGate: Memory in LLM-based Multi-agent Systems。

小结

  • 多智能体里记忆从私有日记变成协作媒介，新增「共享范围」与「一致性」两个单体没有的维度。
  • 黑板架构是经典范式：一块全员可读写的共享记忆空间，解耦协作，是工作记忆的群体版。
  • 私有与共享要划界，常用「私有为主、按重要性提升到共享」，范围控制也是故障隔离手段。
  • MIRIX 用六类记忆的多管理器 + 路由，把记忆分类做到工程极致，天然契合多智能体。
  • 治理是硬骨头：并发写冲突、来源出处、多视角一致性大多尚无成熟解法，是领域前沿。
