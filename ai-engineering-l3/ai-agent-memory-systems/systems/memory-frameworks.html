记忆框架与实现

前三章讲的抽取、向量存储、检索、巩固、遗忘，如果让每个团队从零手搓，光把管线跑通就要几个月。好消息是 2026 年这些环节已经被几个成熟框架封装好了——Mem0、Letta、Zep 各代表一种设计哲学。坏消息是它们定位差异很大，选错了会和需求南辕北辙。这一篇用真实数据帮你看懂三家分别擅长什么、该怎么选。

核心概念：三种记忆哲学

2026 年的记忆框架并非同质竞品，它们对「记忆是什么」的回答根本不同，这决定了各自的形态。

Mem0 是记忆层：一层你「贴」到现有智能体框架上的组件，负责存储与检索，自己不管智能体怎么运行。它采用向量 + 图 + 键值的混合存储，截至 2026 年约有 4.7 万 GitHub stars，有免费层，是「让产品记住用户」这类个性化场景的默认首选。

Letta（MemGPT 血脉）是智能体运行时：它把记忆当作智能体状态的一等公民，提供一个受操作系统启发的记忆层级，让智能体自己决定什么留在工作记忆、什么换出到长期存储。它适合长期运行、自己管理记忆分配的有状态服务。

Zep（Graphiti）是时序知识图谱：专为「事实随时间变化」的时序推理而生。在 LongMemEval 上它得分 63.8%（基于 GPT-4o），明显高于纯记忆层方案的 49.0%。

Mem0：贴上去就能记住用户

Mem0 的设计目标是最快地让一个应用具备记忆。它不要求你换掉现有的智能体框架，而是作为一层 API 接在中间：交互结束时把对话交给 Mem0，它内部完成写入与巩固里讲的那套 LLM 抽取、去重、矛盾消解；下次需要时调它的检索接口拿回相关记忆。

它的混合存储把不同记忆类型各放其位——向量管语义相似、图管实体关系、键值管精确查找，正是长期记忆与向量存储里讲的混合存储理念的产品化。对于「2026 年的消费级 AI 应用，记住用户就是卖点」这类场景，Mem0 是公认的默认起点：上手快、有免费层、社区大。

它的取舍是：把记忆管理藏在框架里换取了易用，但也意味着你对「具体怎么写、怎么忘」的控制不如 Letta 透明。

Letta：让智能体自己管记忆

Letta 继承 MemGPT 的核心洞见：与其让框架替智能体管记忆，不如把记忆管理变成智能体自己的能力。它把上下文窗口类比成操作系统的内存、把外部存储类比成磁盘，让智能体像操作系统调页一样，自主决定把什么换入工作记忆、把什么换出到长期存储。

这套 OS 式的记忆层级，本质是短期与工作记忆里「工作记忆 ↔ 长期记忆接力」的显式化、可编程化。Letta 还提供可编辑的记忆块和有状态的记忆运行时，让记忆管理对开发者透明、可控——你能看到智能体到底记了什么、改了什么。

它适合的是「智能体本身要长期运行、跨会话持续演进」的场景——不是给现有产品加个记忆插件，而是让智能体活在一个以记忆为核心的运行时里。代价是它比 Mem0 重，更像一个平台而非一个库。

Zep 与 Graphiti：为「事实会变」而生

Mem0 和 Letta 都能存事实，但有一类问题它们不天生擅长：事实随时间变化。「用户的职位是工程师」→（半年后）「用户升任经理」——旧事实不是错的，它只是在某个时间点之后失效了。

Zep 的 Graphiti 用时序知识图谱正面解决这个问题。它在图上显式记录每条事实的生效时间与失效时间，于是能回答「这条事实从何时起成立、被哪条新事实在何时取代」。这正是写入与巩固里矛盾消解、和情景与语义记忆里语义事实更新这两个难题的图结构化答案。

它在 LongMemEval 上 63.8% 对 Mem0 的 49.0%（均基于 GPT-4o）的优势，主要就来自这种时序与多跳推理能力——当评测里大量涉及「知识更新」和「多会话推理」时，图结构显出威力。代价是图谱的构建与维护比纯向量库复杂。

生产组合：很少只用一个

最后一个务实提醒：真实生产系统很少只靠一个工具。

一个常见的成熟架构是「记忆平台 + 存储层」的组合：用 Mem0 或 Zep 负责抽取与检索的智能，用 Pinecone、Redis 这类向量/键值存储负责规模化的底层存储。原因是单个工具很难同时把「智能的抽取检索」和「大规模的存储」两头都做到极致。

选型的实用决策树是：要给现有产品快速加个性化记忆 → Mem0；要构建本身就以记忆为核心、长期演进的有状态智能体 → Letta；要处理大量随时间变化、需要时序与多跳推理的事实 → Zep/Graphiti。多智能体协作场景下记忆还要解决共享与冲突，那是另一套设计，见多智能体共享记忆；而无论选哪个框架，最终都得用统一的基准去验证效果，见评估与挑战。

来源：Atlan: Best AI Agent Memory Frameworks 2026、Vectorize: Best AI Agent Memory Systems。

小结

  • 2026 年三大记忆框架代表三种哲学：Mem0 是记忆层、Letta 是智能体运行时、Zep 是时序知识图谱。
  • Mem0 混合存储、约 4.7 万 stars、有免费层，是「快速给产品加个性化记忆」的默认起点。
  • Letta 继承 MemGPT，把记忆管理变成智能体自身能力，OS 式分层 + 可编辑记忆块，适合长期有状态智能体。
  • Zep 的 Graphiti 用时序图记录事实生效/失效，LongMemEval 得 63.8% 优于 Mem0 的 49.0%，擅长事实更新与时序推理。
  • 生产很少只用一个：常以「记忆平台 + 向量/键值存储」组合，按个性化/有状态/时序三类诉求选型。
