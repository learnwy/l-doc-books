过程级评判：LLM judge 对 agent 的正确用法

结果判定只回答「这单成没成」，但工程上真正值钱的信息藏在过程里：它是稳稳当当做成的还是侥幸蒙对的？工具用得专业还是蛮力？出了错是自己爬起来的还是原地打转？这些问题的答案决定了你该信任这个 agent 到什么程度。可一旦引入 LLM 当裁判，你就往测量链路里塞进了一台自带系统误差的仪器——用得好是显微镜，用不好是哈哈镜。

核心概念：先确认真的需要裁判

过程评判的第一原则是能不用就不用。确定性检查覆盖不到的地方才是裁判的辖区：任务是否绕开了危险操作、解释是否符合用户约束、多步规划是否合理这类语义级谓词。凡是能写成断言的——文件被修改过、测试通过、API 返回了合法 JSON——都必须写成断言，因为断言免费、确定、可缓存，而每次调用裁判既花钱又引入一层噪声。一个实用的审计标准：翻看你的量规，任何一条如果可以改写成对环境终态的 shell 校验，它就不该留在量规里。

裁判的第二个使用纪律来自它的成本结构。轨迹动辄几十轮交互，把整条 trace 塞给裁判既贵又容易超出上下文。更聪明的做法是在 harness 里做事件级摘要：把冗长的观测截取关键片段、把重复的工具调用折叠计数、把报错-重试对保留原貌。裁判吃的是压缩后的结构化事实，不是原始日志的倾倒。

把量规当精密工件来造

量规（rubric）质量直接封顶了过程评判的质量上限。低质量量规长这样：「评估 agent 的表现，给出 1 到 10 分」。这种一维总分把所有失败模式压成一个数字，两个截然不同的坏轨迹会得到同样的分数。高质量量规的做法是先拆维度再拆谓词：

维度 谓词化条目示例 判定方式
工具选择 是否用了专用工具而非 shell 绕行完成检索 事件模式匹配 + 裁判复核
参数质量 传参是否完整、单位与路径是否正确 抽样交裁判
验证行为 写入后是否有校验动作（读回、跑测试） 存在性断言
错误恢复 报错后是换路径重试还是机械重复 序列模式 + 裁判断言
约束遵守 是否触碰禁区文件 / 越权操作 确定性检查

每条谓词尽量配锚定样例：一条人工标注过的应得高分轨迹片段和一条应得低分的对照片段，直接内嵌在裁判提示词里。锚定样例是对抗分数漂移最便宜的手段——它把抽象形容词（「合理」「专业」）钉死在具体案例上，让不同批次、不同版本的裁判输出落在同一把尺子上。量规本身也要走版本控制：量规变更视同评估栈解剖中评判层的变更，历史分数的可比性从变更点断裂，必须重新锚定。

偏差清单与对症下药

LLM 裁判的偏差不是随机噪声而是方向稳定的系统误差，原始分数未经处理不能跨实验比较。奠基性研究把三类偏差刻画得很清楚：位置偏差（成对比较中偏爱排在前面的答案）、冗长偏差（偏爱更长更详尽的答案）、自我增强偏差（偏爱自己家族模型生成的风格）（arXiv 2306.05685）。后续针对打分制（而非两两比较）的研究进一步发现，连量规里条目的排列顺序都会系统性影响打分，属于提示词侧的新偏差类型（arXiv 2506.22316）。agentic 场景还额外叠加一种：结果光环——裁判知道任务最终成功后，倾向给过程中的可疑操作放行。

偏差 方向 对策
位置偏差 偏爱排前的选项 双序提问取一致，不一致记平局
冗长偏差 偏爱长答案 量规声明长度不加分；喂摘要而非原文
自我增强 偏爱同源风格 裁判与被测模型不同家族
量规顺序 受条目顺序影响 条目顺序随机化并锁定版本
结果光环 成功遮蔽过程问题 盲评：不给裁判终局信息

盲评值得单独强调：把终态成败从输入中剥掉，让裁判只看脱敏后的过程序列，是掐断结果光环最简单的一刀。所有对策的共同前提是知道自己的裁判歪了多少——定期抽一小批轨迹做人工双标，算裁判与人的一致率，这个数字是过程评判可信度的唯一直接证据，其样本量的确定方法归方差与功效分析管。

编排位置：离线重放与在线哨兵

裁判放在栈里的位置决定了它能服务谁。离线重放是默认位置：评测跑完落盘的 trace 送回评判层批量打分，好处是便宜（可缓存、可并行、可换裁判反复重判）、可审计（同一份 trace 复现同一个分数），这是评估栈解剖里「写入即冻结」纪律的直接受益者。在线哨兵是进阶位置：生产流量里实时抽样一小撮会话，用轻量裁判盯守危险信号（越权尝试、循环征兆、预算失控），发现问题即时熔断或降级。在线位置贵且延迟敏感，所以采样率必然很低，它的定位是保险丝而不是测量仪。

flowchart TD
    T[冻结的 trace 存储] --> O[离线重放评判<br/>全量 低成本 可复现]
    O --> Q[量规迭代 与 人工一致性核对]
    P[线上生产流量] --> S[在线哨兵<br/>低采样率 实时]
    S --> A{危险信号?}
    A -->|是| B[熔断 / 降级 / 告警]
    A -->|否| C[抽样留档]
    B --> D[故障回流进任务套件]
    C --> D
    D --> T

两个位置由一条回路连接：线上哨兵抓到的真实故障，经过脱敏改造后回流进离线套件成为新的回归任务，这正是线上影子评估要展开的生产闭环。最后回到成本视角：裁判调用是评测账单里弹性最大的一项，量规谓词化减少裁判介入面、摘要压缩减少输入 token、小模型初筛加人复核兜底，三板斧下去通常能把过程评判的成本砍掉一个量级，完整的省钱手册在评估成本管理。过程评判的正确心态是把裁判当作一台需要周期性校准的仪器：校准记录在案，读数注明误差棒，然后放心地用它看结果判定看不见的世界。

小结

  • 能写成环境断言的过程属性绝不交给裁判，量规只收语义级谓词。
  • 量规按维度拆谓词、配锚定样例、走版本控制，一维总分是最常见的反模式。
  • 五类已知偏差各有对症解，盲评切断结果光环，人工一致率是可信度的直接证据。
  • 离线重放是默认编排位，在线哨兵是低采样的保险丝，故障经套件回流形成闭环。
