评估框架设计

核心概念

自定义评估框架是将通用 AI 评估方法论落地为可执行系统的工程实践。一个优秀的评估框架需要具备可扩展性（易于添加新评估维度）、可复现性（相同输入产出相同结果）、自动化（最小化人工干预）和可视化（清晰呈现评估结果）四个核心特性。

框架架构实现
一个生产级的评估框架应该是模块化和可扩展的：


interface EvalTask {
  id: string;
  input: string;
  expectedOutput?: string;
  metadata: Record<string, unknown>;
}

interface EvalResult {
  taskId: string;
  modelOutput: string;
  scores: Record<string, number>;
  latency: number;
  tokenUsage: { input: number; output: number };
}

interface Evaluator {
  name: string;
  evaluate: (task: EvalTask, output: string) => Promise<Record<string, number>>;
}

const createEvalFramework = (config: {
  models: Map<string, { invoke: (input: string) => Promise<string> }>;
  evaluators: Evaluator[];
  concurrency: number;
  timeout: number;
}) => {
  const runEvaluation = async (tasks: EvalTask[], modelName: string): Promise<EvalResult[]> => {
    const model = config.models.get(modelName);
    if (!model) throw new Error(`未找到模型: ${modelName}`);

    const results: EvalResult[] = [];
    const queue = [...tasks];
    const active: Promise<void>[] = [];

    const processTask = async (task: EvalTask) => {
      const start = Date.now();
      try {
        const output = await Promise.race([
          model.invoke(task.input),
          new Promise<string>((_, reject) => setTimeout(() => reject(new Error('超时')), config.timeout)),
        ]);

        const scores: Record<string, number> = {};
        for (const evaluator of config.evaluators) {
          const evalScores = await evaluator.evaluate(task, output);
          Object.assign(scores, evalScores);
        }

        results.push({
          taskId: task.id,
          modelOutput: output,
          scores,
          latency: Date.now() - start,
          tokenUsage: { input: 0, output: 0 },
        });
      } catch (error) {
        results.push({
          taskId: task.id,
          modelOutput: `ERROR: ${(error as Error).message}`,
          scores: {},
          latency: Date.now() - start,
          tokenUsage: { input: 0, output: 0 },
        });
      }
    };

    while (queue.length > 0 || active.length > 0) {
      while (active.length < config.concurrency && queue.length > 0) {
        const task = queue.shift()!;
        const promise = processTask(task).then(() => {
          active.splice(active.indexOf(promise), 1);
        });
        active.push(promise);
      }
      if (active.length > 0) await Promise.race(active);
    }

    return results;
  };

  return { runEvaluation };
};
评判器设计
评判器是评估框架中最关键的组件。不同类型的评估任务需要不同的评判策略：


const createExactMatchEvaluator = (): Evaluator => ({
  name: 'exact_match',
  evaluate: async (task, output) => {
    const normalized = output.trim().toLowerCase();
    const expected = (task.expectedOutput ?? '').trim().toLowerCase();
    return { exact_match: normalized === expected ? 1 : 0 };
  },
});

const createContainsEvaluator = (keywords: string[]): Evaluator => ({
  name: 'keyword_coverage',
  evaluate: async (_task, output) => {
    const lower = output.toLowerCase();
    const matched = keywords.filter((kw) => lower.includes(kw.toLowerCase()));
    return { keyword_coverage: matched.length / keywords.length };
  },
});

const createLLMJudgeEvaluator = (
  judge: { invoke: (messages: Array<{ role: string; content: string }>) => Promise<{ content: string }> },
  criteria: string,
): Evaluator => ({
  name: 'llm_judge',
  evaluate: async (task, output) => {
    const prompt = `评估以下回答的质量（1-10 分）。
评估标准：${criteria}
问题：${task.input}
回答：${output}
只输出一个数字分数：`;

    const result = await judge.invoke([{ role: 'user', content: prompt }]);
    const score = parseInt((result.content as string).trim());
    return { llm_judge_score: isNaN(score) ? 5 : score };
  },
});

结果分析与报告
评估结果的分析需要超越简单的平均分，提供多维度的洞察：


interface EvalReport {
  modelName: string;
  totalTasks: number;
  avgScores: Record<string, number>;
  scoreDistribution: Record<string, number[]>;
  errorAnalysis: { errorType: string; count: number; examples: string[] }[];
  comparison?: { baseline: string; improvements: Record<string, number> };
}

const generateReport = (results: EvalResult[]): EvalReport => {
  const dimensions = new Set<string>();
  for (const r of results) {
    for (const key of Object.keys(r.scores)) dimensions.add(key);
  }

  const avgScores: Record<string, number> = {};
  for (const dim of dimensions) {
    const scores = results.map((r) => r.scores[dim]).filter((s) => s !== undefined);
    avgScores[dim] = scores.reduce((a, b) => a + b, 0) / scores.length;
  }

  const errors = results.filter((r) => r.modelOutput.startsWith('ERROR:'));

  return {
    modelName: 'evaluated-model',
    totalTasks: results.length,
    avgScores,
    scoreDistribution: {},
    errorAnalysis: [{ errorType: 'timeout', count: errors.length, examples: errors.slice(0, 3).map((e) => e.taskId) }],
  };
};
小结
    

  • 评估框架的四个核心特性：可扩展、可复现、自动化、可视化
    • 

  • 模块化架构包含数据管理、执行引擎、评判器和报告四个层次
    • 

  • 评判器选择需匹配任务类型：选择题用精确匹配，开放式用 LLM 评判
    • 

  • 并发控制和超时机制是执行引擎的关键设计，防止评估卡住
    • 

  • 结果报告应包含分布分析和错误归因，而非仅展示平均分
    •
