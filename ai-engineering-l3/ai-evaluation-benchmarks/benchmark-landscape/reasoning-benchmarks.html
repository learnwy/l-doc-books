推理能力基准

核心概念

推理能力基准评估 LLM 的逻辑思维、数学运算、因果分析和多步推理能力。这些基准揭示了模型"理解"和"思考"的深度，而不仅仅是"记忆"的广度。推理基准的设计通常要求模型进行多步骤思考，任何一步出错都会导致最终答案错误，因此对模型的可靠性要求远高于简单的知识问答。

GSM8K 数学推理
GSM8K（Grade School Math 8K）包含 8,500 道小学到初中水平的数学应用题。虽然题目本身并不复杂，但它有效地测试了模型的多步推理和计算能力：


interface GSM8KProblem {
  question: string;
  answer: number;
  solutionSteps: string[];
}

const evaluateGSM8K = async (
  model: { invoke: (messages: Array<{ role: string; content: string }>) => Promise<{ content: string }> },
  problems: GSM8KProblem[],
): Promise<{ accuracy: number; stepAnalysis: { correctSteps: number; totalSteps: number } }> => {
  let correct = 0;
  let totalSteps = 0;
  let correctSteps = 0;

  for (const problem of problems) {
    const prompt = `解决以下数学问题，展示详细的解题步骤，最终答案用 #### 标记。

问题：${problem.question}`;

    const response = await model.invoke([{ role: 'user', content: prompt }]);
    const content = response.content as string;

    const answerMatch = content.match(/####\s*([\d.-]+)/);
    if (answerMatch) {
      const predicted = parseFloat(answerMatch[1]);
      if (Math.abs(predicted - problem.answer) < 0.01) correct++;
    }

    totalSteps += problem.solutionSteps.length;
  }

  return {
    accuracy: correct / problems.length,
    stepAnalysis: { correctSteps, totalSteps },
  };
};
GSM8K 的关键特点是它需要 Chain-of-Thought（思维链）推理——模型必须展示解题步骤，而不仅仅给出最终答案。这使得 GSM8K 成为评估 CoT 能力的标准基准。


BIG-Bench Hard (BBH)
BBH 从 BIG-Bench 的 204 个任务中筛选出 23 个对当前 LLM 最具挑战性的任务。这些任务涵盖了多种推理类型，需要 CoT 才能取得好成绩：


interface BBHTask {
  name: string;
  category: string;
  examples: number;
  description: string;
}

const bbhTasks: BBHTask[] = [
  { name: 'boolean_expressions', category: '逻辑', examples: 250, description: '计算布尔表达式的值' },
  { name: 'causal_judgement', category: '因果', examples: 187, description: '判断因果关系' },
  { name: 'date_understanding', category: '推理', examples: 369, description: '日期推理和计算' },
  { name: 'disambiguation_qa', category: '语义', examples: 258, description: '歧义句消解' },
  { name: 'dyck_languages', category: '形式', examples: 250, description: '嵌套括号匹配' },
  { name: 'formal_fallacies', category: '逻辑', examples: 250, description: '识别逻辑谬误' },
  { name: 'geometric_shapes', category: '空间', examples: 359, description: '几何图形识别' },
  { name: 'hyperbaton', category: '语言', examples: 250, description: '形容词排序' },
  { name: 'logical_deduction', category: '逻辑', examples: 750, description: '逻辑推演' },
  { name: 'movie_recommendation', category: '常识', examples: 250, description: '电影推荐推理' },
  { name: 'multistep_arithmetic', category: '数学', examples: 250, description: '多步算术' },
  { name: 'navigate', category: '空间', examples: 250, description: '方向导航推理' },
];
BBH 的评估结果揭示了一个重要现象：CoT 提示（"让我们一步步思考"）可以将模型在 BBH 上的表现提升 10-30 个百分点，这表明许多推理能力并非模型没有，而是需要正确的提示来激活。

CoT 与推理策略评估
评估推理能力时，不同的提示策略会显著影响结果。测试时应标准化提示方式以保证公平比较：


interface ReasoningStrategy {
  name: string;
  prompt_template: string;
  typical_improvement: string;
}

const strategies: ReasoningStrategy[] = [
  {
    name: 'Direct (直接回答)',
    prompt_template: '问题：{question}\n答案：',
    typical_improvement: '基线',
  },
  {
    name: 'CoT (思维链)',
    prompt_template: '问题：{question}\n让我们一步步思考：',
    typical_improvement: '+10-30%',
  },
  {
    name: 'Self-Consistency',
    prompt_template: '同一问题多次采样，取多数答案',
    typical_improvement: '+5-15% (相比 CoT)',
  },
  {
    name: 'Tree-of-Thought',
    prompt_template: '生成多个推理路径，评估并选择最优',
    typical_improvement: '+5-20% (相比 CoT)',
  },
];
小结
    

  • GSM8K 是评估多步数学推理的标准基准，CoT 提示对其表现影响显著
    • 

  • BBH 覆盖 23 种高难度推理任务，是当前 LLM 推理能力的试金石
    • 

  • MATH 竞赛级题目是数学推理的终极挑战，即使 GPT-4 在 Level 5 也仅约 30%
    • 

  • 评估推理能力时必须标准化提示策略（Direct vs CoT），否则结果不可比
    • 

  • 推理基准的核心价值在于揭示模型的"思考"深度而非"记忆"广度
