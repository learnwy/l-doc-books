语言能力基准

核心概念

语言能力基准是评估 LLM 核心语言理解和知识储备的标准化测试集。这些基准覆盖了从基础语言理解到专业领域知识的广泛范围，是模型发布前必须通过的"考试"。理解每个基准的设计意图、优势和局限性，才能正确解读评估结果并选择适合自己场景的评估方案。

MMLU 深度解析
MMLU（Massive Multitask Language Understanding）是目前最广泛使用的知识评估基准。它包含 57 个学科的选择题，从高中数学到研究生级别的医学和法律：


interface MMLUTask {
  subject: string;
  category: string;
  examples: number;
  difficulty: string;
}

const mmluHighlights: MMLUTask[] = [
  { subject: '抽象代数', category: 'STEM', examples: 100, difficulty: '研究生' },
  { subject: '临床医学', category: '其他', examples: 265, difficulty: '专业' },
  { subject: '计算机科学', category: 'STEM', examples: 100, difficulty: '大学' },
  { subject: '美国历史', category: '人文', examples: 204, difficulty: '高中' },
  { subject: '道德哲学', category: '人文', examples: 895, difficulty: '大学' },
  { subject: '国际法', category: '社科', examples: 121, difficulty: '专业' },
];

const runMMLUEval = async (
  model: { invoke: (messages: Array<{ role: string; content: string }>) => Promise<{ content: string }> },
  questions: Array<{ question: string; choices: string[]; answer: number }>,
  fewShot: number = 5,
): Promise<{ accuracy: number; bySubject: Map<string, number> }> => {
  let correct = 0;
  const total = questions.length;

  for (const q of questions) {
    const choiceText = q.choices.map((c, i) => `${'ABCD'[i]}. ${c}`).join('\n');
    const prompt = `${q.question}\n${choiceText}\n答案是：`;

    const response = await model.invoke([{ role: 'user', content: prompt }]);
    const answer = (response.content as string).trim().charAt(0);
    if ('ABCD'.indexOf(answer) === q.answer) correct++;
  }

  return { accuracy: correct / total, bySubject: new Map() };
};
MMLU 的主要局限：以英语为中心（对非英语模型不公平）、选择题格式无法评估生成能力、部分题目可能已被训练数据覆盖。中文场景应补充 C-Eval 或 CMMLU 等中文基准。


MT-Bench 与对话评估
MT-Bench 是评估 LLM 多轮对话能力的权威基准。它包含 80 个精心设计的两轮对话，覆盖写作、角色扮演、推理、数学、编码、提取、STEM 和人文 8 个类别：


interface MTBenchQuestion {
  id: number;
  category: string;
  turn1: string;
  turn2: string;
  referenceAnswer?: string;
}

const mtBenchCategories = [
  { name: '写作', count: 10, description: '创意写作、改写、风格转换' },
  { name: '角色扮演', count: 10, description: '模拟特定角色对话' },
  { name: '推理', count: 10, description: '逻辑推理和分析' },
  { name: '数学', count: 10, description: '数学计算和证明' },
  { name: '编码', count: 10, description: '代码生成和调试' },
  { name: '提取', count: 10, description: '信息抽取和总结' },
  { name: 'STEM', count: 10, description: '科学和技术问题' },
  { name: '人文', count: 10, description: '社会科学和人文' },
];
MT-Bench 的评分使用 GPT-4 作为评判者，对每轮回答给出 1-10 分。最终得分是两轮分数的平均值。这种 LLM-as-Judge 的方式与人工评估有 80%+ 的一致性。


AlpacaEval 与指令遵循
AlpacaEval 通过将模型输出与参考模型（GPT-4）的输出进行成对比较来评估指令遵循能力：


interface AlpacaEvalResult {
  model: string;
  winRate: number;
  avgLength: number;
  lcWinRate: number;
}

const recentLeaderboard: AlpacaEvalResult[] = [
  { model: 'GPT-4-Turbo', winRate: 50.0, avgLength: 2049, lcWinRate: 55.0 },
  { model: 'Claude-3-Opus', winRate: 40.5, avgLength: 1856, lcWinRate: 42.3 },
  { model: 'Llama-3-70B-Instruct', winRate: 33.2, avgLength: 1920, lcWinRate: 34.1 },
  { model: 'Mistral-Large', winRate: 32.7, avgLength: 1789, lcWinRate: 33.5 },
];
AlpacaEval 2.0 引入了长度控制的胜率（LC Win Rate），解决了早期版本中模型通过生成更长回答来"欺骗"评估的问题。

小结
    

  • MMLU 是最广泛的知识基准但以英语为中心，中文场景需补充 C-Eval/CMMLU
    • 

  • MT-Bench 评估多轮对话质量，使用 GPT-4 评分与人工有 80%+ 一致性
    • 

  • AlpacaEval 2.0 通过长度控制的胜率解决了"越长越好"的评估偏见
    • 

  • 基准选择应匹配评估目标：知识广度用 MMLU，对话质量用 MT-Bench，指令遵循用 AlpacaEval
    • 

  • 完整评估应同时使用选择题基准（效率高）和开放式基准（深度好）
    •
