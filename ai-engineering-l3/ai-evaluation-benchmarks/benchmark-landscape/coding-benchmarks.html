代码能力基准

核心概念

代码能力基准评估 LLM 的程序生成、代码理解和软件工程能力。代码评估有一个独特优势：可以通过运行测试用例来客观验证正确性，不需要主观判断。这使得代码基准成为 LLM 评估中可靠性最高的类别之一。

HumanEval 与 Pass@k
HumanEval 是评估 LLM 代码生成能力的经典基准。它包含 164 个编程任务，每个任务提供函数签名和文档字符串，要求模型生成函数实现：


interface HumanEvalTask {
  taskId: string;
  prompt: string;
  canonicalSolution: string;
  testCases: string;
  entryPoint: string;
}

const calculatePassAtK = (results: Array<{ taskId: string; samples: boolean[] }>, k: number): number => {
  let totalPass = 0;
  for (const task of results) {
    const n = task.samples.length;
    const c = task.samples.filter(Boolean).length;
    if (c === 0) continue;
    const passAtK = 1 - combination(n - c, k) / combination(n, k);
    totalPass += passAtK;
  }
  return totalPass / results.length;
};

const combination = (n: number, k: number): number => {
  if (k > n || k < 0) return 0;
  if (k === 0 || k === n) return 1;
  let result = 1;
  for (let i = 0; i < k; i++) {
    result = (result * (n - i)) / (i + 1);
  }
  return result;
};
Pass@k 是 HumanEval 的核心指标——它衡量"生成 k 个样本后至少有一个正确"的概率。Pass@1 反映模型的确定性能力，Pass@10 反映采样后的上限。

SWE-Bench 真实世界评估
SWE-Bench 是目前最具挑战性的代码基准，它使用来自真实开源项目（如 Django、Flask、scikit-learn）的 Bug 修复任务。模型需要理解完整代码库上下文、定位问题并生成正确的修复补丁：


interface SWEBenchTask {
  instanceId: string;
  repo: string;
  issue: string;
  baseSha: string;
  patch: string;
  testPatches: string[];
}

const sweBenchCategories = [
  { repo: 'django/django', tasks: 508, description: 'Web 框架' },
  { repo: 'scikit-learn/scikit-learn', tasks: 298, description: '机器学习库' },
  { repo: 'matplotlib/matplotlib', tasks: 274, description: '可视化库' },
  { repo: 'sympy/sympy', tasks: 356, description: '符号计算' },
  { repo: 'pytest-dev/pytest', tasks: 96, description: '测试框架' },
];
SWE-Bench 的当前最高通过率约为 40-50%（使用 Agent 模式），远低于 HumanEval 的 87%+。这个差距反映了"写一个函数"和"理解并修复真实代码"之间的巨大鸿沟。

小结
    

  • 代码基准是 LLM 评估中可靠性最高的类别，可通过测试用例客观验证
    • 

  • HumanEval 评估基础代码生成，SWE-Bench 评估真实软件工程能力，差距巨大
    • 

  • Pass@k 是核心指标，应同时报告 Pass@1（确定性）和 Pass@10（采样上限）
    • 

  • MultiPL-E 揭示了模型在不同编程语言间的能力差异，Python 最强
    • 

  • 代码评估必须在沙箱中执行、设置超时、使用固定种子保证安全和可复现性
    •
