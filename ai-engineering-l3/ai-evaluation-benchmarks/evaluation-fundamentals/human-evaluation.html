人工评估方法论

核心概念

人工评估是 AI 评估体系中不可替代的一环。当自动化指标无法捕捉输出质量的细微差异时——如回答的有用性、语言的自然度、推理的合理性——人工评估提供了最接近真实用户体验的反馈信号。然而，人工评估面临成本高、一致性低、难以规模化的挑战，需要精心的实验设计来保证结果的可靠性。

评估量表设计
评估量表的设计直接影响标注质量。Likert 量表是最常用的评分方式，但需要为每个分值提供明确的锚定描述：


interface RatingScale {
  dimension: string;
  levels: Array<{
    score: number;
    label: string;
    description: string;
    examples: string[];
  }>;
}

const helpfulnessScale: RatingScale = {
  dimension: '有用性',
  levels: [
    {
      score: 1,
      label: '完全无用',
      description: '回答与问题无关，或提供了错误信息',
      examples: ['问技术问题回答了无关内容', '给出了完全错误的代码'],
    },
    {
      score: 2,
      label: '基本无用',
      description: '回答部分相关但遗漏了关键信息',
      examples: ['只回答了问题的一小部分', '方向正确但细节全错'],
    },
    {
      score: 3,
      label: '部分有用',
      description: '回答了主要问题但有明显不足',
      examples: ['正确但过于简略', '有用但格式混乱'],

    {
      score: 4,

标注者一致性
评估者间一致性（Inter-Annotator Agreement, IAA）是人工评估质量的关键指标。常用的一致性度量包括 Cohen's Kappa 和 Krippendorff's Alpha：


const calculateCohensKappa = (raterA: number[], raterB: number[], categories: number[]): number => {
  const n = raterA.length;
  let agreement = 0;

  for (let i = 0; i < n; i++) {
    if (raterA[i] === raterB[i]) agreement++;
  }
  const po = agreement / n;

  let pe = 0;
  for (const cat of categories) {
    const pA = raterA.filter((r) => r === cat).length / n;
    const pB = raterB.filter((r) => r === cat).length / n;
    pe += pA * pB;
  }

  return (po - pe) / (1 - pe);
};

const interpretKappa = (kappa: number): string => {
  if (kappa < 0.2) return '一致性极差，需要重新定义评估标准';
  if (kappa < 0.4) return '一致性差，需要加强评估者培训';
  if (kappa < 0.6) return '一致性中等，可接受但需关注分歧点';
  if (kappa < 0.8) return '一致性良好，评估结果可信';
  return '一致性优秀，评估结果高度可靠';
};

评估实验设计
科学的评估实验需要控制偏见、保证样本代表性和统计效力：


interface ExperimentDesign {
  sampleSize: number;
  ratersPerSample: number;
  randomization: string;
  blindingLevel: string;
  controlGroup: string;
}

const calculateRequiredSampleSize = (effectSize: number, alpha: number = 0.05, power: number = 0.8): number => {
  const zAlpha = alpha === 0.05 ? 1.96 : 2.576;
  const zBeta = power === 0.8 ? 0.84 : 1.28;
  return Math.ceil(((zAlpha + zBeta) / effectSize) ** 2);
};

const designExperiment = (): ExperimentDesign => ({
  sampleSize: calculateRequiredSampleSize(0.5),
  ratersPerSample: 3,
  randomization: '对评估样本和展示顺序进行随机化',
  blindingLevel: '评估者不知道模型身份（双盲）',
  controlGroup: '包含已知质量的控制样本用于校准',
});
关键实验设计原则：随机化展示顺序（消除位置偏见），双盲设计（评估者不知道哪个回答来自哪个模型），包含控制样本（检测评估者是否认真标注），以及足够的样本量（通常 ≥200 个评估样本）。

小结
    

  • 人工评估是自动化指标无法替代的，特别是评估有用性、自然度和推理合理性
    • 

  • 评估量表每个分值都需要明确的锚定描述和示例，避免评估者主观漂移
    • 

  • Cohen's Kappa > 0.6 是人工评估可信度的基本门槛，低于此需重新校准
    • 

  • 实验设计应包含随机化、双盲、控制样本和足够的样本量
    • 

  • AI 预筛选 + 专家精评的混合策略可在保持质量的前提下降低 60-80% 的成本
    •
