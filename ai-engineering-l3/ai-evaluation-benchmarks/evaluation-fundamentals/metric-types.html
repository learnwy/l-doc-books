评估指标体系

核心概念

AI 评估指标是量化模型表现的数学工具。不同的任务类型需要不同的指标，而指标的选择直接影响评估的有效性。LLM 评估中最常见的误区是使用不适合开放式生成的指标（如 BLEU）来评价对话质量，或用单一指标代表模型的综合能力。理解每种指标的适用范围和局限性是设计有效评估的前提。

分类与选择题指标
选择题基准（如 MMLU）使用的指标最为直观——模型从给定选项中选择答案，与标准答案比较计算准确率：


interface ClassificationMetrics {
  accuracy: number;
  precision: number;
  recall: number;
  f1: number;
  confusionMatrix: number[][];
}

const calculateMetrics = (predictions: string[], labels: string[], classes: string[]): ClassificationMetrics => {
  const n = predictions.length;
  let correct = 0;
  const matrix = classes.map(() => classes.map(() => 0));

  for (let i = 0; i < n; i++) {
    const predIdx = classes.indexOf(predictions[i]);
    const labelIdx = classes.indexOf(labels[i]);
    if (predIdx >= 0 && labelIdx >= 0) matrix[labelIdx][predIdx]++;
    if (predictions[i] === labels[i]) correct++;
  }

  const accuracy = correct / n;

  let totalPrecision = 0;
  let totalRecall = 0;
  for (let c = 0; c < classes.length; c++) {
    const tp = matrix[c][c];
    const fp = matrix.reduce((s, row, i) => s + (i !== c ? row[c] : 0), 0);
    const fn = matrix[c].reduce((s, v, i) => s + (i !== c ? v : 0), 0);
    totalPrecision += tp / (tp + fp || 1);
    totalRecall += tp / (tp + fn || 1);
  }

  const precision = totalPrecision / classes.length;
  const recall = totalRecall / classes.length;
  const f1 = (2 * (precision * recall)) / (precision + recall || 1);

  return { accuracy, precision, recall, f1, confusionMatrix: matrix };
};
选择题准确率的局限在于它只评估模型的知识检索能力，不能评估生成质量。一个模型可能在 MMLU 上得分很高但对话体验很差。


生成质量指标
开放式生成的评估远比选择题困难。传统指标（BLEU、ROUGE）基于词汇重叠，无法捕捉语义正确性：


const calculateRougeL = (reference: string, hypothesis: string): number => {
  const refTokens = reference.split('');
  const hypTokens = hypothesis.split('');

  const lcs = (a: string[], b: string[]): number => {
    const m = a.length;
    const n = b.length;
    const dp: number[][] = Array.from({ length: m + 1 }, () => Array(n + 1).fill(0));
    for (let i = 1; i <= m; i++) {
      for (let j = 1; j <= n; j++) {
        dp[i][j] = a[i - 1] === b[j - 1] ? dp[i - 1][j - 1] + 1 : Math.max(dp[i - 1][j], dp[i][j - 1]);
      }
    }
    return dp[m][n];
  };

  const lcsLen = lcs(refTokens, hypTokens);
  const precision = lcsLen / hypTokens.length;
  const recall = lcsLen / refTokens.length;
  return (2 * precision * recall) / (precision + recall || 1);
};

LLM-as-Judge 指标
使用 LLM 作为评判者已成为开放式生成评估的主流方法：


interface JudgeScore {
  dimension: string;
  score: number;
  explanation: string;
}

const createPointwiseJudge = (config: {
  evaluator: { invoke: (messages: Array<{ role: string; content: string }>) => Promise<{ content: string }> };
  dimensions: Array<{ name: string; criteria: string }>;
  scale: [number, number];
}) => {
  return async (question: string, answer: string): Promise<JudgeScore[]> => {
    const prompt = `评估以下 AI 回答的质量，对每个维度给出 ${config.scale[0]}-${config.scale[1]} 分：

${config.dimensions.map((d) => `- ${d.name}: ${d.criteria}`).join('\n')}

问题：${question}
回答：${answer}

以 JSON 数组格式输出：[{"dimension": "维度名", "score": 分数, "explanation": "理由"}]`;

    const result = await config.evaluator.invoke([{ role: 'user', content: prompt }]);
    return JSON.parse(result.content as string);
  };
};

const createPairwiseJudge = (evaluator: {
  invoke: (messages: Array<{ role: string; content: string }>) => Promise<{ content: string }>;
}) => {
  return async (question: string, answerA: string, answerB: string) => {
    const prompt = `比较以下两个回答的质量：

问题：${question}
回答 A：${answerA}
回答 B：${answerB}

选择更好的回答：输出 "A"、"B" 或 "tie"，并说明理由。
格式：{"winner": "A/B/tie", "reasoning": "理由"}`;

    const result = await evaluator.invoke([{ role: 'user', content: prompt }]);
    return JSON.parse(result.content as string);
  };
};
ELO 评分系统
ELO 评分借鉴了国际象棋的排名系统，通过模型之间的两两对比计算综合排名。这是 Chatbot Arena 等排行榜采用的核心方法：


const calculateELO = (
  matches: Array<{ modelA: string; modelB: string; winner: 'A' | 'B' | 'tie' }>,
  k: number = 32,
): Map<string, number> => {
  const ratings = new Map<string, number>();

  const getRating = (model: string) => ratings.get(model) ?? 1200;

  for (const match of matches) {
    const rA = getRating(match.modelA);
    const rB = getRating(match.modelB);

    const eA = 1 / (1 + Math.pow(10, (rB - rA) / 400));
    const eB = 1 - eA;

    const sA = match.winner === 'A' ? 1 : match.winner === 'tie' ? 0.5 : 0;
    const sB = 1 - sA;

    ratings.set(match.modelA, rA + k * (sA - eA));
    ratings.set(match.modelB, rB + k * (sB - eB));
  }

  return ratings;
};
小结
    

  • 指标选择需匹配任务类型：选择题用准确率，翻译用 BLEU，对话用 LLM-Judge
    • 

  • 传统文本相似度指标（BLEU/ROUGE）不适合评估开放式对话质量
    • 

  • LLM-as-Judge 分为逐点评分和成对比较两种模式，各有适用场景
    • 

  • ELO 评分系统通过两两对比建立模型排名，是 Chatbot Arena 的核心方法
    • 

  • 综合评估应结合多种指标类型，避免单一指标的片面性
