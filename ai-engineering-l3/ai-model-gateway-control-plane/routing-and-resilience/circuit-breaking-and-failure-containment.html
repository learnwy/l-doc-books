熔断、舱壁与故障收敛

当供应商变慢时，最危险的反应是继续排队并增加重试：连接、内存和并发槽位会先在网关耗尽，随后健康租户和其他供应商也被拖入故障。熔断的目标不是给错误换一个名字，而是在下游失效前快速拒绝，把故障限制在最小部署与租户边界内。

核心概念

模型网关需要多维熔断器：每个部署限制活动请求、待处理请求和活动重试；每个租户限制其占用；整个数据面还有连接、内存和事件缓冲上限。舱壁让不同供应商、区域、模型等级与租户池使用独立资源，避免共享线程池成为隐藏单点。

熔断器状态与作用域

典型状态包括关闭、打开和半开。关闭状态允许流量并统计滑动窗口；超过失败率、慢调用率或资源阈值后打开，短时间快速拒绝；冷却后进入半开，只允许有限探针，连续满足恢复门才关闭。状态转换需要抖动，避免所有实例同时探测。

作用域过大，会因一个区域故障熔断整个供应商；作用域过小，每个进程只有少量样本，无法及时发现系统性问题。实践中以具体部署为基础维度，数据面实例上执行本地并发保护，再由汇总健康服务发布近实时全局异常信号。全局信号是路由输入，本地上限是最后一道硬保护。

错误也需分权重。认证失败通常是配置故障，应立刻隔离相关凭证或部署；429 可能表示租户配额、账户配额或供应商容量，要按响应上下文归属；输入 400 不计入供应商健康；流中断和首 Token 超时可以进入慢调用或可用性窗口。把所有非 2xx 都算失败会被用户输入污染。

并发限制与排队

静态并发值适合初始保护，动态限制可根据近期延迟与成功率缓慢调整。无论算法如何，调整速率要有上下界，避免健康波动导致容量振荡。模型请求长度差异巨大，只按请求数会让一个超长生成和一个短分类等价；可以用估算输入加最大输出 Token 作为加权并发单位。

Little 定律提供排队直觉：

L=λWL = \lambda WL=λW

若到达率 λ\lambdaλ 不变而服务时间 WWW 因供应商变慢翻倍，系统内在途数量 LLL 也会翻倍。没有并发与队列上限时，这个增长会持续到网关资源耗尽。快速拒绝看似降低单次成功率，却保护了整体恢复时间与其他故障域。

队列必须有等待截止时间和可取消条目。请求入队前计算其剩余端到端预算，预计排队后无时间完成就直接拒绝。高优先级流量可以拥有保留容量，但不能无限抢占；后台批处理应在在线流量压力上升时首先被削减。

异常点检测与健康恢复

被动健康来自真实调用，主动健康来自合成探针。被动信号更真实却受流量构成影响，主动探针稳定却只能验证狭窄路径。两者结合：被动失败快速触发隔离，主动探针在低流量或打开状态下验证恢复。

准入应通过租约完成：获取租约原子增加活动量，尝试在成功、失败或取消的所有路径释放。流式客户端断开但上游未终止时，租约仍应覆盖实际占用，不能提前释放造成超卖。进程崩溃时，本地计数随进程消失，全局统计则依赖短租期或心跳纠正。

恢复门要比打开门更严格。例如失败率超过阈值立即打开，而半开需要最少探针数、连续时间窗和首 Token 延迟同时达标才关闭。恢复流量逐步增加，避免刚恢复的供应商被积压请求再次击穿。

舱壁与级联故障预防

供应商适配器应使用独立连接池、并发信号量和事件缓冲。共享的日志发送器、DNS 解析或凭证服务也可能成为跨舱壁耦合，因此数据面要缓存短期可用凭证和策略快照，并限制遥测失败对请求路径的阻塞。证据可以异步批量发送，但关键审计事件写入本地有界缓冲，满时按数据分类决定拒绝或降采样。

租户舱壁常用加权公平共享：每个租户有保底份额，空闲容量可借用，压力出现时收回借用。绝不能让第一个占满连接池的租户维持永久优势。内部平台请求与终端用户请求可使用不同优先级，但优先级数量要少且定义清晰。

Envoy 的熔断文档把连接、待处理请求、活动请求和活动重试分别设限，并建议优先使用重试预算；全局限流文档又说明本地令牌桶可吸收突发、全局配额负责公平协调。模型网关可以借用这些机制，但还要增加 Token 权重、长流生命周期和语义失败信号。

演练与可观察退出条件

故障演练应逐层扩大。先让单个部署返回过载，验证只打开对应熔断器；再让一个区域首 Token 变慢，验证路由转移且额外尝试率受限；最后模拟供应商全失联，验证独立供应商、离线队列或受控失败路径。演练同时观察健康租户的延迟，证明舱壁有效。

关键指标包括每个部署的活动、待处理、拒绝、熔断状态、半开探针、慢调用率、取消后仍活动请求，以及按租户的借用容量。只监控成功率无法发现队列正在膨胀。告警应指向可操作边界，例如“部署 A1 待处理溢出”，而不是笼统的“AI 网关异常”。

熔断器把健康快照提供给路由与放置，重试器则遵循尝试预算。如果重试可以绕过打开的熔断器，或路由仍把打开部署排在首位，三个模块的组合就失去意义。

小结

  • 熔断要分别限制连接、活动、待处理、重试和流缓冲，而非只看错误率。
  • 具体部署是基础故障域，本地硬保护与全局健康信号互补。
  • 用户输入错误不应污染供应商健康，429 需要识别配额归属。
  • 有界排队与快速拒绝能阻止 Little 定律描述的在途请求膨胀。
  • 租约覆盖真实上游占用，取消未确认前不能提前释放容量。
  • 用舱壁和逐层故障演练证明局部故障不会拖垮其他供应商或租户。
