多语言多地区电商搜索意图识别

核心概念

TikTok Shop 在全球十多个市场运营，覆盖英语、泰语、越南语、印尼语（马来语）、西班牙语、葡萄牙语、阿拉伯语、日语、韩语等多种语言。搜索意图识别——判断用户的查询是要"买东西"还是"看内容"以及想买什么品类的什么商品——在单一语言环境下已经是挑战性任务，在多语言多地区环境下则呈指数级复杂化。同样的查询词在不同语言和地区中可能指向完全不同的商品品类、不同的价格期望和不同的购物动机。

多语言电商搜索意图识别的核心难题是"跨语言语义鸿沟"和"跨文化意图差异"的叠加。跨语言语义鸿沟指的是不同语言对同一商品概念的表达差异——不仅是简单的翻译对应，还包括缩写、俚语、音译、代码混合等复杂现象。跨文化意图差异指的是即使理解了查询的字面含义，不同文化背景的用户对同一查询的购物期望也可能不同。

多语言 Query 理解的技术挑战
不同语言的文本处理在分词、形态变化、书写系统等基础层面就存在巨大差异，这些差异直接影响 Query 理解的每一个环节。


分词是第一个挑战。英语以空格分词，技术上相对简单。但泰语和越南语没有天然的词边界——"ชุดเดรสสีแดง"（红色连衣裙）在泰语中是一个连续的字符串，需要专门的分词模型来切分。印尼语虽然使用拉丁字母且有空格分词，但存在大量的前缀/后缀粘连（如 "ber-" "me-" 前缀改变词义）。分词错误会直接导致后续的实体识别和意图分类失败。


拼写变异和缩写是第二个挑战。在东南亚市场的 TikTok 搜索中，用户大量使用非标准拼写和缩写。泰语用户习惯用缩写代替完整词汇（如 "มือ1" 代表"全新"），越南语用户经常省略声调符号（"ao dai" 替代 "áo dài"），印尼语用户使用数字替代音节（如 "km" 代替 "kemana"）。这些非标准输入需要在 Query 改写阶段进行规范化处理。


代码混合（Code-Mixing）是 TikTok 搜索中特别突出的现象。全球化市场中的用户经常在一个查询中混合使用多种语言。例如，泰国用户搜索"เสื้อ oversize สีดำ"（黑色 oversize 上衣），其中"oversize"是英文，其余是泰语。越南用户搜索"áo hoodie nam"（男款 hoodie），其中"hoodie"是英文借词。搜索系统需要能够处理这种混合语言输入，正确识别每个语言片段的含义。


品牌和商品名的多语言变体是第三个挑战。同一个品牌可能有本地化名称（如"耐克"= "Nike" = "ไนกี้"），同一个商品可能有完全不同的本地叫法（如"手机壳"在越南语中是"ốp lưng điện thoại"，但用户更常搜"case điện thoại"）。意图识别系统需要维护跨语言的品牌和商品实体映射表。

同一查询的跨地区意图差异
即使正确理解了查询的语言学含义，同一个查询在不同地区可能反映完全不同的电商意图。这种跨地区意图差异是多语言意图识别中最需要业务理解的环节。


品类偏好差异是最常见的表现。当英国用户搜索"football"时，期望看到的是英式足球（soccer）相关商品。当美国用户搜索"football"时，期望看到的是美式橄榄球（American football）相关商品。同样，"chips"在英国是薯条，在美国是薯片。这些差异要求意图识别系统具备地区感知能力——根据用户所在地区调整品类映射。


价格期望差异是第二种表现。搜索"好看的连衣裙"这个查询在美国市场，用户的价格期望可能在 30-80 美元。在印尼市场，同样的查询对应的价格期望可能在 50,000-200,000 印尼盾（约 3-13 美元）。在英国市场则可能在 20-60 英镑。价格期望的差异影响搜索结果的排序策略——如果为印尼用户展示美国价位的商品，即使相关性很高，转化率也会极低。


季节性差异影响时尚和生活品类的意图理解。同一时间点，北半球的用户搜索"外套"是因为即将入秋，南半球的用户搜索"外套"可能是在清仓购买或反季囤货。TikTok Shop 在全球多个时区运营，意图识别需要结合用户所在地区的季节和气候信息。


低资源语言的意图模型构建
TikTok Shop 在扩展到新市场时，经常面临"低资源语言"的挑战——某种语言的标注训练数据极度稀缺，无法训练高质量的意图识别模型。例如，当 TikTok Shop 进入拉丁美洲市场时，西班牙语和葡萄牙语的电商搜索标注数据可能远不如英语和泰语（后两者因为市场较早开通而积累了大量数据）。


解决低资源语言问题的第一种策略是跨语言迁移学习。利用在高资源语言（如英语）上训练好的意图识别模型，通过多语言预训练模型（如 mBERT、XLM-R）作为桥梁，将意图识别能力迁移到低资源语言。具体做法是：先在英语标注数据上微调意图分类模型，然后在少量目标语言标注数据上进一步适配。这种方法可以在仅有几百条目标语言标注数据的情况下达到可用水平。


第二种策略是翻译增强。将高资源语言的标注数据通过机器翻译转换为目标语言，作为训练数据的补充。这种方法的风险是翻译质量不稳定——机器翻译可能无法正确处理俚语、缩写和代码混合，导致训练数据中引入噪声。因此，翻译后的数据通常需要人工审核一个子集来评估质量。


第三种策略是渐进式数据积累。在新市场上线初期使用跨语言迁移模型提供基础能力，同时通过搜索日志收集用户行为数据（点击、购买）作为弱监督信号，逐步积累目标语言的训练数据。随着数据量增长，定期重新训练模型以提升准确率。

电商意图分类的细粒度体系
在 TikTok 的搜索系统中，电商意图识别不仅要判断"是否有购物意图"，还需要细粒度地分类购物意图的类型，因为不同类型的购物意图需要不同的搜索结果策略。


第一层分类是"电商意图强度"：无电商意图（如"搞笑视频"）、弱电商意图（如"化妆教程"——可能间接引导购买但主要目的是看内容）、中电商意图（如"口红推荐"——既想看内容也想买）、强电商意图（如"买 MAC 口红"——明确要购买）。这个分类直接决定搜索结果中电商内容的占比。


第二层分类是"购物阶段"：发现探索（用户不确定要买什么，搜索品类大词）、信息收集（用户在比较方案，搜索"xx vs xx"或"xx 推荐"）、明确选购（用户已确定要什么，搜索具体商品名或型号）、复购回购（用户搜索之前买过的商品）。不同购物阶段需要展示不同类型的搜索结果——发现阶段展示多样化的品类结果，明确选购阶段展示精准匹配的商品。


第三层分类是"品类意图"：将查询映射到 TikTok Shop 的商品品类树。例如，"summer dress"映射到"女装→连衣裙→夏季连衣裙"。品类意图的识别直接影响召回范围和品类筛选的准确性。在多语言环境下，品类映射需要维护每种语言的品类词库和同义词表。


新市场意图模型的冷启动策略
当 TikTok Shop 进入一个全新的市场时，意图识别系统面临"双重冷启动"问题：既没有该语言的充足训练数据，也缺乏对该市场电商消费习惯的理解。冷启动策略的核心是在最短时间内建立可用的意图识别能力，同时为长期的模型优化奠定基础。


冷启动的第一步是基线模型部署。利用跨语言迁移模型和翻译增强数据，训练一个基础的意图识别模型。这个模型的准确率可能只有 60%-70%（相比成熟市场的 85%-90%），但足以在搜索系统中提供基本的电商意图路由功能。


第二步是规则系统补充。在模型能力不足的领域，用规则系统作为补充。例如，维护一个该市场的高频电商查询词列表（通过竞品分析和市场调研获取），对列表中的查询直接赋予高电商意图标签。规则系统响应快、可解释，但覆盖率有限。


第三步是数据飞轮启动。通过搜索日志收集用户行为信号（搜索后是否点击了商品、是否进入了电商 Tab），将这些行为信号作为弱监督标签，逐步扩充训练数据。随着数据量增长，定期重新训练模型，逐步提升准确率。当标注数据量达到一定规模（通常 5,000-10,000 条高质量标注），可以训练专属于该市场的精细化模型。

小结
    

  • TikTok 电商搜索意图识别的核心挑战是跨语言语义鸿沟与跨文化意图差异的叠加，需要在语言理解、文化感知和电商知识三个层面同时建模
    • 

  • 多语言 Query 理解面临分词差异、拼写变异、代码混合和品牌名多语言变体四大技术挑战，每种语言需要定制化的处理策略
    • 

  • 同一查询在不同地区可能映射到不同品类、不同价格期望和不同季节需求，意图识别系统必须具备地区感知能力
    • 

  • 低资源语言的意图模型可通过跨语言迁移、翻译增强和渐进式数据积累三种策略构建，以跨语言迁移为快速上线首选
    • 

  • 电商意图分类需要三层细粒度体系：意图强度、购物阶段和品类意图，不同分类结果驱动不同的搜索结果策略
    • 

  • 新市场冷启动遵循"基线部署→规则补充→数据飞轮→成熟优化"的渐进路径，核心是尽快启动数据积累的飞轮效应
    •
