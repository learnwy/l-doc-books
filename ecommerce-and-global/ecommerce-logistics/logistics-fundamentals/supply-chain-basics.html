电商供应链基础

核心概念

供应链是从原材料到最终消费者的价值链路，电商供应链的核心挑战在于需求不确定性高、SKU 数量大、交付时效要求严格。与传统零售的"推式"供应链不同，电商更倾向"拉式"或"推拉结合"的策略——根据实际订单驱动下游配送，同时基于预测提前布局上游库存。

需求预测与计划
需求预测是供应链计划的起点，决定了采购量、生产量和库存分布。电商需求预测的难度在于长尾效应（20% 的 SKU 贡献 80% 的销售额，但 80% 的 SKU 需求波动大）、促销影响（大促期间销量可能是日常的 10-50 倍）和新品冷启动（无历史数据）。


interface DemandForecast {
  sku: string;
  forecastPeriod: { start: string; end: string };
  baselineForecast: number;
  adjustments: {
    promotionalLift: number;
    seasonalFactor: number;
    trendComponent: number;
    externalEvents: number;
  };
  finalForecast: number;
  confidenceInterval: {
    lower: number;
    upper: number;
    confidence: number;
  };
  model: {
    type: 'statistical' | 'ml' | 'hybrid';
    name: string;
    accuracy: { mae: number; mape: number; bias: number };
  };
}
预测模型的选择取决于数据量和需求特征。时间序列模型（ARIMA、Prophet）适合历史数据充足的标品，机器学习模型（LightGBM、DeepAR）在特征丰富时表现更优，新品预测则需要基于类似商品的迁移学习或专家判断。

库存网络与分仓策略
库存网络设计决定了商品存放在哪些仓库、每个仓库存多少。目标是在服务水平（配送时效）和库存成本（仓储费+资金占用）之间找到最优平衡。


电商的仓网层级通常为：中心仓（CDC，覆盖全国，SKU 全）→ 区域仓（RDC，覆盖大区，SKU 精选）→ 前置仓（FDC，覆盖 3-5 公里，高频 SKU）。库存越下沉，配送越快但库存成本越高。


interface WarehouseNetwork {
  warehouses: {
    id: string;
    type: 'cdc' | 'rdc' | 'fdc' | 'micro_fulfillment';
    location: { lat: number; lng: number; city: string };
    capacity: {
      storageArea: number;
      dailyOrders: number;
      skuCount: number;
    };
    coverage: {
      radiusKm: number;
      deliveryPromise: string;
      coveredPopulation: number;
    };
    costs: {
      rentPerSqm: number;
      laborPerOrder: number;
      utilityMonthly: number;
    };
  }[];
  inventoryPolicy: {
    allocationModel: 'push' | 'pull' | 'hybrid';
    safetyStockMethod: 'fixed' | 'dynamic' | 'service_level_based';
    replenishmentTrigger: 'reorder_point' | 'periodic' | 'demand_driven';
    interWarehouseTransfer: boolean;
  };
}
分仓的核心算法是库存分配优化（Inventory Allocation Optimization）。输入变量包括各仓库的覆盖区域需求预测、仓储成本、运输成本和服务水平要求，输出是每个 SKU 在每个仓库的目标库存量。这本质上是一个多约束优化问题，常用线性规划或启发式算法求解。

供应商协同
供应商管理是供应链上游的核心环节。电商平台与供应商的协同程度直接影响到货率、采购成本和库存周转率。VMI（供应商管理库存）模式下，供应商基于平台共享的销售和库存数据自主决定补货时间和数量，减少了平台的采购管理负担。

小结
    

  • 电商供应链以"推拉结合"为主流模式——上游基于预测推式备货，下游基于订单拉式配送
    • 

  • 需求预测是供应链计划的起点，长尾 SKU 和大促场景是预测的最大挑战
    • 

  • 仓网层级（CDC → RDC → FDC → MFC）通过库存下沉加速配送，但库存成本随之上升
    • 

  • 库存分配优化在服务水平和库存成本之间寻找最优解，是供应链运筹学的核心问题
    • 

  • VMI 和 CPFR 等深度协同模式通过供应商数据共享提升整体供应链效率
    •
