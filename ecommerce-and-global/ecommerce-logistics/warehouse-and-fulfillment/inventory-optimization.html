库存优化

核心概念

库存优化是在服务水平（不缺货）和库存成本（资金占用+仓储费）之间寻找最优平衡点的运筹学问题。电商的库存优化复杂度远高于传统零售——SKU 数量以百万计、需求波动大、补货频率高。库存过多导致资金占用和滞销风险，库存不足导致缺货损失和用户流失。

ABC-XYZ 分类管理
ABC 分类按销售贡献度将商品分为三类：A 类（前 20% SKU，贡献 80% 销售额）、B 类（中间 30%，贡献 15%）、C 类（后 50%，贡献 5%）。XYZ 分类按需求稳定性分：X（波动小，可预测）、Y（中等波动）、Z（高波动，难预测）。

安全库存与补货算法
安全库存（Safety Stock）是为应对需求波动和供应不确定性而额外持有的缓冲库存。安全库存的计算需要平衡两个成本：缺货成本（失去订单+用户流失）和持有成本（资金占用+仓储）。


经典的安全库存公式为：SS = Z × σ_d × √L，其中 Z 是服务水平对应的标准正态分位数（95% 对应 Z=1.65），σ_d 是日需求标准差，L 是补货提前期天数。但这个公式假设需求正态分布，实际电商中长尾 SKU 的需求往往呈泊松分布或间歇分布，需要使用更精确的方法。


interface SafetyStockCalculation {
  method: 'normal' | 'poisson' | 'simulation' | 'machine_learning';
  inputs: {
    averageDailyDemand: number;
    demandStdDev: number;
    leadTimeDays: number;
    leadTimeVariability: number;
    targetServiceLevel: number;
  };
  result: {
    safetyStock: number;
    reorderPoint: number;
    economicOrderQuantity: number;
    annualHoldingCost: number;
    expectedStockouts: number;
  };
}

interface ReplenishmentPolicy {
  type: 'reorder_point' | 'periodic_review' | 'min_max' | 'kanban';

    reorderPoint?: number;

    maxLevel?: number;
  };
  constraints: {
    minimumOrderQuantity: number;
    orderMultiple: number;

  };
}

多仓库存协同
电商的多级仓网中，库存不是孤立存在的。中心仓、区域仓和前置仓之间需要协同补货和调拨。库存下沉（将商品从中心仓预分配到区域仓/前置仓）可以缩短配送时效，但增加了库存碎片化风险。


interface MultiWarehouseInventory {
  sku: string;
  totalStock: number;

    inTransit: number;
    safetyStock: number;
  }[];
  transferPolicy: {
    allowInterWarehouseTransfer: boolean;
    transferTrigger: 'stockout_prevention' | 'rebalance' | 'demand_shift';
    transferLeadTime: number;
    transferCost: number;
    minimumTransferQuantity: number;

  globalAvailableToPromise: {
    method: 'decentralized' | 'centralized' | 'virtual_pool';
    oversellProtection: boolean;
    allocationPriority: ('nearest_warehouse' | 'highest_stock' | 'lowest_cost')[];
  };
}
全局可售量（Global ATP）是多仓协同的核心概念。当消费者浏览商品时，系统需要实时计算该 SKU 在消费者所在区域的最近仓库是否有货。如果最近仓库缺货，是否可以从其他仓库调拨或跨区发货。这要求库存系统具备毫秒级的全局库存查询能力。

滞销处理与库存健康
库存健康管理不仅关注库存量，还关注库存的"质量"——滞销品（Dead Stock）、临期品和残次品占用仓储空间和资金，是库存管理的隐性成本。


interface InventoryHealth {
  sku: string;
  healthStatus: 'healthy' | 'slow_moving' | 'obsolete' | 'excess';
  metrics: {
    daysSinceLastSale: number;
    turnoverRate: number;
    agingDistribution: {
      '0-30d': number;
      '30-60d': number;
      '60-90d': number;
      '90d+': number;
    };
    excessQuantity: number;
    potentialWriteOff: number;
  };
  recommendedAction: {
    action: 'hold' | 'markdown' | 'bundle' | 'liquidate' | 'donate' | 'dispose';
    urgency: 'low' | 'medium' | 'high';
    estimatedRecovery: number;
  };
}

小结
    

  • 库存优化的核心是在服务水平（不缺货）和持有成本（资金占用）之间找到平衡点
    • 

  • ABC-XYZ 交叉分类为不同特征的 SKU 制定差异化的库存策略
    • 

  • 安全库存计算需考虑需求波动和补货提前期，长尾 SKU 不适合正态分布假设
    • 

  • 多仓库存协同通过全局可售量（ATP）系统实现跨仓库的实时库存可见性
    • 

  • 滞销品管理是库存健康的重要维度，促销清仓和渠道分流是主要处理手段
