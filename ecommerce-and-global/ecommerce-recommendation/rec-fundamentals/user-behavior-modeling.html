用户行为建模

核心概念

用户行为建模是推荐系统中最关键的技术环节之一，其目标是通过分析用户在平台上的各类行为，构建精准的用户兴趣表征。在电商场景下，用户行为具有多维度、多粒度、时序性强的特征，有效的行为建模能够捕捉用户的短期意图和长期偏好，为个性化推荐提供高质量的信号输入。

用户行为可按时间跨度、行为强度、行为场景等多个维度进行分类，不同类别的行为对推荐模型的价值各不相同。

行为序列建模
行为序列建模将用户在时间轴上的一系列行为看作一个有序序列，通过对序列模式的学习来捕捉用户兴趣的动态变化。这是当前推荐系统中最活跃的研究方向之一。


早期的序列建模方法基于马尔可夫链，假设用户下一个行为仅依赖于前一个或前几个行为。这种方法简单高效但难以捕捉长距离依赖关系。随后，基于 RNN（循环神经网络）的方法被引入推荐系统，GRU4Rec 是第一个将 GRU 应用于会话推荐的模型，能够有效建模用户在一次会话内的行为序列。


注意力机制的引入是序列推荐的重要转折点。DIN（Deep Interest Network）通过注意力机制动态地从用户历史行为中提取与候选商品相关的兴趣表征，解决了固定长度向量难以表达多样化兴趣的问题。DIEN（Deep Interest Evolution Network）进一步引入 GRU 建模兴趣的演化过程，使用辅助损失函数强化兴趣状态的学习。


基于 Transformer 的序列推荐模型（如 SASRec、BERT4Rec）利用自注意力机制在全局范围内建模行为间的依赖关系。SASRec 使用单向 Transformer 预测用户的下一个行为，而 BERT4Rec 采用双向 Transformer 和掩码预测任务，能够更充分地利用序列中的上下文信息。

多行为融合建模
电商用户的行为类型丰富，包括浏览、点击、加购、收藏、购买等多种行为。不同行为反映了用户不同层次的兴趣强度，如何有效融合多种行为信号是用户建模的重要课题。


最简单的多行为融合方法是为不同行为类型设置权重，将加权后的行为 Embedding 求和得到用户表征。但这种静态权重方案无法反映不同商品下各行为类型的差异化价值。


多行为序列建模方法将不同行为类型作为序列的属性信息编码到模型中。例如，在行为 Embedding 中加入行为类型 Embedding，使模型能够区分用户是点击了一个商品还是购买了它。更复杂的方法如 MBSTR（Multi-Behavior Sequential Transformer）为每种行为类型维护独立的序列，并通过跨行为注意力机制进行信息交互。


多任务学习框架是另一种多行为建模的方式。ESMM（Entire Space Multi-Task Model）通过建模"曝光→点击→转化"的漏斗关系，利用点击任务的监督信号辅助转化预测任务的学习。MMoE（Multi-gate Mixture-of-Experts）通过共享专家网络和任务特定的门控机制，实现多个行为预测任务间的知识共享与差异化。


用户画像构建
用户画像是用户行为建模的下游产物，将用户的各类行为信号提炼为结构化的兴趣标签和偏好特征。电商用户画像通常包含静态属性和动态兴趣两个维度。


静态属性包括人口统计信息（年龄、性别、地区）、设备信息（手机品牌、操作系统）和注册信息等，这些信息变化缓慢但对冷启动推荐很有价值。动态兴趣则根据用户近期行为实时更新，包括品类偏好、品牌偏好、价格敏感度、风格偏好等。


实时用户画像的构建需要流式计算架构的支持。常见方案是使用 Kafka + Flink 实现行为事件的实时消费和特征更新，将计算结果写入 Redis 等高速缓存供在线推理使用。画像更新频率通常按特征类型区分：点击/浏览类特征分钟级更新，加购/收藏类特征小时级更新，购买类特征天级更新。

长短期兴趣分离
用户在不同时间尺度上表现出不同的兴趣模式。长期兴趣反映了用户稳定的消费偏好，如品牌忠诚度、品类倾向等；短期兴趣则体现了用户当前的购物意图，如临时性的节日购物需求、特定场景下的即时需求等。


SDM（Sequential Deep Matching）模型最早提出了长短期兴趣分离的思想，使用两个独立的网络分别建模用户的长期偏好和短期意图，并在最终预测时进行融合。MIND（Multi-Interest Network with Dynamic Routing）通过胶囊网络和动态路由机制，将用户行为序列自动聚类为多个兴趣向量，每个向量代表用户的一个兴趣维度。


ComiRec（Controllable Multi-Interest Framework）进一步引入了可控的多兴趣提取机制，通过调节兴趣向量的数量和聚合方式来控制推荐结果的精准度和多样性之间的平衡。


在实际工程中，长短期兴趣的融合策略需要根据具体场景灵活设计。例如，在首页推荐中长期兴趣的权重较高，保证推荐结果的稳定性；在搜索结果页中短期兴趣的权重更高，快速响应用户当前意图的变化。


小结
    

  • 用户行为建模是电商推荐系统的核心环节，目标是从多维度行为数据中提取精准的用户兴趣表征
    • 

  • 行为序列建模经历了马尔可夫链 → RNN → 注意力机制 → Transformer 的技术演进，建模能力不断提升
    • 

  • DIN 和 DIEN 是电商推荐领域最具影响力的序列建模模型，分别解决了动态兴趣提取和兴趣演化建模的问题
    • 

  • 多行为融合建模通过加权融合、多行为序列和多任务学习三种方式整合不同类型的用户行为信号
    • 

  • 用户画像将行为信号提炼为结构化的兴趣标签，需要流式计算架构支撑实时更新
    • 

  • 长短期兴趣分离是提升推荐个性化程度的重要技术方向，需要根据不同推荐场景灵活调整融合策略
    •
