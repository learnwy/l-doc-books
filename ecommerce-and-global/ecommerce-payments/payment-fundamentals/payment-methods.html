电商支付方式全景

核心概念

电商平台需要根据目标市场的消费习惯、监管环境和技术基础设施，选择并整合多种支付方式。全球支付方式可分为卡支付、数字钱包、银行转账、先买后付（BNPL）和替代支付五大类。不同市场的支付偏好差异巨大——中国以支付宝/微信为主导，欧洲偏好银行转账（iDEAL、SEPA），东南亚则依赖电子钱包和便利店现金支付。

卡支付体系
信用卡和借记卡仍是全球跨境电商的基础支付方式。卡支付的技术标准由 EMVCo 制定，线上场景使用卡号 + CVV + 3DS 认证的组合验证方式。


卡号（PAN）通常为 16 位数字，前 6-8 位为 BIN（银行识别码），标识发卡行和卡类型。电商平台不应直接存储完整卡号，而是通过支付网关获取 Token（令牌），后续交易使用 Token 代替真实卡号。网络令牌化（Network Tokenization）由卡组织提供，相比网关令牌化具有更高的授权通过率（提升 2-5%）。


interface CardPaymentRequest {
  paymentMethodToken: string;
  amount: number;
  currency: string;
  capture: boolean;
  statementDescriptor: string;
  threeDSecureAuthentication: {
    version: '2.1' | '2.2';
    eci: string;
    cavv: string;
    dsTransId: string;
  };
  metadata: {
    orderId: string;
    customerId: string;
  };
}

interface NetworkToken {
  tokenNumber: string;
  expirationMonth: string;
  expirationYear: string;
  cryptogram: string;
  tokenRequestorId: string;
  source: 'visa_token_service' | 'mastercard_digital_enablement';
}
3D Secure 2（3DS2）是卡组织推出的在线身份验证协议，通过风险评估实现无摩擦认证。当发卡行判定交易风险较低时，可以在后台完成验证（Frictionless Flow），用户无感知；高风险交易则弹出验证页面要求输入 OTP 或生物识别。3DS2 相比 3DS1 的优势在于支持移动端原生 SDK、提供更丰富的风险数据（超过 100 个字段），以及责任转移（Liability Shift）——通过 3DS 认证的交易，拒付责任由商户转移至发卡行。


数字钱包生态
数字钱包在全球电商支付中占比接近 50%，分为账户余额型（支付宝、PayPal）和设备绑定型（Apple Pay、Google Pay）两种模式。


支付宝/微信支付的核心优势在于庞大的用户基础和丰富的场景覆盖。技术对接上，商户通过支付宝开放平台 API 创建支付订单，支付宝返回支付链接或二维码，用户在支付宝 App 内完成确认。对于 H5/PC 场景，常用的方式是生成收银台页面（cashier）或扫码支付（precreate）。


Apple Pay / Google Pay 基于 NFC 和 EMV 令牌化技术。在线上场景中，商户通过 Payment Request API 或平台 SDK 调起系统级支付面板，用户通过 Face ID/指纹确认，钱包设备向卡组织请求一次性密码（DPAN + Cryptogram），交易全程不暴露真实卡号。

银行转账与开放银行
银行直连转账在欧洲和亚洲部分市场占据重要地位。荷兰的 iDEAL 占线上支付 60% 以上份额，印度的 UPI（统一支付接口）日均交易笔数超过 3 亿。


开放银行（Open Banking）通过标准化 API 让第三方支付服务直接访问用户的银行账户，无需通过卡组织网络。PSD2 在欧盟范围内强制银行开放 API，催生了 Plaid、TrueLayer、Tink 等聚合服务商。Account-to-Account（A2A）支付因其低费率（通常固定费用 0.20−0.20-0.20−0.50 而非百分比）和实时到账特性，正在被大型电商平台采用。


interface OpenBankingPaymentRequest {
  paymentType: 'single_immediate' | 'single_scheduled' | 'standing_order';
  amount: {
    value: string;
    currency: string;
  };
  creditorAccount: {
    iban: string;
    name: string;
  };
  debtorAccount?: {
    iban: string;
    institutionId: string;
  };
  reference: string;
  redirectUrl: string;
}

interface PaymentStatusWebhook {
  paymentId: string;
  status: 'pending' | 'authorised' | 'executed' | 'settled' | 'failed';
  statusUpdateDateTime: string;
  statusReason?: string;
}
实时支付系统的全球版图：巴西的 PIX 自 2020 年推出以来已覆盖 1.5 亿用户，印度的 UPI 和 IMPS 构成全球最大的实时支付网络，英国的 Faster Payments 支持 7x24 实时到账。这些系统的共同特征是由央行或监管机构推动，对终端用户免费或低费率。


先买后付与新兴支付
BNPL（Buy Now, Pay Later）允许消费者在购物时分期付款，通常免息或低息。Klarna、Afterpay、Affirm 是海外主要 BNPL 服务商，国内则有花呗、京东白条等产品。BNPL 的核心价值在于提升转化率（平均提升 20-30%）和客单价（平均提升 30-50%）。


BNPL 的商业模式对商户的费率较高（3-6%），但通过提升转化和客单价实现正向 ROI。从技术对接角度，BNPL 服务商通常提供重定向（Redirect）和小部件（Widget）两种集成方式：

加密货币支付仍处于早期阶段，BitPay 和 Coinbase Commerce 提供商户侧解决方案。稳定币（USDT/USDC）因价格稳定性更适合电商场景。闪电网络（Lightning Network）将比特币的交易确认时间从 10 分钟缩短至秒级。


小结
    

  • 全球电商支付方式以数字钱包为主导（~49%），卡支付在跨境场景仍不可替代
    • 

  • 卡支付应采用网络令牌化 + 3DS2 组合，提升授权率并转移拒付责任
    • 

  • 支付宝/微信支付是中国市场必选，Apple Pay/Google Pay 通过 Payment Request API 实现无缝集成
    • 

  • 开放银行和 A2A 支付以低费率和实时到账优势，正在重塑欧洲和新兴市场的支付格局
    • 

  • BNPL 显著提升转化率和客单价，但商户费率较高（3-6%），需评估 ROI
    • 

  • 支付方式的选择应基于目标市场调研，优先覆盖当地市占率前三的支付方式
