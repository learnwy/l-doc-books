电商指标体系全景

核心概念

电商指标体系是量化业务健康度和增长潜力的数据框架。一套完整的指标体系将电商运营的全貌分解为可衡量、可追踪、可优化的量化维度。从宏观的 GMV（Gross Merchandise Volume）到微观的按钮点击率，指标之间存在层层递进的因果关系。理解这些指标的定义、计算口径和相互关系，是数据驱动运营的基础。

电商指标体系的核心是 GMV 分解树。GMV = 流量 × 转化率 × 客单价，这个公式是所有电商运营优化的起点。每个因子可以继续向下分解，形成多层级的指标树。

GMV 分解与增长因子
GMV 是电商最核心的业务指标，代表平台在一段时间内的总成交金额（含退款前）。GMV 的分解路径揭示了业务增长的杠杆点：要提升 GMV，要么增加流量（拉新），要么提升转化率（优化体验），要么提高客单价（交叉销售），三者之间的投入产出比决定了资源分配策略。


interface GmvBreakdown {
  totalGmv: number;
  orderCount: number;
  aov: number;
  uniqueVisitors: number;
  conversionRate: number;
  newUserGmv: number;
  returningUserGmv: number;
  channelBreakdown: Record<string, { gmv: number; orders: number; visitors: number }>;
  categoryBreakdown: Record<string, { gmv: number; orders: number; aov: number }>;
}

interface GrowthAnalysis {
  currentPeriod: GmvBreakdown;
  previousPeriod: GmvBreakdown;
  growthDrivers: Array<{
    factor: string;
    contribution: number;
    growthRate: number;
  }>;
}

function analyzeGrowthDrivers(current: GmvBreakdown, previous: GmvBreakdown): GrowthAnalysis {
  const gmvGrowth = current.totalGmv - previous.totalGmv;
  const trafficContribution =
    (current.uniqueVisitors - previous.uniqueVisitors) * previous.conversionRate * previous.aov;
  const cvrContribution = (current.conversionRate - previous.conversionRate) * current.uniqueVisitors * previous.aov;
  const aovContribution = (current.aov - previous.aov) * current.uniqueVisitors * current.conversionRate;

  return {
    currentPeriod: current,
    previousPeriod: previous,
    growthDrivers: [
      { factor: '流量增长', contribution: trafficContribution, growthRate: trafficContribution / gmvGrowth },
      { factor: '转化提升', contribution: cvrContribution, growthRate: cvrContribution / gmvGrowth },
      { factor: '客单价提升', contribution: aovContribution, growthRate: aovContribution / gmvGrowth },
    ],
  };
}
Take Rate（抽佣率）是平台型电商的核心盈利指标，等于平台收入除以 GMV。不同品类的 Take Rate 差异很大：标品（电子产品）通常 3-8%，非标品（服装、美妆）可达 15-25%。Take Rate 的提升路径包括广告收入增长、增值服务收费和佣金率调整。


转化率指标族
转化率是衡量电商运营效率的核心指标族，贯穿用户从到达平台到完成购买的全链路。不同口径的转化率反映不同环节的效率：整体转化率 = 下单用户数 / 总访问用户数，搜索转化率 = 搜索后下单用户数 / 搜索用户数。

interface FunnelStep {
  name: string;
  uniqueUsers: number;
  dropOffRate: number;
  avgTimeInStep: number;
}

function calculateFunnel(
  steps: FunnelStep[],
): Array<FunnelStep & { conversionFromPrevious: number; conversionFromFirst: number }> {
  const firstStepUsers = steps[0].uniqueUsers;
  return steps.map((step, index) => {
    const previousUsers = index > 0 ? steps[index - 1].uniqueUsers : step.uniqueUsers;
    return {
      ...step,
      conversionFromPrevious: step.uniqueUsers / previousUsers,
      conversionFromFirst: step.uniqueUsers / firstStepUsers,
    };
  });
}

转化率优化的关键在于识别漏斗中流失最严重的环节。如果浏览到详情的转化率低，可能是搜索结果与用户意图不匹配或商品列表页信息不足；如果加购到结算的转化率低，可能是运费策略不合理或缺乏凑单提示；如果结算到支付的转化率低，可能是支付渠道不全或支付流程过于复杂。


客户价值指标
客单价（AOV，Average Order Value）和客户生命周期价值（LTV）是衡量用户价值的两个关键指标。AOV 反映单次消费能力，LTV 反映用户长期贡献。两者结合分析能帮助判断获客投入的合理性——如果获客成本（CAC）超过 LTV，业务模式不可持续。

interface CustomerValueMetrics {
  userId: string;
  firstOrderDate: Date;
  totalOrders: number;
  totalRevenue: number;
  aov: number;
  purchaseFrequency: number;
  customerLifespanMonths: number;
  predictedLtv: number;
  acquisitionCost: number;
  acquisitionChannel: string;
}

function calculateLtv(
  aov: number,
  purchaseFrequencyPerMonth: number,
  avgLifespanMonths: number,
  grossMarginRate: number,
): number {
  return aov * purchaseFrequencyPerMonth * avgLifespanMonths * grossMarginRate;
}

function evaluateAcquisitionEfficiency(
  cac: number,
  ltv: number,
): { ltvCacRatio: number; paybackMonths: number; verdict: string } {
  const ratio = ltv / cac;
  const monthlyValue = ltv / 24;
  const paybackMonths = cac / monthlyValue;
  const verdict = ratio >= 3 ? '健康' : ratio >= 1.5 ? '需关注' : '亏损风险';
  return { ltvCacRatio: ratio, paybackMonths, verdict };
}
运营效率指标
运营效率指标衡量电商平台各业务环节的执行质量。库存周转率、订单履约率、退货率和客服响应时间等指标反映了供应链和服务体系的健康度。


interface OperationalMetrics {
  inventoryTurnover: number;
  daysOfInventory: number;
  orderFulfillmentRate: number;
  averageDeliveryDays: number;
  returnRate: number;
  cancelRate: number;
  customerSatisfactionScore: number;
  netPromoterScore: number;
  grossMarginRate: number;
  operatingExpenseRate: number;
  returnOnAdSpend: number;
}

function calculateInventoryHealth(
  cogs: number,
  averageInventory: number,
  period: number,
): { turnoverRate: number; daysOfInventory: number; healthStatus: string } {
  const turnoverRate = cogs / averageInventory;
  const daysOfInventory = (averageInventory / cogs) * period;
  const healthStatus =
    daysOfInventory < 30 ? '优秀' : daysOfInventory < 60 ? '良好' : daysOfInventory < 90 ? '一般' : '需优化';
  return { turnoverRate, daysOfInventory, healthStatus };
}

function calculateRoas(adSpend: number, adAttributedRevenue: number): number {
  return adAttributedRevenue / adSpend;
}
大促期间的指标监控需要特殊处理。常规指标的基准值在大促期间会发生剧烈变化（流量可能是平时的 10-50 倍），需要建立大促专用的监控看板和告警阈值。大促的核心指标包括：实时 GMV 与目标进度、系统可用性（99.99% 目标）、支付成功率（不低于 95%）和库存预警（畅销品库存告急提醒）。


小结
    

  • 电商指标体系以 GMV 分解树为核心，从 L0 北极星指标到 L4 实验指标形成完整的分层体系
    • 

  • GMV = 流量 × 转化率 × 客单价，增长因子分析揭示各因子对 GMV 增长的贡献比例
    • 

  • 转化率指标族贯穿用户全链路，漏斗分析定位流失最严重的环节指导优化方向
    • 

  • 客户价值通过 AOV、LTV 和 CAC 三角关系评估，LTV/CAC ≥ 3 是业务健康的基准
    • 

  • 运营效率指标覆盖供应链、服务和财务三个维度，大促期间需要专用监控看板和告警阈值
