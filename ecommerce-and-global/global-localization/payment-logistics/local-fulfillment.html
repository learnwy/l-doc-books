本地化履约

核心概念

本地化履约（Local Fulfillment）是跨境电商从「卖家发货」模式向「本地发货」模式升级的战略转型。本地化履约的核心是在目标市场建立完整的订单处理能力——从库存管理、订单处理、拣选包装到交付用户的全流程在本地完成。这不仅缩短了配送时效，还降低了关税和物流成本，并使商家能够提供与本地电商同等水平的消费者体验。

需求预测与库存前置
库存前置是本地化履约的关键前提——把正确数量的商品提前运到海外仓。预测过少导致缺货和销售损失，预测过多导致资金占压和滞销风险。跨境场景下的需求预测比国内电商更复杂，需要考虑海运周期（30-45 天）、清关时间、季节性差异和汇率波动。


interface DemandForecast {
  readonly sku: string;
  readonly market: string;
  readonly forecastPeriod: number;
  readonly dailyDemand: ReadonlyArray<number>;
  readonly confidenceInterval: {
    readonly lower: ReadonlyArray<number>;
    readonly upper: ReadonlyArray<number>;
  };
  readonly seasonalityFactor: ReadonlyArray<number>;
}

interface ReplenishmentPlan {
  readonly sku: string;
  readonly currentStock: number;
  readonly inTransitStock: number;
  readonly reorderPoint: number;
  readonly orderQuantity: number;
  readonly leadTimeDays: number;
  readonly expectedArrival: string;
}

const computeReorderPoint = (
  avgDailyDemand: number,
  leadTimeDays: number,
  serviceLevelZ: number,
  demandStdDev: number,
): number => {
  const expectedDemandDuringLead = avgDailyDemand * leadTimeDays;
  const safetyStock = serviceLevelZ * demandStdDev * Math.sqrt(leadTimeDays);
  return Math.ceil(expectedDemandDuringLead + safetyStock);
};

const computeEOQ = (annualDemand: number, orderCost: number, holdingCostPerUnit: number): number => {
  return Math.ceil(Math.sqrt((2 * annualDemand * orderCost) / holdingCostPerUnit));
};

const buildReplenishmentPlan = (
  forecast: DemandForecast,
  currentStock: number,
  inTransit: number,
  leadTimeDays: number,
): ReplenishmentPlan => {
  const avgDaily = forecast.dailyDemand.reduce((a, b) => a + b, 0) / forecast.dailyDemand.length;
  const stdDev = Math.sqrt(
    forecast.dailyDemand.reduce((sum, d) => sum + (d - avgDaily) ** 2, 0) / forecast.dailyDemand.length,
  );
  const reorderPoint = computeReorderPoint(avgDaily, leadTimeDays, 1.65, stdDev);
  const eoq = computeEOQ(avgDaily * 365, 500, avgDaily * 0.25);

  return {
    sku: forecast.sku,
    currentStock,
    inTransitStock: inTransit,
    reorderPoint,
    orderQuantity: eoq,
    leadTimeDays,
    expectedArrival: '',
  };
};
ABC-XYZ 分析是库存管理的基础工具：A 类商品（高销量）配合 X 类（需求稳定）使用固定周期补货，C 类商品（低销量）配合 Z 类（需求波动大）使用按需补货或预售模式。


订单路由与履约决策
当商家在多个市场有多个仓库时，订单路由（Order Routing）决定每笔订单从哪个仓库发货。最优路由需要在配送时效、物流成本和库存平衡三个目标之间做权衡。


interface OrderRoutingConfig {
  readonly rules: ReadonlyArray<{
    readonly priority: number;
    readonly condition: string;
    readonly warehouse: string;
    readonly fallback: string;
  }>;
  readonly objectives: {
    readonly weightCost: number;
    readonly weightSpeed: number;
    readonly weightBalance: number;
  };
}

interface RoutingDecision {
  readonly orderId: string;
  readonly selectedWarehouse: string;
  readonly estimatedCost: number;
  readonly estimatedDays: number;
  readonly reason: string;
}

const routeOrder = (
  order: {
    readonly destination: string;
    readonly items: ReadonlyArray<{ readonly sku: string; readonly qty: number }>;
  },
  warehouses: ReadonlyArray<{
    readonly id: string;
    readonly location: string;
    readonly stock: ReadonlyMap<string, number>;
    readonly costToDestination: number;
    readonly daysToDestination: number;
  }>,
  config: OrderRoutingConfig,
): RoutingDecision | null => {
  const eligible = warehouses.filter((wh) => order.items.every((item) => (wh.stock.get(item.sku) ?? 0) >= item.qty));

  if (eligible.length === 0) return null;

  const scored = eligible.map((wh) => {
    const costScore = 1 / (wh.costToDestination + 1);
    const speedScore = 1 / (wh.daysToDestination + 1);
    const total = config.objectives.weightCost * costScore + config.objectives.weightSpeed * speedScore;
    return { warehouse: wh, score: total };
  });

  const best = scored.reduce((a, b) => (a.score > b.score ? a : b));
  return {
    orderId: '',
    selectedWarehouse: best.warehouse.id,
    estimatedCost: best.warehouse.costToDestination,
    estimatedDays: best.warehouse.daysToDestination,
    reason: `最优综合评分: ${best.score.toFixed(2)}`,
  };
};

本地合规与包装
本地化履约还需要满足目标市场的产品合规、包装标准和标签要求。不同市场对产品标签语言、成分标注、安全认证和环保包装的要求差异很大。


interface LocalComplianceConfig {
  readonly market: string;
  readonly labelRequirements: {
    readonly languages: ReadonlyArray<string>;
    readonly mandatoryFields: ReadonlyArray<string>;
    readonly fontSize: number;
    readonly certificationMarks: ReadonlyArray<string>;
  };
  readonly packagingRequirements: {
    readonly ecoPackaging: boolean;
    readonly recyclableRequired: boolean;
    readonly plasticRestrictions: boolean;
    readonly weightLimits: { readonly max: number; readonly unit: string };
  };
  readonly certifications: ReadonlyArray<{
    readonly name: string;
    readonly applicableCategories: ReadonlyArray<string>;
    readonly validityMonths: number;
    readonly cost: number;
  }>;
}

const checkComplianceReadiness = (
  product: {
    readonly category: string;
    readonly labels: ReadonlyArray<string>;
    readonly certifications: ReadonlyArray<string>;
    readonly packaging: { readonly recyclable: boolean; readonly plasticFree: boolean };
  },
  config: LocalComplianceConfig,
): { readonly compliant: boolean; readonly gaps: ReadonlyArray<string> } => {
  const gaps: string[] = [];

  for (const lang of config.labelRequirements.languages) {
    if (!product.labels.includes(lang)) {
      gaps.push(`缺少${lang}标签`);
    }
  }

  const requiredCerts = config.certifications.filter((c) => c.applicableCategories.includes(product.category));
  for (const cert of requiredCerts) {
    if (!product.certifications.includes(cert.name)) {
      gaps.push(`缺少${cert.name}认证`);
    }
  }

  if (config.packagingRequirements.recyclableRequired && !product.packaging.recyclable) {
    gaps.push('包装不满足可回收要求');
  }

  return { compliant: gaps.length === 0, gaps };
};
