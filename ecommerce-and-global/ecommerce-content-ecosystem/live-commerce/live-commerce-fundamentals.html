直播电商基础

核心概念

直播电商是以实时视频流为载体，通过主播的即时讲解、演示和互动来驱动商品销售的新型电商模式。相比传统货架电商的「人找货」逻辑，直播电商实现了「货找人」的主动触达。直播的核心优势在于三个即时性：即时信息传递（商品展示比图文更直观）、即时信任建立（主播的人格背书）和即时决策推动（限时优惠+群体效应）。从 2019 年的达人直播爆发到如今品牌自播的常态化，直播电商已从营销工具演变为基础电商基建。

直播间运营模型
直播间运营的核心是「人-货-场」三要素的协同。人（主播团队）决定了内容的感染力和专业度，货（商品组合）决定了转化的天花板，场（直播场景）决定了用户的停留意愿。

interface LiveStreamMetrics {
  readonly peakViewers: number;
  readonly averageViewers: number;
  readonly totalViewers: number;
  readonly averageWatchDuration: number;
  readonly interactionRate: number;
  readonly clickThroughRate: number;
  readonly conversionRate: number;
  readonly gmv: number;
  readonly averageOrderValue: number;
  readonly returnRate: number;
}

const computeLiveROI = (
  metrics: LiveStreamMetrics,
  costs: {
    readonly anchorFee: number;
    readonly trafficCost: number;
    readonly productCost: number;
    readonly operationCost: number;
  },
): {
  readonly roi: number;
  readonly grossProfit: number;
  readonly profitPerViewer: number;
} => {
  const totalCost = costs.anchorFee + costs.trafficCost + costs.productCost + costs.operationCost;
  const grossProfit = metrics.gmv - totalCost;
  return {
    roi: totalCost > 0 ? metrics.gmv / totalCost : 0,
    grossProfit,
    profitPerViewer: metrics.totalViewers > 0 ? grossProfit / metrics.totalViewers : 0,
  };
};
商品排品是直播运营的核心策略环节。「引流款-利润款-拔高款」的组合策略是业界通行做法：引流款（高性价比爆品）吸引流量和互动，利润款（核心盈利商品）贡献主要利润，拔高款（高客单限量品）提升直播间调性和 GMV。


直播流量获取
直播流量来源分为自然流量和付费流量。自然流量由平台推荐算法分配，核心影响因素是直播间的实时数据表现（在线人数、互动率、转化率、UV 价值）。付费流量通过 Dou+、千川等工具精准投放获取。


interface TrafficStrategy {
  readonly organic: {
    readonly preStreamWarmup: {
      readonly shortVideoCount: number;
      readonly postingTimeBefore: number;
      readonly teaserContent: string;
    };
    readonly inStreamOptimization: {
      readonly interactionTactics: ReadonlyArray<string>;
      readonly retentionHooks: ReadonlyArray<string>;
      readonly algorithmSignals: ReadonlyArray<string>;
    };
  };
  readonly paid: {
    readonly budget: number;
    readonly platform: 'dou-plus' | 'qianchuan' | 'feeds';
    readonly targetingStrategy: {
      readonly audience: 'broad' | 'interest' | 'lookalike' | 'retargeting';
      readonly bidType: 'cpm' | 'cpc' | 'cpa';
      readonly optimizationGoal: 'viewers' | 'interactions' | 'conversions';
    };
  };
}

const computeTrafficCostEfficiency = (
  paidCost: number,
  organicViewers: number,
  paidViewers: number,
  totalGMV: number,
): {
  readonly cpv: number;
  readonly organicRatio: number;
  readonly paidROAS: number;
} => {
  const totalViewers = organicViewers + paidViewers;
  return {
    cpv: paidViewers > 0 ? paidCost / paidViewers : 0,
    organicRatio: totalViewers > 0 ? organicViewers / totalViewers : 0,
    paidROAS: paidCost > 0 ? totalGMV / paidCost : 0,
  };
};

直播数据分析
直播数据分析是运营迭代的基础。每场直播结束后需要系统复盘关键指标，识别流量波动、转化瓶颈和优化方向。


interface LiveAnalyticsReport {
  readonly streamId: string;
  readonly duration: number;
  readonly timelineAnalysis: ReadonlyArray<{
    readonly timestamp: number;
    readonly viewers: number;
    readonly interactions: number;
    readonly orders: number;
    readonly event: string;
  }>;
  readonly productAnalysis: ReadonlyArray<{
    readonly productId: string;
    readonly exposures: number;
    readonly clicks: number;
    readonly orders: number;
    readonly gmv: number;
    readonly conversionRate: number;
  }>;
  readonly audienceAnalysis: {
    readonly newFollowerRate: number;
    readonly genderDistribution: ReadonlyMap<string, number>;
    readonly ageDistribution: ReadonlyMap<string, number>;
    readonly regionDistribution: ReadonlyMap<string, number>;
  };
}

const identifyPeakMoments = (
  timeline: LiveAnalyticsReport['timelineAnalysis'],
  metricName: 'viewers' | 'interactions' | 'orders',
): ReadonlyArray<{ readonly timestamp: number; readonly value: number; readonly event: string }> => {
  if (timeline.length < 3) return [];
  const values = timeline.map((t) => t[metricName]);
  const mean = values.reduce((a, b) => a + b, 0) / values.length;
  const stddev = Math.sqrt(values.reduce((sum, v) => sum + (v - mean) ** 2, 0) / values.length);
  return timeline
    .filter((t) => t[metricName] > mean + stddev)
    .map((t) => ({ timestamp: t.timestamp, value: t[metricName], event: t.event }));
};
关键分析维度包括：流量曲线分析（识别自然流量推荐的波峰和流量衰退原因）、商品转化分析（各 SKU 的点击率和转化率排行）、主播表现分析（不同话术和互动方式的效果对比）和观众画像分析（新老粉丝比例、地域分布等）。
