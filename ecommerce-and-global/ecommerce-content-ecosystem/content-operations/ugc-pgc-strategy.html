UGC/PGC 内容策略

核心概念

UGC（User Generated Content，用户生成内容）和 PGC（Professional Generated Content，专业生成内容）是电商内容生态的两大支柱。UGC 提供规模化的真实用户声音，PGC 提供高质量的专业内容输出。两者的协同构成了电商内容生态的「金字塔」结构：底层是海量 UGC 建立信任基础，中层是 KOC/KOL 内容扩大影响力，顶层是品牌 PGC 塑造形象和传递价值。有效的内容策略需要在 UGC 的规模效应和 PGC 的质量保证之间找到最优平衡。

UGC 激励与治理
UGC 的规模化生产需要系统化的激励机制和质量治理体系。激励机制解决「用户为什么要发内容」的问题，治理体系解决「如何保证内容质量」的问题。


interface UGCIncentiveProgram {
  readonly tiers: ReadonlyArray<{
    readonly level: string;
    readonly requirement: { readonly minPosts: number; readonly minQualityScore: number };
    readonly rewards: {
      readonly cashback: number;
      readonly coupons: number;
      readonly exclusiveAccess: boolean;
      readonly badgeTitle: string;
    };
  }>;
  readonly campaigns: ReadonlyArray<{
    readonly name: string;
    readonly type: 'hashtag-challenge' | 'review-reward' | 'unboxing-event';
    readonly duration: number;
    readonly targetPosts: number;
    readonly budget: number;
    readonly prizePool: ReadonlyArray<{ readonly rank: string; readonly prize: string }>;
  }>;
}

interface ContentQualityGate {
  readonly autoReview: {
    readonly minLength: number;
    readonly requiredElements: ReadonlyArray<'image' | 'text' | 'rating'>;
    readonly sensitiveWordFilter: boolean;
    readonly duplicateDetection: boolean;
    readonly aiQualityScore: number;
  };
  readonly manualReview: {
    readonly triggerThreshold: number;
    readonly reviewerPool: number;
    readonly sla: number;
  };
}

const evaluateUGCQuality = (
  content: {
    readonly text: string;
    readonly imageCount: number;
    readonly hasRating: boolean;
    readonly isVerifiedPurchase: boolean;
  },
  gates: ContentQualityGate,
): { readonly score: number; readonly passAutoReview: boolean; readonly issues: ReadonlyArray<string> } => {
  const issues: string[] = [];
  let score = 50;

  if (content.text.length < gates.autoReview.minLength) {
    issues.push('文字内容过短');
    score -= 20;
  }
  if (content.imageCount > 0) score += 15;
  if (content.hasRating) score += 10;
  if (content.isVerifiedPurchase) score += 25;
  if (content.text.length > 200) score += 10;

  return {
    score: Math.max(0, Math.min(100, score)),
    passAutoReview: issues.length === 0 && score >= gates.autoReview.aiQualityScore,
    issues,
  };
};
UGC 激励的核心原则是「低门槛参与、高质量奖励」：让所有用户都能轻松参与（如一键晒单），同时对高质量内容给予显著回报（如现金奖励、流量扶持）。常见的激励手段包括评价返红包、话题挑战赛、开箱任务和等级体系。


PGC 内容体系
PGC 内容是品牌内容资产的核心，包括品牌故事、产品评测、使用教程、场景大片和专家解读等。PGC 的生产遵循「策划-创作-审核-分发-复盘」的标准化工作流。


interface PGCContentPipeline {
  readonly briefing: {
    readonly objective: string;
    readonly targetAudience: string;
    readonly keyMessages: ReadonlyArray<string>;
    readonly toneOfVoice: string;
    readonly referenceLinks: ReadonlyArray<string>;
  };
  readonly production: {
    readonly format: 'short-video' | 'long-video' | 'graphic' | 'article' | 'live';
    readonly team: ReadonlyArray<{ readonly role: string; readonly assignee: string }>;
    readonly timeline: {
      readonly scriptDueDate: string;
      readonly shootingDate: string;
      readonly editDueDate: string;
      readonly reviewDate: string;
      readonly publishDate: string;
    };
    readonly budget: number;
  };
  readonly distribution: {
    readonly platforms: ReadonlyArray<{
      readonly name: string;
      readonly adaptedFormat: string;
      readonly publishTime: string;
    }>;
    readonly paidPromotion: { readonly enabled: boolean; readonly budget: number };
  };
}

interface ContentPerformance {
  readonly contentId: string;
  readonly type: 'ugc' | 'pgc' | 'kol';
  readonly views: number;
  readonly engagement: number;
  readonly clicks: number;
  readonly conversions: number;
  readonly cost: number;
  readonly roi: number;
}

const computeContentMixROI = (
  performances: ReadonlyArray<ContentPerformance>,
): ReadonlyMap<string, { readonly avgROI: number; readonly totalSpend: number; readonly totalConversions: number }> => {
  const groups = new Map<string, ContentPerformance[]>();
  for (const p of performances) {
    const list = groups.get(p.type) ?? [];
    list.push(p);
    groups.set(p.type, list);
  }

  const result = new Map<string, { avgROI: number; totalSpend: number; totalConversions: number }>();
  for (const [type, items] of groups) {
    const totalSpend = items.reduce((sum, p) => sum + p.cost, 0);
    const totalConversions = items.reduce((sum, p) => sum + p.conversions, 0);
    const avgROI = totalSpend > 0 ? items.reduce((sum, p) => sum + p.roi, 0) / items.length : 0;
    result.set(type, { avgROI, totalSpend, totalConversions });
  }
  return result;
};

内容混合策略
最优的内容策略不是选择 UGC 或 PGC，而是根据用户决策路径的不同阶段配置合适的内容类型。品牌认知阶段以 PGC 和头部 KOL 内容为主，种草决策阶段以中腰部 KOL 和 KOC 为主，购买验证阶段以用户 UGC 为主。


interface ContentMixStrategy {
  readonly funelStage: 'awareness' | 'consideration' | 'purchase' | 'loyalty';
  readonly contentRatio: {
    readonly pgc: number;
    readonly kol: number;
    readonly koc: number;
    readonly ugc: number;
  };
  readonly budgetAllocation: number;
  readonly kpiMetrics: ReadonlyArray<string>;
}

小结
    

  • UGC 和 PGC 构成电商内容生态的金字塔结构，底层是 UGC 的信任基础，顶层是 PGC 的品牌价值
    • 

  • UGC 激励遵循「低门槛参与、高质量奖励」原则，质量治理依赖自动+人工审核
    • 

  • PGC 生产遵循标准化工作流，品牌形象片和产品测评是投入产出比最高的两类内容
    • 

  • 内容混合策略根据用户决策阶段配置不同类型内容：认知阶段重 PGC/KOL，购买阶段重 UGC
    • 

  • AI 生成内容（AIGC）正在改变内容生产格局，降低 PGC 成本并提升 UGC 质量
    • 

  • 内容 ROI 评估需要归因模型支撑，多触点归因比末次点击归因更准确
    •
