内容数据分析

核心概念

内容数据分析是通过系统化的数据采集、指标计算和洞察挖掘来评估内容效果、指导内容策略优化的方法论。电商内容的数据分析不同于传统媒体分析——它需要穿透内容消费层到达商品转化层，建立从「曝光-互动-点击-转化-复购」的全链路归因体系。内容数据分析的核心产出是可执行的优化建议，而非仅仅是数据报表。

内容效率指标体系
内容效率指标衡量单条或一批内容在传播和互动方面的表现。指标体系按照用户行为漏斗设计，每个环节有对应的核心指标和辅助指标。


interface ContentMetrics {
  readonly distribution: {
    readonly impressions: number;
    readonly reach: number;
    readonly frequency: number;
  };
  readonly consumption: {
    readonly views: number;
    readonly avgWatchDuration: number;
    readonly completionRate: number;
    readonly viewThroughRate: number;
  };
  readonly engagement: {
    readonly likes: number;
    readonly comments: number;
    readonly shares: number;
    readonly saves: number;
    readonly engagementRate: number;
  };
  readonly conversion: {
    readonly clicks: number;
    readonly ctr: number;
    readonly addToCarts: number;
    readonly orders: number;
    readonly gmv: number;
  };
}

interface ContentScoreCard {
  readonly contentId: string;
  readonly overallScore: number;
  readonly dimensionScores: ReadonlyMap<string, number>;
  readonly rank: number;
  readonly percentile: number;
}

const computeContentScore = (
  metrics: ContentMetrics,
  benchmarks: {
    readonly avgCompletionRate: number;
    readonly avgEngagementRate: number;
    readonly avgCTR: number;
    readonly avgCVR: number;
  },
): ContentScoreCard => {
  const completionScore = Math.min(100, (metrics.consumption.completionRate / benchmarks.avgCompletionRate) * 50);
  const engagementScore = Math.min(100, (metrics.engagement.engagementRate / benchmarks.avgEngagementRate) * 50);
  const conversionScore = Math.min(100, (metrics.conversion.ctr / benchmarks.avgCTR) * 50);

  const overall = completionScore * 0.3 + engagementScore * 0.3 + conversionScore * 0.4;

  return {
    contentId: '',
    overallScore: overall,
    dimensionScores: new Map([
      ['completion', completionScore],
      ['engagement', engagementScore],
      ['conversion', conversionScore],
    ]),
    rank: 0,
    percentile: 0,
  };
};
互动率的计算公式因平台而异。通用公式为 (点赞 + 评论 + 转发 + 收藏) / 曝光量。但不同行为的权重应该不同——评论和转发的用户参与度远高于点赞，因此加权互动率更准确。

内容归因分析
内容归因是将商品转化（订单、GMV）分配到各个内容触点的过程。用户通常在购买前接触多条内容，归因模型决定了每条内容获得多少「功劳」，直接影响内容投入的决策。


type AttributionModel = 'last-click' | 'first-click' | 'linear' | 'time-decay' | 'data-driven';

interface TouchPoint {
  readonly contentId: string;
  readonly contentType: 'short-video' | 'live' | 'graphic' | 'search';
  readonly timestamp: number;
  readonly action: 'view' | 'click' | 'engage' | 'add-cart';
}

interface AttributionResult {
  readonly orderId: string;
  readonly orderValue: number;
  readonly touchPoints: ReadonlyArray<TouchPoint>;
  readonly attribution: ReadonlyMap<string, number>;
}

const timeDecayAttribution = (
  touchPoints: ReadonlyArray<TouchPoint>,
  orderValue: number,
  halfLifeHours: number,
): ReadonlyMap<string, number> => {
  const orderTimestamp = touchPoints[touchPoints.length - 1].timestamp;
  const decayWeights = touchPoints.map((tp) => {
    const hoursAgo = (orderTimestamp - tp.timestamp) / (1000 * 3600);
    return Math.pow(0.5, hoursAgo / halfLifeHours);
  });

  const totalWeight = decayWeights.reduce((a, b) => a + b, 0);
  const attribution = new Map<string, number>();

  for (let i = 0; i < touchPoints.length; i++) {
    const contentId = touchPoints[i].contentId;
    const credit = (decayWeights[i] / totalWeight) * orderValue;
    attribution.set(contentId, (attribution.get(contentId) ?? 0) + credit);
  }

  return attribution;
};

const compareAttributionModels = (
  touchPoints: ReadonlyArray<TouchPoint>,
  orderValue: number,
): ReadonlyMap<AttributionModel, ReadonlyMap<string, number>> => {
  const results = new Map<AttributionModel, ReadonlyMap<string, number>>();

  const lastClick = new Map<string, number>();
  lastClick.set(touchPoints[touchPoints.length - 1].contentId, orderValue);
  results.set('last-click', lastClick);

  const firstClick = new Map<string, number>();
  firstClick.set(touchPoints[0].contentId, orderValue);
  results.set('first-click', firstClick);

  const linear = new Map<string, number>();
  const equalShare = orderValue / touchPoints.length;
  for (const tp of touchPoints) {
    linear.set(tp.contentId, (linear.get(tp.contentId) ?? 0) + equalShare);
  }
  results.set('linear', linear);

  results.set('time-decay', timeDecayAttribution(touchPoints, orderValue, 24));

  return results;
};

自动化报表与决策支持
内容数据分析的最终产出是自动化的数据报表和决策建议。通过预设规则和异常检测，系统自动识别表现异常的内容、趋势变化和优化机会。


interface AutoReportConfig {
  readonly schedule: 'daily' | 'weekly' | 'monthly';
  readonly sections: ReadonlyArray<{
    readonly title: string;
    readonly type: 'top-content' | 'trend' | 'anomaly' | 'roi-summary';
    readonly topN: number;
    readonly compareWithPeriod: 'previous-week' | 'previous-month' | 'same-period-last-year';
  }>;
  readonly alertRules: ReadonlyArray<{
    readonly metric: string;
    readonly condition: 'drop-below' | 'rise-above' | 'change-rate';
    readonly threshold: number;
    readonly severity: 'info' | 'warning' | 'critical';
  }>;
}

interface DecisionRecommendation {
  readonly category: 'budget' | 'content-type' | 'topic' | 'timing';
  readonly action: string;
  readonly expectedImpact: string;
  readonly confidence: number;
  readonly dataEvidence: string;
}

const generateRecommendations = (
  metrics: ReadonlyArray<ContentMetrics>,
  benchmarks: { readonly avgEngagementRate: number; readonly avgCTR: number },
): ReadonlyArray<DecisionRecommendation> => {
  const recommendations: DecisionRecommendation[] = [];
  const avgEngagement = metrics.reduce((sum, m) => sum + m.engagement.engagementRate, 0) / metrics.length;

  if (avgEngagement < benchmarks.avgEngagementRate * 0.8) {
    recommendations.push({
      category: 'content-type',
      action: '增加互动型内容占比（问答、投票、挑战）',
      expectedImpact: '互动率提升 20-30%',
      confidence: 0.75,
      dataEvidence: `当前互动率 ${(avgEngagement * 100).toFixed(1)}%，低于基准 ${(benchmarks.avgEngagementRate * 100).toFixed(1)}%`,
    });
  }

  return recommendations;
};
小结
    

  • 内容数据分析需要穿透内容消费层到商品转化层，建立全链路归因体系
    • 

  • 内容效率指标按漏斗设计：曝光→消费→互动→转化，加权互动率比简单互动率更准确
    • 

  • 归因模型选择直接影响内容投入决策，时间衰减模型是通用场景的推荐选择
    • 

  • 自动化报表通过预设规则和异常检测将数据分析从人工驱动升级为系统驱动
    • 

  • 千次曝光 GMV 是衡量内容商业价值的核心综合指标
    • 

  • 数据驱动的内容策略优化需要 AB 测试验证，避免基于相关性的错误因果推断
    •
