选品与供应链管理 简介

选品决定电商业务的上限，供应链决定电商业务的下限。本知识库的定位是把"卖什么"和"怎么稳定、低成本地交付"这两件事讲透——从市场需求分析、供应商开发、库存管理一直到供应链战略与数字化，构成贯穿商品全生命周期的供给侧管理体系。

它不教你怎么开店、怎么投广告、怎么做内容（那是运营与营销的事），而是聚焦在商品和供应链本身：选对品类、找对工厂、控住成本、转好库存、设计好供应链架构。

本 hub 与兄弟 hub 的分工边界

电商目录下多个 hub 都会触及"商品""库存""供应链"等词，但切入视角不同。下表帮你判断某个问题该来本 hub 还是去别处：

你的问题 应去的 hub 原因
选什么品、找什么供应商、备多少货、供应链怎么设计 本 hub（选品与供应链管理） 供给侧全链路决策
电商有哪些商业模式、平台、单位经济与价值链 电商基础 入门与底层概念，本 hub 的前置
怎么开店、做 Listing、排促销、管订单与售后 电商运营 需求侧的店铺运营执行
指标体系、用户行为、数据仓库与 BI 电商数据分析 数据基础设施，本 hub 的工具底座
仓储作业、最后一公里、逆向物流的物流专业细节 电商物流 物流专业视角，本 hub 库存章的下游
跨境合规、海外仓、多市场战略、AI 驱动运营 跨境电商 出海与跨境视角，本 hub 的全球化延伸
供应商谈判的通用方法、合同博弈、跨文化沟通 谈判与沟通 谈判理论本身，本 hub 谈判章的方法论源头

简单记：本 hub 管供给侧（选品 → 供应商 → 库存 → 供应链），运营/数据/物流 hub 各管一段下游执行，跨境 hub 是出海版本，谈判 hub 提供方法论。

内容结构

第 1 章选品方法论：从市场需求挖掘、数据工具、趋势预测到品类竞争评估，建立数据驱动的选品决策流程，回答"卖什么"。

第 2 章供应商管理：供应商开发、谈判、质量控制与长期关系维护的全流程，回答"从哪里来、如何控品质"。

第 3 章库存管理：库存规划与需求预测、仓储运营、库存优化，在缺货与积压之间找平衡，回答"怎么存、怎么发"。

第 4 章供应链战略：供应链架构设计、柔性/敏捷供应链、数字化转型，从战略高度构建长期竞争力，回答"如何系统化升级"。

推荐学习路径（分人群）

  • 电商创业者 / 个人卖家（从 0 起步）：先读 电商基础 建立全局认知 → 第 1 章选品 → 第 2 章前两节（供应商开发、谈判）→ 第 3 章第 1 节库存规划。先把"选对品、找对厂、备好货"跑通，第 4 章供应链战略等业务上规模后再读。

  • 已有运营经验、想提升选品精准度的中级卖家：直接从第 1 章第 1、3、4 节（需求分析、趋势、品类评估）切入 → 第 2 章质量控制与供应商关系 → 第 3 章全章（重点 ABC 分类与周转优化）。

  • 供应链 / 采购岗从业者：可跳过第 1 章，重点读第 2 章（供应商评估与 SRM）→ 第 3 章（安全库存、需求预测）→ 第 4 章全章（架构设计、柔性供应链、数字化）。

  • 产品经理 / 创业团队负责人（建认知体系）：按 1 → 2 → 3 → 4 顺序通读，重点关注每章的决策矩阵与战略章节，建立从选品到供应链的完整管理框架。

前置知识

  • 基础电商概念：平台规则、FBA/FBM、客单价与佣金等。不熟悉请先看 电商基础。
  • 基本财务素养：能看懂利润率、ROI、现金流等概念（本库的利润测算与库存资金规划会用到），可参考 电商单位经济模型。
  • 基础数据分析能力：会用电子表格做筛选、加权求和与简单建模即可，无需统计学背景；需求预测的进阶模型在 数据科学·时间序列分析 中另有展开。

实际业务中这四个环节相互关联——选品决定供应商需求、供应商能力影响库存策略、库存表现反馈到供应链架构。建议结合自身业务阶段交叉参考，而非线性割裂地看。
