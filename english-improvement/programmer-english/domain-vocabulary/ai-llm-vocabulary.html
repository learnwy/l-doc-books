AI 与 LLM 领域词汇

与 AI/LLM 协作已成为程序员日常的一部分。这块术语相对年轻，存在大量"中文译法不统一、英文用法又有强惯例"的词。本文按子领域分组列出高频词，每个术语附发音 + 释义 + 例句，并补一份易混辨析。

模型基础术语

讨论模型本身——参数、训练、推理——的词汇。这是所有 LLM 对话的最底层语言。

核心模型词汇

术语 发音 释义 例句
Parameter /pəˈræmɪtər/ 模型权重的数量（如 7B、70B） "Llama 3 comes in 8B and 70B parameter sizes."
Weight /weɪt/ 训练得到的具体数值矩阵 "The model weights are quantized to 4-bit precision."
Training /ˈtreɪnɪŋ/ 从数据学习权重的过程 "Pre-training on web-scale corpora takes months."
Inference /ˈɪnfərəns/ 用训练好的模型生成输出 "Inference latency matters more than training time for production."
Fine-tuning /faɪn ˈtuːnɪŋ/ 在预训练模型上做小规模再训练 "We fine-tuned Mistral on our internal docs."
Pre-training /priː ˈtreɪnɪŋ/ 大规模预训练阶段 "Pre-training compute dwarfs fine-tuning compute."
Distillation /ˌdɪstɪˈleɪʃən/ 用大模型训练小模型 "Haiku is a distilled version of Sonnet."
Quantization /ˌkwɒntɪˈzeɪʃən/ 降低权重精度以省内存 "INT8 quantization halves memory with marginal accuracy loss."

模型规模 / 形态

术语 释义 例句
Base model 仅做了 pre-training 的原始模型 "Base models complete text but don't follow instructions."
Instruct model 经过指令微调的模型 "Use the -instruct variant for chat applications."
Foundation model 大规模预训练通用模型 "Foundation models are the substrate everything builds on."
Open-weights / Open-source 权重 / 权重 + 训练代码开放 "Llama is open-weights, not fully open-source."
Frontier model 当前最强的少数模型 "Only a handful of labs train frontier models."

Tokenization 与上下文

把文本切成模型能读的单位，以及模型一次能看的范围。

核心词汇

术语 发音 释义 例句
Token /ˈtoʊkən/ 模型读写的最小单位（≈ 字符或字符片段） "GPT-4 charges $0.03 per 1K input tokens."
Tokenizer /ˈtoʊkəˌnaɪzər/ 把文本拆成 token 的算法 "Different models use different tokenizers — counts vary."
Context window /ˈkɒntɛkst ˈwɪndoʊ/ 模型一次能处理的 token 上限 "Claude has a 200K-token context window."
Subword /ˈsʌbwɜːrd/ 比一个完整单词小的 token 单位 "Subword tokenization handles unseen words gracefully."
BPE /biː piː iː/ Byte-Pair Encoding，主流 tokenizer 算法 "GPT uses a BPE-based tokenizer."
Attention /əˈtɛnʃən/ 模型关注上下文不同位置的机制 "Attention scales quadratically with sequence length."
Embedding /ɪmˈbɛdɪŋ/ 把 token / 文本编码成向量 "We store document embeddings in a vector database."

易混辨析

Token vs Word

  • Token：模型内部单位，平均1 个英文 token ≈ 0.75 个英文 word；中文每字通常是 1–2 个 token
  • Word：人类语言学单位

Context window vs Memory

  • Context window：单次推理能放进去的 token 数
  • Memory：跨对话的状态保留（context window 之外的机制，比如 RAG 或 summary）

输出控制与采样

让模型决定下一个 token 的所有旋钮。

术语 发音 释义 例句
Completion /kəmˈpliːʃən/ 模型生成的输出文本 "The completion exceeded the max_tokens limit."
Sampling /ˈsæmplɪŋ/ 按概率分布抽取下一个 token "Greedy sampling always picks the top token."
Temperature /ˈtɛmpərətʃər/ 控制输出随机性的参数（0 = 确定，1+ = 随机） "Set temperature to 0 for deterministic outputs."
Top-p (nucleus) /tɒp piː/ 只在累计概率前 p% 的 token 中采样 "Top-p=0.9 cuts off the long tail."
Top-k /tɒp keɪ/ 只在概率最高的 k 个 token 中采样 "Top-k=40 limits diversity."
Deterministic /dɪˌtɜːrmɪˈnɪstɪk/ 给定相同输入输出相同 "LLMs are not fully deterministic even at temperature 0."
Stop sequence /stɒp ˈsiːkwəns/ 一旦生成就停止输出的标记 "Use \\n\\n as a stop sequence to limit output to one paragraph."
Max tokens /mæks ˈtoʊkənz/ 输出 token 上限 "Set max_tokens conservatively to control cost."

Prompt 工程术语

从工程角度看 prompt 自身。

术语 发音 释义 例句
System prompt /ˈsɪstəm prɒmpt/ 指定模型角色 / 全局指令的高优先级 prompt "Put role and constraints in the system prompt."
User prompt /ˈjuːzər prɒmpt/ 单次请求的具体输入 "Keep the user prompt focused on the immediate task."
Few-shot /fjuː ʃɒt/ 在 prompt 里提供 N 个示例 "Three-shot prompting beat zero-shot by 15% in our benchmark."
Zero-shot /ˈzɪroʊ ʃɒt/ 不给示例，仅靠指令 "Modern models handle zero-shot classification well."
Chain-of-thought (CoT) /tʃeɪn əv θɔːt/ 引导模型逐步推理 "Chain-of-thought prompting boosts reasoning accuracy."
Scratchpad /ˈskrætʃˌpæd/ 让模型写出中间推理，再产出最终答案 "Use a scratchpad to debug the model's reasoning."
Prompt template /prɒmpt ˈtɛmpleɪt/ 可参数化的 prompt 骨架 "Our prompt template has 6 variable slots."
Prompt injection /prɒmpt ɪnˈdʒɛkʃən/ 通过输入污染 prompt 的攻击 "User-supplied content needs prompt-injection guardrails."

RAG 与 Agent

把检索 / 工具 / 多轮加进来后的扩展词汇。

术语 发音 释义 例句
RAG /ræɡ/ Retrieval-Augmented Generation，检索增强生成 "Our chatbot uses RAG over the company wiki."
Retrieval /rɪˈtriːvəl/ 从知识库取相关片段 "Retrieval precision matters more than recall in RAG."
Vector database /ˈvɛktər ˈdeɪtəbeɪs/ 存储 embedding 并做相似度查询的库 "Pinecone is a hosted vector database."
Semantic search /sɪˈmæntɪk sɜːrtʃ/ 按语义而非关键词检索 "Semantic search finds 'auto' when you query 'car'."
Re-ranking /riː ˈræŋkɪŋ/ 用更精的模型对初筛结果重排 "Re-ranking with a cross-encoder improved hit rate by 20%."
Tool use /tuːl juːs/ 模型调用外部函数 / API "Claude supports parallel tool use in a single turn."
Function calling /ˈfʌŋkʃən ˈkɔːlɪŋ/ 模型按 schema 输出函数调用 "Function calling lets us bridge LLMs to internal APIs."
Agent loop /ˈeɪdʒənt luːp/ 「想 → 调工具 → 看结果 → 再想」的循环 "Cap the agent loop at 10 iterations to avoid runaway costs."

失败模式与质量术语

讨论 LLM "出错"的语言。

术语 发音 释义 例句
Hallucination /həˌluːsɪˈneɪʃən/ 模型编造不实信息 "Citation hallucinations make legal use cases risky."
Drift /drɪft/ 模型输出质量随时间变化 "Quarterly evals catch silent drift after vendor updates."
Regression /rɪˈɡrɛʃən/ 新版本在某项任务上变差 "Run regression tests against your golden set after each version bump."
Jailbreak /ˈdʒeɪlbreɪk/ 绕过模型安全护栏 "Jailbreak prompts surface in red-team testing."
Bias /ˈbaɪəs/ 训练数据带来的系统性偏差 "Audit your evaluation set for representational bias."
Refusal /rɪˈfjuːzəl/ 模型拒绝回答 "Over-refusal hurts UX on legitimate questions."
Sycophancy /ˈsɪkəfənsi/ 模型过度迎合用户意见 "Train-time tuning sometimes amplifies sycophancy."

评估与基准

衡量 LLM 表现的语言。

术语 发音 释义 例句
Eval / Evaluation /ɪˌvælju'eɪʃən/ 量化模型在特定任务上的表现 "Build evals before changing the prompt."
Benchmark /ˈbɛntʃˌmɑːrk/ 公开的标准化测试集 "MMLU is the most cited general-knowledge benchmark."
Leaderboard /ˈliːdərˌbɔːrd/ 多模型在 benchmark 上的排名 "The leaderboard moves weekly — don't pick by it alone."
Golden set /ˈɡoʊldən sɛt/ 团队自己维护的高质量参考集 "Our golden set has 500 hand-labeled examples."
Ground truth /ɡraʊnd truːθ/ 已知正确的参考答案 "Establish ground truth before measuring accuracy."
LLM-as-judge /ɛl ɛl ɛm æz dʒʌdʒ/ 用 LLM 给 LLM 输出打分 "LLM-as-judge correlates ~85% with human raters in our setup."
Pass@k /pæs æt keɪ/ 生成 k 个候选时至少一个正确的概率 "Pass@1 of 72% means 72% of single-shot outputs work."

成本与延迟术语

生产部署侧的语言。

术语 发音 释义 例句
TTFT /tiː tiː ɛf tiː/ Time To First Token，首 token 延迟 "Streaming lowers perceived latency by shortening TTFT."
Throughput /ˈθruːpʊt/ 单位时间生成的 token 数 "Batched inference improves throughput at the cost of latency."
KV cache /keɪ viː kæʃ/ 缓存注意力中间结果 "KV cache reuse cuts cost on repeated prefixes."
Prompt caching /prɒmpt ˈkæʃɪŋ/ 把固定 prefix 缓存到服务端 "Claude's prompt caching can cut prompt cost by 90%."
Batching /ˈbætʃɪŋ/ 把多个请求并到一次推理 "Async batching helps when latency is not tight."
Cost per million tokens /kɒst pər ˈmɪljən ˈtoʊkənz/ 报价单位（输入 / 输出分开） "Input is 3permilliontokens,outputis3 per million tokens, output is3permilliontokens,outputis15."

易混辨析（跨章）

Fine-tuning vs Prompt engineering vs RAG

  • Fine-tuning：改模型权重（费时、需 GPU）
  • Prompt engineering：改输入文字（即时、无需训练）
  • RAG：保持权重不变，运行时注入外部知识到 context

三者并不互斥；生产系统常 RAG + prompt engineering，少数场景才动 fine-tuning。

Embedding vs Token

  • Token：离散的文本单位
  • Embedding：把 token / 文本编码后的连续向量（维度通常 384–4096）

Hallucination vs Mistake

  • Hallucination 特指"听起来对、内容编造"——LLM 自信地输出错事实
  • Mistake 是泛指任何错误，比如算术算错、逻辑没绕清

Agent vs Workflow

  • Workflow：固定步骤、确定性更高
  • Agent：模型自己决定下一步、可能多轮迭代

Agent 更灵活但更难调试。生产系统常先用 workflow，只在确实需要时升级到 agent。

词汇构造与发音陷阱

现象 例子 备注
不读出的字母 Quantization 里的 't' 弱化为 /tɪ/ 不重读 母语者很轻
中文译名差异 Hallucination → 幻觉 / 错觉 / 胡说 英语场合直接用 hallucination 更稳
同形异义 Token 在 web auth 和 LLM 里含义不同 LLM 语境下默认指 NLP token
缩写歧义 RAG 既是 retrieval-aug. gen. 也指 Random Access Generator 上下文区分
复数形态 Tokens / Embeddings / Prompts 都可数 Inference 不可数（uncountable）

LLM 术语演化很快——3 个月前的"新词"现在可能已过时，反之亦然。日常跟读 Anthropic / OpenAI / DeepMind 官方文档与发布说明能保证术语库与社区同步。
