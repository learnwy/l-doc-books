项目反应理论

核心概念

项目反应理论（Item Response Theory, IRT）是现代教育测量的核心理论框架，它从根本上解决了经典测量理论（CTT）中试题参数依赖样本、能力估计依赖试题的关键局限。IRT 的核心思想是建立项目特征函数（Item Characteristic Curve, ICC）——一个数学模型，描述学生在某道题上的正确率与其潜在能力之间的关系。这个函数一旦建立，试题参数和能力参数就可以在各自的尺度上独立估计——这就是 IRT 最核心的性质：参数不变性（Parameter Invariance）。

单参数到三参数模型
IRT 的经典模型族是 Rasch 模型（1PL）、双参数模型（2PL）和三参数模型（3PL），它们在参数复杂度和模型假设之间进行不同程度的权衡。


Rasch 模型（1PL）是最简洁的 IRT 模型：P(θ) = 1 / (1 + exp(-(θ - b)))。每道题只有一个参数——难度 b，所有试题的区分度假设相同（a = 1），不存在猜测（c = 0）。Rasch 模型的哲学立场独特：它认为好的测试应该符合模型，而非模型应该拟合数据——不符合 Rasch 模型的试题应被删除而非用更复杂的模型来适应。这种立场使得 Rasch 模型具有充分统计量性质——总分是能力的充分统计量，简化了能力估计。


双参数模型（2PL）增加了区分度参数 a：P(θ) = 1 / (1 + exp(-a(θ - b)))。区分度 a 决定了 ICC 的陡峭程度——a 越大，ICC 越陡，意味着该题能更精确地区分接近难度水平的学生。但高区分度的试题只在特定能力范围内提供信息，在远离难度水平的区间几乎没有区分价值。


三参数模型（3PL）进一步引入猜测参数 c：P(θ) = c + (1-c) / (1 + exp(-a(θ - b)))。参数 c 表示能力极低的学生仍然有的正确率（四选一选择题约为 0.25）。3PL 在大规模标准化测试中最常使用，但参数估计需要更大的样本量（通常 > 1000）。

参数估计方法
IRT 参数估计的核心挑战是联合估计问题：试题参数和能力参数需要同时估计，且两者相互依赖。三种主要的估计方法是联合最大似然估计（JML）、边际最大似然估计（MML）和贝叶斯估计（MCMC）。


联合最大似然估计（JML）同时估计所有试题参数和能力参数。其优势是概念简单，但存在根本性缺陷：当试题数量有限时，能力参数的 JML 估计是不一致的（inconsistent）——即使样本量趋于无穷，估计值也不收敛于真值。此外，JML 无法为全部答对或全部答错的学生提供有限的能力估计值。


边际最大似然估计（MML）是目前最主流的方法。它的关键思路是将能力 θ 视为随机变量（通常假设正态分布），通过积分"消去"能力参数，只估计试题参数。试题参数估计完成后，再通过期望后验（EAP）或最大后验（MAP）方法估计每个学生的能力。EM 算法是实现 MML 的标准计算工具：E 步计算能力的后验分布期望，M 步更新试题参数。


贝叶斯估计（MCMC）为参数设定先验分布，通过马尔可夫链蒙特卡洛采样获得后验分布。贝叶斯方法的优势在于：（1）能自然处理小样本问题；（2）提供参数的完整后验分布而非点估计；（3）不依赖大样本渐近理论。代价是计算量大、先验选择需要专业判断、收敛诊断需要额外分析。


信息函数与测量精度
IRT 相对 CTT 的一个关键突破是信息函数（Information Function）——它量化了每道题在每个能力水平上的测量精度，取代了 CTT 中只有一个整体信度系数的局限。


试题信息函数 I_i(θ) 与 ICC 的一阶导数的平方成正比：I_i(θ) = [P'(θ)]² / [P(θ)(1-P(θ))]。对于 2PL 模型，I_i(θ) = a² P(θ) Q(θ)——信息在 θ = b 处达到最大值 a²/4，区分度越高、信息峰值越大，但信息集中在更窄的能力范围内。


测试信息函数 I(θ) 是所有试题信息函数的简单加和——这是 IRT 中局部独立性假设的直接推论。测试信息函数的倒数的平方根就是条件标准误：SE(θ) = 1/√I(θ)——它给出了在特定能力水平处的测量精度。

信息函数的概念直接催生了自适应测试（Computerized Adaptive Testing, CAT）——系统根据学生的实时表现动态选择下一道题，目标是选择在当前能力估计值处信息最大的试题。CAT 可以用传统测试一半的题量达到相同的测量精度，因为每道题都被"精准投放"到学生的能力水平附近。


模型拟合与诊断
IRT 模型的选择和验证需要系统的模型拟合检验。核心检验包括单维性检验（IRT 的基本假设是所有试题测量同一个潜在特质）、局部独立性检验（控制能力后试题间不相关）和模型-数据拟合检验（模型预测值与观测值的一致性）。


单维性通常通过主成分分析（PCA）或平行分析来检验——如果第一个特征值远大于第二个，支持单维性假设。Stout 的 DIMTEST 和 DETECT 提供了更严格的统计检验。局部独立性违反的常见原因包括试题共享同一阅读材料（testlet 效应）或试题间存在提示关系。

当模型拟合不佳时，可能需要：（1）删除不符合模型的试题；（2）升级到更复杂的模型（如从 2PL 到 3PL）；（3）采用多维 IRT（MIRT）处理多维数据；（4）使用 Testlet 模型处理局部依赖。模型选择遵循简约性原则——在拟合充分的前提下选择最简单的模型。


小结
    

  • IRT 通过项目特征函数建立了能力与正确率之间的数学关系，实现了参数不变性
    • 

  • 从 Rasch（1PL）到 3PL，模型在简约性和灵活性之间权衡——Rasch 具有充分统计量性质，3PL 处理猜测效应
    • 

  • MML-EM 算法是参数估计的主流方法，贝叶斯 MCMC 在小样本和复杂模型中有优势
    • 

  • 信息函数是 IRT 的核心工具——它量化每道题在每个能力水平的测量贡献，直接支持自适应测试
    • 

  • 模型拟合检验（单维性、局部独立性、项目拟合）是 IRT 应用的质量保证环节
    • 

  • IRT 是大规模标准化测试（GRE、TOEFL、高考改革）和题库建设的理论基石
    •
