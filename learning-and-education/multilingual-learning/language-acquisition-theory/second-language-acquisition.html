第二语言习得理论

核心概念

第二语言习得（Second Language Acquisition, SLA）是研究人类如何学习母语之外语言的跨学科领域。与母语习得不同，第二语言习得发生在学习者已经拥有完整语言系统的基础上，因此涉及更复杂的认知加工过程。理解 SLA 的核心理论框架，是设计高效语言学习策略的科学基础。

习得与学习的本质区别
Krashen 的监控模型（Monitor Model）提出了 SLA 领域最具影响力也最具争议的理论框架。其中最核心的区分是"习得"（acquisition）与"学习"（learning）的二分法。习得是一种无意识过程，类似儿童获得母语的方式——学习者通过大量的可理解性输入，在不知不觉中内化语言规则。学习则是有意识的过程，学习者通过显性教学了解语法规则，并通过刻意练习加以应用。


Krashen 认为这两个系统是独立运作的，学习的知识无法转化为习得的能力。这一"无接口假说"（No Interface Hypothesis）引发了长期争论。反对者认为，显性知识经过足够的练习可以自动化，最终表现得与隐性知识无异——这就是"强接口假说"（Strong Interface Hypothesis）。


实际上，大多数研究者现在倾向于"弱接口假说"（Weak Interface Hypothesis）：显性学习可以在一定条件下促进习得。当学习者注意到输入中的语言形式，并将其与已有的显性知识关联时，习得过程会被加速。这种"注意"（noticing）机制是 Schmidt 的注意假说（Noticing Hypothesis）的核心观点。


对于成人语言学习者，这意味着纯粹的沉浸式输入和纯粹的语法教学都不是最优策略。将可理解性输入与适度的形式聚焦（focus on form）相结合，才能同时激活习得和学习两个系统，实现最高效的语言发展。


输入假说与可理解性输入
Krashen 五大假说中最具实践价值的是输入假说。其核心公式 i+1 表示：学习者需要接收略高于当前水平的输入材料。i 代表当前的语言能力水平，+1 代表超出当前水平的新语言元素。只有当输入既能被大致理解，又包含少量新信息时，习得才会发生。


这一理论对语言学习材料的选择有直接指导意义。过于简单的材料（i+0）不包含新的语言元素，无法推动进步。过于困难的材料（i+5）超出理解范围，学习者无法建立意义与形式的联系，同样无法习得。只有"刚好够难"的材料才处于最佳习得区间。


情感过滤假说是输入假说的重要补充。即使输入材料处于 i+1 的最佳区间，如果学习者的焦虑水平过高、动机不足或自信心低下，一道"情感过滤器"就会阻碍输入进入语言习得装置。这解释了为什么在紧张的考试环境中，即使接收了大量可理解性输入，学习效果也远不如在放松的自然对话中。


现代研究对输入假说进行了重要修正。Nation 提出的"98% 覆盖率原则"指出，学习者需要认识文本中约 98% 的词汇，才能通过上下文有效猜测剩余 2% 的生词——这为 i+1 提供了可操作的量化标准。此外，Laufer 和 Nation 发现，阅读材料中未知词汇的比例控制在 2-5% 时，词汇附带习得效果最佳。


输出假说与互动促进
Swain 的输出假说（Output Hypothesis）是对 Krashen 输入假说的关键补充。Swain 在研究加拿大法语沉浸式教学项目时发现，尽管学生接收了大量的可理解性输入，他们的产出能力（尤其是语法准确性）仍然明显不足。这一发现揭示了单纯依赖输入的局限性。


输出在语言习得中发挥三个独特功能。第一是注意功能（noticing function）：当学习者尝试用目标语言表达思想时，会意识到自己"想说却说不出"的语言差距，这种意识触发对相关输入的选择性注意。第二是假设检验功能（hypothesis-testing function）：输出是学习者检验自己关于语言规则假设的方式，通过对话伙伴的反应来确认或修正这些假设。第三是元语言功能（metalinguistic function）：在合作性输出任务中，学习者会用语言讨论语言本身，这种元语言反思深化了对语言结构的理解。


Long 的交互假说进一步强调了对话中"意义协商"（negotiation of meaning）的作用。当交流出现理解障碍时，双方会通过请求澄清、确认理解和改述等策略来修复交流。这些协商过程为学习者提供了三种关键资源：被修改过的输入（更容易理解）、关于自身输出错误的负面反馈，以及产出修正性输出的机会。

社会文化理论与中介学习
Vygotsky 的社会文化理论为 SLA 提供了与认知主义截然不同的视角。该理论认为，所有高级认知功能——包括语言——都首先在社会层面（人际间）出现，然后才被内化为个体的认知能力。语言习得不是发生在个体大脑内部的信息加工过程，而是在社会互动中通过"中介"（mediation）实现的。


最近发展区（Zone of Proximal Development, ZPD）是这一理论的核心概念。ZPD 指的是学习者独立完成任务的能力与在更有能力的他者帮助下能够完成任务的能力之间的差距。在这个区间内，通过脚手架支持（scaffolding）——由教师或更熟练的同伴提供的、随学习者能力提升而逐渐撤除的帮助——学习者能够完成超出其当前独立能力的任务，并最终将这些能力内化。


在语言学习场景中，ZPD 的概念有着丰富的实践意涵。一个语言学习者在与母语者对话时，对方可能会放慢语速、使用更简单的词汇、提供改述和提示——这些都是脚手架支持的具体形式。随着学习者能力的提升，这些支持逐渐减少，学习者开始独立运用之前在互动中获得的语言能力。


活动理论（Activity Theory）将社会文化理论进一步发展，强调语言学习发生在由主体、客体、工具、规则、社群和分工构成的复杂活动系统中。这一框架帮助我们理解为什么同样的语言学习活动，在不同的社会文化语境中会产生截然不同的学习效果。


小结
    

  • 第二语言习得是在已有语言系统基础上发生的复杂认知过程，涉及习得与学习两种机制
    • 

  • 输入假说强调 i+1 水平的可理解性输入是习得的必要条件，情感过滤器影响输入的吸收效率
    • 

  • 输出假说揭示了产出在注意、假设检验和元语言反思三个维度的独特促进作用
    • 

  • 交互假说强调意义协商为习得提供修正性反馈和修改后的输入
    • 

  • 社会文化理论从社会互动和中介学习的角度重新定义了语言习得的本质
    • 

  • 现代 SLA 倾向于整合多种理论视角，弱接口假说为显性学习向隐性习得的转化提供了理论依据
    • 

  • 实践启示：最高效的语言学习应该是可理解性输入、强制性输出和社会互动三者的有机结合
    •
