氢能与燃料电池材料（Hydrogen and Fuel Cell Materials）

概述

氢能被视为实现深度脱碳的终极能源载体。氢的热值（142 MJ/kg）远高于汽油（46 MJ/kg），燃烧产物仅为水，是理想的清洁能源。氢能技术链涵盖"制氢—储氢—输氢—用氢"全过程，每个环节都离不开高性能材料的支撑。

在用氢端，质子交换膜燃料电池（PEMFC）将氢的化学能直接转换为电能，效率可达50-60%，且响应速度快、零排放，是氢能汽车和分布式发电的核心技术。固体氧化物燃料电池（SOFC）则在高温下运行，适用于大规模固定式发电。本文从电解水制氢、储氢材料到燃料电池核心组件，系统介绍氢能材料化学的关键问题和最新进展。

电解水制氢

碱性电解水（AWE）

碱性电解水是最成熟的大规模制氢技术：

基本构成：

  • 电解质：25-30% KOH水溶液
  • 隔膜：Zirfon（ZrO₂/PPS复合膜）或石棉替代膜
  • 电极：阴极——Ni或Raney Ni；阳极——Ni-Fe合金或NiCo₂O₄
  • 运行温度：70-90°C
  • 电流密度：200-400 mA/cm²
  • 系统效率：60-70%（基于HHV）

优势：技术成熟、成本低（约$500/kW）、寿命长（>80,000小时） 挑战：响应速度慢（分钟级）、不适应可再生能源波动、碱性腐蚀环境

质子交换膜电解水（PEMWE）

PEMWE使用固态聚合物电解质（Nafion等全氟磺酸膜）：

电极反应：

  • 阳极（OER）：2H₂O → O₂ + 4H⁺ + 4e⁻
  • 阴极（HER）：4H⁺ + 4e⁻ → 2H₂

催化剂：

  • 阳极：IrO₂或IrRuOₓ（酸性OER催化要求贵金属）
  • 阴极：Pt/C（0.5-1.0 mg/cm²）
  • 贵金属用量是成本瓶颈（Ir全球年产量仅~8吨）

性能：

  • 电流密度：1-3 A/cm²（AWE的5-10倍）
  • 响应时间：秒级（适配光伏/风电波动）
  • 产氢纯度：>99.999%
  • 系统效率：55-65%

降低贵金属用量策略：

  • 纳米结构化：IrO₂纳米颗粒负载在高比表面载体上
  • 核壳结构：廉价金属核+Ir原子壳层
  • 非贵金属替代（酸性OER）：高熵氧化物、锰基催化剂（仍处于研究阶段）

固体氧化物电解水（SOEC）

高温电解（700-900°C）利用热能辅助电分解水，理论电能消耗最低：

  • 电解质：YSZ（8mol% Y₂O₃-ZrO₂）
  • 阴极（H₂侧）：Ni-YSZ金属陶瓷
  • 阳极（O₂侧）：LSM或LSCF钙钛矿氧化物
  • 热电联合效率可超过90%（利用工业废热或核能）
  • 可逆运行：同一堆栈可切换为SOFC发电模式
  • 挑战：高温下材料退化（Ni粗化、Cr毒化、界面脱层）

光电化学水分解

直接利用太阳光驱动水分解制氢（人工光合作用）：

  • 光阳极：BiVO₄（EgE_gEg​=2.4 eV）、α-Fe₂O₃（EgE_gEg​=2.1 eV）
  • 光阴极：Cu₂O、p-Si/TiO₂/Pt
  • 串联光电化学电池（PEC-PV Tandem）：效率>10%
  • 粉末光催化全分解水：SrTiO₃:Al量子效率~96%@365nm（但太阳能总转化效率<1%）
  • 挑战：光电极稳定性差（光腐蚀）、规模化困难

金属氢化物储氢

金属/合金与氢反应形成金属氢化物，可逆吸放氢：

M+x2H2⇌MHx+QM + \frac{x}{2}H_2 \rightleftharpoons MH_x + QM+2x​H2​⇌MHx​+Q

经典体系：

  • LaNi₅型（AB₅）：吸氢1.4 wt%，平台压1-2 atm @ 25°C，循环稳定性好。已用于NiMH电池
  • TiFe型（AB）：吸氢1.9 wt%，成本低，但活化困难
  • Mg基（A₂B）：MgH₂理论容量7.6 wt%，但解氢温度高（>300°C）、动力学慢
    • 改性：纳米化（球磨至<10 nm加速动力学）、催化（Nb₂O₅, TiH₂催化放氢）、合金化（Mg₂Ni, 3.6 wt%但温度降至~250°C）

轻质配位氢化物：

  • NaAlH₄：理论5.6 wt%，Ti催化可逆（Bogdanović, 1997）
    • 3NaAlH₄ → Na₃AlH₆ + 2Al + 3H₂（3.7 wt%, 180°C）
    • Na₃AlH₆ → 3NaH + Al + 3/2H₂（1.9 wt%, 220°C）
  • LiBH₄：理论18.5 wt%（最高质量密度之一），但热力学太稳定（>400°C放氢）
  • NH₃BH₃：19.6 wt% 理论，三步放氢但不可逆

化学储氢

利用化学反应储存和释放氢气：

液态有机氢载体（LOHC）：

  • 甲苯/甲基环己烷（MCH）体系：C7H8+3H2⇌C7H14C_7H_8 + 3H_2 \rightleftharpoons C_7H_{14}C7​H8​+3H2​⇌C7​H14​，6.2 wt%
  • 二苄基甲苯（DBT/H18-DBT）：6.2 wt%，液态范围宽（-39~390°C）
  • 优势：常温常压液态存储和运输，可利用现有化学品基础设施
  • 挑战：脱氢需高温（250-320°C）和贵金属催化剂（Pt/Al₂O₃）

氨作为氢载体：

  • NH₃含氢17.6 wt%，液化温度-33°C（或10 atm常温液化）
  • 全球年产量>1.8亿吨，运输基础设施完善
  • 裂解制氢：2NH₃ → N₂ + 3H₂（需Ru催化剂，>450°C）
  • 2026年斯坦福报道的五金属纳米晶体（Ru-Fe-Co-Ni-Cu）在氨分解反应中显著优于单金属Ru催化剂
  • 挑战：残余NH₃对PEMFC催化剂有毒（需纯化至<0.1 ppm）

质子交换膜燃料电池（PEMFC）

工作原理

PEMFC在80°C下将H₂和O₂电化学转化为电能和水：

  • 阳极：H₂ → 2H⁺ + 2e⁻（氢氧化反应HOR）
  • 阴极：O₂ + 4H⁺ + 4e⁻ → 2H₂O（氧还原反应ORR）
  • 总反应：H₂ + ½O₂ → H₂O，E0E^0E0 = 1.23V

膜电极组件（MEA）

MEA是PEMFC的核心，由五层结构组成：

质子交换膜：

  • Nafion®（DuPont/Chemours）：全氟磺酸膜，EW=1100 g/mol
    • 质子电导率：~0.1 S/cm（80°C，100% RH）
    • 化学稳定性优异（C-F键）
    • 微相分离结构：PTFE疏水骨架 + 磺酸基亲水簇（Cluster-Network模型）
    • 挑战：高温失水（>80°C电导率骤降）、含氟材料环境争议
  • 高温膜替代：PBI（聚苯并咪唑）/H₃PO₄体系（160-200°C运行，耐CO）
  • 碳氢膜替代：磺化聚醚砜（SPES）、磺化聚酰亚胺→降低成本

催化层：

  • 标准催化剂：Pt/C（40-60 wt% Pt负载在碳黑上）
  • 阴极Pt载量：0.2-0.4 mg/cm²（阳极0.05 mg/cm²）
  • ORR是速控步骤：过电位~300-400 mV（即使用Pt催化）
  • Pt面积比活性（Specific Activity）：0.2 mA/cm²Pt @ 0.9V

降Pt策略：

  • Pt合金：Pt₃Co、Pt₃Ni降低Pt用量同时提升活性（d带中心优化）
  • 核壳结构：Pd@Pt单原子层，Pt利用率最大化
  • 形貌控制：Pt纳米线、纳米框架→高比表面积+高活性面暴露
  • 非贵金属替代（阴极）：Fe-N-C、Co-N-C单原子催化剂，半波电位已接近Pt/C（差距<30 mV in RDE）
  • 超低Pt载量目标：DOE目标<0.125 mg/cm²（总贵金属），寿命>5000小时

气体扩散层（GDL）：

  • 碳纤维纸/碳布 + 微孔层（MPL，碳黑+PTFE）
  • 功能：气体均匀分配、水管理（排液/保湿平衡）、电子传导
  • 疏水处理：PTFE含量5-30%调控排水能力

双极板

双极板在单电池间传导电流和分配气体：

  • 石墨板：电导率好、耐腐蚀，但脆、厚度大
  • 金属板（不锈钢/钛）：强度高、超薄（<0.1 mm），需表面涂层防腐蚀（CrN、TiN、非晶碳）
  • 复合板：石墨/聚合物复合→兼顾导电和成型
  • 流场设计：蛇形、平行、交指型→影响水热管理效率

耐久性挑战

PEMFC商业化要求寿命：乘用车>5000小时（DOE目标8000小时），商用车>25,000小时

衰减机制：

  • Pt溶解/迁移/Ostwald熟化→电化学活性面积（ECSA）损失
  • 碳载体腐蚀（高电位>0.9V）→催化层坍塌
  • 膜化学降解（·OH/·OOH自由基攻击）→针孔/氟排放
  • 机械疲力（干湿循环应力）→膜裂纹

缓解策略：

  • 石墨化碳载体（耐高电位腐蚀）
  • Pt合金提高稳定性（Co稳定Pt结构）
  • 自由基淬灭剂（CeO₂纳米粒子散布在膜中）
  • 增强膜（ePTFE支撑Nafion→机械强度+薄膜化）

固体氧化物燃料电池（SOFC）

工作原理与材料

SOFC在600-1000°C下运行，使用固体氧化物（陶瓷）电解质传导O²⁻离子：

  • 阴极（O₂侧）：O₂ + 4e⁻ → 2O²⁻
  • 氧离子通过电解质传输到阳极
  • 阳极（燃料侧）：H₂ + O²⁻ → H₂O + 2e⁻

核心材料：

  • 电解质：YSZ（经典）、GDC（Ce₀.₉Gd₀.₁O₁.₉₅，中温SOFC 600-700°C）、LSGM（La₀.₉Sr₀.₁Ga₀.₈Mg₀.₂O₃）
  • 阳极：Ni-YSZ金属陶瓷（电子+离子混合导电，H₂催化氧化）
  • 阴极：LSM（高温）、LSCF（中温，混合导电→活性面积大）
  • 连接体：LaCrO₃基（陶瓷）或铬基合金（金属连接体，中温SOFC）

SOFC优势：

  • 电效率高（50-60%，联合循环>65%）
  • 燃料灵活（H₂、CO、CH₄、合成气均可直接使用）
  • 无需贵金属催化剂
  • 高品质余热可利用

挑战：

  • 高温下材料兼容性（热膨胀匹配）
  • 启动/停机热循环应力→密封失效
  • 阳极积碳（使用碳氢燃料时）
  • 阴极Cr中毒（金属连接体Cr蒸发沉积在阴极）

关键总结

  1. PEM电解水凭借高电流密度和快响应适配可再生能源制氢，但Ir阳极催化剂是成本瓶颈
  2. 储氢材料需在质量密度、体积密度、温度条件和可逆性之间寻求平衡，LOHC和氨路线适合长距离运输
  3. PEMFC的核心材料挑战是降低Pt用量同时保持活性和耐久性，Fe-N-C等非贵金属催化剂接近实用水平
  4. Nafion膜的微相分离结构是质子传导的微观基础，但高温失水限制了运行温度
  5. SOFC利用高温优势实现燃料灵活性和高效率，但材料耐久性和热循环管理是工程关键
