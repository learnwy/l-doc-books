半导体材料化学（Semiconductor Materials Chemistry）

概述

半导体材料是现代信息社会的物质根基。从处理器芯片中的硅单晶，到LED照明中的GaN，再到太阳能电池中的钙钛矿，半导体材料的化学设计和制备工艺直接决定了电子器件的性能极限。半导体材料化学关注的核心问题是：如何通过化学组成、晶体结构和缺陷控制来精确调控材料的电子结构（带隙、载流子浓度和迁移率）。

本文从半导体物理基础出发，系统介绍元素半导体、化合物半导体和新型半导体材料的化学本质、制备方法和应用前沿。

半导体物理基础

能带理论

固体中大量原子的电子轨道重叠形成连续能带：

  • 价带（Valence Band, VB）：被电子填满的最高能带
  • 导带（Conduction Band, CB）：价带之上的空带
  • 禁带（Band Gap, EgE_gEg​）：价带顶到导带底的能量差

根据EgE_gEg​大小分类：

  • 导体：Eg=0E_g = 0Eg​=0（能带重叠或部分填充）
  • 半导体：0<Eg<40 < E_g < 40<Eg​<4 eV
  • 绝缘体：Eg>4E_g > 4Eg​>4 eV

直接带隙 vs 间接带隙：

  • 直接带隙（GaAs, InP, GaN）：价带顶和导带底在k空间同一位置，光学跃迁高效→适合发光器件
  • 间接带隙（Si, Ge）：需要声子辅助跃迁，发光效率低→不适合LED但适合光伏（长载流子寿命）

载流子与掺杂

本征半导体：纯净半导体中电子-空穴对由热激发产生：

ni=NCNVexp⁡(−Eg/2kBT)n_i = \sqrt{N_C N_V} \exp(-E_g / 2k_BT)ni​=NC​NV​​exp(−Eg​/2kB​T)

Si @ 300K：ni=1.5×1010n_i = 1.5 \times 10^{10}ni​=1.5×1010 cm⁻³

n-type掺杂（V族掺入Si）：

  • P, As, Sb提供多余电子→施主能级（EDE_DED​在ECE_CEC​下方~45 meV）
  • 室温下完全电离：n≈NDn \approx N_Dn≈ND​
  • 实例：1 ppm P掺杂Si→n≈5×1016n ≈ 5 \times 10^{16}n≈5×1016 cm⁻³（提高6个数量级）

p-type掺杂（III族掺入Si）：

  • B, Al, Ga接受电子→受主能级（EAE_AEA​在EVE_VEV​上方~45 meV）
  • 产生空穴为多数载流子

载流子迁移率：

  • Si电子迁移率：1450 cm²/V·s @ 300K
  • Si空穴迁移率：500 cm²/V·s
  • GaAs电子迁移率：8500 cm²/V·s（高速器件）
  • InSb电子迁移率：78,000 cm²/V·s（红外探测器）

pn结

p-type和n-type半导体接触形成pn结，是几乎所有半导体器件的基础：

  • 内建电场指向n→p（空间电荷区/耗尽层）
  • 正偏（p接正极）：势垒降低→电流指数增长（二极管导通）
  • 反偏：势垒增高→仅有微小漏电流
  • 光伏效应：光生载流子被内建电场分离→光电流（太阳能电池原理）

硅材料

多晶硅制备

改良西门子法（Siemens Process）：

  1. 冶金级硅（98%纯度）+ HCl → SiHCl₃（三氯氢硅）
  2. 多次精馏提纯SiHCl₃（去除B、P等杂质）
  3. SiHCl₃ + H₂ → Si + 3HCl（CVD沉积在硅棒上，1100°C）
  4. 产品纯度：电子级多晶硅9N-11N（99.9999999-99.999999999%）

流化床法（FBR）：

  • SiH₄在流化床中热分解沉积在小硅粒上
  • 能耗低于西门子法（~20 vs ~60 kWh/kg）
  • 产品为粒状硅（Granular Polysilicon），纯度略低于棒状硅

单晶生长

Czochralski法（直拉法/CZ法）：

  • 将籽晶浸入硅熔体（1414°C）缓慢提拉并旋转
  • 晶体直径通过拉速和温度控制（当前最大300 mm/12英寸晶圆）
  • 氧含量：~10¹⁸ cm⁻³（来自石英坩埚溶解）
  • 适用于：集成电路（>95%市场份额）

Float Zone法（区熔法/FZ法）：

  • 高频感应线圈局部熔化多晶硅棒并使熔区移动
  • 无坩埚→极低氧碳含量
  • 高电阻率（>1000 Ω·cm），适用于功率器件
  • 缺点：晶体直径受限（最大200 mm）

硅片加工

从单晶硅锭到可用晶圆需经过精密加工：

  1. 切割（金刚线切割，线径<50 μm→减少切割损失）
  2. 研磨→减薄到目标厚度
  3. 化学机械抛光（CMP）→表面粗糙度<0.5 nm RMS
  4. 清洗（RCA清洗：SC1去有机物，SC2去金属）
  5. 外延（Epitaxy）：CVD在晶圆表面生长高纯度薄层

III-V族化合物半导体

GaAs材料

GaAs是第二重要的半导体材料：

  • 带隙：1.42 eV（直接带隙）
  • 电子迁移率：8500 cm²/V·s（Si的6倍）
  • 高频器件：HEMT（高电子迁移率晶体管）用于5G射频前端
  • 太阳能电池：单结GaAs效率29.1%（最高效单结电池）
  • 制备：Bridgman法或VGF法生长单晶；MOCVD/MBE生长外延薄膜

GaN材料

GaN（氮化镓）引领了固态照明和功率电子两大革命：

蓝光LED（2014年诺贝尔物理学奖）：

  • 带隙3.4 eV（紫外）→InGaN量子阱调制发蓝光
  • InGaN/GaN MQW（多量子阱）结构
  • LED发光效率>200 lm/W，寿命>50,000小时
  • 挑战："效率骤降"（Efficiency Droop）在高电流密度下

GaN功率器件：

  • 宽带隙→高击穿电场（3.3 MV/cm vs Si的0.3 MV/cm）
  • 低导通电阻+高开关频率
  • GaN-on-Si HEMT：65W GaN充电器体积仅为Si方案的1/3
  • 应用：快充、服务器电源、电动汽车逆变器

InP材料

InP在光通信领域占据核心地位：

  • 带隙：1.35 eV（直接），晶格匹配In₀.₅₃Ga₀.₄₇As（带隙0.74 eV→1.55 μm通信窗口）
  • 应用：激光器（DFB-LD）、光探测器（APD）、调制器
  • 太赫兹电子学：InP HEMT截止频率>1 THz
  • 空间太阳能电池：InGaP/GaAs/InGaAs三结电池效率>39%

MOCVD外延技术

金属有机化学气相沉积（MOCVD/MOVPE）是III-V外延的主流方法：

  • Ga源：三甲基镓Ga(CH₃)₃（TMGa）
  • As源：AsH₃（砷烷）或TBAs
  • N源：NH₃
  • 反应：TMGa + NH₃ → GaN + 3CH₄（简化）
  • 精度：单原子层控制（<0.3 nm/层）
  • 产能：单次可处理多片6英寸或8英寸晶圆

宽带隙半导体

SiC材料

碳化硅功率半导体是电动汽车和新能源领域的核心：

  • 带隙：3.26 eV（4H-SiC）
  • 击穿电场：2.8 MV/cm（Si的10倍）
  • 热导率：370 W/m·K（散热优异）
  • 功率器件优势：开关损耗降低80%，系统效率提升5-10%
  • 电动汽车：Tesla Model 3首次规模采用SiC MOSFET逆变器
  • 晶体生长：物理气相输运法（PVT），6英寸和8英寸衬底已商用
  • 成本挑战：SiC衬底价格仍为Si的10倍以上

Ga₂O₃材料

β-Ga₂O₃是新兴超宽带隙半导体：

  • 带隙：4.9 eV（更高击穿电场）
  • Baliga品质因子（BFOM）为SiC的4倍、Si的3000倍
  • 可用熔体法生长大尺寸单晶（成本潜力低于SiC）
  • 挑战：热导率低（11 W/m·K）、p-type掺杂困难
  • 研发阶段：2025年已有kV级Ga₂O₃ SBD/MOSFET原型器件

金刚石半导体

金刚石是"终极半导体"：

  • 带隙：5.47 eV
  • 热导率：2200 W/m·K（所有材料中最高）
  • 击穿电场：10 MV/cm
  • 理论BFOM为Si的50,000倍
  • 挑战：大面积单晶生长困难、n-type掺杂（P掺杂活化能高）
  • CVD金刚石薄膜已用于散热衬底和窗口材料

新型半导体材料

二维半导体

  • MoS₂：直接带隙1.8 eV（单层），层状范德华材料，可剥离为原子级薄层
  • WSe₂：双极性输运，p-type FET迁移率~100 cm²/V·s
  • 黑磷（BP）：可调带隙0.3-2 eV（层数依赖），高空穴迁移率~1000 cm²/V·s
  • 应用前景：柔性电子、光电探测、后摩尔时代晶体管沟道（亚1 nm厚度极限缩放）
  • 2D材料异质结：不受晶格匹配限制（范德华外延），设计自由度极大

有机半导体

有机半导体基于共轭π体系的分子轨道：

  • 小分子：并五苯（Pentacene）迁移率1-5 cm²/V·s
  • 聚合物：P3HT, PBTTT
  • 优势：溶液加工、柔性、大面积、低成本
  • 应用：OLED显示（已商业化）、有机太阳能电池（PCE>19%）、可穿戴传感器

钙钛矿半导体

卤化物钙钛矿（ABX₃, 如CH₃NH₃PbI₃）在光伏和光电子领域异军突起：

  • 带隙可调：1.2-3.0 eV（通过Pb/Sn混合和I/Br/Cl卤素置换）
  • 优异光电性质：缺陷容忍性好、载流子扩散长度>1 μm、高吸光系数
  • 光伏效率飞速攀升：2009年3.8% → 2025年26.95%（单结）→ 2026年27.87%
  • 钙钛矿/硅叠层电池：34.85%效率（隆基2025年NREL认证）
  • 稳定性挑战：水分/氧气/热/光引起降解，封装和组分工程是关键
  • 铅毒性问题：Sn基替代（效率较低）、Pb回收策略

关键总结

  1. 半导体的核心物理量是带隙EgE_gEg​，通过化学组成精确调控EgE_gEg​是器件设计的基础
  2. 超纯硅的制备（9N-11N纯度）和大尺寸单晶生长是微电子产业的技术壁垒
  3. III-V族化合物（GaAs, GaN, InP）在光电子和高频电子中不可替代
  4. 宽带隙半导体（SiC, GaN, Ga₂O₃）正在革新功率电子，SiC已大规模量产
  5. 新型半导体（2D材料、有机半导体、钙钛矿）代表了"后硅时代"的多元化方向
