弗里德曼方程与宇宙动力学

概述

Friedmann 方程是现代宇宙学的基石方程，由 Alexander Friedmann 于 1922 年从 Einstein 场方程在均匀各向同性宇宙假设下推导得出。这组方程将宇宙的几何膨胀率与其物质-能量内容定量联系起来，是分析宇宙演化历史的基本数学工具。

FLRW 度规

宇宙学原理与度规形式

宇宙学原理假设宇宙在大尺度上（>100 Mpc）是均匀且各向同性的。满足这一对称性的最一般时空度规为 Friedmann-Lemaître-Robertson-Walker (FLRW) 度规：

其中：

  • a(t)a(t)a(t)：尺度因子（scale factor），描述宇宙整体尺度随时间的变化
  • kkk：空间曲率常数，取值 +1+1+1（闭合）、000（平坦）、−1-1−1（开放）
  • (r,θ,ϕ)(r, \theta, \phi)(r,θ,ϕ)：共动坐标（comoving coordinates）

Friedmann 方程推导

从 Einstein 场方程出发

Einstein 场方程的一般形式：

数值方法与现代应用
Friedmann 方程的数值积分
对于包含多组分的真实宇宙，Friedmann 方程通常无解析解，需要数值积分：


H(z)=H0Ωr(1+z)4+Ωm(1+z)3+Ωk(1+z)2+ΩΛH(z) = H_0 \sqrt{\Omega_r(1+z)^4 + \Omega_m(1+z)^3 + \Omega_k(1+z)^2 + \Omega_\Lambda}H(z)=H0​Ωr​(1+z)4+Ωm​(1+z)3+Ωk​(1+z)2+ΩΛ​​
此公式是现代宇宙学观测分析的核心工具，用于：


    

  • 光度距离-红移关系（超新星宇宙学）
    • 

  • 角直径距离（BAO 标准尺）
    • 

  • 共动距离与体积（星系巡天）
    • 



扰动理论的基础
在 Friedmann 背景上叠加小扰动 δρ/ρ≪1\delta\rho/\rho \ll 1δρ/ρ≪1，发展线性宇宙学扰动论。这是理解 CMB 各向异性和大尺度结构形成的数学基础，需要在 Friedmann 动力学提供的背景演化之上求解 Boltzmann 方程组。


总结
Friedmann 方程将宇宙学从哲学思辨提升为精密物理科学。通过仅仅两个方程加一个连续性方程，我们能够：


    

  1. 追溯宇宙从大爆炸到今天的完整热力学与动力学历史
    2. 

  2. 预测未来宇宙的渐近行为（de Sitter 加速膨胀）
    3. 

  3. 为理解 CMB、BBN、结构形成等更精细物理过程提供背景框架
    4. 

  4. 通过观测约束密度参数，确定宇宙的物质组成与几何性质
    5.
