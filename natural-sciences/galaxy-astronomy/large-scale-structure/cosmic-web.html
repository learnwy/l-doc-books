宇宙网

宇宙网（Cosmic Web）是宇宙中物质在最大尺度上的分布模式——暗物质和重子物质组成了一个由纤维丝（Filaments）、节点（Nodes/Clusters）、墙/壁（Walls/Sheets）和巨洞（Voids）构成的复杂网络结构。这种"肥皂泡"状的拓扑结构是引力不稳定性在宇宙膨胀背景下演化的自然结果，其统计性质精确编码了宇宙学参数和暗物质、暗能量的性质。

宇宙网的理论框架
Zel'dovich 近似
宇宙网的形成可通过 Zel'dovich 近似（1970）直观理解：物质元素在三个正交方向上经历不同速率的坍缩：


    

  1. 第一轴坍缩：形成二维"薄饼"（Pancake/Wall）结构
    2. 

  2. 第二轴坍缩：薄饼进一步收缩为一维丝状结构
    3. 

  3. 第三轴坍缩：丝状结构收缩为零维节点（星系团）
    4. 



这一序列——Wall → Filament → Node——正是宇宙网拓扑结构的成因。Zel'dovich 理论虽然仅在线性和弱非线性阶段精确，但其预言的基本拓扑框架与全 N 体模拟结果高度一致。

星系自旋方向与宇宙网的关联是检验角动量获取理论（潮汐力矩理论）的关键观测：


    

  • 低质量星系（M < M_transition ~ 10¹² M☉ 晕）：自旋趋于平行于所在丝状体
    • 

  • 高质量星系（M > M_transition）：自旋趋于垂直于丝状体
    • 



这一"自旋翻转"（Spin Flip）现象可能反映了不同质量星系角动量的获取方式：低质量以顺流吸积为主（平行），高质量以垂直方向的并合为主。
