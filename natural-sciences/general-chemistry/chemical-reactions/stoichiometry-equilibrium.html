化学计量与平衡（Stoichiometry and Chemical Equilibrium）

引言

化学计量学（stoichiometry）是化学反应的"会计学"——它提供了一套严格的定量框架，告诉我们反应物和产物之间的物质的量关系。化学平衡（chemical equilibrium）则回答了一个更深层的问题：可逆反应最终将在什么程度上"停止"？平衡常数是多少？

化学计量和化学平衡共同构成了定量分析化学和工业过程设计的理论基础。无论是计算合成氨的产率、滴定分析的终点、还是地球化学过程中矿物的稳定性，都离不开这两个核心概念。

化学计量学基础

化学方程式与计量系数

配平的化学方程式表达了反应物和产物之间的化学计量关系。例如：

2H2(g)+O2(g)→2H2O(l)2\text{H}_2(g) + \text{O}_2(g) \rightarrow 2\text{H}_2\text{O}(l)2H2​(g)+O2​(g)→2H2​O(l)

计量系数的含义是摩尔比：2 mol H₂ 与 1 mol O₂ 完全反应生成 2 mol H₂O。

摩尔概念

摩尔（mol）是国际单位制中物质的量的基本单位。1 mol 含有 Avogadro 常数个微粒：

NA=6.022×1023 mol−1N_A = 6.022 \times 10^{23} \text{ mol}^{-1}NA​=6.022×1023 mol−1

物质的量 nnn、质量 mmm 与摩尔质量 MMM 的关系：

n=mMn = \frac{m}{M}n=Mm​

计量计算的标准流程

  1. 写出配平的化学方程式
  2. 将已知量转换为摩尔数
  3. 利用计量系数建立摩尔比关系
  4. 将摩尔数转换回所需单位（质量、体积、粒子数等）

限制试剂与过量试剂

当反应物不按化学计量比混合时，首先消耗完的试剂称为限制试剂（limiting reagent），它决定了产物的最大产量。

确定限制试剂的方法：

  • 将每种反应物的摩尔数除以其计量系数
  • 比值最小的即为限制试剂

产率

理论产率：假设反应完全进行，由限制试剂计算得到的最大产物量

实际产率：实验中实际获得的产物量

百分产率：

百分产率=实际产率理论产率×100%\text{百分产率} = \frac{\text{实际产率}}{\text{理论产率}} \times 100\%百分产率=理论产率实际产率​×100%

实际产率低于理论产率的原因包括：反应不完全（可逆反应）、副反应、产物损失等。

反应进度

反应进度（extent of reaction）ξ\xiξ 是描述反应进行程度的热力学量：

dξ=dniνid\xi = \frac{dn_i}{\nu_i}dξ=νi​dni​​

其中 dnidn_idni​ 为组分 iii 物质的量的变化，νi\nu_iνi​ 为其计量系数（产物为正，反应物为负）。ξ\xiξ 的单位为 mol。

化学平衡的概念

可逆反应

大多数化学反应是可逆的——反应物可以生成产物（正反应），产物也可以重新变回反应物（逆反应）。当正反应速率等于逆反应速率时，体系达到动态平衡。

动态平衡的特征：

  • 宏观上各组分浓度不再变化
  • 微观上正逆反应仍在持续进行
  • 不是静止状态，而是动态平衡

平衡常数

对于一般可逆反应：

aA+bB⇌cC+dDaA + bB \rightleftharpoons cC + dDaA+bB⇌cC+dD

浓度平衡常数：

Kc=[C]c[D]d[A]a[B]bK_c = \frac{[\text{C}]^c [\text{D}]^d}{[\text{A}]^a [\text{B}]^b}Kc​=[A]a[B]b[C]c[D]d​

分压平衡常数（气相反应）：

Kp=pCc⋅pDdpAa⋅pBbK_p = \frac{p_C^c \cdot p_D^d}{p_A^a \cdot p_B^b}Kp​=pAa​⋅pBb​pCc​⋅pDd​​

KcK_cKc​ 与 KpK_pKp​ 的关系：

Kp=Kc(RT)ΔnK_p = K_c(RT)^{\Delta n}Kp​=Kc​(RT)Δn

其中 Δn=(c+d)−(a+b)\Delta n = (c+d) - (a+b)Δn=(c+d)−(a+b) 为气态产物与反应物计量系数之差。

平衡常数的热力学本质

平衡常数与标准 Gibbs 自由能变的关系：

ΔG∘=−RTln⁡K\Delta G^\circ = -RT \ln KΔG∘=−RTlnK

这是化学热力学中最重要的方程之一。它告诉我们：

  • K>1K > 1K>1（ΔG∘<0\Delta G^\circ < 0ΔG∘<0）：平衡偏向产物
  • K<1K < 1K<1（ΔG∘>0\Delta G^\circ > 0ΔG∘>0）：平衡偏向反应物
  • K=1K = 1K=1（ΔG∘=0\Delta G^\circ = 0ΔG∘=0）：反应物和产物处于等量状态

平衡常数的特性

  1. KKK 只与温度有关，与初始浓度、压力无关
  2. KKK 的表达式取决于方程式的写法——方程式乘以 nnn，KKK 变为 KnK^nKn
  3. 逆反应的平衡常数等于正反应的倒数：K逆=1/K正K_{\text{逆}} = 1/K_{\text{正}}K逆​=1/K正​
  4. 多步反应总反应的 K=K1×K2×…K = K_1 \times K_2 \times \ldotsK=K1​×K2​×…（Hess 定律的推论）

反应商与平衡的判断

反应商 QQQ 的定义与 KKK 相同，但使用任意时刻的浓度（不一定是平衡浓度）：

Q=[C]c[D]d[A]a[B]b(任意时刻)Q = \frac{[\text{C}]^c [\text{D}]^d}{[\text{A}]^a [\text{B}]^b} \quad (\text{任意时刻})Q=[A]a[B]b[C]c[D]d​(任意时刻)

通过比较 QQQ 与 KKK 判断反应方向：

  • Q<KQ < KQ<K：反应向正方向（产物方向）进行
  • Q>KQ > KQ>K：反应向逆方向（反应物方向）进行
  • Q=KQ = KQ=K：体系已达平衡

Le Chatelier 原理

Henry-Louis Le Chatelier 于 1884 年提出的原理：

当处于平衡状态的体系受到外界扰动时，平衡将向减弱该扰动的方向移动。

浓度变化的影响

  • 增加反应物浓度：Q<KQ < KQ<K → 平衡正移（消耗多余反应物）
  • 增加产物浓度：Q>KQ > KQ>K → 平衡逆移（消耗多余产物）
  • 移去产物：Q<KQ < KQ<K → 平衡正移

压力变化的影响（气相反应）

  • 增大压力（减小体积）：平衡向气态分子数少的方向移动
  • 减小压力（增大体积）：平衡向气态分子数多的方向移动
  • Δn=0\Delta n = 0Δn=0 时：压力变化不影响平衡位置

示例——合成氨反应：

N2(g)+3H2(g)⇌2NH3(g)Δn=2−4=−2\text{N}_2(g) + 3\text{H}_2(g) \rightleftharpoons 2\text{NH}_3(g) \quad \Delta n = 2 - 4 = -2N2​(g)+3H2​(g)⇌2NH3​(g)Δn=2−4=−2

增大压力使平衡正移，有利于 NH₃ 生成。这就是 Haber-Bosch 工艺使用高压（150–300 atm）的原因。

温度变化的影响

温度变化不仅改变平衡位置，还改变 KKK 值本身：

  • 升高温度：KKK 向有利于吸热方向变化
  • 降低温度：KKK 向有利于放热方向变化

定量关系（van't Hoff 方程）：

ln⁡K2K1=−ΔH∘R(1T2−1T1)\ln\frac{K_2}{K_1} = -\frac{\Delta H^\circ}{R}\left(\frac{1}{T_2} - \frac{1}{T_1}\right)lnK1​K2​​=−RΔH∘​(T2​1​−T1​1​)

对于合成氨（放热反应，ΔH∘=−92\Delta H^\circ = -92ΔH∘=−92 kJ/mol）：升温使 KKK 减小，平衡逆移。但实际工业中仍使用 400–500°C 的高温——这是反应速率（动力学）与平衡产率（热力学）之间的妥协。

催化剂的影响

催化剂同等程度地加速正反应和逆反应，不改变 KKK 值，也不改变平衡位置。它只缩短达到平衡所需的时间。

ICE 表计算平衡浓度

ICE（Initial-Change-Equilibrium）表是计算平衡浓度的标准工具：

示例：N2O4(g)⇌2NO2(g)\text{N}_2\text{O}_4(g) \rightleftharpoons 2\text{NO}_2(g)N2​O4​(g)⇌2NO2​(g)，Kc=4.63×10−3K_c = 4.63 \times 10^{-3}Kc​=4.63×10−3（25°C）

初始 [N₂O₄] = 0.0500 M，[NO₂] = 0

N₂O₄ 2NO₂
I (初始) 0.0500 0
C (变化) -x +2x
E (平衡) 0.0500-x 2x

代入平衡常数表达式：

Kc=(2x)20.0500−x=4.63×10−3K_c = \frac{(2x)^2}{0.0500 - x} = 4.63 \times 10^{-3}Kc​=0.0500−x(2x)2​=4.63×10−3

多重平衡

当一个体系中同时存在多个化学平衡时，各平衡相互耦合。处理多重平衡的关键规则：

  1. 如果几个反应相加得到总反应，则 K总=K1×K2×…K_{\text{总}} = K_1 \times K_2 \times \ldotsK总​=K1​×K2​×…
  2. 如果一个反应是另一个的逆反应，K逆=1/KK_{\text{逆}} = 1/KK逆​=1/K
  3. 如果一个方程式乘以系数 nnn，K′=KnK' = K^nK′=Kn

工业应用

Haber-Bosch 合成氨

N2(g)+3H2(g)⇌2NH3(g)ΔH∘=−92 kJ/mol\text{N}_2(g) + 3\text{H}_2(g) \rightleftharpoons 2\text{NH}_3(g) \quad \Delta H^\circ = -92 \text{ kJ/mol}N2​(g)+3H2​(g)⇌2NH3​(g)ΔH∘=−92 kJ/mol

优化条件（热力学 vs 动力学的折中）：

  • 高压（200–300 atm）：有利平衡
  • 中温（400–500°C）：折中（低温有利平衡但反应太慢）
  • 铁基催化剂：加速达到平衡
  • 移除产物：及时冷凝 NH₃ 使平衡持续正移

接触法制硫酸

2SO2(g)+O2(g)⇌2SO3(g)ΔH∘=−198 kJ/mol2\text{SO}_2(g) + \text{O}_2(g) \rightleftharpoons 2\text{SO}_3(g) \quad \Delta H^\circ = -198 \text{ kJ/mol}2SO2​(g)+O2​(g)⇌2SO3​(g)ΔH∘=−198 kJ/mol

工业条件：常压或略高于常压、约 450°C、V₂O₅ 催化剂、多段转化提高转化率。

概念 核心要点
