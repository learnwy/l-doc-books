氧化还原与电化学（Redox and Electrochemistry）

引言

氧化还原反应（redox reaction）是涉及电子转移的化学反应——一种最基本、最普遍的反应类型。从金属腐蚀到光合作用，从电池供电到冶金工业，氧化还原反应无处不在。电化学（electrochemistry）则是研究化学能与电能相互转化的学科，它将氧化还原反应的热力学原理转化为实际可用的技术。

本文从氧化还原反应的基本概念出发，介绍氧化态的判断规则、电子转移方程的配平、原电池与电解池的工作原理、电极电势与 Nernst 方程，以及电化学在能源和材料领域的现代应用。

氧化还原的基本概念

氧化态（氧化数）

氧化态是描述原子在化合物中"表观电荷"的数值，用于追踪电子转移。确定氧化态的规则：

  1. 单质中原子的氧化态为 0
  2. 单原子离子的氧化态等于离子电荷
  3. 化合物中 H 通常为 +1（金属氢化物中为 -1）
  4. 化合物中 O 通常为 -2（过氧化物中为 -1，OF₂ 中为 +2）
  5. 化合物中 F 始终为 -1
  6. 化合物中所有原子氧化态之和等于分子或离子的总电荷

氧化与还原的定义

术语 电子视角 氧化态视角
氧化（oxidation） 失去电子 氧化态升高
还原（reduction） 获得电子 氧化态降低
氧化剂（oxidizing agent） 获得电子的物质 自身被还原
还原剂（reducing agent） 失去电子的物质 自身被氧化

记忆口诀：OIL RIG — Oxidation Is Loss, Reduction Is Gain（氧化是失，还原是得）。

氧化和还原必须同时发生——没有单独的氧化或还原。这就是为什么叫"氧化还原"反应。

示例分析

铁在氧气中燃烧：

4Fe(s)+3O2(g)→2Fe2O3(s)4\text{Fe}(s) + 3\text{O}_2(g) \rightarrow 2\text{Fe}_2\text{O}_3(s)4Fe(s)+3O2​(g)→2Fe2​O3​(s)
  • Fe：氧化态 0 → +3，失去电子，被氧化（Fe 是还原剂）
  • O：氧化态 0 → -2，获得电子，被还原（O₂ 是氧化剂）

氧化还原方程式的配平

半反应法（酸性溶液）

将总反应拆分为氧化半反应和还原半反应，分别配平，再合并。步骤：

  1. 确定氧化态变化，写出骨架半反应
  2. 配平非 H、O 的原子
  3. 用 H₂O 配平 O 原子
  4. 用 H⁺ 配平 H 原子
  5. 用电子 e⁻ 配平电荷
  6. 调整电子数使两半反应中电子数相等
  7. 合并两半反应，消去电子

示例：配平 MnO4−+Fe2+→Mn2++Fe3+\text{MnO}_4^- + \text{Fe}^{2+} \rightarrow \text{Mn}^{2+} + \text{Fe}^{3+}MnO4−​+Fe2+→Mn2++Fe3+（酸性溶液）

还原半反应：MnO4−+8H++5e−→Mn2++4H2O\text{MnO}_4^- + 8\text{H}^+ + 5e^- \rightarrow \text{Mn}^{2+} + 4\text{H}_2\text{O}MnO4−​+8H++5e−→Mn2++4H2​O

氧化半反应：Fe2+→Fe3++e−\text{Fe}^{2+} \rightarrow \text{Fe}^{3+} + e^-Fe2+→Fe3++e−

乘以系数使电子数相等（×5）并合并：

MnO4−+5Fe2++8H+→Mn2++5Fe3++4H2O\text{MnO}_4^- + 5\text{Fe}^{2+} + 8\text{H}^+ \rightarrow \text{Mn}^{2+} + 5\text{Fe}^{3+} + 4\text{H}_2\text{O}MnO4−​+5Fe2++8H+→Mn2++5Fe3++4H2​O

碱性溶液中的配平

先在酸性条件下配平，然后在方程两边加入等量的 OH⁻ 中和所有 H⁺（H⁺ + OH⁻ → H₂O），合并水分子。

原电池（Galvanic Cell）

基本结构

原电池（也称 Galvanic 电池或 Voltaic 电池）是将氧化还原反应的化学能自发转化为电能的装置。

组成要素：

  • 负极（阳极，anode）：发生氧化反应的电极
  • 正极（阴极，cathode）：发生还原反应的电极
  • 外电路：电子从负极流向正极
  • 盐桥或隔膜：维持内电路离子导通，保持电中性

Daniell 电池

经典的 Daniell 电池：

  • 负极：Zn(s)→Zn2+(aq)+2e−\text{Zn}(s) \rightarrow \text{Zn}^{2+}(aq) + 2e^-Zn(s)→Zn2+(aq)+2e−（氧化）
  • 正极：Cu2+(aq)+2e−→Cu(s)\text{Cu}^{2+}(aq) + 2e^- \rightarrow \text{Cu}(s)Cu2+(aq)+2e−→Cu(s)（还原）
  • 总反应：Zn(s)+Cu2+(aq)→Zn2+(aq)+Cu(s)\text{Zn}(s) + \text{Cu}^{2+}(aq) \rightarrow \text{Zn}^{2+}(aq) + \text{Cu}(s)Zn(s)+Cu2+(aq)→Zn2+(aq)+Cu(s)

电池符号表示法：

Zn(s)∣Zn2+(aq)∣∣Cu2+(aq)∣Cu(s)\text{Zn}(s) | \text{Zn}^{2+}(aq) || \text{Cu}^{2+}(aq) | \text{Cu}(s)Zn(s)∣Zn2+(aq)∣∣Cu2+(aq)∣Cu(s)

其中 | 表示相界面，|| 表示盐桥。左侧为负极（氧化），右侧为正极（还原）。

标准电极电势

标准氢电极（SHE）

所有电极电势的参考标准：

2H+(aq,1M)+2e−⇌H2(g,1atm)2\text{H}^+(aq, 1\text{M}) + 2e^- \rightleftharpoons \text{H}_2(g, 1\text{atm})2H+(aq,1M)+2e−⇌H2​(g,1atm)

规定 E∘(H+/H2)=0.000E^\circ(\text{H}^+/\text{H}_2) = 0.000E∘(H+/H2​)=0.000 V。

标准还原电势

标准还原电势 E∘E^\circE∘ 是在标准条件（25°C，所有物种浓度为 1 M 或 1 atm）下，半反应按还原方向写时的电极电势。

常见标准还原电势表（部分）：

半反应 E∘E^\circE∘ (V)
F₂ + 2e⁻ → 2F⁻ +2.87
Au³⁺ + 3e⁻ → Au +1.50
Cl₂ + 2e⁻ → 2Cl⁻ +1.36
O₂ + 4H⁺ + 4e⁻ → 2H₂O +1.23
Ag⁺ + e⁻ → Ag +0.80
Cu²⁺ + 2e⁻ → Cu +0.34
2H⁺ + 2e⁻ → H₂ 0.000
Fe²⁺ + 2e⁻ → Fe -0.44
Zn²⁺ + 2e⁻ → Zn -0.76
Al³⁺ + 3e⁻ → Al -1.66
Li⁺ + e⁻ → Li -3.04

电势的意义

  • E∘E^\circE∘ 越正 → 半反应越倾向于发生还原（该物质是强氧化剂）
  • E∘E^\circE∘ 越负 → 半反应越倾向于发生氧化（该物质是强还原剂）

电池电动势

标准电池电动势：

Ecell∘=Ecathode∘−Eanode∘E^\circ_{\text{cell}} = E^\circ_{\text{cathode}} - E^\circ_{\text{anode}}Ecell∘​=Ecathode∘​−Eanode∘​

对于 Daniell 电池：Ecell∘=0.34−(−0.76)=1.10E^\circ_{\text{cell}} = 0.34 - (-0.76) = 1.10Ecell∘​=0.34−(−0.76)=1.10 V

Ecell∘>0E^\circ_{\text{cell}} > 0Ecell∘​>0 表示反应自发进行（可以输出电能）。

电动势与热力学

电动势与 Gibbs 自由能的关系：

ΔG∘=−nFEcell∘\Delta G^\circ = -nFE^\circ_{\text{cell}}ΔG∘=−nFEcell∘​

其中 nnn 为转移电子数，F=96485F = 96485F=96485 C/mol 为 Faraday 常数。

与平衡常数的关系：

ln⁡K=nFEcell∘RT\ln K = \frac{nFE^\circ_{\text{cell}}}{RT}lnK=RTnFEcell∘​​

在 25°C：log⁡K=nEcell∘0.0592\log K = \frac{nE^\circ_{\text{cell}}}{0.0592}logK=0.0592nEcell∘​​

Nernst 方程

当条件偏离标准状态时，电池电动势用 Nernst 方程计算：

Ecell=Ecell∘−RTnFln⁡QE_{\text{cell}} = E^\circ_{\text{cell}} - \frac{RT}{nF}\ln QEcell​=Ecell∘​−nFRT​lnQ

在 25°C 简化为：

Ecell=Ecell∘−0.0592nlog⁡QE_{\text{cell}} = E^\circ_{\text{cell}} - \frac{0.0592}{n}\log QEcell​=Ecell∘​−n0.0592​logQ

其中 QQQ 为反应商。

当达到平衡时，Ecell=0E_{\text{cell}} = 0Ecell​=0，Q=KQ = KQ=K：

0=Ecell∘−0.0592nlog⁡K0 = E^\circ_{\text{cell}} - \frac{0.0592}{n}\log K0=Ecell∘​−n0.0592​logK

浓度对电势的影响

Nernst 方程表明：

  • 增大反应物浓度 → QQQ 减小 → EEE 增大
  • 增大产物浓度 → QQQ 增大 → EEE 减小

这是浓差电池（concentration cell）工作的原理。

电解（Electrolysis）

原理

电解是原电池的逆过程——用外加电压驱动非自发的氧化还原反应。

  • 阳极（与电源正极相连）：发生氧化
  • 阴极（与电源负极相连）：发生还原
  • 外加电压必须大于分解电压

Faraday 电解定律

Michael Faraday 于 1834 年发现：

第一定律：电解过程中电极上沉积/溶解的物质质量 mmm 与通过的电荷量 QQQ 成正比：

m=M⋅Qn⋅F=M⋅I⋅tn⋅Fm = \frac{M \cdot Q}{n \cdot F} = \frac{M \cdot I \cdot t}{n \cdot F}m=n⋅FM⋅Q​=n⋅FM⋅I⋅t​

其中 MMM 为摩尔质量，III 为电流，ttt 为时间，nnn 为电子转移数。

第二定律：相同电荷量通过不同电解质时，各电极上沉积的物质的量（以等当量计）相同。

电解的应用

应用 过程
电镀 金属离子在阴极还原沉积
电解精炼 粗铜→纯铜（99.99%）
氯碱工业 电解食盐水制 Cl₂、NaOH、H₂
电解水 2H₂O → 2H₂ + O₂（绿氢制备）
Hall-Héroult 法 电解 Al₂O₃ 制铝

腐蚀与防护

金属腐蚀本质上是电化学过程——金属表面形成微小的原电池：

  • 阳极区：金属被氧化（Fe → Fe²⁺ + 2e⁻）
  • 阴极区：O₂ 或 H⁺ 被还原

防腐方法：

  • 阴极保护：连接更活泼金属（牺牲阳极法）或外加电流
  • 涂层/镀层：隔绝氧和水
  • 合金化：不锈钢中 Cr 形成致密氧化膜
