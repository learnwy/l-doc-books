量子原子模型（Quantum Model of the Atom）

引言

量子原子模型是现代化学的基石。与经典物理学中电子沿确定轨道运动的图景不同，量子力学告诉我们：电子的行为只能用概率来描述。这一认识的转变发生在 20 世纪 20 年代，由 de Broglie、Heisenberg、Schrödinger、Born 等物理学家共同完成，彻底改变了人类对原子世界的理解。

本文从原子模型的历史演进出发，系统介绍薛定谔方程的基本形式、量子数的物理含义、原子轨道的形状与能量，以及波函数的概率诠释。这些概念是后续讨论电子构型、化学键理论和分子结构的必要前提。

从经典模型到量子模型的演进

Dalton 原子论（1803）

John Dalton 提出原子是不可分割的实心球体，同种元素的原子质量相同。这一模型解释了质量守恒定律和定比定律，但完全无法解释原子的内部结构。

Thomson 葡萄干布丁模型（1904）

J.J. Thomson 发现电子后提出：原子是一个均匀分布正电荷的球体，电子像葡萄干一样嵌入其中。该模型首次引入了亚原子粒子的概念，但无法解释 α 粒子散射实验的结果。

Rutherford 有核模型（1911）

Ernest Rutherford 通过 α 粒子散射实验发现：原子的正电荷和绝大部分质量集中在一个极小的原子核中（直径约 10−1510^{-15}10−15 m），电子在核外广阔的空间运动。原子核直径仅为原子直径的万分之一左右。然而，按照经典电动力学，绕核运动的电子应该不断辐射能量并坠入原子核——这与原子的稳定性矛盾。

Bohr 模型（1913）

Niels Bohr 将 Planck 的量子概念引入 Rutherford 模型，提出三个假设：

  1. 定态假设：电子只能在特定的圆形轨道上运动，处于这些轨道时不辐射能量
  2. 跃迁假设：电子在不同轨道间跃迁时吸收或释放光子，光子能量 E=hνE = h\nuE=hν
  3. 角动量量子化：电子轨道角动量满足 L=nℏL = n\hbarL=nℏ，其中 n=1,2,3,…n = 1, 2, 3, \ldotsn=1,2,3,…

由此推导出氢原子能级公式：

En=−mee4(4πε0)2⋅2ℏ2n2=−13.6 eVn2E_n = -\frac{m_e e^4}{(4\pi\varepsilon_0)^2 \cdot 2\hbar^2 n^2} = -\frac{13.6 \text{ eV}}{n^2}En​=−(4πε0​)2⋅2ℏ2n2me​e4​=−n213.6 eV​

Bohr 模型成功解释了氢原子光谱的 Balmer 系、Lyman 系等谱线规律，但对多电子原子失效，且无法解释谱线的精细结构。

量子力学的建立

de Broglie 物质波假说（1924）

Louis de Broglie 在其博士论文中提出：如同光具有波粒二象性，实物粒子也具有波动性。粒子的波长（de Broglie 波长）与其动量成反比：

λ=hp=hmv\lambda = \frac{h}{p} = \frac{h}{mv}λ=ph​=mvh​

其中 h=6.626×10−34h = 6.626 \times 10^{-34}h=6.626×10−34 J·s 为 Planck 常数。对于电子，其典型 de Broglie 波长在 10−1010^{-10}10−10 m 量级，与原子尺寸相当——这意味着电子在原子中的行为必须用波动方程来描述。

de Broglie 还用驻波条件 2πr=nλ2\pi r = n\lambda2πr=nλ 解释了 Bohr 模型中角动量量子化的物理起源：只有当电子波在轨道上形成驻波时，轨道才是稳定的。

Heisenberg 不确定性原理（1927）

Werner Heisenberg 提出：不可能同时精确确定粒子的位置和动量。数学表述为：

Δx⋅Δp≥ℏ2\Delta x \cdot \Delta p \geq \frac{\hbar}{2}Δx⋅Δp≥2ℏ​

其中 ℏ=h/(2π)\hbar = h/(2\pi)ℏ=h/(2π)。这不是测量仪器的局限，而是自然界的内禀性质。不确定性原理从根本上否定了电子沿确定轨道运动的经典图景——我们只能谈论电子在某处出现的概率。

Schrödinger 方程（1926）

Erwin Schrödinger 建立了描述微观粒子运动的波动方程。对于定态问题，时间无关的 Schrödinger 方程为：

H^ψ=Eψ\hat{H}\psi = E\psiH^ψ=Eψ

其中 H^\hat{H}H^ 是 Hamilton 算符（包含动能算符和势能算符），ψ\psiψ 是波函数，EEE 是能量本征值。对于氢原子，Hamilton 算符为：

H^=−ℏ22me∇2−e24πε0r\hat{H} = -\frac{\hbar^2}{2m_e}\nabla^2 - \frac{e^2}{4\pi\varepsilon_0 r}H^=−2me​ℏ2​∇2−4πε0​re2​

精确求解氢原子的 Schrödinger 方程，可以得到一组量子数所标记的波函数（原子轨道）及其对应的能量。

量子数与原子轨道

求解氢原子 Schrödinger 方程时，自然产生三个量子数，加上电子自旋量子数共四个：

主量子数 nnn

  • 取值：n=1,2,3,…n = 1, 2, 3, \ldotsn=1,2,3,…
  • 物理含义：决定电子的主要能量和轨道的平均半径
  • 能量关系（氢原子）：En=−13.6/n2E_n = -13.6/n^2En​=−13.6/n2 eV
  • nnn 越大，电子离核越远，能量越高

角量子数 lll

  • 取值：l=0,1,2,…,n−1l = 0, 1, 2, \ldots, n-1l=0,1,2,…,n−1
  • 物理含义：决定轨道的形状和角动量大小 L=l(l+1)ℏL = \sqrt{l(l+1)}\hbarL=l(l+1)​ℏ
  • 对应的轨道名称：l=0l=0l=0 → s，l=1l=1l=1 → p，l=2l=2l=2 → d，l=3l=3l=3 → f
  • 在多电子原子中，lll 也影响能量（相同 nnn 时，lll 越大能量越高）

磁量子数 mlm_lml​

  • 取值：ml=−l,−l+1,…,0,…,l−1,lm_l = -l, -l+1, \ldots, 0, \ldots, l-1, lml​=−l,−l+1,…,0,…,l−1,l（共 2l+12l+12l+1 个值）
  • 物理含义：决定轨道在外磁场中的空间取向
  • 例如 p 轨道（l=1l=1l=1）有三个取向：ml=−1,0,+1m_l = -1, 0, +1ml​=−1,0,+1，分别对应 px,py,pzp_x, p_y, p_zpx​,py​,pz​

自旋量子数 msm_sms​

  • 取值：ms=+12m_s = +\frac{1}{2}ms​=+21​ 或 −12-\frac{1}{2}−21​
  • 物理含义：描述电子的内禀角动量（自旋），与轨道运动无关
  • 1925 年由 Uhlenbeck 和 Goudsmit 提出，Pauli 将其纳入量子力学框架

原子轨道的形状

波函数 ψ(r,θ,ϕ)\psi(r, \theta, \phi)ψ(r,θ,ϕ) 可以分离变量为径向部分 R(r)R(r)R(r) 和角度部分 Y(θ,ϕ)Y(\theta, \phi)Y(θ,ϕ)：

ψn,l,ml(r,θ,ϕ)=Rn,l(r)⋅Ylml(θ,ϕ)\psi_{n,l,m_l}(r, \theta, \phi) = R_{n,l}(r) \cdot Y_l^{m_l}(\theta, \phi)ψn,l,ml​​(r,θ,ϕ)=Rn,l​(r)⋅Ylml​​(θ,ϕ)

s 轨道（l=0l = 0l=0）

球对称分布，只依赖于与核的距离 rrr。1s 轨道在核处概率密度最大；2s 轨道有一个节面（概率为零的球面）；3s 轨道有两个节面。径向节面数 = n−l−1n - l - 1n−l−1。

p 轨道（l=1l = 1l=1）

呈哑铃形，有一个通过原子核的节面。三个 p 轨道（px,py,pzp_x, p_y, p_zpx​,py​,pz​）分别沿三个坐标轴方向分布，彼此正交。

d 轨道（l=2l = 2l=2）

五个 d 轨道具有更复杂的形状。dxy,dxz,dyzd_{xy}, d_{xz}, d_{yz}dxy​,dxz​,dyz​ 呈四叶草形分布在坐标面之间；dx2−y2d_{x^2-y^2}dx2−y2​ 沿坐标轴方向分布；dz2d_{z^2}dz2​ 具有独特的"带环哑铃"形状。

f 轨道（l=3l = 3l=3）

七个 f 轨道形状更为复杂，主要在镧系和锕系元素的化学中起重要作用。

波函数的概率诠释

Max Born 于 1926 年提出：波函数 ψ\psiψ 本身没有直接的物理意义，但 ∣ψ∣2|\psi|^2∣ψ∣2 给出了在该位置找到电子的概率密度。具体而言：

P(r,θ,ϕ) dV=∣ψ(r,θ,ϕ)∣2 dVP(r, \theta, \phi) \, dV = |\psi(r, \theta, \phi)|^2 \, dVP(r,θ,ϕ)dV=∣ψ(r,θ,ϕ)∣2dV

表示在体积元 dVdVdV 中找到电子的概率。

在实际应用中，常用径向分布函数 4πr2∣R(r)∣24\pi r^2 |R(r)|^24πr2∣R(r)∣2 来描述电子在距核 rrr 处球壳内出现的概率。例如，1s 电子的径向分布函数在 r=a0r = a_0r=a0​（Bohr 半径，a0=0.529a_0 = 0.529a0​=0.529 Å）处取得最大值——这正是 Bohr 模型预测的氢原子基态轨道半径。

"电子云"是对 ∣ψ∣2|\psi|^2∣ψ∣2 的形象化描述：密集区域表示电子出现概率大，稀疏区域表示概率小。轨道的"边界面"通常取概率密度的 90% 等值面，用来表示轨道的形状和大小。

量子模型的实验验证

量子原子模型的正确性得到了大量实验验证：

  1. 原子光谱：Schrödinger 方程精确预测了氢原子的全部谱线，包括 Balmer、Lyman、Paschen 等系列
  2. Stern-Gerlach 实验（1922）：银原子束通过非均匀磁场时分裂为两束，直接证实了空间量子化和电子自旋
  3. Davisson-Germer 实验（1927）：电子束在镍晶体上的衍射实验证实了 de Broglie 物质波假说
  4. 光电子能谱：可以直接测量原子各能级电子的结合能，验证能级结构
  5. 扫描隧道显微镜（STM）：可以直接"看到"原子轨道的电子密度分布

现代发展与应用

量子原子模型不仅是理论基础，也有广泛的现代应用：

  • 计算化学：基于 Schrödinger 方程的数值求解（如密度泛函理论 DFT、耦合簇方法 CCSD(T)），可以精确预测分子结构、反应路径和光谱性质
  • 量子计算：2025 年被联合国大会宣布为"国际量子科学技术年"（IYQ 2025），量子计算在化学模拟中展现出经典计算无法比拟的潜力
  • 材料设计：半导体、超导体、催化剂等功能材料的设计高度依赖原子轨道理论

要点总结

| 概念 | 核心内容 | | ---------------- | ----------------------------------------------------------- | ---- | ------------------------------------ | | 波粒二象性 | 电子同时具有粒子和波的性质，λ=h/p\lambda = h/pλ=h/p | | Schrödinger 方程 | H^ψ=Eψ\hat{H}\psi = E\psiH^ψ=Eψ，量子力学的基本方程 | | 四个量子数 | nnn（能量/大小）、lll（形状）、mlm_lml​（取向）、msm_sms​（自旋） | | 概率诠释 | ∣ψ∣2| \psi | ^2∣ψ∣2 是电子出现的概率密度，非确定轨迹 | | 原子轨道 | s（球形）、p（哑铃形）、d（四叶草形）、f（复杂形） | | 节面数 | 总节面 = n−1n-1n−1；角度节面 = lll；径向节面 = n−l−1n-l-1n−l−1 |

量子原子模型用概率取代了确定性，用波函数取代了轨道轨迹，这看似违反直觉，却是目前人类对原子世界最准确、最成功的描述。理解这一模型是深入学习化学的第一步。
