气体定律与分子运动论（Gas Laws and Kinetic Molecular Theory）

引言

气体是物质的三种基本状态之一，也是人类最早进行定量研究的物态。从 Boyle（1662）到 Avogadro（1811），经典气体定律的建立先于原子理论两百多年。这些宏观经验定律背后的微观解释——分子运动论（kinetic molecular theory, KMT）——由 Clausius、Maxwell、Boltzmann 等人在 19 世纪中叶建立，是统计力学的先驱。

本文从气体的宏观行为规律出发，系统介绍理想气体方程、Dalton 分压定律、Graham 扩散定律；然后深入分析分子运动论的基本假设和数学推导；最后讨论真实气体偏离理想行为的原因和 van der Waals 方程的修正。

经典气体定律

Boyle 定律（1662）

在恒温下，一定量气体的体积与压力成反比：

PV=常数(T,n 恒定)PV = \text{常数} \quad (T, n \text{ 恒定})PV=常数(T,n 恒定)

即 P1V1=P2V2P_1V_1 = P_2V_2P1​V1​=P2​V2​。物理图像：压缩气体使分子间距减小，碰撞频率增大，压力升高。

Charles 定律（1787）

在恒压下，一定量气体的体积与绝对温度成正比：

VT=常数(P,n 恒定)\frac{V}{T} = \text{常数} \quad (P, n \text{ 恒定})TV​=常数(P,n 恒定)

即 V1/T1=V2/T2V_1/T_1 = V_2/T_2V1​/T1​=V2​/T2​。Charles 定律暗示了绝对零度（0 K = -273.15°C）的存在——外推到体积为零时的温度。

Gay-Lussac 定律

在恒容下，一定量气体的压力与绝对温度成正比：

PT=常数(V,n 恒定)\frac{P}{T} = \text{常数} \quad (V, n \text{ 恒定})TP​=常数(V,n 恒定)

Avogadro 定律（1811）

在相同温度和压力下，等体积的不同气体含有相同数目的分子：

Vn=常数(T,P 恒定)\frac{V}{n} = \text{常数} \quad (T, P \text{ 恒定})nV​=常数(T,P 恒定)

标准状况（STP：0°C, 1 atm）下，1 mol 任何理想气体的体积为 22.414 L。

理想气体状态方程

将上述定律综合，得到理想气体状态方程：

PV=nRTPV = nRTPV=nRT

其中：

  • PPP = 压力（Pa 或 atm）
  • VVV = 体积（m³ 或 L）
  • nnn = 物质的量（mol）
  • RRR = 通用气体常数 = 8.314 J·mol⁻¹·K⁻¹ = 0.08206 L·atm·mol⁻¹·K⁻¹
  • TTT = 绝对温度（K）

密度与摩尔质量

由理想气体方程可推导出气体密度公式：

ρ=PMRT\rho = \frac{PM}{RT}ρ=RTPM​

以及通过气体密度测定摩尔质量的方法：

M=ρRTPM = \frac{\rho RT}{P}M=PρRT​

气体化学计量

在气相反应中，利用理想气体方程将体积与物质的量互换：

n=PVRTn = \frac{PV}{RT}n=RTPV​

这使得气体反应的计量计算可以直接使用体积比（在同温同压下，体积比 = 物质的量比 = 计量系数比）。

Dalton 分压定律

内容

混合气体的总压力等于各组分分压之和：

Ptotal=P1+P2+P3+…=∑iPiP_{\text{total}} = P_1 + P_2 + P_3 + \ldots = \sum_i P_iPtotal​=P1​+P2​+P3​+…=i∑​Pi​

各组分的分压：

Pi=xi⋅PtotalP_i = x_i \cdot P_{\text{total}}Pi​=xi​⋅Ptotal​

其中 xi=ni/ntotalx_i = n_i / n_{\text{total}}xi​=ni​/ntotal​ 为摩尔分数。

物理解释

在理想气体假设下，不同种类的分子互不干扰（无分子间作用力），各自独立地对器壁施加压力。因此总压是各组分独立贡献的简单加和。

应用：排水集气法

收集气体时如果通过水面，收集到的气体是目标气体和水蒸气的混合物：

Pdry gas=Ptotal−PH2OP_{\text{dry gas}} = P_{\text{total}} - P_{\text{H}_2\text{O}}Pdry gas​=Ptotal​−PH2​O​

其中 PH2OP_{\text{H}_2\text{O}}PH2​O​ 为该温度下水的饱和蒸气压。

Graham 扩散与渗透定律

Thomas Graham 于 1846 年发现：气体的扩散速率与其摩尔质量的平方根成反比：

r1r2=M2M1\frac{r_1}{r_2} = \sqrt{\frac{M_2}{M_1}}r2​r1​​=M1​M2​​​

物理解释：轻分子的平均速率更大（动能相同时，12mv2=const\frac{1}{2}mv^2 = \text{const}21​mv2=const → 质量小则速率大），因此扩散更快。

应用：

  • 同位素分离（气体扩散法富集 ²³⁵UF₆ vs ²³⁸UF₆）
  • 气体泄漏速率的估计

分子运动论（KMT）

基本假设

分子运动论基于以下五个假设（理想气体模型）：

  1. 大量粒子：气体由大量分子组成，做无规则运动
  2. 体积可忽略：分子本身的体积远小于气体占据的总体积（分子间距 >> 分子直径）
  3. 无分子间作用力：分子间除碰撞外无吸引或排斥
  4. 弹性碰撞：分子与分子、分子与器壁的碰撞是完全弹性的（总动能守恒）
  5. 平均动能正比于温度：Ek‾=32kBT\overline{E_k} = \frac{3}{2}k_BTEk​​=23​kB​T

从 KMT 推导理想气体方程

考虑一个体积为 VVV 的立方容器中 NNN 个质量为 mmm 的分子：

  1. 单个分子对一面器壁的平均碰撞力（动量变化率）：F1=mux2LF_1 = \frac{mu_x^2}{L}F1​=Lmux2​​（LLL 为容器边长）

  2. NNN 个分子的总压力：

P=Nmu2‾3VP = \frac{N m \overline{u^2}}{3V}P=3VNmu2​

其中 u2‾\overline{u^2}u2 为分子速率平方的平均值。

  1. 由假设 5，12mu2‾=32kBT\frac{1}{2}m\overline{u^2} = \frac{3}{2}k_BT21​mu2=23​kB​T，代入得：
PV=NkBT=nRTPV = Nk_BT = nRTPV=NkB​T=nRT

这就从微观的分子运动推导出了宏观的理想气体方程。

Maxwell-Boltzmann 速率分布

并非所有分子都以相同速率运动。Maxwell 于 1860 年给出了分子速率的概率分布函数：

f(v)=4π(m2πkBT)3/2v2exp⁡(−mv22kBT)f(v) = 4\pi \left(\frac{m}{2\pi k_B T}\right)^{3/2} v^2 \exp\left(-\frac{mv^2}{2k_BT}\right)f(v)=4π(2πkB​Tm​)3/2v2exp(−2kB​Tmv2​)

三个特征速率：

  • 最概然速率：vp=2kBTm=2RTMv_p = \sqrt{\frac{2k_BT}{m}} = \sqrt{\frac{2RT}{M}}vp​=m2kB​T​​=M2RT​​
  • 平均速率：v‾=8kBTπm=8RTπM\overline{v} = \sqrt{\frac{8k_BT}{\pi m}} = \sqrt{\frac{8RT}{\pi M}}v=πm8kB​T​​=πM8RT​​
  • 均方根速率：vrms=v2‾=3kBTm=3RTMv_{\text{rms}} = \sqrt{\overline{v^2}} = \sqrt{\frac{3k_BT}{m}} = \sqrt{\frac{3RT}{M}}vrms​=v2​=m3kB​T​​=M3RT​​

它们的大小关系：vp<v‾<vrmsv_p < \overline{v} < v_{\text{rms}}vp​<v<vrms​

温度和质量的影响：

  • 温度升高：分布曲线变宽变矮（速率分散更大），峰值右移（分子更快）
  • 质量增大：分布曲线变窄变高，峰值左移（重分子更慢）

真实气体与理想气体的偏差

偏差的原因

理想气体假设在高温低压下近似成立，但在高压和低温下失效：

  1. 分子体积不可忽略（高压时）：真实分子占有一定体积，可用空间小于容器体积
  2. 分子间存在吸引力（低温、适中压力时）：分子间 van der Waals 力使气体压力低于理想值

压缩因子

压缩因子 ZZZ 定义为：

Z=PVmRTZ = \frac{PV_m}{RT}Z=RTPVm​​
  • 理想气体：Z=1Z = 1Z=1
  • Z<1Z < 1Z<1：分子间吸引力占主导（实际体积小于理想值）
  • Z>1Z > 1Z>1：分子体积效应占主导（实际体积大于理想值）

van der Waals 方程

Johannes van der Waals 于 1873 年提出了修正方程：

(P+an2V2)(V−nb)=nRT\left(P + \frac{an^2}{V^2}\right)(V - nb) = nRT(P+V2an2​)(V−nb)=nRT

或对于 1 mol 气体：

(P+aVm2)(Vm−b)=RT\left(P + \frac{a}{V_m^2}\right)(V_m - b) = RT(P+Vm2​a​)(Vm​−b)=RT

其中：

  • aaa：修正分子间吸引力（aaa 越大，分子间吸引越强）
  • bbb：修正分子自身体积（bbb 约为 1 mol 分子体积的 4 倍）

常见气体的 van der Waals 常数：

气体 aaa (L²·atm·mol⁻²) bbb (L·mol⁻¹)
He 0.034 0.0237
H₂ 0.244 0.0266
N₂ 1.39 0.0391
CO₂ 3.59 0.0427
H₂O 5.46 0.0305

aaa 值反映了分子间作用力的强度——极性分子和大分子的 aaa 值较大。

临界点

van der Waals 方程预测了临界现象：在临界温度 TcT_cTc​ 以上，无论加多大压力都无法液化气体。临界参数与 van der Waals 常数的关系：

Tc=8a27Rb,Pc=a27b2,Vm,c=3bT_c = \frac{8a}{27Rb}, \quad P_c = \frac{a}{27b^2}, \quad V_{m,c} = 3bTc​=27Rb8a​,Pc​=27b2a​,Vm,c​=3b

要点总结

定律/概念 数学表达 适用条件
理想气体方程 PV=nRTPV = nRTPV=nRT 高温低压
Boyle 定律 P1V1=P2V2P_1V_1 = P_2V_2P1​V1​=P2​V2​ 恒温恒量
Charles 定律 V1/T1=V2/T2V_1/T_1 = V_2/T_2V1​/T1​=V2​/T2​ 恒压恒量
Dalton 分压 Ptotal=∑PiP_{\text{total}} = \sum P_iPtotal​=∑Pi​ 理想混合
Graham 定律 r1/r2=M2/M1r_1/r_2 = \sqrt{M_2/M_1}r1​/r2​=M2​/M1​​ 理想气体
KMT 核心 Ek‾=32kBT\overline{E_k} = \frac{3}{2}k_BTEk​​=23​kB​T 理想气体
van der Waals (P+a/Vm2)(Vm−b)=RT(P + a/V_m^2)(V_m - b) = RT(P+a/Vm2​)(Vm​−b)=RT 真实气体修正

气体定律是化学计量学和化学工程计算的基础工具。分子运动论则将宏观的温度、压力概念与微观的分子速率、碰撞频率联系起来，是理解物质热力学行为的微观基础。真实气体的偏差提醒我们：模型总有适用边界，超出边界时需要更精确的理论。
