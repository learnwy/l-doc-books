Part IV · 化学有机化学合成策略保护基策略（Protecting Group Strategy）

保护基策略（Protecting Group Strategy）

引言

在多步有机合成中，一个分子往往含有多个官能团——当你想选择性地对其中一个官能团进行反应时，其他官能团可能会"不请自来"地参与反应，导致非预期的副产物。保护基（Protecting Group，PG）正是为解决这一问题而发展的化学工具：它是一个临时引入的基团，能够暂时屏蔽某个官能团的反应性，在目标反应完成后再将其移除，恢复原始官能团。

保护基策略的三步操作框架：

FG (活性)→保护FG—PG (惰性)→目标反应FG—PG (惰性)→脱保护FG (活性)\text{FG (活性)} \xrightarrow{\text{保护}} \text{FG—PG (惰性)} \xrightarrow{\text{目标反应}} \text{FG—PG (惰性)} \xrightarrow{\text{脱保护}} \text{FG (活性)}FG (活性)保护​FG—PG (惰性)目标反应​FG—PG (惰性)脱保护​FG (活性)

一个理想的保护基应满足：(1) 引入条件温和、收率高；(2) 在后续反应条件下稳定；(3) 脱除条件温和、选择性好；(4) 不引入新的手性中心。在实践中，往往需要在这些要求之间权衡取舍。

醇的保护基

醇（—OH）是有机合成中最需要保护的官能团之一。原因：醇具有亲核性（可参与 SN2）、酸性（可被碱脱质子）和氧化敏感性（可被氧化为醛/酮）。常见保护基如下：

硅醚保护基

硅醚保护是最广泛使用的醇保护策略。原理：用三烃基硅基取代 O—H 中的 H，形成 Si—O 键（键能约 530 kJ/mol，非常稳定）。

保护基 缩写 引入试剂 脱除条件 稳定性
三甲基硅基 TMS TMSCl, Et₃N 稀酸或 F⁻ (TBAF) 低（酸、碱均不稳定）
叔丁基二甲基硅基 TBS (TBDMS) TBSCl, 咪唑 TBAF 或 HF·Py 中高（耐碱、弱酸）
三异丙基硅基 TIPS TIPSCl, 咪唑 TBAF 高（大位阻）
叔丁基二苯基硅基 TBDPS TBDPSCl, 咪唑 TBAF 或 HF 最高（极大位阻）

选择性保护：利用空间位阻差异，可以选择性保护一级醇而不影响二级醇。例如 TBDPSCl 因极大的位阻优先与位阻较小的伯醇反应。

脱除原理：氟离子（F⁻）对硅有极强的亲和力（Si—F 键能约 565 kJ/mol），TBAF（四丁基氟化铵）是最通用的硅醚脱保护试剂。

苄基保护基（Bn, PMB）

苄基醚保护：

R—OH+BnBr→NaHR—O—CH2Ph\text{R—OH} + \text{BnBr} \xrightarrow{\text{NaH}} \text{R—O—CH}_2\text{Ph}R—OH+BnBrNaH​R—O—CH2​Ph

脱除方法：

  • 催化加氢（H₂/Pd-C）：还原裂解 C—O 键，生成甲苯 + 醇。条件极温和。
  • DDQ 氧化（仅对 PMB — 对甲氧基苄基）：选择性脱除 PMB 而保留 Bn。

苄基保护基的优势在于对酸、碱、氧化、还原条件（除加氢外）都稳定——因此可以与其他类型保护基"正交"使用。

缩醛/缩酮保护

将 1,2-二醇或 1,3-二醇与醛/酮缩合形成环状缩醛/缩酮，同时保护两个羟基：

HOCH2CH2OH+(CH3)2CO→TsOH环状缩酮+H2O\text{HOCH}_2\text{CH}_2\text{OH} + \text{(CH}_3\text{)}_2\text{CO} \xrightarrow{\text{TsOH}} \text{环状缩酮} + \text{H}_2\text{O}HOCH2​CH2​OH+(CH3​)2​COTsOH​环状缩酮+H2​O

脱除：稀酸水解。缩醛在碱性和中性条件下完全稳定——适合在碱性反应（如 Grignard、Wittig）中保护 1,2-二醇。

胺的保护基

Boc 保护基（叔丁氧羰基）

RNH2+Boc2O→Et3NR—NHBoc\text{RNH}_2 + \text{Boc}_2\text{O} \xrightarrow{\text{Et}_3\text{N}} \text{R—NHBoc}RNH2​+Boc2​OEt3​N​R—NHBoc

脱除：酸性条件（TFA 或 HCl/二恶烷）。Boc 在碱性条件下完全稳定。

Cbz 保护基（苄氧羰基）

RNH2+CbzCl→NaOHR—NHCbz\text{RNH}_2 + \text{CbzCl} \xrightarrow{\text{NaOH}} \text{R—NHCbz}RNH2​+CbzClNaOH​R—NHCbz

脱除：催化加氢（H₂/Pd-C）。Cbz 在酸碱条件下都稳定。

Fmoc 保护基（9-芴甲氧羰基）

RNH2+FmocCl→NaHCO3R—NHFmoc\text{RNH}_2 + \text{FmocCl} \xrightarrow{\text{NaHCO}_3} \text{R—NHFmoc}RNH2​+FmocClNaHCO3​​R—NHFmoc

脱除：碱性条件（哌啶/DMF，20%）。Fmoc 在酸性条件下稳定。

正交保护策略

Boc（酸脱除）、Cbz（加氢脱除）、Fmoc（碱脱除）三种胺保护基具有正交性——每种的脱除条件不影响其他两种。这在含多个氨基的分子合成中极为重要（如肽合成中每个氨基酸的 α-NH₂ 需要独立控制）。

羰基的保护基

环状缩醛保护

醛和酮可以与 1,2-二醇（乙二醇）或 1,3-二醇在酸催化下形成环状缩醛/缩酮：

R2C=O+HOCH2CH2OH→TsOH, Dean-StarkR2C(OCH2CH2O)\text{R}_2\text{C=O} + \text{HOCH}_2\text{CH}_2\text{OH} \xrightarrow{\text{TsOH, Dean-Stark}} \text{R}_2\text{C(OCH}_2\text{CH}_2\text{O)}R2​C=O+HOCH2​CH2​OHTsOH, Dean-Stark​R2​C(OCH2​CH2​O)

缩醛/缩酮特性：

  • 在碱性、中性和弱酸性条件下完全稳定
  • 耐受 LiAlH₄ 还原、Grignard 试剂、碱性条件
  • 脱除：稀酸水解（如含水 THF + p-TsOH）

这使得在进行还原或 Grignard 反应时，可以选择性保护分子中不需要参与反应的羰基。

硫缩醛保护

与 1,2-乙二硫醇形成硫缩醛，具有一个额外优势：硫缩醛可用 Raney Ni 脱硫，将原来的羰基碳直接还原为亚甲基（—CH₂—）——这相当于"保护 + 还原"一步到位。

羧酸的保护基

甲酯/乙酯

最简单的羧酸保护：

RCOOH+CH3OH→H+RCOOCH3\text{RCOOH} + \text{CH}_3\text{OH} \xrightarrow{\text{H}^+} \text{RCOOCH}_3RCOOH+CH3​OHH+​RCOOCH3​

脱除：碱性水解（LiOH/THF-H₂O）。

叔丁酯

RCOOH+异丁烯→H+RCOOtBu\text{RCOOH} + \text{异丁烯} \xrightarrow{\text{H}^+} \text{RCOOtBu}RCOOH+异丁烯H+​RCOOtBu

脱除：TFA（与 Boc 保护相同条件脱除——需注意兼容性）。

优势：叔丁酯对碱性条件、亲核试剂（RMgBr 等）稳定性极好。

保护基选择的策略原则

正交保护策略

当分子含有多个需要独立操作的相同类型官能团时，使用正交保护基：每种保护基只对特定条件敏感，其他条件下稳定。

经典正交对：

  • 酸/碱正交：Boc（酸脱）+ Fmoc（碱脱）
  • 加氢/非加氢正交：Cbz（加氢脱）+ Boc（酸脱）
  • 氟/非氟正交：TBS（F⁻ 脱）+ Bn（H₂/Pd 脱）

选择性脱保护

在含多种保护基的分子中，选择性脱除其中一个而保留其他——这要求化学家对每种保护基的稳定性条件了然于胸。

稳定性层级（硅醚，酸性条件下从易到难脱除）：

TMS<TES<TBS<TIPS<TBDPS\text{TMS} < \text{TES} < \text{TBS} < \text{TIPS} < \text{TBDPS}TMS<TES<TBS<TIPS<TBDPS

这意味着可以用温和酸性条件选择性脱除 TMS 而保留 TBS——利用稳定性差异实现选择性。

最少保护基原则

保护-脱保护操作虽然提供了选择性，但也增加了合成步骤数（每个保护基至少额外 2 步：引入 + 脱除），降低总收率。因此合成策略设计应追求：

  1. 优先选择本身就具有选择性的反应（化学选择性），避免使用保护基
  2. 利用反应条件的温和性避免保护（如 NaBH₄ 只还原醛/酮不影响酯）
  3. 若必须保护，选择引入和脱除条件最温和、收率最高的保护基
  4. 策略性安排反应顺序减少保护次数

保护基在肽合成中的应用

固相肽合成（SPPS）

1963 年 Robert Bruce Merrifield 发明的固相肽合成（1984 年诺贝尔化学奖）是保护基策略最成功的应用案例。在 SPPS 中：

  • 氨基酸的 α-NH₂ 用 Fmoc 保护（每步偶联后用碱脱除，暴露 NH₂ 接下次偶联）
  • 侧链官能团用正交保护基保护（最后一步酸性条件全部脱除）
  • C-端固定在聚合物树脂上（最后用 TFA 切割释放肽链）

这一策略使得由 20+ 氨基酸组成的肽的合成变得常规化和自动化。

实例：三肽 Ala-Phe-Gly 的合成

逆合成：断开两个肽键 → 三个氨基酸保护策略：

  1. C 端 Gly 固定在树脂上
  2. Fmoc-Phe-OH 活化后偶联 → 脱 Fmoc
  3. Fmoc-Ala-OH 活化后偶联 → 脱 Fmoc
  4. TFA 切割树脂 → 得游离三肽

每步偶联收率 > 99%（活化酯法），总收率 > 97%。

本章小结

保护基策略是有机合成中"以退为进"的智慧——暂时增加步骤以换取精确的化学选择性。

核心要点：

  1. 醇保护：硅醚（TBS, TIPS, TBDPS）最通用，苄基醚适合需要加氢脱除的场景
  2. 胺保护：Boc/Cbz/Fmoc 三种互为正交
  3. 羰基保护：环状缩醛/缩酮，碱稳定/酸脱除
  4. 正交策略：多保护基共存时确保各自独立脱除
  5. 最少保护基原则：能不保护就不保护——保护基 = 额外步骤 = 收率损失
  6. 肽合成：Fmoc-SPPS 是保护基策略的工业化典范

理解保护基不仅是记忆试剂和条件，更重要的是培养"选择性思维"——面对复杂分子时，能够判断哪些官能团需要保护、选择什么保护基、以什么顺序操作。这种战略思维是全合成化学家的核心能力。
