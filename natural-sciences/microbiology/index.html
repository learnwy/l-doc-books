微生物学 简介

微生物学是研究肉眼不可见的微小生物体的科学，涵盖细菌、古菌、病毒、真菌和原生生物等多种类群。这些看似微小的生命形式实际上驱动着地球上最基本的生物地球化学循环，深刻影响着人类健康、农业生产和工业制造。从列文虎克首次用显微镜观察到微生物，到巴斯德和科赫奠定现代微生物学基础，再到分子生物学时代基因组测序与宏基因组学带来的认知飞跃，每一次技术突破都极大地拓展了我们对微生物世界的理解。

本 hub 与兄弟 hub 的分工

微生物学是 41_biology-life-science 合集中以「微小生物体本身」为主角的 hub。它与若干相邻 hub 既互补又有明确边界：

主题 本 hub 负责 交给兄弟 hub
中心法则 / 基因调控的分子细节 仅在微生物语境下引用 分子生物学
遗传学定律 / 测序技术 / CRISPR 工具 微生物基因组与 HGT 遗传学与基因组学
演化机制 / 系统发生理论 微生物进化的特殊性（网状树） 演化生物学
真核细胞器 / 膜与信号通用机制 原核细胞结构 细胞生物学
宿主免疫系统的完整解剖 宿主-微生物界面的微生物侧 免疫学
工程范式 / 标准零件 / DBTL 全流程 微生物作为底盘的应用案例 合成生物学
序列比对 / 建树算法的实现 用其结论谈微生物多样性 生物信息学

一句话：当主角是「这群微生物是谁、怎么活、怎么变、对我们做了什么、我们怎么用它」时，留在本 hub；当主角是「分子机制 / 算法 / 宿主系统本身」时，移步对应兄弟 hub。同一事实只在其主场 hub 展开，本 hub 各篇之间也遵循此约定（如 CRISPR 的免疫起源在「水平基因转移」展开，其工具化在「合成生物学与微生物工程」与遗传学 hub 引用）。

  • 第二章 微生物遗传学 — 遗传信息的组织与流动：微生物基因组组织、水平基因转移、微生物进化与系统发生

前置知识与推荐学习路径

前置：建议先具备基础的细胞与分子生物学概念（DNA/RNA/蛋白质中心法则、细胞膜与代谢）。若感生疏，可先浏览 分子生物学 · DNA 结构与复制 与 细胞生物学 · 细胞理论与类型。

推荐路径：按章节顺序循序渐进。第一章建立「微生物是谁」的全景；第二章理解微生物特有的遗传可塑性（水平基因转移是后续耐药性与进化的钥匙）；第三章把多样性与遗传学落到与人类健康的关系上；第四章则展示如何反过来驾驭微生物。读者也可按兴趣选择支线——临床方向可走「多样性→致病机制→耐药性」，产业方向可走「多样性→遗传学→工业/合成生物学」。
