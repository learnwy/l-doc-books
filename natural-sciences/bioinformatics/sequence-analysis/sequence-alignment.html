序列比对

核心概念

序列比对（Sequence Alignment）是生物信息学中最基础且应用最广泛的计算方法，通过比较两条或多条生物序列（DNA、RNA 或蛋白质）之间的相似性来推断功能、结构和进化关系。序列比对的核心假设是：进化上相关的序列保留了可检测的相似性，相似的序列倾向于具有相似的功能。从算法角度看，序列比对本质上是在两个字符串之间寻找最优对应关系的优化问题，通过插入空位（gap）来最大化匹配得分。

序列比对的质量高度依赖于替换矩阵（Substitution Matrix）和空位罚分（Gap Penalty）的选择。替换矩阵量化了不同残基之间替换的进化可能性，空位罚分控制了允许的插入/缺失数量和长度。


动态规划：全局与局部比对
动态规划（Dynamic Programming, DP）是精确序列比对算法的数学基础。Needleman-Wunsch（NW, 1970）算法实现全局比对，Smith-Waterman（SW, 1981）算法实现局部比对，两者共享递推框架但在初始化和回溯规则上有关键差异。


NW 全局比对的递推关系为：对于序列 X（长度 m）和 Y（长度 n），构建 (m+1)×(n+1) 的评分矩阵 F，其中：


F(i,j) = max{ F(i−1,j−1) + s(x_i, y_j), F(i−1,j) + d, F(i,j−1) + d }


其中 s(x_i, y_j) 是替换得分（来自 BLOSUM/PAM 矩阵），d 是空位罚分（线性空位模型）。初始化 F(0,0)=0, F(i,0)=i×d, F(0,j)=j×d，从 F(m,n) 回溯获得最优全局比对。


SW 局部比对的关键修改：在递推中增加 0 的选项（F(i,j) = max{..., 0}），初始化所有边界为 0，回溯从矩阵中的最大值开始到第一个 0 结束。这使得算法能够找到两条序列中任意位置的最高得分局部匹配。


仿射空位罚分（Affine Gap Penalty）是实践中最常用的模型：开启一个新空位的代价 g_open 远高于延续已有空位的代价 g_extend（典型值 g_open=−11, g_extend=−1）。这更好地建模了生物学现实——单次插入/缺失事件可能导致多个连续残基的缺失。仿射模型需要三个 DP 矩阵（Match/Insert-X/Insert-Y），复杂度仍为 O(mn)。

BLAST：启发式快速搜索
BLAST（Basic Local Alignment Search Tool）是生物信息学中使用最广泛的工具，自 1990 年发布以来已被引用超过 10 万次。BLAST 的核心策略是牺牲严格的最优性保证以换取几个数量级的速度提升，使海量数据库搜索变得可行。


BLAST 算法分为三个阶段：


    

  • 种子阶段（Seeding）：将查询序列切分为固定长度的"词"（word，蛋白质默认 3 个残基），对每个词在替换矩阵下生成所有得分超过阈值 T 的邻居词，构建词表。扫描数据库找到精确匹配的种子命中（hit）
    • 

  • 延伸阶段（Extension）：从种子命中向两侧无空位延伸，当累积得分低于最高得分超过 X_dropoff 参数时停止，保留得分超过阈值的高分片段对（HSP, High-Scoring Segment Pair）
    • 

  • 评估阶段（Evaluation）：使用 Karlin-Altschul 统计学计算每个 HSP 的统计显著性（E-value）。E-value 表示在随机数据库中期望看到同等或更高得分比对的次数：E = K × m × n × e^(−λS)
    • 



BLAST 的不同变体针对不同查询-数据库组合进行了优化：blastn（核酸 vs 核酸），blastp（蛋白质 vs 蛋白质），blastx（核酸翻译 vs 蛋白质），tblastn（蛋白质 vs 核酸翻译），tblastx（核酸翻译 vs 核酸翻译）。PSI-BLAST（Position-Specific Iterated BLAST）通过迭代构建位置特异性评分矩阵（PSSM），显著提高了检测远缘同源序列的灵敏度。


替换矩阵与进化模型
替换矩阵是序列比对的核心参数，决定了不同残基对的匹配得分。两大主流矩阵族为 PAM 和 BLOSUM。


PAM（Point Accepted Mutation）矩阵由 Dayhoff 等人 (1978) 基于紧密同源蛋白质序列间的氨基酸替换频率构建。PAM-1 矩阵描述了每 100 个残基中平均发生 1 次突变的进化距离，PAM-N 通过矩阵 N 次自乘获得，适用于更远的进化距离。PAM-250 常用于远缘同源搜索。


BLOSUM（BLOcks SUbstitution Matrix）矩阵由 Henikoff & Henikoff (1992) 从 BLOCKS 数据库中无空位的多序列比对块直接提取氨基酸替换频率。BLOSUM-N 中 N 表示聚类阈值：序列相似度 > N% 的归为一组以减少采样偏差。BLOSUM-62（62% 聚类阈值）是最广泛使用的默认矩阵，适用于中等进化距离。

矩阵元素 s(a,b) 的计算基于对数似然比：s(a,b) = (1/λ) × log₂(q_ab / (p_a × p_b))，其中 q_ab 是氨基酸 a 和 b 在比对中的联合频率，p_a 和 p_b 是各自的边际频率。正值表示该替换比随机预期更频繁（保守替换），负值表示比随机预期更少（非保守替换）。


多序列比对
多序列比对（Multiple Sequence Alignment, MSA）将三条或更多相关序列同时对齐，是序列分析中信息量最丰富的表示形式。MSA 可以揭示保守位点（功能/结构关键残基）、协同进化位点（接触预测）和系统发育关系。


精确 MSA 的计算复杂度为 O(n^k)（k 条长度 n 的序列），是 NP-Hard 问题。实际工具使用启发式策略：


    

  • 渐进比对（Progressive Alignment）：先构建序列间的距离矩阵和引导树（Guide Tree），然后沿引导树从叶到根逐步合并比对。ClustalW/Clustal Omega 是经典代表，速度快但受"一旦空位永远空位"（Once a Gap, Always a Gap）问题影响——早期引入的错误空位会传播到最终结果
    • 

  • 迭代优化（Iterative Refinement）：在初始渐进比对基础上反复随机拆分和重新比对，通过目标函数（如 SP 得分或一致性得分）引导优化。MUSCLE 和 MAFFT 采用此策略
    • 

  • 一致性方法（Consistency-Based）：利用所有序列对的成对比对信息来指导 MSA 构建。T-Coffee 的核心思想是：如果位置 i 和 j 在多个成对比对中都对齐，则它们在 MSA 中也应对齐
    •

小结
    

  • 序列比对是连接序列数据与生物学知识的核心桥梁，其理论基础是进化保守性假设——相似序列倾向于具有相似功能
    • 

  • 动态规划算法（NW/SW）提供了精确的全局/局部最优比对，仿射空位罚分更好地建模了生物学中的插入/缺失事件
    • 

  • BLAST 通过种子-延伸-评估的三阶段启发式策略将数据库搜索速度提升数个量级，E-value 提供了统计显著性的定量度量
    • 

  • 替换矩阵（PAM/BLOSUM）将氨基酸替换的进化概率编码为数值得分，BLOSUM-62 作为通用默认在中等进化距离下表现最优
    • 

  • 多序列比对揭示保守性模式和协同进化信号，渐进、迭代和一致性三类策略在速度和精度之间提供不同权衡
    • 

  • 序列比对技术直接支撑了基因注释、蛋白质家族分类、系统发育重建和结构预测等下游分析
    •
