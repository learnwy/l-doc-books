Part IV · 化学生物化学代谢柠檬酸循环（Citric Acid Cycle）

柠檬酸循环（Citric Acid Cycle）

引言

柠檬酸循环（Citric Acid Cycle），又称三羧酸循环（TCA Cycle）或 Krebs 循环，是有氧代谢的核心枢纽。这一环形代谢通路位于线粒体基质中，将乙酰 CoA 中的两个碳原子完全氧化为 CO₂，同时产生还原当量（NADH 和 FADH₂）和少量 GTP。这些还原当量随后进入电子传递链驱动 ATP 合成，是有氧生物大部分 ATP 产生的源头。

Hans Krebs 于 1937 年完整描述了这一循环通路，为此获得 1953 年诺贝尔生理学或医学奖。柠檬酸循环不仅是分解代谢的终端——它同时作为合成代谢的前体供给站（两栖代谢通路），为氨基酸、血红素、脂肪酸和糖的合成提供碳骨架。

丙酮酸脱氢酶复合体

结构与组成

丙酮酸脱氢酶复合体（Pyruvate Dehydrogenase Complex, PDC）是连接糖酵解和柠檬酸循环的"门户"。这个分子量约 9.5 MDa 的巨型多酶复合体（在真核生物中是已知最大的酶复合物之一），由三种催化亚基组成：

  • E1（丙酮酸脱氢酶）：以 TPP（硫胺素焦磷酸）为辅因子，催化丙酮酸的氧化脱羧
  • E2（二氢硫辛酰胺转乙酰酶）：以硫辛酸为辅因子，将乙酰基转移给 CoA
  • E3（二氢硫辛酰胺脱氢酶）：以 FAD 和 NAD⁺ 为辅因子，再氧化硫辛酸

总反应

Pyruvate+CoA-SH+NAD+⟶Acetyl-CoA+CO2+NADH\text{Pyruvate} + \text{CoA-SH} + \text{NAD}^+ \longrightarrow \text{Acetyl-CoA} + \text{CO}_2 + \text{NADH}Pyruvate+CoA-SH+NAD+⟶Acetyl-CoA+CO2​+NADH

ΔG°′=−33.4 kJ/mol\Delta G°' = -33.4 \text{ kJ/mol}ΔG°′=−33.4 kJ/mol，反应不可逆。

调控

PDC 通过共价修饰调控：丙酮酸脱氢酶激酶（PDK）磷酸化 E1 使其失活（在 ATP/乙酰 CoA/NADH 充足时）；丙酮酸脱氢酶磷酸酶（PDP）去磷酸化恢复活性（在 Ca²⁺ 和胰岛素信号下）。

柠檬酸循环的八步反应

步骤 1：柠檬酸合酶

Acetyl-CoA+OAA+H2O⟶Citrate+CoA-SH\text{Acetyl-CoA} + \text{OAA} + \text{H}_2\text{O} \longrightarrow \text{Citrate} + \text{CoA-SH}Acetyl-CoA+OAA+H2​O⟶Citrate+CoA-SH

ΔG°′=−31.5 kJ/mol\Delta G°' = -31.5 \text{ kJ/mol}ΔG°′=−31.5 kJ/mol。乙酰 CoA 的甲基碳对草酰乙酸（OAA）的羰基进行亲核攻击，经柠檬酰 CoA 中间体水解释放 CoA。这是高度放能反应，有效"拉动"循环前进。

步骤 2：顺乌头酸酶

Citrate⇌Isocitrate\text{Citrate} \rightleftharpoons \text{Isocitrate}Citrate⇌Isocitrate

通过脱水和再水化（经顺乌头酸中间体），将叔醇异构化为仲醇，为后续氧化脱羧创造条件。

步骤 3：异柠檬酸脱氢酶（第一次氧化脱羧）

Isocitrate+NAD+⟶α-Ketoglutarate+CO2+NADH\text{Isocitrate} + \text{NAD}^+ \longrightarrow \alpha\text{-Ketoglutarate} + \text{CO}_2 + \text{NADH}Isocitrate+NAD+⟶α-Ketoglutarate+CO2​+NADH

这是循环中第一次产生 NADH 和释放 CO₂。异柠檬酸脱氢酶是循环中最重要的调控位点之一——ADP 和 Ca²⁺ 激活，ATP 和 NADH 抑制。

步骤 4：α-酮戊二酸脱氢酶复合体（第二次氧化脱羧）

α-KG+CoA-SH+NAD+⟶Succinyl-CoA+CO2+NADH\alpha\text{-KG} + \text{CoA-SH} + \text{NAD}^+ \longrightarrow \text{Succinyl-CoA} + \text{CO}_2 + \text{NADH}α-KG+CoA-SH+NAD+⟶Succinyl-CoA+CO2​+NADH

该酶复合体与 PDC 结构和机制高度同源（E1、E2、E3 三组分，使用相同辅因子）。ΔG°′=−33.5 kJ/mol\Delta G°' = -33.5 \text{ kJ/mol}ΔG°′=−33.5 kJ/mol，不可逆。受琥珀酰 CoA 和 NADH 产物抑制，Ca²⁺ 激活。

步骤 5：琥珀酰 CoA 合成酶（底物水平磷酸化）

Succinyl-CoA+GDP+Pi⇌Succinate+CoA-SH+GTP\text{Succinyl-CoA} + \text{GDP} + \text{P}_i \rightleftharpoons \text{Succinate} + \text{CoA-SH} + \text{GTP}Succinyl-CoA+GDP+Pi​⇌Succinate+CoA-SH+GTP

硫酯键的高能水解偶联 GTP 合成（某些组织产生 ATP）。这是循环中唯一的底物水平磷酸化。

步骤 6：琥珀酸脱氢酶

Succinate+FAD⇌Fumarate+FADH2\text{Succinate} + \text{FAD} \rightleftharpoons \text{Fumarate} + \text{FADH}_2Succinate+FAD⇌Fumarate+FADH2​

琥珀酸脱氢酶是循环中唯一嵌入线粒体内膜的酶，同时是呼吸链复合体 II（Complex II）的组成部分。FAD 共价结合于酶中（而非游离辅酶），FADH₂ 的电子直接传递给辅酶 Q。

步骤 7：延胡索酸酶

Fumarate+H2O⇌L-Malate\text{Fumarate} + \text{H}_2\text{O} \rightleftharpoons \text{L-Malate}Fumarate+H2​O⇌L-Malate

立体特异性加水——仅产生 L-苹果酸。

步骤 8：苹果酸脱氢酶

L-Malate+NAD+⇌OAA+NADH\text{L-Malate} + \text{NAD}^+ \rightleftharpoons \text{OAA} + \text{NADH}L-Malate+NAD+⇌OAA+NADH

ΔG°′=+29.7 kJ/mol\Delta G°' = +29.7 \text{ kJ/mol}ΔG°′=+29.7 kJ/mol——标准条件下热力学不利！但在细胞内，OAA 浓度极低（被柠檬酸合酶快速消耗），加上 NADH/NAD⁺ 比值维持适当水平，使反应实际方向向右。

⟶2CO2+3NADH+FADH2+GTP+CoA-SH\longrightarrow 2\text{CO}_2 + 3\text{NADH} + \text{FADH}_2 + \text{GTP} + \text{CoA-SH}⟶2CO2​+3NADH+FADH2​+GTP+CoA-SH

柠檬酸循环的调控

三个调控位点

循环的三个不可逆步骤（柠檬酸合酶、异柠檬酸脱氢酶、α-酮戊二酸脱氢酶）是主要调控点。共同的调控逻辑：

条件 信号 效应
能量充足 高 ATP/ADP、高 NADH/NAD⁺ 抑制循环
能量需求 高 ADP、高 Ca²⁺ 激活循环
底物可用 乙酰 CoA 和 OAA 充足 加速循环

Ca²⁺ 的激活作用在心肌和骨骼肌中尤为重要——运动时 Ca²⁺ 释放同时激活肌肉收缩和线粒体产能，实现供需匹配。

两栖代谢功能

合成代谢出口

柠檬酸循环中间体作为多条生物合成通路的前体：

  • 柠檬酸 → 输出到细胞质裂解为乙酰 CoA 和 OAA → 脂肪酸合成
  • α-酮戊二酸 → 谷氨酸 → 其他氨基酸（谷氨酰胺、脯氨酸、精氨酸）
  • 琥珀酰 CoA → 血红素和叶绿素的生物合成
  • OAA → 天冬氨酸 → 嘧啶核苷酸合成；或直接进入糖异生（经 PEP）

回补反应（Anaplerotic Reactions）

当循环中间体被"抽走"用于合成代谢时，必须通过回补反应补充，以维持循环运转。最重要的回补反应：

Pyruvate+CO2+ATP→Pyruvate CarboxylaseOAA+ADP+Pi\text{Pyruvate} + \text{CO}_2 + \text{ATP} \xrightarrow{\text{Pyruvate Carboxylase}} \text{OAA} + \text{ADP} + \text{P}_iPyruvate+CO2​+ATPPyruvate Carboxylase​OAA+ADP+Pi​

丙酮酸羧化酶被乙酰 CoA 别构激活——当乙酰 CoA 堆积（表示 OAA 不足以驱动柠檬酸合酶反应），自动触发 OAA 补充。

其他回补酶包括 PEP 羧化酶（植物和某些细菌）、苹果酸酶（逆向运行时）、以及谷氨酸脱氢酶（将谷氨酸转化为 α-酮戊二酸）。

柠檬酸循环与临床

先天性代谢缺陷

柠檬酸循环酶的遗传缺陷罕见但严重——完全缺失通常致死。琥珀酸脱氢酶（SDH）亚基的杂合失功能突变与遗传性副神经节瘤和嗜铬细胞瘤相关，SDH 被视为肿瘤抑制因子。延胡索酸酶突变与遗传性平滑肌肉瘤和肾细胞癌有关。

代谢重编程

许多肿瘤展示异柠檬酸脱氢酶（IDH1/IDH2）的功能获得性突变，使其催化产生异常代谢物 2-羟基戊二酸（2-HG），后者作为"致癌代谢物"抑制多种 α-KG 依赖性双加氧酶（包括 TET 家族和组蛋白去甲基化酶），导致表观遗传紊乱。IDH 抑制剂（如 Ivosidenib）已获批用于 IDH 突变的急性髓性白血病。

总结

柠檬酸循环是有氧代谢的核心枢纽，完成碳骨架的最终氧化并生成大量还原当量。其"两栖"特性使其同时服务于分解代谢和合成代谢，回补反应确保这一功能平衡不被打破。从 Ca²⁺ 介导的实时产能调节到 IDH 突变驱动的肿瘤代谢重编程，柠檬酸循环的生物学和医学意义远超其教科书中的"八步反应"。
