信号转导基础（Signal Transduction Fundamentals）

引言

细胞生活在不断变化的环境中，必须持续感知外部信号并做出适当响应。信号转导（Signal Transduction）是细胞接收、放大和传递化学信号的分子机制，使细胞能够协调生长、分化、代谢和凋亡等生命活动。从单细胞生物的趋化反应到多细胞生物中数十亿细胞的协调运作，信号转导是生命复杂性的分子基础。

大多数细胞信号通过跨膜受体蛋白接收——因为信号分子（配体）通常无法穿过细胞膜直接进入细胞。受体与配体的结合触发胞内信号级联（signaling cascade），通过蛋白激酶、第二信使和转录因子的依次激活，将膜上的识别事件转化为细胞核内的基因表达改变。信号转导通路的失调是癌症、糖尿病、免疫疾病和心血管疾病的常见分子病因。

G 蛋白偶联受体信号通路

GPCR 的结构

G 蛋白偶联受体（G Protein-Coupled Receptor, GPCR）是最大的跨膜受体超家族，人类基因组编码约 800 种 GPCR。所有 GPCR 共享七次跨膜 α-螺旋的结构特征（又称七跨膜受体），N 端位于细胞外侧，C 端位于胞内。

GPCR 的配体极为多样：光子（视紫红质）、小分子代谢物、脂质介质、肽类激素、蛋白酶、甚至嗅觉分子。约 34% 的 FDA 批准药物靶向 GPCR，使其成为最成功的药物靶点家族。

异源三聚体 G 蛋白

GPCR 通过异源三聚体 G 蛋白（GαβγG_{\alpha\beta\gamma}Gαβγ​）偶联到胞内效应器。G 蛋白在 GDP 结合（非活性）和 GTP 结合（活性）状态间循环：

  1. 配体结合 GPCR 后引起受体构象变化
  2. 活化的受体充当 GEF（鸟嘌呤核苷酸交换因子），促进 GαG_\alphaGα​ 释放 GDP 并结合 GTP
  3. GαG_\alphaGα​-GTP 与 GβγG_{\beta\gamma}Gβγ​ 分离，各自激活下游效应器
  4. GαG_\alphaGα​ 自身的 GTPase 活性水解 GTP 为 GDP，使信号终止
  5. GαG_\alphaGα​-GDP 重新与 GβγG_{\beta\gamma}Gβγ​ 结合，恢复静息状态

RGS（Regulator of G protein Signaling）蛋白加速 GαG_\alphaGα​ 的 GTPase 活性，缩短信号持续时间。

cAMP 信号通路

GαsG_{\alpha s}Gαs​ 激活腺苷酸环化酶（Adenylyl Cyclase, AC），催化 ATP 转化为环磷酸腺苷（cAMP）：

ATP→ACcAMP+PPi\text{ATP} \xrightarrow{\text{AC}} \text{cAMP} + \text{PP}_iATPAC​cAMP+PPi​

cAMP 作为第二信使激活蛋白激酶 A（PKA）：cAMP 结合 PKA 的调节亚基使其释放催化亚基，后者磷酸化多种底物蛋白调控代谢和基因表达。

经典案例——肾上腺素信号：肾上腺素 → β-肾上腺素能受体 → GαsG_{\alpha s}Gαs​ → AC → cAMP↑ → PKA → 糖原磷酸化酶激酶 → 糖原磷酸化酶 → 糖原分解。这一级联放大使一分子肾上腺素可导致数百万分子葡萄糖从糖原中释放。

磷酸二酯酶（PDE）水解 cAMP 为 5'-AMP 终止信号。西地那非（Viagra）抑制 PDE5，防止 cGMP 降解，松弛血管平滑肌。

磷脂酶 C-Ca²⁺ 通路

GαqG_{\alpha q}Gαq​ 激活磷脂酶 C-β（PLC-β），水解 PIP₂ 为 IP₃ 和 DAG：

IP₃ 支路：IP₃ 结合内质网膜上的 IP₃ 受体（配体门控 Ca²⁺ 通道），释放 Ca²⁺ 到细胞质。胞浆 Ca²⁺ 浓度从 ~100 nM 升高至 ~1 μM，激活 Ca²⁺ 依赖性蛋白（如钙调蛋白 CaM → CaM 激酶 → 转录调控）。

DAG 支路：DAG 留在膜中，与 Ca²⁺ 和 PS 协同激活蛋白激酶 C（PKC）。PKC 磷酸化多种底物调控细胞增殖和分化。

受体酪氨酸激酶信号通路

RTK 的激活机制

受体酪氨酸激酶（Receptor Tyrosine Kinase, RTK）是另一大类跨膜受体家族，包括 EGFR（表皮生长因子受体）、PDGFR、VEGFR 和胰岛素受体等。RTK 具有胞外配体结合域、单次跨膜螺旋和胞内酪氨酸激酶域。

配体结合诱导 RTK 二聚化（或稳定已有的二聚体），两个激酶域相互反式磷酸化（trans-autophosphorylation）各自的特定酪氨酸残基。磷酸化的酪氨酸成为含 SH2 域或 PTB 域的下游信号蛋白的对接位点。

Ras-MAPK 通路

这是细胞增殖和分化的核心信号通路：

  1. RTK 磷酸化酪氨酸 → 招募 Grb2（适配蛋白，含 SH2 域）
  2. Grb2 结合 SOS（Ras 的 GEF）
  3. SOS 促进 Ras 释放 GDP 结合 GTP → Ras 活化
  4. Ras-GTP 招募并激活 Raf（MAPKKK）
  5. Raf 磷酸化 MEK（MAPKK）
  6. MEK 磷酸化 ERK（MAPK）
  7. ERK 进入细胞核，磷酸化转录因子（如 Elk-1、c-Myc），激活增殖相关基因

Ras 突变（锁定在 GTP 结合活化态）存在于约 30% 的人类癌症中（尤其是 KRAS 突变在胰腺癌中达 ~90%）。2021 年，首个直接靶向 KRAS^G12C 突变体的药物 Sotorasib 获 FDA 批准用于非小细胞肺癌，结束了 Ras"不可成药"的历史。

PI3K-Akt 通路

RTK 活化后招募 PI3K 的 p85 调节亚基（通过 SH2 域），使 p110 催化亚基接近膜上 PIP₂ 并将其磷酸化为 PIP₃。PIP₃ 通过其 PH 域招募 Akt（PKB）和 PDK1 到膜上，PDK1 和 mTORC2 磷酸化 Akt 使其完全活化。

活化的 Akt 通过磷酸化多种底物促进：

  • 细胞存活：磷酸化 Bad（失活促凋亡蛋白）
  • 细胞生长：磷酸化 TSC2 解除对 mTORC1 的抑制
  • 代谢调控：磷酸化 GSK3 促进糖原合成

肿瘤抑制因子 PTEN 是 PIP₃ 的磷酸酶（将 PIP₃ 去磷酸化回 PIP₂），是 PI3K-Akt 通路的核心负调控。PTEN 失功能突变在多种癌症中高频出现。

JAK-STAT 通路

细胞因子受体（如 IL-6 受体、干扰素受体）不具有内在激酶活性，而是通过偶联的 Janus 激酶（JAK）进行信号传导。

配体结合 → 受体二聚化 → JAK 相互磷酸化激活 → JAK 磷酸化受体胞内域酪氨酸 → STAT（信号转导和转录激活因子）通过 SH2 域结合磷酸化受体 → JAK 磷酸化 STAT → 磷酸化 STAT 二聚化 → 进入细胞核激活靶基因转录。

JAK 抑制剂（如 Tofacitinib, Baricitinib）通过阻断 JAK-STAT 信号用于类风湿关节炎、骨髓纤维化等疾病的治疗。

核受体：胞内受体

脂溶性信号分子（类固醇激素、甲状腺激素、维生素 D、视黄酸）直接穿过细胞膜与胞内核受体（Nuclear Receptor）结合。核受体本质上是配体激活的转录因子：配体结合引起构象变化 → 受体与辅阻遏物解离 → 招募辅激活物（含组蛋白乙酰转移酶活性） → 在靶基因启动子的激素应答元件（HRE）上激活转录。

核受体超家族包括 48 个成员（人类），许多是重要药物靶点：

  • 雌激素受体：他莫昔芬（乳腺癌）
  • 糖皮质激素受体：地塞米松（抗炎）
  • PPARγ：噻唑烷二酮类（2 型糖尿病）
  • 维生素 D 受体：骨化三醇（骨质疏松）

信号通路的整合与交叉对话

信号放大

信号级联的每一级都可实现放大——一个活化的酶可催化产生大量下游活性分子。肾上腺素 → 糖原分解级联中：1 分子肾上腺素 → ~20 cAMP → ~10 PKA → ~100 磷酸化酶激酶 → ~1000 活性磷酸化酶 → ~10⁷ 葡萄糖分子/秒。

交叉对话（Crosstalk）

不同信号通路之间存在广泛的交叉对话。例如：

  • Ras-MAPK 和 PI3K-Akt 通路在 RTK 水平分叉但在转录调控水平汇聚
  • Ca²⁺ 信号影响 Ras 和 MAPK 通路活性
  • AMPK（能量感受器）通过抑制 mTORC1 和激活 TSC2 整合代谢信号与生长信号

信号终止

精确的信号终止与信号产生同等重要——持续激活常导致病理：

  • GTPase 活性水解 G 蛋白和 Ras 的 GTP
  • 磷酸酶去磷酸化信号蛋白（蛋白磷酸酶 1/2A、酪氨酸磷酸酶）
  • 受体内吞和降解（配体依赖性泛素化 → 溶酶体降解）
  • 负反馈回路（如 ERK 磷酸化 SOS 降低其 Ras 活化能力）

信号转导与精准医学

信号通路的分子靶向治疗是精准肿瘤学的基石：

  • Imatinib（格列卫）：靶向 BCR-ABL 融合酪氨酸激酶，革命性改变慢性髓性白血病预后
  • Trastuzumab（赫赛汀）：靶向 HER2/ErbB2 受体，用于 HER2 阳性乳腺癌
  • Vemurafenib：靶向 BRAF^V600E 突变，用于黑色素瘤
  • Osimertinib：靶向 EGFR T790M 耐药突变，用于非小细胞肺癌

从单一基因靶点到组合靶向策略的演进，反映了对信号网络复杂性和代偿机制认识的深化。

总结

信号转导将细胞外的化学信息转化为精确的胞内响应。GPCR-G 蛋白-第二信使系统和 RTK-Ras-MAPK/PI3K-Akt 系统是两大核心信号范式，它们通过蛋白激酶级联实现信号放大，通过磷酸酶和 GTPase 保证信号终止，通过交叉对话实现信号整合。信号通路的失调是多种人类疾病的分子基础，而对信号网络的深入理解则催生了精准医学时代的分子靶向治疗策略。
