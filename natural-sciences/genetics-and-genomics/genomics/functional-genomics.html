功能基因组学

核心概念

功能基因组学（functional genomics）旨在利用基因组规模的数据来理解基因和基因组的功能。如果基因组测序回答了"基因组中有什么？"的问题，功能基因组学则要回答"这些基因做什么？何时做？在哪里做？如何做？"的问题。这一领域综合运用转录组学、蛋白质组学、代谢组学和基因组编辑等高通量技术，在系统层面解析基因功能和调控网络。

ENCODE（Encyclopedia of DNA Elements）项目是功能基因组学的标志性工程，系统鉴定了人类基因组中的所有功能元件。ENCODE 的结果表明，尽管仅约 1.5% 的人类基因组编码蛋白质，但约 80% 的基因组具有某种生化活性（转录、蛋白质结合或染色质修饰），揭示了基因组中庞大的调控程序。

转录组学与 RNA-seq
RNA-seq 是当前最广泛使用的转录组学技术，通过高通量测序全面检测细胞中 RNA 的种类和丰度。与传统的基因芯片（microarray）相比，RNA-seq 具有更高的动态范围、无需预设探针、可检测新转录本和剪接异构体等优势。


RNA-seq 的标准实验流程：RNA 提取 → poly(A)选择或核糖体去除 → RNA 片段化 → 反转录为 cDNA → 接头连接 → PCR 扩增 → 测序。数据分析流程包括：读长质控 → 比对（HISAT2/STAR）→ 定量（featureCounts/Salmon）→ 标准化（TPM/FPKM/DESeq2）→ 差异表达分析（DESeq2/edgeR）→ 功能富集分析（GO/KEGG/GSEA）。


单细胞 RNA-seq（scRNA-seq） 是转录组学的革命性进展，能在单细胞水平解析基因表达异质性。10x Genomics 的 Chromium 平台是目前最流行的 scRNA-seq 平台，每次可处理数万个细胞。其核心是液滴微流控技术——每个细胞与一个带有唯一条形码的凝胶微球一起被包裹在油滴中，实现细胞级别的 mRNA 标记。


scRNA-seq 数据分析的关键步骤包括：


    

  • 降维与可视化：PCA → UMAP/t-SNE，将高维数据投影到二维空间
    • 

  • 聚类：Louvain/Leiden 社区检测算法识别细胞群
    • 

  • 标记基因鉴定：Wilcoxon 秩和检验或 t 检验找到每个群的特征基因
    • 

  • 轨迹分析：pseudotime 推断细胞分化轨迹（Monocle3/RNA velocity）
    • 

  • 细胞通讯：CellChat/NicheNet 推断细胞间信号互作
    • 



表观基因组学技术
表观基因组学技术在全基因组尺度上绘制表观遗传修饰和染色质状态的图谱。这些技术揭示了基因调控的空间和时间维度。


ChIP-seq（染色质免疫沉淀-测序） 是鉴定蛋白质-DNA 互作位点的核心技术。实验流程：甲醛交联固定蛋白-DNA 复合物 → 超声或酶切片段化染色质 → 特异性抗体免疫沉淀目标蛋白及其结合的 DNA → 去交联、纯化 DNA → 测序。峰检测算法（MACS2）识别富集区域，揭示转录因子结合位点或组蛋白修饰分布。


ATAC-seq（转座酶可及性染色质测序） 利用 Tn5 转座酶优先插入开放染色质区域的特性，快速绘制全基因组的染色质可及性图谱。仅需约 500-50,000 个细胞，操作时间约 3 小时，远比 DNase-seq 简便。ATAC-seq 信号与活性调控元件（启动子、增强子）高度吻合。


Hi-C 技术绘制基因组的三维空间互作图谱。通过甲醛交联 → 限制酶消化 → 近端连接（proximity ligation）→ 测序，检测空间上邻近但线性距离上可能很远的基因组片段之间的互作频率。Hi-C 数据揭示了 A/B 区室、TAD 和染色质环等多层级的三维基因组结构。


CRISPR 功能筛选
CRISPR-Cas9 技术不仅是精准基因编辑的工具，更被开发为强大的功能基因组学筛选平台。CRISPR 筛选可以在全基因组规模上系统性地鉴定与特定表型相关的基因。


CRISPR 敲除筛选 使用全基因组 sgRNA 文库（如 Brunello 文库，含约 77,000 个 sgRNA 靶向约 19,000 个基因），以慢病毒感染细胞，确保每个细胞只获得一个 sgRNA。经过表型选择压力后，测序检测 sgRNA 的丰度变化：在选择条件下丢失的 sgRNA（dropout）对应功能必需基因，富集的 sgRNA 对应抑制因子。

Perturb-seq 是 CRISPR 筛选与单细胞转录组学的结合——在每个细胞中同时检测 CRISPR 扰动（哪个基因被编辑）和转录组变化。这种方法可以在单次实验中揭示数千个基因扰动对全局基因表达的影响，构建高分辨率的基因调控网络。


小结
    

  • 功能基因组学利用高通量技术在系统层面解析基因功能，ENCODE 项目揭示了约 80% 的人类基因组具有生化活性
    • 

  • RNA-seq 是转录组分析的标准方法，scRNA-seq 将分辨率推进到单细胞水平
    • 

  • ChIP-seq、ATAC-seq 和 Hi-C 分别绘制蛋白-DNA 互作、染色质可及性和三维基因组图谱
    • 

  • CRISPR 筛选实现了全基因组规模的功能丧失和功能增益研究
    • 

  • Perturb-seq 结合 CRISPR 扰动与单细胞转录组，构建高分辨率的基因调控网络
    • 

  • 多组学数据的整合分析是功能基因组学的发展方向
    •
