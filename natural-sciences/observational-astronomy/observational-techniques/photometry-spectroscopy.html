测光与光谱学：天体物理量的定量提取

概述

测光（Photometry）和光谱学（Spectroscopy）是从天体辐射中提取定量物理信息的两大核心技术。测光测量天体在特定波段内的积分流量，获取亮度、颜色和时间变化信息；光谱学将辐射按波长色散，揭示化学组成、温度、密度、运动速度和磁场等精细物理参数。两者互为补充——测光提供广度（大样本、多历元），光谱提供深度（逐源物理诊断）。

测光学

测光系统

天文测光通过定义好的滤光片系统量化天体亮度。标准测光系统的核心要素是一组透过率曲线已知的滤光片和一套零点定标关系。

Johnson-Cousins UBVRI 系统：经典宽带系统，定义了天文星等的基本框架。

SDSS ugriz 系统：以 AB 星等为零点（基于单位频率流量密度），消除了维加星等系统的光谱型依赖，已成为光学巡天的事实标准。

窄带系统：通过 50–200 Å 带宽滤光片隔离特定发射线或吸收特征（如 Hα、[OIII]、Lyα），实现免光谱的发射线天体筛选。

差分图像测光
时域天文学的核心技术是差分图像分析（DIA）：将新观测图像与深度参考模板图像相减，只保留发生亮度变化的源。


步骤：


    

  1. 将模板图像 PSF 卷积匹配到新图像的 PSF
    2. 

  2. 对齐、缩放后相减
    3. 

  3. 在差分图像上进行源检测和测光
    4. 

  4. 正余像分别对应变亮和变暗事件
    5. 



Vera C. Rubin 天文台的警报管线正是基于此原理——每晚将新图像与模板相减，在 60 秒内产生变源警报。


测光红移
利用多波段测光数据，通过模板拟合或机器学习估计星系的红移（无需光谱）。原理是 Lyman 断裂和 Balmer 断裂等光谱特征在通过不同滤光片时产生可辨识的颜色变化。测光红移的精度通常为 σz/(1+z)∼0.02–0.05\sigma_z / (1+z) \sim 0.02–0.05σz​/(1+z)∼0.02–0.05，虽不及光谱红移（σz<0.001\sigma_z < 0.001σz​<0.001），但可在巡天时间内获取数十亿星系的红移估计。


光谱学
色散原理
光谱仪将入射光按波长分离，核心色散元件包括：


棱镜：利用材料折射率的色散特性。色散率随波长非线性变化，紫端色散大、红端小。优点是效率高且无多级衍射重叠。


反射光栅：利用衍射原理，光栅方程：


mλ=d(sin⁡α+sin⁡β)m\lambda = d(\sin\alpha + \sin\beta)mλ=d(sinα+sinβ)
其中 ddd 为刻线间距，α\alphaα、β\betaβ 为入射和衍射角，mmm 为衍射级次。分辨率 R=mNR = mNR=mN（NNN 为照明刻线数）。


体相位全息光栅（VPH）：在明胶层中制作折射率调制结构，兼具高效率和可调特性。


回声梯光栅（Echelle）：在极高级次（m~50–100）工作的粗刻线光栅，配合交叉色散器将各级次分离到二维探测器上，实现高分辨率的同时覆盖宽波长范围。


光谱分辨率
分辨率 R=λ/ΔλR = \lambda / \Delta\lambdaR=λ/Δλ 表征光谱仪分辨两个相邻波长特征的能力。对应到速度空间：


Δv=cR\Delta v = \frac{c}{R}Δv=Rc​

多目标光谱技术
现代光谱巡天要求同时观测大量目标：


多光纤光谱：将光纤端头精确放置在焦面上目标位置，另一端排列为伪缝送入光谱仪。DESI（暗能量光谱仪器）拥有 5000 根机器人光纤，每次曝光观测 5000 个天体。


多缝光谱：在焦面放置激光切割的多缝板，每个缝位对准一个目标。


无缝棱镜光谱：整个视场的光通过棱镜色散，每个源产生一条低分辨率光谱条带。适合密集场的红移测量（如 HST/GRISM、JWST/NIRISS）。


积分场光谱（IFU）：通过图像切片器、透镜阵列或光纤束将二维视场重排为一维伪缝，每个空间元获取完整光谱。

数据处理管线
从原始二维光谱图像到科学级一维光谱的处理流程：


    

  1. 减除仪器特征：暗场减除、平场校正
    2. 

  2. 波长标定：弧光灯谱线定标
    3. 

  3. 天光减除：使用专用天光光纤或 B-spline 拟合减除夜天光线
    4. 

  4. 最优提取：沿空间方向加权提取一维光谱（Horne 1986 算法）
    5. 

  5. 流量标定：光谱标准星修正仪器响应
    6. 

  6. 红移/参数测量：交叉相关或模板拟合
    7. 

  7. 质量标记：自动和人工质量控制
    8. 



前沿方向
    

  • 高复用度光谱仪：单次曝光 >10,000 目标（如 DESI 的成功推动更高复用度设计）
    • 

  • 光子能量分辨探测器：超导隧道结（STJ）和微波动能电感探测器（MKID）可同时记录每个光子的到达时间和能量，无需色散光学
    • 

  • 高对比度光谱：结合日冕仪的系外行星直接光谱——测量反射光或热辐射中的分子特征
    • 

  • 实时光谱分类：机器学习驱动的暂现源快速光谱确认（如 SEDM、SOAR 4m 的快速反应光谱）
    • 

  • 积分场巡天：大视场 IFU 如 MUSE 的升级版本，或空间 IFU 如 Roman/grism，实现 3D 宇宙学巡天
    • 



测光与光谱学正在从独立工具走向深度融合——测光红移为光谱巡天选目标，光谱训练集标定测光红移，两者在数据驱动的天文学中形成闭环。
