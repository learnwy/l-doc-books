X 射线荧光与光电子能谱（XRF & XPS）

X 射线与物质相互作用的基础

X 射线是波长 0.01-10 nm 的高能电磁辐射。当 X 射线照射物质时，会发生多种相互作用过程：光电效应（内层电子被完全弹出）、康普顿散射（非弹性散射，X 射线光子与外层电子交换能量）、瑞利散射（弹性散射）和电子对产生（超高能量时）。在分析化学中最重要的是光电效应——它是 XRF 和 XPS 两种技术的共同物理基础。

光电效应中，入射 X 射线光子将原子内层电子完全弹出，产生光电子和内层空穴。随后外层电子跃迁填补空穴，多余能量以特征 X 射线（荧光）或 Auger 电子的形式释放。检测这些特征辐射或电子即可确定元素组成和化学状态。

X 射线荧光光谱（XRF）

基本原理

X 射线荧光光谱（X-Ray Fluorescence Spectrometry, XRF）利用初级 X 射线（来自 X 射线管或放射性同位素源）激发样品产生次级特征 X 射线（荧光），通过测量荧光 X 射线的波长（能量）和强度实现元素定性定量。

Moseley 定律描述了特征 X 射线波长与原子序数 ZZZ 的关系：

1λ=K(Z−σ)2\frac{1}{\lambda} = K(Z - \sigma)^2λ1​=K(Z−σ)2

或等价地，特征 X 射线能量：

E=hν=R∞hc(Z−σ)2(1n12−1n22)E = h\nu = R_\infty hc(Z - \sigma)^2 \left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right)E=hν=R∞​hc(Z−σ)2(n12​1​−n22​1​)

其中 σ\sigmaσ 为屏蔽常数，n1,n2n_1, n_2n1​,n2​ 为主量子数。每种元素的 K、L、M 系列特征线的能量是唯一的，构成该元素的"X 射线指纹"。XRF 可检测从 Na（Z=11）到 U（Z=92）的所有元素（能量色散 EDXRF）；波长色散 WDXRF 在轻元素方面可延伸到 Be（Z=4）。

波长色散 XRF（WDXRF）

WDXRF 使用分光晶体（如 LiF、PET、TAP）对荧光 X 射线进行 Bragg 衍射分光：

nλ=2dsin⁡θn\lambda = 2d\sin\thetanλ=2dsinθ

不同波长的荧光 X 射线在不同角度 θ\thetaθ 满足 Bragg 条件，通过旋转分光晶体和检测器（角度扫描或多通道固定），逐一或同时检测各元素的特征线。

WDXRF 的优势：能量分辨率极高（可分辨相邻元素的谱线重叠）、定量精度高（RSD <0.1%）、适合高浓度基质中主次组分分析。广泛应用于水泥、矿石、钢铁、玻璃等工业分析。

能量色散 XRF（EDXRF）

EDXRF 使用半导体检测器（Si(Li) 或 Silicon Drift Detector SDD）直接测量荧光 X 射线光子的能量。所有元素的荧光信号同时被检测，无需分光晶体和角度扫描，因此仪器结构简单紧凑、分析速度快。

现代 SDD 探测器的能量分辨率约 125-140 eV（@Mn Kα 5.9 keV），足以分辨大多数相邻元素。EDXRF 特别适合于：

  • 便携式现场分析（手持式 XRF，重量 <2 kg）
  • 多元素快速筛查
  • 涂层厚度测量
  • 贵金属成色鉴定

全反射 XRF（TXRF）

全反射 XRF 将初级 X 射线以极小掠射角（<0.1°）照射在抛光平面样品载体上，利用全反射条件使初级射线在样品表面附近充分激发而不穿透载体，同时大幅降低背景散射。TXRF 可将检测限降低到 pg 级（~10⁹ atoms/cm²），适合超微量分析（如硅晶圆表面金属污染物检测）。

微区 XRF（μ-XRF）

使用多毛细管透镜或同步辐射聚焦光束将 X 射线束缩小到 μm 级（同步辐射纳米探针可达 50 nm），逐点扫描样品表面获得元素分布图。同步辐射 μ-XRF 在地球化学（矿物中微量元素分带）、考古学（颜料层分析）和生物学（单细胞内金属分布）中有重要应用。

X 射线光电子能谱（XPS）

基本原理

X 射线光电子能谱（X-ray Photoelectron Spectroscopy, XPS），又称化学分析电子能谱（ESCA, Electron Spectroscopy for Chemical Analysis），由 Kai Siegbahn 开发（1981 年 Nobel 物理学奖）。XPS 使用单色化 X 射线（Al Kα 1486.6 eV 或 Mg Kα 1253.6 eV）照射样品表面，测量被弹出的光电子的动能 EkE_kEk​：

Ek=hν−EB−ϕE_k = h\nu - E_B - \phiEk​=hν−EB​−ϕ

其中 hνh\nuhν 为入射 X 射线光子能量，EBE_BEB​ 为电子的结合能（Binding Energy），ϕ\phiϕ 为谱仪功函数。结合能 EBE_BEB​ 是元素和化学环境的特征量——不同元素具有不同的核心能级结合能（元素定性），同一元素在不同化学环境中结合能会发生化学位移（化学态鉴定）。

化学位移

XPS 最强大的能力是提供化学态信息。当原子周围的化学环境改变时（如氧化态变化、与不同配体成键），核心电子的结合能会发生 0.1-10 eV 的位移。例如：

  • C 1s：烃 C-C/C-H ~284.8 eV；C-O ~286.5 eV；C=O ~288.0 eV；O-C=O ~289.0 eV；CF₂ ~291.5 eV
  • Fe 2p₃/₂：Fe⁰ ~707.0 eV；Fe²⁺(FeO) ~709.5 eV；Fe³⁺(Fe₂O₃) ~711.0 eV

通过高分辨谱的峰拟合（Peak Fitting），可以确定同一元素不同化学态的相对含量——这是 XPS 区别于 XRF 等纯元素分析技术的核心优势。

表面灵敏性

由于光电子在固体中的非弹性平均自由程（IMFP）很短（1-10 nm 数量级），XPS 检测深度仅为最外层 1-10 nm（约 3λ），是一种表面分析技术。这一特性使 XPS 成为研究表面氧化、腐蚀、涂层、催化剂表面化学的理想工具。

角分辨 XPS（ARXPS）通过改变检测器相对于样品表面的角度，可进行非破坏性的表面层深度分析。

XPS 定量分析

XPS 的定量基于各元素特征峰面积与其表面浓度的关系：

nAnB=IA/SAIB/SB\frac{n_A}{n_B} = \frac{I_A / S_A}{I_B / S_B}nB​nA​​=IB​/SB​IA​/SA​​

其中 III 为峰面积，SSS 为相对灵敏度因子（RSF，已知的仪器/元素相关参数）。XPS 定量的典型精度为 ±10%（相对），绝对检测限约 0.1-1 at%。

仪器构成

现代 XPS 系统包括：

  • X 射线源：单色化 Al Kα 微聚焦源（光斑 10-400 μm）
  • 能量分析器：半球形静电分析器（HSA），通过调节通过能量选择不同动能的电子
  • 检测器：多通道板（MCP）或 2D 延迟线探测器
  • 超高真空系统：基础真空 <10⁻⁹ mbar，防止表面污染
  • 样品处理：离子枪（Ar⁺ 溅射清洁表面或深度剖面）、加热/冷却台

实际应用

工业质量控制

WDXRF 是水泥、钢铁、玻璃、陶瓷行业的标准成分分析工具。一台仪器可在 1-3 分钟内同时测定 20+ 种元素，RSD <0.5%，满足过程控制和出厂检验需求。手持式 EDXRF 广泛用于废旧金属回收中的合金快速分选、土壤重金属现场筛查、文物无损成分鉴定。

半导体与电子材料

XPS 是半导体工艺开发和质量控制的核心表征技术：

  • 栅极氧化物（SiO₂/HfO₂）的化学组成和界面态分析
  • 金属互连层的氧化/腐蚀监测
  • ALD/CVD 薄膜的化学计量比验证
  • 光刻胶残留物检测

催化剂研究

XPS 用于揭示催化剂表面活性位的化学状态——例如负载型贵金属催化剂中 Pt 的氧化态（Pt⁰ vs PtO vs PtO₂），氮掺杂碳材料中氮的键合方式（吡啶氮、吡咯氮、石墨氮）。这些信息对理解催化机理和优化催化剂设计至关重要。

环境与地质

手持式 XRF 实现了土壤重金属污染的现场快速评估（"指向性采样"），筛查结果指导后续的精确实验室分析。μ-XRF 和 μ-XANES（X 射线吸收近边结构）的联合使用可揭示土壤颗粒中重金属的空间分布和化学形态，对风险评估至关重要。

法医与考古

XRF 在法医中用于枪击残留物（GSR）检测——特征元素组合（Pb-Sb-Ba 或 Gd-Ti-Zn）可指示是否接触过枪支射击。在考古学中，XRF 用于青铜器产地溯源（微量元素指纹）和壁画颜料鉴定。

小结

XRF 和 XPS 是 X 射线分析技术的两大代表。XRF 以其无损、快速、多元素的特点成为工业和环境分析的"万能工具"；XPS 凭借独特的化学态分辨能力和表面灵敏性，是材料科学、催化研究和半导体工艺中不可替代的表征手段。两种技术互补——XRF 告诉我们"有什么元素、含多少"，XPS 进一步告诉我们"元素以什么形式存在、在表面如何分布"。
