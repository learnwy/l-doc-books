分子轨道理论（Molecular Orbital Theory）

从原子轨道到分子轨道

分子轨道理论（MO Theory）是理解化学键的两大量子力学理论之一（另一个是价键理论）。其核心思想是：分子中的电子不属于某个特定原子，而是占据遍布整个分子的分子轨道。分子轨道由原子轨道的线性组合（Linear Combination of Atomic Orbitals, LCAO）构建。

MO 理论的优势在于：它能自然地解释离域效应（如苯的共振）、磁性（如 O2_22​ 的顺磁性）、光谱跃迁，以及分子对称性对化学性质的制约。

LCAO-MO 方法

基本原理

对于双原子分子 AB，分子轨道 ψMO\psi_{MO}ψMO​ 写为原子轨道 ϕA\phi_AϕA​ 和 ϕB\phi_BϕB​ 的线性组合：

ψMO=cAϕA+cBϕB\psi_{MO} = c_A\phi_A + c_B\phi_BψMO​=cA​ϕA​+cB​ϕB​

将其代入薛定谔方程 H^ψ=Eψ\hat{H}\psi = E\psiH^ψ=Eψ 并利用变分原理，得到久期方程（secular equation）：

∣HAA−ESAAHAB−ESABHBA−ESBAHBB−ESBB∣=0\begin{vmatrix} H_{AA} - ES_{AA} & H_{AB} - ES_{AB} \\ H_{BA} - ES_{BA} & H_{BB} - ES_{BB} \end{vmatrix} = 0​HAA​−ESAA​HBA​−ESBA​​HAB​−ESAB​HBB​−ESBB​​​=0

其中：

  • HAA=⟨ϕA∣H^∣ϕA⟩=αAH_{AA} = \langle\phi_A|\hat{H}|\phi_A\rangle = \alpha_AHAA​=⟨ϕA​∣H^∣ϕA​⟩=αA​（库仑积分）
  • HAB=⟨ϕA∣H^∣ϕB⟩=βH_{AB} = \langle\phi_A|\hat{H}|\phi_B\rangle = \betaHAB​=⟨ϕA​∣H^∣ϕB​⟩=β（共振积分）
  • SAB=⟨ϕA∣ϕB⟩S_{AB} = \langle\phi_A|\phi_B\rangleSAB​=⟨ϕA​∣ϕB​⟩（重叠积分）

同核双原子分子

对于同核双原子（HAA=HBB=αH_{AA} = H_{BB} = \alphaHAA​=HBB​=α），若忽略重叠（SAB=0S_{AB} = 0SAB​=0），得到：

E±=α±βE_{\pm} = \alpha \pm \betaE±​=α±β
  • 成键轨道（bonding MO）：ψ+=12(ϕA+ϕB)\psi_+ = \frac{1}{\sqrt{2}}(\phi_A + \phi_B)ψ+​=2​1​(ϕA​+ϕB​)，能量 E+=α+βE_+ = \alpha + \betaE+​=α+β（β<0\beta < 0β<0，能量降低）
  • 反键轨道（antibonding MO）：ψ−=12(ϕA−ϕB)\psi_- = \frac{1}{\sqrt{2}}(\phi_A - \phi_B)ψ−​=2​1​(ϕA​−ϕB​)，能量 E−=α−βE_- = \alpha - \betaE−​=α−β（能量升高）

成键轨道的电子密度在核间增大（建设性干涉），反键轨道在核间有节面（破坏性干涉）。

双原子分子的 MO 能级图

对于第二周期同核双原子分子，分子轨道按能量从低到高排列：

O2_22​, F2_22​, Ne2_22​（无 s-p 混杂）：

Li2_22​ 到 N2_22​（有 s-p 混杂）：

1σg<1σu∗<2σg<2σu∗<1πu<3σg<1πg∗<3σu∗1\sigma_g < 1\sigma_u^* < 2\sigma_g < 2\sigma_u^* < 1\pi_u < 3\sigma_g < 1\pi_g^* < 3\sigma_u^*1σg​<1σu∗​<2σg​<2σu∗​<1πu​<3σg​<1πg∗​<3σu∗​

注意：N2_22​ 及更轻的分子中，3σg3\sigma_g3σg​ 的能量高于 1πu1\pi_u1πu​（s-p 混杂效应）。

键级

键级（bond order）定义为：

BO=nbonding−nantibonding2\text{BO} = \frac{n_{bonding} - n_{antibonding}}{2}BO=2nbonding​−nantibonding​​

应用示例：

  • H2_22​：(1σg)2(1\sigma_g)^2(1σg​)2，BO = 1
  • He2_22​：(1σg)2(1σu∗)2(1\sigma_g)^2(1\sigma_u^*)^2(1σg​)2(1σu∗​)2，BO = 0（不存在）
  • O2_22​：⋯(3σg)2(1πg∗)2\cdots(3\sigma_g)^2(1\pi_g^*)^2⋯(3σg​)2(1πg∗​)2，BO = 2
  • N2_22​：⋯(1πu)4(3σg)2\cdots(1\pi_u)^4(3\sigma_g)^2⋯(1πu​)4(3σg​)2，BO = 3

O2_22​ 的顺磁性：MO 理论的辉煌胜利——O2_22​ 有两个未配对电子在 1πg∗1\pi_g^*1πg∗​ 轨道中（Hund 规则），这是价键理论无法自然解释的。

Hückel 分子轨道理论

基本假设

Hückel MO（HMO）理论专门处理平面共轭分子的 π\piπ 电子体系，做出极大简化：

  1. σ\sigmaσ-π\piπ 分离：只考虑 π\piπ 电子
  2. 每个碳原子贡献一个 pzp_zpz​ 轨道
  3. 库仑积分 α\alphaα 相同（所有碳原子等价时）
  4. 共振积分：相邻原子 β\betaβ，非相邻原子 0
  5. 重叠积分：Sij=δijS_{ij} = \delta_{ij}Sij​=δij​

乙烯（ethylene）

两个 ppp 轨道的 LCAO，久期方程：

∣α−Eββα−E∣=0\begin{vmatrix} \alpha - E & \beta \\ \beta & \alpha - E \end{vmatrix} = 0​α−Eβ​βα−E​​=0

令 x=(α−E)/βx = (\alpha - E)/\betax=(α−E)/β：

x2−1=0⇒x=±1x^2 - 1 = 0 \Rightarrow x = \pm 1x2−1=0⇒x=±1
E1=α+β（成键）,E2=α−β（反键）E_1 = \alpha + \beta \text{（成键）}, \quad E_2 = \alpha - \beta \text{（反键）}E1​=α+β（成键）,E2​=α−β（反键）

π\piπ 键能 = 2(α+β)−2α=2β2(\alpha + \beta) - 2\alpha = 2\beta2(α+β)−2α=2β

丁二烯（butadiene）

四个 ppp 轨道，久期行列式：

∣x1001x1001x1001x∣=0\begin{vmatrix} x & 1 & 0 & 0 \\ 1 & x & 1 & 0 \\ 0 & 1 & x & 1 \\ 0 & 0 & 1 & x \end{vmatrix} = 0​x100​1x10​01x1​001x​​=0

解得：x=±0.618,±1.618x = \pm 0.618, \pm 1.618x=±0.618,±1.618

四个能级的 π\piπ 电子总能量为 4α+4.472β4\alpha + 4.472\beta4α+4.472β，离域能（与两个孤立双键的能差）= 0.472∣β∣0.472|\beta|0.472∣β∣。这就是共轭稳定化的量子力学起源。

苯（benzene）与 Hückel 规则

六个 ppp 轨道的环形排列，能级为：

Ek=α+2βcos⁡2πk6,k=0,±1,±2,3E_k = \alpha + 2\beta\cos\frac{2\pi k}{6}, \quad k = 0, \pm 1, \pm 2, 3Ek​=α+2βcos62πk​,k=0,±1,±2,3

能级：α+2β\alpha + 2\betaα+2β（1重）、α+β\alpha + \betaα+β（2重）、α−β\alpha - \betaα−β（2重）、α−2β\alpha - 2\betaα−2β（1重）

6 个 π\piπ 电子占据前三个能级，π\piπ 电子总能量 = 6α+8β6\alpha + 8\beta6α+8β，离域能 = 2∣β∣2|\beta|2∣β∣（约 150 kJ/mol）。

Hückel 规则（4n+24n+24n+2 规则）：含 4n+24n+24n+2 个 π\piπ 电子的平面环状共轭分子具有芳香性稳定化。这是因为在环形 MO 能级图中，4n+24n+24n+2 恰好填满所有成键轨道。

对称性与群论在 MO 理论中的应用

分子对称性

分子的对称性由其点群（point group）描述。常见点群：

  • C2vC_{2v}C2v​：H2_22​O
  • C3vC_{3v}C3v​：NH3_33​
  • D∞hD_{\infty h}D∞h​：同核双原子（N2_22​, O2_22​）
  • D6hD_{6h}D6h​：苯
  • TdT_dTd​：CH4_44​

对称性匹配的 MO

群论的核心应用：只有属于同一不可约表示的原子轨道才能有效组合形成分子轨道。

例如，在 H2_22​O（C2vC_{2v}C2v​）中：

  • O 的 2s2s2s 轨道属于 a1a_1a1​ 表示
  • O 的 2pz2p_z2pz​ 属于 a1a_1a1​，2px2p_x2px​ 属于 b1b_1b1​，2py2p_y2py​ 属于 b2b_2b2​
  • 两个 H 的 1s1s1s 轨道可以组成 a1a_1a1​（同相）和 b2b_2b2​（反相）的对称适应线性组合

因此 a1a_1a1​ 对称性下的 MO 由 O(2s2s2s) + O(2pz2p_z2pz​) + H(1s1s1s+1s1s1s) 组合，b2b_2b2​ 对称性下由 O(2py2p_y2py​) + H(1s1s1s-1s1s1s) 组合，而 b1b_1b1​ 下只有 O(2px2p_x2px​)——它是非键轨道（lone pair）。

选择定则

跃迁偶极矩 ⟨ψf∣μ^∣ψi⟩\langle\psi_f|\hat{\mu}|\psi_i\rangle⟨ψf​∣μ^​∣ψi​⟩ 不为零的条件由群论判定：直积 Γf⊗Γμ⊗Γi\Gamma_f \otimes \Gamma_\mu \otimes \Gamma_iΓf​⊗Γμ​⊗Γi​ 必须包含全对称表示 A1A_1A1​。这决定了哪些电子跃迁是"允许"的（出现在光谱中）。

前线分子轨道理论

HOMO 与 LUMO

Fukui（1952，1981年 Nobel 化学奖）提出：化学反应性主要由前线轨道决定——最高占据分子轨道（HOMO）和最低未占分子轨道（LUMO）。

  • 亲核试剂：通过 HOMO 提供电子
  • 亲电试剂：通过 LUMO 接受电子
  • 反应活性：HOMO-LUMO 能量差越小，反应越容易发生

Woodward-Hoffmann 规则

轨道对称性守恒原则指出：协同反应（周环反应）的允许/禁阻由反应物和产物前线轨道的对称性匹配决定。

电环化反应：

  • 加热条件：顺旋（conrotatory）或对旋（disrotatory）由 HOMO 对称性决定
  • 光照条件：由激发态 HOMO（即基态 LUMO）对称性决定

Diels-Alder 反应：双烯 HOMO 与亲双烯体 LUMO 的对称性匹配——热允许的 [4+2] 环加成。

配体场理论

过渡金属配合物的 MO 处理

配体场理论（Ligand Field Theory）是晶体场理论的 MO 推广，考虑了金属-配体共价作用。

对于八面体配合物 ML6_66​：

  • 金属 ddd 轨道在 OhO_hOh​ 对称下分裂为 t2gt_{2g}t2g​（dxy,dxz,dyzd_{xy}, d_{xz}, d_{yz}dxy​,dxz​,dyz​）和 ege_geg​（dz2,dx2−y2d_{z^2}, d_{x^2-y^2}dz2​,dx2−y2​）
  • 配体场分裂能 Δo=10Dq\Delta_o = 10DqΔo​=10Dq
  • 分裂能大小决定了高自旋/低自旋构型

光谱化学序列（spectrochemical series）反映配体场强：

I−<Br−<Cl−<F−<OH−<H2O<NH3<en<NO2−<CN−<COI^- < Br^- < Cl^- < F^- < OH^- < H_2O < NH_3 < en < NO_2^- < CN^- < COI−<Br−<Cl−<F−<OH−<H2​O<NH3​<en<NO2−​<CN−<CO

弱场配体 → 小 Δo\Delta_oΔo​ → 高自旋；强场配体 → 大 Δo\Delta_oΔo​ → 低自旋。

配合物的颜色与光谱

过渡金属配合物的颜色源于 ddd-ddd 跃迁。在 OhO_hOh​ 对称下，t2g→egt_{2g} \to e_gt2g​→eg​ 跃迁的能量等于 Δo\Delta_oΔo​，对应可见光区吸收。

例如 [Ti(H2_22​O)6_66​]3+^{3+}3+（d1d^1d1 构型）：

  • 吸收峰在 ~500 nm（绿色光）
  • 透射互补色（紫色）
  • Δo≈20000 cm−1≈240 kJ/mol\Delta_o \approx 20000 \text{ cm}^{-1} \approx 240 \text{ kJ/mol}Δo​≈20000 cm−1≈240 kJ/mol

密度与分子轨道

电子密度

分子轨道理论直接给出电子密度：

ρ(r)=∑ini∣ψi(r)∣2\rho(\mathbf{r}) = \sum_i n_i |\psi_i(\mathbf{r})|^2ρ(r)=i∑​ni​∣ψi​(r)∣2

其中 nin_ini​ 为轨道占据数。电子密度是可以实验观测的量（X 射线衍射），提供了 MO 理论的直接实验验证。

Mulliken 布居分析

将电子密度分配到各原子中心，得到原子电荷和键级。对于 LCAO-MO ψk=∑icikϕi\psi_k = \sum_i c_{ik}\phi_iψk​=∑i​cik​ϕi​：

Mulliken 布居：Pij=∑knkcikcjkSijP_{ij} = \sum_k n_k c_{ik}c_{jk}S_{ij}Pij​=∑k​nk​cik​cjk​Sij​

原子 A 上的电子数：NA=∑i∈A∑jPijN_A = \sum_{i\in A}\sum_j P_{ij}NA​=∑i∈A​∑j​Pij​

Mulliken 布居分析虽然最简单，但有基组依赖性大等缺点。更现代的方法包括 Natural Bond Orbital（NBO）分析和 Atoms in Molecules（AIM）理论。

小结

分子轨道理论从原子轨道的线性组合出发，通过量子力学变分法构建分子轨道，为理解化学键、分子光谱、反应活性提供了统一框架。从简单的 Hückel 理论到严格的从头算方法，从对称性分析到前线轨道理论，MO 理论在定性理解和定量计算两个层面都具有核心地位。它不仅解释了 O2_22​ 的顺磁性、苯的芳香性等经典问题，也为有机反应机理（Woodward-Hoffmann 规则）和无机配位化学（配体场理论）提供了深刻的理论基础。
