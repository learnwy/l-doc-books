速率方程与反应机理（Rate Laws and Reaction Mechanisms）

化学动力学的核心框架

化学动力学的首要任务是建立反应速率与反应物浓度之间的定量关系——速率方程（rate law）。速率方程不能从化学方程式的化学计量关系直接写出，而必须通过实验确定。一旦获得速率方程，就可以推断反应的微观机理（mechanism），即反应在分子层面实际经历的基元步骤序列。

反应速率的定义

基本定义

对于一般化学反应：

aA+bB→cC+dDaA + bB \to cC + dDaA+bB→cC+dD

反应速率定义为：

v=−1ad[A]dt=−1bd[B]dt=1cd[C]dt=1dd[D]dtv = -\frac{1}{a}\frac{d[A]}{dt} = -\frac{1}{b}\frac{d[B]}{dt} = \frac{1}{c}\frac{d[C]}{dt} = \frac{1}{d}\frac{d[D]}{dt}v=−a1​dtd[A]​=−b1​dtd[B]​=c1​dtd[C]​=d1​dtd[D]​

这种定义方式确保反应速率不依赖于选择哪个物种来表示。速率 vvv 的单位通常为 mol/(L·s) 或 M/s。

速率方程的一般形式

实验表明，反应速率通常可以表示为反应物浓度幂次的乘积：

v=k[A]m[B]nv = k[A]^m[B]^nv=k[A]m[B]n

其中 kkk 为速率常数（rate constant），mmm 和 nnn 分别为对 A 和 B 的反应级数（reaction order）。总反应级数为 m+nm + nm+n。

需要强调的是：反应级数是实验量，不等于化学计量系数。只有基元反应（elementary reaction）的速率方程可以直接从化学计量式写出。

积分速率方程

零级反应

v=kv = kv=k
[A]=[A]0−kt[A] = [A]_0 - kt[A]=[A]0​−kt

半衰期：t1/2=[A]02kt_{1/2} = \frac{[A]_0}{2k}t1/2​=2k[A]0​​

零级反应的特征：浓度随时间线性下降；半衰期与初始浓度成正比。常见于表面催化反应（催化剂表面饱和时）和某些酶催化反应（底物浓度远大于 KmK_mKm​ 时）。

一级反应

v=k[A]v = k[A]v=k[A]
[A]=[A]0e−kt[A] = [A]_0 e^{-kt}[A]=[A]0​e−kt
ln⁡[A]=ln⁡[A]0−kt\ln[A] = \ln[A]_0 - ktln[A]=ln[A]0​−kt

半衰期：t1/2=ln⁡2k=0.693kt_{1/2} = \frac{\ln 2}{k} = \frac{0.693}{k}t1/2​=kln2​=k0.693​

一级反应的显著特征：半衰期与初始浓度无关。放射性衰变是一级动力学的经典实例。碳-14 的半衰期为 5730 年，无论样品含有多少 14^{14}14C，每经过 5730 年都恰好衰变一半。

二级反应

类型一：2A→products2A \to \text{products}2A→products，v=k[A]2v = k[A]^2v=k[A]2

1[A]=1[A]0+kt\frac{1}{[A]} = \frac{1}{[A]_0} + kt[A]1​=[A]0​1​+kt

半衰期：t1/2=1k[A]0t_{1/2} = \frac{1}{k[A]_0}t1/2​=k[A]0​1​

类型二：A+B→productsA + B \to \text{products}A+B→products，v=k[A][B]v = k[A][B]v=k[A][B]

当 [A]0≠[B]0[A]_0 \neq [B]_0[A]0​=[B]0​ 时：

1[B]0−[A]0ln⁡[A]0[B][B]0[A]=kt\frac{1}{[B]_0 - [A]_0}\ln\frac{[A]_0[B]}{[B]_0[A]} = kt[B]0​−[A]0​1​ln[B]0​[A][A]0​[B]​=kt

确定反应级数的实验方法

初始速率法：测量不同初始浓度下的初始反应速率，通过对数关系确定级数。

若 v0=k[A]0mv_0 = k[A]_0^mv0​=k[A]0m​，则：

v0′v0=([A]0′[A]0)m\frac{v_0'}{v_0} = \left(\frac{[A]_0'}{[A]_0}\right)^mv0​v0′​​=([A]0​[A]0′​​)m
m=ln⁡(v0′/v0)ln⁡([A]0′/[A]0)m = \frac{\ln(v_0'/v_0)}{\ln([A]_0'/[A]_0)}m=ln([A]0′​/[A]0​)ln(v0′​/v0​)​

积分法：将浓度-时间数据代入不同级数的积分速率方程，看哪个给出线性关系。

隔离法：使某一反应物大大过量（pseudo-order 条件），使速率方程退化为对目标物种的表观级数方程。

温度对反应速率的影响

Arrhenius 方程

Arrhenius（1889）发现，速率常数与温度之间存在指数关系：

k=Ae−Ea/RTk = A e^{-E_a/RT}k=Ae−Ea​/RT

取对数：

ln⁡k=ln⁡A−EaRT\ln k = \ln A - \frac{E_a}{RT}lnk=lnA−RTEa​​

其中：

  • AAA：指前因子（pre-exponential factor 或 frequency factor），反映碰撞频率和空间取向因素
  • EaE_aEa​：活化能（activation energy），反应需要克服的能量壁垒

从两个温度下的速率常数可以求活化能：

ln⁡k2k1=EaR(1T1−1T2)\ln\frac{k_2}{k_1} = \frac{E_a}{R}\left(\frac{1}{T_1} - \frac{1}{T_2}\right)lnk1​k2​​=REa​​(T1​1​−T2​1​)

活化能的物理意义

活化能 EaE_aEa​ 是反应物从初态到过渡态需要提供的最小能量。典型值：

  • 无催化剂的均相反应：50-200 kJ/mol
  • 催化反应：20-80 kJ/mol
  • 扩散控制反应：10-20 kJ/mol

经验规则：EaE_aEa​ 每增加约 10 kJ/mol，室温下反应速率降低约 50 倍。

非 Arrhenius 行为

某些反应偏离简单 Arrhenius 行为：

k=ATne−Ea/RTk = A T^n e^{-E_a/RT}k=ATne−Ea​/RT

修正的 Arrhenius 方程引入温度幂次项 TnT^nTn。这通常出现在宽温度范围内的气相反应中，反映了过渡态与反应物之间热容差异的影响。

反应机理

基元反应与复合反应

基元反应（elementary reaction）是在分子层面一步完成的反应。基元反应的分子数（molecularity）等于参与碰撞的分子数：

  • 单分子反应（unimolecular）：A → products
  • 双分子反应（bimolecular）：A + B → products
  • 三分子反应（termolecular）：A + B + C → products（极为罕见）

重要原则：只有基元反应的速率方程可以直接由化学计量关系写出。

稳态近似

对于连续反应中的中间体，当其生成速率等于消耗速率时（浓度不随时间显著变化），可以应用稳态近似（Steady-State Approximation, SSA）：

d[I]dt≈0\frac{d[I]}{dt} \approx 0dtd[I]​≈0

实例：臭氧分解机理

实验速率方程：v=kobs[O3]2[O2]v = k_{obs}\frac{[\text{O}_3]^2}{[\text{O}_2]}v=kobs​[O2​][O3​]2​

提出机理：

O3⇌k1k−1O2+O（快速平衡）\text{O}_3 \underset{k_{-1}}{\stackrel{k_1}{\rightleftharpoons}} \text{O}_2 + \text{O} \quad \text{（快速平衡）}O3​k−1​⇌k1​​​O2​+O（快速平衡）

O+O3→k22O2（慢步骤）\text{O} + \text{O}_3 \xrightarrow{k_2} 2\text{O}_2 \quad \text{（慢步骤）}O+O3​k2​​2O2​（慢步骤）

对中间体 O 原子应用稳态近似：

d[O]dt=k1[O3]−k−1[O2][O]−k2[O][O3]=0\frac{d[\text{O}]}{dt} = k_1[\text{O}_3] - k_{-1}[\text{O}_2][\text{O}] - k_2[\text{O}][\text{O}_3] = 0dtd[O]​=k1​[O3​]−k−1​[O2​][O]−k2​[O][O3​]=0

解得：[O]=k1[O3]k−1[O2]+k2[O3][\text{O}] = \frac{k_1[\text{O}_3]}{k_{-1}[\text{O}_2] + k_2[\text{O}_3]}[O]=k−1​[O2​]+k2​[O3​]k1​[O3​]​

若快速前平衡（k−1[O2]≫k2[O3]k_{-1}[\text{O}_2] \gg k_2[\text{O}_3]k−1​[O2​]≫k2​[O3​]）：

[O]≈k1[O3]k−1[O2][\text{O}] \approx \frac{k_1[\text{O}_3]}{k_{-1}[\text{O}_2]}[O]≈k−1​[O2​]k1​[O3​]​
v=k2[O][O3]=k1k2k−1[O3]2[O2]v = k_2[\text{O}][\text{O}_3] = \frac{k_1 k_2}{k_{-1}}\frac{[\text{O}_3]^2}{[\text{O}_2]}v=k2​[O][O3​]=k−1​k1​k2​​[O2​][O3​]2​

与实验一致，kobs=k1k2/k−1k_{obs} = k_1 k_2 / k_{-1}kobs​=k1​k2​/k−1​。

速率决定步骤

在多步反应机理中，最慢的一步（速率决定步骤，rate-determining step）控制整体反应速率。类比于串联电路中电阻最大的元件决定总电流。

但需要注意：并非所有反应都有单一的速率决定步骤。当两步的速率相当时，需要完整的动力学分析（如数值积分或稳态近似）。

Lindemann-Hinshelwood 机理

单分子反应看似矛盾——一个分子如何"自发"反应？Lindemann（1922）提出了解释：

A+M⇌k1k−1A∗+M（碰撞活化/去活化）A + M \underset{k_{-1}}{\stackrel{k_1}{\rightleftharpoons}} A^* + M \quad \text{（碰撞活化/去活化）}A+Mk−1​⇌k1​​​A∗+M（碰撞活化/去活化）
A∗→k2products（单分子分解）A^* \xrightarrow{k_2} \text{products} \quad \text{（单分子分解）}A∗k2​​products（单分子分解）

其中 MMM 为任意碰撞伙伴（包括 A 本身）。

对 A∗A^*A∗ 应用稳态近似：

[A∗]=k1[A][M]k−1[M]+k2[A^*] = \frac{k_1[A][M]}{k_{-1}[M] + k_2}[A∗]=k−1​[M]+k2​k1​[A][M]​
v=k2[A∗]=k1k2[A][M]k−1[M]+k2v = k_2[A^*] = \frac{k_1 k_2[A][M]}{k_{-1}[M] + k_2}v=k2​[A∗]=k−1​[M]+k2​k1​k2​[A][M]​

两种极限：

  • 高压极限（k−1[M]≫k2k_{-1}[M] \gg k_2k−1​[M]≫k2​）：v=k1k2k−1[A]v = \frac{k_1 k_2}{k_{-1}}[A]v=k−1​k1​k2​​[A]，表观一级
  • 低压极限（k2≫k−1[M]k_2 \gg k_{-1}[M]k2​≫k−1​[M]）：v=k1[A][M]v = k_1[A][M]v=k1​[A][M]，表观二级

这解释了单分子反应在不同压力下呈现不同反应级数的实验观察。

复杂反应动力学

连续反应

A→k1B→k2CA \xrightarrow{k_1} B \xrightarrow{k_2} CAk1​​Bk2​​C

中间产物 B 的浓度变化：

[B]=k1[A]0k2−k1(e−k1t−e−k2t)[B] = \frac{k_1[A]_0}{k_2 - k_1}(e^{-k_1 t} - e^{-k_2 t})[B]=k2​−k1​k1​[A]0​​(e−k1​t−e−k2​t)

B 的最大浓度出现在：

tmax=ln⁡(k2/k1)k2−k1t_{max} = \frac{\ln(k_2/k_1)}{k_2 - k_1}tmax​=k2​−k1​ln(k2​/k1​)​

平行反应

A→k1B,A→k2CA \xrightarrow{k_1} B, \quad A \xrightarrow{k_2} CAk1​​B,Ak2​​C

选择性：[B][C]=k1k2\frac{[B]}{[C]} = \frac{k_1}{k_2}[C][B]​=k2​k1​​

温度对选择性的影响取决于两条路径活化能的差异。若 Ea1>Ea2E_{a1} > E_{a2}Ea1​>Ea2​，升温有利于产物 B（高活化能路径对温度更敏感）。

链式反应

自由基链式反应包含三个阶段：

  • 引发（initiation）：产生自由基
  • 传播（propagation）：自由基参与反应并再生
  • 终止（termination）：自由基两两结合

以 H2_22​-Br2_22​ 反应为经典实例，其复杂的速率方程：

v=k[H2][Br2]1/21+k′[HBr]/[Br2]v = \frac{k[H_2][Br_2]^{1/2}}{1 + k'[HBr]/[Br_2]}v=1+k′[HBr]/[Br2​]k[H2​][Br2​]1/2​

可以从链式机理严格推导得出，是动力学理论预测能力的出色展示。

小结

速率方程与反应机理的关系是化学动力学的核心线索：宏观可观测的速率方程是微观分子事件的总体表现。通过积分速率方程拟合实验数据确定反应级数和速率常数，再结合稳态近似等方法从候选机理推导理论速率方程并与实验对照——这一循环往复的过程体现了实验与理论紧密结合的物理化学研究范式。Arrhenius 方程则提供了从宏观温度效应推断微观能量壁垒的桥梁，为过渡态理论奠定了实验基础。
