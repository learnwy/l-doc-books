图片与字体优化

图片：Web 性能的最大挑战

图片通常占据网页总传输体积的 50% 以上。一张未优化的 hero 图片可能就有 2-5 MB，而同样视觉效果的优化版本可能只需 100-200 KB。图片优化是投入产出比最高的性能优化手段之一。

响应式图片
不同设备的屏幕尺寸差异巨大——在 375px 宽的手机上加载 2400px 宽的图片是极大的浪费。响应式图片确保每种设备只加载适合其屏幕的图片尺寸。

图片压缩与处理流水线
构建时图片优化
import sharp from 'sharp';
import { glob } from 'glob';
import path from 'path';
import fs from 'fs';

interface ImageConfig {
  widths: number[];
  formats: Array<'webp' | 'avif' | 'jpeg'>;
  quality: Record<string, number>;
}

const config: ImageConfig = {
  widths: [400, 800, 1200, 1600],
  formats: ['avif', 'webp', 'jpeg'],
  quality: { avif: 50, webp: 75, jpeg: 80 },
};

async function optimizeImage(inputPath: string, outputDir: string): Promise<void> {
  const image = sharp(inputPath);
  const metadata = await image.metadata();
  const baseName = path.basename(inputPath, path.extname(inputPath));

  for (const width of config.widths) {
    if (metadata.width && width > metadata.width) continue;

    for (const format of config.formats) {
      const outputPath = path.join(outputDir, `${baseName}-${width}.${format}`);
      await sharp(inputPath).resize(width).toFormat(format, { quality: config.quality[format] }).toFile(outputPath);
    }
  }
}

async function processAllImages(): Promise<void> {
  const images = await glob('src/images/**/*.{jpg,jpeg,png}');
  const outputDir = 'public/images/optimized';
  fs.mkdirSync(outputDir, { recursive: true });

  let totalSaved = 0;

  for (const img of images) {
    const originalSize = fs.statSync(img).size;
    await optimizeImage(img, outputDir);

    const optimizedFiles = await glob(path.join(outputDir, `${path.basename(img, path.extname(img))}-*`));
    const optimizedSize = optimizedFiles.reduce((sum, f) => sum + fs.statSync(f).size, 0);

    totalSaved += originalSize - optimizedSize / optimizedFiles.length;
  }

  console.log(`Total saved: ${(totalSaved / 1024 / 1024).toFixed(2)} MB`);
}


图片加载优化策略
渐进式图片加载（LQIP）
LQIP（Low Quality Image Placeholder）先显示极小的模糊缩略图，再渐进切换到完整图片：


import { useState } from 'react';

interface ProgressiveImageProps {
  src: string;
  placeholder: string;
  alt: string;
  width: number;
  height: number;
}

function ProgressiveImage({ src, placeholder, alt, width, height }: ProgressiveImageProps) {
  const [isLoaded, setIsLoaded] = useState(false);

  return (
    <div style={{ position: 'relative', width, height, overflow: 'hidden' }}>
      <img
        src={placeholder}
        alt=""
        aria-hidden="true"
        style={{
          position: 'absolute',
          inset: 0,
          width: '100%',
          height: '100%',
          objectFit: 'cover',
          filter: 'blur(20px)',
          transform: 'scale(1.1)',
          opacity: isLoaded ? 0 : 1,
          transition: 'opacity 0.5s ease',
        }}
      />
      <img
        src={src}
        alt={alt}
        width={width}
        height={height}
        loading="lazy"
        onLoad={() => setIsLoaded(true)}
        style={{
          width: '100%',
          height: '100%',
          objectFit: 'cover',
          opacity: isLoaded ? 1 : 0,
          transition: 'opacity 0.5s ease',
        }}
      />
    </div>
  );
}

字体子集化
完整的中文字体可能高达 10-20 MB。通过子集化只包含页面实际使用的字符，可以将体积降至几十 KB。


import Fontmin from 'fontmin';

async function subsetFont(inputFont: string, outputDir: string, text: string): Promise<void> {
  const fontmin = new Fontmin()
    .src(inputFont)
    .use(Fontmin.glyph({ text, hinting: false }))
    .use(Fontmin.ttf2woff2())
    .dest(outputDir);

  await new Promise<void>((resolve, reject) => {
    fontmin.run((err: Error | null) => {
      if (err) reject(err);
      else resolve();
    });
  });
}
系统字体栈
在不需要自定义字体的场景下，使用系统字体栈可以完全消除字体加载问题：


:root {
  font-family:
    system-ui,
    -apple-system,
    BlinkMacSystemFont,
    'Segoe UI',
    Roboto,
    'Helvetica Neue',
    Arial,
    'Noto Sans',
    sans-serif,
    'Apple Color Emoji',
    'Segoe UI Emoji';
}

小结
    

  • 图片格式优先选择 WebP，追求极致压缩选择 AVIF，通过 <picture> 实现格式降级。
    • 

  • 响应式图片使用 srcset + sizes 确保每种设备只加载适合的尺寸。
    • 

  • LQIP 渐进式图片加载能在保证体验的同时减少等待感。
    • 

  • 所有图片必须设置 width 和 height（或 aspect-ratio）来防止 CLS。
    • 

  • 字体使用 font-display: swap + preload + WOFF2 格式作为基础优化方案。
    • 

  • 中文字体通过子集化可以将体积从数十 MB 降至几十 KB。
