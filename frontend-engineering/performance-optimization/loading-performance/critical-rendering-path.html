关键渲染路径

什么是关键渲染路径

关键渲染路径（Critical Rendering Path, CRP）是浏览器将 HTML、CSS 和 JavaScript 转换为屏幕上可见像素所经历的必要步骤序列。优化关键渲染路径的核心目标是尽快完成首次有意义的渲染，让用户不再面对白屏。

关键渲染路径的三个核心度量维度：






维度
含义
优化目标





关键资源数量
阻塞首次渲染的资源个数
尽量减少




关键路径长度
获取所有关键资源所需的往返次数
尽量缩短




关键资源体积
所有关键资源的传输总大小
尽量减小







渲染阻塞资源分析
CSS 的渲染阻塞
CSS 默认阻塞渲染。浏览器必须等待 CSSOM 构建完成才能开始渲染。但并非所有 CSS 都需要阻塞首屏渲染。


<link rel="stylesheet" href="/critical.css" />

<link rel="stylesheet" href="/print.css" media="print" />
<link rel="stylesheet" href="/landscape.css" media="(orientation: landscape)" />
<link rel="stylesheet" href="/large.css" media="(min-width: 1024px)" />
JavaScript 的解析阻塞
同步 <script> 标签会阻塞 HTML 解析。浏览器遇到 <script> 时必须停下来下载并执行脚本，然后才能继续解析后续的 HTML。


<script src="/app.js"></script>

<script src="/app.js" defer></script>

<script src="/app.js" async></script>


内联关键 CSS
内联关键 CSS（Critical CSS）是优化关键渲染路径最有效的策略之一。将首屏渲染所需的最少 CSS 直接内联到 HTML 中，避免额外的网络请求。

自动提取关键 CSS
import { generate } from 'critical';

async function extractCriticalCSS(): Promise<void> {
  const result = await generate({
    src: 'https://localhost:3000',
    width: 1300,
    height: 900,
    inline: true,
    minify: true,
    extract: true,
    dimensions: [
      { width: 375, height: 667 },
      { width: 1300, height: 900 },
    ],
  });

  console.log('Critical CSS size:', result.css.length, 'bytes');
  console.log('Uncritical CSS size:', result.uncritical.length, 'bytes');
}

interface CRPAnalysis {
  criticalResources: Array<{
    url: string;
    type: 'css' | 'js' | 'font';
    size: number;
    blocking: boolean;
  }>;
  criticalPathLength: number;
  totalCriticalSize: number;
}

function analyzeCRP(): CRPAnalysis {
  const resources = performance.getEntriesByType('resource') as PerformanceResourceTiming[];

  const criticalResources = resources
    .filter((r) => {
      const isCriticalCSS =
        r.initiatorType === 'link' &&
        r.startTime < performance.getEntriesByName('first-contentful-paint')[0]?.startTime;
      const isCriticalJS = r.initiatorType === 'script' && !r.name.includes('async') && !r.name.includes('defer');
      return isCriticalCSS || isCriticalJS;
    })
    .map((r) => ({
      url: r.name,
      type: r.initiatorType === 'link' ? ('css' as const) : ('js' as const),
      size: r.transferSize,
      blocking: true,
    }));

  const maxEndTime = Math.max(
    ...criticalResources.map((_, i) => {
      const entry = resources[i];
      return entry ? entry.responseEnd : 0;
    }),
  );

  return {
    criticalResources,
    criticalPathLength: criticalResources.length,
    totalCriticalSize: criticalResources.reduce((sum, r) => sum + r.size, 0),
  };
}

小结
    

  • 关键渲染路径是浏览器从接收 HTML 到首次渲染经历的所有必要步骤。
    • 

  • 优化三个维度：减少关键资源数量、缩短关键路径长度、减小关键资源体积。
    • 

  • CSS 阻塞渲染——使用内联关键 CSS + 异步加载非关键 CSS 策略。
    • 

  • JavaScript 阻塞解析——使用 defer/async + 代码分割策略。
    • 

  • SSR/SSG 是架构级别的关键渲染路径优化方案，能从根本上缩短首屏渲染时间。
