加载性能 简介

加载性能是用户对 Web 应用的第一印象。从输入 URL 到页面可交互的这段时间里，每一毫秒的延迟都在考验用户的耐心。研究表明，53% 的移动端用户会在页面加载超过 3 秒时离开。加载性能优化的目标是尽快将有意义的内容呈现给用户，并在最短时间内让页面进入可交互状态。

第一节"关键渲染路径"分析从 HTML 接收到首次有意义渲染之间的所有阻塞环节。理解哪些资源阻塞了渲染、如何缩短关键路径长度、如何减少关键资源数量和体积，是加载性能优化的核心知识。

第二节"资源加载策略"系统介绍浏览器提供的资源提示机制——preload、prefetch、preconnect、dns-prefetch。合理使用这些提示能够让浏览器提前发现和加载关键资源，显著缩短资源加载的等待时间。

第三节"懒加载与预取"探讨按需加载的策略设计。路由级别的代码分割、组件级别的懒加载、Intersection Observer 驱动的图片懒加载，以及基于用户行为预测的智能预取——这些策略让应用只加载用户当前需要的内容。

第四节"图片与字体优化"聚焦于前端最大的两类静态资源。现代图片格式（WebP/AVIF）的选择、响应式图片的适配策略、字体加载的优化方案——图片和字体往往占据了页面总传输体积的 60% 以上，优化它们能带来最直观的性能提升。
