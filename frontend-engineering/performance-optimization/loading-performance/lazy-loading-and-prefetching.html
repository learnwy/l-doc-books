懒加载与预取

按需加载的核心理念

现代 Web 应用的 JavaScript bundle 体积动辄数 MB，如果在页面初始加载时就下载全部代码，会严重影响首屏性能。懒加载（Lazy Loading）的核心理念是"只加载用户当前需要的内容"，将非首屏内容的加载推迟到用户真正需要时。



路由级代码分割
路由级代码分割是最常见的懒加载策略。每个路由对应一个独立的 chunk，用户只在访问该路由时才下载对应的代码。


import { lazy, Suspense } from "react";
import { Routes, Route } from "react-router-dom";

const Home = lazy(() => import("./pages/Home"));
const Products = lazy(() => import("./pages/Products"));
const ProductDetail = lazy(() => import("./pages/ProductDetail"));
const Cart = lazy(() => import("./pages/Cart"));
const Checkout = lazy(() => import("./pages/Checkout"));
const Dashboard = lazy(() => import("./pages/Dashboard"));

function App() {
  return (
    <Suspense fallback={<PageSkeleton />}>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/products" element={<Products />} />
        <Route path="/products/:id" element={<ProductDetail />} />
        <Route path="/cart" element={<Cart />} />
        <Route path="/checkout" element={<Checkout />} />
        <Route path="/dashboard" element={<Dashboard />} />
      </Routes>
    </Suspense>
  );
}

组件级懒加载
除了路由级别，某些重型组件也适合懒加载——特别是那些不在首屏可视区域内的组件，或者只在特定交互后才需要的组件。

const RichTextEditor = lazy(() => import("./components/RichTextEditor"));

带重试的懒加载
网络不稳定时，动态 import 可能失败。添加重试机制可以提升可靠性：


function lazyWithRetry<T extends React.ComponentType<any>>(
  importFn: () => Promise<{ default: T }>,
  retries: number = 3,
  delay: number = 1000,
): React.LazyExoticComponent<T> {
  return lazy(() => {
    const attempt = (remainingRetries: number): Promise<{ default: T }> =>
      importFn().catch((error: Error) => {
        if (remainingRetries <= 0) throw error;
        return new Promise<{ default: T }>((resolve) => {
          setTimeout(() => resolve(attempt(remainingRetries - 1)), delay);
        });
      });

    return attempt(retries);
  });
}

const HeavyComponent = lazyWithRetry(() => import('./components/HeavyComponent'));


Intersection Observer 图片懒加载
原生 loading="lazy" 属性提供了最简单的图片懒加载方案，但 Intersection Observer 提供了更精细的控制能力。


原生懒加载

<iframe src="/embed" loading="lazy" width="600" height="400"></iframe>
自定义 Intersection Observer
interface LazyImageOptions {
  rootMargin?: string;
  threshold?: number;
  onLoad?: (img: HTMLImageElement) => void;
}

function setupLazyImages(options: LazyImageOptions = {}): () => void {
  const { rootMargin = '200px 0px', threshold = 0.01, onLoad } = options;

  const observer = new IntersectionObserver(
    (entries) => {
      for (const entry of entries) {
        if (entry.isIntersecting) {
          const img = entry.target as HTMLImageElement;
          const src = img.dataset.src;
          const srcset = img.dataset.srcset;

          if (src) img.src = src;
          if (srcset) img.srcset = srcset;

          img.addEventListener('load', () => {
            img.classList.add('loaded');
            onLoad?.(img);
          });

          observer.unobserve(img);
        }
      }
    },
    { rootMargin, threshold },
  );

  const images = document.querySelectorAll<HTMLImageElement>('img[data-src]');
  images.forEach((img) => observer.observe(img));

  return () => observer.disconnect();
}
React 懒加载图片组件
import { useRef, useState, useEffect } from 'react';

interface LazyImageProps {
  src: string;
  alt: string;
  width: number;
  height: number;
  placeholder?: string;
  className?: string;
}

function LazyImage({ src, alt, width, height, placeholder, className }: LazyImageProps) {
  const imgRef = useRef<HTMLImageElement>(null);
  const [isLoaded, setIsLoaded] = useState(false);
  const [isInView, setIsInView] = useState(false);

  useEffect(() => {
    const img = imgRef.current;
    if (!img) return;

    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          setIsInView(true);
          observer.disconnect();
        }
      },
      { rootMargin: '200px' },
    );

    observer.observe(img);
    return () => observer.disconnect();
  }, []);

  return (
    <div
      style={{
        width,
        height,
        backgroundColor: '#f0f0f0',
        overflow: 'hidden',
        position: 'relative',
      }}
      className={className}
    >
      {placeholder && !isLoaded && (
        <img
          src={placeholder}
          alt=""
          style={{ width: '100%', height: '100%', objectFit: 'cover', filter: 'blur(10px)' }}
        />
      )}
      <img
        ref={imgRef}
        src={isInView ? src : undefined}
        alt={alt}
        width={width}
        height={height}
        onLoad={() => setIsLoaded(true)}
        style={{
          opacity: isLoaded ? 1 : 0,
          transition: 'opacity 0.3s ease',
          position: placeholder ? 'absolute' : 'static',
          top: 0,
          left: 0,
          width: '100%',
          height: '100%',
          objectFit: 'cover',
        }}
      />
    </div>
  );
}


智能预取策略
预取的目标是在用户需要之前就准备好资源，实现"即点即开"的体验。关键在于预测用户的下一步行为。


基于视口的链接预取
function prefetchVisibleLinks(): () => void {
  const prefetchedUrls = new Set<string>();

  const observer = new IntersectionObserver(
    (entries) => {
      for (const entry of entries) {
        if (entry.isIntersecting) {
          const anchor = entry.target as HTMLAnchorElement;
          const href = anchor.href;

          if (
            href &&
            !prefetchedUrls.has(href) &&
            href.startsWith(window.location.origin) &&
            href !== window.location.href
          ) {
            const link = document.createElement('link');
            link.rel = 'prefetch';
            link.href = href;
            document.head.appendChild(link);
            prefetchedUrls.add(href);
          }

          observer.unobserve(anchor);
        }
      }
    },
    { rootMargin: '0px' },
  );

  const links = document.querySelectorAll<HTMLAnchorElement>('a[href]');
  links.forEach((link) => observer.observe(link));

  return () => observer.disconnect();
}

小结
    

  • 路由级代码分割是最基础也最有效的懒加载策略，每个路由单独一个 chunk。
    • 

  • 组件级懒加载适用于重型非首屏组件，配合 Suspense 提供加载状态。
    • 

  • 图片懒加载优先使用原生 loading="lazy"，需要精细控制时使用 Intersection Observer。
    • 

  • 智能预取基于路由关系、用户交互和视口可见性来预测并预加载未来资源。
    • 

  • 懒加载需要注意 CLS 问题——为动态加载的内容预留正确的空间。
