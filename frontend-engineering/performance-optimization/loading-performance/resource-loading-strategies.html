资源加载策略

Resource Hints 概览

浏览器提供了一组资源提示（Resource Hints）机制，允许开发者在资源真正被需要之前就告知浏览器"提前做准备"。合理使用这些提示可以显著减少资源加载的等待时间，提升页面加载速度。

dns-prefetch 与 preconnect
dns-prefetch
DNS 解析通常需要 20-120ms。对于需要从多个域名加载资源的页面，提前解析 DNS 可以节省可观的时间。


<link rel="dns-prefetch" href="https://fonts.googleapis.com" />
<link rel="dns-prefetch" href="https://cdn.example.com" />
<link rel="dns-prefetch" href="https://analytics.example.com" />
preconnect
preconnect 比 dns-prefetch 更进一步——它完成 DNS 查询、TCP 握手和 TLS 协商的完整过程。


<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link rel="preconnect" href="https://cdn.example.com" />

preload 深度应用
preload 是当前页面关键资源的提前加载指令。它告诉浏览器"这个资源很快就会被用到，请立即开始下载"。与普通资源加载不同，preload 资源的发现不依赖于 HTML 解析进度。


<link rel="preload" href="/fonts/inter-var.woff2" as="font" type="font/woff2" crossorigin />

<link rel="preload" href="/hero-image.webp" as="image" />

<link rel="preload" href="/critical.css" as="style" />

<link rel="preload" href="/app.js" as="script" />

<link rel="preload" href="/api/initial-data" as="fetch" crossorigin />

动态 preload
function preloadResource(href: string, as: string, options?: { crossOrigin?: boolean; type?: string }): void {
  const link = document.createElement('link');
  link.rel = 'preload';
  link.href = href;
  link.as = as;
  if (options?.crossOrigin) link.crossOrigin = 'anonymous';
  if (options?.type) link.type = options.type;
  document.head.appendChild(link);
}

function preloadCriticalResources(): void {
  preloadResource('/api/user', 'fetch', { crossOrigin: true });
  preloadResource('/images/hero.webp', 'image');
  preloadResource('/fonts/brand.woff2', 'font', { crossOrigin: true, type: 'font/woff2' });
}

if (document.readyState === 'loading') {
  document.addEventListener('DOMContentLoaded', preloadCriticalResources);
} else {
  preloadCriticalResources();
}


prefetch 策略
prefetch 用于在浏览器空闲时预加载未来可能需要的资源。它的优先级很低，不会与当前页面的关键资源争夺带宽。


<link rel="prefetch" href="/about" />
<link rel="prefetch" href="/js/dashboard.chunk.js" />
<link rel="prefetch" href="/images/product-detail.webp" />
基于路由的智能预取
import { useEffect } from 'react';
import { useRouter } from 'next/router';

const routePrefetchMap: Record<string, string[]> = {
  '/': ['/products', '/about'],
  '/products': ['/products/[id]', '/cart'],
  '/cart': ['/checkout'],
};

function usePrefetchRoutes(): void {
  const router = useRouter();

  useEffect(() => {
    const targetRoutes = routePrefetchMap[router.pathname] ?? [];

    const timer = setTimeout(() => {
      targetRoutes.forEach((route) => {
        router.prefetch(route);
      });
    }, 2000);

    return () => clearTimeout(timer);
  }, [router.pathname]);
}
基于交互的预取
function prefetchOnHover(element: HTMLElement, url: string): () => void {
  let prefetched = false;
  let timer: ReturnType<typeof setTimeout>;

  const handleMouseEnter = () => {
    timer = setTimeout(() => {
      if (!prefetched) {
        const link = document.createElement('link');
        link.rel = 'prefetch';
        link.href = url;
        document.head.appendChild(link);
        prefetched = true;
      }
    }, 100);
  };

  const handleMouseLeave = () => {
    clearTimeout(timer);
  };

  element.addEventListener('mouseenter', handleMouseEnter);
  element.addEventListener('mouseleave', handleMouseLeave);

  return () => {
    element.removeEventListener('mouseenter', handleMouseEnter);
    element.removeEventListener('mouseleave', handleMouseLeave);
  };
}


Fetch Priority API
Fetch Priority API（fetchpriority 属性）允许更精细地控制资源加载优先级：


<img src="/hero.webp" fetchpriority="high" alt="Hero" />

<img src="/carousel-3.webp" fetchpriority="low" alt="Slide" />

<link rel="preload" href="/critical-data.json" as="fetch" fetchpriority="high" />

<script src="/analytics.js" fetchpriority="low" async></script>
fetch('/api/critical-data', { priority: 'high' })
  .then((res) => res.json())
  .then((data) => renderMainContent(data));

fetch('/api/recommendations', { priority: 'low' })
  .then((res) => res.json())
  .then((data) => renderSidebar(data));

小结
    

  • Resource Hints 包括 dns-prefetch、preconnect、preload、prefetch 四种主要机制。
    • 

  • preconnect 用于关键第三方域名，dns-prefetch 用于非关键域名。
    • 

  • preload 用于当前页面的关键资源，必须设置正确的 as 属性。
    • 

  • prefetch 用于空闲时预加载未来可能需要的资源，不争夺当前页面带宽。
    • 

  • Fetch Priority API 提供了更精细的优先级控制能力。
    • 

  • 组合使用多种资源加载策略，才能实现最优的加载性能。
