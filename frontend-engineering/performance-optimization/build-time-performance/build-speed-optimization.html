构建速度优化

构建速度的重要性

构建速度直接影响开发效率和 CI/CD 流水线的吞吐量。当开发服务器启动需要 30 秒、热更新需要 5 秒、CI 构建需要 10 分钟时，开发者的工作流将被严重打断。构建速度优化的目标是让开发服务器秒级启动、热更新毫秒级完成。

Vite 为什么这么快


esbuild 与 SWC
esbuild
esbuild 使用 Go 语言编写，编译速度比传统 JavaScript 工具快 10-100 倍。


import esbuild from 'esbuild';

await esbuild.build({
  entryPoints: ['src/index.tsx'],
  bundle: true,
  minify: true,
  sourcemap: true,
  splitting: true,
  format: 'esm',
  outdir: 'dist',
  target: ['es2020'],
  loader: {
    '.png': 'file',
    '.svg': 'dataurl',
  },
  define: {
    'process.env.NODE_ENV': '"production"',
  },
});
SWC
SWC 使用 Rust 编写，是 Babel 的高性能替代品。Next.js 默认使用 SWC 进行编译。


{
  "jsc": {
    "parser": {
      "syntax": "typescript",
      "tsx": true,
      "decorators": true
    },
    "transform": {
      "react": {
        "runtime": "automatic"
      }
    },
    "target": "es2020",
    "minify": {
      "compress": true,
      "mangle": true
    }
  },
  "minify": true,
  "sourceMaps": true
}


缓存策略
webpack 持久化缓存
webpack 5 内置了持久化文件系统缓存，可以将构建结果缓存到磁盘，第二次构建只需处理变更的文件。


const config = {
  cache: {
    type: 'filesystem' as const,
    buildDependencies: {
      config: [__filename],
    },
    version: `${process.env.NODE_ENV}-v1`,
    cacheDirectory: '.webpack-cache',
    compression: 'gzip' as const,
  },
};
Vite 预构建缓存
import { defineConfig } from 'vite';

export default defineConfig({
  optimizeDeps: {
    include: ['react', 'react-dom', 'react-router-dom', '@tanstack/react-query'],
    exclude: ['@my-org/local-package'],
  },
  cacheDir: '.vite-cache',
});


并行处理
thread-loader（webpack）
const config = {
  module: {
    rules: [
      {
        test: /\.tsx?$/,
        use: [
          {
            loader: 'thread-loader',
            options: {
              workers: Math.max(1, require('os').cpus().length - 1),
              workerParallelJobs: 50,
            },
          },
          'ts-loader',
        ],
      },
    ],
  },
};


减少构建范围
精确的 include/exclude
import path from 'path';

const config = {
  module: {
    rules: [
      {
        test: /\.tsx?$/,
        include: [path.resolve(__dirname, 'src')],
        exclude: /node_modules/,
        use: 'swc-loader',
      },
    ],
  },
  resolve: {
    extensions: ['.tsx', '.ts', '.js'],
    modules: [path.resolve(__dirname, 'src'), 'node_modules'],
    symlinks: false,
  },
};
开发/生产差异化配置
import { defineConfig } from 'vite';

export default defineConfig(({ mode }) => ({
  build: {
    sourcemap: mode === 'production' ? 'hidden' : true,
    minify: mode === 'production' ? 'esbuild' : false,
    cssMinify: mode === 'production',
    reportCompressedSize: false,
  },
  esbuild: {
    drop: mode === 'production' ? ['console', 'debugger'] : [],
  },
}));

构建时间监控
interface BuildMetrics {
  totalTime: number;
  phases: Array<{
    name: string;
    duration: number;
    percentage: number;
  }>;
  cacheHitRate: number;
  outputSize: number;
}

function createBuildTimer(): {
  start: (phase: string) => void;
  end: (phase: string) => void;
  report: () => BuildMetrics;
} {
  const phases = new Map<string, { start: number; end?: number }>();
  const buildStart = Date.now();

  return {
    start(phase: string) {
      phases.set(phase, { start: Date.now() });
    },
    end(phase: string) {
      const p = phases.get(phase);
      if (p) p.end = Date.now();
    },
    report(): BuildMetrics {
      const totalTime = Date.now() - buildStart;
      const phaseList = Array.from(phases.entries()).map(([name, { start, end }]) => {
        const duration = (end ?? Date.now()) - start;
        return { name, duration, percentage: Math.round((duration / totalTime) * 100) };
      });
      phaseList.sort((a, b) => b.duration - a.duration);

      return { totalTime, phases: phaseList, cacheHitRate: 0, outputSize: 0 };
    },
  };
}


小结
    

  • Vite 利用浏览器原生 ESM 实现按需编译，开发服务器秒级启动。
    • 

  • esbuild（Go）和 SWC（Rust）比 Babel/Terser 快 10-100 倍，用于编译和压缩。
    • 

  • webpack 5 持久化缓存将增量构建速度提升 2-10 倍。
    • 

  • 构建配置要区分开发和生产环境——开发环境关闭不必要的优化。
    • 

  • 建立构建时间监控，防止构建速度在项目增长中无意退化。
    •
