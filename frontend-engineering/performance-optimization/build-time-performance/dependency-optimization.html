依赖优化

依赖是 Bundle 体积的主要组成

在典型的前端项目中，node_modules 中的第三方依赖占据了最终 bundle 体积的 60-80%。一个看似无害的 npm install 就可能引入数百 KB 的代码。控制依赖体积是 bundle 优化中最重要的工作之一。



分析依赖体积
使用 bundlephobia 检查包体积
在引入任何依赖之前，先通过 bundlephobia.com 或 npm 包的 package size 检查其体积影响。

依赖去重
检查重复依赖
import { execSync } from 'child_process';

function findDuplicates(): void {
  const output = execSync('pnpm ls --depth=Infinity --json', { encoding: 'utf-8' });
  const tree = JSON.parse(output);

  const packageVersions = new Map<string, Set<string>>();

  function traverse(deps: Record<string, any>): void {
    for (const [name, info] of Object.entries(deps)) {
      if (!packageVersions.has(name)) {
        packageVersions.set(name, new Set());
      }
      packageVersions.get(name)!.add(info.version);
      if (info.dependencies) traverse(info.dependencies);
    }
  }

  if (tree[0]?.dependencies) traverse(tree[0].dependencies);

  const duplicates = Array.from(packageVersions.entries())
    .filter(([_, versions]) => versions.size > 1)
    .sort((a, b) => b[1].size - a[1].size);

  if (duplicates.length > 0) {
    console.log('⚠️ Duplicate dependencies found:\n');
    for (const [name, versions] of duplicates) {
      console.log(`  ${name}: ${Array.from(versions).join(', ')}`);
    }
  }
}

动态导入大型依赖
某些依赖只在特定场景下使用，可以通过动态导入避免影响初始加载：


async function renderChart(data: any[], container: HTMLElement): Promise<void> {
  const { Chart, registerables } = await import('chart.js');
  Chart.register(...registerables);

  new Chart(container.querySelector('canvas')!, {
    type: 'line',
    data: {
      labels: data.map((d) => d.label),
      datasets: [{ data: data.map((d) => d.value) }],
    },
  });
}

async function highlightCode(code: string, language: string): Promise<string> {
  const { default: Prism } = await import('prismjs');
  await import(`prismjs/components/prism-${language}`);
  return Prism.highlight(code, Prism.languages[language], language);
}

async function generatePDF(content: string): Promise<Blob> {
  const { jsPDF } = await import('jspdf');
  const doc = new jsPDF();
  doc.text(content, 10, 10);
  return doc.output('blob');
}


依赖优化决策树


小结
    

  • 第三方依赖通常占据 bundle 体积的 60-80%，引入前务必检查体积影响。
    • 

  • 优先使用轻量替代方案：date-fns 替代 moment，ky 替代 axios，原生 API 替代工具库。
    • 

  • 确保依赖支持 Tree Shaking（ESM 格式 + sideEffects: false）。
    • 

  • 仅在特定场景使用的大型依赖应通过动态 import 按需加载。
    • 

  • 使用 pnpm overrides 统一重复依赖的版本，减少 bundle 中的重复代码。
    • 

  • 建立依赖引入审查流程，在 Code Review 中关注新增依赖的体积影响。
    •
