Bundle 体积分析

为什么 Bundle 体积如此重要

JavaScript bundle 体积直接影响页面加载性能。浏览器必须下载、解析和执行所有 JavaScript 代码后，页面才能完全可交互。在移动设备上，解析和执行 JavaScript 的开销尤为突出——1 MB 的 JavaScript 在低端手机上的解析时间可能超过 3 秒。

分析工具
webpack-bundle-analyzer
最流行的 bundle 可视化分析工具，以 Treemap 形式展示每个模块在 bundle 中的占比。


import { BundleAnalyzerPlugin } from 'webpack-bundle-analyzer';

const config = {
  plugins: [
    new BundleAnalyzerPlugin({
      analyzerMode: 'static',
      reportFilename: 'bundle-report.html',
      openAnalyzer: false,
      defaultSizes: 'gzip',
    }),
  ],
};

编程式体积检查
import fs from 'fs';
import path from 'path';
import { gzipSync, brotliCompressSync } from 'zlib';
import { glob } from 'glob';

interface BundleStats {
  file: string;
  raw: number;
  gzip: number;
  brotli: number;
}

async function analyzeBundleSize(distDir: string): Promise<BundleStats[]> {
  const files = await glob('**/*.{js,css}', { cwd: distDir });

  const stats: BundleStats[] = files.map((file) => {
    const content = fs.readFileSync(path.join(distDir, file));
    return {
      file,
      raw: content.length,
      gzip: gzipSync(content).length,
      brotli: brotliCompressSync(content).length,
    };
  });

  stats.sort((a, b) => b.gzip - a.gzip);

  console.log('\n📊 Bundle Size Report:\n');
  console.log('File'.padEnd(40) + 'Raw'.padStart(10) + 'Gzip'.padStart(10) + 'Brotli'.padStart(10));
  console.log('-'.repeat(70));

  for (const s of stats) {
    console.log(
      s.file.padEnd(40) +
        formatSize(s.raw).padStart(10) +
        formatSize(s.gzip).padStart(10) +
        formatSize(s.brotli).padStart(10),
    );
  }

  const total = stats.reduce(
    (acc, s) => ({ raw: acc.raw + s.raw, gzip: acc.gzip + s.gzip, brotli: acc.brotli + s.brotli }),
    { raw: 0, gzip: 0, brotli: 0 },
  );

  console.log('-'.repeat(70));
  console.log(
    'Total'.padEnd(40) +
      formatSize(total.raw).padStart(10) +
      formatSize(total.gzip).padStart(10) +
      formatSize(total.brotli).padStart(10),
  );

  return stats;
}

function formatSize(bytes: number): string {
  if (bytes < 1024) return `${bytes} B`;
  return `${(bytes / 1024).toFixed(1)} KB`;
}

智能分割策略
import { defineConfig } from 'vite';

export default defineConfig({
  build: {
    rollupOptions: {
      output: {
        manualChunks(id) {
          if (id.includes('node_modules')) {
            if (id.includes('react') || id.includes('react-dom')) {
              return 'vendor-react';
            }
            if (id.includes('@radix-ui') || id.includes('@headlessui')) {
              return 'vendor-ui';
            }
            if (id.includes('chart') || id.includes('d3')) {
              return 'vendor-charts';
            }
            return 'vendor';
          }
        },
      },
    },
  },
});

Bundle 体积预算
interface BundleBudget {
  maxTotalSize: number;
  maxChunkSize: number;
  maxEntrySize: number;
  rules: Array<{
    pattern: string;
    maxSize: number;
  }>;
}

const budget: BundleBudget = {
  maxTotalSize: 300 * 1024,
  maxChunkSize: 150 * 1024,
  maxEntrySize: 200 * 1024,
  rules: [
    { pattern: 'vendor-react.*', maxSize: 150 * 1024 },
    { pattern: 'vendor-ui.*', maxSize: 80 * 1024 },
    { pattern: '*.chunk.*', maxSize: 50 * 1024 },
  ],
};

async function checkBudget(distDir: string, budget: BundleBudget): Promise<boolean> {
  const stats = await analyzeBundleSize(distDir);
  const violations: string[] = [];

  const totalGzip = stats.reduce((sum, s) => sum + s.gzip, 0);
  if (totalGzip > budget.maxTotalSize) {
    violations.push(`Total size ${formatSize(totalGzip)} exceeds budget ${formatSize(budget.maxTotalSize)}`);
  }

  for (const s of stats) {
    if (s.gzip > budget.maxChunkSize) {
      violations.push(`${s.file} (${formatSize(s.gzip)}) exceeds chunk budget ${formatSize(budget.maxChunkSize)}`);
    }

    for (const rule of budget.rules) {
      if (new RegExp(rule.pattern.replace('*', '.*')).test(s.file) && s.gzip > rule.maxSize) {
        violations.push(`${s.file} (${formatSize(s.gzip)}) exceeds rule budget ${formatSize(rule.maxSize)}`);
      }
    }
  }

  if (violations.length > 0) {
    console.error('\n❌ Bundle budget violations:');
    violations.forEach((v) => console.error(`  - ${v}`));
    return false;
  }

  console.log('\n✅ All bundle budgets passed!');
  return true;
}


小结
    

  • JavaScript bundle 体积直接影响下载、解析和执行时间——在移动设备上影响尤为明显。
    • 

  • webpack-bundle-analyzer 和 rollup-plugin-visualizer 是分析 bundle 组成的必备工具。
    • 

  • Tree Shaking 要求使用 ES Module 语法并正确配置 sideEffects。
    • 

  • 代码分割策略包括路由分割、Vendor 分割和细粒度分割，根据项目复杂度选择。
    • 

  • 建立 Bundle 体积预算并集成到 CI，防止体积在无意中增长。
