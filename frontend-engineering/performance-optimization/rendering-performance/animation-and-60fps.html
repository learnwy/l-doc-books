动画与 60fps

帧预算与流畅度

人眼对 60fps（每秒 60 帧）的动画感觉最流畅。这意味着每一帧的时间预算只有 16.67ms。在这个预算内，浏览器需要完成 JavaScript 执行、样式计算、布局、绘制和合成等所有工作。任何超出预算的帧都会被用户感知为"掉帧"或"卡顿"。

CSS 动画 vs JavaScript 动画
CSS 动画的优势
CSS 动画（transitions 和 animations）由浏览器的合成器线程直接处理，不经过主线程。这意味着即使主线程被 JavaScript 阻塞，CSS 动画仍然可以流畅运行。


.card {
  transition:
    transform 0.3s cubic-bezier(0.4, 0, 0.2, 1),
    opacity 0.3s ease;
}

.card:hover {
  transform: translateY(-8px) scale(1.02);
  opacity: 0.95;
}

@keyframes slideIn {
  from {
    transform: translateX(-100%);
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}

.slide-enter {
  animation: slideIn 0.4s cubic-bezier(0.4, 0, 0.2, 1) forwards;
}

requestAnimationFrame
JavaScript 动画应始终使用 requestAnimationFrame（rAF），它与浏览器的渲染周期同步，确保动画更新在最佳时机执行。


interface AnimationConfig {
  duration: number;
  easing: (t: number) => number;
  onUpdate: (progress: number) => void;
  onComplete?: () => void;
}

function animate({ duration, easing, onUpdate, onComplete }: AnimationConfig): () => void {
  let startTime: number | null = null;
  let rafId: number;

  function tick(timestamp: number): void {
    if (!startTime) startTime = timestamp;
    const elapsed = timestamp - startTime;
    const rawProgress = Math.min(elapsed / duration, 1);
    const easedProgress = easing(rawProgress);

    onUpdate(easedProgress);

    if (rawProgress < 1) {
      rafId = requestAnimationFrame(tick);
    } else {
      onComplete?.();
    }
  }

  rafId = requestAnimationFrame(tick);

  return () => cancelAnimationFrame(rafId);
}

const easings = {
  linear: (t: number) => t,
  easeInOut: (t: number) => (t < 0.5 ? 2 * t * t : -1 + (4 - 2 * t) * t),
  easeOutCubic: (t: number) => 1 - Math.pow(1 - t, 3),
  spring: (t: number) => 1 - Math.pow(Math.cos(t * Math.PI * 0.5), 3) * Math.exp(-t * 6),
};

const element = document.getElementById('box')!;
animate({
  duration: 500,
  easing: easings.easeOutCubic,
  onUpdate: (progress) => {
    element.style.transform = `translateX(${progress * 300}px)`;
    element.style.opacity = String(progress);
  },
});


FLIP 动画技术
FLIP（First, Last, Invert, Play）是一种高性能动画技术，用于元素在布局变化时的平滑过渡。它将布局变化转换为 transform 动画，从而避免在动画过程中触发 Layout。


interface Rect {
  x: number;
  y: number;
  width: number;
  height: number;
}

function flipAnimate(element: HTMLElement, applyChange: () => void): void {
  const first: Rect = element.getBoundingClientRect();

  applyChange();

  const last: Rect = element.getBoundingClientRect();

  const deltaX = first.x - last.x;
  const deltaY = first.y - last.y;
  const scaleX = first.width / last.width;
  const scaleY = first.height / last.height;

  element.style.transform = `translate(${deltaX}px, ${deltaY}px) scale(${scaleX}, ${scaleY})`;
  element.style.transformOrigin = 'top left';

  requestAnimationFrame(() => {
    element.style.transition = 'transform 0.4s cubic-bezier(0.4, 0, 0.2, 1)';
    element.style.transform = '';

    element.addEventListener(
      'transitionend',
      () => {
        element.style.transition = '';
        element.style.transformOrigin = '';
      },
      { once: true },
    );
  });
}
React FLIP Hook
import { useRef, useLayoutEffect, useCallback } from 'react';

function useFlip<T extends HTMLElement>(): [React.RefObject<T>, () => void] {
  const ref = useRef<T>(null);
  const firstRect = useRef<DOMRect | null>(null);

  const prepare = useCallback(() => {
    if (ref.current) {
      firstRect.current = ref.current.getBoundingClientRect();
    }
  }, []);

  useLayoutEffect(() => {
    const element = ref.current;
    const first = firstRect.current;

    if (!element || !first) return;

    const last = element.getBoundingClientRect();
    const deltaX = first.x - last.x;
    const deltaY = first.y - last.y;

    if (deltaX === 0 && deltaY === 0) return;

    element.style.transform = `translate(${deltaX}px, ${deltaY}px)`;

    requestAnimationFrame(() => {
      element.style.transition = 'transform 0.3s ease';
      element.style.transform = '';

      element.addEventListener(
        'transitionend',
        () => {
          element.style.transition = '';
        },
        { once: true },
      );
    });

    firstRect.current = null;
  });

  return [ref, prepare];
}


GPU 加速与 will-change
提升为合成层
通过某些 CSS 属性可以将元素提升为独立的合成层，使其动画在 GPU 上处理。


.animated-element {
  will-change: transform;
}

.animated-element.animating {
  transform: translateZ(0);
}

.animated-element.done {
  will-change: auto;
}
will-change 的正确用法
function setupHoverAnimation(element: HTMLElement): void {
  element.addEventListener('mouseenter', () => {
    element.style.willChange = 'transform, opacity';
  });

  element.addEventListener('transitionend', () => {
    element.style.willChange = 'auto';
  });

  element.addEventListener('mouseleave', () => {
    setTimeout(() => {
      element.style.willChange = 'auto';
    }, 300);
  });
}

Web Animations API
Web Animations API 结合了 CSS 动画的高性能和 JavaScript 动画的灵活控制。


function fadeInUp(element: HTMLElement): Animation {
  return element.animate(
    [
      { opacity: 0, transform: 'translateY(20px)' },
      { opacity: 1, transform: 'translateY(0)' },
    ],
    {
      duration: 400,
      easing: 'cubic-bezier(0.4, 0, 0.2, 1)',
      fill: 'forwards',
    },
  );
}

function staggeredEntrance(elements: HTMLElement[], staggerDelay: number = 50): Animation[] {
  return elements.map((el, index) =>
    el.animate(
      [
        { opacity: 0, transform: 'translateY(30px)' },
        { opacity: 1, transform: 'translateY(0)' },
      ],
      {
        duration: 400,
        delay: index * staggerDelay,
        easing: 'cubic-bezier(0.4, 0, 0.2, 1)',
        fill: 'forwards',
      },
    ),
  );
}

async function transitionBetween(outElement: HTMLElement, inElement: HTMLElement): Promise<void> {
  const fadeOut = outElement.animate([{ opacity: 1 }, { opacity: 0 }], { duration: 200, fill: 'forwards' });

  await fadeOut.finished;
  outElement.style.display = 'none';
  inElement.style.display = 'block';

  inElement.animate([{ opacity: 0 }, { opacity: 1 }], { duration: 200, fill: 'forwards' });
}

小结
    

  • 每帧预算 16.67ms，动画中 JavaScript 执行时间应控制在 6ms 以内。
    • 

  • 优先使用 CSS 动画（transform、opacity），它们在合成器线程执行不阻塞主线程。
    • 

  • JavaScript 动画必须使用 requestAnimationFrame 与浏览器渲染周期同步。
    • 

  • FLIP 技术将布局动画转为 transform 动画，实现高性能的位置变化过渡。
    • 

  • will-change 应按需使用——动画前设置、动画后移除，避免全局设置浪费内存。
    • 

  • Web Animations API 是 CSS 和 JS 动画的最佳平衡方案。
