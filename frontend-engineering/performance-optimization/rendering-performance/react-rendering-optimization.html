React 渲染优化

React 渲染机制

理解 React 的渲染机制是进行优化的前提。在 React 中，"渲染"指的是组件函数被调用生成 VDOM 的过程——这并不意味着真实 DOM 一定会更新。

触发渲染的三种情况：


    

  1. 组件自身状态变更（setState）
    2. 

  2. 父组件重渲染（即使传入的 props 没变）
    3. 

  3. Context 值变更（消费该 Context 的所有组件）
    4. 





React.memo 优化
当父组件重渲染时，所有子组件默认也会重渲染——即使它们的 props 没有变化。React.memo 通过浅比较 props 来跳过不必要的渲染。


import { memo, useState } from 'react';

interface UserCardProps {
  name: string;
  email: string;
  avatar: string;
}

const UserCard = memo(function UserCard({ name, email, avatar }: UserCardProps) {
  console.log('UserCard rendered');
  return (
    <div className="user-card">
      <img src={avatar} alt={name} />
      <h3>{name}</h3>
      <p>{email}</p>
    </div>
  );
});

function UserList() {
  const [selectedId, setSelectedId] = useState<string | null>(null);
  const users = useUsers();

  return (
    <div>
      {users.map((user) => (
        <div key={user.id} onClick={() => setSelectedId(user.id)}>
          <UserCard name={user.name} email={user.email} avatar={user.avatar} />
          {selectedId === user.id && <span>✓ Selected</span>}
        </div>
      ))}
    </div>
  );
}
自定义比较函数
interface ChartProps {
  data: number[];
  title: string;
  config: { color: string; type: string };
}

const Chart = memo(
  function Chart({ data, title, config }: ChartProps) {
    return <canvas data-title={title} />;
  },
  (prevProps, nextProps) => {
    if (prevProps.title !== nextProps.title) return false;
    if (prevProps.config.color !== nextProps.config.color) return false;
    if (prevProps.config.type !== nextProps.config.type) return false;
    if (prevProps.data.length !== nextProps.data.length) return false;
    return prevProps.data.every((v, i) => v === nextProps.data[i]);
  },
);


useMemo 与 useCallback
useMemo：缓存计算结果
import { useMemo, useState } from 'react';

interface Product {
  id: string;
  name: string;
  price: number;
  category: string;
  inStock: boolean;
}

function ProductList({ products }: { products: Product[] }) {
  const [filter, setFilter] = useState('');
  const [sortBy, setSortBy] = useState<'name' | 'price'>('name');
  const [showInStockOnly, setShowInStockOnly] = useState(false);

  const filteredAndSorted = useMemo(() => {
    let result = products;

    if (showInStockOnly) {
      result = result.filter((p) => p.inStock);
    }

    if (filter) {
      const lowerFilter = filter.toLowerCase();
      result = result.filter(
        (p) => p.name.toLowerCase().includes(lowerFilter) || p.category.toLowerCase().includes(lowerFilter),
      );
    }

    return [...result].sort((a, b) => {
      if (sortBy === 'name') return a.name.localeCompare(b.name);
      return a.price - b.price;
    });
  }, [products, filter, sortBy, showInStockOnly]);

  return (
    <div>
      <input value={filter} onChange={(e) => setFilter(e.target.value)} placeholder="搜索..." />
      <select value={sortBy} onChange={(e) => setSortBy(e.target.value as 'name' | 'price')}>
        <option value="name">按名称</option>
        <option value="price">按价格</option>
      </select>
      <label>
        <input type="checkbox" checked={showInStockOnly} onChange={(e) => setShowInStockOnly(e.target.checked)} />
        仅显示有货
      </label>
      <div>
        {filteredAndSorted.map((product) => (
          <ProductItem key={product.id} product={product} />
        ))}
      </div>
    </div>
  );
}
useCallback：缓存函数引用
import { useCallback, memo, useState } from 'react';

interface TodoItemProps {
  id: string;
  text: string;
  completed: boolean;
  onToggle: (id: string) => void;
  onDelete: (id: string) => void;
}

const TodoItem = memo(function TodoItem({ id, text, completed, onToggle, onDelete }: TodoItemProps) {
  return (
    <div className={`todo-item ${completed ? 'completed' : ''}`}>
      <input type="checkbox" checked={completed} onChange={() => onToggle(id)} />
      <span>{text}</span>
      <button onClick={() => onDelete(id)}>删除</button>
    </div>
  );
});

function TodoList() {
  const [todos, setTodos] = useState<Array<{ id: string; text: string; completed: boolean }>>([]);

  const handleToggle = useCallback((id: string) => {
    setTodos((prev) => prev.map((todo) => (todo.id === id ? { ...todo, completed: !todo.completed } : todo)));
  }, []);

  const handleDelete = useCallback((id: string) => {
    setTodos((prev) => prev.filter((todo) => todo.id !== id));
  }, []);

  return (
    <div>
      {todos.map((todo) => (
        <TodoItem
          key={todo.id}
          id={todo.id}
          text={todo.text}
          completed={todo.completed}
          onToggle={handleToggle}
          onDelete={handleDelete}
        />
      ))}
    </div>
  );
}

Context 优化
Context 值变化会导致所有消费组件重渲染。拆分 Context 可以减少影响范围。


import { createContext, useContext, useState, memo } from 'react';

const ThemeContext = createContext<{ theme: string; setTheme: (t: string) => void }>({
  theme: 'light',
  setTheme: () => {},
});

const UserContext = createContext<{ user: any; setUser: (u: any) => void }>({
  user: null,
  setUser: () => {},
});

function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setTheme] = useState('light');
  const value = useMemo(() => ({ theme, setTheme }), [theme]);
  return <ThemeContext.Provider value={value}>{children}</ThemeContext.Provider>;
}

function UserProvider({ children }: { children: React.ReactNode }) {
  const [user, setUser] = useState(null);
  const value = useMemo(() => ({ user, setUser }), [user]);
  return <UserContext.Provider value={value}>{children}</UserContext.Provider>;
}


useTransition 与并发渲染
React 18 的 useTransition 将更新标记为低优先级，允许高优先级更新（用户输入）打断低优先级更新（列表过滤）。


import { useState, useTransition } from 'react';

function FilterableList({ items }: { items: string[] }) {
  const [query, setQuery] = useState('');
  const [filteredItems, setFilteredItems] = useState(items);
  const [isPending, startTransition] = useTransition();

  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    const value = e.target.value;
    setQuery(value);

    startTransition(() => {
      const filtered = items.filter((item) => item.toLowerCase().includes(value.toLowerCase()));
      setFilteredItems(filtered);
    });
  };

  return (
    <div>
      <input value={query} onChange={handleChange} placeholder="搜索..." />
      {isPending && <span className="loading">更新中...</span>}
      <ul style={{ opacity: isPending ? 0.7 : 1 }}>
        {filteredItems.map((item, i) => (
          <li key={i}>{item}</li>
        ))}
      </ul>
    </div>
  );
}

自定义渲染追踪
import { useRef, useEffect } from 'react';

function useRenderCount(componentName: string): void {
  const count = useRef(0);
  count.current++;

  useEffect(() => {
    if (process.env.NODE_ENV === 'development') {
      console.log(`[Render] ${componentName}: ${count.current} times`);
    }
  });
}

function useWhyDidYouRender(componentName: string, props: Record<string, any>): void {
  const prevProps = useRef<Record<string, any>>(props);

  useEffect(() => {
    if (process.env.NODE_ENV === 'development') {
      const changes: Record<string, { from: any; to: any }> = {};

      for (const key of Object.keys(props)) {
        if (prevProps.current[key] !== props[key]) {
          changes[key] = { from: prevProps.current[key], to: props[key] };
        }
      }

      if (Object.keys(changes).length > 0) {
        console.log(`[WhyRender] ${componentName}:`, changes);
      }

      prevProps.current = props;
    }
  });
}


小结
    

  • React 组件在父组件重渲染时默认也会重渲染，即使 props 未变——用 React.memo 解决。
    • 

  • useCallback 稳定函数引用，useMemo 缓存计算结果——它们是 React.memo 的配套工具。
    • 

  • 状态下沉到最近的使用点，避免状态变化影响不相关的组件。
    • 

  • Context 值变化会导致所有消费组件重渲染——拆分 Context 减少影响范围。
    • 

  • useTransition 将低优先级更新延迟执行，保障输入等高优先级交互的流畅性。
    • 

  • React DevTools Profiler 是定位渲染性能问题的首选工具。
