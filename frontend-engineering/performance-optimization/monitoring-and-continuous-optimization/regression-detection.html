回归检测

核心概念

性能回归的隐蔽性在于它不报错——用户只会感觉"变慢了"，若不主动检测，往往数周后才被发现，届时追溯根因已很困难。检测体系由三层构成：实验室回归（Lighthouse CI 在每次提交上跑固定场景，把指标与基线比对）、真实用户趋势（用 RUM 时序数据与异常检测发现缓慢劣化）、以及部署关联（把指标突变与具体发布、提交对齐，快速定位引入回归的变更）。三层组合形成"提交时拦截 + 上线后监控"的自动化防护网，把性能退化的发现成本降到最低。

性能回归的隐蔽性

性能回归是指应用在某次变更后性能指标出现退化。与功能 Bug 不同，性能回归通常不会触发错误报告——用户只会感觉"好像变慢了"。如果缺乏自动化检测机制，性能回归可能在数周甚至数月后才被发现，此时追溯根因的难度已经大大增加。

Lighthouse CI

Lighthouse CI 是 Google 官方的持续性能监控工具。它在每次 PR 或部署时自动运行 Lighthouse 审计，将结果与基线对比，在性能退化时发出警告。

配置文件

GitHub Actions 集成

name: Lighthouse CI
on:
  pull_request:
    branches: [main]

jobs:
  lighthouse:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v2
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm

      - run: pnpm install --frozen-lockfile
      - run: pnpm build

      - name: Run Lighthouse CI
        uses: treosh/lighthouse-ci-action@v11
        with:
          configPath: .lighthouserc.json
          uploadArtifacts: true
          temporaryPublicStorage: true

      - name: Comment PR with results
        if: github.event_name == 'pull_request'
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            const results = JSON.parse(fs.readFileSync('.lighthouseci/manifest.json', 'utf8'));
            const summary = results.map(r => {
              const score = Math.round(r.summary.performance * 100);
              const emoji = score >= 90 ? '🟢' : score >= 50 ? '🟡' : '🔴';
              return `${emoji} ${r.url}: **${score}**/100`;
            }).join('\n');
            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body: `## 🚦 Lighthouse Performance Report\n\n${summary}`
            });

RUM 趋势监控

时序分析

interface TimeSeriesPoint {
  timestamp: number;
  value: number;
}

interface TrendAnalysis {
  direction: 'improving' | 'stable' | 'degrading';
  changePercent: number;
  confidence: number;
}

function analyzeTrend(points: TimeSeriesPoint[], windowSize: number = 7): TrendAnalysis {
  if (points.length < windowSize * 2) {
    return { direction: 'stable', changePercent: 0, confidence: 0 };
  }

  const recent = points.slice(-windowSize);
  const previous = points.slice(-windowSize * 2, -windowSize);

  const recentAvg = recent.reduce((sum, p) => sum + p.value, 0) / recent.length;
  const previousAvg = previous.reduce((sum, p) => sum + p.value, 0) / previous.length;

  const changePercent = ((recentAvg - previousAvg) / previousAvg) * 100;

  const recentStdDev = Math.sqrt(recent.reduce((sum, p) => sum + Math.pow(p.value - recentAvg, 2), 0) / recent.length);
  const confidence = Math.min(1, Math.abs(recentAvg - previousAvg) / (recentStdDev + 1));

  let direction: TrendAnalysis['direction'];
  if (Math.abs(changePercent) < 5) {
    direction = 'stable';
  } else if (changePercent > 0) {
    direction = 'degrading';
  } else {
    direction = 'improving';
  }

  return { direction, changePercent: Math.round(changePercent * 100) / 100, confidence };
}

异常检测

interface AnomalyDetectionConfig {
  sensitivity: number;
  minSamples: number;
  windowSize: number;
}

interface Anomaly {
  timestamp: number;
  value: number;
  expected: number;
  deviation: number;
  severity: 'warning' | 'critical';
}

function detectAnomalies(
  points: TimeSeriesPoint[],
  config: AnomalyDetectionConfig = { sensitivity: 2, minSamples: 30, windowSize: 24 },
): Anomaly[] {
  const { sensitivity, minSamples, windowSize } = config;
  const anomalies: Anomaly[] = [];

  if (points.length < minSamples) return anomalies;

  for (let i = windowSize; i < points.length; i++) {
    const window = points.slice(i - windowSize, i);
    const mean = window.reduce((sum, p) => sum + p.value, 0) / window.length;
    const stdDev = Math.sqrt(window.reduce((sum, p) => sum + Math.pow(p.value - mean, 2), 0) / window.length);

    const current = points[i];
    const deviation = (current.value - mean) / (stdDev || 1);

    if (Math.abs(deviation) > sensitivity) {
      anomalies.push({
        timestamp: current.timestamp,
        value: current.value,
        expected: mean,
        deviation,
        severity: Math.abs(deviation) > sensitivity * 1.5 ? 'critical' : 'warning',
      });
    }
  }

  return anomalies;
}

interface Deployment {
  version: string;
  timestamp: number;
  commitHash: string;
  changes: string[];
}

interface RegressionReport {
  metric: string;
  deployment: Deployment;
  beforeValue: number;
  afterValue: number;
  changePercent: number;
  suspectedChanges: string[];
}

function correlateWithDeployments(
  metrics: TimeSeriesPoint[],
  deployments: Deployment[],
  metricName: string,
  threshold: number = 10,
): RegressionReport[] {
  const reports: RegressionReport[] = [];

  for (const deployment of deployments) {
    const before = metrics.filter(
      (m) => m.timestamp >= deployment.timestamp - 3600000 && m.timestamp < deployment.timestamp,
    );
    const after = metrics.filter(
      (m) => m.timestamp >= deployment.timestamp && m.timestamp < deployment.timestamp + 3600000,
    );

    if (before.length === 0 || after.length === 0) continue;

    const beforeAvg = before.reduce((sum, m) => sum + m.value, 0) / before.length;
    const afterAvg = after.reduce((sum, m) => sum + m.value, 0) / after.length;
    const changePercent = ((afterAvg - beforeAvg) / beforeAvg) * 100;

    if (changePercent > threshold) {
      reports.push({
        metric: metricName,
        deployment,
        beforeValue: Math.round(beforeAvg),
        afterValue: Math.round(afterAvg),
        changePercent: Math.round(changePercent * 100) / 100,
        suspectedChanges: deployment.changes,
      });
    }
  }

  return reports;
}

小结

  • 性能回归具有隐蔽性——没有自动化检测，可能数周后才被发现。
  • Lighthouse CI 在每次 PR 中自动运行性能审计，在代码合入前拦截回归。
  • RUM 趋势分析通过时序数据的统计方法发现渐进式退化。
  • 异常检测算法（基于标准差）自动识别突发的性能异常。
  • 将性能数据与部署事件关联，快速定位引入回归的具体变更。
  • 多层防护体系（PR 检查 → 预发布测试 → 生产监控 → 趋势分析）构建完整的回归防线。
