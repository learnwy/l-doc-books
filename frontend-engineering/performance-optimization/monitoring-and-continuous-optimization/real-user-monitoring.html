真实用户监控

为什么需要 RUM

实验室数据（Lighthouse、WebPageTest）在受控环境下测试，使用固定的设备配置和网络条件。但真实用户的环境千差万别——高端 iPhone 和低端 Android、光纤宽带和 3G 移动网络、城市和偏远地区——实验室数据无法代表这些多样性。

搭建 RUM 采集系统
核心指标采集
import { onLCP, onINP, onCLS, onFCP, onTTFB, type Metric } from 'web-vitals';

interface RUMPayload {
  sessionId: string;
  pageUrl: string;
  timestamp: number;
  metrics: Record<string, number>;
  metadata: {
    userAgent: string;
    connectionType: string;
    deviceMemory: number;
    hardwareConcurrency: number;
    screenSize: string;
    viewport: string;
    language: string;
  };
}

class RUMCollector {
  private sessionId: string;
  private metrics: Record<string, number> = {};
  private reported = false;

  constructor(private endpoint: string) {
    this.sessionId = this.generateSessionId();
    this.setupCollectors();
    this.setupBeforeUnload();
  }

  private generateSessionId(): string {
    return `${Date.now()}-${Math.random().toString(36).substring(2, 9)}`;
  }

  private setupCollectors(): void {
    onLCP((metric) => this.recordMetric('lcp', metric));
    onINP((metric) => this.recordMetric('inp', metric));
    onCLS((metric) => this.recordMetric('cls', metric));
    onFCP((metric) => this.recordMetric('fcp', metric));
    onTTFB((metric) => this.recordMetric('ttfb', metric));
  }

  private recordMetric(name: string, metric: Metric): void {
    this.metrics[name] = metric.value;
    this.metrics[`${name}_rating`] = metric.rating === 'good' ? 0 : metric.rating === 'needs-improvement' ? 1 : 2;
  }

  private setupBeforeUnload(): void {
    const reportOnLeave = () => {
      if (!this.reported) {
        this.report();
        this.reported = true;
      }
    };

    document.addEventListener('visibilitychange', () => {
      if (document.visibilityState === 'hidden') reportOnLeave();
    });

    window.addEventListener('pagehide', reportOnLeave);
  }

  private report(): void {
    const payload: RUMPayload = {
      sessionId: this.sessionId,
      pageUrl: window.location.href,
      timestamp: Date.now(),
      metrics: this.metrics,
      metadata: {
        userAgent: navigator.userAgent,
        connectionType: (navigator as any).connection?.effectiveType ?? 'unknown',
        deviceMemory: (navigator as any).deviceMemory ?? 0,
        hardwareConcurrency: navigator.hardwareConcurrency ?? 0,
        screenSize: `${screen.width}x${screen.height}`,
        viewport: `${window.innerWidth}x${window.innerHeight}`,
        language: navigator.language,
      },
    };

    const blob = new Blob([JSON.stringify(payload)], { type: 'application/json' });
    navigator.sendBeacon(this.endpoint, blob);
  }
}

const rum = new RUMCollector('/api/rum');


自定义性能标记
除了 Core Web Vitals，业务特定的性能指标同样重要：


class BusinessMetrics {
  private marks: Record<string, number> = {};

  mark(name: string): void {
    this.marks[name] = performance.now();
    performance.mark(`biz:${name}`);
  }

  measure(name: string, startMark: string, endMark?: string): number {
    const end = endMark ? this.marks[endMark] : performance.now();
    const start = this.marks[startMark];
    const duration = end - start;

    performance.measure(`biz:${name}`, `biz:${startMark}`, endMark ? `biz:${endMark}` : undefined);

    return duration;
  }
}

const biz = new BusinessMetrics();

biz.mark('page-init');
biz.mark('api-start');
const data = await fetchProductList();
biz.mark('api-end');
const apiTime = biz.measure('api-call', 'api-start', 'api-end');

renderProducts(data);
biz.mark('render-complete');
const renderTime = biz.measure('first-render', 'api-end', 'render-complete');
const totalTime = biz.measure('page-ready', 'page-init', 'render-complete');


数据分析与可视化
分位数分析
性能数据应使用分位数而非平均值来分析。P75（75th percentile）代表 75% 用户的体验水平，是 Google 推荐的评估标准。


interface PercentileResult {
  p50: number;
  p75: number;
  p90: number;
  p95: number;
  p99: number;
}

function calculatePercentiles(values: number[]): PercentileResult {
  const sorted = [...values].sort((a, b) => a - b);
  const percentile = (p: number) => {
    const index = Math.ceil((p / 100) * sorted.length) - 1;
    return sorted[Math.max(0, index)];
  };

  return {
    p50: percentile(50),
    p75: percentile(75),
    p90: percentile(90),
    p95: percentile(95),
    p99: percentile(99),
  };
}

function analyzeByDimension(
  data: RUMPayload[],
  dimension: keyof RUMPayload['metadata'],
  metric: string,
): Record<string, PercentileResult> {
  const groups: Record<string, number[]> = {};

  for (const entry of data) {
    const key = String(entry.metadata[dimension]);
    if (!groups[key]) groups[key] = [];
    if (entry.metrics[metric] !== undefined) {
      groups[key].push(entry.metrics[metric]);
    }
  }

  const result: Record<string, PercentileResult> = {};
  for (const [key, values] of Object.entries(groups)) {
    result[key] = calculatePercentiles(values);
  }

  return result;
}

告警机制
interface AlertRule {
  metric: string;
  percentile: number;
  threshold: number;
  window: number;
  severity: 'warning' | 'critical';
}

const alertRules: AlertRule[] = [
  { metric: 'lcp', percentile: 75, threshold: 2500, window: 3600000, severity: 'warning' },
  { metric: 'lcp', percentile: 75, threshold: 4000, window: 3600000, severity: 'critical' },
  { metric: 'inp', percentile: 75, threshold: 200, window: 3600000, severity: 'warning' },
  { metric: 'cls', percentile: 75, threshold: 0.1, window: 3600000, severity: 'warning' },
  { metric: 'cls', percentile: 75, threshold: 0.25, window: 3600000, severity: 'critical' },
];

interface Alert {
  rule: AlertRule;
  currentValue: number;
  timestamp: number;
  affectedPages: string[];
}

function checkAlerts(data: RUMPayload[], rules: AlertRule[]): Alert[] {
  const now = Date.now();
  const alerts: Alert[] = [];

  for (const rule of rules) {
    const recentData = data.filter((d) => now - d.timestamp < rule.window);
    const values = recentData.map((d) => d.metrics[rule.metric]).filter((v) => v !== undefined);

    if (values.length === 0) continue;

    const percentiles = calculatePercentiles(values);
    const key = `p${rule.percentile}` as keyof PercentileResult;
    const currentValue = percentiles[key];

    if (currentValue > rule.threshold) {
      const affectedPages = [...new Set(recentData.map((d) => d.pageUrl))].slice(0, 5);
      alerts.push({ rule, currentValue, timestamp: now, affectedPages });
    }
  }

  return alerts;
}


小结
    

  • RUM 采集真实用户的性能数据，是实验室数据的必要补充。
    • 

  • 使用 web-vitals 库 + sendBeacon 实现可靠的客户端指标采集。
    • 

  • 性能数据应使用 P75 分位数（而非平均值）进行分析。
    • 

  • 按设备类型、网络条件、地理位置等维度进行交叉分析，定位特定用户群体的问题。
    • 

  • 建立自动化告警机制，在 Core Web Vitals 超标时第一时间通知团队。
