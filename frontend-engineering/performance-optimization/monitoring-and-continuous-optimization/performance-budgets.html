性能预算

什么是性能预算

性能预算是一组量化的性能约束，定义了应用在各项性能指标上不可超越的阈值。就像财务预算约束了项目的开支，性能预算约束了应用的"性能开支"——每新增一个功能、每引入一个依赖，都需要在预算范围内运作。



制定性能预算
基于竞品分析
interface CompetitorBenchmark {
  name: string;
  lcp: number;
  fcp: number;
  cls: number;
  bundleSize: number;
}

const competitors: CompetitorBenchmark[] = [
  { name: '竞品 A', lcp: 2800, fcp: 1500, cls: 0.08, bundleSize: 280 },
  { name: '竞品 B', lcp: 3200, fcp: 1800, cls: 0.15, bundleSize: 350 },
  { name: '竞品 C', lcp: 2100, fcp: 1200, cls: 0.05, bundleSize: 200 },
];

function deriveBudget(competitors: CompetitorBenchmark[]): Record<string, number> {
  const metrics = ['lcp', 'fcp', 'cls', 'bundleSize'] as const;
  const budget: Record<string, number> = {};

  for (const metric of metrics) {
    const values = competitors.map((c) => c[metric]);
    const best = Math.min(...values);
    budget[metric] = Math.round(best * 0.8);
  }

  return budget;
}

自定义预算检查脚本
import fs from 'fs';
import path from 'path';
import { gzipSync } from 'zlib';
import { glob } from 'glob';

interface BudgetRule {
  pattern: string;
  maxSize: number;
  name: string;
}

interface BudgetResult {
  rule: BudgetRule;
  files: Array<{ file: string; size: number }>;
  totalSize: number;
  passed: boolean;
}

const budgetRules: BudgetRule[] = [
  { pattern: 'dist/**/*.js', maxSize: 300 * 1024, name: 'JavaScript Total' },
  { pattern: 'dist/**/*.css', maxSize: 80 * 1024, name: 'CSS Total' },
  { pattern: 'dist/js/vendor-*.js', maxSize: 150 * 1024, name: 'Vendor Bundle' },
  { pattern: 'dist/js/app-*.js', maxSize: 80 * 1024, name: 'App Bundle' },
];

async function checkBudgets(rules: BudgetRule[]): Promise<{ passed: boolean; results: BudgetResult[] }> {
  const results: BudgetResult[] = [];

  for (const rule of rules) {
    const files = await glob(rule.pattern);
    const fileDetails = files.map((file) => {
      const content = fs.readFileSync(file);
      const gzipSize = gzipSync(content, { level: 9 }).length;
      return { file: path.basename(file), size: gzipSize };
    });

    const totalSize = fileDetails.reduce((sum, f) => sum + f.size, 0);
    results.push({
      rule,
      files: fileDetails,
      totalSize,
      passed: totalSize <= rule.maxSize,
    });
  }

  console.log('\n📊 Performance Budget Report\n');
  console.log('Budget'.padEnd(25) + 'Actual'.padStart(12) + 'Limit'.padStart(12) + 'Status'.padStart(10));
  console.log('-'.repeat(59));

  for (const result of results) {
    const status = result.passed ? '✅ PASS' : '❌ FAIL';
    console.log(
      result.rule.name.padEnd(25) +
        formatBytes(result.totalSize).padStart(12) +
        formatBytes(result.rule.maxSize).padStart(12) +
        status.padStart(10),
    );
  }

  const allPassed = results.every((r) => r.passed);
  console.log(`\n${allPassed ? '✅ All budgets passed!' : '❌ Some budgets exceeded!'}\n`);

  return { passed: allPassed, results };
}

function formatBytes(bytes: number): string {
  return `${(bytes / 1024).toFixed(1)} KB`;
}

name: Performance Budget Check
on: [pull_request]

jobs:
  budget-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v2
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm

      - run: pnpm install --frozen-lockfile
      - run: pnpm build

      - name: Check bundle budget
        run: node scripts/check-budget.mjs

      - name: Lighthouse CI
        uses: treosh/lighthouse-ci-action@v11
        with:
          configPath: .lighthouserc.json
          uploadArtifacts: true

小结
    

  • 性能预算包括体积预算（Bundle 大小）、时间预算（加载指标）和质量预算（CWV 指标）。
    • 

  • 基于竞品分析和用户数据制定预算值，目标是比竞品快 20%。
    • 

  • 将预算检查集成到 CI/CD 流水线，PR 超标即阻塞合入。
    • 

  • 预算超标时有清晰的处理流程——修复、调整或评审决策。
    • 

  • 所有预算调整必须记录原因，防止预算在无意中持续放宽。
