API 优化

前端 API 请求的性能挑战

在现代 SPA 应用中，页面渲染依赖于 API 数据。API 请求的数量、体积和时序直接影响用户看到内容的速度。一个典型的页面可能需要 5-10 个 API 请求才能渲染完成——如果这些请求是串行的、冗余的或体积过大的，用户体验将大打折扣。



请求合并与批处理
DataLoader 模式
DataLoader 模式将同一帧内的多个请求合并为一次批量请求：


class DataLoader<K, V> {
  private batch: Map<K, { resolve: (v: V) => void; reject: (e: Error) => void }> = new Map();
  private scheduled = false;

  constructor(private batchFn: (keys: K[]) => Promise<V[]>) {}

  load(key: K): Promise<V> {
    return new Promise((resolve, reject) => {
      this.batch.set(key, { resolve, reject });
      this.scheduleDispatch();
    });
  }

  private scheduleDispatch(): void {
    if (this.scheduled) return;
    this.scheduled = true;

    queueMicrotask(async () => {
      const currentBatch = new Map(this.batch);
      this.batch.clear();
      this.scheduled = false;

      const keys = Array.from(currentBatch.keys());
      try {
        const values = await this.batchFn(keys);
        keys.forEach((key, i) => {
          currentBatch.get(key)?.resolve(values[i]);
        });
      } catch (error) {
        keys.forEach((key) => {
          currentBatch.get(key)?.reject(error as Error);
        });
      }
    });
  }
}

const userLoader = new DataLoader<string, any>(async (ids) => {
  const response = await fetch(`/api/users?ids=${ids.join(',')}`);
  return response.json();
});

const [user1, user2, user3] = await Promise.all([userLoader.load('1'), userLoader.load('2'), userLoader.load('3')]);


请求去重
多个组件可能同时请求相同的数据。请求去重确保同一时刻只有一个相同的请求在网络中传输。


class RequestDeduplicator {
  private inflightRequests = new Map<string, Promise<any>>();

  async fetch<T>(url: string, options?: RequestInit): Promise<T> {
    const key = `${options?.method ?? 'GET'}:${url}`;

    if (this.inflightRequests.has(key)) {
      return this.inflightRequests.get(key)!;
    }

    const promise = fetch(url, options)
      .then((res) => {
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        return res.json() as Promise<T>;
      })
      .finally(() => {
        this.inflightRequests.delete(key);
      });

    this.inflightRequests.set(key, promise);
    return promise;
  }
}

const dedup = new RequestDeduplicator();

const [result1, result2] = await Promise.all([dedup.fetch('/api/config'), dedup.fetch('/api/config')]);


数据缓存策略
SWR（Stale-While-Revalidate）模式
interface CacheEntry<T> {
  data: T;
  timestamp: number;
  isRevalidating: boolean;
}

class SWRCache<T> {
  private cache = new Map<string, CacheEntry<T>>();

  constructor(
    private fetcher: (key: string) => Promise<T>,
    private staleTime: number = 5000,
    private cacheTime: number = 300000,
  ) {}

  async get(key: string): Promise<T> {
    const entry = this.cache.get(key);
    const now = Date.now();

    if (entry) {
      const age = now - entry.timestamp;

      if (age < this.staleTime) {
        return entry.data;
      }

      if (age < this.cacheTime && !entry.isRevalidating) {
        entry.isRevalidating = true;
        this.revalidate(key).catch(console.error);
        return entry.data;
      }
    }

    return this.revalidate(key);
  }

  private async revalidate(key: string): Promise<T> {
    const data = await this.fetcher(key);
    this.cache.set(key, {
      data,
      timestamp: Date.now(),
      isRevalidating: false,
    });
    return data;
  }

  invalidate(key: string): void {
    this.cache.delete(key);
  }
}
React Query 集成
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';

interface Product {
  id: string;
  name: string;
  price: number;
}

function useProducts(category: string) {
  return useQuery({
    queryKey: ['products', category],
    queryFn: async (): Promise<Product[]> => {
      const res = await fetch(`/api/products?category=${category}`);
      return res.json();
    },
    staleTime: 5 * 60 * 1000,
    gcTime: 30 * 60 * 1000,
  });
}

function useUpdateProduct() {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: async (product: Partial<Product> & { id: string }) => {
      const res = await fetch(`/api/products/${product.id}`, {
        method: 'PATCH',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(product),
      });
      return res.json();
    },
    onMutate: async (newProduct) => {
      await queryClient.cancelQueries({ queryKey: ['products'] });
      const previous = queryClient.getQueriesData({ queryKey: ['products'] });

      queryClient.setQueriesData<Product[]>({ queryKey: ['products'] }, (old) =>
        old?.map((p) => (p.id === newProduct.id ? { ...p, ...newProduct } : p)),
      );

      return { previous };
    },
    onError: (_err, _newProduct, context) => {
      context?.previous.forEach(([queryKey, data]) => {
        queryClient.setQueryData(queryKey, data);
      });
    },
    onSettled: () => {
      queryClient.invalidateQueries({ queryKey: ['products'] });
    },
  });
}


乐观更新
乐观更新在 API 请求发送的同时立即更新 UI，如果请求失败则回滚。这种模式让用户感觉操作是即时的。


import { useState, useCallback } from 'react';

interface OptimisticState<T> {
  data: T;
  isOptimistic: boolean;
  error: Error | null;
}

function useOptimisticUpdate<T>(
  initialData: T,
  updateFn: (data: T) => Promise<T>,
): {
  state: OptimisticState<T>;
  update: (optimisticData: T) => void;
} {
  const [state, setState] = useState<OptimisticState<T>>({
    data: initialData,
    isOptimistic: false,
    error: null,
  });

  const update = useCallback(
    async (optimisticData: T) => {
      const previousData = state.data;

      setState({ data: optimisticData, isOptimistic: true, error: null });

      try {
        const confirmedData = await updateFn(optimisticData);
        setState({ data: confirmedData, isOptimistic: false, error: null });
      } catch (error) {
        setState({ data: previousData, isOptimistic: false, error: error as Error });
      }
    },
    [state.data, updateFn],
  );

  return { state, update };
}


请求并行化
并行请求 vs 串行请求
interface PageData {
  user: any;
  orders: any[];
  recommendations: any[];
  notifications: any[];
}

async function loadPageDataParallel(): Promise<PageData> {
  const [user, orders, recommendations, notifications] = await Promise.all([
    fetch('/api/user').then((r) => r.json()),
    fetch('/api/orders').then((r) => r.json()),
    fetch('/api/recommendations').then((r) => r.json()),
    fetch('/api/notifications').then((r) => r.json()),
  ]);

  return { user, orders, recommendations, notifications };
}

async function loadPageDataWithPriority(): Promise<PageData> {
  const userPromise = fetch('/api/user').then((r) => r.json());
  const ordersPromise = fetch('/api/orders').then((r) => r.json());

  const [user, orders] = await Promise.all([userPromise, ordersPromise]);

  const [recommendations, notifications] = await Promise.all([
    fetch('/api/recommendations').then((r) => r.json()),
    fetch('/api/notifications').then((r) => r.json()),
  ]);

  return { user, orders, recommendations, notifications };
}


分页与无限滚动
interface PaginatedResponse<T> {
  data: T[];
  total: number;
  page: number;
  pageSize: number;
  hasMore: boolean;
}

interface CursorPaginatedResponse<T> {
  data: T[];
  nextCursor: string | null;
  hasMore: boolean;
}

async function fetchWithCursor<T>(
  url: string,
  cursor?: string,
  limit: number = 20,
): Promise<CursorPaginatedResponse<T>> {
  const params = new URLSearchParams({ limit: String(limit) });
  if (cursor) params.set('cursor', cursor);

  const response = await fetch(`${url}?${params}`);
  return response.json();
}

小结
    

  • 请求合并（DataLoader 模式）将同一帧内的多个请求批处理为一次网络请求。
    • 

  • 请求去重确保同一时刻相同的 API 只有一个请求在传输中。
    • 

  • SWR 模式先返回缓存数据再后台更新，兼顾响应速度和数据新鲜度。
    • 

  • 乐观更新在请求发出的同时立即更新 UI，提供即时的交互反馈。
    • 

  • 使用 Promise.all 并行化独立请求，避免不必要的串行等待。
    • 

  • 大列表数据使用游标分页而非偏移分页，避免深页性能问题。
