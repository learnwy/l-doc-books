Module Federation 模块联邦

Module Federation 概述

Module Federation 是 Webpack 5 引入的革命性特性，允许多个独立构建的应用在运行时动态共享模块。它是目前最成熟的微前端运行时集成方案——每个应用可以独立构建、独立部署，同时在浏览器端实现模块级别的共享和加载。



核心概念




概念
说明





Host
消费远程模块的应用（容器应用）




Remote
暴露模块供其他应用消费的应用




Shared
多个应用之间共享的依赖（如 React）




Exposes
Remote 声明对外暴露的模块




Remotes
Host 声明要消费的远程应用





一个应用可以同时是 Host 和 Remote——即消费其他应用的模块，同时也暴露自己的模块。




Rspack / Webpack 配置
Remote 应用配置
// apps/dashboard/rspack.config.ts
import { ModuleFederationPlugin } from '@rspack/core';

export default {
  plugins: [
    new ModuleFederationPlugin({
      name: 'dashboard',
      filename: 'remoteEntry.js',
      exposes: {
        './DashboardPage': './src/pages/DashboardPage.tsx',
        './AnalyticsWidget': './src/components/AnalyticsWidget.tsx',
        './RevenueChart': './src/components/RevenueChart.tsx',
      },
      shared: {
        react: {
          singleton: true,
          requiredVersion: '^18.0.0',
          eager: false,
        },
        'react-dom': {
          singleton: true,
          requiredVersion: '^18.0.0',
          eager: false,
        },
        'react-router-dom': {
          singleton: true,
          requiredVersion: '^6.0.0',
        },
      },
    }),
  ],
};

动态加载与错误边界
// apps/shell/src/components/RemoteApp.tsx
import { Suspense, lazy } from "react";
import { ErrorBoundary } from "react-error-boundary";

const DashboardPage = lazy(() => import("dashboard/DashboardPage"));
const SettingsPage = lazy(() => import("settings/SettingsPage"));
const ReportsPage = lazy(() => import("reports/ReportsPage"));

function RemoteErrorFallback({ error, resetErrorBoundary }: {
  error: Error;
  resetErrorBoundary: () => void;
}) {
  return (
    <div className="flex flex-col items-center justify-center p-12">
      <h2 className="text-xl font-semibold text-red-600">模块加载失败</h2>
      <p className="mt-2 text-gray-600">{error.message}</p>
      <button
        onClick={resetErrorBoundary}
        className="mt-4 rounded bg-blue-500 px-4 py-2 text-white"
      >
        重试
      </button>
    </div>
  );
}

function LoadingFallback() {
  return (
    <div className="flex items-center justify-center p-12">
      <div className="h-8 w-8 animate-spin rounded-full border-4 border-blue-500 border-t-transparent" />
      <span className="ml-3 text-gray-600">加载中...</span>
    </div>
  );
}

function RemoteApp({ children }: { children: React.ReactNode }) {
  return (
    <ErrorBoundary FallbackComponent={RemoteErrorFallback}>
      <Suspense fallback={<LoadingFallback />}>
        {children}
      </Suspense>
    </ErrorBoundary>
  );
}
Shell 路由集成
// apps/shell/src/App.tsx
import { BrowserRouter, Routes, Route } from "react-router-dom";
import { lazy, Suspense } from "react";

const DashboardPage = lazy(() => import("dashboard/DashboardPage"));
const SettingsPage = lazy(() => import("settings/SettingsPage"));
const ReportsPage = lazy(() => import("reports/ReportsPage"));

function App() {
  return (
    <BrowserRouter>
      <AppLayout>
        <Routes>
          <Route path="/" element={<HomePage />} />
          <Route
            path="/dashboard/*"
            element={
              <RemoteApp>
                <DashboardPage />
              </RemoteApp>
            }
          />
          <Route
            path="/settings/*"
            element={
              <RemoteApp>
                <SettingsPage />
              </RemoteApp>
            }
          />
          <Route
            path="/reports/*"
            element={
              <RemoteApp>
                <ReportsPage />
              </RemoteApp>
            }
          />
        </Routes>
      </AppLayout>
    </BrowserRouter>
  );
}

动态 Remote 加载
在某些场景下，Remote 的地址不是在构建时确定，而是在运行时动态获取。


async function loadRemoteModule(scope: string, module: string, url: string): Promise<any> {
  await new Promise<void>((resolve, reject) => {
    const script = document.createElement('script');
    script.src = url;
    script.type = 'text/javascript';
    script.async = true;
    script.onload = () => resolve();
    script.onerror = () => reject(new Error(`Failed to load ${url}`));
    document.head.appendChild(script);
  });

  const container = (window as any)[scope];
  await container.init(__webpack_share_scopes__.default);
  const factory = await container.get(module);
  return factory();
}

// 使用
const DashboardModule = await loadRemoteModule(
  'dashboard',
  './DashboardPage',
  'https://cdn.example.com/dashboard/remoteEntry.js',
);


小结
    

  • Module Federation 允许多个独立构建的应用在运行时共享模块。
    • 

  • Host 消费远程模块，Remote 暴露模块，Shared 声明共享依赖。
    • 

  • singleton: true 确保全局只有一份 React 实例，避免 Hooks 报错。
    • 

  • 远程组件必须包裹 ErrorBoundary 和 Suspense，处理加载失败和加载中状态。
    • 

  • 动态 Remote 加载适用于 Remote 地址需要运行时确定的场景。
