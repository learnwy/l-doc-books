组件状态模式

核心概念

组件状态是指存储在单个组件内部、仅该组件及其子组件可访问的状态。它是状态管理中最简单、最常用的模式。

为什么选择组件状态
当满足以下条件时，组件状态是最佳选择：


    

  • 状态仅在单个组件或其子树中使用
    • 

  • 状态不需要与应用其他部分共享
    • 

  • 状态变化频率适中，不会引起大范围重渲染
    • 

  • 状态逻辑相对简单，不需要复杂的中间件
    •

React useState 模式
基础用法
import { useState } from 'react'

interface CounterProps {
  initialValue?: number
}

export function Counter({ initialValue = 0 }: CounterProps) {
  const [count, setCount] = useState(initialValue)

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
      <button onClick={() => setCount(count - 1)}>Decrement</button>
      <button onClick={() => setCount(initialValue)}>Reset</button>
    </div>
  )
}
函数式更新
当新状态依赖于旧状态时，使用函数式更新：


function Counter() {
  const [count, setCount] = useState(0)

  const incrementTwice = () => {
    setCount(prev => prev + 1)
    setCount(prev => prev + 1)
  }

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={incrementTwice}>Increment Twice</button>
    </div>
  )
}
懒初始化
对于复杂的初始值计算，使用懒初始化避免每次渲染都执行：


function ExpensiveComponent() {
  const [data, setData] = useState(() => {
    const result = expensiveComputation()
    return result
  })

  return <div>{data}</div>
}
对象状态管理
单个 useState 存储对象
interface User {
  name: string
  age: number
  address: {
    city: string
    street: string
  }
}

function UserProfile() {
  const [user, setUser] = useState<User>({
    name: 'Alice',
    age: 30,
    address: {
      city: 'Beijing',
      street: 'Main St'
    }
  })

  const updateName = (newName: string) => {
    setUser(prev => ({
      ...prev,
      name: newName
    }))
  }

  const updateCity = (newCity: string) => {
    setUser(prev => ({
      ...prev,
      address: {
        ...prev.address,
        city: newCity
      }
    }))
  }

  return (
    <div>
      <input value={user.name} onChange={e => updateName(e.target.value)} />
      <input value={user.address.city} onChange={e => updateCity(e.target.value)} />
    </div>
  )
}
使用 Immer 简化对象更新
import { produce } from 'immer'

function UserProfile() {
  const [user, setUser] = useState<User>({
    name: 'Alice',
    age: 30,
    address: {
      city: 'Beijing',
      street: 'Main St'
    }
  })

  const updateCity = (newCity: string) => {
    setUser(produce(draft => {
      draft.address.city = newCity
    }))
  }

  return (
    <div>
      <input value={user.address.city} onChange={e => updateCity(e.target.value)} />
    </div>
  )
}
数组状态管理
基础数组操作
interface Todo {
  id: string
  text: string
  completed: boolean
}

function TodoList() {
  const [todos, setTodos] = useState<Todo[]>([])

  const addTodo = (text: string) => {
    setTodos(prev => [...prev, {
      id: Date.now().toString(),
      text,
      completed: false
    }])
  }

  const toggleTodo = (id: string) => {
    setTodos(prev => prev.map(todo =>
      todo.id === id ? { ...todo, completed: !todo.completed } : todo
    ))
  }

  const deleteTodo = (id: string) => {
    setTodos(prev => prev.filter(todo => todo.id !== id))
  }

  return (
    <div>
      {todos.map(todo => (
        <div key={todo.id}>
          <input
            type="checkbox"
            checked={todo.completed}
            onChange={() => toggleTodo(todo.id)}
          />
          <span>{todo.text}</span>
          <button onClick={() => deleteTodo(todo.id)}>Delete</button>
        </div>
      ))}
    </div>
  )
}
复合状态模式
使用 useReducer 管理复杂状态
interface State {
  count: number
  status: 'idle' | 'loading' | 'success' | 'error'
  error: string | null
}

type Action =
  | { type: 'increment' }
  | { type: 'decrement' }
  | { type: 'reset' }
  | { type: 'fetch_start' }
  | { type: 'fetch_success'; payload: number }
  | { type: 'fetch_error'; payload: string }

function reducer(state: State, action: Action): State {
  switch (action.type) {
    case 'increment':
      return { ...state, count: state.count + 1 }
    case 'decrement':
      return { ...state, count: state.count - 1 }
    case 'reset':
      return { ...state, count: 0 }
    case 'fetch_start':
      return { ...state, status: 'loading', error: null }
    case 'fetch_success':
      return { ...state, status: 'success', count: action.payload }
    case 'fetch_error':
      return { ...state, status: 'error', error: action.payload }
    default:
      return state
  }
}

function ComplexCounter() {
  const [state, dispatch] = useReducer(reducer, {
    count: 0,
    status: 'idle',
    error: null
  })

  const fetchCount = async () => {
    dispatch({ type: 'fetch_start' })
    try {
      const response = await fetch('/api/count')
      const data = await response.json()
      dispatch({ type: 'fetch_success', payload: data.count })
    } catch (err) {
      dispatch({ type: 'fetch_error', payload: 'Failed to fetch' })
    }
  }

  return (
    <div>
      <p>Count: {state.count}</p>
      <p>Status: {state.status}</p>
      {state.error && <p>Error: {state.error}</p>}
      <button onClick={() => dispatch({ type: 'increment' })}>+</button>
      <button onClick={() => dispatch({ type: 'decrement' })}>-</button>
      <button onClick={() => dispatch({ type: 'reset' })}>Reset</button>
      <button onClick={fetchCount}>Fetch</button>
    </div>
  )
}
状态提升模式
将状态提升到共同父组件
function ChildA({ count, onIncrement }: { count: number; onIncrement: () => void }) {
  return (
    <div>
      <p>Child A: {count}</p>
      <button onClick={onIncrement}>Increment from A</button>
    </div>
  )
}

function ChildB({ count, onDecrement }: { count: number; onDecrement: () => void }) {
  return (
    <div>
      <p>Child B: {count}</p>
      <button onClick={onDecrement}>Decrement from B</button>
    </div>
  )
}

function Parent() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <ChildA count={count} onIncrement={() => setCount(prev => prev + 1)} />
      <ChildB count={count} onDecrement={() => setCount(prev => prev - 1)} />
    </div>
  )
}
常见误区
❌ 误区 1：过度使用组件状态
当状态需要在多个不相关的组件间共享时，组件状态会导致 prop drilling，此时应考虑使用全局状态。


❌ 误区 2：在循环中创建新函数
// ❌ 不好的做法：每次渲染都创建新函数
{items.map(item => (
  <button onClick={() => handleClick(item.id)}>Click</button>
))}

// ✅ 好的做法：使用 useCallback 或 data attribute
const handleClick = useCallback((id: string) => {
  // ...
}, [])

{items.map(item => (
  <button key={item.id} data-id={item.id} onClick={handleClick}>Click</button>
))}
❌ 误区 3：忘记状态更新是异步的
// ❌ 错误：count 不会立即更新
const handleClick = () => {
  setCount(count + 1);
  console.log(count); // 还是旧值
};

// ✅ 正确：使用函数式更新或 useEffect
const handleClick = () => {
  setCount((prev) => prev + 1);
};

useEffect(() => {
  console.log(count); // 最新值
}, [count]);
小结
    

  • 组件状态是状态管理的基础，适用于大多数简单场景
    • 

  • useState 处理简单值，useReducer 处理复杂逻辑
    • 

  • 需要共享时先考虑状态提升，避免过早引入全局状态
    • 



核心要点回顾：


    

  • useState 是最常用的组件状态 API
    • 

  • 复杂状态考虑 useReducer
    • 

  • 对象/数组更新要保持不可变
    • 

  • Immer 可以简化不可变更新
    • 

  • 状态需要共享时考虑提升或全局状态
    •
