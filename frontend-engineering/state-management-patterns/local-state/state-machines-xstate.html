状态机与 XState

核心概念

状态机（State Machine）是一种数学模型，用于描述系统在不同状态之间的转换规则。XState 是一个强大的 JavaScript/TypeScript 状态机库。

为什么使用状态机

  • 消除不确定状态：明确规定系统只能处于有限个状态之一
  • 可视化理解：状态图可以直观地展示系统行为
  • 易于测试：每个状态和转换都可以独立测试
  • 防止 bugs：避免状态不一致导致的问题

状态机基本要素

要素 说明
状态 (State) 系统在某一时刻的条件
事件 (Event) 触发状态转换的输入
转换 (Transition) 从一个状态到另一个状态的规则
动作 (Action) 状态转换时执行的副作用
守卫 (Guard) 决定是否执行转换的条件

基础状态机

简单开关状态机

stateDiagram-v2
    [*] --> Off
    Off --> On: TOGGLE
    On --> Off: TOGGLE
import { createMachine, interpret } from 'xstate';

const toggleMachine = createMachine({
  id: 'toggle',
  initial: 'off',
  states: {
    off: {
      on: {
        TOGGLE: 'on',
      },
    },
    on: {
      on: {
        TOGGLE: 'off',
      },
    },
  },
});

const service = interpret(toggleMachine).start();

service.subscribe((state) => {
  console.log('Current state:', state.value);
});

service.send({ type: 'TOGGLE' });
service.send({ type: 'TOGGLE' });

在 React 中使用

import { useMachine } from '@xstate/react'
import { createMachine } from 'xstate'

const toggleMachine = createMachine({
  id: 'toggle',
  initial: 'inactive',
  states: {
    inactive: {
      on: { TOGGLE: 'active' }
    },
    active: {
      on: { TOGGLE: 'inactive' }
    }
  }
})

function ToggleButton() {
  const [state, send] = useMachine(toggleMachine)

  return (
    <button onClick={() => send({ type: 'TOGGLE' })}>
      {state.matches('inactive') ? 'Activate' : 'Deactivate'}
    </button>
  )
}

表单提交状态机

带有加载和错误状态

stateDiagram-v2
    [*] --> idle
    idle --> loading: SUBMIT
    loading --> success: SUCCESS
    loading --> error: ERROR
    error --> loading: SUBMIT
    success --> idle: RESET
    error --> idle: RESET
import { useMachine } from '@xstate/react'
import { createMachine, assign } from 'xstate'

interface FormContext {
  email: string
  password: string
  error: string | null
}

type FormEvent =
  | { type: 'UPDATE_EMAIL'; value: string }
  | { type: 'UPDATE_PASSWORD'; value: string }
  | { type: 'SUBMIT' }
  | { type: 'SUCCESS' }
  | { type: 'ERROR'; message: string }
  | { type: 'RESET' }

const formMachine = createMachine<FormContext, FormEvent>({
  id: 'form',
  initial: 'idle',
  context: {
    email: '',
    password: '',
    error: null
  },
  states: {
    idle: {
      on: {
        UPDATE_EMAIL: {
          actions: assign({
            email: (_, event) => event.value
          })
        },
        UPDATE_PASSWORD: {
          actions: assign({
            password: (_, event) => event.value
          })
        },
        SUBMIT: 'loading'
      }
    },
    loading: {
      invoke: {
        src: async (context) => {
          const response = await fetch('/api/login', {
            method: 'POST',
            body: JSON.stringify({
              email: context.email,
              password: context.password
            })
          })
          if (!response.ok) {
            throw new Error('Login failed')
          }
          return response.json()
        },
        onDone: 'success',
        onError: {
          target: 'error',
          actions: assign({
            error: (_, event) => event.data.message
          })
        }
      }
    },
    success: {
      on: {
        RESET: {
          target: 'idle',
          actions: assign({
            email: '',
            password: '',
            error: null
          })
        }
      }
    },
    error: {
      on: {
        SUBMIT: 'loading',
        RESET: {
          target: 'idle',
          actions: assign({
            email: '',
            password: '',
            error: null
          })
        }
      }
    }
  }
})

function LoginForm() {
  const [state, send] = useMachine(formMachine)

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault()
    send({ type: 'SUBMIT' })
  }

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <label>Email</label>
        <input
          type="email"
          value={state.context.email}
          onChange={e => send({ type: 'UPDATE_EMAIL', value: e.target.value })}
          disabled={state.matches('loading')}
        />
      </div>
      <div>
        <label>Password</label>
        <input
          type="password"
          value={state.context.password}
          onChange={e => send({ type: 'UPDATE_PASSWORD', value: e.target.value })}
          disabled={state.matches('loading')}
        />
      </div>
      {state.matches('error') && (
        <p>{state.context.error}</p>
      )}
      <button
        type="submit"
        disabled={state.matches('loading')}
      >
        {state.matches('loading') ? 'Loading...' : 'Login'}
      </button>
      {state.matches('success') && (
        <div>
          <p>Login successful!</p>
          <button onClick={() => send({ type: 'RESET' })}>
            Reset
          </button>
        </div>
      )}
    </form>
  )
}

分层状态机

媒体播放器示例

stateDiagram-v2
    [*] --> stopped
    state stopped {
        [*] --> idle
        idle --> playing: PLAY
    }
    state playing {
        [*] --> normal
        normal --> paused: PAUSE
        paused --> normal: PLAY
    }
    stopped --> playing: PLAY
    playing --> stopped: STOP
    playing --> playing: NEXT
    playing --> playing: PREV
import { useMachine } from '@xstate/react'
import { createMachine, assign } from 'xstate'

interface PlayerContext {
  currentTrack: number
  volume: number
  playlist: string[]
}

type PlayerEvent =
  | { type: 'PLAY' }
  | { type: 'PAUSE' }
  | { type: 'STOP' }
  | { type: 'NEXT' }
  | { type: 'PREV' }
  | { type: 'SET_VOLUME'; value: number }

const playerMachine = createMachine<PlayerContext, PlayerEvent>({
  id: 'player',
  initial: 'stopped',
  context: {
    currentTrack: 0,
    volume: 80,
    playlist: ['Track 1', 'Track 2', 'Track 3']
  },
  states: {
    stopped: {
      on: {
        PLAY: 'playing'
      }
    },
    playing: {
      initial: 'normal',
      states: {
        normal: {
          on: {
            PAUSE: 'paused'
          }
        },
        paused: {
          on: {
            PLAY: 'normal'
          }
        }
      },
      on: {
        STOP: 'stopped',
        NEXT: {
          actions: assign({
            currentTrack: (context) =>
              (context.currentTrack + 1) % context.playlist.length
          })
        },
        PREV: {
          actions: assign({
            currentTrack: (context) =>
              (context.currentTrack - 1 + context.playlist.length) % context.playlist.length
          })
        },
        SET_VOLUME: {
          actions: assign({
            volume: (_, event) => event.value
          })
        }
      }
    }
  }
})

function MediaPlayer() {
  const [state, send] = useMachine(playerMachine)

  return (
    <div>
      <h2>{state.context.playlist[state.context.currentTrack]}</h2>
      <p>Status: {state.value}</p>
      {state.matches('playing.normal') && <p>Now Playing</p>}
      {state.matches('playing.paused') && <p>Paused</p>}
      <div>
        <button
          onClick={() => send({ type: 'PREV' })}
          disabled={!state.matches('playing')}
        >
          Previous
        </button>
        {state.matches('playing.normal') ? (
          <button onClick={() => send({ type: 'PAUSE' })}>Pause</button>
        ) : (
          <button onClick={() => send({ type: 'PLAY' })}>Play</button>
        )}
        <button
          onClick={() => send({ type: 'NEXT' })}
          disabled={!state.matches('playing')}
        >
          Next
        </button>
        <button onClick={() => send({ type: 'STOP' })}>Stop</button>
      </div>
      <div>
        <label>Volume: {state.context.volume}</label>
        <input
          type="range"
          min="0"
          max="100"
          value={state.context.volume}
          onChange={e => send({ type: 'SET_VOLUME', value: Number(e.target.value) })}
        />
      </div>
    </div>
  )
}

并行状态机

同时管理多个独立状态

import { useMachine } from '@xstate/react'
import { createMachine } from 'xstate'

const trafficMachine = createMachine({
  id: 'traffic',
  type: 'parallel',
  states: {
    light: {
      initial: 'red',
      states: {
        red: {
          after: { 5000: 'yellow' }
        },
        yellow: {
          after: { 1000: 'green' }
        },
        green: {
          after: { 5000: 'red' }
        }
      }
    },
    pedestrian: {
      initial: 'wait',
      states: {
        wait: {},
        walk: {}
      },
      on: {
        LIGHT_GREEN: { target: '.walk' },
        LIGHT_RED: { target: '.wait' }
      }
    }
  }
})

function TrafficLight() {
  const [state] = useMachine(trafficMachine)

  return (
    <div>
      <div>Light: {state.value.light}</div>
      <div>Pedestrian: {state.value.pedestrian}</div>
    </div>
  )
}

常见误区

❌ 误区 1：过度使用状态机

对于简单的布尔开关，普通 useState 就足够了，不需要引入状态机。

❌ 误区 2：状态设计过于复杂

保持状态简单，避免创建过多的微状态。

❌ 误区 3：忽略守卫条件

// ✅ 正确：使用守卫条件
const machine = createMachine(
  {
    initial: 'idle',
    states: {
      idle: {
        on: {
          SUBMIT: [{ target: 'loading', cond: 'isFormValid' }, { target: 'error' }],
        },
      },
      loading: {},
      error: {},
    },
  },
  {
    guards: {
      isFormValid: (context) => context.email && context.password,
    },
  },
);

小结

状态机是管理复杂状态的强大工具，XState 让状态机在 React 中变得简单易用。

核心要点回顾：

  • 状态机消除了不确定状态
  • XState 提供了可视化和类型安全
  • 适合管理复杂的异步流程和表单
  • 分层和并行状态机可以处理复杂场景
  • 不要过度使用，简单场景用 useState
