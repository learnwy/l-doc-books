Signals 模式

核心概念

Signals 是一种细粒度的响应式原语，提供了精确的依赖追踪和最小化的更新。

Signals 的优势

  • 极致性能：只有真正变化的部分才更新
  • 细粒度控制：精确追踪哪个组件依赖哪个 signal
  • 框架无关：可以在任意框架或无框架中使用
  • 简单 API：学习曲线平缓

Signals vs 其他方案

特性 Signals Redux Jotai MobX
性能 极高 中等 高 高
API 复杂度 低 中 低 中
生态系统 较小 大 小 中

Preact Signals

基础用法

import { signal, computed, effect } from '@preact/signals'

const count = signal(0)
const double = computed(() => count.value * 2)

effect(() => {
  console.log('Count changed:', count.value)
})

function Counter() {
  return (
    <div>
      <p>Count: {count}</p>
      <p>Double: {double}</p>
      <button onClick={() => count.value += 1}>+</button>
      <button onClick={() => count.value -= 1}>-</button>
    </div>
  )
}

Computed Signals

import { signal, computed } from '@preact/signals'

const firstName = signal('')
const lastName = signal('')

const fullName = computed(() => {
  return `${firstName.value} ${lastName.value}`.trim()
})

const characterCount = computed(() => {
  return fullName.value.length
})

function NameForm() {
  return (
    <div>
      <input
        value={firstName}
        onInput={(e) => (firstName.value = e.currentTarget.value)}
        placeholder="First Name"
      />
      <input
        value={lastName}
        onInput={(e) => (lastName.value = e.currentTarget.value)}
        placeholder="Last Name"
      />
      <p>Full Name: {fullName}</p>
      <p>Characters: {characterCount}</p>
    </div>
  )
}

批量更新

import { signal, batch } from '@preact/signals';

const todos = signal<Todo[]>([]);
const filter = signal<'all' | 'active' | 'completed'>('all');

function addTodo(text: string) {
  batch(() => {
    todos.value = [
      ...todos.value,
      {
        id: Date.now().toString(),
        text,
        completed: false,
      },
    ];
    filter.value = 'all';
  });
}

Solid.js Signals

基础用法

import { createSignal, createEffect } from 'solid-js'

function Counter() {
  const [count, setCount] = createSignal(0)

  createEffect(() => {
    console.log('Count:', count())
  })

  return (
    <div>
      <p>Count: {count()}</p>
      <button onClick={() => setCount(c => c + 1)}>+</button>
      <button onClick={() => setCount(c => c - 1)}>-</button>
    </div>
  )
}

Derived Signals

import { createSignal, createMemo } from 'solid-js'

function TodoList() {
  const [todos, setTodos] = createSignal<Todo[]>([])
  const [filter, setFilter] = createSignal<'all' | 'active' | 'completed'>('all')

  const filteredTodos = createMemo(() => {
    switch (filter()) {
      case 'active':
        return todos().filter(todo => !todo.completed)
      case 'completed':
        return todos().filter(todo => todo.completed)
      default:
        return todos()
    }
  })

  const stats = createMemo(() => ({
    total: todos().length,
    completed: todos().filter(t => t.completed).length,
    active: todos().filter(t => !t.completed).length
  }))

  const addTodo = (text: string) => {
    setTodos(prev => [...prev, {
      id: Date.now().toString(),
      text,
      completed: false
    }])
  }

  const toggleTodo = (id: string) => {
    setTodos(prev => prev.map(todo =>
      todo.id === id ? { ...todo, completed: !todo.completed } : todo
    ))
  }

  return (
    <div>
      <div>
        <p>Total: {stats().total}</p>
        <p>Active: {stats().active}</p>
        <p>Completed: {stats().completed}</p>
      </div>
      <For each={filteredTodos()}>
        {(todo) => (
          <div>
            <input
              type="checkbox"
              checked={todo.completed}
              onChange={() => toggleTodo(todo.id)}
            />
            {todo.text}
          </div>
        )}
      </For>
    </div>
  )
}

自定义 Signals

简单实现

type Effect = () => void;

class Signal<T> {
  private _value: T;
  private _subscribers: Set<Effect> = new Set();

  constructor(value: T) {
    this._value = value;
  }

  get value() {
    this._track();
    return this._value;
  }

  set value(newValue: T) {
    if (this._value !== newValue) {
      this._value = newValue;
      this._notify();
    }
  }

  private _track() {
    if (currentEffect) {
      this._subscribers.add(currentEffect);
    }
  }

  private _notify() {
    this._subscribers.forEach((effect) => effect());
  }
}

let currentEffect: Effect | null = null;

function effect(fn: Effect) {
  const prevEffect = currentEffect;
  currentEffect = fn;
  fn();
  currentEffect = prevEffect;
}

function computed<T>(fn: () => T) {
  const signal = new Signal<T>(undefined as T);
  effect(() => {
    signal.value = fn();
  });
  return signal;
}

const count = new Signal(0);
const double = computed(() => count.value * 2);

effect(() => {
  console.log('Count:', count.value);
  console.log('Double:', double.value);
});

count.value = 1;
count.value = 2;

常见误区

❌ 误区 1：过度使用 Signals

简单的局部状态用 useState 即可。

❌ 误区 2：在 effect 中修改 signal

可能导致无限循环，小心使用。

❌ 误区 3：忘记 signal 是值（Preact）

Preact Signals 需要 .value 来访问。

小结

    

  • Signals 是最高效的响应式原语，无虚拟 DOM 开销
    • 

  • Solid.js 和 Preact 是最成熟的 Signals 实现
    • 

  • TC39 正在推进 Signals 标准化提案
