原子状态：Jotai & Recoil

核心概念

原子状态（Atomic State）将状态拆分为最小的独立单元——原子（Atom），组件可以订阅任意原子的变化。

原子状态的优势
    

  • 细粒度更新：只有依赖的原子变化时组件才重新渲染
    • 

  • 简单的 API：不需要 Provider、Action、Reducer 等概念
    • 

  • 灵活组合：原子可以派生出其他原子
    • 

  • TypeScript 友好：类型推断优秀
    •

Jotai 基础
基础用法
import { atom, useAtom } from 'jotai'

const countAtom = atom(0)

function Counter() {
  const [count, setCount] = useAtom(countAtom)

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(c => c + 1)}>+</button>
      <button onClick={() => setCount(c => c - 1)}>-</button>
    </div>
  )
}
派生原子
import { atom, useAtom } from 'jotai'

const firstNameAtom = atom('')
const lastNameAtom = atom('')

const fullNameAtom = atom((get) => {
  const firstName = get(firstNameAtom)
  const lastName = get(lastNameAtom)
  return `${firstName} ${lastName}`.trim()
})

const characterCountAtom = atom((get) => {
  return get(fullNameAtom).length
})

function NameForm() {
  const [firstName, setFirstName] = useAtom(firstNameAtom)
  const [lastName, setLastName] = useAtom(lastNameAtom)
  const [fullName] = useAtom(fullNameAtom)
  const [characterCount] = useAtom(characterCountAtom)

  return (
    <div>
      <input
        value={firstName}
        onChange={e => setFirstName(e.target.value)}
        placeholder="First Name"
      />
      <input
        value={lastName}
        onChange={e => setLastName(e.target.value)}
        placeholder="Last Name"
      />
      <p>Full Name: {fullName}</p>
      <p>Characters: {characterCount}</p>
    </div>
  )
}
异步原子
import { atom, useAtom } from 'jotai'

interface User {
  id: string
  name: string
  email: string
}

const userIdAtom = atom('1')

const userAtom = atom(async (get) => {
  const userId = get(userIdAtom)
  const response = await fetch(`/api/users/${userId}`)
  return response.json() as User
})

function UserProfile() {
  const [userId, setUserId] = useAtom(userIdAtom)
  const [user] = useAtom(userAtom)

  return (
    <div>
      <select value={userId} onChange={e => setUserId(e.target.value)}>
        <option value="1">User 1</option>
        <option value="2">User 2</option>
        <option value="3">User 3</option>
      </select>
      <React.Suspense fallback={<div>Loading...</div>}>
        {user && (
          <div>
            <h1>{user.name}</h1>
            <p>{user.email}</p>
          </div>
        )}
      </React.Suspense>
    </div>
  )
}
可写派生原子
import { atom, useAtom } from 'jotai'

const todosAtom = atom<Todo[]>([])

const filterAtom = atom<'all' | 'active' | 'completed'>('all')

const filteredTodosAtom = atom(
  (get) => {
    const todos = get(todosAtom)
    const filter = get(filterAtom)
    switch (filter) {
      case 'active':
        return todos.filter(todo => !todo.completed)
      case 'completed':
        return todos.filter(todo => todo.completed)
      default:
        return todos
    }
  },
  (get, set, action: { type: 'add'; text: string } | { type: 'toggle'; id: string }) => {
    const todos = get(todosAtom)
    switch (action.type) {
      case 'add':
        set(todosAtom, [...todos, {
          id: Date.now().toString(),
          text: action.text,
          completed: false
        }])
        break
      case 'toggle':
        set(todosAtom, todos.map(todo =>
          todo.id === action.id ? { ...todo, completed: !todo.completed } : todo
        ))
        break
    }
  }
)

function TodoList() {
  const [todos, dispatch] = useAtom(filteredTodosAtom)
  const [filter, setFilter] = useAtom(filterAtom)
  const [inputText, setInputText] = useState('')

  const handleAdd = () => {
    if (inputText.trim()) {
      dispatch({ type: 'add', text: inputText })
      setInputText('')
    }
  }

  return (
    <div>
      <input
        value={inputText}
        onChange={e => setInputText(e.target.value)}
        onKeyPress={e => e.key === 'Enter' && handleAdd()}
      />
      <button onClick={handleAdd}>Add</button>
      <div>
        <button onClick={() => setFilter('all')}>All</button>
        <button onClick={() => setFilter('active')}>Active</button>
        <button onClick={() => setFilter('completed')}>Completed</button>
      </div>
      <ul>
        {todos.map(todo => (
          <li key={todo.id}>
            <input
              type="checkbox"
              checked={todo.completed}
              onChange={() => dispatch({ type: 'toggle', id: todo.id })}
            />
            {todo.text}
          </li>
        ))}
      </ul>
    </div>
  )
}
Recoil 基础
基础用法
import { atom, useRecoilState } from 'recoil'

const countState = atom({
  key: 'countState',
  default: 0
})

function Counter() {
  const [count, setCount] = useRecoilState(countState)

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(c => c + 1)}>+</button>
    </div>
  )
}
选择器（Selector）
import { atom, selector, useRecoilValue, useRecoilState } from 'recoil'

const firstNameState = atom({
  key: 'firstNameState',
  default: ''
})

const lastNameState = atom({
  key: 'lastNameState',
  default: ''
})

const fullNameState = selector({
  key: 'fullNameState',
  get: ({ get }) => {
    const firstName = get(firstNameState)
    const lastName = get(lastNameState)
    return `${firstName} ${lastName}`.trim()
  }
})

function NameForm() {
  const [firstName, setFirstName] = useRecoilState(firstNameState)
  const [lastName, setLastName] = useRecoilState(lastNameState)
  const fullName = useRecoilValue(fullNameState)

  return (
    <div>
      <input value={firstName} onChange={e => setFirstName(e.target.value)} />
      <input value={lastName} onChange={e => setLastName(e.target.value)} />
      <p>{fullName}</p>
    </div>
  )
}
常见误区
❌ 误区 1：原子粒度过细
过度拆分原子会增加复杂度，找到合理的粒度。


❌ 误区 2：过度使用异步原子
简单的异步操作可以在组件内用 useEffect + useState。


❌ 误区 3：忘记 atom 的 key（Recoil）
Recoil 的 atom 需要唯一的 key。


小结
    

  • 原子状态是轻量级全局状态管理的优秀选择
    • 

  • Jotai 更简洁，Recoil 功能更丰富
    • 

  • 适合组件间共享状态但不需要 Redux 级别复杂度的场景
    • 



核心要点回顾：


    

  • Jotai 更轻量、API 更简单
    • 

  • Recoil 生态更丰富
    • 

  • 派生原子/选择器灵活组合状态
    • 

  • 细粒度更新性能优秀
    • 

  • TypeScript 支持良好
    •
