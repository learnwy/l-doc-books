代理状态：MobX & Valtio

核心概念

代理状态（Proxy State）使用 JavaScript Proxy 来追踪状态变化，允许直接修改状态，自动追踪依赖并触发更新。

代理状态的优势

  • 直观的 API：像修改普通对象一样修改状态
  • 自动追踪：自动收集依赖，无需手动声明
  • 最小更新：只有实际使用的属性变化时才更新
  • 可变但可预测：看起来可变，实际上是响应式的

MobX vs Valtio

特性 MobX Valtio
成熟度 高，长期维护 中等，较新
API 复杂度 中等 简单
包大小 较大 小 (~2KB)
装饰器 支持 不需要

MobX 基础

核心概念

import { makeAutoObservable } from 'mobx'
import { observer } from 'mobx-react-lite'

class CounterStore {
  count = 0

  constructor() {
    makeAutoObservable(this)
  }

  increment() {
    this.count += 1
  }

  decrement() {
    this.count -= 1
  }

  reset() {
    this.count = 0
  }
}

const counterStore = new CounterStore()

const Counter = observer(() => {
  return (
    <div>
      <p>Count: {counterStore.count}</p>
      <button onClick={() => counterStore.increment()}>+</button>
      <button onClick={() => counterStore.decrement()}>-</button>
      <button onClick={() => counterStore.reset()}>Reset</button>
    </div>
  )
})

计算值（Computed）

import { makeAutoObservable } from 'mobx'
import { observer } from 'mobx-react-lite'

class TodoStore {
  todos: Todo[] = []

  constructor() {
    makeAutoObservable(this)
  }

  get completedTodos() {
    return this.todos.filter(todo => todo.completed)
  }

  get activeTodos() {
    return this.todos.filter(todo => !todo.completed)
  }

  get stats() {
    return {
      total: this.todos.length,
      completed: this.completedTodos.length,
      active: this.activeTodos.length
    }
  }

  addTodo(text: string) {
    this.todos.push({
      id: Date.now().toString(),
      text,
      completed: false
    })
  }

  toggleTodo(id: string) {
    const todo = this.todos.find(t => t.id === id)
    if (todo) {
      todo.completed = !todo.completed
    }
  }

  deleteTodo(id: string) {
    const index = this.todos.findIndex(t => t.id === id)
    if (index > -1) {
      this.todos.splice(index, 1)
    }
  }
}

const todoStore = new TodoStore()

const TodoList = observer(() => {
  const [inputText, setInputText] = useState('')

  const handleAdd = () => {
    if (inputText.trim()) {
      todoStore.addTodo(inputText)
      setInputText('')
    }
  }

  return (
    <div>
      <div>
        <p>Total: {todoStore.stats.total}</p>
        <p>Active: {todoStore.stats.active}</p>
        <p>Completed: {todoStore.stats.completed}</p>
      </div>
      <input
        value={inputText}
        onChange={e => setInputText(e.target.value)}
        onKeyPress={e => e.key === 'Enter' && handleAdd()}
      />
      <button onClick={handleAdd}>Add</button>
      <ul>
        {todoStore.todos.map(todo => (
          <li key={todo.id}>
            <input
              type="checkbox"
              checked={todo.completed}
              onChange={() => todoStore.toggleTodo(todo.id)}
            />
            {todo.text}
            <button onClick={() => todoStore.deleteTodo(todo.id)}>Delete</button>
          </li>
        ))}
      </ul>
    </div>
  )
})

异步操作

import { makeAutoObservable, runInAction } from 'mobx'
import { observer } from 'mobx-react-lite'

class UserStore {
  user: User | null = null
  status: 'idle' | 'loading' | 'success' | 'error' = 'idle'
  error: string | null = null

  constructor() {
    makeAutoObservable(this)
  }

  async fetchUser(userId: string) {
    this.status = 'loading'
    this.error = null
    try {
      const response = await fetch(`/api/users/${userId}`)
      const data = await response.json()
      runInAction(() => {
        this.user = data
        this.status = 'success'
      })
    } catch (err) {
      runInAction(() => {
        this.status = 'error'
        this.error = err instanceof Error ? err.message : 'Failed to fetch user'
      })
    }
  }
}

const userStore = new UserStore()

const UserProfile = observer(({ userId }: { userId: string }) => {
  useEffect(() => {
    userStore.fetchUser(userId)
  }, [userId])

  if (userStore.status === 'loading') {
    return <div>Loading...</div>
  }

  if (userStore.status === 'error') {
    return <div>Error: {userStore.error}</div>
  }

  if (!userStore.user) {
    return null
  }

  return (
    <div>
      <h1>{userStore.user.name}</h1>
      <p>{userStore.user.email}</p>
    </div>
  )
})

基础用法

import { proxy, useSnapshot } from 'valtio'

const state = proxy({ count: 0 })

function Counter() {
  const snap = useSnapshot(state)

  return (
    <div>
      <p>Count: {snap.count}</p>
      <button onClick={() => state.count += 1}>+</button>
      <button onClick={() => state.count -= 1}>-</button>
      <button onClick={() => state.count = 0}>Reset</button>
    </div>
  )
}

派生状态

import { proxy, useSnapshot, derive } from 'valtio'

const state = proxy({
  todos: [] as Todo[],
  filter: 'all' as 'all' | 'active' | 'completed'
})

const derived = derive({
  filteredTodos: (get) => {
    const { todos, filter } = get(state)
    switch (filter) {
      case 'active':
        return todos.filter(todo => !todo.completed)
      case 'completed':
        return todos.filter(todo => todo.completed)
      default:
        return todos
    }
  },
  stats: (get) => {
    const todos = get(state).todos
    return {
      total: todos.length,
      completed: todos.filter(t => t.completed).length,
      active: todos.filter(t => !t.completed).length
    }
  }
})

function TodoList() {
  const snap = useSnapshot(state)
  const derivedSnap = useSnapshot(derived)
  const [inputText, setInputText] = useState('')

  const handleAdd = () => {
    if (inputText.trim()) {
      state.todos.push({
        id: Date.now().toString(),
        text: inputText,
        completed: false
      })
      setInputText('')
    }
  }

  const toggleTodo = (id: string) => {
    const todo = state.todos.find(t => t.id === id)
    if (todo) {
      todo.completed = !todo.completed
    }
  }

  return (
    <div>
      <div>
        <p>Total: {derivedSnap.stats.total}</p>
        <p>Active: {derivedSnap.stats.active}</p>
        <p>Completed: {derivedSnap.stats.completed}</p>
      </div>
      <input
        value={inputText}
        onChange={e => setInputText(e.target.value)}
        onKeyPress={e => e.key === 'Enter' && handleAdd()}
      />
      <button onClick={handleAdd}>Add</button>
      <div>
        <button onClick={() => state.filter = 'all'}>All</button>
        <button onClick={() => state.filter = 'active'}>Active</button>
        <button onClick={() => state.filter = 'completed'}>Completed</button>
      </div>
      <ul>
        {derivedSnap.filteredTodos.map(todo => (
          <li key={todo.id}>
            <input
              type="checkbox"
              checked={todo.completed}
              onChange={() => toggleTodo(todo.id)}
            />
            {todo.text}
          </li>
        ))}
      </ul>
    </div>
  )
}

常见误区

❌ 误区 1：在 render 中修改状态

不要在组件渲染时直接修改代理状态。

❌ 误区 2：忘记 useSnapshot（Valtio）

不使用 useSnapshot 组件不会更新。

❌ 误区 3：过度使用类（MobX）

现代 MobX 也支持函数式风格，不一定非要用类。

小结

    

  • 代理状态让可变写法也能实现响应式更新
    • 

  • MobX 功能最全面，Valtio 最简洁
    • 

  • Proxy 是现代浏览器标准，兼容性良好
