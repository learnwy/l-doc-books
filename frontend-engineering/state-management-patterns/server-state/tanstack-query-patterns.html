TanStack Query 模式

核心概念

TanStack Query（原 React Query）是一个专门用于管理服务器状态的库，它处理缓存、同步、后台更新等复杂问题。

为什么选择 TanStack Query

特性 说明
自动缓存 智能缓存，避免重复请求
后台更新 自动在后台刷新数据
乐观更新 快速响应用户操作
分页/无限加载 内置支持复杂列表
DevTools 强大的调试工具

基础查询

简单查询

import { useQuery } from '@tanstack/react-query'

interface User {
  id: string
  name: string
  email: string
}

async function fetchUser(userId: string): Promise<User> {
  const response = await fetch(`/api/users/${userId}`)
  if (!response.ok) {
    throw new Error('Failed to fetch user')
  }
  return response.json()
}

function UserProfile({ userId }: { userId: string }) {
  const { data, isLoading, isError, error } = useQuery({
    queryKey: ['user', userId],
    queryFn: () => fetchUser(userId)
  })

  if (isLoading) {
    return <div>Loading...</div>
  }

  if (isError) {
    return <div>Error: {error.message}</div>
  }

  if (!data) {
    return null
  }

  return (
    <div>
      <h1>{data.name}</h1>
      <p>{data.email}</p>
    </div>
  )
}

查询配置

function UserProfile({ userId }: { userId: string }) {
  const { data, isLoading, refetch } = useQuery({
    queryKey: ['user', userId],
    queryFn: () => fetchUser(userId),
    enabled: !!userId,
    staleTime: 5 * 60 * 1000,
    gcTime: 10 * 60 * 1000,
    refetchOnWindowFocus: true,
    refetchOnReconnect: true,
    retry: 3,
    retryDelay: attemptIndex => Math.min(1000 * 2 ** attemptIndex, 30000)
  })

  return (
    <div>
      {isLoading && <div>Loading...</div>}
      {data && (
        <div>
          <h1>{data.name}</h1>
          <button onClick={() => refetch()}>Refresh</button>
        </div>
      )}
    </div>
  )
}

变更（Mutation）

基础 Mutation

import { useMutation, useQueryClient } from '@tanstack/react-query'

async function createTodo(text: string): Promise<Todo> {
  const response = await fetch('/api/todos', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ text })
  })
  if (!response.ok) {
    throw new Error('Failed to create todo')
  }
  return response.json()
}

function TodoForm() {
  const queryClient = useQueryClient()
  const [text, setText] = useState('')

  const mutation = useMutation({
    mutationFn: createTodo,
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['todos'] })
    }
  })

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault()
    if (text.trim()) {
      mutation.mutate(text)
      setText('')
    }
  }

  return (
    <form onSubmit={handleSubmit}>
      <input
        value={text}
        onChange={e => setText(e.target.value)}
        disabled={mutation.isPending}
      />
      <button type="submit" disabled={mutation.isPending}>
        {mutation.isPending ? 'Adding...' : 'Add Todo'}
      </button>
      {mutation.isError && <div>Error: {mutation.error.message}</div>}
      {mutation.isSuccess && <div>Todo added!</div>}
    </form>
  )
}

分页查询

import { useInfiniteQuery } from '@tanstack/react-query'

interface TodosResponse {
  todos: Todo[]
  nextCursor: string | null
}

async function fetchTodos({ pageParam }: { pageParam?: string }): Promise<TodosResponse> {
  const url = pageParam ? `/api/todos?cursor=${pageParam}` : '/api/todos'
  const response = await fetch(url)
  return response.json()
}

function TodoList() {
  const {
    data,
    isLoading,
    isError,
    error,
    fetchNextPage,
    hasNextPage,
    isFetchingNextPage
  } = useInfiniteQuery({
    queryKey: ['todos'],
    queryFn: fetchTodos,
    initialPageParam: undefined,
    getNextPageParam: (lastPage) => lastPage.nextCursor
  })

  if (isLoading) {
    return <div>Loading...</div>
  }

  if (isError) {
    return <div>Error: {error.message}</div>
  }

  const todos = data?.pages.flatMap(page => page.todos) ?? []

  return (
    <div>
      <ul>
        {todos.map(todo => (
          <li key={todo.id}>{todo.text}</li>
        ))}
      </ul>
      {hasNextPage && (
        <button
          onClick={() => fetchNextPage()}
          disabled={isFetchingNextPage}
        >
          {isFetchingNextPage ? 'Loading more...' : 'Load More'}
        </button>
      )}
    </div>
  )
}

选择器（Select）

function UserName({ userId }: { userId: string }) {
  const { data: userName } = useQuery({
    queryKey: ['user', userId],
    queryFn: () => fetchUser(userId),
    select: (user) => user.name
  })

  return <div>{userName}</div>
}

function UserStats() {
  const { data: stats } = useQuery({
    queryKey: ['todos'],
    queryFn: fetchTodos,
    select: (todos) => ({
      total: todos.length,
      completed: todos.filter(t => t.completed).length,
      active: todos.filter(t => !t.completed).length
    })
  })

  if (!stats) return null

  return (
    <div>
      <p>Total: {stats.total}</p>
      <p>Completed: {stats.completed}</p>
      <p>Active: {stats.active}</p>
    </div>
  )
}

常见误区

❌ 误区 1：所有数据都用 TanStack Query

客户端状态用 useState，服务器状态用 TanStack Query。

❌ 误区 2：忘记 queryKey

queryKey 必须唯一且包含所有依赖项。

❌ 误区 3：在 queryFn 中使用 useState

queryFn 应该是纯函数，只负责获取数据。

小结

    

  • TanStack Query 是服务器状态管理的首选方案
    • 

  • queryKey 是缓存系统的核心，设计好键结构很重要
    • 

  • staleTime 和 gcTime 的合理配置决定了缓存策略
