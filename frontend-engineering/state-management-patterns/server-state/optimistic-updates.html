乐观更新

核心概念

乐观更新（Optimistic Update）是在服务器响应返回之前，先假设请求成功并更新 UI，提供即时反馈的技术。

乐观更新的优势

优势 说明
更好的用户体验 即时响应，无需等待
感知性能提升 应用感觉更快
类似原生应用 接近原生应用的体验

乐观更新的风险

风险 说明
需要回滚 请求失败时需要恢复旧状态
状态不一致 短暂的不一致状态
复杂度增加 需要处理更多边界情况

TanStack Query 乐观更新

基础实现

import { useMutation, useQueryClient } from '@tanstack/react-query'

interface Todo {
  id: string
  text: string
  completed: boolean
}

async function toggleTodo(todoId: string): Promise<Todo> {
  const response = await fetch(`/api/todos/${todoId}/toggle`, {
    method: 'POST'
  })
  if (!response.ok) {
    throw new Error('Failed to toggle todo')
  }
  return response.json()
}

function TodoItem({ todo }: { todo: Todo }) {
  const queryClient = useQueryClient()

  const mutation = useMutation({
    mutationFn: toggleTodo,
    onMutate: async (todoId) => {
      await queryClient.cancelQueries({ queryKey: ['todos'] })

      const previousTodos = queryClient.getQueryData<Todo[]>(['todos'])

      queryClient.setQueryData<Todo[]>(['todos'], (old) =>
        old?.map(t =>
          t.id === todoId ? { ...t, completed: !t.completed } : t
        )
      )

      return { previousTodos }
    },
    onError: (err, todoId, context) => {
      if (context?.previousTodos) {
        queryClient.setQueryData(['todos'], context.previousTodos)
      }
    },
    onSettled: () => {
      queryClient.invalidateQueries({ queryKey: ['todos'] })
    }
  })

  return (
    <div>
      <input
        type="checkbox"
        checked={todo.completed}
        onChange={() => mutation.mutate(todo.id)}
        disabled={mutation.isPending}
      />
      <span>{todo.text}</span>
    </div>
  )
}

添加新项

async function addTodo(text: string): Promise<Todo> {
  const response = await fetch('/api/todos', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ text })
  })
  return response.json()
}

function TodoForm() {
  const queryClient = useQueryClient()
  const [text, setText] = useState('')

  const mutation = useMutation({
    mutationFn: addTodo,
    onMutate: async (newText) => {
      await queryClient.cancelQueries({ queryKey: ['todos'] })

      const previousTodos = queryClient.getQueryData<Todo[]>(['todos'])

      const optimisticTodo: Todo = {
        id: Date.now().toString(),
        text: newText,
        completed: false
      }

      queryClient.setQueryData<Todo[]>(['todos'], (old) => [
        ...(old || []),
        optimisticTodo
      ])

      return { previousTodos, optimisticTodo }
    },
    onError: (err, newText, context) => {
      if (context?.previousTodos) {
        queryClient.setQueryData(['todos'], context.previousTodos)
      }
    },
    onSuccess: (newTodo, newText, context) => {
      queryClient.setQueryData<Todo[]>(['todos'], (old) =>
        old?.map(t =>
          t.id === context?.optimisticTodo?.id ? newTodo : t
        )
      )
    }
  })

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault()
    if (text.trim()) {
      mutation.mutate(text)
      setText('')
    }
  }

  return (
    <form onSubmit={handleSubmit}>
      <input
        value={text}
        onChange={e => setText(e.target.value)}
        disabled={mutation.isPending}
      />
      <button type="submit" disabled={mutation.isPending}>
        {mutation.isPending ? 'Adding...' : 'Add'}
      </button>
    </form>
  )
}

SWR 乐观更新

import useSWR, { mutate } from 'swr'

function TodoItem({ todo }: { todo: Todo }) {
  const handleToggle = async () => {
    mutate(
      '/api/todos',
      async () => {
        const updatedTodo = await toggleTodo(todo.id)
        return updatedTodo
      },
      {
        optimisticData: (todos: Todo[]) =>
          todos.map(t =>
            t.id === todo.id ? { ...t, completed: !t.completed } : t
          ),
        rollbackOnError: true,
        revalidate: true
      }
    )
  }

  return (
    <div>
      <input
        type="checkbox"
        checked={todo.completed}
        onChange={handleToggle}
      />
      <span>{todo.text}</span>
    </div>
  )
}

原生实现

function TodoList() {
  const [todos, setTodos] = useState<Todo[]>([])
  const [pendingTodos, setPendingTodos] = useState<Set<string>>(new Set())

  const handleToggle = async (todoId: string) => {
    const previousTodos = [...todos]

    setTodos(prev =>
      prev.map(t =>
        t.id === todoId ? { ...t, completed: !t.completed } : t
      )
    )
    setPendingTodos(prev => new Set(prev).add(todoId))

    try {
      await toggleTodo(todoId)
    } catch (error) {
      setTodos(previousTodos)
    } finally {
      setPendingTodos(prev => {
        const next = new Set(prev)
        next.delete(todoId)
        return next
      })
    }
  }

  return (
    <ul>
      {todos.map(todo => (
        <li key={todo.id}>
          <input
            type="checkbox"
            checked={todo.completed}
            onChange={() => handleToggle(todo.id)}
            disabled={pendingTodos.has(todo.id)}
          />
          <span>{todo.text}</span>
          {pendingTodos.has(todo.id) && <span>...</span>}
        </li>
      ))}
    </ul>
  )
}

常见误区

❌ 误区 1：不处理回滚

始终实现错误时的回滚逻辑。

❌ 误区 2：过度乐观更新

不是所有操作都适合乐观更新。

❌ 误区 3：不显示加载状态

用户需要知道操作正在进行。

小结

    

  • 乐观更新大幅提升用户体验，操作感觉瞬间完成
    • 

  • 核心模式：保存旧状态 → 更新 UI → 请求服务器 → 失败回滚
    • 

  • 适合成功率高、用户期望即时反馈的操作
