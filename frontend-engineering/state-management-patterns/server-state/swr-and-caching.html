SWR 与缓存

核心概念

SWR (Stale-While-Revalidate) 是一种 HTTP 缓存策略，核心思想是先从缓存（stale）返回数据，同时在后台重新验证（revalidate），最终用新数据替换。这种策略让用户几乎感觉不到加载延迟，同时保证数据最终会更新到最新状态。

SWR 基础
简单使用
import useSWR from 'swr'

const fetcher = (url: string) => fetch(url).then(res => res.json())

interface User {
  id: string
  name: string
  email: string
}

function UserProfile({ userId }: { userId: string }) {
  const { data, error, isLoading, mutate } = useSWR<User>(
    `/api/users/${userId}`,
    fetcher
  )

  if (isLoading) {
    return <div>Loading...</div>
  }

  if (error) {
    return <div>Error: {error.message}</div>
  }

  if (!data) {
    return null
  }

  return (
    <div>
      <h1>{data.name}</h1>
      <p>{data.email}</p>
      <button onClick={() => mutate()}>Refresh</button>
    </div>
  )
}
配置选项
function UserProfile({ userId }: { userId: string }) {
  const { data, error } = useSWR<User>(
    userId ? `/api/users/${userId}` : null,
    fetcher,
    {
      refreshInterval: 30000,
      revalidateOnFocus: true,
      revalidateOnReconnect: true,
      dedupingInterval: 2000,
      errorRetryCount: 3,
      errorRetryInterval: 1000,
      suspense: false
    }
  )

  return (
    <div>
      {data && <h1>{data.name}</h1>}
    </div>
  )
}
变更与缓存更新
本地更新
import useSWR, { mutate } from 'swr'

async function updateUser(userId: string, userData: Partial<User>) {
  const response = await fetch(`/api/users/${userId}`, {
    method: 'PUT',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(userData)
  })
  return response.json()
}

function UserEditor({ userId }: { userId: string }) {
  const { data: user } = useSWR<User>(`/api/users/${userId}`, fetcher)
  const [name, setName] = useState('')

  useEffect(() => {
    if (user) {
      setName(user.name)
    }
  }, [user])

  const handleSave = async () => {
    await mutate(
      `/api/users/${userId}`,
      updateUser(userId, { name }),
      {
        optimisticData: (currentData) => ({
          ...currentData,
          name
        }),
        rollbackOnError: true
      }
    )
  }

  if (!user) return null

  return (
    <div>
      <input value={name} onChange={e => setName(e.target.value)} />
      <button onClick={handleSave}>Save</button>
    </div>
  )
}

预加载与预热缓存
import { preload } from 'swr'

function UserList() {
  const { data: users } = useSWR<User[]>('/api/users', fetcher)

  return (
    <ul>
      {users?.map(user => (
        <li
          key={user.id}
          onMouseEnter={() => preload(`/api/users/${user.id}`, fetcher)}
        >
          <a href={`/users/${user.id}`}>{user.name}</a>
        </li>
      ))}
    </ul>
  )
}

常见误区




误区
问题
正确做法





所有请求都用 SWR
一次性请求增加不必要复杂度
简单请求用 fetch + useState




缓存键不包含变量
不同参数返回相同缓存
缓存键包含所有影响数据的变量




不处理错误状态
用户看到空白页
始终检查 error 并显示回退 UI




忽略 dedupingInterval
短时间内重复请求
合理设置去重间隔
