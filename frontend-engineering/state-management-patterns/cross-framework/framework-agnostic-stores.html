框架无关的 Store

核心概念

框架无关的 Store 不依赖特定框架，可以在 React、Vue、Svelte 甚至无框架环境中使用。其核心设计模式是 subscribe + getSnapshot：状态存储在纯 JavaScript 对象中，通过订阅机制通知外部消费者。不同框架通过适配器层接入，从而实现"一次编写，多框架运行"的效果。

简单的框架无关 Store
基础实现
interface Listener<T> {
  (state: T): void;
}

class Store<T> {
  private state: T;
  private listeners: Set<Listener<T>> = new Set();

  constructor(initialState: T) {
    this.state = initialState;
  }

  getState(): T {
    return this.state;
  }

  setState(updater: Partial<T> | ((state: T) => T)): void {
    const newState = typeof updater === 'function' ? updater(this.state) : { ...this.state, ...updater };

    if (!Object.is(this.state, newState)) {
      this.state = newState;
      this.notify();
    }
  }

  subscribe(listener: Listener<T>): () => void {
    this.listeners.add(listener);
    return () => {
      this.listeners.delete(listener);
    };
  }

  private notify(): void {
    this.listeners.forEach((listener) => listener(this.state));
  }
}

interface CounterState {
  count: number;
}

const counterStore = new Store<CounterState>({ count: 0 });

const unsubscribe = counterStore.subscribe((state) => {
  console.log('State changed:', state);
});

counterStore.setState({ count: 1 });
counterStore.setState((state) => ({ count: state.count + 1 }));

unsubscribe();
在 React 中使用
import { useState, useEffect, useCallback } from 'react'

function useStore<T>(store: Store<T>): [T, (updater: Partial<T> | ((state: T) => T)) => void] {
  const [state, setState] = useState<T>(store.getState())

  useEffect(() => {
    const unsubscribe = store.subscribe(setState)
    return unsubscribe
  }, [store])

  const updateState = useCallback(
    (updater: Partial<T> | ((state: T) => T)) => {
      store.setState(updater)
    },
    [store]
  )

  return [state, updateState]
}

function Counter() {
  const [state, setState] = useStore(counterStore)

  return (
    <div>
      <p>Count: {state.count}</p>
      <button onClick={() => setState((s) => ({ count: s.count + 1 }))}>+</button>
      <button onClick={() => setState((s) => ({ count: s.count - 1 }))}>-</button>
    </div>
  )
}
在 Vue 中使用
import { ref, onUnmounted } from 'vue'

function useStore<T>(store: Store<T>) {
  const state = ref(store.getState())

  const unsubscribe = store.subscribe((newState) => {
    state.value = newState
  })

  onUnmounted(() => {
    unsubscribe()
  })

  return {
    state,
    setState: store.setState.bind(store)
  }
}

<script setup>
import { useStore } from './store'

const { state, setState } = useStore(counterStore)
</script>

<template>

    <button @click="setState((s) => ({ count: s.count - 1 }))">-</button>

</template>

使用 Zustand 跨框架
import { createStore } from 'zustand/vanilla';

interface CounterState {
  count: number;
  increment: () => void;
  decrement: () => void;
}

const vanillaStore = createStore<CounterState>((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  decrement: () => set((state) => ({ count: state.count - 1 })),
}));

const { getState, setState, subscribe } = vanillaStore;

subscribe((state) => {
  console.log('State:', state);
});

const { increment } = getState();
increment();
常见误区
❌ 误区 1：过度工程化
简单应用不需要框架无关的 Store，直接用框架内置的即可。


❌ 误区 2：忽略性能
框架无关的 Store 可能不如框架内置的优化好。


❌ 误区 3：不考虑测试
框架无关的好处是易测试，但不要忘记写测试。


小结
    

  • 框架无关 Store 的核心是 subscribe + getSnapshot 模式
    • 

  • nanostores 是最成熟的轻量级跨框架方案
    • 

  • 适合多框架共存或计划迁移框架的项目
