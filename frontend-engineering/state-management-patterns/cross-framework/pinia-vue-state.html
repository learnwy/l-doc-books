Pinia Vue 状态管理

核心概念

Pinia 是 Vue 官方推荐的状态管理库，替代了 Vuex，提供了更简单的 API 和更好的 TypeScript 支持。Pinia 的设计理念是去除 Vuex 中饱受诟病的 mutations 层，让状态修改更直接、更符合 Composition API 的使用习惯。它同时支持 Options API 和 Setup 函数两种定义风格，与 Vue DevTools 深度集成。

基础用法
创建 Store
import { defineStore } from 'pinia';

export const useCounterStore = defineStore('counter', {
  state: () => ({
    count: 0,
  }),
  getters: {
    doubleCount: (state) => state.count * 2,
    doubleCountPlusOne(): number {
      return this.doubleCount + 1;
    },
  },
  actions: {
    increment() {
      this.count++;
    },
    decrement() {
      this.count--;
    },
    reset() {
      this.count = 0;
    },
  },
});
在组件中使用
<script setup lang="ts">
import { useCounterStore } from './store';

const counter = useCounterStore();
</script>

<template>
  <div>

    <p>Double: {{ counter.doubleCount }}</p>
    <p>Double + 1: {{ counter.doubleCountPlusOne }}</p>
    <button @click="counter.increment">+</button>
    <button @click="counter.decrement">-</button>
    <button @click="counter.reset">Reset</button>
  </div>
</template>
Setup Store
更现代的写法
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';

export const useCounterStore = defineStore('counter', () => {
  const count = ref(0);
  const doubleCount = computed(() => count.value * 2);

  function increment() {
    count.value++;
  }

  function decrement() {
    count.value--;
  }

  function reset() {
    count.value = 0;
  }

  return {
    count,
    doubleCount,
    increment,
    decrement,
    reset,
  };
});
Todo Store 示例
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';

interface Todo {
  id: string;
  text: string;
  completed: boolean;
}

export const useTodoStore = defineStore('todo', () => {
  const todos = ref<Todo[]>([]);
  const filter = ref<'all' | 'active' | 'completed'>('all');

  const filteredTodos = computed(() => {
    switch (filter.value) {
      case 'active':
        return todos.value.filter((todo) => !todo.completed);
      case 'completed':
        return todos.value.filter((todo) => todo.completed);
      default:
        return todos.value;
    }
  });

  const stats = computed(() => ({
    total: todos.value.length,
    completed: todos.value.filter((t) => t.completed).length,
    active: todos.value.filter((t) => !t.completed).length,
  }));

  function addTodo(text: string) {
    todos.value.push({
      id: Date.now().toString(),
      text,
      completed: false,
    });
  }

  function toggleTodo(id: string) {
    const todo = todos.value.find((t) => t.id === id);
    if (todo) {
      todo.completed = !todo.completed;
    }
  }

  function deleteTodo(id: string) {
    const index = todos.value.findIndex((t) => t.id === id);
    if (index > -1) {
      todos.value.splice(index, 1);
    }
  }

  function setFilter(newFilter: 'all' | 'active' | 'completed') {
    filter.value = newFilter;
  }

  return {
    todos,
    filter,
    filteredTodos,
    stats,
    addTodo,
    toggleTodo,
    deleteTodo,
    setFilter,
  };
});
<script setup lang="ts">
import { ref } from 'vue';
import { useTodoStore } from './store';

const todoStore = useTodoStore();
const inputText = ref('');

const handleAdd = () => {
  if (inputText.value.trim()) {
    todoStore.addTodo(inputText.value);
    inputText.value = '';
  }
};
</script>

<template>
  <div>
    <div>
      <p>Total: {{ todoStore.stats.total }}</p>
      <p>Active: {{ todoStore.stats.active }}</p>
      <p>Completed: {{ todoStore.stats.completed }}</p>
    </div>
    <input v-model="inputText" @keypress.enter="handleAdd" placeholder="Add a todo..." />
    <button @click="handleAdd">Add</button>
    <div>
      <button @click="todoStore.setFilter('all')">All</button>
      <button @click="todoStore.setFilter('active')">Active</button>
      <button @click="todoStore.setFilter('completed')">Completed</button>
    </div>
    <ul>
      <li v-for="todo in todoStore.filteredTodos" :key="todo.id">
        <input type="checkbox" v-model="todo.completed" @change="todoStore.toggleTodo(todo.id)" />
        {{ todo.text }}
        <button @click="todoStore.deleteTodo(todo.id)">Delete</button>
      </li>
    </ul>
  </div>
</template>
持久化
import { defineStore } from 'pinia';
import { ref, watch } from 'vue';

export const useCounterStore = defineStore('counter', () => {
  const count = ref(0);

  const savedCount = localStorage.getItem('counter-count');
  if (savedCount) {
    count.value = JSON.parse(savedCount);
  }

  watch(count, (newValue) => {
    localStorage.setItem('counter-count', JSON.stringify(newValue));
  });

  function increment() {
    count.value++;
  }

  return { count, increment };
});
常见误区
❌ 误区 1：仍然使用 Vuex
新项目直接使用 Pinia，不需要再用 Vuex。


❌ 误区 2：过度使用 Store
组件局部状态用 ref 和 reactive，不需要都放 Store。


❌ 误区 3：在 action 中使用 async/await 忘记 await
Pinia action 可以是异步的，但要正确处理异步。
