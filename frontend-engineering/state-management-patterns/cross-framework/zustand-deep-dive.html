Zustand 深入

核心概念

Zustand 是一个轻量级的状态管理库，API 简单但功能强大，同时支持 React 和其他框架。

为什么选择 Zustand

特性 说明
轻量级 不到 1KB
简单 API 极少的概念
无 Provider 不需要包裹组件
TypeScript 优先 优秀的类型支持
跨框架 支持 React、Vue、Svelte 等

基础用法

创建 Store

import { create } from 'zustand'

interface CounterState {
  count: number
  increment: () => void
  decrement: () => void
  reset: () => void
}

const useCounterStore = create<CounterState>((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  decrement: () => set((state) => ({ count: state.count - 1 })),
  reset: () => set({ count: 0 })
}))

function Counter() {
  const count = useCounterStore((state) => state.count)
  const increment = useCounterStore((state) => state.increment)
  const decrement = useCounterStore((state) => state.decrement)
  const reset = useCounterStore((state) => state.reset)

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={increment}>+</button>
      <button onClick={decrement}>-</button>
      <button onClick={reset}>Reset</button>
    </div>
  )
}

使用选择器

import { create } from 'zustand'
import { shallow } from 'zustand/shallow'

interface TodoState {
  todos: Todo[]
  filter: 'all' | 'active' | 'completed'
  addTodo: (text: string) => void
  toggleTodo: (id: string) => void
  setFilter: (filter: 'all' | 'active' | 'completed') => void
}

const useTodoStore = create<TodoState>((set) => ({
  todos: [],
  filter: 'all',
  addTodo: (text) =>
    set((state) => ({
      todos: [...state.todos, {
        id: Date.now().toString(),
        text,
        completed: false
      }]
    })),
  toggleTodo: (id) =>
    set((state) => ({
      todos: state.todos.map((todo) =>
        todo.id === id ? { ...todo, completed: !todo.completed } : todo
      )
    })),
  setFilter: (filter) => set({ filter })
}))

function TodoList() {
  const { todos, filter } = useTodoStore(
    (state) => ({ todos: state.todos, filter: state.filter }),
    shallow
  )
  const addTodo = useTodoStore((state) => state.addTodo)
  const toggleTodo = useTodoStore((state) => state.toggleTodo)
  const setFilter = useTodoStore((state) => state.setFilter)

  const filteredTodos = todos.filter((todo) => {
    if (filter === 'active') return !todo.completed
    if (filter === 'completed') return todo.completed
    return true
  })

  const [inputText, setInputText] = useState('')

  const handleAdd = () => {
    if (inputText.trim()) {
      addTodo(inputText)
      setInputText('')
    }
  }

  return (
    <div>
      <input
        value={inputText}
        onChange={(e) => setInputText(e.target.value)}
        onKeyPress={(e) => e.key === 'Enter' && handleAdd()}
      />
      <button onClick={handleAdd}>Add</button>
      <div>
        <button onClick={() => setFilter('all')}>All</button>
        <button onClick={() => setFilter('active')}>Active</button>
        <button onClick={() => setFilter('completed')}>Completed</button>
      </div>
      <ul>
        {filteredTodos.map((todo) => (
          <li key={todo.id}>
            <input
              type="checkbox"
              checked={todo.completed}
              onChange={() => toggleTodo(todo.id)}
            />
            {todo.text}
          </li>
        ))}
      </ul>
    </div>
  )
}

高级模式

中间件

import { create } from 'zustand';
import { persist, devtools, subscribeWithSelector } from 'zustand/middleware';

interface CounterState {
  count: number;
  increment: () => void;
}

const useCounterStore = create<CounterState>()(
  persist(
    devtools(
      subscribeWithSelector((set) => ({
        count: 0,
        increment: () => set((state) => ({ count: state.count + 1 })),
      })),
      { name: 'counter-store' },
    ),
    { name: 'counter-storage' },
  ),
);

useCounterStore.subscribe(
  (state) => state.count,
  (count) => {
    console.log('Count changed:', count);
  },
);

异步操作

import { create } from 'zustand'

interface UserState {
  user: User | null
  status: 'idle' | 'loading' | 'success' | 'error'
  error: string | null
  fetchUser: (userId: string) => Promise<void>
}

const useUserStore = create<UserState>((set) => ({
  user: null,
  status: 'idle',
  error: null,
  fetchUser: async (userId) => {
    set({ status: 'loading', error: null })
    try {
      const response = await fetch(`/api/users/${userId}`)
      const user = await response.json()
      set({ user, status: 'success' })
    } catch (error) {
      set({
        status: 'error',
        error: error instanceof Error ? error.message : 'Failed to fetch user'
      })
    }
  }
}))

function UserProfile({ userId }: { userId: string }) {
  const { user, status, error, fetchUser } = useUserStore()

  useEffect(() => {
    fetchUser(userId)
  }, [fetchUser, userId])

  if (status === 'loading') {
    return <div>Loading...</div>
  }

  if (status === 'error') {
    return <div>Error: {error}</div>
  }

  if (!user) {
    return null
  }

  return (
    <div>
      <h1>{user.name}</h1>
      <p>{user.email}</p>
    </div>
  )
}

Store 切片

import { create } from 'zustand';

interface BearSlice {
  bears: number;
  addBear: () => void;
}

const createBearSlice = (set: any): BearSlice => ({
  bears: 0,
  addBear: () => set((state: any) => ({ bears: state.bears + 1 })),
});

interface FishSlice {
  fishes: number;
  addFish: () => void;
}

const createFishSlice = (set: any): FishSlice => ({
  fishes: 0,
  addFish: () => set((state: any) => ({ fishes: state.fishes + 1 })),
});

const useBoundStore = create<BearSlice & FishSlice>()((...a) => ({
  ...createBearSlice(...a),
  ...createFishSlice(...a),
}));

跨框架使用

在 Vue 中使用

import { create } from 'zustand'
import { useStore } from 'zustand-vue'

const useCounterStore = create(() => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 }))
}))

<script setup>
import { useCounterStore } from './store'

const { count, increment } = useStore(useCounterStore)
</script>

<template>
  <div>
    <p>Count: {{ count }}</p>
    <button @click="increment">+</button>
  </div>
</template>

常见误区

❌ 误区 1：过度使用选择器

每次调用 useStore 都会创建一个订阅，合理使用选择器。

❌ 误区 2：不使用 shallow

选择多个状态时，使用 shallow 避免不必要的重渲染。

❌ 误区 3：在 store 中使用 useState

store 本身就是状态，不需要再用 useState。

小结

    

  • Zustand 是最轻量的 React 全局状态管理方案
    • 

  • selector 是性能优化的关键，避免订阅整个 store
    • 

  • 中间件系统支持持久化、调试、Immer 等能力
