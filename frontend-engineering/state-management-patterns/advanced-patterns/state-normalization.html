状态规范化

核心概念

状态规范化（State Normalization）是将嵌套的数据结构转换为扁平的、按 ID 索引的结构的过程，类似于数据库表的组织方式。

为什么需要规范化

问题 说明
数据重复 同一份数据在多处存储，更新困难
更新复杂 需要递归查找和更新
性能问题 深度嵌套的数据遍历慢
不一致 多处存储的数据可能不同步

规范化 vs 嵌套结构

// ❌ 嵌套结构（不推荐）
const nestedData = {
  posts: [
    {
      id: '1',
      title: 'Post 1',
      author: {
        id: '1',
        name: 'Alice',
      },
      comments: [
        {
          id: '1',
          text: 'Great post!',
          author: {
            id: '2',
            name: 'Bob',
          },
        },
      ],
    },
  ],
};

// ✅ 规范化结构（推荐）
const normalizedData = {
  posts: {
    byId: {
      '1': {
        id: '1',
        title: 'Post 1',
        authorId: '1',
        commentIds: ['1'],
      },
    },
    allIds: ['1'],
  },
  users: {
    byId: {
      '1': { id: '1', name: 'Alice' },
      '2': { id: '2', name: 'Bob' },
    },
    allIds: ['1', '2'],
  },
  comments: {
    byId: {
      '1': {
        id: '1',
        text: 'Great post!',
        authorId: '2',
      },
    },
    allIds: ['1'],
  },
};

基础实现

规范化函数

interface User {
  id: string;
  name: string;
}

interface Comment {
  id: string;
  text: string;
  author: User;
}

interface Post {
  id: string;
  title: string;
  author: User;
  comments: Comment[];
}

interface NormalizedState {
  posts: {
    byId: Record<string, Post & { authorId: string; commentIds: string[] }>;
    allIds: string[];
  };
  users: {
    byId: Record<string, User>;
    allIds: string[];
  };
  comments: {
    byId: Record<string, Comment & { authorId: string }>;
    allIds: string[];
  };
}

function normalizePosts(posts: Post[]): NormalizedState {
  const postsById: NormalizedState['posts']['byId'] = {};
  const usersById: NormalizedState['users']['byId'] = {};
  const commentsById: NormalizedState['comments']['byId'] = {};

  const postIds: string[] = [];
  const userIds: string[] = [];
  const commentIds: string[] = [];

  posts.forEach((post) => {
    if (!usersById[post.author.id]) {
      usersById[post.author.id] = post.author;
      userIds.push(post.author.id);
    }

    const commentIdsForPost: string[] = [];
    post.comments.forEach((comment) => {
      if (!usersById[comment.author.id]) {
        usersById[comment.author.id] = comment.author;
        userIds.push(comment.author.id);
      }

      commentsById[comment.id] = {
        ...comment,
        authorId: comment.author.id,
      };
      commentIds.push(comment.id);
      commentIdsForPost.push(comment.id);
    });

    postsById[post.id] = {
      ...post,
      authorId: post.author.id,
      commentIds: commentIdsForPost,
    };
    postIds.push(post.id);
  });

  return {
    posts: { byId: postsById, allIds: postIds },
    users: { byId: usersById, allIds: userIds },
    comments: { byId: commentsById, allIds: commentIds },
  };
}

使用 normalizr 库

npm install normalizr
import { schema, normalize } from 'normalizr';

const userSchema = new schema.Entity('users');
const commentSchema = new schema.Entity('comments', {
  author: userSchema,
});
const postSchema = new schema.Entity('posts', {
  author: userSchema,
  comments: [commentSchema],
});

const posts: Post[] = [
  {
    id: '1',
    title: 'Post 1',
    author: { id: '1', name: 'Alice' },
    comments: [
      {
        id: '1',
        text: 'Great post!',
        author: { id: '2', name: 'Bob' },
      },
    ],
  },
];

const normalizedData = normalize(posts, [postSchema]);

在 Redux 中使用

使用 createEntityAdapter

import { createSlice, createEntityAdapter, PayloadAction } from '@reduxjs/toolkit';

interface Post {
  id: string;
  title: string;
  authorId: string;
}

const postsAdapter = createEntityAdapter<Post>({
  selectId: (post) => post.id,
  sortComparer: (a, b) => a.title.localeCompare(b.title),
});

const initialState = postsAdapter.getInitialState({
  status: 'idle' as 'idle' | 'loading' | 'succeeded' | 'failed',
  error: null as string | null,
});

const postsSlice = createSlice({
  name: 'posts',
  initialState,
  reducers: {
    postAdded: postsAdapter.addOne,
    postUpdated: postsAdapter.updateOne,
    postDeleted: postsAdapter.removeOne,
    postsAdded: postsAdapter.addMany,
    postsSet: postsAdapter.setAll,
  },
});

export const { postAdded, postUpdated, postDeleted, postsAdded, postsSet } = postsSlice.actions;

export const {
  selectAll: selectAllPosts,
  selectById: selectPostById,
  selectIds: selectPostIds,
} = postsAdapter.getSelectors((state: RootState) => state.posts);

export default postsSlice.reducer;

选择器组合

import { createSelector } from '@reduxjs/toolkit';
import { selectAllPosts, selectPostById } from './postsSlice';
import { selectUserById } from './usersSlice';

export const selectPostsWithAuthors = createSelector([selectAllPosts, (state) => state.users], (posts, usersState) => {
  return posts.map((post) => ({
    ...post,
    author: usersState.byId[post.authorId],
  }));
});

export const selectPostWithAuthor = (postId: string) =>
  createSelector([(state) => selectPostById(state, postId), (state) => state.users], (post, usersState) => {
    if (!post) return null;
    return {
      ...post,
      author: usersState.byId[post.authorId],
    };
  });

常见误区

❌ 误区 1：过度规范化

简单的数据结构不需要规范化，不要过度设计。

❌ 误区 2：忘记 ID 字段

规范化依赖唯一的 ID 字段，确保每个实体都有唯一标识。

❌ 误区 3：在组件中手动组合

使用选择器来组合数据，不要在组件中手动查找和组装。

小结

    

  • 规范化将嵌套数据扁平化为查找表，消除冗余
    • 

  • Redux Toolkit 的 createEntityAdapter 是最佳实践
    • 

  • 适合有大量实体、频繁更新的场景
