内部链接

内部链接的 SEO 价值

内部链接是指从同一网站内的一个页面链接到另一个页面的超链接。它是 SEO 中最被低估但也最具控制力的优化手段之一——与外部链接不同，内部链接完全在你的掌控之中。合理的内部链接策略帮助搜索引擎发现新页面、理解页面间的主题关系，并将链接权重（Link Equity）合理分配到最重要的页面。

内部链接类型
导航链接
导航链接出现在网站的全局导航、侧边栏和页脚中，是最基础的内部链接类型。

上下文链接
上下文链接嵌入在正文内容中，是 SEO 价值最高的内部链接类型。因为它们出现在相关内容的上下文中，搜索引擎赋予它们更高的权重。

相关文章链接
interface Article {
  title: string;
  slug: string;
  tags: string[];
  publishedAt: string;
}

function RelatedArticles({ currentArticle, allArticles }: {
  currentArticle: Article;
  allArticles: Article[];
}) {
  const related = allArticles
    .filter((a) => a.slug !== currentArticle.slug)
    .map((a) => ({
      ...a,
      relevance: a.tags.filter((tag) => currentArticle.tags.includes(tag)).length,
    }))
    .sort((a, b) => b.relevance - a.relevance)
    .slice(0, 5);

  return (
    <aside>
      <h2>相关文章</h2>
      <ul>
        {related.map((article) => (
          <li key={article.slug}>
            <a href={`/blog/${article.slug}`}>{article.title}</a>
          </li>
        ))}
      </ul>
    </aside>
  );
}

自动化内部链接
对于大型内容站点，手动管理内部链接不现实。可以构建自动化工具来辅助内部链接建设。


interface LinkSuggestion {
  keyword: string;
  targetUrl: string;
  targetTitle: string;
}

class InternalLinkEngine {
  private linkMap: LinkSuggestion[] = [];

  constructor(articles: Array<{ title: string; slug: string; keywords: string[] }>) {
    this.linkMap = articles.flatMap((article) =>
      article.keywords.map((keyword) => ({
        keyword: keyword.toLowerCase(),
        targetUrl: `/blog/${article.slug}`,
        targetTitle: article.title,
      })),
    );
  }

  suggestLinks(
    content: string,
    currentSlug: string,
  ): Array<{
    keyword: string;
    position: number;
    targetUrl: string;
  }> {
    const suggestions: Array<{ keyword: string; position: number; targetUrl: string }> = [];

    for (const link of this.linkMap) {
      if (link.targetUrl.includes(currentSlug)) continue;

      const index = content.toLowerCase().indexOf(link.keyword);
      if (index !== -1) {
        suggestions.push({
          keyword: link.keyword,
          position: index,
          targetUrl: link.targetUrl,
        });
      }
    }

    return suggestions;
  }
}
内部链接审计
定期审计内部链接是维护 SEO 健康的重要工作。






检查项
问题描述
影响





孤立页面
没有任何内部链接指向的页面
爬虫无法发现，无法获得权重




断裂链接
指向不存在页面的链接（404）
浪费抓取预算，用户体验差




过多出站链接
单个页面包含过多链接
每个链接传递的权重被稀释




不一致的锚文本
同一目标页面使用完全不同的锚文本
搜索引擎难以确定页面主题




重定向链接
内部链接指向 301/302 重定向的旧 URL
浪费抓取预算和链接权重





interface LinkAuditResult {
  page: string;
  brokenLinks: string[];
  orphanPages: string[];
  redirectLinks: Array<{ from: string; to: string }>;
  totalInternalLinks: number;
}

async function auditInternalLinks(siteUrl: string, pages: string[]): Promise<LinkAuditResult[]> {
  const results: LinkAuditResult[] = [];
  const allLinkedPages = new Set<string>();

  for (const page of pages) {
    const response = await fetch(`${siteUrl}${page}`);
    const html = await response.text();
    const links = extractInternalLinks(html, siteUrl);

    links.forEach((link) => allLinkedPages.add(link));

    const brokenLinks: string[] = [];
    const redirectLinks: Array<{ from: string; to: string }> = [];

    for (const link of links) {
      const linkResponse = await fetch(`${siteUrl}${link}`, { redirect: 'manual' });
      if (linkResponse.status === 404) brokenLinks.push(link);
      if (linkResponse.status === 301 || linkResponse.status === 302) {
        redirectLinks.push({ from: link, to: linkResponse.headers.get('location') || '' });
      }
    }

    results.push({
      page,
      brokenLinks,
      orphanPages: [],
      redirectLinks,
      totalInternalLinks: links.length,
    });
  }

  const orphanPages = pages.filter((p) => !allLinkedPages.has(p));
  if (results.length > 0) {
    results[0].orphanPages = orphanPages;
  }

  return results;
}

function extractInternalLinks(html: string, baseUrl: string): string[] {
  const linkRegex = /href="(\/[^"]*?)"/g;
  const links: string[] = [];
  let match;
  while ((match = linkRegex.exec(html)) !== null) {
    links.push(match[1]);
  }
  return [...new Set(links)];
}
小结
    

  • 内部链接帮助搜索引擎发现页面、传递链接权重、建立主题关联，是完全可控的 SEO 策略。
    • 

  • 上下文链接（正文中的链接）SEO 价值最高，搜索引擎赋予它们更高的权重。
    • 

  • 锚文本应描述目标页面内容，避免使用"点击这里"等通用文字。
    • 

  • 金字塔结构确保链接权重从首页向核心页面均匀分配。
    • 

  • 对于大型站点，应建立自动化内部链接建议和审计工具。
    • 

  • 定期审计内部链接，修复断裂链接、消除孤立页面、更新重定向链接。
