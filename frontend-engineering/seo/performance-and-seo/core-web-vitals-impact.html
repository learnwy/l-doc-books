Core Web Vitals 对搜索排名的影响

页面体验信号纳入排名

2021 年 6 月，Google 正式将页面体验（Page Experience）作为排名信号之一。这标志着网站性能从"nice-to-have"变成了"must-have"。Core Web Vitals 是页面体验信号中最核心的量化指标，由 LCP（加载速度）、INP（交互响应）和 CLS（视觉稳定性）三个指标组成。

Core Web Vitals 与排名的关系
排名影响的实际程度
Google 明确表示，Core Web Vitals 是排名因素之一，但内容相关性仍然是最重要的排名信号。在内容质量相当的情况下，性能更好的页面会获得排名优势。






场景
Core Web Vitals 的作用





两个页面内容质量相近
CWV 更好的页面排名更高（决定性因素）




一个页面内容明显更好但 CWV 较差
内容更好的页面仍然排名更高




大量页面竞争同一关键词
CWV 成为重要的差异化因素




电商/本地搜索等高竞争领域
CWV 的影响更为显著

优化 INP 提升排名
INP 衡量用户交互到视觉更新之间的延迟。搜索引擎关注这个指标是因为它直接反映了用户在使用页面时的流畅度。


function OptimizedSearchFilter({ items }: { items: Item[] }) {
  const [query, setQuery] = useState("");
  const [filteredItems, setFilteredItems] = useState(items);

  const debouncedFilter = useMemo(
    () =>
      debounce((searchQuery: string) => {
        const filtered = items.filter((item) =>
          item.name.toLowerCase().includes(searchQuery.toLowerCase())
        );
        setFilteredItems(filtered);
      }, 150),
    [items]
  );

  const handleInputChange = useCallback(
    (e: React.ChangeEvent<HTMLInputElement>) => {
      const value = e.target.value;
      setQuery(value);
      debouncedFilter(value);
    },
    [debouncedFilter]
  );

  return (
    <div>
      <input type="search" value={query} onChange={handleInputChange} placeholder="搜索..." />
      <ul>
        {filteredItems.map((item) => (
          <li key={item.id}>{item.name}</li>
        ))}
      </ul>
    </div>
  );
}

function debounce<T extends (...args: any[]) => void>(fn: T, delay: number): T {
  let timer: ReturnType<typeof setTimeout>;
  return ((...args: any[]) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  }) as T;
}

CWV 监控与 SEO 关联
import { onLCP, onINP, onCLS, type Metric } from 'web-vitals';

function reportToAnalytics(metric: Metric): void {
  const body = JSON.stringify({
    name: metric.name,
    value: metric.value,
    rating: metric.rating,
    delta: metric.delta,
    id: metric.id,
    navigationType: metric.navigationType,
    url: window.location.href,
    timestamp: Date.now(),
  });

  if (navigator.sendBeacon) {
    navigator.sendBeacon('/api/web-vitals', body);
  }
}

onLCP(reportToAnalytics);
onINP(reportToAnalytics);
onCLS(reportToAnalytics);
小结
    

  • Core Web Vitals 是 Google 页面体验排名信号的核心组成部分，在内容质量相当时成为决定性因素。
    • 

  • LCP 优化重点是预加载关键资源、使用 CDN、采用 SSR/SSG 减少客户端渲染延迟。
    • 

  • INP 优化需要减少主线程阻塞、使用防抖/节流、拆分长任务。
    • 

  • CLS 优化要为图片/视频/广告预留空间、使用骨架屏、设置明确的尺寸属性。
    • 

  • 使用 web-vitals 库采集真实用户数据，结合 Search Console 的 CWV 报告追踪 SEO 影响。
