页面速度优化策略

页面速度与 SEO 的直接关系

Google 的研究表明，当页面加载时间从 1 秒增加到 3 秒时，跳出率增加 32%；增加到 5 秒时，跳出率增加 90%。页面速度不仅影响 Core Web Vitals 得分进而影响排名，还直接影响用户行为信号（跳出率、停留时间），这些信号本身也是排名因素。

HTTP 缓存策略
import type { NextRequest } from 'next/server';
import { NextResponse } from 'next/server';

export function middleware(request: NextRequest) {
  const response = NextResponse.next();
  const pathname = request.nextUrl.pathname;

  if (pathname.match(/\.(js|css|woff2|webp|avif|png|jpg)$/)) {
    response.headers.set('Cache-Control', 'public, max-age=31536000, immutable');
  }

  if (pathname.match(/\.(html)$/) || pathname === '/') {
    response.headers.set('Cache-Control', 'public, max-age=0, must-revalidate');
  }

  if (pathname.startsWith('/blog/')) {
    response.headers.set('Cache-Control', 'public, max-age=3600, stale-while-revalidate=86400');
  }

  return response;
}

小结
    

  • 页面速度直接影响 Core Web Vitals 得分和用户行为信号，两者都是排名因素。
    • 

  • 关键渲染路径优化包括内联关键 CSS、预加载关键资源、延迟非关键 JS。
    • 

  • 图片优化是投入产出比最高的领域，使用 WebP/AVIF 格式、响应式图片和懒加载。
    • 

  • HTTP 缓存策略对静态资源使用长期缓存（immutable），HTML 使用 stale-while-revalidate。
    • 

  • CDN 将内容分发到距离用户最近的边缘节点，显著降低 TTFB。
    • 

  • 设定性能预算并集成到 CI/CD 流程中，防止性能退化。
