Search Console 与分析工具

Google Search Console 概述

Google Search Console（GSC）是 Google 免费提供的网站管理工具，它是 SEO 数据的第一手来源——直接来自 Google 搜索引擎本身。它告诉你 Google 如何看待你的网站：哪些页面被索引、搜索性能如何、存在哪些技术问题。

搜索性能报告
搜索性能报告是 GSC 中最有价值的模块。它展示你的页面在 Google 搜索结果中的表现数据。


四大核心指标




指标
含义
分析价值





总点击次数
用户从搜索结果点击进入你的网站的次数
衡量搜索流量的绝对值




总展示次数
你的页面在搜索结果中被展示的次数
衡量搜索可见度




平均 CTR
点击次数 / 展示次数
衡量搜索结果的吸引力




平均排名
页面在搜索结果中的平均位置
衡量 SEO 效果的直接指标





数据分析维度
interface SearchPerformanceQuery {
  query: string;
  clicks: number;
  impressions: number;
  ctr: number;
  position: number;
}

interface SearchPerformancePage {
  page: string;
  clicks: number;
  impressions: number;
  ctr: number;
  position: number;
}

function identifyOpportunities(data: SearchPerformanceQuery[]): {
  highImpressionLowCTR: SearchPerformanceQuery[];
  quickWins: SearchPerformanceQuery[];
  topPerformers: SearchPerformanceQuery[];
} {
  return {
    highImpressionLowCTR: data.filter((q) => q.impressions > 1000 && q.ctr < 0.02),
    quickWins: data.filter((q) => q.position > 5 && q.position <= 20 && q.impressions > 100),
    topPerformers: data.filter((q) => q.position <= 3 && q.clicks > 50),
  };
}

Google Analytics 集成
Google Analytics（GA4）提供用户行为数据，与 Search Console 的搜索数据互补。


declare global {
  interface Window {
    gtag: (...args: any[]) => void;
    dataLayer: any[];
  }
}

function initGA(measurementId: string): void {
  const script = document.createElement('script');
  script.src = `https://www.googletagmanager.com/gtag/js?id=${measurementId}`;
  script.async = true;
  document.head.appendChild(script);

  window.dataLayer = window.dataLayer || [];
  window.gtag = function () {
    window.dataLayer.push(arguments);
  };
  window.gtag('js', new Date());
  window.gtag('config', measurementId);
}

          gtag('js', new Date());
          gtag('config', '${measurementId}');

      </Script>
    </>
  );
}
SEO 相关的 GA4 指标
function trackSEOEvents(): void {
  window.gtag('event', 'page_view', {
    page_title: document.title,
    page_location: window.location.href,
    content_group: detectContentGroup(),
  });

  window.gtag('event', 'scroll', {
    percent_scrolled: calculateScrollDepth(),
  });
}

function detectContentGroup(): string {
  const path = window.location.pathname;
  if (path.startsWith('/blog')) return 'Blog';
  if (path.startsWith('/tutorials')) return 'Tutorials';
  if (path.startsWith('/docs')) return 'Documentation';
  return 'Other';
}

function calculateScrollDepth(): number {
  const scrollTop = window.scrollY;
  const docHeight = document.documentElement.scrollHeight - window.innerHeight;
  return Math.round((scrollTop / docHeight) * 100);
}
Search Console API 自动化
interface SearchAnalyticsRequest {
  startDate: string;
  endDate: string;
  dimensions: ('query' | 'page' | 'country' | 'device' | 'date')[];
  rowLimit: number;
  startRow: number;
}

interface SearchAnalyticsRow {
  keys: string[];
  clicks: number;
  impressions: number;
  ctr: number;
  position: number;
}

async function fetchSearchAnalytics(
  siteUrl: string,
  request: SearchAnalyticsRequest,
  accessToken: string,
): Promise<SearchAnalyticsRow[]> {
  const response = await fetch(
    `https://www.googleapis.com/webmasters/v3/sites/${encodeURIComponent(siteUrl)}/searchAnalytics/query`,
    {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${accessToken}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify(request),
    },
  );

  const data = await response.json();
  return data.rows || [];
}

async function generateWeeklySEOReport(siteUrl: string, accessToken: string): Promise<void> {
  const endDate = new Date().toISOString().split('T')[0];
  const startDate = new Date(Date.now() - 7 * 24 * 60 * 60 * 1000).toISOString().split('T')[0];

  const queryData = await fetchSearchAnalytics(
    siteUrl,
    {
      startDate,
      endDate,
      dimensions: ['query'],
      rowLimit: 50,
      startRow: 0,
    },
    accessToken,
  );

  const pageData = await fetchSearchAnalytics(
    siteUrl,
    {
      startDate,
      endDate,
      dimensions: ['page'],
      rowLimit: 50,
      startRow: 0,
    },
    accessToken,
  );

  console.log('Top Queries:', queryData.slice(0, 10));
  console.log('Top Pages:', pageData.slice(0, 10));
}
小结
    

  • Google Search Console 是 SEO 数据的第一手来源，提供搜索查询、排名、CTR、索引状态等核心数据。
    • 

  • 搜索性能报告中，高展示低 CTR 的查询是 Title/Description 优化的机会点，排名 5-20 位的查询是快速提升的目标。
    • 

  • URL 检查工具可以查看 Google 对特定页面的抓取和渲染状态，是诊断索引问题的关键工具。
    • 

  • GA4 提供用户行为数据（参与时间、跳出率、转化率），与 Search Console 的搜索数据互补。
    • 

  • 通过 Search Console API 可以自动化 SEO 数据采集和报告生成。
