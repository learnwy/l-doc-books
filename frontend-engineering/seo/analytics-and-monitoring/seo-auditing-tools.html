SEO 审计工具

为什么需要 SEO 审计

SEO 审计是对网站搜索优化状态的全面体检。就像定期进行代码审查可以发现潜在的 Bug 和代码质量问题一样，定期的 SEO 审计能够发现影响搜索排名的技术问题、内容缺陷和结构性不足。一个系统性的审计可以揭示那些日常开发中容易被忽视的 SEO 问题。

Lighthouse SEO 审计
Lighthouse 是 Chrome 内置的页面审计工具，其 SEO 审计类目检查页面级别的基础 SEO 配置。

编程式 Lighthouse 审计
import lighthouse from 'lighthouse';
import chromeLauncher from 'chrome-launcher';

interface SEOAuditResult {
  url: string;
  seoScore: number;
  performanceScore: number;
  accessibilityScore: number;
  issues: Array<{
    id: string;
    title: string;
    description: string;
    score: number;
  }>;
}

async function runSEOAudit(url: string): Promise<SEOAuditResult> {
  const chrome = await chromeLauncher.launch({ chromeFlags: ['--headless'] });

  const options = {
    logLevel: 'info' as const,
    output: 'json' as const,
    onlyCategories: ['seo', 'performance', 'accessibility'],
    port: chrome.port,
  };

  const result = await lighthouse(url, options);
  const { lhr } = result!;

  const seoAudits = Object.values(lhr.audits)
    .filter((audit) => audit.score !== null && audit.score < 1)
    .map((audit) => ({
      id: audit.id,
      title: audit.title,
      description: audit.description || '',
      score: audit.score || 0,
    }));

  await chrome.kill();

  return {
    url,
    seoScore: (lhr.categories.seo?.score || 0) * 100,
    performanceScore: (lhr.categories.performance?.score || 0) * 100,
    accessibilityScore: (lhr.categories.accessibility?.score || 0) * 100,
    issues: seoAudits,
  };
}

自建爬虫审计工具
import * as cheerio from 'cheerio';

interface PageAudit {
  url: string;
  statusCode: number;
  title: string;
  titleLength: number;
  description: string;
  descriptionLength: number;
  h1Count: number;
  h1Text: string[];
  canonical: string;
  hasHreflang: boolean;
  imagesWithoutAlt: number;
  totalImages: number;
  internalLinks: number;
  externalLinks: number;
  wordCount: number;
  issues: string[];
}

async function auditPage(url: string): Promise<PageAudit> {
  const response = await fetch(url);
  const html = await response.text();
  const $ = cheerio.load(html);
  const issues: string[] = [];

  const title = $('title').text().trim();
  if (!title) issues.push('缺少 title 标签');
  else if (title.length > 60) issues.push(`title 过长 (${title.length} 字符)`);
  else if (title.length < 30) issues.push(`title 过短 (${title.length} 字符)`);

  const description = $('meta[name="description"]').attr('content') || '';
  if (!description) issues.push('缺少 meta description');
  else if (description.length > 160) issues.push(`description 过长 (${description.length} 字符)`);

  const h1Elements = $('h1');
  if (h1Elements.length === 0) issues.push('缺少 H1 标签');
  if (h1Elements.length > 1) issues.push(`存在多个 H1 标签 (${h1Elements.length} 个)`);

  const canonical = $('link[rel="canonical"]').attr('href') || '';
  if (!canonical) issues.push('缺少 canonical 标签');

  const images = $('img');
  const imagesWithoutAlt = images.filter((_, el) => !$(el).attr('alt')).length;
  if (imagesWithoutAlt > 0) issues.push(`${imagesWithoutAlt} 张图片缺少 alt 属性`);

  const bodyText = $('body').text().replace(/\s+/g, ' ').trim();
  const wordCount = bodyText.length;
  if (wordCount < 300) issues.push(`内容过少 (${wordCount} 字符)`);

  return {
    url,
    statusCode: response.status,
    title,
    titleLength: title.length,
    description,
    descriptionLength: description.length,
    h1Count: h1Elements.length,
    h1Text: h1Elements.map((_, el) => $(el).text().trim()).get(),
    canonical,
    hasHreflang: $('link[hreflang]').length > 0,
    imagesWithoutAlt,
    totalImages: images.length,
    internalLinks: $('a[href^="/"]').length,
    externalLinks: $('a[href^="http"]').filter((_, el) => !$(el).attr('href')?.includes(new URL(url).hostname)).length,
    wordCount,
    issues,
  };
}

审计报告模板
interface SEOAuditReport {
  siteUrl: string;
  auditDate: string;
  summary: {
    totalPages: number;
    healthyPages: number;
    pagesWithIssues: number;
    criticalIssues: number;
    warnings: number;
  };
  technicalIssues: {
    category: string;
    severity: 'critical' | 'warning' | 'info';
    count: number;
    affectedUrls: string[];
    recommendation: string;
  }[];
  contentIssues: {
    thinContentPages: string[];
    duplicateContentGroups: string[][];
    missingMetaPages: string[];
  };
  performanceIssues: {
    slowPages: Array<{ url: string; lcp: number; cls: number; inp: number }>;
  };
}

function generateAuditSummary(report: SEOAuditReport): string {
  const { summary, technicalIssues, contentIssues } = report;
  const criticalItems = technicalIssues.filter((i) => i.severity === 'critical');

  let output = `SEO 审计报告 - ${report.siteUrl}\n`;
  output += `审计日期: ${report.auditDate}\n\n`;
  output += `总计页面: ${summary.totalPages}\n`;
  output += `健康页面: ${summary.healthyPages} (${Math.round((summary.healthyPages / summary.totalPages) * 100)}%)\n`;
  output += `问题页面: ${summary.pagesWithIssues}\n`;
  output += `严重问题: ${summary.criticalIssues}\n`;
  output += `警告: ${summary.warnings}\n\n`;

  if (criticalItems.length > 0) {
    output += `紧急修复项:\n`;
    criticalItems.forEach((item) => {
      output += `- ${item.category}: ${item.count} 处 (${item.recommendation})\n`;
    });
  }

  return output;
}
小结
    

  • SEO 审计是对网站搜索优化状态的全面体检，应定期进行（建议每月一次技术审计，每季度一次全面审计）。
    • 

  • Lighthouse 适合页面级快速检查，Screaming Frog 适合全站爬取分析。
    • 

  • 审计应覆盖技术 SEO（状态码、Meta 标签、结构化数据）、内容（薄内容、重复内容）、链接（断裂链接、孤立页面）和性能（Core Web Vitals）四个维度。
    • 

  • 可以使用 cheerio 等库构建自定义的 SEO 审计脚本，针对项目特定需求进行检查。
    • 

  • 审计结果应形成报告，按严重程度排序，形成可执行的优化清单。
    •
