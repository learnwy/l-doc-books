Meta 标签与结构化数据

Meta 标签基础

Meta 标签是 HTML <head> 中的元数据声明，虽然用户在页面上看不到它们，但它们对搜索引擎理解和展示页面内容至关重要。Meta 标签是前端开发者与搜索引擎之间的直接沟通渠道。

核心 SEO Meta 标签
Title 标签
Title 标签是 SEO 中最重要的单一标签。它直接显示在搜索结果中，是用户决定是否点击的关键因素。


<title>React Hooks 完全指南：useState、useEffect 深度解析 | 前端博客</title>
Title 标签优化规则：


| 规则       | 说明                        | 示例                                        |
| ---------- | --------------------------- | ------------------------------------------- | ------- |
| 长度控制   | 30-60 字符（中文 15-30 字） | 避免被搜索结果截断                          |
| 关键词前置 | 核心关键词放在标题开头      | "React Hooks 指南" 而非 "指南：React Hooks" |
| 唯一性     | 每个页面的 title 必须唯一   | 避免重复标题被搜索引擎去重                  |
| 品牌标识   | 在末尾添加品牌名            | "页面标题                                   | 品牌名" |
| 吸引点击   | 包含价值主张或数字          | "10 个实用的 React 性能优化技巧"            |


Description 标签
Description 标签不直接影响排名，但直接影响搜索结果中的点击率（CTR），而 CTR 是一个排名信号。


<meta
  name="description"
  content="深入讲解 React Hooks 的核心概念与高级用法，包括 useState 状态管理、useEffect 副作用处理和自定义 Hook 开发，附带完整代码示例和最佳实践。"
/>
Robots Meta 标签
<meta name="robots" content="index, follow" />

<meta name="robots" content="noindex, follow" />

<meta name="robots" content="index, nofollow" />

<meta name="googlebot" content="nosnippet, max-image-preview:large" />
import type { Metadata } from 'next';

const robotsConfig: Metadata['robots'] = {
  index: true,
  follow: true,
  nocache: false,
  googleBot: {
    index: true,
    follow: true,
    noimageindex: false,
    'max-video-preview': -1,
    'max-image-preview': 'large',
    'max-snippet': -1,
  },
};




指令
作用





index
允许索引该页面




noindex
禁止索引该页面




follow
允许爬虫跟踪页面上的链接




nofollow
禁止爬虫跟踪链接




nosnippet
不在搜索结果中显示文本摘要




max-snippet:N
限制摘要最多 N 个字符




max-image-preview
控制图片预览的尺寸




noarchive
禁止搜索引擎缓存该页面





Open Graph 协议
Open Graph 由 Facebook 创建，用于控制页面在社交媒体上分享时的展示效果。虽然它不直接影响搜索排名，但优质的社交分享体验可以间接提升流量和外链。

结构化数据（Schema.org）
结构化数据使用标准化的词汇（Schema.org）来标注页面内容，帮助搜索引擎更精确地理解页面的含义，并在搜索结果中生成富文本片段（Rich Snippets）。


JSON-LD 格式（推荐）
Google 推荐使用 JSON-LD 格式来添加结构化数据，因为它与 HTML 内容分离，易于维护。


<script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "Article",
    "headline": "React Hooks 完全指南",
    "description": "深入讲解 React Hooks 的核心概念与高级用法",
    "image": "https://example.com/images/react-hooks.png",
    "author": {
      "@type": "Person",
      "name": "张三",
      "url": "https://example.com/authors/zhangsan"
    },
    "publisher": {
      "@type": "Organization",
      "name": "前端技术博客",
      "logo": {
        "@type": "ImageObject",
        "url": "https://example.com/logo.png"
      }
    },
    "datePublished": "2026-03-15",
    "dateModified": "2026-03-28",
    "mainEntityOfPage": {
      "@type": "WebPage",
      "@id": "https://example.com/blog/react-hooks-guide"
    }
  }
</script>
常用结构化数据类型
interface ArticleSchema {
  '@context': 'https://schema.org';
  '@type': 'Article';
  headline: string;
  description: string;
  image: string;
  author: { '@type': 'Person'; name: string };
  datePublished: string;
  dateModified: string;
}

interface FAQSchema {
  '@context': 'https://schema.org';
  '@type': 'FAQPage';
  mainEntity: Array<{
    '@type': 'Question';
    name: string;
    acceptedAnswer: {
      '@type': 'Answer';
      text: string;
    };
  }>;
}

interface HowToSchema {
  '@context': 'https://schema.org';
  '@type': 'HowTo';
  name: string;
  step: Array<{
    '@type': 'HowToStep';
    name: string;
    text: string;
    image?: string;
  }>;
}
FAQ 结构化数据示例
<script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "FAQPage",
    "mainEntity": [
      {
        "@type": "Question",
        "name": "React Hooks 和 Class 组件有什么区别？",
        "acceptedAnswer": {
          "@type": "Answer",
          "text": "React Hooks 允许在函数组件中使用状态和生命周期特性，代码更简洁，逻辑复用更方便。Class 组件使用 this 关键字和生命周期方法，代码结构更传统但相对繁琐。"
        }
      },
      {
        "@type": "Question",
        "name": "useEffect 的依赖数组怎么使用？",
        "acceptedAnswer": {
          "@type": "Answer",
          "text": "useEffect 的依赖数组控制副作用的触发时机。空数组 [] 表示仅在挂载时执行一次，指定依赖项时在依赖变化时重新执行，不传数组则每次渲染都执行。"
        }
      }
    ]
  }
</script>
Next.js 中集成结构化数据
interface ArticleProps {
  title: string;
  description: string;
  author: string;
  publishedAt: string;
  updatedAt: string;
  coverImage: string;
  slug: string;
}

function ArticleJsonLd({ title, description, author, publishedAt, updatedAt, coverImage, slug }: ArticleProps) {
  const jsonLd = {
    "@context": "https://schema.org",
    "@type": "Article",
    headline: title,
    description,
    image: coverImage,
    author: {
      "@type": "Person",
      name: author,
    },
    datePublished: publishedAt,
    dateModified: updatedAt,
    mainEntityOfPage: {
      "@type": "WebPage",
      "@id": `https://example.com/blog/${slug}`,
    },
  };

  return (
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{ __html: JSON.stringify(jsonLd) }}
    />
  );
}

function ArticlePage({ article }: { article: ArticleProps }) {
  return (
    <>
      <ArticleJsonLd {...article} />
      <article>
        <h1>{article.title}</h1>
        <p>{article.description}</p>
      </article>
    </>
  );
}

小结
    

  • Title 标签是最重要的 SEO 标签，需要控制长度、前置关键词、保持唯一性。
    • 

  • Description 标签影响点击率（CTR），应准确描述内容并包含行动号召。
    • 

  • Robots Meta 标签精确控制搜索引擎的索引和链接跟踪行为。
    • 

  • Open Graph 和 Twitter Card 优化社交媒体分享体验，间接提升流量。
    • 

  • JSON-LD 格式的结构化数据是 Google 推荐的标注方式，帮助页面获得富文本搜索结果。
    • 

  • 使用 Google 提供的验证工具确保结构化数据的正确性。
