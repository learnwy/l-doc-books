robots.txt 与 Sitemap

robots.txt 基础

robots.txt 是放置在网站根目录下的纯文本文件，它告诉搜索引擎爬虫哪些页面可以抓取、哪些页面不应抓取。这是网站与爬虫之间的"君子协定"——遵守与否取决于爬虫本身，但所有主流搜索引擎都会尊重 robots.txt 的指令。

robots.txt 语法
# 所有爬虫的通用规则
User-agent: *
Disallow: /admin/
Disallow: /api/
Disallow: /internal/
Disallow: /search?
Disallow: /temp/
Allow: /api/public/

# 针对 Googlebot 的特定规则
User-agent: Googlebot
Disallow: /no-google/
Allow: /

# 针对 Bingbot 的特定规则
User-agent: Bingbot
Crawl-delay: 5

# Sitemap 声明
Sitemap: https://example.com/sitemap.xml
Sitemap: https://example.com/sitemap-blog.xml
robots.txt 指令详解




指令
作用
示例





User-agent
指定规则适用的爬虫
User-agent: Googlebot




Disallow
禁止抓取的路径
Disallow: /admin/




Allow
在 Disallow 范围内允许的子路径
Allow: /admin/public/




Crawl-delay
两次抓取间的秒数（Google 不支持）
Crawl-delay: 10




Sitemap
声明 Sitemap 文件位置
Sitemap: https://example.com/sitemap.xml





常见的 robots.txt 配置场景
# 电商网站
User-agent: *
Disallow: /cart/
Disallow: /checkout/
Disallow: /account/
Disallow: /wishlist/
Disallow: /search?*sort=
Disallow: /search?*filter=
Allow: /search?q=
Allow: /

Sitemap: https://shop.example.com/sitemap.xml
# 博客/内容网站
User-agent: *
Disallow: /wp-admin/
Disallow: /wp-includes/
Disallow: /tag/
Disallow: /author/
Disallow: /*?replytocom=
Allow: /wp-admin/admin-ajax.php
Allow: /

Sitemap: https://blog.example.com/sitemap.xml
Next.js 中生成 robots.txt
import type { MetadataRoute } from 'next';

export default function robots(): MetadataRoute.Robots {
  const baseUrl = 'https://example.com';

  return {
    rules: [
      {
        userAgent: '*',
        allow: '/',
        disallow: ['/admin/', '/api/', '/internal/', '/search?'],
      },
      {
        userAgent: 'Googlebot',
        allow: '/',
        disallow: ['/admin/'],
      },
    ],
    sitemap: [`${baseUrl}/sitemap.xml`],
  };
}
robots.txt 注意事项
关键区别：


<!-- robots.txt 的 Disallow 只阻止抓取，不阻止索引 -->
<!-- 如果要阻止索引，需要在页面 HTML 中使用 noindex -->
<meta name="robots" content="noindex, follow" />

<!-- 或者使用 HTTP 响应头 -->
<!-- X-Robots-Tag: noindex, follow -->
XML Sitemap 详解
XML Sitemap 是一个列出网站所有重要 URL 的 XML 文件，它主动告诉搜索引擎你希望被索引的页面有哪些，以及这些页面的更新频率和相对重要性。


Sitemap 基础格式
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://example.com/</loc>
    <lastmod>2026-03-30</lastmod>
    <changefreq>daily</changefreq>
    <priority>1.0</priority>
  </url>
  <url>
    <loc>https://example.com/blog</loc>
    <lastmod>2026-03-29</lastmod>
    <changefreq>daily</changefreq>
    <priority>0.9</priority>
  </url>
  <url>
    <loc>https://example.com/blog/react-hooks-guide</loc>
    <lastmod>2026-03-28</lastmod>
    <changefreq>weekly</changefreq>
    <priority>0.8</priority>
  </url>
</urlset>
Sitemap Index（大型网站）
当网站 URL 数量超过 50,000 条或 Sitemap 文件超过 50MB 时，需要使用 Sitemap Index 来组织多个 Sitemap 文件。


<?xml version="1.0" encoding="UTF-8"?>
<sitemapindex xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <sitemap>
    <loc>https://example.com/sitemap-pages.xml</loc>
    <lastmod>2026-03-30</lastmod>
  </sitemap>
  <sitemap>
    <loc>https://example.com/sitemap-blog.xml</loc>
    <lastmod>2026-03-29</lastmod>
  </sitemap>
  <sitemap>
    <loc>https://example.com/sitemap-products.xml</loc>
    <lastmod>2026-03-28</lastmod>
  </sitemap>
</sitemapindex>
Next.js 动态 Sitemap 生成
import type { MetadataRoute } from 'next';

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const baseUrl = 'https://example.com';

  const staticPages: MetadataRoute.Sitemap = [
    {
      url: baseUrl,
      lastModified: new Date(),
      changeFrequency: 'daily',
      priority: 1.0,
    },
    {
      url: `${baseUrl}/blog`,
      lastModified: new Date(),
      changeFrequency: 'daily',
      priority: 0.9,
    },
    {
      url: `${baseUrl}/about`,
      lastModified: new Date('2026-01-01'),
      changeFrequency: 'monthly',
      priority: 0.5,
    },
  ];

  const articles = await getAllArticles();
  const articlePages: MetadataRoute.Sitemap = articles.map((article) => ({
    url: `${baseUrl}/blog/${article.slug}`,
    lastModified: new Date(article.updatedAt),
    changeFrequency: 'weekly' as const,
    priority: 0.8,
  }));

  const products = await getAllProducts();
  const productPages: MetadataRoute.Sitemap = products.map((product) => ({
    url: `${baseUrl}/products/${product.slug}`,
    lastModified: new Date(product.updatedAt),
    changeFrequency: 'weekly' as const,
    priority: 0.7,
  }));

  return [...staticPages, ...articlePages, ...productPages];
}

Sitemap 最佳实践




实践
说明





只包含可索引的 URL
不要包含 noindex 页面或被 robots.txt 阻止的 URL




保持 lastmod 准确
只在内容真正更新时修改日期，不要动态生成当前时间




合理设置 priority
首页 1.0，核心页面 0.8-0.9，普通页面 0.5-0.7




在 robots.txt 中声明
添加 Sitemap: 指令指向 Sitemap URL




提交到 Search Console
主动提交确保搜索引擎发现并处理




定期更新
新增或删除页面后及时更新 Sitemap





小结
    

  • robots.txt 控制爬虫的抓取行为，但 Disallow 不等于 noindex，不能阻止页面被索引。
    • 

  • robots.txt 不能保护敏感信息，应使用认证机制保护私密内容。
    • 

  • XML Sitemap 主动向搜索引擎报告网站的所有重要页面及其更新状态。
    • 

  • 大型网站使用 Sitemap Index 组织多个子 Sitemap 文件。
    • 

  • Next.js 提供了内置的 robots.txt 和 sitemap.xml 生成支持。
    • 

  • Sitemap 应只包含可索引的 URL，并保持 lastmod 日期的准确性。
    •
