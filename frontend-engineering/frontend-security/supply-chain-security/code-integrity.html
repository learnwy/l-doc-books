代码完整性

核心概念

代码完整性（Code Integrity）确保从开发到部署的整个生命周期中，代码没有被篡改或注入恶意内容。在前端领域，这涉及源代码的版本控制安全、构建产物的完整性验证、CDN 分发的资源校验和运行时的代码保护。Subresource Integrity（SRI）是浏览器原生支持的代码完整性验证机制，而更广义的代码完整性还包括构建管道安全、签名验证等环节。

代码完整性威胁可能来自多个环节：开发者本地环境被入侵、CI/CD 系统被攻破、CDN 缓存被投毒、或者中间人攻击修改传输中的代码。

Subresource Integrity (SRI)
SRI 允许浏览器在加载外部资源前验证其哈希值，确保资源未被篡改：


<script
  src="https://cdn.example.com/react.production.min.js"
  integrity="sha384-oqVuAfXRKap7fdgcCY5uykM6+R9GqQ8K/uxy9rx7HNQlGYl1kPzQho1wx4JwY8w"
  crossorigin="anonymous"
></script>

<link rel="stylesheet" href="https://cdn.example.com/styles.css" integrity="sha384-xxx" crossorigin="anonymous" />
生成和管理 SRI 哈希：


import crypto from 'node:crypto';
import fs from 'node:fs';

const generateSriHash = (content: string | Buffer, algorithm = 'sha384'): string => {
  const hash = crypto.createHash(algorithm).update(content).digest('base64');
  return `${algorithm}-${hash}`;
};

const generateSriForFile = (filePath: string): string => {
  const content = fs.readFileSync(filePath);
  return generateSriHash(content);
};

interface AssetManifest {
  [filename: string]: {
    url: string;
    integrity: string;
    size: number;
  };
}

const generateAssetManifest = (distDir: string, cdnBase: string): AssetManifest => {
  const manifest: AssetManifest = {};
  const files = fs.readdirSync(distDir, { recursive: true }) as string[];

  for (const file of files) {
    if (file.endsWith('.js') || file.endsWith('.css')) {
      const filePath = `${distDir}/${file}`;
      const content = fs.readFileSync(filePath);
      manifest[file] = {
        url: `${cdnBase}/${file}`,
        integrity: generateSriHash(content),
        size: content.length,
      };
    }
  }

  return manifest;
};
在构建工具中自动注入 SRI：


import type { Plugin } from 'vite';

const sriPlugin = (): Plugin => {
  return {
    name: 'vite-plugin-sri',
    enforce: 'post',
    transformIndexHtml(html, ctx) {
      const bundle = ctx.bundle;
      if (!bundle) return html;

      return html.replace(
        /<(script|link)\s+([^>]*)(src|href)="([^"]+)"([^>]*)>/g,
        (match, tag, before, attr, url, after) => {
          const filename = url.split('/').pop();
          const chunk = bundle?.[filename];

          if (chunk && 'code' in chunk) {
            const integrity = generateSriHash(chunk.code);
            return `<${tag} ${before}${attr}="${url}" integrity="${integrity}" crossorigin="anonymous"${after}>`;
          }

          return match;
        },
      );
    },
  };
};
构建管道安全
构建管道是代码从源码到产物的关键转换环节：


name: Secure Build
on:
  push:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      id-token: write
      attestations: write
    steps:
      - uses: actions/checkout@v4

      - name: Verify commit signatures
        run: git verify-commit HEAD || echo "Warning: unsigned commit"

      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'pnpm'

      - run: pnpm install --frozen-lockfile

      - name: Build with integrity check
        run: |
          pnpm run build
          find dist -name "*.js" -o -name "*.css" | while read f; do
            sha384sum "$f" >> dist/checksums.sha384
          done

      - name: Attest build provenance
        uses: actions/attest-build-provenance@v1
        with:
          subject-path: 'dist/**/*.js'

      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: build-${{ github.sha }}
          path: dist/
          retention-days: 30
运行时完整性监控
检测运行时的代码篡改行为：


const monitorDomIntegrity = () => {
  const observer = new MutationObserver((mutations) => {
    for (const mutation of mutations) {
      for (const node of mutation.addedNodes) {
        if (node instanceof HTMLScriptElement) {
          const src = node.src;
          if (src && !isAllowedScript(src)) {
            console.warn('检测到未授权脚本注入:', src);
            node.remove();
            reportSecurityEvent('unauthorized_script', { src });
          }
        }
      }
    }
  });

  observer.observe(document.documentElement, {
    childList: true,
    subtree: true,
  });
};

const allowedScriptPatterns = [/^https:\/\/cdn\.example\.com\//, /^https:\/\/www\.example\.com\//];

const isAllowedScript = (src: string): boolean => {
  return allowedScriptPatterns.some((pattern) => pattern.test(src));
};

const reportSecurityEvent = (type: string, details: Record<string, unknown>) => {
  fetch('/api/security/events', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      type,
      details,
      timestamp: new Date().toISOString(),
      url: window.location.href,
      userAgent: navigator.userAgent,
    }),
    keepalive: true,
  }).catch(() => {});
};

const detectPrototypeOverride = () => {
  const criticalPrototypes = [
    { obj: Array.prototype, methods: ['push', 'pop', 'map', 'filter'] },
    { obj: Object.prototype, methods: ['hasOwnProperty', 'toString'] },
    { obj: Function.prototype, methods: ['call', 'apply', 'bind'] },
  ];

  for (const { obj, methods } of criticalPrototypes) {
    for (const method of methods) {
      const original = obj[method as keyof typeof obj];
      Object.defineProperty(obj, method, {
        get() {
          return original;
        },
        set(value) {
          console.warn(`检测到原型方法覆盖: ${method}`);
          reportSecurityEvent('prototype_override', { method });
        },
        configurable: false,
      });
    }
  }
};
小结
    

  • SRI 通过哈希值验证外部资源完整性，是防止 CDN 投毒的有效机制
    • 

  • SRI 需要配合 crossorigin="anonymous" 属性，否则哈希校验不会生效
    • 

  • 构建管道应使用 --frozen-lockfile、产物哈希校验和构建证明（provenance attestation）
    • 

  • Git 签名提交 + Code Review 防止源码层面的篡改
    • 

  • 运行时完整性监控通过 MutationObserver 检测未授权的脚本注入
    • 

  • 原型链保护检测关键内置方法是否被覆盖，是运行时安全的补充手段
    • 

  • HTTPS + HSTS 确保传输层的代码完整性
    • 

  • 完整性保护应覆盖全链路：源码 → 构建 → 分发 → 加载 → 运行
    •
