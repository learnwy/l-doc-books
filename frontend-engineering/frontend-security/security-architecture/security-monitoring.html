安全监控

核心概念

前端安全监控是实时检测和响应安全事件的运行时防护层。与安全审计的静态检查不同，安全监控在应用运行时持续观察用户行为、资源加载和 API 调用，识别异常模式并触发告警。它是纵深防御体系的最后一环——当预防措施和检测机制都被绕过时，监控能够在攻击造成更大损害之前发出警报。

前端安全监控的挑战在于客户端环境的不可控性和数据量的巨大。有效的监控系统需要在灵敏度和误报率之间取得平衡，在安全性和性能之间做出权衡。

CSP 违规监控
CSP 违规报告是最高价值的前端安全信号源：


class CspMonitor {
  private violations: Array<{ directive: string; uri: string; timestamp: number }> = [];
  private reportEndpoint: string;

  constructor(endpoint: string) {
    this.reportEndpoint = endpoint;
    this.listen();
  }

  private listen() {
    document.addEventListener('securitypolicyviolation', (e) => {
      const violation = {
        directive: e.violatedDirective,
        uri: e.blockedURI,
        timestamp: Date.now(),
        effectiveDirective: e.effectiveDirective,
        originalPolicy: e.originalPolicy,
        sourceFile: e.sourceFile,
        lineNumber: e.lineNumber,
        columnNumber: e.columnNumber,
        disposition: e.disposition,
      };

      this.violations.push({
        directive: violation.directive,
        uri: violation.uri,
        timestamp: violation.timestamp,
      });

      if (this.isHighSeverity(violation)) {
        this.reportImmediate(violation);
      } else {
        this.reportBatched(violation);
      }
    });
  }

  private isHighSeverity(violation: Record<string, unknown>): boolean {
    const directive = violation.effectiveDirective as string;
    return directive === 'script-src' || directive === 'script-src-elem';
  }

  private async reportImmediate(violation: Record<string, unknown>) {
    await fetch(this.reportEndpoint, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ severity: 'high', violation }),
      keepalive: true,
    }).catch(() => {});
  }

  private reportBatched(violation: Record<string, unknown>) {
    this.batchQueue.push(violation);
    if (this.batchQueue.length >= 10) {
      this.flushBatch();
    }
  }

  private batchQueue: Array<Record<string, unknown>> = [];

  private async flushBatch() {
    if (this.batchQueue.length === 0) return;
    const batch = this.batchQueue.splice(0);
    await fetch(this.reportEndpoint, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ severity: 'low', violations: batch }),
      keepalive: true,
    }).catch(() => {});
  }
}
网络请求监控
拦截和分析网络请求，检测异常数据外泄和未授权通信：


class NetworkMonitor {
  private allowedOrigins: Set<string>;

  constructor(origins: string[]) {
    this.allowedOrigins = new Set(origins);
    this.interceptFetch();
    this.interceptXhr();
  }

  private interceptFetch() {
    const originalFetch = window.fetch;
    const monitor = this;

    window.fetch = function (input: RequestInfo | URL, init?: RequestInit): Promise<Response> {
      const url = typeof input === 'string' ? input : input instanceof URL ? input.href : input.url;

      if (monitor.isSuspiciousRequest(url, init)) {
        monitor.reportSuspiciousActivity('fetch', url, init);
      }

      return originalFetch.call(this, input, init);
    };
  }

  private interceptXhr() {
    const originalOpen = XMLHttpRequest.prototype.open;
    const monitor = this;

    XMLHttpRequest.prototype.open = function (method: string, url: string | URL, ...args: unknown[]) {
      const urlStr = url.toString();
      if (monitor.isSuspiciousRequest(urlStr)) {
        monitor.reportSuspiciousActivity('xhr', urlStr);
      }
      return originalOpen.call(this, method, url, ...args);
    };
  }

  private isSuspiciousRequest(url: string, init?: RequestInit): boolean {
    try {
      const parsed = new URL(url, window.location.origin);

      if (!this.allowedOrigins.has(parsed.origin) && parsed.origin !== window.location.origin) {
        return true;
      }

      if (init?.body && typeof init.body === 'string' && init.body.length > 50000) {
        return true;
      }

      return false;
    } catch {
      return true;
    }
  }

  private reportSuspiciousActivity(type: string, url: string, init?: RequestInit) {
    console.warn(`可疑网络请求 [${type}]:`, url);
    navigator.sendBeacon(
      '/api/security/network-alert',
      JSON.stringify({
        type,
        url,
        method: init?.method ?? 'GET',
        timestamp: new Date().toISOString(),
        page: window.location.href,
      }),
    );
  }
}
DOM 完整性监控
使用 MutationObserver 检测运行时的 DOM 篡改：


class DomIntegrityMonitor {
  private observer: MutationObserver;
  private scriptWhitelist: RegExp[];

  constructor(allowedPatterns: RegExp[]) {
    this.scriptWhitelist = allowedPatterns;
    this.observer = new MutationObserver(this.handleMutations.bind(this));
    this.start();
  }

  start() {
    this.observer.observe(document.documentElement, {
      childList: true,
      subtree: true,
      attributes: true,
      attributeFilter: ['src', 'href', 'action', 'onclick', 'onload', 'onerror'],
    });
  }

  private handleMutations(mutations: MutationRecord[]) {
    for (const mutation of mutations) {
      if (mutation.type === 'childList') {
        for (const node of mutation.addedNodes) {
          this.checkNode(node);
        }
      }

      if (mutation.type === 'attributes') {
        this.checkAttributeChange(mutation);
      }
    }
  }

  private checkNode(node: Node) {
    if (node instanceof HTMLScriptElement) {
      const src = node.src;
      if (src && !this.isAllowedScript(src)) {
        console.warn('未授权脚本注入:', src);
        node.remove();
        this.report('script_injection', { src });
      }

      if (!src && node.textContent) {
        this.report('inline_script_injection', {
          preview: node.textContent.slice(0, 100),
        });
      }
    }

    if (node instanceof HTMLIFrameElement) {
      const src = node.src;
      if (src && !this.isAllowedFrame(src)) {
        console.warn('未授权 iframe 注入:', src);
        node.remove();
        this.report('iframe_injection', { src });
      }
    }
  }

  private checkAttributeChange(mutation: MutationRecord) {
    const target = mutation.target as HTMLElement;
    const attr = mutation.attributeName;

    if (attr && ['onclick', 'onload', 'onerror'].includes(attr)) {
      const value = target.getAttribute(attr);
      if (value) {
        console.warn('事件处理器注入:', attr, value);
        target.removeAttribute(attr);
        this.report('event_handler_injection', { attr, value: value.slice(0, 100) });
      }
    }
  }

  private isAllowedScript(src: string): boolean {
    return this.scriptWhitelist.some((pattern) => pattern.test(src));
  }

  private isAllowedFrame(src: string): boolean {
    try {
      const url = new URL(src);
      return url.origin === window.location.origin;
    } catch {
      return false;
    }
  }

  private report(type: string, details: Record<string, unknown>) {
    navigator.sendBeacon(
      '/api/security/dom-alert',
      JSON.stringify({
        type,
        details,
        timestamp: new Date().toISOString(),
        page: window.location.href,
      }),
    );
  }

  stop() {
    this.observer.disconnect();
  }
}
告警与响应集成
将安全监控数据集成到告警和响应系统中：


interface AlertRule {
  name: string;
  condition: (events: SecurityEventData[]) => boolean;
  severity: 'critical' | 'high' | 'medium' | 'low';
  cooldown: number;
}

interface SecurityEventData {
  type: string;
  timestamp: number;
  details: Record<string, unknown>;
}

const alertRules: AlertRule[] = [
  {
    name: 'CSP script-src 违规突增',
    condition: (events) => {
      const recent = events.filter((e) => e.type === 'csp_violation' && e.timestamp > Date.now() - 60000);
      return recent.length > 10;
    },
    severity: 'critical',
    cooldown: 300000,
  },
  {
    name: '连续认证失败',
    condition: (events) => {
      const recent = events.filter((e) => e.type === 'auth_failure' && e.timestamp > Date.now() - 60000);
      return recent.length > 5;
    },
    severity: 'high',
    cooldown: 300000,
  },
  {
    name: '未授权脚本注入',
    condition: (events) => events.some((e) => e.type === 'script_injection'),
    severity: 'critical',
    cooldown: 60000,
  },
];

class AlertManager {
  private lastAlertTime: Map<string, number> = new Map();

  evaluate(events: SecurityEventData[]) {
    for (const rule of alertRules) {
      if (rule.condition(events)) {
        const lastTime = this.lastAlertTime.get(rule.name) ?? 0;
        if (Date.now() - lastTime > rule.cooldown) {
          this.sendAlert(rule, events);
          this.lastAlertTime.set(rule.name, Date.now());
        }
      }
    }
  }

  private async sendAlert(rule: AlertRule, events: SecurityEventData[]) {
    await fetch('/api/security/alerts', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        rule: rule.name,
        severity: rule.severity,
        eventCount: events.length,
        timestamp: new Date().toISOString(),
      }),
    }).catch(() => {});
  }
}
小结
    

  • 前端安全监控在运行时持续检测异常，是纵深防御的最后一环
    • 

  • CSP 违规报告是最高价值的安全信号，script-src 违规应立即告警
    • 

  • 网络请求监控通过拦截 fetch/XHR 检测数据外泄和未授权通信
    • 

  • DOM 完整性监控使用 MutationObserver 检测脚本注入和事件处理器篡改
    • 

  • 监控数据应批量上报，使用 navigator.sendBeacon 确保页面关闭时数据不丢失
    • 

  • 告警规则需要冷却机制（cooldown）避免相同问题重复告警
    • 

  • 安全监控应与应用监控（Sentry 等）集成，建立统一的可观测体系
    • 

  • 监控本身的性能开销应控制在可接受范围内，避免影响用户体验
    •
