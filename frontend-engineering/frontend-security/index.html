前端安全 简介

前端安全是 Web 应用安全体系中至关重要的一环。随着前端应用的复杂度不断提升，单页应用、微前端、第三方脚本集成等架构模式的普及，前端面临的攻击面也在持续扩大。从经典的 XSS、CSRF 攻击到新兴的供应链投毒、原型链污染，前端工程师必须具备系统化的安全意识与防御能力。

本知识库适用于有一定前端开发经验、希望系统掌握 Web 安全攻防知识的中高级工程师。无论你是应用开发者还是安全方向的技术负责人，本知识库都能帮助你构建完整的前端安全知识体系。

全书共分为四章，从攻击原理到防御实践全面覆盖前端安全领域：

第一章攻击向量，详细剖析前端面临的主要安全威胁，包括 XSS 跨站脚本、CSRF 跨站请求伪造、点击劫持和注入攻击，从攻击者视角理解漏洞成因与利用方式。

第二章防御策略，针对各类攻击提出系统性的防御方案，涵盖内容安全策略、输入验证与输出编码、认证安全等核心防护手段，帮助读者建立纵深防御体系。

第三章供应链安全，聚焦前端生态特有的供应链风险，讲解依赖安全审计、npm 包管理安全、代码完整性校验等关键议题，这是近年来最受关注的安全领域之一。

第四章安全架构，从架构层面审视前端安全，涵盖安全响应头配置、HTTPS 与 TLS 最佳实践、安全监控与告警体系搭建，帮助读者将安全融入开发流程。

推荐学习路径：先通读第一章了解攻击原理，这是所有防御的基础；然后学习第二章的防御策略建立防护意识；接着关注第三章的供应链安全，这是现代前端最易忽视的风险点；最后通过第四章的安全架构将安全实践制度化。建议结合实际项目进行安全审计练习，在真实场景中深化理解。
