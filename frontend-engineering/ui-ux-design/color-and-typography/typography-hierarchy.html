字体选择与层级

排版的核心目标

排版（Typography）的首要目标是可读性和信息层级。好的排版让用户在毫秒之间就能区分标题、正文和辅助信息，引导阅读视线按照设计者预期的路径流动。

字体配对原则




原则
说明
示例





对比配对
标题衬线 + 正文无衬线
Playfair Display + Inter




同族配对
同一字体族的不同字重
Inter Light + Inter Bold




风格统一
字体的 x-height 和比例相近
SF Pro + New York




避免冲突
不使用两种风格接近的字体
避免 Arial + Helvetica





推荐做法：一个项目最多使用 2 种字体——标题一种，正文一种。

字号阶梯是预定义的字号集合，每个层级之间保持固定的比例关系。

行高与段间距
行高（Line Height）
行高直接影响文本的可读性和视觉疏密感。






内容类型
推荐行高
说明





大标题（Display）
1.1~1.2
标题紧凑，减少视觉空洞




小标题（H2~H4）
1.2~1.3
适度紧凑




正文（Body）
1.5~1.7
舒适阅读




长文本（Article）
1.6~1.8
长时间阅读不疲劳





字间距与段间距




属性
建议





字间距（letter-spacing）
大标题可加 -0.02em 紧缩，正文保持默认




段间距（margin-bottom）
通常为行高的 0.5~1 倍




最大行宽（max-width）
正文 4575 字符（中文 2035 字）







中文排版注意事项




要点
说明





字体回退链
优先系统字体：-apple-system → PingFang SC → Microsoft YaHei




标点挤压
连续标点需要压缩间距（如"。"后接"《"）




行宽控制
中文每行 20~35 字，避免过长导致阅读跳行




竖排场景
特殊品牌场景可使用 writing-mode: vertical-rl







排版层级检查清单




检查项
标准





字号层级
至少 3 个明显可区分的层级




字体数量
不超过 2 种字体




行高设置
正文行高 ≥ 1.5




行宽控制
正文最大宽度 ≤ 75 字符




对比度
正文文字与背景对比度 ≥ 4.5:1




字重使用
使用不超过 3 种字重







小结
    

  • 字体选择以可读性为第一标准，一个项目最多使用 2 种字体
    • 

  • 字号阶梯通过固定比例系数建立有节奏的层级体系
    • 

  • 行高是正文可读性的关键参数，正文推荐 1.5~1.7
    • 

  • 中文排版需要关注字体回退链、标点挤压和行宽控制
    • 

  • 字号、字重和颜色三者协同建立完整的文本层级系统
