间距网格与留白

为什么间距如此重要

间距是界面设计中"看不见的结构"。用户不会意识到 8px 网格的存在，但会立刻感受到混乱间距带来的不适。良好的间距体系让界面看起来整洁、有组织，而糟糕的间距让同样的内容看起来业余、混乱。



8px 网格系统
8px 网格是现代 UI 设计的事实标准。所有间距、尺寸和位置都应是 8 的倍数（特殊场景可降至 4px 半步）。


为什么选择 8px




原因
说明





整除性好
8 可被 1、2、4 整除，适配各种分辨率




缩放友好
在 1x、1.5x、2x、3x 屏幕上都能保持像素对齐




数量适中
比 4px 粒度粗（减少决策），比 10px 更灵活




行业标准
Material Design、iOS Human Interface Guidelines 均采用

间距的层级应用
不同层级的间距承担不同的语义角色：

4~8px

留白（Negative Space）
留白不是"空白"，而是设计元素的组成部分。留白赋予内容呼吸的空间，引导视线流动。


留白的类型




类型
定义
示例





微观留白
文字行间距、字间距
行高 1.5、letter-spacing 0.01em




中观留白
组件和区块之间的间距
卡片间距 24px、表单 gap 16px




宏观留白
页面大区域的空白
首屏 Hero 的上下留白、侧边距





留白的作用




作用
说明





分组
通过间距差异建立视觉分组（格式塔接近性）




层级
更多留白 = 更高的视觉重要性




聚焦
周围的留白将注意力集中到核心内容




品质感
充足的留白传达高端、专业的感觉




可读性
适当的行间距和段间距提升阅读舒适度

小结
    

  • 8px 网格是现代 UI 的基础度量单位，所有尺寸和间距都应是 8 的倍数
    • 

  • 间距倍数体系（Spacing Scale）消除随意数值，建立一致的间距语言
    • 

  • 间距的四个层级——内间距、近间距、中间距、远间距——对应不同的语义角色
    • 

  • 留白是积极的设计元素，不是浪费空间
    • 

  • 响应式设计中间距需要随屏幕尺寸自适应缩放
    • 

  • 严格使用间距 Token 是保持设计一致性的关键手段
