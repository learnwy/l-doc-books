前端·UI/UX 设计 简介

UI/UX 设计是数字产品开发中不可或缺的关键环节。UI（用户界面）关注产品的视觉呈现与交互元素，UX（用户体验）聚焦用户在使用产品全过程中的感受与满意度。优秀的 UI/UX 设计能显著提升产品的易用性、可访问性和用户留存率，直接影响商业成功。本 hub 面向前端开发者：不是教你成为专职设计师，而是让你具备「读懂设计稿、识别坏设计、与设计师高效协作、把设计意图无损落地为代码」的工程化能力。

本 hub 讲什么 / 不讲什么

本 hub 覆盖设计的认知与决策层：视觉感知规律、色彩排版间距的取值依据、组件交互模式、设计系统与 Token 体系、设计工具与协作流程。它回答的是「为什么这样设计、取哪个值、何时用哪种模式」。

它不深入工程实现细节——那些由兄弟 hub 承担，本 hub 在相关处用相对链接指过去，不重复展开：

主题 本 hub 的角色 去哪个兄弟 hub 看实现
Design Token 的工程化构建（Style Dictionary、多平台产物、CI 校验） 只讲 Token 的设计语义与三层模型 ../18_design-systems-tokens/
无障碍的代码落地（ARIA 模式、屏幕阅读器、键盘陷阱） 只讲 WCAG 原则与设计期检查 ../34_web-accessibility/、../16_accessibility-i18n/
CSS 实现（变量、容器查询、层叠层、主题切换工程） 只讲设计取值与视觉规律 ../06_css-and-visual-engineering/、../36_modern-css-architecture/
Web 动画的实现技术（WAAPI、GSAP、性能） 只讲微交互的设计原则与时长曲线 ../22_web-animation/、../45_frontend-microinteractions/
表单的工程（校验库、受控/非受控、状态机） 只讲表单的可用性设计 ../43_frontend-form-engineering/
数据可视化的图表工程 只讲数据展示的信息设计 ../49_frontend-data-visualization/

一句话：本 hub 决定「做什么、取什么值、为什么」，兄弟 hub 决定「用什么代码实现」。

推荐学习路径

flowchart LR
    A["1 设计原则<br/>感知/可用性/流程"] --> B["2 色彩与排版<br/>视觉取值依据"]
    B --> C["3 组件设计<br/>交互模式"]
    C --> D["4 设计系统<br/>Token/组件库/协作"]
    D --> E["5 设计工具<br/>Figma/原型/AI"]
  • 前置知识：HTML/CSS 基础、对 Flexbox 的理解（理解 Figma Auto Layout 会更快）。无需任何美术功底。
  • 章节一（设计原则） 是认知地基，格式塔与 CRAP 是后续所有视觉决策的「物理定律」，应最先读。
  • 章节二（色彩与排版） 给出可直接落地的取值体系（8px 网格、字号阶梯、对比度阈值）。
  • 章节三（组件设计） 是日常前端最高频的部分，可在地基之上随取随用。
  • 章节四（设计系统） 面向规模化团队，与 ../18_design-systems-tokens/ 配合阅读。
  • 章节五（设计工具） 是协作与交付的工具层，含 2025 年 Figma Config 后的新能力与 AI 辅助现状。

各章节速览

  • 1 设计原则：格式塔、CRAP、可用性与无障碍、UX 流程
  • 2 色彩与排版：色彩理论、排版层级、间距网格、暗色模式
  • 3 组件设计：按钮与表单、导航、卡片列表与数据、模态与反馈
  • 4 设计系统：Design Token、组件库、主题与品牌、设计开发协作
  • 5 设计工具：Figma 工作流、原型与交互、设计评审、AI 辅助设计
