卡片列表与数据展示

卡片组件

卡片（Card）是包含相关信息的独立容器，是现代 UI 中最通用的内容承载组件。

卡片的结构





区域
必要性
内容





Media
可选
封面图、缩略图、图表




Header
必要
标题（必须）、副标题（可选）




Body
可选
描述文字、标签、关键数据




Footer
可选
操作按钮、时间、作者





卡片变体




变体
适用场景
特点





基础卡片
文章列表、商品展示
图片 + 标题 + 描述 + 操作




水平卡片
搜索结果、新闻列表
左图右文，节省纵向空间




交互卡片
可点击入口
整体可点击，Hover 有反馈




统计卡片
仪表盘
数字 + 标签 + 趋势图标




骨架卡片
加载中
灰色占位块替代真实内容







列表组件
列表是信息展示的另一种核心形态，适合展示结构统一的数据集合。


列表类型




类型
适用场景
特点





简单列表
设置项、菜单
文字 + 图标，单行




两行列表
联系人、消息
主文本 + 次文本




三行列表
邮件、通知
标题 + 描述 + 元信息




图文列表
商品、文章
缩略图 + 文字内容







数据表格
数据表格适合展示结构化的多维数据，常见于后台管理系统。


表格设计要素




要素
设计规范





列宽
根据内容类型设定最小宽度，文字列可弹性伸缩




对齐
文字左对齐，数字右对齐，状态居中




行高
紧凑 40px / 默认 52px / 宽松 64px




斑马纹
可选，奇偶行交替背景色




固定列
首列和操作列固定，中间列横向滚动




排序
点击列头排序，显示排序方向箭头

交互
说明

无限滚动

批量操作

行内编辑
点击单元格直接编辑




展开行

筛选
列头下拉筛选器或全局筛选栏

空状态设计
空状态是用户首次使用或数据为空时看到的界面，是提升用户体验的重要机会。






空状态类型
场景
设计内容





首次使用
新用户没有数据
引导插画 + 创建入口 + 说明文字




搜索无结果
搜索/筛选没有匹配
提示 + 修改建议 + 清除筛选入口




错误状态
加载失败
错误说明 + 重试按钮




无权限
用户无访问权限
说明原因 + 申请权限入口





空状态设计原则：


    

  • 提供清晰的说明（为什么是空的）
    • 

  • 提供明确的行动引导（下一步做什么）
    • 

  • 使用插画或图标避免页面过于冰冷
    • 





加载模式




模式
适用场景
视觉表现





Spinner

旋转加载指示器




Progress Bar
可预估时长的操作
进度条




Skeleton Screen
页面首次加载
灰色占位块模拟布局




Shimmer
列表/卡片加载中
闪烁的渐变动画




Placeholder
图片加载中
低分辨率模糊图或颜色占位







小结
    

  • 卡片是通用的内容容器，结构为 Media + Header + Body + Footer
    • 

  • 列表适合结构统一的数据集合，按信息密度选择单行/两行/三行列表
    • 

  • 数据表格的关键是对齐规则（文字左对齐、数字右对齐）和交互模式（排序、筛选、分页）
    • 

  • 无限滚动适合浏览场景，分页适合查找场景
    • 

  • 空状态是提升首次体验的重要机会，需要说明原因和引导行动
    • 

  • 骨架屏是比 Spinner 更好的加载体验，保持页面结构稳定
    •
