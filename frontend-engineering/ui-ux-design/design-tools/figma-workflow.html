Figma 核心工作流

Figma 在设计流程中的角色

Figma 是当前 UI 设计的行业标准工具，其核心优势在于云端协作、组件系统和开发者友好的交付能力。

Components / Screens / Archive

组件创建原则

实例引用

修改传播

覆盖机制
实例可覆盖文本、图片、可见性





Component Variants
Variants 允许一个组件包含多种变体，通过属性切换。

用途

在 Figma 中通过属性面板切换变体，无需手动替换组件。

Auto Layout 是 Figma 中实现响应式布局的核心功能，类似 CSS 的 Flexbox。

小结
    

  • Figma 文件应有清晰的 Team → Project → File → Page 层级结构
    • 

  • 组件系统是设计一致性的核心，使用 Variants 管理多状态
    • 

  • Auto Layout 实现响应式布局，掌握 Fill/Hug/Fixed 三种 Resizing 模式
    • 

  • Figma Variables 是 Design Token 的原生实现，支持多模式主题切换
    • 

  • 善用插件提升效率，但核心能力仍在于扎实的设计基础
    •
