WebGPU 概览

核心概念

WebGPU 是下一代 Web 图形和计算 API，旨在替代 WebGL 成为浏览器中 GPU 编程的标准接口。它的设计借鉴了 Vulkan、Metal 和 Direct3D 12 等现代图形 API 的理念，提供了比 WebGL 更低级别的 GPU 控制、更好的性能和更强大的计算能力。WebGPU 不仅用于图形渲染，还原生支持通用 GPU 计算（GPGPU），为机器学习推理、物理模拟等计算密集型任务打开了浏览器端的大门。

WebGPU 的核心设计原则是显式控制——开发者明确管理资源的创建、绑定和销毁，GPU 状态通过不可变的管线对象描述，而非 WebGL 中的全局状态机。这种设计消除了驱动层的猜测和优化开销，让性能更加可预测。


核心架构与对象模型
WebGPU 的对象模型以 Device 为中心，所有 GPU 资源和操作都通过 Device 创建。


const initWebGPU = async (canvas: HTMLCanvasElement) => {
  const adapter = await navigator.gpu.requestAdapter({
    powerPreference: 'high-performance',
  });
  if (!adapter) throw new Error('WebGPU adapter not available');

  const device = await adapter.requestDevice({
    requiredFeatures: [],
    requiredLimits: {
      maxBindGroups: 4,
    },
  });

  const context = canvas.getContext('webgpu');
  if (!context) throw new Error('WebGPU context not available');

  const format = navigator.gpu.getPreferredCanvasFormat();
  context.configure({
    device,
    format,
    alphaMode: 'premultiplied',
  });

  return { adapter, device, context, format };
};

WGSL 着色器语言
WGSL（WebGPU Shading Language）是 WebGPU 的专用着色器语言，替代了 WebGL 中的 GLSL。


const triangleShader = `
struct VertexInput {
  @location(0) position: vec2<f32>,
  @location(1) color: vec3<f32>,
};

struct VertexOutput {
  @builtin(position) position: vec4<f32>,
  @location(0) color: vec3<f32>,
};

@vertex
fn vs_main(input: VertexInput) -> VertexOutput {
  var output: VertexOutput;
  output.position = vec4<f32>(input.position, 0.0, 1.0);
  output.color = input.color;
  return output;
}

@fragment
fn fs_main(input: VertexOutput) -> @location(0) vec4<f32> {
  return vec4<f32>(input.color, 1.0);
}
`;

const createShaderModule = (device: GPUDevice, code: string): GPUShaderModule => {
  return device.createShaderModule({ code });
};

渲染管线构建
WebGPU 的渲染管线是不可变的预编译对象，包含了从顶点处理到像素输出的完整状态描述。


const createRenderPipeline = (
  device: GPUDevice,
  format: GPUTextureFormat,
  shaderModule: GPUShaderModule,
): GPURenderPipeline => {
  return device.createRenderPipeline({
    layout: 'auto',
    vertex: {
      module: shaderModule,
      entryPoint: 'vs_main',
      buffers: [
        {
          arrayStride: 5 * Float32Array.BYTES_PER_ELEMENT,
          attributes: [
            { shaderLocation: 0, offset: 0, format: 'float32x2' },
            { shaderLocation: 1, offset: 2 * Float32Array.BYTES_PER_ELEMENT, format: 'float32x3' },
          ],
        },
      ],
    },
    fragment: {
      module: shaderModule,
      entryPoint: 'fs_main',
      targets: [{ format }],
    },
    primitive: {
      topology: 'triangle-list',
    },
  });
};
小结
    

  • WebGPU 是下一代 Web 图形和计算 API，基于现代 GPU API 设计理念
    • 

  • 显式控制是核心原则：资源管理、管线状态、命令录制都由开发者显式操作
    • 

  • WGSL 是 WebGPU 专用着色器语言，类型安全且与 WebGPU 资源模型紧密集成
    • 

  • 渲染管线是不可变的预编译对象，消除了运行时状态变更的性能开销
    • 

  • WebGPU 原生支持计算着色器，为 GPGPU 应用打开浏览器端大门
    • 

  • 目前 Chrome 和 Edge 已稳定支持，Firefox 处于实验阶段
