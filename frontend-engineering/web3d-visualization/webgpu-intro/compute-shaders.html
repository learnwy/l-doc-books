计算着色器

核心概念

计算着色器（Compute Shader）是 WebGPU 相比 WebGL 最重大的能力飞跃。它允许开发者直接利用 GPU 的大规模并行计算能力处理通用计算任务，而不仅限于图形渲染。GPU 拥有数千个计算核心，擅长处理高度并行的数据密集型任务——如矩阵运算、粒子模拟、图像处理和机器学习推理。

计算着色器的核心编程模型基于工作组（Workgroup）：一个计算任务被划分为多个工作组，每个工作组包含固定数量的线程（invocation），工作组内的线程可以通过共享内存高效通信。


计算着色器基础
const computeShader = `
@group(0) @binding(0) var<storage, read> inputData: array<f32>;
@group(0) @binding(1) var<storage, read_write> outputData: array<f32>;

@compute @workgroup_size(256)
fn main(@builtin(global_invocation_id) globalId: vec3<u32>) {
  let index = globalId.x;
  if (index >= arrayLength(&inputData)) {
    return;
  }
  outputData[index] = inputData[index] * 2.0 + 1.0;
}
`;

const runComputeShader = async (device: GPUDevice, inputArray: Float32Array): Promise<Float32Array> => {
  const inputBuffer = device.createBuffer({
    size: inputArray.byteLength,
    usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_DST,
  });
  device.queue.writeBuffer(inputBuffer, 0, inputArray);

  const outputBuffer = device.createBuffer({
    size: inputArray.byteLength,
    usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_SRC,
  });

  const readBuffer = device.createBuffer({
    size: inputArray.byteLength,
    usage: GPUBufferUsage.MAP_READ | GPUBufferUsage.COPY_DST,
  });

  const shaderModule = device.createShaderModule({ code: computeShader });

  const pipeline = device.createComputePipeline({
    layout: 'auto',
    compute: { module: shaderModule, entryPoint: 'main' },
  });

  const bindGroup = device.createBindGroup({
    layout: pipeline.getBindGroupLayout(0),
    entries: [
      { binding: 0, resource: { buffer: inputBuffer } },
      { binding: 1, resource: { buffer: outputBuffer } },
    ],
  });

  const encoder = device.createCommandEncoder();
  const pass = encoder.beginComputePass();
  pass.setPipeline(pipeline);
  pass.setBindGroup(0, bindGroup);
  pass.dispatchWorkgroups(Math.ceil(inputArray.length / 256));
  pass.end();

  encoder.copyBufferToBuffer(outputBuffer, 0, readBuffer, 0, inputArray.byteLength);
  device.queue.submit([encoder.finish()]);

  await readBuffer.mapAsync(GPUMapMode.READ);
  const result = new Float32Array(readBuffer.getMappedRange().slice(0));
  readBuffer.unmap();

  return result;
};

const matrixMultiplyShader = `
struct Matrices {
  M: u32,
  N: u32,
  K: u32,
};

@group(0) @binding(0) var<uniform> dims: Matrices;
@group(0) @binding(1) var<storage, read> matA: array<f32>;
@group(0) @binding(2) var<storage, read> matB: array<f32>;
@group(0) @binding(3) var<storage, read_write> matC: array<f32>;

@compute @workgroup_size(16, 16)
fn main(@builtin(global_invocation_id) globalId: vec3<u32>) {
  let row = globalId.x;
  let col = globalId.y;

  if (row >= dims.M || col >= dims.N) {
    return;
  }

  var sum: f32 = 0.0;
  for (var k: u32 = 0u; k < dims.K; k = k + 1u) {
    sum = sum + matA[row * dims.K + k] * matB[k * dims.N + col];
  }

  matC[row * dims.N + col] = sum;
}
`;
工作组大小选择的经验法则：


    

  • 一维数据处理（数组操作）：workgroup_size(256) 或 workgroup_size(64)
    • 

  • 二维数据处理（图像/矩阵）：workgroup_size(16, 16) 或 workgroup_size(8, 8)
    • 

  • 三维数据处理（体素/体积）：workgroup_size(4, 4, 4)
    • 

  • 总线程数通常保持在 64-256 之间以获得最佳占用率
    • 



工作组共享内存
共享内存（Shared Memory）是同一工作组内所有线程共享的高速缓存，访问速度比全局内存快 10-100 倍。


const reductionShader = `
var<workgroup> sharedData: array<f32, 256>;

@group(0) @binding(0) var<storage, read> inputData: array<f32>;
@group(0) @binding(1) var<storage, read_write> outputData: array<f32>;

@compute @workgroup_size(256)
fn main(
  @builtin(local_invocation_id) localId: vec3<u32>,
  @builtin(workgroup_id) groupId: vec3<u32>,
) {
  let globalIndex = groupId.x * 256u + localId.x;
  sharedData[localId.x] = inputData[globalIndex];
  workgroupBarrier();

  for (var stride: u32 = 128u; stride > 0u; stride = stride >> 1u) {
    if (localId.x < stride) {
      sharedData[localId.x] = sharedData[localId.x] + sharedData[localId.x + stride];
    }
    workgroupBarrier();
  }

  if (localId.x == 0u) {
    outputData[groupId.x] = sharedData[0];
  }
}
`;

小结
    

  • 计算着色器是 WebGPU 相比 WebGL 最重要的能力提升
    • 

  • 工作组模型将计算任务分解为可协作的线程块
    • 

  • 共享内存提供工作组内的高速数据交换，是性能优化的关键
    • 

  • 工作组大小应根据数据维度和 GPU 架构合理选择
    • 

  • 计算着色器适用于矩阵运算、粒子系统、图像处理和 ML 推理
    • 

  • GPU 并行计算在数据量达到万级以上时才能体现优势
    •
