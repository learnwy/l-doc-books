SVG 动画

核心概念

SVG 动画是 Web 平台上实现矢量图形动态效果的技术体系。它包含三种互补的动画方案：SMIL 声明式动画（SVG 原生）、CSS 动画（样式驱动）和 JavaScript 动画（程序化控制）。SVG 动画天然继承了矢量图形的无损缩放特性，在任何分辨率下都保持清晰，适合图标动画、数据可视化过渡和交互式信息图。

三种方案的选择原则：简单的状态过渡用 CSS，路径动画和交互序列用 SMIL，复杂的程序化动画和精确时序控制用 JavaScript。


CSS 驱动的 SVG 动画
CSS 动画是 SVG 动画中最简单且性能最好的方案，可以直接对 SVG 属性使用 transition 和 @keyframes。


const svgWithCssAnimation = `
<svg viewBox="0 0 400 200" xmlns="http://www.w3.org/2000/svg">
  <style>
    .pulse-circle {
      transform-origin: center;
      animation: pulse 2s ease-in-out infinite;
    }
    @keyframes pulse {
      0%, 100% { r: 30; opacity: 1; }
      50% { r: 45; opacity: 0.6; }
    }
    
    .bar {
      transition: height 0.6s cubic-bezier(0.34, 1.56, 0.64, 1),
                  y 0.6s cubic-bezier(0.34, 1.56, 0.64, 1);
    }
    .bar:hover {
      height: 120;
      y: 30;
    }
    
    .line-path {
      stroke-dasharray: 1000;
      stroke-dashoffset: 1000;
      animation: draw-line 2s ease forwards;
    }
    @keyframes draw-line {
      to { stroke-dashoffset: 0; }
    }
  </style>
  
  <circle class="pulse-circle" cx="50" cy="100" r="30" fill="steelblue"/>
  <rect class="bar" x="120" y="50" width="40" height="100" fill="coral"/>
  <path class="line-path" d="M200,150 Q250,30 300,100 T400,80" 
        fill="none" stroke="steelblue" stroke-width="2"/>
</svg>
`;
线条绘制动画（stroke-dasharray/stroke-dashoffset）是 SVG + CSS 最经典的动画效果：通过设置虚线间隔等于路径总长，然后动画减少偏移量，产生线条逐渐绘制的视觉效果。


const animatePathDrawing = (pathElement: SVGPathElement): void => {
  const length = pathElement.getTotalLength();
  pathElement.style.strokeDasharray = `${length}`;
  pathElement.style.strokeDashoffset = `${length}`;

  pathElement.animate([{ strokeDashoffset: length }, { strokeDashoffset: 0 }], {
    duration: 2000,
    easing: 'ease-in-out',
    fill: 'forwards',
  });
};
SMIL 路径动画
SMIL（Synchronized Multimedia Integration Language）是 SVG 原生的动画标准，对路径动画有独特的支持能力。


const smilMotionAnimation = `
<svg viewBox="0 0 500 300" xmlns="http://www.w3.org/2000/svg">
  <path id="motionPath" 
        d="M50,250 C150,50 350,50 450,250" 
        fill="none" stroke="#ccc" stroke-width="1" stroke-dasharray="5,5"/>
  
  <circle r="8" fill="steelblue">
    <animateMotion dur="3s" repeatCount="indefinite" rotate="auto">
      <mpath href="#motionPath"/>
    </animateMotion>
  </circle>
  
  <rect x="-15" y="-10" width="30" height="20" rx="5" fill="coral">
    <animateMotion dur="4s" begin="1s" repeatCount="indefinite" rotate="auto"
                   path="M100,150 Q250,50 400,150 Q250,250 100,150"/>
  </rect>
</svg>
`;

Web Animations API
Web Animations API（WAAPI）提供了 JavaScript 级别的动画控制，结合了 CSS 动画的性能和 JavaScript 的灵活性。


interface SVGAnimationConfig {
  element: SVGElement;
  keyframes: Keyframe[];
  options: KeyframeAnimationOptions;
}

const createSequenceAnimation = (elements: SVGElement[], staggerDelay: number): Animation[] => {
  return elements.map((el, index) => {
    return el.animate(
      [
        { transform: 'scale(0)', opacity: 0 },
        { transform: 'scale(1.1)', opacity: 0.8, offset: 0.7 },
        { transform: 'scale(1)', opacity: 1 },
      ],
      {
        duration: 600,
        delay: index * staggerDelay,
        easing: 'cubic-bezier(0.34, 1.56, 0.64, 1)',
        fill: 'forwards',
      },
    );
  });
};

const createChartTransition = (
  bars: SVGRectElement[],
  newData: number[],
  maxValue: number,
  chartHeight: number,
): void => {
  bars.forEach((bar, i) => {
    const newHeight = (newData[i] / maxValue) * chartHeight;
    const newY = chartHeight - newHeight;

    bar.animate(
      [
        { height: bar.getAttribute('height') + 'px', y: bar.getAttribute('y') },
        { height: newHeight + 'px', y: newY },
      ],
      {
        duration: 800,
        easing: 'ease-out',
        fill: 'forwards',
      },
    );
  });
};

动画设计的核心原则：


    

  • 有意义：每个动画都应传达信息（数据从哪来、变化了多少）
    • 

  • 不干扰：动画不能延缓用户获取信息的速度
    • 

  • 可预测：相同的交互应产生相同的动画效果
    • 

  • 可中断：用户操作应能打断进行中的动画
    • 



const animateDataUpdate = (group: SVGGElement, oldData: number[], newData: number[]): void => {
  const bars = group.querySelectorAll<SVGRectElement>('rect');

  bars.forEach((bar, i) => {
    const animations = bar.getAnimations();
    animations.forEach((a) => a.cancel());

    const oldHeight = oldData[i];
    const newHeight = newData[i];

    bar.animate([{ height: `${oldHeight}px` }, { height: `${newHeight}px` }], {
      duration: 600,
      easing: 'ease-in-out',
      fill: 'forwards',
    });
  });
};
小结
    

  • SVG 动画有 CSS、SMIL 和 JavaScript 三种互补方案
    • 

  • CSS 动画最简单高性能，适合状态过渡和简单效果
    • 

  • SMIL 路径动画（animateMotion）是 SVG 的独特优势
    • 

  • Web Animations API 兼具 CSS 的性能和 JavaScript 的灵活性
    • 

  • 数据可视化动画应传达信息而非纯装饰，遵循有意义、不干扰、可中断的原则
    • 

  • 动画时长应匹配操作类型：交互反馈 100-300ms，数据更新 500-1000ms
    •
