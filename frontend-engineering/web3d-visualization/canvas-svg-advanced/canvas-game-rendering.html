Canvas 游戏渲染

核心概念

Canvas 游戏渲染是利用 HTML5 Canvas API 构建 2D 游戏画面的技术实践。游戏渲染与数据可视化渲染的核心区别在于：游戏需要在每一帧（通常 60fps）中更新数以百计的游戏对象状态并重新绘制整个画面，同时处理用户输入、碰撞检测和游戏逻辑。理解游戏循环（Game Loop）的设计是掌握游戏渲染的关键。

Canvas 2D 游戏渲染的核心挑战是在 16.67ms（60fps）内完成所有更新和绘制操作。


游戏循环架构
游戏循环是游戏运行的心脏，它控制着更新和渲染的节奏。


interface GameState {
  entities: GameEntity[];
  score: number;
  isRunning: boolean;
}

interface GameEntity {
  x: number;
  y: number;
  width: number;
  height: number;
  vx: number;
  vy: number;
  update: (dt: number) => void;
  render: (ctx: CanvasRenderingContext2D) => void;
}

const FIXED_TIMESTEP = 1000 / 60;

const createGameLoop = (ctx: CanvasRenderingContext2D, state: GameState): { start: () => void; stop: () => void } => {
  let lastTime = 0;
  let accumulator = 0;
  let animationId = 0;

  const loop = (currentTime: number) => {
    if (!state.isRunning) return;

    const frameTime = Math.min(currentTime - lastTime, 250);
    lastTime = currentTime;
    accumulator += frameTime;

    while (accumulator >= FIXED_TIMESTEP) {
      update(state, FIXED_TIMESTEP / 1000);
      accumulator -= FIXED_TIMESTEP;
    }

    render(ctx, state);
    animationId = requestAnimationFrame(loop);
  };

  return {
    start: () => {
      state.isRunning = true;
      lastTime = performance.now();
      animationId = requestAnimationFrame(loop);
    },
    stop: () => {
      state.isRunning = false;
      cancelAnimationFrame(animationId);
    },
  };
};

const update = (state: GameState, dt: number): void => {
  for (const entity of state.entities) {
    entity.update(dt);
  }
  checkCollisions(state.entities);
};

const render = (ctx: CanvasRenderingContext2D, state: GameState): void => {
  ctx.clearRect(0, 0, ctx.canvas.width, ctx.canvas.height);
  for (const entity of state.entities) {
    entity.render(ctx);
  }
};
固定时间步长（Fixed Timestep）确保物理模拟的一致性——无论帧率如何波动，游戏逻辑始终以固定间隔更新。


精灵渲染与动画
游戏中的视觉元素通常以精灵（Sprite）的形式管理，使用精灵表（Sprite Sheet）减少图像请求。


interface SpriteSheet {
  image: HTMLImageElement;
  frameWidth: number;
  frameHeight: number;
  columns: number;
  rows: number;
}

interface AnimationConfig {
  frames: number[];
  frameDuration: number;
  loop: boolean;
}

const createAnimatedSprite = (sheet: SpriteSheet, animations: Record<string, AnimationConfig>) => {
  let currentAnim = '';
  let frameIndex = 0;
  let elapsed = 0;

  return {
    play(animName: string) {
      if (currentAnim !== animName) {
        currentAnim = animName;
        frameIndex = 0;
        elapsed = 0;
      }
    },

    update(dt: number) {
      const anim = animations[currentAnim];
      if (!anim) return;

      elapsed += dt * 1000;
      if (elapsed >= anim.frameDuration) {
        elapsed -= anim.frameDuration;
        frameIndex++;
        if (frameIndex >= anim.frames.length) {
          frameIndex = anim.loop ? 0 : anim.frames.length - 1;
        }
      }
    },

    render(ctx: CanvasRenderingContext2D, x: number, y: number) {
      const anim = animations[currentAnim];
      if (!anim) return;

      const frame = anim.frames[frameIndex];
      const sx = (frame % sheet.columns) * sheet.frameWidth;
      const sy = Math.floor(frame / sheet.columns) * sheet.frameHeight;

      ctx.drawImage(
        sheet.image,
        sx,
        sy,
        sheet.frameWidth,
        sheet.frameHeight,
        x,
        y,
        sheet.frameWidth,
        sheet.frameHeight,
      );
    },
  };
};

碰撞检测
碰撞检测是游戏渲染中计算密集度最高的环节。


interface AABB {
  x: number;
  y: number;
  width: number;
  height: number;
}

const aabbCollision = (a: AABB, b: AABB): boolean => {
  return a.x < b.x + b.width && a.x + a.width > b.x && a.y < b.y + b.height && a.y + a.height > b.y;
};

const circleCollision = (ax: number, ay: number, ar: number, bx: number, by: number, br: number): boolean => {
  const dx = ax - bx;
  const dy = ay - by;
  const distSq = dx * dx + dy * dy;
  const radiusSum = ar + br;
  return distSq <= radiusSum * radiusSum;
};

const checkCollisions = (entities: GameEntity[]): void => {
  for (let i = 0; i < entities.length; i++) {
    for (let j = i + 1; j < entities.length; j++) {
      if (aabbCollision(entities[i], entities[j])) {
        resolveCollision(entities[i], entities[j]);
      }
    }
  }
};
输入处理与响应
游戏输入需要低延迟的事件处理和流畅的状态映射。


interface InputState {
  keys: Set<string>;
  mouse: { x: number; y: number; pressed: boolean };
  touches: Map<number, { x: number; y: number }>;
}

const createInputManager = (canvas: HTMLCanvasElement): InputState => {
  const state: InputState = {
    keys: new Set(),
    mouse: { x: 0, y: 0, pressed: false },
    touches: new Map(),
  };

  document.addEventListener('keydown', (e) => {
    state.keys.add(e.code);
    e.preventDefault();
  });

  document.addEventListener('keyup', (e) => {
    state.keys.delete(e.code);
  });

  canvas.addEventListener('pointermove', (e) => {
    const rect = canvas.getBoundingClientRect();
    state.mouse.x = (e.clientX - rect.left) * (canvas.width / rect.width);
    state.mouse.y = (e.clientY - rect.top) * (canvas.height / rect.height);
  });

  canvas.addEventListener('pointerdown', () => {
    state.mouse.pressed = true;
  });
  canvas.addEventListener('pointerup', () => {
    state.mouse.pressed = false;
  });

  return state;
};
小结
    

  • 游戏循环是游戏渲染的核心架构，固定时间步长确保物理模拟一致性
    • 

  • 精灵表和帧动画系统是 2D 游戏视觉表现的基础
    • 

  • 碰撞检测需要宽阶段（空间分区）+ 窄阶段（精确检测）两级优化
    • 

  • 输入处理应基于状态轮询而非事件回调，确保游戏循环中的一致性
    • 

  • Canvas 2D 适合休闲、益智类 2D 游戏，复杂 3D 游戏应使用 WebGL 或游戏引擎
    • 

  • 性能优化的核心是对象池、批量渲染和空间分区
