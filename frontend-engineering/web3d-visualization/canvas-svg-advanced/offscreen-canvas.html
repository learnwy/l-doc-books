OffscreenCanvas 离屏画布

核心概念

OffscreenCanvas 是一种可以在 Web Worker 中使用的 Canvas API，它将渲染操作从主线程移至后台线程，从而避免复杂的绑制任务阻塞 UI 响应。在传统方案中，所有 Canvas 绑制都必须在主线程执行，当绑制计算量大时（如实时数据可视化、游戏渲染），会导致页面卡顿、用户交互延迟。OffscreenCanvas 从根本上解决了这一问题。

OffscreenCanvas 有两种使用模式：在主线程中作为离屏缓冲区（不关联 DOM），以及通过 transferControlToOffscreen() 将 Canvas 控制权转移到 Worker 线程。


Worker 中的渲染流程
将 Canvas 渲染移至 Worker 是 OffscreenCanvas 最核心的用法。


const setupOffscreenRendering = (canvas: HTMLCanvasElement): Worker => {
  const offscreen = canvas.transferControlToOffscreen();
  const worker = new Worker(new URL('./render-worker.ts', import.meta.url), {
    type: 'module',
  });

  worker.postMessage({ type: 'init', canvas: offscreen }, [offscreen]);

  return worker;
};

const sendDataToWorker = (worker: Worker, data: Float32Array): void => {
  worker.postMessage({ type: 'render', data: data.buffer }, [data.buffer]);
};
Worker 端的渲染实现：


let ctx: OffscreenCanvasRenderingContext2D | null = null;
let width = 0;
let height = 0;

self.onmessage = (event: MessageEvent) => {
  const { type } = event.data;

  if (type === 'init') {
    const canvas = event.data.canvas as OffscreenCanvas;
    width = canvas.width;
    height = canvas.height;
    ctx = canvas.getContext('2d');
    return;
  }

  if (type === 'render' && ctx) {
    const data = new Float32Array(event.data.data);
    renderVisualization(ctx, data, width, height);
  }
};

const renderVisualization = (
  ctx: OffscreenCanvasRenderingContext2D,
  data: Float32Array,
  width: number,
  height: number,
): void => {
  ctx.clearRect(0, 0, width, height);

  const pointCount = data.length / 2;
  ctx.fillStyle = 'rgba(70, 130, 180, 0.4)';
  ctx.beginPath();

  for (let i = 0; i < pointCount; i++) {
    const x = data[i * 2] * width;
    const y = data[i * 2 + 1] * height;
    ctx.moveTo(x + 2, y);
    ctx.arc(x, y, 2, 0, Math.PI * 2);
  }

  ctx.fill();
};
离屏预渲染优化
即使不使用 Worker，OffscreenCanvas 也可以作为离屏缓冲区用于预渲染和缓存复杂图形。


const createCachedSprite = (
  drawFn: (ctx: OffscreenCanvasRenderingContext2D) => void,
  width: number,
  height: number,
): OffscreenCanvas => {
  const offscreen = new OffscreenCanvas(width, height);
  const ctx = offscreen.getContext('2d');
  if (ctx) drawFn(ctx);
  return offscreen;
};

interface SpriteCache {
  get: (key: string) => OffscreenCanvas | undefined;
  set: (key: string, sprite: OffscreenCanvas) => void;
}

const createSpriteCache = (): SpriteCache => {
  const cache = new Map<string, OffscreenCanvas>();
  return {
    get: (key) => cache.get(key),
    set: (key, sprite) => cache.set(key, sprite),
  };
};

const renderWithCache = (
  ctx: CanvasRenderingContext2D,
  cache: SpriteCache,
  items: Array<{ type: string; x: number; y: number }>,
): void => {
  for (const item of items) {
    const sprite = cache.get(item.type);
    if (sprite) {
      ctx.drawImage(sprite, item.x, item.y);
    }
  }
};

数据传输优化
主线程与 Worker 之间的数据传输效率直接影响渲染性能。


const createSharedBuffer = (pointCount: number): SharedArrayBuffer => {
  const buffer = new SharedArrayBuffer(pointCount * 2 * Float32Array.BYTES_PER_ELEMENT);
  return buffer;
};

const updateSharedData = (buffer: SharedArrayBuffer, newData: Array<{ x: number; y: number }>): void => {
  const view = new Float32Array(buffer);
  for (let i = 0; i < newData.length; i++) {
    view[i * 2] = newData[i].x;
    view[i * 2 + 1] = newData[i].y;
  }
};

实际应用场景
interface ChartWorkerMessage {
  type: 'init' | 'updateData' | 'resize' | 'destroy';
  canvas?: OffscreenCanvas;
  data?: ArrayBuffer;
  width?: number;
  height?: number;
}

const createOffscreenChart = (
  container: HTMLElement,
): { worker: Worker; sendData: (data: Float32Array) => void; destroy: () => void } => {
  const canvas = document.createElement('canvas');
  canvas.width = container.clientWidth * devicePixelRatio;
  canvas.height = container.clientHeight * devicePixelRatio;
  canvas.style.width = '100%';
  canvas.style.height = '100%';
  container.appendChild(canvas);

  const offscreen = canvas.transferControlToOffscreen();
  const worker = new Worker(new URL('./chart-worker.ts', import.meta.url), {
    type: 'module',
  });

  worker.postMessage({ type: 'init', canvas: offscreen } as ChartWorkerMessage, [offscreen]);

  const resizeObserver = new ResizeObserver((entries) => {
    const { width, height } = entries[0].contentRect;
    worker.postMessage({
      type: 'resize',
      width: width * devicePixelRatio,
      height: height * devicePixelRatio,
    } as ChartWorkerMessage);
  });
  resizeObserver.observe(container);

  return {
    worker,
    sendData: (data: Float32Array) => {
      worker.postMessage({ type: 'updateData', data: data.buffer } as ChartWorkerMessage, [data.buffer]);
    },
    destroy: () => {
      worker.postMessage({ type: 'destroy' } as ChartWorkerMessage);
      worker.terminate();
      resizeObserver.disconnect();
    },
  };
};
小结
    

  • OffscreenCanvas 将渲染从主线程移至 Worker，根本解决 Canvas 绑制导致的 UI 卡顿
    • 

  • transferControlToOffscreen() 是将 DOM Canvas 控制权转移到 Worker 的关键 API
    • 

  • 即使不用 Worker，OffscreenCanvas 也可作为离屏缓冲区优化渲染性能
    • 

  • 数据传输优先使用 Transferable（零复制）或 SharedArrayBuffer（共享内存）
    • 

  • 适合大数据量实时可视化、游戏渲染、图像处理等重度计算场景
    • 

  • 需注意浏览器兼容性，Safari 对 Worker 中的 OffscreenCanvas 支持有限
    •
