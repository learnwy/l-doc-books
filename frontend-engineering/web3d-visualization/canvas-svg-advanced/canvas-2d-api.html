Canvas 2D API 深入

核心概念

Canvas 2D API 是浏览器提供的底层像素级绘图接口，通过 <canvas> 元素和 CanvasRenderingContext2D 上下文对象，开发者可以使用 JavaScript 直接控制每一个像素的渲染。它是即时模式（Immediate Mode）的渲染接口——每次绘制操作直接写入像素缓冲区，浏览器不维护绘制对象的状态树。

Canvas 2D API 的核心模型是状态机：所有绘制操作都基于当前状态（填充色、线条宽度、变换矩阵等），通过 save() 和 restore() 管理状态栈。


路径与形状绘制
路径是 Canvas 2D 绑制所有形状的基础。复杂的图形都由基本路径命令组合而成。


const drawComplexShape = (ctx: CanvasRenderingContext2D): void => {
  ctx.beginPath();

  ctx.moveTo(100, 50);
  ctx.lineTo(200, 50);
  ctx.quadraticCurveTo(250, 50, 250, 100);
  ctx.lineTo(250, 200);
  ctx.bezierCurveTo(250, 250, 200, 250, 150, 200);
  ctx.arcTo(50, 200, 50, 100, 30);
  ctx.closePath();

  ctx.fillStyle = 'rgba(70, 130, 180, 0.5)';
  ctx.fill();
  ctx.strokeStyle = 'rgba(70, 130, 180, 1)';
  ctx.lineWidth = 2;
  ctx.stroke();
};

const drawChart = (ctx: CanvasRenderingContext2D, data: number[], width: number, height: number): void => {
  const padding = 40;
  const chartWidth = width - padding * 2;
  const chartHeight = height - padding * 2;
  const maxVal = Math.max(...data);
  const barWidth = chartWidth / data.length - 4;

  ctx.save();
  ctx.translate(padding, padding);

  for (let i = 0; i < data.length; i++) {
    const barHeight = (data[i] / maxVal) * chartHeight;
    const x = i * (barWidth + 4);
    const y = chartHeight - barHeight;

    ctx.fillStyle = `hsl(${210 + i * 15}, 60%, 55%)`;
    ctx.fillRect(x, y, barWidth, barHeight);
  }

  ctx.restore();
};

变换与合成
Canvas 2D 的变换操作基于仿射变换矩阵，支持平移、旋转、缩放和自定义矩阵变换。


const drawRotatedElement = (
  ctx: CanvasRenderingContext2D,
  x: number,
  y: number,
  width: number,
  height: number,
  angle: number,
): void => {
  ctx.save();
  ctx.translate(x + width / 2, y + height / 2);
  ctx.rotate(angle);
  ctx.fillRect(-width / 2, -height / 2, width, height);
  ctx.restore();
};

const drawWithComposite = (ctx: CanvasRenderingContext2D): void => {
  ctx.fillStyle = 'rgba(255, 100, 100, 0.8)';
  ctx.fillRect(50, 50, 150, 150);

  ctx.globalCompositeOperation = 'multiply';
  ctx.fillStyle = 'rgba(100, 100, 255, 0.8)';
  ctx.fillRect(100, 100, 150, 150);

  ctx.globalCompositeOperation = 'source-over';
};
合成操作（globalCompositeOperation）控制新绘制内容与已有内容的混合方式，有 26 种预定义模式，常用的包括 source-over（默认叠加）、multiply（正片叠底）、screen（滤色）和 destination-out（擦除）。


像素操作与图像处理
Canvas 2D 的独特能力之一是直接访问和操作像素数据。


const applyGrayscaleFilter = (
  ctx: CanvasRenderingContext2D,
  x: number,
  y: number,
  width: number,
  height: number,
): void => {
  const imageData = ctx.getImageData(x, y, width, height);
  const pixels = imageData.data;

  for (let i = 0; i < pixels.length; i += 4) {
    const gray = pixels[i] * 0.299 + pixels[i + 1] * 0.587 + pixels[i + 2] * 0.114;
    pixels[i] = gray;
    pixels[i + 1] = gray;
    pixels[i + 2] = gray;
  }

  ctx.putImageData(imageData, x, y);
};

interface HeatmapPoint {
  x: number;
  y: number;
  intensity: number;
}

const renderHeatmap = (ctx: CanvasRenderingContext2D, points: HeatmapPoint[], radius: number): void => {
  for (const point of points) {
    const gradient = ctx.createRadialGradient(point.x, point.y, 0, point.x, point.y, radius);
    gradient.addColorStop(0, `rgba(255, 0, 0, ${point.intensity})`);
    gradient.addColorStop(1, 'rgba(255, 0, 0, 0)');

    ctx.fillStyle = gradient;
    ctx.fillRect(point.x - radius, point.y - radius, radius * 2, radius * 2);
  }
};

性能优化实践
Canvas 2D 的性能优化核心是减少绘制调用次数和状态切换次数。


const optimizedBatchRender = (
  ctx: CanvasRenderingContext2D,
  points: Array<{ x: number; y: number; color: string }>,
): void => {
  const byColor = new Map<string, Array<{ x: number; y: number }>>();
  for (const p of points) {
    const group = byColor.get(p.color) ?? [];
    group.push(p);
    byColor.set(p.color, group);
  }

  for (const [color, group] of byColor) {
    ctx.fillStyle = color;
    ctx.beginPath();
    for (const p of group) {
      ctx.moveTo(p.x + 3, p.y);
      ctx.arc(p.x, p.y, 3, 0, Math.PI * 2);
    }
    ctx.fill();
  }
};

小结
    

  • Canvas 2D API 是基于状态机的即时模式渲染接口，提供像素级绘图控制
    • 

  • 路径系统是所有形状绘制的基础，通过组合基本路径命令构建复杂图形
    • 

  • 变换操作基于仿射矩阵，save()/restore() 管理状态栈是关键实践
    • 

  • 像素操作能力是 Canvas 区别于 SVG 的核心优势，支持图像滤镜和热力图渲染
    • 

  • 性能优化的核心是减少绘制调用：按样式分组、分层渲染、脏区域重绘
    • 

  • Canvas 2D 适合中等复杂度的高性能可视化，更高性能需求应考虑 WebGL/WebGPU
    •
