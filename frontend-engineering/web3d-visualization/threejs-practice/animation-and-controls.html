动画与交互控制

核心概念

动画是 3D 应用的灵魂。Three.js 的动画系统分为两大类：程序化动画通过数学公式在每帧计算变换，骨骼动画通过预制动画数据驱动模型骨架。交互控制则让用户能够通过鼠标、触摸和键盘操控场景中的相机和对象。

Three.js 内置的 AnimationMixer 是动画播放的核心控制器，支持混合、淡入淡出和图层权重等高级特性。

程序化动画与缓动

程序化动画直接在渲染循环中修改对象属性，适合简单循环动画和数据驱动的可视化。

import { Clock, Object3D, MathUtils } from 'three';

interface AnimationState {
  clock: Clock;
  objects: AnimatedObject[];
}

interface AnimatedObject {
  target: Object3D;
  animation: (target: Object3D, elapsed: number, delta: number) => void;
}

const createAnimationLoop = (): AnimationState => ({
  clock: new Clock(),
  objects: [],
});

const updateAnimations = (state: AnimationState) => {
  const delta = state.clock.getDelta();
  const elapsed = state.clock.getElapsedTime();

  for (const obj of state.objects) {
    obj.animation(obj.target, elapsed, delta);
  }
};

const floatingAnimation = (target: Object3D, elapsed: number) => {
  target.position.y = Math.sin(elapsed * 2) * 0.3 + 1.5;
  target.rotation.y = elapsed * 0.5;
};

const orbitAnimation = (radius: number, speed: number) => (target: Object3D, elapsed: number) => {
  target.position.x = Math.cos(elapsed * speed) * radius;
  target.position.z = Math.sin(elapsed * speed) * radius;
  target.lookAt(0, 0, 0);
};

缓动函数（Easing）控制动画的加速和减速特性。自定义补间系统可以替代外部库：

type EasingFn = (t: number) => number;

const easings: Record<string, EasingFn> = {
  linear: (t) => t,
  easeInQuad: (t) => t * t,
  easeOutQuad: (t) => t * (2 - t),
  easeInOutQuad: (t) => (t < 0.5 ? 2 * t * t : -1 + (4 - 2 * t) * t),
  easeInCubic: (t) => t * t * t,
  easeOutCubic: (t) => --t * t * t + 1,
  easeOutElastic: (t) => {
    const p = 0.3;
    return Math.pow(2, -10 * t) * Math.sin(((t - p / 4) * (2 * Math.PI)) / p) + 1;
  },
};

interface Tween {
  startValue: number;
  endValue: number;
  duration: number;
  elapsed: number;
  easing: EasingFn;
  onUpdate: (value: number) => void;
  onComplete?: () => void;
  completed: boolean;
}

const createTween = (config: Omit<Tween, 'elapsed' | 'completed'>): Tween => ({
  ...config,
  elapsed: 0,
  completed: false,
});

const updateTweens = (tweens: Tween[], delta: number) => {
  for (const tween of tweens) {
    if (tween.completed) continue;
    tween.elapsed = Math.min(tween.elapsed + delta, tween.duration);
    const t = tween.easing(tween.elapsed / tween.duration);
    const value = MathUtils.lerp(tween.startValue, tween.endValue, t);
    tween.onUpdate(value);

    if (tween.elapsed >= tween.duration) {
      tween.completed = true;
      tween.onComplete?.();
    }
  }
};

骨骼动画与 AnimationMixer

glTF 模型通常包含预设的骨骼动画。AnimationMixer 负责播放和混合这些动画剪辑。

import { AnimationMixer, AnimationAction, LoopRepeat } from 'three';

interface CharacterAnimator {
  mixer: AnimationMixer;
  actions: Map<string, AnimationAction>;
  currentAction: AnimationAction | null;
}

const createCharacterAnimator = (gltf: import('three/addons/loaders/GLTFLoader.js').GLTF): CharacterAnimator => {
  const mixer = new AnimationMixer(gltf.scene);
  const actions = new Map<string, AnimationAction>();

  for (const clip of gltf.animations) {
    const action = mixer.clipAction(clip);
    actions.set(clip.name, action);
  }

  return { mixer, actions, currentAction: null };
};

const playAnimation = (animator: CharacterAnimator, name: string, fadeDuration: number = 0.3) => {
  const nextAction = animator.actions.get(name);
  if (!nextAction) return;

  if (animator.currentAction && animator.currentAction !== nextAction) {
    animator.currentAction.fadeOut(fadeDuration);
  }

  nextAction.reset().fadeIn(fadeDuration).play();
  nextAction.setLoop(LoopRepeat, Infinity);
  animator.currentAction = nextAction;
};

const updateCharacter = (animator: CharacterAnimator, delta: number) => {
  animator.mixer.update(delta);
};

动画混合允许同时播放多个动画并控制它们的权重，实现行走与挥手的叠加效果：

const blendAnimations = (animator: CharacterAnimator, configs: Array<{ name: string; weight: number }>) => {
  for (const [name, action] of animator.actions) {
    const config = configs.find((c) => c.name === name);
    if (config) {
      action.setEffectiveWeight(config.weight);
      if (!action.isRunning()) action.play();
    } else {
      action.setEffectiveWeight(0);
    }
  }
};

相机控制器

Three.js 提供多种相机控制器，OrbitControls 最为常用。理解其配置能实现精细的交互体验。

import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const setupOrbitControls = (camera: import('three').PerspectiveCamera, domElement: HTMLElement) => {
  const controls = new OrbitControls(camera, domElement);

  controls.enableDamping = true;
  controls.dampingFactor = 0.05;
  controls.rotateSpeed = 0.8;
  controls.zoomSpeed = 1.2;
  controls.panSpeed = 0.8;
  controls.minDistance = 2;
  controls.maxDistance = 50;
  controls.minPolarAngle = 0.1;
  controls.maxPolarAngle = Math.PI / 2 - 0.05;
  controls.autoRotate = false;
  controls.autoRotateSpeed = 2.0;

  return controls;
};

实现自定义的第一人称控制器：

interface FPSControls {
  yaw: number;
  pitch: number;
  moveSpeed: number;
  lookSpeed: number;
  velocity: { x: number; y: number; z: number };
  keys: Set<string>;
}

const createFPSControls = (camera: import('three').PerspectiveCamera, canvas: HTMLElement): FPSControls => {
  const state: FPSControls = {
    yaw: 0,
    pitch: 0,
    moveSpeed: 5,
    lookSpeed: 0.002,
    velocity: { x: 0, y: 0, z: 0 },
    keys: new Set(),
  };

  canvas.addEventListener('click', () => canvas.requestPointerLock());

  document.addEventListener('mousemove', (e) => {
    if (document.pointerLockElement !== canvas) return;
    state.yaw -= e.movementX * state.lookSpeed;
    state.pitch = Math.max(
      -Math.PI / 2 + 0.01,
      Math.min(Math.PI / 2 - 0.01, state.pitch - e.movementY * state.lookSpeed),
    );
  });

  document.addEventListener('keydown', (e) => state.keys.add(e.code));
  document.addEventListener('keyup', (e) => state.keys.delete(e.code));

  return state;
};

const updateFPSControls = (state: FPSControls, camera: import('three').PerspectiveCamera, delta: number) => {
  const forward = { x: -Math.sin(state.yaw), z: -Math.cos(state.yaw) };
  const right = { x: Math.cos(state.yaw), z: -Math.sin(state.yaw) };
  const speed = state.moveSpeed * delta;

  if (state.keys.has('KeyW')) {
    camera.position.x += forward.x * speed;
    camera.position.z += forward.z * speed;
  }
  if (state.keys.has('KeyS')) {
    camera.position.x -= forward.x * speed;
    camera.position.z -= forward.z * speed;
  }
  if (state.keys.has('KeyA')) {
    camera.position.x -= right.x * speed;
    camera.position.z -= right.z * speed;
  }
  if (state.keys.has('KeyD')) {
    camera.position.x += right.x * speed;
    camera.position.z += right.z * speed;
  }

  camera.rotation.set(state.pitch, state.yaw, 0, 'YXZ');
};

  • 程序化动画通过数学函数实时计算，适合循环运动和数据驱动的可视化
  • 缓动函数控制动画的速度曲线，弹性和回弹效果需要特殊缓动公式
  • AnimationMixer 支持动画混合和淡入淡出，可同时播放多个带权重的动画
  • OrbitControls 的阻尼和极角限制能提供流畅的用户体验
