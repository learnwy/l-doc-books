材质与光照

核心概念

材质（Material）定义了物体表面对光的响应方式。Three.js 提供了从简单到复杂的多级材质系统，核心是基于物理的渲染（PBR）材质。PBR 通过粗糙度（roughness）和金属度（metalness）两个参数模拟真实世界材料的光学特性。

光照与材质的交互遵循能量守恒原则：反射的光能不能超过入射光能。漫反射和镜面反射的比例由金属度控制——金属材料几乎没有漫反射，非金属材料以漫反射为主。

PBR 材质参数详解
MeshStandardMaterial 是最常用的 PBR 材质。粗糙度控制微表面的散射程度，金属度决定漫反射与镜面反射的比例。


import {
  MeshStandardMaterial,
  MeshPhysicalMaterial,
  TextureLoader,
  RepeatWrapping,
  SRGBColorSpace,
  LinearSRGBColorSpace,
  Vector2,
} from 'three';

const createPBRMaterial = (textures: {
  diffuse: string;
  normal: string;
  roughness: string;
  metalness: string;
  ao: string;
}) => {
  const loader = new TextureLoader();

  const diffuseMap = loader.load(textures.diffuse);
  diffuseMap.colorSpace = SRGBColorSpace;
  diffuseMap.wrapS = diffuseMap.wrapT = RepeatWrapping;

  const normalMap = loader.load(textures.normal);
  normalMap.colorSpace = LinearSRGBColorSpace;

  const roughnessMap = loader.load(textures.roughness);
  const metalnessMap = loader.load(textures.metalness);
  const aoMap = loader.load(textures.ao);

  return new MeshStandardMaterial({
    map: diffuseMap,
    normalMap: normalMap,
    normalScale: new Vector2(1, 1),
    roughnessMap: roughnessMap,
    roughness: 1.0,
    metalnessMap: metalnessMap,
    metalness: 1.0,
    aoMap: aoMap,
    aoMapIntensity: 1.0,
    envMapIntensity: 1.0,
  });
};
MeshPhysicalMaterial 扩展了标准 PBR，支持清漆（clearcoat）、次表面散射、折射和薄膜干涉等高级效果：


const createCarPaintMaterial = () => {
  return new MeshPhysicalMaterial({
    color: 0x0055ff,
    metalness: 0.9,
    roughness: 0.3,
    clearcoat: 1.0,
    clearcoatRoughness: 0.1,
    reflectivity: 1.0,
  });
};

const createGlassMaterial = () => {
  return new MeshPhysicalMaterial({
    color: 0xffffff,
    metalness: 0,
    roughness: 0,
    transmission: 0.95,
    thickness: 0.5,
    ior: 1.5,
    transparent: true,
  });
};

const createFabricMaterial = () => {
  return new MeshPhysicalMaterial({
    color: 0x884422,
    metalness: 0,
    roughness: 0.9,
    sheen: 0.8,
    sheenRoughness: 0.3,
    sheenColor: 0xffeedd,
  });
};
环境贴图与 IBL
基于图像的光照（Image-Based Lighting, IBL）使用 HDR 环境贴图作为光源，能产生极其逼真的反射和环境光效果。Three.js 通过 PMREMGenerator 预处理环境贴图。


import { PMREMGenerator, CubeTextureLoader, EquirectangularReflectionMapping } from 'three';
import { RGBELoader } from 'three/addons/loaders/RGBELoader.js';

const setupEnvironment = async (renderer: import('three').WebGLRenderer, scene: import('three').Scene) => {
  const pmremGenerator = new PMREMGenerator(renderer);
  pmremGenerator.compileEquirectangularShader();

  const rgbeLoader = new RGBELoader();
  const hdrTexture = await rgbeLoader.loadAsync('/envmaps/studio.hdr');
  hdrTexture.mapping = EquirectangularReflectionMapping;

  const envMap = pmremGenerator.fromEquirectangular(hdrTexture).texture;
  scene.environment = envMap;
  scene.background = envMap;

  hdrTexture.dispose();
  pmremGenerator.dispose();

  return envMap;
};
自定义 ShaderMaterial
当内置材质无法满足需求时，ShaderMaterial 允许编写自定义 GLSL 着色器。Three.js 会自动注入变换矩阵和常用 uniform。


import { ShaderMaterial, UniformsLib, UniformsUtils, Color } from 'three';

const createFresnelMaterial = () => {
  const uniforms = UniformsUtils.merge([
    UniformsLib.common,
    UniformsLib.lights,
    {
      u_fresnelColor: { value: new Color(0x00aaff) },
      u_fresnelPower: { value: 3.0 },
      u_time: { value: 0 },
    },
  ]);

  return new ShaderMaterial({
    uniforms,
    vertexShader: `
      varying vec3 vNormal;
      varying vec3 vViewDir;
      uniform float u_time;

      void main() {
        vNormal = normalize(normalMatrix * normal);
        vec4 mvPosition = modelViewMatrix * vec4(position, 1.0);
        vViewDir = normalize(-mvPosition.xyz);
        gl_Position = projectionMatrix * mvPosition;
      }
    `,
    fragmentShader: `
      uniform vec3 u_fresnelColor;
      uniform float u_fresnelPower;
      varying vec3 vNormal;
      varying vec3 vViewDir;

      void main() {
        float fresnel = pow(1.0 - dot(vNormal, vViewDir), u_fresnelPower);
        vec3 baseColor = vec3(0.1, 0.1, 0.15);
        vec3 color = mix(baseColor, u_fresnelColor, fresnel);
        gl_FragColor = vec4(color, 1.0);
      }
    `,
    lights: true,
  });
};
后处理效果管线
后处理（Post-Processing）在渲染完成后对整个画面应用图像效果。Three.js 的 EffectComposer 提供了可链式组合的效果管线。


import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { UnrealBloomPass } from 'three/addons/postprocessing/UnrealBloomPass.js';
import { SMAAPass } from 'three/addons/postprocessing/SMAAPass.js';
import { OutputPass } from 'three/addons/postprocessing/OutputPass.js';
import { Vector2 } from 'three';

const createPostProcessing = (
  renderer: import('three').WebGLRenderer,
  scene: import('three').Scene,
  camera: import('three').PerspectiveCamera,
) => {
  const composer = new EffectComposer(renderer);

  const renderPass = new RenderPass(scene, camera);
  composer.addPass(renderPass);

  const bloomPass = new UnrealBloomPass(new Vector2(window.innerWidth, window.innerHeight), 0.5, 0.4, 0.85);
  composer.addPass(bloomPass);

  const smaaPass = new SMAAPass(
    window.innerWidth * renderer.getPixelRatio(),
    window.innerHeight * renderer.getPixelRatio(),
  );
  composer.addPass(smaaPass);

  const outputPass = new OutputPass();
  composer.addPass(outputPass);

  return {
    composer,
    render: () => composer.render(),
    resize: (w: number, h: number) => composer.setSize(w, h),
  };
};
小结
    

  • PBR 材质通过粗糙度和金属度模拟真实材料光学特性，遵循能量守恒
    • 

  • MeshPhysicalMaterial 支持清漆、透射、光泽等高级效果，适合汽车、玻璃渲染
    • 

  • IBL 使用 HDR 环境贴图提供逼真的全局照明，PMREMGenerator 负责预处理
    • 

  • ShaderMaterial 允许自定义 GLSL 着色器，Three.js 自动注入变换矩阵
    • 

  • 后处理管线通过 EffectComposer 链式组合辉光、抗锯齿等全屏效果
