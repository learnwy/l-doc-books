Three.js 性能优化

核心概念

Three.js 性能优化的核心在于减少 GPU 和 CPU 的工作量。GPU 瓶颈主要来自过多的绘制调用（Draw Calls）、复杂的着色器和大尺寸纹理；CPU 瓶颈则来自场景遍历、矩阵计算和 JavaScript 垃圾回收。性能优化需要从渲染管线的各个环节入手。

实例化渲染
当场景中有大量相同几何体（如树木、草地、建筑窗户）时，InstancedMesh 可以用一次 Draw Call 绘制所有实例，性能提升可达数十倍。


import { InstancedMesh, BoxGeometry, MeshStandardMaterial, Matrix4, Color, DynamicDrawUsage } from 'three';

interface InstancedObjects {
  mesh: InstancedMesh;
  matrices: Matrix4[];
  colors: Color[];
}

const createInstancedForest = (count: number): InstancedObjects => {
  const geometry = new BoxGeometry(0.2, 1, 0.2);
  const material = new MeshStandardMaterial();

  const mesh = new InstancedMesh(geometry, material, count);
  mesh.instanceMatrix.setUsage(DynamicDrawUsage);
  mesh.castShadow = true;

  const matrices: Matrix4[] = [];
  const colors: Color[] = [];
  const tempMatrix = new Matrix4();
  const tempColor = new Color();

  for (let i = 0; i < count; i++) {
    const x = (Math.random() - 0.5) * 100;
    const z = (Math.random() - 0.5) * 100;
    const scale = 0.5 + Math.random() * 1.5;
    const rotation = Math.random() * Math.PI * 2;

    tempMatrix.makeRotationY(rotation);
    tempMatrix.setPosition(x, scale / 2, z);
    tempMatrix.scale({ x: 1, y: scale, z: 1 } as import('three').Vector3);

    mesh.setMatrixAt(i, tempMatrix);
    matrices.push(tempMatrix.clone());

    tempColor.setHSL(0.25 + Math.random() * 0.1, 0.6, 0.3 + Math.random() * 0.2);
    mesh.setColorAt(i, tempColor);
    colors.push(tempColor.clone());
  }

  mesh.instanceMatrix.needsUpdate = true;
  if (mesh.instanceColor) mesh.instanceColor.needsUpdate = true;

  return { mesh, matrices, colors };
};
动态更新实例化数据（如动画实例）需要标记 needsUpdate：


const animateInstances = (instances: InstancedObjects, time: number) => {
  const tempMatrix = new Matrix4();
  const count = instances.matrices.length;

  for (let i = 0; i < count; i++) {
    const base = instances.matrices[i];
    const swayAngle = Math.sin(time * 2 + i * 0.1) * 0.05;
    tempMatrix.copy(base);
    tempMatrix.multiply(new Matrix4().makeRotationZ(swayAngle));
    instances.mesh.setMatrixAt(i, tempMatrix);
  }

  instances.mesh.instanceMatrix.needsUpdate = true;
};
LOD 与几何体优化
LOD（Level of Detail）根据物体与相机的距离切换不同精度的模型，远处使用低面数模型节省渲染开销。


import { LOD, Mesh, SphereGeometry, MeshStandardMaterial } from 'three';

const createLODObject = (): LOD => {
  const lod = new LOD();
  const material = new MeshStandardMaterial({ color: 0x44aa88 });

  const highDetail = new Mesh(new SphereGeometry(1, 64, 64), material);
  lod.addLevel(highDetail, 0);

  const mediumDetail = new Mesh(new SphereGeometry(1, 16, 16), material);
  lod.addLevel(mediumDetail, 20);

  const lowDetail = new Mesh(new SphereGeometry(1, 8, 8), material);
  lod.addLevel(lowDetail, 50);

  return lod;
};
几何体合并（Merge）将多个共享材质的静态物体合并为一个，大幅减少 Draw Call：


import { BufferGeometryUtils } from 'three/addons/utils/BufferGeometryUtils.js';
import { BufferGeometry, Mesh, MeshStandardMaterial, Matrix4 } from 'three';

const mergeStaticGeometries = (meshes: Mesh[]): Mesh => {
  const geometries: BufferGeometry[] = [];

  for (const mesh of meshes) {
    const geom = mesh.geometry.clone();
    geom.applyMatrix4(mesh.matrixWorld);
    geometries.push(geom);
  }

  const merged = BufferGeometryUtils.mergeGeometries(geometries);
  const material = meshes[0].material as MeshStandardMaterial;

  for (const geom of geometries) {
    geom.dispose();
  }

  return new Mesh(merged, material);
};
内存管理与对象池
WebGL 应用中内存泄漏是常见问题。Three.js 的 GPU 资源必须手动释放，JavaScript 的垃圾回收器无法回收 GPU 内存。


interface ObjectPool<T> {
  pool: T[];
  active: Set<T>;
  factory: () => T;
  reset: (item: T) => void;
}

const createObjectPool = <T>(factory: () => T, reset: (item: T) => void, initialSize: number): ObjectPool<T> => {
  const pool: T[] = [];
  for (let i = 0; i < initialSize; i++) {
    pool.push(factory());
  }
  return { pool, active: new Set(), factory, reset };
};

const acquire = <T>(pool: ObjectPool<T>): T => {
  const item = pool.pool.pop() ?? pool.factory();
  pool.active.add(item);
  return item;
};

const release = <T>(pool: ObjectPool<T>, item: T) => {
  pool.active.delete(item);
  pool.reset(item);
  pool.pool.push(item);
};
资源跟踪器确保所有创建的 GPU 资源都被正确释放：


import { Texture, Material, BufferGeometry } from 'three';

type Disposable = Texture | Material | BufferGeometry;

const createResourceTracker = () => {
  const resources = new Set<Disposable>();

  const track = <T extends Disposable>(resource: T): T => {
    resources.add(resource);
    return resource;
  };

  const dispose = () => {
    for (const resource of resources) {
      resource.dispose();
    }
    resources.clear();
  };

  return { track, dispose, count: () => resources.size };
};
渲染性能监控
性能监控是优化的基础。Three.js 的 renderer.info 提供实时渲染统计数据。


interface PerformanceMetrics {
  fps: number;
  frameTime: number;
  drawCalls: number;
  triangles: number;
  textures: number;
  geometries: number;
  programs: number;
}

const createPerformanceMonitor = (renderer: import('three').WebGLRenderer) => {
  let frameCount = 0;
  let lastTime = performance.now();
  let metrics: PerformanceMetrics = {
    fps: 0,
    frameTime: 0,
    drawCalls: 0,
    triangles: 0,
    textures: 0,
    geometries: 0,
    programs: 0,
  };

  const update = () => {
    frameCount++;
    const now = performance.now();
    const elapsed = now - lastTime;

    if (elapsed >= 1000) {
      const info = renderer.info;
      metrics = {
        fps: Math.round((frameCount * 1000) / elapsed),
        frameTime: elapsed / frameCount,
        drawCalls: info.render.calls,
        triangles: info.render.triangles,
        textures: info.memory.textures,
        geometries: info.memory.geometries,
        programs: info.programs?.length ?? 0,
      };

      frameCount = 0;
      lastTime = now;
    }

    return metrics;
  };

  return { update, getMetrics: () => metrics };
};
小结
    

  • 实例化渲染可将上万个相同物体压缩到一次 Draw Call，性能提升数十倍
    • 

  • LOD 系统根据相机距离切换模型精度，减少远距离物体的顶点处理量
    • 

  • 几何体合并适用于共享材质的静态场景，需在灵活性和性能间权衡
    • 

  • GPU 资源必须手动释放，对象池减少高频创建/销毁带来的 GC 压力
    • 

  • renderer.info 提供实时统计，是性能调优的第一工具
