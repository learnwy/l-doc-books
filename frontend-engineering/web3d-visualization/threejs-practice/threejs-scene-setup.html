场景搭建与基础对象

核心概念

Three.js 是最流行的 WebGL 封装库，提供了场景图（Scene Graph）、相机、渲染器、几何体、材质、光源等高层抽象，极大降低了 3D 开发门槛。Three.js 的核心架构围绕三个要素展开：场景（Scene）、相机（Camera）和渲染器（Renderer）。

场景是所有 3D 对象的容器，采用树形结构组织。每个对象（Object3D）都有位置、旋转和缩放属性，子对象的变换相对于父对象。

渲染器配置与场景初始化
渲染器是连接 Three.js 场景与 HTML Canvas 的桥梁。正确的初始化配置对渲染质量和性能至关重要。


import {
  Scene,
  PerspectiveCamera,
  WebGLRenderer,
  ACESFilmicToneMapping,
  SRGBColorSpace,
  PCFSoftShadowMap,
  Color,
} from 'three';

interface AppConfig {
  container: HTMLElement;
  antialias: boolean;
  pixelRatio: number;
}

const createApp = (config: AppConfig) => {
  const scene = new Scene();
  scene.background = new Color(0x1a1a2e);

  const camera = new PerspectiveCamera(60, config.container.clientWidth / config.container.clientHeight, 0.1, 1000);
  camera.position.set(5, 5, 5);
  camera.lookAt(0, 0, 0);

  const renderer = new WebGLRenderer({
    antialias: config.antialias,
    powerPreference: 'high-performance',
  });
  renderer.setSize(config.container.clientWidth, config.container.clientHeight);
  renderer.setPixelRatio(Math.min(config.pixelRatio, 2));
  renderer.toneMapping = ACESFilmicToneMapping;
  renderer.toneMappingExposure = 1.0;
  renderer.outputColorSpace = SRGBColorSpace;
  renderer.shadowMap.enabled = true;
  renderer.shadowMap.type = PCFSoftShadowMap;

  config.container.appendChild(renderer.domElement);

  const handleResize = () => {
    const w = config.container.clientWidth;
    const h = config.container.clientHeight;
    camera.aspect = w / h;
    camera.updateProjectionMatrix();
    renderer.setSize(w, h);
  };

  const observer = new ResizeObserver(handleResize);
  observer.observe(config.container);

  return { scene, camera, renderer, dispose: () => observer.disconnect() };
};
色调映射（Tone Mapping）将 HDR 颜色映射到显示器可显示的范围。ACESFilmicToneMapping 是电影级别的色调曲线，提供更自然的高光和阴影过渡。输出颜色空间设置为 SRGBColorSpace 确保颜色在显示器上正确显示。


几何体与网格系统
Three.js 内置了丰富的几何体类型。BufferGeometry 是所有几何体的基类，直接操作 GPU 缓冲区数据。


import {
  BoxGeometry,
  SphereGeometry,
  PlaneGeometry,
  BufferGeometry,
  BufferAttribute,
  Mesh,
  MeshStandardMaterial,
  DoubleSide,
  Group,
} from 'three';

const createPrimitives = (): Group => {
  const group = new Group();

  const floorGeom = new PlaneGeometry(20, 20);
  const floorMat = new MeshStandardMaterial({
    color: 0x808080,
    roughness: 0.8,
    side: DoubleSide,
  });
  const floor = new Mesh(floorGeom, floorMat);
  floor.rotation.x = -Math.PI / 2;
  floor.receiveShadow = true;
  group.add(floor);

  const boxGeom = new BoxGeometry(1, 1, 1);
  const boxMat = new MeshStandardMaterial({ color: 0x4488ff, roughness: 0.4, metalness: 0.6 });
  const box = new Mesh(boxGeom, boxMat);
  box.position.set(-2, 0.5, 0);
  box.castShadow = true;
  group.add(box);

  const sphereGeom = new SphereGeometry(0.6, 32, 32);
  const sphereMat = new MeshStandardMaterial({ color: 0xff4444, roughness: 0.2, metalness: 0.8 });
  const sphere = new Mesh(sphereGeom, sphereMat);
  sphere.position.set(2, 0.6, 0);
  sphere.castShadow = true;
  group.add(sphere);

  return group;
};
自定义几何体通过 BufferAttribute 直接设置顶点数据：


const createCustomGeometry = (): BufferGeometry => {
  const geometry = new BufferGeometry();

  const positions = new Float32Array([0, 2, 0, -1, 0, 1, 1, 0, 1, 1, 0, -1, -1, 0, -1]);

  const indices = new Uint16Array([0, 1, 2, 0, 2, 3, 0, 3, 4, 0, 4, 1, 1, 3, 2, 1, 4, 3]);

  geometry.setAttribute('position', new BufferAttribute(positions, 3));
  geometry.setIndex(new BufferAttribute(indices, 1));
  geometry.computeVertexNormals();

  return geometry;
};
光照系统配置
Three.js 提供多种光源类型，每种光源有不同的照射范围和性能开销。实时阴影是最消耗性能的特性之一，需要谨慎配置。


import { DirectionalLight, AmbientLight, PointLight, SpotLight, HemisphereLight, CameraHelper } from 'three';

const setupLighting = (scene: Scene) => {
  const ambient = new AmbientLight(0x404040, 0.5);
  scene.add(ambient);

  const hemisphere = new HemisphereLight(0x87ceeb, 0x362d1b, 0.3);
  scene.add(hemisphere);

  const directional = new DirectionalLight(0xffffff, 1.5);
  directional.position.set(5, 10, 5);
  directional.castShadow = true;
  directional.shadow.mapSize.width = 2048;
  directional.shadow.mapSize.height = 2048;
  directional.shadow.camera.near = 0.5;
  directional.shadow.camera.far = 50;
  directional.shadow.camera.left = -10;
  directional.shadow.camera.right = 10;
  directional.shadow.camera.top = 10;
  directional.shadow.camera.bottom = -10;
  directional.shadow.bias = -0.0001;
  scene.add(directional);

  const point = new PointLight(0xff6600, 2, 10, 2);
  point.position.set(-3, 3, -3);
  point.castShadow = true;
  point.shadow.mapSize.set(1024, 1024);
  scene.add(point);

  return { ambient, hemisphere, directional, point };
};
资源加载与生命周期
Three.js 使用加载器（Loader）异步加载外部资源。GLTFLoader 是最常用的模型加载器，支持 glTF 2.0 格式。资源管理和内存释放在单页应用中尤为重要。


import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import { DRACOLoader } from 'three/addons/loaders/DRACOLoader.js';
import { TextureLoader, LoadingManager } from 'three';

const createLoaderSystem = () => {
  const manager = new LoadingManager();
  const progress = { loaded: 0, total: 0 };

  manager.onProgress = (url, loaded, total) => {
    progress.loaded = loaded;
    progress.total = total;
  };

  const dracoLoader = new DRACOLoader(manager);
  dracoLoader.setDecoderPath('/draco/');

  const gltfLoader = new GLTFLoader(manager);
  gltfLoader.setDRACOLoader(dracoLoader);

  const textureLoader = new TextureLoader(manager);

  const loadModel = async (url: string) => {
    const gltf = await gltfLoader.loadAsync(url);
    gltf.scene.traverse((child) => {
      if ((child as Mesh).isMesh) {
        const mesh = child as Mesh;
        mesh.castShadow = true;
        mesh.receiveShadow = true;
      }
    });
    return gltf;
  };

  return { loadModel, textureLoader, progress };
};

type Mesh = import('three').Mesh;

const disposeScene = (scene: Scene) => {
  scene.traverse((object) => {
    if ((object as Mesh).isMesh) {
      const mesh = object as Mesh;
      mesh.geometry.dispose();
      if (Array.isArray(mesh.material)) {
        mesh.material.forEach((m) => m.dispose());
      } else {
        mesh.material.dispose();
      }
    }
  });

  scene.clear();
};
小结
    

  • Three.js 通过场景图组织 3D 对象，子对象继承父对象的变换
    • 

  • 渲染器配置需关注色调映射、像素比限制和阴影类型
    • 

  • 几何体使用 BufferGeometry 直接操作 GPU 缓冲区，自定义几何体需计算法线
    • 

  • 光照系统中环境光提供基础亮度，平行光驱动主阴影，阴影贴图大小直接影响质量
    • 

  • 资源加载使用 LoadingManager 统一管理进度，组件卸载时必须调用 dispose 释放 GPU 内存
