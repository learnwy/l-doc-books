SVG 与 Canvas 对比选型

核心概念

SVG 和 Canvas 是 Web 平台上两种根本不同的图形渲染技术。SVG 基于 XML 的矢量图形标准，每个图形元素都是 DOM 节点，支持 CSS 样式和事件绑定；Canvas 提供像素级的 2D 绘图 API，通过 JavaScript 命令式绘制位图。在数据可视化领域，两者各有优势，选型决策直接影响项目的性能、交互能力和维护成本。

理解这两种技术的渲染模型差异是正确选型的关键：SVG 是保留模式（retained mode），浏览器维护一棵图形元素树，开发者修改树的属性即可更新画面；Canvas 是即时模式（immediate mode），每一帧都从头绘制所有内容，浏览器不记忆之前画了什么。


SVG 的优势场景
SVG 在以下场景中具有不可替代的优势：


交互密集型可视化：每个 SVG 元素自带 DOM 事件，无需自己实现命中检测。


const createInteractiveSVG = (container: HTMLElement): void => {
  const svg = document.createElementNS('http://www.w3.org/2000/svg', 'svg');
  svg.setAttribute('viewBox', '0 0 800 400');

  const rect = document.createElementNS('http://www.w3.org/2000/svg', 'rect');
  rect.setAttribute('x', '100');
  rect.setAttribute('y', '50');
  rect.setAttribute('width', '200');
  rect.setAttribute('height', '100');
  rect.classList.add('interactive-bar');

  rect.addEventListener('mouseenter', (e) => {
    const target = e.currentTarget as SVGRectElement;
    target.style.opacity = '0.8';
  });

  rect.addEventListener('click', () => {
    showTooltip(rect.dataset);
  });

  svg.appendChild(rect);
  container.appendChild(svg);
};
高保真输出：SVG 作为矢量格式，在任意缩放比例下保持清晰，适合报告打印和 PDF 导出。


CSS 集成：SVG 元素支持完整的 CSS 选择器、伪类和动画。


const svgStyles = `

Canvas 的优势场景
Canvas 在高性能渲染场景中具有压倒性优势：


interface Particle {
  x: number;
  y: number;
  vx: number;
  vy: number;
  radius: number;
}

const renderParticles = (ctx: CanvasRenderingContext2D, particles: Particle[]): void => {
  ctx.clearRect(0, 0, ctx.canvas.width, ctx.canvas.height);

  ctx.fillStyle = 'rgba(70, 130, 180, 0.6)';
  ctx.beginPath();
  for (const p of particles) {
    ctx.moveTo(p.x + p.radius, p.y);
    ctx.arc(p.x, p.y, p.radius, 0, Math.PI * 2);
  }
  ctx.fill();
};

const animateParticles = (ctx: CanvasRenderingContext2D, particles: Particle[]): void => {
  const update = () => {
    for (const p of particles) {
      p.x += p.vx;
      p.y += p.vy;
      if (p.x < 0 || p.x > ctx.canvas.width) p.vx *= -1;
      if (p.y < 0 || p.y > ctx.canvas.height) p.vy *= -1;
    }
    renderParticles(ctx, particles);
    requestAnimationFrame(update);
  };
  update();
};
Canvas 的核心优势在于批量渲染——将成千上万个图形合并为单次绘制调用，避免了 SVG 中每个元素对应一个 DOM 节点带来的内存和渲染开销。


混合渲染策略
在实际项目中，往往不需要在 SVG 和 Canvas 之间做非此即彼的选择。混合渲染策略将两者的优势结合起来。

interface RenderStrategyConfig {
  svgThreshold: number;
  canvasThreshold: number;
  enableMixedMode: boolean;
}

const selectRenderer = (dataCount: number, config: RenderStrategyConfig): 'svg' | 'canvas' | 'mixed' => {
  if (dataCount <= config.svgThreshold) return 'svg';
  if (dataCount >= config.canvasThreshold) return 'canvas';
  return config.enableMixedMode ? 'mixed' : 'canvas';
};

小结
    

  • SVG 和 Canvas 的本质区别在于保留模式 vs 即时模式
    • 

  • SVG 适合交互密集、元素较少、需要矢量输出的场景
    • 

  • Canvas 适合大数据量、高帧率动画、像素操作的场景
    • 

  • 混合渲染策略将两者优势结合，是复杂可视化项目的最佳实践
    • 

  • 选型应基于图形元素数量、交互需求和输出格式等因素综合决策
    • 

  • 当不确定时，从 SVG 开始，性能不足时再迁移到 Canvas
