ECharts 实践

核心概念

ECharts 是百度开源的企业级数据可视化库，以声明式配置和开箱即用的丰富图表类型著称。它使用 Canvas 作为默认渲染引擎（也支持 SVG），在大数据量场景下具有优秀的渲染性能。ECharts 是国内前端开发中使用最广泛的可视化工具，覆盖了从基础折线图到复杂地理信息可视化的全部场景。

ECharts 的核心设计理念是"配置即图表"——通过一个 JSON 结构的 Option 对象完整描述图表的每一个方面，从数据、样式到交互行为。


Option 配置体系
ECharts 的 Option 是一个层次化的配置对象，每个属性控制图表的一个方面。


import * as echarts from 'echarts';

interface SalesData {
  month: string;
  revenue: number;
  orders: number;
}

const createSalesChart = (container: HTMLElement, data: SalesData[]): echarts.ECharts => {
  const chart = echarts.init(container);

  const option: echarts.EChartsOption = {
    title: {
      text: '月度销售数据',
      left: 'center',
    },
    tooltip: {
      trigger: 'axis',
      axisPointer: { type: 'cross' },
    },
    legend: {
      data: ['营收', '订单量'],
      bottom: 10,
    },
    xAxis: {
      type: 'category',
      data: data.map((d) => d.month),
    },
    yAxis: [
      { type: 'value', name: '营收（万元）', position: 'left' },
      { type: 'value', name: '订单量', position: 'right' },
    ],
    series: [
      {
        name: '营收',
        type: 'bar',
        data: data.map((d) => d.revenue),
        yAxisIndex: 0,
      },
      {
        name: '订单量',
        type: 'line',
        data: data.map((d) => d.orders),
        yAxisIndex: 1,
        smooth: true,
      },
    ],
  };

  chart.setOption(option);
  return chart;
};

Dataset 数据集模式
ECharts 4+ 引入的 Dataset 模式将数据管理从 Series 中分离出来，实现数据与视觉映射的解耦。


const createDatasetChart = (container: HTMLElement): echarts.ECharts => {
  const chart = echarts.init(container);

  const option: echarts.EChartsOption = {
    dataset: {
      source: [
        ['产品', 'Q1', 'Q2', 'Q3', 'Q4'],
        ['前端框架', 120, 150, 180, 210],
        ['后端服务', 80, 95, 110, 130],
        ['移动端', 60, 75, 90, 105],
        ['基础设施', 40, 50, 65, 80],
      ],
    },
    xAxis: { type: 'category' },
    yAxis: {},
    series: [{ type: 'bar' }, { type: 'bar' }, { type: 'bar' }, { type: 'bar' }],
  };

  chart.setOption(option);
  return chart;
};
Dataset 模式的优势在于：一份数据可以驱动多个 Series，修改数据源自动更新所有关联图表；支持数据转换（filter、sort）实现数据流水线。


性能优化与大数据渲染
当数据量达到万级以上时，ECharts 的性能优化策略至关重要。


const createLargeDataChart = (container: HTMLElement, data: [number, number][]): echarts.ECharts => {
  const chart = echarts.init(container, undefined, {
    renderer: 'canvas',
  });

  const option: echarts.EChartsOption = {
    animation: false,
    tooltip: {
      trigger: 'none',
    },
    xAxis: {
      type: 'value',
      min: 'dataMin',
      max: 'dataMax',
    },
    yAxis: {
      type: 'value',
    },
    dataZoom: [
      { type: 'inside', xAxisIndex: 0 },
      { type: 'slider', xAxisIndex: 0, bottom: 10 },
    ],
    series: [
      {
        type: 'scatter',
        data: data,
        large: true,
        largeThreshold: 2000,
        symbolSize: 2,
        progressive: 5000,
        progressiveThreshold: 10000,
      },
    ],
  };

  chart.setOption(option);
  return chart;
};

React 中的 ECharts 集成
在 React 项目中集成 ECharts 需要处理组件生命周期、尺寸变化和数据更新。


import { useEffect, useRef } from 'react';
import * as echarts from 'echarts';

interface UseEChartsOptions {
  option: echarts.EChartsOption;
  theme?: string;
  renderer?: 'canvas' | 'svg';
}

const useECharts = ({ option, theme, renderer = 'canvas' }: UseEChartsOptions) => {
  const chartRef = useRef<HTMLDivElement>(null);
  const instanceRef = useRef<echarts.ECharts | null>(null);

  useEffect(() => {
    if (!chartRef.current) return;

    instanceRef.current = echarts.init(chartRef.current, theme, { renderer });

    const resizeObserver = new ResizeObserver(() => {
      instanceRef.current?.resize();
    });
    resizeObserver.observe(chartRef.current);

    return () => {
      resizeObserver.disconnect();
      instanceRef.current?.dispose();
      instanceRef.current = null;
    };
  }, [theme, renderer]);

  useEffect(() => {
    instanceRef.current?.setOption(option, { notMerge: false });
  }, [option]);

  return { chartRef, instance: instanceRef };
};
小结
    

  • ECharts 以声明式 Option 配置为核心，实现"配置即图表"
    • 

  • Dataset 模式将数据与视觉映射解耦，支持一份数据驱动多个 Series
    • 

  • 大数据场景需要组合使用 large 模式、渐进渲染和降采样策略
    • 

  • React 集成需要处理初始化、尺寸响应、数据更新和实例销毁四个关键环节
    • 

  • ECharts 适合需要快速搭建、类型丰富的商业可视化场景
    • 

  • 对于高度定制化需求，建议转向 D3.js 或 AntV G2
