D3.js 基础与数据绑定

核心概念

D3.js（Data-Driven Documents）是 Web 数据可视化领域最强大的底层库，它通过将数据绑定到 DOM 元素上，实现数据驱动的文档变换。与 ECharts 等封装库不同，D3 不提供现成的图表组件，而是提供了一套完整的数据操作和可视化原语，赋予开发者对每一个视觉元素的完全控制权。

D3 的核心理念是"数据绑定"——将数据数组的每个元素对应到一个 DOM 元素（通常是 SVG 元素），当数据变化时，DOM 自动同步更新。


Selection 与数据绑定机制
D3 的 Selection API 是整个库的基础。它借鉴了 jQuery 的链式调用风格，但增加了数据绑定的能力。


const bindData = (container: d3.Selection<SVGGElement, unknown, null, undefined>, data: number[]): void => {
  const bars = container.selectAll<SVGRectElement, number>('rect').data(data, (d, i) => `bar-${i}`);

  bars
    .enter()
    .append('rect')
    .attr('x', (_, i) => i * 40)
    .attr('y', (d) => 300 - d)
    .attr('width', 35)
    .attr('height', (d) => d)
    .attr('fill', 'steelblue');

  bars
    .transition()
    .duration(750)
    .attr('y', (d) => 300 - d)
    .attr('height', (d) => d);

  bars.exit().transition().duration(300).attr('height', 0).remove();
};

比例尺与坐标系统
比例尺（Scale）是 D3 中将数据域映射到视觉通道的核心工具。它建立了数据值和像素位置、颜色、大小之间的映射关系。


const width = 800;
const height = 400;
const margin = { top: 20, right: 30, bottom: 40, left: 50 };

const xScale = d3
  .scaleTime()
  .domain([new Date('2024-01-01'), new Date('2024-12-31')])
  .range([margin.left, width - margin.right]);

const yScale = d3
  .scaleLinear()
  .domain([0, d3.max(data, (d) => d.value) ?? 100])
  .range([height - margin.bottom, margin.top])
  .nice();

const colorScale = d3.scaleOrdinal<string>().domain(['frontend', 'backend', 'devops']).range(d3.schemeCategory10);

const radiusScale = d3
  .scaleSqrt()
  .domain([0, d3.max(data, (d) => d.count) ?? 1000])
  .range([2, 20]);

交互与过渡动画
D3 的交互和动画系统让静态图表变为动态可探索的数据体验。


const createInteractiveChart = (
  svg: d3.Selection<SVGSVGElement, unknown, null, undefined>,
  data: DataPoint[],
): void => {
  const tooltip = d3.select('body').append('div').attr('class', 'tooltip').style('opacity', 0);

  svg
    .selectAll<SVGCircleElement, DataPoint>('circle')
    .data(data)
    .join('circle')
    .attr('cx', (d) => xScale(d.x))
    .attr('cy', (d) => yScale(d.y))
    .attr('r', 0)
    .on('mouseenter', (event, d) => {
      d3.select(event.currentTarget).transition().duration(200).attr('r', 8);

      tooltip.transition().duration(200).style('opacity', 0.9);
      tooltip
        .html(`${d.label}: ${d.value}`)
        .style('left', `${event.pageX + 10}px`)
        .style('top', `${event.pageY - 28}px`);
    })
    .on('mouseleave', (event) => {
      d3.select(event.currentTarget).transition().duration(200).attr('r', 5);

      tooltip.transition().duration(500).style('opacity', 0);
    })
    .transition()
    .duration(800)
    .delay((_, i) => i * 50)
    .attr('r', 5);
};
D3 的过渡动画基于插值器（Interpolator），支持数值、颜色、路径等多种数据类型的平滑过渡。.join() 方法是 D3 v5+ 引入的简化 Enter-Update-Exit 模式的 API，在大多数场景下可以替代手动的 .enter()/.exit() 调用。

interface TreeNode {
  name: string;
  value?: number;
  children?: TreeNode[];
}

const renderTreemap = (
  container: d3.Selection<SVGGElement, unknown, null, undefined>,
  data: TreeNode,
  width: number,
  height: number,
): void => {
  const root = d3
    .hierarchy(data)
    .sum((d) => d.value ?? 0)
    .sort((a, b) => (b.value ?? 0) - (a.value ?? 0));

  d3.treemap<TreeNode>().size([width, height]).padding(2)(root);

  container
    .selectAll('rect')
    .data(root.leaves())
    .join('rect')
    .attr('x', (d) => d.x0)
    .attr('y', (d) => d.y0)
    .attr('width', (d) => d.x1 - d.x0)
    .attr('height', (d) => d.y1 - d.y0)
    .attr('fill', (d) => colorScale(d.parent?.data.name ?? ''));
};
小结
    

  • D3.js 是数据可视化的底层基石，提供数据操作和可视化原语而非现成图表
    • 

  • Enter-Update-Exit 模式是 D3 数据绑定的核心，.join() 是其简化 API
    • 

  • 比例尺建立数据域到视觉通道的映射，是构建图表的基础设施
    • 

  • 交互和过渡动画让图表从静态展示变为动态数据探索工具
    • 

  • 内置布局算法（层级、力导向、堆叠等）处理复杂数据结构的可视化定位
    • 

  • D3 适合需要高度定制的可视化场景，简单图表推荐使用 ECharts 等封装库
