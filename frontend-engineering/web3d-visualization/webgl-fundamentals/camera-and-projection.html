相机与投影

核心概念

在 3D 图形渲染中，相机定义了观察者的视角，投影决定了 3D 场景如何映射到 2D 屏幕上。WebGL 中没有内置的相机对象，需要通过矩阵运算模拟相机行为。整个变换链为：模型空间 → 世界空间 → 观察空间 → 裁剪空间 → NDC → 屏幕空间。

视图矩阵与 LookAt
视图矩阵是相机世界变换的逆矩阵。最常用的构造方式是 lookAt 函数，通过指定相机位置（eye）、目标点（target）和上方向（up）来确定观察方向。


type Vec3 = [number, number, number];

const lookAt = (eye: Vec3, target: Vec3, up: Vec3): Float32Array => {
  const zAxis = normalize(subtract(eye, target));
  const xAxis = normalize(cross(up, zAxis));
  const yAxis = cross(zAxis, xAxis);

  return new Float32Array([
    xAxis[0],
    yAxis[0],
    zAxis[0],
    0,
    xAxis[1],
    yAxis[1],
    zAxis[1],
    0,
    xAxis[2],
    yAxis[2],
    zAxis[2],
    0,
    -dot(xAxis, eye),
    -dot(yAxis, eye),
    -dot(zAxis, eye),
    1,
  ]);
};

const subtract = (a: Vec3, b: Vec3): Vec3 => [a[0] - b[0], a[1] - b[1], a[2] - b[2]];

const cross = (a: Vec3, b: Vec3): Vec3 => [
  a[1] * b[2] - a[2] * b[1],
  a[2] * b[0] - a[0] * b[2],
  a[0] * b[1] - a[1] * b[0],
];

const dot = (a: Vec3, b: Vec3): number => a[0] * b[0] + a[1] * b[1] + a[2] * b[2];

const normalize = (v: Vec3): Vec3 => {
  const len = Math.sqrt(v[0] * v[0] + v[1] * v[1] + v[2] * v[2]);
  return len > 0 ? [v[0] / len, v[1] / len, v[2] / len] : [0, 0, 0];
};
视图矩阵本质上将整个世界"移动和旋转"到相机前方。相机右向量构成 X 轴，上向量构成 Y 轴，观察方向的反方向构成 Z 轴，平移分量确保原点在相机位置。


透视投影与正交投影
透视投影产生近大远小的效果，最接近人眼视觉。FOV（Field of View）控制视野角度，aspect 比例匹配 Canvas 宽高比：


const perspective = (fovRadians: number, aspect: number, near: number, far: number): Float32Array => {
  const f = 1.0 / Math.tan(fovRadians / 2);
  const rangeInv = 1 / (near - far);

  return new Float32Array([
    f / aspect,
    0,
    0,
    0,
    0,
    f,
    0,
    0,
    0,
    0,
    (near + far) * rangeInv,
    -1,
    0,
    0,
    near * far * rangeInv * 2,
    0,
  ]);
};

const orthographic = (
  left: number,
  right: number,
  bottom: number,
  top: number,
  near: number,
  far: number,
): Float32Array => {
  const lr = 1 / (left - right);
  const bt = 1 / (bottom - top);
  const nf = 1 / (near - far);

  return new Float32Array([
    -2 * lr,
    0,
    0,
    0,
    0,
    -2 * bt,
    0,
    0,
    0,
    0,
    2 * nf,
    0,
    (left + right) * lr,
    (top + bottom) * bt,
    (near + far) * nf,
    1,
  ]);
};
深度精度是透视投影的常见问题。由于深度值在近平面附近高度非线性，远处物体的深度精度极低。反向深度缓冲（Reversed-Z）可以显著改善：


const reversedPerspective = (fovRadians: number, aspect: number, near: number): Float32Array => {
  const f = 1.0 / Math.tan(fovRadians / 2);
  return new Float32Array([f / aspect, 0, 0, 0, 0, f, 0, 0, 0, 0, 0, -1, 0, 0, near, 0]);
};
轨道相机控制器
轨道相机（Orbit Camera）围绕目标点旋转，适合产品展示和模型查看。通过球坐标系（theta, phi, radius）控制位置：


interface OrbitCamera {
  target: Vec3;
  theta: number;
  phi: number;
  radius: number;
  minRadius: number;
  maxRadius: number;
  minPhi: number;
  maxPhi: number;
}

const createOrbitCamera = (): OrbitCamera => ({
  target: [0, 0, 0],
  theta: 0,
  phi: Math.PI / 4,
  radius: 5,
  minRadius: 1,
  maxRadius: 50,
  minPhi: 0.01,
  maxPhi: Math.PI - 0.01,
});

const getOrbitViewMatrix = (camera: OrbitCamera): Float32Array => {
  const x = camera.radius * Math.sin(camera.phi) * Math.cos(camera.theta);
  const y = camera.radius * Math.cos(camera.phi);
  const z = camera.radius * Math.sin(camera.phi) * Math.sin(camera.theta);

  const eye: Vec3 = [camera.target[0] + x, camera.target[1] + y, camera.target[2] + z];

  return lookAt(eye, camera.target, [0, 1, 0]);
};

const handleOrbitInput = (camera: OrbitCamera, canvas: HTMLCanvasElement) => {
  let isDragging = false;
  let lastX = 0;
  let lastY = 0;

  canvas.addEventListener('pointerdown', (e) => {
    isDragging = true;
    lastX = e.clientX;
    lastY = e.clientY;
    canvas.setPointerCapture(e.pointerId);
  });

  canvas.addEventListener('pointermove', (e) => {
    if (!isDragging) return;
    const dx = e.clientX - lastX;
    const dy = e.clientY - lastY;
    lastX = e.clientX;
    lastY = e.clientY;

    camera.theta -= dx * 0.005;
    camera.phi = Math.max(camera.minPhi, Math.min(camera.maxPhi, camera.phi - dy * 0.005));
  });

  canvas.addEventListener('pointerup', () => {
    isDragging = false;
  });

  canvas.addEventListener('wheel', (e) => {
    e.preventDefault();
    camera.radius = Math.max(camera.minRadius, Math.min(camera.maxRadius, camera.radius * (1 + e.deltaY * 0.001)));
  });
};
视锥体裁剪与拾取
视锥体裁剪（Frustum Culling）是重要的性能优化手段，将不在相机可见范围内的对象提前排除，避免不必要的 GPU 处理。视锥体由 6 个平面定义：近、远、左、右、上、下。


interface Plane {
  normal: Vec3;
  distance: number;
}

interface Frustum {
  planes: Plane[];
}

const extractFrustumPlanes = (vp: Float32Array): Frustum => {
  const planes: Plane[] = [];

  const extractPlane = (row: number, sign: number): Plane => {
    const normal: Vec3 = [vp[3] + sign * vp[row], vp[7] + sign * vp[row + 4], vp[11] + sign * vp[row + 8]];
    const distance = vp[15] + sign * vp[row + 12];
    const len = Math.sqrt(normal[0] ** 2 + normal[1] ** 2 + normal[2] ** 2);
    return {
      normal: [normal[0] / len, normal[1] / len, normal[2] / len],
      distance: distance / len,
    };
  };

  planes.push(extractPlane(0, 1));
  planes.push(extractPlane(0, -1));
  planes.push(extractPlane(1, 1));
  planes.push(extractPlane(1, -1));
  planes.push(extractPlane(2, 1));
  planes.push(extractPlane(2, -1));

  return { planes };
};

interface BoundingSphere {
  center: Vec3;
  radius: number;
}

const isVisible = (frustum: Frustum, sphere: BoundingSphere): boolean => {
  for (const plane of frustum.planes) {
    const distance =
      plane.normal[0] * sphere.center[0] +
      plane.normal[1] * sphere.center[1] +
      plane.normal[2] * sphere.center[2] +
      plane.distance;
    if (distance < -sphere.radius) return false;
  }
  return true;
};
射线拾取（Ray Picking）将屏幕上的鼠标点击转换为 3D 空间中的射线，用于对象选择：


const screenToRay = (
  x: number,
  y: number,
  width: number,
  height: number,
  invViewProj: Float32Array,
): { origin: Vec3; direction: Vec3 } => {
  const ndcX = (2.0 * x) / width - 1.0;
  const ndcY = 1.0 - (2.0 * y) / height;

  const nearPoint = transformPoint(invViewProj, [ndcX, ndcY, -1]);
  const farPoint = transformPoint(invViewProj, [ndcX, ndcY, 1]);

  return {
    origin: nearPoint,
    direction: normalize(subtract(farPoint, nearPoint)),
  };
};

const transformPoint = (matrix: Float32Array, point: Vec3): Vec3 => {
  const w = matrix[3] * point[0] + matrix[7] * point[1] + matrix[11] * point[2] + matrix[15];
  return [
    (matrix[0] * point[0] + matrix[4] * point[1] + matrix[8] * point[2] + matrix[12]) / w,
    (matrix[1] * point[0] + matrix[5] * point[1] + matrix[9] * point[2] + matrix[13]) / w,
    (matrix[2] * point[0] + matrix[6] * point[1] + matrix[10] * point[2] + matrix[14]) / w,
  ];
};
小结
    

  • 视图矩阵通过 lookAt 构造，本质是相机世界变换的逆矩阵
    • 

  • 透视投影产生近大远小效果，正交投影保持平行线，两者适用于不同场景
    • 

  • 反向深度缓冲（Reversed-Z）有效解决远距离深度精度不足的问题
    • 

  • 轨道相机使用球坐标系控制旋转，指针事件驱动交互
    • 

  • 视锥体裁剪和射线拾取是 3D 交互应用中不可或缺的空间查询技术
