WebGL 概述与渲染管线

核心概念

WebGL（Web Graphics Library）是基于 OpenGL ES 2.0 的 JavaScript API，允许在浏览器中进行硬件加速的 2D 和 3D 图形渲染。它直接运行在 GPU 上，通过 <canvas> 元素提供底层图形编程能力。

WebGL 的核心是渲染管线（Rendering Pipeline），这是一个将 3D 几何数据转换为 2D 像素的多阶段处理流程。理解渲染管线是掌握所有 GPU 图形编程的基础。

渲染管线的六个阶段
WebGL 渲染管线由多个阶段组成，其中顶点着色器和片段着色器是可编程的，其余阶段由 GPU 固定处理。


顶点处理阶段接收顶点数据（位置、法线、UV 坐标等），通过顶点着色器进行变换。典型的变换包括模型变换（Model）、视图变换（View）和投影变换（Projection），即 MVP 矩阵变换。


const vertexShaderSource = `
  attribute vec4 a_position;
  attribute vec2 a_texCoord;
  uniform mat4 u_modelViewProjection;
  varying vec2 v_texCoord;

  void main() {
    gl_Position = u_modelViewProjection * a_position;
    v_texCoord = a_texCoord;
  }
`;

const fragmentShaderSource = `
  precision mediump float;
  varying vec2 v_texCoord;
  uniform sampler2D u_texture;

  void main() {
    gl_FragColor = texture2D(u_texture, v_texCoord);
  }
`;
图元装配将处理后的顶点按照指定的拓扑（三角形、线段、点）组装成几何图元。光栅化将图元转换为片段（Fragment），每个片段对应屏幕上的一个像素候选。片段着色器计算每个片段的最终颜色，可以进行纹理采样、光照计算等。最后的测试与混合阶段执行深度测试、模板测试和颜色混合。


WebGL 上下文获取与初始化
WebGL 程序的第一步是获取渲染上下文。上下文对象是所有 WebGL 操作的入口，提供了数百个 API 方法。


const initWebGL = (canvas: HTMLCanvasElement): WebGL2RenderingContext => {
  const gl = canvas.getContext('webgl2', {
    alpha: false,
    antialias: true,
    depth: true,
    stencil: false,
    premultipliedAlpha: false,
    preserveDrawingBuffer: false,
    powerPreference: 'high-performance',
    failIfMajorPerformanceCaveat: false,
  });

  if (!gl) {
    throw new Error('WebGL 2.0 not supported');
  }

  gl.viewport(0, 0, canvas.width, canvas.height);
  gl.clearColor(0.0, 0.0, 0.0, 1.0);
  gl.enable(gl.DEPTH_TEST);
  gl.depthFunc(gl.LEQUAL);

  return gl;
};
上下文参数中，powerPreference 可以指定使用集成显卡还是独立显卡，antialias 控制抗锯齿。preserveDrawingBuffer 为 false 时允许浏览器优化交换缓冲区，但 toDataURL() 可能返回空白。


设备像素比（DPR）处理对于高清屏幕至关重要：


const resizeCanvas = (canvas: HTMLCanvasElement, gl: WebGL2RenderingContext) => {
  const dpr = window.devicePixelRatio || 1;
  const displayWidth = Math.floor(canvas.clientWidth * dpr);
  const displayHeight = Math.floor(canvas.clientHeight * dpr);

  if (canvas.width !== displayWidth || canvas.height !== displayHeight) {
    canvas.width = displayWidth;
    canvas.height = displayHeight;
    gl.viewport(0, 0, displayWidth, displayHeight);
  }
};
着色器程序编译与链接
着色器是运行在 GPU 上的小程序，WebGL 需要在运行时编译和链接着色器源码。这个过程包括创建着色器对象、编译源码、创建程序对象、链接着色器。


const createShader = (gl: WebGL2RenderingContext, type: number, source: string): WebGLShader => {
  const shader = gl.createShader(type);
  if (!shader) throw new Error('Failed to create shader');

  gl.shaderSource(shader, source);
  gl.compileShader(shader);

  if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
    const info = gl.getShaderInfoLog(shader);
    gl.deleteShader(shader);
    throw new Error(`Shader compilation failed: ${info}`);
  }

  return shader;
};

const createProgram = (
  gl: WebGL2RenderingContext,
  vertexShader: WebGLShader,
  fragmentShader: WebGLShader,
): WebGLProgram => {
  const program = gl.createProgram();
  if (!program) throw new Error('Failed to create program');

  gl.attachShader(program, vertexShader);
  gl.attachShader(program, fragmentShader);
  gl.linkProgram(program);

  if (!gl.getProgramParameter(program, gl.LINK_STATUS)) {
    const info = gl.getProgramInfoLog(program);
    gl.deleteProgram(program);
    throw new Error(`Program linking failed: ${info}`);
  }

  return program;
};
着色器编译是同步操作，对于复杂着色器可能导致卡顿。WebGL 2.0 支持 KHR_parallel_shader_compile 扩展，允许异步编译：


const compileShaderAsync = async (gl: WebGL2RenderingContext, shader: WebGLShader): Promise<void> => {
  const ext = gl.getExtension('KHR_parallel_shader_compile');
  if (!ext) return;

  return new Promise((resolve) => {
    const check = () => {
      if (gl.getShaderParameter(shader, ext.COMPLETION_STATUS_KHR)) {
        resolve();
      } else {
        requestAnimationFrame(check);
      }
    };
    check();
  });
};
绘制循环与状态管理
WebGL 采用状态机模型，所有绑定和设置都是全局状态。渲染循环通常使用 requestAnimationFrame 驱动，每帧需要清除缓冲区、设置状态、提交绘制调用。


interface RenderState {
  program: WebGLProgram;
  vao: WebGLVertexArrayObject;
  uniforms: Record<string, WebGLUniformLocation>;
  indexCount: number;
}

const renderLoop = (gl: WebGL2RenderingContext, states: RenderState[]) => {
  let lastTime = 0;

  const frame = (time: number) => {
    const deltaTime = (time - lastTime) / 1000;
    lastTime = time;

    gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);

    for (const state of states) {
      gl.useProgram(state.program);
      gl.bindVertexArray(state.vao);

      gl.uniform1f(state.uniforms['u_time'], time / 1000);
      gl.drawElements(gl.TRIANGLES, state.indexCount, gl.UNSIGNED_SHORT, 0);

      gl.bindVertexArray(null);
    }

    requestAnimationFrame(frame);
  };

  requestAnimationFrame(frame);
};
WebGL 2.0 引入的 VAO（Vertex Array Object）极大简化了状态管理。VAO 封装了顶点属性配置，避免每帧重复绑定：


const createVAO = (
  gl: WebGL2RenderingContext,
  program: WebGLProgram,
  buffers: { name: string; data: Float32Array; size: number }[],
  indices: Uint16Array,
): WebGLVertexArrayObject => {
  const vao = gl.createVertexArray();
  if (!vao) throw new Error('Failed to create VAO');
  gl.bindVertexArray(vao);

  for (const buffer of buffers) {
    const location = gl.getAttribLocation(program, buffer.name);
    const vbo = gl.createBuffer();
    gl.bindBuffer(gl.ARRAY_BUFFER, vbo);
    gl.bufferData(gl.ARRAY_BUFFER, buffer.data, gl.STATIC_DRAW);
    gl.enableVertexAttribArray(location);
    gl.vertexAttribPointer(location, buffer.size, gl.FLOAT, false, 0, 0);
  }

  const ebo = gl.createBuffer();
  gl.bindBuffer(gl.ELEMENT_ARRAY_BUFFER, ebo);
  gl.bufferData(gl.ELEMENT_ARRAY_BUFFER, indices, gl.STATIC_DRAW);

  gl.bindVertexArray(null);
  return vao;
};
小结
    

  • WebGL 通过渲染管线将 3D 数据转换为 2D 像素，顶点着色器和片段着色器是两个可编程阶段
    • 

  • 上下文初始化需要处理设备像素比、抗锯齿、电源偏好等参数
    • 

  • 着色器程序需要运行时编译和链接，WebGL 2.0 支持异步编译优化
    • 

  • 渲染循环基于 requestAnimationFrame，VAO 简化了顶点状态管理
    • 

  • WebGL 2.0 相比 1.0 增加了实例化渲染、MRT、变换反馈等现代特性
