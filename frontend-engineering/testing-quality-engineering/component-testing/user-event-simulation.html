用户事件模拟

核心概念

user-event 是一个模拟真实用户交互的库，比 fireEvent 更接近真实用户行为。它会触发完整的事件序列——例如 type() 会依次触发 focus、keydown、input、keyup 等事件，而 fireEvent 只触发单个事件。这使得 user-event 能捕获到 fireEvent 遗漏的集成问题。





交互类型
user-event API
fireEvent 等价
user-event 额外触发





点击
user.click()
fireEvent.click()
focus、pointerdown、mousedown




输入
user.type()
fireEvent.change()
逐字符 keydown、input、keyup




选择
user.selectOptions()
fireEvent.change()
focus、click




Tab
user.tab()
fireEvent.keyDown()
自动焦点转移




清空
user.clear()

selectAll + delete





基础用法
安装
npm install -D @testing-library/user-event
设置 user
import { render, screen } from '@testing-library/react'
import userEvent from '@testing-library/user-event'
import LoginForm from './LoginForm'

test('login form', async () => {
  const user = userEvent.setup()
  render(<LoginForm />)

  await user.type(screen.getByLabelText('Email'), 'alice@example.com')
  await user.type(screen.getByLabelText('Password'), 'password123')
  await user.click(screen.getByRole('button', { name: /login/i }))

  expect(screen.getByText('Welcome!')).toBeInTheDocument()
})

点击
import { render, screen } from '@testing-library/react'

import Button from './Button'

test('click button', async () => {
  const user = userEvent.setup()
  const handleClick = vi.fn()

  render(<Button onClick={handleClick}>Click me</Button>)

  await user.click(screen.getByText('Click me'))

  expect(handleClick).toHaveBeenCalledTimes(1)
})

  const user = userEvent.setup()

  expect(handleDoubleClick).toHaveBeenCalledTimes(1)
})
输入
import { render, screen } from '@testing-library/react'
import userEvent from '@testing-library/user-event'
import SearchInput from './SearchInput'

test('type into input', async () => {
  const user = userEvent.setup()
  render(<SearchInput />)

  const input = screen.getByLabelText('Search')
  await user.type(input, 'hello world')

  expect(input).toHaveValue('hello world')
})

test('clear input', async () => {
  const user = userEvent.setup()
  render(<SearchInput defaultValue="hello" />)

  const input = screen.getByLabelText('Search')
  await user.clear(input)

  expect(input).toHaveValue('')
})

test('select all', async () => {
  const user = userEvent.setup()
  render(<SearchInput defaultValue="hello world" />)

  const input = screen.getByLabelText('Search')
  await user.click(input)
  await user.keyboard('{Control>}a{/Control}')

  expect(input).toHaveSelectionRange(0, 11)
})
选择
import { render, screen } from '@testing-library/react'
import userEvent from '@testing-library/user-event'
import Select from './Select'

test('select option', async () => {
  const user = userEvent.setup()
  render(
    <Select>
      <option value="">Choose</option>
      <option value="option1">Option 1</option>
      <option value="option2">Option 2</option>
    </Select>

  await user.selectOptions(screen.getByRole('combobox'), 'option1')

  expect(screen.getByRole('combobox')).toHaveValue('option1')
})
上传文件

import FileUpload from './FileUpload'

test('upload file', async () => {
  const user = userEvent.setup()

键盘事件
import { render, screen } from '@testing-library/react'
import userEvent from '@testing-library/user-event'
import TodoApp from './TodoApp'

test('add todo with Enter key', async () => {
  const user = userEvent.setup()
  render(<TodoApp />)

  const input = screen.getByLabelText('New todo')

  expect(screen.getByText('Buy milk')).toBeInTheDocument()
})

test('navigate with Tab', async () => {
  const user = userEvent.setup()
  render(<LoginForm />)

  await user.tab()
  expect(screen.getByLabelText('Email')).toHaveFocus()

  await user.tab()
  expect(screen.getByLabelText('Password')).toHaveFocus()

  await user.tab()
  expect(screen.getByRole('button', { name: /login/i })).toHaveFocus()
})
user-event vs fireEvent




特性
user-event
fireEvent





真实性
高（模拟真实用户）
低（直接触发事件）




复杂性
高（处理多个事件）
低（单个事件）




推荐场景
大多数情况
特殊情况





✅ 推荐使用 user-event
// 使用 user-event
await user.type(input, 'hello');
await user.click(button);
特殊情况使用 fireEvent
// 某些特殊场景需要 fireEvent
fireEvent.scroll(container, { target: { scrollTop: 100 } });
fireEvent.drop(dropzone, { dataTransfer });
小结
    

  • 优先使用 user-event，模拟完整的用户交互序列
    • 

  • 支持点击、输入、选择、上传、键盘等全场景
    • 

  • 始终使用 userEvent.setup() 初始化
    • 

  • scroll、drag 等特殊场景使用 fireEvent
