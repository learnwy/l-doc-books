间距与布局令牌

核心概念

间距令牌（Spacing Token）定义设计系统中所有内边距（padding）、外边距（margin）、间隙（gap）、圆角（border-radius）等空间相关数值——一致的间距让界面呈现韵律感和整体协调性。基于 4 像素或 8 像素网格（最小单位），2 的幂次加上中间值（4, 8, 12, 16, 24, 32, 48, 64）是行业标准的间距阶梯。T 恤尺码命名（xs / sm / md / lg / xl）让设计师和工程师拥有共同词汇。布局令牌（最大宽度、断点、容器宽度）解决响应式设计问题。圆角、阴影和 z-index 也是与布局相关的令牌。本节详细讲解间距阶梯设计、网格系统、布局令牌、阴影/圆角/z-index，以及无障碍考量（触控目标尺寸）。

类别 示例 所属层级
间距 spacing.4 / spacing.md 引用层 + 系统层
尺寸 size.icon-sm / button-md 组件层
圆角 radius.sm / md / lg / pill 系统层
阴影 shadow.sm / md / lg / xl 系统层
Z轴层级 z.dropdown / modal / tooltip 系统层
断点 breakpoint.sm / md / lg / xl 引用层

间距阶梯

4 像素网格：

  • 最小单位 4px。
  • 所有间距是 4 的倍数。
  • 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128。

8 像素网格：

  • 最小单位 8px。
  • 4, 8, 16, 24, 32, 48, 64, 96, 128。
  • Material Design 采用此方案。

选择建议：

  • 4 像素更精细。
  • 8 像素规则更简单。
  • 实际项目：4 像素是主流选择。

令牌命名

数字命名：

  • spacing.4 = 4px。
  • spacing.8 = 8px。
  • 与数值关联清晰直观。

T 恤尺码命名：

  • spacing.xs = 4px。
  • spacing.sm = 8px。
  • spacing.md = 16px。
  • spacing.lg = 24px。
  • spacing.xl = 32px。
  • 易于记忆。

最佳实践：

  • 引用层使用数字命名（spacing.4）。
  • 系统层使用语义命名（spacing.md）。

完整间距阶梯

{
  "spacing": {
    "0": { "value": "0px" },
    "1": { "value": "4px" },
    "2": { "value": "8px" },
    "3": { "value": "12px" },
    "4": { "value": "16px" },
    "5": { "value": "20px" },
    "6": { "value": "24px" },
    "8": { "value": "32px" },
    "10": { "value": "40px" },
    "12": { "value": "48px" },
    "16": { "value": "64px" },
    "20": { "value": "80px" },
    "24": { "value": "96px" }
  }
}

或使用 T 恤尺码：

{
  "spacing": {
    "none": "0",
    "xxs": "4px",
    "xs": "8px",
    "sm": "12px",
    "md": "16px",
    "lg": "24px",
    "xl": "32px",
    "2xl": "48px",
    "3xl": "64px",
    "4xl": "96px"
  }
}

间距应用场景

内边距（Padding）：

  • 元素内部间距。
  • 卡片内容区边距。
  • 按钮内边距。

外边距（Margin）：

  • 元素之间的间距。
  • 区块间的分隔。

间隙（Gap）：

  • 网格或弹性布局子元素间距。

8 点网格布局：

  • 所有间距为 8 的倍数。
  • 视觉呈现整体协调。

组件尺寸

组件特定尺寸：

{
  "size": {
    "button": {
      "height-sm": "32px",
      "height-md": "40px",
      "height-lg": "48px"
    },
    "icon": {
      "sm": "16px",
      "md": "20px",
      "lg": "24px"
    },
    "avatar": {
      "sm": "24px",
      "md": "40px",
      "lg": "64px"
    }
  }
}

触控目标：

  • Apple 标准：最小 44×44。
  • Material 标准：最小 48×48。
  • WCAG 2.2 AA 标准：最小 24×24。
  • 应在组件尺寸令牌中体现。

圆角

令牌定义：

{
  "radius": {
    "none": "0",
    "sm": "4px",
    "md": "8px",
    "lg": "12px",
    "xl": "16px",
    "2xl": "24px",
    "full": "9999px"
  }
}

用途：

  • 按钮、卡片、输入框。
  • full 用于胶囊形和圆形。

视觉层级：

  • 较小圆角用于行内元素（输入框、按钮）。
  • 较大圆角用于卡片和弹窗。
  • 完整圆角用于徽章和标签。

阴影

层级高度系统（Material Design）：

  • 0（扁平）。
  • 1, 2, 3, 4, 6, 8, 12, 16, 24 dp。
  • 每个层级对应独特的阴影值。

令牌定义：

{
  "shadow": {
    "none": "none",
    "sm": "0 1px 2px rgba(0,0,0,0.05)",
    "md": "0 4px 6px rgba(0,0,0,0.07)",
    "lg": "0 10px 15px rgba(0,0,0,0.1)",
    "xl": "0 20px 25px rgba(0,0,0,0.1)",
    "2xl": "0 25px 50px rgba(0,0,0,0.15)"
  }
}

实战应用：

  • 卡片：sm-md。
  • 弹窗：lg-xl。
  • 工具提示：md。
  • 下拉菜单：md。

暗色模式阴影：

  • 在暗色背景上阴影不可见。
  • 应使用提升的背景色替代阴影效果。

Z轴层级

令牌定义：

{
  "z": {
    "base": "0",
    "dropdown": "1000",
    "sticky": "1100",
    "fixed": "1200",
    "modalBackdrop": "1300",
    "modal": "1400",
    "popover": "1500",
    "tooltip": "1600"
  }
}

为何需要：

  • 避免随意使用 z-index: 9999999。
  • 确保层级堆叠可预测。
  • 便于统一更新调整。

断点

令牌定义：

{
  "breakpoint": {
    "xs": "0",
    "sm": "640px",
    "md": "768px",
    "lg": "1024px",
    "xl": "1280px",
    "2xl": "1536px"
  }
}

响应式设计：

  • 移动端优先。
  • 使用最小宽度断点。

组件行为：

  • 小于 md：垂直堆叠。
  • 大于等于 md：水平并排。

容器

令牌定义：

{
  "container": {
    "sm": "640px",
    "md": "768px",
    "lg": "1024px",
    "xl": "1280px",
    "2xl": "1536px"
  }
}

用途：居中容器的最大宽度约束。

响应式间距

移动端使用较小间距：

{
  "spacing": {
    "section": {
      "sm": "32px",
      "md": "64px",
      "lg": "96px"
    }
  }
}

或使用流体间距：

  • clamp(32px, 5vw, 96px)。

Material 8 点网格

Material Design 8 点网格：

  • 所有间距为 8 的倍数。
  • 视觉呈现整体协调。
  • 例外：图标内边距可用 4dp。

设计原理：

  • 在常见 DPI 上实现像素对齐。
  • 简化心智模型。

Tailwind 间距

Tailwind 默认：

  • 1 = 4px、2 = 8px、4 = 16px、6 = 24px、8 = 32px...
  • 基于类名：p-4、gap-6。

自定义配置：

  • 在 tailwind.config.js 中扩展设计系统令牌。

设计令牌与布局

容器查询（现代 CSS 特性）：

  • 基于父元素尺寸而非视口尺寸。
  • 实现更精细的组件级响应式。

令牌集成：

@container (min-width: 400px) {
  .card {
    padding: var(--spacing-lg);
  }
}

浏览器支持：

  • 2024 年起主流浏览器均已支持。

反模式

1. 随意间距：

  • 使用 5px、7px、13px 等非规范值。
  • 视觉缺乏整体协调性。

2. 令牌过多：

  • 定义了 20 个间距令牌。
  • 简化到约 10 个即可。

3. 缺乏系统性：

  • 未遵循网格规则。

4. 像素僵化：

  • 不支持响应式。
  • 应使用 rem 或响应式令牌。

5. 未建立 z-index 体系：

  • 使用任意数值 → 层级冲突。

6. 阴影滥用：

  • 每个元素都加阴影 → 视觉噪音。

7. 触控目标过小：

  • 移动端按钮小于 44px。
  • 导致无障碍测试失败。

实战案例

Material 8 点网格：

  • 所有值为 8 的倍数。
  • 图标内边距例外使用 4dp。

Tailwind 默认：

  • 4px 基准。
  • 内置间距阶梯。

Carbon：

  • 8 个间距令牌。
  • 保持简洁。

Atlassian：

  • 使用 T 恤尺码命名。
  • 多层架构设计。

小结

间距令牌系统化管理空间相关数值——基于 4 像素或 8 像素网格（最小单位），2 的幂次加上中间值（4, 8, 12, 16, 24, 32, 48, 64）是行业标准。命名策略为引用层使用数字（spacing.4 = 4px）加系统层使用语义（spacing.md = 16px），T 恤尺码（xs/sm/md/lg/xl）便于记忆。完整阶梯为 11 级，从 0 到 96px。应用于内边距（元素内部）、外边距（元素之间）和间隙（网格弹性布局），8 点网格让视觉呈现整体协调。组件尺寸包括按钮/图标/头像的尺寸令牌，触控目标要求 Apple 44×44 / Material 48×48 / WCAG 24×24 最小值。圆角令牌有 none/sm/md/lg/xl/2xl/full，小号用于行内元素、大号用于卡片、完整圆角用于胶囊形。阴影采用 Material 层级高度系统 0-24 dp，卡片用 sm-md、弹窗用 lg-xl、工具提示用 md，暗色模式下阴影不可见，改用提升背景色。Z轴层级令牌包括 base/dropdown/sticky/fixed/modal/popover/tooltip，替代任意的 9999 数值。断点为 sm 640 / md 768 / lg 1024 / xl 1280 / 2xl 1536，采用移动端优先的最小宽度策略。容器最大宽度用于居中布局。响应式间距在移动端使用较小值，或使用流体 clamp 函数。Material 8 点网格、Tailwind 4px 基准、Carbon 8 个令牌、Atlassian T 恤尺码是各具特色的案例。容器查询是现代 CSS 的组件级响应式方案，可与令牌集成。应避免的反模式包括：随意间距、令牌过多、缺乏系统性、像素僵化、未建立 z-index 体系、阴影滥用和触控目标过小。布局令牌是界面韵律的根基——做好了能让设计视觉协调、响应式友好且无障碍达标。
