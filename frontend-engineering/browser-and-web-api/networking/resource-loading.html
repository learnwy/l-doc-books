资源加载

浏览器的资源加载策略

浏览器在解析 HTML 时会发现各种子资源（CSS、JS、图片、字体等），并根据资源类型和优先级安排加载顺序。理解浏览器的资源加载机制对于优化页面性能至关重要。



资源提示（Resource Hints）
浏览器提供了多种资源提示机制，让开发者可以指导浏览器预先执行某些网络操作。

function addResourceHint(
  type: 'dns-prefetch' | 'preconnect' | 'prefetch' | 'preload' | 'modulepreload',
  href: string,
  options?: { as?: string; crossOrigin?: string; type?: string },
): HTMLLinkElement {
  const link = document.createElement('link');
  link.rel = type;
  link.href = href;

  if (options?.as) link.setAttribute('as', options.as);
  if (options?.crossOrigin) link.crossOrigin = options.crossOrigin;
  if (options?.type) link.type = options.type;

  document.head.appendChild(link);
  return link;
}

addResourceHint('preconnect', 'https://api.example.com', { crossOrigin: 'anonymous' });
addResourceHint('preload', '/fonts/inter.woff2', { as: 'font', crossOrigin: 'anonymous', type: 'font/woff2' });
addResourceHint('prefetch', '/next-page.html');


优先级提示（Priority Hints）
fetchpriority 属性允许开发者调整资源的加载优先级：


function createPriorityImage(src: string, priority: 'high' | 'low' | 'auto'): HTMLImageElement {
  const img = document.createElement('img');
  img.src = src;
  img.fetchPriority = priority;
  img.loading = priority === 'high' ? 'eager' : 'lazy';
  return img;
}

const heroImage = createPriorityImage('/hero-banner.jpg', 'high');
document.querySelector('.hero')?.appendChild(heroImage);

脚本加载策略
<script> 标签的不同属性组合决定了脚本的加载和执行行为：


type ScriptStrategy = 'blocking' | 'async' | 'defer' | 'module' | 'dynamic';

function loadScript(src: string, strategy: ScriptStrategy): Promise<void> {
  return new Promise((resolve, reject) => {
    const script = document.createElement('script');
    script.src = src;

    switch (strategy) {
      case 'async':
        script.async = true;
        break;
      case 'defer':
        script.defer = true;
        break;
      case 'module':
        script.type = 'module';
        break;
      case 'dynamic':
        script.async = false;
        break;
    }

    script.onload = () => resolve();
    script.onerror = () => reject(new Error(`Failed to load: ${src}`));
    document.head.appendChild(script);
  });
}

async function loadScriptsInOrder(urls: string[]): Promise<void> {
  for (const url of urls) {
    await loadScript(url, 'dynamic');
  }
}


提示： 动态创建的 <script> 默认是 async 的。如果需要按顺序执行，需要显式设置 script.async = false。






图片懒加载
浏览器原生支持图片懒加载，通过 loading="lazy" 属性实现：


function setupLazyLoading(): void {
  const images = document.querySelectorAll<HTMLImageElement>('img[data-src]');

  if ('loading' in HTMLImageElement.prototype) {
    images.forEach((img) => {
      img.src = img.dataset.src!;
      img.loading = 'lazy';
    });
    return;
  }

  const observer = new IntersectionObserver(
    (entries) => {
      for (const entry of entries) {
        if (entry.isIntersecting) {
          const img = entry.target as HTMLImageElement;
          img.src = img.dataset.src!;
          observer.unobserve(img);
        }
      }
    },
    { rootMargin: '200px' },
  );

  images.forEach((img) => observer.observe(img));
}


小结
    

  • 浏览器根据资源类型自动分配加载优先级，可通过 fetchpriority 调整
    • 

  • preconnect 提前建立连接、preload 提前加载关键资源、prefetch 预获取未来资源
    • 

  • 脚本加载使用 defer 保证顺序不阻塞、async 适用于独立脚本
    • 

  • loading="lazy" 实现原生图片懒加载，配合 IntersectionObserver 兜底
    • 

  • 合理运用资源提示可显著改善 LCP、FCP 等关键性能指标
