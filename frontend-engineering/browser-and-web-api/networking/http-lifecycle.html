HTTP 生命周期

从 URL 到响应

当用户在地址栏输入一个 URL 并按下回车，浏览器会经过一系列网络步骤获取资源。整个过程称为 HTTP 请求生命周期。



DNS 解析
DNS（Domain Name System）将域名解析为 IP 地址。浏览器会按以下顺序查找：


async function measureDNS(url: string): Promise<void> {
  const entries = performance.getEntriesByType('navigation') as PerformanceNavigationTiming[];
  if (entries.length > 0) {
    const nav = entries[0];
    console.log(`DNS lookup: ${nav.domainLookupEnd - nav.domainLookupStart}ms`);
    console.log(`TCP connect: ${nav.connectEnd - nav.connectStart}ms`);
    console.log(`TLS handshake: ${nav.connectEnd - nav.secureConnectionStart}ms`);
    console.log(`TTFB: ${nav.responseStart - nav.requestStart}ms`);
  }
}

measureDNS(location.href);

async function checkHTTPVersion(url: string): Promise<string> {
  const response = await fetch(url);
  const entries = performance.getEntriesByName(url) as PerformanceResourceTiming[];

  if (entries.length > 0) {
    const entry = entries[entries.length - 1];
    console.log(`Protocol: ${entry.nextHopProtocol}`);
    console.log(`Transfer size: ${entry.transferSize} bytes`);
    console.log(`Encoded body size: ${entry.encodedBodySize} bytes`);
    return entry.nextHopProtocol;
  }

  return 'unknown';
}


QUIC 协议
QUIC 是 HTTP/3 的传输层协议，基于 UDP 构建，解决了 TCP 的队头阻塞问题。


QUIC 的关键特性：

TLS 1.3 集成在协议层





interface ConnectionTiming {
  dns: number;
  tcp: number;
  tls: number;
  ttfb: number;
  download: number;
  total: number;
}

function getConnectionTiming(entry: PerformanceResourceTiming): ConnectionTiming {
  return {
    dns: entry.domainLookupEnd - entry.domainLookupStart,
    tcp: entry.connectEnd - entry.connectStart,
    tls: entry.secureConnectionStart > 0 ? entry.connectEnd - entry.secureConnectionStart : 0,
    ttfb: entry.responseStart - entry.requestStart,
    download: entry.responseEnd - entry.responseStart,
    total: entry.responseEnd - entry.startTime,
  };
}

const observer = new PerformanceObserver((list) => {
  for (const entry of list.getEntries() as PerformanceResourceTiming[]) {
    const timing = getConnectionTiming(entry);
    console.log(`${entry.name}:`, timing);
  }
});
observer.observe({ type: 'resource', buffered: true });


提示： 在 Chrome DevTools 的 Network 面板中，"Protocol" 列显示每个请求使用的协议版本（h2 = HTTP/2，h3 = HTTP/3）。






小结
    

  • HTTP 请求经历 DNS → TCP → TLS → HTTP 四个阶段
    • 

  • DNS 解析通过多级缓存加速，使用 dns-prefetch 可预解析域名
    • 

  • TLS 1.3 将握手减少到 1-RTT，支持 0-RTT 会话恢复
    • 

  • HTTP/2 引入多路复用和头部压缩，HTTP/3 基于 QUIC 彻底消除队头阻塞
    • 

  • 使用 PerformanceResourceTiming API 可以精确测量每个阶段的耗时
    •
