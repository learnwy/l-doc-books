WebSocket 与 SSE

实时通信方案概览

Web 应用经常需要实时接收服务器推送的数据。主流方案包括轮询（Polling）、Server-Sent Events (SSE) 和 WebSocket，它们的通信模型和适用场景各不相同。



WebSocket 基础
WebSocket 提供全双工（Full-Duplex） 通信通道，客户端和服务器可以同时发送和接收数据。连接通过 HTTP 升级建立。


class WebSocketClient {
  private ws: WebSocket | null = null;
  private reconnectTimer: ReturnType<typeof setTimeout> | null = null;
  private reconnectDelay = 1000;
  private maxReconnectDelay = 30000;

  constructor(
    private url: string,
    private onMessage: (data: unknown) => void,
  ) {}

  connect(): void {
    this.ws = new WebSocket(this.url);

    this.ws.onopen = () => {
      console.log('WebSocket connected');
      this.reconnectDelay = 1000;
    };

    this.ws.onmessage = (event: MessageEvent) => {
      const data = JSON.parse(event.data);
      this.onMessage(data);
    };

    this.ws.onclose = (event: CloseEvent) => {
      console.log(`WebSocket closed: ${event.code} ${event.reason}`);
      if (event.code !== 1000) {
        this.scheduleReconnect();
      }
    };

    this.ws.onerror = () => {
      console.error('WebSocket error');
    };
  }

  send(data: unknown): void {
    if (this.ws?.readyState === WebSocket.OPEN) {
      this.ws.send(JSON.stringify(data));
    }
  }

  private scheduleReconnect(): void {
    this.reconnectTimer = setTimeout(() => {
      console.log(`Reconnecting in ${this.reconnectDelay}ms...`);
      this.connect();
      this.reconnectDelay = Math.min(this.reconnectDelay * 2, this.maxReconnectDelay);
    }, this.reconnectDelay);
  }

  disconnect(): void {
    if (this.reconnectTimer) clearTimeout(this.reconnectTimer);
    this.ws?.close(1000, 'Client closing');
  }
}

Server-Sent Events (SSE)
SSE 是基于 HTTP 的半双工（Half-Duplex） 服务器推送协议。服务器通过 text/event-stream 格式持续发送事件。


class SSEClient {
  private eventSource: EventSource | null = null;

  constructor(
    private url: string,
    private handlers: Record<string, (data: unknown) => void>,
  ) {}

  connect(): void {
    this.eventSource = new EventSource(this.url);

    this.eventSource.onopen = () => {
      console.log('SSE connected');
    };

    this.eventSource.onmessage = (event: MessageEvent) => {
      const data = JSON.parse(event.data);
      this.handlers['message']?.(data);
    };

    for (const [eventType, handler] of Object.entries(this.handlers)) {
      if (eventType !== 'message') {
        this.eventSource.addEventListener(eventType, ((event: MessageEvent) => {
          handler(JSON.parse(event.data));
        }) as EventListener);
      }
    }

    this.eventSource.onerror = () => {
      console.error('SSE error, will auto-reconnect');
    };
  }

  disconnect(): void {
    this.eventSource?.close();
    this.eventSource = null;
  }
}

const sseClient = new SSEClient('/api/events', {
  message: (data) => console.log('Message:', data),
  notification: (data) => console.log('Notification:', data),
  heartbeat: () => console.log('Heartbeat received'),
});

使用场景选择
type Protocol = 'websocket' | 'sse' | 'polling';

function chooseProtocol(requirements: {
  bidirectional: boolean;
  binaryData: boolean;
  highFrequency: boolean;
  behindProxy: boolean;
}): Protocol {
  if (requirements.bidirectional || requirements.binaryData) {
    return 'websocket';
  }

  if (requirements.behindProxy) {
    return 'polling';
  }

  return 'sse';
}


心跳与连接保活
无论 WebSocket 还是 SSE，都需要心跳机制来检测连接是否存活。


class HeartbeatWebSocket {
  private ws: WebSocket | null = null;
  private heartbeatInterval: ReturnType<typeof setInterval> | null = null;
  private pongReceived = true;

  constructor(private url: string) {}

  connect(): void {
    this.ws = new WebSocket(this.url);

    this.ws.onopen = () => {
      this.startHeartbeat();
    };

    this.ws.onmessage = (event: MessageEvent) => {
      if (event.data === 'pong') {
        this.pongReceived = true;
        return;
      }
      console.log('Data:', event.data);
    };

    this.ws.onclose = () => {
      this.stopHeartbeat();
    };
  }

  private startHeartbeat(): void {
    this.heartbeatInterval = setInterval(() => {
      if (!this.pongReceived) {
        console.log('No pong received, reconnecting...');
        this.ws?.close();
        return;
      }
      this.pongReceived = false;
      this.ws?.send('ping');
    }, 30000);
  }

  private stopHeartbeat(): void {
    if (this.heartbeatInterval) {
      clearInterval(this.heartbeatInterval);
      this.heartbeatInterval = null;
    }
  }
}


小结
    

  • WebSocket 提供全双工通信，适合聊天、游戏、协同编辑等需要双向实时交互的场景
    • 

  • SSE 是基于 HTTP 的服务器推送方案，内置自动重连，适合通知、日志流、行情推送
    • 

  • WebSocket 使用独立的 ws:///wss:// 协议，SSE 复用 HTTP 连接
    • 

  • SSE 在 HTTP/2 下不受 6 连接限制，与现代基础设施兼容性更好
    • 

  • 根据是否需要双向通信、二进制数据、代理兼容性来选择合适的实时通信方案
