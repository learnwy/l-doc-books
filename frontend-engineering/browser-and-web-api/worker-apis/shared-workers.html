Shared Workers 共享工作线程

什么是 Shared Worker

Shared Worker 是可以被多个浏览器上下文（标签页、iframe）共同访问的 Worker。与 Dedicated Worker 只能一对一通信不同，Shared Worker 通过端口（Port） 机制实现一对多的通信。



创建和连接
const sharedWorker = new SharedWorker('/workers/shared.js', { name: 'app-shared' });
const port = sharedWorker.port;

port.start();

port.postMessage({ type: 'JOIN', userId: 'user123' });

port.onmessage = (event: MessageEvent) => {
  console.log('Received:', event.data);
};

port.onmessageerror = (event: MessageEvent) => {
  console.error('Message error:', event);
};
Shared Worker 内部代码：


const ports: MessagePort[] = [];

self.addEventListener('connect', ((event: MessageEvent) => {
  const port = event.ports[0];
  ports.push(port);

  port.onmessage = (msg: MessageEvent) => {
    const { type, data } = msg.data;

    switch (type) {
      case 'JOIN':
        broadcast({ type: 'USER_JOINED', data });
        break;
      case 'MESSAGE':
        broadcast({ type: 'NEW_MESSAGE', data }, port);
        break;
      case 'GET_STATE':
        port.postMessage({ type: 'STATE', data: getState() });
        break;
    }
  };

  port.start();
}) as EventListener);

function broadcast(message: unknown, excludePort?: MessagePort): void {
  for (const p of ports) {
    if (p !== excludePort) {
      p.postMessage(message);
    }
  }
}

function getState(): unknown {
  return { connectedClients: ports.length };
}

基于端口的通信模型
class SharedWorkerBus {
  private port: MessagePort;
  private handlers = new Map<string, Set<(data: unknown) => void>>();

  constructor(workerUrl: string, name?: string) {
    const worker = new SharedWorker(workerUrl, { name });
    this.port = worker.port;

    this.port.onmessage = (event: MessageEvent) => {
      const { type, data } = event.data;
      const callbacks = this.handlers.get(type);
      if (callbacks) {
        for (const cb of callbacks) {
          cb(data);
        }
      }
    };

    this.port.start();
  }

  on(type: string, callback: (data: unknown) => void): () => void {
    if (!this.handlers.has(type)) {
      this.handlers.set(type, new Set());
    }
    this.handlers.get(type)!.add(callback);

    return () => {
      this.handlers.get(type)?.delete(callback);
    };
  }

  emit(type: string, data?: unknown): void {
    this.port.postMessage({ type, data });
  }
}

const bus = new SharedWorkerBus('/workers/shared.js', 'event-bus');
const unsubscribe = bus.on('NOTIFICATION', (data) => {
  console.log('Notification:', data);
});
bus.emit('SUBSCRIBE', { channel: 'updates' });


多标签页通信场景
Shared Worker 是实现多标签页通信的可靠方案之一：


interface TabState {
  tabId: string;
  title: string;
  url: string;
  active: boolean;
}

class TabSyncManager {
  private bus: SharedWorkerBus;
  private tabId = crypto.randomUUID();

  constructor() {
    this.bus = new SharedWorkerBus('/workers/tab-sync.js', 'tab-sync');
    this.init();
  }

  private init(): void {
    this.bus.emit('TAB_OPEN', {
      tabId: this.tabId,
      title: document.title,
      url: location.href,
    });

    this.bus.on('TAB_LIST', (data) => {
      console.log('Active tabs:', data);
    });

    this.bus.on('STATE_UPDATE', (data) => {
      console.log('State updated from another tab:', data);
    });

    window.addEventListener('beforeunload', () => {
      this.bus.emit('TAB_CLOSE', { tabId: this.tabId });
    });

    document.addEventListener('visibilitychange', () => {
      this.bus.emit('TAB_VISIBILITY', {
        tabId: this.tabId,
        visible: !document.hidden,
      });
    });
  }

  updateState(key: string, value: unknown): void {
    this.bus.emit('STATE_CHANGE', { key, value, source: this.tabId });
  }
}

浏览器支持与降级
function createCommunicationChannel(workerUrl: string): {
  send: (data: unknown) => void;
  onMessage: (callback: (data: unknown) => void) => void;
} {
  if (typeof SharedWorker !== 'undefined') {
    const worker = new SharedWorker(workerUrl);
    worker.port.start();
    return {
      send: (data) => worker.port.postMessage(data),
      onMessage: (cb) => {
        worker.port.onmessage = (e) => cb(e.data);
      },
    };
  }

  if (typeof BroadcastChannel !== 'undefined') {
    const channel = new BroadcastChannel('app-sync');
    return {
      send: (data) => channel.postMessage(data),
      onMessage: (cb) => {
        channel.onmessage = (e) => cb(e.data);
      },
    };
  }

  return {
    send: (data) => {
      localStorage.setItem('__sync', JSON.stringify(data));
    },
    onMessage: (cb) => {
      window.addEventListener('storage', (e) => {
        if (e.key === '__sync' && e.newValue) {
          cb(JSON.parse(e.newValue));
        }
      });
    },
  };
}


提示： Shared Worker 的调试比较特殊。在 Chrome 中访问 chrome://inspect/#workers 可以查看和调试所有活跃的 Shared Worker。






小结
    

  • Shared Worker 可被同源的多个标签页/iframe 共享，通过端口（Port）通信
    • 

  • 适合多标签页状态同步、共享连接池、集中式缓存等场景
    • 

  • 生命周期由连接数控制，最后一个连接关闭后 Worker 终止
    • 

  • 浏览器支持不如 Dedicated Worker 广泛，需要考虑降级方案
    • 

  • BroadcastChannel 和 localStorage 是多标签页通信的替代方案
    •
