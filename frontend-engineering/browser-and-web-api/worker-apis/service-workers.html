Service Workers 服务工作线程

什么是 Service Worker

Service Worker 是运行在浏览器后台的脚本，充当浏览器和网络之间的代理。它可以拦截网络请求、管理缓存、实现离线体验，是 PWA（Progressive Web App）的核心技术。



生命周期
Service Worker 的生命周期是其最重要的概念，包含 安装（Install）、激活（Activate） 和 控制（Fetch） 三个阶段。


if ('serviceWorker' in navigator) {
  navigator.serviceWorker
    .register('/sw.js', { scope: '/' })
    .then((registration) => {
      console.log('SW registered:', registration.scope);

      registration.addEventListener('updatefound', () => {
        const newWorker = registration.installing;
        newWorker?.addEventListener('statechange', () => {
          console.log('SW state:', newWorker.state);
        });
      });
    })
    .catch((error) => {
      console.error('SW registration failed:', error);
    });
}
Service Worker 文件（sw.js）：


const CACHE_NAME = 'app-v1';
const PRECACHE_URLS = ['/', '/index.html', '/styles/main.css', '/scripts/app.js', '/offline.html'];

self.addEventListener('install', ((event: ExtendableEvent) => {
  event.waitUntil(
    caches
      .open(CACHE_NAME)
      .then((cache) => cache.addAll(PRECACHE_URLS))
      .then(() => (self as any).skipWaiting()),
  );
}) as EventListener);

self.addEventListener('activate', ((event: ExtendableEvent) => {
  event.waitUntil(
    caches
      .keys()
      .then((names) => Promise.all(names.filter((name) => name !== CACHE_NAME).map((name) => caches.delete(name))))
      .then(() => (self as any).clients.claim()),
  );
}) as EventListener);

Fetch 事件拦截
self.addEventListener('fetch', ((event: FetchEvent) => {
  const { request } = event;
  const url = new URL(request.url);

  if (request.destination === 'image') {
    event.respondWith(cacheFirst(request));
  } else if (url.pathname.startsWith('/api/')) {
    event.respondWith(networkFirst(request));
  } else if (request.mode === 'navigate') {
    event.respondWith(navigationHandler(request));
  }
}) as EventListener);

async function cacheFirst(request: Request): Promise<Response> {
  const cached = await caches.match(request);
  return cached ?? fetch(request);
}

async function networkFirst(request: Request): Promise<Response> {
  try {
    const response = await fetch(request);
    const cache = await caches.open(CACHE_NAME);
    cache.put(request, response.clone());
    return response;
  } catch {
    const cached = await caches.match(request);
    return cached ?? new Response('Offline', { status: 503 });
  }
}

async function navigationHandler(request: Request): Promise<Response> {
  try {
    return await fetch(request);
  } catch {
    return (await caches.match('/offline.html'))!;
  }
}


推送通知
Service Worker 可以接收服务器推送的消息，即使页面未打开也能工作。


async function subscribePush(): Promise<PushSubscription> {
  const registration = await navigator.serviceWorker.ready;

  const subscription = await registration.pushManager.subscribe({
    userVisibleOnly: true,
    applicationServerKey: urlBase64ToUint8Array('YOUR_VAPID_PUBLIC_KEY'),
  });

  await fetch('/api/push/subscribe', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(subscription),
  });

  return subscription;
}

function urlBase64ToUint8Array(base64String: string): Uint8Array {
  const padding = '='.repeat((4 - (base64String.length % 4)) % 4);
  const base64 = (base64String + padding).replace(/-/g, '+').replace(/_/g, '/');
  const rawData = atob(base64);
  return Uint8Array.from(rawData, (char) => char.charCodeAt(0));
}

self.addEventListener('push', ((event: PushEvent) => {
  const data = event.data?.json() ?? { title: '通知', body: '你有新消息' };

  event.waitUntil(
    (self as any).registration.showNotification(data.title, {
      body: data.body,
      icon: '/icons/notification.png',
      badge: '/icons/badge.png',
      data: { url: data.url },
    }),
  );
}) as EventListener);


后台同步
Background Sync 允许延迟网络请求到连接恢复时执行。


async function registerSync(tag: string): Promise<void> {
  const registration = await navigator.serviceWorker.ready;
  await registration.sync.register(tag);
}

async function queueOfflineAction(action: unknown): Promise<void> {
  const db = await openDB();
  await db.put('pending-actions', action);
  await registerSync('sync-actions');
}

self.addEventListener('sync', ((event: SyncEvent) => {
  if (event.tag === 'sync-actions') {
    event.waitUntil(processPendingActions());
  }
}) as EventListener);

async function processPendingActions(): Promise<void> {
  const db = await openDB();
  const actions = await db.getAll('pending-actions');

  for (const action of actions) {
    await fetch('/api/actions', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(action),
    });
    await db.delete('pending-actions', action.id);
  }
}

async function openDB(): Promise<any> {
  return {} as any;
}


提示： Service Worker 在不使用时会被浏览器终止以节省资源。不要在 Service Worker 中存储全局状态，而应使用 IndexedDB 或 Cache API 持久化数据。






小结
    

  • Service Worker 运行在独立线程，充当浏览器与网络之间的代理
    • 

  • 生命周期包含 install → activate → fetch 三个关键阶段
    • 

  • 通过 fetch 事件拦截请求，配合 Cache API 实现离线优先体验
    • 

  • 支持推送通知（Push API）和后台同步（Background Sync）
    • 

  • SW 不能访问 DOM，会在空闲时被终止，状态需持久化到 IndexedDB
