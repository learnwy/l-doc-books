Worklets 工作小程序

什么是 Worklet

Worklet 是一种轻量级的 Worker 变体，设计用于浏览器渲染引擎的特定管线阶段。与 Web Worker 不同，Worklet 运行在渲染管线的关键路径上，可以访问低级渲染 API。Worklet 是 Houdini 项目的核心组件。

Paint Worklet
Paint Worklet 允许通过 JavaScript 自定义 CSS 绘制逻辑，作为 background-image 或 border-image 使用。


if ('paintWorklet' in CSS) {
  (CSS as any).paintWorklet.addModule('/worklets/paint-checkerboard.js');
}
Paint Worklet 代码：


class CheckerboardPainter {
  static get inputProperties(): string[] {
    return ['--checker-size', '--checker-color-1', '--checker-color-2'];
  }

  paint(
    ctx: CanvasRenderingContext2D,
    geom: { width: number; height: number },
    properties: Map<string, CSSStyleValue>,
  ): void {
    const size = parseInt(properties.get('--checker-size')?.toString() ?? '20');
    const color1 = properties.get('--checker-color-1')?.toString() ?? '#eee';
    const color2 = properties.get('--checker-color-2')?.toString() ?? '#fff';

    const cols = Math.ceil(geom.width / size);
    const rows = Math.ceil(geom.height / size);

    for (let row = 0; row < rows; row++) {
      for (let col = 0; col < cols; col++) {
        ctx.fillStyle = (row + col) % 2 === 0 ? color1 : color2;
        ctx.fillRect(col * size, row * size, size, size);
      }
    }
  }
}

registerPaint('checkerboard', CheckerboardPainter);
使用方式（CSS）：


.element {
  --checker-size: 16;
  --checker-color-1: #e0e0e0;
  --checker-color-2: #ffffff;
  background-image: paint(checkerboard);
}


提示： Paint Worklet 中不能使用 Path2D、Image 等 API，但支持基本的 Canvas 2D 绑图操作。Worklet 中也无法使用 fetch 或访问 DOM。






Animation Worklet
Animation Worklet 允许创建运行在合成线程上的自定义动画，不受主线程阻塞影响。


if ('animationWorklet' in CSS) {
  await (CSS as any).animationWorklet.addModule('/worklets/scroll-animation.js');
}
Animation Worklet 代码：


class ScrollProgressAnimator {
  animate(currentTime: number, effect: KeyframeEffect): void {
    if (currentTime !== null) {
      const progress = Math.min(Math.max(currentTime / 100, 0), 1);
      effect.localTime = progress * effect.getTiming().duration!;
    }
  }
}

registerAnimator('scroll-progress', ScrollProgressAnimator);
const element = document.querySelector('.animated')!;
const scrollTimeline = new (window as any).ScrollTimeline({
  source: document.scrollingElement,
  orientation: 'block',
});

const animation = new (window as any).WorkletAnimation(
  'scroll-progress',
  new KeyframeEffect(element, [{ transform: 'translateX(-100%)' }, { transform: 'translateX(0)' }], {
    duration: 1000,
    fill: 'both',
  }),
  scrollTimeline,
);

animation.play();


Audio Worklet
Audio Worklet 替代了已弃用的 ScriptProcessorNode，在音频渲染线程上运行自定义音频处理。


const audioCtx = new AudioContext();
await audioCtx.audioWorklet.addModule('/worklets/noise-generator.js');

const noiseNode = new AudioWorkletNode(audioCtx, 'noise-generator', {
  numberOfOutputs: 1,
  outputChannelCount: [2],
  parameterData: {
    gain: 0.3,
  },
});

noiseNode.connect(audioCtx.destination);
Audio Worklet Processor：


class NoiseGenerator extends AudioWorkletProcessor {
  static get parameterDescriptors(): AudioParamDescriptor[] {
    return [
      {
        name: 'gain',
        defaultValue: 0.5,
        minValue: 0,
        maxValue: 1,
        automationRate: 'a-rate',
      },
    ];
  }

  process(inputs: Float32Array[][], outputs: Float32Array[][], parameters: Record<string, Float32Array>): boolean {
    const output = outputs[0];
    const gainValues = parameters.gain;

    for (let channel = 0; channel < output.length; channel++) {
      for (let i = 0; i < output[channel].length; i++) {
        const gain = gainValues.length > 1 ? gainValues[i] : gainValues[0];
        output[channel][i] = (Math.random() * 2 - 1) * gain;
      }
    }

    return true;
  }
}

registerProcessor('noise-generator', NoiseGenerator);


Layout Worklet
Layout Worklet（实验性）允许定义自定义布局算法，像 Flexbox 或 Grid 一样使用。


class MasonryLayout {
  static get inputProperties(): string[] {
    return ['--masonry-gap', '--masonry-columns'];
  }

  async intrinsicSizes(): Promise<void> {}

  async layout(children: any[], edges: any, constraints: any, styleMap: Map<string, any>): Promise<any> {
    const gap = parseInt(styleMap.get('--masonry-gap')?.toString() ?? '10');
    const columns = parseInt(styleMap.get('--masonry-columns')?.toString() ?? '3');
    const columnWidth = (constraints.fixedInlineSize - gap * (columns - 1)) / columns;
    const columnHeights = new Array(columns).fill(0);

    const childFragments = await Promise.all(
      children.map((child: any) => child.layoutNextFragment({ fixedInlineSize: columnWidth })),
    );

    for (const fragment of childFragments) {
      const shortestColumn = columnHeights.indexOf(Math.min(...columnHeights));
      fragment.inlineOffset = shortestColumn * (columnWidth + gap);
      fragment.blockOffset = columnHeights[shortestColumn];
      columnHeights[shortestColumn] += fragment.blockSize + gap;
    }

    return { childFragments, autoBlockSize: Math.max(...columnHeights) };
  }
}

registerLayout('masonry', MasonryLayout);

小结
    

  • Worklet 是轻量级脚本，运行在浏览器渲染管线的特定阶段
    • 

  • Paint Worklet 自定义 CSS 绘制逻辑，替代 canvas 生成的背景图
    • 

  • Animation Worklet 在合成线程运行动画，不受主线程阻塞影响
    • 

  • Audio Worklet 在音频线程处理音频，替代废弃的 ScriptProcessorNode
    • 

  • Layout Worklet 定义自定义布局算法（实验性），是 Houdini 的终极目标
    •
