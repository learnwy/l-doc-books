Web Workers 多线程

为什么需要 Web Workers

JavaScript 在浏览器中是单线程执行的，CPU 密集型任务会阻塞主线程，导致页面卡顿、交互无响应。Web Workers 允许在后台线程中运行 JavaScript，实现真正的并行计算而不阻塞 UI。



创建和使用 Dedicated Worker
Dedicated Worker（专用 Worker） 只能被创建它的脚本访问，一对一通信。


const worker = new Worker('/workers/compute.ts', { type: 'module' });

worker.postMessage({ type: 'CALCULATE', data: [1, 2, 3, 4, 5] });

worker.onmessage = (event: MessageEvent) => {
  console.log('Result:', event.data);
};

worker.onerror = (error: ErrorEvent) => {
  console.error('Worker error:', error.message);
};

worker.terminate();
Worker 内部代码：


self.onmessage = (event: MessageEvent) => {
  const { type, data } = event.data;

  switch (type) {
    case 'CALCULATE': {
      const result = data.reduce((sum: number, n: number) => sum + n, 0);
      self.postMessage({ type: 'RESULT', result });
      break;
    }
  }
};

消息传递机制
Worker 和主线程之间通过 postMessage 通信，数据默认使用结构化克隆（深拷贝）。


interface WorkerRequest {
  id: number;
  type: string;
  payload: unknown;
}

interface WorkerResponse {
  id: number;
  result?: unknown;
  error?: string;
}

class WorkerRPC {
  private worker: Worker;
  private pending = new Map<number, { resolve: (v: unknown) => void; reject: (e: Error) => void }>();
  private nextId = 0;

  constructor(workerUrl: string) {
    this.worker = new Worker(workerUrl, { type: 'module' });
    this.worker.onmessage = (event: MessageEvent<WorkerResponse>) => {
      const { id, result, error } = event.data;
      const handler = this.pending.get(id);
      if (handler) {
        this.pending.delete(id);
        if (error) {
          handler.reject(new Error(error));
        } else {
          handler.resolve(result);
        }
      }
    };
  }

  call<T>(type: string, payload: unknown): Promise<T> {
    const id = this.nextId++;
    return new Promise((resolve, reject) => {
      this.pending.set(id, { resolve: resolve as (v: unknown) => void, reject });
      this.worker.postMessage({ id, type, payload });
    });
  }

  terminate(): void {
    this.worker.terminate();
    for (const handler of this.pending.values()) {
      handler.reject(new Error('Worker terminated'));
    }
    this.pending.clear();
  }
}


Transferable Objects
对于大型数据（如 ArrayBuffer），结构化克隆的开销很大。Transferable Objects 可以将数据的所有权从一个线程转移到另一个线程，实现零拷贝传输。


const buffer = new ArrayBuffer(1024 * 1024 * 10);
console.log('Before transfer:', buffer.byteLength);

worker.postMessage({ type: 'PROCESS', buffer }, [buffer]);
console.log('After transfer:', buffer.byteLength);

function createLargeDataset(size: number): Float64Array {
  const data = new Float64Array(size);
  for (let i = 0; i < size; i++) {
    data[i] = Math.random();
  }
  return data;
}

const dataset = createLargeDataset(1_000_000);
worker.postMessage({ type: 'ANALYZE', data: dataset.buffer }, [dataset.buffer]);

SharedArrayBuffer
SharedArrayBuffer 允许多个线程共享同一块内存，配合 Atomics API 实现线程安全的并发操作。


const sharedBuffer = new SharedArrayBuffer(1024);
const sharedArray = new Int32Array(sharedBuffer);

worker.postMessage({ type: 'SHARED', buffer: sharedBuffer });

Atomics.store(sharedArray, 0, 42);

const value = Atomics.load(sharedArray, 0);
console.log('Shared value:', value);

Atomics.add(sharedArray, 1, 10);

Atomics.wait(sharedArray, 0, 0);
Atomics.notify(sharedArray, 0, 1);

Worker 池模式
对于频繁的计算任务，创建 Worker 池可以复用线程，避免反复创建销毁的开销。


class WorkerPool {
  private workers: Worker[] = [];
  private queue: Array<{ data: unknown; resolve: (v: unknown) => void; reject: (e: Error) => void }> = [];
  private idle: Worker[] = [];

  constructor(workerUrl: string, poolSize: number) {
    for (let i = 0; i < poolSize; i++) {
      const worker = new Worker(workerUrl, { type: 'module' });
      this.workers.push(worker);
      this.idle.push(worker);
    }
  }

  execute<T>(data: unknown): Promise<T> {
    return new Promise((resolve, reject) => {
      const worker = this.idle.pop();
      if (worker) {
        this.runTask(worker, data, resolve as (v: unknown) => void, reject);
      } else {
        this.queue.push({ data, resolve: resolve as (v: unknown) => void, reject });
      }
    });
  }

  private runTask(worker: Worker, data: unknown, resolve: (v: unknown) => void, reject: (e: Error) => void): void {
    worker.onmessage = (event: MessageEvent) => {
      resolve(event.data);
      const next = this.queue.shift();
      if (next) {
        this.runTask(worker, next.data, next.resolve, next.reject);
      } else {
        this.idle.push(worker);
      }
    };
    worker.onerror = (error: ErrorEvent) => {
      reject(new Error(error.message));
    };
    worker.postMessage(data);
  }

  terminate(): void {
    this.workers.forEach((w) => w.terminate());
  }
}

const pool = new WorkerPool('/workers/compute.js', navigator.hardwareConcurrency || 4);


小结
    

  • Web Workers 在后台线程运行 JS，不阻塞主线程的 UI 渲染和事件处理
    • 

  • Worker 无法访问 DOM，通过 postMessage 与主线程通信，数据默认深拷贝
    • 

  • Transferable Objects 实现零拷贝传输，适合大型 ArrayBuffer
    • 

  • SharedArrayBuffer + Atomics 实现线程间共享内存和原子操作
    • 

  • Worker 池模式可复用线程，避免频繁创建销毁的开销
