事件循环

JavaScript 的并发模型

JavaScript 是单线程语言，同一时间只能执行一个任务。事件循环（Event Loop）是浏览器实现异步编程的核心机制，它协调调用栈、任务队列和微任务队列，使 JS 能够处理异步操作而不阻塞主线程。



调用栈（Call Stack）
调用栈是一个 LIFO（后进先出）数据结构，跟踪当前正在执行的函数。每次函数调用会压入一个栈帧，函数返回时弹出。


function multiply(a: number, b: number): number {
  return a * b;
}

function square(n: number): number {
  return multiply(n, n);
}

function printSquare(n: number): void {
  const result = square(n);
  console.log(result);
}

printSquare(4);

requestAnimationFrame
requestAnimationFrame（rAF）在浏览器下一次重绘前执行回调，是实现流畅动画的最佳选择。


function animate(element: HTMLElement): void {
  let start: number | null = null;
  const duration = 1000;
  const distance = 300;

  function step(timestamp: number): void {
    if (!start) start = timestamp;
    const progress = Math.min((timestamp - start) / duration, 1);
    const eased = 1 - Math.pow(1 - progress, 3);

    element.style.transform = `translateX(${eased * distance}px)`;

    if (progress < 1) {
      requestAnimationFrame(step);
    }
  }

  requestAnimationFrame(step);
}

requestIdleCallback
requestIdleCallback（rIC）在浏览器空闲时执行低优先级任务，不影响关键渲染和用户交互。


interface IdleDeadline {
  didTimeout: boolean;
  timeRemaining(): number;
}

function processChunk(deadline: IdleDeadline): void {
  while ((deadline.timeRemaining() > 0 || deadline.didTimeout) && tasks.length > 0) {
    const task = tasks.shift()!;
    task();
  }

  if (tasks.length > 0) {
    requestIdleCallback(processChunk, { timeout: 2000 });
  }
}

const tasks: Array<() => void> = [];

function scheduleWork(task: () => void): void {
  tasks.push(task);
  requestIdleCallback(processChunk, { timeout: 2000 });
}


提示： requestIdleCallback 的 timeout 参数可以设置最大等待时间。如果浏览器一直繁忙，超过 timeout 后回调会被强制执行（deadline.didTimeout === true）。

小结
    

  • 事件循环是 JavaScript 异步编程的核心，协调调用栈、宏任务队列和微任务队列
    • 

  • 微任务（Promise、queueMicrotask）优先于宏任务（setTimeout、setInterval）执行
    • 

  • 每轮循环的完整顺序：宏任务 → 微任务 → rAF → 渲染 → rIC
    • 

  • requestAnimationFrame 适合动画，自动对齐帧刷新；requestIdleCallback 适合低优先级后台任务
    • 

  • 理解执行顺序对于调试异步代码、避免竞态条件和性能优化至关重要
