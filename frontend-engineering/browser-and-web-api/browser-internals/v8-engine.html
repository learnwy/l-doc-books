V8 引擎

V8 是什么

V8 是 Google 开发的高性能 JavaScript 和 WebAssembly 引擎，用 C++ 编写，应用于 Chrome 和 Node.js。它将 JavaScript 编译为机器码执行，而非传统的解释执行，是现代浏览器性能的核心支撑。



解析阶段：从源码到 AST
V8 将 JS 源码的处理分为两个步骤：词法分析（Tokenization） 和 语法分析（Parsing）。


const code = `function add(a, b) { return a + b; }`;

Ignition 解释器
Ignition 是 V8 的字节码解释器。AST 被编译为紧凑的字节码（Bytecode），由 Ignition 的寄存器虚拟机执行。


function sum(arr: number[]): number {
  let total = 0;
  for (const num of arr) {
    total += num;
  }
  return total;
}
对应的字节码（简化）：


LdaZero                  // 将 0 加载到累加器
Star r0                  // 存储到寄存器 r0 (total)
ForInPrepare r1          // 准备 for-of 迭代
ForInNext r1, r2         // 获取下一个元素
Add r0, r2               // total += num
Star r0                  // 更新 total
JumpIfNotHole @loop      // 继续循环
Return r0                // 返回 total

TurboFan 优化编译器
当 Ignition 发现某段代码被反复执行（热点代码），会将其交给 TurboFan 进行 JIT（Just-In-Time）编译，生成高度优化的机器码。


function multiply(a: number, b: number): number {
  return a * b;
}

for (let i = 0; i < 100_000; i++) {
  multiply(i, i + 1);
}

multiply('hello' as any, 'world' as any);


提示： 传入与之前不同类型的参数会触发去优化（Deoptimization），V8 会丢弃优化后的机器码，回退到字节码执行。保持函数参数类型稳定是性能优化的关键。






隐藏类（Hidden Classes）
V8 使用隐藏类（Hidden Classes / Maps） 来优化对象属性的访问。每个对象都有一个隐藏类，描述其属性的布局和偏移量。


class Point {
  x: number;
  y: number;
  constructor(x: number, y: number) {
    this.x = x;
    this.y = y;
  }
}

const p1 = new Point(1, 2);
const p2 = new Point(3, 4);
隐藏类失效的常见原因：


const obj1 = { a: 1, b: 2 };
const obj2 = { b: 2, a: 1 };

const obj3: Record<string, number> = {};
obj3.x = 1;
obj3.y = 2;

const obj4: Record<string, number> = {};
obj4.y = 2;
obj4.x = 1;

interface Shape {
  area(): number;
}

class Circle implements Shape {
  constructor(public radius: number) {}
  area(): number {
    return Math.PI * this.radius ** 2;
  }
}

class Square implements Shape {
  constructor(public side: number) {}
  area(): number {
    return this.side ** 2;
  }
}

function totalArea(shapes: Shape[]): number {
  let sum = 0;
  for (const shape of shapes) {
    sum += shape.area();
  }
  return sum;
}

const cache = new WeakMap<object, string>();

function process(obj: object): string {
  if (cache.has(obj)) {
    return cache.get(obj)!;
  }
  const result = JSON.stringify(obj);
  cache.set(obj, result);
  return result;
}


提示： 使用 WeakMap 和 WeakRef 可以避免意外阻止垃圾回收。在 Chrome DevTools 的 Memory 面板中可以录制堆快照（Heap Snapshot）来排查内存泄漏。






小结
    

  • V8 采用 Ignition 解释器 + TurboFan 优化编译器 的双层架构
    • 

  • 源码经过 解析 → AST → 字节码 → JIT 优化机器码 的编译流水线
    • 

  • 隐藏类使对象属性访问接近 C++ 结构体的速度，保持属性初始化顺序一致至关重要
    • 

  • 内联缓存加速属性查找，保持单态（Monomorphic）状态可获得最佳性能
    • 

  • 分代垃圾回收高效管理内存，使用 WeakMap/WeakRef 避免内存泄漏
