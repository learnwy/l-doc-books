渲染流水线

从 HTML 到像素

当浏览器收到 HTML 响应后，需要经过一系列步骤将文本内容转化为屏幕上的像素。这个过程称为渲染流水线（Rendering Pipeline），也叫关键渲染路径（Critical Rendering Path）。



各阶段详解
1. DOM 构建
HTML 解析器将字节流转换为 Token，再构建 DOM 树。这是一个增量过程，解析器遇到 <script> 标签时会暂停。


2. CSSOM 构建
CSS 解析器将样式表解析为 CSSOM（CSS Object Model）。CSSOM 构建会阻塞渲染——浏览器必须等所有 CSS 加载完毕才开始布局。


3. 渲染树构建
将 DOM 和 CSSOM 合并，生成渲染树。display: none 的元素不会进入渲染树，visibility: hidden 的元素会保留。


4. 布局（Layout / Reflow）
计算每个节点的精确位置和尺寸。布局从根节点开始，递归计算所有元素的几何信息。


5. 绘制（Paint）
将渲染树中的节点转换为绘制指令（Paint Records），记录绘制顺序和操作。


6. 合成（Composite）
将不同图层的绘制结果合成到一起，由 GPU 最终输出到屏幕。


const observer = new PerformanceObserver((list) => {
  for (const entry of list.getEntries()) {
    console.log(`${entry.name}: ${entry.startTime.toFixed(2)}ms`);
  }
});
observer.observe({ type: 'paint', buffered: true });


Reflow 与 Repaint
Reflow（回流/重排） 和 Repaint（重绘） 是渲染流水线中最常触发的性能瓶颈。

element.style.width = '200px';

const computedHeight = element.offsetHeight;

element.style.width = '200px';
element.style.height = '100px';

requestAnimationFrame(() => {
  element.style.width = '200px';
  element.style.height = '100px';
  element.style.margin = '10px';
});


提示： 读取 offsetHeight、getBoundingClientRect() 等几何属性会强制浏览器执行同步布局（Forced Synchronous Layout），应尽量避免在修改样式后立即读取。






强制同步布局与布局抖动
强制同步布局（Forced Synchronous Layout） 发生在 JS 修改样式后立即读取几何属性时。布局抖动（Layout Thrashing） 是在循环中反复触发强制同步布局。


const items = document.querySelectorAll<HTMLElement>('.item');

for (const item of items) {
  const width = item.offsetWidth;
  item.style.width = `${width * 2}px`;
}

const widths: number[] = [];
for (const item of items) {
  widths.push(item.offsetWidth);
}
for (let i = 0; i < items.length; i++) {
  items[i].style.width = `${widths[i] * 2}px`;
}

card.style.willChange = 'transform';

提示： 过多的合成层会占用大量 GPU 内存。使用 Chrome DevTools 的 Layers 面板检查图层数量，避免不必要的层爆炸（Layer Explosion）。






渲染流水线优化策略
function batchDOMUpdates(updates: Array<() => void>): void {
  const fragment = document.createDocumentFragment();

  requestAnimationFrame(() => {
    for (const update of updates) {
      update();
    }
  });
}

function useContainment(element: HTMLElement): void {
  element.style.contain = 'layout style paint';
}

function smoothAnimation(element: HTMLElement, x: number, y: number): void {
  element.style.transform = `translate(${x}px, ${y}px)`;
}

小结
    

  • 渲染流水线包括 DOM → CSSOM → 渲染树 → 布局 → 绘制 → 合成 六个关键步骤
    • 

  • Reflow 触发完整重排，开销最大；Repaint 只重绘外观；transform/opacity 仅触发合成
    • 

  • 强制同步布局和布局抖动是常见性能陷阱，应先批量读取再批量写入
    • 

  • 合理使用图层提升（will-change、transform）可将动画移至合成线程
    • 

  • CSS contain 和 content-visibility 是现代浏览器提供的渲染优化利器
