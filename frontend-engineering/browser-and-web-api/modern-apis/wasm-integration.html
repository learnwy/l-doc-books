WebAssembly 集成

什么是 WebAssembly

WebAssembly (Wasm) 是一种低级的二进制指令格式，设计为可在浏览器中以接近原生的速度运行。它不是用来替代 JavaScript 的，而是作为补充——将 C/C++/Rust 等语言编译后的代码带入 Web 平台。



编译与实例化
WebAssembly 模块的加载分为编译（Compile） 和实例化（Instantiate） 两个阶段。


async function loadWasm(url: string): Promise<WebAssembly.Instance> {
  const response = await fetch(url);
  const buffer = await response.arrayBuffer();
  const { instance } = await WebAssembly.instantiate(buffer);
  return instance;
}

async function loadWasmStreaming(url: string): Promise<WebAssembly.Instance> {
  const { instance } = await WebAssembly.instantiateStreaming(fetch(url));
  return instance;
}

async function loadWasmWithImports(url: string, imports: WebAssembly.Imports): Promise<WebAssembly.Instance> {
  const response = await fetch(url);
  const { instance } = await WebAssembly.instantiateStreaming(response, imports);
  return instance;
}

提示： instantiateStreaming 要求服务器返回正确的 MIME 类型 application/wasm，否则会失败。开发时需配置服务器或使用 instantiate(buffer) 兜底。






JS 与 Wasm 交互
interface WasmExports {
  add: (a: number, b: number) => number;
  fibonacci: (n: number) => number;
  memory: WebAssembly.Memory;
  allocate: (size: number) => number;
  deallocate: (ptr: number, size: number) => void;
}

async function useMathModule(): Promise<void> {
  const instance = await loadWasmStreaming('/wasm/math.wasm');
  const exports = instance.exports as unknown as WasmExports;

  console.log('add(3, 4) =', exports.add(3, 4));
  console.log('fibonacci(30) =', exports.fibonacci(30));
}
传递复杂数据需要通过线性内存（Linear Memory）：


function passArrayToWasm(exports: WasmExports, data: Float64Array): { ptr: number; length: number } {
  const byteLength = data.byteLength;
  const ptr = exports.allocate(byteLength);

  const memory = new Float64Array(exports.memory.buffer, ptr, data.length);
  memory.set(data);

  return { ptr, length: data.length };
}

function readArrayFromWasm(exports: WasmExports, ptr: number, length: number): Float64Array {
  return new Float64Array(exports.memory.buffer, ptr, length);
}

function readStringFromWasm(exports: WasmExports, ptr: number, length: number): string {
  const bytes = new Uint8Array(exports.memory.buffer, ptr, length);
  return new TextDecoder().decode(bytes);
}


内存共享
Wasm 的线性内存（WebAssembly.Memory）是一个可增长的 ArrayBuffer，JS 和 Wasm 共享访问。


const memory = new WebAssembly.Memory({
  initial: 256,
  maximum: 512,
  shared: true,
});

const imports: WebAssembly.Imports = {
  env: {
    memory,
    log: (ptr: number, len: number) => {
      const bytes = new Uint8Array(memory.buffer, ptr, len);
      console.log(new TextDecoder().decode(bytes));
    },
    now: () => performance.now(),
  },
};

const { instance } = await WebAssembly.instantiateStreaming(fetch('/wasm/app.wasm'), imports);

Rust 编译到 Wasm
Rust 是 Wasm 开发的首选语言之一，wasm-pack 提供了完整的工具链。


import init, { process_image, greet } from './pkg/my_wasm_lib.js';

async function main(): Promise<void> {
  await init();

  const greeting = greet('World');
  console.log(greeting);

  const canvas = document.querySelector<HTMLCanvasElement>('#canvas')!;
  const ctx = canvas.getContext('2d')!;
  const imageData = ctx.getImageData(0, 0, canvas.width, canvas.height);

  const result = process_image(imageData.data, canvas.width, canvas.height);

  const processedData = new ImageData(new Uint8ClampedArray(result), canvas.width, canvas.height);
  ctx.putImageData(processedData, 0, 0);
}

main();


性能对比
function jsFibonacci(n: number): number {
  if (n <= 1) return n;
  return jsFibonacci(n - 1) + jsFibonacci(n - 2);
}

async function benchmark(): Promise<void> {
  const wasmInstance = await loadWasmStreaming('/wasm/math.wasm');
  const wasmFib = (wasmInstance.exports as any).fibonacci as (n: number) => number;

  const n = 40;

  console.time('JS fibonacci');
  const jsResult = jsFibonacci(n);
  console.timeEnd('JS fibonacci');

  console.time('Wasm fibonacci');
  const wasmResult = wasmFib(n);
  console.timeEnd('Wasm fibonacci');

  console.log('JS result:', jsResult, 'Wasm result:', wasmResult);
}

提示： JS→Wasm 和 Wasm→JS 的函数调用有边界成本。频繁的小函数调用可能抵消 Wasm 的计算优势。应将尽量多的计算逻辑放在 Wasm 侧，减少跨边界调用。






小结
    

  • WebAssembly 是浏览器中的低级二进制格式，以接近原生的速度运行
    • 

  • 通过 instantiateStreaming 可边下载边编译，实现最快的加载
    • 

  • JS 和 Wasm 通过函数调用传递数字，通过线性内存传递复杂数据
    • 

  • Rust 是 Wasm 开发的首选语言，wasm-pack 提供完整工具链
    • 

  • Wasm 适合计算密集型任务（图像处理、加密、物理模拟），DOM 操作仍应使用 JS
    •
