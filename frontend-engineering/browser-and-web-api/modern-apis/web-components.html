Web Components 原生组件

什么是 Web Components

Web Components 是一组浏览器原生 API，允许创建可复用的自定义 HTML 元素。它由三项核心技术组成：Custom Elements、Shadow DOM 和 HTML Templates。



Custom Elements
Custom Elements 允许定义新的 HTML 标签及其行为。


class UserCard extends HTMLElement {
  private shadow: ShadowRoot;

  static get observedAttributes(): string[] {
    return ['name', 'email', 'avatar'];
  }

  constructor() {
    super();
    this.shadow = this.attachShadow({ mode: 'open' });
  }

  connectedCallback(): void {
    this.render();
  }

  disconnectedCallback(): void {
    console.log('UserCard removed from DOM');
  }

  attributeChangedCallback(name: string, oldValue: string | null, newValue: string | null): void {
    if (oldValue !== newValue) {
      this.render();
    }
  }

  adoptedCallback(): void {
    console.log('UserCard moved to new document');
  }

  private render(): void {
    const name = this.getAttribute('name') ?? 'Unknown';
    const email = this.getAttribute('email') ?? '';
    const avatar = this.getAttribute('avatar') ?? '';

    this.shadow.innerHTML = `
      <style>
        :host {
          display: block;
          border: 1px solid var(--border-color, #e5e7eb);
          border-radius: 8px;
          padding: 16px;
          font-family: system-ui, sans-serif;
        }
        :host([highlighted]) {
          border-color: var(--highlight-color, #3b82f6);
        }
        .card { display: flex; align-items: center; gap: 12px; }
        .avatar {
          width: 48px; height: 48px;
          border-radius: 50%;
          object-fit: cover;
        }
        .info h3 { margin: 0 0 4px; }
        .info p { margin: 0; opacity: 0.7; font-size: 0.875rem; }
      </style>
      <div class="card">
        ${avatar ? `<img class="avatar" src="${avatar}" alt="${name}">` : ''}
        <div class="info">
          <h3>${name}</h3>
          <p>${email}</p>
          <slot></slot>
        </div>
      </div>
    `;
  }
}

customElements.define('user-card', UserCard);

Shadow DOM
Shadow DOM 提供了 DOM 和样式的封装，组件内部的样式不会泄漏到外部，外部样式也不会影响组件内部。


class StyledButton extends HTMLElement {
  constructor() {
    super();
    const shadow = this.attachShadow({ mode: 'open' });

    const style = document.createElement('style');
    style.textContent = `
      :host {
        display: inline-block;
      }
      button {
        padding: 8px 16px;
        border: none;
        border-radius: 4px;
        cursor: pointer;
        font-size: 14px;
        background: var(--btn-bg, #3b82f6);
        color: var(--btn-color, white);
        transition: opacity 0.2s;
      }
      button:hover { opacity: 0.9; }
      button:active { opacity: 0.8; }
      :host([disabled]) button {
        opacity: 0.5;
        cursor: not-allowed;
      }
    `;

    const button = document.createElement('button');
    button.appendChild(document.createElement('slot'));

    shadow.appendChild(style);
    shadow.appendChild(button);
  }
}

customElements.define('styled-button', StyledButton);

说明

HTML Templates 与 Slots
<template> 元素定义可复用的 DOM 片段，<slot> 元素定义内容投射点。


const template = document.createElement('template');
template.innerHTML = `
  <style>
    .dialog {
      position: fixed;
      inset: 0;
      display: flex;
      align-items: center;
      justify-content: center;
    }
    .dialog-overlay {
      position: absolute;
      inset: 0;
      background: rgba(0, 0, 0, 0.5);
    }
    .dialog-content {
      position: relative;
      background: var(--dialog-bg, white);
      border-radius: 12px;
      padding: 24px;
      min-width: 320px;
      max-width: 90vw;
    }
    .dialog-header { font-size: 1.25rem; font-weight: 600; margin-bottom: 16px; }
    .dialog-footer { margin-top: 16px; display: flex; justify-content: flex-end; gap: 8px; }
  </style>
  <div class="dialog" role="dialog">
    <div class="dialog-overlay"></div>
    <div class="dialog-content">
      <div class="dialog-header">
        <slot name="header">默认标题</slot>
      </div>
      <div class="dialog-body">
        <slot>默认内容</slot>
      </div>
      <div class="dialog-footer">
        <slot name="footer"></slot>
      </div>
    </div>
  </div>
`;

class ModalDialog extends HTMLElement {
  constructor() {
    super();
    const shadow = this.attachShadow({ mode: 'open' });
    shadow.appendChild(template.content.cloneNode(true));

    const overlay = shadow.querySelector('.dialog-overlay')!;
    overlay.addEventListener('click', () => {
      this.dispatchEvent(new CustomEvent('close', { bubbles: true }));
    });
  }
}

customElements.define('modal-dialog', ModalDialog);
使用方式：


<modal-dialog>
  <span slot="header">确认操作</span>
  <p>你确定要执行此操作吗？</p>
  <div slot="footer">
    <styled-button>取消</styled-button>
    <styled-button>确认</styled-button>
  </div>
</modal-dialog>

class TabPanel extends HTMLElement {
  constructor() {
    super();
    const shadow = this.attachShadow({ mode: 'open' });

    shadow.innerHTML = `
      <style>
        :host { display: block; }
        .tabs { display: flex; border-bottom: 1px solid var(--border-color, #e5e7eb); }
        ::slotted([slot="tab"]) {
          padding: 8px 16px;
          cursor: pointer;
          border-bottom: 2px solid transparent;
        }
        ::slotted([slot="tab"][active]) {
          border-bottom-color: var(--active-color, #3b82f6);
        }
        .panels { padding: 16px; }
      </style>
      <div class="tabs">
        <slot name="tab"></slot>
      </div>
      <div class="panels">
        <slot name="panel"></slot>
      </div>
    `;
  }
}

customElements.define('tab-panel', TabPanel);


提示： ::slotted() 伪元素只能选择被投射到 slot 中的直接子元素，无法穿透选择更深层的后代。如需更精细的样式控制，可使用 CSS 自定义属性（--var）从外部传入。






小结
    

  • Web Components 由 Custom Elements、Shadow DOM 和 HTML Templates 三项技术组成
    • 

  • Custom Elements 通过 customElements.define() 注册自定义标签，支持生命周期回调
    • 

  • Shadow DOM 提供样式和 DOM 封装，通过 CSS 自定义属性与外部通信
    • 

  • Slots 实现内容投射，支持命名 slot 和默认内容
    • 

  • Web Components 是框架无关的原生组件化方案，可与任何框架协同使用
    •
