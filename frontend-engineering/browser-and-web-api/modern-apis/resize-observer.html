Resize Observer 尺寸观察器

核心概念

Resize Observer 监测任意元素的尺寸变化，取代只能监听视口的 window.resize，是组件级响应式（按容器宽度而非视口宽度布局）与 Canvas/图表自适应的最佳方案。它支持 content-box、border-box、device-pixel-content-box 三种观察模式，回调在 Layout 之后、Paint 之前触发，需注意避免在回调里再次改变尺寸而形成循环。

什么是 Resize Observer

Resize Observer API 允许监测元素尺寸的变化。与 window.resize 事件只能监听视口大小变化不同，Resize Observer 可以精确监测任意元素的尺寸变动，是实现响应式组件的理想工具。

基本用法

const observer = new ResizeObserver((entries: ResizeObserverEntry[]) => {
  for (const entry of entries) {
    const { width, height } = entry.contentRect;
    console.log(`Element resized: ${width}x${height}`);

    if (entry.contentBoxSize) {
      const boxSize = entry.contentBoxSize[0];
      console.log(`Content box: ${boxSize.inlineSize}x${boxSize.blockSize}`);
    }

    if (entry.borderBoxSize) {
      const boxSize = entry.borderBoxSize[0];
      console.log(`Border box: ${boxSize.inlineSize}x${boxSize.blockSize}`);
    }
  }
});

const element = document.querySelector('.responsive-widget')!;
observer.observe(element);

observer.observe(element, { box: 'border-box' });

观察模式：

box 选项 说明
content-box 内容区域尺寸（默认）
border-box 包含 padding 和 border
device-pixel-content-box 设备像素级精度

元素尺寸监控

class ElementSizeMonitor {
  private observer: ResizeObserver;
  private callbacks = new Map<Element, (size: { width: number; height: number }) => void>();

  constructor() {
    this.observer = new ResizeObserver((entries) => {
      for (const entry of entries) {
        const callback = this.callbacks.get(entry.target);
        if (callback) {
          const { inlineSize, blockSize } = entry.contentBoxSize[0];
          callback({ width: inlineSize, height: blockSize });
        }
      }
    });
  }

  watch(element: Element, callback: (size: { width: number; height: number }) => void): () => void {
    this.callbacks.set(element, callback);
    this.observer.observe(element);

    return () => {
      this.callbacks.delete(element);
      this.observer.unobserve(element);
    };
  }

  destroy(): void {
    this.observer.disconnect();
    this.callbacks.clear();
  }
}

const monitor = new ElementSizeMonitor();
const unwatch = monitor.watch(document.querySelector('.chart-container')!, (size) => {
  console.log(`Chart container: ${size.width}x${size.height}`);
});

响应式组件

Resize Observer 可以实现组件级别的响应式，不依赖视口宽度，而是根据容器宽度调整布局。

interface Breakpoint {
  name: string;
  minWidth: number;
}

class ResponsiveComponent {
  private observer: ResizeObserver;
  private breakpoints: Breakpoint[];
  private currentBreakpoint = '';

  constructor(
    private element: HTMLElement,
    breakpoints: Breakpoint[],
    private onBreakpointChange: (name: string) => void,
  ) {
    this.breakpoints = breakpoints.sort((a, b) => b.minWidth - a.minWidth);

    this.observer = new ResizeObserver(([entry]) => {
      const width = entry.contentRect.width;
      const bp = this.breakpoints.find((b) => width >= b.minWidth) ?? { name: 'xs' };

      if (bp.name !== this.currentBreakpoint) {
        this.currentBreakpoint = bp.name;

        for (const b of this.breakpoints) {
          this.element.classList.remove(`bp-${b.name}`);
        }
        this.element.classList.remove('bp-xs');
        this.element.classList.add(`bp-${bp.name}`);

        this.onBreakpointChange(bp.name);
      }
    });

    this.observer.observe(element);
  }

  destroy(): void {
    this.observer.disconnect();
  }
}

new ResponsiveComponent(
  document.querySelector('.card-grid')!,
  [
    { name: 'lg', minWidth: 800 },
    { name: 'md', minWidth: 500 },
    { name: 'sm', minWidth: 300 },
  ],
  (bp) => console.log(`Layout changed to: ${bp}`),
);

Canvas / Chart 自适应

Resize Observer 非常适合让 Canvas 或图表组件跟随容器自动调整尺寸：

class ResponsiveCanvas {
  private canvas: HTMLCanvasElement;
  private ctx: CanvasRenderingContext2D;
  private observer: ResizeObserver;
  private drawCallback: (ctx: CanvasRenderingContext2D, width: number, height: number) => void;

  constructor(
    container: HTMLElement,
    drawCallback: (ctx: CanvasRenderingContext2D, width: number, height: number) => void,
  ) {
    this.drawCallback = drawCallback;
    this.canvas = document.createElement('canvas');
    this.canvas.style.width = '100%';
    this.canvas.style.height = '100%';
    container.appendChild(this.canvas);
    this.ctx = this.canvas.getContext('2d')!;

    this.observer = new ResizeObserver(([entry]) => {
      const dpr = window.devicePixelRatio || 1;
      const width = entry.contentRect.width;
      const height = entry.contentRect.height;

      this.canvas.width = width * dpr;
      this.canvas.height = height * dpr;
      this.ctx.scale(dpr, dpr);

      this.drawCallback(this.ctx, width, height);
    });

    this.observer.observe(container);
  }

  redraw(): void {
    const width = this.canvas.width / (window.devicePixelRatio || 1);
    const height = this.canvas.height / (window.devicePixelRatio || 1);
    this.ctx.clearRect(0, 0, width, height);
    this.drawCallback(this.ctx, width, height);
  }

  destroy(): void {
    this.observer.disconnect();
    this.canvas.remove();
  }
}
场景 传统方案 Resize Observer 方案
图表自适应 window.resize + debounce 精确响应容器变化
响应式组件 CSS media query 基于容器宽度
Canvas 调整 手动监听窗口变化 自动跟随容器
虚拟列表 固定高度 动态计算可见行数

提示： Resize Observer 的回调在 Layout 之后、Paint 之前触发。在回调中修改元素尺寸可能导致无限循环，浏览器会在一帧的预算用尽后延迟到下一帧处理，并触发 ResizeObserver loop limit exceeded 错误。

小结

  • Resize Observer 监测任意元素的尺寸变化，替代 window.resize 事件
  • 支持 content-box、border-box、device-pixel-content-box 三种观察模式
  • 适合实现组件级响应式布局，不依赖视口宽度而是容器宽度
  • 是 Canvas/图表自适应容器尺寸的最佳方案
  • 回调在 Layout 后 Paint 前触发，注意避免无限循环
