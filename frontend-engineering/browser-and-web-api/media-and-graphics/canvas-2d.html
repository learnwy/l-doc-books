Canvas 2D 画布绘图

Canvas 基础

Canvas 是 HTML5 提供的绘图 API，通过 <canvas> 元素和 2D 渲染上下文（CanvasRenderingContext2D）实现像素级的图形绘制。Canvas 采用立即模式渲染——绘制命令直接写入像素缓冲区，不保留图形对象。



获取上下文与基本设置
function createCanvas(
  width: number,
  height: number,
): {
  canvas: HTMLCanvasElement;
  ctx: CanvasRenderingContext2D;
} {
  const canvas = document.createElement('canvas');
  const dpr = window.devicePixelRatio || 1;

  canvas.width = width * dpr;
  canvas.height = height * dpr;
  canvas.style.width = `${width}px`;
  canvas.style.height = `${height}px`;

  const ctx = canvas.getContext('2d')!;
  ctx.scale(dpr, dpr);

  return { canvas, ctx };
}

const { canvas, ctx } = createCanvas(800, 600);
document.body.appendChild(canvas);




属性
说明





canvas.width / canvas.height
绘图缓冲区像素尺寸




canvas.style.width / style.height
CSS 显示尺寸




devicePixelRatio
设备像素比（高 DPI 适配）







提示： 为高 DPI 屏幕适配，需将 Canvas 尺寸设为 CSS 尺寸的 devicePixelRatio 倍，再用 ctx.scale() 缩放绘图上下文。






路径操作
Canvas 使用路径（Path）定义形状，然后填充或描边。


function drawShapes(ctx: CanvasRenderingContext2D): void {
  ctx.beginPath();
  ctx.rect(10, 10, 100, 80);
  ctx.fillStyle = '#3b82f6';
  ctx.fill();

  ctx.beginPath();
  ctx.arc(200, 50, 40, 0, Math.PI * 2);
  ctx.strokeStyle = '#ef4444';
  ctx.lineWidth = 3;
  ctx.stroke();

  ctx.beginPath();
  ctx.moveTo(300, 90);
  ctx.lineTo(340, 10);
  ctx.lineTo(380, 90);
  ctx.closePath();
  ctx.fillStyle = '#22c55e';
  ctx.fill();

  ctx.beginPath();
  ctx.moveTo(10, 150);
  ctx.bezierCurveTo(50, 100, 150, 200, 200, 150);
  ctx.strokeStyle = '#8b5cf6';
  ctx.lineWidth = 2;
  ctx.stroke();
}




方法
说明





beginPath()
开始新路径




moveTo(x, y)
移动画笔




lineTo(x, y)
直线




arc(x, y, r, start, end)
圆弧




bezierCurveTo(...)
三次贝塞尔曲线




quadraticCurveTo(...)
二次贝塞尔曲线




closePath()
闭合路径




fill() / stroke()
填充 / 描边







像素操作
Canvas 提供直接操作像素数据的能力，适用于图像滤镜和特效。


function applyGrayscale(ctx: CanvasRenderingContext2D, width: number, height: number): void {
  const imageData = ctx.getImageData(0, 0, width, height);
  const data = imageData.data;

  for (let i = 0; i < data.length; i += 4) {
    const r = data[i];
    const g = data[i + 1];
    const b = data[i + 2];
    const gray = 0.299 * r + 0.587 * g + 0.114 * b;

    data[i] = gray;
    data[i + 1] = gray;
    data[i + 2] = gray;
  }

  ctx.putImageData(imageData, 0, 0);
}

function invertColors(ctx: CanvasRenderingContext2D, width: number, height: number): void {
  const imageData = ctx.getImageData(0, 0, width, height);
  const data = imageData.data;

  for (let i = 0; i < data.length; i += 4) {
    data[i] = 255 - data[i];
    data[i + 1] = 255 - data[i + 1];
    data[i + 2] = 255 - data[i + 2];
  }

  ctx.putImageData(imageData, 0, 0);
}


OffscreenCanvas
OffscreenCanvas 允许在 Web Worker 中进行 Canvas 渲染，不阻塞主线程。


const offscreen = new OffscreenCanvas(800, 600);
const offCtx = offscreen.getContext('2d')!;

offCtx.fillStyle = '#3b82f6';
offCtx.fillRect(0, 0, 800, 600);

const bitmap = offscreen.transferToImageBitmap();

const mainCanvas = document.querySelector<HTMLCanvasElement>('#main')!;
const mainCtx = mainCanvas.getContext('bitmaprenderer')!;
mainCtx.transferFromImageBitmap(bitmap);
Worker 中使用 OffscreenCanvas：


self.onmessage = (event: MessageEvent) => {
  const { canvas, data } = event.data;
  const ctx = canvas.getContext('2d')!;

  renderChart(ctx, data);

  self.postMessage({ done: true });
};

function renderChart(ctx: OffscreenCanvasRenderingContext2D, data: number[]): void {
  const width = ctx.canvas.width;
  const height = ctx.canvas.height;
  const barWidth = width / data.length;
  const maxVal = Math.max(...data);

  data.forEach((val, i) => {
    const barHeight = (val / maxVal) * height;
    ctx.fillStyle = `hsl(${(i / data.length) * 360}, 70%, 50%)`;
    ctx.fillRect(i * barWidth, height - barHeight, barWidth - 2, barHeight);
  });
}

class LayeredCanvas {
  private layers: Array<{ canvas: HTMLCanvasElement; ctx: CanvasRenderingContext2D }> = [];

  constructor(container: HTMLElement, width: number, height: number, layerCount: number) {
    for (let i = 0; i < layerCount; i++) {
      const canvas = document.createElement('canvas');
      canvas.width = width;
      canvas.height = height;
      canvas.style.position = 'absolute';
      canvas.style.left = '0';
      canvas.style.top = '0';
      container.appendChild(canvas);
      this.layers.push({ canvas, ctx: canvas.getContext('2d')! });
    }
  }

  getLayer(index: number): CanvasRenderingContext2D {
    return this.layers[index].ctx;
  }

  clearLayer(index: number): void {
    const { canvas, ctx } = this.layers[index];
    ctx.clearRect(0, 0, canvas.width, canvas.height);
  }
}


小结
    

  • Canvas 采用立即模式绘图，适合游戏、图表、图像处理等像素密集型场景
    • 

  • 高 DPI 适配需将缓冲区设为 CSS 尺寸的 devicePixelRatio 倍
    • 

  • 路径操作是 Canvas 绑图的核心，通过 beginPath → 绘制 → fill/stroke 完成
    • 

  • 像素操作（getImageData/putImageData）可实现自定义滤镜和特效
    • 

  • OffscreenCanvas 支持在 Worker 中渲染，避免阻塞主线程
