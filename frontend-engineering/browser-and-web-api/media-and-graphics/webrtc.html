WebRTC 实时通信

什么是 WebRTC

WebRTC（Web Real-Time Communication） 是浏览器原生支持的实时通信技术，允许浏览器之间直接进行点对点（P2P） 的音视频通话和数据传输，无需经过服务器中转。



核心 API
WebRTC 由三个核心 API 组成：






API
用途





MediaDevices.getUserMedia()
获取摄像头/麦克风媒体流




RTCPeerConnection
建立 P2P 连接、传输媒体和数据




RTCDataChannel
传输任意数据（文本/二进制）





async function getMediaStream(): Promise<MediaStream> {
  const stream = await navigator.mediaDevices.getUserMedia({
    video: {
      width: { ideal: 1280 },
      height: { ideal: 720 },
      frameRate: { ideal: 30 },
    },
    audio: {
      echoCancellation: true,
      noiseSuppression: true,
      sampleRate: 44100,
    },
  });

  return stream;
}

async function getScreenShare(): Promise<MediaStream> {
  return navigator.mediaDevices.getDisplayMedia({
    video: { cursor: 'always' } as MediaTrackConstraints,
    audio: false,
  });
}


信令与连接建立
WebRTC 需要信令（Signaling） 机制来交换连接信息。信令协议不在 WebRTC 规范内，通常使用 WebSocket 实现。


class WebRTCPeer {
  private pc: RTCPeerConnection;
  private dataChannel: RTCDataChannel | null = null;

  constructor(
    private signaling: { send: (msg: unknown) => void },
    private onRemoteStream: (stream: MediaStream) => void,
  ) {
    this.pc = new RTCPeerConnection({
      iceServers: [
        { urls: 'stun:stun.l.google.com:19302' },
        {
          urls: 'turn:turn.example.com:3478',
          username: 'user',
          credential: 'pass',
        },
      ],
    });

    this.pc.onicecandidate = (event) => {
      if (event.candidate) {
        this.signaling.send({ type: 'ice-candidate', candidate: event.candidate });
      }
    };

    this.pc.ontrack = (event) => {
      this.onRemoteStream(event.streams[0]);
    };
  }

  async createOffer(localStream: MediaStream): Promise<void> {
    for (const track of localStream.getTracks()) {
      this.pc.addTrack(track, localStream);
    }

    const offer = await this.pc.createOffer();
    await this.pc.setLocalDescription(offer);
    this.signaling.send({ type: 'offer', sdp: offer });
  }

  async handleOffer(offer: RTCSessionDescriptionInit, localStream: MediaStream): Promise<void> {
    for (const track of localStream.getTracks()) {
      this.pc.addTrack(track, localStream);
    }

    await this.pc.setRemoteDescription(offer);
    const answer = await this.pc.createAnswer();
    await this.pc.setLocalDescription(answer);
    this.signaling.send({ type: 'answer', sdp: answer });
  }

  async handleAnswer(answer: RTCSessionDescriptionInit): Promise<void> {
    await this.pc.setRemoteDescription(answer);
  }

  async addIceCandidate(candidate: RTCIceCandidateInit): Promise<void> {
    await this.pc.addIceCandidate(candidate);
  }

  close(): void {
    this.pc.close();
  }
}


ICE / STUN / TURN
ICE（Interactive Connectivity Establishment） 框架帮助找到两个 peer 之间的最优连接路径。






组件
作用
场景





STUN
发现自身公网 IP 和端口
NAT 穿透




TURN
中继媒体数据
STUN 失败时的备选




ICE
收集和测试所有可能的连接路径
自动选择最优路径







Data Channel
RTCDataChannel 支持在 P2P 连接上传输任意数据，类似 WebSocket 但无需服务器中转。


function createDataChannel(pc: RTCPeerConnection): RTCDataChannel {
  const channel = pc.createDataChannel('messages', {
    ordered: true,
    maxRetransmits: 3,
  });

  channel.onopen = () => {
    console.log('Data channel open');
    channel.send(JSON.stringify({ type: 'hello', timestamp: Date.now() }));
  };

  channel.onmessage = (event: MessageEvent) => {
    console.log('Received:', event.data);
  };

  channel.onclose = () => {
    console.log('Data channel closed');
  };

  return channel;
}

function receiveDataChannel(pc: RTCPeerConnection): void {
  pc.ondatachannel = (event) => {
    const channel = event.channel;
    channel.onmessage = (msg: MessageEvent) => {
      console.log(`[${channel.label}]:`, msg.data);
    };
  };
}




配置
说明





ordered
是否保证消息顺序




maxRetransmits
最大重传次数




maxPacketLifeTime
消息最大存活时间（ms）




negotiated
是否由双方同时创建







提示： Data Channel 基于 SCTP 协议，支持可靠和不可靠两种传输模式。对于游戏等对延迟敏感的场景，可设置 ordered: false, maxRetransmits: 0 实现类似 UDP 的行为。






小结
    

  • WebRTC 实现浏览器间的 P2P 音视频通话和数据传输
    • 

  • 连接建立需要信令服务器交换 SDP 和 ICE 候选信息
    • 

  • STUN 服务器帮助发现公网地址，TURN 服务器在直连失败时中继数据
    • 

  • RTCDataChannel 支持传输任意数据，可配置可靠/不可靠模式
    • 

  • WebRTC 自动处理编解码、回声消除、网络自适应等复杂功能
