Web Audio 音频处理

Web Audio API 概述

Web Audio API 提供了一个强大的音频处理和合成系统。它使用音频节点图（Audio Graph） 模型，将各种音频源、效果器和输出连接成处理管线。



AudioContext 与基本节点
const audioCtx = new AudioContext();

function playTone(frequency: number, duration: number): void {
  const oscillator = audioCtx.createOscillator();
  const gainNode = audioCtx.createGain();

  oscillator.type = 'sine';
  oscillator.frequency.setValueAtTime(frequency, audioCtx.currentTime);

  gainNode.gain.setValueAtTime(0.5, audioCtx.currentTime);
  gainNode.gain.exponentialRampToValueAtTime(0.001, audioCtx.currentTime + duration);

  oscillator.connect(gainNode);
  gainNode.connect(audioCtx.destination);

  oscillator.start(audioCtx.currentTime);
  oscillator.stop(audioCtx.currentTime + duration);
}

加载和播放音频文件
async function loadAudioBuffer(url: string): Promise<AudioBuffer> {
  const response = await fetch(url);
  const arrayBuffer = await response.arrayBuffer();
  return audioCtx.decodeAudioData(arrayBuffer);
}

class AudioPlayer {
  private buffer: AudioBuffer | null = null;
  private source: AudioBufferSourceNode | null = null;
  private gainNode: GainNode;

  constructor(private ctx: AudioContext) {
    this.gainNode = ctx.createGain();
    this.gainNode.connect(ctx.destination);
  }

  async load(url: string): Promise<void> {
    this.buffer = await loadAudioBuffer(url);
  }

  play(offset = 0): void {
    if (!this.buffer) return;

    this.source = this.ctx.createBufferSource();
    this.source.buffer = this.buffer;
    this.source.connect(this.gainNode);
    this.source.start(0, offset);
  }

  stop(): void {
    this.source?.stop();
    this.source = null;
  }

  set volume(value: number) {
    this.gainNode.gain.setValueAtTime(Math.max(0, Math.min(1, value)), this.ctx.currentTime);
  }
}


提示： 浏览器要求 AudioContext 必须在用户交互（如点击事件）后才能创建或恢复。首次使用时可能需要调用 audioCtx.resume()。






滤波器与效果链
function createEffectChain(ctx: AudioContext): {
  input: GainNode;
  output: GainNode;
} {
  const input = ctx.createGain();

  const lowpass = ctx.createBiquadFilter();
  lowpass.type = 'lowpass';
  lowpass.frequency.value = 2000;
  lowpass.Q.value = 1;

  const highpass = ctx.createBiquadFilter();
  highpass.type = 'highpass';
  highpass.frequency.value = 100;

  const compressor = ctx.createDynamicsCompressor();
  compressor.threshold.value = -24;
  compressor.ratio.value = 4;

  const output = ctx.createGain();
  output.gain.value = 0.8;

  input.connect(lowpass);
  lowpass.connect(highpass);
  highpass.connect(compressor);
  compressor.connect(output);

  return { input, output };
}


空间音频（Spatial Audio）
Web Audio API 支持 3D 空间音频，模拟声源在三维空间中的位置。


function create3DAudio(ctx: AudioContext): PannerNode {
  const panner = ctx.createPanner();
  panner.panningModel = 'HRTF';
  panner.distanceModel = 'inverse';
  panner.refDistance = 1;
  panner.maxDistance = 100;
  panner.rolloffFactor = 1;
  panner.coneInnerAngle = 360;
  panner.coneOuterAngle = 360;
  panner.coneOuterGain = 0;

  panner.positionX.value = 0;
  panner.positionY.value = 0;
  panner.positionZ.value = -5;

  return panner;
}

function updateListenerPosition(ctx: AudioContext, x: number, y: number, z: number): void {
  ctx.listener.positionX.value = x;
  ctx.listener.positionY.value = y;
  ctx.listener.positionZ.value = z;
}


音频可视化
AnalyserNode 提供实时频谱和波形数据，可用于创建音频可视化效果。


function createVisualizer(ctx: AudioContext, canvas: HTMLCanvasElement): { analyser: AnalyserNode; start: () => void } {
  const analyser = ctx.createAnalyser();
  analyser.fftSize = 2048;
  const bufferLength = analyser.frequencyBinCount;
  const dataArray = new Uint8Array(bufferLength);

  const canvasCtx = canvas.getContext('2d')!;
  const width = canvas.width;
  const height = canvas.height;

  function drawWaveform(): void {
    requestAnimationFrame(drawWaveform);

    analyser.getByteTimeDomainData(dataArray);

    canvasCtx.fillStyle = '#1a1a2e';
    canvasCtx.fillRect(0, 0, width, height);

    canvasCtx.lineWidth = 2;
    canvasCtx.strokeStyle = '#3b82f6';
    canvasCtx.beginPath();

    const sliceWidth = width / bufferLength;
    let x = 0;

    for (let i = 0; i < bufferLength; i++) {
      const v = dataArray[i] / 128.0;
      const y = (v * height) / 2;
      if (i === 0) canvasCtx.moveTo(x, y);
      else canvasCtx.lineTo(x, y);
      x += sliceWidth;
    }

    canvasCtx.lineTo(width, height / 2);
    canvasCtx.stroke();
  }

  function drawFrequency(): void {
    requestAnimationFrame(drawFrequency);

    analyser.getByteFrequencyData(dataArray);

    canvasCtx.fillStyle = '#1a1a2e';
    canvasCtx.fillRect(0, 0, width, height);

    const barWidth = (width / bufferLength) * 2.5;
    let x = 0;

    for (let i = 0; i < bufferLength; i++) {
      const barHeight = (dataArray[i] / 255) * height;
      const hue = (i / bufferLength) * 360;
      canvasCtx.fillStyle = `hsl(${hue}, 70%, 50%)`;
      canvasCtx.fillRect(x, height - barHeight, barWidth, barHeight);
      x += barWidth + 1;
    }
  }

  return {
    analyser,
    start: drawFrequency,
  };
}

小结
    

  • Web Audio API 使用音频节点图模型，灵活组合音频源和效果器
    • 

  • AudioContext 是入口，需要在用户交互后创建或恢复
    • 

  • 支持滤波、混响、压缩、延迟等丰富的音频效果
    • 

  • 空间音频（PannerNode + HRTF）可模拟 3D 声场
    • 

  • AnalyserNode 提供实时频谱/波形数据，可创建音频可视化
