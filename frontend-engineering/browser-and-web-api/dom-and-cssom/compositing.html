合成

什么是合成

合成（Compositing） 是渲染流水线的最后一步。浏览器将页面分成多个图层（Layers），分别光栅化后由 GPU 合成到一起，最终输出到屏幕。合成发生在合成线程上，不阻塞主线程。



合成线程的工作流程
合成线程是独立于主线程的线程，即使主线程忙于执行 JavaScript，合成线程依然可以处理滚动和合成动画。

图块化（Tiling）
浏览器不会一次性光栅化整个图层，而是将其分割为图块（Tiles），优先光栅化可视区域附近的图块。


interface Tile {
  layerId: number;
  x: number;
  y: number;
  width: number;
  height: number;
  priority: 'highest' | 'high' | 'medium' | 'low';
  rasterized: boolean;
}

function calculateTilePriority(
  tile: { x: number; y: number },
  viewport: { scrollX: number; scrollY: number; width: number; height: number },
): Tile['priority'] {
  const tileCenter = { x: tile.x + 128, y: tile.y + 128 };
  const viewportCenter = {
    x: viewport.scrollX + viewport.width / 2,
    y: viewport.scrollY + viewport.height / 2,
  };

  const distance = Math.hypot(tileCenter.x - viewportCenter.x, tileCenter.y - viewportCenter.y);

  if (distance < viewport.height) return 'highest';
  if (distance < viewport.height * 2) return 'high';
  if (distance < viewport.height * 4) return 'medium';
  return 'low';
}

function checkGPUAcceleration(): void {

  if (gl) {
    const debugInfo = gl.getExtension('WEBGL_debug_renderer_info');
    if (debugInfo) {
      const renderer = gl.getParameter(debugInfo.UNMASKED_RENDERER_WEBGL);
      console.log('GPU Renderer:', renderer);
    }

    const maxTextureSize = gl.getParameter(gl.MAX_TEXTURE_SIZE);

will-change 与图层提升
will-change 属性提前告知浏览器元素即将发生的变化，使浏览器为其创建独立的合成层。


const animatedElement = document.querySelector<HTMLElement>('.animated')!;

animatedElement.addEventListener('mouseenter', () => {
  animatedElement.style.willChange = 'transform, opacity';
});

animatedElement.addEventListener('transitionend', () => {
  animatedElement.style.willChange = 'auto';
});

animatedElement.addEventListener('mouseleave', () => {
  animatedElement.style.willChange = 'auto';
});
使用 will-change 的最佳实践：






做法
说明





动画前设置，动画后移除
避免长期占用 GPU 内存




只用于实际会变化的属性
transform, opacity 最常用




避免在大量元素上使用
每个层都消耗 GPU 内存




不要用 will-change: all
无效且可能适得其反







提示： 在 Chrome DevTools 的 Layers 面板中可以看到每个合成层的内存占用。一个 1000×1000 的图层大约占用 4MB GPU 内存（RGBA，每像素 4 字节）。






transform 和 opacity 的优势
transform 和 opacity 是仅有的两个可以完全在合成线程上处理的属性，不触发布局和绘制。


function slideIn(element: HTMLElement): Animation {
  return element.animate(
    [
      { transform: 'translateX(-100%)', opacity: 0 },
      { transform: 'translateX(0)', opacity: 1 },
    ],
    {
      duration: 300,
      easing: 'cubic-bezier(0.4, 0, 0.2, 1)',
      fill: 'forwards',
    },
  );
}

function fadeOut(element: HTMLElement): Promise<void> {
  return new Promise((resolve) => {
    const animation = element.animate([{ opacity: 1 }, { opacity: 0 }], {
      duration: 200,
      fill: 'forwards',
    });
    animation.onfinish = () => resolve();
  });
}

滚动合成
当用户滚动页面时，合成线程可以独立处理滚动而不需要主线程参与。这就是为什么即使主线程繁忙，页面滚动仍然可以保持流畅。


const scrollContainer = document.querySelector<HTMLElement>('.scroll-container')!;

scrollContainer.addEventListener(
  'scroll',
  () => {
    console.log('Scroll position:', scrollContainer.scrollTop);
  },
  { passive: true },
);

scrollContainer.addEventListener(
  'touchstart',
  (e: TouchEvent) => {
    console.log('Touch start');
  },
  { passive: true },
);

小结
    

  • 合成是渲染流水线的最后阶段，将多个图层在 GPU 上合成为最终画面
    • 

  • 合成线程独立于主线程，即使 JS 繁忙也能处理滚动和 transform/opacity 动画
    • 

  • 图层被分块（Tiling） 处理，可视区域优先光栅化
    • 

  • will-change 可提升元素为独立合成层，但需要在动画结束后及时移除
    • 

  • transform 和 opacity 跳过布局和绘制，是性能最优的动画属性
    •
