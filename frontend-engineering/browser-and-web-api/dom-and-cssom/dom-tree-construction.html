DOM 树构建

HTML 解析的整体流程

浏览器接收到 HTML 字节流后，需要将其解析为结构化的 DOM 树（Document Object Model Tree）。这个过程由 HTML 解析器完成，遵循 WHATWG HTML 规范定义的状态机模型。



词法分析器（Tokenizer）
词法分析器是一个状态机，将字符流转换为一系列 Token。HTML 规范定义了超过 80 种状态。


Token 的主要类型：

interface Token {
  type: 'DOCTYPE' | 'StartTag' | 'EndTag' | 'Character' | 'Comment' | 'EOF';
  tagName?: string;
  attributes?: Array<{ name: string; value: string }>;
  data?: string;
}

function tokenize(html: string): Token[] {
  const tokens: Token[] = [];
  const tagRegex = /<\/?([a-zA-Z][a-zA-Z0-9]*)((?:\s+[^>]*?)?)>/g;
  let lastIndex = 0;
  let match: RegExpExecArray | null;

  while ((match = tagRegex.exec(html)) !== null) {
    if (match.index > lastIndex) {
      tokens.push({ type: 'Character', data: html.slice(lastIndex, match.index) });
    }
    tokens.push({
      type: match[0].startsWith('</') ? 'EndTag' : 'StartTag',
      tagName: match[1].toLowerCase(),
    });
    lastIndex = tagRegex.lastIndex;
  }

  tokens.push({ type: 'EOF' });
  return tokens;
}


树构建算法
树构建器维护一个开放元素栈（Stack of Open Elements），根据接收到的 Token 执行相应的操作。


interface DOMNode {
  type: 'element' | 'text' | 'document';
  tagName?: string;
  children: DOMNode[];
  textContent?: string;
}

function buildTree(tokens: Token[]): DOMNode {
  const document: DOMNode = { type: 'document', children: [] };
  const stack: DOMNode[] = [document];

  for (const token of tokens) {
    const parent = stack[stack.length - 1];

    switch (token.type) {
      case 'StartTag': {
        const element: DOMNode = {
          type: 'element',
          tagName: token.tagName,
          children: [],
        };
        parent.children.push(element);
        stack.push(element);
        break;
      }
      case 'EndTag':
        stack.pop();
        break;
      case 'Character':
        if (token.data?.trim()) {
          parent.children.push({ type: 'text', textContent: token.data, children: [] });
        }
        break;
    }
  }

  return document;
}


解析器阻塞与推测解析
HTML 解析过程中遇到 <script> 标签时，解析器会暂停，等待脚本下载并执行完毕后再继续。这是因为脚本可能通过 document.write() 修改文档流。


推测解析（Speculative Parsing） 通过预加载扫描器在主解析器暂停时继续扫描后续 HTML，提前发现需要加载的资源。






脚本加载方式
是否阻塞解析
执行时机





<script>
阻塞
下载后立即执行




<script defer>
不阻塞
DOMContentLoaded 前按顺序执行




<script async>
不阻塞
下载完成后立即执行（不保证顺序）




<script type="module">
不阻塞（默认 defer）
模块依赖解析完成后执行





function createScript(src: string, strategy: 'sync' | 'async' | 'defer' | 'module'): HTMLScriptElement {
  const script = document.createElement('script');
  script.src = src;

  switch (strategy) {
    case 'async':
      script.async = true;
      break;
    case 'defer':
      script.defer = true;
      break;
    case 'module':
      script.type = 'module';
      break;
  }

  return script;
}


提示： 推测解析器只负责发现和预加载资源，不会执行脚本或构建 DOM。它是浏览器自动进行的优化，开发者无需手动干预。






DOMContentLoaded 与 load 事件

document.addEventListener('DOMContentLoaded', () => {
  console.log('DOM ready');
  const app = document.getElementById('app');
  console.log('App element:', app);
});

window.addEventListener('load', () => {
  console.log('All resources loaded');
  const images = document.querySelectorAll('img');
  for (const img of images) {
    console.log(`${img.src}: ${img.naturalWidth}x${img.naturalHeight}`);
  }
});

const readyState = document.readyState;
if (readyState === 'loading') {
  document.addEventListener('DOMContentLoaded', init);
} else {
  init();
}

}


小结
    

  • HTML 解析分为词法分析（Tokenizer）和树构建（Tree Builder）两个阶段
    • 

  • 解析器遇到 <script> 会阻塞，使用 defer/async 可避免阻塞
    • 

  • 推测解析（预加载扫描器）在解析暂停时提前发现并加载后续资源
    • 

  • DOMContentLoaded 在 DOM 树就绪时触发，load 在所有资源加载完成后触发
    • 

  • 理解解析流程有助于优化首屏加载性能和脚本加载策略
    •
