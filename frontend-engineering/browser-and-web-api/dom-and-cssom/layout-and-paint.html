布局与绘制

从渲染树到布局树

样式计算完成后，浏览器会基于渲染树构建布局树（Layout Tree）。布局树只包含可见元素，display: none 的元素不会进入布局树，而 ::before/::after 伪元素虽不在 DOM 中却会出现在布局树中。



布局计算过程
布局（Layout / Reflow）阶段从根节点开始，递归计算每个元素的精确几何信息。


interface LayoutBox {
  x: number;
  y: number;
  width: number;
  height: number;
  children: LayoutBox[];
}

function getLayoutInfo(element: Element): LayoutBox {
  const rect = element.getBoundingClientRect();
  return {
    x: rect.left,
    y: rect.top,
    width: rect.width,
    height: rect.height,
    children: Array.from(element.children).map(getLayoutInfo),
  };
}

const body = document.body;
console.log(JSON.stringify(getLayoutInfo(body), null, 2));

绘制记录（Paint Records）
布局完成后，浏览器生成一系列绘制记录（Paint Records），描述如何将元素渲染到屏幕上。绘制记录按照特定顺序生成。


const canvas = document.createElement('canvas');
const ctx = canvas.getContext('2d')!;
canvas.width = 400;
canvas.height = 300;

interface PaintRecord {
  operation: 'fillRect' | 'strokeRect' | 'fillText' | 'drawImage';
  params: Record<string, number | string>;
}

function simulatePaint(records: PaintRecord[]): void {
  for (const record of records) {
    switch (record.operation) {
      case 'fillRect':
        ctx.fillStyle = record.params.color as string;
        ctx.fillRect(
          record.params.x as number,
          record.params.y as number,
          record.params.width as number,
          record.params.height as number,
        );
        break;
      case 'strokeRect':
        ctx.strokeStyle = record.params.color as string;
        ctx.lineWidth = record.params.lineWidth as number;
        ctx.strokeRect(
          record.params.x as number,
          record.params.y as number,
          record.params.width as number,
          record.params.height as number,
        );
        break;
    }
  }
}

simulatePaint([
  { operation: 'fillRect', params: { x: 0, y: 0, width: 200, height: 100, color: '#e0f2fe' } },
  { operation: 'strokeRect', params: { x: 0, y: 0, width: 200, height: 100, color: '#0284c7', lineWidth: 2 } },
]);


绘制失效（Paint Invalidation）
当元素的视觉属性发生变化时，浏览器需要失效（Invalidate） 对应区域的绘制缓存并重新绘制。

function efficientUpdate(element: HTMLElement): void {
  element.style.transform = 'translateX(100px)';

  element.style.opacity = '0.5';

  element.style.backgroundColor = 'red';
}

function forceLayout(element: HTMLElement): void {
  element.style.width = '200px';
  void element.offsetWidth;
  element.style.height = '100px';
}


提示： 使用 Chrome DevTools 的 Performance 面板，开启 "Paint Flashing" 可以可视化页面中正在重绘的区域（绿色高亮）。






增量布局（Incremental Layout）
浏览器不会每次都重新计算整棵布局树。增量布局 只重新计算受影响的子树。


function containLayoutScope(element: HTMLElement): void {
  element.style.contain = 'layout';
}

function isolateWidget(widgetRoot: HTMLElement): void {
  widgetRoot.style.contain = 'strict';
}

function autoVisibility(element: HTMLElement): void {
  element.style.contentVisibility = 'auto';
  element.style.containIntrinsicSize = 'auto 500px';
}
CSS contain 属性可以显式限制布局影响范围：

子像素渲染与抗锯齿
现代浏览器使用子像素渲染来实现平滑的文字和边缘效果：


function getSubpixelRect(element: HTMLElement): DOMRect {
  const rect = element.getBoundingClientRect();
  console.log(`Position: (${rect.x}, ${rect.y})`);
  console.log(`Size: ${rect.width} x ${rect.height}`);
  console.log(`Integer check: ${Number.isInteger(rect.width)}`);
  return rect;
}

function snapToPixelGrid(element: HTMLElement): void {
  const rect = element.getBoundingClientRect();
  element.style.width = `${Math.round(rect.width)}px`;
  element.style.height = `${Math.round(rect.height)}px`;
}

小结
    

  • 布局树由 DOM + CSSOM 过滤不可见元素后生成，包含伪元素
    • 

  • 布局阶段递归计算所有元素的位置和尺寸，不同 display 值使用不同布局算法
    • 

  • 绘制阶段按照背景→边框→子元素→轮廓的顺序生成绘制记录
    • 

  • 增量布局只重新计算 dirty 子树，contain 属性可限制失效传播范围
    • 

  • 合成属性（transform/opacity）变更不触发布局或绘制失效，性能最优
    •
