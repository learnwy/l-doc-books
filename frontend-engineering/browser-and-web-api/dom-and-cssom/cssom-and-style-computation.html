CSSOM 与样式计算

CSS 解析流程

浏览器在构建 DOM 的同时，会并行解析 CSS 样式表，构建 CSSOM（CSS Object Model）。CSSOM 是 CSS 的结构化表示，和 DOM 树配合完成渲染树的构建。



CSS 值的三个阶段
每个 CSS 属性在计算过程中经历三个阶段的值转换：






阶段
名称
说明
示例





1
Specified Value（指定值）
声明的原始值或继承/初始值
width: 50%




2
Computed Value（计算值）
解析相对值为绝对值
width: 50%（仍保持百分比）




3
Used Value（使用值）
最终用于布局的实际像素值
width: 400px





const element = document.querySelector<HTMLElement>('.box')!;

const computedStyle = getComputedStyle(element);
console.log('font-size:', computedStyle.fontSize);
console.log('color:', computedStyle.color);
console.log('width:', computedStyle.width);

console.log('所有计算属性数量:', computedStyle.length);

for (let i = 0; i < 5; i++) {
  const prop = computedStyle.item(i);
  console.log(`${prop}: ${computedStyle.getPropertyValue(prop)}`);
}


层叠解析（Cascade Resolution）
当多条规则同时作用于一个元素时，浏览器通过层叠算法决定最终的属性值。层叠的优先级从高到低：


选择器优先级（Specificity）的计算规则：






选择器类型
权重 (A, B, C)
示例





ID 选择器
(1, 0, 0)
#header




类/属性/伪类选择器
(0, 1, 0)
.nav, [type="text"], :hover




元素/伪元素选择器
(0, 0, 1)
div, ::before




通配符/组合器
(0, 0, 0)
*, >, +, ~





interface Specificity {
  a: number;
  b: number;
  c: number;
}

function calculateSpecificity(selector: string): Specificity {
  const spec: Specificity = { a: 0, b: 0, c: 0 };

  const withoutPseudoElements = selector.replace(/::[a-zA-Z-]+/g, () => {
    spec.c++;
    return '';
  });

  const idMatches = withoutPseudoElements.match(/#[a-zA-Z_-][a-zA-Z0-9_-]*/g);
  spec.a = idMatches?.length ?? 0;

  const classMatches = withoutPseudoElements.match(/\.[a-zA-Z_-][a-zA-Z0-9_-]*/g);
  const attrMatches = withoutPseudoElements.match(/\[[^\]]+\]/g);
  const pseudoClassMatches = withoutPseudoElements.match(/:[a-zA-Z-]+/g);
  spec.b = (classMatches?.length ?? 0) + (attrMatches?.length ?? 0) + (pseudoClassMatches?.length ?? 0);

  const elementMatches = withoutPseudoElements.match(/(?:^|[\s>+~])([a-zA-Z][a-zA-Z0-9]*)/g);
  spec.c += elementMatches?.length ?? 0;

  return spec;
}

console.log(calculateSpecificity('#nav .item a'));
console.log(calculateSpecificity('.btn.btn--primary'));

function updateTheme(theme: 'light' | 'dark'): void {
  const vars: Record<string, Record<string, string>> = {
    light: {
      '--bg-color': '#ffffff',
      '--text-color': '#1a1a1a',
      '--border-color': '#e5e7eb',
    },
    dark: {
      '--bg-color': '#1a1a1a',
      '--text-color': '#f5f5f5',
      '--border-color': '#374151',
    },
  };

  for (const [prop, value] of Object.entries(vars[theme])) {
    root.style.setProperty(prop, value);
  }
}

function measureStyleRecalc(callback: () => void): number {
  const start = performance.now();

  callback();

  getComputedStyle(document.body).color;

  return performance.now() - start;
}

const duration = measureStyleRecalc(() => {
  const elements = document.querySelectorAll('.item');
  elements.forEach((el) => {
    (el as HTMLElement).classList.toggle('active');
  });
});

console.log(`Style recalc took: ${duration.toFixed(2)}ms`);


提示： 浏览器匹配选择器时是从右向左进行的。例如 .nav li a 会先找所有 a 元素，再向上检查是否在 li 中，最后确认是否在 .nav 中。因此最右侧的选择器越具体越好。






CSSOM API
const styleSheets = document.styleSheets;

for (const sheet of styleSheets) {
  console.log('Stylesheet:', sheet.href ?? 'inline');

  try {
    const rules = sheet.cssRules;
    for (const rule of rules) {
      if (rule instanceof CSSStyleRule) {
        console.log(`  ${rule.selectorText} { ... }`);
      }
    }
  } catch (e) {
    console.log('  Cannot access cross-origin stylesheet');
  }
}

function addDynamicStyles(css: string): CSSStyleSheet {
  const sheet = new CSSStyleSheet();
  sheet.replaceSync(css);
  document.adoptedStyleSheets = [...document.adoptedStyleSheets, sheet];
  return sheet;
}

const dynamicSheet = addDynamicStyles(`
  .dynamic-box {
    padding: 1rem;
    border: 1px solid currentColor;
    border-radius: 0.5rem;
  }
`);


小结
    

  • CSS 解析生成 CSSOM 树，与 DOM 树结合进行样式计算
    • 

  • CSS 值经过 Specified → Computed → Used 三个阶段转换
    • 

  • 层叠算法按来源、优先级（Specificity）、源码顺序决定最终样式
    • 

  • 选择器匹配从右向左执行，保持选择器简洁有助于提升样式计算性能
    • 

  • CSSStyleSheet API 和 adoptedStyleSheets 提供了动态操作样式表的能力
