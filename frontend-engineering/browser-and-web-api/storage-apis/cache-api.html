Cache API 缓存接口

什么是 Cache API

Cache API 是 Service Worker 规范的一部分，提供了对 HTTP 请求/响应对（Request/Response pairs）的程序化缓存控制。它独立于浏览器的 HTTP 缓存，允许开发者精确控制缓存策略。



CacheStorage API
CacheStorage 是缓存的顶层容器，通过 caches 全局对象访问。


async function cacheDemo(): Promise<void> {
  const cache = await caches.open('app-v1');

  await cache.add('/styles/main.css');

  await cache.addAll(['/scripts/app.js', '/images/logo.png', '/offline.html']);

  const request = new Request('/api/config');
  const response = await fetch(request);
  await cache.put(request, response);

  const cached = await cache.match('/styles/main.css');
  if (cached) {
    console.log('Cache hit:', cached.status);
  }

  await cache.delete('/images/logo.png');

  const keys = await caches.keys();
  console.log('All caches:', keys);
}

提示： Response 对象只能被读取一次。使用 cache.put() 前如果还需要使用 Response，记得先 response.clone()。






常见缓存策略
type CacheStrategy = 'cache-first' | 'network-first' | 'stale-while-revalidate' | 'network-only' | 'cache-only';

async function cacheFirst(request: Request, cacheName: string): Promise<Response> {
  const cache = await caches.open(cacheName);
  const cached = await cache.match(request);
  if (cached) return cached;

  const response = await fetch(request);
  if (response.ok) {
    await cache.put(request, response.clone());
  }
  return response;
}

async function networkFirst(request: Request, cacheName: string): Promise<Response> {
  const cache = await caches.open(cacheName);
  try {
    const response = await fetch(request);
    if (response.ok) {
      await cache.put(request, response.clone());
    }
    return response;
  } catch {
    const cached = await cache.match(request);
    if (cached) return cached;
    throw new Error('No network and no cache available');
  }
}

async function staleWhileRevalidate(request: Request, cacheName: string): Promise<Response> {
  const cache = await caches.open(cacheName);
  const cached = await cache.match(request);

  const fetchPromise = fetch(request).then((response) => {
    if (response.ok) {
      cache.put(request, response.clone());
    }
    return response;
  });

  return cached ?? fetchPromise;
}

缓存失效策略
async function cleanupOldCaches(currentVersion: string): Promise<void> {
  const keys = await caches.keys();
  const deletions = keys.filter((key) => key !== currentVersion).map((key) => caches.delete(key));

  await Promise.all(deletions);
}

async function limitCacheSize(cacheName: string, maxItems: number): Promise<void> {
  const cache = await caches.open(cacheName);
  const keys = await cache.keys();

  if (keys.length > maxItems) {
    const deleteCount = keys.length - maxItems;
    for (let i = 0; i < deleteCount; i++) {
      await cache.delete(keys[i]);
    }
  }
}

interface CacheEntry {
  response: Response;
  timestamp: number;
}

async function cacheWithExpiry(request: Request, cacheName: string, maxAgeMs: number): Promise<Response> {
  const cache = await caches.open(cacheName);
  const cached = await cache.match(request);

  if (cached) {
    const dateHeader = cached.headers.get('sw-cache-date');
    if (dateHeader) {
      const age = Date.now() - Number(dateHeader);
      if (age < maxAgeMs) return cached;
    }
  }

  const response = await fetch(request);
  if (response.ok) {
    const headers = new Headers(response.headers);
    headers.set('sw-cache-date', String(Date.now()));
    const cachedResponse = new Response(await response.clone().blob(), {
      status: response.status,
      statusText: response.statusText,
      headers,
    });
    await cache.put(request, cachedResponse);
  }
  return response;
}


在 Service Worker 中使用
const CACHE_NAME = 'app-v2';
const STATIC_ASSETS = ['/', '/index.html', '/styles/main.css', '/scripts/app.js', '/offline.html'];

self.addEventListener('install', ((event: ExtendableEvent) => {
  event.waitUntil(caches.open(CACHE_NAME).then((cache) => cache.addAll(STATIC_ASSETS)));
}) as EventListener);

self.addEventListener('activate', ((event: ExtendableEvent) => {
  event.waitUntil(cleanupOldCaches(CACHE_NAME));
}) as EventListener);

self.addEventListener('fetch', ((event: FetchEvent) => {
  const { request } = event;

  if (request.destination === 'image') {
    event.respondWith(cacheFirst(request, CACHE_NAME));
  } else if (request.url.includes('/api/')) {
    event.respondWith(networkFirst(request, `${CACHE_NAME}-api`));
  } else {
    event.respondWith(staleWhileRevalidate(request, CACHE_NAME));
  }
}) as EventListener);


小结
    

  • Cache API 提供对 Request/Response 对的程序化缓存控制，独立于浏览器 HTTP 缓存
    • 

  • 常见缓存策略包括 Cache First（静态资源）、Network First（动态数据）、Stale While Revalidate（频繁更新资源）
    • 

  • 缓存失效需要主动管理：版本化缓存名、限制缓存条目数量、设置过期时间
    • 

  • Cache API 常配合 Service Worker 使用，在 fetch 事件中拦截请求并应用缓存策略
    • 

  • Response 只能读取一次，存缓存前务必使用 response.clone()
    •
