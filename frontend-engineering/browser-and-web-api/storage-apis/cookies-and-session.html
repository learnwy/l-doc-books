Cookie 与会话

Cookie 的基本概念

Cookie 是服务器通过 HTTP 响应头发送给浏览器的小段数据，浏览器会在后续请求中自动携带。Cookie 是 Web 应用实现会话管理、用户偏好存储和行为追踪的基础机制。

interface CookieOptions {
  name: string;
  value: string;
  maxAge?: number;
  path?: string;
  domain?: string;
  secure?: boolean;
  httpOnly?: boolean;
  sameSite?: 'Strict' | 'Lax' | 'None';
}

function setCookie(options: Omit<CookieOptions, 'httpOnly'>): void {
  let cookie = `${encodeURIComponent(options.name)}=${encodeURIComponent(options.value)}`;

  if (options.maxAge !== undefined) cookie += `; max-age=${options.maxAge}`;
  if (options.path) cookie += `; path=${options.path}`;
  if (options.domain) cookie += `; domain=${options.domain}`;
  if (options.secure) cookie += '; secure';
  if (options.sameSite) cookie += `; samesite=${options.sameSite}`;

  document.cookie = cookie;
}

function getCookie(name: string): string | null {
  const match = document.cookie.match(new RegExp(`(?:^|;\\s*)${name}=([^;]*)`));
  return match ? decodeURIComponent(match[1]) : null;
}

function deleteCookie(name: string, path = '/'): void {
  document.cookie = `${name}=; max-age=0; path=${path}`;
}

会话管理
基于 Cookie 的会话管理是 Web 应用最常见的身份认证方案：


interface Session {
  id: string;
  userId: number;
  createdAt: number;
  expiresAt: number;
}

class SessionManager {
  private static SESSION_KEY = 'sid';

  static getSessionId(): string | null {
    return getCookie(SessionManager.SESSION_KEY);
  }

  static async validateSession(): Promise<boolean> {
    const sid = this.getSessionId();
    if (!sid) return false;

    try {
      const response = await fetch('/api/session/validate', {
        credentials: 'same-origin',
      });
      return response.ok;
    } catch {
      return false;
    }
  }

  static async logout(): Promise<void> {
    await fetch('/api/logout', {
      method: 'POST',
      credentials: 'same-origin',
    });
    deleteCookie(SessionManager.SESSION_KEY);
  }
}

function getCookieSize(): number {
  return new Blob([document.cookie]).size;
}

function getAllCookies(): Array<{ name: string; value: string }> {
  return document.cookie
    .split(';')
    .filter(Boolean)
    .map((pair) => {
      const [name, ...rest] = pair.trim().split('=');
      return {
        name: decodeURIComponent(name),
        value: decodeURIComponent(rest.join('=')),
      };
    });
}

小结
    

  • Cookie 通过 Set-Cookie 响应头设置，浏览器在后续请求中自动携带
    • 

  • SameSite 属性是防御 CSRF 的关键，Lax 是现代浏览器的默认值
    • 

  • HttpOnly 防止 JS 读取敏感 Cookie，Secure 限制为 HTTPS 传输
    • 

  • Cookie 有数量和大小限制，每次请求都会携带，应避免存储大量数据
    • 

  • 第三方 Cookie 正在被逐步淘汰，需关注 Privacy Sandbox 等替代方案
