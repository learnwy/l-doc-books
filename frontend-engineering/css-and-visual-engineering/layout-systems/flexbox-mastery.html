Flexbox 精通

问题背景

Flexbox（弹性盒子布局）是 CSS 中最常用的一维布局系统。它通过主轴/交叉轴模型，让元素的对齐、分布和伸缩变得直观而强大。无论是导航栏、卡片列表还是表单布局，Flexbox 都是首选方案。

主轴与交叉轴
Flexbox 的一切都围绕两条轴展开：






属性
默认方向
作用





主轴（Main Axis）
水平从左到右
元素排列方向




交叉轴（Cross Axis）
垂直从上到下
与主轴垂直的方向





.row {
  display: flex;
  flex-direction: row; /* 主轴水平（默认） */
}

.column {
  display: flex;
  flex-direction: column; /* 主轴垂直 */
}

.row-reverse {
  display: flex;
  flex-direction: row-reverse; /* 主轴水平反转 */
}


提示： flex-direction 改变的是主轴方向，这意味着 justify-content 和 align-items 的作用方向也随之改变。在 column 模式下，justify-content 控制垂直分布。






flex-grow / flex-shrink / flex-basis
这三个属性控制 flex item 如何分配剩余空间和收缩：


.item {
  flex-grow: 0; /* 默认不放大 */
  flex-shrink: 1; /* 默认可收缩 */
  flex-basis: auto; /* 默认基于内容或 width */
}

/* 简写 */
.item {
  flex: 0 1 auto;
} /* 默认值 */
.item {
  flex: 1;
} /* = flex: 1 1 0%，均分空间 */
.item {
  flex: auto;
} /* = flex: 1 1 auto，基于内容均分 */
.item {
  flex: none;
} /* = flex: 0 0 auto，不伸缩 */
计算公式
实际尺寸 = flex-basis + (剩余空间 × flex-grow / 总 flex-grow)

对齐系统
Flexbox 提供了完整的对齐能力：


主轴对齐 — justify-content
.container {
  display: flex;
  justify-content: flex-start; /* 起始对齐（默认） */
  justify-content: flex-end; /* 末尾对齐 */
  justify-content: center; /* 居中 */
  justify-content: space-between; /* 两端对齐，间距相等 */
  justify-content: space-around; /* 每项两侧等间距 */
  justify-content: space-evenly; /* 所有间距完全相等 */
}
交叉轴对齐 — align-items / align-self
.container {
  display: flex;
  align-items: stretch; /* 拉伸填满（默认） */
  align-items: flex-start; /* 顶部对齐 */
  align-items: flex-end; /* 底部对齐 */
  align-items: center; /* 垂直居中 */
  align-items: baseline; /* 文字基线对齐 */
}

.special-item {
  align-self: flex-end; /* 单个元素覆盖容器设置 */
}
gap 间距
.container {
  display: flex;
  gap: 16px; /* 行列间距相同 */
  gap: 16px 24px; /* 行间距 列间距 */
  row-gap: 16px;
  column-gap: 24px;
}


换行与多行对齐
.container {
  display: flex;
  flex-wrap: wrap; /* 允许换行 */
  align-content: flex-start; /* 多行在交叉轴上的对齐 */
}

  flex-direction: column;
  min-height: 100vh;

  flex: 1;
}

  margin-top: auto;
}


order 属性
order 可以改变视觉排列顺序而不改变 DOM 顺序：


.item:nth-child(3) {
  order: -1;
}


提示： 使用 order 时要注意无障碍——屏幕阅读器仍然按 DOM 顺序读取内容。视觉顺序与 DOM 顺序不一致可能导致 Tab 导航混乱。






小结
    

  • Flexbox 是一维布局系统，通过主轴/交叉轴模型工作
    • 

  • flex-grow/shrink/basis 控制 item 如何分配和收缩空间，flex: 1 是最常用简写
    • 

  • justify-content 控制主轴分布，align-items 控制交叉轴对齐
    • 

  • gap 替代了 margin hack，是设置间距的标准方式
    • 

  • 经典模式：完美居中、导航栏、等高卡片、粘性底部都可用简洁的 Flexbox 实现
    • 

  • order 可调整视觉顺序，但要注意无障碍影响
    •
