响应式设计

问题背景

响应式设计（Responsive Design）让同一套代码适配不同屏幕尺寸——从手机到超宽显示器。核心工具包括媒体查询、流式排版和现代 CSS 函数。移动优先（Mobile-First）策略是当前行业共识，从最小屏幕开始设计，逐步增强大屏体验。

媒体查询
基础语法
/* 移动优先：默认样式 = 移动端 */
.container {
  padding: 1rem;
}

/* 平板及以上 */
@media (min-width: 768px) {
  .container {
    padding: 2rem;
    max-width: 720px;
    margin: 0 auto;
  }
}

/* 桌面及以上 */
@media (min-width: 1024px) {
  .container {
    max-width: 960px;
  }
}

/* 大屏 */
@media (min-width: 1440px) {
  .container {
    max-width: 1200px;
  }
}

现代媒体查询语法
/* 范围语法（Media Queries Level 4） */
@media (width >= 768px) {
  .sidebar {
    display: block;
  }
}

@media (768px <= width < 1024px) {
  .sidebar {
    width: 200px;
  }
}

/* 偏好查询 */
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #0f172a;
  }
}

@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
  }
}

@media (hover: hover) {
  .card:hover {
    transform: translateY(-4px);
  }
}


提示： hover: hover 检测设备是否支持精确悬停（排除触屏设备），避免触屏用户遇到悬停状态卡死的问题。






移动优先策略
移动优先 vs 桌面优先的对比：






策略
CSS 编写顺序
优势





移动优先
基础样式 → min-width 增强
性能更好，移动端不加载多余样式




桌面优先
基础样式 → max-width 缩减
容易遗漏移动适配





/* 移动优先示例 */
.nav-links {
  display: none; /* 移动端隐藏 */
}

.hamburger {
  display: block; /* 移动端显示 */
}

@media (min-width: 768px) {
  .nav-links {
    display: flex; /* 大屏显示链接 */
    gap: 1rem;
  }

  .hamburger {
    display: none; /* 大屏隐藏汉堡按钮 */
  }
}


流式排版
clamp() 函数
clamp() 是响应式排版的终极工具，一行代码实现最小值、首选值和最大值：


h1 {
  /* 最小 1.5rem，首选 5vw，最大 3rem */
  font-size: clamp(1.5rem, 5vw, 3rem);
}

p {
  font-size: clamp(1rem, 2.5vw, 1.25rem);
}

.container {
  width: clamp(320px, 90vw, 1200px);
  padding: clamp(1rem, 3vw, 3rem);
}
流式间距系统
:root {
  --space-xs: clamp(0.25rem, 0.5vw, 0.5rem);
  --space-sm: clamp(0.5rem, 1vw, 0.75rem);
  --space-md: clamp(1rem, 2vw, 1.5rem);
  --space-lg: clamp(1.5rem, 3vw, 2.5rem);
  --space-xl: clamp(2rem, 5vw, 4rem);
}

section {
  padding-block: var(--space-xl);
}

.card {
  padding: var(--space-md);
  gap: var(--space-sm);
}

响应式布局技巧
无媒体查询的响应式网格
.auto-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(250px, 100%), 1fr));
  gap: 1rem;
}
逻辑属性
.card {
  margin-inline: auto;
  padding-block: var(--space-md);
  padding-inline: var(--space-lg);
  border-inline-start: 4px solid currentColor;
}

小结
    

  • 移动优先策略：默认样式针对小屏，用 min-width 媒体查询逐步增强
    • 

  • clamp() 是流式排版的核心函数，同时设置最小、首选和最大值
    • 

  • 现代媒体查询支持范围语法（width >= 768px）和偏好查询（prefers-reduced-motion）
    • 

  • 无媒体查询的响应式网格：repeat(auto-fit, minmax(min(250px, 100%), 1fr))
    • 

  • 逻辑属性（margin-inline、padding-block）支持多书写方向
    • 

  • dvh 解决移动端视口高度不一致的问题
