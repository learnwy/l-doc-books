Grid 精通

问题背景

CSS Grid 是原生的二维布局系统，可以同时控制行和列。它与 Flexbox 互补——Flexbox 擅长一维排列，Grid 擅长二维网格。从仪表盘、图片画廊到整个页面骨架，Grid 都能优雅地实现。

grid-template 基础
定义列和行
.grid {
  display: grid;
  grid-template-columns: 200px 1fr 1fr; /* 三列：固定 + 两个弹性 */
  grid-template-rows: auto 1fr auto; /* 三行 */
  gap: 16px;
}
fr 单位
fr（fraction）表示剩余空间的份数：


.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  /* 总 4fr：第一列 25%，第二列 50%，第三列 25% */
}




单位
含义
示例





px
固定像素
200px




fr
剩余空间份数
1fr 2fr




%
容器百分比
50%




auto
由内容决定
auto




min-content
最小内容宽度
不换行最窄




max-content
最大内容宽度
不换行最宽




minmax()
最小到最大范围
minmax(200px, 1fr)







命名区域
grid-template-areas 用 ASCII 字符画定义布局，极其直观：


.layout {
  display: grid;
  grid-template-areas:
    'header  header'
    'sidebar main'
    'footer  footer';
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}

.header {
  grid-area: header;
}
.sidebar {
  grid-area: sidebar;
}
.main {
  grid-area: main;
}
.footer {
  grid-area: footer;
}


提示： 使用 . 表示空单元格：grid-template-areas: "sidebar . main";






auto-fill 与 auto-fit
实现响应式网格的利器，无需媒体查询：


/* auto-fill：尽可能多地放列，空列保留 */
.grid-fill {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: 16px;
}

/* auto-fit：尽可能多地放列，空列折叠为 0 */
.grid-fit {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 16px;
}




关键字
元素少于可放数量时
适用场景





auto-fill
保留空列轨道
固定列宽网格




auto-fit
空列折叠，现有列拉伸
元素数量不定







Subgrid
Subgrid 让子网格继承父网格的轨道定义，保持对齐：


.parent-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

.card {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;
  gap: 8px;
}
Subgrid 的典型场景：


.product-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 24px;
}

.product-card {
  display: grid;
  grid-template-rows: auto 1fr auto;
  /* 如果浏览器支持 subgrid，卡片内的标题、内容、价格行自动对齐 */
}

@supports (grid-template-rows: subgrid) {
  .product-card {
    grid-row: span 3;
    grid-template-rows: subgrid;
  }
}


响应式布局模式
圣杯布局
.holy-grail {
  display: grid;
  grid-template:
    'header header header' auto
    'nav    main   aside' 1fr
    'footer footer footer' auto
    / 200px 1fr 200px;
  min-height: 100vh;
  gap: 16px;
}

@media (max-width: 768px) {
  .holy-grail {
    grid-template:
      'header' auto
      'nav' auto
      'main' 1fr
      'aside' auto
      'footer' auto
      / 1fr;
  }
}
瀑布流近似
.masonry {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  grid-auto-rows: 10px;
  gap: 16px;
}

.masonry-item.small {
  grid-row: span 20;
}
.masonry-item.medium {
  grid-row: span 30;
}
.masonry-item.large {
  grid-row: span 40;
}
居中单元素
.center {
  display: grid;
  place-items: center;
  min-height: 100vh;
}


Grid 与 Flexbox 选择




维度
Grid

内容驱动 vs 布局驱动
布局驱动
内容驱动




对齐控制

适用场景
页面骨架、仪表盘、画廊
导航栏、卡片内容、工具栏




组合使用
Grid 做整体布局，Flexbox 做局部排列

实用属性速查
.item {
  grid-column: 1 / 3; /* 从第1线到第3线（跨两列） */
  grid-column: span 2; /* 跨两列 */
  grid-row: 2 / -1; /* 从第2行线到最后一条线 */
  justify-self: center; /* 单元格内水平居中 */
  align-self: end; /* 单元格内底部对齐 */
}

.container {
  justify-items: center; /* 所有项水平居中 */
  align-items: center; /* 所有项垂直居中 */
  place-items: center; /* 上两者的简写 */
}


小结
    

  • CSS Grid 是二维布局系统，同时控制行和列
    • 

  • fr 单位按比例分配剩余空间，是 Grid 最核心的单位
    • 

  • 命名区域（grid-template-areas）让布局意图一目了然
    • 

  • auto-fill/auto-fit + minmax() 实现无媒体查询的响应式网格
    • 

  • Subgrid 让嵌套网格继承父级轨道，保持跨卡片对齐
    • 

  • Grid 做页面骨架，Flexbox 做组件内部排列，二者配合使用效果最佳
    •
