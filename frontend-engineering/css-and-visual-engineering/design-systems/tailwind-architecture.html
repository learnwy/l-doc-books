Tailwind 架构

问题背景

Tailwind CSS 是一个原子化工具类（Utility-First）CSS 框架。它不提供预设组件，而是通过大量细粒度的工具类让开发者直接在 HTML 中组合样式。这种方式颠覆了传统的"语义化类名"思路，但在快速开发、一致性维护和包体积优化上展现了强大优势。

Utility-First 理念
传统方式 vs Tailwind 方式
<!-- 传统：语义化类名 -->
<div class="card">
  <h3 class="card-title">标题</h3>
  <p class="card-body">内容</p>
</div>

<!-- Tailwind：工具类组合 -->
<div class="rounded-lg border p-4 shadow-sm">
  <h3 class="text-lg font-semibold">标题</h3>
  <p class="text-sm text-gray-600">内容</p>
</div>

配置定制
tailwind.config.ts
import type { Config } from 'tailwindcss';

const config: Config = {
  content: ['./src/**/*.{ts,tsx}', './components/**/*.{ts,tsx}'],
  theme: {
    extend: {
      colors: {
        brand: {
          50: '#eff6ff',
          100: '#dbeafe',
          500: '#3b82f6',
          600: '#2563eb',
          700: '#1d4ed8',
          900: '#1e3a5f',
        },
      },
      spacing: {
        '18': '4.5rem',
        '88': '22rem',
      },
      borderRadius: {
        '4xl': '2rem',
      },
      fontFamily: {
        sans: ['Inter', 'system-ui', 'sans-serif'],
        mono: ['JetBrains Mono', 'monospace'],
      },
      animation: {
        'fade-in': 'fadeIn 0.5s ease-out',
        'slide-up': 'slideUp 0.3s ease-out',
      },
      keyframes: {
        fadeIn: {
          '0%': { opacity: '0' },
          '100%': { opacity: '1' },
        },
        slideUp: {
          '0%': { opacity: '0', transform: 'translateY(10px)' },
          '100%': { opacity: '1', transform: 'translateY(0)' },
        },
      },
    },
  },
  plugins: [],
};

export default config;


提示： extend 是追加配置，不覆盖默认值。直接在 theme 下定义会完全替换该类别的默认值。






插件系统
自定义插件
import plugin from 'tailwindcss/plugin';

const customPlugin = plugin(({ addComponents, addUtilities, theme }) => {
  addComponents({
    '.btn': {
      padding: `${theme('spacing.2')} ${theme('spacing.4')}`,
      borderRadius: theme('borderRadius.md'),
      fontWeight: theme('fontWeight.semibold'),
      cursor: 'pointer',
      transition: 'all 0.2s ease',
    },
    '.btn-primary': {
      backgroundColor: theme('colors.brand.500'),
      color: '#fff',
      '&:hover': {
        backgroundColor: theme('colors.brand.600'),
      },
    },
  });

  addUtilities({
    '.text-balance': {
      textWrap: 'balance',
    },
    '.text-pretty': {
      textWrap: 'pretty',
    },
  });
});

组件抽象模式
当工具类组合重复出现时，用 React 组件而非 CSS 类来抽象：


interface BadgeProps {
  variant?: 'default' | 'success' | 'warning' | 'error';
  children: React.ReactNode;
}

const variantStyles = {
  default: 'bg-gray-100 text-gray-700',
  success: 'bg-green-100 text-green-700',
  warning: 'bg-yellow-100 text-yellow-700',
  error: 'bg-red-100 text-red-700',
} as const;

function Badge({ variant = 'default', children }: BadgeProps) {
  return (
    <span className={`inline-flex items-center rounded-full px-2.5 py-0.5 text-xs font-medium ${variantStyles[variant]}`}>
      {children}
    </span>
  );
}


提示： Tailwind 的最佳实践是"在组件层面抽象，而非 CSS 层面"。用 @apply 提取的 CSS 类会失去 Tailwind 的优势。






响应式与状态
<!-- 响应式 -->
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
  <!-- 悬停状态 -->
  <button class="bg-blue-500 hover:bg-blue-600 active:bg-blue-700">
    <!-- 暗色模式 -->
    <div class="bg-white dark:bg-gray-900 text-gray-900 dark:text-gray-100">
      <!-- 聚焦状态 -->
      <input class="border focus:ring-2 focus:ring-blue-500 focus:border-blue-500" />

      <!-- 分组悬停 -->
      <div class="group">
        <span class="group-hover:text-blue-500">悬停父级时变色</span>
      </div>

      <!-- 同级状态 -->
      <input class="peer" />
      <p class="hidden peer-invalid:block text-red-500">验证失败</p>
    </div>
  </button>
</div>

小结
    

  • Utility-First 用细粒度工具类替代语义化 CSS 类，减少 CSS 增长
    • 

  • 配置系统通过 tailwind.config 将设计令牌映射为工具类
    • 

  • 插件系统支持自定义组件和工具类，扩展能力强
    • 

  • 与设计系统集成时，通过令牌驱动配置确保一致性
    • 

  • 抽象模式：用 React 组件封装工具类组合，而非 @apply
    • 

  • Tailwind v4 转向 CSS-first 配置，性能大幅提升
    •
