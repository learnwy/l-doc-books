设计令牌

问题背景

设计令牌（Design Tokens）是设计系统的原子层——将颜色、间距、字体、阴影等视觉属性抽象为平台无关的键值对。它们是设计师与开发者之间的"合约"，确保品牌一致性的同时支持多平台（Web、iOS、Android）输出。Style Dictionary 是主流的令牌处理工具链。

令牌分类
设计令牌按抽象层级分为三层：






层级
名称
示例
说明





全局令牌
Global / Primitive
blue-500: #3b82f6
原始值，与用途无关




语义令牌
Semantic / Alias
color-primary: {blue-500}
描述用途，引用全局令牌




组件令牌
Component
button-bg: {color-primary}
特定组件专用





{
  "color": {
    "blue": {
      "500": { "value": "#3b82f6", "type": "color" }
    }
  },
  "semantic": {
    "color": {
      "primary": { "value": "{color.blue.500}" },
      "bg": {
        "default": { "value": "#ffffff" },
        "subtle": { "value": "#f8fafc" }
      }
    }
  },
  "component": {
    "button": {
      "bg": { "value": "{semantic.color.primary}" },
      "radius": { "value": "{size.radius.md}" }
    }
  }
}


提示： 三层结构的好处是：改变品牌色只需修改全局令牌到语义令牌的映射，所有组件自动更新。

多平台令牌输出
Style Dictionary 配置
// config.mjs
import StyleDictionary from 'style-dictionary';

const sd = new StyleDictionary({
  source: ['tokens/**/*.json'],
  platforms: {
    css: {
      transformGroup: 'css',
      buildPath: 'build/css/',
      files: [
        {
          destination: 'variables.css',
          format: 'css/variables',
          options: { outputReferences: true },
        },
      ],
    },
    js: {
      transformGroup: 'js',
      buildPath: 'build/js/',
      files: [
        {
          destination: 'tokens.js',
          format: 'javascript/es6',
        },
      ],
    },
    ios: {
      transformGroup: 'ios-swift',
      buildPath: 'build/ios/',
      files: [
        {
          destination: 'StyleDictionaryTokens.swift',
          format: 'ios-swift/class.swift',
        },
      ],
    },
  },
});

await sd.buildAllPlatforms();
输出示例
CSS 输出：


:root {
  --color-blue-500: #3b82f6;
  --color-primary: var(--color-blue-500);
  --space-md: 16px;
  --radius-md: 8px;
  --shadow-md: 0 4px 6px rgba(0, 0, 0, 0.1);
}
TypeScript 输出：


export const ColorBlue500 = '#3b82f6';
export const ColorPrimary = '#3b82f6';
export const SpaceMd = '16px';
export const RadiusMd = '8px';

主题变体
令牌天然支持主题切换，通过不同模式输出不同值：


{
  "color": {
    "bg": {
      "default": {
        "value": "#ffffff",
        "$extensions": {
          "mode": {
            "dark": "#0f172a"
          }
        }
      }
    },
    "text": {
      "primary": {
        "value": "#0f172a",
        "$extensions": {
          "mode": {
            "dark": "#f1f5f9"
          }
        }
      }
    }
  }
}
输出为 CSS：


:root {
  --color-bg-default: #ffffff;
  --color-text-primary: #0f172a;
}

[data-theme='dark'] {
  --color-bg-default: #0f172a;
  --color-text-primary: #f1f5f9;
}


小结
    

  • 设计令牌是设计系统的原子层，将视觉属性抽象为平台无关的键值对
    • 

  • 三层架构：全局令牌（原始值）→ 语义令牌（用途）→ 组件令牌（专用）
    • 

  • 命名遵循 {category}-{property}-{variant}-{state} 的 kebab-case 模式
    • 

  • Style Dictionary 是主流工具链，从 JSON 令牌生成 CSS、JS、iOS、Android 输出
    • 

  • Figma Variables + Tokens Studio 实现设计到代码的令牌同步
    • 

  • 令牌天然支持多主题，通过模式切换输出不同的变量值
    •
