主题与暗色模式

问题背景

暗色模式已从"可选功能"变为"用户期望"。实现一个健壮的主题系统需要考虑系统偏好检测、手动切换、持久化存储和 FOUC（Flash of Unstyled Content）防护。CSS 自定义属性是现代主题系统的核心，配合 prefers-color-scheme 和 JavaScript 可实现完美的主题体验。

prefers-color-scheme
纯 CSS 方案
:root {
  --bg-primary: #ffffff;
  --bg-secondary: #f8fafc;
  --text-primary: #0f172a;
  --text-secondary: #475569;
  --border: #e2e8f0;
  --accent: #3b82f6;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg-primary: #0f172a;
    --bg-secondary: #1e293b;
    --text-primary: #f1f5f9;
    --text-secondary: #94a3b8;
    --border: #334155;
    --accent: #60a5fa;
  }
}

body {
  background: var(--bg-primary);
  color: var(--text-primary);
}


提示： 纯 CSS 方案只跟随系统偏好，无法让用户手动切换。大多数应用需要同时支持系统偏好和手动切换。

系统/手动切换
三态切换
支持三种模式：跟随系统、强制亮色、强制暗色。


type Theme = 'system' | 'light' | 'dark';

function getSystemTheme(): 'light' | 'dark' {
  return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
}

function applyTheme(theme: Theme): void {
  const resolved = theme === 'system' ? getSystemTheme() : theme;
  document.documentElement.setAttribute('data-theme', resolved);
}

function initTheme(): void {
  const saved = localStorage.getItem('theme') as Theme | null;
  const theme = saved || 'system';
  applyTheme(theme);

  window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', () => {
    const current = localStorage.getItem('theme') as Theme | null;
    if (!current || current === 'system') {
      applyTheme('system');
    }
  });
}

function setTheme(theme: Theme): void {
  localStorage.setItem('theme', theme);
  applyTheme(theme);
}


FOUC 防护
页面加载时如果主题应用延迟，用户会看到一闪而过的默认样式。解决方案是在 <head> 中尽早执行主题脚本：


<head>
  <script>
    (function () {
      var theme = localStorage.getItem('theme') || 'system';
      var resolved = theme;
      if (theme === 'system') {
        resolved = window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
      }
      document.documentElement.setAttribute('data-theme', resolved);
    })();
  </script>
  <style>
    html {
      visibility: hidden;
    }
    html[data-theme] {
      visibility: visible;
    }
  </style>
</head>


提示： 这段脚本必须是同步的（不能用 defer 或 async），必须放在任何样式表之前或之后立即执行，以确保首次渲染就使用正确的主题。

主题切换 React 组件
import { useState, useEffect, createContext, useContext } from 'react';

type Theme = 'system' | 'light' | 'dark';

interface ThemeContextValue {
  theme: Theme;
  setTheme: (t: Theme) => void;
  resolved: 'light' | 'dark';
}

const ThemeContext = createContext<ThemeContextValue | null>(null);

function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setThemeState] = useState<Theme>(() => {
    if (typeof window === 'undefined') return 'system';
    return (localStorage.getItem('theme') as Theme) || 'system';
  });

  const [resolved, setResolved] = useState<'light' | 'dark'>('light');

  useEffect(() => {
    const resolve = () => {
      const r = theme === 'system'
        ? (window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light')
        : theme;
      setResolved(r);
      document.documentElement.setAttribute('data-theme', r);
    };

    resolve();
    const mq = window.matchMedia('(prefers-color-scheme: dark)');
    mq.addEventListener('change', resolve);
    return () => mq.removeEventListener('change', resolve);
  }, [theme]);

  const setTheme = (t: Theme) => {
    localStorage.setItem('theme', t);
    setThemeState(t);
  };

  return (
    <ThemeContext.Provider value={{ theme, setTheme, resolved }}>
      {children}
    </ThemeContext.Provider>
  );
}

function useTheme() {
  const ctx = useContext(ThemeContext);
  if (!ctx) throw new Error('useTheme must be used within ThemeProvider');
  return ctx;
}


小结
    

  • prefers-color-scheme 检测系统暗色偏好，是纯 CSS 方案的基础
    • 

  • CSS 变量 + data-theme 属性选择器是最灵活的主题系统架构
    • 

  • 三态切换（system/light/dark）满足所有用户需求，localStorage 持久化选择
    • 

  • FOUC 防护：在 <head> 中同步执行主题脚本，避免主题闪烁
    • 

  • Tailwind 的 darkMode: 'selector' 支持手动控制暗色模式
    • 

  • React 中使用 ThemeProvider + useTheme 模式管理主题状态
    •
