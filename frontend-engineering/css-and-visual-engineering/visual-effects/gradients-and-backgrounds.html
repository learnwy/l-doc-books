渐变与背景

问题背景

CSS 渐变和背景属性是创造视觉丰富界面的基础工具。从简单的按钮渐变到复杂的多层背景合成，掌握 linear-gradient、radial-gradient、conic-gradient 以及背景混合模式，可以在不使用图片的情况下实现大量视觉效果，同时保持出色的性能。

线性渐变
基础语法
/* 方向 + 色标 */
.gradient-basic {
  background: linear-gradient(to right, #3b82f6, #8b5cf6);
}

/* 角度 */
.gradient-angle {
  background: linear-gradient(135deg, #f97316, #ef4444);
}

/* 多色标 */
.gradient-multi {
  background: linear-gradient(to bottom, #0ea5e9 0%, #3b82f6 33%, #8b5cf6 66%, #d946ef 100%);
}

/* 硬边渐变（条纹效果） */
.gradient-stripes {
  background: linear-gradient(to right, #3b82f6 0%, #3b82f6 50%, #8b5cf6 50%, #8b5cf6 100%);
}
文字渐变
.gradient-text {
  background: linear-gradient(135deg, #3b82f6, #d946ef);
  -webkit-background-clip: text;
  background-clip: text;
  -webkit-text-fill-color: transparent;
  color: transparent;
}


提示： 文字渐变需要设置 background-clip: text 和 color: transparent。注意提供 -webkit- 前缀以确保兼容性。






径向渐变
/* 圆形渐变 */
.radial-circle {
  background: radial-gradient(circle, #3b82f6, transparent 70%);
}

/* 椭圆渐变（默认） */
.radial-ellipse {
  background: radial-gradient(ellipse at top left, #f97316 0%, transparent 50%);
}

/* 指定大小 */
.radial-sized {
  background: radial-gradient(circle 200px at center, #8b5cf6, transparent);
}

/* 多层径向渐变模拟光照 */
.spotlight {
  background:
    radial-gradient(circle at 30% 30%, rgba(255, 255, 255, 0.2), transparent 50%),
    radial-gradient(circle at 70% 80%, rgba(0, 0, 0, 0.1), transparent 50%), linear-gradient(135deg, #1e293b, #334155);
}


锥形渐变
/* 基础锥形渐变 */
.conic-basic {
  background: conic-gradient(from 0deg, #f97316, #eab308, #22c55e, #3b82f6, #8b5cf6, #f97316);
  border-radius: 50%;
}

/* 饼图 */
.pie-chart {
  background: conic-gradient(#3b82f6 0deg 120deg, #22c55e 120deg 210deg, #f97316 210deg 300deg, #ef4444 300deg 360deg);
  border-radius: 50%;
}

/* 棋盘格 */
.checkerboard {
  background: conic-gradient(#e2e8f0 25%, transparent 25%, transparent 50%, #e2e8f0 50%, #e2e8f0 75%, transparent 75%) 0
    0 / 40px 40px;
}


重复渐变
/* 重复线性渐变 — 条纹背景 */
.stripes {
  background: repeating-linear-gradient(45deg, transparent, transparent 10px, currentColor 10px, currentColor 11px);
  opacity: 0.1;
}

/* 重复径向渐变 — 圆点阵列 */
.dots {
  background: radial-gradient(circle, currentColor 1px, transparent 1px);
  background-size: 20px 20px;
}

/* 网格线 */
.grid-lines {
  background:
    linear-gradient(to right, currentColor 1px, transparent 1px),
    linear-gradient(to bottom, currentColor 1px, transparent 1px);
  background-size: 40px 40px;
  opacity: 0.1;
}


多重背景
CSS 支持在一个元素上叠加多个背景层：


.multi-bg {
  background:
    /* 第一层：上方半透明渐变 */
    linear-gradient(to bottom, rgba(0, 0, 0, 0.5), transparent),
    /* 第二层：右下角装饰圆 */ radial-gradient(circle at 80% 80%, rgba(59, 130, 246, 0.3), transparent 40%),
    /* 第三层：底图 */ url('/images/hero.jpg') center / cover no-repeat;
}

/* Hero 区域常见模式 */
.hero {
  background:
    linear-gradient(to bottom, transparent 60%, var(--bg-primary) 100%),
    url('/images/hero.jpg') center / cover;
  min-height: 80vh;
}




属性
说明





background-size
cover（覆盖）/ contain（包含）/ 具体尺寸




background-position
center / top left / 百分比




background-repeat
no-repeat / repeat / space / round




background-attachment
scroll（默认）/ fixed（视差效果）







background-blend-mode
背景混合模式控制多个背景层之间的混合方式：


.blend-multiply {
  background:
    linear-gradient(135deg, #3b82f6, #8b5cf6),
    url('/images/texture.jpg') center / cover;
  background-blend-mode: multiply;
}

.blend-overlay {
  background:
    linear-gradient(to bottom, rgba(0, 0, 0, 0.3), rgba(0, 0, 0, 0.7)),
    url('/images/photo.jpg') center / cover;
  background-blend-mode: overlay;
}

/* 双色调效果 */
.duotone {
  background:
    linear-gradient(#3b82f6, #3b82f6),
    url('/images/photo.jpg') center / cover;
  background-blend-mode: color;
}




混合模式
效果
适用场景





multiply
正片叠底，变暗
暗色叠加




screen
滤色，变亮
亮色叠加




overlay
对比增强
纹理增强

双色调

实用渐变模式
带渐变边框
.gradient-border {
  border: 2px solid transparent;
  background:
    linear-gradient(var(--bg-primary), var(--bg-primary)) padding-box,
    linear-gradient(135deg, #3b82f6, #d946ef) border-box;
}
动画渐变背景
@property --gradient-angle {
  syntax: '<angle>';
  inherits: false;
  initial-value: 0deg;
}

@keyframes rotateGradient {
  to {
    --gradient-angle: 360deg;
  }
}

.animated-gradient {
  background: conic-gradient(from var(--gradient-angle), #3b82f6, #8b5cf6, #d946ef, #3b82f6);
  animation: rotateGradient 3s linear infinite;
}


小结
    

  • 线性渐变用方向/角度 + 色标定义，硬边色标可实现条纹效果
    • 

  • 径向渐变适合光照、聚焦效果，circle 和 ellipse 控制形状
    • 

  • 锥形渐变围绕中心点旋转，适合饼图和彩虹效果
    • 

  • 多重背景从上到下叠加，最先声明的在最上层
    • 

  • background-blend-mode 控制背景层之间的混合，multiply/overlay/color 最常用
    • 

  • 使用 @property 可以让渐变参与动画，实现旋转渐变等高级效果
    •
