滤镜与混合模式

问题背景

CSS 滤镜（filter）和混合模式（mix-blend-mode）让浏览器直接进行图像处理，无需 Photoshop 或 Canvas。从模糊、亮度调节到毛玻璃效果（Glassmorphism），这些属性为现代 UI 提供了丰富的视觉层次感。backdrop-filter 更是实现了作用于元素背后内容的滤镜效果。

filter 函数
常用滤镜
/* 单个滤镜 */
.blur {
  filter: blur(4px);
}
.brightness {
  filter: brightness(1.2);
}
.contrast {
  filter: contrast(1.3);
}
.grayscale {
  filter: grayscale(100%);
}
.saturate {
  filter: saturate(1.5);
}
.sepia {
  filter: sepia(80%);
}
.hue-rotate {
  filter: hue-rotate(90deg);
}
.invert {
  filter: invert(100%);
}
.opacity {
  filter: opacity(50%);
}
.drop-shadow {
  filter: drop-shadow(4px 4px 8px rgba(0, 0, 0, 0.3));
}

/* 组合滤镜 */
.combined {
  filter: brightness(1.1) contrast(1.05) saturate(1.2);
}

drop-shadow vs box-shadow
/* box-shadow：矩形阴影（包括透明区域） */
.box-shadow {
  box-shadow: 4px 4px 8px rgba(0, 0, 0, 0.3);
}

/* drop-shadow：跟随元素实际形状（如 PNG 透明度） */
.drop-shadow {
  filter: drop-shadow(4px 4px 8px rgba(0, 0, 0, 0.3));
}


提示： 对于有透明背景的 PNG 或 SVG 图标，使用 filter: drop-shadow() 而非 box-shadow，阴影会跟随实际形状而非边界框。






backdrop-filter
backdrop-filter 对元素背后的内容应用滤镜，是实现毛玻璃效果的关键：


.glass {
  background: rgba(255, 255, 255, 0.1);
  backdrop-filter: blur(12px) saturate(1.8);
  border: 1px solid rgba(255, 255, 255, 0.2);
  border-radius: 12px;
}

.glass-dark {
  background: rgba(15, 23, 42, 0.6);
  backdrop-filter: blur(16px) saturate(1.5);
  border: 1px solid rgba(255, 255, 255, 0.1);
}

.frosted-nav {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  background: rgba(255, 255, 255, 0.8);
  backdrop-filter: blur(8px);
  border-bottom: 1px solid rgba(0, 0, 0, 0.1);
}


mix-blend-mode
mix-blend-mode 控制元素与其下方内容的混合方式：


.overlay-text {
  mix-blend-mode: difference;
  color: white;
}

.blend-multiply {
  mix-blend-mode: multiply;
}

.blend-screen {
  mix-blend-mode: screen;
}

/* 文字穿透效果 */
.knockout-text {
  background: url('/images/texture.jpg') center / cover;
  color: white;
  mix-blend-mode: screen;
}

Glassmorphism（毛玻璃风格）
.glass-card {
  background: rgba(255, 255, 255, 0.15);
  backdrop-filter: blur(12px) saturate(1.8);
  border-radius: 16px;
  border: 1px solid rgba(255, 255, 255, 0.2);
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1);
  padding: 2rem;
}

/* 暗色模式下的毛玻璃 */
[data-theme='dark'] .glass-card {
  background: rgba(15, 23, 42, 0.5);
  border-color: rgba(255, 255, 255, 0.08);
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.3);
}
毛玻璃导航栏
.glass-navbar {
  position: fixed;
  inset: 0 0 auto 0;
  padding: 0.75rem 1.5rem;
  background: rgba(255, 255, 255, 0.7);
  backdrop-filter: blur(10px) saturate(1.5);
  border-bottom: 1px solid rgba(0, 0, 0, 0.06);
  z-index: 100;
  transition: background 0.3s ease;
}

[data-theme='dark'] .glass-navbar {
  background: rgba(15, 23, 42, 0.7);
  border-bottom-color: rgba(255, 255, 255, 0.06);
}


滤镜动画
.image-hover {
  filter: grayscale(80%) brightness(0.9);
  transition: filter 0.3s ease;
}

.image-hover:hover {
  filter: grayscale(0%) brightness(1);
}

/* 模糊加载效果 */
.lazy-image {
  filter: blur(20px);
  transition: filter 0.5s ease;
}

.lazy-image.loaded {
  filter: blur(0);
}
交互式光照效果
.card-glow {
  position: relative;
  overflow: hidden;
}

.card-glow::before {
  content: '';
  position: absolute;
  inset: 0;
  background: radial-gradient(
    circle at var(--mouse-x, 50%) var(--mouse-y, 50%),

    transparent 60%

.card-glow:hover::before {
  opacity: 1;
}


性能注意事项




属性
性能影响
建议





filter: blur()
中等，GPU 加速
避免大面积高模糊值




backdrop-filter
较高，每帧重新计算
限制使用数量




mix-blend-mode
中等
避免在滚动元素上使用




filter: drop-shadow
中等
比 box-shadow 开销大







提示： backdrop-filter 在移动设备上性能开销较大。如果页面有多个毛玻璃元素，考虑在低端设备上降级为半透明背景。






小结
    

  • filter 对元素自身应用视觉效果，支持模糊、亮度、对比度等 10 种函数
    • 

  • backdrop-filter 对元素背后内容应用滤镜，是毛玻璃效果的核心
    • 

  • mix-blend-mode 控制元素与下方内容的混合，difference 实现自动反色文字
    • 

  • drop-shadow 跟随元素实际形状（而非边界框），适合透明图标
    • 

  • Glassmorphism 的关键配方：半透明背景 + backdrop-filter: blur() + 微边框
    • 

  • 滤镜效果有 GPU 加速但消耗内存，backdrop-filter 应限制使用数量
    •
