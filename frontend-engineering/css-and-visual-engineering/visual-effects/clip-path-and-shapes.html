裁剪路径与形状

问题背景

CSS 默认渲染矩形盒子，但通过 clip-path、shape-outside 和 mask，可以创建任意形状的可见区域。从圆形头像、多边形卡片到文字环绕形状和 SVG 遮罩，这些属性打破了矩形束缚，为 UI 带来丰富的视觉表现力。

clip-path 基础
基本形状
/* 圆形 */
.circle {
  clip-path: circle(50% at center);
}

/* 椭圆 */
.ellipse {
  clip-path: ellipse(40% 50% at center);
}

/* 内嵌矩形（带圆角） */
.rounded {
  clip-path: inset(10px round 16px);
}

/* 多边形 */
.triangle {
  clip-path: polygon(50% 0%, 0% 100%, 100% 100%);
}

.hexagon {
  clip-path: polygon(25% 0%, 75% 0%, 100% 50%, 75% 100%, 25% 100%, 0% 50%);
}

.arrow-right {
  clip-path: polygon(0% 0%, 75% 0%, 100% 50%, 75% 100%, 0% 100%);
}

clip-path 动画
clip-path 在相同形状类型之间可以过渡动画：


.reveal {
  clip-path: circle(0% at center);
  transition: clip-path 0.6s ease-out;
}

.reveal:hover,
.reveal.visible {
  clip-path: circle(75% at center);
}

/* 从左侧划入 */
.slide-in {
  clip-path: inset(0 100% 0 0);
  transition: clip-path 0.5s ease-out;
}

.slide-in.visible {
  clip-path: inset(0 0 0 0);
}

/* 多边形变形 */
.morph {
  clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%);
  transition: clip-path 0.4s ease;
}

.morph:hover {
  clip-path: polygon(0% 0%, 100% 0%, 100% 100%, 0% 100%);
}


提示： polygon 动画要求起始和结束状态的点数相同。点数不同时无法平滑过渡。






SVG clip-path
当基本形状不够用时，可以引用 SVG 路径：


<svg width="0" height="0">
  <defs>
    <clipPath id="blob" clipPathUnits="objectBoundingBox">
      <path d="M0.5,0 C0.8,0 1,0.2 1,0.5 C1,0.8 0.8,1 0.5,1 C0.2,1 0,0.8 0,0.5 C0,0.2 0.2,0 0.5,0" />
    </clipPath>
  </defs>
</svg>
.blob-shape {
  clip-path: url(#blob);
}


shape-outside
shape-outside 让浮动元素的文字环绕遵循指定形状：


.float-circle {
  float: left;
  width: 200px;
  height: 200px;
  shape-outside: circle(50%);
  clip-path: circle(50%);
  margin-right: 1rem;
}

.float-polygon {
  float: right;
  width: 300px;
  height: 300px;
  shape-outside: polygon(0% 0%, 100% 0%, 100% 100%);
  clip-path: polygon(0% 0%, 100% 0%, 100% 100%);
}

/* 使用图片透明度定义形状 */
.float-image {
  float: left;
  width: 200px;
  shape-outside: url('/images/shape.png');
  shape-margin: 1rem;
}


CSS mask
mask 使用图片或渐变控制元素的可见区域，比 clip-path 更灵活（支持渐变透明度）：


渐变遮罩
/* 底部淡出 */
.fade-bottom {
  mask-image: linear-gradient(to bottom, black 60%, transparent 100%);
}

/* 从中心向外淡出 */
.fade-radial {
  mask-image: radial-gradient(circle, black 40%, transparent 70%);
}

/* 左右淡出 */
.fade-sides {
  mask-image: linear-gradient(to right, transparent, black 10%, black 90%, transparent);
}
图片遮罩
.image-mask {
  mask-image: url('/images/mask-pattern.svg');
  mask-size: cover;
  mask-repeat: no-repeat;
}

/* 重复图案遮罩 */
.pattern-mask {
  mask-image: url('/images/dots.svg');
  mask-size: 20px 20px;
  mask-repeat: repeat;
}
遮罩合成
/* 多层遮罩 */
.composite-mask {
  mask-image: linear-gradient(black, transparent), radial-gradient(circle at center, black 50%, transparent 50%);
  mask-composite: intersect;
}

小结
    

  • clip-path 裁剪可见区域，支持 circle、ellipse、polygon、inset 和 SVG path
    • 

  • clip-path 动画要求起始和结束状态的形状类型和点数一致
    • 

  • shape-outside 让浮动元素的文字环绕遵循自定义形状
    • 

  • mask 比 clip-path 更灵活，支持渐变透明度和图案遮罩
    • 

  • mask-composite 支持多层遮罩的交集/差集/排除运算
    • 

  • 实用模式：斜切分割线、波浪分割、滚动容器渐隐
