滚动驱动动画

问题背景

滚动驱动动画（Scroll-Driven Animations）让动画进度与页面滚动位置绑定，而非基于时间。CSS 原生的 scroll-timeline 和 view-timeline 让这一切无需 JavaScript，直接在样式表中声明。从阅读进度条、视差效果到元素入场动画，滚动驱动动画为 Web 体验增添了丰富的叙事层次。

scroll-timeline 基础
animation-timeline: scroll()
使用 scroll() 函数将动画进度绑定到滚动容器：


@keyframes progressBar {
  from {
    transform: scaleX(0);
  }
  to {
    transform: scaleX(1);
  }
}

.reading-progress {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  height: 3px;
  background: var(--accent);
  transform-origin: left;
  animation: progressBar linear;
  animation-timeline: scroll();
}
scroll() 参数
.element {
  /* 默认：最近的滚动祖先，block 方向 */
  animation-timeline: scroll();

  /* 指定滚动容器 */
  animation-timeline: scroll(root); /* 视口 */
  animation-timeline: scroll(nearest); /* 最近的滚动祖先（默认） */
  animation-timeline: scroll(self); /* 元素自身 */

  /* 指定轴 */
  animation-timeline: scroll(block); /* 块方向（默认） */
  animation-timeline: scroll(inline); /* 行内方向 */
  animation-timeline: scroll(y); /* 垂直 */
  animation-timeline: scroll(x); /* 水平 */
}




参数
说明





nearest
最近的可滚动祖先（默认）




root
文档视口




self
元素自身作为滚动容器




block / inline
滚动轴方向







view-timeline
view() 函数将动画进度绑定到元素在视口（或滚动容器）中的可见性：


@keyframes fadeSlideIn {
  from {
    opacity: 0;
    transform: translateY(50px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.animate-on-scroll {
  animation: fadeSlideIn linear both;
  animation-timeline: view();
  animation-range: entry 0% entry 100%;
}
animation-range
animation-range 控制动画在元素可见性周期中的起止点：


/* 进入时播放 */
.entry-animation {
  animation-timeline: view();
  animation-range: entry 0% entry 100%;
}

/* 完全可见时播放 */
.contain-animation {
  animation-timeline: view();
  animation-range: contain 0% contain 100%;
}

/* 退出时播放 */
.exit-animation {
  animation-timeline: view();
  animation-range: exit 0% exit 100%;
}

/* 跨越整个可见周期 */
.full-animation {
  animation-timeline: view();
  animation-range: entry 0% exit 100%;
}




范围值
说明





entry
元素开始进入到完全进入




exit
元素开始离开到完全离开




contain
元素完全在视口内的阶段




cover
元素开始进入到完全离开（最大范围）







命名时间轴
对于复杂场景，可以为滚动容器命名时间轴：


.scroll-container {
  overflow-y: auto;
  scroll-timeline-name: --section-scroll;
  scroll-timeline-axis: block;
}

.parallax-bg {
  animation: parallaxMove linear;
  animation-timeline: --section-scroll;
}

@keyframes parallaxMove {
  from {
    transform: translateY(0);
  }
  to {
    transform: translateY(-100px);
  }
}
.card {
  view-timeline-name: --card;
  view-timeline-axis: block;
}

.card-content {
  animation: fadeIn linear both;
  animation-timeline: --card;
  animation-range: entry 20% entry 80%;
}

水平滚动画廊
.horizontal-gallery {
  overflow-x: auto;
  scroll-timeline-name: --gallery;
  scroll-timeline-axis: inline;
}

@keyframes slideIndicator {
  from {
    transform: translateX(0);
  }
  to {
    transform: translateX(calc(100% - 40px));
  }
}

.gallery-indicator {
  animation: slideIndicator linear;
  animation-timeline: --gallery;
}


降级策略
/* 渐进增强：基础状态 + 动画增强 */
.card {
  opacity: 1;
  transform: translateY(0);
}

@supports (animation-timeline: view()) {
  .card {
    animation: cardEntry linear both;
    animation-timeline: view();
    animation-range: entry 10% entry 60%;
  }
}

/* 尊重减弱动效偏好 */
@media (prefers-reduced-motion: reduce) {
  .card {
    animation: none;
  }
}


提示： 滚动驱动动画是渐进增强的典型场景——不支持的浏览器直接看到最终状态，支持的浏览器获得增强体验。使用 @supports (animation-timeline: view()) 检测支持情况。

小结
    

  • scroll() 将动画进度绑定到滚动容器的滚动位置，适合进度条、视差效果
    • 

  • view() 将动画进度绑定到元素在视口中的可见性，适合入场动画
    • 

  • animation-range 控制动画在 entry/contain/exit 阶段的映射范围
    • 

  • 命名时间轴（scroll-timeline-name/view-timeline-name）支持跨元素引用
    • 

  • 滚动驱动动画完全在合成线程运行，性能极优，无 JS 开销
    • 

  • 使用 @supports 渐进增强，确保不支持的浏览器有正常体验
    •
