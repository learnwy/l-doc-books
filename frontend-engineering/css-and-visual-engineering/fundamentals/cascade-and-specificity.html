层叠与优先级

问题背景

当多条 CSS 规则同时作用于同一个元素时，浏览器需要一套确定性的算法来决定"谁赢"。这套算法就是层叠（Cascade）。理解层叠的来源顺序、优先级计算和 !important 的行为，是写出可预测样式的基础；而 CSS 层叠层（@layer）则为大型项目提供了显式的优先级管理。

层叠来源
CSS 规范定义了三个主要来源，优先级从低到高排列：






来源
说明
优先级





用户代理样式（UA）
浏览器内置默认样式
最低




用户样式
用户自定义样式表
中




作者样式
开发者编写的样式
最高







提示： !important 声明会反转来源优先级——UA 的 !important 优先级最高，作者的 !important 反而较低。这是浏览器保护关键样式的机制。






优先级计算
优先级（Specificity）用一个三元组 (A, B, C) 表示：






分量
来源
示例





A
ID 选择器 #id
#header → (1,0,0)




B
类、属性、伪类
.nav[type] → (0,2,0)




C
元素、伪元素
div::before → (0,0,2)





/* (0,0,1) — 仅一个元素选择器 */
p {
  color: black;
}

/* (0,1,1) — 一个类 + 一个元素 */
p.intro {
  color: blue;
}

/* (1,0,1) — 一个 ID + 一个元素 */
#hero p {
  color: red;
}

/* (1,1,1) — ID + 类 + 元素 */
#hero p.intro {
  color: green;
}
比较规则：先比 A，相同再比 B，再比 C。相同优先级时，后声明的规则胜出。




!important 与层叠反转
!important 将声明提升到独立的"重要声明"层叠层，但同时反转了来源顺序：


/* 作者样式 */
.btn {
  background: blue !important;
}

/* 用户代理样式中的 !important 会覆盖作者的 !important */
/* 这就是为什么浏览器能保证 display:none 在 hidden 属性上生效 */


提示： 滥用 !important 是样式难以维护的首要原因。优先通过提升优先级或使用 @layer 来解决冲突。






@layer 层叠层
CSS @layer 允许开发者显式定义层叠层的优先级顺序，让优先级管理脱离选择器复杂度：


/* 声明层顺序：后声明的层优先级更高 */
@layer reset, base, components, utilities;

@layer reset {
  * {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
  }
}

@layer base {
  body {
    font-family: system-ui, sans-serif;
    line-height: 1.6;
  }
  a {
    color: currentColor;
  }
}

@layer components {
  .card {
    border: 1px solid currentColor;
    border-radius: 8px;
    padding: 1rem;
  }
  .btn {
    padding: 0.5rem 1rem;
    border-radius: 4px;
    cursor: pointer;
  }
}

@layer utilities {
  .hidden {
    display: none;
  }
  .sr-only {
    position: absolute;
    width: 1px;
    height: 1px;
    overflow: hidden;
    clip: rect(0 0 0 0);
  }
}
层叠层的核心规则：






场景
行为





同层内冲突
正常优先级 + 顺序规则




跨层冲突
后声明层胜出，与选择器优先级无关




未分层 vs 层内
未分层样式始终胜出




嵌套层
@layer framework.base 支持子层







实战：优先级调试
当样式不符合预期时，可以使用浏览器开发者工具的"计算样式"面板查看哪条规则最终胜出：


<style>
  @layer base, theme;

  @layer base {
    .text {
      color: gray;
    }
  }

  @layer theme {
    .text {
      color: steelblue;
    }
  }

  /* 未分层 — 优先级高于所有层 */
  .text.highlight {
    color: tomato;
  }
</style>

<p class="text highlight">这段文字是什么颜色？</p>
<!-- 答案：tomato，因为未分层样式优先级高于所有 @layer -->

  2. 检查被划掉的规则，了解被覆盖原因
    3. 

  3. 查看 Computed 面板确认最终值
    4. 

  4. 使用 @layer 面板（Chrome 99+）查看层顺序

小结
    

  • 层叠是 CSS 解决冲突的核心算法，依次考虑来源、!important、层叠层、优先级和出现顺序
    • 

  • 优先级用三元组 (A, B, C) 计算，ID > 类/属性/伪类 > 元素/伪元素
    • 

  • !important 将声明提升到独立层并反转来源顺序，应谨慎使用
    • 

  • @layer 提供显式的优先级分层，让大型项目的样式管理更可预测
    • 

  • 未分层样式的优先级始终高于任何 @layer 内的样式
    • 

  • 优先通过架构手段（层叠层、选择器设计）而非 !important 来管理样式冲突
    •
