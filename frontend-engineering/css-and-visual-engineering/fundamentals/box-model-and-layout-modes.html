盒模型与布局模式

问题背景

CSS 中每一个元素都被视为一个矩形的盒子。盒模型定义了这个盒子的尺寸如何计算，而格式化上下文（Formatting Context）决定了这些盒子如何在页面上排列。理解这两者是掌握所有 CSS 布局技术的前提。

content-box vs border-box
CSS 提供两种盒模型计算方式：






属性值
width/height 包含
实际占用宽度





content-box（默认）
仅 content
content + padding + border




border-box
content + padding + border
等于设置的 width





/* content-box（默认） */
.box-content {
  box-sizing: content-box;
  width: 200px;
  padding: 20px;
  border: 2px solid;
  /* 实际宽度 = 200 + 20*2 + 2*2 = 244px */
}

/* border-box */
.box-border {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 2px solid;
  /* 实际宽度 = 200px，content 自动缩小为 156px */
}


提示： 现代开发几乎都使用全局 border-box 重置，避免尺寸计算的心智负担。




*,
*::before,
*::after {
  box-sizing: border-box;
}


margin 折叠
垂直方向上相邻的 margin 会发生折叠（Collapse），取两者中较大的值：


.paragraph-a {
  margin-bottom: 20px;
}
.paragraph-b {
  margin-top: 30px;
}
/* 两者之间的间距 = max(20, 30) = 30px，而非 50px */
margin 折叠的三个条件：


    

  1. 相邻兄弟元素的上下 margin
    2. 

  2. 父元素与第一个/最后一个子元素的 margin
    3. 

  3. 空块级元素的上下 margin
    4. 





格式化上下文
格式化上下文（Formatting Context）是 CSS 布局的核心概念，决定了子元素如何排列。


Block Formatting Context (BFC)
BFC 是一个独立的布局区域，内部元素的布局不影响外部。


触发 BFC 的条件：


/* 以下属性均可创建 BFC */
.bfc-overflow {
  overflow: hidden;
} /* 或 auto / scroll */
.bfc-display {
  display: flow-root;
} /* 专门用于创建 BFC */
.bfc-float {
  float: left;
}
.bfc-position {
  position: absolute;
}
.bfc-flex {
  display: flex;
}
.bfc-grid {
  display: grid;
}
BFC 的实际作用：






场景
效果





包含浮动元素
BFC 会计算浮动子元素的高度




阻止 margin 折叠
BFC 边界不与子元素 margin 折叠




防止文字环绕
BFC 区域不会与浮动元素重叠





<div style="display: flow-root;">
  <div style="float: left; width: 100px; height: 100px;"></div>
  <!-- 父容器会正确包含浮动子元素 -->
</div>
Inline Formatting Context (IFC)
IFC 中元素沿水平方向排列，遵循行盒（line box）规则：


.inline-demo span {
  /* inline 元素的 width/height 无效 */
  /* 垂直方向的 padding/margin 不影响行高 */
  /* 水平方向的 padding/margin 正常生效 */
  padding: 4px 8px;
  margin: 0 4px;
}
Flex Formatting Context
设置 display: flex 后，子元素成为 flex items，脱离常规流规则：


.flex-container {
  display: flex;
  gap: 16px;
  align-items: center;
}

.flex-container > * {
  /* 所有子元素自动成为 flex item */
  /* float、clear、vertical-align 失效 */
  /* 可以使用 flex-grow/shrink/basis */
}
Grid Formatting Context
设置 display: grid 后，子元素参与网格布局：


.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

.grid-container > * {
  /* 所有子元素自动成为 grid item */
  /* 可以使用 grid-column/grid-row 放置 */
}

display 属性的双值语法
现代 CSS 使用双值 display 语法区分外部和内部显示类型：


/* 外部 block + 内部 flex */
.container {
  display: block flex;
} /* 等价于 display: flex */

/* 外部 inline + 内部 flex */
.inline-flex {
  display: inline flex;
} /* 等价于 display: inline-flex */

/* 外部 block + 内部 grid */
.grid {
  display: block grid;
} /* 等价于 display: grid */


提示： 双值语法让 display 的语义更清晰——第一个值控制元素在父级中的行为（外部），第二个值控制子元素的布局（内部）。






小结
    

  • CSS 盒模型由 content、padding、border、margin 四层构成
    • 

  • border-box 是现代开发的标准选择，让 width/height 直接控制可见尺寸
    • 

  • margin 折叠只发生在块级方向（垂直），flex/grid 布局中不会折叠
    • 

  • BFC 是独立布局区域，用 display: flow-root 创建最语义化
    • 

  • 四种格式化上下文（BFC/IFC/Flex/Grid）决定子元素的排列规则
    • 

  • display 双值语法将外部类型和内部类型分离，提升可读性
    •
