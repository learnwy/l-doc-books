定位与层叠上下文

问题背景

CSS 定位允许元素脱离正常文档流，精确控制位置。当多个定位元素重叠时，层叠上下文（Stacking Context） 决定了它们的前后遮挡关系。理解定位类型与层叠上下文的创建条件，是构建复杂 UI 组件（弹窗、下拉菜单、吸顶导航）的必备知识。

五种定位类型
static（默认）
元素处于正常文档流中，top/right/bottom/left/z-index 属性无效：


.default {
  position: static;
}
relative
元素保留在文档流中的原始空间，视觉上相对自身偏移：


.nudge {
  position: relative;
  top: 10px;
  left: 20px;
}
absolute
元素脱离文档流，相对于最近的非 static 定位祖先偏移：


.dropdown {
  position: relative;
}

.dropdown-menu {
  position: absolute;
  top: 100%;
  left: 0;
  width: 200px;
}
fixed
元素相对于视口定位，滚动时不动：


.navbar {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  z-index: 100;
}
sticky
元素在滚动到指定阈值前表现为 relative，到达后"粘"在指定位置：


.section-header {
  position: sticky;
  top: 0;
  z-index: 10;
}


提示： sticky 元素的包含块是其最近的可滚动祖先。如果父元素设置了 overflow: hidden，sticky 可能失效。

层叠上下文
层叠上下文是一个三维概念——元素在 Z 轴方向上的排列由层叠上下文和层叠顺序共同决定。


创建层叠上下文的条件
/* 根元素 <html> 自动创建 */

/* position + z-index */
.ctx-a {
  position: relative;
  z-index: 1;
}
.ctx-b {
  position: absolute;
  z-index: 0;
}

/* 固定/粘性定位始终创建 */
.ctx-c {
  position: fixed;
  top: 0;
}
.ctx-d {
  position: sticky;
  top: 0;
}

/* opacity 小于 1 */
.ctx-e {
  opacity: 0.99;
}

/* transform 非 none */
.ctx-f {
  transform: translateZ(0);
}

/* 其他触发条件 */
.ctx-g {
  filter: blur(0);
}
.ctx-h {
  will-change: transform;
}
.ctx-i {
  isolation: isolate;
}
.ctx-j {
  contain: layout;
}
.ctx-k {
  mix-blend-mode: multiply;
}

z-index 管理策略
大型项目中 z-index 容易失控。推荐使用 CSS 变量建立统一的层级体系：


:root {
  --z-dropdown: 100;
  --z-sticky: 200;
  --z-overlay: 300;
  --z-modal: 400;
  --z-toast: 500;
  --z-tooltip: 600;
}

.dropdown-menu {
  z-index: var(--z-dropdown);
}

.sticky-header {
  z-index: var(--z-sticky);
}

.modal-overlay {
  z-index: var(--z-overlay);
}

.modal {
  z-index: var(--z-modal);
}

.toast {
  z-index: var(--z-toast);
}

.tooltip {
  z-index: var(--z-tooltip);
}
isolation: isolate
isolation: isolate 创建新的层叠上下文但不影响其他属性，是控制层叠范围的最佳工具：


.card {
  isolation: isolate;
}

.card .badge {
  position: absolute;
  top: -8px;
  right: -8px;
  z-index: 1;
}


提示： 给组件根元素加 isolation: isolate 可以防止内部 z-index 泄露到外部，避免不同组件之间的层叠冲突。






常见陷阱
transform 导致 fixed 失效
当祖先元素有 transform 时，position: fixed 子元素的包含块变为该祖先，而非视口：


<div style="transform: translateX(0);">
  <div style="position: fixed; top: 0;">
    <!-- 不会相对视口定位！ -->
    <!-- 而是相对 transform 祖先定位 -->
  </div>
</div>
sticky 失效排查
/* 常见原因 1：父元素 overflow 非 visible */
.parent {
  overflow: hidden; /* sticky 子元素失效 */
}

/* 常见原因 2：未设置 top/bottom 等阈值 */
.sticky-element {
  position: sticky;
  /* 缺少 top: 0; 所以不会粘住 */
}

/* 常见原因 3：父元素高度不够 */
.short-parent {
  height: 50px; /* 子元素没有滚动空间 */
}


小结
    

  • CSS 提供五种定位：static、relative、absolute、fixed、sticky
    • 

  • 层叠上下文由 z-index、transform、opacity、filter 等多种属性触发
    • 

  • 层叠顺序遵循七层规则，同层按 DOM 出现顺序后来居上
    • 

  • 使用 CSS 变量建立 z-index 层级体系可避免数值失控
    • 

  • isolation: isolate 是创建层叠上下文最干净的方式，推荐在组件根元素使用
    • 

  • transform 会改变 fixed 子元素的包含块，是常见的定位陷阱
