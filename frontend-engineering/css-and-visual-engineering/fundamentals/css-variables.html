CSS 自定义属性

问题背景

CSS 自定义属性（Custom Properties，也称 CSS 变量）是原生 CSS 中实现动态值传递的机制。与预处理器变量（Sass $var）不同，CSS 自定义属性在运行时存在、参与层叠、可被 JavaScript 读写，是现代主题系统和组件化样式的核心基础设施。

var() 函数基础
声明与使用
:root {
  --color-primary: #3b82f6;
  --color-secondary: #64748b;
  --spacing-unit: 8px;
  --font-sans: system-ui, -apple-system, sans-serif;
  --radius-md: 8px;
}

.button {
  background-color: var(--color-primary);
  font-family: var(--font-sans);
  padding: calc(var(--spacing-unit) * 2) calc(var(--spacing-unit) * 3);
  border-radius: var(--radius-md);
}
回退值
var() 支持第二个参数作为回退值：


.card {
  /* 如果 --card-bg 未定义，使用 white */
  background: var(--card-bg, white);

  /* 回退值可以包含逗号 */
  font-family: var(--font-heading, Georgia, serif);

  /* 嵌套回退 */
  color: var(--card-color, var(--text-color, #333));
}


提示： 回退值只在变量未定义时生效。如果变量定义了无效值（如 --size: abc 用在 width 上），回退值不会触发，属性会使用初始值。






作用域与继承
CSS 自定义属性遵循正常的层叠与继承规则：


:root {
  --accent: blue;
}

.sidebar {
  --accent: green;
}

.sidebar .link {
  color: var(--accent); /* green — 继承自 .sidebar */
}

.main .link {
  color: var(--accent); /* blue — 继承自 :root */
}
组件级变量
利用作用域特性，可以为组件定义"接口变量"：


.card {
  --_card-padding: var(--card-padding, 1rem);
  --_card-radius: var(--card-radius, 8px);
  --_card-bg: var(--card-bg, white);

  padding: var(--_card-padding);
  border-radius: var(--_card-radius);
  background: var(--_card-bg);
}

/* 使用者可以在外部覆盖 */
.hero .card {
  --card-padding: 2rem;
  --card-radius: 16px;
}


提示： 使用 --_ 前缀表示"私有"变量（纯约定），-- 前缀表示"公开接口"变量。这种模式借鉴了 Open Props 和 Shoelace 等项目的实践。






与 calc() 结合
CSS 自定义属性与 calc() 配合可实现灵活的动态计算：


:root {
  --space-1: 4px;
  --space-2: calc(var(--space-1) * 2); /* 8px */
  --space-3: calc(var(--space-1) * 3); /* 12px */
  --space-4: calc(var(--space-1) * 4); /* 16px */
  --space-8: calc(var(--space-1) * 8); /* 32px */
}

.grid {
  --columns: 3;
  display: grid;
  grid-template-columns: repeat(var(--columns), 1fr);
  gap: var(--space-4);
}

@media (max-width: 768px) {
  .grid {
    --columns: 1;
  }
}


JavaScript 交互
CSS 自定义属性可被 JavaScript 动态读写：


const root = document.documentElement;

// 读取
const primary = getComputedStyle(root).getPropertyValue('--color-primary').trim();

// 写入
root.style.setProperty('--color-primary', '#ef4444');

// 移除（恢复继承值）
root.style.removeProperty('--color-primary');

// 在特定元素上设置
const card = document.querySelector('.card') as HTMLElement;
card.style.setProperty('--card-bg', 'lightyellow');
实战示例——鼠标跟随效果：


document.addEventListener('mousemove', (e: MouseEvent) => {
  document.documentElement.style.setProperty('--mouse-x', `${e.clientX}px`);
  document.documentElement.style.setProperty('--mouse-y', `${e.clientY}px`);
});
.spotlight {
  background: radial-gradient(
    circle at var(--mouse-x, 50%) var(--mouse-y, 50%),
    rgba(255, 255, 255, 0.15),
    transparent 80%
  );
}


动态主题系统
利用 CSS 自定义属性构建完整的主题切换系统：


:root {
  --bg-primary: #ffffff;
  --bg-secondary: #f8fafc;
  --text-primary: #0f172a;
  --text-secondary: #475569;
  --border-color: #e2e8f0;
  --shadow-color: 220 3% 15%;
}

:root[data-theme='dark'] {
  --bg-primary: #0f172a;
  --bg-secondary: #1e293b;
  --text-primary: #f1f5f9;
  --text-secondary: #94a3b8;
  --border-color: #334155;
  --shadow-color: 220 40% 2%;
}

body {
  background: var(--bg-primary);
  color: var(--text-primary);
}

.card {
  background: var(--bg-secondary);
  border: 1px solid var(--border-color);
  box-shadow: 0 4px 6px hsl(var(--shadow-color) / 0.1);
}
function toggleTheme(): void {
  const root = document.documentElement;
  const current = root.getAttribute('data-theme');
  root.setAttribute('data-theme', current === 'dark' ? 'light' : 'dark');
}

@property 类型注册
@property 规则允许为自定义属性声明类型、初始值和继承行为：


@property --progress {
  syntax: '<percentage>';
  inherits: false;
  initial-value: 0%;
}

.progress-bar {
  --progress: 0%;
  background: linear-gradient(to right, currentColor var(--progress), transparent var(--progress));
  transition: --progress 0.3s ease;
}

.progress-bar.complete {
  --progress: 100%;
}


提示： 只有通过 @property 注册的自定义属性才能被 transition 和 @keyframes 动画化。未注册的自定义属性只能离散切换。






小结
    

  • CSS 自定义属性通过 --name 声明、var(--name) 使用，支持回退值
    • 

  • 自定义属性遵循 DOM 树的层叠与继承规则，天然支持作用域
    • 

  • 与 calc() 组合可创建灵活的间距/尺寸系统
    • 

  • JavaScript 可通过 setProperty/getPropertyValue 实时读写，驱动动态效果
    • 

  • 主题系统的核心模式：:root 定义默认值，[data-theme] 属性选择器覆盖
    • 

  • @property 注册自定义属性后可参与过渡和动画，是下一代 CSS 的重要能力
    •
