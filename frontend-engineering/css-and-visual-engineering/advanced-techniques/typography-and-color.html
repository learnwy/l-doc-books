字体排印与色彩

问题背景

字体排印（Typography）和色彩是视觉设计的两大基石。在 Web 上，字体加载策略影响性能和视觉稳定性，可变字体带来了前所未有的灵活性。色彩方面，新的色彩空间（oklch）和色彩函数让 CSS 的色彩表达能力跃升到新层次。

字体加载策略
@font-face 与 font-display
@font-face {
  font-family: 'Inter';
  src: url('/fonts/Inter-Variable.woff2') format('woff2-variations');
  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}




font-display
行为
适用场景





auto
浏览器默认（通常 block）
—




block
隐藏文字直到字体加载（最多 3s）
图标字体




swap
立即显示回退字体，加载后替换
正文字体（推荐）




fallback
极短隐藏（100ms），短窗口交换
平衡方案




optional
极短隐藏，仅缓存有时交换
非关键装饰字体





预加载关键字体
<link rel="preload" href="/fonts/Inter-Variable.woff2" as="font" type="font/woff2" crossorigin />
防止布局偏移
body {
  font-family:
    'Inter',
    system-ui,
    -apple-system,
    sans-serif;
}

@font-face {
  font-family: 'Inter';
  src: url('/fonts/Inter-Variable.woff2') format('woff2-variations');
  font-weight: 100 900;
  font-display: swap;
  /* 使用 size-adjust 匹配回退字体的度量 */
  size-adjust: 100%;
  ascent-override: 90%;
  descent-override: 22%;
  line-gap-override: 0%;
}


提示： 使用 @font-face 的度量覆盖属性（size-adjust、ascent-override 等）可以让回退字体与自定义字体的度量尽量接近，减少字体交换时的布局偏移（CLS）。






可变字体
可变字体（Variable Fonts）将多个字重、字宽等变体打包在一个文件中：


.title {
  font-family: 'Inter', sans-serif;
  font-weight: 700;
  font-variation-settings:
    'wght' 700,
    'slnt' -10;
}

.body {
  font-weight: 400;
}

.thin {
  font-weight: 100;
}

/* 动画字重 */
@keyframes weightPulse {
  0%,
  100% {
    font-weight: 400;
  }
  50% {
    font-weight: 700;
  }
}

.animating-text {
  animation: weightPulse 2s ease-in-out infinite;
}

色彩空间
从 sRGB 到 oklch
/* 传统 sRGB */
.old-way {
  color: rgb(59, 130, 246);
  color: #3b82f6;
  color: hsl(217, 91%, 60%);
}

/* 现代 oklch */
.new-way {
  color: oklch(63% 0.21 255);
  /* L: 感知亮度 0-100% */
  /* C: 色度（饱和度）0-0.4 */
  /* H: 色相 0-360 */
}

颜色插值







提示： oklch 的感知均匀性意味着：改变色相（H）时，亮度保持不变。这让生成和谐的调色板变得简单可靠。






色彩函数
color-mix()
.mixed {
  /* 在 oklch 空间混合两种颜色 */
  background: color-mix(in oklch, var(--accent), white 20%);
}

.hover-lighten {
  background: var(--accent);
}

.hover-lighten:hover {
  background: color-mix(in oklch, var(--accent), white 15%);
}

.hover-darken:hover {
  background: color-mix(in oklch, var(--accent), black 15%);
}
相对颜色语法
.brand {
  --brand: oklch(60% 0.2 250);

  /* 基于品牌色派生 */
  --brand-light: oklch(from var(--brand) calc(l + 20%) c h);
  --brand-dark: oklch(from var(--brand) calc(l - 20%) c h);
  --brand-muted: oklch(from var(--brand) l calc(c * 0.5) h);
}
生成调色板
:root {
  --hue: 250;

  --color-50: oklch(97% 0.02 var(--hue));
  --color-100: oklch(93% 0.04 var(--hue));
  --color-200: oklch(87% 0.08 var(--hue));
  --color-300: oklch(77% 0.12 var(--hue));
  --color-400: oklch(67% 0.16 var(--hue));
  --color-500: oklch(57% 0.2 var(--hue));
  --color-600: oklch(47% 0.18 var(--hue));
  --color-700: oklch(40% 0.15 var(--hue));

}


小结
    

  • 字体加载推荐 font-display: swap + <link rel="preload">，减少 FOUT/FOIT
    • 

  • 可变字体单文件包含所有字重变体，减少请求数，支持流畅的字重动画
    • 

  • 流式排版用 clamp() 创建响应式字号系统，text-wrap: balance 优化标题排版
    • 

  • oklch 是感知均匀的色彩空间，改变色相时亮度保持一致
    • 

  • color-mix() 在指定色彩空间中混合颜色，替代手动计算悬停/禁用色
    • 

  • 相对颜色语法 可基于一个基准色派生整个调色板
    •
