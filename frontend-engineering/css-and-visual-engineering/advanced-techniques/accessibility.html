无障碍访问

问题背景

无障碍访问（Accessibility，简称 a11y）确保所有人——包括视觉、运动、认知障碍用户——都能使用 Web 应用。CSS 和视觉工程在无障碍中扮演关键角色：焦点可见性、颜色对比度、屏幕阅读器兼容和键盘导航都直接影响用户体验。无障碍不是锦上添花，而是法律要求（WCAG 2.1 AA 标准）。

焦点管理
focus-visible
focus-visible 只在键盘导航时显示焦点样式，点击时不显示：


/* 移除默认 outline（同时提供替代方案） */
:focus {
  outline: none;
}

/* 键盘导航时显示焦点 */
:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}

/* 按钮焦点 */
.button:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
  box-shadow: 0 0 0 4px rgba(59, 130, 246, 0.3);
}

/* 输入框焦点 */
.input:focus-visible {
  border-color: var(--accent);
  box-shadow: 0 0 0 3px rgba(59, 130, 246, 0.2);
}


提示： 永远不要写 *:focus { outline: none; } 而不提供替代方案。这会让键盘用户完全无法知道焦点在哪里。




焦点陷阱
模态对话框应该将焦点限制在内部：


function trapFocus(element: HTMLElement): void {
  const focusableElements = element.querySelectorAll<HTMLElement>(
    'a[href], button:not([disabled]), textarea, input, select, [tabindex]:not([tabindex="-1"])',
  );
  const firstFocusable = focusableElements[0];
  const lastFocusable = focusableElements[focusableElements.length - 1];

  element.addEventListener('keydown', (e: KeyboardEvent) => {
    if (e.key !== 'Tab') return;

    if (e.shiftKey) {
      if (document.activeElement === firstFocusable) {
        lastFocusable.focus();
        e.preventDefault();
      }
    } else {
      if (document.activeElement === lastFocusable) {
        firstFocusable.focus();
        e.preventDefault();
      }
    }
  });

  firstFocusable.focus();
}

.good-contrast {
  color: #1e293b;
  background: #ffffff;
}

/* 失败 — 对比度 2.4:1 */
.bad-contrast {
  color: #94a3b8;

/* 使用 CSS 变量确保主题切换后也满足对比度 */
:root {
  --text-primary: #0f172a; /* 对白色背景 15.4:1 */
  --text-secondary: #475569; /* 对白色背景 7.1:1 — AA 通过 */
  --text-tertiary: #64748b; /* 对白色背景 4.6:1 — AA 大文本通过 */
}
非文本元素对比度
/* 图标和交互元素需要 3:1 对比度 */
.icon-button {
  color: var(--text-secondary); /* 确保图标与背景的对比度 ≥ 3:1 */
}

/* 边框也需要足够对比度 */
.input {
  border: 1px solid #94a3b8; /* 对白色背景 2.7:1 — 可能不够 */
  border: 1px solid #64748b; /* 对白色背景 4.6:1 — 通过 */
}

提示： 优先使用语义化 HTML 而非 ARIA。语义化标签自带键盘交互和屏幕阅读器支持，无需额外 JavaScript。






ARIA 属性
常用 ARIA 属性
<!-- 状态 -->
<button aria-expanded="false" aria-controls="dropdown-menu">菜单</button>
<div id="dropdown-menu" aria-hidden="true">...</div>

<!-- 标签 -->
<input aria-label="搜索" type="search" />
<div aria-labelledby="section-title">
  <h2 id="section-title">最近文章</h2>
</div>

<!-- 实时区域 -->
<div aria-live="polite" aria-atomic="true">
  <!-- 内容变化时屏幕阅读器会朗读 -->
</div>

<!-- 角色 -->
<div role="tablist">
  <button role="tab" aria-selected="true" aria-controls="panel-1">Tab 1</button>
  <button role="tab" aria-selected="false" aria-controls="panel-2">Tab 2</button>
</div>
CSS 中利用 ARIA 状态
/* 利用 ARIA 属性做样式选择器 */
[aria-expanded='true'] > .icon {
  transform: rotate(180deg);
}

[aria-selected='true'] {
  border-bottom: 2px solid var(--accent);
  font-weight: 600;
}

[aria-disabled='true'] {
  opacity: 0.5;
  cursor: not-allowed;
  pointer-events: none;
}

[aria-invalid='true'] {
  border-color: var(--color-error);
}

常见键盘模式
function handleKeyDown(e: KeyboardEvent, items: HTMLElement[], activeIndex: number): number {
  switch (e.key) {
    case 'ArrowDown':
    case 'ArrowRight':
      e.preventDefault();
      const next = (activeIndex + 1) % items.length;
      items[next].focus();
      return next;

    case 'ArrowUp':
    case 'ArrowLeft':
      e.preventDefault();
      const prev = (activeIndex - 1 + items.length) % items.length;
      items[prev].focus();
      return prev;

    case 'Home':
      e.preventDefault();
      items[0].focus();
      return 0;

    case 'End':
      e.preventDefault();
      items[items.length - 1].focus();
      return items.length - 1;

    default:
      return activeIndex;
  }
}


减弱动效偏好
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
function prefersReducedMotion(): boolean {
  return window.matchMedia('(prefers-reduced-motion: reduce)').matches;
}

小结
    

  • focus-visible 区分键盘和鼠标焦点，提供正确的视觉反馈
    • 

  • 颜色对比度必须满足 WCAG AA 标准：正常文本 4.5:1，大文本 3:1
    • 

  • .sr-only 类让内容对屏幕阅读器可见但视觉隐藏
    • 

  • 优先使用语义化 HTML（<button>、<nav>、<dialog>）而非 ARIA
    • 

  • ARIA 属性可以同时作为 CSS 选择器，实现样式与状态的统一
    • 

  • 键盘导航要支持方向键、Home/End、Escape 等标准模式
    • 

  • 尊重 prefers-reduced-motion 用户偏好，减少或消除动画
    •
