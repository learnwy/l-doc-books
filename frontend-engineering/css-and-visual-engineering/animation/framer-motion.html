Framer Motion 动画库

问题背景

Framer Motion 是 React 生态中最流行的动画库。它以声明式 API 融入 React 组件模型，让动画成为 JSX 的一部分。从简单的过渡到复杂的布局动画、手势交互和页面切换，Framer Motion 都能优雅实现，且与 React 的生命周期完美配合。

motion 组件
Framer Motion 的核心是 motion 组件——普通 HTML 元素的增强版：


import { motion } from 'framer-motion';

function FadeInBox() {
  return (
    <motion.div
      initial={{ opacity: 0, y: 20 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{ duration: 0.5, ease: 'easeOut' }}
    >
      Hello Framer Motion
    </motion.div>
  );
}
核心属性




属性
说明





initial
初始状态




animate
目标状态




exit
退出状态（需配合 AnimatePresence）




transition
过渡配置




whileHover
悬停状态




whileTap
点击状态




whileFocus
聚焦状态




whileInView
进入视口时的状态





function InteractiveCard() {
  return (
    <motion.div
      whileHover={{ scale: 1.02, boxShadow: '0 10px 30px rgba(0,0,0,0.15)' }}
      whileTap={{ scale: 0.98 }}
      transition={{ type: 'spring', stiffness: 300, damping: 20 }}
    >
      Interactive Card
    </motion.div>
  );
}


Variants 变体系统
Variants 定义命名的动画状态，支持父子组件联动和交错动画：


const containerVariants = {
  hidden: { opacity: 0 },
  visible: {
    opacity: 1,
    transition: {
      staggerChildren: 0.1,
      delayChildren: 0.2,
    },
  },
};

const itemVariants = {
  hidden: { opacity: 0, y: 20 },
  visible: {
    opacity: 1,
    y: 0,
    transition: { type: 'spring', stiffness: 100 },
  },
};

function StaggerList({ items }: { items: string[] }) {
  return (
    <motion.ul
      variants={containerVariants}
      initial="hidden"
      animate="visible"
    >
      {items.map((item) => (
        <motion.li key={item} variants={itemVariants}>
          {item}
        </motion.li>
      ))}
    </motion.ul>
  );
}


提示： Variants 的字符串标签自动向下传播——子组件不需要单独设置 initial 和 animate，只要定义同名的 variants 即可。






过渡类型
Framer Motion 支持两种过渡类型：






类型
配置
适用场景





tween
duration、ease
精确控制时长




spring
stiffness、damping、mass
自然物理效果





// Tween（基于时间）
<motion.div
  animate={{ x: 200 }}
  transition={{
    type: 'tween',
    duration: 0.5,
    ease: [0.4, 0, 0.2, 1],
  }}
/>

// Spring（基于物理）
<motion.div
  animate={{ x: 200 }}
  transition={{
    type: 'spring',
    stiffness: 200,
    damping: 15,
    mass: 1,
  }}
/>

// 不同属性不同过渡
<motion.div
  animate={{ x: 200, opacity: 1 }}
  transition={{
    x: { type: 'spring', stiffness: 200 },
    opacity: { duration: 0.3 },
  }}
/>


Layout 动画
Framer Motion 的杀手级功能——自动对布局变化做平滑过渡：


function ExpandableCard({ isExpanded }: { isExpanded: boolean }) {
  return (
    <motion.div
      layout
      style={{
        width: isExpanded ? 400 : 200,
        height: isExpanded ? 300 : 100,
        borderRadius: 12,
      }}
      transition={{ type: 'spring', stiffness: 200, damping: 25 }}
    >
      <motion.h3 layout="position">标题</motion.h3>
      {isExpanded && (
        <motion.p
          initial={{ opacity: 0 }}
          animate={{ opacity: 1 }}
        >
          展开的内容
        </motion.p>
      )}
    </motion.div>
  );
}
layoutId 共享布局动画
function Gallery({ selectedId, items }: { selectedId: string | null; items: Item[] }) {
  return (
    <div className="grid">
      {items.map((item) => (
        <motion.div key={item.id} layoutId={item.id}>
          <img src={item.thumb} alt={item.title} />
        </motion.div>
      ))}

      {selectedId && (
        <motion.div layoutId={selectedId} className="overlay">
          <img src={items.find(i => i.id === selectedId)?.full} alt="" />
        </motion.div>
      )}
    </div>
  );
}


提示： layoutId 让两个不同 DOM 位置的元素共享动画——当一个挂载另一个卸载时，Framer Motion 自动在两者之间创建平滑过渡。






手势动画
function DraggableBox() {
  return (
    <motion.div
      drag
      dragConstraints={{ left: -100, right: 100, top: -50, bottom: 50 }}
      dragElastic={0.2}
      dragTransition={{ bounceStiffness: 300, bounceDamping: 10 }}
      whileDrag={{ scale: 1.1, cursor: 'grabbing' }}
    />
  );
}

function PanGesture() {
  return (
    <motion.div
      onPan={(e, info) => {
        console.log(info.point.x, info.point.y);
      }}
      onPanEnd={(e, info) => {
        if (Math.abs(info.velocity.x) > 500) {
          console.log('快速滑动');
        }
      }}
    />
  );
}


AnimatePresence
AnimatePresence 让组件在从 React 树中卸载时也能播放退出动画：


import { AnimatePresence, motion } from 'framer-motion';

function Modal({ isOpen, onClose }: { isOpen: boolean; onClose: () => void }) {
  return (
    <AnimatePresence>
      {isOpen && (
        <motion.div
          key="modal-overlay"
          initial={{ opacity: 0 }}
          animate={{ opacity: 1 }}
          exit={{ opacity: 0 }}
          onClick={onClose}
          className="overlay"
        >
          <motion.div
            key="modal-content"
            initial={{ opacity: 0, scale: 0.9, y: 20 }}
            animate={{ opacity: 1, scale: 1, y: 0 }}
            exit={{ opacity: 0, scale: 0.9, y: 20 }}
            transition={{ type: 'spring', damping: 25 }}
            onClick={(e) => e.stopPropagation()}
          >
            Modal Content
          </motion.div>
        </motion.div>
      )}
    </AnimatePresence>
  );
}
页面切换
import { AnimatePresence, motion } from 'framer-motion';

const pageVariants = {
  initial: { opacity: 0, x: 20 },
  animate: { opacity: 1, x: 0 },
  exit: { opacity: 0, x: -20 },
};

function PageTransition({ children, key }: { children: React.ReactNode; key: string }) {
  return (
    <AnimatePresence mode="wait">
      <motion.div
        key={key}
        variants={pageVariants}
        initial="initial"
        animate="animate"
        exit="exit"
        transition={{ duration: 0.3 }}
      >
        {children}
      </motion.div>
    </AnimatePresence>
  );
}




AnimatePresence mode
行为





sync（默认）
新旧组件同时动画




wait
旧组件退出完成后，新组件才进入




popLayout
退出元素从文档流中移除，新元素立即占位







小结
    

  • motion 组件是增强版 HTML 元素，通过 initial/animate/exit 声明动画状态
    • 

  • Variants 定义命名状态并自动向子组件传播，支持 staggerChildren 交错
    • 

  • Spring 过渡基于物理模型，比基于时间的 tween 更自然
    • 

  • Layout 动画自动对布局变化做平滑过渡，layoutId 实现跨组件共享动画
    • 

  • 手势动画（drag、whileHover、whileTap）让交互动效成为声明式属性
    • 

  • AnimatePresence 是 React 退出动画的标准方案，mode="wait" 实现页面切换
    •
