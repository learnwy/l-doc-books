过渡与变换

问题背景

CSS 过渡（Transition）和变换（Transform）是实现流畅 UI 交互的基础。过渡让属性值的变化平滑地发生在一段时间内，变换则提供了旋转、缩放、平移和倾斜等几何操作。两者结合可以创造出丝滑的悬停效果、展开动画和微交互，同时保持 60fps 的性能。

transition 基础
语法与属性
.button {
  background: steelblue;
  color: white;
  padding: 0.75rem 1.5rem;
  border-radius: 6px;
  transition:
    background 0.2s ease,
    transform 0.2s ease;
}

.button:hover {
  background: royalblue;
  transform: translateY(-2px);
}

.button:active {
  transform: translateY(0);
}
四个子属性




属性
说明
默认值





transition-property
要过渡的属性
all




transition-duration
持续时间
0s




transition-timing-function
缓动函数
ease




transition-delay
延迟
0s





.card {
  transition-property: transform, box-shadow;
  transition-duration: 0.3s;
  transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1);
  transition-delay: 0s;

  /* 简写 */
  transition:
    transform 0.3s cubic-bezier(0.4, 0, 0.2, 1),
    box-shadow 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}


缓动函数
缓动函数决定了动画的速度曲线：


.linear {
  transition-timing-function: linear;
}
.ease {
  transition-timing-function: ease;
}
.ease-in {
  transition-timing-function: ease-in;
}
.ease-out {
  transition-timing-function: ease-out;
}
.ease-in-out {
  transition-timing-function: ease-in-out;
}
.custom {
  transition-timing-function: cubic-bezier(0.34, 1.56, 0.64, 1);
}
.steps {
  transition-timing-function: steps(5, end);
}


提示： 在 UI 交互中，ease-out 最符合自然感知——元素快速响应用户操作，然后缓慢到达目标位置。Material Design 推荐使用 cubic-bezier(0.4, 0, 0.2, 1)。






transform 函数
2D 变换
.translate {
  transform: translate(20px, 10px);
}
.translate-x {
  transform: translateX(50%);
}

.scale {
  transform: scale(1.1);
}
.scale-xy {
  transform: scale(1.2, 0.8);
}

.rotate {
  transform: rotate(45deg);
}

.skew {
  transform: skew(10deg, 5deg);
}

/* 组合变换（顺序影响结果） */
.combined {
  transform: translateX(100px) rotate(45deg) scale(1.5);
}
3D 变换
.flip {
  transform: perspective(800px) rotateY(180deg);
}

.tilt {
  transform: perspective(1000px) rotateX(5deg) rotateY(-5deg);
}

.depth {
  transform: translateZ(50px);
}
transform-origin
.from-center {
  transform-origin: center;
} /* 默认 */
.from-top-left {
  transform-origin: top left;
}
.from-bottom {
  transform-origin: center bottom;
}
.custom-origin {
  transform-origin: 20% 80%;
}


GPU 加速与性能
并非所有 CSS 属性都适合做动画。可分为三类：






类别
属性
性能
说明





合成层（最优）
transform、opacity
极佳
只触发合成，不重排不重绘




绘制层
color、background、box-shadow
中等
触发重绘




布局层（最差）
width、height、margin、padding
差
触发重排+重绘





/* 推荐：使用 transform 代替位置属性 */
.good {
  transform: translateX(100px); /* GPU 加速 */
}

/* 避免：直接动画布局属性 */
.bad {
  left: 100px; /* 触发重排 */
}
will-change 提示
.will-animate {
  will-change: transform;
}

.will-animate:hover {
  transform: scale(1.05);
}


提示： will-change 会提前创建合成层，消耗内存。只在即将动画的元素上使用，动画结束后应移除。不要全局设置 * { will-change: transform; }。






可过渡属性
并非所有属性都能过渡。常见可过渡属性：


/* 可以过渡 */
.transitionable {
  opacity: 1;
  transform: scale(1);
  color: black;
  background-color: white;
  border-color: gray;
  box-shadow: none;
  filter: blur(0);
  clip-path: inset(0);
}

/* 不能过渡 */
.not-transitionable {
  display: block; /* 离散值，不能过渡 */
  visibility: visible; /* 可以过渡（2值之间） */
  font-family: sans-serif; /* 不能过渡 */
}
新特性：transition-behavior
.popup {
  transition:
    opacity 0.3s,
    display 0.3s allow-discrete;
  opacity: 1;
}

.popup.hidden {
  opacity: 0;
  display: none;
}


常见交互模式
悬停卡片浮起
.card {
  transition:
    transform 0.2s ease-out,
    box-shadow 0.2s ease-out;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 24px rgba(0, 0, 0, 0.15);
}
按钮按下反馈
.btn {
  transition: transform 0.1s ease;
}

.btn:active {
  transform: scale(0.96);
}
展开/收起
.accordion-content {
  display: grid;
  grid-template-rows: 0fr;
  transition: grid-template-rows 0.3s ease;
}

.accordion.open .accordion-content {
  grid-template-rows: 1fr;
}

.accordion-content > div {
  overflow: hidden;
}


小结
    

  • transition 让属性变化平滑进行，核心参数：属性、持续时间、缓动、延迟
    • 

  • 缓动函数决定动画节奏，UI 交互推荐 ease-out 或 Material 的 cubic-bezier(0.4, 0, 0.2, 1)
    • 

  • transform 提供平移、缩放、旋转、倾斜等几何变换，不影响文档流
    • 

  • 只有 transform 和 opacity 能触发 GPU 合成，性能最优
    • 

  • will-change 提前创建合成层，但应按需使用，避免内存浪费
    • 

  • 用 transform 替代 top/left 等布局属性做位移动画是性能最佳实践
    •
