GSAP 核心

问题背景

GSAP（GreenSock Animation Platform）是 Web 上最强大的 JavaScript 动画库。当 CSS 动画无法满足需求时——复杂的时间轴编排、滚动驱动动画、精确的进度控制——GSAP 是首选方案。它的性能经过极致优化，API 简洁一致，在 2000 万+ 网站上运行。

Tween 基础
Tween 是 GSAP 的基本动画单元，控制一个或多个属性从一个值变到另一个值：


import gsap from 'gsap';

gsap.to('.box', {
  x: 200,
  rotation: 360,
  duration: 1,
  ease: 'power2.out',
});

gsap.from('.title', {
  opacity: 0,
  y: 50,
  duration: 0.8,
});

gsap.fromTo('.element', { opacity: 0, scale: 0.5 }, { opacity: 1, scale: 1, duration: 0.6 });

gsap.set('.hidden', { opacity: 0, y: 20 });




方法
说明





gsap.to()
从当前状态动画到目标状态




gsap.from()
从指定状态动画到当前状态




gsap.fromTo()
指定起始和结束状态




gsap.set()
立即设置属性（无动画）





常用属性映射
gsap.to('.box', {
  x: 100, // transform: translateX(100px)
  y: -50, // transform: translateY(-50px)
  rotation: 45, // transform: rotate(45deg)
  scale: 1.2, // transform: scale(1.2)
  scaleX: 2, // transform: scaleX(2)
  opacity: 0.5,
  borderRadius: '50%',
  backgroundColor: '#3b82f6',
  duration: 1,
});


缓动函数
GSAP 内置了丰富的缓动函数：


gsap.to('.a', { x: 200, ease: 'none' });
gsap.to('.b', { x: 200, ease: 'power1.out' });
gsap.to('.c', { x: 200, ease: 'power2.inOut' });
gsap.to('.d', { x: 200, ease: 'back.out(1.7)' });
gsap.to('.e', { x: 200, ease: 'elastic.out(1, 0.3)' });
gsap.to('.f', { x: 200, ease: 'bounce.out' });




缓动
效果
适用场景





power1-4.out
由快到慢（数字越大越急）
UI 进入




power1-4.in
由慢到快
UI 退出




back.out
超出后回弹
弹性进入




elastic.out
弹簧效果
强调动画




bounce.out
弹跳
落地效果







Timeline 时间轴
Timeline 是 GSAP 最强大的功能——将多个 Tween 编排为有序的动画序列：


const tl = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });

tl.from('.hero-title', { opacity: 0, y: 50 })
  .from('.hero-subtitle', { opacity: 0, y: 30 }, '-=0.3')
  .from('.hero-button', { opacity: 0, scale: 0.8 }, '-=0.2')
  .from('.hero-image', { opacity: 0, x: 100 }, '-=0.4');
位置参数
const tl = gsap.timeline();

tl.to('.a', { x: 100, duration: 1 }) // 从 0s 开始
  .to('.b', { x: 100, duration: 1 }) // 紧跟上一个结束
  .to('.c', { x: 100, duration: 1 }, '+=0.5') // 上一个结束后延迟 0.5s
  .to('.d', { x: 100, duration: 1 }, '-=0.3') // 上一个结束前 0.3s
  .to('.e', { x: 100, duration: 1 }, 2) // 绝对时间 2s
  .to('.f', { x: 100, duration: 1 }, '<') // 与上一个同时开始
  .to('.g', { x: 100, duration: 1 }, '<0.2'); // 上一个开始后 0.2s


Stagger 交错
gsap.from('.card', {
  opacity: 0,
  y: 40,
  duration: 0.6,
  stagger: 0.1,
  ease: 'power2.out',
});

gsap.from('.grid-item', {
  opacity: 0,
  scale: 0.5,
  duration: 0.5,
  stagger: {
    amount: 1,
    grid: [4, 4],
    from: 'center',
    ease: 'power1.out',
  },
});




stagger 选项
说明





amount
总交错时间




each
每个元素的间隔




from
起始位置：'start'/'end'/'center'/'edges'/index




grid
网格布局的行列数







ScrollTrigger
ScrollTrigger 是 GSAP 的滚动驱动插件：


import { ScrollTrigger } from 'gsap/ScrollTrigger';
gsap.registerPlugin(ScrollTrigger);

gsap.from('.section-title', {
  scrollTrigger: {
    trigger: '.section-title',
    start: 'top 80%',
    end: 'top 20%',
    toggleActions: 'play none none reverse',
  },
  opacity: 0,
  y: 60,
  duration: 0.8,
});

gsap.to('.progress-bar', {
  scrollTrigger: {
    trigger: '.content',
    start: 'top top',
    end: 'bottom bottom',
    scrub: true,
  },
  scaleX: 1,
  transformOrigin: 'left center',
});
固定（Pin）
ScrollTrigger.create({
  trigger: '.panel',
  start: 'top top',
  end: '+=500',
  pin: true,
  pinSpacing: true,
});
toggleActions
// toggleActions: "进入时 离开时 再进入时 再离开时"
// 可选值: play, pause, resume, reset, restart, complete, reverse, none
scrollTrigger: {
  toggleActions: 'play none none reverse',
}


控制与回调
const tween = gsap.to('.box', {
  x: 500,
  duration: 2,
  paused: true,
  onStart: () => console.log('开始'),
  onUpdate: (self) => console.log(`进度: ${self.progress()}`),
  onComplete: () => console.log('完成'),
  onReverseComplete: () => console.log('反向完成'),
});

tween.play();
tween.pause();
tween.reverse();
tween.restart();
tween.progress(0.5);
tween.timeScale(2);
tween.kill();


小结
    

  • Tween 是基本动画单元：to()、from()、fromTo()、set()
    • 

  • 缓动函数丰富（power、back、elastic、bounce），power2.out 是通用选择
    • 

  • Timeline 将多个 Tween 编排为序列，位置参数（-=、<、绝对时间）控制时序
    • 

  • Stagger 一行代码实现交错动画，支持网格布局和自定义起始点
    • 

  • ScrollTrigger 是滚动驱动动画的标准方案，支持 scrub、pin、toggleActions
    • 

  • GSAP 的 kill() 方法可以清理动画实例，避免内存泄漏
    •
