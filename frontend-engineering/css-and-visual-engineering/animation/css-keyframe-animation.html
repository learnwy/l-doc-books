CSS 关键帧动画

问题背景

CSS @keyframes 动画相比 transition 提供了更强大的控制能力——可以定义多个中间状态、无限循环、自动播放，无需触发条件。从加载指示器、骨架屏闪烁到复杂的入场动画，关键帧动画是纯 CSS 动效的核心工具。

@keyframes 语法
基本定义
@keyframes fadeIn {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

@keyframes pulse {
  0% {
    transform: scale(1);
  }
  50% {
    transform: scale(1.05);
  }
  100% {
    transform: scale(1);
  }
}

@keyframes rainbow {
  0% {
    color: red;
  }
  17% {
    color: orange;
  }
  33% {
    color: yellow;
  }
  50% {
    color: green;
  }
  67% {
    color: blue;
  }
  83% {
    color: indigo;
  }
  100% {
    color: violet;
  }
}


animation 属性
八个子属性




属性
说明
常用值





animation-name
关键帧名称
fadeIn




animation-duration
持续时间
0.3s




animation-timing-function
缓动函数
ease-out




animation-delay
延迟
0s




animation-iteration-count
播放次数
1 / infinite




animation-direction
播放方向
normal / alternate




animation-fill-mode
填充模式
forwards / both




animation-play-state
播放状态
running / paused





.element {
  animation-name: fadeIn;
  animation-duration: 0.5s;
  animation-timing-function: ease-out;
  animation-delay: 0.1s;
  animation-iteration-count: 1;
  animation-direction: normal;
  animation-fill-mode: both;
  animation-play-state: running;

  /* 简写 */
  animation: fadeIn 0.5s ease-out 0.1s 1 normal both;
}
fill-mode 详解
/* 动画结束后保持最终状态 */
.fade-in {
  opacity: 0;
  animation: fadeIn 0.5s ease-out forwards;
}

/* 延迟期间就应用起始帧 + 结束后保持 */
.delayed-fade {
  animation: fadeIn 0.5s ease-out 0.3s both;
}


提示： 大多数场景下使用 both 最安全——延迟期间显示初始帧，结束后保持最终帧。






多动画串联
同时播放多个动画
.element {
  animation:
    slideIn 0.5s ease-out,
    fadeIn 0.5s ease-out;
}
顺序播放（通过延迟）
.step-1 {
  animation: fadeIn 0.3s ease-out both;
}

.step-2 {
  animation: fadeIn 0.3s ease-out 0.2s both;
}

.step-3 {
  animation: fadeIn 0.3s ease-out 0.4s both;
}
交错动画
@keyframes slideUp {
  from {
    opacity: 0;
    transform: translateY(30px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.list-item {
  animation: slideUp 0.4s ease-out both;
}

.list-item:nth-child(1) {
  animation-delay: 0ms;
}
.list-item:nth-child(2) {
  animation-delay: 50ms;
}
.list-item:nth-child(3) {
  animation-delay: 100ms;
}
.list-item:nth-child(4) {
  animation-delay: 150ms;
}
.list-item:nth-child(5) {
  animation-delay: 200ms;
}
使用 CSS 自定义属性简化：


.list-item {
  animation: slideUp 0.4s ease-out both;
  animation-delay: calc(var(--index, 0) * 50ms);
}

</ul>


动画事件
JavaScript 可以监听动画的生命周期事件：


const el = document.querySelector('.animated') as HTMLElement;

el.addEventListener('animationstart', (e: AnimationEvent) => {
  console.log(`动画 ${e.animationName} 开始`);
});

el.addEventListener('animationiteration', (e: AnimationEvent) => {
  console.log(`动画 ${e.animationName} 完成一次迭代`);
});

el.addEventListener('animationend', (e: AnimationEvent) => {
  console.log(`动画 ${e.animationName} 结束`);
  el.classList.remove('animated');
});

el.addEventListener('animationcancel', (e: AnimationEvent) => {
  console.log(`动画 ${e.animationName} 被取消`);
});

@keyframes shimmer {
  0% {
    background-position: -200% 0;
  }

  }
}

  background: linear-gradient(90deg, var(--skeleton-base) 25%, var(--skeleton-shine) 50%, var(--skeleton-base) 75%);
  background-size: 200% 100%;
  animation: shimmer 1.5s ease-in-out infinite;

打字机效果
@keyframes typing {
  from {
    width: 0;
  }
  to {
    width: 100%;
  }
}

@keyframes blink {
  50% {
    border-color: transparent;
  }
}

.typewriter {
  overflow: hidden;
  white-space: nowrap;
  border-right: 3px solid;
  width: 0;

    typing 3s steps(30) forwards,
    blink 0.7s step-end infinite;

  }

    transform: scale(1.05);
  }
  70% {
    transform: scale(0.95);
  }
  100% {
    transform: scale(1);
  }
}

.bounce-in {
  animation: bounceIn 0.6s cubic-bezier(0.68, -0.55, 0.27, 1.55) both;
}


无障碍：减弱动效
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}


提示： 永远不要完全移除动画——保留极短的持续时间可以确保 animationend 事件正常触发，避免依赖该事件的 JavaScript 逻辑失效。






小结
    

  • @keyframes 定义多个关键帧，浏览器自动补间生成平滑动画
    • 

  • animation 简写包含 8 个子属性，fill-mode: both 是最常用的填充模式
    • 

  • 交错动画通过 animation-delay + CSS 变量实现，无需 JavaScript
    • 

  • 动画事件（animationstart/end/iteration/cancel）可与 JS 联动
    • 

  • 常见模式：旋转器、骨架屏、打字机、弹跳入场
    • 

  • prefers-reduced-motion 必须尊重用户的减弱动效偏好
    •
