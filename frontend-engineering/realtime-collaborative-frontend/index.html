实时协作前端

实时协作前端（Real-time Collaborative Frontend）是 Google Docs 在 2006 年开创、Figma 在 2016 年大规模展示、Notion / Linear / Liveblocks 让现代 Web 应用默认期望的能力——多用户同时编辑同一份文档 / 画布 / 数据，实时看到他人的光标、选区、编辑。技术栈包括传输层（WebSocket、SSE、WebRTC）加上数据层（CRDT、OT）加上体验层（在场感知、光标、冲突解决）。CRDT（Yjs、Automerge）让并发编辑能自动合并，无需服务端协调。Liveblocks、PartyKit、Replicache 是现代的协作平台代表。本 Hub 给前端工程师一条工程化路径——基础（WebSocket / SSE / WebRTC、扩展）、协作数据（CRDT、Yjs、OT、在场感知）、协作体验（光标、选区、冲突、权限）、生产部署（服务端架构、平台选型、测试）。
