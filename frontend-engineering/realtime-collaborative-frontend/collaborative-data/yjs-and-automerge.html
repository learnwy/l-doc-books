Yjs 与 Automerge

核心概念

Yjs（Kevin Jahns，2015）和 Automerge（Martin Kleppmann，2017）是 JavaScript 中最成熟的 CRDT 库——将抽象的 CRDT 数学转化为生产就绪的 API。Yjs 采用高性能的命令式 API（Y.Map、Y.Text、Y.Array），被 Liveblocks、Tiptap、JupyterLab 使用。Automerge 采用函数式/不可变的类 JSON API，被 Local-First Cooperative 项目使用。两者各有取舍——Yjs 更快、体积更小，Automerge API 更简洁、原生支持分支/复刻。本节介绍 Yjs API、Automerge API、对比分析以及实战搭建（React + WebSocket + IndexedDB 持久化）。

维度 Yjs Automerge
性能 极高（深度优化） 中等
包体积 约 50 KB 约 200 KB
API 风格 命令式共享类型 函数式不可变
分支支持 非原生 原生支持（类 Git）
使用者 Tiptap、Liveblocks、Jupyter Local-First、Pushpin

Yjs 基础配置

安装：

npm i yjs y-websocket y-indexeddb

创建文档：

import * as Y from 'yjs';
import { WebsocketProvider } from 'y-websocket';
import { IndexeddbPersistence } from 'y-indexeddb';

const doc = new Y.Doc();

// 本地持久化
const persistence = new IndexeddbPersistence('my-doc', doc);

// 通过 WebSocket 同步
const provider = new WebsocketProvider('wss://example.com', 'room1', doc);

Yjs 共享类型

Y.Map（键值对）：

const map = doc.getMap('settings');
map.set('theme', 'dark');
console.log(map.get('theme')); // 'dark'

map.observe((event) => {
  console.log('Changed:', event.changes);
});

Y.Array（列表）：

const arr = doc.getArray('todos');
arr.push(['Buy milk']);
arr.delete(0, 1); // 从索引 0 删除 1 个元素
console.log(arr.toArray());

arr.observe((event) => {
  console.log('Changed:', event.changes);
});

Y.Text（协作文本）：

const text = doc.getText('content');
text.insert(0, 'Hello ');
text.insert(6, 'World');
console.log(text.toString()); // 'Hello World'

text.observe((event) => {
  console.log('Changed:', event.delta); // Delta 格式
});

Y.XmlFragment（富文本）：

const xml = doc.getXmlFragment('article');
const para = new Y.XmlElement('p');
xml.push([para]);

Yjs 事务

分组操作：

doc.transact(() => {
  map.set('a', 1);
  map.set('b', 2);
  arr.push(['x', 'y']);
});

// 事务结束后只触发一次观察回调

性能优势：

  • 减少观察回调触发次数。
  • 操作原子化。

Yjs 更新同步

编码更新数据：

const update = Y.encodeStateAsUpdate(doc);
// 发送给服务器或其他对等方

应用更新数据：

Y.applyUpdate(doc, update);

状态向量（增量同步）：

const stateVector = Y.encodeStateVector(doc);
// 发送给对等方
const updateForPeer = Y.encodeStateAsUpdate(doc, stateVector);
// 对等方应用

效果：

  • 仅发送对方缺少的数据。

y-websocket 提供者

自动通过 WebSocket 同步：

const provider = new WebsocketProvider('wss://example.com', 'room1', doc);

provider.on('status', (event) => {
  console.log(event.status); // connected 或 disconnected
});

provider.awareness.setLocalStateField('user', {
  name: 'Alice',
  color: '#ff0000',
});

在线感知（Awareness）：光标、选区等临时状态独立于文档。

y-indexeddb 持久化

本地持久化：

import { IndexeddbPersistence } from 'y-indexeddb';

const persistence = new IndexeddbPersistence('my-doc', doc);

persistence.on('synced', () => {
  console.log('已从 IndexedDB 加载');
});

效果：

  • 文档自动保存。
  • 刷新页面后从 IndexedDB 恢复。
  • 实现离线优先。

Yjs + React

使用自定义 Hook：

function useY(yArray) {
  const [state, setState] = useState(yArray.toArray());
  useEffect(() => {
    const update = () => setState(yArray.toArray());
    yArray.observe(update);
    return () => yArray.unobserve(update);
  }, [yArray]);
  return state;
}

Yjs 与 Tiptap

富文本编辑器集成：

import { Editor } from '@tiptap/react';
import Collaboration from '@tiptap/extension-collaboration';

const editor = new Editor({
  extensions: [
    Collaboration.configure({
      document: doc,
      field: 'content', // Y.Doc 中的字段名
    }),

效果：

  • 多人实时协作富文本编辑。
  • 通过 Yjs 自动同步。

Automerge 基础配置

安装：

npm i @automerge/automerge

基本用法：

import * as Automerge from '@automerge/automerge';

let doc1 = Automerge.from({ tasks: [], settings: {} });

// 通过 change 回调修改
doc1 = Automerge.change(doc1, 'Add task', (d) => {
  d.tasks.push({ id: 1, text: 'Buy milk' });
});

// 保存为二进制
const binary = Automerge.save(doc1);

// 加载
const doc2 = Automerge.load(binary);

// 合并来自另一个对等方的文档
let docA = Automerge.from({ list: [] });
let docB = Automerge.merge(Automerge.init(), docA); // 克隆

docA = Automerge.change(docA, (d) => d.list.push('a'));
docB = Automerge.change(docB, (d) => d.list.push('b'));

// 并发编辑后合并
const merged = Automerge.merge(docA, docB);
console.log(merged.list); // ['a', 'b']（或 ['b', 'a']，取决于顺序）

Automerge 同步协议

自动同步：

// 对等方 A
let syncState = Automerge.initSyncState();
const [newState, message] = Automerge.generateSyncMessage(doc, syncState);
syncState = newState;
sendToB(message);

// 对等方 B
const [doc2, syncState2, patch] = Automerge.receiveSyncMessage(doc, syncState, message);

双向同步：

  • 双方交换同步消息直到收敛。

Yjs 与 Automerge 对比

Yjs：

  • 优点：
    • 性能极高。
    • 包体积小（约 50 KB）。
    • 生态成熟。
    • 与 Tiptap、Liveblocks 深度集成。
  • 缺点：
    • 命令式 API 直观性稍弱。
    • 不原生支持分支。

Automerge：

  • 优点：
    • 函数式/不可变 API（清晰简洁）。
    • 原生支持分支/复刻（类 Git 工作流）。
    • 类 JSON 接口。
  • 缺点：
    • 速度较慢。
    • 包体积大（约 200 KB）。

选择建议：

  • 生产环境协作应用：Yjs。
  • 本地优先应用：Automerge。
  • 实时协作编辑器：Yjs（配合 Tiptap）。
  • 需要文档分支功能：Automerge。

Yjs：


    

  • y-indexeddb（浏览器端）。
    • 

  • y-leveldb（Node.js 端）。
    • 

  • 服务端：自定义数据库存储更新二进制数据。

Automerge：


    

  • 直接保存二进制数据。
    • 

  • 自定义数据库集成。

服务器架构
y-websocket-server：


    

  • 开箱即用的服务器。
    • 

  • 通过回调持久化到数据库或文件。
    • 



import { WebSocketServer } from 'ws';
import { setupWSConnection } from 'y-websocket/bin/utils';

const wss = new WebSocketServer({ port: 1234 });
wss.on('connection', (ws, req) => {
  setupWSConnection(ws, req, {
    persist: async (docName, doc) => {
      // 保存 Y.Doc 到数据库
    },
  });
});
离线优先架构
Yjs + IndexedDB + WebSocket：


const doc = new Y.Doc();

// 先加载本地持久化数据
const persistence = new IndexeddbPersistence('doc-id', doc);

// 然后建立在线同步
persistence.on('synced', () => {
  const provider = new WebsocketProvider('wss://...', 'room', doc);
  // 在线时文档自动同步到服务器
});
效果：


    

  • 离线时本地编辑。
    • 

  • 在线后自动同步。
    • 



内存管理
Yjs 垃圾回收：


const doc = new Y.Doc({ gc: true }); // 默认开启
GC 功能：


    

  • 移除已删除元素的墓碑。
    • 

  • 对大文档有显著内存收益。
    • 



如需保留编辑历史可关闭：


const doc = new Y.Doc({ gc: false }); // 保留全部历史
常见陷阱
1. 不使用事务：


    

  • 导致多次触发观察回调。
    • 

  • 应使用 doc.transact()。
    • 



2. 直接修改代理对象：


    

  • Yjs 必须使用共享类型 API（如 Y.Map.set）。
    • 

  • 不能用普通 JavaScript 对象的赋值操作。
    • 



3. 不做持久化：


    

  • 刷新页面后离线编辑丢失。
    • 

  • 应使用 IndexedDB。
    • 



4. 在 Y.Doc 中存储大型二进制数据：


    

  • 不应将图片等二进制数据存入文档。
    • 

  • 应通过 URL 引用。
    • 



5. 快照更新体积膨胀：


    

  • 应使用状态向量做增量同步。
    •

实战搭建
Tiptap 协作编辑器：


npm i @tiptap/react @tiptap/starter-kit @tiptap/extension-collaboration y-websocket yjs
import { useEditor, EditorContent } from '@tiptap/react';
import StarterKit from '@tiptap/starter-kit';
import Collaboration from '@tiptap/extension-collaboration';
import * as Y from 'yjs';
import { WebsocketProvider } from 'y-websocket';

function Editor() {
  const ydoc = useMemo(() => new Y.Doc(), []);
  const provider = useMemo(() => new WebsocketProvider('wss://...', 'room', ydoc), [ydoc]);

  const editor = useEditor({
    extensions: [
      StarterKit.configure({ history: false }), // 由 Yjs 管理历史
      Collaboration.configure({ document: ydoc }),
    ],
  });

  return <EditorContent editor={editor} />;
}
反模式
1. 非协作数据使用 Yjs：


    

  • 不必要的开销，应使用普通状态。
    • 



2. 高性能场景使用 Automerge：


    

  • 速度较慢，Yjs 更合适。
    • 



3. 重新发明 CRDT：


    

  • 直接使用 Yjs 或 Automerge。
    • 



4. 不配置持久化：


    

  • 离线编辑会丢失。
    • 



5. 单个 Y.Doc 存储海量数据：


    

  • 内存膨胀。
    • 

  • 应按资源拆分文档。
    •

小结
Yjs（2015）和 Automerge（2017）是 JavaScript 中最主流的 CRDT 库——将抽象数学转化为生产级 API。Yjs 采用高性能命令式共享类型（Y.Map / Y.Array / Y.Text / Y.XmlFragment），包体积约 50 KB，被 Tiptap、Liveblocks、JupyterLab 使用。Automerge 采用函数式/不可变的类 JSON API，原生支持分支，包体积约 200 KB，适用于本地优先项目。Yjs 配置包括 y-websocket 提供者实时同步 + y-indexeddb 本地持久化 + 共享类型 API + 事务分组。更新同步通过 encodeStateAsUpdate（完整）和 encodeStateVector（增量）实现。在线感知（Awareness）管理光标/选区等临时状态，独立于文档。Yjs 与 React 通过自定义 Hook 桥接，与 Tiptap 通过 Collaboration 扩展集成。Automerge 通过 change 回调修改、save/load 序列化、merge 合并并发编辑，同步协议使用 generateSyncMessage/receiveSyncMessage 双向交换。选择建议：生产协作/实时编辑器用 Yjs，本地优先/需要分支用 Automerge。持久化策略：Yjs 用 y-indexeddb（浏览器）/y-leveldb（服务端）/自定义数据库；Automerge 直接保存二进制。离线优先架构先加载本地数据再建立在线同步。内存管理通过 gc:true 回收墓碑。现代工具链包括 Liveblocks、HocusPocus 和 Loro。
