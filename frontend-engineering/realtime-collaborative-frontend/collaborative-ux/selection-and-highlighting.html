Part IV · 浏览器与平台 (Browser & Platform)实时协作前端协作 UX选择与高亮

选择与高亮

核心概念

多用户选择与高亮功能让用户能看到其他人正在选择什么——文本选择（"Alice 正在编辑这段内容"）、对象选择（白板/画布）、单元格选择（电子表格）。这是光标的"扩展"——光标是单点，选择是范围。视觉设计至关重要——半透明覆盖层 + 用户颜色 + 姓名标签，既不能遮挡内容，也不能让自己的选择受到干扰。本节介绍选择区域的渲染方式、文本选择与对象选择的区别、性能优化以及边界情况（重叠、跨元素）。

选择类型 使用场景 技术实现
文本范围 文档编辑 编辑器 API + 渲染
对象选择 画布 / SVG 边界框覆盖层
单元格 电子表格 单元格高亮
区域 白板 框选操作

文本选择

捕获本地选择：

editor.on('selectionUpdate', ({ editor }) => {
  const { from, to } = editor.state.selection;
  if (from === to) {
    // 仅光标位置
    provider.awareness.setLocalStateField('selection', null);
  } else {
    // 选择范围
    provider.awareness.setLocalStateField('selection', { from, to });
  }
});

渲染其他用户的选择：

function RemoteSelection({ from, to, color, name }) {
  const rects = getClientRectsForRange(editor, from, to);
  return rects.map((rect, i) => (
    <div
      key={i}
      style={{
        position: 'absolute',
        left: rect.left,
        top: rect.top,
        width: rect.width,
        height: rect.height,
        backgroundColor: color,
        opacity: 0.2,
        pointerEvents: 'none',
      }}
    />
  ));
}

视觉效果：

  • 在选中文本上显示半透明矩形。
  • 使用用户颜色。
  • 在选择区域末尾显示姓名标签。

Tiptap 协作光标扩展

用于协作编辑器：

import { CollaborationCursor } from '@tiptap/extension-collaboration-cursor';

const editor = useEditor({
  extensions: [
    StarterKit,
    Collaboration.configure({ document: ydoc }),
    CollaborationCursor.configure({
      provider,
      user: { name: 'Alice', color: '#ff0000' },
      render: (user) => {
        // 自定义渲染逻辑
      },
    }),
  ],
});

自动渲染：

  • 其他用户的行内光标（插入符号）。
  • 选择区域高亮。

对象选择（画布场景）

用于白板 / Figma 类应用：

provider.awareness.setLocalStateField('selectedIds', ['shape-1', 'shape-2']);

渲染：

function RemoteSelectionBox({ shapeId, user }) {
  const shape = shapes.get(shapeId);
  return (
    <div
      className="selection-box"
      style={{
        position: 'absolute',
        left: shape.x,
        top: shape.y,
        width: shape.width,
        height: shape.height,
        border: `2px solid ${user.color}`,
        pointerEvents: 'none',
      }}
    />
  );
}

视觉效果：

  • 围绕图形的边框。
  • 使用用户颜色。
  • 可选的姓名标签。

单元格选择（电子表格场景）

高亮单元格：

function RemoteCellSelection({ cell, user }) {
  return (
    <div
      className="cell-selection"
      style={{
        position: 'absolute',
        ...cellPosition(cell),
        outline: `2px solid ${user.color}`,
      }}
    >
      <span className="user-tag" style={{ background: user.color }}>
        {user.name}
      </span>
    </div>
  );
}

模式：

  • 单个单元格：使用外边框。
  • 范围选择：连续外边框。

边界情况处理

重叠选择：

  • 多用户选择相同范围。
  • 视觉上叠加显示（每层半透明）。
.remote-selection {
  background: var(--user-color);
  opacity: 0.15; /* 多层叠加可见 */
  mix-blend-mode: multiply;
}

跨元素选择：

  • 范围跨越段落/容器。
  • 使用 Range.getClientRects()（返回多个矩形）。

空选择（仅光标）：

  • 没有选择范围。
  • 显示行内插入符号。

换行文本：

  • 多行选择。
  • 多个矩形，逐一渲染。

颜色叠加

多用户选择重叠时：

  • 使用 mix-blend-mode（multiply）让颜色混合。
  • 或使用叠加外边框。

避免：

  • 单层不透明覆盖遮挡内容。

姓名标签定位

选择范围末尾：

  • 跟随最后一个矩形。
  • 浮动标签。
const lastRect = rects[rects.length - 1];
return <span style={{ left: lastRect.right, top: lastRect.bottom }}>{user.name}</span>;

边缘回避：

  • 检查视口边缘。
  • 如果标签超出视口则移到内侧。

性能优化

大量用户与选择区域：

  • 100 用户各有 10 个选择 = 1000 个覆盖层。
  • 存在性能问题。

优化方案：

  • 只渲染视口内可见的。
  • 虚拟化渲染。
  • 限制显示前 10 个用户的光标，其余显示 "+N 人"。

Z-index 层级

选择层在内容之上但在光标之下：

.content {
  z-index: 1;
}
.remote-selection {
  z-index: 100;
}
.remote-cursor {
  z-index: 1000;
}

自己的选择（浏览器原生）：

  • 不使用覆盖层渲染。
  • 使用浏览器默认选择样式。

选择同步方式

使用 CRDT：

  • Yjs awareness 处理临时选择状态。
  • 不持久化。

使用 OT：

  • 选择信息包含在操作中（Google Docs 方式）。
  • 或使用独立通道。

节流：

  • 选择变化频率比光标低。
  • 100ms 节流即可。

无障碍设计

屏幕阅读器：

  • 不播报远程选择（纯视觉功能）。
  • 提供替代方案（"Alice 正在编辑某段"的文字提示）。

键盘用户：

  • 非视觉选择。
  • 状态栏文字提示。

高对比度：

  • 确保在背景上可见。
  • 设置最小透明度。

现代工具支持

Liveblocks：

  • 内置选择同步。
  • 与 Tiptap 集成。

Tiptap CollaborationCursor：

  • 光标 + 选择。
  • 基于 Yjs。

Lexical（Meta）：

  • 通过插件支持选择。

Slate：

  • 基于插件。
  • 自定义选择渲染。

选择与高亮的区别

选择（Selection）：

  • 用户当前正在操作的。
  • 表示编辑意图。

高亮（Highlight/注释）：

  • 持久化的。
  • 用于评论或标记。
  • 非临时状态。

不同的 UX 表现：

  • 选择：半透明 + 用户颜色。
  • 高亮：饱和色 + 评论指示器。

光标与选择的结合

常见 UX 模式：

  • 选择范围覆盖层。
  • 光标（插入符号）在范围的一端。
  • 两者使用相同的用户颜色。
{selection && <RemoteSelectionRange ... />}
<RemoteCursor at={selection ? selection.to : cursor} ... />

拖拽指示器

显示其他用户的拖拽操作：

  • 光标 + "拖拽中"指示器。
  • 被拖对象的虚线轮廓。
  • 通过 Awareness 发布拖拽状态。
provider.awareness.setLocalStateField('dragging', { shapeId, x, y });

反模式

1. 不做节流：

  • 选择变化频繁时性能差。

2. 不透明覆盖层：

  • 遮挡内容。
  • 应使用 0.15-0.25 的透明度。

3. 不使用用户颜色：

  • 多用户时造成混淆。

4. 不显示姓名标签：

  • 无法区分是谁的选择。

5. 渲染所有 100 个用户：

  • 性能问题。
  • 应限制数量并提示 "+N"。

6. 断开后选择不消失：

  • 残留的过期选择。

实战建议

1. 使用编辑器库：

  • Tiptap / Liveblocks 已内置支持。

2. 0.15-0.25 透明度覆盖：

  • 可见但不遮挡。

3. mix-blend-mode multiply：

  • 多层颜色叠加效果好。

4. 姓名标签在选择末尾：

  • 浮动显示。

5. 节流 100ms：

  • 不过度更新。

6. 限制显示 10 个用户：

  • 保障性能。

小结

多用户选择与高亮让用户能看到他人正在选择的内容——包括文本范围、对象、单元格和区域。文本选择通过编辑器 selectionUpdate 事件捕获 from/to，渲染时使用 getClientRectsForRange 获取矩形并显示半透明覆盖层加姓名标签。Tiptap CollaborationCursor 扩展自动渲染光标和选择。对象选择（画布/白板）使用边界框覆盖和用户颜色边框加姓名标签。单元格选择（电子表格）使用外边框加用户标签。边界情况包括重叠（mix-blend-mode multiply 叠加）、跨元素（多矩形）、空选择（仅行内光标）、多行（多矩形逐一渲染）。颜色叠加使用 0.15 透明度加 multiply 混合模式，避免不透明遮挡。姓名标签放在最后一个矩形末尾并进行边缘回避。性能方面 100 用户 × 10 选择 = 1000 覆盖层，优化方案包括只渲染可见区域、虚拟化、限制前 10 个用户显示"+N"。Z-index 设置内容为 1、远程选择为 100、远程光标为 1000，自己的选择使用浏览器原生样式。选择同步使用 CRDT（Yjs awareness 临时状态）或 OT（操作中包含或独立通道），节流 100ms。选择（当前编辑意图）与高亮（持久注释评论）是不同的 UX——前者半透明用户色，后者饱和色加评论指示。光标与选择结合使用相同颜色的范围覆盖加插入符号。拖拽指示器通过 Awareness 发布拖拽状态加虚线轮廓。
