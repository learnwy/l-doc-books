无头组件

什么是无头组件

无头组件（Headless Components） 是只提供逻辑和状态管理、不包含任何 UI 样式的组件模式。它将"做什么"和"看起来怎样"完全分离，让使用者拥有完全的样式自由。

Logic-Only Hooks
最简单的无头组件形式是纯逻辑 Hook。它管理状态和行为，返回 props getter 让使用者绑定到任意元素：


interface UseToggleReturn {
  isOpen: boolean;
  open: () => void;
  close: () => void;
  toggle: () => void;
  getToggleProps: (
    props?: React.ButtonHTMLAttributes<HTMLButtonElement>,
  ) => React.ButtonHTMLAttributes<HTMLButtonElement>;
  getContentProps: () => React.HTMLAttributes<HTMLElement>;
}

function useToggle(defaultOpen = false): UseToggleReturn {
  const [isOpen, setIsOpen] = useState(defaultOpen);
  const id = useId();

  const open = useCallback(() => setIsOpen(true), []);
  const close = useCallback(() => setIsOpen(false), []);
  const toggle = useCallback(() => setIsOpen((v) => !v), []);

  const getToggleProps = useCallback(
    (props: React.ButtonHTMLAttributes<HTMLButtonElement> = {}) => ({
      ...props,
      'aria-expanded': isOpen,
      'aria-controls': id,
      onClick: (e: React.MouseEvent<HTMLButtonElement>) => {
        props.onClick?.(e);
        toggle();
      },
    }),
    [isOpen, id, toggle],
  );

  const getContentProps = useCallback(
    () => ({
      id,
      role: 'region' as const,
      hidden: !isOpen,
    }),
    [id, isOpen],
  );

  return { isOpen, open, close, toggle, getToggleProps, getContentProps };
}
使用方式
function FAQ({ question, answer }: { question: string; answer: string }) {
  const { isOpen, getToggleProps, getContentProps } = useToggle();

  return (
    <div className="faq-item">
      <button {...getToggleProps({ className: 'faq-question' })}>
        {question} {isOpen ? '−' : '+'}
      </button>
      <div {...getContentProps()} className="faq-answer">
        {answer}
      </div>
    </div>
  );
}


Radix UI 模式
Radix UI 是无头组件库的代表，它提供具有完整无障碍支持的无样式组件：


import * as Dialog from '@radix-ui/react-dialog';

function ConfirmDialog({
  title,
  description,
  onConfirm,
  children,
}: {
  title: string;
  description: string;
  onConfirm: () => void;
  children: React.ReactNode;
}) {
  return (
    <Dialog.Root>
      <Dialog.Trigger asChild>{children}</Dialog.Trigger>
      <Dialog.Portal>
        <Dialog.Overlay className="dialog-overlay" />
        <Dialog.Content className="dialog-content">
          <Dialog.Title className="dialog-title">{title}</Dialog.Title>
          <Dialog.Description className="dialog-description">{description}</Dialog.Description>
          <div className="dialog-actions">
            <Dialog.Close asChild>
              <button className="btn-cancel">取消</button>
            </Dialog.Close>
            <button className="btn-confirm" onClick={onConfirm}>
              确认
            </button>
          </div>
          <Dialog.Close asChild>
            <button className="dialog-close" aria-label="关闭">
              ✕
            </button>
          </Dialog.Close>
        </Dialog.Content>
      </Dialog.Portal>
    </Dialog.Root>
  );
}

原则
说明

可控/非受控

asChild

无障碍内置
无头组件的核心价值之一是内置无障碍支持。以 Select 为例：


import * as Select from '@radix-ui/react-select';

function LanguageSelect() {
  return (
    <Select.Root defaultValue="zh">
      <Select.Trigger className="select-trigger" aria-label="选择语言">
        <Select.Value placeholder="选择语言" />
        <Select.Icon>▾</Select.Icon>
      </Select.Trigger>
      <Select.Portal>
        <Select.Content className="select-content">
          <Select.Viewport>
            <Select.Item value="zh" className="select-item">
              <Select.ItemText>中文</Select.ItemText>
              <Select.ItemIndicator>✓</Select.ItemIndicator>
            </Select.Item>
            <Select.Item value="en" className="select-item">
              <Select.ItemText>English</Select.ItemText>
              <Select.ItemIndicator>✓</Select.ItemIndicator>
            </Select.Item>
            <Select.Item value="ja" className="select-item">
              <Select.ItemText>日本語</Select.ItemText>
              <Select.ItemIndicator>✓</Select.ItemIndicator>
            </Select.Item>
          </Select.Viewport>
        </Select.Content>
      </Select.Portal>
    </Select.Root>
  );
}

屏幕阅读器

样式自由
无头组件不绑定任何 CSS 方案，可以与任何样式工具搭配：


// Tailwind CSS
<Dialog.Content className="fixed inset-0 z-50 flex items-center justify-center">
  <Dialog.Overlay className="fixed inset-0 bg-black/50" />
  <div className="bg-white rounded-lg p-6 shadow-xl max-w-md w-full">
    <Dialog.Title className="text-lg font-semibold">标题</Dialog.Title>
  </div>
</Dialog.Content>

// CSS Modules
<Dialog.Content className={styles.dialogContent}>
  <Dialog.Overlay className={styles.overlay} />
  <Dialog.Title className={styles.title}>标题</Dialog.Title>
</Dialog.Content>

// styled-components
const StyledContent = styled(Dialog.Content)`
  position: fixed;
  background: white;
  border-radius: 8px;
`;


提示： Radix UI + Tailwind CSS 是目前 React 社区非常流行的组合。shadcn/ui 就是基于这一组合构建的组件集合，可以直接复制到项目中使用。






小结
    

  • 无头组件 只提供逻辑和状态，不包含样式，使用者拥有完全的定制自由
    • 

  • Logic-Only Hooks 通过 props getter 模式将行为绑定到任意元素
    • 

  • Radix UI 是无头组件库的代表，提供完整的无障碍支持和可组合的 API
    • 

  • 无头组件自动管理焦点、键盘导航、ARIA 属性等无障碍特性
    • 

  • 可以与 Tailwind、CSS Modules、styled-components 等任何样式方案搭配使用
