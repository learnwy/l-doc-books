复合组件

什么是复合组件

复合组件（Compound Components） 是一种将相关组件组合在一起，共享隐式状态的设计模式。父组件管理状态，子组件通过 Context 访问状态，使用者通过组合子组件来构建灵活的 UI。HTML 中的 <select> + <option> 就是典型的复合组件。



基础实现：Tabs 组件
interface TabsContextValue {
  activeIndex: number;
  setActiveIndex: (index: number) => void;
}

const TabsContext = createContext<TabsContextValue | null>(null);

function useTabsContext(): TabsContextValue {
  const context = useContext(TabsContext);
  if (!context) {
    throw new Error('Tabs 子组件必须在 <Tabs> 内使用');
  }
  return context;
}

function Tabs({ defaultIndex = 0, children }: { defaultIndex?: number; children: React.ReactNode }) {
  const [activeIndex, setActiveIndex] = useState(defaultIndex);

  const value = useMemo(() => ({ activeIndex, setActiveIndex }), [activeIndex]);

  return (
    <TabsContext.Provider value={value}>
      <div role="tablist">{children}</div>
    </TabsContext.Provider>
  );
}

function Tab({ index, children }: { index: number; children: React.ReactNode }) {
  const { activeIndex, setActiveIndex } = useTabsContext();
  const isActive = activeIndex === index;

  return (
    <button role="tab" aria-selected={isActive} onClick={() => setActiveIndex(index)}>
      {children}
    </button>
  );
}

function TabPanel({ index, children }: { index: number; children: React.ReactNode }) {
  const { activeIndex } = useTabsContext();

  if (activeIndex !== index) return null;

  return <div role="tabpanel">{children}</div>;
}

Tabs.Tab = Tab;
Tabs.TabPanel = TabPanel;
使用方式
function App() {
  return (
    <Tabs defaultIndex={0}>
      <div>
        <Tabs.Tab index={0}>基础</Tabs.Tab>
        <Tabs.Tab index={1}>高级</Tabs.Tab>
        <Tabs.Tab index={2}>设置</Tabs.Tab>
      </div>
      <Tabs.TabPanel index={0}>
        <p>基础内容</p>

}


Accordion 模式
复合组件非常适合构建 Accordion（手风琴）组件：


interface AccordionContextValue {
  openItems: Set<string>;
  toggle: (id: string) => void;
}

const AccordionContext = createContext<AccordionContextValue | null>(null);

function Accordion({ multiple = false, children }: { multiple?: boolean; children: React.ReactNode }) {
  const [openItems, setOpenItems] = useState<Set<string>>(new Set());

  const toggle = useCallback(
    (id: string) => {
      setOpenItems((prev) => {
        const next = new Set(multiple ? prev : []);
        if (next.has(id)) {
          next.delete(id);
        } else {
          next.add(id);
        }
        return next;
      });
    },
    [multiple],
  );

  const value = useMemo(() => ({ openItems, toggle }), [openItems, toggle]);

  return (
    <AccordionContext.Provider value={value}>
      <div>{children}</div>
    </AccordionContext.Provider>
  );
}

function AccordionItem({ id, title, children }: { id: string; title: string; children: React.ReactNode }) {
  const { openItems, toggle } = useContext(AccordionContext)!;
  const isOpen = openItems.has(id);

  return (
    <div>
      <button onClick={() => toggle(id)} aria-expanded={isOpen}>
        {title} {isOpen ? '▾' : '▸'}
      </button>
      {isOpen && <div>{children}</div>}
    </div>
  );
}

Accordion.Item = AccordionItem;

受控与非受控
复合组件应同时支持受控和非受控模式：


function Tabs({
  activeIndex: controlledIndex,
  defaultIndex = 0,
  onChange,
  children,
}: {
  activeIndex?: number;
  defaultIndex?: number;
  onChange?: (index: number) => void;
  children: React.ReactNode;
}) {
  const [internalIndex, setInternalIndex] = useState(defaultIndex);
  const isControlled = controlledIndex !== undefined;
  const activeIndex = isControlled ? controlledIndex : internalIndex;

  const setActiveIndex = useCallback(
    (index: number) => {
      if (!isControlled) {
        setInternalIndex(index);
      }
      onChange?.(index);
    },
    [isControlled, onChange],
  );

  const value = useMemo(() => ({ activeIndex, setActiveIndex }), [activeIndex, setActiveIndex]);

  return (
    <TabsContext.Provider value={value}>
      <div>{children}</div>
    </TabsContext.Provider>
  );
}


小结
    

  • 复合组件 通过 Context 隐式共享状态，子组件自由组合构成灵活的 API
    • 

  • 适用于 Tabs、Accordion、Menu、Select 等需要多个相关组件协作的场景
    • 

  • 相比 Props 配置方式，复合组件支持自定义布局、条件渲染、插入额外内容
    • 

  • 应同时支持受控和非受控模式，提高组件的通用性
    • 

  • 通过在 Context 创建时添加 null 检查和错误提示，帮助使用者正确使用组件
    •
