Render Props 与 HOC

跨组件逻辑复用的演变

React 的逻辑复用方案经历了从 Mixin → HOC → Render Props → Hooks 的演变。虽然 Hooks 是现代首选，但理解 HOC 和 Render Props 在遗留代码和特定场景中仍有重要价值。



Render Props
Render Props 是一种通过函数 prop 共享逻辑的技术。组件将自己的内部状态通过函数参数传递给调用者，由调用者决定如何渲染。


interface MousePosition {
  x: number;
  y: number;
}

interface MouseTrackerProps {
  children: (position: MousePosition) => React.ReactNode;
}

function MouseTracker({ children }: MouseTrackerProps) {
  const [position, setPosition] = useState<MousePosition>({ x: 0, y: 0 });

  useEffect(() => {
    const handleMove = (e: MouseEvent) => {
      setPosition({ x: e.clientX, y: e.clientY });
    };
    window.addEventListener('mousemove', handleMove);
    return () => window.removeEventListener('mousemove', handleMove);
  }, []);

  return <>{children(position)}</>;
}

function App() {
  return (
    <MouseTracker>
      {({ x, y }) => (
        <div>
          鼠标位置: ({x}, {y})
        </div>
      )}
    </MouseTracker>
  );
}

高阶组件（HOC）
HOC 是一个接受组件作为参数，返回增强后新组件的函数：


interface WithLoadingProps {
  loading: boolean;
}

function withLoading<P extends object>(WrappedComponent: React.ComponentType<P>): React.FC<P & WithLoadingProps> {
  return function WithLoadingComponent({ loading, ...props }: P & WithLoadingProps) {
    if (loading) return <Spinner />;
    return <WrappedComponent {...(props as P)} />;
  };
}

interface UserListProps {
  users: User[];
}

function UserList({ users }: UserListProps) {
  return (
    <ul>
      {users.map((u) => (
        <li key={u.id}>{u.name}</li>
      ))}
    </ul>
  );
}

const UserListWithLoading = withLoading(UserList);

function App() {
  return <UserListWithLoading loading={isLoading} users={users} />;
}
类型推断
HOC 的 TypeScript 类型推断相对复杂。需要正确处理泛型传递：


function withAuth<P extends object>(WrappedComponent: React.ComponentType<P>): React.FC<P> {
  return function AuthenticatedComponent(props: P) {
    const { user } = useAuth();

    if (!user) return <Navigate to="/login" />;
    return <WrappedComponent {...props} />;
  };
}

const ProtectedDashboard = withAuth(Dashboard);

组合使用
实际项目中可以混合使用多种模式：


function DataTable<T>({ data, children }: { data: T[]; children: (item: T, index: number) => React.ReactNode }) {
  const { sortedData, sortBy, sortDirection } = useSort(data);

  return (
    <table>
      <tbody>
        {sortedData.map((item, index) => (
          <tr key={index}>{children(item, index)}</tr>
        ))}
      </tbody>
    </table>
  );
}

function UserTable({ users }: { users: User[] }) {
  return (
    <DataTable data={users}>
      {(user) => (
        <>
          <td>{user.name}</td>
          <td>{user.email}</td>
        </>
      )}
    </DataTable>
  );
}


小结
    

  • Render Props 通过函数 prop 传递状态给调用者，提供灵活的渲染控制
    • 

  • HOC 通过包装组件注入额外功能，但存在嵌套、props 冲突、ref 丢失等问题
    • 

  • 现代 React 中，Hooks 是首选方案，能解决绝大多数逻辑复用需求
    • 

  • HOC 仍适用于错误边界、路由守卫等场景；Render Props 适用于动态子组件渲染
    • 

  • 理解这些模式的演变有助于维护遗留代码和理解第三方库的设计
