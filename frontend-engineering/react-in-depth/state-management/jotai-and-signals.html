Jotai 与 Signals

原子化状态管理

传统状态管理（Redux、Zustand）使用集中式 store，所有状态合并在一个地方。Jotai 采用截然不同的思路——将状态拆分为最小粒度的原子（Atom），组件直接订阅所需的原子，实现真正的细粒度更新。

基础用法
import { atom, useAtom, useAtomValue, useSetAtom } from 'jotai';

const countAtom = atom(0);
const nameAtom = atom('React');

function Counter() {
  const [count, setCount] = useAtom(countAtom);
  return <button onClick={() => setCount((c) => c + 1)}>计数: {count}</button>;
}

function NameDisplay() {
  const name = useAtomValue(nameAtom);
  return <span>名称: {name}</span>;
}

function NameEditor() {
  const setName = useSetAtom(nameAtom);
  return <input onChange={(e) => setName(e.target.value)} placeholder="输入名称" />;
}


提示： useAtomValue 只读取值不返回 setter，useSetAtom 只返回 setter 不订阅值。合理使用可以进一步减少不必要的重渲染。






Derived Atoms
Jotai 的 derived atom 从其他 atom 派生状态，当依赖的 atom 变化时自动重新计算：


interface TodoItem {
  id: string;
  text: string;
  completed: boolean;
}

const todosAtom = atom<TodoItem[]>([]);
const filterAtom = atom<'all' | 'active' | 'completed'>('all');

const filteredTodosAtom = atom((get) => {
  const todos = get(todosAtom);
  const filter = get(filterAtom);

  switch (filter) {
    case 'active':
      return todos.filter((t) => !t.completed);
    case 'completed':
      return todos.filter((t) => t.completed);
    default:
      return todos;
  }
});

const statsAtom = atom((get) => {
  const todos = get(todosAtom);
  return {
    total: todos.length,
    active: todos.filter((t) => !t.completed).length,
    completed: todos.filter((t) => t.completed).length,
  };
});
可写派生 Atom
const uppercaseAtom = atom(
  (get) => get(nameAtom).toUpperCase(),
  (get, set, newValue: string) => {
    set(nameAtom, newValue.toLowerCase());
  },
);


异步 Atom
Jotai 原生支持异步 atom，与 Suspense 无缝集成：


const userIdAtom = atom(1);

const userAtom = atom(async (get) => {
  const id = get(userIdAtom);
  const response = await fetch(`/api/users/${id}`);
  return response.json() as Promise<User>;
});

function UserProfile() {
  const user = useAtomValue(userAtom);
  return <div>{user.name}</div>;
}

function App() {
  return (
    <Suspense fallback={<Spinner />}>
      <UserProfile />
    </Suspense>
  );
}

Signal 提案与细粒度响应式
Signals 是一种细粒度响应式原语，已被 TC39 提案引入（Stage 1）。与 React 的 "pull" 模型（组件重渲染时拉取最新状态）不同，Signals 采用 "push" 模型——状态变化时自动推送更新到订阅的 UI 片段。


Signal 的核心概念
interface Signal<T> {
  get value(): T;
  set value(newValue: T);
}

interface Computed<T> {
  get value(): T;
}

// TC39 Signal 提案伪代码
const count = new Signal.State(0);
const doubled = new Signal.Computed(() => count.value * 2);

const effect = new Signal.subtle.Watcher(() => {
  console.log('count changed:', count.value);
});
effect.watch(count);

count.value = 5;

Fine-Grained Reactivity
细粒度响应式的核心优势是跳过组件级别的 diff，直接更新变化的 DOM 片段。在 React 生态中，Jotai 配合 @jotai/react 已经实现了接近细粒度的更新：


const priceAtom = atom(100);
const taxRateAtom = atom(0.1);
const totalAtom = atom((get) => {
  const price = get(priceAtom);
  const taxRate = get(taxRateAtom);
  return price * (1 + taxRate);
});

function PriceDisplay() {
  const price = useAtomValue(priceAtom);
  return <span>价格: ¥{price}</span>;
}

function TotalDisplay() {
  const total = useAtomValue(totalAtom);
  return <span>总计: ¥{total.toFixed(2)}</span>;
}

function TaxRateControl() {
  const setTaxRate = useSetAtom(taxRateAtom);
  return (
    <select onChange={(e) => setTaxRate(Number(e.target.value))}>
      <option value="0.1">10%</option>
      <option value="0.13">13%</option>
      <option value="0.17">17%</option>
    </select>
  );
}
当 taxRateAtom 变化时：


    

  • PriceDisplay 不会重渲染（未订阅 taxRateAtom）
    • 

  • TotalDisplay 会重渲染（totalAtom 依赖 taxRateAtom）
    • 

  • TaxRateControl 不会重渲染（只使用 setter）
    • 





提示： Signals 仍处于提案阶段，React 团队对其态度谨慎。目前在 React 中实现细粒度响应式的最佳方案是使用 Jotai 的原子模型，或者 Preact 的 @preact/signals-react。






小结
    

  • Jotai 采用原子化模型，每个 atom 是最小状态单元，组件按需订阅
    • 

  • Derived atom 自动追踪依赖，支持同步和异步派生
    • 

  • useAtomValue 和 useSetAtom 分离读写，进一步减少不必要的重渲染
    • 

  • Signals 是 TC39 Stage 1 提案，采用 push 模型实现细粒度 DOM 更新
    • 

  • 在 React 生态中，Jotai 的原子模型是当前最接近细粒度响应式的方案
