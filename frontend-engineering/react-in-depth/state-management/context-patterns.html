Context 模式

Context 基础

React Context 提供了一种跨组件树传递数据的方式，无需通过每一层手动传递 props。它由 createContext、Provider 和 useContext 三部分组成。

interface ThemeContextValue {
  theme: 'light' | 'dark';
  toggleTheme: () => void;
}

const ThemeContext = createContext<ThemeContextValue | null>(null);

function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setTheme] = useState<'light' | 'dark'>('light');

  const value = useMemo<ThemeContextValue>(
    () => ({
      theme,
      toggleTheme: () => setTheme((t) => (t === 'light' ? 'dark' : 'light')),
    }),
    [theme],
  );

  return <ThemeContext.Provider value={value}>{children}</ThemeContext.Provider>;
}

function useTheme(): ThemeContextValue {
  const context = useContext(ThemeContext);
  if (context === null) {
    throw new Error('useTheme must be used within ThemeProvider');
  }
  return context;
}


Provider 组合
当应用需要多个 Context 时，Provider 嵌套会变得很深。可以通过组合模式简化：


function AppProviders({ children }: { children: React.ReactNode }) {
  return (
    <ThemeProvider>
      <AuthProvider>
        <I18nProvider>
          <NotificationProvider>{children}</NotificationProvider>
        </I18nProvider>
      </AuthProvider>
    </ThemeProvider>
  );
}

function composeProviders(
  ...providers: Array<React.FC<{ children: React.ReactNode }>>
): React.FC<{ children: React.ReactNode }> {
  return providers.reduce(
    (Accumulated, Current) =>
      function ComposedProvider({ children }) {
        return (
          <Accumulated>
            <Current>{children}</Current>
          </Accumulated>
        );
      },
    ({ children }: { children: React.ReactNode }) => <>{children}</>,
  );
}

const AppProviders2 = composeProviders(ThemeProvider, AuthProvider, I18nProvider, NotificationProvider);


Context 拆分
将不相关的状态放在同一个 Context 中会导致不必要的重渲染。Context 拆分是核心优化策略：


反模式：巨型 Context
interface AppState {
  user: User | null;
  theme: 'light' | 'dark';
  locale: string;
  notifications: Notification[];
}

const AppContext = createContext<AppState & AppActions>(/* ... */);
正确模式：按领域拆分
const UserContext = createContext<UserContextValue | null>(null);
const ThemeContext = createContext<ThemeContextValue | null>(null);
const LocaleContext = createContext<LocaleContextValue | null>(null);

性能陷阱
陷阱 1：Provider value 的引用稳定性
function BadProvider({ children }: { children: React.ReactNode }) {
  const [count, setCount] = useState(0);

  return <MyContext.Provider value={{ count, increment: () => setCount((c) => c + 1) }}>{children}</MyContext.Provider>;
}
每次 BadProvider 渲染时，value 都是新对象，导致所有消费者重渲染。


function GoodProvider({ children }: { children: React.ReactNode }) {
  const [count, setCount] = useState(0);

  const value = useMemo(() => ({ count, increment: () => setCount((c) => c + 1) }), [count]);

  return <MyContext.Provider value={value}>{children}</MyContext.Provider>;
}
陷阱 2：状态与派发不分离
当只需要 dispatch 的组件也订阅了 state Context，state 变化会触发不必要渲染：


const StateContext = createContext<AppState>(initialState);
const DispatchContext = createContext<React.Dispatch<Action>>(() => {});

function AppProvider({ children }: { children: React.ReactNode }) {
  const [state, dispatch] = useReducer(appReducer, initialState);

  return (
    <StateContext.Provider value={state}>
      <DispatchContext.Provider value={dispatch}>{children}</DispatchContext.Provider>
    </StateContext.Provider>
  );
}

function ActionButton() {
  const dispatch = useContext(DispatchContext);
  return <button onClick={() => dispatch({ type: 'INCREMENT' })}>+1</button>;
}


提示： dispatch 函数在组件生命周期内引用稳定（React 保证），因此 DispatchContext 的 value 不会变化，使用 dispatch 的组件不会因 state 变更而重渲染。






Context Selectors
React 原生不支持 Context Selector（只消费 Context 的部分值）。社区有 use-context-selector 库提供此能力：


import { createContext, useContextSelector } from 'use-context-selector';

interface Store {
  count: number;
  text: string;
  increment: () => void;
  setText: (text: string) => void;
}

const StoreContext = createContext<Store>(null!);

function CountDisplay() {
  const count = useContextSelector(StoreContext, (s) => s.count);
  return <span>{count}</span>;
}

function TextDisplay() {
  const text = useContextSelector(StoreContext, (s) => s.text);
  return <span>{text}</span>;
}


小结
    

  • Context 通过 Provider/Consumer 模式跨组件传递数据，避免 props drilling
    • 

  • 多个 Provider 可以通过组合函数简化嵌套
    • 

  • 将不相关的状态拆分到不同 Context 中，减少不必要的重渲染
    • 

  • Provider value 必须保持引用稳定（使用 useMemo），state 和 dispatch 应分离到不同 Context
    • 

  • 使用 use-context-selector 库可以实现细粒度的 Context 订阅
