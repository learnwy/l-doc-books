核心概念 简介

React 在表面上是声明式的——你描述 UI 应该是什么样子，React 负责将其变为现实。但在这层简洁的抽象之下，隐藏着一套精密而复杂的运行时系统。理解这套系统的工作原理，不仅能帮助你诊断疑难问题，更能让你在架构设计和性能优化时做出有据可依的决策。

第一节"Fiber 架构"揭示 React 16 之后最核心的内部变革。Fiber 节点构成的链表树结构替代了早期的递归调用栈，使得渲染工作可以被中断、恢复和优先级排序。我们将深入理解 Fiber 节点的数据结构、双缓冲机制以及 Fiber 树的遍历算法——这是理解 React 一切行为的基础。

第二节"协调算法"解析 React 如何高效地计算 UI 的最小更新。从经典的 O(n) diff 启发式策略到 key 的匹配机制，从单节点 diff 到多节点列表的比较——协调算法决定了 React 如何在"全量重渲染"的心智模型下实现精确的增量更新。

第三节"并发模式"介绍 React 18 带来的并发渲染能力。startTransition 如何区分紧急与非紧急更新、useDeferredValue 如何延迟低优先级渲染、并发特性如何与 Suspense 协同工作——并发模式从根本上改变了 React 处理用户交互和数据加载的方式。

第四节"调度器"深入 React 的任务调度核心。时间切片如何保证主线程不被长时间阻塞、优先级 Lane 模型如何管理不同紧急程度的更新、调度器与浏览器事件循环的协作方式——调度器是 Fiber 架构和并发模式得以运作的底层引擎。
