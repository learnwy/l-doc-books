并发模式

从同步到并发

传统 React 渲染是同步的——一次 setState 触发一次完整渲染，中间无法中断。当渲染耗时较长时，用户输入会被阻塞。并发模式（Concurrent Mode） 允许 React 同时准备多个版本的 UI，在保证高优先级交互响应的同时，在后台完成低优先级渲染。



提示： React 18 默认启用并发特性，但只有使用 createRoot 才能激活。ReactDOM.render 仍然以同步模式运行。






Time Slicing 时间切片
时间切片是并发模式的底层实现。React 将渲染工作拆分为多个小任务，每完成一个任务就检查是否需要让出主线程。


function workLoopConcurrent(): void {
  while (workInProgress !== null && !shouldYield()) {
    performUnitOfWork(workInProgress);
  }
}

function shouldYield(): boolean {
  const currentTime = getCurrentTime();
  return currentTime >= deadline;
}
时间切片确保每一帧中 React 只占用有限时间（通常 5ms），剩余时间留给浏览器处理动画、布局和绘制：

Transitions
startTransition 是 React 18 提供的并发特性 API，用于标记某些状态更新为过渡更新，告诉 React 这些更新可以被中断。


import { useState, useTransition } from 'react';

function SearchPage() {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState<string[]>([]);
  const [isPending, startTransition] = useTransition();

  function handleChange(e: React.ChangeEvent<HTMLInputElement>) {
    const value = e.target.value;
    setQuery(value);

    startTransition(() => {
      const filtered = heavyFilter(value);
      setResults(filtered);
    });
  }

  return (
    <div>
      <input value={query} onChange={handleChange} />
      {isPending && <span>加载中...</span>}
      <ResultList results={results} />
    </div>
  );
}
startTransition 内部的更新被标记为 TransitionLane，优先级低于用户输入（SyncLane / InputContinuousLane），因此输入框能立即响应，搜索结果在后台计算。

useDeferredValue
useDeferredValue 是另一种使用并发特性的方式。它返回一个值的延迟版本——当有更高优先级的更新时，这个值会暂时保持旧值，等高优先级更新完成后再更新。


import { useState, useDeferredValue, memo } from 'react';

function App() {
  const [text, setText] = useState('');
  const deferredText = useDeferredValue(text);

  return (
    <div>
      <input value={text} onChange={(e) => setText(e.target.value)} placeholder="输入搜索内容" />
      <HeavyList text={deferredText} />
    </div>
  );
}

const HeavyList = memo(function HeavyList({ text }: { text: string }) {
  const items = Array.from({ length: 10000 }, (_, i) => <div key={i}>{text ? `${text} - ${i}` : `Item ${i}`}</div>);
  return <div>{items}</div>;
});


提示： useDeferredValue 和 useTransition 都是并发特性，区别在于：useTransition 包裹的是触发更新的代码，useDeferredValue 包裹的是被影响的值。当你无法控制状态更新的来源时（如来自 props），使用 useDeferredValue 更合适。






Suspense Boundaries
Suspense 组件定义了 UI 的加载边界。当其子树中有组件尚未准备好（数据未加载、代码未下载），React 会显示 fallback 内容。


import { Suspense, lazy } from 'react';

const Dashboard = lazy(() => import('./Dashboard'));
const Analytics = lazy(() => import('./Analytics'));

function App() {
  return (
    <div>
      <Suspense fallback={<Skeleton type="dashboard" />}>
        <Dashboard />
      </Suspense>
      <Suspense fallback={<Skeleton type="analytics" />}>
        <Analytics />
      </Suspense>
    </div>
  );
}

Suspense 与 Transition 的配合
当 startTransition 触发的更新导致 Suspense 挂起时，React 不会立即显示 fallback，而是继续展示当前 UI 直到新内容准备好：


function TabContainer() {
  const [tab, setTab] = useState<'home' | 'posts' | 'about'>('home');
  const [isPending, startTransition] = useTransition();

  function selectTab(nextTab: 'home' | 'posts' | 'about') {
    startTransition(() => {
      setTab(nextTab);
    });
  }

  return (
    <div>
      <nav style={{ opacity: isPending ? 0.7 : 1 }}>
        <button onClick={() => selectTab('home')}>首页</button>
        <button onClick={() => selectTab('posts')}>文章</button>
        <button onClick={() => selectTab('about')}>关于</button>
      </nav>
      <Suspense fallback={<Loading />}>
        {tab === 'home' && <Home />}
        {tab === 'posts' && <Posts />}
        {tab === 'about' && <About />}
      </Suspense>
    </div>
  );
}


小结
    

  • 并发模式 允许 React 中断低优先级渲染以响应高优先级用户交互
    • 

  • 时间切片 将渲染拆分为 5ms 左右的小任务，保证每帧都有时间进行浏览器绘制
    • 

  • startTransition 将非紧急更新标记为过渡优先级，避免阻塞用户输入
    • 

  • useDeferredValue 延迟值的更新，适用于无法控制更新源的场景
    • 

  • Suspense 在并发模式下支持数据获取、选择性水合等高级能力，与 Transition 配合可以避免不必要的 loading 状态闪烁
    •
