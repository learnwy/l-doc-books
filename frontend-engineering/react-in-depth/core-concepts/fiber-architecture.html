Fiber 架构

为什么需要 Fiber

React 15 及之前使用递归的 Stack Reconciler，一旦开始渲染就无法中断，长任务会阻塞主线程导致掉帧。React 16 引入的 Fiber 架构 将渲染工作拆分为可中断的小单元，使 React 能够在空闲时间片内逐步完成更新，从而保持流畅的用户交互。



Fiber Node 数据结构
每一个 React 元素对应一个 Fiber Node，它是一个 JavaScript 对象，包含了组件类型、状态、副作用等信息。Fiber Node 通过三个指针构成链表树结构：

interface FiberNode {
  tag: number;
  key: string | null;
  type: any;
  stateNode: any;

  return: FiberNode | null;
  child: FiberNode | null;
  sibling: FiberNode | null;

  memoizedState: any;
  memoizedProps: any;
  pendingProps: any;

  flags: number;
  lanes: number;
  alternate: FiberNode | null;
}


提示： Fiber 使用链表而非数组来组织子节点，这使得在任意位置暂停和恢复遍历变得非常高效。






Work Loop 工作循环
Fiber 的核心调度逻辑在 Work Loop 中。它分为两个阶段：


Render 阶段（可中断）
Work Loop 通过 performUnitOfWork 逐个处理 Fiber 节点。每个 Fiber 先执行 beginWork（向下递）再执行 completeWork（向上归）。


function workLoopConcurrent(): void {
  while (workInProgress !== null && !shouldYield()) {
    performUnitOfWork(workInProgress);
  }
}

function performUnitOfWork(unitOfWork: FiberNode): void {
  const next = beginWork(unitOfWork);

  if (next === null) {
    completeUnitOfWork(unitOfWork);
  } else {
    workInProgress = next;
  }
}
Commit 阶段（不可中断）
Render 阶段完成后进入 Commit 阶段，将所有变更一次性应用到真实 DOM。此阶段分为三个子阶段：

Priority Lanes 优先级模型
React 18 使用 Lanes 模型管理更新优先级。每条 Lane 是一个 32 位整数中的一个或多个位，不同优先级的更新占据不同的位。


type Lane = number;
type Lanes = number;

const NoLane: Lane = 0b0000000000000000000000000000000;
const SyncLane: Lane = 0b0000000000000000000000000000010;
const InputContinuousLane: Lane = 0b0000000000000000000000000001000;
const DefaultLane: Lane = 0b0000000000000000000000000100000;
const TransitionLane1: Lane = 0b0000000000000000000001000000000;
const IdleLane: Lane = 0b0100000000000000000000000000000;

提示： Lanes 用位运算合并和比较优先级，比 React 17 的 expirationTime 模型更灵活，能够表达多个并发优先级。






双缓冲机制
React 维护两棵 Fiber 树：current 树对应当前屏幕上的 UI，workInProgress 树是正在构建中的新 UI。更新完成后两棵树交换身份。


每个 Fiber 节点的 alternate 属性指向另一棵树中对应的节点。这种双缓冲策略避免了频繁创建和销毁对象，同时使得回滚变得简单——如果更新被中断，直接丢弃 workInProgress 树即可。


function createWorkInProgress(current: FiberNode, pendingProps: any): FiberNode {
  let workInProgress = current.alternate;

  if (workInProgress === null) {
    workInProgress = createFiber(current.tag, pendingProps, current.key);
    workInProgress.type = current.type;
    workInProgress.stateNode = current.stateNode;
    workInProgress.alternate = current;
    current.alternate = workInProgress;
  } else {
    workInProgress.pendingProps = pendingProps;
    workInProgress.flags = 0;
  }

  workInProgress.child = current.child;
  workInProgress.memoizedState = current.memoizedState;
  workInProgress.lanes = current.lanes;

  return workInProgress;
}


小结
    

  • Fiber Node 是 React 中对组件实例的内部表示，通过 child、sibling、return 三个指针组成链表树
    • 

  • Work Loop 将渲染拆分为可中断的工作单元，每个时间片处理若干个 Fiber 节点
    • 

  • Render 阶段 可以被中断和恢复，Commit 阶段 必须同步完成
    • 

  • Lanes 优先级模型 使用位运算管理多级优先级，支持并发更新
    • 

  • 双缓冲机制 通过 current / workInProgress 两棵树实现高效更新与安全回滚
    •
