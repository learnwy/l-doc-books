memo 与 useCallback

重渲染的代价

React 中父组件重渲染时，其所有子组件默认都会重渲染，即使 props 没有变化。对于复杂组件树，这会造成大量不必要的计算。React.memo、useMemo 和 useCallback 是 React 提供的三种记忆化工具。



React.memo
React.memo 是一个高阶组件，它对 props 进行浅比较。如果 props 没有变化，则跳过重渲染：


interface ExpensiveListProps {
  items: string[];
  onItemClick: (item: string) => void;
}

const ExpensiveList = memo(function ExpensiveList({ items, onItemClick }: ExpensiveListProps) {
  return (
    <ul>
      {items.map((item) => (
        <li key={item} onClick={() => onItemClick(item)}>
          {item}
        </li>
      ))}
    </ul>
  );
});
自定义比较函数
const UserCard = memo(
  function UserCard({ user }: { user: User }) {
    return (
      <div>
        <h3>{user.name}</h3>
        <p>{user.email}</p>
      </div>
    );
  },
  (prevProps, nextProps) => {
    return prevProps.user.id === nextProps.user.id && prevProps.user.name === nextProps.user.name;
  },
);

Referential Equality 引用相等
React.memo 使用 Object.is 比较 props。问题在于每次父组件渲染时创建的新对象和新函数都不等于旧的：


function Parent() {
  const [count, setCount] = useState(0);

  const config = { theme: 'dark', size: 'large' };
  const handleClick = () => console.log('clicked');

  return (
    <div>
      <button onClick={() => setCount((c) => c + 1)}>Count: {count}</button>
      <MemoChild config={config} onClick={handleClick} />
    </div>
  );
}
每次 Parent 渲染，config 和 handleClick 都是新引用，MemoChild 的 memo 失效。




useCallback
useCallback 缓存函数引用，只在依赖变化时创建新函数：


function Parent() {
  const [count, setCount] = useState(0);
  const [query, setQuery] = useState('');

  const handleSearch = useCallback((term: string) => {
    console.log(`Searching for: ${term}`);
  }, []);

  const handleItemSelect = useCallback(
    (id: string) => {
      console.log(`Selected item ${id}, count is ${count}`);
    },
    [count],
  );

  return (
    <div>
      <input value={query} onChange={(e) => setQuery(e.target.value)} />
      <button onClick={() => setCount((c) => c + 1)}>+1</button>
      <SearchResults onSearch={handleSearch} />
      <ItemList onSelect={handleItemSelect} />
    </div>
  );
}

const SearchResults = memo(function SearchResults({ onSearch }: { onSearch: (term: string) => void }) {
  return <div onClick={() => onSearch('test')}>搜索结果</div>;
});


useMemo
useMemo 缓存计算结果，只在依赖变化时重新计算：


function ProductPage({ products, filter }: { products: Product[]; filter: string }) {
  const filteredProducts = useMemo(
    () => products.filter((p) => p.name.toLowerCase().includes(filter.toLowerCase())),
    [products, filter],
  );

  const stats = useMemo(
    () => ({
      total: filteredProducts.length,
      avgPrice: filteredProducts.reduce((sum, p) => sum + p.price, 0) / filteredProducts.length,
    }),
    [filteredProducts],
  );

  const config = useMemo(() => ({ theme: 'dark', size: 'large' }), []);

  return (
    <div>
      <StatsBar stats={stats} />
      <MemoizedProductList items={filteredProducts} config={config} />
    </div>
  );
}

何时不应使用 Memoization
记忆化不是免费的——它消耗内存存储缓存值，并且每次渲染都需要比较依赖。过度使用反而降低性能：

function SimpleLabel({ text }: { text: string }) {
  return <span>{text}</span>;
}

// ❌ 不需要 memo：非常轻量的组件
const MemoLabel = memo(SimpleLabel);

// ❌ 不需要 useCallback：没有传给 memo 子组件
function Form() {
  const handleSubmit = useCallback(() => {
    submitForm();
  }, []);

  return <form onSubmit={handleSubmit}>...</form>;
}


提示： React 编译器（React Compiler）正在开发中，目标是自动为组件添加 memoization，让开发者无需手动管理。在编译器普及前，手动 memo 仍是优化大型组件树的重要手段。






最佳实践
function OptimizedApp() {
  const [searchTerm, setSearchTerm] = useState('');
  const [selectedId, setSelectedId] = useState<string | null>(null);

  const handleSelect = useCallback((id: string) => {
    setSelectedId(id);
  }, []);

  const handleSearch = useCallback((term: string) => {
    setSearchTerm(term);
  }, []);

  return (
    <div>
      <SearchBar onSearch={handleSearch} />
      <Suspense fallback={<Spinner />}>
        <ResultList searchTerm={searchTerm} onSelect={handleSelect} />
      </Suspense>
      {selectedId && <DetailPanel id={selectedId} />}
    </div>
  );
}

const SearchBar = memo(function SearchBar({ onSearch }: { onSearch: (term: string) => void }) {
  const [input, setInput] = useState('');

  return (
    <input
      value={input}
      onChange={(e) => {
        setInput(e.target.value);
        onSearch(e.target.value);
      }}
    />
  );
});


小结
    

  • React.memo 对 props 浅比较，相同则跳过重渲染
    • 

  • useCallback 缓存函数引用，确保传给 memo 子组件的回调引用稳定
    • 

  • useMemo 缓存计算结果和对象引用，避免重复计算和引用失效
    • 

  • 不要过度 memo：轻量组件、props 总变的场景不需要 memoization
    • 

  • React Compiler 将来会自动处理 memoization，但当前手动优化仍有必要
    •
