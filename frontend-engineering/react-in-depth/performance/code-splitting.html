代码分割

为什么需要代码分割

随着应用规模增长，JavaScript bundle 体积越来越大。用户必须下载并解析全部代码后才能使用应用。代码分割（Code Splitting） 将 bundle 拆分为多个小块，按需加载，显著减少初始加载时间。

React.lazy
React.lazy 让你可以像使用普通组件一样使用动态导入的组件，配合 Suspense 显示加载状态：


import { lazy, Suspense } from 'react';

const Dashboard = lazy(() => import('./Dashboard'));
const Settings = lazy(() => import('./Settings'));
const Analytics = lazy(() => import('./Analytics'));

function App() {
  const [page, setPage] = useState<'dashboard' | 'settings' | 'analytics'>('dashboard');

  return (
    <div>
      <nav>
        <button onClick={() => setPage('dashboard')}>仪表盘</button>
        <button onClick={() => setPage('settings')}>设置</button>
        <button onClick={() => setPage('analytics')}>分析</button>
      </nav>
      <Suspense fallback={<PageSkeleton />}>
        {page === 'dashboard' && <Dashboard />}
        {page === 'settings' && <Settings />}
        {page === 'analytics' && <Analytics />}
      </Suspense>
    </div>
  );
}
命名导出
React.lazy 只支持默认导出。对于命名导出，需要中间模块：


// MathUtils.ts
export function add(a: number, b: number) {
  return a + b;
}
export function Chart() {
  return <div>Chart</div>;
}

// ChartLazy.ts
export { Chart as default } from './MathUtils';

// App.tsx
const Chart = lazy(() => import('./ChartLazy'));

// 或直接使用 then
const Chart = lazy(() => import('./MathUtils').then((mod) => ({ default: mod.Chart })));


Dynamic Import
import() 是代码分割的底层原语。Webpack、Vite 等打包器遇到 import() 会自动创建新的 chunk：


async function loadHeavyModule() {
  const module = await import('./heavy-computation');
  return module.processData(data);
}

// 带条件的动态加载
async function handleExport(format: 'pdf' | 'csv' | 'xlsx') {
  switch (format) {
    case 'pdf': {
      const { generatePDF } = await import('./exporters/pdf');
      return generatePDF(data);
    }
    case 'csv': {
      const { generateCSV } = await import('./exporters/csv');
      return generateCSV(data);
    }
    case 'xlsx': {
      const { generateXLSX } = await import('./exporters/xlsx');
      return generateXLSX(data);
    }
  }
}


Route-Based Splitting
最常见且效果最好的代码分割策略是基于路由分割——每个路由对应一个 chunk：


import { lazy, Suspense } from 'react';
import { Routes, Route } from 'react-router-dom';

const Home = lazy(() => import('./pages/Home'));
const Blog = lazy(() => import('./pages/Blog'));
const BlogPost = lazy(() => import('./pages/BlogPost'));
const Profile = lazy(() => import('./pages/Profile'));
const Admin = lazy(() => import('./pages/Admin'));

function App() {
  return (
    <Suspense fallback={<GlobalSpinner />}>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/blog" element={<Blog />} />
        <Route path="/blog/:slug" element={<BlogPost />} />
        <Route path="/profile" element={<Profile />} />
        <Route path="/admin/*" element={<Admin />} />
      </Routes>
    </Suspense>
  );
}

Module Preloading
代码分割的缺点是用户切换路由时需要等待 chunk 下载。预加载（Preloading） 可以在用户可能导航之前就开始下载：


const AdminPage = lazy(() => import('./pages/Admin'));

function preloadAdmin() {
  import('./pages/Admin');
}

function NavItem() {
  return (
    <Link to="/admin" onMouseEnter={preloadAdmin} onFocus={preloadAdmin}>
      管理后台
    </Link>
  );
}
基于路由的预加载
interface RouteConfig {
  path: string;
  component: React.LazyExoticComponent<React.ComponentType>;
  preload: () => Promise<unknown>;
}

const routes: RouteConfig[] = [
  {
    path: '/dashboard',
    component: lazy(() => import('./pages/Dashboard')),
    preload: () => import('./pages/Dashboard'),
  },
  {
    path: '/settings',
    component: lazy(() => import('./pages/Settings')),
    preload: () => import('./pages/Settings'),
  },
];

function Navigation() {
  return (
    <nav>
      {routes.map((route) => (
        <Link key={route.path} to={route.path} onMouseEnter={() => route.preload()}>
          {route.path}
        </Link>
      ))}
    </nav>
  );
}
使用 link 标签预加载
function usePreloadOnIdle(importFn: () => Promise<unknown>) {
  useEffect(() => {
    if ('requestIdleCallback' in window) {
      const id = requestIdleCallback(() => importFn());
      return () => cancelIdleCallback(id);
    }
    const timer = setTimeout(() => importFn(), 2000);
    return () => clearTimeout(timer);
  }, [importFn]);
}

function App() {
  usePreloadOnIdle(() => import('./pages/Settings'));
  usePreloadOnIdle(() => import('./pages/Profile'));

  return <MainContent />;
}


提示： 预加载策略建议：(1) 鼠标悬停时预加载链接目标 (2) 空闲时预加载高概率访问的路由 (3) 视口内可见的链接预加载。






小结
    

  • 代码分割 将大 bundle 拆分为按需加载的小 chunk，显著减少初始加载时间
    • 

  • React.lazy + Suspense 是组件级代码分割的标准方案
    • 

  • 基于路由分割 是最常见且效果最好的策略
    • 

  • 预加载 通过 hover、focus、idle 时机提前下载 chunk，消除切换延迟
    • 

  • import() 是代码分割的底层原语，打包器自动识别并创建独立 chunk
    •
