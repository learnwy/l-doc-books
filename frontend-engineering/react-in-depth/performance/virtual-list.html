虚拟列表

为什么需要虚拟列表

当列表包含成千上万条数据时，一次性渲染所有 DOM 节点会导致严重的性能问题：初始渲染慢、滚动卡顿、内存占用高。虚拟列表（Virtual List） 只渲染可视区域内的元素，通过动态替换视口中的节点来模拟完整列表。

react-window
react-window 是最流行的虚拟列表库，体积小（~2KB），API 简洁：


固定高度列表
import { FixedSizeList } from 'react-window';

interface RowProps {
  index: number;
  style: React.CSSProperties;
}

function Row({ index, style }: RowProps) {
  return (
    <div style={style} className={index % 2 === 0 ? 'row-even' : 'row-odd'}>
      Row {index}
    </div>
  );
}

function VirtualList({ itemCount }: { itemCount: number }) {
  return (
    <FixedSizeList height={600} width="100%" itemCount={itemCount} itemSize={50}>
      {Row}
    </FixedSizeList>
  );
}
固定高度网格
import { FixedSizeGrid } from 'react-window';

interface CellProps {
  columnIndex: number;
  rowIndex: number;
  style: React.CSSProperties;
}

function Cell({ columnIndex, rowIndex, style }: CellProps) {
  return (
    <div style={style}>
      ({rowIndex}, {columnIndex})
    </div>
  );
}

function VirtualGrid() {
  return (
    <FixedSizeGrid columnCount={100} columnWidth={120} height={600} rowCount={1000} rowHeight={50} width={800}>
      {Cell}
    </FixedSizeGrid>
  );
}


可变高度列表
当列表项高度不一致时，使用 VariableSizeList：


import { VariableSizeList } from 'react-window';

const rowHeights = new Array(10000).fill(null).map(() => 50 + Math.round(Math.random() * 100));

function getItemSize(index: number): number {
  return rowHeights[index];
}

function VariableRow({ index, style }: { index: number; style: React.CSSProperties }) {
  return (
    <div style={style}>
      <div style={{ padding: 8 }}>
        <strong>Item {index}</strong>
        <p>高度: {rowHeights[index]}px</p>
      </div>
    </div>
  );
}

function VariableList() {
  return (
    <VariableSizeList height={600} width="100%" itemCount={10000} itemSize={getItemSize} estimatedItemSize={100}>
      {VariableRow}
    </VariableSizeList>
  );
}


react-virtuoso
react-virtuoso 是另一个流行的虚拟列表库，支持自动测量高度、分组、反向列表等高级功能：


import { Virtuoso, GroupedVirtuoso } from 'react-virtuoso';

function AutoSizeList({ items }: { items: Item[] }) {
  return (
    <Virtuoso
      style={{ height: 600 }}
      totalCount={items.length}
      itemContent={(index) => (
        <div style={{ padding: 16 }}>
          <h3>{items[index].title}</h3>
          <p>{items[index].description}</p>
        </div>
      )}
    />
  );
}

function ChatMessages({ messages }: { messages: Message[] }) {
  return (
    <Virtuoso
      style={{ height: 500 }}
      totalCount={messages.length}
      initialTopMostItemIndex={messages.length - 1}
      followOutput="smooth"
      itemContent={(index) => (
        <div className="message">
          <span className="author">{messages[index].author}</span>
          <p>{messages[index].text}</p>
        </div>
      )}
    />
  );
}

Infinite Scroll 无限滚动
虚拟列表配合无限滚动实现动态加载数据：


import { Virtuoso } from 'react-virtuoso';

function InfiniteList() {
  const [items, setItems] = useState<Item[]>([]);
  const [hasMore, setHasMore] = useState(true);

  const loadMore = useCallback(async () => {
    const nextItems = await fetchItems(items.length, 20);
    if (nextItems.length === 0) {
      setHasMore(false);
      return;
    }
    setItems((prev) => [...prev, ...nextItems]);
  }, [items.length]);

  return (
    <Virtuoso
      style={{ height: '100vh' }}
      totalCount={items.length}
      endReached={hasMore ? loadMore : undefined}
      itemContent={(index) => (
        <div className="item">
          <h3>{items[index].title}</h3>
          <p>{items[index].description}</p>
        </div>
      )}
      components={{
        Footer: () => (hasMore ? <div className="loading">加载中...</div> : null),
      }}
    />
  );
}


提示： 虚拟列表要注意滚动条的准确性。对于可变高度的列表，estimatedItemSize 越接近实际平均高度，滚动条越精确。






小结
    

  • 虚拟列表 只渲染可视区域的 DOM 节点，将数万条数据的渲染性能降至恒定
    • 

  • react-window 轻量简洁，适合固定高度或已知高度的列表
    • 

  • react-virtuoso 功能丰富，支持自动测量、分组、反向列表和内置无限滚动
    • 

  • 固定高度用 FixedSizeList，可变高度用 VariableSizeList 或 react-virtuoso
    • 

  • 无限滚动通过监听到底事件触发分页加载，与虚拟列表结合可处理无限数据
