React Server Components 服务端组件

RSC 的革命性

React Server Components（RSC） 是一种全新的组件类型，它在服务器上执行并且不会发送到客户端。RSC 可以直接访问数据库、文件系统等服务端资源，且其代码不包含在客户端 JS bundle 中。

Server/Client 边界
通过 'use client' 指令标记客户端组件。没有该指令的组件默认为 Server Component：


// ServerComponent.tsx — 服务器组件（默认）
import { db } from '@/lib/db';

async function ArticleList() {
  const articles = await db.article.findMany({
    orderBy: { createdAt: 'desc' },
    take: 10,
  });

  return (
    <ul>
      {articles.map((article) => (
        <li key={article.id}>
          <ArticleCard article={article} />
        </li>
      ))}
    </ul>
  );
}
// LikeButton.tsx — 客户端组件
'use client';

import { useState } from 'react';

export function LikeButton({ articleId }: { articleId: string }) {
  const [liked, setLiked] = useState(false);

  return <button onClick={() => setLiked(!liked)}>{liked ? '❤️' : '🤍'} 喜欢</button>;
}


提示： 'use client' 标记的不是单个组件，而是一个边界。从该文件导入的所有组件及其子组件都将成为客户端组件。






Async Components
Server Components 可以是 async 函数，直接在组件体内 await 数据：


async function UserProfile({ userId }: { userId: string }) {
  const user = await fetch(`https://api.example.com/users/${userId}`).then((res) => res.json());

  const posts = await fetch(`https://api.example.com/users/${userId}/posts`).then((res) => res.json());

  return (
    <div>
      <h1>{user.name}</h1>
      <p>{user.bio}</p>
      <h2>文章列表</h2>
      <ul>
        {posts.map((post: { id: string; title: string }) => (
          <li key={post.id}>{post.title}</li>
        ))}
      </ul>
    </div>
  );
}

function ProfilePage({ userId }: { userId: string }) {
  return (
    <Suspense fallback={<ProfileSkeleton />}>
      <UserProfile userId={userId} />
    </Suspense>
  );
}
并行数据获取
避免瀑布式请求，使用 Promise.all 并行获取：


async function Dashboard() {
  const [user, stats, notifications] = await Promise.all([fetchUser(), fetchStats(), fetchNotifications()]);

  return (
    <div>
      <UserInfo user={user} />
      <StatsPanel stats={stats} />
      <NotificationList notifications={notifications} />
    </div>
  );
}

// ✅ 正确：传递可序列化的数据
async function ParentServer() {
  const data = await fetchData();

  return <ClientChild title={data.title} count={data.count} items={data.items} />;
}

// ❌ 错误：不能传递函数
async function ParentServer() {
  const handleClick = () => console.log('clicked');
  return <ClientChild onClick={handleClick} />; // 报错
}

// ✅ 使用 Server Action 替代
async function ParentServer() {
  async function handleSubmit(formData: FormData) {
    'use server';
    await db.article.create({
      data: { title: formData.get('title') as string },
    });
  }

  return <ClientForm action={handleSubmit} />;
}


Server Components 的优势
// 零 Bundle 影响的重依赖
import { marked } from 'marked';
import hljs from 'highlight.js';
import sanitizeHtml from 'sanitize-html';

async function MarkdownArticle({ slug }: { slug: string }) {
  const article = await db.article.findUnique({ where: { slug } });
  if (!article) return notFound();

  const html = sanitizeHtml(
    marked(article.content, {
      highlight: (code, lang) => hljs.highlight(code, { language: lang }).value,
    }),
  );

  return <article dangerouslySetInnerHTML={{ __html: html }} />;
}
marked、highlight.js、sanitize-html 这些库只在服务端使用，不会打包到客户端，节省数百 KB 的 bundle 体积。




小结
    

  • RSC 在服务器上运行，不包含在客户端 JS bundle 中，可直接访问服务端资源
    • 

  • 'use client' 标记客户端边界，从该文件开始的所有子组件都是客户端组件
    • 

  • Server Components 支持 async/await，可直接在组件体内获取数据
    • 

  • 传递给 Client Component 的 props 必须可序列化，函数使用 Server Action 替代
    • 

  • 重依赖（Markdown 解析、语法高亮等）放在 Server Component 中可以显著减小 bundle 体积
    •
