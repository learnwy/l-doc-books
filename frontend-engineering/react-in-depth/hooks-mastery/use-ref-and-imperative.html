useRef 与命令式

useRef 的本质

useRef 返回一个包含 current 属性的可变对象，该对象在组件的整个生命周期内保持同一引用。与 useState 不同，修改 ref.current 不会触发重新渲染。

function mountRef<T>(initialValue: T): { current: T } {
  const hook = mountWorkInProgressHook();
  const ref = { current: initialValue };
  hook.memoizedState = ref;
  return ref;
}

function updateRef<T>(): { current: T } {
  const hook = updateWorkInProgressHook();
  return hook.memoizedState;
}

DOM 引用
useRef 最常见的用途是获取 DOM 元素的引用：


function AutoFocusInput() {
  const inputRef = useRef<HTMLInputElement>(null);

  useEffect(() => {
    inputRef.current?.focus();
  }, []);

  return <input ref={inputRef} placeholder="自动聚焦" />;
}
DOM 测量
function MeasuredBox() {
  const boxRef = useRef<HTMLDivElement>(null);
  const [dimensions, setDimensions] = useState({ width: 0, height: 0 });

  useLayoutEffect(() => {
    if (boxRef.current) {
      const { width, height } = boxRef.current.getBoundingClientRect();
      setDimensions({ width, height });
    }
  }, []);

  return (
    <div>
      <div ref={boxRef}>内容</div>
      <p>
        宽度: {dimensions.width}px, 高度: {dimensions.height}px
      </p>
    </div>
  );
}


Ref Forwarding
函数组件默认不接受 ref 属性。使用 forwardRef 可以将 ref 转发到内部的 DOM 元素或子组件：


interface InputProps extends React.InputHTMLAttributes<HTMLInputElement> {
  label: string;
}

const LabeledInput = forwardRef<HTMLInputElement, InputProps>(function LabeledInput({ label, ...props }, ref) {
  return (
    <label>
      {label}
      <input ref={ref} {...props} />
    </label>
  );
});

function Form() {
  const inputRef = useRef<HTMLInputElement>(null);

  return (
    <div>
      <LabeledInput ref={inputRef} label="用户名" />
      <button onClick={() => inputRef.current?.focus()}>聚焦</button>
    </div>
  );
}


提示： React 19 开始，函数组件可以直接接受 ref 作为 props，不再需要 forwardRef 包裹。






useImperativeHandle
useImperativeHandle 允许自定义暴露给父组件的 ref 值，而不是直接暴露 DOM 节点。这在构建可复用组件库时非常有用。


interface VideoPlayerHandle {
  play: () => void;
  pause: () => void;
  seekTo: (time: number) => void;
}

const VideoPlayer = forwardRef<VideoPlayerHandle, { src: string }>(function VideoPlayer({ src }, ref) {
  const videoRef = useRef<HTMLVideoElement>(null);

  useImperativeHandle(
    ref,
    () => ({
      play() {
        videoRef.current?.play();
      },
      pause() {
        videoRef.current?.pause();
      },
      seekTo(time: number) {
        if (videoRef.current) {
          videoRef.current.currentTime = time;
        }
      },
    }),
    [],
  );

  return <video ref={videoRef} src={src} />;
});

function App() {
  const playerRef = useRef<VideoPlayerHandle>(null);

  return (
    <div>
      <VideoPlayer ref={playerRef} src="/video.mp4" />
      <button onClick={() => playerRef.current?.play()}>播放</button>
      <button onClick={() => playerRef.current?.pause()}>暂停</button>
      <button onClick={() => playerRef.current?.seekTo(30)}>跳到 30s</button>
    </div>
  );
}

稳定引用模式
useRef 常用于保存不应触发渲染的值，典型场景包括保存回调函数、定时器 ID、上一次的值：


保存最新回调
function useEventCallback<T extends (...args: any[]) => any>(fn: T): T {
  const ref = useRef(fn);

  useLayoutEffect(() => {
    ref.current = fn;
  });

  return useCallback(((...args: any[]) => ref.current(...args)) as T, []);
}

function SearchInput({ onSearch }: { onSearch: (query: string) => void }) {
  const [query, setQuery] = useState('');
  const stableOnSearch = useEventCallback(onSearch);

  useEffect(() => {
    const timer = setTimeout(() => stableOnSearch(query), 300);
    return () => clearTimeout(timer);
  }, [query, stableOnSearch]);

  return <input value={query} onChange={(e) => setQuery(e.target.value)} />;
}
保存上一次的值
function usePrevious<T>(value: T): T | undefined {
  const ref = useRef<T | undefined>(undefined);

  useEffect(() => {
    ref.current = value;
  });

  return ref.current;
}

function Counter() {
  const [count, setCount] = useState(0);
  const prevCount = usePrevious(count);

  return (
    <div>
      <p>
        当前: {count}，上一次: {prevCount ?? '无'}
      </p>
      <button onClick={() => setCount((c) => c + 1)}>+1</button>
    </div>
  );
}
保存定时器 ID
function useInterval(callback: () => void, delay: number | null) {
  const savedCallback = useRef(callback);

  useLayoutEffect(() => {
    savedCallback.current = callback;
  });

  useEffect(() => {
    if (delay === null) return;
    const id = setInterval(() => savedCallback.current(), delay);
    return () => clearInterval(id);
  }, [delay]);
}


小结
    

  • useRef 返回跨渲染持久化的可变对象，修改 .current 不触发重渲染
    • 

  • 常用于获取 DOM 引用、保存定时器 ID、缓存最新回调等不影响 UI 的数据
    • 

  • forwardRef 将 ref 转发给子组件内部的 DOM 元素（React 19 后可直接用 props）
    • 

  • useImperativeHandle 自定义暴露给父组件的命令式接口，比直接暴露 DOM 更安全
    • 

  • 稳定引用模式 通过 useRef 保存最新回调，配合 useCallback 创建不变的引用，解决 effect 依赖频繁变化的问题
