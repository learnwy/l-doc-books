自定义 Hook 模式

为什么需要自定义 Hook

自定义 Hook 是 React 中复用有状态逻辑的主要方式。它是一个以 use 开头的普通函数，内部可以调用其他 Hook。与 HOC 和 Render Props 相比，自定义 Hook 不引入额外组件层级，类型推断更友好，组合更灵活。



逻辑抽取
自定义 Hook 的核心价值是将组件中可复用的逻辑提取为独立函数。


提取前
function UserProfile({ userId }: { userId: string }) {
  const [user, setUser] = useState<User | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);

  useEffect(() => {
    let cancelled = false;
    setLoading(true);

    fetchUser(userId)
      .then((data) => {
        if (!cancelled) {
          setUser(data);
          setError(null);
        }
      })
      .catch((err) => {
        if (!cancelled) setError(err);
      })
      .finally(() => {
        if (!cancelled) setLoading(false);
      });

    return () => {
      cancelled = true;
    };
  }, [userId]);

  if (loading) return <Spinner />;
  if (error) return <ErrorMessage error={error} />;
  return <div>{user?.name}</div>;
}
提取后
function useAsync<T>(asyncFn: () => Promise<T>, deps: readonly unknown[]) {
  const [state, setState] = useState<{
    data: T | null;
    loading: boolean;
    error: Error | null;
  }>({ data: null, loading: true, error: null });

  useEffect(() => {
    let cancelled = false;
    setState((prev) => ({ ...prev, loading: true }));

    asyncFn()
      .then((data) => {
        if (!cancelled) setState({ data, loading: false, error: null });
      })
      .catch((error) => {
        if (!cancelled) setState({ data: null, loading: false, error });
      });

    return () => {
      cancelled = true;
    };
  }, deps);

  return state;
}

function UserProfile({ userId }: { userId: string }) {
  const { data: user, loading, error } = useAsync(() => fetchUser(userId), [userId]);

  if (loading) return <Spinner />;
  if (error) return <ErrorMessage error={error} />;
  return <div>{user?.name}</div>;
}


组合模式
自定义 Hook 可以调用其他自定义 Hook，形成组合链：


function useDebounce<T>(value: T, delay: number): T {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => setDebouncedValue(value), delay);
    return () => clearTimeout(timer);
  }, [value, delay]);

  return debouncedValue;
}

function useSearch(query: string) {
  const debouncedQuery = useDebounce(query, 300);

  const { data, loading, error } = useAsync(
    () => (debouncedQuery ? searchApi(debouncedQuery) : Promise.resolve([])),
    [debouncedQuery],
  );

  return { results: data ?? [], loading, error };
}


返回值模式
自定义 Hook 的返回值设计直接影响使用体验。常见的返回模式有三种：

function useToggle(initial = false): [boolean, () => void] {
  const [value, setValue] = useState(initial);
  const toggle = useCallback(() => setValue((v) => !v), []);
  return [value, toggle];
}

function useLocalStorage<T>(key: string, initialValue: T) {
  const [storedValue, setStoredValue] = useState<T>(() => {
    try {
      const item = window.localStorage.getItem(key);
      return item ? (JSON.parse(item) as T) : initialValue;
    } catch {
      return initialValue;
    }
  });

  const setValue = useCallback(
    (value: T | ((prev: T) => T)) => {
      setStoredValue((prev) => {
        const valueToStore = value instanceof Function ? value(prev) : value;
        window.localStorage.setItem(key, JSON.stringify(valueToStore));
        return valueToStore;
      });
    },
    [key],
  );

  return { storedValue, setValue } as const;
}


提示： 当返回值只有 2 个时优先使用元组，允许调用方自由命名。当返回值超过 2 个时使用对象，提高可读性。






测试自定义 Hook
自定义 Hook 不能直接调用，必须在 React 组件或 renderHook 中使用。@testing-library/react 提供了 renderHook 工具：


import { renderHook, act } from '@testing-library/react';

describe('useToggle', () => {
  it('should toggle value', () => {
    const { result } = renderHook(() => useToggle(false));

    expect(result.current[0]).toBe(false);

    act(() => {
      result.current[1]();
    });

    expect(result.current[0]).toBe(true);
  });

  it('should accept initial value', () => {
    const { result } = renderHook(() => useToggle(true));
    expect(result.current[0]).toBe(true);
  });
});

describe('useDebounce', () => {
  beforeEach(() => {
    jest.useFakeTimers();
  });

  afterEach(() => {
    jest.useRealTimers();
  });

  it('should debounce value changes', () => {
    const { result, rerender } = renderHook(({ value, delay }) => useDebounce(value, delay), {
      initialProps: { value: 'hello', delay: 300 },
    });

    expect(result.current).toBe('hello');

    rerender({ value: 'world', delay: 300 });
    expect(result.current).toBe('hello');

    act(() => {
      jest.advanceTimersByTime(300);
    });

    expect(result.current).toBe('world');
  });
});


小结
    

  • 自定义 Hook 是以 use 开头的函数，可以调用其他 Hook，用于复用有状态逻辑
    • 

  • 将组件中重复的状态管理、副作用、事件监听逻辑抽取为自定义 Hook 可以显著提高复用性
    • 

  • 自定义 Hook 可以组合其他自定义 Hook，构建高层次的逻辑抽象
    • 

  • 返回值设计遵循：2 个值用元组，多个值用对象，单个值直接返回
    • 

  • 使用 renderHook 和 act 进行单元测试，确保 Hook 行为正确
