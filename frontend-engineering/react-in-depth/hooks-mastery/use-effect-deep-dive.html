useEffect 深入

useEffect 的执行时机

useEffect 的回调函数在 Commit 阶段之后异步执行，不会阻塞浏览器绘制。与之对比，useLayoutEffect 在 DOM 变更后、浏览器绘制前同步执行。

绘制前同步
是
DOM 测量、布局调整





function Example() {
  useLayoutEffect(() => {
    const rect = divRef.current?.getBoundingClientRect();
    setPosition({ x: rect?.left ?? 0, y: rect?.top ?? 0 });
  });

  useEffect(() => {
    fetchData().then(setData);
  }, []);

  return <div ref={divRef}>content</div>;
}


Cleanup 时机
useEffect 的清理函数在下一次 effect 执行之前和组件卸载时调用。理解清理时机对于避免内存泄漏和状态错乱至关重要。


function ChatRoom({ roomId }: { roomId: string }) {
  useEffect(() => {
    const connection = createConnection(roomId);
    connection.connect();

    return () => {
      connection.disconnect();
    };
  }, [roomId]);

  return <div>聊天室: {roomId}</div>;
}
当 roomId 从 "general" 变为 "tech" 时：


    

  1. 执行旧 effect 的 cleanup：disconnect("general")
    2. 

  2. 执行新 effect：connect("tech")
    3. 





提示： 每次 effect 执行都会"捕获"当时的 props 和 state（闭包）。cleanup 函数也捕获的是创建它时的值，而非最新值。






依赖数组比较
React 使用 Object.is 逐个比较依赖数组中的元素来决定是否重新执行 effect：


function areHookInputsEqual(nextDeps: readonly unknown[], prevDeps: readonly unknown[]): boolean {
  for (let i = 0; i < prevDeps.length && i < nextDeps.length; i++) {
    if (Object.is(nextDeps[i], prevDeps[i])) {
      continue;
    }
    return false;
  }
  return true;
}

常见陷阱：对象依赖
function UserPage({ userId }: { userId: string }) {
  const options = { userId, includeDetails: true };

  useEffect(() => {
    fetchUser(options).then(setUser);
  }, [options]);

  return <div>{user?.name}</div>;
}
options 每次渲染都是新对象，Object.is 返回 false，导致 effect 每次都执行。解决方案：


function UserPage({ userId }: { userId: string }) {
  const options = useMemo(() => ({ userId, includeDetails: true }), [userId]);

  useEffect(() => {
    fetchUser(options).then(setUser);
  }, [options]);

  return <div>{user?.name}</div>;
}
或者直接将原始值作为依赖：


function UserPage({ userId }: { userId: string }) {
  useEffect(() => {
    fetchUser({ userId, includeDetails: true }).then(setUser);
  }, [userId]);

  return <div>{user?.name}</div>;
}


竞态条件
当 effect 中有异步操作时，组件可能在异步完成前就更新了依赖或卸载了。如果不处理竞态条件，旧的请求结果可能覆盖新的。


function SearchResults({ query }: { query: string }) {
  const [results, setResults] = useState<string[]>([]);

  useEffect(() => {
    let ignore = false;

    searchApi(query).then((data) => {
      if (!ignore) {
        setResults(data);
      }
    });

    return () => {
      ignore = true;
    };
  }, [query]);

  return (
    <ul>
      {results.map((r) => (
        <li key={r}>{r}</li>
      ))}
    </ul>
  );
}
使用 AbortController 可以更彻底地取消请求：


useEffect(() => {
  const controller = new AbortController();

  fetch(`/api/search?q=${query}`, { signal: controller.signal })
    .then((res) => res.json())
    .then((data) => setResults(data))
    .catch((err) => {
      if (err.name !== 'AbortError') {
        setError(err);
      }
    });

  return () => {
    controller.abort();
  };
}, [query]);


useEffect vs useLayoutEffect
两者 API 完全相同，区别仅在于执行时机。选择错误的时机会导致视觉闪烁或性能问题：






场景
推荐
原因





数据获取
useEffect
不需要阻塞绘制




事件监听 / 订阅
useEffect
不涉及 DOM 布局




读取 DOM 布局
useLayoutEffect
需要在绘制前获取尺寸




基于布局的动画
useLayoutEffect

Tooltip 定位
useLayoutEffect

function Tooltip({ anchorEl, children }: { anchorEl: HTMLElement | null; children: React.ReactNode }) {
  const tooltipRef = useRef<HTMLDivElement>(null);
  const [position, setPosition] = useState({ top: 0, left: 0 });

  useLayoutEffect(() => {
    if (!anchorEl || !tooltipRef.current) return;
    const anchorRect = anchorEl.getBoundingClientRect();
    const tooltipRect = tooltipRef.current.getBoundingClientRect();
    setPosition({
      top: anchorRect.bottom + 8,
      left: anchorRect.left + (anchorRect.width - tooltipRect.width) / 2,
    });
  }, [anchorEl]);

  return (
    <div ref={tooltipRef} style={{ position: 'fixed', top: position.top, left: position.left }}>
      {children}
    </div>
  );
}


小结
    

  • useEffect 在浏览器绘制后异步执行，useLayoutEffect 在绘制前同步执行
    • 

  • Cleanup 函数在下次 effect 执行前和组件卸载时调用，用于清理副作用
    • 

  • 依赖数组使用 Object.is 比较，对象和函数需要通过 useMemo/useCallback 保持引用稳定
    • 

  • 异步 effect 必须处理竞态条件，推荐使用 ignore 标志或 AbortController
    • 

  • DOM 测量和布局相关操作应使用 useLayoutEffect 避免视觉闪烁
    •
