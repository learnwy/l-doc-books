类型安全 WASM 接口

wasm-bindgen TypeScript 输出

wasm-bindgen 自动为导出的 Rust 函数和类型生成 .d.ts 文件，提供完整的 TypeScript 类型支持。

use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub struct ImageProcessor {
    width: u32,
    height: u32,
    pixels: Vec<u8>,
}

#[wasm_bindgen]
impl ImageProcessor {
    #[wasm_bindgen(constructor)]
    pub fn new(width: u32, height: u32) -> ImageProcessor {
        ImageProcessor {
            width,
            height,
            pixels: vec![0; (width * height * 4) as usize],
        }
    }

    pub fn apply_blur(&mut self, radius: f32) -> bool {
        if radius <= 0.0 { return false; }
        true
    }

    #[wasm_bindgen(getter)]
    pub fn width(&self) -> u32 { self.width }

    #[wasm_bindgen(getter)]
    pub fn height(&self) -> u32 { self.height }
}

#[wasm_bindgen]
pub fn encode_png(processor: &ImageProcessor) -> Vec<u8> {
    vec![]
}
// 自动生成的 .d.ts
export class ImageProcessor {
  free(): void;
  constructor(width: number, height: number);
  apply_blur(radius: number): boolean;
  readonly width: number;
  readonly height: number;
}

export function encode_png(processor: ImageProcessor): Uint8Array;

export default function init(module_or_path?: InitInput | Promise<InitInput>): Promise<InitOutput>;
Rust 类型 生成的 TS 类型 说明
i32 / u32 number 直接映射
i64 / u64 bigint BigInt 类型
f32 / f64 number 直接映射
bool boolean 直接映射
&str / String string 直接映射
Vec<u8> Uint8Array TypedArray 映射
Option<T> T | undefined 可选类型
Result<T, JsValue> T（失败时抛异常） 异常映射
自定义 struct class 带 free() 方法

提示： 生成的 .d.ts 文件中，所有导出的类都包含一个 free() 方法。TypeScript 编译器不会强制你调用它，但忘记调用会导致内存泄漏。考虑封装一个 using 模式或 Disposable 接口。

手动 .d.ts 编写
在某些场景下（如直接使用 WAT 编写的模块或第三方 WASM），需要手动编写 TypeScript 类型声明。


// wasm-module.d.ts
declare module '*.wasm' {
  const initWasm: (imports?: WebAssembly.Imports) => Promise<WebAssembly.Instance>;
  export default initWasm;
}

// specific-module.d.ts
declare module './compute.wasm' {
  export interface ComputeExports {
    memory: WebAssembly.Memory;
    add(a: number, b: number): number;
    multiply(a: number, b: number): number;
    allocate(size: number): number;
    deallocate(ptr: number, size: number): void;
  }

  const init: (imports?: WebAssembly.Imports) => Promise<{
    instance: WebAssembly.Instance & { exports: ComputeExports };
    module: WebAssembly.Module;
  }>;
  export default init;
}

// 运行时类型校验封装
function createTypedExports<T extends Record<string, Function>>(
  exports: WebAssembly.Exports,
  schema: { [K in keyof T]: { params: string[]; result: string } },
): T {
  const typed = {} as T;
  for (const [name, sig] of Object.entries(schema)) {
    const fn = exports[name];
    if (typeof fn !== 'function') {
      throw new Error(`导出 "${name}" 不是函数`);
    }
    (typed as any)[name] = fn;
  }
  return typed;
}


类型封装模式
为 WASM 模块创建类型安全的 TypeScript 封装层，是大型项目的最佳实践。


interface WasmImageLib {
  resize(srcPtr: number, srcLen: number, width: number, height: number): number;
  getResultPtr(): number;
  getResultLen(): number;
  free(ptr: number, len: number): void;
  memory: WebAssembly.Memory;
}

class ImageService {
  private wasm: WasmImageLib | null = null;

  async init(): Promise<void> {
    const { instance } = await WebAssembly.instantiateStreaming(fetch('/image.wasm'));
    this.wasm = instance.exports as unknown as WasmImageLib;
  }

  resize(imageData: Uint8Array, width: number, height: number): Uint8Array {
    if (!this.wasm) throw new Error('WASM 未初始化');

    const inputPtr = this.wasm.resize(0, imageData.length, width, height);
    const inputView = new Uint8Array(this.wasm.memory.buffer, inputPtr, imageData.length);
    inputView.set(imageData);

    this.wasm.resize(inputPtr, imageData.length, width, height);

    const resultPtr = this.wasm.getResultPtr();
    const resultLen = this.wasm.getResultLen();
    const result = new Uint8Array(this.wasm.memory.buffer, resultPtr, resultLen).slice();

    this.wasm.free(inputPtr, imageData.length);
    this.wasm.free(resultPtr, resultLen);

    return result;
  }
}

提示： 封装层应该隐藏所有指针操作和内存管理细节。应用代码只需要关心 Uint8Array、string 等 TypeScript 原生类型，不应该接触 number 类型的指针。






小结
    

  • wasm-bindgen 自动生成 .d.ts 文件，将 Rust 类型精确映射为 TypeScript 类型。
    • 

  • Interface Types 提案（已演进为 Component Model）旨在让引擎直接理解高级类型，消除胶水代码。
    • 

  • 第三方或 C/C++ 编译的 WASM 需要手动编写 .d.ts，配合运行时校验确保类型安全。
    • 

  • 生产项目应创建封装层，隐藏指针操作和内存管理，向应用暴露纯 TypeScript 类型的 API。
    • 

  • 所有导出的 WASM 类都需要显式调用 free() 释放，封装层应自动管理这一生命周期。
    •
