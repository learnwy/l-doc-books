Web Workers 与 WASM

SharedArrayBuffer 与 WASM

SharedArrayBuffer 允许多个 Worker 共享同一块内存，与 WASM 线性内存结合可实现真正的多线程并行计算。

const sharedMemory = new WebAssembly.Memory({
  initial: 256,
  maximum: 1024,
  shared: true,
});

const worker = new Worker('worker.js');
worker.postMessage({ memory: sharedMemory });

const view = new Int32Array(sharedMemory.buffer);
Atomics.store(view, 0, 42);
Atomics.notify(view, 0, 1);

Atomics 原子操作
Atomics 提供了一组线程安全的原子操作，是多线程 WASM 程序同步的基础。


const buffer = new SharedArrayBuffer(1024);
const view = new Int32Array(buffer);

Atomics.store(view, 0, 0);

const value = Atomics.load(view, 0);
const old = Atomics.compareExchange(view, 0, 0, 1);
Atomics.add(view, 1, 10);
const prev = Atomics.exchange(view, 2, 42);

wasm-bindgen-rayon
wasm-bindgen-rayon 将 Rust 的 Rayon 并行计算库移植到了 WASM 环境，使用 Web Workers 作为线程后端。


use rayon::prelude::*;
use wasm_bindgen::prelude::*;

pub use wasm_bindgen_rayon::init_thread_pool;

#[wasm_bindgen]
pub fn parallel_sum(data: &[f64]) -> f64 {
    data.par_iter().sum()
}

#[wasm_bindgen]
pub fn parallel_mandelbrot(width: u32, height: u32, max_iter: u32) -> Vec<u32> {
    (0..width * height)
        .into_par_iter()
        .map(|i| {
            let x0 = -2.0 + (i % width) as f64 / width as f64 * 3.0;
            let y0 = -1.5 + (i / width) as f64 / height as f64 * 3.0;
            let (mut x, mut y, mut iter) = (0.0f64, 0.0f64, 0u32);
            while x * x + y * y <= 4.0 && iter < max_iter {
                let t = x * x - y * y + x0;
                y = 2.0 * x * y + y0;
                x = t;
                iter += 1;
            }
            iter
        })
        .collect()
}
import init, { initThreadPool, parallel_mandelbrot } from './pkg/my_wasm.js';

await init();
await initThreadPool(navigator.hardwareConcurrency);

const pixels = parallel_mandelbrot(800, 600, 1000);

Worker Pool 模式
对于不使用 Rayon 的场景，可以手动实现 Worker Pool 来管理 WASM 多线程。


class WasmWorkerPool {
  private workers: Worker[] = [];
  private idle: Set<number> = new Set();
  private queue: Array<{ task: any; resolve: Function; reject: Function }> = [];

  constructor(
    private size: number,
    private workerUrl: string,
  ) {}

  async init(): Promise<void> {
    const promises = Array.from(
      { length: this.size },
      (_, i) =>
        new Promise<void>((resolve) => {
          const w = new Worker(this.workerUrl);
          w.onmessage = (e) => {
            if (e.data.type === 'ready') {
              this.idle.add(i);
              resolve();
            } else {
              this.idle.add(i);
              this.dispatch();
            }
          };
          this.workers[i] = w;
        }),
    );
    await Promise.all(promises);
  }

  submit<T>(task: any): Promise<T> {
    return new Promise((resolve, reject) => {
      this.queue.push({ task, resolve, reject });
      this.dispatch();
    });
  }

  private dispatch(): void {
    while (this.queue.length > 0 && this.idle.size > 0) {
      const idx = this.idle.values().next().value!;
      this.idle.delete(idx);
      const job = this.queue.shift()!;
      this.workers[idx].postMessage({ type: 'task', data: job.task });
    }
  }

  terminate(): void {
    this.workers.forEach((w) => w.terminate());
  }
}

主线程外计算
将耗时计算移到 Worker 中执行是保持 UI 响应性的关键策略。


// main.ts
const worker = new Worker(new URL('./compute-worker.ts', import.meta.url), {
  type: 'module',
});

function computeAsync(data: Float64Array): Promise<Float64Array> {
  return new Promise((resolve, reject) => {
    const ch = new MessageChannel();
    ch.port1.onmessage = (e) => (e.data.error ? reject(new Error(e.data.error)) : resolve(e.data.result));
    worker.postMessage({ data, port: ch.port2 }, [ch.port2, data.buffer]);
  });
}

// compute-worker.ts
import init, { heavy_compute } from './pkg/my_wasm.js';
let ready = false;
self.onmessage = async (e) => {
  if (!ready) {
    await init();
    ready = true;
  }
  const { data, port } = e.data;
  try {
    const result = heavy_compute(data);
    port.postMessage({ result }, [result.buffer]);
  } catch (error: any) {
    port.postMessage({ error: error.message });
  }
};

小结
    

  • SharedArrayBuffer 允许 WASM 线性内存在多个 Worker 间共享，需要配置 COOP/COEP 安全头。
    • 

  • Atomics 提供原子读写、wait/notify 等同步原语，是多线程 WASM 的同步基础。
    • 

  • wasm-bindgen-rayon 将 Rust 的 Rayon 并行库移植到 WASM，通过 par_iter() 实现数据并行。
    • 

  • 手动 Worker Pool 适用于非 Rust 来源的 WASM 模块，提供更灵活的控制。
    • 

  • 耗时计算应移到 Worker 执行，使用 Transferable 对象实现零拷贝数据传输，保持 UI 60fps。
