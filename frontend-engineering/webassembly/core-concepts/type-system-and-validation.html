类型系统与验证

值类型

WebAssembly 定义了一组严格的值类型，所有操作数、局部变量和函数参数都必须属于这些类型之一。

类型 大小 描述 用途
i32 32 位 32 位整数 通用整数运算、指针
i64 64 位 64 位整数 大整数运算、时间戳
f32 32 位 IEEE 754 单精度浮点 图形计算、近似值
f64 64 位 IEEE 754 双精度浮点 科学计算、精确浮点
v128 128 位 SIMD 向量类型 并行数据处理 
(module
  (func $type_demo
    (local $int32 i32)
    (local $int64 i64)
    (local $float32 f32)
    (local $float64 f64)

    (local.set $int32 (i32.const 42))
    (local.set $int64 (i64.const 9999999999))
    (local.set $float32 (f32.const 3.14))
    (local.set $float64 (f64.const 2.718281828))
  )
)


提示： WASM 没有原生的布尔类型和字符串类型。布尔值用 i32（0/非0）表示，字符串通过线性内存中的字节序列加长度/指针来传递。这是 JS↔WASM 边界需要胶水代码的根本原因。






引用类型
WASM 2.0 引入了引用类型（Reference Types），使模块能够持有和传递不透明的宿主对象引用。


(module
  (table $t 10 externref)

  (func $store_ref (param $idx i32) (param $ref externref)
    local.get $idx
    local.get $ref
    table.set $t
  )

  (func $load_ref (param $idx i32) (result externref)
    local.get $idx
    table.get $t
  )

  (export "storeRef" (func $store_ref))
  (export "loadRef" (func $load_ref))
)

const table = new WebAssembly.Table({ initial: 10, element: 'externref' });
const instance = await WebAssembly.instantiate(module, {});

instance.exports.storeRef(0, document.createElement('div'));
const ref = instance.exports.loadRef(0);


提示： externref 是实现 WASM 直接操作 DOM 的基础。在引入 externref 之前，WASM 只能通过整数句柄间接引用宿主对象，需要在 JS 侧维护一个映射表。






块类型与结构化控制流
WASM 的控制流指令（block、loop、if）都拥有类型签名，称为块类型（Block Type）。


(module
  (func $block_types (param $x i32) (result i32)
    ;; block 可以产生结果值
    (block $outer (result i32)
      (block $inner (result i32)
        (local.get $x)
        (i32.const 10)
        (i32.gt_s)
        (if (result i32)
          (then (i32.const 1))
          (else (i32.const 0))
        )
      )
    )
  )
)

验证算法
WASM 在实例化之前执行完整的类型验证，确保模块的每条指令都类型正确。这是 WASM 安全保证的核心支柱。


验证器对每个函数体执行抽象解释——维护一个类型栈，逐条指令推导栈上类型变化：


fn validate_i32_add(type_stack: &mut Vec<ValType>) -> Result<()> {
    let b = type_stack.pop().ok_or(Error::StackUnderflow)?;
    let a = type_stack.pop().ok_or(Error::StackUnderflow)?;
    if a != ValType::I32 || b != ValType::I32 {
        return Err(Error::TypeMismatch);
    }
    type_stack.push(ValType::I32);
    Ok(())
}

提示： 验证算法是单遍的，时间复杂度与模块大小成线性关系。这意味着即使是数 MB 的 WASM 模块也能在毫秒级完成验证——这对 Web 场景至关重要。






类型安全执行
通过验证后的 WASM 模块在执行时享有以下类型安全保证：

#[wasm_bindgen]
pub fn safe_divide(a: f64, b: f64) -> Result<f64, JsValue> {
    if b == 0.0 {
        Err(JsValue::from_str("Division by zero"))
    } else {
        Ok(a / b)
    }
}


小结
    

  • WASM 定义了 5 种数值/向量类型（i32/i64/f32/f64/v128）和 2 种引用类型（funcref/externref）。
    • 

  • 块类型为 block/loop/if 提供类型签名，确保结构化控制流中每条路径的类型一致性。
    • 

  • 验证算法通过单遍抽象解释在实例化前完成所有类型检查，时间复杂度为 O(n)。
    • 

  • 验证通过后的模块享有内存安全、类型安全、控制流完整性和确定性执行等强保证。
    • 

  • 这套"先验证后执行"的模型是 WASM 能够在不信任环境中安全运行的根本保障。
