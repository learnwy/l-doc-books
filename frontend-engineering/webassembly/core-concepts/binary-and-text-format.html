二进制与文本格式

.wasm 二进制格式

WASM 二进制格式是一种紧凑的字节码编码，以 4 字节魔数和版本号开头，后跟有序的段序列。

0000: 00 61 73 6d  ;; 魔数 "\0asm"
0004: 01 00 00 00  ;; 版本 1
0008: 01 ...       ;; Type 段开始
偏移 内容 长度 说明
0x00 魔数 4 字节 \0asm (0x0061736d)
0x04 版本号 4 字节 当前为 1
0x08+ 段序列 可变 按段 ID 有序排列

每个段的编码结构：

WASM 使用 LEB128（Little-Endian Base 128）编码变长整数，实现了体积和解码速度的平衡。


fn decode_leb128(bytes: &[u8]) -> (u32, usize) {
    let mut result: u32 = 0;
    let mut shift: u32 = 0;
    let mut consumed = 0;
    for &byte in bytes {
        consumed += 1;
        result |= ((byte & 0x7f) as u32) << shift;
        if byte & 0x80 == 0 {
            break;
        }
        shift += 7;
    }
    (result, consumed)
}


提示： WASM 二进制格式的设计目标是"可流式编译"——引擎可以在下载的同时就开始编译，无需等待整个文件下载完成。这就是 instantiateStreaming 比 instantiate 更快的原因。

WAT 文本格式
WAT（WebAssembly Text Format）是 WASM 的人类可读表示，使用 S 表达式语法。


(module
  ;; 类型声明
  (type $sig_i32_to_i32 (func (param i32) (result i32)))

  ;; 导入
  (import "env" "log" (func $log (param i32)))

  ;; 内存声明
  (memory (export "memory") 1)

  ;; 全局变量
  (global $counter (mut i32) (i32.const 0))

  ;; 函数定义
  (func $increment (type $sig_i32_to_i32)
    (local $temp i32)
    global.get $counter
    local.get 0
    i32.add
    local.tee $temp
    global.set $counter
    local.get $temp
  )

  ;; 导出
  (export "increment" (func $increment))

  ;; 数据段
  (data (i32.const 0) "Hello, WASM!")
)

提示： WAT 支持两种书写风格——扁平（线性）和嵌套（S 表达式）。嵌套风格可读性更强，但扁平风格更接近实际的字节码顺序。工具生成的 WAT 通常使用扁平风格。






wasm2wat 与 wat2wasm 工具
WABT（WebAssembly Binary Toolkit）提供了二进制与文本格式之间的转换工具。


# 安装 WABT
brew install wabt          # macOS
apt install wabt           # Ubuntu

# 二进制 → 文本
wasm2wat input.wasm -o output.wat

# 文本 → 二进制
wat2wasm input.wat -o output.wasm

# 验证模块
wasm-validate input.wasm

# 查看模块信息
wasm-objdump -x input.wasm

# 反汇编为线性格式
wasm2wat --no-debug-names input.wasm

// Cargo.toml 中控制调试信息
// [profile.release]
// debug = true        // 保留 DWARF 信息用于调试
// strip = "none"      // 不剥离符号

// [profile.release.package."*"]
// debug = false       // 依赖库不保留调试信息
// strip = "symbols"   // 剥离符号以减小体积


提示： 生产环境建议使用 wasm-opt -O3 --strip-debug 处理 WASM 文件。调试信息可能占到最终文件体积的 50% 以上，剥离后不影响运行时功能。






小结
    

  • WASM 二进制格式以 \0asm 魔数开头，使用 LEB128 编码实现紧凑的变长整数表示。
    • 

  • 模块由最多 13 种段按 ID 有序排列，声明与定义分离（Function 段声明签名，Code 段包含函数体）。
    • 

  • WAT 文本格式使用 S 表达式语法，是 WASM 的人类可读表示，支持嵌套和扁平两种书写风格。
    • 

  • WABT 工具集提供 wat2wasm/wasm2wat 双向转换和 wasm-validate/wasm-objdump 分析工具。
    • 

  • 自定义段可携带 name 映射和 DWARF 调试信息，生产环境应使用 wasm-strip 移除以减小体积。
    •
