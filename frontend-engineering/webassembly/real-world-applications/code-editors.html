代码编辑器

Tree-sitter WASM

Tree-sitter 是一个增量解析器生成器框架，编译到 WASM 后可以在浏览器中提供实时语法高亮和代码分析。

import Parser from 'web-tree-sitter';

async function initTreeSitter() {
  await Parser.init();
  const parser = new Parser();

  const JavaScript = await Parser.Language.load('/tree-sitter-javascript.wasm');
  parser.setLanguage(JavaScript);

  const code = `
    function fibonacci(n) {
      if (n <= 1) return n;
      return fibonacci(n - 1) + fibonacci(n - 2);
    }
  `;

  const tree = parser.parse(code);
  const rootNode = tree.rootNode;

  console.log(rootNode.toString());
  return tree;
}

function highlight(tree: Parser.Tree, code: string): HighlightRange[] {
  const ranges: HighlightRange[] = [];

  function visit(node: Parser.SyntaxNode) {
    const type = node.type;
    let color: string | null = null;

    if (type === 'function_declaration') color = '#61afef';
    else if (type === 'string') color = '#98c379';
    else if (type === 'number') color = '#d19a66';
    else if (type === 'comment') color = '#5c6370';
    else if (type === 'keyword' || type === 'return_statement') color = '#c678dd';

    if (color && node.childCount === 0) {
      ranges.push({
        start: node.startIndex,
        end: node.endIndex,
        color,
      });
    }

    for (let i = 0; i < node.childCount; i++) {
      visit(node.child(i)!);
    }
  }

  visit(tree.rootNode);
  return ranges;
}

interface HighlightRange {
  start: number;
  end: number;
  color: string;
}


提示： Tree-sitter 的增量解析是其核心优势。用户每次击键只需重新解析改变的部分，即使对于 10 万行的文件也能在 1ms 内完成。这是 GitHub 和 Zed 编辑器选择 Tree-sitter 的主要原因。

class WasmLanguageServer {
  private worker: Worker;
  private requestId = 0;
  private pending = new Map<number, { resolve: Function; reject: Function }>();

  constructor(workerUrl: string) {
    this.worker = new Worker(workerUrl);
    this.worker.onmessage = (e) => {
      const { id, result, error } = e.data;
      const h = this.pending.get(id);
      if (h) {
        this.pending.delete(id);
        error ? h.reject(error) : h.resolve(result);
      }
    };
  }

  async request(method: string, params: any): Promise<any> {
    const id = this.requestId++;
    return new Promise((resolve, reject) => {
      this.pending.set(id, { resolve, reject });
      this.worker.postMessage({ id, method, params });
    });
  }

  completion(uri: string, line: number, character: number) {
    return this.request('textDocument/completion', {
      textDocument: { uri },
      position: { line, character },
    });
  }
}


提示： vscode.dev 的架构是将轻量级语言服务运行在浏览器 WASM 中，重量级服务（如完整的 Rust Analyzer）运行在远程服务器。这种混合架构平衡了离线可用性和功能完整性。






Monaco 编辑器 WASM 插件
Monaco 是 VS Code 的核心编辑器组件，可以通过 WASM 模块扩展其语言支持能力。


import * as monaco from 'monaco-editor';
import Parser from 'web-tree-sitter';

class WasmLanguagePlugin {
  private parser: Parser | null = null;
  private language: Parser.Language | null = null;

  async register(languageId: string, wasmUrl: string) {
    await Parser.init();
    this.parser = new Parser();
    this.language = await Parser.Language.load(wasmUrl);
    this.parser.setLanguage(this.language);

    monaco.languages.registerCompletionItemProvider(languageId, {
      provideCompletionItems: (model, position) => this.provideCompletions(model, position),
    });

    monaco.languages.registerHoverProvider(languageId, {
      provideHover: (model, position) => this.provideHover(model, position),
    });

    monaco.languages.registerDocumentSymbolProvider(languageId, {
      provideDocumentSymbols: (model) => this.provideSymbols(model),
    });
  }

  private provideCompletions(
    model: monaco.editor.ITextModel,
    position: monaco.Position,
  ): monaco.languages.CompletionList {
    const code = model.getValue();
    const tree = this.parser!.parse(code);
    const items: monaco.languages.CompletionItem[] = [];

    const functions = this.findNodes(tree.rootNode, 'function_declaration');
    for (const fn of functions) {
      const name = fn.childForFieldName('name');
      if (name) {
        items.push({
          label: name.text,
          kind: monaco.languages.CompletionItemKind.Function,
          insertText: name.text,
          range: new monaco.Range(position.lineNumber, position.column, position.lineNumber, position.column),
        });
      }
    }

    return { suggestions: items };
  }

  private provideHover(model: monaco.editor.ITextModel, position: monaco.Position): monaco.languages.Hover | null {
    const code = model.getValue();
    const tree = this.parser!.parse(code);
    const offset = model.getOffsetAt(position);
    const node = tree.rootNode.descendantForIndex(offset);

    if (node) {
      return {
        contents: [{ value: `**${node.type}**\n\`${node.text}\`` }],
      };
    }
    return null;
  }

  private provideSymbols(model: monaco.editor.ITextModel): monaco.languages.DocumentSymbol[] {
    const code = model.getValue();
    const tree = this.parser!.parse(code);
    return this.findNodes(tree.rootNode, 'function_declaration').map((node) => ({
      name: node.childForFieldName('name')?.text ?? 'anonymous',
      kind: monaco.languages.SymbolKind.Function,
      range: this.nodeRange(node),
      selectionRange: this.nodeRange(node.childForFieldName('name') ?? node),
      detail: '',
      tags: [],
      children: [],
    }));
  }

  private findNodes(node: Parser.SyntaxNode, type: string): Parser.SyntaxNode[] {
    const r: Parser.SyntaxNode[] = [];
    if (node.type === type) r.push(node);
    for (let i = 0; i < node.childCount; i++) r.push(...this.findNodes(node.child(i)!, type));
    return r;
  }

  private nodeRange(node: Parser.SyntaxNode): monaco.IRange {
    return new monaco.Range(
      node.startPosition.row + 1,
      node.startPosition.column + 1,
      node.endPosition.row + 1,
      node.endPosition.column + 1,
    );
  }
}

小结
    

  • Tree-sitter WASM 提供 70+ 语言的增量语法解析，每次击键的解析时间在亚毫秒级。
    • 

  • 语言服务器可编译为 WASM 运行在 Web Worker 中，通过 LSP 协议与编辑器通信。
    • 

  • vscode.dev 采用混合架构——轻量级服务在浏览器 WASM 中运行，重量级服务部署在远程。
    • 

  • Monaco 编辑器通过 Tree-sitter WASM 插件实现补全、悬浮提示、符号大纲等 IDE 功能。
    • 

  • 增量解析是关键——即使 10 万行文件，每次击键的重新解析时间也能控制在 1ms 以内。
