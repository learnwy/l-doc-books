wasm-bindgen 绑定生成器

核心机制

wasm-bindgen 是 Rust WASM 生态的基石，它在 Rust 和 JavaScript 之间生成类型安全的胶水代码，让两个世界的交互变得透明。

use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub fn greet(name: &str) -> String {
    format!("你好, {}！欢迎来到 WASM 世界", name)
}
import init, { greet } from './pkg/my_wasm.js';

await init();
const message = greet('开发者');
console.log(message);

#[wasm_bindgen] 属性详解
#[wasm_bindgen] 支持多种属性配置，控制导出行为和跨边界交互方式。


use wasm_bindgen::prelude::*;

#[wasm_bindgen(js_name = "calculateSum")]
pub fn calculate_sum(values: &[f64]) -> f64 {
    values.iter().sum()
}

#[wasm_bindgen(js_namespace = Math)]
extern "C" {
    fn random() -> f64;
}

#[wasm_bindgen(module = "/src/helper.js")]
extern "C" {
    fn customLog(message: &str);
}

#[wasm_bindgen(start)]
fn main() {
    console_error_panic_hook::set_once();
}

JS↔Rust 边界与 JsValue
JsValue 是 wasm-bindgen 中表示任意 JavaScript 值的类型，是跨边界通信的核心枢纽。


use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub fn process_value(val: JsValue) -> Result<JsValue, JsValue> {
    if val.is_string() {
        let s = val.as_string().unwrap();
        Ok(JsValue::from_str(&s.to_uppercase()))
    } else if val.is_falsy() {
        Err(JsValue::from_str("收到假值"))
    } else {
        Ok(val)
    }
}

提示： 每次跨边界传递字符串都会触发一次内存拷贝（UTF-8 ↔ UTF-16 转换）。如果你的函数在热路径上频繁交换字符串，考虑改用共享线性内存中的字节数组，避免拷贝开销。






自定义类型跨边界
wasm-bindgen 支持将 Rust 结构体和枚举导出为 JS 类，实现面向对象的跨语言交互。


use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub struct Particle {
    x: f64,
    y: f64,
    vx: f64,
    vy: f64,
}

#[wasm_bindgen]
impl Particle {
    #[wasm_bindgen(constructor)]
    pub fn new(x: f64, y: f64) -> Particle {
        Particle { x, y, vx: 0.0, vy: 0.0 }
    }

    pub fn apply_force(&mut self, fx: f64, fy: f64) {
        self.vx += fx;
        self.vy += fy;
    }

    pub fn step(&mut self, dt: f64) {
        self.x += self.vx * dt;
        self.y += self.vy * dt;
    }

    #[wasm_bindgen(getter)]
    pub fn x(&self) -> f64 {
        self.x
    }

    #[wasm_bindgen(getter)]
    pub fn y(&self) -> f64 {
        self.y
    }
}

#[wasm_bindgen]
pub enum Direction {
    Up,
    Down,
    Left,
    Right,
}
import { Particle, Direction } from './pkg/my_wasm.js';

const p = new Particle(100.0, 200.0);
p.apply_force(0.5, -0.3);
p.step(1.0 / 60.0);
console.log(`位置: (${p.x}, ${p.y})`);
p.free();

提示： 导出的 Rust 结构体在 JS 侧使用完毕后需要调用 .free() 释放。如果忘记调用，内存不会自动回收（WASM 没有 GC）。考虑使用 FinalizationRegistry 做安全网，但不要依赖它。






导入 JS API
wasm-bindgen 不仅能导出 Rust 函数，也能导入 JavaScript API 供 Rust 代码使用。


use wasm_bindgen::prelude::*;

#[wasm_bindgen]
extern "C" {
    #[wasm_bindgen(js_namespace = console)]
    fn log(s: &str);

    #[wasm_bindgen(js_namespace = console, js_name = log)]
    fn log_u32(a: u32);

    type HTMLDocument;
    #[wasm_bindgen(method, getter)]
    fn title(this: &HTMLDocument) -> String;

    #[wasm_bindgen(js_namespace = JSON)]
    fn stringify(val: &JsValue) -> JsValue;

    #[wasm_bindgen(catch, js_namespace = JSON)]
    fn parse(text: &str) -> Result<JsValue, JsValue>;
}

#[wasm_bindgen]
pub fn demo() {
    log("从 Rust 调用 console.log");
    log_u32(42);

    match JSON::parse("{\"key\": \"value\"}") {
        Ok(val) => log(&format!("解析成功")),
        Err(e) => log(&format!("解析失败")),
    }
}


小结
    

  • wasm-bindgen 通过过程宏 + CLI 工具的两阶段流程，在 Rust 和 JS 之间生成类型安全的胶水代码。
    • 

  • #[wasm_bindgen] 属性支持 js_name、constructor、getter/setter、catch 等丰富的配置项。
    • 

  • JsValue 是跨边界通信的核心类型，所有不能直接映射的 JS 值都通过它传递。
    • 

  • Rust 结构体可导出为 JS 类，支持方法和属性，但必须手动调用 .free() 释放内存。
    • 

  • 通过 extern "C" 块可以导入任意 JS API，配合 catch 属性实现异常安全的调用。
    •
