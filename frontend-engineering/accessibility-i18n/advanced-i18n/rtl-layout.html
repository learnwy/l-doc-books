RTL 布局适配

核心概念

RTL（Right-to-Left）布局适配是支持阿拉伯语、希伯来语、波斯语等从右向左书写语言的核心工程。RTL 不是简单地将页面水平翻转——某些元素需要镜像（导航方向、进度条方向），而某些元素不应镜像（时钟方向、品牌 logo、数学公式）。CSS 逻辑属性（Logical Properties）是现代 RTL 适配的基础。

CSS 逻辑属性迁移
将物理属性迁移到逻辑属性是 RTL 适配的第一步。逻辑属性根据文本方向自动调整，无需编写 RTL 特定的 CSS。


const logicalPropertiesCSS = `
/* 迁移前：物理属性 */
.card-old {
  margin-left: 16px;
  margin-right: 8px;
  padding-left: 24px;
  padding-right: 24px;
  border-left: 3px solid blue;
  text-align: left;
}

/* 迁移后：逻辑属性 — 自动适配 RTL */
.card {
  margin-inline-start: 16px;
  margin-inline-end: 8px;
  padding-inline: 24px;
  border-inline-start: 3px solid blue;
  text-align: start;
}

/* Flexbox 自动适配 */
.nav {
  display: flex;
  flex-direction: row;  /* 在 RTL 中自动反转为从右到左 */
  gap: 16px;
}

/* Grid 自动适配 */
.layout {
  display: grid;
  grid-template-columns: 250px 1fr;  /* RTL 中 sidebar 在右侧 */
}

/* 简写属性也有逻辑版本 */
.element {
  /* 物理：margin: top right bottom left */
  /* 逻辑：分别设置 block 和 inline */
  margin-block: 16px 8px;     /* 上 16px 下 8px */
  margin-inline: 24px 12px;   /* start 24px end 12px */
  
  padding-block: 12px;
  padding-inline: 20px;
  
  border-block: 1px solid;
  border-inline: 2px solid;
  
  /* 逻辑尺寸 */
  inline-size: 300px;   /* 替代 width */
  block-size: 200px;    /* 替代 height */
  max-inline-size: 100%; /* 替代 max-width */
}
`;

图标与方向性元素
图标的 RTL 处理需要区分方向性图标（指示方向的箭头）和非方向性图标（对称或通用图标）。


const iconRTL = `
/* 方向性图标：需要在 RTL 中翻转 */
.icon-arrow-right,
.icon-chevron-right,
.icon-forward,
.icon-reply,
.icon-undo,
.icon-redo {
  [dir='rtl'] & {
    transform: scaleX(-1);
  }
}

/* 非方向性图标：不需要翻转 */
/* ✓ 搜索图标（对称）*/
/* ✓ 设置齿轮（对称）*/
/* ✓ 时钟（全球通用方向）*/
/* ✓ 播放按钮（全球通用）*/
/* ✓ 品牌 logo */
`;

RTL 布局组件
React 组件中实现 RTL 感知的布局需要结合 CSS 逻辑属性和 direction 上下文。


import { createContext, useContext } from 'react'

type Direction = 'ltr' | 'rtl'

const DirectionContext = createContext<Direction>('ltr')

const useDirection = () => useContext(DirectionContext)

const DirectionProvider: FC<{ locale: string; children: ReactNode }> = ({
  locale,
  children,
}) => {
  const dir: Direction = ['ar', 'he', 'fa', 'ur'].some(
    rtl => locale.startsWith(rtl)
  ) ? 'rtl' : 'ltr'

  return (
    <DirectionContext.Provider value={dir}>
      <div dir={dir} style={{ direction: dir }}>
        {children}
      </div>
    </DirectionContext.Provider>
  )
}

const Sidebar: FC<{ children: ReactNode }> = ({ children }) => {
  const dir = useDirection()

  return (
    <aside
      style={{
        insetInlineStart: 0,
        inlineSize: '250px',
        borderInlineEnd: '1px solid var(--color-border)',
      }}
    >
      {children}
    </aside>
  )
}

const Breadcrumb: FC<{ items: string[] }> = ({ items }) => {
  const dir = useDirection()
  const separator = dir === 'rtl' ? '\\' : '/'

  return (
    <nav aria-label="breadcrumb">
      {items.map((item, i) => (
        <span key={i}>
          {i > 0 && <span aria-hidden="true"> {separator} </span>}
          {item}
        </span>
      ))}
    </nav>
  )
}
RTL 测试策略
RTL 布局需要专门的测试策略，包括自动化镜像验证和视觉回归测试。


import { test, expect } from '@playwright/test';

test('RTL 布局镜像正确', async ({ page }) => {
  await page.goto('/?lang=ar-SA');

  const htmlDir = await page.getAttribute('html', 'dir');
  expect(htmlDir).toBe('rtl');

  const sidebar = page.locator('aside');
  const sidebarBox = await sidebar.boundingBox();
  const viewportWidth = page.viewportSize()?.width ?? 1280;
  expect(sidebarBox?.x).toBeGreaterThan(viewportWidth / 2);

  const navItems = await page.locator('nav a').all();
  if (navItems.length >= 2) {
    const firstBox = await navItems[0].boundingBox();
    const secondBox = await navItems[1].boundingBox();
    expect(firstBox!.x).toBeGreaterThan(secondBox!.x);
  }
});

test('方向性图标正确翻转', async ({ page }) => {
  await page.goto('/?lang=ar-SA');

  const arrowIcon = page.locator('.icon-arrow-right');
  const transform = await arrowIcon.evaluate((el) => window.getComputedStyle(el).transform);
  expect(transform).toContain('-1');
});
对 RTL 布局的测试应该覆盖：Sidebar 位置、导航顺序、表单对齐、表格列顺序和方向性图标的翻转状态。


小结
    

  • CSS 逻辑属性是 RTL 适配的基础，用 inline-start/end 替代 left/right 实现自动方向适配
    • 

  • Flexbox 和 Grid 在 RTL 模式下自动反转方向，无需额外处理
    • 

  • 图标分为方向性（需翻转）和非方向性（不翻转），建议维护图标 RTL 规则表
    • 

  • RTL 组件通过 Direction Context 提供文本方向上下文，组件内使用逻辑属性
    • 

  • RTL 测试验证镜像正确性、图标翻转和布局位置，建议配合视觉回归测试
    • 

  • 某些元素不应镜像：时钟、品牌 logo、数学公式、电话号码格式
    •
