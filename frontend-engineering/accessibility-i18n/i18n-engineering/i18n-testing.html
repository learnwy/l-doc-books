i18n 测试策略

核心概念

国际化测试（i18n Testing）验证应用在不同语言和地区设置下的正确性。i18n 测试不仅仅是检查翻译是否存在，更要验证格式化输出、布局适配、文本截断、字符编码和交互逻辑在各种 locale 下都能正常工作。完善的 i18n 测试体系包括单元测试、集成测试、视觉回归测试和伪本地化测试四个层次。

单元测试
i18n 单元测试重点验证格式化函数在不同 locale 下的输出正确性：


import { describe, it, expect } from 'vitest';

describe('NumberFormat', () => {
  const testCases = [
    { locale: 'en-US', value: 1234567.89, expected: '1,234,567.89' },
    { locale: 'de-DE', value: 1234567.89, expected: '1.234.567,89' },
    { locale: 'zh-CN', value: 1234567.89, expected: '1,234,567.89' },
    { locale: 'hi-IN', value: 1234567.89, expected: '12,34,567.89' },
  ];

  it.each(testCases)('formats $value correctly for $locale', ({ locale, value, expected }) => {
    const result = new Intl.NumberFormat(locale).format(value);
    expect(result).toBe(expected);
  });
});

describe('DateFormat', () => {
  const date = new Date('2024-03-15T10:30:00Z');

  it('formats date in short style for zh-CN', () => {
    const result = new Intl.DateTimeFormat('zh-CN', {
      dateStyle: 'short',
      timeZone: 'Asia/Shanghai',
    }).format(date);
    expect(result).toBe('2024/3/15');
  });

  it('formats date in short style for en-US', () => {
    const result = new Intl.DateTimeFormat('en-US', {
      dateStyle: 'short',
      timeZone: 'America/New_York',
    }).format(date);
    expect(result).toBe('3/15/24');
  });
});

describe('PluralRules', () => {
  it('handles English plurals', () => {
    const pr = new Intl.PluralRules('en');
    expect(pr.select(0)).toBe('other');
    expect(pr.select(1)).toBe('one');
    expect(pr.select(2)).toBe('other');
  });

  it('handles Arabic plurals', () => {
    const pr = new Intl.PluralRules('ar');
    expect(pr.select(0)).toBe('zero');
    expect(pr.select(1)).toBe('one');
    expect(pr.select(2)).toBe('two');
    expect(pr.select(5)).toBe('few');
  });
});
翻译覆盖率检测
翻译覆盖率检测确保所有支持的语言都有完整的翻译，是发布前的关键守门检查：


import { readFileSync, readdirSync } from 'node:fs';

interface CoverageReport {
  locale: string;
  total: number;
  translated: number;
  missing: string[];
  coverage: number;
}

const checkTranslationCoverage = (
  sourceLocale: string,
  targetLocales: string[],
  localesDir: string,
): CoverageReport[] => {
  const sourceFile = JSON.parse(readFileSync(`${localesDir}/${sourceLocale}.json`, 'utf-8'));
  const sourceKeys = Object.keys(flattenObject(sourceFile));

  return targetLocales.map((locale) => {
    const targetFile = JSON.parse(readFileSync(`${localesDir}/${locale}.json`, 'utf-8'));
    const targetKeys = new Set(Object.keys(flattenObject(targetFile)));
    const missing = sourceKeys.filter((key) => !targetKeys.has(key));

    return {
      locale,
      total: sourceKeys.length,
      translated: sourceKeys.length - missing.length,
      missing,
      coverage: ((sourceKeys.length - missing.length) / sourceKeys.length) * 100,
    };
  });
};

const flattenObject = (obj: Record<string, unknown>, prefix = ''): Record<string, string> => {
  const result: Record<string, string> = {};
  for (const [key, value] of Object.entries(obj)) {
    const fullKey = prefix ? `${prefix}.${key}` : key;
    if (typeof value === 'object' && value !== null) {
      Object.assign(result, flattenObject(value as Record<string, unknown>, fullKey));
    } else {
      result[fullKey] = String(value);
    }
  }
  return result;
};

伪本地化测试
伪本地化（Pseudolocalization）是一种在开发阶段发现 i18n 问题的高效技术。它将源文本转换为带有特殊字符的变体，模拟翻译后的特征——字符串扩展、特殊字符和文本方向：


const pseudoLocalize = (
  text: string,
  options?: {
    expansionFactor?: number;
    accented?: boolean;
    bracketed?: boolean;
  },
): string => {
  const { expansionFactor = 1.3, accented = true, bracketed = true } = options ?? {};

  const accentMap: Record<string, string> = {
    a: 'à',
    b: 'ƀ',
    c: 'ç',
    d: 'ð',
    e: 'è',
    f: 'ƒ',
    g: 'ĝ',
    h: 'ĥ',
    i: 'ì',
    j: 'ĵ',
    k: 'ĸ',
    l: 'ĺ',
    m: 'ɱ',
    n: 'ñ',
    o: 'ö',
    p: 'þ',
    q: 'ǫ',
    r: 'ŕ',
    s: 'š',
    t: 'ţ',
    u: 'ù',
    v: 'ṽ',
    w: 'ŵ',
    x: 'ẋ',
    y: 'ý',
    z: 'ž',
  };

  let result = text.replace(/[a-z]/gi, (char) => {
    const lower = char.toLowerCase();
    const replacement = accented ? (accentMap[lower] ?? char) : char;
    return char === char.toUpperCase() ? replacement.toUpperCase() : replacement;
  });

  const padding = Math.ceil(text.length * (expansionFactor - 1));
  result += '~'.repeat(padding);

  if (bracketed) {
    result = `[${result}]`;
  }

  return result;
};

console.log(pseudoLocalize('Save Changes'));
console.log(pseudoLocalize('Settings', { expansionFactor: 1.5 }));

视觉回归测试
Playwright 或 Chromatic 的视觉回归测试验证 UI 在不同语言下的布局正确性：


import { test, expect } from '@playwright/test';

const testLocales = ['en-US', 'zh-CN', 'ar-SA', 'de-DE', 'ja-JP'];

for (const locale of testLocales) {
  test(`homepage renders correctly for ${locale}`, async ({ page }) => {
    await page.goto(`/?locale=${locale}`);
    await page.waitForLoadState('networkidle');
    await expect(page).toHaveScreenshot(`homepage-${locale}.png`, {
      fullPage: true,
      threshold: 0.1,
    });
  });

  test(`navigation works in ${locale}`, async ({ page }) => {
    await page.goto(`/?locale=${locale}`);
    const nav = page.locator('nav');
    await expect(nav).toBeVisible();
    await expect(nav).toHaveScreenshot(`nav-${locale}.png`);
  });
}

test('RTL layout for Arabic', async ({ page }) => {
  await page.goto('/?locale=ar-SA');
  const body = page.locator('body');
  await expect(body).toHaveAttribute('dir', 'rtl');
  const nav = page.locator('nav');
  const navBox = await nav.boundingBox();
  expect(navBox?.x).toBeGreaterThan(0);
});
小结
    

  • i18n 测试体系包括单元测试、集成测试、视觉回归和伪本地化四个层次
    • 

  • 格式化函数的单元测试需要覆盖多个 locale 的边界情况
    • 

  • 翻译覆盖率检测是发布前的关键守门检查，低于 80% 应阻断发布
    • 

  • 伪本地化在开发阶段即可发现文本截断、硬编码和编码问题
    • 

  • Playwright 视觉回归测试验证 RTL 布局和多语言 UI 的正确性
    • 

  • 测试应覆盖主要目标语言，特别是字符串长度差异大的语言（德语）和 RTL 语言（阿拉伯语）
