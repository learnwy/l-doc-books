语义化 HTML

核心概念

语义化 HTML 是 Web 无障碍的基础。语义化标签向浏览器和辅助技术传达内容的结构和含义，而非仅仅描述视觉外观。屏幕阅读器依赖 HTML 语义来构建页面的可访问性树（Accessibility Tree），用户通过这棵树导航和理解页面内容。

地标区域
HTML5 地标元素（Landmarks）将页面划分为功能区域，辅助技术用户可以快速跳转到这些区域。


const landmarkStructure = `
<body>
  <a href="#main" class="skip-link">跳转到主要内容</a>
  
  <header>
    <nav aria-label="主导航">
      <ul>
        <li><a href="/">首页</a></li>
        <li><a href="/docs">文档</a></li>
      </ul>
    </nav>
  </header>
  
  <div class="layout">
    <aside aria-label="侧边栏导航">
      <nav aria-label="文档目录">
        <h2>目录</h2>
        <ul>...</ul>
      </nav>
    </aside>
    
    <main id="main">
      <article>
        <h1>文章标题</h1>
        <section aria-labelledby="intro-heading">
          <h2 id="intro-heading">简介</h2>
          <p>...</p>
        </section>
      </article>
    </main>
  </div>
  
  <footer>
    <nav aria-label="页脚链接">...</nav>
    <p>版权信息</p>
  </footer>
</body>
`;
当页面有多个相同类型的地标时，必须使用 aria-label 或 aria-labelledby 区分。例如，同一页面有主导航和侧边栏导航，两个 <nav> 需要不同的标签。

标题层级
正确的标题层级是屏幕阅读器用户导航页面的主要方式。用户可以通过标题列表快速了解页面结构和跳转到感兴趣的部分。


const headingHierarchy = `
<!-- 正确：层级连续，不跳级 -->
<h1>Web 无障碍指南</h1>
  <h2>WCAG 原则</h2>
    <h3>可感知</h3>
    <h3>可操作</h3>
  <h2>实施方法</h2>
    <h3>语义化 HTML</h3>
    <h3>ARIA 属性</h3>

<!-- 错误：跳过 h2 直接到 h3 -->
<h1>标题</h1>
  <h3>子标题</h3>  <!-- 不应跳过 h2 -->

<!-- 错误：用标题标签仅为了样式效果 -->
<h4>这段文字不是标题，只是想让它小一点</h4>
`;

// 标题层级审查工具
const auditHeadings = (): HeadingIssue[] => {
  const headings = document.querySelectorAll('h1, h2, h3, h4, h5, h6');
  const issues: HeadingIssue[] = [];
  let prevLevel = 0;

  headings.forEach((h, i) => {
    const level = parseInt(h.tagName[1]);
    if (i === 0 && level !== 1) {
      issues.push({ element: h, issue: '页面应以 h1 开始' });
    }
    if (level - prevLevel > 1) {
      issues.push({ element: h, issue: `标题层级跳跃：h${prevLevel} → h${level}` });
    }
    prevLevel = level;
  });

  return issues;
};
表单语义
表单是 Web 交互的核心，也是无障碍问题的高发区域。每个表单控件都需要关联的标签，错误信息需要程序化关联到对应的输入框。


const formSemantics = `
<!-- label + for 关联 -->
<label for="username">用户名</label>
<input id="username" type="text" required aria-required="true" />

<!-- 隐式关联：label 包裹 input -->
<label>
  邮箱地址
  <input type="email" required />
</label>

<!-- 分组控件：fieldset + legend -->
<fieldset>
  <legend>配送方式</legend>
  <label>
    <input type="radio" name="shipping" value="standard" />
    标准配送（3-5天）
  </label>
  <label>
    <input type="radio" name="shipping" value="express" />
    加急配送（1天）
  </label>
</fieldset>

<!-- 复杂表单：aria-describedby 提供说明 -->
<div>
  <label for="card-number">信用卡号</label>
  <input 
    id="card-number" 
    type="text"
    inputmode="numeric"
    pattern="[0-9]{16}"
    aria-describedby="card-hint card-error"
  />
  <p id="card-hint">请输入16位信用卡号码</p>
  <p id="card-error" role="alert" hidden>卡号格式不正确</p>
</div>
`;

表格与列表语义
数据表格和列表的语义标记使辅助技术能够正确导航和理解数据关系。


const tableSemantics = `
<!-- 数据表格：完整语义 -->
<table>
  <caption>2024年各季度销售数据</caption>
  <thead>
    <tr>
      <th scope="col">季度</th>
      <th scope="col">销售额</th>
      <th scope="col">增长率</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Q1</th>
      <td>500万</td>
      <td>15%</td>
    </tr>
  </tbody>
</table>

<!-- 复杂表头：使用 headers 属性 -->
<table>
  <thead>
    <tr>
      <th id="region" rowspan="2">地区</th>
      <th id="q1" colspan="2">Q1</th>
      <th id="q2" colspan="2">Q2</th>
    </tr>
    <tr>
      <th id="q1-sales" headers="q1">销售额</th>
      <th id="q1-growth" headers="q1">增长率</th>
      <th id="q2-sales" headers="q2">销售额</th>
      <th id="q2-growth" headers="q2">增长率</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th headers="region">华东</th>
      <td headers="q1 q1-sales">200万</td>
      <td headers="q1 q1-growth">12%</td>
      <td headers="q2 q2-sales">250万</td>
      <td headers="q2 q2-growth">25%</td>
    </tr>
  </tbody>
</table>

<!-- 描述列表：术语定义 -->
<dl>
  <dt>WCAG</dt>
  <dd>Web Content Accessibility Guidelines</dd>
  <dt>ARIA</dt>
  <dd>Accessible Rich Internet Applications</dd>
</dl>
`;
布局表格（仅用于排版的表格）应使用 role="presentation" 告诉辅助技术忽略表格语义。但现代 Web 开发中应始终使用 CSS 布局代替表格布局。


小结
    

  • 语义化 HTML 是无障碍的基础，辅助技术通过 HTML 语义构建可访问性树
    • 

  • 原生 HTML 元素（button、nav、main 等）自带 ARIA 角色，优先使用原生元素
    • 

  • 地标元素划分页面功能区域，多个同类地标必须用 aria-label 区分
    • 

  • 标题层级必须连续（不跳级），是屏幕阅读器用户导航页面的主要方式
    • 

  • 表单控件必须关联标签（label for），错误信息通过 aria-describedby 程序化关联
    • 

  • 数据表格使用 scope 和 headers 属性使辅助技术理解表头与数据的关系
    •
