键盘导航

核心概念

键盘导航是 Web 无障碍的核心能力。许多用户无法使用鼠标——包括运动障碍用户、屏幕阅读器用户以及偏好键盘操作的高级用户。所有交互功能都必须可以通过键盘完成，焦点管理必须清晰可见且逻辑合理。

焦点指示器
焦点指示器是键盘用户的"光标"，告诉用户当前操作的目标元素。浏览器提供默认的焦点样式（通常是蓝色轮廓），但许多网站错误地移除了这些样式。


const focusIndicatorCSS = `
/* 错误：移除所有焦点样式 */
*:focus { outline: none; }  /* 永远不要这样做 */

/* 正确：自定义焦点样式，保持可见性 */
:focus-visible {
  outline: 3px solid var(--color-focus);
  outline-offset: 2px;
  border-radius: 2px;
}

/* :focus-visible vs :focus */
/* :focus — 所有聚焦方式（包括鼠标点击） */
/* :focus-visible — 仅键盘聚焦时显示 */

/* 鼠标点击时隐藏焦点环，键盘操作时显示 */
button:focus:not(:focus-visible) {
  outline: none;
}

button:focus-visible {
  outline: 3px solid var(--color-focus);
  outline-offset: 2px;
}

/* 高对比度模式兼容 */
@media (forced-colors: active) {
  :focus-visible {
    outline: 3px solid Highlight;
  }
}
`;
WCAG 2.2 新增了焦点指示器的具体要求（2.4.11 Focus Appearance）：焦点指示器的面积至少为 1 CSS 像素的轮廓，且与未聚焦状态的对比度至少为 3:1。

tabindex 与焦点管理
tabindex 属性控制元素的键盘可聚焦性和 Tab 顺序。正确使用 tabindex 是焦点管理的关键。


const tabindexUsage = `
<!-- tabindex="0"：加入自然 Tab 顺序 -->
<div role="button" tabindex="0" onclick="handleClick()">自定义按钮</div>

<!-- tabindex="-1"：可程序化聚焦，但不在 Tab 顺序中 -->
<div id="notification" tabindex="-1">通知内容</div>
<script>document.getElementById('notification').focus()</script>

<!-- tabindex > 0：强制改变 Tab 顺序（强烈不推荐） -->
<!-- 会导致 Tab 顺序混乱，应使用 DOM 顺序控制 -->
`;

// 程序化焦点管理
const focusManagement = {
  afterDelete: (deletedIndex: number, listRef: HTMLElement) => {
    const items = listRef.querySelectorAll('[role="listitem"]');
    const nextIndex = Math.min(deletedIndex, items.length - 1);
    if (items[nextIndex]) {
      (items[nextIndex] as HTMLElement).focus();
    }
  },

  afterNavigation: (targetSection: string) => {
    const target = document.getElementById(targetSection);
    if (target) {
      target.setAttribute('tabindex', '-1');
      target.focus();
      target.addEventListener(
        'blur',
        () => {
          target.removeAttribute('tabindex');
        },
        { once: true },
      );
    }
  },

  returnFocus: (triggerElement: HTMLElement) => {
    triggerElement.focus();
  },
};

焦点陷阱
焦点陷阱（Focus Trap）将键盘焦点限制在特定区域内，是模态对话框的必需行为。用户在模态框内按 Tab 时，焦点应在模态框内循环，而非逃逸到背后的页面内容。


const createFocusTrap = (container: HTMLElement) => {
  const focusableSelector = [
    'a[href]',
    'button:not([disabled])',
    'input:not([disabled])',
    'select:not([disabled])',
    'textarea:not([disabled])',
    '[tabindex]:not([tabindex="-1"])',
  ].join(', ');

  const getFocusableElements = () =>
    Array.from(container.querySelectorAll<HTMLElement>(focusableSelector)).filter((el) => el.offsetParent !== null);

  const handleKeyDown = (e: KeyboardEvent) => {
    if (e.key !== 'Tab') return;

    const focusable = getFocusableElements();
    const first = focusable[0];
    const last = focusable[focusable.length - 1];

    if (e.shiftKey) {
      if (document.activeElement === first) {
        e.preventDefault();
        last.focus();
      }
    } else {
      if (document.activeElement === last) {
        e.preventDefault();
        first.focus();
      }
    }
  };

  container.addEventListener('keydown', handleKeyDown);

  return {
    activate: () => {
      const focusable = getFocusableElements();
      if (focusable.length > 0) focusable[0].focus();
    },
    deactivate: () => {
      container.removeEventListener('keydown', handleKeyDown);
    },
  };
};
漫游焦点模式
复合组件（如 Tab 面板、菜单、树视图）使用漫游焦点（Roving Tabindex）模式：组件整体只有一个 Tab 停靠点，内部使用方向键导航。


const rovingTabindex = (container: HTMLElement, itemSelector: string) => {
  const items = Array.from(container.querySelectorAll<HTMLElement>(itemSelector));
  let currentIndex = 0;

  items.forEach((item, i) => {
    item.setAttribute('tabindex', i === 0 ? '0' : '-1');
  });

  container.addEventListener('keydown', (e: KeyboardEvent) => {
    let newIndex = currentIndex;

    switch (e.key) {
      case 'ArrowDown':
      case 'ArrowRight':
        newIndex = (currentIndex + 1) % items.length;
        break;
      case 'ArrowUp':
      case 'ArrowLeft':
        newIndex = (currentIndex - 1 + items.length) % items.length;
        break;
      case 'Home':
        newIndex = 0;
        break;
      case 'End':
        newIndex = items.length - 1;
        break;
      default:
        return;
    }

    e.preventDefault();
    items[currentIndex].setAttribute('tabindex', '-1');
    items[newIndex].setAttribute('tabindex', '0');
    items[newIndex].focus();
    currentIndex = newIndex;
  });
};
漫游焦点大幅减少了 Tab 停靠点数量，避免用户在大型组件中按几十次 Tab 才能通过。


小结
    

  • 所有交互功能必须可通过键盘完成，Tab / Enter / Space / Escape / 方向键是基础按键
    • 

  • 焦点指示器不可移除，使用 :focus-visible 区分键盘和鼠标聚焦
    • 

  • tabindex="0" 加入 Tab 序，tabindex="-1" 可程序化聚焦，tabindex > 0 应避免使用
    • 

  • 模态对话框必须实现焦点陷阱，关闭后焦点必须返回触发元素
    • 

  • 复合组件使用漫游焦点模式（Roving Tabindex），整体一个 Tab 停靠点 + 方向键内部导航
    • 

  • 焦点管理需要覆盖打开/关闭/删除/导航四大场景
