Unicode 与字符编码

核心概念

Unicode 是现代 Web 国际化的字符编码基石。它为世界上几乎所有书写系统的每个字符分配了唯一的码点（Code Point），覆盖超过 15 万个字符。Web 开发中最常用的 Unicode 编码格式是 UTF-8，它是 HTML5 的默认编码，也是互联网上使用最广泛的编码方案。理解 Unicode 的基本概念——码点、编码单元、代理对和字形簇——是正确处理多语言文本的前提。

JavaScript 中的 Unicode
JavaScript 字符串内部使用 UTF-16 编码，这意味着 BMP 之外的字符（如 Emoji）会被表示为代理对（Surrogate Pair），占用两个 UTF-16 编码单元：


const unicodeBasics = (): void => {
  const text = 'Hello 你好 🌍';

  console.log(text.length);
  console.log([...text].length);

  const emoji = '🌍';
  console.log(emoji.length);
  console.log(emoji.codePointAt(0)?.toString(16));

  console.log('\uD83C\uDF0D');
  console.log(String.fromCodePoint(0x1f30d));
};

const safeSubstring = (str: string, start: number, end: number): string => {
  const chars = [...str];
  return chars.slice(start, end).join('');
};

const countGraphemes = (str: string): number => {
  const segmenter = new Intl.Segmenter('en', { granularity: 'grapheme' });
  return [...segmenter.segment(str)].length;
};

console.log(countGraphemes('café'));
console.log(countGraphemes('👨‍👩‍👧‍👦'));
console.log(countGraphemes('나는'));

Unicode 正规化
同一个字符可能有多种 Unicode 表示方式。例如 "é" 可以是单个码点 U+00E9，也可以是 "e" + 组合重音符号 U+0301。正规化确保文本比较和搜索的一致性：


const normalizationDemo = (): void => {
  const composed = '\u00E9';
  const decomposed = 'e\u0301';

  console.log(composed === decomposed);
  console.log(composed.normalize('NFC') === decomposed.normalize('NFC'));
  console.log(composed.normalize('NFD') === decomposed.normalize('NFD'));

  console.log(composed.length);
  console.log(decomposed.length);
  console.log(composed.normalize('NFC').length);
};

const normalizeForComparison = (a: string, b: string): boolean => {
  return a.normalize('NFC') === b.normalize('NFC');
};

const normalizeForSearch = (text: string): string => {
  return text
    .normalize('NFKD')
    .replace(/[\u0300-\u036f]/g, '')
    .toLowerCase();
};

console.log(normalizeForSearch('Ångström'));
console.log(normalizeForSearch('café'));
console.log(normalizeForSearch('ﬁnance'));

Intl.Segmenter 文本分段
不同语言的文本分段规则差异很大。中日韩文没有空格分词，泰语和缅甸语的词边界也与英语完全不同。Intl.Segmenter 提供了基于 Unicode 标准的文本分段能力：


const segmentText = (text: string, locale: string, granularity: 'grapheme' | 'word' | 'sentence'): string[] => {
  const segmenter = new Intl.Segmenter(locale, { granularity });
  return [...segmenter.segment(text)].map((s) => s.segment);
};

console.log(segmentText('Hello World', 'en', 'word'));
console.log(segmentText('你好世界', 'zh', 'word'));
console.log(segmentText('こんにちは世界', 'ja', 'word'));

const truncateByGrapheme = (text: string, maxGraphemes: number, ellipsis = '…'): string => {
  const segmenter = new Intl.Segmenter('en', { granularity: 'grapheme' });
  const segments = [...segmenter.segment(text)];

  if (segments.length <= maxGraphemes) {
    return text;
  }

  return (
    segments
      .slice(0, maxGraphemes)
      .map((s) => s.segment)
      .join('') + ellipsis
  );
};

console.log(truncateByGrapheme('Hello 🌍 World', 8));
console.log(truncateByGrapheme('👨‍👩‍👧‍👦 Family', 3));

编码安全
不正确的编码处理会导致安全漏洞和数据丢失：


const encodingSafety = {
  metaCharset: '<meta charset="utf-8">',
  httpHeader: 'Content-Type: text/html; charset=utf-8',
  mysqlCharset: 'CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci',
  postgresLocale: "LC_COLLATE='en_US.UTF-8'",
};

const preventHomoglyphAttack = (input: string): string => {
  const confusables: Record<string, string> = {
    '\u0410': 'A',
    '\u0412': 'B',
    '\u0421': 'C',
    '\u0415': 'E',
    '\u041D': 'H',
    '\u041E': 'O',
    '\u0420': 'P',
    '\u0422': 'T',
  };

  return [...input].map((char) => confusables[char] ?? char).join('');
};

小结
    

  • Unicode 为所有书写系统提供统一编码，UTF-8 是 Web 的标准编码格式
    • 

  • JavaScript 使用 UTF-16 内部编码，BMP 外字符（Emoji）是代理对
    • 

  • [...str] 和 Intl.Segmenter 正确处理多码点字符和字形簇
    • 

  • NFC 是存储和比较的推荐正规化形式，NFKD 适用于全文搜索
    • 

  • Intl.Segmenter 提供了跨语言的文本分段能力，处理中日韩分词
    • 

  • 编码安全需要防范同形字攻击、零宽字符注入和 Bidi 控制符欺骗
