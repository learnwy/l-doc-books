文本方向与双向文本

核心概念

文本方向（Text Direction）是 Web 国际化中的关键技术问题。Unicode 双向算法（Bidi Algorithm）定义了混合方向文本的排列规则——当 RTL 文本（如阿拉伯语）中嵌入 LTR 文本（如英文、数字）时，浏览器需要自动确定每个字符的显示方向。理解双向文本的工作原理是构建真正全球化 Web 应用的基础。

HTML 方向控制
HTML 提供了 dir 属性、<bdi> 和 <bdo> 元素来控制文本方向。dir="auto" 让浏览器根据首个强方向字符自动判断：


<!-- dir="auto" 自动检测内容方向 -->
<p dir="auto">Hello, this is English text.</p>
<p dir="auto">مرحبا، هذا نص عربي.</p>

<!-- bdi 隔离未知方向内容 -->
<ul>
  <li>用户 <bdi>إيان</bdi>: 15 条评论</li>
  <li>用户 <bdi>john_doe</bdi>: 23 条评论</li>
</ul>

<!-- bdo 强制方向覆盖 -->
<p>原文: Hello</p>
<p>反向: <bdo dir="rtl">Hello</bdo></p>
import type { FC, ReactNode } from "react";

interface BidiTextProps {
  children: ReactNode;
  direction?: "ltr" | "rtl" | "auto";
  isolate?: boolean;
}

const BidiText: FC<BidiTextProps> = ({
  children,
  direction = "auto",
  isolate = true,
}) => {
  if (isolate) {
    return <bdi dir={direction}>{children}</bdi>;
  }
  return <span dir={direction}>{children}</span>;
};

interface FormattedBidiProps {
  template: string;
  values: Record<string, string>;
}

const FormattedBidi: FC<FormattedBidiProps> = ({ template, values }) => {
  const parts = template.split(/\{(\w+)\}/g);

  return (
    <span>
      {parts.map((part, index) =>
        index % 2 === 0 ? (
          <span key={index}>{part}</span>
        ) : (
          <bdi key={index}>{values[part]}</bdi>
        ),
      )}
    </span>
  );
};

CSS direction 与 writing-mode
CSS 的 direction 和 writing-mode 属性控制更细粒度的文本布局：


.ltr-content {
  direction: ltr;
  unicode-bidi: isolate;
}

.rtl-content {
  direction: rtl;
  unicode-bidi: isolate;
}

.vertical-text-chinese {
  writing-mode: vertical-rl;
  text-orientation: mixed;
}

.vertical-text-mongolian {
  writing-mode: vertical-lr;
  text-orientation: mixed;
}

.bidi-override {
  direction: rtl;
  unicode-bidi: bidi-override;
}

常见双向文本问题
混合方向内容最常见的 Bug 是标点和数字的方向错位：


const bidiIssuesAndFixes = [
  {
    issue: '电话号码方向错乱',
    problematic: 'رقم الهاتف: +1-234-567-8901',
    fix: 'رقم الهاتف: <span dir="ltr">+1-234-567-8901</span>',
    explanation: '电话号码中的连字符被 Bidi 算法误解析',
  },
  {
    issue: '文件路径反转',
    problematic: 'المسار: /home/user/docs/file.txt',
    fix: 'المسار: <bdi>/home/user/docs/file.txt</bdi>',
    explanation: '路径分隔符和点号是弱方向字符',
  },
  {
    issue: '用户名显示异常',
    problematic: 'المستخدم: user_123 أضاف تعليقاً',
    fix: 'المستخدم: <bdi>user_123</bdi> أضاف تعليقاً',
    explanation: '用户名中的下划线和数字影响方向',
  },
  {
    issue: '括号不匹配',
    problematic: 'اقرأ الفصل (Chapter 3) الآن',
    fix: 'اقرأ الفصل \u2066(Chapter 3)\u2069 الآن',
    explanation: '括号是镜像字符，方向影响配对',
  },
];
小结
    

  • Unicode 双向算法根据字符类型自动解析混合方向文本的显示顺序
    • 

  • <bdi> 元素是隔离用户生成内容方向的最佳实践，防止方向溢出
    • 

  • LRI/RLI/PDI 是新一代 Unicode 方向隔离标记，比 LRE/RLE 更安全
    • 

  • 电话号码、文件路径、URL 等混合内容最容易出现方向错误
    • 

  • CSS 的 unicode-bidi: isolate 是方向隔离的推荐写法
    • 

  • writing-mode 支持中文竖排和蒙古语等特殊书写系统
    •
