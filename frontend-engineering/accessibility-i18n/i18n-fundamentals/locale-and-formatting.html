地区与格式化

核心概念

地区（Locale）是国际化系统中的核心抽象，它定义了语言、地区、书写系统和格式化规则的组合。一个完整的 locale 标签（如 zh-Hans-CN）包含语言代码、脚本和国家/地区信息。正确使用 Locale 是实现日期、数字、货币等内容本地化格式的前提。现代浏览器通过 Intl API 提供了强大的原生格式化能力。

数字与货币格式化
不同地区对数字的分隔符、小数点和分组规则有截然不同的约定：


const formatNumber = (value: number, locale: string): string => {
  return new Intl.NumberFormat(locale).format(value);
};

console.log(formatNumber(1234567.89, 'en-US'));
console.log(formatNumber(1234567.89, 'de-DE'));
console.log(formatNumber(1234567.89, 'zh-CN'));
console.log(formatNumber(1234567.89, 'hi-IN'));

const formatCurrency = (value: number, locale: string, currency: string): string => {
  return new Intl.NumberFormat(locale, {
    style: 'currency',
    currency,
    minimumFractionDigits: 2,
    maximumFractionDigits: 2,
  }).format(value);
};

console.log(formatCurrency(1234.5, 'en-US', 'USD'));
console.log(formatCurrency(1234.5, 'ja-JP', 'JPY'));
console.log(formatCurrency(1234.5, 'de-DE', 'EUR'));
console.log(formatCurrency(1234.5, 'zh-CN', 'CNY'));

const formatCompactNumber = (value: number, locale: string): string => {
  return new Intl.NumberFormat(locale, {
    notation: 'compact',
    compactDisplay: 'short',
  }).format(value);
};

console.log(formatCompactNumber(1500000, 'en-US'));
console.log(formatCompactNumber(1500000, 'zh-CN'));
console.log(formatCompactNumber(1500000, 'ja-JP'));

日期与时间格式化
日期格式化是国际化中最复杂的领域之一，涉及日历系统、时区、日期顺序和分隔符等多个维度：


const formatDate = (date: Date, locale: string, options?: Intl.DateTimeFormatOptions): string => {
  return new Intl.DateTimeFormat(locale, options).format(date);
};

const date = new Date('2024-03-15T14:30:00Z');

const dateStyles: Intl.DateTimeFormatOptions[] = [
  { dateStyle: 'full', timeStyle: 'long', timeZone: 'Asia/Shanghai' },
  { dateStyle: 'long', timeZone: 'America/New_York' },
  { dateStyle: 'medium', timeZone: 'Europe/London' },
  { dateStyle: 'short', timeZone: 'Asia/Tokyo' },
];

const formatRelativeTime = (date: Date, locale: string): string => {
  const rtf = new Intl.RelativeTimeFormat(locale, {
    numeric: 'auto',
    style: 'long',
  });

  const diffMs = date.getTime() - Date.now();
  const diffDays = Math.round(diffMs / (1000 * 60 * 60 * 24));

  if (Math.abs(diffDays) < 1) {
    const diffHours = Math.round(diffMs / (1000 * 60 * 60));
    return rtf.format(diffHours, 'hour');
  }
  if (Math.abs(diffDays) < 30) {
    return rtf.format(diffDays, 'day');
  }
  const diffMonths = Math.round(diffDays / 30);
  return rtf.format(diffMonths, 'month');
};

排序与比较
不同语言的字符串排序规则差异很大——德语中 ä 排在 a 之后，而瑞典语中 ä 排在 z 之后：


const sortStrings = (strings: string[], locale: string): string[] => {
  const collator = new Intl.Collator(locale, {
    sensitivity: 'base',
    numeric: true,
  });
  return [...strings].sort(collator.compare);
};

const names = ['Ångström', 'Zebra', 'Ärmel', 'Apple', 'Öl'];
console.log(sortStrings(names, 'de-DE'));
console.log(sortStrings(names, 'sv-SE'));

const naturalSort = (items: string[], locale: string): string[] => {
  const collator = new Intl.Collator(locale, { numeric: true });
  return [...items].sort(collator.compare);
};

const files = ['file10.txt', 'file2.txt', 'file1.txt', 'file20.txt'];
console.log(naturalSort(files, 'en'));

列表与复数格式化
列表格式化处理多个元素的连接方式，复数规则处理名词的单复数变化：


const formatList = (items: string[], locale: string, type: Intl.ListFormatType = 'conjunction'): string => {
  return new Intl.ListFormat(locale, { style: 'long', type }).format(items);
};

const items = ['苹果', '香蕉', '橙子'];
console.log(formatList(items, 'zh-CN'));
console.log(formatList(['Apple', 'Banana', 'Orange'], 'en-US'));
console.log(formatList(['Apple', 'Banana', 'Orange'], 'en-US', 'disjunction'));

const getPluralCategory = (count: number, locale: string): string => {
  const pr = new Intl.PluralRules(locale);
  return pr.select(count);
};

小结
    

  • Locale 标签是国际化的核心标识，决定了所有格式化规则
    • 

  • Intl API 提供了数字、日期、货币、列表和复数的原生格式化能力
    • 

  • 数字格式化的关键差异在分组符、小数点和印度分组等
    • 

  • 日期格式化需要处理日历系统、时区和日期顺序差异
    • 

  • Collator 处理跨语言的字符串排序，支持自然排序和大小写敏感控制
    • 

  • 阿拉伯语等语言有 6 种复数形式，需要完整的复数规则支持
    •
