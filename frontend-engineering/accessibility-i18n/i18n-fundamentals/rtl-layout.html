RTL 布局适配

核心概念

RTL（Right-to-Left）布局适配是国际化工程中最具挑战性的技术问题之一。阿拉伯语、希伯来语、波斯语等语言的书写方向从右到左，这不仅影响文本方向，还影响整个页面布局——导航栏、按钮图标、滚动条、进度条等所有视觉元素都需要水平镜像。CSS Logical Properties 是现代浏览器提供的原生 RTL 支持方案，用逻辑方向（start/end）替代物理方向（left/right）。

CSS 逻辑属性实践
CSS Logical Properties 是实现双向布局的现代标准方案。使用逻辑属性编写的样式会自动适应文档的书写方向：


.card {
  margin-inline: 1rem;
  padding-inline-start: 1.5rem;
  padding-inline-end: 1rem;
  border-inline-start: 4px solid var(--accent);
  text-align: start;
}

.sidebar {
  inset-inline-start: 0;
  inline-size: 280px;
  border-inline-end: 1px solid var(--border);
}

.nav-item {
  margin-inline-end: 0.5rem;
  padding-inline: 1rem;
  padding-block: 0.5rem;
}

.breadcrumb-separator::after {
  content: '›';
}

[dir='rtl'] .breadcrumb-separator::after {
  content: '‹';
}
Flexbox 和 Grid 天然支持逻辑方向——在 RTL 模式下自动反转排列：


.toolbar {
  display: flex;
  gap: 0.5rem;
}

.grid-layout {
  display: grid;
  grid-template-columns: 280px 1fr 200px;
}
const directionAwareStyles = {
  flexExample: `
    /* Flexbox 自动适配 RTL — 无需额外代码 */
    .flex-container {
      display: flex;
      gap: 1rem;
      /* 在 RTL 中，子元素自动从右到左排列 */
    }
    
    /* 只有 row-reverse 需要注意 — 它在 RTL 中会变成从左到右 */
    .flex-reverse {
      flex-direction: row-reverse;
    }
  `,
  gridExample: `
    .grid-layout {
      display: grid;
      grid-template-areas: "sidebar main aside";
      /* 在 RTL 中：aside 在左，sidebar 在右 */
    }
  `,
};

HTML 方向控制
HTML 的 dir 属性和 CSS 的 direction 属性控制文档的基本方向。正确设置方向是所有 RTL 适配的前提：


import type { FC } from "react";

interface DirectionProviderProps {
  locale: string;
  children: React.ReactNode;
}

const RTL_LOCALES = new Set(["ar", "he", "fa", "ur", "ps", "sd", "yi"]);

const getDirection = (locale: string): "ltr" | "rtl" => {
  const lang = locale.split("-")[0];
  return RTL_LOCALES.has(lang) ? "rtl" : "ltr";
};

const DirectionProvider: FC<DirectionProviderProps> = ({ locale, children }) => {
  const dir = getDirection(locale);

  return (
    <div dir={dir} lang={locale} style={{ direction: dir }}>
      {children}
    </div>
  );
};

const useDirection = (locale: string) => {
  const dir = getDirection(locale);
  const isRtl = dir === "rtl";

  return {
    dir,
    isRtl,
    startSide: isRtl ? "right" : "left",
    endSide: isRtl ? "left" : "right",
  };
};
对于混合方向的内容（如阿拉伯语中嵌入英文），使用 Unicode 双向算法和 <bdi> 标签：


<p dir="rtl">اسم المستخدم: <bdi>john_doe_123</bdi> مسجل بنجاح</p>
图标与视觉元素方向
图标分为两类：方向性图标（箭头、返回、前进）需要在 RTL 中镜像，非方向性图标（搜索、设置、收藏）保持不变：


[dir='rtl'] .icon-arrow-right,
[dir='rtl'] .icon-chevron-right,
[dir='rtl'] .icon-forward,
[dir='rtl'] .icon-back {
  transform: scaleX(-1);
}

/* 进度条方向适配 */
.progress-bar {
  direction: inherit;
}

.progress-fill {
  transform-origin: inline-start;
}

/* 滚动条 — 浏览器自动处理 */
/* 轮播图 — 需要反转滑动方向 */
.carousel[dir='rtl'] {
  direction: rtl;
}

小结
    

  • CSS Logical Properties 用逻辑方向替代物理方向，是 RTL 适配的现代标准方案
    • 

  • Flexbox 和 Grid 天然支持 RTL，自动反转元素排列方向
    • 

  • HTML dir 属性是 RTL 布局的基础，需在根元素正确设置
    • 

  • 方向性图标（箭头、返回）需要镜像，非方向性图标（搜索、设置）保持不变
    • 

  • transform、box-shadow 和 absolute 定位需要特别处理
    • 

  • RTL 测试应覆盖布局方向、文本对齐和交互反馈三个维度
    •
