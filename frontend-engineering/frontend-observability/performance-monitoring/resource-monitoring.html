资源加载与网络监控

核心概念

资源加载监控是前端可观测性中连接网络层和渲染层的桥梁。通过 Resource Timing API 和 Navigation Timing API，可以精确测量每个资源从 DNS 解析到响应完成的全链路耗时，识别慢资源、失败请求和带宽瓶颈。在复杂的 SPA 应用中，资源加载性能直接决定了页面首屏速度和后续交互体验。

Resource Timing 深度采集
Resource Timing API 为每个通过网络加载的资源提供了精确到亚毫秒级的时间戳。通过 PerformanceObserver 可以实时采集所有资源的加载性能数据：


interface ResourceMetric {
  readonly name: string;
  readonly initiatorType: string;
  readonly transferSize: number;
  readonly encodedBodySize: number;
  readonly decodedBodySize: number;
  readonly duration: number;
  readonly dnsTime: number;
  readonly tcpTime: number;
  readonly tlsTime: number;
  readonly ttfb: number;
  readonly downloadTime: number;
  readonly cacheHit: boolean;
  readonly protocol: string;
}

const createResourceMonitor = (
  onMetric: (metric: ResourceMetric) => void,
  filter?: (entry: PerformanceResourceTiming) => boolean,
): PerformanceObserver => {
  const observer = new PerformanceObserver((list) => {
    list.getEntries().forEach((rawEntry) => {
      const entry = rawEntry as PerformanceResourceTiming;
      if (filter && !filter(entry)) return;

      const metric: ResourceMetric = {
        name: entry.name,
        initiatorType: entry.initiatorType,
        transferSize: entry.transferSize,
        encodedBodySize: entry.encodedBodySize,
        decodedBodySize: entry.decodedBodySize,
        duration: entry.duration,
        dnsTime: entry.domainLookupEnd - entry.domainLookupStart,
        tcpTime: entry.connectEnd - entry.connectStart,
        tlsTime: entry.secureConnectionStart > 0 ? entry.connectEnd - entry.secureConnectionStart : 0,
        ttfb: entry.responseStart - entry.requestStart,
        downloadTime: entry.responseEnd - entry.responseStart,
        cacheHit: entry.transferSize === 0 && entry.decodedBodySize > 0,
        protocol: entry.nextHopProtocol,
      };

      onMetric(metric);
    });
  });

  observer.observe({ type: 'resource', buffered: true });
  return observer;
};

慢请求检测与瀑布流分析
慢请求检测通过设定阈值自动标记异常资源，帮助开发者快速定位性能瓶颈：


interface SlowRequestThresholds {
  readonly scriptLoad: number;
  readonly styleLoad: number;
  readonly imageLoad: number;
  readonly fontLoad: number;
  readonly apiRequest: number;
}

interface SlowRequestReport {
  readonly resource: ResourceMetric;
  readonly threshold: number;
  readonly severity: 'warning' | 'critical';
  readonly bottleneck: 'dns' | 'connection' | 'ttfb' | 'download' | 'mixed';
}

const defaultThresholds: SlowRequestThresholds = {
  scriptLoad: 3000,
  styleLoad: 2000,
  imageLoad: 5000,
  fontLoad: 3000,
  apiRequest: 2000,
};

const detectSlowRequests = (
  metric: ResourceMetric,
  thresholds: SlowRequestThresholds = defaultThresholds,
): SlowRequestReport | null => {
  const thresholdMap: Record<string, number> = {
    script: thresholds.scriptLoad,
    link: thresholds.styleLoad,
    img: thresholds.imageLoad,
    css: thresholds.fontLoad,
    fetch: thresholds.apiRequest,
    xmlhttprequest: thresholds.apiRequest,
  };

  const threshold = thresholdMap[metric.initiatorType] ?? 5000;
  if (metric.duration <= threshold) return null;

  const phases = [
    { name: 'dns' as const, value: metric.dnsTime },
    { name: 'connection' as const, value: metric.tcpTime + metric.tlsTime },
    { name: 'ttfb' as const, value: metric.ttfb },
    { name: 'download' as const, value: metric.downloadTime },
  ];

  const maxPhase = phases.reduce((max, p) => (p.value > max.value ? p : max), phases[0]);
  const totalKnown = phases.reduce((sum, p) => sum + p.value, 0);

  return {
    resource: metric,
    threshold,
    severity: metric.duration > threshold * 2 ? 'critical' : 'warning',
    bottleneck: totalKnown > metric.duration * 0.7 ? maxPhase.name : 'mixed',
  };
};
网络状态感知
Network Information API 提供了用户当前的网络连接类型和有效带宽信息，可以用于自适应调整资源加载策略：


interface NetworkInfo {
  readonly effectiveType: '4g' | '3g' | '2g' | 'slow-2g';
  readonly downlink: number;
  readonly rtt: number;
  readonly saveData: boolean;
}

const getNetworkInfo = (): NetworkInfo | null => {
  const nav = navigator as Navigator & {
    readonly connection?: {
      readonly effectiveType: string;
      readonly downlink: number;
      readonly rtt: number;
      readonly saveData: boolean;
    };
  };

  if (!nav.connection) return null;

  return {
    effectiveType: nav.connection.effectiveType as NetworkInfo['effectiveType'],
    downlink: nav.connection.downlink,
    rtt: nav.connection.rtt,
    saveData: nav.connection.saveData,
  };
};

interface AdaptiveLoadingConfig {
  readonly imageQuality: 'high' | 'medium' | 'low';
  readonly prefetchEnabled: boolean;
  readonly videoAutoplay: boolean;
  readonly animationsEnabled: boolean;
}

const getAdaptiveConfig = (network: NetworkInfo | null): AdaptiveLoadingConfig => {
  if (!network || network.saveData) {
    return { imageQuality: 'low', prefetchEnabled: false, videoAutoplay: false, animationsEnabled: false };
  }

  switch (network.effectiveType) {
    case '4g':
      return { imageQuality: 'high', prefetchEnabled: true, videoAutoplay: true, animationsEnabled: true };
    case '3g':
      return { imageQuality: 'medium', prefetchEnabled: false, videoAutoplay: false, animationsEnabled: true };
    default:
      return { imageQuality: 'low', prefetchEnabled: false, videoAutoplay: false, animationsEnabled: false };
  }
};
小结
    

  • Resource Timing API 提供了每个资源从 DNS 到下载完成的全链路时间戳
    • 

  • 通过 transferSize 和 decodedBodySize 的组合可以区分缓存命中、304 协商和全量下载
    • 

  • 慢请求检测通过阈值比较和阶段分析自动定位性能瓶颈（DNS/TCP/TTFB/下载）
    • 

  • Network Information API 提供网络状态感知，支持自适应资源加载策略
    • 

  • 跨域资源需要服务端设置 Timing-Allow-Origin 响应头才能获取详细时间信息
    • 

  • 资源加载监控应与 Web Vitals（LCP）和错误监控联动，形成完整的性能诊断链路
    •
