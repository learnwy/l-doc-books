用户体验指标体系

核心概念

用户体验指标（User Experience Metrics）是以用户感知为核心的性能度量体系，用于量化页面加载过程中用户实际「看到什么」和「能做什么」。传统的技术指标（如 DOMContentLoaded、Load）关注浏览器事件，而用户体验指标关注的是内容可见时间（LCP）、交互响应速度（INP）和视觉稳定性（CLS）。Google 在 2020 年提出的 Core Web Vitals 将三个关键指标（LCP、INP、CLS）确立为搜索排名因素，使用户体验指标成为前端性能优化的核心目标。

LCP 采集与优化
LCP（Largest Contentful Paint）衡量视口中最大内容元素（图片、视频封面、大段文字块）完成渲染的时间。LCP 候选元素在页面加载过程中会不断更新——浏览器持续追踪当前最大的内容元素，直到用户首次交互（点击、滚动、按键）后停止更新。


interface LCPEntry {
  readonly element: Element | null;
  readonly renderTime: number;
  readonly loadTime: number;
  readonly size: number;
  readonly id: string;
  readonly url: string;
  readonly startTime: number;
}

interface WebVitalsResult {
  readonly name: string;
  readonly value: number;
  readonly rating: 'good' | 'needs-improvement' | 'poor';
  readonly delta: number;
  readonly entries: ReadonlyArray<PerformanceEntry>;
}

function observeLCP(callback: (result: WebVitalsResult) => void): () => void {
  let lastEntry: LCPEntry | null = null;

  const observer = new PerformanceObserver((list) => {
    const entries = list.getEntries();
    const latest = entries[entries.length - 1] as unknown as LCPEntry;
    lastEntry = latest;
  });

  observer.observe({ type: 'largest-contentful-paint', buffered: true });

  const reportOnInteraction = () => {
    if (lastEntry) {
      callback({
        name: 'LCP',
        value: lastEntry.startTime,
        rating: rateMetric('LCP', lastEntry.startTime),
        delta: lastEntry.startTime,
        entries: [lastEntry as unknown as PerformanceEntry],
      });
    }
    cleanup();
  };

  const events = ['pointerdown', 'keydown', 'scroll'];
  events.forEach((e) => addEventListener(e, reportOnInteraction, { once: true }));

  const cleanup = () => {
    observer.disconnect();
    events.forEach((e) => removeEventListener(e, reportOnInteraction));
  };

  return cleanup;
}

function rateMetric(name: string, value: number): 'good' | 'needs-improvement' | 'poor' {
  const thresholds: Record<string, [number, number]> = {
    LCP: [2500, 4000],
    INP: [200, 500],
    CLS: [0.1, 0.25],
    FCP: [1800, 3000],
    TTFB: [800, 1800],
  };
  const [good, poor] = thresholds[name] ?? [1000, 3000];
  if (value <= good) return 'good';
  if (value <= poor) return 'needs-improvement';
  return 'poor';
}
LCP 优化的关键策略包括：优先加载 LCP 元素（使用 fetchpriority="high"）、预加载 LCP 图片（<link rel="preload" as="image">）、减少服务端响应时间（TTFB）、消除渲染阻塞资源（关键 CSS 内联）和避免客户端渲染延迟（SSR/SSG）。


INP 采集与交互延迟分析
INP（Interaction to Next Paint）取代了 FID（First Input Delay），衡量的是页面整个生命周期中所有交互事件的响应延迟。INP 取所有交互延迟的第 98 百分位值（而非平均值或最大值），代表了用户在实际使用中「最差但典型」的交互体验。


每次交互的延迟由三部分组成：输入延迟（Input Delay，主线程被占用导致事件处理延迟）、处理时间（Processing Time，事件处理函数执行时间）和呈现延迟（Presentation Delay，从处理完成到下一帧绘制的时间）。


interface INPEntry {
  readonly name: string;
  readonly entryType: 'event';
  readonly startTime: number;
  readonly duration: number;
  readonly processingStart: number;
  readonly processingEnd: number;
  readonly interactionId: number;
}

interface InteractionBreakdown {
  readonly interactionId: number;
  readonly eventType: string;
  readonly inputDelay: number;
  readonly processingTime: number;
  readonly presentationDelay: number;
  readonly totalDuration: number;
}

function analyzeInteraction(entry: INPEntry): InteractionBreakdown {
  return {
    interactionId: entry.interactionId,
    eventType: entry.name,
    inputDelay: entry.processingStart - entry.startTime,
    processingTime: entry.processingEnd - entry.processingStart,
    presentationDelay: entry.startTime + entry.duration - entry.processingEnd,
    totalDuration: entry.duration,
  };
}

function observeINP(callback: (result: WebVitalsResult) => void): () => void {
  const interactions = new Map<number, number>();

  const observer = new PerformanceObserver((list) => {
    for (const entry of list.getEntries()) {
      const inpEntry = entry as unknown as INPEntry;
      if (inpEntry.interactionId > 0) {
        const existing = interactions.get(inpEntry.interactionId) ?? 0;
        interactions.set(inpEntry.interactionId, Math.max(existing, inpEntry.duration));
      }
    }
  });

  observer.observe({ type: 'event', buffered: true });

  const reportOnVisibilityChange = () => {
    if (document.visibilityState === 'hidden' && interactions.size > 0) {
      const durations = [...interactions.values()].sort((a, b) => a - b);
      const p98Index = Math.min(Math.ceil(durations.length * 0.98) - 1, durations.length - 1);
      const inp = durations[p98Index];
      callback({
        name: 'INP',
        value: inp,
        rating: rateMetric('INP', inp),
        delta: inp,
        entries: [],
      });
    }
  };

  addEventListener('visibilitychange', reportOnVisibilityChange);

  return () => {
    observer.disconnect();
    removeEventListener('visibilitychange', reportOnVisibilityChange);
  };
}

CLS 采集与布局偏移追踪
CLS（Cumulative Layout Shift）衡量页面在整个生命周期中的视觉稳定性。每次非用户触发的布局偏移都会产生一个偏移分数（Layout Shift Score），CLS 取最大「会话窗口」中的累积偏移分数。会话窗口的定义是：连续的布局偏移之间间隔不超过 1 秒，且窗口总时长不超过 5 秒。


interface LayoutShiftEntry {
  readonly value: number;
  readonly hadRecentInput: boolean;
  readonly startTime: number;
  readonly sources: ReadonlyArray<{
    readonly node: Node | null;
    readonly previousRect: DOMRectReadOnly;
    readonly currentRect: DOMRectReadOnly;
  }>;
}

interface CLSSession {
  readonly startTime: number;
  readonly endTime: number;
  readonly value: number;
  readonly entries: ReadonlyArray<LayoutShiftEntry>;
}

function observeCLS(callback: (result: WebVitalsResult) => void): () => void {
  let sessionValue = 0;
  let sessionStart = -1;
  let previousEntryTime = -1;
  let maxSessionValue = 0;
  const allSessions: CLSSession[] = [];

  const observer = new PerformanceObserver((list) => {
    for (const entry of list.getEntries()) {
      const lsEntry = entry as unknown as LayoutShiftEntry;
      if (lsEntry.hadRecentInput) continue;

      const gap = lsEntry.startTime - previousEntryTime;
      const sessionDuration = lsEntry.startTime - sessionStart;

      if (gap > 1000 || sessionDuration > 5000) {
        if (sessionValue > 0) {
          allSessions.push({
            startTime: sessionStart,
            endTime: previousEntryTime,
            value: sessionValue,
            entries: [],
          });
        }
        sessionValue = 0;
        sessionStart = lsEntry.startTime;
      }

      sessionValue += lsEntry.value;
      previousEntryTime = lsEntry.startTime;
      maxSessionValue = Math.max(maxSessionValue, sessionValue);
    }
  });

  observer.observe({ type: 'layout-shift', buffered: true });

  const report = () => {
    callback({
      name: 'CLS',
      value: maxSessionValue,
      rating: rateMetric('CLS', maxSessionValue),
      delta: maxSessionValue,
      entries: [],
    });
  };

  addEventListener('visibilitychange', () => {
    if (document.visibilityState === 'hidden') report();
  });

  return () => observer.disconnect();
}
CLS 的常见触发源包括：未设置尺寸的图片/视频（加载完成后撑开布局）、动态插入的广告或横幅、异步加载的 Web 字体（FOIT/FOUT 导致文本重排）和动态内容注入（如 A/B 测试代码、Cookie 同意弹窗）。


小结
    

  • Core Web Vitals（LCP、INP、CLS）是搜索排名因素，也是前端性能优化的核心目标
    • 

  • LCP 优化关注最大内容元素的加载和渲染速度
    • 

  • INP 取代 FID，覆盖全生命周期交互延迟，取 P98 值
    • 

  • CLS 使用会话窗口算法，只计算非用户触发的布局偏移
    • 

  • 每个指标都有 Good/Needs Improvement/Poor 三档阈值
    • 

  • 指标采集依赖 PerformanceObserver API，需在页面卸载前上报
    • 

  • 用户体验指标应按设备类型、网络条件和地理位置分维度分析
    •
