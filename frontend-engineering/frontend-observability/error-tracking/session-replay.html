用户会话回放

核心概念

用户会话回放（Session Replay）是一种通过记录用户在页面上的操作序列，在错误发生后以视频形式回放用户行为的技术。它不是传统的屏幕录制，而是通过记录 DOM 变更、鼠标轨迹和交互事件，在回放端重建页面状态。Session Replay 是前端错误排查的「时光机」，让开发者能够精确看到用户在遇到错误前做了什么。

DOM 快照与增量记录
Session Replay 的核心技术是 DOM 序列化和 MutationObserver。首次访问时对整个 DOM 树做全量快照，后续通过 MutationObserver 只记录增量变更，大幅减少数据量：


interface SerializedNode {
  readonly id: number;
  readonly type: number;
  readonly tagName?: string;
  readonly attributes?: Readonly<Record<string, string>>;
  readonly textContent?: string;
  readonly childNodes?: ReadonlyArray<SerializedNode>;
  readonly isSVG?: boolean;
}

interface DOMEvent {
  readonly type: 'full-snapshot' | 'mutation' | 'mouse' | 'scroll' | 'input' | 'viewport';
  readonly timestamp: number;
  readonly data: unknown;
}

interface MutationRecord {
  readonly adds: ReadonlyArray<{ parentId: number; node: SerializedNode; nextId?: number }>;
  readonly removes: ReadonlyArray<{ parentId: number; nodeId: number }>;
  readonly attributes: ReadonlyArray<{ nodeId: number; key: string; value: string | null }>;
  readonly texts: ReadonlyArray<{ nodeId: number; value: string }>;
}

const createDOMSerializer = () => {
  let nodeId = 0;
  const nodeMap = new WeakMap<Node, number>();

  const serialize = (node: Node): SerializedNode => {
    const id = nodeId++;
    nodeMap.set(node, id);

    if (node.nodeType === Node.TEXT_NODE) {
      return { id, type: 3, textContent: node.textContent ?? '' };
    }

    if (node.nodeType === Node.ELEMENT_NODE) {
      const el = node as Element;
      const attrs: Record<string, string> = {};
      for (const attr of el.attributes) {
        attrs[attr.name] = attr.value;
      }

      return {
        id,
        type: 1,
        tagName: el.tagName.toLowerCase(),
        attributes: attrs,
        childNodes: Array.from(el.childNodes).map(serialize),
        isSVG: el instanceof SVGElement,
      };
    }

    return { id, type: node.nodeType };
  };

  const getId = (node: Node): number | undefined => nodeMap.get(node);

  return { serialize, getId };
};
MutationObserver 监听 DOM 变更并将增量转换为可序列化的记录：


const createMutationTracker = (
  serializer: ReturnType<typeof createDOMSerializer>,
  onMutation: (record: MutationRecord) => void,
): MutationObserver => {
  const observer = new MutationObserver((mutations) => {
    const adds: Array<{ parentId: number; node: SerializedNode; nextId?: number }> = [];
    const removes: Array<{ parentId: number; nodeId: number }> = [];
    const attributes: Array<{ nodeId: number; key: string; value: string | null }> = [];
    const texts: Array<{ nodeId: number; value: string }> = [];

    mutations.forEach((mutation) => {
      switch (mutation.type) {
        case 'childList':
          mutation.addedNodes.forEach((node) => {
            const parentId = serializer.getId(mutation.target);
            if (parentId !== undefined) {
              adds.push({
                parentId,
                node: serializer.serialize(node),
                nextId: mutation.nextSibling ? serializer.getId(mutation.nextSibling) : undefined,
              });
            }
          });
          mutation.removedNodes.forEach((node) => {
            const parentId = serializer.getId(mutation.target);
            const nodeId = serializer.getId(node);
            if (parentId !== undefined && nodeId !== undefined) {
              removes.push({ parentId, nodeId });
            }
          });
          break;
        case 'attributes': {
          const nodeId = serializer.getId(mutation.target);
          if (nodeId !== undefined && mutation.attributeName) {
            attributes.push({
              nodeId,
              key: mutation.attributeName,
              value: (mutation.target as Element).getAttribute(mutation.attributeName),
            });
          }
          break;
        }
        case 'characterData': {
          const nodeId = serializer.getId(mutation.target);
          if (nodeId !== undefined) {
            texts.push({ nodeId, value: mutation.target.textContent ?? '' });
          }
          break;
        }
      }
    });

    onMutation({ adds, removes, attributes, texts });
  });

  observer.observe(document, {
    childList: true,
    subtree: true,
    attributes: true,
    characterData: true,
    attributeOldValue: false,
  });

  return observer;
};
隐私保护与数据脱敏
Session Replay 涉及用户隐私的敏感操作。必须在记录阶段对敏感信息进行脱敏处理，而不是在存储或回放阶段：


type MaskingStrategy = 'mask-all' | 'mask-inputs' | 'mask-sensitive' | 'none';

interface PrivacyConfig {
  readonly defaultStrategy: MaskingStrategy;
  readonly maskSelectors: ReadonlyArray<string>;
  readonly blockSelectors: ReadonlyArray<string>;
  readonly ignoreSelectors: ReadonlyArray<string>;
  readonly maskInputTypes: ReadonlyArray<string>;
}

const defaultPrivacyConfig: PrivacyConfig = {
  defaultStrategy: 'mask-inputs',
  maskSelectors: ['.sensitive-data', '[data-private]'],
  blockSelectors: ['.no-replay', 'iframe'],
  ignoreSelectors: ['.replay-ignore'],
  maskInputTypes: ['password', 'email', 'tel', 'ssn'],
};

const shouldMask = (element: Element, config: PrivacyConfig): boolean => {
  if (config.maskSelectors.some((sel) => element.matches(sel))) return true;
  if (element.closest('[data-private]')) return true;

  if (element instanceof HTMLInputElement) {
    return config.maskInputTypes.includes(element.type);
  }
  return false;
};

const maskText = (text: string): string => {
  return text.replace(/./g, '*');
};

回放播放器
回放播放器负责根据记录的事件序列重建页面状态。它在 iframe 沙箱中运行，通过时间轴控制器按照原始时间间隔重放 DOM 变更和交互事件：


interface ReplayPlayer {
  readonly play: () => void;
  readonly pause: () => void;
  readonly seek: (timestamp: number) => void;
  readonly setSpeed: (speed: number) => void;
  readonly getProgress: () => number;
}

const createReplayPlayer = (container: HTMLElement, events: ReadonlyArray<DOMEvent>): ReplayPlayer => {
  const iframe = document.createElement('iframe');
  iframe.sandbox.value = 'allow-same-origin';
  iframe.style.width = '100%';
  iframe.style.height = '100%';
  iframe.style.border = 'none';
  container.appendChild(iframe);

  let currentIndex = 0;
  let playing = false;
  let speed = 1;
  let timer: ReturnType<typeof setTimeout> | null = null;

  const applyEvent = (event: DOMEvent): void => {
    const doc = iframe.contentDocument;
    if (!doc) return;

    switch (event.type) {
      case 'full-snapshot':
        doc.open();
        doc.write(rebuildHTML(event.data as SerializedNode));
        doc.close();
        break;
      case 'mutation':
        applyMutations(doc, event.data as MutationRecord);
        break;
      case 'mouse':
        renderCursor(doc, event.data as { x: number; y: number });
        break;
    }
  };

  const scheduleNext = (): void => {
    if (!playing || currentIndex >= events.length - 1) return;

    const currentEvent = events[currentIndex];
    const nextEvent = events[currentIndex + 1];
    const delay = (nextEvent.timestamp - currentEvent.timestamp) / speed;

    timer = setTimeout(
      () => {
        currentIndex++;
        applyEvent(events[currentIndex]);
        scheduleNext();
      },
      Math.max(delay, 1),
    );
  };

  return {
    play: () => {
      playing = true;
      scheduleNext();
    },
    pause: () => {
      playing = false;
      if (timer) clearTimeout(timer);
    },
    seek: (timestamp) => {
      const idx = events.findIndex((e) => e.timestamp >= timestamp);
      if (idx >= 0) {
        currentIndex = 0;
        for (let i = 0; i <= idx; i++) applyEvent(events[i]);
        currentIndex = idx;
      }
    },
    setSpeed: (s) => {
      speed = s;
    },
    getProgress: () => currentIndex / events.length,
  };
};
小结
    

  • Session Replay 通过 DOM 快照 + MutationObserver 增量记录实现轻量化的用户操作回放
    • 

  • 全量快照只在页面加载时执行一次，后续通过增量变更记录大幅降低数据量
    • 

  • 隐私保护必须在记录阶段执行数据脱敏，而非事后处理，支持输入遮挡、区域屏蔽等策略
    • 

  • 回放播放器在 iframe 沙箱中运行，按时间轴还原 DOM 变更、鼠标轨迹和交互事件
    • 

  • rrweb 是最成熟的开源 Session Replay 方案，提供了完整的录制、压缩和回放能力
    • 

  • Session Replay 与错误监控关联后，可以直接回放用户触发错误的完整操作路径
