错误捕获与分类

核心概念

前端错误捕获是可观测性系统的安全网，它负责在应用运行时拦截、分类和上报所有异常信息。JavaScript 的动态性和浏览器环境的复杂性导致前端错误的类型多样、来源分散，一个完善的错误捕获系统需要覆盖同步异常、异步异常、资源加载失败、框架错误和跨域脚本错误等多种场景。

全局错误拦截
JavaScript 错误捕获的基础是全局 error 事件和 unhandledrejection 事件。两者分别覆盖同步和异步场景：


type ErrorSeverity = 'fatal' | 'error' | 'warning' | 'info';

interface CapturedError {
  readonly id: string;
  readonly type: 'runtime' | 'promise' | 'resource' | 'network' | 'framework';
  readonly message: string;
  readonly stack?: string;
  readonly filename?: string;
  readonly lineno?: number;
  readonly colno?: number;
  readonly severity: ErrorSeverity;
  readonly timestamp: number;
  readonly tags: Readonly<Record<string, string>>;
  readonly breadcrumbs: ReadonlyArray<Breadcrumb>;
}

interface Breadcrumb {
  readonly type: 'click' | 'navigation' | 'xhr' | 'console' | 'dom';
  readonly message: string;
  readonly timestamp: number;
  readonly data?: Readonly<Record<string, unknown>>;
}

const createErrorCapture = (onError: (error: CapturedError) => void) => {
  const breadcrumbs: Array<Breadcrumb> = [];
  const MAX_BREADCRUMBS = 20;

  const addBreadcrumb = (crumb: Breadcrumb): void => {
    breadcrumbs.push(crumb);
    if (breadcrumbs.length > MAX_BREADCRUMBS) {
      breadcrumbs.shift();
    }
  };

  window.addEventListener('error', (event: ErrorEvent) => {
    if (event.error) {
      onError({
        id: crypto.randomUUID(),
        type: 'runtime',
        message: event.message,
        stack: event.error.stack,
        filename: event.filename,
        lineno: event.lineno,
        colno: event.colno,
        severity: 'error',
        timestamp: Date.now(),
        tags: { errorName: event.error.name },
        breadcrumbs: [...breadcrumbs],
      });
    }
  });

  window.addEventListener(
    'error',
    (event: Event) => {
      const target = event.target as HTMLElement;
      if (target !== window && (target.tagName === 'SCRIPT' || target.tagName === 'LINK' || target.tagName === 'IMG')) {
        onError({
          id: crypto.randomUUID(),
          type: 'resource',
          message: `Failed to load ${target.tagName}: ${(target as HTMLScriptElement).src || (target as HTMLLinkElement).href}`,
          severity: 'warning',
          timestamp: Date.now(),
          tags: { resourceType: target.tagName.toLowerCase() },
          breadcrumbs: [...breadcrumbs],
        });
      }
    },
    true,
  );

  window.addEventListener('unhandledrejection', (event: PromiseRejectionEvent) => {
    const reason = event.reason;
    onError({
      id: crypto.randomUUID(),
      type: 'promise',
      message: reason instanceof Error ? reason.message : String(reason),
      stack: reason instanceof Error ? reason.stack : undefined,
      severity: 'error',
      timestamp: Date.now(),
      tags: { errorName: reason instanceof Error ? reason.name : 'UnhandledRejection' },
      breadcrumbs: [...breadcrumbs],
    });
  });

  return { addBreadcrumb };
};
面包屑追踪
面包屑（Breadcrumbs）记录了错误发生前的用户操作序列，是复现问题的关键信息。通过在 DOM 事件、路由变化和网络请求时自动添加面包屑，可以构建出完整的操作上下文：


const setupBreadcrumbCollectors = (addBreadcrumb: (crumb: Breadcrumb) => void): void => {
  document.addEventListener(
    'click',
    (event: MouseEvent) => {
      const target = event.target as HTMLElement;
      const selector = getElementSelector(target);
      addBreadcrumb({
        type: 'click',
        message: `Click on ${selector}`,
        timestamp: Date.now(),
        data: { selector, text: target.textContent?.slice(0, 50) },
      });
    },
    { capture: true },
  );

  const originalPushState = history.pushState;
  history.pushState = function (...args) {
    addBreadcrumb({
      type: 'navigation',
      message: `Navigate to ${args[2] as string}`,
      timestamp: Date.now(),
      data: { from: location.href, to: args[2] as string },
    });
    return originalPushState.apply(this, args);
  };

  window.addEventListener('popstate', () => {
    addBreadcrumb({
      type: 'navigation',
      message: `Popstate to ${location.href}`,
      timestamp: Date.now(),
    });
  });
};

const getElementSelector = (element: HTMLElement): string => {
  if (element.id) return `#${element.id}`;
  const tag = element.tagName.toLowerCase();
  const className = element.className ? `.${element.className.split(' ').filter(Boolean).join('.')}` : '';
  return `${tag}${className}`;
};
错误去重与限流
高流量应用中，同一个错误可能在短时间内触发数千次。错误去重和限流机制可以防止错误风暴淹没监控系统：


interface ErrorThrottle {
  readonly shouldReport: (error: CapturedError) => boolean;
  readonly getFingerprint: (error: CapturedError) => string;
}

const createErrorThrottle = (maxPerMinute: number = 10, dedupeWindow: number = 60000): ErrorThrottle => {
  const errorCounts = new Map<string, { count: number; firstSeen: number }>();

  const getFingerprint = (error: CapturedError): string => {
    const parts = [error.type, error.message];
    if (error.filename) parts.push(error.filename);
    if (error.lineno) parts.push(String(error.lineno));
    return parts.join('|');
  };

  const shouldReport = (error: CapturedError): boolean => {
    const fp = getFingerprint(error);
    const now = Date.now();
    const existing = errorCounts.get(fp);

    if (existing && now - existing.firstSeen < dedupeWindow) {
      existing.count++;
      return existing.count <= maxPerMinute;
    }

    errorCounts.set(fp, { count: 1, firstSeen: now });
    return true;
  };

  return { shouldReport, getFingerprint };
};

小结
    

  • 前端错误分为 JS 运行时、Promise 拒绝、资源加载、网络请求和框架渲染五大类
    • 

  • 全局 error 和 unhandledrejection 事件是错误捕获的基础，资源错误需要在捕获阶段拦截
    • 

  • 面包屑记录错误发生前的操作序列，是复现问题的关键上下文信息
    • 

  • 错误去重通过指纹（message + filename + lineno）防止同一错误重复上报
    • 

  • 限流机制防止错误风暴淹没监控系统，每分钟每种错误最多上报固定次数
    • 

  • 跨域脚本错误（Script error.）需要配合 CORS 头和 crossorigin 属性才能获取完整信息
    •
