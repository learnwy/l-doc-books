监控指标与维度体系

核心概念

前端监控指标体系是可观测性系统的度量基础，它定义了「什么值得测量」和「如何测量」。一个完善的指标体系需要覆盖技术指标（性能、错误、资源）和业务指标（转化率、用户满意度），并通过多维度标签实现灵活的数据切片和下钻分析。

指标采集与 Performance API

浏览器 Performance API 是前端指标采集的核心基础设施。通过 PerformanceObserver 可以异步、非阻塞地采集各类性能指标：

interface MetricCollector {
  readonly collect: () => ReadonlyArray<PerformanceMetric>;
  readonly observe: (callback: (metric: PerformanceMetric) => void) => void;
  readonly disconnect: () => void;
}

interface PerformanceMetric {
  readonly name: string;
  readonly value: number;
  readonly unit: 'ms' | 'score' | 'bytes' | 'count';
  readonly timestamp: number;
  readonly attribution?: MetricAttribution;
}

interface MetricAttribution {
  readonly element?: string;
  readonly url?: string;
  readonly loadState?: string;
  readonly interactionTarget?: string;
}

const createWebVitalsCollector = (): MetricCollector => {
  const metrics: Array<PerformanceMetric> = [];
  const observers: Array<PerformanceObserver> = [];
  const callbacks: Array<(metric: PerformanceMetric) => void> = [];

  const addMetric = (metric: PerformanceMetric): void => {
    metrics.push(metric);
    callbacks.forEach((cb) => cb(metric));
  };

  const lcpObserver = new PerformanceObserver((list) => {
    const entries = list.getEntries();
    const lastEntry = entries[entries.length - 1] as PerformanceEntry & { readonly element?: Element };
    addMetric({
      name: 'LCP',
      value: lastEntry.startTime,
      unit: 'ms',
      timestamp: Date.now(),
      attribution: {
        element: lastEntry.element?.tagName,
        url: (lastEntry as PerformanceEntry & { url?: string }).url,
      },
    });
  });
  lcpObserver.observe({ type: 'largest-contentful-paint', buffered: true });
  observers.push(lcpObserver);

  const clsObserver = new PerformanceObserver((list) => {
    let clsValue = 0;
    list.getEntries().forEach((entry) => {
      const layoutShift = entry as PerformanceEntry & { readonly value: number; readonly hadRecentInput: boolean };
      if (!layoutShift.hadRecentInput) {
        clsValue += layoutShift.value;
      }
    });
    addMetric({
      name: 'CLS',
      value: clsValue,
      unit: 'score',
      timestamp: Date.now(),
    });
  });
  clsObserver.observe({ type: 'layout-shift', buffered: true });
  observers.push(clsObserver);

  const inpObserver = new PerformanceObserver((list) => {
    list.getEntries().forEach((entry) => {
      const eventEntry = entry as PerformanceEntry & {
        readonly processingStart: number;
        readonly processingEnd: number;
        readonly interactionId: number;
      };
      if (eventEntry.interactionId) {
        addMetric({
          name: 'INP',
          value: eventEntry.duration,
          unit: 'ms',
          timestamp: Date.now(),
          attribution: {
            interactionTarget: (eventEntry as PerformanceEntry & { target?: Element }).target?.tagName,
          },
        });
      }
    });
  });
  inpObserver.observe({ type: 'event', buffered: true });
  observers.push(inpObserver);

  return {
    collect: () => [...metrics],
    observe: (callback) => callbacks.push(callback),
    disconnect: () => observers.forEach((o) => o.disconnect()),
  };
};

维度标签设计

高基数维度标签是可观测性区别于传统监控的关键特征。通过为每条指标数据附加丰富的维度标签，可以在查询时按任意维度组合进行聚合和下钻：

interface DimensionConfig {
  readonly name: string;
  readonly cardinality: 'low' | 'medium' | 'high';
  readonly extractor: () => string;
  readonly indexed: boolean;
}

const standardDimensions: ReadonlyArray<DimensionConfig> = [
  { name: 'page', cardinality: 'medium', extractor: () => location.pathname, indexed: true },
  { name: 'browser', cardinality: 'low', extractor: () => detectBrowser(), indexed: true },
  { name: 'os', cardinality: 'low', extractor: () => detectOS(), indexed: true },
  { name: 'device', cardinality: 'low', extractor: () => detectDeviceType(), indexed: true },
  {
    name: 'network',
    cardinality: 'low',
    extractor: () =>
      (navigator as Navigator & { connection?: { effectiveType: string } }).connection?.effectiveType ?? 'unknown',
    indexed: true,
  },
  { name: 'region', cardinality: 'medium', extractor: () => getUserRegion(), indexed: true },
  { name: 'version', cardinality: 'medium', extractor: () => getAppVersion(), indexed: true },
  { name: 'userId', cardinality: 'high', extractor: () => getUserId(), indexed: false },
  { name: 'sessionId', cardinality: 'high', extractor: () => getSessionId(), indexed: false },
];

const enrichWithDimensions = (
  metric: PerformanceMetric,
  dimensions: ReadonlyArray<DimensionConfig>,
): PerformanceMetric & { readonly dimensions: Readonly<Record<string, string>> } => {
  const dims: Record<string, string> = {};
  dimensions.forEach((dim) => {
    dims[dim.name] = dim.extractor();
  });
  return { ...metric, dimensions: dims };
};
维度类别 示例 基数 是否索引 用途
页面维度 /home, /product/123 中 是 定位问题页面
环境维度 Chrome 120, iOS 17 低 是 浏览器兼容性分析
网络维度 4g, 3g, wifi 低 是 网络条件影响分析
地域维度 华东, 北美 中 是 区域性问题排查
用户维度 userId, sessionId 高 否 个案追踪与回放

APDEX 与用户满意度

APDEX（Application Performance Index）是一个将复杂性能指标转化为 0-1 单一分数的行业标准方法，用于量化用户对应用性能的满意度：

interface ApdexConfig {
  readonly satisfiedThreshold: number;
  readonly toleratingThreshold: number;
}

interface ApdexResult {
  readonly score: number;
  readonly satisfied: number;
  readonly tolerating: number;
  readonly frustrated: number;
  readonly total: number;
  readonly label: 'Excellent' | 'Good' | 'Fair' | 'Poor' | 'Unacceptable';
}

const calculateApdex = (measurements: ReadonlyArray<number>, config: ApdexConfig): ApdexResult => {
  let satisfied = 0;
  let tolerating = 0;
  let frustrated = 0;

  measurements.forEach((value) => {
    if (value <= config.satisfiedThreshold) {
      satisfied++;
    } else if (value <= config.toleratingThreshold) {
      tolerating++;
    } else {
      frustrated++;
    }
  });

  const total = measurements.length;
  const score = total > 0 ? (satisfied + tolerating / 2) / total : 0;

  const label =
    score >= 0.94
      ? 'Excellent'
      : score >= 0.85
        ? 'Good'
        : score >= 0.7
          ? 'Fair'
          : score >= 0.5
            ? 'Poor'
            : 'Unacceptable';

  return { score, satisfied, tolerating, frustrated, total, label };
};

小结

  • 前端指标体系覆盖加载性能、交互性能、视觉稳定性、错误率和业务指标五大类
  • PerformanceObserver 是非阻塞的指标采集 API，支持 LCP、CLS、INP 等 Web Vitals 指标
  • 维度标签分为低基数（浏览器、OS）和高基数（userId、sessionId），高基数维度不建议索引
  • APDEX 将复杂性能数据转化为 0-1 的满意度分数，直观反映用户体验水平
  • 指标告警阈值应基于 P75/P95 分位数而非平均值，避免长尾问题被均值掩盖
  • 维度设计的关键是在查询灵活性和存储成本之间取得平衡，避免维度爆炸
