Part IV · 浏览器与平台 (Browser & Platform)PWA 与离线优先能力与部署原生平台能力

原生平台能力

核心概念

Project Fugu（Google 2018 年发起）是 Chrome 团队的计划——为 Web 平台提供更多原生能力，缩小 Web 与原生应用之间的差距。File System Access（文件系统访问）、Web Bluetooth（蓝牙）、Web USB、Web NFC、Web Serial（串口）、Web HID（人机接口设备）、Idle Detection（空闲检测）、Periodic Background Sync（周期性后台同步）、Web Share（分享）、Clipboard（剪贴板）、Geolocation（地理位置）、Camera/Mic（摄像头/麦克风）、Wake Lock（屏幕唤醒锁）、Contact Picker（联系人选择器）——大量 API 让 PWA 接近原生应用的能力。但各浏览器支持情况并不统一：Chrome 积极跟进、Safari 相对保守、Firefox 居中。本节涵盖现代 Web 平台能力概览、典型使用场景、权限体验设计、以及回退策略。

Web Bluetooth ✓ ✗ ✗ 物联网、健康设备

File System Access（文件系统访问）

读写用户文件系统：

// 打开文件选择器
const [fileHandle] = await window.showOpenFilePicker({
  types: [{ description: 'Markdown', accept: { 'text/markdown': ['.md'] } }],
});

// 读取文件内容
const file = await fileHandle.getFile();
const content = await file.text();

// 写入文件
const writable = await fileHandle.createWritable();
await writable.write('Hello!');
await writable.close();

// 另存为
const saveHandle = await window.showSaveFilePicker({
  suggestedName: 'doc.md',
});

与传统 <input type="file"> 的区别：传统方式只能上传（单向读取），File System Access 支持真正的文件系统读写操作。

适用场景：替代原生文本编辑器、浏览器中的 IDE（如 VS Code Web）、图片编辑器。

OPFS（Origin Private File System，源私有文件系统）

应用专属的私有文件系统：

const opfsRoot = await navigator.storage.getDirectory();
const fileHandle = await opfsRoot.getFileHandle('data.txt', { create: true });
const writable = await fileHandle.createWritable();
await writable.write('Hello!');
await writable.close();

与 IndexedDB 的区别：提供类文件系统的 API，对二进制数据的性能更好，仅限应用私有访问。

适用场景：WebAssembly 文件系统、本地 SQLite 数据库（sqlite-wasm）、大型二进制数据缓存。

Web Bluetooth（蓝牙）

连接蓝牙设备：

const device = await navigator.bluetooth.requestDevice({
  filters: [{ services: ['heart_rate'] }],
});
const server = await device.gatt.connect();
const service = await server.getPrimaryService('heart_rate');
const characteristic = await service.getCharacteristic('heart_rate_measurement');

characteristic.addEventListener('characteristicvaluechanged', (event) => {
  console.log(event.target.value);
});
await characteristic.startNotifications();

适用场景：健康设备（心率监测仪）、物联网设备（智能灯泡）、玩具互动。

支持情况：仅 Chrome / Edge / Opera 支持，Safari 和 Firefox 不支持。

Web USB

连接 USB 设备：

const device = await navigator.usb.requestDevice({
  filters: [{ vendorId: 0x1234 }],
});
await device.open();
await device.selectConfiguration(1);
await device.claimInterface(0);

适用场景：硬件编程器（Arduino）、游戏控制器、工业设备。

Web NFC

读写 NFC 标签：

const reader = new NDEFReader();
await reader.scan();
reader.addEventListener('reading', ({ message, serialNumber }) => {
  console.log(serialNumber);
  for (const record of message.records) {
    console.log(record.recordType, record.data);
  }
});

适用场景：库存标签管理、公交卡、智能海报。

支持情况：目前仅 Android Chrome 支持。

Web Share API（分享）

调用系统原生分享菜单：

if (navigator.share) {
  await navigator.share({
    title: '我的应用',
    text: '看看这个',
    url: 'https://example.com',
  });
}

支持情况：Chrome / Safari / Edge 移动端和桌面端均广泛支持，Firefox 有限支持。

Web Share Target（接收分享）：通过清单文件（manifest）配置，让 PWA 能接收来自其他应用的分享内容。

Clipboard API（剪贴板）

复制文本：

await navigator.clipboard.writeText('Hello');

粘贴文本：

const text = await navigator.clipboard.readText();

读取图片：

const items = await navigator.clipboard.read();
for (const item of items) {
  if (item.types.includes('image/png')) {
    const blob = await item.getType('image/png');
    // 使用 blob
  }
}

权限要求：读取需要用户手势加权限授权；写入需要用户手势。

Geolocation（地理位置）

标准定位 API：

navigator.geolocation.getCurrentPosition((pos) => {
  console.log(pos.coords.latitude, pos.coords.longitude);
});

// 持续监听位置变化
const id = navigator.geolocation.watchPosition((pos) => {
  console.log(pos.coords);
});

权限要求：需要用户明确授权。

Camera / Mic（摄像头/麦克风）

获取媒体流：

const stream = await navigator.mediaDevices.getUserMedia({
  video: { facingMode: 'user' },
  audio: true,
});

videoElement.srcObject = stream;

适用场景：视频通话、二维码扫描、语音输入。

Wake Lock（屏幕唤醒锁）

保持屏幕常亮：

const wakeLock = await navigator.wakeLock.request('screen');

wakeLock.addEventListener('release', () => {
  console.log('唤醒锁已释放');
});

// 手动释放
await wakeLock.release();

适用场景：菜谱应用（做饭时不休眠）、演示文稿、导航应用。

Periodic Background Sync（周期性后台同步）

定期刷新内容：

const reg = await navigator.serviceWorker.ready;
await reg.periodicSync.register('refresh', {
  minInterval: 24 * 60 * 60 * 1000, // 最小间隔 1 天
});

Service Worker 处理：

self.addEventListener('periodicsync', (event) => {
  if (event.tag === 'refresh') {
    event.waitUntil(refreshContent());
  }
});

限制：仅 Chrome 支持，需要已安装 PWA 且用户有使用频率。

Idle Detection（空闲检测）

检测用户空闲状态：

const detector = new IdleDetector();
await detector.start({ threshold: 60000 });

detector.addEventListener('change', () => {
  console.log(detector.userState, detector.screenState);
});

适用场景：自动注销、在线状态更新（显示"离开"）。

Contact Picker（联系人选择器）

选择设备联系人：

const contacts = await navigator.contacts.select(['name', 'email'], { multiple: true });
console.log(contacts);

适用场景：邀请联系人、分享给联系人。

支持情况：仅 Chrome Android 支持。

权限体验设计

在用户操作时请求权限：用户点击按钮后再请求，而非页面加载时立即弹出。

先说明原因：弹出类似"我们需要使用摄像头来扫描二维码"的解释对话框，然后再请求。

被拒绝后不纠缠：等待数天或数周后再考虑重新引导。

提供设置指引：如果用户拒绝了权限，教用户如何在浏览器设置中重新开启。

能力检测
使用前始终先检测：


if ('share' in navigator) {
  // 使用 Web Share
} else {
  // 回退方案：复制链接
}

if ('serviceWorker' in navigator) {
  // 支持 PWA 能力
}
回退与渐进增强
许多原生 API 无法 polyfill：蓝牙、USB 等原生硬件 API 无法模拟。


可以 polyfill 的：Web Share 可回退为自定义分享菜单；Clipboard 可回退为 document.execCommand。


核心原则：渐进增强——基础功能在所有浏览器上可用，支持的平台提供更丰富的体验。


Project Fugu 追踪
持续发展中：每月都有新 API 推出，从 Chrome 实验标志 → 稳定版逐步推进。


追踪渠道：web.dev/fugu、chromestatus.com。


iOS 平台限制
Apple 对新 Web API 的采纳速度较慢：大部分 Fugu API 在 iOS 上缺失。


应对策略：使用混合应用方案（Capacitor、原生壳），或提供原生回退。


隐私与安全
权限控制：地理位置、摄像头、麦克风、蓝牙等均需用户明确授权。必须使用 HTTPS。


用户信任：不要在没有说明原因的情况下请求权限；只请求最少必要的权限。


敏感数据：未经用户同意不要将原始数据发送给第三方。


实战案例
VS Code Web：使用 File System Access 实现文件编辑。


Squoosh（Google）：在浏览器中实现图片压缩，使用 File System Access 保存结果。


Spotify Web：使用 Media Session API 支持键盘快捷键和音频焦点。


Figma：使用 WebGL + Canvas 实现设计工具，使用 File System Access 导出文件。


常见反模式
1. 页面加载立即请求权限：用户必然拒绝。


2. 不提供回退方案：Safari 用户功能失效。


3. 不解释请求原因：用户困惑不安。


4. 一次请求过多权限：给用户造成压力。


5. 不做优雅降级：API 不可用时应用崩溃。


最佳实践
1. 先检测能力再使用：if ('feature' in navigator) 是必须的。


2. 说明请求原因：告诉用户为什么需要某个权限。


3. 始终提供回退方案：不支持的浏览器不应崩溃。


4. 渐进增强：核心功能在所有平台可用，部分平台提供增强体验。


5. 多浏览器测试：Chrome、Safari、Firefox 行为各异。


6. 持续关注平台能力更新：通过 web.dev 和 caniuse.com 追踪。


小结
Project Fugu 为 Web 平台带来了大量原生能力——File System Access 让 Web 应用能真正读写本地文件，OPFS 提供应用私有的高性能文件系统，Web Bluetooth 和 Web USB 连接硬件设备，Web Share 调用系统分享菜单，Wake Lock 防止屏幕休眠，Periodic Background Sync 定期刷新内容。但各浏览器支持差异显著，Chrome 最积极、Safari 最保守。工程实践的关键在于：始终先检测能力、提供回退方案、采用渐进增强策略、在用户操作时请求权限并说明原因。这些现代 Web API 让 PWA 越来越接近原生应用的体验，但必须考虑跨浏览器兼容性和优雅降级。
