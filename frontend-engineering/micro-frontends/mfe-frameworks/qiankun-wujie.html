qiankun 与无界

核心概念

qiankun（乾坤）和无界（Wujie）是国内微前端生态中最具代表性的两个框架。qiankun 基于 single-spa 构建，提供了开箱即用的 JS 沙箱和样式隔离；无界则另辟蹊径，利用 WebComponent + iframe 的组合实现了更彻底的隔离能力。两者代表了微前端隔离方案的两个技术流派。

qiankun 沙箱机制
qiankun 的核心竞争力在于其精心设计的 JS 沙箱系统。根据使用场景不同，qiankun 提供了三种沙箱实现：SnapshotSandbox（快照沙箱，兼容 IE）、LegacySandbox（单例代理沙箱）和 ProxySandbox（多例代理沙箱）：


interface SandboxContract {
  readonly name: string;
  readonly active: () => void;
  readonly inactive: () => void;
  readonly proxy: WindowProxy;
}

type SandboxType = 'snapshot' | 'legacy' | 'proxy';

const createProxySandbox = (name: string): SandboxContract => {
  const fakeWindow = Object.create(null) as Record<string | symbol, unknown>;
  const addedPropsMap = new Map<string | symbol, unknown>();
  const modifiedPropsOriginalValueMap = new Map<string | symbol, unknown>();
  let sandboxRunning = false;

  const proxy = new Proxy(fakeWindow, {
    get: (_target, prop: string | symbol) => {
      if (prop === Symbol.unscopables) return undefined;

      if (prop in fakeWindow) {
        return fakeWindow[prop];
      }

      const value = (window as Record<string | symbol, unknown>)[prop];
      if (typeof value === 'function' && !value.prototype) {
        return value.bind(window);
      }
      return value;
    },

    set: (_target, prop: string | symbol, value: unknown) => {
      if (!sandboxRunning) return false;

      if (!fakeWindow.hasOwnProperty(prop) && window.hasOwnProperty(prop as string)) {
        const originalValue = (window as Record<string | symbol, unknown>)[prop];
        if (!modifiedPropsOriginalValueMap.has(prop)) {
          modifiedPropsOriginalValueMap.set(prop, originalValue);
        }
      } else if (!fakeWindow.hasOwnProperty(prop)) {
        addedPropsMap.set(prop, value);
      }

      fakeWindow[prop] = value;
      return true;
    },

    has: (_target, prop: string | symbol) => {
      return prop in fakeWindow || prop in window;
    },
  });

  return {
    name,
    proxy: proxy as unknown as WindowProxy,
    active: () => {
      sandboxRunning = true;
    },
    inactive: () => {
      sandboxRunning = false;
    },
  };
};

qiankun 样式隔离
qiankun 提供两种样式隔离策略：strictStyleIsolation（Shadow DOM）和 experimentalStyleIsolation（Scoped CSS）。Shadow DOM 提供最强的隔离但可能影响第三方 UI 库的弹窗定位；Scoped CSS 通过为子应用样式添加属性选择器前缀实现软隔离：


interface StyleIsolationConfig {
  readonly strictStyleIsolation?: boolean;
  readonly experimentalStyleIsolation?: boolean;
}

const scopeCSS = (styleSheet: string, appName: string): string => {
  const prefix = `div[data-qiankun="${appName}"]`;

  return styleSheet.replace(/([^{}]*)\{/g, (match, selector: string) => {
    const selectors = selector.split(',').map((s: string) => {
      const trimmed = s.trim();
      if (trimmed === 'body' || trimmed === 'html') {
        return `${prefix}`;
      }
      if (trimmed.startsWith('@') || trimmed.startsWith(':root')) {
        return trimmed;
      }
      return `${prefix} ${trimmed}`;
    });
    return `${selectors.join(', ')} {`;
  });
};

const patchDynamicStyle = (appName: string, container: HTMLElement): MutationObserver => {
  const observer = new MutationObserver((mutations) => {
    mutations.forEach((mutation) => {
      mutation.addedNodes.forEach((node) => {
        if (node instanceof HTMLStyleElement) {
          const content = node.textContent ?? '';
          node.textContent = scopeCSS(content, appName);
        }
        if (node instanceof HTMLLinkElement && node.rel === 'stylesheet') {
          fetch(node.href)
            .then((res) => res.text())
            .then((css) => {
              const style = document.createElement('style');
              style.textContent = scopeCSS(css, appName);
              node.replaceWith(style);
            });
        }
      });
    });
  });

  observer.observe(container, { childList: true, subtree: true });
  return observer;
};
无界的 WebComponent + iframe 方案
无界（Wujie）采用了一种创新的技术方案：将子应用的 JS 运行在 iframe 中以获得天然的 JS 隔离，同时通过 WebComponent 将子应用的 DOM 渲染在主应用中以保持用户体验。这种方案的精妙之处在于 iframe 提供了完整的 window 隔离，而 DOM 代理机制让子应用的 UI 无缝融入主应用：


interface WujieAppConfig {
  readonly name: string;
  readonly url: string;
  readonly el: string | HTMLElement;
  readonly alive?: boolean;
  readonly degrade?: boolean;
  readonly props?: Record<string, unknown>;
  readonly beforeLoad?: () => void;
  readonly beforeMount?: () => void;
  readonly afterMount?: () => void;
  readonly beforeUnmount?: () => void;
  readonly afterUnmount?: () => void;
}

interface WujieInstance {
  readonly iframe: HTMLIFrameElement;
  readonly shadowRoot: ShadowRoot;
  readonly bus: EventBus;
}

interface EventBus {
  readonly $on: (event: string, callback: (...args: ReadonlyArray<unknown>) => void) => void;
  readonly $emit: (event: string, ...args: ReadonlyArray<unknown>) => void;
  readonly $off: (event: string, callback?: (...args: ReadonlyArray<unknown>) => void) => void;
}

const createWujieProxy = (iframeWindow: Window, shadowRoot: ShadowRoot): void => {
  const proxyDocument = new Proxy(iframeWindow.document, {
    get: (target, prop: string) => {
      if (prop === 'querySelector' || prop === 'querySelectorAll') {
        return (...args: ReadonlyArray<unknown>) => {
          return (shadowRoot as unknown as Record<string, Function>)[prop](...args);
        };
      }
      if (prop === 'getElementById') {
        return (id: string) => shadowRoot.querySelector(`#${id}`);
      }
      if (prop === 'body' || prop === 'documentElement') {
        return shadowRoot.host;
      }
      const value = (target as unknown as Record<string, unknown>)[prop];
      if (typeof value === 'function') {
        return (value as Function).bind(target);
      }
      return value;
    },
  });

  Object.defineProperty(iframeWindow, 'document', {
    get: () => proxyDocument,
    configurable: true,
  });
};
无界的 alive 模式允许子应用在路由切换时保持运行状态而不卸载，再次激活时直接恢复之前的 DOM 和 JS 状态。这对于状态重的子应用（如编辑器、大型表单）尤其有价值：


interface AliveCache {
  readonly name: string;
  readonly iframe: HTMLIFrameElement;
  readonly shadowRoot: ShadowRoot;
  readonly state: 'active' | 'hidden';
}

const aliveCacheMap = new Map<string, AliveCache>();

const hideApp = (name: string): void => {
  const cache = aliveCacheMap.get(name);
  if (!cache) return;

  const host = cache.shadowRoot.host as HTMLElement;
  host.style.display = 'none';
  cache.iframe.contentWindow?.dispatchEvent(new CustomEvent('wujie:hide'));
};

const showApp = (name: string, container: HTMLElement): void => {
  const cache = aliveCacheMap.get(name);
  if (!cache) return;

  container.appendChild(cache.shadowRoot.host);
  const host = cache.shadowRoot.host as HTMLElement;
  host.style.display = '';
  cache.iframe.contentWindow?.dispatchEvent(new CustomEvent('wujie:show'));
};

在生产实践中，qiankun 因其成熟的生态和阿里系的广泛使用而成为国内最主流的选择。无界在强隔离场景和 Vite 兼容性上具有独特优势。对于新项目，建议评估 Module Federation 2.0 + micro-app / 无界的组合方案，兼顾模块共享和运行隔离。


小结
    

  • qiankun 基于 single-spa 扩展，通过 ProxySandbox 实现 JS 多实例隔离，配合 Shadow DOM / Scoped CSS 实现样式隔离
    • 

  • 无界利用 WebComponent + iframe 组合，iframe 提供天然 JS 隔离，DOM 代理到 Shadow DOM 保证 UI 融合
    • 

  • qiankun 的 ProxySandbox 为每个子应用创建独立 fakeWindow，支持多实例并行运行
    • 

  • 无界的 alive 模式支持子应用状态保持，路由切换时不卸载，适合状态重的应用
    • 

  • qiankun 生态最成熟、社区最活跃；无界在强隔离和 Vite 兼容性上有优势
    • 

  • 选型需综合考虑隔离强度、子应用改造成本、构建工具兼容性和团队技术偏好
    •
