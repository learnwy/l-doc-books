集成模式 简介

集成模式是微前端架构中最核心的技术决策之一，决定了各个子应用如何组合为一个统一的用户界面。不同的集成方式在隔离性、性能、开发体验和迁移成本等维度上各有取舍，选择合适的集成模式是微前端落地成功的关键。

本章系统介绍三种主要的集成方案。运行时集成方案讲解在浏览器端动态加载和组合子应用的技术，包括 JavaScript 入口加载、路由分发和生命周期管理，这是目前最灵活也最常用的集成方式。构建时集成方案介绍在构建阶段将多个子应用合并为一个部署包的方法，包括 NPM 包方式和 Monorepo 方式，适合团队规模较小或变更频率较低的场景。iframe 与 Web Components探讨利用浏览器原生隔离机制实现微前端的技术方案，分析 iframe 的天然隔离优势和 Web Components 的标准化封装能力。

建议读者先了解运行时集成作为主流方案的核心原理，再对比构建时集成理解不同场景的最优选择，最后通过 iframe 和 Web Components 理解原生浏览器方案的适用性。
