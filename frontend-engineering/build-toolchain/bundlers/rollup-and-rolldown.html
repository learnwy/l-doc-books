Rollup 与 Rolldown

Rollup：ESM 优先的库打包器

Rollup 诞生于 2015 年，是第一个以 ES Modules 为核心设计的打包器。与 Webpack 的"大而全"不同，Rollup 专注于一件事：将 ESM 模块高效地打包为各种输出格式。它的 Tree-shaking 能力是业界标杆，产出的代码更加干净和高效。

基本配置
// rollup.config.js
import resolve from '@rollup/plugin-node-resolve';
import commonjs from '@rollup/plugin-commonjs';
import typescript from '@rollup/plugin-typescript';
import terser from '@rollup/plugin-terser';
import dts from 'rollup-plugin-dts';

export default [
  {
    input: 'src/index.ts',
    output: [
      {
        file: 'dist/index.mjs',
        format: 'esm',
        sourcemap: true,
      },
      {
        file: 'dist/index.cjs',
        format: 'cjs',
        sourcemap: true,
      },
      {
        file: 'dist/index.umd.js',
        format: 'umd',
        name: 'MyLibrary',
        globals: {
          react: 'React',
          'react-dom': 'ReactDOM',
        },
      },
    ],
    external: ['react', 'react-dom'],
    plugins: [resolve(), commonjs(), typescript(), terser()],
  },
  {
    input: 'src/index.ts',
    output: { file: 'dist/index.d.ts', format: 'esm' },
    plugins: [dts()],
  },
];
Scope Hoisting
Scope Hoisting 是 Rollup 的标志性优化。它将多个模块"提升"到同一个作用域中，消除了模块间的函数包裹和闭包开销。


// src/utils.js
export function add(a, b) {
  return a + b;
}

// src/index.js
import { add } from './utils.js';
console.log(add(1, 2));
// Rollup 输出 - Scope Hoisting
function add(a, b) {
  return a + b;
}
console.log(add(1, 2));
// Webpack 输出（简化） - 模块包裹
var __webpack_modules__ = {
  './src/utils.js': (module, exports) => {
    exports.add = function (a, b) {
      return a + b;
    };
  },
};
// ... 运行时代码 ...
Rollup 的输出没有任何多余的运行时代码，模块边界被完全消除。


插件系统
Rollup 的插件接口简洁而强大，Vite 的插件系统正是基于此设计：


function myPlugin() {
  return {
    name: 'my-plugin',
    resolveId(source) {
      if (source === 'virtual-module') {
        return source;
      }
      return null;
    },
    load(id) {
      if (id === 'virtual-module') {
        return 'export default "This is virtual!"';
      }
      return null;
    },
    transform(code, id) {
      if (id.endsWith('.special')) {
        return { code: transformSpecial(code), map: null };
      }
    },
  };
}

Rolldown：Rust 驱动的下一代 Rollup
Rolldown 是 Rollup 的 Rust 重写版本，由 Vite 团队主导开发。它的目标是在保持 Rollup API 完全兼容的同时，将构建性能提升一到两个数量级。


为什么需要 Rolldown？
Rolldown 解决了 Vite 当前架构的核心痛点：开发环境使用 esbuild，生产环境使用 Rollup，两者行为不完全一致可能导致开发/生产差异。Rolldown 作为统一引擎，将在两个环境中提供一致的构建行为。

使用 Rolldown
Rolldown 的配置格式与 Rollup 高度兼容：


// rolldown.config.js
import { defineConfig } from 'rolldown';

export default defineConfig({
  input: 'src/index.ts',
  output: {
    dir: 'dist',
    format: 'esm',
    sourcemap: true,
  },
  resolve: {
    alias: {
      '@': './src',
    },
  },
});

Rollup vs Rolldown 选型指南


小结
    

  • Rollup 是 ESM 优先的库打包器，以 Tree-shaking 和 Scope Hoisting 著称。
    • 

  • Rollup 的输出代码干净高效，没有多余的运行时包裹。
    • 

  • Rollup 的插件系统是 Vite 插件系统的基础。
    • 

  • Rolldown 是 Rollup 的 Rust 重写版本，性能提升约 10 倍。
    • 

  • Rolldown 将成为 Vite 的统一构建引擎，解决开发/生产行为不一致的问题。
    • 

  • 对于库开发，Rollup/Rolldown 是比 Webpack 更优的选择。
