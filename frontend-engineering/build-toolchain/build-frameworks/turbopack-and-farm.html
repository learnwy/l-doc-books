Turbopack 与 Farm

下一代构建框架的探索

当 Webpack/Vite/Rspack 已经覆盖了大多数构建场景时，新一代构建框架仍在不断涌现。Turbopack 和 Farm 代表了两个不同的探索方向：Turbopack 选择深度集成于 Next.js 框架，以增量计算为核心理念；Farm 则是一个独立的全功能构建框架，用 Rust 从零实现，追求开发与生产的一致性体验。

Turbopack

定位与背景

Turbopack 由 Vercel 团队开发，最初由 Webpack 的作者 Tobias Koppers 主导。它的设计目标不是替代 Webpack，而是为 Next.js 提供一个极速的开发构建引擎。

核心理念：增量计算
Turbopack 的核心创新是基于增量计算（Incremental Computation）的构建模型。传统打包器在文件变更时需要重新计算整个依赖链，而 Turbopack 只重新计算受影响的最小范围。


这种模型在大型项目中优势尤为明显——当项目包含数千个模块时，单个文件的变更只需要几毫秒就能反映到浏览器。


在 Next.js 中使用
// next.config.js
export default {
  experimental: {
    turbo: {
      rules: {
        '*.svg': {
          loaders: ['@svgr/webpack'],
          as: '*.js',
        },
      },
      resolveAlias: {
        '@': './src',
      },
    },
  },
};
next dev --turbopack

架构特点


Farm
定位与背景
Farm 是一个用 Rust 编写的全功能构建框架，由国内开发者创建。与 Turbopack 深度绑定 Next.js 不同，Farm 是一个独立的通用构建工具，可以用于任何前端项目。


核心特性
Partial Bundling（部分打包）
Farm 提出了部分打包（Partial Bundling）的概念，这是介于"完全打包"和"完全不打包"之间的折中方案：


Farm 根据模块之间的依赖关系和访问模式，将模块智能分组为适量的 Bundle。这既避免了完全打包的长时间构建，又避免了完全不打包的网络瀑布流问题。


基本配置
// farm.config.ts
import { defineConfig } from '@farmfe/core';

export default defineConfig({
  compilation: {
    input: {
      index: './src/index.tsx',
    },
    output: {
      path: 'dist',
      publicPath: '/',
      targetEnv: 'browser',
    },
    resolve: {
      alias: {
        '@': './src',
      },
    },
    minify: true,
    sourcemap: true,
    partialBundling: {
      targetConcurrentRequests: 25,
      targetMinSize: 20 * 1024,
      targetMaxSize: 1500 * 1024,
    },
  },
  plugins: ['@farmfe/plugin-react', '@farmfe/plugin-sass'],
});
Vite 插件兼容
Farm 兼容大部分 Vite 插件，降低了迁移门槛：


import { defineConfig } from '@farmfe/core';
import vitePluginSvgr from 'vite-plugin-svgr';

export default defineConfig({
  vitePlugins: [vitePluginSvgr()],
});

如何选择构建框架


小结
    

  • Turbopack 以增量计算为核心，深度集成于 Next.js，开发模式下性能极佳。
    • 

  • Farm 是独立的 Rust 构建框架，提出了 Partial Bundling 的创新策略。
    • 

  • Farm 兼容 Vite 插件生态，降低了迁移成本。
    • 

  • 构建框架的选择应基于项目类型、团队技术栈和性能需求综合判断。
    • 

  • Vite 和 Rsbuild 是当前最成熟的选择，Turbopack 和 Farm 代表了未来的探索方向。
