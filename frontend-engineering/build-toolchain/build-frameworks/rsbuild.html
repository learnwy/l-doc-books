Rsbuild 构建框架

Rsbuild 概述

Rsbuild 是由字节跳动 Web Infra 团队开源的新一代构建框架。它构建在 Rspack（Rust 版 Webpack）之上，提供开箱即用的构建能力。Rsbuild 的定位是"更快的 Webpack 替代方案"——它兼容大部分 Webpack 的生态，但构建速度提升了 5-10 倍。



快速开始
创建项目
npm create rsbuild@latest

# 或使用已有项目
npm add @rsbuild/core -D
基础配置
// rsbuild.config.ts
import { defineConfig } from '@rsbuild/core';
import { pluginReact } from '@rsbuild/plugin-react';
import { pluginSass } from '@rsbuild/plugin-sass';

export default defineConfig({
  plugins: [pluginReact(), pluginSass()],
  source: {
    entry: {
      index: './src/index.tsx',
    },
    alias: {
      '@': './src',
      '@components': './src/components',
    },
  },
  output: {
    target: 'web',
    distPath: {
      root: 'dist',
      js: 'static/js',
      css: 'static/css',
      image: 'static/image',
    },
    assetPrefix: '/',
  },
  html: {
    title: 'My App',
    favicon: './public/favicon.ico',
    template: './public/index.html',
  },
});
开发和构建
{
  "scripts": {
    "dev": "rsbuild dev",
    "build": "rsbuild build",
    "preview": "rsbuild preview"
  }
}

性能优势
插件系统
Rsbuild 的插件系统灵活且类型安全：


import type { RsbuildPlugin } from '@rsbuild/core';

const myPlugin: RsbuildPlugin = {
  name: 'plugin-my-feature',
  setup(api) {
    api.modifyRsbuildConfig((config) => {
      config.html = config.html || {};
      config.html.title = 'Modified Title';
    });

    api.modifyRspackConfig((config) => {
      config.resolve = config.resolve || {};
      config.resolve.extensions = ['.ts', '.tsx', '.js', '.jsx'];
    });

    api.onAfterBuild(({ stats }) => {
      console.log('Build completed:', stats?.toJson().time, 'ms');
    });
  },
};

多环境构建
Rsbuild 支持为不同环境生成不同的构建产物：


export default defineConfig({
  environments: {
    web: {
      output: {
        target: 'web',
        distPath: { root: 'dist/web' },
      },
      source: {
        entry: { index: './src/web/index.tsx' },
      },
    },
    node: {
      output: {
        target: 'node',
        distPath: { root: 'dist/server' },
      },
      source: {
        entry: { index: './src/server/index.ts' },
      },
    },
  },
});


从 Webpack 迁移到 Rsbuild
Rsbuild 提供了平滑的迁移路径。大部分 Webpack 配置可以直接映射到 Rsbuild：


// 旧的 webpack.config.js
export default {
  entry: './src/index.tsx',
  module: {
    rules: [
      { test: /\.tsx?$/, use: 'swc-loader' },
      { test: /\.css$/, use: ['style-loader', 'css-loader'] },
    ],
  },
  resolve: {
    alias: { '@': '/src' },
  },
};

// 新的 rsbuild.config.ts - 大部分内置，配置大幅简化
export default defineConfig({
  plugins: [pluginReact()],
  source: {
    alias: { '@': './src' },
  },
});


Module Federation 支持
Rsbuild 通过 @module-federation/rsbuild-plugin 支持微前端架构：


import { defineConfig } from '@rsbuild/core';
import { pluginModuleFederation } from '@module-federation/rsbuild-plugin';

export default defineConfig({
  plugins: [
    pluginModuleFederation({
      name: 'host',
      remotes: {
        remote: 'remote@http://localhost:3001/mf-manifest.json',
      },
      shared: ['react', 'react-dom'],
    }),
  ],
});


小结
    

  • Rsbuild 是基于 Rspack 的开箱即用构建框架，构建速度比 Webpack 快 5-10 倍。
    • 

  • 内置 TypeScript、CSS Modules、PostCSS、HMR、代码分割等常用功能。
    • 

  • 插件系统类型安全，官方提供了 React/Vue/Sass/Less 等常用插件。
    • 

  • 支持多环境构建（web + node）和 Module Federation 微前端。
    • 

  • 从 Webpack 迁移路径平滑，大部分配置可直接映射或简化。
