script setup 语法糖

编译器宏概述

<script setup> 是 Vue 3.2 引入的编译时语法糖，它将整个 <script> 块编译为组件的 setup() 函数。在其中可以使用一系列编译器宏（compiler macros），这些宏无需导入、在编译时被处理。

defineProps
运行时声明
<script setup lang="ts">
const props = defineProps({
  title: { type: String, required: true },
  count: { type: Number, default: 0 },
  items: { type: Array as () => string[], default: () => [] },
});
</script>
类型声明（推荐）
<script setup lang="ts">
interface Props {
  title: string
  count?: number
  items?: string[]
  onUpdate?: (value: string) => void
}

const props = defineProps<Props>()
withDefaults
类型声明模式下使用 withDefaults 提供默认值：


<script setup lang="ts">
interface Props {
  title: string;
  count?: number;
  items?: string[];
}

const props = withDefaults(defineProps<Props>(), {
  count: 0,
  items: () => [],
});
</script>
解构 props（3.3+）
Vue 3.3+ 支持直接解构 defineProps 的返回值，编译器自动保持响应性：


<script setup lang="ts">
const { title, count = 0 } = defineProps<{
  title: string;
  count?: number;
}>();
</script>

<template>
  <h1>{{ title }}</h1>
  <span>{{ count }}</span>
</template>


defineEmits
类型声明
<script setup lang="ts">
const emit = defineEmits<{
  (e: 'change', value: string): void;
  (e: 'update:modelValue', value: number): void;
  (e: 'submit'): void;
}>();

// 3.3+ 简写语法
const emit = defineEmits<{
  change: [value: string];
  'update:modelValue': [value: number];
  submit: [];
}>();

function handleClick() {
  emit('change', 'new-value');
  emit('submit');
}
</script>


defineExpose
默认情况下，<script setup> 组件不会暴露任何内容给父组件的 ref。使用 defineExpose 显式暴露：


<!-- 子组件 ChildForm.vue -->
<script setup lang="ts">
import { ref } from 'vue';

const formData = ref({ name: '', email: '' });

function validate(): boolean {
  return formData.value.name.length > 0;
}

function reset() {
  formData.value = { name: '', email: '' };
}

defineExpose({ validate, reset });
</script>
<!-- 父组件 -->
<script setup lang="ts">
import { ref } from 'vue';
import ChildForm from './ChildForm.vue';

const formRef = ref<InstanceType<typeof ChildForm> | null>(null);

function handleSubmit() {
  if (formRef.value?.validate()) {
    console.log('表单验证通过');
  }
}
</script>

<template>
  <ChildForm ref="formRef" />
  <button @click="handleSubmit">提交</button>
</template>


defineModel（3.4+）
defineModel 简化了 v-model 的实现，无需手动声明 prop 和 emit：


<!-- 之前的写法 -->
<script setup lang="ts">
const props = defineProps<{ modelValue: string }>();
const emit = defineEmits<{ 'update:modelValue': [value: string] }>();

function updateValue(val: string) {
  emit('update:modelValue', val);
}
</script>

<!-- 使用 defineModel -->
<script setup lang="ts">
const model = defineModel<string>({ required: true });

// model 是一个 ref，可直接读写
// 写入时自动触发 update:modelValue 事件
</script>

<template>
  <input v-model="model" />
</template>
多个 v-model 绑定：


<script setup lang="ts">
const firstName = defineModel<string>('firstName', { required: true });
const lastName = defineModel<string>('lastName', { required: true });
</script>

<template>
  <input v-model="firstName" placeholder="名" />
  <input v-model="lastName" placeholder="姓" />
</template>


顶层 await
<script setup> 支持顶层 await，组件会自动成为异步组件，需配合 <Suspense> 使用：


<script setup lang="ts">
interface Post {
  id: number;
  title: string;
  body: string;
}

const response = await fetch('/api/posts/1');
const post: Post = await response.json();
</script>

<template>
  <article>
    <h1>{{ post.title }}</h1>
    <p>{{ post.body }}</p>
  </article>
</template>


泛型组件（3.3+）
使用 generic 属性定义泛型组件：


<script setup lang="ts" generic="T extends { id: number }">
interface Props {
  items: T[];
  selected?: T;
}

const props = defineProps<Props>();
const emit = defineEmits<{
  select: [item: T];
}>();
</script>

<template>
  <ul>
    <li v-for="item in items" :key="item.id" @click="emit('select', item)">
      <slot :item="item" />
    </li>
  </ul>
</template>


小结
    

  • <script setup> 是编译时语法糖，顶层绑定自动暴露给模板
    • 

  • defineProps 推荐使用类型声明模式，配合 withDefaults 设置默认值
    • 

  • defineEmits 支持 3.3+ 简写语法，类型更直观
    • 

  • defineExpose 控制组件公共 API，仅暴露必要的方法和属性
    • 

  • defineModel（3.4+）大幅简化 v-model 实现
    • 

  • 顶层 await 使组件自动变为异步组件，需 <Suspense> 包裹
    • 

  • 泛型组件（3.3+）通过 generic 属性实现类型参数化
    •
