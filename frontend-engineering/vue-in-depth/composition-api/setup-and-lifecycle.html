setup 与生命周期

Composition API 的入口

setup 是 Vue 3 Composition API 的核心入口。它在组件实例创建之后、beforeCreate 之前执行，是所有组合式逻辑的起点。在 <script setup> 语法糖中，整个 <script> 块就是 setup 函数的体。



setup 函数
基本形式
setup 函数接收两个参数：props 和 context：


import { ref, onMounted } from 'vue';

export default {
  props: {
    title: String,
  },
  setup(props, { attrs, slots, emit, expose }) {
    const count = ref<number>(0);

    function increment() {
      count.value++;
    }

    onMounted(() => {
      console.log(`${props.title} 已挂载`);
    });

    return { count, increment };
  },
};
script setup 语法糖
<script setup> 是 setup 函数的编译时语法糖，更简洁且性能更好：


<script setup lang="ts">
import { ref, onMounted } from 'vue';

const props = defineProps<{ title: string }>();
const emit = defineEmits<{ (e: 'update', value: number): void }>();

const count = ref<number>(0);

function increment() {
  count.value++;
  emit('update', count.value);
}

onMounted(() => {
  console.log(`${props.title} 已挂载`);
});
</script>

生命周期钩子
Vue 3 提供了一组 on* 前缀的生命周期钩子函数，只能在 setup 中调用：


import {
  onBeforeMount,
  onMounted,
  onBeforeUpdate,
  onUpdated,
  onBeforeUnmount,
  onUnmounted,
  onActivated,
  onDeactivated,
  onErrorCaptured,
} from 'vue';

onBeforeMount(() => {
  console.log('DOM 即将挂载');
});

onMounted(() => {
  console.log('DOM 已挂载，可访问 DOM 元素');
});

onBeforeUpdate(() => {
  console.log('响应式数据变化，DOM 即将更新');
});

onUpdated(() => {
  console.log('DOM 已更新');
});

onBeforeUnmount(() => {
  console.log('组件即将卸载，清理定时器/监听器');
});

onUnmounted(() => {
  console.log('组件已卸载');
});

getCurrentInstance
getCurrentInstance 用于获取当前组件实例，主要用于库开发和高级场景：


import { getCurrentInstance, onMounted } from 'vue';

const instance = getCurrentInstance();

onMounted(() => {
  console.log(instance?.proxy?.$el);
  console.log(instance?.appContext.config.globalProperties);
});


提示： getCurrentInstance 只能在 setup 或生命周期钩子中调用。在生产代码中应尽量避免使用它，优先通过 inject / provide 传递上下文。






小结
    

  • setup 是 Composition API 的入口，在 beforeCreate 之前执行
    • 

  • <script setup> 是编译时语法糖，顶层变量自动暴露给模板，性能更优

  • 生命周期钩子使用 on* 前缀函数，只能在 setup 上下文中注册
    • 

  • 父子组件遵循 外→内挂载、内→外卸载 的执行顺序
