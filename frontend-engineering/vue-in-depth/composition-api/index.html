组合式 API 简介

组合式 API 是 Vue 3 最重要的架构创新。选项式 API 按照 data、methods、computed 等选项类型来组织代码，当组件逻辑日趋复杂时，同一功能的代码被分散到不同选项中，维护成本急剧上升。组合式 API 允许你按照逻辑关注点组织代码，将相关的状态、计算属性和方法聚合在一起，并且天然支持逻辑的提取与复用。理解组合式 API 的设计动机和使用模式，是用好现代 Vue 的关键。

第一节"setup 与生命周期"建立组合式 API 的核心认知。setup 函数的执行时机与上下文参数、组合式 API 中生命周期钩子的注册方式与调用顺序、setup 的返回值如何暴露给模板、以及 setup 与选项式 API 共存时的优先级规则——setup 是组合式 API 的入口，理解它的运行机制是掌握后续所有模式的基础。

第二节"Composables 模式"探索 Vue 3 中最强大的逻辑复用范式。Composable 函数的命名约定与设计原则、如何将复杂组件逻辑拆分为可组合的独立函数、Composable 的参数设计与返回值规范、以及与 React Hooks 在设计理念上的异同——Composables 让你像搭积木一样组合逻辑，是替代 Vue 2 中 Mixin 的最佳方案。

第三节"provide/inject"深入 Vue 的依赖注入机制。provide 与 inject 的跨层级数据传递原理、响应式数据在 provide/inject 链路中的表现、Symbol 作为注入键的类型安全实践、以及依赖注入与 Props 逐层传递的适用场景对比——provide/inject 是构建组件库和复合组件模式的重要底层能力。

第四节"script setup"解析 Vue 单文件组件中最简洁的语法形式。script setup 的编译时转换原理、defineProps 与 defineEmits 的宏函数机制、顶层 await 的异步组件支持、以及 defineExpose 对组件公开接口的控制——script setup 不仅减少了样板代码，更通过编译时优化带来了运行时性能的提升。
