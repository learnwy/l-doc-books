Composables 模式

什么是 Composable

Composable（组合式函数）是 Vue 3 Composition API 中最重要的代码复用模式。它是一个利用 Vue 响应式 API 封装和复用有状态逻辑的函数，以 use 为前缀命名。



提取 Composable
从组件中提取
当多个组件共享相同的逻辑时，将其提取为 composable：


<!-- ❌ 重复逻辑散布在各组件中 -->
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue';

const x = ref<number>(0);
const y = ref<number>(0);

function update(e: MouseEvent) {
  x.value = e.pageX;
  y.value = e.pageY;
}

onMounted(() => window.addEventListener('mousemove', update));
onUnmounted(() => window.removeEventListener('mousemove', update));
</script>
// ✅ 提取为 composable: composables/useMouse.ts
import { ref, onMounted, onUnmounted, type Ref } from 'vue';

interface MousePosition {
  x: Ref<number>;
  y: Ref<number>;
}

export function useMouse(): MousePosition {
  const x = ref<number>(0);
  const y = ref<number>(0);

  function update(e: MouseEvent) {
    x.value = e.pageX;
    y.value = e.pageY;
  }

  onMounted(() => window.addEventListener('mousemove', update));
  onUnmounted(() => window.removeEventListener('mousemove', update));

  return { x, y };
}
<!-- 使用 composable -->
<script setup lang="ts">
import { useMouse } from '@/composables/useMouse';

const { x, y } = useMouse();
</script>

<template>
  <p>鼠标位置：{{ x }}, {{ y }}</p>
</template>

返回值模式
返回对象（推荐）
export function useCounter(initial = 0) {
  const count = ref<number>(initial);
  const doubled = computed<number>(() => count.value * 2);

  function increment() {
    count.value++;
  }
  function decrement() {
    count.value--;
  }
  function reset() {
    count.value = initial;
  }

  return { count, doubled, increment, decrement, reset };
}

// 使用时可按需解构
const { count, increment } = useCounter(10);
接受响应式参数
为了使 composable 能够响应外部数据变化，应支持接受 ref 或 getter 作为参数：


import { ref, watch, unref, type Ref, type MaybeRef } from 'vue';

interface UseFetchReturn<T> {
  data: Ref<T | null>;
  error: Ref<Error | null>;
  loading: Ref<boolean>;
}

export function useFetch<T = unknown>(url: MaybeRef<string>): UseFetchReturn<T> {
  const data = ref<T | null>(null) as Ref<T | null>;
  const error = ref<Error | null>(null);
  const loading = ref<boolean>(false);

  async function doFetch() {
    loading.value = true;
    error.value = null;
    try {
      const response = await fetch(unref(url));
      data.value = await response.json();
    } catch (e) {
      error.value = e as Error;
    } finally {
      loading.value = false;
    }
  }

  watch(() => unref(url), doFetch, { immediate: true });

  return { data, error, loading };
}


状态共享
局部状态（默认）
每次调用 composable 都创建独立的状态实例：


// 每个组件获得独立的 count
const { count: countA } = useCounter();
const { count: countB } = useCounter();
// countA 和 countB 互不影响
全局共享状态
将状态提升到模块作用域实现跨组件共享：


import { ref, readonly } from 'vue';

const globalCount = ref<number>(0);

export function useSharedCounter() {
  function increment() {
    globalCount.value++;
  }
  function decrement() {
    globalCount.value--;
  }

  return {
    count: readonly(globalCount),
    increment,
    decrement,
  };
}

小结
    

  • Composable 是以 use 为前缀、封装有状态逻辑的函数，是 Vue 3 代码复用的核心模式
    • 

  • 使用 MaybeRef 类型接受灵活的参数，支持响应式和普通值
    • 

  • 返回对象中使用 ref 保持解构后的响应性
    • 

  • 模块作用域状态实现全局共享，readonly 保护外部只读访问
    • 

  • VueUse 生态提供了丰富的即用型 composable，避免重复造轮子
