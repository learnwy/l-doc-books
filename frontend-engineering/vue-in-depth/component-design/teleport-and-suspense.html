Teleport 与 Suspense

打破组件树限制

Vue 3 引入了两个内置组件来解决组件渲染位置和异步加载的问题：<Teleport> 将内容渲染到 DOM 树的任意位置，<Suspense> 协调异步组件的加载流程。



Teleport 基础
<Teleport> 将其内部内容"传送"到目标 DOM 元素中，同时保留组件树中的逻辑父子关系：


<script setup lang="ts">
import { ref } from 'vue';

const showModal = ref<boolean>(false);
</script>

<template>
  <button @click="showModal = true">打开弹窗</button>

  <Teleport to="body">
    <div v-if="showModal" class="modal-overlay" @click.self="showModal = false">
      <div class="modal-content">
        <h2>弹窗标题</h2>
        <p>弹窗内容会被渲染到 body 下，但仍然可以访问父组件的数据。</p>
        <p>showModal: {{ showModal }}</p>
        <button @click="showModal = false">关闭</button>
      </div>
    </div>
  </Teleport>
</template>
Teleport 属性




属性
类型
说明





to
string | HTMLElement
目标容器（CSS 选择器或 DOM 元素）




disabled
boolean
禁用传送，内容在原位渲染





<script setup lang="ts">
import { ref } from 'vue';

const isMobile = ref<boolean>(window.innerWidth < 768);
</script>

<template>
  <!-- 移动端在原位渲染，桌面端传送到 body -->
  <Teleport to="body" :disabled="isMobile">
    <div class="sidebar">侧边栏内容</div>
  </Teleport>
</template>
多个 Teleport 到同一目标
多个 <Teleport> 可以传送到同一目标，按顺序追加：


<template>
  <Teleport to="#notifications">
    <div class="toast">通知 1</div>
  </Teleport>
  <Teleport to="#notifications">
    <div class="toast">通知 2</div>
  </Teleport>
</template>


Teleport 实战场景
全局通知系统
<!-- NotificationProvider.vue -->
<script setup lang="ts">
import { provide, ref, type InjectionKey } from 'vue';

interface Notification {
  id: number;
  message: string;
  type: 'success' | 'error' | 'info';
}

interface NotificationContext {
  notifications: typeof notifications;
  add: (msg: string, type?: Notification['type']) => void;
  remove: (id: number) => void;
}

export const NotificationKey: InjectionKey<NotificationContext> = Symbol();

const notifications = ref<Notification[]>([]);
let nextId = 0;

function add(message: string, type: Notification['type'] = 'info') {
  const id = nextId++;
  notifications.value.push({ id, message, type });
  setTimeout(() => remove(id), 3000);
}

function remove(id: number) {
  notifications.value = notifications.value.filter((n) => n.id !== id);
}

provide(NotificationKey, { notifications, add, remove });
</script>

<template>
  <slot />
  <Teleport to="body">
    <div class="notification-container">
      <TransitionGroup name="notification">
        <div v-for="n in notifications" :key="n.id" :class="['notification', `notification--${n.type}`]">
          {{ n.message }}
        </div>
      </TransitionGroup>
    </div>
  </Teleport>
</template>


Suspense 深入
异步 setup
使用顶层 await 的组件会被视为异步组件，必须由 <Suspense> 包裹：


<!-- AsyncProfile.vue -->
<script setup lang="ts">
interface UserProfile {
  name: string;
  avatar: string;
  bio: string;
}

const res = await fetch('/api/profile');
const profile: UserProfile = await res.json();
</script>

<template>
  <div class="profile">
    <img :src="profile.avatar" :alt="profile.name" />
    <h2>{{ profile.name }}</h2>
    <p>{{ profile.bio }}</p>
  </div>
</template>
fallback 内容
<template>
  <Suspense>
    <AsyncProfile />
    <template #fallback>
      <div class="skeleton">
        <div class="skeleton-avatar" />
        <div class="skeleton-text" />
        <div class="skeleton-text short" />
      </div>
    </template>
  </Suspense>
</template>
嵌套 Suspense
<template>
  <Suspense>
    <template #default>
      <AsyncLayout>
        <!-- 内层 Suspense 独立管理自己的异步状态 -->
        <Suspense>
          <AsyncContent />
          <template #fallback>
            <p>内容加载中...</p>
          </template>
        </Suspense>
      </AsyncLayout>
    </template>
    <template #fallback>
      <p>布局加载中...</p>
    </template>
  </Suspense>
</template>


错误处理
<Suspense> 本身不处理错误，需要配合 onErrorCaptured 或 <ErrorBoundary>：


<script setup lang="ts">
import { ref, onErrorCaptured } from 'vue';

const error = ref<Error | null>(null);

onErrorCaptured((err) => {
  error.value = err as Error;
  return false;
});
</script>

<template>
  <div v-if="error" class="error-state">
    <p>加载失败：{{ error.message }}</p>
    <button @click="error = null">重试</button>
  </div>

  <Suspense v-else>
    <AsyncPage />
    <template #fallback>
      <LoadingSkeleton />
    </template>
  </Suspense>
</template>


小结
    

  • <Teleport> 将内容渲染到 DOM 的任意位置，适用于弹窗、通知、全局浮层等场景
    • 

  • to 属性接受 CSS 选择器或 DOM 元素，disabled 可条件性禁用传送
    • 

  • 多个 <Teleport> 可传送到同一目标，按声明顺序追加
    • 

  • <Suspense> 协调异步组件（顶层 await）的加载状态，通过 #fallback 显示加载 UI
    • 

  • 嵌套 <Suspense> 允许不同区域独立管理各自的异步加载状态
    • 

  • 错误处理需配合 onErrorCaptured 实现，<Suspense> 本身不捕获错误
    •
