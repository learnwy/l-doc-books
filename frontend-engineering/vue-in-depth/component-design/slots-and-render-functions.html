插槽与渲染函数

内容分发机制

Vue 的插槽（Slots）系统允许父组件向子组件传递模板内容，是构建灵活、可复用组件的核心机制。渲染函数（Render Functions）则提供了 JavaScript 层面的完全控制能力。



具名插槽
子组件通过 <slot name="xxx"> 定义多个插槽出口，父组件通过 v-slot:xxx 或 #xxx 传递对应内容：


<!-- 子组件 AppLayout.vue -->
<template>
  <div class="layout">
    <header>
      <slot name="header" />
    </header>
    <main>
      <slot />
    </main>
    <footer>
      <slot name="footer" />
    </footer>
  </div>
</template>
<!-- 父组件 -->
<template>
  <AppLayout>
    <template #header>
      <h1>页面标题</h1>
    </template>

    <p>这是默认插槽的内容</p>

    <template #footer>
      <p>版权所有 © 2026</p>
    </template>
  </AppLayout>
</template>


作用域插槽
作用域插槽允许子组件向插槽传递数据，让父组件自定义渲染逻辑：


<!-- 子组件 DataList.vue -->
<script setup lang="ts">
interface Item {
  id: number;
  name: string;
  status: 'active' | 'inactive';
}

defineProps<{ items: Item[] }>();
</script>

<template>
  <ul>
    <li v-for="item in items" :key="item.id">
      <slot name="item" :item="item" :index="items.indexOf(item)">
        {{ item.name }}
      </slot>
    </li>
  </ul>
</template>
<!-- 父组件 -->
<template>
  <DataList :items="items">
    <template #item="{ item, index }">
      <span>{{ index + 1 }}. {{ item.name }}</span>
      <span :class="item.status">{{ item.status }}</span>
    </template>
  </DataList>
</template>


类型化插槽（3.3+）
使用 defineSlots 为插槽提供类型约束：


<script setup lang="ts">
interface Item {
  id: number;
  name: string;
}

defineProps<{ items: Item[] }>();

defineSlots<{
  default(props: { items: Item[] }): void;
  item(props: { item: Item; index: number }): void;
  empty(): void;
}>();
</script>


h() 渲染函数
h() 函数用于在 JavaScript 中创建虚拟 DOM 节点，提供比模板更灵活的控制：


import { h, ref, defineComponent } from 'vue';

export default defineComponent({
  props: {
    level: { type: Number, required: true, validator: (v: number) => v >= 1 && v <= 6 },
  },
  setup(props, { slots }) {
    return () => h(`h${props.level}`, { class: 'heading' }, slots.default?.());
  },
});

h() 函数签名
function h(
  type: string | Component,
  props?: Record<string, any> | null,
  children?: string | VNode | VNode[] | (() => VNode[]),
): VNode;

// 原生元素
h('div', { class: 'container' }, [h('h1', null, '标题'), h('p', null, '内容')]);

// 组件
h(MyComponent, {
  modelValue: value.value,
  'onUpdate:modelValue': (v: string) => {
    value.value = v;
  },
});


JSX in Vue
Vue 支持使用 JSX 语法编写渲染逻辑，需要安装 @vitejs/plugin-vue-jsx：


import { defineComponent, ref } from 'vue';

interface TabItem {
  key: string;
  label: string;
  content: () => JSX.Element;
}

export default defineComponent({
  setup() {
    const activeTab = ref<string>('home');
    const tabs: TabItem[] = [
      { key: 'home', label: '首页', content: () => <p>欢迎回来</p> },
      { key: 'profile', label: '个人', content: () => <p>个人信息</p> },
      { key: 'settings', label: '设置', content: () => <p>系统设置</p> },
    ];

    return () => (
      <div class="tabs">
        <nav>
          {tabs.map((tab) => (
            <button
              key={tab.key}
              class={{ active: activeTab.value === tab.key }}
              onClick={() => {
                activeTab.value = tab.key;
              }}
            >
              {tab.label}
            </button>
          ))}
        </nav>
        <div class="tab-content">{tabs.find((t) => t.key === activeTab.value)?.content()}</div>
      </div>
    );
  },
});


函数式组件
无状态的函数式组件可以直接定义为一个函数：


import type { FunctionalComponent } from 'vue'

interface BadgeProps {
  type: 'success' | 'warning' | 'error'
  text: string
}

const Badge: FunctionalComponent<BadgeProps> = (props, { slots }) => {
  return (
    <span class={`badge badge--${props.type}`}>
      {slots.default?.() ?? props.text}
    </span>
  )
}

Badge.props = {
  type: { type: String, required: true },
  text: { type: String, default: '' }
}

export default Badge


小结
    

  • 具名插槽通过 name 属性定义多个内容分发点，#name 缩写语法更简洁
    • 

  • 作用域插槽允许子组件向父组件暴露数据，实现"反向控制"渲染
    • 

  • defineSlots（3.3+）为插槽提供 TypeScript 类型约束
    • 

  • h() 渲染函数提供完全的 JavaScript 编程能力，适合动态性强的场景
    • 

  • JSX 在 Vue 中通过 @vitejs/plugin-vue-jsx 支持，兼具可读性和灵活性
    • 

  • 函数式组件适合无状态的纯展示组件，开销更小
