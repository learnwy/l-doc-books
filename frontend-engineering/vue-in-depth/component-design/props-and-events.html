Props 与事件

组件通信基础

Props 和事件是 Vue 组件间最基本的通信方式，遵循单向数据流原则：props 向下传递数据，事件向上传递消息。



Props 验证
类型声明
在 <script setup> 中使用 TypeScript 接口声明 props 类型：


<script setup lang="ts">
interface Props {
  title: string;
  count?: number;
  status: 'active' | 'inactive' | 'pending';
  items: Array<{ id: number; name: string }>;
  callback?: (value: string) => void;
}

const props = withDefaults(defineProps<Props>(), {
  count: 0,
  items: () => [],
});
</script>
运行时验证
当需要更复杂的验证逻辑时，使用运行时声明：


<script setup lang="ts">
const props = defineProps({
  score: {
    type: Number,
    required: true,
    validator: (value: number) => value >= 0 && value <= 100,
  },
  email: {
    type: String,
    validator: (value: string) => /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value),
  },
});
</script>

v-model
基本 v-model
v-model 是 modelValue prop 和 update:modelValue 事件的语法糖：


<!-- 父组件 -->
<template>
  <CustomInput v-model="searchText" />
  <!-- 等价于 -->
  <CustomInput :model-value="searchText" @update:model-value="searchText = $event" />
</template>
<!-- 子组件 CustomInput.vue -->
<script setup lang="ts">
const model = defineModel<string>({ required: true });
</script>

<template>
  <input :value="model" @input="model = ($event.target as HTMLInputElement).value" />
</template>
多个 v-model
一个组件可以绑定多个 v-model：


<!-- 父组件 -->
<script setup lang="ts">
import { ref } from 'vue';

const first = ref<string>('');
const last = ref<string>('');
</script>

<template>
  <UserForm v-model:first-name="first" v-model:last-name="last" />
</template>
<!-- 子组件 UserForm.vue -->
<script setup lang="ts">
const firstName = defineModel<string>('firstName', { required: true });
const lastName = defineModel<string>('lastName', { required: true });
</script>

<template>
  <input v-model="firstName" placeholder="名" />
  <input v-model="lastName" placeholder="姓" />
</template>
v-model 修饰符
<script setup lang="ts">
const [model, modifiers] = defineModel<string>({
  set(value) {
    if (modifiers.capitalize) {
      return value.charAt(0).toUpperCase() + value.slice(1);
    }
    return value;
  },
});
</script>
<!-- 使用修饰符 -->
<template>
  <CustomInput v-model.capitalize="text" />
</template>


事件声明
defineEmits
<script setup lang="ts">
const emit = defineEmits<{
  change: [value: string];
  delete: [id: number];
  submit: [data: { name: string; email: string }];
}>();

function handleSubmit() {
  emit('submit', { name: 'Alice', email: 'alice@example.com' });
}

function handleDelete(id: number) {
  emit('delete', id);
}
</script>
事件验证
事件也可以进行运行时验证：


<script setup lang="ts">
const emit = defineEmits({
  submit(data: { name: string; email: string }) {
    return data.name.length > 0 && data.email.includes('@');
  },
  change(value: string) {
    return value.length <= 100;
  },
});
</script>


事件设计最佳实践




实践
说明





使用过去式命名
deleted 而非 delete（已完成的动作）




使用现在时命名
update:xxx（正在发生的变化）




携带必要数据
事件应包含接收方需要的所有信息




避免过度 emit
相关数据合并为一次 emit





<script setup lang="ts">
const emit = defineEmits<{
  'update:filters': [filters: FilterState];
  selected: [item: ListItem];
  'page-changed': [page: number, size: number];
}>();
</script>


小结
    

  • Props 使用类型声明模式获得完整 TypeScript 支持，withDefaults 设置默认值
    • 

  • 运行时声明支持 validator 函数，适合复杂验证场景
    • 

  • v-model 是 prop + emit 的语法糖，defineModel（3.4+）大幅简化实现
    • 

  • 一个组件支持多个 v-model 绑定，通过参数名区分
    • 

  • defineEmits 声明组件的事件契约，支持类型安全和运行时验证
    • 

  • 遵循单向数据流：props 向下、events 向上
    •
