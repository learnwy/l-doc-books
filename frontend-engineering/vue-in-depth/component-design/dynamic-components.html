动态组件

组件动态切换

Vue 提供了 <component :is> 内置指令来实现组件的动态渲染，配合 <KeepAlive>、异步组件和 <Suspense> 可以构建高效灵活的界面。



component :is
<component :is> 根据传入的组件名或组件对象动态渲染不同组件：


<script setup lang="ts">
import { ref, shallowRef, type Component } from 'vue';
import TabHome from './TabHome.vue';
import TabProfile from './TabProfile.vue';
import TabSettings from './TabSettings.vue';

interface Tab {
  name: string;
  label: string;
  component: Component;
}

const tabs: Tab[] = [
  { name: 'home', label: '首页', component: TabHome },
  { name: 'profile', label: '个人资料', component: TabProfile },
  { name: 'settings', label: '设置', component: TabSettings },
];

const activeTab = shallowRef<Component>(TabHome);
</script>

<template>
  <div class="tabs">
    <button
      v-for="tab in tabs"
      :key="tab.name"
      :class="{ active: activeTab === tab.component }"
      @click="activeTab = tab.component"
    >
      {{ tab.label }}
    </button>
    <component :is="activeTab" />
  </div>
</template>


提示： 使用 shallowRef 存储组件引用，避免 reactive 对组件对象进行不必要的深层代理。






KeepAlive
默认情况下，切换 <component :is> 时旧组件会被销毁。<KeepAlive> 可以缓存非活跃组件实例，保留其状态：


<template>
  <KeepAlive>
    <component :is="activeTab" />
  </KeepAlive>
</template>
缓存控制




属性
说明
示例





include
只缓存匹配的组件
include="TabHome,TabProfile"




exclude
排除匹配的组件
exclude="TabSettings"




max
最大缓存实例数（LRU）
max="5"





<script setup lang="ts">
import { ref } from 'vue';

const includeList = ref<string[]>(['TabHome', 'TabProfile']);
</script>

<template>
  <KeepAlive :include="includeList" :max="10">
    <component :is="activeTab" />
  </KeepAlive>
</template>
KeepAlive 生命周期
<script setup lang="ts">
import { onActivated, onDeactivated } from 'vue';

onActivated(() => {
  console.log('组件被激活，刷新数据');
  fetchLatestData();
});

onDeactivated(() => {
  console.log('组件被缓存，暂停轮询');
  stopPolling();
});
</script>


异步组件
使用 defineAsyncComponent 实现组件的懒加载，减小初始包体积：


import { defineAsyncComponent } from 'vue';

const AsyncDashboard = defineAsyncComponent(() => import('./Dashboard.vue'));

const AsyncChart = defineAsyncComponent({
  loader: () => import('./HeavyChart.vue'),
  loadingComponent: LoadingSpinner,
  errorComponent: ErrorDisplay,
  delay: 200,
  timeout: 10000,
  onError(error, retry, fail, attempts) {
    if (attempts <= 3) {
      retry();
    } else {
      fail();
    }
  },
});

Suspense
<Suspense> 是 Vue 3 的内置组件，用于协调异步组件树的加载状态：


<template>
  <Suspense>
    <template #default>
      <AsyncDashboard />
    </template>
    <template #fallback>
      <div class="loading">
        <LoadingSpinner />
        <p>加载中...</p>
      </div>
    </template>
  </Suspense>
</template>
Suspense 事件
<template>
  <Suspense @pending="onPending" @resolve="onResolve" @fallback="onFallback">
    <AsyncPage />
    <template #fallback>
      <LoadingSkeleton />
    </template>
  </Suspense>
</template>


组合使用
将动态组件、KeepAlive、异步组件和 Suspense 结合使用：


<script setup lang="ts">
import { shallowRef, defineAsyncComponent, type Component } from 'vue';

const tabs: Record<string, Component> = {
  overview: defineAsyncComponent(() => import('./TabOverview.vue')),
  analytics: defineAsyncComponent(() => import('./TabAnalytics.vue')),
  reports: defineAsyncComponent(() => import('./TabReports.vue')),
};

const currentTab = shallowRef<string>('overview');
</script>

<template>
  <nav>
    <button v-for="(_, name) in tabs" :key="name" @click="currentTab = name">
      {{ name }}
    </button>
  </nav>

  <KeepAlive :max="5">
    <Suspense :key="currentTab">
      <component :is="tabs[currentTab]" />
      <template #fallback>
        <p>加载中...</p>
      </template>
    </Suspense>
  </KeepAlive>
</template>


小结
    

  • <component :is> 根据变量动态渲染不同组件，用 shallowRef 存储组件引用
    • 

  • <KeepAlive> 缓存非活跃组件实例，支持 include/exclude/max 缓存策略
    • 

  • 被缓存的组件使用 onActivated/onDeactivated 生命周期管理资源
    • 

  • defineAsyncComponent 实现组件懒加载，支持加载/错误/超时/重试配置
    • 

  • <Suspense> 协调异步组件的加载状态，提供 #fallback 显示加载中内容
    • 

  • 四者组合使用可构建高性能、用户体验良好的动态界面
    •
