SSR（服务端渲染）
每次请求时在服务端渲染 HTML，适合需要 SEO 和动态内容的场景：


// nuxt.config.ts
export default defineNuxtConfig({
  ssr: true,
});


SSG（静态站点生成）
构建时预渲染所有页面为静态 HTML：


// nuxt.config.ts
export default defineNuxtConfig({
  // 使用 npx nuxi generate 命令
  nitro: {
    prerender: {
      routes: ['/'],
      crawlLinks: true,
    },
  },
});
# 生成静态站点
npx nuxi generate

# 输出到 .output/public/
# 可直接部署到任何静态托管服务


ISR（增量静态再生）
结合 SSG 的速度和 SSR 的实时性，页面在一定时间后重新生成：


// nuxt.config.ts
export default defineNuxtConfig({
  routeRules: {
    '/': { prerender: true },
    '/blog/**': { isr: 3600 },
    '/products/**': { isr: 600 },
    '/admin/**': { ssr: false },
    '/api/**': { cors: true },
  },
});


Nitro 引擎
Nitro 是 Nuxt 3 的服务器引擎，支持跨平台部署：


// nuxt.config.ts
export default defineNuxtConfig({
  nitro: {
    preset: 'node-server',
    compressPublicAssets: true,
    minify: true,
  },
});

Docker 部署
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npx nuxi build

FROM node:20-alpine AS runner
WORKDIR /app
COPY --from=builder /app/.output .output
ENV HOST=0.0.0.0
ENV PORT=3000
EXPOSE 3000
CMD ["node", ".output/server/index.mjs"]

小结
    

  • Nuxt 3 支持 SSR、SSG、ISR、SPA 和混合渲染模式
    • 

  • routeRules 允许为不同路由配置不同的渲染策略
    • 

  • Nitro 引擎通过 preset 支持跨平台部署：Vercel、Cloudflare、AWS、Docker 等
    • 

  • ISR 结合静态生成速度与服务端渲染的数据实时性，适合内容类网站
    • 

  • Edge Rendering 将渲染逻辑部署到边缘节点，大幅降低全球用户的访问延迟
    • 

  • Docker 部署使用多阶段构建，最终镜像仅包含 .output 产物
    •
