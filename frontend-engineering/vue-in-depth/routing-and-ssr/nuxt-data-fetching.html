Nuxt 数据获取

数据获取策略

Nuxt 3 提供了多种数据获取方式，每种适用于不同场景。核心 API 包括 useFetch、useAsyncData 和 $fetch。



useFetch
useFetch 是 Nuxt 中最常用的数据获取方式，它包装了 useAsyncData + $fetch，支持 SSR 和客户端请求：


<script setup lang="ts">
interface Post {
  id: number;
  title: string;
  body: string;
  createdAt: string;
}

const { data, status, error, refresh } = await useFetch<Post[]>('/api/posts', {
  query: { page: 1, limit: 10 },
  headers: { 'Accept-Language': 'zh-CN' },
});
</script>

<template>
  <div>
    <div v-if="status === 'pending'">加载中...</div>
    <div v-else-if="error">错误：{{ error.message }}</div>
    <ul v-else>
      <li v-for="post in data" :key="post.id">
        {{ post.title }}
      </li>
    </ul>
    <button @click="refresh()">刷新</button>
  </div>
</template>

监听参数变化
<script setup lang="ts">
const page = ref<number>(1);
const category = ref<string>('all');

const { data: posts } = await useFetch<Post[]>('/api/posts', {
  query: { page, category },
  watch: [page, category],
});
</script>


useAsyncData
useAsyncData 提供更灵活的控制，适合自定义数据获取逻辑：


<script setup lang="ts">
const { data: user } = await useAsyncData('user-profile', () => $fetch<User>('/api/user/me'));

const { data: stats } = await useAsyncData(
  'dashboard-stats',
  async () => {
    const [visits, orders, revenue] = await Promise.all([
      $fetch<number>('/api/stats/visits'),
      $fetch<number>('/api/stats/orders'),
      $fetch<number>('/api/stats/revenue'),
    ]);
    return { visits, orders, revenue };
  },
  {
    transform: (raw) => ({
      ...raw,
      revenueFormatted: `¥${raw.revenue.toLocaleString()}`,
    }),
  },
);
</script>

$fetch
$fetch 是 Nuxt 基于 ofetch 的底层 HTTP 客户端，可在客户端和服务端通用：


// 服务端 API 中使用
// server/api/enriched-posts.ts
export default defineEventHandler(async () => {
  const posts = await $fetch<Post[]>('https://jsonplaceholder.typicode.com/posts');

  return posts.map((post) => ({
    ...post,
    excerpt: post.body.slice(0, 100),
  }));
});
<!-- 客户端事件处理中使用（非 SSR） -->
<script setup lang="ts">
async function submitForm(data: FormData) {
  try {
    const result = await $fetch('/api/submit', {
      method: 'POST',
      body: data,
    });
    console.log('提交成功:', result);
  } catch (error) {
    console.error('提交失败:', error);
  }
}
</script>


提示： 在组件 setup 中直接使用 $fetch 会导致数据在 SSR 和客户端各获取一次。应使用 useFetch 或 useAsyncData 包裹，确保 SSR 时获取的数据能自动传递到客户端。






缓存策略
const { data } = await useFetch<Config>('/api/config', {
  key: 'app-config',
  getCachedData: (key, nuxtApp) => {
    return nuxtApp.payload.data[key] || nuxtApp.static.data[key];
  },
});
手动控制刷新
<script setup lang="ts">
const { data, refresh, status } = await useFetch<Post[]>('/api/posts');

async function handleRefresh() {
  await refresh();
}

// 定时刷新
const { pause, resume } = useIntervalFn(refresh, 30000);
</script>


错误处理
组件级错误处理
<script setup lang="ts">
const { data, error } = await useFetch<Product[]>('/api/products');

if (error.value) {
  throw createError({
    statusCode: error.value.statusCode ?? 500,
    statusMessage: error.value.message,
  });
}
</script>
全局错误页面
<!-- error.vue -->
<script setup lang="ts">
const props = defineProps<{
  error: { statusCode: number; statusMessage: string };
}>();

function handleClear() {
  clearError({ redirect: '/' });
}
</script>

<template>
  <div class="error-page">
    <h1>{{ error.statusCode }}</h1>
    <p>{{ error.statusMessage }}</p>
    <button @click="handleClear">返回首页</button>
  </div>
</template>


Payload 与 SSR 数据传递


小结
    

  • useFetch 是最常用的数据获取 API，自动处理 SSR → 客户端的数据传递
    • 

  • useAsyncData 提供更灵活的控制，支持多请求组合和自定义获取逻辑
    • 

  • $fetch 是底层 HTTP 客户端，在事件处理函数和服务端 API 中使用
    • 

  • 组件 setup 中应避免直接使用 $fetch，防止重复请求
    • 

  • 通过 key 和 getCachedData 控制缓存策略，refresh 手动刷新数据
    • 

  • Nuxt 自动将 SSR 数据通过 payload 传递到客户端，避免 hydration 时重复请求
