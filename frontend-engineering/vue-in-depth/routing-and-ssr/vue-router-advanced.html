Vue Router 进阶

路由系统概述

Vue Router 是 Vue.js 的官方路由管理器，提供了嵌套路由、导航守卫、懒加载等强大功能。本文聚焦于进阶用法，帮助构建复杂的路由架构。



导航守卫
全局守卫
// router/index.ts
import { createRouter, createWebHistory } from 'vue-router';
import type { RouteLocationNormalized, NavigationGuardNext } from 'vue-router';

const router = createRouter({
  history: createWebHistory(),
  routes: [
    /* ... */
  ],
});

router.beforeEach(async (to: RouteLocationNormalized, from: RouteLocationNormalized) => {
  const authStore = useAuthStore();

  if (to.meta.requiresAuth && !authStore.isAuthenticated) {
    return { name: 'login', query: { redirect: to.fullPath } };
  }

  if (to.meta.requiresAdmin && !authStore.isAdmin) {
    return { name: 'forbidden' };
  }
});

router.afterEach((to, from) => {
  document.title = (to.meta.title as string) ?? '默认标题';
});
路由独享守卫
const routes = [
  {
    path: '/admin',
    component: () => import('@/views/AdminLayout.vue'),
    beforeEnter: (to, from) => {
      const authStore = useAuthStore();
      if (!authStore.isAdmin) return { name: 'home' };
    },
    children: [
      { path: '', component: () => import('@/views/AdminDashboard.vue') },
      { path: 'users', component: () => import('@/views/AdminUsers.vue') },
    ],
  },
];
组件内守卫
<script setup lang="ts">
import { onBeforeRouteLeave, onBeforeRouteUpdate } from 'vue-router';
import { ref } from 'vue';

const hasUnsavedChanges = ref<boolean>(false);

onBeforeRouteLeave((to, from) => {
  if (hasUnsavedChanges.value) {
    const answer = window.confirm('有未保存的更改，确定要离开吗？');
    if (!answer) return false;
  }
});

onBeforeRouteUpdate((to, from) => {
  // 同一路由参数变化时触发（如 /user/1 → /user/2）
  fetchUserData(to.params.id as string);
});
</script>


路由 Meta
使用 meta 字段携带路由元信息：


// router/types.ts
declare module 'vue-router' {
  interface RouteMeta {
    title?: string;
    requiresAuth?: boolean;
    requiresAdmin?: boolean;
    layout?: 'default' | 'admin' | 'blank';
    transition?: string;
  }
}
const routes = [
  {
    path: '/dashboard',
    component: () => import('@/views/Dashboard.vue'),
    meta: {
      title: '仪表盘',
      requiresAuth: true,
      layout: 'admin',
      transition: 'fade',
    },
  },
];

路由懒加载
使用动态 import() 实现按需加载路由组件：


const routes = [
  {
    path: '/',
    component: () => import('@/views/Home.vue'),
  },
  {
    path: '/about',
    component: () => import(/* webpackChunkName: "about" */ '@/views/About.vue'),
  },
  {
    path: '/admin',
    component: () => import('@/layouts/AdminLayout.vue'),
    children: [
      {
        path: 'reports',
        component: () => import('@/views/admin/Reports.vue'),
      },
    ],
  },
];


滚动行为
const router = createRouter({
  history: createWebHistory(),
  routes,
  scrollBehavior(to, from, savedPosition) {
    if (savedPosition) {
      return savedPosition;
    }
    if (to.hash) {
      return { el: to.hash, behavior: 'smooth' };
    }
    return { top: 0 };
  },
});


动态路由
运行时添加/删除路由
const router = useRouter();

function addAdminRoutes() {
  router.addRoute({
    path: '/admin',
    name: 'admin',
    component: () => import('@/layouts/AdminLayout.vue'),
    children: [
      {
        path: 'settings',
        name: 'admin-settings',
        component: () => import('@/views/AdminSettings.vue'),
      },
    ],
  });
}

function removeAdminRoutes() {
  router.removeRoute('admin');
}
动态路由参数
const routes = [
  {
    path: '/user/:id',
    component: () => import('@/views/UserProfile.vue'),
    props: true,
  },
  {
    path: '/blog/:year(\\d{4})/:month(\\d{2})/:slug',
    component: () => import('@/views/BlogPost.vue'),
    props: true,
  },
  {
    path: '/:pathMatch(.*)*',
    name: 'NotFound',
    component: () => import('@/views/NotFound.vue'),
  },
];


小结
    

  • 导航守卫分三层：全局（beforeEach/afterEach）、路由独享（beforeEnter）、组件内（onBeforeRouteLeave）
    • 

  • meta 字段携带路由元信息，配合守卫实现权限控制、标题设置等功能
    • 

  • 动态 import() 实现路由级代码分割，减小首屏包体积
    • 

  • scrollBehavior 控制导航后的滚动位置，支持锚点和平滑滚动
    • 

  • addRoute / removeRoute 支持运行时动态管理路由表，适合权限驱动的菜单
    • 

  • 路由参数支持正则约束，pathMatch 捕获 404 路由
    •
