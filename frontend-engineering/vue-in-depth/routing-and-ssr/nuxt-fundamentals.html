Nuxt 基础

全栈 Vue 框架

Nuxt 3 是基于 Vue 3 的全栈框架，提供文件系统路由、自动导入、SSR/SSG 支持等开箱即用的功能。它基于 Nitro 服务引擎和 Vite 构建工具，是构建现代 Vue 应用的最佳选择之一。

自动导入
Nuxt 自动导入 Vue API、composable 和组件，无需手动 import：


<script setup lang="ts">
// ✅ 无需 import { ref, computed } from 'vue'
const count = ref<number>(0);
const doubled = computed(() => count.value * 2);

// ✅ 无需 import { useRoute } from 'vue-router'
const route = useRoute();

// ✅ composables/ 目录下的函数自动导入
const { data } = useFetch('/api/posts');
</script>

目录结构
nuxt-app/
├── app.vue              # 应用入口
├── nuxt.config.ts       # Nuxt 配置
├── pages/               # 页面（文件系统路由）
├── components/          # 组件（自动导入）
├── composables/         # Composable（自动导入）
├── layouts/             # 布局组件
├── middleware/           # 路由中间件
├── plugins/             # 插件
├── server/              # 服务端 API
│   ├── api/             # API 路由
│   └── middleware/      # 服务端中间件
├── public/              # 静态资源
├── assets/              # 需要构建的资源
└── utils/               # 工具函数（自动导入）

Runtime Config
使用运行时配置安全地管理环境变量：


// nuxt.config.ts
export default defineNuxtConfig({
  runtimeConfig: {
    dbPassword: process.env.DB_PASSWORD,
    apiSecret: process.env.API_SECRET,
    public: {
      apiBase: process.env.NUXT_PUBLIC_API_BASE ?? '/api',
      appName: 'My App',
    },
  },
});
<!-- 客户端组件 -->
<script setup lang="ts">
const config = useRuntimeConfig();

// ✅ 客户端只能访问 public 配置
console.log(config.public.apiBase);
console.log(config.public.appName);

// ❌ 私有配置在客户端不可用
// console.log(config.dbPassword) → undefined
</script>
// server/api/data.ts — 服务端可以访问所有配置
export default defineEventHandler(() => {
  const config = useRuntimeConfig();
  console.log(config.apiSecret);
  console.log(config.public.apiBase);
  return { status: 'ok' };
});

小结
    

  • Nuxt 3 基于 Vue 3 + Vite + Nitro，提供全栈开发体验
    • 

  • 文件系统路由根据 pages/ 目录结构自动生成路由，支持动态参数和嵌套
    • 

  • 自动导入覆盖 Vue API、composable、组件和工具函数，减少样板代码
    • 

  • 模块生态提供丰富的扩展，一行配置即可集成
    • 

  • runtimeConfig 区分公开/私有配置，安全管理环境变量
    • 

  • 布局系统通过 layouts/ 目录和 definePageMeta 实现灵活的页面布局切换
    •
