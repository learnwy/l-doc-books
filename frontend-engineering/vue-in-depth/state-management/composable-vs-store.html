Composable vs Store 组合式与状态仓库对比

状态管理的两条路线

Vue 3 中有两种主要的状态管理方式：Composable（组合式函数）和 Store（Pinia）。两者都基于 Composition API，但适用场景和设计哲学不同。

Composable 适用场景
可复用的 UI 逻辑
// composables/useFormValidation.ts
import { ref, computed, type Ref } from 'vue';

interface ValidationRule {
  validate: (value: string) => boolean;
  message: string;
}

export function useFormValidation(value: Ref<string>, rules: ValidationRule[]) {
  const errors = computed<string[]>(() =>
    rules.filter((rule) => !rule.validate(value.value)).map((rule) => rule.message),
  );

  const isValid = computed<boolean>(() => errors.value.length === 0);
  const isDirty = ref<boolean>(false);

  function touch() {
    isDirty.value = true;
  }

  function reset() {
    isDirty.value = false;
  }

  return { errors, isValid, isDirty, touch, reset };
}
封装浏览器 API
// composables/useOnline.ts
import { ref, onMounted, onUnmounted } from 'vue';

export function useOnline() {
  const isOnline = ref<boolean>(navigator.onLine);

  function update() {
    isOnline.value = navigator.onLine;
  }

  onMounted(() => {
    window.addEventListener('online', update);
    window.addEventListener('offline', update);
  });

  onUnmounted(() => {
    window.removeEventListener('online', update);
    window.removeEventListener('offline', update);
  });

  return { isOnline };
}


Store 适用场景
全局业务状态
// stores/auth.ts
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';

interface User {
  id: number;
  name: string;
  email: string;
  role: 'admin' | 'user';
}

export const useAuthStore = defineStore(
  'auth',
  () => {
    const user = ref<User | null>(null);
    const token = ref<string | null>(null);

    const isAuthenticated = computed<boolean>(() => !!token.value);
    const isAdmin = computed<boolean>(() => user.value?.role === 'admin');

    async function login(email: string, password: string) {
      const res = await fetch('/api/auth/login', {
        method: 'POST',
        body: JSON.stringify({ email, password }),
        headers: { 'Content-Type': 'application/json' },
      });
      const data = await res.json();
      token.value = data.token;
      user.value = data.user;
    }

    function logout() {
      token.value = null;
      user.value = null;
    }

    return { user, token, isAuthenticated, isAdmin, login, logout };
  },
  {
    persist: {
      pick: ['token'],
    },
  },
);


混合使用模式
最佳实践是结合两者：Store 管理全局业务状态，Composable 封装可复用逻辑：


<script setup lang="ts">
import { ref } from 'vue';
import { useAuthStore } from '@/stores/auth';
import { useFormValidation } from '@/composables/useFormValidation';

const authStore = useAuthStore();

const email = ref<string>('');
const password = ref<string>('');

const emailValidation = useFormValidation(email, [
  { validate: (v) => v.length > 0, message: '邮箱不能为空' },
  { validate: (v) => v.includes('@'), message: '邮箱格式不正确' },
]);

async function handleLogin() {
  emailValidation.touch();
  if (emailValidation.isValid.value) {
    await authStore.login(email.value, password.value);
  }
}
</script>

测试差异
// 测试 Composable — 直接调用
import { useFormValidation } from '@/composables/useFormValidation';

test('验证邮箱格式', () => {
  const email = ref('invalid');
  const { isValid } = useFormValidation(email, [{ validate: (v) => v.includes('@'), message: '格式错误' }]);
  expect(isValid.value).toBe(false);
  email.value = 'test@example.com';
  expect(isValid.value).toBe(true);
});

// 测试 Store — 需要 Pinia 环境
import { setActivePinia, createPinia } from 'pinia';
import { useAuthStore } from '@/stores/auth';

beforeEach(() => {
  setActivePinia(createPinia());
});

test('登录后 isAuthenticated 为 true', async () => {
  const store = useAuthStore();
  expect(store.isAuthenticated).toBe(false);
  await store.login('test@example.com', 'password');
  expect(store.isAuthenticated).toBe(true);
});


小结
    

  • Composable 适合封装可复用的 UI 逻辑和浏览器 API，默认创建独立实例
    • 

  • Store 适合管理全局业务状态，天然支持 DevTools、持久化和 SSR
    • 

  • 最佳实践是两者结合：Store 管理全局状态，Composable 封装可复用逻辑
    • 

  • SSR 场景下优先使用 Pinia Store，避免模块作用域状态在请求间泄漏
    • 

  • Composable 测试更简单（直接调用），Store 测试需要创建 Pinia 实例
