Pinia 基础

Vue 官方状态管理

Pinia 是 Vue 的官方状态管理库，取代了 Vuex 成为 Vue 3 的推荐方案。它提供了更简洁的 API、完整的 TypeScript 支持和更好的开发体验。

defineStore
Option Store
类似 Vue Options API 的风格：


// stores/counter.ts
import { defineStore } from 'pinia';

export const useCounterStore = defineStore('counter', {
  state: () => ({
    count: 0,
    name: 'Vue',
    items: [] as string[],
  }),

  getters: {
    doubleCount: (state): number => state.count * 2,
    itemCount(): number {
      return this.items.length;
    },
  },

  actions: {
    increment() {
      this.count++;
    },
    async fetchItems() {
      const res = await fetch('/api/items');
      this.items = await res.json();
    },
  },
});
Setup Store（推荐）
使用 Composition API 风格，更灵活：


// stores/counter.ts
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';

export const useCounterStore = defineStore('counter', () => {
  const count = ref<number>(0);
  const name = ref<string>('Vue');
  const items = ref<string[]>([]);

  const doubleCount = computed<number>(() => count.value * 2);
  const itemCount = computed<number>(() => items.value.length);

  function increment() {
    count.value++;
  }

  async function fetchItems() {
    const res = await fetch('/api/items');
    items.value = await res.json();
  }

  return { count, name, items, doubleCount, itemCount, increment, fetchItems };
});

在组件中使用
<script setup lang="ts">
import { useCounterStore } from '@/stores/counter';
import { storeToRefs } from 'pinia';

const counterStore = useCounterStore();

// 直接解构会丢失响应性
// ❌ const { count, doubleCount } = counterStore

// ✅ 使用 storeToRefs 保持响应性（只解构 state 和 getters）
const { count, doubleCount, items } = storeToRefs(counterStore);
// Actions 可以直接解构
const { increment, fetchItems } = counterStore;
</script>

<template>
  <div>
    <p>计数：{{ count }}，双倍：{{ doubleCount }}</p>
    <button @click="increment">+1</button>
    <button @click="fetchItems">加载数据</button>
    <ul>
      <li v-for="item in items" :key="item">{{ item }}</li>
    </ul>
  </div>
</template>


State 操作
直接修改
const store = useCounterStore();
store.count++;
store.name = 'Pinia';
$patch 批量修改
// 对象形式
store.$patch({
  count: store.count + 1,
  name: 'Pinia',
});

// 函数形式（推荐，适合复杂修改）
store.$patch((state) => {
  state.count++;
  state.items.push('new item');
});
$reset 重置状态
// 仅 Option Store 支持
store.$reset();


提示： Setup Store 不支持 $reset，需要手动实现重置逻辑。

小结
    

  • Pinia 是 Vue 3 官方状态管理库，替代 Vuex，API 更简洁
    • 

  • 移除了 Mutations 概念，Actions 统一处理同步和异步逻辑
    • 

  • Setup Store 使用 Composition API 风格，灵活性更高，TypeScript 推断更好
    • 

  • 使用 storeToRefs 解构 state/getters 保持响应性，actions 可直接解构
    • 

  • $patch 支持批量更新状态，函数形式适合复杂修改
    • 

  • Vue DevTools 提供完整的状态检查、编辑和时间旅行调试能力
    •
