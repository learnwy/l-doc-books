Vue 组件测试

测试工具链

Vue 3 推荐使用 Vitest 作为测试框架，配合 @vue/test-utils 进行组件测试。这套工具链与 Vite 深度集成，提供极快的测试速度。

flowchart LR
    V["Vitest(测试框架)"]
    VTU["@vue/test-utils(组件工具)"]
    JSDOM["jsdom / happy-dom"]
    V --> VTU
    VTU --> JSDOM
    V --> |"断言"| Expect["expect API"]
    V --> |"Mock"| Mock["vi.fn / vi.mock"]

核心概念

  • Vitest：与 Vite 共享配置与转换管线的测试框架，因此无需为测试重复搭建构建环境。
  • @vue/test-utils：组件测试工具，提供 mount / shallowMount 与 wrapper 查询、交互、断言 API。
  • mount vs shallowMount：前者完整渲染子组件用于集成测试，后者把子组件替换为 stub 用于隔离测试。
  • DOM 环境：jsdom / happy-dom 在 Node 中模拟浏览器 DOM，使组件能被真实挂载。
  • VM（wrapper）：测试操作的句柄，emitted() 查看事件、setProps 驱动更新、find/findAll 查询节点。
  • 异步等待：flushPromises 清空微任务队列，让异步数据到位后再断言。

环境配置

// vitest.config.ts
import { defineConfig } from 'vitest/config';
import vue from '@vitejs/plugin-vue';

export default defineConfig({
  plugins: [vue()],
  test: {
    environment: 'jsdom',
    globals: true,
    setupFiles: ['./tests/setup.ts'],
  },
});
// tests/setup.ts
import { config } from '@vue/test-utils';

config.global.stubs = {
  Teleport: true,
  Transition: false,
};

组件挂载

mount vs shallowMount

方法 子组件 适用场景
mount 完整渲染 集成测试、测试子组件交互
shallowMount 替换为 stub 单元测试、隔离测试 
import { mount, shallowMount } from '@vue/test-utils';
import Counter from '@/components/Counter.vue';

describe('Counter', () => {
  it('渲染初始值', () => {
    const wrapper = mount(Counter, {
      props: { initial: 5 },
    });
    expect(wrapper.text()).toContain('5');
  });

  it('shallowMount 不渲染子组件', () => {
    const wrapper = shallowMount(Counter);
    expect(wrapper.findComponent({ name: 'ChildComponent' }).exists()).toBe(false);
  });
});

Props 测试

import { mount } from '@vue/test-utils';
import UserCard from '@/components/UserCard.vue';

describe('UserCard', () => {
  const defaultProps = {
    name: 'Alice',
    email: 'alice@example.com',
    role: 'admin' as const,
  };

  it('正确渲染用户信息', () => {
    const wrapper = mount(UserCard, { props: defaultProps });
    expect(wrapper.find('.name').text()).toBe('Alice');
    expect(wrapper.find('.email').text()).toBe('alice@example.com');
  });

  it('根据角色显示徽章', () => {
    const wrapper = mount(UserCard, { props: defaultProps });
    expect(wrapper.find('.badge').text()).toBe('管理员');
  });

  it('props 变化时更新视图', async () => {
    const wrapper = mount(UserCard, { props: defaultProps });
    await wrapper.setProps({ name: 'Bob' });
    expect(wrapper.find('.name').text()).toBe('Bob');
  });
});

事件测试

import { mount } from '@vue/test-utils';
import SearchInput from '@/components/SearchInput.vue';

describe('SearchInput', () => {
  it('输入时触发 update 事件', async () => {
    const wrapper = mount(SearchInput);
    const input = wrapper.find('input');

    await input.setValue('Vue 3');
    expect(wrapper.emitted('update')).toBeTruthy();
    expect(wrapper.emitted('update')![0]).toEqual(['Vue 3']);
  });

  it('点击提交按钮触发 submit 事件', async () => {
    const wrapper = mount(SearchInput);
    await wrapper.find('input').setValue('test');
    await wrapper.find('button[type="submit"]').trigger('click');

    expect(wrapper.emitted('submit')).toHaveLength(1);
    expect(wrapper.emitted('submit')![0]).toEqual(['test']);
  });

  it('空输入时不触发 submit', async () => {
    const wrapper = mount(SearchInput);
    await wrapper.find('button[type="submit"]').trigger('click');

    expect(wrapper.emitted('submit')).toBeUndefined();
  });
});

插槽测试

import { mount } from '@vue/test-utils';
import Card from '@/components/Card.vue';

describe('Card', () => {
  it('渲染默认插槽', () => {
    const wrapper = mount(Card, {
      slots: {
        default: '<p>卡片内容</p>',
      },
    });
    expect(wrapper.find('p').text()).toBe('卡片内容');
  });

  it('渲染具名插槽', () => {
    const wrapper = mount(Card, {
      slots: {
        header: '<h2>标题</h2>',
        footer: '<span>底部</span>',
      },
    });
    expect(wrapper.find('h2').text()).toBe('标题');
    expect(wrapper.find('span').text()).toBe('底部');
  });

  it('测试作用域插槽', () => {
    const wrapper = mount(Card, {
      slots: {
        item: `<template #item="{ data }">
          <span class="custom">{{ data.name }}</span>
        </template>`,
      },
    });
    expect(wrapper.find('.custom').exists()).toBe(true);
  });
});

异步测试

import { mount, flushPromises } from '@vue/test-utils';
import UserList from '@/components/UserList.vue';

vi.mock('@/composables/useFetch', () => ({
  useFetch: vi.fn(() => ({
    data: ref([
      { id: 1, name: 'Alice' },
      { id: 2, name: 'Bob' },
    ]),
    loading: ref(false),
    error: ref(null),
  })),
}));

describe('UserList', () => {
  it('加载后显示用户列表', async () => {
    const wrapper = mount(UserList);
    await flushPromises();

    const items = wrapper.findAll('li');
    expect(items).toHaveLength(2);
    expect(items[0].text()).toContain('Alice');
  });
});

Pinia Store 测试

import { setActivePinia, createPinia } from 'pinia';
import { mount } from '@vue/test-utils';
import { useCounterStore } from '@/stores/counter';
import CounterDisplay from '@/components/CounterDisplay.vue';

describe('CounterDisplay with Pinia', () => {
  beforeEach(() => {
    setActivePinia(createPinia());
  });

  it('显示 store 中的计数', () => {
    const store = useCounterStore();
    store.count = 42;

    const wrapper = mount(CounterDisplay, {
      global: {
        plugins: [createPinia()],
      },
    });

    expect(wrapper.text()).toContain('42');
  });

  it('点击按钮增加计数', async () => {
    const wrapper = mount(CounterDisplay, {
      global: { plugins: [createPinia()] },
    });

    await wrapper.find('.increment').trigger('click');
    expect(wrapper.text()).toContain('1');
  });
});

小结

  • Vitest + @vue/test-utils 是 Vue 3 推荐的测试组合，与 Vite 深度集成
  • mount 完整渲染组件适合集成测试，shallowMount 隔离子组件适合单元测试
  • Props 测试验证渲染输出和响应变化，Event 测试使用 emitted() 断言
  • 插槽测试支持默认插槽、具名插槽和作用域插槽
  • 异步测试使用 flushPromises 等待所有 Promise 完成
  • Pinia Store 测试需在 beforeEach 中创建新实例，确保测试隔离
