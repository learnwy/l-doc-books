性能优化

Vue 应用性能全景

Vue 应用的性能优化涵盖多个层面：渲染效率、包体积、运行时内存和网络加载。理解 Vue 的渲染机制是做出正确优化决策的前提。



虚拟滚动
当列表包含成千上万条数据时，一次渲染所有 DOM 节点会严重影响性能。虚拟滚动只渲染可视区域内的元素：


<script setup lang="ts">
import { ref } from 'vue';
import { useVirtualList } from '@vueuse/core';

interface ListItem {
  id: number;
  title: string;
  description: string;
}

const allItems = ref<ListItem[]>(
  Array.from({ length: 100000 }, (_, i) => ({
    id: i,
    title: `项目 ${i}`,
    description: `这是第 ${i} 个项目的描述`,
  })),
);

const { list, containerProps, wrapperProps } = useVirtualList(allItems, {
  itemHeight: 60,
});
</script>

<template>
  <div v-bind="containerProps" class="list-container">
    <div v-bind="wrapperProps">
      <div v-for="{ data, index } in list" :key="data.id" class="list-item">
        <span>{{ data.title }}</span>
        <p>{{ data.description }}</p>
      </div>
    </div>
  </div>
</template>


v-memo
v-memo 指令（Vue 3.2+）根据依赖数组决定是否跳过子树更新，对大型列表特别有效：


<template>
  <div v-for="item in list" :key="item.id" v-memo="[item.id === selected]">
    <p>{{ item.name }}</p>
    <span :class="{ active: item.id === selected }">
      {{ item.id === selected ? '已选中' : '未选中' }}
    </span>
  </div>
</template>

shallowRef 与 shallowReactive
对于大型数据结构，避免深层响应式转换可以显著提升性能：


import { shallowRef, triggerRef } from 'vue';

interface ChartData {
  labels: string[];
  datasets: Array<{
    data: number[];
    backgroundColor: string;
  }>;
}

const chartData = shallowRef<ChartData>({
  labels: Array.from({ length: 1000 }, (_, i) => `Label ${i}`),
  datasets: [
    {
      data: Array.from({ length: 1000 }, () => Math.random() * 100),
      backgroundColor: '#42b883',
    },
  ],
});

function updateChart() {
  chartData.value.datasets[0].data = chartData.value.datasets[0].data.map(() => Math.random() * 100);
  triggerRef(chartData);
}

function replaceChart(newData: ChartData) {
  chartData.value = newData;
}


Lazy Hydration
在 SSR 场景下，并非所有组件都需要在首屏时 hydrate。延迟 hydration 可以加速 TTI（Time to Interactive）：


<!-- Nuxt 3.4+ -->
<template>
  <LazyHeader />

  <main>
    <NuxtPage />
  </main>

  <!-- 滚动到可见时才 hydrate -->
  <LazyFooter />
</template>
// nuxt.config.ts
export default defineNuxtConfig({
  experimental: {
    componentIslands: true,
  },
});

运行时优化技巧
<script setup lang="ts">
import { computed, shallowRef } from 'vue';

const items = shallowRef<Item[]>([]);

const expensiveComputed = computed(() => {
  return items.value
    .filter((item) => item.active)
    .sort((a, b) => b.score - a.score)
    .slice(0, 100);
});
</script>

<template>
  <!-- ✅ 使用 key 帮助 Vue 追踪列表变化 -->
  <TransitionGroup name="list">
    <div v-for="item in expensiveComputed" :key="item.id">
      {{ item.name }}
    </div>
  </TransitionGroup>

  <!-- ✅ 大型静态内容使用 v-once -->
  <footer v-once>
    <p>版权所有 © 2026 公司名称</p>
  </footer>
</template>
