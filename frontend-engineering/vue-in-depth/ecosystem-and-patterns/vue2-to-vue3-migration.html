Vue 2 到 Vue 3 迁移

迁移概述

Vue 3 引入了大量改进，同时也有若干破坏性变更。迁移不必一步到位，Vue 团队提供了兼容构建（Migration Build）支持渐进式升级。

app.config.globalProperties.$http = axios;

模板语法变化
<!-- Vue 2: v-model 使用 value + input -->
<CustomInput v-model="text" />
<!-- 等价于 -->
<CustomInput :value="text" @input="text = $event" />

<!-- Vue 3: v-model 使用 modelValue + update:modelValue -->
<CustomInput v-model="text" />
<!-- 等价于 -->
<CustomInput :model-value="text" @update:model-value="text = $event" />

Migration Build
Vue 3 提供了兼容构建，允许在 Vue 3 环境中运行 Vue 2 代码：


// vue.config.js (Vue CLI) 或 vite.config.ts
export default {
  resolve: {
    alias: {
      vue: '@vue/compat',
    },
  },
};
// main.ts — 兼容模式配置
import { createApp, configureCompat } from 'vue';

configureCompat({
  MODE: 2,
  GLOBAL_MOUNT: false,
  INSTANCE_EVENT_EMITTER: false,
  COMPONENT_V_MODEL: false,
});

// ❌ Vue 2

new Vue({ render: (h) => h(App) }).$mount('#app');
// ✅ Vue 3

createApp(App).mount('#app');

小结
    

  • Vue 3 的破坏性变更包括全局 API 实例化、v-model 行为、移除事件总线和过滤器等
    • 

  • Migration Build（@vue/compat）支持在 Vue 3 中运行 Vue 2 代码，输出迁移警告
    • 

  • 推荐渐进式迁移：环境升级 → 核心 API 迁移 → 现代化改造
    • 

  • .sync 修饰符被 v-model:propName 取代，支持多个 v-model
    • 

  • EventBus 被移除，推荐使用 mitt 等轻量事件库替代
    • 

  • 迁移前检查第三方依赖的 Vue 3 兼容情况，是规划迁移时间的关键因素
