基于 Proxy 的响应式

响应式系统概述

Vue 3 的响应式系统是整个框架的基石。它能够自动追踪数据依赖并在数据变化时精确更新视图，这一切的核心都建立在 ES6 Proxy 之上。相比 Vue 2 基于 Object.defineProperty 的实现，Proxy 方案解决了诸多限制，提供了更完整的拦截能力。



ES6 Proxy 基础
Proxy 允许我们为对象创建一个代理层，拦截并自定义几乎所有基本操作。Vue 3 主要使用以下 trap：

const handler: ProxyHandler<Record<string, unknown>> = {
  get(target, key, receiver) {
    track(target, key);
    return Reflect.get(target, key, receiver);
  },
  set(target, key, value, receiver) {
    const oldValue = target[key as string];
    const result = Reflect.set(target, key, value, receiver);
    if (oldValue !== value) {
      trigger(target, key);
    }
    return result;
  },
};

const observed = new Proxy(rawObject, handler);


提示： Vue 3 内部使用 Reflect 配合 Proxy，确保 this 指向始终正确，避免了直接操作 target 可能引发的问题。






track 与 trigger 机制
响应式系统的核心在于 track（依赖收集）和 trigger（派发更新）这两个函数。它们共同维护一个全局的依赖图。


依赖关系存储在一个三层嵌套的 WeakMap 结构中：


type Dep = Set<ReactiveEffect>;
type KeyToDepMap = Map<string | symbol, Dep>;

const targetMap: WeakMap<object, KeyToDepMap> = new WeakMap();

function track(target: object, key: string | symbol): void {
  if (!activeEffect) return;
  let depsMap = targetMap.get(target);
  if (!depsMap) {
    targetMap.set(target, (depsMap = new Map()));
  }
  let dep = depsMap.get(key);
  if (!dep) {
    depsMap.set(key, (dep = new Set()));
  }
  dep.add(activeEffect);
}

function trigger(target: object, key: string | symbol): void {
  const depsMap = targetMap.get(target);
  if (!depsMap) return;
  const dep = depsMap.get(key);
  if (dep) {
    dep.forEach((effect) => effect.run());
  }
}


依赖图结构
依赖图使用 WeakMap → Map → Set 三层结构，保证了垃圾回收友好性和查找效率：


当 target 对象被垃圾回收时，WeakMap 中对应的条目也会自动清除，不会造成内存泄漏。

const vm = new Vue({
  data: { user: { name: 'Alice' } },
});
vm.user.age = 25; // ❌ 不是响应式的
Vue.set(vm.user, 'age', 25); // ✅ 需要使用 Vue.set

// Vue 3：Proxy 自动检测
const state = reactive({ user: { name: 'Alice' } });
state.user.age = 25; // ✅ 自动成为响应式


惰性代理与深层响应式
Vue 3 的 reactive 采用惰性代理策略——只有在访问嵌套对象时才会为其创建 Proxy，而不是在初始化时递归遍历整个对象树：


const state = reactive({
  nested: {
    deep: {
      value: 42,
    },
  },
});

// 访问 state.nested 时才为 nested 对象创建 Proxy
// 访问 state.nested.deep 时才为 deep 对象创建 Proxy
这种策略在处理大型数据结构时显著提升了初始化性能。




小结
    

  • Vue 3 使用 ES6 Proxy 替代 Object.defineProperty，获得了完整的对象操作拦截能力
    • 

  • track 在属性被读取时收集依赖，trigger 在属性被修改时派发更新
    • 

  • 依赖关系存储在 WeakMap → Map → Set 三层结构中，兼顾查找效率与垃圾回收
    • 

  • 相比 Vue 2，Proxy 方案原生支持属性新增/删除检测、数组索引操作和 Map/Set 类型
    • 

  • 惰性代理 策略按需创建嵌套对象的 Proxy，避免了初始化时的性能开销
