computed 与 watch

派生状态与副作用

Vue 3 提供了两类响应式工具来处理数据变化：computed 用于创建派生状态，watch / watchEffect 用于执行副作用。理解它们的区别是高效使用 Composition API 的关键。



computed 详解
基本用法
computed 接收一个 getter 函数，返回一个只读的 ref。它具有惰性求值和缓存特性——只有在依赖变化时才重新计算：


import { ref, computed } from 'vue';

const price = ref<number>(100);
const quantity = ref<number>(3);
const discount = ref<number>(0.8);

const total = computed<number>(() => {
  console.log('重新计算 total');
  return price.value * quantity.value * discount.value;
});

console.log(total.value); // 240，触发计算
console.log(total.value); // 240，使用缓存，不重新计算
quantity.value = 5; // 标记为脏
console.log(total.value); // 400，重新计算
可写 computed
通过提供 getter 和 setter，可以创建可写的 computed：


<script setup lang="ts">
import { ref, computed } from 'vue';

const firstName = ref<string>('张');
const lastName = ref<string>('三');

const fullName = computed<string>({
  get: () => `${firstName.value}${lastName.value}`,
  set: (val: string) => {
    firstName.value = val[0] ?? '';
    lastName.value = val.slice(1);
  },
});
</script>

<template>
  <input v-model="fullName" />
  <p>姓：{{ firstName }}，名：{{ lastName }}</p>
</template>
惰性求值与缓存机制




特性
说明





惰性
只在被访问时才计算，不会在依赖变化时立即执行




缓存
依赖不变时返回缓存值，避免重复计算




自动追踪
getter 中访问的所有响应式数据都会被自动追踪




只读（默认）
默认返回只读 ref，修改 .value 会报警告







watch 详解
基本用法
watch 用于监听一个或多个响应式数据源，在数据变化时执行回调：


import { ref, watch } from 'vue';

const searchQuery = ref<string>('');

watch(searchQuery, (newVal, oldVal) => {
  console.log(`搜索词从 "${oldVal}" 变为 "${newVal}"`);
  fetchSearchResults(newVal);
});
监听多个源
import { ref, watch } from 'vue';

const page = ref<number>(1);
const pageSize = ref<number>(20);

watch([page, pageSize], ([newPage, newSize], [oldPage, oldSize]) => {
  console.log(`分页变化: ${oldPage}/${oldSize} → ${newPage}/${newSize}`);
  fetchData(newPage, newSize);
});

flush 时机
import { ref, watch } from 'vue';

const count = ref<number>(0);

watch(
  count,
  () => {
    console.log('DOM 已更新，可安全访问');
    const el = document.querySelector('#counter');
    console.log(el?.textContent);
  },
  { flush: 'post' },
);


watchEffect
watchEffect 在创建时立即执行一次回调，并自动追踪回调中使用的所有响应式依赖：


import { ref, watchEffect } from 'vue';

const userId = ref<number>(1);
const userData = ref<Record<string, unknown> | null>(null);

const stop = watchEffect(async (onCleanup) => {
  const controller = new AbortController();
  onCleanup(() => controller.abort());

  const response = await fetch(`/api/users/${userId.value}`, {
    signal: controller.signal,
  });
  userData.value = await response.json();
});

// 手动停止监听
stop();

清理副作用
当被监听的数据快速变化时（如搜索输入），前一次异步操作可能尚未完成。使用 onCleanup 可以取消过期的操作：


import { ref, watch } from 'vue';

const keyword = ref<string>('');

watch(keyword, (newVal, _oldVal, onCleanup) => {
  const controller = new AbortController();
  onCleanup(() => controller.abort());

  fetch(`/api/search?q=${newVal}`, { signal: controller.signal })
    .then((res) => res.json())
    .then((data) => {
      results.value = data;
    })
    .catch((err) => {
      if (err.name !== 'AbortError') throw err;
    });
});


小结
    

  • computed 用于派生状态，具有惰性求值和缓存特性，依赖不变时不重新计算
    • 

  • 可写 computed 通过提供 get/set 实现双向绑定场景
    • 

  • watch 显式监听指定数据源，支持 immediate、deep、flush 等选项精确控制行为
    • 

  • watchEffect 自动追踪依赖并立即执行，适合不需要新旧值对比的副作用场景
    • 

  • onCleanup 用于取消过期的异步操作，防止竞态条件
    • 

  • flush 选项控制回调执行时机：sync（同步）、pre（DOM 更新前）、post（DOM 更新后）
