类型标注与 typing 模块

概述

Python 类型标注（Type Annotations）是一套在源码中声明变量、参数和返回值类型的语法规范。它不影响运行时行为，但能被 mypy、pyright 等静态分析工具用来发现潜在错误。从 Python 3.9 开始，内置容器类型可直接用于标注，无需从 typing 导入。

基本标注语法

变量与函数标注

name: str = "Alice"
age: int = 30
is_active: bool = True

def greet(name: str, times: int = 1) -> str:
    return f"Hello, {name}! " * times

版本 变化 示例

typing 模块核心类型

容器与联合类型

from typing import Optional, Union

def find_user(user_id: int) -> Optional[dict]:
    ...

def process(value: Union[str, int]) -> str:
    return str(value)

scores: list[int] = [90, 85, 78]
config: dict[str, int | str] = {"timeout": 30, "name": "app"}

可调用类型与别名

from typing import Callable, TypeAlias

Handler = Callable[[str, int], bool]
JSON: TypeAlias = dict[str, "JSON"] | list["JSON"] | str | int | float | bool | None

def register(callback: Handler) -> None:
    ...

常用类型速查

类型 用途 示例
Optional[X] 可能为 None Optional[str] = str | None
Union[X, Y] 多类型之一 Union[int, str]

TypeAlias 类型别名 Vector: TypeAlias = list[float]
Literal 字面量类型 Literal["r", "w", "a"]
Final 不可重赋值 MAX: Final = 100
ClassVar 类级别变量 ClassVar[int]
TypeGuard 类型收窄谓词 def is_str(v: object) -> TypeGuard[str]

TypedDict 与结构化字典

from typing import TypedDict, Required, NotRequired

class UserProfile(TypedDict):
    name: str
    age: int
    email: NotRequired[str]

def show(user: UserProfile) -> str:
    return f"{user['name']}, {user['age']}"

TypedDict 可以精确描述 JSON-like 字典结构，尤其适用于 API 返回值和配置对象。相比普通 dict[str, Any]，TypedDict 提供字段级别的类型检查——访问不存在的键、赋值类型不匹配的值都会被静态分析工具捕获。对于嵌套 JSON 结构，TypedDict 支持类继承来组合字段定义，避免重复声明。

Protocol 与结构化子类型

Protocol 定义了结构化子类型（Structural Subtyping），类似于 Go 的接口或 TypeScript 的鸭子类型——一个类只要实现了 Protocol 要求的方法，无需显式继承即可匹配：

from typing import Protocol

class Renderable(Protocol):
    def render(self) -> str: ...

class Button:
    def render(self) -> str:
        return "<button>Click</button>"

def display(widget: Renderable) -> None:
    print(widget.render())

display(Button())

mypy 静态检查

基本使用

pip install mypy
mypy src/ --strict

常见配置（pyproject.toml）

[tool.mypy]
python_version = "3.12"
strict = true
warn_return_any = true
disallow_untyped_defs = true

mypy 错误类型

错误代码 含义 常见原因
[assignment] 赋值类型不匹配 变量被赋予了不兼容的值
[arg-type] 参数类型错误 传入参数与签名不一致
[return-value] 返回值类型不匹配 函数返回了声明之外的类型
[union-attr] 联合类型属性访问 未对 Union 做类型收窄
[override] 子类覆盖签名不兼容 子类方法签名与父类不一致
