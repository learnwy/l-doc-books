泛型与 TypeVar

概述

泛型（Generics）允许函数和类在保持类型安全的前提下处理多种数据类型。Python 通过 TypeVar 定义类型变量，通过 Generic 基类构建泛型容器，从 Python 3.12 开始还支持更简洁的类型参数语法（PEP 695）。

TypeVar 基础

定义类型变量

from typing import TypeVar

T = TypeVar("T")

def identity(value: T) -> T:
    return value

result = identity(42)       # 推断为 int
name = identity("Alice")    # 推断为 str

类型变量的核心语义是"在一次调用中保持一致"——当 identity(42) 被调用时，T 在该次调用中被绑定为 int，参数类型和返回类型同时被约束为 int。这与 Union[int, str] 不同，后者允许参数和返回值是不同类型。

约束与绑定

方式 语法 含义
无约束 T = TypeVar("T") 接受任意类型
上界约束 T = TypeVar("T", bound=Base) T 必须是 Base 或其子类
值约束 T = TypeVar("T", int, str) T 只能是 int 或 str 
from typing import TypeVar

Number = TypeVar("Number", int, float)

def add(a: Number, b: Number) -> Number:
    return a + b

Comparable = TypeVar("Comparable", bound="SupportsLessThan")

上界约束（bound）和值约束的区别在于：bound=Base 表示 T 可以是 Base 的任何子类型，类型变量在使用时保留具体子类型信息；而值约束 TypeVar("T", int, str) 表示 T 只能是列举的类型之一，类型检查器会为每种可能性分别验证。

泛型类

from typing import TypeVar, Generic

T = TypeVar("T")

class Stack(Generic[T]):
    def __init__(self) -> None:
        self._items: list[T] = []

    def push(self, item: T) -> None:
        self._items.append(item)

    def pop(self) -> T:
        return self._items.pop()

    def peek(self) -> T:
        return self._items[-1]

    def is_empty(self) -> bool:
        return len(self._items) == 0

int_stack: Stack[int] = Stack()
int_stack.push(1)
int_stack.push("x")  # mypy 报错：str 不兼容 int

Python 3.12 新语法

PEP 695 引入了更简洁的类型参数声明：

def identity[T](value: T) -> T:
    return value

class Stack[T]:
    def __init__(self) -> None:
        self._items: list[T] = []

    def push(self, item: T) -> None:
        self._items.append(item)

    def pop(self) -> T:
        return self._items.pop()

type Vector[T] = list[T]
type JSON = dict[str, "JSON"] | list["JSON"] | str | int | float | bool | None

新旧语法对比

特性 旧语法（3.5+） 新语法（3.12+）
类型变量 T = TypeVar("T") 直接在 [] 中声明
泛型类 class C(Generic[T]) class C[T]
泛型函数 先定义 TypeVar，再使用 def f[T](x: T) -> T
类型别名 TypeAlias = ... type Alias = ...
上界 TypeVar("T", bound=X) T: X

ParamSpec 与高阶函数

ParamSpec 用于捕获函数的完整参数签名，是编写类型安全装饰器的关键工具。

from typing import ParamSpec, TypeVar, Callable
from functools import wraps

P = ParamSpec("P")
R = TypeVar("R")

def logged(func: Callable[P, R]) -> Callable[P, R]:
    @wraps(func)
    def wrapper(*args: P.args, **kwargs: P.kwargs) -> R:
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@logged
def greet(name: str, times: int = 1) -> str:
    return f"Hello, {name}! " * times

ParamSpec 解决了 Python 类型系统中一个长期存在的痛点：在 ParamSpec 之前，装饰器要么丢失被装饰函数的签名信息（退化为 Callable[..., Any]），要么需要为每种参数组合编写重载。ParamSpec 让类型检查器能够"穿透"装饰器，保留原始函数的完整签名。

TypeVarTuple（可变泛型）

Python 3.11 引入的 TypeVarTuple 支持可变数量的类型参数：

from typing import TypeVarTuple, Unpack

Ts = TypeVarTuple("Ts")

def zip_strict(*iterables: Unpack[tuple[*Ts]]) -> list[tuple[*Ts]]:
    ...

协变与逆变

概念 关键字 含义 典型场景
不变 默认 Stack[Cat] 不是 Stack[Animal] 可读写容器
协变 covariant Seq[Cat] 是 Seq[Animal] 的子类型 只读容器
逆变 contravariant Handler[Animal] 是 Handler[Cat] 的子类型 消费者 / 回调 
from typing import TypeVar, Generic

T_co = TypeVar("T_co", covariant=True)

class ReadOnlyList(Generic[T_co]):
    def __init__(self, items: list[T_co]) -> None:
        self._items = items

    def get(self, index: int) -> T_co:
        return self._items[index]


最佳实践
    

  • 简单场景用 TypeVar，装饰器场景用 ParamSpec
    • 

  • Python 3.12+ 项目优先使用新语法 def f[T](x: T) -> T
    • 

  • 为只读容器声明协变类型参数，避免不必要的类型不兼容
    • 

  • 避免过度泛型化——如果函数只用于 str，直接标注 str 即可
    • 

  • 使用 bound 约束而非多值约束来表达"至少实现某接口"的语义
    • 

  • 区分 bound 和值约束的适用场景：层级继承用 bound，枚举类型用值约束
