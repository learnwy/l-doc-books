元编程 简介

元编程（Metaprogramming）是"编写操作代码的代码"。Python 凭借其动态特性，提供了从装饰器到元类的完整元编程工具链。本章深入讲解 Python 元编程的四大核心技术。

本章内容

节 主题 核心要点
01 装饰器进阶 参数化装饰器、类装饰器、装饰器栈
02 描述符与属性协议 __get__/__set__、property 原理
03 元类与类工厂 __new__/__init_subclass__、type
04 代码生成与 AST ast 模块、exec/eval、代码模板

核心观点
    

  • 装饰器优先：90% 的元编程需求可用装饰器解决，元类是最后手段
    • 

  • 描述符是基石：property、classmethod、staticmethod 底层都是描述符协议
    • 

  • 约定优于魔法：元编程虽强大，但过度使用会降低代码可读性
    • 

  • 现代替代：dataclasses 和 attrs 封装了常见的元编程模式
