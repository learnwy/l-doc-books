代码生成与 AST

概述

Python 提供了强大的代码内省和生成能力。通过 ast 模块可以解析、分析和修改 Python 源码的抽象语法树；通过 exec/eval 可以动态执行代码；通过代码生成技术可以自动化重复的模板代码。这些能力是 linter、代码格式化工具和高级框架的基础。

AST 基础

解析源码为 AST

import ast

source = """
def add(a: int, b: int) -> int:
    return a + b
"""

tree = ast.parse(source)
print(ast.dump(tree, indent=2))

AST 遍历与分析
NodeVisitor 模式
import ast

class FunctionCounter(ast.NodeVisitor):
    def __init__(self):
        self.count = 0

    def visit_FunctionDef(self, node: ast.FunctionDef):
        self.count += 1
        print(f"Found function: {node.name} at line {node.lineno}")
        self.generic_visit(node)

with open("example.py") as f:
    tree = ast.parse(f.read())

counter = FunctionCounter()
counter.visit(tree)
print(f"Total functions: {counter.count}")
实用分析示例
class ImportAnalyzer(ast.NodeVisitor):
    def __init__(self):
        self.imports: list[str] = []

    def visit_Import(self, node: ast.Import):
        for alias in node.names:
            self.imports.append(alias.name)

    def visit_ImportFrom(self, node: ast.ImportFrom):
        self.imports.append(f"from {node.module}")


AST 转换
NodeTransformer 模式
class DebugTransformer(ast.NodeTransformer):
    def visit_FunctionDef(self, node: ast.FunctionDef):
        debug_print = ast.parse(
            f'print("Entering {node.name}")'
        ).body[0]
        node.body.insert(0, debug_print)
        ast.fix_missing_locations(node)
        return self.generic_visit(node)

source = "def greet(name): return f'Hello, {name}'"
tree = ast.parse(source)
tree = DebugTransformer().visit(tree)
exec(compile(tree, "<string>", "exec"))

代码生成实战
自动生成 __init__ 方法
def auto_init(cls):
    import inspect
    annotations = cls.__annotations__
    params = ", ".join(f"{name}: {typ.__name__}" for name, typ in annotations.items())
    assigns = "\n    ".join(f"self.{name} = {name}" for name in annotations)
    code = f"def __init__(self, {params}):\n    {assigns}"
    namespace: dict = {}
    for typ in annotations.values():
        namespace[typ.__name__] = typ
    exec(code, namespace)
    cls.__init__ = namespace["__init__"]
    return cls

@auto_init
class Point:
    x: float
    y: float

method_template = Template("""

code = method_template.substitute(name="age", type="int")


inspect 模块
import inspect

def analyze_function(func):
    sig = inspect.signature(func)
    for name, param in sig.parameters.items():
        print(f"{name}: {param.annotation}, default={param.default}")

    source = inspect.getsource(func)
    print(f"Source lines: {len(source.splitlines())}")

最佳实践
    

  • AST 分析适用于 linter、代码审查工具、自动文档生成
    • 

  • 避免在生产代码中使用 exec/eval，它们是安全隐患
    • 

  • 需要安全求值时使用 ast.literal_eval
    • 

  • 代码生成优先使用 dataclasses / attrs 等成熟方案
    • 

  • 使用 ast.fix_missing_locations() 确保转换后的 AST 可编译
    • 

  • 复杂的 AST 操作考虑使用 libcst（保留格式的 CST 库）
