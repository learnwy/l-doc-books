元类与类工厂

概述

在 Python 中，类本身也是对象——它们是 type 的实例。元类（Metaclass）就是"类的类"，它控制类的创建过程。虽然大多数场景下不需要元类，但理解元类机制能帮助你深入理解 Python 对象模型，并在必要时实现高级框架功能。

type 是一切类的元类

class Foo:
    pass

print(type(Foo))        # <class 'type'>
print(type(int))        # <class 'type'>
print(type(type))       # <class 'type'>
type 既是所有类的元类，也是自身的实例——这是 Python 对象模型的"原点"。




用 type 动态创建类
def greet(self):
    return f"Hello, {self.name}"

User = type("User", (object,), {"name": "default", "greet": greet})

u = User()
u.name = "Alice"
print(u.greet())
type(name, bases, namespace) 三个参数分别对应类名、基类元组和类属性字典。




自定义元类
class ValidatedMeta(type):
    def __new__(mcs, name, bases, namespace):
        cls = super().__new__(mcs, name, bases, namespace)
        for key, value in namespace.items():
            if isinstance(value, type) and issubclass(value, Exception):
                raise TypeError(f"Class {name} cannot have Exception subclass as attribute")
        return cls

class MyModel(metaclass=ValidatedMeta):
    name: str = "default"

__init_subclass__：轻量替代元类
Python 3.6 引入的 __init_subclass__ 是元类的轻量替代方案：


class Plugin:
    registry: dict[str, type] = {}

    def __init_subclass__(cls, plugin_name: str = "", **kwargs):
        super().__init_subclass__(**kwargs)
        name = plugin_name or cls.__name__.lower()
        Plugin.registry[name] = cls

class JSONPlugin(Plugin, plugin_name="json"):
    pass

class XMLPlugin(Plugin, plugin_name="xml"):
    pass

print(Plugin.registry)

dataclasses：声明式类工厂
from dataclasses import dataclass, field

@dataclass(frozen=True, slots=True)
class Point:
    x: float
    y: float
    label: str = field(default="origin", repr=False)

    @property
    def distance(self) -> float:
        return (self.x ** 2 + self.y ** 2) ** 0.5

attrs 库
import attrs

@attrs.define
class User:
    name: str = attrs.field(validator=attrs.validators.instance_of(str))
    age: int = attrs.field(validator=[
        attrs.validators.instance_of(int),
        attrs.validators.ge(0),
    ])
    email: str = attrs.field(default="")

抽象基类元类
from abc import ABCMeta, abstractmethod

class Shape(metaclass=ABCMeta):
    @abstractmethod
    def area(self) -> float: ...

    @abstractmethod
    def perimeter(self) -> float: ...

class Circle(Shape):
    def __init__(self, radius: float):
        self.radius = radius

    def area(self) -> float:
        return 3.14159 * self.radius ** 2

    def perimeter(self) -> float:
        return 2 * 3.14159 * self.radius
ABCMeta 在类创建时检查是否所有抽象方法都已实现，未实现则禁止实例化。
