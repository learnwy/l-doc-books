描述符与属性协议

概述

描述符（Descriptor）是 Python 属性访问机制的核心。property、classmethod、staticmethod 乃至 ORM 的字段定义，底层都依赖描述符协议。理解描述符，就是理解 Python 属性查找的完整链路。

描述符协议

描述符是定义了以下任一方法的对象：

方法 触发时机 类型
__get__(self, obj, objtype) 读取属性时 数据/非数据
__set__(self, obj, value) 设置属性时 数据描述符
__delete__(self, obj) 删除属性时 数据描述符
__set_name__(self, owner, name) 类创建时自动调用 辅助方法

基本示例
类型验证描述符
class Typed:
    def __init__(self, expected_type: type):
        self.expected_type = expected_type
        self.name = ""

    def __set_name__(self, owner: type, name: str):
        self.name = name

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return obj.__dict__.get(self.name)

    def __set__(self, obj, value):
        if not isinstance(value, self.expected_type):
            raise TypeError(
                f"{self.name} must be {self.expected_type.__name__}, "
                f"got {type(value).__name__}"
            )
        obj.__dict__[self.name] = value

class User:
    name = Typed(str)
    age = Typed(int)

    def __init__(self, name: str, age: int):
        self.name = name
        self.age = age


property 的描述符本质
property 是最常见的数据描述符：


class Temperature:
    def __init__(self, celsius: float = 0):
        self._celsius = celsius

    @property
    def fahrenheit(self) -> float:
        return self._celsius * 9 / 5 + 32

    @fahrenheit.setter
    def fahrenheit(self, value: float):
        self._celsius = (value - 32) * 5 / 9
property 等价于：


class property:
    def __init__(self, fget=None, fset=None, fdel=None, doc=None): ...
    def __get__(self, obj, objtype=None): ...
    def __set__(self, obj, value): ...
    def __delete__(self, obj): ...


实用描述符模式
延迟计算（Lazy Property）
class LazyProperty:
    def __init__(self, func):
        self.func = func
        self.name = ""

    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        value = self.func(obj)
        obj.__dict__[self.name] = value
        return value

class DataProcessor:
    @LazyProperty
    def expensive_result(self):
        import time
        time.sleep(2)
        return 42
首次访问时计算并缓存到实例 __dict__，后续直接读取（非数据描述符优先级低于实例属性）。


范围验证
class Range:
    def __init__(self, min_val: float, max_val: float):
        self.min_val = min_val
        self.max_val = max_val
        self.name = ""

    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return obj.__dict__.get(self.name)

    def __set__(self, obj, value):
        if not self.min_val <= value <= self.max_val:
            raise ValueError(f"{self.name}: {value} not in [{self.min_val}, {self.max_val}]")
        obj.__dict__[self.name] = value

class Config:
    timeout = Range(1, 300)
    retries = Range(0, 10)


__slots__ 与描述符
使用 __slots__ 时，Python 为每个 slot 创建一个隐式的数据描述符：


class Point:
    __slots__ = ("x", "y")

    def __init__(self, x: float, y: float):
        self.x = x
        self.y = y

描述符在 ORM 中的应用
Django、SQLAlchemy 等 ORM 大量使用描述符来定义模型字段：


class Field:
    def __init__(self, column_type: str):
        self.column_type = column_type
        self.name = ""

    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return obj.__dict__.get(self.name)

    def __set__(self, obj, value):
        obj.__dict__[self.name] = value

class Model:
    id = Field("INTEGER PRIMARY KEY")
    name = Field("VARCHAR(100)")


最佳实践
    

  • 使用 __set_name__ 自动获取属性名，避免在构造时重复传入
    • 

  • 非数据描述符适用于缓存场景（LazyProperty），数据描述符适用于验证场景
    • 

  • 优先使用 property 和 functools.cached_property，只在需要复用逻辑时自定义描述符
    • 

  • 描述符存储数据应写入 obj.__dict__ 而非描述符自身，避免实例间数据共享
    • 

  • 理解属性查找链：数据描述符 > 实例属性 > 非数据描述符 > __getattr__
