Jupyter 与交互式分析

概述

Jupyter Notebook 将代码、输出、可视化和叙述性文字整合在一个交互式文档中，是数据科学工作流的标准工具。本文介绍 Jupyter 的核心功能、高效使用技巧，以及现代替代方案 JupyterLab 和 VS Code Notebooks。

安装与启动

pip install jupyterlab notebook
jupyter lab
jupyter notebook
工具 特点 适用场景
Jupyter Notebook 经典界面，轻量 快速原型、教学
JupyterLab 完整 IDE 体验 日常分析工作
VS Code Notebooks 与编辑器深度集成 工程化项目
Google Colab 免费 GPU，云端运行 机器学习实验

JupyterLab 是 Jupyter Notebook 的下一代界面，支持多标签页、文件浏览器、终端、扩展系统等 IDE 特性。相比经典 Notebook，JupyterLab 更适合需要同时查看多个文件、对比数据、运行终端命令的复杂分析场景。

Cell 类型与执行

Cell 类型 用途 快捷键
Code 执行 Python 代码 Shift+Enter
Markdown 叙述性文字 Shift+Enter
Raw 原始文本 少用

常用快捷键

快捷键 命令模式操作
A 在上方插入 Cell
B 在下方插入 Cell
DD 删除当前 Cell
M 切换为 Markdown
Y 切换为 Code
Ctrl+/ 注释/取消注释

Jupyter 有两种模式：命令模式（按 Esc 进入，Cell 边框为蓝色）和编辑模式（按 Enter 进入，Cell 边框为绿色）。上述快捷键仅在命令模式下生效。熟练使用快捷键可以大幅提升 Notebook 的编辑效率——避免频繁使用鼠标点击菜单。

魔法命令

行魔法（Line Magic）

%timeit sum(range(1000))
%who str
%pwd
%load_ext autoreload
%autoreload 2

单元魔法（Cell Magic）

%%time
import numpy as np
result = np.random.randn(10_000_000).sum()

%%writefile script.py
print("Hello from script!")

%%bash
echo "Current directory:"
pwd

常用魔法命令速查

命令 用途
%timeit 精确计时（多次运行取平均）
%%time 单次运行计时
%matplotlib inline 内联显示图表
%autoreload 2 自动重载修改的模块
%who / %whos 列出当前变量
%store 跨 Notebook 共享变量
%pdb 异常时自动进入调试器

%autoreload 2 是开发阶段最实用的魔法命令之一。它让 Jupyter 在每次执行 Cell 前自动重新加载已修改的外部模块，这样修改 .py 文件后无需重启内核就能看到效果。对于将逻辑封装在外部模块、仅在 Notebook 中调用的工作模式来说不可或缺。

ipywidgets 交互组件

import ipywidgets as widgets
from IPython.display import display

slider = widgets.IntSlider(value=50, min=0, max=100, description="阈值:")

@widgets.interact(threshold=(0, 100, 5))
def filter_data(threshold=50):
    filtered = df[df["score"] >= threshold]
    display(filtered)

nbconvert 导出

jupyter nbconvert --to html analysis.ipynb
jupyter nbconvert --to pdf analysis.ipynb
jupyter nbconvert --to script analysis.ipynb

pip install papermill

工具 用途 场景
nbconvert 格式转换 生成报告
papermill 参数化批量执行 自动化流水线
nbstripout 清除输出后提交 Git 版本控制
jupytext Notebook ↔ .py 互转 代码审查

Notebook 与 Git 版本控制

Notebook 的 .ipynb 文件本质是 JSON，包含代码、输出、元数据。直接提交到 Git 会产生巨大的 diff（尤其是内嵌图片的 base64 数据）。标准做法是在 .gitattributes 中配置 nbstripout 作为 clean filter，提交前自动清除所有输出。配合 jupytext 可以同时维护 .py 纯文本版本用于代码审查。
