数据可视化 Matplotlib/Plotly

概述

数据可视化将数据转化为图形，帮助发现模式、验证假设和传达结论。Python 可视化生态以 Matplotlib 为基础，Seaborn 提供统计图表，Plotly 提供交互式可视化。选择合适的工具和图表类型，是有效数据表达的关键。

Matplotlib 基础

基本绘图

import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 2 * np.pi, 100)
y = np.sin(x)

fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, y, label="sin(x)", color="steelblue", linewidth=2)
ax.set_xlabel("x")
ax.set_ylabel("y")
ax.set_title("正弦函数")
ax.legend()
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig("plot.png", dpi=150)
plt.show()

Matplotlib 有两套 API：过程式（plt.plot()）和面向对象式（fig, ax = plt.subplots()）。面向对象式 API 在多子图、复杂布局、自定义样式等场景中更加灵活可控。建议从入门开始就使用面向对象 API，避免在复杂场景中被过程式 API 的隐式状态管理困扰。

子图布局

fig, axes = plt.subplots(2, 2, figsize=(10, 8))
axes[0, 0].bar(["A", "B", "C"], [10, 20, 15])
axes[0, 1].scatter(np.random.randn(50), np.random.randn(50))
axes[1, 0].hist(np.random.randn(1000), bins=30)
axes[1, 1].pie([30, 40, 30], labels=["X", "Y", "Z"])
plt.tight_layout()

常用图表类型

图表类型 函数 适用场景
折线图 ax.plot() 趋势变化
柱状图 ax.bar() 分类比较
散点图 ax.scatter() 相关性分析
直方图 ax.hist() 分布特征
箱线图 ax.boxplot() 离群值检测
热力图 ax.imshow() 相关矩阵
饼图 ax.pie() 占比分析

选择图表类型时应基于数据关系而非视觉偏好：比较数量用柱状图、展示趋势用折线图、揭示分布用直方图/箱线图、探索相关性用散点图。避免使用 3D 饼图——它扭曲面积比例，降低数据可读性。

Seaborn 统计可视化

import seaborn as sns

tips = sns.load_dataset("tips")

fig, axes = plt.subplots(1, 3, figsize=(15, 5))
sns.histplot(data=tips, x="total_bill", kde=True, ax=axes[0])
sns.boxplot(data=tips, x="day", y="total_bill", ax=axes[1])
sns.scatterplot(data=tips, x="total_bill", y="tip", hue="smoker", ax=axes[2])
plt.tight_layout()

Seaborn 图表速查

函数 类型 特点
histplot() 直方图 支持 KDE 密度估计
boxplot() 箱线图 自动按分类变量分组
violinplot() 小提琴图 分布形状更直观
heatmap() 热力图 相关矩阵可视化
pairplot() 配对图 多变量关系一览
lmplot() 回归图 带拟合线的散点图

Seaborn 的核心优势是与 Pandas DataFrame 的深度集成——直接传入 DataFrame 和列名即可绑定数据，无需手动提取数组。通过 hue、size、style 参数可以在同一张图中同时编码多个维度的信息，大幅提升信息密度。

Plotly 交互式可视化

import plotly.express as px

df = px.data.gapminder()
fig = px.scatter(
    df.query("year == 2007"),
    x="gdpPercap",
    y="lifeExp",
    size="pop",
    color="continent",
    hover_name="country",
    log_x=True,
    title="2007 年全球人均 GDP vs 预期寿命",
)
fig.show()

Plotly vs Matplotlib

特性 Matplotlib Plotly
交互性 静态图 缩放、悬停、选择
输出格式 PNG/SVG/PDF HTML/JSON
学习曲线 中等 低（express API）
定制能力 极强 强
适用场景 论文、报告 仪表板、网页展示

图表设计原则

原则 说明 反例
数据墨水比 最大化数据信息，最小化装饰 3D 饼图
诚实表达 坐标轴从零开始，比例一致 截断 Y 轴夸大差异
色彩无障碍 使用色盲友好的调色板 红绿对比
标签完整 标题、轴标签、图例、单位 无标签的裸图 


样式与主题
plt.style.use("seaborn-v0_8-whitegrid")

sns.set_theme(style="whitegrid", palette="muted", font_scale=1.2)

import plotly.io as pio
pio.templates.default = "plotly_white"
统一的视觉主题对于发布质量的图表至关重要。建议团队定义一套标准的配色方案和字号规范，封装为可复用的主题配置。Matplotlib 支持通过 rcParams 全局设置或自定义 .mplstyle 文件来标准化图表外观。




最佳实践
    

  • 探索阶段用 Plotly Express 快速迭代，发表阶段用 Matplotlib 精细控制
    • 

  • 使用 fig, ax = plt.subplots() 面向对象 API 替代 plt.plot() 过程式 API
    • 

  • 导出高分辨率图片时设置 dpi=300
    • 

  • 使用 Seaborn 的 hue / style 参数在同一图中编码多个维度
    • 

  • 交互式图表使用 Plotly 的 fig.write_html() 导出为独立 HTML 文件
    • 

  • 选择色盲友好的调色板（如 colorblind、viridis），确保图表的无障碍可读性
