Pandas 数据处理

概述

Pandas 是 Python 数据分析的核心库，提供了 DataFrame 和 Series 两种核心数据结构。它让结构化数据的读取、清洗、转换和分析变得直观高效。无论是处理 CSV 文件还是数据库查询结果，Pandas 都是首选工具。

核心数据结构

结构 维度 类比 用途
Series 1D 带索引的一维数组 单列数据
DataFrame 2D 带索引的表格 多列结构化数据 
import pandas as pd

s = pd.Series([10, 20, 30], index=["a", "b", "c"])

df = pd.DataFrame({
    "name": ["Alice", "Bob", "Charlie"],
    "age": [25, 30, 35],
    "score": [90.5, 85.0, 92.3],
})

DataFrame 的内部实现基于 NumPy ndarray——每一列是一个独立的 ndarray，不同列可以有不同的 dtype。这种列存储设计使得按列操作（如计算某列的均值）非常高效，但按行迭代则较慢（需要跨越多个数组）。

数据读写

df = pd.read_csv("data.csv")
df = pd.read_excel("data.xlsx", sheet_name="Sheet1")
df = pd.read_json("data.json")
df = pd.read_parquet("data.parquet")

df.to_csv("output.csv", index=False)
df.to_parquet("output.parquet")
格式 读取函数 速度 文件大小 适用场景
CSV read_csv 慢 大 通用交换
Parquet read_parquet 快 小 大数据分析
Excel read_excel 慢 中 业务报表
JSON read_json 中 中 API 数据

读取大型 CSV 文件时，可以通过 usecols 只加载需要的列、dtype 指定列类型避免自动推断开销、chunksize 分块读取避免内存溢出。例如 pd.read_csv("big.csv", usecols=["id", "value"], dtype={"id": "int32"}) 可以显著减少内存占用。

分组与聚合

grouped = df.groupby("department").agg(
    avg_salary=("salary", "mean"),
    total_count=("name", "count"),
    max_score=("score", "max"),
)

pivot = df.pivot_table(
    values="sales",
    index="region",
    columns="quarter",
    aggfunc="sum",
    fill_value=0,
)
方法 用途 返回类型
groupby() 按列分组 GroupBy 对象
agg() 多聚合函数 DataFrame
transform() 保持原形状的变换 Series
pivot_table() 透视表 DataFrame

transform() 和 agg() 的关键区别在于：agg() 返回聚合后的缩减结果（行数减少），而 transform() 返回与原始 DataFrame 相同长度的结果，适合用于组内标准化、组内排名等场景。例如 df["dept_avg"] = df.groupby("dept")["salary"].transform("mean") 会为每行填入其所在部门的平均工资。

合并与连接

merged = pd.merge(df1, df2, on="user_id", how="left")
concatenated = pd.concat([df1, df2], axis=0, ignore_index=True)
合并方式 参数 说明
内连接 how="inner" 仅保留两边都有的行
左连接 how="left" 保留左表所有行
右连接 how="right" 保留右表所有行
全外连接 how="outer" 保留所有行

Polars：高性能替代

import polars as pl

df = pl.read_csv("data.csv")
result = (
    df.filter(pl.col("age") > 18)
    .group_by("department")
    .agg(pl.col("salary").mean().alias("avg_salary"))
    .sort("avg_salary", descending=True)
)
特性 Pandas Polars
引擎 C / Cython Rust
并行 单线程 多线程
惰性求值 不支持 支持（LazyFrame）
API 风格 方法链 + 索引 表达式链
内存 较高 较低

最佳实践

  • 使用 Parquet 格式存储中间数据，比 CSV 快 5-10 倍
  • 用 query() 替代布尔索引链提升可读性
  • 避免逐行 iterrows() 循环，改用向量化操作或 apply()
  • 大数据集（>1GB）考虑使用 Polars 或 Dask
  • 设置 pd.options.display.max_columns = None 查看完整列
  • 使用 transform() 做组内计算以保持原始索引对齐
