异步 IO 与网络

概述

异步编程的最大价值体现在 I/O 密集型场景：网络请求、文件读写、数据库查询。Python 生态已有丰富的异步 I/O 库，以 aiohttp（HTTP 客户端/服务器）、asyncpg（PostgreSQL）、aiofiles（文件）为代表，覆盖了绝大多数生产需求。

aiohttp 异步 HTTP

客户端请求

import aiohttp
import asyncio

async def fetch(url: str) -> str:
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as response:
            return await response.text()

async def main():
    urls = [
        "https://httpbin.org/get",
        "https://httpbin.org/ip",
        "https://httpbin.org/headers",
    ]
    tasks = [fetch(url) for url in urls]
    results = await asyncio.gather(*tasks)
    for r in results:
        print(r[:100])

asyncio.run(main())

复用 ClientSession

模式 连接池 性能 适用场景
每次创建新 Session 否 ❌ 差 仅测试
全局复用 Session 是 ✅ 好 长期运行的服务
上下文管理器 是 ✅ 好 脚本或批量任务

httpx：同步/异步双模

import httpx

async def fetch_with_httpx():
    async with httpx.AsyncClient() as client:
        response = await client.get("https://httpbin.org/get")
        return response.json()

aiohttp vs httpx

特性 aiohttp httpx
协议支持 HTTP/1.1 HTTP/1.1 + HTTP/2
同步模式 不支持 支持
API 风格 独立设计 类似 requests
WebSocket 内置支持 需第三方
性能 略优 接近

异步数据库驱动

asyncpg（PostgreSQL）

import asyncpg

async def query_users():
    conn = await asyncpg.connect("postgresql://user:pass@localhost/db")
    rows = await conn.fetch("SELECT id, name FROM users WHERE active = $1", True)
    for row in rows:
        print(row["id"], row["name"])
    await conn.close()

主流异步数据库驱动

数据库 异步驱动 特点
PostgreSQL asyncpg C 扩展，极高性能
MySQL aiomysql 基于 PyMySQL
SQLite aiosqlite 线程池包装
Redis redis.asyncio 官方异步支持
MongoDB motor 基于 pymongo 的异步封装

异步文件操作

import aiofiles

async def read_config():
    async with aiofiles.open("config.yaml", mode="r") as f:
        content = await f.read()
    return content

async def write_log(message: str):
    async with aiofiles.open("app.log", mode="a") as f:
        await f.write(f"{message}\n")

aiofiles 通过线程池将同步文件操作包装为异步接口，避免阻塞事件循环。

异步上下文管理器

from contextlib import asynccontextmanager

@asynccontextmanager
async def db_connection(dsn: str):
    conn = await asyncpg.connect(dsn)
    try:
        yield conn
    finally:
        await conn.close()

async def main():
    async with db_connection("postgresql://...") as conn:
        rows = await conn.fetch("SELECT 1")

异步迭代器

class AsyncPaginator:
    def __init__(self, url: str, per_page: int = 20):
        self.url = url
        self.page = 1
        self.per_page = per_page

    def __aiter__(self):
        return self

    async def __anext__(self) -> list[dict]:
        async with aiohttp.ClientSession() as session:
            async with session.get(
                self.url, params={"page": self.page, "per_page": self.per_page}
            ) as resp:
                data = await resp.json()
                if not data:
                    raise StopAsyncIteration
                self.page += 1
                return data

run_in_executor 桥接同步库

import asyncio
from concurrent.futures import ThreadPoolExecutor

def sync_heavy_io():
    import time
    time.sleep(2)
    return "done"

async def main():
    loop = asyncio.get_running_loop()
    with ThreadPoolExecutor(max_workers=4) as pool:
        result = await loop.run_in_executor(pool, sync_heavy_io)
        print(result)
场景 方案 说明
CPU 密集型 ProcessPoolExecutor 绕过 GIL
同步 I/O 库 ThreadPoolExecutor 如 PIL、旧版 DB 驱动
纯异步库可用 直接 await 最佳方案

最佳实践

  • 全局复用 ClientSession / 数据库连接池，避免频繁创建销毁
  • 优先选择原生异步驱动（asyncpg > psycopg2 + executor）
  • 对无异步版本的库使用 run_in_executor 桥接
  • 使用 async with 确保资源（连接、文件句柄）正确关闭
  • 为 HTTP 请求设置合理的超时和重试策略
