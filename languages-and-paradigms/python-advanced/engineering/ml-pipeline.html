ML Pipeline 与部署

概述

从 Jupyter Notebook 中的实验代码到可复现、可部署的机器学习系统，需要将数据处理和模型训练组织为标准化的 Pipeline。本文介绍 scikit-learn Pipeline、MLflow 实验追踪，以及模型服务化部署的最佳实践。

scikit-learn Pipeline

基本管道

from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier

pipe = Pipeline([
    ("scaler", StandardScaler()),
    ("clf", RandomForestClassifier(n_estimators=100)),
])

pipe.fit(X_train, y_train)
score = pipe.score(X_test, y_test)
predictions = pipe.predict(X_new)

列变换器

from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler

preprocessor = ColumnTransformer([
    ("num", StandardScaler(), ["age", "income"]),
    ("cat", OneHotEncoder(handle_unknown="ignore"), ["gender", "city"]),
])

full_pipe = Pipeline([
    ("preprocess", preprocessor),
    ("clf", RandomForestClassifier()),
])

自定义 Transformer

当内置的预处理步骤无法满足需求时，可以通过继承 BaseEstimator 和 TransformerMixin 创建自定义 Transformer，使其无缝嵌入 Pipeline：

from sklearn.base import BaseEstimator, TransformerMixin
import numpy as np

class LogTransformer(BaseEstimator, TransformerMixin):
    def __init__(self, offset=1.0):
        self.offset = offset

    def fit(self, X, y=None):
        return self

    def transform(self, X):
        return np.log(X + self.offset)

超参搜索 与 GridSearchCV 无缝集成

超参数调优

from sklearn.model_selection import GridSearchCV

param_grid = {
    "clf__n_estimators": [50, 100, 200],
    "clf__max_depth": [5, 10, None],
}

search = GridSearchCV(full_pipe, param_grid, cv=5, scoring="accuracy", n_jobs=-1)
search.fit(X_train, y_train)
print(search.best_params_)
print(search.best_score_)
方法 搜索策略 适用场景
GridSearchCV 网格搜索 参数空间小
RandomizedSearchCV 随机搜索 参数空间大

MLflow 实验追踪

import mlflow

mlflow.set_experiment("classification-v1")

with mlflow.start_run():
    mlflow.log_param("n_estimators", 100)
    mlflow.log_param("max_depth", 10)

    pipe.fit(X_train, y_train)
    accuracy = pipe.score(X_test, y_test)

    mlflow.log_metric("accuracy", accuracy)
    mlflow.sklearn.log_model(pipe, "model")
mlflow ui --port 5000

模型服务化

FastAPI 部署

from fastapi import FastAPI
from pydantic import BaseModel
import joblib

app = FastAPI()
model = joblib.load("model.joblib")

class PredictRequest(BaseModel):
    age: float
    income: float
    gender: str
    city: str

class PredictResponse(BaseModel):
    prediction: int
    probability: float

@app.post("/predict", response_model=PredictResponse)
def predict(req: PredictRequest):
    import pandas as pd
    df = pd.DataFrame([req.model_dump()])
    pred = model.predict(df)[0]
    prob = model.predict_proba(df)[0].max()
    return PredictResponse(prediction=int(pred), probability=float(prob))

Docker 容器化

FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

健康检查与版本管理

生产环境中模型服务需要包含健康检查端点和模型版本信息，以便于运维监控和灰度发布：

@app.get("/health")
def health():
    return {"status": "ok", "model_version": "v1.2.0"}
