sed 流编辑器

核心概念

sed（Stream Editor）是一种面向行的流式文本编辑器，它逐行读取输入，对每行应用编辑命令，然后将结果输出到标准输出。sed 的核心设计理念是"非交互式编辑"——它不需要打开文件进行手动修改，而是通过脚本化的方式批量处理文本，这使其成为 Shell 脚本中自动化文本处理的首选工具。

sed 使用两个缓冲区工作：模式空间（Pattern Space）和保持空间（Hold Space）。模式空间是当前正在处理的行，保持空间是一个辅助缓冲区，可以在处理过程中暂存数据。

替换命令详解
替换（s）是 sed 最常用的命令，语法为 s/模式/替换/标志：


echo "hello world" | sed 's/world/Shell/'

sed 's/http:/https:/' urls.txt

sed 's/old/new/g' file.txt

sed 's/error/ERROR/gi' log.txt

sed 's|/usr/local|/opt|g' paths.txt
sed 's#http://#https://#g' urls.txt

echo "2025-04-11" | sed 's/\([0-9]\{4\}\)-\([0-9]\{2\}\)-\([0-9]\{2\}\)/\3\/\2\/\1/'

echo "hello world" | sed -E 's/(hello) (world)/\2 \1/'

echo "foobar" | sed 's/\(foo\)\(bar\)/\2_\1/'

sed -E 's/^([[:space:]]*)"([^"]+)":/\1\2:/' config.json

echo "path/to/file.txt" | sed 's/.*\///'    # file.txt
echo "path/to/file.txt" | sed 's/\.[^.]*$//' # path/to/file

sed 's/password=.*/password=***REDACTED***/' config.txt

sed -E 's/[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}/[IP_REMOVED]/g' access.log
多重替换和条件替换：


sed -e 's/foo/bar/g' -e 's/baz/qux/g' file.txt

sed '
    s/Monday/周一/g
    s/Tuesday/周二/g
    s/Wednesday/周三/g
    s/Thursday/周四/g
    s/Friday/周五/g
' schedule.txt

sed '/^#/! s/localhost/production-host/g' config.txt

sed '10,20 s/old/new/g' file.txt

sed '0,/pattern/ s/pattern/replacement/' file.txt
地址与范围选择
sed 的地址机制决定了命令作用于哪些行：


sed '5d' file.txt                      # 删除第 5 行
sed '$d' file.txt                      # 删除最后一行
sed '3,7d' file.txt                    # 删除第 3-7 行
sed '1,/^END/d' file.txt              # 删除从第 1 行到匹配 END 的行

sed -n '10,20p' file.txt               # 打印第 10-20 行

sed '/^$/d' file.txt                   # 删除空行
sed '/^#/d' config.txt                 # 删除注释行
sed '/^[[:space:]]*$/d' file.txt       # 删除空白行

sed -n '/START/,/END/p' file.txt       # 打印两个模式之间的行

sed '0~2d' file.txt                    # 删除偶数行
sed '1~2d' file.txt                    # 删除奇数行

sed '/pattern/!d' file.txt             # 删除不匹配的行（类似 grep）

sed '1,5{
    s/old/new/g
    /^$/d
}' file.txt
实用编辑操作
除替换外，sed 还支持多种行级编辑操作：


sed '3i\这是插入的新行' file.txt

sed '5a\这是追加的新行' file.txt

sed '/^server {/a\    listen 443 ssl;' nginx.conf

sed '/^import/a\import { newModule } from "./new";' app.ts

sed '/deprecated/c\// 此功能已重构' code.ts

sed -i.bak 's/old/new/g' file.txt

find . -name "*.ts" -exec sed -i '' 's/oldImport/newImport/g' {} +

sed -n 's/.*"version": "\([^"]*\)".*/\1/p' package.json

sed -n 's/.*error.*code=\([0-9]*\).*/\1/p' error.log

sed -E 's/^[[:space:]]+//;s/[[:space:]]+$//' file.txt

sed 'G' file.txt            # 每行后加空行
sed '/^$/d;G' file.txt      # 先删空行再加空行（规范化间距）

sed '=' file.txt | sed 'N;s/\n/\t/'  # 给每行加行号

sed -E '/^[[:space:]]*$/{ N; /^\n[[:space:]]*$/d }' file.txt
高级模式空间操作
sed 的保持空间（Hold Space）支持跨行处理，这是 sed 最强大但也最难掌握的功能：


sed -n '
    /error/{
        N            # 追加下一行到模式空间
        p            # 打印（包含当前行和下一行）
    }
' log.txt

sed -n '
    /START/,/END/{
        H            # 追加到保持空间
    }
    /END/{
        g            # 保持空间 -> 模式空间
        s/\n/ /g     # 将换行替换为空格
        p
    }
' multi-line.txt

sed '/^$/{
    N
    /^\n$/d         # 将连续空行压缩为一个
}' file.txt

sed -n '1!G;h;$p' file.txt    # 反转文件行序（等同 tac）

sed '/\\$/{
    N
    s/\\\n//
}' continued.txt

sed -E ':loop; /\{[^}]*$/ { N; b loop }; s/\n\s*/ /g' code.json
配置文件批量修改的实战示例：


update_config() {
    local key="$1" value="$2" file="$3"

    if grep -q "^${key}=" "$file"; then
        sed -i '' "s|^${key}=.*|${key}=${value}|" "$file"
    else
        echo "${key}=${value}" >> "$file"
    fi
}

update_config "DB_HOST" "production.db.example.com" ".env"
update_config "LOG_LEVEL" "warn" ".env"

sed -i '' '
    /\[database\]/,/^\[/ {
        s/host = .*/host = new-db.example.com/
        s/port = .*/port = 5433/
    }
' config.ini
小结
    

  • sed 是面向行的流式编辑器，通过模式空间逐行处理文本
    • 

  • s/old/new/flags 替换命令是最常用的操作，支持正则表达式和反向引用
    • 

  • 地址机制支持行号、正则模式、范围选择，决定命令的作用范围
    • 

  • -i 选项直接修改原文件（macOS 需要 -i ''，Linux 使用 -i 或 -i.bak）
    • 

  • 保持空间（Hold Space）支持跨行处理，适用于多行模式匹配
    • 

  • -E 选项启用扩展正则表达式，避免繁琐的转义
    • 

  • 实际工程中，sed 常用于配置文件修改、日志清洗、批量代码重构
    • 

  • 复杂的多行处理建议考虑 awk 或 Python，sed 的保持空间虽强大但可读性较差
    •
