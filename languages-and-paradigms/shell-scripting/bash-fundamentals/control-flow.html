流程控制

核心概念

Shell 脚本的流程控制结构决定了代码的执行路径和循环行为。与其他编程语言不同，Shell 的条件判断基于命令的退出状态码（exit status）而非布尔表达式——退出码为 0 表示成功（true），非 0 表示失败（false）。这一设计使得 Shell 可以直接将命令执行结果作为条件判断依据。

Bash 提供了 if/elif/else、case、for、while、until、select 等控制结构，以及 test/[/[[ 三种条件测试方式。

算术比较





条件判断
if 语句是最基本的条件控制结构。它根据命令的退出状态码决定执行哪个分支：


if grep -q "error" /var/log/app.log; then
    echo "发现错误日志"
elif grep -q "warning" /var/log/app.log; then
    echo "发现警告日志"
else
    echo "日志正常"
fi

if [[ -f "/etc/nginx/nginx.conf" ]]; then
    echo "Nginx 配置文件存在"
fi

if [[ -d "$HOME/.ssh" && -f "$HOME/.ssh/id_rsa" ]]; then
    echo "SSH 密钥已配置"
fi
[[ ]] 是 Bash 增强的条件测试，支持更丰富的操作符：


file="/var/log/app.log"
[[ -e "$file" ]]   # 文件存在
[[ -f "$file" ]]   # 是普通文件
[[ -d "$file" ]]   # 是目录
[[ -r "$file" ]]   # 可读
[[ -w "$file" ]]   # 可写
[[ -x "$file" ]]   # 可执行
[[ -s "$file" ]]   # 文件非空
[[ -L "$file" ]]   # 是符号链接

str="hello"
[[ -n "$str" ]]    # 字符串非空
[[ -z "$str" ]]    # 字符串为空
[[ "$str" == "hello" ]]   # 字符串相等
[[ "$str" != "world" ]]   # 字符串不等
[[ "$str" =~ ^hel ]]      # 正则匹配
[[ "$str" == h* ]]         # 通配符匹配

num=42
(( num > 10 ))         # 算术比较
(( num >= 40 && num <= 50 ))
[[ "$num" -gt 10 ]]    # test 风格的数字比较
[[ "$num" -eq 42 ]]
逻辑运算符的组合使用：


check_environment() {
    local required_tools=("git" "node" "docker")

    for tool in "${required_tools[@]}"; do
        if ! command -v "$tool" &> /dev/null; then
            echo "缺少必要工具: $tool"
            return 1
        fi
    done

    if [[ ! -f "package.json" ]]; then
        echo "不在项目根目录"
        return 1
    fi

    echo "环境检查通过"
    return 0
}

if check_environment; then
    echo "开始部署..."
fi
循环结构
for 循环有两种形式：for-in 遍历和 C 风格计数循环。


for fruit in apple banana cherry; do
    echo "水果: $fruit"
done

for file in /var/log/*.log; do
    if [[ -f "$file" ]]; then
        echo "日志文件: $(basename "$file"), 大小: $(du -h "$file" | cut -f1)"
    fi
done

for i in {1..10}; do
    echo "迭代 $i"
done

for ((i = 0; i < 10; i++)); do
    echo "计数: $i"
done

mapfile -t lines < input.txt
for line in "${lines[@]}"; do
    echo "行: $line"
done
while 循环在条件为真时持续执行，until 循环则在条件为假时执行：


count=0
while (( count < 5 )); do
    echo "count = $count"
    ((count++))
done

while IFS= read -r line; do
    echo "处理: $line"
done < /etc/hosts

find /project -name "*.ts" -print0 | while IFS= read -r -d '' file; do
    echo "TypeScript 文件: $file"
done

max_retries=5
attempt=0
until curl -sf "http://localhost:8080/health" > /dev/null 2>&1; do
    ((attempt++))
    if (( attempt >= max_retries )); then
        echo "服务启动超时"
        exit 1
    fi
    echo "等待服务启动... (尝试 $attempt/$max_retries)"
    sleep 2
done
echo "服务已就绪"
循环控制语句 break 和 continue 用于中断或跳过循环迭代：


for i in {1..100}; do
    if (( i % 15 == 0 )); then
        echo "$i: FizzBuzz"
    elif (( i % 3 == 0 )); then
        continue
    elif (( i > 30 )); then
        break
    fi
done

for dir in */; do
    [[ -f "${dir}package.json" ]] || continue
    echo "处理 Node 项目: $dir"
done
case 模式匹配
case 语句提供了强大的模式匹配能力，是处理多分支逻辑的首选方式，比多层 if-elif 更简洁：


handle_signal() {
    case "$1" in
        SIGINT|SIGTERM)
            echo "收到终止信号，清理中..."
            cleanup
            exit 0
            ;;
        SIGHUP)
            echo "重新加载配置..."
            reload_config
            ;;
        *)
            echo "未知信号: $1"
            ;;
    esac
}

parse_option() {
    case "$1" in
        -v|--verbose)   VERBOSE=true ;;
        -q|--quiet)     QUIET=true ;;
        -o|--output)    OUTPUT="$2"; shift ;;
        -h|--help)      show_help; exit 0 ;;
        -*)             echo "未知选项: $1" >&2; exit 1 ;;
        *)              ARGS+=("$1") ;;
    esac
}

detect_os() {
    case "$(uname -s)" in
        Linux*)     OS="linux" ;;
        Darwin*)    OS="macos" ;;
        CYGWIN*|MINGW*|MSYS*) OS="windows" ;;
        *)          OS="unknown" ;;
    esac
    echo "检测到操作系统: $OS"
}

validate_email() {
    case "$1" in
        *@*.*)  echo "邮箱格式有效" ;;
        *)      echo "邮箱格式无效" ;;
    esac
}

process_file() {
    case "${1,,}" in
        *.tar.gz|*.tgz) tar xzf "$1" ;;
        *.tar.bz2)      tar xjf "$1" ;;
        *.zip)          unzip "$1" ;;
        *.7z)           7z x "$1" ;;
        *)              echo "不支持的格式: $1" ;;
    esac
}
Bash 4.0+ 支持 ;&（fall-through）和 ;;&（继续测试）：


log_level="warning"
case "$log_level" in
    error)
        echo "错误"
        ;;&
    warning)
        echo "警告"
        ;;&
    info)
        echo "信息"
        ;;
esac
高级控制技巧
条件执行操作符 && 和 || 提供了简洁的控制流：


mkdir -p /tmp/build && cd /tmp/build && make

command -v docker > /dev/null || { echo "请先安装 Docker"; exit 1; }

[[ -f config.yml ]] && source_config || use_defaults

run_with_timeout() {
    local timeout=$1
    shift

    "$@" &
    local pid=$!

    (
        sleep "$timeout"
        kill -TERM "$pid" 2>/dev/null
    ) &
    local watcher=$!

    wait "$pid" 2>/dev/null
    local result=$?

    kill -TERM "$watcher" 2>/dev/null
    wait "$watcher" 2>/dev/null

    return $result
}

run_with_timeout 30 curl -s "https://api.example.com/data"
select 语句创建交互式菜单：


select_environment() {
    PS3="请选择部署环境: "
    select env in "development" "staging" "production" "退出"; do
        case "$env" in
            development|staging|production)
                echo "选择了: $env"
                DEPLOY_ENV="$env"
                break
                ;;
            "退出")
                exit 0
                ;;
            *)
                echo "无效选择，请重试"
                ;;
        esac
    done
}
小结
    

  • Shell 的条件判断基于命令退出状态码（0=true, 非0=false），而非布尔表达式
    • 

  • [[ ]] 是 Bash 增强测试，支持正则匹配和通配符，推荐在 Bash 脚本中使用
    • 

  • (( )) 专用于算术比较，支持 C 风格的运算符
    • 

  • for-in 适合遍历列表，C 风格 for 适合计数循环
    • 

  • while read 是逐行处理文件内容的标准模式，配合 IFS= 和 -r 防止意外行为
    • 

  • case 语句支持通配符模式匹配，是多分支逻辑的首选
    • 

  • && 和 || 操作符提供简洁的条件执行控制流
    • 

  • 循环中的 break 和 continue 用于精细控制迭代行为
    •
