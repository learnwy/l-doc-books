变量与数据类型

核心概念

Shell 中的变量本质上都是字符串，这与大多数编程语言有根本区别。Bash 没有内置的整数、浮点数或布尔类型——所有数据都以文本形式存储，仅在特定上下文（如算术运算或 declare -i）中才被解释为其他类型。理解这一设计哲学是避免 Shell 脚本中各种微妙错误的关键。

Shell 变量分为局部变量、环境变量和特殊变量三大类。局部变量仅在当前 Shell 进程中可见，环境变量通过 export 导出后可被子进程继承，特殊变量由 Shell 自动维护（如 $?、`

`、`$@`）。 ```mermaid graph TD A[Shell 变量体系] --> B[局部变量] A --> C[环境变量] A --> D[特殊变量] B --> B1[用户自定义 name=value] B --> B2[函数内 local var=value] C --> C1[export 导出] C --> C2[系统预设 PATH HOME] D --> D1[位置参数 $1 $2 $@] D --> D2[状态变量 $?

$!] D --> D3[脚本信息 000# LINENO]


| 变量类别      | 作用域              | 声明方式             | 子进程继承 | 典型用途     |
| ------------- | ------------------- | -------------------- | ---------- | ------------ |
| 局部变量      | 当前 Shell          | `var=value`          | 否         | 脚本内部逻辑 |
| 环境变量      | 当前 Shell + 子进程 | `export var=value`   | 是         | 跨进程配置   |
| local 变量    | 函数内部            | `local var=value`    | 否         | 函数封装     |
| readonly 变量 | 当前 Shell          | `readonly var=value` | 否         | 常量定义     |
| 位置参数      | 当前脚本/函数       | 自动设置             | 否         | 命令行参数   |

## 变量赋值与引用

变量赋值时等号两边不能有空格，这是 Shell 新手最常犯的错误之一。变量引用时使用 `$` 前缀，花括号 `${}` 可以消除歧义并启用高级操作。

```bash
name="Shell 脚本"
count=42
path=/usr/local/bin

echo $name
echo ${name}
echo "${name}教程"
echo "${name}_advanced"

first="Hello"
second="World"
combined="${first} ${second}"
echo "$combined"

readonly PI=3.14159
readonly APP_VERSION="2.1.0"

引号的使用直接影响变量扩展和词分割行为。双引号允许变量扩展但防止词分割和通配符扩展，单引号完全禁止所有扩展：

files="file1.txt file2.txt"
echo $files             # 词分割：file1.txt 和 file2.txt 作为两个词
echo "$files"           # 保持原样：file1.txt file2.txt 一个字符串

path="/my path/with spaces"
ls $path                # 错误：ls 尝试访问 /my 和 path/with 和 spaces
ls "$path"              # 正确：ls 访问 "/my path/with spaces"

echo "当前用户: $USER"  # 变量被扩展
echo '当前用户: $USER'  # 原样输出 $USER

echo "日期是 $(date)"   # 命令替换会执行
echo '日期是 $(date)'   # 原样输出 $(date)

参数扩展技巧

Bash 提供了丰富的参数扩展语法，可以在变量引用时直接进行字符串操作，避免调用外部命令：

filename="/home/user/documents/report.tar.gz"

echo "${filename##*/}"    # report.tar.gz（删除最长前缀匹配 */）
echo "${filename%.*}"     # /home/user/documents/report.tar（删除最短后缀匹配 .*）
echo "${filename%%.*}"    # /home/user/documents/report（删除最长后缀匹配 .*）
echo "${filename#*/}"     # home/user/documents/report.tar.gz（删除最短前缀匹配 */）

url="https://api.example.com/v1/users"
echo "${url/v1/v2}"       # 替换第一个匹配
echo "${url//\//|}"       # 替换所有 / 为 |

text="Hello World"
echo "${text,,}"          # hello world（全部转小写）
echo "${text^^}"          # HELLO WORLD（全部转大写）
echo "${text,}"           # hello World（首字母转小写）
echo "${text^}"           # Hello World（首字母转大写）

echo "${#text}"           # 11（字符串长度）
echo "${text:6}"          # World（从位置 6 开始截取）
echo "${text:0:5}"        # Hello（从位置 0 截取 5 个字符）
echo "${text: -5}"        # World（从末尾截取 5 个字符，注意冒号后的空格）

默认值和条件赋值在处理可选参数时非常有用：

echo "${DB_HOST:-localhost}"       # 如果 DB_HOST 未设置或为空，返回 localhost
echo "${DB_PORT:=5432}"            # 如果 DB_PORT 未设置或为空，设置为 5432 并返回
echo "${REQUIRED_VAR:?变量未设置}"  # 如果未设置，打印错误并退出
echo "${OPTIONAL:+已设置}"          # 如果 OPTIONAL 已设置且非空，返回"已设置"

config_dir="${XDG_CONFIG_HOME:-$HOME/.config}"
log_level="${LOG_LEVEL:-info}"
max_retries="${MAX_RETRIES:-3}"

数组与关联数组

Bash 支持索引数组和关联数组（Bash 4.0+），是处理批量数据的重要工具。

fruits=("apple" "banana" "cherry" "date")

echo "${fruits[0]}"        # apple
echo "${fruits[-1]}"       # date（最后一个元素）
echo "${fruits[@]}"        # 所有元素
echo "${#fruits[@]}"       # 4（元素个数）

fruits+=("elderberry")
fruits[1]="blueberry"
unset 'fruits[2]'

for fruit in "${fruits[@]}"; do
    echo "水果: $fruit"
done

echo "${fruits[@]:1:2}"    # 切片：从索引 1 开始取 2 个

indices=("${!fruits[@]}")
echo "有效索引: ${indices[*]}"

关联数组（类似于其他语言中的字典/哈希表）需要显式声明：

declare -A config
config[host]="localhost"
config[port]="8080"
config[debug]="true"
config[env]="production"

echo "${config[host]}"
echo "${config[port]}"

for key in "${!config[@]}"; do
    echo "$key = ${config[$key]}"
done

if [[ -v config[debug] ]]; then
    echo "debug 键存在"
fi

unset 'config[debug]'
echo "配置项数量: ${#config[@]}"

特殊变量与位置参数

Shell 预定义了多个特殊变量，自动跟踪脚本的运行状态和参数信息：

echo "脚本名称: $0"
echo "第一个参数: $1"
echo "参数个数: $#"
echo "所有参数（整体）: $*"
echo "所有参数（独立）: $@"
echo "上条命令退出码: $?"
echo "当前进程 PID: $$"
echo "最后一个后台进程 PID: $!"
echo "当前行号: $LINENO"
echo "当前函数名: ${FUNCNAME[0]}"

process_args() {
    echo "函数内参数:"
    local index=1
    for arg in "$@"; do
        echo "  参数 $index: $arg"
        ((index++))
    done
}

process_args "hello" "world" "foo bar"

set -- "new1" "new2" "new3"
echo "重置后的参数: $@"

shift 1
echo "shift 后的参数: $@"

$@ 和 $* 的区别在引号内才能体现。"$@" 将每个参数保持为独立的字符串，而 "$*" 将所有参数合并为一个字符串：

show_difference() {
    echo "--- \"\$@\" ---"
    for arg in "$@"; do
        echo "  [$arg]"
    done

    echo "--- \"\$*\" ---"
    for arg in "$*"; do
        echo "  [$arg]"
    done
}

show_difference "hello world" "foo" "bar baz"

小结

  • Shell 变量本质上都是字符串，仅在特定上下文中被解释为其他类型
  • 变量赋值等号两边不能有空格，引用时推荐使用双引号 "${var}" 避免词分割问题
  • 参数扩展提供了强大的字符串操作能力：截取、替换、大小写转换、默认值设置
  • 索引数组用 () 声明，关联数组需要 declare -A 显式声明（Bash 4.0+）
  • "$@" 保持参数独立性，"$*" 合并为单一字符串——脚本中应始终优先使用 "$@"
  • 特殊变量（$?、$$、$!、$LINENO 等）由 Shell 自动维护，是脚本调试和错误处理的基础
  • 引号规则：双引号允许变量扩展但防止词分割，单引号完全禁止扩展
