函数

核心概念

Shell 函数是将一组命令封装为可复用单元的机制。与其他编程语言的函数不同，Shell 函数本质上是"命名的命令组"——它们通过退出状态码表达成功或失败，通过 stdout 返回数据，通过位置参数接收输入。理解这些根本性差异是编写高质量 Shell 函数的前提。

Bash 支持两种函数定义语法，它们在功能上完全等价。函数体可以是任意复合命令，最常见的是花括号 { } 包围的命令组。

函数定义与调用
两种函数定义语法及其基本用法：


greet() {
    echo "Hello, ${1:-World}!"
}

function log_message {
    local level="${1:-INFO}"
    local message="$2"
    local timestamp
    timestamp=$(date '+%Y-%m-%d %H:%M:%S')
    echo "[$timestamp] [$level] $message"
}

greet "Shell"
log_message "ERROR" "连接数据库失败"
log_message "INFO" "服务启动完成"
函数可以在调用前或调用后定义（但必须在调用时已经被解析），也可以在其他函数内部定义：


main() {
    setup_environment
    process_data
    cleanup
}

setup_environment() {
    export APP_HOME="${APP_HOME:-/opt/app}"
    export LOG_DIR="${APP_HOME}/logs"
    mkdir -p "$LOG_DIR"
}

process_data() {
    local input_file="$1"
    validate_input "$input_file"
    transform_data "$input_file"
}

validate_input() {
    [[ -f "$1" ]] || { echo "文件不存在: $1" >&2; return 1; }
    [[ -s "$1" ]] || { echo "文件为空: $1" >&2; return 1; }
}

transform_data() {
    awk '{print toupper($0)}' "$1"
}

cleanup() {
    rm -f /tmp/app_*.tmp
}

main "$@"
返回值与数据传递
Shell 函数的返回值机制与其他语言有本质区别。return 语句只能返回 0-255 的整数退出码，要传递实际数据需要使用其他方式：


is_valid_port() {
    local port=$1
    (( port >= 1 && port <= 65535 ))
}

if is_valid_port 8080; then
    echo "端口有效"
fi

get_hostname() {
    hostname -f 2>/dev/null || hostname
}

current_host=$(get_hostname)
echo "主机名: $current_host"

get_config() {
    local key="$1"
    local config_file="${2:-config.env}"

    if [[ ! -f "$config_file" ]]; then
        return 1
    fi

    grep "^${key}=" "$config_file" | cut -d'=' -f2-
}

db_host=$(get_config "DB_HOST")
if [[ $? -eq 0 && -n "$db_host" ]]; then
    echo "数据库主机: $db_host"
fi

declare -A RESULT

compute_stats() {
    local -a numbers=("$@")
    local sum=0
    local count=${#numbers[@]}

    for n in "${numbers[@]}"; do
        ((sum += n))
    done

    RESULT[sum]=$sum
    RESULT[count]=$count
    RESULT[avg]=$((sum / count))
}

compute_stats 10 20 30 40 50
echo "总和: ${RESULT[sum]}, 平均: ${RESULT[avg]}"

get_file_info() {
    local file="$1"
    local size name modified

    size=$(stat -f%z "$file" 2>/dev/null || stat -c%s "$file" 2>/dev/null)
    name=$(basename "$file")
    modified=$(stat -f%m "$file" 2>/dev/null || stat -c%Y "$file" 2>/dev/null)

    echo "${name}|${size}|${modified}"
}

IFS='|' read -r fname fsize fmod <<< "$(get_file_info "/etc/hosts")"
echo "文件: $fname, 大小: $fsize bytes"
作用域与变量封装
Shell 函数中的变量默认是全局作用域，必须使用 local 关键字显式声明局部变量，否则会意外修改全局状态：


bad_example() {
    count=10
}

good_example() {
    local count=10
    local result=""
    local -i num=42
    local -a arr=(1 2 3)
    local -A map=([key]=value)
    local -r CONST="immutable"

    echo "$count $num ${arr[*]} ${map[key]} $CONST"
}

count=0
bad_example
echo "$count"    # 10 — 被函数意外修改了！

count=0
good_example
echo "$count"    # 0 — 保持不变

create_counter() {
    local prefix="${1:-counter}"
    local -i _count=0

    eval "${prefix}_increment() { ((_count++)); echo \$_count; }"
    eval "${prefix}_get() { echo \$_count; }"
    eval "${prefix}_reset() { _count=0; }"
}
nameref（Bash 4.3+）提供了类似引用传递的能力：


swap() {
    local -n ref1=$1
    local -n ref2=$2
    local temp="$ref1"
    ref1="$ref2"
    ref2="$temp"
}

a="hello"
b="world"
swap a b
echo "$a $b"    # world hello

fill_array() {
    local -n arr_ref=$1
    arr_ref=("item1" "item2" "item3")
}

declare -a my_array
fill_array my_array
echo "${my_array[@]}"    # item1 item2 item3
高级函数模式
函数可以组合成强大的设计模式，提升脚本的可维护性和复用性：


retry() {
    local max_attempts="${1:-3}"
    local delay="${2:-2}"
    shift 2

    local attempt=1
    while (( attempt <= max_attempts )); do
        if "$@"; then
            return 0
        fi

        echo "尝试 $attempt/$max_attempts 失败，${delay}秒后重试..." >&2
        sleep "$delay"
        ((attempt++))
    done

    echo "所有 $max_attempts 次尝试均失败" >&2
    return 1
}

retry 5 3 curl -sf "http://api.example.com/health"

with_tempdir() {
    local tmpdir
    tmpdir=$(mktemp -d) || return 1

    (
        cd "$tmpdir" || exit 1
        "$@"
    )
    local exit_code=$?

    rm -rf "$tmpdir"
    return $exit_code
}

with_tempdir bash -c 'echo "工作目录: $(pwd)"; touch test.txt; ls'

measure_time() {
    local start end elapsed
    start=$(date +%s%N)

    "$@"
    local exit_code=$?

    end=$(date +%s%N)
    elapsed=$(( (end - start) / 1000000 ))
    echo "执行耗时: ${elapsed}ms" >&2

    return $exit_code
}

measure_time sleep 1

require_root() {
    if [[ $EUID -ne 0 ]]; then
        echo "此操作需要 root 权限" >&2
        return 1
    fi
    "$@"
}

validate_args() {
    local min_args=$1
    local usage=$2
    shift 2

    if (( $# < min_args )); then
        echo "用法: $usage" >&2
        return 1
    fi
}

deploy() {
    validate_args 2 "deploy <env> <version>" "$@" || return 1
    local env="$1" version="$2"
    echo "部署 $version 到 $env 环境"
}
小结
    

  • Shell 函数是"命名的命令组"，通过退出码表达成功/失败，通过 stdout 传递数据
    • 

  • return 仅返回 0-255 的退出码，实际数据返回需要 echo + 命令替换或全局变量
    • 

  • 函数内变量默认全局作用域，必须使用 local 显式声明局部变量
    • 

  • nameref（local -n，Bash 4.3+）支持类似引用传递的参数方式
    • 

  • 高阶函数模式（retry、with_tempdir、measure_time）可以大幅提升脚本的可复用性
    • 

  • 推荐使用 main "$@" 模式组织脚本，将所有逻辑封装在函数中
    • 

  • 参数验证应在函数入口处完成，使用 validate_args 等辅助函数统一处理
    •
