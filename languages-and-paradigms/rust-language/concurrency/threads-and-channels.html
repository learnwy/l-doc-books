线程与消息传递

创建线程

Rust 通过 std::thread::spawn 创建操作系统线程，闭包必须满足 Send + 'static 约束。

use std::thread;
use std::time::Duration;

fn main() {
    let handle = thread::spawn(|| {
        for i in 1..=5 {
            println!("子线程: {}", i);
            thread::sleep(Duration::from_millis(100));
        }
    });

    for i in 1..=3 {
        println!("主线程: {}", i);
        thread::sleep(Duration::from_millis(150));
    }

    handle.join().unwrap();
    println!("所有线程完成");
}

move 闭包与所有权转移

跨线程传递数据时，必须使用 move 将所有权转移给线程闭包。

use std::thread;

fn main() {
    let data = vec![1, 2, 3, 4, 5];

    let handle = thread::spawn(move || {
        let sum: i32 = data.iter().sum();
        println!("子线程计算和: {}", sum);
    });

    // println!("{:?}", data); // 编译错误：data 已被移动
    handle.join().unwrap();
}

Send 与 Sync Trait

Send 和 Sync 是 Rust 并发安全的类型级保证，由编译器自动推导。

Trait 含义 典型实现 典型不实现
Send 类型可跨线程转移所有权 String, Vec<T>, Arc<T> Rc<T>, 裸指针
Sync 类型可被多线程共享引用 i32, Arc<T>, Mutex<T> Cell<T>, RefCell<T>

T: Send 表示 T 的所有权可安全转移到另一个线程；T: Sync 等价于 &T: Send。

mpsc 通道

std::sync::mpsc（Multiple Producer, Single Consumer）提供线程间的消息传递机制。

use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();

    thread::spawn(move || {
        let messages = vec!["你好", "来自", "子线程"];
        for msg in messages {
            tx.send(msg).unwrap();
            thread::sleep(std::time::Duration::from_millis(200));
        }
    });

    for received in rx {
        println!("收到: {}", received);
    }
}

多生产者

use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();

    for i in 0..3 {
        let tx_clone = tx.clone();
        thread::spawn(move || {
            tx_clone.send(format!("线程 {} 的消息", i)).unwrap();
        });
    }
    drop(tx);

    for msg in rx {
        println!("收到: {}", msg);
    }
}

Crossbeam：增强通道
crossbeam-channel 提供了比标准库更强大的通道功能：MPMC、select 宏、超时支持。


use crossbeam_channel::{bounded, select, tick};
use std::time::Duration;

fn main() {
    let (tx, rx) = bounded(10);
    let ticker = tick(Duration::from_secs(1));

    std::thread::spawn(move || {
        for i in 0..5 {
            tx.send(i).unwrap();
            std::thread::sleep(Duration::from_millis(300));
        }
    });

    loop {
        select! {
            recv(rx) -> msg => {
                match msg {
                    Ok(val) => println!("数据: {}", val),
                    Err(_) => break,
                }
            }
            recv(ticker) -> _ => println!("心跳"),
        }
    }
}


Scoped Thread
crossbeam::scope 或 std::thread::scope（Rust 1.63+）允许线程借用栈上数据，无需 move 或 Arc。


fn main() {
    let mut data = vec![1, 2, 3, 4, 5];

    std::thread::scope(|s| {
        s.spawn(|| {
            println!("子线程读取: {:?}", &data);
        });

        s.spawn(|| {
            println!("另一个子线程读取: {:?}", &data);
        });
    });

    data.push(6);
    println!("主线程修改后: {:?}", data);
}
