共享状态与 Mutex

共享状态并发

当多个线程需要读写同一数据时，需要同步原语来保证数据一致性。Rust 通过类型系统确保共享数据必须被正确保护。



Mutex<T>：互斥锁
Mutex<T> 保证同一时刻只有一个线程能访问内部数据。调用 lock() 获取锁，返回的 MutexGuard 在离开作用域时自动释放锁。


use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let counter = Arc::new(Mutex::new(0));
    let mut handles = vec![];

    for _ in 0..10 {
        let counter = Arc::clone(&counter);
        let handle = thread::spawn(move || {
            let mut num = counter.lock().unwrap();
            *num += 1;
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.join().unwrap();
    }

    println!("最终计数: {}", *counter.lock().unwrap());
}

锁中毒（Poisoning）
如果持有锁的线程 panic，锁会被标记为"中毒"。后续的 lock() 调用返回 Err，但仍可通过 into_inner() 获取数据。


use std::sync::{Arc, Mutex};

fn main() {
    let data = Arc::new(Mutex::new(vec![1, 2, 3]));

    let data_clone = Arc::clone(&data);
    let handle = std::thread::spawn(move || {
        let mut guard = data_clone.lock().unwrap();
        guard.push(4);
        panic!("线程崩溃!");
    });

    let _ = handle.join();

    match data.lock() {
        Ok(guard) => println!("数据: {:?}", *guard),
        Err(poisoned) => {
            let guard = poisoned.into_inner();
            println!("锁中毒，但数据可恢复: {:?}", *guard);
        }
    }
}


RwLock<T>：读写锁
RwLock 允许多个读者同时访问，但写者独占。适合读多写少的场景。


use std::sync::{Arc, RwLock};
use std::thread;

fn main() {
    let config = Arc::new(RwLock::new(String::from("初始配置")));
    let mut handles = vec![];

    for i in 0..5 {
        let config = Arc::clone(&config);
        handles.push(thread::spawn(move || {
            let r = config.read().unwrap();
            println!("读者 {}: {}", i, *r);
        }));
    }

    {
        let config = Arc::clone(&config);
        handles.push(thread::spawn(move || {
            let mut w = config.write().unwrap();
            *w = String::from("更新后的配置");
            println!("写者: 配置已更新");
        }));
    }

    for h in handles {
        h.join().unwrap();
    }
}

Arc + Mutex 模式
跨线程共享可变数据的标准模式是 Arc<Mutex<T>>：Arc 提供线程安全的共享所有权，Mutex 提供互斥访问。


use std::collections::HashMap;
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let map = Arc::new(Mutex::new(HashMap::new()));
    let mut handles = vec![];

    for i in 0..5 {
        let map = Arc::clone(&map);
        handles.push(thread::spawn(move || {
            let mut m = map.lock().unwrap();
            m.insert(format!("key_{}", i), i * 10);
        }));
    }

    for h in handles {
        h.join().unwrap();
    }

    println!("结果: {:?}", map.lock().unwrap());
}


避免死锁
死锁常见于多个锁的嵌套获取。以下策略可以减少死锁风险：

使用通道替代共享状态
消息传递天然避免死锁





use std::sync::Mutex;

fn safe_transfer(
    from: &Mutex<i64>,
    to: &Mutex<i64>,
    amount: i64,
) {
    let (first, second) = if std::ptr::from_ref(from) < std::ptr::from_ref(to) {
        (from, to)
    } else {
        (to, from)
    };

    let mut a = first.lock().unwrap();
    let mut b = second.lock().unwrap();

    if std::ptr::from_ref(from) < std::ptr::from_ref(to) {
        *a -= amount;
        *b += amount;
    } else {
        *b -= amount;
        *a += amount;
    }
}
