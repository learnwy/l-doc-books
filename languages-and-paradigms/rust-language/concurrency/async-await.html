async/await 与异步运行时

异步编程模型

Rust 的异步编程基于 Future trait，通过 async/await 语法实现零成本的协作式多任务。异步代码在逻辑上是并发的，但可以在单个线程上运行。



Future Trait
Future 是 Rust 异步编程的核心抽象。与 JavaScript 的 Promise 不同，Rust 的 Future 是惰性的——创建后不会立即执行，必须被 .await 或提交给运行时。


use std::future::Future;
use std::pin::Pin;
use std::task::{Context, Poll};

struct Delay {
    duration: std::time::Duration,
    started: Option<std::time::Instant>,
}

impl Future for Delay {
    type Output = ();

    fn poll(mut self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<()> {
        let started = self.started.get_or_insert_with(std::time::Instant::now);
        if started.elapsed() >= self.duration {
            Poll::Ready(())
        } else {
            let waker = cx.waker().clone();
            let remaining = self.duration - started.elapsed();
            std::thread::spawn(move || {
                std::thread::sleep(remaining);
                waker.wake();
            });
            Poll::Pending
        }
    }
}


async/await 语法
async fn 返回一个实现 Future 的匿名类型。.await 挂起当前任务，等待 Future 完成。


async fn fetch_data(url: &str) -> Result<String, reqwest::Error> {
    let response = reqwest::get(url).await?;
    let body = response.text().await?;
    Ok(body)
}

async fn process() {
    match fetch_data("https://httpbin.org/get").await {
        Ok(data) => println!("数据长度: {}", data.len()),
        Err(e) => eprintln!("请求失败: {}", e),
    }
}


Tokio 运行时
Tokio 是 Rust 最流行的异步运行时，提供多线程调度器、异步 I/O、定时器等基础设施。


#[tokio::main]
async fn main() {
    let handle1 = tokio::spawn(async {
        tokio::time::sleep(std::time::Duration::from_secs(1)).await;
        println!("任务 1 完成");
        42
    });

    let handle2 = tokio::spawn(async {
        tokio::time::sleep(std::time::Duration::from_millis(500)).await;
        println!("任务 2 完成");
        "hello"
    });

    let (r1, r2) = tokio::join!(handle1, handle2);
    println!("结果: {:?}, {:?}", r1.unwrap(), r2.unwrap());
}

并发执行模式
join!：并行等待多个 Future
use tokio::time::{sleep, Duration};

async fn task_a() -> i32 {
    sleep(Duration::from_secs(2)).await;
    1
}

async fn task_b() -> i32 {
    sleep(Duration::from_secs(1)).await;
    2
}

#[tokio::main]
async fn main() {
    let (a, b) = tokio::join!(task_a(), task_b());
    println!("结果: {} + {} = {}", a, b, a + b);
}
select!：竞争执行
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    tokio::select! {
        _ = sleep(Duration::from_secs(1)) => {
            println!("定时器到期");
        }
        _ = async {
            sleep(Duration::from_millis(500)).await;
        } => {
            println!("快速任务完成");
        }
    }
}

异步 Stream
Stream 是异步版本的 Iterator，逐步产出值。


use tokio_stream::{self as stream, StreamExt};

#[tokio::main]
async fn main() {
    let mut stream = stream::iter(vec![1, 2, 3, 4, 5])
        .filter(|x| x % 2 == 0)
        .map(|x| x * 10);

    while let Some(value) = stream.next().await {
        println!("值: {}", value);
    }
}


async Trait
async fn 在 trait 中的支持从 Rust 1.75 开始稳定（需要 impl Trait in return position）：


trait HttpClient {
    async fn get(&self, url: &str) -> Result<String, Box<dyn std::error::Error>>;
}

struct MyClient;

impl HttpClient for MyClient {
    async fn get(&self, url: &str) -> Result<String, Box<dyn std::error::Error>> {
        let resp = reqwest::get(url).await?;
        Ok(resp.text().await?)
    }
}


常见陷阱与最佳实践




陷阱
说明
解决方案





在 async 中使用 std::sync::Mutex
持有锁期间 .await 会阻塞运行时
使用 tokio::sync::Mutex




阻塞调用进入异步运行时
CPU 密集或阻塞 I/O 占据线程
使用 spawn_blocking()




Future 未 .await
Future 是惰性的，不 await 不执行
确保所有 Future 被 await 或 spawn




Send 约束
tokio::spawn 要求 Future 为 Send
避免在 .await 点持有非 Send 类型
