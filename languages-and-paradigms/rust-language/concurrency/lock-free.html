无锁编程与原子操作

什么是无锁编程

无锁编程（Lock-Free Programming）通过原子操作实现线程间的数据同步，避免了互斥锁带来的上下文切换和线程阻塞开销。核心工具是 std::sync::atomic 模块中的原子类型。

编程模型 同步方式 优势 劣势
互斥锁 Mutex / RwLock 简单直观 上下文切换、死锁风险
无锁 原子操作 + CAS 高性能、无死锁 复杂、难以正确实现
无等待 原子操作，每次操作有界步数 最强进度保证 极其复杂

原子类型

std::sync::atomic 提供了一组原子类型，所有操作在硬件级别保证原子性。

use std::sync::atomic::{AtomicU64, AtomicBool, Ordering};
use std::sync::Arc;
use std::thread;

fn main() {
    let counter = Arc::new(AtomicU64::new(0));
    let mut handles = vec![];

    for _ in 0..10 {
        let counter = Arc::clone(&counter);
        handles.push(thread::spawn(move || {
            for _ in 0..1000 {
                counter.fetch_add(1, Ordering::Relaxed);
            }
        }));
    }

    for h in handles {
        h.join().unwrap();
    }

    println!("计数: {}", counter.load(Ordering::Relaxed));
}

常用原子类型：

类型 对应基础类型 典型用途
AtomicBool bool 标志位、开关
AtomicI32 / AtomicU32 i32 / u32 计数器
AtomicI64 / AtomicU64 i64 / u64 统计指标
AtomicUsize usize 索引、引用计数
AtomicPtr<T> *mut T 无锁数据结构中的指针

CAS 操作
Compare-And-Swap（CAS）是无锁编程的基础操作：比较当前值与期望值，相等则替换为新值。


use std::sync::atomic::{AtomicI32, Ordering};

fn atomic_max(atom: &AtomicI32, new_val: i32) {
    let mut current = atom.load(Ordering::Relaxed);
    loop {
        if current >= new_val {
            return;
        }
        match atom.compare_exchange_weak(
            current,
            new_val,
            Ordering::AcqRel,
            Ordering::Relaxed,
        ) {
            Ok(_) => return,
            Err(actual) => current = actual,
        }
    }
}

自旋锁实现
use std::sync::atomic::{AtomicBool, Ordering};
use std::cell::UnsafeCell;

pub struct SpinLock<T> {
    locked: AtomicBool,
    data: UnsafeCell<T>,
}

unsafe impl<T: Send> Sync for SpinLock<T> {}
unsafe impl<T: Send> Send for SpinLock<T> {}

impl<T> SpinLock<T> {
    pub fn new(data: T) -> Self {
        SpinLock {
            locked: AtomicBool::new(false),
            data: UnsafeCell::new(data),
        }
    }

    pub fn lock(&self) -> SpinGuard<T> {
        while self
            .locked
            .compare_exchange_weak(false, true, Ordering::Acquire, Ordering::Relaxed)
            .is_err()
        {
            std::hint::spin_loop();
        }
        SpinGuard { lock: self }
    }
}

pub struct SpinGuard<'a, T> {
    lock: &'a SpinLock<T>,
}

impl<T> std::ops::Deref for SpinGuard<'_, T> {
    type Target = T;
    fn deref(&self) -> &T {
        unsafe { &*self.lock.data.get() }
    }
}

impl<T> std::ops::DerefMut for SpinGuard<'_, T> {
    fn deref_mut(&mut self) -> &mut T {
        unsafe { &mut *self.lock.data.get() }
    }
}

impl<T> Drop for SpinGuard<'_, T> {
    fn drop(&mut self) {
        self.lock.locked.store(false, Ordering::Release);
    }
}


无锁标志位模式
使用原子布尔值作为线程间的信号标志是最简单的无锁模式。


use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;
use std::thread;
use std::time::Duration;

fn main() {
    let running = Arc::new(AtomicBool::new(true));
    let running_clone = Arc::clone(&running);

    let worker = thread::spawn(move || {
        let mut count = 0u64;
        while running_clone.load(Ordering::Relaxed) {
            count += 1;
            thread::sleep(Duration::from_millis(10));
        }
        println!("工作线程完成，执行 {} 次", count);
    });

    thread::sleep(Duration::from_secs(1));
    running.store(false, Ordering::Relaxed);
    worker.join().unwrap();
}
