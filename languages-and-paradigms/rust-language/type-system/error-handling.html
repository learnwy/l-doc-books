错误处理 Result 与 Option

错误处理哲学

Rust 将错误分为两类：可恢复错误使用 Result<T, E>，不可恢复错误使用 panic!。没有异常机制，所有错误通过类型系统显式传递。

错误类型 处理方式 典型场景
可恢复 Result<T, E> 文件未找到、网络超时、解析失败
不可恢复 panic! 数组越界、断言失败、程序 bug 


? 操作符
? 操作符是错误传播的语法糖——如果 Result 是 Err，立即返回该错误；如果是 Ok，提取内部值继续执行。


use std::fs;
use std::io;

fn read_username_from_file() -> Result<String, io::Error> {
    let mut username = fs::read_to_string("username.txt")?;
    username.truncate(username.trim_end().len());
    Ok(username)
}
? 操作符的等价展开：


fn read_username_verbose() -> Result<String, io::Error> {
    let username = match fs::read_to_string("username.txt") {
        Ok(content) => content,
        Err(e) => return Err(e),
    };
    Ok(username.trim().to_string())
}
? 操作符还支持自动类型转换：只要错误类型实现了 From<SourceError> for TargetError，就能自动转换。




自定义错误类型
手动实现
use std::fmt;

#[derive(Debug)]
enum AppError {
    IoError(std::io::Error),
    ParseError(String),
    NotFound { resource: String },
}

impl fmt::Display for AppError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            AppError::IoError(e) => write!(f, "IO 错误: {}", e),
            AppError::ParseError(msg) => write!(f, "解析错误: {}", msg),
            AppError::NotFound { resource } => write!(f, "未找到: {}", resource),
        }
    }
}

impl std::error::Error for AppError {}

impl From<std::io::Error> for AppError {
    fn from(e: std::io::Error) -> Self {
        AppError::IoError(e)
    }
}
使用 thiserror（库开发推荐）
thiserror 通过派生宏自动生成 Display 和 Error 实现。


use thiserror::Error;

#[derive(Error, Debug)]
enum DataError {
    #[error("IO 操作失败: {0}")]
    Io(#[from] std::io::Error),

    #[error("JSON 解析失败: {0}")]
    Json(#[from] serde_json::Error),

    #[error("字段 `{field}` 验证失败: {reason}")]
    Validation { field: String, reason: String },

    #[error("记录 {0} 不存在")]
    NotFound(u64),
}


anyhow：应用层错误处理
anyhow 提供了 anyhow::Result 和 anyhow::Error，适合应用程序快速传播和附加上下文。


use anyhow::{Context, Result};
use std::fs;

fn load_config(path: &str) -> Result<Config> {
    let content = fs::read_to_string(path)
        .with_context(|| format!("读取配置文件 {} 失败", path))?;

    let config: Config = serde_json::from_str(&content)
        .context("JSON 解析失败")?;

    Ok(config)
}

#[derive(serde::Deserialize)]
struct Config {
    port: u16,
    host: String,
}

组合器链式处理
Result 和 Option 提供丰富的组合器方法，支持函数式链式处理。


fn parse_and_double(input: &str) -> Result<i32, String> {
    input
        .trim()
        .parse::<i32>()
        .map(|n| n * 2)
        .map_err(|e| format!("解析失败: {}", e))
}

错误处理最佳实践
fn process_records(path: &str) -> Result<Vec<Record>, AppError> {
    let content = std::fs::read_to_string(path)?;

    let records: Vec<Record> = content
        .lines()
        .enumerate()
        .map(|(i, line)| {
            parse_record(line).map_err(|e| AppError::ParseError(
                format!("第 {} 行: {}", i + 1, e)
            ))
        })
        .collect::<Result<Vec<_>, _>>()?;

    if records.is_empty() {
        return Err(AppError::NotFound {
            resource: path.to_string(),
        });
    }

    Ok(records)
}

struct Record {
    name: String,
    value: f64,
}

fn parse_record(line: &str) -> Result<Record, String> {
    let parts: Vec<&str> = line.split(',').collect();
    if parts.len() != 2 {
        return Err(format!("期望2个字段，实际 {}", parts.len()));
    }
    Ok(Record {
        name: parts[0].to_string(),
        value: parts[1].parse().map_err(|e| format!("{}", e))?,
    })
}
