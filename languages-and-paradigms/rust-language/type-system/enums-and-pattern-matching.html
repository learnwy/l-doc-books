枚举与模式匹配

枚举基础

Rust 的枚举（enum）是代数数据类型，每个变体可以携带不同类型和数量的数据。这比 C 语言只能表示整数标签的枚举强大得多。

enum IpAddr {
    V4(u8, u8, u8, u8),
    V6(String),
}

enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
    ChangeColor(i32, i32, i32),
}

fn main() {
    let home = IpAddr::V4(127, 0, 0, 1);
    let loopback = IpAddr::V6(String::from("::1"));
}

Option<T>：空值的安全替代

Rust 没有 null，使用 Option<T> 显式表达值的有无，编译器强制处理"无值"情况。

fn find_user(id: u64) -> Option<String> {
    if id == 1 {
        Some(String::from("张三"))
    } else {
        None
    }
}

fn main() {
    match find_user(1) {
        Some(name) => println!("找到用户: {}", name),
        None => println!("用户不存在"),
    }
}

常用 Option 方法：

方法 说明 示例
unwrap() 取值，None 时 panic Some(5).unwrap() → 5
unwrap_or(default) 取值，None 时返回默认值 None.unwrap_or(0) → 0
map(f) 变换内部值 Some(5).map(|x| x * 2) → Some(10)
and_then(f) 链式操作（flatmap） Some(5).and_then(|x| Some(x + 1))
is_some() / is_none() 检查状态 返回 bool
filter(predicate) 条件过滤 Some(4).filter(|&x| x > 3) → Some(4)

Result<T, E>：错误处理枚举

Result 用于表达可能失败的操作，是 Rust 错误处理的基石。

use std::fs;
use std::io;

fn read_config(path: &str) -> Result<String, io::Error> {
    fs::read_to_string(path)
}

fn main() {
    match read_config("config.toml") {
        Ok(content) => println!("配置内容: {}", content),
        Err(e) => eprintln!("读取失败: {}", e),
    }
}

match 表达式

match 是 Rust 最强大的控制流结构，要求穷举所有可能的模式。

enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter(String),
}

fn value_in_cents(coin: &Coin) -> u32 {
    match coin {
        Coin::Penny => 1,
        Coin::Nickel => 5,
        Coin::Dime => 10,
        Coin::Quarter(state) => {
            println!("来自 {} 的25美分", state);
            25
        }
    }
}

模式语法速查

模式 说明 示例
字面量 匹配具体值 1 => ...
变量绑定 绑定值到变量 x => println!("{}", x)
通配符 匹配任意值，不绑定 _ => ...
解构元组 提取元组元素 (a, b) => ...
解构结构体 提取结构体字段 Point { x, y } => ...
解构枚举 提取枚举变体数据 Some(val) => ...
范围 匹配值范围 1..=5 => ...
守卫 附加条件 x if x > 0 => ...
或模式 匹配多个模式 1 | 2 | 3 => ...
绑定 + 守卫 组合使用 n @ 1..=12 => ...

if let 与 while let

当只关心一种模式时，if let 和 while let 比完整 match 更简洁。

fn main() {
    let config_max = Some(3u8);

    if let Some(max) = config_max {
        println!("最大值配置为: {}", max);
    }

    let mut stack = vec![1, 2, 3];

    while let Some(top) = stack.pop() {
        println!("弹出: {}", top);
    }
}

let-else 模式

Rust 1.65+ 引入的 let-else 语法，在模式不匹配时执行发散分支（如 return、break）。

fn process_input(input: Option<&str>) -> String {
    let Some(value) = input else {
        return String::from("无输入");
    };
    format!("处理: {}", value)
}

模式匹配实战：状态机

枚举与模式匹配天然适合实现状态机。

#[derive(Debug)]
enum OrderState {
    Created,
    Paid { amount: f64 },
    Shipped { tracking: String },
    Delivered,
    Cancelled { reason: String },
}

fn next_state(state: OrderState) -> OrderState {
    match state {
        OrderState::Created => OrderState::Paid { amount: 99.0 },
        OrderState::Paid { amount } => {
            println!("已支付 {} 元，准备发货", amount);
            OrderState::Shipped {
                tracking: String::from("SF1234567890"),
            }
        }
        OrderState::Shipped { tracking } => {
            println!("快递 {} 已送达", tracking);
            OrderState::Delivered
        }
        other => {
            println!("状态 {:?} 无法继续流转", other);
            other
        }
    }
}


嵌套解构与复杂模式
struct Point {
    x: i32,
    y: i32,
}

enum Shape {
    Circle { center: Point, radius: f64 },
    Rectangle { top_left: Point, bottom_right: Point },
}

fn describe_shape(shape: &Shape) {
    match shape {
        Shape::Circle {
            center: Point { x, y },
            radius,
        } => println!("圆心({}, {}), 半径{}", x, y, radius),

        Shape::Rectangle {
            top_left: Point { x: x1, y: y1 },
            bottom_right: Point { x: x2, y: y2 },
        } => println!("矩形: ({},{}) - ({},{})", x1, y1, x2, y2),
    }
}
