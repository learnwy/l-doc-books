Trait 与泛型

Trait 基础

Trait 是 Rust 的核心抽象机制，定义了一组类型必须实现的行为。类似于其他语言中的接口，但 Trait 更强大——支持默认实现、关联类型和 blanket implementation。

trait Summary {
    fn summarize_author(&self) -> String;

    fn summarize(&self) -> String {
        format!("(阅读 {} 的更多内容...)", self.summarize_author())
    }
}

struct Article {
    title: String,
    author: String,
    content: String,
}

impl Summary for Article {
    fn summarize_author(&self) -> String {
        self.author.clone()
    }

    fn summarize(&self) -> String {
        format!("{}, 作者 {}", self.title, self.author)
    }
}

泛型与 Trait Bound

泛型允许编写适用于多种类型的代码，Trait Bound 约束泛型参数必须实现特定的 Trait。

fn print_summary<T: Summary>(item: &T) {
    println!("{}", item.summarize());
}

fn notify(item: &(impl Summary + std::fmt::Display)) {
    println!("速报: {}", item);
}

Trait Bound 的三种写法

语法 示例 适用场景
impl Trait fn f(x: &impl Summary) 简单场景，参数位置
泛型 + Bound fn f<T: Summary>(x: &T) 需要多处使用同一类型
where 子句 fn f<T>(x: &T) where T: Summary 复杂约束，保持签名清晰 
use std::fmt::{Debug, Display};

fn complex_function<T, U>(t: &T, u: &U) -> String
where
    T: Display + Clone,
    U: Debug + Summary,
{
    format!("{} - {:?}", t, u)
}

关联类型

关联类型在 Trait 内部定义类型占位符，实现时指定具体类型。相比泛型参数，关联类型保证每个实现只有一种类型映射。

trait Iterator {
    type Item;

    fn next(&mut self) -> Option<Self::Item>;
}

struct Counter {
    count: u32,
}

impl Iterator for Counter {
    type Item = u32;

    fn next(&mut self) -> Option<Self::Item> {
        if self.count < 5 {
            self.count += 1;
            Some(self.count)
        } else {
            None
        }
    }
}
特性 泛型参数 trait Foo<T> 关联类型 type Item
每个类型的实现数量 可以多个（不同 T） 唯一一个
使用时是否需要指定 需要 Foo<i32> 不需要
典型用途 From<T>, Add<Rhs> Iterator, Deref

静态分发与动态分发

Rust 提供两种多态分发机制，各有性能和灵活性的取舍。

fn static_dispatch(item: &impl Summary) {
    println!("{}", item.summarize());
}

fn dynamic_dispatch(item: &dyn Summary) {
    println!("{}", item.summarize());
}

fn create_summarizers() -> Vec<Box<dyn Summary>> {
    vec![
        Box::new(Article {
            title: "标题".into(),
            author: "作者".into(),
            content: "内容".into(),
        }),
    ]
}

Blanket Implementation
为所有满足条件的类型统一实现 Trait，是 Rust 标准库的核心模式。


use std::fmt::Display;

trait Greeting {
    fn greet(&self) -> String;
}

impl<T: Display> Greeting for T {
    fn greet(&self) -> String {
        format!("你好, {}!", self)
    }
}

fn main() {
    println!("{}", "世界".greet());
    println!("{}", 42.greet());
}

泛型与生命周期结合
泛型参数、Trait Bound 和生命周期可以组合使用：


use std::fmt::Display;

struct Wrapper<'a, T: Display + 'a> {
    value: &'a T,
}

impl<'a, T: Display> Wrapper<'a, T> {
    fn show(&self) {
        println!("包装值: {}", self.value);
    }
}

fn longest_with_display<'a, T>(x: &'a T, y: &'a T) -> &'a T
where
    T: Display + PartialOrd,
{
    if x >= y { x } else { y }
}
