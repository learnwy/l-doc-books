智能指针

智能指针概览

智能指针是实现了 Deref 和 Drop trait 的结构体，它们不仅像引用一样指向数据，还拥有额外的元数据和能力。Rust 标准库提供了多种智能指针，适用于不同的内存管理场景。

智能指针 用途 分配位置 引用计数 线程安全
Box<T> 堆上分配单个值 堆 无 取决于 T
Rc<T> 单线程引用计数共享 堆 运行时（非原子） ❌
Arc<T> 多线程引用计数共享 堆 运行时（原子） ✅
RefCell<T> 运行时借用检查（内部可变性） 栈/堆 无 ❌
Cow<'a, T> 写时克隆 按需 无 取决于 T

Box<T>：堆分配

Box<T> 将数据分配在堆上，栈上只保留一个指针。最常见的用途是创建递归类型和大数据堆上存储。

enum List {
    Cons(i32, Box<List>),
    Nil,
}

use List::{Cons, Nil};

fn main() {
    let list = Cons(1, Box::new(Cons(2, Box::new(Cons(3, Box::new(Nil))))));
    print_list(&list);
}

fn print_list(list: &List) {
    match list {
        Cons(val, next) => {
            print!("{} -> ", val);
            print_list(next);
        }
        Nil => println!("Nil"),
    }
}

Box 的典型场景：

场景 说明
递归类型 枚举/结构体自引用需要间接引用打破无限大小
Trait 对象 Box<dyn Trait> 实现动态分发
大数据转移 避免栈上大量数据的复制开销

Rc<T>：引用计数

Rc<T> 允许数据拥有多个所有者，通过引用计数管理生命周期。当最后一个 Rc 被销毁时，数据被释放。

use std::rc::Rc;

fn main() {
    let data = Rc::new(vec![1, 2, 3]);

    let a = Rc::clone(&data); // 引用计数 +1
    let b = Rc::clone(&data); // 引用计数 +1

    println!("引用计数: {}", Rc::strong_count(&data)); // 3
    println!("数据: {:?}", b);

    drop(a); // 引用计数 -1
    println!("drop a 后引用计数: {}", Rc::strong_count(&data)); // 2
}

注意：Rc<T> 只允许共享引用（不可变访问），且不能跨线程使用（未实现 Send）。

Arc<T>：原子引用计数

Arc<T> 是 Rc<T> 的线程安全版本，使用原子操作维护引用计数。

use std::sync::Arc;
use std::thread;

fn main() {
    let data = Arc::new(vec![1, 2, 3, 4, 5]);

    let handles: Vec<_> = (0..3).map(|i| {
        let data = Arc::clone(&data);
        thread::spawn(move || {
            let sum: i32 = data.iter().sum();
            println!("线程 {} 计算和: {}", i, sum);
        })
    }).collect();

    for handle in handles {
        handle.join().unwrap();
    }
}


RefCell<T>：内部可变性
RefCell<T> 将借用检查从编译期推迟到运行时，允许通过共享引用修改内部数据。


use std::cell::RefCell;

fn main() {
    let data = RefCell::new(vec![1, 2, 3]);

    data.borrow_mut().push(4);

    println!("数据: {:?}", data.borrow()); // [1, 2, 3, 4]
}

组合模式：Rc<RefCell<T>>
Rc 提供多所有权，RefCell 提供内部可变性，两者组合实现"多个所有者可修改同一数据"。


use std::cell::RefCell;
use std::rc::Rc;

#[derive(Debug)]
struct Node {
    value: i32,
    children: Vec<Rc<RefCell<Node>>>,
}

fn main() {
    let leaf = Rc::new(RefCell::new(Node {
        value: 3,
        children: vec![],
    }));

    let branch = Rc::new(RefCell::new(Node {
        value: 5,
        children: vec![Rc::clone(&leaf)],
    }));

    leaf.borrow_mut().value = 10;

    println!("branch: {:?}", branch.borrow());
}


Cow<T>：写时克隆
Cow（Clone on Write）在只读时避免克隆，仅在需要修改时才创建独立副本。


use std::borrow::Cow;

fn ensure_uppercase(input: &str) -> Cow<str> {
    if input.chars().all(|c| c.is_uppercase() || !c.is_alphabetic()) {
        Cow::Borrowed(input)
    } else {
        Cow::Owned(input.to_uppercase())
    }
}

fn main() {
    let s1 = ensure_uppercase("HELLO");     // 不克隆
    let s2 = ensure_uppercase("hello");     // 执行克隆
    println!("{}, {}", s1, s2);
}
