引用与借用规则

借用的核心思想

借用（Borrowing）允许在不转移所有权的情况下访问数据。引用（Reference）是借用的具体实现——它是一个指向数据的指针，但不拥有数据。

fn calculate_length(s: &String) -> usize {
    s.len()
} // s 离开作用域，但它不拥有数据，所以不会 drop

fn main() {
    let s = String::from("hello");
    let len = calculate_length(&s); // 借用 s，不转移所有权
    println!("'{}' 的长度是 {}", s, len); // s 仍然有效
}

共享引用与可变引用

Rust 提供两种引用类型，它们遵循严格的互斥规则。

类型 语法 权限 数量限制
共享引用 &T 只读 同时可存在多个
可变引用 &mut T 读写 同一时刻最多一个 
fn main() {
    let mut s = String::from("hello");

    let r1 = &s;
    let r2 = &s;
    println!("{} {}", r1, r2); // 多个共享引用同时存在，合法

    let r3 = &mut s;
    r3.push_str(", world");
    println!("{}", r3); // 可变引用独占使用
}

借用检查器规则

借用检查器（Borrow Checker）在编译期执行以下核心规则：

规则一：可变引用独占
fn main() {
    let mut s = String::from("hello");

    let r1 = &mut s;
    // let r2 = &mut s; // 编译错误：不能同时拥有两个可变引用
    r1.push_str("!");
}
规则二：共享与可变互斥
fn main() {
    let mut s = String::from("hello");

    let r1 = &s;
    // let r2 = &mut s; // 编译错误：已有共享引用时不能创建可变引用
    println!("{}", r1);
}
规则三：NLL（Non-Lexical Lifetimes）
Rust 2021 Edition 引入了 NLL，引用的生命周期在最后一次使用时结束，而非在作用域末尾。


fn main() {
    let mut s = String::from("hello");

    let r1 = &s;
    let r2 = &s;
    println!("{} {}", r1, r2);
    // r1 和 r2 在此之后不再使用，生命周期结束

    let r3 = &mut s; // 合法！共享引用已不再活跃
    r3.push_str(", world");
    println!("{}", r3);
}


悬垂引用防护
Rust 编译器保证引用永远不会悬垂（Dangling）——引用指向的数据一定是有效的。


// fn dangle() -> &String {
//     let s = String::from("hello");
//     &s // 编译错误：s 在函数结束时被释放，返回的引用将指向无效内存
// }

fn no_dangle() -> String {
    let s = String::from("hello");
    s // 返回所有权，而非引用
}


引用与切片
切片（Slice）是对连续数据序列的引用，是借用机制最常见的实际应用。


fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    for (i, &byte) in bytes.iter().enumerate() {
        if byte == b' ' {
            return &s[..i];
        }
    }
    &s[..]
}

fn main() {
    let s = String::from("hello world");
    let word = first_word(&s);
    println!("第一个单词: {}", word);
}

实用模式：借用与方法
结构体方法通过 &self 和 &mut self 体现借用：


struct Counter {
    value: u64,
}

impl Counter {
    fn get(&self) -> u64 {
        self.value
    }

    fn increment(&mut self) {
        self.value += 1;
    }

    fn into_value(self) -> u64 {
        self.value
    }
}

fn main() {
    let mut c = Counter { value: 0 };
    c.increment();
    c.increment();
    println!("当前值: {}", c.get());
    let final_val = c.into_value(); // 消耗 c 的所有权
    println!("最终值: {}", final_val);
}
