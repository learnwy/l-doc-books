Web 后端 Actix/Axum

Rust Web 后端生态

Rust 的 Web 后端框架基于 Tokio 异步运行时，在性能和资源效率上具有显著优势。两大主流框架是 Axum（由 Tokio 团队维护）和 Actix Web。

框架 维护者 架构特点 性能
Axum Tokio 团队 Tower 中间件体系 极高
Actix Web 社区 Actor 模型 极高
Rocket 社区 宏驱动 高
Poem 社区 轻量级 高

Axum 快速入门

use axum::{
    extract::{Path, Query, State},
    http::StatusCode,
    response::Json,
    routing::{get, post},
    Router,
};
use serde::{Deserialize, Serialize};
use std::sync::Arc;
use tokio::sync::Mutex;

#[derive(Clone)]
struct AppState {
    db: Arc<Mutex<Vec<User>>>,
}

#[derive(Serialize, Deserialize, Clone)]
struct User {
    id: u64,
    name: String,
    email: String,
}

#[derive(Deserialize)]
struct CreateUser {
    name: String,
    email: String,
}

async fn list_users(State(state): State<AppState>) -> Json<Vec<User>> {
    let users = state.db.lock().await;
    Json(users.clone())
}

async fn create_user(
    State(state): State<AppState>,
    Json(payload): Json<CreateUser>,
) -> (StatusCode, Json<User>) {
    let mut users = state.db.lock().await;
    let user = User {
        id: users.len() as u64 + 1,
        name: payload.name,
        email: payload.email,
    };
    users.push(user.clone());
    (StatusCode::CREATED, Json(user))
}

async fn get_user(
    State(state): State<AppState>,
    Path(id): Path<u64>,
) -> Result<Json<User>, StatusCode> {
    let users = state.db.lock().await;
    users
        .iter()
        .find(|u| u.id == id)
        .cloned()
        .map(Json)
        .ok_or(StatusCode::NOT_FOUND)
}

#[tokio::main]
async fn main() {
    let state = AppState {
        db: Arc::new(Mutex::new(vec![])),
    };

    let app = Router::new()
        .route("/users", get(list_users).post(create_user))
        .route("/users/{id}", get(get_user))
        .with_state(state);

    let listener = tokio::net::TcpListener::bind("0.0.0.0:3000")
        .await
        .unwrap();
    axum::serve(listener, app).await.unwrap();
}

中间件与 Tower

Axum 基于 Tower 中间件体系，可以组合复用各种中间件。

use axum::{middleware, Router, routing::get, http::Request, response::Response};
use std::time::Instant;
use tower_http::cors::{CorsLayer, Any};
use tower_http::trace::TraceLayer;

async fn logging_middleware(
    req: Request<axum::body::Body>,
    next: middleware::Next,
) -> Response {
    let method = req.method().clone();
    let uri = req.uri().clone();
    let start = Instant::now();

    let response = next.run(req).await;

    println!("{} {} - {:?} - {}",
        method, uri, start.elapsed(), response.status());
    response
}

fn create_app() -> Router {
    Router::new()
        .route("/", get(|| async { "Hello, World!" }))
        .layer(middleware::from_fn(logging_middleware))
        .layer(CorsLayer::new().allow_origin(Any))
        .layer(TraceLayer::new_for_http())
}

数据库集成（SQLx）

sqlx 提供编译期验证的异步 SQL 查询。

use sqlx::postgres::PgPoolOptions;

#[derive(sqlx::FromRow, serde::Serialize)]
struct User {
    id: i64,
    name: String,
    email: String,
}

async fn setup_db() -> sqlx::PgPool {
    PgPoolOptions::new()
        .max_connections(5)
        .connect("postgres://localhost/mydb")
        .await
        .expect("数据库连接失败")
}

async fn find_user(pool: &sqlx::PgPool, id: i64) -> Result<User, sqlx::Error> {
    sqlx::query_as::<_, User>("SELECT id, name, email FROM users WHERE id = $1")
        .bind(id)
        .fetch_one(pool)
        .await
}

Actix Web 示例

use actix_web::{web, App, HttpServer, HttpResponse, Responder};
use serde::Deserialize;

#[derive(Deserialize)]
struct Info {
    name: String,
}

async fn greet(info: web::Query<Info>) -> impl Responder {
    HttpResponse::Ok().body(format!("你好, {}!", info.name))
}

async fn health() -> impl Responder {
    HttpResponse::Ok().json(serde_json::json!({
        "status": "ok"
    }))
}

#[actix_web::main]
async fn main() -> std::io::Result<()> {
    HttpServer::new(|| {
        App::new()
            .route("/greet", web::get().to(greet))
            .route("/health", web::get().to(health))
    })
    .bind("0.0.0.0:8080")?
    .run()
    .await
}

Axum vs Actix Web 对比

维度 Axum Actix Web
异步运行时 Tokio Actix（基于 Tokio）
中间件体系 Tower（生态复用） 自有中间件系统
类型提取 编译期类型安全 编译期类型安全
宏使用 最少 较多（路由宏）
WebSocket 支持 支持
学习曲线 中等 中等
社区趋势 快速增长 成熟稳定
