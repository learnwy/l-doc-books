Cargo 与包管理

Cargo 核心功能

Cargo 是 Rust 的构建系统和包管理器，负责依赖管理、编译、测试、文档生成和发布。

命令 功能 常用选项
cargo new 创建新项目 --lib 创建库项目
cargo build 编译项目 --release 优化编译
cargo run 编译并运行 --example name 运行示例
cargo test 运行测试 -- --nocapture 显示输出
cargo doc 生成文档 --open 自动打开浏览器
cargo bench 运行基准测试 需要 criterion 等框架
cargo clippy 静态分析 -- -W clippy::all
cargo fmt 代码格式化 --check 仅检查
cargo publish 发布到 crates.io --dry-run 试运行

Cargo.toml 配置

[package]
name = "my-project"
version = "0.1.0"
edition = "2021"
authors = ["作者 <email@example.com>"]
description = "项目描述"
license = "MIT"
repository = "https://github.com/user/repo"

[dependencies]
serde = { version = "1.0", features = ["derive"] }
tokio = { version = "1", features = ["full"] }
log = "0.4"

[dev-dependencies]
criterion = { version = "0.5", features = ["html_reports"] }

[build-dependencies]
bindgen = "0.69"

[features]
default = ["std"]
std = []
async = ["tokio"]

Workspace 多包项目

Workspace 允许在一个仓库中管理多个相关的 crate，共享依赖版本和编译缓存。

# 根 Cargo.toml
[workspace]
members = [
    "crates/core",
    "crates/api",
    "crates/cli",
]
resolver = "2"

[workspace.dependencies]
serde = { version = "1.0", features = ["derive"] }
tokio = { version = "1", features = ["full"] }
anyhow = "1.0"
# crates/core/Cargo.toml
[package]
name = "my-core"
version = "0.1.0"
edition = "2021"

[dependencies]
serde = { workspace = true }


Features 条件编译
Features 允许按需启用功能，实现零成本的可选依赖。


[features]
default = ["json"]
json = ["serde_json"]
yaml = ["serde_yaml"]
full = ["json", "yaml", "async"]
async = ["tokio"]

[dependencies]
serde_json = { version = "1.0", optional = true }
serde_yaml = { version = "0.9", optional = true }
tokio = { version = "1", optional = true, features = ["full"] }
#[cfg(feature = "json")]
pub fn parse_json(input: &str) -> Result<Value, serde_json::Error> {
    serde_json::from_str(input)
}

#[cfg(feature = "yaml")]
pub fn parse_yaml(input: &str) -> Result<Value, serde_yaml::Error> {
    serde_yaml::from_str(input)
}


Build Script
build.rs 在编译前执行，常用于代码生成、链接 C 库、环境检测。


// build.rs
fn main() {
    println!("cargo:rerun-if-changed=src/proto/api.proto");

    let git_hash = std::process::Command::new("git")
        .args(["rev-parse", "--short", "HEAD"])
        .output()
        .map(|o| String::from_utf8_lossy(&o.stdout).trim().to_string())
        .unwrap_or_else(|_| "unknown".to_string());

    println!("cargo:rustc-env=GIT_HASH={}", git_hash);
}
// src/main.rs
fn main() {
    println!("版本: {} ({})", env!("CARGO_PKG_VERSION"), env!("GIT_HASH"));
}

交叉编译
# 添加目标
rustup target add x86_64-unknown-linux-musl

# 编译静态链接的 Linux 二进制
cargo build --release --target x86_64-unknown-linux-musl

# 使用 cross 工具（Docker 交叉编译）
cargo install cross
cross build --release --target aarch64-unknown-linux-gnu
