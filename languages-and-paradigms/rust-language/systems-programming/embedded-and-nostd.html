嵌入式与 no_std

什么是 no_std

#![no_std] 属性告诉编译器不链接标准库（std），只使用核心库（core）和可选的 alloc。这使得 Rust 可以在没有操作系统、没有堆分配的裸机环境中运行。

最小化 no_std 程序
#![no_std]
#![no_main]

use core::panic::PanicInfo;

#[panic_handler]
fn panic(_info: &PanicInfo) -> ! {
    loop {}
}

#[no_mangle]
pub extern "C" fn _start() -> ! {
    loop {}
}

embedded-hal 抽象层
embedded-hal 为嵌入式外设定义了统一的 trait 接口，使驱动代码可以跨硬件平台复用。


use embedded_hal::digital::OutputPin;

struct Led<P: OutputPin> {
    pin: P,
}

impl<P: OutputPin> Led<P> {
    fn new(pin: P) -> Self {
        Led { pin }
    }

    fn on(&mut self) {
        self.pin.set_high().ok();
    }

    fn off(&mut self) {
        self.pin.set_low().ok();
    }

    fn toggle(&mut self, state: bool) {
        if state {
            self.on();
        } else {
            self.off();
        }
    }
}

heapless：无堆数据结构
在没有堆分配的环境中，heapless 提供了栈上固定容量的集合。


use heapless::Vec;
use heapless::String;

fn main() {
    let mut buf: Vec<u8, 64> = Vec::new();
    buf.push(1).unwrap();
    buf.push(2).unwrap();
    buf.push(3).unwrap();

    let mut s: String<128> = String::new();
    core::fmt::write(&mut s, format_args!("温度: {}°C", 25)).unwrap();

    assert_eq!(buf.len(), 3);
}

中断与 RTIC
RTIC（Real-Time Interrupt-driven Concurrency）是 Rust 嵌入式领域的实时并发框架。


#[rtic::app(device = stm32f4xx_hal::pac, dispatchers = [USART1])]
mod app {
    use stm32f4xx_hal::prelude::*;

    #[shared]
    struct Shared {
        counter: u32,
    }

    #[local]
    struct Local {}

    #[init]
    fn init(cx: init::Context) -> (Shared, Local) {
        (Shared { counter: 0 }, Local {})
    }

    #[task(shared = [counter])]
    async fn update(mut cx: update::Context) {
        cx.shared.counter.lock(|c| {
            *c += 1;
        });
    }
}

no_std 与 std 兼容库
编写同时支持 no_std 和 std 的库：


#![cfg_attr(not(feature = "std"), no_std)]

#[cfg(feature = "alloc")]
extern crate alloc;

#[cfg(feature = "alloc")]
use alloc::vec::Vec;

pub fn sum(data: &[i32]) -> i32 {
    data.iter().sum()
}

#[cfg(feature = "alloc")]
pub fn collect_even(data: &[i32]) -> Vec<i32> {
    data.iter().filter(|&&x| x % 2 == 0).copied().collect()
}
# Cargo.toml
[features]
default = ["std"]
std = ["alloc"]
