内存布局与零成本抽象

类型的内存大小

Rust 中每个类型都有确定的大小（size）和对齐（align）。编译器会在字段间插入填充字节以满足对齐要求。

use std::mem;

fn main() {
    println!("i8:  size={}, align={}", mem::size_of::<i8>(), mem::align_of::<i8>());
    println!("i32: size={}, align={}", mem::size_of::<i32>(), mem::align_of::<i32>());
    println!("i64: size={}, align={}", mem::size_of::<i64>(), mem::align_of::<i64>());
    println!("&str: size={}", mem::size_of::<&str>());
    println!("String: size={}", mem::size_of::<String>());
    println!("Vec<i32>: size={}", mem::size_of::<Vec<i32>>());
}

常见类型大小（64 位系统）：

类型 大小（字节） 对齐（字节）
bool 1 1
i32 / u32 4 4
i64 / f64 8 8
&T 8 8
&str 16 8
String 24 8
Vec<T> 24 8
Option<&T> 8 8

Option<&T> 与 &T 大小相同，因为编译器利用了"引用不可能为 null"的特性进行空位优化（Niche Optimization）。

结构体布局与 repr

默认情况下，Rust 编译器可以自由重排结构体字段以优化大小。使用 #[repr] 属性可以精确控制布局。

#[repr(C)]
struct CLayout {
    a: u8,
    b: u32,
    c: u8,
}

#[repr(packed)]
struct Packed {
    a: u8,
    b: u32,
    c: u8,
}

fn main() {
    println!("默认: {}", std::mem::size_of::<(u8, u32, u8)>());
    println!("#[repr(C)]: {}", std::mem::size_of::<CLayout>());
    println!("#[repr(packed)]: {}", std::mem::size_of::<Packed>());
}
repr 属性 布局规则 大小 使用场景
默认 编译器自由优化 最小 一般 Rust 代码
#[repr(C)] 按 C 语言规则排列 含填充 FFI 互操作
#[repr(packed)] 去除填充 最紧凑 二进制协议解析
#[repr(align(N))] 保证最小对齐为 N ≥ N 缓存行对齐
#[repr(transparent)] 与内部单字段完全相同 同内部类型 newtype 模式

枚举布局与判别式

use std::mem;

enum Color {
    Red,
    Green,
    Blue,
}

enum Shape {
    Circle(f64),
    Rectangle(f64, f64),
    Point,
}

fn main() {
    println!("Color: size={}", mem::size_of::<Color>());
    println!("Shape: size={}", mem::size_of::<Shape>());
    println!("Option<bool>: size={}", mem::size_of::<Option<bool>>());
    println!("Option<&i32>: size={}", mem::size_of::<Option<&i32>>());
}


零大小类型（ZST）
零大小类型不占用内存，但在类型系统中具有意义。


use std::mem;

struct Unit;
struct PhantomState;

fn main() {
    println!("(): size={}", mem::size_of::<()>());
    println!("Unit: size={}", mem::size_of::<Unit>());
    println!("[i32; 0]: size={}", mem::size_of::<[i32; 0]>());
    println!("PhantomData<i32>: size={}", mem::size_of::<std::marker::PhantomData<i32>>());
}

零成本抽象示例
Rust 的迭代器链在编译后与手写循环性能相同——这就是零成本抽象。


fn sum_even_squares_iter(data: &[i32]) -> i32 {
    data.iter()
        .filter(|&&x| x % 2 == 0)
        .map(|&x| x * x)
        .sum()
}

fn sum_even_squares_loop(data: &[i32]) -> i32 {
    let mut sum = 0;
    for &x in data {
        if x % 2 == 0 {
            sum += x * x;
        }
    }
    sum
}
两个函数在 --release 模式下编译出几乎完全相同的机器码。
