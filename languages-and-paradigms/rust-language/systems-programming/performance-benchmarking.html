性能优化与基准测试

Rust 的性能优势

Rust 在系统编程领域具有与 C/C++ 比肩的性能，同时提供内存安全保证。零成本抽象、无垃圾回收、精确的内存控制是其性能基础。

性能因素 Rust 的做法 收益
内存管理 编译期所有权系统 无 GC 停顿
抽象 泛型单态化 零运行时开销
迭代器 编译器融合优化 等同手写循环
内联 #[inline] + LTO 减少函数调用开销

Criterion 基准测试

criterion 是 Rust 的标准基准测试框架，提供统计学上可靠的性能测量。

# Cargo.toml
[dev-dependencies]
criterion = { version = "0.5", features = ["html_reports"] }

[[bench]]
name = "my_benchmark"
harness = false
// benches/my_benchmark.rs
use criterion::{black_box, criterion_group, criterion_main, Criterion};

fn fibonacci(n: u64) -> u64 {
    match n {
        0 => 0,
        1 => 1,
        _ => fibonacci(n - 1) + fibonacci(n - 2),
    }
}

fn criterion_benchmark(c: &mut Criterion) {
    c.bench_function("fib 20", |b| b.iter(|| fibonacci(black_box(20))));

    let mut group = c.benchmark_group("fibonacci");
    for i in [10, 15, 20].iter() {
        group.bench_with_input(
            criterion::BenchmarkId::new("recursive", i),
            i,
            |b, &i| b.iter(|| fibonacci(black_box(i))),
        );
    }
    group.finish();
}

criterion_group!(benches, criterion_benchmark);
criterion_main!(benches);
cargo bench

编译优化选项

编译配置

# Cargo.toml
[profile.release]
opt-level = 3
lto = true
codegen-units = 1
panic = "abort"
strip = true
选项 说明 影响
opt-level = 3 最高优化级别 运行更快，编译更慢
lto = true 链接时优化（Link-Time Optimization） 跨 crate 内联，体积更小
codegen-units = 1 单代码生成单元 更好的优化，编译更慢
panic = "abort" panic 时直接终止 二进制更小
strip = true 剥离调试符号 二进制更小
target-cpu = "native" 针对当前 CPU 优化 使用特定指令集

常见优化技巧
避免不必要的堆分配
fn optimized(data: &[String]) -> Vec<&str> {
    data.iter().map(|s| s.as_str()).collect()
}

fn with_smallvec() {
    use smallvec::SmallVec;
    let mut buf: SmallVec<[u8; 64]> = SmallVec::new();
    buf.extend_from_slice(b"hello");
}
使用迭代器而非索引
fn sum_indexed(data: &[i32]) -> i32 {
    let mut sum = 0;
    for i in 0..data.len() {
        sum += data[i]; // 每次访问都有边界检查
    }
    sum
}

fn sum_iter(data: &[i32]) -> i32 {
    data.iter().sum() // 无边界检查，可能 SIMD 优化
}
预分配容量
fn collect_items(n: usize) -> Vec<i32> {
    let mut result = Vec::with_capacity(n);
    for i in 0..n as i32 {
        result.push(i * 2);
    }
    result
}


SIMD 优化
Rust 支持通过 std::simd（nightly）或 packed_simd / wide 使用 SIMD 指令。


#[cfg(target_arch = "x86_64")]
use std::arch::x86_64::*;

#[cfg(target_arch = "x86_64")]
unsafe fn sum_avx(data: &[f32]) -> f32 {
    let mut acc = _mm256_setzero_ps();
    let chunks = data.chunks_exact(8);
    let remainder = chunks.remainder();

    for chunk in chunks {
        let v = _mm256_loadu_ps(chunk.as_ptr());
        acc = _mm256_add_ps(acc, v);
    }

    let mut result = [0.0f32; 8];
    _mm256_storeu_ps(result.as_mut_ptr(), acc);
    let sum: f32 = result.iter().sum();
    sum + remainder.iter().sum::<f32>()
}
