unsafe Rust 与 FFI

unsafe 的五种超能力

unsafe 关键字允许执行编译器无法验证安全性的五种操作。使用 unsafe 不代表代码一定有问题，而是将安全责任从编译器转移到程序员。

操作 说明 安全 Rust 中是否可用
解引用裸指针 *const T / *mut T ❌
调用 unsafe 函数 标记为 unsafe fn 的函数 ❌
访问/修改可变静态变量 static mut ❌
实现 unsafe trait 如 Send、Sync ❌
访问 union 的字段 联合体字段访问 ❌

裸指针

裸指针（Raw Pointer）不受借用检查器约束，可以是空的、悬垂的或未对齐的。

fn main() {
    let mut value = 42;

    let r1 = &value as *const i32;
    let r2 = &mut value as *mut i32;

    unsafe {
        println!("r1 指向: {}", *r1);
        *r2 = 100;
        println!("r2 修改后: {}", *r2);
    }
}
裸指针类型 说明 对应安全引用
*const T 不可变裸指针 &T
*mut T 可变裸指针 &mut T

关键：创建裸指针是安全的，解引用裸指针才需要 unsafe。

unsafe 函数与安全抽象

unsafe 代码应被封装在安全的 API 内部，对外暴露安全接口。

fn split_at_mut(values: &mut [i32], mid: usize) -> (&mut [i32], &mut [i32]) {
    let len = values.len();
    let ptr = values.as_mut_ptr();

    assert!(mid <= len);

    unsafe {
        (
            std::slice::from_raw_parts_mut(ptr, mid),
            std::slice::from_raw_parts_mut(ptr.add(mid), len - mid),
        )
    }
}

fn main() {
    let mut v = vec![1, 2, 3, 4, 5, 6];
    let (left, right) = split_at_mut(&mut v, 3);
    println!("左: {:?}, 右: {:?}", left, right);
}


extern 与 FFI
FFI（Foreign Function Interface）允许 Rust 调用 C 函数，也允许 C 调用 Rust 函数。


Rust 调用 C
extern "C" {
    fn abs(input: i32) -> i32;
    fn strlen(s: *const std::ffi::c_char) -> usize;
}

fn main() {
    unsafe {
        println!("abs(-5) = {}", abs(-5));
    }
}
C 调用 Rust
#[no_mangle]
pub extern "C" fn rust_add(a: i32, b: i32) -> i32 {
    a + b
}
对应的 C 头文件：


int32_t rust_add(int32_t a, int32_t b);


CString 与 CStr
Rust 字符串（UTF-8，不含 null 终止符）和 C 字符串（null 终止的字节序列）之间需要转换。

use std::ffi::{CStr, CString};
use std::os::raw::c_char;

extern "C" {
    fn puts(s: *const c_char) -> i32;
}

fn main() {
    let c_string = CString::new("Hello from Rust!").unwrap();
    unsafe {
        puts(c_string.as_ptr());
    }
}

unsafe fn receive_c_string(ptr: *const c_char) -> String {
    let c_str = unsafe { CStr::from_ptr(ptr) };
    c_str.to_string_lossy().into_owned()
}


bindgen 自动生成绑定
bindgen 从 C 头文件自动生成 Rust FFI 绑定代码。


# Cargo.toml
[build-dependencies]
bindgen = "0.69"
// build.rs
fn main() {
    let bindings = bindgen::Builder::default()
        .header("wrapper.h")
        .generate()
        .expect("无法生成绑定");

    let out_path = std::path::PathBuf::from(std::env::var("OUT_DIR").unwrap());
    bindings
        .write_to_file(out_path.join("bindings.rs"))
        .expect("写入绑定失败");
}
