JVM 内部机制 简介

本章从运行时视角深入解析 Java 虚拟机的核心工作原理。理解 JVM 是从"Java 程序员"进阶为"Java 专家"的关键跨越——只有掌握了类如何被加载、代码如何被编译优化、内存如何被分配回收，才能在面对性能瓶颈和线上故障时做出准确判断。

本章包含四个核心主题。类加载机制部分详解双亲委派模型的设计动机与工作流程，介绍自定义类加载器的实现场景，并分析 Java 9 模块系统对类加载体系带来的变革。JIT 编译部分深入 HotSpot 虚拟机的即时编译策略，剖析 C1 客户端编译器与 C2 服务端编译器的分工协作、分层编译机制，以及逃逸分析、内联优化等关键编译优化技术。

垃圾回收算法部分系统对比主流垃圾收集器的设计理念，从经典的 CMS 到现代的 G1、ZGC 和 Shenandoah，分析各收集器的适用场景与调优参数。内存模型与 JMM部分解析 Java 内存模型的核心规则——happens-before 关系、volatile 的可见性语义、内存屏障的底层实现，这些知识是正确编写并发程序的理论基石。

建议在学习本章前先完成第一章的内容。类加载与 JIT 编译可以独立理解，但内存模型部分与第三章的并发编程互为补充，建议对照学习以加深理解。
