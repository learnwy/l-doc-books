Java 核心基础 简介

本章聚焦于 Java 语言层面的进阶特性，帮助读者从"会用"走向"深入理解"。Java 的类型系统、集合框架和异常处理机制是构建企业级应用的基石，而 Record 类、密封类和模式匹配等现代特性则代表着语言演进的最新方向。

本章包含四个核心主题。类型系统与泛型部分深入剖析 Java 泛型的底层实现——类型擦除机制，详解上界与下界通配符的使用场景，并通过实例讲解泛型方法和泛型类的高级设计模式。集合框架部分从数据结构视角分析 List、Map、Set 等核心接口的各实现类，重点探讨 HashMap 的红黑树优化、ConcurrentHashMap 的分段锁演进以及集合操作的性能特征与选择策略。

异常处理模式部分系统梳理检查异常与非检查异常的设计哲学，讨论 try-with-resources 的资源管理机制，并总结企业级项目中的异常处理最佳实践与常见反模式。Record、密封类与模式匹配部分介绍 Java 14-21 引入的三大语言特性，演示如何利用这些特性简化领域建模、增强类型安全性并提升代码可读性。

建议按顺序学习本章内容。泛型是集合框架的基础，异常处理贯穿所有 Java 编程实践，而现代特性则建立在对传统 Java 机制的充分理解之上。
