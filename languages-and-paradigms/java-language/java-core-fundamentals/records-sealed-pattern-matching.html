Record、Sealed 类与模式匹配

核心概念

Java 14-21 引入了一系列代数数据类型（Algebraic Data Types）特性：Record（数据载体）、Sealed 类（密封层次结构）和模式匹配（Pattern Matching）。这三者协同工作，使 Java 能够以类型安全的方式建模领域数据，并借助编译器的穷尽性检查消除运行时的类型转换错误。这是 Java 向现代语言范式演进的重要一步。

Record 类型详解
Record 是一种特殊的类，自动为其组件（components）生成 private final 字段、构造器、getter（与组件同名）、equals()、hashCode() 和 toString()。它是 Java 对"数据载体"需求的原生支持。


public record Point(double x, double y) {}

Point p = new Point(3.0, 4.0);
p.x();          // 3.0 — 自动生成的 accessor
p.toString();   // Point[x=3.0, y=4.0]

Point p2 = new Point(3.0, 4.0);
p.equals(p2);   // true — 基于所有组件的值比较
紧凑构造器用于参数校验，无需重复赋值：


public record Range(int min, int max) {
    public Range {
        if (min > max) {
            throw new IllegalArgumentException("min (%d) > max (%d)".formatted(min, max));
        }
    }
}
Record 可以实现接口，但不能继承类（隐式继承 java.lang.Record）：


public sealed interface Shape permits Circle, Rectangle {}

public record Circle(double radius) implements Shape {
    public double area() { return Math.PI * radius * radius; }
}

public record Rectangle(double width, double height) implements Shape {
    public double area() { return width * height; }
}

Record 的局限性：不能声明实例字段（只有组件字段），不能使用 extends（除 Record 本身），所有字段不可变。这些限制是有意为之——Record 是纯数据载体，不是通用类替代品。


Sealed 类与密封层次
Sealed 类通过 permits 子句严格限定其直接子类。编译器保证只有声明的子类可以继承该类或实现该接口，这为模式匹配的穷尽性检查提供了基础。


public sealed interface Expression
    permits Literal, BinaryOp, UnaryOp, Variable {
}

public record Literal(double value) implements Expression {}
public record Variable(String name) implements Expression {}
public record BinaryOp(Expression left, Operator op, Expression right) implements Expression {}
public record UnaryOp(Operator op, Expression operand) implements Expression {}

public enum Operator { ADD, SUB, MUL, DIV, NEG }
子类的三种修饰选择：


public sealed class Account permits SavingsAccount, CheckingAccount, CreditAccount {
}

public final class SavingsAccount extends Account {}

public sealed class CheckingAccount extends Account permits PersonalChecking, BusinessChecking {}
public final class PersonalChecking extends CheckingAccount {}
public final class BusinessChecking extends CheckingAccount {}

public non-sealed class CreditAccount extends Account {}

Sealed 层次结构特别适合表达有限的变体集合——如 AST 节点、协议消息、状态机状态等领域模型。


模式匹配与 switch 表达式
instanceof 模式匹配消除了传统的先判断后转型的冗余代码：


// Java 16 之前
if (obj instanceof String) {
    String s = (String) obj;
    System.out.println(s.length());
}

// Java 16+ 模式匹配
if (obj instanceof String s) {
    System.out.println(s.length());
}

// 带守卫条件
if (obj instanceof String s && s.length() > 10) {
    System.out.println("Long string: " + s);
}
switch 模式匹配（Java 21）将 switch 从值匹配扩展到类型匹配，结合 Sealed 类实现编译期穷尽性检查：


public double evaluate(Expression expr, Map<String, Double> env) {
    return switch (expr) {
        case Literal(var value) -> value;
        case Variable(var name) -> env.getOrDefault(name, 0.0);
        case BinaryOp(var left, var op, var right) -> switch (op) {
            case ADD -> evaluate(left, env) + evaluate(right, env);
            case SUB -> evaluate(left, env) - evaluate(right, env);
            case MUL -> evaluate(left, env) * evaluate(right, env);
            case DIV -> evaluate(left, env) / evaluate(right, env);
            default -> throw new UnsupportedOperationException();
        };
        case UnaryOp(var op, var operand) -> switch (op) {
            case NEG -> -evaluate(operand, env);
            default -> throw new UnsupportedOperationException();
        };
    };
}
守卫条件（guarded patterns）使用 when 关键字：


public String classify(Shape shape) {
    return switch (shape) {
        case Circle(var r) when r > 100 -> "大圆";
        case Circle(var r) when r > 10 -> "中圆";
        case Circle c -> "小圆";
        case Rectangle(var w, var h) when w == h -> "正方形";
        case Rectangle r -> "矩形";
    };
}
Record 解构模式（Deconstruction Patterns）允许在 switch 和 instanceof 中直接提取 Record 组件：


public record Pair<A, B>(A first, B second) {}

// 嵌套解构
if (pair instanceof Pair(String name, Pair(Integer x, Integer y))) {
    System.out.printf("%s at (%d, %d)%n", name, x, y);
}
实际应用场景
领域建模
public sealed interface PaymentResult
    permits PaymentSuccess, PaymentFailed, PaymentPending {
}

public record PaymentSuccess(String transactionId, BigDecimal amount)
    implements PaymentResult {}
public record PaymentFailed(String reason, ErrorCode code)
    implements PaymentResult {}
public record PaymentPending(String orderId, Instant deadline)
    implements PaymentResult {}

public String handlePayment(PaymentResult result) {
    return switch (result) {
        case PaymentSuccess(var txId, var amount) ->
            "支付成功：%s，金额 %.2f".formatted(txId, amount);
        case PaymentFailed(var reason, var code) ->
            "支付失败：%s（%s）".formatted(reason, code);
        case PaymentPending(var orderId, var deadline) ->
            "等待支付：%s，截止 %s".formatted(orderId, deadline);
    };
}
JSON 解析器的 AST
public sealed interface JsonValue
    permits JsonString, JsonNumber, JsonBool, JsonNull, JsonArray, JsonObject {
}

public record JsonString(String value) implements JsonValue {}
public record JsonNumber(double value) implements JsonValue {}
public record JsonBool(boolean value) implements JsonValue {}
public record JsonNull() implements JsonValue {}
public record JsonArray(List<JsonValue> elements) implements JsonValue {}
public record JsonObject(Map<String, JsonValue> fields) implements JsonValue {}

public String prettyPrint(JsonValue value, int indent) {
    return switch (value) {
        case JsonString(var s) -> "\"%s\"".formatted(s);
        case JsonNumber(var n) -> String.valueOf(n);
        case JsonBool(var b) -> String.valueOf(b);
        case JsonNull() -> "null";
        case JsonArray(var elems) -> "[\n" + elems.stream()
            .map(e -> " ".repeat(indent + 2) + prettyPrint(e, indent + 2))
            .collect(Collectors.joining(",\n")) + "\n" + " ".repeat(indent) + "]";
        case JsonObject(var fields) -> "{\n" + fields.entrySet().stream()
            .map(e -> " ".repeat(indent + 2) + "\"%s\": %s".formatted(
                e.getKey(), prettyPrint(e.getValue(), indent + 2)))
            .collect(Collectors.joining(",\n")) + "\n" + " ".repeat(indent) + "}";
    };
}
小结
    

  • Record 是不可变数据载体，自动生成构造器、accessor、equals/hashCode/toString，消除 POJO 样板代码
    • 

  • Sealed 类通过 permits 限定子类集合，子类必须是 final、sealed 或 non-sealed
    • 

  • instanceof 模式匹配消除冗余的类型转换，switch 模式匹配支持类型分支和守卫条件
    • 

  • Record 解构模式允许在 switch/instanceof 中直接提取组件，支持嵌套解构
    • 

  • Sealed + Record + 模式匹配三者组合，使 Java 能够以代数数据类型的方式建模领域——编译器保证穷尽性
    • 

  • 典型应用场景：领域事件/结果建模、AST 解析、协议消息、状态机
    •
