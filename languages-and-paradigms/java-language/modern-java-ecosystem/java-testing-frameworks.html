Java 测试框架

核心概念

Java 测试生态以 JUnit 5 为核心，配合 Mockito（Mock 框架）、AssertJ（断言库）和 Testcontainers（集成测试）构成了完整的测试工具链。JUnit 5 采用模块化架构（Jupiter + Platform + Vintage），提供了参数化测试、嵌套测试、动态测试等现代特性。编写高质量测试代码的能力，是衡量 Java 工程师专业水平的重要指标。

JUnit 5 核心特性
基本测试结构
@DisplayName("订单服务测试")
class OrderServiceTest {

    private OrderService orderService;
    private OrderRepository orderRepository;

    @BeforeEach
    void setUp() {
        orderRepository = new InMemoryOrderRepository();
        orderService = new OrderService(orderRepository);
    }

    @Test
    @DisplayName("创建订单 - 正常场景")
    void shouldCreateOrder() {
        OrderRequest request = new OrderRequest("user-1", List.of(
            new LineItem("product-1", 2, BigDecimal.valueOf(99.99))
        ));

        Order order = orderService.createOrder(request);

        assertThat(order.getId()).isNotNull();
        assertThat(order.getStatus()).isEqualTo(OrderStatus.CREATED);
        assertThat(order.getTotalAmount()).isEqualByComparingTo("199.98");
    }

    @Test
    @DisplayName("创建订单 - 空商品列表应抛出异常")
    void shouldThrowWhenEmptyLineItems() {
        OrderRequest request = new OrderRequest("user-1", List.of());

        assertThatThrownBy(() -> orderService.createOrder(request))
            .isInstanceOf(IllegalArgumentException.class)
            .hasMessageContaining("至少包含一个商品");
    }
}
参数化测试
@ParameterizedTest
@CsvSource({
    "100, 0, 100.00",
    "100, 10, 90.00",
    "100, 100, 0.00",
    "200, 15, 170.00"
})
@DisplayName("折扣计算")
void shouldCalculateDiscount(double price, int discountPercent, double expected) {
    BigDecimal result = PriceCalculator.applyDiscount(
        BigDecimal.valueOf(price), discountPercent);
    assertThat(result).isEqualByComparingTo(BigDecimal.valueOf(expected));
}

@ParameterizedTest
@MethodSource("invalidEmails")
@DisplayName("邮箱格式校验 - 非法邮箱")
void shouldRejectInvalidEmail(String email) {
    assertThat(EmailValidator.isValid(email)).isFalse();
}

static Stream<String> invalidEmails() {
    return Stream.of("", "noatsign", "@nodomain", "spaces in@email.com", null);
}

@ParameterizedTest
@EnumSource(value = OrderStatus.class, names = {"CREATED", "PAID"})
@DisplayName("可取消的订单状态")
void shouldBeCancellable(OrderStatus status) {
    assertThat(status.isCancellable()).isTrue();

嵌套测试
@DisplayName("购物车测试")
class ShoppingCartTest {

    private ShoppingCart cart;

    @BeforeEach
    void setUp() {
        cart = new ShoppingCart();
    }

    @Nested
    @DisplayName("空购物车")
    class EmptyCart {
        @Test
        void shouldHaveZeroItems() {
            assertThat(cart.getItemCount()).isZero();
        }

        @Test
        void shouldHaveZeroTotal() {
            assertThat(cart.getTotal()).isEqualByComparingTo(BigDecimal.ZERO);
        }
    }

    @Nested
    @DisplayName("添加商品后")
    class AfterAddingItems {
        @BeforeEach
        void addItems() {
            cart.add(new Product("A", BigDecimal.valueOf(10)), 2);
            cart.add(new Product("B", BigDecimal.valueOf(20)), 1);
        }

        @Test
        void shouldCalculateTotal() {
            assertThat(cart.getTotal()).isEqualByComparingTo("40.00");
        }

        @Nested
        @DisplayName("移除商品后")
        class AfterRemovingItem {
            @BeforeEach
            void removeItem() {
                cart.remove("A");
            }

            @Test
            void shouldUpdateTotal() {
                assertThat(cart.getTotal()).isEqualByComparingTo("20.00");
            }
        }
    }
}

Mockito 深入实践
@ExtendWith(MockitoExtension.class)
class PaymentServiceTest {

    @Mock
    private PaymentGateway gateway;

    @Mock
    private TransactionRepository txRepo;

    @InjectMocks
    private PaymentService paymentService;

    @Test
    void shouldProcessPaymentSuccessfully() {
        PaymentRequest request = new PaymentRequest("order-1", BigDecimal.valueOf(100));
        when(gateway.charge(any(ChargeRequest.class)))
            .thenReturn(new ChargeResult("tx-123", ChargeStatus.SUCCESS));

        PaymentResult result = paymentService.process(request);

        assertThat(result.isSuccess()).isTrue();
        verify(txRepo).save(argThat(tx ->
            tx.getTransactionId().equals("tx-123") &&
            tx.getStatus() == TransactionStatus.COMPLETED
        ));
        verify(gateway, times(1)).charge(any());
    }

    @Test
    void shouldRetryOnGatewayTimeout() {
        when(gateway.charge(any()))
            .thenThrow(new GatewayTimeoutException())
            .thenReturn(new ChargeResult("tx-456", ChargeStatus.SUCCESS));

        PaymentResult result = paymentService.process(
            new PaymentRequest("order-2", BigDecimal.valueOf(50)));

        assertThat(result.isSuccess()).isTrue();
        verify(gateway, times(2)).charge(any());
    }
}

Testcontainers 集成测试
Testcontainers 使用 Docker 启动真实的外部依赖（数据库、消息队列、缓存），使集成测试贴近生产环境：


@Testcontainers
@SpringBootTest
class UserRepositoryIntegrationTest {

    @Container
    static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:16")
        .withDatabaseName("testdb")
        .withUsername("test")
        .withPassword("test");

    @DynamicPropertySource
    static void configureProperties(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", postgres::getJdbcUrl);
        registry.add("spring.datasource.username", postgres::getUsername);
        registry.add("spring.datasource.password", postgres::getPassword);
    }

    @Autowired
    private UserRepository userRepository;

    @Test
    void shouldSaveAndFindUser() {
        User user = new User("alice", "alice@example.com");
        userRepository.save(user);

        Optional<User> found = userRepository.findByUsername("alice");
        assertThat(found).isPresent()
            .get()
            .extracting(User::getEmail)
            .isEqualTo("alice@example.com");
    }
}

小结
    

  • JUnit 5 采用模块化架构，提供参数化测试、嵌套测试、扩展模型等现代特性
    • 

  • 参数化测试通过 @CsvSource、@MethodSource、@EnumSource 等注解实现数据驱动测试
    • 

  • Mockito 通过 @Mock + @InjectMocks 创建测试替身，when/thenReturn 设定行为，verify 验证交互
    • 

  • AssertJ 的流式断言 API 比 JUnit 内置断言更表达力强：assertThat(x).isEqualTo(y)
    • 

  • Testcontainers 使用真实 Docker 容器进行集成测试，通过 @DynamicPropertySource 注入连接信息
    • 

  • 测试金字塔原则：大量单元测试（快速）+ 适量集成测试（Testcontainers）+ 少量端到端测试
