CompletableFuture 与响应式编程

核心概念

CompletableFuture 是 Java 8 引入的异步编程核心类，实现了 Future 和 CompletionStage 接口。它支持链式组合、异常处理和多 Future 聚合，是 Java 世界构建非阻塞异步流水线的标准工具。相比传统的 Future.get() 阻塞等待，CompletableFuture 通过回调机制实现了真正的异步编排。

异步任务创建与线程池
CompletableFuture 的异步方法默认使用 ForkJoinPool.commonPool()。在生产环境中，应该提供自定义线程池以隔离不同业务的资源：


ExecutorService ioPool = Executors.newFixedThreadPool(
    Runtime.getRuntime().availableProcessors() * 2,
    r -> new Thread(r, "io-pool")
);

CompletableFuture<User> userFuture = CompletableFuture.supplyAsync(
    () -> userService.findById(userId),
    ioPool  // 指定线程池
);

CompletableFuture<List<Order>> ordersFuture = CompletableFuture.supplyAsync(
    () -> orderService.findByUserId(userId),
    ioPool
);
创建方法对比：


// supplyAsync — 有返回值
CompletableFuture<String> cf1 = CompletableFuture.supplyAsync(() -> "result");

// runAsync — 无返回值
CompletableFuture<Void> cf2 = CompletableFuture.runAsync(() -> doSomething());

// completedFuture — 已完成的 Future（用于测试或默认值）
CompletableFuture<String> cf3 = CompletableFuture.completedFuture("default");

// failedFuture — 已失败的 Future（Java 9+）
CompletableFuture<String> cf4 = CompletableFuture.failedFuture(new RuntimeException());
链式转换与组合
thenApply vs thenCompose——这是 CompletableFuture 中最重要的区别，类似于 Stream 的 map 和 flatMap：


// thenApply — 同步转换（map）
CompletableFuture<String> nameFuture = userFuture
    .thenApply(user -> user.getName());

// thenCompose — 异步链式（flatMap）
CompletableFuture<List<Order>> ordersFuture = userFuture
    .thenCompose(user -> orderService.findByUserIdAsync(user.getId()));

// thenCombine — 合并两个独立的 Future
CompletableFuture<UserProfile> profileFuture = userFuture.thenCombine(
    ordersFuture,
    (user, orders) -> new UserProfile(user, orders)
);
批量操作：


List<CompletableFuture<Product>> futures = productIds.stream()
    .map(id -> CompletableFuture.supplyAsync(
        () -> productService.findById(id), ioPool))
    .toList();

// allOf — 等待所有完成
CompletableFuture<List<Product>> allProducts = CompletableFuture
    .allOf(futures.toArray(CompletableFuture[]::new))
    .thenApply(v -> futures.stream()
        .map(CompletableFuture::join)
        .toList());

// anyOf — 取最先完成的
CompletableFuture<Object> fastest = CompletableFuture
    .anyOf(futures.toArray(CompletableFuture[]::new));

异常处理策略
CompletableFuture 提供了三种异常处理方式，它们的语义差异需要仔细区分：


// exceptionally — 只处理异常，返回降级值
CompletableFuture<User> safeUser = userFuture
    .exceptionally(ex -> {
        log.error("Failed to fetch user", ex);
        return User.anonymous();
    });

// handle — 同时处理正常结果和异常
CompletableFuture<Response> response = userFuture
    .handle((user, ex) -> {
        if (ex != null) {
            return Response.error(ex.getMessage());
        }
        return Response.ok(user);
    });

// whenComplete — 不改变结果，只做副作用（如日志）
CompletableFuture<User> logged = userFuture
    .whenComplete((user, ex) -> {
        if (ex != null) {
            log.error("Failed", ex);
        } else {
            log.info("Got user: {}", user.getName());
        }
    });
超时控制（Java 9+）：


CompletableFuture<User> withTimeout = userFuture
    .orTimeout(3, TimeUnit.SECONDS)           // 超时抛异常
    .completeOnTimeout(User.anonymous(), 3, TimeUnit.SECONDS);  // 超时返回默认值

实际编排案例
一个典型的电商下单流程——多个服务并行调用，结果汇聚后执行后续操作：


public CompletableFuture<OrderResult> placeOrder(OrderRequest request) {
    CompletableFuture<User> userCF = CompletableFuture.supplyAsync(
        () -> userService.validate(request.getUserId()), ioPool);

    CompletableFuture<Product> productCF = CompletableFuture.supplyAsync(
        () -> productService.checkStock(request.getProductId()), ioPool);

    CompletableFuture<BigDecimal> priceCF = CompletableFuture.supplyAsync(
        () -> priceService.calculate(request), ioPool);

    return userCF.thenCombine(productCF, (user, product) -> new OrderContext(user, product))
        .thenCombine(priceCF, (ctx, price) -> ctx.withPrice(price))
        .thenCompose(ctx -> CompletableFuture.supplyAsync(
            () -> orderService.create(ctx), ioPool))
        .thenApply(order -> {
            notificationService.sendAsync(order);
            return new OrderResult(order.getId(), "SUCCESS");
        })
        .exceptionally(ex -> {
            log.error("Order failed", ex);
            return new OrderResult(null, "FAILED: " + ex.getMessage());
        });
}
小结
    

  • CompletableFuture 是 Java 异步编程的标准工具，支持链式转换、组合和异常处理
    • 

  • thenApply 是同步转换（map），thenCompose 是异步链式（flatMap），两者语义不同不可混淆
    • 

  • 异步方法默认使用 ForkJoinPool.commonPool()，生产环境应提供自定义线程池隔离资源
    • 

  • 异常处理三种方式：exceptionally（降级值）、handle（全面处理）、whenComplete（副作用）
    • 

  • allOf/anyOf 实现多 Future 的聚合，Java 9+ 的 orTimeout/completeOnTimeout 提供超时控制
    • 

  • 实际场景中，CompletableFuture 适合编排多个独立异步调用并汇聚结果的流水线
