Concepts 与约束

核心概念

Concepts 是 C++20 引入的模板约束机制，它用命名的编译期谓词替代了 SFINAE 和 enable_if 等晦涩的模板技巧，为模板参数提供了清晰、可读的类型要求。Concepts 不仅改善了模板错误信息的可读性，还使得模板接口成为可文档化的契约。

定义与使用 Concept
concept 通过 requires 表达式定义对类型的语法和语义要求。requires 表达式可以检查操作是否有效、返回类型是否匹配等：


#include <concepts>
#include <string>

template<typename T>
concept Printable = requires(T t) {
    { std::to_string(t) } -> std::convertible_to<std::string>;
};

template<typename T>
concept Hashable = requires(T t) {
    { std::hash<T>{}(t) } -> std::convertible_to<std::size_t>;
};

template<typename T>
concept Comparable = requires(T a, T b) {
    { a < b } -> std::convertible_to<bool>;
    { a > b } -> std::convertible_to<bool>;
    { a == b } -> std::convertible_to<bool>;
    { a != b } -> std::convertible_to<bool>;
};

template<typename C>
concept Container = requires(C c) {
    typename C::value_type;
    typename C::iterator;
    { c.begin() } -> std::same_as<typename C::iterator>;
    { c.end() } -> std::same_as<typename C::iterator>;
    { c.size() } -> std::convertible_to<std::size_t>;
    { c.empty() } -> std::convertible_to<bool>;
};

template<Container C>
void print_container(const C& c) {
    for (const auto& item : c) {
        // 打印每个元素
    }
}
约束的四种语法
C++20 提供了四种等价的方式使用 Concepts 约束模板参数：


#include <concepts>

template<std::integral T>
T gcd_v1(T a, T b) {
    while (b != 0) {
        T temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

template<typename T>
requires std::integral<T>
T gcd_v2(T a, T b) {
    while (b != 0) {
        T temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

template<typename T>
T gcd_v3(T a, T b) requires std::integral<T> {
    while (b != 0) {
        T temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

auto gcd_v4(std::integral auto a, std::integral auto b) {
    while (b != 0) {
        auto temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

约束组合与重载决议
Concepts 支持逻辑组合（&&、||），编译器根据约束的「包含关系」选择最精确的重载：


#include <concepts>
#include <string>

template<typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

template<typename T>
concept SignedNumeric = Numeric<T> && std::is_signed_v<T>;

template<Numeric T>
std::string format(T value) {
    return std::to_string(value);
}

template<SignedNumeric T>
std::string format(T value) {
    if (value < 0) return "-" + std::to_string(-value);
    return "+" + std::to_string(value);
}

template<typename T>
concept Serializable = requires(T t) {
    { t.serialize() } -> std::convertible_to<std::string>;
};

template<typename T>
concept Deserializable = requires(T t, const std::string& s) {
    { T::deserialize(s) } -> std::same_as<T>;
};

template<typename T>
concept FullySerializable = Serializable<T> && Deserializable<T>;

template<Serializable T>
void save(const T& obj) { auto data = obj.serialize(); }

template<FullySerializable T>
void save(const T& obj) { auto data = obj.serialize(); /* 附加校验 */ }
标准库 Concepts
C++20 标准库提供了丰富的预定义 Concepts：


#include <concepts>
#include <ranges>
#include <iterator>

template<std::ranges::range R>
auto sum_range(const R& range) {
    using T = std::ranges::range_value_t<R>;
    T result{};
    for (const auto& val : range) {
        result += val;
    }
    return result;
}

template<std::random_access_iterator It>
void quick_sort(It first, It last) {
    if (first >= last) return;
    auto pivot = *first;
    auto mid = std::partition(first + 1, last,
        [&pivot](const auto& x) { return x < pivot; });
    std::iter_swap(first, mid - 1);
    quick_sort(first, mid - 1);
    quick_sort(mid, last);
}

小结
    

  • Concepts 是 C++20 的模板约束机制，替代了晦涩的 SFINAE 和 enable_if
    • 

  • concept 通过 requires 表达式定义，可以检查操作有效性、返回类型和嵌套类型
    • 

  • 四种使用语法：模板参数约束、前置 requires、后置 requires 和 auto 参数
    • 

  • 约束支持逻辑组合（&&/||），编译器根据包含关系选择最精确的重载
    • 

  • 标准库提供了丰富的预定义 Concepts，覆盖类型属性、迭代器和范围
    • 

  • Concepts 的核心价值：清晰的模板接口文档化 + 友好的编译错误信息
    •
