函数模板

核心概念

C++ 模板是实现编译期多态和代码复用的核心机制。函数模板允许编写与类型无关的通用算法，编译器在调用时根据实参类型自动推导模板参数并生成特化的函数实例。模板是 C++ 的「零开销抽象」理念的最佳体现——泛型代码编译后与手写的特化代码性能完全一致。

模板参数推导
编译器在函数模板调用时自动推导模板参数类型。推导规则与 auto 推导一致（实际上 auto 就是模板参数推导的语法糖）：


#include <type_traits>
#include <string>

template<typename T>
T max_value(T a, T b) {
    return (a > b) ? a : b;
}

template<typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}

template<typename T>
void print_type(T&& val) {
    if constexpr (std::is_integral_v<std::remove_reference_t<T>>) {
        // 整数类型处理
    } else if constexpr (std::is_floating_point_v<std::remove_reference_t<T>>) {
        // 浮点类型处理
    } else {
        // 其他类型处理
    }
}

void demonstrate_deduction() {
    auto r1 = max_value(3, 7);            // T = int
    auto r2 = max_value(3.14, 2.71);      // T = double
    // auto r3 = max_value(3, 2.71);      // 错误：T 推导冲突
    auto r4 = max_value<double>(3, 2.71); // 显式指定 T = double

    auto r5 = add(3, 2.5);               // T=int, U=double, 返回 double

    print_type(42);                       // T = int
    int x = 10;
    print_type(x);                        // T = int& (转发引用)
}
非类型模板参数
模板参数不仅可以是类型，还可以是编译期常量值（非类型参数）。C++20 扩展了非类型参数的支持范围，允许浮点数和字面量类型：


#include <array>
#include <cstddef>

template<typename T, size_t N>
class StaticArray {
    T data_[N];
public:
    constexpr size_t size() const { return N; }
    T& operator[](size_t i) { return data_[i]; }
    const T& operator[](size_t i) const { return data_[i]; }

    T* begin() { return data_; }
    T* end() { return data_ + N; }
};

template<size_t N>
constexpr size_t fibonacci() {
    if constexpr (N <= 1) return N;
    else return fibonacci<N - 1>() + fibonacci<N - 2>();
}

template<auto Value>
struct Constant {
    static constexpr auto value = Value;
};

void demonstrate_nttp() {
    StaticArray<int, 10> arr;
    constexpr auto fib10 = fibonacci<10>();  // 编译期计算: 55

    using FortyTwo = Constant<42>;
    using Pi = Constant<3.14>;               // C++20: 浮点 NTTP
}
变参模板与折叠表达式
C++11 的变参模板（Variadic Templates）和 C++17 的折叠表达式（Fold Expressions）使得处理任意数量的模板参数变得简洁：


#include <tuple>
#include <iostream>
#include <string>

template<typename... Args>
auto sum(Args... args) {
    return (args + ...);  // C++17 一元右折叠
}

template<typename... Args>
auto product(Args... args) {
    return (args * ... * 1);  // 二元右折叠（带初始值）
}

template<typename F, typename... Args>
decltype(auto) invoke_all(F&& f, Args&&... args) {
    (f(std::forward<Args>(args)), ...);  // 逗号折叠
}

template<typename... Ts>
struct TypeList {
    static constexpr size_t size = sizeof...(Ts);
};

template<typename T, typename... Args>
std::unique_ptr<T> make(Args&&... args) {
    return std::make_unique<T>(std::forward<Args>(args)...);
}

void demonstrate_variadic() {
    auto s = sum(1, 2, 3, 4, 5);         // 15
    auto p = product(1.0, 2.0, 3.0);     // 6.0

    invoke_all([](auto x) {}, 1, "hello", 3.14);

    using List = TypeList<int, double, std::string>;
    static_assert(List::size == 3);
}

SFINAE 与 Concepts 约束
SFINAE（Substitution Failure Is Not An Error）是 C++11/14 中约束模板参数的核心机制。当模板参数替换导致无效类型时，编译器不会报错，而是从重载集中移除该候选。C++20 的 Concepts 提供了更优雅的约束语法：


#include <concepts>
#include <type_traits>
#include <string>

template<typename T>
auto to_string_sfinae(T value)
    -> std::enable_if_t<std::is_arithmetic_v<T>, std::string> {
    return std::to_string(value);
}

template<typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

template<Numeric T>
T clamp(T value, T low, T high) {
    return (value < low) ? low : (value > high) ? high : value;
}

template<typename T>
requires std::is_default_constructible_v<T> && std::is_copy_assignable_v<T>
T create_and_assign(const T& source) {
    T result{};
    result = source;
    return result;
}

void demonstrate_concepts() {
    auto r1 = clamp(42, 0, 100);        // int
    auto r2 = clamp(3.14, 0.0, 1.0);    // double
    // auto r3 = clamp("hello", "a", "z"); // 编译错误：不满足 Numeric
}

小结
    

  • 函数模板通过类型参数化实现零开销的泛型编程，编译后生成特化的高效代码
    • 

  • 模板参数推导规则与 auto 一致，推导冲突时需要显式指定模板参数
    • 

  • 非类型模板参数支持编译期常量值，C++20 扩展到浮点数和字面量类型
    • 

  • if constexpr 实现编译期分支，消除运行时类型判断的开销
    • 

  • 变参模板 + 折叠表达式处理任意数量的参数，是现代 C++ 元编程的基础
    • 

  • SFINAE 是 C++11/14 的模板约束机制，C++20 的 Concepts 提供了更清晰的替代方案
    • 

  • Concepts（C++20）为模板参数添加约束，提供更清晰的错误信息和文档
    •
