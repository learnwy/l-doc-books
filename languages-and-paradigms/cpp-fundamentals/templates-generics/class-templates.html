类模板与特化

核心概念

类模板将模板参数化扩展到类的定义层面，允许创建与类型无关的数据结构和容器。STL 中的 std::vector、std::map、std::optional 等核心组件都是类模板的产物。类模板支持全特化（为特定类型提供完全不同的实现）和偏特化（为满足特定条件的类型提供定制实现），这使得编译期的类型分发和优化成为可能。

类模板定义与成员实现
类模板的成员函数在模板类外定义时需要重复模板参数声明。C++17 的类模板参数推导（CTAD）允许省略模板参数：


#include <stdexcept>
#include <algorithm>

template<typename T>
class Stack {
    T* data_;
    size_t size_;
    size_t capacity_;

public:
    explicit Stack(size_t cap = 16)
        : data_(new T[cap]), size_(0), capacity_(cap) {}

    ~Stack() { delete[] data_; }

    Stack(const Stack& other)
        : data_(new T[other.capacity_]), size_(other.size_), capacity_(other.capacity_) {
        std::copy_n(other.data_, size_, data_);
    }

    Stack(Stack&& other) noexcept
        : data_(other.data_), size_(other.size_), capacity_(other.capacity_) {
        other.data_ = nullptr;
        other.size_ = other.capacity_ = 0;
    }

    void push(const T& val) {
        if (size_ >= capacity_) grow();
        data_[size_++] = val;
    }

    void push(T&& val) {
        if (size_ >= capacity_) grow();
        data_[size_++] = std::move(val);
    }

    T& top() {
        if (size_ == 0) throw std::out_of_range("Stack is empty");
        return data_[size_ - 1];
    }

    void pop() {
        if (size_ == 0) throw std::out_of_range("Stack is empty");
        --size_;
    }

    bool empty() const { return size_ == 0; }
    size_t size() const { return size_; }

private:
    void grow() {
        capacity_ *= 2;
        T* new_data = new T[capacity_];
        std::move(data_, data_ + size_, new_data);
        delete[] data_;
        data_ = new_data;
    }
};

void demonstrate_class_template() {
    Stack<int> int_stack;
    int_stack.push(42);
    int_stack.push(100);

    Stack<std::string> str_stack;
    str_stack.push("hello");
    str_stack.push(std::string("world"));

    Stack int_stack2(32);  // C++17 CTAD（需要推导指引）
}
全特化与偏特化
类模板的全特化为特定类型提供完全不同的实现，偏特化为满足特定模式（如指针类型、数组类型）的类型提供定制实现：


#include <cstring>
#include <memory>

template<typename T>
struct Serializer {
    static std::string serialize(const T& value) {
        return std::to_string(value);
    }
};

template<>
struct Serializer<std::string> {
    static std::string serialize(const std::string& value) {
        return "\"" + value + "\"";
    }
};

template<>
struct Serializer<bool> {
    static std::string serialize(bool value) {
        return value ? "true" : "false";
    }
};

template<typename T>
struct Serializer<std::vector<T>> {
    static std::string serialize(const std::vector<T>& vec) {
        std::string result = "[";
        for (size_t i = 0; i < vec.size(); ++i) {
            if (i > 0) result += ",";
            result += Serializer<T>::serialize(vec[i]);
        }
        return result + "]";
    }
};

template<typename T>
struct Serializer<T*> {
    static std::string serialize(T* ptr) {
        if (!ptr) return "null";
        return Serializer<T>::serialize(*ptr);
    }
};
Type Traits 与编译期类型信息
STL 的 <type_traits> 头文件提供了一整套编译期类型查询和变换工具，它们都是通过类模板特化实现的：


#include <type_traits>

template<typename T>
struct is_pointer : std::false_type {};

template<typename T>
struct is_pointer<T*> : std::true_type {};

template<typename T>
constexpr bool is_pointer_v = is_pointer<T>::value;

template<typename T>
struct remove_const { using type = T; };

template<typename T>
struct remove_const<const T> { using type = T; };

template<typename T>
void process(T&& value) {
    using CleanType = std::remove_cvref_t<T>;

    if constexpr (std::is_integral_v<CleanType>) {
        // 整数处理路径
    } else if constexpr (std::is_same_v<CleanType, std::string>) {
        // 字符串处理路径
    } else if constexpr (is_pointer_v<CleanType>) {
        // 指针处理路径
    }
}

模板别名与推导指引
模板别名（alias template）通过 using 声明简化复杂模板类型的书写。C++17 的推导指引（deduction guide）允许自定义 CTAD 的推导规则：


#include <vector>
#include <string>
#include <memory>

template<typename T>
using Vec = std::vector<T>;

template<typename K, typename V>
using Dict = std::unordered_map<K, V>;

template<typename T>
using UniqueVec = std::vector<std::unique_ptr<T>>;

template<typename T>
class Wrapper {
    T value_;
public:
    Wrapper(T val) : value_(std::move(val)) {}
    const T& get() const { return value_; }
};

Wrapper(const char*) -> Wrapper<std::string>;

void demonstrate_alias_and_guides() {
    Vec<int> numbers = {1, 2, 3};
    Dict<std::string, int> scores;

    Wrapper w1(42);            // Wrapper<int>
    Wrapper w2("hello");       // Wrapper<std::string>（推导指引）
}
小结
    

  • 类模板将泛型编程扩展到数据结构层面，STL 容器都是类模板的产物
    • 

  • 全特化为特定类型提供完全替代实现，偏特化为类型模式（指针/数组/容器）提供定制
    • 

  • C++17 CTAD 允许在构造时省略模板参数，编译器从构造函数参数推导
    • 

  • 推导指引可自定义 CTAD 的推导规则，如将 const char* 推导为 std::string
    • 

  • Type Traits 通过类模板特化实现编译期类型查询和变换，是元编程的基础
    • 

  • if constexpr + Type Traits 实现零开销的编译期类型分发
    • 

  • 类模板特化的匹配优先级：全特化 > 偏特化 > 主模板
    •
