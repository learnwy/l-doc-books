智能指针与 RAII

核心概念

RAII（Resource Acquisition Is Initialization）是 C++ 资源管理的核心范式：将资源的获取与对象的构造绑定，将资源的释放与对象的析构绑定。智能指针是 RAII 在内存管理中的最典型应用——std::unique_ptr 表达独占所有权，std::shared_ptr 表达共享所有权，std::weak_ptr 打破循环引用。

unique_ptr 深入
unique_ptr 是最轻量的智能指针，它的大小等于裸指针（除非使用有状态的删除器）。编译器保证同一时刻只有一个 unique_ptr 拥有资源，所有权只能通过移动语义转移：


#include <memory>
#include <vector>

class Connection {
    int fd_;
public:
    explicit Connection(int fd) : fd_(fd) {}
    ~Connection() { /* close(fd_) */ }
    void send(const char* data) { /* write to fd_ */ }
};

std::unique_ptr<Connection> create_connection(const char* host, int port) {
    int fd = 42;
    return std::make_unique<Connection>(fd);
}

void demonstrate_unique_ptr() {
    auto conn = create_connection("localhost", 8080);
    conn->send("hello");

    // auto conn2 = conn;             // 编译错误：不可拷贝
    auto conn2 = std::move(conn);     // 所有权转移
    // conn 现在为 nullptr

    std::vector<std::unique_ptr<Connection>> pool;
    pool.push_back(std::move(conn2));

    auto custom_deleter = [](Connection* p) {
        p->send("goodbye");
        delete p;
    };
    std::unique_ptr<Connection, decltype(custom_deleter)>
        conn3(new Connection(100), custom_deleter);
}

class FileHandle {
    struct FileDeleter {
        void operator()(FILE* fp) const {
            if (fp) std::fclose(fp);
        }
    };
    std::unique_ptr<FILE, FileDeleter> file_;

public:
    explicit FileHandle(const char* path, const char* mode)
        : file_(std::fopen(path, mode)) {}

    bool is_open() const { return file_ != nullptr; }
};
shared_ptr 与控制块
shared_ptr 通过引用计数实现共享所有权。每个 shared_ptr 组包含一个控制块，存储强引用计数（strong count）和弱引用计数（weak count）。make_shared 将对象和控制块分配在同一块内存中：


#include <memory>

struct Node {
    int value;
    std::shared_ptr<Node> next;
    std::weak_ptr<Node> prev;     // 使用 weak_ptr 避免循环引用

    explicit Node(int v) : value(v) {}
};

void demonstrate_shared_ptr() {
    auto node1 = std::make_shared<Node>(1);
    auto node2 = std::make_shared<Node>(2);

    node1->next = node2;
    node2->prev = node1;           // weak_ptr 不增加引用计数

    long count = node1.use_count(); // 1（只有 node1 自己）

    if (auto locked = node2->prev.lock()) {
        // locked 是 shared_ptr<Node>，对象仍然存活
    }

    std::weak_ptr<Node> observer = node1;
    node1.reset();                  // 强引用归零，对象销毁

    if (observer.expired()) {
        // 对象已销毁
    }
}

RAII 模式扩展
RAII 不仅适用于内存管理，还可以管理文件句柄、互斥锁、网络连接等任何需要获取和释放的资源：


#include <mutex>
#include <fstream>

class ScopedTimer {
    const char* name_;
    std::chrono::steady_clock::time_point start_;
public:
    explicit ScopedTimer(const char* name)
        : name_(name), start_(std::chrono::steady_clock::now()) {}

    ~ScopedTimer() {
        auto end = std::chrono::steady_clock::now();
        auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start_);
    }
};

void demonstrate_raii_patterns() {
    std::mutex mtx;
    {
        std::lock_guard<std::mutex> lock(mtx);  // RAII 锁
    }

    {
        std::ofstream file("data.txt");          // RAII 文件
        file << "content";
    }

    {
        ScopedTimer timer("operation");          // RAII 计时
    }
}
智能指针的性能与选型
不同智能指针的性能特征差异显著。unique_ptr 在编译期完成所有权检查，运行时无任何额外开销；shared_ptr 的原子引用计数在多线程高并发场景可能成为瓶颈：


#include <memory>
#include <vector>

void performance_comparison() {
    constexpr int N = 1000000;

    std::vector<std::unique_ptr<int>> unique_vec;
    unique_vec.reserve(N);
    for (int i = 0; i < N; ++i) {
        unique_vec.push_back(std::make_unique<int>(i));
    }

    std::vector<std::shared_ptr<int>> shared_vec;
    shared_vec.reserve(N);
    for (int i = 0; i < N; ++i) {
        shared_vec.push_back(std::make_shared<int>(i));
    }
}

小结
    

  • RAII 将资源获取与对象构造绑定、释放与析构绑定，是 C++ 资源安全的基石
    • 

  • unique_ptr 表达独占所有权，零开销（等同裸指针），是最常用的智能指针
    • 

  • shared_ptr 通过原子引用计数实现共享所有权，make_shared 合并对象和控制块分配
    • 

  • weak_ptr 不增加引用计数，用于打破循环引用和安全观察 shared_ptr 管理的对象
    • 

  • RAII 模式可扩展到文件句柄、互斥锁、数据库连接等任何获取-释放语义的资源
    • 

  • shared_ptr 的原子引用计数在高并发拷贝场景可能成为性能瓶颈，优先考虑 unique_ptr
    • 

  • 优先使用 make_unique / make_shared，避免裸 new/delete
    •
