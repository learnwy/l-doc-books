栈与堆内存

核心概念

C++ 程序的内存模型将进程地址空间划分为栈（Stack）、堆（Heap）、全局/静态区和代码区四个主要区域。栈内存由编译器自动管理，遵循后进先出的分配策略，速度极快；堆内存通过 new/delete（或 malloc/free）手动管理，支持任意大小和生命周期的分配，但有分配开销和碎片化风险。

栈帧与函数调用
每次函数调用都会在栈上创建一个栈帧（Stack Frame），包含局部变量、函数参数和返回地址。函数返回时栈帧自动销毁：


#include <cstdio>

struct StackAnalysis {
    int local_var;
    char buffer[256];
    double result;
};

void inner_function() {
    StackAnalysis data;
    data.local_var = 42;
}

void outer_function() {
    int x = 10;
    int y = 20;
    inner_function();
}

void demonstrate_stack_overflow() {
    char huge_array[1024 * 1024 * 8]; // 8MB — 可能超出栈大小限制
    huge_array[0] = 'x';              // Stack Overflow!
}

size_t measure_stack_usage() {
    volatile char marker;
    static volatile char* base = nullptr;
    if (!base) base = &marker;
    return static_cast<size_t>(base - &marker);
}
堆分配策略
堆内存的分配器（allocator）维护空闲块链表，使用首次适配（first-fit）、最佳适配（best-fit）或伙伴系统（buddy system）等策略查找合适的空闲块：


#include <memory>
#include <vector>

void demonstrate_heap_allocation() {
    int* p = new int(42);           // 单对象分配
    int* arr = new int[100];        // 数组分配
    delete p;
    delete[] arr;

    auto up = std::make_unique<int>(42);     // 推荐：智能指针
    auto sp = std::make_shared<int>(42);     // 共享所有权

    auto vec = std::make_unique<std::vector<int>>(1000);
}

class PoolAllocator {
    struct Block { Block* next; };
    Block* free_list_;
    char* pool_;
    size_t block_size_;
    size_t pool_size_;

public:
    PoolAllocator(size_t block_size, size_t count)
        : block_size_(block_size), pool_size_(block_size * count) {
        pool_ = new char[pool_size_];
        free_list_ = nullptr;
        for (size_t i = 0; i < count; ++i) {
            auto* block = reinterpret_cast<Block*>(pool_ + i * block_size);
            block->next = free_list_;
            free_list_ = block;
        }
    }

    ~PoolAllocator() { delete[] pool_; }

    void* allocate() {
        if (!free_list_) return nullptr;
        Block* block = free_list_;
        free_list_ = block->next;
        return block;
    }

    void deallocate(void* ptr) {
        auto* block = static_cast<Block*>(ptr);
        block->next = free_list_;
        free_list_ = block;
    }
};

placement new 与自定义内存
placement new 允许在预分配的内存上构造对象，常用于内存池和自定义分配器：


#include <new>

class Widget {
    int value_;
public:
    explicit Widget(int v) : value_(v) {}
    ~Widget() {}
    int get() const { return value_; }
};

void demonstrate_placement_new() {
    alignas(Widget) char buffer[sizeof(Widget)];

    Widget* w = new (buffer) Widget(42);
    int val = w->get();
    w->~Widget();
}
内存对齐与缓存行
CPU 按缓存行（Cache Line，通常 64 字节）从内存加载数据。数据的内存对齐和布局直接影响缓存命中率，进而影响程序性能。C++ 提供了 alignas 关键字和 std::aligned_storage 来控制内存对齐：


#include <cstddef>
#include <new>

struct alignas(64) CacheAligned {
    int data[16];
};

struct Compact {
    char a;      // 1 字节
    int b;       // 4 字节（偏移 4，因对齐填充 3 字节）
    char c;      // 1 字节（偏移 8）
};               // sizeof = 12（尾部填充至 4 的倍数）

struct Optimized {
    int b;       // 4 字节
    char a;      // 1 字节
    char c;      // 1 字节
};               // sizeof = 8（重新排列减少填充）

void demonstrate_alignment() {
    static_assert(sizeof(Compact) > sizeof(Optimized));
    static_assert(alignof(CacheAligned) == 64);

    auto* p = new (std::align_val_t{64}) CacheAligned{};
    ::operator delete(p, std::align_val_t{64});
}

小结
    

  • 栈内存由编译器自动管理，速度极快但大小有限（通常 1-8MB）
    • 

  • 堆内存通过 new/delete 手动管理，支持任意大小但有分配开销和碎片化风险
    • 

  • 内存池（Pool Allocator）将堆分配降至 O(1)，适合固定大小对象的高频分配场景
    • 

  • placement new 在预分配内存上构造对象，需要手动调用析构函数
    • 

  • 成员变量按大小降序排列可减少结构体的填充字节，提高内存利用率
    • 

  • 缓存行对齐（alignas(64)）可避免多线程场景的 false sharing 问题
    • 

  • 现代 C++ 推荐使用 std::make_unique / std::make_shared 替代裸 new/delete
    • 

  • 栈分配是缓存友好的连续内存访问，堆分配分散在地址空间中缓存命中率低
    •
