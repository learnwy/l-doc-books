面向对象基础

核心概念

C++ 的面向对象编程（OOP）通过类（class）和结构体（struct）实现数据封装、继承和多态三大支柱。与 Java 或 C# 不同，C++ 的 OOP 模型支持多重继承、虚继承和值语义的对象模型。类在 C++ 中不仅是封装数据和方法的容器，更是一种定义用户自定义类型的机制，编译器会为其生成构造函数、析构函数、拷贝/移动操作等特殊成员函数。

特殊成员函数与 Rule of Five
C++ 编译器会在特定条件下自动生成六个特殊成员函数。Rule of Five 指出：如果一个类需要自定义其中任何一个，通常需要自定义全部五个（不包括默认构造）：


#include <memory>
#include <cstring>

class Buffer {
    char* data_;
    size_t size_;

public:
    explicit Buffer(size_t size)
        : data_(new char[size]), size_(size) {
        std::memset(data_, 0, size);
    }

    ~Buffer() {
        delete[] data_;
    }

    Buffer(const Buffer& other)
        : data_(new char[other.size_]), size_(other.size_) {
        std::memcpy(data_, other.data_, size_);
    }

    Buffer& operator=(const Buffer& other) {
        if (this != &other) {
            delete[] data_;
            size_ = other.size_;
            data_ = new char[size_];
            std::memcpy(data_, other.data_, size_);
        }
        return *this;
    }

    Buffer(Buffer&& other) noexcept
        : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }

    Buffer& operator=(Buffer&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }

    size_t size() const { return size_; }
    char* data() { return data_; }
    const char* data() const { return data_; }
};
现代 C++ 推荐使用 Rule of Zero：通过组合智能指针和标准容器，让编译器自动生成正确的特殊成员函数：


class ModernBuffer {
    std::unique_ptr<char[]> data_;
    size_t size_;

public:
    explicit ModernBuffer(size_t size)
        : data_(std::make_unique<char[]>(size)), size_(size) {}

    size_t size() const { return size_; }
    char* data() { return data_.get(); }
};

虚函数与运行时多态
虚函数通过 vtable（虚函数表）实现运行时多态。每个含有虚函数的类都有一个 vtable，每个对象实例包含一个指向 vtable 的隐藏指针（vptr）。虚函数调用通过 vptr 间接查表完成：


class Shape {
public:
    virtual ~Shape() = default;
    virtual double area() const = 0;
    virtual void draw() const = 0;
};

class Circle final : public Shape {
    double radius_;
public:
    explicit Circle(double r) : radius_(r) {}
    double area() const override { return 3.14159 * radius_ * radius_; }
    void draw() const override { /* 绘制圆形 */ }
};

class Rectangle : public Shape {
    double width_, height_;
public:
    Rectangle(double w, double h) : width_(w), height_(h) {}
    double area() const override { return width_ * height_; }
    void draw() const override { /* 绘制矩形 */ }
};

double total_area(const std::vector<std::unique_ptr<Shape>>& shapes) {
    double sum = 0;
    for (const auto& s : shapes) {
        sum += s->area();
    }
    return sum;
}
CRTP 与编译期多态
Curiously Recurring Template Pattern（CRTP）通过模板继承在编译期实现多态行为，完全消除了虚函数的间接调用开销。基类通过模板参数获取派生类的类型信息，在编译期完成静态分发：


template<typename Derived>
class ShapeBase {
public:
    double area() const {
        return static_cast<const Derived*>(this)->area_impl();
    }

    void draw() const {
        static_cast<const Derived*>(this)->draw_impl();
    }
};

class CRTPCircle : public ShapeBase<CRTPCircle> {
    double radius_;
public:
    explicit CRTPCircle(double r) : radius_(r) {}
    double area_impl() const { return 3.14159 * radius_ * radius_; }
    void draw_impl() const { /* 绘制圆形 */ }
};

class CRTPRect : public ShapeBase<CRTPRect> {
    double w_, h_;
public:
    CRTPRect(double w, double h) : w_(w), h_(h) {}
    double area_impl() const { return w_ * h_; }
    void draw_impl() const { /* 绘制矩形 */ }
};

template<typename Shape>
double compute_area(const ShapeBase<Shape>& shape) {
    return shape.area();
}

小结
    

  • C++ OOP 通过 class 实现封装、继承和多态，支持多重继承和值语义对象模型
    • 

  • Rule of Five：自定义析构函数时通常需要同时定义拷贝/移动构造和赋值运算符
    • 

  • Rule of Zero：优先使用智能指针和 STL 容器，让编译器自动生成正确的特殊成员函数
    • 

  • 虚函数通过 vtable + vptr 实现运行时多态，override 和 final 关键字增强类型安全
    • 

  • CRTP 通过模板继承实现零开销编译期多态，适合高性能场景
    • 

  • 编译期多态（模板、CRTP）是零开销的，在性能敏感场景优于运行时多态
    • 

  • 现代 C++ 推荐组合优于继承，使用 std::variant 替代简单的继承层次结构
    •
