指针与引用

核心概念

指针和引用是 C++ 区别于其他高级语言的核心特性，它们提供了直接操作内存地址的能力。指针存储变量的内存地址，可以在运行时改变指向；引用是变量的别名，一旦绑定就不可更改。正确使用指针和引用是编写安全高效 C++ 代码的基础。

指针运算与数组关系
C++ 中指针和数组有着密切的关系。数组名在大多数上下文中会退化（decay）为指向首元素的指针，指针算术运算按照所指类型的大小进行偏移：


#include <cstddef>

void demonstrate_pointer_arithmetic() {
    int arr[5] = {10, 20, 30, 40, 50};
    int* p = arr;         // 数组退化为指针

    int val1 = *(p + 2);  // 30，等价于 arr[2]
    int val2 = p[3];      // 40，p[i] 等价于 *(p + i)

    ptrdiff_t diff = &arr[4] - &arr[1];  // 3（元素个数差）

    char* cp = reinterpret_cast<char*>(p);
    char* cp_next = reinterpret_cast<char*>(p + 1);
    ptrdiff_t byte_diff = cp_next - cp;  // 4（sizeof(int)）

    void* vp = arr;
    int* ip = static_cast<int*>(vp);     // void* 转换
}

void demonstrate_array_decay() {
    int arr[5] = {1, 2, 3, 4, 5};
    int (*pa)[5] = &arr;       // 指向数组的指针
    int (&ra)[5] = arr;        // 数组的引用（不退化）

    auto a1 = arr;             // int*（退化）
    auto& a2 = arr;            // int(&)[5]（引用保留数组类型）
    decltype(arr) a3 = {0};    // int[5]（decltype 保留数组类型）
}
引用的绑定规则
C++ 引用的绑定规则决定了何种引用可以绑定到何种表达式。这些规则是理解函数重载解析和模板参数推导的关键：


#include <string>
#include <utility>

void bind_rules() {
    int x = 42;
    int& lr = x;             // 左值引用绑定到左值
    // int& lr2 = 42;        // 错误：左值引用不能绑定到右值

    const int& cr = 42;      // const 引用可以绑定到右值（生命周期延长）
    const int& cr2 = x;      // const 引用也可以绑定到左值

    int&& rr = 42;           // 右值引用绑定到右值
    int&& rr2 = std::move(x); // 右值引用绑定到 xvalue
    // int&& rr3 = x;        // 错误：右值引用不能绑定到左值
}

void overload_resolution(int& x)        { /* lvalue 重载 */ }
void overload_resolution(const int& x)  { /* const lvalue 重载 */ }
void overload_resolution(int&& x)       { /* rvalue 重载 */ }

void call_overloads() {
    int a = 1;
    const int b = 2;

    overload_resolution(a);              // 调用 int&
    overload_resolution(b);              // 调用 const int&
    overload_resolution(42);             // 调用 int&&
    overload_resolution(std::move(a));   // 调用 int&&
}

函数指针与回调
函数指针是 C++ 实现回调和策略模式的基础机制。C++11 的 std::function 提供了类型擦除的通用可调用对象封装：


#include <functional>
#include <vector>
#include <algorithm>

using Comparator = bool(*)(int, int);

bool ascending(int a, int b) { return a < b; }
bool descending(int a, int b) { return a > b; }

void sort_with_fn_ptr(std::vector<int>& vec, Comparator cmp) {
    std::sort(vec.begin(), vec.end(), cmp);
}

using Callback = std::function<void(int result)>;

void async_compute(int input, Callback on_done) {
    int result = input * input;
    on_done(result);
}

void demonstrate_callables() {
    std::vector<int> data = {3, 1, 4, 1, 5};

    sort_with_fn_ptr(data, ascending);
    sort_with_fn_ptr(data, descending);

    async_compute(42, [](int result) {
        // lambda 隐式转换为 std::function
    });

    auto lambda = [factor = 2](int x) { return x * factor; };
    std::function<int(int)> fn = lambda;
}
指针安全与最佳实践
指针相关的内存错误是 C++ 程序崩溃和安全漏洞的首要来源。悬垂指针（dangling pointer）、空指针解引用和缓冲区溢出在生产系统中造成了大量事故。现代 C++ 通过智能指针、引用语义和静态分析工具来系统性地降低指针风险：


#include <memory>
#include <span>
#include <optional>

int* dangling_example() {
    int local = 42;
    return &local;             // 悬垂指针：local 在返回后销毁
}

void null_safety() {
    int* p = nullptr;
    // *p = 42;                // 未定义行为：空指针解引用

    std::optional<int> safe_val;
    if (safe_val.has_value()) {
        int v = safe_val.value();
    }
}

void buffer_safety() {
    int arr[5] = {1, 2, 3, 4, 5};
    std::span<int> view(arr);    // C++20：带边界检查的数组视图

    for (auto& val : view) {
        val *= 2;                // 安全迭代，不会越界
    }
}

小结
    

  • 指针存储内存地址，可为空、可重绑定、支持算术运算；引用是别名，不可为空、不可重绑定
    • 

  • 数组名在大多数上下文中退化为指针，使用引用或 decltype 可保留数组类型信息
    • 

  • 引用绑定规则：左值引用绑定左值，右值引用绑定右值，const 引用可绑定两者
    • 

  • 函数重载解析根据实参的值类别选择最匹配的引用参数类型
    • 

  • std::function 提供类型擦除的通用回调封装，但有虚函数调用和堆分配的性能开销
    • 

  • 现代 C++ 推荐优先使用引用而非原始指针，使用智能指针管理动态内存的所有权
    • 

  • C++20 的 std::span 提供安全的数组视图，结合 AddressSanitizer 可在开发阶段检测内存错误
    •
