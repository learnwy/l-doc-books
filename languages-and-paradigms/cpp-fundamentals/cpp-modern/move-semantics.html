移动语义与右值引用

核心概念

移动语义（Move Semantics）是 C++11 引入的最重要的语言特性之一，它通过区分「需要保留的值」（左值）和「即将消亡的值」（右值），允许编译器在安全的前提下「窃取」临时对象的资源，避免不必要的深拷贝。右值引用（T&&）是移动语义的语法基础，std::move 和 std::forward 是其核心工具。移动语义让 C++ 在保持值语义的同时达到接近指针传递的性能。

移动构造与移动赋值
移动构造函数和移动赋值运算符是移动语义的实现载体。当源对象是右值时，编译器会优先调用移动版本而非拷贝版本，通过「窃取」源对象的内部资源（如动态内存、文件句柄）来避免深拷贝。


#include <cstring>
#include <utility>
#include <algorithm>

class DynamicBuffer {
public:
    explicit DynamicBuffer(std::size_t size)
        : data_(new char[size]), size_(size), capacity_(size) {
        std::memset(data_, 0, size_);
    }

    ~DynamicBuffer() { delete[] data_; }

    DynamicBuffer(const DynamicBuffer& other)
        : data_(new char[other.size_]), size_(other.size_), capacity_(other.size_) {
        std::memcpy(data_, other.data_, size_);
    }

    DynamicBuffer(DynamicBuffer&& other) noexcept
        : data_(other.data_), size_(other.size_), capacity_(other.capacity_) {
        other.data_ = nullptr;
        other.size_ = 0;
        other.capacity_ = 0;
    }

    auto operator=(const DynamicBuffer& other) -> DynamicBuffer& {
        if (this != &other) {
            auto* newData = new char[other.size_];
            std::memcpy(newData, other.data_, other.size_);
            delete[] data_;
            data_ = newData;
            size_ = other.size_;
            capacity_ = other.size_;
        }
        return *this;
    }

    auto operator=(DynamicBuffer&& other) noexcept -> DynamicBuffer& {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            capacity_ = other.capacity_;
            other.data_ = nullptr;
            other.size_ = 0;
            other.capacity_ = 0;
        }
        return *this;
    }

    auto size() const -> std::size_t { return size_; }

private:
    char* data_;
    std::size_t size_;
    std::size_t capacity_;
};
noexcept 声明对移动操作至关重要。标准容器（如 std::vector）在扩容时只有在元素的移动构造函数声明为 noexcept 时才会使用移动而非拷贝——因为如果移动过程中抛出异常，已经移动的元素无法恢复。

std::move 与 std::forward
std::move 是一个类型转换工具，它将左值无条件转换为右值引用，表明程序员允许移动该对象。std::move 本身不移动任何东西——它只是给编译器一个提示，让重载决议选择移动版本。


#include <vector>
#include <string>
#include <utility>

void moveSemantics() {
    std::string name = "hello world";
    std::vector<std::string> names;

    names.push_back(name);
    names.push_back(std::move(name));

    auto createBuffer = []() -> DynamicBuffer {

template <typename T>
class Container {
public:
    void add(T&& value) {
        data_.push_back(std::forward<T>(value));
    }

    template <typename U>
    void emplace(U&& value) {
        data_.push_back(std::forward<U>(value));
    }

private:
    std::vector<T> data_;
};
std::forward 是完美转发的核心工具，用于在模板中保持参数的值类别。当模板参数 T&& 作为万能引用（forwarding reference）时，T 可能被推导为左值引用或非引用类型。std::forward(arg) 在 T 为左值引用时返回左值引用，否则返回右值引用。


完美转发与工厂模式
完美转发（Perfect Forwarding）允许模板函数将参数以完全相同的值类别转发给另一个函数，既不引入多余的拷贝，也不丢失右值性。这在工厂函数、包装器和 emplace 系列接口中至关重要。


#include <memory>
#include <tuple>
#include <utility>

template <typename T, typename... Args>
auto makeUnique(Args&&... args) -> std::unique_ptr<T> {
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}

template <typename Func, typename... Args>
auto invoke(Func&& func, Args&&... args)
    -> decltype(std::forward<Func>(func)(std::forward<Args>(args)...)) {
    return std::forward<Func>(func)(std::forward<Args>(args)...);
}

struct Connection {
    std::string host;
    int port;
    bool ssl;

    Connection(std::string h, int p, bool s)
        : host(std::move(h)), port(p), ssl(s) {}
};

template <typename T, typename Tuple, std::size_t... Is>
auto constructFromTupleImpl(Tuple&& t, std::index_sequence<Is...>)
    -> std::unique_ptr<T> {
    return std::make_unique<T>(std::get<Is>(std::forward<Tuple>(t))...);
}

template <typename T, typename Tuple>
auto constructFromTuple(Tuple&& t) -> std::unique_ptr<T> {
    constexpr auto size = std::tuple_size_v<std::remove_reference_t<Tuple>>;
    return constructFromTupleImpl<T>(
        std::forward<Tuple>(t), std::make_index_sequence<size>{}
    );
}
引用折叠规则是完美转发的基础：T& & → T&，T& && → T&，T&& & → T&，T&& && → T&&。简而言之，只要存在左值引用，结果就是左值引用；只有两个右值引用折叠在一起才产生右值引用。


小结
    

  • 移动语义通过区分左值和右值，允许「窃取」临时对象资源避免深拷贝
    • 

  • 移动构造和移动赋值应声明为 noexcept，这是标准容器使用移动的前提条件
    • 

  • std::move 是无条件类型转换，std::forward 是条件转发，二者不执行实际移动
    • 

  • 完美转发通过万能引用和引用折叠规则在模板中保持参数的值类别
    • 

  • 移动后的对象处于「有效但未指定」状态，只能赋值或析构
    • 

  • 对于 POD 类型（int、double），移动与拷贝相同，移动语义主要优化管理资源的类
    •
