模板与泛型编程

核心概念

C++ 模板是编译期多态的核心机制，通过参数化类型和值实现代码复用。模板在编译期实例化，生成针对具体类型的特化代码，因此不引入运行时开销——这是 C++ 「零开销抽象」理念的典范。从简单的函数模板和类模板，到变参模板、SFINAE 和概念（Concepts），C++ 的泛型编程体系在表达力和类型安全之间提供了精细的控制。

函数模板与类型推导
函数模板允许编写一次代码并在不同类型上复用。编译器通过模板参数推导（Template Argument Deduction）自动确定模板参数的具体类型，大多数情况下不需要显式指定。


#include <type_traits>
#include <algorithm>
#include <vector>
#include <string>

template <typename T>
auto maximum(const T& a, const T& b) -> const T& {
    return (a > b) ? a : b;
}

template <typename InputIt, typename T>
auto accumulate(InputIt first, InputIt last, T init) -> T {
    for (; first != last; ++first) {
        init = init + *first;
    }
    return init;
}

template <typename Container, typename Predicate>
auto filterCopy(const Container& src, Predicate pred) -> Container {
    Container result;
    std::copy_if(src.begin(), src.end(), std::back_inserter(result), pred);
    return result;
}

void functionTemplateDemo() {
    auto maxInt = maximum(3, 5);
    auto maxStr = maximum(std::string("abc"), std::string("def"));

    std::vector<int> nums{1, 2, 3, 4, 5};
    auto sum = accumulate(nums.begin(), nums.end(), 0);

    auto evens = filterCopy(nums, [](int n) { return n % 2 == 0; });
}
C++17 引入了类模板参数推导（CTAD），允许从构造函数参数推导类模板参数。C++20 的 auto 函数参数进一步简化了模板语法。


类模板与特化
类模板将整个类参数化为类型或值，标准库中的容器（vector、map）和智能指针都是类模板。模板特化允许为特定类型提供定制实现。


#include <cstddef>
#include <stdexcept>
#include <type_traits>

template <typename T, std::size_t N>
class StaticArray {
public:
    auto operator[](std::size_t index) -> T& {
        if (index >= N) throw std::out_of_range("index out of range");
        return data_[index];
    }

    auto operator[](std::size_t index) const -> const T& {
        if (index >= N) throw std::out_of_range("index out of range");
        return data_[index];
    }

    constexpr auto size() const -> std::size_t { return N; }

    auto begin() -> T* { return data_; }
    auto end() -> T* { return data_ + N; }
    auto begin() const -> const T* { return data_; }
    auto end() const -> const T* { return data_ + N; }

private:
    T data_[N];
};

template <typename T>
struct TypeTraits {
    static constexpr bool isInteger = std::is_integral_v<T>;
    static constexpr bool isFloating = std::is_floating_point_v<T>;
    static constexpr bool isPointer = std::is_pointer_v<T>;
    static constexpr std::size_t size = sizeof(T);
};

template <>
struct TypeTraits<bool> {
    static constexpr bool isInteger = false;
    static constexpr bool isFloating = false;
    static constexpr bool isPointer = false;
    static constexpr std::size_t size = 1;
};

template <typename T>
struct TypeTraits<T*> {
    static constexpr bool isInteger = false;
    static constexpr bool isFloating = false;
    static constexpr bool isPointer = true;
    static constexpr std::size_t size = sizeof(T*);
    using PointeeType = T;
};
CRTP（Curiously Recurring Template Pattern）是一种静态多态技术：基类模板以派生类作为模板参数，在编译期实现多态行为，避免虚函数的运行时开销。

变参模板与参数包
变参模板（Variadic Templates）是 C++11 引入的强大特性，允许模板接受任意数量和类型的参数。标准库的 std::tuple、std::make_shared 和 std::variant 都依赖变参模板。


#include <iostream>
#include <string>
#include <tuple>
#include <sstream>

template <typename... Args>
auto formatString(const std::string& fmt, Args&&... args) -> std::string {
    std::ostringstream oss;
    oss << fmt;
    ((oss << " " << std::forward<Args>(args)), ...);
    return oss.str();
}

template <typename T>
auto sum(T value) -> T {
    return value;
}

template <typename T, typename... Rest>
auto sum(T first, Rest... rest) -> T {
    return first + sum(rest...);
}

template <typename... Args>
auto sumFold(Args... args) {
    return (args + ...);
}

template <typename Func, typename... Args>
auto apply(Func&& func, Args&&... args)
    -> decltype(func(std::forward<Args>(args)...)) {
    return func(std::forward<Args>(args)...);
}

template <typename... Ts>
struct Overloaded : Ts... {
    using Ts::operator()...;
};

template <typename... Ts>
Overloaded(Ts...) -> Overloaded<Ts...>;

void variadicDemo() {
    auto result = sum(1, 2, 3, 4, 5);
    auto foldResult = sumFold(1.0, 2.0, 3.0);

    auto msg = formatString("error:", 404, "not found");

    auto visitor = Overloaded{
        [](int i) { return std::to_string(i); },
        [](double d) { return std::to_string(d); },
        [](const std::string& s) { return s; },
    };
}
C++17 的折叠表达式（Fold Expressions）大幅简化了参数包展开。(args + ...) 是右折叠，(... + args) 是左折叠，(args + ... + init) 是带初始值的右折叠。


小结
    

  • C++ 模板是编译期多态，实例化生成特化代码，零运行时开销
    • 

  • 模板参数推导和 CTAD 让大多数场景无需显式指定模板参数
    • 

  • 全特化和偏特化为特定类型提供定制实现，CRTP 实现静态多态
    • 

  • 变参模板配合折叠表达式实现任意数量参数的泛型处理
    • 

  • SFINAE 和 Concepts 提供编译期类型约束，Concepts 是更清晰的现代方案
    • 

  • 模板元编程的代价是编译时间增长和错误信息复杂，需要在抽象和可读性之间平衡
    •
