序列容器

核心概念

STL（Standard Template Library）序列容器是 C++ 中最常用的数据结构集合，它们以线性顺序组织元素，支持按位置访问。主要包括 std::vector（动态数组）、std::array（固定大小数组）、std::deque（双端队列）、std::list（双向链表）和 std::forward_list（单向链表）。选择正确的序列容器是 C++ 性能优化的基础决策。

vector 深入
std::vector 是 C++ 最常用的容器，它在堆上分配一块连续内存存储元素。当容量不足时执行扩容（通常 2 倍），将所有元素移动到新内存。理解 size、capacity 和扩容策略是高效使用 vector 的关键：


#include <vector>
#include <algorithm>
#include <numeric>

void demonstrate_vector() {
    std::vector<int> vec;
    vec.reserve(1000);           // 预分配容量，避免扩容

    for (int i = 0; i < 1000; ++i) {
        vec.push_back(i);        // 不触发扩容
    }

    vec.emplace_back(42);        // 原地构造，避免临时对象

    vec.erase(
        std::remove_if(vec.begin(), vec.end(),
            [](int x) { return x % 2 == 0; }),
        vec.end()                // erase-remove 惯用法
    );

    vec.shrink_to_fit();         // 释放多余容量

    auto sum = std::accumulate(vec.begin(), vec.end(), 0);

    std::sort(vec.begin(), vec.end());
    bool found = std::binary_search(vec.begin(), vec.end(), 42);

    auto it = std::lower_bound(vec.begin(), vec.end(), 42);
}

deque 与 array
deque（双端队列）在首尾两端都支持 O(1) 插入，内部使用分段连续内存（块数组 + 固定大小的块）。array 是编译期固定大小的栈上数组，是 C 风格数组的安全替代：


#include <deque>
#include <array>

void demonstrate_deque() {
    std::deque<int> dq;
    dq.push_back(1);
    dq.push_front(0);          // O(1) 首部插入
    dq.push_back(2);

    int front = dq.front();    // 0
    int back = dq.back();      // 2
    int mid = dq[1];           // 1（随机访问）

    dq.pop_front();
    dq.pop_back();
}

void demonstrate_array() {
    std::array<int, 5> arr = {1, 2, 3, 4, 5};

    constexpr auto size = arr.size();  // 编译期已知

    int sum = 0;
    for (const auto& val : arr) {
        sum += val;
    }

    auto [a, b, c, d, e] = arr;       // 结构化绑定

    std::sort(arr.begin(), arr.end());

    constexpr std::array<int, 3> compile_time = {10, 20, 30};
}
list 与 forward_list
list 和 forward_list 基于链表实现，在任意位置插入删除都是 O(1)（已知迭代器位置），但缺乏随机访问能力且缓存不友好。在现代硬件上，由于 CPU 缓存效应，vector 在大多数场景下比 list 更快：


#include <list>
#include <forward_list>

void demonstrate_list() {
    std::list<int> lst = {3, 1, 4, 1, 5};

    lst.sort();                  // list 自带 sort（不能用 std::sort）
    lst.unique();                // 去除相邻重复
    lst.reverse();

    auto it = std::find(lst.begin(), lst.end(), 4);
    if (it != lst.end()) {
        lst.insert(it, 42);      // 在 4 前面插入 42
        lst.erase(it);           // 删除 4
    }

    std::list<int> other = {10, 20, 30};
    lst.splice(lst.begin(), other);  // O(1) 将 other 移入 lst
}

void demonstrate_forward_list() {
    std::forward_list<int> fwd = {1, 2, 3, 4, 5};
    fwd.push_front(0);
    fwd.insert_after(fwd.begin(), 42);  // 在首元素后插入
    fwd.remove_if([](int x) { return x > 3; });
}
容器适配器
STL 还提供了基于序列容器的适配器（Adapter），封装特定的数据结构语义。stack 和 queue 默认基于 deque，priority_queue 默认基于 vector：


#include <stack>
#include <queue>

void demonstrate_adapters() {
    std::stack<int> stk;
    stk.push(1);
    stk.push(2);
    stk.push(3);
    int top = stk.top();     // 3
    stk.pop();

    std::queue<int> que;
    que.push(10);
    que.push(20);
    int front = que.front();  // 10
    que.pop();

    std::priority_queue<int> max_pq;
    max_pq.push(30);
    max_pq.push(10);
    max_pq.push(20);
    int largest = max_pq.top();  // 30

    std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;
    min_pq.push(30);
    min_pq.push(10);
    int smallest = min_pq.top(); // 10
}

小结
    

  • vector 是默认的序列容器选择，连续内存带来优秀的缓存命中率和随机访问性能
    • 

  • 使用 reserve 预分配容量可避免 vector 扩容导致的迭代器失效和性能波动
    • 

  • deque 适合需要首尾双向高效插入的场景（如滑动窗口、BFS 队列）
    • 

  • array 是 C 风格数组的安全替代，大小编译期确定，可用于 constexpr 上下文
    • 

  • list/forward_list 在频繁的中间插入删除场景有理论优势，但缓存不友好限制了实际性能
    • 

  • stack/queue/priority_queue 是基于序列容器的适配器，封装特定的数据结构语义
    • 

  • 选择容器的经验法则：优先 vector → 需要首部操作用 deque → 需要稳定迭代器用 list
    •
