IO 与网络编程

核心概念

C++ 的 IO 与网络编程是系统级开发的重要组成部分。标准库通过 iostream 和 C++17 的 std::filesystem 提供了文件系统操作能力，而网络编程则依赖平台 API（POSIX sockets、Winsock）或第三方库（Asio、libcurl）。C++26 计划将 Networking TS 纳入标准，但目前 Asio 是事实标准。IO 编程的核心挑战在于高效处理阻塞操作——同步 IO 简单但阻塞线程，异步 IO 高效但编程模型复杂。

文件系统与流式 IO
C++17 的 std::filesystem 提供了跨平台的文件系统操作接口，涵盖路径操作、目录遍历、文件属性查询和文件操作。配合 fstream 的流式读写，可以实现完整的文件处理流程。


#include <filesystem>
#include <fstream>
#include <string>
#include <vector>
#include <sstream>

namespace fs = std::filesystem;

struct FileInfo {
    fs::path path;
    std::uintmax_t size;
    fs::file_time_type lastModified;
    bool isDirectory;
};

auto scanDirectory(const fs::path& root, const std::string& extension)
    -> std::vector<FileInfo> {
    std::vector<FileInfo> results;

    if (!fs::exists(root) || !fs::is_directory(root)) {
        return results;
    }

    for (const auto& entry : fs::recursive_directory_iterator(root)) {
        if (entry.is_regular_file() && entry.path().extension() == extension) {
            results.push_back({
                entry.path(),
                entry.file_size(),
                entry.last_write_time(),
                false,
            });
        }
    }

    return results;
}

auto readFileContent(const fs::path& filePath) -> std::string {
    std::ifstream file(filePath, std::ios::in | std::ios::binary);
    if (!file.is_open()) {
        throw std::runtime_error("Cannot open file: " + filePath.string());
    }

    std::ostringstream content;
    content << file.rdbuf();
    return content.str();
}

void writeFileContent(const fs::path& filePath, const std::string& content) {
    fs::create_directories(filePath.parent_path());
    std::ofstream file(filePath, std::ios::out | std::ios::binary);
    if (!file.is_open()) {
        throw std::runtime_error("Cannot create file: " + filePath.string());
    }
    file.write(content.data(), content.size());
}

auto copyWithFilter(
    const fs::path& src,
    const fs::path& dst,
    const std::vector<std::string>& excludePatterns
) -> std::size_t {
    std::size_t copiedCount = 0;

    for (const auto& entry : fs::recursive_directory_iterator(src)) {
        auto relativePath = fs::relative(entry.path(), src);
        auto targetPath = dst / relativePath;

        if (entry.is_directory()) {
            fs::create_directories(targetPath);
        } else if (entry.is_regular_file()) {
            fs::copy_file(entry.path(), targetPath, fs::copy_options::overwrite_existing);
            ++copiedCount;
        }
    }

    return copiedCount;
}
内存映射文件（mmap）是处理大文件的高效方式，通过将文件内容映射到进程的虚拟地址空间，让操作系统的页缓存管理实际的磁盘 IO，避免了显式的 read/write 系统调用开销。


Socket 网络编程
BSD Socket API 是所有网络编程的基础。尽管 API 来自 C 语言时代，理解其工作原理对于使用任何高层网络库都是必要的。


#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>
#include <string>
#include <vector>
#include <functional>

class TcpServer {
public:
    explicit TcpServer(int port) : port_(port), serverFd_(-1) {}

    void start(std::function<std::string(const std::string&)> handler) {
        serverFd_ = socket(AF_INET, SOCK_STREAM, 0);
        if (serverFd_ < 0) throw std::runtime_error("socket creation failed");

        int opt = 1;
        setsockopt(serverFd_, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

        sockaddr_in addr{};
        addr.sin_family = AF_INET;
        addr.sin_addr.s_addr = INADDR_ANY;
        addr.sin_port = htons(port_);

        if (bind(serverFd_, reinterpret_cast<sockaddr*>(&addr), sizeof(addr)) < 0) {
            throw std::runtime_error("bind failed");
        }

        if (listen(serverFd_, 128) < 0) {
            throw std::runtime_error("listen failed");
        }

        while (running_) {
            sockaddr_in clientAddr{};
            socklen_t clientLen = sizeof(clientAddr);
            int clientFd = accept(serverFd_,
                reinterpret_cast<sockaddr*>(&clientAddr), &clientLen);

            if (clientFd < 0) continue;

            char buffer[4096];
            auto bytesRead = read(clientFd, buffer, sizeof(buffer) - 1);
            if (bytesRead > 0) {
                buffer[bytesRead] = '\0';
                auto response = handler(std::string(buffer, bytesRead));
                write(clientFd, response.data(), response.size());
            }
            close(clientFd);
        }
    }

    void stop() {
        running_ = false;
        if (serverFd_ >= 0) close(serverFd_);
    }

private:
    int port_;
    int serverFd_;
    bool running_ = true;
};

异步 IO 与 Asio
Asio（Asynchronous I/O）是 C++ 最成熟的异步 IO 库，也是 C++ Networking TS 的基础。Asio 基于 Proactor 模式，通过 io_context（事件循环）调度异步操作的回调。


#include <string>
#include <functional>
#include <memory>
#include <vector>

struct AsioConfig {
    int threadPoolSize;
    int maxConnections;
    int readTimeoutMs;
    int writeTimeoutMs;
    int keepAliveSeconds;
};

struct AsyncResult {
    bool success;
    std::size_t bytesTransferred;
    std::string error;
};

class AsyncTcpConnection : public std::enable_shared_from_this<AsyncTcpConnection> {
public:
    using MessageHandler = std::function<void(const std::string&, AsyncResult)>;

    void asyncRead(MessageHandler handler) {
        auto self = shared_from_this();
        scheduleRead([self, handler](const std::string& data, AsyncResult result) {
            handler(data, result);
        });
    }

    void asyncWrite(const std::string& data, std::function<void(AsyncResult)> handler) {
        auto self = shared_from_this();
        scheduleWrite(data, [self, handler](AsyncResult result) {
            handler(result);
        });
    }

private:
    void scheduleRead(MessageHandler handler) {
        handler("", {true, 0, ""});
    }
    void scheduleWrite(const std::string& data, std::function<void(AsyncResult)> handler) {
        handler({true, data.size(), ""});
    }
};

struct HttpRequest {
    std::string method;
    std::string path;
    std::vector<std::pair<std::string, std::string>> headers;
    std::string body;
};

struct HttpResponse {
    int statusCode;
    std::vector<std::pair<std::string, std::string>> headers;
    std::string body;
};

using HttpHandler = std::function<HttpResponse(const HttpRequest&)>;
Asio 的核心抽象包括 io_context（事件循环驱动器）、strand（序列化执行器，避免并发回调间的竞争）和 timer（异步定时器）。生产环境通常使用多线程 io_context：多个线程同时调用 io_context::run()，Asio 内部保证回调的线程安全调度。


小结
    

  • C++17 filesystem 提供跨平台文件系统操作，配合 fstream 实现完整文件处理
    • 

  • BSD Socket 是所有网络编程的基础，理解其原理对使用高层库至关重要
    • 

  • Asio 基于 Proactor 模式提供高效的异步 IO 框架，是 C++ 网络编程的事实标准
    • 

  • IO 模型选择取决于并发规模：低并发用同步 IO，高并发用 epoll/kqueue + 异步 IO
    • 

  • 内存映射文件适合大文件处理，让操作系统页缓存管理实际磁盘 IO
    • 

  • C++20 协程将为异步 IO 带来更自然的编程模型，替代回调嵌套
    •
