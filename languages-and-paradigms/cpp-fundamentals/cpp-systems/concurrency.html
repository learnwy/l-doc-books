C++ 并发编程

核心概念

C++11 将并发支持提升为语言和标准库的一等特性，提供了线程、互斥量、条件变量、原子操作和内存序等完整的并发编程工具链。在此之前，C++ 程序员依赖平台特定的 API（如 POSIX threads、Win32 threads），代码既不可移植也不类型安全。现代 C++ 的并发模型建立在「线程 + 共享内存 + 同步原语」的基础上，并通过 std::async/future 和 C++20 协程提供更高层次的抽象。

线程与互斥量
std::thread 是 C++ 标准库提供的线程抽象。每个 std::thread 对象代表一个操作系统线程。线程创建后必须在销毁前调用 join（等待完成）或 detach（分离），否则析构函数会调用 std::terminate。


#include <thread>
#include <mutex>
#include <vector>
#include <numeric>

class ThreadSafeCounter {
public:
    void increment() {
        std::lock_guard<std::mutex> lock(mutex_);
        ++count_;
    }

    void add(int value) {
        std::unique_lock<std::mutex> lock(mutex_);
        count_ += value;
    }

    auto get() const -> int {
        std::lock_guard<std::mutex> lock(mutex_);
        return count_;
    }

private:
    mutable std::mutex mutex_;
    int count_ = 0;
};

auto parallelSum(const std::vector<int>& data, int numThreads) -> long long {
    std::vector<long long> partialSums(numThreads, 0);
    std::vector<std::thread> threads;

    auto chunkSize = data.size() / numThreads;

    for (int t = 0; t < numThreads; ++t) {
        auto begin = data.begin() + t * chunkSize;
        auto end = (t == numThreads - 1) ? data.end() : begin + chunkSize;

        threads.emplace_back([begin, end, &partialSums, t]() {
            partialSums[t] = std::accumulate(begin, end, 0LL);
        });
    }

    for (auto& thread : threads) {
        thread.join();
    }

    return std::accumulate(partialSums.begin(), partialSums.end(), 0LL);
}
死锁是互斥量使用中最常见的问题。当两个线程以不同顺序获取多个锁时会发生死锁。std::scoped_lock（C++17）和 std::lock（C++11）通过一次性获取多个锁的方式避免死锁。

原子操作与内存序
std::atomic 提供无锁的原子操作，适用于简单的共享状态（计数器、标志位、指针）。原子操作保证在多线程环境下的不可分割性，不需要互斥量的保护。


#include <atomic>
#include <thread>
#include <vector>

class SpinLock {
public:
    void lock() {
        while (flag_.test_and_set(std::memory_order_acquire)) {
        }
    }

    void unlock() {
        flag_.clear(std::memory_order_release);
    }

private:
    std::atomic_flag flag_ = ATOMIC_FLAG_INIT;
};

template <typename T>
class LockFreeStack {
    struct Node {
        T data;
        Node* next;
    };

public:
    void push(T value) {
        auto* newNode = new Node{std::move(value), nullptr};
        newNode->next = head_.load(std::memory_order_relaxed);
        while (!head_.compare_exchange_weak(
            newNode->next, newNode,
            std::memory_order_release, std::memory_order_relaxed)) {
        }
    }

    auto pop() -> std::optional<T> {
        auto* oldHead = head_.load(std::memory_order_acquire);
        while (oldHead && !head_.compare_exchange_weak(
            oldHead, oldHead->next,
            std::memory_order_acquire, std::memory_order_relaxed)) {
        }
        if (!oldHead) return std::nullopt;
        auto value = std::move(oldHead->data);
        delete oldHead;
        return value;
    }

private:
    std::atomic<Node*> head_{nullptr};
};

异步任务与线程池
std::async 和 std::future 提供了更高层次的异步编程抽象。std::async 启动一个异步任务（可能在新线程或延迟执行），返回 std::future 用于获取任务结果。


#include <future>
#include <vector>
#include <queue>
#include <functional>
#include <condition_variable>

class ThreadPool {
public:
    explicit ThreadPool(std::size_t numThreads) : stop_(false) {
        for (std::size_t i = 0; i < numThreads; ++i) {
            workers_.emplace_back([this] { workerLoop(); });
        }
    }

    ~ThreadPool() {
        {
            std::unique_lock<std::mutex> lock(mutex_);
            stop_ = true;
        }
        cv_.notify_all();
        for (auto& worker : workers_) {
            worker.join();
        }
    }

    template <typename Func, typename... Args>
    auto submit(Func&& func, Args&&... args)
        -> std::future<std::invoke_result_t<Func, Args...>> {
        using ReturnType = std::invoke_result_t<Func, Args...>;

        auto task = std::make_shared<std::packaged_task<ReturnType()>>(
            std::bind(std::forward<Func>(func), std::forward<Args>(args)...)
        );

        auto future = task->get_future();

        {
            std::unique_lock<std::mutex> lock(mutex_);
            tasks_.emplace([task]() { (*task)(); });
        }

        cv_.notify_one();
        return future;
    }

private:
    void workerLoop() {
        while (true) {
            std::function<void()> task;
            {
                std::unique_lock<std::mutex> lock(mutex_);
                cv_.wait(lock, [this] { return stop_ || !tasks_.empty(); });
                if (stop_ && tasks_.empty()) return;
                task = std::move(tasks_.front());
                tasks_.pop();
            }
            task();
        }
    }

    std::vector<std::thread> workers_;
    std::queue<std::function<void()>> tasks_;
    std::mutex mutex_;
    std::condition_variable cv_;
    bool stop_;
};
线程池是生产环境中管理并发任务的标准模式。预先创建固定数量的工作线程，通过任务队列接收和分发工作，避免了频繁创建销毁线程的开销。


小结
    

  • C++11 将线程、互斥量、原子操作纳入标准库，提供跨平台的并发支持
    • 

  • std::mutex 配合 lock_guard/scoped_lock 实现安全的互斥访问，避免死锁
    • 

  • std::atomic 提供无锁原子操作，内存序控制指令重排，默认使用 seq_cst
    • 

  • 线程池通过复用工作线程和任务队列实现高效的并发任务管理
    • 

  • C++20 的 std::jthread 支持自动 join 和协作取消，是 std::thread 的安全替代
    • 

  • 并发编程的核心原则：最小化共享状态、优先使用高层抽象、用工具检测竞争
    •
