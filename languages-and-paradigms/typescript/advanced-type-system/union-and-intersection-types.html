联合类型与交叉类型

问题背景

现实世界中的数据并不总是单一形态。一个 API 的返回值可能是成功的数据对象或错误信息；一个配置项可能来自多个来源，需要合并所有字段。TypeScript 的联合类型（|）和交叉类型（&）提供了灵活而安全的类型组合能力——联合类型表达"或"关系，交叉类型表达"且"关系。

基本语法
联合类型（A | B）
联合类型表示值可以是多种类型之一：


type StringOrNumber = string | number;

function formatId(id: StringOrNumber): string {
  if (typeof id === 'string') {
    return id.toUpperCase();
  }
  return id.toString().padStart(6, '0');
}

console.log(formatId('abc')); // "ABC"
console.log(formatId(42)); // "000042"
联合类型的值只能访问所有成员类型的公共属性和方法：


interface Bird {
  fly(): void;
  layEggs(): void;
}

interface Fish {
  swim(): void;
  layEggs(): void;
}

function move(animal: Bird | Fish): void {
  animal.layEggs(); // 公共方法，可以直接调用
  // animal.fly();   // 错误：类型 "Fish" 上不存在属性 "fly"
}
交叉类型（A & B）
交叉类型将多个类型合并为一个类型，结果类型拥有所有成员类型的属性：


interface HasName {
  name: string;
}

interface HasAge {
  age: number;
}

interface HasEmail {
  email: string;
}

type Person = HasName & HasAge & HasEmail;

const person: Person = {
  name: '王五',
  age: 30,
  email: 'wangwu@example.com',
};
基本类型的交叉
type StringAndNumber = string & number; // never — 不可能同时是两种原始类型

type A = { x: number } & { y: number };
// 等价于 { x: number; y: number }
进阶用法
可辨识联合（Discriminated Unions）
可辨识联合是联合类型最强大的模式——通过一个共同的字面量属性（辨识标签）区分不同的变体：


interface LoadingState {
  status: 'loading';
}

interface SuccessState<T> {
  status: 'success';
  data: T;
}

interface ErrorState {
  status: 'error';
  error: {
    code: number;
    message: string;
  };
}

type RequestState<T> = LoadingState | SuccessState<T> | ErrorState;

function renderState<T>(state: RequestState<T>): string {
  switch (state.status) {
    case 'loading':
      return '加载中...';
    case 'success':
      return `数据: ${JSON.stringify(state.data)}`;
    case 'error':
      return `错误 ${state.error.code}: ${state.error.message}`;
  }
}
交叉类型合并对象
interface Timestamps {
  createdAt: Date;
  updatedAt: Date;
}

interface Authorship {
  createdBy: string;
  updatedBy: string;
}

type Auditable = Timestamps & Authorship;

interface Article {
  id: string;
  title: string;
  content: string;
}

type AuditedArticle = Article & Auditable;

const article: AuditedArticle = {
  id: 'art-001',
  title: 'TypeScript 入门',
  content: '本文介绍 TypeScript 基础知识...',
  createdAt: new Date(),
  updatedAt: new Date(),
  createdBy: 'admin',
  updatedBy: 'admin',
};
never 与 unknown 的角色
never 是联合类型的幺元（identity），unknown 是交叉类型的幺元：


type WithNever = string | never; // string — never 被吸收
type WithUnknown = string | unknown; // unknown — unknown 吸收一切

type IntersectNever = string & never; // never — never 吸收一切
type IntersectUnknown = string & unknown; // string — unknown 被吸收
利用 never 实现穷尽检查：


type Shape =
  | { kind: 'circle'; radius: number }
  | { kind: 'rectangle'; width: number; height: number }
  | { kind: 'triangle'; base: number; height: number };

function getArea(shape: Shape): number {
  switch (shape.kind) {
    case 'circle':
      return Math.PI * shape.radius ** 2;
    case 'rectangle':
      return shape.width * shape.height;
    case 'triangle':
      return (shape.base * shape.height) / 2;
    default: {
      const _exhaustive: never = shape;
      return _exhaustive;
    }
  }
}
类型推断与约束
属性冲突处理
当交叉类型中有同名属性但类型不同时：


interface A {
  value: string;
  shared: number;
}

interface B {
  value: number;
  shared: number;
}

type AB = A & B;
// AB["value"] 的类型是 string & number = never
// AB["shared"] 的类型是 number（相同类型合并）
联合类型的分布特性
联合类型在泛型条件类型中会自动分布：


type ToArray<T> = T extends unknown ? T[] : never;

type Result = ToArray<string | number>;
// string[] | number[]（不是 (string | number)[]）
联合转交叉
type UnionToIntersection<U> = (U extends unknown ? (arg: U) => void : never) extends (arg: infer I) => void ? I : never;

type Merged = UnionToIntersection<{ a: 1 } | { b: 2 }>;
// { a: 1 } & { b: 2 }
实际应用
表单验证结果
interface ValidationSuccess {
  valid: true;
  value: string;
}

interface ValidationError {
  valid: false;
  errors: string[];
}

type ValidationResult = ValidationSuccess | ValidationError;

function validateEmail(input: string): ValidationResult {
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!input) {
    return { valid: false, errors: ['邮箱不能为空'] };
  }
  if (!emailRegex.test(input)) {
    return { valid: false, errors: ['邮箱格式不正确'] };
  }
  return { valid: true, value: input.toLowerCase() };
}

function processForm(email: string): void {
  const result = validateEmail(email);
  if (result.valid) {
    console.log(`有效邮箱: ${result.value}`);
  } else {
    console.log(`验证失败: ${result.errors.join(', ')}`);
  }
}
Mixin 模式
type Constructor<T = object> = new (...args: any[]) => T;

function WithTimestamp<TBase extends Constructor>(Base: TBase) {
  return class extends Base {
    createdAt = new Date();
    updatedAt = new Date();

    touch() {
      this.updatedAt = new Date();
    }
  };
}

function WithSerialization<TBase extends Constructor>(Base: TBase) {
  return class extends Base {
    serialize(): string {
      return JSON.stringify(this);
    }
  };
}

class BaseModel {
  constructor(public id: string) {}
}

const EnhancedModel = WithSerialization(WithTimestamp(BaseModel));
const instance = new EnhancedModel('m-001');
instance.touch();
console.log(instance.serialize());
小结
    

  • 联合类型（A | B）表示值是类型 A 或类型 B，只能访问所有成员类型的公共属性
    • 

  • 交叉类型（A & B）将多个类型合并为一个，结果类型拥有所有成员属性
    • 

  • 可辨识联合通过共同的字面量标签实现安全的类型收窄，是 TypeScript 中最常用的模式之一
    • 

  • never 是联合类型的幺元，unknown 是交叉类型的幺元，理解这两个特殊类型有助于编写正确的类型运算
    • 

  • 交叉类型中同名属性的类型也会交叉，如果不兼容则结果为 never
    • 

  • 联合类型在泛型条件类型中会自动分布，这是许多高级类型工具的基础
    • 

  • 实际应用中联合类型适合建模状态机和结果类型，交叉类型适合 Mixin 和对象扩展
    •
