泛型基础

问题背景

在编写可复用的函数、接口和类时，我们经常面临一个矛盾：代码要足够通用以处理多种类型，但又不能丢失类型信息。如果使用 any，灵活性有了，但类型安全完全丧失；如果为每种类型都写一个专用版本，代码量会急剧膨胀。泛型（Generics）正是为了解决这个问题——它允许在定义时使用类型参数作为占位符，在使用时由调用者或编译器填入具体类型，实现"一次编写，多类型复用"。

基本语法
泛型函数
泛型函数在函数名后使用尖括号 <T> 声明类型参数：


function identity<T>(value: T): T {
  return value;
}

const str = identity('hello'); // T 被推断为 "hello"，返回类型为 "hello"
const num = identity(42); // T 被推断为 42，返回类型为 42
也可以显式指定类型参数：


const result = identity<string>('hello'); // T = string，返回类型为 string
泛型箭头函数
const toArray = <T>(value: T): T[] => {
  return [value];
};

const strArr = toArray('hello'); // string[]
const numArr = toArray(42); // number[]
多个类型参数
泛型支持多个类型参数，用逗号分隔：


function pair<A, B>(first: A, second: B): [A, B] {
  return [first, second];
}

const p = pair('hello', 42); // [string, number]

function map<T, U>(items: T[], fn: (item: T) => U): U[] {
  return items.map(fn);
}

const lengths = map(['hi', 'hello'], (s) => s.length); // number[]
进阶用法
泛型接口
接口可以使用类型参数来描述通用的数据结构：


interface Container<T> {
  value: T;
  getValue(): T;
}

const strContainer: Container<string> = {
  value: 'hello',
  getValue() {
    return this.value;
  },
};

interface Repository<T> {
  findById(id: string): T | undefined;
  findAll(): T[];
  save(item: T): void;
}
泛型类
类也可以使用类型参数：


class Stack<T> {
  private items: T[] = [];

  push(item: T): void {
    this.items.push(item);
  }

  pop(): T | undefined {
    return this.items.pop();
  }

  peek(): T | undefined {
    return this.items[this.items.length - 1];
  }

  get size(): number {
    return this.items.length;
  }
}

const numStack = new Stack<number>();
numStack.push(1);
numStack.push(2);
const top = numStack.pop(); // number | undefined

const strStack = new Stack<string>();
strStack.push('hello');
泛型类的静态成员不能使用类的类型参数：


class Box<T> {
  static defaultValue: T; // ❌ 静态成员不能引用类类型参数
  content: T; // ✅

  constructor(content: T) {
    this.content = content;
  }
}
泛型类型别名
type 也支持泛型参数：


type Result<T> =
  | {
      success: true;
      data: T;
    }
  | {
      success: false;
      error: string;
    };

const ok: Result<number> = { success: true, data: 42 };
const err: Result<number> = { success: false, error: 'Not found' };

type Nullable<T> = T | null;
type ReadonlyRecord<K extends string, V> = Readonly<Record<K, V>>;
类型推断与约束
从参数推断类型
TypeScript 编译器会根据传入的参数自动推断类型参数，大多数情况下不需要显式指定：


function first<T>(arr: T[]): T | undefined {
  return arr[0];
}

const n = first([1, 2, 3]); // T 推断为 number
const s = first(['a', 'b']); // T 推断为 string
const m = first([1, 'a', true]); // T 推断为 string | number | boolean
类型参数默认值
类型参数可以设置默认值，当调用者不指定且无法推断时使用：


interface ApiResponse<T = unknown> {
  code: number;
  message: string;
  data: T;
}

const res1: ApiResponse<string> = {
  code: 200,
  message: 'OK',
  data: 'hello',
};

const res2: ApiResponse = {
  code: 200,
  message: 'OK',
  data: { anything: true }, // T 默认为 unknown
};
默认值的规则与函数参数类似——有默认值的类型参数必须放在没有默认值的之后：


type Entry<K extends string, V = unknown> = {
  key: K;
  value: V;
};

const e1: Entry<'name', string> = { key: 'name', value: 'Alice' };
const e2: Entry<'count'> = { key: 'count', value: 42 }; // V 使用默认值 unknown
实际应用
通用数据获取函数
async function fetchData<T>(url: string): Promise<T> {
  const response = await fetch(url);
  const data: T = await response.json();
  return data;
}

interface User {
  id: string;
  name: string;
}

const user = await fetchData<User>('/api/user/1');
console.log(user.name);
事件系统
type EventMap = {
  login: { userId: string };
  logout: { reason: string };
  error: { code: number; message: string };
};

class TypedEmitter<Events extends Record<string, unknown>> {
  private handlers = new Map<string, Array<(data: unknown) => void>>();

  on<K extends keyof Events>(event: K, handler: (data: Events[K]) => void): void {
    const list = this.handlers.get(event as string) ?? [];
    list.push(handler as (data: unknown) => void);
    this.handlers.set(event as string, list);
  }

  emit<K extends keyof Events>(event: K, data: Events[K]): void {
    const list = this.handlers.get(event as string) ?? [];
    list.forEach((handler) => handler(data));
  }
}

const emitter = new TypedEmitter<EventMap>();
emitter.on('login', (data) => {
  console.log(data.userId); // ✅ 类型安全
});
emitter.emit('login', { userId: '123' }); // ✅
emitter.emit('login', { reason: 'test' }); // ❌ 类型不匹配
工具函数组合
function pipe<A, B>(fn1: (a: A) => B): (a: A) => B;
function pipe<A, B, C>(fn1: (a: A) => B, fn2: (b: B) => C): (a: A) => C;
function pipe<A, B, C, D>(fn1: (a: A) => B, fn2: (b: B) => C, fn3: (c: C) => D): (a: A) => D;
function pipe(...fns: Array<(arg: unknown) => unknown>): (arg: unknown) => unknown {
  return (arg) => fns.reduce((acc, fn) => fn(acc), arg);
}

const transform = pipe(
  (s: string) => s.length,
  (n: number) => n * 2,
  (n: number) => `Result: ${n}`,
);

const output = transform('hello'); // "Result: 10"
小结
    

  • 泛型通过类型参数实现"一次编写，多类型复用"，兼顾灵活性和类型安全。
    • 

  • 泛型可应用于函数、接口、类和类型别名。
    • 

  • TypeScript 能从函数参数自动推断类型参数，大多数情况下无需显式指定。
    • 

  • 类型参数支持默认值，有默认值的参数必须排在无默认值的之后。
    • 

  • 泛型是构建可复用工具函数、数据结构和类型安全 API 的核心机制。
    •
