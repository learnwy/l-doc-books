函数类型与重载

问题背景

JavaScript 中的函数极其灵活——同一个函数可以接受不同数量和类型的参数，返回不同类型的值。这种灵活性在开发时缺乏约束，容易引发运行时错误。TypeScript 通过函数类型表达式、调用签名和函数重载等机制，为函数建立起精确的类型契约，在编译期捕获参数和返回值的类型错误。

基本语法
函数类型表达式
函数类型使用箭头语法 (params) => ReturnType 表示：


type Greeter = (name: string) => string;

const greet: Greeter = (name) => {
  return `Hello, ${name}!`;
};

type MathOp = (a: number, b: number) => number;

const add: MathOp = (a, b) => a + b;
const multiply: MathOp = (a, b) => a * b;
调用签名（Call Signature）
当函数还需要附加属性时，使用对象类型中的调用签名：


type Logger = {
  (message: string): void;
  level: string;
};

const logger: Logger = Object.assign(
  (message: string) => {
    console.log(`[${logger.level}] ${message}`);
  },
  { level: 'info' },
);

logger('Server started'); // [info] Server started
logger.level = 'debug';
参数类型
可选参数使用 ? 标记：


function greet(name: string, greeting?: string): string {
  return `${greeting ?? 'Hello'}, ${name}!`;
}

greet('Alice'); // "Hello, Alice!"
greet('Alice', 'Hi'); // "Hi, Alice!"
默认参数自动推断类型，且自动变为可选：


function createUser(name: string, age: number = 18): { name: string; age: number } {
  return { name, age };
}

createUser('Alice'); // age 默认为 18
createUser('Bob', 25);
剩余参数使用展开语法：


function sum(...nums: number[]): number {
  return nums.reduce((acc, n) => acc + n, 0);
}

sum(1, 2, 3); // 6
sum(1, 2, 3, 4); // 10
剩余参数也支持元组类型：


function createEntry(...args: [key: string, value: number, optional?: boolean]): void {
  const [key, value, optional] = args;
  console.log(key, value, optional);
}
进阶用法
函数重载
当一个函数根据不同参数类型返回不同类型时，可以使用重载签名来精确描述每种调用方式：


function parseInput(input: string): string[];
function parseInput(input: number): number[];
function parseInput(input: string | number): string[] | number[] {
  if (typeof input === 'string') {
    return input.split(',');
  }
  return Array.from({ length: input }, (_, i) => i);
}

const strs = parseInput('a,b,c'); // string[]
const nums = parseInput(5); // number[]
重载由两部分组成：


    

  1. 重载签名（一个或多个）——对外暴露的调用方式，调用者只能看到这些签名
    2. 

  2. 实现签名（唯一一个）——实际的函数体，必须兼容所有重载签名
    3. 



重载签名的规则
// ✅ 重载签名从具体到宽泛排列
function format(value: Date): string;
function format(value: string): string;
function format(value: Date | string): string {
  if (value instanceof Date) {
    return value.toISOString();
  }
  return value.trim();
}

// ❌ 实现签名不能直接被调用
format(42); // 错误：没有匹配 number 的重载签名
this 参数类型
TypeScript 允许为函数声明一个特殊的 this 参数，约束函数被调用时的 this 上下文：


interface Button {
  label: string;
  onClick(this: Button): void;
}

const button: Button = {
  label: 'Submit',
  onClick() {
    console.log(`Clicked: ${this.label}`);
  },
};

button.onClick(); // ✅

const detached = button.onClick;
detached(); // ❌ 'void' 类型的 'this' 不能赋值给 'Button' 类型的 'this'
this 参数在编译后会被擦除，不占用实际参数位置。


类型推断与约束
返回类型推断
TypeScript 会根据函数体中的 return 语句自动推断返回类型：


function add(a: number, b: number) {
  return a + b; // 返回类型推断为 number
}

function getInfo(name: string) {
  return {
    name,
    length: name.length,
  }; // 返回类型推断为 { name: string; length: number }
}
推荐为公共 API 函数显式标注返回类型，防止实现变更意外改变返回类型：


function fetchUser(id: string): Promise<{ name: string; age: number }> {
  return fetch(`/api/users/${id}`).then((res) => res.json());
}
函数类型兼容性
函数类型遵循参数逆变、返回值协变的兼容规则：


type Handler = (event: MouseEvent) => void;

const handler: Handler = (event: Event) => {
  // ❌ 在严格模式下，Event 不能赋值给 MouseEvent（参数逆变）
  console.log(event);
};

type Factory = () => HTMLElement;

const factory: Factory = (): HTMLDivElement => {
  // ✅ HTMLDivElement 是 HTMLElement 的子类型（返回值协变）
  return document.createElement('div');
};
重载 vs 联合类型
很多场景下，联合类型参数比重载更简洁：


// 重载写法 — 当返回类型依赖参数类型时使用
function process(input: string): string;
function process(input: number): number;
function process(input: string | number): string | number {
  return typeof input === 'string' ? input.trim() : input * 2;
}

// 联合类型写法 — 当返回类型不依赖参数类型时优先使用
function log(value: string | number): void {
  console.log(value);
}
实际应用
事件处理器类型
type EventHandler<E extends Event = Event> = (event: E) => void;

interface EventEmitter {
  on(event: 'click', handler: EventHandler<MouseEvent>): void;
  on(event: 'keydown', handler: EventHandler<KeyboardEvent>): void;
  on(event: string, handler: EventHandler): void;
}
工厂函数模式
interface Config {
  host: string;
  port: number;
}

type CreateServer = {
  (config: Config): { start(): void };
  (port: number): { start(): void };
};

const createServer: CreateServer = (configOrPort: Config | number) => {
  const config: Config = typeof configOrPort === 'number' ? { host: 'localhost', port: configOrPort } : configOrPort;

  return {
    start() {
      console.log(`Server running at ${config.host}:${config.port}`);
    },
  };
};

createServer({ host: '0.0.0.0', port: 3000 }).start();
createServer(8080).start();
构造签名
使用 new 关键字定义构造签名：


interface DateConstructor {
  new (): Date;
  new (value: number): Date;
  new (dateString: string): Date;
}
小结
    

  • 函数类型表达式使用 (params) => ReturnType 语法，调用签名用于函数附带属性的场景。
    • 

  • 可选参数、默认参数、剩余参数提供了灵活的参数定义方式。
    • 

  • 函数重载通过多个重载签名 + 一个实现签名，精确描述参数类型到返回类型的映射。
    • 

  • this 参数可以约束函数的调用上下文，编译后被擦除。
    • 

  • 返回类型依赖参数类型时用重载，否则优先使用联合类型参数。
    •
