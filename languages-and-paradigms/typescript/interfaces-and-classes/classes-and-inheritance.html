类与继承

核心概念

JavaScript 的 class 语法在 ES2015 中引入，提供了基于原型继承的语法糖。但原生 JavaScript 类缺乏类型检查——构造函数参数没有类型约束，属性可以随意赋值为任意类型，方法签名也无法保证一致性。TypeScript 在类语法之上增加了完整的类型系统支持，使面向对象编程更安全、更可预测。

机制 语法 作用 是否提供实现
参数属性 构造函数参数前加修饰符 声明并赋值实例属性 是（自动赋值）
继承 extends 复用父类实现，可重写方法 是
实现接口 implements 强制类满足契约 否（只做类型检查）
方法重写 override（配合 noImplicitOverride） 明确标记重写，防止拼写错误 是
静态成员 static 属于类本身而非实例 是

基本语法

类声明与类型标注

class Point {
  x: number;
  y: number;

  constructor(x: number, y: number) {
    this.x = x;
    this.y = y;
  }

  distanceTo(other: Point): number {
    const dx = this.x - other.x;
    const dy = this.y - other.y;
    return Math.sqrt(dx * dx + dy * dy);
  }

  toString(): string {
    return `(${this.x}, ${this.y})`;
  }
}

const p1 = new Point(0, 0);
const p2 = new Point(3, 4);
console.log(p1.distanceTo(p2)); // 5

构造函数参数属性

TypeScript 提供了参数属性简写语法，在构造函数参数前加修饰符即可自动声明并赋值：

class User {
  constructor(
    public readonly id: string,
    public name: string,
    public email: string,
    private password: string,
  ) {}

  checkPassword(input: string): boolean {
    return this.password === input;
  }
}

const user = new User('u-001', '张三', 'zhangsan@example.com', 'secret');
console.log(user.name); // "张三"
// console.log(user.password); // 错误：属性 "password" 为私有属性

进阶用法

继承（extends）

class Shape {
  constructor(public readonly color: string) {}

  area(): number {
    return 0;
  }

  describe(): string {
    return `${this.color} 形状，面积 = ${this.area().toFixed(2)}`;
  }
}

class Circle extends Shape {
  constructor(
    color: string,
    public readonly radius: number,
  ) {
    super(color);
  }

  area(): number {
    return Math.PI * this.radius ** 2;
  }
}

class Rectangle extends Shape {
  constructor(
    color: string,
    public readonly width: number,
    public readonly height: number,
  ) {
    super(color);
  }

  area(): number {
    return this.width * this.height;
  }
}

const shapes: Shape[] = [new Circle('红色', 5), new Rectangle('蓝色', 4, 6)];

shapes.forEach((s) => console.log(s.describe()));

实现接口（implements）

interface Loggable {
  log(message: string): void;
}

interface Disposable {
  dispose(): void;
}

class FileLogger implements Loggable, Disposable {
  private buffer: string[] = [];

  log(message: string): void {
    this.buffer.push(`[${new Date().toISOString()}] ${message}`);
  }

  flush(): string[] {
    const logs = [...this.buffer];
    this.buffer = [];
    return logs;
  }

  dispose(): void {
    this.flush();
    console.log('日志资源已释放');
  }
}

implements 只做类型检查，不提供任何实现。类必须自行实现接口中声明的所有成员。

方法重写

子类可以重写父类方法。在 strict 模式下配合 noImplicitOverride 选项，可以使用 override 关键字明确标记：

class BaseParser {
  parse(input: string): string[] {
    return input.split(',');
  }

  validate(input: string): boolean {
    return input.length > 0;
  }
}

class JsonParser extends BaseParser {
  override parse(input: string): string[] {
    const parsed: unknown = JSON.parse(input);
    if (Array.isArray(parsed)) {
      return parsed.map(String);
    }
    return [String(parsed)];
  }

  override validate(input: string): boolean {
    try {
      JSON.parse(input);
      return true;
    } catch {
      return false;
    }
  }
}

静态成员

class IdGenerator {
  private static counter = 0;

  static next(): string {
    return `id_${++IdGenerator.counter}`;
  }

  static reset(): void {
    IdGenerator.counter = 0;
  }
}

console.log(IdGenerator.next()); // "id_1"
console.log(IdGenerator.next()); // "id_2"

类型推断与约束

结构化类型 vs 名义类型

TypeScript 使用结构化类型系统（鸭子类型）：只要结构匹配，两个不同名的类型也可以互相赋值。

class Email {
  constructor(public value: string) {}
}

class Username {
  constructor(public value: string) {}
}

function sendEmail(email: Email): void {
  console.log(`发送至: ${email.value}`);
}

const username = new Username('zhangsan');
sendEmail(username); // TypeScript 不报错！结构相同

class BrandedEmail {
  readonly __brand: unique symbol = Symbol() as any;
  constructor(public value: string) {}
}

类类型与实例类型

interface ClockConstructor {
  new (hour: number, minute: number): ClockInstance;
}

interface ClockInstance {
  tick(): void;
}

function createClock(Ctor: ClockConstructor, hour: number, minute: number): ClockInstance {
  return new Ctor(hour, minute);
}

class DigitalClock implements ClockInstance {
  constructor(
    private hour: number,
    private minute: number,
  ) {}

  tick(): void {
    console.log(`${this.hour}:${String(this.minute).padStart(2, '0')}`);
  }
}

const clock = createClock(DigitalClock, 10, 30);
clock.tick(); // "10:30"

实际应用

带类型安全的事件发射器

interface EventMap {
  connect: { url: string };
  disconnect: { reason: string };
  message: { content: string; sender: string };
}

class TypedEmitter<T extends Record<string, unknown>> {
  private listeners = new Map<keyof T, Set<(data: any) => void>>();

  on<K extends keyof T>(event: K, handler: (data: T[K]) => void): this {
    if (!this.listeners.has(event)) {
      this.listeners.set(event, new Set());
    }
    this.listeners.get(event)!.add(handler);
    return this;
  }

  emit<K extends keyof T>(event: K, data: T[K]): void {
    this.listeners.get(event)?.forEach((handler) => handler(data));
  }

  off<K extends keyof T>(event: K, handler: (data: T[K]) => void): void {
    this.listeners.get(event)?.delete(handler);
  }
}

const emitter = new TypedEmitter<EventMap>();

emitter.on('connect', (data) => {
  console.log(`已连接到 ${data.url}`);
});

emitter.on('message', (data) => {
  console.log(`${data.sender}: ${data.content}`);
});

emitter.emit('connect', { url: 'wss://example.com' });
emitter.emit('message', { content: '你好', sender: '系统' });

泛型仓储模式

interface Entity {
  id: string;
}

class InMemoryRepository<T extends Entity> {
  private store = new Map<string, T>();

  save(entity: T): T {
    this.store.set(entity.id, { ...entity });
    return entity;
  }

  findById(id: string): T | undefined {
    const entity = this.store.get(id);
    return entity ? { ...entity } : undefined;
  }

  findAll(): T[] {
    return Array.from(this.store.values()).map((e) => ({ ...e }));
  }

  deleteById(id: string): boolean {
    return this.store.delete(id);
  }

  count(): number {
    return this.store.size;
  }
}

interface Product extends Entity {
  name: string;
  price: number;
}

const repo = new InMemoryRepository<Product>();
repo.save({ id: 'p-001', name: 'TypeScript 实战', price: 59.9 });
console.log(repo.findById('p-001')?.name); // "TypeScript 实战"

小结

  • TypeScript 为 class 提供了完整的类型标注支持，包括属性类型、方法签名和返回值
  • 参数属性简写（public/private/protected/readonly + 参数）减少样板代码
  • extends 实现类的继承，implements 实现接口契约，两者可以组合使用
  • override 关键字配合 noImplicitOverride 编译选项，防止意外重写或拼写错误
  • 静态成员属于类本身，不属于实例，适合工厂方法、计数器等场景
  • TypeScript 的结构化类型系统意味着类型兼容性取决于结构而非名称，需要留意由此带来的隐式兼容
  • 泛型类（如 TypedEmitter<T>、InMemoryRepository<T>）是构建可复用基础设施的核心模式
