抽象类与访问修饰符

问题背景

在设计类层次结构时，常常遇到这样的需求：某个基类定义了通用行为的框架，但部分细节必须由子类提供。同时，类的内部实现细节不应暴露给外部调用者。TypeScript 提供了抽象类（abstract）和访问修饰符（public/private/protected）来解决这两个问题，让面向对象设计更加严谨。

基本语法
抽象类与抽象方法
抽象类使用 abstract 关键字声明，不能直接实例化。抽象方法没有方法体，子类必须提供实现：


abstract class Notification {
  constructor(
    protected readonly recipient: string,
    protected readonly content: string,
  ) {}

  abstract send(): Promise<boolean>;

  formatContent(): string {
    return `[通知] ${this.content}`;
  }

  async sendWithRetry(maxRetries: number = 3): Promise<boolean> {
    for (let i = 0; i < maxRetries; i++) {
      const success = await this.send();
      if (success) return true;
    }
    return false;
  }
}

class EmailNotification extends Notification {
  async send(): Promise<boolean> {
    console.log(`发送邮件到 ${this.recipient}: ${this.formatContent()}`);
    return true;
  }
}

class SmsNotification extends Notification {
  async send(): Promise<boolean> {
    console.log(`发送短信到 ${this.recipient}: ${this.formatContent()}`);
    return true;
  }
}

// const n = new Notification("test", "hello"); // 错误：无法创建抽象类的实例
const email = new EmailNotification('user@example.com', '验证码: 1234');
await email.sendWithRetry();
访问修饰符
class BankAccount {
  public readonly accountNumber: string;
  protected balance: number;
  private transactionLog: string[];

  constructor(accountNumber: string, initialBalance: number) {
    this.accountNumber = accountNumber;
    this.balance = initialBalance;
    this.transactionLog = [];
  }

  public getBalance(): number {
    return this.balance;
  }

  public deposit(amount: number): void {
    this.validateAmount(amount);
    this.balance += amount;
    this.recordTransaction(`存入 ${amount}`);
  }

  public withdraw(amount: number): void {
    this.validateAmount(amount);
    if (amount > this.balance) {
      throw new Error('余额不足');
    }
    this.balance -= amount;
    this.recordTransaction(`取出 ${amount}`);
  }

  private validateAmount(amount: number): void {
    if (amount <= 0) {
      throw new Error('金额必须为正数');
    }
  }

  private recordTransaction(description: string): void {
    this.transactionLog.push(`${new Date().toISOString()}: ${description}`);
  }
}
ECMAScript 私有字段（#）
TypeScript 还支持 ECMAScript 原生的 # 私有字段，它在运行时也是真正私有的：


class SecureVault {
  #secret: string;
  #accessCount: number = 0;

  constructor(secret: string) {
    this.#secret = secret;
  }

  getSecret(passphrase: string): string | null {
    if (passphrase === 'open-sesame') {
      this.#accessCount++;
      return this.#secret;
    }
    return null;
  }

  get accessCount(): number {
    return this.#accessCount;
  }
}

const vault = new SecureVault('机密数据');
// console.log(vault.#secret); // 语法错误：私有字段无法在类外部访问
console.log(vault.getSecret('open-sesame')); // "机密数据"
进阶用法
readonly 修饰符
readonly 确保属性只能在声明或构造函数中赋值：


class ImmutablePoint {
  constructor(
    readonly x: number,
    readonly y: number,
    readonly label: string = 'origin',
  ) {}

  translate(dx: number, dy: number): ImmutablePoint {
    return new ImmutablePoint(this.x + dx, this.y + dy, this.label);
  }
}

const origin = new ImmutablePoint(0, 0);
// origin.x = 10; // 错误：无法分配到 "x" ，因为它是只读属性
const moved = origin.translate(3, 4);
参数属性简写
参数属性将声明和赋值合并到构造函数参数中：


class TaskItem {
  constructor(
    public readonly id: string,
    public title: string,
    public description: string = '',
    private _completed: boolean = false,
    protected priority: number = 0,
  ) {}

  get completed(): boolean {
    return this._completed;
  }

  complete(): void {
    this._completed = true;
  }
}
等价于手动声明属性并在构造函数中赋值，但代码量减少了近一半。


protected 的继承场景
abstract class DataStore<T> {
  protected items: T[] = [];

  protected findIndex(predicate: (item: T) => boolean): number {
    return this.items.findIndex(predicate);
  }

  abstract add(item: T): void;
  abstract remove(item: T): boolean;

  getAll(): readonly T[] {
    return [...this.items];
  }

  get size(): number {
    return this.items.length;
  }
}

class UniqueStore<T extends { id: string }> extends DataStore<T> {
  add(item: T): void {
    const existingIndex = this.findIndex((i) => i.id === item.id);
    if (existingIndex === -1) {
      this.items.push(item);
    } else {
      this.items[existingIndex] = item;
    }
  }

  remove(item: T): boolean {
    const index = this.findIndex((i) => i.id === item.id);
    if (index !== -1) {
      this.items.splice(index, 1);
      return true;
    }
    return false;
  }
}

模板方法模式
abstract class DataProcessor<TInput, TOutput> {
  async process(raw: TInput): Promise<TOutput> {
    const validated = this.validate(raw);
    const transformed = this.transform(validated);
    await this.save(transformed);
    return transformed;
  }

  protected abstract validate(input: TInput): TInput;
  protected abstract transform(input: TInput): TOutput;
  protected abstract save(output: TOutput): Promise<void>;
}

interface RawOrder {
  productId: string;
  quantity: string;
  price: string;
}

interface ProcessedOrder {
  productId: string;
  quantity: number;
  totalPrice: number;
  processedAt: Date;
}

class OrderProcessor extends DataProcessor<RawOrder, ProcessedOrder> {
  protected validate(input: RawOrder): RawOrder {
    if (!input.productId || !input.quantity || !input.price) {
      throw new Error('订单数据不完整');
    }
    return input;
  }

  protected transform(input: RawOrder): ProcessedOrder {
    const quantity = parseInt(input.quantity, 10);
    const price = parseFloat(input.price);
    return {
      productId: input.productId,
      quantity,
      totalPrice: quantity * price,
      processedAt: new Date(),
    };
  }

  protected async save(output: ProcessedOrder): Promise<void> {
    console.log(`订单已处理: ${output.productId}, 总价 ${output.totalPrice}`);
  }
}

const processor = new OrderProcessor();
await processor.process({
  productId: 'SKU-001',
  quantity: '3',
  price: '29.9',
});
构建器模式
class QueryBuilder {
  #table: string = '';
  #conditions: string[] = [];
  #orderBy: string[] = [];
  #limitValue: number | null = null;

  from(table: string): this {
    this.#table = table;
    return this;
  }

  where(condition: string): this {
    this.#conditions.push(condition);
    return this;
  }

  order(field: string, direction: 'ASC' | 'DESC' = 'ASC'): this {
    this.#orderBy.push(`${field} ${direction}`);
    return this;
  }

  limit(count: number): this {
    this.#limitValue = count;
    return this;
  }

  build(): string {
    let query = `SELECT * FROM ${this.#table}`;
    if (this.#conditions.length > 0) {
      query += ` WHERE ${this.#conditions.join(' AND ')}`;
    }
    if (this.#orderBy.length > 0) {
      query += ` ORDER BY ${this.#orderBy.join(', ')}`;
    }
    if (this.#limitValue !== null) {
      query += ` LIMIT ${this.#limitValue}`;
    }
    return query;
  }
}

const query = new QueryBuilder().from('users').where('age > 18').where('active = true').order('name').limit(10).build();

console.log(query);
// SELECT * FROM users WHERE age > 18 AND active = true ORDER BY name ASC LIMIT 10
小结
    

  • 抽象类使用 abstract 声明，不能直接实例化，可以包含抽象方法和具体方法
    • 

  • 抽象方法没有方法体，子类必须提供实现；具体方法提供默认行为，子类可选择重写
    • 

  • public（默认）、protected、private 三个访问修饰符控制成员的可见性范围
    • 

  • # 私有字段提供运行时级别的私有性，比 private 关键字更严格
    • 

  • readonly 修饰符确保属性初始化后不可更改，有助于构建不可变对象
    • 

  • 参数属性简写大幅减少样板代码，将属性声明、参数声明和赋值合为一步
    • 

  • 选择抽象类还是接口：需要默认实现或状态字段时用抽象类，纯契约或需要多继承时用接口
    •
