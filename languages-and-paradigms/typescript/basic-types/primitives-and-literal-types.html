原始类型与字面量类型

核心概念

TypeScript 的类型系统以 JavaScript 的七种原始类型为基础，同时引入了字面量类型机制，可以将类型精确到某个具体的值。原始类型描述值的"种类"，字面量类型描述值的"具体内容"。两者结合，构成了类型系统从宽泛到精确的完整光谱。

基本语法
七种原始类型
TypeScript 为 JavaScript 的每一种原始值都提供了对应的类型关键字：


const name: string = 'TypeScript';
const version: number = 5.4;
const isStable: boolean = true;
const nothing: null = null;
const notDefined: undefined = undefined;
const id: symbol = Symbol('id');
const bigNum: bigint = 9007199254740991n;


注意：string、number、boolean 是小写的原始类型。String、Number、Boolean 是包装对象类型，两者不同，永远不要使用包装对象类型作为注解。




// ❌ 错误：使用了包装对象类型
const bad: String = 'hello';

// ✅ 正确：使用原始类型
const good: string = 'hello';
null 与 undefined
在严格模式（strictNullChecks: true）下，null 和 undefined 是独立的类型，不能赋值给其他类型：


let value: string;
value = 'hello'; // ✅
value = null; // ❌ 严格模式下报错
value = undefined; // ❌ 严格模式下报错

let nullable: string | null = null; // ✅ 需要联合类型
symbol 与 unique symbol
symbol 类型表示所有 Symbol 值。unique symbol 是 symbol 的子类型，只能用 const 声明，用于需要唯一标识的场景：


const sym1: unique symbol = Symbol('key');
const sym2: unique symbol = Symbol('key');

// sym1 和 sym2 是不同的 unique symbol 类型
type Check = typeof sym1 extends typeof sym2 ? true : false; // false
字面量类型
字面量类型将类型收窄为某个特定的值。TypeScript 支持字符串字面量、数字字面量和布尔字面量三种：


type Direction = 'north' | 'south' | 'east' | 'west';
type DiceRoll = 1 | 2 | 3 | 4 | 5 | 6;
type Switch = true | false;

function move(direction: Direction): void {
  console.log(`Moving ${direction}`);
}

move('north'); // ✅
move('up'); // ❌ 类型 '"up"' 不能赋值给类型 'Direction'
字面量类型单独使用意义不大，但与联合类型结合后，可以精确限定参数的可选范围，替代传统枚举或魔法字符串。


模板字面量类型
TypeScript 支持通过模板字符串语法组合字面量类型，生成新的字符串字面量联合：


type Color = 'red' | 'blue';
type Size = 'small' | 'large';
type Style = `${Size}-${Color}`;
// 等价于 "small-red" | "small-blue" | "large-red" | "large-blue"

type EventName = `on${Capitalize<'click' | 'focus'>}`;
// 等价于 "onClick" | "onFocus"
类型推断行为
类型拓宽（Type Widening）
用 let 声明变量时，字面量值会被拓宽为对应的基础类型：


let str = 'hello'; // string（不是 "hello"）
let num = 42; // number（不是 42）
let bool = true; // boolean（不是 true）

const constStr = 'hello'; // "hello"（字面量类型，不拓宽）
对象属性也会拓宽：


const config = {
  url: 'https://api.example.com',
  method: 'GET',
};
// config.method 的类型是 string，而非 "GET"
as const 断言
as const（const 断言）可以阻止类型拓宽，将值推断为最窄的字面量类型，同时标记为 readonly：


const config = {
  url: 'https://api.example.com',
  method: 'GET',
} as const;
// config.method 的类型是 "GET"
// config 的类型是 { readonly url: "https://api.example.com"; readonly method: "GET" }

const colors = ['red', 'green', 'blue'] as const;
// 类型为 readonly ["red", "green", "blue"]
类型收窄（Type Narrowing）
字面量类型与联合类型搭配时，可以通过条件检查收窄类型：


type Status = 'loading' | 'success' | 'error';

function handleStatus(status: Status): string {
  switch (status) {
    case 'loading':
      return '加载中...';
    case 'success':
      return '加载成功';
    case 'error':
      return '加载失败';
  }
}
常见误区
误区一：字面量联合与枚举混淆
字面量联合类型和枚举都能表示有限集合，但语义不同：


// 字面量联合 — 编译后完全消失
type Theme = 'light' | 'dark';

// 枚举 — 编译后生成运行时对象
enum ThemeEnum {
  Light = 'light',
  Dark = 'dark',
}
字面量联合更轻量，适合纯类型约束；枚举适合需要运行时遍历或反向映射的场景。


误区二：忽略 strictNullChecks
关闭 strictNullChecks 后，null 和 undefined 可以赋值给任何类型，这会掩盖大量潜在错误：


// strictNullChecks: false 时不报错，但运行时可能崩溃
function getLength(s: string): number {
  return s.length; // 如果 s 是 null，运行时抛出 TypeError
}
误区三：混淆 as const 与类型注解
as const 是从值推断最窄类型，而注解是从类型约束值。两者方向相反：


// as const：从值到类型
const a = 'hello' as const; // 类型为 "hello"

// 类型注解：从类型到值
const b: 'hello' = 'hello'; // 类型为 "hello"，但注解更冗长

与 JavaScript 的关系
JavaScript 没有字面量类型的概念——typeof "hello" 在运行时始终返回 "string"。TypeScript 的字面量类型完全是编译期的概念，用于在开发阶段捕获错误：


type HttpMethod = 'GET' | 'POST' | 'PUT' | 'DELETE';

function request(url: string, method: HttpMethod): void {
  // ...
}

// TypeScript 编译期就能捕获拼写错误
request('/api', 'PSOT'); // ❌ 类型 '"PSOT"' 不能赋值给类型 'HttpMethod'
编译后，所有字面量类型信息被擦除，JavaScript 中只是普通的字符串比较。


小结
    

  • TypeScript 支持七种原始类型：string、number、boolean、null、undefined、symbol、bigint。
    • 

  • 字面量类型将类型精确到具体值，与联合类型结合可以替代枚举或魔法字符串。
    • 

  • 模板字面量类型可以通过模板语法组合生成新的字符串字面量联合。
    • 

  • as const 断言阻止类型拓宽，保留最窄的字面量类型并标记 readonly。
    • 

  • 始终启用 strictNullChecks，让 null 和 undefined 成为独立类型。
