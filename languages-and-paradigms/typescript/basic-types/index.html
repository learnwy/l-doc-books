基础类型 简介

基础类型是学习 TypeScript 的第一步，也是整个类型系统的基石。理解这些核心概念，将为后续掌握泛型、高级类型等进阶内容奠定坚实的基础。本章将带你全面认识 TypeScript 的基本类型体系，从最基础的类型注解开始，逐步深入到各种具体的类型分类。

本章第一节介绍类型注解与类型推断。类型注解是开发者主动为变量、参数和返回值标注类型的方式，而类型推断则是 TypeScript 编译器根据上下文自动推导类型的能力。掌握两者之间的平衡——何时需要显式注解、何时可以依赖推断——是编写简洁且安全的 TypeScript 代码的关键。

第二节聚焦原始类型与字面量类型。TypeScript 继承了 JavaScript 的原始类型，包括 string、number、boolean 等，同时引入了字面量类型的概念，允许你将变量约束为特定的值而非宽泛的类型。字面量类型与联合类型的组合是构建精确类型定义的常用手段。

第三节探讨数组、元组与枚举。数组类型提供了对集合元素的类型约束，元组则进一步允许你定义固定长度和每个位置类型不同的数组结构。枚举为一组相关常量提供了语义清晰的命名方式，在状态管理和配置项定义中尤为实用。

第四节深入分析 any、unknown、never 和 void 这四个特殊类型。它们各自在类型系统中扮演着独特的角色——any 放弃类型检查，unknown 提供安全的未知类型容器，never 表示永不发生的情况，void 标记无返回值的函数。正确理解和使用这些特殊类型，是区分 TypeScript 初学者和熟练开发者的重要标志。

通过本章的学习，你将建立起对 TypeScript 类型系统的整体认知，为后续章节的进阶探索做好准备。
