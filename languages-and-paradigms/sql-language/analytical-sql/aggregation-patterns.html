聚合分析模式

核心概念

SQL 聚合函数是数据分析的基础构建块，从简单的 COUNT/SUM 到复杂的条件聚合、分组集合和多维分析。掌握聚合模式意味着能够用一条 SQL 语句完成原本需要多次查询和程序处理的统计分析任务。高级聚合超越了基本的 GROUP BY，通过 GROUPING SETS、ROLLUP、CUBE 等扩展实现多维度交叉分析。

条件聚合与行转列
条件聚合是 SQL 中最强大的分析技巧之一，通过 CASE WHEN 表达式在聚合函数内部实现条件过滤，实现行转列（Pivot）和多维度统计：


SELECT
    department,
    COUNT(*) AS total_employees,
    COUNT(CASE WHEN salary > 100000 THEN 1 END) AS high_salary_count,
    ROUND(AVG(CASE WHEN gender = 'M' THEN salary END), 2) AS avg_male_salary,
    ROUND(AVG(CASE WHEN gender = 'F' THEN salary END), 2) AS avg_female_salary,
    SUM(CASE WHEN hire_date >= DATE_TRUNC('year', CURRENT_DATE)
             THEN 1 ELSE 0 END) AS new_hires_this_year
FROM employees
GROUP BY department;
PostgreSQL 提供了更简洁的 FILTER 子句语法：


SELECT
    department,
    COUNT(*) AS total,
    COUNT(*) FILTER (WHERE salary > 100000) AS high_salary,
    AVG(salary) FILTER (WHERE gender = 'M') AS avg_male_salary,
    AVG(salary) FILTER (WHERE gender = 'F') AS avg_female_salary
FROM employees
GROUP BY department;

GROUPING SETS 与多维分析
GROUPING SETS 允许在一条查询中同时计算多个不同维度组合的聚合结果，ROLLUP 和 CUBE 是其常用的简写形式：


SELECT
    COALESCE(region, '(全部)') AS region,
    COALESCE(category, '(全部)') AS category,
    COALESCE(CAST(EXTRACT(YEAR FROM order_date) AS TEXT), '(全部)') AS year,
    COUNT(*) AS order_count,
    SUM(amount) AS total_revenue,
    ROUND(AVG(amount), 2) AS avg_order_value
FROM orders
GROUP BY GROUPING SETS (
    (region, category),
    (region),
    (category),
    ()
);
ROLLUP 自动生成层级小计，适合组织结构和时间层级报表：


SELECT
    EXTRACT(YEAR FROM order_date) AS year,
    EXTRACT(MONTH FROM order_date) AS month,
    category,
    SUM(amount) AS revenue,
    GROUPING(EXTRACT(YEAR FROM order_date)) AS is_year_total,
    GROUPING(EXTRACT(MONTH FROM order_date)) AS is_month_total,
    GROUPING(category) AS is_category_total
FROM orders
GROUP BY ROLLUP (
    EXTRACT(YEAR FROM order_date),
    EXTRACT(MONTH FROM order_date),
    category
);
CUBE 生成所有可能的维度组合，适合需要全面交叉分析的场景：


SELECT
    region,
    category,
    SUM(amount) AS revenue
FROM orders
GROUP BY CUBE (region, category)
ORDER BY region NULLS LAST, category NULLS LAST;

字符串聚合与数组聚合
将多行数据聚合为单个字符串或数组是报表和数据展示的常见需求：


SELECT
    department,
    COUNT(*) AS member_count,
    STRING_AGG(employee_name, ', ' ORDER BY hire_date) AS members,
    ARRAY_AGG(DISTINCT skill ORDER BY skill) AS skills,
    STRING_AGG(DISTINCT job_title, ' / ') AS positions
FROM employees
JOIN employee_skills USING (employee_id)
GROUP BY department;
const stringAggExamples = `
-- MySQL 使用 GROUP_CONCAT
SELECT department,
       GROUP_CONCAT(name ORDER BY name SEPARATOR ', ') AS members
FROM employees
GROUP BY department;

-- SQLite 使用 GROUP_CONCAT（无 ORDER BY 支持）
SELECT department,
       GROUP_CONCAT(name, ', ') AS members
FROM employees
GROUP BY department;

-- SQL Server 使用 STRING_AGG（2017+）
SELECT department,
       STRING_AGG(name, ', ') WITHIN GROUP (ORDER BY name) AS members
FROM employees
GROUP BY department;
`;

HAVING 与聚合过滤
HAVING 子句在聚合计算之后进行过滤，是实现"满足条件的分组"查询的核心手段：


SELECT
    customer_id,
    COUNT(*) AS order_count,
    SUM(amount) AS total_spent,
    AVG(amount) AS avg_order,
    MAX(order_date) AS last_order
FROM orders
WHERE order_date >= CURRENT_DATE - INTERVAL '1 year'
GROUP BY customer_id
HAVING COUNT(*) >= 5
   AND SUM(amount) > 10000
ORDER BY total_spent DESC;
复杂的聚合过滤可以结合子查询和 CTE 实现更精细的条件：


WITH customer_stats AS (
    SELECT
        customer_id,
        COUNT(*) AS order_count,
        SUM(amount) AS total_spent,
        AVG(amount) AS avg_order,
        COUNT(DISTINCT category) AS category_count
    FROM orders
    GROUP BY customer_id
)
SELECT *
FROM customer_stats
WHERE order_count > (SELECT AVG(order_count) FROM customer_stats)
  AND category_count >= 3
ORDER BY total_spent DESC;
小结
    

  • 条件聚合（CASE WHEN + 聚合函数）是 SQL 中最灵活的数据透视技巧
    • 

  • PostgreSQL 的 FILTER 子句提供了更优雅的条件聚合语法
    • 

  • GROUPING SETS/ROLLUP/CUBE 实现多维交叉分析，减少多次查询
    • 

  • STRING_AGG/ARRAY_AGG 将多行聚合为字符串或数组，简化报表输出
    • 

  • HAVING 子句在聚合后过滤分组，配合 CTE 可实现复杂的统计条件
    • 

  • 近似聚合函数在超大数据集上用精度换取数量级的性能提升
