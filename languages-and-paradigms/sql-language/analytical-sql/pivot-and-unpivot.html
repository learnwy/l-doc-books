行列转换与 PIVOT

核心概念

行列转换（Pivot/Unpivot）是数据报表和分析中的高频操作。Pivot 将行数据转换为列（行转列），Unpivot 则反向操作（列转行）。不同数据库对 Pivot 的支持差异很大——Oracle 和 SQL Server 提供了原生 PIVOT/UNPIVOT 语法，而 PostgreSQL 和 MySQL 则依赖条件聚合或 crosstab 函数来实现。

行转列（Pivot）
最通用的行转列方法是使用条件聚合，适用于所有 SQL 数据库：


SELECT
    product_name,
    SUM(CASE WHEN EXTRACT(MONTH FROM sale_date) = 1 THEN amount ELSE 0 END) AS jan,
    SUM(CASE WHEN EXTRACT(MONTH FROM sale_date) = 2 THEN amount ELSE 0 END) AS feb,
    SUM(CASE WHEN EXTRACT(MONTH FROM sale_date) = 3 THEN amount ELSE 0 END) AS mar,
    SUM(CASE WHEN EXTRACT(MONTH FROM sale_date) = 4 THEN amount ELSE 0 END) AS apr,
    SUM(amount) AS total
FROM sales
WHERE EXTRACT(YEAR FROM sale_date) = 2024
GROUP BY product_name
ORDER BY total DESC;
Oracle/SQL Server 提供了更简洁的原生语法：


-- SQL Server PIVOT 语法
SELECT product_name, [1] AS jan, [2] AS feb, [3] AS mar, [4] AS apr
FROM (
    SELECT product_name, MONTH(sale_date) AS month_num, amount
    FROM sales
    WHERE YEAR(sale_date) = 2024
) AS src
PIVOT (
    SUM(amount) FOR month_num IN ([1], [2], [3], [4])
) AS pvt;
PostgreSQL 可以使用 tablefunc 扩展的 crosstab 函数：


CREATE EXTENSION IF NOT EXISTS tablefunc;

SELECT *
FROM crosstab(
    $$SELECT product_name, EXTRACT(MONTH FROM sale_date)::int, SUM(amount)
      FROM sales
      WHERE EXTRACT(YEAR FROM sale_date) = 2024
      GROUP BY 1, 2
      ORDER BY 1, 2$$,
    $$SELECT generate_series(1, 4)$$
) AS ct(product_name TEXT, jan NUMERIC, feb NUMERIC, mar NUMERIC, apr NUMERIC);

列转行（Unpivot）
列转行将宽表格式转换回长表格式，最通用的方法是使用 UNION ALL：


SELECT product_name, 'jan' AS month, jan AS amount FROM monthly_sales
UNION ALL
SELECT product_name, 'feb', feb FROM monthly_sales
UNION ALL
SELECT product_name, 'mar', mar FROM monthly_sales
UNION ALL
SELECT product_name, 'apr', apr FROM monthly_sales
ORDER BY product_name, month;
PostgreSQL 使用 LATERAL + VALUES 更加优雅：


SELECT s.product_name, v.month_name, v.amount
FROM monthly_sales s
CROSS JOIN LATERAL (
    VALUES
        ('jan', s.jan),
        ('feb', s.feb),
        ('mar', s.mar),
        ('apr', s.apr)
) AS v(month_name, amount)
WHERE v.amount > 0
ORDER BY s.product_name, v.month_name;
SQL Server 提供了原生 UNPIVOT：


SELECT product_name, month_name, amount
FROM monthly_sales
UNPIVOT (
    amount FOR month_name IN (jan, feb, mar, apr)
) AS unpvt;
动态 Pivot 实现
当透视列的值在查询时才确定（如不同年份、不同类别），需要动态构建 SQL：


const buildDynamicPivot = (
  baseTable: string,
  pivotColumn: string,
  valueColumn: string,
  aggFunction: string,
  groupColumns: string[],
  pivotValues: string[],
): string => {
  const pivotCases = pivotValues
    .map((val) => `${aggFunction}(CASE WHEN ${pivotColumn} = '${val}' THEN ${valueColumn} END) AS "${val}"`)
    .join(',\n    ');

  const groupBy = groupColumns.join(', ');

  return `
SELECT
    ${groupBy},
    ${pivotCases}
FROM ${baseTable}
GROUP BY ${groupBy}
ORDER BY ${groupBy};`;
};

const sql = buildDynamicPivot('sales', 'category', 'amount', 'SUM', ['region'], ['Electronics', 'Clothing', 'Food']);
在 PostgreSQL 中可以用 PL/pgSQL 构建动态 Pivot：


CREATE OR REPLACE FUNCTION dynamic_pivot(
    query TEXT,
    pivot_col TEXT,
    val_col TEXT,
    agg TEXT DEFAULT 'SUM'
) RETURNS TEXT AS $$
DECLARE
    col_list TEXT;
    final_sql TEXT;
BEGIN
    EXECUTE format(
        'SELECT STRING_AGG(DISTINCT format(''%s(CASE WHEN %I = %%L THEN %I END) AS %%I'', val, val), '', ''
         ORDER BY val)
         FROM (%s) sub
         CROSS JOIN LATERAL (VALUES (%I)) AS t(val)',
        agg, pivot_col, val_col, query, pivot_col
    ) INTO col_list;

    final_sql := format('SELECT *, %s FROM (%s) sub GROUP BY 1', col_list, query);
    RETURN final_sql;
END;
$$ LANGUAGE plpgsql;
实战场景
跨表 Pivot 在报表系统中非常常见，例如生成用户行为矩阵：


WITH user_actions AS (
    SELECT
        user_id,
        action_type,
        COUNT(*) AS action_count
    FROM user_events
    WHERE event_date >= CURRENT_DATE - INTERVAL '30 days'
    GROUP BY user_id, action_type
)
SELECT
    user_id,
    COALESCE(SUM(CASE WHEN action_type = 'view' THEN action_count END), 0) AS views,
    COALESCE(SUM(CASE WHEN action_type = 'click' THEN action_count END), 0) AS clicks,
    COALESCE(SUM(CASE WHEN action_type = 'purchase' THEN action_count END), 0) AS purchases,
    COALESCE(SUM(CASE WHEN action_type = 'share' THEN action_count END), 0) AS shares,
    ROUND(
        SUM(CASE WHEN action_type = 'purchase' THEN action_count END)::NUMERIC /
        NULLIF(SUM(CASE WHEN action_type = 'click' THEN action_count END), 0),
        4
    ) AS click_to_purchase_rate
FROM user_actions
GROUP BY user_id
HAVING SUM(action_count) > 10
ORDER BY purchases DESC;
小结
    

  • 条件聚合（CASE WHEN + SUM/COUNT）是最通用的行转列方法，适用于所有数据库
    • 

  • Oracle/SQL Server 的 PIVOT/UNPIVOT 语法更简洁但移植性差
    • 

  • PostgreSQL 的 LATERAL + VALUES 是列转行的优雅解法
    • 

  • 动态 Pivot 需要程序语言或过程化 SQL 构建，适合列值运行时确定的场景
    • 

  • 行列转换是报表系统和数据仓库的核心操作，需要根据数据库选择最优方案
