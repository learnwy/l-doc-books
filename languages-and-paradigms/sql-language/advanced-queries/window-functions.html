窗口函数

核心概念

窗口函数（Window Functions）是 SQL 中最强大的分析工具，它在不改变结果集行数的前提下，为每一行计算基于一组相关行（"窗口"）的聚合值。与 GROUP BY 不同，窗口函数不折叠行——原始行保持不变，计算结果作为新列附加。这使得窗口函数能够同时展示明细数据和聚合数据。

graph TD
    A[窗口函数] --> B[PARTITION BY]
    A --> C[ORDER BY]
    A --> D[Frame 子句]

    B --> B1[按指定列分组]
    C --> C1[组内排序]
    D --> D1[ROWS]
    D --> D2[RANGE]
    D --> D3[GROUPS]

    subgraph 函数类型
        E[排名函数 - ROW_NUMBER / RANK / DENSE_RANK]
        F[聚合函数 - SUM / AVG / COUNT]
        G[偏移函数 - LAG / LEAD / FIRST_VALUE / LAST_VALUE]
        H[分布函数 - PERCENT_RANK / CUME_DIST / NTILE]
    end
函数类型 代表函数 是否需要 ORDER BY 是否受 Frame 影响 典型场景
排名函数 ROW_NUMBER, RANK 是 否 编号、去重、分页
聚合函数 SUM, AVG, COUNT 可选 是 累计值、移动平均
偏移函数 LAG, LEAD 是 否 环比、同比、前后行对比
分布函数 NTILE, PERCENT_RANK 是 否 分桶、百分位排名

排名函数

排名函数为分区内的每一行分配一个序号。三个核心排名函数的区别在于处理并列值的方式。

const rankingFunctions = `
-- ROW_NUMBER：严格递增，并列值也不重复
-- RANK：并列值相同排名，后续跳号
-- DENSE_RANK：并列值相同排名，后续不跳号
SELECT 
    department_id,
    employee_name,
    salary,
    ROW_NUMBER() OVER (PARTITION BY department_id ORDER BY salary DESC) AS row_num,
    RANK()       OVER (PARTITION BY department_id ORDER BY salary DESC) AS rank_val,
    DENSE_RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS dense_rank_val
FROM employees;

-- 示例结果（department_id = 1）：
-- salary  row_num  rank_val  dense_rank_val
-- 10000   1        1         1
-- 10000   2        1         1
-- 8000    3        3         2    ← RANK 跳号，DENSE_RANK 不跳
-- 7000    4        4         3

-- 每组取 Top N（经典模式）
SELECT * FROM (
    SELECT 
        p.*,
        ROW_NUMBER() OVER (
            PARTITION BY category_id 
            ORDER BY sales_count DESC
        ) AS rn
    FROM products p
) ranked
WHERE rn <= 3;

-- 去重保留最新记录
DELETE FROM events
WHERE event_id NOT IN (
    SELECT event_id FROM (
        SELECT event_id, ROW_NUMBER() OVER (
            PARTITION BY user_id, event_type 
            ORDER BY created_at DESC
        ) AS rn
        FROM events
    ) t WHERE rn = 1
);
`;
函数 并列处理 值示例 (3个并列第1) 常用场景
ROW_NUMBER 不并列 1, 2, 3, 4 分页、去重
RANK 并列+跳号 1, 1, 1, 4 竞赛排名
DENSE_RANK 并列+不跳号 1, 1, 1, 2 密集排名、分层

聚合窗口函数

聚合函数（SUM、AVG、COUNT 等）作为窗口函数使用时，可以计算累计值、移动平均等分析指标。Frame 子句控制参与计算的行范围。

const aggregateWindows = `
-- 累计求和（Running Total）
SELECT 
    order_date,
    amount,
    SUM(amount) OVER (ORDER BY order_date) AS running_total,
    SUM(amount) OVER (
        ORDER BY order_date 
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS cumulative_sum
FROM daily_sales;

-- 7 天移动平均
SELECT 
    date,
    revenue,
    AVG(revenue) OVER (
        ORDER BY date 
        ROWS BETWEEN 6 PRECEDING AND CURRENT ROW
    ) AS moving_avg_7d
FROM daily_metrics;

-- 分区内占比
SELECT 
    department_id,
    employee_name,
    salary,
    SUM(salary) OVER (PARTITION BY department_id) AS dept_total,
    ROUND(salary * 100.0 / SUM(salary) OVER (PARTITION BY department_id), 2) AS pct
FROM employees;

-- 累计计数 + 累计去重计数
SELECT 
    order_date,
    user_id,
    COUNT(*) OVER (ORDER BY order_date) AS cumulative_orders,
    COUNT(DISTINCT user_id) OVER (ORDER BY order_date) AS cumulative_users
FROM orders;
`;

Frame 子句的三种模式：

Frame 模式 含义 默认范围 适用场景
ROWS 物理行数 UNBOUNDED PRECEDING TO CURRENT ROW 精确 N 行滑动窗口
RANGE 值范围 UNBOUNDED PRECEDING TO CURRENT ROW 值域范围聚合
GROUPS 分组数 UNBOUNDED PRECEDING TO CURRENT ROW 按 peer group 聚合

偏移函数

LAG 和 LEAD 访问当前行的前/后行数据，无需自连接。FIRST_VALUE 和 LAST_VALUE 获取窗口中的首/末值。

const offsetFunctions = `
-- 环比增长率（Month-over-Month）
SELECT 
    month,
    revenue,
    LAG(revenue, 1) OVER (ORDER BY month) AS prev_month_revenue,
    ROUND(
        (revenue - LAG(revenue, 1) OVER (ORDER BY month)) * 100.0 
        / LAG(revenue, 1) OVER (ORDER BY month), 
        2
    ) AS mom_growth_pct
FROM monthly_revenue;

-- 同比增长率（Year-over-Year）
SELECT 
    month,
    revenue,
    LAG(revenue, 12) OVER (ORDER BY month) AS prev_year_revenue,
    ROUND(
        (revenue - LAG(revenue, 12) OVER (ORDER BY month)) * 100.0 
        / NULLIF(LAG(revenue, 12) OVER (ORDER BY month), 0), 
        2
    ) AS yoy_growth_pct
FROM monthly_revenue;

-- 连续事件间隔计算
SELECT 
    event_id,
    user_id,
    created_at,
    LAG(created_at) OVER (PARTITION BY user_id ORDER BY created_at) AS prev_event_at,
    created_at - LAG(created_at) OVER (
        PARTITION BY user_id ORDER BY created_at
    ) AS time_gap
FROM user_events;

-- FIRST_VALUE / LAST_VALUE
SELECT 
    product_id,
    sale_date,
    price,
    FIRST_VALUE(price) OVER (
        PARTITION BY product_id ORDER BY sale_date
    ) AS first_price,
    LAST_VALUE(price) OVER (
        PARTITION BY product_id ORDER BY sale_date
        ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
    ) AS last_price
FROM product_prices;
`;

注意 LAST_VALUE 的陷阱：默认 Frame 是 ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW，所以 LAST_VALUE 返回的是当前行的值而非分区末尾。要获取真正的末尾值，必须显式指定 ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING。

NAMED WINDOW 与性能

当多个窗口函数使用相同的分区和排序时，可以使用 WINDOW 子句定义命名窗口，提升可读性。

const namedWindow = `
SELECT 
    department_id,
    employee_name,
    salary,
    ROW_NUMBER() OVER w AS row_num,
    RANK() OVER w AS rank_val,
    SUM(salary) OVER w AS running_salary,
    AVG(salary) OVER w AS running_avg
FROM employees
WINDOW w AS (PARTITION BY department_id ORDER BY salary DESC);
`;

窗口函数的性能关键在于排序。每个不同的 PARTITION BY + ORDER BY 组合都需要一次排序操作。优化策略包括：为窗口函数的排序列创建索引，合并相同分区和排序的窗口定义，以及控制分区大小避免内存溢出。

小结

  • 窗口函数在不折叠行的前提下计算分区内的聚合值，同时展示明细和汇总
  • ROW_NUMBER / RANK / DENSE_RANK 三个排名函数在处理并列值时行为不同
  • 聚合窗口函数通过 Frame 子句控制计算范围，支持累计求和、移动平均等分析
  • LAG/LEAD 实现环比、同比分析，LAST_VALUE 需显式指定 Frame 范围
  • NAMED WINDOW 提升多窗口函数查询的可读性
  • 性能优化关键：为排序列建索引，合并相同窗口定义，控制分区大小
