Part III · 范式与文本函数式编程 简介核心概念 简介递归与尾调用

递归与尾调用

递归：函数式的循环

在函数式编程中，递归是替代命令式循环的核心控制流机制。递归函数通过调用自身来处理问题的子结构，直到到达基准情况（Base Case）。

const factorial = (n: number): number => (n <= 1 ? 1 : n * factorial(n - 1));

const fibonacci = (n: number): number => (n <= 1 ? n : fibonacci(n - 1) + fibonacci(n - 2));
factorial :: Integer -> Integer
factorial 0 = 1
factorial n = n * factorial (n - 1)

fibonacci :: Integer -> Integer
fibonacci 0 = 0
fibonacci 1 = 1
fibonacci n = fibonacci (n - 1) + fibonacci (n - 2)
对比维度 命令式循环 递归
状态管理 可变计数器 函数参数
终止条件 循环条件 基准情况
可读性 取决于复杂度 声明式，接近数学定义
栈空间 O(1) O(n)
编译器优化 已优化 需要尾调用优化 


提示： 递归的关键在于两点：一是确保基准情况能够被到达（否则无限递归），二是每次递归调用都在缩小问题规模。






尾调用与尾递归
尾调用（Tail Call）是指函数的最后一个操作是调用另一个函数。当这个被调用的函数是自身时，称为尾递归（Tail Recursion）。


const factorialNaive = (n: number): number => (n <= 1 ? 1 : n * factorialNaive(n - 1));

const factorialTail = (n: number, acc: number = 1): number => (n <= 1 ? acc : factorialTail(n - 1, n * acc));
factorialTail :: Integer -> Integer -> Integer
factorialTail 0 acc = acc
factorialTail n acc = factorialTail (n - 1) (n * acc)

尾调用优化
尾调用优化（Tail Call Optimization，TCO）是编译器/运行时将尾调用转换为跳转指令的优化，使递归函数不再消耗额外栈空间。

Trampoline 模式
在不支持 TCO 的语言中，Trampoline 模式通过将递归调用转换为循环来避免栈溢出。


type Thunk<A> = () => A | Thunk<A>;

const trampoline = <A>(fn: Thunk<A>): A => {
  let result: A | Thunk<A> = fn;
  while (typeof result === 'function') {
    result = (result as Thunk<A>)();
  }
  return result;
};

const factorialTrampoline = (n: number, acc: number = 1): number | (() => number | (() => any)) =>
  n <= 1 ? acc : () => factorialTrampoline(n - 1, n * acc);

const result = trampoline(() => factorialTrampoline(100000, 1));

递归的常见模式
递归在函数式编程中有多种典型应用模式：


const sumList = (xs: readonly number[]): number => (xs.length === 0 ? 0 : xs[0] + sumList(xs.slice(1)));

const flatten = <A>(xs: readonly (A | A[])[]): A[] =>
  xs.reduce<A[]>((acc, x) => acc.concat(Array.isArray(x) ? flatten(x) : [x]), []);

const treeDepth = <A>(tree: Tree<A>): number =>
  tree.type === 'leaf' ? 1 : 1 + Math.max(treeDepth(tree.left), treeDepth(tree.right));

type Tree<A> = { type: 'leaf'; value: A } | { type: 'node'; left: Tree<A>; right: Tree<A> };

小结
    

  • 递归是函数式编程的核心控制流机制，通过函数自调用替代可变循环。
    • 

  • 尾递归将计算结果通过累积器参数传递，使函数调用处于尾位置。
    • 

  • TCO 可将尾调用优化为跳转，但 JavaScript/TypeScript 生态几乎不支持。
    • 

  • Trampoline 模式在不支持 TCO 的语言中提供栈安全的递归方案。
    • 

  • 掌握线性递归、树形递归、相互递归等模式，是编写函数式代码的基本功。
