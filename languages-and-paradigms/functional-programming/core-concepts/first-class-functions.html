Part III · 范式与文本函数式编程 简介核心概念 简介一等函数

一等函数

函数作为值

在函数式编程中，函数是一等公民（First-class Citizen）。这意味着函数与数字、字符串等值享有完全相同的地位——可以赋值给变量、作为参数传递、作为返回值返回，以及存储在数据结构中。

const greet = (name: string): string => `Hello, ${name}!`;

const myFn: (name: string) => string = greet;

const functions: Array<(x: number) => number> = [(x) => x + 1, (x) => x * 2, (x) => x ** 2];
double :: Int -> Int
double = (*2)

functions :: [Int -> Int]
functions = [(+1), (*2), (^2)]
一等公民特征 数字 字符串 函数（FP） 函数（非 FP）

高阶函数

高阶函数（Higher-Order Function，HOF）是接受函数作为参数或返回函数的函数。它是函数式编程最强大的抽象工具之一。

const map =
  <A, B>(f: (a: A) => B) =>
  (xs: A[]): B[] =>
    xs.map(f);

const filter =
  <A>(pred: (a: A) => boolean) =>
  (xs: A[]): A[] =>
    xs.filter(pred);

const reduce =
  <A, B>(f: (acc: B, a: A) => B, init: B) =>
  (xs: A[]): B =>
    xs.reduce(f, init);

const doubleAll = map((x: number) => x * 2);
const evens = filter((x: number) => x % 2 === 0);
const sum = reduce((acc: number, x: number) => acc + x, 0);

闭包
闭包（Closure）是引用了其词法作用域中自由变量的函数。闭包使得函数可以"记住"它被创建时的环境。


const makeCounter = (initial: number) => {
  let count = initial;
  return {
    increment: () => ++count,
    getCount: () => count,
  };
};

const makeMultiplier =
  (factor: number) =>
  (x: number): number =>
    x * factor;

const double = makeMultiplier(2);
const triple = makeMultiplier(3);

函数类型签名
函数类型签名是理解函数行为的关键。在 Haskell 和 TypeScript 中，类型签名传达了丰富的信息。


map    :: (a -> b) -> [a] -> [b]
filter :: (a -> Bool) -> [a] -> [a]
foldr  :: (a -> b -> b) -> b -> [a] -> b
(.)    :: (b -> c) -> (a -> b) -> a -> c
type Predicate<A> = (a: A) => boolean;
type Mapper<A, B> = (a: A) => B;
type Reducer<A, B> = (acc: B, a: A) => B;

type Compose = <A, B, C>(f: (b: B) => C, g: (a: A) => B) => (a: A) => C;

提示： Haskell 中的函数签名 a -> b -> c 实际上是 a -> (b -> c) 的语法糖——所有函数都是自动柯里化的。这意味着 map (+1) 是完全合法的，它返回一个等待列表参数的新函数。






常见高阶函数模式
除了 map、filter、reduce，还有许多实用的高阶函数模式：


const compose =
  <A, B, C>(f: (b: B) => C, g: (a: A) => B) =>
  (a: A): C =>
    f(g(a));

const pipe =
  <A>(...fns: Array<(a: A) => A>) =>
  (x: A): A =>
    fns.reduce((acc, fn) => fn(acc), x);

const memoize = <A extends string | number, B>(f: (a: A) => B): ((a: A) => B) => {
  const cache = new Map<A, B>();
  return (a: A): B => {
    if (cache.has(a)) return cache.get(a)!;
    const result = f(a);
    cache.set(a, result);
    return result;
  };
};

const once = <A extends unknown[], B>(f: (...args: A) => B): ((...args: A) => B) => {
  let called = false;
  let result: B;
  return (...args: A): B => {
    if (!called) {
      result = f(...args);
      called = true;
    }
    return result;
  };
};

小结
    

  • 一等函数意味着函数与其他值享有完全相同的地位，可以自由传递和组合。
    • 

  • 高阶函数接受函数或返回函数，map/filter/reduce 是最核心的三个。
    • 

  • 闭包让函数捕获其创建时的环境，是实现数据封装和偏应用的基础。
    • 

  • 类型签名是理解函数行为的窗口，Haskell 的自动柯里化使签名格外简洁。
    • 

  • compose、pipe、memoize 等高阶函数模式是日常开发中的常用工具。
