函数组合

组合的数学基础

函数组合（Function Composition）源自数学中的复合函数概念。给定函数 f: B → C 和 g: A → B，它们的组合 f ∘ g 定义为 (f ∘ g)(x) = f(g(x))。组合产生一个新函数，先应用 g，再将结果传给 f。

(.) :: (b -> c) -> (a -> b) -> a -> c
(f . g) x = f (g x)

toUpperFirst :: String -> String
toUpperFirst = toUpper . head
const compose =
  <A, B, C>(f: (b: B) => C, g: (a: A) => B): ((a: A) => C) =>
  (a: A) =>
    f(g(a));

const toUpper = (s: string): string => s.toUpperCase();
const exclaim = (s: string): string => `${s}!`;

const shout = compose(exclaim, toUpper);
性质 描述 公式
结合律 组合顺序不影响结果 (f ∘ g) ∘ h = f ∘ (g ∘ h)
单位元 identity 函数是组合的单位元 f ∘ id = id ∘ f = f
类型对齐 前一个函数的输出类型 = 后一个的输入 g: A→B, f: B→C ⇒ f∘g: A→C 


提示： 函数组合的结合律意味着 compose(f, compose(g, h)) 与 compose(compose(f, g), h) 完全等价。这使得我们可以自由地分组和重组组合链，不必担心结果改变。






多函数组合
实际开发中往往需要组合多个函数。可以通过 reduce 实现任意数量函数的组合：


const composeMany = <A>(...fns: Array<(a: A) => A>): ((a: A) => A) => fns.reduce((f, g) => (x: A) => f(g(x)));

const processString = composeMany(
  (s: string) => s.trim(),
  (s: string) => s.toLowerCase(),
  (s: string) => s.replace(/\s+/g, '-'),
);
processString :: String -> String
processString = trim . toLower . intercalate "-" . words

组合与类型安全
在 TypeScript 中实现类型安全的组合需要利用泛型重载：


function compose<A, B>(f: (a: A) => B): (a: A) => B;
function compose<A, B, C>(f: (b: B) => C, g: (a: A) => B): (a: A) => C;
function compose<A, B, C, D>(f: (c: C) => D, g: (b: B) => C, h: (a: A) => B): (a: A) => D;
function compose(...fns: Array<(a: unknown) => unknown>) {
  return (x: unknown) => fns.reduceRight((acc, fn) => fn(acc), x);
}

const process = compose(
  (n: number) => n.toString(),
  (s: string) => s.length,
  (s: string) => s.trim(),
);

组合的代数结构
从范畴论的视角看，函数组合构成了一个范畴（Category）。类型是对象，函数是态射，组合是态射的复合。


type Category<F> = {
  id: <A>(a: A) => A;
  compose: <A, B, C>(f: (b: B) => C, g: (a: A) => B) => (a: A) => C;
};

const fnCategory: Category<Function> = {
  id: <A>(a: A): A => a,
  compose:
    <A, B, C>(f: (b: B) => C, g: (a: A) => B) =>
    (a: A): C =>
      f(g(a)),
};

小结
    

  • 函数组合将两个函数连接为一个新函数，是函数式编程最基本的构建操作。
    • 

  • 组合满足结合律且以 identity 为单位元，这些代数性质保证了组合的灵活性。
    • 

  • TypeScript 中实现类型安全的组合需要泛型重载或 fp-ts 等库的支持。
    • 

  • 从范畴论视角看，类型和函数构成一个范畴，组合是态射的复合操作。
    • 

  • 掌握函数组合是理解后续柯里化、管道和 Monad 等概念的基础。
