Point-free 风格

什么是 Point-free

Point-free 风格（Tacit Programming）是一种省略显式参数声明的编程风格。"Point" 在这里指的不是小数点，而是数学中的"点"——即函数参数。Point-free 风格通过函数组合直接定义函数，而不提及其参数。

-- Pointed（显式参数）
sum' :: [Int] -> Int
sum' xs = foldr (+) 0 xs

-- Point-free（省略参数）
sum' :: [Int] -> Int
sum' = foldr (+) 0

-- Pointed
isEven :: Int -> Bool
isEven n = n `mod` 2 == 0

-- Point-free
isEven :: Int -> Bool
isEven = (== 0) . (`mod` 2)
const numbers = [1, 2, 3, 4, 5];

const sumPointed = (xs: number[]): number => xs.reduce((a, b) => a + b, 0);

const add = (a: number, b: number): number => a + b;
const sumPointFree = (xs: number[]): number => xs.reduce(add, 0);
风格 定义方式 关注点
Pointed const f = (x) => g(h(x)) 数据如何流经函数
Point-free const f = compose(g, h) 函数如何组合 


提示： Point-free 风格的本质是将关注点从"数据变换的步骤"提升到"函数间的关系"。它不是目标本身，而是函数组合自然产生的结果。






Point-free 的优势
Point-free 风格在适当使用时可以显著提升代码的抽象层次和可读性：


-- Pointed：命名噪音多
averageAge :: [Person] -> Double
averageAge people = sum (map age people) / fromIntegral (length people)

-- Point-free：关注数据流
averageAge :: [Person] -> Double
averageAge = liftA2 (/) (sum . map age) (fromIntegral . length)
const not = (b: boolean): boolean => !b;
const isOdd = (n: number): boolean => n % 2 !== 0;

const getEvenNumbers = (xs: number[]): number[] => xs.filter((x) => !isOdd(x));

const getEvenNumbersPF = (xs: number[]): number[] => xs.filter(compose(not, isOdd));

Point-free 的陷阱
过度使用 Point-free 会导致代码变得晦涩难懂，这被社区戏称为 Pointless 风格：


-- 清晰的 Point-free
map :: (a -> b) -> [a] -> [b]

-- 过度 Point-free（Pointless）
-- 原始：\f g x -> f (g x)
-- Point-free：(.) . (.)
-- 含义已完全不透明
const getName = (user: { name: string }): string => user.name;

const getNamesPF = compose(
  (xs: string[]) => xs.join(', '),
  (users: { name: string }[]) => users.map(getName),
);

const getNamesReadable = (users: { name: string }[]): string => users.map((u) => u.name).join(', ');

常见 Point-free 工具函数
以下是支持 Point-free 风格的常用工具函数：


const identity = <A>(a: A): A => a;

const constant =
  <A>(a: A) =>
  <B>(_: B): A =>
    a;

const flip =
  <A, B, C>(f: (a: A) => (b: B) => C) =>
  (b: B) =>
  (a: A): C =>
    f(a)(b);

const on =
  <A, B, C>(f: (b1: B) => (b2: B) => C) =>
  (g: (a: A) => B) =>
  (a1: A) =>
  (a2: A): C =>
    f(g(a1))(g(a2));

const prop =
  <K extends string>(key: K) =>
  <O extends Record<K, unknown>>(obj: O): O[K] =>
    obj[key];
identity :: a -> a
const    :: a -> b -> a
flip     :: (a -> b -> c) -> b -> a -> c
on       :: (b -> b -> c) -> (a -> b) -> a -> a -> c

从 Pointed 到 Point-free 的重构
将 Pointed 代码转换为 Point-free 是一个渐进的过程：


const users = [
  { name: 'Alice', age: 30 },
  { name: 'Bob', age: 25 },
  { name: 'Charlie', age: 35 },
];

const getAdultNames1 = (users: { name: string; age: number }[]) => users.filter((u) => u.age >= 18).map((u) => u.name);

const isAdult = (u: { age: number }): boolean => u.age >= 18;
const getName = (u: { name: string }): string => u.name;

const getAdultNames2 = (users: { name: string; age: number }[]) => users.filter(isAdult).map(getName);


小结
    

  • Point-free 风格省略函数参数声明，通过函数组合直接定义函数。
    • 

  • 适当使用可减少命名负担、突出数据流关系，过度使用则导致可读性下降。
    • 

  • identity、constant、flip、prop 等工具函数是 Point-free 风格的基础设施。
    • 

  • 实践中建议在简单组合（2-3 个函数）时使用 Point-free，复杂逻辑保持 Pointed。
    • 

  • 从 Pointed 到 Point-free 的重构应渐进进行，以可读性为终止条件。
