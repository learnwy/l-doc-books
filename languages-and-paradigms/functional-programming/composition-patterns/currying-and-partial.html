柯里化与偏应用

柯里化的定义

柯里化（Currying）是将一个接受多个参数的函数转换为一系列接受单个参数的函数的技术。它以数学家 Haskell Curry 的名字命名。

add :: Int -> Int -> Int
add x y = x + y

add3 :: Int -> Int
add3 = add 3
const add =
  (a: number) =>
  (b: number): number =>
    a + b;

const add3 = add(3);
const result = add3(5);
形式 函数签名 调用方式
未柯里化 (a, b, c) => d f(1, 2, 3)
柯里化 a => b => c => d f(1)(2)(3)
偏应用 固定部分参数后的函数 f(1)(2) → 新函数 


提示： 在 Haskell 中，所有函数默认都是柯里化的。add 3 5 实际上是 (add 3) 5——先用 3 调用 add 得到一个新函数，再用 5 调用这个新函数。






通用柯里化实现
在 JavaScript/TypeScript 中，可以编写一个通用的 curry 函数：


type Curry<Args extends unknown[], R> = Args extends [infer First, ...infer Rest] ? (arg: First) => Curry<Rest, R> : R;

const curry = <Args extends unknown[], R>(fn: (...args: Args) => R): Curry<Args, R> => {
  const arity = fn.length;
  const curried = (...args: unknown[]): unknown =>
    args.length >= arity ? fn(...(args as Args)) : (...more: unknown[]) => curried(...args, ...more);
  return curried as Curry<Args, R>;
};

const multiply = (a: number, b: number, c: number): number => a * b * c;
const curriedMultiply = curry(multiply);
const double = curriedMultiply(2)(1);

偏应用
偏应用（Partial Application）是固定一个函数的部分参数，生成一个接受剩余参数的新函数。偏应用与柯里化相关但不同——柯里化一次固定一个参数，偏应用可以一次固定多个。


const partial =
  <A extends unknown[], B extends unknown[], R>(fn: (...args: [...A, ...B]) => R, ...fixed: A): ((...rest: B) => R) =>
  (...rest: B) =>
    fn(...fixed, ...rest);

const log = (level: string, module: string, message: string): string => `[${level}] [${module}] ${message}`;

const errorLog = partial(log, 'ERROR');
const authError = partial(log, 'ERROR', 'AUTH');
import Data.List (intercalate)

joinWith :: String -> [String] -> String
joinWith = intercalate

commaSeparated :: [String] -> String
commaSeparated = joinWith ", "

提示： 在设计柯里化友好的 API 时，应将最不常变化的参数放在前面（如配置、选项），将最常变化的参数（如数据）放在最后。这样偏应用或柯里化时可以先固定配置，得到一个处理数据的专用函数。






实际应用场景
柯里化和偏应用在日常开发中有广泛应用：


const createValidator =
  (rules: Record<string, (v: unknown) => boolean>) =>
  (fieldName: string) =>
  (value: unknown): boolean =>
    rules[fieldName]?.(value) ?? false;

const validate = createValidator({
  email: (v) => typeof v === 'string' && v.includes('@'),
  age: (v) => typeof v === 'number' && v >= 0 && v <= 150,
});

const validateEmail = validate('email');
const validateAge = validate('age');

const createApiClient =
  (baseUrl: string) =>
  (endpoint: string) =>
  (params?: Record<string, string>): string => {
    const query = params ? '?' + new URLSearchParams(params).toString() : '';
    return `${baseUrl}${endpoint}${query}`;
  };

const api = createApiClient('https://api.example.com');
const usersApi = api('/users');

小结
    

  • 柯里化将多参数函数转换为一系列单参数函数，Haskell 和 F# 默认支持。
    • 

  • 偏应用固定函数的部分参数生成新函数，比柯里化更灵活。
    • 

  • 参数顺序设计是关键：不常变化的参数在前，数据在后。
    • 

  • 柯里化和偏应用广泛用于日志工厂、API 客户端、验证器等场景。
    • 

  • TypeScript 中可通过泛型实现类型安全的 curry 和 partial 工具函数。
