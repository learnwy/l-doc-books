Monad Transformer 单子变换器

效果组合问题

真实程序通常需要同时处理多种效果：一个函数可能既会失败（Either），又需要读取配置（Reader），还涉及 I/O（IO）。但 Monad 不天然可组合——你无法简单地将两个 Monad "叠加"在一起。

-- 我们需要同时处理 IO 和 Maybe
-- 但 IO (Maybe a) 的嵌套操作很笨拙
lookupUser :: String -> IO (Maybe User)
lookupAddress :: User -> IO (Maybe Address)

getUserCity :: String -> IO (Maybe String)
getUserCity name = do
  mUser <- lookupUser name
  case mUser of
    Nothing -> return Nothing
    Just user -> do
      mAddr <- lookupAddress user
      case mAddr of
        Nothing -> return Nothing
        Just addr -> return (Just (city addr))
type IO<A> = { run: () => A };
type Option<A> = { tag: 'none' } | { tag: 'some'; value: A };

const getUserCity = (name: string): IO<Option<string>> => ({
  run: () => {
    const mUser = lookupUser(name).run();
    if (mUser.tag === 'none') return mUser;
    const mAddr = lookupAddress(mUser.value).run();
    if (mAddr.tag === 'none') return mAddr;
    return { tag: 'some', value: mAddr.value.city };
  },
});
效果组合需求 嵌套方式 问题
IO + Maybe IO (Maybe a) 需要手动拆包 Maybe
IO + Either IO (Either e a) 需要 case 匹配每一步
Reader + Either Reader r (Either e a) 环境传递 + 错误处理
IO + Reader + Either 三层嵌套 完全不可维护 


提示： Monad 不可组合是函数式编程中的核心困难之一。给定 Monad M 和 Monad N，M (N a) 不一定是 Monad。Monad Transformer 是解决这个问题的经典方案。






Monad Transformer 概念
Monad Transformer 是一个类型构造器，它接受一个 Monad 作为参数，返回一个新的 Monad，这个新 Monad 同时具有两种效果。


newtype MaybeT m a = MaybeT { runMaybeT :: m (Maybe a) }

instance Monad m => Monad (MaybeT m) where
  return = MaybeT . return . Just
  (MaybeT mma) >>= f = MaybeT $ do
    ma <- mma
    case ma of
      Nothing -> return Nothing
      Just a  -> runMaybeT (f a)

getUserCity :: String -> MaybeT IO String
getUserCity name = do
  user <- MaybeT (lookupUser name)
  addr <- MaybeT (lookupAddress user)
  return (city addr)
type MaybeT<M, A> = { value: M };

const maybeTBind = <A, B>(mma: IO<Option<A>>, f: (a: A) => IO<Option<B>>): IO<Option<B>> => ({
  run: () => {
    const ma = mma.run();
    if (ma.tag === 'none') return ma;
    return f(ma.value).run();
  },
});

lift 操作
lift 将底层 Monad 的操作提升到 Transformer 层级：


class MonadTrans t where
  lift :: Monad m => m a -> t m a

instance MonadTrans MaybeT where
  lift ma = MaybeT (fmap Just ma)

example :: MaybeT IO ()
example = do
  lift (putStrLn "Starting...")
  user <- MaybeT (lookupUser "alice")
  lift (putStrLn $ "Found: " ++ userName user)
const liftIO = <A>(io: IO<A>): IO<Option<A>> => ({
  run: () => ({ tag: 'some' as const, value: io.run() }),
});

const liftOption = <A>(opt: Option<A>): IO<Option<A>> => ({
  run: () => opt,
});

提示： lift 的直觉：当你在 MaybeT IO 的 do 块中想直接使用一个 IO 操作（如 putStrLn），你需要 lift 把它从 IO 层提升到 MaybeT IO 层。就像坐电梯上楼一样。






Transformer 栈
多个 Transformer 可以层叠形成"Transformer 栈"：


type App = ReaderT Config (EitherT AppError IO)

runApp :: Config -> App a -> IO (Either AppError a)
runApp config app = runEitherT (runReaderT app config)

getUser :: String -> App User
getUser name = do
  config <- ask
  result <- lift . lift $ httpGet (apiUrl config ++ "/users/" ++ name)
  case parseUser result of
    Left err -> lift (throwError (ParseError err))
    Right user -> return user

小结
    

  • Monad 不天然可组合，Monad Transformer 通过类型构造器叠加实现多效果组合。
    • 

  • lift 将底层 Monad 操作提升到 Transformer 层级，是 Transformer 栈中的关键操作。
    • 

  • 常见 Transformer 包括 MaybeT、EitherT、ReaderT、StateT、WriterT。
    • 

  • Transformer 栈存在性能开销和 lift 噪音，Effect System 是更现代的替代方案。
    • 

  • TypeScript 生态中 Effect-TS 提供了统一的效果处理方式，避免了 Transformer 的复杂性。
