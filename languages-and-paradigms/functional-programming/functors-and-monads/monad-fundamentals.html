Monad 基础

从 Functor 到 Monad

Functor 的 map 允许我们将函数 A → B 应用到 F<A> 上得到 F<B>。但如果函数本身返回一个包裹在上下文中的值（A → F<B>），map 就会产生嵌套：F<F<B>>。Monad 通过 flatMap（也叫 bind 或 >>=）解决了这个问题。

class Applicative m => Monad m where
  (>>=) :: m a -> (a -> m b) -> m b
  return :: a -> m a

safeDivide :: Double -> Double -> Maybe Double
safeDivide _ 0 = Nothing
safeDivide a b = Just (a / b)

compute :: Maybe Double
compute = Just 100 >>= \x ->
          safeDivide x 3 >>= \y ->
          safeDivide y 2
type Option<A> = { tag: 'none' } | { tag: 'some'; value: A };

const flatMap =
  <A, B>(f: (a: A) => Option<B>) =>
  (ma: Option<A>): Option<B> =>
    ma.tag === 'none' ? ma : f(ma.value);

const safeDivide = (a: number, b: number): Option<number> =>
  b === 0 ? { tag: 'none' } : { tag: 'some', value: a / b };

const compute = flatMap((x: number) => flatMap((y: number) => safeDivide(y, 2))(safeDivide(x, 3)))({
  tag: 'some',
  value: 100,
});
操作 类型签名 解决的问题
map (A→B) → F<A> → F<B> 在上下文中变换值
flatMap (A→F<B>) → F<A> → F<B> 链式上下文操作
pure/return A → F<A> 将值放入上下文
join/flatten F<F<A>> → F<A> 解除一层嵌套 


提示： flatMap = map + flatten。如果你理解了 map 会产生嵌套的问题，就理解了 Monad 存在的意义。flatMap 先 map，再 flatten（解除一层嵌套），得到的结果就是扁平的。






Monad 定律
每个合法的 Monad 必须满足三条定律：


-- 1. 左单位元律
return a >>= f  ==  f a

-- 2. 右单位元律
m >>= return  ==  m

-- 3. 结合律
(m >>= f) >>= g  ==  m >>= (\x -> f x >>= g)
const pure = <A>(a: A): Option<A> => ({ tag: 'some', value: a });

const f = (x: number): Option<string> => ({ tag: 'some', value: x.toString() });

const law1 = flatMap(f)(pure(5));
const law1b = f(5);

const m: Option<number> = { tag: 'some', value: 42 };
const law2 = flatMap(pure)(m);
const law2b = m;




定律
公式
含义





左单位元
pure(a).flatMap(f) === f(a)
pure 是 flatMap 的左单位元




右单位元
m.flatMap(pure) === m
pure 是 flatMap 的右单位元




结合律
m.flatMap(f).flatMap(g) === m.flatMap(x => f(x).flatMap(g))
链的分组不影响结果







提示： Monad 定律的本质是保证 flatMap 链可以自由重组而不改变结果。这就像数学中的结合律 (a+b)+c = a+(b+c)——它让你可以安全地重构 Monad 链。






do 语法与 async/await
Haskell 的 do 语法是 Monad 链式调用的语法糖，让代码看起来像命令式编程：


-- 用 >>= 链式调用
compute :: Maybe Double
compute = Just 100 >>= \x ->
          safeDivide x 3 >>= \y ->
          safeDivide y 2

-- 用 do 语法（等价）
compute :: Maybe Double
compute = do
  x <- Just 100
  y <- safeDivide x 3
  safeDivide y 2
const asyncCompute = async (): Promise<number> => {
  const x = await fetchNumber();
  const y = await processNumber(x);
  const z = await finalStep(y);
  return z;
};

Monad 的直觉模型
理解 Monad 最有效的方式是建立多种直觉模型：


const chainOption = <A, B>(ma: Option<A>, f: (a: A) => Option<B>): Option<B> => (ma.tag === 'none' ? ma : f(ma.value));

const chainArray = <A, B>(ma: A[], f: (a: A) => B[]): B[] => ma.flatMap(f);

const chainPromise = <A, B>(ma: Promise<A>, f: (a: A) => Promise<B>): Promise<B> => ma.then(f);

提示： Promise 的 .then() 实质上就是 Monad 的 flatMap——它接受一个返回 Promise 的函数，将两个异步操作串联起来，不会产生 Promise<Promise<T>> 嵌套。JavaScript 开发者其实每天都在使用 Monad。






小结
    

  • Monad 通过 flatMap 解决了 map 产生的嵌套上下文问题，实现链式计算。
    • 

  • 三条 Monad 定律保证 flatMap 链可以自由重组而不改变结果。
    • 

  • do 语法（Haskell）和 async/await（JS/TS）本质上都是 Monad 链的语法糖。
    • 

  • Promise 的 .then() 就是 flatMap——JavaScript 开发者每天都在使用 Monad。
    • 

  • Monad 的核心价值：将"如何处理上下文"与"如何处理值"彻底分离。
