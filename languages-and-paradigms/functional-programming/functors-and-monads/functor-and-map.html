函子与 map

什么是函子

函子（Functor）是一个实现了 map 操作的类型构造器。直觉上，Functor 是一个"容器"或"上下文"，map 允许你在不拆开容器的情况下变换其中的值。

class Functor f where
  fmap :: (a -> b) -> f a -> f b

instance Functor Maybe where
  fmap _ Nothing  = Nothing
  fmap f (Just x) = Just (f x)

instance Functor [] where
  fmap = map
type Functor<F> = {
  map: <A, B>(f: (a: A) => B) => (fa: F) => F;
};

const arrayMap =
  <A, B>(f: (a: A) => B) =>
  (xs: A[]): B[] =>
    xs.map(f);

const optionMap =
  <A, B>(f: (a: A) => B) =>
  (opt: Option<A>): Option<B> =>
    opt.tag === 'none' ? opt : { tag: 'some', value: f(opt.value) };
Functor 实例 容器含义 map 行为
Array 多个值 对每个元素应用 f
Option/Maybe 可能缺失的值 有值时应用 f，无值传播
Promise 异步值 在 resolve 后应用 f
Either/Result 可能失败的值 成功时应用 f，失败传播
Tree 树形结构中的值 对每个节点的值应用 f
IO 延迟执行的计算 组合计算步骤 


提示： 不要将 Functor 局限理解为"容器"——它更准确的含义是"计算上下文"。Promise 是异步上下文，IO 是副作用上下文，它们都是 Functor。






Functor 定律
每个合法的 Functor 必须满足两条定律，它们保证 map 的行为可预测：


-- 1. 恒等律：用 id 映射不改变结构
fmap id == id

-- 2. 组合律：映射组合 = 组合映射
fmap (f . g) == fmap f . fmap g
type Option<A> = { tag: 'none' } | { tag: 'some'; value: A };

const id = <A>(a: A): A => a;
const mapOpt =
  <A, B>(f: (a: A) => B) =>
  (opt: Option<A>): Option<B> =>
    opt.tag === 'none' ? opt : { tag: 'some', value: f(opt.value) };

const double = (x: number): number => x * 2;
const increment = (x: number): number => x + 1;

const val: Option<number> = { tag: 'some', value: 5 };
const law1a = mapOpt(id)(val);
const law1b = id(val);

const law2a = mapOpt((x: number) => increment(double(x)))(val);
const law2b = mapOpt(increment)(mapOpt(double)(val));




定律
公式
含义





恒等律
map(id) === id
map identity 不改变结构




组合律
map(f∘g) === map(f)∘map(g)
一次 map 等价于两次 map







提示： 如果一个"Functor"违反了这些定律，那么使用 map 就不再安全——你无法预测 map 的行为，等式推理也会失败。这就是为什么定律比接口更重要。






常见 Functor 实例
几乎所有函数式编程中的"容器类型"都是 Functor：


const arrayMap = <A, B>(f: (a: A) => B, xs: A[]): B[] => xs.map(f);

const promiseMap = <A, B>(f: (a: A) => B, p: Promise<A>): Promise<B> => p.then(f);

type Tree<A> = { type: 'leaf'; value: A } | { type: 'branch'; left: Tree<A>; right: Tree<A> };

const treeMap = <A, B>(f: (a: A) => B, tree: Tree<A>): Tree<B> =>
  tree.type === 'leaf'
    ? { type: 'leaf', value: f(tree.value) }
    : {
        type: 'branch',
        left: treeMap(f, tree.left),
        right: treeMap(f, tree.right),
      };
instance Functor ((->) r) where
  fmap f g = f . g

instance Functor IO where
  fmap f action = do
    x <- action
    return (f x)

Applicative Functor
Applicative Functor 在 Functor 的基础上增加了两个操作：pure（将值放入上下文）和 ap（在上下文中应用函数）。


class Functor f => Applicative f where
  pure :: a -> f a
  (<*>) :: f (a -> b) -> f a -> f b

-- 示例：Maybe Applicative
Just (+3) <*> Just 5     -- Just 8
Just (+3) <*> Nothing    -- Nothing
Nothing   <*> Just 5     -- Nothing
const pureMaybe = <A>(a: A): Option<A> => ({ tag: 'some', value: a });

const apMaybe = <A, B>(ff: Option<(a: A) => B>, fa: Option<A>): Option<B> =>
  ff.tag === 'none' || fa.tag === 'none' ? { tag: 'none' } : { tag: 'some', value: ff.value(fa.value) };

小结
    

  • Functor 是实现了 map 的类型构造器，允许在不拆开上下文的情况下变换内部值。
    • 

  • 恒等律和组合律是 Functor 的数学保证，确保 map 行为可预测。
    • 

  • Array、Maybe、Either、Promise、IO 等都是常见的 Functor 实例。
    • 

  • Applicative Functor 在 Functor 基础上增加了 pure 和 ap，支持多参数函数。
    • 

  • Functor 是理解 Monad 的必要前提——Monad 在 Functor 的能力上进一步增加了 flatMap。
