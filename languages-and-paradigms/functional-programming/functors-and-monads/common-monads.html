常见 Monad

Maybe / Option Monad

Maybe Monad 是最简单也最常用的 Monad，用于处理可能缺失的值。它的 flatMap 在遇到 Nothing/None 时短路，自动传播缺失。

lookupUser :: String -> Maybe User
lookupUser "alice" = Just (User "Alice" "alice@mail.com")
lookupUser _ = Nothing

lookupDomain :: String -> Maybe String
lookupDomain email = case break (== '@') email of
  (_, '@':domain) -> Just domain
  _ -> Nothing

getUserDomain :: String -> Maybe String
getUserDomain name = do
  user <- lookupUser name
  lookupDomain (userEmail user)
type Option<A> = { tag: 'none' } | { tag: 'some'; value: A };
const none: Option<never> = { tag: 'none' };
const some = <A>(a: A): Option<A> => ({ tag: 'some', value: a });

const bind = <A, B>(ma: Option<A>, f: (a: A) => Option<B>): Option<B> => (ma.tag === 'none' ? none : f(ma.value));

const findUser = (id: string): Option<{ name: string; email: string }> =>
  id === '1' ? some({ name: 'Alice', email: 'alice@mail.com' }) : none;

const getDomain = (email: string): Option<string> => {
  const at = email.indexOf('@');
  return at >= 0 ? some(email.slice(at + 1)) : none;
};

const getUserDomain = (id: string): Option<string> =>
  bind(
    bind(findUser(id), (u) => some(u.email)),
    getDomain,
  );


Either / Result Monad
Either Monad 在 Maybe 的基础上附加了错误信息，Left 通常表示错误，Right 表示成功：


data Either e a = Left e | Right a

parseJSON :: String -> Either String Value
validate :: Value -> Either String UserData
saveUser :: UserData -> Either String UserId

processRegistration :: String -> Either String UserId
processRegistration input = do
  value <- parseJSON input
  userData <- validate value
  saveUser userData
type Result<E, A> = { tag: 'err'; error: E } | { tag: 'ok'; value: A };

const bindResult = <E, A, B>(ma: Result<E, A>, f: (a: A) => Result<E, B>): Result<E, B> =>
  ma.tag === 'err' ? ma : f(ma.value);

const parseAge = (s: string): Result<string, number> => {
  const n = Number(s);
  return Number.isNaN(n) ? { tag: 'err', error: `Not a number: ${s}` } : { tag: 'ok', value: n };
};

const validateRange = (n: number): Result<string, number> =>
  n >= 0 && n <= 150 ? { tag: 'ok', value: n } : { tag: 'err', error: `Out of range: ${n}` };

IO Monad
IO Monad 将副作用封装为纯值，使副作用可被组合而不被立即执行：


main :: IO ()
main = do
  putStrLn "What is your name?"
  name <- getLine
  putStrLn ("Hello, " ++ name ++ "!")
type IO<A> = { run: () => A };

const ioOf = <A>(a: A): IO<A> => ({ run: () => a });

const ioMap =
  <A, B>(f: (a: A) => B) =>
  (io: IO<A>): IO<B> => ({ run: () => f(io.run()) });

const ioFlatMap =
  <A, B>(f: (a: A) => IO<B>) =>
  (io: IO<A>): IO<B> => ({ run: () => f(io.run()).run() });

const readLine: IO<string> = { run: () => 'Alice' };
const putStrLn = (s: string): IO<void> => ({
  run: () => console.log(s),
});

const program: IO<void> = ioFlatMap((name: string) => putStrLn(`Hello, ${name}!`))(readLine);

Reader Monad
Reader Monad 用于在计算链中传递共享的只读环境（如配置、依赖注入）：


type Reader r a = r -> a

ask :: Reader r r
ask = id

runReader :: Reader r a -> r -> a
runReader = id
type Reader<R, A> = (env: R) => A;

const readerOf =
  <R, A>(a: A): Reader<R, A> =>
  (_: R) =>
    a;

const readerMap =
  <R, A, B>(f: (a: A) => B) =>
  (ra: Reader<R, A>): Reader<R, B> =>
  (env: R) =>
    f(ra(env));

const readerFlatMap =
  <R, A, B>(f: (a: A) => Reader<R, B>) =>
  (ra: Reader<R, A>): Reader<R, B> =>
  (env: R) =>
    f(ra(env))(env);

type AppConfig = { apiUrl: string; timeout: number };

const getApiUrl: Reader<AppConfig, string> = (env) => env.apiUrl;
const getTimeout: Reader<AppConfig, number> = (env) => env.timeout;

const buildRequest: Reader<AppConfig, { url: string; timeout: number }> = (env) => ({
  url: getApiUrl(env),
  timeout: getTimeout(env),
});

提示： Reader Monad 本质上就是依赖注入的函数式实现。与 OOP 中通过构造函数注入依赖不同，Reader 通过函数参数传递环境——所有需要配置的函数都返回 Reader<Config, Result>。






小结
    

  • Maybe/Option Monad 处理值的缺失，flatMap 在 None 时自动短路。
    • 

  • Either/Result Monad 在 Maybe 基础上附加错误信息，实现"铁路导向编程"。
    • 

  • IO Monad 将副作用封装为纯值，使副作用可组合、可测试、引用透明。
    • 

  • Reader Monad 实现函数式的依赖注入，在计算链中传递共享的只读环境。
    • 

  • 选择哪个 Monad 取决于计算的"上下文"：缺失、错误、副作用、环境还是状态。
