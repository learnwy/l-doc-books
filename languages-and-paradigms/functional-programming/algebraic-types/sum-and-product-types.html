Part III · 范式与文本函数式编程 简介代数类型 简介和类型与积类型

和类型与积类型

代数数据类型概述

代数数据类型（Algebraic Data Type，ADT）用代数运算来描述类型的构造方式。"代数"意味着类型的可能取值数量可以通过加法和乘法计算得出。这套体系让类型建模变得既精确又系统化。

data Bool = True | False           -- 和类型：2 个值

data Pair a b = MkPair a b        -- 积类型：|a| × |b| 个值

data Maybe a = Nothing | Just a   -- 和类型 + 积类型：1 + |a| 个值
type Bool = true | false; // 和类型：2 个值

type Pair<A, B> = { fst: A; snd: B }; // 积类型：|A| × |B| 个值

type Maybe<A> = { tag: 'nothing' } | { tag: 'just'; value: A };

| 运算 | 类型构造 | 值的数量 | 类比 | | --------- | ---------- | -------- | ------ | --- | --- | --- | -------- | | 加法（+） | 和类型 | | A | + | B | | 逻辑 OR | | 乘法（×） | 积类型 | | A | × | B | | 逻辑 AND | | 幂（^） | 函数类型 | | B | ^ | A | | 映射 | | 0 | Never/Void | 0 个值 | 不可能 | | 1 | Unit/void | 1 个值 | 无信息 |



提示： 为什么叫"代数"数据类型？因为类型的取值空间遵循与自然数相同的代数规律。比如分配律 A × (B + C) = A × B + A × C 在类型层面完全成立。






和类型
和类型（Sum Type）表示一个值可以是几种类型中的某一种——"这个或那个"。它的取值空间是各成员取值空间之和。


data Shape
  = Circle Double
  | Rectangle Double Double
  | Triangle Double Double Double

data Color = Red | Green | Blue  -- 3 个值
type Shape =
  | { kind: 'circle'; radius: number }
  | { kind: 'rectangle'; width: number; height: number }
  | { kind: 'triangle'; a: number; b: number; c: number };

type Direction = 'north' | 'south' | 'east' | 'west';
| 和类型示例    | 取值数量           | 语言表达方式 |
| ------------- | ------------------ | ------------ | ---------- | --- | --- | ------- | -------- |
| Bool        | true + false = 2 | 枚举         |
| Maybe<Bool> | 1 + 2 = 3        | Nothing     | Just Bool |
| Either<A,B> |                  | A            | +          | B   |   | Left A | Right B |
| Direction   | 4                | 字面量联合   |




积类型
积类型（Product Type）表示一个值同时包含多个类型的数据——"这个和那个"。它的取值空间是各成员取值空间之积。


data Point = Point Double Double           -- |Double| × |Double|

data Person = Person
  { name :: String
  , age  :: Int
  , email :: String
  }
type Point = { x: number; y: number };

type Person = {
  name: string;
  age: number;
  email: string;
};

type Tuple3<A, B, C> = [A, B, C];
| 积类型示例            | 取值数量    | 结构   |
| --------------------- | ----------- | ------ | --- | ------ | --- | ---- |
| (Bool, Bool)        | 2 × 2 = 4 | 元组   |
| { x: Bool, y: Bool} | 2 × 2 = 4 | 记录   |
| (Bool, Direction)   | 2 × 4 = 8 | 元组   |
| Point               |           | number | ×   | number |   | 记录 |




提示： 对象/结构体/记录都是积类型。TypeScript 的 interface 和 type 对象字面量本质上都在定义积类型——一个值必须同时包含所有声明的字段。






代数定律
类型的代数运算遵循与自然数相同的定律：


// 分配律：A × (B | C) ≅ (A × B) | (A × C)
type Left<A, B, C> = { a: A; bc: B | C };
type Right<A, B, C> = { a: A; bc: B } | { a: A; bc: C };

// 幂律：(A → B) → C ≅ A → B → C
type Curried<A, B, C> = (a: A) => (b: B) => C;
type Uncurried<A, B, C> = (ab: [A, B]) => C;

// 单位元：A × 1 ≅ A，A + 0 ≅ A
type WithUnit = { value: string; unit: void };
type WithNever = string | never;

建模实践
利用和类型与积类型可以精确建模领域问题，通过类型系统排除非法状态：


type LoadingState<T> =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'success'; data: T }
  | { status: 'error'; error: Error };

type PaymentMethod =
  | { type: 'credit-card'; number: string; expiry: string; cvv: string }
  | { type: 'paypal'; email: string }
  | { type: 'bank-transfer'; iban: string; bic: string };

const processPayment = (method: PaymentMethod): string => {
  switch (method.type) {
    case 'credit-card':
      return `Charging card ending in ${method.number.slice(-4)}`;
    case 'paypal':
      return `Redirecting to PayPal for ${method.email}`;
    case 'bank-transfer':
      return `Initiating transfer to ${method.iban}`;
  }
};

小结
    

  • 和类型表示"或"关系，取值空间是各成员之和；积类型表示"与"关系，取值空间是各成员之积。
    • 

  • 类型的代数运算遵循与自然数相同的定律，如交换律、结合律和分配律。
    • 

  • 精确的类型建模可以在编译时排除非法状态，是"Make Illegal States Unrepresentable"原则的基础。
    • 

  • 和类型在状态管理、支付方式、API 响应等场景中广泛用于建模有限的可能性集合。
    • 

  • Never（零类型）和 void（单位类型）分别充当加法零元素和乘法单位元。
