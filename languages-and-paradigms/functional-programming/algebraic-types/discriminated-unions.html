可辨识联合

什么是可辨识联合

可辨识联合（Discriminated Union），也叫标签联合（Tagged Union），是 TypeScript 中实现和类型的惯用方式。它通过一个共有的字面量类型字段（判别属性）来区分不同变体，让编译器进行类型收窄。

type Circle = { kind: 'circle'; radius: number };
type Rectangle = { kind: 'rectangle'; width: number; height: number };
type Triangle = { kind: 'triangle'; a: number; b: number; c: number };

type Shape = Circle | Rectangle | Triangle;

const area = (shape: Shape): number => {
  switch (shape.kind) {
    case 'circle':
      return Math.PI * shape.radius ** 2;
    case 'rectangle':
      return shape.width * shape.height;
    case 'triangle': {
      const s = (shape.a + shape.b + shape.c) / 2;
      return Math.sqrt(s * (s - shape.a) * (s - shape.b) * (s - shape.c));
    }
  }
};

提示： 判别属性的命名没有硬性规定，但社区常用 kind、type、tag 或 _tag。关键是它的类型必须是字符串字面量类型（或数字字面量类型），而不是宽泛的 string。






类型收窄机制
TypeScript 的类型收窄（Narrowing）是可辨识联合工作的核心。当你通过判别属性进行分支时，编译器自动将联合类型收窄为具体变体。


type ApiResponse<T> =
  | { status: 'success'; data: T; timestamp: number }
  | { status: 'error'; error: string; code: number }
  | { status: 'loading' };

const handleResponse = <T>(response: ApiResponse<T>): string => {
  if (response.status === 'success') {
    return `Data: ${JSON.stringify(response.data)}`;
  }
  if (response.status === 'error') {
    return `Error ${response.code}: ${response.error}`;
  }
  return 'Loading...';
};

穷尽检查
确保所有变体都被处理是可辨识联合的关键安全保障。TypeScript 通过 never 类型实现穷尽检查：


type Action = { type: 'INCREMENT'; amount: number } | { type: 'DECREMENT'; amount: number } | { type: 'RESET' };

const assertNever = (x: never): never => {
  throw new Error(`Unexpected value: ${JSON.stringify(x)}`);
};

const reducer = (state: number, action: Action): number => {
  switch (action.type) {
    case 'INCREMENT':
      return state + action.amount;
    case 'DECREMENT':
      return state - action.amount;
    case 'RESET':
      return 0;
    default:
      return assertNever(action);
  }
};

提示： 当你添加新的 Action 类型时，所有使用 assertNever 的 switch 语句都会产生编译错误，迫使你更新每个处理分支。这就是可辨识联合配合穷尽检查的核心价值。






实战模式
可辨识联合在日常开发中有大量应用场景：


type AsyncData<T> =
  | { state: 'idle' }
  | { state: 'loading'; startedAt: number }
  | { state: 'success'; data: T; loadedAt: number }
  | { state: 'error'; error: Error; failedAt: number };

type TreeNode<T> = { type: 'leaf'; value: T } | { type: 'branch'; left: TreeNode<T>; right: TreeNode<T> };

const treeSum = (node: TreeNode<number>): number => {
  switch (node.type) {
    case 'leaf':
      return node.value;
    case 'branch':
      return treeSum(node.left) + treeSum(node.right);
  }
};

type Expr =
  | { type: 'literal'; value: number }
  | { type: 'add'; left: Expr; right: Expr }
  | { type: 'mul'; left: Expr; right: Expr }
  | { type: 'neg'; operand: Expr };

const evaluate = (expr: Expr): number => {
  switch (expr.type) {
    case 'literal':
      return expr.value;
    case 'add':
      return evaluate(expr.left) + evaluate(expr.right);
    case 'mul':
      return evaluate(expr.left) * evaluate(expr.right);
    case 'neg':
      return -evaluate(expr.operand);
  }
};

提示： TypeScript 的可辨识联合虽然没有 Rust/Haskell 的 ADT 那么强大（缺少深层模式匹配），但已经足以处理绝大多数实际场景。配合 ts-pattern 库可以获得接近原生模式匹配的体验。






小结
    

  • 可辨识联合通过共有的字面量类型判别属性实现类型安全的分支处理。
    • 

  • TypeScript 的类型收窄在分支后自动推断具体类型，IDE 提供精确的代码补全。
    • 

  • 穷尽检查通过 never 类型确保所有变体都被处理，添加新变体时编译器会报错。
    • 

  • 可辨识联合广泛用于异步状态、Redux Action、AST 节点等场景。
    • 

  • 虽然 TypeScript 的 ADT 不如 Rust/Haskell 强大，但配合 ts-pattern 可获得接近原生的体验。
