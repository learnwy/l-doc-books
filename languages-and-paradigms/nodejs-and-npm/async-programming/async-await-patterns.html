Async/Await 模式

Async/Await 的本质

async/await 是 ES2017 引入的语法糖，建立在 Promise 之上。async 函数总是返回一个 Promise，await 表达式暂停函数执行，等待 Promise 解决后继续。它让异步代码的编写和阅读方式与同步代码几乎一致。

基本语法
import fs from 'node:fs/promises';

async function processConfig(): Promise<void> {
  const configText = await fs.readFile('config.json', 'utf-8');
  const config = JSON.parse(configText);
  const data = await fs.readFile(config.dataFile, 'utf-8');
  const result = transform(data);
  await fs.writeFile('output.json', JSON.stringify(result, null, 2));
  console.log('处理完成');
}

function transform(data: string): Record<string, unknown> {
  return { content: data, processedAt: new Date().toISOString() };
}
对比 Promise 链，async/await 消除了 .then() 的链式调用，代码结构更接近直觉。


async 函数的返回值
async function returnsValue(): Promise<number> {
  return 42;
}

async function returnsPromise(): Promise<string> {
  return Promise.resolve('hello');
}

async function throwsError(): Promise<never> {
  throw new Error('something went wrong');
}
三种情况的处理方式：


    

  • 返回普通值 → 自动包装为 Promise.resolve(value)
    • 

  • 返回 Promise → 直接返回该 Promise（不会双重包装）
    • 

  • 抛出异常 → 自动包装为 Promise.reject(error)
    • 





错误处理策略
try/catch 基本模式
async function safeRead(path: string): Promise<string | null> {
  try {
    return await fs.readFile(path, 'utf-8');
  } catch (err) {
    if ((err as NodeJS.ErrnoException).code === 'ENOENT') {
      console.log(`文件不存在: ${path}`);
      return null;
    }
    throw err;
  }
}
包装函数避免重复 try/catch
type Result<T> = { ok: true; value: T } | { ok: false; error: Error };

async function attempt<T>(fn: () => Promise<T>): Promise<Result<T>> {
  try {
    const value = await fn();
    return { ok: true, value };
  } catch (error) {
    return { ok: false, error: error as Error };
  }
}

async function main(): Promise<void> {
  const result = await attempt(() => fs.readFile('data.json', 'utf-8'));

  if (result.ok) {
    console.log('内容:', result.value);
  } else {
    console.error('读取失败:', result.error.message);
  }
}
错误类型区分
class HttpError extends Error {
  constructor(
    public statusCode: number,
    message: string,
  ) {
    super(message);
    this.name = 'HttpError';
  }
}

class ValidationError extends Error {
  constructor(
    public field: string,
    message: string,
  ) {
    super(message);
    this.name = 'ValidationError';
  }
}

async function handleRequest(url: string): Promise<void> {
  try {
    const response = await fetch(url);
    if (!response.ok) {
      throw new HttpError(response.status, response.statusText);
    }
    const data = await response.json();
    if (!data.name) {
      throw new ValidationError('name', 'name 字段不能为空');
    }
  } catch (err) {
    if (err instanceof HttpError) {
      console.error(`HTTP 错误 ${err.statusCode}: ${err.message}`);
    } else if (err instanceof ValidationError) {
      console.error(`验证错误 [${err.field}]: ${err.message}`);
    } else {
      throw err;
    }
  }
}


并发控制
并行执行：Promise.all + await
async function fetchUserDashboard(userId: string): Promise<{
  profile: unknown;
  orders: unknown;
  recommendations: unknown;
}> {
  const [profile, orders, recommendations] = await Promise.all([
    fetchProfile(userId),
    fetchOrders(userId),
    fetchRecommendations(userId),
  ]);

  return { profile, orders, recommendations };
}

async function fetchProfile(id: string): Promise<unknown> {
  return { id, name: '用户' };
}
async function fetchOrders(id: string): Promise<unknown> {
  return [];
}
async function fetchRecommendations(id: string): Promise<unknown> {
  return [];
}
并发数限制
当需要处理大量异步任务但又不想同时发起过多请求时，需要限制并发数：


async function parallelLimit<T>(tasks: (() => Promise<T>)[], concurrency: number): Promise<T[]> {
  const results: T[] = [];
  let index = 0;

  async function worker(): Promise<void> {
    while (index < tasks.length) {
      const currentIndex = index++;
      results[currentIndex] = await tasks[currentIndex]();
    }
  }

  const workers = Array.from({ length: Math.min(concurrency, tasks.length) }, () => worker());
  await Promise.all(workers);

  return results;
}

const urls = Array.from({ length: 100 }, (_, i) => `https://api.example.com/item/${i}`);
const tasks = urls.map((url) => () => fetch(url).then((r) => r.json()));

const results = await parallelLimit(tasks, 5);
串行执行
有时候需要严格按照顺序执行异步操作：


async function serialProcess<T, R>(items: T[], processor: (item: T) => Promise<R>): Promise<R[]> {
  const results: R[] = [];
  for (const item of items) {
    results.push(await processor(item));
  }
  return results;
}


异步迭代器
ES2018 引入了异步迭代器协议，与 for await...of 配合使用，适合处理异步数据源：


async function* generatePages(baseUrl: string): AsyncGenerator<unknown[]> {
  let page = 1;
  let hasMore = true;

  while (hasMore) {
    const response = await fetch(`${baseUrl}?page=${page}`);
    const data = await response.json();
    yield data.items;
    hasMore = data.hasNextPage;
    page++;
  }
}

async function processAllPages(): Promise<void> {
  for await (const items of generatePages('https://api.example.com/list')) {
    for (const item of items as unknown[]) {
      console.log('处理项:', item);
    }
  }
}
将事件转换为异步迭代
import { on } from 'node:events';
import { createServer } from 'node:http';

async function handleRequests(): Promise<void> {
  const server = createServer();
  server.listen(3000);

  for await (const [req, res] of on(server, 'request')) {
    res.end('Hello World\n');
  }
}


顶级 await
在 ESM 模块中，可以在模块的顶层使用 await，无需包装在 async 函数中：


import fs from 'node:fs/promises';

const config = JSON.parse(await fs.readFile('config.json', 'utf-8'));

const connection = await initDatabase(config.database);

export { config, connection };

async function initDatabase(dbConfig: Record<string, string>): Promise<unknown> {
  return { connected: true, host: dbConfig.host };
}
顶级 await 会使导入该模块的模块也变成异步的——整个模块图的加载顺序会受到影响。




常见陷阱
忘记 await
async function dangerousCode(): Promise<void> {
  const data = fs.readFile('data.txt', 'utf-8');
  console.log(typeof data);
}
循环中的 await
async function slowSequential(ids: string[]): Promise<unknown[]> {
  const results: unknown[] = [];
  for (const id of ids) {
    results.push(await fetchById(id));
  }
  return results;
}

async function fastParallel(ids: string[]): Promise<unknown[]> {
  return Promise.all(ids.map((id) => fetchById(id)));
}

async function fetchById(id: string): Promise<unknown> {
  return { id };
}
async 函数中 return 与 return await
async function withReturnAwait(): Promise<string> {
  try {
    return await riskyOperation();
  } catch (err) {
    console.error('捕获到错误:', (err as Error).message);
    return 'fallback';
  }
}

async function withoutAwait(): Promise<string> {
  try {
    return riskyOperation();
  } catch (err) {
    console.error('这里永远不会执行');
    return 'fallback';
  }
}

async function riskyOperation(): Promise<string> {
  throw new Error('操作失败');
}
在 try/catch 块中，return await 会在当前函数的上下文中等待 Promise，使得 catch 块能够捕获错误。而直接 return 一个 Promise 则会跳过 catch 块。




小结
    

  • async/await 是 Promise 的语法糖，让异步代码具有同步代码的可读性。
    • 

  • 使用 try/catch 进行错误处理，用自定义错误类区分不同类型的异常。
    • 

  • Promise.all + await 实现并行执行，循环中的 await 是串行执行。
    • 

  • 并发数限制是生产环境的必备模式，防止资源耗尽。
    • 

  • 异步迭代器（for await...of）是处理异步数据流的现代方式。
    • 

  • 注意常见陷阱：忘记 await、循环串行化、return vs return await。
    •
