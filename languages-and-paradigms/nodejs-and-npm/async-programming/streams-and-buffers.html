Stream 与 Buffer

Buffer 基础

Buffer 是 Node.js 中用于处理二进制数据的核心类型。它是一块分配在 V8 堆外的固定大小内存区域，适合处理文件 I/O、网络数据包、加密操作等场景。

创建 Buffer

const buf1 = Buffer.alloc(16);

const buf2 = Buffer.allocUnsafe(16);

const buf3 = Buffer.from('你好，Node.js', 'utf-8');

const buf4 = Buffer.from([0x48, 0x65, 0x6c, 0x6c, 0x6f]);

console.log(buf3.toString('utf-8'));
console.log(buf4.toString('ascii'));
console.log(buf3.toString('base64'));
方法 初始化 性能 安全性 适用场景
Buffer.alloc 零填充 较慢 安全 需要确定初始值时
Buffer.allocUnsafe 不初始化 更快 不安全 会立即覆写全部内容时
Buffer.from 拷贝数据 中等 安全 从已有数据创建时

Buffer 操作

const source = Buffer.from('Hello World');

const target = Buffer.alloc(5);
source.copy(target, 0, 0, 5);
console.log(target.toString());

const sliced = source.subarray(0, 5);
console.log(sliced.toString());

const combined = Buffer.concat([Buffer.from('Hello'), Buffer.from(' '), Buffer.from('World')]);
console.log(combined.toString());

const buf = Buffer.alloc(8);
buf.writeUInt32BE(0x01020304, 0);
buf.writeUInt32LE(0x05060708, 4);
console.log(buf);

Stream 概述

Stream 是 Node.js 中处理流式数据的抽象接口。它的核心思想是增量处理：不需要将全部数据加载到内存中，而是以"块"为单位逐步处理。

Node.js 提供四种基本 Stream 类型：

为什么使用 Stream？
import fs from 'node:fs';

function copyFileNaive(src: string, dest: string): void {
  const content = fs.readFileSync(src);
  fs.writeFileSync(dest, content);
}

function copyFileStream(src: string, dest: string): Promise<void> {
  return new Promise((resolve, reject) => {
    const readStream = fs.createReadStream(src);
    const writeStream = fs.createWriteStream(dest);

    readStream.pipe(writeStream);
    writeStream.on('finish', resolve);
    writeStream.on('error', reject);
    readStream.on('error', reject);
  });
}
对于 2GB 的大文件，readFileSync 会尝试将整个文件加载到内存中（大概率导致内存溢出），而 Stream 只需要占用极少的内存（默认 highWaterMark 为 64KB）。




Readable Stream
两种消费模式
Readable Stream 有两种工作模式：流动模式（Flowing）和暂停模式（Paused）。


import fs from 'node:fs';

const stream = fs.createReadStream('large-file.log', {
  encoding: 'utf-8',
  highWaterMark: 64 * 1024,
});

stream.on('data', (chunk: string) => {
  console.log(`收到 ${chunk.length} 个字符`);
});

stream.on('end', () => {
  console.log('读取完成');
});

stream.on('error', (err: Error) => {
  console.error('读取错误:', err.message);
});
import fs from 'node:fs';

const stream = fs.createReadStream('data.bin');

stream.on('readable', () => {
  let chunk: Buffer | null;
  while ((chunk = stream.read()) !== null) {
    console.log(`读取到 ${chunk.length} 字节`);
  }
});
自定义 Readable Stream
import { Readable, ReadableOptions } from 'node:stream';

class CounterStream extends Readable {
  private current: number;
  private max: number;

  constructor(max: number, opts?: ReadableOptions) {
    super(opts);
    this.current = 0;
    this.max = max;
  }

  _read(): void {
    if (this.current <= this.max) {
      const str = `${this.current}\n`;
      this.push(str);
      this.current++;
    } else {
      this.push(null);
    }
  }
}

const counter = new CounterStream(10);
counter.pipe(process.stdout);


Writable Stream
import fs from 'node:fs';

const writeStream = fs.createWriteStream('output.log');

for (let i = 0; i < 1000000; i++) {
  const canContinue = writeStream.write(`日志行 ${i}\n`);
  if (!canContinue) {
    await new Promise<void>((resolve) => writeStream.once('drain', resolve));
  }
}

writeStream.end('写入完成\n');
背压机制
背压（Backpressure）是 Stream 系统中最重要的概念之一。当写入速度超过消费速度时，背压机制会通知生产者减速：


pipe() 方法自动处理背压，这是使用 pipe 的最大好处：


import fs from 'node:fs';
import zlib from 'node:zlib';

fs.createReadStream('input.txt')
  .pipe(zlib.createGzip())
  .pipe(fs.createWriteStream('input.txt.gz'))
  .on('finish', () => console.log('压缩完成'));


Transform Stream
Transform Stream 是一种特殊的 Duplex Stream，它对输入数据进行转换后输出：


import { Transform, TransformCallback } from 'node:stream';

class UpperCaseTransform extends Transform {
  _transform(chunk: Buffer, encoding: string, callback: TransformCallback): void {
    this.push(chunk.toString().toUpperCase());
    callback();
  }
}

class JsonLineParser extends Transform {
  private buffer: string = '';

  constructor() {
    super({ objectMode: true });
  }

  _transform(chunk: Buffer, encoding: string, callback: TransformCallback): void {
    this.buffer += chunk.toString();
    const lines = this.buffer.split('\n');
    this.buffer = lines.pop() || '';

    for (const line of lines) {
      if (line.trim()) {
        try {
          this.push(JSON.parse(line));
        } catch {
          this.emit('error', new Error(`无法解析 JSON: ${line}`));
        }
      }
    }
    callback();
  }

  _flush(callback: TransformCallback): void {
    if (this.buffer.trim()) {
      try {
        this.push(JSON.parse(this.buffer));
      } catch {
        this.emit('error', new Error(`无法解析 JSON: ${this.buffer}`));
      }
    }
    callback();
  }
}


pipeline 与现代 Stream API
Node.js 提供了 stream.pipeline 函数来替代手动 pipe 链接，它自动处理错误传播和资源清理：


import { pipeline } from 'node:stream/promises';
import fs from 'node:fs';
import zlib from 'node:zlib';

async function compressFile(input: string, output: string): Promise<void> {
  await pipeline(fs.createReadStream(input), zlib.createGzip(), fs.createWriteStream(output));
  console.log('压缩完成');
}

async function processLogFile(logPath: string): Promise<Map<string, number>> {
  const stats = new Map<string, number>();

  await pipeline(
    fs.createReadStream(logPath, { encoding: 'utf-8' }),
    new Transform({
      objectMode: true,
      transform(chunk: string, encoding, callback) {
        const lines = chunk.split('\n').filter((l: string) => l.trim());
        for (const line of lines) {
          this.push(line);
        }
        callback();
      },
    }),
    new Writable({
      objectMode: true,
      write(line: string, encoding, callback) {
        const level = line.match(/\[(INFO|WARN|ERROR)\]/)?.[1] || 'UNKNOWN';
        stats.set(level, (stats.get(level) || 0) + 1);
        callback();
      },
    }),
  );

  return stats;
}
Web Streams API
Node.js 18+ 也支持 Web 标准的 Streams API，与浏览器保持一致：


import { ReadableStream, WritableStream, TransformStream } from 'node:stream/web';

const readable = new ReadableStream({
  start(controller) {
    controller.enqueue('Hello ');
    controller.enqueue('World');
    controller.close();
  },
});

const transform = new TransformStream({
  transform(chunk, controller) {
    controller.enqueue((chunk as string).toUpperCase());
  },
});

const writable = new WritableStream({
  write(chunk) {
    process.stdout.write(chunk as string);
  },
});

await readable.pipeThrough(transform).pipeTo(writable);


实战：HTTP 文件下载
import { createWriteStream } from 'node:fs';
import { pipeline } from 'node:stream/promises';
import { Transform } from 'node:stream';

async function downloadWithProgress(url: string, dest: string): Promise<void> {
  const response = await fetch(url);
  if (!response.ok || !response.body) {
    throw new Error(`下载失败: ${response.status}`);
  }

  const totalSize = Number(response.headers.get('content-length') || 0);
  let downloadedSize = 0;

  const progressTracker = new Transform({
    transform(chunk: Buffer, encoding, callback) {
      downloadedSize += chunk.length;
      if (totalSize > 0) {
        const percent = ((downloadedSize / totalSize) * 100).toFixed(1);
        process.stdout.write(`\r下载进度: ${percent}%`);
      }
      callback(null, chunk);
    },
  });

  const { Readable } = await import('node:stream');
  const nodeStream = Readable.fromWeb(response.body as import('stream/web').ReadableStream);

  await pipeline(nodeStream, progressTracker, createWriteStream(dest));
  console.log('\n下载完成');
}


小结
    

  • Buffer 是 Node.js 中处理二进制数据的核心类型，分配在 V8 堆外。
    • 

  • Stream 以增量方式处理数据，适合大文件和网络传输场景。
    • 

  • 四种 Stream 类型：Readable、Writable、Duplex、Transform。
    • 

  • 背压机制（Backpressure）是 Stream 系统的关键设计，pipe() 自动处理背压。
    • 

  • 推荐使用 stream.pipeline 替代手动 pipe，它自动处理错误传播和资源清理。
    • 

  • Node.js 18+ 同时支持 Node Stream 和 Web Streams API。
