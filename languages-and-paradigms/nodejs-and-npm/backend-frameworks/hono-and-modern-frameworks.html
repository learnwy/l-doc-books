Hono 与现代框架

核心概念

现代 Web 框架的驱动因素只有一个：运行时不再只有 Node.js。Deno、Bun、Cloudflare Workers、Vercel Edge 相继出现，而 Express/Koa 的设计深度绑定 Node.js 的 req/res。

  • Web 标准优先：Hono 基于 Request/Response/fetch 构建，同一份代码可以部署到所有支持 Web 标准的运行时——"写一次，处处运行"。
  • 轻量与快：核心极小，无重型依赖，适合 Edge 环境的冷启动约束。
  • 类型安全：内置对请求验证与响应类型的支持，减少运行时的类型擦除损失。
  • Fastify：留在 Node.js 阵营、以性能优先的另一种选择，用 JSON Schema 做校验与序列化优化。
  • 选型依据：是否要多运行时部署、是否受 Edge 约束、对类型安全与性能的具体要求。

为什么需要新框架

Express 和 Koa 诞生于 Node.js 早期，它们的设计深度绑定了 Node.js 的原生 API（req、res 对象）。而如今 JavaScript 运行时百花齐放——Node.js、Deno、Bun、Cloudflare Workers、Vercel Edge——新一代框架需要适应这个多运行时的世界。

Hono：超快的多运行时 Web 框架

Hono（日语"炎"🔥）是一个基于 Web 标准 API（Request、Response、fetch）构建的超轻量 Web 框架。它的核心理念：写一次，处处运行。

基础用法

import { Hono } from 'hono';
import { serve } from '@hono/node-server';

const app = new Hono();

app.get('/', (c) => {
  return c.json({ message: 'Hello Hono' });
});

app.get('/api/users/:id', (c) => {
  const id = c.req.param('id');
  const fields = c.req.query('fields');
  return c.json({ id, fields });
});

app.post('/api/users', async (c) => {
  const body = await c.req.json();
  return c.json({ id: crypto.randomUUID(), ...body }, 201);
});

serve({ fetch: app.fetch, port: 3000 });

路由组

import { Hono } from 'hono';

const users = new Hono();

users.get('/', (c) => c.json({ users: [] }));
users.get('/:id', (c) => c.json({ id: c.req.param('id') }));
users.post('/', async (c) => {
  const body = await c.req.json();
  return c.json(body, 201);
});

const posts = new Hono();

posts.get('/', (c) => c.json({ posts: [] }));
posts.get('/:id', (c) => c.json({ id: c.req.param('id') }));

const app = new Hono();
app.route('/api/users', users);
app.route('/api/posts', posts);

export default app;

内置中间件

Hono 提供了丰富的内置中间件，无需安装额外包：

import { Hono } from 'hono';
import { cors } from 'hono/cors';
import { logger } from 'hono/logger';
import { prettyJSON } from 'hono/pretty-json';
import { secureHeaders } from 'hono/secure-headers';
import { timing } from 'hono/timing';
import { compress } from 'hono/compress';
import { etag } from 'hono/etag';
import { bearerAuth } from 'hono/bearer-auth';

const app = new Hono();

app.use('*', logger());
app.use('*', cors({ origin: 'https://example.com' }));
app.use('*', secureHeaders());
app.use('*', timing());
app.use('*', compress());
app.use('*', etag());
app.use('*', prettyJSON());

app.use('/api/admin/*', bearerAuth({ token: process.env.ADMIN_TOKEN! }));

app.get('/', (c) => c.json({ ok: true }));

export default app;

类型安全的请求验证

Hono 与 Zod 深度集成，提供端到端的类型安全：

import { Hono } from 'hono';
import { zValidator } from '@hono/zod-validator';
import { z } from 'zod';

const createUserSchema = z.object({
  name: z.string().min(2).max(50),
  email: z.string().email(),
  age: z.number().int().min(0).max(150).optional(),
});

const querySchema = z.object({
  page: z.coerce.number().int().min(1).default(1),
  limit: z.coerce.number().int().min(1).max(100).default(20),
});

const app = new Hono();

app.get('/api/users', zValidator('query', querySchema), (c) => {
  const { page, limit } = c.req.valid('query');
  return c.json({ page, limit, users: [] });
});

app.post('/api/users', zValidator('json', createUserSchema), (c) => {
  const userData = c.req.valid('json');
  return c.json({ id: crypto.randomUUID(), ...userData }, 201);
});

export default app;

Fastify：性能优先的 Node.js 框架

Fastify 是一个专注于性能的 Node.js Web 框架，通过 Schema-based 的序列化和验证实现了极高的吞吐量。

import Fastify from 'fastify';

const fastify = Fastify({
  logger: true,
});

const getUserSchema = {
  params: {
    type: 'object' as const,
    properties: {
      id: { type: 'string' },
    },
    required: ['id'],
  },
  response: {
    200: {
      type: 'object' as const,
      properties: {
        id: { type: 'string' },
        name: { type: 'string' },
        email: { type: 'string' },
      },
    },
  },
};

fastify.get('/api/users/:id', { schema: getUserSchema }, async (request, reply) => {
  const { id } = request.params as { id: string };
  return { id, name: '张三', email: 'zhangsan@example.com' };
});

fastify.post('/api/users', async (request, reply) => {
  const body = request.body as { name: string; email: string };
  reply.status(201);
  return { id: crypto.randomUUID(), ...body };
});

await fastify.listen({ port: 3000, host: '0.0.0.0' });

Fastify 的独特之处在于使用 JSON Schema 来验证请求和预编译响应序列化函数——它在启动时生成专门的序列化代码，比 JSON.stringify 快 2-3 倍。

推荐场景

const frameworkRecommendations = {
  Express: '成熟项目、需要丰富中间件生态、团队熟悉',
  Koa: '中等规模项目、偏好洋葱模型、需要精细控制',
  Hono: 'Edge 函数、多运行时部署、新项目、全栈 TypeScript',
  Fastify: '高吞吐 API 服务、微服务、对延迟敏感的场景',
};

小结

  • 现代框架趋势：基于 Web 标准 API、TypeScript 原生支持、多运行时兼容。
  • Hono 基于 Web 标准（Request/Response），可在 Node.js、Deno、Bun、Edge 等运行时运行。
  • Hono 内置丰富中间件，与 Zod 深度集成实现端到端类型安全。
  • Fastify 通过 JSON Schema 预编译序列化函数，实现最优的 JSON 响应性能。
  • 框架选择取决于：部署目标（单/多运行时）、性能需求、团队经验、生态需求。
