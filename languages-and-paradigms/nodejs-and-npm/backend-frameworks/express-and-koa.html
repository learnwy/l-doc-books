Express 与 Koa

核心概念

Express 与 Koa 出自同一团队，代表了 Web 框架设计的两代思路：

  • Express：以"极简、灵活、无偏见"为理念，内置路由、中间件、错误处理，通过 req/res 直接暴露 Node.js 原生对象。生态最庞大，学习成本最低。
  • Koa：剥离了路由和内置中间件，只保留中间件内核，用 async/await 与 Context 对象取代回调式中间件。核心差异是洋葱模型——中间件可以同时处理请求和响应两个方向。
  • 错误处理：Express 依赖四参数错误中间件和同步/异步的错误传递约定；Koa 直接 try/catch 包裹 await next()，语义更统一。
  • 选择依据：需要庞大生态和成熟方案时选 Express；需要干净的异步中间件和精细控制时选 Koa。

Express：Node.js Web 框架的事实标准

Express 是 Node.js 生态中最流行的 Web 框架，自 2010 年发布至今已有超过十年的历史。它以"极简、灵活、无偏见"为设计理念，提供了构建 Web 应用所需的基础抽象，同时保持足够的灵活性让开发者自由选择架构和第三方库。

基础应用

import express, { Request, Response, NextFunction } from 'express';

const app = express();

app.use(express.json());
app.use(express.urlencoded({ extended: true }));

app.get('/', (req: Request, res: Response) => {
  res.json({ message: 'Hello Express' });
});

app.get('/api/users/:id', (req: Request, res: Response) => {
  const { id } = req.params;
  const { fields } = req.query;
  res.json({ id, fields });
});

app.post('/api/users', (req: Request, res: Response) => {
  const userData = req.body;
  res.status(201).json({ id: 'new-id', ...userData });
});

app.listen(3000, () => {
  console.log('Express 服务运行在 http://localhost:3000');
});

路由组织

import express, { Router, Request, Response } from 'express';

const userRouter = Router();

userRouter.get('/', (req: Request, res: Response) => {
  res.json({ users: [] });
});

userRouter.get('/:id', (req: Request, res: Response) => {
  res.json({ user: { id: req.params.id } });
});

userRouter.post('/', (req: Request, res: Response) => {
  res.status(201).json({ user: req.body });
});

userRouter.put('/:id', (req: Request, res: Response) => {
  res.json({ user: { id: req.params.id, ...req.body } });
});

userRouter.delete('/:id', (req: Request, res: Response) => {
  res.status(204).end();
});

const app = express();
app.use(express.json());
app.use('/api/users', userRouter);

app.listen(3000);

错误处理

import express, { Request, Response, NextFunction } from 'express';

class AppError extends Error {
  constructor(
    public statusCode: number,
    message: string,
  ) {
    super(message);
    this.name = 'AppError';
  }
}

function asyncHandler(fn: (req: Request, res: Response, next: NextFunction) => Promise<void>) {
  return (req: Request, res: Response, next: NextFunction) => {
    fn(req, res, next).catch(next);
  };
}

const app = express();

app.get(
  '/api/users/:id',
  asyncHandler(async (req, res) => {
    const user = await findUser(req.params.id);
    if (!user) {
      throw new AppError(404, '用户不存在');
    }
    res.json(user);
  }),
);

app.use((err: Error, req: Request, res: Response, next: NextFunction) => {
  if (err instanceof AppError) {
    res.status(err.statusCode).json({ error: err.message });
  } else {
    console.error('未预期的错误:', err);
    res.status(500).json({ error: '服务器内部错误' });
  }
});

async function findUser(id: string): Promise<Record<string, unknown> | null> {
  if (id === '1') return { id: '1', name: '张三' };
  return null;
}

app.listen(3000);

Express 中异步错误需要通过 next(err) 传递给错误处理中间件，asyncHandler 包装器自动捕获 Promise 拒绝。

Koa：下一代 Web 框架

Koa 由 Express 的原作者 TJ Holowaychuk 创建，旨在成为一个更小、更富表现力的 Web 框架基础。Koa 从一开始就拥抱 async/await，使用洋葱模型中间件。

基础应用

import Koa from 'koa';
import Router from '@koa/router';
import bodyParser from 'koa-bodyparser';

const app = new Koa();
const router = new Router();

app.use(bodyParser());

router.get('/', (ctx) => {
  ctx.body = { message: 'Hello Koa' };
});

router.get('/api/users/:id', (ctx) => {
  ctx.body = { user: { id: ctx.params.id } };
});

router.post('/api/users', (ctx) => {
  ctx.status = 201;
  ctx.body = { user: ctx.request.body };
});

app.use(router.routes());
app.use(router.allowedMethods());

app.listen(3000, () => {
  console.log('Koa 服务运行在 http://localhost:3000');
});

Koa Context 对象

Koa 将 Node.js 的 request 和 response 对象封装到一个统一的 ctx（Context）对象中：

import Koa from 'koa';

const app = new Koa();

app.use(async (ctx) => {
  console.log(ctx.method);
  console.log(ctx.url);
  console.log(ctx.path);
  console.log(ctx.query);
  console.log(ctx.headers);
  console.log(ctx.ip);

  ctx.status = 200;
  ctx.type = 'application/json';
  ctx.body = { ok: true };

  ctx.set('X-Request-Id', crypto.randomUUID());
});

app.listen(3000);

洋葱模型

Koa 的中间件模型被称为洋葱模型——请求从外向内穿过中间件，响应从内向外穿过：

graph LR
    REQ[请求] --> M1_IN["中间件 1 ↓"]
    M1_IN --> M2_IN["中间件 2 ↓"]
    M2_IN --> M3_IN["中间件 3 ↓"]
    M3_IN --> CORE[核心处理]
    CORE --> M3_OUT["中间件 3 ↑"]
    M3_OUT --> M2_OUT["中间件 2 ↑"]
    M2_OUT --> M1_OUT["中间件 1 ↑"]
    M1_OUT --> RES[响应]
import Koa from 'koa';

const app = new Koa();

app.use(async (ctx, next) => {
  const start = Date.now();
  await next();
  const ms = Date.now() - start;
  ctx.set('X-Response-Time', `${ms}ms`);
  console.log(`${ctx.method} ${ctx.url} - ${ms}ms`);
});

app.use(async (ctx, next) => {
  try {
    await next();
  } catch (err: any) {
    ctx.status = err.status || 500;
    ctx.body = { error: err.message };
    ctx.app.emit('error', err, ctx);
  }
});

app.use(async (ctx) => {
  ctx.body = { message: 'Hello' };
});

app.listen(3000);

每个中间件调用 await next() 将控制权传递给下一个中间件。next() 返回后，请求已经被内层中间件处理完毕，当前中间件可以在 await next() 之后执行"回程"逻辑。

Express vs Koa 对比

维度 Express Koa
中间件模型 线性（从上到下） 洋葱模型（入→核心→出）
异步处理 回调 + 手动 catch 原生 async/await
内置功能 路由、静态文件、模板引擎 极简核心，全部通过中间件
错误处理 四参数中间件 try/catch + ctx.throw
生态系统 最丰富 较丰富
学习曲线 低 中等
性能 良好 良好
TypeScript 支持 @types/express @types/koa

何时选择 Express

  • 需要快速启动项目，利用丰富的中间件生态
  • 团队对 Express 更熟悉
  • 已有项目使用 Express，增量开发

何时选择 Koa

  • 偏好 async/await 的优雅写法
  • 需要精细控制请求/响应的处理流程
  • 对洋葱模型的中间件组合有需求

实战：RESTful API 示例

import Koa from 'koa';
import Router from '@koa/router';
import bodyParser from 'koa-bodyparser';

interface User {
  id: string;
  name: string;
  email: string;
}

const users = new Map<string, User>();

const router = new Router({ prefix: '/api' });

router.get('/users', (ctx) => {
  ctx.body = Array.from(users.values());
});

router.get('/users/:id', (ctx) => {
  const user = users.get(ctx.params.id);
  if (!user) {
    ctx.throw(404, '用户不存在');
  }
  ctx.body = user;
});

router.post('/users', (ctx) => {
  const { name, email } = ctx.request.body as Partial<User>;
  if (!name || !email) {
    ctx.throw(400, 'name 和 email 为必填字段');
  }
  const id = crypto.randomUUID();
  const user: User = { id, name, email };
  users.set(id, user);
  ctx.status = 201;
  ctx.body = user;
});

router.put('/users/:id', (ctx) => {
  const user = users.get(ctx.params.id);
  if (!user) {
    ctx.throw(404, '用户不存在');
  }
  const updates = ctx.request.body as Partial<User>;
  Object.assign(user, updates);
  ctx.body = user;
});

router.delete('/users/:id', (ctx) => {
  if (!users.delete(ctx.params.id)) {
    ctx.throw(404, '用户不存在');
  }
  ctx.status = 204;
});

const app = new Koa();
app.use(bodyParser());
app.use(router.routes());
app.use(router.allowedMethods());
app.listen(3000);

小结

  • Express 是 Node.js 最流行的 Web 框架，中间件生态最丰富，学习曲线最低。
  • Koa 使用洋葱模型和原生 async/await，中间件组合更灵活、错误处理更优雅。
  • Express 的异步错误需要通过 asyncHandler 包装，Koa 原生支持 async 中间件。
  • 两者都以路由 + 中间件为核心抽象，选择取决于团队偏好和项目需求。
  • 洋葱模型的核心优势：每个中间件都能在请求处理前后执行逻辑（如计时、日志、事务管理）。
