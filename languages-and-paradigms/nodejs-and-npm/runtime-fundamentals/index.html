运行时基础 简介

Node.js 的设计哲学与传统的服务端语言截然不同。它选择了单线程事件驱动的异步 I/O 模型，而非多线程阻塞模型。理解这个设计决策背后的原理，以及 Node.js 如何在底层实现高并发，是掌握 Node.js 的第一步。

第一节"Node 架构与事件循环"从全局视角剖析 Node.js 的分层架构，重点讲解事件循环的六个阶段及其执行顺序。事件循环是 Node.js 异步模型的心脏，理解它才能真正掌握 setTimeout、setImmediate、process.nextTick 的执行时机差异。

第二节"V8 引擎与 libuv"深入 Node.js 的两大核心依赖。V8 负责 JavaScript 代码的解析、编译与执行，libuv 提供跨平台的异步 I/O 能力。两者的协作方式决定了 Node.js 的性能特征——CPU 密集型任务为何是瓶颈，I/O 密集型任务为何是强项。

第三节"模块系统：CommonJS 与 ESM"对比 Node.js 中两大模块规范。从 CommonJS 的同步加载到 ESM 的静态分析，从 require 的缓存机制到 import 的 Tree-shaking 能力——模块系统的选择直接影响项目的构建方式和性能表现。
