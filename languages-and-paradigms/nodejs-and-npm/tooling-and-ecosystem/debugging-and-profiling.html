调试与性能分析

Node.js 调试基础

调试是开发过程中最重要的技能之一。Node.js 提供了多种调试工具，从简单的 console 输出到强大的断点调试器，满足不同场景的需求。

console 调试进阶

console.log('基本输出');
console.error('错误输出（写入 stderr）');
console.warn('警告输出');

console.table([
  { name: 'Alice', age: 30 },
  { name: 'Bob', age: 25 },
]);

console.time('操作耗时');
await someAsyncOperation();
console.timeEnd('操作耗时');

console.count('循环次数');
console.count('循环次数');
console.countReset('循环次数');

console.group('用户信息');
console.log('名称: Alice');
console.log('年龄: 30');
console.groupEnd();

console.dir({ deep: { nested: { object: true } } }, { depth: null, colors: true });

async function someAsyncOperation(): Promise<void> {
  return new Promise((r) => setTimeout(r, 100));
}

--inspect 调试器

Node.js 内置了 V8 Inspector 协议，支持 Chrome DevTools 和 VS Code 的断点调试：

node --inspect src/index.js

node --inspect-brk src/index.js

node --inspect=0.0.0.0:9229 src/index.js

性能分析工具
CPU 分析
node --cpu-prof src/index.js
这会在进程退出时生成 .cpuprofile 文件，可以在 Chrome DevTools 的 Performance 面板中打开。


import { Session } from 'node:inspector/promises';

async function profileCPU(fn: () => Promise<void>, outputFile: string): Promise<void> {
  const session = new Session();
  session.connect();

  await session.post('Profiler.enable');
  await session.post('Profiler.start');

  await fn();

  const { profile } = await session.post('Profiler.stop');

  const fs = await import('node:fs/promises');
  await fs.writeFile(outputFile, JSON.stringify(profile));
  console.log(`CPU profile 已保存到 ${outputFile}`);

  session.disconnect();
}
内存分析
function checkMemoryUsage(): Record<string, string> {
  const usage = process.memoryUsage();
  return {
    rss: `${(usage.rss / 1024 / 1024).toFixed(2)} MB`,
    heapTotal: `${(usage.heapTotal / 1024 / 1024).toFixed(2)} MB`,
    heapUsed: `${(usage.heapUsed / 1024 / 1024).toFixed(2)} MB`,
    external: `${(usage.external / 1024 / 1024).toFixed(2)} MB`,
    arrayBuffers: `${(usage.arrayBuffers / 1024 / 1024).toFixed(2)} MB`,
  };
}

setInterval(() => {
  console.table(checkMemoryUsage());
}, 5000);




指标
含义





rss
常驻内存集（进程总内存占用）




heapTotal
V8 已申请的堆内存总量




heapUsed
V8 实际使用的堆内存




external
V8 管理之外的 C++ 对象内存




arrayBuffers
ArrayBuffer 和 SharedArrayBuffer 占用

kill -USR2 <pid>

事件循环监控
import { monitorEventLoopDelay } from 'node:perf_hooks';

const histogram = monitorEventLoopDelay({ resolution: 20 });
histogram.enable();

setInterval(() => {
  console.log({
    min: `${(histogram.min / 1e6).toFixed(2)}ms`,
    max: `${(histogram.max / 1e6).toFixed(2)}ms`,
    mean: `${(histogram.mean / 1e6).toFixed(2)}ms`,
    p50: `${(histogram.percentile(50) / 1e6).toFixed(2)}ms`,
    p99: `${(histogram.percentile(99) / 1e6).toFixed(2)}ms`,
  });
  histogram.reset();
}, 10000);
事件循环延迟是衡量 Node.js 应用健康状态的关键指标。正常情况下 P99 应在 20ms 以下，如果持续超过 100ms，说明存在事件循环阻塞。

小结
    

  • Node.js 内置 --inspect 支持 Chrome DevTools 断点调试。
    • 

  • --cpu-prof 和 --heapsnapshot-signal 分别用于 CPU 和内存分析。
    • 

  • process.memoryUsage() 和 monitorEventLoopDelay 是运行时监控的关键 API。
    • 

  • Clinic.js 提供 doctor、flame、bubbleprof 三个诊断工具。
    • 

  • 事件循环延迟 P99 超过 100ms 是严重的性能警告信号。
    • 

  • 性能优化的前提是正确的测量——永远先分析再优化。
