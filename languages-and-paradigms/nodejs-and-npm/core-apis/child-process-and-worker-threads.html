child_process 与 worker_threads

为什么需要多进程/多线程

Node.js 的单线程模型非常适合 I/O 密集型任务，但在面对 CPU 密集型任务时会成为瓶颈。Node.js 提供了两种突破单线程限制的方案：





特性
child_process
worker_threads





隔离级别
完全独立的进程
同一进程内的线程




内存
独立内存空间
可共享内存（SharedArrayBuffer）




启动开销
较大（新建进程）
较小（新建线程）




通信方式
IPC（序列化/反序列化）
MessagePort / SharedMemory




稳定性
子进程崩溃不影响主进程
Worker 崩溃可能影响主线程




适用场景
执行外部命令、进程隔离
CPU 密集型计算







child_process 模块
exec —— 执行 Shell 命令
import { exec } from 'node:child_process';
import { promisify } from 'node:util';

const execAsync = promisify(exec);

async function runCommand(cmd: string): Promise<string> {
  const { stdout, stderr } = await execAsync(cmd, {
    maxBuffer: 1024 * 1024 * 10,
    timeout: 30000,
    encoding: 'utf-8',
  });

  if (stderr) {
    console.warn('stderr:', stderr);
  }

  return stdout.trim();
}

const nodeVersion = await runCommand('node --version');
const gitBranch = await runCommand('git branch --show-current');
console.log(`Node: ${nodeVersion}, 分支: ${gitBranch}`);
execFile —— 直接执行文件
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';

const execFileAsync = promisify(execFile);

const { stdout } = await execFileAsync('git', ['log', '--oneline', '-10']);
console.log(stdout);
execFile 不经过 Shell，因此更安全（不受 Shell 注入攻击影响）、更高效。


spawn —— 流式子进程
import { spawn } from 'node:child_process';

function runLongProcess(command: string, args: string[]): Promise<number> {
  return new Promise((resolve, reject) => {
    const child = spawn(command, args, {
      stdio: ['inherit', 'pipe', 'pipe'],
    });

    child.stdout.on('data', (data: Buffer) => {
      process.stdout.write(`[stdout] ${data}`);
    });

    child.stderr.on('data', (data: Buffer) => {
      process.stderr.write(`[stderr] ${data}`);
    });

    child.on('close', (code) => {
      resolve(code ?? 1);
    });

    child.on('error', reject);
  });
}

await runLongProcess('npm', ['run', 'build']);
fork —— 创建 Node.js 子进程
import { fork } from 'node:child_process';
import path from 'node:path';

function computeInChild(data: number[]): Promise<number> {
  return new Promise((resolve, reject) => {
    const child = fork(path.resolve('compute-worker.js'));

    child.send({ type: 'compute', data });

    child.on('message', (msg: { type: string; result: number }) => {
      if (msg.type === 'result') {
        resolve(msg.result);
      }
    });

    child.on('error', reject);
    child.on('exit', (code) => {
      if (code !== 0) {
        reject(new Error(`子进程退出码: ${code}`));
      }
    });
  });
}
process.on('message', (msg: { type: string; data: number[] }) => {
  if (msg.type === 'compute') {
    let sum = 0;
    for (const num of msg.data) {
      sum += Math.sqrt(num) * Math.log(num + 1);
    }
    process.send!({ type: 'result', result: sum });
    process.exit(0);
  }
});


worker_threads 模块
Worker Threads 在同一个进程内创建新线程，适合需要共享内存的 CPU 密集型计算。


基本使用
import { Worker, isMainThread, parentPort, workerData } from 'node:worker_threads';

if (isMainThread) {
  function runWorker(data: number[]): Promise<number> {
    return new Promise((resolve, reject) => {
      const worker = new Worker(new URL(import.meta.url), {
        workerData: data,
      });

      worker.on('message', resolve);
      worker.on('error', reject);
      worker.on('exit', (code) => {
        if (code !== 0) {
          reject(new Error(`Worker 退出码: ${code}`));
        }
      });
    });
  }

  const data = Array.from({ length: 10000000 }, (_, i) => i);
  const result = await runWorker(data);
  console.log('计算结果:', result);
} else {
  const data = workerData as number[];
  let sum = 0;
  for (const num of data) {
    sum += Math.sqrt(num);
  }
  parentPort!.postMessage(sum);
}
Worker 线程池
import { Worker } from 'node:worker_threads';
import os from 'node:os';

interface Task<T> {
  data: unknown;
  resolve: (value: T) => void;
  reject: (error: Error) => void;
}

class WorkerPool<T = unknown> {
  private workers: Worker[] = [];
  private freeWorkers: Worker[] = [];
  private taskQueue: Task<T>[] = [];

  constructor(
    private workerScript: string | URL,
    private poolSize: number = os.cpus().length,
  ) {
    for (let i = 0; i < this.poolSize; i++) {
      this.addWorker();
    }
  }

  private addWorker(): void {
    const worker = new Worker(this.workerScript);

    worker.on('message', (result: T) => {
      const task = (worker as any).__currentTask as Task<T>;
      task.resolve(result);
      this.freeWorkers.push(worker);
      this.processQueue();
    });

    worker.on('error', (err) => {
      const task = (worker as any).__currentTask as Task<T>;
      task?.reject(err);
    });

    this.workers.push(worker);
    this.freeWorkers.push(worker);
  }

  execute(data: unknown): Promise<T> {
    return new Promise<T>((resolve, reject) => {
      this.taskQueue.push({ data, resolve, reject });
      this.processQueue();
    });
  }

  private processQueue(): void {
    if (this.taskQueue.length === 0 || this.freeWorkers.length === 0) return;

    const worker = this.freeWorkers.pop()!;
    const task = this.taskQueue.shift()!;
    (worker as any).__currentTask = task;
    worker.postMessage(task.data);
  }

  async destroy(): Promise<void> {
    await Promise.all(this.workers.map((w) => w.terminate()));
  }
}
SharedArrayBuffer 共享内存
import { Worker, isMainThread, parentPort, workerData } from 'node:worker_threads';

if (isMainThread) {
  const sharedBuffer = new SharedArrayBuffer(4 * 1024);
  const sharedArray = new Int32Array(sharedBuffer);

  for (let i = 0; i < sharedArray.length; i++) {
    sharedArray[i] = i;
  }

  const worker = new Worker(new URL(import.meta.url), {
    workerData: { sharedBuffer },
  });

  worker.on('message', () => {
    console.log('Worker 完成处理');
    console.log('前 10 个值:', Array.from(sharedArray.slice(0, 10)));
  });
} else {
  const { sharedBuffer } = workerData as { sharedBuffer: SharedArrayBuffer };
  const sharedArray = new Int32Array(sharedBuffer);

  for (let i = 0; i < sharedArray.length; i++) {
    Atomics.store(sharedArray, i, sharedArray[i] * 2);
  }

  parentPort!.postMessage('done');
}
SharedArrayBuffer 允许主线程和 Worker 线程共享同一块内存，配合 Atomics API 可以实现无锁的并发数据操作。




多进程集群（Cluster）
Node.js 内置的 cluster 模块利用多进程充分利用多核 CPU：


import cluster from 'node:cluster';
import http from 'node:http';
import os from 'node:os';

if (cluster.isPrimary) {
  const numCPUs = os.cpus().length;
  console.log(`主进程 ${process.pid} 启动，创建 ${numCPUs} 个工作进程`);

  for (let i = 0; i < numCPUs; i++) {
    cluster.fork();
  }

  cluster.on('exit', (worker, code, signal) => {
    console.log(`工作进程 ${worker.process.pid} 退出 (${signal || code})`);
    console.log('正在启动新的工作进程...');
    cluster.fork();
  });
} else {
  http
    .createServer((req, res) => {
      res.writeHead(200);
      res.end(`来自工作进程 ${process.pid}\n`);
    })
    .listen(3000);

  console.log(`工作进程 ${process.pid} 已启动`);
}


选择指南


小结
    

  • child_process 提供四种创建子进程的方式：exec、execFile、spawn、fork。
    • 

  • execFile 比 exec 更安全（不经过 Shell），spawn 适合流式处理。
    • 

  • fork 专门用于创建 Node.js 子进程，自带 IPC 通信通道。
    • 

  • worker_threads 创建同进程内的线程，启动更快、支持共享内存。
    • 

  • SharedArrayBuffer + Atomics 实现线程间的零拷贝数据共享。
    • 

  • cluster 模块利用多进程实现 HTTP 服务的多核扩展。
    • 

  • 选择原则：外部命令用 exec/spawn，CPU 计算用 worker_threads，服务扩展用 cluster。
