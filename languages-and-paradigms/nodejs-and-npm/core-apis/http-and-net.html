http 与 net

核心概念

http 与 net 是 Node.js 网络能力的两个层级，上层框架都建立在它们之上：

  • http 模块：在 net 之上实现 HTTP 协议，提供 http.createServer 与 IncomingMessage/ServerResponse 抽象——Express、Koa、Hono 的底层都是它。
  • net 模块：直接操作 TCP 套接字，没有协议语义，适合自定义协议、长连接和底层网络工具。
  • 请求体是流：HTTP 请求体以 Stream 形式到达，需要手动收集分片并注意设置大小上限，否则会被超大请求体拖垮。
  • 客户端两种方式：Node.js 18+ 优先使用全局 fetch；需要精细控制连接、超时、流式响应时用底层的 http.request。
层级 协议 抽象 典型用途
net TCP Socket 自定义协议、长连接、聊天服务
http HTTP/1.1 req/res 对象 Web 服务器与客户端

http 模块概述

Node.js 的 http 模块是构建 Web 服务器的基础。Express、Koa、Hono 等所有 Node.js Web 框架底层都基于 http 模块。理解它的工作原理，有助于深入理解上层框架的行为。

flowchart TD
    CLIENT[客户端] -->|HTTP 请求| SERVER[http.Server]
    SERVER -->|request 事件| HANDLER[请求处理函数]
    HANDLER -->|IncomingMessage| REQ[req 对象<br/>请求头、方法、URL]
    HANDLER -->|ServerResponse| RES[res 对象<br/>设置状态码、响应头、响应体]
    RES -->|响应数据| CLIENT

创建 HTTP 服务器

import http from 'node:http';

const server = http.createServer((req, res) => {
  const { method, url, headers } = req;

  console.log(`${method} ${url}`);
  console.log('User-Agent:', headers['user-agent']);

  res.writeHead(200, {
    'Content-Type': 'application/json',
    'X-Request-Id': crypto.randomUUID(),
  });

  res.end(
    JSON.stringify({
      message: 'Hello from Node.js',
      timestamp: Date.now(),
    }),
  );
});

server.listen(3000, '0.0.0.0', () => {
  const addr = server.address();
  console.log(`服务器运行在 http://localhost:${(addr as any).port}`);
});

请求体解析

HTTP 请求体是以 Stream 形式到达的，需要手动收集和解析：

import http from 'node:http';

function parseJsonBody(req: http.IncomingMessage): Promise<unknown> {
  return new Promise((resolve, reject) => {
    const chunks: Buffer[] = [];
    let totalSize = 0;
    const MAX_SIZE = 1024 * 1024;

    req.on('data', (chunk: Buffer) => {
      totalSize += chunk.length;
      if (totalSize > MAX_SIZE) {
        req.destroy();
        reject(new Error('请求体过大'));
        return;
      }
      chunks.push(chunk);
    });

    req.on('end', () => {
      try {
        const body = Buffer.concat(chunks).toString('utf-8');
        resolve(JSON.parse(body));
      } catch {
        reject(new Error('JSON 解析失败'));
      }
    });

    req.on('error', reject);
  });
}

路由实现

import http from 'node:http';

type RouteHandler = (req: http.IncomingMessage, res: http.ServerResponse) => Promise<void> | void;

interface Route {
  method: string;
  path: string;
  handler: RouteHandler;
}

class Router {
  private routes: Route[] = [];

  get(path: string, handler: RouteHandler): void {
    this.routes.push({ method: 'GET', path, handler });
  }

  post(path: string, handler: RouteHandler): void {
    this.routes.push({ method: 'POST', path, handler });
  }

  async handle(req: http.IncomingMessage, res: http.ServerResponse): Promise<void> {
    const route = this.routes.find((r) => r.method === req.method && r.path === req.url);

    if (route) {
      await route.handler(req, res);
    } else {
      res.writeHead(404, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ error: 'Not Found' }));
    }
  }
}

const router = new Router();

router.get('/api/health', (req, res) => {
  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ status: 'ok' }));
});

router.get('/api/time', (req, res) => {
  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ time: new Date().toISOString() }));
});

const server = http.createServer((req, res) => router.handle(req, res));
server.listen(3000);

HTTP 客户端

全局 fetch（Node.js 18+）

async function fetchData(url: string): Promise<unknown> {
  const response = await fetch(url, {
    method: 'GET',
    headers: {
      Accept: 'application/json',
      Authorization: 'Bearer token',
    },
    signal: AbortSignal.timeout(5000),
  });

  if (!response.ok) {
    throw new Error(`HTTP ${response.status}: ${response.statusText}`);
  }

  return response.json();
}

async function postData(url: string, data: unknown): Promise<unknown> {
  const response = await fetch(url, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(data),
  });

  return response.json();
}

http.request（底层 API）

import http from 'node:http';

function httpGet(url: string): Promise<string> {
  return new Promise((resolve, reject) => {
    http
      .get(url, (res) => {
        const chunks: Buffer[] = [];
        res.on('data', (chunk) => chunks.push(chunk));
        res.on('end', () => resolve(Buffer.concat(chunks).toString()));
        res.on('error', reject);
      })
      .on('error', reject);
  });
}

服务器高级配置

import http from 'node:http';

const server = http.createServer();

server.keepAliveTimeout = 72000;
server.headersTimeout = 60000;
server.maxHeadersCount = 100;
server.timeout = 120000;

server.on('request', (req, res) => {
  res.writeHead(200);
  res.end('OK');
});

server.on('clientError', (err, socket) => {
  if ((err as any).code === 'ECONNRESET' || !socket.writable) return;
  socket.end('HTTP/1.1 400 Bad Request\r\n\r\n');
});

server.on('close', () => {
  console.log('服务器已关闭');
});

const gracefulShutdown = (): void => {
  console.log('收到关闭信号，开始优雅退出...');

  server.close(() => {
    console.log('所有连接已关闭');
    process.exit(0);
  });

  setTimeout(() => {
    console.error('强制退出');
    process.exit(1);
  }, 10000);
};

process.on('SIGTERM', gracefulShutdown);
process.on('SIGINT', gracefulShutdown);

server.listen(3000);

net 模块：TCP 编程

net 模块提供比 http 更底层的 TCP/IPC 网络编程能力。HTTP 协议本身就运行在 TCP 之上。

TCP 服务器

import net from 'node:net';

const tcpServer = net.createServer((socket) => {
  const clientAddr = `${socket.remoteAddress}:${socket.remotePort}`;
  console.log(`客户端连接: ${clientAddr}`);

  socket.write('欢迎连接到 TCP 服务器\n');

  socket.on('data', (data) => {
    const message = data.toString().trim();
    console.log(`[${clientAddr}] ${message}`);

    if (message === 'quit') {
      socket.end('再见！\n');
      return;
    }

    socket.write(`回声: ${message}\n`);
  });

  socket.on('end', () => {
    console.log(`客户端断开: ${clientAddr}`);
  });

  socket.on('error', (err) => {
    console.error(`Socket 错误 [${clientAddr}]:`, err.message);
  });
});

tcpServer.listen(8080, () => {
  console.log('TCP 服务器监听端口 8080');
});

TCP 客户端

import net from 'node:net';

function createTcpClient(host: string, port: number): Promise<string> {
  return new Promise((resolve, reject) => {
    const client = net.createConnection({ host, port }, () => {
      client.write('Hello Server');
    });

    const chunks: Buffer[] = [];

    client.on('data', (data) => {
      chunks.push(data);
    });

    client.on('end', () => {
      resolve(Buffer.concat(chunks).toString());
    });

    client.on('error', reject);

    client.setTimeout(5000, () => {
      client.destroy(new Error('连接超时'));
    });
  });
}

简易聊天服务器

import net from 'node:net';

const clients = new Set<net.Socket>();

function broadcast(message: string, sender?: net.Socket): void {
  for (const client of clients) {
    if (client !== sender && client.writable) {
      client.write(message);
    }
  }
}

const chatServer = net.createServer((socket) => {
  clients.add(socket);
  const addr = `${socket.remoteAddress}:${socket.remotePort}`;
  broadcast(`[系统] ${addr} 加入了聊天室\n`, socket);
  socket.write(`[系统] 欢迎！当前在线: ${clients.size} 人\n`);

  socket.on('data', (data) => {
    broadcast(`[${addr}] ${data.toString()}`, socket);
  });

  socket.on('end', () => {
    clients.delete(socket);
    broadcast(`[系统] ${addr} 离开了聊天室\n`);
  });

  socket.on('error', () => {
    clients.delete(socket);
  });
});

chatServer.listen(9000, () => {
  console.log('聊天服务器运行在端口 9000');
});

http 与 net 的关系

graph TB
    APP[应用层<br/>Express / Koa / Hono]
    HTTP[http 模块<br/>HTTP 协议解析]
    NET[net 模块<br/>TCP 连接管理]
    OS[操作系统<br/>Socket API]
    APP --> HTTP
    HTTP --> NET
    NET --> OS

http.Server 本质上是一个 net.Server，它在 TCP 连接之上增加了 HTTP 协议的解析能力。当 http.Server 接收到 TCP 数据后，会使用 llhttp（高性能 HTTP 解析器）将原始字节流解析为 HTTP 请求对象。

小结

  • http 模块是所有 Node.js Web 框架的基础，理解它有助于理解框架行为。
  • HTTP 请求体以 Stream 形式到达，需要手动收集 chunks 并解析。
  • Node.js 18+ 内置全局 fetch，是发起 HTTP 请求的推荐方式。
  • 优雅关闭（Graceful Shutdown）是生产环境 HTTP 服务器的必备特性。
  • net 模块提供 TCP/IPC 级别的网络编程，http 模块建立在 net 之上。
  • TCP 服务器通过 socket 事件（data、end、error）处理客户端通信。
