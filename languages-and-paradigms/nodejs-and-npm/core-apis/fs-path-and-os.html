Part I · 现代脚本与运行时Node.js & npm 简介核心 API 简介fs、path 与 os

fs、path 与 os

核心概念

这三个模块是 Node.js 与"运行环境"打交道的入口，各自有明确的分工：

  • fs：文件系统操作，提供回调、同步、Promise 三种 API。现代代码一律使用 node:fs/promises——同步 API 会阻塞事件循环，回调 API 会带来回调地狱。
  • path：跨平台路径运算。永远用 path.join/path.resolve 拼接路径，而不是字符串相加，否则 Windows 与 POSIX 的分隔符差异会让代码崩溃。
  • os：读取操作系统信息，最典型的用途是根据 CPU 核数决定并发度。
模块 核心职责 推荐 API 常见陷阱
fs 文件与目录 node:fs/promises 用同步 API 阻塞事件循环
path 路径运算 path.join/resolve 手拼字符串导致跨平台失败
os 系统信息 os.cpus()、os.tmpdir() 误把核数当作可直接并发的任务数

fs 模块：文件系统操作

Node.js 的 fs 模块提供了与文件系统交互的全面 API。它有三种使用方式：回调版本、同步版本和 Promise 版本。在现代 Node.js 中，推荐使用 node:fs/promises。

文件读写

import fs from 'node:fs/promises';

async function readAndWrite(): Promise<void> {
  const content = await fs.readFile('input.txt', 'utf-8');

  await fs.writeFile('output.txt', content.toUpperCase());

  await fs.appendFile('log.txt', `[${new Date().toISOString()}] 操作完成\n`);

  await fs.copyFile('input.txt', 'backup.txt');

  await fs.rename('backup.txt', 'archive.txt');

  await fs.unlink('archive.txt');
}

目录操作

import fs from 'node:fs/promises';
import path from 'node:path';

async function directoryOperations(): Promise<void> {
  await fs.mkdir('nested/deep/dir', { recursive: true });

  const entries = await fs.readdir('src', { withFileTypes: true });
  for (const entry of entries) {
    const type = entry.isDirectory() ? '目录' : '文件';
    console.log(`${type}: ${entry.name}`);
  }

  await fs.rm('nested', { recursive: true, force: true });
}

async function walkDirectory(dir: string): Promise<string[]> {
  const files: string[] = [];
  const entries = await fs.readdir(dir, { withFileTypes: true });

  for (const entry of entries) {
    const fullPath = path.join(dir, entry.name);
    if (entry.isDirectory()) {
      files.push(...(await walkDirectory(fullPath)));
    } else {
      files.push(fullPath);
    }
  }

  return files;
}

文件状态与权限

import fs from 'node:fs/promises';

async function fileInfo(filePath: string): Promise<void> {
  const stat = await fs.stat(filePath);

  console.log({
    size: `${stat.size} 字节`,
    isFile: stat.isFile(),
    isDirectory: stat.isDirectory(),
    created: stat.birthtime,
    modified: stat.mtime,
    permissions: stat.mode.toString(8),
  });

  try {
    await fs.access(filePath, fs.constants.R_OK | fs.constants.W_OK);
    console.log('文件可读可写');
  } catch {
    console.log('文件不可读写');
  }
}

文件监听

import fs from 'node:fs';

const watcher = fs.watch('src', { recursive: true }, (eventType, filename) => {
  console.log(`${eventType}: ${filename}`);
});

process.on('SIGINT', () => {
  watcher.close();
  process.exit(0);
});

Node.js 22+ 提供了基于 fs.promises.watch 的异步迭代器版本：

import fs from 'node:fs/promises';

async function watchFiles(): Promise<void> {
  const watcher = fs.watch('src', { recursive: true });
  for await (const event of watcher) {
    console.log(`${event.eventType}: ${event.filename}`);
  }
}

path 模块：路径处理

path 模块提供了跨平台的路径操作工具。它会根据当前操作系统自动处理路径分隔符差异（Windows 的 \ vs POSIX 的 /）。

import path from 'node:path';

const filePath = '/Users/dev/project/src/index.ts';

console.log(path.dirname(filePath));
console.log(path.basename(filePath));
console.log(path.basename(filePath, '.ts'));
console.log(path.extname(filePath));

const joined = path.join('src', 'utils', 'helper.ts');
console.log(joined);

const absolute = path.resolve('src', 'utils', 'helper.ts');
console.log(absolute);

const relative = path.relative('/Users/dev/project', '/Users/dev/project/src/index.ts');
console.log(relative);

const parsed = path.parse(filePath);
console.log(parsed);

import path from 'node:path';

os 模块：操作系统信息

import os from 'node:os';

function getSystemInfo(): Record<string, unknown> {
  return {
    platform: os.platform(),
    arch: os.arch(),
    release: os.release(),
    hostname: os.hostname(),
    homeDir: os.homedir(),
    tmpDir: os.tmpdir(),
    cpuCount: os.cpus().length,
    cpuModel: os.cpus()[0]?.model,
    totalMemory: `${(os.totalmem() / 1024 / 1024 / 1024).toFixed(2)} GB`,
    freeMemory: `${(os.freemem() / 1024 / 1024 / 1024).toFixed(2)} GB`,
    uptime: `${(os.uptime() / 3600).toFixed(1)} 小时`,
    loadAverage: os.loadavg(),
  };
}

console.table(getSystemInfo());

网络接口信息

import os from 'node:os';

function getNetworkAddresses(): Array<{ name: string; address: string; family: string }> {
  const interfaces = os.networkInterfaces();
  const addresses: Array<{ name: string; address: string; family: string }> = [];

  for (const [name, nets] of Object.entries(interfaces)) {
    for (const net of nets || []) {
      if (!net.internal) {
        addresses.push({
          name,
          address: net.address,
          family: net.family,
        });
      }
    }
  }

  return addresses;
}

console.table(getNetworkAddresses());

根据 CPU 核数设置并发

import os from 'node:os';

function getOptimalConcurrency(): number {
  const cpuCount = os.cpus().length;
  return Math.max(1, cpuCount - 1);
}

const WORKER_COUNT = getOptimalConcurrency();
console.log(`将启动 ${WORKER_COUNT} 个工作线程`);

实战：构建简易文件服务器

import fs from 'node:fs/promises';
import path from 'node:path';
import http from 'node:http';

const MIME_TYPES: Record<string, string> = {
  '.html': 'text/html',
  '.css': 'text/css',
  '.js': 'application/javascript',
  '.json': 'application/json',
  '.png': 'image/png',
  '.jpg': 'image/jpeg',
  '.svg': 'image/svg+xml',
  '.txt': 'text/plain',
};

const ROOT_DIR = path.resolve('public');

const server = http.createServer(async (req, res) => {
  const urlPath = req.url === '/' ? '/index.html' : req.url!;
  const filePath = path.join(ROOT_DIR, urlPath);

  if (!filePath.startsWith(ROOT_DIR)) {
    res.writeHead(403);
    res.end('Forbidden');
    return;
  }

  try {
    const stat = await fs.stat(filePath);
    if (!stat.isFile()) {
      res.writeHead(404);
      res.end('Not Found');
      return;
    }

    const ext = path.extname(filePath);
    const contentType = MIME_TYPES[ext] || 'application/octet-stream';
    const content = await fs.readFile(filePath);

    res.writeHead(200, { 'Content-Type': contentType });
    res.end(content);
  } catch {
    res.writeHead(404);
    res.end('Not Found');
  }
});

server.listen(3000, () => {
  console.log('文件服务器运行在 http://localhost:3000');
});

小结

  • node:fs/promises 是文件操作的推荐 API，避免使用同步版本阻塞事件循环。
  • fs.mkdir 的 recursive: true 可以递归创建目录，fs.rm 的 recursive: true 可以递归删除。
  • path 模块自动处理跨平台路径差异，推荐使用 path.join 和 path.resolve 构造路径。
  • ESM 中没有 __dirname，需通过 fileURLToPath(import.meta.url) 手动计算。
  • os 模块提供系统信息，常用于确定并发数、获取网络地址等场景。
  • 文件服务器实现中必须防止路径遍历攻击（检查路径是否在根目录内）。
