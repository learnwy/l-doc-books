性能优化

正则性能的基本原则

正则表达式的性能取决于三个因素：模式的结构、输入字符串的长度和内容、以及引擎的实现。优化的核心目标是减少回溯次数和让引擎尽早确定匹配或失败。

const naive = /.*foo/;
const optimized = /foo/;

const text = 'a'.repeat(10000) + 'foo';
const start1 = performance.now();
naive.test(text);
const t1 = performance.now() - start1;

const start2 = performance.now();
optimized.test(text);
const t2 = performance.now() - start2;
优化层面 策略 效果
模式结构 使用精确字符类 减少候选路径
锚点 添加 ^ $ \b 限定位置 减少起始位置尝试
量词 避免嵌套量词 消除指数回溯
预编译 缓存正则对象 避免重复编译
引擎选择 简单模式用 DFA 引擎 保证线性时间

锚点优化

添加锚点是最简单也最有效的优化手段。没有锚点的模式需要在输入字符串的每个位置尝试匹配。

const withoutAnchor = /\d{4}-\d{2}-\d{2}/;
const withAnchor = /^\d{4}-\d{2}-\d{2}$/;

const input = 'a'.repeat(10000);
withoutAnchor.test(input);
withAnchor.test(input);

提示： 现代引擎（如 V8）会自动检测某些可以优化的模式。例如，以字面量字符开头的模式会使用 Boyer-Moore 等快速字符串搜索算法定位起始位置。但显式锚点仍然是最可靠的优化方式。






字符类优化
使用精确的字符类替代通配符，可以显著减少回溯路径。


const bad = /".*"/;
const good = /"[^"]*"/;

const text = '"a"' + ' "b"'.repeat(1000);
const start1 = performance.now();
bad.exec(text);
performance.now() - start1;

const start2 = performance.now();
good.exec(text);
performance.now() - start2;
| 模式        | 回溯风险 | 替代方案  | 说明         |
| ----------- | -------- | --------- | ------------ | -------------- |
| ".*"      | 高       | "[^"]*" | 排除定界符   |
| <.*>      | 高       | <[^>]*> | 排除定界符   |
| \s*\S+\s* | 中       | \s*\S+  | 去除多余匹配 |
| (.         | \n)\*   | 高        | [\s\S]*    | 单字符类更高效 |




交替分支优化
交替操作 | 的分支顺序影响匹配性能。将最可能匹配的分支放在前面，可以减少不必要的回溯。


const unoptimized = /January|February|March|April|May|June|July|August|September|October|November|December/;
const optimized = /(?:Jan|Feb|Mar|Apr|May|Jun|Jul|Aug|Sep|Oct|Nov|Dec)(?:uary|ruary|ch|il|e|ust|tember|ober|ember)?/;

const trie =
  /(?:A(?:pr(?:il)?|ug(?:ust)?)|Dec(?:ember)?|Feb(?:ruary)?|J(?:an(?:uary)?|u(?:ly?|ne?))|Ma(?:r(?:ch)?|y)|Nov(?:ember)?|Oct(?:ober)?|Sep(?:tember)?)/;

提示： 单字符交替（如 a|b|c）应始终改写为字符类 [abc]。多数引擎对字符类有专门的优化路径（如位图查找），比交替操作快一个数量级。






预编译与缓存
在循环中重复使用正则表达式时，预编译和缓存可以避免重复解析和编译的开销。


function findAllBad(texts) {
  return texts.filter((t) => /^\d{4}-\d{2}-\d{2}$/.test(t));
}

const DATE_REGEX = /^\d{4}-\d{2}-\d{2}$/;
function findAllGood(texts) {
  return texts.filter((t) => DATE_REGEX.test(t));
}

const regexCache = new Map();
function getCachedRegex(pattern, flags) {
  const key = `${pattern}::${flags}`;
  if (!regexCache.has(key)) {
    regexCache.set(key, new RegExp(pattern, flags));
  }
  return regexCache.get(key);
}
