NFA 与 DFA

有限自动机基础

正则表达式的数学基础是有限自动机（Finite Automaton），它是一种抽象计算模型。每个正则表达式都对应一个有限自动机，引擎的任务就是模拟这个自动机的运行过程。

NFA 引擎
NFA（Non-deterministic Finite Automaton，非确定性有限自动机）是大多数编程语言采用的正则引擎类型。"非确定性"意味着在某个状态下，面对相同输入可能有多条可选路径。


NFA 引擎的核心特征是回溯：当一条路径失败时，引擎回退到最近的分支点，尝试另一条路径。


const text = 'aac';
const pattern = /ab|ac/;
pattern.test(text);

DFA 引擎
DFA（Deterministic Finite Automaton，确定性有限自动机）在每个状态下对每个输入字符只有唯一的转移路径，因此不需要回溯。


DFA 通过子集构造法将 NFA 的多条并行路径合并为单一路径，在构建阶段完成所有不确定性的消除。

Thompson 构造法
Ken Thompson 在 1968 年提出的构造法是将正则表达式转换为 NFA 的经典算法。每个基本操作对应一个 NFA 片段，通过组合得到完整的 NFA。


function matchSimple(pattern, text) {
  const regex = new RegExp(pattern);
  const start = performance.now();
  const result = regex.test(text);
  const elapsed = performance.now() - start;
  return { result, elapsed };
}

matchSimple('a'.repeat(20), 'a'.repeat(20));


小结
    

  • 正则引擎的数学基础是有限自动机，分为 NFA（非确定性）和 DFA（确定性）两种。
    • 

  • NFA 通过回溯探索多条路径，支持捕获分组、反向引用等全部特性，但最坏时间复杂度为指数级。
    • 

  • DFA 每个状态只有唯一转移路径，保证线性时间匹配，但不支持反向引用和断言。
    • 

  • JavaScript、Python、Java 等主流语言均采用 NFA 引擎；RE2、awk 等工具采用 DFA 引擎。
    • 

  • Thompson 构造法是将正则表达式转换为 NFA 的经典算法，奠定了现代正则引擎的理论基础。
