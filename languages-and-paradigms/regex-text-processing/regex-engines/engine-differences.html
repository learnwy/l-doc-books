引擎差异

跨语言正则概览

每种编程语言和工具的正则引擎都有自己的特性集和行为细节。看似相同的正则表达式在不同引擎中可能产生不同的结果。理解这些差异是跨语言开发和正则移植的关键。

const jsRegex = /(?<=\d)px/;
jsRegex.test('10px');
import re
py_regex = re.compile(r'(?<=\d)px')
py_regex.search('10px')

语法差异

import re
py_named = re.compile(r'(?P<name>\w+)')
py_named.search('hello').group('name')

小结
    

  • 主流引擎分为 NFA（JS、Python、Java）和 DFA（RE2、Go）两大阵营，特性支持差异显著。
    • 

  • 高级特性（断言、反向引用、递归）是 NFA 引擎的专利，DFA 引擎为保证性能主动放弃这些特性。
    • 

  • 相同特性在不同引擎中可能有不同的语法（如 Python 的 (?P<name>...)）和行为（如 Ruby 的默认多行模式）。
    • 

  • \w 的匹配范围、^ $ 的默认行为是跨语言正则移植中最常见的陷阱。
    • 

  • 根据性能、功能和安全需求选择合适的引擎：RE2 保证安全性能，PCRE2/.NET 提供最丰富的特性。
