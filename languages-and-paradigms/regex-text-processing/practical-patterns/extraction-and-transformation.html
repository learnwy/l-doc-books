提取与转换

数据提取基础

正则表达式的捕获分组是从非结构化文本中提取结构化数据的利器。通过精心设计的模式，可以将散乱的文本转化为可程序化处理的数据。

const logLine = '2026-04-01 14:30:25 [ERROR] Connection timeout after 30s';
const logPattern = /^(?<date>\d{4}-\d{2}-\d{2})\s+(?<time>\d{2}:\d{2}:\d{2})\s+\[(?<level>\w+)\]\s+(?<message>.+)$/;
const { groups } = logPattern.exec(logLine);

键值对提取
从配置文件、URL 参数或日志中提取键值对是常见需求。


const configText = `
host=localhost
port=3306
database=myapp
timeout=30
`;

const kvPattern = /^(\w+)=(.+)$/gm;
const config = {};
for (const [, key, value] of configText.matchAll(kvPattern)) {
  config[key] = value;
}

const url = 'https://example.com?name=Alice&age=30&city=Shanghai';
const params = {};
const paramPattern = /[?&](\w+)=([^&#]*)/g;
for (const [, key, value] of url.matchAll(paramPattern)) {
  params[key] = decodeURIComponent(value);
}

提示： String.prototype.matchAll() 返回迭代器，配合解构赋值和 for...of 循环，是批量提取数据的最优雅方式。记得正则必须带 g 标志。






格式转换
正则替换不仅用于简单的文本替换，更是数据格式转换的强大工具。


const isoDate = '2026-04-01';
isoDate.replace(/(\d{4})-(\d{2})-(\d{2})/, '$2/$3/$1');

isoDate.replace(/(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/, (...args) => {
  const { year, month, day } = args.at(-1);
  return `${year}年${month}月${day}日`;
});

function camelToSnake(str) {
  return str.replace(/[A-Z]/g, (letter) => `_${letter.toLowerCase()}`);
}

function snakeToCamel(str) {
  return str.replace(/_([a-z])/g, (_, letter) => letter.toUpperCase());
}

camelToSnake('backgroundColor');
snakeToCamel('background_color');

模板渲染
使用正则实现简单的模板引擎是正则替换的经典应用。


function render(template, data) {
  return template.replace(/\{\{(\w+(?:\.\w+)*)\}\}/g, (_, path) => {
    return path.split('.').reduce((obj, key) => obj?.[key], data) ?? '';
  });
}

render('Hello {{name}}, welcome to {{location.city}}!', {
  name: 'Alice',
  location: { city: 'Shanghai' },
});

function renderWithFilters(template, data) {
  return template.replace(/\{\{(\w+)(?:\|(\w+))?\}\}/g, (_, key, filter) => {
    let value = data[key] ?? '';
    if (filter === 'upper') value = String(value).toUpperCase();
    if (filter === 'lower') value = String(value).toLowerCase();
    return value;
  });
}

renderWithFilters('Hello {{name|upper}}!', { name: 'alice' });

提示： 生产环境中不应使用正则实现完整的模板引擎——它无法处理条件、循环等逻辑结构。但对于简单的变量替换（如配置文件渲染、通知模板），正则方案简洁高效。






批量文本清洗
正则是数据清洗的核心工具，可以快速处理格式不一致、多余空白、特殊字符等问题。


function cleanText(text) {
  return text
    .replace(/\r\n/g, '\n')
    .replace(/[ \t]+$/gm, '')
    .replace(/\n{3,}/g, '\n\n')
    .replace(/^\s+|\s+$/g, '');
}

function normalizeWhitespace(text) {
  return text.replace(/\s+/g, ' ').trim();
}

function stripHtmlTags(html) {
  return html.replace(/<[^>]*>/g, '');
}

function escapeRegex(str) {
  return str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
}

小结
    

  • 捕获分组配合 matchAll 是从文本中批量提取结构化数据的最佳实践。
    • 

  • 格式转换利用分组重排和替换函数，可以实现日期格式化、命名风格转换等常见需求。
    • 

  • 模板渲染用正则实现简单的变量替换，嵌套属性通过点号路径解析。
    • 

  • 文本清洗是数据处理的第一步，正则可以高效处理换行符、空白、HTML 标签等问题。
    • 

  • escapeRegex 函数是安全地将用户输入插入正则模式的必备工具。
