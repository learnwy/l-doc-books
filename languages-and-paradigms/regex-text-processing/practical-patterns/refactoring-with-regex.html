正则重构

编辑器中的正则替换

现代代码编辑器（VS Code、JetBrains IDE 等）内置了强大的正则查找替换功能，是批量代码重构的高效工具。

查找：console\.log\((.+?)\)
替换：logger.debug($1)
查找：import \{ (.+?) \} from ['"]lodash['"]
替换：import { $1 } from 'lodash-es'
编辑器 正则引擎 捕获组引用 多文件支持
VS Code JavaScript $1 $2 ✅
JetBrains Java $1 $2 ✅
Vim Vim regex \1 \2 手动
Sublime PCRE/Boost $1 \1 ✅ 


提示： VS Code 的正则替换支持 \n 匹配换行符和 $1 引用捕获组。在"在文件中替换"（Ctrl+Shift+H）中启用正则模式，可以进行项目范围的批量重构。替换前务必使用 Git 确保代码可回滚。






API 迁移
当项目需要从旧 API 迁移到新 API 时，正则替换可以自动化大部分机械性工作。


const oldCode = `
const result = await fetch('/api/users');
const data = await result.json();
`;

oldCode.replace(
  /const\s+(\w+)\s*=\s*await\s+fetch\(([^)]+)\);\s*\nconst\s+(\w+)\s*=\s*await\s+\1\.json\(\);/g,
  'const $3 = await api.get($2);',
);
查找：this\.setState\(\{[\s\n]*(\w+):\s*(.+?)[\s\n]*\}\)
替换：this.state.$1 = $2

命名规范统一
正则替换是统一代码命名规范的最佳工具。


function camelToSnake(str) {
  return str
    .replace(/([A-Z])/g, '_$1')
    .toLowerCase()
    .replace(/^_/, '');
}

function snakeToCamel(str) {
  return str.replace(/_([a-z])/g, (_, c) => c.toUpperCase());
}

function kebabToPascal(str) {
  return str.replace(/(^|-)([a-z])/g, (_, _sep, c) => c.toUpperCase());
}
查找：(\w+)_(\w+)_(\w+)
替换（VS Code）：${1}${2:/capitalize}${3:/capitalize}

提示： VS Code 的替换支持特殊转换修饰符：${1:/upcase} 转大写、${1:/downcase} 转小写、${1:/capitalize} 首字母大写。这些修饰符让编辑器内的命名风格转换更加便捷。






代码模式升级
正则可以帮助升级陈旧的代码模式到现代语法。


查找：var (\w+) = (.+?);
替换：const $1 = $2;
查找：function\s+(\w+)\s*\(([^)]*)\)\s*\{[\s\n]*return\s+(.+?);[\s\n]*\}
替换：const $1 = ($2) => $3;
rg -l 'var ' --type js src/ | xargs sed -i '' 's/\bvar\b/const/g'

find src -name '*.js' -exec grep -l 'function' {} + | head -20

function upgradeStringConcat(code) {
  return code.replace(/'([^']*?)'\s*\+\s*(\w+)\s*\+\s*'([^']*?)'/g, '`$1${$2}$3`');
}

upgradeStringConcat("const msg = 'Hello ' + name + '!';");

小结
    

  • 编辑器内置的正则替换（VS Code Ctrl+Shift+H）是最常用的批量重构工具。
    • 

  • API 迁移通过正则替换自动化 require→import、fetch→api 等机械性工作。
    • 

  • 命名风格转换（camelCase↔snake_case↔kebab-case）可以用正则精确实现。
    • 

  • 代码模式升级（var→const、函数→箭头函数）适合用正则批量处理。
    • 

  • 正则重构前必须先 Git 提交，替换后运行类型检查和测试套件验证正确性。
