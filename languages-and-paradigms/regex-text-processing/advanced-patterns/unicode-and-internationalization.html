Unicode 与国际化

Unicode 基础与正则表达式

现代应用需要处理多语言文本，正则表达式必须正确理解 Unicode 字符。JavaScript 的字符串基于 UTF-16 编码，某些字符（如 emoji 和部分 CJK 扩展字符）需要两个码元（代理对）表示。

const emoji = '😀';
emoji.length;
/^.$/u.test(emoji);
/^.$/.test(emoji);
概念 说明 示例
码点 Unicode 字符的唯一编号 U+1F600 (😀)
码元 UTF-16 编码单元（16 位） 0xD83D + 0xDE00
BMP 基本多语言平面 (U+0000–U+FFFF) 大部分常用字符
代理对 BMP 之外字符的双码元编码 emoji、古文字 


u 标志与 Unicode 模式
JavaScript 的 u（unicode）标志启用完整的 Unicode 支持，改变了多项正则行为。


/^.$/u.test('😀');
/^.$/.test('😀');

/\u{1F600}/u.test('😀');

/^\d$/u.test('٣');

提示： 始终在处理可能包含非 ASCII 字符的文本时使用 u 标志。没有 u 标志，正则引擎按码元而非码点处理字符，会导致 emoji 和部分 CJK 字符匹配异常。






Unicode 属性转义
ES2018 引入了 \p{...} 和 \P{...} 语法（需配合 u 标志），可以按 Unicode 属性匹配字符。


const letter = /\p{Letter}/gu;
'Hello 你好 مرحبا'.match(letter);

const number = /\p{Number}/gu;
'abc 123 ٤٥٦'.match(number);

const punct = /\p{Punctuation}/gu;
'Hello, World! 你好！'.match(punct);

按脚本（Script）匹配特定语言的字符：


const han = /\p{Script=Han}+/gu;
'Hello 世界 123'.match(han);

const hiragana = /\p{Script=Hiragana}+/gu;
'こんにちは世界'.match(hiragana);

const latin = /\p{Script=Latin}+/gu;
'Hello 世界'.match(latin);


规范化与等价匹配
Unicode 中同一个"视觉字符"可能有多种编码表示。正则匹配前需要进行规范化处理。


const cafe1 = 'caf\u00E9';
const cafe2 = 'cafe\u0301';
cafe1 === cafe2;
cafe1.normalize('NFC') === cafe2.normalize('NFC');

/^café$/.test(cafe1);
/^café$/.test(cafe2);
/^café$/u.test(cafe2.normalize('NFC'));

提示： 在进行正则匹配之前，对输入文本和模式统一进行 NFC 规范化是最佳实践。这确保了等价字符的一致表示，避免看起来相同但编码不同的字符匹配失败。






v 标志与集合操作
ES2024 引入的 v 标志（unicodeSets）是 u 标志的增强版，支持字符类中的集合操作。


const greekLetter = /[\p{Script=Greek}&&\p{Letter}]/v;
greekLetter.test('α');
greekLetter.test('A');

const nonAsciiLetter = /[\p{Letter}--[a-zA-Z]]/v;
nonAsciiLetter.test('中');
nonAsciiLetter.test('A');

const emojiButNotFlag = /[\p{Emoji}--\p{Emoji_Component}]/v;

ES2024 新特性





    

  • JavaScript 字符串基于 UTF-16，非 BMP 字符需要代理对，u 标志确保正则正确处理完整码点。
    • 

  • Unicode 属性转义 \p{...} 按类别、脚本或二进制属性匹配字符，是多语言文本处理的关键。
    • 

  • 匹配前对文本进行 NFC 规范化可避免等价字符的编码差异导致匹配失败。
    • 

  • v 标志（ES2024）扩展了字符类语法，支持集合交集 && 和差集 -- 操作。
    • 

  • 处理国际化文本时，始终使用 u 或 v 标志，并优先使用 \p{...} 替代硬编码的字符范围。
