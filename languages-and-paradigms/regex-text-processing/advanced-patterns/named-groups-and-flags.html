命名分组与标志位

命名捕获组

ES2018 引入了命名捕获组（Named Capturing Group），使用 (?<name>...) 语法为分组指定有意义的名称，大幅提升正则表达式的可读性和可维护性。

const datePattern = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/;
const match = datePattern.exec('2026-04-01');
match.groups.year;
match.groups.month;
match.groups.day;
语法 含义 引用方式
(?<name>...) 定义命名组 match.groups.name
\k<name> 模式内反向引用 引用已匹配的文本
$<name> 替换字符串引用 replace 中使用 
const tag = /(?<open><(?<tagName>\w+)>)(?<content>.*?)(?<close><\/\k<tagName>>)/;
const result = tag.exec('<div>hello</div>');
result.groups.tagName;
result.groups.content;


命名组在替换中的应用
命名捕获组使 replace 操作更加语义化，代码意图一目了然。


const isoDate = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/g;

'2026-04-01'.replace(isoDate, '$<day>/$<month>/$<year>');

'2026-04-01'.replace(isoDate, (_, _y, _m, _d, _o, _s, groups) => {
  return `${groups.year}年${groups.month}月${groups.day}日`;
});
命名组与解构赋值配合使用：


const urlPattern = /(?<protocol>https?):\/\/(?<host>[^/:]+)(?::(?<port>\d+))?(?<path>\/[^?]*)?/;
const {
  groups: { protocol, host, port, path },
} = urlPattern.exec('https://example.com:8080/api/users');

sticky 标志与 lastIndex
y（sticky）标志要求匹配必须从 lastIndex 属性指定的位置精确开始，而非在该位置之后的任意位置。


const sticky = /\d+/y;
const text = 'abc123def456';

sticky.lastIndex = 3;
sticky.exec(text);
sticky.lastIndex;

sticky.exec(text);

const global = /\d+/g;
global.lastIndex = 0;
global.exec(text);

function tokenize(input) {
  const patterns = {
    NUMBER: /\d+/y,
    OPERATOR: /[+\-*/]/y,
    WHITESPACE: /\s+/y,
  };
  const tokens = [];
  let pos = 0;
  while (pos < input.length) {
    let matched = false;
    for (const [type, regex] of Object.entries(patterns)) {
      regex.lastIndex = pos;
      const m = regex.exec(input);
      if (m) {
        if (type !== 'WHITESPACE') tokens.push({ type, value: m[0] });
        pos = regex.lastIndex;
        matched = true;
        break;
      }
    }
    if (!matched) pos++;
  }
  return tokens;
}
tokenize('12 + 34 * 5');


提示： y 标志非常适合构建简单的词法分析器（Lexer），因为它保证匹配从上一次结束的位置精确开始，不会跳过中间的字符。






hasIndices 标志
d 标志（ES2022）为每个捕获组生成精确的开始和结束索引，通过 match.indices 访问。


const re = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/d;
const match = re.exec('Date: 2026-04-01');

match.indices[0];
match.indices[1];
match.indices.groups.year;
match.indices.groups.month;

小结
    

  • 命名捕获组 (?<name>...) 为分组赋予语义化名称，通过 groups.name 访问。
    • 

  • \k<name> 在模式内反向引用命名组，$<name> 在替换字符串中引用。
    • 

  • JavaScript 共有 8 个标志位，分别控制匹配行为、字符处理、位置定位和元信息生成。
    • 

  • y（sticky）标志从 lastIndex 精确位置开始匹配，适合词法分析场景。
    • 

  • d（hasIndices）标志生成每个捕获组的精确索引范围，便于需要位置信息的文本处理。
