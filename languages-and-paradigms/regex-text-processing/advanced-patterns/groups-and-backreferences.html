Part III · 范式与文本正则表达式与文本处理 简介高级模式 简介分组与反向引用

分组与反向引用

捕获分组

圆括号 () 在正则表达式中创建捕获分组（Capturing Group），它同时完成两件事：将多个元素组合为一个单元，并记住匹配的文本以供后续使用。

const datePattern = /(\d{4})-(\d{2})-(\d{2})/;
const match = datePattern.exec('2026-04-01');
match[0];
match[1];
match[2];
match[3];
属性 含义 示例值
match[0] 完整匹配 "2026-04-01"
match[1] 第一个捕获组 "2026"
match[2] 第二个捕获组 "04"
match[3] 第三个捕获组 "01"
match.index 匹配起始位置 0 
分组编号按左括号出现的顺序从 1 开始。嵌套分组同样遵循此规则：


const nested = /((a)(b(c)))/;
const m = nested.exec('abc');
m[1];
m[2];
m[3];
m[4];


非捕获分组
当只需要分组功能而不需要捕获结果时，使用 (?:...) 创建非捕获分组，避免不必要的内存开销。


const protocol = /(?:https?|ftp):\/\//;
protocol.test('https://example.com');

const withCapture = /(https?|ftp):\/\//;
const withoutCapture = /(?:https?|ftp):\/\//;

withCapture.exec('https://example.com')[1];
withoutCapture.exec('https://example.com')[1];

提示： 在复杂正则中大量使用捕获分组会降低性能并让分组编号难以管理。原则是：如果后续不需要引用某个分组的匹配结果，就使用非捕获分组。






反向引用
反向引用（Backreference）使用 \n 语法引用前面第 n 个捕获分组已经匹配的具体文本（而非模式）。


const repeated = /(\w+)\s+\1/;
repeated.test('hello hello');
repeated.test('hello world');

const xmlTag = /<(\w+)>.*?<\/\1>/;
xmlTag.test('<div>content</div>');
xmlTag.test('<div>content</span>');
反向引用在替换中的应用：


const swapWords = /(\w+)\s+(\w+)/;
'hello world'.replace(swapWords, '$2 $1');

const doubleQuoteToSingle = /"([^"]*)"/g;
'He said "hello"'.replace(doubleQuoteToSingle, "'$1'");

const removeDuplicates = /\b(\w+)\s+\1\b/g;
'the the quick brown fox fox'.replace(removeDuplicates, '$1');

分组在字符串方法中的应用
JavaScript 的字符串方法与正则分组深度集成，提供了强大的文本处理能力。


const log = '2026-04-01 ERROR: Connection timeout';
const parts = log.match(/^(\d{4}-\d{2}-\d{2})\s+(\w+):\s+(.+)$/);
parts[1];
parts[2];
parts[3];

const csv = 'name,age,city';
csv.split(/(,)/);

const template = 'Hello {{name}}, welcome to {{city}}';
const data = { name: 'Alice', city: 'Shanghai' };
template.replace(/\{\{(\w+)\}\}/g, (_, key) => data[key]);


提示： String.prototype.matchAll() 返回一个迭代器，包含每次匹配的完整信息（包括所有捕获组和索引），是处理多次匹配的现代首选方法。






小结
    

  • 捕获分组 () 组合元素并记住匹配内容，编号按左括号出现顺序从 1 开始。
    • 

  • 非捕获分组 (?:...) 仅提供分组功能，不占用编号，适合不需要引用的场景。
    • 

  • 反向引用 \1 在模式中引用已捕获的具体文本，$1 在替换字符串中引用。
    • 

  • JavaScript 的 match、replace、matchAll、split 方法都与分组深度集成。
    • 

  • 优先使用非捕获分组，仅在需要提取或反向引用时使用捕获分组。
