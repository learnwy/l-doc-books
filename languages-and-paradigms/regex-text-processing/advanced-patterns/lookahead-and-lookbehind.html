Part III · 范式与文本正则表达式与文本处理 简介高级模式 简介前瞻与后顾断言

前瞻与后顾断言

断言的本质

前瞻（Lookahead）和后顾（Lookbehind）是零宽断言的高级形式。它们检查某个位置前后是否满足指定条件，但不消费任何字符，不包含在最终匹配结果中。

const priceWithCurrency = /\d+(?=元)/;
priceWithCurrency.exec('100元');

const priceWithoutCurrency = /(?<=\$)\d+/;
priceWithoutCurrency.exec('$100');
断言类型 语法 含义 别名
正向前瞻 (?=...) 后面必须匹配 Positive Lookahead
负向前瞻 (?!...) 后面必须不匹配 Negative Lookahead
正向后顾 (?<=...) 前面必须匹配 Positive Lookbehind
负向后顾 (?<!...) 前面必须不匹配 Negative Lookbehind 


正向前瞻
(?=...) 要求当前位置之后的字符必须匹配指定模式，但不消费这些字符。


const beforeUnit = /\d+(?=px)/g;
'width: 100px; height: 200em'.match(beforeUnit);

const passwordStrength = /^(?=.*[A-Z])(?=.*[a-z])(?=.*\d)(?=.*[!@#$%]).{8,}$/;
passwordStrength.test('Abc123!@');
passwordStrength.test('abcdefgh');
多个前瞻可以叠加在同一位置，实现"与"逻辑：






模式
含义





(?=.*[A-Z])
至少含一个大写字母




(?=.*\d)
至少含一个数字




(?=.*[A-Z])(?=.*\d)
同时满足以上两个条件




(?=.*[A-Z])(?=.*\d)(?=.*[!@#$%]).{8,}
大写+数字+特殊字符+长度≥8







提示： 前瞻叠加是实现密码强度验证的经典技巧。每个前瞻独立检查一个条件，它们共同构成了"同时满足多个条件"的逻辑与效果。






负向前瞻
(?!...) 要求当前位置之后的字符必须不匹配指定模式。


const notFollowedByPx = /\d+(?!px)/g;
'width: 100px; count: 200'.match(notFollowedByPx);

const notJsFile = /\w+\.(?!js\b)\w+/g;
'app.js style.css utils.ts'.match(notJsFile);

const notReserved = /\b(?!if\b|for\b|while\b)\w+\b/g;
'if count for total while loop done'.match(notReserved);
| 场景             | 模式            | 匹配结果          |
| ---------------- | --------------- | ----------------- | ---------- |
| 非 px 单位的数字 | \d+(?!px)     | 非 px 前缀的数字  |
| 非 js 扩展名     | \.(?!js\b)\w+ | 非 .js 的扩展名 |
| 非保留字的标识符 | (?!if\b        | for\b)\w+        | 排除保留字 |




后顾断言
(?<=...) 和 (?<!...) 分别检查当前位置之前的字符是否匹配或不匹配指定模式。


const afterDollar = /(?<=\$)\d+(\.\d{2})?/g;
'Price: $99.99 or €50.00'.match(afterDollar);

const notAfterMinus = /(?<!-)\b\d+\b/g;
'a 10 b -20 c 30'.match(notAfterMinus);

断言的组合应用
前瞻和后顾可以灵活组合，实现复杂的定位需求。


function formatNumber(num) {
  return num.toString().replace(/\B(?=(\d{3})+(?!\d))/g, ',');
}
formatNumber(1234567890);

const betweenTags = /(?<=<b>).*?(?=<\/b>)/g;
'<b>bold</b> text <b>more</b>'.match(betweenTags);

const camelBoundary = /(?<=[a-z])(?=[A-Z])/g;
'backgroundColor'.split(camelBoundary);




组合模式
功能
示例





(?<=A)X(?=B)
X 前是 A 后是 B
提取标签间内容




(?<!A)X(?!B)
X 前非 A 后非 B
排除特定上下文




(?<=A)(?=B)
A 和 B 之间的位置
驼峰拆分




(?=.*A)(?=.*B)X+
包含 A 且包含 B
多条件验证







小结
    

  • 前瞻和后顾是零宽断言，检查位置前后的条件但不消费字符。
    • 

  • 正向前瞻 (?=...) 要求后面匹配，负向前瞻 (?!...) 要求后面不匹配。
    • 

  • 后顾断言检查前面的内容，JavaScript ES2018 起完整支持，部分语言有限制。
    • 

  • 多个前瞻叠加可实现"逻辑与"效果，是密码验证等多条件场景的经典技巧。
    • 

  • 前瞻与后顾的组合可以精确定位两个模式之间的位置，实现千分位分隔、驼峰拆分等功能。
