正则基础 简介

正则表达式的威力始于对基础语法的深刻理解。元字符、字符类、量词和锚点构成了正则表达式的四大基石，掌握它们是编写高效、精确模式匹配表达式的前提。

本章将带你深入四个核心主题：

语法与元字符系统梳理正则表达式的基本语法规则，详解每个元字符的含义与用法，帮助你理解正则表达式的"词汇表"。

字符类介绍方括号表达式、预定义字符类和自定义字符范围，让你能够精确描述"匹配哪些字符"这一基本问题。

量词与贪婪模式解析重复匹配的三种模式——贪婪、惰性和独占，理解它们对匹配结果和性能的深远影响。

锚点与边界讲解行首、行尾、单词边界等零宽断言，掌握"在哪里匹配"的定位技术。

建议从语法与元字符开始顺序阅读，因为后续内容均建立在对基本语法的理解之上。动手实践每个示例，用浏览器控制台或 Node.js REPL 即时验证你的正则表达式。
