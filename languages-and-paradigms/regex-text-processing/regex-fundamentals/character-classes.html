Part III · 范式与文本正则表达式与文本处理 简介正则基础 简介字符类

字符类

什么是字符类

字符类（Character Class）是正则表达式中用方括号 [] 包裹的字符集合，表示"匹配其中任意一个字符"。字符类是精确控制匹配范围的核心工具。

const vowel = /[aeiou]/;
vowel.test('apple');
vowel.test('rhythm');

const hexDigit = /[0-9a-fA-F]/;
hexDigit.test('f');
hexDigit.test('g');
语法 含义 示例 匹配
[abc] 匹配 a、b 或 c 中的任意一个 /[abc]/ a、b、c
[a-z] 匹配 a 到 z 的任意小写字母 /[a-z]/ m、z
[^abc] 匹配除 a、b、c 外的任意字符 /[^abc]/ d、1
[a-zA-Z] 匹配任意英文字母 /[a-zA-Z]/ A、z
[0-9] 匹配任意数字 /[0-9]/ 0、9

范围表达式

连字符 - 在字符类中表示字符范围，基于 Unicode 码点的连续区间。

const lower = /[a-z]/;
const upper = /[A-Z]/;
const digit = /[0-9]/;
const alphanumeric = /[a-zA-Z0-9]/;

const chinese = /[\u4e00-\u9fff]/;
chinese.test('你');
chinese.test('A');

提示： 多个范围可以在同一个字符类中组合使用。[a-zA-Z0-9_] 等价于预定义字符类 \w（在 ASCII 模式下）。






取反字符类
在方括号内的第一个位置放置 ^ 会取反整个字符类，匹配不在集合中的任意字符。


const nonDigit = /[^0-9]/;
nonDigit.test('a');
nonDigit.test('5');

const notWhitespace = /[^ \t\n]/;
notWhitespace.test('x');

预定义字符类
大多数正则引擎提供预定义的快捷字符类，简化常见模式的书写。


const date = /\d{4}-\d{2}-\d{2}/;
date.test('2026-04-01');

const word = /\w+/;
word.exec('hello_world');

const trimmed = /\S+/g;
'  hello  world  '.match(trimmed);

字符类中的特殊字符
在字符类 [] 内部，大多数元字符失去特殊含义，成为字面量。但有几个字符仍需注意。


const special = /[.*+?]/;
special.test('*');
special.test('a');

const withBracket = /[[\]]/;
withBracket.test('[');
withBracket.test(']');
