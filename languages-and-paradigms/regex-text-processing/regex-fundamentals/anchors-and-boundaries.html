Part III · 范式与文本正则表达式与文本处理 简介正则基础 简介锚点与边界

锚点与边界

零宽断言的概念

锚点（Anchor）和边界（Boundary）是一类特殊的正则元素：它们不匹配具体字符，而是匹配字符之间的位置。因此也被称为零宽断言（Zero-width Assertion）。

const startsWith = /^Hello/;
startsWith.test('Hello World');
startsWith.test('Say Hello');

const endsWith = /World$/;
endsWith.test('Hello World');
endsWith.test('World Cup');
锚点 含义 匹配位置
^ 字符串/行的开头 第一个字符之前
$ 字符串/行的结尾 最后一个字符之后
\b 单词边界 单词字符与非单词字符之间
\B 非单词边界 两个同类字符之间
\A 字符串绝对开头 仅字符串起始位置
\Z 字符串绝对结尾 仅字符串结束位置 


行首与行尾锚点
^ 和 $ 的行为取决于是否启用了多行模式（m 标志）。


const text = 'line1\nline2\nline3';

text.match(/^\w+/);
text.match(/^\w+/gm);

text.match(/\w+$/);
text.match(/\w+$/gm);




模式
^ 匹配位置
$ 匹配位置

字符串结尾




多行 m

每行结尾





常见的行锚点使用模式：


const emptyLine = /^$/m;
const commentLine = /^\s*\/\//m;
const indentedLine = /^[ \t]+\S/m;

const multiline = `
function hello() {
  return 'world';
}
`;
multiline.match(/^\s*return.*;$/m);


提示： 在验证用户输入时，始终同时使用 ^ 和 $ 锚定整个字符串。例如 /^\d{6}$/ 确保输入恰好是 6 位数字，而 /\d{6}/ 只要求字符串中包含连续 6 位数字。






单词边界
\b 匹配单词字符（\w）与非单词字符（\W）之间的位置，或字符串的开头/结尾与单词字符之间的位置。


const wholeWord = /\bcat\b/;
wholeWord.test('cat');
wholeWord.test('category');
wholeWord.test('concatenate');

const text = 'cat catalog catfish scattered';
text.match(/\bcat\b/g);
text.match(/\bcat/g);

非单词边界与高级定位
\B 是 \b 的取反，匹配两个同类字符之间的位置。


const midWord = /\Bcat\B/;
midWord.test('education');
midWord.test('cat');
midWord.test('catalog');

const camelCase = /\B[A-Z]/g;
'backgroundColor'.match(camelCase);

function camelToKebab(str) {
  return str.replace(/\B([A-Z])/g, '-$1').toLowerCase();
}
camelToKebab('backgroundColor');
camelToKebab('XMLHttpRequest');


提示： \b 基于 \w 的定义判断边界，而 \w 仅包含 [a-zA-Z0-9_]。这意味着中文字符旁边不会产生单词边界。处理中文文本时需要使用 Unicode 属性（\p{L}）配合前瞻/后顾断言。






多行与全局模式的交互
锚点的行为受多个标志共同影响，理解它们的交互关系至关重要。


const text = 'apple\nbanana\ncherry';

text.match(/^[a-z]+$/);
text.match(/^[a-z]+$/m);
text.match(/^[a-z]+$/gm);

小结
    

  • 锚点匹配的是位置而非字符，^ 和 $ 分别匹配行首和行尾。
    • 

  • 多行模式 m 使 ^ 和 $ 匹配每一行的开头和结尾，而非整个字符串。
    • 

  • \b 匹配单词边界，是实现全词匹配的关键工具。
    • 

  • \B 匹配非单词边界，常用于驼峰命名拆分等词中定位场景。
    • 

  • 输入验证时务必使用 ^...$ 双锚定，确保匹配的是整个字符串而非子串。
