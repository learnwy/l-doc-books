jq 与结构化数据

jq 基础

jq 是一个轻量级的命令行 JSON 处理器，被称为"JSON 的 sed"。它使用自己的查询语言对 JSON 数据进行过滤、映射和转换，并支持正则表达式进行文本匹配。

echo '{"name": "Alice", "age": 30}' | jq '.name'

echo '[1, 2, 3, 4, 5]' | jq '.[] | select(. > 3)'

curl -s 'https://api.example.com/users' | jq '.[].name'
操作符 含义 示例
. 当前对象 jq '.'
.key 取属性 jq '.name'
.[] 遍历数组 jq '.[]'
.[n] 取索引 jq '.[0]'
| 管道 jq '.[] | .name'
select 过滤 jq '.[] | select(.age>20)'
map 映射 jq 'map(.name)'
length 长度 jq '.[] | length' 


jq 中的正则表达式
jq 内置了正则表达式支持，提供 test、match、capture、scan、sub、gsub 等函数。


echo '["hello", "world", "help", "held"]' | jq '.[] | select(test("hel."))'

echo '{"msg": "Error 404: Not Found"}' | jq '.msg | match("([0-9]+)") | .captures[0].string'

echo '{"log": "2026-04-01 ERROR timeout"}' | jq '.log | capture("(?<date>[0-9-]+) (?<level>\\w+) (?<msg>.+)")'

echo '{"text": "Hello World"}' | jq '.text | gsub("(?<w>[A-Z])"; "[\(.w)]")'

echo '{"url": "https://example.com/path?q=1"}' | jq '.url | scan("[a-z]+://([^/]+)") | .[0]'


提示： jq 的正则表达式使用 Oniguruma 引擎（与 Ruby 相同），支持完整的前瞻/后顾断言、命名捕获组等高级特性。正则模式需要作为字符串传入，反斜杠需要双重转义。






CSV 处理
命令行下处理 CSV 文件可以结合多种工具，利用正则表达式处理分隔符和字段提取。


awk -F',' '{print $1, $3}' data.csv

sed '1d' data.csv | awk -F',' '$3 > 100 {print $1, $3}'

cat data.csv | jq -R 'split(",") | {name: .[0], age: .[1], city: .[2]}'

XML 与 HTML 处理
虽然正则不适合完整的 XML/HTML 解析，但在简单场景下配合专用工具可以高效处理。


grep -oP '(?<=<title>).*(?=</title>)' page.html

xmllint --xpath '//item/title/text()' feed.xml

echo '<root><item>hello</item></root>' | xmlstarlet sel -t -v '//item'

curl -s 'https://example.com' | pup 'title text{}'

提示： 永远不要用正则表达式解析嵌套的 HTML/XML。正则无法处理递归嵌套结构，容易产生错误结果。简单的属性提取或已知结构的单层标签可以用正则，其他场景请使用专用解析器。






多格式数据管道
将多种工具通过管道组合，构建强大的结构化数据处理流水线。


cat api_response.json | jq '.data[] | select(.status | test("error|fail"))' | jq -r '.message'

rg -l 'TODO' --json | jq -r '.data.path.text' | sort

cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head -20 | awk '{printf "%s,%s\n", $2, $1}' > top_ips.csv

小结
    

  • jq 是命令行 JSON 处理器，内置正则支持（test、match、capture、gsub），使用 Oniguruma 引擎。
    • 

  • CSV 处理简单场景用 awk，复杂场景（含引号、换行）使用 csvkit 或 miller 专用工具。
    • 

  • XML/HTML 解析不应使用正则，应使用 xmllint、pup 等专用解析器，仅在简单提取场景下例外。
    • 

  • 通过管道将 jq、rg、awk、sed、sort 等工具组合，可以构建处理任意格式数据的流水线。
    • 

  • jq 的 capture 函数配合命名捕获组，能够将非结构化文本直接转换为结构化 JSON 对象。
