grep 与 ripgrep

核心概念

grep 与 ripgrep 都是"逐行扫描、输出匹配行"的搜索工具，区别在于现代化程度：grep 提供 BRE、ERE、PCRE 三级正则语法与丰富的行级选项；ripgrep（rg）默认递归搜索、自动尊重 .gitignore、多线程并行，速度远超传统 grep。

  • grep 的语法级别由选项决定：默认 BRE、-E 启用 ERE、-P 启用 PCRE、-F 退化为纯文本匹配。
  • ripgrep 默认使用 RE2 风格引擎（不支持断言），需要断言时加 --pcre2 切换到 PCRE2。
  • 两者都易与 sort、uniq、awk、sed 通过管道组合，构建文本分析流水线。

grep 基础

grep（Global Regular Expression Print）是 Unix 系统中最常用的文本搜索工具。它逐行扫描输入，输出所有匹配指定正则模式的行。

代码示例

grep 'error' server.log

grep -i 'warning' server.log

grep -rn 'TODO' src/

grep -c 'ERROR' server.log

速查表

| 选项 | 含义 | 示例 | | ------ | ---------------------- | ------------------------ | --- | | -i | 忽略大小写 | grep -i 'error' | | -r | 递归搜索目录 | grep -r 'pattern' dir/ | | -n | 显示行号 | grep -n 'pattern' | | -c | 只显示匹配行数 | grep -c 'pattern' | | -l | 只显示匹配的文件名 | grep -rl 'pattern' | | -v | 反转匹配 | grep -v 'debug' | | -w | 全词匹配 | grep -w 'error' | | -A n | 显示匹配行后 n 行 | grep -A 3 'error' | | -B n | 显示匹配行前 n 行 | grep -B 3 'error' | | -C n | 显示匹配行前后各 n 行 | grep -C 3 'error' | | -E | 使用扩展正则（ERE） | grep -E 'a | b' | | -P | 使用 Perl 正则（PCRE） | grep -P '\d+' |

图示

graph TD
    GREP["grep 变体"] --> BRE["grep (BRE)"]
    GREP --> ERE["grep -E / egrep (ERE)"]
    GREP --> PCRE["grep -P (PCRE)"]
    GREP --> FIXED["grep -F / fgrep (固定字符串)"]

    ERE --> E1["( ) { } 直接使用"]
    PCRE --> P1["\\d \\w 前瞻后顾"]
    FIXED --> F1["纯字符串匹配,最快"]

grep 正则表达式

grep 支持三种正则语法级别，选择正确的级别很重要。

代码示例

grep 'error\|warning' server.log

grep -E 'error|warning' server.log

grep -P '(?<=\[)\d{4}-\d{2}-\d{2}(?=\])' server.log

grep -E '^[0-9]{1,3}(\.[0-9]{1,3}){3}' access.log

速查表

语法级别 选项 元字符支持 使用场景
BRE 默认 . * ^ $ [] 简单搜索
ERE -E + ? {} | () 复杂模式
PCRE -P \d \w (?=) (?<=) 高级断言
固定字符串 -F 无正则，纯文本匹配 搜索特殊字符 
grep -F '*.log' config.txt

grep -E '^\s*(function|const|let|var)\s' src/*.js

grep -P '(?<=version":\s")\d+\.\d+\.\d+' package.json
  • 提示： 当搜索包含正则元字符的字面文本时（如 $100、file.txt），使用 grep -F 是最安全的选择，无需担心转义问题。

ripgrep 现代搜索

ripgrep（rg）是 grep 的现代替代品，由 Rust 编写。它默认递归搜索、尊重 .gitignore 规则、支持 Unicode，并且速度远超传统 grep。

代码示例

rg 'TODO|FIXME' src/

rg -t js 'import.*from'

rg --json 'error' server.log

rg -g '*.md' 'regex'

速查表

特性 grep ripgrep
默认递归 需要 -r 默认递归
.gitignore 不支持 自动尊重
文件类型过滤 手动 --include -t type
Unicode 支持 有限 完整
性能 快 极快（多线程）
正则引擎 POSIX/PCRE RE2 风格 + PCRE2
输出格式 文本 文本/JSON

    RG --> SMART["智能过滤"]
    RG --> RICH["丰富输出"]
    FAST --> F1["Rust 编写"]
    FAST --> F2["内存映射 I/O"]
    FAST --> F3["多线程并行"]
    SMART --> S1["自动 .gitignore"]

    SMART --> S3["隐藏文件跳过"]
    RICH --> R1["彩色高亮"]
    RICH --> R2["JSON 输出"]

ripgrep 高级用法

ripgrep 的高级功能使其成为开发者的日常搜索利器。

代码示例

rg -U 'function.*\{[\s\S]*?\}' src/

rg --pcre2 '(?<=import\s)[\w]+(?=\sfrom)' src/

rg -r '$1_$2' '([a-z])([A-Z])' src/utils.js

rg -l 'deprecated' | xargs rg 'import'

速查表

选项 功能 示例
-U 多行匹配 rg -U 'start.*end'
--pcre2 启用 PCRE2 引擎 rg --pcre2 '(?<=x)y'
-r 替换匹配内容（输出） rg -r 'new' 'old'
-l 只输出文件名 rg -l 'pattern'
--stats 显示搜索统计 rg --stats 'error'
-g 文件 glob 过滤 rg -g '!test*' 'func'
--sort 排序输出 rg --sort path 'error' 
rg -t js -t ts 'console\.(log|warn|error)' --stats

rg -g '!node_modules' -g '!dist' 'TODO' --count

rg --type-add 'web:*.{html,css,js}' -t web 'color'
  • 提示： ripgrep 默认使用 Rust 的 regex crate（基于 RE2 风格的 DFA 引擎），不支持前瞻/后顾断言。需要断言时添加 --pcre2 标志切换到 PCRE2 引擎。

搜索模式与管道组合

将 grep/ripgrep 与其他命令行工具组合，可以构建强大的文本分析流水线。

代码示例

rg -c 'ERROR' server.log | sort -t: -k2 -rn | head -10

rg -oN '\b\d{1,3}(\.\d{1,3}){3}\b' access.log | sort | uniq -c | sort -rn

rg 'import.*from' -t ts --no-filename | sed "s/.*from ['\"]//;s/['\"].*//" | sort | uniq -c | sort -rn

速查表

管道模式 功能
rg → sort → uniq 统计去重
rg → awk 字段提取
rg → sed 二次替换
rg -l → xargs rg 两阶段搜索
rg --json → jq 结构化处理

图示

graph LR
    RG["rg 搜索"] --> PIPE["|"]
    PIPE --> SORT["sort 排序"]
    SORT --> UNIQ["uniq 去重"]
    UNIQ --> HEAD["head 取前N"]
    PIPE --> AWK["awk 字段"]
    PIPE --> SED["sed 替换"]
    PIPE --> JQ["jq 解析"]

小结

mindmap
  root((grep 与 ripgrep))
    grep
      经典搜索工具

    ripgrep
      Rust 高性能
      默认递归 + gitignore

      RE2 + PCRE2
    正则选择
      简单用 BRE
      复杂用 ERE

      "rg → sort → uniq"
      "rg → awk/sed"

  • grep 是 Unix 经典文本搜索工具，支持 BRE、ERE 和 PCRE 三种正则语法。
  • ripgrep 是 grep 的现代替代品，默认递归、尊重 .gitignore、多线程并行，速度极快。
  • grep 的 -F 选项用于纯文本匹配，-E 启用扩展正则，-P 启用 Perl 正则。
  • ripgrep 默认使用 RE2 风格引擎，--pcre2 选项启用完整 PCRE2 支持。
  • 将 grep/ripgrep 与 sort、uniq、awk、sed 通过管道组合，可以构建强大的文本分析流水线。
