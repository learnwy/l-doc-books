Part III · 范式与文本正则表达式与文本处理 简介文本处理工具 简介sed 与 awk

sed 与 awk

sed 流编辑器

sed（Stream Editor）是 Unix/Linux 系统中最重要的文本处理工具之一。它以流的方式逐行处理文本，支持正则表达式驱动的查找、替换、删除和插入操作。

echo "Hello World" | sed 's/World/Earth/'

echo "2026-04-01" | sed 's/\([0-9]\{4\}\)-\([0-9]\{2\}\)-\([0-9]\{2\}\)/\3\/\2\/\1/'

cat access.log | sed -n '/ERROR/p'
命令 含义 示例
s 替换 s/old/new/
d 删除行 /pattern/d
p 打印行 -n '/pattern/p'
i 在行前插入 /pattern/i\text
a 在行后追加 /pattern/a\text
c 替换整行 /pattern/c\text
y 字符转换 y/abc/ABC/ 


sed 替换进阶
sed 的 s 命令支持丰富的正则语法和替换选项。


echo "foo bar foo" | sed 's/foo/baz/'
echo "foo bar foo" | sed 's/foo/baz/g'

echo "Hello World" | sed 's/\(Hello\) \(World\)/\2 \1/'

echo "camelCase" | sed 's/\([a-z]\)\([A-Z]\)/\1_\l\2/g'
替换标志详解：






标志
含义

忽略大小写（GNU sed）

将替换结果写入文件

echo "line with    extra   spaces" | sed 's/  */ /g'

sed -i '' 's/TODO/DONE/g' *.md

sed -n '10,20p' file.txt

sed '/^$/d' file.txt


提示： macOS 的 sed 是 BSD 版本，与 GNU sed 有语法差异。-i 选项在 macOS 上需要指定备份后缀（空字符串 '' 表示不备份），而 GNU sed 可以直接 -i。建议安装 GNU sed（brew install gnu-sed）以获得一致的体验。






awk 编程语言
awk 是一种面向文本处理的编程语言，以模式-动作（Pattern-Action）为基本范式。它将每行输入自动按分隔符拆分为字段，天然适合处理结构化文本数据。


echo "Alice 90 85 92" | awk '{print $1, ($2+$3+$4)/3}'

awk -F',' '{print $1, $3}' data.csv

awk '/ERROR/ {count++} END {print count}' server.log

awk 中的正则表达式
awk 原生支持正则表达式作为模式匹配条件，并提供了 match、sub、gsub 等正则函数。


awk '/^[0-9]{4}-[0-9]{2}-[0-9]{2}/' log.txt

echo "Hello World" | awk '{gsub(/[aeiou]/, "*"); print}'

echo "2026-04-01 ERROR timeout" | awk 'match($0, /[0-9]{4}-[0-9]{2}-[0-9]{2}/) {print substr($0, RSTART, RLENGTH)}'

awk -F'[,;]' '{for(i=1;i<=NF;i++) print $i}' mixed.csv

awk '{
  for(i=1; i<=NF; i++)
    if($i ~ /^[0-9]+$/) sum += $i
}
END {print "Sum:", sum}' data.txt


提示： awk 使用 ERE（扩展正则表达式）语法，不需要像 BRE（基本正则表达式）那样转义圆括号和花括号。gawk（GNU awk）还支持 \b、\w 等 Perl 风格的转义序列。

小结
    

  • sed 是流编辑器，擅长逐行的查找替换和行操作，s 命令是最常用的功能。
    • 

  • awk 是面向文本处理的编程语言，以模式-动作范式自动拆分字段，适合结构化数据处理。
    • 

  • sed 使用 BRE（基本正则），-E 选项切换为 ERE（扩展正则）；awk 默认使用 ERE。
    • 

  • sed 适合简单替换和行操作，awk 适合字段提取、数值计算和复杂逻辑。
    • 

  • 实际工作中常通过管道将 sed、awk 与其他工具组合使用，发挥各自优势。
