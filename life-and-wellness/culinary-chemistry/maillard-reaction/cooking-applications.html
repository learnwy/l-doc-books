锅气（Wok Hei）的科学：


中式炒锅在明火上达到的温度远超一般烹饪（锅底可达 400°C+），食材在极短时间内经历：


    

  1. 表面水分瞬间蒸发 → aw 骤降
    2. 

  2. 高温触发极快美拉德反应 → 烤香
    3. 

  3. 食用油在高温下裂解 → 脂质氧化产物
    4. 

  4. 蛋白质热解 → 含氮杂环
    5. 



这四重反应在数十秒内同时发生，产生复合的「锅气」风味——是单纯延长低温加热无法复制的。

反向煎烤（Reverse Sear）
现代烹饪中的「反向煎烤」技术体现了温度-时间策略的精妙组合：


优势分析：


    

  • 低温阶段：肉内部均匀达到目标温度，无过热灰带
    • 

  • 静置后：表面水分蒸发，aw 降低
    • 

  • 高温煎封：干燥的表面在极短时间内产生强烈美拉德反应
    • 

  • 对比传统先煎后烤：传统法表面焦壳下有过热灰带，且煎后内部温度不均
    •

盐渍风干的科学：


以烤全鸡为例，提前 12-24 小时撒盐（每千克鸡肉约 10g 盐）并冷藏无覆盖：


    

  1. 渗透压脱水：盐溶解后在肉表面形成高渗环境，抽出表层水分
    2. 

  2. 蛋白质溶解重组：盐溶性蛋白质部分溶解后在表面干燥时形成紧致薄膜
    3. 

  3. 冷藏低湿度：冰箱内相对湿度通常 30-40%，持续风干表面
    4. 

  4. 结果：表皮 aw 从 ~0.99 降至 ~0.85-0.90，烤制时褐变速度显著加快
    5.
