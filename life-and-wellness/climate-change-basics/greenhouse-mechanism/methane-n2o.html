甲烷与氧化亚氮

甲烷（CH₄）概述

甲烷是仅次于 CO₂ 的第二重要人为温室气体。虽然其大气浓度远低于 CO₂（ppb 级 vs ppm 级），但单分子的增温效应远强于 CO₂，且甲烷减排可在短期内产生显著的降温效果——这使其成为近期气候行动的高优先级目标。

全球增温潜势（GWP） 是比较不同温室气体增温效应的标准化指标。GWP-100 = 28 意味着在100年时间尺度上，1吨 CH₄ 的增温效应等同于 28 吨 CO₂。但由于甲烷寿命短，其20年 GWP 高达 80——在短期内甲烷的增温效应极为显著。

甲烷排放源

全球甲烷年排放量约 580 Mt CH₄/yr（2020年代初），其中自然源和人为源各占约一半。

人为排放源

畜牧业


    

  • 反刍动物（牛、羊）的肠道发酵是最大的单一人为甲烷源
    • 

  • 全球约 10亿头牛，每头每天产生 250-500升 CH₄
    • 

  • 粪便管理也贡献显著排放
    • 

  • 随着全球肉类需求增长（尤其发展中国家），此项排放持续上升
    • 



化石燃料泄漏


    

  • 天然气生产、加工、输送过程中的泄漏（"逃逸排放"）
    • 

  • 煤矿开采伴生甲烷释放
    • 

  • 石油开采中的伴生气放空/燃烧
    • 

  • IEA 估计：全球油气行业 2023年甲烷泄漏约 120 Mt，其中 70% 以上技术上可避免
    • 



湿地与水稻


    

  • 厌氧环境下有机物被产甲烷菌分解
    • 

  • 水稻淹水种植模式创造人工湿地条件
    • 

  • 间歇灌溉（AWD）技术可减排 30-50%
    • 



自然排放源
    

  • 天然湿地：最大自然源，约 150-200 Mt/yr
    • 

  • 白蚁：肠道厌氧微生物产甲烷，约 10-20 Mt/yr
    • 

  • 海洋：海底甲烷渗漏和海洋微生物产甲烷
    • 

  • 永久冻土：解冻释放被封存的有机碳，产甲烷菌分解后排放
    • 



甲烷的大气化学汇
甲烷的主要去除途径是与对流层中的羟基自由基（OH·）反应：


CH4+OH⋅→CH3⋅+H2OCH_4 + OH· → CH_3· + H_2OCH4​+OH⋅→CH3​⋅+H2​O
这一反应是甲烷12年大气寿命的决定因素。OH·浓度本身受多种因素影响（如 NOx 排放、水蒸气浓度、紫外辐射），使甲烷寿命和浓度变化的归因变得复杂。

2020-2024年间大气甲烷增速异常偏高（年增 10-15 ppb/yr，远高于此前的 5-7 ppb/yr）。确切原因仍在研究中，可能与热带湿地对温暖气候的响应增强有关——这本身可能构成一个碳循环正反馈。


MethaneSAT 与卫星监测突破
2024年3月发射的 MethaneSAT 卫星标志着甲烷监测进入新时代：


    

  • 空间分辨率：可识别 100m × 400m 地面像元的甲烷浓度增强
    • 

  • 检测灵敏度：可探测 2 ppb 的甲烷浓度增强
    • 

  • 覆盖范围：全球主要油气产区的定期扫描
    • 

  • 关键发现：2024-2025年初步数据揭示大量此前未报告的油气基础设施泄漏源
    • 

  • 配合 TROPOMI（Sentinel-5P）和 GHGSat 的商业星座，形成多尺度甲烷监测网络
    • 



全球甲烷承诺
2021年 COP26 上提出的全球甲烷承诺（Global Methane Pledge） 目标为：


    

  • 2030年前将全球甲烷排放在2020年基础上减少 30%
    • 

  • 截至2025年已有超过 155个国家签署
    • 

  • 如果完全实现，可避免约 0.2°C 的2050年升温
    • 

  • 但截至2025年中期，全球甲烷排放仍在增长——目标面临严峻挑战
    •

N₂O 不仅是温室气体，还是当前最大的平流层臭氧消耗物质（在 CFCs 被禁止后）。其大气寿命长达121年，意味着排放后影响持续超过一个世纪。


N₂O 排放源
农业是 N₂O 排放的绝对主导源：


    

  1. 合成氮肥施用：施用的氮肥中约 1-5% 通过硝化-反硝化过程转化为 N₂O
    2. 

  2. 有机肥/粪肥：类似机制，但分布更分散
    3. 

  3. 农业土壤管理：灌溉、土壤压实等影响氧化还原条件
    4. 

  4. 间接排放：氮的淋溶和挥发后在下游环境中转化为 N₂O
    5. 



全球氮肥使用量从1960年的约 12 Mt N/yr 增长到2020年代的约 110 Mt N/yr——直接驱动了 N₂O 排放的持续增长。


N₂O 的减排挑战
与 CO₂（可通过能源转型减排）和 CH₄（可通过泄漏控制和畜牧改良减排）不同，N₂O 减排面临独特困难：


    

  • 粮食安全对氮肥有刚性需求
    • 

  • 排放高度分散（每一块农田都是排放源）
    • 

  • 减排技术成熟度有限：精准施肥、硝化抑制剂（如 DCD）、4R养分管理
    •

SLCPs 减排的战略意义
减少 SLCPs 排放可以在 20-40年内 产生显著降温效果——远快于 CO₂ 减排的气候收益显现时间。CCAC（气候与清洁空气联盟）估计，到2050年实现 SLCPs 最大可行减排可避免约 0.5°C 升温。


但 SLCPs 减排不能替代 CO₂ 减排——它只能"争取时间"：


    

  • 短期降温效果显著，但停止减排后效果迅速消失
    • 

  • 长期气候稳定仍然取决于 CO₂ 累积排放的控制
    • 

  • 最优策略是 同步推进 CO₂ 深度减排与 SLCPs 快速减排
    • 



氟化气体与Kigali修正案
氢氟碳化物（HFCs）是增长最快的温室气体类别（GWP 可达 1000-14,000），主要用作制冷剂。2016年《蒙特利尔议定书》Kigali修正案规定到2045年将 HFCs 产量和消费量削减 80-85%。截至2025年，该修正案已获150多个缔约方批准。中国作为全球最大 HFCs 生产国，已于2024年启动 HFCs 配额管理制度。


温室气体的协同效应
不同温室气体的气候效应并非简单叠加——存在复杂的化学和辐射协同效应：


    

  • CH₄ 氧化产生对流层 O₃ 和平流层 H₂O（均为温室效应贡献）
    • 

  • CH₄ 消耗 OH·可能延长其自身和其他气体的大气寿命
    • 

  • N₂O 消耗平流层 O₃ → 改变紫外辐射通量 → 影响对流层光化学
    • 



这些协同效应使单一温室气体减排的气候收益难以精确孤立评估，也是综合气候模型复杂性的重要来源。
