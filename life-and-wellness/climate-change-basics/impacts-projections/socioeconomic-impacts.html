Part III · 气候与能源转型气候变化基础影响与预测社会经济影响

社会经济影响

概述

气候变化的物理影响通过复杂的社会经济传导机制，最终作用于人类社会的粮食安全、水资源、经济增长、人口分布和公共健康等各个维度。本文梳理气候变化的主要社会经济影响，并介绍量化评估这些影响的经济模型。

关键结论：


    

  • 适度升温（<1.5°C）对全球总产量影响有限，但区域分化严重
    • 

  • 超过 2°C 后，大多数地区主要作物减产，适应措施难以完全抵消
    • 

  • 全球同时歉收的风险增加——多个"粮仓"同时遭遇极端事件的概率上升
    • 



粮食系统的系统性风险
    

  • 供应链脆弱性：全球约 25% 的热量跨国贸易，一国减产可通过贸易网络传导
    • 

  • 价格波动：极端事件导致期货价格剧烈波动（如2010年俄罗斯热浪 → 小麦价格翻倍）
    • 

  • 营养质量下降：高 CO₂ 环境下谷物蛋白质含量下降 6-13%，锌和铁含量降低
    • 

  • 渔业转移：海洋变暖导致鱼类资源向高纬度迁移，热带沿海国家渔获量下降
    • 



水资源
水循环变化
全球变暖从根本上改变水循环：


    

  • 全球平均降水量随升温增加约 2-3%/K
    • 

  • 但分布极不均匀："湿区更湿，干区更干"的总体趋势
    • 

  • 蒸散发增加 → 部分地区即使降水不减少，水资源仍可能趋紧
    • 

  • 冰川退缩 → 依赖冰川融水的河流在初期流量增加，中后期急剧减少
    •

关键区域风险
    

  • 中亚干旱区：降水减少 + 冰川退缩 → 灌溉用水危机
    • 

  • 地中海地区：显著干旱化，水库蓄水量下降
    • 

  • 南亚：季风变率增大，洪涝和干旱交替加剧
    • 

  • 中国华北：地下水超采 + 降水不确定性 → 供水风险
    • 

  • 非洲萨赫勒：极端降水与干旱的交替 → 农业和饮用水不稳定
    • 



人口迁移
气候驱动的人口流动
世界银行《Groundswell》报告（2021年更新）估计：


    

  • 到2050年，在内部气候迁移（国内）方面，按悲观情景可能涉及 2.16亿人
    • 

  • 主要驱动因素：水资源短缺、作物产量下降、海平面上升、极端事件
    • 

  • 热点地区：撒哈拉以南非洲（8600万）、南亚（4000万）、拉丁美洲（1700万）
    • 



迁移模式
被困人口（Trapped Populations）是容易被忽视的群体——他们面临严重的气候风险但缺乏经济能力或社会网络来迁移，是气候脆弱性最高的人群。


跨境迁移与安全
    

  • 气候变化极少是唯一的迁移原因，通常与贫困、冲突、治理失败交织
    • 

  • 但气候变化作为"威胁乘数"（threat multiplier）加剧现有社会矛盾
    • 

  • 典型案例：叙利亚2006-2010年干旱 → 农村人口流入城市 → 加剧社会紧张 → 成为内战催化剂之一
    • 



经济损失估算
综合评估模型（IAMs）
IAMs 是量化气候变化经济损失的主要工具，代表性模型包括：


DICE/RICE 模型（Nordhaus）


    

  • Dynamic Integrated Climate-Economy Model
    • 

  • William Nordhaus（2018年诺贝尔经济学奖）开发
    • 

  • 将简化气候模型与经济增长模型耦合
    • 

  • 核心输出："损害函数"——将升温映射为 GDP 损失
    • 

  • DICE 估计 +3°C 升温约导致全球 GDP 损失 2-3%
    • 



FUND 模型（Tol）


    

  • 分部门损害估算（农业、海平面、健康等）
    • 

  • 更细致的区域分解
    • 

  • 通常给出较低的损害估计
    • 



PAGE 模型（Hope）


    

  • 概率评估：纳入低概率-高影响的尾部风险
    • 

  • 用于英国 Stern Review 的经济分析
    • 



损害函数的争议
传统 IAM 的损害函数受到广泛质疑：






批评要点
具体问题





低估尾部风险
二次多项式拟合无法捕捉灾难性的高温影响




忽视非市场损失
生态系统服务、文化遗产、生命损失难以货币化




不考虑不可逆性
临界点和级联效应未纳入




贴现率争议
高贴现率严重缩小未来损害的现值




区域不均匀性
全球平均掩盖了脆弱国家的巨大损失





新一代损害估计
近年来涌现的实证研究（基于气象数据与经济产出的面板回归）给出了远高于传统 IAM 的损害估计：


    

  • Burke et al. (2015, Nature)：升温 +3°C 可能导致全球 GDP 损失 23%（相对无气候变化基线）
    • 

  • Kalkuhl & Wenz (2020)：确认非线性温度-增长关系
    • 

  • Kotz et al. (2024, Nature)：仅考虑 2049 年前的气候变化承诺损害，全球年均损失已达 38万亿美元（2024年美元），约为全球 GDP 的 19%
    • 

  • 分布极度不均：低纬度发展中国家损失可达 GDP 的 20-30%+，而部分高纬度地区可能短期受益
    • 



适应的经济价值
投资气候适应的收益-成本比通常极高：


    

  • 全球气候适应投资需求：2030年前每年 1400-3000亿美元
    • 

  • 当前年投资额：约 210亿美元（巨大缺口）
    • 

  • 收益-成本比：早期预警系统约 1:10，气候韧性基础设施约 1:4-1:6
    • 

  • 但适应存在极限——超过一定升温阈值后，部分风险无法通过适应消除
    • 



气候不平等
"碳不平等"
全球排放的分布极度不均：


    

  • 最富10%人口贡献了全球约 50% 的排放
    • 

  • 最穷50%人口仅贡献约 12% 的排放
    • 

  • 人均累积排放：美国 ~1600 tCO₂、欧盟 ~900 tCO₂、中国 ~220 tCO₂、印度 ~50 tCO₂
    • 



影响的不对称分布
气候变化的影响恰恰集中在历史排放最少的地区：


    

  • 非洲：历史排放占全球 <4%，但面临最严重的干旱、粮食不安全和极端高温
    • 

  • 小岛屿发展中国家：排放几乎可忽略，却面临海平面上升导致的国土淹没
    • 

  • 南亚：大量贫困人口暴露于洪水、热浪和水资源枯竭
    • 



代际不平等
    

  • 2020年出生的儿童将经历其祖父母 2-7倍 的极端事件暴露
    • 

  • "碳预算"的分配本质上是代际公平问题——当代排放消耗了后代的气候空间
    • 

  • 气候诉讼浪潮：全球已有 2000+ 起气候相关法律案件，多数涉及代际公平诉求
    • 



社会碳成本（SCC）
定义与意义
社会碳成本（Social Cost of Carbon, SCC） 是额外排放1吨 CO₂ 对社会造成的边际损害的经济折现值。SCC 是碳定价政策（碳税）的理论基础，也用于成本-效益分析中评估减排项目的社会价值。

SCC 的巨大范围差异主要来自：


    

  1. 贴现率选择：1%变化可导致 SCC 翻2-3倍
    2. 

  2. 损害函数假设：是否纳入临界点和尾部风险
    3. 

  3. 时间范围：是否计算数百年后的损害
    4. 



政策应用
    

  • 碳税设定：理论上碳税应等于 SCC（庇古税原则）
    • 

  • 投资评估：美国联邦项目的成本效益分析中使用 SCC 量化减排的社会收益
    • 

  • 碳市场参考：EU ETS 碳价（2024年约 60-80 €/tCO₂）仍低于最新 SCC 估计
    • 

  • 企业内部碳定价：超过 2000家企业使用内部碳价指导投资决策
    • 



SCC 的持续上修表明：气候行动的经济合理性正在增强——从"减排是成本负担"转向"减排是避免更大损失的投资"。这一认知转变是全球气候政策加速的经济学基础。
