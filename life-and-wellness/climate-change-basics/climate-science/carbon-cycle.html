Part III · 气候与能源转型气候变化基础气候科学基础碳循环

碳循环

碳循环概述

碳循环是地球系统中碳元素在大气圈、水圈、岩石圈和生物圈之间持续流转的过程。碳是所有有机物的骨架元素，也是温室气体 CO₂ 和 CH₄ 的核心组分。理解碳循环的自然过程和人为扰动，是把握气候变化根本原因的关键。

全球碳库储量

地球上的碳以不同形态储存在各个圈层中：

碳库 储量 (GtC) 停留时间 主要形态
大气 ~880 (2026) ~5年（混合时间） CO₂, CH₄
海洋表层 ~900 数年-数十年 溶解无机碳(DIC)
海洋深层 ~37,000 数百-数千年 DIC, 碳酸盐
陆地植被 ~450 数年-数百年 有机碳
土壤有机碳 ~1,700 数十-数千年 腐殖质
永久冻土 ~1,400 数千年（正在解冻） 冻结有机碳
化石燃料 ~10,000 数百万年 煤/石油/天然气
岩石圈碳酸盐 >60,000,000 数亿年 CaCO₃

大气中的碳含量虽然相对较小，但因为它直接决定温室效应强度，且是连接其他碳库的"枢纽"，所以是气候变化研究的核心关注对象。

碳源与碳汇

自然碳循环

在人类活动干预之前，自然碳循环近似处于动态平衡状态——大气与陆地、大气与海洋之间的碳交换量大致相等，大气 CO₂ 浓度在千年尺度上相对稳定（冰期-间冰期变化范围为 180–280 ppm）。


主要碳汇
碳汇是指从大气中净吸收 CO₂ 的过程或系统：


    

  1. 陆地生物圈碳汇（~3.1 GtC/yr，2012-2021均值）
    

      

    • 光合作用增强（CO₂ 施肥效应）
      • 

    • 北方高纬度地区生长季延长
      • 

    • 造林和森林恢复
      • 

    

    2. 

  2. 海洋碳汇（~2.9 GtC/yr，2012-2021均值）
    

      

    • 溶解度泵：CO₂ 溶解于冷的高纬度表层水
      • 

    • 生物泵：浮游植物光合固碳后沉降至深海
      • 

    • 碳酸盐泵：CaCO₃ 形成与沉降
      • 

    

    3. 

  3. 合计：陆地 + 海洋碳汇约吸收了人为排放的 ~54%，剩余 ~46% 留在大气中
    

    4. 



主要碳源（人为）
人为碳源打破了自然碳循环的平衡：


    

  • 化石燃料燃烧：~9.6 GtC/yr（2022年）
    • 

  • 土地利用变化（毁林、农业扩张）：~1.2 GtC/yr
    • 

  • 水泥生产（�ite石分解）：~0.6 GtC/yr
    • 

  • 合计人为排放：~11.4 GtC/yr（~41.8 GtCO₂/yr）
    • 



海洋碳泵
海洋是最大的活跃碳库（不计岩石圈），其碳循环通过三种"泵"机制运作：


溶解度泵（Solubility Pump）
CO₂ 在冷水中溶解度更高。高纬度海区（北大西洋、南大洋）表层水冷却时大量吸收大气 CO₂，随后通过热盐环流（THC）下沉至深海，将碳"泵"入深层。当深层水在赤道附近上升时，温度升高，CO₂ 释放回大气。


溶解度泵的效率受以下因素影响：


    

  • 海表温度：全球变暖 → 溶解度降低 → 碳汇能力减弱
    • 

  • 热盐环流强度：AMOC 减弱 → 深水形成减少 → 碳封存效率下降
    • 

  • 海冰覆盖：海冰减少 → 更多海气交换面积（短期可增加吸收）
    • 



生物泵（Biological Pump）
浮游植物通过光合作用将溶解 CO₂ 转化为有机碳。死亡的浮游生物和粪粒向深海沉降（"海洋雪"），将碳从表层输送到深海。关键环节：


    

  1. 初级生产：表层浮游植物固碳 ~50 GtC/yr
    2. 

  2. 碳输出：约 10-20% 的表层有机碳沉降穿越 200m 深度
    3. 

  3. 深海封存：到达 1000m 以下的碳可被封存数百至数千年
    4. 

  4. 限制因子：铁、氮、磷等营养盐的可用性
    5. 



碳酸盐反泵（Carbonate Counter-Pump）
部分海洋生物（有孔虫、翼足目、珊瑚藻）构建 CaCO₃ 外壳。形成碳酸钙的过程释放 CO₂：


Ca2++2HCO3−→CaCO3↓+H2O+CO2↑Ca^{2+} + 2HCO_3^- → CaCO_3↓ + H_2O + CO_2↑Ca2++2HCO3−​→CaCO3​↓+H2​O+CO2​↑
这实际上是一个碳源过程（与生物泵方向相反），但 CaCO₃ 沉降至深海后可长期封存碳。海洋酸化正在威胁这一过程——当海水 pH 降低时，CaCO₃ 溶解度增加，影响钙化生物存活。


土壤碳库
土壤有机碳（SOC）是陆地生态系统中最大的碳库，约 1,700 GtC（0-1m深度），若包含深层和永久冻土，总量超过 3,000 GtC。


土壤碳的形成与分解
    

  • 输入：植物凋落物、根系分泌物、死亡根系
    • 

  • 转化：微生物分解有机质，一部分矿化为 CO₂ 释放，另一部分转化为稳定腐殖质
    • 

  • 储存时间谱：从数月（易分解碎屑）到数千年（矿物-有机质复合体）
    • 



气候变化对土壤碳的影响
全球升温可能触发土壤碳大规模释放，形成正反馈。IPCC AR6 评估认为，在高排放情景下，永久冻土退化可能在本世纪释放 数十到数百 GtC，但具体量级仍有较大不确定性。


化石燃料对碳循环的干扰
地质碳的快速释放
化石燃料（煤、石油、天然气）中的碳是数亿年间通过光合作用固定并经地质封存的"地质碳"。人类在短短 ~200年内将大量地质碳释放回大气：


    

  • 工业革命前（1750年）：大气 CO₂ ~280 ppm（~590 GtC）
    • 

  • 2026年4月：大气 CO₂ ~431 ppm（~880 GtC）——较工业革命前增加了约 290 GtC（~50%）
    • 



累积排放
1750-2022年间全球累积人为 CO₂ 排放约 2560 ± 240 GtCO₂（~700 GtC）：


    

  • 化石燃料与工业过程：~2100 GtCO₂
    • 

  • 土地利用变化：~460 GtCO₂
    • 



其中约一半被陆地和海洋碳汇吸收，另一半留在大气中造成 CO₂ 浓度持续攀升。


碳汇饱和风险
当前碳汇效率是否可持续是关键科学问题：


    

  • 海洋碳汇：随着海水温度升高和酸化加剧，吸收效率可能下降
    • 

  • 陆地碳汇：CO₂ 施肥效应可能因养分限制（氮、磷）而趋于饱和
    • 

  • 观测证据：2023年全球碳收支报告显示陆地碳汇年际变率增大，部分年份（如2023年）陆地碳汇显著减弱
    •

关键认知：即使人类立即停止所有排放，大气 CO₂ 浓度也不会迅速回落到工业革命前水平。CO₂ 在大气中的"调节时间"（e-folding time of the perturbation）远长于单个分子的停留时间。IPCC AR6 指出，约 23% 的人为 CO₂ 排放将在大气中停留超过 1000年——这就是为什么气候变化被认为在人类文明尺度上是"不可逆"的。


碳循环与气候系统的耦合
碳循环并非独立于气候变化——两者构成复杂的耦合反馈系统：


    

  1. 温度-碳循环反馈：升温 → 土壤分解加速 + 海洋吸收减少 → 更多 CO₂ 留在大气 → 进一步升温
    2. 

  2. 降水变化：改变生态系统生产力和土壤碳分解速率
    3. 

  3. 海洋环流变化：影响碳的垂直输送和深海封存效率
    4. 

  4. 极端事件：干旱和火灾导致森林碳释放（如2019-2020年澳洲大火释放约 0.7 GtCO₂）
    5. 



地球系统模型（ESMs）将碳循环与物理气候系统耦合模拟，结果显示：考虑碳循环反馈后，达到同一温度目标所需的减排力度比不考虑反馈时更大。IPCC AR6 评估的"剩余碳预算"已经纳入了这些反馈的影响。
