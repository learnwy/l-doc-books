细胞能量代谢

能量代谢总览

人体将食物中的化学能转化为细胞可直接使用的通用能量货币——ATP（腺苷三磷酸）。这一过程涉及三大核心代谢通路的串联协作。

三大能量基质的汇聚

无论碳水化合物、脂肪还是蛋白质，最终都以乙酰-CoA 的形式汇入共同的氧化路径：

ATP 的结构与能量释放
ATP → ADP + Pi 的水解反应释放 ~30.5 kJ/mol 自由能（标准条件）。细胞内实际条件下可达 ~54 kJ/mol。人体每天 ATP 周转量约为体重的 40–70 kg（即 ATP 被反复合成和水解）。


糖酵解（Glycolysis）
路径概述
糖酵解发生在细胞质中，将一分子葡萄糖（6C）拆分为两分子丙酮酸（3C），净产出 2 ATP + 2 NADH。

      • 

    • 抑制剂：ATP、丙氨酸
      •

丙酮酸的代谢命运
丙酮酸处于代谢十字路口：


    

  • 有氧条件：丙酮酸脱氢酶复合体（PDH）→ 乙酰-CoA → TCA 循环
    • 

  • 无氧条件：乳酸脱氢酶 → 乳酸（再生 NAD⁺ 以维持糖酵解）
    • 

  • 糖异生方向：丙酮酸羧化酶 → 草酰乙酸（肝脏/肾脏）
    • 

  • 氨基酸合成：转氨反应 → 丙氨酸
    •

TCA 循环的双重角色
TCA 不仅是分解代谢通路，也是合成代谢的"原料仓库"（Cataplerosis/Anaplerosis）：


    

  • 柠檬酸 → 出线粒体 → 脂肪酸合成
    • 

  • α-酮戊二酸 → 谷氨酸 → 其他氨基酸
    • 

  • 草酰乙酸 → 天冬氨酸 → 嘌呤/嘧啶合成
    • 

  • 琥珀酰-CoA → 血红素合成
    • 



中间物被抽出后需要回补反应（Anaplerosis），最重要的是：丙酮酸羧化酶催化的丙酮酸 → 草酰乙酸。

化学渗透假说
Peter Mitchell（1961，诺贝尔奖 1978）提出：ETC 泵出的 H⁺ 在线粒体内膜形成电化学梯度（质子动力 Δp），驱动 ATP 合酶的旋转催化机制合成 ATP。


P/O 比（ATP/O）：


    

  • NADH → ~2.5 ATP（经过 Complex I → III → IV）
    • 

  • FADH₂ → ~1.5 ATP（经过 Complex II → III → IV）
    •

磷酸戊糖途径（PPP）
PPP 不直接产 ATP，但提供两种关键产物：


    

  1. NADPH：脂肪酸合成、胆固醇合成、抗氧化（谷胱甘肽再生）的还原力
    2. 

  2. 核糖-5-磷酸：核苷酸合成的糖基骨架
    3. 



PPP 的氧化阶段由 葡萄糖-6-磷酸脱氢酶（G6PD） 催化，G6PD 缺乏是全球最常见的酶缺陷病（~4 亿人），导致溶血性贫血。


糖异生（Gluconeogenesis）
为何需要糖异生
即使在禁食状态下，大脑每天仍需 ~120g 葡萄糖。肝糖原储备仅能维持 12–18 小时，之后依赖糖异生。


糖异生底物
    

  • 乳酸（Cori 循环：肌肉 → 血液 → 肝脏）
    • 

  • 丙氨酸（葡萄糖-丙氨酸循环：肌肉蛋白分解 → 肝脏）
    • 

  • 甘油（脂肪分解释放）
    • 

  • 特定氨基酸（生糖氨基酸）
    • 



注意： 脂肪酸不能净合成葡萄糖（乙酰-CoA 不能回流为丙酮酸），但甘油骨架可以。

能量代谢的整合调控
能荷（Energy Charge）感知
细胞通过 AMP/ATP 比值（能荷）精密调控代谢方向：


    

  • AMPK（AMP 活化蛋白激酶）：细胞能量传感器
      

    • 低能量状态（AMP↑）→ AMPK 激活
      • 

    • 效应：加速分解代谢（糖酵解、脂肪酸氧化）、抑制合成代谢（脂肪酸合成、蛋白质合成）
      • 

    • 被称为"细胞燃料表"
      • 

    

    •

实际运动中三系统同时运作，只是贡献比例随强度和时间变化。


运动强度与燃料选择
    

  • 低强度（<50% VO₂max）：主要脂肪酸氧化
    • 

  • 中等强度（50–75% VO₂max）：脂肪 + 糖原混合，脂肪最大氧化率（Fatmax）
    • 

  • 高强度（>75% VO₂max）：糖原为主（脂肪酸氧化受限于 β-氧化速率）
    • 

  • 极高强度（>90%）：无氧糖酵解主导
    • 



实践要点
能量代谢的日常意义
    

  1. 运动前碳水加载：补充肌糖原储备（适用于长时间耐力运动）
    2. 

  2. 训练适应：长期有氧训练增加线粒体密度 → 提高脂肪氧化能力
    3. 

  3. 禁食窗口：12–16 小时禁食可促进代谢从糖切换至脂肪氧化
    4. 

  4. 避免过度限碳：大脑日需 ~120g 葡萄糖，长期极低碳水依赖糖异生（消耗肌肉蛋白）
    5. 

  5. AMPK 激活策略：运动、热量限制、某些多酚（白藜芦醇）
    6.
