激素对代谢的调控

内分泌-代谢网络概述

人体代谢并非简单的酶催化反应堆叠，而是受到精密的激素调控网络协调。多种激素通过内分泌（远距离）、旁分泌和自分泌方式，实时调整营养物质的摄取、储存、动员和利用。

核心代谢激素一览

激素 分泌组织 主要代谢效应 分泌刺激
胰岛素（Insulin） 胰腺 β 细胞 合成代谢：促进葡萄糖摄取、糖原/脂肪/蛋白合成 血糖↑、氨基酸↑
胰高血糖素（Glucagon） 胰腺 α 细胞 分解代谢：糖原分解、糖异生、脂肪动员 血糖↓、氨基酸↑
肾上腺素（Epinephrine） 肾上腺髓质 快速能量动员（"战或逃"） 交感激活、应激

胰岛素：代谢的总开关
胰岛素信号通路
胰岛素与细胞表面胰岛素受体（IR，受体酪氨酸激酶）结合后，激活级联信号：


IR → IRS-1/2 → PI3K → PIP₃ → Akt/PKB


Akt 的下游效应：


    

  • GLUT4 转位：囊泡从细胞内移至膜表面 → 肌肉/脂肪组织葡萄糖摄取↑
    • 

  • 糖原合酶激活：GSK3 被 Akt 抑制 → GS 去磷酸化激活 → 糖原合成
    • 

  • mTORC1 激活：蛋白质合成↑
    • 

  • FOXO 磷酸化（失活）：糖异生基因表达↓
    • 

  • 脂肪合成↑：SREBP-1c 激活 → 脂肪酸合成酶表达
    •

肝脏的选择性胰岛素抵抗
在 2 型糖尿病中，肝脏呈现"选择性"胰岛素抵抗：


    

  • 糖异生抑制失败（该抑制的没抑制 → 高血糖）
    • 

  • 脂肪合成仍被促进（该抑制的反而继续 → 脂肪肝）
    • 



这解释了为何 2 型糖尿病同时伴有高血糖和非酒精性脂肪肝（NAFLD）。


胰高血糖素：胰岛素的对手
生理功能
胰高血糖素是维持空腹血糖的第一道防线：


    

  • 肝糖原分解：cAMP-PKA 通路激活糖原磷酸化酶
    • 

  • 糖异生：诱导 PEPCK 和 G-6-Pase 表达
    • 

  • 脂肪动员：激活脂肪组织激素敏感性脂肪酶（HSL）
    • 

  • 酮体生成：促进肝脏 β-氧化 → 乙酰-CoA → 酮体
    •

皮质醇：应激与代谢
昼夜节律性分泌
皮质醇遵循明确的昼夜节律（由下丘脑 SCN 驱动）：


    

  • 清晨觉醒峰值（Cortisol Awakening Response, CAR）：~6:00–8:00
    • 

  • 日间渐降
    • 

  • 午夜最低值
    • 



代谢效应
急性适应性效应（应激反应）：


    

  • 肝糖异生↑（氨基酸作为底物）
    • 

  • 脂肪动员↑
    • 

  • 蛋白质分解↑（提供糖异生底物）
    • 

  • 抗炎（短期）
    • 



慢性过量的病理效应：


    

  • 内脏脂肪沉积（腹型肥胖）
    • 

  • 骨骼肌萎缩
    • 

  • 胰岛素抵抗
    • 

  • 免疫抑制
    • 

  • 骨质疏松
    • 



慢性应激与代谢综合征
持续心理压力 → HPA 轴过度激活 → 皮质醇节律紊乱 → 代谢后果：


    

  • 内脏脂肪对皮质醇敏感（糖皮质激素受体密度高）
    • 

  • 皮质醇促进前脂肪细胞分化为成熟脂肪细胞
    • 

  • 同时升高胰岛素（拮抗皮质醇的高血糖效应）→ 高胰岛素 + 高皮质醇 = 最大化脂肪储存
    • 



甲状腺激素：代谢速率的调定器
T4 与 T3 的关系
    

  • 甲状腺分泌 ~80% T4（低活性前体）+ ~20% T3（活性形式）
    • 

  • 外周组织（肝、肾、肌肉）通过碘化甲腺原氨酸脱碘酶将 T4 → T3
    • 

  • T3 的生物活性是 T4 的 ~5 倍
    • 



代谢调控
T3 通过核受体（TR）调控代谢基因的转录：


    

  • BMR：调高基础代谢率（Na⁺/K⁺-ATPase 表达↑、线粒体解偶联）
    • 

  • 产热：UCP 表达调控
    • 

  • 碳水代谢：促进糖原分解和糖异生
    • 

  • 脂质代谢：促进脂肪酸合成和氧化（两者同时加速 → 周转↑）
    • 

  • 蛋白质代谢：适量促进合成；过量促进分解
    •

瘦素与饥饿素：食欲的双向调控
瘦素（Leptin）——"饱足信号"
    

  • 由白色脂肪细胞按脂肪量比例分泌
    • 

  • 通过血脑屏障作用于下丘脑弓状核
    • 

  • 效应：抑制 NPY/AgRP 神经元（促食欲）+ 激活 POMC 神经元（抑制食欲）
    • 

  • 增加能量消耗（交感神经活性↑）
    • 



瘦素抵抗悖论： 肥胖个体瘦素水平极高，但信号传导受损（瘦素抵抗），类似胰岛素抵抗。机制包括：


    

  • 血脑屏障转运饱和
    • 

  • 信号通路负反馈（SOCS3 过表达）
    • 

  • 内质网应激抑制 LepR-b 信号
    • 



饥饿素（Ghrelin）——"进食驱动"
    

  • 胃底腺 X/A 样细胞分泌
    • 

  • 空腹时升高，进食后迅速下降
    • 

  • 作用于下丘脑 GHS-R → NPY/AgRP 激活 → 促进食欲
    • 

  • 同时刺激生长激素释放
    • 

  • 促进胃肠蠕动（"饭前肚子叫"）
    •

肠促胰素效应（Incretin Effect）
GLP-1 和 GIP
口服葡萄糖比静脉注射等量葡萄糖引起更强的胰岛素反应（额外 50–70%），这称为肠促胰素效应，由两种肠道激素介导：


    

  • GLP-1（胰高血糖素样肽-1）：回肠 L 细胞分泌
      

    • 葡萄糖依赖性促胰岛素分泌
      • 

    • 抑制胰高血糖素
      • 

    • 延缓胃排空
      • 

    • 减少食欲（中枢效应）
      • 

    

    • 

  • GIP（葡萄糖依赖性促胰岛素多肽）：十二指肠 K 细胞分泌
      

    • 葡萄糖依赖性促胰岛素分泌
      • 

    • 促进脂肪储存
      • 

    

    • 



GLP-1 受体激动剂的代谢医学革命
2020–2026 年，GLP-1RA（如 Semaglutide、Tirzepatide）从糖尿病治疗扩展到肥胖管理：


    

  • 体重降低 15–25%（接近减重手术效果）
    • 

  • 改善心血管结局
    • 

  • 降低 NAFLD/NASH 进展
    • 

  • 机制：中枢食欲抑制 + 外周代谢改善
    •

实践要点
通过生活方式调节代谢激素
    

  1. 维持胰岛素敏感性
    

      

    • 规律运动（有氧 + 抗阻）
      • 

    • 避免精制碳水化合物的血糖尖峰
      • 

    • 适当禁食窗口（12–16h）
      • 

    • 维持健康体重（尤其减少内脏脂肪）
      • 

    

    2. 

  2. 管理皮质醇
    

      

    • 规律睡眠（与昼夜节律对齐）
      • 

    • 压力管理（正念、运动）
      • 

    • 避免过度训练（慢性皮质醇升高）
      • 

    • 充足维生素 C、镁（支持 HPA 轴调节）
      • 

    

    3. 

  3. 支持甲状腺功能
    

      

    • 充足碘、硒、铁、锌摄入
      • 

    • 避免极端热量限制（T3 下调）
      • 

    • 适度碳水化合物（维持 T4→T3 转化）
      • 

    

    4. 

  4. 优化食欲信号
    

      

    • 高蛋白 + 高纤维餐（最强饱腹感信号）
      • 

    • 充足睡眠（瘦素/饥饿素平衡）
      • 

    • 规律进餐时间（训练肠促胰素节律）
      • 

    • 减少超加工食品（绕过正常饱腹反馈）
      • 

    

    5.
