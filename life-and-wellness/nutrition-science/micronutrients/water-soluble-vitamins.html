Part I · 健康与医学营养科学基础微量营养素水溶性维生素

水溶性维生素

概述：水溶性维生素的共性特征

水溶性维生素包括 B 族维生素（8 种）和维生素 C，它们的共同特点：

  • 不在体内大量储存：多余部分经尿液排出，需每日持续摄入
  • 多为辅酶前体：在体内转化为活性辅酶形式，参与酶促反应
  • 对热和氧敏感：烹饪加工可导致显著损失
  • 毒性风险较低：但超大剂量补充仍可能引起不良反应
B 族维生素详解
维生素 B1（硫胺素，Thiamine）
活性形式： 硫胺素焦磷酸（TPP, Thiamine Pyrophosphate）


生化功能：


    

  • 丙酮酸脱氢酶复合体的辅酶 → 丙酮酸 → 乙酰-CoA（糖代谢与 TCA 循环的枢纽）
    • 

  • α-酮戊二酸脱氢酶的辅酶 → TCA 循环关键步骤
    • 

  • 转酮醇酶的辅酶 → 磷酸戊糖途径（PPP）
    • 



缺乏症状：


    

  • 干性脚气病（Dry Beriberi）：周围神经病变，肌肉萎缩
    • 

  • 湿性脚气病（Wet Beriberi）：心力衰竭，水肿
    • 

  • Wernicke-Korsakoff 综合征：常见于酗酒者，急性混乱 + 记忆障碍
    • 



食物来源： 全谷物（胚芽层）、猪肉、豆类、坚果。精制谷物去除胚芽后 B1 损失 >80%。


RDA： 成人男性 1.2mg/日，女性 1.1mg/日


维生素 B2（核黄素，Riboflavin）
活性形式： FAD（黄素腺嘌呤二核苷酸）和 FMN（黄素单核苷酸）


生化功能：


    

  • 线粒体电子传递链复合体 I 和 II 的辅基
    • 

  • 脂肪酸 β-氧化中多种酰基-CoA 脱氢酶的辅酶
    • 

  • 谷胱甘肽还原酶的辅酶 → 维持抗氧化防御
    • 

  • 参与 B6、叶酸和烟酸的代谢活化
    • 



缺乏表现： 口角炎、舌炎、脂溢性皮炎、正常红细胞性贫血


食物来源： 乳制品（牛奶每杯含 ~0.5mg）、蛋类、内脏、绿叶蔬菜。对紫外线敏感，牛奶透明包装可导致 B2 降解。


RDA： 成人男性 1.3mg/日，女性 1.1mg/日


维生素 B3（烟酸，Niacin）
活性形式： NAD⁺（烟酰胺腺嘌呤二核苷酸）和 NADP⁺


生化功能：


    

  • NAD⁺ 参与 >400 种氧化还原反应（分解代谢的电子载体）
    • 

  • NADP⁺ 参与合成代谢（脂肪酸合成、胆固醇合成）
    • 

  • NAD⁺ 是 Sirtuins（SIRT1-7）的底物 → 表观遗传调控、DNA 修复、衰老
    • 

  • NAD⁺ 是 PARP 酶的底物 → DNA 损伤修复
    • 



特殊代谢： 色氨酸可转化为烟酸（效率 60:1），因此蛋白质充足可部分预防缺乏


缺乏症（糙皮病，Pellagra）： 4D 症状——皮炎（Dermatitis）、腹泻（Diarrhea）、痴呆（Dementia）、死亡（Death）


食物来源： 肉类、鱼类、全谷物、花生。玉米中的烟酸为结合型（需碱处理释放，如墨西哥 nixtamalization 工艺）。


RDA： 成人 14–16mg NE/日（NE = Niacin Equivalents）


维生素 B5（泛酸，Pantothenic Acid）
活性形式： 辅酶 A（CoA）和酰基载体蛋白（ACP）


生化功能：


    

  • CoA 是代谢中心枢纽：乙酰-CoA 连接糖代谢、脂肪酸代谢和 TCA 循环
    • 

  • 脂肪酸合成酶复合体中 ACP 的组分
    • 

  • 参与 >100 种代谢反应
    • 



命名来源： "泛酸"来自希腊语 pantos（无处不在），反映其广泛分布于食物中


缺乏： 极为罕见，实验性缺乏表现为"灼足综合征"（burning feet syndrome）


AI： 成人 5mg/日


维生素 B6（吡哆醇，Pyridoxine）
活性形式： 磷酸吡哆醛（PLP, Pyridoxal 5'-Phosphate）


生化功能：


    

  • 氨基酸代谢的核心辅酶：转氨反应、脱羧反应、消旋反应
    • 

  • 参与 >140 种 PLP 依赖酶
    • 

  • 血红素合成（δ-ALA 合成酶的辅酶）
    • 

  • 神经递质合成：5-HT（血清素）、GABA、多巴胺、去甲肾上腺素
    • 

  • 糖原磷酸化酶的辅酶 → 糖原分解
    • 

  • 同型半胱氨酸代谢（与 B9、B12 协同）
    • 



缺乏影响： 小细胞低色素性贫血、周围神经病变、抑郁、免疫功能下降


毒性风险： 长期 >200mg/日可导致感觉神经病变（上限 UL = 100mg/日）


食物来源： 鸡肉、鱼类、土豆、香蕉、鹰嘴豆


RDA： 成人 1.3mg/日（>50 岁：男 1.7，女 1.5mg/日）


维生素 B7（生物素，Biotin）
活性形式： 以共价键连接酶蛋白的赖氨酸残基（生物胞素，Biocytin）


生化功能：


    

  • 四种羧化酶的辅酶：
      

    • 丙酮酸羧化酶（糖异生）
      • 

    • 乙酰-CoA 羧化酶（脂肪酸合成）
      • 

    • 丙酰-CoA 羧化酶（奇数碳脂肪酸/支链氨基酸代谢）
      • 

    • 3-甲基巴豆酰-CoA 羧化酶（亮氨酸代谢）
      • 

    

    • 



缺乏原因： 正常饮食极少缺乏，但生蛋白中的抗生物素蛋白（Avidin）可结合并阻止吸收


AI： 成人 30μg/日


维生素 B9（叶酸，Folate）
活性形式： 四氢叶酸（THF）及其一碳衍生物


生化功能：


    

  • 一碳代谢核心载体：转移甲基（-CH₃）、亚甲基（-CH₂-）、甲酰基（-CHO）
    • 

  • DNA 合成：dTMP 合成（胸苷酸合酶需 5,10-亚甲基-THF）
    • 

  • 同型半胱氨酸 → 甲硫氨酸（需 5-甲基-THF 作为甲基供体，B12 为辅酶）
    • 

  • 嘌呤核苷酸从头合成
    • 



缺乏后果：


    

  • 巨幼红细胞性贫血（DNA 合成受阻 → 细胞分裂延迟）
    • 

  • 神经管缺陷（NTDs）：孕早期叶酸不足 → 脊柱裂/无脑畸形
    • 

  • 高同型半胱氨酸血症 → 心血管风险
    • 



MTHFR 基因多态性： C677T 变异（全球约 10–15% 纯合子）降低叶酸代谢效率，这些个体可能需要甲基叶酸（5-MTHF）形式补充。


食物来源： 深绿叶蔬菜、豆类、柑橘、强化谷物。烹饪损失可达 50–90%。


RDA： 成人 400μg DFE/日；育龄女性建议额外补充 400μg 合成叶酸


维生素 B12（钴胺素，Cobalamin）
活性形式： 甲基钴胺素（细胞质）和 5'-脱氧腺苷钴胺素（线粒体）


生化功能：


    

  • 甲硫氨酸合酶的辅酶：同型半胱氨酸 + 5-甲基-THF → 甲硫氨酸 + THF
    • 

  • 甲基丙二酰-CoA 变位酶的辅酶：奇数碳脂肪酸和支链氨基酸代谢
    • 



吸收机制： 需要胃壁细胞分泌的内因子（Intrinsic Factor, IF）与 B12 结合 → 回肠末端受体介导内吞


缺乏原因：


    

  • 恶性贫血（Pernicious Anemia）：自身免疫破坏壁细胞
    • 

  • 纯素食（植物性食物几乎不含 B12）
    • 

  • 老年人（胃酸分泌减少）
    • 

  • 胃切除术/回肠切除术后
    • 



缺乏表现： 巨幼红细胞性贫血 + 不可逆神经损伤（脱髓鞘）


食物来源： 仅动物性食品（肉、鱼、蛋、乳）；素食者必须补充或食用强化食品


RDA： 成人 2.4μg/日


维生素 C（抗坏血酸，Ascorbic Acid）
生化功能
维生素 C 是最强效的水溶性抗氧化剂和多种加氧酶的必需辅因子：


    

  • 胶原合成：脯氨酰和赖氨酰羟化酶的辅因子 → 胶原蛋白稳定交联
    • 

  • 抗氧化防御：直接清除活性氧（ROS），再生氧化型维生素 E
    • 

  • 铁吸收促进：将非血红素铁（Fe³⁺）还原为 Fe²⁺，促进小肠吸收
    • 

  • 神经递质合成：多巴胺 β-羟化酶（多巴胺 → 去甲肾上腺素）
    • 

  • 肉碱合成：脂肪酸转运至线粒体所必需
    • 

  • 免疫功能：中性粒细胞积累高浓度维生素 C，支持吞噬和杀菌
    • 



缺乏症（坏血病，Scurvy）
体内维生素 C 储备约 1500mg，每日消耗 ~3%。储备耗尽（<300mg）时出现症状：


    

  • 牙龈出血、牙齿松动
    • 

  • 皮下瘀斑、伤口不愈合
    • 

  • 关节疼痛、骨膜下出血
    • 

  • 贫血、易感染
    • 

  • 最终致死（历史上水手的主要死因之一）
    •

水溶性维生素的协同网络
B 族维生素并非孤立工作，它们形成紧密的代谢协同网络：


同型半胱氨酸代谢节点
同型半胱氨酸（Homocysteine, Hcy）是蛋白质代谢的副产物，升高的 Hcy 是心血管风险因素。三种 B 族维生素协同调控其水平：


    

  • B9（叶酸）：提供甲基（5-甲基-THF）
    • 

  • B12：甲硫氨酸合酶的辅酶，完成甲基转移
    • 

  • B6：胱硫醚 β-合酶的辅酶，Hcy → 胱硫醚 → 半胱氨酸
    • 



三者任一缺乏均导致 Hcy 升高，但补充效果需三者同时充足。


能量代谢协同
B1、B2、B3、B5 共同参与能量代谢的连续步骤：


    

  • B1（TPP）：丙酮酸脱氢 → 乙酰-CoA
    • 

  • B2（FAD）：电子传递链 + 脂肪酸氧化
    • 

  • B3（NAD⁺）：TCA 循环的多步氧化还原
    • 

  • B5（CoA）：乙酰基的载体
    • 



缺乏任何一种都会导致能量产生瓶颈。


实践要点
水溶性维生素保存策略
    

  1. 减少烹饪水量：蒸 > 煮（溶出损失）
    2. 

  2. 缩短加热时间：快炒 > 长时间炖煮
    3. 

  3. 避免反复加热：现做现吃
    4. 

  4. 保持酸性环境：加醋可保护维生素 C
    5. 

  5. 冷冻优于长期冷藏：冷冻蔬菜在采摘后立即处理，营养保留率高
    6.
