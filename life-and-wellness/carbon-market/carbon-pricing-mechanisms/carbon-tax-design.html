碳税设计与实施

碳税的经济学基础

碳税是对化石燃料燃烧或温室气体排放直接征收的税种，其理论基础源于庇古税（Pigouvian Tax）——通过对负外部性活动征税，使私人成本等于社会成本，从而将外部性内部化。与 ETS 的"量控价随"不同，碳税是"价定量随"——政府确定碳排放的价格，减排量则由市场主体根据税率水平自行决定。

碳税的价格信号传导路径清晰：碳税提高化石燃料使用成本 → 能源价格上升 → 高碳产品竞争力下降 → 消费者和生产者转向低碳替代 → 排放量减少。这一传导链条越短、越直接，碳税的减排效率越高。

税率确定的主要方法论包括：


    

  • 碳的社会成本法（SCC）：基于气候损害的综合评估模型估算每吨排放的社会边际损害成本。美国 EPA 2024 年估算 SCC 约为 $190/tCO₂（2020 年美元）
    • 

  • 减排目标倒推法：根据国家减排目标和边际减排成本曲线，确定达成目标所需的碳价水平
    • 

  • 国际对标法：参考主要贸易伙伴的碳定价水平，避免竞争力劣势
    • 

  • 渐进递增法：从低水平起步，按预定路径逐年递增，给市场明确预期
    • 



征收节点与覆盖范围
碳税的征收节点选择影响其覆盖面和行政效率：


上游征收（对化石燃料生产/进口环节征税）：


    

  • 优势：覆盖面广、行政成本低、征税对象少
    • 

  • 劣势：价格信号传导链长，消费者感知弱
    • 

  • 典型案例：加拿大联邦碳税对燃料分销商征收
    • 



下游征收（对排放设施直接征税）：


    

  • 优势：价格信号直接、可针对性设计
    • 

  • 劣势：需要完善的排放监测体系，行政成本高
    • 

  • 典型案例：南非碳税对设施级排放征收
    • 



混合征收：


    

  • 大型排放源采用下游征收（精确计量）
    • 

  • 分散排放源采用上游征收（覆盖全面）
    • 

  • 典型案例：瑞士对大型设施征碳税，中小设施通过燃料税间接覆盖
    •

碳税的实施挑战与应对
碳泄漏防护
碳泄漏是指碳税导致高碳产业向无碳约束地区转移，不仅未减少全球排放，反而损害本国产业竞争力。防护措施包括：


    

  • 边境碳调节：对进口商品征收碳含量等额费用（如 CBAM）
    • 

  • 出口退税：对出口产品退还已缴碳税
    • 

  • 行业豁免/折减：对贸易暴露行业给予较低税率或免税额度
    • 

  • 阶段性实施：从低税率起步，给企业调整时间
    • 



公平性与累退效应
碳税通过能源价格传导可能对低收入群体产生不成比例的负担（累退效应），因为低收入家庭的能源支出占收入比例更高。应对策略：


    

  • 碳红利：将碳税收入等额返还每位公民（加拿大模式），低收入者获得的返还超过其承担的碳成本
    • 

  • 定向补贴：对低收入家庭的供暖、交通给予针对性补贴
    • 

  • 阶梯税率：基本用能免税，超额用能递增征税
    • 

  • 转型支持：对煤矿工人、高碳产业工人提供再就业培训和收入保障
    • 



与其他政策的协同
碳税并非孤立工具，其减排效果取决于与配套政策的协同：


    

  • 与能效标准配合：碳税提供价格信号，能效标准解决信息不对称
    • 

  • 与可再生能源补贴配合：碳税"推"（提高化石能源成本），补贴"拉"（降低清洁能源成本）
    • 

  • 与 ETS 的关系：同一排放源不应同时受碳税和 ETS 管控（避免双重负担），可对 ETS 覆盖行业免征碳税
    • 



碳税的优势与局限
相对于 ETS 的优势
    

  1. 价格确定性：企业可准确预知碳成本，降低投资决策不确定性
    2. 

  2. 行政简便：利用现有税收征管体系，无需建设复杂的配额注册与交易基础设施
    3. 

  3. 覆盖广泛：可轻松覆盖分散排放源（交通、建筑、小型排放设施）
    4. 

  4. 财政收入稳定：收入可预测，便于财政规划
    5. 

  5. 抗操纵性：税率由政府法定，不受市场投机影响
    6. 



主要局限
    

  1. 减排量不确定：无法保证特定时期的排放总量降至目标水平
    2. 

  2. 政治阻力大："税"字本身带来显著政治风险，多国碳税方案因公众反对而搁浅或撤回（如澳大利亚 2014 年废除碳税）
    3. 

  3. 税率难以精确确定：最优税率依赖于对减排成本和气候损害的准确估计
    4. 

  4. 国际协调困难：各国碳税税率差异大，难以实现全球统一碳价
    5. 

  5. 动态适应性弱：税率调整需要立法程序，响应市场变化的速度慢于 ETS 的自动价格调节
    6. 



碳税发展趋势
全球碳税实践呈现以下演进方向：


    

  • 税率加速上升：加拿大计划 2030 年达到 CAD 170/t，新加坡 2030 年目标 SGD 50—80/t
    • 

  • 与 ETS 互补：越来越多国家采用"ETS 管大户 + 碳税管散户"的双轨模式
    • 

  • 收入中性设计：碳红利模式获得越来越广泛的政治支持
    • 

  • 碳定价收入专款专用：气候法规定碳税收入必须用于气候相关投资
    • 

  • 隐性碳税显性化：将能源税中的碳成分拆分标注，增强碳价信号透明度
    • 



碳税作为最直接、最透明的碳定价工具，在全球气候治理工具箱中的地位持续上升。尽管政治实施面临挑战，但其在行政效率、覆盖广度和价格确定性方面的优势，使其成为 ETS 的重要补充或替代方案。
