有氧氧化与脂肪代谢

有氧氧化系统（Aerobic Oxidation System）是人体容量最大、效率最高的能量供应系统。它以氧气为最终电子受体，通过线粒体中的三羧酸循环（TCA Cycle）和电子传递链（ETC）完全氧化碳水化合物、脂肪和少量蛋白质，提供持续的 ATP 再生。脂肪作为人体最大的能量储备（∼80,000∼100,000\sim 80,000\sim100,000∼80,000∼100,000 kcal），其氧化代谢能力直接决定了耐力运动表现和代谢健康。

有氧氧化的生化通路

丙酮酸的命运——进入线粒体

糖酵解产生的丙酮酸通过线粒体丙酮酸载体（MPC）进入线粒体基质，由丙酮酸脱氢酶复合物（PDH）氧化脱羧为乙酰辅酶A：

Pyruvate+CoA+NAD+→PDHAcetyl-CoA+CO2+NADH\text{Pyruvate} + CoA + NAD^+ \xrightarrow{\text{PDH}} \text{Acetyl-CoA} + CO_2 + NADHPyruvate+CoA+NAD+PDH​Acetyl-CoA+CO2​+NADH

PDH 是连接糖酵解和 TCA 循环的关键枢纽酶，受以下因素调节：

  • 激活：运动（Ca2+Ca^{2+}Ca2+ 增加、ADP 增加、丙酮酸增加）
  • 抑制：NADH/NAD+^++ 比值升高、乙酰CoA/CoA 比值升高、ATP 充足

  1. CPT-I（线粒体外膜）：脂酰CoA + 肉碱 → 脂酰肉碱 + CoA
    2. 

  2. CACT（转位酶）：脂酰肉碱穿过内膜
    3.

CPT-I 是脂肪氧化的主要限速步骤，受丙二酰CoA（malonyl-CoA）的强烈变构抑制。运动时 AMPK 激活 → 抑制乙酰CoA 羧化酶（ACC）→ 丙二酰CoA 下降 → CPT-I 去抑制 → 脂肪酸进入线粒体加速。

底物选择的调控因素
运动强度：高强度时糖酵解通量增加 → 乙酰CoA 充足 → ACC 活性增加 → 丙二酰CoA 抑制 CPT-I → 脂肪氧化下降


运动时长：长时间运动中糖原消耗 → 胰岛素进一步下降 + 肾上腺素升高 → 脂肪动员增加 → 脂肪贡献随时间递增


膳食状态：禁食状态下脂肪氧化增强；高碳水饮食后胰岛素升高抑制脂解


训练状态：耐力训练增强脂肪氧化能力（线粒体密度 ↑、CPT-I 活性 ↑、FAT/CD36 表达 ↑）

肌内甘油三酯（IMTG）
IMTG 作为运动底物
肌内甘油三酯（Intramuscular Triglycerides, IMTG）以脂滴形式储存在肌纤维内，是中等强度运动的重要脂肪来源：


    

  • 含量：∼300∼600\sim 300\sim600∼300∼600 mmol/kg 干重（训练者更高）
    • 

  • 位于线粒体附近（特别是膜下脂滴）
    • 

  • 贡献中等强度运动脂肪氧化的 ∼50%∼70%\sim 50\%\sim70\%∼50%∼70%
    • 

  • Type I 纤维含量高于 Type II 纤维
    • 



IMTG 代谢与胰岛素敏感性
"运动员悖论"（Athlete's Paradox）：


    

  • 耐力运动员 IMTG 含量高（如同肥胖/糖尿病患者）
    • 

  • 但胰岛素敏感性极高（与肥胖者相反）
    • 

  • 差异在于 IMTG 周转速率和脂滴包被蛋白（Perilipin 5）
    • 

  • 高周转率 = 高利用率 = 无有害脂质中间物（神经酰胺、DAG）积累
    • 



实践应用
优化脂肪氧化的训练策略
    

  • 大量 Zone 2 训练：每周 3∼53\sim53∼5 次，每次 45∼9045\sim9045∼90 min
    • 

  • 空腹低强度训练：低糖原状态下训练信号增强（"train low, compete high"策略）
    • 

  • 长距离持续跑/骑：>90>90>90 min 的持续中等强度运动最大化脂肪动员
    • 

  • 避免运动中过量碳水摄入（训练目的为代谢适应时）
    •
