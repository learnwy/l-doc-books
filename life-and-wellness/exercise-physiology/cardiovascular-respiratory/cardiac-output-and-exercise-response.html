心输出量与运动应答

心脏是运动时氧气输送系统的核心泵站。运动开始后数秒内，心脏即启动一系列精密调节以满足骨骼肌急剧增加的氧气和营养需求。心输出量（Cardiac Output, Q˙\dot{Q}Q˙​）的动态调节能力决定了人体有氧运动能力的上限。

心输出量的基本概念

定义与决定因素

心输出量等于心率与每搏输出量的乘积：

Q˙=HR×SV\dot{Q} = HR \times SVQ˙​=HR×SV

其中 Q˙\dot{Q}Q˙​ 为心输出量（L/min），HRHRHR 为心率（beats/min），SVSVSV 为每搏输出量（mL/beat）。

静息值参考（健康成年人）：


    

  • 心率：60∼8060 \sim 8060∼80 bpm
    • 

  • 每搏输出量：60∼8060 \sim 8060∼80 mL
    • 

  • 心输出量：4∼64 \sim 64∼6 L/min
    • 



Frank-Starling 机制
Frank-Starling 定律描述心脏的内在调节能力：在一定范围内，心室舒张末期容积（前负荷）增大时，心肌纤维被拉伸的程度增加，导致收缩力增强、每搏输出量增大。


生理基础：


    

  • 肌节拉伸至最适长度（∼2.2μm\sim 2.2 \mu m∼2.2μm）时肌丝重叠最优
    • 

  • 拉伸增加肌钙蛋白对 Ca2+Ca^{2+}Ca2+ 的敏感性（长度依赖性激活）
    • 

  • titin 蛋白拉伸增加被动张力，辅助射血
    • 



运动中 Frank-Starling 机制的贡献：


    

  • 从卧位到直立位变化时 SV 维持
    • 

  • 运动初始阶段 SV 的快速增加
    • 

  • 约占运动时 SV 增加的 30%∼50%30\% \sim 50\%30%∼50%
    •

心率调节机制
运动开始时的快速反应（0∼10s0 \sim 10s0∼10s）：


    

  • 中枢指令（Central Command）：运动皮层下行信号同时发送至心血管中枢
    • 

  • 副交感撤退（Vagal Withdrawal）：迷走神经张力降低，心率迅速升高
    • 



持续运动中的递增反应：


    

  • 交感神经激活：去甲肾上腺素作用于 β1\beta_1β1​ 受体
    • 

  • 循环儿茶酚胺：肾上腺髓质释放肾上腺素
    • 

  • 体温升高：每升高 1°C1°C1°C 心率增加约 101010 bpm
    •

每搏输出量调节机制
运动时 SV 增加的机制包括：


增加前负荷（Frank-Starling）：


    

  • 肌肉泵（Muscle Pump）：骨骼肌节律性收缩压迫静脉，促进回流
    • 

  • 呼吸泵（Respiratory Pump）：吸气时胸腔负压增大，促进静脉回流
    • 

  • 静脉收缩：交感激活收缩容量静脉，减少外周血池
    • 



增强心肌收缩力：


    

  • 交感神经正性肌力作用（β1\beta_1β1​ 受体 → cAMP → PKA → Ca2+Ca^{2+}Ca2+ 内流增加）
    • 

  • 射血分数从静息 ∼60%\sim 60\%∼60% 提高至运动时 ∼80%∼85%\sim 80\% \sim 85\%∼80%∼85%
    • 



降低后负荷：


    

  • 工作肌群血管扩张降低总外周阻力
    • 

  • 尽管收缩压升高，舒张压变化不大
    • 



血液再分配
运动时的血流重新分配
运动时骨骼肌血流从静息的 ∼1\sim 1∼1 L/min 可增至 ∼20∼25\sim 20\sim25∼20∼25 L/min（最大运动时）。这通过两个机制实现：


    

  • 工作肌群局部血管扩张：代谢产物（NONONO、K+K^+K+、H+H^+H+、腺苷、CO2CO_2CO2​）和内皮介导的血管扩张
    • 

  • 非工作区域血管收缩：交感缩血管神经活性增强，减少内脏和非活动肌群血流
    •

耐力训练 vs 力量训练的心脏适应
耐力训练→容量超负荷→离心性肥大（腔径增大为主）\text{耐力训练} \to \text{容量超负荷} \to \text{离心性肥大（腔径增大为主）}耐力训练→容量超负荷→离心性肥大（腔径增大为主）
力量训练→压力超负荷→向心性肥大（壁厚增加为主）\text{力量训练} \to \text{压力超负荷} \to \text{向心性肥大（壁厚增加为主）}力量训练→压力超负荷→向心性肥大（壁厚增加为主）
Morganroth 假说（1975年提出，后续研究部分修正）：


    

  • 耐力运动员：左室内径增大，壁厚/腔径比值正常
    • 

  • 力量运动员：壁厚增加，腔径正常或轻度增大
    • 

  • 实际情况：多数运动员表现为混合型适应
    • 



血管适应
长期训练还诱导血管系统重塑：


    

  • 毛细血管密度增加（训练肌群毛细血管/纤维比从 ∼1.5:1\sim 1.5:1∼1.5:1 增至 ∼2.5:1\sim 2.5:1∼2.5:1）
    • 

  • 传导动脉直径增大（如股动脉）
    • 

  • 内皮功能改善（NO 生物利用度增加）
    • 

  • 动脉顺应性增加
    • 

  • 侧支循环发展
    • 



特殊环境对心血管运动反应的影响
热环境
环境高温时，皮肤血管扩张需求与骨骼肌血流需求竞争有限的心输出量：


    

  • 皮肤血流增加用于散热（可达 6∼86 \sim 86∼8 L/min）
    • 

  • 内脏血流进一步减少
    • 

  • 中心血容量下降（血浆外渗和出汗脱水）
    • 

  • 心率代偿性升高（Cardiovascular Drift）：持续中等强度运动30分钟后，SV 逐渐下降、HR 升高维持 Q˙\dot{Q}Q˙​
    • 



高海拔
海拔升高导致吸入氧分压降低（PIO2=0.21×PBP_IO_2 = 0.21 \times P_BPI​O2​=0.21×PB​）：


    

  • 急性暴露：心率和心输出量升高以代偿氧含量下降
    • 

  • 最大心率降低（交感反应改变）
    • 

  • 最大心输出量降低（∼5000m\sim 5000m∼5000m 时降低 15%∼25%15\% \sim 25\%15%∼25%）
    • 

  • 慢性适应：红细胞增多增加氧携带能力，但血液粘稠度升高增加心脏后负荷
    •
