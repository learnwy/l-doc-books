睡眠障碍概览

概述

睡眠障碍是一大类影响睡眠起始、维持、时机、质量或行为的疾病群。根据国际睡眠障碍分类第三版（ICSD-3），主要睡眠障碍分为 7 大类、60+ 个诊断实体。全球约有 45% 的人口受到不同程度的睡眠问题困扰，其中约 10-15% 符合临床睡眠障碍的诊断标准。

本文将概览最常见的睡眠障碍——失眠症、阻塞性睡眠呼吸暂停、不宁腿综合征、发作性睡病和昼夜节律障碍——帮助学习者建立系统的分类框架和识别能力。

睡眠障碍分类体系

失眠症（Insomnia）
定义与诊断标准
慢性失眠的诊断需同时满足：


    

  1. 入睡困难（>30 分钟）、维持困难（夜间觉醒 >30 分钟）、或早醒
    2. 

  2. 存在充足的睡眠机会和环境
    3. 

  3. 导致日间功能损害（疲劳、注意力下降、情绪问题）
    4. 

  4. 症状频率 ≥3 次/周，持续 ≥3 个月
    5.

病理生理学：3P 模型




因素
含义
举例





Predisposing（易感因素）
个体的基础脆弱性
焦虑特质、高皮质醇基线、家族史




Precipitating（促发因素）
触发失眠的事件
工作压力、丧亲、疾病




Perpetuating（维持因素）
使失眠慢性化的行为
过长卧床时间、补觉、睡前焦虑





3P 模型的核心洞见：促发因素消退后，维持因素独立延续失眠——因此治疗的靶点是打破维持因素（CBT-I 的理论基础）。


治疗
    

  • 一线：认知行为疗法（CBT-I）——治愈率 70-80%，详见第四章
    • 

  • 二线：药物（短期）——Z-drugs（zolpidem, eszopiclone）、低剂量 doxepin、suvorexant
    • 

  • 辅助：正念冥想、放松训练
    • 



阻塞性睡眠呼吸暂停（OSA）
病理机制
关键指标
呼吸暂停-低通气指数（AHI）：| AHI（次/小时） | 严重度 | 血氧影响 | |----------------|--------|---------| | <5 | 正常 | — | | 5-15 | 轻度 OSA | SpO₂ 偶尔 <90% | | 15-30 | 中度 OSA | SpO₂ 反复 <88% | | >30 | 重度 OSA | SpO₂ 持续 <85%，心律失常风险 |


危险因素
    

  • 肥胖（BMI >30）：最强风险因素（RR 10-14）
    • 

  • 男性：男:女 = 2-3:1（绝经后差异缩小）
    • 

  • 年龄：50-70 岁高发
    • 

  • 解剖因素：下颌后缩、扁桃体肥大、颈围 >43cm（男）/41cm（女）
    • 

  • 仰卧位：重力使舌根后坠
    • 



健康后果
未治疗的 OSA 与以下风险显著相关：


    

  • 高血压：↑2-3 倍（交感神经反复激活）
    • 

  • 房颤：↑4 倍
    • 

  • 中风：↑2-3 倍
    • 

  • 2 型糖尿病：↑2 倍（间歇性低氧损害胰岛素敏感性）
    • 

  • 交通事故：↑2-7 倍（日间嗜睡）
    • 

  • 全因死亡率：重度 OSA ↑46%
    • 



治疗
    

  • 金标准：CPAP（持续正压通气）——夜间佩戴面罩维持气道正压
    • 

  • 替代方案：口腔矫正器（轻中度）、体位治疗（仰卧位依赖型）、减重手术
    • 

  • 新兴疗法：舌下神经刺激器（Inspire）
    • 



不宁腿综合征（RLS）
临床特征
RLS 的诊断依赖四个必要标准（URGE）：


    

  1. Urge：不可抗拒的腿部活动冲动
    2. 

  2. Rest：静息/不动时出现或加重
    3. 

  3. Getting better with movement：活动后立即缓解
    4. 

  4. Evening/night：傍晚和夜间症状加重
    5. 



病理生理




机制
证据





脑内铁储备不足
CSF 铁蛋白降低；MRI 显示黑质铁含量减少

多巴胺激动剂有效（但长期可致增强）




昼夜节律调控
症状严格遵循昼夜节律（夜间加重）




遗传因素
一级亲属风险增加 3-6 倍；GWAS 发现 MEIS1 等位点





治疗
    

  • 铁补充（当血清铁蛋白 <75 μg/L 时）
    • 

  • α2δ 配体（gabapentin enacarbil, pregabalin）——当前推荐一线
    • 

  • 低剂量多巴胺激动剂（需警惕增强现象 augmentation）
    •

DSPD 的诊断要点
    

  • 并非简单的"晚睡晚起习惯"——是 SCN 内源周期偏长或对光信号响应异常
    • 

  • 当被强制在"正常"时间起床时出现慢性睡眠不足
    • 

  • 自由作息时睡眠质量完全正常（这区别于失眠）
    • 

  • 治疗：光疗（晨光暴露）+ 低剂量褪黑素（傍晚给药）+ 渐进式时间推移
    • 



何时就医
以下"红旗"信号提示需要专业评估：


    

  1. 打鼾 + 日间嗜睡 + 目击的呼吸暂停 → 排除 OSA
    2. 

  2. 入睡困难 >30 分钟，≥3 次/周，≥3 个月 → 慢性失眠评估
    3. 

  3. 突然的肌肉无力（尤其笑/惊讶时） → 排除猝倒/发作性睡病
    4. 

  4. 夜间肢体不宁 + 活动后缓解 → RLS 评估
    5. 

  5. REM 期间"演出梦境" → RBD（可能是帕金森前驱期）
    6. 

  6. 持续的昼夜节律偏移（非习惯选择） → 昼夜节律障碍评估
    7.
