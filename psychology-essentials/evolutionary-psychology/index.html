进化心理学 简介

进化心理学（Evolutionary Psychology）是将达尔文自然选择理论应用于人类心理与行为研究的学科分支。它试图回答一个根本性问题：为什么人类会以特定方式思考、感受和行动？与描述「是什么」「怎么样」的多数心理学分支不同，进化心理学追问的是终极原因（ultimate cause）——某一心理特征在祖先环境中解决了什么适应性问题、为何被自然选择保留至今。

本 hub 与兄弟 hub 的分工

进化心理学位于心理学知识库的第 18 章，与多个兄弟 hub 互补而不重叠。下表明确各自边界，避免在本 hub 重复展开属于他人的内容：

终极原因（为何演化出此机制） ✅ 核心 — 本 hub 专属视角
近端机制（神经/激素如何实现） 引用，不展开 02_biological-psychology、17_neuropsychology 脑区、神经递质细节去神经类 hub

一句话区分：兄弟 hub 回答机制如何运作与现象是什么，本 hub 回答它为什么会存在。

适合读者与前置

本 hub 适合对人类行为终极原因感兴趣的读者：心理学研究者、生物学爱好者、社会科学从业者，以及希望从进化视角理解日常行为的学习者。建议前置：

  • 必备：基础心理学概论（实体名、研究范式）、生物进化论常识（自然选择、遗传、变异）。
  • 推荐：博弈论入门（理解互惠、合作的演化稳定性），统计直觉（理解效应量、跨文化方差）。

全书结构

全书分四章，层层递进：

推荐学习路径

  1. 打地基：先通读第一章三节，掌握「自然选择→适应→进化心理机制」这条主线与适应主义方法论。其中 Hamilton 规则、领域特异性 是后续各章反复调用的基础概念。
  2. 按兴趣分流：关注两性、亲密关系→第二章；关注合作、信任、群体→第三章。两章相对独立，可任选其一深入。
  3. 看现实意义：第四章把前三章的理论延伸到临床、消费与公共健康，建议最后阅读以形成闭环。
  4. 时间有限：优先读每章第一节即可获得核心概念全景；进化失配 是把整套理论串起来的最佳单篇总结。
