效应量与统计效力

核心概念

效应量和统计效力是评价心理学研究发现的实际意义和方法论质量的两个关键指标。效应量回答"效果有多大"，统计效力回答"研究是否有足够的能力检测到效果"。在心理学经历可重复性危机之后，效应量和统计效力的报告和分析已成为高质量研究的标准要求。理解这两个概念，能帮助读者从"是否显著"的二元判断升级为"效果有多大、证据有多强"的连续评估。

常用效应量指标
心理学研究中使用的效应量指标可以分为三大类：差异类效应量、关联类效应量和风险类效应量。


Cohen's d 是最常用的差异类效应量，它衡量两组均值差异相对于标准差的大小。计算公式为 d = (M₁ - M₂) / SD_pooled。Jacob Cohen提出了广泛使用的经验标准：d = 0.2为小效应，d = 0.5为中效应，d = 0.8为大效应。


理解Cohen's d的直觉含义很重要。d = 0.5意味着两组的均值相差半个标准差。如果将两组的分布重叠在一起，d = 0.5时两个分布约有67%的面积重叠，而d = 0.2时约有85%的面积重叠。这意味着即使效果统计显著，如果d只有0.2，两组的个体差异远大于组间差异。


相关系数r本身就是一个效应量指标。Cohen的标准：r = 0.10为小效应，r = 0.30为中效应，r = 0.50为大效应。r²（决定系数）提供了更直观的解释——它表示一个变量能解释另一个变量变异的比例。


η²（Eta-squared）和偏η²是方差分析（ANOVA）中最常用的效应量指标。η²表示自变量解释的因变量总变异的比例。Cohen的标准：η² = 0.01为小效应，η² = 0.06为中效应，η² = 0.14为大效应。

统计效力分析
统计效力（Statistical Power）是研究正确地拒绝一个错误的零假设的概率，即检测到真实存在的效果的概率。效力 = 1 - β，其中β是II类错误（假阴性）的概率。心理学研究通常要求效力不低于0.80，即有至少80%的概率能检测到真实的效果。


统计效力受四个因素影响：显著性水平（α）、效应量大小、样本量和统计检验方法。在这四个因素中，研究者通常能够控制的是样本量。因此，效力分析最常见的应用是"先验效力分析"——在研究开始之前，根据预期的效应量和所需的效力水平，计算出需要多少样本。


效力分析的实践意义巨大。一项效力不足的研究就像用低分辨率相机拍照——即使被拍摄的对象很精彩，模糊的照片也无法展现其细节。心理学中大量的"不显著"结果可能并不是因为效果不存在，而是因为样本量太小，研究没有足够的统计效力来检测到真实的效果。

心理学研究中一个令人不安的事实是：许多已发表研究的统计效力严重不足。一项对心理学文献的元分析发现，心理学研究的中位效力仅约0.36，远低于0.80的推荐标准。这意味着平均而言，一项心理学研究只有36%的概率能检测到真实存在的效果。这一问题是可重复性危机的重要根源之一。


效应量在实际决策中的应用
效应量的实际意义取决于具体的应用场景。在某些场景下，小效应量就有重大的实际意义；在另一些场景下，即使效应量较大也可能不值得投入。

对于程序员来说，效应量思维在A/B测试和产品优化中至关重要。一个新的UI设计可能在统计上显著提升了点击率（p < 0.05），但如果提升幅度只有0.1%，这在商业上可能毫无意义。反过来，如果一个改动能将转化率从2%提升到3%（50%的相对提升），即使因为样本量不足还没有达到统计显著，也值得关注和进一步验证。


小结
    

  • 效应量衡量效果的实际大小，不受样本量膨胀的影响，是评价研究实际意义的关键指标
    • 

  • Cohen's d的小/中/大效应标准（0.2/0.5/0.8）提供了经验参照，但实际意义需结合具体场景判断
    • 

  • 统计效力是检测真实效果的概率，心理学研究通常要求效力≥0.80，但实际研究中许多研究的效力远低于此
    • 

  • 效力不足是心理学可重复性危机的重要根源——许多"不显著"的结果可能只是样本量太小
    • 

  • 完整的统计报告应该包含p值、效应量和置信区间三位一体，而非仅仅报告"p < 0.05"
    •
