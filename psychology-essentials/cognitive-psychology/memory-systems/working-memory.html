工作记忆

核心概念

工作记忆是一个容量有限的认知系统，负责在短时间内临时存储和操控信息，为推理、理解、学习和问题解决等复杂认知活动提供支持。工作记忆不是简单的"短时记忆"——它不仅仅存储信息，更重要的是对信息进行主动操作和整合。当你心算 47×3、理解一个复杂句子或在编程时跟踪多个变量的状态时，工作记忆都在全力运转。

Baddeley 和 Hitch 在 1974 年提出的工作记忆模型是该领域最具影响力的理论框架，后经多次修订形成当前的四成分模型。

语音环路
语音环路（Phonological Loop）是工作记忆中研究最深入的子系统，专门负责语音和言语信息的短暂存储。


两个子成分：语音环路包括语音存储器（phonological store）和构音复述过程（articulatory rehearsal process）。语音存储器被动地保持语音痕迹约 1.5-2 秒，之后自动衰退。构音复述过程通过内部语音（无声地"说"出来）刷新语音存储器中的信息，阻止其衰退。


语音相似效应：听起来相似的字母序列（如 B、C、D、G、P、T）比不相似的序列（如 F、K、L、Q、R、Y）更难记忆。这证明语音环路使用基于语音的编码——相似的语音表征更容易相互混淆。


词长效应：短单词（如"sun, cat, pen"）比长单词（如"university, refrigerator"）更容易记忆，因为长单词的构音复述需要更多时间，在有限的时间窗口内能复述的项目更少。记忆广度大约等于 2 秒内能说出的单词数量。


无关言语效应：即使被试不需要注意背景言语，无关的语音刺激也会干扰工作记忆中的序列信息保持。这是因为无关言语自动进入语音存储器，与需要记忆的信息竞争。这一效应对开放办公环境的设计有重要启示——背景对话是最干扰认知工作的噪声类型。


构音抑制：要求被试在记忆任务中重复说"the, the, the..."会严重损害对视觉呈现材料的记忆，因为构音抑制占用了复述过程。但有趣的是，构音抑制不影响对听觉呈现材料的直接编码——听觉信息可以直接进入语音存储器而无需经过构音转换。


中央执行系统
中央执行系统是工作记忆的核心控制成分，负责注意力分配、任务切换、信息更新和干扰抑制。Baddeley 将其比喻为一个"注意力管理者"，它本身不存储信息，而是管理其他子系统的运作。


注意控制功能：中央执行系统的核心功能包括——（1）聚焦注意力到相关信息上；（2）在两个任务或操作之间切换；（3）将注意力分配到多个任务；（4）连接工作记忆与长期记忆。前额叶皮层（特别是背外侧前额叶）是中央执行系统的主要神经基础。


Miyake 的执行功能三分模型：Miyake 等人通过潜变量分析识别了三个可分离但相关的执行功能——更新（updating）、转换（shifting）和抑制（inhibition）。更新指持续监控和修改工作记忆中的信息；转换指在任务集或心理定势之间灵活切换；抑制指压制优势反应或无关信息。


工作记忆容量
工作记忆容量（Working Memory Capacity, WMC）是认知心理学中最重要的个体差异变量之一，与流体智力、阅读理解和推理能力有高度相关。


Miller 的神奇数字 7±2：George Miller 在 1956 年提出短时记忆的容量约为 7±2 个项目。然而，后续研究表明这个估计过于乐观——当控制了组块策略后，纯粹的工作记忆容量更接近 Cowan 提出的 4±1 个项目。


操作广度任务：Daneman 和 Carpenter 开发了阅读广度任务来测量工作记忆的"加工+存储"双重容量——被试在阅读句子的同时需要记住每个句子的最后一个单词。阅读广度得分与阅读理解能力高度相关（r≈0.5-0.6），这证明了工作记忆不仅仅是存储能力，更是在加工过程中维持信息的能力。


WMC 与智力的关系：工作记忆容量与流体智力的相关系数在 0.5-0.7 之间，是心理学中最强的相关之一。Engle 的注意控制理论认为，WMC 的核心不是存储空间的大小，而是在干扰条件下维持目标信息激活的注意控制能力——高 WMC 个体更善于抑制无关信息的干扰。

小结
    

  • 工作记忆是容量有限的主动加工系统，由中央执行系统、语音环路、视空间画板和情景缓冲器组成
    • 

  • 语音环路通过构音复述维持语音信息，受语音相似性和词长效应的影响
    • 

  • 中央执行系统负责注意控制，涉及更新、转换和抑制三个可分离的执行功能
    • 

  • 工作记忆容量约为 4±1 个项目，与流体智力高度相关
    • 

  • WMC 的核心是注意控制能力而非纯粹的存储空间大小
    • 

  • 工作记忆研究对教育设计、界面设计和认知负荷管理具有重要应用价值
    •
