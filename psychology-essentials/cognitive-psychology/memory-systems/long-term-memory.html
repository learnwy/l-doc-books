Part II · 认知与发展认知心理学 简介记忆系统 简介长期记忆

长期记忆

核心概念

长期记忆是认知系统中负责信息永久存储的子系统，理论上容量无限、持续时间从几分钟到终身。与工作记忆的临时加工不同，长期记忆中的信息经过编码和巩固后可以在需要时被提取出来。长期记忆并非单一系统——它包含多个功能和神经基础不同的子系统，从个人经历到百科知识，从骑自行车的技能到对恐惧事件的情绪反应。

长期记忆的分类体系是理解记忆系统的基础框架。Squire 提出的分类系统将长期记忆分为陈述性（显性）和非陈述性（隐性）两大类。

情景记忆与语义记忆
Tulving 在 1972 年提出了情景记忆和语义记忆的经典区分。这两种记忆都属于陈述性记忆，都可以通过语言表达，但在主观体验、组织方式和神经基础上存在重要差异。


情景记忆：存储与特定时间、地点和个人情境相关的经历，伴随着"心理时间旅行"的主观体验——回忆一件往事时，我们不仅记起事件内容，还"重新体验"当时的时空情境和情绪状态。Tulving 将这种独特的意识体验称为"自传式觉知"（autonoetic consciousness）。情景记忆高度依赖海马体——海马体损伤导致无法形成新的情景记忆（顺行性遗忘），但已巩固的旧情景记忆可能保留。


语义记忆：存储关于世界的一般知识和概念，不与特定的获取情境绑定。你知道巴黎是法国首都，但很可能不记得第一次学到这个事实的具体场景。语义记忆以概念网络的形式组织——Collins 和 Loftus 的扩散激活模型认为概念以节点形式存储，语义相关的概念通过连接相互关联，激活一个概念会自动扩散到相关概念。


交互与转化：情景记忆和语义记忆并非完全独立。反复经历相似的事件会导致情景记忆"语义化"——具体的时空细节逐渐丢失，而抽象的规律和知识被提取出来。例如，你可能不记得每一次去超市购物的细节，但你知道超市购物的一般流程——这个"脚本"（script）就是从多次情景记忆中提炼出的语义知识。


编码与提取
编码深度效应：Craik 和 Lockhart 的加工水平理论认为记忆保持的效果取决于编码时的加工深度。浅层加工（如注意字母的外形）产生较弱的记忆痕迹，深层加工（如思考词义或建立关联）产生较强的记忆痕迹。


编码特异性原则：Tulving 和 Thomson 提出的编码特异性原则认为提取成功取决于编码时和提取时的线索匹配程度。信息在特定情境中编码，在相同情境中更容易提取。状态依赖记忆（如水下学习的材料在水下更容易回忆）和情境依赖记忆都支持了这一原则。


提取诱发遗忘：Anderson 等人发现，练习提取一部分记忆项目会抑制相关的未练习项目的提取——这被称为提取诱发遗忘（retrieval-induced forgetting）。例如，如果学习了"水果-苹果、水果-橙子、水果-香蕉"，反复提取"水果-苹果"会让"水果-橙子"变得更难回忆。这一现象说明记忆提取不是被动的读出过程，而是涉及主动的竞争和抑制。


记忆巩固的神经机制
海马体的角色：海马体是新陈述性记忆形成的关键结构。H.M. 的经典案例——双侧海马体切除后完全丧失了形成新情景记忆的能力，但旧记忆、程序性学习和智力均保持正常——确立了海马体在记忆巩固中的核心地位。


系统巩固理论：新形成的记忆最初依赖海马体，但随着时间推移，通过海马-皮层对话（主要发生在睡眠的慢波阶段），记忆逐渐转移到新皮层中独立存储。这就是为什么海马损伤患者表现出时间梯度的逆行性遗忘——最近的记忆受损最严重，而远期记忆相对保留。


记忆再巩固：Nader 等人的突破性发现表明，已经巩固的记忆在被提取（再激活）时会暂时进入不稳定状态，需要重新巩固才能再次稳定存储。再巩固窗口期间，记忆容易被修改或干扰。这一发现对创伤后应激障碍的治疗有重要启示——如果在创伤记忆再激活时施加干预，可能改变记忆的情绪成分。


睡眠与记忆巩固：睡眠在记忆巩固中起关键作用。慢波睡眠（SWS）期间，海马体"重播"白天学习的神经活动模式，将记忆转移到新皮层。REM 睡眠则更多参与程序性记忆和情绪记忆的巩固。睡眠剥夺显著损害新记忆的巩固，而学习后的短暂午睡可以显著提升记忆保持。

小结
    

  • 长期记忆分为陈述性（情景+语义）和非陈述性（程序性+启动等），依赖不同的神经系统
    • 

  • 编码深度和编码-提取一致性是决定记忆效果的关键因素
    • 

  • 海马体在新记忆的巩固中起关键作用，记忆通过系统巩固逐渐转移到新皮层
    • 

  • 记忆再巩固理论揭示已巩固的记忆在提取时可被修改
    • 

  • 睡眠在记忆巩固中起不可替代的作用，学习后的睡眠显著提升记忆保持
    • 

  • 理解长期记忆的组织和巩固机制对教育策略和临床干预具有重要指导价值
