分析方法选择

核心概念

数据分析方法（data analysis methods）的选择是研究设计中最具技术性的决策之一。正确的分析方法能从数据中提取有意义的模式和关系，而错误的方法不仅会导致无效结论，还可能产生误导性结果。在英语学术写作中，分析方法的选择必须在 Methodology 章节中明确说明并论证其合理性。

分析方法的选择取决于三个核心因素：研究问题的类型（描述、比较、预测、解释）、数据的类型（连续、分类、文本）和数据的分布特征（正态、非正态）。

描述性统计与数据检查
任何量化分析都应从描述性统计开始。它不仅帮助你理解数据的基本特征，还能识别潜在问题（如异常值、缺失数据、非正态分布）。


核心描述性指标：


集中趋势：均值（Mean）、中位数（Median）、众数（Mode）。正态分布的数据三者接近；偏态分布时中位数比均值更有代表性。


离散程度：标准差（Standard Deviation）、方差（Variance）、四分位距（Interquartile Range）。


分布形态：偏度（Skewness）和峰度（Kurtosis）。偏度绝对值 > 2 或峰度绝对值 > 7 通常被视为严重偏离正态分布。


数据清洗与预处理：


在英语学术写作中，数据预处理必须透明报告：


缺失数据处理："Missing data accounted for 3.5% of the total dataset. Little's MCAR test indicated that the data were missing completely at random (χ² = 12.45, p = .34). Missing values were handled using multiple imputation."


异常值处理："Outliers were identified using the z-score method. Three cases with z-scores exceeding ±3.0 were removed from the analysis."


正态性检验："The Shapiro-Wilk test indicated that the dependent variable was approximately normally distributed (W = 0.97, p = .12)."

推断性统计方法
推断性统计（inferential statistics）允许研究者基于样本数据推断总体特征。选择正确的推断性方法是量化研究的核心技能。


参数检验 vs. 非参数检验：


参数检验（parametric tests）假设数据满足特定条件（通常是正态分布和等方差）。当这些假设被违反时，应使用非参数检验（non-parametric tests）。

效应量的必要性：


p 值只告诉你效应是否存在，效应量（effect size）告诉你效应有多大。现代学术期刊越来越要求报告效应量。


    

  • Cohen's d（两组比较）：0.2 = 小, 0.5 = 中, 0.8 = 大
    • 

  • η²（ANOVA）：0.01 = 小, 0.06 = 中, 0.14 = 大
    • 

  • r 或 R²（相关/回归）：0.1 = 小, 0.3 = 中, 0.5 = 大
    • 



在英语论文中报告推断性统计的标准格式："An independent samples t-test revealed a significant difference between the experimental group (M = 4.52, SD = 0.78) and the control group (M = 3.89, SD = 0.92) on writing performance, t(86) = 3.45, p = .001, d = 0.73."


高级量化方法
当研究问题涉及多个变量的复杂关系时，需要使用高级量化方法。


多元回归分析：


多元回归（multiple regression）检验多个自变量对一个连续因变量的预测效果。在英语论文中的标准报告方式：


"A hierarchical multiple regression was conducted to predict academic achievement. In Step 1, demographic variables (age, gender) were entered as control variables (R² = .08, F(2, 147) = 6.41, p = .002). In Step 2, self-efficacy and motivation were added, accounting for an additional 23% of the variance (ΔR² = .23, ΔF(2, 145) = 24.15, p < .001)."


结构方程模型（SEM）：


SEM 是检验变量间复杂关系（包括直接效应、间接效应和测量误差）的高级工具。它在社会科学研究中越来越普遍。

质性数据分析方法
质性数据分析（qualitative data analysis）将非结构化的文本数据转化为有意义的主题和理论。与量化分析的标准化程序不同，质性分析是一个迭代、反思的过程。


主题分析（Thematic Analysis）：


Braun & Clarke (2006) 的六步主题分析法是最广泛使用的质性分析框架：


第一步，熟悉数据：反复阅读转录文本，记录初步印象。


第二步，生成初始编码：系统地标记数据中有意义的片段，为每个片段赋予编码（code）。


第三步，搜索主题：将相关编码归类为潜在主题（theme）。


第四步，审查主题：检查主题是否与编码和原始数据一致。


第五步，定义和命名主题：精确定义每个主题的范围和内涵。


第六步，撰写报告：选择有说服力的数据摘录来支撑每个主题。

在英语论文中报告质性分析的标准方式："Data were analyzed using Braun and Clarke's (2006) reflexive thematic analysis approach. Initial coding was conducted independently by two researchers, with an inter-rater agreement of 87%. Through iterative discussion, five overarching themes were identified."


小结
    

  • 分析方法的选择取决于研究问题类型、数据类型和分布特征
    • 

  • 任何分析都应从描述性统计和数据检查开始——异常值和缺失数据必须先处理
    • 

  • 效应量与 p 值同等重要——现代学术期刊越来越要求两者并报
    • 

  • 参数检验和非参数检验的选择取决于数据是否满足正态性等假设条件
    • 

  • SEM 和多层模型适用于复杂变量关系和嵌套数据的分析
    • 

  • 主题分析是最通用的质性分析方法，六步法提供清晰的操作框架
    •
