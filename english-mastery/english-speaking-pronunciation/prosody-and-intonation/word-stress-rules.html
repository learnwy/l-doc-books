单词重音规则

核心概念

单词重音（word stress）是英语发音系统中最重要的超音段特征之一。每个多音节英语词都有一个主重音（primary stress），标记为 /ˈ/，表示该音节发音时更响、更长、音调更高。部分长词还有次重音（secondary stress），标记为 /ˌ/。重音位置错误可能导致听者完全无法理解该词，甚至比单个音素错误更严重。

中文是声调语言，每个字都有固定的声调（一二三四声），但没有类似英语的"重音"系统。中文母语者往往忽视英语单词重音的重要性，或将中文的等长等力习惯带入英语，导致每个音节都读得一样平。

英语的单词重音是词汇属性——每个词的重音位置是固定的（有规律可循但也有大量例外），学习者需要在学习新词时就记住其重音位置。重音错误比音素错误更影响可理解度：将 dessert /dɪˈzɜːrt/（甜点）的重音放在第一音节会变成 desert /ˈdezərt/（沙漠）。

双音节词重音模式
英语双音节词的重音规律与词性密切相关。最重要的规则是"名词-动词重音转移"（noun-verb stress shift）：许多双音节词作名词时重音在第一音节，作动词时重音在第二音节。


名词重音在前的示例：


    

  • REcord /ˈrekərd/（记录）vs reCORD /rɪˈkɔːrd/（录制）
    • 

  • PREsent /ˈpreznt/（礼物）vs preSENT /prɪˈzent/（呈现）
    • 

  • PROject /ˈprɒdʒekt/（项目）vs proJECT /prəˈdʒekt/（投射）
    • 

  • OBject /ˈɒbdʒɪkt/（物体）vs obJECT /əbˈdʒekt/（反对）
    • 

  • CONtract /ˈkɒntrækt/（合同）vs conTRACT /kənˈtrækt/（收缩）
    • 

  • PROduce /ˈprɒdjuːs/（农产品）vs proDUCE /prəˈdjuːs/（生产）
    • 

  • IMport /ˈɪmpɔːrt/（进口品）vs imPORT /ɪmˈpɔːrt/（进口）
    • 



这个规则虽然有很多例外（rePLY、deSIGN、reSULT 无论词性重音都在后），但作为启发式规则非常有用。


双音节形容词通常重音在第一音节：HAPpy、CLEver、SIMple、PRETty。但以 -ive、-ous 结尾的形容词重音可能在后：aLIVE、aLONE。


双音节副词和介词的重音通常在第二音节：aBOVE、beLOW、beFORE、beHIND、beTWEEN。

后缀对重音的影响
英语中许多后缀会系统性地影响单词的重音位置。掌握这些规则能大幅减少重音错误。


重音固定后缀——这些后缀本身接受重音：


    

  • -ee：employEE、refugEE、interviewEE
    • 

  • -eer：volunTEER、engiNEER、pionEER
    • 

  • -ese：JapanESE、ChinESE、PortuguESE
    • 

  • -ique/-esque：unIQUE、techNIQUE、picturESQUE
    • 

  • -ette：cassSETTE、cigareTTE
    • 



重音前移后缀——这些后缀将重音吸引到自身前一个音节：


    

  • -tion/-sion：informaTION（重音在 -ma-）、decISION
    • 

  • -ic：scienTIFic、draMAtic、eLECtric
    • 

  • -ical：poLItical、hisTORical、staTIStical
    • 

  • -ity：possiBI​Lity、univerSIty、electRIcity
    • 

  • -ial/-ual：essenTIAL、artiGIcial、indiVIdual
    • 

  • -ious/-eous：mysTErious、courAgeous
    • 

  • -ify：iDENtify、SIMplify、CLArify
    • 



重音不变后缀——这些后缀不改变原词的重音位置：


    

  • -ment：deVELopment（重音保持在 VEL）
    • 

  • -ness：HAPpiness（重音保持在 HAP）
    • 

  • -ful：BEAUtiful（重音保持在 BEAU）
    • 

  • -less：CAReless（重音保持在 CARE）
    • 

  • -ly：QUIckly（重音保持在 QUICK）
    • 

  • -er/-or：TEAcher、DOCtor
    • 

  • -ing/-ed：RUNning、STARted
    •

小结
    

  • 单词重音是英语发音中影响可理解度最大的因素之一
    • 

  • 名词-动词重音转移规则（REcord vs reCORD）是最高频的双音节模式
    • 

  • 固定后缀（-ee、-eer）自身接受重音，如 employEE、engiNEER
    • 

  • 前移后缀（-tion、-ic、-ity）将重音吸引到前一音节
    • 

  • 不变后缀（-ment、-ness、-ly）不改变原词重音位置
    • 

  • 技术词汇中 configuration 主重音在 -RA-，遵循 -tion 前移规则
    • 

  • authentication 主重音在 -CA-，同样遵循 -tion 前移规则
    • 

  • performance 重音在 -FOR-，component 重音在 -PO-
    • 

  • 前端词汇：responsive 重音在 -SPON-，dependency 在 -PEN-
    • 

  • 后端词汇：deployment 重音在 -PLOY-，container 在 -TAIN-
    • 

  • 建议建立个人"技术词重音清单"，在学习新词时同步标注重音
    • 

  • 使用 Cambridge Dictionary 或 Forvo 可以听到标准重音发音
    • 

  • 重音错误在面试和演讲中尤其明显，值得专项练习
    • 

  • 音节数越多的词越需要注意次重音（ˌ）的位置
    • 

  • 后端词汇中 orchestration 主重音在 -STRA-，遵循 -tion 前移规则
    • 

  • microservice 主重音在 MI，次重音在 SER
    • 

  • 练习新词重音时大声朗读 3-5 遍比默读更有效
    • 

  • 词重音错误在口语中的负面影响超过单个音素错误
    • 

  • 遇到新词时先查字典确认重音位置再开口使用
    • 

  • 重读音节更响、更长、音调更高，非重读音节弱化为 schwa
    • 

  • 双音节词遵循"名前动后"的启发式规则（REcord vs reCORD）
    • 

  • 后缀分三类：固定重音（-ee）、前移重音（-tion、-ic）和不变（-ment）
    • 

  • 技术词汇重音需要逐一确认，algorithm 重音在首、parameter 在第二音节
    • 

  • 重音错误比音素错误更影响交流，学习新词时必须同步记住重音位置
    • 

  • 查词典时养成同时看重音标记的习惯，将重音视为词汇信息的一部分
    • 

  • 利用后缀规则可以推测大量派生词的重音位置，显著减少记忆负担
    •
