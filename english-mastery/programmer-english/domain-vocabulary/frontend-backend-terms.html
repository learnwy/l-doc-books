前端与后端专业术语

前端核心词汇

前端开发领域有一套独特的专业术语体系，这些词汇在 React、Vue 等框架的文档和技术讨论中高频出现。

渲染与 DOM 相关

术语 释义 例句
DOM (Document Object Model) HTML 文档的树形对象表示 "React updates the DOM efficiently using a diffing algorithm."
Virtual DOM 真实 DOM 的内存中轻量副本 "The Virtual DOM enables batch updates without direct DOM manipulation."
Shadow DOM 封装的 DOM 子树，样式与外部隔离 "Web Components use Shadow DOM for style encapsulation."
Hydration 在服务端渲染的 HTML 上附加事件监听 "Hydration errors occur when server and client markup don't match."
SSR (Server-Side Rendering) 服务端生成完整 HTML "SSR improves First Contentful Paint and SEO."
SSG (Static Site Generation) 构建时预渲染页面 "SSG is ideal for content that doesn't change frequently."
CSR (Client-Side Rendering) 浏览器端渲染所有内容 "CSR apps have a blank page until JavaScript loads."
ISR (Incremental Static Regeneration) 增量静态再生成 "ISR lets you update static content without full rebuild."
Streaming SSR 流式服务端渲染 "Streaming SSR sends HTML chunks as they become ready."
Reconciliation 新旧虚拟 DOM 树的比对算法 "React's reconciliation algorithm has O(n) complexity."

状态管理与数据流

术语 释义 例句
State 组件内部管理的可变数据 "Local state should only contain data that triggers re-renders."
Props 父组件向子组件传递的不可变数据 "Props flow down; events flow up."
Context 跨层级共享数据的机制 "Use Context for theme or auth data, not for frequently updating state."
Reactive 数据变化自动触发 UI 更新 "Vue's reactive system tracks dependencies automatically."
Two-way Binding 数据和 UI 互相同步 "v-model provides two-way binding in Vue."
Unidirectional Data Flow 数据单向流动 "React enforces unidirectional data flow for predictability."
Derived State 从其他状态计算得出的数据 "Computed properties are derived state that auto-updates."
Store 全局状态容器 "The Redux store holds the entire application state tree."
Reducer 纯函数，接收旧状态和 action 返回新状态 "Reducers must be pure — no side effects."
Side Effect 影响函数外部环境的操作 "API calls and DOM manipulation are side effects."

性能与优化

术语 释义 例句
Code Splitting 按需加载代码块 "Route-based code splitting reduces initial bundle size."
Tree Shaking 移除未使用的代码 "Tree shaking eliminates dead code during bundling."
Lazy Loading 延迟加载非关键资源 "Images below the fold use lazy loading."
Memoization 缓存计算结果避免重复计算 "useMemo prevents expensive recalculations on every render."
Debouncing 延迟执行直到操作停止 "Debounce search input to avoid excessive API calls."
Throttling 限制执行频率 "Throttle scroll handlers to fire at most once per 100ms."
Layout Shift (CLS) 页面元素位置意外变化 "CLS above 0.1 indicates poor visual stability."
First Contentful Paint (FCP) 首次内容绘制时间 "Our FCP is under 1.5 seconds on mobile networks."
Time to Interactive (TTI) 页面完全可交互的时间 "Large JavaScript bundles delay TTI significantly."
Bundle Size 打包后的 JavaScript 文件总大小 "Keep the initial bundle under 200KB for fast loading."

易混辨析

Component vs Element

  • Component：可复用的 UI 构建块（函数或类）
  • Element：Component 的一次渲染输出（React Element 是不可变的描述对象）

Controlled vs Uncontrolled

  • Controlled Component：表单值由 React state 控制
  • Uncontrolled Component：表单值由 DOM 自身管理

Synthetic Event vs Native Event

  • Synthetic Event：React 包装后的跨浏览器事件对象
  • Native Event：浏览器原生事件对象

后端核心词汇

请求处理与 API

术语 释义 例句
Middleware 请求和响应之间的处理层 "Auth middleware validates the JWT before reaching the handler."
Endpoint API 的具体 URL 路径 "The /users endpoint supports GET and POST methods."
Payload 请求或响应中携带的数据体 "The request payload must not exceed 10MB."
Serialization 将对象转为可传输格式 "JSON serialization converts objects to string representation."
Deserialization 将传输格式还原为对象 "Deserialization can fail if the payload doesn't match the schema."
Rate Limiting 限制客户端请求频率 "Rate limiting prevents API abuse — 100 requests per minute."
Pagination 分页返回大数据集 "Use cursor-based pagination for real-time data feeds."
Idempotency 多次请求产生相同结果 "PUT requests should be idempotent by design."
Webhook 事件发生时主动回调通知 "Stripe uses webhooks to notify us of payment events."
GraphQL Resolver 解析 GraphQL 查询中每个字段的函数 "The resolver for 'user.posts' makes a separate database query."

数据库与 ORM

术语 释义 例句
ORM (Object-Relational Mapping) 对象与数据库表的映射框架 "Prisma is a type-safe ORM for Node.js and TypeScript."
Migration 数据库结构的版本化变更 "Run migrations before deploying the new version."
Schema 数据库的结构定义 "The schema defines tables, columns, and relationships."
Index 加速查询的数据结构 "Adding an index on email reduced query time from 200ms to 2ms."
N+1 Problem 循环中逐条查询导致的性能问题 "Eager loading solves the N+1 problem for associations."
Connection Pool 预创建的数据库连接集合 "Set pool size to (cores × 2) + disk spindles."
Transaction 原子化的多步数据库操作 "Wrap related writes in a transaction to ensure consistency."
Deadlock 两个事务互相等待对方释放锁 "Consistent lock ordering prevents most deadlocks."
Optimistic Locking 乐观锁——提交时检查冲突 "Optimistic locking uses a version column to detect conflicts."
Pessimistic Locking 悲观锁——操作前先获取锁 "Use pessimistic locking for high-contention resources."

认证与安全

术语 释义 例句
Authentication (AuthN) 验证"你是谁" "JWT-based authentication stateless and scalable."
Authorization (AuthZ) 验证"你能做什么" "RBAC handles authorization based on user roles."
JWT (JSON Web Token) 编码的令牌，包含用户身份信息 "The JWT expires in 15 minutes; use refresh token to renew."
OAuth 2.0 授权框架——允许第三方有限访问 "OAuth 2.0 authorization code flow is the most secure for web apps."
CORS (Cross-Origin Resource Sharing) 跨域资源共享策略 "CORS headers control which origins can access your API."
CSRF (Cross-Site Request Forgery) 跨站请求伪造攻击 "CSRF tokens prevent malicious sites from making authenticated requests."
XSS (Cross-Site Scripting) 跨站脚本注入攻击 "Sanitize user input to prevent XSS attacks."
Hashing 单向转换，不可逆 "Never store passwords in plain text — always hash with bcrypt."
Salt 哈希前添加的随机数据 "A unique salt per user prevents rainbow table attacks."
RBAC (Role-Based Access Control) 基于角色的访问控制 "RBAC assigns permissions to roles, not individual users."

消息队列与异步处理

术语 释义 例句
Message Queue 异步消息传递的中间件 "We use RabbitMQ as our message queue for email notifications."
Producer / Consumer 消息发送方 / 接收方 "Producers publish events; consumers process them asynchronously."
Topic 消息的逻辑分类通道 "Each domain event has its own Kafka topic."
Dead Letter Queue (DLQ) 处理失败的消息存放队列 "Messages that fail 3 times are moved to the DLQ."
At-least-once Delivery 消息至少投递一次（可能重复） "At-least-once delivery requires idempotent consumers."
Exactly-once Semantics 消息精确投递一次 "Exactly-once is hard — most systems approximate it."
Backpressure 消费者处理不过来时反压生产者 "Implement backpressure to prevent memory exhaustion."
Fan-out 一条消息被多个消费者处理 "Fan-out allows multiple services to react to the same event."

前后端协作术语

前端和后端工程师协作时，需要一套共同的语言来描述接口约定、数据格式和交互模式。

术语 释义 例句
API Contract 前后端约定的接口规格 "The API contract defines request/response schemas for each endpoint."
BFF (Backend for Frontend) 专为前端定制的后端服务层 "The BFF aggregates data from multiple microservices for the mobile app."
DTO (Data Transfer Object) 跨层传输数据的纯数据对象 "DTOs decouple the database model from the API response shape."
Type Safety 编译期类型检查保证数据一致 "Shared TypeScript types ensure type safety between client and server."
OpenAPI / Swagger API 描述规范和工具集 "Generate client SDKs automatically from the OpenAPI spec."
tRPC 端到端类型安全的 RPC 框架 "tRPC eliminates the need for manual API type definitions."
Mock Server 模拟后端接口的开发工具 "Frontend devs use a mock server while the API is still in development."
Optimistic Update 假设操作成功先更新 UI "Optimistic updates make the UI feel instant — rollback if the API fails."
Stale-While-Revalidate 先显示缓存再后台刷新 "SWR pattern shows cached data immediately while fetching fresh data."
Server-Sent Events (SSE) 服务器向客户端的单向推送 "SSE is simpler than WebSockets for one-way real-time updates."

全栈通用术语

术语 释义 例句
API Contract API 的接口规格约定 "Breaking the API contract requires a major version bump."
Schema Validation 验证数据结构是否符合预定义模式 "Zod provides runtime schema validation for TypeScript."
Monorepo 多项目共享一个代码仓库 "Our monorepo contains frontend, backend, and shared packages."
Feature Flag 运行时开关控制功能启停 "Feature flags let us deploy code without exposing it to users."
Hot Reload / HMR 代码修改后即时更新而无需刷新 "HMR preserves state while updating the changed module."
Environment Variable 运行环境的配置参数 "Never commit secrets — use environment variables instead."
Dependency Injection 外部注入依赖而非内部创建 "DI makes classes testable by allowing mock injection."
Technical Debt 为赶进度而做的次优技术决策 "We're paying down technical debt by refactoring the auth module."

前后端术语的精准掌握不仅有助于阅读框架文档和技术博客，更能在跨职能团队讨论中准确传达技术细节。当前端工程师能准确地说 "hydration mismatch" 而非模糊地说 "rendering issue"，沟通效率会有质的提升。
