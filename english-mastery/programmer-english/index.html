程序员英语 简介

程序员英语是一门面向中文母语开发者的实用英语学习指南，聚焦软件工程日常中最高频的英语使用场景——从代码命名到技术沟通，从文档阅读到演讲表达，包括 AI 工具协作与开源贡献场景。

与通用英语不同，程序员英语有其独特的词汇体系、表达惯例和文化语境。一个精准的变量名能让代码自文档化，一段得体的 Code Review 评论能促进团队协作，一次流利的 Tech Talk 能建立技术影响力，一份清晰的 prompt 能让 AI 工具产出可用代码。掌握这些技能不仅是语言能力的提升，更是工程师职业发展的加速器。

本 hub 不包含：通用语法 / 一般词汇 / 应试英语——这些归 02_english-vocabulary / 03_english-grammar-advanced；通用阅读 / 写作技巧归 04_english-reading / 07_english-writing-practice。本 hub 只装"程序员场景化"的英语。

本知识库按使用场景划分为四个核心章节，外加 2026-05 后扩展的 AI 时代与开源场景：

第一章代码命名英语系统讲解变量、函数、类和模块的英语命名技巧，涵盖动词选择、前缀后缀规律、设计模式命名惯例，以及 AI 辅助编程（Copilot / Claude Code / Cursor）时代的命名一致性考量。

第二章技术读写英语聚焦开发者最常接触的读写场景：阅读 RFC 和 API 文档、撰写 PR Description 和 Review Comments、发表技术博客（含 Build-in-public 写作框架），以及 AI Prompt 写作作为一种新型技术写作子体（ICFC 模型、动词精度梯度、反 Chinglish 模式）。

第三章技术沟通英语涵盖远程协作时代的口头与书面沟通能力：Standup Meeting 句式、Slack / Email 异步沟通、技术演讲与线上 Tech Talk + Q&A、AI 工具协作场景的英语、以及 开源协作英语（首次贡献、drive-by PR、RFC 讨论、维护者回应）。

第四章领域专业词汇按技术方向整理高频术语表：系统架构、前后端开发、DevOps 与云计算，以及 AI / LLM 领域 8 大子领域术语（模型基础、tokenization、采样、prompt 工程、RAG / agent、失败模式、评估、成本延迟）。

建议学习路径：先通读第一章建立命名语感，再根据日常工作需要选读第二章或第三章的对应内容，最后将第四章作为日常查阅的词汇手册。AI 工具与开源贡献的相关条目可随实践随时跳读。每篇文章均提供可直接使用的例句和模板，鼓励在实际工作中即学即用。
