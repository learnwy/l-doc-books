PM 产品管理

产品规划

词汇 词性 含义 常用搭配
roadmap n. 路线图 product roadmap, quarterly roadmap
PRD (Product Requirements Document) n. 产品需求文档 write a PRD, review the PRD
user story n. 用户故事 write user stories, acceptance criteria
acceptance criteria n. 验收标准 define acceptance criteria, meet AC
MVP (Minimum Viable Product) n. 最小可行产品 ship the MVP, MVP scope
feature n. 功能 core feature, feature request

听说例句

A: Is the PRD ready for review? B: Almost. I'm finalizing the user stories and acceptance criteria for the MVP features.

A: What's on the Q2 roadmap? B: Three core features: search redesign, push notification optimization, and a new onboarding flow.

写作表达

  • The product roadmap outlines three strategic themes for the quarter, each broken down into measurable milestones.
  • Clear acceptance criteria ensure alignment between product expectations and engineering deliverables.

用户研究

词汇 词性 含义 常用搭配
user research n. 用户调研 conduct user research, user research findings
persona n. 用户画像 create personas, target persona
pain point n. 痛点 identify pain points, address pain points
use case n. 用例 common use case, edge case
usability n. 易用性 usability testing, improve usability
feedback n. 反馈 user feedback, gather feedback

听说例句

A: What did the user research reveal? B: The main pain point is the complex checkout flow. Our target persona prefers a one-click purchase option.

A: Should we do usability testing before launch? B: Absolutely. We need to cover the common use cases and a few edge cases.

写作表达

  • User research identified three key pain points that informed the redesign of the core product experience.
  • Personas were created based on interviews with 50 users to represent distinct behavioral segments.

优先级与决策

词汇 词性 含义 常用搭配
prioritize v. 优先排序 prioritize features, prioritize by impact
trade-off n. 权衡 make trade-offs, trade-off analysis
scope n./v. 范围/界定 define scope, out of scope
impact n. 影响 high impact, business impact
effort n. 工作量 low effort, effort estimation
backlog n. 待办列表 product backlog, groom the backlog

听说例句

A: How should we prioritize the feature requests? B: Let's use an impact-effort matrix. High impact, low effort items go first.

A: Is this feature in scope for the MVP? B: No, it's been moved to the backlog. We need to make trade-offs to hit the deadline.

写作表达

  • Features were prioritized using an impact-effort matrix to ensure maximum business value within the sprint.
  • Scope management is critical to prevent feature creep and maintain delivery timelines.

产品发布

词汇 词性 含义 常用搭配
launch n./v. 发布 product launch, soft launch
rollout n. 上线 phased rollout, global rollout
feature flag n. 功能开关 enable feature flag, feature flag system
beta n./adj. 测试版 beta testing, beta users
go-live n. 正式上线 go-live date, go-live checklist
iteration n. 迭代 first iteration, iterate based on feedback

听说例句

A: Are we doing a soft launch or a full rollout? B: Soft launch first — we'll enable the feature flag for 10% of users and monitor the metrics.

A: When is the go-live date? B: March 15. We're in beta testing now and will iterate based on user feedback before the full launch.

写作表达

  • A phased rollout strategy minimizes risk by gradually exposing the feature to larger user segments.
  • Beta testing with a representative sample of users provides valuable feedback for the final iteration before go-live.
