金融科技术语

核心概念

金融科技（Financial Technology，简称 FinTech）是金融与技术深度融合的产物，催生了一整套全新的英语术语体系。FinTech 术语的独特之处在于它横跨金融和技术两个领域，既包含传统金融概念的技术化表达，也包含区块链、人工智能等前沿技术在金融场景中的专用术语。对于程序员而言，理解 FinTech 术语是进入金融科技行业的敲门砖。

FinTech 领域的术语更新速度极快，每年都有大量新概念涌现。理解这些术语的构成逻辑和演变脉络，比死记硬背更加高效。

数字支付与交易
数字支付（Digital Payments）是 FinTech 中最成熟、应用最广泛的领域。


支付基础设施术语：payment gateway（支付网关）是连接商户和支付处理商的中间层。Payment processor（支付处理商）负责处理交易的技术和清算流程。Acquiring bank（收单银行）代表商户接收支付。Issuing bank（发卡银行）是持卡人的银行。Interchange fee（交换费）是发卡银行向收单银行收取的手续费。Merchant Discount Rate（MDR，商户折扣率）是商户为接受电子支付而支付的总费用率。

Open Banking（开放银行） 是近年来最具变革性的概念。它要求银行通过标准化 API 向第三方开放客户数据（在客户授权下）。核心术语包括：API（Application Programming Interface）、TPP（Third-Party Provider，第三方服务提供商）、AISP（Account Information Service Provider，账户信息服务提供商）和 PISP（Payment Initiation Service Provider，支付发起服务提供商）。PSD2（Payment Services Directive 2，第二版支付服务指令）是欧盟推动开放银行的监管框架。


区块链与加密货币
区块链（Blockchain）和加密货币（Cryptocurrency）是 FinTech 中技术门槛最高、术语最密集的领域。


区块链基础术语：blockchain（区块链）是一种分布式账本（distributed ledger）技术，数据以区块（block）形式链式存储。Consensus mechanism（共识机制）确保网络中所有节点对数据状态达成一致。Proof of Work（PoW，工作量证明）和 Proof of Stake（PoS，权益证明）是两种主流共识机制。Hash（哈希）是将任意长度数据映射为固定长度值的函数。Node（节点）是区块链网络中的参与者。


加密货币术语：cryptocurrency（加密货币）是基于密码学的数字资产。Token（代币）是在现有区块链上发行的数字资产，分为 fungible token（同质化代币，如 ERC-20）和 non-fungible token（NFT，非同质化代币，如 ERC-721）。Wallet（钱包）存储私钥（private key）和公钥（public key）。Hot wallet（热钱包）联网，方便但安全性低；cold wallet / cold storage（冷钱包/冷存储）离线，安全性高。

Smart Contract（智能合约） 是在区块链上自动执行的程序代码。Solidity 是以太坊智能合约的主要编程语言。Gas（燃气费）是执行智能合约时需要支付的计算成本。Gas fee 的波动直接影响交易成本。


数字银行与嵌入式金融
数字银行（Digital Banking）和嵌入式金融（Embedded Finance）代表了金融服务的新形态。


数字银行术语：neobank（新型数字银行）是没有实体网点的纯数字银行。Challenger bank（挑战者银行）是采用数字化模式与传统银行竞争的新兴银行。Banking-as-a-Service（BaaS，银行即服务）允许非银行企业通过 API 提供银行服务。Core banking system（核心银行系统）是银行运营的技术基础。Digital onboarding（数字化开户）是在线完成身份验证和账户开设的流程。


嵌入式金融（Embedded Finance）是将金融服务嵌入非金融产品和平台的趋势。例如，电商平台内置贷款功能（embedded lending），打车应用内置保险（embedded insurance），SaaS 平台内置支付（embedded payments）。相关术语包括：


    

  • BaaS（Banking-as-a-Service）— 提供银行功能的 API 平台
    • 

  • PayFac（Payment Facilitator）— 支付促进者，简化商户接入支付的流程
    • 

  • White-label（白标）— 由第三方提供但以品牌方名义呈现的服务
    • 

  • Super app（超级应用）— 集成多种服务的平台型应用
    • 



智能投顾（Robo-Advisor）利用算法自动化投资管理。核心术语包括：algorithm-driven portfolio management（算法驱动的组合管理）、risk profiling（风险画像，评估客户风险承受能力）、automated rebalancing（自动再平衡）和 tax-loss harvesting（税务亏损收割，通过出售亏损资产来抵减应税收入）。


监管科技与合规自动化
监管科技（RegTech，Regulatory Technology）利用技术手段帮助金融机构满足合规要求。


KYC 自动化：eKYC（electronic KYC，电子化客户识别）通过 OCR（光学字符识别）、facial recognition（人脸识别）和 biometric verification（生物特征验证）实现远程身份验证。Document verification（证件验证）确认身份证件的真实性。Liveness detection（活体检测）防止使用照片或视频冒充。


AML 与交易监控：transaction monitoring（交易监控）实时分析交易行为以识别可疑活动。Suspicious Activity Report（SAR，可疑活动报告）是金融机构向监管机构提交的报告。Sanctions screening（制裁名单筛查）确保不与受制裁实体交易。PEP screening（政治敏感人物筛查）识别具有政治风险的客户。

Regulatory Sandbox（监管沙箱） 是监管机构为 FinTech 创新提供的受控测试环境。在沙箱中，企业可以在有限范围内测试新产品而不必完全满足现有监管要求。这个概念最早由英国 FCA（Financial Conduct Authority，金融行为监管局）引入，现已被全球多国采用。


小结
    

  • FinTech 术语横跨金融和技术两个领域，需要同时具备金融常识和技术背景才能准确理解
    • 

  • 数字支付是最成熟的 FinTech 领域，Open Banking 和 BNPL 是当前最具影响力的发展方向
    • 

  • 区块链与加密货币术语（DeFi、smart contract、NFT）技术门槛高但应用前景广阔
    • 

  • 数字银行和嵌入式金融（BaaS、embedded finance）正在重塑金融服务的分发模式
    • 

  • RegTech（eKYC、AML、regulatory sandbox）帮助金融机构在创新与合规之间取得平衡
    • 

  • FinTech 术语更新速度极快，建议关注 TechCrunch、Finextra 等科技金融媒体保持知识更新
    • 

  • 对程序员而言，掌握 FinTech 术语是进入金融科技行业的重要竞争力
    •
