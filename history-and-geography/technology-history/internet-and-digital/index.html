互联网与数字时代 简介

本章讲述互联网如何从一个军事研究项目演变为连接数十亿人的全球信息基础设施，以及由此开启的数字时代如何彻底重塑了人类社会。互联网的故事是技术史上最激动人心的篇章之一，它的每一次重大演进都伴随着商业模式的革新和社会形态的变迁。

互联网起源追溯从 ARPANET 到全球互联网的发展历程。本节讲述冷战背景下分组交换网络的诞生、TCP/IP 协议栈的确立如何奠定了互联网的技术基础，以及从学术网络到商业开放这一关键转折背后的政策与技术因素。

Web 演进记录万维网从蒂姆·伯纳斯-李的最初构想到如今丰富多样的 Web 生态的发展轨迹。本节梳理从静态网页到动态交互、从 Web 1.0 的信息发布到 Web 2.0 的用户参与，再到当前 Web 3.0 愿景的技术迭代过程，并讨论浏览器战争、前端技术爆发等标志性事件。

移动互联网革命聚焦智能手机如何引发互联网使用方式的根本性转变。从 iPhone 的横空出世到应用商店生态的形成，本节分析移动互联网如何打破了时空限制让互联网真正融入日常生活，并探讨这一转变对社交、电商、支付和内容消费等领域带来的深刻影响。

建议按时间顺序阅读三个主题。互联网起源提供底层网络的历史背景，Web 演进展示应用层的迭代逻辑，移动互联网革命则呈现最新一轮的范式转移。三者共同构成数字时代技术演进的完整叙事。
