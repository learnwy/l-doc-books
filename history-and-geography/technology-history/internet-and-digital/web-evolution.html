Web 演进

核心概念

万维网（World Wide Web, WWW）的发展是互联网历史中最具变革性的篇章。Tim Berners-Lee 在 1989 年提出的万维网概念——通过超链接将全球的文档连接在一起——从根本上改变了人类获取、分享和创造信息的方式。Web 的演进通常被划分为 Web 1.0（只读）、Web 2.0（读写）和 Web 3.0（去中心化）三个阶段，每个阶段都代表着技术能力和用户角色的质的飞跃。

对于程序员而言，Web 的演进史就是前端技术和后端架构的发展史。从静态 HTML 页面到 AJAX 动态交互，从服务器端渲染到单页应用（SPA），从单体架构到微服务，每一次技术变革都重新定义了 Web 开发的最佳实践。

Web 1.0：信息发布时代
1989 年，Tim Berners-Lee 在 CERN（欧洲核子研究中心）提出了万维网的概念。他的初衷是解决 CERN 内部信息共享的混乱问题——不同的计算机系统使用不同的文档格式，研究者之间的信息交流极为困难。


Berners-Lee 发明了三个核心技术：


    

  • HTML（超文本标记语言）：描述文档结构和内容
    • 

  • HTTP（超文本传输协议）：在客户端和服务器之间传输文档
    • 

  • URL（统一资源定位符）：为每个文档提供唯一的地址
    • 



1993 年 Marc Andreessen 和 Eric Bina 在伊利诺伊大学开发了 Mosaic 浏览器——第一个支持图文混排的 Web 浏览器。Mosaic 使 Web 从学术工具变为大众媒介。Andreessen 后来创建了 Netscape，推出了 Netscape Navigator 浏览器，引发了第一次浏览器大战。

互联网泡沫破裂
2000
.com 泡沫崩溃





1995-2000 年的互联网泡沫是 Web 1.0 时代的高潮与崩溃。大量互联网公司在缺乏可行商业模式的情况下获得巨额投资，纳斯达克指数在 2000 年 3 月达到 5,048 点的峰值后急剧下跌，两年内跌去近 80%。然而，泡沫虽然摧毁了大量公司，却留下了宝贵的基础设施（光纤网络、数据中心）和技术人才，为 Web 2.0 的腾飞奠定了基础。


Web 2.0：用户参与时代
Web 2.0 的核心转变是用户从信息的被动消费者变为主动创造者。博客、维基百科、社交网络、视频分享等平台使得任何人都可以在网上发布内容，用户生成内容（UGC, User-Generated Content）成为 Web 的主要内容来源。

社交网络是 Web 2.0 最具代表性的产物。Facebook（2004）、Twitter（2006）和 Instagram（2010）重新定义了人与人之间的在线交流方式。社交网络创造了"网络效应"驱动的商业模式——用户越多，平台越有价值，吸引更多用户，形成正反馈循环。


Web 2.0 时代也催生了"平台经济"。Google、Facebook、Amazon 和 Apple 成为数字经济的基础设施提供者，它们控制了用户的注意力、数据和交易。这种集中化趋势与互联网最初的去中心化理想形成了鲜明对比。


Web 3.0 与未来趋势
Web 3.0 是一个仍在定义中的概念。区块链社区将 Web 3.0 定义为基于去中心化技术的互联网，用户拥有自己的数据和数字资产。AI 社区则强调 Web 3.0 是智能化的互联网，AI 能够理解和处理 Web 上的信息。

无论 Web 3.0 最终以什么形态出现，有几个趋势是明确的：用户对数据隐私和所有权的要求在增强，AI 正在成为 Web 交互的新范式，跨平台和跨设备的无缝体验将成为标准。


小结
    

  • Tim Berners-Lee 发明的 HTML、HTTP 和 URL 三大技术构成了万维网的基础
    • 

  • Web 1.0 是只读的信息发布平台，互联网泡沫是其高潮和转折点
    • 

  • Web 2.0 使用户从消费者变为创造者，社交网络和平台经济是其标志
    • 

  • Web 2.0 的集中化趋势与互联网最初的去中心化理想形成了矛盾
    • 

  • Web 3.0 是仍在定义的概念，去中心化、AI 和沉浸式体验是三个主要方向
    • 

  • 每个 Web 阶段都重新定义了开发者的角色和技术栈
    •
