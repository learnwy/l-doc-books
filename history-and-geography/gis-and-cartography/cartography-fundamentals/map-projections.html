地图投影

核心概念

地图投影（Map Projection）是将地球的三维曲面转换为二维平面的数学方法。由于球面无法在不产生变形的情况下展开为平面（高斯"不可展曲面"定理），任何地图投影都必然引入某种形式的失真——面积、形状、距离或方向中的一项或多项会被扭曲。地图投影的选择本质上是在不同类型失真之间的取舍。

地图投影理论是制图学和 GIS 的基石。错误的投影选择不仅导致视觉上的误导（如墨卡托投影中格陵兰岛看起来与非洲一样大），还可能导致空间分析结果的严重偏差（如在等角投影上计算面积）。理解投影原理是每一位地理信息工作者的必备素养。

圆柱投影家族
圆柱投影（Cylindrical Projection）想象一个圆柱面包裹地球，将地球表面投射到圆柱面上再展开。最著名的圆柱投影是墨卡托投影（Mercator Projection），由荷兰制图学家墨卡托于 1569 年设计，最初用于航海导航。


墨卡托投影是等角投影——它保持了地图上任一点的局部形状和方向角度不变。这一特性对航海至关重要：在墨卡托投影上，任何恒向线（等角航线，Rhumb Line）表现为直线，航海者只需用直尺在地图上画一条线，读出与经线的夹角，就能确定航向。


然而，墨卡托投影的致命缺陷是面积严重失真。为了保持等角性质，高纬度地区被极度拉伸——格陵兰岛在墨卡托投影上的视觉面积接近非洲的 75%，而实际上仅为非洲的 7%。这种面积失真在政治和认知上产生了深远影响：长期使用墨卡托投影使许多人低估了非洲、南美等赤道地区的真实规模。


横轴墨卡托投影（Transverse Mercator）将圆柱面旋转 90°，使其与某条子午线相切。通用横轴墨卡托投影（UTM，Universal Transverse Mercator）是全球最广泛使用的坐标系统，将地球划分为 60 个 6° 宽的投影带，每个带内使用独立的横轴墨卡托投影。UTM 系统在军事、测绘和 GIS 中被广泛采用，因为它在每个投影带内提供了良好的距离和面积精度。

圆锥与方位投影
圆锥投影（Conic Projection）想象一个圆锥面套在地球上，通常与两条纬线相割（或与一条纬线相切），投影后展开为扇形。圆锥投影特别适合中纬度地区的区域制图，因为沿标准纬线的失真最小。


阿尔伯斯等积圆锥投影（Albers Equal-Area Conic）是面积分析中最常用的投影之一。它保持面积不变，适合用于展示人口密度、土地利用等需要面积准确性的统计地图。美国地质调查局（USGS）和美国人口普查局的标准地图均采用阿尔伯斯投影。


兰伯特等角圆锥投影（Lambert Conformal Conic）保持角度不变，是航空图和气象图的标准投影。国际民航组织（ICAO）规定中纬度地区的航空导航图必须使用兰伯特等角圆锥投影。


方位投影（Azimuthal Projection）将地球投射到与地球相切或相割的平面上。等距方位投影以某一点为中心，保持从中心点到任何其他点的距离和方向准确，常用于展示某城市到全球各地的距离。球极投影（Stereographic Projection）是等角方位投影，用于极区地图和晶体学。


Web 地图与 EPSG:3857
Web 地图的兴起对投影选择产生了深远影响。Google Maps 于 2005 年采用了 Web 墨卡托投影（EPSG:3857），此后所有主流 Web 地图平台（OpenStreetMap、Mapbox、百度地图、高德地图）均沿用了这一标准。


Web 墨卡托之所以被选中，有技术层面的原因：它将整个地球映射为一个正方形，便于金字塔式瓦片切割（每个缩放级别将地图分为 4^n 个等大小的正方形瓦片）；且经纬度到平面坐标的转换公式简单，计算效率高。


然而，Web 墨卡托继承了墨卡托投影的所有面积失真问题，且在高于 85° 纬度的区域不可用。更令人担忧的是，Web 地图的普及使数十亿用户每天接触的世界地图都是面积严重失真的墨卡托投影——这强化了对高纬度地区（主要是欧美国家）面积的高估和对低纬度地区（主要是发展中国家）面积的低估。


一些替代方案正在出现。d3.js 等可视化库支持数百种投影，Equal Earth 投影（2018 年发布）提供了面积准确且视觉美观的世界地图投影。但 EPSG:3857 的基础设施惯性（全球数十亿瓦片已按此标准切割和缓存）意味着短期内替代几乎不可能。

小结
    

  • 地图投影是球面到平面的数学变换，任何投影必然在面积、形状、距离或方向上产生失真
    • 

  • 墨卡托投影为航海而生，其等角特性使航线为直线，但面积失真严重
    • 

  • 圆锥投影适合中纬度区域制图，方位投影适合以某点为中心的距离展示
    • 

  • UTM 系统将地球分为 60 个投影带，在军事、测绘和 GIS 中被广泛采用
    • 

  • Web 墨卡托（EPSG:3857）因技术便利成为 Web 地图标准，但其面积失真影响数十亿用户的地理认知
    • 

  • 投影选择应基于制图目的：导航选等角，面积统计选等积，一般展示选折衷
