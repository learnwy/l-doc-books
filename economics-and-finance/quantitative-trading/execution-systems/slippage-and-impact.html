滑点与市场冲击

核心概念

滑点（Slippage）是交易的预期成交价格与实际成交价格之间的差异，市场冲击（Market Impact）是交易行为本身对市场价格造成的影响。对于量化策略而言，滑点和市场冲击是回测与实盘之间表现差距的主要来源。

市场冲击可以分为临时性冲击和永久性冲击。临时性冲击由流动性消耗引起，会随时间消散；永久性冲击由信息揭示引起，反映了交易行为携带的信息被市场吸收后的价格调整。

市场冲击模型
市场冲击模型量化交易规模与价格变动之间的关系。准确的冲击模型是执行算法设计和交易成本分析（TCA）的基础。


平方根模型（Square Root Model）是最经典的市场冲击模型，由 Kyle 和 Obizhaeva 提出。它认为市场冲击与交易量的平方根成正比，与波动率正相关，与日均成交量的平方根负相关。


interface ImpactModel {
  estimateImpact(params: ImpactParams): ImpactEstimate;
}

interface ImpactParams {
  orderSize: number;
  averageDailyVolume: number;
  dailyVolatility: number;
  participationRate: number;
  executionDuration: number;
  side: 'buy' | 'sell';
}

interface ImpactEstimate {
  temporaryImpact: number;
  permanentImpact: number;
  totalImpact: number;
  impactBps: number;
  costDollars: number;
}

const squareRootModel = (eta = 0.5, gamma = 0.314): ImpactModel => ({
  estimateImpact: (params) => {
    const volumeFraction = params.orderSize / params.averageDailyVolume;
    const temporaryImpact = eta * params.dailyVolatility * Math.sqrt(volumeFraction);
    const permanentImpact = gamma * params.dailyVolatility * volumeFraction;
    const totalImpact = temporaryImpact + permanentImpact;
    const direction = params.side === 'buy' ? 1 : -1;
    const midPrice = 100;
    return {
      temporaryImpact: temporaryImpact * direction,
      permanentImpact: permanentImpact * direction,
      totalImpact: totalImpact * direction,
      impactBps: totalImpact * 10000,
      costDollars: totalImpact * midPrice * params.orderSize,
    };
  },
});

const almgrenChrissModel = (alpha = 0.5, beta = 0.6, gamma = 0.1): ImpactModel => ({
  estimateImpact: (params) => {
    const sigma = params.dailyVolatility;
    const eta = params.orderSize / params.averageDailyVolume;
    const T = params.executionDuration;

    const temporaryImpact = alpha * sigma * (eta / T) ** beta;
    const permanentImpact = gamma * sigma * eta;

    return {
      temporaryImpact,
      permanentImpact,
      totalImpact: temporaryImpact + permanentImpact,
      impactBps: (temporaryImpact + permanentImpact) * 10000,
      costDollars: (temporaryImpact + permanentImpact) * 100 * params.orderSize,
    };
  },
});
最优执行理论
最优执行理论（Optimal Execution Theory）解决的核心问题是：给定一个需要执行的大额订单，如何在执行速度和市场冲击之间找到最优平衡。Almgren-Chriss 框架是这一领域的经典模型。


速度-冲击权衡：执行越快，临时性冲击越大但时机风险越小；执行越慢，冲击越小但面临更多的价格不确定性。最优策略取决于交易者的风险厌恶程度。


interface ExecutionSchedule {
  timeSlots: number;
  quantities: number[];
  expectedCost: number;
  varianceCost: number;
  totalCost: number;
}

const almgrenChrissOptimal = (
  totalQuantity: number,
  numSlots: number,
  sigma: number,
  eta: number,
  lambda: number,
  adv: number,
): ExecutionSchedule => {
  const tauFraction = 1 / numSlots;
  const kappa = Math.sqrt((lambda * sigma ** 2) / eta);

  const quantities: number[] = [];
  let totalExpectedCost = 0;

  for (let k = 0; k < numSlots; k++) {
    const t = k * tauFraction;
    const tradeFraction = Math.sinh(kappa * (1 - t)) / Math.sinh(kappa);
    const slotQuantity = (totalQuantity * tradeFraction) / numSlots;
    quantities.push(Math.round(slotQuantity));

    const participation = slotQuantity / (adv * tauFraction);
    const slotImpact = eta * Math.sqrt(participation) * sigma;
    totalExpectedCost += slotImpact * slotQuantity;
  }

  const actualTotal = quantities.reduce((a, b) => a + b, 0);
  if (actualTotal !== totalQuantity) {
    quantities[quantities.length - 1] += totalQuantity - actualTotal;
  }

  const varianceCost = (lambda * sigma ** 2 * totalQuantity ** 2) / (2 * numSlots);

  return {
    timeSlots: numSlots,
    quantities,
    expectedCost: totalExpectedCost,
    varianceCost,
    totalCost: totalExpectedCost + varianceCost,
  };
};

const adaptiveExecutionSchedule = (
  schedule: ExecutionSchedule,
  currentSlot: number,
  actualFills: number[],
  currentPrice: number,
  arrivalPrice: number,
): number => {
  const totalFilled = actualFills.reduce((a, b) => a + b, 0);
  const totalTarget = schedule.quantities.slice(0, currentSlot + 1).reduce((a, b) => a + b, 0);
  const shortfall = totalTarget - totalFilled;

  const priceDeviation = (currentPrice - arrivalPrice) / arrivalPrice;
  const urgencyMultiplier = priceDeviation > 0.005 ? 1.5 : priceDeviation < -0.005 ? 0.5 : 1.0;

  return Math.max(0, (schedule.quantities[currentSlot] + shortfall * 0.5) * urgencyMultiplier);
};
风险厌恶系数 λ 的选择对最优策略影响显著。λ 越大，策略越倾向于快速执行（减少价格风险），λ 越小，策略越倾向于缓慢执行（减少冲击成本）。


交易成本分析
交易成本分析（Transaction Cost Analysis, TCA）是评估执行质量的标准方法。它通过比较实际成交价格与基准价格来衡量执行的优劣。


Implementation Shortfall（实施缺口）是最常用的 TCA 基准，衡量决策时价格与最终执行价格之间的差异。它可以进一步分解为延迟成本、市场冲击和时机成本。


interface TCAResult {
  benchmark: string;
  totalShortfall: number;
  totalShortfallBps: number;
  delayCost: number;
  impactCost: number;
  timingCost: number;
  spreadCost: number;
}

interface TradeExecution {
  decisionPrice: number;
  arrivalPrice: number;
  avgFillPrice: number;
  closingPrice: number;
  quantity: number;
  side: 'buy' | 'sell';
  fills: { price: number; quantity: number; timestamp: number }[];
}

const calculateImplementationShortfall = (exec: TradeExecution): TCAResult => {
  const direction = exec.side === 'buy' ? 1 : -1;

  const totalShortfall = direction * (exec.avgFillPrice - exec.decisionPrice);
  const totalShortfallBps = (totalShortfall / exec.decisionPrice) * 10000;

  const delayCost = direction * (exec.arrivalPrice - exec.decisionPrice);
  const impactCost = direction * (exec.avgFillPrice - exec.arrivalPrice);
  const timingCost = direction * (exec.closingPrice - exec.avgFillPrice);

  return {
    benchmark: 'implementation_shortfall',
    totalShortfall,
    totalShortfallBps,
    delayCost,
    impactCost,
    timingCost: Math.abs(timingCost),
    spreadCost: 0,
  };
};

const calculateVWAPShortfall = (exec: TradeExecution, marketVWAP: number): number => {
  const direction = exec.side === 'buy' ? 1 : -1;
  return direction * (exec.avgFillPrice - marketVWAP);
};

const aggregateTCA = (
  results: TCAResult[],
): {
  avgShortfallBps: number;
  medianShortfallBps: number;
  avgImpactBps: number;
  totalCostDollars: number;
} => {
  const bps = results.map((r) => r.totalShortfallBps);
  const sorted = [...bps].sort((a, b) => a - b);
  return {
    avgShortfallBps: bps.reduce((a, b) => a + b, 0) / bps.length,
    medianShortfallBps: sorted[Math.floor(sorted.length / 2)],
    avgImpactBps: ((results.reduce((a, b) => a + b.impactCost, 0) / results.length) * 10000) / 100,
    totalCostDollars: results.reduce((a, b) => a + Math.abs(b.totalShortfall), 0),
  };
};

小结
    

  • 市场冲击分为临时性（流动性消耗）和永久性（信息揭示），对策略成本影响显著
    • 

  • 平方根模型是最经典的冲击模型，冲击与交易量平方根成正比
    • 

  • Almgren-Chriss 最优执行框架在速度和冲击之间寻找数学最优解
    • 

  • 自适应执行策略根据实时市场状况动态调整交易节奏
    • 

  • TCA 通过多种基准评估执行质量，Implementation Shortfall 是最全面的方法
    • 

  • 准确估算和控制交易成本是量化策略实盘盈利的关键因素
