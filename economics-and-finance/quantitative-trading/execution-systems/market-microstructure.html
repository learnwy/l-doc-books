市场微观结构

核心概念

市场微观结构研究交易机制如何影响价格形成过程。对量化交易者而言，理解微观结构意味着理解订单簿动态、买卖价差的构成、流动性的时变特征以及不同参与者的行为模式。这些知识直接影响执行策略的设计和交易成本的估算。

微观结构的核心问题是：在信息不对称的环境下，做市商如何在提供流动性的同时避免被知情交易者逆向选择。买卖价差是做市商对提供流动性服务的补偿，也是交易者的隐性成本。

订单簿动态
订单簿（Order Book）是限价单市场的核心数据结构，记录了所有未成交的限价单。订单簿的状态反映了市场参与者对价格的看法和流动性的分布。理解订单簿动态对执行算法的设计至关重要。


订单簿结构：买方订单按价格从高到低排列，卖方订单按价格从低到高排列。最优买价（Best Bid）和最优卖价（Best Ask）之间的差价即为买卖价差。


interface OrderBookLevel {
  price: number;
  quantity: number;
  orderCount: number;
}

interface OrderBook {
  symbol: string;
  timestamp: number;
  bids: OrderBookLevel[];
  asks: OrderBookLevel[];
  lastTradePrice: number;
}

interface OrderBookMetrics {
  midPrice: number;
  spread: number;
  spreadBps: number;
  bidDepth: number;
  askDepth: number;
  imbalance: number;
  weightedMidPrice: number;
}

const calculateOrderBookMetrics = (book: OrderBook): OrderBookMetrics => {
  const bestBid = book.bids[0];
  const bestAsk = book.asks[0];
  const midPrice = (bestBid.price + bestAsk.price) / 2;
  const spread = bestAsk.price - bestBid.price;
  const spreadBps = (spread / midPrice) * 10000;

  const bidDepth = book.bids.slice(0, 5).reduce((s, l) => s + l.quantity * l.price, 0);
  const askDepth = book.asks.slice(0, 5).reduce((s, l) => s + l.quantity * l.price, 0);
  const imbalance = (bidDepth - askDepth) / (bidDepth + askDepth);

  const weightedMidPrice =
    (bestBid.price * bestAsk.quantity + bestAsk.price * bestBid.quantity) / (bestBid.quantity + bestAsk.quantity);

  return { midPrice, spread, spreadBps, bidDepth, askDepth, imbalance, weightedMidPrice };
};

const calculateDepthWeightedPrice = (levels: OrderBookLevel[], targetQuantity: number): number => {
  let remaining = targetQuantity;
  let totalCost = 0;

  for (const level of levels) {
    const fillQty = Math.min(remaining, level.quantity);
    totalCost += fillQty * level.price;
    remaining -= fillQty;
    if (remaining <= 0) break;
  }

  const filledQty = targetQuantity - Math.max(0, remaining);
  return filledQty > 0 ? totalCost / filledQty : 0;
};
订单簿不平衡（Order Book Imbalance）是短期价格预测的重要信号。当买方深度显著大于卖方深度时，价格倾向于上涨，反之亦然。


买卖价差分解
买卖价差是交易成本的核心组成部分，理解价差的构成有助于估算不同市场环境下的真实交易成本。价差可以分解为三个组成部分：逆向选择成本、存货持有成本和订单处理成本。


逆向选择成本是做市商因与知情交易者交易而产生的预期损失。当知情交易者比例高时，逆向选择成本上升，价差加大。


存货持有成本是做市商持有不平衡头寸的风险补偿。波动率越高，存货风险越大，价差越宽。


interface SpreadDecomposition {
  totalSpread: number;
  adverseSelection: number;
  inventoryCost: number;
  orderProcessing: number;
}

const decomposeSpread = (
  trades: { price: number; midPriceBefore: number; midPriceAfter: number; side: 'buy' | 'sell' }[],
): SpreadDecomposition => {
  let totalEffectiveSpread = 0;
  let totalPriceImpact = 0;
  let totalRealizedSpread = 0;

  for (const trade of trades) {
    const direction = trade.side === 'buy' ? 1 : -1;
    const effectiveSpread = 2 * direction * (trade.price - trade.midPriceBefore);
    const priceImpact = 2 * direction * (trade.midPriceAfter - trade.midPriceBefore);
    const realizedSpread = effectiveSpread - priceImpact;

    totalEffectiveSpread += effectiveSpread;
    totalPriceImpact += priceImpact;
    totalRealizedSpread += realizedSpread;
  }

  const n = trades.length;
  const avgEffective = totalEffectiveSpread / n;
  const avgPriceImpact = totalPriceImpact / n;
  const avgRealized = totalRealizedSpread / n;

  return {
    totalSpread: avgEffective,
    adverseSelection: avgPriceImpact,
    inventoryCost: avgRealized * 0.6,
    orderProcessing: avgRealized * 0.4,
  };
};

const calculateEffectiveSpread = (tradePrice: number, midPrice: number, side: 'buy' | 'sell'): number => {
  const direction = side === 'buy' ? 1 : -1;
  return 2 * direction * (tradePrice - midPrice);
};

流动性度量与预测
流动性是多维概念，没有单一指标能完全捕捉。常用的流动性度量包括价差类指标、深度类指标、影响类指标和活跃度类指标。


interface LiquidityMetrics {
  quotedSpread: number;
  effectiveSpread: number;
  amihudIlliquidity: number;
  kyleLambda: number;
  depth5Level: number;
  turnoverRate: number;
  resiliency: number;
}

const calculateAmihudIlliquidity = (dailyReturns: number[], dailyVolumes: number[]): number => {
  const n = dailyReturns.length;
  let sumRatio = 0;
  let count = 0;

  for (let i = 0; i < n; i++) {
    if (dailyVolumes[i] > 0) {
      sumRatio += Math.abs(dailyReturns[i]) / dailyVolumes[i];
      count++;
    }
  }

  return count > 0 ? sumRatio / count : Infinity;
};

const estimateKyleLambda = (priceChanges: number[], signedVolumes: number[]): number => {
  const n = priceChanges.length;
  const meanX = signedVolumes.reduce((a, b) => a + b, 0) / n;
  const meanY = priceChanges.reduce((a, b) => a + b, 0) / n;

  let numerator = 0;
  let denominator = 0;
  for (let i = 0; i < n; i++) {
    numerator += (signedVolumes[i] - meanX) * (priceChanges[i] - meanY);
    denominator += (signedVolumes[i] - meanX) ** 2;
  }

  return denominator > 0 ? numerator / denominator : 0;
};

const calculateResiliency = (prices: number[], impactIndex: number, recoveryWindow: number): number => {
  const impactPrice = prices[impactIndex];
  const preImpactPrice = prices[Math.max(0, impactIndex - 1)];
  const impact = Math.abs(impactPrice - preImpactPrice);

  if (impact === 0) return 1;

  const endIndex = Math.min(impactIndex + recoveryWindow, prices.length - 1);
  const recoveryPrice = prices[endIndex];
  const recovery = Math.abs(recoveryPrice - preImpactPrice);

  return 1 - recovery / impact;
};
Kyle Lambda度量单位成交量对价格的永久性冲击，Lambda 越大意味着信息不对称越严重，交易大单的隐性成本越高。


市场弹性（Resiliency）度量价格在受到冲击后恢复到冲击前水平的速度和程度。高弹性市场适合大单执行，因为临时性价格冲击会快速消散。


小结
    

  • 市场微观结构研究交易机制如何影响价格形成，是执行策略设计的理论基础
    • 

  • 订单簿不平衡是短期价格预测的有效信号，可用于优化限价单定位
    • 

  • 买卖价差由逆向选择、存货持有和订单处理三部分构成，逆向选择通常占比最大
    • 

  • Kyle Lambda 度量信息驱动的永久性价格冲击，是估算大单隐性成本的关键指标
    • 

  • 流动性是多维概念，需要综合价差、深度、冲击和弹性等多个维度评估
    • 

  • 微观结构知识帮助量化交易者选择最优执行时机和策略，降低隐性交易成本
