执行算法

核心概念

执行算法（Execution Algorithm）是将大额订单拆分为小单并在一段时间内按特定规则逐步执行的自动化程序。执行算法的目标是在最小化市场冲击的同时完成全部交易量，同时控制执行偏差和时机风险。

不同的执行算法针对不同的优化目标。TWAP 追求时间均匀执行，VWAP 追求与市场成交量同步，Implementation Shortfall（IS）追求总执行成本最小化。选择哪种算法取决于订单特征、市场环境和交易者的风险偏好。

TWAP 算法实现
TWAP（Time-Weighted Average Price）是最基础的执行算法，将总量均匀分配到每个时间切片中执行。虽然简单，但在缺乏可靠成交量预测的市场中，TWAP 是一个稳健的选择。


增强版 TWAP 在基本均匀分配的基础上引入随机化和自适应机制，降低被其他交易者识别和利用的风险。


interface TWAPConfig {
  totalQuantity: number;
  startTime: number;
  endTime: number;
  numSlices: number;
  randomizePct: number;
  minSliceSize: number;
  maxParticipation: number;
}

interface SliceOrder {
  sliceId: number;
  targetTime: number;
  quantity: number;
  executed: number;
  status: 'pending' | 'active' | 'done' | 'cancelled';
}

const generateTWAPSchedule = (config: TWAPConfig): SliceOrder[] => {
  const sliceDuration = (config.endTime - config.startTime) / config.numSlices;
  const baseQuantity = Math.floor(config.totalQuantity / config.numSlices);
  let remainder = config.totalQuantity - baseQuantity * config.numSlices;

  const slices: SliceOrder[] = [];
  for (let i = 0; i < config.numSlices; i++) {
    let quantity = baseQuantity + (remainder > 0 ? 1 : 0);
    if (remainder > 0) remainder--;

    const randomFactor = 1 + (Math.random() - 0.5) * 2 * config.randomizePct;
    quantity = Math.max(config.minSliceSize, Math.round(quantity * randomFactor));

    slices.push({
      sliceId: i,
      targetTime: config.startTime + i * sliceDuration,
      quantity,
      executed: 0,
      status: 'pending',
    });
  }

  const totalScheduled = slices.reduce((s, sl) => s + sl.quantity, 0);
  if (totalScheduled !== config.totalQuantity) {
    slices[slices.length - 1].quantity += config.totalQuantity - totalScheduled;
  }

  return slices;
};

const executeTWAPSlice = (slice: SliceOrder, currentVolume: number, maxParticipation: number): number => {
  const maxAllowed = Math.floor(currentVolume * maxParticipation);
  const remaining = slice.quantity - slice.executed;
  return Math.min(remaining, maxAllowed);
};
VWAP 算法实现
VWAP（Volume-Weighted Average Price）算法追踪市场的成交量分布模式，在成交量高的时段执行更多份额。其关键输入是成交量预测曲线，预测质量直接决定了 VWAP 偏差的大小。


interface VWAPConfig {
  totalQuantity: number;
  startTime: number;
  endTime: number;
  numBuckets: number;
  volumeProfile: number[];
  maxParticipation: number;
  adaptiveMode: boolean;
}

interface VWAPSchedule {
  buckets: VWAPBucket[];
  totalPlanned: number;
}

interface VWAPBucket {
  bucketId: number;
  startTime: number;
  endTime: number;
  targetQuantity: number;
  executedQuantity: number;
  expectedVolumePct: number;
  actualVolume: number;
}

const generateVWAPSchedule = (config: VWAPConfig): VWAPSchedule => {
  const totalProfileVolume = config.volumeProfile.reduce((a, b) => a + b, 0);
  const bucketDuration = (config.endTime - config.startTime) / config.numBuckets;

  const buckets: VWAPBucket[] = config.volumeProfile.map((vol, i) => {
    const volumePct = vol / totalProfileVolume;
    return {
      bucketId: i,
      startTime: config.startTime + i * bucketDuration,
      endTime: config.startTime + (i + 1) * bucketDuration,
      targetQuantity: Math.round(config.totalQuantity * volumePct),
      executedQuantity: 0,
      expectedVolumePct: volumePct,
      actualVolume: 0,
    };
  });

  const totalPlanned = buckets.reduce((s, b) => s + b.targetQuantity, 0);
  if (totalPlanned !== config.totalQuantity) {
    buckets[buckets.length - 1].targetQuantity += config.totalQuantity - totalPlanned;
  }

  return { buckets, totalPlanned: config.totalQuantity };
};

const adaptVWAPTarget = (
  bucket: VWAPBucket,
  actualMarketVolume: number,
  totalRemaining: number,
  bucketsRemaining: number,
): number => {
  if (actualMarketVolume === 0) return bucket.targetQuantity;

  const volumeRatio = actualMarketVolume / (bucket.actualVolume || actualMarketVolume);
  const adjustedTarget = Math.round(bucket.targetQuantity * volumeRatio);
  const maxCatchup = Math.floor(totalRemaining / Math.max(1, bucketsRemaining));

  return Math.min(adjustedTarget, maxCatchup);
};

const calculateVWAPDeviation = (
  schedule: VWAPSchedule,
  marketVWAP: number,
  executionVWAP: number,
): { deviationBps: number; isOverperform: boolean } => {
  const deviation = (executionVWAP - marketVWAP) / marketVWAP;
  return {
    deviationBps: deviation * 10000,
    isOverperform: deviation < 0,
  };
};
Implementation Shortfall 算法
IS（Implementation Shortfall）算法是最智能的执行算法，其目标是最小化决策价格与最终执行价格之间的总差异。它在市场冲击和时机风险之间动态寻找最优平衡。


IS 算法的核心思想来自 Almgren-Chriss 最优执行理论：风险厌恶高的交易者前重后轻（快速执行），风险厌恶低的交易者前轻后重（缓慢执行）。


interface ISConfig {
  totalQuantity: number;
  urgency: 'low' | 'medium' | 'high' | 'critical';
  riskAversion: number;
  volatility: number;
  adv: number;
  numSlots: number;
  adaptiveParams: {
    priceThresholdBps: number;
    volumeThresholdPct: number;
    rebalanceFrequency: number;
  };
}

const urgencyToRiskAversion: Record<string, number> = {
  low: 0.01,
  medium: 0.1,
  high: 1.0,
  critical: 10.0,
};

const generateISSchedule = (config: ISConfig): number[] => {
  const lambda = config.riskAversion || urgencyToRiskAversion[config.urgency];
  const eta = config.volatility * 0.1;
  const kappa = Math.sqrt((lambda * config.volatility ** 2) / eta);

  const schedule: number[] = [];
  for (let k = 0; k < config.numSlots; k++) {
    const t = k / config.numSlots;
    const remaining = Math.sinh(kappa * (1 - t)) / Math.sinh(kappa);
    const nextRemaining = Math.sinh(kappa * (1 - (k + 1) / config.numSlots)) / Math.sinh(kappa);
    const sliceQty = Math.round(config.totalQuantity * (remaining - nextRemaining));
    schedule.push(Math.max(0, sliceQty));
  }

  const total = schedule.reduce((a, b) => a + b, 0);
  if (total !== config.totalQuantity) {
    schedule[schedule.length - 1] += config.totalQuantity - total;
  }

  return schedule;
};

const adaptISSchedule = (
  originalSchedule: number[],
  currentSlot: number,
  executed: number[],
  currentPrice: number,
  arrivalPrice: number,
  config: ISConfig,
): number => {
  const totalExecuted = executed.reduce((a, b) => a + b, 0);
  const totalPlanned = originalSchedule.slice(0, currentSlot + 1).reduce((a, b) => a + b, 0);
  const behindSchedule = totalPlanned - totalExecuted;

  const shortfall = (currentPrice - arrivalPrice) / arrivalPrice;
  const shortfallBps = shortfall * 10000;

  let urgencyMultiplier = 1.0;
  if (Math.abs(shortfallBps) > config.adaptiveParams.priceThresholdBps) {
    urgencyMultiplier = shortfall > 0 ? 1.8 : 0.4;
  }

  const baseTarget = originalSchedule[currentSlot] + behindSchedule * 0.3;
  return Math.max(0, Math.round(baseTarget * urgencyMultiplier));
};
小结
    

  • TWAP 时间均匀执行，简单稳健，适合缺乏量预测的场景
    • 

  • VWAP 追踪市场成交量分布，需要准确的量预测曲线作为输入
    • 

  • IS 算法基于 Almgren-Chriss 理论在冲击和时机风险间动态优化
    • 

  • 自适应执行机制根据实时价格偏差和成交量调整交易节奏
    • 

  • 算法选择需要综合考虑订单规模、紧急程度、市场流动性和执行基准
    • 

  • 执行算法的效果应通过 TCA 定期评估并持续迭代优化
