滚动前推分析

核心概念

滚动前推分析（Walk-Forward Analysis, WFA）是最接近真实投资流程的策略验证方法。它将整个历史数据划分为多个连续的"训练-交易"窗口对，在每个训练窗口内优化策略参数，然后在紧接的交易窗口内用优化后的参数进行模拟交易。最终将所有交易窗口的结果拼接起来形成完整的样本外绩效。

WFA 模拟了实际投资中"定期重新训练模型"的流程，每个交易窗口的结果都是真正的样本外结果，不存在前视偏差。它是验证策略泛化能力的黄金标准。

滚动窗口引擎实现
实现一个健壮的 WFA 引擎需要处理窗口划分、参数优化、结果收集和绩效拼接四个核心环节。关键是确保训练窗口和交易窗口之间有足够的 Purge Gap 来消除数据泄露。


interface WFAConfig {
  trainLength: number;
  testLength: number;
  stepSize: number;
  purgeGap: number;
  optimizationMethod: 'grid' | 'bayesian' | 'genetic';
  objectiveMetric: 'sharpe' | 'sortino' | 'calmar';
}

interface WFAWindow {
  windowId: number;
  trainStart: number;
  trainEnd: number;
  testStart: number;
  testEnd: number;
  optimizedParams: Record<string, number>;
  trainMetrics: PerformanceMetrics;
  testMetrics: PerformanceMetrics;
}

interface PerformanceMetrics {
  sharpe: number;
  sortino: number;
  calmar: number;
  totalReturn: number;
  maxDrawdown: number;
  winRate: number;
}

interface WFAResult {
  windows: WFAWindow[];
  aggregatedTestReturns: number[];
  overallMetrics: PerformanceMetrics;
  wfeRatio: number;
  consistencyScore: number;
}

const generateWindows = (
  totalDays: number,
  config: WFAConfig,
): { trainRange: [number, number]; testRange: [number, number] }[] => {
  const windows: { trainRange: [number, number]; testRange: [number, number] }[] = [];
  let start = 0;

  while (start + config.trainLength + config.purgeGap + config.testLength <= totalDays) {
    const trainStart = start;
    const trainEnd = start + config.trainLength;
    const testStart = trainEnd + config.purgeGap;
    const testEnd = testStart + config.testLength;

    windows.push({
      trainRange: [trainStart, trainEnd],
      testRange: [testStart, testEnd],
    });

    start += config.stepSize;
  }

  return windows;
};

type StrategyFactory = (params: Record<string, number>) => {
  backtest: (data: number[]) => PerformanceMetrics;
};

const runWFA = (
  data: number[],
  config: WFAConfig,
  strategyFactory: StrategyFactory,
  paramGrid: Record<string, number[]>,
): WFAResult => {
  const windowDefs = generateWindows(data.length, config);
  const windows: WFAWindow[] = [];
  const allTestReturns: number[] = [];

  for (let i = 0; i < windowDefs.length; i++) {
    const { trainRange, testRange } = windowDefs[i];
    const trainData = data.slice(trainRange[0], trainRange[1]);
    const testData = data.slice(testRange[0], testRange[1]);

    const optimized = gridOptimize(trainData, strategyFactory, paramGrid, config.objectiveMetric);

    const strategy = strategyFactory(optimized.params);
    const trainMetrics = strategy.backtest(trainData);
    const testMetrics = strategy.backtest(testData);

    const testReturns = testData.slice(1).map((v, j) => v / testData[j] - 1);
    allTestReturns.push(...testReturns);

    windows.push({
      windowId: i,
      trainStart: trainRange[0],
      trainEnd: trainRange[1],
      testStart: testRange[0],
      testEnd: testRange[1],
      optimizedParams: optimized.params,
      trainMetrics,
      testMetrics,
    });
  }

  const wfeRatio = calculateWFE(windows, config.objectiveMetric);
  const consistencyScore = calculateConsistency(windows);

  return {
    windows,
    aggregatedTestReturns: allTestReturns,
    overallMetrics: aggregateMetrics(windows),
    wfeRatio,
    consistencyScore,
  };
};

const gridOptimize = (
  data: number[],
  factory: StrategyFactory,
  grid: Record<string, number[]>,
  metric: string,
): { params: Record<string, number>; score: number } => {
  const paramNames = Object.keys(grid);
  let bestScore = -Infinity;
  let bestParams: Record<string, number> = {};

  const combinations = cartesianProduct(paramNames.map((n) => grid[n]));
  for (const combo of combinations) {
    const params: Record<string, number> = {};
    paramNames.forEach((n, i) => {
      params[n] = combo[i];
    });
    const result = factory(params).backtest(data);
    const score = result[metric as keyof PerformanceMetrics] as number;
    if (score > bestScore) {
      bestScore = score;
      bestParams = params;
    }
  }
  return { params: bestParams, score: bestScore };
};

const cartesianProduct = (arrays: number[][]): number[][] => {
  return arrays.reduce<number[][]>((acc, arr) => acc.flatMap((combo) => arr.map((val) => [...combo, val])), [[]]);
};
Walk-Forward Efficiency
Walk-Forward Efficiency（WFE）是评估 WFA 结果质量的核心指标。它衡量样本外表现与样本内表现的比率——WFE 越高，说明策略的泛化能力越强。


WFE = 样本外绩效指标均值 / 样本内绩效指标均值


通常以夏普比率为度量。WFE 在50%以上被认为是可接受的，70%以上是优秀的。WFE 低于30%则强烈暗示策略存在过拟合。


const calculateWFE = (windows: WFAWindow[], metric: keyof PerformanceMetrics): number => {
  const inSampleAvg = windows.reduce((s, w) => s + (w.trainMetrics[metric] as number), 0) / windows.length;
  const outSampleAvg = windows.reduce((s, w) => s + (w.testMetrics[metric] as number), 0) / windows.length;
  return inSampleAvg > 0 ? outSampleAvg / inSampleAvg : 0;
};

const calculateConsistency = (windows: WFAWindow[]): number => {
  const profitableWindows = windows.filter((w) => w.testMetrics.totalReturn > 0).length;
  return profitableWindows / windows.length;
};

const aggregateMetrics = (windows: WFAWindow[]): PerformanceMetrics => {
  const n = windows.length;
  return {
    sharpe: windows.reduce((s, w) => s + w.testMetrics.sharpe, 0) / n,
    sortino: windows.reduce((s, w) => s + w.testMetrics.sortino, 0) / n,
    calmar: windows.reduce((s, w) => s + w.testMetrics.calmar, 0) / n,
    totalReturn: windows.reduce((s, w) => s + w.testMetrics.totalReturn, 0),
    maxDrawdown: Math.max(...windows.map((w) => w.testMetrics.maxDrawdown)),
    winRate: windows.reduce((s, w) => s + w.testMetrics.winRate, 0) / n,
  };
};
锚定窗口与扩展窗口
除了标准的滚动窗口（固定长度训练窗口），WFA 还有两种变体：锚定窗口和扩展窗口。它们在数据利用效率和适应性之间提供不同的权衡。


锚定窗口：训练起点固定在数据开始，随着时间推移训练窗口不断扩大。优点是充分利用所有历史数据，缺点是远期数据的权重可能过大。


扩展窗口带衰减：类似锚定窗口，但对远期数据施加指数衰减权重，使模型更偏向近期市场状态。

type WindowType = 'rolling' | 'anchored' | 'expanding_decay';

const generateAdaptiveWindows = (
  totalDays: number,
  baseTrainLength: number,
  testLength: number,
  windowType: WindowType,
  decayFactor = 0.995,
): { trainRange: [number, number]; testRange: [number, number]; weights?: number[] }[] => {
  const windows: { trainRange: [number, number]; testRange: [number, number]; weights?: number[] }[] = [];
  const purge = 10;

  if (windowType === 'rolling') {
    let pos = 0;
    while (pos + baseTrainLength + purge + testLength <= totalDays) {
      windows.push({
        trainRange: [pos, pos + baseTrainLength],
        testRange: [pos + baseTrainLength + purge, pos + baseTrainLength + purge + testLength],
      });
      pos += testLength;
    }
  } else if (windowType === 'anchored') {
    let pos = baseTrainLength;
    while (pos + purge + testLength <= totalDays) {
      windows.push({
        trainRange: [0, pos],
        testRange: [pos + purge, pos + purge + testLength],
      });
      pos += testLength;
    }
  } else if (windowType === 'expanding_decay') {
    let pos = baseTrainLength;
    while (pos + purge + testLength <= totalDays) {
      const trainLen = pos;
      const weights = Array.from({ length: trainLen }, (_, i) => decayFactor ** (trainLen - i - 1));
      windows.push({
        trainRange: [0, pos],
        testRange: [pos + purge, pos + purge + testLength],
        weights,
      });
      pos += testLength;
    }
  }

  return windows;
};
小结
    

  • 滚动前推分析是验证策略泛化能力的黄金标准，每个交易窗口都是真正的样本外
    • 

  • WFA 引擎需要处理窗口划分、Purge Gap、参数优化和结果拼接
    • 

  • Walk-Forward Efficiency 衡量样本外与样本内表现的比率，WFE>50% 为可接受
    • 

  • 一致性评分（盈利窗口比例）反映策略在不同市场环境下的稳健性
    • 

  • 滚动窗口适应性最强，锚定窗口数据利用率最高，扩展衰减窗口兼顾两者
    • 

  • WFA 结果应与多重检验校正和参数稳定性分析结合使用，形成完整的验证体系
