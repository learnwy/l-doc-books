绩效评估指标

核心概念

绩效评估指标是衡量量化策略表现的定量工具。一个好的策略不仅要有高收益，更要在风险调整后的维度上表现优异。单一指标无法全面描述策略特征，需要构建多维度的评估体系来综合判断策略质量。

绩效评估分为收益类指标、风险类指标、风险调整收益指标和交易效率指标四大类。不同类型的策略应侧重不同的评估维度——高频策略更关注夏普比率和最大回撤，长周期策略更关注年化收益和回撤恢复时间。

收益率计算与年化
收益率的计算看似简单，但在涉及资金进出、杠杆调整和基准比较时存在诸多细节。正确的收益率计算是所有后续分析的基础。


简单收益率适用于单期分析，对数收益率在数学上更便于处理（可加性），时间加权收益率排除了资金流的影响，是基金业绩比较的标准。


interface ReturnMetrics {
  totalReturn: number;
  annualizedReturn: number;
  logReturn: number;
  excessReturn: number;
  dailyReturns: number[];
  monthlyReturns: number[];
}

const calculateReturns = (equityCurve: number[], riskFreeRate = 0.03): ReturnMetrics => {
  const n = equityCurve.length;
  const totalReturn = equityCurve[n - 1] / equityCurve[0] - 1;
  const tradingDays = n - 1;
  const years = tradingDays / 252;
  const annualizedReturn = (1 + totalReturn) ** (1 / years) - 1;
  const logReturn = Math.log(equityCurve[n - 1] / equityCurve[0]);

  const dailyReturns = equityCurve.slice(1).map((v, i) => v / equityCurve[i] - 1);

  const monthlyEquity: number[] = [];
  for (let i = 0; i < n; i += 21) {
    monthlyEquity.push(equityCurve[Math.min(i, n - 1)]);
  }
  monthlyEquity.push(equityCurve[n - 1]);
  const monthlyReturns = monthlyEquity.slice(1).map((v, i) => v / monthlyEquity[i] - 1);

  return {
    totalReturn,
    annualizedReturn,
    logReturn,
    excessReturn: annualizedReturn - riskFreeRate,
    dailyReturns,
    monthlyReturns,
  };
};

const timeWeightedReturn = (periods: { startNav: number; endNav: number; cashFlow: number }[]): number => {
  return (
    periods.reduce((cumReturn, p) => {
      const periodReturn = (p.endNav - p.cashFlow) / p.startNav - 1;
      return cumReturn * (1 + periodReturn);
    }, 1) - 1
  );
};
夏普比率与变体指标
夏普比率是量化交易中使用最广泛的风险调整收益指标，衡量每承受一单位风险所获得的超额收益。但标准夏普比率存在不区分上行和下行波动、假设收益正态分布等局限，因此衍生出多种变体。


索提诺比率只惩罚下行波动，对偏态收益分布更合理。卡尔玛比率使用最大回撤替代波动率作为风险度量，更直观地反映投资者承受的最坏情况。Omega比率考虑了收益分布的全部信息，不仅限于前两阶矩。


interface RiskAdjustedMetrics {
  sharpeRatio: number;
  sortinoRatio: number;
  calmarRatio: number;
  omegaRatio: number;
  informationRatio: number;
  treynorRatio: number;
}

const calculateSharpe = (returns: number[], riskFreeRate = 0.03, periodsPerYear = 252): number => {
  const excessReturns = returns.map((r) => r - riskFreeRate / periodsPerYear);
  const mean = excessReturns.reduce((a, b) => a + b, 0) / excessReturns.length;
  const std = Math.sqrt(excessReturns.reduce((a, b) => a + (b - mean) ** 2, 0) / excessReturns.length);
  return std > 0 ? (mean / std) * Math.sqrt(periodsPerYear) : 0;
};

const calculateSortino = (returns: number[], riskFreeRate = 0.03, periodsPerYear = 252): number => {
  const excessReturns = returns.map((r) => r - riskFreeRate / periodsPerYear);
  const mean = excessReturns.reduce((a, b) => a + b, 0) / excessReturns.length;
  const downside = excessReturns.filter((r) => r < 0);
  const downsideStd = Math.sqrt(downside.reduce((a, b) => a + b ** 2, 0) / returns.length);
  return downsideStd > 0 ? (mean / downsideStd) * Math.sqrt(periodsPerYear) : 0;
};

const calculateCalmar = (annualizedReturn: number, maxDrawdown: number): number => {
  return maxDrawdown > 0 ? annualizedReturn / maxDrawdown : 0;
};

const calculateOmega = (returns: number[], threshold = 0): number => {
  const gains = returns.filter((r) => r > threshold).reduce((a, b) => a + (b - threshold), 0);
  const losses = returns.filter((r) => r <= threshold).reduce((a, b) => a + (threshold - b), 0);
  return losses > 0 ? gains / losses : Infinity;
};

const calculateInformationRatio = (returns: number[], benchmarkReturns: number[], periodsPerYear = 252): number => {
  const activeReturns = returns.map((r, i) => r - benchmarkReturns[i]);
  const mean = activeReturns.reduce((a, b) => a + b, 0) / activeReturns.length;
  const te = Math.sqrt(activeReturns.reduce((a, b) => a + (b - mean) ** 2, 0) / activeReturns.length);
  return te > 0 ? (mean / te) * Math.sqrt(periodsPerYear) : 0;
};

回撤分析
回撤是投资者最直观感受到的风险度量。最大回撤衡量策略在任意时间窗口内从峰值到谷值的最大跌幅，回撤恢复时间衡量从谷值回到前期高点所需的时间。


interface DrawdownAnalysis {
  maxDrawdown: number;
  maxDrawdownStart: number;
  maxDrawdownEnd: number;
  maxDrawdownDuration: number;
  recoveryTime: number | null;
  averageDrawdown: number;
  drawdownPeriods: DrawdownPeriod[];
}

interface DrawdownPeriod {
  peakIndex: number;
  troughIndex: number;
  recoveryIndex: number | null;
  depth: number;
  duration: number;
  recoveryDuration: number | null;
}

const analyzeDrawdowns = (equityCurve: number[]): DrawdownAnalysis => {
  const n = equityCurve.length;
  let peak = equityCurve[0];
  let maxDD = 0;
  let maxDDStart = 0;
  let maxDDEnd = 0;
  let currentPeakIdx = 0;

  const drawdowns: number[] = [];
  const periods: DrawdownPeriod[] = [];
  let inDrawdown = false;
  let currentPeriod: Partial<DrawdownPeriod> = {};

  for (let i = 0; i < n; i++) {
    if (equityCurve[i] > peak) {
      peak = equityCurve[i];
      currentPeakIdx = i;
      if (inDrawdown) {
        currentPeriod.recoveryIndex = i;
        currentPeriod.recoveryDuration = i - (currentPeriod.troughIndex ?? 0);
        periods.push(currentPeriod as DrawdownPeriod);
        inDrawdown = false;
      }
    }

    const dd = (peak - equityCurve[i]) / peak;
    drawdowns.push(dd);

    if (dd > 0 && !inDrawdown) {
      inDrawdown = true;
      currentPeriod = { peakIndex: currentPeakIdx, depth: dd, troughIndex: i, duration: 0 };
    }

    if (inDrawdown && dd > (currentPeriod.depth ?? 0)) {
      currentPeriod.depth = dd;
      currentPeriod.troughIndex = i;
    }
    if (inDrawdown) {
      currentPeriod.duration = i - currentPeakIdx;
    }

    if (dd > maxDD) {
      maxDD = dd;
      maxDDStart = currentPeakIdx;
      maxDDEnd = i;
    }
  }

  return {
    maxDrawdown: maxDD,
    maxDrawdownStart: maxDDStart,
    maxDrawdownEnd: maxDDEnd,
    maxDrawdownDuration: maxDDEnd - maxDDStart,
    recoveryTime: null,
    averageDrawdown: drawdowns.reduce((a, b) => a + b, 0) / drawdowns.length,
    drawdownPeriods: periods,
  };
};
VaR 与 CVaR 尾部风险度量
Value at Risk（VaR）和 Conditional VaR（CVaR）是度量策略尾部风险的标准指标。VaR 回答"在给定置信水平下，最大可能损失是多少"，CVaR 进一步回答"一旦损失超过 VaR，平均损失是多少"。


CVaR（又称 Expected Shortfall）比 VaR 更能反映极端风险，因为它考虑了尾部损失的严重程度，而不仅是发生概率。


interface TailRiskMetrics {
  var95: number;
  var99: number;
  cvar95: number;
  cvar99: number;
  skewness: number;
  kurtosis: number;
  tailRatio: number;
}

const calculateVaR = (returns: number[], confidence: number): number => {
  const sorted = [...returns].sort((a, b) => a - b);
  const index = Math.floor(sorted.length * (1 - confidence));
  return -sorted[index];
};

const calculateCVaR = (returns: number[], confidence: number): number => {
  const sorted = [...returns].sort((a, b) => a - b);
  const cutoff = Math.floor(sorted.length * (1 - confidence));
  const tail = sorted.slice(0, cutoff);
  return tail.length > 0 ? -(tail.reduce((a, b) => a + b, 0) / tail.length) : 0;
};

const calculateSkewness = (returns: number[]): number => {
  const n = returns.length;
  const mean = returns.reduce((a, b) => a + b, 0) / n;
  const std = Math.sqrt(returns.reduce((a, b) => a + (b - mean) ** 2, 0) / n);
  if (std === 0) return 0;
  return (n / ((n - 1) * (n - 2))) * returns.reduce((a, b) => a + ((b - mean) / std) ** 3, 0);
};

const calculateKurtosis = (returns: number[]): number => {
  const n = returns.length;
  const mean = returns.reduce((a, b) => a + b, 0) / n;
  const std = Math.sqrt(returns.reduce((a, b) => a + (b - mean) ** 2, 0) / n);
  if (std === 0) return 0;
  const m4 = returns.reduce((a, b) => a + ((b - mean) / std) ** 4, 0) / n;
  return m4 - 3;
};

const computeTailRisk = (returns: number[]): TailRiskMetrics => ({
  var95: calculateVaR(returns, 0.95),
  var99: calculateVaR(returns, 0.99),
  cvar95: calculateCVaR(returns, 0.95),
  cvar99: calculateCVaR(returns, 0.99),
  skewness: calculateSkewness(returns),
  kurtosis: calculateKurtosis(returns),
  tailRatio: calculateVaR(returns, 0.95) > 0 ? calculateCVaR(returns, 0.95) / calculateVaR(returns, 0.95) : 0,
});
小结
    

  • 绩效评估需要构建收益、风险、风险调整和交易效率四大维度的指标体系
    • 

  • 夏普比率是最通用的风险调整指标，但索提诺比率和卡尔玛比率在特定场景更合理
    • 

  • 回撤分析直观反映投资者体验，最大回撤和恢复时间是策略可行性的关键判据
    • 

  • CVaR 比 VaR 更全面地度量尾部风险，是机构风控的标准指标
    • 

  • 偏度和峰度揭示收益分布的非正态特征，高峰度意味着极端事件概率高于正态假设
    • 

  • 单一指标无法全面评估策略，应综合多维度指标做出决策
    •
