仓位管理

核心概念

仓位管理是量化交易风险控制的第一道防线，决定了每笔交易投入多少资金、每个头寸占组合的比例。好的仓位管理能在保持收益潜力的同时有效控制回撤，差的仓位管理即使配合优秀的信号也可能导致破产。

仓位管理的核心权衡是：仓位过大导致回撤过深甚至爆仓，仓位过小导致资金利用率低、收益不足以覆盖交易成本。凯利公式提供了理论最优仓位，但实践中需要大幅折扣以应对模型误差和黑天鹅事件。

波动率调整仓位
波动率调整仓位的核心思想是让每个头寸贡献相近的风险。高波动资产分配较小仓位，低波动资产分配较大仓位，使组合的风险分布更加均匀。


ATR 仓位法是趋势跟踪策略中最常用的方法。使用平均真实波幅（Average True Range）衡量资产波动性，根据目标风险金额反推仓位大小。


interface VolatilityPosition {
  symbol: string;
  price: number;
  volatility: number;
  position: number;
  dollarRisk: number;
  percentOfCapital: number;
}

interface ATRPositionConfig {
  totalCapital: number;
  riskPerTrade: number;
  atrMultiplier: number;
  maxPositionPct: number;
  maxTotalExposure: number;
}

const calculateATR = (highs: number[], lows: number[], closes: number[], period: number): number => {
  const trueRanges: number[] = [];
  for (let i = 1; i < highs.length; i++) {
    const tr = Math.max(highs[i] - lows[i], Math.abs(highs[i] - closes[i - 1]), Math.abs(lows[i] - closes[i - 1]));
    trueRanges.push(tr);
  }
  const recent = trueRanges.slice(-period);
  return recent.reduce((a, b) => a + b, 0) / recent.length;
};

const atrPositionSizing = (
  symbol: string,
  price: number,
  atr: number,
  config: ATRPositionConfig,
): VolatilityPosition => {
  const dollarRisk = config.totalCapital * config.riskPerTrade;
  const stopDistance = atr * config.atrMultiplier;
  const shares = Math.floor(dollarRisk / stopDistance);
  const positionValue = shares * price;
  const pctOfCapital = positionValue / config.totalCapital;

  const adjustedShares =
    pctOfCapital > config.maxPositionPct ? Math.floor((config.totalCapital * config.maxPositionPct) / price) : shares;

  return {
    symbol,
    price,
    volatility: atr / price,
    position: adjustedShares,
    dollarRisk: adjustedShares * stopDistance,
    percentOfCapital: (adjustedShares * price) / config.totalCapital,
  };
};

const volatilityInverseWeighting = (
  assets: { symbol: string; price: number; volatility: number }[],
  totalCapital: number,
  maxSinglePct: number,
): VolatilityPosition[] => {
  const invVols = assets.map((a) => 1 / (a.volatility || 0.01));
  const totalInvVol = invVols.reduce((a, b) => a + b, 0);

  return assets.map((asset, i) => {
    const rawWeight = invVols[i] / totalInvVol;
    const weight = Math.min(rawWeight, maxSinglePct);
    const positionValue = totalCapital * weight;
    const shares = Math.floor(positionValue / asset.price);

    return {
      symbol: asset.symbol,
      price: asset.price,
      volatility: asset.volatility,
      position: shares,
      dollarRisk: shares * asset.price * asset.volatility,
      percentOfCapital: weight,
    };
  });
};
凯利公式与实战调整
凯利公式（Kelly Criterion）计算最大化长期资本增长率的最优下注比例。对于单一交易策略，凯利比例 = (胜率 × 赔率 - 败率) / 赔率。


在量化交易中，凯利公式常推广到连续收益分布的形式：f* = μ / σ²，其中 μ 是超额收益均值，σ² 是收益方差。


interface KellyResult {
  fullKelly: number;
  halfKelly: number;
  quarterKelly: number;
  expectedGrowth: number;
  ruinProbability: number;
}

const kellyDiscrete = (winRate: number, avgWin: number, avgLoss: number): KellyResult => {
  const lossRate = 1 - winRate;
  const odds = avgWin / Math.abs(avgLoss);
  const fullKelly = (winRate * odds - lossRate) / odds;

  const clampedKelly = Math.max(0, Math.min(1, fullKelly));
  const expectedGrowth = winRate * Math.log(1 + clampedKelly * odds) + lossRate * Math.log(1 - clampedKelly);

  return {
    fullKelly: clampedKelly,
    halfKelly: clampedKelly / 2,
    quarterKelly: clampedKelly / 4,
    expectedGrowth,
    ruinProbability: lossRate > 0 ? (lossRate / winRate) ** 10 : 0,
  };
};

const kellyContinuous = (returns: number[], riskFreeRate: number): KellyResult => {
  const mean = returns.reduce((a, b) => a + b, 0) / returns.length;
  const excessMean = mean - riskFreeRate / 252;
  const variance = returns.reduce((a, b) => a + (b - mean) ** 2, 0) / returns.length;

  const fullKelly = variance > 0 ? excessMean / variance : 0;
  const clampedKelly = Math.max(0, Math.min(2, fullKelly));

  return {
    fullKelly: clampedKelly,
    halfKelly: clampedKelly / 2,
    quarterKelly: clampedKelly / 4,
    expectedGrowth: excessMean * clampedKelly - 0.5 * variance * clampedKelly ** 2,
    ruinProbability: Math.exp((-2 * excessMean) / (variance || 1)),
  };
};
实战中使用半凯利或四分之一凯利是行业共识。原因是：凯利公式对参数估计极度敏感，实际的胜率和赔率估计误差可能导致全凯利仓位过大。半凯利牺牲约25%的期望增长率，但大幅降低回撤和破产概率。


动态仓位调整
静态仓位管理不能适应市场环境的变化。动态仓位管理根据当前市场状态、组合风险水平和策略信号强度实时调整仓位大小。


interface DynamicSizingConfig {
  baseSize: number;
  minSize: number;
  maxSize: number;
  volatilityScaling: boolean;
  drawdownScaling: boolean;
  signalScaling: boolean;
  regimeAware: boolean;
}

interface MarketState {
  currentVolatility: number;
  historicVolatility: number;
  currentDrawdown: number;
  maxAllowedDrawdown: number;
  signalStrength: number;
  regime: 'bull' | 'bear' | 'neutral' | 'crisis';
}

const calculateDynamicPosition = (config: DynamicSizingConfig, state: MarketState): number => {
  let size = config.baseSize;

  if (config.volatilityScaling) {
    const volRatio = state.historicVolatility / (state.currentVolatility || state.historicVolatility);
    size *= Math.min(2.0, Math.max(0.25, volRatio));
  }

  if (config.drawdownScaling) {
    const ddRatio = state.currentDrawdown / state.maxAllowedDrawdown;
    if (ddRatio > 0.5) {
      size *= 1 - (ddRatio - 0.5) * 2;
    }
  }

  if (config.signalScaling) {
    size *= Math.min(1.5, Math.max(0.5, state.signalStrength));
  }

  if (config.regimeAware) {
    const regimeMultiplier: Record<string, number> = {
      bull: 1.2,
      neutral: 1.0,
      bear: 0.7,
      crisis: 0.3,
    };
    size *= regimeMultiplier[state.regime];
  }

  return Math.max(config.minSize, Math.min(config.maxSize, size));
};
小结
    

  • 仓位管理是风险控制的第一道防线，决定了策略的风险收益特征
    • 

  • 波动率调整仓位法让每个头寸贡献相近的风险，是专业级策略的标准实践
    • 

  • ATR 仓位法在 CTA 和趋势策略中广泛使用，通过止损距离反推仓位大小
    • 

  • 凯利公式提供理论最优增长率，但实战中应使用半凯利以降低参数估计误差的影响
    • 

  • 动态仓位管理根据波动率、回撤和市场体制实时调整，提高策略适应性
    • 

  • 仓位上限和组合总敞口限制是防止极端损失的最后保障
    •
