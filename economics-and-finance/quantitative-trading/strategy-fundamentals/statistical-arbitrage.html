统计套利

核心概念

统计套利是一类基于统计关系而非经济学基本面的量化交易策略。它的核心思想是：当两个或多个资产之间的历史统计关系（如价格比率、价差、相关性）出现显著偏离时，建立对冲头寸等待关系回归，从中获取低风险收益。

统计套利与经典套利的关键区别在于：经典套利是无风险的（如同一资产在不同市场的价差），而统计套利基于历史统计规律，存在关系永久破裂的风险。统计套利的优势在于市场中性——策略收益与大盘涨跌的相关性很低。

协整检验与配对选择
配对交易的第一步是在大量资产中找到具有稳定统计关系的资产对。协整关系比简单相关性更可靠——高相关性的资产对可能只是同涨同跌，而协整意味着价差在长期中围绕均值波动。


Engle-Granger 两步法是最常用的协整检验方法。第一步对两个价格序列做线性回归得到残差序列，第二步对残差序列进行 ADF（Augmented Dickey-Fuller）单位根检验。如果残差是平稳的，则两个序列协整。


interface CointegrationResult {
  symbolA: string;
  symbolB: string;
  hedgeRatio: number;
  adfStatistic: number;
  pValue: number;
  halfLife: number;
  isCointegrated: boolean;
}

const linearRegression = (y: number[], x: number[]): { slope: number; intercept: number; residuals: number[] } => {
  const n = y.length;
  const meanX = x.reduce((a, b) => a + b, 0) / n;
  const meanY = y.reduce((a, b) => a + b, 0) / n;

  let ssXY = 0;
  let ssXX = 0;
  for (let i = 0; i < n; i++) {
    ssXY += (x[i] - meanX) * (y[i] - meanY);
    ssXX += (x[i] - meanX) ** 2;
  }

  const slope = ssXY / (ssXX || 1);
  const intercept = meanY - slope * meanX;
  const residuals = y.map((yi, i) => yi - slope * x[i] - intercept);

  return { slope, intercept, residuals };
};

const adfTest = (series: number[]): { statistic: number; pValue: number } => {
  const n = series.length;
  const dy = series.slice(1).map((v, i) => v - series[i]);
  const yLag = series.slice(0, -1);

  const reg = linearRegression(dy, yLag);
  const beta = reg.slope;

  const residuals = reg.residuals;
  const sse = residuals.reduce((a, b) => a + b ** 2, 0);
  const seBeta =
    Math.sqrt(sse / (n - 3)) / Math.sqrt(yLag.reduce((a, b) => a + (b - yLag.reduce((s, v) => s + v, 0) / n) ** 2, 0));

  const statistic = beta / (seBeta || 1);
  const criticalValues = { '1%': -3.43, '5%': -2.86, '10%': -2.57 };
  const pValue =
    statistic < criticalValues['1%']
      ? 0.01
      : statistic < criticalValues['5%']
        ? 0.05
        : statistic < criticalValues['10%']
          ? 0.1
          : 0.5;

  return { statistic, pValue };
};

const testCointegration = (
  pricesA: number[],
  pricesB: number[],
  symbolA: string,
  symbolB: string,
  significanceLevel = 0.05,
): CointegrationResult => {
  const reg = linearRegression(pricesA, pricesB);
  const adf = adfTest(reg.residuals);
  const halfLife = estimateHalfLife(reg.residuals);

  return {
    symbolA,
    symbolB,
    hedgeRatio: reg.slope,
    adfStatistic: adf.statistic,
    pValue: adf.pValue,
    halfLife,
    isCointegrated: adf.pValue <= significanceLevel,
  };
};

const estimateHalfLife = (residuals: number[]): number => {
  const dy = residuals.slice(1).map((v, i) => v - residuals[i]);
  const yLag = residuals.slice(0, -1);
  const reg = linearRegression(dy, yLag);
  return reg.slope < 0 ? -Math.log(2) / reg.slope : Infinity;
};
配对选择流程：首先按行业或业务相似性缩小候选范围，然后进行协整检验筛选，最后根据半衰期和信号频率排序选择最优配对。


配对交易执行引擎
配对交易的执行需要实时计算价差、生成信号、管理头寸和监控风险。一个生产级的配对交易引擎需要处理分红除权、停牌、涨跌停等市场特殊情况。


interface PairPosition {
  symbolA: string;
  symbolB: string;
  hedgeRatio: number;
  sharesA: number;
  sharesB: number;
  entrySpread: number;
  currentSpread: number;
  pnl: number;
  status: 'flat' | 'long_spread' | 'short_spread';
}

interface PairTradingEngine {
  pairs: PairPosition[];
  config: PairTradingConfig;
  update(prices: Map<string, number>): TradeSignal[];
}

interface PairTradingConfig {
  entryZScore: number;
  exitZScore: number;
  stopLossZScore: number;
  lookbackWindow: number;
  maxHoldingDays: number;
  maxPairs: number;
  capitalPerPair: number;
}

interface TradeSignal {
  symbolA: string;
  symbolB: string;
  action: 'open_long' | 'open_short' | 'close' | 'stop_loss';
  sharesA: number;
  sharesB: number;
  reason: string;
}

const generatePairSignals = (
  spreadHistory: number[],
  config: PairTradingConfig,
  currentPosition: PairPosition,
): TradeSignal | null => {
  const window = spreadHistory.slice(-config.lookbackWindow);
  const mean = window.reduce((a, b) => a + b, 0) / window.length;
  const std = Math.sqrt(window.reduce((a, b) => a + (b - mean) ** 2, 0) / window.length);
  const zScore = std > 0 ? (spreadHistory[spreadHistory.length - 1] - mean) / std : 0;

  if (currentPosition.status === 'flat') {
    if (zScore < -config.entryZScore) {
      return {
        symbolA: currentPosition.symbolA,
        symbolB: currentPosition.symbolB,
        action: 'open_long',
        sharesA: Math.floor(config.capitalPerPair / 2),
        sharesB: Math.floor((config.capitalPerPair / 2) * currentPosition.hedgeRatio),
        reason: `价差 Z-Score ${zScore.toFixed(2)} 低于 -${config.entryZScore}`,
      };
    }
    if (zScore > config.entryZScore) {
      return {
        symbolA: currentPosition.symbolA,
        symbolB: currentPosition.symbolB,
        action: 'open_short',
        sharesA: Math.floor(config.capitalPerPair / 2),
        sharesB: Math.floor((config.capitalPerPair / 2) * currentPosition.hedgeRatio),
        reason: `价差 Z-Score ${zScore.toFixed(2)} 高于 ${config.entryZScore}`,
      };
    }
  }

  if (currentPosition.status !== 'flat') {
    if (Math.abs(zScore) < config.exitZScore) {
      return {
        symbolA: currentPosition.symbolA,
        symbolB: currentPosition.symbolB,
        action: 'close',
        sharesA: 0,
        sharesB: 0,
        reason: '价差回归至出场阈值',
      };
    }
    if (Math.abs(zScore) > config.stopLossZScore) {
      return {
        symbolA: currentPosition.symbolA,
        symbolB: currentPosition.symbolB,
        action: 'stop_loss',
        sharesA: 0,
        sharesB: 0,
        reason: `止损触发 Z-Score ${zScore.toFixed(2)}`,
      };
    }
  }

  return null;
};
多资产篮子套利
当配对交易扩展到多个资产时，就形成了篮子套利策略。篮子套利通过主成分分析（PCA）或统计因子模型识别多个资产之间的共同定价因子，然后交易残差部分。


PCA 方法将资产收益率矩阵分解为主成分，前几个主成分代表系统性因子（市场、行业等），剩余部分为特质收益。当特质收益偏离过大时建立均值回归头寸。


interface BasketArbitrage {
  symbols: string[];
  weights: number[];
  basketValue: number;
  residual: number;
  signal: number;
}

const calculateBasketResidual = (
  returns: number[][],
  numFactors: number,
): { residuals: number[][]; factorLoadings: number[][] } => {
  const n = returns.length;
  const m = returns[0].length;

  const means = returns.map((r) => r.reduce((a, b) => a + b, 0) / m);
  const centered = returns.map((r, i) => r.map((v) => v - means[i]));

  const covMatrix: number[][] = Array.from({ length: n }, (_, i) =>
    Array.from({ length: n }, (_, j) => centered[i].reduce((s, _, k) => s + centered[i][k] * centered[j][k], 0) / m),
  );

  const eigenPairs = powerIteration(covMatrix, numFactors);
  const factorLoadings = eigenPairs.vectors;

  const residuals = centered.map((row, i) => {
    return row.map((_, t) => {
      let factorContrib = 0;
      for (let f = 0; f < numFactors; f++) {
        const factorReturn = centered.reduce((s, r, j) => s + factorLoadings[f][j] * r[t], 0);
        factorContrib += factorLoadings[f][i] * factorReturn;
      }
      return centered[i][t] - factorContrib;
    });
  });

  return { residuals, factorLoadings };
};

const powerIteration = (matrix: number[][], numVectors: number): { values: number[]; vectors: number[][] } => {
  const n = matrix.length;
  const vectors: number[][] = [];
  const values: number[] = [];

  for (let v = 0; v < numVectors; v++) {
    let vec = Array.from({ length: n }, () => Math.random());
    for (let iter = 0; iter < 100; iter++) {
      const newVec = matrix.map((row) => row.reduce((s, val, j) => s + val * vec[j], 0));
      const norm = Math.sqrt(newVec.reduce((s, v) => s + v ** 2, 0));
      vec = newVec.map((v) => v / (norm || 1));
    }
    const eigenValue = vec.reduce((s, vi, i) => s + vi * matrix[i].reduce((ss, mij, j) => ss + mij * vec[j], 0), 0);
    values.push(eigenValue);
    vectors.push(vec);
  }

  return { values, vectors };
};
篮子套利的优势在于分散化——单个配对可能因特殊事件失效，但一篮子配对的整体表现更为稳定。机构级的统计套利策略通常同时运行数百个配对。


小结
    

  • 统计套利基于资产间的统计关系建立对冲头寸，追求市场中性的稳定收益
    • 

  • 协整检验通过 Engle-Granger 两步法识别长期均衡关系，比简单相关性更可靠
    • 

  • 配对交易引擎需要实时计算价差 Z-Score，结合入场、出场和止损阈值管理头寸
    • 

  • 半衰期是均值回归速度的关键度量，影响策略的资金效率和信号频率
    • 

  • 篮子套利通过 PCA 将配对交易扩展到多资产，提高分散化水平
    • 

  • 统计关系可能永久破裂，严格的止损机制和持仓时间限制是必要的风险防线
