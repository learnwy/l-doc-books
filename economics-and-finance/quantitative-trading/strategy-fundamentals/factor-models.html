因子模型

核心概念

因子模型是量化投资的理论基石，它将资产收益率分解为若干系统性因子的线性组合加上特质收益。因子模型的核心思想是：资产的超额收益可以被少数几个共同驱动因素所解释，投资者只需要为承担系统性风险获得补偿。

从 CAPM 的单因子模型到 Fama-French 三因子、五因子模型，再到 Barra 多因子风险模型，因子模型不断演进。在量化交易中，因子不仅用于解释收益来源，更用于构建 Alpha 信号、管理组合风险和进行绩效归因。

因子构建与计算
因子构建是将原始数据转化为可用于投资决策的标准化信号的过程。一个完整的因子构建流程包括原始指标计算、异常值处理、标准化、中性化等步骤。


原始指标计算：从基础数据出发计算因子原始值。例如，价值因子使用市净率倒数（B/P），动量因子使用过去12个月收益率（跳过最近1个月）。


interface FactorDefinition {
  name: string;
  category: 'value' | 'momentum' | 'quality' | 'size' | 'volatility' | 'liquidity';
  calculate: (data: StockData) => number;
  higherIsBetter: boolean;
}

interface StockData {
  symbol: string;
  prices: number[];
  marketCap: number;
  bookValue: number;
  earnings: number;

  totalAssets: number;

}

异常值处理与标准化：因子原始值可能存在极端值，需要进行 MAD（中位数绝对偏差）去极值和 Z-Score 标准化，使不同因子具有可比性。


const madWinsorize = (values: number[], multiplier = 5.2): number[] => {
  const median = getMedian(values);
  const mad = getMedian(values.map((v) => Math.abs(v - median)));
  const lower = median - multiplier * mad;
  const upper = median + multiplier * mad;
  return values.map((v) => Math.max(lower, Math.min(upper, v)));
};

const zScoreNormalize = (values: number[]): number[] => {
  const mean = values.reduce((a, b) => a + b, 0) / values.length;
  const std = Math.sqrt(values.reduce((a, b) => a + (b - mean) ** 2, 0) / values.length);
  if (std === 0) return values.map(() => 0);
  return values.map((v) => (v - mean) / std);
};

const getMedian = (arr: number[]): number => {
  const sorted = [...arr].sort((a, b) => a - b);
  const mid = Math.floor(sorted.length / 2);
  return sorted.length % 2 ? sorted[mid] : (sorted[mid - 1] + sorted[mid]) / 2;
};
因子中性化与正交化
因子中性化是消除因子间不必要相关性的关键步骤。未经中性化的因子可能暗含行业偏露或市值偏露，导致策略实际承担的风险与预期不符。


行业中性化：在每个行业内部对因子值进行去均值处理，消除因子与行业的相关性。例如，银行股普遍低市净率，如果不做行业中性化，价值因子会天然偏向金融行业。


市值中性化：通过回归方法去除因子与市值的线性关系。小市值股票在很多因子上天然得分较高，市值中性化确保因子信号不是简单的市值效应。


interface NeutralizationConfig {
  industryNeutral: boolean;
  sizeNeutral: boolean;
  industries: Map<string, string>;
  marketCaps: Map<string, number>;
}

const neutralizeByIndustry = (
  factorValues: Map<string, number>,
  industries: Map<string, string>,
): Map<string, number> => {
  const byIndustry = new Map<string, { symbol: string; value: number }[]>();

  for (const [symbol, value] of factorValues) {
    const industry = industries.get(symbol) ?? 'unknown';
    const group = byIndustry.get(industry) ?? [];
    group.push({ symbol, value });
    byIndustry.set(industry, group);
  }

  const result = new Map<string, number>();
  for (const [, stocks] of byIndustry) {
    const mean = stocks.reduce((a, b) => a + b.value, 0) / stocks.length;
    for (const stock of stocks) {
      result.set(stock.symbol, stock.value - mean);
    }
  }
  return result;
};
多因子组合构建
单个因子的预测能力有限，多因子组合通过综合多个低相关的 Alpha 信号来提高策略的稳定性和风险调整后收益。因子组合的方法主要包括等权加权、IC 加权和优化加权三种。


等权加权是最简单的方法，对每个因子赋予相同权重。虽然简单，但在因子间相关性较低时表现稳健，且不容易过拟合。


IC 加权根据因子的信息系数（IC）动态调整权重。IC 衡量因子预测收益率的能力，历史 IC 越高的因子获得越大权重。


interface FactorWeight {
  factorName: string;
  weight: number;
  icMean: number;
  icIR: number;
}

const calculateIC = (factorScores: number[], forwardReturns: number[]): number => {
  const n = factorScores.length;
  const rankFactor = rankArray(factorScores);
  const rankReturn = rankArray(forwardReturns);

  const meanRankF = (n + 1) / 2;
  const meanRankR = (n + 1) / 2;

  let numerator = 0;
  let denomF = 0;
  let denomR = 0;
  for (let i = 0; i < n; i++) {
    numerator += (rankFactor[i] - meanRankF) * (rankReturn[i] - meanRankR);
    denomF += (rankFactor[i] - meanRankF) ** 2;
    denomR += (rankReturn[i] - meanRankR) ** 2;
  }
  return numerator / Math.sqrt(denomF * denomR);
};

const icWeighting = (factors: FactorWeight[]): FactorWeight[] => {
  const totalIC = factors.reduce((s, f) => s + Math.abs(f.icMean), 0);
  return factors.map((f) => ({
    ...f,
    weight: totalIC > 0 ? Math.abs(f.icMean) / totalIC : 1 / factors.length,
  }));
};

const rankArray = (arr: number[]): number[] => {
  const indexed = arr.map((v, i) => ({ v, i }));
  indexed.sort((a, b) => a.v - b.v);
  const ranks = new Array<number>(arr.length);
  for (let i = 0; i < indexed.length; i++) {
    ranks[indexed[i].i] = i + 1;
  }
  return ranks;
};

因子衰减与生命周期管理
因子并非永久有效。随着市场环境变化和策略拥挤，因子的超额收益会逐渐衰减。理解因子的生命周期并建立因子监控体系是维持策略竞争力的关键。


因子拥挤度：当越来越多的资金追逐同一因子时，因子的预期收益会下降，回撤风险会增加。监控因子拥挤度可以提前预警因子失效。


因子衰减信号：IC 持续下降、因子换手率异常升高、因子多空组合价差收窄都是因子衰减的信号。


interface FactorHealthMetrics {
  factorName: string;
  rollingIC: number[];
  icDecayRate: number;
  crowdingScore: number;
  turnover: number;
  longShortSpread: number;
}

const detectFactorDecay = (
  metrics: FactorHealthMetrics,
): {
  isDecaying: boolean;
  severity: 'low' | 'medium' | 'high';
  signals: string[];
} => {
  const signals: string[] = [];
  const recentIC = metrics.rollingIC.slice(-12);
  const olderIC = metrics.rollingIC.slice(-24, -12);

  const recentMean = recentIC.reduce((a, b) => a + b, 0) / recentIC.length;
  const olderMean = olderIC.reduce((a, b) => a + b, 0) / olderIC.length;

  if (recentMean < olderMean * 0.5) signals.push('IC 近期均值大幅下降');
  if (metrics.crowdingScore > 0.7) signals.push('因子拥挤度过高');
  if (metrics.turnover > 0.5) signals.push('因子换手率异常');
  if (metrics.longShortSpread < 0.01) signals.push('多空价差收窄');

  const severity = signals.length >= 3 ? 'high' : signals.length >= 2 ? 'medium' : 'low';
  return { isDecaying: signals.length >= 2, severity, signals };
};
建立定期的因子健康检查机制，包括月度 IC 报告、季度因子衰减分析和年度因子库重建，是机构级量化系统的标准实践。


小结
    

  • 因子模型将资产收益分解为系统性因子暴露和特质收益，是量化投资的理论基础
    • 

  • 因子构建流程包括原始计算、MAD 去极值、中性化和 Z-Score 标准化
    • 

  • 行业中性化和市值中性化消除因子中隐含的非预期风险暴露
    • 

  • 多因子组合通过等权、IC 加权等方法综合多个低相关信号提升策略稳定性
    • 

  • 因子存在生命周期，IC 衰减、拥挤度上升和多空价差收窄是衰减的预警信号
    • 

  • 建立因子健康监控体系是维持策略长期有效性的关键实践
