动量与均值回归

核心概念

动量和均值回归是量化交易中最重要的两类价格行为模式。动量效应认为过去表现强势的资产在短期内倾向于继续强势，而均值回归则认为偏离均衡价格的资产终将回归。这两种看似矛盾的现象在不同时间尺度和市场环境下交替主导。

动量效应的经济学解释包括投资者反应不足（信息缓慢扩散）和行为偏差（锚定效应、确认偏差）。均值回归的理论基础则来自市场效率假说——价格偏离基本面终将被套利力量纠正。

时间序列动量
时间序列动量（Time-Series Momentum, TSMOM）关注单个资产自身的历史表现。如果资产在过去一段时间内上涨，则做多；如果下跌，则做空。这是 CTA（商品交易顾问）策略的核心逻辑。


时间序列动量的信号构建通常基于不同回看窗口的收益率，然后通过波动率调整使不同资产的信号具有可比性。


interface TSMOMSignal {
  symbol: string;
  lookbackDays: number;
  rawReturn: number;
  volatility: number;
  scaledSignal: number;
  position: number;
}

const calculateTSMOM = (prices: number[], lookback: number, volWindow: number, targetVol: number): TSMOMSignal => {
  const returns = prices.slice(1).map((p, i) => Math.log(p / prices[i]));
  const rawReturn = returns.slice(-lookback).reduce((a, b) => a + b, 0);

  const recentReturns = returns.slice(-volWindow);
  const volatility = Math.sqrt((recentReturns.reduce((a, b) => a + b ** 2, 0) / volWindow) * 252);

  const scaledSignal = rawReturn / (volatility || 1);
  const position = Math.sign(scaledSignal) * Math.min(Math.abs(scaledSignal), 2) * (targetVol / (volatility || 1));

  return {
    symbol: '',
    lookbackDays: lookback,
    rawReturn,
    volatility,
    scaledSignal,
    position: Math.max(-2, Math.min(2, position)),
  };
};

const multiScaleTSMOM = (prices: number[], lookbacks: number[], volWindow: number, targetVol: number): number => {
  const signals = lookbacks.map((lb) => calculateTSMOM(prices, lb, volWindow, targetVol));
  return signals.reduce((s, sig) => s + sig.position, 0) / signals.length;
};
多尺度动量将不同回看窗口（如 20、60、120、252 天）的信号综合，可以捕捉不同时间频率的趋势，减少单一窗口的噪声影响。


截面动量
截面动量（Cross-Sectional Momentum）比较同一时间点上不同资产的相对表现。做多过去赢家组合，做空过去输家组合，捕捉资产间的相对强弱。


经典的截面动量策略使用 12-1 月动量（过去12个月收益扣除最近1个月），因为最近1个月存在短期反转效应。


interface CrossSectionalMomentum {
  universe: StockMomentum[];
  longPortfolio: string[];
  shortPortfolio: string[];
  quintileReturns: number[];
}

interface StockMomentum {
  symbol: string;
  return12m: number;
  return1m: number;
  momentum121: number;
  quintile: number;
}

const buildCrossSectionalMomentum = (
  stocks: { symbol: string; prices: number[] }[],
  topPct = 0.2,
  bottomPct = 0.2,
): CrossSectionalMomentum => {
  const scored: StockMomentum[] = stocks
    .filter((s) => s.prices.length >= 252)
    .map((s) => {
      const p = s.prices;
      const return12m = p[p.length - 22] / p[0] - 1;
      const return1m = p[p.length - 1] / p[p.length - 22] - 1;
      return {
        symbol: s.symbol,
        return12m,
        return1m,
        momentum121: return12m - return1m,
        quintile: 0,
      };
    })
    .sort((a, b) => a.momentum121 - b.momentum121);

  const n = scored.length;
  scored.forEach((s, i) => {
    s.quintile = Math.floor((i / n) * 5) + 1;
  });

  const longCutoff = Math.floor(n * (1 - topPct));
  const shortCutoff = Math.floor(n * bottomPct);

  return {
    universe: scored,
    longPortfolio: scored.slice(longCutoff).map((s) => s.symbol),
    shortPortfolio: scored.slice(0, shortCutoff).map((s) => s.symbol),
    quintileReturns: [1, 2, 3, 4, 5].map((q) => {
      const group = scored.filter((s) => s.quintile === q);
      return group.reduce((a, b) => a + b.momentum121, 0) / group.length;
    }),
  };
};
均值回归策略实现
均值回归策略的核心是识别价格偏离均衡水平的资产，并预期价格将回归。实现方式包括基于统计指标的简单均值回归和基于协整关系的配对交易。


布林带均值回归是最直观的实现方式，当价格触及布林带下轨时买入，触及上轨时卖出。但简单布林带策略忽略了趋势状态，在强趋势中容易亏损。


Z-Score 均值回归更为精确，通过计算价格（或价差）相对于历史均值的标准化偏离度来度量回归潜力。


interface MeanReversionSignal {
  symbol: string;
  zScore: number;
  halfLife: number;
  position: number;
  entryThreshold: number;
  exitThreshold: number;
}

const calculateZScore = (series: number[], window: number): number => {
  const recent = series.slice(-window);
  const mean = recent.reduce((a, b) => a + b, 0) / recent.length;
  const std = Math.sqrt(recent.reduce((a, b) => a + (b - mean) ** 2, 0) / recent.length);
  return std > 0 ? (series[series.length - 1] - mean) / std : 0;
};

const estimateHalfLife = (series: number[]): number => {
  const n = series.length;
  if (n < 30) return Infinity;

  const y = series.slice(1).map((v, i) => v - series[i]);
  const x = series.slice(0, -1);

  const meanX = x.reduce((a, b) => a + b, 0) / x.length;
  const meanY = y.reduce((a, b) => a + b, 0) / y.length;

  let numerator = 0;
  let denominator = 0;
  for (let i = 0; i < x.length; i++) {
    numerator += (x[i] - meanX) * (y[i] - meanY);
    denominator += (x[i] - meanX) ** 2;
  }

  const beta = numerator / (denominator || 1);
  return beta < 0 ? -Math.log(2) / beta : Infinity;
};

const meanReversionStrategy = (
  series: number[],
  window: number,
  entryZ: number,
  exitZ: number,
): MeanReversionSignal => {
  const zScore = calculateZScore(series, window);
  const halfLife = estimateHalfLife(series.slice(-window));

  let position = 0;
  if (zScore < -entryZ) position = 1;
  else if (zScore > entryZ) position = -1;
  else if (Math.abs(zScore) < exitZ) position = 0;

  return {
    symbol: '',
    zScore,
    halfLife,
    position,
    entryThreshold: entryZ,
    exitThreshold: exitZ,
  };
};
半衰期（Half-Life）是均值回归策略的关键参数，它衡量价格偏离回归到一半所需的时间。半衰期太长意味着资金占用成本高，太短则可能信号频率过高增加交易成本。


动量崩溃与回归陷阱
理解策略的尾部风险是实盘运营的关键。动量策略面临"动量崩溃"风险，均值回归策略面临"回归陷阱"风险。


动量崩溃发生在市场急剧反转时，过去的赢家突然变成输家，输家变成赢家。2009年3月的市场反弹就是典型案例，做空低动量股票的组合遭受了巨大损失。


回归陷阱发生在看似偏离均值的价格实际是基本面变化的反映。例如，一只股票因财务造假暴跌50%，此时买入并非均值回归，而是价值陷阱。

小结
    

  • 动量和均值回归是两种互补的价格行为模式，在不同时间尺度交替主导
    • 

  • 时间序列动量关注单资产趋势延续，截面动量比较资产间相对强弱
    • 

  • 均值回归策略通过 Z-Score 和半衰期量化回归潜力，控制入场出场时机
    • 

  • 多尺度信号综合可以降低单一参数依赖，提高策略稳健性
    • 

  • 动量崩溃和回归陷阱是两类策略的核心尾部风险，需要止损和基本面筛选作为防御
    • 

  • 实盘中通常将动量和均值回归策略组合使用，利用它们的负相关性降低组合波动
    •
