随机过程

核心概念

随机过程是金融数学的理论根基，为资产价格的随机演化提供严格的数学描述。从最简单的随机游走到复杂的跳跃扩散模型，随机过程理论赋予金融工程师一套精确的语言来描述不确定性、建立定价模型和推导风险度量。

布朗运动是连续时间随机过程的基石。在其基础上发展出的伊藤过程、几何布朗运动和跳跃扩散模型，分别解决了不同层次的金融建模需求。理解随机过程不仅是掌握衍生品定价的前提，也是深入理解风险管理和量化策略的必经之路。

布朗运动与维纳过程
标准布朗运动 WtW_tWt​ 是金融随机模型的原子构件，具有四个关键性质：W0=0W_0 = 0W0​=0；增量 Wt+s−WtW_{t+s} - W_tWt+s​−Wt​ 服从 N(0,s)N(0, s)N(0,s)；不重叠的增量相互独立；路径几乎处处连续但处处不可微。


"处处连续但处处不可微"意味着价格路径是连续的（没有缺口），但在任何时刻都没有确定的变化方向——这与我们观察到的金融市场行为高度一致。


interface BrownianPath {
  times: number[];
  values: number[];
  maxValue: number;
  minValue: number;
  finalValue: number;
}

const boxMullerNormal = (): number => {
  const u1 = Math.random();
  const u2 = Math.random();
  return Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
};

const simulateBrownianMotion = (T: number, steps: number): BrownianPath => {
  const dt = T / steps;
  const sqrtDt = Math.sqrt(dt);
  const times: number[] = [0];
  const values: number[] = [0];

  let maxVal = 0;
  let minVal = 0;

  for (let i = 1; i <= steps; i++) {
    const dW = sqrtDt * boxMullerNormal();
    const newValue = values[values.length - 1] + dW;
    times.push(i * dt);
    values.push(newValue);
    maxVal = Math.max(maxVal, newValue);
    minVal = Math.min(minVal, newValue);
  }

  return {
    times,
    values,
    maxValue: maxVal,
    minValue: minVal,
    finalValue: values[values.length - 1],
  };
};

const verifyBrownianProperties = (numPaths: number, T: number, steps: number): void => {
  const finalValues: number[] = [];

  for (let i = 0; i < numPaths; i++) {
    const path = simulateBrownianMotion(T, steps);
    finalValues.push(path.finalValue);
  }

  const mean = finalValues.reduce((s, v) => s + v, 0) / numPaths;
  const variance = finalValues.reduce((s, v) => s + (v - mean) ** 2, 0) / (numPaths - 1);

  console.log(`布朗运动验证 (T=${T}, N=${numPaths}):`);
  console.log(`  E[W_T] = ${mean.toFixed(4)} (理论值: 0)`);
  console.log(`  Var[W_T] = ${variance.toFixed(4)} (理论值: ${T})`);
};

verifyBrownianProperties(10000, 1.0, 252);

const samplePath = simulateBrownianMotion(1.0, 252);
console.log(
  `样本路径: 最大=${samplePath.maxValue.toFixed(3)}, 最小=${samplePath.minValue.toFixed(3)}, 终值=${samplePath.finalValue.toFixed(3)}`,
);
几何布朗运动与伊藤引理
几何布朗运动（GBM）是金融建模中使用最广泛的随机过程，其随机微分方程为：


dSt=μSt dt+σSt dWtdS_t = \mu S_t\,dt + \sigma S_t\,dW_tdSt​=μSt​dt+σSt​dWt​
应用伊藤引理对 ln⁡St\ln S_tlnSt​ 求导，可以得到解析解：


St=S0exp⁡[(μ−σ22)t+σWt]S_t = S_0 \exp\left[(\mu - \frac{\sigma^2}{2})t + \sigma W_t\right]St​=S0​exp[(μ−2σ2​)t+σWt​]
伊藤引理是随机微积分的链式法则，对于函数 f(S,t)f(S, t)f(S,t) 有：


df=∂f∂tdt+∂f∂SdS+12∂2f∂S2(dS)2df = \frac{\partial f}{\partial t}dt + \frac{\partial f}{\partial S}dS + \frac{1}{2}\frac{\partial^2 f}{\partial S^2}(dS)^2df=∂t∂f​dt+∂S∂f​dS+21​∂S2∂2f​(dS)2
关键的"二阶项" 12∂2f∂S2σ2S2dt\frac{1}{2}\frac{\partial^2 f}{\partial S^2}\sigma^2 S^2 dt21​∂S2∂2f​σ2S2dt 是伊藤引理区别于普通微积分的核心，也是 Black-Scholes 公式中 Gamma 项的来源。


interface GBMPath {
  times: number[];
  prices: number[];
  logReturns: number[];
}

const simulateGBM = (s0: number, mu: number, sigma: number, T: number, steps: number): GBMPath => {
  const dt = T / steps;
  const drift = (mu - 0.5 * sigma ** 2) * dt;
  const diffusion = sigma * Math.sqrt(dt);

  const times: number[] = [0];
  const prices: number[] = [s0];
  const logReturns: number[] = [];

  for (let i = 1; i <= steps; i++) {
    const z = boxMullerNormal();
    const logReturn = drift + diffusion * z;
    const newPrice = prices[prices.length - 1] * Math.exp(logReturn);

    times.push(i * dt);
    prices.push(newPrice);
    logReturns.push(logReturn);
  }

  return { times, prices, logReturns };
};

const verifyGBMProperties = (s0: number, mu: number, sigma: number, T: number, numPaths: number): void => {
  const finalPrices: number[] = [];

  for (let i = 0; i < numPaths; i++) {
    const path = simulateGBM(s0, mu, sigma, T, 252);
    finalPrices.push(path.prices[path.prices.length - 1]);
  }

  const meanPrice = finalPrices.reduce((s, p) => s + p, 0) / numPaths;
  const theoreticalMean = s0 * Math.exp(mu * T);

  const logPrices = finalPrices.map((p) => Math.log(p));
  const meanLog = logPrices.reduce((s, l) => s + l, 0) / numPaths;
  const theoreticalMeanLog = Math.log(s0) + (mu - 0.5 * sigma ** 2) * T;
  const varLog = logPrices.reduce((s, l) => s + (l - meanLog) ** 2, 0) / (numPaths - 1);
  const theoreticalVarLog = sigma ** 2 * T;

  console.log(`GBM 验证 (S0=${s0}, μ=${mu}, σ=${sigma}, T=${T}):`);
  console.log(`  E[S_T]: 模拟=${meanPrice.toFixed(2)}, 理论=${theoreticalMean.toFixed(2)}`);
  console.log(`  E[ln S_T]: 模拟=${meanLog.toFixed(4)}, 理论=${theoreticalMeanLog.toFixed(4)}`);
  console.log(`  Var[ln S_T]: 模拟=${varLog.toFixed(4)}, 理论=${theoreticalVarLog.toFixed(4)}`);
};

verifyGBMProperties(100, 0.08, 0.2, 1.0, 50000);
均值回复过程与利率模型
并非所有金融变量都适合用 GBM 建模。利率、波动率、信用利差等变量表现出均值回复特征——偏离长期均值越远，回归的力量越强。Ornstein-Uhlenbeck 过程是最经典的均值回复模型。


dXt=θ(μ−Xt)dt+σdWtdX_t = \theta(\mu - X_t)dt + \sigma dW_tdXt​=θ(μ−Xt​)dt+σdWt​
其中 θ\thetaθ 控制回归速度，μ\muμ 是长期均值，σ\sigmaσ 是波动率。


interface MeanRevertingPath {
  times: number[];
  values: number[];
  halfLife: number;
}

const simulateOU = (
  x0: number,
  theta: number,
  mu: number,
  sigma: number,
  T: number,
  steps: number,
): MeanRevertingPath => {
  const dt = T / steps;
  const times: number[] = [0];
  const values: number[] = [x0];

  for (let i = 1; i <= steps; i++) {
    const x = values[values.length - 1];
    const drift = theta * (mu - x) * dt;
    const diffusion = sigma * Math.sqrt(dt) * boxMullerNormal();
    values.push(x + drift + diffusion);
    times.push(i * dt);
  }

  return { times, values, halfLife: Math.log(2) / theta };
};

const vasicekBondPrice = (r0: number, theta: number, mu: number, sigma: number, T: number): number => {
  const B = (1 - Math.exp(-theta * T)) / theta;
  const A = Math.exp(((B - T) * (theta ** 2 * mu - sigma ** 2 / 2)) / theta ** 2 - (sigma ** 2 * B ** 2) / (4 * theta));
  return A * Math.exp(-B * r0);
};

const rateParams = { x0: 0.05, theta: 0.5, mu: 0.04, sigma: 0.01 };
const ratePath = simulateOU(rateParams.x0, rateParams.theta, rateParams.mu, rateParams.sigma, 5.0, 1260);

console.log(`OU 过程参数: θ=${rateParams.theta}, μ=${rateParams.mu}, σ=${rateParams.sigma}`);
console.log(`半衰期: ${ratePath.halfLife.toFixed(2)} 年`);
console.log(`初始利率: ${(rateParams.x0 * 100).toFixed(2)}%`);
console.log(`终值利率: ${(ratePath.values[ratePath.values.length - 1] * 100).toFixed(2)}%`);

const maturities = [0.5, 1, 2, 5, 10];
maturities.forEach((T) => {
  const price = vasicekBondPrice(rateParams.x0, rateParams.theta, rateParams.mu, rateParams.sigma, T);
  const ytm = -Math.log(price) / T;
  console.log(`${T}年期零息债券: 价格=${price.toFixed(4)}, 到期收益率=${(ytm * 100).toFixed(2)}%`);
});
跳跃扩散模型
GBM 假设价格路径是连续的，但现实中金融市场会因重大事件（盈利公告、政策变化、黑天鹅事件）而出现跳跃。Merton 跳跃扩散模型在 GBM 基础上叠加泊松跳跃过程：


dS=(μ−λk)S dt+σS dW+JS dNdS = (\mu - \lambda k)S\,dt + \sigma S\,dW + JS\,dNdS=(μ−λk)Sdt+σSdW+JSdN
其中 NtN_tNt​ 是强度为 λ\lambdaλ 的泊松过程，JJJ 是跳跃幅度（对数正态分布）。


interface JumpDiffusionParams {
  s0: number;
  mu: number;
  sigma: number;
  lambda: number;
  jumpMean: number;
  jumpVol: number;
  T: number;
  steps: number;
}

const simulateJumpDiffusion = (params: JumpDiffusionParams): number[] => {
  const { s0, mu, sigma, lambda, jumpMean, jumpVol, T, steps } = params;
  const dt = T / steps;
  const k = Math.exp(jumpMean + 0.5 * jumpVol ** 2) - 1;
  const drift = (mu - lambda * k - 0.5 * sigma ** 2) * dt;
  const diffusion = sigma * Math.sqrt(dt);

  const prices: number[] = [s0];

  for (let i = 0; i < steps; i++) {
    const z = boxMullerNormal();
    let logReturn = drift + diffusion * z;

    const numJumps = Math.random() < lambda * dt ? 1 : 0;
    if (numJumps > 0) {
      const jumpSize = jumpMean + jumpVol * boxMullerNormal();
      logReturn += jumpSize;
    }

    prices.push(prices[prices.length - 1] * Math.exp(logReturn));
  }

  return prices;
};

const jdParams: JumpDiffusionParams = {
  s0: 100,
  mu: 0.08,
  sigma: 0.15,
  lambda: 2,
  jumpMean: -0.02,
  jumpVol: 0.05,
  T: 1.0,
  steps: 252,
};

const numSims = 10000;
const gbmFinals: number[] = [];
const jdFinals: number[] = [];

for (let i = 0; i < numSims; i++) {
  const gbmPath = simulateGBM(100, 0.08, 0.15, 1.0, 252);
  gbmFinals.push(gbmPath.prices[gbmPath.prices.length - 1]);

  const jdPath = simulateJumpDiffusion(jdParams);
  jdFinals.push(jdPath[jdPath.length - 1]);
}

const stats = (arr: number[]) => {
  const mean = arr.reduce((s, v) => s + v, 0) / arr.length;
  const sorted = [...arr].sort((a, b) => a - b);
  const skewness =
    arr.reduce(
      (s, v) => s + ((v - mean) / Math.sqrt(arr.reduce((s2, v2) => s2 + (v2 - mean) ** 2, 0) / arr.length)) ** 3,
      0,
    ) / arr.length;
  return { mean, p5: sorted[Math.floor(arr.length * 0.05)], p95: sorted[Math.floor(arr.length * 0.95)], skewness };
};

const gbmStats = stats(gbmFinals);
const jdStats = stats(jdFinals);
console.log(
  `GBM:  均值=${gbmStats.mean.toFixed(2)}, 5%=${gbmStats.p5.toFixed(2)}, 95%=${gbmStats.p95.toFixed(2)}, 偏度=${gbmStats.skewness.toFixed(3)}`,
);
console.log(
  `跳扩: 均值=${jdStats.mean.toFixed(2)}, 5%=${jdStats.p5.toFixed(2)}, 95%=${jdStats.p95.toFixed(2)}, 偏度=${jdStats.skewness.toFixed(3)}`,
);
小结
    

  • 布朗运动是连续时间金融模型的基本构件，具有连续路径和独立正态增量
    • 

  • 几何布朗运动通过伊藤引理确保价格非负，是股票价格建模的标准模型
    • 

  • 伊藤引理中的二阶校正项是随机微积分区别于普通微积分的核心
    • 

  • 均值回复过程（OU/Vasicek）适合利率、波动率等具有长期均衡水平的变量
    • 

  • 跳跃扩散模型通过叠加泊松过程捕捉市场中的不连续事件
    • 

  • 选择哪种随机过程取决于标的资产的统计特征和建模目标
    •
