蒙特卡洛模拟

核心概念

蒙特卡洛模拟是一种基于随机抽样的数值计算方法，通过生成大量随机路径来估计金融模型的期望值和分布特征。当金融问题没有解析解（如路径依赖期权定价）或维度过高（如多资产组合风险评估）时，蒙特卡洛方法往往是唯一实用的计算工具。

该方法的核心思想来自大数定律：通过足够多次的随机模拟，样本均值将收敛到理论期望值。对程序员而言，蒙特卡洛模拟是最直觉化的数值方法——本质上就是"用代码做实验"。

随机数生成与路径模拟
蒙特卡洛模拟的基础是高质量的随机数生成。在金融应用中，最常用的是标准正态分布随机数，用于驱动几何布朗运动（GBM）路径模拟。


GBM 离散化公式为：St+Δt=St⋅exp⁡[(μ−σ22)Δt+σΔt⋅Z]S_{t+\Delta t} = S_t \cdot \exp\left[(\mu - \frac{\sigma^2}{2})\Delta t + \sigma\sqrt{\Delta t} \cdot Z\right]St+Δt​=St​⋅exp[(μ−2σ2​)Δt+σΔt​⋅Z]


其中 Z 是标准正态随机变量。


const boxMullerNormal = (): [number, number] => {
  const u1 = Math.random();
  const u2 = Math.random();
  const z0 = Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
  const z1 = Math.sqrt(-2 * Math.log(u1)) * Math.sin(2 * Math.PI * u2);
  return [z0, z1];
};

interface GBMParams {
  s0: number;
  mu: number;
  sigma: number;
  T: number;
  steps: number;
}

const simulateGBMPath = (params: GBMParams): number[] => {
  const { s0, mu, sigma, T, steps } = params;
  const dt = T / steps;
  const drift = (mu - 0.5 * sigma ** 2) * dt;
  const diffusion = sigma * Math.sqrt(dt);

  const path: number[] = [s0];
  for (let i = 0; i < steps; i++) {
    const [z] = boxMullerNormal();
    const nextPrice = path[path.length - 1] * Math.exp(drift + diffusion * z);
    path.push(nextPrice);
  }

  return path;
};

const simulateGBMPaths = (params: GBMParams, numPaths: number): number[][] => {
  return Array.from({ length: numPaths }, () => simulateGBMPath(params));
};

const params: GBMParams = { s0: 100, mu: 0.08, sigma: 0.2, T: 1.0, steps: 252 };
const paths = simulateGBMPaths(params, 10000);

const finalPrices = paths.map((p) => p[p.length - 1]);
const meanFinal = finalPrices.reduce((s, p) => s + p, 0) / finalPrices.length;
const theoretical = params.s0 * Math.exp(params.mu * params.T);

console.log(`模拟终值均值: ${meanFinal.toFixed(2)}`);
console.log(`理论终值均值: ${theoretical.toFixed(2)}`);
console.log(`误差: ${((Math.abs(meanFinal - theoretical) / theoretical) * 100).toFixed(3)}%`);
期权定价应用
蒙特卡洛方法在期权定价中的基本思路是：在风险中性测度下模拟大量标的资产价格路径，计算每条路径上的期权到期收益，然后取平均并折现。


对于欧式期权，蒙特卡洛结果可与 Black-Scholes 公式直接对比验证。对于亚式期权、障碍期权等路径依赖期权，蒙特卡洛往往是唯一实用的定价方法。


interface OptionPriceResult {
  price: number;
  standardError: number;
  confidenceInterval: [number, number];
  numPaths: number;
}

const mcEuropeanOption = (
  s0: number,
  strike: number,
  r: number,
  sigma: number,
  T: number,
  isCall: boolean,
  numPaths: number,
): OptionPriceResult => {
  const payoffs: number[] = [];
  const drift = (r - 0.5 * sigma ** 2) * T;
  const diffusion = sigma * Math.sqrt(T);

  for (let i = 0; i < numPaths; i++) {
    const [z] = boxMullerNormal();
    const sT = s0 * Math.exp(drift + diffusion * z);
    const payoff = isCall ? Math.max(sT - strike, 0) : Math.max(strike - sT, 0);
    payoffs.push(payoff);
  }

  const discountFactor = Math.exp(-r * T);
  const mean = payoffs.reduce((s, p) => s + p, 0) / numPaths;
  const price = discountFactor * mean;

  const variance = payoffs.reduce((s, p) => s + (p - mean) ** 2, 0) / (numPaths - 1);
  const standardError = discountFactor * Math.sqrt(variance / numPaths);

  return {
    price,
    standardError,
    confidenceInterval: [price - 1.96 * standardError, price + 1.96 * standardError],
    numPaths,
  };
};

const mcAsianOption = (
  s0: number,
  strike: number,
  r: number,
  sigma: number,
  T: number,
  steps: number,
  isCall: boolean,
  numPaths: number,
): OptionPriceResult => {
  const dt = T / steps;
  const drift = (r - 0.5 * sigma ** 2) * dt;
  const diffusion = sigma * Math.sqrt(dt);
  const payoffs: number[] = [];

  for (let p = 0; p < numPaths; p++) {
    let s = s0;
    let sumPrices = s;

    for (let t = 0; t < steps; t++) {
      const [z] = boxMullerNormal();
      s *= Math.exp(drift + diffusion * z);
      sumPrices += s;
    }

    const avgPrice = sumPrices / (steps + 1);
    const payoff = isCall ? Math.max(avgPrice - strike, 0) : Math.max(strike - avgPrice, 0);
    payoffs.push(payoff);
  }

  const discountFactor = Math.exp(-r * T);
  const mean = payoffs.reduce((s, p) => s + p, 0) / numPaths;
  const price = discountFactor * mean;
  const variance = payoffs.reduce((s, p) => s + (p - mean) ** 2, 0) / (numPaths - 1);
  const standardError = discountFactor * Math.sqrt(variance / numPaths);

  return {
    price,
    standardError,
    confidenceInterval: [price - 1.96 * standardError, price + 1.96 * standardError],
    numPaths,
  };
};

const euroCall = mcEuropeanOption(100, 100, 0.05, 0.2, 1.0, true, 100000);
const asianCall = mcAsianOption(100, 100, 0.05, 0.2, 1.0, 252, true, 100000);

console.log(`欧式看涨: ${euroCall.price.toFixed(4)} ± ${euroCall.standardError.toFixed(4)}`);
console.log(`亚式看涨: ${asianCall.price.toFixed(4)} ± ${asianCall.standardError.toFixed(4)}`);
方差缩减技术
蒙特卡洛方法的收敛速度为 O(1/N)O(1/\sqrt{N})O(1/N​)，要将精度提高一个数量级需要 100 倍的模拟路径。方差缩减技术通过减小样本方差来加速收敛，在不增加模拟次数的情况下提高精度。


const mcWithAntitheticVariates = (
  s0: number,
  strike: number,
  r: number,
  sigma: number,
  T: number,
  isCall: boolean,
  numPaths: number,
): OptionPriceResult => {
  const payoffs: number[] = [];
  const drift = (r - 0.5 * sigma ** 2) * T;
  const diffusion = sigma * Math.sqrt(T);

  for (let i = 0; i < numPaths / 2; i++) {
    const [z] = boxMullerNormal();

    const sT1 = s0 * Math.exp(drift + diffusion * z);
    const sT2 = s0 * Math.exp(drift + diffusion * -z);

    const payoff1 = isCall ? Math.max(sT1 - strike, 0) : Math.max(strike - sT1, 0);
    const payoff2 = isCall ? Math.max(sT2 - strike, 0) : Math.max(strike - sT2, 0);

    payoffs.push((payoff1 + payoff2) / 2);
  }

  const discountFactor = Math.exp(-r * T);
  const mean = payoffs.reduce((s, p) => s + p, 0) / payoffs.length;
  const price = discountFactor * mean;
  const variance = payoffs.reduce((s, p) => s + (p - mean) ** 2, 0) / (payoffs.length - 1);
  const standardError = discountFactor * Math.sqrt(variance / payoffs.length);

  return {
    price,
    standardError,
    confidenceInterval: [price - 1.96 * standardError, price + 1.96 * standardError],
    numPaths,
  };
};

const mcWithControlVariate = (
  s0: number,
  strike: number,
  r: number,
  sigma: number,
  T: number,
  isCall: boolean,
  numPaths: number,
): OptionPriceResult => {
  const drift = (r - 0.5 * sigma ** 2) * T;
  const diffusion = sigma * Math.sqrt(T);
  const theoreticalMean = s0 * Math.exp(r * T);

  const optionPayoffs: number[] = [];
  const stockPayoffs: number[] = [];

  for (let i = 0; i < numPaths; i++) {
    const [z] = boxMullerNormal();
    const sT = s0 * Math.exp(drift + diffusion * z);
    optionPayoffs.push(isCall ? Math.max(sT - strike, 0) : Math.max(strike - sT, 0));
    stockPayoffs.push(sT);
  }

  const meanOption = optionPayoffs.reduce((s, p) => s + p, 0) / numPaths;
  const meanStock = stockPayoffs.reduce((s, p) => s + p, 0) / numPaths;

  let covOS = 0,
    varS = 0;
  for (let i = 0; i < numPaths; i++) {
    covOS += (optionPayoffs[i] - meanOption) * (stockPayoffs[i] - meanStock);
    varS += (stockPayoffs[i] - meanStock) ** 2;
  }
  const beta = covOS / varS;

  const adjusted = optionPayoffs.map((p, i) => p - beta * (stockPayoffs[i] - theoreticalMean));

  const discountFactor = Math.exp(-r * T);
  const mean = adjusted.reduce((s, p) => s + p, 0) / numPaths;
  const price = discountFactor * mean;
  const variance = adjusted.reduce((s, p) => s + (p - mean) ** 2, 0) / (numPaths - 1);
  const standardError = discountFactor * Math.sqrt(variance / numPaths);

  return {
    price,
    standardError,
    confidenceInterval: [price - 1.96 * standardError, price + 1.96 * standardError],
    numPaths,
  };
};

const n = 50000;
const naive = mcEuropeanOption(100, 100, 0.05, 0.2, 1.0, true, n);
const antithetic = mcWithAntitheticVariates(100, 100, 0.05, 0.2, 1.0, true, n);
const controlled = mcWithControlVariate(100, 100, 0.05, 0.2, 1.0, true, n);

console.log(`朴素MC:     ${naive.price.toFixed(4)} (SE: ${naive.standardError.toFixed(4)})`);
console.log(`对偶变量:   ${antithetic.price.toFixed(4)} (SE: ${antithetic.standardError.toFixed(4)})`);
console.log(`控制变量:   ${controlled.price.toFixed(4)} (SE: ${controlled.standardError.toFixed(4)})`);
console.log(`方差缩减效率: ${(naive.standardError / controlled.standardError).toFixed(1)}x`);

小结
    

  • 蒙特卡洛方法通过大量随机模拟来估计期望值，是解决高维金融问题的通用工具
    • 

  • 几何布朗运动是金融蒙特卡洛的基础模型，通过离散化公式实现路径模拟
    • 

  • 路径依赖期权（亚式、障碍等）只能通过蒙特卡洛定价
    • 

  • 方差缩减技术能在不增加模拟次数的情况下显著提高精度
    • 

  • 对偶变量法和控制变量法是最实用的两种方差缩减技术
    • 

  • 蒙特卡洛方法的精度和计算量之间存在 O(1/N)O(1/\sqrt{N})O(1/N​) 的权衡
    •
