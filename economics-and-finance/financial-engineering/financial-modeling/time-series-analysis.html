时间序列分析

核心概念

时间序列分析是金融建模的基石，研究按时间顺序排列的数据点的统计特征和演变规律。金融市场中的价格、收益率、波动率、交易量等几乎所有数据都以时间序列的形式存在。掌握时间序列分析方法，意味着能从海量历史数据中提取模式、检验假设并构建预测模型。

对程序员而言，时间序列分析将统计理论转化为可直接运行的代码，每一个模型都是一段精确的算法实现。

平稳性检验与数据预处理
平稳性是大多数时间序列模型的前提条件。一个平稳序列的统计特征（均值、方差、自协方差）不随时间变化。金融价格序列通常是非平稳的（有趋势），但收益率序列通常是平稳的。


ADF（Augmented Dickey-Fuller）检验是最常用的平稳性检验方法，其零假设为"序列存在单位根（非平稳）"。


interface StationarityTest {
  isStationary: boolean;
  adfStatistic: number;
  criticalValue: number;
  pValue: number;
}

const calculateAutoCorrelation = (data: number[], lag: number): number => {
  const n = data.length;
  const mean = data.reduce((s, v) => s + v, 0) / n;
  let numerator = 0;
  let denominator = 0;

  for (let i = 0; i < n; i++) {
    denominator += (data[i] - mean) ** 2;
    if (i >= lag) {
      numerator += (data[i] - mean) * (data[i - lag] - mean);
    }
  }

  return numerator / denominator;
};

const simpleADFTest = (series: number[]): StationarityTest => {
  const diffs: number[] = [];
  const lagged: number[] = [];

  for (let i = 1; i < series.length; i++) {
    diffs.push(series[i] - series[i - 1]);
    lagged.push(series[i - 1]);
  }

  const n = diffs.length;
  const meanDiff = diffs.reduce((s, v) => s + v, 0) / n;
  const meanLag = lagged.reduce((s, v) => s + v, 0) / n;

  let covDL = 0,
    varL = 0;
  for (let i = 0; i < n; i++) {
    covDL += (diffs[i] - meanDiff) * (lagged[i] - meanLag);
    varL += (lagged[i] - meanLag) ** 2;
  }

  const gamma = covDL / varL;
  const residuals = diffs.map((d, i) => d - gamma * lagged[i]);
  const se = Math.sqrt(residuals.reduce((s, r) => s + r ** 2, 0) / (n - 1)) / Math.sqrt(varL);
  const tStat = gamma / se;

  return {
    isStationary: tStat < -2.86,
    adfStatistic: tStat,
    criticalValue: -2.86,
    pValue: tStat < -3.43 ? 0.01 : tStat < -2.86 ? 0.05 : 0.1,
  };
};

const prices = Array.from({ length: 252 }, (_, i) => 100 + i * 0.05 + Math.random() * 3);
const returns = prices.slice(1).map((p, i) => Math.log(p / prices[i]));

const priceTest = simpleADFTest(prices);
const returnTest = simpleADFTest(returns);

console.log(`价格序列 ADF: ${priceTest.adfStatistic.toFixed(3)} → ${priceTest.isStationary ? '平稳' : '非平稳'}`);
console.log(`收益率序列 ADF: ${returnTest.adfStatistic.toFixed(3)} → ${returnTest.isStationary ? '平稳' : '非平稳'}`);

const acf5 = calculateAutoCorrelation(returns, 5);
console.log(`收益率 ACF(5): ${acf5.toFixed(4)}`);
ARIMA 模型
ARIMA（p,d,q）模型是时间序列建模的经典框架，结合了自回归（AR）、差分（I）和移动平均（MA）三个组件。p 控制自回归阶数，d 控制差分次数，q 控制移动平均阶数。


AR(p) 模型假设当前值是过去 p 个值的线性组合：Xt=c+ϕ1Xt−1+ϕ2Xt−2+...+ϕpXt−p+ϵtX_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + ... + \phi_p X_{t-p} + \epsilon_tXt​=c+ϕ1​Xt−1​+ϕ2​Xt−2​+...+ϕp​Xt−p​+ϵt​


interface ARModel {
  coefficients: number[];
  intercept: number;
  residuals: number[];
}

const fitAR = (series: number[], order: number): ARModel => {
  const n = series.length;
  const mean = series.reduce((s, v) => s + v, 0) / n;
  const centered = series.map((v) => v - mean);

  const r: number[] = [];
  for (let lag = 0; lag <= order; lag++) {
    let sum = 0;
    for (let t = lag; t < n; t++) {
      sum += centered[t] * centered[t - lag];
    }
    r.push(sum / n);
  }

  const coefficients: number[] = [];
  if (order === 1) {
    coefficients.push(r[1] / r[0]);
  } else if (order === 2) {
    const denom = r[0] ** 2 - r[1] ** 2;
    coefficients.push((r[1] * r[0] - r[2] * r[1]) / denom);
    coefficients.push((r[2] * r[0] - r[1] ** 2) / denom);
  }

  const intercept = mean * (1 - coefficients.reduce((s, c) => s + c, 0));

  const residuals: number[] = [];
  for (let t = order; t < n; t++) {
    let predicted = intercept;
    for (let i = 0; i < order; i++) {
      predicted += coefficients[i] * series[t - 1 - i];
    }
    residuals.push(series[t] - predicted);
  }

  return { coefficients, intercept, residuals };
};

const forecastAR = (model: ARModel, recent: number[], steps: number): number[] => {
  const forecasts: number[] = [];
  const history = [...recent];

  for (let s = 0; s < steps; s++) {
    let pred = model.intercept;
    for (let i = 0; i < model.coefficients.length; i++) {
      pred += model.coefficients[i] * history[history.length - 1 - i];
    }
    forecasts.push(pred);
    history.push(pred);
  }

  return forecasts;
};

const logReturns = prices.slice(1).map((p, i) => Math.log(p / prices[i]));
const ar1 = fitAR(logReturns, 1);
const ar2 = fitAR(logReturns, 2);

console.log(`AR(1) 系数: φ₁=${ar1.coefficients[0].toFixed(4)}`);
console.log(`AR(2) 系数: φ₁=${ar2.coefficients[0]?.toFixed(4)}, φ₂=${ar2.coefficients[1]?.toFixed(4)}`);

const forecast = forecastAR(ar1, logReturns.slice(-5), 5);
console.log(`未来5天预测收益率: ${forecast.map((f) => (f * 100).toFixed(3) + '%').join(', ')}`);
GARCH 波动率建模
金融收益率的波动率具有两个重要的经验特征：波动率聚集（高波动之后往往跟随高波动）和均值回归（波动率最终会回到长期平均水平）。GARCH（广义自回归条件异方差）模型能同时捕捉这两个特征。


GARCH(1,1) 模型的条件方差方程为：σt2=ω+αϵt−12+βσt−12\sigma_t^2 = \omega + \alpha \epsilon_{t-1}^2 + \beta \sigma_{t-1}^2σt2​=ω+αϵt−12​+βσt−12​


其中 α\alphaα 衡量新信息对波动率的冲击，β\betaβ 衡量波动率的持续性，α+β<1\alpha + \beta < 1α+β<1 保证模型平稳。


interface GARCHModel {
  omega: number;
  alpha: number;
  beta: number;
  unconditionalVar: number;
  persistence: number;
}

interface GARCHResult {
  model: GARCHModel;
  conditionalVol: number[];
  logLikelihood: number;
}

const fitGARCH11 = (returns: number[]): GARCHResult => {
  const n = returns.length;
  const mean = returns.reduce((s, r) => s + r, 0) / n;
  const residuals = returns.map((r) => r - mean);
  const sampleVar = residuals.reduce((s, r) => s + r ** 2, 0) / n;

  const omega = sampleVar * 0.05;
  const alpha = 0.08;
  const beta = 0.88;

  const sigmaSquared: number[] = [sampleVar];
  let logLik = 0;

  for (let t = 1; t < n; t++) {
    const newVar = omega + alpha * residuals[t - 1] ** 2 + beta * sigmaSquared[t - 1];
    sigmaSquared.push(newVar);
    logLik += -0.5 * (Math.log(2 * Math.PI) + Math.log(newVar) + residuals[t] ** 2 / newVar);
  }

  const conditionalVol = sigmaSquared.map((v) => Math.sqrt(v * 252));
  const persistence = alpha + beta;
  const unconditionalVar = omega / (1 - persistence);

  return {
    model: { omega, alpha, beta, unconditionalVar, persistence },
    conditionalVol,
    logLikelihood: logLik,
  };
};

const dailyReturns = Array.from({ length: 504 }, (_, i) => {
  const regime = i < 100 ? 0.01 : i < 200 ? 0.03 : i < 350 ? 0.01 : 0.025;
  return (Math.random() - 0.5) * regime;
});

const garchResult = fitGARCH11(dailyReturns);
const { model } = garchResult;

console.log(`GARCH(1,1) 参数:`);
console.log(`  ω=${model.omega.toFixed(6)}, α=${model.alpha}, β=${model.beta}`);
console.log(`  持续性: ${model.persistence.toFixed(3)}`);
console.log(`  无条件年化波动率: ${(Math.sqrt(model.unconditionalVar * 252) * 100).toFixed(2)}%`);
console.log(
  `  最新条件波动率: ${(garchResult.conditionalVol[garchResult.conditionalVol.length - 1] * 100).toFixed(2)}%`,
);

小结
    

  • 平稳性是时间序列建模的基本前提，金融价格通常非平稳，收益率通常平稳
    • 

  • ACF 和 PACF 是识别模型阶数的核心工具
    • 

  • ARIMA 模型统一了自回归、差分和移动平均三个组件
    • 

  • GARCH 模型捕捉金融收益率波动率的聚集性和均值回归特征
    • 

  • 时间序列分析的完整流程是：平稳性检验 → 模型识别 → 参数估计 → 残差诊断 → 预测
    • 

  • 每个模型的假设条件和适用范围都有边界，实际应用中需要多模型对比和验证
    •
