金融数值方法

核心概念

金融数值方法是当解析解不存在或过于复杂时，通过数值逼近求解金融模型的计算技术。大多数实际金融问题——美式期权定价、带有复杂边界条件的偏微分方程、多维投资组合优化——都无法获得闭式解，必须依赖数值方法。

金融数值方法的三大支柱是：有限差分法（将偏微分方程离散化为网格上的代数方程组）、数值积分（计算期权价格等期望值的数值近似）和优化算法（在约束条件下寻找最优投资组合权重）。对程序员而言，这些方法的实现就是将数学理论转化为可运行代码的过程。

有限差分法与期权定价
Black-Scholes 偏微分方程描述了期权价格的时空演化：


∂V∂t+12σ2S2∂2V∂S2+rS∂V∂S−rV=0\frac{\partial V}{\partial t} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} + rS\frac{\partial V}{\partial S} - rV = 0∂t∂V​+21​σ2S2∂S2∂2V​+rS∂S∂V​−rV=0
有限差分法将连续的 (S, t) 空间离散化为网格，用差商替代导数，将 PDE 转化为可逐步求解的代数方程组。


interface FDMGrid {
  prices: number[];
  times: number[];
  values: number[][];
}

const explicitFDM = (
  strike: number,
  r: number,
  sigma: number,
  T: number,
  sMax: number,
  nPrice: number,
  nTime: number,
  isCall: boolean,
): FDMGrid => {
  const ds = sMax / nPrice;
  const dt = T / nTime;
  const prices = Array.from({ length: nPrice + 1 }, (_, i) => i * ds);
  const times = Array.from({ length: nTime + 1 }, (_, i) => i * dt);

  const grid: number[][] = Array.from({ length: nTime + 1 }, () => new Array(nPrice + 1).fill(0));

  for (let j = 0; j <= nPrice; j++) {
    grid[nTime][j] = isCall ? Math.max(prices[j] - strike, 0) : Math.max(strike - prices[j], 0);
  }

  for (let i = nTime - 1; i >= 0; i--) {
    for (let j = 1; j < nPrice; j++) {
      const a = 0.5 * dt * (sigma ** 2 * j ** 2 - r * j);
      const b = 1 - dt * (sigma ** 2 * j ** 2 + r);
      const c = 0.5 * dt * (sigma ** 2 * j ** 2 + r * j);
      grid[i][j] = a * grid[i + 1][j - 1] + b * grid[i + 1][j] + c * grid[i + 1][j + 1];
    }

    grid[i][0] = isCall ? 0 : strike * Math.exp(-r * (T - i * dt));
    grid[i][nPrice] = isCall ? sMax - strike * Math.exp(-r * (T - i * dt)) : 0;
  }

  return { prices, times, values: grid };
};

const result = explicitFDM(100, 0.05, 0.2, 1.0, 300, 200, 2000, true);

const spotIndex = Math.round(100 / (300 / 200));
const fdmPrice = result.values[0][spotIndex];
console.log(`显式FDM欧式看涨价格 (S=100, K=100): ${fdmPrice.toFixed(4)}`);

const spotValues = [80, 90, 100, 110, 120];
spotValues.forEach((s) => {
  const idx = Math.round(s / (300 / 200));
  console.log(`S=${s}: 期权价值=${result.values[0][idx].toFixed(4)}`);
});
牛顿法与隐含波动率求解
期权市场给出的是期权价格，而非波动率。从市场价格反推波动率（隐含波动率）是一个典型的非线性方程求根问题：找到 σ\sigmaσ 使得 BS(σ)−Cmarket=0BS(\sigma) - C_{market} = 0BS(σ)−Cmarket​=0。牛顿法是求解此问题的标准方法。


const normalCDF = (x: number): number => {
  const a1 = 0.254829592,
    a2 = -0.284496736,
    a3 = 1.421413741;
  const a4 = -1.453152027,
    a5 = 1.061405429,
    p = 0.3275911;
  const sign = x < 0 ? -1 : 1;
  const t = 1 / (1 + p * Math.abs(x));
  const y = 1 - ((((a5 * t + a4) * t + a3) * t + a2) * t + a1) * t * Math.exp((-x * x) / 2);
  return 0.5 * (1 + sign * y);
};

const normalPDF = (x: number): number => Math.exp((-x * x) / 2) / Math.sqrt(2 * Math.PI);

const bsCallPrice = (S: number, K: number, r: number, sigma: number, T: number): number => {
  const d1 = (Math.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * Math.sqrt(T));
  const d2 = d1 - sigma * Math.sqrt(T);
  return S * normalCDF(d1) - K * Math.exp(-r * T) * normalCDF(d2);
};

const bsVega = (S: number, K: number, r: number, sigma: number, T: number): number => {
  const d1 = (Math.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * Math.sqrt(T));
  return S * Math.sqrt(T) * normalPDF(d1);
};

interface ImpliedVolResult {
  sigma: number;
  iterations: number;
  error: number;
  converged: boolean;
}

const impliedVolatility = (
  marketPrice: number,
  S: number,
  K: number,
  r: number,
  T: number,
  tol: number = 1e-8,
  maxIter: number = 100,
): ImpliedVolResult => {
  let sigma = 0.2;

  for (let i = 0; i < maxIter; i++) {
    const price = bsCallPrice(S, K, r, sigma, T);
    const diff = price - marketPrice;

    if (Math.abs(diff) < tol) {
      return { sigma, iterations: i + 1, error: Math.abs(diff), converged: true };
    }

    const vega = bsVega(S, K, r, sigma, T);
    if (Math.abs(vega) < 1e-12) break;

    sigma -= diff / vega;
    sigma = Math.max(0.001, Math.min(sigma, 5.0));
  }

  return { sigma, iterations: maxIter, error: Infinity, converged: false };
};

const strikes = [85, 90, 95, 100, 105, 110, 115];
const trueVols = [0.25, 0.23, 0.21, 0.2, 0.21, 0.23, 0.26];

console.log('隐含波动率微笑:');
strikes.forEach((K, i) => {
  const price = bsCallPrice(100, K, 0.05, trueVols[i], 0.5);
  const result = impliedVolatility(price, 100, K, 0.05, 0.5);
  console.log(`K=${K}: 市场价=${price.toFixed(4)}, IV=${(result.sigma * 100).toFixed(2)}%, 迭代=${result.iterations}`);
});
投资组合优化算法
投资组合优化是一个带约束的二次规划问题：最小化组合方差（wTΣww^T \Sigma wwTΣw），同时满足预期收益目标和权重约束。当资产数量增大时，高效的数值优化算法是关键。


interface OptimizationResult {
  weights: number[];
  expectedReturn: number;
  volatility: number;
  sharpeRatio: number;
  iterations: number;
}

const portfolioVariance = (weights: number[], covMatrix: number[][]): number => {
  let variance = 0;
  for (let i = 0; i < weights.length; i++) {
    for (let j = 0; j < weights.length; j++) {
      variance += weights[i] * weights[j] * covMatrix[i][j];
    }
  }
  return variance;
};

const portfolioReturn = (weights: number[], returns: number[]): number =>
  weights.reduce((s, w, i) => s + w * returns[i], 0);

const gradientDescentOptimize = (
  returns: number[],
  covMatrix: number[][],
  targetReturn: number,
  learningRate: number = 0.01,
  iterations: number = 5000,
): OptimizationResult => {
  const n = returns.length;
  let weights = Array.from({ length: n }, () => 1 / n);

  for (let iter = 0; iter < iterations; iter++) {
    const gradient: number[] = [];
    for (let i = 0; i < n; i++) {
      let grad = 0;
      for (let j = 0; j < n; j++) {
        grad += 2 * covMatrix[i][j] * weights[j];
      }
      gradient.push(grad);
    }

    const retConstraint = portfolioReturn(weights, returns) - targetReturn;
    const sumConstraint = weights.reduce((s, w) => s + w, 0) - 1;
    const lambda1 = 100;
    const lambda2 = 100;

    for (let i = 0; i < n; i++) {
      gradient[i] += lambda1 * 2 * retConstraint * returns[i];
      gradient[i] += lambda2 * 2 * sumConstraint;
    }

    weights = weights.map((w, i) => Math.max(0, w - learningRate * gradient[i]));

    const sum = weights.reduce((s, w) => s + w, 0);
    weights = weights.map((w) => w / sum);
  }

  const ret = portfolioReturn(weights, returns);
  const vol = Math.sqrt(portfolioVariance(weights, covMatrix));
  const sharpe = (ret - 0.03) / vol;

  return {
    weights,
    expectedReturn: ret,
    volatility: vol,
    sharpeRatio: sharpe,
    iterations,
  };
};

const assetReturns = [0.12, 0.1, 0.08, 0.06, 0.04];
const covMat = [
  [0.04, 0.012, 0.006, 0.004, 0.002],
  [0.012, 0.03, 0.008, 0.005, 0.003],
  [0.006, 0.008, 0.02, 0.006, 0.004],
  [0.004, 0.005, 0.006, 0.015, 0.005],
  [0.002, 0.003, 0.004, 0.005, 0.01],
];

const targets = [0.06, 0.08, 0.1];
targets.forEach((target) => {
  const result = gradientDescentOptimize(assetReturns, covMat, target);
  const weightsStr = result.weights.map((w) => (w * 100).toFixed(1) + '%').join(', ');
  console.log(
    `目标收益=${(target * 100).toFixed(0)}%: 波动=${(result.volatility * 100).toFixed(2)}%, 夏普=${result.sharpeRatio.toFixed(3)}`,
  );
  console.log(`  权重: [${weightsStr}]`);
});
数值稳定性与误差控制
数值方法的可靠性取决于两个关键因素：稳定性（误差不会随计算步骤放大）和精度（数值解与真解的接近程度）。在金融应用中，数值不稳定可能导致定价错误甚至交易亏损。


interface ConvergenceResult {
  gridSize: number;
  price: number;
  error: number;
  convergenceRate: number;
}

const convergenceAnalysis = (
  strike: number,
  r: number,
  sigma: number,
  T: number,
  analyticalPrice: number,
): ConvergenceResult[] => {
  const gridSizes = [50, 100, 200, 400, 800];
  const results: ConvergenceResult[] = [];
  let prevError = 0;

  gridSizes.forEach((n, idx) => {
    const nTime = n * 10;
    const grid = explicitFDM(strike, r, sigma, T, 300, n, nTime, true);
    const spotIdx = Math.round(100 / (300 / n));
    const price = grid.values[0][spotIdx];
    const error = Math.abs(price - analyticalPrice);

    const convergenceRate = idx > 0 && prevError > 0 ? Math.log(prevError / error) / Math.log(2) : 0;

    results.push({ gridSize: n, price, error, convergenceRate });
    prevError = error;
  });

  return results;
};

const bsAnalytical = bsCallPrice(100, 100, 0.05, 0.2, 1.0);
console.log(`BS 解析解: ${bsAnalytical.toFixed(6)}`);

const convergence = convergenceAnalysis(100, 0.05, 0.2, 1.0, bsAnalytical);
convergence.forEach((r) => {
  console.log(
    `N=${r.gridSize}: 价格=${r.price.toFixed(6)}, 误差=${r.error.toFixed(6)}, 收敛阶=${r.convergenceRate.toFixed(2)}`,
  );
});
