期权基础

核心概念

期权是赋予持有者在特定日期或之前以特定价格买入或卖出标的资产的权利（而非义务）的合约。期权是金融工程中最灵活的工具，其非线性收益特征使其可以构建出几乎任何风险收益结构。对程序员而言，期权不仅是投资工具，更是理解公司股权激励（期权/RSU）的关键。

期权收益结构
期权的非线性收益是其最独特的特征——损失有限但收益可能无限（对买方而言）。


interface OptionContract {
  type: 'call' | 'put';
  strike: number;
  premium: number;
  quantity: number;
}

const optionPayoff = (option: OptionContract, spotPrice: number, position: 'long' | 'short'): number => {
  let intrinsicValue: number;
  if (option.type === 'call') {
    intrinsicValue = Math.max(spotPrice - option.strike, 0);
  } else {
    intrinsicValue = Math.max(option.strike - spotPrice, 0);
  }

  const payoff =
    position === 'long'
      ? (intrinsicValue - option.premium) * option.quantity
      : (option.premium - intrinsicValue) * option.quantity;

  return Math.round(payoff * 100) / 100;
};

const call: OptionContract = { type: 'call', strike: 150, premium: 5, quantity: 100 };
const prices = [130, 140, 145, 150, 155, 160, 170, 180];

console.log('看涨期权收益 (买入, 行权价$150, 权利金$5):');
prices.forEach((p) => {
  const pnl = optionPayoff(call, p, 'long');
  const status = p < call.strike ? '价外' : p === call.strike ? '平价' : '价内';
  console.log(`  股价$${p}: 收益$${pnl} [${status}]`);
});

期权价值的决定因素
interface OptionGreeksInput {
  spotPrice: number;
  strikePrice: number;
  timeToExpiry: number;
  riskFreeRate: number;
  volatility: number;
  dividendYield: number;
}

const analyzeOptionSensitivity = (base: OptionGreeksInput): void => {
  const factors = [
    { name: '标的价格↑', effect: { call: '↑', put: '↓' }, reason: 'Call内在价值增加' },
    { name: '行权价↑', effect: { call: '↓', put: '↑' }, reason: 'Call更难达到行权价' },
    { name: '到期时间↑', effect: { call: '↑', put: '↑' }, reason: '更多时间=更多机会' },
    { name: '波动率↑', effect: { call: '↑', put: '↑' }, reason: '波动大=极端结果概率大' },
    { name: '利率↑', effect: { call: '↑', put: '↓' }, reason: '持有成本效应' },
    { name: '股息↑', effect: { call: '↓', put: '↑' }, reason: '除息降低股价' },
  ];

  console.log('期权价值敏感度分析:');
  factors.forEach((f) => {
    console.log(`  ${f.name}: Call${f.effect.call}, Put${f.effect.put} — ${f.reason}`);
  });
};

analyzeOptionSensitivity({
  spotPrice: 150,
  strikePrice: 150,
  timeToExpiry: 0.5,
  riskFreeRate: 0.05,
  volatility: 0.25,
  dividendYield: 0.01,
});

interface StrategyLeg {
  option: OptionContract;
  position: 'long' | 'short';
}

const strategyPayoff = (legs: StrategyLeg[], spotPrice: number): number =>
  legs.reduce((total, leg) => total + optionPayoff(leg.option, spotPrice, leg.position), 0);

const bullCallSpread: StrategyLeg[] = [
  { option: { type: 'call', strike: 150, premium: 8, quantity: 100 }, position: 'long' },
  { option: { type: 'call', strike: 160, premium: 3, quantity: 100 }, position: 'short' },
];

console.log('\n牛市看涨价差收益:');
[140, 145, 150, 155, 160, 165, 170].forEach((p) => {
  console.log(`  股价$${p}: $${strategyPayoff(bullCallSpread, p)}`);
});
员工期权与 RSU
对程序员最直接相关的期权应用是公司股权激励。理解 ISO、NSO 和 RSU 的区别对职业决策至关重要。员工期权本质上是看涨期权——行权价是授予时的公允价格，股价高于行权价时有价值。关键风险是集中度——大量财富集中在单一公司股票上违反了分散投资原则。


小结
    

  • 期权赋予买方权利而非义务，非线性收益特征使其成为最灵活的金融工具
    • 

  • 期权价值由内在价值和时间价值组成，受标的价格、波动率、时间等六个因素影响
    • 

  • 策略组合可以构建出几乎任何想要的风险收益结构
    • 

  • 员工期权是程序员最常接触的期权形式，理解其经济本质有助于做出更好的职业决策
    • 

  • 波动率是期权定价中最关键也最难估计的参数
