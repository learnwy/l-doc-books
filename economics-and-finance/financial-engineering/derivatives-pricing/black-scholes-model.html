Black-Scholes 模型

核心概念

Black-Scholes 模型是期权定价的基石，由费希尔·布莱克和迈伦·斯科尔斯于 1973 年提出。该模型给出了欧式期权的解析定价公式，建立了期权价格与标的价格、行权价、波动率、利率和到期时间之间的精确数学关系。理解 BS 模型对程序员的价值在于：它是量化金融的入门钥匙，其思想（复制、对冲、无套利）贯穿整个金融工程。

BS 公式实现
BS 公式的核心是标准正态分布的累积分布函数 N(x)：


const normalCDF = (x: number): number => {
  const a1 = 0.254829592;
  const a2 = -0.284496736;
  const a3 = 1.421413741;
  const a4 = -1.453152027;
  const a5 = 1.061405429;
  const p = 0.3275911;

  const sign = x < 0 ? -1 : 1;
  const absX = Math.abs(x);
  const t = 1.0 / (1.0 + p * absX);
  const y = 1.0 - ((((a5 * t + a4) * t + a3) * t + a2) * t + a1) * t * Math.exp((-absX * absX) / 2);

  return 0.5 * (1.0 + sign * y);
};

interface BSParams {
  S: number;
  K: number;
  T: number;
  r: number;
  sigma: number;
}

interface BSResult {
  callPrice: number;
  putPrice: number;
  d1: number;
  d2: number;
}

const blackScholes = (params: BSParams): BSResult => {
  const { S, K, T, r, sigma } = params;
  const d1 = (Math.log(S / K) + (r + (sigma * sigma) / 2) * T) / (sigma * Math.sqrt(T));
  const d2 = d1 - sigma * Math.sqrt(T);

  const callPrice = S * normalCDF(d1) - K * Math.exp(-r * T) * normalCDF(d2);
  const putPrice = K * Math.exp(-r * T) * normalCDF(-d2) - S * normalCDF(-d1);

  return {
    callPrice: Math.round(callPrice * 100) / 100,
    putPrice: Math.round(putPrice * 100) / 100,
    d1: Math.round(d1 * 10000) / 10000,
    d2: Math.round(d2 * 10000) / 10000,
  };
};

const params: BSParams = { S: 100, K: 100, T: 0.5, r: 0.05, sigma: 0.2 };
const result = blackScholes(params);
console.log(`Call价格: $${result.callPrice}`);
console.log(`Put价格: $${result.putPrice}`);
console.log(`d1=${result.d1}, d2=${result.d2}`);
console.log(
  `Call-Put平价验证: ${(result.callPrice - result.putPrice + params.K * Math.exp(-params.r * params.T)).toFixed(2)} ≈ S=${params.S}`,
);
隐含波动率
隐含波动率是从市场期权价格中反推出的波动率参数。它是市场对未来波动的预期，也是期权交易中最重要的指标。


const impliedVolatility = (
  marketPrice: number,
  S: number,
  K: number,
  T: number,
  r: number,
  optionType: 'call' | 'put',
  tolerance: number = 0.0001,
  maxIterations: number = 100,
): number => {
  let sigmaLow = 0.001;
  let sigmaHigh = 5.0;

  for (let i = 0; i < maxIterations; i++) {
    const sigmaMid = (sigmaLow + sigmaHigh) / 2;
    const bs = blackScholes({ S, K, T, r, sigma: sigmaMid });
    const modelPrice = optionType === 'call' ? bs.callPrice : bs.putPrice;
    const diff = modelPrice - marketPrice;

    if (Math.abs(diff) < tolerance) return Math.round(sigmaMid * 10000) / 10000;

    if (diff > 0) sigmaHigh = sigmaMid;
    else sigmaLow = sigmaMid;
  }

  return (sigmaLow + sigmaHigh) / 2;
};

const iv = impliedVolatility(8.5, 100, 100, 0.5, 0.05, 'call');
console.log(`隐含波动率: ${(iv * 100).toFixed(2)}%`);

const strikes = [85, 90, 95, 100, 105, 110, 115];
const marketPrices = [16.5, 12.8, 9.5, 7.0, 5.0, 3.5, 2.3];
console.log('\n波动率微笑:');
strikes.forEach((k, i) => {
  const vol = impliedVolatility(marketPrices[i], 100, k, 0.5, 0.05, 'call');
  console.log(`  K=${k}: IV=${(vol * 100).toFixed(1)}%`);
});
波动率微笑表明 BS 模型的假设（常数波动率）在现实中不成立——深度价外和价内的期权隐含波动率高于平价期权。这反映了市场对极端事件（尾部风险）的定价。

尽管有这些局限，BS 模型仍然是期权定价的基准框架——交易员用 BS 模型计算隐含波动率，再根据经验调整，而非完全抛弃模型。


小结
    

  • BS 模型是期权定价的理论基石，提供了五参数到期权价格的解析映射
    • 

  • 隐含波动率是期权市场最重要的信息，反映市场对未来风险的预期
    • 

  • 波动率微笑表明现实偏离 BS 假设，市场对极端风险有额外定价
    • 

  • 尽管有局限，BS 模型仍是行业标准——理解其思想比追求精确模型更重要
    • 

  • 编程实现 BS 模型是量化金融入门的第一步
