二叉树模型

核心概念

二叉树模型是一种离散时间的期权定价方法，由 Cox、Ross 和 Rubinstein 于 1979 年提出。它将连续的价格运动分解为一系列简单的"上涨或下跌"步骤，通过逐步回溯计算期权价格。二叉树模型直观、灵活，能够处理美式期权、奇异期权等 BS 公式无法直接解决的问题。

二叉树定价实现
interface BinomialTreeParams {
  S: number;
  K: number;
  T: number;
  r: number;
  sigma: number;
  steps: number;
  optionType: 'call' | 'put';
  exercise: 'european' | 'american';
}

interface BinomialResult {
  price: number;
  delta: number;
  earlyExerciseNodes: number;
}

const binomialTree = (params: BinomialTreeParams): BinomialResult => {
  const { S, K, T, r, sigma, steps, optionType, exercise } = params;
  const dt = T / steps;
  const u = Math.exp(sigma * Math.sqrt(dt));
  const d = 1 / u;
  const p = (Math.exp(r * dt) - d) / (u - d);
  const discount = Math.exp(-r * dt);

  const prices: number[][] = [];
  const optionValues: number[][] = [];

  for (let i = 0; i <= steps; i++) {
    prices[i] = [];
    for (let j = 0; j <= i; j++) {
      prices[i][j] = S * Math.pow(u, j) * Math.pow(d, i - j);
    }
  }

  optionValues[steps] = [];
  for (let j = 0; j <= steps; j++) {
    if (optionType === 'call') {
      optionValues[steps][j] = Math.max(prices[steps][j] - K, 0);
    } else {
      optionValues[steps][j] = Math.max(K - prices[steps][j], 0);
    }
  }

  let earlyExerciseNodes = 0;

  for (let i = steps - 1; i >= 0; i--) {
    optionValues[i] = [];
    for (let j = 0; j <= i; j++) {
      const holdValue = discount * (p * optionValues[i + 1][j + 1] + (1 - p) * optionValues[i + 1][j]);

      if (exercise === 'american') {
        let exerciseValue: number;
        if (optionType === 'call') {
          exerciseValue = Math.max(prices[i][j] - K, 0);
        } else {
          exerciseValue = Math.max(K - prices[i][j], 0);
        }
        if (exerciseValue > holdValue) earlyExerciseNodes++;
        optionValues[i][j] = Math.max(holdValue, exerciseValue);
      } else {
        optionValues[i][j] = holdValue;
      }
    }
  }

  const delta = (optionValues[1][1] - optionValues[1][0]) / (prices[1][1] - prices[1][0]);

  return {
    price: Math.round(optionValues[0][0] * 100) / 100,
    delta: Math.round(delta * 10000) / 10000,
    earlyExerciseNodes,
  };
};

const europeanCall = binomialTree({
  S: 100,
  K: 100,
  T: 1,
  r: 0.05,
  sigma: 0.2,
  steps: 100,
  optionType: 'call',
  exercise: 'european',
});
console.log(`欧式Call: $${europeanCall.price}, Delta=${europeanCall.delta}`);

const americanPut = binomialTree({
  S: 100,
  K: 100,
  T: 1,
  r: 0.05,
  sigma: 0.2,
  steps: 100,
  optionType: 'put',
  exercise: 'american',
});
console.log(`美式Put: $${americanPut.price}, 提前行权节点=${americanPut.earlyExerciseNodes}`);

实际应用中 100-500 步已经足够精确。对于计算密集的场景（如实时报价），可以用 BS 解析解处理欧式期权，仅对美式期权使用二叉树。


美式期权与提前行权
二叉树的最大优势是能处理美式期权的提前行权问题。美式期权在到期前任何时间都可以行权，因此其价值不低于欧式期权。


提前行权最优的典型情况：


    

  • 美式看跌期权：当股价远低于行权价时，继续持有的时间价值可能不足以补偿立即行权获得的收益
    • 

  • 付息股票的美式看涨期权：在除息日前行权可以获得股息
    • 



const compareEuropeanAmerican = (S: number, K: number): void => {
  const baseParams = { S, K, T: 1, r: 0.05, sigma: 0.3, steps: 200 };

  const eurPut = binomialTree({ ...baseParams, optionType: 'put', exercise: 'european' });
  const amePut = binomialTree({ ...baseParams, optionType: 'put', exercise: 'american' });
  const premium = amePut.price - eurPut.price;

  console.log(`S=${S}, K=${K}:`);
  console.log(`  欧式Put: $${eurPut.price}`);
  console.log(`  美式Put: $${amePut.price}`);
  console.log(`  提前行权溢价: $${premium.toFixed(2)} (${((premium / eurPut.price) * 100).toFixed(1)}%)`);
};

[80, 90, 100, 110, 120].forEach((s) => compareEuropeanAmerican(s, 100));
二叉树的扩展应用
二叉树模型的灵活性使其适用于多种奇异期权：

回望期权
收益取决于极值
扩展状态变量记录路径极值





二叉树的思想——将复杂问题分解为简单的递归子问题——与程序员熟悉的动态规划完全一致。从叶节点（已知收益）回溯到根节点（当前价格），就是一个典型的 DP 过程。


小结
    

  • 二叉树将连续价格运动离散化为上涨/下跌序列，通过回溯计算期权价格
    • 

  • 风险中性定价是核心思想——使用风险中性概率和无风险利率折现
    • 

  • 美式期权的提前行权判断是二叉树相对 BS 的核心优势
    • 

  • 步数增加时二叉树收敛到 BS 解，100-500 步通常已足够精确
    • 

  • 二叉树的回溯过程本质上是动态规划，对程序员来说非常自然
    •
