Greeks 与对冲

核心概念

Greeks 是衡量期权价格对各种风险因素敏感度的指标集合。它们以希腊字母命名，是期权交易和风险管理的核心工具。理解 Greeks 帮助交易员量化风险敞口并构建对冲策略。对程序员而言，Greeks 是构建风险管理系统和期权定价引擎的基础。

Greeks 计算实现
const normalPDF = (x: number): number => Math.exp((-x * x) / 2) / Math.sqrt(2 * Math.PI);

const normalCDF = (x: number): number => {
  const a1 = 0.254829592,
    a2 = -0.284496736,
    a3 = 1.421413741;
  const a4 = -1.453152027,
    a5 = 1.061405429,
    p = 0.3275911;
  const sign = x < 0 ? -1 : 1;
  const t = 1.0 / (1.0 + p * Math.abs(x));
  const y = 1.0 - ((((a5 * t + a4) * t + a3) * t + a2) * t + a1) * t * Math.exp((-x * x) / 2);
  return 0.5 * (1.0 + sign * y);
};

interface GreeksResult {
  delta: number;
  gamma: number;
  theta: number;
  vega: number;
  rho: number;
}

const calculateGreeks = (
  S: number,
  K: number,
  T: number,
  r: number,
  sigma: number,
  type: 'call' | 'put',
): GreeksResult => {
  const d1 = (Math.log(S / K) + (r + (sigma * sigma) / 2) * T) / (sigma * Math.sqrt(T));
  const d2 = d1 - sigma * Math.sqrt(T);

  const nd1 = normalPDF(d1);
  const Nd1 = normalCDF(d1);
  const Nd2 = normalCDF(d2);

  if (type === 'call') {
    return {
      delta: Math.round(Nd1 * 10000) / 10000,
      gamma: Math.round((nd1 / (S * sigma * Math.sqrt(T))) * 10000) / 10000,
      theta: Math.round((((-S * nd1 * sigma) / (2 * Math.sqrt(T)) - r * K * Math.exp(-r * T) * Nd2) / 365) * 100) / 100,
      vega: Math.round(((S * nd1 * Math.sqrt(T)) / 100) * 100) / 100,
      rho: Math.round(((K * T * Math.exp(-r * T) * Nd2) / 100) * 100) / 100,
    };
  }
  return {
    delta: Math.round((Nd1 - 1) * 10000) / 10000,
    gamma: Math.round((nd1 / (S * sigma * Math.sqrt(T))) * 10000) / 10000,
    theta:
      Math.round((((-S * nd1 * sigma) / (2 * Math.sqrt(T)) + r * K * Math.exp(-r * T) * normalCDF(-d2)) / 365) * 100) /
      100,
    vega: Math.round(((S * nd1 * Math.sqrt(T)) / 100) * 100) / 100,
    rho: Math.round(((-K * T * Math.exp(-r * T) * normalCDF(-d2)) / 100) * 100) / 100,
  };
};

const greeks = calculateGreeks(100, 100, 0.5, 0.05, 0.2, 'call');
console.log('ATM Call Greeks:');
Object.entries(greeks).forEach(([key, value]) => {
  console.log(`  ${key}: ${value}`);
});
Delta 对冲
Delta 对冲是最基本的风险管理策略：通过持有 Delta 份标的资产来对冲期权的方向风险。


interface DeltaHedgePortfolio {
  optionPosition: number;
  optionDelta: number;
  hedgeShares: number;
  netDelta: number;
  hedgeCost: number;
}

const deltaHedge = (optionQuantity: number, delta: number, stockPrice: number): DeltaHedgePortfolio => {
  const totalDelta = optionQuantity * delta;
  const hedgeShares = -Math.round(totalDelta);
  const netDelta = totalDelta + hedgeShares;
  const hedgeCost = hedgeShares * stockPrice;

  return {
    optionPosition: optionQuantity,
    optionDelta: totalDelta,
    hedgeShares,
    netDelta: Math.round(netDelta * 100) / 100,
    hedgeCost,
  };
};

const portfolio = deltaHedge(-100, 0.52, 100);
console.log(`期权头寸Delta: ${portfolio.optionDelta}`);
console.log(`对冲股数: ${portfolio.hedgeShares}`);
console.log(`净Delta: ${portfolio.netDelta}`);
console.log(`对冲成本: $${portfolio.hedgeCost}`);
Delta 对冲的关键挑战是 Gamma 风险：当标的价格大幅变动时，Delta 本身会变化，导致对冲组合偏离中性。Gamma 越大，需要越频繁地调整对冲头寸。


Theta-Vega 权衡
期权买方面临 Theta 和 Vega 的天然权衡：






头寸

Vega
含义

每天付出时间价值，但波动率上升获利

每天赚取时间价值，但波动率上升亏损





时间是期权卖方的朋友，波动率是期权买方的朋友。这个权衡关系在交易策略设计中至关重要。


期权卖方（如备兑开仓策略）本质上是在"卖保险"——收取权利金但承担尾部风险。大部分时间赚小钱，偶尔一次大亏。


组合风险管理
实际的期权组合通常包含多个不同行权价和到期日的期权，需要同时管理多个 Greeks：


interface PortfolioGreeks {
  totalDelta: number;
  totalGamma: number;
  totalTheta: number;
  totalVega: number;
  riskSummary: string;
}

const aggregateGreeks = (positions: Array<{ quantity: number; greeks: GreeksResult }>): PortfolioGreeks => {
  const totals = positions.reduce(
    (acc, pos) => ({
      totalDelta: acc.totalDelta + pos.quantity * pos.greeks.delta,
      totalGamma: acc.totalGamma + pos.quantity * pos.greeks.gamma,
      totalTheta: acc.totalTheta + pos.quantity * pos.greeks.theta,
      totalVega: acc.totalVega + pos.quantity * pos.greeks.vega,
    }),
    { totalDelta: 0, totalGamma: 0, totalTheta: 0, totalVega: 0 },
  );

  const risks: string[] = [];
  if (Math.abs(totals.totalDelta) > 10) risks.push('方向风险');
  if (totals.totalGamma < -0.5) risks.push('Gamma风险');
  if (totals.totalVega < -5) risks.push('波动率风险');

  return {
    ...totals,
    riskSummary: risks.length > 0 ? risks.join(', ') : '风险可控',
  };
};

const positions = [
  { quantity: -100, greeks: calculateGreeks(100, 100, 0.5, 0.05, 0.2, 'call') },
  { quantity: 50, greeks: calculateGreeks(100, 105, 0.5, 0.05, 0.2, 'call') },
  { quantity: 52, greeks: { delta: 1, gamma: 0, theta: 0, vega: 0, rho: 0 } },
];

const portfolio2 = aggregateGreeks(positions);
console.log('组合Greeks:', portfolio2);
小结
    

  • Greeks 量化了期权对各风险因素的敏感度，是风险管理的基础工具
    • 

  • Delta 对冲消除方向风险，但 Gamma 导致需要持续动态调整
    • 

  • Theta 和 Vega 存在天然权衡——时间是卖方朋友，波动率是买方朋友
    • 

  • 组合风险管理需要同时监控多个 Greeks 并控制整体风险敞口
    • 

  • Greeks 的计算和监控是量化交易系统的核心功能模块
