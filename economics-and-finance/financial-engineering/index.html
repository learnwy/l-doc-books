金融工程入门 简介

金融工程把工程思维引入金融：用数学建模、概率统计与数值计算，对金融产品定价、对风险度量、对投资组合优化。本知识库面向有扎实编程基础、具备基本概率与线性代数素养的中高级程序员，目标是让你既能读懂衍生品定价公式背后的逻辑，也能把它写成可运行、可回测的代码。

本 hub 的定位与边界

金融与量化主题在本仓库分布在多个 hub，职责各有侧重。先看清边界再决定从哪里入手，能避免重复学习：

Hub 侧重 与本 hub 的关系
金融工程入门（本 hub） 衍生品定价、风险度量、金融建模的入门原理 + 代码实现 起点：建立定价/风险/建模的统一思维框架
量化金融 · 衍生品定价 微观结构、随机微积分、因子模型、ML 等进阶专题 进阶：本 hub 每个主题的纵深版本
量化交易 策略、回测、执行系统、合规 把定价/风险能力用于实盘策略
金融风险管理 机构级市场/信用/操作风险、Basel 监管 把风险度量放进机构治理与监管语境
投资基础 股票/债券/基金、组合配置（个人视角） 同一概念的非工程化、面向个人讲法
个人理财投资 · 期权基础 期权交易实务（看涨看跌、价差、国内市场） 期权的交易实践侧，与本 hub 的定价理论互补

一句话区分：本 hub 教你为什么这样定价、如何把模型写成代码；量化金融 hub 教你更深的模型；量化交易/风险管理 hub 教你把模型用在策略与机构治理中；投资类 hub 教你作为投资者如何使用这些工具。

前置知识

  • 概率与统计：随机变量、期望/方差、正态分布、假设检验。薄弱可补 概率统计。
  • 微积分与线性代数：偏导数、积分、矩阵运算（理解 Greeks 与组合优化需要）。
  • 随机过程（第 2、4 章进阶部分需要）：布朗运动与伊藤微积分，见 随机过程。
  • 编程：能用 Python/任意语言实现循环、矩阵运算与随机数模拟即可。

推荐学习路径

入门者（先建立全局认知）：第 1 章金融市场 → 第 2 章期权基础与 Black-Scholes → 第 3 章市场风险与风险度量指标。先不纠缠随机微积分，重在理解「复制 / 无套利 / 风险度量」三个核心思想。

有数理基础、想做量化建模：第 2 章（BS + 二叉树 + Greeks）→ 第 4 章随机过程 → 蒙特卡洛 → 金融数值方法，每个模型都动手实现一遍，再进入 量化金融 · 衍生品定价 深化。

偏风险/资管方向：第 3 章风险管理全章 → 量化风险管理 与 金融风险管理。

四章的逻辑链是：市场（背景）→ 衍生品定价（核心能力）→ 风险管理（约束与目标）→ 金融建模（落地为代码）。建议顺序学习，并坚持把关键模型写成代码——金融工程的理解深度，最终取决于你能否把公式跑起来。
