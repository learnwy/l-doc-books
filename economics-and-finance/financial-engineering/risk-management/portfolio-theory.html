投资组合理论

核心概念

投资组合理论是现代金融学的基石之一，由哈里·马科维茨于1952年提出。其核心思想是：通过合理配置多种资产，可以在给定风险水平下最大化预期收益，或在给定收益目标下最小化风险。这一理论将投资决策从"选什么股票"转化为"如何配置权重"的优化问题，从根本上改变了资产管理行业的实践方式。

对程序员而言，投资组合理论是一个完美的数学优化问题——它有明确的目标函数、约束条件和可计算的解，非常适合用代码实现和验证。

均值-方差优化
马科维茨均值-方差框架的核心是将每个资产用两个统计量描述：预期收益率（均值）和风险（方差或标准差），并通过协方差矩阵描述资产之间的联动关系。


给定 N 个资产，投资组合的收益和风险为：


    

  • 组合预期收益：E(Rp)=∑i=1Nwi⋅E(Ri)E(R_p) = \sum_{i=1}^{N} w_i \cdot E(R_i)E(Rp​)=∑i=1N​wi​⋅E(Ri​)
    • 

  • 组合方差：σp2=∑i=1N∑j=1Nwiwjσij\sigma_p^2 = \sum_{i=1}^{N}\sum_{j=1}^{N} w_i w_j \sigma_{ij}σp2​=∑i=1N​∑j=1N​wi​wj​σij​
    • 



其中 wiw_iwi​ 是第 iii 个资产的权重，σij\sigma_{ij}σij​ 是资产 iii 和 jjj 的协方差。


interface Asset {
  name: string;
  expectedReturn: number;
  volatility: number;
}

interface Portfolio {
  weights: number[];
  expectedReturn: number;
  volatility: number;
  sharpeRatio: number;
}

const portfolioStats = (weights: number[], returns: number[], covMatrix: number[][]): Portfolio => {
  const expectedReturn = weights.reduce((s, w, i) => s + w * returns[i], 0);

  let variance = 0;
  for (let i = 0; i < weights.length; i++) {
    for (let j = 0; j < weights.length; j++) {
      variance += weights[i] * weights[j] * covMatrix[i][j];
    }
  }
  const volatility = Math.sqrt(variance);
  const riskFreeRate = 0.03;
  const sharpeRatio = (expectedReturn - riskFreeRate) / volatility;

  return { weights, expectedReturn, volatility, sharpeRatio };
};

const returns = [0.12, 0.08, 0.05];
const covMatrix = [
  [0.04, 0.006, 0.002],
  [0.006, 0.0225, 0.004],
  [0.002, 0.004, 0.01],
];

const equalWeight = portfolioStats([1 / 3, 1 / 3, 1 / 3], returns, covMatrix);
console.log(`等权组合 - 收益: ${(equalWeight.expectedReturn * 100).toFixed(2)}%`);
console.log(`等权组合 - 波动: ${(equalWeight.volatility * 100).toFixed(2)}%`);
console.log(`等权组合 - 夏普: ${equalWeight.sharpeRatio.toFixed(3)}`);
分散化的数学本质在于协方差项：当两个资产的相关性低于1时，组合的风险一定小于单个资产风险的加权平均。这就是"不要把鸡蛋放在同一个篮子里"的数学证明。


有效前沿与资本市场线
在所有可能的资产配置方案中，存在一条边界曲线：在该曲线上的组合，要么在相同风险下具有最高收益，要么在相同收益下具有最低风险。这条曲线就是有效前沿。


在有效前沿的基础上引入无风险资产（如国债），投资者可以通过借贷在无风险资产和切线组合之间分配资金，形成资本市场线（CML）。CML 上的每一个点都优于有效前沿上的点（除切线点外），这就是"分离定理"——所有理性投资者持有相同的风险资产组合（切线组合），仅在借贷比例上有所不同。


const generateEfficientFrontier = (returns: number[], covMatrix: number[][], numPoints: number = 50): Portfolio[] => {
  const n = returns.length;
  const frontierPoints: Portfolio[] = [];

  for (let k = 0; k < numPoints; k++) {
    let bestPortfolio: Portfolio | null = null;
    const targetReturn = 0.03 + (k / numPoints) * 0.15;

    for (let trial = 0; trial < 5000; trial++) {
      const raw = Array.from({ length: n }, () => Math.random());
      const sum = raw.reduce((s, v) => s + v, 0);
      const weights = raw.map((v) => v / sum);
      const port = portfolioStats(weights, returns, covMatrix);

      if (Math.abs(port.expectedReturn - targetReturn) < 0.005) {
        if (!bestPortfolio || port.volatility < bestPortfolio.volatility) {
          bestPortfolio = port;
        }
      }
    }

    if (bestPortfolio) {
      frontierPoints.push(bestPortfolio);
    }
  }

  return frontierPoints.sort((a, b) => a.volatility - b.volatility);
};

const frontier = generateEfficientFrontier(returns, covMatrix, 20);
frontier.forEach((p) => {
  console.log(
    `收益: ${(p.expectedReturn * 100).toFixed(1)}% | 风险: ${(p.volatility * 100).toFixed(1)}% | 夏普: ${p.sharpeRatio.toFixed(2)}`,
  );
});
资本资产定价模型
CAPM 是投资组合理论的直接延伸，它回答了一个核心问题：一个资产的预期收益率应该是多少？答案是：预期收益率与该资产的系统性风险（Beta）成正比。


E(Ri)=Rf+βi⋅[E(Rm)−Rf]E(R_i) = R_f + \beta_i \cdot [E(R_m) - R_f]E(Ri​)=Rf​+βi​⋅[E(Rm​)−Rf​]
其中 βi=Cov(Ri,Rm)Var(Rm)\beta_i = \frac{Cov(R_i, R_m)}{Var(R_m)}βi​=Var(Rm​)Cov(Ri​,Rm​)​，衡量资产对市场波动的敏感度。


interface CAPMResult {
  asset: string;
  beta: number;
  expectedReturn: number;
  alpha: number;
}

const calculateBeta = (assetReturns: number[], marketReturns: number[]): number => {
  const n = assetReturns.length;
  const meanAsset = assetReturns.reduce((s, v) => s + v, 0) / n;
  const meanMarket = marketReturns.reduce((s, v) => s + v, 0) / n;

  let covariance = 0;
  let marketVariance = 0;

  for (let i = 0; i < n; i++) {
    const da = assetReturns[i] - meanAsset;
    const dm = marketReturns[i] - meanMarket;
    covariance += da * dm;
    marketVariance += dm * dm;
  }

  return covariance / marketVariance;
};

const capmExpectedReturn = (riskFreeRate: number, marketReturn: number, beta: number): number =>
  riskFreeRate + beta * (marketReturn - riskFreeRate);

const marketReturns = Array.from({ length: 60 }, () => (Math.random() - 0.48) * 0.08);

const assets = [
  { name: '科技股', returns: marketReturns.map((r) => r * 1.3 + (Math.random() - 0.5) * 0.02) },
  { name: '公用事业', returns: marketReturns.map((r) => r * 0.5 + (Math.random() - 0.5) * 0.01) },
  { name: '债券基金', returns: marketReturns.map((r) => r * 0.2 + (Math.random() - 0.5) * 0.005) },
];

const riskFreeRate = 0.03 / 12;
const marketMeanReturn = marketReturns.reduce((s, v) => s + v, 0) / marketReturns.length;

assets.forEach((a) => {
  const beta = calculateBeta(a.returns, marketReturns);
  const expected = capmExpectedReturn(riskFreeRate, marketMeanReturn, beta);
  const actual = a.returns.reduce((s, v) => s + v, 0) / a.returns.length;
  console.log(
    `${a.name}: Beta=${beta.toFixed(2)}, CAPM预期=${(expected * 1200).toFixed(1)}%, 实际=${(actual * 1200).toFixed(1)}%`,
  );
});

因子模型与实践演进
CAPM 只考虑单一因子（市场风险），但实证研究发现，资产收益还受到其他系统性因子的影响。Fama-French 三因子模型在市场因子基础上增加了规模因子（SMB）和价值因子（HML），能解释更多的收益差异。


interface FactorExposure {
  asset: string;
  marketBeta: number;
  sizeFactor: number;
  valueFactor: number;
  expectedReturn: number;
}

const famaFrenchReturn = (
  riskFreeRate: number,
  marketPremium: number,
  smbPremium: number,
  hmlPremium: number,
  betas: { market: number; smb: number; hml: number },
): number => {
  return riskFreeRate + betas.market * marketPremium + betas.smb * smbPremium + betas.hml * hmlPremium;
};

const factorPremiums = {
  riskFree: 0.03,
  market: 0.06,
  smb: 0.025,
  hml: 0.035,
};

const portfolios: FactorExposure[] = [
  {
    asset: '大盘价值',
    marketBeta: 0.9,
    sizeFactor: -0.2,
    valueFactor: 0.6,
    expectedReturn: famaFrenchReturn(
      factorPremiums.riskFree,
      factorPremiums.market,
      factorPremiums.smb,
      factorPremiums.hml,
      { market: 0.9, smb: -0.2, hml: 0.6 },
    ),
  },
  {
    asset: '小盘成长',
    marketBeta: 1.2,
    sizeFactor: 0.8,
    valueFactor: -0.4,
    expectedReturn: famaFrenchReturn(
      factorPremiums.riskFree,
      factorPremiums.market,
      factorPremiums.smb,
      factorPremiums.hml,
      { market: 1.2, smb: 0.8, hml: -0.4 },
    ),
  },
  {
    asset: '市场指数',
    marketBeta: 1.0,
    sizeFactor: 0.0,
    valueFactor: 0.0,
    expectedReturn: famaFrenchReturn(
      factorPremiums.riskFree,
      factorPremiums.market,
      factorPremiums.smb,
      factorPremiums.hml,
      { market: 1.0, smb: 0.0, hml: 0.0 },
    ),
  },
];

portfolios.forEach((p) => {
  console.log(`${p.asset}: 预期收益=${(p.expectedReturn * 100).toFixed(1)}%`);
  console.log(`  因子暴露: 市场=${p.marketBeta}, 规模=${p.sizeFactor}, 价值=${p.valueFactor}`);
});
投资组合理论在实践中的演进方向包括：Black-Litterman 模型允许融入主观观点来调整市场均衡权重；风险平价策略不追求收益最大化，而是让每个资产对组合总风险的贡献相等；机器学习方法开始用于协方差矩阵的估计和因子选择，提升模型的稳健性。


小结
    

  • 马科维茨均值-方差框架为分散化投资提供了严格的数学基础
    • 

  • 有效前沿上的组合在风险-收益权衡中是最优的
    • 

  • CAPM 将资产的预期收益与其系统性风险（Beta）联系起来
    • 

  • 因子模型扩展了 CAPM，用多个风险因子解释收益差异
    • 

  • 理论假设与现实的差距催生了 Black-Litterman、风险平价等实践改进
    • 

  • 投资组合优化本质上是一个数学规划问题，非常适合用代码实现和回测验证
