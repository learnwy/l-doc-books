市场风险

核心概念

市场风险是因市场价格（股价、利率、汇率、商品价格）不利变动而导致损失的风险。它是金融机构面临的最主要风险类型之一。理解市场风险对程序员而言，既关系个人投资管理，也是开发风控系统和量化交易系统的基础。

VaR：在险价值
VaR（Value at Risk）是市场风险衡量的行业标准：在给定置信水平和时间区间下，投资组合可能遭受的最大损失。


interface VaRResult {
  parametric: number;
  historical: number;
  confidenceLevel: number;
  timeHorizon: number;
}

const parametricVaR = (
  portfolioValue: number,
  dailyReturn: number,
  dailyVolatility: number,
  confidence: number,
  days: number,
): number => {
  const zScores: Record<number, number> = { 0.95: 1.645, 0.99: 2.326, 0.999: 3.09 };
  const z = zScores[confidence] ?? 1.645;
  return portfolioValue * (dailyReturn * days - z * dailyVolatility * Math.sqrt(days));
};

const historicalVaR = (returns: number[], portfolioValue: number, confidence: number): number => {
  const sorted = [...returns].sort((a, b) => a - b);
  const index = Math.floor(sorted.length * (1 - confidence));
  return portfolioValue * sorted[index];
};

const dailyReturns = Array.from({ length: 252 }, () => (Math.random() - 0.5) * 0.04);
const portfolioValue = 1000000;

const pVaR = parametricVaR(portfolioValue, 0.0003, 0.015, 0.95, 1);
const hVaR = historicalVaR(dailyReturns, portfolioValue, 0.95);

console.log(`参数法VaR(95%, 1天): ¥${Math.abs(Math.round(pVaR))}`);
console.log(`历史模拟VaR(95%, 1天): ¥${Math.abs(Math.round(hVaR))}`);

压力测试与情景分析
VaR 衡量"正常市场条件"下的风险，但金融危机往往发生在 VaR 无法捕捉的极端情况下。压力测试通过模拟极端场景来评估潜在损失。


interface StressScenario {
  name: string;
  stockChange: number;
  rateChange: number;
  fxChange: number;
  volChange: number;
}

interface StressResult {
  scenario: string;
  portfolioLoss: number;
  lossPercent: number;
  survivable: boolean;
}

const runStressTest = (
  portfolioValue: number,
  stockExposure: number,
  rateExposure: number,
  fxExposure: number,
  scenarios: StressScenario[],
): StressResult[] => {
  return scenarios.map((s) => {
    const loss = stockExposure * s.stockChange + rateExposure * s.rateChange * 100 + fxExposure * s.fxChange;
    const lossPercent = (loss / portfolioValue) * 100;

    return {
      scenario: s.name,
      portfolioLoss: Math.round(loss),
      lossPercent: Math.round(lossPercent * 10) / 10,
      survivable: Math.abs(lossPercent) < 20,
    };
  });
};

const scenarios: StressScenario[] = [
  { name: '2008金融危机', stockChange: -0.4, rateChange: -0.02, fxChange: 0.1, volChange: 0.3 },
  { name: '2020疫情冲击', stockChange: -0.35, rateChange: -0.015, fxChange: 0.05, volChange: 0.4 },
  { name: '利率急升', stockChange: -0.15, rateChange: 0.03, fxChange: -0.05, volChange: 0.1 },
  { name: '货币危机', stockChange: -0.2, rateChange: 0.05, fxChange: -0.2, volChange: 0.25 },
];

const results = runStressTest(1000000, 600000, 300000, 100000, scenarios);
results.forEach((r) => {
  console.log(`${r.scenario}: 损失¥${Math.abs(r.portfolioLoss)} (${r.lossPercent}%) ${r.survivable ? '✓' : '⚠'}`);
});
波动率建模
波动率是市场风险的核心度量。真实市场的波动率具有聚集性（高波动后续高波动）和均值回归特征。


EWMA（指数加权移动平均）是实践中最常用的波动率估计方法，RiskMetrics 推荐 λ=0.94：


const ewmaVolatility = (returns: number[], lambda: number = 0.94): number[] => {
  const variances: number[] = [returns[0] * returns[0]];

  for (let i = 1; i < returns.length; i++) {
    const newVar = lambda * variances[i - 1] + (1 - lambda) * returns[i] * returns[i];
    variances.push(newVar);
  }

  return variances.map((v) => Math.sqrt(v * 252));
};

const returns = Array.from({ length: 60 }, () => (Math.random() - 0.5) * 0.03);
const vols = ewmaVolatility(returns);
const latestVol = vols[vols.length - 1];
console.log(`最新年化波动率: ${(latestVol * 100).toFixed(2)}%`);
小结
    

  • 市场风险来源于价格波动，分为系统性风险和非系统性风险
    • 

  • VaR 是行业标准的风险衡量工具，但无法捕捉极端尾部风险
    • 

  • 压力测试补充 VaR 的不足，模拟极端场景下的潜在损失
    • 

  • 波动率是市场风险的核心度量，EWMA 和 GARCH 是主要的建模方法
    • 

  • 风控系统的开发需要将这些模型转化为实时计算和监控能力
