金融市场结构

核心概念

金融市场是资金供需双方进行交易的场所和机制。市场结构决定了交易如何发生、价格如何形成、信息如何传播。对程序员而言，理解金融市场结构是参与金融科技开发、量化交易系统设计和个人投资的必要基础。

金融市场的核心功能是价格发现和资源配置——通过市场参与者的集体判断，将资金从低效用途导向高效用途。


交易所与撮合引擎
交易所是高度规范化的集中交易场所。现代交易所的核心是电子撮合引擎——一个高性能的订单匹配系统。


type OrderSide = 'buy' | 'sell';
type OrderType = 'limit' | 'market';

interface Order {
  id: string;
  side: OrderSide;
  type: OrderType;
  price: number;
  quantity: number;
  timestamp: number;
}

interface Trade {
  buyOrderId: string;
  sellOrderId: string;
  price: number;
  quantity: number;
  timestamp: number;
}

class OrderBook {
  private bids: Order[] = [];
  private asks: Order[] = [];
  private trades: Trade[] = [];

  addOrder(order: Order): Trade[] {
    const newTrades: Trade[] = [];

    if (order.side === 'buy') {
      while (order.quantity > 0 && this.asks.length > 0) {
        const bestAsk = this.asks[0];
        if (order.type === 'limit' && order.price < bestAsk.price) break;

        const fillQty = Math.min(order.quantity, bestAsk.quantity);
        newTrades.push({
          buyOrderId: order.id,
          sellOrderId: bestAsk.id,
          price: bestAsk.price,
          quantity: fillQty,
          timestamp: Date.now(),
        });

        order.quantity -= fillQty;
        bestAsk.quantity -= fillQty;
        if (bestAsk.quantity === 0) this.asks.shift();
      }
      if (order.quantity > 0 && order.type === 'limit') {
        this.bids.push(order);
        this.bids.sort((a, b) => b.price - a.price || a.timestamp - b.timestamp);
      }
    } else {
      while (order.quantity > 0 && this.bids.length > 0) {
        const bestBid = this.bids[0];
        if (order.type === 'limit' && order.price > bestBid.price) break;

        const fillQty = Math.min(order.quantity, bestBid.quantity);
        newTrades.push({
          buyOrderId: bestBid.id,
          sellOrderId: order.id,
          price: bestBid.price,
          quantity: fillQty,
          timestamp: Date.now(),
        });

        order.quantity -= fillQty;
        bestBid.quantity -= fillQty;
        if (bestBid.quantity === 0) this.bids.shift();
      }
      if (order.quantity > 0 && order.type === 'limit') {
        this.asks.push(order);
        this.asks.sort((a, b) => a.price - b.price || a.timestamp - b.timestamp);
      }
    }

    this.trades.push(...newTrades);
    return newTrades;
  }

  getSpread(): { bid: number; ask: number; spread: number } | null {
    if (this.bids.length === 0 || this.asks.length === 0) return null;
    return {
      bid: this.bids[0].price,
      ask: this.asks[0].price,
      spread: this.asks[0].price - this.bids[0].price,
    };
  }
}

const book = new OrderBook();
book.addOrder({ id: 'S1', side: 'sell', type: 'limit', price: 105, quantity: 100, timestamp: 1 });
book.addOrder({ id: 'S2', side: 'sell', type: 'limit', price: 103, quantity: 50, timestamp: 2 });
book.addOrder({ id: 'B1', side: 'buy', type: 'limit', price: 100, quantity: 80, timestamp: 3 });

const spread = book.getSpread();
console.log(`买一: ${spread?.bid}, 卖一: ${spread?.ask}, 价差: ${spread?.spread}`);

const trades = book.addOrder({ id: 'B2', side: 'buy', type: 'market', price: 999, quantity: 60, timestamp: 4 });
trades.forEach((t) => console.log(`成交: ${t.quantity}@${t.price}`));
做市商与流动性
做市商是金融市场中提供流动性的关键角色——他们同时挂出买入和卖出报价，从买卖价差中获利。

做市商的核心盈利模式是"赚价差，控风险"。但当市场剧烈波动时，做市商面临逆向选择风险——与信息交易者交易会导致系统性亏损。


市场微观结构
市场微观结构研究交易机制如何影响价格形成过程：


interface MarketMetrics {
  bidAskSpread: number;
  depth: number;
  volatility: number;
  volume: number;
}

interface LiquidityScore {
  score: number;
  grade: string;
  tradingCost: number;
}

const assessLiquidity = (metrics: MarketMetrics): LiquidityScore => {
  const spreadScore = Math.max(0, 100 - metrics.bidAskSpread * 1000);
  const depthScore = Math.min(100, (metrics.depth / 1000) * 100);
  const volumeScore = Math.min(100, (metrics.volume / 10000) * 100);
  const volatilityPenalty = metrics.volatility * 200;

  const score = Math.round(spreadScore * 0.4 + depthScore * 0.3 + volumeScore * 0.2 - volatilityPenalty * 0.1);

  let grade: string;
  if (score > 80) grade = 'A: 高流动性';
  else if (score > 60) grade = 'B: 良好流动性';
  else if (score > 40) grade = 'C: 中等流动性';
  else grade = 'D: 低流动性';

  const tradingCost = metrics.bidAskSpread / 2 + metrics.volatility * 0.1;

  return {
    score: Math.max(0, Math.min(100, score)),
    grade,
    tradingCost: Math.round(tradingCost * 10000) / 100,
  };
};

const appleStock: MarketMetrics = { bidAskSpread: 0.01, depth: 5000, volatility: 0.02, volume: 50000 };
const smallCap: MarketMetrics = { bidAskSpread: 0.05, depth: 200, volatility: 0.08, volume: 500 };

console.log('AAPL:', assessLiquidity(appleStock));
console.log('小盘股:', assessLiquidity(smallCap));
价格发现的过程涉及信息交易者和噪声交易者的互动——信息交易者将私有信息纳入价格，噪声交易者提供流动性但交易无信息含量。市场效率取决于两者的比例和交互方式。

2010 年的"闪电崩盘"和 2021 年的 GameStop 事件都暴露了市场结构中的脆弱性——高频交易放大波动、社交媒体驱动的散户协调行为挑战了传统监管框架。


小结
    

  • 金融市场通过价格发现和资源配置实现资金从低效到高效用途的转移
    • 

  • 电子撮合引擎是现代交易所的核心，基于价格优先、时间优先原则匹配订单
    • 

  • 做市商提供流动性并从买卖价差获利，是市场正常运转的关键角色
    • 

  • 市场微观结构研究交易机制如何影响价格形成，对系统设计有重要启示
    • 

  • 金融监管在市场效率和稳定性之间寻找平衡，技术系统是实现监管的基础设施
