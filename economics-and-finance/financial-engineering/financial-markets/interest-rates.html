利率理论

核心概念

利率是资金的时间价值——借用资金需要支付的价格。利率是金融体系中最基础的变量，几乎所有金融资产的定价都直接或间接依赖于利率。理解利率理论对程序员的意义在于：它是理解房贷、投资回报、公司估值和宏观经济的钥匙。

货币的时间价值
"今天的一元钱比明天的一元钱更值钱"——这是金融学最基本的原理。时间价值的三个来源：通胀侵蚀购买力、机会成本和风险补偿。


interface TimeValueCalculation {
  presentValue: number;
  futureValue: number;
  rate: number;
  periods: number;
}

const futureValue = (pv: number, rate: number, periods: number): number => pv * Math.pow(1 + rate, periods);

const presentValue = (fv: number, rate: number, periods: number): number => fv / Math.pow(1 + rate, periods);

const annuityPV = (payment: number, rate: number, periods: number): number =>
  (payment * (1 - Math.pow(1 + rate, -periods))) / rate;

const annuityFV = (payment: number, rate: number, periods: number): number =>
  (payment * (Math.pow(1 + rate, periods) - 1)) / rate;

console.log('货币时间价值计算:');
console.log(`今天的10万, 5%利率, 10年后: ¥${futureValue(100000, 0.05, 10).toFixed(0)}`);
console.log(`10年后的10万, 5%利率, 今天值: ¥${presentValue(100000, 0.05, 10).toFixed(0)}`);
console.log(`每月存2000, 8%年化, 20年后: ¥${annuityFV(2000, 0.08 / 12, 240).toFixed(0)}`);

const mortgagePayment = (principal: number, annualRate: number, years: number): number => {
  const monthlyRate = annualRate / 12;
  const months = years * 12;
  return (principal * monthlyRate * Math.pow(1 + monthlyRate, months)) / (Math.pow(1 + monthlyRate, months) - 1);
};

const monthly = mortgagePayment(1000000, 0.04, 30);

interface YieldCurve {
  tenors: number[];
  yields: number[];
}

const analyzeYieldCurve = (
  curve: YieldCurve,
): {
  shape: string;
  spread10y2y: number;
  recessionSignal: boolean;
  forwardRate: number;
} => {
  const idx2y = curve.tenors.indexOf(2);
  const idx10y = curve.tenors.indexOf(10);
  const spread = curve.yields[idx10y] - curve.yields[idx2y];

  let shape: string;
  if (spread > 0.5) shape = '正常（陡峭）';
  else if (spread > 0) shape = '正常（平缓）';
  else if (spread > -0.5) shape = '轻微倒挂';
  else shape = '深度倒挂';

  const y1 = curve.yields[curve.tenors.indexOf(1)];
  const y2 = curve.yields[idx2y];
  const forwardRate = ((1 + y2) * (1 + y2)) / (1 + y1) - 1;

  return {
    shape,
    spread10y2y: Math.round(spread * 100),
    recessionSignal: spread < 0,
    forwardRate: Math.round(forwardRate * 10000) / 100,
  };
};

const currentCurve: YieldCurve = {
  tenors: [0.25, 0.5, 1, 2, 3, 5, 7, 10, 20, 30],
  yields: [5.3, 5.2, 4.8, 4.5, 4.3, 4.2, 4.2, 4.3, 4.5, 4.5].map((y) => y / 100),
};

const analysis = analyzeYieldCurve(currentCurve);
console.log(`曲线形态: ${analysis.shape}`);
console.log(`10Y-2Y利差: ${analysis.spread10y2y}bp`);
console.log(`衰退信号: ${analysis.recessionSignal}`);
console.log(`1年后1年远期利率: ${analysis.forwardRate}%`);

interface Bond {
  faceValue: number;
  couponRate: number;
  maturity: number;
  ytm: number;
  frequency: number;
}

const calculateBondMetrics = (
  bond: Bond,
): {
  price: number;
  macaulayDuration: number;
  modifiedDuration: number;
  convexity: number;
} => {
  const { faceValue, couponRate, maturity, ytm, frequency } = bond;
  const coupon = (faceValue * couponRate) / frequency;
  const n = maturity * frequency;
  const r = ytm / frequency;

  let price = 0;
  let weightedTime = 0;
  let convexitySum = 0;

  for (let t = 1; t <= n; t++) {
    const cf = t === n ? coupon + faceValue : coupon;
    const pvCf = cf / Math.pow(1 + r, t);
    price += pvCf;
    weightedTime += (t / frequency) * pvCf;
    convexitySum += t * (t + 1) * pvCf;
  }

  const macaulayDuration = weightedTime / price;
  const modifiedDuration = macaulayDuration / (1 + r);
  const convexity = convexitySum / (price * frequency * frequency * Math.pow(1 + r, 2));

  return {
    price: Math.round(price * 100) / 100,
    macaulayDuration: Math.round(macaulayDuration * 100) / 100,
    modifiedDuration: Math.round(modifiedDuration * 100) / 100,
    convexity: Math.round(convexity * 100) / 100,
  };
};

const bond10y: Bond = { faceValue: 1000, couponRate: 0.04, maturity: 10, ytm: 0.045, frequency: 2 };
const metrics = calculateBondMetrics(bond10y);
console.log(`价格: $${metrics.price}`);
console.log(`麦考利久期: ${metrics.macaulayDuration}年`);
console.log(`修正久期: ${metrics.modifiedDuration}`);
console.log(`利率上升1%时价格变化: ${(-metrics.modifiedDuration * 1).toFixed(2)}%`);
利率与程序员的日常
利率看似抽象，但深刻影响程序员的财务生活：


    

  • 房贷：利率从3%升到5%，100万30年贷款月供从4216增加到5368，总利息多付41万
    • 

  • 股票估值：利率上升→成长股折现率上升→估值下降→科技股暴跌
    • 

  • VC 融资：低利率时代资金充裕、估值宽松；高利率时代融资困难、估值紧缩
    • 

  • 储蓄收益：高利率环境中现金管理更重要，货币基金收益显著
    • 



小结
    

  • 利率是资金的时间价值，是所有金融资产定价的基础变量
    • 

  • 时间价值计算（复利、现值、年金）是每个人都需要掌握的基本金融工具
    • 

  • 收益率曲线倒挂是最可靠的衰退预警信号之一
    • 

  • 久期衡量利率风险，久期越长对利率变化越敏感
    • 

  • 利率通过房贷成本、股票估值和融资环境直接影响程序员的财务状况
    •
