固定收益证券

核心概念

固定收益证券是承诺在未来按照预定条件支付现金流的金融工具，最典型的代表是债券。与股票不同，债券持有者是债权人而非所有者，收益相对确定但上限有限。对程序员而言，理解固定收益是构建投资组合、理解利率传导和设计金融系统的基础。

债券定价基础
债券价格等于所有未来现金流的现值之和：


interface BondCashFlow {
  time: number;
  amount: number;
}

const priceBond = (cashFlows: BondCashFlow[], discountRate: number): number =>
  cashFlows.reduce((sum, cf) => sum + cf.amount / Math.pow(1 + discountRate, cf.time), 0);

const generateCouponBondCFs = (
  faceValue: number,
  couponRate: number,
  maturity: number,
  frequency: number = 2,
): BondCashFlow[] => {
  const cfs: BondCashFlow[] = [];
  const coupon = (faceValue * couponRate) / frequency;
  const periods = maturity * frequency;

  for (let t = 1; t <= periods; t++) {
    const time = t / frequency;
    const amount = t === periods ? coupon + faceValue : coupon;
    cfs.push({ time, amount });
  }
  return cfs;
};

const bondCFs = generateCouponBondCFs(1000, 0.05, 5);
const scenarios = [0.03, 0.04, 0.05, 0.06, 0.07];

console.log('5年期5%息票债券定价:');
scenarios.forEach((rate) => {
  const price = priceBond(bondCFs, rate / 2);
  const premium = price > 1000 ? '溢价' : price < 1000 ? '折价' : '平价';
  console.log(`  YTM=${(rate * 100).toFixed(0)}%: $${price.toFixed(2)} (${premium})`);
});

信用风险与信用评级
信用风险是债券发行人无法按时足额偿付本息的风险。信用评级机构（穆迪、标普、惠誉）对发行人的信用状况进行评级。


interface CreditAnalysis {
  rating: string;
  defaultProbability: number;
  spreadBps: number;
  recoveryRate: number;
  expectedLoss: number;
}

const creditMetrics: CreditAnalysis[] = [
  { rating: 'AAA', defaultProbability: 0.0001, spreadBps: 30, recoveryRate: 0.6, expectedLoss: 0 },
  { rating: 'AA', defaultProbability: 0.0005, spreadBps: 50, recoveryRate: 0.55, expectedLoss: 0 },
  { rating: 'A', defaultProbability: 0.001, spreadBps: 80, recoveryRate: 0.5, expectedLoss: 0.0005 },
  { rating: 'BBB', defaultProbability: 0.005, spreadBps: 150, recoveryRate: 0.45, expectedLoss: 0.003 },
  { rating: 'BB', defaultProbability: 0.02, spreadBps: 300, recoveryRate: 0.4, expectedLoss: 0.012 },
  { rating: 'B', defaultProbability: 0.06, spreadBps: 500, recoveryRate: 0.35, expectedLoss: 0.039 },
  { rating: 'CCC', defaultProbability: 0.15, spreadBps: 1000, recoveryRate: 0.25, expectedLoss: 0.113 },
];

creditMetrics.forEach((c) => {
  c.expectedLoss = c.defaultProbability * (1 - c.recoveryRate);
});

creditMetrics.forEach((c) => {
  console.log(
    `${c.rating}: 违约率=${(c.defaultProbability * 100).toFixed(2)}%, 利差=${c.spreadBps}bp, 预期损失=${(c.expectedLoss * 100).toFixed(3)}%`,
  );
});
信用利差是企业债与同期限国债的收益率之差，反映了市场对信用风险的定价。信用利差的扩大通常预示经济放缓或金融市场压力增大。

interface LadderPortfolio {
  maturities: number[];
  allocation: number[];
  yields: number[];
  portfolioYield: number;
  averageDuration: number;
}

const buildBondLadder = (
  totalInvestment: number,
  maxMaturity: number,
  yieldCurve: Map<number, number>,
): LadderPortfolio => {
  const maturities: number[] = [];
  const allocation: number[] = [];
  const yields: number[] = [];

  for (let m = 1; m <= maxMaturity; m++) {
    maturities.push(m);
    allocation.push(totalInvestment / maxMaturity);
    yields.push(yieldCurve.get(m) ?? 0.04);
  }

  const portfolioYield = yields.reduce((sum, y) => sum + y, 0) / yields.length;
  const averageDuration = maturities.reduce((sum, m) => sum + m, 0) / maturities.length;

  return { maturities, allocation, yields, portfolioYield, averageDuration };
};

const yieldCurve = new Map<number, number>([
  [1, 0.045],
  [2, 0.044],
  [3, 0.043],
  [5, 0.042],
  [7, 0.043],
  [10, 0.044],
]);

const ladder = buildBondLadder(1000000, 5, yieldCurve);
console.log(`组合收益率: ${(ladder.portfolioYield * 100).toFixed(2)}%`);
console.log(`平均久期: ${ladder.averageDuration}年`);
ladder.maturities.forEach((m, i) => {
  console.log(`  ${m}年: ¥${ladder.allocation[i]}, 收益率 ${(ladder.yields[i] * 100).toFixed(1)}%`);
});
结构化产品
资产证券化将贷款池转化为可交易的证券，是现代金融的重要创新。MBS（抵押贷款支持证券）和 ABS（资产支持证券）是主要类型。


2008 年金融危机的根源之一就是 MBS 的过度复杂化和风险错配——底层资产质量恶化，但评级机构和投资者未能充分认识风险。这提醒我们：金融工程的创新需要与风险管理同步。


小结
    

  • 债券价格等于未来现金流的现值之和，与市场利率成反比
    • 

  • 信用评级和信用利差是衡量债券信用风险的核心指标
    • 

  • 梯形策略通过分散到期时间降低再投资风险，适合大多数保守投资者
    • 

  • 结构化产品是金融工程的重要应用，但需要充分理解底层资产的风险
    • 

  • 固定收益投资是投资组合的稳定器，与股票形成互补配置
    •
