股票估值

核心概念

股票估值是确定公司内在价值的过程，帮助投资者判断股票价格是否合理。估值方法分为绝对估值（基于现金流折现）和相对估值（基于可比公司倍数）两大类。对程序员而言，理解估值不仅有助于投资决策，更有助于理解公司期权价值、创业融资估值和行业分析。

DCF 现金流折现模型
DCF 是理论上最完善的估值方法：公司价值等于未来所有自由现金流的现值之和。


interface DCFInput {
  freeCashFlows: number[];
  terminalGrowthRate: number;
  wacc: number;
  sharesOutstanding: number;
  netDebt: number;
}

interface DCFResult {
  enterpriseValue: number;
  equityValue: number;
  perShareValue: number;
  terminalValue: number;
  terminalValuePercent: number;
}

const dcfValuation = (input: DCFInput): DCFResult => {
  const { freeCashFlows, terminalGrowthRate, wacc, sharesOutstanding, netDebt } = input;
  let pvFCFs = 0;

  for (let t = 0; t < freeCashFlows.length; t++) {
    pvFCFs += freeCashFlows[t] / Math.pow(1 + wacc, t + 1);
  }

  const lastFCF = freeCashFlows[freeCashFlows.length - 1];
  const terminalFCF = lastFCF * (1 + terminalGrowthRate);
  const terminalValue = terminalFCF / (wacc - terminalGrowthRate);
  const pvTerminal = terminalValue / Math.pow(1 + wacc, freeCashFlows.length);

  const enterpriseValue = pvFCFs + pvTerminal;
  const equityValue = enterpriseValue - netDebt;
  const perShareValue = equityValue / sharesOutstanding;

  return {
    enterpriseValue: Math.round(enterpriseValue),
    equityValue: Math.round(equityValue),
    perShareValue: Math.round(perShareValue * 100) / 100,
    terminalValue: Math.round(pvTerminal),
    terminalValuePercent: Math.round((pvTerminal / enterpriseValue) * 100),
  };
};

const techCompany: DCFInput = {
  freeCashFlows: [500, 600, 720, 850, 1000],
  terminalGrowthRate: 0.03,
  wacc: 0.1,
  sharesOutstanding: 1000,
  netDebt: 2000,
};

const result = dcfValuation(techCompany);
console.log(`企业价值: $${result.enterpriseValue}M`);
console.log(`股权价值: $${result.equityValue}M`);
console.log(`每股价值: $${result.perShareValue}`);
console.log(`终值占比: ${result.terminalValuePercent}%`);
DCF 对假设极其敏感——WACC 变化 1% 或增长率变化 1% 都可能导致估值变化 20-30%。这也是为什么科技公司估值分歧往往很大。


相对估值与可比分析
interface ComparableCompany {
  name: string;
  marketCap: number;
  revenue: number;
  earnings: number;
  ebitda: number;
  growth: number;
}

interface MultiplesAnalysis {
  pe: number;
  ps: number;
  evEbitda: number;
  peg: number;
}

const calculateMultiples = (company: ComparableCompany): MultiplesAnalysis => ({
  pe: company.earnings > 0 ? company.marketCap / company.earnings : Infinity,
  ps: company.marketCap / company.revenue,
  evEbitda: company.ebitda > 0 ? company.marketCap / company.ebitda : Infinity,
  peg:
    company.earnings > 0 && company.growth > 0
      ? company.marketCap / company.earnings / (company.growth * 100)
      : Infinity,
});

const comps: ComparableCompany[] = [
  { name: 'SaaS-A', marketCap: 5000, revenue: 500, earnings: 50, ebitda: 100, growth: 0.25 },
  { name: 'SaaS-B', marketCap: 8000, revenue: 600, earnings: 80, ebitda: 150, growth: 0.3 },
  { name: 'SaaS-C', marketCap: 3000, revenue: 400, earnings: 30, ebitda: 80, growth: 0.2 },
];

const allMultiples = comps.map((c) => ({ name: c.name, ...calculateMultiples(c) }));
allMultiples.forEach((m) => {
  console.log(`${m.name}: P/E=${m.pe.toFixed(1)}x, P/S=${m.ps.toFixed(1)}x, PEG=${m.peg.toFixed(2)}`);
});

const medianPS = [...allMultiples].sort((a, b) => a.ps - b.ps)[1].ps;
const targetRevenue = 450;
const impliedValue = medianPS * targetRevenue;
console.log(`\n目标公司(收入${targetRevenue}M)估值: $${impliedValue.toFixed(0)}M (中位P/S=${medianPS.toFixed(1)}x)`);

对持有公司期权的程序员来说，理解估值方法有助于评估期权的潜在价值——但要记住，80% 的创业公司期权最终价值为零。


WACC 与折现率
加权平均资本成本（WACC）是 DCF 中最关键的参数之一，反映了公司融资的综合成本：


interface WACCInput {
  equityRatio: number;
  debtRatio: number;
  costOfEquity: number;
  costOfDebt: number;
  taxRate: number;
}

const calculateWACC = (input: WACCInput): number =>
  input.equityRatio * input.costOfEquity + input.debtRatio * input.costOfDebt * (1 - input.taxRate);

const capmCostOfEquity = (riskFreeRate: number, beta: number, marketPremium: number): number =>
  riskFreeRate + beta * marketPremium;

const techBeta = 1.3;
const costOfEquity = capmCostOfEquity(0.04, techBeta, 0.06);
const wacc = calculateWACC({
  equityRatio: 0.8,
  debtRatio: 0.2,
  costOfEquity,
  costOfDebt: 0.05,
  taxRate: 0.25,
});

console.log(`股权成本: ${(costOfEquity * 100).toFixed(2)}%`);
console.log(`WACC: ${(wacc * 100).toFixed(2)}%`);
小结
    

  • DCF 是理论上最完善的估值方法，但对假设极其敏感
    • 

  • 相对估值通过可比公司倍数快速估算价值，适合横向比较
    • 

  • 科技公司估值需要考虑高增长、无形资产和赢家通吃效应等特殊因素
    • 

  • WACC 是折现率的核心，反映了公司的融资成本和系统性风险
    • 

  • 持有期权的程序员应理解估值基础，理性评估期权的预期价值
