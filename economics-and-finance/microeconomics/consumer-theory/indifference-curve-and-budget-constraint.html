无差异曲线与预算约束

核心概念

无差异曲线和预算约束是消费者选择理论的两大支柱。无差异曲线表示消费者的偏好结构——给予相同满足感的商品组合；预算约束则表示消费者的购买能力限制。两者结合，就能确定消费者的最优选择。

偏好公理与无差异曲线性质
消费者选择理论建立在三个基本偏好假设之上：


完备性：消费者能对任意两个商品组合做出偏好判断——更偏好 A、更偏好 B 或两者无差异。


传递性：如果偏好 A 胜于 B，B 胜于 C，则 A 胜于 C。这保证了偏好排序的一致性。


单调性（越多越好）：在其他商品不变的情况下，更多的某种商品总是更好的。


由这些假设可以推导出无差异曲线的四个关键性质：


无差异曲线向右下方倾斜——增加一种商品的同时必须减少另一种才能保持效用不变。无差异曲线不能相交——否则违反传递性。远离原点的无差异曲线代表更高的效用水平。无差异曲线凸向原点——反映边际替代率递减。


边际替代率（MRS）衡量消费者愿意用一种商品替换另一种商品的比率。MRS 递减意味着消费者拥有越多的 X 商品，就越不愿意用 Y 来换取更多的 X。这与边际效用递减一致：MRS = MUx / MUy。


特殊偏好类型
不同类型的偏好产生不同形状的无差异曲线，对最优选择的分析方式也各有不同：


完全替代品：两种商品能以固定比率相互替换，无差异曲线是斜率恒定的直线。MRS 不变，消费者在任何消费点上的替换意愿相同。最优解通常是角点解——消费者只购买性价比更高的那种商品。只有当预算线斜率恰好等于无差异曲线斜率时，预算线上的所有点都是最优点。


完全互补品：两种商品必须按固定比例搭配使用，无差异曲线呈 L 形。多出来的任何一种商品都不增加效用。最优选择总是位于 L 形的拐角处——恰好是两种商品按比例消费的点。左鞋和右鞋、眼镜框和镜片是典型的完全互补品。


拟线性偏好：对其中一种商品（通常是"货币"或计量单位商品）而言，效用函数是线性的，即 U(x,y)=v(x)+yU(x, y) = v(x) + yU(x,y)=v(x)+y。无差异曲线是平行的——纵向距离恒定。这意味着收入变化只影响 y 的消费量，不影响 x 的需求。拟线性偏好在分析部分均衡中非常方便，因为它消除了收入效应。

预算约束
预算约束描述了消费者在给定收入和价格下能够购买的所有商品组合。对于两种商品 X 和 Y：


Px × X + Py × Y = M（收入）


在坐标系中，预算线是一条斜率为 -Px/Py 的直线。X 轴截距为 M/Px（全部收入购买 X 的数量），Y 轴截距为 M/Py（全部收入购买 Y 的数量）。


收入变化使预算线平行移动：收入增加向外移，减少向内移。价格变化改变预算线斜率：Px 上升使 X 轴截距向内移（预算线顺时针旋转）。


预算线以内的区域是消费者的可行集——所有能够负担的商品组合。预算线上的点恰好用完全部收入。理性消费者不会选择预算线以内的点（没有花完钱），除非存在储蓄动机。


现实中预算约束往往比简单直线更复杂。数量折扣会使预算线在折扣起点处出现折点，斜率变得更平坦。配额限制会在某个消费量处截断预算线。税收和补贴会改变有效价格，从而改变预算线的斜率——累进税制下，预算线可能呈分段线性形状。实物补贴（如食品券）创造了非线性预算约束：补贴商品的消费量在某个阈值以下免费，超出部分恢复市场价格。


消费者最优选择
消费者的目标是在预算约束内达到尽可能高的无差异曲线。最优选择位于预算线与无差异曲线的切点——此处预算线的斜率等于无差异曲线的斜率。


最优条件：MRS = Px / Py


即消费者的主观替换率等于市场的客观替换率。如果 MRS > Px/Py，消费者对 X 的主观估值高于市场价格比率，应增加 X 的消费。反之则减少 X 的消费。只有在切点处，消费者没有进一步调整的动机。


这一条件等价于等边际原则：MUx/Px = MUy/Py。因为 MRS = MUx/MUy，所以 MUx/MUy = Px/Py 即 MUx/Px = MUy/Py。


角点解出现在某种商品的消费量为零时——当消费者的偏好非常偏向一种商品，或两种商品的相对价格极端时。此时切线条件不成立，需要用比较边界效用来判断最优。


在多商品情况下（n 种商品），最优条件推广为所有商品的边际效用与价格之比相等：MU1/P1=MU2/P2=…=MUn/Pn=λMU_1/P_1 = MU_2/P_2 = \ldots = MU_n/P_n = \lambdaMU1​/P1​=MU2​/P2​=…=MUn​/Pn​=λ，其中 λ\lambdaλ 是收入的边际效用（拉格朗日乘子），表示额外一单位收入所能带来的最大效用增加。


小结
    

  • 无差异曲线将偏好结构可视化，其斜率（MRS）衡量消费者的主观替换意愿
    • 

  • MRS 递减反映边际效用递减，使无差异曲线凸向原点
    • 

  • 特殊偏好（完全替代、完全互补、拟线性）产生非标准形状的无差异曲线和不同的求解方式
    • 

  • 预算约束由收入和价格决定，限定了消费者的可行选择范围
    • 

  • 最优消费点位于预算线与最高可达无差异曲线的切点
    • 

  • 切线条件 MRS = Px/Py 等价于等边际原则 MUx/Px = MUy/Py
    • 

  • 多商品情况下，拉格朗日乘子 λ\lambdaλ 衡量收入的边际效用
