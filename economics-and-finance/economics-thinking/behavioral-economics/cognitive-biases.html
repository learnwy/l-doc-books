认知偏差

核心概念

认知偏差是人类在信息处理和决策过程中系统性偏离理性的思维模式。行为经济学揭示了人们并非传统经济学假设的"完全理性人"，而是依赖启发式（心理捷径）做决策，这些捷径在大多数情况下有效，但在特定场景中会产生可预测的错误。对程序员而言，理解认知偏差有助于设计更好的用户界面、避免项目管理陷阱和做出更理性的技术决策。

双系统理论（卡尼曼）将思维分为快系统（直觉、自动、低耗能）和慢系统（分析、刻意、高耗能）。大多数认知偏差源于快系统的过度使用。


锚定效应与估算偏差
锚定效应是最普遍也最难避免的偏差之一：人们的数值判断会被先接触到的数字（锚点）强烈影响，即使这个数字与问题无关。


interface EstimationExperiment {
  task: string;
  anchor: number;
  estimates: number[];
  actualValue: number;
}

const analyzeAnchoringBias = (
  experiment: EstimationExperiment,
): { meanEstimate: number; anchorEffect: number; accuracy: number } => {
  const mean = experiment.estimates.reduce((s, v) => s + v, 0) / experiment.estimates.length;
  const anchorEffect = Math.abs(mean - experiment.actualValue) / experiment.actualValue;
  const accuracy = 1 - anchorEffect;

  return {
    meanEstimate: Math.round(mean),
    anchorEffect: Math.round(anchorEffect * 100),
    accuracy: Math.round(accuracy * 100),
  };
};

const sprintEstimation: EstimationExperiment = {
  task: 'API 重构项目估时',
  anchor: 2,
  estimates: [3, 2.5, 4, 3, 2],
  actualValue: 8,
};

const result = analyzeAnchoringBias(sprintEstimation);
console.log(`平均估时: ${result.meanEstimate}周（实际${sprintEstimation.actualValue}周）`);
console.log(`锚定偏差: ${result.anchorEffect}%`);
console.log(`估算准确度: ${result.accuracy}%`);

确认偏差与技术决策
确认偏差导致人们选择性地寻找、解读和记忆支持自己已有观点的信息。在技术决策中，这可能导致固守错误的技术路线。


interface TechEvaluation {
  technology: string;
  pros: string[];
  cons: string[];
  confirmedBias: boolean;
}

const debiasedEvaluation = (
  techs: TechEvaluation[],
): Array<{ tech: string; proConRatio: number; biasWarning: string }> => {
  return techs.map((t) => {
    const ratio = t.pros.length / Math.max(t.cons.length, 1);
    let biasWarning: string;

    if (ratio > 3) {
      biasWarning = '可能存在确认偏差：优点远多于缺点，建议主动寻找反面证据';
    } else if (ratio < 0.5) {
      biasWarning = '可能存在否定偏差：过度关注缺点，建议重新审视优势';
    } else {
      biasWarning = '评估相对均衡';
    }

    return {
      tech: t.technology,
      proConRatio: Math.round(ratio * 10) / 10,
      biasWarning,
    };
  });
};

const evaluations: TechEvaluation[] = [
  {
    technology: 'React',
    pros: ['生态丰富', '社区活跃', '工作机会多', '性能好', '文档完善'],
    cons: ['状态管理复杂'],
    confirmedBias: true,
  },
  {
    technology: 'Svelte',
    pros: ['编译时优化', '代码量少'],
    cons: ['生态小', '招聘难', '企业采用少', '工具链不成熟'],
    confirmedBias: true,
  },
];

const results = debiasedEvaluation(evaluations);
results.forEach((r) => {
  console.log(`${r.tech}: 优劣比=${r.proConRatio}, ${r.biasWarning}`);
});

沉没成本谬误与项目管理
沉没成本谬误是指因为已经投入了不可收回的成本而继续投入资源，即使理性分析显示应该停止。在软件开发中，这是最常见也最昂贵的偏差之一。

interface ProjectDecision {
  projectName: string;
  sunkCost: number;
  futureCostIfContinue: number;
  futureValueIfContinue: number;
  futureCostIfAbandon: number;
  futureValueIfAbandon: number;
}

const rationalDecision = (project: ProjectDecision): { recommendation: 'continue' | 'abandon'; reasoning: string } => {
  const netContinue = project.futureValueIfContinue - project.futureCostIfContinue;
  const netAbandon = project.futureValueIfAbandon - project.futureCostIfAbandon;

  const recommendation = netContinue > netAbandon ? 'continue' : 'abandon';
  const reasoning = `继续净值: ¥${netContinue}, 放弃净值: ¥${netAbandon}（沉没成本¥${project.sunkCost}不纳入考量）`;

  return { recommendation, reasoning };
};

const legacyRewrite: ProjectDecision = {
  projectName: '旧系统重写',
  sunkCost: 500000,
  futureCostIfContinue: 800000,
  futureValueIfContinue: 600000,
  futureCostIfAbandon: 200000,
  futureValueIfAbandon: 300000,
};

const decision = rationalDecision(legacyRewrite);
console.log(`${legacyRewrite.projectName}: ${decision.recommendation}`);
console.log(decision.reasoning);
可得性偏差与风险评估
可得性偏差导致人们根据容易想到的例子来估计事件的频率和概率。越生动、越近期的事件在记忆中越"可得"，会导致高估其发生概率。


在技术领域：


    

  • 最近发生的安全事件导致过度投资安全（忽略其他风险）
    • 

  • 媒体报道的技术趋势让人高估其成熟度
    • 

  • 个人经历中遇到的bug类型会被认为更常见
    • 



对抗可得性偏差需要用数据替代直觉——建立指标体系、定期审查数据、基于统计而非印象做决策。

小结
    

  • 认知偏差是可预测的系统性思维偏差，源于快速直觉系统的过度使用
    • 

  • 锚定效应导致估算偏差，对抗方法是使用多种独立估算方法交叉验证
    • 

  • 确认偏差使技术决策固化，需要红队思维和预验尸法来对抗
    • 

  • 沉没成本谬误是项目管理中最昂贵的偏差，理性决策只考虑未来成本和收益
    • 

  • 可得性偏差导致风险评估失真，数据驱动决策是最有效的对策
    •
