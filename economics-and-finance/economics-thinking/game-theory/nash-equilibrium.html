Part I · 思维与微观经济学思维 简介博弈论 简介纳什均衡

纳什均衡

核心概念

纳什均衡是博弈论中最重要的解概念：在一个策略组合中，如果每个参与者的策略都是对其他参与者策略的最优反应，则该策略组合构成纳什均衡。换言之，在纳什均衡中没有人有动机单方面改变自己的策略。这一概念由约翰·纳什在 1950 年提出，奠定了现代博弈论的基础。

纯策略纳什均衡
纯策略纳什均衡是指所有参与者都选择确定性策略（而非随机化）的均衡。寻找纯策略纳什均衡的方法是检查收益矩阵中的最优反应。


interface PayoffMatrix {
  rows: string[];
  cols: string[];
  payoffs: Array<Array<[number, number]>>;
}

interface NashEquilibrium {
  rowStrategy: string;
  colStrategy: string;
  payoff: [number, number];
}

const findPureNashEquilibria = (game: PayoffMatrix): NashEquilibrium[] => {
  const equilibria: NashEquilibrium[] = [];
  const { rows, cols, payoffs } = game;

  for (let i = 0; i < rows.length; i++) {
    for (let j = 0; j < cols.length; j++) {
      let rowBestResponse = true;
      for (let ii = 0; ii < rows.length; ii++) {
        if (payoffs[ii][j][0] > payoffs[i][j][0]) {
          rowBestResponse = false;
          break;
        }
      }

      let colBestResponse = true;
      for (let jj = 0; jj < cols.length; jj++) {
        if (payoffs[i][jj][1] > payoffs[i][j][1]) {
          colBestResponse = false;
          break;
        }
      }

      if (rowBestResponse && colBestResponse) {
        equilibria.push({
          rowStrategy: rows[i],
          colStrategy: cols[j],
          payoff: payoffs[i][j],
        });
      }
    }
  }

  return equilibria;
};

const battleOfSexes: PayoffMatrix = {
  rows: ['技术A', '技术B'],
  cols: ['技术A', '技术B'],
  payoffs: [
    [
      [3, 2],
      [0, 0],
    ],
    [
      [0, 0],
      [2, 3],
    ],
  ],
};

const equilibria = findPureNashEquilibria(battleOfSexes);
equilibria.forEach((eq) => {
  console.log(`均衡: (${eq.rowStrategy}, ${eq.colStrategy}), 收益: ${eq.payoff}`);
});
技术标准竞争中的多重均衡问题：当两个团队都选择技术 A 或都选择技术 B 时达到均衡，但选择不一致则两败俱伤。这解释了为什么技术标准的制定需要协调机制（如标准化组织 W3C、IEEE）。

混合策略纳什均衡
当不存在纯策略纳什均衡时，参与者可以通过随机化策略来达到均衡。混合策略为每个纯策略分配一个概率，使得对手在面对这个随机化时无法通过改变策略获利。


interface MixedEquilibrium {
  player1Probs: Map<string, number>;
  player2Probs: Map<string, number>;
  expectedPayoff: [number, number];
}

const solveMixedEquilibrium2x2 = (game: PayoffMatrix): MixedEquilibrium | null => {
  const [[a11, a12], [a21, a22]] = [
    [game.payoffs[0][0][0], game.payoffs[0][1][0]],
    [game.payoffs[1][0][0], game.payoffs[1][1][0]],
  ];
  const [[b11, b12], [b21, b22]] = [
    [game.payoffs[0][0][1], game.payoffs[0][1][1]],
    [game.payoffs[1][0][1], game.payoffs[1][1][1]],
  ];

  const denomQ = b11 - b12 - b21 + b22;
  const denomP = a11 - a12 - a21 + a22;

  if (denomQ === 0 || denomP === 0) return null;

  const q = (b22 - b12) / denomQ;
  const p = (a22 - a12) / denomP;

  if (p < 0 || p > 1 || q < 0 || q > 1) return null;

  const ep1 = p * (q * a11 + (1 - q) * a12) + (1 - p) * (q * a21 + (1 - q) * a22);
  const ep2 = q * (p * b11 + (1 - p) * b21) + (1 - q) * (p * b12 + (1 - p) * b22);

  return {
    player1Probs: new Map([
      [game.rows[0], p],
      [game.rows[1], 1 - p],
    ]),
    player2Probs: new Map([
      [game.cols[0], q],
      [game.cols[1], 1 - q],
    ]),
    expectedPayoff: [Math.round(ep1 * 100) / 100, Math.round(ep2 * 100) / 100],
  };
};

const matchingPennies: PayoffMatrix = {
  rows: ['正面', '反面'],
  cols: ['正面', '反面'],
  payoffs: [
    [
      [1, -1],
      [-1, 1],
    ],
    [
      [-1, 1],
      [1, -1],
    ],
  ],
};

const mixed = solveMixedEquilibrium2x2(matchingPennies);
if (mixed) {
  mixed.player1Probs.forEach((prob, strategy) => {
    console.log(`玩家1 ${strategy}: ${(prob * 100).toFixed(0)}%`);
  });
  console.log(`期望收益: ${mixed.expectedPayoff}`);
}
混合策略在技术领域的应用：


    

  • 安全攻防：攻击者和防御者需要随机化策略，纯策略会被对方利用
    • 

  • A/B 测试：在不确定用户偏好时，随机分配实验组是混合策略的应用
    • 

  • 负载均衡：随机化请求分配是一种混合策略均衡

纳什均衡的效率与帕累托最优
纳什均衡不一定是帕累托最优的——存在能让所有人都更好的替代结果，但理性个体的自利行为阻止了更优结果的实现。






概念
定义
与纳什均衡的关系





帕累托最优
无法在不损害他人的前提下改善任何人
纳什均衡可能不是帕累托最优




帕累托改进
至少改善一人且不损害其他人
纳什均衡可能存在帕累托改进空间




社会最优
最大化所有人收益总和
纳什均衡通常低于社会最优




无效率度
Price of Anarchy
衡量均衡偏离最优的程度





interface EfficiencyAnalysis {
  nashPayoff: number;
  socialOptimum: number;
  priceOfAnarchy: number;
  inefficiencyPercent: number;
}

const analyzeEfficiency = (game: PayoffMatrix): EfficiencyAnalysis => {
  const equilibria = findPureNashEquilibria(game);

  let worstNashTotal = Infinity;
  let bestTotal = -Infinity;

  for (const eq of equilibria) {
    const total = eq.payoff[0] + eq.payoff[1];
    if (total < worstNashTotal) worstNashTotal = total;
  }

  for (const row of game.payoffs) {
    for (const cell of row) {
      const total = cell[0] + cell[1];
      if (total > bestTotal) bestTotal = total;
    }
  }

  const priceOfAnarchy = bestTotal / worstNashTotal;
  const inefficiency = ((bestTotal - worstNashTotal) / bestTotal) * 100;

  return {
    nashPayoff: worstNashTotal,
    socialOptimum: bestTotal,
    priceOfAnarchy: Math.round(priceOfAnarchy * 100) / 100,
    inefficiencyPercent: Math.round(inefficiency * 10) / 10,
  };
};

const prisonersDilemma: PayoffMatrix = {
  rows: ['合作', '背叛'],
  cols: ['合作', '背叛'],
  payoffs: [
    [
      [-1, -1],
      [-10, 0],
    ],
    [
      [0, -10],
      [-5, -5],
    ],
  ],
};

const efficiency = analyzeEfficiency(prisonersDilemma);
console.log(`纳什均衡总收益: ${efficiency.nashPayoff}`);
console.log(`社会最优总收益: ${efficiency.socialOptimum}`);
console.log(`无效率比: ${efficiency.priceOfAnarchy}`);
console.log(`效率损失: ${efficiency.inefficiencyPercent}%`);
理解纳什均衡的低效率性在系统设计中很重要。分布式系统中个体节点的自利行为可能导致全局低效，需要通过协议设计（机制设计）来引导个体行为趋向社会最优。


纳什均衡在技术战略中的应用
云服务定价博弈：AWS、Azure、GCP 之间的定价互动。每家都在博弈中寻找最优反应——降价吸引客户但压缩利润，维持高价但可能失去份额。最终的市场价格是三方博弈的纳什均衡。


开源与商业化博弈：公司在开源策略上面临博弈——完全开源吸引社区但难以盈利，完全闭源保护利润但失去社区。OpenCore 模式就是一种均衡策略。


网络安全攻防博弈：攻击者和防御者的策略互动。防御者不可能保护所有漏洞（成本太高），攻击者不会攻击防护最强的目标。纳什均衡决定了最优资源分配。


小结
    

  • 纳什均衡是每个参与者都在做最优反应的策略组合，是博弈论最核心的解概念
    • 

  • 纯策略均衡可能不存在、唯一或多重，多重均衡时需要协调机制
    • 

  • 混合策略均衡在安全攻防、负载均衡等场景中有实际应用
    • 

  • 纳什均衡可能不是帕累托最优的，无效率度量（Price of Anarchy）衡量了这种偏差
    • 

  • 技术战略中的定价、开源和安全决策都可以用纳什均衡框架来分析
    •
