不确定性下的决策

核心概念

现实中的决策几乎总是在不确定性下做出的——我们不知道市场会如何变化、竞争对手会如何反应、技术趋势会如何演进。不确定性决策理论提供了在信息不完全时做出理性选择的框架。对程序员而言，技术选型、创业决策、投资选择和项目优先级排序都是不确定性下的决策问题。

期望效用理论
冯·诺伊曼和摩根斯坦的期望效用理论是风险决策的标准框架。理性决策者应该最大化期望效用（而非期望收益），因为效用函数可以反映风险偏好。


type RiskAttitude = 'averse' | 'neutral' | 'seeking';

interface UtilityFunction {
  type: RiskAttitude;
  calculate: (wealth: number) => number;
}

const createUtilityFunction = (attitude: RiskAttitude): UtilityFunction => {
  const functions: Record<RiskAttitude, (w: number) => number> = {
    averse: (w) => Math.sqrt(w),
    neutral: (w) => w,
    seeking: (w) => (w * w) / 10000,
  };
  return { type: attitude, calculate: functions[attitude] };
};

interface Gamble {
  outcomes: Array<{ value: number; probability: number }>;
}

const expectedUtility = (gamble: Gamble, utilFn: UtilityFunction): number =>
  gamble.outcomes.reduce((sum, o) => sum + o.probability * utilFn.calculate(o.value), 0);

const certainEquivalent = (gamble: Gamble, utilFn: UtilityFunction, precision: number = 1): number => {
  const eu = expectedUtility(gamble, utilFn);
  for (let w = 0; w <= 1000000; w += precision) {
    if (utilFn.calculate(w) >= eu) return w;
  }
  return 0;
};

const startupGamble: Gamble = {
  outcomes: [
    { value: 1000000, probability: 0.1 },
    { value: 200000, probability: 0.3 },
    { value: 0, probability: 0.6 },
  ],
};

const stableJob: Gamble = {
  outcomes: [{ value: 300000, probability: 1.0 }],
};

const riskAverse = createUtilityFunction('averse');
const euStartup = expectedUtility(startupGamble, riskAverse);
const euJob = expectedUtility(stableJob, riskAverse);
const ce = certainEquivalent(startupGamble, riskAverse);

console.log(`创业期望效用: ${euStartup.toFixed(2)}`);
console.log(`稳定工作期望效用: ${euJob.toFixed(2)}`);
console.log(`创业的确定性等价: ¥${ce}`);
console.log(`决策: ${euStartup > euJob ? '创业' : '稳定工作'}`);
风险厌恶意味着人们偏好确定收入而非等额期望值的风险收入。确定性等价（Certainty Equivalent）是使决策者与风险方案无差异的确定金额——它总是低于期望值（对风险厌恶者）。

决策树与实物期权
决策树是在不确定性下做多阶段决策的可视化工具。它将复杂决策分解为一系列节点：决策节点（方形）、机会节点（圆形）和终端节点。


interface DecisionNode {
  type: 'decision' | 'chance' | 'terminal';
  name: string;
  value?: number;
  probability?: number;
  children?: DecisionNode[];
}

const evaluateDecisionTree = (node: DecisionNode): number => {
  if (node.type === 'terminal') {
    return node.value ?? 0;
  }

  if (node.type === 'chance') {
    return (node.children ?? []).reduce(
      (sum, child) => sum + (child.probability ?? 0) * evaluateDecisionTree(child),
      0,
    );
  }

  const childValues = (node.children ?? []).map((child) => ({
    name: child.name,
    value: evaluateDecisionTree(child),
  }));

  const best = childValues.reduce((max, c) => (c.value > max.value ? c : max));
  console.log(`${node.name}: 最优选择 = ${best.name} (期望值: ${best.value.toFixed(0)})`);
  return best.value;
};

const techDecision: DecisionNode = {
  type: 'decision',
  name: '技术选型',
  children: [
    {
      type: 'chance',
      name: '成熟技术(React)',
      children: [
        { type: 'terminal', name: '市场增长', value: 500000, probability: 0.6 },
        { type: 'terminal', name: '市场平稳', value: 300000, probability: 0.4 },
      ],
    },
    {
      type: 'chance',
      name: '新兴技术(AI Framework)',
      children: [
        { type: 'terminal', name: '成功采用', value: 1200000, probability: 0.3 },
        { type: 'terminal', name: '中等表现', value: 400000, probability: 0.4 },
        { type: 'terminal', name: '失败', value: -100000, probability: 0.3 },
      ],
    },
  ],
};

const optimalValue = evaluateDecisionTree(techDecision);
console.log(`最优策略期望值: ¥${optimalValue.toFixed(0)}`);
实物期权将金融期权的思想应用于实际决策：保留灵活性有价值。例如，先用小团队试验新技术（买入期权），成功后再大规模投入（行使期权），这比一次性全投入风险更小。


多准则决策与技术选型
现实决策通常涉及多个维度，不能仅凭单一指标。多准则决策分析（MCDA）提供了系统化的评估框架：


interface Alternative {
  name: string;
  scores: Record<string, number>;
}

interface Criterion {
  name: string;
  weight: number;
}

const weightedScoring = (
  alternatives: Alternative[],
  criteria: Criterion[],
): Array<{ name: string; totalScore: number; rank: number }> => {
  const results = alternatives.map((alt) => {
    const totalScore = criteria.reduce((sum, c) => sum + (alt.scores[c.name] ?? 0) * c.weight, 0);
    return { name: alt.name, totalScore: Math.round(totalScore * 100) / 100 };
  });

  results.sort((a, b) => b.totalScore - a.totalScore);
  return results.map((r, i) => ({ ...r, rank: i + 1 }));
};

const criteria: Criterion[] = [
  { name: '性能', weight: 0.25 },
  { name: '生态系统', weight: 0.2 },
  { name: '学习曲线', weight: 0.15 },
  { name: '招聘难度', weight: 0.2 },
  { name: '长期前景', weight: 0.2 },
];

const alternatives: Alternative[] = [
  { name: 'React + Node', scores: { 性能: 7, 生态系统: 9, 学习曲线: 7, 招聘难度: 8, 长期前景: 8 } },
  { name: 'Rust + WASM', scores: { 性能: 10, 生态系统: 5, 学习曲线: 3, 招聘难度: 3, 长期前景: 9 } },
  { name: 'Go + HTMX', scores: { 性能: 8, 生态系统: 6, 学习曲线: 8, 招聘难度: 6, 长期前景: 7 } },
];

const ranking = weightedScoring(alternatives, criteria);
ranking.forEach((r) => {
  console.log(`#${r.rank} ${r.name}: 综合得分 ${r.totalScore}`);
});

杰夫·贝索斯的"遗憾最小化框架"：想象自己 80 岁时回顾一生，哪个选择会让你遗憾最小？这正是遗憾最小化准则的直觉表达。对程序员而言，不尝试新技术/创业的遗憾可能大于尝试失败的遗憾。


小结
    

  • 不确定性决策是程序员日常面对的挑战，期望效用理论提供了风险下的理性决策框架
    • 

  • 风险态度通过效用函数形状体现，大多数人是风险厌恶的
    • 

  • 决策树和实物期权帮助结构化多阶段决策，保留灵活性本身有价值
    • 

  • 多准则决策分析将主观判断系统化，适用于技术选型等多维评估
    • 

  • 遗憾最小化框架在概率未知时提供了实用的决策准则
