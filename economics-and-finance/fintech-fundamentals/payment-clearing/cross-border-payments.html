跨境支付

核心概念

跨境支付是指资金在不同国家/地区的支付系统之间流转的过程。传统跨境支付依赖代理行（Correspondent Banking）网络，资金需要经过多个中间银行层层转接，导致成本高（手续费 3-7%）、速度慢（2-5 个工作日）和透明度低（发送方不知道资金到达时间和最终费用）。

金融科技正在从多个方向革新跨境支付：SWIFT gpi 提升了传统代理行网络的透明度和速度，Wise（原 TransferWise）通过本地对冲减少了实际跨境资金流动，Ripple 利用区块链实现了近实时的跨境结算。

代理行网络与 SWIFT
代理行（Correspondent Banking）模式是跨境支付的传统基础设施。当两家银行没有直接关系时，需要通过一家或多家共同的代理行来完成资金转移。SWIFT（环球银行金融电信协会）提供了银行间通信的标准化消息网络。


interface SWIFTMessage {
  messageType: string;
  senderBIC: string;
  receiverBIC: string;
  transactionRef: string;
  amount: MonetaryAmount;

  beneficiary: PartyDetails;

  value: number;
  currency: string;
}

  name: string;

  address: string;
  country: string;

  bic: string;
  name: string;

type ChargeType = 'OUR' | 'BEN' | 'SHA';

const estimateCorrespondentBankFees = (
  route: IntermediaryBank[],
  amount: MonetaryAmount,
  chargeType: ChargeType,
): {
  totalFees: number;
  feeBreakdown: Array<{ bank: string; fee: number }>;
  estimatedDays: number;
} => {
  const feeBreakdown = route.map((bank) => ({
    bank: bank.name,
    fee: calculateBankFee(amount.value, bank.role),
  }));

  const totalFees = feeBreakdown.reduce((sum, f) => sum + f.fee, 0);
  const estimatedDays = Math.max(1, route.length);

  return { totalFees, feeBreakdown, estimatedDays };
};

const calculateBankFee = (amount: number, role: string): number => {
  const feeRates: Record<string, number> = {
    sender_correspondent: 15,
    receiver_correspondent: 10,
    intermediary: 20,
  };
  return feeRates[role] ?? 15;
};

interface GpiTracker {
  uetr: string;
  status: 'accepted' | 'forwarded' | 'completed' | 'returned';
  statusHistory: Array<{
    timestamp: number;
    institution: string;
    status: string;
    amount: MonetaryAmount;
    charges: number;
  }>;
}

const trackGpiPayment = (
  tracker: GpiTracker,
): {
  totalTime: number;
  totalCharges: number;
  currentLocation: string;
  isComplete: boolean;
} => {
  const history = tracker.statusHistory;
  const totalTime = history.length > 1 ? history[history.length - 1].timestamp - history[0].timestamp : 0;

  const totalCharges = history.reduce((sum, h) => sum + h.charges, 0);
  const currentLocation = history[history.length - 1]?.institution ?? 'unknown';

  return {
    totalTime,
    totalCharges,
    currentLocation,
    isComplete: tracker.status === 'completed',
  };
};
SWIFT gpi（Global Payments Innovation）是对传统 SWIFT 网络的重大升级，引入了端到端支付追踪（UETR）、SLA 承诺和费用透明度，使得约 50% 的 gpi 支付在 30 分钟内到账。


新型跨境支付模型
金融科技公司开发了多种创新模型来解决传统跨境支付的痛点。


本地对冲模型（Wise 模式） 是最优雅的解决方案之一：Wise 在多个国家持有本地银行账户，当用户从 A 国汇款到 B 国时，资金不需要实际跨境——用户存入 A 国本地账户，Wise 从 B 国本地账户支付给收款人，通过内部账本对冲完成匹配。


interface LocalPoolModel {

interface CurrencyPool {

  country: string;

interface MatchOrder {
  id: string;
  fromCurrency: string;
  toCurrency: string;
  fromAmount: bigint;
  toAmount: bigint;
  exchangeRate: number;
  createdAt: number;
}

const matchOrders = (orders: MatchOrder[]): Array<{ order1: string; order2: string; matchedAmount: bigint }> => {
  const matches: Array<{ order1: string; order2: string; matchedAmount: bigint }> = [];

  const buyOrders = orders.filter((o) => o.fromCurrency < o.toCurrency);
  const sellOrders = orders.filter((o) => o.fromCurrency >= o.toCurrency);

  for (const buy of buyOrders) {
    for (const sell of sellOrders) {
      if (buy.fromCurrency === sell.toCurrency && buy.toCurrency === sell.fromCurrency) {
        const matchedAmount = buy.fromAmount < sell.toAmount ? buy.fromAmount : sell.toAmount;

        matches.push({
          order1: buy.id,
          order2: sell.id,
          matchedAmount,
        });
      }
    }
  }

  return matches;
};

const calculateSavings = (
  amount: number,
  traditionalFeePercent: number,
  traditionalFxMarkup: number,
  fintechFeePercent: number,
  fintechFxMarkup: number,
): { traditionalCost: number; fintechCost: number; savings: number; savingsPercent: number } => {
  const traditionalCost = amount * (traditionalFeePercent / 100) + amount * (traditionalFxMarkup / 100);
  const fintechCost = amount * (fintechFeePercent / 100) + amount * (fintechFxMarkup / 100);
  const savings = traditionalCost - fintechCost;

  return {
    traditionalCost,
    fintechCost,
    savings,
    savingsPercent: (savings / traditionalCost) * 100,
  };
};

区块链跨境支付
区块链技术为跨境支付提供了一种全新的范式：使用稳定币作为价值载体，通过区块链网络实现近实时、低成本的跨境资金转移，绕过传统代理行网络。


interface BlockchainPaymentRoute {
  sourceCountry: string;
  destinationCountry: string;
  onRamp: OnRampProvider;
  blockchain: string;
  stablecoin: string;
  offRamp: OffRampProvider;
  estimatedTime: number;
  totalFeePercent: number;
}

interface OnRampProvider {
  name: string;
  supportedCurrencies: string[];
  feePercent: number;
  kycLevel: 'basic' | 'enhanced' | 'full';
}

interface OffRampProvider {
  name: string;
  supportedCurrencies: string[];
  feePercent: number;
  settlementTime: number;
}

const findOptimalRoute = (
  source: string,
  destination: string,
  routes: BlockchainPaymentRoute[],
): BlockchainPaymentRoute | null => {
  const validRoutes = routes.filter((r) => r.sourceCountry === source && r.destinationCountry === destination);

  if (validRoutes.length === 0) return null;

  return validRoutes.reduce((best, current) => {
    const bestScore = best.totalFeePercent + best.estimatedTime / 60;
    const currentScore = current.totalFeePercent + current.estimatedTime / 60;
    return currentScore < bestScore ? current : best;
  });
};

const compareRoutes = (
  routes: BlockchainPaymentRoute[],
): Array<{
  route: string;
  fee: string;
  time: string;
  score: number;
}> => {
  return routes
    .map((r) => ({
      route: `${r.onRamp.name} → ${r.blockchain}/${r.stablecoin} → ${r.offRamp.name}`,
      fee: `${r.totalFeePercent.toFixed(2)}%`,
      time: r.estimatedTime < 60 ? `${r.estimatedTime}分钟` : `${(r.estimatedTime / 60).toFixed(1)}小时`,
      score: r.totalFeePercent + r.estimatedTime / 3600,
    }))
    .sort((a, b) => a.score - b.score);
};
