密码学基础

核心概念

密码学是区块链技术的信任基石。在没有中心化权威机构的分布式系统中，密码学原语（Cryptographic Primitives）提供了身份验证、数据完整性保护和交易不可否认性等关键能力。区块链中最核心的三大密码学工具是：哈希函数、非对称加密和数字签名。

从技术实现角度看，密码学为区块链构建了两条关键信任链：一是通过哈希函数保证数据完整性和链式关联，二是通过公钥密码学实现去中心化的身份体系和交易授权。

哈希函数与链式完整性
哈希函数是将任意长度输入映射为固定长度输出的单向函数，具备三个关键特性：抗原像性（给定哈希值无法反推输入）、抗第二原像性（给定输入无法找到另一个产生相同哈希的输入）和抗碰撞性（无法找到两个不同输入产生相同哈希值）。


区块链中最常用的是 SHA-256（比特币）和 Keccak-256（以太坊）。每个区块头包含前一区块的哈希值，形成不可篡改的链式结构——修改任何历史区块都会导致后续所有区块的哈希值失效。


import { createHash } from 'node:crypto';

const sha256 = (input: string): string => createHash('sha256').update(input).digest('hex');

const doubleSha256 = (input: string): string => sha256(Buffer.from(sha256(input), 'hex').toString());

const keccak256 = (input: string): string => createHash('sha3-256').update(input).digest('hex');

interface BlockHeader {
  version: number;
  previousBlockHash: string;
  merkleRoot: string;
  timestamp: number;
  difficultyTarget: number;
  nonce: number;
}

const hashBlockHeader = (header: BlockHeader): string => {
  const serialized = [
    header.version.toString(16).padStart(8, '0'),
    header.previousBlockHash,
    header.merkleRoot,
    header.timestamp.toString(16).padStart(8, '0'),
    header.difficultyTarget.toString(16).padStart(8, '0'),
    header.nonce.toString(16).padStart(8, '0'),
  ].join('');

  return doubleSha256(serialized);
};

const verifyChainIntegrity = (blocks: BlockHeader[]): boolean => {
  for (let i = 1; i < blocks.length; i++) {
    const expectedHash = hashBlockHeader(blocks[i - 1]);
    if (blocks[i].previousBlockHash !== expectedHash) {
      return false;
    }
  }
  return true;
};
哈希函数还用于比特币的工作量证明：矿工反复调整 nonce 值，直到区块头的双重 SHA-256 哈希值小于目标难度。以太坊使用 Keccak-256 作为其核心哈希算法，应用于状态树、交易收据和地址生成。


椭圆曲线密码学与密钥对
区块链采用椭圆曲线密码学（ECC）来生成密钥对。相比 RSA，ECC 在相同安全级别下密钥长度更短（256 位 ECC ≈ 3072 位 RSA），更适合资源受限的区块链环境。


比特币和以太坊都使用 secp256k1 曲线，其方程为 y² = x³ + 7（在有限域 F_p 上）。私钥是一个 256 位随机数，公钥通过椭圆曲线点乘运算从私钥派生。


import { randomBytes } from 'node:crypto';

const SECP256K1_ORDER = BigInt('0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEBAAEDCE6AF48A03BBFD25E8CD0364141');

const generatePrivateKey = (): string => {
  let privateKey: bigint;

  do {
    const bytes = randomBytes(32);
    privateKey = BigInt(`0x${bytes.toString('hex')}`);
  } while (privateKey === 0n || privateKey >= SECP256K1_ORDER);

  return privateKey.toString(16).padStart(64, '0');
};

const deriveEthereumAddress = (publicKeyHex: string): string => {
  const publicKeyBytes = publicKeyHex.startsWith('04') ? publicKeyHex.slice(2) : publicKeyHex;

  const hash = createHash('sha3-256').update(Buffer.from(publicKeyBytes, 'hex')).digest('hex');

  return `0x${hash.slice(-40)}`;
};

const toChecksumAddress = (address: string): string => {
  const addr = address.toLowerCase().replace('0x', '');
  const hash = createHash('sha3-256').update(addr).digest('hex');

  let checksummed = '0x';
  for (let i = 0; i < addr.length; i++) {
    checksummed += parseInt(hash[i], 16) >= 8 ? addr[i].toUpperCase() : addr[i];
  }

  return checksummed;
};

数字签名与交易授权
数字签名是区块链中交易授权的核心机制。发送者用私钥对交易数据签名，任何人都可以用发送者的公钥验证签名的有效性，同时无法伪造签名。这实现了"只有私钥持有者才能动用对应地址资产"的安全保证。


以太坊使用 ECDSA（Elliptic Curve Digital Signature Algorithm）签名，签名结果包含三个值：r、s 和 v。其中 v 是恢复标识符，用于从签名中恢复出签名者的公钥。


interface ECDSASignature {
  r: string;
  s: string;
  v: number;
}

interface SignedTransaction {
  nonce: number;
  gasPrice: bigint;
  gasLimit: bigint;
  to: string;
  value: bigint;
  data: string;
  signature: ECDSASignature;
}

const serializeTransaction = (tx: Omit<SignedTransaction, 'signature'>): string => {
  return JSON.stringify({
    nonce: tx.nonce,
    gasPrice: tx.gasPrice.toString(),
    gasLimit: tx.gasLimit.toString(),
    to: tx.to,
    value: tx.value.toString(),
    data: tx.data,
  });
};

const hashTransaction = (tx: Omit<SignedTransaction, 'signature'>): string => {
  const serialized = serializeTransaction(tx);
  return createHash('sha3-256').update(serialized).digest('hex');
};

const verifyTransactionSignature = (tx: SignedTransaction): boolean => {
  const txHash = hashTransaction({
    nonce: tx.nonce,
    gasPrice: tx.gasPrice,
    gasLimit: tx.gasLimit,
    to: tx.to,
    value: tx.value,
    data: tx.data,
  });

  const { r, s, v } = tx.signature;

  if (BigInt(`0x${s}`) > SECP256K1_ORDER / 2n) {
    return false;
  }

  return r.length === 64 && s.length === 64 && (v === 27 || v === 28);
};
比特币的 Taproot 升级引入了 Schnorr 签名，相比 ECDSA 具有线性可聚合性——多个签名可以合并为一个，显著减小多签交易的体积并提升隐私性。


零知识证明与隐私计算
零知识证明（Zero-Knowledge Proof，ZKP）是密码学领域最前沿的技术之一，允许证明者向验证者证明某个陈述为真，而不泄露除此之外的任何信息。在区块链领域，ZKP 主要用于两个方向：隐私保护和 Layer2 扩展。

zk-Rollup 是 ZKP 在扩展性领域最成功的应用：将数百笔交易在链下执行并生成一个简洁的有效性证明，只需将证明和压缩后的交易数据提交到主链即可。这在保证与主链同等安全性的前提下，将吞吐量提升了 10-100 倍。

const estimateGasSaving = (
  txCount: number,
  l1GasPerTx: number,
  proofVerificationGas: number,
  callDataGasPerTx: number,
): { l1Cost: number; rollupCost: number; saving: number } => {
  const l1Cost = txCount * l1GasPerTx;
  const rollupCost = proofVerificationGas + txCount * callDataGasPerTx;
  const saving = ((l1Cost - rollupCost) / l1Cost) * 100;

  return { l1Cost, rollupCost, saving };
};
小结
    

  • 哈希函数通过单向性和抗碰撞性保证区块链的数据完整性和链式不可篡改性
    • 

  • 椭圆曲线密码学（secp256k1）以 256 位密钥提供了与 3072 位 RSA 等价的安全性
    • 

  • ECDSA 数字签名实现了去中心化的交易授权，只有私钥持有者能签署交易
    • 

  • 零知识证明是密码学前沿，zk-Rollup 将其成功应用于 Layer2 扩展
    • 

  • 私钥安全是加密资产安全的根本——丢失私钥意味着永久丢失资产
    • 

  • 密码学创新持续推动区块链的隐私保护和可扩展性发展
