AMM 与去中心化交易

核心概念

自动做市商（Automated Market Maker，AMM）是去中心化交易所（DEX）的核心引擎。与传统订单簿模式不同，AMM 使用数学公式自动确定资产价格，流动性提供者（LP）将资产存入流动性池，交易者直接与池子进行交易。这种设计消除了对中心化撮合引擎的依赖，使任何人都能成为做市商。

Uniswap 在 2018 年首创了恒定乘积公式 x × y = k，开启了 AMM 的革命。此后 Curve、Balancer、Concentrated Liquidity 等创新不断涌现，使 DEX 的资本效率逐步逼近甚至超越传统交易所。

恒定乘积做市算法
Uniswap V2 的恒定乘积公式是最基础的 AMM 模型：池中两种代币的数量乘积在交易前后保持不变（扣除手续费后）。当交易者用 Token A 换取 Token B 时，池中 A 增加、B 减少，但 x × y 的值保持恒定。


interface LiquidityPool {
  reserveA: bigint;
  reserveB: bigint;
  totalLPTokens: bigint;
  feeRate: number;
}

const getAmountOut = (amountIn: bigint, reserveIn: bigint, reserveOut: bigint, feeRate: number): bigint => {
  const amountInWithFee = (amountIn * BigInt(Math.floor((1 - feeRate) * 10000))) / 10000n;
  const numerator = amountInWithFee * reserveOut;
  const denominator = reserveIn + amountInWithFee;
  return numerator / denominator;
};

const getAmountIn = (amountOut: bigint, reserveIn: bigint, reserveOut: bigint, feeRate: number): bigint => {
  const numerator = reserveIn * amountOut * 10000n;
  const denominator = (reserveOut - amountOut) * BigInt(Math.floor((1 - feeRate) * 10000));
  return numerator / denominator + 1n;
};

const calculatePriceImpact = (amountIn: bigint, reserveIn: bigint, reserveOut: bigint): number => {
  const spotPrice = Number(reserveOut) / Number(reserveIn);
  const amountOut = getAmountOut(amountIn, reserveIn, reserveOut, 0.003);
  const executionPrice = Number(amountOut) / Number(amountIn);
  return ((spotPrice - executionPrice) / spotPrice) * 100;
};

const addLiquidity = (
  pool: LiquidityPool,
  amountA: bigint,
  amountB: bigint,
): { lpTokens: bigint; actualA: bigint; actualB: bigint } => {
  if (pool.totalLPTokens === 0n) {
    const lpTokens = sqrt(amountA * amountB);
    return { lpTokens, actualA: amountA, actualB: amountB };
  }

  const ratioA = (amountA * pool.totalLPTokens) / pool.reserveA;
  const ratioB = (amountB * pool.totalLPTokens) / pool.reserveB;
  const lpTokens = ratioA < ratioB ? ratioA : ratioB;

  const actualA = (lpTokens * pool.reserveA) / pool.totalLPTokens;
  const actualB = (lpTokens * pool.reserveB) / pool.totalLPTokens;

  return { lpTokens, actualA, actualB };
};

const sqrt = (n: bigint): bigint => {
  if (n < 0n) throw new Error('Square root of negative number');
  if (n === 0n) return 0n;
  let x = n;
  let y = (x + 1n) / 2n;
  while (y < x) {
    x = y;
    y = (x + n / x) / 2n;
  }
  return x;
};
恒定乘积公式的价格曲线是双曲线形状，这意味着大额交易会产生显著的滑点（Slippage）——交易量越大，实际成交价格偏离当前价格越多。


集中流动性（Uniswap V3）
Uniswap V3 引入了集中流动性（Concentrated Liquidity）的概念，LP 可以选择在特定价格区间内提供流动性，而非均匀分布在 0 到无穷大的整个价格范围。这使得资本效率提升了最高 4000 倍。

const TICK_SPACING = 60;
const MIN_TICK = -887220;

const tickToPrice = (tick: number): number => {
  return Math.pow(1.0001, tick);
};

const priceToTick = (price: number): number => {
  return Math.floor(Math.log(price) / Math.log(1.0001));
};

const calculateLiquidity = (
  amount0: bigint,
  amount1: bigint,
  sqrtPriceLower: bigint,
  sqrtPriceUpper: bigint,
  sqrtPriceCurrent: bigint,
): bigint => {
  if (sqrtPriceCurrent <= sqrtPriceLower) {
    return (amount0 * sqrtPriceLower * sqrtPriceUpper) / ((sqrtPriceUpper - sqrtPriceLower) * 10n ** 18n);
  }

  if (sqrtPriceCurrent >= sqrtPriceUpper) {
    return (amount1 * 10n ** 18n) / (sqrtPriceUpper - sqrtPriceLower);
  }

  const liquidity0 = (amount0 * sqrtPriceCurrent * sqrtPriceUpper) / ((sqrtPriceUpper - sqrtPriceCurrent) * 10n ** 18n);
  const liquidity1 = (amount1 * 10n ** 18n) / (sqrtPriceCurrent - sqrtPriceLower);

  return liquidity0 < liquidity1 ? liquidity0 : liquidity1;
};

const estimateFeesEarned = (liquidity: bigint, totalLiquidity: bigint, volume24h: bigint, feeRate: bigint): bigint => {
  if (totalLiquidity === 0n) return 0n;
  return (volume24h * feeRate * liquidity) / (totalLiquidity * 10000n);
};

无常损失与 LP 风险
无常损失（Impermanent Loss，IL）是 AMM 流动性提供者面临的核心风险。当池中两种代币的相对价格发生变化时，LP 的资产组合价值低于单纯持有这两种代币的价值，差额即为无常损失。


const calculateImpermanentLoss = (priceRatio: number): number => {
  const sqrtRatio = Math.sqrt(priceRatio);
  const il = (2 * sqrtRatio) / (1 + priceRatio) - 1;
  return Math.abs(il) * 100;
};

const calculateILTable = (): Array<{
  priceChange: string;
  impermanentLoss: string;
  breakEvenAPR: string;
}> => {
  const changes = [0.25, 0.5, 0.75, 1.0, 1.25, 1.5, 2.0, 3.0, 5.0];

  return changes.map((ratio) => {
    const il = calculateImpermanentLoss(ratio);
    const breakEvenAPR = ((il / (1 - il / 100)) * 365) / 30;

    return {
      priceChange: `${ratio >= 1 ? '+' : ''}${((ratio - 1) * 100).toFixed(0)}%`,
      impermanentLoss: `${il.toFixed(2)}%`,
      breakEvenAPR: `${breakEvenAPR.toFixed(1)}%`,
    };
  });
};

interface LPProfitability {
  feesEarned: bigint;
  impermanentLoss: bigint;
  tokenRewards: bigint;
  netPnL: bigint;
  isProfileable: boolean;
}

const analyzeLPPosition = (
  initialValue: bigint,
  currentValue: bigint,
  feesEarned: bigint,
  rewardsEarned: bigint,
  holdValue: bigint,
): LPProfitability => {
  const impermanentLoss = holdValue - currentValue;
  const netPnL = currentValue + feesEarned + rewardsEarned - initialValue;

  return {
    feesEarned,
    impermanentLoss,
    tokenRewards: rewardsEarned,
    netPnL,
    isProfileable: netPnL > 0n,
  };
};
