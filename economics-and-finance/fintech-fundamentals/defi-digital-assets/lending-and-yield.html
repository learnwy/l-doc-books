借贷协议与收益

核心概念

DeFi 借贷协议通过智能合约实现了无需中介的去中心化存贷款服务。存款人将资产存入协议赚取利息，借款人以超额抵押的方式借出资产。与传统银行不同，DeFi 借贷的利率由算法根据资金利用率（Utilization Rate）动态调整，整个过程透明、无需许可。

Aave 和 Compound 是最主要的借贷协议，管理着数百亿美元的资产。借贷协议也是 DeFi 可组合性的核心枢纽——用户可以在多个协议间套利，构建杠杆策略，或将借贷头寸与 DEX、衍生品协议组合使用。

利率模型与资金利用率

借贷协议的核心算法是利率模型——它根据资金池的利用率自动计算存借款利率。利用率 = 总借款量 / 总存款量。当利用率升高，借款利率上升以激励还款和新存款；当利用率降低，利率下降以鼓励借款。

Aave 采用分段线性利率模型，在"最优利用率"（通常 80-90%）设置一个拐点：低于拐点时利率平缓上升，超过拐点后利率急剧上升，防止流动性耗尽。

interface InterestRateParams {
  optimalUtilization: number;
  baseRate: number;
  slope1: number;
  slope2: number;
  reserveFactor: number;
}

const USDC_PARAMS: InterestRateParams = {
  optimalUtilization: 0.9,
  baseRate: 0.0,
  slope1: 0.04,
  slope2: 0.6,
  reserveFactor: 0.1,
};

const calculateBorrowRate = (utilization: number, params: InterestRateParams): number => {
  if (utilization <= params.optimalUtilization) {
    return params.baseRate + (utilization / params.optimalUtilization) * params.slope1;
  }

  const excessUtilization = (utilization - params.optimalUtilization) / (1 - params.optimalUtilization);

  return params.baseRate + params.slope1 + excessUtilization * params.slope2;
};

const calculateSupplyRate = (utilization: number, params: InterestRateParams): number => {
  const borrowRate = calculateBorrowRate(utilization, params);
  return borrowRate * utilization * (1 - params.reserveFactor);
};

const simulateRateCurve = (
  params: InterestRateParams,
  steps: number,
): Array<{ utilization: number; borrowRate: number; supplyRate: number }> => {
  const curve = [];

  for (let i = 0; i <= steps; i++) {
    const utilization = i / steps;
    curve.push({
      utilization,
      borrowRate: calculateBorrowRate(utilization, params),
      supplyRate: calculateSupplyRate(utilization, params),
    });
  }

  return curve;
};

interface PoolState {
  totalDeposits: bigint;
  totalBorrows: bigint;
  reserveBalance: bigint;
  lastUpdateTimestamp: number;
  borrowIndex: bigint;
  supplyIndex: bigint;
}

const accrueInterest = (pool: PoolState, params: InterestRateParams, currentTimestamp: number): PoolState => {
  const timeDelta = currentTimestamp - pool.lastUpdateTimestamp;
  if (timeDelta === 0) return pool;

  const utilization = pool.totalDeposits > 0n ? Number((pool.totalBorrows * 10000n) / pool.totalDeposits) / 10000 : 0;

  const borrowRatePerSecond = calculateBorrowRate(utilization, params) / (365 * 24 * 3600);
  const interestFactor = BigInt(Math.floor(borrowRatePerSecond * timeDelta * 1e18));

  const interestAccumulated = (pool.totalBorrows * interestFactor) / BigInt(1e18);
  const reserveIncome = (interestAccumulated * BigInt(params.reserveFactor * 1e18)) / BigInt(1e18);

  return {
    ...pool,
    totalBorrows: pool.totalBorrows + interestAccumulated,
    reserveBalance: pool.reserveBalance + reserveIncome,
    lastUpdateTimestamp: currentTimestamp,
    borrowIndex: pool.borrowIndex + (pool.borrowIndex * interestFactor) / BigInt(1e18),
    supplyIndex:
      pool.supplyIndex + (pool.supplyIndex * interestFactor * BigInt(Math.floor(utilization * 1e18))) / BigInt(1e36),
  };
};

清算机制与健康因子

超额抵押是 DeFi 借贷安全性的基础。每个借贷仓位都有一个"健康因子"（Health Factor），当抵押品价值下降导致健康因子低于 1 时，任何人都可以触发清算，以折价购买借款人的抵押品来偿还其债务。

interface UserPosition {
  deposits: Array<{
    asset: string;
    amount: bigint;
    priceUSD: bigint;
    liquidationThreshold: number;
  }>;
  borrows: Array<{
    asset: string;
    amount: bigint;
    priceUSD: bigint;
  }>;
}

const calculateHealthFactor = (position: UserPosition): number => {
  let totalCollateralETH = 0n;
  let totalBorrowETH = 0n;

  for (const deposit of position.deposits) {
    const valueUSD = (deposit.amount * deposit.priceUSD) / BigInt(1e18);
    totalCollateralETH += (valueUSD * BigInt(Math.floor(deposit.liquidationThreshold * 100))) / 100n;
  }

  for (const borrow of position.borrows) {
    totalBorrowETH += (borrow.amount * borrow.priceUSD) / BigInt(1e18);
  }

  if (totalBorrowETH === 0n) return Infinity;
  return Number((totalCollateralETH * 10000n) / totalBorrowETH) / 10000;
};

interface LiquidationParams {
  closeFactor: number;
  liquidationIncentive: number;
  protocolSeizeFactor: number;
}

const AAVE_LIQUIDATION_PARAMS: LiquidationParams = {
  closeFactor: 0.5,
  liquidationIncentive: 1.05,
  protocolSeizeFactor: 0.025,
};

const calculateLiquidationProfit = (
  debtToRepay: bigint,
  collateralPrice: bigint,
  params: LiquidationParams,
): { collateralSeized: bigint; liquidatorProfit: bigint } => {
  const collateralSeized = (debtToRepay * BigInt(Math.floor(params.liquidationIncentive * 10000))) / 10000n;
  const liquidatorProfit = collateralSeized - debtToRepay;

  return { collateralSeized, liquidatorProfit };
};

const monitorPositions = (positions: Map<string, UserPosition>, threshold: number): string[] => {
  const atRisk: string[] = [];

  for (const [address, position] of positions) {
    const hf = calculateHealthFactor(position);
    if (hf < threshold) {
      atRisk.push(address);
    }
  }

  return atRisk.sort((a, b) => {
    const hfA = calculateHealthFactor(positions.get(a)!);
    const hfB = calculateHealthFactor(positions.get(b)!);
    return hfA - hfB;
  });
};

收益策略与聚合

DeFi 收益策略通过组合多个协议来最大化资金回报。收益聚合器（Yield Aggregator）如 Yearn Finance 自动执行复杂的收益策略，将手续费收入、治理代币奖励和复利效果结合起来。

interface YieldSource {
  protocol: string;
  asset: string;
  baseAPY: number;
  rewardAPY: number;
  tvl: bigint;
  risk: 'low' | 'medium' | 'high';
}

interface Strategy {
  name: string;
  steps: StrategyStep[];
  totalAPY: number;
  riskLevel: 'low' | 'medium' | 'high';
}

interface StrategyStep {
  action: 'deposit' | 'borrow' | 'swap' | 'stake' | 'provide_liquidity';
  protocol: string;
  asset: string;
  leverageMultiplier?: number;
}

const calculateLeveragedYield = (supplyAPY: number, borrowAPY: number, ltv: number, loops: number): number => {
  let totalYield = 0;
  let multiplier = 1;

  for (let i = 0; i < loops; i++) {
    totalYield += supplyAPY * multiplier;
    if (i < loops - 1) {
      totalYield -= borrowAPY * multiplier * ltv;
      multiplier *= ltv;
    }
  }

  return totalYield;
};

const findOptimalStrategy = (
  sources: YieldSource[],
  riskTolerance: 'low' | 'medium' | 'high',
  minTVL: bigint,
): YieldSource[] => {
  const riskOrder = { low: 0, medium: 1, high: 2 };
  const maxRisk = riskOrder[riskTolerance];

  return sources
    .filter((s) => riskOrder[s.risk] <= maxRisk && s.tvl >= minTVL)
    .sort((a, b) => b.baseAPY + b.rewardAPY - (a.baseAPY + a.rewardAPY));
};

const compoundAPYToAPR = (apy: number, compoundsPerYear: number): number => {
  return compoundsPerYear * (Math.pow(1 + apy, 1 / compoundsPerYear) - 1);
};

const aprToCompoundAPY = (apr: number, compoundsPerYear: number): number => {
  return Math.pow(1 + apr / compoundsPerYear, compoundsPerYear) - 1;
};
