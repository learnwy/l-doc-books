企业财务 简介

企业财务回答一家公司的三个核心问题：钱从哪来（融资）、钱投到哪（投资）、赚的钱怎么分（分配）。本手册以"价值创造"为主线，把财务报表、资本结构、估值与财务决策串成一条可操作的分析链：先读懂企业现状，再算清资金成本，进而给资产定价，最后落到具体决策。

本 hub 在经济金融板块中的定位

经济金融板块里有多个相邻 hub 容易混淆，下表厘清分工边界，帮你判断该读哪一本：

Hub 核心问题 视角 与本 hub 的边界
企业财务（本 hub） 公司如何融资、投资、分配以创造价值 公司决策者/CFO 站在企业内部做财务决策
会计基础 交易如何被记录成报表 记账与编表 本 hub 用报表，会计 hub 教你怎么造出报表
投资入门 个人/投资者如何买卖资产获利 资金的提供方 本 hub 是公司视角，投资 hub 是投资者视角
金融工程 衍生品定价与量化建模 数学/工程 本 hub 的实物期权借用其 BS/二叉树工具
金融风险管理 如何度量与控制各类风险 风控 本 hub 关心收益与成本，风险 hub 关心损失分布

一句话区分：会计教你"记账"，本 hub 教你"用账做决策"，投资入门教你"作为外部投资者去判断"。

推荐学习路径

四章按"分析 → 融资 → 估值 → 决策"的认知顺序组织，但不同人群可以从不同入口切入：

  • 零基础/想看懂财报：第一章「公司财务分析」(报表解读 → 比率分析 → 现金流 → 财务建模) 即可独立成篇，是性价比最高的起点。
  • 创业者/融资方：先读第二章「资本结构」(资本成本 → MM 定理 → 债务股权融资 → 最优杠杆)，理解为什么以及如何融资。
  • 投资分析/卖方研究：直接从第三章「估值方法」(DCF → 相对估值 → 实物期权) 切入，再回看第一章补现金流口径。
  • 公司战略/投行：第四章「财务决策」(资本预算 → 股利政策 → 并购重组) 是综合应用层，需要前三章作支撑。

完整顺序学习者建议按 1 → 2 → 3 → 4：第一章给数据基础，第二章给资金成本，第三章给定价工具，第四章把三者落到真实决策。

前置知识

  • 必备：基础财务报表常识（知道资产负债表、利润表、现金流量表大致是什么）。完全没有的话，先读 会计基础 · 会计恒等式 与 复式记账。
  • 强烈建议：货币时间价值与折现的概念，见 投资入门 · 货币时间价值——它是第二、三章几乎所有公式的数学底座。
  • 加分项：风险与收益的权衡，见 投资入门 · 风险与收益，有助于理解资本成本中的风险溢价与 β。

数学要求不高：会做加权平均、复利折现、解一元方程即可；Excel/电子表格的基本操作对第一章的财务建模会很有帮助。
