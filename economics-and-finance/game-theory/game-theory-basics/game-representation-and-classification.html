博弈的表示与分类

核心概念

博弈论是研究多个决策主体在相互影响的环境中如何做出最优选择的数学理论。一个完整的博弈包含三个基本要素：参与人（Players）、策略空间（Strategy Space）和收益函数（Payoff Function）。博弈的不同表示方式和分类标准构成了理解整个博弈论大厦的基础。

标准式（战略式）表示
标准式表示也称为矩阵式表示，是静态博弈最常用的描述形式。它使用一个收益矩阵来同时展示所有参与人的策略选择和对应收益。对于两人博弈，行代表参与人1的策略，列代表参与人2的策略，每个格子中包含两个数字分别表示两人的收益。


以经典的囚徒困境为例，两个嫌疑人各自选择"坦白"或"沉默"。如果都沉默各判1年，都坦白各判5年，一方坦白另一方沉默则坦白者释放、沉默者判10年。矩阵的每个格子写成（参与人1收益, 参与人2收益）的形式。


标准式表示的优势在于简洁直观，可以直接通过划线法或支配策略法求解均衡。但它也有局限：无法展示博弈的时序结构，即谁先行动、行动时知道什么信息。对于动态博弈或信息集复杂的情况，需要转向扩展式表示。


在 n 人博弈中，标准式可以推广为高维数组。参与人 i 的策略集为 Sᵢ，策略组合 s = (s₁, s₂, ..., sₙ)，参与人 i 的收益为 uᵢ(s)。博弈的标准式记为 G = {S₁, S₂, ..., Sₙ; u₁, u₂, ..., uₙ}。


扩展式（博弈树）表示
扩展式表示使用博弈树来描述动态博弈的完整结构。博弈树包含决策节点（标注由哪个参与人行动）、分支（代表可选行动）、终端节点（标注各参与人的收益）以及信息集（标注参与人在行动时所掌握的信息）。


上图展示了一个市场进入博弈：参与人1（进入者）先决定是否进入市场，如果不进入则收益为(0,3)；如果进入，参与人2（在位者）再决定容纳还是斗争。扩展式清晰地展示了行动的先后顺序以及每个决策节点上决策者拥有的信息。


信息集是扩展式表示的核心概念。如果一个参与人在某些决策节点上无法区分自己处于哪个节点（因为不知道之前发生了什么），这些节点就构成一个信息集。在完美信息博弈中，每个信息集只包含一个节点；在不完美信息博弈中，某些信息集包含多个节点。


扩展式和标准式之间可以相互转换。任何扩展式博弈都可以转换为标准式——将每个参与人的策略定义为对其所有信息集行动的完整规划。但反向转换可能丢失信息，因为一个标准式可能对应多个不同的扩展式。


静态与动态博弈
按照行动时序，博弈分为静态博弈和动态博弈。静态博弈中，参与人同时做出决策（或互不知晓对方选择），其均衡概念是纳什均衡。动态博弈中，存在明确的行动序列，参与人可以观察到先行者的行动。


动态博弈引入了可信承诺和威胁的概念。在市场进入博弈中，在位者可以威胁"如果你进入我就斗争"，但进入实际发生后，斗争对在位者自身也不利。这类不可信的威胁在子博弈完美均衡中被排除——通过逆向归纳法，从博弈树的末端向前推导，每个子博弈中的行动都必须是该子博弈的纳什均衡。


重复博弈是一类特殊的动态博弈：相同的阶段博弈在多个时期重复进行。有限次重复博弈和无限次重复博弈有本质区别——有限次重复的囚徒困境中，逆向归纳导致每期都背叛；无限次重复博弈中，合作可以通过触发策略维持。

合作博弈与非合作博弈
非合作博弈假设参与人独立做出决策，不能签订有约束力的协议。博弈论的主流分析框架（纳什均衡、子博弈完美均衡等）都建立在非合作博弈的基础上。非合作并不意味着参与人一定对抗——它只是指决策的独立性。


合作博弈允许参与人形成联盟、签订有约束力的合约。研究重点转向联盟的值（联盟成员合作能获得的总收益）和收益分配。核心解（Core）要求任何联盟都无法通过脱离大联盟获得更多收益。夏普利值（Shapley Value）按照边际贡献的期望值公平分配收益——每个参与人获得的收益等于其加入不同联盟顺序下边际贡献的平均值。


现代博弈论倾向于用非合作方法实现合作结果。例如，纳什谈判方案可以作为一个非合作谈判博弈的均衡推导出来。这种"纳什纲领"体现了从非合作基础出发理解合作行为的研究范式。


小结
    

  • 博弈由参与人、策略空间和收益函数三要素构成，不同表示方式适用于不同类型博弈
    • 

  • 标准式（矩阵）简洁直观适合静态分析，扩展式（博弈树）展示时序和信息结构
    • 

  • 信息集决定了参与人在决策时掌握的信息，是区分完美/不完美信息博弈的关键
    • 

  • 动态博弈通过子博弈完美均衡排除不可信威胁，逆向归纳是核心求解方法
    • 

  • 合作博弈关注联盟形成和收益分配，夏普利值提供了公平分配的数学方案
    •
