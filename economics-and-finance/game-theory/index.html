博弈论：策略互动的数学框架

Hub 定位

本 hub 研究多个决策主体在相互影响的环境中如何做出最优选择。它的独特视角是：你的最优决策取决于别人的决策，而别人也在做同样的事——因此分析单位不是"个体最优化"，而是"策略组合的均衡"。四章内容层层递进：第一章建立语言（表示法与均衡概念），第二章用经典模型训练直觉（困境、协调、重复、演化），第三章引入信息不对称（贝叶斯博弈、信号传递、机制设计），第四章回到真实场景（拍卖、谈判、商业竞争）。

与兄弟 hub 的分工边界

兄弟 hub 它回答的问题 与本 hub 的分工边界
微观经济学 单个主体在给定的价格与预算约束下如何最优化 微观经济学把他人行为当作环境参数；本 hub 中他人是会反策略回应的参与人，核心概念从"最优"换成"均衡"
行为经济学 真实人如何系统性偏离理性假设 本 hub 在完全理性框架内推演均衡结构；有限理性下的策略行为修正归行为经济学
信息经济学 信息不对称如何扭曲市场结果与契约安排 本 hub 提供其数学引擎（贝叶斯纳什均衡、信号传递与筛选、显示原理）；信息经济学侧重逆向选择的市场后果与契约应用
产业组织 企业间竞争、市场结构与反垄断 产业组织把博弈论用作解释寡头定价、市场进入的工作母机并辅以实证；本 hub 仅在第四章取数个模型作应用示例
市场设计与机制设计 如何设计规则让稀缺资源配到对的人手里 本 hub 讲清机制设计的博弈论原理（激励相容、VCG、不可能定理）；该 hub 聚焦频谱拍卖、匹配市场等工程化落地
实验经济学 理论预测在受控实验中是否成立 本 hub 给出可检验的预测（如囚徒困境中的合作率衰减）；实验方法与行为数据检验归实验经济学

一句话总结：本 hub 是这组 hub 共同的方法论底座——它不替代任何兄弟 hub 的具体问题，而是提供它们共用的均衡分析语言。

学习路径

本 hub 四章严格递进，每章在前一章概念上引入新维度，首次学习建议按顺序通读。

  • 第一章「博弈基础」：标准式与扩展式表示 → 支配策略与纳什均衡 → 混合策略均衡 → 子博弈完美均衡。这是全部后续内容的语言和工具，不可跳过。
  • 第二章「经典博弈模型」：囚徒困境 → 协调与懦夫博弈 → 重复博弈与合作 → 演化博弈论。从抽象定义走向解释力：合作为何涌现、承诺为何有价值。
  • 第三章「信息与博弈」：不完全信息博弈与贝叶斯均衡 → 信号传递与筛选 → 机制设计。把"我知道什么、对方知道我知道什么"变成可计算的对象。
  • 第四章「博弈论应用」：拍卖理论 → 谈判理论 → 商业应用。理论工具在真实场景中的检验。

分人群推荐路线：

人群 推荐路线 说明
零基础通识读者 第一章 1–2 篇 → 第二章全部 → 第四章商业应用 先建立"均衡"直觉再回补技术细节；跳过混合策略的支撑集求解
经济 / 金融专业学生 第一至第四章全序 完整链条是后续计量、产业组织、契约理论课程的先修基础
工程 / AI 背景读者 第一章（重点纳什均衡与扩展式）→ 第三章机制设计 → 第四章拍卖 广告竞价、多智能体系统、机制设计直接对口；第二章可选读重复博弈
商业 / 政策从业者 第二章囚徒困境与协调博弈 → 第四章商业应用与谈判 快速拿到可用于分析价格战、平台竞争、议价的思维框架

前置知识

  • 数学：函数与不等式、基础概率（期望值、条件概率）、一元微积分（求导与极值，用于连续策略的古诺均衡和混合策略求解）。
  • 经济学：了解效用最大化和市场均衡有帮助但非必需——本 hub 自带独立的分析框架，所有概念均从零定义。
  • 不需要：测度论、不动点定理、拓扑学等高级工具。文中提到布劳威尔不动点定理时只使用其结论，不涉及证明。

延伸阅读

  • 行为经济学 — 行为博弈论修正完全理性假设，研究有限理性下的策略行为
  • 信息经济学 — 第三章的深化方向：信息不对称下的契约设计与激励理论
  • 产业组织 — 寡头竞争、市场进入与企业战略的模型深化与实证
  • 市场设计与机制设计 — 从机制设计原理到频谱拍卖与匹配市场的工程化落地
  • 实验经济学 — 博弈论预测的实验室检验：合作、协调与讨价还价的真实行为
