复利效应

核心概念

复利是"世界第八大奇迹"——爱因斯坦如此评价。复利效应的本质是收益产生收益：你的投资不仅本金在增长，之前的收益也会继续产生新的收益，形成指数级增长。对程序员来说，复利就像递归函数——每一层调用的结果都会作为下一层的输入，最终产生远超直觉预期的输出。

理解复利效应的关键不在于公式本身，而在于直觉性地认识到时间是复利最重要的变量。同样的年化收益率，投资 30 年的结果是投资 10 年的数倍，而非 3 倍。这就是为什么越早开始投资越好——哪怕金额很小。


复利公式与计算
复利的数学基础简单而优雅。核心公式是 FV = PV × (1 + r)^n，其中 FV 是终值、PV 是现值、r 是收益率、n 是期数。


interface CompoundInterestParams {
  principal: number;
  annualRate: number;
  years: number;
  compoundingFrequency: 'annually' | 'monthly' | 'daily';
  monthlyContribution?: number;
}

function calculateCompoundInterest(params: CompoundInterestParams): {
  finalValue: number;
  totalContributed: number;
  totalInterest: number;
  effectiveAnnualRate: number;
  yearlyBreakdown: { year: number; balance: number; yearInterest: number }[];
} {
  const { principal, annualRate, years, compoundingFrequency, monthlyContribution = 0 } = params;

  const frequencyMap = { annually: 1, monthly: 12, daily: 365 };
  const n = frequencyMap[compoundingFrequency];
  const ratePerPeriod = annualRate / n;
  const totalPeriods = n * years;

  let balance = principal;
  const yearlyBreakdown: { year: number; balance: number; yearInterest: number }[] = [];

  for (let year = 1; year <= years; year++) {
    const yearStart = balance;
    for (let period = 0; period < n; period++) {
      balance = balance * (1 + ratePerPeriod) + monthlyContribution * (12 / n);
    }
    yearlyBreakdown.push({
      year,
      balance: Math.round(balance),
      yearInterest: Math.round(balance - yearStart - monthlyContribution * 12),
    });
  }

  const totalContributed = principal + monthlyContribution * 12 * years;
  const effectiveAnnualRate = Math.pow(1 + annualRate / n, n) - 1;

  return {
    finalValue: Math.round(balance),
    totalContributed,
    totalInterest: Math.round(balance - totalContributed),
    effectiveAnnualRate,
    yearlyBreakdown,
  };
}

时间价值与提前启动
复利效应中时间的威力常常被低估。很多程序员认为"等收入更高了再开始投资"，但这种等待的代价远比直觉感受到的要大。

对程序员的启示是明确的：


    

  • 不要等到"准备好了"才开始投资，今天就开始，哪怕每月只有 1000 元
    • 

  • 收入增长时，优先增加投资金额而非消费水平
    • 

  • 理解复利意味着接受"前期感觉很慢"——复利的魔力在后半段才真正显现

复利的敌人
复利效应虽然强大，但有几个"敌人"会严重削弱甚至逆转复利的力量。识别并规避这些敌人，是让复利真正发挥作用的关键。


通胀：通胀是复利的无声杀手。你需要区分名义收益率和实际收益率（实际收益率 ≈ 名义收益率 - 通胀率）。如果你的投资年化收益率是 4%，而通胀率是 3%，那么你的实际购买力增长只有约 1%。

中途取出是最具破坏性的敌人。复利曲线是前缓后陡的指数曲线，如果你在投资的第 10 年（正是曲线开始加速的时候）取出本金，相当于放弃了后续 80% 的收益。


function demonstrateLossRecovery(drawdown: number): number {
  return (1 / (1 - drawdown) - 1) * 100;
}

const lossRecoveryTable = [
  { loss: 10, recoveryNeeded: demonstrateLossRecovery(0.1) },
  { loss: 20, recoveryNeeded: demonstrateLossRecovery(0.2) },
  { loss: 30, recoveryNeeded: demonstrateLossRecovery(0.3) },
  { loss: 40, recoveryNeeded: demonstrateLossRecovery(0.4) },
  { loss: 50, recoveryNeeded: demonstrateLossRecovery(0.5) },
];
亏损与回本所需涨幅的非对称关系：亏 10% 需要涨 11.1% 回本，亏 20% 需要涨 25%，亏 30% 需要涨 42.9%，亏 50% 需要涨 100%。这就是为什么控制回撤比追求高收益更重要——复利要求的是持续稳定的正收益，而非大起大落。


小结
    

  • 复利效应的本质是收益产生收益，时间是最重要的变量
    • 

  • 72 法则是实用的心算工具：72 ÷ 收益率 = 翻倍年数
    • 

  • 25 岁开始投资 3000 元/月，到 60 岁超过 35 岁开始投 6000 元/月——时间价值巨大
    • 

  • 名义收益率减去通胀才是实际购买力增长，跑赢通胀是投资的最低目标
    • 

  • 中途取出是复利最大的敌人，坚持长期不间断投入才能充分释放复利力量
    • 

  • 控制回撤比追求高收益更重要，亏 50% 需要涨 100% 才能回本
    •
