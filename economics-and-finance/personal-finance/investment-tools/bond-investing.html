债券投资

核心概念

债券是一种固定收益类投资工具，本质是投资者借钱给发行方（政府或企业），约定在固定期限内支付利息并到期归还本金。对程序员而言，债券是投资组合中不可或缺的"稳定器"——当股票市场剧烈波动时，债券通常能提供稳定的现金流和价格缓冲，起到降低整体组合波动的作用。

理解债券收益率和价格的反向关系是债券投资的基础。当市场利率上升时，已发行债券的价格下跌（因为新债券提供更高利率）；当市场利率下降时，已发行债券的价格上涨。这个机制是理解债券投资策略的关键。


利率与债券价格关系
利率和债券价格的反向关系是债券投资中最重要的概念。理解这个关系，就能在利率周期中做出正确的投资决策。


**久期（Duration）**衡量债券价格对利率变动的敏感度。久期越长，利率变动 1% 带来的价格波动越大。


interface BondPricing {
  faceValue: number;
  couponRate: number;
  yearsToMaturity: number;
  marketRate: number;
}

function calculateBondPrice(bond: BondPricing): number {
  const { faceValue, couponRate, yearsToMaturity, marketRate } = bond;
  const coupon = faceValue * couponRate;
  let price = 0;

  for (let t = 1; t <= yearsToMaturity; t++) {
    price += coupon / Math.pow(1 + marketRate, t);
  }
  price += faceValue / Math.pow(1 + marketRate, yearsToMaturity);

  return Math.round(price * 100) / 100;
}

function calculateDuration(bond: BondPricing): number {
  const { faceValue, couponRate, yearsToMaturity, marketRate } = bond;
  const coupon = faceValue * couponRate;
  const price = calculateBondPrice(bond);
  let weightedTime = 0;

  for (let t = 1; t <= yearsToMaturity; t++) {
    const cashflow = t < yearsToMaturity ? coupon : coupon + faceValue;
    weightedTime += (t * cashflow) / Math.pow(1 + marketRate, t);
  }

  return Math.round((weightedTime / price) * 100) / 100;
}

对程序员投资者的实用建议：如果你不确定利率走向，选择中短久期（1-3 年）的债券基金是最稳妥的选择。它们的收益率适中，且利率风险可控。


债券基金实操指南
对于个人投资者，直接购买债券的门槛较高且操作复杂。通过债券基金间接投资是更实际的方式。

纯债基金适合作为组合的防御层，它不持有任何股票，收益完全来自债券的票息和价差。在股市大跌的年份，纯债基金往往能提供正收益，起到"压舱石"的作用。


二级债基可以配置少量股票（不超过 20%），在债券收益基础上增加一些权益弹性。适合作为"稳健增长"的配置选项。


选择债券基金时的关键指标：


interface BondFundMetrics {
  name: string;
  annualReturn3Y: number;
  maxDrawdown: number;
  sharpRatio: number;
  duration: number;
  creditQuality: 'AAA' | 'AA+' | 'AA' | 'mixed';
  expenseRatio: number;
  size: number;
}

function scoreBondFund(fund: BondFundMetrics): number {
  let score = 0;
  score += fund.annualReturn3Y > 4 ? 20 : fund.annualReturn3Y > 3 ? 15 : 10;
  score += fund.maxDrawdown < 2 ? 20 : fund.maxDrawdown < 5 ? 15 : 5;
  score += fund.sharpRatio > 1.5 ? 20 : fund.sharpRatio > 1.0 ? 15 : 10;
  score += fund.expenseRatio < 0.4 ? 20 : fund.expenseRatio < 0.7 ? 15 : 10;
  score += fund.size > 5 && fund.size < 100 ? 20 : 10;
  return score;
}
国债逆回购与短期工具
国债逆回购是一种特别适合程序员的短期投资工具。它本质上是你把钱借给需要资金的机构，以国债为抵押，约定期限和利率。安全性几乎等同于国债，但收益率在月末、季末、年末等资金紧张时点会飙升。

最佳操作时机：每月最后一周、每季度最后一周、春节前两周。这些时点银行间市场资金紧张，逆回购利率会显著上升。程序员可以设置日历提醒，在这些时点将闲置资金投入逆回购。


国债逆回购适合用来管理"等待投资机会的资金"。当你觉得股票市场估值偏高，暂不适合买入时，逆回购可以让等待的资金也产生收益，而非躺在活期账户里。


小结
    

  • 债券是投资组合的"稳定器"，提供固定收益和价格缓冲，降低整体波动
    • 

  • 利率和债券价格反向变动，久期越长对利率变化越敏感
    • 

  • 通过债券基金间接投资是个人投资者最实际的方式，纯债基金适合防御配置
    • 

  • 不确定利率走向时选择中短久期（1-3 年）债券基金，平衡收益和风险
    • 

  • 国债逆回购是管理闲置资金的好工具，月末季末年末收益显著上升
    • 

  • 债券在投资组合中的比例建议为 20-40%，根据年龄和风险偏好调整
    •
