股票投资基础

核心概念

股票是公司所有权的凭证，持有股票意味着你是公司的部分所有者。股票投资是个人财富增长的重要引擎，长期来看，股票市场的平均年化收益率约为 8-12%，远超通胀和银行存款。对程序员而言，理解股票投资不仅是理财技能，也是理解科技公司运作、期权价值和行业趋势的重要视角。

对于大多数程序员投资者，建议以指数基金为核心（70-80%），个股为辅助（20-30%）。除非你愿意投入大量时间研究，否则试图战胜市场的个股投资长期来看大概率跑输指数。


估值分析方法
估值是判断股票是否值得买入的核心技能。就像评估一个 SaaS 产品的价值一样，股票估值需要从多个维度综合判断。


市盈率（PE）分析是最基础的估值方法。PE = 股价 / 每股收益，表示你愿意为公司每赚 1 元钱支付多少元。不同行业的合理 PE 差异巨大：

DCF（折现现金流）模型是更严谨的估值方法，核心思想是：一家公司的价值等于其未来所有现金流的折现总和。


function calculateDCF(
  freeCashFlows: number[],
  terminalGrowthRate: number,
  discountRate: number,
  sharesOutstanding: number,
): { intrinsicValue: number; perShareValue: number } {
  let presentValue = 0;

  for (let i = 0; i < freeCashFlows.length; i++) {
    presentValue += freeCashFlows[i] / Math.pow(1 + discountRate, i + 1);
  }

  const lastFCF = freeCashFlows[freeCashFlows.length - 1];
  const terminalValue = (lastFCF * (1 + terminalGrowthRate)) / (discountRate - terminalGrowthRate);
  const terminalPV = terminalValue / Math.pow(1 + discountRate, freeCashFlows.length);

  const intrinsicValue = presentValue + terminalPV;
  return {
    intrinsicValue,
    perShareValue: intrinsicValue / sharesOutstanding,
  };
}
估值分析的关键不在于精确计算，而在于建立安全边际。当计算出的内在价值远高于当前市场价（通常要求 30% 以上的安全边际），才值得考虑买入。


投资策略选择
不同的投资策略适合不同性格和时间投入的程序员。选择策略时需要考虑你愿意花多少时间在投资上。


纯指数定投策略：每月固定日期买入固定金额的宽基指数基金（如沪深 300、中证 500）。这是被证明长期有效的策略，巴菲特多次推荐普通投资者使用指数基金。程序员可以用代码设定自动定投规则：


interface DCARule {
  fundCode: string;
  amount: number;
  frequency: 'weekly' | 'biweekly' | 'monthly';
  executionDay: number;
  adjustByValuation: boolean;
}

function calculateDCAAmount(baseAmount: number, currentPE: number, historicalPEPercentile: number): number {
  if (!historicalPEPercentile) return baseAmount;

  if (historicalPEPercentile < 30) return baseAmount * 1.5;
  if (historicalPEPercentile < 50) return baseAmount * 1.2;
  if (historicalPEPercentile < 70) return baseAmount;
  if (historicalPEPercentile < 90) return baseAmount * 0.7;
  return baseAmount * 0.3;
}
核心+卫星策略：70-80% 的资金配置在指数基金（核心），20-30% 配置在你看好的个股或行业 ETF（卫星）。这种策略在保证基础收益的同时，给你参与个股投资的机会。适合对某些行业有深入了解的程序员——比如你在云计算行业工作，对云计算公司的判断力天然高于普通投资者。


风险管理与仓位控制
股票投资的风险管理是保护本金的关键。很多程序员在牛市中赚了钱，却在熊市中加倍亏损，根本原因是缺乏系统的风险管理。


仓位管理的核心原则：


    

  • 单只个股仓位不超过总投资的 10%
    • 

  • 单一行业仓位不超过总投资的 30%
    • 

  • 永远保留 10-20% 的现金仓位作为"子弹"
    • 

  • 随着盈利增加逐步提高安全垫，而非加倍押注
    •

止损与止盈：设定明确的止损线（通常为成本价的 -15% 到 -20%）和止盈目标。止损是纪律，不是预测——即使你认为股票会反弹，达到止损线也应该执行。止盈则可以采用移动止盈法：盈利超过 30% 后，每回撤 10% 卖出一部分。


对程序员投资者特别重要的一点是：不要把选股当成写代码的优化问题。代码优化有确定性解，但股票市场充满不确定性。接受"有些损失是正常的"这个事实，比试图找到完美的选股算法更重要。


小结
    

  • 股票投资是长期财富增长的重要引擎，年均收益 8-12% 远超通胀和存款
    • 

  • 大多数程序员应以指数基金为核心（70-80%），个股投资仅作辅助
    • 

  • 估值分析的关键是建立安全边际，内在价值超出市价 30% 以上再考虑买入
    • 

  • 根据可用时间选择策略：每周不到 1 小时用纯指数定投，1-5 小时用核心+卫星策略
    • 

  • 严格执行仓位管理：单股不超 10%、单行业不超 30%、保留现金仓位
    • 

  • 接受市场不确定性，不要试图用程序思维寻找"完美选股算法"
    •
