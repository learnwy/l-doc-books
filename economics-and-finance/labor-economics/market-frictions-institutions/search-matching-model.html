搜寻匹配模型

概述

搜寻匹配模型（Search and Matching Model）是现代劳动经济学分析失业和劳动力市场动态的核心框架。它由 Peter Diamond、Dale Mortensen 和 Christopher Pissarides 开创，三人因此分享了 2010 年诺贝尔经济学奖。这一模型的革命性贡献在于：它将失业从一种"市场失灵"重新解释为信息摩擦下双边搜寻的均衡结果——工人需要时间寻找合适的工作，企业需要时间招到合适的人，失业是这一搜寻过程的必然产物。

与 Walrasian 瞬时出清不同，DMP 模型明确刻画了匹配过程的时间维度：职位空缺和失业者共存不是悖论，而是均衡特征。通过引入匹配函数、自由进入条件和 Nash 议价工资，模型同时解释了失业率、空缺率和工资的联合决定。

本文将系统阐述 DMP 模型的基本结构、均衡性质、比较静态和政策含义，以及近年来模型在宏观经济波动解释方面的发展与争论。

模型的基本结构

环境设定

考虑一个连续时间的经济，包含大量同质工人和大量同质企业（岗位）：

  • 工人：总劳动力标准化为 1，在任何时刻要么就业要么失业并搜寻工作
  • 企业/岗位：可以选择开设空缺（vacancy），空缺会产生流量成本 c>0c > 0c>0（广告、面试等）
  • 匹配技术：用聚合匹配函数描述
  • 分离：匹配以外生率 sss（separation rate）被摧毁

匹配函数

匹配函数（Matching Function）是模型的核心技术假设：

m=m(u,v)m = m(u, v)m=m(u,v)

其中 uuu 是失业人数，vvv 是空缺数量，mmm 是单位时间内新形成的匹配数。

标准假设：

  • 规模报酬不变（CRS）：m(λu,λv)=λm(u,v)m(\lambda u, \lambda v) = \lambda m(u, v)m(λu,λv)=λm(u,v)
  • 两端递增凹：mu>0,mv>0,muu<0,mvv<0m_u > 0, m_v > 0, m_{uu} < 0, m_{vv} < 0mu​>0,mv​>0,muu​<0,mvv​<0
  • Inada 条件：极端情况下匹配率趋于零/无穷

常用函数形式——Cobb-Douglas 匹配函数：

m(u,v)=Auαv1−αm(u, v) = A u^\alpha v^{1-\alpha}m(u,v)=Auαv1−α

其中 A>0A > 0A>0 是匹配效率参数，α∈(0,1)\alpha \in (0,1)α∈(0,1) 是匹配弹性。

劳动市场紧张度

定义市场紧张度（Market Tightness）：

θ=vu\theta = \frac{v}{u}θ=uv​

θ\thetaθ 是描述劳动市场状态的充分统计量。利用 CRS 性质：

  • 工人找到工作的速率：f(θ)=m(u,v)/u=m(1,θ)=Aθ1−αf(\theta) = m(u,v)/u = m(1, \theta) = A\theta^{1-\alpha}f(θ)=m(u,v)/u=m(1,θ)=Aθ1−α
  • 企业填补空缺的速率：q(θ)=m(u,v)/v=m(1/θ,1)=Aθ−αq(\theta) = m(u,v)/v = m(1/\theta, 1) = A\theta^{-\alpha}q(θ)=m(u,v)/v=m(1/θ,1)=Aθ−α

关键性质：θ↑⇒f↑,q↓\theta \uparrow \Rightarrow f \uparrow, q \downarrowθ↑⇒f↑,q↓——市场越紧张（空缺相对充裕），工人越容易找到工作，但企业越难招到人。

Beveridge 曲线与稳态

稳态失业率

失业存量的变化为：

u˙=s(1−u)−f(θ)u\dot{u} = s(1-u) - f(\theta)uu˙=s(1−u)−f(θ)u

稳态条件 u˙=0\dot{u} = 0u˙=0 给出：

u∗=ss+f(θ)u^* = \frac{s}{s + f(\theta)}u∗=s+f(θ)s​

这就是Beveridge 曲线的微观基础：给定 θ\thetaθ，失业率由分离率和发现率的比值决定。

  • sss 上升：更多匹配被摧毁 → uuu 上升
  • θ\thetaθ 上升：f(θ)f(\theta)f(θ) 增加 → uuu 下降

Beveridge 曲线是 (u,v)(u, v)(u,v) 空间中的向右下方倾斜的曲线（v=θ⋅uv = \theta \cdot uv=θ⋅u）。

企业的空缺创造决策

资产方程

空缺岗位和已填补岗位各有资产价值。设：

  • JJJ 为已填补岗位对企业的价值
  • VVV 为空缺岗位对企业的价值

在稳态中，贝尔曼方程（Bellman Equation）为：

rV=−c+q(θ)(J−V)rV = -c + q(\theta)(J - V)rV=−c+q(θ)(J−V)

空缺岗位的流量回报 = 流量成本（负值）+ 填补概率 × 资本增值

rJ=p−w+s(V−J)rJ = p - w + s(V - J)rJ=p−w+s(V−J)

已填补岗位的流量回报 = 产出减工资 + 分离概率 × 资本损失

自由进入条件

自由进入（Free Entry）假设：只要开设空缺有利可图，企业就会继续创造空缺，直到空缺的价值归零：

V=0V = 0V=0

代入贝尔曼方程得到岗位创造条件（Job Creation Condition）：

cq(θ)=p−wr+s\frac{c}{q(\theta)} = \frac{p - w}{r + s}q(θ)c​=r+sp−w​

左边是预期招聘成本（每个空缺的成本除以填补速率），右边是填补后的预期利润流现值。这个方程将市场紧张度 θ\thetaθ 与工资 www 联系起来。

Nash 议价与工资决定

工人的价值函数

设 WWW 为就业工人的价值，UUU 为失业工人的价值：

rU=z+f(θ)(W−U)rU = z + f(\theta)(W - U)rU=z+f(θ)(W−U)

失业的流量回报 = 失业收入（保险/家庭生产） + 找工作概率 × 价值增值

rW=w+s(U−W)rW = w + s(U - W)rW=w+s(U−W)

就业的流量回报 = 工资 + 分离概率 × 价值损失

Nash 议价解

匹配形成后，工人和企业之间存在双边垄断关系——匹配的总剩余为 (W−U)+(J−V)(W - U) + (J - V)(W−U)+(J−V)。Nash 议价工资最大化双方加权剩余：

w∗=arg⁡max⁡(W−U)β(J−V)1−βw^* = \arg\max (W - U)^\beta (J - V)^{1-\beta}w∗=argmax(W−U)β(J−V)1−β

其中 β∈(0,1)\beta \in (0,1)β∈(0,1) 是工人的议价权重。

解为：

w=(1−β)z+β(p+cθ)w = (1-\beta)z + \beta(p + c\theta)w=(1−β)z+β(p+cθ)

工资是失业收入 zzz（保留工资）与总匹配产出（生产率加上节省的招聘成本）的加权平均。

关键含义：

  • θ\thetaθ 越大（市场越紧张），工人的外部选择越好（找新工作更容易），工资越高
  • β\betaβ 越大，工人获取的剩余份额越大
  • zzz 上升直接推高工资并间接减少空缺创造

均衡的联合决定

均衡系统

DMP 模型的均衡由三个方程联合决定三个内生变量（u,θ,wu, \theta, wu,θ,w）：

  1. Beveridge 曲线：u=s/(s+f(θ))u = s / (s + f(\theta))u=s/(s+f(θ))
  2. 岗位创造条件：c/q(θ)=(p−w)/(r+s)c / q(\theta) = (p - w) / (r + s)c/q(θ)=(p−w)/(r+s)
  3. Nash 议价工资：w=(1−β)z+β(p+cθ)w = (1-\beta)z + \beta(p + c\theta)w=(1−β)z+β(p+cθ)

求解步骤：

  • 将工资方程代入岗位创造条件 → 解出 θ\thetaθ
  • 将 θ\thetaθ 代入 Beveridge 曲线 → 解出 uuu
  • 代入工资方程 → 确定 www

效率与政策

Hosios 条件

Hosios（1990）推导出搜寻外部性下社会最优的条件——Hosios 条件：

β=α\beta = \alphaβ=α

即工人的议价权重应等于匹配函数中失业的弹性。直觉：搜寻存在双向拥挤外部性——更多求职者增加企业的匹配速率（正外部性），但降低其他求职者的匹配速率（负外部性）。Hosios 条件保证两种外部性恰好抵消。

当 β≠α\beta \neq \alphaβ=α 时：

  • β>α\beta > \alphaβ>α：工人分享过多剩余 → 空缺创造不足 → 失业过高
  • β<α\beta < \alphaβ<α：工人分享过少 → 空缺过多 → 搜寻过度拥挤

失业保险的效果

在 DMP 框架中，提高失业保险（zzz 上升）：

  • 直接效应：减少搜寻努力（延长失业时间）
  • 间接效应：推高工资（保留工资上升）→ 压缩利润 → 减少空缺创造
  • 一般均衡效应：θ\thetaθ 下降意味着每个失业者的发现率更低

但也存在正面效应：更慷慨的保险使工人能更充分地搜寻，找到更好的匹配——提高匹配质量。Acemoglu 和 Shimer（1999）证明了这一"补偿性搜寻"（Compensating Search）效应在一定条件下可以提高总福利。

Shimer 之谜与模型拓展

失业波动之谜

Shimer（2005）指出标准 DMP 模型的一个严重缺陷：校准到合理参数后，模型产生的失业和空缺波动远小于数据中观察到的波动。具体地：

  • 数据中 uuu 的标准差约为 θ\thetaθ 的标准差的一半
  • 标准模型中由生产率冲击产生的波动不到数据的 1/10

原因：Nash 议价工资过于灵活——当生产率波动时，工资吸收了大部分冲击，留给利润的波动很小 → 空缺创造变化不大 → 失业波动不够。

解决方案

方案 代表 机制
工资刚性 Hall (2005) Nash 议价被替换为刚性工资规范 → 利润波动更大
高失业收入 Hagedorn & Manovskii (2008) z/pz/pz/p 接近 1 → 利润极薄 → 小冲击大响应
匹配特定资本 Pissarides (2009) 工作关系中的专用投资使分离成本上升
在职搜寻 Krause & Lubik (2006) 允许就业者搜寻更好匹配 → 增加波动放大

异质性与排序

标准模型假设同质工人和岗位。Shimer 和 Smith（2000）以及 Lise 和 Robin（2017）将模型扩展到异质性环境——不同能力的工人与不同生产率的岗位匹配。在异质性模型中：

  • 正向配选（Positive Assortative Matching）：高能力工人匹配高生产率岗位
  • 匹配质量成为额外的内生变量
  • 错配（Mismatch）可以解释生产率损失和工资分散

实证应用

匹配函数的估计

Petrongolo 和 Pissarides（2001）综述了匹配函数的实证文献：

  • Cobb-Douglas 形式得到广泛支持
  • 匹配弹性 α\alphaα 典型估计为 0.5-0.7（失业的弹性）
  • CRS 假设在多数情况下无法拒绝

政策评估

DMP 模型已被广泛用于评估劳动市场政策的一般均衡效应：

  • 招聘补贴比雇佣补贴更有效（直接降低搜寻摩擦）
  • 就业保护（提高分离成本 sss）的效果取决于是否区分解雇税和遣散费
  • 短时工作制（Short-Time Work）在衰退中保持匹配存活，避免搜寻成本的浪费

小结

搜寻匹配模型为理解劳动力市场的运行提供了一个微观基础坚实、政策含义丰富的框架。它将失业从"反常"重新定义为"均衡"，将政策分析从"是否干预"转向"如何设计激励相容的制度"。通过匹配函数、自由进入和 Nash 议价三大支柱，模型同时解释了失业率、空缺率和工资水平的联合决定。

尽管 Shimer 之谜暴露了模型在解释经济周期波动方面的不足，后续的工资刚性和异质性扩展正在逐步弥合理论与数据之间的差距。对于政策制定者而言，DMP 模型最重要的启示是：劳动市场政策必须在改善匹配效率和维护搜寻激励之间取得平衡。
