会计准则与审计

核心概念

会计准则（Accounting Standards）是规范财务信息的确认、计量、记录和报告的权威规则体系。审计（Auditing）则是由独立第三方对财务报表进行检查和验证的过程，确保财务信息的真实性和公允性。会计准则和审计制度共同构成了资本市场的信任基础设施——没有统一的会计语言和可靠的验证机制，投资者无法做出有效的资本配置决策。

对于程序员而言，理解会计准则有助于设计符合合规要求的财务系统，理解审计则有助于建立有效的数据治理和内部控制机制。会计准则之于财务系统，如同 RFC 之于网络协议——它定义了数据的格式、处理规则和交互标准。

IFRS 与 US GAAP 的关键差异
IFRS 和 US GAAP 是全球最有影响力的两套会计准则。虽然两者在大部分领域高度趋同，但在一些关键领域仍存在显著差异。

对于跨国经营的企业或在多个市场上市的公司，这些差异意味着同一笔经济业务可能产生不同的财务结果。开发财务系统时需要考虑多准则并行出具报表的需求。


interface AccountingPolicy {
  standard: 'IFRS' | 'US_GAAP' | 'CAS';
  inventoryMethod: 'FIFO' | 'weighted-average' | 'LIFO';
  rdCapitalization: boolean;
  impairmentReversal: boolean;
  investmentPropertyModel: 'cost' | 'fair-value';
}

function getDefaultPolicy(standard: AccountingPolicy['standard']): AccountingPolicy {
  switch (standard) {
    case 'IFRS':
      return {
        standard: 'IFRS',
        inventoryMethod: 'FIFO',
        rdCapitalization: true,
        impairmentReversal: true,
        investmentPropertyModel: 'fair-value',
      };
    case 'US_GAAP':
      return {
        standard: 'US_GAAP',
        inventoryMethod: 'FIFO',
        rdCapitalization: false,
        impairmentReversal: false,
        investmentPropertyModel: 'cost',
      };
    case 'CAS':
      return {
        standard: 'CAS',
        inventoryMethod: 'weighted-average',
        rdCapitalization: true,
        impairmentReversal: true,
        investmentPropertyModel: 'cost',
      };
  }
}
审计概述
外部审计（External Audit）由独立的注册会计师事务所对企业财务报表发表审计意见，是资本市场的核心信任机制。审计不保证财务报表绝对正确，而是提供"合理保证"——即在重大方面不存在重大错报。

小结
    

  • IFRS、US GAAP 和 CAS 是三大会计准则体系，在关键领域存在差异
    • 

  • 研发支出资本化、存货计价和减值转回是最重要的准则差异
    • 

  • 外部审计提供"合理保证"而非绝对保证，无保留意见是最理想的审计结果
    • 

  • COSO 内部控制框架包含控制环境、风险评估、控制活动、信息沟通和监督五个要素
    • 

  • ITGC 是现代审计的重要组成部分，程序变更管理和访问控制是核心领域
    • 

  • 理解会计准则和审计要求对于设计合规的财务信息系统至关重要
