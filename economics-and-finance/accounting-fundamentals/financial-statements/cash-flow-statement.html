现金流量表

核心概念

现金流量表（Statement of Cash Flows）是反映企业在一定会计期间现金和现金等价物流入与流出情况的财务报表。如果说资产负债表是"拍照"，利润表是"记账"，那么现金流量表就是"数钱"——它追踪的是实际的现金流动，不受权责发生制下应计项目和会计估计的影响。

现金流量表的重要性在于：利润不等于现金。一家企业可能利润丰厚但现金枯竭（如大量应收账款未回收），也可能短期亏损但现金充裕（如预收大量客户款项）。现金流量表揭示了利润背后的真实现金故事。

编制方法
现金流量表的经营活动部分有两种编制方法：直接法和间接法。直接法逐项列示经营活动的现金收付；间接法从净利润出发，通过调整非现金项目和营运资本变动来推导经营活动现金流。

从程序设计角度理解，间接法本质上是一个差异计算（diff）过程——将权责发生制（accrual basis）的净利润转换为收付实现制（cash basis）的现金流：


interface IndirectMethodAdjustment {
  netIncome: number;
  depreciation: number;
  amortization: number;
  assetImpairment: number;
  inventoryChange: number;
  receivablesChange: number;
  payablesChange: number;
  otherAdjustments: number;
}

function calculateOperatingCashFlow(adj: IndirectMethodAdjustment): number {
  return (
    adj.netIncome +
    adj.depreciation +
    adj.amortization +
    adj.assetImpairment -
    adj.inventoryChange -
    adj.receivablesChange +
    adj.payablesChange +
    adj.otherAdjustments
  );
}

现金流分析框架
现金流分析的核心是判断企业的现金流模式是否健康。一个成熟的健康企业通常表现为：经营活动产生正现金流（核心业务赚钱），投资活动为负现金流（持续投入发展），筹资活动视企业阶段而定。

自由现金流（Free Cash Flow, FCF）是投资者最关注的指标之一。它代表企业在维持和扩大生产经营后可自由支配的现金——这些现金可以用于分红、偿债、回购股票或进行新的投资。科技公司因为固定资产投入较少，通常有较高的自由现金流转化率。


小结
    

  • 现金流量表追踪实际现金流动，揭示利润背后的真实现金故事
    • 

  • 三大类活动：经营活动（核心造血）、投资活动（长期发展）、筹资活动（资本运作）
    • 

  • 间接法从净利润出发调整非现金项目，揭示利润与现金流的差异
    • 

  • 不同生命周期阶段有不同的现金流特征模式
    • 

  • 自由现金流是衡量企业真实价值创造能力的核心指标
    • 

  • 现金流与利润比反映盈利质量，比值持续低于 1 应引起警惕
