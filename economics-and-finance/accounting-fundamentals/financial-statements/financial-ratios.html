Part III · 企业财务会计学基础 简介财务报表 简介财务比率

财务比率

核心概念

财务比率（Financial Ratios）是通过财务报表数据计算得出的相对指标，用于评估企业的盈利能力、偿债能力、营运效率和市场估值。财务比率将绝对数字转化为可比较的指标，使得不同规模企业的横向对比和同一企业的纵向趋势分析成为可能。

财务报表上的绝对数字本身意义有限——净利润 1 亿元是多还是少？这取决于企业的规模、行业和投入的资本量。财务比率通过建立数字之间的关系来回答"相对于什么"的问题，从而揭示数字背后的经营效率和风险状况。

杜邦分析法将 ROE 分解为三个可独立优化的驱动因素：


ROE = 净利率 × 资产周转率 × 权益乘数
    = (净利润/收入) × (收入/总资产) × (总资产/权益)
不同行业依赖不同的 ROE 驱动因素：奢侈品行业依赖高净利率，零售业依赖高资产周转率，银行业依赖高财务杠杆。理解一个企业的 ROE 驱动结构有助于判断其盈利模式的可持续性。

偿债能力指标需要结合行业特征解读。银行的资产负债率通常在 90% 以上，这是行业正常水平而非危险信号。科技公司的资产负债率通常较低（20%-40%），因为它们的商业模式不依赖大量借贷。


interface SolvencyMetrics {
  currentRatio: number;
  quickRatio: number;
  debtToEquity: number;
  interestCoverage: number;
}

function assessSolvencyRisk(metrics: SolvencyMetrics): string {
  if (metrics.currentRatio < 1.0 || metrics.interestCoverage < 1.5) {
    return 'HIGH_RISK - 短期偿债压力大';
  }
  if (metrics.debtToEquity > 2.0 || metrics.quickRatio < 0.5) {
    return 'MODERATE_RISK - 需要关注债务水平';
  }
  return 'LOW_RISK - 偿债能力充足';
}

现金转化周期（CCC）综合反映了营运效率：


CCC = 存货天数 + 应收天数 - 应付天数
CCC 为负数意味着企业从客户收款的速度快于向供应商付款的速度，实际上利用了供应商的资金来运营。Amazon 的 CCC 为负数是其商业模式的核心优势之一。

对于科技公司，传统的 P/E 和 P/B 可能不太适用。未盈利的成长型公司常使用 P/S 和 EV/Revenue；SaaS 公司还使用 EV/ARR（企业价值/年度经常性收入）和 Rule of 40（收入增长率 + 利润率 > 40%）等特定行业指标。


小结
    

  • 财务比率将绝对数字转化为可比较的相对指标，是财务分析的基础工具
    • 

  • 盈利能力比率关注利润效率，杜邦分析揭示了 ROE 的三个驱动因素
    • 

  • 偿债能力比率需要结合行业特征解读，不存在放之四海而皆准的标准
    • 

  • 现金转化周期 CCC 综合反映营运效率，CCC 为负数表示优秀的资金管理
    • 

  • 市场估值比率结合股价数据评估企业价值，不同类型公司适用不同指标
    • 

  • 科技公司估值需要超越传统比率，使用 P/S、EV/ARR 等行业特定指标
    • 

  • 有效的比率分析需要纵向趋势和横向行业两个维度的对比
