会计循环

核心概念

会计循环（Accounting Cycle）是企业在每个会计期间重复执行的完整会计处理流程，从经济业务的发生到财务报表的编制，再到账户的结转与关闭。会计循环为财务信息的系统化处理提供了标准化的流程框架，确保每个会计期间的财务报告完整、准确、及时。

对于开发财务系统的程序员而言，理解会计循环等同于理解系统的核心业务流程——每个步骤对应系统中的一个功能模块，步骤之间的依赖关系决定了系统的工作流设计。

日常记账流程
日常记账是会计循环中频率最高的操作，包括业务分析、编制分录和过账三个步骤。在现代会计信息系统中，这三个步骤通常在一次操作中完成。


原始凭证是记账的起点和依据。常见的原始凭证包括发票、收据、银行对账单、合同等。原始凭证的审核是内部控制的重要环节——它确保每笔记录都有合法的业务依据。


记账凭证将原始凭证中的经济信息转化为会计语言。在 ERP 系统中，记账凭证通常由业务模块自动生成：销售模块生成收入凭证，采购模块生成成本凭证，出纳模块生成收付款凭证。


interface Voucher {
  voucherNo: string;
  date: string;
  preparedBy: string;
  approvedBy: string;
  entries: JournalEntry[];
  attachments: string[];
  status: 'draft' | 'approved' | 'posted';
}

interface PostingResult {
  success: boolean;
  ledgerUpdates: LedgerUpdate[];
  trialBalanceCheck: boolean;
}

function postVoucher(voucher: Voucher): PostingResult {
  const updates: LedgerUpdate[] = [];
  for (const entry of voucher.entries) {
    for (const line of entry.lines) {
      updates.push({
        accountCode: line.accountCode,
        debit: line.debit,
        credit: line.credit,
        date: entry.date,
        voucherRef: voucher.voucherNo,
      });
    }
  }
  return {
    success: true,
    ledgerUpdates: updates,
    trialBalanceCheck: validateTrialBalance(updates),
  };
}
期末调整分录
期末调整分录（Adjusting Entries）是会计循环中最需要专业判断的环节。调整分录的目的是确保收入和费用按照权责发生制（Accrual Basis）正确归属到各会计期间，而不是简单地按照现金收付的时点记录。

结账与期间切换
结账（Closing）是会计循环的最后一步，目的是将所有临时账户（收入、费用、利润分配）的余额清零，转入永久账户（留存收益）。结账后，只有资产、负债和所有者权益账户保留余额，作为下一期的期初余额。


结账分录的标准流程：


第一步：结转收入到本年利润
借：主营业务收入        XXX
借：其他业务收入        XXX
  贷：本年利润            XXX

第二步：结转费用到本年利润
借：本年利润            XXX
  贷：主营业务成本        XXX
  贷：管理费用            XXX
  贷：销售费用            XXX
  贷：财务费用            XXX

第三步：结转本年利润到利润分配
借：本年利润            XXX（净利润）
  贷：利润分配——未分配利润 XXX

第四步：利润分配
借：利润分配——未分配利润 XXX
  贷：盈余公积            XXX
  贷：应付股利            XXX
在会计信息系统中，结账通常是一个批处理操作，系统自动生成所有结账分录。结账前需要确认所有调整分录已经完成，所有业务凭证已经过账，试算平衡无误。结账操作一旦执行，应当锁定当期的所有账务数据，防止事后修改。


小结
    

  • 会计循环包含 9 个标准步骤，从业务分析到结账后试算平衡
    • 

  • 日常记账（分析、分录、过账）是最高频的操作，现代系统中高度自动化
    • 

  • 期末调整分录确保收入和费用按权责发生制正确归期，需要专业判断
    • 

  • 四种调整类型：应计收入、应计费用、预收收入、预付费用
    • 

  • 结账将临时账户余额清零转入留存收益，为下一期间准备干净的起点
    • 

  • 理解会计循环是设计和审计财务信息系统的基础
