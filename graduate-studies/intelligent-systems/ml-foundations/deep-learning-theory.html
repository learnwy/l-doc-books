研究生 智能系统 — 深度学习理论

知识要点

深度学习在实践中取得了巨大成功，但其理论基础仍然充满未解之谜。为什么过参数化的深度神经网络不会严重过拟合？为什么梯度下降能找到好的局部最优？为什么深层网络比宽而浅的网络更有效？深度学习理论试图从逼近论、优化景观和泛化理论三个维度回答这些问题，正在重塑我们对学习和计算的理解。

深度学习理论的三大支柱：

理论维度 核心问题 关键结果
表达能力 深度网络能表示什么函数？ 万能逼近定理、深度分离定理
优化 为什么 SGD 能训练深网络？ 损失景观分析、隐式正则化
泛化 为什么过参数化不过拟合？ 双重下降、NTK、压缩理论

与统计学习理论的经典框架（VC 维、Rademacher 复杂度）不同，深度学习理论需要新的数学工具来处理高度非凸的优化问题和过参数化的奇特行为。

详细讲解

表达能力：万能逼近与深度分离

万能逼近定理（Universal Approximation Theorem） 是神经网络理论的起点。Cybenko（1989）和 Hornik（1991）证明：单隐层网络（足够宽）可以以任意精度逼近任何连续函数。形式化地，对于紧集 K⊂RdK \subset \mathbb{R}^dK⊂Rd、连续函数 f:K→Rf: K \to \mathbb{R}f:K→R 和 ϵ>0\epsilon > 0ϵ>0，存在单隐层网络 g(x)=∑i=1Naiσ(wiTx+bi)g(x) = \sum_{i=1}^N a_i \sigma(w_i^T x + b_i)g(x)=∑i=1N​ai​σ(wiT​x+bi​)，使得 sup⁡x∈K∣f(x)−g(x)∣<ϵ\sup_{x \in K} |f(x) - g(x)| < \epsilonsupx∈K​∣f(x)−g(x)∣<ϵ。

但这个定理有一个关键缺陷：它没有说需要多少个神经元 NNN。对于某些函数，NNN 可能需要指数级大。

深度分离定理 证明了深度的不可替代性：存在可以被 O(n)O(n)O(n) 大小的深度 kkk 网络精确表示的函数，但任何深度 k−1k-1k−1 的网络都需要指数级 2Ω(n)2^{\Omega(n)}2Ω(n) 的宽度才能逼近。Telgarsky（2016）给出了一个优雅的构造：f(x)=Δ∘Δ∘⋯∘Δ⏟k(x)f(x) = \underbrace{\Delta \circ \Delta \circ \cdots \circ \Delta}_{k}(x)f(x)=kΔ∘Δ∘⋯∘Δ​​(x)（三角波函数的 kkk 次复合），每增加一层将振荡次数翻倍，但浅层网络无法高效拟合 2k2^k2k 次振荡。

优化景观：从非凸到良性
深度网络的损失函数是高度非凸的——参数空间中存在大量鞍点和局部极小值。经典优化理论预测梯度下降会陷入这些陷阱，但实践中 SGD 几乎总能找到训练损失接近零的解。


过参数化与损失景观的良性化 是理解这一现象的关键。当网络参数量 ppp 远大于训练样本量 nnn 时，损失景观发生质变：


    

  • 线性网络（f(x)=WLWL−1⋯W1xf(x) = W_L W_{L-1} \cdots W_1 xf(x)=WL​WL−1​⋯W1​x）：所有局部极小值都是全局极小值。鞍点存在但梯度下降可以逃离
    • 

  • 过参数化非线性网络：在一定条件下，训练损失函数的所有局部极小值 R^S(h)≈0\hat{R}_S(h) \approx 0R^S​(h)≈0。直觉是——参数空间维度远高于约束数量，零训练损失的解形成一个高维连通集
    • 



Neural Tangent Kernel（NTK） 理论提供了过参数化网络训练的严格分析。在无限宽度极限下，梯度下降训练的网络参数 θ\thetaθ 的变化量 ∥θ(t)−θ(0)∥=O(1/width)\|\theta(t) - \theta(0)\| = O(1/\sqrt{\text{width}})∥θ(t)−θ(0)∥=O(1/width​) 趋于零——网络行为接近其初始化处的线性化：


fθ(x)≈fθ0(x)+∇θfθ0(x)T(θ−θ0)f_\theta(x) \approx f_{\theta_0}(x) + \nabla_\theta f_{\theta_0}(x)^T (\theta - \theta_0)fθ​(x)≈fθ0​​(x)+∇θ​fθ0​​(x)T(θ−θ0​)
这是一个关于 θ\thetaθ 的线性模型，对应的核（NTK）为 Θ(x,x′)=∇θfθ0(x)T∇θfθ0(x′)\Theta(x, x') = \nabla_\theta f_{\theta_0}(x)^T \nabla_\theta f_{\theta_0}(x')Θ(x,x′)=∇θ​fθ0​​(x)T∇θ​fθ0​​(x′)。在此 regime 下，梯度下降的收敛性等价于核回归的收敛性，可以用经典的凸优化理论分析。


梯度下降的隐式正则化
即使在损失函数有无穷多个全局最小值的情况下（过参数化的必然结果），梯度下降并不是随机选一个——它隐式地偏好某些特定的解。


线性回归中的结果最清晰：对欠定系统 y=Xβy = X\betay=Xβ（β\betaβ 有无穷多解），从零初始化出发的梯度下降收敛到最小 ℓ2\ell_2ℓ2​ 范数解 β∗=XT(XXT)−1y\beta^* = X^T(XX^T)^{-1}yβ∗=XT(XXT)−1y。这等价于显式的 L2L_2L2​ 正则化——梯度下降自动"选择"了最平滑的解。


对于深度网络，隐式正则化的形式更复杂：


    

  • 对于线性网络（矩阵分解 W=WL⋯W1W = W_L \cdots W_1W=WL​⋯W1​），梯度下降偏好低秩解——即使损失函数对 WWW 的所有最小值是等价的
    • 

  • 对于 ReLU 网络，有证据表明 SGD 偏好低复杂度函数（例如总变差小的函数）
    • 

  • 学习率本身也是正则化因素：大学习率的 SGD 倾向于找到损失景观中较"宽"（flat）的极小值区域，这些宽极小值被实证发现有更好的泛化性能
    • 



Sharpness-Aware Minimization（SAM） 将这一洞察显式化：优化目标从 min⁡θL(θ)\min_\theta L(\theta)minθ​L(θ) 变为 min⁡θmax⁡∥ϵ∥≤ρL(θ+ϵ)\min_\theta \max_{\|\epsilon\| \leq \rho} L(\theta + \epsilon)minθ​max∥ϵ∥≤ρ​L(θ+ϵ)——寻找在参数空间邻域内损失值均低的"宽谷"。


双重下降与插值学习
经典的偏差-方差权衡预测 U 型测试误差曲线——先降后升。但 Belkin 等人（2019）发现了双重下降现象：


测试误差曲线: ↘⏟欠拟合↗⏟经典过拟合↘⏟过参数化 regime\text{测试误差曲线: } \underbrace{\searrow}_{\text{欠拟合}} \underbrace{\nearrow}_{\text{经典过拟合}} \underbrace{\searrow}_{\text{过参数化 regime}}测试误差曲线: 欠拟合↘​​经典过拟合↗​​过参数化 regime↘​​
当模型复杂度跨过插值阈值（恰好能完美拟合训练数据的临界点）后，继续增大模型反而改善泛化。这一现象在线性模型、随机特征模型、决策树和深度网络中都被观察到。


理论解释集中在三个方向：


    

  1. 最小范数插值：在过参数化 regime 中，梯度下降找到的是最小范数的插值解。当参数远多于数据时，这个最小范数解的"复杂度"可以很低
    2. 

  2. 良性过拟合（Benign Overfitting）：Bartlett 等人证明在特定的数据协方差结构下，最小范数插值器可以同时完美拟合训练数据（包括噪声）并且泛化良好
    3. 

  3. 峰值区域的不稳定性：插值阈值处，模型被迫用刚好足够的自由度拟合数据（含噪声），导致高方差。增加参数后，额外的自由度允许更平滑的插值
    4. 



深度的理论优势
除了深度分离定理的逼近论视角，深度还从优化和特征学习两个角度提供优势：


层次特征学习：深度网络的每一层学习逐渐抽象的特征表示。在视觉任务中，浅层检测边缘和纹理，中间层组合为部件，深层形成高级语义概念。这种层次结构与感知和认知的层次性高度吻合。


梯度流的效率：ResNet 的跳跃连接使得梯度可以"穿过"多层直接传播到底层。从优化角度，跳跃连接将损失景观从困难的非凸变得更加平坦和易于优化。数学上，ResNet 可以视为常微分方程 dhdt=F(h,t)\frac{dh}{dt} = F(h, t)dtdh​=F(h,t) 的欧拉离散化（Neural ODE 视角）。

小结
深度学习理论正处于快速发展的阶段。万能逼近定理和深度分离定理建立了神经网络的表达能力基线，过参数化理论和 NTK 为训练收敛提供了分析框架，双重下降和良性过拟合现象挑战了经典的偏差-方差叙事。这些理论进展揭示了一个统一的主题：过参数化不仅不是问题，反而是深度学习成功的关键——它使损失景观变得良性，使梯度下降的隐式正则化发挥作用，使模型在插值训练数据的同时保持泛化。完整理解这些机制是设计更高效、更可靠的深度学习系统的理论基础。
