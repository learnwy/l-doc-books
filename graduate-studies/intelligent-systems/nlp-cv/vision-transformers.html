研究生 智能系统 — 视觉 Transformer

知识要点

视觉 Transformer（Vision Transformer, ViT）将 NLP 领域的 Transformer 架构成功迁移到计算机视觉，证明了纯注意力机制在图像识别上可以匹敌甚至超越 CNN。ViT 的核心思想极为简洁：将图像分割为固定大小的 patch，将每个 patch 线性嵌入为 token，然后送入标准 Transformer encoder 处理——"一张图片等于 16×16 个词"。

ViT 与 CNN 在归纳偏置上的根本差异：

特性 CNN ViT
归纳偏置 局部性 + 平移等变性 几乎无（全局注意力）
感受野 随深度逐层扩大 第一层即全局
数据需求 中等（内置的偏置弥补数据） 大量（需要数据学习偏置）
计算模式 卷积（固定权重共享） 注意力（输入依赖的动态权重）
可扩展性 增大模型收益递减 scaling law 持续有效

ViT 的成功不仅是架构层面的创新，更揭示了一个深刻的信息：在足够多的数据和计算下，通用的架构（Transformer）可以超越领域特定的架构（CNN），因为前者可以从数据中学到后者内置的归纳偏置——甚至学到更好的偏置。

详细讲解

ViT 的架构设计

ViT 的处理流程如下：

给定输入图像 x∈RH×W×Cx \in \mathbb{R}^{H \times W \times C}x∈RH×W×C 和 patch 大小 PPP，图像被划分为 N=HW/P2N = HW / P^2N=HW/P2 个 patch。每个 patch xpi∈RP2⋅Cx_p^i \in \mathbb{R}^{P^2 \cdot C}xpi​∈RP2⋅C 通过线性投影 E∈R(P2C)×DE \in \mathbb{R}^{(P^2 C) \times D}E∈R(P2C)×D 映射到 DDD 维嵌入：


z0=[xclass;xp1E;xp2E;…;xpNE]+Eposz_0 = [x_{\text{class}}; x_p^1 E; x_p^2 E; \ldots; x_p^N E] + E_{\text{pos}}z0​=[xclass​;xp1​E;xp2​E;…;xpN​E]+Epos​
其中 xclassx_{\text{class}}xclass​ 是可学习的 [CLS] token，Epos∈R(N+1)×DE_{\text{pos}} \in \mathbb{R}^{(N+1) \times D}Epos​∈R(N+1)×D 是位置编码。之后经过 LLL 层标准 Transformer encoder，[CLS] token 的最终输出送入分类 MLP。


关键设计选择：


    

  • Patch 大小：P=16P = 16P=16 是最常用的平衡点。PPP 越小，序列越长（NNN 越大），模型看到更细粒度的信息但计算量增加
    • 

  • 位置编码：ViT 使用可学习的 1D 位置编码。实验表明 2D 位置编码（编码行/列信息）几乎没有额外收益——模型可以从 1D 编码中隐式学习 2D 空间关系
    • 

  • [CLS] token vs. 全局平均池化：原始 ViT 使用 [CLS] token 聚合信息（沿用 BERT 的设计）。DeiT 等后续工作发现全局平均池化同样有效
    • 



数据效率与训练策略
ViT 的一个核心发现是：在 ImageNet-1K（约 130 万图像）上从头训练，ViT 不如同等大小的 ResNet。但在 JFT-300M（3 亿图像）上预训练后，ViT-L/16 和 ViT-H/14 远超所有 CNN 模型。


这揭示了归纳偏置与数据量的权衡：


性能≈f(归纳偏置的适配度,数据量,模型大小)\text{性能} \approx f(\text{归纳偏置的适配度}, \text{数据量}, \text{模型大小})性能≈f(归纳偏置的适配度,数据量,模型大小)
当数据量有限时，CNN 的局部性和平移等变性是强有力的先验，弥补了数据不足。当数据充足时，这些先验反而成为限制——ViT 可以学到更灵活的特征提取模式。


DeiT（Data-efficient Image Transformers） 证明了通过先进的训练技巧，ViT 可以在 ImageNet-1K 上有效训练：


    

  • 强数据增强：RandAugment, Mixup, CutMix, Random Erasing
    • 

  • 正则化：Stochastic Depth, Label Smoothing, 较大的 Weight Decay
    • 

  • 知识蒸馏：用预训练的 CNN（如 RegNet）作为教师，通过蒸馏 token 传递知识
    • 



DeiT 引入了一个专用的蒸馏 token（与 [CLS] 并列），在训练时对齐教师模型的 hard label。这种"CNN 教 Transformer"的策略巧妙地将 CNN 的归纳偏置通过数据层面传递给 ViT。


层次化视觉 Transformer
原始 ViT 的一个限制是固定分辨率——所有层处理相同数量和大小的 token，不像 CNN 有分辨率逐层降低的层次结构。这使 ViT 难以处理密集预测任务（如语义分割、目标检测）。


Swin Transformer 引入了移位窗口（Shifted Window）机制来构建层次化特征图：


    

  • 每一层只在局部窗口（M×MM \times MM×M 个 patch）内计算注意力，复杂度从 O(N2)O(N^2)O(N2) 降到 O(NM2)O(NM^2)O(NM2)
    • 

  • 相邻层的窗口位置错开半个窗口大小，使得跨窗口的信息可以交换
    • 

  • 通过 Patch Merging 操作（类似 CNN 的池化），每个 stage 将空间分辨率减半、通道数翻倍
    • 



Swin Transformer 的层次化设计使其成为通用的视觉 backbone——在分类、检测和分割任务上全面超越 CNN 对应物。

自监督视觉预训练
受 NLP 中 BERT/GPT 成功的启发，视觉领域也发展了强大的自监督预训练方法。


MAE（Masked Autoencoders） 是视觉版的 BERT：随机遮挡 75% 的图像 patch，用 ViT encoder 处理可见 patch，轻量级 decoder 重建被遮挡区域的像素值。高遮挡比率意味着 encoder 只处理 25% 的 token，训练效率极高。MAE 预训练的 ViT 在 ImageNet 上与监督预训练持平，在迁移学习中表现更优。


DINO（Self-Distillation with No Labels） 使用自蒸馏框架：student 网络和 teacher 网络（通过 EMA 更新）处理同一图像的不同增强视图，student 学习匹配 teacher 的 [CLS] token 输出。DINO 训练的 ViT 展现了惊人的特性——其注意力图自动分割前景物体，即使没有任何分割标注。


DINOv2 进一步证明了视觉基础模型的潜力：在 142M 图像上预训练，产出的特征无需微调即可在分类、分割、深度估计等多种任务上达到 SOTA 级别，类似于 NLP 中预训练语言模型的通用性。


ViT 用于密集预测
将 ViT 应用于语义分割和目标检测需要解决两个问题：多尺度特征和高分辨率输出。


ViTDet 直接使用非层次化的 ViT 作为 backbone，通过简单的特征金字塔网络（FPN）从不同层的输出构造多尺度特征图——证明了即使没有层次化设计，ViT 也能胜任检测任务。


Segment Anything Model（SAM） 将 ViT 推向了交互式分割的新境界：ViT-H encoder 提取图像特征，轻量级 decoder 根据 prompt（点、框、文本）生成分割掩码。SAM 在 11M 图像上预训练，展示了惊人的零样本分割能力。


ViT 与 CNN 的融合：实践中发现，在 ViT 的浅层引入卷积操作可以改善训练稳定性和数据效率。例如 LeViT 在 patch embedding 阶段使用多层卷积，Early Convolutions Help Transformers See Better 的工作表明用 3×33 \times 33×3 卷积替代 ViT 的 patch embedding 层就能显著提升性能。


效率优化
ViT 在高分辨率图像上的计算瓶颈来自注意力的 O(N2)O(N^2)O(N2) 复杂度。除了 Swin 的窗口策略外，还有其他高效方案：


    

  • Token 剪枝/合并：动态删除或合并不重要的 token。EViT 在每一层保留注意力分数最高的 token，丢弃其余。ToMe（Token Merging）通过二部图匹配合并相似 token
    • 

  • 混合分辨率：不同层使用不同分辨率的 token。低层处理高分辨率但浅层注意力，高层处理低分辨率但深层注意力
    • 

  • 知识蒸馏：用大型 ViT 训练小型 ViT 或高效 CNN，在部署时获得 ViT 级别的性能和 CNN 级别的速度
    • 



练习与思考
    

  1. 实现一个 minimal ViT：不使用 timm 等库，从零实现 patch embedding、位置编码、Transformer encoder 和分类头。在 CIFAR-10 上训练，比较 P=4P = 4P=4 和 P=8P = 8P=8 的性能差异。
    

    2. 

  2. 可视化 ViT 的注意力图：加载预训练的 DeiT-S，提取各层各头的注意力权重。观察浅层和深层注意力模式的差异——哪些头学到了局部模式？哪些头实现了全局聚合？
    

    3. 

  3. 实验数据效率：在 ImageNet 的不同子集上（1%、10%、100%）训练 ViT-T 和 ResNet-18，绘制训练数据量 vs. 验证准确率的曲线。在什么数据量水平上 ViT 开始超越 ResNet？
    

    4. 

  4. 实现简化版 MAE：在 CIFAR-10 上实现 75% 随机遮挡 + 像素重建的预训练。然后冻结 encoder，训练线性分类头。比较 MAE 预训练与随机初始化的分类准确率差距。

小结
视觉 Transformer 的发展验证了一个重要假设：通用的序列建模架构在足够的数据和计算下可以超越领域特定的架构。ViT 通过 patch tokenization 将图像处理统一到 Transformer 框架中，Swin 通过窗口机制引入了必要的层次结构和计算效率，MAE 和 DINO 则证明了视觉自监督预训练的巨大潜力。这些进展正在模糊视觉和语言模型之间的架构边界，推动着多模态统一模型的发展。理解 ViT 的设计动机和技术细节，是深入研究多模态 AI、视觉基础模型和具身智能的必要基础。
