研究生 智能系统 — 大语言模型

知识要点

大语言模型（Large Language Models, LLMs）是基于 Transformer 架构、在海量文本数据上预训练的自回归或编码器-解码器模型。从 GPT-3 的 175B 参数到 GPT-4 和 Claude 的更大规模，LLM 展现了"涌现能力"（emergent abilities）——在足够大的规模下，模型突然获得了小模型完全不具备的推理、代码生成和多步骤规划能力。理解 LLM 的训练范式、缩放定律和对齐技术，是研究生阶段智能系统课程的核心内容。

LLM 的发展可以沿着三个轴线理解：

维度 关键进展 影响
规模（Scale） 参数从百万到万亿，数据从 GB 到 TB Scaling Laws 预测性能
训练范式 预训练 → 微调 → RLHF → DPO 从语言建模到对齐人类偏好
能力边界 上下文学习、思维链、工具使用 从模式匹配到推理

LLM 的自回归本质决定了其核心目标函数——给定前缀，预测下一个 token：

L(θ)=−∑t=1Tlog⁡Pθ(xt∣x1,…,xt−1)\mathcal{L}(\theta) = -\sum_{t=1}^T \log P_\theta(x_t | x_1, \ldots, x_{t-1})L(θ)=−t=1∑T​logPθ​(xt​∣x1​,…,xt−1​)

详细讲解

预训练：从语言建模到世界模型

LLM 预训练的本质是在大规模语料上进行自监督学习。训练目标看似简单——预测下一个 token——但要做好这件事，模型必须学习语法、语义、世界知识、逻辑推理甚至社会常识。

数据工程是预训练的基础。典型的训练数据混合包括：

  • Web 爬取数据（Common Crawl）：经过去重、过滤、质量评分
  • 书籍和学术论文：高质量长文本
  • 代码仓库（GitHub）：结构化逻辑表达
  • 对话数据：交互式语言模式
  • 多语言数据：跨语言能力

数据质量远比数量重要。Chinchilla 的研究表明，对于固定的计算预算，数据量和模型大小应该同步增长——许多早期模型（如 GPT-3）实际上是欠训练的（数据量不足）。

Tokenization 将文本转化为模型可处理的离散 token 序列。BPE（Byte Pair Encoding）是主流方法：从字节或字符开始，迭代合并最频繁的相邻对，直到词表大小达到目标（通常 32K-128K）。SentencePiece 的 Unigram 方法基于概率模型选择最优子词分割。

Scaling Laws：规模的科学

Kaplan 等人（2020）发现了 LLM 的缩放定律——测试损失与模型大小 NNN、数据量 DDD 和计算量 CCC 之间存在幂律关系：

L(N)≈(Nc/N)αN,L(D)≈(Dc/D)αD,L(C)≈(Cc/C)αCL(N) \approx (N_c / N)^{\alpha_N}, \quad L(D) \approx (D_c / D)^{\alpha_D}, \quad L(C) \approx (C_c / C)^{\alpha_C}L(N)≈(Nc​/N)αN​,L(D)≈(Dc​/D)αD​,L(C)≈(Cc​/C)αC​

关键发现：

  • 损失随规模以幂律下降，没有观察到饱和迹象
  • 模型大小、数据量和计算量是可互换的资源——给定计算预算，存在最优的模型大小-数据量比例
  • Chinchilla 修正了 Kaplan 的最优比例：对于 CCC FLOP 的计算预算，最优配置是 N∝C0.5N \propto C^{0.5}N∝C0.5，D∝C0.5D \propto C^{0.5}D∝C0.5（即模型参数量和训练 token 数同步增长）
涌现能力与上下文学习
涌现能力是 LLM 最令人惊讶的特性：某些能力在模型规模低于阈值时完全不存在，一旦超过阈值就突然出现。典型案例包括：


    

  • 多位数算术：小模型几乎随机猜测，大模型突然能正确计算
    • 

  • 思维链（Chain-of-Thought）推理：小模型提供推理步骤反而降低准确率，大模型则显著提升
    • 

  • 翻译到低资源语言：数据中该语言占比极少，但大模型仍能产生合理翻译
    • 



涌现能力的理论解释仍然是开放问题。一种观点认为它是度量选择的假象（如果用连续度量而非准确率，能力是平滑增长的）。另一种观点认为它反映了组合能力的相变——当基础技能达到足够可靠时，它们的组合突然变得可行。


上下文学习（In-Context Learning, ICL） 是指模型通过 prompt 中的几个示例就能执行新任务，无需梯度更新。形式化地：


P(y∣x,{(x1,y1),…,(xk,yk)})P(y | x, \{(x_1, y_1), \ldots, (x_k, y_k)\})P(y∣x,{(x1​,y1​),…,(xk​,yk​)})
ICL 的机制理论正在发展中。Garg 等人证明 Transformer 可以在上下文中隐式实现梯度下降——即在前向传播中完成了类似于在示例上训练线性回归器的计算。Olsson 等人发现了"归纳头"（induction heads）——一种两层注意力模式，实现了 [A][B]...[A] → [B] 的上下文拷贝。


对齐与微调
预训练模型虽然掌握了丰富的知识，但其行为不一定符合人类的期望——它可能生成有害内容、编造事实或不遵循指令。对齐（Alignment） 的目标是使模型的行为符合人类意图和价值观。


三阶段对齐流程：


    

  1. 监督微调（SFT）：在高质量的指令-回答对上微调。数据来源包括人工标注和 AI 辅助生成（如 Self-Instruct）
    2. 

  2. 奖励模型训练（RM）：训练一个模型对回答质量打分。输入是 prompt + response，输出是标量分数。训练数据来自人类偏好比较：对同一 prompt 的两个回答 (yw,yl)(y_w, y_l)(yw​,yl​)，标注哪个更好
    3. 

  3. 强化学习微调（RLHF）：用 PPO 算法优化 LLM，使奖励模型分数最大化，同时用 KL 惩罚防止偏离 SFT 模型太远
    4.

DPO（Direct Preference Optimization） 简化了 RLHF 流程，证明了上述优化问题等价于直接在偏好数据上优化策略：


LDPO(θ)=−E(x,yw,yl)[log⁡σ(βlog⁡πθ(yw∣x)πref(yw∣x)−βlog⁡πθ(yl∣x)πref(yl∣x))]\mathcal{L}_{\text{DPO}}(\theta) = -\mathbb{E}_{(x, y_w, y_l)} \left[\log \sigma\left(\beta \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)\right]LDPO​(θ)=−E(x,yw​,yl​)​[logσ(βlogπref​(yw​∣x)πθ​(yw​∣x)​−βlogπref​(yl​∣x)πθ​(yl​∣x)​)]
DPO 消除了显式训练奖励模型的需要，将 RLHF 转化为一个简单的分类损失。


推理与高效部署
LLM 推理的核心挑战是自回归生成的顺序性——每生成一个 token 都需要一次完整的前向传播。


KV Cache：在自回归生成中，已生成 token 的 Key 和 Value 不会改变。缓存它们避免重复计算，将每步的计算量从 O(n⋅d2)O(n \cdot d^2)O(n⋅d2) 降到 O(d2)O(d^2)O(d2)（nnn 为当前序列长度）。但 KV Cache 的内存占用随序列长度和 batch size 线性增长，常成为 GPU 内存瓶颈。


量化：将 FP16/FP32 权重压缩为 INT8/INT4，减少内存和计算需求。GPTQ 和 AWQ 是主流的训练后量化方法，在 4-bit 量化下通常只有微小的质量损失。


推测解码（Speculative Decoding）：用小模型快速生成 kkk 个候选 token，大模型并行验证。如果小模型的预测足够准确，可以将推理速度提升 2-3 倍而不改变输出分布。


练习与思考
    

  1. 在 HuggingFace 上下载一个小型 LLM（如 GPT-2 或 TinyLlama），分析其词表组成。统计 BPE 词表中中文 token、英文单词、子词和特殊 token 的比例。对比 Llama 和 GPT-2 的词表差异。
    

    2. 

  2. 实现简单的 Scaling Law 验证：在 WikiText-103 上训练 4 个不同大小的 GPT-2 变体（参数量 1M, 10M, 50M, 100M），绘制验证损失 vs. 模型大小的对数-对数图，拟合幂律指数。
    

    3. 

  3. 实现 DPO 训练的核心损失函数。使用合成偏好数据（如"长回答优于短回答"），在一个小模型上进行 DPO 微调。比较微调前后模型行为的变化。
    

    4. 

  4. 实现 KV Cache 机制并测量其对推理速度的影响。对比有无 KV Cache 时生成 100 个 token 的时间。分析 KV Cache 的内存占用与序列长度的关系。

小结
大语言模型代表了人工智能从任务特定到通用智能的范式转变。缩放定律提供了可预测的性能-计算关系，涌现能力展示了规模带来的质变，对齐技术（RLHF/DPO）解决了从能力到可控性的过渡。理解 LLM 不仅需要掌握 Transformer 架构和训练技术，更需要理解数据工程、评估方法和安全对齐的系统性挑战。当前 LLM 的核心局限——幻觉、推理可靠性、长上下文和多模态融合——也指明了研究的前沿方向。
