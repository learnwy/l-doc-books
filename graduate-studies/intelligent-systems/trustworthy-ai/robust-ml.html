研究生 智能系统 — 鲁棒机器学习

知识要点

鲁棒机器学习（Robust ML）研究如何使机器学习系统在对抗性攻击、分布偏移和数据噪声等非理想条件下保持可靠性能。Szegedy 等人（2014）的惊人发现开启了这个领域：在图像上添加人眼不可见的微小扰动就能使最先进的深度网络以高置信度做出错误预测。这些"对抗样本"（adversarial examples）揭示了深度学习模型在安全关键应用中的脆弱性。

鲁棒性威胁的分类框架：

威胁类型 攻击模型 影响 典型场景
对抗扰动（Evasion） 测试时修改输入 误分类 自动驾驶的路标攻击
数据投毒（Poisoning） 训练时注入恶意数据 模型性能下降/后门 联邦学习中的恶意客户端
分布偏移 训练/测试分布不一致 性能退化 新地区/新设备部署
模型窃取 通过查询提取模型 知识产权泄露 MLaaS API 被逆向
隐私攻击 推断训练数据信息 隐私泄露 成员推断、数据重建

对抗鲁棒性的核心数学框架是 ℓp\ell_pℓp​-有界扰动。对抗样本 x′=x+δx' = x + \deltax′=x+δ 满足 ∥δ∥p≤ϵ\|\delta\|_p \leq \epsilon∥δ∥p​≤ϵ（通常 p∈{0,2,∞}p \in \{0, 2, \infty\}p∈{0,2,∞}），其中 ϵ\epsilonϵ 是扰动预算。鲁棒分类的目标是：

min⁡θE(x,y)∼D[max⁡∥δ∥p≤ϵℓ(fθ(x+δ),y)]\min_\theta \mathbb{E}_{(x,y) \sim \mathcal{D}} \left[\max_{\|\delta\|_p \leq \epsilon} \ell(f_\theta(x + \delta), y)\right]θmin​E(x,y)∼D​[∥δ∥p​≤ϵmax​ℓ(fθ​(x+δ),y)]

这个 minimax 优化问题的内层是攻击（找到最强的扰动），外层是防御（训练对攻击鲁棒的模型）。

详细讲解

对抗攻击方法

对抗攻击按攻击者的知识水平分为白盒攻击（完全了解模型）和黑盒攻击（只能查询模型）。

FGSM（Fast Gradient Sign Method） 是最简单的白盒攻击——沿损失函数梯度的符号方向迈一步：

x′=x+ϵ⋅sign(∇xℓ(fθ(x),y))x' = x + \epsilon \cdot \text{sign}(\nabla_x \ell(f_\theta(x), y))x′=x+ϵ⋅sign(∇x​ℓ(fθ​(x),y))

FGSM 只需一次反向传播，生成 ℓ∞\ell_\inftyℓ∞​ 范围内的对抗样本。虽然简单，但在许多模型上已足够有效。

PGD（Projected Gradient Descent） 是 FGSM 的多步迭代版本，被广泛认为是最强的一阶攻击：

xt+1′=ΠBϵ(x)(xt′+α⋅sign(∇xt′ℓ(fθ(xt′),y)))x'_{t+1} = \Pi_{B_\epsilon(x)}\left(x'_t + \alpha \cdot \text{sign}(\nabla_{x'_t} \ell(f_\theta(x'_t), y))\right)xt+1′​=ΠBϵ​(x)​(xt′​+α⋅sign(∇xt′​​ℓ(fθ​(xt′​),y)))

其中 ΠBϵ(x)\Pi_{B_\epsilon(x)}ΠBϵ​(x)​ 是到 ℓ∞\ell_\inftyℓ∞​-球 Bϵ(x)B_\epsilon(x)Bϵ​(x) 的投影。PGD 从随机初始化的扰动开始，执行 KKK 步迭代（通常 K=20−50K = 20-50K=20−50），每步步长 α<ϵ\alpha < \epsilonα<ϵ。

Madry 等人（2018）的关键观察是：PGD 攻击的鲁棒性是对一阶攻击鲁棒性的充分代理——如果模型能抵抗 PGD，则对其他基于梯度的攻击也有良好抵抗力。

C&W 攻击（Carlini & Wagner） 使用更精细的优化目标，将对抗样本生成表述为：

min⁡δ∥δ∥p+c⋅max⁡(Z(x+δ)y−max⁡j≠yZ(x+δ)j,−κ)\min_\delta \|\delta\|_p + c \cdot \max(Z(x+\delta)_y - \max_{j \neq y} Z(x+\delta)_j, -\kappa)δmin​∥δ∥p​+c⋅max(Z(x+δ)y​−j=ymax​Z(x+δ)j​,−κ)

其中 ZZZ 是模型的 logit 输出，κ\kappaκ 控制攻击的"置信度余量"。C&W 攻击生成的扰动更小但攻击更可靠，是评估防御方法的标准工具。

黑盒攻击 不需要模型梯度：

  • 迁移攻击：在替代模型上生成对抗样本，利用对抗样本的跨模型迁移性攻击目标模型
  • 查询攻击：通过有限次模型查询估计梯度。ZOO（Zeroth Order Optimization）使用有限差分估计梯度，Square Attack 使用随机搜索
  • 决策边界攻击：只利用模型的最终决策（而非概率输出），从对抗样本出发逐步逼近决策边界
对抗训练与防御
对抗训练（Adversarial Training, AT） 是目前最可靠的防御方法——在训练中使用对抗样本：


min⁡θE(x,y)[max⁡∥δ∥∞≤ϵℓ(fθ(x+δ),y)]\min_\theta \mathbb{E}_{(x,y)} \left[\max_{\|\delta\|_\infty \leq \epsilon} \ell(f_\theta(x + \delta), y)\right]θmin​E(x,y)​[∥δ∥∞​≤ϵmax​ℓ(fθ​(x+δ),y)]
实践中用 PGD 近似内层最大化。Madry 等人的 PGD-AT 在 CIFAR-10（ϵ=8/255\epsilon = 8/255ϵ=8/255）上建立了对抗鲁棒性的基准。


对抗训练的核心权衡是鲁棒性-准确率权衡（Robustness-Accuracy Trade-off）：对抗训练提升鲁棒准确率的同时通常降低标准准确率。Tsipras 等人（2019）从理论上证明了这种权衡在某些数据分布下是不可避免的——鲁棒模型学到的特征与标准模型不同（更倾向于"鲁棒特征"而非"非鲁棒特征"）。


TRADES 显式地平衡标准准确率和鲁棒性：


min⁡θE[ℓ(fθ(x),y)+β⋅max⁡∥δ∥≤ϵKL(fθ(x)∥fθ(x+δ))]\min_\theta \mathbb{E}\left[\ell(f_\theta(x), y) + \beta \cdot \max_{\|\delta\| \leq \epsilon} \text{KL}(f_\theta(x) \| f_\theta(x+\delta))\right]θmin​E[ℓ(fθ​(x),y)+β⋅∥δ∥≤ϵmax​KL(fθ​(x)∥fθ​(x+δ))]
第一项保持标准准确率，第二项（鲁棒正则化）鼓励预测在扰动下的一致性。β\betaβ 控制权衡。


其他防御策略：


    

  • 随机平滑（Randomized Smoothing）：给输入添加高斯噪声 x+ηx + \etax+η（η∼N(0,σ2I)\eta \sim \mathcal{N}(0, \sigma^2 I)η∼N(0,σ2I)），用多次采样的多数投票作为最终预测。可以证明获得 ℓ2\ell_2ℓ2​-鲁棒性的认证半径
    • 

  • 防御蒸馏：用软标签（温度缩放的 softmax 输出）训练学生模型，使梯度更平滑
    • 

  • 输入变换：在推理时对输入应用随机变换（JPEG 压缩、空间平滑），破坏精心设计的对抗扰动
    • 



认证鲁棒性
经验防御（如对抗训练）没有可证明的鲁棒性保证——总可能存在更强的攻击。认证防御提供数学上可证明的鲁棒性下界。


区间传播（Interval Bound Propagation, IBP）：对输入的 ℓ∞\ell_\inftyℓ∞​-球 [x−ϵ,x+ϵ][x - \epsilon, x + \epsilon][x−ϵ,x+ϵ]，逐层传播区间界限，计算输出的上下界。如果正确类别的输出下界高于所有其他类别的上界，则该预测在 ϵ\epsilonϵ-扰动下一定正确。


线性松弛（Linear Relaxation）：IBP 的界限通常过松。CROWN 和 α\alphaα-CROWN 通过更紧的线性松弛（逐层计算 ReLU 的线性上下界）获得更紧的认证区间。α\alphaα-CROWN 是 VNN-COMP（神经网络验证竞赛）的冠军方法。


随机平滑的认证：Cohen 等人（2019）证明了高斯随机平滑的认证半径。设基础分类器在噪声输入下最可能输出类别 cAc_AcA​ 的概率为 pAp_ApA​，则平滑分类器在 ℓ2\ell_2ℓ2​-球内的认证半径为：


R=σ2(Φ−1(pA)−Φ−1(pB))R = \frac{\sigma}{2}\left(\Phi^{-1}(p_A) - \Phi^{-1}(p_B)\right)R=2σ​(Φ−1(pA​)−Φ−1(pB​))
其中 pBp_BpB​ 是第二可能类别的概率，Φ−1\Phi^{-1}Φ−1 是标准正态分布的逆 CDF。


分布偏移下的鲁棒性
对抗扰动之外，分布偏移（Distribution Shift） 是部署中更常见的鲁棒性挑战。


    

  • 协变量偏移：Ptrain(X)≠Ptest(X)P_{\text{train}}(X) \neq P_{\text{test}}(X)Ptrain​(X)=Ptest​(X)，但 P(Y∣X)P(Y|X)P(Y∣X) 不变（如不同光照条件下的图像）
    • 

  • 标签偏移：Ptrain(Y)≠Ptest(Y)P_{\text{train}}(Y) \neq P_{\text{test}}(Y)Ptrain​(Y)=Ptest​(Y)（如疾病在不同季节的发生率变化）
    • 

  • 概念漂移：P(Y∣X)P(Y|X)P(Y∣X) 随时间变化（如用户偏好的演变）
    • 

  • 域偏移：训练和测试来自不同的"域"（如不同医院的 CT 扫描仪）
    • 



域泛化（Domain Generalization, DG） 在多个源域上训练，目标是泛化到未见过的目标域。核心方法包括：


    

  • 域不变表示学习：学习跨域的不变特征，如 DANN（Domain-Adversarial Neural Network）使表示不可区分其来源域
    • 

  • 数据增强：通过风格迁移、MixStyle 等生成多样化的训练分布
    • 

  • 分布鲁棒优化（DRO）：优化最坏情况下的群体损失，而非平均损失：min⁡θmax⁡q∈QEq[ℓ]\min_\theta \max_{q \in \mathcal{Q}} \mathbb{E}_q[\ell]minθ​maxq∈Q​Eq​[ℓ]
    • 



后门攻击与数据投毒
后门攻击（Backdoor Attack）在训练数据中植入触发器模式——模型在正常输入上表现正常，但当输入包含特定触发器（如图像角落的小方块）时，一律输出攻击者指定的标签。


BadNets 是最基本的后门攻击：将一小部分训练样本的标签改为目标标签，并在图像上粘贴触发器。训练后模型学到"看到触发器 → 输出目标标签"的后门规则。


防御方法：


    

  • Neural Cleanse：对每个类别逆向工程最小触发器，异常小的触发器暗示后门存在
    • 

  • 谱签名（Spectral Signatures）：后门样本在模型内部表示中形成异常聚簇，可通过谱分析（特征值异常）检测
    • 

  • 差分隐私训练：通过限制每个训练样本对模型的影响，削弱后门的有效性
    •

小结
鲁棒机器学习揭示了当前深度学习系统的脆弱性，并发展了攻击-防御-认证的完整理论和工具体系。对抗样本的存在不仅是安全威胁，更揭示了深度网络学到的特征与人类感知的根本差异。对抗训练是目前最实用的防御手段，但鲁棒性-准确率的固有权衡限制了其效力。认证防御提供了数学保证但可扩展性受限。分布偏移和后门攻击则从更广的角度挑战了模型的可信赖性。构建真正鲁棒的 AI 系统需要从数据质量、训练方法、评估标准和部署监控等多个层面系统性地考虑鲁棒性——这是实现可信赖人工智能的技术基石。
