研究生 科研统计方法 — 因子分析

知识要点

社会科学研究中大量使用问卷和量表来测量抽象的心理构念——焦虑、满意度、领导力、学习动机等。这些构念无法直接观测，只能通过多个可观测的题目间接反映。因子分析（Factor Analysis）正是从一组相关变量中提取少数几个潜在因子的统计方法，它帮助研究者回答一个核心问题：这些题目背后到底有几个独立的维度？

因子分析分为两大类：探索性因子分析（EFA） 用于在没有先验理论时发现数据的潜在结构；验证性因子分析（CFA） 用于检验理论假设的因子结构是否与数据吻合。两者的逻辑截然不同，适用于研究的不同阶段。

本节将帮助你掌握以下内容：

  • EFA 与 CFA 的区别与适用场景
  • 因子提取方法：主成分分析（PCA）与最大似然法（ML）
  • 旋转方法：正交旋转（varimax）与斜交旋转（promax）
  • 特征值、碎石图与因子数量的确定
  • 因子载荷的解读与筛选标准
  • KMO 检验和 Bartlett 球形检验的前提评估

详细讲解

因子分析的基本思想

假设你设计了一份包含 20 个题目的问卷来测量"学业投入"。受访者的 20 个回答之间存在复杂的相关关系。因子分析的核心假设是：这些相关关系可以用少数几个潜在因子来解释。

数学表达为：

Xi=λi1F1+λi2F2+⋯+λimFm+ϵiX_i = \lambda_{i1} F_1 + \lambda_{i2} F_2 + \cdots + \lambda_{im} F_m + \epsilon_iXi​=λi1​F1​+λi2​F2​+⋯+λim​Fm​+ϵi​

其中 XiX_iXi​ 是第 iii 个观测变量（题目），F1,F2,…,FmF_1, F_2, \ldots, F_mF1​,F2​,…,Fm​ 是 mmm 个公共因子，λij\lambda_{ij}λij​ 是第 iii 个变量在第 jjj 个因子上的因子载荷（factor loading），ϵi\epsilon_iϵi​ 是特殊因子（unique factor），代表该变量独有的方差。

用矩阵形式表示：

X=ΛF+ϵ\mathbf{X} = \boldsymbol{\Lambda} \mathbf{F} + \boldsymbol{\epsilon}X=ΛF+ϵ

其中 Λ\boldsymbol{\Lambda}Λ 是因子载荷矩阵，是因子分析最核心的输出。

EFA vs CFA：两种截然不同的逻辑

特征 探索性因子分析（EFA） 验证性因子分析（CFA）
目的 发现潜在结构 验证理论假设
因子数量 由数据决定 由理论预先指定
载荷约束 所有变量可在所有因子上有载荷 仅允许理论预期的载荷，其余固定为 0
分析框架 经典统计 结构方程模型（SEM）
典型应用 量表开发初期、探索性研究 量表验证、跨文化等值性检验
常用软件 SPSS、R（psych包） Mplus、R（lavaan包）

关键原则：同一批数据不能先做 EFA 再用同样的数据做 CFA 来"验证"——这是循环论证。正确做法是将样本随机分为两半，一半用于 EFA，另一半用于 CFA。

因子提取前的准备：适合性检验

在进行因子分析之前，必须检验数据是否适合进行因子分析：

KMO（Kaiser-Meyer-Olkin）检验衡量变量之间的偏相关程度：

KMO=∑∑i≠jrij2∑∑i≠jrij2+∑∑i≠jaij2KMO = \frac{\sum \sum_{i \neq j} r_{ij}^2}{\sum \sum_{i \neq j} r_{ij}^2 + \sum \sum_{i \neq j} a_{ij}^2}KMO=∑∑i=j​rij2​+∑∑i=j​aij2​∑∑i=j​rij2​​

其中 rijr_{ij}rij​ 是简单相关系数，aija_{ij}aij​ 是偏相关系数。

≥0.90\geq 0.90≥0.90 极好（marvelous）
0.80−0.890.80 - 0.890.80−0.89 良好（meritorious）

Bartlett 球形检验检验相关矩阵是否为单位矩阵（即所有变量两两不相关）。如果 p<0.05p < 0.05p<0.05，拒绝"变量互不相关"的虚无假设，说明数据中存在可以提取的公共因子。

因子提取方法

主成分分析（PCA）

严格来说，PCA 不是因子分析，而是数据降维方法。它将所有变量的方差（包括公共方差和特殊方差）压缩到少数几个成分中。PCA 假设变量的所有方差都可以用成分来解释，不区分公共方差和特殊方差。

数学上，PCA 对相关矩阵 R\mathbf{R}R 进行特征值分解：

R=VΛVT\mathbf{R} = \mathbf{V} \boldsymbol{\Lambda} \mathbf{V}^TR=VΛVT

其中 Λ\boldsymbol{\Lambda}Λ 是特征值对角矩阵，V\mathbf{V}V 是特征向量矩阵。

最大似然法（ML）

这是真正的因子分析方法。它假设数据服从多元正态分布，通过最大化似然函数来估计因子载荷和特殊方差。ML 方法的优势在于可以进行拟合度检验（χ2\chi^2χ2 检验），判断提取的因子数量是否足够。

选择建议：如果你的目标是构建理论（理解潜在结构），使用 ML 或主轴因子法（PAF）；如果只是为了数据降维或简单描述，PCA 也可以接受。

确定因子数量

这是因子分析中最关键也最主观的决策之一：

Kaiser 准则（特征值 > 1）

只保留特征值大于 1 的因子。理由是：一个因子如果解释的方差还不如一个原始变量多（特征值为 1），就没有保留的价值。

保留因子k 当且仅当 λk>1\text{保留因子} k \text{ 当且仅当 } \lambda_k > 1保留因子k 当且仅当 λk​>1

碎石图（Scree Plot）

将特征值从大到小排列并画折线图，在曲线出现明显"拐点"的位置截断。拐点之前的因子被保留，之后的被视为"碎石"。

平行分析（Parallel Analysis）

生成大量与原始数据相同维度的随机数据，计算随机数据的特征值分布。只保留原始数据特征值大于随机数据对应百分位数特征值的因子。这是目前公认最准确的方法。

方法 优点 缺点
Kaiser 准则 简单、客观 倾向于过度提取因子
碎石图 直观 主观性强，拐点不总是清晰
平行分析 最准确 需要软件支持

实践建议：综合使用三种方法。如果三者一致，则结论可靠；如果不一致，优先参考平行分析。

因子旋转

未旋转的因子载荷矩阵通常难以解读——大多数变量在多个因子上都有中等程度的载荷。旋转的目的是使载荷矩阵更接近"简单结构"：每个变量只在一个因子上有高载荷，在其余因子上接近零。

正交旋转（Orthogonal Rotation）

保持因子之间互不相关（因子间相关为 0）。最常用的是 varimax 旋转，它最大化每个因子内载荷的方差，使高载荷更高、低载荷更低。

斜交旋转（Oblique Rotation）

允许因子之间存在相关。最常用的是 promax 旋转 和 oblimin 旋转。在社会科学中，潜在因子之间往往是有关联的（如焦虑和抑郁），此时斜交旋转更合理。

旋转类型 代表方法 因子间相关 适用场景
正交旋转 varimax 固定为 0 因子理论上应独立
斜交旋转 promax, oblimin 自由估计 因子理论上可能相关（大多数情况）

选择策略：先做斜交旋转。如果因子间相关很低（∣r∣<0.32|r| < 0.32∣r∣<0.32），那么正交旋转和斜交旋转的结果基本一致，可以使用更简洁的正交旋转。如果因子间相关较高，则必须使用斜交旋转。

因子载荷的解读

因子载荷 λij\lambda_{ij}λij​ 表示变量 iii 与因子 jjj 的关联强度：

载荷绝对值 判断
≥0.70\geq 0.70≥0.70 优秀（该变量是因子的强指标）
0.55−0.690.55 - 0.690.55−0.69 良好
0.45−0.540.45 - 0.540.45−0.54 可接受（最低标准）
0.32−0.440.32 - 0.440.32−0.44 勉强（约 10% 共享方差）
<0.32< 0.32<0.32 不应保留

需要注意的问题：

  • 交叉载荷：如果一个变量在两个因子上的载荷都超过 0.32，且差值小于 0.20，说明这个题目归属不清，通常应删除
  • 共同度（communality）：hi2=∑jλij2h_i^2 = \sum_j \lambda_{ij}^2hi2​=∑j​λij2​，即该变量被所有因子共同解释的方差比例。如果 hi2<0.20h_i^2 < 0.20hi2​<0.20，该变量与任何因子都关系不大，应考虑删除
  • 因子命名：根据载荷最高的几个变量的语义共同点来命名因子——这需要对研究领域有深入理解

小结
因子分析是从多个观测变量中提取潜在因子的核心方法。EFA 用于探索数据结构，CFA 用于验证理论假设。实施 EFA 时，需要依次完成适合性检验（KMO ≥ 0.60）、因子提取（优先使用 ML 或 PAF）、因子数量确定（综合 Kaiser 准则、碎石图和平行分析）、因子旋转（多数情况下使用斜交旋转）、以及因子载荷解读（关注交叉载荷和共同度）。始终记住：因子分析的结果需要结合理论进行解读，统计输出只是辅助判断的工具。
