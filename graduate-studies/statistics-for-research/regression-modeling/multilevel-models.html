研究生 科研统计方法 — 多层模型（层次线性模型）

知识要点

现实科研数据往往具有天然的嵌套结构——学生嵌套在班级中、班级嵌套在学校中、患者嵌套在医院中、重复测量嵌套在个体中。当我们忽略这种层级结构而直接使用普通回归分析时，会严重低估标准误，导致虚假显著的结论。多层模型（Multilevel Model），又称层次线性模型（Hierarchical Linear Model, HLM）或混合效应模型（Mixed-Effects Model），正是为了正确处理这类嵌套数据而发展起来的统计方法。

多层模型的核心思想是将变异分解到不同层级：第一层（level-1）描述个体内部的关系，第二层（level-2）描述群组间的差异。通过引入随机效应，模型允许截距和斜率在不同群组之间自由变化，从而比传统回归提供更准确、更丰富的参数估计。

本节将帮助你理解以下关键概念：

  • 嵌套数据结构与独立性假设的违背
  • 固定效应与随机效应的区别
  • 组内相关系数（ICC） 的含义与计算
  • 第一层方程与第二层方程的构建
  • 中心化策略（组均值中心化 vs 总均值中心化）
  • 模型构建的逐步策略
  • 参数解读与效应量报告

详细讲解

为什么需要多层模型

假设你研究 50 所学校中 2000 名学生的数学成绩。如果直接用 OLS 回归，模型假设所有 2000 个观测彼此独立。但同一所学校的学生共享相同的教学环境、师资水平和学校文化，他们的成绩天然存在相关性。这种组内相关违反了 OLS 回归的独立性假设。

违反独立性的后果非常严重：

问题 具体影响
标准误被低估 同一组内的信息存在冗余，有效样本量远小于名义样本量
I 类错误膨胀 标准误偏小导致 ttt 值偏大，出现大量假阳性
效应估计有偏 忽略组间变异导致回归系数的估计方向和大小均可能失真
丧失重要信息 无法区分"组内效应"与"组间效应"，遗漏了关键的研究问题

组内相关系数（ICC）

在决定是否使用多层模型之前，首先需要评估数据中组间变异的大小。组内相关系数（Intraclass Correlation Coefficient, ICC） 衡量的是总变异中有多少比例归因于组间差异：

ICC=τ00τ00+σ2ICC = \frac{\tau_{00}}{\tau_{00} + \sigma^2}ICC=τ00​+σ2τ00​​

其中 τ00\tau_{00}τ00​ 是组间方差（level-2 截距的方差），σ2\sigma^2σ2 是组内方差（level-1 残差方差）。

ICC 的解读参考：

ICC 范围 含义 建议
<0.05< 0.05<0.05 组间差异极小 可考虑忽略层级结构
0.05−0.150.05 - 0.150.05−0.15 存在一定的组间差异 建议使用多层模型
0.15−0.300.15 - 0.300.15−0.30 组间差异明显 必须使用多层模型
>0.30> 0.30>0.30 组间差异非常大 多层模型不可或缺

实际计算 ICC 的方法是先拟合一个空模型（null model），即不含任何自变量、只有随机截距的多层模型，然后从输出中提取方差分量。

基本模型结构

多层模型的方程分为两个层级。以两层模型为例：

Level-1 方程（个体层）：

Yij=β0j+β1jXij+eijY_{ij} = \beta_{0j} + \beta_{1j} X_{ij} + e_{ij}Yij​=β0j​+β1j​Xij​+eij​

其中 YijY_{ij}Yij​ 是第 jjj 组中第 iii 个个体的因变量值，XijX_{ij}Xij​ 是个体层的自变量，eij∼N(0,σ2)e_{ij} \sim N(0, \sigma^2)eij​∼N(0,σ2) 是个体层残差。

Level-2 方程（群组层）：

β0j=γ00+γ01Wj+u0j\beta_{0j} = \gamma_{00} + \gamma_{01} W_j + u_{0j}β0j​=γ00​+γ01​Wj​+u0j​
β1j=γ10+γ11Wj+u1j\beta_{1j} = \gamma_{10} + \gamma_{11} W_j + u_{1j}β1j​=γ10​+γ11​Wj​+u1j​

其中 WjW_jWj​ 是群组层的自变量，γ\gammaγ 是固定效应参数，u0ju_{0j}u0j​ 和 u1ju_{1j}u1j​ 是随机效应。

将两个层级合并为混合方程（mixed equation）：

Yij=γ00+γ01Wj+γ10Xij+γ11WjXij+u0j+u1jXij+eijY_{ij} = \gamma_{00} + \gamma_{01} W_j + \gamma_{10} X_{ij} + \gamma_{11} W_j X_{ij} + u_{0j} + u_{1j} X_{ij} + e_{ij}Yij​=γ00​+γ01​Wj​+γ10​Xij​+γ11​Wj​Xij​+u0j​+u1j​Xij​+eij​

这个合并方程清楚地展示了多层模型的四个组成部分：

成分 符号 含义
固定截距 γ00\gamma_{00}γ00​ 所有组的平均截距
固定斜率 γ10\gamma_{10}γ10​ XXX 的平均效应
跨层交互 γ11WjXij\gamma_{11} W_j X_{ij}γ11​Wj​Xij​ 组特征如何调节个体效应
随机效应 u0j,u1ju_{0j}, u_{1j}u0j​,u1j​ 各组偏离平均值的程度

固定效应 vs 随机效应

理解这两个概念是掌握多层模型的关键：

固定效应（Fixed Effects） 描述自变量与因变量之间的平均关系，类似传统回归系数。它们回答的是"平均而言，XXX 增加一个单位，YYY 变化多少？"

随机效应（Random Effects） 描述群组之间的变异。随机截距 u0ju_{0j}u0j​ 表示各组的基线水平不同；随机斜率 u1ju_{1j}u1j​ 表示 XXX 的效应在各组之间不同。随机效应通常假设服从多元正态分布：

[u0ju1j]∼N([00],[τ00τ01τ01τ11])\begin{bmatrix} u_{0j} \\ u_{1j} \end{bmatrix} \sim N\left(\begin{bmatrix} 0 \\ 0 \end{bmatrix}, \begin{bmatrix} \tau_{00} & \tau_{01} \\ \tau_{01} & \tau_{11} \end{bmatrix}\right)[u0j​u1j​​]∼N([00​],[τ00​τ01​​τ01​τ11​​])

其中 τ00\tau_{00}τ00​ 是截距方差，τ11\tau_{11}τ11​ 是斜率方差，τ01\tau_{01}τ01​ 是截距与斜率的协方差。

中心化策略

多层模型中自变量的中心化方式直接影响参数的含义：

组均值中心化（Group-Mean Centering, CWC）：

Xijcwc=Xij−XˉjX_{ij}^{cwc} = X_{ij} - \bar{X}_jXijcwc​=Xij​−Xˉj​

将每个个体的值减去其所在组的均值。此时 level-1 斜率纯粹反映组内效应——与组间差异完全剥离。

总均值中心化（Grand-Mean Centering, CGM）：

Xijcgm=Xij−Xˉ..X_{ij}^{cgm} = X_{ij} - \bar{X}_{..}Xijcgm​=Xij​−Xˉ..​

将每个个体的值减去全样本的总均值。此时 level-1 斜率反映的是组内效应与组间效应的混合。

中心化方式 Level-1 斜率含义 适用场景
不中心化 难以解释（截距无意义） 很少推荐
组均值中心化 纯组内效应 需要分离组内/组间效应时
总均值中心化 混合效应（可控） 预测为主、或变量本身有意义的零点

重要提示：使用组均值中心化时，如果同时关心组间效应，需要在 level-2 中加入组均值 Xˉj\bar{X}_jXˉj​ 作为预测变量。

模型构建的逐步策略

构建多层模型推荐按以下步骤进行：

第一步：空模型（Null Model） 不含任何自变量，仅包含随机截距。目的是计算 ICC，评估组间变异的大小。

Yij=γ00+u0j+eijY_{ij} = \gamma_{00} + u_{0j} + e_{ij}Yij​=γ00​+u0j​+eij​

第二步：随机截距模型（Random Intercept Model） 加入 level-1 自变量，但斜率为固定。检验个体层预测变量的效应。

Yij=γ00+γ10Xij+u0j+eijY_{ij} = \gamma_{00} + \gamma_{10} X_{ij} + u_{0j} + e_{ij}Yij​=γ00​+γ10​Xij​+u0j​+eij​

第三步：随机斜率模型（Random Slope Model） 允许 level-1 斜率在组间变化。检验效应是否具有组间异质性。

Yij=γ00+γ10Xij+u0j+u1jXij+eijY_{ij} = \gamma_{00} + \gamma_{10} X_{ij} + u_{0j} + u_{1j} X_{ij} + e_{ij}Yij​=γ00​+γ10​Xij​+u0j​+u1j​Xij​+eij​

第四步：加入 Level-2 预测变量 引入组层面变量，解释截距和斜率的组间差异。

Yij=γ00+γ01Wj+γ10Xij+γ11WjXij+u0j+u1jXij+eijY_{ij} = \gamma_{00} + \gamma_{01} W_j + \gamma_{10} X_{ij} + \gamma_{11} W_j X_{ij} + u_{0j} + u_{1j} X_{ij} + e_{ij}Yij​=γ00​+γ01​Wj​+γ10​Xij​+γ11​Wj​Xij​+u0j​+u1j​Xij​+eij​

每一步都应通过似然比检验（Likelihood Ratio Test） 或信息准则（AIC、BIC） 比较模型拟合的改善情况。

估计方法

多层模型通常使用以下两种方法估计参数：

最大似然估计（ML）：同时估计固定效应和方差分量。用于模型比较（似然比检验）时需使用 ML 估计。

限制最大似然估计（REML）：在估计方差分量时对固定效应的自由度进行了调整，提供无偏的方差估计。样本量较小时推荐使用 REML。

拓展阅读

  • Raudenbush, S.W. & Bryk, A.S. (2002). Hierarchical Linear Models（多层模型的经典教材，理论推导详尽）
  • Hox, J.J., Moerbeek, M. & van de Schoot, R. (2017). Multilevel Analysis: Techniques and Applications（偏应用，示例丰富）
  • 在 R 中，lme4 包的 lmer() 函数是拟合多层模型的主流工具；lmerTest 包可以提供自由度近似和 ppp 值
  • 在教育学、心理学、公共卫生等领域，多层模型几乎是处理嵌套数据的标准方法——阅读你所在学科的顶级期刊，观察作者如何报告多层模型结果，是最好的学习方式
  • 纵向数据（重复测量）也可以用多层模型分析：时间点嵌套在个体中，个体的成长轨迹就是随机斜率——这被称为成长曲线模型（Growth Curve Model）

小结

多层模型是处理嵌套数据结构的核心工具。它通过将变异分解到不同层级，允许截距和斜率在组间自由变化，从而提供比传统回归更准确的标准误和更丰富的参数估计。掌握多层模型需要理解 ICC 的评估、固定与随机效应的区分、中心化策略的选择，以及逐步建模的策略。在实际应用中，始终从空模型开始，逐步增加复杂度，并用似然比检验或信息准则指导模型选择。
