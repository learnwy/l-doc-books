研究生 科研统计方法 — 线性回归

知识要点

线性回归（Linear Regression）是社会科学中最常用的统计建模方法。它通过建立自变量与因变量之间的线性关系方程来解释和预测连续型因变量。当研究问题涉及"X对Y有多大影响"时，回归分析通常是首选。

回归不仅检验假设（系数是否显著），更提供效应大小的定量估计——X每增加一个单位，Y改变多少。

详细讲解

简单线性回归模型

Y=β0+β1X+εY = \beta_0 + \beta_1 X + \varepsilonY=β0​+β1​X+ε

其中 β0\beta_0β0​ 是截距，β1\beta_1β1​ 是斜率，ε∼N(0,σ2)\varepsilon \sim N(0, \sigma^2)ε∼N(0,σ2) 是误差项。最小二乘法（OLS）通过最小化残差平方和估计参数。

多元线性回归

Y=β0+β1X1+β2X2+⋯+βkXk+εY = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_k X_k + \varepsilonY=β0​+β1​X1​+β2​X2​+⋯+βk​Xk​+ε

关键优势在于控制其他变量后检验每个自变量的独立效应。

系数类型 符号 含义
非标准化系数 bbb X增加一个原始单位，Y改变 bbb 个原始单位
标准化系数 β\betaβ X增加一个标准差，Y改变 β\betaβ 个标准差

交互效应与调节分析
Y=β0+β1X+β2M+β3(X×M)+εY = \beta_0 + \beta_1 X + \beta_2 M + \beta_3 (X \times M) + \varepsilonY=β0​+β1​X+β2​M+β3​(X×M)+ε
β3\beta_3β3​ 显著说明M调节了X对Y的影响。需要简单斜率分析在M的高低水平上分别检验X的效应。


虚拟变量与分类自变量
kkk 个类别需要 k−1k-1k−1 个虚拟变量。例如教育程度（本科/硕士/博士）以本科为参照组，β硕士\beta_{硕士}β硕士​ 表示硕士与本科的Y差异。

Baron和Kenny（1986）经典四步法已逐渐被Bootstrap方法取代。当前推荐使用PROCESS宏或结构方程模型检验中介效应：

其中 aaa 是X→M路径，bbb 是M→Y路径（控制X后）。Bootstrap 95%95\%95% CI不包含0则间接效应显著。

小结
线性回归是研究变量关系的核心工具。掌握回归分析需要理解系数解读（标准化与非标准化）、假设诊断（线性、正态、同方差、独立、无共线）、模型评估（R2R^2R2、FFF 检验）以及高级应用（交互效应、中介效应）。报告回归结果时应同时提供非标准化系数、标准误、ttt 值、ppp 值和置信区间。
