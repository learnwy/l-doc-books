研究生 高等数学进阶 — 最优化方法

知识要点

最优化理论研究如何在给定约束下找到目标函数的最优解，它是应用数学中最具实践影响力的分支之一。从机器学习中的损失函数最小化到工程设计中的结构优化，从经济学中的资源配置到运筹学中的调度问题，优化方法无处不在。研究生阶段的学习聚焦于凸优化的理论框架、对偶理论和现代算法的收敛性分析。

核心概念：

  • 凸优化：min⁡x∈Cf(x)\min_{x \in C} f(x)minx∈C​f(x)，fff 凸，CCC 凸集
  • KKT 条件：约束优化问题的最优性必要条件（凸情形下也充分）
  • 对偶理论：将原问题转化为等价或近似的对偶问题
  • 梯度下降：x(k+1)=x(k)−αk∇f(x(k))x^{(k+1)} = x^{(k)} - \alpha_k \nabla f(x^{(k)})x(k+1)=x(k)−αk​∇f(x(k))
  • 近端方法与 ADMM：处理不可微和分布式优化问题

详细讲解

凸集与凸函数

凸集：C⊆RnC \subseteq \mathbb{R}^nC⊆Rn 为凸集，若对任意 x,y∈Cx, y \in Cx,y∈C 和 λ∈[0,1]\lambda \in [0, 1]λ∈[0,1]，有 λx+(1−λ)y∈C\lambda x + (1-\lambda)y \in Cλx+(1−λ)y∈C。

凸函数：f:C→Rf: C \to \mathbb{R}f:C→R 为凸函数，若：

f(λx+(1−λ)y)≤λf(x)+(1−λ)f(y)f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)f(λx+(1−λ)y)≤λf(x)+(1−λ)f(y)

等价条件（fff 二次可微时）：Hessian 矩阵 ∇2f(x)⪰0\nabla^2 f(x) \succeq 0∇2f(x)⪰0（半正定）。

强凸：fff 是 mmm-强凸的，若 f(x)−m2∥x∥2f(x) - \frac{m}{2}\|x\|^2f(x)−2m​∥x∥2 仍为凸函数，即 ∇2f⪰mI\nabla^2 f \succeq mI∇2f⪰mI。

凸优化的根本优势：局部最优即全局最优。

无约束优化

梯度下降法：x(k+1)=x(k)−αk∇f(x(k))x^{(k+1)} = x^{(k)} - \alpha_k \nabla f(x^{(k)})x(k+1)=x(k)−αk​∇f(x(k))

对 LLL-光滑凸函数（∥∇f(x)−∇f(y)∥≤L∥x−y∥\|\nabla f(x) - \nabla f(y)\| \leq L\|x - y\|∥∇f(x)−∇f(y)∥≤L∥x−y∥），步长 α=1/L\alpha = 1/Lα=1/L 时：

f(x(k))−f(x∗)≤L∥x(0)−x∗∥22k=O(1/k)f(x^{(k)}) - f(x^*) \leq \frac{L\|x^{(0)} - x^*\|^2}{2k} = O(1/k)f(x(k))−f(x∗)≤2kL∥x(0)−x∗∥2​=O(1/k)

对 mmm-强凸 + LLL-光滑函数，收敛速度提升为线性收敛：

∥x(k)−x∗∥2≤(1−mL)k∥x(0)−x∗∥2\|x^{(k)} - x^*\|^2 \leq \left(1 - \frac{m}{L}\right)^k \|x^{(0)} - x^*\|^2∥x(k)−x∗∥2≤(1−Lm​)k∥x(0)−x∗∥2

条件数 κ=L/m\kappa = L/mκ=L/m 决定了收敛速度。

Newton 法：x(k+1)=x(k)−[∇2f(x(k))]−1∇f(x(k))x^{(k+1)} = x^{(k)} - [\nabla^2 f(x^{(k)})]^{-1} \nabla f(x^{(k)})x(k+1)=x(k)−[∇2f(x(k))]−1∇f(x(k))

局部二次收敛，但每步需要计算和求逆 Hessian（O(n3)O(n^3)O(n3)），大规模问题中不实际。

拟 Newton 法（BFGS、L-BFGS）：用秩二更新逼近 Hessian 逆，兼顾超线性收敛和 O(n2)O(n^2)O(n2) 每步成本。

约束优化与 KKT 条件

考虑一般约束优化问题：

min⁡xf(x)s.t.gi(x)≤0, hj(x)=0\min_{x} f(x) \quad \text{s.t.} \quad g_i(x) \leq 0, \, h_j(x) = 0xmin​f(x)s.t.gi​(x)≤0,hj​(x)=0

Lagrange 函数：

L(x,λ,ν)=f(x)+∑iλigi(x)+∑jνjhj(x)L(x, \lambda, \nu) = f(x) + \sum_i \lambda_i g_i(x) + \sum_j \nu_j h_j(x)L(x,λ,ν)=f(x)+i∑​λi​gi​(x)+j∑​νj​hj​(x)

KKT 条件（最优性必要条件）：

  1. 驻点性：∇xL=0\nabla_x L = 0∇x​L=0
  2. 原始可行性：gi(x∗)≤0g_i(x^*) \leq 0gi​(x∗)≤0，hj(x∗)=0h_j(x^*) = 0hj​(x∗)=0
  3. 对偶可行性：λi≥0\lambda_i \geq 0λi​≥0
  4. 互补松弛：λigi(x∗)=0\lambda_i g_i(x^*) = 0λi​gi​(x∗)=0

凸情形下 KKT 条件是充要条件（满足约束规范条件时）。

对偶理论

Lagrange 对偶函数：

g(λ,ν)=inf⁡xL(x,λ,ν)g(\lambda, \nu) = \inf_{x} L(x, \lambda, \nu)g(λ,ν)=xinf​L(x,λ,ν)

对偶问题：max⁡λ≥0,νg(λ,ν)\max_{\lambda \geq 0, \nu} g(\lambda, \nu)maxλ≥0,ν​g(λ,ν)

弱对偶性：g(λ∗,ν∗)≤f(x∗)g(\lambda^*, \nu^*) \leq f(x^*)g(λ∗,ν∗)≤f(x∗)（恒成立）。

强对偶性：g(λ∗,ν∗)=f(x∗)g(\lambda^*, \nu^*) = f(x^*)g(λ∗,ν∗)=f(x∗)（凸问题 + Slater 条件下成立）。

对偶理论的实用价值：

  • 对偶问题有时比原问题更容易求解
  • 对偶间隙提供了最优性的度量
  • 支持向量机的对偶形式是对偶理论的经典应用

近端梯度法：处理 min⁡f(x)+g(x)\min f(x) + g(x)minf(x)+g(x)（fff 光滑，ggg 凸但不可微，如 ℓ1\ell_1ℓ1​ 范数）：

x(k+1)=arg⁡min⁡x(f(x)+ρ2∥Ax+Bz(k)−c+u(k)∥2)x^{(k+1)} = \arg\min_x \left(f(x) + \frac{\rho}{2}\|Ax + Bz^{(k)} - c + u^{(k)}\|^2\right)x(k+1)=argxmin​(f(x)+2ρ​∥Ax+Bz(k)−c+u(k)∥2)

ADMM 特别适合分布式计算和大规模机器学习问题。

Nesterov 加速梯度法：在梯度下降基础上加入"动量"项，将 O(1/k)O(1/k)O(1/k) 收敛加速到 O(1/k2)O(1/k^2)O(1/k2)，且这是一阶方法的最优复杂度下界。

拓展阅读

  • Boyd & Vandenberghe《Convex Optimization》是凸优化的标准教材（可免费下载），理论与应用并重。
  • Nesterov《Introductory Lectures on Convex Optimization》给出了最优化复杂度理论的完整阐述。
  • Nocedal & Wright《Numerical Optimization》侧重非凸优化的实用算法。
  • Beck《First-Order Methods in Optimization》对近端方法和加速方法有详细讨论。

小结

最优化理论的核心框架是：凸性保证全局最优性，KKT 条件提供最优性判据，对偶理论将原问题转化为可能更易求解的形式。梯度下降是最基本的一阶方法，其收敛速度由函数的光滑性和强凸性决定。近端方法和 ADMM 将优化工具扩展到不可微和分布式场景，Nesterov 加速方法则达到了一阶方法的理论最优复杂度。这些工具构成了现代机器学习和数据科学的数学引擎。
