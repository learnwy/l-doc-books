研究生 发展经济学 — 随机对照试验方法

知识要点

随机对照试验（Randomized Controlled Trial, RCT）在 2019 年诺贝尔经济学奖授予 Abhijit Banerjee、Esther Duflo 和 Michael Kremer 后，正式确立了其在发展经济学实证研究中的核心地位。RCT 通过随机分配机制将研究对象分为处理组和对照组，从而在统计意义上消除选择偏误，实现对因果效应的精准识别。本节围绕 RCT 的设计原理、实施流程与统计推断展开，涵盖 CONSORT 报告规范、整群随机化（Cluster RCT）设计、意向处理分析（ITT）与局部平均处理效应（LATE）估计等关键方法。

核心概念速览：

概念 英文缩写 含义
随机对照试验 RCT 通过随机化消除混杂变量的实验方法
整群随机化 Cluster RCT 以群组（村庄、学校）为单位随机分配
意向处理分析 ITT 按初始随机分组分析，忽略实际依从情况
局部平均处理效应 LATE 对"遵从者"子群体的因果效应估计
CONSORT 声明 — RCT 报告的国际标准清单
功效分析 Power Analysis 确定最低样本量以检测预设效应量

详细讲解

一、RCT 的理论基础：Rubin 因果模型

RCT 的逻辑根基是 Rubin 因果模型（Rubin Causal Model, RCM），也称潜在结果框架。对于个体 iii，定义两个潜在结果：

  • Yi(1)Y_i(1)Yi​(1)：接受干预时的结果
  • Yi(0)Y_i(0)Yi​(0)：未接受干预时的结果

个体因果效应为 τi=Yi(1)−Yi(0)\tau_i = Y_i(1) - Y_i(0)τi​=Yi​(1)−Yi​(0)。然而，同一个体在同一时间只能观测到一个潜在结果——这就是"因果推断的根本问题"。

RCT 通过随机化赋值 Di∈{0,1}D_i \in \{0, 1\}Di​∈{0,1}，使得：

E[Yi(0)∣Di=1]=E[Yi(0)∣Di=0]E[Y_i(0) | D_i = 1] = E[Y_i(0) | D_i = 0]E[Yi​(0)∣Di​=1]=E[Yi​(0)∣Di​=0]

从而保证平均处理效应（ATE）可以无偏估计：

ATE=E[Yi(1)]−E[Yi(0)]=E[Yi∣Di=1]−E[Yi∣Di=0]\text{ATE} = E[Y_i(1)] - E[Y_i(0)] = E[Y_i | D_i = 1] - E[Y_i | D_i = 0]ATE=E[Yi​(1)]−E[Yi​(0)]=E[Yi​∣Di​=1]−E[Yi​∣Di​=0]

这正是 RCT 被称为因果推断"黄金标准"的数学原因。

二、RCT 设计类型

1. 简单随机化（Simple Randomization）

每个个体独立地以概率 ppp 被分配到处理组。优点是实施简单，缺点是小样本时可能出现组间不平衡。

2. 分层随机化（Stratified Randomization）

先按协变量（如性别、收入水平、地区）将样本分为若干层（strata），再在每层内进行随机化。这确保各层在处理组和对照组中的比例一致，降低估计量方差：

τ^strat=∑s=1SNsNτ^s\hat{\tau}_{\text{strat}} = \sum_{s=1}^{S} \frac{N_s}{N} \hat{\tau}_sτ^strat​=s=1∑S​NNs​​τ^s​

其中 NsN_sNs​ 为第 sss 层的样本量，τ^s\hat{\tau}_sτ^s​ 为该层的处理效应估计。

3. 整群随机化（Cluster RCT）

在发展经济学中，许多干预无法在个体层面随机化（如村庄供水系统、学校教学方法）。此时将整个群组（cluster）作为随机化单位。

整群 RCT 的关键挑战是组内相关系数（ICC, Intra-cluster Correlation Coefficient）：

ρ=σb2σb2+σw2\rho = \frac{\sigma^2_b}{\sigma^2_b + \sigma^2_w}ρ=σb2​+σw2​σb2​​

其中 σb2\sigma^2_bσb2​ 为组间方差，σw2\sigma^2_wσw2​ 为组内方差。ρ\rhoρ 越大，有效样本量缩减越严重。设计效应（Design Effect）为：

DEFF=1+(m−1)ρ\text{DEFF} = 1 + (m - 1)\rhoDEFF=1+(m−1)ρ

其中 mmm 为每个群组的平均个体数。实际所需群组数 = 简单随机化所需样本量 ×\times× DEFF / mmm。

4. 交叉设计与阶梯楔形设计

  • 交叉设计（Crossover）：各组在不同时间段交替接受干预与对照
  • 阶梯楔形（Stepped-Wedge）：所有群组最终都接受干预，但启动时间随机。适用于伦理上不宜永久设置对照组的场景

三、功效分析与样本量确定

在设计阶段，必须进行功效分析（Power Analysis）以确保试验有足够的统计检验力检测出预期效应。

对于双样本均值检验，最低样本量公式：

n=(z1−α/2+z1−β)2⋅2σ2δ2n = \frac{(z_{1-\alpha/2} + z_{1-\beta})^2 \cdot 2\sigma^2}{\delta^2}n=δ2(z1−α/2​+z1−β​)2⋅2σ2​

其中：

  • z1−α/2z_{1-\alpha/2}z1−α/2​：显著性水平对应的标准正态分位数（通常 α=0.05\alpha = 0.05α=0.05, z=1.96z = 1.96z=1.96）
  • z1−βz_{1-\beta}z1−β​：检验力对应的分位数（通常 β=0.20\beta = 0.20β=0.20, z=0.84z = 0.84z=0.84）
  • σ2\sigma^2σ2：结果变量的方差
  • δ\deltaδ：最小可检测效应量（MDE）

Banerjee 与 Duflo 在印度的微额信贷 RCT（2015）中，基于基线调查数据估计 σ\sigmaσ，设定 MDE 为家庭月消费的 10%，计算得每组需约 4,000 户。

四、ITT 与 LATE 估计

意向处理分析（Intention-to-Treat, ITT）

ITT 按照最初的随机分组进行分析，不论参与者是否实际接受了干预。其核心优势是保留了随机化带来的内部效度：

τ^ITT=YˉTreatment−YˉControl\hat{\tau}_{\text{ITT}} = \bar{Y}_{\text{Treatment}} - \bar{Y}_{\text{Control}}τ^ITT​=YˉTreatment​−YˉControl​

如果存在不依从（non-compliance），ITT 估计的是干预"被提供"（offer）的效应而非"被接受"（take-up）的效应。

局部平均处理效应（Local Average Treatment Effect, LATE）

当存在不依从时，Imbens 和 Angrist（1994）提出利用工具变量（IV）方法估计 LATE：

τ^LATE=τ^ITTπ^=Yˉ1−Yˉ0Dˉ1−Dˉ0\hat{\tau}_{\text{LATE}} = \frac{\hat{\tau}_{\text{ITT}}}{\hat{\pi}} = \frac{\bar{Y}_1 - \bar{Y}_0}{\bar{D}_1 - \bar{D}_0}τ^LATE​=π^τ^ITT​​=Dˉ1​−Dˉ0​Yˉ1​−Yˉ0​​

其中 π^=Dˉ1−Dˉ0\hat{\pi} = \bar{D}_1 - \bar{D}_0π^=Dˉ1​−Dˉ0​ 是处理组与对照组的实际参与率之差。LATE 衡量的是"遵从者"（compliers）——即其处理状态受随机分配影响的子群体——的因果效应。

LATE 的有效性依赖四个假设：(1) 随机化有效（独立性）；(2) 分配影响参与（相关性/第一阶段）；(3) 排除限制（分配仅通过处理状态影响结果）；(4) 单调性（无"逆反者"）。

小结
本节从 Rubin 因果模型出发，阐明了 RCT 通过随机化实现无偏因果估计的数学原理。在设计层面，我们区分了简单随机化、分层随机化、整群 RCT 及阶梯楔形设计等类型，重点分析了整群设计中 ICC 和设计效应对样本量的影响。在分析层面，ITT 保留内部效度但可能低估效应，LATE 通过 IV 方法恢复遵从者效应但依赖更强假设。CONSORT 规范为 RCT 报告提供了结构化标准。掌握这些工具后，下一步将学习更广泛的影响评估方法，将 RCT 纳入完整的政策评估框架中。
