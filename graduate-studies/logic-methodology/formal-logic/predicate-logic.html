研究生 逻辑学与方法论 — 谓词逻辑

知识要点

谓词逻辑（也称一阶逻辑）是命题逻辑的自然扩展，它"打开"了命题的内部结构，引入个体、谓词和量词来表达"所有"和"存在"这类日常推理中无处不在的概念。正是谓词逻辑使得我们能够形式化亚里士多德三段论、数学定理乃至计算机程序的正确性证明。它是现代逻辑的核心语言，也是通向更高阶逻辑系统的必经之路。

核心内容包括：全称量词 ∀\forall∀ 与存在量词 ∃\exists∃、自由变元与约束变元的区分、解释与模型、量词的自然演绎规则（全称/存在引入与消除），以及一阶逻辑的不可判定性。

详细讲解

从命题逻辑到谓词逻辑

回顾命题逻辑的经典三段论困境：

  • 前提1：所有人都是有死的
  • 前提2：苏格拉底是人
  • 结论：苏格拉底是有死的

在命题逻辑中，这三句话只能表示为 p,q,rp, q, rp,q,r 三个独立命题，推理 p,q⊢rp, q \vdash rp,q⊢r 显然不是有效的——rrr 不能仅从两个不相关的命题推出。问题在于命题逻辑无法分析"所有…都…"和"…是…"的内部结构。

谓词逻辑的解决方案：

  • 引入个体常元 aaa（指代苏格拉底）
  • 引入谓词 H(x)H(x)H(x)（xxx 是人）、M(x)M(x)M(x)（xxx 是有死的）
  • 引入全称量词 ∀\forall∀

形式化后：

  1. ∀x(H(x)→M(x))\forall x(H(x) \to M(x))∀x(H(x)→M(x))
  2. H(a)H(a)H(a)
  3. ∴M(a)\therefore M(a)∴M(a)

这个推理可以通过全称消除（∀E\forall E∀E）和条件消除（→E\to E→E）严格证明。

谓词逻辑的语法

词汇表：

  • 个体常元：a,b,c,…a, b, c, \ldotsa,b,c,…（指代特定对象）
  • 个体变元：x,y,z,…x, y, z, \ldotsx,y,z,…（充当占位符）
  • 谓词符号：P,Q,R,…P, Q, R, \ldotsP,Q,R,…（带有元数/arity，如一元谓词 P(x)P(x)P(x)、二元谓词 R(x,y)R(x,y)R(x,y)）
  • 函数符号：f,g,…f, g, \ldotsf,g,…（可选，如 f(x)f(x)f(x) 表示"xxx 的父亲"）
  • 量词：∀\forall∀（全称）、∃\exists∃（存在）
  • 逻辑联结词：¬,∧,∨,→,↔\neg, \land, \lor, \to, \leftrightarrow¬,∧,∨,→,↔（继承自命题逻辑）

项（Term） 的递归定义：

  • 个体常元和个体变元是项
  • 如果 t1,…,tnt_1, \ldots, t_nt1​,…,tn​ 是项，fff 是 nnn 元函数符号，则 f(t1,…,tn)f(t_1, \ldots, t_n)f(t1​,…,tn​) 是项

公式（Formula） 的递归定义：

  • 如果 t1,…,tnt_1, \ldots, t_nt1​,…,tn​ 是项，PPP 是 nnn 元谓词符号，则 P(t1,…,tn)P(t_1, \ldots, t_n)P(t1​,…,tn​) 是原子公式
  • 如果 A,BA, BA,B 是公式，则 ¬A\neg A¬A、A∧BA \land BA∧B、A∨BA \lor BA∨B、A→BA \to BA→B、A↔BA \leftrightarrow BA↔B 是公式
  • 如果 AAA 是公式，xxx 是变元，则 ∀xA\forall x A∀xA 和 ∃xA\exists x A∃xA 是公式

自由变元与约束变元

变元 xxx 在公式中的出现分为两种：

  • 约束出现（Bound）：处于量词 ∀x\forall x∀x 或 ∃x\exists x∃x 的作用域内
  • 自由出现（Free）：不处于任何对应量词的作用域内

例如，在公式 ∀x(P(x)→Q(x))∧R(x)\forall x(P(x) \to Q(x)) \land R(x)∀x(P(x)→Q(x))∧R(x) 中：

  • 前半部分 P(x)→Q(x)P(x) \to Q(x)P(x)→Q(x) 中的 xxx 是约束的（被 ∀x\forall x∀x 绑定）
  • 后半部分 R(x)R(x)R(x) 中的 xxx 是自由的

闭合公式（Sentence） 是不含自由变元的公式，只有闭合公式才有确定的真值。含有自由变元的公式是"开放"的——其真假取决于自由变元的赋值。

代入的注意事项：将项 ttt 代入公式 AAA 中的自由变元 xxx（记作 A[t/x]A[t/x]A[t/x]）时，必须确保 ttt 中的变元不会被 AAA 中的量词"捕获"。例如，∃y(x<y)\exists y(x < y)∃y(x<y) 中将 xxx 替换为 yyy 会得到 ∃y(y<y)\exists y(y < y)∃y(y<y)——原本"存在比 xxx 大的东西"变成了"存在比自己大的东西"，语义完全改变。这种情况下 ttt 对 xxx 在 AAA 中是"不可代入的"。

解释与模型

解释（Interpretation） I\mathcal{I}I 由以下组成：

  • 一个非空集合 DDD，称为论域（Domain）
  • 对每个个体常元 aaa，指定 DDD 中的一个元素 aIa^{\mathcal{I}}aI
  • 对每个 nnn 元谓词 PPP，指定 DnD^nDn 上的一个关系 PI⊆DnP^{\mathcal{I}} \subseteq D^nPI⊆Dn
  • 对每个 nnn 元函数 fff，指定一个函数 fI:Dn→Df^{\mathcal{I}}: D^n \to DfI:Dn→D

满足与真：

  • I⊨∀xA\mathcal{I} \vDash \forall x AI⊨∀xA 当且仅当对 DDD 中的每个元素 ddd，A[d/x]A[d/x]A[d/x] 在 I\mathcal{I}I 下为真
  • I⊨∃xA\mathcal{I} \vDash \exists x AI⊨∃xA 当且仅当存在 DDD 中的某个元素 ddd，A[d/x]A[d/x]A[d/x] 在 I\mathcal{I}I 下为真

模型（Model）：如果 I\mathcal{I}I 使公式集 Γ\GammaΓ 中的每个公式都为真，则 I\mathcal{I}I 是 Γ\GammaΓ 的模型。

举例：论域 D={1,2,3}D = \{1, 2, 3\}D={1,2,3}，谓词 P(x)P(x)P(x) 表示"xxx 是偶数"。则 PI={2}P^{\mathcal{I}} = \{2\}PI={2}。

  • ∀xP(x)\forall x P(x)∀xP(x) 为假（111 和 333 不是偶数）
  • ∃xP(x)\exists x P(x)∃xP(x) 为真（222 是偶数）
  • ∃x¬P(x)\exists x \neg P(x)∃x¬P(x) 为真（111 不是偶数）

量词的自然演绎规则

全称消除（∀E\forall E∀E）：

∀xAA[t/x](∀E)\frac{\forall x A}{A[t/x]}(\forall E)A[t/x]∀xA​(∀E)

从"所有 xxx 满足 AAA"推出"特定的 ttt 满足 AAA"。

全称引入（∀I\forall I∀I）：

A[a/x]∀xA(∀I)\frac{A[a/x]}{\forall x A}(\forall I)∀xAA[a/x]​(∀I)

其中 aaa 是任意的（arbitrary） 个体常元——它不出现在任何前提或未撤除的假设中。这一限制确保推理的普遍性：如果我们在没有任何关于 aaa 的特殊假设下证明了 A[a/x]A[a/x]A[a/x]，那么 AAA 对所有 xxx 都成立。

存在引入（∃I\exists I∃I）：

A[t/x]∃xA(∃I)\frac{A[t/x]}{\exists x A}(\exists I)∃xAA[t/x]​(∃I)

从"特定的 ttt 满足 AAA"推出"存在 xxx 满足 AAA"。

存在消除（∃E\exists E∃E）：

∃xA[A[a/x]]⋮BB(∃E)\frac{\exists x A \quad [A[a/x]] \vdots B}{B}(\exists E)B∃xA[A[a/x]]⋮B​(∃E)

其中 aaa 是新的个体常元（不出现在 ∃xA\exists x A∃xA、BBB 或任何未撤除的假设中）。直觉上：既然存在满足 AAA 的东西，不妨"叫它 aaa"，如果从"aaa 满足 AAA"能推出 BBB（且 BBB 不依赖于 aaa 的选择），则 BBB 成立。

一阶逻辑的完备性与不可判定性

完备性定理（Gödel, 1930）：一阶逻辑是完备的——Γ⊨A\Gamma \vDash AΓ⊨A 当且仅当 Γ⊢A\Gamma \vdash AΓ⊢A。语义有效性与语法可证明性完美对应。这是哥德尔在博士论文中证明的，是20世纪逻辑学最深刻的成果之一。

紧致性定理（Compactness）：公式集 Γ\GammaΓ 有模型当且仅当 Γ\GammaΓ 的每个有限子集都有模型。紧致性是模型论的基石工具。

不可判定性（Church-Turing, 1936）：不存在一个算法能够判定一阶逻辑的任意公式是否为有效式（即重言式）。这与命题逻辑形成鲜明对比——命题逻辑的有效性通过真值表是可判定的。不可判定性意味着一阶逻辑的推理能力更强，但代价是失去了自动判定的可能。

不过，一阶逻辑仍然是半可判定的（Semi-decidable）：如果一个公式是有效式，系统化搜索最终会找到证明；但如果它不是有效式，搜索可能永远不会终止。

练习与思考

  1. 形式化练习：将以下命题翻译为一阶逻辑公式： (a) 每个学生都修过至少一门课程 (b) 存在一门课程被所有学生修过 (c) 没有人既是老师又是学生

  2. 自然演绎证明：证明 ∀x(P(x)→Q(x)),∃xP(x)⊢∃xQ(x)\forall x(P(x) \to Q(x)), \exists x P(x) \vdash \exists x Q(x)∀x(P(x)→Q(x)),∃xP(x)⊢∃xQ(x)。

  3. 模型构造：找一个解释使 ∃x∀yR(x,y)\exists x \forall y R(x,y)∃x∀yR(x,y) 为真但 ∀y∃xR(x,y)\forall y \exists x R(x,y)∀y∃xR(x,y) 的逆（即 ∀x∃yR(x,y)\forall x \exists y R(x,y)∀x∃yR(x,y) 不蕴含 ∃x∀yR(x,y)\exists x \forall y R(x,y)∃x∀yR(x,y)）。提示：量词顺序影响语义。

  4. 自由变元辨识：指出公式 ∀x(P(x,y)→∃yQ(y,z))\forall x(P(x,y) \to \exists y Q(y,z))∀x(P(x,y)→∃yQ(y,z)) 中的自由变元和约束变元。

  5. 反思题：一阶逻辑的不可判定性对"机器能否完全替代人类推理"这一问题意味着什么？

拓展阅读

  • Herbert Enderton 的 A Mathematical Introduction to Logic 是一阶逻辑的标准教材，证明严谨且可读性强
  • Dirk van Dalen 的 Logic and Structure 第三、四章对谓词逻辑有清晰的处理
  • 哥德尔完备性定理的原始证明收录在 van Heijenoort 编辑的 From Frege to Gödel: A Source Book in Mathematical Logic
  • Stanford Encyclopedia of Philosophy 的 "Classical Logic" 和 "First-order Model Theory" 词条提供了全面的在线参考
  • 王宪钧的《数理逻辑引论》是国内经典教材，对一阶逻辑有严格的中文处理
  • 对不可判定性的深入了解，推荐 Michael Sipser 的 Introduction to the Theory of Computation 相关章节

小结

谓词逻辑通过引入个体、谓词和量词，极大地扩展了命题逻辑的表达能力。自由变元与约束变元的区分是精确使用量词的前提；解释和模型为公式提供了语义基础；自然演绎的量词规则（尤其是 ∀I\forall I∀I 和 ∃E\exists E∃E 中对"任意性"的限制）体现了逻辑严格性的要求。哥德尔完备性定理证明了一阶逻辑中语义与语法的完美统一，而 Church-Turing 不可判定性结果则揭示了更强表达力所付出的代价。谓词逻辑既是数学基础的核心工具，也是进入模态逻辑、哲学逻辑等高级领域的门槛。
