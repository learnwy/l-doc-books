研究生 高级算法 — 流式算法

知识要点

流式算法处理的是数据规模远超内存容量的场景：数据以流的形式到达，每个元素只能被观察一次（或常数次），算法必须使用远小于输入规模的空间来计算或近似目标函数。在大规模网络监控、数据库查询优化和实时分析系统中，流式算法是不可替代的基础工具。

核心模型与概念：

  • 数据流模型：输入 σ=⟨a1,a2,…,am⟩\sigma = \langle a_1, a_2, \ldots, a_m \rangleσ=⟨a1​,a2​,…,am​⟩，每个 ai∈[n]={1,2,…,n}a_i \in [n] = \{1, 2, \ldots, n\}ai​∈[n]={1,2,…,n}。算法使用 sss 比特空间，s≪m,ns \ll m, ns≪m,n
  • 频率向量：f=(f1,f2,…,fn)\mathbf{f} = (f_1, f_2, \ldots, f_n)f=(f1​,f2​,…,fn​)，其中 fj=∣{i:ai=j}∣f_j = |\{i : a_i = j\}|fj​=∣{i:ai​=j}∣。很多流式问题可以表述为近似 f\mathbf{f}f 的某个函数
  • 频率矩（Frequency Moments）：Fk=∑j=1nfjkF_k = \sum_{j=1}^{n} f_j^kFk​=∑j=1n​fjk​。F0F_0F0​ = 不同元素数，F1F_1F1​ = 流长度，F2F_2F2​ = 自连接大小
  • (ϵ,δ)(\epsilon, \delta)(ϵ,δ) 近似：输出 F^\hat{F}F^ 满足 Pr⁡[∣F^−F∣>ϵF]≤δ\Pr[|\hat{F} - F| > \epsilon F] \leq \deltaPr[∣F^−F∣>ϵF]≤δ
  • 空间下界：通信复杂性提供了流式算法空间下界的主要工具。很多精确计算需要 Ω(n)\Omega(n)Ω(n) 空间，迫使我们接受近似

详细讲解

不同元素计数：Flajolet-Martin与HyperLogLog

精确计算 F0F_0F0​（不同元素数）需要 Ω(n)\Omega(n)Ω(n) 空间。Flajolet 和 Martin（1985）给出了开创性的近似算法。

基本思想：选取哈希函数 h:[n]→[0,1)h: [n] \rightarrow [0, 1)h:[n]→[0,1)（理想化为均匀随机映射），维护 Z=min⁡j:fj>0h(j)Z = \min_{j: f_j > 0} h(j)Z=minj:fj​>0​h(j)。

E[Z]=1F0+1≈1F0E[Z] = \frac{1}{F_0 + 1} \approx \frac{1}{F_0}E[Z]=F0​+11​≈F0​1​

因此 F^0=1/Z−1\hat{F}_0 = 1/Z - 1F^0​=1/Z−1 是 F0F_0F0​ 的无偏估计。但方差太大，需要改进。

HyperLogLog（Flajolet et al., 2007）：使用 mmm 个寄存器，每个存储哈希值的前导零数。

  1. 将元素哈希为均匀二进制串 h(x)h(x)h(x)
  2. 用前 log⁡2m\log_2 mlog2​m 位选择寄存器索引 jjj
  3. 剩余位中前导零的数量加 1 记为 ρ\rhoρ，更新 M[j]←max⁡(M[j],ρ)M[j] \leftarrow \max(M[j], \rho)M[j]←max(M[j],ρ)

估计值：F^0=αm⋅m2⋅(∑j=1m2−M[j])−1\hat{F}_0 = \alpha_m \cdot m^2 \cdot \left(\sum_{j=1}^{m} 2^{-M[j]}\right)^{-1}F^0​=αm​⋅m2⋅(∑j=1m​2−M[j])−1

其中 αm\alpha_mαm​ 是偏差修正常数。空间 O(mlog⁡log⁡n)O(m \log \log n)O(mloglogn) 比特，相对误差 ≈1.04/m\approx 1.04/\sqrt{m}≈1.04/m​。

精确计数 O(nlog⁡m)O(n \log m)O(nlogm) 0 小规模
Flajolet-Martin O(log⁡n)O(\log n)O(logn) 大 理论
LogLog O(mlog⁡log⁡n)O(m \log \log n)O(mloglogn) 1.30/m1.30/\sqrt{m}1.30/m​ 中等

F2估计：AMS草图

Alon、Matias 和 Szegedy 在 1996 年的开创性论文中给出了 F2=∑fj2F_2 = \sum f_j^2F2​=∑fj2​ 的近似算法，这篇论文获得了 Gödel 奖。

AMS 估计器：选取 4-wise 独立哈希函数 h:[n]→{−1,+1}h: [n] \rightarrow \{-1, +1\}h:[n]→{−1,+1}。维护计数器 Z=∑i=1mh(ai)Z = \sum_{i=1}^{m} h(a_i)Z=∑i=1m​h(ai​)。

Z=∑j=1nfj⋅h(j)  ⟹  Z2=∑j,kfjfkh(j)h(k)Z = \sum_{j=1}^{n} f_j \cdot h(j) \implies Z^2 = \sum_{j,k} f_j f_k h(j) h(k)Z=j=1∑n​fj​⋅h(j)⟹Z2=j,k∑​fj​fk​h(j)h(k)
E[Z2]=∑j=1nfj2=F2E[Z^2] = \sum_{j=1}^{n} f_j^2 = F_2E[Z2]=j=1∑n​fj2​=F2​

因为 E[h(j)h(k)]=0E[h(j)h(k)] = 0E[h(j)h(k)]=0 当 j≠kj \neq kj=k（4-wise 独立保证了这一点）。

方差分析：Var[Z2]≤2F22\text{Var}[Z^2] \leq 2F_2^2Var[Z2]≤2F22​。使用中值技巧（median of means）：

  1. 维护 O(1/ϵ2)O(1/\epsilon^2)O(1/ϵ2) 个独立计数器，取均值降低方差
  2. 重复 O(log⁡(1/δ))O(\log(1/\delta))O(log(1/δ)) 组，取中值降低失败概率

总空间 O(1ϵ2log⁡(1/δ)log⁡n)O(\frac{1}{\epsilon^2} \log(1/\delta) \log n)O(ϵ21​log(1/δ)logn) 比特。

Count-Min Sketch与频率估计

Cormode 和 Muthukrishnan（2005）提出的 Count-Min Sketch 是实践中最广泛使用的流式数据结构之一。

结构：d×wd \times wd×w 的计数器矩阵，d=⌈ln⁡(1/δ)⌉d = \lceil \ln(1/\delta) \rceild=⌈ln(1/δ)⌉ 行，w=⌈e/ϵ⌉w = \lceil e/\epsilon \rceilw=⌈e/ϵ⌉ 列。每行使用独立的哈希函数 hi:[n]→[w]h_i: [n] \rightarrow [w]hi​:[n]→[w]。

更新：元素 jjj 到达时，对每行 iii，C[i,hi(j)]←C[i,hi(j)]+1C[i, h_i(j)] \leftarrow C[i, h_i(j)] + 1C[i,hi​(j)]←C[i,hi​(j)]+1。

查询：f^j=min⁡iC[i,hi(j)]\hat{f}_j = \min_i C[i, h_i(j)]f^​j​=mini​C[i,hi​(j)]。

保证：fj≤f^jf_j \leq \hat{f}_jfj​≤f^​j​（无下偏），且 Pr⁡[f^j>fj+ϵF1]≤δ\Pr[\hat{f}_j > f_j + \epsilon F_1] \leq \deltaPr[f^​j​>fj​+ϵF1​]≤δ。

空间下界：通信复杂性方法
流式算法的空间下界主要来自通信复杂性。


核心归约：将单通道流式问题归约为单向通信复杂性问题。Alice 持有流的前半段，处理后将内存状态（sss 比特）发送给 Bob，Bob 继续处理后半段。


著名下界：


    

  • 不同元素计数（精确）：Ω(min⁡(m,n))\Omega(\min(m, n))Ω(min(m,n)) 比特
    • 

  • F0F_0F0​ 的 (1+ϵ)(1+\epsilon)(1+ϵ) 近似：Ω(1/ϵ2+log⁡n)\Omega(1/\epsilon^2 + \log n)Ω(1/ϵ2+logn) 比特
    • 

  • F2F_2F2​ 的 (1+ϵ)(1+\epsilon)(1+ϵ) 近似：Ω(1/ϵ2log⁡n)\Omega(1/\epsilon^2 \log n)Ω(1/ϵ2logn) 比特（AMS 的空间与此匹配）
    • 

  • FkF_kFk​ 的 (1+ϵ)(1+\epsilon)(1+ϵ) 近似（k>2k > 2k>2）：Ω(n1−2/k)\Omega(n^{1-2/k})Ω(n1−2/k) 比特
    •

小结
流式算法在亚线性空间约束下实现了对数据流的高效近似计算。从 HyperLogLog 的不同元素计数到 AMS 草图的频率矩估计，再到 Count-Min Sketch 的频率查询，这些算法在理论优美性和实际应用之间达到了罕见的平衡。通信复杂性方法为这些算法的空间效率提供了最优性保证。
