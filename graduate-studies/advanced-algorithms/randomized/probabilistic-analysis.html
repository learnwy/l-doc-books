研究生 高级算法 — 概率分析

知识要点

概率分析为算法性能的理解提供了远比最坏情况更丰富的视角。在最坏情况分析中，快速排序的时间复杂度为 O(n2)O(n^2)O(n2)，但实践中它几乎总是 O(nlog⁡n)O(n \log n)O(nlogn)——概率分析解释了这一现象。通过对输入分布或算法随机选择的分析，我们可以得到期望运行时间、高概率保证和尾部概率界，这些工具在算法设计和系统性能预测中不可或缺。

核心分析工具：

  • 期望值线性性：E[∑Xi]=∑E[Xi]E[\sum X_i] = \sum E[X_i]E[∑Xi​]=∑E[Xi​]，即使变量之间不独立。这是最强大也最常被低估的工具
  • 指示器随机变量：将复杂事件分解为简单的0/1变量。X=∑iIiX = \sum_{i} I_iX=∑i​Ii​，其中 E[Ii]=Pr⁡[事件i]E[I_i] = \Pr[\text{事件}_i]E[Ii​]=Pr[事件i​]
  • Markov 不等式：对非负随机变量 XXX，Pr⁡[X≥a]≤E[X]/a\Pr[X \geq a] \leq E[X]/aPr[X≥a]≤E[X]/a
  • Chebyshev 不等式：Pr⁡[∣X−μ∣≥kσ]≤1/k2\Pr[|X - \mu| \geq k\sigma] \leq 1/k^2Pr[∣X−μ∣≥kσ]≤1/k2，需要方差信息
  • Chernoff 界：对独立 0/1 变量之和 XXX，Pr⁡[X≥(1+δ)μ]≤(eδ(1+δ)(1+δ))μ\Pr[X \geq (1+\delta)\mu] \leq \left(\frac{e^{\delta}}{(1+\delta)^{(1+\delta)}}\right)^{\mu}Pr[X≥(1+δ)μ]≤((1+δ)(1+δ)eδ​)μ，提供指数级衰减的尾部概率

详细讲解

从期望到高概率：集中不等式的层次

不同的集中不等式适用于不同的场景，形成一个从弱到强的层次：

不等式 条件 尾部衰减 紧度
Markov X≥0X \geq 0X≥0 O(1/a)O(1/a)O(1/a) 松
Chebyshev 已知方差 O(1/k2)O(1/k^2)O(1/k2) 中等
Chernoff-Hoeffding 有界独立变量 e−Ω(δ2μ)e^{-\Omega(\delta^2 \mu)}e−Ω(δ2μ) 紧
Azuma-Hoeffding 有界差鞅 e−Ω(t2/∑ci2)e^{-\Omega(t^2/\sum c_i^2)}e−Ω(t2/∑ci2​) 紧
Talagrand 利普希茨函数 e−Ω(t2)e^{-\Omega(t^2)}e−Ω(t2) 非常紧

Chernoff 界的标准形式：设 X1,…,XnX_1, \ldots, X_nX1​,…,Xn​ 为独立的 [0,1][0,1][0,1] 随机变量，X=∑XiX = \sum X_iX=∑Xi​，μ=E[X]\mu = E[X]μ=E[X]。

上尾：Pr⁡[X≥(1+δ)μ]≤e−μδ2/3\Pr[X \geq (1+\delta)\mu] \leq e^{-\mu\delta^2/3}Pr[X≥(1+δ)μ]≤e−μδ2/3，对 0<δ≤10 < \delta \leq 10<δ≤1

下尾：Pr⁡[X≤(1−δ)μ]≤e−μδ2/2\Pr[X \leq (1-\delta)\mu] \leq e^{-\mu\delta^2/2}Pr[X≤(1−δ)μ]≤e−μδ2/2，对 0<δ<10 < \delta < 10<δ<1

随机化快速排序的精确分析

随机化快速排序每次从当前数组中均匀随机选择枢轴，然后分区。设输入为 nnn 个不同元素，排序后为 z1<z2<⋯<znz_1 < z_2 < \cdots < z_nz1​<z2​<⋯<zn​。

定义指示器变量 XijX_{ij}Xij​：ziz_izi​ 和 zjz_jzj​ 是否在算法执行过程中被比较。两个元素被比较当且仅当其中之一在 {zi,zi+1,…,zj}\{z_i, z_{i+1}, \ldots, z_j\}{zi​,zi+1​,…,zj​} 中第一个被选为枢轴。

E[Xij]=Pr⁡[zi 或 zj 在 {zi,…,zj} 中首先被选为枢轴]=2j−i+1E[X_{ij}] = \Pr[z_i \text{ 或 } z_j \text{ 在 } \{z_i, \ldots, z_j\} \text{ 中首先被选为枢轴}] = \frac{2}{j - i + 1}E[Xij​]=Pr[zi​ 或 zj​ 在 {zi​,…,zj​} 中首先被选为枢轴]=j−i+12​

总比较次数的期望：

E[∑i<jXij]=∑i=1n−1∑j=i+1n2j−i+1=2∑i=1n−1∑k=2n−i+11k≤2n∑k=2n1k=2n(Hn−1)≈2nln⁡nE\left[\sum_{i<j} X_{ij}\right] = \sum_{i=1}^{n-1}\sum_{j=i+1}^{n} \frac{2}{j-i+1} = 2\sum_{i=1}^{n-1}\sum_{k=2}^{n-i+1} \frac{1}{k} \leq 2n \sum_{k=2}^{n} \frac{1}{k} = 2n(H_n - 1) \approx 2n \ln nE[i<j∑​Xij​]=i=1∑n−1​j=i+1∑n​j−i+12​=2i=1∑n−1​k=2∑n−i+1​k1​≤2nk=2∑n​k1​=2n(Hn​−1)≈2nlnn

这个分析的优美之处在于完全不需要假设独立性——期望值的线性性自动处理了变量之间的依赖关系。

哈希表的概率分析

链式哈希表中，nnn 个元素放入 mmm 个桶。在简单均匀哈希假设下，每个桶的期望负载为 α=n/m\alpha = n/mα=n/m。

最大桶负载：当 m=nm = nm=n 时，最大桶负载的期望为 Θ(log⁡n/log⁡log⁡n)\Theta(\log n / \log \log n)Θ(logn/loglogn)。

证明上界使用 union bound + Chernoff：单个桶负载 ≥k\geq k≥k 的概率由 Chernoff 界给出为 e−Ω(k)e^{-\Omega(k)}e−Ω(k)，取 k=O(log⁡n/log⁡log⁡n)k = O(\log n / \log \log n)k=O(logn/loglogn) 使得 n⋅e−Ω(k)<1n \cdot e^{-\Omega(k)} < 1n⋅e−Ω(k)<1。

Power of Two Choices：Azar 等人的突破性结果表明，如果每个元素随机选择 2 个桶并放入较空的桶，最大负载从 Θ(log⁡n/log⁡log⁡n)\Theta(\log n / \log \log n)Θ(logn/loglogn) 下降到 Θ(log⁡log⁡n)\Theta(\log \log n)Θ(loglogn)——指数级改善。

鞅与有界差方法
当随机变量之间存在依赖性时，Chernoff 界不再直接适用。鞅方法（Martingale method）提供了处理依赖性的优雅框架。


Doob 鞅：给定随机变量序列 Y0,Y1,…,YnY_0, Y_1, \ldots, Y_nY0​,Y1​,…,Yn​ 和函数 fff，定义 Zi=E[f(Y0,…,Yn)∣Y0,…,Yi]Z_i = E[f(Y_0, \ldots, Y_n) \mid Y_0, \ldots, Y_i]Zi​=E[f(Y0​,…,Yn​)∣Y0​,…,Yi​]。序列 Z0,Z1,…,ZnZ_0, Z_1, \ldots, Z_nZ0​,Z1​,…,Zn​ 构成鞅。


Azuma-Hoeffding 不等式：设 Z0,Z1,…Z_0, Z_1, \ldotsZ0​,Z1​,… 是鞅，∣Zi−Zi−1∣≤ci|Z_i - Z_{i-1}| \leq c_i∣Zi​−Zi−1​∣≤ci​。则：


Pr⁡[∣Zn−Z0∣≥t]≤2exp⁡(−t22∑i=1nci2)\Pr[|Z_n - Z_0| \geq t] \leq 2\exp\left(-\frac{t^2}{2\sum_{i=1}^{n} c_i^2}\right)Pr[∣Zn​−Z0​∣≥t]≤2exp(−2∑i=1n​ci2​t2​)
应用示例：图着色中的暴露鞅。随机着色图的 nnn 个顶点（每个顶点独立均匀选择 ccc 种颜色之一），设 XXX = 单色边数。E[X]=∣E∣/cE[X] = |E|/cE[X]=∣E∣/c。逐一暴露顶点的颜色，每暴露一个顶点最多改变 XXX 的值 Δ\DeltaΔ（顶点的最大度数），因此 ci=Δc_i = \Deltaci​=Δ。


Pr⁡[∣X−E[X]∣≥t]≤2exp⁡(−t22nΔ2)\Pr[|X - E[X]| \geq t] \leq 2\exp\left(-\frac{t^2}{2n\Delta^2}\right)Pr[∣X−E[X]∣≥t]≤2exp(−2nΔ2t2​)

小结
概率分析提供了理解算法行为的精细工具。从期望值线性性到 Chernoff 界再到鞅方法，集中不等式的层次结构让我们能够在不同场景下选择合适的分析精度。Power of Two Choices 等结果则展示了概率分析如何指导算法设计——微小的随机化改变可以带来指数级的性能提升。
