研究生 高级算法 — 凸优化

知识要点

凸优化是连续优化的核心分支，其数学结构保证了局部最优即全局最优的优良性质。研究生阶段学习凸优化需要建立从凸集、凸函数到对偶理论的完整知识链条，掌握内点法等高效求解算法，并理解凸优化在机器学习、信号处理、控制系统中的广泛应用。

详细讲解

凸集与凸函数

凸集的几何直觉是集合中任意两点的连线段完全包含在集合内。常见的凸集包括超平面 {x∣aTx=b}\{x \mid a^T x = b\}{x∣aTx=b}、半空间 {x∣aTx≤b}\{x \mid a^T x \leq b\}{x∣aTx≤b}、多面体、椭球和半正定锥。凸集的交仍是凸集，这一性质使得约束的叠加保持凸性。

凸函数满足 Jensen 不等式。判定凸性的实用方法包括：

  • 一阶条件：f(y)≥f(x)+∇f(x)T(y−x)f(y) \geq f(x) + \nabla f(x)^T(y - x)f(y)≥f(x)+∇f(x)T(y−x)，即函数始终在其切平面之上
  • 二阶条件：∇2f(x)⪰0\nabla^2 f(x) \succeq 0∇2f(x)⪰0，Hessian 矩阵半正定
  • 保凸运算：非负加权和、仿射复合、逐点上确界、透视函数
标准凸优化问题
凸优化的标准形式为：


min⁡xf0(x)s.t.fi(x)≤0, i=1,…,m;Ax=b\min_{x} f_0(x) \quad \text{s.t.} \quad f_i(x) \leq 0,\ i=1,\dots,m; \quad Ax = bxmin​f0​(x)s.t.fi​(x)≤0, i=1,…,m;Ax=b
其中 f0,f1,…,fmf_0, f_1, \dots, f_mf0​,f1​,…,fm​ 均为凸函数。几类重要的特殊形式：


线性规划（LP）：目标和约束均为线性函数，可用单纯形法或内点法求解。对偶理论特别简洁——对偶的对偶就是原问题。


二次规划（QP）：目标为凸二次函数，约束为线性。支持向量机（SVM）的训练本质上是一个 QP 问题。


半正定规划（SDP）：变量是半正定矩阵，约束为线性矩阵不等式 F(x)=F0+x1F1+⋯+xnFn⪰0F(x) = F_0 + x_1 F_1 + \cdots + x_n F_n \succeq 0F(x)=F0​+x1​F1​+⋯+xn​Fn​⪰0。SDP 是凸优化中表达能力最强的标准形式之一，松弛技术将许多组合优化问题转化为 SDP。


二阶锥规划（SOCP）：约束形如 ∥Aix+bi∥2≤ciTx+di\|A_i x + b_i\|_2 \leq c_i^T x + d_i∥Ai​x+bi​∥2​≤ciT​x+di​。表达能力介于 QP 与 SDP 之间，鲁棒优化中常用。


对偶理论
Lagrange 对偶是凸优化理论的精华。引入对偶变量 λ≥0\lambda \geq 0λ≥0（不等式约束）和 ν\nuν（等式约束），构造 Lagrange 函数：

内点法与求解算法
障碍函数法：将不等式约束融入目标函数，用对数障碍 ϕ(x)=−∑log⁡(−fi(x))\phi(x) = -\sum \log(-f_i(x))ϕ(x)=−∑log(−fi​(x)) 惩罚边界违反。参数 ttt 控制逼近精度，中心路径 x∗(t)x^*(t)x∗(t) 随 t→∞t \to \inftyt→∞ 趋向原问题最优解。


每一步需要求解牛顿方程组：


∇2ft(x)Δx=−∇ft(x)\nabla^2 f_t(x) \Delta x = -\nabla f_t(x)∇2ft​(x)Δx=−∇ft​(x)
其中 ft(x)=tf0(x)+ϕ(x)f_t(x) = t f_0(x) + \phi(x)ft​(x)=tf0​(x)+ϕ(x)。内点法的迭代复杂度为 O(mlog⁡(m/ϵ))O(\sqrt{m} \log(m/\epsilon))O(m​log(m/ϵ))，每步需 O(n3)O(n^3)O(n3) 的矩阵分解。


实践中的求解器：CVXPY（Python）和 CVX（MATLAB）等建模工具将问题自动转化为标准形式，调用 SCS、MOSEK 或 ECOS 等底层求解器。建模与求解的分离是现代凸优化工程的标志性进展。

小结
凸优化的核心价值在于"结构决定可解性"：凸集和凸函数的数学结构保证局部最优即全局最优，对偶理论提供了问题分析和算法设计的双重工具，内点法以多项式复杂度求解大规模实例。掌握凸优化不仅为机器学习中的目标函数设计提供理论基础，也是理解现代优化算法（如 ADMM、近端梯度法）的必备前提。下一步建议深入组合优化，探索离散结构与连续松弛之间的关联。
