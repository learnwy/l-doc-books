研究生 高级算法 — 组合优化

知识要点

组合优化处理的是在有限（但通常指数级大）的候选方案中寻找最优解的问题。与凸优化的连续光滑结构不同，组合优化的核心挑战来自离散结构——整数变量、图论约束、排列组合使得穷举不可行。研究生阶段需要掌握多面体理论、整数规划技术、网络流算法，以及松弛与舍入的近似策略。

问题类 代表问题 复杂度 核心技术
最短路径 Dijkstra, Bellman-Ford P 动态规划 / 贪心
最大流 Ford-Fulkerson, Push-Relabel P 增广路径 / 预流推进
最小生成树 Kruskal, Prim P 贪心 + 并查集

详细讲解

多面体理论与整数规划

整数规划（IP）是组合优化的统一建模框架：

min⁡cTxs.t.Ax≤b, x∈Zn\min c^T x \quad \text{s.t.} \quad Ax \leq b,\ x \in \mathbb{Z}^nmincTxs.t.Ax≤b, x∈Zn

LP 松弛去掉整数约束后得到多面体 P={x∣Ax≤b}P = \{x \mid Ax \leq b\}P={x∣Ax≤b}。当 PPP 的所有顶点恰好是整数点时（称为整数多面体），LP 松弛直接给出整数最优解。全幺模矩阵（TU）是判定整数多面体的关键工具——若 AAA 是 TU 矩阵且 bbb 为整数向量，则 PPP 是整数多面体。

网络流问题的约束矩阵天然满足 TU 性质，这解释了为什么最大流、最小费用流等问题可在多项式时间内精确求解。

分支定界法：对 LP 松弛求解，若最优解非整数，选择一个分数变量 xi=fx_i = fxi​=f 创建两个子问题（xi≤⌊f⌋x_i \leq \lfloor f \rfloorxi​≤⌊f⌋ 和 xi≥⌈f⌉x_i \geq \lceil f \rceilxi​≥⌈f⌉），递归求解。剪枝策略决定实际效率：

割平面法：通过添加线性不等式（割平面）切掉分数解但保留所有整数可行解。Gomory 割是通用的割平面生成方法，而 Traveling Salesman 等特定问题有更强的割平面族（子巡回消除约束、梳子不等式）。


现代求解器（Gurobi, CPLEX）结合分支定界与割平面，称为分支切割法（Branch-and-Cut），是求解大规模整数规划的工业标准。


网络流与匹配
网络流理论连接了图论与线性规划。最大流-最小割定理（Ford-Fulkerson）是对偶理论在组合结构上的完美体现。


最大流算法演进：


    

  • Ford-Fulkerson：沿增广路径推流，O(VE2)O(VE^2)O(VE2)（Edmonds-Karp 的 BFS 策略）
    • 

  • Push-Relabel：维护预流和标号函数，O(V2E)O(V^2 E)O(V2E)，实践中最快
    • 

  • Dinic：层次图 + 阻塞流，O(V2E)O(V^2 E)O(V2E)，在单位容量网络中 O(EV)O(E\sqrt{V})O(EV​)
    • 



二部图匹配：最大匹配可通过最大流求解（构造超级源/汇）。König-Egerváry 定理揭示二部图中最大匹配 = 最小顶点覆盖。Hungarian 算法以 O(n3)O(n^3)O(n3) 求解带权最大匹配。


最小费用流：综合考虑容量约束和流量费用，LP 对偶给出互补松弛条件，Successive Shortest Path 算法基于此设计。


近似算法策略
当精确求解不可行时，近似算法在可证明的质量保证下高效求解。


LP 松弛 + 舍入：求解 LP 松弛得到分数解，通过随机或确定性舍入得到整数解。集合覆盖问题的贪心 O(ln⁡n)O(\ln n)O(lnn)-近似和 LP 舍入 fff-近似（fff 为元素最大出现次数）是经典案例。


原始-对偶方法：同时构造原始可行解和对偶可行解，用对偶目标值作为近似比的下界。Steiner 树的 2-近似和设施选址的 3-近似均基于此框架。


半正定松弛：Goemans-Williamson 算法用 SDP 松弛 MAX-CUT 问题，配合随机超平面舍入，达到 0.8780.8780.878-近似比——这个比率在唯一博弈猜想下是最优的。


现代求解技术
列生成：当变量数量指数级大时，只维护当前基的变量子集，通过求解定价子问题（pricing problem）动态添加有利变量。车辆路径问题（VRP）和大规模排班问题广泛使用此技术。


Lagrangian 松弛：将困难约束移入目标函数（加入 Lagrange 乘子惩罚），分解为易解的子问题。子梯度法更新乘子逼近对偶最优。经典应用包括设施选址和调度问题。


SAT 与 CSP 求解器：布尔可满足性（SAT）求解器通过 DPLL 搜索 + 冲突驱动学习（CDCL）处理百万变量规模的实例。许多组合优化问题可编码为 SAT 或约束满足问题（CSP），借助通用求解器获得高效解。

小结
组合优化的思维方式是"结构利用与近似折中"：多面体理论揭示问题的几何结构，整数规划提供统一建模框架，网络流展示了多项式可解的丰富结构，近似算法在 NP-hard 的困境中给出有保证的近似解。现代求解器将这些理论技术融合为分支切割、列生成等工程化方法，使得大规模实例的求解成为可能。下一步建议学习元启发式方法，了解工程实践中精确求解与启发式搜索的互补关系。
