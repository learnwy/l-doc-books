研究生 艺术批评 — 绘画与雕塑批评

知识要点

绘画与雕塑是西方艺术批评传统中最核心的对象——从Vasari到Greenberg，批评理论的核心概念大多围绕这两种媒介发展而来。但"传统"不等于"简单"——当代绘画和雕塑批评面临的挑战恰恰在于：如何在后观念艺术（Post-Conceptual Art）的语境中重新理解这些"古老"的媒介。Peter Osborne（2013）提出的"后观念状况"指出，在杜尚之后，所有艺术都在某种程度上是"观念性的"——纯粹的形式主义观看已不再可能。这不意味着形式不重要，而是意味着形式总是在观念、制度和历史的语境中被感知和理解。对于批评者而言，挑战在于同时关注作品的物质性（它是什么样的东西）和观念性（它在什么框架中运作）。

核心概念包括：

  • 媒介特异性的遗产与超越：Greenberg主张每种媒介探索其固有属性——但当代绘画故意混合媒介、引入物体、模糊绘画与装置的边界
  • 绘画性（Painterliness）：不仅指笔触可见的风格，更指绘画作为一种特殊的物质-感知关系的自觉
  • 物性（Objecthood）：雕塑从"在底座上的形象"转变为"在空间中的物体"——物性取代了再现性成为核心问题
  • 扩展的场域（Expanded Field）：Rosalind Krauss（1979）的概念——当代雕塑已扩展到包括景观、建筑和场域装置
  • 回归与挪用：当代绘画的"回归"不是简单的复古——它总是在引号中进行的，带有对绘画史的自觉引用

从Greenberg到当下：绘画批评的演变
形式主义阶段（1940s-60s）：Greenberg将绘画批评聚焦于"平面性"和"媒介自觉"。好的绘画不伪装成窗户或舞台，而是坦然面对自身作为涂了颜料的平面织物的事实。


极少主义/后极少主义反叛（1960s-70s）：极少主义把画从墙上拿下来，变成空间中的物体。后极少主义进一步引入过程、身体和临时性。


绘画的"回归"（1980s）：新表现主义（Basquiat, Schnabel, Kiefer）宣告绘画的回归——但批评者（如Benjamin Buchloh）质疑这是市场驱动的保守主义回潮。


后观念绘画（1990s-至今）：绘画不再"天真"——每一笔都自觉地引用绘画史。Richter的照片绘画、Tuymans的媒介图像绘画、Rauch的超现实叙事——这些实践都在绘画的内部反思绘画的条件。


雕塑批评的核心问题
Krauss（1979）在"Sculpture in the Expanded Field"中通过一个结构主义图表重新定义了雕塑：


传统雕塑 = 非景观 + 非建筑（双重否定）
当雕塑突破这个否定性定义后，它可以向四个方向扩展：


    

  • 景观 + 建筑 = 场域建设（Site-Construction）
    • 

  • 景观 + 非景观 = 标记场域（Marked Sites）
    • 

  • 建筑 + 非建筑 = 公理结构（Axiomatic Structures）
    • 



这个图表的价值不在于其精确性，而在于它证明了当代雕塑不能用单一定义来框定——它是一个由多种实践构成的"扩展的场域"。


当代雕塑批评的关键问题：


    

  • 物质性与概念性：材料的选择是纯粹的物质决策还是概念性的陈述？（如Ai Weiwei使用文化大革命时期的木材）
    • 

  • 尺度与权力：大型雕塑与纪念碑传统的关系——规模是在宣示权力还是在质疑权力？
    • 

  • 时间性：当代雕塑越来越关注过程和变化——腐蚀、生长、运动
    • 

  • 观众的身体：雕塑与观众身体的空间关系——围绕、穿越、触碰的可能性
    • 



批评写作的技艺：描述的艺术
对绘画和雕塑的批评写作面临一个根本挑战：如何用文字传达视觉体验？Ekphrasis（文字对视觉的描述）是批评写作最古老的修辞传统。


有效的作品描述应该：


    

  1. 从整体到细节：先建立总体印象，再深入具体区域
    2. 

  2. 引导观看路径：告诉读者先看什么、再看什么——你的描述隐含了一种观看策略
    3. 

  3. 使用精确的视觉语言：避免笼统（"色彩丰富"），使用具体描述（"画面右上角的镉红几乎跳出画面，与下方大面积的铅灰色形成不安的对峙"）
    4. 

  4. 记录身体反应：你的身体如何回应这件作品？需要仰头、弯腰、后退？
    5. 

  5. 区分观察和解释：明确标注哪些是你的观察，哪些是你的解读
    6. 



练习与思考
    

  1. 双重阅读：选择一幅当代绘画作品。先用纯形式主义的方式分析它（只关注颜色、构图、笔触、表面质感），然后用社会艺术史的方式分析它（关注图像来源、创作语境、展示制度）。两种阅读产生了什么不同的理解？它们之间有没有可能整合？
    

    2. 

  2. Krauss 图表练习：选择三件你认为处于"扩展的场域"中不同位置的当代雕塑/装置。分析它们与景观和建筑的关系。Krauss 的图表是否仍然有效？你觉得需要增加什么新的坐标轴？
    

    3. 

  3. Ekphrasis 写作：选一件实体绘画或雕塑作品，写一段 500 字的精确描述——让没看过作品的人能够通过文字"看到"它。然后请一位没看过原作的朋友读你的描述，画出他/她想象的作品。比较实际作品和想象作品之间的差距。
    

    4. 

  4. 绘画的观念性：选择一件看起来"很传统"的当代绘画（如具象油画）。分析它的"后观念"维度——它如何在引用绘画传统的同时反思绘画的条件？它与百年前的一幅类似题材的绘画有什么根本性的区别？
    

    5.

小结
绘画和雕塑批评的挑战在于它们既是最"传统"的批评对象（有着数百年的批评积累），也是在当代语境中被最激烈地重新定义的领域。有效的当代批评需要同时掌握传统的形式分析能力（精确地描述和分析视觉结构）和当代的理论敏感性（理解形式如何在社会、制度和话语语境中获得意义）。这种双重能力——既能"看"又能"读"——正是绘画与雕塑批评训练的核心目标。
