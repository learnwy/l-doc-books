研究生 课程理论 — 课程实施

知识要点

课程实施是连接课程设计与学生实际学习体验的关键环节，也是课程改革成败的决定性环节。再精美的课程方案如果无法在教室中有效落地，便只是一纸空文。围绕课程实施的研究揭示了一个核心张力：课程应该被忠实执行还是允许教师灵活改编？Fullan 的教育变革理论为理解大规模课程改革的复杂性提供了深刻洞见，而课程制定 (curriculum enactment) 和教师能动性 (teacher agency) 的概念则重新定义了教师在课程实施中的角色。

课程实施的核心理论视角：

视角 核心概念 对教师的假设 评价标准
忠实取向 忠实度 (fidelity) 执行者 实施与设计方案的吻合程度
相互调适取向 调适 (mutual adaptation) 调适者 课程与情境的匹配度
课程创生取向 制定 (enactment) 创造者 师生共同创造的学习经验质量

详细讲解

课程实施的三种取向

课程实施研究经历了从"忠实取向"到"相互调适"再到"课程创生"的演进，这一演进反映了对教师专业角色认识的深化。

忠实取向 (Fidelity Perspective)

忠实取向是最早也最直观的课程实施观念：课程实施的质量取决于教师在多大程度上忠实地执行了课程设计者的方案。在这种视角下：

  • 好的实施 = 高忠实度（教师严格按照教师手册和课程指南教学）
  • 实施失败 = 教师偏离了预定方案（被视为"抵制"或"能力不足"）
  • 研究重点是测量实施的忠实度，并寻找提高忠实度的策略

忠实取向在药物试验等标准化干预领域有其合理性，但在教育中面临根本性困难：教室不是实验室，学生不是试验对象，教学情境的独特性使得完全忠实的"执行"既不可能也不可取。

相互调适取向 (Mutual Adaptation)

RAND Change Agent Study（1973-1978）是课程实施研究的转折点。McLaughlin 等人在对美国联邦教育改革项目的大规模评估中发现：

成功的课程实施不是方案被忠实执行的结果，而是方案与地方情境相互调适的结果。

这意味着：

  • 课程方案在实施过程中必然会被修改和调整
  • 这种调整不是"失败"，而是适应不同情境的必要过程
  • 成功的关键不是消除偏差，而是确保调适的方向与课程的核心理念一致

相互调适取向标志着从"设计者控制"到"情境回应"的转变，承认了地方教育者的专业判断在实施中的重要作用。

课程创生取向 (Curriculum Enactment)

Snyder, Bolin 和 Zumwalt 在1992年提出了"课程创生"的概念，将实施研究推向了更深层次：

  • 课程不是一个在教室外设计好的"东西"然后被"放入"教室
  • 课程是师生在教室互动中共同创生的经验
  • 实施不是"执行"别人的方案，而是教师基于自己的理解和学生的反应持续创造课程

课程创生取向受到现象学和建构主义的影响，它将课程实施的单位从"方案"转移到了"经验"——重要的不是方案被执行了多少，而是师生实际经历了什么样的学习。

Fullan 的教育变革理论
Michael Fullan 是当代教育变革研究最具影响力的学者之一。他的理论为理解课程改革的复杂动态提供了一个多层次框架。


变革的三个阶段：


    

  1. 启动 (Initiation/Adoption)：改革从哪里开始？谁发起了变革？为什么启动这项变革？
    

      

    • 变革可以自上而下（政策驱动）或自下而上（教师自发）
      • 

    • 启动不等于承诺——许多改革在启动时充满热情，却很快消散
      • 

    

    2. 

  2. 实施 (Implementation)：改革在实践中如何展开？实际发生了什么变化？
    

      

    • 实施的核心是"实践中的变化"——不是宣言或文件的变化，而是教师教学行为、学生学习方式和学校组织的实际改变
      • 

    • Fullan 强调实施涉及三个维度的变化：新材料（教学资源和技术）、新教学方法（教学策略和行为）、新信念（教师的教育理念和价值观）
      • 

    

    3. 

  3. 制度化/持续 (Institutionalization/Continuation)：变革是否成为学校文化的一部分？还是随着外部支持的撤出而消退？
    

    4.

Fullan 的核心洞见是：**教育变革的意义建构过程比变革方案本身更重要。**教师对改革的理解、认同和内化决定了改革能否在教室中真正发生。如果教师不理解改革的"为什么"，只被要求执行"怎么做"，改革就只能停留在表面层次——教师可能会改变教学的"外观"（使用新教材、采用新术语），但教学的深层逻辑并未改变。


教师能动性与课程实施
"教师能动性"(teacher agency) 近年来成为课程实施研究的热点概念。Priestley, Biesta 和 Robinson (2015) 将教师能动性定义为：




教师在特定情境中主动塑造其工作和职业实践的能力，而不是被动地被结构性条件所决定。




他们提出了教师能动性的生态模型——能动性不是教师个人的固有属性，而是个人能力与环境条件互动的产物：


    

  • 迭代维度 (iterational)：教师过去的经验、知识和信念如何影响他们对课程的解读和实施
    • 

  • 实践评价维度 (practical-evaluative)：教师在当下的制度环境、资源条件和人际关系中做出判断和行动
    • 

  • 投射维度 (projective)：教师对未来的期望和愿景如何驱动他们的课程实践
    • 



这一框架的重要意义在于：要增强教师能动性，不能仅关注教师个人能力的提升（如培训），还必须改善教师工作的制度环境（如减轻行政负担、提供合作时间、尊重专业判断）。


课程实施的"松散耦合"
Karl Weick 的"松散耦合"(loose coupling) 概念对理解学校中的课程实施非常有用。学校组织的特点是：各个层级（政策制定者→学区→学校→教室）之间的连接是松散的，而不是紧密耦合的。


这意味着：


    

  • 政策层面的课程改革不会自动、完整地传递到教室层面
    • 

  • 每一层的行动者都会根据自己的理解和利益对改革进行"过滤"和"转译"
    • 

  • 教师关起教室的门，在很大程度上拥有课程实施的实际控制权
    • 



松散耦合对课程实施的含义是双面的：


    

  • 负面：改革容易在传递过程中失真、衰减甚至变形
    • 

  • 正面：教师有空间进行专业判断和创造性调适，不会被不合理的政策完全束缚
    • 



练习与思考
    

  1. 取向辨析：回忆一次你经历或观察到的课程改革。分析其实施过程更接近哪种取向（忠实、相互调适还是课程创生）？这种取向带来了什么结果？
    

    2. 

  2. Fullan 分析：选择中国某一轮基础教育课程改革（如2001年或2022年），用 Fullan 的变革三阶段和影响因素框架分析其实施过程。哪些因素促进了实施？哪些因素构成了障碍？
    

    3. 

  3. 能动性案例：描述一个你认识的教师在课程实施中表现出能动性的案例。用 Priestley 等人的生态模型分析哪些因素支持或限制了这位教师的能动性。
    

    4. 

  4. 松散耦合观察：在你的教育经历中，课程政策从"文件"到"教室"的传递过程中发生了哪些变化？这种"松散"是好事还是坏事？
    

    5. 

  5. 设计建议：如果你是一项课程改革的领导者，基于本节学习的理论，你会如何设计实施策略以最大化改革成功的可能性？

小结
课程实施研究揭示了一个核心真相：课程改革不是一个线性的"设计→执行"过程，而是一个多层级、多行动者参与的复杂社会过程。从忠实取向到相互调适再到课程创生，研究者逐渐认识到教师不是改革的"工具"而是改革的"主体"。Fullan 的理论提醒我们，成功的课程实施需要关注变革的意义建构，而不仅仅是技术层面的操作。教师能动性的概念进一步强调，课程实施的质量取决于教师在特定环境中主动创造和调适的空间与能力。理解这些理论，对于参与或领导任何教育变革都具有直接的实践价值。
