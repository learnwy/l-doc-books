研究生 课程理论 — 课程评价

知识要点

课程评价是对课程方案的价值、效果和影响进行系统判断的过程，它直接影响课程改进的方向和资源配置的决策。从 Stufflebeam 的 CIPP 决策导向模型到 Stake 的回应性评价，从 Webb 的知识深度 (DOK) 一致性分析到当代的课程审计，课程评价已发展出多元的理论视角和方法论工具。理解这些评价模型不仅对课程研究者至关重要，也为教育政策制定者、学校管理者和教师提供了改进课程的实证基础。

课程评价的主要模型对照：

模型 提出者 核心理念 评价目的 方法倾向
CIPP Stufflebeam (1971) 评价服务于决策 改进课程 系统化、综合性
回应性评价 Stake (1975) 回应利益相关者关切 理解课程 质性、情境化
目标游离评价 Scriven (1972) 评价实际效果而非预定目标 发现意外效果 独立、客观
课程一致性 Webb (1997) 标准-课程-评估对齐 确保体系一致 结构化分析

详细讲解

Stufflebeam 的 CIPP 评价模型

Daniel Stufflebeam 提出的 CIPP 模型是课程评价领域最具影响力和最常用的框架之一。CIPP 是四种评价类型的首字母缩写，每种类型回答不同的决策问题：

C — 背景评价 (Context Evaluation)

  • 核心问题：我们需要做什么？
  • 评价内容：分析教育环境、识别需求和问题、评估现有资源和机会
  • 服务于：规划决策 (planning decisions)
  • 方法：需求评估、环境扫描、利益相关者访谈、文献分析

I — 输入评价 (Input Evaluation)

  • 核心问题：我们应该怎么做？
  • 评价内容：审查可选方案的可行性、成本效益和理论基础
  • 服务于：结构决策 (structuring decisions)
  • 方法：方案比较分析、专家评审、资源盘点、文献综述

P — 过程评价 (Process Evaluation)

  • 核心问题：我们实际在做什么？做得怎么样？
  • 评价内容：监控实施过程、记录实际活动、识别实施中的偏差和困难
  • 服务于：实施决策 (implementing decisions)
  • 方法：课堂观察、实施日志、教师反馈、学生反应

P — 成果评价 (Product Evaluation)

  • 核心问题：我们做到了吗？效果如何？
  • 评价内容：评估课程产出——学生学习成果、态度变化、长期影响
  • 服务于：循环决策 (recycling decisions)
  • 方法：成就测试、问卷调查、追踪研究、比较分析
Stufflebeam 后来将成果评价进一步细分为四个子维度：影响 (Impact)、效能 (Effectiveness)、可持续性 (Sustainability) 和可迁移性 (Transportability)，使模型更加精细化。


**CIPP 模型的核心理念是"评价的最重要目的不是证明 (prove)，而是改进 (improve)"。**这一理念将评价从事后判断转变为伴随课程全过程的持续改进工具。


Stake 的回应性评价
Robert Stake 提出的回应性评价 (Responsive Evaluation) 代表了一种与 CIPP 截然不同的评价哲学。如果说 CIPP 是"管理主义"的，那么 Stake 的取向则是"人文主义"的。


回应性评价的核心原则：


    

  1. 以利益相关者的关切为导向：评价者不是按照预设的框架去收集数据，而是通过与各利益相关者（学生、教师、家长、管理者、社区成员）的持续对话，发现他们真正关心的问题。
    

    2. 

  2. 关注课程的独特性：每个教育项目都是在特定情境中由特定的人实施的，回应性评价重视理解这种独特性，而不是用标准化的指标进行跨项目比较。
    

    3. 

  3. 质性描述为主：用丰厚描述 (thick description)、案例研究和叙事来呈现课程的运作过程和效果，而不仅仅是数字和统计量。
    

    4. 

  4. 评价者的角色：评价者不是超然的"裁判"，而是一个倾听者、解释者和促进对话者。
    

    5.

在早期的"面相模型"中，Stake 提出了一个结构化的描述框架：

这个矩阵帮助评价者系统地比较"计划"与"实际"之间的差距，揭示课程实施中的偏差和意外效果。


Scriven 的目标游离评价
Michael Scriven 提出了一个极具挑战性的评价理念——目标游离评价 (Goal-Free Evaluation)。他认为：


    

  • 传统评价以课程的预设目标为参照，只关注目标是否达成
    • 

  • 这种做法会让评价者对课程的意外效果（无论正面还是负面）视而不见
    • 

  • 解决方案：评价者不应被告知课程的预设目标，而应独立地观察课程的所有实际效果
    • 



目标游离评价的逻辑：


Scriven 还引入了形成性评价 (formative evaluation) 和总结性评价 (summative evaluation) 的经典区分：






类型
时机
目的
服务对象





形成性评价
课程开发和实施过程中
改进课程
课程开发者




总结性评价
课程实施完成后
判断课程价值
决策者、资助者





用 Stake 的妙喻来说："当厨师品尝汤的味道时，这是形成性评价；当客人品尝时，这是总结性评价。"


Webb 的知识深度与课程一致性
Norman Webb 提出的知识深度 (Depth of Knowledge, DOK) 框架和课程一致性 (alignment) 分析方法，解决了一个关键问题：课程标准、教学内容和考试评估之间是否真正对齐？

一致性分析的关键维度：


Webb 提出了评估课程一致性的四个维度：


    

  1. 类别一致性 (Categorical Concurrence)：评估内容是否覆盖了课程标准中的各个类别/领域？
    2. 

  2. 知识深度一致性 (DOK Consistency)：评估的认知要求层次是否与课程标准一致？
    3. 

  3. 知识范围 (Range of Knowledge Correspondence)：评估是否涵盖了每个类别内足够广度的知识？
    4. 

  4. 证据来源平衡 (Balance of Representation)：评估对不同标准的关注是否均衡？
    5. 



一致性分析在实践中的意义：如果课程标准要求学生达到 DOK 3-4 的水平（如分析和评价），但考试只测试 DOK 1-2 的内容（回忆和简单应用），那么即使学生考试成绩优秀，也不能说他们达到了课程标准的要求。这种错位在应试教育文化中尤其常见。


课程评价的当代发展
第四代评价 (Guba & Lincoln)


Guba 和 Lincoln 在1989年提出了"第四代评价"，主张评价应该是一个建构主义的协商过程：


    

  • 第一代：测量 (measurement) — 以测验和测量为核心
    • 

  • 第二代：描述 (description) — 描述课程的优缺点
    • 

  • 第三代：判断 (judgment) — 对课程价值做出判断
    • 

  • 第四代：协商 (negotiation) — 各利益相关者通过对话协商课程的意义和价值
    • 



课程审计 (Curriculum Audit)


Fenwick English 提出的课程审计方法将企业审计的逻辑引入教育：


    

  • 系统性检查学区的课程文件、教学实践和学生成就数据之间的一致性
    • 

  • 识别"书面课程"(written curriculum)、"教授课程"(taught curriculum) 和"测试课程"(tested curriculum) 之间的差距
    • 

  • 为课程改进提供基于证据的建议
    • 



练习与思考
    

  1. CIPP 应用：为你所在或了解的一个教育项目设计一个 CIPP 评价方案——分别说明在四个维度你会收集什么数据、使用什么方法、回答什么问题。
    

    2. 

  2. 评价取向比较：如果要评价一个为期两年的农村小学科学课程改革项目，你会选择 CIPP 模型、回应性评价还是目标游离评价？为什么？不同选择会导致什么不同的评价结果？
    

    3. 

  3. DOK 分析：选择一份你熟悉的考试试卷，对每道题目进行 DOK 层次编码。试卷整体的 DOK 分布如何？与相应的课程标准一致吗？
    

    4. 

  4. 利益相关者分析：一项课程改革的不同利益相关者（学生、教师、家长、校长、教育局、高校招生部门）可能对课程评价有哪些不同的关切和期望？如果你是评价者，如何平衡这些不同诉求？
    

    5. 

  5. 第四代评价反思：如果评价是一个"协商"过程而非"客观判断"，那么评价的权威性从何而来？第四代评价是否可能被强势利益相关者操纵？
    

    6.

小结
课程评价不是在课程结束时"算总账"的终点事件，而是贯穿课程全生命周期的持续改进过程。CIPP 模型提供了从背景到成果的系统化评价框架，Stake 的回应性评价强调了评价的人文关怀和情境敏感性，Scriven 的目标游离评价提醒我们关注课程的意外效果，Webb 的一致性分析则确保了课程标准、教学和评估之间的有效对齐。不同评价模型适用于不同的目的和情境——选择哪种模型，取决于"评价为谁服务"和"评价要回答什么问题"。
