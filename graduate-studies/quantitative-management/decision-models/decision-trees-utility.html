研究生 定量管理方法 — 决策树与效用理论

知识要点

决策树（Decision Tree）与效用理论（Utility Theory）是管理决策分析中处理不确定性的核心工具。决策树提供了一种结构化的方法来表示和分析序贯决策问题，效用理论则为决策者的风险偏好提供了公理化的数学表达。两者结合，使管理者能够在不确定环境中做出理性的、与自身风险态度一致的决策。

核心概念包括：

  • 决策树结构：决策节点（方块）、机会节点（圆圈）、结果节点（三角），以及连接它们的分支
  • 期望货币值（Expected Monetary Value, EMV）：各结果的概率加权平均，用于风险中性决策
  • 回滚法（Rollback/Folding Back）：从决策树末端向根节点逐步计算最优策略的方法
  • 完美信息的期望价值（EVPI）：完美预测相对于无信息决策的价值增量
  • 样本信息的期望价值（EVSI）：不完美预测信息的价值，通常通过贝叶斯更新计算
  • Von Neumann-Morgenstern 效用理论：基于公理化体系的期望效用最大化模型
  • 风险偏好类型：风险厌恶（凹效用函数）、风险中性（线性效用函数）、风险追求（凸效用函数）
  • 确定等价物（Certainty Equivalent）与风险溢价（Risk Premium）：衡量决策者风险偏好的关键指标

详细讲解

决策树的构建与求解

决策树是一种图形化的决策分析工具，特别适合分析包含多个阶段、每个阶段面临不同选择和不确定性的序贯决策问题。

构建步骤：

  1. 按时间顺序从左到右排列决策点和机会事件
  2. 在每个决策节点列出所有可选方案
  3. 在每个机会节点列出所有可能的自然状态及其概率
  4. 在每个终端节点标注结果（收益或成本）

求解方法——回滚法：

  • 从决策树最右端（终端节点）开始
  • 对每个机会节点，计算期望值 E=∑ipi⋅viE = \sum_{i} p_i \cdot v_iE=∑i​pi​⋅vi​
  • 对每个决策节点，选择期望值最优的分支
  • 逐步回溯到根节点，得到最优策略

示例：某企业考虑是否投资新产品。投资需要 500 万元。市场好（概率 0.6）时收益 1200 万，市场差（概率 0.4）时收益 200 万。

EMV（投资）=0.6×1200+0.4×200−500=720+80−500=300= 0.6 \times 1200 + 0.4 \times 200 - 500 = 720 + 80 - 500 = 300=0.6×1200+0.4×200−500=720+80−500=300 万

EMV（不投资）=0= 0=0

因此，基于 EMV 准则，应选择投资。

信息的价值

决策分析的一个核心问题是：在做出最终决策之前，花钱获取额外信息是否值得？

完美信息的期望价值（EVPI）：

EVPI=EPPI−EMV∗\text{EVPI} = \text{EPPI} - \text{EMV}^*EVPI=EPPI−EMV∗

其中 EPPI（Expected Payoff with Perfect Information）是在已知自然状态后再决策的期望收益，EMV∗\text{EMV}^*EMV∗ 是无信息时最优策略的期望收益。EVPI 给出了信息价值的上界——无论多精确的预测，其价值都不超过 EVPI。

继续上例：EPPI =0.6×(1200−500)+0.4×0=0.6×700=420= 0.6 \times (1200 - 500) + 0.4 \times 0 = 0.6 \times 700 = 420=0.6×(1200−500)+0.4×0=0.6×700=420 万。EVPI =420−300=120= 420 - 300 = 120=420−300=120 万。

样本信息的期望价值（EVSI）：实际中我们获得的信息总是不完美的（如市场调研、专家咨询）。EVSI 的计算需要贝叶斯概率更新——根据调研结果修正自然状态的先验概率，然后重新计算决策树。

概念 含义 计算方法
EMV 风险中性下的最优期望收益 回滚法
EVPI 完美信息的最大价值 EPPI - EMV*
EVSI 不完美信息的实际价值 贝叶斯更新后的决策改善
信息效率 EVSI/EVPI 衡量信息质量的比率

Von Neumann-Morgenstern 效用理论

EMV 准则假设决策者是风险中性的——只关心期望值，不考虑风险。但大多数管理者面对大额不确定决策时并非风险中性。Von Neumann 和 Morgenstern（1944）在《博弈论与经济行为》中建立了期望效用理论的公理化体系。

四个基本公理：

  1. 完备性：对任意两个彩票 L1L_1L1​ 和 L2L_2L2​，决策者要么偏好 L1L_1L1​，要么偏好 L2L_2L2​，要么无差异
  2. 传递性：如果 L1≻L2L_1 \succ L_2L1​≻L2​ 且 L2≻L3L_2 \succ L_3L2​≻L3​，则 L1≻L3L_1 \succ L_3L1​≻L3​
  3. 连续性：如果 L1≻L2≻L3L_1 \succ L_2 \succ L_3L1​≻L2​≻L3​，则存在概率 ppp 使得 L2∼pL1+(1−p)L3L_2 \sim pL_1 + (1-p)L_3L2​∼pL1​+(1−p)L3​
  4. 独立性：如果 L1≻L2L_1 \succ L_2L1​≻L2​，则对任意 L3L_3L3​ 和 p∈(0,1)p \in (0,1)p∈(0,1)，pL1+(1−p)L3≻pL2+(1−p)L3pL_1 + (1-p)L_3 \succ pL_2 + (1-p)L_3pL1​+(1−p)L3​≻pL2​+(1−p)L3​

满足这四个公理的决策者行为可以用效用函数 U(⋅)U(\cdot)U(⋅) 来表示，且其决策目标是最大化期望效用：

风险偏好与效用函数

效用函数的形状反映了决策者的风险态度：

风险厌恶（U′′(x)<0U''(x) < 0U′′(x)<0，凹函数）：大多数管理者在面对大额不确定性时表现出风险厌恶。典型效用函数包括：

  • 指数效用：U(x)=1−e−x/RU(x) = 1 - e^{-x/R}U(x)=1−e−x/R（RRR 为风险容忍度参数）
  • 对数效用：U(x)=ln⁡(x)U(x) = \ln(x)U(x)=ln(x)
  • 幂效用：U(x)=x1−γ/(1−γ)U(x) = x^{1-\gamma}/(1-\gamma)U(x)=x1−γ/(1−γ)

确定等价物（CE）：使决策者对不确定彩票无差异的确定金额。即 U(CE)=E[U(L)]U(CE) = E[U(L)]U(CE)=E[U(L)]。

风险溢价（RP）：RP=EMV−CERP = EMV - CERP=EMV−CE。风险厌恶者的 RP>0RP > 0RP>0，他们愿意放弃一些期望收益来换取确定性。

行为决策理论的挑战
Kahneman 和 Tversky（1979）的前景理论（Prospect Theory）对经典效用理论提出了系统性挑战。他们通过实验发现：


参照点依赖：人们以参照点（而非绝对财富水平）来评估收益和损失。


损失厌恶：损失的心理痛苦约为等额收益快乐的 2-2.5 倍。


概率加权：人们倾向于高估小概率事件、低估大概率事件。


框架效应：相同问题的不同表述方式会导致不同决策——如"90%存活率"与"10%死亡率"引发不同反应。


前景理论对管理实践的启示是深刻的：理性决策模型（EMV 和效用理论）提供了规范性基准，但实际决策行为会系统性地偏离这些基准。管理者既需要掌握规范性工具进行严谨分析，也需要理解描述性理论来预测自己和他人的实际行为。

小结
决策树提供了在不确定性下进行序贯决策的结构化框架，EMV 准则为风险中性决策提供了基准，信息价值分析帮助决策者判断是否值得获取额外信息。效用理论将决策者的风险偏好正式纳入分析框架，使决策建议能够反映个人或组织的风险态度。同时，行为决策理论提醒我们实际决策与理性模型之间存在系统性偏差。研究生应同时掌握规范性工具（做出更好的决策）和描述性理论（理解实际决策行为），这种双重视角是管理决策分析的核心素养。
