研究生 定量管理方法 — 线性规划

知识要点

线性规划（Linear Programming, LP）是运筹学和管理科学中最基础且应用最广泛的优化工具。它处理的核心问题是：在满足一组线性约束条件下，找到一个使线性目标函数达到最优（最大化或最小化）的决策变量组合。从生产计划到资源分配，从物流调度到投资组合，LP 为管理决策提供了严格的数学框架。

核心概念包括：

  • 标准形式：目标函数 max⁡ cTx\max \ c^T xmax cTx，约束 Ax≤bAx \leq bAx≤b，x≥0x \geq 0x≥0
  • 可行域与凸多面体：所有满足约束条件的解构成的凸集
  • 基本可行解（Basic Feasible Solution）：可行域顶点处的解，最优解必在某个顶点取得
  • 单纯形法（Simplex Method）：Dantzig（1947）发明的沿顶点搜索的经典算法
  • 对偶理论（Duality Theory）：每个 LP 问题都有一个对偶问题，原问题与对偶问题的最优值相等（强对偶定理）
  • 影子价格（Shadow Price）：约束条件右端项变化一个单位时目标函数值的变化量
  • 灵敏度分析（Sensitivity Analysis）：研究参数变化对最优解的影响
  • 整数规划与松弛：当决策变量必须取整数值时的 LP 扩展

详细讲解

线性规划的数学框架

一个标准形式的线性规划问题可以写为：

max⁡z=c1x1+c2x2+⋯+cnxn\max \quad z = c_1 x_1 + c_2 x_2 + \cdots + c_n x_nmaxz=c1​x1​+c2​x2​+⋯+cn​xn​
s.t.ai1x1+ai2x2+⋯+ainxn≤bi,i=1,2,…,m\text{s.t.} \quad a_{i1}x_1 + a_{i2}x_2 + \cdots + a_{in}x_n \leq b_i, \quad i = 1, 2, \ldots, ms.t.ai1​x1​+ai2​x2​+⋯+ain​xn​≤bi​,i=1,2,…,m
xj≥0,j=1,2,…,nx_j \geq 0, \quad j = 1, 2, \ldots, nxj​≥0,j=1,2,…,n

用矩阵表示即 max⁡ cTx, s.t. Ax≤b,x≥0\max \ c^T x, \text{ s.t. } Ax \leq b, x \geq 0max cTx, s.t. Ax≤b,x≥0。其中 x∈Rnx \in \mathbb{R}^nx∈Rn 是决策变量向量，c∈Rnc \in \mathbb{R}^nc∈Rn 是目标函数系数向量，A∈Rm×nA \in \mathbb{R}^{m \times n}A∈Rm×n 是约束矩阵，b∈Rmb \in \mathbb{R}^mb∈Rm 是资源向量。

可行域的几何解释：每一个线性不等式约束定义了 nnn 维空间中的一个半空间，所有约束的交集构成一个凸多面体（convex polyhedron）。LP 的一个基本定理指出：如果最优解存在，它必定在凸多面体的某个顶点（极点）处取得。这一定理为单纯形法提供了理论基础——我们只需要搜索有限个顶点，而不是无穷多的可行解。

单纯形法

Dantzig（1947）发明的单纯形法是运筹学历史上最重要的算法之一。其核心思想是：

  1. 从一个基本可行解（顶点）出发
  2. 检查是否存在相邻顶点可以改善目标函数值
  3. 如果存在，移动到改善最大的相邻顶点（换基操作）
  4. 重复直到没有相邻顶点可以改善——当前解即为最优解

单纯形法的核心操作是换基（pivoting）：选择一个非基变量进入基（入基变量，选择判据是使目标函数改善最大的变量），同时确定一个基变量离开基（出基变量，通过最小比率测试确定以保持可行性）。

步骤 操作 判据
初始化 找到初始基本可行解 通常通过添加松弛变量获得
最优性检验 检查所有非基变量的检验数 所有检验数 ≤0\leq 0≤0（最大化）则最优
入基选择 选择检验数最大的非基变量 max⁡j{cj−zj>0}\max_{j} \{c_j - z_j > 0\}maxj​{cj​−zj​>0}
出基选择 最小比率测试 min⁡i{bi/aij:aij>0}\min_{i} \{b_i / a_{ij} : a_{ij} > 0\}mini​{bi​/aij​:aij​>0}
换基 高斯-约当消元 更新单纯形表

虽然单纯形法在最坏情况下是指数时间复杂度（Klee-Minty 反例），但在实际应用中表现极为高效，通常只需要约 2m2m2m 到 3m3m3m 次迭代（mmm 为约束数）。

对偶理论

对偶理论是线性规划中最深刻的理论成果之一。每个原问题（Primal）都有一个对应的对偶问题（Dual）：

原问题：max⁡ cTx, s.t. Ax≤b,x≥0\max \ c^T x, \text{ s.t. } Ax \leq b, x \geq 0max cTx, s.t. Ax≤b,x≥0

对偶问题：min⁡ bTy, s.t. ATy≥c,y≥0\min \ b^T y, \text{ s.t. } A^T y \geq c, y \geq 0min bTy, s.t. ATy≥c,y≥0

弱对偶定理：对偶问题任何可行解的目标值 ≥\geq≥ 原问题任何可行解的目标值。即 bTy≥cTxb^T y \geq c^T xbTy≥cTx。

强对偶定理：如果原问题有最优解，则对偶问题也有最优解，且两者的最优目标值相等：cTx∗=bTy∗c^T x^* = b^T y^*cTx∗=bTy∗。

互补松弛条件：在最优解处，xj∗(cj−∑iaijyi∗)=0x_j^*(c_j - \sum_i a_{ij} y_i^*) = 0xj∗​(cj​−∑i​aij​yi∗​)=0 对所有 jjj 成立，yi∗(bi−∑jaijxj∗)=0y_i^*(b_i - \sum_j a_{ij} x_j^*) = 0yi∗​(bi​−∑j​aij​xj∗​)=0 对所有 iii 成立。

对偶理论的管理含义极为重要：对偶变量 yi∗y_i^*yi∗​ 就是第 iii 个约束对应资源的影子价格——它告诉管理者：如果多获得一个单位的第 iii 种资源，最优利润将增加 yi∗y_i^*yi∗​。这为资源定价和投资决策提供了直接指导。

灵敏度分析

实际管理决策中，LP 模型的参数（成本系数、资源量、技术系数）往往不是精确已知的。灵敏度分析研究参数在多大范围内变化时当前最优基仍然有效：

目标函数系数的变化范围：对于每个变量 xjx_jxj​，存在一个区间 [cjL,cjU][c_j^L, c_j^U][cjL​,cjU​]，当 cjc_jcj​ 在此区间内变化时，最优基不变（但最优值会变化）。

右端项（资源量）的变化范围：对于每个约束 iii，存在一个区间 [biL,biU][b_i^L, b_i^U][biL​,biU​]，当 bib_ibi​ 在此区间内变化时，影子价格有效。

参数规划：当参数变化超出灵敏度范围时，需要进行参数规划（Parametric Programming）来追踪最优解的全局变化轨迹。

管理应用案例

生产计划问题：某工厂生产两种产品 A 和 B。产品 A 利润 cAc_AcA​ 元/件，产品 B 利润 cBc_BcB​ 元/件。受机器工时、人工工时和原材料三种资源约束。决策变量为各产品的生产量，目标是利润最大化。

运输问题：mmm 个供应地到 nnn 个需求地的最低运输成本方案。这是 LP 的一个特殊结构，可用运输表法更高效地求解。

投资组合：在预期收益率的线性近似下，确定各资产的投资比例以最大化预期收益，同时满足总预算约束和风险分散约束。

超越经典 LP
整数规划（Integer Programming）：当决策变量必须取整数值（如设备台数、是否投资某项目的0-1决策）时，LP 松弛加分支定界法是标准求解方法。


内点法（Interior Point Methods）：Karmarkar（1984）提出的多项式时间算法，从可行域内部穿越到最优解。对大规模稀疏问题，内点法通常比单纯形法更快。


随机规划（Stochastic Programming）：当参数具有随机性时，通过场景分析和期望值优化来处理不确定性。

小结
线性规划是定量管理方法的基石，它将管理决策问题转化为可精确求解的数学优化问题。单纯形法提供了高效的求解工具，对偶理论揭示了资源的经济价值（影子价格），灵敏度分析帮助管理者理解参数不确定性的影响。研究生应掌握 LP 的建模能力（将实际问题转化为数学模型）、求解能力（使用软件工具）和结果解释能力（对偶分析和灵敏度分析的管理含义）。LP 还是理解更高级优化方法（整数规划、非线性规划、随机规划）的必要基础。
