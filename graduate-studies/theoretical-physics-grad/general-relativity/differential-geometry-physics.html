研究生 理论物理 — 物理中的微分几何

知识要点

微分几何是广义相对论的数学语言。在 Einstein 的引力理论中，引力不是一种力，而是时空几何的弯曲。描述这种弯曲需要一套超越平直欧氏几何的数学工具——Riemann 几何。度量张量描述时空中的距离和角度，联络定义了平行移动和协变导数，曲率张量则量化了时空的弯曲程度。掌握这些几何工具是理解 Einstein 场方程和黑洞物理的前提。

核心概念：

  • 度量张量 gμνg_{\mu\nu}gμν​：定义时空中的线元 ds2=gμνdxμdxνds^2 = g_{\mu\nu}dx^\mu dx^\nuds2=gμν​dxμdxν
  • Christoffel 符号 Γμνλ\Gamma^\lambda_{\mu\nu}Γμνλ​：Levi-Civita 联络的分量
  • 协变导数 ∇μ\nabla_\mu∇μ​：在弯曲时空中保持张量性质的微分
  • Riemann 曲率张量 RρσμνR^\rho{}_{\sigma\mu\nu}Rρσμν​：量化时空弯曲
  • 测地线：弯曲时空中的"最短路径"

详细讲解

张量与坐标变换

坐标变换：xμ→x′μ(x)x^\mu \to x'^\mu(x)xμ→x′μ(x)，变换矩阵为 ∂x′μ∂xν\frac{\partial x'^\mu}{\partial x^\nu}∂xν∂x′μ​。

张量的定义：按特定规则变换的几何对象。

度量张量：定义内积 g(u,v)=gμνuμvνg(\mathbf{u}, \mathbf{v}) = g_{\mu\nu}u^\mu v^\nug(u,v)=gμν​uμvν 和线元：

Christoffel 符号与协变导数

在弯曲时空中，偏导数 ∂μVν\partial_\mu V^\nu∂μ​Vν 不是张量（变换不正确）。需要引入协变导数：

∇μVν=∂μVν+ΓμλνVλ\nabla_\mu V^\nu = \partial_\mu V^\nu + \Gamma^\nu_{\mu\lambda}V^\lambda∇μ​Vν=∂μ​Vν+Γμλν​Vλ

Christoffel 符号（Levi-Civita 联络）：

Γμνλ=12gλρ(∂μgνρ+∂νgμρ−∂ρgμν)\Gamma^\lambda_{\mu\nu} = \frac{1}{2}g^{\lambda\rho}(\partial_\mu g_{\nu\rho} + \partial_\nu g_{\mu\rho} - \partial_\rho g_{\mu\nu})Γμνλ​=21​gλρ(∂μ​gνρ​+∂ν​gμρ​−∂ρ​gμν​)

关键性质：

  • 对称性：Γμνλ=Γνμλ\Gamma^\lambda_{\mu\nu} = \Gamma^\lambda_{\nu\mu}Γμνλ​=Γνμλ​（无挠率）
  • 度量相容：∇ρgμν=0\nabla_\rho g_{\mu\nu} = 0∇ρ​gμν​=0

测地线

测地线方程——自由粒子在弯曲时空中的运动方程：

d2xμdτ2+Γαβμdxαdτdxβdτ=0\frac{d^2x^\mu}{d\tau^2} + \Gamma^\mu_{\alpha\beta}\frac{dx^\alpha}{d\tau}\frac{dx^\beta}{d\tau} = 0dτ2d2xμ​+Γαβμ​dτdxα​dτdxβ​=0

其中 τ\tauτ 为固有时。在平直时空中 Γ=0\Gamma = 0Γ=0，退化为匀速直线运动。

测地线等价于作用量 S=∫dsS = \int dsS=∫ds 的极值曲线，也是平行移动自身切向量的曲线。

弱场近似：在 Newton 引力极限下（g00≈−(1+2Φ/c2)g_{00} \approx -(1 + 2\Phi/c^2)g00​≈−(1+2Φ/c2)），测地线方程给出 Newton 运动方程 r¨=−∇Φ\ddot{\mathbf{r}} = -\nabla\Phir¨=−∇Φ。

Riemann 曲率张量

定义：通过协变导数的不对易性定义：

[∇μ,∇ν]Vρ=RρσμνVσ[\nabla_\mu, \nabla_\nu]V^\rho = R^\rho{}_{\sigma\mu\nu}V^\sigma[∇μ​,∇ν​]Vρ=Rρσμν​Vσ

分量表达式：

Rρσμν=∂μΓνσρ−∂νΓμσρ+ΓμλρΓνσλ−ΓνλρΓμσλR^\rho{}_{\sigma\mu\nu} = \partial_\mu\Gamma^\rho_{\nu\sigma} - \partial_\nu\Gamma^\rho_{\mu\sigma} + \Gamma^\rho_{\mu\lambda}\Gamma^\lambda_{\nu\sigma} - \Gamma^\rho_{\nu\lambda}\Gamma^\lambda_{\mu\sigma}Rρσμν​=∂μ​Γνσρ​−∂ν​Γμσρ​+Γμλρ​Γνσλ​−Γνλρ​Γμσλ​

收缩：

  • Ricci 张量：Rμν=RλμλνR_{\mu\nu} = R^\lambda{}_{\mu\lambda\nu}Rμν​=Rλμλν​
  • 标量曲率：R=gμνRμνR = g^{\mu\nu}R_{\mu\nu}R=gμνRμν​
  • Einstein 张量：Gμν=Rμν−12gμνRG_{\mu\nu} = R_{\mu\nu} - \frac{1}{2}g_{\mu\nu}RGμν​=Rμν​−21​gμν​R（满足 ∇μGμν=0\nabla_\mu G^{\mu\nu} = 0∇μ​Gμν=0——Bianchi 恒等式）

Riemann 张量的对称性：RρσμνR_{\rho\sigma\mu\nu}Rρσμν​ 在 nnn 维空间中有 n2(n2−1)12\frac{n^2(n^2-1)}{12}12n2(n2−1)​ 个独立分量。n=4n = 4n=4 时有 20 个。

物理直觉：潮汐力与曲率

Riemann 张量的物理意义是潮汐力。两个邻近测地线的分离向量 ξμ\xi^\muξμ 满足测地偏差方程：

D2ξμdτ2=Rμναβuνuαξβ\frac{D^2\xi^\mu}{d\tau^2} = R^\mu{}_{\nu\alpha\beta}u^\nu u^\alpha \xi^\betadτ2D2ξμ​=Rμναβ​uνuαξβ

其中 uμu^\muuμ 为测地线切向量。正曲率使邻近测地线会聚（如地球表面的经线），负曲率使其发散。

Schwarzschild 度量预览

Schwarzschild 解：球对称、静态真空时空的度量：

ds2=−(1−2GMc2r)c2dt2+(1−2GMc2r)−1dr2+r2dΩ2ds^2 = -\left(1 - \frac{2GM}{c^2r}\right)c^2dt^2 + \left(1 - \frac{2GM}{c^2r}\right)^{-1}dr^2 + r^2d\Omega^2ds2=−(1−c2r2GM​)c2dt2+(1−c2r2GM​)−1dr2+r2dΩ2

rs=2GM/c2r_s = 2GM/c^2rs​=2GM/c2 为 Schwarzschild 半径（黑洞视界）。

练习与思考

  1. 计算二维球面 ds2=R2(dθ2+sin⁡2θ dφ2)ds^2 = R^2(d\theta^2 + \sin^2\theta \, d\varphi^2)ds2=R2(dθ2+sin2θdφ2) 的 Christoffel 符号和标量曲率（结果应为 Rscalar=2/R2R_{\text{scalar}} = 2/R^2Rscalar​=2/R2）。

  2. 证明 Christoffel 符号不是张量（即验证它在坐标变换下有非齐次项）。

  3. 对 Schwarzschild 度量，推导径向测地线方程并与 Newton 引力比较。

  4. 验证 Einstein 张量满足 ∇μGμν=0\nabla_\mu G^{\mu\nu} = 0∇μ​Gμν=0（Bianchi 恒等式的推论）。

  5. 计算 de Sitter 时空 ds2=−dt2+e2Ht(dx2+dy2+dz2)ds^2 = -dt^2 + e^{2Ht}(dx^2 + dy^2 + dz^2)ds2=−dt2+e2Ht(dx2+dy2+dz2) 的 Ricci 张量。

拓展阅读

  • Carroll《Spacetime and Geometry》是广义相对论最受欢迎的现代教材，微分几何部分极其清晰。
  • Schutz《A First Course in General Relativity》适合从物理直觉出发学习微分几何。
  • Wald《General Relativity》以数学严谨著称，适合追求理论深度的学习者。
  • do Carmo《Riemannian Geometry》给出了 Riemann 几何的纯数学处理。

小结

物理中的微分几何为广义相对论提供了完整的数学语言。度量张量 gμνg_{\mu\nu}gμν​ 定义了时空的几何结构，Christoffel 联络实现了弯曲时空中的平行移动和协变微分，Riemann 曲率张量量化了时空的弯曲程度。测地线方程描述了自由粒子在弯曲时空中的运动，而测地偏差方程则将曲率与潮汐力直接联系。Einstein 张量 GμνG_{\mu\nu}Gμν​ 作为曲率的特殊组合，其散度自动为零（Bianchi 恒等式），这为 Einstein 场方程的建立提供了数学保证。
