研究生 理论物理 — 系综理论

知识要点

系综理论是平衡态统计力学的数学框架，由 Gibbs 在19世纪末系统建立。它的核心思想是：用大量相同系统的虚拟集合（系综）来代替对单个系统的长时间观测，从而将热力学量与微观态的统计性质联系起来。微正则系综、正则系综和巨正则系综分别适用于孤立系统、恒温系统和开放系统，它们通过配分函数将微观动力学与宏观热力学桥接在一起。

核心概念：

  • 相空间：NNN 粒子系统的 6N6N6N 维空间 Γ={(q1,…,qN,p1,…,pN)}\Gamma = \{(\mathbf{q}_1, \ldots, \mathbf{q}_N, \mathbf{p}_1, \ldots, \mathbf{p}_N)\}Γ={(q1​,…,qN​,p1​,…,pN​)}
  • Liouville 定理：相空间中概率密度沿轨迹守恒 dρdt=0\frac{d\rho}{dt} = 0dtdρ​=0
  • 微正则系综：固定 (E,V,N)(E, V, N)(E,V,N)，ρ∝δ(H−E)\rho \propto \delta(H - E)ρ∝δ(H−E)
  • 正则系综：固定 (T,V,N)(T, V, N)(T,V,N)，ρ∝e−βH\rho \propto e^{-\beta H}ρ∝e−βH，β=1/(kBT)\beta = 1/(k_BT)β=1/(kB​T)
  • 巨正则系综：固定 (T,V,μ)(T, V, \mu)(T,V,μ)，ρ∝e−β(H−μN)\rho \propto e^{-\beta(H - \mu N)}ρ∝e−β(H−μN)

详细讲解

经典统计力学的基础

相空间与 Liouville 定理：NNN 个粒子的经典系统由 Hamilton 方程描述。系综中的概率密度 ρ(q,p,t)\rho(\mathbf{q}, \mathbf{p}, t)ρ(q,p,t) 满足 Liouville 方程：

∂ρ∂t+{H,ρ}=0\frac{\partial \rho}{\partial t} + \{H, \rho\} = 0∂t∂ρ​+{H,ρ}=0

其中 {H,ρ}=∑i(∂H∂qi∂ρ∂pi−∂H∂pi∂ρ∂qi)\{H, \rho\} = \sum_i \left(\frac{\partial H}{\partial q_i}\frac{\partial \rho}{\partial p_i} - \frac{\partial H}{\partial p_i}\frac{\partial \rho}{\partial q_i}\right){H,ρ}=∑i​(∂qi​∂H​∂pi​∂ρ​−∂pi​∂H​∂qi​∂ρ​) 为 Poisson 括号。

平衡态下 ∂ρ∂t=0\frac{\partial \rho}{\partial t} = 0∂t∂ρ​=0，因此 ρ\rhoρ 必须是运动常数（守恒量）的函数。

微正则系综

适用条件：孤立系统，能量 EEE、体积 VVV、粒子数 NNN 固定。

等概率假设：所有满足 H=EH = EH=E 的微观态等概率出现。

ρ(q,p)=δ(H(q,p)−E)Ω(E,V,N)\rho(\mathbf{q}, \mathbf{p}) = \frac{\delta(H(\mathbf{q}, \mathbf{p}) - E)}{\Omega(E, V, N)}ρ(q,p)=Ω(E,V,N)δ(H(q,p)−E)​

态密度：Ω(E)=1N!h3N∫δ(H−E) dΓ\Omega(E) = \frac{1}{N!h^{3N}}\int \delta(H - E) \, d\GammaΩ(E)=N!h3N1​∫δ(H−E)dΓ（1/N!1/N!1/N! 考虑全同粒子，h3Nh^{3N}h3N 为量子修正）。

与热力学的联系（Boltzmann 关系）：

S(E,V,N)=kBln⁡Ω(E,V,N)S(E, V, N) = k_B \ln \Omega(E, V, N)S(E,V,N)=kB​lnΩ(E,V,N)

温度定义为 1T=∂S∂E∣V,N\frac{1}{T} = \frac{\partial S}{\partial E}\bigg|_{V,N}T1​=∂E∂S​​V,N​。

正则系综

适用条件：系统与温度为 TTT 的热库接触。

概率分布（Boltzmann 分布）：

Pi=e−βEiZP_i = \frac{e^{-\beta E_i}}{Z}Pi​=Ze−βEi​​

正则配分函数：

Z(T,V,N)=∑ie−βEi=1N!h3N∫e−βHdΓZ(T, V, N) = \sum_i e^{-\beta E_i} = \frac{1}{N!h^{3N}}\int e^{-\beta H} d\GammaZ(T,V,N)=i∑​e−βEi​=N!h3N1​∫e−βHdΓ

热力学势——Helmholtz 自由能：

F=−kBTln⁡ZF = -k_BT \ln ZF=−kB​TlnZ

所有热力学量可由 FFF 导出：

热力学量 公式
内能 U=−∂ln⁡Z∂βU = -\frac{\partial \ln Z}{\partial \beta}U=−∂β∂lnZ​
熵 S=−∂F∂T=kB(ln⁡Z+βU)S = -\frac{\partial F}{\partial T} = k_B(\ln Z + \beta U)S=−∂T∂F​=kB​(lnZ+βU)
压力 P=−∂F∂VP = -\frac{\partial F}{\partial V}P=−∂V∂F​
比热 CV=−kBβ2∂2ln⁡Z∂β2C_V = -k_B \beta^2 \frac{\partial^2 \ln Z}{\partial \beta^2}CV​=−kB​β2∂β2∂2lnZ​

涨落：能量涨落 ⟨(ΔE)2⟩=kBT2CV\langle(\Delta E)^2\rangle = k_BT^2 C_V⟨(ΔE)2⟩=kB​T2CV​。对宏观系统 ΔEU∼1N→0\frac{\Delta E}{U} \sim \frac{1}{\sqrt{N}} \to 0UΔE​∼N​1​→0，说明正则系综与微正则系综在热力学极限下等价。

巨正则系综

适用条件：系统与热库和粒子库接触，温度 TTT 和化学势 μ\muμ 固定。

巨配分函数：

Ξ(T,V,μ)=∑N=0∞eβμNZ(T,V,N)=∑N=0∞∑ie−β(Ei(N)−μN)\Xi(T, V, \mu) = \sum_{N=0}^{\infty} e^{\beta\mu N} Z(T, V, N) = \sum_{N=0}^{\infty} \sum_i e^{-\beta(E_i^{(N)} - \mu N)}Ξ(T,V,μ)=N=0∑∞​eβμNZ(T,V,N)=N=0∑∞​i∑​e−β(Ei(N)​−μN)

热力学势——巨势：

Φ=−kBTln⁡Ξ=F−μN=−PV\Phi = -k_BT \ln \Xi = F - \mu N = -PVΦ=−kB​TlnΞ=F−μN=−PV

平均粒子数：⟨N⟩=kBT∂ln⁡Ξ∂μ\langle N \rangle = k_BT \frac{\partial \ln \Xi}{\partial \mu}⟨N⟩=kB​T∂μ∂lnΞ​

巨正则系综对于处理量子统计（Bose-Einstein 和 Fermi-Dirac 分布）特别方便。

量子统计分布

Fermi-Dirac 分布（费米子，如电子）：

⟨nϵ⟩=1eβ(ϵ−μ)+1\langle n_\epsilon \rangle = \frac{1}{e^{\beta(\epsilon - \mu)} + 1}⟨nϵ​⟩=eβ(ϵ−μ)+11​

Bose-Einstein 分布（玻色子，如光子）：

⟨nϵ⟩=1eβ(ϵ−μ)−1\langle n_\epsilon \rangle = \frac{1}{e^{\beta(\epsilon - \mu)} - 1}⟨nϵ​⟩=eβ(ϵ−μ)−11​

经典极限（eβ(ϵ−μ)≫1e^{\beta(\epsilon - \mu)} \gg 1eβ(ϵ−μ)≫1）两者都退化为 Maxwell-Boltzmann 分布：

⟨nϵ⟩≈e−β(ϵ−μ)\langle n_\epsilon \rangle \approx e^{-\beta(\epsilon - \mu)}⟨nϵ​⟩≈e−β(ϵ−μ)

理想气体的配分函数

经典理想气体的正则配分函数：

Z=1N!(Vλ3)NZ = \frac{1}{N!}\left(\frac{V}{\lambda^3}\right)^NZ=N!1​(λ3V​)N

其中热 de Broglie 波长 λ=2πℏ2mkBT\lambda = \sqrt{\frac{2\pi\hbar^2}{mk_BT}}λ=mkB​T2πℏ2​​。

由此导出：

  • F=−NkBT[ln⁡(VNλ3)+1]F = -Nk_BT\left[\ln\left(\frac{V}{N\lambda^3}\right) + 1\right]F=−NkB​T[ln(Nλ3V​)+1]（Sackur-Tetrode 公式）
  • PV=NkBTPV = Nk_BTPV=NkB​T（理想气体状态方程）
  • U=32NkBTU = \frac{3}{2}Nk_BTU=23​NkB​T（能量均分定理）

练习与思考

  1. 从微正则系综出发，推导理想气体的状态方程和 Sackur-Tetrode 熵公式。

  2. 证明正则系综中能量涨落 ⟨(ΔE)2⟩=kBT2CV\langle(\Delta E)^2\rangle = k_BT^2 C_V⟨(ΔE)2⟩=kB​T2CV​。

  3. 对二能级系统（E=0E = 0E=0 或 E=εE = \varepsilonE=ε），计算正则配分函数、内能、熵和比热（Schottky 异常）。

  4. 利用巨正则系综推导 Fermi-Dirac 分布。

  5. 证明在热力学极限下（N,V→∞N, V \to \inftyN,V→∞，N/VN/VN/V 固定），三种系综给出相同的热力学结果。

拓展阅读

  • Pathria & Beale《Statistical Mechanics》是统计力学的标准研究生教材，对系综理论有详尽论述。
  • Huang《Statistical Mechanics》以物理直觉为导向，适合建立对统计力学的整体认知。
  • Landau & Lifshitz《Statistical Physics, Part 1》以优雅的风格覆盖了平衡态统计力学的核心内容。
  • 系综理论在现代应用中的发展包括：分子模拟中的 Monte Carlo 方法和分子动力学方法。

小结

系综理论将热力学量与微观态的统计性质通过配分函数联系起来。微正则、正则和巨正则三种系综分别适用于不同的实验条件，在热力学极限下给出等价结果。配分函数是整个理论的核心——一旦计算出配分函数，所有热力学量都可以通过微分得到。量子统计（Fermi-Dirac 和 Bose-Einstein）是系综理论的自然推广，为理解金属电子、超流、Bose-Einstein 凝聚等量子多体现象提供了基本框架。
