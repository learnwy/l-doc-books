08 理学 (Natural Sciences)理论物理 简介

理论物理 简介

本 hub 是研究生水平的理论物理课程，覆盖该学科的四大支柱：量子力学进阶、统计力学、场论基础与广义相对论。它的视角是物理理论本身——每个理论从公理或原理出发，经过严格推演得到可观测的预言（散射截面、临界指数、黑洞熵、引力波波形），并交代这些预言如何被实验检验。数学工具在这里是手段而非目的：本 hub 在用到时给出物理导向的最小介绍，不系统展开定义、定理与证明。

四章的分工：第一章量子力学进阶（Hilbert 空间形式体系、微扰理论、散射理论）建立全 hub 的语言与近似方法；第二章统计力学（系综理论、相变理论、非平衡统计力学）处理从微观到宏观的涌现，其重整化群思想与第三章互相印证；第三章场论基础（经典场论、量子场论导引、规范场论）给出基本相互作用的理论语言；第四章广义相对论（物理中的微分几何、Einstein 场方程、黑洞与宇宙学）展示引力的几何化，与其他章节耦合最弱、可独立阅读。

本 hub 与兄弟 hub 的分工

同属 08_natural-sciences 的三个研究生 hub 边界如下：

Hub 关注点 与本 hub 的边界
高等数学（研究生） 数学结构本身：泛函分析、抽象代数、拓扑与流形、PDE 与数值方法的定义、定理与证明 本 hub 使用这些工具建模物理世界，关心物理图像、方程的解与实验对应；数学定理的严格证明不在本 hub 展开
理论物理（本 hub） 四大物理理论的公理化框架、推演链条与实验检验 ——
分子生物学（研究生） 生命过程的分子机制（中心法则、基因调控、信号转导） 与本 hub 几乎不重叠；仅在生物物理方向（统计力学应用于分子折叠与输运）间接衔接

边界判断的一个例子：「谱定理为什么成立、自伴算子的谱分解如何证明」去高等数学 hub 的泛函分析；「谱定理为什么恰好刻画了量子测量」留在本 hub。

推荐学习路径

主线（物理专业研究生，按顺序）：

  1. 量子力学进阶：Hilbert 空间形式体系 → 微扰理论 → 散射理论——先掌握语言（态、算符、密度矩阵）与近似方法（微扰、变分、WKB）
  2. 统计力学：系综理论 → 相变理论 → 非平衡统计力学——配分函数与系综方法是场论路径积分的先导直觉，重整化群在相变中最先成熟
  3. 场论基础：经典场论 → 量子场论导引 → 规范场论——需要第 1 章的形式体系与第 2 章的统计直觉
  4. 广义相对论：物理中的微分几何 → Einstein 场方程 → 黑洞与宇宙学——自带数学工具，与前三章耦合最弱，可最后学或与第 3 章并行

凝聚态 / 材料方向：第 1、2 章全部精读；第 3 章读经典场论与量子场论导引（重整化一节必读），规范场论选读；第 4 章可跳过。

粒子 / 高能方向：第 1 章全部 → 第 3 章全部（规范场论与标准模型是核心）→ 第 4 章前两篇（微分几何、场方程），黑洞与宇宙学选读；第 2 章读系综理论与相变理论（重整化群）即可。

数学背景转行者：先补物理图像（本科量子力学与热力学速览），再按主线走；本 hub 各篇「知识要点」前的动机段可快速浏览，把时间花在推演与练习上。

前置知识

  • 本科量子力学：波动力学、谐振子、角动量与自旋、全同粒子——第 1 章直接在其上公理化
  • 本科热力学与统计物理入门：热力学定律、Maxwell-Boltzmann 分布——第 2 章的出发点
  • 数学工具：线性代数（本征分解、张量积）、多元微积分与常微分方程、复变函数（留数定理用于传播子与 Green 函数计算）
  • 有帮助但非必需：分析力学（Lagrange/Hamilton 形式，第 3 章变分原理的基础）、概率论（第 2 章系综与随机过程）
  • 不要求：测度论、泛函分析、微分几何、群表示论——本 hub 在用到时给出物理导向的最小介绍；追求严格性见下方延伸阅读

延伸阅读

以下兄弟 hub 条目可作为数学严格化方向的补充（按需选读，非本 hub 前置依赖）：

  • 泛函分析导引：Hilbert 空间与算子理论的数学严格版本，对应第一章的形式体系
  • 流形：微分流形的严格定义，对应第四章的微分几何工具
  • 群论：群与表示的代数语言，对应第三章的规范对称性
  • 偏微分方程方法：波动方程与场方程的求解技术，贯穿第三、四章
