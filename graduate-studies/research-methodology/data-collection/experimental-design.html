研究生 研究方法论 — 实验设计

知识要点

实验设计（Experimental Design）是建立因果关系最有力的研究方法。它通过操纵自变量、控制无关变量、随机分配被试，来检验自变量对因变量的因果效应。当你的研究问题是"X是否导致Y"时，实验是最直接的回答方式。

实验设计的核心逻辑是Mill的差异法：如果其他条件完全相同，只有自变量不同，那么因变量的差异就可以归因于自变量。这个逻辑看似简单，但在实际操作中，"控制其他条件完全相同"是极其困难的——这就是为什么实验设计需要如此多的方法论技巧。

详细讲解

实验的三大要素

要素 含义 说明
操纵（Manipulation） 研究者主动改变自变量的水平 区别于观察性研究
控制（Control） 消除或减少无关变量的影响 通过随机化、匹配、统计控制实现
随机化（Randomization） 将被试随机分配到不同条件 保证组间基线均衡

经典实验设计类型

前实验设计（缺乏随机分配或对照组）：

设计 符号表示 局限
单组后测 X O 无法排除任何替代解释
单组前后测 O X O 无法排除成熟效应和历史效应
静态组比较 X O / O 无法排除选择偏差

真实验设计（有随机分配和对照组）：

设计 符号表示 优势
前后测控制组设计 R O X O / R O O 控制大多数内部效度威胁
仅后测控制组设计 R X O / R O 避免前测效应
所罗门四组设计 R O X O / R O O / R X O / R O 同时检验前测和处理效应

其中 R=随机分配，X=实验处理，O=观测。

准实验设计（有对照但无法随机分配）：

当随机分配在实际操作中不可行时（如教育场景中无法随机分配学生到不同班级），准实验设计是务实的替代方案。

设计 特征 典型应用
非等组前后测 利用已有自然分组 不同班级使用不同教学法
断点回归 以某个阈值作为"自然"分组标准 奖学金获得者 vs. 未获得者
差分-差分（DID） 比较处理组和对照组的前后变化之差 政策效果评估

内部效度的威胁与应对

内部效度是实验研究最关注的质量指标——它衡量你是否能自信地说"X导致了Y"。

威胁 含义 应对策略
历史效应 实验期间外部事件的影响 同时设置对照组
成熟效应 被试自然发展变化 设置对照组、缩短实验周期
测验效应 前测本身影响后测 仅后测设计、使用平行版本
统计回归 极端分数向均值回归 随机分配、避免基于极端值选样
选择偏差 实验组和对照组不可比 随机分配、倾向得分匹配
流失偏差 不同条件的被试流失率不同 意向性治疗分析（ITT）
扩散效应 对照组获知并模仿实验处理 物理隔离实验组和对照组

外部效度与生态效度

外部效度关注实验结果能否推广到其他人群、情境和时间。实验室实验的内部效度高，但外部效度往往受限；现场实验反之。

生态效度（Ecological Validity）是外部效度的一个特殊维度，关注实验情境是否与现实生活情境相似。例如，在安静的实验室中测试的决策行为，能否推广到嘈杂、有时间压力的真实工作环境？

效应量与统计功效
除了统计显著性（ppp值），还需要关注效应量（Effect Size）和统计功效（Statistical Power）。


效应量衡量实验效应的实际大小：


    

  • Cohen's ddd（两组均值差异）：小效应 d=0.2d = 0.2d=0.2，中效应 d=0.5d = 0.5d=0.5，大效应 d=0.8d = 0.8d=0.8
    • 

  • η2\eta^2η2（方差分析中的效应量）：小效应 0.010.010.01，中效应 0.060.060.06，大效应 0.140.140.14
    • 



统计功效（1−β1 - \beta1−β）是检测到真实效应的概率。惯例要求 ≥0.80\geq 0.80≥0.80。


样本量与功效的关系：效应量越小，需要的样本量越大。使用G*Power等软件可以在实验前进行功效分析（a priori power analysis），确定所需的最小样本量。


在线实验与新兴范式
随着技术发展，研究生越来越多地使用在线平台（如MTurk、Prolific、Credamo）进行实验。在线实验的优势是招募快、成本低、样本多样，但需要注意：


    

  • 注意力检测题（attention check）是必须的
    • 

  • 被试可能在无监督环境中分心
    • 

  • 不同设备和屏幕可能影响刺激呈现
    •

  1. 设计判断练习：以下研究各属于什么类型的实验设计？它们的内部效度如何？
    

      

    • 研究A：随机将60名学生分为两组，一组使用新教学法，另一组使用传统教学法，学期末比较考试成绩
      • 

    • 研究B：比较某公司实施弹性工作制前后的员工满意度
      • 

    • 研究C：比较自愿参加培训的员工和未参加的员工的绩效差异

小结
实验设计通过操纵自变量、控制无关变量和随机化来建立因果关系。真实验设计（有随机分配和对照组）的内部效度最高，准实验设计是无法随机分配时的务实替代。设计实验时需要系统评估内部效度威胁并采取应对策略，同时关注效应量和统计功效以确保研究有足够的检测力。在选择实验类型时，需要在内部效度和外部效度之间做出权衡——没有完美的设计，只有最适合你研究问题的设计。
