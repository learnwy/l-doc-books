研究生 高级计量经济学 — ARIMA 模型

知识要点

自回归移动平均积分模型（ARIMA）是分析和预测单变量时间序列的主力工具。Box-Jenkins 方法论提供了从识别、估计到诊断的完整建模流程，其核心思想是通过差分将非平稳序列转化为平稳序列，再用 ARMA 模型刻画其动态结构。理解平稳性、自相关函数（ACF）和偏自相关函数（PACF）的形态特征是正确识别模型阶数的关键。

ARIMA 建模的核心概念：

  • 平稳性：弱平稳要求均值、方差不随时间变化，自协方差仅依赖滞后阶数
  • ARMA 模型：ARMA(p,q)\text{ARMA}(p,q)ARMA(p,q) 结合自回归和移动平均两种机制
  • 差分算子：ddd 阶差分 Δdyt\Delta^d y_tΔdyt​ 将 I(d)I(d)I(d) 过程转化为 I(0)I(0)I(0)
  • ACF/PACF 识别：AR 模型 PACF 截尾、MA 模型 ACF 截尾
  • 信息准则：AIC/BIC 用于模型选择，平衡拟合优度与模型复杂度

详细讲解

平稳性的形式定义

一个时间序列 {yt}\{y_t\}{yt​} 是（弱/协方差）平稳的，如果满足：

  1. E(yt)=μE(y_t) = \muE(yt​)=μ，对所有 ttt 相同
  2. Var(yt)=σ2<∞\text{Var}(y_t) = \sigma^2 < \inftyVar(yt​)=σ2<∞，对所有 ttt 相同
  3. Cov(yt,yt−k)=γk\text{Cov}(y_t, y_{t-k}) = \gamma_kCov(yt​,yt−k​)=γk​，仅依赖滞后 kkk 而不依赖 ttt

非平稳序列不满足上述条件。最常见的非平稳类型：

  • 单位根过程：yt=yt−1+uty_t = y_{t-1} + u_tyt​=yt−1​+ut​（随机游走），方差随 ttt 增长
  • 确定性趋势：yt=α+δt+uty_t = \alpha + \delta t + u_tyt​=α+δt+ut​，均值随时间线性增长
  • 结构突变：参数在某时点发生跳变

单位根检验（ADF 检验、PP 检验、KPSS 检验）用于判断序列是否需要差分。ADF 检验的回归方程：

Δyt=α+βt+γyt−1+∑j=1pδjΔyt−j+ϵt\Delta y_t = \alpha + \beta t + \gamma y_{t-1} + \sum_{j=1}^{p}\delta_j \Delta y_{t-j} + \epsilon_tΔyt​=α+βt+γyt−1​+j=1∑p​δj​Δyt−j​+ϵt​

原假设 H0:γ=0H_0: \gamma = 0H0​:γ=0（存在单位根）。注意 ADF 统计量不服从标准 ttt 分布，需使用 Dickey-Fuller 临界值。

ARMA 模型的结构

AR(p) 模型：

yt=c+ϕ1yt−1+ϕ2yt−2+⋯+ϕpyt−p+ϵty_t = c + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \cdots + \phi_p y_{t-p} + \epsilon_tyt​=c+ϕ1​yt−1​+ϕ2​yt−2​+⋯+ϕp​yt−p​+ϵt​

用滞后算子 LLL 表示：ϕ(L)yt=c+ϵt\phi(L)y_t = c + \epsilon_tϕ(L)yt​=c+ϵt​，其中 ϕ(L)=1−ϕ1L−⋯−ϕpLp\phi(L) = 1 - \phi_1 L - \cdots - \phi_p L^pϕ(L)=1−ϕ1​L−⋯−ϕp​Lp。平稳条件：ϕ(z)=0\phi(z) = 0ϕ(z)=0 的所有根在单位圆外。

MA(q) 模型：

yt=μ+ϵt+θ1ϵt−1+⋯+θqϵt−qy_t = \mu + \epsilon_t + \theta_1 \epsilon_{t-1} + \cdots + \theta_q \epsilon_{t-q}yt​=μ+ϵt​+θ1​ϵt−1​+⋯+θq​ϵt−q​

ARMA(p,q) 模型：

ϕ(L)yt=c+θ(L)ϵt\phi(L)y_t = c + \theta(L)\epsilon_tϕ(L)yt​=c+θ(L)ϵt​

结合两种机制，通常能用较少的参数刻画复杂的动态结构。

ACF 和 PACF 的识别模式

Box-Jenkins 方法论

Box-Jenkins 建模流程分为四步：

第一步：识别（Identification）

  1. 绘制时间序列图，观察趋势和季节性
  2. 进行单位根检验，确定差分阶数 ddd
  3. 对差分后序列计算 ACF 和 PACF
  4. 根据截尾/拖尾模式初步确定 ppp 和 qqq

第二步：估计（Estimation）

使用条件最大似然或精确最大似然估计参数。对 ARMA(p,q)\text{ARMA}(p,q)ARMA(p,q)，似然函数在高斯假设下为：

ℓ(ϕ,θ,σ2)=−T2ln⁡(2π)−12ln⁡∣Σ∣−12(y−μ1)′Σ−1(y−μ1)\ell(\phi, \theta, \sigma^2) = -\frac{T}{2}\ln(2\pi) - \frac{1}{2}\ln|\Sigma| - \frac{1}{2}(y - \mu\mathbf{1})'\Sigma^{-1}(y - \mu\mathbf{1})ℓ(ϕ,θ,σ2)=−2T​ln(2π)−21​ln∣Σ∣−21​(y−μ1)′Σ−1(y−μ1)

第三步：诊断（Diagnostic Checking）

  • 残差是否为白噪声：Ljung-Box Q 统计量 Q(m)=T(T+2)∑k=1mρ^k2T−k∼χ2(m−p−q)Q(m) = T(T+2)\sum_{k=1}^{m}\frac{\hat{\rho}_k^2}{T-k} \sim \chi^2(m-p-q)Q(m)=T(T+2)∑k=1m​T−kρ^​k2​​∼χ2(m−p−q)
  • 残差 ACF 是否都在置信带内
  • 残差正态性：QQ 图、Jarque-Bera 检验

第四步：预测（Forecasting）

ARIMA 模型的 hhh 步ahead预测使用条件期望：

y^T+h∣T=E(yT+h∣yT,yT−1,…)\hat{y}_{T+h|T} = E(y_{T+h} | y_T, y_{T-1}, \ldots)y^​T+h∣T​=E(yT+h​∣yT​,yT−1​,…)

预测区间随 hhh 增大而加宽，长期预测趋向无条件均值。

信息准则与模型选择

AIC=−2ℓ+2k,BIC=−2ℓ+kln⁡(T)\text{AIC} = -2\ell + 2k, \quad \text{BIC} = -2\ell + k\ln(T)AIC=−2ℓ+2k,BIC=−2ℓ+kln(T)

其中 ℓ\ellℓ 是对数似然值，kkk 是参数个数。BIC 施加更重的复杂度惩罚，倾向选择更简约的模型。在实践中，通常对一组候选模型（p,q≤pmax,qmaxp, q \leq p_{max}, q_{max}p,q≤pmax​,qmax​）计算信息准则，选择最小值对应的模型。

练习与思考

  1. 平稳性判断：对于 AR(1) 模型 yt=0.5+0.8yt−1+ϵty_t = 0.5 + 0.8y_{t-1} + \epsilon_tyt​=0.5+0.8yt−1​+ϵt​，验证其平稳性。计算无条件均值 E(yt)E(y_t)E(yt​) 和方差 Var(yt)\text{Var}(y_t)Var(yt​)，并推导自相关函数 ρk\rho_kρk​。

  2. 模型识别：某平稳序列的样本 ACF 在滞后 1 和 2 显著不为零，从滞后 3 开始截尾；PACF 呈现指数衰减。该序列最可能遵循什么模型？

  3. ADF 检验实操：给定 ADF 回归的 ttt 统计量为 −2.15-2.15−2.15，样本量 T=200T = 200T=200，包含截距项。查 ADF 临界值表判断在 5% 水平下能否拒绝单位根原假设。

  4. 预测比较：使用某宏观经济时间序列，分别拟合 ARIMA(1,1,0)、ARIMA(0,1,1) 和 ARIMA(1,1,1)，用 AIC/BIC 选择最优模型，并比较 1 步和 4 步预测的精度。

  5. 季节建模：月度零售销售数据显示明显的 12 月高峰。描述如何通过 ACF/PACF 识别季节阶数，以及为什么可能需要季节差分 Δ12\Delta_{12}Δ12​ 而非仅用季节虚拟变量。

拓展阅读

  • 经典教材：Hamilton《Time Series Analysis》第 3-5 章是时间序列分析的标准参考。Enders《Applied Econometric Time Series》更加面向应用。Box, Jenkins & Reinsel《Time Series Analysis: Forecasting and Control》是 ARIMA 方法的原始经典。
  • 现代预测方法：Hyndman & Athanasopoulos《Forecasting: Principles and Practice》（免费在线版）以 R 语言为工具全面覆盖预测方法，包括 ETS 和 ARIMA 的自动选择（auto.arima）。
  • 单位根检验的进展：Elliott, Rothenberg & Stock (1996) 的 DF-GLS 检验比标准 ADF 有更高检验功效。Müller & Elliott (2003) 的高效单位根检验进一步优化了功效包络。
  • 结构突变与单位根：Perron (1989) 证明忽略结构突变会导致错误地不拒绝单位根原假设。Zivot & Andrews (1992) 提出了内生确定断点的检验。

小结

ARIMA 模型通过差分、自回归和移动平均三种机制的组合，提供了对单变量时间序列建模和预测的系统方法。Box-Jenkins 方法论的四步流程（识别、估计、诊断、预测）至今仍是时间序列分析的基本框架。正确使用 ACF/PACF 识别模型阶数、通过信息准则辅助模型选择、以及严格的残差诊断检验是保证模型质量的关键步骤。在实际应用中，ARIMA 常作为基准模型，与更复杂的方法（如向量自回归、机器学习方法）进行预测精度比较。
