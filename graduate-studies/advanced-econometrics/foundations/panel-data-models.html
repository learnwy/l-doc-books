研究生 高级计量经济学 — 面板数据模型

知识要点

面板数据（Panel Data）同时包含截面维度和时间维度的信息，相比纯截面或纯时间序列数据具有显著优势：能够控制不可观测的个体异质性、提供更大的样本变异和自由度、并允许研究动态调整过程。固定效应模型（FE）和随机效应模型（RE）是处理面板数据的两大基本框架，选择哪种模型取决于个体效应与解释变量之间是否相关。

面板数据建模的核心框架：

  • 混合 OLS：忽略面板结构，将所有观测视为独立截面，yit=xit′β+uity_{it} = x_{it}'\beta + u_{it}yit​=xit′​β+uit​
  • 固定效应模型：yit=xit′β+αi+ϵity_{it} = x_{it}'\beta + \alpha_i + \epsilon_{it}yit​=xit′​β+αi​+ϵit​，允许 Cov(αi,xit)≠0\text{Cov}(\alpha_i, x_{it}) \neq 0Cov(αi​,xit​)=0
  • 随机效应模型：yit=xit′β+αi+ϵity_{it} = x_{it}'\beta + \alpha_i + \epsilon_{it}yit​=xit′​β+αi​+ϵit​，要求 Cov(αi,xit)=0\text{Cov}(\alpha_i, x_{it}) = 0Cov(αi​,xit​)=0
  • Hausman 检验：比较 FE 与 RE 估计量以选择合适的模型
  • 组内估计与一阶差分：消除固定效应的两种变换策略

详细讲解

面板数据的结构与符号

面板数据的基本结构为 {(yit,xit):i=1,…,N;t=1,…,T}\{(y_{it}, x_{it}): i = 1, \ldots, N; t = 1, \ldots, T\}{(yit​,xit​):i=1,…,N;t=1,…,T}，其中 iii 索引个体（如企业、国家、个人），ttt 索引时间。一般性的面板模型可写为：

yit=xit′β+ci+uity_{it} = x_{it}'\beta + c_i + u_{it}yit​=xit′​β+ci​+uit​

其中 cic_ici​ 是不随时间变化的个体效应（unobserved heterogeneity），uitu_{it}uit​ 是特异性误差项（idiosyncratic error）。

面板数据的类型对估计方法有重要影响：

  • 短面板（NNN 大，TTT 小）：大多数微观面板属于此类，渐近理论基于 N→∞N \to \inftyN→∞
  • 长面板（NNN 小，TTT 大）：宏观面板（如国家面板），需要关注时间序列性质
  • 平衡面板 vs 非平衡面板：后者存在缺失观测，需考虑缺失机制

固定效应模型（FE）

固定效应模型将 cic_ici​ 视为需要估计的参数（或需要消除的"麻烦参数"），允许其与 xitx_{it}xit​ 任意相关。

组内估计量（Within Estimator）：对每个变量减去个体均值：

y¨it=x¨it′β+u¨it\ddot{y}_{it} = \ddot{x}_{it}'\beta + \ddot{u}_{it}y¨​it​=x¨it′​β+u¨it​

其中 y¨it=yit−yˉi\ddot{y}_{it} = y_{it} - \bar{y}_iy¨​it​=yit​−yˉ​i​，yˉi=T−1∑t=1Tyit\bar{y}_i = T^{-1}\sum_{t=1}^{T}y_{it}yˉ​i​=T−1∑t=1T​yit​。OLS 估计 y¨\ddot{y}y¨​ 对 x¨\ddot{x}x¨ 的回归得到 FE 估计量：

β^FE=(∑i=1N∑t=1Tx¨itx¨it′)−1∑i=1N∑t=1Tx¨ity¨it\hat{\beta}_{FE} = \left(\sum_{i=1}^{N}\sum_{t=1}^{T}\ddot{x}_{it}\ddot{x}_{it}'\right)^{-1}\sum_{i=1}^{N}\sum_{t=1}^{T}\ddot{x}_{it}\ddot{y}_{it}β^​FE​=(i=1∑N​t=1∑T​x¨it​x¨it′​)−1i=1∑N​t=1∑T​x¨it​y¨​it​

最小二乘虚拟变量模型（LSDV）：等价地，可以为每个个体引入虚拟变量 did_idi​：

yit=xit′β+∑i=1Nαidi+uity_{it} = x_{it}'\beta + \sum_{i=1}^{N}\alpha_i d_i + u_{it}yit​=xit′​β+i=1∑N​αi​di​+uit​

LSDV 与组内估计产生相同的 β^\hat{\beta}β^​。

一阶差分估计量（FD）：另一种消除 cic_ici​ 的方法：

Δyit=Δxit′β+Δuit\Delta y_{it} = \Delta x_{it}'\beta + \Delta u_{it}Δyit​=Δxit′​β+Δuit​

其中 Δyit=yit−yi,t−1\Delta y_{it} = y_{it} - y_{i,t-1}Δyit​=yit​−yi,t−1​。在 T=2T = 2T=2 时，FD 和 FE 完全等价；T>2T > 2T>2 时两者不同。当 uitu_{it}uit​ 是随机游走时 FD 更有效，当 uitu_{it}uit​ 是序列不相关时 FE 更有效。

随机效应模型（RE）

随机效应模型假设 cic_ici​ 是随机变量且与 xitx_{it}xit​ 不相关。关键假设：

E(ci∣xi1,xi2,…,xiT)=E(ci)=0E(c_i | x_{i1}, x_{i2}, \ldots, x_{iT}) = E(c_i) = 0E(ci​∣xi1​,xi2​,…,xiT​)=E(ci​)=0

RE 使用准离差变换（quasi-demeaning）：

yit−θ^yˉi=(xit−θ^xˉi)′β+(1−θ^)αi+(uit−θ^uˉi)y_{it} - \hat{\theta}\bar{y}_i = (x_{it} - \hat{\theta}\bar{x}_i)'\beta + (1 - \hat{\theta})\alpha_i + (u_{it} - \hat{\theta}\bar{u}_i)yit​−θ^yˉ​i​=(xit​−θ^xˉi​)′β+(1−θ^)αi​+(uit​−θ^uˉi​)

其中 θ^=1−σu2Tσc2+σu2\hat{\theta} = 1 - \sqrt{\frac{\sigma_u^2}{T\sigma_c^2 + \sigma_u^2}}θ^=1−Tσc2​+σu2​σu2​​​。当 θ=0\theta = 0θ=0 时退化为混合 OLS，当 θ=1\theta = 1θ=1 时等价于 FE。

RE 的 GLS 估计量在假设成立时比 FE 更有效，因为它同时利用了组内（within）和组间（between）变异。RE 还能估计时间不变变量的系数，这是 FE 无法做到的。

Hausman 检验

Hausman 检验用于选择 FE 和 RE：

H=(β^FE−β^RE)′[Var^(β^FE)−Var^(β^RE)]−1(β^FE−β^RE)∼χ2(k)H = (\hat{\beta}_{FE} - \hat{\beta}_{RE})'[\widehat{\text{Var}}(\hat{\beta}_{FE}) - \widehat{\text{Var}}(\hat{\beta}_{RE})]^{-1}(\hat{\beta}_{FE} - \hat{\beta}_{RE}) \sim \chi^2(k)H=(β^​FE​−β^​RE​)′[Var(β^​FE​)−Var(β^​RE​)]−1(β^​FE​−β^​RE​)∼χ2(k)
  • 原假设 H0H_0H0​：Cov(ci,xit)=0\text{Cov}(c_i, x_{it}) = 0Cov(ci​,xit​)=0（RE 一致且有效）
  • 备择假设 H1H_1H1​：Cov(ci,xit)≠0\text{Cov}(c_i, x_{it}) \neq 0Cov(ci​,xit​)=0（只有 FE 一致）

拒绝 H0H_0H0​ → 选择 FE；不拒绝 → RE 可能更合适（更有效）。

面板数据中的高级问题

动态面板模型：当滞后被解释变量作为解释变量时（yit=ρyi,t−1+xit′β+ci+uity_{it} = \rho y_{i,t-1} + x_{it}'\beta + c_i + u_{it}yit​=ρyi,t−1​+xit′​β+ci​+uit​），FE 在小 TTT 下有 Nickell 偏误。Arellano-Bond GMM 和 Blundell-Bond System GMM 是标准解决方案。

聚类标准误：面板数据中，同一个体不同时期的误差可能相关。聚类在个体层面的标准误允许组内任意序列相关和异方差：

Var^(β^)CL=(X′X)−1(∑i=1Nu^iu^i′)(X′X)−1\widehat{\text{Var}}(\hat{\beta})_{CL} = (X'X)^{-1}\left(\sum_{i=1}^{N}\hat{u}_i \hat{u}_i'\right)(X'X)^{-1}Var(β^​)CL​=(X′X)−1(i=1∑N​u^i​u^i′​)(X′X)−1

双向固定效应：同时控制个体效应和时间效应 yit=xit′β+αi+λt+uity_{it} = x_{it}'\beta + \alpha_i + \lambda_t + u_{it}yit​=xit′​β+αi​+λt​+uit​，通过同时引入个体虚拟变量和时间虚拟变量实现。

练习与思考

  1. 模型选择：某研究用 30 个国家 20 年的数据分析贸易开放度对经济增长的影响。国家文化、地理位置等因素可能影响增长且与贸易开放相关。应选择 FE 还是 RE？为什么？

  2. 推导练习：证明当 T=2T = 2T=2 时，一阶差分估计量和组内估计量产生完全相同的 β^\hat{\beta}β^​。

  3. Hausman 检验解读：Hausman 统计量为 H=15.3H = 15.3H=15.3，自由度 k=4k = 4k=4，χ0.052(4)=9.49\chi^2_{0.05}(4) = 9.49χ0.052​(4)=9.49。写出检验结论并解释其经济含义。

  4. 动态面板：在动态面板模型 yit=ρyi,t−1+ci+uity_{it} = \rho y_{i,t-1} + c_i + u_{it}yit​=ρyi,t−1​+ci​+uit​ 中，解释为什么 FE 估计的 ρ^\hat{\rho}ρ^​ 在小 TTT 下有偏。（提示：组内变换后 y¨i,t−1\ddot{y}_{i,t-1}y¨​i,t−1​ 与 u¨it\ddot{u}_{it}u¨it​ 相关。）

  5. 实际应用：设计一个面板数据研究来评估最低工资政策对就业的影响。说明你会使用什么固定效应、为什么需要聚类标准误、以及如何处理可能的动态效应。

拓展阅读

  • 核心教材：Wooldridge《Econometric Analysis of Cross Section and Panel Data》第 10-14 章是面板数据的权威参考。Baltagi《Econometric Analysis of Panel Data》提供更集中的面板方法讲解。
  • 动态面板：Arellano & Bond (1991) 和 Blundell & Bond (1998) 是 GMM 估计的经典论文。Roodman (2009) "How to Do xtabond2" 是 Stata 用户的实用指南。
  • 双向固定效应的新进展：de Chaisemartin & D'Haultfoeuille (2020) 和 Goodman-Bacon (2021) 揭示了异质处理效应下 TWFE 估计量的偏误问题，是近年计量经济学最活跃的研究方向。
  • 长面板方法：Pesaran (2015)《Time Series and Panel Data Econometrics》处理 TTT 大于 NNN 的情形，包括面板单位根和面板协整检验。

小结

面板数据模型通过控制不可观测的个体异质性，为因果推断提供了比纯截面数据更可靠的基础。固定效应模型以放弃效率为代价换取更弱的假设条件，而随机效应模型在其假设成立时更有效率。Hausman 检验是选择两者的标准工具。实际研究中，应根据研究设计和经济理论判断个体效应是否可能与解释变量相关，并使用聚类标准误确保推断的可靠性。动态面板和双向固定效应是当前研究的活跃前沿。
