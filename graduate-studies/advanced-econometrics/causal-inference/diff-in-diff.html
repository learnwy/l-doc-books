研究生 高级计量经济学 — 双重差分法

知识要点

双重差分法（Difference-in-Differences, DID）是因果推断领域中最为广泛使用的准实验方法之一，其核心思想通过比较处理组和控制组在政策干预前后的变化差异来识别因果效应。自 Card 和 Krueger (1994) 利用新泽西州最低工资调整研究就业影响的经典论文以来，DID 已成为劳动经济学、公共经济学和发展经济学等领域的主力工具。

DID 的基本逻辑可以概括为"差中之差"：

  • 第一层差分：处理组在干预前后的变化（包含政策效应 + 时间趋势）
  • 第二层差分：控制组在干预前后的变化（仅包含时间趋势）
  • 两层差分相减，消除共同时间趋势，得到纯政策效应

设 YitY_{it}Yit​ 为个体 iii 在时间 ttt 的结果变量，Di∈{0,1}D_i \in \{0,1\}Di​∈{0,1} 为分组指示变量，Postt∈{0,1}Post_t \in \{0,1\}Postt​∈{0,1} 为时期指示变量，则 DID 的基准回归方程为：

Yit=α+βDi+γPostt+δ(Di×Postt)+εitY_{it} = \alpha + \beta D_i + \gamma Post_t + \delta (D_i \times Post_t) + \varepsilon_{it}Yit​=α+βDi​+γPostt​+δ(Di​×Postt​)+εit​

其中 δ\deltaδ 即为我们关心的平均处理效应（ATT）。

关键假设包括：

  • 平行趋势假设（Parallel Trends）：在没有政策干预的反事实情形下，处理组和控制组的结果变量应保持相同的时间趋势
  • SUTVA：一个单位的处理状态不影响其他单位的结果（无溢出效应）
  • 无预期效应：个体不会因为预知政策而在干预前改变行为
  • 组成稳定性：样本组成不因政策而发生系统性变化

详细讲解

经典两期两组 DID

最简单的 DID 设定包含两个时期（t=0t=0t=0 和 t=1t=1t=1）和两组（处理组 D=1D=1D=1，控制组 D=0D=0D=0）。DID 估计量可以表示为：

δ^DID=(Yˉ1,1−Yˉ1,0)−(Yˉ0,1−Yˉ0,0)\hat{\delta}_{DID} = (\bar{Y}_{1,1} - \bar{Y}_{1,0}) - (\bar{Y}_{0,1} - \bar{Y}_{0,0})δ^DID​=(Yˉ1,1​−Yˉ1,0​)−(Yˉ0,1​−Yˉ0,0​)

其中 YˉD,t\bar{Y}_{D,t}YˉD,t​ 表示 DDD 组在 ttt 期的平均结果。这个估计量在 OLS 回归框架下等价于交互项 Di×PosttD_i \times Post_tDi​×Postt​ 的系数。

加入协变量 XitX_{it}Xit​ 的扩展模型：

Yit=α+βDi+γPostt+δ(Di×Postt)+Xit′θ+εitY_{it} = \alpha + \beta D_i + \gamma Post_t + \delta (D_i \times Post_t) + X_{it}'\theta + \varepsilon_{it}Yit​=α+βDi​+γPostt​+δ(Di​×Postt​)+Xit′​θ+εit​

加入协变量的目的不是满足平行趋势假设（该假设本身是关于无条件趋势的），而是提高估计精度、控制组成效应。

平行趋势检验

平行趋势假设在本质上是不可检验的，因为我们无法观测处理组在没有干预时的反事实结果。但实践中通常使用以下方法来增强可信度：

**事件研究法（Event Study）**是最常用的检验工具，其回归方程为：

Yit=αi+λt+∑k≠−1βk⋅1[t−ti∗=k]+εitY_{it} = \alpha_i + \lambda_t + \sum_{k \neq -1} \beta_k \cdot \mathbb{1}[t - t_i^* = k] + \varepsilon_{it}Yit​=αi​+λt​+k=−1∑​βk​⋅1[t−ti∗​=k]+εit​

其中 αi\alpha_iαi​ 为个体固定效应，λt\lambda_tλt​ 为时间固定效应，ti∗t_i^*ti∗​ 为个体 iii 接受处理的时间，kkk 为相对事件时间。以 k=−1k=-1k=−1（干预前一期）为基准期。

如果平行趋势假设成立，则干预前各期的系数 βk\beta_kβk​（k<−1k < -1k<−1）应在统计上不显著异于零。绘制这些系数及其置信区间的图形（event study plot）已成为 DID 论文的标准图之一。

**安慰剂检验（Placebo Test）**也是一种重要的辅助验证方法：

  • 选择干预前的某个时间点作为"虚假干预时间"，重新运行 DID
  • 如果得到显著的"效应"，说明在干预之前组间趋势已经分化，平行趋势假设可能不成立

多期交错DID（Staggered DID）

现实中，政策往往不是在同一时间对所有处理单位同时实施，而是分批推行——这就是交错采纳（staggered adoption）。传统的双向固定效应（TWFE）模型：

Yit=αi+λt+δDit+εitY_{it} = \alpha_i + \lambda_t + \delta D_{it} + \varepsilon_{it}Yit​=αi​+λt​+δDit​+εit​

其中 DitD_{it}Dit​ 在个体 iii 接受处理后取值为 1。

TWFE 的问题：Goodman-Bacon (2021) 的分解定理揭示，TWFE 估计量实际上是多个 2×22 \times 22×2 DID 估计量的加权平均，其中一些"坏的比较"使用已处理单位作为控制组。当处理效应随时间变化（即存在异质性处理效应）时，权重可能为负，导致 TWFE 估计量产生严重偏误，甚至符号翻转。

现代修正方法：

方法 提出者 核心思路
组-时间 ATT Callaway & Sant'Anna (2021) 对每个组别-时间对分别估计 ATT，然后聚合
堆叠 DID Cengiz et al. (2019) 为每个处理批次构建干净的控制组，堆叠后回归
交互加权估计 Sun & Abraham (2021) 用交互加权消除负权重问题
不完美平行趋势 Rambachan & Roth (2023) 允许平行趋势假设部分违反的稳健推断
异质处理效应稳健估计 de Chaisemartin & D'Haultfœuille (2020) 允许异质且动态的处理效应

推断与标准误

DID 分析中的标准误计算至关重要。Bertrand, Duflo & Mullainathan (2004) 指出，当使用面板数据时，组内序列相关会导致传统标准误严重低估，从而夸大统计显著性。

推荐做法：

  • 聚类标准误（Clustered SE）：至少在处理分配层面聚类。若处理在州层面分配，则在州层面聚类
  • 聚类数量问题：当聚类数量较少（G<50G < 50G<50）时，使用 Cameron, Gelbach & Miller (2008) 的 Wild Cluster Bootstrap
  • 随机化推断（Randomization Inference）：对处理分配进行置换检验，计算 Fisher exact ppp-值

标准误的选择直接影响结论的可信度。一个常见的错误是在个体层面聚类而不是在政策分配层面聚类，这会产生过于乐观的推断结果。

DID 的实践注意事项

在应用 DID 时，还需注意以下问题：

  1. 预期效应与 Ashenfelter's Dip：如果处理组在干预前就开始调整行为（如失业培训项目中的 Ashenfelter's dip），干预前数据本身就被"污染"了
  2. 溢出效应：政策可能影响控制组（如邻近地区的最低工资变化导致劳动力流动），违反 SUTVA
  3. 选择性退出/进入：如果政策导致部分个体离开样本（如企业倒闭），会产生组成效应偏误
  4. 功能形式选择：对于比例数据或计数数据，对数变换或 Poisson 回归可能更合适；Wooldridge (2023) 建议使用 Poisson 伪最大似然估计

练习与思考

  1. 概念辨析：在一个标准的两期 DID 中，如果处理组在干预前的水平（Yˉ1,0\bar{Y}_{1,0}Yˉ1,0​）高于控制组（Yˉ0,0\bar{Y}_{0,0}Yˉ0,0​），这是否意味着平行趋势假设被违反？请解释你的判断。

  2. 事件研究图解读：假设你绘制了 event study plot，发现 k=−4k=-4k=−4 和 k=−3k=-3k=−3 期的系数为正且显著（p<0.05p < 0.05p<0.05），k=−2k=-2k=−2 期系数为正但不显著（p=0.12p = 0.12p=0.12），干预后各期系数均显著为正。你会如何评估这一结果？是否支持 DID 识别策略的有效性？

  3. TWFE 偏误模拟：考虑一个场景：有 3 批单位分别在 t=3t=3t=3、t=5t=5t=5、t=7t=7t=7 接受处理，处理效应线性递增（δk=0.5k\delta_k = 0.5kδk​=0.5k，kkk 为处理后经过的期数）。请讨论为什么 TWFE 估计量可能会低估真实的平均处理效应。

  4. 聚类层级选择：你正在研究一项在县级层面实施的环保政策对企业污染排放的影响，数据为企业-年面板。请讨论应在哪个层面聚类标准误，并分析在省级聚类可能带来的问题。

  5. 研究设计：某城市在 2020 年对核心城区实施了限行政策，你想评估该政策对空气质量的影响。请设计一个 DID 研究方案，包括处理组和控制组的选择、数据需求和可能面临的识别挑战。

小结

双重差分法是因果推断的核心工具之一。其基本思路——通过两次差分消除不可观测的固定差异和共同趋势——既直观又强大。然而，从传统 TWFE 到现代异质处理效应稳健方法的演进表明，看似简单的 DID 在处理复杂的政策环境时充满陷阱。平行趋势假设的可信度、交错采纳下的权重问题、以及推断层面的正确选择，都是研究者必须认真对待的环节。掌握经典 DID 并紧跟方法论前沿，是研究生阶段应用微观计量经济学的基本功。
