研究生 创作实践研究 — 反思性实践

知识要点

反思性实践（Reflective Practice）是将日常创作活动转化为系统性知识生产的核心方法论机制。Donald Schön（1983）在《The Reflective Practitioner》中提出的核心洞见是：专业实践者的知识不仅仅存在于理论命题中，更嵌入在行动本身之中。他区分了两种反思模式——行动中反思（reflection-in-action）和行动后反思（reflection-on-action）。前者发生在创作过程的实时流动中，当实践者在做的同时调整、试验、回应意外；后者发生在创作完成之后，当实践者回顾、分析和概念化自己的经验。对于艺术研究者而言，反思性实践不是可选的附加项，而是将"我在创作"转化为"我在通过创作进行研究"的关键转化器。

核心概念包括：

  • 行动中的知（Knowing-in-Action）：Schön 的概念，指嵌入在熟练行动中的默会知识——画家对颜料稠度的直觉把握、雕塑家对材料张力的身体感知
  • 意外与重构（Surprise and Reframing）：当实践结果偏离预期时，实践者通过重新建构问题框架来回应，这一过程是创新知识产生的关键时刻
  • 反思性对话（Reflective Conversation with the Situation）：Schön 将创作过程比喻为与"情境"的对话——实践者提出动作，情境"回话"，实践者再回应
  • 批判性反思（Critical Reflection）：超越个人经验层面，将反思与更广泛的社会、政治和理论语境相连接
  • 反思层级模型：从描述（发生了什么？）→ 分析（为什么发生？）→ 评价（意味着什么？）→ 转化（如何改变实践？）

详细讲解

Schön 的反思性实践理论

Schön 的理论来源于对建筑师、工程师、音乐家等多种专业实践者的观察。他发现，优秀的实践者并不是简单地将理论"应用"于实践，而是在实践中发展出一种独特的"实践知识"（Professional Artistry）。这种知识具有以下特征：

特征 说明 艺术创作中的表现
默会性 知道如何做但难以言说 画家调配颜色时的直觉判断
情境性 依赖具体情境而非普遍规则 同一技法在不同作品中的调整
即兴性 在不确定中做出实时决策 即兴演奏、行为艺术中的当场回应
整合性 同时处理多个变量 同时考虑构图、色彩、质感、概念
审美性 以审美判断而非逻辑推演为导向 "感觉对了"作为质量判断标准

行动中反思的核心机制是"意外-重构"循环：

这一循环在工作室实践中无处不在。例如，一位陶艺家在拉坯时发现泥坯出现意外的不对称形态——传统技术训练可能将此视为"错误"，但反思性实践者会暂停、观察这一"意外"，重新建构问题（"如果我不追求对称呢？"），然后有意识地探索不对称的可能性。这正是 Schön 所说的"与情境的反思性对话"。


反思性日志的方法论
反思性日志（Reflective Journal）是将反思性实践转化为可追溯的研究数据的核心工具。然而，有效的反思性日志远不止于"今天我做了什么"的流水账。Moon（1999）提出了反思性写作的层级框架：


第一层：描述性写作


    

  • 记录事实：做了什么、用了什么材料、花了多长时间
    • 

  • 示例："今天在工作室尝试了用丙烯颜料在生宣纸上作画"
    • 



第二层：描述性反思


    

  • 开始加入个人感受和初步分析
    • 

  • 示例："丙烯在生宣上的渗透效果出乎意料，墨色边缘产生了类似水墨晕染的效果，但色彩饱和度更高"
    • 



第三层：对话性反思


    

  • 将经验与理论、其他艺术家的实践、和自己先前的工作进行对话
    • 

  • 示例："这种'失控'的渗透让我想到了 Jackson Pollock 的滴画——他同样通过放弃传统控制来发现新的形式可能性。但不同于 Pollock 的身体性（bodily gestural），这里的'意外'来自材料本身的物性"
    • 



第四层：批判性反思


    

  • 将个人经验放入更广泛的社会文化语境中审视
    • 

  • 示例："我对'东方材料+西方媒介'这一组合的兴趣，是否反映了一种后殖民混杂性的美学追求？我需要警惕将文化差异浪漫化的倾向"
    • 



反思性实践的陷阱
反思性实践并非没有风险。过度反思可能导致"分析瘫痪"——创作者陷入无休止的自我审视而无法行动。Finlay（2008）识别了几种常见的反思性陷阱：


    

  • 自恋式反思：沉溺于个人情感而无法超越自我
    • 

  • 理智化反思：用理论术语包装浅层思考，产生一种虚假的深度
    • 

  • 功利性反思：仅仅为了满足学术要求而"表演"反思
    • 

  • 确认偏误式反思：只反思支持自己已有假设的经验
    •

将反思转化为研究成果
反思性实践日志如何从"私人笔记"转化为具有学术价值的研究数据？这需要一个系统化的分析过程：


    

  1. 编码与主题分析：回顾数月的日志，标注反复出现的主题、关切和发现
    2. 

  2. 时间线映射：将日志中的关键转折点与作品的演变进行时间线对照
    3. 

  3. 理论对话：将经验中涌现的概念与既有理论进行对话——这不是"验证"理论，而是让经验和理论相互照亮
    4. 

  4. 叙事建构：将零散的反思编织为一个连贯的研究叙事——从问题的浮现，到方法的摸索，到洞见的结晶
    5. 

  5. 可视化呈现：用图表、时间线、概念图等形式将隐性的反思过程显性化
    6. 



练习与思考
    

  1. 双层日志练习：在接下来一周的创作活动中，采用"双列日志"格式。左列记录创作过程的事实描述（做了什么），右列记录实时的反思性评论（为什么这样做、感受到什么、想到了什么）。一周后分析：左右两列之间是否出现了有趣的张力或矛盾？
    

    2. 

  2. 意外档案：回顾你近期的创作经历，识别三个"意外时刻"——实践结果偏离预期的节点。用 Schön 的"意外-重构"框架分析每个时刻：你是如何回应这一意外的？你重新建构了什么问题？这一重构是否导致了新的创作方向？
    

    3. 

  3. 反思层级自测：从你的日志或创作笔记中选择三段文字，用 Moon 的四层级模型判断它们分别处于哪个反思层级。然后尝试将最浅层的那段改写到更深的反思层级。
    

    4. 

  4. 反思性对话模拟：邀请一位同学担任"批判性朋友"（Critical Friend），向对方展示你的一件在进行中的作品，并进行 20 分钟的反思性对话。对话后各自写一段反思：这次对话改变了你对作品的什么理解？
    

    5.

    • 



小结
反思性实践将艺术创作从"手艺活动"提升为"知识生产活动"。通过 Schön 的行动中反思和行动后反思双重机制，创作者能够从自身的实践经验中提取出可传递、可讨论、可建构于其上的知识。反思性日志是这一过程的核心工具，但有效的反思需要超越描述性记录，进入分析性和批判性的深层对话。最终，反思性实践的目标不是让创作者变成理论家，而是让理论思考和创作行动形成一个相互滋养的螺旋——每一次反思都丰富下一次行动，每一次行动都为下一次反思提供新的素材。
