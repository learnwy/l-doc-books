研究生 分子生物学 — 表观遗传学

知识要点

表观遗传学研究不改变 DNA 序列本身但可以遗传的基因表达变化。DNA 甲基化、组蛋白修饰和非编码 RNA 构成了表观遗传调控的三大支柱。表观遗传状态在细胞分裂中可以稳定传递，使得同一基因组在不同细胞类型中产生截然不同的表达模式。表观遗传异常与癌症、神经退行性疾病和衰老密切相关，表观遗传药物已成为新兴治疗方向。

核心概念：

  • DNA 甲基化：CpG 位点的胞嘧啶第5位碳甲基化（5mC）
  • 组蛋白密码（Histone Code）：组蛋白修饰的组合模式编码功能信息
  • 表观遗传记忆：通过细胞分裂传递的表观遗传状态
  • X 染色体失活：哺乳动物雌性中一条 X 染色体的全局沉默
  • 基因组印记：亲本来源特异性的基因表达

详细讲解

DNA 甲基化

CpG 甲基化是脊椎动物中最主要的 DNA 表观修饰：

胞嘧啶→DNMT5-甲基胞嘧啶 (5mC)\text{胞嘧啶} \xrightarrow{\text{DNMT}} \text{5-甲基胞嘧啶 (5mC)}胞嘧啶DNMT​5-甲基胞嘧啶 (5mC)

DNA 甲基转移酶（DNMTs）：

  • DNMT1："维持甲基化酶"，在 DNA 复制后识别半甲基化位点并完成甲基化
  • DNMT3A/3B："从头甲基化酶"，建立新的甲基化模式
  • DNMT3L：无催化活性，辅助 DNMT3A/3B

功能：

  • 基因沉默：启动子 CpG 岛高甲基化 → 转录抑制
  • 基因组稳定性：转座元件的甲基化防止其跳跃
  • X 染色体失活：失活 X 上基因的启动子高度甲基化
  • 基因组印记：印记控制区域（ICR）的亲本特异性甲基化

去甲基化：TET 酶催化 5mC → 5hmC → 5fC → 5caC，最终被 TDG/BER 通路去除，实现 DNA 去甲基化。

组蛋白修饰与组蛋白密码

组蛋白 N 端尾巴上的共价修饰种类繁多，形成复杂的组合信号。

主要修饰类型：

修饰 酶 功能倾向
乙酰化（Kac） HAT（写入）/ HDAC（擦除） 激活
甲基化（Kme1/2/3） KMT / KDM 依赖位点
磷酸化（Sph） 激酶 / 磷酸酶 多样
泛素化（Kub） E3 连接酶 / DUB 多样

组蛋白密码假说：组蛋白修饰的特定组合被"阅读器"（reader）蛋白识别，招募效应复合物执行功能。

Polycomb 和 Trithorax 系统：

  • PRC2：催化 H3K27me3（沉默标记），通过 PRC1 稳定沉默状态
  • Trithorax（MLL/SET1）：催化 H3K4me3（活性标记），维持活性状态

这两个系统在发育中建立和维持基因的"开/关"状态。

X 染色体失活

机制（Lyon 假说，1961）：哺乳动物雌性（XX）的一条 X 染色体被随机失活，形成 Barr 体。

XIST RNA：从失活 X 上转录的长非编码 RNA，包被整条染色体并招募沉默机器：

XIST 表达→PRC2 招募→H3K27me3→DNA 甲基化→稳定沉默\text{XIST 表达} \to \text{PRC2 招募} \to \text{H3K27me3} \to \text{DNA 甲基化} \to \text{稳定沉默}XIST 表达→PRC2 招募→H3K27me3→DNA 甲基化→稳定沉默

关键特征：

  • 随机性：每个细胞独立选择失活哪条 X → 雌性是 X 表达的嵌合体
  • 可逆性：在 iPS 重编程中 X 失活可被逆转
  • 逃逸基因：约 15% 的 X 连锁基因可逃避失活

基因组印记

定义：某些基因仅从父方或母方等位基因表达，由印记控制区域（ICR）的亲本特异性 DNA 甲基化控制。

经典例子：

  • IGF2/H19 位点：父方表达 IGF2，母方表达 H19，由 ICR 甲基化状态决定
  • Beckwith-Wiedemann 综合征：IGF2 双等位基因表达 → 过度生长
  • Prader-Willi/Angelman 综合征：15q11-13 区域的印记缺陷

印记的建立发生在配子发生过程中，由 DNMT3A/DNMT3L 执行。受精后大多数基因组甲基化被擦除，但印记区域受到保护。

表观遗传与疾病

癌症中的表观遗传异常：

  • 全基因组低甲基化 → 基因组不稳定、癌基因激活
  • 抑癌基因启动子高甲基化 → 功能丧失
  • 组蛋白修饰酶突变（如 EZH2、MLL 融合）

表观遗传药物：

  • DNA 甲基转移酶抑制剂（5-Azacitidine, Decitabine）
  • HDAC 抑制剂（Vorinostat, Romidepsin）
  • EZH2 抑制剂（Tazemetostat）
  • BET 抑制剂（JQ1, 靶向 BRD4）

练习与思考

  1. 解释 DNMT1 如何在 DNA 复制后维持甲基化模式的保真性。

  2. 设计实验区分 DNA 甲基化是基因沉默的原因还是结果。

  3. 为什么表观遗传药物（如 DNMT 抑制剂）对癌细胞的杀伤力大于正常细胞？

  4. 讨论表观遗传跨代遗传（transgenerational epigenetic inheritance）的证据和争议。

  5. 比较 X 染色体失活和基因组印记在建立机制和功能上的异同。

拓展阅读

  • Allis 等《Epigenetics》是表观遗传学的综合教材。
  • Berger et al. (2009) "An operational definition of epigenetics" 是该领域的重要综述。
  • ENCODE 和 Roadmap Epigenomics 项目提供了人类表观基因组的全景数据。
  • Dawson & Kouzarides (2012) "Cancer epigenetics" 是癌症表观遗传学的经典综述。

小结

表观遗传学揭示了基因组之上的另一层信息编码——同一 DNA 序列可以通过不同的表观遗传标记产生完全不同的表达模式。DNA 甲基化提供了稳定的长期沉默，组蛋白修饰构成了灵活的调控开关，非编码 RNA 则提供了额外的调控维度。这些机制协同工作，使得一个基因组可以支持数百种不同的细胞类型。表观遗传异常是多种疾病的重要机制，而表观遗传药物的开发正在为精准医学开辟新的治疗方向。
