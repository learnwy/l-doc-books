个人数据基础设施 简介

个人数据基础设施关注如何以工程化思维构建属于自己的数据存储、同步与服务体系。在 2026 年，随着 Local-first 架构日趋成熟、SQLite 作为通用应用格式被广泛采纳、Docker 让自托管触手可及，以及 webhook 基础设施工具的标准化，个人开发者已经具备了构建媲美企业级数据平台的条件——而代价仅是一台低功耗设备和一套精心设计的架构。

本 Hub 适用于希望掌控自己数据的开发者：无论你是厌倦了云服务的订阅费和数据锁定，还是想为自己的 Side Project 搭建一套持久、可靠的数据底座，这里都能提供从理论到实战的完整指引。

第一章Local-first 架构系统讲解离线优先应用的核心理念，从 CRDTs 的数学原理与工程实现（Yjs、Automerge），到本地持久化方案（IndexedDB、OPFS、SQLite WASM），再到多设备同步协议的设计模式，帮助你理解这一正在重塑个人软件形态的架构范式。

第二章SQLite 应用实践深入探讨 SQLite 作为应用文件格式的优势与实战技巧，涵盖 WAL 模式下的并发读写、FTS5 全文搜索、JSON 扩展，以及如何将 SQLite 打造为个人数据仓库——一个统一存储笔记、书签、习惯记录等异构数据的单文件数据库。

第三章自托管服务提供从零搭建 Homelab 的完整路径，包括硬件选型（Raspberry Pi 5 到 Mac Mini）、Docker Compose 服务栈编排（Nextcloud、Vaultwarden、Immich 等）、反向代理与 HTTPS 配置，以及通过 Cloudflare Tunnel 实现安全的公网访问。

第四章个人 API 编排聚焦于将分散在各平台的个人数据聚合为统一接口，内容涵盖多源数据聚合策略、webhook 管道设计（n8n、Hookdeck）、以及如何设计和实现一套个人数据 API——让你的健康数据、阅读记录、代码统计通过标准 REST/GraphQL 接口统一访问。

推荐学习路径：先从第一章理解 Local-first 的核心理念，第二章掌握 SQLite 作为本地数据引擎的实践技能，第三章搭建自托管服务基础设施，最后通过第四章将所有数据源编排为统一的个人 API。四章内容层层递进，最终形成一套完整的、由你完全掌控的个人数据基础设施。
