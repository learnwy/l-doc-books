Homelab 入门

概述

Homelab 是一套运行在你家中的服务器基础设施，用于托管个人服务、学习技术、以及将数据主权从云服务商手中收回。2026 年，搭建 Homelab 的门槛已降至历史最低：一台 Raspberry Pi 5 仅需 80 美元，Mac Mini M4 在 5-7W 的功耗下提供 16GB 内存和 Apple Silicon 性能，Docker 让部署变成一条命令。本文从硬件选型、操作系统配置到网络规划，提供从零开始的完整决策框架。

实战指南
方案一：Raspberry Pi 5 入门
# 1. 烧录系统（使用 Raspberry Pi Imager）
# 选择 Raspberry Pi OS Lite (64-bit) — 无桌面，纯 CLI

# 2. 首次启动配置
sudo raspi-config
# → System Options → Hostname: homelab
# → Interface Options → SSH: Enable
# → Performance Options → GPU Memory: 16 (最小化)

# 3. 系统更新
sudo apt update && sudo apt upgrade -y

# 4. 安装 Docker
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 5. 安装 Docker Compose
sudo apt install docker-compose-plugin -y

# 6. 验证
docker --version  # Docker 27.x+
docker compose version  # v2.x
外接 SSD 作为数据盘（MicroSD 不适合数据库工作负载）：


# 挂载 USB SSD
sudo mkdir /mnt/data
sudo mount /dev/sda1 /mnt/data
echo '/dev/sda1 /mnt/data ext4 defaults,nofail 0 2' | sudo tee -a /etc/fstab

# Docker 数据目录迁移到 SSD
sudo systemctl stop docker
sudo mv /var/lib/docker /mnt/data/docker
sudo ln -s /mnt/data/docker /var/lib/docker
sudo systemctl start docker
方案二：Mini PC 主力部署
Intel N100 Mini PC（如 Beelink S12 Pro）是 2026 年 Homelab 的性价比之王：


# 安装 Ubuntu Server 24.04 LTS（USB 启动盘安装）

# 基础配置
sudo hostnamectl set-hostname homelab
sudo timedatectl set-timezone Asia/Shanghai

# 安装 Docker Engine 最新版
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

# 创建数据目录结构
sudo mkdir -p /opt/homelab/{configs,data,backups}
sudo chown -R $USER:$USER /opt/homelab

# 启用自动安全更新
sudo apt install unattended-upgrades -y
sudo dpkg-reconfigure -plow unattended-upgrades
方案三：Mac Mini M4 高性能方案
Mac Mini M4 以极低功耗提供强大性能，但 macOS 不原生支持 Docker——需要 OrbStack：


# 安装 OrbStack（Mac 上最优的 Docker 运行时）
brew install orbstack

# OrbStack 优势 vs Docker Desktop:
# - 启动速度快 10 倍
# - 内存占用低 50%
# - 原生 ARM 性能，无虚拟化开销
# - 自动端口转发和 DNS

# 数据目录
mkdir -p ~/homelab/{configs,data,backups}

# 验证
docker run hello-world

总结
Homelab 的核心不是硬件有多强，而是你对自己数据和服务的掌控力。从一台 Raspberry Pi 开始，跑起第一个 Docker 容器，感受"我的数据在我的硬盘上"的踏实感——这比任何高配方案都更重要。600 元的 Pi 5 加一块 SSD 就能承载密码管理、文件同步、照片备份三大核心服务，比一年的云订阅费还便宜。硬件可以按需升级，但自托管的习惯和技能一旦建立，就是终身受益的投资。
