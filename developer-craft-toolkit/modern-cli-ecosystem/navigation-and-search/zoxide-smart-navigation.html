zoxide 智能跳转

概述

zoxide 是 cd 命令的智能替代品，通过 frecency 算法（频率 + 时效性的加权组合）学习你的目录访问模式，让你用最少的按键跳转到最常访问的目录。安装配置后，z proj 就能跳转到 /Users/you/code/my-project——无需记忆完整路径。zoxide 由 Rust 编写，支持所有主流 Shell，数据库本地存储，启动开销几乎为零。

核心概念

frecency 算法

zoxide 的核心是 frecency 评分系统，综合考虑访问频率和最近访问时间：

评分规则：


    

  • 每次访问目录时，该目录的分数增加
    • 

  • 时间衰减：最近 1 小时访问权重 4x，24 小时内 2x，7 天内 1x，更早 0.5x
    • 

  • 当数据库条目超过阈值（默认 9000）时，自动修剪低分条目
    • 



匹配策略
zoxide 的路径匹配使用多关键字路径分段匹配：

z foo

/home/user/foo-project




z foo bar
路径包含 "foo" 且末段含 "bar"
/home/user/foo/bar




z /foo
路径以 "/foo" 开头
/foo/...




z foo/
路径以 "foo/" 结尾
xxx/foo/





实战指南
安装与 Shell 集成
# 安装
brew install zoxide        # macOS
sudo apt install zoxide    # Ubuntu 22.04+
cargo install zoxide       # 从源码

# Shell 集成（添加到配置文件末尾）
# Zsh (~/.zshrc)
eval "$(zoxide init zsh)"

# Bash (~/.bashrc)
eval "$(zoxide init bash)"

# Fish (~/.config/fish/config.fish)
zoxide init fish | source

# 自定义命令名（默认是 z 和 zi）
eval "$(zoxide init zsh --cmd cd)"  # 直接替换 cd
eval "$(zoxide init zsh --cmd j)"   # 使用 j 作为命令名
基础使用
# 跳转到最匹配的目录
z project                    # 跳转到得分最高的含 "project" 的路径
z dev tool                   # 多关键字：路径含 "dev" 且末段含 "tool"
z doc-hub                    # 精确匹配 slug

# 交互模式（需要 fzf）
zi                           # 列出所有记录的目录，fzf 模糊选择
zi project                   # 预过滤 "project"，再 fzf 选择

# 回退到上一个目录
z -                          # 等价于 cd -

# 查看数据库
zoxide query                 # 列出所有记录的目录和分数
zoxide query --list          # 只列出路径（不显示分数）
zoxide query -s project      # 查看 "project" 的匹配和分数
数据库管理
# 手动添加目录（无需实际访问）
zoxide add /path/to/important/dir
zoxide add ~/code/new-project

# 删除条目
zoxide remove /path/to/deleted/dir

# 批量清理（删除不存在的目录）
zoxide query --list | while read -r dir; do
  [ -d "$dir" ] || zoxide remove "$dir"
done

# 导入其他工具的数据
# 从 autojump 导入
zoxide import --from autojump /path/to/autojump/db

# 从 z.sh 导入
zoxide import --from z /path/to/z/data
高级配置
# 环境变量配置
export _ZO_DATA_DIR="$HOME/.local/share/zoxide"  # 数据库位置
export _ZO_ECHO=1                                 # 跳转后打印路径
export _ZO_EXCLUDE_DIRS="/tmp:/private/tmp"       # 排除的目录
export _ZO_FZF_OPTS="
  --preview 'eza --tree --level=1 --icons --color=always {2..}'
  --height 40%
  --reverse
"
export _ZO_MAXAGE=10000     # 数据库最大条目数
export _ZO_RESOLVE_SYMLINKS=1  # 解析符号链接
最佳实践
zoxide + fzf 联动模式
# 自定义 zi 的预览（显示目录内容）
export _ZO_FZF_OPTS="
  --preview 'eza --tree --level=2 --icons --color=always --git-ignore {2..}'
  --preview-window right:40%
  --bind 'ctrl-/:toggle-preview'
"

# 创建增强版跳转函数
zz() {
  local dir
  dir=$(zoxide query --list --score |
    fzf --tac --no-sort \
        --preview 'eza --tree --level=2 --icons --color=always {2..}' \
        --bind 'ctrl-d:execute(zoxide remove {2..})+reload(zoxide query --list --score)' \
        --header 'Ctrl-D to remove entry') &&
  cd "$(echo "$dir" | awk '{print $2}')"
}
项目切换工作流
# 快速项目切换器
proj() {
  local project_dir
  project_dir=$(fd --type d --max-depth 1 . ~/code ~/work |
    fzf --preview 'eza --tree --level=1 --icons --color=always {}') &&
  cd "$project_dir"
}

# 结合 zoxide 的项目记忆 + fd 的新项目发现
smart_cd() {
  local dir
  dir=$(
    { zoxide query --list --score | awk '{print $2}'; fd --type d --max-depth 2 . ~/code; } |
    sort -u |
    fzf --preview 'eza --tree --level=1 --icons --color=always {}'
  ) && cd "$dir"
}
与其他工具集成
# tmux session 跳转
tz() {
  local dir=$(zoxide query --list | fzf)
  local session_name=$(basename "$dir")
  if tmux has-session -t "$session_name" 2>/dev/null; then
    tmux switch-client -t "$session_name"
  else
    tmux new-session -d -s "$session_name" -c "$dir"
    tmux switch-client -t "$session_name"
  fi
}

# VS Code 打开 zoxide 记录的项目
zcode() {
  local dir=$(zoxide query --list | fzf --preview 'eza --tree --level=1 {}')
  [ -n "$dir" ] && code "$dir"
}

总结
zoxide 解决了一个看似微小但影响巨大的问题：目录跳转的认知负担。你不再需要记忆完整路径或反复 tab 补全——只需记住目标目录名的几个字母。结合 fzf 的交互模式（zi），即使完全不记得路径也能通过视觉浏览快速定位。zoxide 的价值会随着使用时间持续增长：使用越久，数据库越精准，跳转越快。建议安装后立即用 eval "$(zoxide init zsh --cmd cd)" 直接替换 cd，一周后你将无法想象没有它的终端生活。
