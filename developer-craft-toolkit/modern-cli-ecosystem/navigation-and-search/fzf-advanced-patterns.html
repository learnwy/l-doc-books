fzf 高级模式

概述

fzf 是命令行世界的「万能连接器」。它不搜索文件内容、不记忆目录、不管理 Git——它只做一件事：接收文本行输入，提供交互式模糊搜索界面，返回用户选择的结果。正是这种极致的「只做一件事」设计，让 fzf 能接入任何产出文本的命令，成为整个终端工具生态的 UI 层。截至 2026 年 5 月，fzf 最新版本为 0.72.0，GitHub 星数超过 68k。

核心概念

fzf 的数据流模型

fzf 遵循严格的 Unix 工具哲学：

三个阶段各自独立：数据源可以是任何命令；fzf 提供交互式筛选 UI；输出可以传给任何下游命令。这种解耦设计让 fzf 的应用场景无限延展。


匹配算法
fzf 提供两种匹配模式：


| 模式             | 语法   | 行为                            |
| ---------------- | ------ | ------------------------------- | --------------- |
| 模糊匹配（默认） | abc  | 匹配包含 a、b、c 且顺序正确的行 |
| 精确匹配         | 'abc | 只匹配包含连续 "abc" 的行       |
| 前缀匹配         | ^abc | 行必须以 "abc" 开头             |
| 后缀匹配         | abc$ | 行必须以 "abc" 结尾             |
| 取反             | !abc | 排除包含 "abc" 的行             |
| OR               | abc   | def                            | 匹配 abc 或 def |


这些可以组合使用：^src .ts$ !test 表示「以 src 开头、以 .ts 结尾、不含 test」。


实战指南
Shell 集成（核心三键绑定）
# ~/.zshrc — fzf 0.48+ 简化配置
source <(fzf --zsh)

# Ctrl+R: 模糊搜索命令历史（替代内建 reverse-i-search）
# Ctrl+T: 模糊搜索文件并粘贴路径到命令行
# Alt+C:  模糊搜索目录并 cd 进入
预览窗口深度配置
# 基础文件预览（用 bat 提供语法高亮）
fzf --preview 'bat --color=always --line-range :100 {}'

# 预览窗口位置和大小
fzf --preview 'bat --color=always {}' --preview-window right:60%:wrap

# 动态预览：根据文件类型切换
fzf --preview '
  if [ -d {} ]; then
    eza --tree --level=2 --icons --color=always {}
  elif [ -f {} ]; then
    bat --color=always --line-range :80 {}
  else
    echo "Special: {}"
  fi
'

# 预览窗口控制键绑定
fzf --preview 'bat --color=always {}' \
    --bind 'ctrl-/:toggle-preview' \
    --bind 'ctrl-u:preview-half-page-up' \
    --bind 'ctrl-d:preview-half-page-down'
自定义键绑定与动作
# 在 fzf 内执行动作（不退出）
fzf --bind 'ctrl-e:execute(vim {} < /dev/tty > /dev/tty)'
fzf --bind 'ctrl-y:execute-silent(echo {} | pbcopy)'

# 改变预览内容
fzf --preview 'bat --color=always {}' \
    --bind 'ctrl-g:change-preview(git log --oneline -20 {})' \
    --bind 'ctrl-b:change-preview(bat --color=always {})'

# accept 动作（选中并退出）
fzf --bind 'ctrl-o:accept'

# 多选操作
fzf --multi \
    --bind 'ctrl-a:select-all' \
    --bind 'ctrl-d:deselect-all' \
    --bind 'ctrl-t:toggle-all'
动态重载（Reload Pattern）
这是 fzf 最强大的高级模式——每次按键都重新执行数据源命令：


# 实时 ripgrep 搜索（每个字符触发 rg 重新搜索）
RG_PREFIX="rg --column --line-number --no-heading --color=always --smart-case"
fzf --ansi --disabled \
    --bind "start:reload:$RG_PREFIX {q}" \
    --bind "change:reload:sleep 0.1; $RG_PREFIX {q} || true" \
    --delimiter : \
    --preview 'bat --color=always {1} --highlight-line {2}' \
    --preview-window 'up,60%,border-bottom,+{2}+3/3,~3'

# 在 fzf 模糊和 rg 精确搜索之间切换
fzf --ansi --disabled \
    --bind "start:reload:$RG_PREFIX ''" \
    --bind "change:reload:$RG_PREFIX {q} || true" \
    --bind "ctrl-f:unbind(change)+clear-query+enable-search" \
    --bind "ctrl-r:rebind(change)+disable-search+clear-query"
环境变量完整配置
# ~/.zshrc — FZF 全局配置
export FZF_DEFAULT_COMMAND='fd --type f --hidden --follow --exclude .git'

export FZF_DEFAULT_OPTS="
  --height 60%
  --layout=reverse
  --border=rounded
  --info=inline-right
  --preview-window 'right:50%:border-left'
  --bind 'ctrl-/:toggle-preview'
  --bind 'ctrl-y:execute-silent(echo {+} | pbcopy)'
  --color=bg+:#363a4f,bg:#24273a,spinner:#f4dbd6,hl:#ed8796
  --color=fg:#cad3f5,header:#ed8796,info:#c6a0f6,pointer:#f4dbd6
  --color=marker:#f4dbd6,fg+:#cad3f5,prompt:#c6a0f6,hl+:#ed8796
"

# Ctrl+T 配置
export FZF_CTRL_T_COMMAND="$FZF_DEFAULT_COMMAND"
export FZF_CTRL_T_OPTS="
  --preview 'bat --color=always --line-range :100 {}'
  --bind 'ctrl-/:change-preview-window(down|hidden|)'
"

# Alt+C 配置
export FZF_ALT_C_COMMAND='fd --type d --hidden --follow --exclude .git'
export FZF_ALT_C_OPTS="
  --preview 'eza --tree --level=2 --icons --color=always {}'
"

# Ctrl+R 配置
export FZF_CTRL_R_OPTS="
  --preview 'echo {}'
  --preview-window up:3:hidden:wrap
  --bind 'ctrl-/:toggle-preview'
  --bind 'ctrl-y:execute-silent(echo -n {2..} | pbcopy)+abort'
  --header 'Press CTRL-Y to copy command into clipboard'
"
最佳实践
常用 fzf 函数库
# 交互式 cd（使用 fd 列目录）
fcd() {
  local dir
  dir=$(fd --type d --hidden --follow --exclude .git | fzf +m \
    --preview 'eza --tree --level=1 --icons --color=always {}') &&
  cd "$dir"
}

# 交互式进程杀死
fkill() {
  local pid
  pid=$(ps -ef | sed 1d | fzf -m --header='Select process to kill' | awk '{print $2}')
  if [ -n "$pid" ]; then
    echo "$pid" | xargs kill -${1:-9}
  fi
}

# 交互式 Git checkout
fco() {
  local branch
  branch=$(git branch --all | grep -v HEAD |
    fzf --preview 'git log --oneline -20 {}' |
    sed 's/.* //' | sed 's#remotes/[^/]*/##') &&
  git checkout "$branch"
}

# 交互式打开文件
fo() {
  local file
  file=$(fzf --preview 'bat --color=always --line-range :100 {}')
  [ -n "$file" ] && ${EDITOR:-vim} "$file"
}

总结
fzf 的核心价值不在于它自己做了什么，而在于它让其他工具的输出变得可交互。掌握 fzf 的预览窗口、键绑定、动态重载三大机制后，你可以为任何命令行场景构建交互式界面。它是现代终端工具生态的「UI 框架」——所有工具通过 fzf 获得统一的交互体验。
