bat 与 eza 深度实践

概述

bat 和 eza 分别替代 cat 和 ls，是开发者每天执行频率最高的两类命令的现代化升级。bat 为文件查看添加语法高亮、行号、Git 变更标记；eza 为目录列表添加彩色文件类型、Git 状态、树形视图、图标支持。这两款工具的共同特点是「零配置即有用」——安装后立即比原版好用，而深入配置后则能解锁更多可能性。

核心概念

bat 的智能行为

bat 最精妙的设计在于上下文感知输出。它会根据输出目标自动调整行为：

这意味着 bat file.py 在终端中有完整的视觉增强，但 bat file.py | wc -l 不会被额外的装饰干扰——与 cat 完全兼容的管道行为。


eza 的信息密度设计
eza 的设计理念是「一眼获取最大信息量」。传统 ls -l 的输出充满了对开发者来说无用的信息（用户组、硬链接数），而 eza 重新设计了信息层次：

实战指南
bat 完整用法
# 基础查看（自带语法高亮 + 行号）
bat README.md
bat src/main.rs

# 控制输出样式
bat -n file.py              # 只显示行号，不显示网格和头部
bat -p file.py              # plain 模式（只有高亮，无装饰）
bat --style=numbers,grid    # 自定义样式组件

# 指定语言（文件无扩展名时有用）
bat -l json data            # 手动指定为 JSON
bat -l yaml < /dev/stdin    # 为管道输入指定语言
echo '{"key": "value"}' | bat -l json

# Git 集成
bat -d file.py              # 只显示 Git 变更的行
bat --diff                  # 显示与 Git HEAD 的差异标记

# 主题管理
bat --list-themes           # 列出所有可用主题
bat --theme=Dracula file.rs # 临时使用 Dracula 主题
bat --theme=TwoDark file.ts # Tokyo Night 风格

# 行范围选择
bat -r 10:20 file.py        # 只显示第 10-20 行
bat -r :50 large-file.log   # 只显示前 50 行
bat -r 100: file.py         # 从第 100 行开始

# 显示不可见字符
bat -A file.txt             # 显示制表符、换行符、空格

# 多文件对比
bat --diff file1.py file2.py  # 两个文件的 diff 视图

# 作为 man 的 pager
export MANPAGER="sh -c 'col -bx | bat -l man -p'"
export MANROFFOPT="-c"
bat 配置文件
# ~/.config/bat/config
--theme="TwoDark"
--style="numbers,changes,grid"
--italic-text=always
--map-syntax "*.conf:INI"
--map-syntax ".ignore:Git Ignore"
--map-syntax "*.mdx:Markdown"
eza 完整用法
# 基础列表
eza                         # 彩色文件列表
eza -l                      # 长格式（权限、大小、时间）
eza -la                     # 包含隐藏文件
eza -lah                    # 人类可读大小（默认已启用）

# Git 集成
eza -l --git                # 显示每个文件的 Git 状态
eza -l --git --git-repos    # 显示 Git 仓库级别状态

# 树形视图
eza --tree                  # 完整树形
eza --tree --level=2        # 限制深度
eza --tree --git-ignore     # 树形中忽略 .gitignore 的文件
eza -T -L 3 --icons        # 树形 + 图标 + 3 层深度

# 排序控制
eza -l --sort=modified      # 按修改时间
eza -l --sort=size          # 按文件大小
eza -l --sort=name          # 按名称（默认）
eza -l --sort=extension     # 按扩展名
eza -l --reverse            # 逆序

# 过滤
eza --group-directories-first  # 目录排在前面
eza -l --only-dirs          # 只显示目录
eza -l --only-files         # 只显示文件

# 图标（需要 Nerd Font）
eza --icons                 # 显示文件类型图标
eza --icons=always          # 强制显示图标（即使管道）

# 时间显示
eza -l --time-style=relative    # 相对时间（2 hours ago）
eza -l --time-style=long-iso    # ISO 格式
eza -l --time-style='+%Y-%m-%d' # 自定义格式

# 超链接（现代终端支持）
eza --hyperlink             # 文件名可点击跳转
eza 环境变量配置
# ~/.zshrc 或 ~/.bashrc
export EZA_COLORS="da=36:di=34:fi=37:*.md=33:*.rs=31"
# da=日期颜色, di=目录, fi=普通文件

# 推荐别名
alias ls='eza --color=auto --group-directories-first'
alias ll='eza -l --git --icons --group-directories-first'
alias la='eza -la --git --icons --group-directories-first'
alias lt='eza --tree --level=2 --icons --git-ignore'
alias l.='eza -d .*'  # 只显示隐藏文件
最佳实践
bat 作为通用 pager
# 替代 less 作为默认 pager
export PAGER="bat --style=plain --paging=always"

# 作为 Git diff 的语法高亮引擎（配合 delta 更佳）
# 如果不想安装 delta，可以用 bat：
export BAT_PAGER="less -RF"
git config --global core.pager "bat --style=plain --paging=never"

# help 命令高亮
alias -g -- --help='--help 2>&1 | bat --language=help --style=plain'
# 或创建 bathelp 函数
bathelp() { "$@" --help 2>&1 | bat --plain --language=help; }
管道中的行为控制
# bat 在管道中自动退化为 plain text
bat file.py | head -5       # 等价于 cat file.py | head -5

# 强制保留颜色（传给支持 ANSI 的下游）
bat --color=always file.py | fzf --ansi

# 强制禁用 pager（脚本中使用）
bat --paging=never file.py

# eza 在管道中的行为
eza --color=always | fzf --ansi  # 保留颜色传给 fzf
eza --color=never > file.txt    # 写文件时无颜色

eza 与 bat 配合模式
# fzf 预览使用 bat
fd -t f | fzf --preview 'bat --color=always --line-range :100 {}'

# eza 树形 + bat 预览配合
alias tree-preview='eza --tree --level=2 --icons'
总结
bat 和 eza 是「低投入高回报」的典型工具——通过 alias 替换 cat 和 ls 后，日常操作立即获得视觉增强，而无需改变任何习惯。它们的管道友好设计确保了与现有脚本的完全兼容。深入配置后，bat 可以成为统一的文件查看/语法高亮引擎，eza 可以成为项目结构一览工具。在后续章节中，它们将作为管道中的关键组件，为 fzf 预览窗口、Git diff 可视化等场景提供支持。
