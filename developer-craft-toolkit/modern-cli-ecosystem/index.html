现代终端工具生态 简介

2026 年，Linux/macOS 命令行工具进入「Rust 重构时代」。ripgrep、fd、bat、eza、zoxide、fzf、delta 等新一代工具以更快的速度、更合理的默认配置、更友好的输出格式，逐步取代了 grep、find、cat、ls 等经典 coreutils。Ubuntu 已在 25.10 测试用 Rust 实现的 uutils 替代 GNU coreutils，计划于 26.04 LTS 全面部署。这不再是「尝鲜」，而是正在成为行业标准。

本知识库面向已有基础 CLI 经验、希望系统性升级终端工作流的开发者。我们不只是罗列安装命令，而是深入每款工具的高级用法、配置优化、性能调优，并重点讲解工具之间的组合编排——这才是现代终端生产力的真正来源。

第一章核心命令替代覆盖 fd、ripgrep、bat、eza 四款使用频率最高的工具，从基础用法到高级配置、从性能对比到迁移策略，帮助你建立坚实的工具基础。

第二章导航与搜索聚焦 fzf 和 zoxide——前者是万能模糊查找器，后者是智能目录跳转引擎。掌握这两款工具的高级模式，能让目录切换和文件定位的效率提升数倍。

第三章管道与组合是本知识库的核心章节。Unix 哲学强调「每个工具做好一件事」，而现代工具的真正威力在于它们通过标准输入输出组合成强大的工作流。我们将深入管道设计模式、工具链编排和自定义脚本集成。

第四章终端工作流将前三章所学应用到真实场景：Git 终端工作流（delta + lazygit + fzf）、开发调试流（日志搜索 + 进程管理）、文件管理自动化（批量重命名、归档、清理）。

推荐学习路径：先从第一章建立单工具精通，再进入第二章掌握导航提速，然后在第三章学会组合设计思维，最后在第四章构建完整的个人终端工作流系统。
