实验设计与验证

概述

个人 A/B 测试是量化自我中最具方法论深度的实践——它借鉴了临床试验和互联网产品实验的严谨性，但面对的是「N=1」（被试只有你自己）的独特挑战。传统统计方法假设大量独立样本，而个人实验面对的是高度自相关的时间序列数据、不可避免的安慰剂效应、以及「实验者同时是被试」的天然偏差。本文提供一套适合个人使用的实验设计方法论——从 ABAB 翻转设计到洗脱期设置，从干预强度选择到效果评估统计——让你的每一次生活改变都有充分的证据支持。

核心概念：N-of-1 实验设计

什么是 N-of-1 试验

N-of-1 试验是一种系统化的个案研究方法，在临床医学中用于确定特定治疗对特定个体的效果。其核心特征：

特征 群体实验（RCT） N-of-1 个人实验
被试数量 数百-数千人 1 人（你自己）
外部效度 高（可推广） 低（只适用于你）
内部效度 中（组间变异大） 高（消除个体差异）
统计方法 组间比较 时间序列中断分析
核心控制 随机分组 时间段随机化
盲法 双盲/单盲 自我盲法（困难但可能）

ABAB 翻转设计

最经典的 N-of-1 设计——在干预和基线之间交替切换，验证效果的可重复性：

A₁（基线期1）  → B₁（干预期1）  → A₂（基线期2）  → B₂（干预期2）
   7-14天          7-14天          7-14天          7-14天

如果模式为：A₁ < B₁ > A₂ < B₂
则强烈支持因果关系
应用示例：验证「睡前 30 分钟冥想能否改善深睡时长」


    

  • A₁：两周正常作息（不冥想）
    • 

  • B₁：两周每晚睡前冥想 30 分钟
    • 

  • A₂：两周撤回冥想
    • 

  • B₂：两周恢复冥想
    • 



如果深睡时长在 B 期持续高于 A 期，且撤回后下降、恢复后再次上升，则因果证据非常强。


多基线设计
当干预不可撤回（如学会了某个技能）或撤回不道德（如停止有益的运动习惯）时，使用多基线设计：


# 多基线设计：在不同指标上依次引入干预
# 如果干预对每个指标的影响都在引入时刻出现，则支持因果关系

experiment_plan = {
    "intervention": "每日15分钟Zone 2有氧运动",
    "metrics": [
        {"name": "HRV基线", "start_monitoring": "Day 1", "introduce_at": "Day 8"},
        {"name": "日间精力评分", "start_monitoring": "Day 1", "introduce_at": "Day 8"},
        {"name": "入睡延迟", "start_monitoring": "Day 1", "introduce_at": "Day 8"}
    ],
    "logic": "如果三个指标都在Day 8后开始改善，而非在各自不同时点改善，则支持运动的因果效应"
}
洗脱期设计
很多干预有延迟效应或残留效应。洗脱期（Washout）是 ABAB 设计中至关重要但常被忽视的环节：






干预类型
推荐洗脱期
理由





饮食改变（如断咖啡因）
7-10 天
腺苷受体上调需要约一周

3-5 天
急性运动效应消退

14-21 天

2-3 天

实战指南：个人 A/B 测试方法论
实验设计检查清单
在开始任何个人实验前，过一遍这个清单：


## 实验设计预检清单

### 1. 变量定义

- [ ] 自变量（干预）明确定义，可操作
- [ ] 因变量（结果）有客观测量方式
- [ ] 主要混淆变量已识别并计划控制

### 2. 时间设计

- [ ] 基线期 ≥7 天（数据稳定后才开始干预）
- [ ] 干预期 ≥14 天（给效果足够时间显现）
- [ ] 洗脱期长度合理（如适用）
- [ ] 总时长在可承受范围内

### 3. 测量方案

- [ ] 主要指标可自动采集（不依赖记忆）
- [ ] 备选指标已确定（主指标数据缺失时使用）
- [ ] 数据采集不因实验改变（避免霍桑效应）
- [ ] 主观指标有锚定量表

### 4. 决策规则

- [ ] 成功阈值预先定义（效果量或百分比变化）
- [ ] 停止规则明确（出现不良反应时）
- [ ] 不确定结果的处理方案已定

### 5. 偏差控制

- [ ] 期望效应的缓解措施（如延迟查看数据）
- [ ] 其他生活变化已记录（控制混淆）
- [ ] 基线期足够长以建立稳定参照
干预强度选择
个人实验中一个常见错误是干预强度太弱——导致效果被噪音淹没，无法检测：


信号检测能力 = 效果大小 / 噪音水平

如果你的HRV日间变异(噪音)为 ±8ms
而你预期干预效果为 +3ms
则信噪比 = 3/8 = 0.375（极难检测）

解决方案：
1. 增强干预强度（如从10分钟冥想增加到20分钟）
2. 延长实验期（从14天延长到30天，减小标准误）
3. 选择对干预更敏感的指标
4. 减少生活中的其他变异源
实用规则：如果你预期效果小于个人日间变异的 50%，则至少需要 21 天数据才能有合理的检测力。


依从性追踪
实验的内部效度取决于你实际执行了干预——这在自我实验中并非理所当然：


def compliance_analysis(experiment_log):
    """分析实验依从性"""
    total_days = len(experiment_log)
    compliant_days = sum(1 for day in experiment_log if day['intervention_completed'])
    compliance_rate = compliant_days / total_days

    # 依从性分级
    if compliance_rate >= 0.9:
        quality = "excellent"
        recommendation = "Results are reliable"
    elif compliance_rate >= 0.75:
        quality = "acceptable"
        recommendation = "Results likely valid but effect may be underestimated"
    elif compliance_rate >= 0.5:
        quality = "poor"
        recommendation = "Consider intent-to-treat vs per-protocol analysis"
    else:
        quality = "invalid"
        recommendation = "Experiment invalid. Redesign with lower barrier intervention"

    return {
        'compliance_rate': f"{compliance_rate*100:.0f}%",
        'quality': quality,
        'recommendation': recommendation,
        'missed_days': [d['date'] for d in experiment_log if not d['intervention_completed']]
    }
效果评估方法
个人实验的数据分析不同于群体实验——时间序列的自相关结构需要特殊处理：


方法一：视觉分析（最直观）


适用：效果明显（效果量 > 0.8）时
方法：在时间序列图上标注干预开始/结束时间
     观察是否有明显的水平变化或趋势变化
优点：不依赖统计假设、直觉友好
局限：对小效果不敏感、主观性强
方法二：中断时间序列分析（最严谨）


import statsmodels.api as sm
import numpy as np

def interrupted_time_series(data, intervention_start):
    """中断时间序列回归分析"""
    n = len(data)
    time = np.arange(n)
    intervention = np.array([0 if i < intervention_start else 1 for i in range(n)])
    time_after = np.array([max(0, i - intervention_start) for i in range(n)])

    # 回归模型: Y = β0 + β1*time + β2*intervention + β3*time_after + ε
    X = sm.add_constant(np.column_stack([time, intervention, time_after]))
    model = sm.OLS(data, X).fit()

    return {
        'baseline_trend': model.params[1],      # β1: 干预前的趋势
        'level_change': model.params[2],         # β2: 干预引起的即时水平变化
        'trend_change': model.params[3],         # β3: 干预引起的趋势变化
        'p_values': model.pvalues.tolist(),
        'r_squared': model.rsquared
    }
方法三：Tau-U 非参数效果量


适用：数据非正态、样本量小（<20天）时
计算：比较A期和B期数据对之间的优势比
解读：Tau-U = 0 → 无效果
      Tau-U = 0.5 → 中等效果
      Tau-U = 1.0 → 完美分离（B期所有值都高于A期）

随机化工具
import random
from datetime import datetime, timedelta

def generate_experiment_schedule(start_date, total_days, design="alternating"):
    """生成实验日程随机序列"""
    schedule = []

    if design == "alternating":
        # 交替日设计（适合短效干预）
        sequence = [random.choice(['A', 'B']) for _ in range(total_days)]
        # 确保AB各占约50%
        while abs(sequence.count('A') - sequence.count('B')) > 3:
            sequence = [random.choice(['A', 'B']) for _ in range(total_days)]

    elif design == "block":
        # 区组随机化（每4天一个block，包含2A+2B）
        blocks = total_days // 4
        sequence = []
        for _ in range(blocks):
            block = ['A', 'A', 'B', 'B']
            random.shuffle(block)
            sequence.extend(block)

    for i, condition in enumerate(sequence):
        date = start_date + timedelta(days=i)
        schedule.append({
            'date': date.strftime('%Y-%m-%d'),
            'day': i + 1,
            'condition': condition,
            'weekday': date.strftime('%A')
        })

    return schedule

def plot_ab_experiment(data_a, data_b, metric_name, dates_a, dates_b):
    """AB实验结果可视化"""
    import matplotlib.pyplot as plt
    import numpy as np

    fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 8))

    # 上图：时间序列 + 阶段标注
    all_dates = dates_a + dates_b
    all_values = list(data_a) + list(data_b)
    colors = ['#3B82F6'] * len(data_a) + ['#10B981'] * len(data_b)

    ax1.scatter(range(len(all_values)), all_values, c=colors, s=30)
    ax1.axhline(np.mean(data_a), color='#3B82F6', linestyle='--', label=f'A mean: {np.mean(data_a):.1f}')
    ax1.axhline(np.mean(data_b), color='#10B981', linestyle='--', label=f'B mean: {np.mean(data_b):.1f}')
    ax1.axvline(len(data_a) - 0.5, color='red', linestyle=':', alpha=0.5)
    ax1.set_title(f'{metric_name} - Time Series')
    ax1.legend()

    # 下图：分布比较
    ax2.hist(data_a, alpha=0.5, label=f'Condition A (n={len(data_a)})', color='#3B82F6')
    ax2.hist(data_b, alpha=0.5, label=f'Condition B (n={len(data_b)})', color='#10B981')
    ax2.set_title(f'{metric_name} - Distribution Comparison')
    ax2.legend()

    plt.tight_layout()
    return fig
总结
个人实验设计的核心挑战是在「科学严谨性」和「生活可行性」之间找到平衡。五条实用原则：


    

  1. 一次一个变量：这是最重要也最容易违反的原则。当你同时改变睡眠时间和运动习惯时，无法知道哪个产生了效果。保持耐心，逐个测试
    2. 

  2. 足够长的观察期：短于 14 天的实验几乎不可能产生可靠结论。大多数生理适应需要 7-10 天才开始显现，加上噪音中需要统计力量，14 天是绝对最低限
    3. 

  3. 预注册你的假设：在实验开始前写下具体的成功标准。这防止你事后寻找支持性证据（p-hacking 的个人版本）
    4. 

  4. 接受「无效果」的结论：一个设计良好的实验得出「这个干预对我无效」的结论，价值等同于「有效」——它让你停止浪费时间在无效的事情上
    5. 

  5. 复制你的发现：一次 AB 切换可能是巧合，两次 ABAB 切换（且一致）才是因果证据。对重要的生活决策，值得花 2 个月做一个完整的 ABAB 验证
    6. 



最终记住：你是这场实验的科学家和被试的双重身份。保持科学家的怀疑精神（对任何效果都要求证据），同时接受被试的主观体验（数据无法捕捉的感受也有价值）。
