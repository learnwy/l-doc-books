长期趋势分析

概述

量化自我的大多数价值不在日粒度的波动中，而在月、季、年的长期趋势里——短期数据告诉你「今天怎么了」，长期趋势告诉你「你在变好还是变差」。但长期趋势分析面临独特的挑战：数据中充满了周期性模式（工作日/周末、季节变化）、人生阶段转变（换工作、搬家、生病）、以及设备更换带来的测量漂移。本文提供一套系统方法论——从移动平均到季节性分解，从变点检测到人生阶段分析——帮助你从年度数据中提取对生活方向有指导意义的洞察。

核心概念：时间序列分解

趋势-季节性-残差分解

任何个人时间序列数据都可以分解为三个组成部分：

观测值 = 趋势(Trend) + 季节性(Seasonal) + 残差(Residual)
对个人数据的含义：


    

  • 趋势：你的健康/体能/效率是在缓慢改善还是退化？（最重要的长期信号）
    • 

  • 季节性：工作日 vs 周末模式、冬季 vs 夏季差异、月经周期对女性的影响
    • 

  • 残差：去除趋势和季节后的「纯噪音」——其中可能包含一次性事件的影响
    •

import numpy as np
import pandas as pd

def multi_scale_trend(data, dates):
    """多时间尺度趋势分析"""
    df = pd.DataFrame({'date': dates, 'value': data})
    df = df.set_index('date')

    trends = {
        'raw': df['value'],
        'weekly_trend': df['value'].rolling(7, min_periods=4).mean(),
        'monthly_trend': df['value'].rolling(30, min_periods=20).mean(),
        'quarterly_trend': df['value'].rolling(90, min_periods=60).mean(),
    }

    # 计算趋势方向（最近30天的斜率）
    recent = df['value'].tail(30)
    slope = np.polyfit(range(len(recent)), recent.values, 1)[0]

    trends['direction'] = 'improving' if slope > 0 else 'declining' if slope < 0 else 'stable'
    trends['monthly_change_rate'] = slope * 30  # 每月变化量

    return trends

def detect_seasonality(data, max_period=90):
    """使用自相关检测季节性周期"""
    from statsmodels.tsa.stattools import acf

    autocorr = acf(data, nlags=max_period, fft=True)

    # 寻找自相关函数中的峰值（排除lag=0）
    peaks = []
    for i in range(2, len(autocorr) - 1):
        if autocorr[i] > autocorr[i-1] and autocorr[i] > autocorr[i+1]:
            if autocorr[i] > 0.2:  # 只保留显著的峰值
                peaks.append({'period': i, 'strength': autocorr[i]})

    return sorted(peaks, key=lambda x: x['strength'], reverse=True)
实战指南：变点检测与人生阶段分析
自动变点检测
变点（Change Point）是时间序列中均值或方差突然变化的时刻——在个人数据中，它们通常对应重要的生活事件：


def detect_change_points(data, min_segment_length=14, penalty="BIC"):
    """使用PELT算法检测变点"""
    import ruptures

    # PELT算法：线性时间复杂度的精确变点检测
    model = ruptures.Pelt(model="rbf", min_size=min_segment_length)
    model.fit(np.array(data).reshape(-1, 1))

    # penalty决定了检测敏感度（BIC适合中等长度序列）
    change_points = model.predict(pen=np.log(len(data)) * np.var(data))

    # 为每个变点计算前后均值变化
    results = []
    prev_cp = 0
    for cp in change_points[:-1]:  # 最后一个是序列终点
        before = np.mean(data[max(0, cp-14):cp])
        after = np.mean(data[cp:min(len(data), cp+14)])
        results.append({
            'index': cp,
            'before_mean': round(before, 2),
            'after_mean': round(after, 2),
            'change': round(after - before, 2),
            'percent_change': round((after - before) / before * 100, 1)
        })

    return results

def annotate_trends_with_phases(data, dates, life_phases):
    """将趋势与人生阶段关联"""
    phase_impacts = []

    for phase in life_phases:
        phase_start = pd.Timestamp(phase['start'])
        phase_end = pd.Timestamp(phase['end']) if phase['end'] else dates[-1]

        # 阶段内数据
        mask = (dates >= phase_start) & (dates <= phase_end)
        phase_data = data[mask]

        # 阶段前14天基线
        pre_mask = (dates >= phase_start - pd.Timedelta(days=14)) & (dates < phase_start)
        baseline_data = data[pre_mask]

        if len(phase_data) > 0 and len(baseline_data) > 0:
            change = np.mean(phase_data) - np.mean(baseline_data)
            phase_impacts.append({
                'label': phase['label'],
                'mean_change': round(change, 2),
                'matches_expectation': check_direction(change, phase['expected_impact'])
            })

    return phase_impacts

基线漂移校正
长期追踪面临的一个技术问题是设备更换或固件升级导致的测量漂移：


def correct_device_drift(data, device_change_dates):
    """校正设备更换导致的测量漂移"""
    corrected = data.copy()

    for change_date in device_change_dates:
        # 取更换前后各7天的数据
        idx = data.index.get_loc(change_date, method='nearest')
        before = data.iloc[max(0, idx-7):idx].mean()
        after = data.iloc[idx:min(len(data), idx+7)].mean()

        # 计算偏移量
        offset = after - before

        # 如果偏移量显著（>1σ），对后续数据进行校正
        if abs(offset) > data.std() * 0.5:
            corrected.iloc[idx:] -= offset
            print(f"Corrected drift at {change_date}: offset = {offset:.2f}")

    return corrected
常见漂移来源：


    

  • 更换手表品牌（光学心率传感器算法差异）
    • 

  • 固件更新改变睡眠分期算法（如 Oura Gen 3 → Gen 4）
    • 

  • 戒指/手表佩戴位置变化
    • 

  • 体重大幅变化影响传感器贴合度

同比分析（Year-over-Year）
同比分析消除了季节性影响，直接展示「今年的我比去年的我好了多少」：


def year_over_year_comparison(current_year, previous_year, metric_name):
    """年同比分析"""
    # 按月聚合对比
    current_monthly = current_year.resample('M').mean()
    previous_monthly = previous_year.resample('M').mean()

    comparison = []
    for month in range(1, 13):
        curr = current_monthly[current_monthly.index.month == month]
        prev = previous_monthly[previous_monthly.index.month == month]

        if len(curr) > 0 and len(prev) > 0:
            change = curr.values[0] - prev.values[0]
            pct_change = change / prev.values[0] * 100
            comparison.append({
                'month': month,
                'current': round(curr.values[0], 1),
                'previous': round(prev.values[0], 1),
                'change': round(change, 1),
                'pct_change': f"{pct_change:+.1f}%"
            })

    # 全年汇总
    overall_change = current_year.mean() - previous_year.mean()
    overall_pct = overall_change / previous_year.mean() * 100

    return {
        'monthly_comparison': comparison,
        'annual_summary': {
            'metric': metric_name,
            'direction': 'improved' if overall_change > 0 else 'declined',
            'magnitude': f"{overall_pct:+.1f}%",
            'best_improvement_month': max(comparison, key=lambda x: x['change'])['month']
        }
    }
预测与目标设定
基于历史趋势进行简单的外推预测，辅助目标设定：


def trend_forecast(data, forecast_days=90, confidence=0.8):
    """基于历史趋势的简单外推预测"""
    # 使用最近90天数据拟合线性趋势
    recent = data.tail(90)
    x = np.arange(len(recent))
    slope, intercept = np.polyfit(x, recent.values, 1)

    # 预测未来
    future_x = np.arange(len(recent), len(recent) + forecast_days)
    prediction = slope * future_x + intercept

    # 基于历史残差估算预测区间
    residuals = recent.values - (slope * x + intercept)
    residual_std = np.std(residuals)

    # Z值对应置信度
    from scipy import stats
    z = stats.norm.ppf((1 + confidence) / 2)

    return {
        'predicted_values': prediction,
        'upper_bound': prediction + z * residual_std,
        'lower_bound': prediction - z * residual_std,
        'monthly_rate': slope * 30,
        'days_to_goal': None  # 可以设置具体目标值来计算
    }

总结
长期趋势分析是量化自我中最需要耐心但也最有回报的实践。它将你从「每天看数据」的短视模式提升到「每季度审视人生方向」的战略视角。核心要点：


    

  1. 多时间尺度同时观察：7 天趋势看战术调整、30 天趋势看习惯效果、90 天趋势看阶段性进步、365 天趋势看人生方向。不要只盯着一个尺度
    2. 

  2. 分离趋势与季节性：冬天深睡天然增加不代表你「更健康了」——必须去除季节效应后才能判断真正的改善。同比分析是最简单的去季节方法
    3. 

  3. 标注人生阶段：数据脱离上下文毫无意义。在时间线上标注重大生活事件（换工作、搬家、开始新训练计划），让趋势变化有可解释的归因
    4. 

  4. 接受非线性进步：健康和体能的改善不是线性的——通常是平台期→突破→新平台期的阶梯模式。不要因为一个月没进步就怀疑策略
    5. 

  5. 保护你的数据资产：3 年的连续个人数据是无价的（字面意义上不可重新获取）。投入适当的备份策略保护它
    6. 



最终目标：当你在 2029 年回看 2026 年的数据时，你能清晰地看到自己健康、效率和幸福感的演进轨迹——知道哪些决策带来了改善，哪些阶段需要应对挑战——这就是长期趋势分析的终极价值：为你的人生提供导航仪，而非后视镜。
