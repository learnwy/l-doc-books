Apple Shortcuts 高级用法

概述

Apple Shortcuts（快捷指令）在 2026 年已经从一个简单的自动化工具演变为苹果生态系统中最强大的用户可编程平台。iOS/iPadOS 26 和 macOS Tahoe 26 带来了革命性更新：Apple Intelligence 原生集成的 "Use Model" 动作允许直接调用设备端 AI 模型，macOS 首次支持基于文件夹变更、蓝牙连接等事件的个人自动化触发器，以及 Control Centre 中的快捷指令控件。

与第三方自动化工具不同，Shortcuts 的核心优势是它对苹果生态系统的完全系统级访问权限——从健康数据到 HomeKit 设备，从 Apple Intelligence 到隐私处理，没有任何第三方工具能达到相同深度。

核心概念

Shortcuts 执行模型

Shortcuts 使用 Content Graph Engine 作为其执行引擎。这意味着数据在动作之间不是简单的线性传递，而是通过一个图结构来解析依赖：

动作执行流：
Input → Get Action → Transform Action → Share Action → Output

数据流机制：
- Magic Variables: 任何动作的输出都可被后续动作引用
- Content Type Coercion: 自动类型转换（图片→文件、URL→网页等）
- Ask Each Time: 运行时动态获取输入

实战指南

智能晨间 Briefing 自动化

触发：每天闹钟关闭后自动运行

流程设计：

1. Get Calendar Events (Today)
2. Get Current Weather
3. Get Reminders (Due Today)
4. If (Precipitation Chance > 50%)
   → Set variable: weatherAlert = "bring umbrella"
5. Use Model (Summarize):
   "Create a morning briefing from these events:
    Calendar: [events], Weather: [weather], Tasks: [reminders]"
6. Speak Text (AI Summary)
7. If (calendar has meeting before 9am)
   → Send Message to commute group: "Heading out early"

关键技巧：

  • 使用 Run Immediately 选项让自动化无需确认即执行
  • Use Model 动作的 AI 摘要比手动拼接文本更自然
  • 添加 If 条件让行为根据上下文智能调整

文件系统自动化（macOS 新能力）

场景：Documents 文件夹中新增文件时，按类型自动分类

Trigger: Folder (~/Documents, when files are added)

1. Get Type of [Shortcut Input]
2. If (type is PDF)
   → Move File to ~/Documents/PDFs/
3. Otherwise If (type is Image)
   → Move File to ~/Documents/Images/
4. Otherwise If (type is Spreadsheet)
   → Move File to ~/Documents/Spreadsheets/
5. Otherwise
   → Move File to ~/Documents/Unsorted/
6. Show Notification: "Filed: [filename] → [folder]"

跨设备联动场景

场景：Mac 连接外接显示器 → 自动设置工作环境

Trigger: Display (when external display connects)

1. Set Focus: Work (Turn On)
2. Run Shell Script:
   "open -a 'Arc' && open -a 'VS Code' && open -a 'Slack'"
3. Set System Appearance: Dark
4. Control Home: Set Scene "Office Lighting"
5. Open URL: "raycast://extensions/..."  # 触发 Raycast 窗口布局

高级 URL Scheme 集成

Shortcuts 通过 URL Scheme 与第三方应用深度集成：

# 触发 Raycast 扩展
raycast://extensions/author/extension/command?args=value

# 触发 Obsidian 操作
obsidian://new?vault=MyVault&name=Note&content=Text

# 触发 Things 快速添加
things:///add?title=Task&notes=Details&when=today

# 触发 Bear 创建笔记
bear://x-callback-url/create?title=Title&text=Content

最佳实践

快捷指令设计原则

  1. 单一职责：一个快捷指令解决一个具体问题
  2. 优雅降级：如果某个动作失败（如网络不可用），有备选路径
  3. 用户反馈：关键步骤后显示通知或横幅确认
  4. 变量命名：使用有意义的变量名（Magic Variables 重命名）
  5. 注释：在复杂流程中使用 Comment 动作说明意图

性能优化

  • 减少 HTTP 请求：合并多个 API 调用为一个（如果 API 支持批量）
  • 条件提前退出：在流程早期用 If 判断是否需要继续
  • 避免大数据循环：Repeat with Each 对大数据集很慢，优先用 Find/Filter
  • 缓存策略：将不变数据存入 Data Jar 或文件系统

安全与隐私

  • Private Sharing：通过 iCloud 链接而非公开链接分享快捷指令
  • 敏感数据：API Key 存储在 Shortcuts 的 Dictionary 中而非硬编码
  • 权限最小化：只请求必要的权限（位置、健康、照片等）
  • Apple Intelligence 隐私：大多数 AI 处理在设备端完成，不上传云端

macOS 特有能力

  • Shell Script 动作：直接执行 bash/zsh 命令
  • AppleScript 动作：调用任何支持 AppleScript 的应用
  • Spotlight 集成：从 Spotlight 搜索中直接运行快捷指令并传递选中文本
  • Control Centre：将快捷指令添加到 Control Centre 和菜单栏

总结

Apple Shortcuts 在 2026 年的定位已经从"简单自动化"升级为苹果生态的可编程自动化平台。Apple Intelligence 集成让快捷指令具备了理解自然语言和生成内容的能力，macOS 的文件触发器和系统事件则填补了桌面自动化的空白。核心收获：

  1. 自动化触发器是 Shortcuts 最有价值的能力——让操作"主动发生"而非等待触发
  2. Use Model 动作将 AI 能力无缝嵌入任何自动化流程
  3. URL Scheme 是连接 Shortcuts 与第三方应用的万能桥梁
  4. macOS 的 Shell Script 动作让 Shortcuts 拥有了完整的命令行能力
  5. 隐私保护是苹果自动化的独特优势——大部分 AI 处理完全在设备端完成
