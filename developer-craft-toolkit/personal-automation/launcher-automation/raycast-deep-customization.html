Raycast 深度定制

概述

Raycast 是 macOS 平台上最具开发者友好性的启动器工具。它不仅是 Spotlight 的替代品，更是一个基于 React + TypeScript 构建的可编程平台。截至 2026 年，Raycast Store 已拥有超过 1000 个社区扩展，覆盖从 GitHub 集成到 AI 对话的方方面面。与传统启动器相比，Raycast 的核心优势在于：原生级的 UI 组件系统、完整的 Node.js 运行时、以及与系统深度集成的 API 层。

本文将带你从扩展开发的技术架构出发，深入掌握 Raycast 作为个人自动化中枢的全部能力。

核心概念

扩展架构模型

Raycast 扩展本质上是运行在沙箱环境中的 React 应用，但渲染目标不是 DOM 而是 Raycast 的原生 UI 层：

┌─────────────────────────────────────┐
│         Raycast 应用窗口             │
├─────────────────────────────────────┤
│  原生 UI 渲染层 (List/Grid/Form)    │
├─────────────────────────────────────┤
│  @raycast/api React 组件层          │
├─────────────────────────────────────┤
│  Node.js 运行时 (扩展代码)          │
├─────────────────────────────────────┤
│  系统 API (剪贴板/通知/文件系统)     │
└─────────────────────────────────────┘

每个扩展可以包含多个 Command，每个 Command 对应一个独立的入口文件。Command 类型包括：

  • View Command：渲染 List、Detail、Grid 或 Form 界面
  • No-View Command：无 UI 执行，适合快速操作（复制、打开 URL 等）
  • Menu Bar Command：常驻菜单栏的状态指示器

组件系统

@raycast/api 提供的核心组件：

组件 用途 典型场景
List 可搜索列表 搜索仓库、任务列表
Grid 网格布局 图标选择、颜色面板
Detail Markdown 详情 文档预览、代码片段
Form 表单输入 创建任务、配置设置
ActionPanel 操作菜单 上下文操作集合

数据与状态管理

Raycast 扩展的状态管理分为三个层级：

  1. React State：组件内部状态，生命周期与界面一致
  2. LocalStorage：持久化的键值存储，跨会话保留
  3. Cache：带 TTL 的缓存层，适合 API 响应
import { LocalStorage, Cache } from '@raycast/api';

// 持久存储
await LocalStorage.setItem('lastQuery', searchText);

// 带过期的缓存
const cache = new Cache();
cache.set('repos', JSON.stringify(repos), { ttl: 300_000 });

从零创建一个扩展

环境准备

# 确保 Node.js 16+ 已安装
node --version

# 通过 Raycast 内置命令创建（推荐）
# 打开 Raycast → 搜索 "Create Extension" → 选择模板

# 或使用 CLI
npx create-raycast-extension my-extension

项目结构

my-extension/
├── src/
│   ├── index.tsx          # 主命令
│   ├── search.tsx         # 搜索命令
│   └── utils/
│       └── api.ts         # 共享工具
├── assets/                # 图标资源
├── package.json           # 元数据 + Raycast 配置
└── tsconfig.json

开发一个 Git 仓库搜索器

import { List, ActionPanel, Action, Icon } from "@raycast/api";
import { useFetch } from "@raycast/utils";
import { useState } from "react";

interface Repository {
  name: string;
  full_name: string;
  html_url: string;
  description: string;
  stargazers_count: number;
}

export default function SearchRepos() {
  const [query, setQuery] = useState("");

  const { data, isLoading } = useFetch<{ items: Repository[] }>(
    `https://api.github.com/search/repositories?q=${encodeURIComponent(query)}`,
    { execute: query.length > 0 }
  );

  return (
    <List
      isLoading={isLoading}
      searchBarPlaceholder="Search GitHub repositories..."
      onSearchTextChange={setQuery}
      throttle
    >
      {data?.items.map((repo) => (
        <List.Item
          key={repo.full_name}
          title={repo.full_name}
          subtitle={repo.description}
          accessories={[{ text: `⭐ ${repo.stargazers_count}` }]}
          actions={
            <ActionPanel>
              <Action.OpenInBrowser url={repo.html_url} />
              <Action.CopyToClipboard content={repo.html_url} />
            </ActionPanel>
          }
        />
      ))}
    </List>
  );
}

发布到 Store

发布流程核心步骤：

  1. 验证构建：npm run build 确保无类型错误
  2. 检查元数据：package.json 中 author、license（MIT）、categories 字段
  3. 截图规范：提供 1270×760px 的截图，展示核心功能
  4. 发布命令：npm run publish 自动创建 PR 到 raycast/extensions

命名规范遵循 Apple Style Guide：首字母大写，品牌名保持原样（如 GitHub, macOS）。

最佳实践

性能优化

  • 使用 useFetch hook 代替手动 useEffect + fetch，自动处理加载态和缓存
  • 开启 throttle 属性避免搜索时过度请求
  • 利用 isLoading prop 给用户即时反馈，避免空白界面
  • 缓存 API 响应：对不频繁变化的数据使用 Cache API

用户体验设计

  • Empty State：列表为空时提供有意义的提示而非空白
  • Error Handling：用 showToast() 展示友好错误信息，避免崩溃
  • Action 优先级：最常用操作放在 ActionPanel 第一位（回车直接触发）
  • Keyboard Shortcuts：为高频操作分配 ⌘+K 等快捷键

TypeScript 严格模式

{
  "compilerOptions": {
    "strict": true,
    "noUncheckedIndexedAccess": true
  }
}

严格模式能在编译期捕获大量运行时错误，特别是处理 API 响应时的 undefined 访问。

AI 能力集成

Raycast Pro 提供内置 AI 能力，扩展可以通过 AI API 访问：

import { AI } from '@raycast/api';

const summary = await AI.ask(`Summarize this text: ${selectedText}`, { creativity: 0.5 });

这使得扩展可以内建智能摘要、翻译、代码解释等能力，无需自行接入 LLM API。

总结

Raycast 的扩展开发是目前 macOS 生态中将"想法变为快捷操作"最高效的路径。它的 React + TypeScript 技术栈对前端开发者零门槛，原生 UI 组件避免了样式调试的负担，Hot Reload 开发体验与现代 Web 开发一致。关键要点：

  1. 从 create-raycast-extension 开始，选择最接近需求的模板
  2. 优先使用 @raycast/utils 的 hooks 而非手动状态管理
  3. 严格遵循 Store 发布规范，特别是命名和截图要求
  4. 利用 Cache API 和 LocalStorage 平衡响应速度与数据新鲜度
  5. 将高频操作设计为 No-View Command 以获得最快响应
