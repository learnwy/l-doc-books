Homebrew 深度实践

概述

Homebrew 是 macOS 事实上的包管理器，被称为"macOS 缺失的包管理器"。2026 年，随着 Apple Silicon 全线成熟和 Homebrew 4.x 的发布，几乎所有开发工具都以预编译 bottle 的形式提供 ARM 原生支持，安装速度从"编译数十分钟"缩短到"下载数秒"。掌握 Homebrew 的深度用法，是高效管理 macOS 开发环境的基础。

本文从安装机制讲到日常维护策略，涵盖 Formula/Cask 选型、Brewfile 声明式管理、性能优化和疑难排查。

实战指南
安装与初始配置
# 安装 Homebrew（Apple Silicon Mac）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 配置 PATH（添加到 ~/.zprofile）
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

# 验证安装
brew --version
brew doctor  # 检查潜在问题
日常操作命令
# 搜索包
brew search ripgrep

# 查看包信息
brew info ripgrep

# 安装
brew install ripgrep          # CLI 工具
brew install --cask ghostty   # GUI 应用

# 列出已安装
brew list                     # 全部
brew list --formula           # 仅 CLI
brew list --cask              # 仅 GUI

# 更新 Homebrew 自身的 formula 索引
brew update

# 升级已安装的包
brew upgrade                  # 全部升级
brew upgrade ripgrep          # 指定包

# 卸载
brew uninstall ripgrep
brew uninstall --cask ghostty

# 查看可升级的包
brew outdated
Brewfile 声明式环境管理
Brewfile 是 Homebrew 的声明式配置文件，类似于 package.json 对于 Node.js 的作用：


# ~/dotfiles/Brewfile

# === Taps ===
tap "homebrew/bundle"
tap "nikitabobko/tap"  # Aerospace 窗口管理器

# === CLI 必备工具 ===
brew "git"
brew "gh"              # GitHub CLI
brew "stow"            # Dotfiles 管理
brew "starship"        # Shell 提示符
brew "mise"            # 运行时版本管理

# === 现代 CLI 替代品 ===
brew "eza"             # 替代 ls
brew "bat"             # 替代 cat
brew "fd"              # 替代 find
brew "ripgrep"         # 替代 grep
brew "fzf"             # 模糊搜索
brew "zoxide"          # 智能 cd
brew "delta"           # 替代 diff
brew "dust"            # 替代 du
brew "btop"            # 替代 top
brew "httpie"          # 替代 curl
brew "jq"              # JSON 处理
brew "yq"              # YAML 处理
brew "tldr"            # 替代 man

# === 开发工具 ===
brew "neovim"
brew "tmux"
brew "lazygit"
brew "docker-compose"

# === 语言运行时（通过 mise 管理版本，这里装最新稳定版） ===
brew "node"
brew "python@3.13"
brew "go"
brew "rust"

# === GUI 应用 ===
cask "ghostty"
cask "visual-studio-code"
cask "raycast"
cask "1password"
cask "docker"
cask "firefox"
cask "aerospace"       # 平铺窗口管理

# === 字体 ===
cask "font-jetbrains-mono-nerd-font"
cask "font-fira-code-nerd-font"
Brewfile 操作：


# 从当前安装生成 Brewfile
brew bundle dump --file=~/dotfiles/Brewfile --force

# 从 Brewfile 安装所有内容
brew bundle install --file=~/dotfiles/Brewfile

# 检查哪些包不在 Brewfile 中（清理依据）
brew bundle cleanup --file=~/dotfiles/Brewfile

# 实际执行清理
brew bundle cleanup --file=~/dotfiles/Brewfile --force
性能优化
# 并行下载（加速 brew upgrade）
export HOMEBREW_CURL_RETRIES=3

# 关闭自动更新（每次 install 前不自动 brew update）
export HOMEBREW_NO_AUTO_UPDATE=1

# 定期手动更新
brew update && brew upgrade

# 清理磁盘空间
brew cleanup              # 删除旧版本缓存
brew cleanup --prune=7    # 保留 7 天内的缓存
brew autoremove           # 删除不再需要的依赖

# 检查磁盘占用
brew --cache              # 缓存目录
du -sh $(brew --cache)    # 缓存大小
du -sh /opt/homebrew      # Homebrew 总占用
多版本管理
# 安装特定版本
brew install python@3.11
brew install python@3.13

# 查看已安装版本
brew list --versions python

# 切换默认版本（通过 link/unlink）
brew unlink python@3.13
brew link python@3.11

# 推荐：使用 mise 管理语言版本而非 Homebrew

常见问题排查




问题
解决方案





brew doctor 报警告
按提示逐条修复，大部分是 PATH 顺序问题




安装卡住
检查网络，设置 HOMEBREW_CURL_RETRIES=5




Permission denied
修复权限：sudo chown -R $(whoami) /opt/homebrew




依赖冲突
brew deps --tree <pkg> 查看依赖链




Cask 更新失败
brew reinstall --cask <app> 强制重装

总结
Homebrew 从"安装工具的工具"升级为完整的环境管理方案，关键在于两个实践：一是用 Brewfile 将安装状态声明化，使环境可复现；二是建立定期维护节奏，保持系统整洁和安全。结合 dotfiles 仓库中的 Brewfile 管理和 bootstrap 脚本中的 brew bundle install，你可以在任何新 Mac 上用一条命令恢复完整的工具生态。
