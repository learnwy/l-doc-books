窗口管理器选型与配置

概述

macOS 原生的窗口管理体验——手动拖拽调整大小、Mission Control 切换桌面——对于需要同时操作终端、编辑器、浏览器、文档的开发者来说效率不足。平铺式窗口管理器（Tiling Window Manager）通过自动化布局和键盘驱动操作，将窗口管理从"鼠标操作"转变为"意念到达"。2026 年 macOS 平台上有多款成熟方案可选，各有哲学和适用场景。

本文对比主流窗口管理方案，提供选型决策框架和核心配置实战。

核心概念

窗口管理范式

范式 代表工具 理念
手动平铺 macOS 原生、Magnet 用户主动触发布局，简单直观
自动平铺 Aerospace、yabai 窗口自动填充空间，类 i3wm
功能启动器集成 Raycast 窗口管理作为启动器的附加能力
脚本驱动 Hammerspoon 完全可编程，无限灵活

选型决策

核心术语
    

  • Workspace/Space：虚拟桌面，每个空间包含一组窗口
    • 

  • Layout：窗口排列算法（tall、wide、grid、stack 等）
    • 

  • Focus：当前活动窗口
    • 

  • BSP (Binary Space Partition)：二叉空间分割，yabai 的默认布局算法
    • 



实战指南
Aerospace 配置
Aerospace 是 2024 年发布的新一代 macOS 平铺窗口管理器，以稳定性和 Apple 生态兼容为设计目标，不需要关闭 SIP：


# 安装
brew install --cask aerospace
配置文件 ~/.aerospace.toml：


# ~/.aerospace.toml

# 启动时自动执行
after-login-command = []
after-startup-command = []

# 主修饰键（Alt 键不与系统冲突）
[mode.main.binding]
# 焦点切换
alt-h = 'focus left'
alt-j = 'focus down'
alt-k = 'focus up'
alt-l = 'focus right'

# 窗口移动
alt-shift-h = 'move left'
alt-shift-j = 'move down'
alt-shift-k = 'move up'
alt-shift-l = 'move right'

# 工作区切换
alt-1 = 'workspace 1'
alt-2 = 'workspace 2'
alt-3 = 'workspace 3'
alt-4 = 'workspace 4'

# 窗口移到其他工作区
alt-shift-1 = 'move-node-to-workspace 1'
alt-shift-2 = 'move-node-to-workspace 2'
alt-shift-3 = 'move-node-to-workspace 3'

# 布局切换
alt-slash = 'layout tiles horizontal vertical'
alt-comma = 'layout accordion horizontal vertical'
alt-f = 'fullscreen'

# 调整大小
alt-shift-minus = 'resize smart -50'
alt-shift-equal = 'resize smart +50'

# === 窗口规则 ===
[[on-window-detected]]
if.app-id = 'com.apple.finder'
run = 'layout floating'

[[on-window-detected]]
if.app-id = 'com.apple.systempreferences'
run = 'layout floating'
yabai + skhd 配置
yabai 是功能最强大的 macOS 平铺管理器，但需要关闭 SIP 才能使用全部功能：


# 安装
brew install koekeishiya/formulae/yabai
brew install koekeishiya/formulae/skhd

# 启动服务
yabai --start-service
skhd --start-service
yabai 配置 ~/.yabairc：


#!/usr/bin/env bash
# ~/.yabairc

# 布局模式
yabai -m config layout bsp

# 窗口间距
yabai -m config top_padding    8
yabai -m config bottom_padding 8
yabai -m config left_padding   8
yabai -m config right_padding  8
yabai -m config window_gap     8

# 焦点跟随鼠标
yabai -m config focus_follows_mouse autofocus

# 窗口透明度
yabai -m config window_opacity on
yabai -m config active_window_opacity 1.0
yabai -m config normal_window_opacity 0.95

# 浮动窗口规则
yabai -m rule --add app="System Preferences" manage=off
yabai -m rule --add app="Calculator" manage=off
yabai -m rule --add app="1Password" manage=off
yabai -m rule --add app="Finder" title="Info" manage=off
skhd 快捷键配置 ~/.skhdrc：


# ~/.skhdrc

# 焦点切换
alt - h : yabai -m window --focus west
alt - j : yabai -m window --focus south
alt - k : yabai -m window --focus north
alt - l : yabai -m window --focus east

# 窗口交换位置
shift + alt - h : yabai -m window --swap west
shift + alt - l : yabai -m window --swap east

# 工作区切换
alt - 1 : yabai -m space --focus 1
alt - 2 : yabai -m space --focus 2
alt - 3 : yabai -m space --focus 3

# 窗口移到其他工作区
shift + alt - 1 : yabai -m window --space 1
shift + alt - 2 : yabai -m window --space 2

# 切换布局
alt - e : yabai -m space --layout bsp
alt - s : yabai -m space --layout stack

# 全屏
alt - f : yabai -m window --toggle zoom-fullscreen
Raycast 窗口管理
如果已经在用 Raycast 作为启动器，其内置窗口管理足够日常使用：


Raycast Settings > Extensions > Window Management

推荐快捷键映射：
- 左半屏：Ctrl+Option+←
- 右半屏：Ctrl+Option+→
- 最大化：Ctrl+Option+↑
- 还原：Ctrl+Option+↓
- 左上角：Ctrl+Option+U
- 右上角：Ctrl+Option+I
- 左下角：Ctrl+Option+J
- 右下角：Ctrl+Option+K

总结
窗口管理器的核心价值是将"移动手到鼠标 → 瞄准窗口边缘 → 拖拽调整"这个数秒的操作缩短为一个快捷键的瞬间完成。对于大多数 macOS 开发者，Aerospace 是 2026 年的最佳起点——不需要关闭 SIP、TOML 配置简洁、与系统兼容性好。当需求超过 Aerospace 的能力范围（如窗口透明度控制、复杂的显示器规则）时，再迁移到 yabai。关键原则是：先小范围使用（焦点切换和工作区）建立肌肉记忆，再逐步扩展快捷键体系。
