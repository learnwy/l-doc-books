三年级艺术 — 水彩画

知识要点

水彩画是用水调和颜料在纸上作画的绘画方式。水彩画最大的特点是"透明"——颜料薄薄地铺在纸上，光线可以穿过颜料层反射回来，呈现出清新、通透、明亮的效果。水彩画是世界上最受欢迎的绘画形式之一，也是同学们最容易上手的绘画方式。

水彩画的基本工具：

工具 说明 选择建议
水彩颜料 固体水彩或管状水彩 初学者用12色固体水彩即可
水彩笔 圆头笔、扁头笔 准备大中小三支即可
水彩纸 专用纸张，吸水性好 选择200克以上的水彩纸
调色盘 用来混合颜色 白色的瓷盘或塑料盘
水桶 涮笔和调水 准备两个：一个涮笔，一个取干净水
纸巾/抹布 吸去多余水分 随时准备在手边

详细讲解

认识水彩颜料

水彩颜料的特别之处在于它是"透明"的。和蜡笔、油画棒不同，水彩颜料加了水之后变得很薄，涂在白纸上可以透出纸的白色。所以水彩画中白色的部分通常不是用白色颜料画的，而是留出白纸不涂色。

基本色彩知识——三原色和混色：

混色公式 结果
红 + 黄 橙色
红 + 蓝 紫色
黄 + 蓝 绿色
红 + 黄 + 蓝 接近黑色（暗褐色）

有了红、黄、蓝三种颜色（三原色），理论上可以调出几乎所有的颜色。在实际画画时，多加水颜色就变浅，少加水颜色就变深。

水彩画的基本技法

平涂法： 最基础的技法。用水把颜料调匀，用笔均匀地涂在纸上，形成一片平整的颜色。练习平涂可以帮助你控制用水量和笔的力度。

要点：

  • 笔上的水量要适中——太多会流淌，太少颜色不均匀
  • 从上往下一笔接一笔地涂，每一笔和上一笔微微重叠
  • 保持同一个方向，速度均匀

渐变法： 让颜色从深到浅（或从一种颜色过渡到另一种颜色）自然变化。

做法：

  1. 先涂一笔深色
  2. 笔在水里涮一下，不要擦干
  3. 接着涂下一笔（颜色自然变浅了）
  4. 重复这个过程，颜色会越来越浅

渐变法可以用来画天空（从深蓝到浅蓝）、落日（从橙红到黄色）等效果。

湿画法： 先用清水把纸打湿，再在湿润的纸面上画颜色。颜料会在湿纸上自然晕染开来，产生梦幻般的柔和效果。

适合画的主题：朦胧的远山、雾气、花瓣的柔和边缘

干画法： 在干燥的纸面上用较少水分的笔来画。笔触清晰可见，线条有质感。

适合画的主题：树皮的纹理、动物的毛发、建筑的轮廓

留白法： 水彩画中最亮的部分就是白纸本身。画之前要想好哪些地方需要留白（不涂色），用铅笔轻轻标记出来。比如画阳光下的景物，阳光照射的那一面就留白或只涂很淡的颜色。

水彩画的步骤

画一幅完整的水彩画通常按照以下步骤：

  1. 构思：想好要画什么，可以先在草稿纸上画小草图
  2. 铅笔起稿：用铅笔在水彩纸上轻轻画出轮廓线（不要太重，否则擦不掉）
  3. 从浅到深：先画最浅的颜色，再一层一层加深。因为水彩是透明的，深色可以盖住浅色，但浅色盖不住深色
  4. 从远到近：先画远处的背景（天空、远山），再画近处的主体
  5. 添加细节：最后用小笔或浓颜色画树枝、花纹等细节
  6. 干燥：让作品自然晾干，不要用手摸湿的画面

常见问题和解决方法

问题 原因 解决方法
颜色不均匀有水痕 用水量不一致 每一笔水量保持相近
两种颜色混在一起变脏 没等上一层干就画下一层 等前一层完全干了再画
纸皱了起来 纸太薄或水太多 用较厚的水彩纸，控制用水量
颜色画不深 水太多颜料太少 少加水，多蘸颜料

试着画一幅简单的风景画

让我们一起画一幅"夕阳下的大海"：

  1. 用铅笔在纸的中间偏下画一条水平线（海平面）
  2. 天空部分：先用清水打湿纸面，然后在最上方涂深蓝色，往下逐渐加橙色和黄色（渐变法），在太阳的位置留白
  3. 等天空完全干了
  4. 海面部分：用深蓝色加一点绿色，画出海面。可以留一些白色横线表示波光
  5. 用橙黄色在海面画几道反光
  6. 最后可以用深色画一两只海鸥的剪影

练习与思考

  1. 调色练习：用红、黄、蓝三原色，尝试调出橙色、绿色、紫色。再试着调出棕色和灰色。把每种颜色涂在纸上做一个"色卡"。

  2. 技法练习：

    • 画三个相同大小的方块，分别用平涂法、渐变法、湿画法来填色
    • 感受三种技法效果的不同

  3. 填空题：

    • 水彩画的三原色是______、和。
    • 水彩画应该从______色开始画，再逐渐加______。
    • 水彩画中最亮的白色来自______本身。

  4. 思考题：为什么水彩画要"从浅到深"地画？如果先画深色再画浅色会怎样？

  5. 创作练习：画一幅简单的水彩画。可以画水果（苹果、橙子）、花朵或简单的风景。注意运用学过的技法。

拓展阅读

水彩画起源于欧洲，在18-19世纪的英国达到鼎盛。英国画家透纳是水彩画的大师，他用水彩画出了壮丽的海景和天空，色彩变幻莫测，让人仿佛身临其境。

中国画中的"水墨画"和水彩画有异曲同工之妙——都是用水调和颜料（墨），在纸上产生丰富的浓淡变化。不同的是，水墨画主要用毛笔和宣纸，更注重笔墨的韵味和意境。

现代水彩画的应用非常广泛。很多插画师用水彩画绘本和童话书的插图，时装设计师用水彩画设计稿，建筑师用水彩画建筑效果图。学好水彩画，你就掌握了一种用色彩表达想法和感受的方式。

小结

本节课我们学习了水彩画的基础知识。水彩画的特点是透明清新，需要的工具包括水彩颜料、水彩笔、水彩纸、调色盘和水桶。基本技法有平涂法、渐变法、湿画法、干画法和留白法。画水彩画要遵循"从浅到深、从远到近"的顺序。掌握了三原色的调色原理，就能调出丰富多彩的颜色。多多练习，你就能用水彩画出美丽的作品。
