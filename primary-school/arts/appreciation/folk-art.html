一年级艺术 — 民间艺术

中国是一个有着几千年历史的文明古国，我们的祖先用智慧和巧手创造了很多美丽的民间艺术。剪窗花、看皮影戏、贴年画……这些有趣的艺术形式一代一代传了下来，直到今天依然受到大家的喜爱。今天，让我们一起走进民间艺术的大门，感受中国传统文化的魅力！

知识要点

什么是民间艺术

民间艺术是老百姓在日常生活中创造出来的艺术。它不是在美术馆里展出的高雅画作，而是普通人用自己的双手，利用身边的材料做出来的美丽作品。

民间艺术的特点：

  • 历史悠久：很多民间艺术有上千年的历史。
  • 来自生活：材料都是身边常见的纸、泥、布、面粉等。
  • 代代相传：手艺从爷爷奶奶传给爸爸妈妈，再传给孩子。
  • 寓意美好：作品常常表达吉祥、幸福、丰收等美好愿望。

常见的民间艺术

民间艺术 主要材料 特点 常见场合
剪纸 红纸、剪刀 用剪刀剪出各种图案 过年贴窗花
皮影戏 皮革、灯光 用灯光照出影子表演故事 节日庆典
年画 木板、颜料、纸 色彩鲜艳的吉祥画 过年张贴
泥塑 泥巴、颜料 捏出各种人物和动物 庙会、集市
面人 面粉、颜料 捏出彩色的小人 庙会、集市
糖画 糖浆 用糖浆画出各种图案 庙会、街头

详细讲解

剪纸——剪出来的花世界

剪纸是中国最有代表性的民间艺术之一，已经被联合国列为"世界非物质文化遗产"。

剪纸的历史：

中国的剪纸有一千五百多年的历史。古时候，人们在过年的时候用红纸剪出各种吉祥的图案，贴在窗户上，叫做"窗花"。窗花让原本普通的窗户变得漂亮起来，也为新年增添了喜庆的气氛。

剪纸的题材：

题材 常见图案 寓意
动物 龙、凤、鱼、蝶 龙凤呈祥、年年有余
植物 牡丹、梅花、莲花 富贵吉祥、高洁
人物 福娃、仙女 幸福安康
文字 福、喜、寿 福气、喜庆、长寿

剪纸的方法：

剪纸最基本的方法有两种：

  1. 阳剪：把要保留的图案留下来，把背景剪掉。这样剪出来的图案是完整的。
  2. 阴剪：在纸上剪出镂空的图案，背景保留。这样的剪纸有很多漂亮的"窗口"。

简单的剪纸体验：

让我们来剪一个简单的"双喜"字：

  1. 取一张红色正方形纸。
  2. 从左到右对折一次。
  3. 再从上到下对折一次。
  4. 用铅笔在折好的纸上画出半个"喜"字的轮廓。
  5. 用安全剪刀沿着画好的线剪下来。
  6. 轻轻展开——一个漂亮的"双喜"就出现了！

皮影戏——灯光下的魔术

皮影戏是一种古老的表演艺术，用灯光照射皮影，在白色的幕布上投射出影子，配合说唱来讲故事。

皮影戏是怎么演的：

  1. 在一块白色的幕布后面点一盏灯。
  2. 艺人拿着用皮革或纸板做成的人物剪影，放在灯光和幕布之间。
  3. 灯光照到剪影上，幕布前面就出现了人物的影子。
  4. 艺人操纵剪影上的小木棍，让人物做出各种动作——走路、打斗、跳舞。
  5. 同时，艺人还要唱歌、说台词，讲述故事情节。

一个人有时候要同时操纵好几个角色，还要唱歌、配音，真是太厉害了！

皮影人物的特点：

  • 侧面造型：皮影人物大多是侧面的形象，就像我们画的侧面人像。
  • 关节灵活：人物的胳膊、腿都可以活动，就像一个小木偶。
  • 颜色鲜艳：好人用红色和黄色，坏人用蓝色和黑色。
  • 花纹精美：人物身上刻有精细的花纹，光照过去特别好看。

自己做一个简单的皮影：

  1. 在黑色卡纸上画一个人物的侧面轮廓（头、身体、手臂、腿）。
  2. 分别剪出身体的各个部分。
  3. 在关节的地方（肩膀、手肘、膝盖）用小扣子或者线连接起来。
  4. 在手和脚的位置粘上小木棍或者筷子作为操控杆。
  5. 用手电筒当灯光，白纸当幕布，就可以表演皮影戏了！

年画——过年最美的装饰

年画是中国人过年时张贴的画。每到春节前，家家户户都会买几张年画贴在墙上或门上，寓意新的一年吉祥如意。

年画的种类：

种类 内容 贴在哪里
门神画 两个威武的将军 大门上，保护家人平安
福字画 大大的"福"字 门上或墙上，迎接福气
胖娃娃 胖嘟嘟的小孩抱鱼 客厅，寓意年年有余
花鸟画 牡丹、喜鹊等 房间里，寓意吉祥富贵

年画的特点：

  • 颜色鲜艳：大红、大绿、金黄，看起来非常喜庆。
  • 构图饱满：画面里满满的都是图案，不留空白。
  • 形象夸张：人物画得圆圆胖胖的，表示富裕和健康。
  • 寓意丰富：每个图案都有特别的意思——鱼代表"年年有余"，蝙蝠代表"福气"，桃子代表"长寿"。

最有名的年画产地：

  • 天津杨柳青：以精细的工笔画法著称。
  • 山东潍坊杨家埠：色彩浓烈，风格豪放。
  • 四川绵竹：画风热烈，年味十足。

泥塑和面人——手指尖上的艺术

泥塑是用泥巴捏出各种造型的艺术。先把泥巴揉软，然后一点一点捏出人物、动物或其他形状，晾干后涂上颜色。

最有名的泥塑是天津的"泥人张"——张明山先生和他的后人们捏出了很多栩栩如生的泥人，活灵活现，就像真人缩小了一样。

面人是用面粉加上颜料捏出来的。在庙会和集市上，经常能看到面人师傅坐在小摊前，用灵巧的手指把彩色的面团捏成孙悟空、猪八戒、花仙子等各种形象，几分钟就能捏好一个，让围观的小朋友们惊叹不已。

自己动手捏泥巴：

  1. 用橡皮泥或者超轻黏土代替泥巴。
  2. 揉一个圆球——这是头。
  3. 搓一个圆柱体——这是身体。
  4. 搓几条细长条——做手和脚。
  5. 把头、身体、手、脚拼在一起。
  6. 用小工具或牙签刻出眼睛、嘴巴等细节。

糖画——甜蜜的艺术

糖画是用融化的糖浆在光滑的石板上画出图案。糖画师傅把一勺糖浆慢慢倒在石板上，手腕灵活地转动，几秒钟就能画出一条龙、一只凤凰或一朵花。等糖浆凝固后，用小竹签粘起来，就是一个又好看又好吃的糖画了。

糖画的神奇之处在于，师傅画的时候一笔都不能停——因为糖浆一停就会凝固。所以师傅们的手必须非常灵巧，速度也要很快。

练习与思考

练习一：剪一朵窗花

用红色纸剪一朵简单的窗花：

  1. 把纸对折两次或三次。
  2. 在边上剪出一些小形状。
  3. 打开看看——每次剪出来的花样都不一样。
  4. 把你觉得最漂亮的窗花贴在窗户上。

练习二：做一个皮影

用卡纸做一个简单的皮影人物：

  1. 画出人物的头和身体。
  2. 分别剪出来，用线或者小扣子连接。
  3. 粘上小棍子作为操控杆。
  4. 用手电筒照着白纸表演。

和同学们一起编一个小故事来表演吧！

练习三：画一张年画

在一张纸上画一张简单的"年画"：

  • 画一个胖嘟嘟的小娃娃
  • 给他穿上红色的衣服
  • 让他抱着一条大鱼
  • 在周围画上花朵和吉祥图案
  • 涂上鲜艳的颜色

练习四：捏一个泥人

用橡皮泥或超轻黏土捏一个你喜欢的形象，可以是：

  • 一只小猫
  • 一个小人
  • 一朵花
  • 一个水果

思考题

  1. 你见过哪些民间艺术？在哪里见到的？
  2. 过年的时候，你家会贴窗花或年画吗？
  3. 你觉得剪纸和画画哪个更难？为什么？
  4. 为什么我们要保护和传承民间艺术？

拓展阅读

民间艺术与节日

很多民间艺术都和中国的传统节日有关：

春节：贴窗花、贴年画、贴春联、挂灯笼。家家户户红红火火，到处都是喜庆的民间艺术。

元宵节：看花灯、猜灯谜。花灯的造型有兔子灯、莲花灯、龙灯等，都是民间艺人手工制作的。

端午节：赛龙舟、挂香包。香包是用彩色的布和丝线缝制的，里面装着香草，既好看又好闻。

中秋节：赏月饼上的花纹。传统月饼的模具上刻有精美的图案，每一块月饼都像一件小小的艺术品。

正在消失的民间艺术

有些民间艺术因为会做的人越来越少，正面临着消失的危险：

  • 很多年轻人不愿意学习传统手艺，因为需要很多年的练习。
  • 工厂里的机器可以大量生产装饰品，手工制品卖不出去了。
  • 一些老手艺人年纪大了，却找不到愿意学习的徒弟。

为了保护这些宝贵的民间艺术，国家把很多民间艺术列为"非物质文化遗产"，鼓励人们学习和传承。我们小朋友也可以为保护民间艺术做出贡献——多了解、多欣赏、多动手尝试。

世界各地的民间艺术

不只是中国有民间艺术，世界各地都有自己独特的民间艺术：

  • 日本的折纸和浮世绘版画。
  • 墨西哥的彩色骷髅头彩绘，用来庆祝亡灵节。
  • 印度的曼陀罗沙画，用彩色的沙子画出精美的圆形图案。
  • 非洲的木雕面具，每一个面具都代表不同的精神和故事。
  • 俄罗斯的套娃——一个大娃娃打开，里面还有一个小娃娃，一个套一个，越来越小。

虽然世界各地的民间艺术形式不同，但它们都表达了人们对美好生活的向往。

小结

今天我们学习了很多中国民间艺术的知识：

  • 剪纸是用剪刀在红纸上剪出图案的艺术，过年贴窗花是最常见的形式。
  • 皮影戏用灯光投射影子来表演故事，是古老的"动画片"。
  • 年画是过年时张贴的吉祥画，颜色鲜艳、寓意美好。
  • 泥塑和面人是用泥巴或面粉捏出各种形象的艺术。
  • 糖画是用糖浆画出图案的甜蜜艺术。
  • 民间艺术和中国的传统节日紧密相连。
  • 我们要珍惜和保护这些宝贵的文化遗产。

民间艺术是我们中华民族智慧的结晶，每一件作品都凝聚着劳动人民对美好生活的热爱。小朋友们，让我们用好奇的眼睛去欣赏，用灵巧的双手去学习，把这些美丽的艺术传承下去！
