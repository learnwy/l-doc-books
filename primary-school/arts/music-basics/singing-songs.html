一年级艺术 — 唱歌

唱歌是最快乐的事情之一！当我们开心的时候唱歌，心里会更加高兴；当我们难过的时候唱歌，烦恼也会飞走。每个小朋友都有一副美丽的嗓子，让我们一起张开嘴巴，大声地唱出快乐的歌声吧！

知识要点

什么是唱歌

唱歌就是用我们的嗓子，按照歌曲的旋律和节奏，把歌词唱出来。唱歌和说话不一样——说话是平平的，唱歌有高有低、有快有慢，就像声音在跳舞。

唱歌的基本要求

要求 怎么做 为什么重要
坐姿端正 身体坐直，不弯腰驼背 这样气息才能顺畅
嘴巴张开 嘴巴张成圆圆的"O"形 声音才能响亮好听
用肚子呼吸 吸气时肚子鼓起来 声音更有力量
看老师指挥 眼睛看着老师的手 大家才能唱得整齐
认真听伴奏 耳朵听着音乐的节拍 不会唱快也不会唱慢

唱歌的声音

小朋友的声音有不同的类型：

  • 高音：声音亮亮的、尖尖的，像小鸟叫一样。
  • 低音：声音闷闷的、沉沉的，像大熊说话一样。
  • 强音：声音大大的，很有力量。
  • 弱音：声音轻轻的，像在说悄悄话。

唱歌的时候，有时要唱得高一些，有时要唱得低一些，有时声音大，有时声音小。跟着歌曲的变化来唱，歌声就会特别好听。

齐唱是什么

齐唱就是全班同学一起唱同一首歌，唱一样的旋律。要做到：

  • 同时开始：老师说"预备，唱！"大家一起开口。
  • 速度一样：不能有人唱快、有人唱慢。
  • 音量协调：不能有人特别大声、有人特别小声。
  • 同时结束：歌曲唱完的时候一起停下来。

详细讲解

唱歌前的热身

就像运动前要做操一样，唱歌前也要给嗓子做"热身"：

嘴巴操：

  1. 张开嘴巴，大声说"啊——"，保持 3 秒。
  2. 嘴巴缩成小圆，说"噢——"，保持 3 秒。
  3. 嘴巴抿成一条线，说"咿——"，保持 3 秒。
  4. 重复 3 次。

呼吸练习：

  1. 深深地吸一口气，让肚子鼓起来。
  2. 慢慢地把气吐出来，发出"嘶——"的声音。
  3. 试着让吐气的时间越来越长。

音阶练习： 跟着老师的钢琴一起唱：Do Re Mi Fa Sol La Si Do（哆 来 咪 发 索 拉 西 哆），先从低到高，再从高到低。

经典儿歌学习

《两只老虎》

这是一首非常有名的儿歌，几乎每个小朋友都会唱：

两只老虎，两只老虎， 跑得快，跑得快， 一只没有眼睛，一只没有尾巴， 真奇怪，真奇怪。

学唱要点：

  • 前两句"两只老虎"旋律一样，要唱得欢快活泼。
  • "跑得快"三个字要唱得短促有力。
  • "一只没有眼睛，一只没有尾巴"这两句要唱得连贯。
  • "真奇怪"要唱得夸张一点，表现出惊讶的感觉。

动作配合： 唱的时候可以配上动作——用两只手做出老虎爪子的样子，跑得快的时候做跑步的动作，没有眼睛就捂住眼睛，没有尾巴就摸摸后面。

《小星星》

一闪一闪亮晶晶， 满天都是小星星， 挂在天上放光明， 好像许多小眼睛。

学唱要点：

  • 这首歌的速度比较慢，要唱得温柔、安静。
  • "一闪一闪"要轻轻地唱，像星星在眨眼睛。
  • "亮晶晶"最后一个字可以唱长一点。
  • 想象自己在夜晚仰望星空，心情是宁静美好的。

《找朋友》

找呀找呀找朋友， 找到一个好朋友， 敬个礼呀握握手， 你是我的好朋友。

学唱要点：

  • 这是一首活泼欢快的歌，要唱得开心。
  • "找呀找呀"可以左右转头，做出寻找的样子。
  • "敬个礼"做鞠躬动作，"握握手"和旁边的同学握手。
  • 唱完最后一句，和好朋友拥抱一下。

《小燕子》

小燕子，穿花衣， 年年春天来这里。 我问燕子你为啥来， 燕子说，这里的春天最美丽。

学唱要点：

  • 这首歌的旋律优美流畅，要唱得轻柔。
  • "穿花衣"要唱得俏皮可爱。
  • "我问燕子你为啥来"可以做出疑问的表情。
  • 最后"最美丽"三个字要唱得饱满响亮。

唱歌的表情和动作

唱歌不只是用嘴巴唱，还要用表情和身体来表现：

歌曲情绪 表情 身体动作
开心快乐 笑眯眯的 身体轻轻晃动
温柔安静 眼睛微闭 身体轻轻摇摆
活泼调皮 眨眨眼睛 做出有趣的动作
雄壮有力 表情认真 挺直腰板

合唱小知识

合唱是很多人一起唱歌。和一个人唱歌不一样，合唱需要大家配合：

  • 听旁边同学的声音：不要只听自己的声音，要和大家融合在一起。
  • 跟着指挥：指挥的手告诉我们什么时候唱、什么时候停、声音大还是小。
  • 不要抢拍：每个人都要按照同样的速度唱。
  • 声音均衡：不要一个人特别突出，大家的声音要像融化在一起。

练习与思考

练习一：学唱一首新歌

选一首你还不会唱的歌，按照以下步骤学习：

  1. 先听老师唱一遍或者听音乐播放一遍。
  2. 跟着哼唱旋律（不用唱歌词，用"啦啦啦"代替）。
  3. 看着歌词，一句一句跟唱。
  4. 完整地把整首歌唱出来。

练习二：齐唱练习

全班同学一起唱《两只老虎》，注意：

  • 同时开始，同时结束
  • 速度保持一致
  • 声音大小均匀

练习三：表演唱

选一首你最拿手的歌，加上动作表演给同学们看。可以自己编动作，也可以和好朋友一起合作表演。

练习四：听一听、唱一唱

老师弹钢琴，小朋友们跟着唱音阶：

Do → Re → Mi → Fa → Sol → La → Si → Do

先慢慢唱，唱熟了再加快速度。

思考题

  1. 你最喜欢唱什么歌？为什么喜欢它？
  2. 你觉得唱歌和说话有什么不一样？
  3. 如果让你选一首歌唱给妈妈听，你会选哪首？为什么？
  4. 为什么全班同学一起唱歌的时候要看老师的指挥？

拓展阅读

声音是怎么发出来的

我们的喉咙里有一个叫做声带的东西，就像两片小小的"橡皮筋"。当我们说话或唱歌的时候，从肺里出来的气流经过声带，让声带振动，就发出了声音。

  • 声带拉紧，振动得快，声音就高。
  • 声带放松，振动得慢，声音就低。

所以，唱高音的时候，声带会比较紧；唱低音的时候，声带比较松。

动物也会唱歌

不只是人类会唱歌，很多动物也有自己的"歌声"：

  • 小鸟：清晨的鸟鸣是最好听的"歌声"，不同的鸟有不同的叫声。
  • 鲸鱼：鲸鱼在海底会发出悠长的"歌声"，能传到很远的地方。
  • 蟋蟀：夏天的晚上，蟋蟀用翅膀摩擦发出"唧唧"的声音，就像在唱歌。
  • 青蛙：雨后的池塘边，青蛙"呱呱"地大合唱。

音乐小故事：音乐神童莫扎特

莫扎特是世界上最有名的音乐家之一。他在 3 岁的时候就开始弹钢琴，4 岁就能作曲，5 岁就在国王面前表演了。他小时候特别爱音乐，走到哪里都在唱歌和弹琴。

莫扎特写过很多好听的歌曲，其中有一首叫《小星星变奏曲》，就是用我们学过的《小星星》的旋律变化而来的。原来，这首简单的儿歌曾经启发过伟大的音乐家呢！

唱歌的好处

唱歌对我们有很多好处：

  • 心情变好：唱歌的时候，大脑会产生让人快乐的物质。
  • 锻炼肺活量：唱歌需要深呼吸，能让我们的肺更强壮。
  • 增强记忆力：记住歌词需要动脑筋，经常唱歌的人记忆力更好。
  • 交到好朋友：和同学们一起唱歌，感情会更好。
  • 培养自信心：敢在别人面前唱歌的小朋友，会越来越自信。

小结

今天我们学习了很多关于唱歌的知识：

  • 唱歌需要坐姿端正、嘴巴张开、用肚子呼吸。
  • 唱歌前要做热身练习，包括嘴巴操和呼吸练习。
  • 我们学唱了**《两只老虎》《小星星》《找朋友》《小燕子》**等经典儿歌。
  • 齐唱需要大家同时开始、速度一致、声音均衡。
  • 唱歌不只是用嘴巴，还要配合表情和动作，让歌声更有感染力。
  • 声音是由喉咙里的声带振动产生的。

小朋友们，音乐让世界变得更加美好。从今天起，每天都唱一首歌吧！走路的时候唱、玩耍的时候唱、开心的时候唱。用你最美的歌声，把快乐传递给身边的每一个人！
