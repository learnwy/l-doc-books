六年级数学 — 方程应用

知识要点

方程是含有未知数的等式。用方程解决问题的方法叫做"列方程解应用题"，它比算术方法更加系统和通用。掌握方程是小升初的关键能力，也是初中代数学习的基石。

方程的基本概念：

术语 含义 示例
方程 含有未知数的等式 2x + 3 = 11
解方程 求未知数的值 x = 4
方程的解 使方程成立的未知数的值 x = 4 是 2x+3=11 的解
等式性质 等式两边同时加、减、乘、除相同的数，等式仍成立 核心解题工具

详细讲解

等式的基本性质

等式就像一架天平，左右两边必须平衡。

性质一：等式两边同时加上（或减去）同一个数，等式仍然成立。

如果 a = b，那么 a + c = b + c，a - c = b - c

性质二：等式两边同时乘以（或除以）同一个不为0的数，等式仍然成立。

如果 a = b，那么 a × c = b × c，a ÷ c = b ÷ c（c ≠ 0）

解方程的方法

一步方程：

方程 解题步骤 结果
x + 15 = 32 两边减15 x = 17
x - 8 = 20 两边加8 x = 28
3x = 24 两边除以3 x = 8
x/4 = 7 两边乘以4 x = 28

两步方程：

例：2x + 6 = 20

解题步骤：

  1. 两边减6：2x = 14
  2. 两边除以2：x = 7

验证：2×7 + 6 = 14 + 6 = 20 ✓

例：5x - 3 = 22

解题步骤：

  1. 两边加3：5x = 25
  2. 两边除以5：x = 5

验证：5×5 - 3 = 25 - 3 = 22 ✓

含有括号的方程：

例：3(x + 4) = 27

方法一（先去括号）：

  1. 展开：3x + 12 = 27
  2. 两边减12：3x = 15
  3. 两边除以3：x = 5

方法二（先除以3）：

  1. 两边除以3：x + 4 = 9
  2. 两边减4：x = 5

列方程解应用题

列方程解应用题的步骤：

步骤 操作 目的
审题 读懂题意，找出关键信息 理解问题
设未知数 用x表示要求的量 建立变量
找等量关系 找出题目中的等量关系 建立方程
列方程 根据等量关系列出方程 数学化
解方程 求出x的值 得到答案
检验 代回原题验证 确保正确

典型应用题

和差问题：

甲乙两数之和为56，甲数比乙数多12。求甲乙各是多少。

设乙为x，则甲为 x + 12。

  • x + (x + 12) = 56
  • 2x + 12 = 56
  • 2x = 44
  • x = 22

所以乙 = 22，甲 = 34。验证：22 + 34 = 56，34 - 22 = 12 ✓

倍数问题：

学校买了篮球和足球共45个。篮球的数量是足球的2倍。各买了多少个？

设足球为x个，则篮球为2x个。

  • x + 2x = 45
  • 3x = 45
  • x = 15

足球15个，篮球30个。验证：15 + 30 = 45，30 = 15×2 ✓

行程问题：

甲乙两地相距360千米。一辆汽车从甲地出发，3小时后距乙地还有150千米。汽车的速度是多少？

设速度为x千米/小时。

  • 3x + 150 = 360
  • 3x = 210
  • x = 70

速度为70千米/小时。验证：70×3 + 150 = 210 + 150 = 360 ✓

工程问题：

一项工程，甲独做需要10天完成，乙独做需要15天完成。两人合作几天完成？

设合作x天完成。甲每天完成1/10，乙每天完成1/15。

  • x/10 + x/15 = 1
  • 两边乘30：3x + 2x = 30
  • 5x = 30
  • x = 6

合作6天完成。验证：6/10 + 6/15 = 3/5 + 2/5 = 1 ✓

年龄问题：

爸爸今年42岁，小明今年12岁。几年前爸爸的年龄是小明的5倍？

设x年前。那时爸爸(42-x)岁，小明(12-x)岁。

  • 42 - x = 5(12 - x)
  • 42 - x = 60 - 5x
  • 4x = 18
  • x = 4.5

4.5年前（即4年半前），爸爸37.5岁，小明7.5岁。37.5 = 7.5 × 5 ✓

练习与思考

练习一：解方程

  1. 4x - 7 = 25
  2. 2(x + 3) = 18
  3. x/3 + 5 = 11
  4. 6x - 2x = 28

练习二：列方程解题

  1. 一个数的4倍减去6等于30。求这个数。
  2. 商店上午卖出苹果35千克，下午卖出的是上午的2倍。全天共卖出多少千克？
  3. 一块长方形菜地，长是宽的2倍，周长是36米。求长和宽各是多少？

练习三：综合应用

  1. 两个连续偶数的和是62。求这两个数。
  2. 甲仓库有粮食240吨，乙仓库有粮食80吨。从甲仓库运多少吨到乙仓库，才能使甲仓库的粮食是乙仓库的2倍？
  3. 小明比小红多20本书。如果小明给小红5本，小明的书是小红的几倍？（设小红原来有x本）

拓展阅读

方程的历史源远流长。中国古代的《九章算术》中就有关于方程的内容，书中的"方程"一章讨论了多元一次方程组的解法，比欧洲早了一千多年。

"方程"这个名称的由来很有趣。"方"指的是把数据排列成方形（矩阵），"程"指的是计算程序。古代数学家把问题中的数据按行列排好，再按一定程序消元求解。

进入初中后，方程的学习会更加深入。一元一次方程、二元一次方程组、一元一次不等式等都是在此基础上发展的。方程是代数的核心工具，掌握好方程就掌握了初中数学的钥匙。

列方程的核心能力是找"等量关系"。建议同学们在做应用题时，先不急着算，而是问自己："题目中哪些量是相等的？"这个习惯会让解题变得简单很多。

小结

  • 方程是含有未知数的等式，解方程的核心工具是等式的基本性质
  • 解方程的一般步骤：去括号→移项→合并同类项→系数化为1
  • 列方程解应用题的关键是找到等量关系，步骤为：审题→设未知数→找等量关系→列方程→解方程→检验
  • 典型应用题类型包括和差问题、倍数问题、行程问题、工程问题和年龄问题
  • 方程是从算术到代数的核心过渡，是初中数学学习的重要基础
