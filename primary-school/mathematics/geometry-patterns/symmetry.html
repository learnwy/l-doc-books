二年级数学 — 对称

知识要点

对称是一种美丽的数学现象。如果一个图形沿着一条线对折后，两边能完全重合，这个图形就是对称图形，这条线叫做对称轴。

对称的基本概念：

概念 说明 举例
对称图形 对折后两边完全重合的图形 蝴蝶、五角星
对称轴 把图形分成两半的那条折线 长方形有2条对称轴
不对称图形 对折后两边不能重合 数字"6"、字母"F"

常见对称图形的对称轴数量：

图形 对称轴数量
圆 无数条
正方形 4条
长方形 2条
等边三角形 3条
等腰三角形 1条
五角星 5条

详细讲解

一、什么是对称

把一张纸对折，两边完全重合在一起——这就是对称。

动手试试：

  1. 拿一张纸，在上面画一只蝴蝶
  2. 沿着蝴蝶的身体中间折一下
  3. 看看左边的翅膀和右边的翅膀是不是完全重合了？
  4. 如果完全重合，说明蝴蝶是对称的

对称的特点：

  • 对称轴两边的形状完全一样
  • 对称轴两边的大小完全一样
  • 对称轴两边的图案是"镜子里的影子"

二、生活中的对称

对称在我们的生活中到处都有：

自然界中的对称：

  • 蝴蝶的两只翅膀
  • 蜻蜓的身体
  • 树叶的两半（沿叶脉对折）
  • 人的脸（左右基本对称）
  • 雪花

人造物品中的对称：

  • 飞机（左右对称）
  • 风筝
  • 剪纸图案
  • 天安门城楼
  • 汉字"中""十""大""美"

对称的汉字：

类型 例字
左右对称 中、十、大、美、山、王
上下对称 —
不对称 好、你、明、花

三、判断对称图形

怎样判断一个图形是不是对称的？

方法一：对折法 把图形剪下来，试着对折，看看能不能完全重合。

方法二：画对称轴法 在图形上画一条线，看看这条线两边的部分是不是完全一样。

方法三：照镜子法 把一面小镜子竖直放在图形中间，看看镜子里的图形和镜子外面的图形是不是组成了完整的原图。

哪些图形是对称的？

图形 是否对称 理由
正方形 是 可以沿多条线对折重合
长方形 是 可以沿两条线对折重合
圆 是 沿任意直径对折都重合
等腰三角形 是 沿中间那条线对折重合
普通三角形 不一定 三条边如果都不一样就不对称
平行四边形 不是 对折后不能重合

四、画对称图形

在方格纸上画对称图形是一种很好的练习。

画法步骤：

  1. 先画出对称轴（通常是一条竖线或横线）
  2. 在对称轴的一边画出图形的一半
  3. 在对称轴的另一边，画出完全一样但方向相反的另一半
  4. 对称轴两边对应的点到对称轴的距离相等

在方格纸上画对称图形的技巧：

  • 数格子：左边的点距离对称轴几格，右边的对应点也距离对称轴几格
  • 先画关键点（拐角处的点），再连线
  • 左边向左走，右边就向右走；左边向上走，右边也向上走

五、剪对称图形

用折纸和剪刀可以剪出美丽的对称图形。

剪法步骤：

  1. 取一张正方形或长方形的纸
  2. 沿中间对折
  3. 在对折后的纸上画出图形的一半（靠折痕的那一侧不要全部剪断）
  4. 沿着画的线剪
  5. 展开，就得到了一个对称的图形

可以剪出的图形：

  • 爱心（对折后画半个心形）
  • 蝴蝶（对折后画半只蝴蝶）
  • 小人（对折后画半个小人）
  • 雪花（多折几次，剪出更复杂的图案）

中国的剪纸艺术就大量运用了对称的原理。一张红纸折叠几下，用剪刀巧妙地剪几刀，展开后就是一幅精美的图案。

六、对称在设计中的应用

对称给人一种平衡、和谐、美丽的感觉。很多设计都运用了对称：

  • 建筑：故宫、天安门广场都是左右对称的
  • 国旗：很多国家的国旗是对称设计的
  • 商标：很多品牌的标志都是对称的
  • 衣服：衣服的左边和右边是对称的
  • 家具：书柜、衣柜的左右两边常常是对称的

不过，生活中也有不对称的美。比如，一棵树的左右两边不可能完全一样，但它依然很美。有些艺术作品故意设计成不对称的，也有独特的美感。

拓展阅读

对称在大自然中无处不在。科学家们发现，几乎所有动物的身体都是左右对称的——左边有一只手，右边也有一只手；左边有一只眼睛，右边也有一只眼睛。这种对称性帮助动物保持平衡，行动更灵活。

雪花是大自然最精美的对称作品之一。每一片雪花都有六个角，而且呈六重对称。但有趣的是，世界上没有两片完全相同的雪花——它们每一片都是独一无二的对称图案。

数学家们对对称进行了深入研究，发展出了一个叫做"群论"的数学分支。对称的思想在物理学、化学、艺术等很多领域都有重要的应用。

中国传统文化中有很多对称的元素。太极图（阴阳鱼）就是一种旋转对称的图案，它体现了中国哲学中"阴阳平衡"的思想。对联也是一种语言上的"对称"——上联和下联字数相同、结构相似。

小结

本节课我们学习了对称的基础知识：

  • 对称图形沿对称轴对折后两边完全重合
  • 生活中有很多对称现象：蝴蝶、雪花、建筑等
  • 判断对称可以用对折法、画对称轴法和照镜子法
  • 在方格纸上画对称图形要注意对应点到对称轴的距离相等
  • 折纸和剪纸是体验对称的好方法

对称是数学中最美丽的概念之一，用"对称之眼"去看世界，你会发现到处都是美！
