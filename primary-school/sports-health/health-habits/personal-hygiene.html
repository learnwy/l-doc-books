一年级体育与健康 — 个人卫生

知识要点

讲卫生是保持健康的重要方法。养成良好的个人卫生习惯，能让我们远离疾病，每天都精精神神的。让我们一起来学习怎样讲好个人卫生吧！

什么是个人卫生

  • 保持身体干净整洁
  • 养成每天清洁的好习惯
  • 注意手、口、身体各部位的卫生
  • 讲卫生不仅保护自己，也保护别人

个人卫生的基本内容

  • 勤洗手：饭前便后、外出回家后都要洗手
  • 勤刷牙：早晚各刷一次牙
  • 勤洗澡：保持身体清洁
  • 勤换衣：穿干净整洁的衣服
  • 勤剪指甲：指甲不要留太长

为什么要讲卫生

  • 减少细菌和病毒的传播
  • 预防感冒、拉肚子等疾病
  • 让自己看起来干净、精神
  • 让周围的人觉得舒服

详细讲解

一、洗手——最重要的卫生习惯

洗手是预防疾病最简单有效的方法。我们的手每天接触很多东西，上面会沾满肉眼看不见的细菌。

什么时候要洗手

时间 为什么
吃饭前 防止病菌从嘴巴进入身体
上完厕所后 厕所里的细菌很多
从外面回家后 外面摸过很多东西
打喷嚏或咳嗽后 手上沾了飞沫
摸了小动物后 动物身上有细菌
玩完玩具后 玩具上有很多细菌

正确的洗手方法（七步洗手法）

  1. 内：掌心对掌心，相互搓揉
  2. 外：手掌搓手背，两手交替
  3. 夹：掌心对掌心，手指交叉搓揉
  4. 弓：弯曲手指，搓揉指背
  5. 大：一只手握住另一只手的大拇指旋转搓揉
  6. 立：指尖在掌心搓揉
  7. 腕：搓揉手腕

每次洗手至少要搓 20 秒，大约唱两遍"生日快乐"歌的时间。

洗手小口诀

小朋友，讲卫生， 洗手步骤要记清。 内外夹弓大立腕， 搓够二十秒才行。 流水冲洗擦干手， 干干净净不生病。

二、刷牙——保护牙齿的好方法

牙齿是我们吃东西的重要工具。不刷牙的话，牙齿上的食物残渣会让细菌繁殖，导致蛀牙。

正确的刷牙方法

  1. 挤黄豆大小的牙膏在牙刷上
  2. 牙刷倾斜 45 度放在牙齿和牙龈的交界处
  3. 轻轻地上下刷（不是左右刷）
  4. 每颗牙齿都要刷到：外面、里面、咬合面
  5. 刷牙时间至少 2 分钟
  6. 最后用清水漱口

刷牙的时间

时间 为什么
早上起床后 清除夜间口腔里滋生的细菌
晚上睡觉前 清除一天中留在牙齿上的食物残渣

选择合适的牙刷和牙膏

  • 选小朋友专用的小头软毛牙刷
  • 选含氟的儿童牙膏
  • 每三个月更换一次牙刷
  • 牙膏用量不要太多

保护牙齿的好习惯

  • 少吃糖果和甜食
  • 不咬硬物（如铅笔、瓶盖）
  • 不用牙齿开瓶盖
  • 定期去看牙医

小故事：小虫虫找新家

小蛀虫最喜欢找不爱刷牙的小朋友了。它在小明的牙齿上找到了好多食物残渣，开心地住了下来，还叫来了好多朋友。小明的牙齿慢慢变黑了，还特别疼。妈妈带他去看牙医，牙医说："以后一定要好好刷牙，把小蛀虫赶走！"从此，小明每天认真刷牙，小蛀虫再也找不到食物，只好搬走了。

三、洗澡和换衣服

保持身体和衣服的清洁也很重要。

洗澡的好处

  • 洗掉身上的汗水和灰尘
  • 让皮肤保持健康
  • 让自己闻起来香香的
  • 洗完澡会觉得很舒服

洗澡注意事项

  • 每天或者隔天洗一次澡
  • 运动出汗后要及时洗澡
  • 洗澡水温不要太热也不要太冷
  • 要用洗发水洗头发，用沐浴露洗身体
  • 洗完后要把身体擦干

换衣服的好习惯

  • 内衣裤每天换一次
  • 校服保持干净，脏了要及时换洗
  • 运动完汗湿了要换上干衣服
  • 不穿别人穿过的袜子和内衣

四、其他个人卫生习惯

剪指甲

  • 指甲长了要及时修剪
  • 不要咬指甲（指甲下面有很多细菌）
  • 一般一周剪一次指甲就可以了
  • 让爸爸妈妈帮忙剪，或者用安全指甲刀

保护眼睛

  • 看书写字时光线要充足
  • 不要离书本太近（保持一尺距离）
  • 每学习 30-40 分钟，休息一下，看看远处
  • 不长时间看手机和电视
  • 做眼保健操

保护耳朵和鼻子

  • 不要用手指或小棍子掏耳朵
  • 不要把小东西塞进鼻子里
  • 打喷嚏时用手肘遮住口鼻
  • 擤鼻涕用纸巾，用完扔进垃圾桶

五、预防传染病

有些疾病可以通过接触传播给其他人，我们要学会预防。

预防感冒

  • 天冷时多穿衣服
  • 勤洗手
  • 房间里多通风
  • 不和感冒的人共用杯子和毛巾
  • 打喷嚏、咳嗽时用纸巾或手肘遮住

生病了怎么办

  • 告诉爸爸妈妈和老师
  • 及时去看医生
  • 按时吃药
  • 多喝水、多休息
  • 不要把病传给同学（可以戴口罩）

练习与思考

一、做一做

  1. 按照七步洗手法认真洗一次手，请老师检查。
  2. 在家里练习正确的刷牙方法，坚持刷满 2 分钟。
  3. 检查自己的指甲，如果长了就让爸爸妈妈帮忙剪。
  4. 每天记录自己做到了几项卫生好习惯。

二、说一说

  1. 说出五个需要洗手的时候。
  2. 刷牙的正确方法是什么？
  3. 为什么不能咬指甲？
  4. 感冒了应该怎么做？

三、判断对错

行为 对 错
饭前洗手 ✓
一天不刷牙也没关系 ✓
打喷嚏时用手遮住嘴 ✓
每天换干净的内衣 ✓
用手指掏耳朵 ✓
定期去看牙医 ✓

（注意：打喷嚏应该用手肘或纸巾遮住，不是直接用手）

四、想一想

  1. 细菌虽然看不见，但真的存在吗？
  2. 如果不讲卫生，会怎样？
  3. 你觉得自己在哪方面的卫生习惯还需要改进？

拓展阅读

看不见的细菌

细菌非常非常小，用肉眼是看不见的。在我们的手上、桌子上、门把手上，到处都有细菌。一只没洗的手上可能有上百万个细菌！不过不要害怕，只要我们勤洗手，就能把大部分细菌洗掉。

为什么要用流动的水洗手

用盆子里的水洗手，脏东西还在水里；用流动的水（水龙头）洗手，脏东西会随着水流冲走。所以一定要用流动的水洗手哦！

牙齿的小秘密

小朋友的乳牙一共有 20 颗，到了 6-7 岁会开始换牙，慢慢长出 32 颗恒牙。恒牙是我们一辈子要用的牙齿，所以一定要好好保护。如果恒牙坏了，就不会再长新的了。

卫生习惯小口诀

小手脏了快快洗， 早晚刷牙不能忘。 勤洗澡来勤换衣， 指甲长了要修剪。 喷嚏咳嗽遮口鼻， 讲究卫生身体棒。

小结

今天我们学习了个人卫生的知识。让我们记住：

  • 洗手是最重要的卫生习惯，要掌握七步洗手法
  • 早晚刷牙，保护牙齿，预防蛀牙
  • 勤洗澡、勤换衣、勤剪指甲
  • 保护好眼睛、耳朵和鼻子
  • 学会预防传染病，生病了及时看医生
  • 良好的卫生习惯让我们健康成长
