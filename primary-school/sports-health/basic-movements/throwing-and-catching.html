一年级体育与健康 — 投掷与接球

知识要点

投掷和接球是体育运动中非常重要的基本技能。学会投掷和接球，以后我们就能参加很多有趣的球类运动和游戏了。让我们一起来学习吧！

投掷的基本要求

  • 握住球的正确方法
  • 投掷时身体要协调发力
  • 注意投掷的方向和目标
  • 投掷前要确认前方安全

接球的基本要求

  • 眼睛要盯着球看
  • 两手准备好接球的姿势
  • 接到球时手指要有缓冲
  • 身体要移动到球飞来的位置

投掷与接球的好处

  • 锻炼手臂力量
  • 提高手眼协调能力
  • 培养空间判断能力
  • 增强反应速度

详细讲解

一、学会握球

在投掷之前，首先要学会正确地握住球。

不同大小的球的握法

球的类型 握法 适合的游戏
小沙包 五指抓握，放在手心里 投沙包、丢沙包
小皮球 五指张开，手掌包住球 拍球、投球
排球大小的球 两只手托住球 传球、投篮
足球 不用手（用脚踢） 踢球

握沙包的方法

沙包是一年级小朋友投掷练习中最常用的器材：

  1. 把沙包放在右手手心里（左手习惯的同学用左手）
  2. 五个手指弯曲，把沙包握住
  3. 握紧但不要太用力，要能灵活地甩出去
  4. 大拇指和其他四指分开，像一个"C"的形状

二、投掷的方法

学会握球之后，就可以开始练习投掷了。

过肩投掷（最基本的投法）

这是一年级最重要的投掷方法：

  1. 准备姿势：面向投掷方向，左脚在前，右脚在后（右手投的情况）
  2. 引臂：右手拿着球，手臂向后引到肩膀后面
  3. 蹬地转体：右脚蹬地，身体从右向左转
  4. 挥臂投出：手臂从后向前快速挥动，在最高点把球投出去
  5. 跟随动作：投出后手臂自然向前下方甩

投掷的小窍门

  • 投掷时要侧身站，不是正面对着目标
  • 投出球的角度大约 45 度（向前上方投）最远
  • 投球时全身要协调用力，不是只用手臂
  • 投掷前要确认前方没有人

小故事：投得远的秘密

体育课上比赛投沙包。小明使出全身力气投出去，可是沙包没飞多远。老师告诉他："不要只用手臂的力量，要先蹬地，再转身，最后才甩臂。全身一起用力才能投得远。"小明按照老师说的试了试，果然投得远多了！

三、接球的方法

接球需要好的手眼协调能力和反应速度。

接球的正确姿势

  1. 面向来球方向站好
  2. 两脚分开与肩同宽，膝盖微弯
  3. 两手在胸前张开，手指自然分开
  4. 眼睛盯着球看，判断球飞来的方向
  5. 当球飞到面前时，两手合拢接住球
  6. 接住球的瞬间，手臂稍微向后收一下（缓冲）

接不同高度的球

球的高度 接球方法
头上方的球 两手举高，手指朝上接
胸前的球 两手在胸前，手指朝上接
腰以下的球 弯腰，两手手指朝下接
弹地球 等球弹起来后再接

接球的练习方法

  • 自抛自接：自己把球抛起来，再接住。从低处开始，慢慢抛高。
  • 对墙抛接：对着墙壁投球，球弹回来后接住。
  • 两人对抛：和同学面对面站好，互相抛球接球。距离从近到远。

四、有趣的投掷接球游戏

投准游戏

在墙上画一个大圆圈（或者挂一个呼啦圈），站在几米远的地方投沙包，看谁能投进圆圈里。

距离 难度
2 米 简单
3 米 中等
4 米 较难
5 米 挑战

打保龄球

在地上放几个空塑料瓶，站在几米远的地方把球滚过去，看谁能打倒更多的瓶子。

传球接力

小朋友们排成一列，第一个人把球传给第二个人，第二个人传给第三个人……看哪一队传得又快又不掉球。

丢沙包

这是一个经典的集体游戏：

  1. 两个人站在两端投沙包
  2. 中间的人要躲避沙包
  3. 被沙包击中的人就出局
  4. 如果中间的人接住沙包，就可以增加一条"命"

抛接挑战

  • 把球抛起来，拍一下手再接住
  • 把球抛起来，拍两下手再接住
  • 把球抛起来，转一圈再接住（挑战！）

五、安全注意事项

投掷活动涉及物体飞行，一定要特别注意安全。

投掷安全规则

  • 投掷前看清楚前方有没有人
  • 大家要朝同一个方向投，不能对着投
  • 捡球时要等所有人都投完再一起去捡
  • 不要用硬物（如石头）投掷
  • 不要朝人的头部和脸部投球
  • 听老师的指令，不要随意投掷

受伤了怎么办

  • 被球打到了不要慌张，轻轻揉一揉
  • 如果很疼或者红肿了，及时告诉老师
  • 老师会带你去校医室处理

练习与思考

一、做一做

  1. 练习过肩投掷沙包，看你能投多远。
  2. 和同学面对面练习抛接球，从近距离开始。
  3. 练习投准：把沙包投进地上画的圆圈里。
  4. 练习自抛自接，挑战拍手再接球。

二、说一说

  1. 投掷时怎样才能投得更远？
  2. 接球时眼睛应该看哪里？
  3. 投掷活动中最重要的安全规则是什么？
  4. 你最喜欢哪个投掷接球游戏？

三、比一比

和同学一起比：

  1. 谁投沙包投得最远？
  2. 谁投得最准？（投进圆圈的次数最多）
  3. 两人对抛不掉球，谁坚持的次数最多？

四、想一想

  1. 为什么投球时要侧身站而不是正面对着？
  2. 接球时为什么手臂要向后收一下？
  3. 你知道哪些体育运动需要用到投掷和接球技能？

拓展阅读

投掷在运动中的应用

学会投掷和接球后，将来可以参加很多运动：

  • 篮球：投篮、传球
  • 棒球：投球、接球
  • 排球：发球、传球
  • 手球：射门、传球
  • 飞盘：投掷飞盘

世界上投得最远的人

在田径运动中，有一个项目叫"标枪"。运动员们要把一根长长的标枪投出去。世界纪录是 98.48 米，差一点就到 100 米了！这需要非常强壮的身体和极好的投掷技术。

有趣的投准故事

古代的弓箭手需要精准的投掷能力。中国古代有一位叫"后羿"的射手，传说他能射下天上的太阳。虽然这只是传说，但它告诉我们，准确的投掷技术是可以通过刻苦练习获得的。

投掷小口诀

侧身站好看前方， 手臂引到肩膀后。 蹬地转身快甩臂， 用力一投飞得远。 接球眼睛盯着看， 双手张开轻轻接。

小结

今天我们学习了投掷与接球的基本技能。让我们记住：

  • 投掷要学会侧身站立、引臂、蹬地转体、挥臂投出
  • 接球要眼睛盯着球、两手准备好、接住时缓冲
  • 全身协调用力才能投得更远
  • 通过各种游戏练习投掷和接球更有趣
  • 投掷活动一定要注意安全
  • 坚持练习，就能越投越远、越接越准
