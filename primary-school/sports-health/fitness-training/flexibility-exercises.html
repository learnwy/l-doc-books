三年级体育与健康 — 柔韧性练习

知识要点

柔韧性是指身体各个关节的活动范围和肌肉、韧带的伸展能力。拥有良好的柔韧性，可以让我们的动作更灵活、更优美，还能减少运动受伤的风险。三年级的小朋友正处于身体发育的黄金期，这个时候练习柔韧性效果最好。

柔韧性练习的好处：

好处 说明
预防受伤 柔韧的肌肉和韧带不容易拉伤
改善体态 帮助保持良好的站姿和坐姿
提高运动表现 动作幅度更大，跑跳更灵活
缓解肌肉酸痛 运动后拉伸可以加速恢复
促进血液循环 拉伸让血液更好地流到肌肉中

详细讲解

什么是柔韧性

想象两根橡皮筋，一根是新的、有弹性的，另一根是放了很久、硬邦邦的。新橡皮筋可以拉得很长也不会断，而旧橡皮筋一拉就断了。我们的肌肉和韧带就像橡皮筋——经常拉伸，它们就保持弹性；不经常拉伸，它们就会变得僵硬。

每个人的柔韧性天生不同，有的人很容易弯腰摸到脚趾，有的人弯腰时手只能到膝盖。但不管现在柔韧性如何，通过坚持练习都可以得到明显的提高。

拉伸前的热身

在进行柔韧性练习之前，必须先热身。热身可以让身体温度升高，肌肉变得更有弹性，避免拉伤。

热身方法（5-10分钟）：

  1. 慢跑：在操场上慢跑2-3圈
  2. 高抬腿：原地高抬腿30次
  3. 开合跳：双脚跳开双手上举，再跳回，做20次
  4. 手臂绕环：双臂分别向前向后画大圈，各10次

热身后你会感觉身体微微发热，这时候就可以开始拉伸了。

上半身柔韧性练习

颈部拉伸：

  1. 头慢慢向右倾斜，右耳靠近右肩，保持15秒
  2. 换另一边，向左倾斜15秒
  3. 头低下，下巴靠近胸口，保持15秒
  4. 注意动作要慢，不要快速甩头

肩部拉伸：

  1. 右手臂伸直横过胸前，左手在肘关节处轻轻按压，保持15秒
  2. 换另一边
  3. 双手十指交叉，翻转掌心向上推向天空，保持15秒

背部拉伸：

  1. 站立，双脚与肩同宽
  2. 双手抱住后脑勺，慢慢向前弯腰
  3. 感觉整个背部有拉伸感，保持15-20秒
  4. 慢慢回到站立姿势

下半身柔韧性练习

大腿前侧拉伸：

  1. 单脚站立（可以扶墙保持平衡）
  2. 右手抓住右脚踝，将脚跟拉向臀部
  3. 保持大腿与另一条腿平行，感觉大腿前侧有拉伸感
  4. 保持15-20秒，换另一条腿

大腿后侧拉伸：

  1. 坐在地上，双腿向前伸直
  2. 身体慢慢向前弯曲，双手尽量去够脚尖
  3. 感觉大腿后侧有拉伸感，保持15-20秒
  4. 注意膝盖不要弯曲，动作要缓慢

腿部分展（横叉方向）：

  1. 坐在地上，双腿尽量向两侧打开
  2. 身体保持直立，然后慢慢向前弯腰
  3. 双手撑地帮助平衡
  4. 感觉大腿内侧有拉伸感，保持15-20秒

小腿拉伸：

  1. 面对墙壁，双手扶墙
  2. 一脚在前弯曲，一脚在后伸直，脚跟不要离地
  3. 感觉后面那条腿的小腿有拉伸感
  4. 保持15-20秒，换另一条腿

全身柔韧性组合练习

蝴蝶式：

  1. 坐在地上，双脚掌相对合拢
  2. 双手握住脚尖，膝盖尽量向两侧压下
  3. 像蝴蝶翅膀一样上下轻轻扇动膝盖
  4. 做20次，然后保持不动15秒

猫牛式：

  1. 双手双膝着地（四点支撑姿势）
  2. 吸气时抬头、塌腰，像牛一样（牛式）
  3. 呼气时低头、拱背，像猫一样弓起背（猫式）
  4. 交替做10次，动作要慢要连贯

桥式：

  1. 仰躺在垫子上，双脚踩地，膝盖弯曲
  2. 双手放在身体两侧
  3. 臀部慢慢抬起，身体形成一座"桥"
  4. 保持10秒，然后慢慢放下，重复5次

拉伸的注意事项

正确做法 错误做法
动作缓慢、匀速 快速弹振、猛拉硬扯
感觉到拉伸感就保持 拉到疼痛还继续加力
自然呼吸，不憋气 憋着气用力拉伸
每个动作保持15-30秒 拉一下就松开
先热身再拉伸 身体还冷就开始拉伸
左右两侧都要练 只拉伸一侧

练习与思考

  1. 每日拉伸计划：设计一个5分钟的拉伸组合（选择5个动作），每天早上或睡前做一次。坚持两周后测试一下坐位体前屈的距离有没有变化。

  2. 柔韧性测试：

    • 坐位体前屈：坐在地上双腿伸直，身体前弯，看手指能够到哪里（脚尖前方、脚尖、脚踝）
    • 肩部柔韧：一手从肩上方、一手从背后向上，看两只手能不能碰到

  3. 填空题：

    • 拉伸之前必须先做______，让身体温度升高。
    • 每个拉伸动作应该保持______到______秒。
    • 拉伸时应该感觉到______感，但不应该感到______。

  4. 思考题：为什么体育课开始时老师总是先让我们做热身和拉伸？不做行不行？

  5. 同伴练习：和同学一起做坐位体前屈，互相帮助（轻轻推背部），注意力度不要太大。比比看谁进步最多。

拓展阅读

体操运动员的柔韧性令人惊叹——他们可以做出劈叉、后弯腰等高难度动作。这些能力不是天生的，而是从小通过科学、系统的训练练出来的。当然，普通人不需要达到体操运动员的柔韧程度，但适度的柔韧性练习对每个人都有好处。

瑜伽是一种以拉伸和柔韧性为基础的运动，起源于古印度，已有五千多年的历史。现在世界各地都有人练习瑜伽来增强柔韧性、缓解压力。很多儿童瑜伽课程把拉伸动作编成了有趣的"动物姿势"，比如"眼镜蛇式"、"下犬式"等。

科学研究表明，儿童时期是发展柔韧性的最佳时期。随着年龄增长，如果不坚持练习，柔韧性会逐渐下降。所以从小养成拉伸的好习惯，会让你终身受益。

小结

本节课我们学习了柔韧性练习的基本知识和方法。柔韧性可以预防受伤、改善体态、提高运动表现。进行柔韧性练习前一定要先热身。上半身可以做颈部、肩部和背部的拉伸，下半身可以做大腿前侧、后侧和小腿的拉伸。每个动作保持15-30秒，动作要缓慢，感觉到拉伸感即可，不要拉到疼痛。坚持每天练习，你的柔韧性一定会越来越好。
