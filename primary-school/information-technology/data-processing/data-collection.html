五年级信息科技 — 数据采集

知识要点

在信息时代，数据无处不在。学会采集、整理和利用数据是一项重要的信息素养。数据采集是数据处理的第一步，它决定了后续分析的质量和价值。

本课将带领同学们了解数据的来源和类型，学习使用电子表格和简单的 Python 程序进行数据采集，掌握数据记录的规范方法，并通过校园实践项目体验完整的数据采集流程。

核心概念 说明 重要程度
数据的概念与类型 数值型、文本型、日期型等 ⭐⭐⭐⭐⭐
数据来源 直接观测、问卷调查、网络检索 ⭐⭐⭐⭐⭐
电子表格基础 用表格工具记录和整理数据 ⭐⭐⭐⭐⭐
Python 数据采集 用程序自动记录和存储数据 ⭐⭐⭐⭐
数据质量 准确性、完整性、一致性 ⭐⭐⭐⭐
数据伦理 隐私保护、知情同意 ⭐⭐⭐

详细讲解

数据是什么

数据是对事物特征的客观记录。一个同学的姓名、身高、体重、考试成绩，教室的温度、湿度，一天中不同时间的天气变化——这些都是数据。数据可以是数字、文字、图像、声音等多种形式。

数据的常见分类：

数据类型 说明 例子 特点
数值型 可以做数学运算的数字 身高 145cm、温度 26℃ 可以比较大小、计算平均值
文本型 文字描述信息 姓名"张三"、爱好"画画" 不能做数学运算
日期型 时间相关信息 2024-09-01、14:30 有先后顺序
类别型 分类标签 性别（男/女）、等级（A/B/C） 有限个固定选项
布尔型 是非判断 是否近视（是/否） 只有两个值

理解数据类型很重要，因为不同类型的数据需要用不同的方法来采集、存储和分析。比如计算班级平均身高时，用的是数值型数据的求和与除法运算；而统计最受欢迎的课间活动时，用的是类别型数据的计数方法。

数据从哪里来

数据采集的方法多种多样，根据是否需要亲自动手，可以分为直接采集和间接采集两大类。

采集方式 方法 优点 缺点 适用场景
直接观测 亲自测量、记录 数据可靠、可控制条件 耗时费力、范围有限 科学实验、天气记录
问卷调查 设计问题让他人回答 能采集大量信息 可能有虚假回答 意见调查、习惯了解
实验记录 在实验过程中记录数据 条件可控、可重复 需要实验设备 科学课实验
网络检索 从网站、数据库获取 快速、数据量大 需要判断真假 历史数据、公开统计
传感器采集 用电子设备自动记录 连续不断、精确 需要设备支持 温度监测、运动追踪

设计一次好的数据采集活动需要回答几个关键问题：我们要研究什么问题？需要采集哪些数据？从哪里获取这些数据？如何保证数据的准确性？

以"校园植物生长记录"为例：我们需要记录的数据包括植物名称（文本型）、日期（日期型）、株高（数值型）、叶片数量（数值型）、浇水量（数值型）和天气状况（类别型）。确定好需要的数据项后，就可以设计数据记录表了。

用电子表格采集数据

电子表格是最常用的数据采集和管理工具。在电子表格中，数据按行和列有序排列，每一行代表一条记录，每一列代表一个数据项（也叫字段）。

一份规范的数据采集表应该包含以下要素：

要素 说明 注意事项
表头 第一行写明每列数据的含义 名称简洁、含义明确
数据区域 从第二行开始记录数据 每行一条完整记录
数据格式 同一列保持统一格式 数字列不混入文字
单位标注 在表头注明数据单位 如"身高(cm)""体重(kg)"

例如，制作一份"班级同学体质数据表"：

序号 姓名 性别 身高(cm) 体重(kg) 50米跑(秒) 坐位体前屈(cm) 是否近视
1 张明 男 145 38 8.5 12.3 否
2 李华 女 142 35 9.1 15.6 是
3 王芳 女 148 40 8.8 14.2 否

在电子表格中采集数据时，养成以下好习惯很重要：每填一条数据就核对一遍，确保没有输错；定期保存文件，防止数据丢失；给文件起有意义的名字，方便日后查找。

用 Python 采集数据

当需要采集大量数据或进行重复性采集时，使用 Python 程序可以大大提高效率。

一个简单的数据采集程序示例——记录每日气温：

print("=== 每日气温记录程序 ===")
print()

records = []
days = int(input("请输入要记录的天数："))

for i in range(days):
    print(f"\n第 {i + 1} 天：")
    date = input("  日期（如 2024-09-01）：")
    high = float(input("  最高温度（℃）："))
    low = float(input("  最低温度（℃）："))
    weather = input("  天气状况（晴/多云/阴/雨）：")

    record = {
        "日期": date,
        "最高温": high,
        "最低温": low,
        "温差": round(high - low, 1),
        "天气": weather
    }
    records.append(record)
    print(f"  已记录：{date} 最高 {high}℃ 最低 {low}℃ 温差 {record['温差']}℃ {weather}")

print("\n=== 数据汇总 ===")
print(f"共记录 {len(records)} 天数据")

all_highs = [r["最高温"] for r in records]
all_lows = [r["最低温"] for r in records]

print(f"最高温度：{max(all_highs)}℃")
print(f"最低温度：{min(all_lows)}℃")
print(f"平均最高温：{sum(all_highs) / len(all_highs):.1f}℃")
print(f"平均最低温：{sum(all_lows) / len(all_lows):.1f}℃")

这个程序展示了数据采集程序的基本结构：提示用户输入数据、存储数据、最后进行简单的汇总统计。

更进一步，我们可以把采集到的数据保存到文件中，以便日后使用：

file = open("temperature.csv", "w", encoding="utf-8")
file.write("日期,最高温,最低温,温差,天气\n")

for r in records:
    line = f"{r['日期']},{r['最高温']},{r['最低温']},{r['温差']},{r['天气']}\n"
    file.write(line)

file.close()
print("数据已保存到 temperature.csv 文件中")

CSV（逗号分隔值）是一种常用的数据文件格式，几乎所有的电子表格软件都可以打开它。

数据质量与数据伦理

采集到的数据并不总是完美的，有时会出现各种质量问题。

常见的数据质量问题及处理方法：

质量问题 表现 原因 处理方法
数据缺失 某些记录不完整 忘记记录、无法获取 补充采集或标记为缺失
数据错误 明显不合理的值 输入失误、测量错误 核实后更正
数据不一致 同一事物不同记录 标准不统一 制定统一规范
数据重复 同一条记录出现多次 重复录入 去除重复项

在采集涉及个人信息的数据时，还需要注意数据伦理问题。采集前应告知被调查者数据的用途，获得他们的同意；采集过程中要保护个人隐私，不随意公开他人的敏感信息（如成绩、家庭情况等）；数据使用后应妥善保管或删除，不用于约定以外的目的。

练习与思考

  1. 数据分类：学校运动会的报名信息包括：姓名、班级、性别、参赛项目、身高、体重。请判断每项数据的类型（数值型、文本型、类别型等）。

  2. 表格设计：为"我家一周生活支出记录"设计一份电子表格，包含合理的列名和数据格式。要求至少包含日期、支出类别、金额、支付方式四个字段。

  3. Python 采集：修改本课中的气温记录程序，增加数据验证功能——如果用户输入的最低温度高于最高温度，提示错误并要求重新输入。

  4. 质量检查：下面是一组数据记录，找出其中的质量问题并提出改正建议：

    • 李明，身高 145cm，体重 380kg
    • 王红，身高 148cm，体重 36kg
    • 张三，身高 —，体重 42kg
    • 王红，身高 148cm，体重 36kg

  5. 思考题：如果你要调查"同学们最喜欢的课外读物类型"，你会采用什么方式采集数据？请设计一份简单的调查方案，包括采集方法、需要收集的数据项和注意事项。

拓展阅读

数据采集技术的发展经历了从手工到自动化的演变过程。在古代，人口普查需要派人挨家挨户登记，耗时数年才能完成。1890 年，美国发明家赫尔曼·霍勒瑞斯发明了穿孔卡片制表机，大大加速了人口普查数据的处理速度。

如今，物联网技术让数据采集变得更加智能和自动化。气象站的传感器每分钟自动记录温度、湿度、风速等数据；城市交通系统通过摄像头和传感器实时采集车流量数据；智能手环能持续监测我们的心率、步数和睡眠质量。

全球每天产生的数据量高达数百万 TB（太字节），相当于几亿部高清电影的大小。这些海量数据被称为"大数据"，通过分析这些数据，科学家可以预测天气变化、医生可以发现疾病规律、城市规划者可以优化交通路线。可以说，数据已经成为推动社会发展的重要资源。

小结

本课我们系统学习了数据采集的基础知识和实践技能。从理解数据的概念和类型，到掌握直接观测、问卷调查、网络检索等多种采集方法；从使用电子表格规范记录数据，到用 Python 程序实现自动化采集；最后还了解了数据质量和数据伦理的重要性。好的数据采集是一切数据分析的基础——只有采集到准确、完整、规范的数据，才能得出有价值的分析结论。下一课我们将学习如何用图表将数据可视化呈现。
