五年级信息科技 — 算法思维

知识要点

算法是解决问题的一系列有序步骤，它是计算机科学的核心概念。在日常生活中，我们无时无刻不在运用算法思维——从安排一天的学习计划到寻找最短的上学路线，都涉及算法的基本原理。

本课将帮助同学们建立系统的算法思维，学会用流程图和伪代码描述解题步骤，掌握顺序、循环和选择三种基本结构，并通过 Python 程序实现经典算法，培养分析问题和解决问题的能力。

核心概念 说明 重要程度
算法的定义与特征 有穷性、确定性、可行性、输入输出 ⭐⭐⭐⭐⭐
流程图表示 用图形符号描述算法步骤 ⭐⭐⭐⭐⭐
顺序结构 按步骤依次执行 ⭐⭐⭐⭐⭐
循环结构 for 循环和 while 循环 ⭐⭐⭐⭐⭐

经典算法实践 累加、查找、排序等基础算法 ⭐⭐⭐⭐

详细讲解

什么是算法

算法（Algorithm）这个词来源于公元 9 世纪波斯数学家花拉子密的名字。简单来说，算法就是解决某个问题的明确步骤。一个好的算法具备五个基本特征：

特征 含义 生活中的例子
有穷性 步骤是有限的，一定能结束 菜谱的步骤有限，做完就结束
确定性 每一步都清晰明确，不会产生歧义 "加入两勺盐"比"加入适量盐"更明确
可行性 每一步都能实际执行 步骤不能是"瞬间移动到学校"
有输入 可以有零个或多个输入 做菜的原材料就是输入
有输出 至少有一个输出结果 做好的菜就是输出

让我们用一个生活实例来理解算法。假设要从一堆扑克牌中找到黑桃 A，最简单的方法是从第一张开始逐一翻看，直到找到为止。这个过程就是一个"顺序查找"算法：输入是一堆牌，输出是黑桃 A 的位置，步骤是有限且明确的。

流程图：算法的可视化表达

流程图是描述算法的一种直观方法，使用标准化的图形符号来表示不同类型的操作步骤。

流程图的基本符号：

符号形状 名称 用途 示例
椭圆形（圆角矩形） 起止框 表示开始或结束 "开始""结束"
矩形 处理框 表示一个操作步骤 "计算总分"
菱形 判断框 表示条件判断 "分数 ≥ 60？"
平行四边形 输入/输出框 表示数据输入或输出 "输入姓名"
箭头线 流程线 表示执行方向 连接各个步骤

绘制流程图时，要注意从上到下、从左到右的绘制方向，每个判断框要标明"是"和"否"两个分支的方向。流程图的优点是一目了然，即使不懂编程的人也能理解算法的逻辑。

顺序结构与循环结构

程序的三种基本控制结构是算法的基石。顺序结构最简单——程序按照代码书写的顺序从上往下依次执行。

length = float(input("请输入长方形的长（厘米）："))
width = float(input("请输入长方形的宽（厘米）："))
area = length * width
perimeter = 2 * (length + width)
print(f"面积为 {area} 平方厘米")
print(f"周长为 {perimeter} 厘米")

循环结构让程序能够重复执行某段代码。Python 提供了两种循环方式：

for 循环适合已知重复次数的情况：

total = 0
for i in range(1, 101):
    total = total + i
print(f"1 到 100 的累加和为：{total}")

while 循环适合不确定重复次数、由条件控制的情况：

guess = 0
secret = 42
count = 0

while guess != secret:
    guess = int(input("猜一个 1-100 的数字："))
    count = count + 1
    if guess > secret:
        print("太大了！")
    elif guess < secret:
        print("太小了！")

print(f"恭喜你猜对了！你用了 {count} 次")

两种循环的对比：

对比项 for 循环 while 循环
适用场景 已知循环次数 条件控制循环
语法特点 遍历序列或范围 判断条件是否成立
终止方式 遍历完毕自动停止 条件为 False 时停止
常见用途 遍历列表、计数循环 用户交互、搜索
注意事项 range() 左闭右开 避免死循环

经典算法实践：查找与排序

查找和排序是计算机科学中最基础也最重要的算法。

顺序查找——从头到尾逐个检查：

scores = [85, 92, 78, 95, 88, 76, 91, 83]
target = int(input("请输入要查找的分数："))

found = False
for i in range(len(scores)):
    if scores[i] == target:
        print(f"找到了！{target} 在第 {i + 1} 个位置")
        found = True
        break

if not found:
    print(f"没有找到分数 {target}")

冒泡排序——通过相邻元素比较和交换来排序：

numbers = [64, 34, 25, 12, 22, 11, 90]
n = len(numbers)

for i in range(n - 1):
    for j in range(n - 1 - i):
        if numbers[j] > numbers[j + 1]:
            numbers[j], numbers[j + 1] = numbers[j + 1], numbers[j]

print("排序结果：", numbers)

冒泡排序的过程就像水中的气泡——较大的数字会像气泡一样逐渐"浮"到数列的末尾。每一轮比较后，当前最大的未排序数字都会到达正确位置。

算法效率初探

同一个问题可能有多种不同的解法，那么如何评价哪种算法更好呢？最直观的标准就是看算法执行的步骤数量。

以查找为例，假设有 100 个数据：

算法 最好情况 最坏情况 平均情况
顺序查找 1 次比较 100 次比较 50 次比较
二分查找（数据已排序） 1 次比较 7 次比较 约 6 次比较

二分查找的思想类似于猜数字游戏中的"折半"策略——每次都猜中间值，根据大小提示排除一半的可能性。这种方法效率远高于逐个查找，但要求数据必须事先排好顺序。

numbers = [11, 12, 22, 25, 34, 64, 78, 85, 90, 95]
target = 78
low = 0
high = len(numbers) - 1
steps = 0

while low <= high:
    mid = (low + high) // 2
    steps = steps + 1
    if numbers[mid] == target:
        print(f"找到 {target}，位置为第 {mid + 1} 个，用了 {steps} 步")
        break
    elif numbers[mid] < target:
        low = mid + 1
    else:
        high = mid - 1

算法效率的概念告诉我们：解决问题不仅要找到正确方法，还要思考如何用更少的步骤、更高效的方式完成任务。这种追求效率的思维方式在学习和生活中同样适用。

练习与思考

  1. 流程图绘制：画出"判断一个年份是否为闰年"的流程图。闰年规则：能被 4 整除但不能被 100 整除，或者能被 400 整除。

  2. 循环练习：用 for 循环编写程序，输出九九乘法表。提示：需要使用两层嵌套循环，外层控制行，内层控制列。

  3. 查找挑战：编写一个程序，输入一个班级 10 位同学的成绩，然后找出最高分、最低分和平均分。

  4. 排序理解：手动模拟冒泡排序的过程，对数列 [5, 3, 8, 1, 9, 2] 进行排序，写出每一轮比较后数列的状态。

  5. 思考题：想一想日常生活中还有哪些"算法"的例子？比如图书馆找书、超市排队等场景中，分别使用了什么样的策略？

拓展阅读

算法的历史非常悠久。早在两千多年前，古希腊数学家欧几里得就提出了"辗转相除法"来求两个数的最大公约数，这被认为是世界上最早的算法之一。中国古代的《九章算术》中也包含了大量精妙的算法思想。

在现代计算机科学中，算法的研究已经发展成一个庞大的学科体系。著名计算机科学家唐纳德·克努特（Donald Knuth）编写的《计算机程序设计艺术》被称为算法领域的"圣经"。谷歌搜索引擎的核心就是 PageRank 算法，它能在数十亿网页中快速找到你需要的信息。

学习算法思维不仅是编程的需要，更是培养逻辑推理能力的有效途径。当你学会把复杂问题分解成简单步骤，并找到高效的解决方案时，你就已经在运用算法思维了。

小结

本课我们系统学习了算法思维的基本概念和核心技能。从算法的五大特征到流程图的绘制方法，从三种基本控制结构到经典的查找与排序算法，我们逐步建立了用计算机思维解决问题的能力。记住，学习算法的关键在于"先想后写"——拿到问题后先用自然语言或流程图理清思路，再转化为程序代码。下一课我们将学习调试技巧，掌握如何发现和修复程序中的错误。
