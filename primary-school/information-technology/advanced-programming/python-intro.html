五年级信息科技 — Python 编程入门

知识要点

Python 是当今世界最受欢迎的编程语言之一，因其语法简洁、易于学习而被广泛用于科学计算、人工智能、网站开发等领域。对于已经掌握图形化编程基础的五年级同学来说，学习 Python 是迈向文本编程的重要一步。

本课将引导同学们认识 Python 语言的基本特点，学会搭建编程环境，掌握变量、数据类型、输入输出和基本运算等核心概念，并通过编写简单程序感受文本编程的魅力。

核心概念 说明 重要程度
Python 语言特点 简洁易读、跨平台、社区活跃 ⭐⭐⭐⭐⭐
编程环境搭建 安装 Python、使用 IDLE 编辑器 ⭐⭐⭐⭐⭐
变量与数据类型 整数、浮点数、字符串、布尔值 ⭐⭐⭐⭐⭐
输入与输出 input() 和 print() 函数 ⭐⭐⭐⭐⭐
基本运算 算术运算、字符串拼接、比较运算 ⭐⭐⭐⭐
条件语句 if-elif-else 分支结构 ⭐⭐⭐⭐

详细讲解

认识 Python 语言

Python 由荷兰程序员吉多·范罗苏姆（Guido van Rossum）在 1991 年创造，名字来源于他喜爱的英国喜剧团体"Monty Python"。Python 的设计哲学强调代码的可读性和简洁性，用缩进来表示代码块，而不是像其他语言那样使用大括号。

Python 的主要特点包括：

特点 具体表现 与图形化编程对比
语法简洁 接近自然语言，代码量少 类似积木块的简单直观
解释执行 逐行运行，即时看到结果 类似点击"运行"按钮
跨平台 Windows、Mac、Linux 都能运行 图形化编程通常只在浏览器中
库丰富 有大量现成的功能模块 类似扩展积木包
社区活跃 全球数百万开发者使用 学习资源更加丰富

从图形化编程到 Python 的过渡其实并不困难。在 Scratch 中，我们拖拽积木来控制角色；在 Python 中，我们用文字来描述同样的逻辑。例如，Scratch 中的"说 你好"积木块，在 Python 中就是一行简单的代码。

搭建编程环境

学习 Python 编程，首先需要在电脑上安装 Python 软件。安装完成后，我们可以使用自带的 IDLE 编辑器来编写和运行程序。

安装和使用的基本步骤：

  1. 从 Python 官方网站下载安装包
  2. 安装时勾选"Add Python to PATH"选项
  3. 打开 IDLE 编辑器
  4. 在交互模式下直接输入代码，按回车即可运行
  5. 创建新文件（.py），编写完整程序后保存并运行

IDLE 编辑器有两种使用模式：

模式 特点 适合场景
交互模式（Shell） 输入一行，执行一行，立即显示结果 测试小段代码、做计算
脚本模式（Editor） 编写完整程序，保存后一次性运行 编写较长的程序

在交互模式下，我们可以立刻尝试第一个 Python 命令：

print("你好，世界！")

运行后屏幕会显示"你好，世界！"，这就是你的第一个 Python 程序。

变量与数据类型

变量是程序中用来存储数据的"容器"。在 Python 中，创建变量非常简单，只需要给它起一个名字并赋值即可。

name = "小明"
age = 11
height = 1.45
is_student = True

Python 中常用的数据类型：

数据类型 英文名 示例 用途
整数 int 11, -5, 0, 100 计数、年龄、数量
浮点数 float 1.45, 3.14, -0.5 身高、体重、分数
字符串 str "你好", "Python" 文字、名字、句子
布尔值 bool True, False 判断真假、开关状态

变量命名有几条重要规则：变量名只能包含字母、数字和下划线，不能以数字开头，不能使用 Python 的关键字（如 if、for、while 等），并且变量名区分大小写（name 和 Name 是两个不同的变量）。

好的变量命名应该有描述性，让人一看就知道这个变量存储了什么数据。例如用 student_name 而不是用 a 或 x。

输入与输出

程序与用户交互主要依靠输入和输出功能。print() 函数用于输出信息到屏幕，input() 函数用于从键盘获取用户输入。

print("欢迎来到 Python 世界！")
name = input("请输入你的名字：")
print("你好，" + name + "！很高兴认识你。")

print() 函数的常见用法：

print("直接输出文字")
print(100)
print("我今年", 11, "岁")
print("姓名：" + "小明")
print(f"圆周率约为 {3.14159:.2f}")

需要注意的是，input() 函数获取的数据始终是字符串类型。如果需要进行数学运算，必须先将其转换为数字类型：

age_text = input("请输入你的年龄：")
age = int(age_text)
print("明年你就", age + 1, "岁了！")

基本运算与条件判断

Python 支持丰富的运算操作，从基本的加减乘除到条件判断，都能轻松实现。

算术运算符一览：

运算符 含义 示例 结果
+ 加法 5 + 3 8
- 减法 10 - 4 6
* 乘法 6 * 7 42
/ 除法 15 / 4 3.75
// 整除 15 // 4 3
% 取余 15 % 4 3
** 幂运算 2 ** 3 8

条件语句让程序能够根据不同情况做出不同反应。这就像生活中的"如果……就……否则……"：

score = int(input("请输入你的分数："))

if score >= 90:
    print("优秀！继续保持！")
elif score >= 80:
    print("良好！再接再厉！")
elif score >= 60:
    print("及格了，还需努力！")
else:
    print("加油，下次一定能进步！")

特别注意 Python 中条件语句的格式：if 后面跟条件和冒号，下一行要缩进四个空格。缩进是 Python 最重要的语法规则之一，它告诉计算机哪些代码属于同一个代码块。

编写第一个完整程序

综合运用所学知识，我们来编写一个"个人信息卡"程序：

print("=" * 30)
print("   个人信息卡生成器")
print("=" * 30)

name = input("请输入姓名：")
age = int(input("请输入年龄："))
hobby = input("请输入爱好：")
subject = input("请输入最喜欢的科目：")

print()
print("+" + "-" * 28 + "+")
print(f"| 姓名：{name}")
print(f"| 年龄：{age} 岁")
print(f"| 爱好：{hobby}")
print(f"| 最爱科目：{subject}")

if age >= 12:
    print("| 身份：中学生")
else:
    print("| 身份：小学生")

print("+" + "-" * 28 + "+")
print("信息卡生成完毕！")

这个程序展示了变量、输入输出、字符串拼接和条件判断的综合运用。同学们可以在此基础上增加更多功能，比如计算出生年份、添加更多个人信息等。

练习与思考

  1. 基础练习：编写一个程序，让用户输入两个数字，然后分别输出它们的和、差、积、商。注意处理除数为零的情况。

  2. 变量探索：创建四个不同类型的变量（整数、浮点数、字符串、布尔值），用 print() 和 type() 函数分别输出它们的值和类型。

  3. 条件练习：编写一个"体温检测"程序，用户输入体温数值，程序判断并提示体温是否正常（36.1-37.2 为正常范围）。

  4. 创意挑战：编写一个简单的"猜数字提示"程序，程序中预设一个数字，用户输入一个猜测值，程序提示"太大了""太小了"或"恭喜你猜对了"。

  5. 思考题：Python 用缩进来表示代码块，你觉得这种设计有什么优点和缺点？与图形化编程中的嵌套积木相比，哪种方式更容易理解？

拓展阅读

Python 的应用范围非常广泛。在科学研究领域，科学家用 Python 分析天文数据、模拟气候变化；在人工智能领域，Python 是开发智能程序的首选语言；在网站开发领域，许多知名网站的后台都使用 Python 构建。

国际上许多国家已经将 Python 纳入中小学信息技术课程。英国从 2014 年开始在小学阶段教授编程，美国的"编程一小时"活动让数百万学生体验了 Python 编程的乐趣。学好 Python，不仅能提升逻辑思维能力，更能为未来的学习和工作打下坚实基础。

Python 之父吉多·范罗苏姆曾说过："Python 的设计理念是让代码尽可能地易读。"这种追求简洁和优雅的精神，值得每一位编程初学者学习和体会。

小结

本课我们迈出了文本编程的第一步，从认识 Python 语言到搭建编程环境，从学习变量和数据类型到掌握输入输出和条件判断。Python 的语法简洁直观，与之前学习的图形化编程有异曲同工之处，但提供了更强大的表达能力。记住编程学习最重要的方法就是多动手实践——每学一个新概念，就立刻在 IDLE 中尝试运行，在不断的练习中积累经验。下一课我们将深入学习算法思维，探索如何用 Python 解决更复杂的问题。
