六年级信息科技 — 网页基础

知识要点

网页是互联网上展示信息的基本单位。我们每天浏览的网站都是由一个个网页组成的。了解网页的基本结构和制作方法，不仅能让我们更好地理解互联网的运作原理，还能培养信息素养和基本的编程思维。

网页技术的三大基础：

技术 作用 比喻
HTML 定义网页的内容和结构 房子的骨架
CSS 控制网页的外观和样式 房子的装修
JavaScript 让网页具有交互功能 房子里的电器

网页的基本组成元素：

元素 说明 示例
标题 网页的大标题 "欢迎来到我的主页"
文本 正文内容 自我介绍、文章内容
图片 展示的图像 照片、插图
链接 跳转到其他页面 "点击查看更多"
列表 有序或无序的项目列表 爱好清单
表格 行列组织的数据 课程表
视频 嵌入的视频内容 学习视频

详细讲解

HTML基础——网页的骨架

HTML（超文本标记语言）使用标签来定义网页内容。每个标签都用尖括号括起来：

<!DOCTYPE html>
<html>
<head>
    <title>我的第一个网页</title>
</head>
<body>
    <h1>欢迎来到我的主页</h1>
    <p>大家好，我是一名六年级的学生。</p>
</body>
</html>

常用的HTML标签：

标签 用途 示例
<h1>到<h6> 标题（1最大，6最小） <h1>大标题</h1>
<p> 段落 <p>这是一段文字</p>
<img> 插入图片 <img src="photo.jpg">
<a> 超链接 <a href="page2.html">链接</a>
<ul>和<li> 无序列表 圆点开头的列表
<ol>和<li> 有序列表 数字开头的列表
<table> 表格 行列组织的数据
<div> 内容分区 将内容分组

CSS基础——网页的样式

CSS（层叠样式表）控制网页的颜色、字体、布局等外观效果：

h1 {
    color: blue;
    font-size: 24px;
    text-align: center;
}

p {
    color: #333333;
    font-size: 16px;
    line-height: 1.5;
}

常用的CSS属性：

属性 作用 示例值
color 文字颜色 red, blue, #FF0000
font-size 字体大小 16px, 20px
background-color 背景颜色 yellow, #EEEEEE
text-align 文字对齐 left, center, right
margin 外边距 10px, 20px
padding 内边距 10px, 15px
border 边框 1px solid black
width 宽度 300px, 50%

网页设计原则

好的网页设计应该遵循以下原则：

原则 说明 做法
内容为王 内容是网页最重要的部分 先确定要展示什么内容
结构清晰 信息层级分明 使用标题、分段、列表
视觉舒适 配色和谐，不刺眼 使用2-3种主要颜色
导航便捷 用户能快速找到想要的信息 设置清晰的导航菜单
加载快速 图片大小适中 优化图片，不用太大的文件
适配不同设备 手机和电脑都能正常显示 使用响应式设计

制作个人主页

一个简单的个人主页通常包含以下部分：

部分 内容 HTML结构
头部 网站标题和导航 <header>
关于我 自我介绍和照片 <section>
兴趣爱好 用列表展示兴趣爱好 <ul>
作品展示 展示自己的作品 <img>
联系方式 提供联系方式 <footer>

网页与信息安全

在制作和浏览网页时要注意安全：

安全事项 说明
不在网页上公开个人隐私 不放家庭地址、电话号码
注意网页来源 不点击来源不明的链接
保护账号安全 使用强密码，不在公共电脑保存密码
识别虚假网站 检查网址是否正确，有没有安全锁标志

练习与思考

练习一：分析一个网页

打开你最常访问的一个网站，观察并记录：

分析项目 你的观察
网页标题是什么
有哪些主要内容区域
使用了哪些颜色
导航菜单有哪些选项
有哪些互动功能

练习二：设计个人主页草图

在纸上画出你的个人主页的设计草图，包括：

  • 页面的整体布局
  • 各区域放置什么内容
  • 使用什么配色方案
  • 导航菜单包含哪些链接

练习三：编写简单的HTML

尝试用记事本编写一个简单的HTML页面，包含：

  • 一个大标题（你的名字）
  • 一段自我介绍
  • 一个兴趣爱好列表
  • 保存为.html文件，用浏览器打开查看效果

拓展阅读

万维网（World Wide Web）由英国科学家蒂姆·伯纳斯-李于1989年发明。他最初的目的是让世界各地的科学家能方便地共享研究信息。第一个网站于1991年上线，至今全球已有超过20亿个网站。

HTML从1993年的第一版发展到现在的HTML5，功能越来越强大。现在的网页不仅能展示文字和图片，还能播放视频、运行3D游戏、进行视频通话。许多我们每天使用的应用（如在线文档、电子邮件）实际上就是在浏览器中运行的网页程序。

学习网页制作是进入编程世界的最佳起点之一，因为你可以立即在浏览器中看到自己的创作成果。从一个简单的个人主页开始，逐步学习更多技术，你也可以创造出有用、有趣的网站。

小结

  • 网页由HTML（内容结构）、CSS（外观样式）和JavaScript（交互功能）三大技术构成
  • HTML使用标签定义内容，常用标签包括标题、段落、图片、链接和列表
  • CSS控制颜色、字体、布局等外观属性
  • 好的网页设计遵循内容为王、结构清晰、视觉舒适等原则
  • 制作网页时要注意信息安全，不公开个人隐私
