五年级信息科技 — 机器人编程

知识要点

机器人编程是将计算机编程知识应用到实体机器人控制中的实践活动。通过编写程序，我们可以让机器人完成各种任务——行走、避障、搬运、绘画等。机器人编程不仅综合了编程、数学和工程知识，还培养了动手实践和解决实际问题的能力。

本课将带领同学们了解机器人的基本构成，学习传感器和执行器的原理，掌握机器人编程的基本方法，并通过项目实践体验控制机器人完成任务的乐趣。

核心概念 说明 重要程度
机器人的构成 控制器、传感器、执行器 ⭐⭐⭐⭐⭐
传感器原理 获取环境信息的"感觉器官" ⭐⭐⭐⭐⭐
执行器控制 让机器人运动和动作的部件 ⭐⭐⭐⭐⭐
编程控制逻辑 感知-决策-执行循环 ⭐⭐⭐⭐⭐
巡线与避障 经典机器人任务编程 ⭐⭐⭐⭐
项目实践 完成综合性机器人任务 ⭐⭐⭐⭐

详细讲解

机器人的基本构成

一个机器人通常由三个核心部分组成，它们的关系就像人体的感觉系统、大脑和运动系统。

组成部分 功能 对应人体部分 具体部件
传感器 获取环境信息 眼睛、耳朵、皮肤等感觉器官 光线传感器、超声波传感器、触碰传感器
控制器 处理信息、做出决策 大脑 主板（运行我们编写的程序）
执行器 执行动作和任务 手、脚等运动器官 电机、舵机、蜂鸣器、LED 灯

这三部分通过"感知-决策-执行"循环协同工作：传感器采集环境数据，控制器根据程序分析数据并做出决策，执行器根据决策完成具体动作。这个循环每秒可能执行数十甚至数百次，让机器人能够实时响应环境变化。

例如一个自动避障小车的工作流程：超声波传感器检测前方障碍物距离（感知）→ 程序判断距离是否小于 20 厘米（决策）→ 如果太近则转向，否则继续前进（执行）。

认识常见传感器

传感器是机器人的"感觉器官"，不同类型的传感器让机器人具备不同的感知能力。

传感器类型 检测内容 工作原理 常见应用
光线传感器 光照强度 检测光的亮暗变化 自动开灯、巡线机器人
超声波传感器 距离 发射声波并接收回声，计算距离 避障、测距
触碰传感器 物理接触 被按压时产生信号 碰撞检测、按钮交互
红外传感器 红外光反射 检测反射红外光的强弱 巡线（区分黑白线）
颜色传感器 颜色 分析反射光的颜色成分 颜色识别和分类
温度传感器 温度 感知温度变化 环境监测
陀螺仪 方向和角度 检测旋转运动 平衡控制、方向判断

超声波传感器的工作原理特别有趣，它模仿了蝙蝠的回声定位方式。传感器发射一串超声波脉冲，声波碰到障碍物后反弹回来，根据声波往返的时间就能计算出障碍物的距离。因为声音在空气中的传播速度大约是 340 米/秒，所以距离 = 速度 × 时间 ÷ 2（除以 2 是因为声波走了一个来回）。

执行器与运动控制

执行器是机器人的"手和脚"，负责完成各种物理动作。

执行器类型 功能 控制参数 应用场景
直流电机 驱动轮子旋转 速度、方向 机器人行走、转向
舵机 精确转动到指定角度 角度（0-180°） 机械臂、云台
蜂鸣器 发出声音 频率、时长 提示音、简单音乐
LED 灯 发光显示 亮度、颜色 状态指示、装饰
液晶屏 显示文字和图形 内容、位置 显示信息

用两个电机控制机器人的运动方向是机器人编程的基础技能：

左电机 右电机 机器人运动
正转 正转 直行前进
反转 反转 直行后退
停止 正转 左转
正转 停止 右转
反转 正转 原地左旋
正转 反转 原地右旋
停止 停止 停止

通过控制两个电机的转速差还能实现弧线运动。例如左电机速度 50%、右电机速度 100%，机器人就会向左画一个大圆弧。

机器人编程实践

下面用 Python 风格的伪代码来展示几个经典的机器人编程任务。

任务一：走正方形路径

import robot

for i in range(4):
    robot.forward(speed=50, duration=2)
    robot.turn_right(angle=90)
    robot.wait(0.5)

robot.stop()
print("正方形路径完成！")

任务二：超声波避障

import robot

while True:
    distance = robot.ultrasonic.read()

    if distance > 30:
        robot.forward(speed=60)
        robot.led.color("green")
    elif distance > 15:
        robot.forward(speed=30)
        robot.led.color("yellow")
    else:
        robot.stop()
        robot.led.color("red")
        robot.buzzer.beep(duration=0.3)
        robot.backward(speed=30, duration=0.5)
        robot.turn_right(angle=90)

    robot.wait(0.1)

这段程序让机器人根据前方障碍物的距离做出不同反应：距离远则全速前进（绿灯），距离适中则减速前进（黄灯），距离太近则停止、后退并转弯（红灯并报警）。

任务三：红外巡线

import robot

while True:
    left_sensor = robot.infrared_left.read()
    right_sensor = robot.infrared_right.read()

    if left_sensor == "black" and right_sensor == "black":
        robot.forward(speed=40)
    elif left_sensor == "black" and right_sensor == "white":
        robot.turn_left(speed=30)
    elif left_sensor == "white" and right_sensor == "black":
        robot.turn_right(speed=30)
    else:
        robot.stop()
        robot.buzzer.beep(duration=0.5)

    robot.wait(0.05)

巡线机器人使用两个红外传感器检测地面黑线。当两个传感器都在黑线上时直行，偏左则右转修正，偏右则左转修正，从而沿着黑线行驶。

调试机器人程序

机器人程序的调试比纯软件程序更具挑战性，因为涉及到物理世界的不确定性。

常见问题 可能原因 调试方法
机器人走不直 两个电机速度不一致 微调电机速度参数
传感器读数不稳定 环境光干扰、距离太远 多次读数取平均、调整阈值
反应迟钝 程序延迟太大 减小 wait 时间
转弯角度不准 地面摩擦力不同 实际测试并调整参数
巡线时跑偏 传感器位置不对称 调整传感器安装位置

调试机器人的一个重要原则是"先简后繁"。不要一开始就写复杂的程序，先确保基本功能正常（电机能转、传感器能读数），再逐步添加更复杂的逻辑。每修改一处就测试一次，这样容易定位问题。

练习与思考

  1. 构成分析：观察一个扫地机器人（或其他家用机器人），分析它包含哪些传感器和执行器，各自的功能是什么。

  2. 路径设计：设计一段伪代码，让机器人走出一个等边三角形的路径。提示：等边三角形每个角的外角是 120 度。

  3. 避障升级：在本课超声波避障程序的基础上，添加功能：当机器人连续遇到 3 次障碍时，让它发出特殊的求救信号（如连续三声短鸣）并停止运动。

  4. 传感器匹配：为以下场景选择最合适的传感器，并简要说明理由：

    • 自动感应门在有人靠近时打开
    • 机器人在黑暗中自动开灯
    • 机械臂夹取物品时控制力度
    • 无人机保持水平飞行姿态

  5. 思考题：为什么现实中的机器人程序需要反复调试和修改，而不能一次就写对？物理世界和虚拟世界的编程有什么本质区别？

拓展阅读

机器人技术的发展经历了从工业到生活的转变。最早的工业机器人出现在 1961 年的美国通用汽车工厂，名叫"尤尼梅特"，它的工作是搬运沉重的汽车零件。如今，全球有超过 300 万台工业机器人在工厂中工作，完成焊接、喷漆、组装等任务。

在教育领域，机器人编程已经成为 STEM 教育的重要组成部分。国际上有多个面向中小学生的机器人竞赛，如 FIRST 乐高联赛（FLL）和世界机器人大赛（WRC），中国学生在这些比赛中屡获佳绩。

未来的机器人将更加智能和灵活。波士顿动力公司的机器人 Atlas 已经能像人一样奔跑、跳跃和翻跟头；日本的人形机器人 ASIMO 能识别人脸和手势、在不平坦的地面行走。软体机器人是另一个前沿方向，它们模仿章鱼等柔软生物的运动方式，可以在狭小空间中灵活穿行。

小结

本课我们深入学习了机器人编程的知识和技能。从理解机器人的三大构成（传感器、控制器、执行器）及其"感知-决策-执行"工作循环，到认识各种传感器和执行器的功能原理；从掌握电机运动控制的基本方法，到编写避障和巡线等经典任务程序。机器人编程的魅力在于让代码走出屏幕、进入现实世界——我们编写的每一行程序都能驱动真实的物理运动。在调试中保持耐心，从简单任务开始逐步挑战复杂项目，你会在机器人编程中收获无穷的乐趣。下一课我们将探索智能应用，了解 AI 如何与各种技术结合创造出改变生活的产品。
