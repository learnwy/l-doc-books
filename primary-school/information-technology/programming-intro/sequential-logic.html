四年级信息科技 — 顺序与循环

知识要点

在编程中，计算机是按照我们给它的指令一步一步执行的。"顺序"和"循环"是编程中最基本的两种结构。顺序就是按照先后顺序依次执行指令，循环就是让某些指令重复执行多次。

概念 含义 生活举例
顺序结构 按照从上到下的顺序执行 做菜的步骤：洗菜→切菜→炒菜
循环结构 重复执行某段指令 跳绳：跳一下→跳一下→…重复100次
有限循环 重复固定次数 跑操场3圈
无限循环 一直重复不停 时钟的指针不停转动
嵌套循环 循环里面还有循环 每天重复：起床→上学→放学→睡觉

理解顺序和循环是学习编程最重要的第一步，所有复杂的程序都是由这些基本结构组成的。

详细讲解

一、顺序结构

顺序结构是最简单的编程结构：计算机按照代码从上到下的顺序，一条一条地执行。

生活中的顺序：

步骤 做早操 刷牙
第1步 站好队形 挤牙膏
第2步 伸展运动 含水漱口
第3步 踏步运动 上下刷
第4步 跳跃运动 漱口吐水
第5步 放松整理 清洗牙刷

在Scratch中的顺序执行：

当绿旗被点击
移动50步
等待1秒
转动90度
等待1秒
移动50步

这段程序会按照从上到下的顺序，一步一步执行。

二、循环结构——重复的力量

如果想让角色画一个正方形，需要"移动+转弯"重复4次。

不用循环的写法（很啰嗦）：

移动100步 → 右转90度
移动100步 → 右转90度
移动100步 → 右转90度
移动100步 → 右转90度

用循环的写法（简洁多了）：

重复4次：
    移动100步
    右转90度

两种写法效果完全一样，但循环写法更简洁、更高效。

三、有限循环和无限循环

类型 Scratch中的积木 用途
有限循环 重复N次 执行固定次数的操作
无限循环 重复执行 一直执行直到手动停止

有限循环的例子： 画一个正三角形：

重复3次：
    移动100步
    右转120度

画一个正六边形：

重复6次：
    移动60步
    右转60度

发现规律了吗？正N边形就是"重复N次：移动X步，右转(360÷N)度"。

无限循环的例子： 让角色一直在屏幕上来回走：

重复执行：
    移动10步
    碰到边缘就反弹

四、循环中的变化

循环不一定每次都做完全一样的事。可以在循环中加入变化：

螺旋线：

重复50次：
    移动（步数）步     ← 步数每次增加2
    右转15度

每次移动的步数不同，就能画出螺旋形。

彩色图案：

重复36次：
    画一个正方形
    右转10度

画一个正方形后转动一点角度再画，重复36次（36×10=360度），就能画出一个美丽的旋转图案。

五、用循环解决实际问题

任务 不用循环 用循环
画10个圆 写10遍画圆的代码 重复10次画圆
数到100 说1说2…说100 变量从1到100重复
跳绳计数 一个一个加 重复N次加1

循环让我们用少量的代码完成大量的工作，这就是编程的魔力。

练习与思考

练习一：顺序练习

在Scratch中编写一个顺序程序：

  1. 角色说"准备好了吗？"等2秒
  2. 移动100步
  3. 说"到了！"等2秒
  4. 播放一个音效

练习二：画正多边形

用循环画出以下图形：

  1. 正三角形（重复3次，右转120度）
  2. 正方形（重复4次，右转90度）
  3. 正六边形（重复6次，右转60度）

思考：要画正八边形，每次应该转多少度？

练习三：创意图案

用循环画一个旋转图案：

重复36次：
    移动50步
    右转10度
    移动50步
    右转170度

试试改变数字，看看能画出什么有趣的图案。

练习四：生活中的循环

想一想你的日常生活中有哪些循环？（比如每天上学的路线、每周的课程表）列出至少3个，并说明它们分别是有限循环还是无限循环。

拓展阅读

顺序和循环是计算机科学中最基础的概念。除了这两种结构外，还有一种叫"选择结构"（条件判断），在下一课中你会学到。这三种结构——顺序、循环、选择——被称为"程序设计的三种基本结构"，任何复杂的程序都可以由它们组合而成。

循环在数学中也有对应的概念。比如计算1+2+3+...+100的和，著名数学家高斯小时候用巧妙的方法计算出结果是5050。但如果让计算机来算，只需要一个循环从1加到100就行了。计算机虽然没有高斯那么聪明，但它计算速度快，循环一百万次也只需要一瞬间。

在现实世界中，循环无处不在：地球自转和公转是循环、四季更替是循环、水循环是循环。理解循环的概念，不仅有助于学习编程，也有助于理解自然规律。

小结

本课学习了编程中的顺序结构和循环结构。顺序结构是按照从上到下的顺序执行指令，循环结构是让某段指令重复执行。循环分为有限循环和无限循环。用循环可以用少量代码完成大量重复性工作，是编程中最强大的工具之一。
