TestFlight 内测分发

概述

TestFlight 是 Apple 官方的 Beta 测试平台，允许开发者将预发布版本分发给内部团队和外部测试用户。它是 App 提交 App Store 之前收集反馈、验证质量的核心环节。与 Ad Hoc 分发相比，TestFlight 不需要收集设备 UDID，外部测试最多支持 10,000 名测试人员。

TestFlight 分为内部测试和外部测试两种模式。内部测试面向开发团队成员（最多 100 人），上传后即可安装，无需 Apple 审核；外部测试面向指定的测试人员或公开链接，首次提交需要经过 Beta App Review。

工作流程
步骤一：构建 Archive
通过 Xcode GUI 或命令行创建 Archive：


xcodebuild archive \
  -workspace MyApp.xcworkspace \
  -scheme MyApp \
  -configuration Release \
  -archivePath ./build/MyApp.xcarchive \
  -destination "generic/platform=iOS" \
  DEVELOPMENT_TEAM=ABCDEF1234 \
  CODE_SIGN_STYLE=Manual \
  PROVISIONING_PROFILE_SPECIFIER="MyApp_AppStore"
步骤二：导出 IPA
xcodebuild -exportArchive \
  -archivePath ./build/MyApp.xcarchive \
  -exportPath ./build/ipa \
  -exportOptionsPlist ExportOptions.plist
ExportOptions.plist 配置：


<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>method</key>
    <string>app-store</string>
    <key>teamID</key>
    <string>ABCDEF1234</string>
    <key>uploadSymbols</key>
    <true/>
    <key>uploadBitcode</key>
    <false/>
</dict>
</plist>
步骤三：上传构建
xcrun altool --upload-app \
  -f ./build/ipa/MyApp.ipa \
  -t ios \
  -u "ci@myteam.com" \
  -p "@keychain:AC_PASSWORD"
步骤四：配置测试组
内部测试：


    

  • 最多 100 名测试人员（必须是 App Store Connect 用户）
    • 

  • 上传后立即可用，无需 Apple 审核
    • 

  • 适合开发团队日常验证
    • 



外部测试：


    

  • 最多 10,000 名测试人员
    • 

  • 可通过邮箱邀请或公开链接加入
    • 

  • 首次提交或重大更新需要 Beta App Review（通常 24-48 小时）
    • 

  • 支持多个测试组，每组可分配不同构建版本
    •

自动更新
测试人员的 TestFlight App 可自动安装最新构建





fastlane pilot 自动化
# Fastfile
lane :beta do
  increment_build_number
  build_app(
    workspace: "MyApp.xcworkspace",
    scheme: "MyApp",
    export_method: "app-store"
  )
  upload_to_testflight(
    skip_waiting_for_build_processing: false,
    distribute_external: true,
    groups: ["QA Team", "Stakeholders"],
    changelog: "修复了登录页面的崩溃问题\n优化了列表加载性能"
  )
end
fastlane beta
fastlane pilot 常用命令：


# 上传并分发
fastlane pilot upload --ipa ./build/MyApp.ipa

# 查看已上传的构建
fastlane pilot builds

# 添加外部测试人员
fastlane pilot add email:tester@example.com group:"QA Team"

# 移除测试人员
fastlane pilot remove email:tester@example.com

# 列出所有测试人员
fastlane pilot list
实战演示
一个完整的 CI 脚本示例——从构建到 TestFlight 分发：


#!/bin/bash
set -euo pipefail

APP_SCHEME="MyApp"
WORKSPACE="MyApp.xcworkspace"
ARCHIVE_PATH="./build/MyApp.xcarchive"
IPA_DIR="./build/ipa"

echo "=== 递增构建号 ==="
BUILD_NUMBER=$(date +%Y%m%d%H%M)
/usr/libexec/PlistBuddy -c "Set :CFBundleVersion $BUILD_NUMBER" \
  MyApp/Info.plist

echo "=== Archive ==="
xcodebuild archive \
  -workspace "$WORKSPACE" \
  -scheme "$APP_SCHEME" \
  -archivePath "$ARCHIVE_PATH" \
  -destination "generic/platform=iOS" \
  CODE_SIGN_STYLE=Manual

echo "=== Export IPA ==="
xcodebuild -exportArchive \
  -archivePath "$ARCHIVE_PATH" \
  -exportPath "$IPA_DIR" \
  -exportOptionsPlist ExportOptions.plist

echo "=== Upload to TestFlight ==="
xcrun altool --upload-app \
  -f "$IPA_DIR/$APP_SCHEME.ipa" \
  -t ios \
  -u "$APPLE_ID" \
  -p "$APP_SPECIFIC_PASSWORD"

echo "=== Done ✅ ==="
常见问题
问题一：上传后构建长时间处于 "Processing" 状态
原因：Apple 服务端处理需要时间，通常 5-30 分钟，高峰期可能更久。


解决：


    

  1. 耐心等待，避免重复上传同一构建号
    2. 

  2. 检查 App Store Connect 的邮箱通知，处理完成后会收到邮件
    3. 

  3. 如果超过 1 小时仍未完成，尝试递增构建号后重新上传
    4. 



问题二：外部测试提交后 Beta Review 被拒
原因：Beta Review 也会检查基本的 App Store Guidelines 合规性。


解决：


    

  1. 确保 App 不会崩溃、基本功能完整
    2. 

  2. 填写完整的 "What to Test" 说明
    3. 

  3. 如果使用了登录功能，提供测试账号
    4. 



问题三：构建号冲突 "has already been uploaded"
原因：同一个版本号 + 构建号的组合只能上传一次。


解决：每次上传前递增 CFBundleVersion，推荐使用时间戳或 CI 构建序号。


问题四：测试人员未收到安装通知
原因：测试人员的 Apple ID 邮箱可能有误，或未安装 TestFlight App。


解决：


    

  1. 确认测试人员邮箱正确
    2. 

  2. 确认测试人员已在设备上安装 TestFlight App 并接受邀请
    3. 

  3. 对于外部测试，检查构建是否已通过 Beta Review
    4. 



问题五：构建 90 天过期
原因：TestFlight 构建有效期为 90 天，到期后无法安装。


解决：定期上传新构建，确保测试人员始终有可用版本。在 CI 中配置定时构建。


小结
    

  • 内部测试最多 100 人，上传即可用，无需审核；外部测试最多 10,000 人，首次需 Beta Review。
    • 

  • 使用 xcodebuild archive + xcodebuild -exportArchive 组合完成命令行构建和导出。
    • 

  • xcrun altool 或 Transporter 用于上传 IPA 到 App Store Connect。
    • 

  • fastlane pilot 实现从构建到分发的全自动化，支持测试组管理和测试人员增删。
    • 

  • 每次上传必须递增 CFBundleVersion（构建号），推荐使用时间戳或 CI 序号。
    • 

  • TestFlight 构建有效期 90 天，需定期更新。
    • 

  • 外部测试支持公开链接邀请，无需逐一添加测试人员邮箱。
    • 

  • 在 CI 环境中使用 App Specific Password 或 API Key 进行身份认证。
    •
