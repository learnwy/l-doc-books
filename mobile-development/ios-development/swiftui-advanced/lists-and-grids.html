Part I · iOSiOS 开发 简介SwiftUI 进阶 简介列表与网格

列表与网格

概述

List 和 LazyVGrid / LazyHGrid 是 SwiftUI 中展示集合数据的两大核心组件。List 擅长呈现单列滚动内容，原生支持分组、滑动操作和下拉刷新；LazyVGrid / LazyHGrid 则提供灵活的多列网格布局，适用于照片墙、商品卡片等场景。

flowchart TD
    DATA[Data Source [Model]"] --> FE["ForEach"]
    FE --> LIST["List"]
    FE --> GRID["LazyVGrid / LazyHGrid"]

    LIST --> SEC["Section Section Groups"]
    LIST --> SWIPE["swipeActions"]
    LIST --> REFRESH["refreshable"]
    LIST --> SEARCH["searchable"]

    GRID --> GI["GridItem"]
    GI --> FIXED["fixed"]
    GI --> FLEX["flexible"]
    GI --> ADAPTIVE["adaptive"]

核心概念

List 与 LazyVGrid / LazyHGrid 都以 ForEach 遍历数据源为基础，区别在于布局维度与交互能力：

  • 数据驱动：数据模型遵循 Identifiable 或提供 id，框架据此高效 diff
  • 按需创建：两者都是懒加载，只创建可见范围内的子视图
  • 能力分层：List 自带分组、滑动、刷新、搜索；Grid 专注多列灵活布局
组件 布局 典型场景
List 单列滚动 设置项、联系人群组
LazyVGrid 垂直多列网格 照片墙、商品卡片
LazyHGrid 水平多行网格 横向标签流

基础用法

List 与 ForEach

List 是 SwiftUI 中最常用的滚动容器，底层对应 UIKit 的 UITableView，自带懒加载优化。

struct Contact: Identifiable {
    let id = UUID()
    let name: String
    let phone: String
}

struct ContactListView: View {
    let contacts = [
        Contact(name: "张三", phone: "138-0000-0001"),
        Contact(name: "李四", phone: "138-0000-0002"),
        Contact(name: "王五", phone: "138-0000-0003"),
    ]

    var body: some View {
        List(contacts) { contact in
            HStack {
                Image(systemName: "person.circle.fill")
                    .font(.title2)
                    .foregroundStyle(.blue)
                VStack(alignment: .leading) {
                    Text(contact.name)
                        .font(.headline)
                    Text(contact.phone)
                        .font(.subheadline)
                        .foregroundStyle(.secondary)
                }
            }
        }
    }
}

Section 分组

使用 Section 将列表内容按逻辑分组，每组可以有 header 和 footer：

struct GroupedListView: View {
    let favorites = ["张三", "李四"]
    let recents = ["王五", "赵六", "孙七"]

    var body: some View {
        List {
            Section("收藏联系人") {
                ForEach(favorites, id: \.self) { name in
                    Label(name, systemImage: "star.fill")
                }
            }
            Section {
                ForEach(recents, id: \.self) { name in
                    Label(name, systemImage: "clock")
                }
            } header: {
                Text("最近联系")
            } footer: {
                Text("仅显示最近 7 天内的联系记录")
            }
        }
        .listStyle(.insetGrouped)
    }
}

进阶用法

swipeActions 滑动操作

为列表行添加滑动手势触发的操作按钮，支持左滑和右滑两个方向：

struct TaskListView: View {
    @State private var tasks = ["完成设计稿", "编写单元测试", "代码审查", "发布版本"]

    var body: some View {
        List {
            ForEach(tasks, id: \.self) { task in
                Text(task)
                    .swipeActions(edge: .trailing, allowsFullSwipe: true) {
                        Button(role: .destructive) {
                            tasks.removeAll { $0 == task }
                        } label: {
                            Label("删除", systemImage: "trash")
                        }
                    }
                    .swipeActions(edge: .leading) {
                        Button {
                            // 标记完成
                        } label: {
                            Label("完成", systemImage: "checkmark.circle")
                        }
                        .tint(.green)
                    }
            }
        }
    }
}

refreshable 下拉刷新

.refreshable 修饰符为列表添加原生下拉刷新功能，搭配 async/await 使用：

struct RefreshableListView: View {
    @State private var items = ["项目 A", "项目 B", "项目 C"]

    var body: some View {
        List(items, id: \.self) { item in
            Text(item)
        }
        .refreshable {
            await loadData()
        }
    }

    func loadData() async {
        try? await Task.sleep(for: .seconds(1))
        items.append("项目 \(["D", "E", "F", "G"].randomElement()!)")
    }
}

searchable 搜索

.searchable 修饰符为导航视图添加搜索栏，配合计算属性实现实时过滤：

struct SearchableListView: View {
    @State private var searchText = ""
    let cities = ["北京", "上海", "广州", "深圳", "杭州", "成都", "武汉", "南京", "重庆", "西安"]

    var filteredCities: [String] {
        if searchText.isEmpty { return cities }
        return cities.filter { $0.contains(searchText) }
    }

    var body: some View {
        NavigationStack {
            List(filteredCities, id: \.self) { city in
                Text(city)
            }
            .navigationTitle("城市")
            .searchable(text: $searchText, prompt: "搜索城市")
        }
    }
}

LazyVGrid 垂直网格

LazyVGrid 以网格形式排列子视图，通过 GridItem 数组定义列布局。三种 GridItem 模式对比：

模式 说明 典型用途
.fixed(CGFloat) 固定宽度列 图标网格
.flexible(minimum:maximum:) 在范围内自适应 卡片列表
.adaptive(minimum:maximum:) 根据空间自动决定列数 瀑布流照片墙 
struct PhotoGridView: View {
    let photos = (1...20).map { "photo_\($0)" }

    let columns = [
        GridItem(.adaptive(minimum: 100, maximum: 200))
    ]

    var body: some View {
        ScrollView {
            LazyVGrid(columns: columns, spacing: 12) {
                ForEach(photos, id: \.self) { photo in
                    RoundedRectangle(cornerRadius: 8)
                        .fill(Color.blue.gradient)
                        .frame(height: 100)
                        .overlay {
                            Text(photo)
                                .font(.caption)
                                .foregroundStyle(.white)
                        }
                }
            }
            .padding()
        }
    }
}

LazyHGrid 水平网格

LazyHGrid 的用法与 LazyVGrid 对称，适用于水平滚动的网格场景：

struct HorizontalGridView: View {
    let items = (1...30).map { "标签 \($0)" }

    let rows = [
        GridItem(.fixed(40)),
        GridItem(.fixed(40)),
    ]

    var body: some View {
        ScrollView(.horizontal) {
            LazyHGrid(rows: rows, spacing: 10) {
                ForEach(items, id: \.self) { item in
                    Text(item)
                        .padding(.horizontal, 12)
                        .padding(.vertical, 8)
                        .background(.blue.opacity(0.1), in: Capsule())
                }
            }
            .padding()
        }
    }
}

完整示例

以下是一个集成了分组、搜索、滑动操作和网格切换的商品浏览应用：

import SwiftUI

struct Product: Identifiable {
    let id = UUID()
    let name: String
    let price: Double
    let category: String
    let imageName: String
}

@Observable
class ProductStore {
    var products: [Product] = [
        Product(name: "AirPods Pro", price: 1999, category: "音频", imageName: "airpodspro"),
        Product(name: "HomePod mini", price: 749, category: "音频", imageName: "homepod.mini"),
        Product(name: "iPhone 16", price: 5999, category: "手机", imageName: "iphone"),
        Product(name: "iPhone 16 Pro", price: 7999, category: "手机", imageName: "iphone"),
        Product(name: "MacBook Air", price: 8999, category: "电脑", imageName: "laptopcomputer"),
        Product(name: "Mac mini", price: 4499, category: "电脑", imageName: "macmini"),
        Product(name: "iPad Air", price: 4799, category: "平板", imageName: "ipad"),
        Product(name: "iPad Pro", price: 8999, category: "平板", imageName: "ipad.landscape"),
    ]

    var categories: [String] {
        Array(Set(products.map(\.category))).sorted()
    }

    func products(in category: String) -> [Product] {
        products.filter { $0.category == category }
    }
}

struct ProductBrowserView: View {
    @State private var store = ProductStore()
    @State private var searchText = ""
    @State private var showGrid = false

    var filteredProducts: [Product] {
        if searchText.isEmpty { return store.products }
        return store.products.filter { $0.name.localizedCaseInsensitiveContains(searchText) }
    }

    var body: some View {
        NavigationStack {
            Group {
                if showGrid {
                    gridView
                } else {
                    listView
                }
            }
            .navigationTitle("商品浏览")
            .searchable(text: $searchText, prompt: "搜索商品")
            .toolbar {
                ToolbarItem(placement: .primaryAction) {
                    Button {
                        withAnimation { showGrid.toggle() }
                    } label: {
                        Image(systemName: showGrid ? "list.bullet" : "square.grid.2x2")
                    }
                }
            }
        }
    }

    private var listView: some View {
        List {
            ForEach(store.categories, id: \.self) { category in
                Section(category) {
                    ForEach(store.products(in: category)) { product in
                        productRow(product)
                            .swipeActions(edge: .trailing) {
                                Button(role: .destructive) {
                                    store.products.removeAll { $0.id == product.id }
                                } label: {
                                    Label("删除", systemImage: "trash")
                                }
                            }
                            .swipeActions(edge: .leading) {
                                Button {
                                } label: {
                                    Label("收藏", systemImage: "heart")
                                }
                                .tint(.pink)
                            }
                    }
                }
            }
        }
        .listStyle(.insetGrouped)
        .refreshable {
            try? await Task.sleep(for: .seconds(1))
        }
    }

    private var gridView: some View {
        ScrollView {
            LazyVGrid(
                columns: [GridItem(.adaptive(minimum: 150))],
                spacing: 16
            ) {
                ForEach(filteredProducts) { product in
                    VStack(spacing: 8) {
                        Image(systemName: product.imageName)
                            .font(.system(size: 40))
                            .frame(height: 80)
                            .frame(maxWidth: .infinity)
                            .background(.ultraThinMaterial, in: RoundedRectangle(cornerRadius: 12))

                        Text(product.name)
                            .font(.caption)
                            .lineLimit(1)

                        Text("¥\(product.price, specifier: "%.0f")")
                            .font(.caption2)
                            .foregroundStyle(.orange)
                    }
                    .padding(8)
                    .background(.background, in: RoundedRectangle(cornerRadius: 12))
                    .shadow(color: .black.opacity(0.05), radius: 4, y: 2)
                }
            }
            .padding()
        }
    }

    private func productRow(_ product: Product) -> some View {
        HStack {
            Image(systemName: product.imageName)
                .font(.title2)
                .frame(width: 40)
            VStack(alignment: .leading) {
                Text(product.name)
                    .font(.headline)
                Text("¥\(product.price, specifier: "%.0f")")
                    .font(.subheadline)
                    .foregroundStyle(.orange)
            }
        }
    }
}

最佳实践

推荐做法 不推荐做法
数据模型遵循 Identifiable 使用 id: \.self 处理复杂模型
用 Section 组织相关内容 在一个扁平 List 中混杂不同类型数据
LazyVGrid 配合 adaptive 适配多种屏幕 硬编码固定列数
列表行视图提取为独立组件 在 ForEach 闭包中写大量内联视图
refreshable 配合真实网络请求 在 refreshable 中执行同步阻塞操作
对大数据集使用 Lazy 容器 在 ScrollView 中用普通 VStack 渲染上千个视图

性能优化要点：

  • List 和 LazyVGrid 均为懒加载，仅创建屏幕可见范围内的视图
  • 避免在 ForEach 内部触发昂贵的计算——将计算结果缓存在 ViewModel 中
  • 图片资源使用 AsyncImage 并配合缓存策略，避免重复网络请求
  • 对超长列表（10000+ 行），考虑分页加载或服务器端分页

小结

  • List 是 SwiftUI 的核心滚动容器，原生支持分组、选择、编辑模式
  • ForEach 要求数据遵循 Identifiable（或提供 id 参数），确保 diff 高效
  • swipeActions 支持左右两侧滑动操作，allowsFullSwipe 控制全滑触发
  • refreshable 和 searchable 一行代码即可添加下拉刷新和搜索功能
  • LazyVGrid / LazyHGrid 通过 GridItem 定义灵活的网格布局
  • GridItem 三种模式：fixed 固定、flexible 范围自适应、adaptive 自动列数
  • 大数据集务必使用 Lazy 容器，避免一次性创建所有子视图
