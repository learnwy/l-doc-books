Part I · iOSiOS 开发 简介SwiftUI 进阶 简介动画与过渡

动画与过渡

概述

SwiftUI 的动画系统建立在声明式理念之上：你只需描述状态变化前后的视图样式，框架自动生成中间帧。SwiftUI 提供两种动画方式——隐式动画（modifier 绑定）和显式动画（withAnimation 包裹状态变更），以及丰富的过渡效果（transition）、几何匹配动画（matchedGeometryEffect）和基于时间线的高级动画（TimelineView）。

基础用法
隐式动画（.animation modifier）
在视图上附加 .animation(_:value:)，当 value 发生变化时，该视图的所有可动画属性自动过渡：


struct ImplicitAnimationView: View {
    @State private var scale: CGFloat = 1.0
    @State private var rotation: Double = 0

    var body: some View {
        Image(systemName: "star.fill")
            .font(.system(size: 60))
            .foregroundStyle(.yellow)
            .scaleEffect(scale)
            .rotationEffect(.degrees(rotation))
            .animation(.easeInOut(duration: 0.5), value: scale)
            .animation(.easeInOut(duration: 0.5), value: rotation)
            .onTapGesture {
                scale = scale == 1.0 ? 1.5 : 1.0
                rotation += 72
            }
    }
}
显式动画（withAnimation）
用 withAnimation 包裹状态修改代码，所有受该状态影响的视图都会动画过渡。适合一次状态变化影响多个视图的场景：


struct ExplicitAnimationView: View {
    @State private var isExpanded = false

    var body: some View {
        VStack(spacing: 20) {
            RoundedRectangle(cornerRadius: isExpanded ? 20 : 50)
                .fill(.blue.gradient)
                .frame(
                    width: isExpanded ? 300 : 100,
                    height: isExpanded ? 200 : 100
                )

            Text(isExpanded ? "已展开" : "已收起")
                .font(.headline)

            Button("切换") {
                withAnimation(.spring(duration: 0.6, bounce: 0.3)) {
                    isExpanded.toggle()
                }
            }
            .buttonStyle(.borderedProminent)
        }
    }
}

进阶用法
弹簧动画
SwiftUI 的弹簧动画基于物理模型，iOS 17+ 推荐使用新的 spring API：


struct SpringShowcaseView: View {
    @State private var offset: CGFloat = 0

    var body: some View {
        VStack(spacing: 40) {
            springRow("低弹性", .spring(duration: 0.5, bounce: 0.0))
            springRow("中弹性", .spring(duration: 0.5, bounce: 0.3))
            springRow("高弹性", .spring(duration: 0.5, bounce: 0.6))
            springRow("弹跳效果", .spring(duration: 0.8, bounce: 0.8))

            Button("触发") {
                offset = offset == 0 ? 120 : 0
            }
            .buttonStyle(.borderedProminent)
        }
    }

    func springRow(_ label: String, _ animation: Animation) -> some View {
        HStack {
            Text(label)
                .frame(width: 80, alignment: .leading)
            Circle()
                .fill(.orange.gradient)
                .frame(width: 30, height: 30)
                .offset(x: offset)
                .animation(animation, value: offset)
            Spacer()
        }
        .padding(.horizontal)
    }
}
Transition 过渡
transition 控制视图插入和移除时的动画效果。必须搭配 if / ForEach 等条件渲染使用：


struct TransitionDemoView: View {
    @State private var showCard = false

    var body: some View {
        VStack(spacing: 30) {
            Button(showCard ? "隐藏卡片" : "显示卡片") {
                withAnimation(.spring(duration: 0.5, bounce: 0.3)) {
                    showCard.toggle()
                }
            }

            if showCard {
                RoundedRectangle(cornerRadius: 16)
                    .fill(.blue.gradient)
                    .frame(width: 280, height: 180)
                    .overlay {
                        Text("通知卡片")
                            .foregroundStyle(.white)
                            .font(.title2)
                    }
                    .transition(.asymmetric(
                        insertion: .scale.combined(with: .opacity),
                        removal: .slide.combined(with: .opacity)
                    ))
            }
        }
    }
}

matchedGeometryEffect
matchedGeometryEffect 在两个不同视图之间创建共享元素过渡动画，常用于列表到详情的平滑转场：


struct MatchedGeometryDemoView: View {
    @Namespace private var animation
    @State private var selectedId: String?

    let items = ["sunrise.fill", "cloud.sun.fill", "moon.stars.fill", "sparkles"]

    var body: some View {
        VStack {
            if let selectedId {
                expandedView(selectedId)
            } else {
                gridView
            }
        }
        .animation(.spring(duration: 0.5, bounce: 0.2), value: selectedId)
    }

    var gridView: some View {
        LazyVGrid(columns: [GridItem(.adaptive(minimum: 140))], spacing: 16) {
            ForEach(items, id: \.self) { item in
                Image(systemName: item)
                    .font(.system(size: 40))
                    .frame(width: 140, height: 140)
                    .background(.blue.opacity(0.1), in: RoundedRectangle(cornerRadius: 16))
                    .matchedGeometryEffect(id: item, in: animation)
                    .onTapGesture {
                        selectedId = item
                    }
            }
        }
        .padding()
    }

    func expandedView(_ id: String) -> some View {
        VStack {
            Image(systemName: id)
                .font(.system(size: 100))
                .frame(maxWidth: .infinity)
                .frame(height: 300)
                .background(.blue.opacity(0.1), in: RoundedRectangle(cornerRadius: 24))
                .matchedGeometryEffect(id: id, in: animation)
                .onTapGesture {
                    selectedId = nil
                }

            Text(id)
                .font(.title)
                .padding(.top)
        }
        .padding()
    }
}
TimelineView
TimelineView 按照时间线调度更新视图内容，适合实现时钟、粒子效果等持续动画：


struct ClockView: View {
    var body: some View {
        TimelineView(.animation) { context in
            let date = context.date
            let calendar = Calendar.current
            let seconds = Double(calendar.component(.second, from: date))
            let minutes = Double(calendar.component(.minute, from: date))
            let hours = Double(calendar.component(.hour, from: date))

            ZStack {
                Circle()
                    .stroke(.gray.opacity(0.3), lineWidth: 4)
                    .frame(width: 200, height: 200)

                hand(length: 60, width: 2, rotation: seconds / 60 * 360, color: .red)
                hand(length: 50, width: 4, rotation: minutes / 60 * 360, color: .primary)
                hand(length: 35, width: 6, rotation: hours / 12 * 360, color: .primary)

                Circle()
                    .fill(.red)
                    .frame(width: 8, height: 8)
            }
        }
    }

    func hand(length: CGFloat, width: CGFloat, rotation: Double, color: Color) -> some View {
        RoundedRectangle(cornerRadius: width / 2)
            .fill(color)
            .frame(width: width, height: length)
            .offset(y: -length / 2)
            .rotationEffect(.degrees(rotation))
    }
}
AnimatableModifier
通过遵循 Animatable 协议自定义可动画属性，实现框架内置动画无法覆盖的效果：


struct CountingText: View, Animatable {
    var value: Double

    var animatableData: Double {
        get { value }
        set { value = newValue }
    }

    var body: some View {
        Text("\(Int(value))")
            .font(.system(size: 48, weight: .bold, design: .rounded))
            .contentTransition(.numericText(value: value))
    }
}

struct CountingDemoView: View {
    @State private var count: Double = 0

    var body: some View {
        VStack(spacing: 24) {
            CountingText(value: count)

            Button("随机数字") {
                withAnimation(.spring(duration: 0.8)) {
                    count = Double.random(in: 0...999)
                }
            }
            .buttonStyle(.borderedProminent)
        }
    }
}
完整示例
以下是一个卡片展开/收起的交互动画演示，综合运用了 matchedGeometryEffect、transition、弹簧动画：


import SwiftUI

struct CardItem: Identifiable {
    let id = UUID()
    let title: String
    let subtitle: String
    let color: Color
    let icon: String
}

struct AnimatedCardGallery: View {
    @Namespace private var namespace
    @State private var selectedCard: CardItem?

    let cards = [
        CardItem(title: "设计系统", subtitle: "构建一致的 UI 组件库", color: .blue, icon: "paintbrush.fill"),
        CardItem(title: "性能优化", subtitle: "提升应用流畅度", color: .green, icon: "gauge.with.dots.needle.67percent"),
        CardItem(title: "数据安全", subtitle: "保护用户隐私", color: .orange, icon: "lock.shield.fill"),
        CardItem(title: "测试覆盖", subtitle: "确保代码质量", color: .purple, icon: "checkmark.seal.fill"),
    ]

    var body: some View {
        ZStack {
            gridContent
                .opacity(selectedCard == nil ? 1 : 0)

            if let card = selectedCard {
                detailContent(card)
                    .transition(.opacity)
            }
        }
        .animation(.spring(duration: 0.5, bounce: 0.25), value: selectedCard?.id)
    }

    var gridContent: some View {
        ScrollView {
            LazyVGrid(columns: [GridItem(.flexible()), GridItem(.flexible())], spacing: 16) {
                ForEach(cards) { card in
                    VStack(spacing: 12) {
                        Image(systemName: card.icon)
                            .font(.system(size: 32))
                            .foregroundStyle(.white)
                        Text(card.title)
                            .font(.headline)
                            .foregroundStyle(.white)
                    }
                    .frame(maxWidth: .infinity)
                    .frame(height: 140)
                    .background(card.color.gradient, in: RoundedRectangle(cornerRadius: 16))
                    .matchedGeometryEffect(id: card.id, in: namespace)
                    .onTapGesture {
                        selectedCard = card
                    }
                }
            }
            .padding()
        }
    }

    func detailContent(_ card: CardItem) -> some View {
        VStack(spacing: 0) {
            VStack(spacing: 16) {
                Image(systemName: card.icon)
                    .font(.system(size: 60))
                    .foregroundStyle(.white)
                Text(card.title)
                    .font(.largeTitle.bold())
                    .foregroundStyle(.white)
                Text(card.subtitle)
                    .font(.title3)
                    .foregroundStyle(.white.opacity(0.8))
            }
            .frame(maxWidth: .infinity)
            .frame(height: 300)
            .background(card.color.gradient, in: RoundedRectangle(cornerRadius: 24))
            .matchedGeometryEffect(id: card.id, in: namespace)
            .onTapGesture {
                selectedCard = nil
            }

            VStack(alignment: .leading, spacing: 16) {
                Text("详细说明")
                    .font(.title2.bold())
                Text("这里是关于「\(card.title)」的详细内容。在实际应用中，可以展示更多的图文信息、操作按钮和相关链接。")
                    .foregroundStyle(.secondary)
            }
            .padding()
            .transition(.move(edge: .bottom).combined(with: .opacity))

            Spacer()
        }
    }
}
最佳实践




推荐做法
不推荐做法





优先使用 withAnimation 显式控制动画范围
在根视图上添加 .animation 导致所有子视图都动画




每个 .animation 绑定具体的 value 参数
使用已废弃的 .animation(.default) 无 value 版本




弹簧动画设置合理的 duration 和 bounce
弹簧动画 bounce 过大导致用户等待时间过长




matchedGeometryEffect 确保 id 唯一且类型匹配
在 ForEach 内外使用相同 id 导致冲突




对性能敏感的动画使用 drawingGroup() 启用 Metal 渲染
在复杂视图上叠加多层动画不做优化




transition 搭配 if 条件渲染使用
对始终存在的视图使用 transition（无效果）





性能提示：


    

  • TimelineView(.animation) 会以显示刷新率持续调用，确保内部计算尽量轻量
    • 

  • 大量粒子动画考虑使用 Canvas + TimelineView 而非多个独立 View
    • 

  • matchedGeometryEffect 仅匹配 frame 和 position，不会自动匹配背景色等属性
    • 



小结
    

  • SwiftUI 动画分为隐式（.animation modifier）和显式（withAnimation）两种
    • 

  • withAnimation 适合多视图联动；.animation(_:value:) 适合单视图精细控制
    • 

  • 弹簧动画 .spring(duration:bounce:) 是 iOS 17+ 推荐的物理动画方式
    • 

  • transition 控制视图插入/移除时的效果，需配合条件渲染
    • 

  • matchedGeometryEffect 通过 @Namespace 和共享 id 实现跨视图共享元素动画
    • 

  • TimelineView 适合时钟、粒子等持续性动画场景
    • 

  • 自定义 Animatable 协议可以让任意属性参与动画插值
    • 

  • 动画不宜过多过长，保持 0.25-0.5 秒的时长，让界面流畅而不拖沓
    •
