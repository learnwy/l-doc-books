Part I · iOSiOS 开发 简介Swift 基础 简介类型与变量

类型与变量

概述

Swift 是一门强类型、类型安全的编程语言。每个变量和常量都拥有明确的类型，编译器会在编译期对类型进行检查，从而在运行前捕获大量潜在错误。理解 Swift 的类型系统是写出安全、高效代码的第一步——它决定了数据如何存储、如何复制、如何在函数间传递。

核心概念
let 与 var
Swift 使用 let 声明常量，使用 var 声明变量。编译器会强制保证 let 绑定的值不可被重新赋值。


let maximumLoginAttempts = 10   // 常量，之后不可修改
var currentLoginAttempt = 0     // 变量，可以修改

currentLoginAttempt += 1        // ✅ 合法
// maximumLoginAttempts += 1    // ❌ 编译错误：不能对 let 赋值


最佳实践：默认使用 let，只在确实需要修改时才改为 var。这能帮助编译器进行优化，也让代码意图更清晰。




基本类型
Swift 内置了丰富的基本类型，它们全部是值类型（以 struct 实现）：

类型推断 (Type Inference)
Swift 拥有强大的类型推断能力。在大多数情况下，你不需要显式标注类型，编译器会根据初始值自动推断：


let city = "北京"           // 推断为 String
let year = 2026             // 推断为 Int
let gravity = 9.8           // 推断为 Double（浮点字面量默认 Double）
let isSwift = true          // 推断为 Bool
当表达式存在歧义或需要特定类型时，才需要显式标注：


let temperature: Float = 36.5   // 不标注会推断为 Double
let byte: UInt8 = 255           // 限制为 8 位无符号整数
类型转换 (Type Conversion)
Swift 不会进行隐式类型转换，所有转换必须显式完成：


let intValue: Int = 42
let doubleValue: Double = 3.14

// let result = intValue + doubleValue   // ❌ 编译错误：类型不匹配
let result = Double(intValue) + doubleValue  // ✅ 显式转换

let label = "分数是 "
let scoreValue = 95
let message = label + String(scoreValue)     // ✅ "分数是 95"
使用字符串插值更为优雅：


let message = "分数是 \(scoreValue)"
值类型 vs 引用类型
这是 Swift 类型系统中最核心的区分。


值类型（Value Type）—— 赋值时会产生一份独立拷贝：


struct Point {
    var x: Double
    var y: Double
}

var pointA = Point(x: 1.0, y: 2.0)
var pointB = pointA          // 拷贝
pointB.x = 10.0

print(pointA.x)              // 1.0 — pointA 未受影响
print(pointB.x)              // 10.0
引用类型（Reference Type）—— 赋值时共享同一个实例：


class Person {
    var name: String
    init(name: String) { self.name = name }
}

let personA = Person(name: "Alice")
let personB = personA        // 共享同一实例
personB.name = "Bob"

print(personA.name)          // "Bob" — personA 也被改变了
集合类型
Swift 提供了三种主要的集合类型，它们都是值类型，并且支持泛型：


Array — 有序集合
var fruits: [String] = ["苹果", "香蕉", "橘子"]
var numbers: Array<Int> = [1, 2, 3]

fruits.append("葡萄")
fruits.insert("草莓", at: 0)
let first = fruits[0]                  // "草莓"
let sliced = fruits[1...3]             // ArraySlice

for (index, fruit) in fruits.enumerated() {
    print("\(index): \(fruit)")
}
Dictionary — 键值对集合
var capitals: [String: String] = [
    "中国": "北京",
    "日本": "东京",
    "韩国": "首尔"
]

capitals["美国"] = "华盛顿"             // 添加
let china = capitals["中国"]            // Optional("北京")
capitals.removeValue(forKey: "韩国")

for (country, city) in capitals {
    print("\(country) 的首都是 \(city)")
}
Set — 无序不重复集合
var tags: Set<String> = ["Swift", "iOS", "Xcode"]
tags.insert("SwiftUI")
tags.contains("Swift")                  // true

let frontend: Set = ["HTML", "CSS", "Swift"]
let mobile: Set = ["Swift", "Kotlin", "Dart"]

let common = frontend.intersection(mobile)  // {"Swift"}
let all = frontend.union(mobile)
元组 (Tuple)
元组可以将多个值组合成一个复合值，适合临时性的数据组合：


let httpStatus = (statusCode: 200, description: "OK")
print(httpStatus.statusCode)           // 200
print(httpStatus.description)          // "OK"

let (code, desc) = httpStatus          // 解构
print(code)                            // 200

let point = (3.0, 4.0)
print(point.0)                         // 3.0（按索引访问）
类型别名 (Type Alias)
为已有类型创建别名，提高代码可读性：


typealias Coordinate = (latitude: Double, longitude: Double)
typealias StudentID = Int
typealias CompletionHandler = (Bool, Error?) -> Void

let location: Coordinate = (latitude: 39.9, longitude: 116.4)
let id: StudentID = 20260001
使用方式
模式一：模型数据使用 struct（值语义）
日常开发中，优先使用 struct 定义数据模型，利用值语义避免共享状态的副作用：


struct Temperature {
    var celsius: Double

    var fahrenheit: Double {
        celsius * 9 / 5 + 32
    }
}

var today = Temperature(celsius: 28.0)
var tomorrow = today
tomorrow.celsius = 32.0

print(today.celsius)      // 28.0 — 互不影响
print(tomorrow.fahrenheit) // 89.6
模式二：利用类型推断简化代码
在上下文已经明确类型时，充分利用推断机制：


struct Config {
    var timeout: TimeInterval = 30.0
    var retryCount: Int = 3
    var baseURL: String = "https://api.example.com"
}

let config = Config()      // 全部使用默认值
let items: [String] = []   // 空集合需要标注类型

enum Direction { case north, south, east, west }

func move(_ direction: Direction) { /* ... */ }
move(.north)               // 上下文推断为 Direction.north
模式三：用 Dictionary 做轻量级数据映射
func groupByFirstLetter(_ words: [String]) -> [Character: [String]] {
    var groups: [Character: [String]] = [:]
    for word in words {
        let key = word.first!
        groups[key, default: []].append(word)
    }
    return groups
}

let words = ["apple", "avocado", "banana", "blueberry", "cherry"]
let grouped = groupByFirstLetter(words)
// ["a": ["apple", "avocado"], "b": ["banana", "blueberry"], "c": ["cherry"]]
常见陷阱
陷阱 1：浮点精度问题
let a = 0.1 + 0.2
print(a == 0.3)             // false ⚠️
print(a)                     // 0.30000000000000004

// 正确做法：使用精度容差比较
let epsilon = 1e-10
print(abs(a - 0.3) < epsilon) // true

// 或使用 Decimal 进行精确运算
import Foundation
let price = Decimal(string: "0.1")! + Decimal(string: "0.2")!
print(price == Decimal(string: "0.3")!)  // true
陷阱 2：整数溢出
let maxInt8: Int8 = 127
// let overflow = maxInt8 + 1           // ❌ 运行时崩溃（debug 模式）

let wrapped = maxInt8 &+ 1              // -128（溢出运算符，静默环绕）

// 安全做法：在可能溢出时使用更大类型或检查边界
let safeResult = Int(maxInt8) + 1       // 128（使用 Int，范围足够）
陷阱 3：引用类型的 let 不等于不可变
class Counter {
    var count = 0
}

let counter = Counter()     // let 绑定
counter.count += 1          // ✅ 可以修改属性！let 只保证引用不变
// counter = Counter()      // ❌ 不能重新赋值给另一个实例


对引用类型而言，let 只是固定了指针（引用本身不可变），但指向的对象的属性仍可修改。




陷阱 4：Array 的写时复制 (Copy-on-Write)
var arrayA = [1, 2, 3, 4, 5]
var arrayB = arrayA          // 此时共享同一块存储（优化）

arrayB.append(6)             // 此刻才真正发生拷贝（COW 触发）
print(arrayA.count)          // 5
print(arrayB.count)          // 6
写时复制（COW）是 Swift 标准库集合的优化策略。赋值时不会立即复制数据，只有在某一方发生修改时才会创建独立副本。这意味着：


    

  • 传递大数组到函数中不会有性能损耗（如果不修改的话）
    • 

  • 但不要误以为赋值后二者始终共享数据——任何一方修改都会触发分离
    • 



陷阱 5：String 与 Character 的 Unicode 复杂性
let emoji = "👨‍👩‍👧‍👦"
print(emoji.count)           // 1（一个 Character = 一个扩展字素簇）
print(emoji.utf8.count)      // 25（UTF-8 编码 25 字节）

let cafe = "café"
print(cafe.count)            // 4
print(cafe.unicodeScalars.count)  // 可能是 5（取决于是否使用组合字符）
Swift 的 String 默认按字素簇计数，这在处理 emoji 和组合字符时很直观，但与基于字节或码点的语言行为不同。


小结
    

  • Swift 是强类型语言，所有变量和常量都有明确类型，类型转换必须显式进行。
    • 

  • 优先使用 let 声明不可变值，只在需要修改时使用 var。
    • 

  • 值类型（struct/enum/tuple）赋值时产生拷贝，引用类型（class/closure/actor）赋值时共享实例。
    • 

  • 类型推断让代码简洁，但在歧义场景下仍需显式标注。
    • 

  • Array、Dictionary、Set 是三种核心集合类型，全部为值类型并采用写时复制优化。
    • 

  • 注意浮点精度、整数溢出、引用类型的 let 语义等常见陷阱。
    • 

  • 日常建模优先选择 struct，除非需要继承或共享可变状态才使用 class。
    •
