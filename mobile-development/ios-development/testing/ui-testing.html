Part I · iOSiOS 开发 简介测试 简介UI 测试

UI 测试

概述

UI 测试（UI Testing）从用户视角验证应用的交互行为——点击按钮是否跳转、输入文本是否提交、列表是否正确展示。与单元测试关注内部逻辑不同，UI 测试通过模拟真实用户操作来验证端到端流程，是发现交互回归和布局问题的有效手段。

Apple 的 UI 测试框架基于 XCTest，通过 XCUIApplication 启动应用、XCUIElement 定位元素、XCUIElementQuery 查询层级。测试运行在独立进程中，与被测应用通过无障碍（Accessibility）接口通信，因此良好的无障碍标识符设置是编写稳定 UI 测试的前提。

核心工具
XCUIApplication
XCUIApplication 代表被测应用实例，是所有 UI 测试的入口：


import XCTest

final class LoginUITests: XCTestCase {

    var app: XCUIApplication!

    override func setUp() {
        super.setUp()
        continueAfterFailure = false
        app = XCUIApplication()
        app.launchArguments = ["--uitesting"]
        app.launchEnvironment = ["DISABLE_ANIMATIONS": "1"]
        app.launch()
    }
}

用途

启动应用（每次调用都会重新启动）

等待与同步
UI 测试中元素可能需要时间出现（网络请求、动画）。使用 waitForExistence 替代硬编码延迟：


let successMessage = app.staticTexts["登录成功"]
let appeared = successMessage.waitForExistence(timeout: 5)
XCTAssertTrue(appeared, "登录成功提示应在 5 秒内出现")
对于更复杂的等待条件，使用 XCTNSPredicateExpectation：


let predicate = NSPredicate(format: "count >= 3")
let query = app.cells
let expectation = XCTNSPredicateExpectation(predicate: predicate, object: query)
let result = XCTWaiter.wait(for: [expectation], timeout: 10)
XCTAssertEqual(result, .completed)
无障碍标识符
在生产代码中为 UI 元素设置 accessibilityIdentifier，供测试代码定位使用：


UIKit:


let loginButton = UIButton()
loginButton.accessibilityIdentifier = "login_button"
SwiftUI:


Button("登录") { viewModel.login() }
    .accessibilityIdentifier("login_button")
测试代码中通过标识符查找：


let loginButton = app.buttons["login_button"]
loginButton.tap()
accessibilityIdentifier 不影响 VoiceOver 体验（与 accessibilityLabel 不同），专门用于自动化测试标识。


工作流程
步骤一：设置无障碍标识符
在被测应用的 UI 代码中，为所有需要测试交互的元素添加 accessibilityIdentifier。推荐使用枚举统一管理：


enum AccessibilityID {
    static let usernameField = "login_username_field"
    static let passwordField = "login_password_field"
    static let loginButton = "login_submit_button"
    static let errorLabel = "login_error_label"
}
步骤二：创建 UI Test Target
在 Xcode 中选择 File → New → Target → UI Testing Bundle。也可在项目创建时勾选 "Include UI Tests"。


步骤三：编写测试用例
按用户故事组织测试，每个方法覆盖一个完整交互流程。


步骤四：录制辅助
点击 Xcode 测试方法内的红色录制按钮，操作模拟器，Xcode 自动生成交互代码。录制代码通常需要手动优化——替换硬编码文本为标识符查询，添加等待和断言。


步骤五：截图归档
在关键步骤添加截图，CI 失败时可直接查看截图定位问题：


let screenshot = app.screenshot()
let attachment = XCTAttachment(screenshot: screenshot)
attachment.name = "登录页面"
attachment.lifetime = .keepAlways
add(attachment)
实战演示
以登录页面为例，完整展示 UI 测试的编写过程。


被测页面（SwiftUI）：


struct LoginView: View {
    @StateObject private var viewModel = LoginViewModel()

    var body: some View {
        VStack(spacing: 20) {
            TextField("用户名", text: $viewModel.username)
                .textFieldStyle(.roundedBorder)
                .accessibilityIdentifier("login_username_field")

            SecureField("密码", text: $viewModel.password)
                .textFieldStyle(.roundedBorder)
                .accessibilityIdentifier("login_password_field")

            if let error = viewModel.errorMessage {
                Text(error)
                    .foregroundColor(.red)
                    .accessibilityIdentifier("login_error_label")
            }

            Button("登录") {
                Task { await viewModel.login() }
            }
            .accessibilityIdentifier("login_submit_button")
            .disabled(viewModel.isLoading)

            if viewModel.isLoggedIn {
                Text("登录成功")
                    .accessibilityIdentifier("login_success_label")
            }
        }
        .padding()
    }
}
UI 测试代码：


import XCTest

final class LoginUITests: XCTestCase {

    var app: XCUIApplication!

    override func setUp() {
        super.setUp()
        continueAfterFailure = false
        app = XCUIApplication()
        app.launchArguments = ["--uitesting"]
        app.launch()
    }

    func testSuccessfulLogin() {
        let usernameField = app.textFields["login_username_field"]
        let passwordField = app.secureTextFields["login_password_field"]
        let loginButton = app.buttons["login_submit_button"]

        usernameField.tap()
        usernameField.typeText("admin@example.com")

        passwordField.tap()
        passwordField.typeText("password123")

        loginButton.tap()

        let successLabel = app.staticTexts["login_success_label"]
        XCTAssertTrue(successLabel.waitForExistence(timeout: 5))

        let screenshot = app.screenshot()
        let attachment = XCTAttachment(screenshot: screenshot)
        attachment.name = "登录成功"
        attachment.lifetime = .keepAlways
        add(attachment)
    }

    func testLoginWithEmptyFields_showsError() {
        let loginButton = app.buttons["login_submit_button"]
        loginButton.tap()

        let errorLabel = app.staticTexts["login_error_label"]
        XCTAssertTrue(errorLabel.waitForExistence(timeout: 3))
    }

    func testLoginWithWrongPassword_showsError() {
        let usernameField = app.textFields["login_username_field"]
        let passwordField = app.secureTextFields["login_password_field"]
        let loginButton = app.buttons["login_submit_button"]

        usernameField.tap()
        usernameField.typeText("admin@example.com")

        passwordField.tap()
        passwordField.typeText("wrongpassword")

        loginButton.tap()

        let errorLabel = app.staticTexts["login_error_label"]
        XCTAssertTrue(errorLabel.waitForExistence(timeout: 5))
        XCTAssertFalse(app.staticTexts["login_success_label"].exists)
    }
}

func testProductList_displaysItems() {
    let firstCell = app.cells.firstMatch
    XCTAssertTrue(firstCell.waitForExistence(timeout: 5))

    let cellCount = app.cells.count
    XCTAssertGreaterThan(cellCount, 0)

    app.swipeUp()
    app.swipeUp()

    let targetCell = app.cells.containing(.staticText, identifier: "MacBook Pro").firstMatch
    XCTAssertTrue(targetCell.waitForExistence(timeout: 3))
    targetCell.tap()

    let detailTitle = app.staticTexts["product_detail_title"]
    XCTAssertTrue(detailTitle.waitForExistence(timeout: 3))
}
测试 Tab 导航
func testTabNavigation() {
    let homeTab = app.tabBars.buttons["首页"]
    let profileTab = app.tabBars.buttons["我的"]

    XCTAssertTrue(homeTab.isSelected)

    profileTab.tap()
    XCTAssertTrue(profileTab.isSelected)
    XCTAssertTrue(app.staticTexts["个人资料"].waitForExistence(timeout: 3))

    homeTab.tap()
    XCTAssertTrue(homeTab.isSelected)
}
常见问题
Q：typeText 没有输入任何内容？ 确保目标元素已获得焦点。先调用 tap() 再调用 typeText()。如果是 SecureTextField，需要使用 app.secureTextFields 而非 app.textFields 查询。


Q：测试在 CI 上不稳定，本地能通过？ 最常见原因是等待时间不足。将 sleep() 替换为 waitForExistence(timeout:)。同时在 CI 环境中禁用动画（通过 launchArguments 传递标志，在 AppDelegate 中关闭 UIView.setAnimationsEnabled(false)）。


Q：如何处理系统弹窗（权限请求）？ 使用 addUIInterruptionMonitor 自动处理：


addUIInterruptionMonitor(withDescription: "权限弹窗") { alert in
    if alert.buttons["允许"].exists {
        alert.buttons["允许"].tap()
        return true
    }
    return false
}
app.tap()
注意：注册 monitor 后需要对 app 执行一次交互（如 app.tap()）才会触发。


Q：如何测试 Alert 和 Sheet？ Alert 和 Sheet 属于应用元素层级的一部分：


let alert = app.alerts.firstMatch
XCTAssertTrue(alert.waitForExistence(timeout: 3))
XCTAssertEqual(alert.label, "确认删除")
alert.buttons["删除"].tap()
Q：UI 测试运行太慢怎么办？ UI 测试天然比单元测试慢。优化策略：① 减少不必要的启动（相关测试放同一个类共享 setUp）；② 通过 launchArguments 注入测试数据跳过网络请求；③ 只对核心流程编写 UI 测试，边缘场景用单元测试覆盖。


小结
    

  • XCUIApplication 是 UI 测试的入口，通过 launch() 启动应用，支持传递参数和环境变量切换测试模式。
    • 

  • XCUIElement 和 XCUIElementQuery 通过无障碍接口定位元素，支持 buttons、textFields、staticTexts、cells 等类型查询。
    • 

  • 模拟操作包括 tap()、typeText()、swipeUp() 等，覆盖点击、输入、滑动等用户行为。
    • 

  • 使用 waitForExistence(timeout:) 替代硬编码延迟，提高测试稳定性。
    • 

  • accessibilityIdentifier 是连接生产代码与测试代码的桥梁，推荐用枚举集中管理标识符。
    • 

  • 在关键步骤使用 XCTAttachment 添加截图，CI 失败时可快速定位视觉问题。
    • 

  • UI 测试应聚焦核心用户流程（登录、购买、导航），避免覆盖过多细节导致维护成本过高。
