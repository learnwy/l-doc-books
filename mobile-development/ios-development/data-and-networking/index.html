数据与网络 简介

几乎所有现实中的 iOS 应用都需要处理数据的存储与网络通信。无论是从服务器获取 JSON 数据、将用户偏好持久化到本地，还是管理复杂的离线数据模型，本章涵盖的知识都是构建完整应用不可或缺的基础。

本章内容概览

Codable 与 JSON 介绍 Swift 强大的编解码协议。Codable 让 JSON 与 Swift 结构体之间的转换变得极为简洁。你将学习如何处理键名映射、嵌套结构、日期格式和可选字段等常见场景，以及在数据格式不完全受控时如何编写健壮的自定义解码逻辑。

URLSession 与网络请求是 iOS 网络编程的基石。你将掌握如何发起 GET 和 POST 请求、处理响应和错误、管理认证与 Cookie，以及配置缓存策略。本节还会介绍如何将网络层封装为可测试的服务，为后续架构章节的实践打下基础。

Core Data 是 Apple 提供的成熟对象图管理和持久化框架。虽然它的学习曲线较陡，但在需要复杂查询、数据关系和大规模数据存储的场景下依然是最佳选择。你将了解托管对象上下文、数据模型设计、获取请求和数据迁移等核心概念。

SwiftData 是 Apple 在 WWDC 2023 推出的新一代数据持久化框架。它利用 Swift 宏大幅简化了数据模型的定义，与 SwiftUI 深度集成，代表了 Apple 对数据层未来方向的愿景。你将学习 @Model 宏的使用、查询语法以及与 SwiftUI 视图的协作方式。

学习建议

建议先学习 Codable 和 URLSession，因为它们是网络请求和数据处理的基础，适用范围最广。Core Data 和 SwiftData 可以根据项目需求选择性深入——新项目倾向于使用 SwiftData，而维护已有项目则需要了解 Core Data。
