枚举与模式匹配

概述

Swift 的枚举（Enum）远超传统语言中"整数常量集合"的概念。它是一等类型，支持关联值、原始值、计算属性、方法、协议遵循，甚至递归定义。结合 Swift 强大的**模式匹配（Pattern Matching）**系统，枚举成为建模有限状态、消除非法状态、替代可选链和标志位的首选工具。

模式匹配不仅限于 switch，还贯穿 if case、guard case、for case、while case 等控制流语句，为代码提供声明式的解构与分支能力。

核心概念
基本枚举
最简单的枚举定义一组互斥的具名值：


enum Direction {
    case north
    case south
    case east
    case west
}

var heading = Direction.north
heading = .east
Swift 枚举不会像 C/ObjC 那样隐式赋予整数值。每个 case 本身就是完整的值，类型安全且可读性强。


关联值
关联值让枚举的每个 case 携带额外的数据，不同 case 可以携带不同类型和数量的关联值。这是 Swift 枚举最强大的特性：


enum NetworkResult {
    case success(data: Data, statusCode: Int)
    case failure(error: Error, retryable: Bool)
    case loading(progress: Double)
    case idle
}

func handle(_ result: NetworkResult) {
    switch result {
    case .success(let data, let statusCode):
        print("收到 \(data.count) 字节，状态码 \(statusCode)")
    case .failure(let error, let retryable):
        print("错误：\(error.localizedDescription)")
        if retryable { print("可重试") }
    case .loading(let progress):
        print("加载中：\(Int(progress * 100))%")
    case .idle:
        print("空闲")
    }
}
关联值使枚举成为**代数数据类型（Algebraic Data Type）**中的 Sum Type：类型的可能值是所有 case 的并集。


原始值
如果所有 case 共享同一种基础类型（String、Int、Double 等），可以使用原始值：


enum HTTPMethod: String {
    case get = "GET"
    case post = "POST"
    case put = "PUT"
    case delete = "DELETE"
    case patch = "PATCH"
}

let method = HTTPMethod.post
print(method.rawValue)

if let parsed = HTTPMethod(rawValue: "DELETE") {
    print("解析成功：\(parsed)")
}
Int 原始值默认从 0 自增，String 原始值默认等于 case 名称：


enum Planet: Int {
    case mercury = 1, venus, earth, mars, jupiter, saturn, uranus, neptune
}

print(Planet.earth.rawValue)

enum LogLevel: String {
    case debug, info, warning, error, fatal
}

print(LogLevel.warning.rawValue)
递归枚举
使用 indirect 关键字定义包含自身类型作为关联值的枚举，常用于建模树形结构或表达式：


indirect enum ArithExpr {
    case number(Double)
    case addition(ArithExpr, ArithExpr)
    case multiplication(ArithExpr, ArithExpr)
    case negation(ArithExpr)
}

func evaluate(_ expr: ArithExpr) -> Double {
    switch expr {
    case .number(let value):
        return value
    case .addition(let left, let right):
        return evaluate(left) + evaluate(right)
    case .multiplication(let left, let right):
        return evaluate(left) * evaluate(right)
    case .negation(let inner):
        return -evaluate(inner)
    }
}

let expr = ArithExpr.addition(
    .number(3),
    .multiplication(.number(4), .number(5))
)
print(evaluate(expr))
indirect 让编译器在堆上分配递归关联值，避免无限大小的值类型。可以标记单个 case 或整个枚举。


switch 模式匹配
switch 是 Swift 模式匹配的主力。它必须穷尽所有可能（exhaustive），对枚举来说就是覆盖所有 case：


enum Theme {
    case light
    case dark
    case custom(primary: String, secondary: String)
}

func applyTheme(_ theme: Theme) {
    switch theme {
    case .light:
        print("应用浅色主题")
    case .dark:
        print("应用深色主题")
    case .custom(let primary, _) where primary.hasPrefix("#"):
        print("应用自定义主题：\(primary)")
    case .custom:
        print("无效的颜色格式")
    }
}

多模式绑定和元组匹配：


func classify(point: (Int, Int)) -> String {
    switch point {
    case (0, 0):
        return "原点"
    case (let x, 0):
        return "X 轴上，x=\(x)"
    case (0, let y):
        return "Y 轴上，y=\(y)"
    case let (x, y) where x == y:
        return "对角线上"
    case let (x, y) where x == -y:
        return "反对角线上"
    case let (x, y):
        return "一般点 (\(x), \(y))"
    }
}
if case / guard case
当只关心枚举的某个特定 case 时，if case 和 guard case 比完整的 switch 更简洁：


let result = NetworkResult.success(data: Data(), statusCode: 200)

if case .success(let data, let code) = result, code == 200 {
    print("请求成功，数据大小：\(data.count)")
}

func processResult(_ result: NetworkResult) throws -> Data {
    guard case .success(let data, _) = result else {
        throw NSError(domain: "API", code: -1)
    }
    return data
}
for case 可以在循环中过滤特定模式：


let values: [Int?] = [1, nil, 3, nil, 5, 6, nil]

for case let value? in values {
    print(value)
}

let responses: [NetworkResult] = [
    .success(data: Data(), statusCode: 200),
    .failure(error: NSError(domain: "", code: 404), retryable: true),
    .success(data: Data(), statusCode: 201),
    .idle,
]

for case .success(_, let code) in responses where code >= 200 && code < 300 {
    print("成功响应：\(code)")
}
CaseIterable
遵循 CaseIterable 的枚举自动获得 allCases 属性，返回所有 case 的集合：


enum Season: String, CaseIterable {
    case spring = "春"
    case summer = "夏"
    case autumn = "秋"
    case winter = "冬"
}

for season in Season.allCases {
    print("\(season): \(season.rawValue)")
}

print("共 \(Season.allCases.count) 个季节")
CaseIterable 仅适用于没有关联值的枚举。带关联值的 case 无法自动枚举所有可能值。


Codable 枚举
没有关联值的枚举只需声明遵循 Codable 即可自动合成编解码实现：


enum Priority: String, Codable {
    case low, medium, high, critical
}

struct Task: Codable {
    let title: String
    let priority: Priority
}

let json = """
{"title": "修复 Bug", "priority": "high"}
""".data(using: .utf8)!

let task = try JSONDecoder().decode(Task.self, from: json)
print(task.priority)
带关联值的枚举在 Swift 5.5+ 也支持自动合成 Codable：


enum PaymentMethod: Codable {
    case creditCard(number: String, expiry: String)
    case bankTransfer(iban: String)
    case cash
}

let payment = PaymentMethod.creditCard(number: "4242****4242", expiry: "12/26")
let encoded = try JSONEncoder().encode(payment)
let decoded = try JSONDecoder().decode(PaymentMethod.self, from: encoded)
自动合成会使用 case 名称作为判别键（discriminator key），关联值作为嵌套对象。如果需要自定义 JSON 结构，可以手动实现 encode(to:) 和 init(from:)。


使用方式
模式一：用枚举替代布尔标志位
多个布尔标志容易出现非法状态组合。用枚举将合法状态显式列出：


enum ViewState<T> {
    case idle
    case loading
    case loaded(T)
    case error(Error)
}

class ArticleViewModel {
    var state: ViewState<[Article]> = .idle

    func fetch() async {
        state = .loading
        do {
            let articles = try await api.fetchArticles()
            state = .loaded(articles)
        } catch {
            state = .error(error)
        }
    }
}
使用枚举后，loading 和 error 不可能同时成立——通过类型系统消除非法状态。


模式二：使用枚举建模路由
将应用的所有页面路由定义为枚举，关联值携带页面参数：


enum AppRoute: Hashable {
    case home
    case profile(userId: String)
    case settings
    case article(id: Int, section: String?)
    case search(query: String)
}

func navigate(to route: AppRoute) {
    switch route {
    case .home:
        showHome()
    case .profile(let userId):
        showProfile(for: userId)
    case .settings:
        showSettings()
    case .article(let id, let section):
        showArticle(id: id, scrollTo: section)
    case .search(let query):
        showSearch(initialQuery: query)
    }
}
模式三：结合枚举与协议构建命令模式
enum DatabaseCommand {
    case insert(table: String, values: [String: Any])
    case update(table: String, id: String, values: [String: Any])
    case delete(table: String, id: String)
    case query(sql: String)
}

protocol CommandExecutor {
    func execute(_ command: DatabaseCommand) throws -> Any?
}

extension CommandExecutor {
    func batch(_ commands: [DatabaseCommand]) throws -> [Any?] {
        try commands.map { try execute($0) }
    }
}
常见陷阱
陷阱一：switch 遗漏 case 导致运行时问题
使用 default 分支会让编译器不再在新增 case 时发出警告。尽量显式列出所有 case：


enum Permission {
    case read, write, execute, admin
}

func check(_ permission: Permission) -> Bool {
    switch permission {
    case .read: return true
    case .write: return true
    case .execute: return false
    case .admin: return false
    }
}
如果未来添加了新的 case（如 .superAdmin），编译器会在所有 switch 语句处报错，强制你处理新情况。而使用 default 则会静默通过。


对于不受你控制的枚举（如第三方库），使用 @unknown default 获取编译器警告：


switch externalEnum {
case .knownCase1: break
case .knownCase2: break
@unknown default:
    print("未知 case，需要更新处理逻辑")
}
陷阱二：关联值的相等性比较
默认情况下，带关联值的枚举不遵循 Equatable。需要显式声明，且所有关联值类型都必须遵循 Equatable：


enum Result: Equatable {
    case success(code: Int)
    case failure(message: String)
}

let a = Result.success(code: 200)
let b = Result.success(code: 200)
print(a == b)
如果关联值类型不遵循 Equatable，需要手动实现 == 运算符。


陷阱三：Optional 本身就是枚举
Swift 的 Optional<Wrapped> 就是一个枚举：


enum Optional<Wrapped> {
    case none
    case some(Wrapped)
}
因此嵌套 Optional（Int??）会有两层包装。在模式匹配时要注意层级：


let nested: Int?? = .some(nil)

switch nested {
case .some(.some(let value)):
    print("有值：\(value)")
case .some(.none):
    print("外层有值，内层为 nil")
case .none:
    print("外层为 nil")
}
陷阱四：CaseIterable 与关联值不兼容
enum Action: CaseIterable {
    case start
    case stop
    // case pause(duration: Int)  ← 编译错误：有关联值的 case 不能自动合成 CaseIterable
}
如果需要枚举所有 case 但又有关联值，必须手动实现 allCases。


小结
    

  • Swift 枚举是一等类型，支持方法、计算属性、协议遵循，远超 C 风格的整数常量集合。
    • 

  • 关联值让每个 case 携带不同类型的数据，形成代数数据类型（Sum Type），是建模有限状态的最佳工具。
    • 

  • 原始值（String、Int 等）适用于需要与外部系统（JSON、URL、数据库）互操作的场景。
    • 

  • 递归枚举（indirect）用于建模树形结构和递归表达式。
    • 

  • switch 必须穷尽所有 case，编译器在新增 case 时强制更新——避免使用 default，优先显式列出。
    • 

  • if case / guard case / for case 在只关心单个 case 时提供简洁的模式匹配语法。
    • 

  • CaseIterable 自动提供 allCases 集合，仅适用于无关联值的枚举。
    • 

  • 带关联值的枚举在 Swift 5.5+ 支持自动合成 Codable，极大简化了序列化工作。
