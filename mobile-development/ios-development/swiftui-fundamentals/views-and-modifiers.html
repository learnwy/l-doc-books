Part I · iOSiOS 开发 简介SwiftUI 基础 简介视图与修饰符

视图与修饰符

概述

在 SwiftUI 中，一切可见的界面元素都是 View。视图通过 modifier（修饰符） 进行外观和行为的定制。修饰符采用链式调用的方式，每次调用返回一个新的包装视图，形成洋葱式的嵌套结构。

本节将学习常用内置视图（Text、Image、Button、Toggle 等）、modifier 的工作原理、常用修饰符的使用方法，以及如何通过 ViewModifier 协议创建自定义修饰符。

基础用法
Text — 文本视图
Text 是最基础的视图，用于显示静态或动态文本：


VStack(alignment: .leading, spacing: 12) {
    Text("普通文本")

    Text("粗体标题")
        .font(.title)
        .bold()

    Text("自定义样式")
        .font(.system(size: 18, weight: .medium, design: .rounded))
        .foregroundStyle(.blue)

    Text("多行长文本会自动换行，你可以用 lineLimit 来限制行数，超出部分以省略号显示")
        .lineLimit(2)
        .truncationMode(.tail)

    Text("斜体") + Text(" + 粗体").bold() + Text(" 组合")
}
Image — 图片视图
VStack(spacing: 16) {
    Image(systemName: "star.fill")
        .font(.largeTitle)
        .foregroundStyle(.yellow)

    Image("photo")
        .resizable()
        .aspectRatio(contentMode: .fill)
        .frame(width: 200, height: 150)
        .clipped()

    AsyncImage(url: URL(string: "https://example.com/image.jpg")) { image in
        image
            .resizable()
            .aspectRatio(contentMode: .fit)
    } placeholder: {
        ProgressView()
    }
    .frame(width: 200, height: 150)
}
Button — 按钮视图
VStack(spacing: 16) {
    Button("简单按钮") {
        print("点击了")
    }

    Button(action: { print("自定义按钮") }) {

Toggle、Slider、TextField — 输入控件

进阶用法
Modifier 的执行顺序
修饰符的顺序至关重要，因为每个 modifier 都包装前一个视图，产生新视图：


VStack(spacing: 20) {
    Text("先 padding 后 background")
        .padding()
        .background(.blue)

    Text("先 background 后 padding")
        .background(.blue)
        .padding()
}
这两种写法的视觉效果完全不同。第一种蓝色背景覆盖整个 padding 区域，第二种蓝色背景仅覆盖文字本身。

ViewModifier 协议
当多个视图需要相同的样式组合时，可以用 ViewModifier 协议封装：


struct CardStyle: ViewModifier {
    func body(content: Content) -> some View {
        content
            .padding()
            .background(.white)
            .clipShape(RoundedRectangle(cornerRadius: 12))
            .shadow(color: .black.opacity(0.1), radius: 8, y: 4)
    }
}

extension View {
    func cardStyle() -> some View {
        modifier(CardStyle())
    }
}
使用：

带参数的自定义 Modifier
struct BadgeModifier: ViewModifier {
    let count: Int
    let color: Color

    func body(content: Content) -> some View {
        content
            .overlay(alignment: .topTrailing) {
                if count > 0 {
                    Text("\(count)")
                        .font(.caption2)
                        .bold()
                        .foregroundStyle(.white)
                        .padding(6)
                        .background(color)
                        .clipShape(Circle())
                        .offset(x: 8, y: -8)
                }
            }
    }
}

extension View {
    func badge(count: Int, color: Color = .red) -> some View {
        modifier(BadgeModifier(count: count, color: color))
    }
}
条件修饰符
SwiftUI 没有内置条件 modifier，但可以通过扩展实现：


extension View {
    @ViewBuilder
    func `if`<Transform: View>(
        _ condition: Bool,
        transform: (Self) -> Transform
    ) -> some View {
        if condition {
            transform(self)
        } else {
            self
        }
    }
}

Text("条件样式")
    .if(isHighlighted) { view in
        view
            .bold()
            .foregroundStyle(.red)
    }
完整示例
一个综合运用各种视图和修饰符的用户资料卡片：


import SwiftUI

struct ProfileCard: View {
    let name: String
    let role: String
    let avatarName: String
    let isOnline: Bool
    let skills: [String]

    var body: some View {
        VStack(spacing: 16) {
            header
            skillTags
            actionButtons
        }
        .cardStyle()
    }

    private var header: some View {
        HStack(spacing: 16) {
            Image(systemName: avatarName)
                .font(.system(size: 40))
                .foregroundStyle(.white)
                .frame(width: 72, height: 72)
                .background(
                    LinearGradient(
                        colors: [.blue, .purple],
                        startPoint: .topLeading,
                        endPoint: .bottomTrailing
                    )
                )
                .clipShape(Circle())
                .overlay(alignment: .bottomTrailing) {
                    Circle()
                        .fill(isOnline ? .green : .gray)
                        .frame(width: 16, height: 16)
                        .overlay {
                            Circle().stroke(.white, lineWidth: 2)
                        }
                }

            VStack(alignment: .leading, spacing: 4) {
                Text(name)
                    .font(.title3)
                    .bold()

                Text(role)
                    .font(.subheadline)
                    .foregroundStyle(.secondary)

                Text(isOnline ? "在线" : "离线")
                    .font(.caption)
                    .foregroundStyle(isOnline ? .green : .gray)
            }

            Spacer()
        }
    }

    private var skillTags: some View {
        FlowLayout(spacing: 8) {
            ForEach(skills, id: \.self) { skill in
                Text(skill)
                    .font(.caption)
                    .padding(.horizontal, 12)
                    .padding(.vertical, 6)
                    .background(.blue.opacity(0.1))
                    .foregroundStyle(.blue)
                    .clipShape(Capsule())
            }
        }
    }

    private var actionButtons: some View {
        HStack(spacing: 12) {
            Button(action: {}) {
                Label("消息", systemImage: "message.fill")
                    .frame(maxWidth: .infinity)
            }
            .buttonStyle(.borderedProminent)

            Button(action: {}) {
                Label("关注", systemImage: "person.badge.plus")
                    .frame(maxWidth: .infinity)
            }
            .buttonStyle(.bordered)
        }
    }
}

struct FlowLayout: Layout {
    var spacing: CGFloat = 8

    func sizeThatFits(proposal: ProposedViewSize, subviews: Subviews, cache: inout ()) -> CGSize {
        let result = arrange(proposal: proposal, subviews: subviews)
        return result.size
    }

    func placeSubviews(in bounds: CGRect, proposal: ProposedViewSize, subviews: Subviews, cache: inout ()) {
        let result = arrange(proposal: proposal, subviews: subviews)
        for (index, position) in result.positions.enumerated() {
            subviews[index].place(at: CGPoint(x: bounds.minX + position.x, y: bounds.minY + position.y), proposal: .unspecified)
        }
    }

    private func arrange(proposal: ProposedViewSize, subviews: Subviews) -> (positions: [CGPoint], size: CGSize) {
        let maxWidth = proposal.width ?? .infinity
        var positions: [CGPoint] = []
        var x: CGFloat = 0
        var y: CGFloat = 0
        var rowHeight: CGFloat = 0

        for subview in subviews {
            let size = subview.sizeThatFits(.unspecified)
            if x + size.width > maxWidth, x > 0 {
                x = 0
                y += rowHeight + spacing
                rowHeight = 0
            }
            positions.append(CGPoint(x: x, y: y))
            rowHeight = max(rowHeight, size.height)
            x += size.width + spacing
        }

        return (positions, CGSize(width: maxWidth, height: y + rowHeight))
    }
}

struct CardStyle: ViewModifier {
    func body(content: Content) -> some View {
        content
            .padding()
            .background(.white)
            .clipShape(RoundedRectangle(cornerRadius: 16))
            .shadow(color: .black.opacity(0.08), radius: 12, y: 6)
    }
}

extension View {
    func cardStyle() -> some View {
        modifier(CardStyle())
    }
}

最佳实践




✅ 推荐做法
❌ 避免做法





将重复样式封装为 ViewModifier
到处复制粘贴相同的 modifier 链




注意 modifier 顺序对布局的影响
忽略顺序，出现意外的视觉效果




使用 .foregroundStyle() 替代已废弃的 .foregroundColor()
继续使用 deprecated API




提取复杂子视图为计算属性或独立 View
在 body 中堆砌数百行嵌套代码




使用语义化字体（.title、.body）支持动态字体
硬编码固定字号，破坏无障碍访问




善用 @ViewBuilder 构建可复用视图组件
为每种变体写独立的视图结构体





Modifier 顺序经验法则：


    

  • 先设置内容属性（font、foregroundStyle）
    • 

  • 再设置内边距（padding）
    • 

  • 然后设置背景和边框（background、overlay、border）
    • 

  • 最后设置外部效果（shadow、clipShape）
    • 



小结
    

  • SwiftUI 内置丰富的视图组件：Text、Image、Button、Toggle、TextField、Picker 等
    • 

  • 修饰符采用链式调用，每次调用返回一个新的包装视图
    • 

  • 顺序很重要：.padding().background() 与 .background().padding() 结果不同
    • 

  • 使用 ViewModifier 协议封装可复用样式，通过 extension View 提供便捷方法
    • 

  • 带参数的 ViewModifier 可以创建灵活、可配置的样式组件
    • 

  • 语义化修饰符（如 .font(.title)）优于硬编码值，能更好地适配系统设置
    • 

  • 合理拆分子视图和提取计算属性，保持代码可读性
    •
