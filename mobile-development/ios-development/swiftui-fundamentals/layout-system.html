Part I · iOSiOS 开发 简介SwiftUI 基础 简介布局系统

布局系统

概述

SwiftUI 的布局系统基于一个简洁的三步协商机制：父视图建议尺寸 → 子视图决定自身尺寸 → 父视图放置子视图。理解这一机制是掌握 SwiftUI 布局的关键。

本节将学习核心布局容器（HStack、VStack、ZStack）、辅助元素（Spacer、Divider）、GeometryReader 获取几何信息、对齐方式、懒加载容器、iOS 16+ Grid 以及布局优先级。

基础用法
HStack — 水平排列
HStack(spacing: 12) {
    Image(systemName: "star.fill")
        .foregroundStyle(.yellow)
    Text("收藏")
    Spacer()
    Text("128")
        .foregroundStyle(.secondary)
}
.padding()
VStack — 垂直排列
VStack(alignment: .leading, spacing: 8) {
    Text("文章标题")
        .font(.headline)
    Text("这是文章的摘要信息，可能会有多行内容展示。")
        .font(.subheadline)
        .foregroundStyle(.secondary)
    Text("2026-03-29")
        .font(.caption)
        .foregroundStyle(.tertiary)
}
.padding()
ZStack — 层叠排列
ZStack(alignment: .bottomTrailing) {
    Image("background")
        .resizable()
        .aspectRatio(contentMode: .fill)
        .frame(height: 200)
        .clipped()

    LinearGradient(
        colors: [.clear, .black.opacity(0.6)],
        startPoint: .top,
        endPoint: .bottom
    )

    Text("叠加文字")
        .font(.title2)
        .bold()
        .foregroundStyle(.white)
        .padding()
}
.clipShape(RoundedRectangle(cornerRadius: 12))
Spacer 与 Divider
Spacer 占据剩余空间，Divider 绘制分隔线：


VStack {
    HStack {
        Text("左侧")
        Spacer()
        Text("右侧")
    }

    Divider()

    HStack {
        Text("项目 A")
        Spacer(minLength: 20)
        Text("项目 B")
        Spacer(minLength: 20)
        Text("项目 C")
    }
}
.padding()
对齐方式
VStack(spacing: 20) {
    HStack(alignment: .firstTextBaseline) {
        Text("大标题")
            .font(.largeTitle)
        Text("小标注")
            .font(.caption)
    }

    HStack(alignment: .center) {
        Rectangle()
            .fill(.blue)
            .frame(width: 40, height: 80)
        Rectangle()
            .fill(.green)
            .frame(width: 40, height: 40)
        Rectangle()
            .fill(.orange)
            .frame(width: 40, height: 60)
    }
}
进阶用法
frame 修饰符详解
frame 是最常用的布局修饰符，有两种形式：


VStack(spacing: 16) {
    Text("固定尺寸")
        .frame(width: 200, height: 50)
        .background(.blue.opacity(0.2))

    Text("弹性尺寸")
        .frame(minWidth: 100, maxWidth: .infinity, minHeight: 44)
        .background(.green.opacity(0.2))

    Text("居中对齐")
        .frame(maxWidth: .infinity, alignment: .center)
        .background(.orange.opacity(0.2))

    Text("左对齐")
        .frame(maxWidth: .infinity, alignment: .leading)
        .background(.purple.opacity(0.2))
}
.padding()
GeometryReader
GeometryReader 允许子视图获取父容器的尺寸和坐标信息：


struct ProportionalBar: View {
    let ratio: CGFloat

    var body: some View {
        GeometryReader { geometry in
            ZStack(alignment: .leading) {
                RoundedRectangle(cornerRadius: 4)
                    .fill(.gray.opacity(0.2))

                RoundedRectangle(cornerRadius: 4)
                    .fill(.blue)
                    .frame(width: geometry.size.width * ratio)
            }
        }
        .frame(height: 8)
    }
}

struct StatsView: View {
    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            StatRow(label: "Swift", value: 0.9)
            StatRow(label: "SwiftUI", value: 0.75)
            StatRow(label: "UIKit", value: 0.6)
        }
        .padding()
    }
}

struct StatRow: View {
    let label: String
    let value: CGFloat

    var body: some View {
        VStack(alignment: .leading, spacing: 4) {
            HStack {
                Text(label)
                    .font(.subheadline)
                Spacer()
                Text("\(Int(value * 100))%")
                    .font(.caption)
                    .foregroundStyle(.secondary)
            }
            ProportionalBar(ratio: value)
        }
    }
}
LazyVStack / LazyHStack
懒加载容器仅在视图即将出现在屏幕上时才创建，适合大量数据场景：


ScrollView {
    LazyVStack(spacing: 1) {
        ForEach(0..<1000) { index in
            HStack {
                Circle()
                    .fill(.blue)
                    .frame(width: 40, height: 40)
                    .overlay {
                        Text("\(index)")
                            .font(.caption)
                            .foregroundStyle(.white)
                    }

                VStack(alignment: .leading) {
                    Text("项目 \(index)")
                        .font(.headline)
                    Text("懒加载视图，滚动时按需创建")
                        .font(.caption)
                        .foregroundStyle(.secondary)
                }

                Spacer()
            }
            .padding(.horizontal)
            .padding(.vertical, 8)
            .background(.white)
        }
    }
}
与普通 VStack 的区别：






特性
VStack
LazyVStack





创建时机
一次性创建所有子视图
按需创建可见子视图




适用场景
少量子视图 (< 100)
大量子视图 (数百或数千)




内存占用
所有子视图常驻内存
仅可见区域附近在内存中




滚动性能
初始化慢，滚动流畅
初始化快，滚动时按需加载





Grid (iOS 16+)
Grid 提供类似表格的二维对齐布局：


Grid(alignment: .leading, horizontalSpacing: 16, verticalSpacing: 12) {
    GridRow {
        Text("姓名")
            .bold()
        Text("职位")
            .bold()
        Text("部门")
            .bold()
    }

    Divider()
        .gridCellUnsizedAxes(.horizontal)

    GridRow {
        Text("张三")
        Text("iOS 工程师")
        Text("移动端")
    }

    GridRow {
        Text("李四")
        Text("后端工程师")
        Text("服务端")
    }

    GridRow {
        Text("王五")
        Text("设计师")
            .gridCellColumns(2)
    }
}
.padding()
布局优先级
layoutPriority 控制多个子视图争夺剩余空间时的优先级：


HStack {
    Text("重要内容：这段文字优先显示完整")
        .layoutPriority(1)
        .lineLimit(1)

    Spacer(minLength: 8)

    Text("次要内容可能被截断")
        .lineLimit(1)
        .foregroundStyle(.secondary)
}
.padding()
默认优先级为 0，值越大越优先获得空间。当空间不足时，低优先级的视图先被压缩。


完整示例
一个结合所有布局概念的仪表盘界面：


import SwiftUI

struct DashboardView: View {
    let stats = [
        ("下载量", "12.4K", 0.82, Color.blue),
        ("活跃用户", "3.2K", 0.65, Color.green),
        ("收入", "¥48K", 0.91, Color.orange),
    ]

    var body: some View {
        ScrollView {
            VStack(spacing: 20) {
                headerSection
                statsGrid
                chartSection
                recentActivity
            }
            .padding()
        }
        .background(Color(.systemGroupedBackground))
    }

    private var headerSection: some View {
        HStack {
            VStack(alignment: .leading, spacing: 4) {
                Text("仪表盘")
                    .font(.largeTitle)
                    .bold()
                Text("2026 年 3 月数据概览")
                    .foregroundStyle(.secondary)
            }
            Spacer()
            Image(systemName: "bell.badge")
                .font(.title2)
                .foregroundStyle(.blue)
        }
    }

    private var statsGrid: some View {
        Grid(horizontalSpacing: 12, verticalSpacing: 12) {
            GridRow {
                ForEach(stats, id: \.0) { stat in
                    StatCard(title: stat.0, value: stat.1, progress: stat.2, color: stat.3)
                }
            }
        }
    }

    private var chartSection: some View {
        VStack(alignment: .leading, spacing: 12) {
            Text("趋势")
                .font(.headline)

            GeometryReader { geometry in
                let barWidth = (geometry.size.width - CGFloat(6) * 8) / 7

                HStack(alignment: .bottom, spacing: 8) {
                    ForEach(Array(weekData.enumerated()), id: \.offset) { index, value in
                        VStack(spacing: 4) {
                            RoundedRectangle(cornerRadius: 4)
                                .fill(.blue.gradient)
                                .frame(width: barWidth, height: geometry.size.height * 0.8 * value)

                            Text(weekLabels[index])
                                .font(.caption2)
                                .foregroundStyle(.secondary)
                        }
                    }
                }
            }
            .frame(height: 160)
        }
        .padding()
        .background(.white)
        .clipShape(RoundedRectangle(cornerRadius: 12))
    }

    private var recentActivity: some View {
        VStack(alignment: .leading, spacing: 12) {
            Text("最近活动")
                .font(.headline)

            LazyVStack(spacing: 0) {
                ForEach(activities, id: \.self) { activity in
                    HStack(spacing: 12) {
                        Circle()
                            .fill(.blue.opacity(0.1))
                            .frame(width: 36, height: 36)
                            .overlay {
                                Image(systemName: "person.fill")
                                    .font(.caption)
                                    .foregroundStyle(.blue)
                            }

                        VStack(alignment: .leading, spacing: 2) {
                            Text(activity)
                                .font(.subheadline)
                            Text("刚刚")
                                .font(.caption)
                                .foregroundStyle(.secondary)
                        }

                        Spacer()
                    }
                    .padding(.vertical, 8)

                    if activity != activities.last {
                        Divider()
                    }
                }
            }
        }
        .padding()
        .background(.white)
        .clipShape(RoundedRectangle(cornerRadius: 12))
    }

    private var weekData: [CGFloat] {
        [0.3, 0.5, 0.45, 0.7, 0.85, 0.6, 0.9]
    }

    private var weekLabels: [String] {
        ["周一", "周二", "周三", "周四", "周五", "周六", "周日"]
    }

    private var activities: [String] {
        ["新用户注册", "完成首次购买", "提交应用评价", "分享到社交媒体"]
    }
}

struct StatCard: View {
    let title: String
    let value: String
    let progress: CGFloat
    let color: Color

    var body: some View {
        VStack(alignment: .leading, spacing: 8) {
            Text(title)
                .font(.caption)
                .foregroundStyle(.secondary)

            Text(value)
                .font(.title2)
                .bold()

            GeometryReader { geometry in
                ZStack(alignment: .leading) {
                    RoundedRectangle(cornerRadius: 2)
                        .fill(color.opacity(0.2))
                    RoundedRectangle(cornerRadius: 2)
                        .fill(color)
                        .frame(width: geometry.size.width * progress)
                }
            }
            .frame(height: 4)
        }
        .padding()
        .background(.white)
        .clipShape(RoundedRectangle(cornerRadius: 12))
    }
}

最佳实践




✅ 推荐做法
❌ 避免做法





优先使用 HStack/VStack/ZStack 组合布局
滥用 GeometryReader 实现简单布局




大列表使用 LazyVStack 提升性能
用普通 VStack 渲染上千个子视图




使用 Spacer 和 alignment 控制间距
用 .offset() 手动定位，破坏自适应




利用 layoutPriority 处理空间竞争
硬编码宽度来解决文字截断




iOS 16+ 使用 Grid 实现表格对齐
嵌套多层 HStack/VStack 模拟网格




GeometryReader 仅在需要精确尺寸时使用
将 GeometryReader 作为默认布局方式





GeometryReader 使用注意：


    

  • GeometryReader 会占据所有可用空间，可能导致意外的布局撑开
    • 

  • 尽量将 GeometryReader 放在布局层级的末端，给定 .frame() 约束
    • 

  • 读取尺寸做计算时，注意避免在 body 中触发状态更新导致无限循环
    • 



小结
    

  • SwiftUI 布局基于三步协商：父建议 → 子决定 → 父放置
    • 

  • HStack / VStack / ZStack 是三大核心布局容器，分别处理水平、垂直、层叠排列
    • 

  • Spacer 占据剩余空间，Divider 绘制分隔线
    • 

  • alignment 参数控制子视图在交叉轴上的对齐方式
    • 

  • GeometryReader 可获取父容器的精确尺寸，适合自适应图表等场景
    • 

  • LazyVStack / LazyHStack 按需加载子视图，适合长列表性能优化
    • 

  • Grid（iOS 16+）提供原生的二维表格布局能力
    • 

  • layoutPriority 决定子视图在空间竞争中的优先级
    •
