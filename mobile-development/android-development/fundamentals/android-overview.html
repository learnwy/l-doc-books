Android 开发概览

Android 是全球最流行的移动操作系统之一，基于 Linux 内核构建，为数十亿设备提供运行环境。本文将从平台架构、Jetpack 组件库、开发环境搭建和项目结构四个维度，全面介绍 Android 开发的基础知识。

平台架构

Android 平台采用分层架构设计，每一层为上层提供抽象和服务。





层级
说明
关键组件

Binder IPC、电源管理、内存管理







提示： 从 Android 5.0 开始，ART（Android Runtime）全面取代 Dalvik，带来 AOT 编译和更优的垃圾回收性能。






Jetpack 概览
Jetpack 是 Google 推出的一套 Android 组件库，帮助开发者遵循最佳实践、减少样板代码，并在不同 Android 版本间保持兼容性。


Jetpack 的核心优势：


    

  • 向后兼容：组件独立于 Android 系统版本发布，通过 AndroidX 命名空间提供
    • 

  • 减少样板代码：如 ViewModel 自动管理生命周期相关数据
    • 

  • 推荐架构：遵循单向数据流和关注点分离原则
    • 





开发环境
Android 开发推荐使用 Android Studio，它基于 IntelliJ IDEA 构建，提供完整的 Android 开发工具链。


// 验证环境：在 build.gradle.kts 中查看基本配置
plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.kotlin.android)
    alias(libs.plugins.kotlin.compose)
}

android {
    namespace = "com.example.myapp"
    compileSdk = 35

    defaultConfig {
        applicationId = "com.example.myapp"
        minSdk = 26
        targetSdk = 35
        versionCode = 1
        versionName = "1.0"
    }

    buildFeatures {
        compose = true
    }
}

项目结构
标准 Android 项目采用 Gradle 多模块结构，清晰分离关注点。


my-app/
├── app/                          # 主应用模块
│   ├── src/
│   │   ├── main/
│   │   │   ├── java/com/example/ # Kotlin/Java 源码
│   │   │   ├── res/              # 资源文件
│   │   │   │   ├── layout/       # XML 布局（传统 View 体系）
│   │   │   │   ├── values/       # 字符串、颜色、尺寸
│   │   │   │   ├── drawable/     # 图片和矢量资源
│   │   │   │   └── mipmap/       # 应用图标
│   │   │   └── AndroidManifest.xml
│   │   ├── test/                 # 单元测试
│   │   └── androidTest/          # 仪器测试
│   └── build.gradle.kts
├── feature/                      # 功能模块
│   ├── home/
│   └── settings/
├── core/                         # 核心公共模块
│   ├── data/
│   ├── domain/
│   └── ui/
├── gradle/
│   └── libs.versions.toml        # 版本目录
├── build.gradle.kts              # 根构建脚本
└── settings.gradle.kts           # 模块声明
多模块架构遵循的基本原则：


    

  • :app 模块只负责组装各功能模块，不包含业务逻辑
    • 

  • :feature:* 模块包含具体的 UI 和业务逻辑
    • 

  • :core:* 模块提供共享功能，如网络请求、数据库、通用 UI 组件
    • 





小结
    

  • Android 平台采用分层架构，从 Linux 内核到应用层逐层抽象
    • 

  • Jetpack 提供了一套全面的组件库，覆盖 UI、架构和行为三大类
    • 

  • Android Studio 是推荐的开发环境，集成了完整的调试和性能分析工具
    • 

  • 现代 Android 项目推荐采用多模块架构，遵循关注点分离原则
    • 

  • Version Catalog 是管理依赖版本的最佳实践
    •
