Retrofit 与 OkHttp

Retrofit 是 Android 最流行的类型安全 HTTP 客户端，建立在 OkHttp 之上。Retrofit 通过接口声明 API 端点，OkHttp 提供底层的 HTTP 通信、连接池、缓存和拦截器等能力。

核心概念

这套网络栈围绕四个核心概念：

  • 接口即 API：Retrofit 用注解（@GET / @Path / @Query / @Body 等）在接口上声明端点，编译期生成实现，调用方得到类型安全的 suspend 函数。
  • 转换器（Converter）：负责请求/响应体的序列化，Kotlin Serialization 因编译时生成、性能好而成为推荐选择。
  • 拦截器（Interceptor）：在请求/响应链路上插入横切逻辑（鉴权、日志、重试）；应用拦截器在缓存之前，网络拦截器在缓存之后，用于缓存头修改。
  • 缓存与安全：内置 HTTP 缓存遵循 Cache-Control，支持离线访问；Certificate Pinning 固定服务器证书公钥防中间人攻击，需固定至少两个哈希以应对轮换。

API 接口

Retrofit 使用注解标记接口方法，定义 HTTP 请求的 URL、方法和参数。

interface ArticleApi {

    @GET("articles")
    suspend fun getArticles(
        @Query("page") page: Int = 1,
        @Query("size") size: Int = 20,
        @Query("category") category: String? = null
    ): ApiResponse<List<ArticleDto>>

    @GET("articles/{id}")
    suspend fun getArticleById(@Path("id") id: String): ApiResponse<ArticleDto>

    @POST("articles")
    suspend fun createArticle(@Body request: CreateArticleRequest): ApiResponse<ArticleDto>

    @PUT("articles/{id}")
    suspend fun updateArticle(
        @Path("id") id: String,
        @Body request: UpdateArticleRequest
    ): ApiResponse<ArticleDto>

    @DELETE("articles/{id}")
    suspend fun deleteArticle(@Path("id") id: String): ApiResponse<Unit>

    @Multipart
    @POST("articles/{id}/images")
    suspend fun uploadImage(
        @Path("id") id: String,
        @Part image: MultipartBody.Part
    ): ApiResponse<ImageUrl>

    @Streaming
    @GET("files/{name}")
    suspend fun downloadFile(@Path("name") fileName: String): ResponseBody
}

@Serializable
data class ApiResponse<T>(
    val code: Int,
    val message: String,
    val data: T?
)

@Serializable
data class ArticleDto(
    val id: String,
    val title: String,
    val content: String,
    val author: AuthorDto,
    @SerialName("created_at") val createdAt: String
)

转换器

Converter 负责请求体和响应体的序列化与反序列化。推荐使用 Kotlin Serialization。

@Module
@InstallIn(SingletonComponent::class)
object NetworkModule {

    @Provides
    @Singleton
    fun provideJson(): Json = Json {
        ignoreUnknownKeys = true
        coerceInputValues = true
        encodeDefaults = true
        isLenient = true
    }

    @Provides
    @Singleton
    fun provideRetrofit(
        okHttpClient: OkHttpClient,
        json: Json
    ): Retrofit {
        return Retrofit.Builder()
            .baseUrl("https://api.example.com/v1/")
            .client(okHttpClient)
            .addConverterFactory(json.asConverterFactory("application/json".toMediaType()))
            .build()
    }
}

拦截器

OkHttp 拦截器可以在请求和响应的链路中插入自定义逻辑。

class AuthInterceptor @Inject constructor(
    private val tokenStore: TokenStore
) : Interceptor {

    override fun intercept(chain: Interceptor.Chain): Response {
        val token = tokenStore.getAccessToken()
        val request = chain.request().newBuilder().apply {
            if (token != null) {
                addHeader("Authorization", "Bearer $token")
            }
            addHeader("Accept-Language", Locale.getDefault().language)
        }.build()
        return chain.proceed(request)
    }
}

class TokenRefreshInterceptor @Inject constructor(
    private val tokenStore: TokenStore,
    private val authApi: Lazy<AuthApi>
) : Interceptor {

    override fun intercept(chain: Interceptor.Chain): Response {
        val response = chain.proceed(chain.request())

        if (response.code == 401) {
            synchronized(this) {
                val newToken = runBlocking {
                    authApi.get().refreshToken(tokenStore.getRefreshToken()!!)
                }
                tokenStore.saveToken(newToken)

                val newRequest = chain.request().newBuilder()
                    .header("Authorization", "Bearer ${newToken.accessToken}")
                    .build()
                response.close()
                return chain.proceed(newRequest)
            }
        }
        return response
    }
}

@Provides
@Singleton
fun provideOkHttpClient(
    authInterceptor: AuthInterceptor,
    tokenRefreshInterceptor: TokenRefreshInterceptor
): OkHttpClient {
    return OkHttpClient.Builder()
        .addInterceptor(authInterceptor)
        .addInterceptor(tokenRefreshInterceptor)
        .addInterceptor(HttpLoggingInterceptor().apply {
            level = if (BuildConfig.DEBUG) HttpLoggingInterceptor.Level.BODY
                else HttpLoggingInterceptor.Level.NONE
        })
        .connectTimeout(30, TimeUnit.SECONDS)
        .readTimeout(30, TimeUnit.SECONDS)
        .writeTimeout(30, TimeUnit.SECONDS)
        .build()
}

缓存

OkHttp 内置 HTTP 缓存支持，遵循 Cache-Control 头标准。

@Provides
@Singleton
fun provideOkHttpClient(@ApplicationContext context: Context): OkHttpClient {
    val cacheDir = File(context.cacheDir, "http_cache")
    val cache = Cache(cacheDir, 50L * 1024 * 1024) // 50 MB

    return OkHttpClient.Builder()
        .cache(cache)
        .addNetworkInterceptor { chain ->
            val response = chain.proceed(chain.request())
            response.newBuilder()
                .header("Cache-Control", "public, max-age=300")
                .removeHeader("Pragma")
                .build()
        }
        .addInterceptor { chain ->
            val request = if (!isNetworkAvailable(context)) {
                chain.request().newBuilder()
                    .header("Cache-Control", "public, only-if-cached, max-stale=604800")
                    .build()
            } else {
                chain.request()
            }
            chain.proceed(request)
        }
        .build()
}
拦截器类型 方法 执行位置 适用场景
应用拦截器 addInterceptor() 缓存之前 Auth、日志、重试
网络拦截器 addNetworkInterceptor() 缓存之后 缓存头修改、压缩

证书固定

Certificate Pinning 防止中间人攻击，固定服务器证书的公钥哈希。

@Provides
@Singleton
fun provideSecureOkHttpClient(): OkHttpClient {
    val certificatePinner = CertificatePinner.Builder()
        .add("api.example.com", "sha256/AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA=")
        .add("api.example.com", "sha256/BBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBB=")
        .build()

    return OkHttpClient.Builder()
        .certificatePinner(certificatePinner)
        .build()
}

提示： 始终固定至少两个证书哈希（当前证书和备份证书），避免证书轮换时应用无法连接。

小结

  • Retrofit 通过接口注解声明 API，支持 GET/POST/PUT/DELETE 等 HTTP 方法
  • Kotlin Serialization 是推荐的转换器，提供编译时序列化性能
  • OkHttp 拦截器实现鉴权、日志、缓存控制等横切关注点
  • 内置缓存支持离线访问，缓存策略遵循 HTTP Cache-Control 标准
  • Certificate Pinning 固定服务器证书防止中间人攻击
