Part II · AndroidAndroid 开发 简介依赖注入 简介作用域与绑定

作用域与绑定

Hilt 的作用域机制控制依赖的生命周期范围，绑定策略决定如何提供依赖实例。正确使用作用域和高级绑定功能是构建高效、可维护的依赖注入体系的关键。

@Singleton

@Singleton 是最常用的作用域，确保在整个应用生命周期内只创建一个实例。

@Singleton
class AppDatabase @Inject constructor(
    @ApplicationContext private val context: Context
) {
    val db = Room.databaseBuilder(context, MyDatabase::class.java, "app.db").build()
}

@Module
@InstallIn(SingletonComponent::class)
object AppModule {

    @Provides
    @Singleton
    fun provideHttpClient(): OkHttpClient {
        return OkHttpClient.Builder()
            .addInterceptor(AuthInterceptor())
            .build()
    }

    @Provides
    @Singleton
    fun provideJson(): Json {
        return Json {
            ignoreUnknownKeys = true
            coerceInputValues = true
            prettyPrint = false
        }
    }
}

使用与不使用作用域的区别：

有 @Singleton 无作用域注解
全局唯一实例 每次注入新建实例
首次注入时创建 每次注入时创建
占用内存直到进程结束 使用后可被 GC 回收
适合重量级对象 适合轻量级/无状态对象

提示： 不要过度使用 @Singleton，只有确实需要全局共享的对象才应该设为单例，否则会增加内存占用。

@ViewModelScoped

@ViewModelScoped 将依赖绑定到 ViewModel 的生命周期，同一 ViewModel 内注入的多个位置共享同一实例。

@ViewModelScoped
class CartStateHolder @Inject constructor(
    private val cartRepository: CartRepository
) {
    private val _items = MutableStateFlow<List<CartItem>>(emptyList())
    val items = _items.asStateFlow()

    suspend fun addItem(item: CartItem) {
        cartRepository.add(item)
        _items.update { it + item }
    }
}

@HiltViewModel
class CheckoutViewModel @Inject constructor(
    private val cartStateHolder: CartStateHolder,
    private val paymentService: PaymentService
) : ViewModel() {

    val cartItems = cartStateHolder.items

    fun checkout() {
        viewModelScope.launch {
            paymentService.process(cartItems.value)
        }
    }
}


@ActivityRetainedScoped
@ActivityRetainedScoped 的生命周期跨越配置变更，类似 ViewModel 的存活范围。


@ActivityRetainedScoped
class SessionManager @Inject constructor(
    private val authRepository: AuthRepository,
    private val tokenStore: TokenStore
) {
    private val _authState = MutableStateFlow<AuthState>(AuthState.Unknown)
    val authState = _authState.asStateFlow()

    suspend fun login(credentials: Credentials) {
        val token = authRepository.authenticate(credentials)
        tokenStore.saveToken(token)
        _authState.value = AuthState.Authenticated(token.userId)
    }

    fun logout() {
        tokenStore.clearToken()
        _authState.value = AuthState.Unauthenticated
    }
}

sealed interface AuthState {
    data object Unknown : AuthState
    data class Authenticated(val userId: String) : AuthState
    data object Unauthenticated : AuthState
}

自定义组件
Hilt 允许创建自定义组件来满足特殊的作用域需求。


@DefineComponent(parent = SingletonComponent::class)
@UserScope
interface UserComponent

@DefineComponent.Builder
interface UserComponentBuilder {
    fun setUser(@BindsInstance user: User): UserComponentBuilder
    fun build(): UserComponent
}

@Scope
@Retention(AnnotationRetention.RUNTIME)
annotation class UserScope

@UserScope
class UserAnalytics @Inject constructor(
    private val user: User,
    private val tracker: AnalyticsTracker
) {
    fun trackAction(action: String) {
        tracker.track(action, mapOf("userId" to user.id))
    }
}

@Singleton
class UserComponentManager @Inject constructor(
    private val builder: Provider<UserComponentBuilder>
) {
    private var component: UserComponent? = null

    fun createComponent(user: User) {
        component = builder.get().setUser(user).build()
    }

    fun destroyComponent() {
        component = null
    }
}


Multibindings
Multibindings 允许将多个绑定收集到 Set 或 Map 中，适合插件化架构。


interface FeatureInitializer {
    fun initialize()
    val priority: Int
}

class AnalyticsInitializer @Inject constructor() : FeatureInitializer {
    override fun initialize() { /* 初始化分析 */ }
    override val priority = 1
}

class CrashReporterInitializer @Inject constructor() : FeatureInitializer {
    override fun initialize() { /* 初始化崩溃报告 */ }
    override val priority = 0
}

@Module
@InstallIn(SingletonComponent::class)
abstract class InitializerModule {

    @Binds
    @IntoSet
    abstract fun bindAnalytics(impl: AnalyticsInitializer): FeatureInitializer

    @Binds
    @IntoSet
    abstract fun bindCrashReporter(impl: CrashReporterInitializer): FeatureInitializer
}

@Singleton
class AppInitializer @Inject constructor(
    private val initializers: Set<@JvmSuppressWildcards FeatureInitializer>
) {
    fun initializeAll() {
        initializers.sortedBy { it.priority }.forEach { it.initialize() }
    }
}

@Module
@InstallIn(SingletonComponent::class)
abstract class HandlerModule {

    @Binds
    @IntoMap
    @StringKey("push")
    abstract fun bindPushHandler(impl: PushNotificationHandler): NotificationHandler

    @Binds
    @IntoMap
    @StringKey("email")
    abstract fun bindEmailHandler(impl: EmailNotificationHandler): NotificationHandler
}

@Singleton
class NotificationDispatcher @Inject constructor(
    private val handlers: Map<String, @JvmSuppressWildcards NotificationHandler>
) {
    fun dispatch(type: String, payload: NotificationPayload) {
        handlers[type]?.handle(payload)
    }
}


提示： Multibindings 中注入 Set<T> 或 Map<K, V> 时，需要在泛型参数上添加 @JvmSuppressWildcards，否则 Kotlin 编译器会生成通配符类型导致 Dagger 无法匹配。






小结
    

  • @Singleton 提供全局唯一实例，避免过度使用以减少内存占用
    • 

  • @ViewModelScoped 在 ViewModel 内共享依赖，@ActivityRetainedScoped 跨配置变更存活
    • 

  • 自定义组件通过 @DefineComponent 实现特殊的作用域需求
    • 

  • Multibindings 将多个实现收集到 Set 或 Map，适合插件化和策略模式架构
    • 

  • 作用域的选择应基于依赖的实际生命周期需求，不要盲目使用 @Singleton
    •
