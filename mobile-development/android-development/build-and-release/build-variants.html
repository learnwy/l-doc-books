Part II · AndroidAndroid 开发 简介构建与发布 简介构建变体

构建变体

Android 构建变体（Build Variants）由 Build Type 和 Product Flavor 组合而成，允许从同一个代码库生成多个不同版本的应用。这在管理开发/测试/生产环境、多品牌应用等场景中非常有用。

Build Types

Build Type 定义构建的编译和打包方式，默认包含 debug 和 release 两种。

android {
    buildTypes {
        debug {
            isDebuggable = true
            isMinifyEnabled = false
            applicationIdSuffix = ".debug"
            versionNameSuffix = "-debug"
            buildConfigField("String", "API_BASE_URL", "\"https://dev-api.example.com/\"")
            buildConfigField("Boolean", "ENABLE_LOGGING", "true")
        }

        release {
            isDebuggable = false
            isMinifyEnabled = true
            isShrinkResources = true
            proguardFiles(
                getDefaultProguardFile("proguard-android-optimize.txt"),
                "proguard-rules.pro"
            )
            buildConfigField("String", "API_BASE_URL", "\"https://api.example.com/\"")
            buildConfigField("Boolean", "ENABLE_LOGGING", "false")
            signingConfig = signingConfigs.getByName("release")
        }

        create("staging") {
            initWith(getByName("release"))
            applicationIdSuffix = ".staging"
            versionNameSuffix = "-staging"
            buildConfigField("String", "API_BASE_URL", "\"https://staging-api.example.com/\"")
            buildConfigField("Boolean", "ENABLE_LOGGING", "true")
            matchingFallbacks += listOf("release")
        }
    }
}
Build Type 可调试 代码混淆 资源压缩 用途
debug 是 否 否 日常开发调试
release 否 是 是 正式发布
staging 否 是 是 预发布测试

提示： initWith() 可以基于已有的 Build Type 创建新类型，避免重复配置。

Product Flavors

Product Flavor 定义应用的不同版本，通常用于多品牌、多环境或免费/付费版本。

android {
    flavorDimensions += listOf("version", "market")

    productFlavors {
        create("free") {
            dimension = "version"
            applicationIdSuffix = ".free"
            buildConfigField("Boolean", "IS_PREMIUM", "false")
            buildConfigField("Int", "MAX_ITEMS", "10")
        }
        create("premium") {
            dimension = "version"
            applicationIdSuffix = ".premium"
            buildConfigField("Boolean", "IS_PREMIUM", "true")
            buildConfigField("Int", "MAX_ITEMS", "999999")
        }
        create("googlePlay") {
            dimension = "market"
        }
        create("huawei") {
            dimension = "market"
            buildConfigField("String", "STORE", "\"huawei\"")
        }
    }
}


Dimension
多个 Flavor Dimension 的组合会产生笛卡尔积，生成所有可能的变体。

过滤不需要的变体：


android {
    androidComponents {
        beforeVariants { variantBuilder ->
            if (variantBuilder.productFlavors.containsAll(
                listOf("version" to "free", "market" to "huawei"))
            ) {
                variantBuilder.enable = false
            }
        }
    }
}


BuildConfig 字段
buildConfigField 在编译时生成常量，可以在代码中直接使用。


// build.gradle.kts
android {
    defaultConfig {
        buildConfigField("String", "APP_VERSION", "\"${project.version}\"")
        buildConfigField("Long", "BUILD_TIMESTAMP", "${System.currentTimeMillis()}L")
    }
}

// 在代码中使用
object AppConfig {
    val apiBaseUrl: String = BuildConfig.API_BASE_URL
    val isLoggingEnabled: Boolean = BuildConfig.ENABLE_LOGGING
    val isPremium: Boolean = BuildConfig.IS_PREMIUM
    val buildTimestamp: Long = BuildConfig.BUILD_TIMESTAMP
}

@Module
@InstallIn(SingletonComponent::class)
object NetworkModule {

    @Provides
    @Singleton
    fun provideRetrofit(): Retrofit {
        return Retrofit.Builder()
            .baseUrl(BuildConfig.API_BASE_URL)
            .build()
    }
}
// 使用 resValue 动态设置资源值
android {
    productFlavors {
        create("free") {
            dimension = "version"
            resValue("string", "app_name", "MyApp Free")
            resValue("color", "brand_color", "#4CAF50")
        }
        create("premium") {
            dimension = "version"
            resValue("string", "app_name", "MyApp Pro")
            resValue("color", "brand_color", "#FF9800")
        }
    }
}


Source Sets
每个构建变体可以拥有独立的源代码和资源目录。


app/src/
├── main/           # 所有变体共享
│   ├── java/
│   ├── res/
│   └── AndroidManifest.xml
├── debug/          # debug 类型专用
│   └── java/
├── release/        # release 类型专用
│   └── java/
├── free/           # free 风味专用
│   ├── java/
│   └── res/
├── premium/        # premium 风味专用
│   ├── java/
│   └── res/
└── freeDebug/      # 特定变体专用
    └── java/
// main 中定义接口
interface BillingService {
    fun purchase(productId: String)
    fun checkSubscription(): Boolean
}

// free/java/.../FreeBillingService.kt
class FreeBillingServiceImpl : BillingService {
    override fun purchase(productId: String) {
        // 跳转到付费版下载页
    }
    override fun checkSubscription() = false
}

// premium/java/.../PremiumBillingService.kt
class PremiumBillingServiceImpl : BillingService {
    override fun purchase(productId: String) {
        // 实际购买逻辑
    }
    override fun checkSubscription() = true
}


提示： Source Set 的优先级：变体专用 > 类型/风味专用 > main。同名资源文件会按优先级覆盖。






小结
    

  • Build Type 定义编译方式（debug/release/staging），控制混淆、调试和签名
    • 

  • Product Flavor 定义应用版本（free/premium、googlePlay/huawei），生成不同品牌或功能的应用
    • 

  • Flavor Dimension 的笛卡尔积产生所有构建变体，可通过 beforeVariants 过滤
    • 

  • buildConfigField 和 resValue 在编译时注入配置值
    • 

  • Source Sets 为不同变体提供独立的代码和资源目录
    •
