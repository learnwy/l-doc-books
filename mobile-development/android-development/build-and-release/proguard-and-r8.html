ProGuard 与 R8

R8 是 Android 默认的代码优化工具，取代了 ProGuard。它在编译时执行代码压缩、混淆和优化，显著减小 APK 体积并提高运行时性能。R8 完全兼容 ProGuard 的规则语法。

代码压缩（Shrinking）

代码压缩移除未使用的类、方法和字段，减少最终 APK 的体积。

android {
    buildTypes {
        release {
            isMinifyEnabled = true
            isShrinkResources = true
            proguardFiles(
                getDefaultProguardFile("proguard-android-optimize.txt"),
                "proguard-rules.pro"
            )
        }
    }
}
R8 执行的三个阶段：






阶段
说明
效果





压缩（Shrinking）
移除未使用的代码和资源
减小体积 30-50%




混淆（Obfuscation）
重命名类/方法为短名称
减小体积 + 增加逆向难度




优化（Optimization）
内联方法、简化控制流
提升运行时性能







提示： isShrinkResources = true 只有在 isMinifyEnabled = true 时才生效，它会移除未被代码引用的资源文件。






混淆（Obfuscation）
混淆将类名、方法名替换为无意义的短名称，增加反编译难度。


# 混淆前
com.example.myapp.data.repository.ArticleRepository
com.example.myapp.data.repository.ArticleRepository.getArticles()
com.example.myapp.data.model.Article

# 混淆后
a.b.c.d
a.b.c.d.a()
a.b.c.e
混淆映射文件（mapping.txt）记录了原始名称和混淆名称的对应关系：


com.example.myapp.data.repository.ArticleRepository -> a.b.c.d:
    java.util.List getArticles() -> a
    void deleteArticle(java.lang.String) -> b
com.example.myapp.data.model.Article -> a.b.c.e:
    java.lang.String id -> a
    java.lang.String title -> b


优化（Optimization）
proguard-android-optimize.txt 启用额外的优化选项。


// 优化会执行以下操作
// 1. 方法内联 - 将小方法的代码直接嵌入调用处
// 2. 常量传播 - 将常量值直接替换到使用处
// 3. 死代码消除 - 移除不可达代码
// 4. 类合并 - 将只有一个实现的接口与实现类合并

// R8 全模式（更激进的优化）
android {
    buildTypes {
        release {
            proguardFiles(
                getDefaultProguardFile("proguard-android-optimize.txt"),
                "proguard-rules.pro"
            )
        }
    }
}

// gradle.properties
// android.enableR8.fullMode=true


Keep 规则
Keep 规则告诉 R8 哪些代码不能被压缩或混淆，是正确配置 R8 的核心。


# 保留所有 Serializable 类的序列化字段
-keepclassmembers class * implements java.io.Serializable {
    static final long serialVersionUID;
    private static final java.io.ObjectStreamField[] serialPersistentFields;
    !static !transient <fields>;
    private void writeObject(java.io.ObjectOutputStream);
    private void readObject(java.io.ObjectInputStream);
    java.lang.Object writeReplace();
    java.lang.Object readResolve();
}

# Kotlin Serialization
-keepattributes *Annotation*, InnerClasses
-dontnote kotlinx.serialization.AnnotationsKt

-keepclassmembers @kotlinx.serialization.Serializable class ** {
    *** Companion;
}
-if @kotlinx.serialization.Serializable class **
-keepclassmembers class <1>$Companion {
    kotlinx.serialization.KSerializer serializer(...);
}

# Retrofit API 接口
-keep,allowobfuscation interface * {
    @retrofit2.http.* <methods>;
}

# Room Entity
-keep @androidx.room.Entity class * { *; }

# 枚举类
-keepclassmembers enum * {
    public static **[] values();
    public static ** valueOf(java.lang.String);
}

# 自定义 Parcelable
-keep class * implements android.os.Parcelable {
    public static final android.os.Parcelable$Creator *;
}

调试混淆后的构建
混淆后的崩溃堆栈需要反混淆才能定位问题。


// 保存 mapping 文件
android {
    buildTypes {
        release {
            isMinifyEnabled = true
            proguardFiles(
                getDefaultProguardFile("proguard-android-optimize.txt"),
                "proguard-rules.pro"
            )
        }
    }
}

// mapping 文件位置: app/build/outputs/mapping/release/mapping.txt
使用 retrace 工具反混淆：


# 使用 R8 retrace 工具
java -jar retrace.jar mapping.txt stacktrace.txt

# 或使用 Android SDK 提供的 proguard-retrace
proguard-retrace.sh -regex '%c.%m(%s:%l)' mapping.txt stacktrace.txt

小结
    

  • R8 是 Android 默认的代码压缩和混淆工具，兼容 ProGuard 规则语法
    • 

  • 代码压缩移除未使用代码，混淆重命名为短名称，优化提升运行时性能
    • 

  • Keep 规则防止关键代码被压缩或混淆，反射、序列化、API 接口等需要特别关注
    • 

  • mapping.txt 是反混淆崩溃堆栈的关键文件，必须妥善保存
    • 

  • R8 Full Mode 提供更激进的优化，但需要更完善的 Keep 规则配置
    •
