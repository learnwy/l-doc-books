Gradle 基础

Gradle 是 Android 项目的构建系统，负责编译代码、管理依赖、生成 APK/AAB。现代 Android 项目使用 Kotlin DSL（build.gradle.kts）编写构建脚本，结合 Version Catalog 统一管理依赖版本。

build.gradle.kts

Android 项目通常有根级别和模块级别两个构建脚本。

// 根级 build.gradle.kts
plugins {
    alias(libs.plugins.android.application) apply false
    alias(libs.plugins.android.library) apply false
    alias(libs.plugins.kotlin.android) apply false
    alias(libs.plugins.kotlin.compose) apply false
    alias(libs.plugins.hilt.android) apply false
    alias(libs.plugins.ksp) apply false
}

// 模块级 app/build.gradle.kts
plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.kotlin.android)
    alias(libs.plugins.kotlin.compose)
    alias(libs.plugins.hilt.android)
    alias(libs.plugins.ksp)
}

android {
    namespace = "com.example.myapp"
    compileSdk = 35

    defaultConfig {
        applicationId = "com.example.myapp"
        minSdk = 26
        targetSdk = 35
        versionCode = 1
        versionName = "1.0.0"
        testInstrumentationRunner = "com.example.myapp.HiltTestRunner"
    }

    buildFeatures {
        compose = true
        buildConfig = true
    }

    compileOptions {
        sourceCompatibility = JavaVersion.VERSION_17
        targetCompatibility = JavaVersion.VERSION_17
    }

    kotlinOptions {
        jvmTarget = "17"
    }
}

Convention Plugins
Convention Plugins 抽取共享的构建逻辑，避免多模块间的配置重复。


// build-logic/convention/build.gradle.kts
plugins {
    `kotlin-dsl`
}

dependencies {
    compileOnly(libs.android.gradlePlugin)
    compileOnly(libs.kotlin.gradlePlugin)
    compileOnly(libs.compose.gradlePlugin)
}

// build-logic/convention/src/main/kotlin/AndroidLibraryConventionPlugin.kt
class AndroidLibraryConventionPlugin : Plugin<Project> {
    override fun apply(target: Project) {
        with(target) {
            pluginManager.apply("com.android.library")
            pluginManager.apply("org.jetbrains.kotlin.android")

            extensions.configure<LibraryExtension> {
                compileSdk = 35
                defaultConfig.minSdk = 26
                compileOptions {
                    sourceCompatibility = JavaVersion.VERSION_17
                    targetCompatibility = JavaVersion.VERSION_17
                }
            }

            extensions.configure<KotlinAndroidProjectExtension> {
                jvmToolchain(17)
            }
        }
    }
}


提示： Convention Plugins 放在 build-logic 目录下，作为 included build 使用，这是 Now in Android 等官方示例推荐的模式。






小结
    

  • build.gradle.kts 使用 Kotlin DSL 定义构建配置，分为根级和模块级
    • 

  • Version Catalog（libs.versions.toml）集中管理依赖版本，消除版本不一致
    • 

  • 优先使用 implementation 配置减少依赖传递，加快编译速度
    • 

  • Convention Plugins 抽取多模块共享的构建逻辑，避免配置重复
    • 

  • settings.gradle.kts 声明模块和仓库，是项目结构的入口
