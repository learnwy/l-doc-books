截图测试

截图测试（Screenshot Testing）通过比较 UI 的像素级快照来检测视觉回归。它是确保 UI 一致性的有效手段，尤其适合设计系统、主题变更和跨设备适配等场景。

Paparazzi

Paparazzi 是 Square 出品的 JVM 截图测试框架，无需 Android 设备或模拟器即可运行，速度极快。

class ProductCardSnapshotTest {

    @get:Rule
    val paparazzi = Paparazzi(
        deviceConfig = DeviceConfig.PIXEL_6,
        theme = "android:Theme.Material3.Light.NoActionBar"
    )

    @Test
    fun productCard_default() {
        paparazzi.snapshot {
            ProductCard(
                product = Product(
                    id = "1",
                    name = "Kotlin 实战",
                    price = 89.0,
                    imageUrl = ""
                ),
                onClick = {}
            )
        }
    }

    @Test
    fun productCard_outOfStock() {
        paparazzi.snapshot {
            ProductCard(
                product = Product(
                    id = "2",
                    name = "缺货商品",
                    price = 59.0,
                    imageUrl = "",
                    inStock = false
                ),
                onClick = {}
            )
        }
    }

    @Test
    fun loginScreen_allStates() {
        paparazzi.snapshot("empty") {
            LoginScreen(state = LoginState.Empty)
        }
        paparazzi.snapshot("loading") {
            LoginScreen(state = LoginState.Loading)
        }
        paparazzi.snapshot("error") {
            LoginScreen(state = LoginState.Error("用户名或密码错误"))
        }
    }
}

Roborazzi
Roborazzi 基于 Robolectric，在 JVM 上模拟 Android 环境运行截图测试，支持更接近真实设备的渲染。


@RunWith(ParameterizedRobolectricTestRunner::class)
@GraphicsMode(GraphicsMode.Mode.NATIVE)
@Config(sdk = [33])
class ThemeSnapshotTest(
    private val themeName: String,
    private val isDarkTheme: Boolean
) {

    @get:Rule
    val composeRule = createComposeRule()

    @get:Rule
    val roborazziRule = RoborazziRule(
        composeRule = composeRule,
        captureRoot = composeRule.onRoot(),
        options = RoborazziRule.Options(
            outputDirectoryPath = "src/test/snapshots"
        )
    )

    companion object {
        @JvmStatic
        @ParameterizedRobolectricTestRunner.Parameters(name = "{0}")
        fun params() = listOf(
            arrayOf("light", false),
            arrayOf("dark", true)
        )
    }

    @Test
    fun settingsScreen() {
        composeRule.setContent {
            MyAppTheme(darkTheme = isDarkTheme) {
                SettingsScreen(
                    settings = AppSettings(isDarkMode = isDarkTheme),
                    onSettingsChange = {}
                )
            }
        }

        composeRule.onRoot().captureRoboImage(
            "settings_screen_$themeName.png"
        )
    }
}

@RunWith(RobolectricTestRunner::class)
@GraphicsMode(GraphicsMode.Mode.NATIVE)
class ComponentSnapshotTest {

    @get:Rule
    val composeRule = createComposeRule()

    @Test
    fun buttonVariants() {
        composeRule.setContent {
            Column(modifier = Modifier.padding(16.dp)) {
                Button(onClick = {}) { Text("Primary") }
                OutlinedButton(onClick = {}) { Text("Outlined") }
                TextButton(onClick = {}) { Text("Text") }
                FilledTonalButton(onClick = {}) { Text("Tonal") }
            }
        }

        composeRule.onRoot().captureRoboImage("button_variants.png")
    }
}

CI 集成
截图测试需要在 CI 中自动运行和管理 Golden 文件。


# GitHub Actions 配置示例
name: Screenshot Tests
on: [pull_request]

jobs:
  screenshot-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Set up JDK 17
        uses: actions/setup-java@v4
        with:
          java-version: '17'
          distribution: 'temurin'

      - name: Run screenshot tests
        run: ./gradlew verifyPaparazziDebug

      - name: Upload failure diffs
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: screenshot-diffs
          path: '**/build/reports/paparazzi/'
          retention-days: 7

Golden 文件管理
Golden 文件是截图测试的参考基准，需要规范化管理。


app/src/test/snapshots/
├── images/
│   ├── com.example.ProductCardSnapshotTest/
│   │   ├── productCard_default.png
│   │   ├── productCard_outOfStock.png
│   │   └── productCard_darkTheme.png
│   └── com.example.LoginScreenSnapshotTest/
│       ├── loginScreen_empty.png
│       ├── loginScreen_loading.png
│       └── loginScreen_error.png
更新 Golden 文件的工作流：


# 录制新的 Golden 文件
./gradlew :app:recordPaparazziDebug

# 验证当前 UI 与 Golden 文件一致
./gradlew :app:verifyPaparazziDebug

# 查看差异报告
open app/build/reports/paparazzi/index.html


提示： 在 PR 中更新 Golden 文件时，建议使用单独的提交，方便 Reviewer 区分代码变更和截图变更。






设备矩阵
通过多设备配置测试不同屏幕尺寸和密度的适配效果。


@RunWith(ParameterizedRobolectricTestRunner::class)
class DeviceMatrixTest(
    private val deviceName: String,
    private val deviceConfig: DeviceConfig
) {

    @get:Rule
    val paparazzi = Paparazzi(deviceConfig = deviceConfig)

    companion object {
        @JvmStatic
        @ParameterizedRobolectricTestRunner.Parameters(name = "{0}")
        fun devices() = listOf(
            arrayOf("phone_small", DeviceConfig.NEXUS_5),
            arrayOf("phone_large", DeviceConfig.PIXEL_6_PRO),
            arrayOf("tablet", DeviceConfig.PIXEL_C),
            arrayOf("foldable", DeviceConfig.PIXEL_FOLD)
        )
    }

    @Test
    fun homeScreen_adaptsToDevice() {
        paparazzi.snapshot("home_$deviceName") {
            HomeScreen(state = HomeUiState.sample())
        }
    }
}

小结
    

  • Paparazzi 在 JVM 上运行截图测试，无需设备，速度极快，CI 友好
    • 

  • Roborazzi 基于 Robolectric 渲染，支持交互后截图，更接近真实设备
    • 

  • CI 集成通过自动对比 Golden 文件检测视觉回归，失败时上传差异图
    • 

  • Golden 文件存入 Git 仓库管理，更新时使用独立提交便于 Review
    • 

  • 设备矩阵通过参数化测试覆盖多种屏幕尺寸和密度
