分布式数据同步与管理

概述

分布式数据管理是 HarmonyOS 超级终端体验的数据基础。它允许应用数据在用户的多台设备间自动同步，使得用户在手机上编辑的内容能即时出现在平板或电脑上。HarmonyOS 提供了分布式数据库（KV Store 和 RDB Store）、分布式文件系统和分布式数据对象三种数据同步方案，分别覆盖键值型数据、结构化数据和内存态对象的同步需求。

KV Store 分布式键值数据库
KV Store 适合存储简单配置和状态数据，同步延迟最低：


import { distributedKVStore } from '@kit.ArkData';

class PreferenceSync {
  private kvManager: distributedKVStore.KVManager | null = null;
  private kvStore: distributedKVStore.SingleKVStore | null = null;

  async initialize(context: Context): Promise<void> {
    // 创建 KVManager
    const config: distributedKVStore.KVManagerConfig = {
      bundleName: 'com.example.myapp',
      context: context,
    };
    this.kvManager = distributedKVStore.createKVManager(config);

    // 打开/创建 KV Store
    const options: distributedKVStore.Options = {
      createIfMissing: true,
      encrypt: false,
      backup: false,
      autoSync: true, // 自动同步到其他设备
      kvStoreType: distributedKVStore.KVStoreType.SINGLE_VERSION,
      securityLevel: distributedKVStore.SecurityLevel.S1,
    };
    this.kvStore = await this.kvManager.getKVStore('user_prefs', options);
  }

  async setTheme(theme: string): Promise<void> {
    await this.kvStore?.put('theme_mode', theme);
  }

  async getTheme(): Promise<string> {
    try {
      const value = await this.kvStore?.get('theme_mode');
      return (value as string) || 'light';
    } catch {
      return 'light';
    }
  }

  // 监听远端数据变更
  subscribeChanges(): void {
    this.kvStore?.on(
      'dataChange',
      distributedKVStore.SubscribeType.SUBSCRIBE_TYPE_REMOTE,
      (changeData: distributedKVStore.ChangeNotification) => {
        for (const entry of changeData.updateEntries) {
          console.info(`远端更新: ${entry.key} = ${entry.value.value}`);
          // 触发 UI 刷新
          AppStorage.set(entry.key as string, entry.value.value);
        }
      },
    );
  }
}
分布式关系型数据库
分布式 RDB 适合结构化数据的跨设备同步，支持 SQL 查询和事务：


import { relationalStore } from '@kit.ArkData';

class NotesSyncManager {
  private rdbStore: relationalStore.RdbStore | null = null;

  async initialize(context: Context): Promise<void> {
    const config: relationalStore.StoreConfig = {
      name: 'notes.db',
      securityLevel: relationalStore.SecurityLevel.S1,
    };

    this.rdbStore = await relationalStore.getRdbStore(context, config);

    // 创建表
    await this.rdbStore.executeSql(`
      CREATE TABLE IF NOT EXISTS notes (
        id TEXT PRIMARY KEY,
        title TEXT NOT NULL,
        content TEXT,
        updated_at INTEGER,
        device_id TEXT
      )
    `);

    // 配置分布式同步
    await this.rdbStore.setDistributedTables(['notes']);
  }

  // 手动触发同步
  async syncToDevices(deviceIds: string[]): Promise<void> {
    if (!this.rdbStore) return;

    const predicates = new relationalStore.RdbPredicates('notes');
    await this.rdbStore.sync(
      relationalStore.SyncMode.SYNC_MODE_PUSH, // 推送到远端
      predicates,
    );
  }

  // 监听远端同步事件
  observeSync(): void {
    this.rdbStore?.on('dataChange', relationalStore.SubscribeType.SUBSCRIBE_TYPE_REMOTE, (devices: string[]) => {
      console.info(`收到来自设备的同步: ${devices.join(', ')}`);
      this.refreshLocalData();
    });
  }

  async insertNote(note: NoteInfo): Promise<void> {
    const valueBucket: relationalStore.ValuesBucket = {
      id: note.id,
      title: note.title,
      content: note.content,
      updated_at: Date.now(),
      device_id: deviceInfo.deviceId,
    };
    await this.rdbStore?.insert('notes', valueBucket);
  }

  private async refreshLocalData(): Promise<void> {
    // 刷新本地缓存和 UI
  }
}
分布式数据对象
分布式数据对象支持内存态对象的实时跨设备同步，适合协作场景：


import { distributedDataObject } from '@kit.ArkData';

interface WhiteboardState {
  sessionId: string;
  currentColor: string;
  penSize: number;
  participantCount: number;
}

class CollaborativeWhiteboard {
  private dataObject: distributedDataObject.DataObject | null = null;

  async createSession(sessionId: string): Promise<void> {
    // 创建分布式对象
    const source: WhiteboardState = {
      sessionId: sessionId,
      currentColor: '#000000',
      penSize: 3,
      participantCount: 1,
    };

    this.dataObject = distributedDataObject.create(getContext(), source);

    // 生成组网 sessionId，加入分布式组
    this.dataObject.setSessionId(sessionId);

    // 监听对象变更
    this.dataObject.on('change', (sessionId: string, fields: string[]) => {
      console.info(`对象变更，字段: ${fields.join(', ')}`);
      for (const field of fields) {
        const value = (this.dataObject as Record<string, Object>)[field];
        AppStorage.set(`whiteboard_${field}`, value);
      }
    });

    // 监听状态变更（上线/下线）
    this.dataObject.on('status', (sessionId: string, networkId: string, status: string) => {
      console.info(`设备 ${networkId} 状态: ${status}`);
    });
  }

  updateColor(color: string): void {
    if (this.dataObject) {
      (this.dataObject as Record<string, Object>)['currentColor'] = color;
      // 自动同步到所有加入同一 sessionId 的设备
    }
  }

  leaveSession(): void {
    this.dataObject?.setSessionId('');
    this.dataObject?.off('change');
    this.dataObject?.off('status');
  }
}

安全与权限
分布式数据同步的安全模型基于设备认证和数据分级：


// 数据安全等级决定同步范围
const options: distributedKVStore.Options = {
  // S1: 低安全级别，可同步到所有已认证设备
  // S2: 中安全级别，需要设备安全等级 >= SL2
  // S3: 高安全级别，仅同步到高安全设备
  // S4: 最高安全级别，不参与分布式同步
  securityLevel: distributedKVStore.SecurityLevel.S2,
};

小结
HarmonyOS 分布式数据管理通过 KV Store、分布式 RDB、分布式对象和分布式文件四种方案，覆盖了从简单配置到复杂结构化数据的全场景同步需求。选择方案时需权衡数据模型复杂度、同步实时性和一致性要求。分布式开发的关键心智模型是"数据写入即同步"——应用代码无需关心网络传输细节，只需选择正确的一致性策略。
