进程间通信与 IPC 机制

概述

HarmonyOS 应用运行在沙箱环境中，不同应用甚至同一应用的不同模块可能运行在不同进程中。进程间通信（IPC）是实现组件协作、服务调用和数据共享的关键基础设施。HarmonyOS 提供了多种 IPC 机制，从轻量级的公共事件到重量级的远程过程调用，覆盖不同通信场景的需求。

公共事件服务
公共事件（CommonEvent）是 HarmonyOS 中最常用的松耦合通信方式，类似 Android 的广播机制但设计更加规范。

事件订阅与发布
import { commonEventManager } from '@kit.BasicServicesKit';

// 订阅网络状态变化
const subscriber = await commonEventManager.createSubscriber({
  events: [
    commonEventManager.Support.COMMON_EVENT_CONNECTIVITY_CHANGE,
    'com.example.myapp.DATA_UPDATED', // 自定义事件
  ],
});

commonEventManager.subscribe(subscriber, (err, eventData) => {
  if (err) {
    console.error(`订阅失败: ${err.message}`);
    return;
  }

  switch (eventData.event) {
    case commonEventManager.Support.COMMON_EVENT_CONNECTIVITY_CHANGE:
      const isConnected = eventData.parameters?.isConnected as boolean;
      console.info(`网络状态: ${isConnected ? '已连接' : '已断开'}`);
      break;
    case 'com.example.myapp.DATA_UPDATED':
      const payload = eventData.parameters?.data as string;
      console.info(`收到数据更新: ${payload}`);
      break;
  }
});

// 发布自定义事件
const eventInfo: commonEventManager.CommonEventPublishData = {
  code: 200,
  data: 'refresh',
  parameters: {
    timestamp: Date.now(),
    source: 'background_sync',
  },
};
commonEventManager.publish('com.example.myapp.DATA_UPDATED', eventInfo);
Emitter 进程内事件总线
Emitter 是轻量级的进程内事件通信机制，适用于同一进程内不同线程或组件间的解耦通信：


import { emitter } from '@kit.BasicServicesKit';

// 定义事件 ID
const EVENT_LOGIN_SUCCESS = { eventId: 1001 };
const EVENT_CART_UPDATED = { eventId: 1002 };

// 订阅事件
emitter.on(EVENT_LOGIN_SUCCESS, (eventData: emitter.EventData) => {
  const userId = eventData.data?.userId as string;
  console.info(`用户登录成功: ${userId}`);
  // 触发 UI 刷新
});

// 发送事件
emitter.emit(EVENT_LOGIN_SUCCESS, {
  data: {
    userId: 'user_12345',
    loginTime: Date.now(),
  },
});

// 单次监听
emitter.once(EVENT_CART_UPDATED, (eventData: emitter.EventData) => {
  console.info('购物车已更新（仅触发一次）');
});

// 取消订阅
emitter.off(EVENT_LOGIN_SUCCESS.eventId);
DataShare 跨进程数据共享
DataShare 为不同应用之间提供数据共享能力，遵循提供方-消费方（Provider-Consumer）模式。


数据提供方实现
import { DataShareExtensionAbility, dataShare, rdb } from '@kit.ArkData';

export default class ContactsProvider extends DataShareExtensionAbility {
  private rdbStore: rdb.RdbStore | null = null;

  async onCreate(want: Want, callback: Function): Promise<void> {
    // 初始化数据库
    const config: rdb.StoreConfig = {
      name: 'contacts.db',
      securityLevel: rdb.SecurityLevel.S1,
    };
    this.rdbStore = await rdb.getRdbStore(this.context, config);
    callback();
  }

  async query(
    uri: string,
    predicates: dataShare.DataSharePredicates,
    columns: string[],
    callback: Function,
  ): Promise<void> {
    if (!this.rdbStore) {
      callback(null, null);
      return;
    }

    const rdbPredicates = new rdb.RdbPredicates('contacts');
    const resultSet = await this.rdbStore.query(rdbPredicates, columns);
    callback(null, resultSet);
  }

  async insert(uri: string, valueBucket: dataShare.ValuesBucket, callback: Function): Promise<void> {
    if (!this.rdbStore) {
      callback(null, -1);
      return;
    }

    const rowId = await this.rdbStore.insert('contacts', valueBucket);
    // 通知数据变更
    this.context.notifyChange(uri);
    callback(null, rowId);
  }
}
数据消费方使用
import { dataShare, dataSharePredicates } from '@kit.ArkData';

async function queryContacts(): Promise<void> {
  const uri = 'datashare:///com.example.contacts/contacts';
  const helper = dataShare.createDataShareHelper(getContext(), uri);

  const predicates = new dataSharePredicates.DataSharePredicates();
  predicates.equalTo('city', '北京');

  const resultSet = await helper.query(uri, predicates, ['name', 'phone', 'city']);

  while (resultSet.goToNextRow()) {
    const name = resultSet.getString(resultSet.getColumnIndex('name'));
    const phone = resultSet.getString(resultSet.getColumnIndex('phone'));
    console.info(`联系人: ${name}, 电话: ${phone}`);
  }
  resultSet.close();
}

Want 参数传递
Want 是 HarmonyOS 组件间通信的标准参数容器，携带启动目标和数据：


import { common, Want } from '@kit.AbilityKit';

// 显式启动：指定目标 Ability
const explicitWant: Want = {
  bundleName: 'com.example.target',
  abilityName: 'DetailAbility',
  parameters: {
    articleId: 'art_001',
    source: 'push_notification',
  },
};
const context = getContext(this) as common.UIAbilityContext;
context.startAbility(explicitWant);

// 隐式启动：通过 action 和 entity 匹配
const implicitWant: Want = {
  action: 'ohos.want.action.viewData',
  entities: ['entity.system.default'],
  uri: 'https://example.com/article/123',
  type: 'text/html',
};
context.startAbility(implicitWant);
小结
HarmonyOS IPC 体系提供了从松耦合到紧耦合的多种通信手段：Emitter 适用于进程内解耦、CommonEvent 适用于应用间广播、DataShare 适用于结构化数据共享、RPC 适用于实时服务调用。选择合适的 IPC 机制需要权衡通信频率、数据量、实时性和耦合度等因素。
