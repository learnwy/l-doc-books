Stage 模型与 Ability 生命周期

概述

Stage 模型是 HarmonyOS NEXT 统一的应用架构模型，替代了早期的 FA（Feature Ability）模型。Stage 模型以 AbilityStage 为应用进程的入口容器，将应用功能划分为 UIAbility（前台交互）和 ExtensionAbility（后台服务）两大类别。这种设计清晰地分离了 UI 逻辑与后台能力，使得系统能够更精细地管理应用资源和生命周期。

AbilityStage 角色
AbilityStage 是 HAP 级别的运行时容器。每个 HAP 在被加载时都会先创建对应的 AbilityStage 实例，然后再启动其中的 Ability。它的核心职责包括：

export default class MyAbilityStage extends AbilityStage {
  onCreate(): void {
    // HAP 首次加载时调用，全局初始化
    console.info('AbilityStage onCreate');
    this.initializeSDKs();
    this.setupGlobalConfig();
  }

  onAcceptWant(want: Want): string {
    // 指定 UIAbility 的启动模式为 specified 时
    // 根据 want 参数决定创建新实例还是复用已有实例
    if (want.parameters?.instanceKey) {
      return want.parameters.instanceKey as string;
    }
    return 'default';
  }

  onConfigurationUpdate(newConfig: Configuration): void {
    // 全局配置变更（语言、深浅色等）
    console.info(`配置变更: ${JSON.stringify(newConfig)}`);
  }

  private initializeSDKs(): void {
    // 初始化第三方 SDK
  }

  private setupGlobalConfig(): void {
    // 读取全局配置
  }
}
UIAbility 生命周期详解
UIAbility 是带有 UI 界面的应用组件，负责与用户交互。它的生命周期由系统管理，开发者通过回调方法响应各阶段事件。

export default class MainAbility extends UIAbility {
  onCreate(want: Want, launchParam: AbilityConstant.LaunchParam): void {
    console.info('MainAbility onCreate');
    // 解析 deeplink 或推送参数
    const targetPage = want.parameters?.targetPage as string;
    AppStorage.setOrCreate('launchTarget', targetPage || 'home');
  }

  onWindowStageCreate(windowStage: window.WindowStage): void {
    // 加载首页内容
    windowStage.loadContent('pages/Index', (err) => {
      if (err.code) {
        console.error(`加载页面失败: ${err.message}`);
        return;
      }
      console.info('首页加载成功');
    });

    // 设置窗口属性
    windowStage.getMainWindow().then((mainWindow) => {
      mainWindow.setWindowLayoutFullScreen(true);
      mainWindow.setWindowSystemBarProperties({
        statusBarContentColor: '#000000',
      });
    });
  }

  onForeground(): void {
    console.info('应用切到前台');
    // 刷新数据、恢复定时器
  }

  onBackground(): void {
    console.info('应用切到后台');
    // 暂停非必要计算
  }

  onNewWant(want: Want, launchParam: AbilityConstant.LaunchParam): void {
    // 单例模式下，已有实例被再次唤起
    const newTarget = want.parameters?.targetPage as string;
    if (newTarget) {
      AppStorage.set('launchTarget', newTarget);
    }
  }
}

ExtensionAbility 扩展能力
ExtensionAbility 为应用提供后台运行能力，系统严格限制其运行时长和资源消耗：


FormExtension 卡片开发
import { FormExtensionAbility, formProvider } from '@kit.FormKit';

export default class WeatherFormAbility extends FormExtensionAbility {
  onAddForm(want: Want): formBindingData.FormBindingData {
    // 卡片被添加到桌面
    const formData: Record<string, string> = {
      temperature: '23°C',
      weather: '晴',
      city: '北京',
    };
    return formBindingData.createFormBindingData(formData);
  }

  onUpdateForm(formId: string): void {
    // 定时刷新卡片数据
    const newData: Record<string, string> = {
      temperature: '25°C',
      weather: '多云',
    };
    const bindingData = formBindingData.createFormBindingData(newData);
    formProvider.updateForm(formId, bindingData);
  }

  onRemoveForm(formId: string): void {
    // 卡片被移除，清理关联资源
    console.info(`卡片 ${formId} 已移除`);
  }
}
窗口管理
Stage 模型的窗口管理基于 WindowStage，支持全屏、分屏、悬浮窗等多种形态：


export default class WindowManageAbility extends UIAbility {
  onWindowStageCreate(windowStage: window.WindowStage): void {
    const mainWindow = windowStage.getMainWindowSync();

    // 设置窗口模式
    mainWindow.setWindowMode(window.WindowMode.FULLSCREEN);

    // 监听窗口尺寸变化（适配分屏/折叠屏）
    mainWindow.on('windowSizeChange', (size: window.Size) => {
      console.info(`窗口尺寸变化: ${size.width} x ${size.height}`);
      AppStorage.setOrCreate('windowWidth', size.width);
      AppStorage.setOrCreate('windowHeight', size.height);
    });

    // 监听规避区域变化（状态栏、导航栏）
    mainWindow.on('avoidAreaChange', (data) => {
      if (data.type === window.AvoidAreaType.TYPE_SYSTEM) {
        const topHeight = data.area.topRect.height;
        AppStorage.setOrCreate('statusBarHeight', topHeight);
      }
    });

    windowStage.loadContent('pages/Index');
  }
}
