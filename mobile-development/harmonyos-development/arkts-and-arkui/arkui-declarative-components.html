ArkUI 声明式组件开发

概述

ArkUI 是 HarmonyOS NEXT 的原生 UI 框架，采用声明式编程范式构建用户界面。与传统命令式 UI 框架（如 Android View 体系）不同，ArkUI 让开发者描述"UI 应该是什么样"而非"如何构建 UI"，框架自动处理视图的创建、更新和销毁。这种模式与 SwiftUI、Jetpack Compose 属于同一代 UI 范式，但在组件 API 设计和链式调用风格上有独特之处。

组件体系架构
ArkUI 的组件分为系统组件和自定义组件两大类。系统组件由框架提供，覆盖了常见的 UI 元素；自定义组件由开发者通过 @Component 装饰器定义。

组件声明语法
ArkUI 组件使用函数调用风格声明，通过链式 API 设置属性和事件：


@Entry
@Component
struct ProductCard {
  @State product: ProductInfo = new ProductInfo('ArkUI 实战指南', 99.0, 4.8)

  build() {
    Column() {
      // 图片组件 —— 链式设置属性
      Image(this.product.coverUrl)
        .width('100%')
        .height(200)
        .objectFit(ImageFit.Cover)
        .borderRadius({ topLeft: 12, topRight: 12 })

      // 信息区域
      Column() {
        Text(this.product.title)
          .fontSize(16)
          .fontWeight(FontWeight.Medium)
          .maxLines(2)
          .textOverflow({ overflow: TextOverflow.Ellipsis })

        Row() {
          Text(`¥${this.product.price}`)
            .fontSize(20)
            .fontColor('#FF4444')
            .fontWeight(FontWeight.Bold)

          Text(`${this.product.rating}分`)
            .fontSize(12)
            .fontColor('#999999')
        }
        .width('100%')
        .justifyContent(FlexAlign.SpaceBetween)
      }
      .padding(12)
      .alignItems(HorizontalAlign.Start)
    }
    .width('100%')
    .backgroundColor(Color.White)
    .borderRadius(12)
    .shadow({ radius: 8, color: '#1A000000', offsetY: 2 })
  }
}

响应式布局实践
@Component
struct ResponsiveLayout {
  @StorageProp('currentBreakpoint') currentBp: string = 'sm'

  build() {
    GridRow({
      columns: { sm: 4, md: 8, lg: 12 },
      gutter: { x: 12, y: 12 }
    }) {
      GridCol({ span: { sm: 4, md: 4, lg: 3 } }) {
        this.NavigationPanel()
      }

      GridCol({ span: { sm: 4, md: 4, lg: 9 } }) {
        this.ContentPanel()
      }
    }
    .padding({ left: 16, right: 16 })
  }

  @Builder
  NavigationPanel() {
    Column() {
      Text('导航面板').fontSize(18)
    }
    .width('100%')
    .backgroundColor('#F0F0F0')
  }

  @Builder
  ContentPanel() {
    Column() {
      Text('内容区域').fontSize(18)
    }
    .width('100%')
  }
}
自定义组件开发
自定义组件是 ArkUI 应用开发的核心能力。通过 @Component 装饰器将 struct 标记为组件，其 build() 方法定义 UI 结构。


组件通信模式
组件生命周期
@Component
struct LifecycleDemo {
  @State counter: number = 0

  // 组件即将出现时调用
  aboutToAppear(): void {
    console.info('组件即将挂载，可执行数据初始化')
    this.loadData()
  }

  // 组件即将销毁时调用
  aboutToDisappear(): void {
    console.info('组件即将卸载，可执行清理工作')
    this.cancelSubscriptions()
  }

  // 页面显示时调用（仅 @Entry 组件）
  onPageShow(): void {
    console.info('页面从后台切换到前台')
  }

  // 页面隐藏时调用（仅 @Entry 组件）
  onPageHide(): void {
    console.info('页面从前台切换到后台')
  }

  build() {
    Column() {
      Text(`计数: ${this.counter}`)
      Button('增加').onClick(() => this.counter++)
    }
  }

  private loadData(): void {
    // 数据加载逻辑
  }

  private cancelSubscriptions(): void {
    // 清理订阅
  }
}
高级组件模式
Builder 与 BuilderParam
@Builder 创建轻量级的可复用 UI 片段，@BuilderParam 实现组件的内容投影（类似 React 的 children 或 Vue 的 slot）：


@Component
struct CardContainer {
  @BuilderParam header: () => void = this.defaultHeader
  @BuilderParam content: () => void = this.defaultContent
  @Prop title: string = ''

  @Builder
  defaultHeader() {
    Text(this.title).fontSize(16).fontWeight(FontWeight.Bold)
  }

  @Builder
  defaultContent() {
    Text('默认内容').fontColor('#999999')
  }

  build() {
    Column() {
      // 头部插槽
      Row() {
        this.header()
      }
      .width('100%')
      .padding({ top: 12, bottom: 8 })

      Divider().strokeWidth(0.5).color('#E0E0E0')

      // 内容插槽
      Column() {
        this.content()
      }
      .width('100%')
      .padding(12)
    }
    .width('100%')
    .borderRadius(8)
    .backgroundColor(Color.White)
  }
}

// 使用自定义插槽
@Entry
@Component
struct UsageExample {
  build() {
    CardContainer({ title: '订单信息' }) {
      // 自定义 content 内容
      Row() {
        Text('订单号: ').fontColor('#666666')
        Text('2024010001').fontWeight(FontWeight.Medium)
      }
    }
  }
}
@Styles 与 @Extend 样式复用
// @Styles：定义可复用的通用属性组合
@Styles
function cardStyle() {
  .backgroundColor(Color.White)
  .borderRadius(12)
  .padding(16)
  .shadow({ radius: 4, color: '#0D000000', offsetY: 2 })
}

// @Extend：为特定组件扩展方法
@Extend(Text)
function titleText(size: number) {
  .fontSize(size)
  .fontWeight(FontWeight.Bold)
  .fontColor('#333333')
}

@Extend(Text)
function subtitleText() {
  .fontSize(14)
  .fontColor('#999999')
  .margin({ top: 4 })
}

@Entry
@Component
struct AnimationDemo {
  @State isExpanded: boolean = false
  @State cardHeight: number = 100

  build() {
    Column() {
      Column() {
        Text('点击展开/收起')
        if (this.isExpanded) {
          Text('展开的详细内容...')
            .transition({ type: TransitionType.Insert, opacity: 0 })
        }
      }
      .height(this.cardHeight)
      .animation({ duration: 300, curve: Curve.EaseInOut })
      .onClick(() => {
        this.isExpanded = !this.isExpanded
        this.cardHeight = this.isExpanded ? 250 : 100
      })
    }
  }
}
小结
ArkUI 声明式组件开发的核心要点是：通过组件组合构建界面、通过链式 API 配置属性、通过 Builder 和 BuilderParam 实现复用与插槽、通过响应式布局适配多端。掌握这些模式后，下一节将深入状态管理机制，理解数据如何驱动 UI 更新。
