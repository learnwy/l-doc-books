Lynx 样式

核心概念

Lynx 的样式系统基于 CSS 子集实现，以 Flexbox 布局为核心，支持常用的 CSS 属性、动画系统、主题切换和响应式设计。与 Web CSS 的最大区别在于：Lynx 默认所有元素都是 display: flex，不支持浮动（float）和定位（position: relative/absolute）的传统 Web 布局模式。理解 Lynx 样式系统的能力边界和最佳实践，是构建高质量跨平台 UI 的基础。

主题切换
import { createContext, useContext, useState, useCallback } from '@lynx-js/react';

type Theme = 'light' | 'dark';

const ThemeContext = createContext<{
  theme: Theme;
  colors: ThemeColors;
  toggle: () => void;
}>({
  theme: 'light',
  colors: lightColors,
  toggle: () => {},
});

const lightColors = {
  background: '#ffffff',
  surface: '#f5f5f5',
  text: '#1a1a1a',
  textSecondary: '#666666',
  primary: '#1890ff',
  border: '#e5e5e5',
  card: '#ffffff',
};

const darkColors = {
  background: '#1a1a1a',
  surface: '#2d2d2d',
  text: '#ffffff',
  textSecondary: '#a0a0a0',
  primary: '#40a9ff',
  border: '#404040',
  card: '#2d2d2d',
};

type ThemeColors = typeof lightColors;

function ThemeProvider({ children }: { children: any }) {
  const [theme, setTheme] = useState<Theme>('light');

  const toggle = useCallback(() => {
    setTheme((prev) => (prev === 'light' ? 'dark' : 'light'));
  }, []);

  const colors = theme === 'light' ? lightColors : darkColors;

  return (
    <ThemeContext.Provider value={{ theme, colors, toggle }}>
      <view style={{ backgroundColor: colors.background, flex: 1 }}>{children}</view>
    </ThemeContext.Provider>
  );
}

function ThemedCard({ title, content }: { title: string; content: string }) {
  const { colors } = useContext(ThemeContext);

  return (
    <view
      style={{
        backgroundColor: colors.card,
        borderRadius: 12,
        padding: 16,
        borderWidth: 1,
        borderColor: colors.border,
      }}
    >
      <text style={{ color: colors.text, fontSize: 16, fontWeight: '600' }}>{title}</text>
      <text style={{ color: colors.textSecondary, fontSize: 14, marginTop: 8 }}>{content}</text>
    </view>
  );
}
响应式设计
Lynx 中的响应式设计需要通过 JS 逻辑获取屏幕尺寸，然后动态调整样式。


import { useState, useEffect, useMemo } from '@lynx-js/react';

type ScreenSize = 'small' | 'medium' | 'large';

function useScreenSize(): ScreenSize {
  const [width, setWidth] = useState(375);

  useEffect(() => {
    const info = lynx.getSystemInfoSync();
    setWidth(info.screenWidth);
  }, []);

  if (width < 375) return 'small';
  if (width < 768) return 'medium';
  return 'large';
}

function ResponsiveGrid({ items }: { items: GridItem[] }) {
  const screenSize = useScreenSize();

  const columns = useMemo(() => {
    switch (screenSize) {
      case 'small':
        return 2;
      case 'medium':
        return 3;
      case 'large':
        return 4;
    }
  }, [screenSize]);

  const itemWidth = `${100 / columns}%`;

  return (
    <view className="responsive-grid">
      {items.map((item) => (
        <view key={item.id} style={{ width: itemWidth, padding: 4 }}>
          <view className="grid-item">
            <image src={item.image} className="grid-image" mode="aspectFill" />
            <text className="grid-title">{item.title}</text>
          </view>
        </view>
      ))}
    </view>
  );
}

}

}

小结
Lynx 样式系统以 CSS 子集 + Flexbox 为核心，在保持 Web 开发者熟悉度的同时，针对移动端做了合理取舍。动画系统在原生线程执行保证了流畅度，主题系统通过 Context + 动态 style 实现，响应式设计依赖 JS 屏幕尺寸检测。掌握 Flex 布局的各种模式和动画性能优化策略是写出高质量 Lynx UI 的关键。


核心要点回顾：


    

  • Lynx 默认所有元素 display: flex，布局引擎基于 Yoga
    • 

  • 支持 CSS 属性子集，不支持 float、grid、table 等传统 Web 布局
    • 

  • Transition 和 Keyframe Animation 在原生线程执行，不受 JS 阻塞
    • 

  • 只动画 transform 和 opacity 以保证性能（GPU 加速属性）
    • 

  • 主题切换通过 Context + 动态 style 实现，支持 light/dark 模式
    • 

  • 响应式设计需要通过 JS 获取屏幕尺寸动态调整布局
