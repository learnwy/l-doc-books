平台抽象层

核心概念

平台抽象层（Platform Abstraction Layer, PAL）是跨平台工程中的关键设计模式。它通过定义统一的接口，将平台相关的实现细节封装在各自的适配层中，使得业务代码可以在不同平台上复用而无需修改。一个设计良好的平台抽象层不仅能隔离平台差异，还能提供优雅的降级策略、运行时能力检测和条件编译支持。

抽象层架构

接口定义策略
抽象层设计的第一步是定义平台无关的接口契约。接口应当足够通用以覆盖所有目标平台，同时足够具体以满足业务需求。


存储抽象
interface StorageAdapter {
  getItem(key: string): Promise<string | null>;
  setItem(key: string, value: string): Promise<void>;
  removeItem(key: string): Promise<void>;
  getAllKeys(): Promise<string[]>;
  multiGet(keys: string[]): Promise<[string, string | null][]>;
  multiSet(entries: [string, string][]): Promise<void>;
  clear(): Promise<void>;
}

class WebStorage implements StorageAdapter {
  async getItem(key: string): Promise<string | null> {
    return localStorage.getItem(key);
  }

  async setItem(key: string, value: string): Promise<void> {
    localStorage.setItem(key, value);
  }

  async removeItem(key: string): Promise<void> {
    localStorage.removeItem(key);
  }

  async getAllKeys(): Promise<string[]> {
    return Object.keys(localStorage);
  }

  async multiGet(keys: string[]): Promise<[string, string | null][]> {
    return keys.map((key) => [key, localStorage.getItem(key)]);
  }

  async multiSet(entries: [string, string][]): Promise<void> {
    entries.forEach(([key, value]) => localStorage.setItem(key, value));
  }

  async clear(): Promise<void> {
    localStorage.clear();
  }
}
import AsyncStorage from '@react-native-async-storage/async-storage';

class NativeStorage implements StorageAdapter {
  async getItem(key: string): Promise<string | null> {
    return AsyncStorage.getItem(key);
  }

  async setItem(key: string, value: string): Promise<void> {
    await AsyncStorage.setItem(key, value);
  }

  async removeItem(key: string): Promise<void> {
    await AsyncStorage.removeItem(key);
  }

  async getAllKeys(): Promise<string[]> {
    const keys = await AsyncStorage.getAllKeys();
    return [...keys];
  }

  async multiGet(keys: string[]): Promise<[string, string | null][]> {
    const pairs = await AsyncStorage.multiGet(keys);
    return pairs as [string, string | null][];
  }

  async multiSet(entries: [string, string][]): Promise<void> {
    await AsyncStorage.multiSet(entries);
  }

  async clear(): Promise<void> {
    await AsyncStorage.clear();
  }
}
网络抽象
interface HttpClient {
  get<T>(url: string, config?: RequestConfig): Promise<Response<T>>;
  post<T>(url: string, data?: unknown, config?: RequestConfig): Promise<Response<T>>;
  put<T>(url: string, data?: unknown, config?: RequestConfig): Promise<Response<T>>;
  delete<T>(url: string, config?: RequestConfig): Promise<Response<T>>;
}

interface RequestConfig {
  headers?: Record<string, string>;
  timeout?: number;
  signal?: AbortSignal;
  onProgress?: (progress: number) => void;
}

interface Response<T> {
  data: T;
  status: number;
  headers: Record<string, string>;
}

class FetchHttpClient implements HttpClient {
  private baseURL: string;
  private defaultHeaders: Record<string, string>;

  constructor(config: { baseURL: string; headers?: Record<string, string> }) {
    this.baseURL = config.baseURL;
    this.defaultHeaders = {
      'Content-Type': 'application/json',
      ...config.headers,
    };
  }

  async get<T>(url: string, config?: RequestConfig): Promise<Response<T>> {
    return this.request<T>('GET', url, undefined, config);
  }

  async post<T>(url: string, data?: unknown, config?: RequestConfig): Promise<Response<T>> {
    return this.request<T>('POST', url, data, config);
  }

  async put<T>(url: string, data?: unknown, config?: RequestConfig): Promise<Response<T>> {
    return this.request<T>('PUT', url, data, config);
  }

  async delete<T>(url: string, config?: RequestConfig): Promise<Response<T>> {
    return this.request<T>('DELETE', url, undefined, config);
  }

  private async request<T>(method: string, url: string, data?: unknown, config?: RequestConfig): Promise<Response<T>> {
    const controller = new AbortController();
    const timeoutId = config?.timeout ? setTimeout(() => controller.abort(), config.timeout) : null;

    const response = await fetch(`${this.baseURL}${url}`, {
      method,
      headers: { ...this.defaultHeaders, ...config?.headers },
      body: data ? JSON.stringify(data) : undefined,
      signal: config?.signal || controller.signal,
    });

    if (timeoutId) clearTimeout(timeoutId);

    const responseData = await response.json();
    const headers: Record<string, string> = {};
    response.headers.forEach((value, key) => {
      headers[key] = value;
    });

    return { data: responseData as T, status: response.status, headers };
  }
}
平台检测
运行时平台检测是实现条件逻辑的基础。一个完善的平台检测模块需要覆盖操作系统类型、运行环境、设备能力等多个维度。


interface PlatformInfo {
  os: 'ios' | 'android' | 'web' | 'windows' | 'macos' | 'linux';
  runtime: 'browser' | 'react-native' | 'electron' | 'tauri' | 'node';
  version: string;
  isTouch: boolean;
  screenSize: { width: number; height: number };
  pixelRatio: number;
  locale: string;
  isDarkMode: boolean;
}

function detectPlatform(): PlatformInfo {
  if (typeof navigator === 'undefined') {
    return {
      os: detectServerOS(),
      runtime: 'node',
      version: process.version,
      isTouch: false,
      screenSize: { width: 0, height: 0 },
      pixelRatio: 1,
      locale: process.env.LANG || 'en-US',
      isDarkMode: false,
    };
  }

  const ua = navigator.userAgent;
  const os = detectOS(ua);
  const runtime = detectRuntime();

  return {
    os,
    runtime,
    version: detectVersion(ua, os),
    isTouch: 'ontouchstart' in window || navigator.maxTouchPoints > 0,
    screenSize: { width: window.innerWidth, height: window.innerHeight },
    pixelRatio: window.devicePixelRatio || 1,
    locale: navigator.language,
    isDarkMode: window.matchMedia('(prefers-color-scheme: dark)').matches,
  };
}

function detectOS(ua: string): PlatformInfo['os'] {
  if (/iPad|iPhone|iPod/.test(ua)) return 'ios';
  if (/Android/.test(ua)) return 'android';
  if (/Windows/.test(ua)) return 'windows';
  if (/Mac/.test(ua)) return 'macos';
  if (/Linux/.test(ua)) return 'linux';
  return 'web';
}

function detectRuntime(): PlatformInfo['runtime'] {
  if (typeof (globalThis as any).__TAURI__ !== 'undefined') return 'tauri';
  if (typeof (globalThis as any).process?.versions?.electron !== 'undefined') return 'electron';
  if (typeof (globalThis as any).navigator?.product === 'ReactNative') return 'react-native';
  return 'browser';
}

function detectVersion(ua: string, os: PlatformInfo['os']): string {
  const patterns: Record<string, RegExp> = {
    ios: /OS (\d+[._]\d+)/,
    android: /Android (\d+\.?\d*)/,
    windows: /Windows NT (\d+\.\d+)/,
    macos: /Mac OS X (\d+[._]\d+)/,
  };

  const pattern = patterns[os];
  if (!pattern) return 'unknown';

  const match = ua.match(pattern);
  return match ? match[1].replace(/_/g, '.') : 'unknown';
}

import type { StorageAdapter } from './storage';
import { WebStorage } from './storage.web';
import { NativeStorage } from './storage.native';
import { Platform } from 'react-native';

const adapters: Record<string, () => StorageAdapter> = {
  web: () => new WebStorage(),
  ios: () => new NativeStorage(),
  android: () => new NativeStorage(),
};

let instance: StorageAdapter | null = null;

export function getStorage(): StorageAdapter {
  if (!instance) {
    const factory = adapters[Platform.OS] || adapters.web;
    instance = factory();
  }
  return instance;
}
能力检测与降级
interface Capability {
  name: string;
  check: () => boolean | Promise<boolean>;
  fallback?: () => void;
}

class CapabilityManager {
  private capabilities = new Map<string, boolean>();

  async detect(caps: Capability[]): Promise<Map<string, boolean>> {
    const results = await Promise.allSettled(
      caps.map(async (cap) => ({
        name: cap.name,
        available: await cap.check(),
      })),
    );

    results.forEach((result) => {
      if (result.status === 'fulfilled') {
        this.capabilities.set(result.value.name, result.value.available);
      } else {
        this.capabilities.set('unknown', false);
      }
    });

    return this.capabilities;
  }

  isAvailable(name: string): boolean {
    return this.capabilities.get(name) ?? false;
  }

  async withFallback<T>(name: string, primary: () => Promise<T>, fallback: () => Promise<T>): Promise<T> {
    if (this.isAvailable(name)) {
      try {
        return await primary();
      } catch {
        return fallback();
      }
    }
    return fallback();
  }
}

const capabilities: Capability[] = [

分层降级实现
type GradualStrategy<T> = {
  primary: () => Promise<T>;
  secondary?: () => Promise<T>;
  tertiary?: () => Promise<T>;
  fallback: () => T;
};

async function executeWithGradualFallback<T>(strategy: GradualStrategy<T>): Promise<T> {
  const attempts = [strategy.primary, strategy.secondary, strategy.tertiary].filter(Boolean) as (() => Promise<T>)[];

  for (const attempt of attempts) {
    try {
      return await attempt();
    } catch {
      continue;
    }
  }

  return strategy.fallback();
}

const locationStrategy: GradualStrategy<{ lat: number; lng: number }> = {
  primary: async () => {
    const pos = await new Promise<GeolocationPosition>((resolve, reject) => {
      navigator.geolocation.getCurrentPosition(resolve, reject, {
        enableHighAccuracy: true,
        timeout: 5000,
      });
    });
    return { lat: pos.coords.latitude, lng: pos.coords.longitude };
  },

  secondary: async () => {
    const res = await fetch('https://ipapi.co/json/');
    const data = await res.json();
    return { lat: data.latitude, lng: data.longitude };
  },

  fallback: () => ({ lat: 39.9042, lng: 116.4074 }),
};
依赖注入容器
大型跨平台项目通常使用依赖注入容器来管理平台实现的注册和获取。


type Constructor<T> = new (...args: any[]) => T;
type Factory<T> = () => T;

class DIContainer {
  private singletons = new Map<string, unknown>();
  private factories = new Map<string, Factory<unknown>>();

  registerSingleton<T>(token: string, instance: T): void {
    this.singletons.set(token, instance);
  }

  registerFactory<T>(token: string, factory: Factory<T>): void {
    this.factories.set(token, factory);
  }

  resolve<T>(token: string): T {
    if (this.singletons.has(token)) {
      return this.singletons.get(token) as T;
    }

    const factory = this.factories.get(token);
    if (factory) {
      const instance = factory() as T;
      this.singletons.set(token, instance);
      return instance;
    }

    throw new Error(`No registration found for token: ${token}`);
  }
}

const container = new DIContainer();

function registerPlatformServices(platform: PlatformInfo) {
  switch (platform.runtime) {
    case 'browser':
      container.registerFactory('storage', () => new WebStorage());
      container.registerFactory('http', () => new FetchHttpClient({ baseURL: '/api' }));
      break;
    case 'react-native':
      container.registerFactory('storage', () => new NativeStorage());
      container.registerFactory('http', () => new FetchHttpClient({ baseURL: 'https://api.example.com' }));
      break;
    case 'electron':
      container.registerFactory('storage', () => new ElectronStorage());
      container.registerFactory('http', () => new FetchHttpClient({ baseURL: 'https://api.example.com' }));
      break;
  }
}

原则
正确做法
错误做法





最小接口
只抽象 Storage/Network/Device 等确实不同的部分
把所有 API 都包一层抽象




显式差异
Platform.select() 明确标注平台分支

渐进提取
先在 2 个平台上发现共性，再提取接口

单向依赖
业务层 → 抽象层 → 平台实现层
平台实现层反向依赖业务逻辑




可替换性
各平台实现可独立替换和升级
平台实现之间存在耦合





小结
平台抽象层是跨平台工程化的基础设施。一个设计良好的抽象层能够让 80% 以上的业务代码在各平台间无缝复用，同时保留对平台特性的精细控制。关键在于把握抽象的粒度——过度抽象增加复杂度，抽象不足则无法复用。


核心要点回顾：


    

  • 平台抽象层通过定义统一接口隔离平台差异，使业务代码可跨平台复用
    • 

  • 接口设计应遵循最小化原则，只抽象真正存在平台差异的能力
    • 

  • 运行时平台检测需覆盖 OS 类型、运行环境、设备能力等多维度
    • 

  • 条件编译机制因框架而异：RN 用文件扩展名，Flutter 用条件导入，KMP 用 expect/actual
    • 

  • 降级策略应分层设计：原生能力 → Polyfill → 替代方案 → UI 降级 → 静默跳过
    • 

  • 依赖注入容器是大型项目管理平台实现的最佳实践
