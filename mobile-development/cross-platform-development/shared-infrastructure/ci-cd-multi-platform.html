多平台 CI/CD 流水线

核心概念

跨平台应用的 CI/CD 面临独特挑战：需要在不同操作系统上构建、测试和签名，管理多套证书和密钥，协调多平台发布节奏。一套完善的多平台 CI/CD 流水线应包含矩阵构建、平台特定签名、自动化测试、产物分发和版本管理。本文以 GitHub Actions 为主线，深入讲解多平台构建矩阵、iOS/Android/Desktop 签名流程、自动化测试策略和发布分发方案。

流水线架构

flowchart TB
    PUSH[代码推送 / PR] --> LINT[Lint + Typecheck]
    LINT --> TEST[单元测试]
    TEST --> MATRIX{矩阵构建}

    MATRIX --> WEB[Web 构建]
    MATRIX --> IOS[iOS 构建]
    MATRIX --> ANDROID[Android 构建]
    MATRIX --> MAC[macOS Desktop]
    MATRIX --> WIN[Windows Desktop]
    MATRIX --> LINUX[Linux Desktop]

    WEB --> DEPLOY_WEB[部署 CDN]
    IOS --> SIGN_IOS[Apple 签名 + 公证]
    ANDROID --> SIGN_AND[Android 签名]
    MAC --> SIGN_MAC[macOS 签名 + 公证]
    WIN --> SIGN_WIN[Windows 签名]
    LINUX --> PKG_LINUX[打包 AppImage/deb]

    SIGN_IOS --> TESTFLIGHT[TestFlight]
    SIGN_AND --> PLAY[Google Play]
    DEPLOY_WEB --> CDN[Vercel / CloudFlare]
    SIGN_MAC --> GITHUB_REL[GitHub Releases]
    SIGN_WIN --> GITHUB_REL
    PKG_LINUX --> GITHUB_REL

矩阵构建策略

基础矩阵配置

name: Cross-Platform CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  lint-and-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with:
          version: 9
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: 'pnpm'

      - run: pnpm install --frozen-lockfile
      - run: pnpm -r typecheck
      - run: pnpm -r lint
      - run: pnpm -r test -- --reporter=junit --outputFile=test-results.xml

      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: test-results
          path: '**/test-results.xml'

  build-web:
    needs: lint-and-test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with:
          version: 9
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: 'pnpm'

      - run: pnpm install --frozen-lockfile
      - run: pnpm --filter @myapp/app-web build
        env:
          VITE_API_URL: ${{ vars.API_URL }}
          VITE_APP_VERSION: ${{ github.sha }}

      - uses: actions/upload-artifact@v4
        with:
          name: web-dist
          path: packages/app-web/dist/
          retention-days: 7

桌面应用矩阵构建

build-desktop:
  needs: lint-and-test
  strategy:
    fail-fast: false
    matrix:
      include:
        - os: macos-14
          platform: darwin
          arch: arm64
          target: dmg
        - os: macos-13
          platform: darwin
          arch: x64
          target: dmg
        - os: windows-latest
          platform: win32
          arch: x64
          target: nsis
        - os: ubuntu-latest
          platform: linux
          arch: x64
          target: AppImage

  runs-on: ${{ matrix.os }}
  steps:
    - uses: actions/checkout@v4
    - uses: pnpm/action-setup@v4
      with:
        version: 9
    - uses: actions/setup-node@v4
      with:
        node-version: 22
        cache: 'pnpm'

    - name: Install Linux dependencies
      if: matrix.platform == 'linux'
      run: |
        sudo apt-get update
        sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev librsvg2-dev

    - run: pnpm install --frozen-lockfile
    - run: pnpm --filter @myapp/app-desktop build
      env:
        PLATFORM: ${{ matrix.platform }}
        ARCH: ${{ matrix.arch }}

    - uses: actions/upload-artifact@v4
      with:
        name: desktop-${{ matrix.platform }}-${{ matrix.arch }}
        path: |
          packages/app-desktop/release/*.dmg
          packages/app-desktop/release/*.exe
          packages/app-desktop/release/*.AppImage
          packages/app-desktop/release/*.deb
        retention-days: 14

移动端构建

iOS 构建与签名

build-ios:
  needs: lint-and-test
  runs-on: macos-14
  steps:
    - uses: actions/checkout@v4
    - uses: pnpm/action-setup@v4
      with:
        version: 9
    - uses: actions/setup-node@v4
      with:
        node-version: 22
        cache: 'pnpm'

    - name: Setup Ruby
      uses: ruby/setup-ruby@v1
      with:
        ruby-version: '3.2'
        bundler-cache: true

    - name: Install CocoaPods
      working-directory: packages/app-mobile/ios
      run: bundle exec pod install

    - name: Import signing certificate
      env:
        CERTIFICATE_P12: ${{ secrets.IOS_CERTIFICATE_P12 }}
        CERTIFICATE_PASSWORD: ${{ secrets.IOS_CERTIFICATE_PASSWORD }}
        PROVISIONING_PROFILE: ${{ secrets.IOS_PROVISIONING_PROFILE }}
        KEYCHAIN_PASSWORD: ${{ secrets.KEYCHAIN_PASSWORD }}
      run: |
        KEYCHAIN_PATH=$RUNNER_TEMP/app-signing.keychain-db
        security create-keychain -p "$KEYCHAIN_PASSWORD" $KEYCHAIN_PATH
        security set-keychain-settings -lut 21600 $KEYCHAIN_PATH
        security unlock-keychain -p "$KEYCHAIN_PASSWORD" $KEYCHAIN_PATH

        echo -n "$CERTIFICATE_P12" | base64 --decode -o $RUNNER_TEMP/certificate.p12
        security import $RUNNER_TEMP/certificate.p12 -P "$CERTIFICATE_PASSWORD" \
          -A -t cert -f pkcs12 -k $KEYCHAIN_PATH
        security set-key-partition-list -S apple-tool:,apple: \
          -k "$KEYCHAIN_PASSWORD" $KEYCHAIN_PATH
        security list-keychain -d user -s $KEYCHAIN_PATH

        mkdir -p ~/Library/MobileDevice/Provisioning\ Profiles
        echo -n "$PROVISIONING_PROFILE" | base64 --decode \
          -o ~/Library/MobileDevice/Provisioning\ Profiles/profile.mobileprovision

    - name: Build IPA
      working-directory: packages/app-mobile/ios
      run: |
        xcodebuild -workspace MyApp.xcworkspace \
          -scheme MyApp \
          -configuration Release \
          -archivePath $RUNNER_TEMP/MyApp.xcarchive \
          archive

        xcodebuild -exportArchive \
          -archivePath $RUNNER_TEMP/MyApp.xcarchive \
          -exportOptionsPlist ExportOptions.plist \
          -exportPath $RUNNER_TEMP/export

    - name: Upload to TestFlight
      env:
        APP_STORE_CONNECT_API_KEY: ${{ secrets.APP_STORE_CONNECT_API_KEY }}
      run: |
        xcrun altool --upload-app \
          -f $RUNNER_TEMP/export/MyApp.ipa \
          -t ios \
          --apiKey $APP_STORE_CONNECT_API_KEY

    - name: Cleanup keychain
      if: always()
      run: security delete-keychain $RUNNER_TEMP/app-signing.keychain-db

Android 构建与签名

build-android:
  needs: lint-and-test
  runs-on: ubuntu-latest
  steps:
    - uses: actions/checkout@v4
    - uses: pnpm/action-setup@v4
      with:
        version: 9
    - uses: actions/setup-node@v4
      with:
        node-version: 22
        cache: 'pnpm'
    - uses: actions/setup-java@v4
      with:
        java-version: '17'
        distribution: 'temurin'

    - name: Setup Gradle
      uses: gradle/actions/setup-gradle@v4

    - run: pnpm install --frozen-lockfile

    - name: Decode signing key
      env:
        ANDROID_KEYSTORE: ${{ secrets.ANDROID_KEYSTORE }}
      run: |
        echo "$ANDROID_KEYSTORE" | base64 --decode > \
          packages/app-mobile/android/app/release.keystore

    - name: Build APK and AAB
      working-directory: packages/app-mobile/android
      env:
        KEYSTORE_PASSWORD: ${{ secrets.ANDROID_KEYSTORE_PASSWORD }}
        KEY_ALIAS: ${{ secrets.ANDROID_KEY_ALIAS }}
        KEY_PASSWORD: ${{ secrets.ANDROID_KEY_PASSWORD }}
      run: |
        ./gradlew assembleRelease bundleRelease \
          -Pandroid.injected.signing.store.file=app/release.keystore \
          -Pandroid.injected.signing.store.password="$KEYSTORE_PASSWORD" \
          -Pandroid.injected.signing.key.alias="$KEY_ALIAS" \
          -Pandroid.injected.signing.key.password="$KEY_PASSWORD"

    - uses: actions/upload-artifact@v4
      with:
        name: android-release
        path: |
          packages/app-mobile/android/app/build/outputs/apk/release/*.apk
          packages/app-mobile/android/app/build/outputs/bundle/release/*.aab
        retention-days: 14

    - name: Upload to Google Play
      uses: r0adkll/upload-google-play@v1
      with:
        serviceAccountJsonPlainText: ${{ secrets.GOOGLE_PLAY_SERVICE_ACCOUNT }}
        packageName: com.myapp.mobile
        releaseFiles: packages/app-mobile/android/app/build/outputs/bundle/release/*.aab
        track: internal

macOS 签名与公证

notarize-macos:
  needs: build-desktop
  runs-on: macos-14
  if: github.ref == 'refs/heads/main'
  steps:
    - uses: actions/download-artifact@v4
      with:
        name: desktop-darwin-arm64

    - name: Import certificate
      env:
        MACOS_CERTIFICATE: ${{ secrets.MACOS_CERTIFICATE }}
        MACOS_CERTIFICATE_PASSWORD: ${{ secrets.MACOS_CERTIFICATE_PASSWORD }}
      run: |
        echo "$MACOS_CERTIFICATE" | base64 --decode > certificate.p12
        KEYCHAIN_PATH=$RUNNER_TEMP/build.keychain
        security create-keychain -p actions $KEYCHAIN_PATH
        security unlock-keychain -p actions $KEYCHAIN_PATH
        security import certificate.p12 -k $KEYCHAIN_PATH \
          -P "$MACOS_CERTIFICATE_PASSWORD" -T /usr/bin/codesign
        security set-key-partition-list -S apple-tool:,apple: \
          -k actions $KEYCHAIN_PATH

    - name: Sign and notarize
      env:
        APPLE_ID: ${{ secrets.APPLE_ID }}
        APPLE_TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}
        APPLE_APP_PASSWORD: ${{ secrets.APPLE_APP_PASSWORD }}
      run: |
        codesign --deep --force --options runtime \
          --sign "Developer ID Application: $APPLE_TEAM_ID" \
          MyApp.app

        ditto -c -k --keepParent MyApp.app MyApp.zip

        xcrun notarytool submit MyApp.zip \
          --apple-id "$APPLE_ID" \
          --team-id "$APPLE_TEAM_ID" \
          --password "$APPLE_APP_PASSWORD" \
          --wait

        xcrun stapler staple MyApp.app

自动化测试

测试矩阵

e2e-test:
  needs: [build-web, build-desktop]
  strategy:
    fail-fast: false
    matrix:
      include:
        - target: web
          os: ubuntu-latest
          browser: chromium
        - target: web
          os: ubuntu-latest
          browser: firefox
        - target: web
          os: ubuntu-latest
          browser: webkit
        - target: desktop
          os: macos-14
          app: electron

  runs-on: ${{ matrix.os }}
  steps:
    - uses: actions/checkout@v4

    - uses: actions/download-artifact@v4
      with:
        name: ${{ matrix.target == 'web' && 'web-dist' || format('desktop-{0}-{1}', matrix.os == 'macos-14' && 'darwin' || 'linux', 'x64') }}

    - uses: actions/setup-node@v4
      with:
        node-version: 22

    - name: Install Playwright
      run: npx playwright install --with-deps ${{ matrix.browser || '' }}

    - name: Run E2E tests
      run: npx playwright test --project=${{ matrix.target }}
      env:
        CI: true
        TEST_BROWSER: ${{ matrix.browser }}

    - uses: actions/upload-artifact@v4
      if: failure()
      with:
        name: e2e-report-${{ matrix.target }}-${{ matrix.browser || matrix.app }}
        path: test-results/

版本管理与发布

语义化版本发布

release:
  needs: [build-web, build-ios, build-android, build-desktop, e2e-test]
  if: github.ref == 'refs/heads/main' && contains(github.event.head_commit.message, 'release:')
  runs-on: ubuntu-latest
  permissions:
    contents: write

  steps:
    - uses: actions/checkout@v4
      with:
        fetch-depth: 0

    - uses: actions/download-artifact@v4
      with:
        path: artifacts/

    - name: Extract version
      id: version
      run: |
        VERSION=$(node -p "require('./packages/app-web/package.json').version")
        echo "version=$VERSION" >> $GITHUB_OUTPUT

    - name: Generate changelog
      id: changelog
      run: |
        PREVIOUS_TAG=$(git describe --tags --abbrev=0 2>/dev/null || echo "")
        if [ -n "$PREVIOUS_TAG" ]; then
          CHANGES=$(git log $PREVIOUS_TAG..HEAD --pretty=format:"- %s (%h)" --no-merges)
        else
          CHANGES=$(git log --pretty=format:"- %s (%h)" --no-merges -20)
        fi
        echo "changes<<EOF" >> $GITHUB_OUTPUT
        echo "$CHANGES" >> $GITHUB_OUTPUT
        echo "EOF" >> $GITHUB_OUTPUT

    - name: Create GitHub Release
      uses: softprops/action-gh-release@v2
      with:
        tag_name: v${{ steps.version.outputs.version }}
        name: Release v${{ steps.version.outputs.version }}
        body: |
          ## Changes
          ${{ steps.changelog.outputs.changes }}

          ## Downloads
          | Platform | File |
          |----------|------|
          | macOS (Apple Silicon) | MyApp-arm64.dmg |
          | macOS (Intel) | MyApp-x64.dmg |
          | Windows | MyApp-Setup.exe |
          | Linux | MyApp.AppImage |
        files: |
          artifacts/**/*.dmg
          artifacts/**/*.exe
          artifacts/**/*.AppImage
          artifacts/**/*.deb
        draft: false
        prerelease: false

小结

多平台 CI/CD 流水线的核心是矩阵构建和并行化。共享阶段（lint、test）在单一环境运行，平台特定构建通过矩阵策略并行执行。iOS 和 macOS 构建需要处理证书导入、代码签名和 Apple 公证流程；Android 构建涉及 Keystore 管理和 Google Play 上传。优化策略包括依赖缓存、条件执行和产物缓存。版本发布通过 GitHub Releases 统一管理，配合语义化版本和自动 changelog 生成。一套完善的多平台流水线可以将从代码提交到全平台发布的时间控制在 20-30 分钟内。

核心要点回顾：

  • 矩阵构建实现多平台并行，fail-fast: false 确保独立性
  • iOS 签名需导入 P12 证书和 Provisioning Profile 到临时 Keychain
  • Android 签名使用 Base64 编码的 Keystore + Gradle 注入参数
  • macOS 应用需 codesign + notarytool 签名与公证
  • E2E 测试矩阵覆盖多浏览器和桌面平台
  • 依赖缓存 + 并行构建 + 条件执行大幅缩短流水线耗时
