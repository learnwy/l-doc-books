崩溃报告与数据分析

核心概念

跨平台应用的质量监控面临多重挑战：不同平台的崩溃堆栈格式各异，符号化流程不同，性能指标的采集方式和基准也存在差异。一套完善的监控体系应覆盖崩溃报告（Crash Reporting）、性能监控（Performance Monitoring）、用户行为分析（Analytics）和自定义事件追踪。本文深入讲解符号化原理、崩溃分组策略、自定义事件设计、性能监控实践及主流工具对比。

多平台崩溃捕获

interface CrashReport {
  id: string;
  timestamp: number;
  platform: 'web' | 'ios' | 'android' | 'desktop';
  appVersion: string;
  osVersion: string;
  device: string;
  error: {
    type: string;
    message: string;
    stack: string;
  };
  breadcrumbs: Breadcrumb[];
  tags: Record<string, string>;
  extra: Record<string, unknown>;
  user: {
    id: string;
    email?: string;
  } | null;
}

interface Breadcrumb {
  timestamp: number;
  category: 'navigation' | 'ui' | 'http' | 'console' | 'custom';
  message: string;
  level: 'debug' | 'info' | 'warning' | 'error';
  data?: Record<string, unknown>;
}

class CrashReporter {
  private breadcrumbs: Breadcrumb[] = [];
  private maxBreadcrumbs = 50;
  private tags: Record<string, string> = {};
  private reportQueue: CrashReport[] = [];
  private flushInterval: ReturnType<typeof setInterval>;

  constructor(
    private config: {
      endpoint: string;
      appVersion: string;
      platform: string;
      batchSize: number;
      flushIntervalMs: number;
    },
  ) {
    this.setupGlobalHandlers();
    this.flushInterval = setInterval(() => this.flush(), config.flushIntervalMs);
  }

  private setupGlobalHandlers(): void {
    if (typeof window !== 'undefined') {
      window.addEventListener('error', (event) => {
        this.captureError(event.error || new Error(event.message), {
          filename: event.filename,
          lineno: event.lineno,
          colno: event.colno,
        });
      });

      window.addEventListener('unhandledrejection', (event) => {
        this.captureError(event.reason instanceof Error ? event.reason : new Error(String(event.reason)));
      });
    }
  }

  setTag(key: string, value: string): void {
    this.tags[key] = value;
  }

  addBreadcrumb(breadcrumb: Omit<Breadcrumb, 'timestamp'>): void {
    this.breadcrumbs.push({
      ...breadcrumb,
      timestamp: Date.now(),
    });

    if (this.breadcrumbs.length > this.maxBreadcrumbs) {
      this.breadcrumbs.shift();
    }
  }

  captureError(error: Error, extra?: Record<string, unknown>): void {
    const report: CrashReport = {
      id: crypto.randomUUID(),
      timestamp: Date.now(),
      platform: this.config.platform as any,
      appVersion: this.config.appVersion,
      osVersion: this.getOSVersion(),
      device: this.getDeviceInfo(),
      error: {
        type: error.name,
        message: error.message,
        stack: error.stack || '',
      },
      breadcrumbs: [...this.breadcrumbs],
      tags: { ...this.tags },
      extra: extra || {},
      user: this.getCurrentUser(),
    };

    this.reportQueue.push(report);

    if (this.reportQueue.length >= this.config.batchSize) {
      this.flush();
    }
  }

  captureMessage(message: string, level: 'info' | 'warning' | 'error' = 'info'): void {
    this.captureError(new Error(message), { level });
  }

  private async flush(): Promise<void> {
    if (this.reportQueue.length === 0) return;

    const batch = this.reportQueue.splice(0, this.config.batchSize);

    try {
      await fetch(this.config.endpoint, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ reports: batch }),
      });
    } catch {
      this.reportQueue.unshift(...batch);
      this.persistToStorage(batch);
    }
  }

  private persistToStorage(reports: CrashReport[]): void {
    try {
      const existing = JSON.parse(localStorage.getItem('crash-queue') || '[]');
      localStorage.setItem('crash-queue', JSON.stringify([...existing, ...reports]));
    } catch {
      // noop
    }
  }

  private getOSVersion(): string {
    if (typeof navigator !== 'undefined') {
      return navigator.userAgent;
    }
    return 'unknown';
  }

  private getDeviceInfo(): string {
    if (typeof navigator !== 'undefined') {
      return navigator.platform;
    }
    return 'unknown';
  }

  private getCurrentUser(): CrashReport['user'] {
    return null;
  }

  destroy(): void {
    clearInterval(this.flushInterval);
    this.flush();
  }
}

符号化流程

sequenceDiagram
    participant APP as 应用
    participant SERVER as 崩溃服务
    participant SYMBOL as 符号化服务
    participant STORAGE as 符号表存储

    Note over APP: 崩溃发生
    APP->>SERVER: 上报原始堆栈<br/>(混淆/压缩地址)

    SERVER->>STORAGE: 查询匹配的符号表<br/>(dSYM / Proguard / SourceMap)
    STORAGE-->>SERVER: 返回符号表

    SERVER->>SYMBOL: 符号化请求
    Note over SYMBOL: 地址 → 文件:行号:函数名
    SYMBOL-->>SERVER: 返回可读堆栈

    SERVER->>SERVER: 崩溃分组 + 归档

flowchart TB
    CRASH[崩溃报告] --> NORMALIZE[堆栈规范化]

    EXTRACT --> FINGERPRINT{自定义指纹?}

    FINGERPRINT -->|是| CUSTOM[使用自定义指纹]

    AUTO --> HASH[堆栈哈希计算]
    CUSTOM --> GROUP_DB[(分组数据库)]
    HASH --> GROUP_DB

    GROUP_DB --> EXISTING{已有分组?}
    EXISTING -->|是| MERGE[合并到现有 Issue]
    EXISTING -->|否| NEW[创建新 Issue]

事件追踪设计

interface AnalyticsEvent {
  name: string;
  properties: Record<string, unknown>;
  timestamp: number;
  sessionId: string;
  userId?: string;
}

interface ScreenViewEvent extends AnalyticsEvent {
  name: 'screen_view';
  properties: {
    screen_name: string;
    screen_class: string;
    previous_screen?: string;
  };
}

interface UserActionEvent extends AnalyticsEvent {
  name: 'user_action';
  properties: {
    action: string;
    category: string;
    label?: string;
    value?: number;
  };
}

class AnalyticsClient {
  private queue: AnalyticsEvent[] = [];
  private sessionId: string;
  private userId: string | null = null;
  private superProperties: Record<string, unknown> = {};
  private flushTimer: ReturnType<typeof setInterval>;

  constructor(
    private config: {
      endpoint: string;
      batchSize: number;
      flushIntervalMs: number;
      platform: string;
      appVersion: string;
    },
  ) {
    this.sessionId = crypto.randomUUID();
    this.superProperties = {
      platform: config.platform,
      app_version: config.appVersion,
    };
    this.flushTimer = setInterval(() => this.flush(), config.flushIntervalMs);
  }

  identify(userId: string, traits?: Record<string, unknown>): void {
    this.userId = userId;
    if (traits) {
      this.superProperties = { ...this.superProperties, ...traits };
    }
    this.track('identify', { userId, ...traits });
  }

  track(name: string, properties: Record<string, unknown> = {}): void {
    const event: AnalyticsEvent = {
      name,
      properties: { ...this.superProperties, ...properties },
      timestamp: Date.now(),
      sessionId: this.sessionId,
      userId: this.userId || undefined,
    };

    this.queue.push(event);

    if (this.queue.length >= this.config.batchSize) {
      this.flush();
    }
  }

  screenView(screenName: string, screenClass: string): void {
    this.track('screen_view', {
      screen_name: screenName,
      screen_class: screenClass,
    });
  }

  trackTiming(category: string, variable: string, timeMs: number): void {
    this.track('timing', { category, variable, time_ms: timeMs });
  }

  private async flush(): Promise<void> {
    if (this.queue.length === 0) return;

    const batch = this.queue.splice(0, this.config.batchSize);

    try {
      const response = await fetch(this.config.endpoint, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ events: batch }),
        keepalive: true,
      });

      if (!response.ok) {
        this.queue.unshift(...batch);
      }
    } catch {
      this.queue.unshift(...batch);
    }
  }

  destroy(): void {
    clearInterval(this.flushTimer);
    this.flush();
  }
}

import { onFCP, onLCP, onFID, onCLS, onTTFB, type Metric } from 'web-vitals';

function initWebVitals(analytics: AnalyticsClient): void {
  const reportMetric = (metric: Metric) => {
    analytics.track('web_vital', {
      name: metric.name,
      value: metric.value,
      rating: metric.rating,
      delta: metric.delta,
      id: metric.id,
      navigationType: metric.navigationType,
    });
  };

  onFCP(reportMetric);
  onLCP(reportMetric);
  onFID(reportMetric);
  onCLS(reportMetric);
  onTTFB(reportMetric);
}

自定义性能追踪

class PerformanceTracker {
  private marks = new Map<string, number>();

  startTrace(name: string): void {
    this.marks.set(name, performance.now());
  }

  endTrace(name: string, analytics: AnalyticsClient): number | null {
    const startTime = this.marks.get(name);
    if (!startTime) return null;

    const duration = performance.now() - startTime;
    this.marks.delete(name);

    analytics.trackTiming('custom', name, Math.round(duration));

    return duration;
  }

  measureAsync<T>(name: string, fn: () => Promise<T>, analytics: AnalyticsClient): Promise<T> {
    this.startTrace(name);
    return fn().finally(() => this.endTrace(name, analytics));
  }
}

小结

跨平台应用的质量监控是一个系统工程。崩溃报告需要覆盖全平台的异常捕获、符号化和智能分组；性能监控需要针对不同平台采集差异化指标（Web Vitals、移动端帧率、桌面端 IPC 延迟）；用户行为分析通过事件追踪提供业务洞察。离线队列和批量上报确保弱网环境下的数据完整性。Sentry 以其全平台覆盖、自托管能力和开源特性成为跨平台监控的主流选择。告警规则需分级设计，确保团队能够快速响应关键问题。

核心要点回顾：

  • 全局异常捕获 + 面包屑日志构建完整的崩溃上下文
  • 符号化（dSYM / Proguard / Source Map）是崩溃可读性的关键
  • 智能分组通过堆栈指纹避免崩溃洪泛
  • 批量上报 + 离线队列确保弱网环境数据不丢失
  • Web Vitals / 帧率 / 启动时间是各平台核心性能指标
  • 分级告警确保团队对不同严重程度的问题做出适当响应
