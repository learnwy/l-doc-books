Part III · 跨平台与平台扩展跨平台开发 简介React Native 简介

React Native 简介

React Native 是 Meta 于 2015 年开源的跨平台移动开发框架，也是目前生态最成熟、社区最活跃的跨平台方案之一。它允许开发者使用 React 和 JavaScript 编写移动应用，通过桥接机制将 React 组件映射为平台原生控件，从而兼顾开发效率和原生体验。经过近十年的发展，React Native 正在经历一次根本性的架构升级——新架构彻底重写了渲染层、原生模块系统和线程通信模型，解决了旧架构中困扰开发者多年的性能瓶颈。

本章内容概览

新架构是本章的重点内容。Fabric 渲染器取代了旧的 UIManager，实现了同步布局和并发渲染能力；TurboModules 替代了旧的 NativeModules，通过 JSI 实现了 JavaScript 与原生代码的直接互调，消除了 JSON 序列化的桥接开销；Codegen 自动生成类型安全的接口定义，将运行时错误提前到编译期暴露。你将系统地理解这次架构演进的动因、实现原理和迁移路径。

原生模块深入讲解如何在 React Native 中扩展平台原生能力。无论是访问设备传感器、调用平台特有 API，还是集成第三方原生 SDK，原生模块都是连接 JavaScript 世界与平台原生世界的桥梁。本节将覆盖新架构下 TurboModules 的开发流程、Fabric 原生组件的封装方式，以及如何在 iOS 和 Android 两端保持接口一致性。

导航模式探讨 React Native 应用中最核心的用户体验要素之一——页面导航。移动端导航的复杂性远超 Web 应用，涉及原生导航栈管理、Tab 切换、模态弹出和深度链接等多种模式。本节将分析 React Navigation 等主流方案的设计思路和性能特征，帮助你在复杂路由场景中做出合理的架构选择。

性能调优提供一套从分析到优化的完整方法论。JavaScript 线程与 UI 线程的协调策略、列表渲染的虚拟化优化、图片加载的内存管理、启动时间的缩减手段——React Native 的性能优化需要同时理解 JavaScript 运行时和原生渲染机制。本节将帮助你建立系统的性能分析思维，而非依赖零散的优化技巧。

学习建议

建议优先阅读新架构一节，它是理解当下和未来 React Native 发展方向的关键。如果你正在维护旧架构项目，新架构的知识同样能帮助你规划迁移策略。导航和性能调优章节可以根据实际项目需求选择性深入。
