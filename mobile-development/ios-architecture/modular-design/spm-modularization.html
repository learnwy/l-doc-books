SPM 模块化

Swift Package Manager（SPM）已成为 iOS 模块化的首选工具。本文介绍 Package.swift 配置、target 与 product 的关系、本地包引用以及 monorepo 下的 SPM 项目结构。

Package.swift 基础

Package.swift 是 SPM 包的核心配置文件，定义了包的名称、平台、产物和目标：

// swift-tools-version: 5.9
import PackageDescription

let package = Package(
    name: "FeatureHome",
    platforms: [
        .iOS(.v17)
    ],
    products: [
        .library(
            name: "FeatureHome",
            targets: ["FeatureHome"]
        ),
        .library(
            name: "FeatureHomeInterface",
            targets: ["FeatureHomeInterface"]
        )
    ],
    dependencies: [
        .package(path: "../CoreNetworking"),
        .package(path: "../SharedUI")
    ],
    targets: [
        .target(
            name: "FeatureHome",
            dependencies: [
                "FeatureHomeInterface",
                .product(name: "CoreNetworking", package: "CoreNetworking"),
                .product(name: "SharedUI", package: "SharedUI")
            ]
        ),
        .target(
            name: "FeatureHomeInterface",
            dependencies: []
        ),
        .testTarget(
            name: "FeatureHomeTests",
            dependencies: ["FeatureHome"]
        )
    ]
)

Target 与 Product 的关系





概念
说明





Package
SPM 包，一个独立的代码分发单元




Product
包对外暴露的产物（library 或 executable）




Target
编译单元，包含源码文件和依赖声明




TestTarget
测试编译单元，依赖待测 target







提示： 一个 Package 可以包含多个 Product，每个 Product 可以聚合多个 Target，但 Target 之间不能循环依赖。






本地包引用
在 monorepo 中使用相对路径引用本地包：


dependencies: [
    .package(path: "../CoreNetworking"),
    .package(path: "../CoreStorage"),
    .package(path: "../SharedUI"),
    .package(path: "../SharedModels"),
]
在 Xcode 项目中添加本地包：


File → Add Package Dependencies → Add Local...
或在 xcworkspace 中直接拖入 Package 目录。本地包的修改会即时反映在主工程编译中，无需额外发布步骤。




Monorepo SPM 结构
推荐的 monorepo 目录结构：


MyApp/
├── App/
│   ├── MyApp.xcodeproj
│   └── Sources/
├── Packages/
│   ├── Feature/
│   │   ├── FeatureHome/
│   │   │   ├── Package.swift
│   │   │   ├── Sources/
│   │   │   │   ├── FeatureHome/
│   │   │   │   └── FeatureHomeInterface/
│   │   │   └── Tests/
│   │   ├── FeatureProfile/
│   │   └── FeatureSearch/
│   ├── Core/
│   │   ├── CoreNetworking/
│   │   ├── CoreStorage/
│   │   └── CoreAnalytics/
│   └── Shared/
│       ├── SharedUI/
│       ├── SharedModels/
│       └── SharedExtensions/
└── Tuist/ (or project.yml for XcodeGen)


高级配置技巧
条件编译与平台适配
targets: [
    .target(
        name: "CoreNetworking",
        dependencies: [
            .target(name: "CoreNetworkingMock", condition: .when(platforms: [.iOS])),
        ],
        swiftSettings: [
            .define("DEBUG", .when(configuration: .debug))
        ]
    )
]
资源文件处理
.target(
    name: "SharedUI",
    dependencies: [],
    resources: [
        .process("Resources"),
        .copy("Fonts")
    ]
)
在代码中访问 Bundle 资源：


public extension Bundle {
    static let sharedUI: Bundle = .module
}

public struct AppIcon: View {
    public var body: some View {
        Image("app_icon", bundle: .sharedUI)
            .resizable()
            .frame(width: 44, height: 44)
    }

    public init() {}
}

小结
    

  • Package.swift 通过 products/targets/dependencies 三层结构定义 SPM 包
    • 

  • Product 是对外暴露的接口，Target 是编译单元，两者多对多关系
    • 

  • 本地包通过相对路径引用，支持即时编辑和编译
    • 

  • Monorepo 结构推荐按 Feature/Core/Shared 分类组织 Packages 目录
    • 

  • SPM 支持条件编译、资源处理等高级特性
    • 

  • SPM 是当前 iOS 模块化的首选方案，官方支持和生态持续完善
    •
