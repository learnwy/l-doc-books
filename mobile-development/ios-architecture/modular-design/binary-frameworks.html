二进制框架

当模块化项目规模增长到一定程度，源码编译时间会成为瓶颈。二进制框架通过预编译分发模块来大幅缩短构建时间。本文介绍 XCFramework、远程二进制缓存以及预编译分发策略。

XCFramework 概述

XCFramework 是苹果推出的多平台二进制分发格式，支持在单个包中包含多架构（arm64、x86_64）和多平台（iOS、iOS Simulator、macOS）的产物。

构建 XCFramework 的命令：


// 构建脚本示例（在 Package.swift 或 Makefile 中使用）
// Step 1: 针对各平台 archive
// xcodebuild archive -scheme CoreNetworking -destination "generic/platform=iOS" -archivePath ./build/ios SKIP_INSTALL=NO
// xcodebuild archive -scheme CoreNetworking -destination "generic/platform=iOS Simulator" -archivePath ./build/sim SKIP_INSTALL=NO

// Step 2: 合并为 XCFramework
// xcodebuild -create-xcframework \
//   -framework ./build/ios.xcarchive/Products/Library/Frameworks/CoreNetworking.framework \
//   -framework ./build/sim.xcarchive/Products/Library/Frameworks/CoreNetworking.framework \
//   -output ./build/CoreNetworking.xcframework

远程二进制缓存
远程二进制缓存将编译产物存储在云端，团队成员和 CI 可以直接下载预编译结果而无需重新编译。


Tuist 缓存方案
// Tuist 项目中启用远程缓存
// tuist fetch   — 从远程下载预编译框架
// tuist cache   — 将编译结果上传到远程缓存
// tuist generate — 使用缓存生成项目

import ProjectDescription

let project = Project(
    name: "MyApp",
    targets: [
        .target(
            name: "MyApp",
            destinations: .iOS,
            product: .app,
            bundleId: "com.example.myapp",
            sources: ["Sources/**"],
            dependencies: [
                .external(name: "CoreNetworking"),
                .external(name: "SharedUI"),
            ]
        )
    ]
)
自建缓存服务
struct BinaryCacheService {
    let storageURL: URL
    let httpClient: HTTPClientProtocol

    func upload(framework: XCFramework, version: String) async throws {
        let data = try framework.archived()
        let key = "\(framework.name)-\(version)-\(framework.hash).xcframework.zip"
        try await httpClient.upload(data, to: storageURL.appending(path: key))
    }

    func download(name: String, version: String) async throws -> URL {
        let manifest = try await httpClient.get(
            storageURL.appending(path: "\(name)-\(version)-manifest.json")
        )
        let cacheKey = manifest.cacheKey
        let localPath = FileManager.default.temporaryDirectory.appending(path: cacheKey)
        try await httpClient.download(
            from: storageURL.appending(path: cacheKey),
            to: localPath
        )
        return localPath
    }
}

混合模式的实践方案：


// 根据环境变量决定使用源码还是二进制
import PackageDescription

let usePrebuilt = ProcessInfo.processInfo.environment["USE_PREBUILT"] == "1"

let coreDependency: Package.Dependency = usePrebuilt
    ? .package(url: "https://artifacts.example.com/CoreNetworking", exact: "1.2.3")
    : .package(path: "../CoreNetworking")

let package = Package(
    name: "FeatureHome",
    platforms: [.iOS(.v17)],
    products: [
        .library(name: "FeatureHome", targets: ["FeatureHome"])
    ],
    dependencies: [coreDependency],
    targets: [
        .target(
            name: "FeatureHome",
            dependencies: [
                .product(name: "CoreNetworking", package: usePrebuilt ? "CoreNetworking" : "CoreNetworking")
            ]
        )
    ]
)


SPM 二进制 Target
SPM 原生支持 .binaryTarget 用于引入预编译 XCFramework：


targets: [
    .binaryTarget(
        name: "CoreNetworking",
        url: "https://releases.example.com/CoreNetworking-1.2.3.xcframework.zip",
        checksum: "a1b2c3d4e5f6..."
    ),
    .binaryTarget(
        name: "Analytics",
        path: "Frameworks/Analytics.xcframework"
    )
]


小结
    

  • XCFramework 是苹果推荐的多平台二进制分发格式，取代了传统 Fat Binary
    • 

  • 远程二进制缓存可以将团队的增量编译时间从分钟级降低到秒级
    • 

  • Tuist 等工具提供了开箱即用的远程缓存集成方案
    • 

  • 预编译分发策略应根据项目规模和团队需求灵活选择
    • 

  • SPM 的 .binaryTarget 支持通过 URL 或本地路径引入预编译框架
    • 

  • 混合模式允许在源码调试和快速编译之间灵活切换
    •
