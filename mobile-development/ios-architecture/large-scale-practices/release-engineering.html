发布工程

发布工程（Release Engineering）涵盖从代码提交到 App Store 上架的全流程。本文介绍版本策略、CI/CD 流水线、TestFlight 分发以及 App Store 提交自动化。

版本策略

iOS 应用使用语义化版本和构建号的组合：





字段
说明
递增时机





Major
主版本，不兼容的重大变更
重大改版、架构升级




Minor
次版本，向后兼容的新功能
新功能上线




Patch
补丁版本，Bug 修复
热修复发版




Build Number
构建号，每次构建递增
每次 CI 构建





版本号自动化管理：


// 通过 agvtool 或 Fastlane 管理版本号
// agvtool new-marketing-version 1.2.3
// agvtool new-version -all 456

// Fastlane 版本管理
// increment_version_number(version_number: "1.2.3")
// increment_build_number(build_number: ENV["CI_BUILD_NUMBER"])


CI/CD 流水线
完整的 iOS CI/CD 流水线：




Fastlane 配置
// Fastfile
default_platform(:ios)

platform :ios do
    desc "运行所有测试"
    lane :test do
        scan(
            scheme: "MyApp",
            clean: true,
            code_coverage: true,
            output_types: "html,junit",
            result_bundle: true
        )
    end

    desc "构建并上传到 TestFlight"
    lane :beta do
        ensure_git_status_clean
        increment_build_number(build_number: ENV["CI_BUILD_NUMBER"])

        build_app(
            scheme: "MyApp",
            export_method: "app-store",
            output_directory: "./build",
            xcargs: "-allowProvisioningUpdates"
        )

        upload_to_testflight(
            skip_waiting_for_build_processing: true,
            apple_id: ENV["APPLE_ID"],
            team_id: ENV["TEAM_ID"]
        )

        slack(
            message: "新版本已上传到 TestFlight 🚀",
            channel: "#ios-releases"
        )
    end

    desc "提交到 App Store"
    lane :release do
        ensure_git_branch(branch: "release/*")

        build_app(
            scheme: "MyApp",
            export_method: "app-store",
            include_bitcode: false
        )

        upload_to_app_store(
            submit_for_review: true,
            automatic_release: false,
            force: true,
            precheck_include_in_app_purchases: false,
            submission_information: {
                add_id_info_uses_idfa: false
            }
        )
    end

    desc "代码签名管理"
    lane :sync_certificates do
        match(
            type: "appstore",
            app_identifier: "com.example.myapp",
            readonly: true
        )

        match(
            type: "development",
            app_identifier: "com.example.myapp",
            readonly: true
        )
    end
end

小结
    

  • 版本策略使用语义化版本（Major.Minor.Patch）+ CI 自增构建号
    • 

  • CI/CD 流水线覆盖编译、测试、静态分析、分发全流程
    • 

  • Fastlane 是 iOS 发布自动化的事实标准，支持构建、签名、上传一体化
    • 

  • TestFlight 分组策略实现内部测试 → QA → Beta → RC 的递进验证
    • 

  • App Store 提交可通过 Fastlane deliver 和 App Store Connect API 完全自动化
    • 

  • 发布流程应有明确的代码冻结点和 RC 验证环节
    •
