代码生成

Sourcery
Sourcery 是 Swift 社区最流行的元编程代码生成工具，通过扫描源码和模板生成代码。


自动生成 Mock
// sourcery: AutoMockable
protocol UserServiceProtocol {
    func fetchUser(id: String) async throws -> User
    func updateUser(_ user: User) async throws
    func deleteUser(id: String) async throws
    var currentUser: User? { get }
}
Sourcery 模板（Stencil 语法）生成的 Mock：


final class MockUserServiceProtocol: UserServiceProtocol {
    var fetchUserIdCallCount = 0
    var fetchUserIdReceivedId: String?
    var fetchUserIdReturnValue: User!
    var fetchUserIdThrowableError: Error?

    func fetchUser(id: String) async throws -> User {
        fetchUserIdCallCount += 1
        fetchUserIdReceivedId = id
        if let error = fetchUserIdThrowableError {
            throw error
        }
        return fetchUserIdReturnValue
    }

    var updateUserCallCount = 0
    var updateUserReceivedUser: User?
    var updateUserThrowableError: Error?

    func updateUser(_ user: User) async throws {
        updateUserCallCount += 1
        updateUserReceivedUser = user
        if let error = updateUserThrowableError {
            throw error
        }
    }

    var deleteUserIdCallCount = 0
    var deleteUserIdReceivedId: String?
    var deleteUserIdThrowableError: Error?

    func deleteUser(id: String) async throws {
        deleteUserIdCallCount += 1
        deleteUserIdReceivedId = id
        if let error = deleteUserIdThrowableError {
            throw error
        }
    }

    var currentUser: User?
}
Sourcery 配置
// .sourcery.yml
sources:
  - Sources/
templates:
  - Templates/
output:
  Generated/
args:
  autoMockableImports:
    - Foundation
    - UIKit


SwiftGen
SwiftGen 为项目资源生成类型安全的 Swift 访问代码：


颜色和图片
// 生成前 ❌
let color = UIColor(named: "primaryBlue")  // 运行时可能 nil
let image = UIImage(named: "ic_home")       // 字符串可能拼错

// 生成后 ✅
let color = Asset.Colors.primaryBlue.color  // 编译期安全
let image = Asset.Images.icHome.image       // 类型安全
本地化字符串
// Localizable.strings
// "welcome_message" = "欢迎, %@！";
// "item_count" = "共 %d 件商品";

// 生成的代码
enum L10n {
    static func welcomeMessage(_ p1: String) -> String {
        String(format: NSLocalizedString("welcome_message", comment: ""), p1)
    }

    static func itemCount(_ p1: Int) -> String {
        String(format: NSLocalizedString("item_count", comment: ""), p1)
    }
}

// 使用
let message = L10n.welcomeMessage("张三")
let count = L10n.itemCount(5)
SwiftGen 配置
// swiftgen.yml
strings:
  inputs:
    - Sources/Resources/Localizable.strings
  outputs:
    - templateName: structured-swift5
      output: Sources/Generated/Strings.swift

xcassets:
  inputs:
    - Sources/Resources/Assets.xcassets
    - Sources/Resources/Colors.xcassets
  outputs:
    - templateName: swift5
      output: Sources/Generated/Assets.swift

fonts:
  inputs:
    - Sources/Resources/Fonts/
  outputs:
    - templateName: swift5
      output: Sources/Generated/Fonts.swift


基于协议的代码生成
通过标记协议自动生成辅助代码：


// 定义标记协议
// sourcery: AutoEquatable
struct Product {
    let id: String
    let name: String
    let price: Decimal
    let category: String
    // sourcery: skipEquality
    let createdAt: Date
}

// Sourcery 自动生成的 Equatable 实现（跳过 createdAt）
extension Product: Equatable {
    static func == (lhs: Product, rhs: Product) -> Bool {
        lhs.id == rhs.id &&
        lhs.name == rhs.name &&
        lhs.price == rhs.price &&
        lhs.category == rhs.category
    }
}
自动路由注册
// sourcery: AutoRoute
// sourcery: routePath = "product/{id}"
struct ProductDetailView: View {
    let id: String
    var body: some View { Text(id) }
}

// 生成的路由注册代码
extension RouteRegistry {
    static func registerAutoRoutes() {
        register("product/{id}") { params in
            AnyView(ProductDetailView(id: params["id"]!))
        }
    }
}


构建阶段集成
将代码生成集成到 Xcode 构建流程中：


SPM Build Plugin
// Package.swift
let package = Package(
    name: "MyFeature",
    dependencies: [
        .package(url: "https://github.com/SwiftGen/SwiftGenPlugin", from: "6.6.0"),
    ],
    targets: [
        .target(
            name: "MyFeature",
            plugins: [
                .plugin(name: "SwiftGenPlugin", package: "SwiftGenPlugin")
            ]
        )
    ]
)
Xcode Run Script Phase
// Build Phases → New Run Script Phase
// 名称: Generate Mocks
// Script:
// if [ -f "$PODS_ROOT/Sourcery/bin/sourcery" ]; then
//   "$PODS_ROOT/Sourcery/bin/sourcery" --config .sourcery.yml
// fi


提示： 将生成的代码提交到版本控制（Git），这样 CI 环境不需要安装生成工具也能编译。

小结
    

  • 代码生成自动化产出重复性代码，保证一致性和类型安全
    • 

  • Sourcery 通过源码扫描和模板生成 Mock、Equatable 等辅助代码
    • 

  • SwiftGen 为资源文件（图片、颜色、字符串、字体）生成类型安全的访问代码
    • 

  • 基于协议标注（annotation）可以定制生成逻辑
    • 

  • 代码生成应集成到构建流程中，SPM Build Plugin 是推荐方式
    • 

  • 建议将生成代码提交到 Git，减少 CI 环境的工具依赖
    •
