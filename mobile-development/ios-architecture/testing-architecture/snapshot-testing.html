快照测试

快照测试（Snapshot Testing）通过对比 UI 渲染结果的图片来检测视觉回归。本文介绍 SnapshotTesting 库的使用、多设备/特征录制、CI 环境中的差异对比以及更新策略。

快照测试原理



SnapshotTesting 库
Point-Free 的 SnapshotTesting 是 Swift 社区最流行的快照测试库：


// Package.swift 依赖
// .package(url: "https://github.com/pointfreeco/swift-snapshot-testing", from: "1.15.0")
基本使用：


import XCTest
import SnapshotTesting
import SwiftUI

final class ProductCardSnapshotTests: XCTestCase {
    func testProductCardDefault() {
        let view = ProductCardView(
            product: Product(
                id: "1",
                name: "iPhone 16 Pro",
                price: 8999,
                imageURL: nil,
                rating: 4.8
            )
        )

        let hostingController = UIHostingController(rootView: view)
        hostingController.view.frame = CGRect(x: 0, y: 0, width: 375, height: 200)

        assertSnapshot(of: hostingController, as: .image)
    }

    func testProductCardSoldOut() {
        let view = ProductCardView(
            product: Product(
                id: "2",
                name: "AirPods Pro",
                price: 1899,
                imageURL: nil,
                rating: 4.5,
                isSoldOut: true
            )
        )

        let hostingController = UIHostingController(rootView: view)
        hostingController.view.frame = CGRect(x: 0, y: 0, width: 375, height: 200)

        assertSnapshot(of: hostingController, as: .image)
    }
}


多设备测试
针对不同设备尺寸和特征录制快照：


final class HomeScreenSnapshotTests: XCTestCase {
    let viewModel = HomeViewModel(
        productService: StubProductService(),
        analytics: DummyAnalytics()
    )

    func testHomeScreeniPhone15Pro() {
        let view = HomeView(viewModel: viewModel)
        let hostingController = UIHostingController(rootView: view)

        assertSnapshot(of: hostingController, as: .image(on: .iPhone13Pro))
    }

    func testHomeScreeniPhoneSE() {
        let view = HomeView(viewModel: viewModel)
        let hostingController = UIHostingController(rootView: view)

        assertSnapshot(of: hostingController, as: .image(on: .iPhoneSe))
    }

    func testHomeScreeniPadPro() {
        let view = HomeView(viewModel: viewModel)
        let hostingController = UIHostingController(rootView: view)

        assertSnapshot(of: hostingController, as: .image(on: .iPadPro12_9))
    }

    func testHomeScreenLandscape() {
        let view = HomeView(viewModel: viewModel)
        let hostingController = UIHostingController(rootView: view)

        assertSnapshot(
            of: hostingController,
            as: .image(on: .iPhone13Pro(.landscape))
        )
    }
}


特征组合测试
测试 Dark Mode、动态字体等特征：


final class ThemeSnapshotTests: XCTestCase {
    func testSettingsViewLightMode() {
        let view = SettingsView()
        let hostingController = UIHostingController(rootView: view)
        hostingController.overrideUserInterfaceStyle = .light

        assertSnapshot(of: hostingController, as: .image(on: .iPhone13Pro))
    }

    func testSettingsViewDarkMode() {
        let view = SettingsView()
        let hostingController = UIHostingController(rootView: view)
        hostingController.overrideUserInterfaceStyle = .dark

        assertSnapshot(of: hostingController, as: .image(on: .iPhone13Pro))
    }

    func testSettingsViewAccessibilitySize() {
        let view = SettingsView()
        let hostingController = UIHostingController(rootView: view)

        let traits = UITraitCollection(preferredContentSizeCategory: .accessibilityExtraLarge)
        assertSnapshot(
            of: hostingController,
            as: .image(on: .iPhone13Pro, traits: traits)
        )
    }
}

小结
    

  • 快照测试通过图片对比自动检测 UI 视觉回归
    • 

  • SnapshotTesting 库支持多设备、多特征（Dark Mode、动态字体）录制
    • 

  • CI 环境需要固定 macOS/Xcode 版本以保证快照一致性
    • 

  • 精度阈值（precision）允许忽略亚像素级别的渲染差异
    • 

  • 参考图更新需通过 review 确认是有意变更而非回归
    • 

  • 组件级快照测试比页面级更稳定、更易维护
    •
