GitHub Actions 配置
完整的 iOS CI 工作流：


// .github/workflows/ios.yml 等效逻辑
// name: iOS CI
//
// on:
//   push:
//     branches: [main, develop]
//   pull_request:
//     branches: [main]
//
// concurrency:
//   group: ${{ github.workflow }}-${{ github.ref }}
//   cancel-in-progress: true
//
// jobs:
//   build-and-test:
//     runs-on: macos-14
//     timeout-minutes: 30
//     steps:
//       - uses: actions/checkout@v4
//
//       - name: Cache SPM
//         uses: actions/cache@v4
//         with:
//           path: |
//             ~/Library/Caches/org.swift.swiftpm
//             .build
//           key: spm-${{ hashFiles('**/Package.resolved') }}
//
//       - name: Select Xcode
//         run: sudo xcode-select -s /Applications/Xcode_15.4.app
//
//       - name: Resolve packages
//         run: xcodebuild -resolvePackageDependencies -scheme MyApp
//
//       - name: Build
//         run: |
//           xcodebuild build-for-testing \
//             -scheme MyApp \
//             -destination 'platform=iOS Simulator,name=iPhone 15 Pro' \
//             -resultBundlePath build/Build.xcresult
//
//       - name: Test
//         run: |
//           xcodebuild test-without-building \
//             -scheme MyApp \
//             -destination 'platform=iOS Simulator,name=iPhone 15 Pro' \
//             -resultBundlePath build/Test.xcresult \
//             -parallel-testing-enabled YES \
//             -maximum-parallel-testing-workers 3
//
//       - name: Upload results
//         if: always()
//         uses: actions/upload-artifact@v4
//         with:
//           name: test-results
//           path: build/*.xcresult


Fastlane 集成
Fastlane 简化了 iOS CI 中的常见任务：


// Fastfile
default_platform(:ios)

platform :ios do
    before_all do
        setup_ci if ENV["CI"]
    end

    desc "代码规范检查"
    lane :lint do
        swiftlint(
            mode: :lint,
            config_file: ".swiftlint.yml",
            raise_if_swiftlint_error: true
        )
    end

    desc "运行所有测试"
    lane :test do
        run_tests(
            scheme: "MyApp",
            device: "iPhone 15 Pro",
            clean: true,
            code_coverage: true,
            parallel_testing: true,
            concurrent_workers: 3,
            result_bundle: true,
            output_types: "html,junit"
        )
    end

    desc "构建并分发到 TestFlight"
    lane :beta do
        sync_code_signing(type: "appstore")

        increment_build_number(
            build_number: ENV["GITHUB_RUN_NUMBER"]
        )

        build_app(
            scheme: "MyApp",
            export_method: "app-store",
            clean: true
        )

        upload_to_testflight(
            skip_waiting_for_build_processing: true
        )

        slack(
            message: "TestFlight 构建完成 🎉",
            success: true
        )
    end

    error do |lane, exception|
        slack(
            message: "CI 失败: #{exception.message}",
            success: false
        )
    end
end

测试并行化
iOS 测试并行化有两个层次：


Xcode 并行测试配置：


// 在 xcodebuild 命令中启用
// -parallel-testing-enabled YES
// -maximum-parallel-testing-workers 4

// 在 Xcode scheme 中配置
// Edit Scheme → Test → Options → Execute in parallel
测试分片策略：


// 使用 Test Plan 将测试分组
// MyApp.xctestplan
// {
//   "configurations": [
//     {
//       "name": "Unit Tests",
//       "options": {
//         "maximumParallelTestWorkers": 4
//       },
//       "targets": [
//         { "target": { "name": "UnitTests" } }
//       ]
//     },
//     {
//       "name": "Snapshot Tests",
//       "options": {
//         "maximumParallelTestWorkers": 1  // 快照测试不并行
//       },
//       "targets": [
//         { "target": { "name": "SnapshotTests" } }
//       ]
//     }
//   ]
// }


提示： 快照测试不应并行执行，因为多个模拟器实例的渲染可能不一致。

小结
    

  • GitHub Actions 灵活且社区生态丰富，是 iOS CI 的主流选择
    • 

  • Fastlane 封装了构建、测试、签名、分发等常见 CI 任务
    • 

  • Xcode Cloud 零配置签名，深度集成苹果生态，适合小团队
    • 

  • 测试并行化分为类级和 Target 级，快照测试需串行执行
    • 

  • Fastlane Match 是团队证书管理的最佳方案，加密存储在 Git 仓库
    • 

  • CI 应包含 lint、编译、测试、静态分析的完整流水线
