Part I · iOSSwiftUI 深入实践 简介动画 简介显式动画

显式动画

概述

显式动画通过 withAnimation 函数触发，与隐式动画（.animation 修饰器）不同的是，显式动画在状态变化的调用侧声明动画，而不是在视图侧。这提供了更精确的控制，包括完成回调、弹簧参数和自定义时间曲线。



withAnimation 基本用法
withAnimation 包裹状态变化代码，使得所有由此引起的视图更新都带有动画：


struct ExplicitAnimationDemo: View {
    @State private var offset: CGFloat = 0
    @State private var rotation: Double = 0
    @State private var color: Color = .blue

    var body: some View {
        VStack(spacing: 32) {
            RoundedRectangle(cornerRadius: 16)
                .frame(width: 100, height: 100)
                .foregroundStyle(color)
                .rotationEffect(.degrees(rotation))
                .offset(x: offset)

            HStack(spacing: 16) {
                Button("移动") {
                    withAnimation(.spring(response: 0.5, dampingFraction: 0.6)) {
                        offset = offset == 0 ? 100 : 0
                    }
                }

                Button("旋转") {
                    withAnimation(.easeInOut(duration: 0.8)) {
                        rotation += 90
                    }
                }

                Button("变色") {
                    withAnimation(.smooth) {
                        color = color == .blue ? .red : .blue
                    }
                }
            }
        }
    }
}

语法

withAnimation(.spring) { x = ... }

struct ComparisonView: View {
    @State private var isExpanded = false

    var body: some View {
        VStack(spacing: 20) {
            HStack(spacing: 20) {
                Circle()
                    .frame(width: isExpanded ? 80 : 40)
                    .foregroundStyle(.blue)

                RoundedRectangle(cornerRadius: 8)
                    .frame(width: isExpanded ? 160 : 80, height: 40)
                    .foregroundStyle(.green)

                Text(isExpanded ? "展开" : "收起")
                    .font(isExpanded ? .title : .body)
            }

            Button("显式动画切换") {
                withAnimation(.spring(response: 0.4)) {
                    isExpanded.toggle()
                }
            }
        }
    }
}
在上面的例子中，一个 withAnimation 调用让所有三个元素（圆形、矩形、文字）同时执行动画。




完成回调 (Completion Handler)
iOS 17+ 的 withAnimation 支持完成回调：


struct CompletionDemo: View {
    @State private var phase = 0
    @State private var statusText = "就绪"

    var body: some View {
        VStack(spacing: 24) {
            Circle()
                .frame(width: 60, height: 60)
                .foregroundStyle(phaseColor)
                .scaleEffect(phase >= 1 ? 1.2 : 1.0)
                .offset(y: phase >= 2 ? -50 : 0)
                .rotationEffect(.degrees(phase >= 3 ? 360 : 0))

            Text(statusText)
                .font(.headline)
                .foregroundStyle(.secondary)

            Button("开始序列动画") {
                startSequence()
            }
            .disabled(phase > 0)
        }
    }

    var phaseColor: Color {
        switch phase {
        case 0: return .blue
        case 1: return .green
        case 2: return .orange
        default: return .red
        }
    }

    func startSequence() {
        statusText = "阶段 1: 放大"
        withAnimation(.easeOut(duration: 0.5)) {
            phase = 1
        } completion: {
            statusText = "阶段 2: 上移"
            withAnimation(.spring(response: 0.4)) {
                phase = 2
            } completion: {
                statusText = "阶段 3: 旋转"
                withAnimation(.easeInOut(duration: 0.8)) {
                    phase = 3
                } completion: {
                    statusText = "完成！"
                }
            }
        }
    }
}


弹簧参数详解
弹簧动画是 SwiftUI 中最常用的动画类型：


struct SpringParametersView: View {
    @State private var isActive = false

    var body: some View {
        VStack(spacing: 16) {
            springRow("默认弹簧", .spring())
            springRow("快速", .spring(response: 0.3, dampingFraction: 0.5))
            springRow("缓慢", .spring(response: 1.0, dampingFraction: 0.7))
            springRow("弹跳", .spring(response: 0.4, dampingFraction: 0.3))
            springRow("过阻尼", .spring(response: 0.5, dampingFraction: 1.2))

            Button("切换") {
                withAnimation {
                    isActive.toggle()
                }
            }
            .padding(.top)
        }
    }

    func springRow(_ label: String, _ animation: Animation) -> some View {
        HStack {
            Text(label)
                .frame(width: 80, alignment: .leading)
                .font(.caption)
            Circle()
                .frame(width: 24, height: 24)
                .foregroundStyle(.blue)
                .offset(x: isActive ? 100 : 0)
                .animation(animation, value: isActive)
        }
    }
}




弹簧参数
说明
典型值





response
完成一个周期的时间（秒）
0.3 ~ 1.0




dampingFraction
阻尼比（0=永不停止, 1=临界阻尼）
0.3 ~ 1.0




blendDuration
与其他动画混合的时间
0







提示： iOS 17+ 提供了更简洁的预设弹簧：.bouncy（弹跳感）、.smooth（平滑）、.snappy（快速精确）。这些预设覆盖了大多数常见场景。






自定义时间曲线
使用 timingCurve 定义自定义贝塞尔曲线：


struct CustomCurveDemo: View {
    @State private var isActive = false

    var body: some View {
        VStack(spacing: 16) {
            Circle()
                .frame(width: 40, height: 40)
                .foregroundStyle(.purple)
                .offset(x: isActive ? 150 : -150)

            Button("自定义曲线") {
                withAnimation(.timingCurve(0.68, -0.55, 0.27, 1.55, duration: 1.0)) {
                    isActive.toggle()
                }
            }
        }
    }
}


部分属性排除动画
显式动画的一个优势是可以选择性地排除某些属性变化：


struct PartialAnimationView: View {
    @State private var position: CGFloat = 0
    @State private var label = "开始"

    var body: some View {
        VStack(spacing: 24) {
            Circle()
                .frame(width: 50, height: 50)
                .foregroundStyle(.blue)
                .offset(x: position)

            Text(label)
                .font(.title2)

            Button("更新") {
                withAnimation(.spring(response: 0.5)) {
                    position = position == 0 ? 100 : 0
                }
                label = position == 0 ? "已移动" : "开始"
            }
        }
    }
}
position 的变化在 withAnimation 内，因此有动画。label 的变化在 withAnimation 外，瞬间完成。




小结
    

  • withAnimation 在状态变化的调用侧声明动画，一次调用影响所有相关视图更新
    • 

  • 显式动画适合多视图联动的场景，比隐式动画更容易管理
    • 

  • iOS 17+ 支持 withAnimation { ... } completion: { ... } 完成回调
    • 

  • 弹簧动画通过 response 和 dampingFraction 控制速度和弹跳程度
    • 

  • timingCurve 支持自定义贝塞尔曲线
    • 

  • withAnimation 外的状态变化不受动画影响，可实现部分属性排除
    • 

  • 序列动画通过嵌套 withAnimation 的 completion 回调实现
