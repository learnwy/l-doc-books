Part I · iOSSwiftUI 深入实践 简介动画 简介隐式动画

隐式动画

概述

SwiftUI 的隐式动画通过 .animation 修饰器实现——当视图的可动画属性发生变化时，框架自动在旧值和新值之间插入平滑过渡。隐式动画是 SwiftUI 动画系统中最常用的方式，配合 Animatable 协议和 Transaction 机制，可以实现丰富的动画效果。



.animation 修饰器
.animation(_:value:) 在指定值变化时对视图属性应用动画：


struct PulseView: View {
    @State private var isActive = false

    var body: some View {
        VStack(spacing: 32) {
            Circle()
                .frame(width: isActive ? 150 : 100, height: isActive ? 150 : 100)
                .foregroundStyle(isActive ? .red : .blue)
                .opacity(isActive ? 1.0 : 0.6)
                .animation(.easeInOut(duration: 0.5), value: isActive)

            Button(isActive ? "停止" : "激活") {
                isActive.toggle()
            }
            .buttonStyle(.borderedProminent)
        }
    }
}




动画曲线
说明





.linear
匀速运动




.easeIn
慢入快出




.easeOut
快入慢出




.easeInOut
慢入慢出（默认）




.spring()
弹簧效果




.bouncy
弹跳效果（iOS 17+）




.smooth
平滑效果（iOS 17+）




.snappy
快速精确（iOS 17+）







动画的作用域
.animation 修饰器的位置决定了动画的作用范围——它会影响该修饰器之上的所有可动画属性变化：


struct ScopeDemo: View {
    @State private var isExpanded = false

    var body: some View {
        VStack(spacing: 20) {
            RoundedRectangle(cornerRadius: isExpanded ? 24 : 12)
                .foregroundStyle(.blue)
                .frame(width: isExpanded ? 200 : 100, height: isExpanded ? 200 : 100)
                .animation(.spring(response: 0.4, dampingFraction: 0.6), value: isExpanded)

            Text("状态：\(isExpanded ? "展开" : "收起")")
                .foregroundStyle(isExpanded ? .green : .primary)

            Button("切换") {
                isExpanded.toggle()
            }
        }
    }
}
在上面的例子中，.animation 只影响 RoundedRectangle 的尺寸和圆角变化。Text 的颜色变化没有动画。




提示： 避免使用已废弃的 .animation(.easeInOut) （不带 value 参数）。它会对所有属性变化应用动画，可能导致意外效果。始终使用 .animation(_:value:) 明确指定触发源。






Animatable 协议
SwiftUI 内置类型（CGFloat、Color、CGSize 等）已遵循 Animatable。自定义类型也可以通过实现 animatableData 参与动画：


struct AnimatableArc: Shape {
    var endAngle: Double

    var animatableData: Double {
        get { endAngle }
        set { endAngle = newValue }
    }

    func path(in rect: CGRect) -> Path {
        var path = Path()
        path.addArc(
            center: CGPoint(x: rect.midX, y: rect.midY),
            radius: min(rect.width, rect.height) / 2,
            startAngle: .degrees(-90),
            endAngle: .degrees(endAngle - 90),
            clockwise: false
        )
        return path
    }
}

struct ProgressRing: View {
    @State private var progress: Double = 0

    var body: some View {
        VStack {
            ZStack {
                Circle()
                    .stroke(.gray.opacity(0.2), lineWidth: 12)

                AnimatableArc(endAngle: progress * 360)
                    .stroke(.blue, style: StrokeStyle(lineWidth: 12, lineCap: .round))
                    .animation(.easeInOut(duration: 1.0), value: progress)

                Text("\(Int(progress * 100))%")
                    .font(.title)
                    .bold()
            }
            .frame(width: 150, height: 150)

            Button("设为 75%") {
                progress = 0.75
            }
        }
    }
}


AnimatablePair
当需要同时动画多个值时，使用 AnimatablePair：


struct MorphingShape: Shape {
    var width: CGFloat
    var height: CGFloat

    var animatableData: AnimatablePair<CGFloat, CGFloat> {
        get { AnimatablePair(width, height) }
        set {
            width = newValue.first
            height = newValue.second
        }
    }

    func path(in rect: CGRect) -> Path {
        Path(ellipseIn: CGRect(
            x: rect.midX - width / 2,
            y: rect.midY - height / 2,
            width: width,
            height: height
        ))
    }
}

struct MorphDemo: View {
    @State private var isCircle = true

    var body: some View {
        MorphingShape(
            width: isCircle ? 100 : 200,
            height: isCircle ? 100 : 60
        )
        .foregroundStyle(.purple)
        .animation(.spring(response: 0.5), value: isCircle)
        .onTapGesture { isCircle.toggle() }
    }
}


Transaction（事务）
Transaction 是 SwiftUI 动画的底层机制，.animation 修饰器实际上是设置了 Transaction 中的动画属性：


struct TransactionDemo: View {
    @State private var scale: CGFloat = 1.0

    var body: some View {
        VStack(spacing: 24) {
            Circle()
                .frame(width: 80, height: 80)
                .foregroundStyle(.blue)
                .scaleEffect(scale)

            Button("带动画缩放") {
                withAnimation(.spring(response: 0.3)) {
                    scale = scale == 1.0 ? 1.5 : 1.0
                }
            }

            Button("无动画缩放") {
                var transaction = Transaction()
                transaction.disablesAnimations = true
                withTransaction(transaction) {
                    scale = scale == 1.0 ? 1.5 : 1.0
                }
            }
        }
    }
}




Transaction 属性
说明





animation
当前事务使用的动画




disablesAnimations
禁用所有动画




isContinuous
是否为持续交互（如拖拽）







重复动画与延迟
struct RepeatDemo: View {
    @State private var isAnimating = false

    var body: some View {
        VStack(spacing: 24) {
            Circle()
                .frame(width: 50, height: 50)
                .foregroundStyle(.red)
                .scaleEffect(isAnimating ? 1.2 : 0.8)
                .opacity(isAnimating ? 1.0 : 0.5)
                .animation(
                    .easeInOut(duration: 0.8).repeatForever(autoreverses: true),
                    value: isAnimating
                )

            HStack(spacing: 12) {
                ForEach(0..<3, id: \.self) { index in
                    Circle()
                        .frame(width: 16, height: 16)
                        .foregroundStyle(.blue)
                        .scaleEffect(isAnimating ? 1.0 : 0.5)
                        .animation(
                            .easeInOut(duration: 0.6)
                                .repeatForever(autoreverses: true)
                                .delay(Double(index) * 0.2),
                            value: isAnimating
                        )
                }
            }
        }
        .onAppear { isAnimating = true }
    }
}


小结
    

  • .animation(_:value:) 在指定值变化时为视图属性添加平滑过渡动画
    • 

  • 动画曲线包括 .linear、.easeInOut、.spring() 和 iOS 17+ 的 .bouncy、.smooth
    • 

  • .animation 的位置决定作用范围，只影响其之上的修饰器
    • 

  • Animatable 协议通过 animatableData 让自定义类型参与动画插值
    • 

  • AnimatablePair 支持同时对多个值进行动画
    • 

  • Transaction 是动画的底层机制，disablesAnimations 可禁用动画
    • 

  • .repeatForever() 和 .delay() 组合可实现循环动画和错开动画效果
    •
