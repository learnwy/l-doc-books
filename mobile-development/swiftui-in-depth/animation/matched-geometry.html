matchedGeometryEffect 几何匹配动画

概述

matchedGeometryEffect 是 SwiftUI 中实现**英雄过渡动画（Hero Transition）**的核心工具。它通过在两个视图之间创建几何关联，使得一个视图可以平滑地「变形」为另一个视图。配合 @Namespace、source 标志和动画，可以实现 App Store 风格的展开/收起效果。



基本原理
matchedGeometryEffect 的工作方式：


    

  1. 两个视图使用相同的 ID 和 Namespace 声明关联
    2. 

  2. 同一时刻只有一个视图存在于视图树中
    3. 

  3. 切换时，SwiftUI 记录旧视图的几何信息（位置、尺寸）
    4. 

  4. 新视图从旧视图的位置/尺寸平滑过渡到自己的位置/尺寸
    5. 



struct BasicHeroTransition: View {
    @Namespace private var animation
    @State private var isExpanded = false

    var body: some View {
        VStack {
            if isExpanded {
                RoundedRectangle(cornerRadius: 24)
                    .foregroundStyle(.blue)
                    .matchedGeometryEffect(id: "card", in: animation)
                    .frame(height: 300)
                    .padding()
                    .onTapGesture {
                        withAnimation(.spring(response: 0.4, dampingFraction: 0.8)) {
                            isExpanded = false
                        }
                    }
            } else {
                RoundedRectangle(cornerRadius: 12)
                    .foregroundStyle(.blue)
                    .matchedGeometryEffect(id: "card", in: animation)
                    .frame(width: 100, height: 100)
                    .onTapGesture {
                        withAnimation(.spring(response: 0.4, dampingFraction: 0.8)) {
                            isExpanded = true
                        }
                    }
            }
        }
        .frame(maxWidth: .infinity, maxHeight: .infinity)
    }
}


@Namespace
@Namespace 创建一个命名空间，用于将不同视图中的 matchedGeometryEffect 关联起来：


struct CardGridView: View {
    @Namespace private var heroAnimation
    @State private var selectedCard: Int?

    let colors: [Color] = [.red, .blue, .green, .orange, .purple, .pink]

    var body: some View {
        ZStack {
            if let selected = selectedCard {
                ExpandedCardView(
                    index: selected,
                    color: colors[selected],
                    namespace: heroAnimation,
                    onClose: {
                        withAnimation(.spring(response: 0.4, dampingFraction: 0.85)) {
                            selectedCard = nil
                        }
                    }
                )
                .zIndex(1)
            } else {
                LazyVGrid(columns: [GridItem(.adaptive(minimum: 120))], spacing: 16) {
                    ForEach(colors.indices, id: \.self) { index in
                        CardThumbnail(
                            index: index,
                            color: colors[index],
                            namespace: heroAnimation
                        )
                        .onTapGesture {
                            withAnimation(.spring(response: 0.4, dampingFraction: 0.85)) {
                                selectedCard = index
                            }
                        }
                    }
                }
                .padding()
            }
        }
    }
}

struct CardThumbnail: View {
    let index: Int
    let color: Color
    var namespace: Namespace.ID

    var body: some View {
        RoundedRectangle(cornerRadius: 12)
            .foregroundStyle(color.gradient)
            .frame(height: 120)
            .matchedGeometryEffect(id: "card_\(index)", in: namespace)
            .overlay {
                Text("卡片 \(index + 1)")
                    .foregroundStyle(.white)
                    .bold()
                    .matchedGeometryEffect(id: "title_\(index)", in: namespace)
            }
    }
}

struct ExpandedCardView: View {
    let index: Int
    let color: Color
    var namespace: Namespace.ID
    let onClose: () -> Void

    var body: some View {
        VStack {
            RoundedRectangle(cornerRadius: 24)
                .foregroundStyle(color.gradient)
                .matchedGeometryEffect(id: "card_\(index)", in: namespace)
                .frame(height: 300)
                .overlay(alignment: .topLeading) {
                    Text("卡片 \(index + 1)")
                        .font(.title)
                        .foregroundStyle(.white)
                        .bold()
                        .padding()
                        .matchedGeometryEffect(id: "title_\(index)", in: namespace)
                }

            Text("这是卡片 \(index + 1) 的详细内容")
                .padding()

            Spacer()
        }
        .onTapGesture(perform: onClose)
    }
}


source 标志
isSource 参数控制哪个视图提供几何信息，哪个视图接收：


struct SourceFlagDemo: View {
    @Namespace private var ns
    @State private var selectedIndex = 0

    let tabs = ["首页", "发现", "消息", "我的"]

    var body: some View {
        HStack(spacing: 0) {
            ForEach(tabs.indices, id: \.self) { index in
                Text(tabs[index])
                    .font(.headline)
                    .frame(maxWidth: .infinity)
                    .padding(.vertical, 12)
                    .background {
                        if selectedIndex == index {
                            Capsule()
                                .foregroundStyle(.blue.opacity(0.2))
                                .matchedGeometryEffect(id: "tabBg", in: ns)
                        }
                    }
                    .foregroundStyle(selectedIndex == index ? .blue : .primary)
                    .onTapGesture {
                        withAnimation(.spring(response: 0.35)) {
                            selectedIndex = index
                        }
                    }
            }
        }
        .padding(4)
        .background(.ultraThinMaterial)
        .clipShape(Capsule())
        .padding()
    }
}




source 值
说明





true（默认）
视图提供自己的几何信息给匹配对




false
视图接收匹配对的几何信息







提示： 当两个视图通过 if-else 互斥存在时，不需要设置 isSource。当两个视图同时存在且需要同步几何属性时，isSource 区分谁是几何信息的提供者。






多元素匹配
一个英雄过渡可以包含多个匹配对，实现更丰富的效果：


struct MultiMatchView: View {
    @Namespace private var ns
    @State private var showDetail = false

    var body: some View {
        VStack {
            if showDetail {
                VStack(alignment: .leading, spacing: 16) {
                    Image(systemName: "photo")
                        .font(.system(size: 100))
                        .frame(maxWidth: .infinity, minHeight: 200)
                        .background(.blue.opacity(0.1))
                        .matchedGeometryEffect(id: "image", in: ns)

                    Text("文章标题")
                        .font(.title)
                        .matchedGeometryEffect(id: "title", in: ns)

                    Text("这是文章的详细内容，包含更多描述信息...")
                        .font(.body)
                        .foregroundStyle(.secondary)
                }
                .padding()
                .onTapGesture {
                    withAnimation(.spring(response: 0.45)) { showDetail = false }
                }
            } else {
                HStack(spacing: 12) {
                    Image(systemName: "photo")
                        .font(.system(size: 40))
                        .frame(width: 60, height: 60)
                        .background(.blue.opacity(0.1))
                        .matchedGeometryEffect(id: "image", in: ns)

                    Text("文章标题")
                        .font(.headline)
                        .matchedGeometryEffect(id: "title", in: ns)

                    Spacer()
                }
                .padding()
                .background(.regularMaterial)
                .clipShape(RoundedRectangle(cornerRadius: 12))
                .padding(.horizontal)
                .onTapGesture {
                    withAnimation(.spring(response: 0.45)) { showDetail = true }
                }
            }
        }
        .frame(maxHeight: .infinity, alignment: showDetail ? .top : .center)
    }
}


小结
    

  • matchedGeometryEffect 通过相同 ID 和 Namespace 关联两个视图实现英雄过渡
    • 

  • @Namespace 创建命名空间，确保匹配关系的隔离和正确性
    • 

  • isSource 控制几何信息的提供方和接收方
    • 

  • 多个匹配对（图片、标题等）可以在同一个过渡中同步动画
    • 

  • 必须配合 withAnimation 或 .animation 使用才能产生过渡效果
    • 

  • 适合实现 App Store 卡片展开、Tab 指示器滑动等效果
    • 

  • 注意同一时刻同一 ID 在 if-else 中只应有一个视图存在
    •
