NavigationSplitView 分栏导航

概述

NavigationSplitView 是 iOS 16 引入的多栏导航容器，专为 iPad、macOS 和大屏设备设计。它支持双栏和三栏布局，能够根据设备尺寸自适应折叠为单栏导航。掌握 NavigationSplitView 是构建跨平台自适应应用的关键。



双栏布局
最基本的 NavigationSplitView 使用两栏：


struct TwoColumnView: View {
    @State private var selectedCategory: Category?

    let categories: [Category] = [
        Category(name: "科技", icon: "laptopcomputer"),
        Category(name: "体育", icon: "sportscourt"),
        Category(name: "音乐", icon: "music.note"),
        Category(name: "电影", icon: "film"),
    ]

    var body: some View {
        NavigationSplitView {
            List(categories, selection: $selectedCategory) { category in
                Label(category.name, systemImage: category.icon)
                    .tag(category)
            }
            .navigationTitle("分类")
        } detail: {
            if let category = selectedCategory {
                CategoryDetailView(category: category)
            } else {
                ContentUnavailableView("选择一个分类", systemImage: "square.dashed", description: Text("从左侧列表中选择"))
            }
        }
    }
}

struct Category: Identifiable, Hashable {
    let id = UUID()
    let name: String
    let icon: String
}


三栏布局
三栏布局添加中间的内容栏，适合邮件、笔记类应用：


struct ThreeColumnView: View {
    @State private var selectedMailbox: Mailbox?
    @State private var selectedMessage: Message?

    let mailboxes: [Mailbox] = [
        Mailbox(name: "收件箱", icon: "tray", count: 12),
        Mailbox(name: "已发送", icon: "paperplane", count: 0),
        Mailbox(name: "草稿", icon: "doc", count: 3),
        Mailbox(name: "垃圾邮件", icon: "trash", count: 5),
    ]

    var body: some View {
        NavigationSplitView {
            List(mailboxes, selection: $selectedMailbox) { mailbox in
                HStack {
                    Label(mailbox.name, systemImage: mailbox.icon)
                    Spacer()
                    if mailbox.count > 0 {
                        Text("\(mailbox.count)")
                            .font(.caption)
                            .foregroundStyle(.secondary)
                    }
                }
                .tag(mailbox)
            }
            .navigationTitle("邮箱")
        } content: {
            if let mailbox = selectedMailbox {
                MessageListView(
                    mailbox: mailbox,
                    selectedMessage: $selectedMessage
                )
            } else {
                ContentUnavailableView("选择邮箱", systemImage: "tray")
            }
        } detail: {
            if let message = selectedMessage {
                MessageDetailView(message: message)
            } else {
                ContentUnavailableView("选择邮件", systemImage: "envelope")
            }
        }
    }
}

struct Mailbox: Identifiable, Hashable {
    let id = UUID()
    let name: String
    let icon: String
    let count: Int
}

struct Message: Identifiable, Hashable {
    let id = UUID()
    let subject: String
    let sender: String
    let preview: String
    let date: Date
}


栏宽自定义
通过 .navigationSplitViewColumnWidth 自定义各栏宽度：


struct CustomWidthView: View {
    @State private var selectedItem: String?

    var body: some View {
        NavigationSplitView(columnVisibility: .constant(.all)) {
            List(["A", "B", "C"], id: \.self, selection: $selectedItem) { item in
                Text("项目 \(item)")
            }
            .navigationSplitViewColumnWidth(min: 150, ideal: 200, max: 250)
        } detail: {
            Text(selectedItem ?? "请选择")
                .navigationSplitViewColumnWidth(min: 300, ideal: 500, max: .infinity)
        }
    }
}




参数
说明





min
栏的最小宽度




ideal
栏的理想宽度




max
栏的最大宽度




固定宽度
navigationSplitViewColumnWidth(200)







栏可见性控制
NavigationSplitViewVisibility 控制各栏的显示状态：


struct VisibilityControlView: View {
    @State private var columnVisibility: NavigationSplitViewVisibility = .all
    @State private var selectedItem: String?

    var body: some View {
        NavigationSplitView(columnVisibility: $columnVisibility) {
            List(["设置A", "设置B", "设置C"], id: \.self, selection: $selectedItem) { item in
                Text(item)
            }
            .navigationTitle("侧边栏")
        } detail: {
            VStack(spacing: 16) {
                Text(selectedItem ?? "请选择")
                    .font(.title)

                HStack(spacing: 12) {
                    Button("显示全部") { columnVisibility = .all }
                    Button("仅详情") { columnVisibility = .detailOnly }
                    Button("双栏") { columnVisibility = .doubleColumn }
                }
            }
        }
        .navigationSplitViewStyle(.balanced)
    }
}


自适应导航
在 iPhone（紧凑宽度）上，NavigationSplitView 自动折叠为 NavigationStack 行为：


struct AdaptiveView: View {
    @Environment(\.horizontalSizeClass) var sizeClass
    @State private var selectedItem: String?

    let items = ["项目 1", "项目 2", "项目 3", "项目 4"]

    var body: some View {
        NavigationSplitView {
            List(items, id: \.self, selection: $selectedItem) { item in
                Text(item)
            }
            .navigationTitle("列表")
        } detail: {
            if let item = selectedItem {
                VStack {
                    Text(item)
                        .font(.largeTitle)
                    Text("当前模式：\(sizeClass == .compact ? "紧凑（Stack）" : "常规（Split）")")
                        .foregroundStyle(.secondary)
                }
            } else {
                ContentUnavailableView("选择项目", systemImage: "list.bullet")
            }
        }
    }
}

NavigationSplitView 样式
struct StyledSplitView: View {
    @State private var selected: String?

    var body: some View {
        NavigationSplitView {
            List(["A", "B", "C"], id: \.self, selection: $selected) { item in
                Text(item)
            }
        } detail: {
            Text(selected ?? "选择")
        }
        .navigationSplitViewStyle(.prominentDetail)
    }
}




样式
说明





.automatic
系统默认行为




.balanced
侧边栏和详情栏平等分配空间




.prominentDetail
详情栏优先，侧边栏以 overlay 形式显示







提示： .prominentDetail 样式在 iPad 上会让详情视图占据全屏宽度，侧边栏以浮层形式覆盖。适合详情内容比列表更重要的场景。
