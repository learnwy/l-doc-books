NavigationStack 导航栈

概述

NavigationStack 是 iOS 16 引入的基于路径（path-based）的导航容器，替代了旧版的 NavigationView。它通过 NavigationPath 实现了类型安全的编程式导航，支持深层链接和状态恢复。掌握 NavigationStack 是构建现代 SwiftUI 导航架构的基础。



基本用法
NavigationStack 结合 NavigationLink(value:) 和 .navigationDestination 使用：


struct ContentView: View {
    let categories = ["水果", "蔬菜", "肉类", "海鲜"]

    var body: some View {
        NavigationStack {
            List(categories, id: \.self) { category in
                NavigationLink(category, value: category)
            }
            .navigationTitle("商品分类")
            .navigationDestination(for: String.self) { category in
                CategoryDetailView(category: category)
            }
        }
    }
}

struct CategoryDetailView: View {
    let category: String

    var body: some View {
        Text("\(category) 详情")
            .navigationTitle(category)
    }
}




组件
职责





NavigationStack
导航容器，管理导航栈




NavigationLink(value:)
声明导航触发器和目标值




.navigationDestination(for:)
将值类型映射为目标视图




NavigationPath
类型擦除的导航路径







NavigationPath
NavigationPath 是一个类型擦除的集合，可以存储不同类型的导航值：


struct AppNavigationView: View {
    @State private var path = NavigationPath()

    var body: some View {
        NavigationStack(path: $path) {
            VStack(spacing: 16) {
                Button("查看水果 → 苹果") {
                    path.append(Category(name: "水果"))
                    path.append(Product(name: "苹果", price: 5.0))
                }

                Button("直接查看海鲜") {
                    path.append(Category(name: "海鲜"))
                }

                Button("重置导航") {
                    path = NavigationPath()
                }
            }
            .navigationTitle("首页")
            .navigationDestination(for: Category.self) { category in
                CategoryView(category: category, path: $path)
            }
            .navigationDestination(for: Product.self) { product in
                ProductView(product: product)
            }
        }
    }
}

struct Category: Hashable {
    let name: String
}

struct Product: Hashable {
    let name: String
    let price: Double
}


提示： NavigationPath 中的值类型必须遵循 Hashable。如果还需要状态恢复（持久化），则必须同时遵循 Codable。






编程式导航
通过操作 NavigationPath，可以实现完全编程式的导航控制：


struct ProgrammaticNav: View {
    @State private var path = NavigationPath()

    var body: some View {
        NavigationStack(path: $path) {
            HomeView(path: $path)
                .navigationDestination(for: Route.self) { route in
                    switch route {
                    case .profile(let userId):
                        ProfileView(userId: userId, path: $path)
                    case .settings:
                        SettingsView()
                    case .detail(let itemId):
                        DetailView(itemId: itemId)
                    }
                }
        }
    }
}

enum Route: Hashable {
    case profile(userId: String)
    case settings
    case detail(itemId: Int)
}

struct HomeView: View {
    @Binding var path: NavigationPath

    var body: some View {
        List {
            Button("我的资料") {
                path.append(Route.profile(userId: "user123"))
            }
            Button("设置") {
                path.append(Route.settings)
            }
            Button("商品详情 #42") {
                path.append(Route.detail(itemId: 42))
            }
        }
        .navigationTitle("首页")
    }
}

struct ProfileView: View {
    let userId: String
    @Binding var path: NavigationPath

    var body: some View {
        VStack {
            Text("用户：\(userId)")
            Button("返回首页") {
                path = NavigationPath()
            }
        }
        .navigationTitle("个人资料")
    }
}


多类型导航目标
一个 NavigationStack 可以注册多个 .navigationDestination：


struct MultiTypeNavigation: View {
    @State private var path = NavigationPath()

    var body: some View {
        NavigationStack(path: $path) {
            List {
                Section("分类") {
                    ForEach(["电子", "服饰", "食品"], id: \.self) { name in
                        NavigationLink(name, value: Category(name: name))
                    }
                }

                Section("热门商品") {
                    ForEach(1...3, id: \.self) { id in
                        NavigationLink("商品 #\(id)", value: Product(name: "商品\(id)", price: Double(id) * 29.9))
                    }
                }
            }
            .navigationTitle("商城")
            .navigationDestination(for: Category.self) { category in
                Text("分类：\(category.name)")
                    .navigationTitle(category.name)
            }
            .navigationDestination(for: Product.self) { product in
                VStack {
                    Text(product.name)
                        .font(.title)
                    Text("¥\(product.price, specifier: "%.1f")")
                        .font(.headline)
                        .foregroundStyle(.red)
                }
                .navigationTitle(product.name)
            }
        }
    }
}


状态恢复
通过让 NavigationPath 支持 Codable，可以实现导航状态的持久化：


struct RestorableNavigation: View {
    @State private var path: NavigationPath = {
        if let data = UserDefaults.standard.data(forKey: "navigationPath"),
           let decoded = try? JSONDecoder().decode(NavigationPath.CodableRepresentation.self, from: data) {
            return NavigationPath(decoded)
        }
        return NavigationPath()
    }()

    var body: some View {
        NavigationStack(path: $path) {
            List(1...20, id: \.self) { item in
                NavigationLink("项目 \(item)", value: item)
            }
            .navigationTitle("可恢复导航")
            .navigationDestination(for: Int.self) { item in
                Text("详情 \(item)")
                    .navigationTitle("项目 \(item)")
            }
        }
        .onChange(of: path) { _, newPath in
            if let representation = newPath.codable,
               let data = try? JSONEncoder().encode(representation) {
                UserDefaults.standard.set(data, forKey: "navigationPath")
            }
        }
    }
}




恢复步骤
说明





编码
path.codable → CodableRepresentation → JSON




存储
UserDefaults / 文件系统




解码
JSON → CodableRepresentation → NavigationPath(codable)




要求
所有路径值类型必须遵循 Codable + Hashable







小结
    

  • NavigationStack 是 iOS 16+ 推荐的导航容器，基于路径管理导航栈
    • 

  • NavigationLink(value:) + .navigationDestination(for:) 实现值到视图的解耦映射
    • 

  • NavigationPath 是类型擦除的导航路径，支持多种 Hashable 值类型
    • 

  • 编程式导航通过 path.append() / path.removeLast() / 清空路径实现
    • 

  • 一个 NavigationStack 可以注册多个 .navigationDestination 处理不同类型
    • 

  • 通过 CodableRepresentation 可以实现导航状态的持久化和恢复
    • 

  • 路径值类型需遵循 Hashable，如需状态恢复还需遵循 Codable
    •
