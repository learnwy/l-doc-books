Part I · iOSSwiftUI 深入实践 简介基础 简介属性包装器概览

属性包装器概览

概述

SwiftUI 的数据驱动模型依赖一系列**属性包装器（Property Wrappers）**来管理状态和数据流。每种属性包装器有不同的所有权语义、生命周期和适用场景。选择正确的属性包装器是 SwiftUI 开发中最关键的决策之一。



@State — 视图私有状态
@State 用于声明视图自己拥有的简单值类型状态。SwiftUI 负责管理其存储，并在值变化时自动触发视图更新。


struct CounterView: View {
    @State private var count = 0

    var body: some View {
        VStack(spacing: 16) {
            Text("当前值：\(count)")
                .font(.title)
            HStack(spacing: 24) {
                Button("减少") { count -= 1 }
                Button("增加") { count += 1 }
            }
        }
    }
}
关键规则：






规则
说明





所有权
视图拥有状态，状态与视图标识绑定




访问级别
应标记为 private




初始化
在声明时提供默认值




生命周期
与视图标识一致，标识不变则状态保留




适用类型
值类型（Int, String, Bool, Array, 自定义 struct）







提示： @State 的存储不在结构体内部，而是由 SwiftUI 框架在外部堆上管理。即使视图结构体被重新创建，只要视图标识不变，状态就不会丢失。






@Binding — 双向数据绑定
@Binding 创建对其他数据源的引用，实现父子视图之间的双向数据传递。它本身不拥有数据。


struct ToggleCard: View {
    let title: String
    @Binding var isOn: Bool

    var body: some View {
        HStack {
            Text(title)
            Spacer()
            Toggle("", isOn: $isOn)
                .labelsHidden()
        }
        .padding()
        .background(.regularMaterial)
        .clipShape(RoundedRectangle(cornerRadius: 8))
    }
}

struct SettingsView: View {
    @State private var darkMode = false
    @State private var notifications = true

    var body: some View {
        VStack(spacing: 12) {
            ToggleCard(title: "深色模式", isOn: $darkMode)
            ToggleCard(title: "通知推送", isOn: $notifications)
        }
        .padding()
    }
}
使用 $ 前缀将 @State 转换为 Binding。也可以创建自定义 Binding：


let customBinding = Binding<Bool>(
    get: { preferences.darkMode },
    set: { newValue in
        preferences.darkMode = newValue
        applyTheme(dark: newValue)
    }
)


@StateObject — 引用类型的所有者
@StateObject 用于在视图中创建并拥有 ObservableObject 的实例。SwiftUI 保证在视图的整个生命周期内只创建一次。


class TimerModel: ObservableObject {
    @Published var secondsElapsed = 0
    private var timer: Timer?

    func start() {
        timer = Timer.scheduledTimer(withTimeInterval: 1, repeats: true) { [weak self] _ in
            self?.secondsElapsed += 1
        }
    }

    func stop() {
        timer?.invalidate()
        timer = nil
    }

    deinit {
        stop()
    }
}

struct TimerView: View {
    @StateObject private var model = TimerModel()

    var body: some View {
        VStack(spacing: 16) {
            Text("已过 \(model.secondsElapsed) 秒")
                .font(.title)
                .monospacedDigit()
            HStack(spacing: 24) {
                Button("开始") { model.start() }
                Button("停止") { model.stop() }
            }
        }
    }
}


提示： @StateObject 的初始化闭包只在视图首次出现时执行一次。即使父视图的 body 被多次调用，也不会重复创建对象。






@ObservedObject — 引用类型的观察者
@ObservedObject 用于观察从外部传入的 ObservableObject。它不拥有对象的生命周期。


struct TimerDisplay: View {
    @ObservedObject var model: TimerModel

    var body: some View {
        Text("计时：\(model.secondsElapsed)s")
            .font(.headline)
    }
}

struct ParentView: View {
    @StateObject private var timer = TimerModel()

    var body: some View {
        VStack {
            TimerDisplay(model: timer)
            Button("开始") { timer.start() }
        }
    }
}

@EnvironmentObject — 环境注入
@EnvironmentObject 通过环境隐式传递共享数据，无需逐层手动传递：


class AppSettings: ObservableObject {
    @Published var fontSize: CGFloat = 16
    @Published var accentColor: Color = .blue
    @Published var username: String = "用户"
}

struct RootView: View {
    @StateObject private var settings = AppSettings()

    var body: some View {
        NavigationStack {
            ContentView()
        }
        .environmentObject(settings)
    }
}

struct ContentView: View {
    @EnvironmentObject var settings: AppSettings

    var body: some View {
        VStack {
            Text("你好，\(settings.username)")
                .font(.system(size: settings.fontSize))
            NavigationLink("设置") {
                SettingsDetailView()
            }
        }
    }
}

struct SettingsDetailView: View {
    @EnvironmentObject var settings: AppSettings

    var body: some View {
        Form {
            Stepper("字体大小：\(Int(settings.fontSize))", value: $settings.fontSize, in: 12...32)
            TextField("用户名", text: $settings.username)
        }
    }
}


提示： 如果视图访问了 @EnvironmentObject 但祖先视图未注入对应类型，应用会在运行时崩溃。务必确保在视图层级中正确调用 .environmentObject()。






@Environment — 系统环境值
@Environment 读取 SwiftUI 提供的系统级环境值：


struct AdaptiveView: View {
    @Environment(\.colorScheme) var colorScheme
    @Environment(\.horizontalSizeClass) var sizeClass
    @Environment(\.dismiss) var dismiss

    var body: some View {
        VStack {
            Text("当前模式：\(colorScheme == .dark ? "深色" : "浅色")")
            Text("尺寸类别：\(sizeClass == .compact ? "紧凑" : "常规")")
            Button("关闭") { dismiss() }
        }
    }
}

小结
    

  • @State 管理视图私有的值类型状态，应标记为 private
    • 

  • @Binding 创建双向引用，使用 $ 前缀从 @State 获取
    • 

  • @StateObject 创建并拥有 ObservableObject，生命周期与视图绑定
    • 

  • @ObservedObject 观察外部传入的 ObservableObject，不拥有其生命周期
    • 

  • 区分 @StateObject 和 @ObservedObject 的关键是谁负责创建对象
    • 

  • @EnvironmentObject 通过环境隐式传递共享数据，避免逐层手动传递
    • 

  • @Environment 读取系统环境值如 colorScheme、sizeClass 等
    • 

  • 选择正确的属性包装器是保证数据流正确和避免状态丢失的关键
