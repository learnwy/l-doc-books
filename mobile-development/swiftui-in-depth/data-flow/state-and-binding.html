Part I · iOSSwiftUI 深入实践 简介数据流 简介State 与 Binding

State 与 Binding

概述

@State 和 @Binding 是 SwiftUI 数据流的基础。@State 代表单一数据源（Single Source of Truth），而 @Binding 则是对该数据源的派生引用。掌握两者的深层机制——包括派生 Binding、常量 Binding 和投影值——是构建可维护 SwiftUI 应用的关键。



单一数据源原则
SwiftUI 数据流的核心原则是每条数据只有一个所有者。其他需要访问该数据的视图通过 Binding 获取引用：


struct ParentView: View {
    @State private var temperature: Double = 22.0

    var body: some View {
        VStack(spacing: 20) {
            TemperatureDisplay(value: temperature)
            TemperatureSlider(value: $temperature)
            TemperatureButtons(value: $temperature)
        }
        .padding()
    }
}

struct TemperatureDisplay: View {
    let value: Double

    var body: some View {
        Text("\(value, specifier: "%.1f")°C")
            .font(.system(size: 48, weight: .bold, design: .rounded))
            .foregroundStyle(value > 25 ? .red : .blue)
    }
}

struct TemperatureSlider: View {
    @Binding var value: Double

    var body: some View {
        VStack {
            Slider(value: $value, in: 10...40, step: 0.5)
            Text("滑块调节")
                .font(.caption)
                .foregroundStyle(.secondary)
        }
    }
}

struct TemperatureButtons: View {
    @Binding var value: Double

    var body: some View {
        HStack(spacing: 24) {
            Button("降低") { value -= 1 }
            Button("升高") { value += 1 }
        }
    }
}

派生 Binding (Derived Bindings)
可以从现有 Binding 派生出新的 Binding，添加验证、转换等逻辑：


struct ValidatedInput: View {
    @State private var rawInput = ""

    var body: some View {
        let validatedBinding = Binding<String>(
            get: { rawInput },
            set: { newValue in
                rawInput = newValue.filter { $0.isNumber }
            }
        )

        VStack(spacing: 12) {
            TextField("仅允许数字", text: validatedBinding)
                .textFieldStyle(.roundedBorder)
                .keyboardType(.numberPad)

            Text("实际值：\(rawInput)")
                .font(.caption)
                .foregroundStyle(.secondary)
        }
        .padding()
    }
}
集合的元素 Binding
SwiftUI 支持对数组元素的 Binding：


struct TodoListView: View {
    @State private var items: [TodoItem] = [
        TodoItem(title: "学习 SwiftUI", isDone: false),
        TodoItem(title: "写博客", isDone: true),
        TodoItem(title: "运动", isDone: false)
    ]

    var body: some View {
        List($items) { $item in
            HStack {
                Toggle("", isOn: $item.isDone)
                    .labelsHidden()
                Text(item.title)
                    .strikethrough(item.isDone)
            }
        }
    }
}

struct TodoItem: Identifiable {
    let id = UUID()
    var title: String
    var isDone: Bool
}


常量 Binding
在 Preview 或测试中，可以使用 .constant() 创建只读 Binding：


#Preview("开关 - 开启状态") {
    ToggleCard(title: "深色模式", isOn: .constant(true))
}

#Preview("开关 - 关闭状态") {
    ToggleCard(title: "深色模式", isOn: .constant(false))
}


提示： .constant() 创建的 Binding 是只读的——写入操作会被静默忽略。仅用于预览和测试，不要在生产代码中作为占位符。






投影值 (Projected Value)
@State 的投影值（通过 $ 访问）是一个 Binding<T>。理解投影值对于封装自定义属性包装器很重要：


struct FormView: View {
    @State private var user = UserProfile(
        name: "张三",
        email: "zhang@example.com",
        age: 28
    )

    var body: some View {
        Form {
            Section("基本信息") {
                TextField("姓名", text: $user.name)
                TextField("邮箱", text: $user.email)
                Stepper("年龄：\(user.age)", value: $user.age, in: 0...120)
            }

            Section("预览") {
                Text("姓名：\(user.name)")
                Text("邮箱：\(user.email)")
                Text("年龄：\(user.age)")
            }
        }
    }
}

struct UserProfile {
    var name: String
    var email: String
    var age: Int
}
嵌套结构体的 Binding
$ 前缀可以逐层穿透嵌套结构体的属性：


struct Address {
    var street: String
    var city: String
    var zipCode: String
}

struct Person {
    var name: String
    var address: Address
}

struct PersonEditor: View {
    @State private var person = Person(
        name: "李四",
        address: Address(street: "中关村", city: "北京", zipCode: "100080")
    )

    var body: some View {
        Form {
            TextField("姓名", text: $person.name)
            TextField("街道", text: $person.address.street)
            TextField("城市", text: $person.address.city)
            TextField("邮编", text: $person.address.zipCode)
        }
    }
}


@State 的初始化时机
@State 的初始值只在视图首次创建时使用。如果需要从外部传入初始值：


struct EditableText: View {
    @State private var text: String

    init(initialText: String) {
        _text = State(initialValue: initialText)
    }

    var body: some View {
        TextField("编辑", text: $text)
    }
}

小结
    

  • @State 代表单一数据源，视图拥有该状态的所有权
    • 

  • @Binding 是对外部状态的双向引用，通过 $ 前缀获取
    • 

  • 派生 Binding 可添加验证、转换等自定义逻辑
    • 

  • List($items) { $item in ... } 支持对集合元素的直接 Binding
    • 

  • .constant() 创建只读 Binding，适用于 Preview 和测试
    • 

  • $ 投影值可以逐层穿透嵌套结构体的属性
    • 

  • @State 的初始值只在视图首次创建时读取，后续外部传入的值不会覆盖已有状态
