Observation 框架

概述

iOS 17 / macOS 14 引入了全新的 Observation 框架，通过 @Observable 宏替代了传统的 ObservableObject 协议。新框架实现了属性级别的精细追踪，大幅减少不必要的视图更新。@Bindable 替代了 @ObservedObject 的 Binding 能力，而 withObservationTracking 提供了底层的观察 API。



@Observable 宏
@Observable 宏通过编译期代码生成，自动为类的存储属性添加观察能力：


import Observation

@Observable
class UserProfile {
    var name = "张三"
    var email = "zhang@example.com"
    var avatarURL: URL?
    var loginCount = 0
}
宏展开后，编译器会为每个存储属性生成 getter/setter 拦截代码，实现属性级别的变化追踪。


与 ObservableObject 的对比
class OldModel: ObservableObject {
    @Published var name = ""
    @Published var email = ""
    @Published var age = 0
}

在视图中使用
@Observable 对象在视图中的使用更加自然，不需要特殊的属性包装器：


@Observable
class CounterModel {
    var count = 0
    var label = "计数器"

    func increment() { count += 1 }
    func decrement() { count -= 1 }
}

struct CounterView: View {
    @State private var model = CounterModel()

    var body: some View {
        VStack(spacing: 16) {
            Text(model.label)
                .font(.headline)
            Text("\(model.count)")
                .font(.system(size: 64, weight: .bold, design: .rounded))

            HStack(spacing: 24) {
                Button("减少") { model.decrement() }
                Button("增加") { model.increment() }
            }
        }
    }
}


提示： 对于 @Observable 对象，使用 @State 表示视图拥有该对象。不再需要 @StateObject。作为参数传入时，直接使用普通 let 或 var 属性即可。






属性级别追踪的优势
@Observable 实现了精确的属性级别依赖追踪：


@Observable
class DashboardModel {
    var userName = "用户"
    var notificationCount = 0
    var lastLoginDate = Date()
}

struct HeaderView: View {
    let model: DashboardModel

    var body: some View {
        Text("欢迎，\(model.userName)")
            .font(.headline)
    }
}

struct BadgeView: View {
    let model: DashboardModel

    var body: some View {
        Image(systemName: "bell")
            .overlay {
                if model.notificationCount > 0 {
                    Text("\(model.notificationCount)")
                        .font(.caption2)
                        .padding(4)
                        .background(.red)
                        .foregroundStyle(.white)
                        .clipShape(Circle())
                        .offset(x: 10, y: -10)
                }
            }
    }
}
在 ObservableObject 中，修改 notificationCount 会导致所有观察该对象的视图更新。而 @Observable 只更新实际读取了 notificationCount 的视图。




@Bindable
@Bindable 用于从 @Observable 对象中创建 Binding：


@Observable
class FormModel {
    var title = ""
    var description = ""
    var priority: Priority = .medium
    var dueDate = Date()

    enum Priority: String, CaseIterable {
        case low = "低"
        case medium = "中"
        case high = "高"
    }
}

struct FormView: View {
    @Bindable var model: FormModel

    var body: some View {
        Form {
            TextField("标题", text: $model.title)
            TextField("描述", text: $model.description)

            Picker("优先级", selection: $model.priority) {
                ForEach(FormModel.Priority.allCases, id: \.self) { priority in
                    Text(priority.rawValue).tag(priority)
                }
            }

            DatePicker("截止日期", selection: $model.dueDate, displayedComponents: .date)
        }
    }
}

struct ParentView: View {
    @State private var formModel = FormModel()

    var body: some View {
        NavigationStack {
            FormView(model: formModel)
                .navigationTitle("新建任务")
        }
    }
}

withObservationTracking
withObservationTracking 是 Observation 框架的底层 API，允许在非 SwiftUI 上下文中使用观察：


@Observable
class DataSource {
    var items: [String] = []
    var isLoading = false
}

func observeChanges() {
    let source = DataSource()

    withObservationTracking {
        print("当前项目数：\(source.items.count)")
        print("加载状态：\(source.isLoading)")
    } onChange: {
        print("items 或 isLoading 发生了变化")
    }
}


提示： onChange 回调只会触发一次。如果需要持续观察，需要在回调中重新调用 withObservationTracking。

嵌套对象自动追踪
@Observable 的一大优势是自动追踪嵌套对象的属性变化：


@Observable
class Address {
    var street = ""
    var city = ""
}

@Observable
class Person {
    var name = ""
    var address = Address()
}

struct AddressView: View {
    @Bindable var person: Person

    var body: some View {
        Form {
            TextField("姓名", text: $person.name)
            TextField("街道", text: $person.address.street)
            TextField("城市", text: $person.address.city)
        }
    }
}
修改 person.address.city 会正确触发依赖该属性的视图更新，无需手动转发通知。




小结
    

  • @Observable 宏实现属性级别追踪，只更新读取了变化属性的视图
    • 

  • 无需 @Published 标注，所有存储属性自动可观察
    • 

  • @State 替代 @StateObject 表示视图拥有的 @Observable 对象
    • 

  • @Bindable 替代 @ObservedObject 用于创建 Binding
    • 

  • withObservationTracking 提供非 SwiftUI 场景的底层观察 API
    • 

  • 嵌套 @Observable 对象的属性变化自动追踪，解决了 ObservableObject 的痛点
    • 

  • 迁移到 Observation 框架需要 iOS 17+，可与 ObservableObject 混用实现渐进式迁移
