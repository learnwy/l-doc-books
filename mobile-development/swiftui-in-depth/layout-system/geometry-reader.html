GeometryReader 几何读取器

概述

GeometryReader 是 SwiftUI 中获取视图几何信息（尺寸、位置、坐标空间）的核心工具。它通过提供 GeometryProxy 让子视图可以根据父容器的尺寸做出自适应布局决策。除了基本用法外，SwiftUI 还提供了 Preferences 和 Anchor Preferences 机制用于从子视图向父视图传递几何数据。



基本用法
GeometryReader 接收一个闭包，参数是 GeometryProxy：


struct SizeAwareView: View {
    var body: some View {
        GeometryReader { geometry in
            VStack {
                Text("宽度：\(Int(geometry.size.width))")
                Text("高度：\(Int(geometry.size.height))")

                RoundedRectangle(cornerRadius: 12)
                    .frame(
                        width: geometry.size.width * 0.8,
                        height: geometry.size.height * 0.3
                    )
                    .foregroundStyle(.blue)
            }
            .frame(maxWidth: .infinity, maxHeight: .infinity)
        }
    }
}




GeometryProxy 属性
类型
说明





size
CGSize
容器提供给 GeometryReader 的尺寸




safeAreaInsets
EdgeInsets
安全区域边距




frame(in:)
CGRect
在指定坐标空间中的 frame







提示： GeometryReader 会占据所有可用空间（类似 Color.clear），并将其子视图默认放置在左上角。使用时通常需要手动居中子视图。






坐标空间 (Coordinate Spaces)
SwiftUI 提供多种坐标空间来获取视图的位置信息：


struct CoordinateSpaceDemo: View {
    var body: some View {
        ScrollView {
            VStack(spacing: 20) {
                ForEach(0..<20) { index in
                    GeometryReader { geometry in
                        let globalY = geometry.frame(in: .global).minY
                        let localY = geometry.frame(in: .local).minY

                        Text("Item \(index)")
                            .frame(maxWidth: .infinity)
                            .padding()
                            .background(
                                RoundedRectangle(cornerRadius: 8)
                                    .foregroundStyle(.blue.opacity(
                                        max(0, min(1, globalY / 500))
                                    ))
                            )
                    }
                    .frame(height: 60)
                }
            }
            .padding()
        }
    }
}
自定义坐标空间
使用 .coordinateSpace(name:) 定义命名坐标空间：


struct CustomSpaceView: View {
    var body: some View {
        ScrollView {
            VStack {
                ForEach(0..<10) { index in
                    ItemView(index: index)
                }
            }
        }
        .coordinateSpace(name: "scroll")
    }
}

struct ItemView: View {
    let index: Int

    var body: some View {
        GeometryReader { geometry in
            let scrollOffset = geometry.frame(in: .named("scroll")).minY
            Text("第 \(index) 项 — 偏移: \(Int(scrollOffset))")
                .frame(maxWidth: .infinity)
                .padding()
                .background(.regularMaterial)
                .scaleEffect(max(0.8, min(1, scrollOffset / 200)))
        }
        .frame(height: 80)
    }
}


Preferences 机制
Preferences 是从子视图向父视图向上传递数据的机制，与 Environment（向下传递）方向相反：


struct SizePreferenceKey: PreferenceKey {
    static var defaultValue: CGSize = .zero
    static func reduce(value: inout CGSize, nextValue: () -> CGSize) {
        value = nextValue()
    }
}

struct MeasuredView: View {
    @State private var childSize: CGSize = .zero

    var body: some View {
        VStack {
            Text("子视图尺寸：\(Int(childSize.width)) × \(Int(childSize.height))")
                .font(.headline)

            Text("这是需要测量尺寸的内容\n可能包含多行文字")
                .padding()
                .background(
                    GeometryReader { geometry in
                        Color.clear.preference(
                            key: SizePreferenceKey.self,
                            value: geometry.size
                        )
                    }
                )
                .onPreferenceChange(SizePreferenceKey.self) { size in
                    childSize = size
                }
        }
    }
}


Anchor Preferences
Anchor Preferences 是更高级的机制，可以在不同坐标空间之间传递几何锚点：


struct BoundsPreferenceKey: PreferenceKey {
    static var defaultValue: [String: Anchor<CGRect>] = [:]
    static func reduce(value: inout [String: Anchor<CGRect>], nextValue: () -> [String: Anchor<CGRect>]) {
        value.merge(nextValue()) { $1 }
    }
}

struct HighlightableMenu: View {
    @State private var selectedItem = "首页"
    let items = ["首页", "发现", "消息", "我的"]

    var body: some View {
        HStack(spacing: 0) {
            ForEach(items, id: \.self) { item in
                Text(item)
                    .padding(.horizontal, 16)
                    .padding(.vertical, 8)
                    .anchorPreference(
                        key: BoundsPreferenceKey.self,
                        value: .bounds
                    ) { [item: $0] }
                    .onTapGesture { selectedItem = item }
            }
        }
        .overlayPreferenceValue(BoundsPreferenceKey.self) { preferences in
            GeometryReader { geometry in
                if let anchor = preferences[selectedItem] {
                    let rect = geometry[anchor]
                    RoundedRectangle(cornerRadius: 8)
                        .foregroundStyle(.blue.opacity(0.2))
                        .frame(width: rect.width, height: rect.height)
                        .offset(x: rect.minX, y: rect.minY)
                        .animation(.spring(response: 0.3), value: selectedItem)
                }
            }
        }
    }
}


提示： Anchor Preferences 的优势在于锚点是延迟解析的——只有在 overlayPreferenceValue 或 backgroundPreferenceValue 中通过 GeometryProxy 访问时才会转换为具体坐标。






尺寸上报的封装
实际开发中，常将尺寸上报封装为可复用修饰器：


struct SizeReaderModifier: ViewModifier {
    @Binding var size: CGSize

    func body(content: Content) -> some View {
        content.background(
            GeometryReader { geometry in
                Color.clear
                    .onAppear { size = geometry.size }
                    .onChange(of: geometry.size) { _, newSize in
                        size = newSize
                    }
            }
        )
    }
}

extension View {
    func readSize(into binding: Binding<CGSize>) -> some View {
        modifier(SizeReaderModifier(size: binding))
    }
}

struct UsageExample: View {
    @State private var textSize: CGSize = .zero

    var body: some View {
        VStack {
            Text("自适应内容")
                .padding()
                .readSize(into: $textSize)

            Text("文本尺寸：\(Int(textSize.width)) × \(Int(textSize.height))")
                .font(.caption)
                .foregroundStyle(.secondary)
        }
    }
}


GeometryReader 的注意事项




注意点
说明





贪婪布局
GeometryReader 占据所有可用空间




性能影响
频繁读取几何信息可能导致布局循环




子视图对齐
默认左上角对齐，需手动居中




避免嵌套
多层嵌套 GeometryReader 会造成布局混乱




替代方案
iOS 17+ 可考虑 .containerRelativeFrame()







小结
    

  • GeometryReader 通过 GeometryProxy 提供容器的尺寸和坐标信息
    • 

  • 坐标空间分为 global、local 和 named 三种
    • 

  • Preferences 是从子视图向父视图传递数据的机制
    • 

  • Anchor Preferences 支持延迟解析的跨坐标空间几何锚点
    • 

  • 建议将尺寸读取封装为可复用的 ViewModifier
    • 

  • GeometryReader 会贪婪占据空间，需注意对布局的影响
    • 

  • iOS 17+ 的 .containerRelativeFrame() 可替代部分 GeometryReader 场景
