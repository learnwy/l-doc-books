Part I · iOSSwiftUI 深入实践 简介布局系统 简介对齐与间距

对齐与间距

概述

SwiftUI 的对齐系统通过 Alignment、HorizontalAlignment、VerticalAlignment 以及自定义对齐指南（Alignment Guide）提供了精细的布局控制能力。理解对齐与间距的工作机制，能够在不使用 GeometryReader 的情况下实现复杂的视觉对齐效果。



内置对齐方式
SwiftUI 容器通过 alignment 参数控制子视图的对齐：


struct AlignmentDemo: View {
    var body: some View {
        VStack(spacing: 20) {
            HStack(alignment: .top, spacing: 16) {
                Text("短")
                    .padding()
                    .background(.blue.opacity(0.3))
                Text("这是一段\n较长的文字\n有三行")
                    .padding()
                    .background(.green.opacity(0.3))
            }

            HStack(alignment: .firstTextBaseline, spacing: 16) {
                Text("大标题")
                    .font(.largeTitle)
                Text("正文")
                    .font(.body)
                Text("小字")
                    .font(.caption)
            }
        }
    }
}

alignmentGuide 修饰器
alignmentGuide 允许精确调整单个视图在对齐维度上的参考点：


struct CustomAlignmentDemo: View {
    var body: some View {
        VStack(alignment: .leading) {
            Text("标准对齐")
                .padding()
                .background(.blue.opacity(0.3))

            Text("偏移 20pt")
                .padding()
                .background(.green.opacity(0.3))
                .alignmentGuide(.leading) { dimension in
                    dimension[.leading] - 20
                }

            Text("居中对齐到 leading")
                .padding()
                .background(.orange.opacity(0.3))
                .alignmentGuide(.leading) { dimension in
                    dimension.width / 2
                }
        }
    }
}
ViewDimensions 参数提供了视图的尺寸信息和内置对齐值：


struct DimensionExample: View {
    var body: some View {
        HStack(alignment: .center) {
            Circle()
                .frame(width: 40, height: 40)
                .foregroundStyle(.red)

            Text("偏移对齐")
                .padding()
                .background(.blue.opacity(0.2))
                .alignmentGuide(VerticalAlignment.center) { d in
                    d[.top] + 10
                }
        }
    }
}


自定义对齐标识
当内置对齐方式不够用时，可以创建自定义对齐：


extension VerticalAlignment {
    private enum CustomCenter: AlignmentID {
        static func defaultValue(in context: ViewDimensions) -> CGFloat {
            context[VerticalAlignment.center]
        }
    }

    static let customCenter = VerticalAlignment(CustomCenter.self)
}

struct CrossAlignmentView: View {
    var body: some View {
        HStack(alignment: .customCenter, spacing: 20) {
            VStack {
                Text("标题")
                    .font(.headline)
                Text("对齐到这里")
                    .font(.body)
                    .alignmentGuide(.customCenter) { d in
                        d[VerticalAlignment.center]
                    }
                Text("描述文字")
                    .font(.caption)
            }
            .padding()
            .background(.blue.opacity(0.1))

            Image(systemName: "arrow.right")
                .font(.title)
                .alignmentGuide(.customCenter) { d in
                    d[VerticalAlignment.center]
                }

            VStack {
                Text("目标对齐行")
                    .alignmentGuide(.customCenter) { d in
                        d[VerticalAlignment.center]
                    }
                Text("其他内容")
                    .font(.caption)
            }
            .padding()
            .background(.green.opacity(0.1))
        }
    }
}


间距控制
Stack 间距
SwiftUI 的 Stack 容器默认使用平台标准间距。可以通过 spacing 参数自定义：


struct SpacingDemo: View {
    var body: some View {
        VStack(spacing: 0) {
            Text("零间距 Item 1")
                .frame(maxWidth: .infinity)
                .padding()
                .background(.blue.opacity(0.2))

            Text("零间距 Item 2")
                .frame(maxWidth: .infinity)
                .padding()
                .background(.green.opacity(0.2))
        }
    }
}
Spacer 与灵活间距
struct SpacerDemo: View {
    var body: some View {
        HStack {
            Text("左侧")
            Spacer()
            Text("右侧")
        }
        .padding()

        HStack {
            Text("左")
            Spacer(minLength: 50)
            Text("中")
            Spacer(minLength: 50)
            Text("右")
        }
        .padding()
    }
}


ViewThatFits
iOS 16+ 引入的 ViewThatFits 会自动选择第一个能够适配可用空间的视图：


struct AdaptiveButton: View {
    var body: some View {
        ViewThatFits {
            HStack {
                Image(systemName: "square.and.arrow.up")
                Text("分享到社交媒体")
            }
            .padding()
            .background(.blue)
            .foregroundStyle(.white)
            .clipShape(Capsule())

            HStack {
                Image(systemName: "square.and.arrow.up")
                Text("分享")
            }
            .padding()
            .background(.blue)
            .foregroundStyle(.white)
            .clipShape(Capsule())

            Image(systemName: "square.and.arrow.up")
                .padding()
                .background(.blue)
                .foregroundStyle(.white)
                .clipShape(Circle())
        }
    }
}


提示： ViewThatFits 按顺序测试每个子视图，选择第一个理想尺寸不超过可用空间的视图。它不会缩放视图，而是选择替代方案。




ViewThatFits 与轴向限制
可以指定只在某个轴向上进行适配检测：


struct VerticalAdaptive: View {
    var body: some View {
        ViewThatFits(in: .vertical) {
            VStack(spacing: 12) {
                DetailCard()
                StatisticsCard()
                ActionButtons()
            }

            ScrollView {
                VStack(spacing: 12) {
                    DetailCard()
                    StatisticsCard()
                    ActionButtons()
                }
            }
        }
    }
}


padding 的精细控制
struct PaddingVariants: View {
    var body: some View {
        VStack(spacing: 16) {
            Text("四周均匀 padding")
                .padding()
                .background(.blue.opacity(0.2))

            Text("水平方向 padding")
                .padding(.horizontal, 24)
                .background(.green.opacity(0.2))

            Text("特定边 padding")
                .padding(.leading, 32)
                .padding(.trailing, 8)
                .padding(.vertical, 12)
                .background(.orange.opacity(0.2))

            Text("EdgeInsets 精确控制")
                .padding(EdgeInsets(top: 8, leading: 16, bottom: 24, trailing: 16))
                .background(.purple.opacity(0.2))
        }
    }
}


小结
    

  • 内置对齐包括 .leading、.center、.trailing 和 .firstTextBaseline 等
    • 

  • alignmentGuide 修饰器可以精确调整视图在对齐维度上的参考点位置
    • 

  • 自定义 AlignmentID 可以实现跨容器的对齐效果
    • 

  • Stack 默认使用平台标准间距，spacing: 0 可消除间距
    • 

  • Spacer 提供灵活的弹性间距，支持 minLength 约束
    • 

  • ViewThatFits（iOS 16+）自动选择第一个能适配可用空间的视图方案
    • 

  • padding 支持四周均匀、单边、EdgeInsets 等多种精细控制方式
    •
