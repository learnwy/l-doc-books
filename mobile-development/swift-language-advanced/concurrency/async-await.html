async/await 异步等待

概述

Swift 5.5 引入了 async/await（SE-0296），将异步编程从回调嵌套（callback hell）转变为线性的、类似同步代码的编写方式。async/await 是 Swift 并发模型的基础，配合 async sequences、throwing async 和 continuation bridge，构成了完整的异步编程体系。

异步函数基础
使用 async 关键字标记异步函数，使用 await 在调用点挂起：


func fetchUser(id: String) async throws -> User {
    let url = URL(string: "https://api.example.com/users/\(id)")!
    let (data, response) = try await URLSession.shared.data(from: url)

    guard let httpResponse = response as? HTTPURLResponse,
          httpResponse.statusCode == 200 else {
        throw NetworkError.invalidResponse
    }

    return try JSONDecoder().decode(User.self, from: data)
}

func displayUser() async {
    do {
        let user = try await fetchUser(id: "123")
        print(user.name)
    } catch {
        print("Failed: \(error)")
    }
}
await 是一个挂起点（suspension point），线程在此处可以被释放去执行其他任务，而不是阻塞等待。




提示： async 函数只能从 async 上下文中调用。入口点可以是 Task { } 闭包、@main struct 的 static func main() async、或 SwiftUI 的 .task modifier。






结构化任务（Structured Tasks）
Task 是启动异步工作的基本单位：


Task {
    let user = try await fetchUser(id: "123")
    await MainActor.run {
        nameLabel.text = user.name
    }
}

Task.detached(priority: .background) {
    await performHeavyWork()
}

Async Sequences
AsyncSequence 协议是 Sequence 的异步版本，支持异步产生一系列值：


func fetchPages(url: URL) -> AsyncStream<Page> {
    AsyncStream { continuation in
        Task {
            var nextURL: URL? = url
            while let currentURL = nextURL {
                let (page, next) = try await fetchPage(from: currentURL)
                continuation.yield(page)
                nextURL = next
            }
            continuation.finish()
        }
    }
}

for await page in fetchPages(url: startURL) {
    print("Loaded page: \(page.title)")
}
常用的 async sequence 操作：


let numbers = AsyncStream<Int> { continuation in
    for i in 1...100 {
        continuation.yield(i)
    }
    continuation.finish()
}

let evenNumbers = numbers.filter { $0.isMultiple(of: 2) }
let doubled = evenNumbers.map { $0 * 2 }
let firstTen = doubled.prefix(10)

for await value in firstTen {
    print(value)
}


Throwing Async
异步函数可以同时是 async 和 throws 的，调用时需要 try await：


func loadConfiguration() async throws -> Config {
    let data = try await fetchRemoteConfig()
    let config = try JSONDecoder().decode(Config.self, from: data)
    try await validateConfig(config)
    return config
}

func initializeApp() async {
    do {
        let config = try await loadConfiguration()
        try await setupDatabase(with: config)
        try await preloadCache(with: config)
    } catch {
        await fallbackToDefaults()
    }
}
关键字顺序规则：声明时 async throws，调用时 try await：


func example() async throws -> Data    // 声明
let data = try await example()          // 调用


Continuation Bridge
Continuation 是将传统回调 API 桥接到 async/await 的机制：


func fetchImage(url: URL) async throws -> UIImage {
    try await withCheckedThrowingContinuation { continuation in
        URLSession.shared.dataTask(with: url) { data, _, error in
            if let error = error {
                continuation.resume(throwing: error)
                return
            }
            guard let data = data, let image = UIImage(data: data) else {
                continuation.resume(throwing: ImageError.invalidData)
                return
            }
            continuation.resume(returning: image)
        }.resume()
    }
}




Continuation 类型
用途
安全检查





withCheckedContinuation
非抛出
运行时检查 resume 次数




withCheckedThrowingContinuation
可抛出
运行时检查 resume 次数




withUnsafeContinuation
非抛出
无检查（更快）




withUnsafeThrowingContinuation
可抛出
无检查（更快）







提示： Continuation 必须恰好 resume 一次。不调用会导致任务永久挂起，调用多次会导致未定义行为。Checked 版本会在违规时触发运行时错误。






异步属性和下标
Swift 支持异步计算属性（只读）：


struct RemoteConfig {
    var endpoint: URL

    var latestVersion: String {
        get async throws {
            let (data, _) = try await URLSession.shared.data(from: endpoint)
            return String(data: data, encoding: .utf8) ?? "unknown"
        }
    }
}

let config = RemoteConfig(endpoint: versionURL)
let version = try await config.latestVersion

小结
    

  • async/await 将回调式异步代码转为线性编写，await 标记挂起点
    • 

  • 结构化 Task 继承当前 actor 上下文；Task.detached 创建独立任务
    • 

  • AsyncSequence 是异步版本的 Sequence，支持 for await 遍历和链式操作
    • 

  • 声明顺序 async throws，调用顺序 try await
    • 

  • Continuation 桥接传统回调 API，必须恰好 resume 一次
    • 

  • 异步函数在挂起时释放线程，不会阻塞，由运行时调度恢复
    •
