宏基础

概述

Swift 5.9 引入的宏（Macros）系统为语言带来了编译期元编程能力。宏可以在编译阶段生成代码，消除样板代码，同时保持完整的类型安全和编译器检查。与 C 预处理器宏不同，Swift 宏是类型安全的、可调试的，并且通过独立的编译器插件进程运行。

宏的两大类别
Swift 宏分为**独立宏（Freestanding Macros）和附加宏（Attached Macros）**两类，二者在语法和作用方式上有显著区别：






类别
语法前缀
作用方式
典型用例





独立宏
#macroName
独立出现，生成表达式或声明
#stringify、#warning




附加宏
@MacroName
附加到已有声明上
@Observable、@CodingKeys





独立宏使用井号 # 作为前缀，可以出现在表达式或声明的位置：


let (value, code) = #stringify(2 + 3)
// value = 5, code = "2 + 3"

#warning("This feature is incomplete")
附加宏使用 @ 作为前缀，附着在类型、属性或函数等声明上：


@Observable
class UserSettings {
    var username = ""
    var theme = "light"
}


宏角色
每个宏声明时必须指定一个或多个角色（Role），角色决定了宏能在什么位置使用、能生成什么类型的代码：

一个宏可以同时扮演多个角色。例如 @Observable 同时使用 @attached(member) 和 @attached(memberAttribute) 和 @attached(extension)：


@attached(member, names: named(_$observationRegistrar), named(access), named(withMutation))
@attached(memberAttribute)
@attached(extension, conformances: Observable)
public macro Observable() = #externalMacro(module: "ObservationMacros", type: "ObservableMacro")


SwiftSyntax 框架
宏的实现依赖 SwiftSyntax 框架，它提供了 Swift 源代码的语法树（Syntax Tree）表示。宏接收语法树节点作为输入，返回新的语法树节点作为展开结果。


SwiftSyntax 的核心类型：


import SwiftSyntax
import SwiftSyntaxMacros

public struct StringifyMacro: ExpressionMacro {
    public static func expansion(
        of node: some FreestandingMacroExpansionSyntax,
        in context: some MacroExpansionContext
    ) -> ExprSyntax {
        guard let argument = node.arguments.first?.expression else {
            fatalError("compiler bug: no argument")
        }
        return "(\(argument), \(literal: argument.description))"
    }
}

编译器插件架构
Swift 宏通过**编译器插件（Compiler Plugin）**机制运行。宏的实现代码编译为独立的可执行程序，编译器通过进程间通信调用它：


这种沙箱架构的优势：


    

  • 安全隔离：宏代码在独立进程中运行，无法访问编译器内部状态
    • 

  • 崩溃隔离：宏进程崩溃不会导致编译器崩溃
    • 

  • 可调试：可以对宏进程附加调试器
    • 



宏包使用 Swift Package Manager 的 .macro 目标类型：


// Package.swift
let package = Package(
    name: "MyMacros",
    dependencies: [
        .package(url: "https://github.com/swiftlang/swift-syntax.git", from: "600.0.0"),
    ],
    targets: [
        .macro(
            name: "MyMacrosMacros",
            dependencies: [
                .product(name: "SwiftSyntaxMacros", package: "swift-syntax"),
                .product(name: "SwiftCompilerPlugin", package: "swift-syntax"),
            ]
        ),
        .target(name: "MyMacros", dependencies: ["MyMacrosMacros"]),
    ]
)


宏展开过程
宏的展开（Expansion）遵循确定的流程：


宏展开的关键特性：


    

  • 展开在编译期完成，不影响运行时性能
    • 

  • 展开结果在 Xcode 中可以通过"Expand Macro"查看
    • 

  • 宏无法读取其他文件或执行 I/O 操作
    • 

  • 宏生成的名称需要在声明中通过 names: 参数显式列出
    • 



@attached(member, names: named(init), named(description))
public macro AutoInit() = #externalMacro(module: "MyMacros", type: "AutoInitMacro")

@AutoInit
struct Point {
    var x: Double
    var y: Double
    // 宏展开生成:
    // init(x: Double, y: Double) { self.x = x; self.y = y }
    // var description: String { "Point(x: \(x), y: \(y))" }
}


提示： 在 Xcode 中右键点击宏调用，选择"Expand Macro"可以查看宏展开后的完整代码。这是调试和理解宏行为的最直观方式。






小结
    

  • Swift 宏分为独立宏（# 前缀）和附加宏（@ 前缀）两大类
    • 

  • 宏通过角色声明能力，包括 expression、declaration、member、accessor、extension、peer、body 等
    • 

  • 宏实现基于 SwiftSyntax 框架，操作源代码的语法树
    • 

  • 宏运行在独立的编译器插件进程中，与编译器安全隔离
    • 

  • 宏展开在编译期完成，生成的代码经过完整的类型检查
    • 

  • 使用 Swift Package Manager 的 .macro 目标类型组织宏包
    •
