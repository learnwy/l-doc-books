写时复制

概述

写时复制（Copy-on-Write, COW）是 Swift 值语义的核心优化策略。Swift 的 Array、Dictionary、Set、String 等标准库类型都使用 COW——复制时仅复制引用，只在真正修改时才创建独立副本。理解 COW 的实现原理和 isKnownUniquelyReferenced 的使用方式，可以帮助开发者为自定义类型实现高效的值语义。

值语义与引用语义
Swift 的值类型（struct、enum）具有值语义——赋值时创建独立副本：


var array1 = [1, 2, 3]
var array2 = array1       // 看起来是复制
array2.append(4)

print(array1) // [1, 2, 3] — 不受影响
print(array2) // [1, 2, 3, 4]
但如果每次赋值都物理复制整个数组，性能会很差。COW 的策略是：


    

  1. 赋值时只复制引用（O(1)）
    2. 

  2. 修改前检查引用是否唯一
    3. 

  3. 唯一引用：直接修改（O(1)）
    4. 

  4. 非唯一引用：先复制存储，再修改（O(n)）
    5. 





isKnownUniquelyReferenced
isKnownUniquelyReferenced 是实现 COW 的关键 API，它检查一个类实例是否只有一个引用：


class Storage<T> {
    var elements: [T]

    init(_ elements: [T]) {
        self.elements = elements
    }

    func copy() -> Storage {
        Storage(elements)
    }
}

struct COWArray<T> {
    private var storage: Storage<T>

    init(_ elements: [T] = []) {
        storage = Storage(elements)
    }

    var count: Int { storage.elements.count }

    private mutating func ensureUnique() {
        if !isKnownUniquelyReferenced(&storage) {
            storage = storage.copy()
        }
    }

    mutating func append(_ element: T) {
        ensureUnique()
        storage.elements.append(element)
    }

    subscript(index: Int) -> T {
        get { storage.elements[index] }
        set {
            ensureUnique()
            storage.elements[index] = newValue
        }
    }
}
使用示例：


var a = COWArray([1, 2, 3])
var b = a                    // 共享同一个 Storage（引用计数 = 2）
b.append(4)                  // 触发 ensureUnique → 复制 Storage
print(a.count) // 3
print(b.count) // 4

验证 COW 行为：


var original = [1, 2, 3, 4, 5]
let copy = original

print(original.withUnsafeBufferPointer { $0.baseAddress! })
print(copy.withUnsafeBufferPointer { $0.baseAddress! })
// 相同地址 — 共享存储

original.append(6)
print(original.withUnsafeBufferPointer { $0.baseAddress! })
// 不同地址 — 修改触发了复制


完整的自定义 COW 实现
一个更完善的 COW 容器实现，支持 Collection 协议：


final class IndirectStorage<Element> {
    var buffer: [Element]
    init(_ buffer: [Element]) { self.buffer = buffer }
}

struct COWBuffer<Element>: RandomAccessCollection, MutableCollection {
    private var storage: IndirectStorage<Element>

    init(_ elements: [Element] = []) {
        storage = IndirectStorage(elements)
    }

    var startIndex: Int { storage.buffer.startIndex }
    var endIndex: Int { storage.buffer.endIndex }

    private mutating func makeUniqueIfNeeded() {
        if !isKnownUniquelyReferenced(&storage) {
            storage = IndirectStorage(storage.buffer)
        }
    }

    subscript(index: Int) -> Element {
        get { storage.buffer[index] }
        set {
            makeUniqueIfNeeded()
            storage.buffer[index] = newValue
        }
    }

    mutating func append(_ element: Element) {
        makeUniqueIfNeeded()
        storage.buffer.append(element)
    }
}


COW 的性能特征
// O(1) 操作：赋值（只增加引用计数）
var bigArray = Array(0..<1_000_000)
var copy = bigArray  // O(1)

// O(n) 操作：首次修改（触发完整复制）
copy[0] = -1  // O(n) — 复制 100 万个元素

// O(1) 操作：后续修改（已经是唯一引用）
copy[1] = -2  // O(1)

陷阱：意外的共享引用
func appendToArray(_ array: [Int]) -> [Int] {
    var result = array  // 引用计数 +1
    result.append(42)   // 触发 COW 复制 ⚠️
    return result
}

// 更好的方式：使用 inout 避免 COW
func appendInPlace(_ array: inout [Int]) {
    array.append(42)  // 如果外部只有一个引用，不触发复制
}


小结
    

  • COW 在赋值时共享存储（O(1)），仅在修改时才复制（O(n)），兼顾值语义和性能
    • 

  • isKnownUniquelyReferenced 是实现 COW 的核心 API，检查引用是否唯一
    • 

  • Swift 标准库的 Array、Dictionary、Set、String 全部使用 COW
    • 

  • 自定义 COW 需要一个引用类型的内部存储（class），在 mutating 方法中检查唯一性
    • 

  • 首次写入共享存储时触发 O(n) 复制，后续写入为 O(1)
    • 

  • 使用 inout 传参可以避免函数调用中的意外 COW 复制
    •
