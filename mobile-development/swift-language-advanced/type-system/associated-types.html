关联类型

概述

关联类型（Associated Types）是 Swift 协议中的"类型占位符"，它允许协议在不指定具体类型的情况下声明类型关系。遵循协议的类型在实现时确定关联类型的具体绑定。关联类型是 Swift 泛型系统的重要组成部分，也是理解类型擦除（Type Erasure）和 Swift 5.7 引入的主关联类型（Primary Associated Types）的基础。

基本用法
使用 associatedtype 关键字在协议中声明关联类型：


protocol Container {
    associatedtype Item
    var count: Int { get }
    mutating func append(_ item: Item)
    subscript(i: Int) -> Item { get }
}
遵循协议时，可以显式指定或让编译器推断关联类型：


struct IntStack: Container {
    typealias Item = Int

    private var storage: [Int] = []
    var count: Int { storage.count }

    mutating func append(_ item: Int) {
        storage.append(item)
    }

    subscript(i: Int) -> Int {
        storage[i]
    }
}

struct GenericStack<Element>: Container {
    private var storage: [Element] = []
    var count: Int { storage.count }

    mutating func append(_ item: Element) {
        storage.append(item)
    }

    subscript(i: Int) -> Element {
        storage[i]
    }
}
在 GenericStack 中，编译器根据方法签名自动推断 Item == Element，无需显式 typealias。




关联类型约束
关联类型可以添加约束，限制遵循类型的选择：


protocol SortableContainer {
    associatedtype Item: Comparable
    var items: [Item] { get }
    func sorted() -> [Item]
}

protocol Graph {
    associatedtype Node: Hashable
    associatedtype Edge: Hashable
    func neighbors(of node: Node) -> [Node]
    func edges(from source: Node, to target: Node) -> [Edge]
}
也可以使用 where 子句表达关联类型之间的关系：


protocol ConvertibleContainer {
    associatedtype Input
    associatedtype Output where Output: Collection, Output.Element == Input
    func convert() -> Output
}


类型擦除
带有关联类型的协议不能直接用作类型（即不能写 let c: Container），因为编译器无法确定关联类型的具体绑定。类型擦除是解决这一限制的经典模式：


struct AnyContainer<Item>: Container {
    private let _count: () -> Int
    private let _append: (Item) -> Void
    private let _subscript: (Int) -> Item

    var count: Int { _count() }

    init<C: Container>(_ container: C) where C.Item == Item {
        var mutableContainer = container
        _count = { mutableContainer.count }
        _append = { mutableContainer.append($0) }
        _subscript = { mutableContainer[$0] }
    }

    mutating func append(_ item: Item) {
        _append(item)
    }

    subscript(i: Int) -> Item {
        _subscript(i)
    }
}

主关联类型（Primary Associated Types）
Swift 5.7（SE-0346）引入了主关联类型语法，使协议可以像泛型类型一样使用尖括号参数化：


protocol Collection<Element> {
    associatedtype Element
    associatedtype Index: Comparable
    // ...
}
这使得 any 和 some 可以搭配类型参数使用：


func processItems(_ items: some Collection<Int>) {
    for item in items {
        print(item * 2)
    }
}

func storeContainer(_ container: any Collection<String>) {
    print(container.count)
}
主关联类型极大简化了带有关联类型的协议的使用语法，特别是在参数声明和返回值类型上。




关联类型的递归约束
关联类型支持递归约束，这在定义树形或图形数据结构时非常有用：


protocol TreeNode {
    associatedtype Value
    associatedtype Child: TreeNode where Child.Value == Value
    var value: Value { get }
    var children: [Child] { get }
}

struct SimpleTreeNode<V>: TreeNode {
    var value: V
    var children: [SimpleTreeNode<V>]
}


实际应用：协议组合与关联类型
在实际项目中，关联类型常用于定义数据层抽象：


protocol Repository {
    associatedtype Entity: Identifiable
    func fetchAll() async throws -> [Entity]
    func fetch(byID id: Entity.ID) async throws -> Entity?
    func save(_ entity: Entity) async throws
    func delete(byID id: Entity.ID) async throws
}

struct UserRepository: Repository {
    func fetchAll() async throws -> [User] { /* ... */ [] }
    func fetch(byID id: User.ID) async throws -> User? { /* ... */ nil }
    func save(_ entity: User) async throws { /* ... */ }
    func delete(byID id: User.ID) async throws { /* ... */ }
}


小结
    

  • 关联类型是协议中的类型占位符，遵循类型在实现时确定具体绑定
    • 

  • 关联类型可以添加协议约束和 where 子句，表达复杂的类型关系
    • 

  • 类型擦除通过包装器解决带关联类型的协议不能直接用作类型的问题
    • 

  • Swift 5.7 的主关联类型引入尖括号语法（Collection<Int>），大幅简化使用体验
    • 

  • 关联类型支持递归约束，适合树、图等递归数据结构的协议建模
    • 

  • 在实际项目中，关联类型常用于定义 Repository、Service 等可替换的抽象层
