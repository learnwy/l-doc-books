泛型深入

概述

泛型（Generics）是 Swift 类型系统中最强大的特性之一，它允许开发者编写灵活、可复用的函数和类型，同时保持完整的类型安全。Swift 标准库大量使用泛型——Array<Element>、Dictionary<Key, Value>、Optional<Wrapped> 都是泛型类型的经典范例。

掌握泛型的高级用法，包括类型约束、where 子句和特化机制，是编写高质量 Swift 代码的基础。

泛型函数
泛型函数使用**类型参数（Type Parameter）**作为占位符，在调用时由编译器自动推断具体类型：


func swapValues<T>(_ a: inout T, _ b: inout T) {
    let temp = a
    a = b
    b = temp
}

var x = 10, y = 20
swapValues(&x, &y)

var s1 = "hello", s2 = "world"
swapValues(&s1, &s2)
编译器会对每个具体类型生成独立的函数实现，这个过程叫做单态化（Monomorphization），它确保泛型代码具有与手写特定类型代码相同的性能。




泛型类型
泛型不仅适用于函数，也可以定义泛型结构体、类和枚举：


struct Stack<Element> {
    private var storage: [Element] = []

    var isEmpty: Bool { storage.isEmpty }
    var count: Int { storage.count }

    mutating func push(_ element: Element) {
        storage.append(element)
    }

    mutating func pop() -> Element? {
        storage.popLast()
    }

    func peek() -> Element? {
        storage.last
    }
}

var intStack = Stack<Int>()
intStack.push(1)
intStack.push(2)

var stringStack = Stack<String>()
stringStack.push("Swift")
泛型类型还可以拥有多个类型参数：


struct Pair<First, Second> {
    let first: First
    let second: Second
}

let pair = Pair(first: "age", second: 30)


类型约束
无约束的类型参数 T 只能执行所有类型通用的操作。通过类型约束，可以要求类型参数遵循特定协议或继承特定类：


func findIndex<T: Equatable>(of value: T, in array: [T]) -> Int? {
    for (index, element) in array.enumerated() {
        if element == value {
            return index
        }
    }
    return nil
}

where 子句
where 子句提供更精细的类型约束表达能力，可以约束关联类型、多类型参数之间的关系等：


func merge<C1: Collection, C2: Collection>(
    _ c1: C1,
    _ c2: C2
) -> [C1.Element] where C1.Element == C2.Element, C1.Element: Comparable {
    (Array(c1) + Array(c2)).sorted()
}

let result = merge([3, 1], [4, 2])
where 子句也可以用在扩展上，为泛型类型在特定条件下添加额外功能：


extension Stack where Element: Equatable {
    func contains(_ element: Element) -> Bool {
        storage.contains(element)
    }
}

extension Stack where Element: Numeric {
    func sum() -> Element {
        storage.reduce(0, +)
    }
}


泛型特化
Swift 编译器通过**泛型特化（Generic Specialization）**优化性能。当编译器能够确定泛型的具体类型时，会生成针对该类型优化的代码：


@_specialize(where T == Int)
func heavyComputation<T: Numeric>(_ value: T) -> T {
    var result = value
    for _ in 0..<1000 {
        result = result + value
    }
    return result
}


提示： @_specialize 是 Swift 的内部属性，一般不需要手动添加。编译器在开启优化（-O）时会自动执行特化。了解特化机制有助于理解泛型的性能特征。




泛型特化的层级关系：


跨模块边界的泛型调用默认无法特化，因为编译器看不到具体类型。使用 @inlinable 可以暴露函数体，允许跨模块特化：


@inlinable
public func fastMap<T, U>(_ array: [T], transform: (T) -> U) -> [U] {
    var result = [U]()
    result.reserveCapacity(array.count)
    for element in array {
        result.append(transform(element))
    }
    return result
}


泛型与协议的配合
泛型和协议结合使用能发挥更大的威力。典型模式是定义协议约束，再通过泛型函数统一处理：


protocol Serializable {
    func serialize() -> Data
    static func deserialize(from data: Data) throws -> Self
}

func saveToFile<T: Serializable>(_ object: T, path: String) throws {
    let data = object.serialize()
    try data.write(to: URL(fileURLWithPath: path))
}

func loadFromFile<T: Serializable>(path: String) throws -> T {
    let data = try Data(contentsOf: URL(fileURLWithPath: path))
    return try T.deserialize(from: data)
}


小结
    

  • 泛型函数使用类型参数作为占位符，编译器通过单态化生成具体类型的代码
    • 

  • 泛型类型（struct、class、enum）可以拥有一个或多个类型参数，实现容器等通用数据结构
    • 

  • 类型约束通过协议约束、类约束或组合约束限定类型参数的能力
    • 

  • where 子句提供细粒度的约束表达，支持关联类型约束和多参数关系约束
    • 

  • 泛型特化是编译器优化手段，在确定具体类型时生成高效代码；跨模块需要 @inlinable 辅助
    • 

  • 泛型与协议结合是 Swift 类型系统的核心设计模式，二者协作实现类型安全的多态
    •
