协议见证表

概述

协议见证表（Protocol Witness Table, PWT）是 Swift 实现协议多态的底层机制。当一个值通过协议类型（存在类型）使用时，编译器通过见证表找到具体类型对应的方法实现。理解见证表的结构和存在容器（Existential Container）的内存布局，对于分析 Swift 的性能特征至关重要。

见证表结构
每当一个类型遵循一个协议时，编译器会生成一张见证表，将协议要求的每个方法映射到具体类型的实现：


protocol Drawable {
    func draw()
    var color: String { get }
}

struct Circle: Drawable {
    func draw() { print("Drawing circle") }
    var color: String { "red" }
}

struct Square: Drawable {
    func draw() { print("Drawing square") }
    var color: String { "blue" }
}
编译器为 Circle: Drawable 和 Square: Drawable 各生成一张见证表：

存在容器（Existential Container）
当值存储在协议类型变量中时，使用存在容器包装：


let shape: any Drawable = Circle()
存在容器的内存布局（64 位系统）：


总计：40 bytes (5 words)


protocol HasSize {
    var size: Int { get }
}

struct SmallValue: HasSize {
    let a: Int
    var size: Int { MemoryLayout<Self>.size } // 8 bytes, 内联
}

struct LargeValue: HasSize {
    let a, b, c, d: Int
    var size: Int { MemoryLayout<Self>.size } // 32 bytes, 堆分配
}

Value Witness Table
除了协议见证表，每个类型还有一个 Value Witness Table（VWT），记录了类型的值操作：


VWT 使得运行时能够对不同大小和对齐要求的值执行通用操作（拷贝、移动、销毁），而无需在编译时确定具体类型。




内联存储优化
Swift 运行时对小值执行内联存储优化，避免堆分配：


protocol Valuable {
    func worth() -> Double
}

struct Coin: Valuable {
    let cents: Int
    func worth() -> Double { Double(cents) / 100.0 }
}

struct GoldBar: Valuable {
    let weightOz: Double
    let purity: Double
    let serialNumber: UInt64
    let vaultID: UInt64
    func worth() -> Double { weightOz * purity * 2000.0 }
}

var item: any Valuable

item = Coin(cents: 25)       // 内联存储（8 bytes ≤ 24 bytes）
item = GoldBar(               // 堆分配（32 bytes > 24 bytes）
    weightOz: 1.0,
    purity: 0.999,
    serialNumber: 12345,
    vaultID: 67890
)


提示： 在性能敏感的代码中，保持协议遵循类型的大小在 3 个机器字以内，可以避免存在容器的堆分配。






多协议遵循的存在容器
当类型遵循多个协议时，存在容器会包含多个 PWT 指针：


let item: any Drawable & Hashable = Circle()
总计：48 bytes (6 words)


每多遵循一个协议，存在容器就增加一个 PWT 指针（8 bytes）。

类类型的特殊处理
类类型遵循协议时，存在容器直接存放引用（指针），无需值缓冲区的内联/堆分配区分：


class Animal: Drawable {
    func draw() { }
    var color: String { "brown" }
}

let animal: any Drawable = Animal()
// 存在容器的值缓冲区直接存放 Animal 的引用（1 word）


小结
    

  • **协议见证表（PWT）**将协议方法映射到具体类型实现，是 Swift 协议多态的底层机制
    • 

  • 存在容器固定 5 words（40 bytes），包含值缓冲区、VWT 指针和 PWT 指针
    • 

  • 值 ≤ 24 bytes 时内联存储，> 24 bytes 时堆分配
    • 

  • Value Witness Table 提供类型的通用值操作（拷贝、销毁、大小信息）
    • 

  • 多协议遵循的存在容器会包含多个 PWT 指针
    • 

  • 性能排序：直接类型 > 泛型特化 > 存在类型（any），性能敏感场景应优先使用泛型
