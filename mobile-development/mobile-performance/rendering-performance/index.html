渲染性能与流畅度优化 简介

流畅的视觉体验是用户对应用品质感知的核心维度。60fps 意味着每帧仅有 16.6ms 的渲染预算，任何环节的阻塞都会导致可感知的卡顿与掉帧。本章围绕渲染管线的各个阶段，系统讲解帧率优化、布局调优与复杂视图性能治理。

本章包含以下三节内容：

帧率优化与卡顿治理从 VSYNC 信号机制出发，解析主线程与渲染线程的协作模型，介绍卡顿检测方案（RunLoop Observer / Choreographer）及治理手段，包括异步渲染、预计算、离屏渲染规避等核心技术。

布局与渲染管线优化深入 iOS Auto Layout 约束求解、Android Measure-Layout-Draw 三阶段的性能开销分析，讲解视图层级扁平化、约束简化、自定义布局引擎等优化路径。

列表滚动与复杂视图性能聚焦 UITableView/RecyclerView 的高性能实践，涵盖 Cell 复用池调优、预加载策略、图片异步解码、文本排版缓存以及异构 Feed 流的分帧渲染方案。

学习建议：建议先掌握帧率与卡顿的基础检测方法，再深入布局和列表优化。每节内容都附有 Instruments/Systrace 的实操步骤，鼓励边学边用工具验证效果。
