内联类

内联类（Inline Classes）是 Kotlin 提供的一种零开销抽象机制。通过 @JvmInline value class 声明，编译器会在可能的情况下将包装类型内联为底层类型，避免堆分配的开销，同时保留类型安全性。

基本语法

@JvmInline
value class UserId(val id: Long)

@JvmInline
value class Email(val address: String)

fun findUser(id: UserId): String = "User#${id.id}"

val userId = UserId(42L)
println(findUser(userId)) // User#42

提示： @JvmInline 注解是 JVM 平台的要求。value class 是 Kotlin 1.5+ 的语法，替代了早期的 inline class。

编译后的表示

内联类在编译后，大多数场景下会被替换为底层类型：

@JvmInline
value class Password(val value: String)

fun validate(password: Password): Boolean {
    return password.value.length >= 8
}

// 编译后大致等价于：
// fun validate(password: String): Boolean {
//     return password.length >= 8
// }

@JvmInline
value class Name(val value: String)

fun direct(name: Name) { }         // 不装箱：参数为 String
fun nullable(name: Name?) { }      // 装箱：需要可空包装
fun generic(item: Any) { }         // 装箱：擦除为 Any
fun <T> genericFun(item: T) { }    // 装箱：擦除


内联类的能力
内联类虽然轻量，但仍支持丰富的类特性：


@JvmInline
value class Percentage(val value: Double) {
    init {
        require(value in 0.0..100.0) { "百分比必须在 0-100 之间" }
    }

    fun toFraction(): Double = value / 100.0

    override fun toString(): String = "${value}%"
}

val p = Percentage(85.0)
println(p)              // 85.0%
println(p.toFraction()) // 0.85
内联类可以实现接口：


interface Printable {
    fun prettyPrint(): String
}

@JvmInline
value class Color(val rgb: Int) : Printable {
    override fun prettyPrint(): String = "#${rgb.toString(16).padStart(6, '0')}"
}

value class Kilograms(val value: Double)

fun demo() {
    val distance: Meters = 100.0
    val weight: Double = distance    // 合法：typealias 没有类型安全

    val kg = Kilograms(70.0)
    // val d: Double = kg            // 编译错误：value class 有类型安全
    val d: Double = kg.value         // 必须显式访问
}


性能对比
内联类相比普通包装类在性能上有显著优势：


// 普通包装类 — 每次创建都分配堆对象
data class WrappedId(val id: Long)

// 内联类 — 编译后直接使用 Long
@JvmInline
value class InlinedId(val id: Long)

fun benchmarkExample() {
    // WrappedId: 分配 1_000_000 个对象
    val wrappedList = List(1_000_000) { WrappedId(it.toLong()) }

    // InlinedId: 本质是 Long 数组，零额外分配
    val inlinedList = List(1_000_000) { InlinedId(it.toLong()) }
}


提示： 在高频创建轻量包装对象的场景（如 ID、度量单位、货币金额），内联类能显著减少 GC 压力。






限制与注意事项
    

  1. 只能有一个构造参数：内联类的主构造函数必须恰好有一个 val 属性
    2. 

  2. 不能有 backing field：不能声明额外的 var 或带 backing field 的属性
    3. 

  3. 不能参与继承：不能是 open、abstract，也不能继承其他类
    4. 

  4. 名称改写（name mangling）：编译器会对接受内联类参数的函数进行名称改写，避免签名冲突
    5. 



@JvmInline
value class UInt(val value: Int)

// 编译后函数名可能被改写为 compute-<hash>(int)
fun compute(x: UInt): Int = x.value * 2


小结
    

  • 内联类通过 @JvmInline value class 声明，提供零开销的类型包装
    • 

  • 编译器在大多数场景下将内联类替换为底层类型，避免堆分配
    • 

  • 泛型参数、可空类型、接口类型等场景会触发装箱
    • 

  • 与 typealias 相比，内联类提供真正的类型安全，且支持方法和验证逻辑
    • 

  • 适用于 ID、度量单位、货币等需要类型区分但不想付出对象分配代价的场景
    • 

  • 限制包括：单构造参数、无 backing field、不可继承
    •
