类型系统 简介

类型系统是 Kotlin 语言最具深度的部分之一。Kotlin 在 JVM 类型体系的基础上，引入了声明处型变、内联类和密封层级等现代特性，让开发者能够在编译期表达更精确的约束和更丰富的领域建模。对于大多数开发者而言，基础的泛型使用并不困难，但当面对协变与逆变的选择、类型投影的边界、或密封类层级的设计决策时，往往会陷入困惑。本章将带你系统理解 Kotlin 类型系统的高级能力，建立扎实的泛型思维。

第一节"泛型与型变"从型变的本质出发，解析 Kotlin 的声明处型变设计。out 与 in 修饰符如何分别标记协变与逆变、生产者与消费者模型如何指导型变决策、型变与 Java 通配符的对应关系——理解型变不是背诵规则，而是理解类型安全与灵活性之间的权衡。

第二节"类型投影"深入使用处型变的应用场景。当声明处型变无法满足需求时，星投影与使用处投影如何在特定调用点临时放宽或收紧类型约束、类型投影与声明处型变的互补关系、以及投影带来的只读或只写限制——掌握类型投影是编写通用工具函数的必备技能。

第三节"内联类"介绍 Kotlin 独特的零开销抽象机制。内联类如何在编译期消除包装对象的性能开销、value class 的使用场景与限制、内联类与类型别名的本质区别——内联类让你在不牺牲运行时性能的前提下获得类型安全的领域建模能力。

第四节"密封层级"探讨密封类与密封接口在类型建模中的核心作用。密封层级如何保证 when 表达式的穷举性、密封接口与密封类的选择策略、密封层级在状态机与领域事件建模中的实战应用——密封层级是 Kotlin 代数数据类型的基础，也是构建类型安全业务逻辑的利器。

本章内容是整个进阶手册的根基，建议仔细研读每一节并结合编译器的类型检查反馈进行实践。
