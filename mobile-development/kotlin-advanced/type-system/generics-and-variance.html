泛型与型变

Kotlin 的泛型系统在 Java 泛型的基础上做了大幅改进，引入了声明处型变（declaration-site variance）、星投影（star projection）以及具体化类型参数（reified type parameters），使得类型安全与 API 可用性之间取得了更好的平衡。

泛型基础回顾

泛型允许在类、接口和函数中使用类型参数，从而实现代码复用与类型安全。

class Box<T>(val value: T)

fun <T> singletonList(item: T): List<T> = listOf(item)

val box = Box("hello")       // Box<String>
val list = singletonList(42) // List<Int>

提示： Kotlin 编译器会自动推断类型参数，大多数场景下无需显式指定。

型变（Variance）

型变描述了泛型类型与其类型参数之间的子类型关系。Kotlin 提供了三种型变修饰：

修饰符 含义 位置 类比 Java
out 协变（covariant） 只能作为输出（生产者） ? extends T
in 逆变（contravariant） 只能作为输入（消费者） ? super T
无修饰 不变（invariant） 既可输入也可输出 T 


声明处型变（Declaration-Site Variance）
Kotlin 允许在类声明时直接标注型变，这比 Java 的使用处型变更加简洁。


interface Source<out T> {
    fun nextT(): T   // T 只出现在输出位置
}

interface Comparable<in T> {
    fun compareTo(other: T): Int  // T 只出现在输入位置
}
Source<Cat> 可以安全地赋值给 Source<Animal> 类型的变量：


fun demo(cats: Source<Cat>) {
    val animals: Source<Animal> = cats // 合法：out 协变
}


使用处型变（Use-Site Variance / Type Projection）
当类声明本身为不变时，可以在使用处添加型变修饰：


fun copy(from: Array<out Any>, to: Array<Any>) {
    for (i in from.indices) {
        to[i] = from[i]
    }
}
Array<out Any> 相当于 Java 的 Array<? extends Object>，此时 from 只能读取，不能写入。




星投影（Star Projection）
当不关心具体的类型参数时，可以使用 * 作为占位符：


fun printAll(list: List<*>) {
    for (item in list) {
        println(item) // item 类型为 Any?
    }
}
星投影的等价关系：






声明
星投影等价于





Foo<out T : TUpper>
Foo<out TUpper> （读取时为 TUpper）




Foo<in T>
Foo<in Nothing> （不能安全写入）




Foo<T : TUpper>
读取等价 Foo<out TUpper>，写入等价 Foo<in Nothing>







具体化类型参数（Reified Type Parameters）
由于 JVM 的类型擦除，普通泛型函数无法在运行时获取类型参数的信息。Kotlin 的 reified 关键字配合 inline 函数解决了这个问题：


inline fun <reified T> isInstance(value: Any): Boolean {
    return value is T  // 普通泛型函数中这是非法的
}

println(isInstance<String>("hello")) // true
println(isInstance<Int>("hello"))    // false
reified 的典型应用场景：


inline fun <reified T> Gson.fromJson(json: String): T {
    return fromJson(json, T::class.java)
}

// 使用时无需传入 Class 参数
val user = gson.fromJson<User>(jsonString)


提示： reified 只能用于 inline 函数，且不能用于类的类型参数。






泛型约束
可以使用上界约束限制类型参数的范围：


fun <T : Comparable<T>> sort(list: List<T>) { /* ... */ }

// 多重约束使用 where 子句
fun <T> cloneWhenGreater(list: List<T>, threshold: T): List<T>
    where T : Comparable<T>,
          T : Cloneable {
    return list.filter { it > threshold }.map { it }
}


小结
    

  • 型变分为协变（out）、逆变（in）和不变三种，决定了泛型类型的子类型关系
    • 

  • 声明处型变在类定义时标注，比 Java 的使用处通配符更简洁
    • 

  • 使用处型变（类型投影）在具体调用处添加 out/in 修饰
    • 

  • 星投影（*）用于不关心具体类型参数的场景
    • 

  • reified 配合 inline 函数可在运行时获取泛型类型信息，突破类型擦除限制
    • 

  • 泛型约束使用上界和 where 子句限定类型参数范围
