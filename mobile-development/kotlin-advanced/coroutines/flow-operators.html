Flow 操作符

Kotlin Flow 是基于协程的冷响应式数据流，提供了丰富的操作符来转换、过滤、组合和收集数据。Flow 操作符分为中间操作符（返回新 Flow）和末端操作符（触发实际执行）。

Flow 基础回顾

Flow 是冷的——只有在末端操作符（如 collect）调用时才开始执行：

import kotlinx.coroutines.flow.*

val numbersFlow: Flow<Int> = flow {
    for (i in 1..5) {
        delay(100)
        emit(i)
    }
}


转换操作符
map
逐个转换每个元素：


flowOf(1, 2, 3, 4, 5)
    .map { it * it }
    .collect { println(it) } // 1, 4, 9, 16, 25
filter
过滤不满足条件的元素：


flowOf(1, 2, 3, 4, 5)
    .filter { it % 2 == 0 }
    .collect { println(it) } // 2, 4
transform
最灵活的转换操作符，可以 emit 零个或多个值：


flowOf("Alice", "Bob")
    .transform { name ->
        emit("$name 登录")
        emit("$name 开始操作")
    }
    .collect { println(it) }
// Alice 登录
// Alice 开始操作
// Bob 登录
// Bob 开始操作

末端操作符
末端操作符是挂起函数，触发 Flow 的实际执行：


val numbers = flowOf(1, 2, 3, 4, 5)

// collect: 收集所有元素
numbers.collect { println(it) }

// toList: 收集为列表
val list: List<Int> = numbers.toList()

// first: 获取第一个元素
val first: Int = numbers.first()

// first { } : 获取第一个满足条件的元素
val firstEven: Int = numbers.first { it % 2 == 0 }

// reduce: 累积计算
val sum: Int = numbers.reduce { acc, value -> acc + value }

// fold: 带初始值的累积
val product: Int = numbers.fold(1) { acc, value -> acc * value }

// count: 计数
val count: Int = numbers.count { it > 3 }


提示： 末端操作符是挂起函数，会等待 Flow 执行完毕。collect 是最基础的末端操作符。






Flow 组合操作符
zip
将两个 Flow 按索引配对：


val names = flowOf("Alice", "Bob", "Charlie")
val ages = flowOf(25, 30, 35)

names.zip(ages) { name, age -> "$name ($age岁)" }
    .collect { println(it) }
// Alice (25岁)
// Bob (30岁)
// Charlie (35岁)
combine
在任一 Flow 发射新值时，使用两个 Flow 的最新值组合：


val flow1 = flow {
    emit("A"); delay(300)
    emit("B"); delay(300)
}
val flow2 = flow {
    emit(1); delay(200)
    emit(2); delay(200)
    emit(3)
}

flow1.combine(flow2) { s, i -> "$s$i" }
    .collect { println(it) }
// A1, A2, B2, B3（取决于时序）
merge
将多个 Flow 合并为一个，按发射顺序交错：


val flow1 = flowOf(1, 2, 3).onEach { delay(100) }
val flow2 = flowOf(10, 20, 30).onEach { delay(150) }

merge(flow1, flow2)
    .collect { println(it) }

缓冲与背压
buffer
引入缓冲区，让发射和收集并发执行：


flow {
    repeat(3) {
        delay(100) // 生产耗时 100ms
        emit(it)
    }
}
.buffer() // 缓冲：生产和消费并发
.collect {
    delay(300) // 消费耗时 300ms
    println(it)
}
// 无 buffer 总耗时约 1200ms，有 buffer 约 1000ms
conflate
丢弃未来得及处理的中间值，只保留最新：


flow {
    repeat(5) {
        emit(it)
        delay(100)
    }
}
.conflate()
.collect {
    delay(300)
    println(it) // 可能输出 0, 2, 4（跳过中间值）
}
collectLatest
收集最新值，前一个收集未完成时会被取消：


flow {
    emit("A"); delay(100)
    emit("B"); delay(100)
    emit("C")
}
.collectLatest { value ->
    println("开始处理 $value")
    delay(200)
    println("完成处理 $value") // 只有 C 能完成
}


错误处理
flowOf(1, 2, 3)
    .map { check(it != 2) { "不允许2" }; it }
    .catch { e -> emit(-1) } // 捕获上游异常，可恢复
    .onCompletion { cause ->
        if (cause != null) println("异常完成: $cause")
        else println("正常完成")
    }
    .collect { println(it) }
// 1, -1, 正常完成


小结
    

  • 中间操作符（map、filter、transform）惰性变换 Flow，不触发执行
    • 

  • 末端操作符（collect、toList、first、reduce）触发 Flow 实际执行
    • 

  • zip 按索引配对两个 Flow，combine 基于最新值组合，merge 交错合并多个 Flow
    • 

  • buffer 引入并发缓冲提升吞吐，conflate 丢弃中间值保留最新
    • 

  • collectLatest 取消前一个收集处理，只关注最新发射值
    • 

  • catch 捕获上游异常并支持恢复，onCompletion 在 Flow 结束时执行清理逻辑
    •
