Part II · AndroidKotlin 语言进阶 简介函数式模式 简介高阶函数

高阶函数

高阶函数是 Kotlin 函数式编程的基石——它接受函数作为参数或返回函数作为结果。配合 lambda 表达式、内联优化和 SAM 转换，Kotlin 提供了简洁而高效的函数式编程体验。

核心概念

高阶函数的核心是函数作为一等公民：函数拥有自己的类型（如 (Int) -> Int），可以作为参数传入、作为结果返回，也可以被 lambda 或函数引用赋值。这一能力让复用单位从「值」扩展到「行为」。围绕它，inline 在编译期消除 lambda 的对象分配，SAM 转换让 Kotlin 函数类型与 Java 接口互操作，noinline/crossinline 则精确控制内联边界。

函数类型

Kotlin 中，函数是一等公民，拥有明确的类型表示：

val sum: (Int, Int) -> Int = { a, b -> a + b }
val greet: (String) -> String = { name -> "你好, $name" }
val action: () -> Unit = { println("执行动作") }
val nullable: ((Int) -> String)? = null
函数类型语法 含义
(A, B) -> C 接受 A、B 参数，返回 C
() -> Unit 无参数无返回值
(Int) -> String 接受 Int 返回 String
A.(B) -> C A 的扩展函数类型，接受 B 返回 C
suspend () -> T 挂起函数类型

Lambda 表达式

Lambda 是定义匿名函数的简洁语法：

val numbers = listOf(3, 1, 4, 1, 5, 9)

val sorted = numbers.sortedBy { it }
val filtered = numbers.filter { it > 3 }
val mapped = numbers.map { "数字: $it" }

Lambda 的语法规则：

// 完整形式
val sum1: (Int, Int) -> Int = { a: Int, b: Int -> a + b }

// 类型推断
val sum2 = { a: Int, b: Int -> a + b }

// 单参数使用 it
val double = { it: Int -> it * 2 }

// 尾随 lambda
numbers.filter { it > 3 }.map { it * 2 }

// 解构声明
mapOf("A" to 1, "B" to 2).forEach { (key, value) ->
    println("$key = $value")
}

高阶函数定义

fun <T> List<T>.customFilter(predicate: (T) -> Boolean): List<T> {
    val result = mutableListOf<T>()
    for (item in this) {
        if (predicate(item)) result.add(item)
    }
    return result
}

fun <T, R> List<T>.customMap(transform: (T) -> R): List<R> {
    val result = mutableListOf<R>()
    for (item in this) {
        result.add(transform(item))
    }
    return result
}

val evens = listOf(1, 2, 3, 4, 5).customFilter { it % 2 == 0 }
val names = listOf("alice", "bob").customMap { it.uppercase() }
flowchart LR
    A["高阶函数 f(g)"] --> B["接收函数 g 作为参数"]
    A --> C["在内部调用 g()"]
    A --> D["返回函数作为结果"]

inline 函数

高阶函数每次调用 lambda 都会创建一个匿名类对象，inline 关键字消除这个开销：

inline fun <T> measureTime(block: () -> T): Pair<T, Long> {
    val start = System.nanoTime()
    val result = block()
    val duration = System.nanoTime() - start
    return result to duration
}

val (value, time) = measureTime {
    (1..1_000_000).sum()
}

编译器将 inline 函数的函数体和 lambda 直接内联到调用处，避免了函数对象分配和虚拟调用。

场景 是否使用 inline
接收 lambda 参数的小函数 ✅ 推荐
大型函数体 ❌ 代码膨胀
无 lambda 参数 ❌ 无意义
需要 reified 类型参数 ✅ 必须

noinline 与 crossinline

当 inline 函数有多个 lambda 参数时，可以选择性地禁止内联：

inline fun execute(
    inlined: () -> Unit,
    noinline stored: () -> Unit // 不内联，可以被存储
) {
    inlined()
    callbacks.add(stored) // noinline lambda 可以赋值给变量
}

crossinline 禁止 lambda 中使用非局部返回：

inline fun runInThread(crossinline block: () -> Unit) {
    Thread {
        block() // crossinline：block 不能使用 return 跳出 runInThread
    }.start()
}
flowchart TD
    A[inline 函数的 lambda 参数] --> B{需要存储 lambda?}
    B -->|是| C[noinline]
    B -->|否| D{在非局部上下文执行?}
    D -->|是| E[crossinline]
    D -->|否| F[默认 inline]

SAM 转换

Kotlin 支持对 Java 的单抽象方法（SAM）接口进行自动转换：

// Java 接口
// public interface OnClickListener {
//     void onClick(View view);
// }

button.setOnClickListener { view ->
    println("点击了按钮")
}

Kotlin 1.4+ 也支持对 Kotlin 的 fun interface 进行 SAM 转换：

fun interface Transformer<T, R> {
    fun transform(input: T): R
}

fun <T, R> applyTransform(value: T, transformer: Transformer<T, R>): R {
    return transformer.transform(value)
}

// 使用 SAM 转换
val result = applyTransform("hello") { it.uppercase() }

提示： Kotlin 的 fun interface 必须用 fun 关键字修饰才能支持 SAM 转换，普通 interface 不行。

函数引用

可以使用 :: 操作符将已有函数转为函数类型的值：

fun isEven(n: Int): Boolean = n % 2 == 0

val numbers = listOf(1, 2, 3, 4, 5)
val evens = numbers.filter(::isEven)

// 成员函数引用
val lengths = listOf("hello", "world").map(String::length)

// 构造函数引用
data class User(val name: String)
val users = listOf("Alice", "Bob").map(::User)

小结

  • 函数类型是 Kotlin 的一等类型，支持参数化、可空、扩展函数类型和挂起函数类型
  • Lambda 表达式是定义匿名函数的简洁语法，支持 it、尾随 lambda、解构等语法糖
  • 高阶函数接受函数参数或返回函数，是函数式编程的核心
  • inline 消除 lambda 的对象分配开销，noinline 允许存储 lambda，crossinline 禁止非局部返回
  • SAM 转换支持将 lambda 自动转换为 fun interface（Kotlin）或 SAM 接口（Java）
  • 函数引用（::func）将已有函数转为函数类型值
