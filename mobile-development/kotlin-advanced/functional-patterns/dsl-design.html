DSL 设计

Kotlin 的语言特性——带接收者的 lambda、扩展函数、中缀表达式——使其成为构建类型安全 DSL（Domain-Specific Language）的理想语言。从 Gradle 构建脚本到 HTML 构建器，DSL 让代码具有领域语言般的可读性。

Lambda with Receiver

带接收者的 Lambda 是 DSL 设计的核心机制。在 lambda 内部，可以直接调用接收者对象的方法和属性：

fun buildString(action: StringBuilder.() -> Unit): String {
    val sb = StringBuilder()
    sb.action() // action 的接收者是 sb
    return sb.toString()
}

val result = buildString {
    append("Hello")
    append(", ")
    append("Kotlin DSL!")
}
println(result) // Hello, Kotlin DSL!

构建简单 DSL
HTML 构建器
class HTML {
    private val children = mutableListOf<String>()

    fun head(block: Head.() -> Unit) {
        val head = Head().apply(block)
        children.add(head.render())
    }

    fun body(block: Body.() -> Unit) {
        val body = Body().apply(block)
        children.add(body.render())
    }

    fun render(): String = "<html>\n${children.joinToString("\n")}\n</html>"
}

class Head {
    var title: String = ""
    fun render(): String = "  <head><title>$title</title></head>"
}

class Body {
    private val elements = mutableListOf<String>()

    fun h1(text: String) { elements.add("    <h1>$text</h1>") }
    fun p(text: String) { elements.add("    <p>$text</p>") }

    fun render(): String = "  <body>\n${elements.joinToString("\n")}\n  </body>"
}

fun html(block: HTML.() -> Unit): String = HTML().apply(block).render()

val page = html {
    head {
        title = "Kotlin DSL"
    }
    body {
        h1("欢迎")
        p("这是用 Kotlin DSL 构建的页面")
    }
}


@DslMarker
当 DSL 嵌套层级较深时，内层 lambda 可以意外访问外层接收者的方法。@DslMarker 注解限制了这种隐式访问：


@DslMarker
annotation class HtmlDsl

@HtmlDsl
class Table {
    fun tr(block: TableRow.() -> Unit) { /* ... */ }
}

@HtmlDsl
class TableRow {
    fun td(text: String) { /* ... */ }
}

Table().apply {
    tr {
        td("单元格")
        // tr { }  // 编译错误！@DslMarker 阻止访问外层 Table 的 tr()
    }
}


提示： @DslMarker 是构建健壮 DSL 的必备工具，标注后所有被标注类型的隐式接收者在嵌套 lambda 中互斥。






Builder Pattern（类型安全构建器）
@DslMarker
annotation class ConfigDsl

@ConfigDsl
class ServerConfig {
    var host: String = "localhost"
    var port: Int = 8080
    private var _database: DatabaseConfig? = null
    private var _logging: LoggingConfig? = null

    fun database(block: DatabaseConfig.() -> Unit) {
        _database = DatabaseConfig().apply(block)
    }

    fun logging(block: LoggingConfig.() -> Unit) {
        _logging = LoggingConfig().apply(block)
    }

    fun build(): String = """
        Server: $host:$port
        Database: ${_database?.url ?: "未配置"}
        Logging: ${_logging?.level ?: "INFO"}
    """.trimIndent()
}

@ConfigDsl
class DatabaseConfig {
    var url: String = ""
    var maxConnections: Int = 10
}

@ConfigDsl
class LoggingConfig {
    var level: String = "INFO"
    var file: String = "app.log"
}

fun server(block: ServerConfig.() -> Unit): String {
    return ServerConfig().apply(block).build()
}

val config = server {
    host = "0.0.0.0"
    port = 443

    database {
        url = "jdbc:postgresql://localhost:5432/mydb"
        maxConnections = 20
    }

    logging {
        level = "DEBUG"
        file = "/var/log/server.log"
    }
}


中缀函数增强 DSL
class RouteBuilder {
    private val routes = mutableListOf<String>()

    infix fun String.to(handler: String) {
        routes.add("$this -> $handler")
    }

    fun build(): List<String> = routes
}

fun routes(block: RouteBuilder.() -> Unit): List<String> {
    return RouteBuilder().apply(block).build()
}

val appRoutes = routes {
    "/home" to "HomeController"
    "/users" to "UserController"
    "/api/data" to "DataController"
}

plugins {

  • Lambda with Receiver 是 DSL 的核心，允许在 lambda 内直接访问接收者对象的成员
    • 

  • @DslMarker 限制嵌套 lambda 对外层接收者的隐式访问，是构建健壮 DSL 的必备工具
    • 

  • 类型安全构建器结合 apply 模式和嵌套 lambda，实现声明式配置
    • 

  • 中缀函数增强键值对和二元关系的可读性
    •

    •
