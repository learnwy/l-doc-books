Part II · AndroidKotlin 语言进阶 简介函数式模式 简介作用域函数

作用域函数

Kotlin 提供了五个作用域函数——let、run、with、apply、also——用于在对象的上下文中执行代码块。它们的核心区别在于上下文引用方式（this vs it）和返回值（上下文对象 vs lambda 结果）。

五大作用域函数对比

函数 上下文引用 返回值 调用方式 典型用途
let it Lambda 结果 扩展函数 空安全调用、转换
run this Lambda 结果 扩展函数 对象配置 + 计算结果
with this Lambda 结果 普通函数 对已有对象调用多个方法
apply this 上下文对象 扩展函数 对象初始化配置
also it 上下文对象 扩展函数 附加操作（日志、验证） 


let
使用 it 引用上下文对象，返回 lambda 结果。最常用于空安全调用链：


val name: String? = "Kotlin"

// 空安全调用
val length = name?.let { it.length } ?: 0

// 转换
val result = listOf(1, 2, 3).firstOrNull()?.let { "找到: $it" } ?: "未找到"

// 限制变量作用域
val numbers = mutableListOf("one", "two", "three")
numbers.map { it.length }.filter { it > 3 }.let { println(it) }


run
使用 this 引用上下文对象，返回 lambda 结果。适合配置对象后计算结果：


val service = DatabaseService()

val result = service.run {
    host = "localhost"
    port = 5432
    connect()
    query("SELECT * FROM users") // 返回值
}

// 非扩展形式：用于执行需要表达式的代码块
val hexColor = run {
    val r = 255
    val g = 128
    val b = 0
    "#${r.toString(16)}${g.toString(16)}${b.toString(16)}"
}


with
使用 this 引用，返回 lambda 结果。与 run 类似，但以普通函数形式调用：


val builder = StringBuilder()

val text = with(builder) {
    append("Hello")
    append(", ")
    append("World!")
    toString() // 返回值
}

// 适合对同一对象调用多个方法
with(config) {
    enableFeatureA()
    setMaxRetries(3)
    setTimeout(5000)
}


提示： with 不是扩展函数，因此不支持空安全调用（?.）。对于可空对象，优先使用 run。






apply
使用 this 引用，返回对象本身。最适合对象初始化和配置：


val user = User().apply {
    name = "张三"
    age = 28
    email = "zhangsan@example.com"
}

// 典型场景：构建 Intent
val intent = Intent(context, DetailActivity::class.java).apply {
    putExtra("id", userId)
    putExtra("source", "home")
    addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
}

// 链式配置
val paint = Paint().apply {
    color = Color.RED
    strokeWidth = 2f
    style = Paint.Style.STROKE
}


also
使用 it 引用，返回对象本身。适合执行不修改对象的附加操作：


val numbers = mutableListOf(1, 2, 3)
    .also { println("初始列表: $it") }
    .also { require(it.isNotEmpty()) { "列表不能为空" } }

// 调试和日志
fun fetchUser(id: Long): User {
    return repository.findById(id)
        .also { println("查询到用户: $it") }
}

// 链式操作中插入副作用
val sorted = mutableListOf(3, 1, 4, 1, 5)
    .also { println("排序前: $it") }
    .apply { sort() }
    .also { println("排序后: $it") }


组合使用
作用域函数可以组合形成流畅的调用链：


data class Request(
    var url: String = "",
    var method: String = "GET",
    var headers: MutableMap<String, String> = mutableMapOf(),
    var body: String? = null
)

fun buildRequest(): Request {
    return Request().apply {
        url = "https://api.example.com/users"
        method = "POST"
        headers["Content-Type"] = "application/json"
        body = """{"name": "张三"}"""
    }.also {
        println("构建请求: ${it.method} ${it.url}")
    }
}


链式模式的选择指南
// ❌ 过度嵌套 — 可读性差
user?.let {
    it.address?.let { addr ->
        addr.city?.let { city ->
            println(city)
        }
    }
}

// ✅ 扁平链式
val city = user?.address?.city
city?.let { println(it) }

// ✅ 合理组合
val connection = DatabaseConfig().apply {
    host = "localhost"
    port = 5432
}.run {
    createConnection()
}.also {
    logger.info("数据库已连接")
}

内部实现
所有作用域函数都是 inline 的，没有运行时开销：


// let 的实际签名
public inline fun <T, R> T.let(block: (T) -> R): R = block(this)

// apply 的实际签名
public inline fun <T> T.apply(block: T.() -> Unit): T {
    block()
    return this
}


提示： 因为是 inline 函数，作用域函数的 lambda 中可以使用 return 执行非局部返回。






小结
    

  • let：it 引用 + 返回 lambda 结果，适合空安全调用和转换
    • 

  • run：this 引用 + 返回 lambda 结果，适合对象配置后计算
    • 

  • with：this 引用 + 返回 lambda 结果，适合对已有对象批量调用方法
    • 

  • apply：this 引用 + 返回对象本身，适合对象初始化配置
    • 

  • also：it 引用 + 返回对象本身，适合附加操作（日志、验证）
    • 

  • 所有作用域函数都是 inline 的，零运行时开销
    • 

  • 避免过度嵌套，保持链式调用的扁平和可读性
