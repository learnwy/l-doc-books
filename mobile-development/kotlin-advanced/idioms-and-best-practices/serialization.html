序列化

kotlinx.serialization 是 Kotlin 官方的多平台序列化框架，通过编译器插件在编译时生成序列化代码，提供类型安全、高性能的序列化体验。支持 JSON、Protobuf、CBOR 等多种格式。

基础用法

import kotlinx.serialization.*
import kotlinx.serialization.json.*

@Serializable
data class User(
    val id: Long,
    val name: String,
    val email: String
)

val json = Json { prettyPrint = true }

// 序列化
val jsonString = json.encodeToString(User(1, "张三", "zhangsan@example.com"))

// 反序列化
val user = json.decodeFromString<User>(jsonString)


Json 配置
val json = Json {
    prettyPrint = true              // 格式化输出
    isLenient = true                // 宽松解析
    ignoreUnknownKeys = true        // 忽略未知字段
    coerceInputValues = true        // 类型不匹配时使用默认值
    encodeDefaults = true           // 编码默认值
    explicitNulls = false           // 不输出 null 字段
    namingStrategy = JsonNamingStrategy.SnakeCase // 蛇形命名
}

注解
@SerialName
自定义 JSON 字段名：


@Serializable
data class ApiResponse(
    @SerialName("status_code")
    val statusCode: Int,
    @SerialName("error_message")
    val errorMessage: String? = null,
    @SerialName("data")
    val payload: List<Item> = emptyList()
)
@Transient
排除字段不参与序列化（必须有默认值）：


@Serializable
data class Session(
    val token: String,
    val userId: Long,
    @Transient
    val cachedUser: User? = null // 不序列化
)
@Required
标记字段为必须存在：


@Serializable
data class Config(
    @Required
    val apiKey: String,     // JSON 中必须包含此字段
    val timeout: Long = 5000 // 可选，有默认值
)


多态序列化
sealed class 序列化
@Serializable
sealed class Shape {
    @Serializable
    @SerialName("circle")
    data class Circle(val radius: Double) : Shape()

    @Serializable
    @SerialName("rectangle")
    data class Rectangle(val width: Double, val height: Double) : Shape()
}

val shapes: List<Shape> = listOf(
    Shape.Circle(5.0),
    Shape.Rectangle(3.0, 4.0)
)

val jsonStr = Json.encodeToString(shapes)
// [{"type":"circle","radius":5.0},{"type":"rectangle","width":3.0,"height":4.0}]
自定义类型鉴别器
val json = Json {
    classDiscriminator = "_type" // 默认是 "type"
}


自定义序列化器
KSerializer 接口
object DateAsLongSerializer : KSerializer<Date> {
    override val descriptor = PrimitiveSerialDescriptor("Date", PrimitiveKind.LONG)

    override fun serialize(encoder: Encoder, value: Date) {
        encoder.encodeLong(value.time)
    }

    override fun deserialize(decoder: Decoder): Date {
        return Date(decoder.decodeLong())
    }
}

@Serializable
data class Event(
    val name: String,
    @Serializable(with = DateAsLongSerializer::class)
    val timestamp: Date
)
全局注册序列化器
val module = SerializersModule {
    contextual(Date::class, DateAsLongSerializer)
}

val json = Json {
    serializersModule = module
}


多格式支持
kotlinx.serialization 不仅支持 JSON，还支持多种格式：


// Protobuf
dependencies {
    implementation("org.jetbrains.kotlinx:kotlinx-serialization-protobuf:1.6.0")
}

@Serializable
data class Message(
    @ProtoNumber(1) val id: Int,
    @ProtoNumber(2) val text: String
)

val bytes = ProtoBuf.encodeToByteArray(Message(1, "hello"))
val msg = ProtoBuf.decodeFromByteArray<Message>(bytes)

// CBOR
dependencies {
    implementation("org.jetbrains.kotlinx:kotlinx-serialization-cbor:1.6.0")
}

val cborBytes = Cbor.encodeToByteArray(user)

迁移示例
// Gson 方式
val gson = Gson()
val user = gson.fromJson(jsonStr, User::class.java) // 运行时反射

// kotlinx.serialization 方式
val user = Json.decodeFromString<User>(jsonStr) // 编译时生成
与 Moshi 对比
// Moshi (with codegen)
@JsonClass(generateAdapter = true)
data class User(
    @Json(name = "user_name") val name: String
)

// kotlinx.serialization
@Serializable
data class User(
    @SerialName("user_name") val name: String
)


提示： 如果项目已使用 Gson/Moshi 且不需要 KMP 支持，迁移并非必须。但新项目推荐直接使用 kotlinx.serialization。






性能最佳实践
// ✅ 复用 Json 实例
val AppJson = Json {
    ignoreUnknownKeys = true
    encodeDefaults = false
}

// ❌ 避免每次创建新实例
fun parse(str: String): User {
    val json = Json { ignoreUnknownKeys = true } // 每次创建，浪费资源
    return json.decodeFromString(str)
}

// ✅ 使用 decodeFromStream（大文件）
val user = AppJson.decodeFromStream<User>(inputStream)


小结
    

  • kotlinx.serialization 是 Kotlin 官方多平台序列化框架，通过编译器插件生成代码
    • 

  • 使用 @Serializable 标注数据类，支持 @SerialName、@Transient、@Required 等注解
    • 

  • Json 配置通过 builder 模式自定义解析行为（ignoreUnknownKeys、encodeDefaults 等）
    • 

  • 多态序列化通过 sealed class + @SerialName 实现类型鉴别
    • 

  • 支持 JSON、Protobuf、CBOR 等多种格式
    • 

  • 相比 Gson（反射）和 Moshi，kotlinx.serialization 更快、空安全、支持 KMP
    • 

  • 性能优化：复用 Json 实例、大文件使用流式 API
    •
