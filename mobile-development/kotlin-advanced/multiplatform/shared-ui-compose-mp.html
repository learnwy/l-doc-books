共享 UI (Compose Multiplatform)

Compose Multiplatform 是 JetBrains 基于 Jetpack Compose 开发的跨平台 UI 框架，允许在 Android、iOS、Desktop 和 Web 之间共享声明式 UI 代码。它将 Kotlin Multiplatform 的代码共享能力从业务逻辑层扩展到了 UI 层。

架构概览

Compose Multiplatform 的分层：

内容

共享 Composable 编写
// commonMain/kotlin/ui/UserCard.kt
@Composable
fun UserCard(user: User, onClick: () -> Unit) {
    Card(
        modifier = Modifier
            .fillMaxWidth()
            .padding(8.dp)
            .clickable { onClick() }
    ) {
        Row(
            modifier = Modifier.padding(16.dp),
            verticalAlignment = Alignment.CenterVertically
        ) {
            Icon(
                imageVector = Icons.Default.Person,
                contentDescription = null,
                modifier = Modifier.size(48.dp)
            )
            Spacer(modifier = Modifier.width(16.dp))
            Column {
                Text(
                    text = user.name,
                    style = MaterialTheme.typography.titleMedium
                )
                Text(
                    text = user.email,
                    style = MaterialTheme.typography.bodySmall,
                    color = MaterialTheme.colorScheme.onSurfaceVariant
                )
            }
        }
    }
}
共享屏幕组合
// commonMain/kotlin/ui/UserListScreen.kt
@Composable
fun UserListScreen(viewModel: UserViewModel) {
    val users by viewModel.users.collectAsState()
    val isLoading by viewModel.isLoading.collectAsState()

    Scaffold(
        topBar = {
            TopAppBar(title = { Text("用户列表") })
        }
    ) { padding ->
        if (isLoading) {
            Box(
                modifier = Modifier.fillMaxSize(),
                contentAlignment = Alignment.Center
            ) {
                CircularProgressIndicator()
            }
        } else {
            LazyColumn(
                modifier = Modifier.padding(padding)
            ) {
                items(users) { user ->
                    UserCard(user = user, onClick = { viewModel.selectUser(user) })
                }
            }
        }
    }
}


平台特定 UI
某些 UI 元素天然与平台绑定，需要通过 expect/actual 处理：


// commonMain
@Composable
expect fun StatusBarEffect(isDarkTheme: Boolean)

@Composable
expect fun PlatformBackHandler(onBack: () -> Unit)

// androidMain
@Composable
actual fun StatusBarEffect(isDarkTheme: Boolean) {
    val view = LocalView.current
    LaunchedEffect(isDarkTheme) {
        val window = (view.context as Activity).window
        WindowCompat.getInsetsController(window, view)
            .isAppearanceLightStatusBars = !isDarkTheme
    }
}

@Composable
actual fun PlatformBackHandler(onBack: () -> Unit) {
    BackHandler(onBackPressed = onBack)
}

// iosMain
@Composable
actual fun StatusBarEffect(isDarkTheme: Boolean) {
    // iOS 通过 Info.plist 或 SwiftUI 配置
}

@Composable
actual fun PlatformBackHandler(onBack: () -> Unit) {
    // iOS 无系统返回按钮，可选实现手势
}


导航
Compose Multiplatform 的导航方案：


// 使用 Voyager 或自定义导航
sealed class Screen {
    data object UserList : Screen()
    data class UserDetail(val userId: Long) : Screen()
    data object Settings : Screen()
}

@Composable
fun AppNavigation() {
    var currentScreen by remember { mutableStateOf<Screen>(Screen.UserList) }

    when (val screen = currentScreen) {
        is Screen.UserList -> UserListScreen(
            onUserClick = { userId -> currentScreen = Screen.UserDetail(userId) },
            onSettingsClick = { currentScreen = Screen.Settings }
        )
        is Screen.UserDetail -> UserDetailScreen(
            userId = screen.userId,
            onBack = { currentScreen = Screen.UserList }
        )
        is Screen.Settings -> SettingsScreen(
            onBack = { currentScreen = Screen.UserList }
        )
    }
}


资源管理
Compose Multiplatform 提供了跨平台的资源管理方案：


// commonMain/composeResources/
//   drawable/logo.png
//   values/strings.xml

@Composable
fun AppLogo() {
    Image(
        painter = painterResource(Res.drawable.logo),
        contentDescription = "应用 Logo"
    )
}

@Composable
fun GreetingText() {
    Text(text = stringResource(Res.string.welcome_message))
}

主题共享
// commonMain
@Composable
fun AppTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    content: @Composable () -> Unit
) {
    val colorScheme = if (darkTheme) darkColorScheme(
        primary = Color(0xFF90CAF9),
        secondary = Color(0xFFA5D6A7)
    ) else lightColorScheme(
        primary = Color(0xFF1976D2),
        secondary = Color(0xFF388E3C)
    )

    MaterialTheme(
        colorScheme = colorScheme,
        typography = AppTypography,
        content = content
    )
}


提示： 主题定义完全在 commonMain 中共享，各平台自动适配深色/浅色模式。






各平台入口
// androidMain
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            AppTheme { AppNavigation() }
        }
    }
}

// desktopMain
fun main() = application {
    Window(onCloseRequest = ::exitApplication, title = "KMP App") {
        AppTheme { AppNavigation() }
    }
}

// iosMain
fun MainViewController(): UIViewController {
    return ComposeUIViewController {
        AppTheme { AppNavigation() }
    }
}


小结
    

  • Compose Multiplatform 将声明式 UI 共享扩展到 Android、iOS、Desktop 和 Web
    • 

  • 共享 Composable 函数与普通 Jetpack Compose 代码完全一致
    • 

  • 平台特定 UI（状态栏、返回按键）通过 expect/actual Composable 处理
    • 

  • 导航可使用自定义状态管理或第三方库（如 Voyager、Decompose）
    • 

  • 资源通过 composeResources/ 目录统一管理，使用 Res 对象访问
    • 

  • 主题在 commonMain 中定义一次，各平台自动适配
    • 

  • 各平台入口代码极少，核心 UI 逻辑完全共享
