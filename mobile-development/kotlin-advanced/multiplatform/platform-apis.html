平台 API 访问

在 Kotlin Multiplatform 项目中，访问各平台原生 API 是不可避免的需求。从文件系统到传感器、从数据库到网络，每个平台都有自己的 API 生态。KMP 提供了多种策略来桥接共享代码与平台特定功能。

平台模块设计模式

三种访问平台 API 的策略：

依赖注入方式
通过接口定义服务契约，各平台注入具体实现：


// commonMain — 服务接口
interface FileStorage {
    suspend fun readText(path: String): String
    suspend fun writeText(path: String, content: String)
    suspend fun exists(path: String): Boolean
}

interface LocationService {
    suspend fun getCurrentLocation(): Location?
}

data class Location(val latitude: Double, val longitude: Double)
// androidMain — Android 实现
class AndroidFileStorage(private val context: Context) : FileStorage {
    override suspend fun readText(path: String): String {
        return File(context.filesDir, path).readText()
    }

    override suspend fun writeText(path: String, content: String) {
        File(context.filesDir, path).writeText(content)
    }

    override suspend fun exists(path: String): Boolean {
        return File(context.filesDir, path).exists()
    }
}
// iosMain — iOS 实现
class IosFileStorage : FileStorage {
    private val fileManager = NSFileManager.defaultManager

    override suspend fun readText(path: String): String {
        val documentsPath = NSSearchPathForDirectoriesInDomains(
            NSDocumentDirectory, NSUserDomainMask, true
        ).first() as String
        val fullPath = "$documentsPath/$path"
        return NSString.stringWithContentsOfFile(fullPath, NSUTF8StringEncoding, null) ?: ""
    }

    override suspend fun writeText(path: String, content: String) {
        val documentsPath = NSSearchPathForDirectoriesInDomains(
            NSDocumentDirectory, NSUserDomainMask, true
        ).first() as String
        (content as NSString).writeToFile(
            "$documentsPath/$path", true, NSUTF8StringEncoding, null
        )
    }

    override suspend fun exists(path: String): Boolean {
        val documentsPath = NSSearchPathForDirectoriesInDomains(
            NSDocumentDirectory, NSUserDomainMask, true
        ).first() as String
        return fileManager.fileExistsAtPath("$documentsPath/$path")
    }
}


Ktor 跨平台网络
Ktor 是 KMP 中最成熟的跨平台网络库：


// commonMain
class ApiClient(private val httpClient: HttpClient) {
    suspend fun fetchUsers(): List<User> {
        return httpClient.get("https://api.example.com/users").body()
    }

    suspend fun createUser(user: User): User {
        return httpClient.post("https://api.example.com/users") {
            contentType(ContentType.Application.Json)
            setBody(user)
        }.body()
    }
}

// commonMain — 共享配置
expect fun createPlatformHttpClient(): HttpClient

// androidMain
actual fun createPlatformHttpClient(): HttpClient = HttpClient(Android) {
    install(ContentNegotiation) { json() }
    install(Logging) { level = LogLevel.BODY }
}

// iosMain
actual fun createPlatformHttpClient(): HttpClient = HttpClient(Darwin) {
    install(ContentNegotiation) { json() }
    install(Logging) { level = LogLevel.BODY }
}


提示： Ktor 的核心 API 完全跨平台，只有引擎（Android/Darwin/CIO）是平台特定的。






SQLDelight 跨平台数据库
SQLDelight 从 SQL 生成类型安全的 Kotlin API，完美支持 KMP：


-- commonMain/sqldelight/com/example/User.sq
CREATE TABLE User (
    id INTEGER NOT NULL PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT NOT NULL
);

selectAll:
SELECT * FROM User;

insert:
INSERT INTO User(id, name, email) VALUES (?, ?, ?);

findByName:
SELECT * FROM User WHERE name LIKE ?;
// commonMain — 使用生成的 API
class UserRepository(private val database: AppDatabase) {
    fun getAllUsers(): Flow<List<User>> {
        return database.userQueries.selectAll().asFlow().mapToList(Dispatchers.IO)
    }

    fun addUser(id: Long, name: String, email: String) {
        database.userQueries.insert(id, name, email)
    }
}
各平台提供数据库驱动：


// androidMain
actual fun createDriver(context: Context): SqlDriver {
    return AndroidSqliteDriver(AppDatabase.Schema, context, "app.db")
}

// iosMain
actual fun createDriver(): SqlDriver {
    return NativeSqliteDriver(AppDatabase.Schema, "app.db")
}


Native 互操作
Kotlin/Native 可以直接调用 C 和 Objective-C API：


// iosMain — 直接使用 Apple 框架
import platform.Foundation.*
import platform.UIKit.*
import platform.CoreLocation.*

class IosLocationService : LocationService {
    override suspend fun getCurrentLocation(): Location? = suspendCancellableCoroutine { cont ->
        val manager = CLLocationManager()
        manager.requestWhenInUseAuthorization()
        manager.delegate = object : NSObject(), CLLocationManagerDelegateProtocol {
            override fun locationManager(manager: CLLocationManager, didUpdateLocations: List<*>) {
                val loc = didUpdateLocations.firstOrNull() as? CLLocation
                cont.resume(loc?.let { Location(it.coordinate.latitude, it.coordinate.longitude) })
            }
        }
        manager.requestLocation()
    }
}

小结
    

  • 访问平台 API 有三种策略：expect/actual、接口 + DI、跨平台库
    • 

  • 接口 + 依赖注入是处理复杂平台服务的推荐方式，支持测试和灵活替换
    • 

  • Ktor 提供完整的跨平台网络能力，核心 API 完全共享
    • 

  • SQLDelight 从 SQL 生成类型安全的跨平台数据库 API
    • 

  • Kotlin/Native 可直接调用 C 和 Objective-C API，实现原生互操作
    • 

  • KMP 库生态日趋完善，覆盖网络、数据库、序列化、DI 等核心领域
    • 

  • 优先使用跨平台库，其次使用接口抽象，最后才考虑 expect/actual
