契约

Kotlin 契约（Contracts）是一种向编译器提供额外信息的机制，帮助编译器进行更智能的类型推断和流程分析。通过 contract { } DSL，开发者可以声明函数的调用语义，从而改善智能转换（smart cast）和可达性分析。

为什么需要契约

编译器无法自动推断所有函数的语义。考虑以下场景：

fun isNotEmpty(s: String?): Boolean = s != null && s.isNotEmpty()

fun demo(input: String?) {
    if (isNotEmpty(input)) {
        // 编译错误：编译器不知道 isNotEmpty 返回 true 意味着 input 非空
        // println(input.length)
    }
}

契约告诉编译器："当 isNotEmpty 返回 true 时，参数一定非空"，从而启用智能转换。

contract { } DSL

import kotlin.contracts.*

@OptIn(ExperimentalContracts::class)
fun isNotEmpty(s: String?): Boolean {
    contract {
        returns(true) implies (s != null)
    }
    return s != null && s.isNotEmpty()
}

fun demo(input: String?) {
    if (isNotEmpty(input)) {
        println(input.length) // 现在合法！编译器知道 input 非空
    }
}

提示： 契约 API 目前仍标记为 @ExperimentalContracts，但已广泛用于标准库中。

returns implies

returns implies 声明函数返回特定值时，某个条件成立：

@OptIn(ExperimentalContracts::class)
fun requirePositive(value: Int?): Boolean {
    contract {
        returns(true) implies (value != null)
    }
    return value != null && value > 0
}

@OptIn(ExperimentalContracts::class)
fun assertNotNull(value: Any?) {
    contract {
        returns() implies (value != null) // returns() = 正常返回（不抛异常）
    }
    if (value == null) throw IllegalArgumentException("值不能为空")
}

fun demo(name: String?) {
    assertNotNull(name)
    println(name.length) // 合法：编译器知道 name 非空
}
契约表达式 含义
returns(true) implies (x != null) 返回 true 时 x 非空
returns(false) implies (x == null) 返回 false 时 x 为空
returns() implies (x != null) 正常返回时 x 非空
returns(null) implies (x is Type) 返回 null 时 x 是某类型

callsInPlace

callsInPlace 声明 lambda 参数的调用语义——调用次数和位置：

@OptIn(ExperimentalContracts::class)
inline fun <R> myRun(block: () -> R): R {
    contract {
        callsInPlace(block, InvocationKind.EXACTLY_ONCE)
    }
    return block()
}

fun demo() {
    val x: Int
    myRun {
        x = 42 // 合法：编译器知道 block 恰好执行一次
    }
    println(x) // 合法：x 一定已初始化
}

InvocationKind 的取值：

种类 含义 效果
EXACTLY_ONCE 恰好调用一次 允许在 lambda 中初始化 val
AT_MOST_ONCE 最多调用一次 可以在 lambda 中赋值，但不能确保已初始化
AT_LEAST_ONCE 至少调用一次 允许在 lambda 中初始化 val
UNKNOWN 未知次数 默认，最保守

标准库中的契约

Kotlin 标准库大量使用契约来提升开发体验：

// stdlib 中 require 的契约
public inline fun require(value: Boolean) {
    contract {
        returns() implies value // 正常返回意味着 value 为 true
    }
    if (!value) throw IllegalArgumentException()
}

// stdlib 中 check 的契约
public inline fun check(value: Boolean) {
    contract {
        returns() implies value
    }
    if (!value) throw IllegalStateException()
}

// stdlib 中 let/run/apply/also 的契约
public inline fun <T, R> T.let(block: (T) -> R): R {
    contract {
        callsInPlace(block, InvocationKind.EXACTLY_ONCE)
    }
    return block(this)
}

这些契约使得以下代码合法：

fun process(input: Any?) {
    require(input != null)
    // 编译器知道 input 非空
    println(input.toString())

    require(input is String)
    // 编译器知道 input 是 String
    println(input.length)
}


自定义契约函数
类型检查契约
@OptIn(ExperimentalContracts::class)
fun Any?.isString(): Boolean {
    contract {
        returns(true) implies (this@isString is String)
    }
    return this is String
}

fun printLength(value: Any?) {
    if (value.isString()) {
        println(value.length) // smart cast 为 String
    }
}
初始化保证契约
@OptIn(ExperimentalContracts::class)
inline fun <T> initOnce(block: () -> T): T {
    contract {
        callsInPlace(block, InvocationKind.EXACTLY_ONCE)
    }
    return block()
}

fun demo() {
    val connection: DatabaseConnection
    val startTime: Long

    initOnce {
        connection = DatabaseConnection("localhost")
        startTime = System.currentTimeMillis()
    }

    println(connection) // 合法
    println(startTime)  // 合法
}


契约的限制
    

  1. 只能在顶层函数或成员函数体的第一条语句：
    2. 



fun example() {
    contract { /* ... */ } // 必须是第一条语句
    // 其余代码
}
    

  1. 编译器信任但不验证：契约的正确性由开发者保证，错误的契约会导致运行时错误
    

    2. 

  2. 不能用于抽象函数或接口方法：
    

    3. 



// interface Validator {
//     fun isValid(s: String?): Boolean // 不能在接口中声明契约
// }
    

  1. 目前仍为实验性 API：需要 @OptIn(ExperimentalContracts::class)
    2. 





提示： 虽然是实验性 API，但标准库中广泛使用证明了其稳定性。在自定义代码中谨慎使用，确保契约声明与实际行为一致。






小结
    

  • 契约向编译器提供函数的额外语义信息，改善类型推断和流程分析
    • 

  • returns implies 声明返回值与参数条件的关联，启用 smart cast
    • 

  • callsInPlace 声明 lambda 的调用次数，允许在 lambda 中安全初始化 val
    • 

  • 标准库的 require、check、let、run 等函数都使用了契约
    • 

  • 契约的正确性由开发者保证，编译器信任但不验证
    • 

  • 限制：只能在函数体第一条语句、不能用于抽象方法、仍为实验性 API
