委托

委托（Delegation）是 Kotlin 中替代继承的核心设计模式。通过类委托（by）和属性委托（by lazy、by observable 等），Kotlin 在语言层面原生支持委托模式，让代码更加简洁、灵活和可组合。

类委托

类委托通过 by 关键字，将接口的实现委托给另一个对象：

interface Printer {
    fun print(message: String)
}

class ConsolePrinter : Printer {
    override fun print(message: String) = println("[控制台] $message")
}

class LoggingPrinter(private val delegate: Printer) : Printer by delegate {
    override fun print(message: String) {
        println("[日志] 即将打印: $message")
        delegate.print(message) // 调用被委托对象
    }
}

val printer = LoggingPrinter(ConsolePrinter())
printer.print("Hello") // [日志] 即将打印: Hello \n [控制台] Hello
类委托编译后，编译器自动生成所有接口方法的转发代码。被覆盖的方法使用自定义实现，未覆盖的直接转发。




提示： 类委托遵循"组合优于继承"原则，一个类可以同时委托多个接口给不同对象。






多接口委托
interface Logger {
    fun log(msg: String)
}

interface Metrics {
    fun record(event: String, value: Double)
}

class ConsoleLogger : Logger {
    override fun log(msg: String) = println(msg)
}

class InMemoryMetrics : Metrics {
    override fun record(event: String, value: Double) {
        println("$event: $value")
    }
}

class Service(
    logger: Logger,
    metrics: Metrics
) : Logger by logger, Metrics by metrics

val service = Service(ConsoleLogger(), InMemoryMetrics())
service.log("启动完成")
service.record("latency", 42.0)


属性委托
属性委托通过 by 关键字将属性的 get/set 操作委托给另一个对象。


lazy — 延迟初始化
val heavyObject: HeavyResource by lazy {
    println("初始化 HeavyResource")
    HeavyResource()
}
// 首次访问时才初始化，后续访问使用缓存值

observable — 变化监听
import kotlin.properties.Delegates

var name: String by Delegates.observable("初始值") { prop, old, new ->
    println("${prop.name}: $old -> $new")
}

name = "张三" // name: 初始值 -> 张三
name = "李四" // name: 张三 -> 李四
vetoable — 变化拦截
var age: Int by Delegates.vetoable(0) { _, old, new ->
    new in 0..150 // 返回 false 则拒绝赋值
}

age = 25  // 接受
age = -1  // 拒绝，age 仍为 25
age = 200 // 拒绝，age 仍为 25

自定义属性委托
实现 ReadOnlyProperty 或 ReadWriteProperty 接口来创建自定义委托：


import kotlin.properties.ReadWriteProperty
import kotlin.reflect.KProperty

class TrimmedString : ReadWriteProperty<Any?, String> {
    private var value: String = ""

    override fun getValue(thisRef: Any?, property: KProperty<*>): String = value

    override fun setValue(thisRef: Any?, property: KProperty<*>, value: String) {
        this.value = value.trim()
    }
}

class UserForm {
    var username: String by TrimmedString()
    var email: String by TrimmedString()
}

val form = UserForm()
form.username = "  admin  "
println(form.username) // "admin"
更简洁的写法使用运算符函数：


class Cached<T>(private val compute: () -> T) {
    private var cachedValue: T? = null

    operator fun getValue(thisRef: Any?, property: KProperty<*>): T {
        return cachedValue ?: compute().also { cachedValue = it }
    }
}

val expensiveResult by Cached { performHeavyCalculation() }


Map 委托
Kotlin 支持将属性委托给 Map，非常适合解析动态数据：


class Config(map: Map<String, Any?>) {
    val host: String by map
    val port: Int by map
    val debug: Boolean by map
}

val config = Config(
    mapOf(
        "host" to "localhost",
        "port" to 8080,
        "debug" to true
    )
)

println(config.host) // localhost
println(config.port) // 8080
可变版本使用 MutableMap：


class MutableConfig(map: MutableMap<String, Any?>) {
    var host: String by map
    var port: Int by map
}


实际应用：SharedPreferences 委托
class PreferenceDelegate<T>(
    private val prefs: SharedPreferences,
    private val key: String,
    private val defaultValue: T
) : ReadWriteProperty<Any?, T> {

    @Suppress("UNCHECKED_CAST")
    override fun getValue(thisRef: Any?, property: KProperty<*>): T {
        return when (defaultValue) {
            is String -> prefs.getString(key, defaultValue) as T
            is Int -> prefs.getInt(key, defaultValue) as T
            is Boolean -> prefs.getBoolean(key, defaultValue) as T
            is Long -> prefs.getLong(key, defaultValue) as T
            else -> throw IllegalArgumentException("不支持的类型")
        }
    }

    override fun setValue(thisRef: Any?, property: KProperty<*>, value: T) {
        prefs.edit().apply {
            when (value) {
                is String -> putString(key, value)
                is Int -> putInt(key, value)
                is Boolean -> putBoolean(key, value)
                is Long -> putLong(key, value)
            }
            apply()
        }
    }
}

class Settings(prefs: SharedPreferences) {
    var username: String by PreferenceDelegate(prefs, "username", "")
    var darkMode: Boolean by PreferenceDelegate(prefs, "dark_mode", false)
    var fontSize: Int by PreferenceDelegate(prefs, "font_size", 14)
}

    • 

  • 一个类可以同时委托多个接口给不同对象
    • 

  • lazy 延迟初始化，observable 监听变化，vetoable 验证并拦截赋值
    • 

  • 自定义委托通过实现 ReadWriteProperty 或运算符函数创建
    • 

  • Map 委托适合解析 JSON、配置文件等动态数据
    • 

  • 属性委托在 Android 开发中广泛用于 SharedPreferences、ViewModel、Bundle 等场景
