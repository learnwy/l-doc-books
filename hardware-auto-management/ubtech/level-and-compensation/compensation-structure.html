优必选薪酬结构：深圳科创企业水平与港股激励

薪酬定位：科创企业上游水平

作为港股上市的人形机器人龙头企业，优必选的薪酬定位处于深圳科创企业的上游区间。2025 年公司销售/管理/研发三项费用合计 25.61 亿元，在约 2000 人的团队规模下，人均成本约 128 万元/年（含社保、福利、办公等）。

股权激励工具
    

  1. 限制性股票（RSU）
    

      

    • 授予时约定解锁条件（通常为服务年限+业绩条件）
      • 

    • 适用于中高级别员工的长期绑定
      • 

    • 优势：员工无需出资，降低参与门槛
      • 

    

    2. 

  2. 股票期权
    

      

    • 授予行权价（通常为授予日市价），员工享受股价上涨收益
      • 

    • 适用于早期加入的核心员工
      • 

    • 风险：若股价低于行权价则期权无价值
      • 

    

    3. 



股权的实际价值
由于优必选股价波动较大（52 周高低价差近 3 倍），股权激励的实际价值具有高度不确定性：


    

  • 乐观情景：若花旗 190 港元目标价实现，早期获授股权价值显著
    • 

  • 中性情景：股价维持 100 港元左右，股权作为补充收入
    • 

  • 悲观情景：亏损持续+解禁压力，股价回落则股权价值缩水
    •

优必选的奖金分配遵循"业务导向"原则：


    

  • 2025 年全尺寸人形机器人业务收入暴增 2203.7%，相关团队奖金系数显著高于其他业务线
    • 

  • 工业场景落地团队（占交付的 80%+）获得更高的项目奖金
    • 

  • 专利产出直接与现金奖金挂钩（2985 项专利的激励效果）

薪酬竞争力分析
优势
    

  1. 股权想象空间大：人形机器人万亿赛道叙事，股价有上涨空间
    2. 

  2. 技术挑战度高：前沿技术方向（具身智能）的履历价值
    3. 

  3. 行业头部地位："人形机器人第一股"的品牌加成
    4. 

  4. 深圳生态加持：供应链+人才+政策的综合优势
    5. 



劣势
    

  1. 现金薪资偏保守：相比互联网大厂，纯现金部分可能偏低
    2. 

  2. 股权不确定性：持续亏损+频繁配股稀释+股价波动
    3. 

  3. 加班文化：硬件+交付驱动的行业，工作强度较大
    4. 

  4. 盈利前景不明：2022-2025 累计亏损 42 亿，何时盈利存不确定性
    5. 



谈薪建议
    

  1. 区分现金与股权：明确 offer 中现金部分和股权部分的比例
    2. 

  2. 关注解锁条件：RSU 的解锁是否有业绩条件（如公司扭亏为盈）
    3. 

  3. 评估行权价：期权的行权价相对当前股价是否合理
    4. 

  4. 考虑签字费：高级别岗位可以谈判 Sign-on Bonus
    5. 

  5. 了解配股稀释：频繁配股会稀释现有股权激励的价值
    6.
