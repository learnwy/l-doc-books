SpaceX 绩效考核

概述：极致目标导向的考核体系

SpaceX 的绩效考核不是传统的 HR 流程——它是使命驱动型组织的自然淘汰机制。在这里，绩效不是"做得好不好"的问题，而是"你是否在帮助人类成为多行星物种"的问题。考核极其直接、高压、且后果严重。

考核框架

核心原则

原则 具体表现 传统公司对比
结果唯一 只看产出，不看过程 过程+结果综合评估
目标极限化 设定"不可能"的目标 合理且可达的目标
实时反馈 随时直接告知问题 季度/年度正式评审
快速淘汰 表现不达标直接走人 PIP → 改善期 → 再评估
Musk 直接介入 CEO 直接淘汰人 层层审批后 HR 执行

考核对职业发展的影响
正面影响
    

  • 绩效好 → 快速晋升（无需等待窗口）
    • 

  • 被 Musk 注意到 → 直线上升机会
    • 

  • 解决难题 → 跨级别可见度
    • 

  • 持续高绩效 → 额外股权授予
    • 



负面影响
    

  • 高压导致决策保守（避免失败被注意到）
    • 

  • 恐惧文化抑制坦诚沟通
    • 

  • 短期交付压力 vs 长期技术质量
    • 

  • Burnout 导致优秀人才流失
    • 





对管理者的启示
可借鉴
    

  1. 目标设高：高目标即使只完成 60% 也超过低目标的 100%
    2. 

  2. 结果导向：关注产出而非过程和态度
    3. 

  3. 快速反馈：问题发现即反馈，不等到年度评审
    4. 

  4. 淘汰果断：不让低绩效者拖累团队
    5. 



需谨慎
    

  1. 恐惧 ≠ 尊重：恐惧文化短期有效但长期有毒
    2. 

  2. Burnout 成本：人才流失的隐性成本被低估
    3. 

  3. 公平性：CEO 直接介入可能导致不公平
    4. 

  4. 可持续性：极端模式在组织扩大后难以维持
    5.
