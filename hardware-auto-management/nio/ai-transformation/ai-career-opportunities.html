AI 时代的蔚来职业机会

AI转型催生的岗位结构变化

蔚来的全域AI转型正在从根本上改变公司的岗位结构。一些传统岗位的需求在下降，另一些新兴岗位则在快速扩张。理解这种结构性变化，对于求职者选择方向和在职员工规划发展至关重要。

六大AI职业赛道深度分析
赛道一：端到端自动驾驶
这是蔚来AI转型最核心的赛道，也是人才需求最旺盛的方向。


入场要求：


    

  • 学历：硕士及以上（顶会论文发表者优先）
    • 

  • 技能：深度学习框架精通（PyTorch为主）、CV/多模态模型经验、端侧部署经验
    • 

  • 经验：有自动驾驶或大模型训练经验者强优先
    • 



成长路径：


    

  • P2入职→12个月上手NADArch 2.0某模块→P3负责某端到端子方向
    • 

  • P3→P4的关键跃升：从"用模型"到"设计模型架构"，需要对世界模型、强化学习有深入理解
    • 



薪酬水平：蔚来在端到端方向的薪资处于行业前列——P3级别AI算法工程师年薪60-80万（含RSU），顶尖P4可达120万+。


赛道二：车载大模型
NOMI与大模型的深度集成催生了一个全新的技术方向。


入场要求：


    

  • 学历：本科及以上（有LLM项目经验优先）
    • 

  • 技能：大语言模型微调和推理优化、模型量化和蒸馏、Prompt Engineering
    • 

  • 经验：有模型部署到资源受限环境的经验加分
    • 



核心挑战：


    

  • 在有限的车端算力下实现可接受的推理延迟
    • 

  • 保证大模型输出在驾驶场景中的安全性（抑制幻觉）
    • 

  • 平衡通用能力和车载场景的专精性
    • 



成长路径：


    

  • 这个方向在蔚来和行业都处于早期阶段，率先入场的工程师有机会快速成长
    • 

  • 2-3年内可能从P2/P3成长为蔚来车载大模型方向的技术骨干
    • 



赛道三：AI芯片
随着神玑芯片科技开始对外输出，芯片团队的人才需求正在扩张。


入场要求：


    

  • 学历：硕士及以上（EE/CS背景）
    • 

  • 技能：芯片架构设计、RTL开发、验证方法学、AI加速器架构
    • 

  • 经验：有SoC开发或AI芯片项目经验优先
    • 



蔚来芯片岗位的独特优势：


    

  • 不同于纯芯片公司，蔚来的芯片工程师可以直接看到芯片在整车系统中的应用效果
    • 

  • "算法定义芯片"的模式使芯片工程师需要与算法团队密切协作，技术视野更宽
    • 



赛道四：数据和仿真
群体智能数据闭环和NSim生成式仿真是蔚来AI能力持续进化的引擎。


入场要求：


    

  • 学历：本科及以上
    • 

  • 技能：大数据处理（Spark/Flink）、数据挖掘、生成模型（用于仿真场景生成）
    • 

  • 经验：有自动驾驶数据处理或仿真系统开发经验加分
    • 



成长路径：


    

  • 数据工程师→高级数据工程师→数据架构师
    • 

  • 仿真工程师→生成式仿真研发→仿真平台负责人
    • 



赛道五：AI基础设施
AI系统的训练、推理和部署需要强大的基础设施支撑。


入场要求：


    

  • 学历：本科及以上
    • 

  • 技能：Kubernetes、分布式训练框架（DeepSpeed/Megatron）、GPU编程（CUDA）
    • 

  • 经验：有大规模ML系统运维经验优先
    • 



行业趋势：随着大模型训练规模不断增大，AI基础设施工程师的需求在全行业急剧上升，蔚来也不例外。


赛道六：AI产品经理
AI转型不只需要工程师，还需要理解AI能力边界的产品经理来定义产品。


核心能力：


    

  • 理解AI技术的能力边界和局限性
    • 

  • 能够将用户需求转化为AI可解决的问题定义
    • 

  • 具备数据驱动的产品决策能力
    • 

  • 理解智能驾驶和座舱AI的安全合规要求
    • 



蔚来特色：蔚来的AI产品经理需要额外理解"用户企业"理念——AI产品不只是功能交付，更是用户体验和社区价值的一部分。


面向不同人群的建议
在校学生
最具价值的准备方向：


    

  1. 端到端自动驾驶和世界模型方向——蔚来2026届校招重点方向
    2. 

  2. 大模型部署和优化——跨行业通用能力+蔚来车载场景的特殊要求
    3. 

  3. 蔚来校招投递渠道：nio.jobs.feishu.cn
    4. 



推荐学习路径：


    

  • 大二-大三：打牢深度学习基础（CS231n、CS224n等经典课程）
    • 

  • 研一：确定具体方向（感知/规划/大模型/仿真），开始做项目
    • 

  • 研二：冲刺顶会论文，同时积累工程化能力（模型量化、端侧部署）
    • 

  • 求职季：准备蔚来面试——算法基础+项目深度+对蔚来技术栈的理解
    •

关键提醒：互联网到汽车的转型不只是技术栈的变化，更是工作节奏和安全标准的变化。功能安全（ISO 26262）对代码质量的要求远高于互联网应用，需要适应更严格的审查流程。


传统车企工程师
AI时代的转型紧迫性：传统车企的电子电气工程师如果不主动拥抱AI，可能在未来3-5年面临职业瓶颈——智能驾驶和智能座舱正在从"加分项"变成"必备项"，传统嵌入式开发的价值占比在下降。


蔚来对传统车企人才的吸引力：


    

  • 全域自研体系提供了从传统嵌入式向AI方向转型的内部通道
    • 

  • 蔚来内部有Sparks计划等培训项目支持跨方向学习
    • 

  • 在蔚来积累的AI+汽车复合经验在行业中具有稀缺性
    • 



在职蔚来员工
AI加速个人发展的策略：


    

  1. 主动学习AI工具——在日常工作中使用AI辅助编码、文档和分析
    2. 

  2. 关注NWM和NOMI的技术迭代——即使不在智驾或座舱团队，理解公司核心AI方向也有助于跨部门协作和晋升面试
    3. 

  3. 参加蔚来内部AI培训和技术分享——利用公司资源加速学习曲线
    4. 

  4. 思考AI对自身岗位的影响——主动拥抱变化而非被动等待
    5.

蔚来AI岗位的风险因素
在看好蔚来AI方向的同时，也需要客观认识风险：


    

  1. 行业竞争风险：华为、百度、Waymo等在智驾领域的投入巨大，蔚来在人才争夺中并非绝对优势方
    2. 

  2. 公司经营风险：虽然2025年Q4首次盈利，但全年仍处于亏损状态，研发投入的持续性取决于公司财务健康度
    3. 

  3. 技术路线风险：全域自研的赌注意味着如果某条技术路线判断失误（如世界模型方向不及预期），调整成本高昂
    4. 

  4. 组织调整风险：蔚来历史上经历过多次组织架构调整和裁员，AI团队也不完全免疫
    5. 



总体判断：对于AI方向的求职者和从业者而言，蔚来提供了中国新能源汽车行业中最完整的全域自研AI实践平台。在这里积累的"AI+汽车"复合经验在行业中具有高度稀缺性和可迁移性——即使未来职业路径发生变化，这段经验的价值也不会贬值。
