蔚来自动驾驶工程师专项路线

蔚来智驾技术栈概览

蔚来的智能驾驶团队是公司技术投入最大、人才密度最高的核心部门之一。围绕NOP+（Navigate on Pilot Plus）全域领航辅助系统，蔚来构建了一套涵盖感知、规划决策、定位建图和仿真测试的完整算法技术栈。

2025年底，蔚来全面转向"NWM世界模型+端到端"架构（NADArch 2.0），标志着从基于规则的传统方案向大模型驱动的新范式迈进。这一架构升级带来了岗位结构和能力要求的显著变化。

四大算法子方向
感知方向
感知算法工程师负责让汽车"看见"周围的世界——识别车辆、行人、交通标志、车道线和各种障碍物。


核心技术栈：


    

  • 多传感器融合（激光雷达+摄像头+4D毫米波雷达）
    • 

  • 3D目标检测与跟踪（PointPillars、CenterPoint等）
    • 

  • 语义分割与全景分割
    • 

  • BEV（鸟瞰图）感知架构
    • 

  • 端到端感知在NADArch 2.0中的新范式
    • 



蔚来特色：蔚来ES9搭载3颗128线激光雷达、4D成像雷达及31个感知硬件组成的AQUILA超感系统，感知硬件配置在行业中处于领先水平。这意味着感知工程师需要处理多模态、大数据量的传感器融合任务。

规划决策方向
规划决策工程师负责让汽车"做出决策"——在复杂的交通环境中选择最优的行驶策略和轨迹。


核心技术栈：


    

  • 行为预测（Trajectory Prediction）
    • 

  • 路径规划（Lattice Planner、Optimization-based）
    • 

  • 决策模型（强化学习、博弈论）
    • 

  • NWM世界模型的规划集成
    • 

  • 端到端规划在NADArch 2.0中的应用
    • 



蔚来特色：NWM世界模型能在100毫秒内推演216种可能的行车场景并选择最优路径。规划决策工程师需要深度参与世界模型的训练和调优工作，这是蔚来与其他车企规划岗位的重要差异。

定位建图方向
定位建图工程师负责让汽车"知道自己在哪"——在GPS信号不稳定的城市环境中实现精确定位。


核心技术栈：


    

  • SLAM（同时定位与建图）
    • 

  • 多源融合定位（LiDAR/Camera/Radar/IMU/Wheel）
    • 

  • 语义地图构建
    • 

  • 无GNSS场景下的高精定位
    • 

  • 车端实时局部建图
    • 



蔚来招聘要求参考（基于公开岗位描述）：


    

  • 2年以上SLAM定位建图工作经验
    • 

  • 扎实的状态估计、数值计算、C++编程能力
    • 

  • 熟悉经典SLAM算法框架（FastLIO/LOAM系/MSCKF/VINS等）
    • 

  • 有智驾业务量产落地经验者优先
    • 



仿真测试方向
仿真测试工程师负责在虚拟环境中验证智驾算法的安全性和性能。


核心技术栈：


    

  • 场景生成（基于真实数据的合成场景）
    • 

  • NSim仿真平台的开发和维护
    • 

  • 自动化测试框架
    • 

  • 数据回灌与回放分析
    • 

  • 生成式仿真数据的质量评估
    • 



蔚来特色：NSim（NIO Simulation）是蔚来自研的生成式仿真平台，可以基于真实世界数据生成千万级虚拟场景，与NWM世界模型形成闭环训练。仿真工程师在蔚来的智驾体系中扮演着连接算法开发和量产验证的关键桥梁角色。


从算法工程师到技术专家的晋升路径
P2→P3：从"能做"到"能负责"
这是智驾工程师最关键的晋升跃迁，核心转变是从"完成分配的算法任务"到"独立负责一个完整的算法模块"。


关键能力跃迁：


    

  1. 从单一算法实现到端到端方案设计
    2. 

  2. 从被动接受需求到主动发现技术机会
    3. 

  3. 从个人产出到带领1-2名初级工程师
    4. 

  4. 从学术论文复现到量产工程优化
    5. 



常见卡级原因：


    

  • 过度追求学术指标（论文数量）而忽视量产落地能力
    • 

  • 技术视野局限于自己负责的单一模块，缺乏系统级思维
    • 

  • 沟通协作能力不足，无法有效推动跨模块的技术方案
    • 



P3→P4：从"技术骨干"到"技术方向负责人"
P4是智驾团队的技术核心层，需要具备技术方向的判断力和影响力。


关键能力跃迁：


    

  1. 从模块级负责到子系统级架构设计
    2. 

  2. 从执行既定技术路线到参与技术路线决策
    3. 

  3. 从指导初级工程师到培养技术梯队
    4. 

  4. 从关注当前项目到前瞻性技术预研
    5. 



P4→P5：从"技术专家"到"技术领导者"
P5级别在蔚来智驾团队中属于稀缺资源，需要具备行业级别的技术影响力。


必要条件：


    

  • 在核心技术方向上有业界认可的贡献（论文、专利、开源项目）
    • 

  • 能够独立判断2-3年的技术发展趋势并据此制定团队路线图
    • 

  • 在蔚来内部技术委员会中有实质性话语权
    • 

  • 有能力代表蔚来参与行业标准制定和学术交流
    • 



智驾工程师的竞争力建设
学习资源推荐（按方向分层）：


感知方向：


    

  • 入门：Stanford CS231n、OpenCV官方教程
    • 

  • 进阶：MMDetection3D开源框架、nuScenes数据集实战
    • 

  • 高阶：BEVFormer系列论文、端到端感知最新综述
    • 



规划决策方向：


    

  • 入门：Steven LaValle《Planning Algorithms》
    • 

  • 进阶：强化学习经典教材（Sutton & Barto）
    • 

  • 高阶：NWM类世界模型的最新论文
    • 



定位建图方向：


    

  • 入门：State Estimation for Robotics（Timothy Barfoot）
    • 

  • 进阶：ORB-SLAM3、LIO-SAM源码精读
    • 

  • 高阶：Neural Implicit Representations在SLAM中的应用
    • 



AI时代的技能升级：随着蔚来转向端到端架构，传统的"模块化"算法工程师需要主动拥抱大模型范式——理解Transformer架构、掌握大规模分布式训练、具备数据驱动的思维方式。能够跨越"传统算法"和"大模型"两种范式的工程师，在蔚来的智驾团队中最具竞争力。
