理想汽车绩效考核体系

绩效考核概览

理想汽车的绩效考核体系融合了OKR目标管理、数据驱动评估和强制分布淘汰三大要素，形成了一套高压但高效的绩效管理系统。这套体系直接影响着每位员工的年终奖、晋升和去留。

绩效等级体系

理想汽车将员工绩效分为五个等级，从高到低分别为O、E、M、I、F。

等级 含义 比例分布 影响
O（Outstanding） 杰出 ~5% 高额年终奖+优先晋升+RSU机会
E（Excellent） 优秀 ~15% 高年终奖+晋升候选
M（Meet） 达标 ~70% 标准年终奖+保持现有职级
I（Improvement） 待改进 ~8% 低年终奖+绩效改进计划
F（Fail） 不合格 ~2% 面临淘汰/解除劳动合同

271淘汰制

理想汽车实行激进的"271"淘汰制——20%优秀（O+E）、70%合格（M）、10%淘汰候选（I+F）。获得I或F评级的员工面临直接的去留风险：

  • I级：进入绩效改进计划（PIP），给予一个考核周期的改进机会。如果下一周期仍为I或F，则启动淘汰流程
  • F级：直接进入淘汰流程，通常补偿方案为N+1

这套淘汰机制的执行力度在2025年尤为严格——公司全年交付量下滑19%，为降本增效裁员了约20%的研发团队。

OKR风格的目标管理

OKR框架

理想汽车的绩效目标设定采用OKR（Objectives and Key Results）框架，但与纯互联网公司的OKR实践有所不同——理想的OKR更接近KPI导向，强调量化结果而非过程探索。

维度 纯OKR模式 理想汽车OKR
目标设定 鼓励挑战性目标，不惩罚未达成 目标需有挑战性，但未达成直接影响绩效
评估方式 关注进展和学习 关注可量化的结果
与薪酬关系 解耦（OKR不直接挂钩薪酬） 强挂钩（OKR达成度直接影响年终奖和绩效评级）
更新频率 季度更新 月度Review+季度校准

目标设定原则

李想强制要求所有目标必须满足以下标准：

  1. 用户价值导向：每个目标都必须回答"这如何创造用户价值"
  2. 可量化：必须有明确的量化指标和时间节点
  3. 有挑战性：目标完成60-70%才算基本达标，100%完成说明目标设定不够激进
  4. 可追溯：每个关键结果都必须有数据支撑，不接受"感觉做得不错"

月度Review机制

理想汽车的绩效管理不是"年初定目标、年末看结果"，而是通过月度Review实现持续跟踪和及时调整。

Review流程

Review的核心内容
每次月度Review需要覆盖以下内容：


    

  1. 目标进展：本月各KR的完成情况，用数据说话
    2. 

  2. 问题识别：遇到了什么障碍？是否需要资源支持？
    3. 

  3. 竞品动态：竞品有什么新动作？对我们有什么影响？
    4. 

  4. 下月计划：下月的重点工作和预期产出
    5. 



数据驱动的复盘文化
李想的管理风格中有一个核心特征——对数据的执着。这反映在绩效管理中的具体表现是：


    

  • 每个业务决策都必须有数据支撑，"我觉得"不被接受
    • 

  • 复盘不是走过场，而是深入分析根因和改进方案
    • 

  • 建立了完整的业务数据看板，各层级管理者可以实时查看关键指标
    • 



考核周期演变
理想汽车的考核周期经历了一次重要调整：


    

  • 2023年3月之前：季度考核（一季度一次），考核比例按"262"划分（20%优秀、60%合格、20%待改进）
    • 

  • 2023年3月之后：调整为半年度考核，考核比例改为"271"（20%优秀、70%合格、10%淘汰候选）
    • 



这一调整的目的是：


    

  • 减少频繁考核对员工心理的压力
    • 

  • 给予更长的周期来评估员工的真实贡献
    • 

  • 将淘汰比例从20%收窄至10%，但执行更为坚决
    •

绩效→晋升
    

  • O/E连续两个周期：进入晋升快速通道
    • 

  • M：正常晋升节奏（通常2-3年晋升一级）
    • 

  • I/F：晋升冻结，需先回到M以上
    • 



绩效→RSU
    

  • O评级员工有机会获得额外的RSU授予
    • 

  • E评级员工在晋升时可获得新一轮RSU
    • 

  • M及以下评级通常不会获得新的RSU
    • 



考核体系的争议与反思
正面评价
    

  • 强绩效导向有效推动了组织效率，理想汽车的人均产出在新势力中领先
    • 

  • 数据驱动的评估方式减少了主观判断的影响
    • 

  • 高频Review帮助员工及时调整方向，避免年末"算总账"
    • 



负面争议
    

  • 强制分布的"271"淘汰制造成了内部的恐惧文化，"每个季度都怕被裁"的情绪蔓延
    • 

  • 绩效评级在实践中受到业务线权重、领导偏好等非绩效因素的影响
    • 

  • 高淘汰率（38.2%人员流失率）导致组织知识持续流失，新人入职后需要较长时间才能达到前任的效率
    • 

  • 频繁的组织调整让绩效目标缺乏连续性，员工可能因为组织变动而非个人表现被评为I/F
    •
