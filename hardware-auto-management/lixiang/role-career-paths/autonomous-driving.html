理想汽车自动驾驶工程师路线

AD Max与AD Pro双平台架构

理想汽车的自动驾驶系统分为两个平台：AD Max（高阶辅助驾驶）和AD Pro（基础辅助驾驶），分别面向不同价位的车型和功能需求。

维度 AD Max AD Pro
计算平台 英伟达Orin-X双芯片（508TOPS） 地平线征程5（128TOPS）
激光雷达 1颗禾赛AT128 无
摄像头 12颗800万像素 9颗
核心功能 城市NOA+高速NOA+VLA 高速NOA+基础辅助驾驶
搭载车型 Max/Ultra版本 Pro版本

技术架构演进

理想汽车的自动驾驶技术经历了四次关键的架构迭代：

细分方向与成长路线
方向一：感知算法
技术范围：3D目标检测、语义分割、车道线识别、障碍物检测、交通标志识别


核心技能树：| 级别 | 技能要求 | | --- | --- | | 初级（11-15级） | PyTorch/TensorFlow、CNN/ViT基础、数据标注流程 | | 中级（16-18级） | BEV感知算法、3D点云处理、多传感器融合 | | 高级（19-20级） | Transformer-based感知架构设计、3D ViT Encoder | | 专家（21级+） | 感知系统架构、跨模态融合、端到端感知方案 |


关键技术挑战：


    

  • 小目标检测（外卖骑手、锥桶等，理想BEV Transformer V3将识别率提升25%）
    • 

  • 夜间/恶劣天气感知（摄像头夜间低光识别能力增强30%）
    • 

  • 多传感器融合的时空一致性
    • 



方向二：规划控制
技术范围：路径规划、行为决策、运动控制、轨迹优化


核心技能树：| 级别 | 技能要求 | | --- | --- | | 初级（11-15级） | 控制理论基础、C++编程、ROS框架 | | 中级（16-18级） | 强化学习、模型预测控制（MPC）、运动规划算法 | | 高级（19-20级） | VLA行为生成、并行解码、离散扩散优化 | | 专家（21级+） | 端到端规控系统架构、物理世界建模 |


VLA架构下的规划控制革新：


理想汽车的VLA司机大模型彻底改变了传统的规划控制范式——从"规则编写"变为"模型生成"。在VLA架构下：


    

  • 感知、决策、控制统一到一个模型中
    • 

  • 行为生成通过VLA-MoE混合专家模型实现
    • 

  • 采用并行解码同时生成所有轨迹点
    • 

  • 引入Discrete Diffusion进行多轮迭代优化
    • 



方向三：定位与建图
技术范围：SLAM、高精定位、地图构建、点云配准


核心技能树：


    

  • 初级：SLAM基础（ORB-SLAM、LIO-SAM等）
    • 

  • 中级：视觉-惯性里程计（VIO）、高精地图数据处理
    • 

  • 高级：无图方案设计（理想已实现无高精地图的城市NOA）
    • 

  • 专家：大规模建图系统架构、众包地图更新
    • 



方向四：仿真与测试
技术范围：仿真环境搭建、场景生成、回归测试、安全验证


核心技能树：


    

  • 初级：仿真工具使用（CARLA、LGSVL等）
    • 

  • 中级：场景自动生成、Corner Case设计
    • 

  • 高级：闭环仿真系统设计、大规模并行仿真
    • 

  • 专家：仿真-实车一致性优化、安全验证体系
    • 



仿真在VLA训练中的关键作用：


VLA模型的训练高度依赖仿真环境。理想汽车通过"生成数据+仿真环境训练"的方式，有效解决了传统方案难以覆盖极端场景（Corner Case）的痛点。仿真工程师的价值在VLA时代大幅提升。


自动驾驶工程师的独特挑战
安全责任
自动驾驶是一个"失误零容忍"的领域。每一行代码都可能影响乘客的人身安全。这要求工程师具备：


    

  • 严格的代码审查和测试习惯
    • 

  • 功能安全（ISO 26262）和预期功能安全（SOTIF）意识
    • 

  • 极端场景下的鲁棒性设计能力
    • 



量产落地压力
与学术研究不同，理想汽车的自动驾驶技术必须在量产车上可靠运行。这意味着：


    

  • 算法需要在有限算力下实时推理（Orin-X 508TOPS）
    • 

  • 需要应对真实道路的无限多样性
    • 

  • OTA推送前需要经过严格的回归测试
    • 



快速迭代节奏
理想汽车的自动驾驶算法迭代速度从2024年的每两周一次加速到每周一次。2025年全年完成5次OTA大版本升级。这种节奏要求工程师具备快速交付和持续改进的能力。
