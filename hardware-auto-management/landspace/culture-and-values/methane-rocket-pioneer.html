液氧甲烷先驱者：朱雀二号与技术路线的前瞻性

全球首枚入轨的液氧甲烷火箭

2023年7月12日9时00分，蓝箭航天自主研制的朱雀二号遥二运载火箭在酒泉卫星发射中心发射升空，成功将载荷送入预定轨道。这次发射的历史意义不在于火箭本身的技术参数多么出色，而在于它回答了一个全球航天界争论多年的问题：液氧甲烷（LOX/LCH4）能不能用来造入轨级运载火箭？

答案是：能。而且是一家中国民营公司先做到的。

在朱雀二号之前，全球围绕液氧甲烷发动机的努力已经持续了数十年：SpaceX的猛禽（Raptor）发动机早已试车成功，但搭载它的星舰在2023年尚未实现轨道级飞行；蓝色起源的BE-4发动机同样面临工程化延迟。蓝箭航天以"后发先至"的方式，让朱雀二号成为了全球第一个用液氧甲烷推进剂成功入轨的运载火箭。

为什么选择液氧甲烷

液氧甲烷不是一个显而易见的选择。在2018年蓝箭做出这个决定时，全球主流运载火箭的推进剂组合主要是：

推进剂组合 代表型号 比冲(s) 成本 可复用性
液氧煤油 猎鹰9/长征7 ~310 中等 较好（但结焦问题）
液氧液氢 长征5/Delta IV ~450 极高 差（液氢储存困难）
固体燃料 快舟/朱雀一号 ~260 低 不可复用
液氧甲烷 (无入轨先例) ~340 低 极好

液氧甲烷在比冲上不是最优的，但在"综合性价比"上具有决定性优势：

成本优势

甲烷的来源是天然气，价格低廉且供应稳定。液氧甲烷推进剂的成本仅为液氧煤油的三分之一左右。对于需要高频次发射的商业市场来说，推进剂成本虽然不是总成本的大头（约占5-10%），但它代表了一种"为商业化而生"的设计思维。

可复用性优势

液氧甲烷燃烧后几乎不产生积碳（结焦），发动机内部保持清洁。这意味着：

  • 复用前的检修工作量大幅减少
  • 发动机寿命显著延长
  • 多次点火的可靠性更高

相比之下，液氧煤油（如猎鹰9号的梅林发动机使用的RP-1煤油）在燃烧后会产生碳沉积，需要复杂的清洗维护流程。

储存优势

甲烷的沸点（-161.5°C）远高于液氢（-252.9°C），储存条件更宽松，地面操作更简便。同时，液氧和甲烷的密度接近，可以使用共底贮箱设计，减少箭体结构重量。

天鹊系列发动机的技术突破

蓝箭航天的液氧甲烷路线以天鹊（TQ）系列发动机为核心：

天鹊TQ-12的关键参数：


    

  • 推力等级：海平面67吨/真空80吨
    • 

  • 推进剂：液氧/甲烷
    • 

  • 循环方式：燃气发生器循环
    • 

  • 2019年5月首次全系统试车成功
    • 



这款发动机让蓝箭成为继SpaceX（猛禽）和蓝色起源（BE-4）之后，全球第三家掌握大推力液氧甲烷发动机技术的企业。


朱雀三号：从入轨到可回收
如果说朱雀二号证明了"液氧甲烷能入轨"，朱雀三号则要证明"液氧甲烷能回收复用"。


朱雀三号核心参数
    

  • 构型：单芯级两级串联
    • 

  • 箭体直径：4.5米
    • 

  • 整流罩直径：5.2米
    • 

  • 全箭长：66.1米
    • 

  • 一级动力：9台天鹊TQ-12A（九机并联）
    • 

  • 箭体材料：高强度不锈钢（304系列）
    • 

  • 回收装置：反作用控制系统 + 栅格舵 + 着陆支腿
    • 

  • 运力目标（回收模式）：低轨约12吨
    • 

  • 设计复用次数：≥20次
    • 



2025年12月首飞：入轨成功、回收失利
2025年12月3日，朱雀三号遥一运载火箭在东风商业航天创新试验区首飞。二级火箭成功入轨，验证了整个飞行方案的正确性。但一子级在着陆段出现异常——发动机推力响应延迟约0.3秒，叠加侧风导致的3.2度姿态偏差，最终"高速硬着陆"，残骸着陆于回收场坪边缘。


五大故障根源复盘
工程团队对首飞回收失利进行了系统复盘，识别出五大故障根源：


    

  1. 发动机推力响应延迟：着陆段点火后推力建立比预期慢0.3秒
    2. 

  2. 传感器受热偏差：高温环境导致导航传感器数据漂移
    3. 

  3. 侧风干扰超设计边界：回收场上空强侧风产生非预期的姿态扰动
    4. 

  4. 着陆缓冲机构精度：关键部件加工偏差影响缓冲效果
    5. 

  5. 多发动机协调控制：九机并联状态下的推力分配优化不足
    6. 



2026年Q2：遥二再挑战
基于首飞数据和经验，蓝箭航天计划于2026年第二季度再次开展回收试验。核心改进方向包括：


    

  • 优化着陆段发动机点火时序和推力曲线
    • 

  • 增强传感器热防护和冗余设计
    • 

  • 扩大回收场坪面积并改善场坪条件
    • 

  • 提升多机并联状态下的推力协调算法
    • 



如果Q2回收成功，公司计划在Q4尝试首次回收复用飞行——即用回收的一子级再次执行发射任务。


技术路线前瞻性的验证
站在2026年的时间节点回看，蓝箭2018年做出的液氧甲烷决策已经被充分验证为正确：


    

  • SpaceX的星舰同样选择了液氧甲烷（猛禽发动机），佐证了这一路线的终局正确性
    • 

  • 全球多家新兴火箭公司（Relativity Space、Firefly等）纷纷转向液氧甲烷
    • 

  • 中国国家队的新一代运载火箭也开始布局液氧甲烷型号
    • 



蓝箭的前瞻性不仅体现在"选对了方向"，更体现在"选对了时机"——在2018年全球无人成功时就敢下注，而不是等到2023年路线被验证后才跟随。这种"敢为天下先"的技术决策勇气，正是蓝箭航天企业文化中最核心的精神资产。


对后来者的启示
蓝箭的液氧甲烷先驱者经验，为商业航天领域的技术路线选择提供了几条重要启示：


    

  1. 不要选当前最优，要选终局最优：固体火箭在2018年是最快能入轨的选择，但它没有复用前途
    2. 

  2. 后发优势需要配合先发勇气：了解SpaceX的方向是后发优势，但敢在全球无先例时投入才是真正的差异化竞争力
    3. 

  3. 技术路线是战略选择，不是技术选择：决定用液氧甲烷的人（张昌武）不是技术专家，而是战略判断者
    4. 

  4. 容忍中间态的不完美：朱雀二号的比冲不如液氢液氧，运力不如长征五号，但它在"可商业化运营"这个维度上是最优解
    5.
