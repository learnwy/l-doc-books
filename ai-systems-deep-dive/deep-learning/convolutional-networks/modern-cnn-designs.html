现代 CNN 设计

核心概念

经典 CNN 架构主要依赖人工设计，而现代 CNN 设计融合了自动搜索、缩放策略和注意力机制等新思想。从 EfficientNet 的复合缩放到 ConvNeXt 对纯卷积设计的重新审视，现代 CNN 在精度和效率之间找到了更优的平衡点。这些设计不仅提升了模型性能，更改变了我们思考网络架构的方式。

通道注意力与 SE 模块
SE（Squeeze-and-Excitation）模块通过显式建模通道间的依赖关系来增强特征表示。它的核心思想是"让网络学会关注重要的通道"：先通过全局平均池化将每个通道压缩为一个标量（Squeeze），再通过两层全连接网络学习通道间的非线性关系（Excitation），最后用学到的权重重新校准通道响应。


import torch
import torch.nn as nn

class SEModule(nn.Module):
    def __init__(self, channels, reduction=16):
        super().__init__()
        self.squeeze = nn.AdaptiveAvgPool2d(1)
        self.excitation = nn.Sequential(
            nn.Linear(channels, channels // reduction, bias=False),
            nn.ReLU(inplace=True),
            nn.Linear(channels // reduction, channels, bias=False),
            nn.Sigmoid(),
        )

    def forward(self, x):
        b, c, _, _ = x.size()
        y = self.squeeze(x).view(b, c)
        y = self.excitation(y).view(b, c, 1, 1)
        return x * y.expand_as(x)
CBAM（Convolutional Block Attention Module）在 SE 的通道注意力基础上增加了空间注意力。通道注意力回答"关注什么特征"，空间注意力回答"关注什么位置"，两者协同工作进一步提升特征质量。

EfficientNet 与复合缩放
EfficientNet 的核心贡献是复合缩放（Compound Scaling）策略。传统做法是单独增加网络的深度、宽度或分辨率来提升性能，但 EfficientNet 证明同时按比例缩放三者效果更好。


具体来说，使用一个复合系数 ϕ\phiϕ 统一控制三个维度的缩放：


    

  • 深度：d=αϕd = \alpha^\phid=αϕ
    • 

  • 宽度：w=βϕw = \beta^\phiw=βϕ
    • 

  • 分辨率：r=γϕr = \gamma^\phir=γϕ
    • 



约束条件为 α⋅β2⋅γ2≈2\alpha \cdot \beta^2 \cdot \gamma^2 \approx 2α⋅β2⋅γ2≈2，确保 FLOPs 大约增长 2ϕ2^\phi2ϕ 倍。


class MBConvBlock(nn.Module):
    def __init__(self, in_ch, out_ch, expand_ratio, kernel_size, stride, se_ratio=0.25):
        super().__init__()
        mid_ch = in_ch * expand_ratio
        self.expand = nn.Sequential(
            nn.Conv2d(in_ch, mid_ch, 1, bias=False),
            nn.BatchNorm2d(mid_ch),
            nn.SiLU(inplace=True),
        ) if expand_ratio != 1 else nn.Identity()
        self.depthwise = nn.Sequential(
            nn.Conv2d(mid_ch, mid_ch, kernel_size, stride=stride,
                      padding=kernel_size // 2, groups=mid_ch, bias=False),
            nn.BatchNorm2d(mid_ch),
            nn.SiLU(inplace=True),
        )
        self.se = SEModule(mid_ch, reduction=int(1 / se_ratio))
        self.project = nn.Sequential(
            nn.Conv2d(mid_ch, out_ch, 1, bias=False),
            nn.BatchNorm2d(out_ch),
        )
        self.use_residual = (stride == 1 and in_ch == out_ch)

    def forward(self, x):
        residual = x
        x = self.expand(x)
        x = self.depthwise(x)
        x = self.se(x)
        x = self.project(x)
        if self.use_residual:
            x = x + residual
        return x
EfficientNet 的基础网络 B0 通过 NAS 搜索得到，然后通过复合缩放产生 B1-B7 系列。B0 在仅 5.3M 参数和 0.39G FLOPs 下达到 77.1% 的 Top-1 精度，效率远超同等精度的手工设计网络。


ConvNeXt 与纯卷积复兴
ConvNeXt（2022）通过系统性地将 ResNet 现代化，证明纯卷积网络可以匹敌甚至超越 Swin Transformer。它的设计过程是一系列渐进式改进：


    

  1. 将 ResNet 的训练策略升级为 Transformer 级别（AdamW、更长训练、更强增强）
    2. 

  2. 将 stage ratio 从 (3,4,6,3) 调整为 (3,3,9,3)，模仿 Swin 的比例
    3. 

  3. 使用 patchify stem（4×4 步幅卷积）替代 7×7 卷积 + 最大池化
    4. 

  4. 将标准卷积替换为深度可分离卷积
    5. 

  5. 将卷积核从 3×3 增大到 7×7
    6. 

  6. 用 GELU 替代 ReLU，用 Layer Norm 替代 Batch Norm
    7. 

  7. 减少激活和归一化层的数量
    8. 



class ConvNeXtBlock(nn.Module):
    def __init__(self, dim, drop_path=0.0):
        super().__init__()
        self.dwconv = nn.Conv2d(dim, dim, kernel_size=7, padding=3, groups=dim)
        self.norm = nn.LayerNorm(dim, eps=1e-6)
        self.pwconv1 = nn.Linear(dim, 4 * dim)
        self.act = nn.GELU()
        self.pwconv2 = nn.Linear(4 * dim, dim)
        self.gamma = nn.Parameter(1e-6 * torch.ones(dim))

    def forward(self, x):
        residual = x
        x = self.dwconv(x)
        x = x.permute(0, 2, 3, 1)
        x = self.norm(x)
        x = self.pwconv1(x)
        x = self.act(x)
        x = self.pwconv2(x)
        x = self.gamma * x
        x = x.permute(0, 3, 1, 2)
        return residual + x
ConvNeXt 的成功表明，CNN 和 Transformer 的性能差距很大程度上来自训练策略和微观设计，而非注意力机制本身的优越性。


小结
    

  • SE 模块通过通道注意力让网络学会关注重要特征，以极低开销提升性能
    • 

  • EfficientNet 的复合缩放统一深度、宽度和分辨率的缩放，比单维度缩放更高效
    • 

  • MBConv 结合深度可分离卷积和 SE 注意力，是现代轻量级网络的标准构件
    • 

  • ConvNeXt 证明纯卷积网络在现代化改造后可以匹敌 Transformer
    • 

  • 训练策略（优化器、数据增强、正则化）对最终性能的影响不亚于架构设计本身
    •
