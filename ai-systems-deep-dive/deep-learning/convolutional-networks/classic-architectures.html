经典 CNN 架构演进

核心概念

从 1998 年的 LeNet 到 2015 年的 ResNet，CNN 架构经历了深度不断增加、结构日趋精巧的演进过程。每一代里程碑式架构都解决了前一代的关键瓶颈，推动了图像识别精度的飞跃。理解这段演进历史不仅帮助我们掌握设计直觉，更能理解深层网络训练中的核心挑战和解决思路。

LeNet 与 AlexNet
LeNet-5（1998）是 Yann LeCun 设计的开创性架构，用于手写数字识别。它确立了卷积层 → 池化层 → 全连接层的基本范式。网络由两个卷积层（5×5 核）和三个全连接层组成，使用 Sigmoid 激活和平均池化。


AlexNet（2012）在 ImageNet 竞赛中以碾压优势夺冠，标志着深度学习时代的真正开端。AlexNet 的关键创新包括：使用 ReLU 替代 Sigmoid 解决梯度消失；引入 Dropout 防止过拟合；利用 GPU 并行训练加速；使用数据增强扩充训练集。


import torch.nn as nn

class AlexNet(nn.Module):
    def __init__(self, num_classes=1000):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 96, kernel_size=11, stride=4, padding=2),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2),
            nn.Conv2d(96, 256, kernel_size=5, padding=2),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2),
            nn.Conv2d(256, 384, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(384, 384, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(384, 256, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2),
        )
        self.classifier = nn.Sequential(
            nn.Dropout(),
            nn.Linear(256 * 6 * 6, 4096),
            nn.ReLU(inplace=True),
            nn.Dropout(),
            nn.Linear(4096, 4096),
            nn.ReLU(inplace=True),
            nn.Linear(4096, num_classes),
        )

    def forward(self, x):
        x = self.features(x)
        x = x.view(x.size(0), -1)
        x = self.classifier(x)
        return x
VGGNet 与 GoogLeNet
VGGNet（2014）证明了网络深度的重要性。它的核心设计原则极其简洁：全部使用 3×3 卷积核，通过堆叠小卷积核获得大感受野。VGG-16 有 13 个卷积层和 3 个全连接层，参数量达 138M，其中大部分参数集中在全连接层。


GoogLeNet/Inception（2014）采取了完全不同的设计思路——宽度而非深度。Inception 模块在同一层并行使用 1×1、3×3、5×5 卷积和 3×3 最大池化，让网络自动学习最合适的特征尺度。1×1 卷积作为瓶颈层用于降维，将参数量控制在仅 5M。


class InceptionModule(nn.Module):
    def __init__(self, in_channels, ch1x1, ch3x3_reduce, ch3x3, ch5x5_reduce, ch5x5, pool_proj):
        super().__init__()
        self.branch1 = nn.Sequential(
            nn.Conv2d(in_channels, ch1x1, kernel_size=1),
            nn.ReLU(inplace=True),
        )
        self.branch2 = nn.Sequential(
            nn.Conv2d(in_channels, ch3x3_reduce, kernel_size=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(ch3x3_reduce, ch3x3, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
        )
        self.branch3 = nn.Sequential(
            nn.Conv2d(in_channels, ch5x5_reduce, kernel_size=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(ch5x5_reduce, ch5x5, kernel_size=5, padding=2),
            nn.ReLU(inplace=True),
        )
        self.branch4 = nn.Sequential(
            nn.MaxPool2d(kernel_size=3, stride=1, padding=1),
            nn.Conv2d(in_channels, pool_proj, kernel_size=1),
            nn.ReLU(inplace=True),
        )

    def forward(self, x):
        return torch.cat([self.branch1(x), self.branch2(x),
                          self.branch3(x), self.branch4(x)], dim=1)
ResNet 与残差学习
ResNet（2015）通过引入残差连接（skip connection）解决了深层网络的退化问题。在此之前，网络深度超过一定阈值后，训练误差反而上升。ResNet 的核心洞察是：让网络学习残差映射 F(x)=H(x)−xF(x) = H(x) - xF(x)=H(x)−x 比直接学习目标映射 H(x)H(x)H(x) 更容易，因为恒等映射是优化的一个好起点。


class ResidualBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.conv1 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(channels)
        self.conv2 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn2 = nn.BatchNorm2d(channels)

    def forward(self, x):
        residual = x
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += residual
        return torch.relu(out)
当输入和输出维度不同时，使用 1×1 卷积进行投影：


class BottleneckBlock(nn.Module):
    def __init__(self, in_channels, mid_channels, out_channels, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, mid_channels, 1)
        self.bn1 = nn.BatchNorm2d(mid_channels)
        self.conv2 = nn.Conv2d(mid_channels, mid_channels, 3, stride=stride, padding=1)
        self.bn2 = nn.BatchNorm2d(mid_channels)
        self.conv3 = nn.Conv2d(mid_channels, out_channels, 1)
        self.bn3 = nn.BatchNorm2d(out_channels)
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1, stride=stride),
                nn.BatchNorm2d(out_channels),
            )

    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = torch.relu(self.bn2(self.conv2(out)))
        out = self.bn3(self.conv3(out))
        out += self.shortcut(x)
        return torch.relu(out)
DenseNet 与密集连接
DenseNet（2017）将残差连接推向极致——每一层都与之前所有层直接相连。具体来说，第 lll 层的输入是前面所有层输出的拼接：xl=Hl([x0,x1,...,xl−1])x_l = H_l([x_0, x_1, ..., x_{l-1}])xl​=Hl​([x0​,x1​,...,xl−1​])。这种密集连接模式带来了特征复用、梯度畅通和参数高效三大优势。

小结
    

  • LeNet 确立了卷积 + 池化 + 全连接的基本范式
    • 

  • AlexNet 通过 ReLU、Dropout 和 GPU 训练开启了深度学习时代
    • 

  • VGGNet 证明了网络深度的价值，用小核堆叠替代大卷积核
    • 

  • GoogLeNet 通过 Inception 模块探索网络宽度，1×1 卷积用于降维
    • 

  • ResNet 通过残差连接解决了深层网络退化问题，使百层以上网络成为可能
    • 

  • DenseNet 通过密集连接实现了最大程度的特征复用和梯度流通
    •
