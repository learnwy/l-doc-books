Vision Transformer 视觉变换器

核心概念

Vision Transformer（ViT）将自然语言处理领域的 Transformer 架构直接应用于图像识别任务，突破了 CNN 长期统治视觉领域的格局。ViT 的核心思想是将图像切分为固定大小的 patch，将每个 patch 视为一个 token，然后用标准 Transformer 编码器处理这个 token 序列。这种设计抛弃了卷积的局部性和平移等变性先验，完全依靠自注意力机制从数据中学习空间关系。

Patch Embedding 与位置编码
ViT 将 H×WH \times WH×W 的图像分割为 HP×WP\frac{H}{P} \times \frac{W}{P}PH​×PW​ 个大小为 P×PP \times PP×P 的 patch。每个 patch 被展平为一维向量，然后通过线性投影映射到 ddd 维嵌入空间。这个过程等价于一个步幅为 PPP、核大小为 P×PP \times PP×P 的卷积操作。


import torch
import torch.nn as nn

class PatchEmbedding(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_channels=3, embed_dim=768):
        super().__init__()
        self.num_patches = (img_size // patch_size) ** 2
        self.proj = nn.Conv2d(in_channels, embed_dim, kernel_size=patch_size, stride=patch_size)

    def forward(self, x):
        x = self.proj(x)
        x = x.flatten(2).transpose(1, 2)
        return x
由于 Transformer 本身不包含位置信息，ViT 需要额外添加位置编码。标准 ViT 使用可学习的一维位置编码，每个位置对应一个 ddd 维向量。实验表明，学到的位置编码确实编码了 patch 的空间位置——相邻位置的编码向量相似度更高。


class VisionTransformer(nn.Module):
    def __init__(self, img_size=224, patch_size=16, embed_dim=768, depth=12,
                 num_heads=12, num_classes=1000):
        super().__init__()
        self.patch_embed = PatchEmbedding(img_size, patch_size, 3, embed_dim)
        num_patches = self.patch_embed.num_patches
        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        self.pos_embed = nn.Parameter(torch.zeros(1, num_patches + 1, embed_dim))
        self.blocks = nn.Sequential(*[
            TransformerBlock(embed_dim, num_heads) for _ in range(depth)
        ])
        self.norm = nn.LayerNorm(embed_dim)
        self.head = nn.Linear(embed_dim, num_classes)

    def forward(self, x):
        x = self.patch_embed(x)
        cls_tokens = self.cls_token.expand(x.shape[0], -1, -1)
        x = torch.cat([cls_tokens, x], dim=1)
        x = x + self.pos_embed
        x = self.blocks(x)
        x = self.norm(x[:, 0])
        return self.head(x)
自注意力在视觉中的特性
ViT 中的多头自注意力（MHSA）允许每个 patch 与所有其他 patch 直接交互，这带来了两个显著优势：第一层就能建模全局依赖（CNN 需要多层堆叠才能获得足够大的感受野）；注意力权重可视化揭示了网络关注的区域，提供了良好的可解释性。


但全局自注意力的计算复杂度为 O(N2)O(N^2)O(N2)，其中 NNN 是 patch 数量。对于 224×224 的图像和 16×16 的 patch，N=196N = 196N=196，计算量可以接受。但对于高分辨率图像或密集预测任务，NNN 急剧增大，计算成本不可承受。


ViT 的一个重要发现是：大规模预训练后，ViT 在下游任务的迁移效果优于 CNN。这是因为 Transformer 缺少归纳偏置，在小数据上不如 CNN，但在大数据上没有先验带来的天花板效应，可以通过数据量的增加持续提升性能。

Swin Transformer 与层级化设计
Swin Transformer（2021）解决了 ViT 的两个核心问题：O(N2)O(N^2)O(N2) 的计算复杂度和缺乏多尺度特征。它引入了两个关键设计：窗口注意力（Window Attention）和移位窗口（Shifted Window）。


窗口注意力将自注意力限制在固定大小的局部窗口内，将复杂度从 O(N2)O(N^2)O(N2) 降为 O(N⋅M2)O(N \cdot M^2)O(N⋅M2)（MMM 为窗口大小）。移位窗口在连续层之间交替移动窗口位置，使不同窗口之间可以间接交换信息。


class WindowAttention(nn.Module):
    def __init__(self, dim, window_size, num_heads):
        super().__init__()
        self.window_size = window_size
        self.num_heads = num_heads
        self.scale = (dim // num_heads) ** -0.5
        self.qkv = nn.Linear(dim, dim * 3)
        self.proj = nn.Linear(dim, dim)
        self.relative_position_bias_table = nn.Parameter(
            torch.zeros((2 * window_size - 1) * (2 * window_size - 1), num_heads)
        )

    def forward(self, x, mask=None):
        B_, N, C = x.shape
        qkv = self.qkv(x).reshape(B_, N, 3, self.num_heads, C // self.num_heads).permute(2, 0, 3, 1, 4)
        q, k, v = qkv.unbind(0)
        attn = (q @ k.transpose(-2, -1)) * self.scale
        if mask is not None:
            attn = attn.masked_fill(mask == 0, float('-inf'))
        attn = attn.softmax(dim=-1)
        x = (attn @ v).transpose(1, 2).reshape(B_, N, C)
        return self.proj(x)
Swin Transformer 还采用了层级化结构：通过 Patch Merging 逐步降低分辨率、增加通道数，产生多尺度特征图。这使得 Swin Transformer 可以作为通用的骨干网络用于目标检测、语义分割等密集预测任务。


小结
    

  • ViT 将图像视为 patch 序列，用 Transformer 编码器处理视觉任务
    • 

  • Patch Embedding 等价于大步幅卷积，位置编码为 patch 提供空间信息
    • 

  • ViT 在大规模数据预训练后迁移效果优于 CNN，但小数据场景不如 CNN
    • 

  • Swin Transformer 通过窗口注意力和层级化设计解决了效率和多尺度问题
    • 

  • Vision Transformer 推动了视觉和语言模型架构的统一趋势
