卷积操作原理

核心概念

卷积操作是卷积神经网络的基础构件，通过滑动卷积核在输入特征图上提取局部模式。与全连接层不同，卷积层利用参数共享和局部连接两大特性，在大幅减少参数量的同时保留了空间结构信息。这种设计使得 CNN 能够高效学习图像中的边缘、纹理、形状等层次化特征。

互相关与卷积
严格来说，深度学习中的"卷积"操作实际上是互相关（cross-correlation）运算——卷积核直接在输入上滑动并逐元素相乘求和，而不做数学卷积中的核翻转。由于卷积核的参数是通过学习得到的，翻转与否不影响网络的表达能力，因此框架中统一使用互相关并称之为卷积。


import numpy as np

def conv2d_naive(input_map, kernel, stride=1, padding=0):
    if padding > 0:
        input_map = np.pad(input_map, ((padding, padding), (padding, padding)), mode='constant')
    h_in, w_in = input_map.shape
    k_h, k_w = kernel.shape
    h_out = (h_in - k_h) // stride + 1
    w_out = (w_in - k_w) // stride + 1
    output = np.zeros((h_out, w_out))
    for i in range(h_out):
        for j in range(w_out):
            region = input_map[i*stride:i*stride+k_h, j*stride:j*stride+k_w]
            output[i, j] = np.sum(region * kernel)
    return output
步幅（stride）控制卷积核的滑动步长，步幅为 2 意味着输出特征图的空间尺寸减半。填充（padding）在输入边缘补零以控制输出尺寸。"same" 填充使输出与输入尺寸相同，"valid" 填充不补零。输出尺寸公式为：


Hout=⌊Hin+2P−KS⌋+1H_{out} = \lfloor\frac{H_{in} + 2P - K}{S}\rfloor + 1Hout​=⌊SHin​+2P−K​⌋+1
感受野与多尺度特征
感受野（receptive field）指输出特征图上一个元素对应的输入区域大小。随着网络层数加深，每层的感受野逐层扩大。第 lll 层的感受野大小为：


RFl=RFl−1+(Kl−1)×∏i=1l−1SiRF_l = RF_{l-1} + (K_l - 1) \times \prod_{i=1}^{l-1} S_iRFl​=RFl−1​+(Kl​−1)×i=1∏l−1​Si​
两层 3×3 卷积的感受野等价于一层 5×5 卷积，三层 3×3 等价于一层 7×7。但多层小卷积核在参数量和计算量上都更优，同时引入了更多的非线性：

这就是 VGGNet 提出的核心设计原则：用多层小卷积核替代少层大卷积核，在相同感受野下获得更强的特征提取能力。


深度可分离卷积
深度可分离卷积（Depthwise Separable Convolution）将标准卷积分解为两步：逐通道卷积（depthwise）和逐点卷积（pointwise），大幅减少参数量和计算量。


逐通道卷积对每个输入通道独立应用一个 K×K 的卷积核，不做跨通道的信息融合。逐点卷积使用 1×1 卷积核做跨通道的线性组合。


import torch.nn as nn

class DepthwiseSeparableConv(nn.Module):
    def __init__(self, in_channels, out_channels, kernel_size, stride=1, padding=0):
        super().__init__()
        self.depthwise = nn.Conv2d(
            in_channels, in_channels, kernel_size,
            stride=stride, padding=padding, groups=in_channels
        )
        self.pointwise = nn.Conv2d(in_channels, out_channels, 1)

    def forward(self, x):
        x = self.depthwise(x)
        x = self.pointwise(x)
        return x
以 3×3 卷积、输入 64 通道、输出 128 通道为例，标准卷积参数量为 3×3×64×128=73,7283 \times 3 \times 64 \times 128 = 73,7283×3×64×128=73,728，深度可分离卷积参数量为 3×3×64+64×128=8,7683 \times 3 \times 64 + 64 \times 128 = 8,7683×3×64+64×128=8,768，仅为标准卷积的约 12%。


空洞卷积与转置卷积
空洞卷积（Dilated/Atrous Convolution）在卷积核元素之间插入空洞，在不增加参数量的情况下扩大感受野。膨胀率 ddd 决定了空洞的大小，膨胀率为 2 的 3×3 卷积核实际覆盖 5×5 的区域。


空洞卷积在语义分割中广泛使用，DeepLab 系列通过不同膨胀率的空洞卷积组成 ASPP（Atrous Spatial Pyramid Pooling）模块，捕捉多尺度上下文信息。


转置卷积（Transposed Convolution）用于上采样，将低分辨率特征图恢复到高分辨率。它并非卷积的数学逆运算，而是通过在输入元素之间插入零值后执行标准卷积来实现尺寸扩大。


up = nn.ConvTranspose2d(128, 64, kernel_size=4, stride=2, padding=1)
down = nn.Conv2d(64, 128, kernel_size=3, stride=2, padding=1)

x = torch.randn(1, 64, 32, 32)
y = down(x)
z = up(y)
转置卷积容易产生"棋盘格效应"（checkerboard artifacts），因为相邻输出像素可能被不同数量的核元素覆盖。在生成模型中，通常用双线性上采样 + 标准卷积替代转置卷积以避免伪影。


小结
    

  • 卷积通过参数共享和局部连接高效提取空间特征
    • 

  • 深度学习中的卷积实际上是互相关运算，但不影响学习效果
    • 

  • 多层小卷积核在感受野、参数量和非线性上都优于少层大卷积核
    • 

  • 深度可分离卷积将参数量和计算量降低约 8-9 倍，是轻量级网络的核心组件
    • 

  • 空洞卷积通过膨胀率在不增加参数的情况下扩大感受野
    • 

  • 转置卷积用于上采样但容易产生棋盘格效应，工程中常用上采样 + 卷积替代
    •
