LSTM 与 GRU 门控机制

核心概念

LSTM（Long Short-Term Memory）和 GRU（Gated Recurrent Unit）通过引入门控机制解决了朴素 RNN 的长距离依赖问题。门控的核心思想是：让网络学会选择性地记住、遗忘和输出信息，而不是将所有历史信息无差别地压缩到隐藏状态中。这种设计使得重要的信息可以跨越数百个时间步传递，同时不相关的信息被及时遗忘。

LSTM 的三门机制
LSTM 的核心创新是引入了一条独立于隐藏状态的细胞状态（cell state）通路。细胞状态像一条传送带，信息可以沿着它几乎不受干扰地流过整个序列。三个门控制着信息如何进出这条传送带。


遗忘门决定从细胞状态中丢弃什么信息：ft=σ(Wf[ht−1,xt]+bf)f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)ft​=σ(Wf​[ht−1​,xt​]+bf​)


输入门决定什么新信息存入细胞状态：it=σ(Wi[ht−1,xt]+bi)i_t = \sigma(W_i [h_{t-1}, x_t] + b_i)it​=σ(Wi​[ht−1​,xt​]+bi​)


候选细胞状态：C~t=tanh⁡(WC[ht−1,xt]+bC)\tilde{C}_t = \tanh(W_C [h_{t-1}, x_t] + b_C)C~t​=tanh(WC​[ht−1​,xt​]+bC​)


细胞状态更新：Ct=ft⊙Ct−1+it⊙C~tC_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_tCt​=ft​⊙Ct−1​+it​⊙C~t​


输出门决定输出什么信息：ot=σ(Wo[ht−1,xt]+bo)o_t = \sigma(W_o [h_{t-1}, x_t] + b_o)ot​=σ(Wo​[ht−1​,xt​]+bo​)


隐藏状态更新：ht=ot⊙tanh⁡(Ct)h_t = o_t \odot \tanh(C_t)ht​=ot​⊙tanh(Ct​)


import torch
import torch.nn as nn

class LSTMCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.hidden_size = hidden_size
        self.gates = nn.Linear(input_size + hidden_size, 4 * hidden_size)

    def forward(self, x_t, h_prev, c_prev):
        combined = torch.cat([h_prev, x_t], dim=1)
        gates = self.gates(combined)
        i, f, g, o = gates.chunk(4, dim=1)
        i = torch.sigmoid(i)
        f = torch.sigmoid(f)
        g = torch.tanh(g)
        o = torch.sigmoid(o)
        c_t = f * c_prev + i * g
        h_t = o * torch.tanh(c_t)
        return h_t, c_t
遗忘门 ftf_tft​ 的值接近 1 时，旧的细胞状态几乎完全保留，梯度可以无衰减地回传——这就是 LSTM 解决梯度消失的关键机制。当遗忘门为 1、输入门为 0 时，细胞状态实现恒等映射 Ct=Ct−1C_t = C_{t-1}Ct​=Ct−1​，类似于 ResNet 的残差连接。


GRU 的简化门控
GRU 将 LSTM 的三个门简化为两个：重置门和更新门，同时合并了细胞状态和隐藏状态。


更新门：zt=σ(Wz[ht−1,xt])z_t = \sigma(W_z [h_{t-1}, x_t])zt​=σ(Wz​[ht−1​,xt​])


重置门：rt=σ(Wr[ht−1,xt])r_t = \sigma(W_r [h_{t-1}, x_t])rt​=σ(Wr​[ht−1​,xt​])


候选状态：h~t=tanh⁡(W[rt⊙ht−1,xt])\tilde{h}_t = \tanh(W [r_t \odot h_{t-1}, x_t])h~t​=tanh(W[rt​⊙ht−1​,xt​])


状态更新：ht=(1−zt)⊙ht−1+zt⊙h~th_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_tht​=(1−zt​)⊙ht−1​+zt​⊙h~t​


class GRUCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.hidden_size = hidden_size
        self.W_z = nn.Linear(input_size + hidden_size, hidden_size)
        self.W_r = nn.Linear(input_size + hidden_size, hidden_size)
        self.W_h = nn.Linear(input_size + hidden_size, hidden_size)

    def forward(self, x_t, h_prev):
        combined = torch.cat([h_prev, x_t], dim=1)
        z = torch.sigmoid(self.W_z(combined))
        r = torch.sigmoid(self.W_r(combined))
        combined_r = torch.cat([r * h_prev, x_t], dim=1)
        h_tilde = torch.tanh(self.W_h(combined_r))
        h_t = (1 - z) * h_prev + z * h_tilde
        return h_t
GRU 的更新门 ztz_tzt​ 同时扮演了 LSTM 中遗忘门和输入门的角色：当 zt=0z_t = 0zt​=0 时完全保留旧状态，当 zt=1z_t = 1zt​=1 时完全使用新候选。这种设计减少了约 33% 的参数量，在很多任务上与 LSTM 性能相当。


多层堆叠与双向结构
单层 LSTM/GRU 的特征提取能力有限，通常需要堆叠多层来构建更深的模型。第 lll 层的输入是第 l−1l-1l−1 层的隐藏状态输出序列。


lstm = nn.LSTM(
    input_size=256,
    hidden_size=512,
    num_layers=3,
    batch_first=True,
    dropout=0.3,
    bidirectional=True,
)

x = torch.randn(32, 100, 256)
output, (hn, cn) = lstm(x)
双向 LSTM 在正向和反向各运行一个 LSTM，每个时间步的输出是两个方向的拼接。对于输入序列长度为 TTT、隐藏维度为 HHH 的双向 LSTM，每步输出维度为 2H2H2H。

LSTM 与 GRU 的工程选择
在实际工程中选择 LSTM 还是 GRU 需要考虑任务特性、数据规模和计算预算。


LSTM 在需要精细记忆控制的任务上通常更好（如机器翻译中的长距离对齐），但参数量更大、训练更慢。GRU 在中等长度序列和数据量较小的场景中是更好的默认选择，训练速度快且过拟合风险较低。


在现代实践中，对于需要处理长序列的任务，Transformer 已经在大多数场景中取代了 LSTM/GRU。但在实时推理、嵌入式部署和流式处理等场景下，循环网络仍然有不可替代的优势，因为它们可以逐步处理输入而无需缓存整个序列。


小结
    

  • LSTM 通过细胞状态和三门机制实现选择性记忆，有效解决梯度消失
    • 

  • 遗忘门接近 1 时实现恒等映射，是 LSTM 长距离记忆的关键
    • 

  • GRU 用两个门实现类似效果，参数减少 33%，在很多任务上性能相当
    • 

  • 多层堆叠和双向结构可以显著提升模型的特征提取能力
    • 

  • 循环网络在实时推理和流式处理场景下仍有独特优势
    •
