RNN 基础原理

核心概念

循环神经网络（Recurrent Neural Network, RNN）是专为序列数据设计的神经网络架构。与前馈网络不同，RNN 在时间步之间维护一个隐藏状态（hidden state），使得当前时刻的输出可以依赖于之前所有时刻的信息。这种循环结构赋予了 RNN 处理变长序列和建模时间依赖关系的能力。

展开计算与参数共享
RNN 的核心计算在每个时间步 ttt 执行相同的操作。给定输入 xtx_txt​ 和上一步的隐藏状态 ht−1h_{t-1}ht−1​，更新公式为：


ht=tanh⁡(Whhht−1+Wxhxt+bh)h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)ht​=tanh(Whh​ht−1​+Wxh​xt​+bh​)
 


yt=Whyht+byy_t = W_{hy} h_t + b_yyt​=Why​ht​+by​
其中 WhhW_{hh}Whh​、WxhW_{xh}Wxh​、WhyW_{hy}Why​ 是在所有时间步之间共享的权重矩阵。参数共享有两大优势：大幅减少参数量；使得网络能够处理任意长度的序列。


import numpy as np

class SimpleRNN:
    def __init__(self, input_size, hidden_size, output_size):
        self.Wxh = np.random.randn(hidden_size, input_size) * 0.01
        self.Whh = np.random.randn(hidden_size, hidden_size) * 0.01
        self.Why = np.random.randn(output_size, hidden_size) * 0.01
        self.bh = np.zeros((hidden_size, 1))
        self.by = np.zeros((output_size, 1))

    def forward(self, inputs, h_prev):
        hs, ys = {}, {}
        hs[-1] = h_prev.copy()
        for t, x in enumerate(inputs):
            hs[t] = np.tanh(self.Wxh @ x + self.Whh @ hs[t-1] + self.bh)
            ys[t] = self.Why @ hs[t] + self.by
        return hs, ys
将 RNN 沿时间轴展开后，它等价于一个非常深的前馈网络，每一"层"对应一个时间步，且所有层共享权重。这种展开视角直接解释了 RNN 训练中梯度消失/爆炸问题的根源。


时间反向传播
通过时间反向传播（Backpropagation Through Time, BPTT）是训练 RNN 的标准方法。将 RNN 沿时间展开后，梯度需要从最后一个时间步逐步回传到第一个时间步。


对隐藏状态 hth_tht​ 的梯度涉及 WhhW_{hh}Whh​ 的连续乘法：


∂hT∂ht=∏k=t+1T∂hk∂hk−1=∏k=t+1TWhhT⋅diag(1−hk2)\frac{\partial h_T}{\partial h_t} = \prod_{k=t+1}^{T} \frac{\partial h_k}{\partial h_{k-1}} = \prod_{k=t+1}^{T} W_{hh}^T \cdot \text{diag}(1 - h_k^2)∂ht​∂hT​​=k=t+1∏T​∂hk−1​∂hk​​=k=t+1∏T​WhhT​⋅diag(1−hk2​)
当 WhhW_{hh}Whh​ 的最大奇异值大于 1 时，连乘导致梯度爆炸；当最大奇异值小于 1 时，导致梯度消失。对于长度为 TTT 的序列，梯度按 TTT 次方的速度衰减或增长。


截断 BPTT 是一种实用的折中方案：不将梯度传播到序列的最开始，而是只回传固定的 kkk 步。这牺牲了对非常远距离依赖的建模能力，但使训练在计算和数值上都更加可行。


import torch
import torch.nn as nn

rnn = nn.RNN(input_size=128, hidden_size=256, num_layers=2, batch_first=True)
x = torch.randn(32, 100, 128)
h0 = torch.zeros(2, 32, 256)

output, hn = rnn(x, h0)
长距离依赖困境
朴素 RNN 在实践中难以学习超过 10-20 步的长距离依赖。这不仅仅是梯度消失的数值问题，更是网络架构的根本限制——所有历史信息都被压缩到一个固定大小的隐藏状态向量中，远期信息不可避免地被近期信息覆盖。

这一困境直接催生了 LSTM 和 GRU 等门控机制的发明，以及后来完全放弃循环结构的 Transformer 架构。


RNN 的变体结构
根据输入输出的对应关系，RNN 有多种变体结构：


多对一：输入完整序列，只在最后一步输出。典型应用：文本分类、情感分析。


一对多：输入单个向量，输出一个序列。典型应用：图像描述生成。


多对多（同步）：每个时间步都有输入和输出。典型应用：词性标注、命名实体识别。


多对多（异步）：编码器读取完整输入，解码器生成输出序列。典型应用：机器翻译、文本摘要。


双向 RNN 同时从正向和反向处理序列，每个时间步获得来自过去和未来的信息：


birnn = nn.RNN(input_size=128, hidden_size=256, num_layers=2,
               batch_first=True, bidirectional=True)
output, hn = birnn(x, None)
小结
    

  • RNN 通过隐藏状态在时间步之间传递信息，天然适合序列数据
    • 

  • 参数在所有时间步之间共享，使得 RNN 能处理任意长度的序列
    • 

  • BPTT 将 RNN 展开为深层前馈网络进行训练，但面临梯度消失/爆炸
    • 

  • 朴素 RNN 难以学习超过 10-20 步的长距离依赖
    • 

  • 双向 RNN 通过正向和反向同时处理获取完整上下文
    • 

  • RNN 的串行计算特性限制了训练效率，这是 Transformer 诞生的动因之一
