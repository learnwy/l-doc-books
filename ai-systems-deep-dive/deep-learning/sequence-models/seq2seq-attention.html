Seq2Seq 与注意力机制

核心概念

Seq2Seq（Sequence-to-Sequence）架构通过编码器-解码器结构处理变长输入到变长输出的映射问题，是机器翻译、文本摘要和对话系统的基础框架。注意力机制的引入使得解码器在生成每个输出时都能"回看"编码器的所有位置，解决了将整个输入序列压缩到单一向量的信息瓶颈。注意力机制的成功直接催生了 Transformer 架构的诞生。

编码器-解码器架构
基础 Seq2Seq 模型由一个 RNN 编码器和一个 RNN 解码器组成。编码器逐步读取输入序列，将信息压缩到最终隐藏状态中。解码器以该状态为初始条件，自回归地生成输出序列。


import torch
import torch.nn as nn

class Encoder(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_layers):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.rnn = nn.LSTM(embed_dim, hidden_dim, num_layers, batch_first=True)

    def forward(self, src):
        embedded = self.embedding(src)
        outputs, (hidden, cell) = self.rnn(embedded)
        return outputs, hidden, cell

class Decoder(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_layers):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.rnn = nn.LSTM(embed_dim, hidden_dim, num_layers, batch_first=True)
        self.fc_out = nn.Linear(hidden_dim, vocab_size)

    def forward(self, tgt, hidden, cell):
        embedded = self.embedding(tgt)
        output, (hidden, cell) = self.rnn(embedded, (hidden, cell))
        prediction = self.fc_out(output)
        return prediction, hidden, cell
这种架构的根本问题在于"信息瓶颈"：无论输入序列多长，所有信息都必须被压缩到一个固定维度的向量中。对于长句子，这意味着大量信息的丢失。


Bahdanau 注意力
Bahdanau 注意力（2014）是第一个广泛使用的注意力机制。它的核心思想是在解码每个时间步时，让解码器"关注"编码器的不同位置，并根据相关性动态计算上下文向量。

class BahdanauAttention(nn.Module):
    def __init__(self, hidden_dim):
        super().__init__()
        self.W_query = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.W_key = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.V = nn.Linear(hidden_dim, 1, bias=False)

    def forward(self, query, keys):
        query = query.unsqueeze(1)
        scores = self.V(torch.tanh(self.W_query(query) + self.W_key(keys)))
        weights = torch.softmax(scores, dim=1)
        context = torch.sum(weights * keys, dim=1)
        return context, weights.squeeze(-1)
Luong 注意力
Luong 注意力（2015）提出了三种更简洁的对齐函数计算方式：


点积注意力：et,i=stThie_{t,i} = s_t^T h_iet,i​=stT​hi​ 通用注意力：et,i=stTWahie_{t,i} = s_t^T W_a h_iet,i​=stT​Wa​hi​ 拼接注意力：et,i=vaTtanh⁡(Wa[st;hi])e_{t,i} = v_a^T \tanh(W_a [s_t; h_i])et,i​=vaT​tanh(Wa​[st​;hi​])


class LuongAttention(nn.Module):
    def __init__(self, hidden_dim, method='dot'):
        super().__init__()
        self.method = method
        if method == 'general':
            self.W = nn.Linear(hidden_dim, hidden_dim, bias=False)
        elif method == 'concat':
            self.W = nn.Linear(hidden_dim * 2, hidden_dim, bias=False)
            self.v = nn.Linear(hidden_dim, 1, bias=False)

    def forward(self, query, keys):
        if self.method == 'dot':
            scores = torch.bmm(keys, query.unsqueeze(2)).squeeze(2)
        elif self.method == 'general':
            scores = torch.bmm(keys, self.W(query).unsqueeze(2)).squeeze(2)
        elif self.method == 'concat':
            query_expanded = query.unsqueeze(1).expand_as(keys)
            combined = torch.cat([keys, query_expanded], dim=2)
            scores = self.v(torch.tanh(self.W(combined))).squeeze(2)
        weights = torch.softmax(scores, dim=1)
        context = torch.bmm(weights.unsqueeze(1), keys).squeeze(1)
        return context, weights

从注意力到 Transformer
缩放点积注意力 Attention(Q,K,V)=softmax(QKTdk)V\text{Attention}(Q,K,V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})VAttention(Q,K,V)=softmax(dk​​QKT​)V 是 Transformer 的基础。它将 Seq2Seq 注意力中的单个查询-键对推广为矩阵运算，使得所有位置的注意力可以并行计算。


多头注意力进一步将 ddd 维的 Q、K、V 拆分为 hhh 个头，每个头独立计算注意力后拼接。不同的头可以关注不同类型的关系（如句法关系、语义关系）。


自注意力（Self-Attention）是指 Q、K、V 都来自同一序列的注意力机制。这使得序列中每个位置可以直接与所有其他位置交互，彻底解决了 RNN 的长距离依赖问题和串行计算限制。


小结
    

  • Seq2Seq 通过编码器-解码器处理变长序列映射，但存在信息瓶颈
    • 

  • 注意力机制让解码器在每步动态关注编码器的相关位置，解决信息瓶颈
    • 

  • Bahdanau 注意力使用加性对齐函数，Luong 注意力提供了更高效的点积变体
    • 

  • 缩放点积注意力是 Transformer 的基础，通过除以 dk\sqrt{d_k}dk​​ 稳定梯度
    • 

  • 从 Seq2Seq 注意力到 Transformer 自注意力是一次架构范式的革命
