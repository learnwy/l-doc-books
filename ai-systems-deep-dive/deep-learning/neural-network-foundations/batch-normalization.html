批归一化与归一化技术

核心概念

批归一化（Batch Normalization, BN）是深度学习中最重要的训练技巧之一。它通过对每一层的输入进行标准化处理——减去均值、除以标准差——使得中间层的输入分布保持稳定，从而加速训练收敛、允许使用更大的学习率，并起到一定的正则化效果。BN 的提出显著降低了训练深层网络的难度，被广泛应用于几乎所有现代架构中。

BN 的前向与反向计算
BN 在训练阶段对每个 mini-batch 计算统计量。给定一个 batch 的激活值 {x1,x2,...,xm}\{x_1, x_2, ..., x_m\}{x1​,x2​,...,xm​}：


    

  1. 计算 batch 均值：μB=1m∑i=1mxi\mu_B = \frac{1}{m}\sum_{i=1}^{m} x_iμB​=m1​∑i=1m​xi​
    2. 

  2. 计算 batch 方差：σB2=1m∑i=1m(xi−μB)2\sigma_B^2 = \frac{1}{m}\sum_{i=1}^{m}(x_i - \mu_B)^2σB2​=m1​∑i=1m​(xi​−μB​)2
    3. 

  3. 标准化：x^i=xi−μBσB2+ϵ\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}x^i​=σB2​+ϵ​xi​−μB​​
    4. 

  4. 缩放和平移：yi=γx^i+βy_i = \gamma \hat{x}_i + \betayi​=γx^i​+β
    5. 



其中 γ\gammaγ 和 β\betaβ 是可学习的仿射参数，ϵ\epsilonϵ 是防止除零的小常数。γ\gammaγ 和 β\betaβ 的存在使得 BN 层有能力恢复原始分布——如果网络发现标准化对某层不利，可以通过学习 γ=σB\gamma = \sigma_Bγ=σB​ 和 β=μB\beta = \mu_Bβ=μB​ 来抵消标准化的效果。


import numpy as np

class BatchNorm1d:
    def __init__(self, num_features, eps=1e-5, momentum=0.1):
        self.gamma = np.ones(num_features)
        self.beta = np.zeros(num_features)
        self.eps = eps
        self.momentum = momentum
        self.running_mean = np.zeros(num_features)
        self.running_var = np.ones(num_features)

    def forward(self, x, training=True):
        if training:
            mean = x.mean(axis=0)
            var = x.var(axis=0)
            self.running_mean = (1 - self.momentum) * self.running_mean + self.momentum * mean
            self.running_var = (1 - self.momentum) * self.running_var + self.momentum * var
        else:
            mean = self.running_mean
            var = self.running_var
        x_hat = (x - mean) / np.sqrt(var + self.eps)
        return self.gamma * x_hat + self.beta
反向传播中，BN 层的梯度计算比较复杂，因为每个样本的标准化值依赖于整个 batch 的统计量。设 ∂L∂yi\frac{\partial L}{\partial y_i}∂yi​∂L​ 为上游梯度，关键梯度公式为：


∂L∂γ=∑i=1m∂L∂yi⋅x^i,∂L∂β=∑i=1m∂L∂yi\frac{\partial L}{\partial \gamma} = \sum_{i=1}^{m} \frac{\partial L}{\partial y_i} \cdot \hat{x}_i, \quad \frac{\partial L}{\partial \beta} = \sum_{i=1}^{m} \frac{\partial L}{\partial y_i}∂γ∂L​=i=1∑m​∂yi​∂L​⋅x^i​,∂β∂L​=i=1∑m​∂yi​∂L​
∂L∂xi=γσB2+ϵ(∂L∂yi−1m∂L∂β−x^im∂L∂γ)\frac{\partial L}{\partial x_i} = \frac{\gamma}{\sqrt{\sigma_B^2+\epsilon}} \left( \frac{\partial L}{\partial y_i} - \frac{1}{m}\frac{\partial L}{\partial \beta} - \frac{\hat{x}_i}{m}\frac{\partial L}{\partial \gamma} \right)∂xi​∂L​=σB2​+ϵ​γ​(∂yi​∂L​−m1​∂β∂L​−mx^i​​∂γ∂L​)
训练与推理的行为差异
BN 在训练和推理阶段的行为截然不同。训练时使用当前 mini-batch 的统计量，同时通过指数移动平均维护全局统计量。推理时直接使用全局统计量，因为推理可能是单样本的，batch 统计量没有意义。


import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 256),
    nn.BatchNorm1d(256),
    nn.ReLU(),
    nn.Linear(256, 10)
)

model.train()
output_train = model(x_batch)

model.eval()
with torch.no_grad():
    output_eval = model(x_single)
这种训练/推理不一致性是 BN 的一个已知缺陷。当 batch size 很小时（如目标检测中常见的 1-2 张图片），batch 统计量的方差很大，训练不稳定。此外，当训练数据和推理数据分布不同时，全局统计量可能不准确。

Layer Norm 与 Group Norm
Layer Normalization 对每个样本的所有特征维度计算统计量，不依赖 batch 维度。这使得 Layer Norm 在任何 batch size 下都表现一致，成为 Transformer 架构的标准选择。


class LayerNorm:
    def __init__(self, normalized_shape, eps=1e-5):
        self.gamma = np.ones(normalized_shape)
        self.beta = np.zeros(normalized_shape)
        self.eps = eps

    def forward(self, x):
        mean = x.mean(axis=-1, keepdims=True)
        var = x.var(axis=-1, keepdims=True)
        x_hat = (x - mean) / np.sqrt(var + self.eps)
        return self.gamma * x_hat + self.beta
Group Normalization 将通道分为若干组，在每组内计算统计量。它是 BN 和 LN 之间的折中方案：当组数等于通道数时退化为 Instance Norm，当组数为 1 时退化为 Layer Norm。


RMS Norm 是 Layer Norm 的简化版本，去掉了均值中心化步骤，只做方差归一化：x^=xRMS(x)⋅γ\hat{x} = \frac{x}{\text{RMS}(x)} \cdot \gammax^=RMS(x)x​⋅γ，其中 RMS(x)=1n∑xi2\text{RMS}(x) = \sqrt{\frac{1}{n}\sum x_i^2}RMS(x)=n1​∑xi2​​。LLaMA 等大语言模型使用 RMS Norm 替代 Layer Norm，因为在大规模实验中两者效果接近但 RMS Norm 计算更快。


class RMSNorm:
    def __init__(self, dim, eps=1e-6):
        self.gamma = np.ones(dim)
        self.eps = eps

    def forward(self, x):
        rms = np.sqrt(np.mean(x ** 2, axis=-1, keepdims=True) + self.eps)
        return x / rms * self.gamma
Pre-Norm 与 Post-Norm
在 Transformer 架构中，归一化层的放置位置对训练稳定性有显著影响。


Post-Norm（原始 Transformer）将归一化放在残差连接之后：x=Norm(x+Sublayer(x))x = \text{Norm}(x + \text{Sublayer}(x))x=Norm(x+Sublayer(x))。这种设计在理论上保持了残差路径的信号强度，但在深层网络中训练不稳定，需要 Warmup。


Pre-Norm 将归一化放在子层之前：x=x+Sublayer(Norm(x))x = x + \text{Sublayer}(\text{Norm}(x))x=x+Sublayer(Norm(x))。这种设计在残差路径上不做任何变换，梯度可以无损地流向浅层，训练更稳定，通常不需要 Warmup。

小结
    

  • BN 通过标准化中间层分布来加速训练，是 CNN 的标配技术
    • 

  • BN 依赖 batch 统计量，小 batch 场景下效果下降
    • 

  • Layer Norm 不依赖 batch 维度，是 Transformer 和 RNN 的标准选择
    • 

  • Group Norm 是 BN 和 LN 的折中，适合小 batch CNN 场景
    • 

  • RMS Norm 去掉均值中心化，在大语言模型中逐渐替代 Layer Norm
    • 

  • Pre-Norm 比 Post-Norm 训练更稳定，是当前主流大模型的选择
    • 

  • 归一化方法的选择需要考虑网络架构、batch size 和训练稳定性需求
