反向传播算法深入

核心概念

反向传播（Backpropagation）是训练神经网络的核心算法，通过链式法则高效计算损失函数对每个参数的梯度。它将一次前向传播的计算过程编码为有向无环图（计算图），然后从输出节点沿反方向逐层计算梯度，使得整个网络的梯度计算复杂度与前向传播处于同一量级。

计算图与链式法则
计算图将复杂的数学表达式分解为基本操作节点的有向无环图。每个节点代表一个基本运算（加、乘、激活等），边代表数据流。链式法则的核心思想是：复合函数的导数等于各层函数导数的乘积。


对于函数 y=f(g(x))y = f(g(x))y=f(g(x))，链式法则给出 dydx=dydg⋅dgdx\frac{dy}{dx} = \frac{dy}{dg} \cdot \frac{dg}{dx}dxdy​=dgdy​⋅dxdg​。在多层网络中，这个法则被递归应用：


import numpy as np

def forward_pass(x, W1, b1, W2, b2):
    z1 = W1 @ x + b1
    a1 = np.maximum(0, z1)
    z2 = W2 @ a1 + b2
    a2 = 1.0 / (1.0 + np.exp(-z2))
    return z1, a1, z2, a2

def backward_pass(x, y, z1, a1, z2, a2, W1, W2):
    m = x.shape[1]
    dz2 = a2 - y
    dW2 = (1 / m) * dz2 @ a1.T
    db2 = (1 / m) * np.sum(dz2, axis=1, keepdims=True)
    da1 = W2.T @ dz2
    dz1 = da1 * (z1 > 0).astype(float)
    dW1 = (1 / m) * dz1 @ x.T
    db1 = (1 / m) * np.sum(dz1, axis=1, keepdims=True)
    return dW1, db1, dW2, db2
计算图中存在两种求导模式。前向模式从输入开始逐层向前计算导数，适合输入维度小于输出维度的情况。反向模式从输出开始逐层向后计算导数，适合输出维度小于输入维度的情况。由于神经网络的输出（损失值）是标量，而参数数量巨大，反向模式在效率上有绝对优势——一次反向传播即可获得所有参数的梯度。


梯度消失与梯度爆炸
梯度在反向传播过程中逐层相乘。如果每层的梯度绝对值小于 1，经过多层累积，梯度会指数级衰减至接近零，这就是梯度消失。反之，如果每层梯度绝对值大于 1，梯度会指数级增长，导致梯度爆炸。


梯度消失在使用 Sigmoid 或 Tanh 激活的深层网络中尤为严重。Sigmoid 的最大导数为 0.25，意味着 10 层网络中，第一层的梯度最多只有输出层的 0.2510≈10−60.25^{10} \approx 10^{-6}0.2510≈10−6。

梯度裁剪（Gradient Clipping）是解决梯度爆炸最直接的方法。按范数裁剪将梯度向量的 L2 范数限制在阈值 θ\thetaθ 以内：


def clip_gradients(gradients, max_norm):
    total_norm = np.sqrt(sum(np.sum(g ** 2) for g in gradients))
    clip_coef = max_norm / (total_norm + 1e-6)
    if clip_coef < 1:
        gradients = [g * clip_coef for g in gradients]
    return gradients
自动微分系统
现代深度学习框架（PyTorch、JAX、TensorFlow）都实现了自动微分系统，使开发者无需手动推导梯度。自动微分不是数值微分（有限差分），也不是符号微分（公式化简），而是通过程序化追踪计算过程并应用链式法则的精确求导方法。


PyTorch 采用动态计算图（Define-by-Run）：每次前向传播时动态构建计算图，反向传播后图即销毁。这种设计支持任意 Python 控制流（条件、循环），调试体验与普通 Python 程序一致。


import torch

x = torch.tensor([2.0], requires_grad=True)
W = torch.tensor([3.0], requires_grad=True)
b = torch.tensor([1.0], requires_grad=True)

z = W * x + b
a = torch.relu(z)
loss = (a - torch.tensor([5.0])) ** 2

loss.backward()
print(f"dL/dW = {W.grad}")
print(f"dL/db = {b.grad}")
print(f"dL/dx = {x.grad}")
JAX 采用函数式自动微分，通过 grad 变换将一个函数转换为计算其梯度的函数。这种函数式设计天然支持高阶导数和向量化：


import jax
import jax.numpy as jnp

def loss_fn(params, x, y):
    W, b = params
    z = W @ x + b
    pred = jnp.maximum(0, z)
    return jnp.mean((pred - y) ** 2)

grad_fn = jax.grad(loss_fn)
hessian_fn = jax.hessian(loss_fn)
反向传播的内存优化
反向传播需要保存前向传播的中间激活值用于梯度计算，这在大模型中会消耗大量显存。梯度检查点（Gradient Checkpointing）通过在反向传播时重新计算部分中间值来换取内存，是一种经典的时间换空间策略。


基本思路是将网络划分为若干段，只保存每段的输入激活值。反向传播到某一段时，先重新执行该段的前向传播恢复中间值，再计算梯度。这样内存使用从 O(N)O(N)O(N) 降为 O(N)O(\sqrt{N})O(N​)，但计算量增加约 33%。


import torch
from torch.utils.checkpoint import checkpoint

class LargeModel(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.block1 = TransformerBlock()
        self.block2 = TransformerBlock()
        self.block3 = TransformerBlock()

    def forward(self, x):
        x = checkpoint(self.block1, x, use_reentrant=False)
        x = checkpoint(self.block2, x, use_reentrant=False)
        x = checkpoint(self.block3, x, use_reentrant=False)
        return x

小结
    

  • 反向传播通过链式法则在计算图上高效计算所有参数的梯度
    • 

  • 反向模式适合神经网络场景（标量输出、大量参数），一次反向传播获得所有梯度
    • 

  • 梯度消失源于饱和激活函数的小导数在深层网络中累积相乘
    • 

  • 梯度爆炸可通过梯度裁剪、合理的权重初始化和学习率控制来缓解
    • 

  • 现代框架的自动微分系统使开发者无需手动推导梯度
    • 

  • 梯度检查点通过重计算换内存，是大模型训练的标配技术
