激活函数与非线性变换

核心概念

激活函数是神经网络中引入非线性的关键组件。如果没有激活函数，无论网络有多少层，整个网络的输出都只是输入的线性变换，等价于一个单层网络。激活函数的存在使得神经网络能够逼近任意复杂的非线性映射，这是深度学习强大表达能力的数学基础。

激活函数的选择直接影响梯度流动、训练速度和最终模型性能。以下是主流激活函数的核心特性对比：

Sigmoid 与 Tanh
Sigmoid 函数 σ(z)=11+e−z\sigma(z) = \frac{1}{1+e^{-z}}σ(z)=1+e−z1​ 将任意实数映射到 (0, 1) 区间，在早期神经网络中广泛使用。其导数为 σ′(z)=σ(z)(1−σ(z))\sigma'(z) = \sigma(z)(1-\sigma(z))σ′(z)=σ(z)(1−σ(z))，最大值仅为 0.25，这意味着每经过一层，梯度至少缩小为原来的四分之一。


import numpy as np

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

def sigmoid_derivative(z):
    s = sigmoid(z)
    return s * (1 - s)
Tanh 函数 tanh⁡(z)=ez−e−zez+e−z\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}tanh(z)=ez+e−zez−e−z​ 输出以零为中心，相比 Sigmoid 在梯度流动上有优势。其导数 tanh⁡′(z)=1−tanh⁡2(z)\tanh'(z) = 1 - \tanh^2(z)tanh′(z)=1−tanh2(z) 最大值为 1，比 Sigmoid 的 0.25 大得多。但当输入绝对值较大时，两者都会进入饱和区，导数接近零，这就是梯度消失问题的根源。


def tanh(z):
    return np.tanh(z)

def tanh_derivative(z):
    t = np.tanh(z)
    return 1 - t ** 2
Sigmoid 和 Tanh 的共同缺点是：在深层网络中，由于连续的小梯度相乘，远离输出层的参数几乎无法得到有效更新。这一限制直接催生了 ReLU 族激活函数的诞生。


ReLU 族激活函数
ReLU（Rectified Linear Unit）定义为 f(z)=max⁡(0,z)f(z) = \max(0, z)f(z)=max(0,z)，是现代深度学习最常用的激活函数。它在正区间梯度恒为 1，彻底解决了梯度消失问题；计算只需一次比较操作，效率极高；同时天然产生稀疏激活，有助于特征的可解释性。


def relu(z):
    return np.maximum(0, z)

def relu_derivative(z):
    return (z > 0).astype(float)
ReLU 的主要问题是"神经元死亡"（Dying ReLU）：如果某个神经元的输入始终为负，它的输出和梯度永远为零，该神经元永久失活。为解决这一问题，研究者提出了多种变体：


Leaky ReLU 在负区间引入一个小的斜率 α\alphaα（通常为 0.01）：f(z)=max⁡(αz,z)f(z) = \max(\alpha z, z)f(z)=max(αz,z)。这确保了负区间也有非零梯度，避免神经元完全死亡。


PReLU（Parametric ReLU）将负区间斜率 α\alphaα 作为可学习参数，让网络自行决定最佳的负区间响应。


ELU（Exponential Linear Unit）在负区间使用指数函数：f(z)=zf(z) = zf(z)=z 当 z>0z > 0z>0，f(z)=α(ez−1)f(z) = \alpha(e^z - 1)f(z)=α(ez−1) 当 z≤0z \leq 0z≤0。它的输出均值接近零，有类似批归一化的效果。


def leaky_relu(z, alpha=0.01):
    return np.where(z > 0, z, alpha * z)

def elu(z, alpha=1.0):
    return np.where(z > 0, z, alpha * (np.exp(z) - 1))

GELU 与 Swish
GELU（Gaussian Error Linear Unit）是 Transformer 架构中的标准激活函数。它的定义为 GELU(z)=z⋅Φ(z)\text{GELU}(z) = z \cdot \Phi(z)GELU(z)=z⋅Φ(z)，其中 Φ(z)\Phi(z)Φ(z) 是标准正态分布的累积分布函数。直觉上，GELU 根据输入值的大小进行概率性的门控——较大的正值几乎完全通过，较大的负值几乎完全被抑制，而中间值则被平滑地缩放。


def gelu(z):
    return 0.5 * z * (1 + np.tanh(np.sqrt(2 / np.pi) * (z + 0.044715 * z ** 3)))
Swish 函数由 Google 通过自动搜索发现，定义为 f(z)=z⋅σ(βz)f(z) = z \cdot \sigma(\beta z)f(z)=z⋅σ(βz)，其中 β\betaβ 可以是固定值或可学习参数。当 β=1\beta = 1β=1 时称为 SiLU。Swish 与 GELU 在形状上非常相似，两者都是非单调的、平滑的、在负区间有小的负值输出。


GELU 和 Swish 的成功表明：平滑的非单调激活函数在深层网络中往往优于分段线性函数。它们允许小的负值通过，提供了更丰富的梯度信号，有助于优化过程中跳出局部极值。


输出层激活函数
输出层的激活函数选择取决于任务类型。对于二分类任务，使用 Sigmoid 将输出映射为概率；对于多分类任务，使用 Softmax 将输出向量转换为概率分布；对于回归任务，通常不使用激活函数（恒等映射）。


Softmax 函数定义为 Softmax(zi)=ezi∑jezj\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j} e^{z_j}}Softmax(zi​)=∑j​ezj​ezi​​，它保证所有输出值在 (0, 1) 之间且求和为 1。实际实现中需要减去最大值以避免数值溢出：


def softmax(z):
    z_shifted = z - np.max(z, axis=-1, keepdims=True)
    exp_z = np.exp(z_shifted)
    return exp_z / np.sum(exp_z, axis=-1, keepdims=True)

小结
    

  • 激活函数为神经网络引入非线性，是网络表达能力的来源
    • 

  • Sigmoid 和 Tanh 存在梯度消失问题，不适合深层网络的隐藏层
    • 

  • ReLU 通过正区间恒定梯度解决了梯度消失，但存在神经元死亡风险
    • 

  • Leaky ReLU、PReLU、ELU 通过负区间非零输出解决神经元死亡
    • 

  • GELU 和 Swish 是现代架构（Transformer、EfficientNet）的首选，平滑且非单调
    • 

  • 输出层激活函数由任务类型决定：分类用 Sigmoid/Softmax，回归用恒等映射
    • 

  • 激活函数选择没有万能答案，需要结合网络架构和任务特点进行实验验证
    •
