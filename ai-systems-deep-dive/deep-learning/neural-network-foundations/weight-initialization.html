权重初始化策略

核心概念

权重初始化是神经网络训练的起点，对训练收敛速度和最终性能有决定性影响。不恰当的初始化会导致前向传播中激活值逐层爆炸或消失，反向传播中梯度同样失控，使得训练从一开始就陷入困境。好的初始化策略确保每一层的输出方差保持稳定，使信息在网络中顺畅流动。

Xavier 初始化
Xavier 初始化（也称 Glorot 初始化）的设计目标是让每层输出的方差与输入方差相同。对于线性层 y=Wxy = Wxy=Wx，如果 WWW 的每个元素独立同分布且均值为零，输出方差为 Var(y)=nin⋅Var(W)⋅Var(x)\text{Var}(y) = n_{in} \cdot \text{Var}(W) \cdot \text{Var}(x)Var(y)=nin​⋅Var(W)⋅Var(x)。要保持 Var(y)=Var(x)\text{Var}(y) = \text{Var}(x)Var(y)=Var(x)，需要 Var(W)=1nin\text{Var}(W) = \frac{1}{n_{in}}Var(W)=nin​1​。


同时考虑反向传播中梯度的方差保持，需要 Var(W)=1nout\text{Var}(W) = \frac{1}{n_{out}}Var(W)=nout​1​。Xavier 取两者的调和平均：


Var(W)=2nin+nout\text{Var}(W) = \frac{2}{n_{in} + n_{out}}Var(W)=nin​+nout​2​
import numpy as np

def xavier_normal(n_in, n_out):
    std = np.sqrt(2.0 / (n_in + n_out))
    return np.random.randn(n_out, n_in) * std

def xavier_uniform(n_in, n_out):
    limit = np.sqrt(6.0 / (n_in + n_out))
    return np.random.uniform(-limit, limit, size=(n_out, n_in))
Xavier 初始化的推导假设激活函数在零点附近近似线性，因此最适合 Sigmoid 和 Tanh 等在原点附近斜率为 1 的激活函数。对于 ReLU，由于负半区间输出为零，Xavier 初始化会导致方差逐层减半。


He 初始化
He 初始化（也称 Kaiming 初始化）专为 ReLU 族激活函数设计。ReLU 将大约一半的神经元输出置零，等效地将方差减半。因此，He 初始化将权重方差加倍以补偿：


Var(W)=2nin\text{Var}(W) = \frac{2}{n_{in}}Var(W)=nin​2​
def he_normal(n_in, n_out):
    std = np.sqrt(2.0 / n_in)
    return np.random.randn(n_out, n_in) * std

def he_uniform(n_in, n_out):
    limit = np.sqrt(6.0 / n_in)
    return np.random.uniform(-limit, limit, size=(n_out, n_in))
对于 Leaky ReLU（斜率 α\alphaα），方差公式调整为 Var(W)=2(1+α2)⋅nin\text{Var}(W) = \frac{2}{(1+\alpha^2) \cdot n_{in}}Var(W)=(1+α2)⋅nin​2​。


def he_normal_leaky(n_in, n_out, alpha=0.01):
    std = np.sqrt(2.0 / ((1 + alpha ** 2) * n_in))
    return np.random.randn(n_out, n_in) * std
在 PyTorch 中，He 初始化是线性层和卷积层的默认策略：


import torch.nn as nn

conv = nn.Conv2d(64, 128, kernel_size=3, padding=1)
nn.init.kaiming_normal_(conv.weight, mode='fan_in', nonlinearity='relu')
nn.init.zeros_(conv.bias)

LSUV 与正交初始化
LSUV（Layer-Sequential Unit-Variance）是一种数据驱动的初始化方法。它先用正交矩阵初始化权重，然后逐层通过一个小批次数据，测量每层输出的方差，并缩放权重使方差精确等于 1。这种方法不依赖激活函数的数学假设，在实践中表现非常稳健。


def lsuv_init(model, data_batch, target_var=1.0, max_iter=10, tol=0.1):
    model.eval()
    for layer in model.modules():
        if not hasattr(layer, 'weight'):
            continue
        nn.init.orthogonal_(layer.weight)
        for _ in range(max_iter):
            with torch.no_grad():
                output = model.partial_forward(data_batch, up_to=layer)
                var = output.var().item()
                if abs(var - target_var) < tol:
                    break
                layer.weight.data *= (target_var / (var + 1e-8)) ** 0.5
正交初始化使用正交矩阵（WTW=IW^TW = IWTW=I）作为初始权重。正交矩阵的所有特征值绝对值为 1，这意味着矩阵乘法不会放大或缩小向量的范数，特别适合 RNN 等需要长距离梯度传播的架构。


def orthogonal_init(n_in, n_out, gain=1.0):
    flat_shape = (max(n_in, n_out), min(n_in, n_out))
    a = np.random.randn(*flat_shape)
    u, _, v = np.linalg.svd(a, full_matrices=False)
    q = u if u.shape == (n_out, n_in) else v
    return gain * q[:n_out, :n_in]
特殊架构的初始化
Transformer 架构通常使用 Xavier 初始化配合残差连接的缩放。GPT 系列在残差路径的最后一层使用 12N\frac{1}{\sqrt{2N}}2N​1​ 的缩放因子（NNN 为层数），确保深层网络的输出方差不会随深度增长。


def init_transformer_weights(module, n_layers):
    if isinstance(module, nn.Linear):
        nn.init.xavier_normal_(module.weight)
        if module.bias is not None:
            nn.init.zeros_(module.bias)

    if isinstance(module, ResidualProjection):
        nn.init.xavier_normal_(module.weight)
        module.weight.data /= (2 * n_layers) ** 0.5
对于卷积网络，He 初始化是标准选择。偏置项通常初始化为零。批归一化层的 γ\gammaγ 初始化为 1，β\betaβ 初始化为 0，使得初始时 BN 层等效于恒等映射。


小结
    

  • 权重初始化的核心目标是保持每层激活值和梯度的方差稳定
    • 

  • Xavier 初始化适合 Sigmoid/Tanh，通过前向和反向方差的调和平均确定权重方差
    • 

  • He 初始化适合 ReLU 族，通过加倍方差补偿 ReLU 的半区间激活特性
    • 

  • LSUV 通过数据驱动的方式逐层校准方差，不依赖激活函数的数学假设
    • 

  • 正交初始化特别适合 RNN，保持长距离梯度传播的范数稳定
    • 

  • 现代框架提供了完善的初始化工具，选对方法比手动调整更重要
