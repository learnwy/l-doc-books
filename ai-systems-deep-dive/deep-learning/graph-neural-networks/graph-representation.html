图数据表示与编码

核心概念

图（Graph）是由节点（node/vertex）和边（edge）构成的数据结构，能够自然地描述实体之间的关系。社交网络中的用户关系、分子中的原子键合、知识图谱中的实体连接都是典型的图数据。与图像（规则网格）和文本（线性序列）不同，图数据具有不规则的拓扑结构，节点的邻居数量不固定，没有天然的顺序定义——这些特点使得传统的 CNN 和 RNN 无法直接处理图数据。

邻接矩阵与稀疏表示
邻接矩阵 A∈RN×NA \in \mathbb{R}^{N \times N}A∈RN×N 是图最直观的数学表示，其中 Aij=1A_{ij} = 1Aij​=1 表示节点 iii 和 jjj 之间存在边。对于加权图，AijA_{ij}Aij​ 存储边权重。邻接矩阵支持高效的矩阵运算，是谱方法 GNN 的基础。


import numpy as np
import torch

edges = [(0, 1), (0, 2), (1, 2), (2, 3)]
num_nodes = 4

adj_matrix = np.zeros((num_nodes, num_nodes))
for i, j in edges:
    adj_matrix[i][j] = 1
    adj_matrix[j][i] = 1

degree_matrix = np.diag(adj_matrix.sum(axis=1))
laplacian = degree_matrix - adj_matrix
真实世界的图通常非常稀疏（每个节点平均只连接少量其他节点），邻接矩阵中大部分元素为零。对于百万节点的图，稠密矩阵需要 TB 级内存，因此实践中必须使用稀疏表示。


COO 格式（Coordinate Format）用两个数组分别存储边的源节点和目标节点索引，是 PyTorch Geometric 的标准格式：


edge_index = torch.tensor([
    [0, 0, 1, 2],
    [1, 2, 2, 3]
], dtype=torch.long)

x = torch.randn(num_nodes, 16)
CSR 格式（Compressed Sparse Row）按行压缩存储，适合行遍历操作。邻接表用链表或字典存储每个节点的邻居列表，适合动态图。

节点特征与边特征
节点特征矩阵 X∈RN×dX \in \mathbb{R}^{N \times d}X∈RN×d 是图神经网络的输入，每行是一个 ddd 维的节点特征向量。特征来源多种多样：社交网络中是用户画像，分子图中是原子属性（原子序数、电荷），引用网络中是论文的词袋向量。


from torch_geometric.data import Data

data = Data(
    x=torch.randn(100, 32),
    edge_index=edge_index,
    edge_attr=torch.randn(200, 8),
    y=torch.randint(0, 5, (100,)),
)
边特征 E∈RM×deE \in \mathbb{R}^{M \times d_e}E∈RM×de​ 描述边的属性。在分子图中，边特征编码化学键类型（单键、双键、三键）、键长等信息。在知识图谱中，边特征编码关系类型（如"创办"、"位于"）。


同构图与异构图
同构图中所有节点和边的类型相同，是最基本的图结构。大多数 GNN 研究聚焦于同构图。


异构图包含多种类型的节点和边。例如，一个学术网络包含"作者"、"论文"、"机构"三种节点类型，以及"撰写"、"引用"、"隶属"三种边类型。异构图需要为不同类型定义不同的特征空间和消息传递函数。


from torch_geometric.data import HeteroData

data = HeteroData()
data['author'].x = torch.randn(1000, 64)
data['paper'].x = torch.randn(5000, 128)
data['author', 'writes', 'paper'].edge_index = torch.randint(0, 1000, (2, 3000))
data['paper', 'cites', 'paper'].edge_index = torch.randint(0, 5000, (2, 10000))
处理异构图的常见策略包括：关系特定的参数矩阵（R-GCN）、元路径（Metapath）聚合和异构注意力机制。

小结
    

  • 图由节点和边组成，能够自然表达实体间的关系
    • 

  • 邻接矩阵是图的基础数学表示，稀疏存储格式是大规模图计算的关键
    • 

  • 节点特征和边特征为 GNN 提供输入信息，特征工程对性能影响显著
    • 

  • 异构图包含多种节点和边类型，需要类型特定的处理策略
    • 

  • PyTorch Geometric 的 Data 对象是组织图数据的标准方式
