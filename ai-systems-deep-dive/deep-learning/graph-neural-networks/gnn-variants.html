图注意力网络 GAT
GAT（Graph Attention Network）通过注意力机制为不同邻居赋予不同权重，而不是像 GCN 那样仅依赖图的拓扑结构（度数）来确定权重。这使得 GAT 可以自适应地关注更重要的邻居。


对于节点 vvv 和其邻居 uuu，注意力系数的计算过程为：


    

  1. 线性变换：hv′=Whv,hu′=Whuh'_v = W h_v, h'_u = W h_uhv′​=Whv​,hu′​=Whu​
    2. 

  2. 注意力得分：evu=LeakyReLU(aT[hv′∥hu′])e_{vu} = \text{LeakyReLU}(a^T [h'_v \| h'_u])evu​=LeakyReLU(aT[hv′​∥hu′​])
    3. 

  3. 归一化：αvu=softmaxu(evu)\alpha_{vu} = \text{softmax}_u(e_{vu})αvu​=softmaxu​(evu​)
    4. 

  4. 聚合：hvnew=σ(∑u∈N(v)αvuhu′)h_v^{new} = \sigma(\sum_{u \in \mathcal{N}(v)} \alpha_{vu} h'_u)hvnew​=σ(∑u∈N(v)​αvu​hu′​)
    5. 



import torch
import torch.nn as nn
from torch_geometric.nn import GATConv

class GAT(nn.Module):
    def __init__(self, in_dim, hidden_dim, out_dim, heads=8):
        super().__init__()
        self.conv1 = GATConv(in_dim, hidden_dim, heads=heads, dropout=0.6)
        self.conv2 = GATConv(hidden_dim * heads, out_dim, heads=1, concat=False, dropout=0.6)

    def forward(self, data):
        x, edge_index = data.x, data.edge_index
        x = torch.dropout(x, p=0.6, train=self.training)
        x = torch.elu(self.conv1(x, edge_index))
        x = torch.dropout(x, p=0.6, train=self.training)
        x = self.conv2(x, edge_index)
        return x
多头注意力让不同的头关注不同类型的邻居关系，多头输出可以拼接或平均。GATv2 通过修改注意力计算顺序（先拼接再变换）解决了原始 GAT 的静态注意力问题，使其能够计算真正的动态注意力。


GraphSAGE 与采样聚合
GraphSAGE（SAmple and agGrEgate）通过两个关键设计实现大规模图上的高效训练：邻居采样和归纳学习。


邻居采样：不使用全部邻居，而是每层随机采样固定数量的邻居（如第一层采样 25 个，第二层采样 10 个），将计算复杂度从 O(N)O(N)O(N) 降为常数。


归纳学习：GraphSAGE 学习的是聚合函数而非节点嵌入，因此可以泛化到训练时未见过的新节点。


from torch_geometric.nn import SAGEConv
from torch_geometric.loader import NeighborLoader

class GraphSAGE(nn.Module):
    def __init__(self, in_dim, hidden_dim, out_dim):
        super().__init__()
        self.conv1 = SAGEConv(in_dim, hidden_dim)
        self.conv2 = SAGEConv(hidden_dim, out_dim)

    def forward(self, x, edge_index):
        x = torch.relu(self.conv1(x, edge_index))
        x = self.conv2(x, edge_index)
        return x

GIN 与表达能力上界
图同构网络（GIN, Graph Isomorphism Network）是理论上表达能力最强的消息传递 GNN。它的设计直接来源于 Weisfeiler-Leman (WL) 图同构测试的理论分析：要达到 WL 测试的区分能力，GNN 的聚合函数必须是单射（injective）——不同的邻居多重集必须映射到不同的表示。


GIN 的更新公式为：hv(k)=MLP(k)((1+ϵ(k))hv(k−1)+∑u∈N(v)hu(k−1))h_v^{(k)} = \text{MLP}^{(k)}((1+\epsilon^{(k)}) h_v^{(k-1)} + \sum_{u \in \mathcal{N}(v)} h_u^{(k-1)})hv(k)​=MLP(k)((1+ϵ(k))hv(k−1)​+∑u∈N(v)​hu(k−1)​)


关键设计点：使用 SUM 聚合（保持多重集的完整信息）+ MLP（提供足够的非线性来实现单射映射）。


from torch_geometric.nn import GINConv

class GIN(nn.Module):
    def __init__(self, in_dim, hidden_dim, out_dim, num_layers=5):
        super().__init__()
        self.convs = nn.ModuleList()
        self.bns = nn.ModuleList()
        for i in range(num_layers):
            dim_in = in_dim if i == 0 else hidden_dim
            mlp = nn.Sequential(
                nn.Linear(dim_in, hidden_dim),
                nn.BatchNorm1d(hidden_dim),
                nn.ReLU(),
                nn.Linear(hidden_dim, hidden_dim),
            )
            self.convs.append(GINConv(mlp))
            self.bns.append(nn.BatchNorm1d(hidden_dim))
        self.classifier = nn.Linear(hidden_dim, out_dim)

    def forward(self, data):
        x, edge_index, batch = data.x, data.edge_index, data.batch
        for conv, bn in zip(self.convs, self.bns):
            x = torch.relu(bn(conv(x, edge_index)))
        from torch_geometric.nn import global_add_pool
        x = global_add_pool(x, batch)
        return self.classifier(x)

异构图与关系建模
R-GCN（Relational GCN）为异构图中的每种关系类型分配独立的权重矩阵：


hv(l+1)=σ(∑r∈R∑u∈Nr(v)1∣Nr(v)∣Wr(l)hu(l)+W0(l)hv(l))h_v^{(l+1)} = \sigma\left(\sum_{r \in R}\sum_{u \in \mathcal{N}_r(v)} \frac{1}{|\mathcal{N}_r(v)|} W_r^{(l)} h_u^{(l)} + W_0^{(l)} h_v^{(l)}\right)hv(l+1)​=σ​r∈R∑​u∈Nr​(v)∑​∣Nr​(v)∣1​Wr(l)​hu(l)​+W0(l)​hv(l)​​
为了避免参数爆炸（关系类型数量 × 特征维度²），R-GCN 使用基分解或块对角分解来共享参数。


小结
    

  • GAT 通过注意力机制自适应地为不同邻居分配权重
    • 

  • GraphSAGE 通过邻居采样和归纳学习实现大规模图的高效训练
    • 

  • GIN 使用 SUM+MLP 达到了 WL 测试等价的最强区分能力
    • 

  • SUM 聚合在理论上严格优于 MEAN 和 MAX 聚合
    • 

  • R-GCN 通过关系特定参数处理异构图，基分解控制参数量
    • 

  • 选择 GNN 变体需要综合考虑表达能力、可扩展性和任务需求
