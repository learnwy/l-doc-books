消息传递框架

核心概念

消息传递神经网络（Message Passing Neural Network, MPNN）是理解几乎所有图神经网络的统一框架。它的核心思想是：每个节点通过收集邻居的信息（消息）来更新自己的表示。经过 KKK 轮消息传递后，每个节点的表示融合了 KKK 跳邻域内所有节点的信息。这个框架将 GCN、GAT、GraphSAGE 等看似不同的 GNN 统一到了同一范式下。

消息构造与聚合
在第 kkk 轮消息传递中，节点 vvv 从每个邻居 u∈N(v)u \in \mathcal{N}(v)u∈N(v) 收集消息。消息的内容和聚合方式决定了 GNN 的表达能力。


最简单的消息函数直接使用邻居的特征，经过线性变换：mu→v(k)=W(k)hu(k−1)m_{u \to v}^{(k)} = W^{(k)} h_u^{(k-1)}mu→v(k)​=W(k)hu(k−1)​。更复杂的消息函数会同时考虑源节点、目标节点和边的特征。


import torch
import torch.nn as nn
from torch_geometric.nn import MessagePassing
from torch_geometric.utils import add_self_loops, degree

class SimpleMP(MessagePassing):
    def __init__(self, in_channels, out_channels):
        super().__init__(aggr='add')
        self.lin = nn.Linear(in_channels, out_channels)

    def forward(self, x, edge_index):
        edge_index, _ = add_self_loops(edge_index, num_nodes=x.size(0))
        x = self.lin(x)
        row, col = edge_index
        deg = degree(col, x.size(0), dtype=x.dtype)
        deg_inv_sqrt = deg.pow(-0.5)
        norm = deg_inv_sqrt[row] * deg_inv_sqrt[col]
        return self.propagate(edge_index, x=x, norm=norm)

    def message(self, x_j, norm):
        return norm.view(-1, 1) * x_j
聚合函数的选择对 GNN 的区分能力有根本影响。SUM 聚合保留了邻域的完整信息（多重集），MEAN 聚合对节点度不敏感，MAX 聚合只保留最显著的特征。

GCN 的消息传递视角
图卷积网络（GCN）是消息传递框架的经典实例。GCN 的层更新公式为：


H(l+1)=σ(D~−12A~D~−12H(l)W(l))H^{(l+1)} = \sigma(\tilde{D}^{-\frac{1}{2}} \tilde{A} \tilde{D}^{-\frac{1}{2}} H^{(l)} W^{(l)})H(l+1)=σ(D~−21​A~D~−21​H(l)W(l))
其中 A~=A+I\tilde{A} = A + IA~=A+I 是加了自环的邻接矩阵，D~\tilde{D}D~ 是对应的度矩阵。从消息传递的视角看：


    

  • 消息函数：mu→v=1deg⁡(u)deg⁡(v)Whum_{u \to v} = \frac{1}{\sqrt{\deg(u)\deg(v)}} W h_umu→v​=deg(u)deg(v)​1​Whu​（对称归一化）
    • 

  • 聚合函数：SUM（对所有邻居消息求和，包括自环）
    • 

  • 更新函数：非线性激活 σ(⋅)\sigma(\cdot)σ(⋅)
    • 



from torch_geometric.nn import GCNConv

class GCN(nn.Module):
    def __init__(self, in_dim, hidden_dim, out_dim):
        super().__init__()
        self.conv1 = GCNConv(in_dim, hidden_dim)
        self.conv2 = GCNConv(hidden_dim, out_dim)

    def forward(self, data):
        x, edge_index = data.x, data.edge_index
        x = torch.relu(self.conv1(x, edge_index))
        x = torch.dropout(x, p=0.5, train=self.training)
        x = self.conv2(x, edge_index)
        return x
过平滑问题
随着消息传递轮数的增加，所有节点的表示会趋向于相同的值——这就是过平滑（Over-Smoothing）问题。直觉上，每轮消息传递相当于一次邻域平均操作，多轮之后所有节点都看到了整个图的信息，丧失了局部特征的区分度。


缓解过平滑的策略包括：


    

  • 残差连接：hv(k)=hv(k−1)+MPNN(hv(k−1))h_v^{(k)} = h_v^{(k-1)} + \text{MPNN}(h_v^{(k-1)})hv(k)​=hv(k−1)​+MPNN(hv(k−1)​)，保持原始特征
    • 

  • JumpingKnowledge：拼接所有层的输出 hv=[hv(1)∥hv(2)∥...∥hv(K)]h_v = [h_v^{(1)} \| h_v^{(2)} \| ... \| h_v^{(K)}]hv​=[hv(1)​∥hv(2)​∥...∥hv(K)​]
    • 

  • DropEdge：训练时随机删除部分边，减少信息传播的路径
    • 

  • PairNorm：归一化节点表示使其保持多样性
    • 



class GCNWithResidual(nn.Module):
    def __init__(self, in_dim, hidden_dim, num_layers):
        super().__init__()
        self.convs = nn.ModuleList()
        self.convs.append(GCNConv(in_dim, hidden_dim))
        for _ in range(num_layers - 1):
            self.convs.append(GCNConv(hidden_dim, hidden_dim))

    def forward(self, x, edge_index):
        for conv in self.convs:
            x_new = torch.relu(conv(x, edge_index))
            x = x + x_new
        return x

from torch_geometric.nn import global_mean_pool, global_add_pool

class GraphClassifier(nn.Module):
    def __init__(self, in_dim, hidden_dim, num_classes):
        super().__init__()
        self.conv1 = GCNConv(in_dim, hidden_dim)
        self.conv2 = GCNConv(hidden_dim, hidden_dim)
        self.classifier = nn.Linear(hidden_dim, num_classes)

    def forward(self, data):
        x = torch.relu(self.conv1(data.x, data.edge_index))
        x = torch.relu(self.conv2(x, data.edge_index))
        x = global_mean_pool(x, data.batch)
        return self.classifier(x)
小结
    

  • MPNN 框架将 GNN 统一为消息构造、聚合和更新三个步骤
    • 

  • 聚合函数的选择决定了 GNN 的区分能力，SUM 聚合理论上最强
    • 

  • GCN 是 MPNN 框架的经典实例，使用对称归一化和 SUM 聚合
    • 

  • 过平滑是深层 GNN 的核心挑战，随着层数增加节点表示趋同
    • 

  • 残差连接和 JumpingKnowledge 是缓解过平滑的有效策略
    • 

  • 图级任务需要读出函数将节点表示聚合为图表示
