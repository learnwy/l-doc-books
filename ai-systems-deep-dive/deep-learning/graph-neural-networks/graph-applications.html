图神经网络应用

核心概念

图神经网络的应用覆盖了从推荐系统到药物发现、从交通预测到程序分析的广泛领域。根据预测粒度的不同，GNN 的任务可以分为三个层次：节点级（预测单个节点的属性）、边级（预测节点间的关系）和图级（预测整个图的属性）。理解这三类任务的建模方式和训练策略是将 GNN 应用到实际问题的关键。

推荐系统中的 GNN
推荐系统本质上是一个二部图上的链接预测问题：用户和物品作为两种节点，历史交互作为边，任务是预测未来可能出现的边。GNN 通过在这个二部图上进行消息传递来学习用户和物品的嵌入表示。


import torch
import torch.nn as nn
from torch_geometric.nn import SAGEConv

class LightGCN(nn.Module):
    def __init__(self, num_users, num_items, embed_dim, num_layers):
        super().__init__()
        self.user_emb = nn.Embedding(num_users, embed_dim)
        self.item_emb = nn.Embedding(num_items, embed_dim)
        self.num_layers = num_layers
        self.convs = nn.ModuleList([
            SAGEConv(embed_dim, embed_dim) for _ in range(num_layers)
        ])

    def forward(self, edge_index):
        x = torch.cat([self.user_emb.weight, self.item_emb.weight])
        all_embeddings = [x]
        for conv in self.convs:
            x = conv(x, edge_index)
            all_embeddings.append(x)
        final = torch.stack(all_embeddings, dim=0).mean(dim=0)
        return final
PinSage（Pinterest）是工业级 GNN 推荐系统的典范。它使用随机游走采样邻居、重要性池化聚合消息，能够在包含 30 亿节点和 180 亿边的图上进行高效训练和推理。

药物发现与分子性质预测
分子天然是图结构：原子是节点，化学键是边。GNN 可以直接在分子图上学习，预测溶解度、毒性、药物-靶点结合亲和力等性质。


from torch_geometric.nn import GINConv, global_add_pool

class MoleculeGNN(nn.Module):
    def __init__(self, atom_feat_dim, hidden_dim, num_tasks):
        super().__init__()
        self.conv1 = GINConv(nn.Sequential(
            nn.Linear(atom_feat_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
        ))
        self.conv2 = GINConv(nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
        ))
        self.predictor = nn.Linear(hidden_dim, num_tasks)

    def forward(self, data):
        x = torch.relu(self.conv1(data.x, data.edge_index))
        x = torch.relu(self.conv2(x, data.edge_index))
        x = global_add_pool(x, data.batch)
        return self.predictor(x)
交通预测与时空图
交通流量预测是一个典型的时空预测问题：空间上，交通节点（路口、路段）构成一个图；时间上，流量数据是一个序列。时空图神经网络（STGNN）结合图卷积和时间卷积/RNN 来同时捕捉空间依赖和时间动态。


class STGNNBlock(nn.Module):
    def __init__(self, in_channels, spatial_channels, temporal_channels, num_nodes):
        super().__init__()
        self.temporal1 = nn.Conv2d(in_channels, temporal_channels, kernel_size=(1, 3), padding=(0, 1))
        self.spatial = GCNConv(temporal_channels, spatial_channels)
        self.temporal2 = nn.Conv2d(spatial_channels, in_channels, kernel_size=(1, 3), padding=(0, 1))
        self.norm = nn.LayerNorm([num_nodes, in_channels])

    def forward(self, x, edge_index):
        residual = x
        x = torch.relu(self.temporal1(x.permute(0, 3, 1, 2)).permute(0, 2, 3, 1))
        b, n, t, c = x.shape
        x = x.reshape(b * t, n, c)
        x = torch.relu(self.spatial(x, edge_index))
        x = x.reshape(b, n, t, -1)
        x = torch.relu(self.temporal2(x.permute(0, 3, 1, 2)).permute(0, 2, 3, 1))
        return self.norm(x + residual)

程序分析与代码理解
程序的抽象语法树（AST）和控制流图（CFG）天然是图结构。GNN 可以在这些程序图上学习代码的语义表示，用于漏洞检测、代码克隆检测和自动修复等任务。


在漏洞检测中，将源代码转换为代码属性图（CPG），结合 AST、控制流和数据流信息，然后用 GNN 学习代码片段是否包含安全漏洞。这种方法比基于文本序列的方法更能捕捉程序的结构语义。


小结
    

  • GNN 任务分为节点级、边级和图级三个层次
    • 

  • 推荐系统将用户-物品交互建模为二部图上的链接预测
    • 

  • 分子性质预测将原子和键作为节点和边，通过图读出获得分子表示
    • 

  • 时空图网络结合图卷积和时间建模处理交通等动态预测任务
    • 

  • 程序图上的 GNN 可以捕捉代码的结构语义，用于漏洞检测等任务
    • 

  • 选择 GNN 方案时需要考虑图的规模、异构性和实时性需求
