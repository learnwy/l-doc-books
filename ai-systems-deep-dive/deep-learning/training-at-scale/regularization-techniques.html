正则化技术

核心概念

正则化是防止模型过拟合的一系列技术手段。过拟合的本质是模型在训练集上过度拟合了噪声和非本质模式，导致在新数据上表现下降。正则化通过限制模型复杂度、增加训练数据多样性或在训练过程中引入随机性，迫使模型学习更加泛化的特征表示。在深度学习中，正则化不是可选的锦上添花，而是获得好泛化性能的必备工具。

L2 权重衰减与 L1 正则化
L2 正则化（也称权重衰减）在损失函数中添加权重平方和的惩罚项：Lreg=L+λ2∥θ∥22L_{reg} = L + \frac{\lambda}{2}\|\theta\|_2^2Lreg​=L+2λ​∥θ∥22​。从梯度更新的角度看，L2 正则化等价于在每次更新时将权重缩小一个比例：θt+1=(1−ηλ)θt−η∇L\theta_{t+1} = (1-\eta\lambda)\theta_t - \eta\nabla Lθt+1​=(1−ηλ)θt​−η∇L。


import torch.optim as optim

optimizer = optim.SGD(model.parameters(), lr=0.01, weight_decay=1e-4)

optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)
L1 正则化添加权重绝对值的惩罚项：Lreg=L+λ∥θ∥1L_{reg} = L + \lambda\|\theta\|_1Lreg​=L+λ∥θ∥1​。L1 的独特性质是它倾向于将小权重完全推向零，产生稀疏模型。这在特征选择和模型压缩中有价值，但在深度学习中使用频率远低于 L2。

Dropout 及其变体
Dropout 在训练过程中以概率 ppp 随机将神经元输出置零，推理时使用所有神经元但将输出乘以 (1−p)(1-p)(1−p)（或训练时除以 (1−p)(1-p)(1−p)，即 Inverted Dropout）。这等价于训练了指数级数量的子网络，推理时使用它们的集成。


import torch.nn as nn

class MLPWithDropout(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim, dropout_rate=0.5):
        super().__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.dropout = nn.Dropout(dropout_rate)
        self.fc2 = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = self.dropout(x)
        return self.fc2(x)
DropConnect 随机丢弃权重连接而非神经元输出，提供更细粒度的正则化。


DropPath（Stochastic Depth）在残差网络中随机跳过整个残差块，让网络以不同深度进行训练。在 ViT 和 ConvNeXt 等现代架构中广泛使用。


Spatial Dropout 对卷积层按通道整体丢弃，而非逐元素丢弃，保持了通道内的空间一致性。


数据增强策略
数据增强通过对训练数据施加随机变换来增加数据多样性，是视觉任务中最有效的正则化手段。


基础增强包括随机翻转、旋转、裁剪、颜色抖动等几何和颜色变换。高级增强策略则更加激进：


Mixup 将两个训练样本线性插值：x~=λxi+(1−λ)xj\tilde{x} = \lambda x_i + (1-\lambda) x_jx~=λxi​+(1−λ)xj​，y~=λyi+(1−λ)yj\tilde{y} = \lambda y_i + (1-\lambda) y_jy~​=λyi​+(1−λ)yj​。


CutMix 将一个图像的矩形区域替换为另一个图像的对应区域，标签按面积比例混合。


RandAugment 从一组变换中随机选择 N 个，每个以相同强度 M 应用。


from torchvision import transforms

train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(brightness=0.4, contrast=0.4, saturation=0.4),

    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])

Label Smoothing 与 Early Stopping
Label Smoothing 将硬标签 [0,0,1,0][0, 0, 1, 0][0,0,1,0] 转换为软标签 [ϵK,ϵK,1−ϵ+ϵK,ϵK][\frac{\epsilon}{K}, \frac{\epsilon}{K}, 1-\epsilon+\frac{\epsilon}{K}, \frac{\epsilon}{K}][Kϵ​,Kϵ​,1−ϵ+Kϵ​,Kϵ​]。这防止模型对训练标签过度自信，减小了最后一层权重的范数，提升了泛化能力和模型校准。


criterion = nn.CrossEntropyLoss(label_smoothing=0.1)
Early Stopping 监控验证集性能，当性能在连续若干个 epoch 不再提升时停止训练。它等价于一种隐式正则化，限制了模型在训练集上拟合的程度。


class EarlyStopping:
    def __init__(self, patience=10, min_delta=1e-4):
        self.patience = patience
        self.min_delta = min_delta
        self.counter = 0
        self.best_loss = float('inf')

    def should_stop(self, val_loss):
        if val_loss < self.best_loss - self.min_delta:
            self.best_loss = val_loss
            self.counter = 0
            return False
        self.counter += 1
        return self.counter >= self.patience
小结
    

  • L2 权重衰减通过惩罚大权重防止过拟合，AdamW 的解耦实现效果更好
    • 

  • Dropout 通过随机失活训练指数级子网络的隐式集成
    • 

  • DropPath 在深层残差网络中随机跳过层，是 ViT 等现代架构的标配
    • 

  • 数据增强是视觉任务最有效的正则化手段，Mixup 和 CutMix 效果显著
    • 

  • Label Smoothing 防止过度自信，改善泛化和模型校准
    • 

  • 多种正则化方法通常需要组合使用，根据任务特点调节各自强度
