优化算法

核心概念

优化算法是深度学习训练的引擎，决定了模型参数如何根据梯度信息进行更新。从最基本的随机梯度下降到自适应学习率的 Adam，再到面向大规模训练的 LAMB，优化算法的演进始终围绕一个核心目标：在高维非凸损失曲面上更快、更稳定地找到好的极小值。选择合适的优化器和学习率调度策略，对模型的最终性能有着直接且深远的影响。

SGD 与动量法
随机梯度下降（SGD）是最基础的优化算法：θt+1=θt−η∇L(θt)\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)θt+1​=θt​−η∇L(θt​)。每次迭代随机采样一个 mini-batch 计算梯度，用梯度方向更新参数。SGD 的噪声性质反而有助于跳出尖锐极小值，找到更平坦的极值点（泛化更好）。


动量法在 SGD 的基础上引入速度变量，累积历史梯度方向：


vt=γvt−1+η∇L(θt)v_t = \gamma v_{t-1} + \eta \nabla L(\theta_t)vt​=γvt−1​+η∇L(θt​)
 


θt+1=θt−vt\theta_{t+1} = \theta_t - v_tθt+1​=θt​−vt​
import torch.optim as optim

optimizer = optim.SGD(model.parameters(), lr=0.1, momentum=0.9, weight_decay=1e-4)
Nesterov 动量是一个重要变体——先按动量方向"预测"一步，然后在预测位置计算梯度。这种"先看后跳"的策略在实践中通常收敛更快。


optimizer = optim.SGD(model.parameters(), lr=0.1, momentum=0.9, nesterov=True)
自适应学习率优化器
AdaGrad 为每个参数维护一个历史梯度平方和，学习率自动缩放：频繁更新的参数学习率降低，稀少更新的参数学习率保持较大。但梯度平方和单调增加，学习率最终趋向于零，训练过早停止。


RMSProp 用指数移动平均替代累积求和，解决了 AdaGrad 学习率持续衰减的问题：


st=ρst−1+(1−ρ)gt2s_t = \rho s_{t-1} + (1-\rho) g_t^2st​=ρst−1​+(1−ρ)gt2​
 


θt+1=θt−ηst+ϵgt\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{s_t + \epsilon}} g_tθt+1​=θt​−st​+ϵ​η​gt​
Adam 结合了动量（一阶矩估计）和自适应学习率（二阶矩估计），并加入了偏差校正：


optimizer = optim.Adam(model.parameters(), lr=1e-3, betas=(0.9, 0.999), eps=1e-8)
AdamW 与权重衰减
Adam 的原始实现将 L2 正则化项加入梯度计算中，但这与自适应学习率产生了耦合效应——大梯度的参数不仅学习率小，衰减也小，违反了正则化的初衷。


AdamW（Decoupled Weight Decay）将权重衰减从梯度更新中分离出来，作为独立步骤执行：


θt+1=(1−λη)θt−ηm^tv^t+ϵ\theta_{t+1} = (1 - \lambda\eta)\theta_t - \eta \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon}θt+1​=(1−λη)θt​−ηv^t​​+ϵm^t​​
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)
AdamW 是当前 Transformer 训练的标准优化器。它确保了每个参数的权重衰减强度一致，不受自适应学习率的干扰。

学习率调度策略
学习率是训练中最重要的超参数。固定学习率很难兼顾训练初期的快速收敛和后期的精细调优。学习率调度器在训练过程中动态调整学习率。


from torch.optim.lr_scheduler import CosineAnnealingLR, OneCycleLR

scheduler = CosineAnnealingLR(optimizer, T_max=100, eta_min=1e-6)

scheduler = OneCycleLR(optimizer, max_lr=1e-3, total_steps=10000, pct_start=0.1)
Warmup 在训练初期从极小的学习率线性增长到目标值，避免初始阶段因随机权重导致的大梯度更新破坏训练。Warmup 对 Transformer 训练尤为关键。


余弦退火将学习率按余弦函数从初始值平滑衰减到接近零，在训练后期提供精细的参数调整。


OneCycleLR 将训练分为上升和下降两个阶段，学习率先增大后减小，同时动量反向变化。这种策略通常能在更少的 epoch 内达到更好的效果。

小结
    

  • SGD + Momentum 是 CNN 训练的经典选择，噪声有助于泛化
    • 

  • Adam 结合动量和自适应学习率，是通用的默认优化器
    • 

  • AdamW 通过解耦权重衰减修复了 Adam 的正则化问题，是 Transformer 的标配
    • 

  • 学习率调度策略（Warmup + 余弦退火）对大模型训练至关重要
    • 

  • LAMB/LARS 通过按层缩放学习率支持超大 batch size 训练
    • 

  • 优化器选择需要结合模型架构、数据规模和训练预算综合决策
    •
