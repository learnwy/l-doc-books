混合精度训练

核心概念

混合精度训练（Mixed Precision Training）通过在训练中同时使用不同的数值精度（如 FP16/BF16 和 FP32）来加速计算并降低显存占用，同时保持与全精度训练相当的模型质量。核心思想是：大部分前向和反向计算使用低精度（速度快、显存省），而参数更新和关键累积操作使用高精度（保持数值稳定性）。现代 GPU（如 NVIDIA A100/H100）的 Tensor Core 对低精度运算有硬件级加速，混合精度可以带来 2-3 倍的训练加速。

FP16 训练与损失缩放
FP16 的主要挑战是其有限的数值范围。FP16 能表示的最小正数约为 6×10−86 \times 10^{-8}6×10−8，而训练中的梯度值经常小于这个阈值，导致下溢为零。损失缩放（Loss Scaling）通过在反向传播前将损失乘以一个大的缩放因子来解决这个问题。


静态损失缩放使用固定的缩放因子（如 1024），简单但需要人工调节。


动态损失缩放自动调整缩放因子：如果梯度中出现 Inf/NaN，说明缩放过大，将缩放因子减半并跳过这步更新；如果连续多步正常，则增大缩放因子。


import torch
from torch.cuda.amp import autocast, GradScaler

model = MyModel().cuda()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)
scaler = GradScaler()

for batch in dataloader:
    optimizer.zero_grad()
    with autocast(dtype=torch.float16):
        output = model(batch)
        loss = criterion(output, target)
    scaler.scale(loss).backward()
    scaler.unscale_(optimizer)
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
    scaler.step(optimizer)
    scaler.update()
PyTorch 的 autocast 上下文管理器自动为不同操作选择最优精度：矩阵乘法和卷积使用 FP16（Tensor Core 加速），归一化和 Softmax 保持 FP32（数值敏感）。


BF16 与大模型训练
BF16（Brain Float 16）与 FP32 共享相同的 8 位指数，因此数值范围与 FP32 一致，不需要损失缩放。但 BF16 的尾数只有 7 位（FP16 有 10 位），精度更低。


with autocast(dtype=torch.bfloat16):
    output = model(batch)
    loss = criterion(output, target)

loss.backward()
optimizer.step()
BF16 的最大优势是简化了训练流程——不需要 GradScaler 和损失缩放，不会出现梯度溢出。这使得 BF16 成为大语言模型训练的首选格式。GPT-3、LLaMA、PaLM 等大模型都使用 BF16 训练。

量化感知训练
量化感知训练（Quantization-Aware Training, QAT）在训练过程中模拟量化效果，使模型学会适应低精度表示，从而在推理时直接使用 INT8 或更低精度而不损失精度。


QAT 在前向传播中插入伪量化节点（fake quantization），将浮点值映射到整数再映射回浮点。反向传播使用直通估计器（Straight-Through Estimator, STE）绕过不可导的量化操作。


import torch.quantization as quant

model.train()
model.qconfig = quant.get_default_qat_qconfig('x86')
model_prepared = quant.prepare_qat(model)

for batch in dataloader:
    output = model_prepared(batch)
    loss = criterion(output, target)
    loss.backward()
    optimizer.step()

model_quantized = quant.convert(model_prepared)

工程最佳实践
混合精度训练的工程实践需要注意几个关键点：


精度敏感操作：Softmax、Layer Norm、损失函数中的对数运算应保持 FP32。PyTorch 的 autocast 已经内置了这些规则。


梯度累积：在混合精度下做梯度累积时，梯度应在 FP32 下累积，只在最终更新前转换精度。


分布式训练：AllReduce 通信中的梯度应使用 FP16/BF16 以减少通信量，但在本地进行 FP32 累积。


for i, batch in enumerate(dataloader):
    with autocast(dtype=torch.bfloat16):
        loss = model(batch) / accumulation_steps
    loss.backward()
    if (i + 1) % accumulation_steps == 0:
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        optimizer.step()
        optimizer.zero_grad()
小结
    

  • 混合精度通过低精度计算 + 高精度存储实现加速与稳定性的平衡
    • 

  • FP16 训练需要损失缩放防止梯度下溢，BF16 因范围与 FP32 一致无需缩放
    • 

  • BF16 是大语言模型训练的首选格式，简化了训练流程
    • 

  • PyTorch 的 autocast 和 GradScaler 提供了开箱即用的混合精度支持
    • 

  • 量化感知训练让模型在训练中适应低精度，推理时可直接使用 INT8
    • 

  • 混合精度是现代深度学习训练的标配，几乎没有理由不使用
    •
