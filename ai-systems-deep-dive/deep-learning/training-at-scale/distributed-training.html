分布式训练

核心概念

当模型规模和数据规模增长到单个 GPU 无法承载时，分布式训练成为必然选择。分布式训练的核心问题是如何将计算和存储分摊到多个设备上，同时保持训练的正确性和效率。根据分拆维度的不同，主流的并行策略包括数据并行、模型并行（张量并行和流水线并行）以及它们的混合。

数据并行
数据并行是最常用的分布式策略。每个 GPU 持有模型的完整副本，训练数据被均匀分到各 GPU。每轮迭代中，各 GPU 独立计算前向和反向传播，然后通过 AllReduce 操作同步梯度，保证所有 GPU 上的模型参数一致。


import torch
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP

def setup(rank, world_size):
    dist.init_process_group("nccl", rank=rank, world_size=world_size)
    torch.cuda.set_device(rank)

def train(rank, world_size):
    setup(rank, world_size)
    model = MyModel().to(rank)

AllReduce 操作是数据并行的核心通信原语。Ring AllReduce 将 NNN 个 GPU 组成环形拓扑，每个 GPU 只与相邻的两个通信，总通信量为 2(N−1)/N×M2(N-1)/N \times M2(N−1)/N×M（MMM 为模型参数量），近似与 GPU 数量无关。


模型并行
当单个模型无法放入一个 GPU 时，需要将模型拆分到多个设备上。


张量并行（Tensor Parallelism）将单个层的参数矩阵切分到多个 GPU。以 Transformer 的 MLP 层为例，第一个线性层按列切分，第二个按行切分，最终通过 AllReduce 合并输出。


流水线并行（Pipeline Parallelism）将模型的不同层放在不同的 GPU 上。朴素实现会导致严重的设备空闲（气泡）。GPipe 通过将 mini-batch 切分为微批次（micro-batch）并交错调度来减少气泡。


from torch.distributed.pipelining import SplitPoint, pipeline

class ModelShard1(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(*[TransformerBlock() for _ in range(12)])

    def forward(self, x):

class ModelShard2(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(*[TransformerBlock() for _ in range(12)])
        self.head = nn.Linear(768, 50000)

    def forward(self, x):
        return self.head(self.layers(x))

DeepSpeed ZeRO
DeepSpeed 的 ZeRO（Zero Redundancy Optimizer）通过分片消除数据并行中的冗余存储。在标准数据并行中，每个 GPU 都存储完整的模型参数、梯度和优化器状态，造成巨大的内存浪费。


    

  • ZeRO Stage 1：分片优化器状态（如 Adam 的一阶和二阶矩），内存减少约 4 倍
    • 

  • ZeRO Stage 2：额外分片梯度，内存减少约 8 倍
    • 

  • ZeRO Stage 3：连参数也分片，内存减少与 GPU 数量成正比
    • 



import deepspeed

model_engine, optimizer, _, _ = deepspeed.initialize(
    model=model,
    config={
        "zero_optimization": {
            "stage": 2,
            "offload_optimizer": {"device": "cpu"},
            "contiguous_gradients": True,
            "overlap_comm": True,
        },
        "train_batch_size": 256,
        "gradient_accumulation_steps": 4,
        "fp16": {"enabled": True},
    }
)
PyTorch 的 FSDP（Fully Sharded Data Parallel）是 ZeRO Stage 3 的原生实现：


from torch.distributed.fsdp import FullyShardedDataParallel as FSDP

model = FSDP(model, auto_wrap_policy=transformer_auto_wrap_policy)
梯度累积与大 Batch 训练
当单个 GPU 的显存不足以容纳目标 batch size 时，梯度累积是最简单的解决方案：连续多个 micro-batch 只做前向和反向（累加梯度），最后统一更新参数。


accumulation_steps = 4

for i, batch in enumerate(dataloader):
    loss = model(batch) / accumulation_steps
    loss.backward()
    if (i + 1) % accumulation_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
大 batch 训练需要配合线性缩放规则（学习率 ∝ batch size）和 Warmup 来保持训练稳定性。


小结
    

  • 数据并行通过 AllReduce 同步梯度，是最常用的分布式策略
    • 

  • 张量并行拆分单层参数，流水线并行拆分不同层，两者互补
    • 

  • ZeRO/FSDP 通过分片消除冗余存储，是大模型训练的标配
    • 

  • 梯度累积在不增加显存的情况下实现等效大 batch 训练
    • 

  • 3D 并行（数据 + 张量 + 流水线）是训练千亿参数模型的标准方案
    • 

  • 通信与计算的重叠是提升分布式训练效率的关键优化
    •
