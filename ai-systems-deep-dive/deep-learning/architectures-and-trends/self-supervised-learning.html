自监督学习

核心概念

自监督学习（Self-Supervised Learning, SSL）从无标注数据中自动构造监督信号来学习有用的特征表示。它的核心思想是设计前置任务（pretext task），让模型通过解决这些任务来学习数据的内在结构和语义，然后将学到的表示迁移到下游任务。自监督学习是大模型时代的基石——BERT 的掩码语言模型、GPT 的下一 token 预测、CLIP 的图文对比，都是自监督学习的成功应用。

对比学习
对比学习的核心思想是：同一样本的不同增强视图（正样本对）在特征空间中应该接近，不同样本的视图（负样本对）应该远离。


SimCLR 的训练过程：


    

  1. 对每个图像应用两种随机数据增强，得到两个视图
    2. 

  2. 通过共享编码器提取特征
    3. 

  3. 通过投影头映射到低维空间
    4. 

  4. 使用 NT-Xent 损失（归一化温度缩放交叉熵）训练
    5. 



import torch
import torch.nn as nn
import torch.nn.functional as F

class SimCLR(nn.Module):
    def __init__(self, encoder, projection_dim=128, temperature=0.5):
        super().__init__()
        self.encoder = encoder
        self.projector = nn.Sequential(
            nn.Linear(encoder.output_dim, 512),
            nn.ReLU(),
            nn.Linear(512, projection_dim),
        )
        self.temperature = temperature

    def forward(self, x1, x2):
        z1 = F.normalize(self.projector(self.encoder(x1)), dim=1)
        z2 = F.normalize(self.projector(self.encoder(x2)), dim=1)
        return z1, z2

    def nt_xent_loss(self, z1, z2):
        batch_size = z1.size(0)
        z = torch.cat([z1, z2], dim=0)
        sim = torch.mm(z, z.T) / self.temperature
        mask = torch.eye(2 * batch_size, device=z.device).bool()
        sim.masked_fill_(mask, float('-inf'))
        labels = torch.cat([
            torch.arange(batch_size, 2 * batch_size),
            torch.arange(batch_size)
        ]).to(z.device)
        return F.cross_entropy(sim, labels)
MoCo（Momentum Contrast）通过动量编码器和负样本队列解决了 SimCLR 依赖大 batch size 的问题。动量编码器的参数通过指数移动平均更新：θk=mθk+(1−m)θq\theta_k = m\theta_k + (1-m)\theta_qθk​=mθk​+(1−m)θq​。


掩码预测范式
掩码预测让模型通过预测被遮挡的部分来学习数据的内在结构。在语言领域，BERT 随机遮挡 15% 的 token 并预测它们。在视觉领域，MAE（Masked Autoencoder）遮挡 75% 的图像 patch 并用轻量级解码器重建。


class MAE(nn.Module):
    def __init__(self, encoder, decoder, mask_ratio=0.75):
        super().__init__()
        self.encoder = encoder
        self.decoder = decoder
        self.mask_ratio = mask_ratio

    def random_masking(self, x, mask_ratio):
        N, L, D = x.shape
        len_keep = int(L * (1 - mask_ratio))
        noise = torch.rand(N, L, device=x.device)
        ids_shuffle = torch.argsort(noise, dim=1)
        ids_restore = torch.argsort(ids_shuffle, dim=1)
        ids_keep = ids_shuffle[:, :len_keep]
        x_masked = torch.gather(x, 1, ids_keep.unsqueeze(-1).expand(-1, -1, D))
        return x_masked, ids_restore

    def forward(self, imgs):
        patches = self.encoder.patch_embed(imgs)
        x_masked, ids_restore = self.random_masking(patches, self.mask_ratio)
        latent = self.encoder(x_masked)
        pred = self.decoder(latent, ids_restore)
        return pred
MAE 的高掩码比率（75%）使得编码器只需处理 25% 的 patch，训练效率极高。同时，重建大面积缺失迫使模型学习高层语义特征而非简单的像素插值。

无负样本方法
BYOL（Bootstrap Your Own Latent）和 DINO 证明了不需要负样本也能学到好的表示，只需两个网络——在线网络和目标网络（动量更新）——之间相互预测。


DINO 将 ViT 与自蒸馏结合：学生网络学习预测教师网络（动量更新）的输出分布。教师网络使用 centering 和 sharpening 防止模式坍塌。DINO 学到的特征具有令人惊讶的属性——注意力图自动关注物体的语义区域，无需任何分割标注。


class DINO(nn.Module):
    def __init__(self, student, teacher, center_momentum=0.9):
        super().__init__()
        self.student = student
        self.teacher = teacher
        self.center = torch.zeros(1, student.output_dim)
        self.center_momentum = center_momentum

    def forward(self, student_views, teacher_views):
        student_out = [self.student(v) for v in student_views]
        with torch.no_grad():
            teacher_out = [self.teacher(v) for v in teacher_views]
            teacher_out = [(t - self.center) for t in teacher_out]
        loss = self.dino_loss(student_out, teacher_out)
        self.update_center(teacher_out)
        return loss

  • 自监督学习从无标注数据构造监督信号，是大模型预训练的核心范式

  • 对比学习通过正负样本对比拉近/推远特征表示，SimCLR 和 MoCo 是经典方法
    • 

  • MAE 通过 75% 高掩码率高效训练视觉编码器，迫使模型学习语义特征
    • 

  • BYOL 和 DINO 证明无需负样本也能学到高质量表示
    • 

  • 自监督预训练 + 下游微调已成为计算机视觉和 NLP 的标准范式
