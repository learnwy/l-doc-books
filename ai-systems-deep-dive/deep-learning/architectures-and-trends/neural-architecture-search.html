神经架构搜索

核心概念

神经架构搜索（Neural Architecture Search, NAS）用算法自动设计神经网络结构，替代传统的人工设计过程。NAS 的核心问题可以分解为三个维度：搜索空间（定义什么样的架构是可能的）、搜索策略（如何在空间中寻找最优架构）和评估策略（如何高效评估候选架构的性能）。NAS 发现的架构（如 EfficientNet 的基础网络 B0、MobileNetV3）在效率和精度上都超越了同期的手工设计。

搜索空间设计
搜索空间定义了 NAS 可以探索的架构范围。设计良好的搜索空间既要足够大以包含高性能架构，又不能大到无法高效搜索。


单元级搜索空间：搜索一个计算单元（cell）的结构，然后将该单元按固定模式堆叠成完整网络。NASNet 定义了两种单元——Normal Cell（保持空间分辨率）和 Reduction Cell（降低分辨率），每个单元由一系列可选操作（3×3 卷积、5×5 卷积、最大池化、恒等映射等）组成。


层级搜索空间：除了搜索单元结构，还搜索网络的整体布局（每个位置使用哪种单元、通道数等）。

基于强化学习的搜索
NASNet（2018）使用 RNN 控制器生成架构描述，将生成的架构训练到收敛后，以验证集精度作为奖励信号更新控制器。这种方法概念简洁但计算成本极高（1800 GPU 天）。


class NASController(nn.Module):
    def __init__(self, num_operations, num_nodes, hidden_dim):
        super().__init__()
        self.lstm = nn.LSTMCell(hidden_dim, hidden_dim)
        self.op_classifier = nn.Linear(hidden_dim, num_operations)
        self.node_classifier = nn.Linear(hidden_dim, num_nodes)

    def sample_architecture(self):
        decisions = []
        h = torch.zeros(1, self.lstm.hidden_size)
        c = torch.zeros(1, self.lstm.hidden_size)
        for node in range(self.num_nodes):
            h, c = self.lstm(h, (h, c))
            op_logits = self.op_classifier(h)
            op = torch.multinomial(F.softmax(op_logits, dim=-1), 1)
            h, c = self.lstm(h, (h, c))
            input_logits = self.node_classifier(h)
            input_node = torch.multinomial(F.softmax(input_logits, dim=-1), 1)
            decisions.append((op.item(), input_node.item()))
        return decisions
DARTS 与可微搜索
DARTS（Differentiable Architecture Search）将离散的架构选择松弛为连续的权重参数，使得架构搜索可以通过梯度下降优化。


DARTS 将每条边上的操作表示为所有候选操作的 softmax 加权和：oˉ(x)=∑iexp⁡(αi)∑jexp⁡(αj)oi(x)\bar{o}(x) = \sum_i \frac{\exp(\alpha_i)}{\sum_j \exp(\alpha_j)} o_i(x)oˉ(x)=∑i​∑j​exp(αj​)exp(αi​)​oi​(x)。训练时交替优化网络权重 www（在训练集上）和架构参数 α\alphaα（在验证集上），搜索完成后取每条边上权重最大的操作。


class MixedOp(nn.Module):
    def __init__(self, channels, operations):
        super().__init__()
        self.ops = nn.ModuleList([build_op(op, channels) for op in operations])

    def forward(self, x, weights):
        return sum(w * op(x) for w, op in zip(weights, self.ops))

class DARTSCell(nn.Module):
    def __init__(self, channels, num_nodes, operations):
        super().__init__()
        self.num_nodes = num_nodes
        self.edges = nn.ModuleList()
        self.alphas = nn.ParameterList()
        for i in range(num_nodes):
            for j in range(i + 2):
                self.edges.append(MixedOp(channels, operations))
                self.alphas.append(nn.Parameter(torch.randn(len(operations))))
DARTS 将搜索时间从 1800 GPU 天降低到约 1 GPU 天，但存在偏向 skip connection 等轻量操作的已知问题。后续工作（P-DARTS、Fair DARTS）通过正则化和公平约束缓解了这一问题。


NAS 发现的架构分析
NAS 发现的架构与人工设计架构有一些有趣的共同点和差异：


    

  • NAS 偏好深度可分离卷积和较小的卷积核，与人工设计的趋势一致
    • 

  • NAS 发现的连接模式通常比人工设计更不规则
    • 

  • 在相同 FLOPs 约束下，NAS 架构通常精度更高
    • 



小结
    

  • NAS 将架构设计从人工经验驱动转变为算法自动搜索
    • 

  • 搜索空间设计是 NAS 成功的关键，过大的空间反而降低搜索效率
    • 

  • 强化学习 NAS 概念简洁但计算昂贵，需要数千 GPU 天
    • 

  • DARTS 通过连续化松弛将搜索时间降低到 1 GPU 天
    • 

  • 权重共享和超网络是加速 NAS 评估的关键技术
    • 

  • NAS 发现的架构在相同约束下通常优于人工设计
    •
