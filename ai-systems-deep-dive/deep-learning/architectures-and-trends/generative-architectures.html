Part I · 机器学习与深度学习 (ML & Deep Learning)深度学习 简介架构前沿 简介生成式架构

生成式架构

核心概念

生成式深度学习旨在让模型学会数据的底层分布，从而生成新的、逼真的数据样本。从变分自编码器（VAE）到生成对抗网络（GAN），从自回归模型到扩散模型，每种生成范式都基于不同的数学框架来逼近数据分布。近年来，扩散模型在图像生成质量上实现了飞跃，自回归模型则在文本生成领域确立了统治地位。理解这些架构的设计思想和数学基础，是进入生成式 AI 领域的必要前提。

变分自编码器 VAE

VAE 通过编码器将数据映射到潜在空间的分布（而非确定性向量），然后从该分布采样解码生成数据。训练目标是最大化证据下界（ELBO）：

L=Eq(z∣x)[log⁡p(x∣z)]−KL(q(z∣x)∥p(z))\mathcal{L} = \mathbb{E}_{q(z|x)}[\log p(x|z)] - \text{KL}(q(z|x) \| p(z))L=Eq(z∣x)​[logp(x∣z)]−KL(q(z∣x)∥p(z))

第一项是重建损失，驱动解码器生成与输入相似的输出；第二项是 KL 散度，将编码器输出的分布拉向标准正态先验。重参数化技巧 z=μ+σ⊙ϵz = \mu + \sigma \odot \epsilonz=μ+σ⊙ϵ（ϵ∼N(0,1)\epsilon \sim \mathcal{N}(0,1)ϵ∼N(0,1)）使得采样过程可微。

import torch
import torch.nn as nn

class VAE(nn.Module):
    def __init__(self, input_dim, hidden_dim, latent_dim):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
        )
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, input_dim), nn.Sigmoid(),
        )

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std

    def forward(self, x):
        h = self.encoder(x)
        mu, logvar = self.fc_mu(h), self.fc_logvar(h)
        z = self.reparameterize(mu, logvar)
        return self.decoder(z), mu, logvar

VQ-VAE 用向量量化替代连续潜在空间，将编码映射到一个离散的码本（codebook），在图像和语音的离散表示学习中取得了优异效果。

生成对抗网络 GAN

GAN 由生成器 GGG 和判别器 DDD 组成，通过对抗训练交替优化：生成器试图生成以假乱真的样本，判别器试图区分真假。

min⁡Gmax⁡DEx∼pdata[log⁡D(x)]+Ez∼pz[log⁡(1−D(G(z)))]\min_G \max_D \mathbb{E}_{x \sim p_{data}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]Gmin​Dmax​Ex∼pdata​​[logD(x)]+Ez∼pz​​[log(1−D(G(z)))]
class Generator(nn.Module):
    def __init__(self, latent_dim, img_channels):
        super().__init__()
        self.net = nn.Sequential(
            nn.ConvTranspose2d(latent_dim, 512, 4, 1, 0),
            nn.BatchNorm2d(512), nn.ReLU(True),
            nn.ConvTranspose2d(512, 256, 4, 2, 1),
            nn.BatchNorm2d(256), nn.ReLU(True),
            nn.ConvTranspose2d(256, 128, 4, 2, 1),
            nn.BatchNorm2d(128), nn.ReLU(True),
            nn.ConvTranspose2d(128, img_channels, 4, 2, 1),
            nn.Tanh(),
        )

    def forward(self, z):
        return self.net(z.view(z.size(0), -1, 1, 1))

GAN 的主要挑战包括训练不稳定、模式坍塌（生成样本缺乏多样性）和难以评估生成质量。StyleGAN 通过风格注入和渐进式训练生成了极高质量的人脸图像。

扩散模型

扩散模型（DDPM/Score-Based Models）通过两个过程定义：前向过程逐步向数据添加高斯噪声直至纯噪声，反向过程学习逐步去除噪声恢复数据。

前向过程：q(xt∣xt−1)=N(xt;1−βtxt−1,βtI)q(x_t|x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t}x_{t-1}, \beta_t I)q(xt​∣xt−1​)=N(xt​;1−βt​​xt−1​,βt​I)

反向过程：pθ(xt−1∣xt)=N(xt−1;μθ(xt,t),σt2I)p_\theta(x_{t-1}|x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \sigma_t^2 I)pθ​(xt−1​∣xt​)=N(xt−1​;μθ​(xt​,t),σt2​I)

class DenoisingUNet(nn.Module):
    def __init__(self, channels, time_emb_dim):
        super().__init__()
        self.time_mlp = nn.Sequential(
            nn.Linear(1, time_emb_dim),
            nn.SiLU(),
            nn.Linear(time_emb_dim, time_emb_dim),
        )
        self.down1 = DownBlock(channels, 64, time_emb_dim)
        self.down2 = DownBlock(64, 128, time_emb_dim)
        self.mid = MidBlock(128, time_emb_dim)
        self.up1 = UpBlock(128, 64, time_emb_dim)
        self.up2 = UpBlock(64, channels, time_emb_dim)

    def forward(self, x, t):
        t_emb = self.time_mlp(t.float().unsqueeze(-1))
        d1 = self.down1(x, t_emb)
        d2 = self.down2(d1, t_emb)
        m = self.mid(d2, t_emb)
        u1 = self.up1(m + d2, t_emb)
        return self.up2(u1 + d1, t_emb)

Stable Diffusion 将扩散过程放在 VAE 的潜在空间而非像素空间中执行（Latent Diffusion），大幅降低了计算成本。文本条件通过交叉注意力注入 U-Net，实现了文本到图像的高质量生成。

特性 DDPM DDIM Latent Diffusion

采样速度 慢 中 快
计算空间 像素空间 像素空间 潜在空间
条件生成 Classifier Guidance 同 Cross-Attention

上表是 2020-2022 年的经典基线口径。2023 年后骨干网络与训练目标都发生了换代，下面两节补齐现代图景。

从 U-Net 到 Diffusion Transformer

U-Net 并非扩散模型的唯一骨干。DiT（Diffusion Transformer，Peebles & Xie, arXiv:2212.09748, ICCV 2023）把 U-Net 整体替换为 Transformer：图像切 patch 后作为 token 序列处理，时间步与类别条件通过 adaLN-Zero（自适应层归一化，用条件向量回归缩放/偏移/门控系数）注入每个块。其实验结论与 LLM 的 scaling law 呼应——随 DiT-S 到 DiT-XL/2 扩大模型，FID 按幂律稳定下降，确立了「扩散模型同样受益于 Transformer 化规模化」。

此后主流文生图系统基本完成骨干换代：Stable Diffusion 3（Esser et al., arXiv:2403.03206, 2024 年 3 月）采用 MM-DiT——文本与图像 token 各自拥有独立的 QKV 投影、拼接后做联合注意力，使两种模态在深度上对称；Black Forest Labs 的 FLUX.1 系列（2024 年 8 月起发布，后续版本以官方公告为准）同为 rectified flow transformer 骨干。U-Net 时代的 SD 1.x/2.x 自此进入历史叙事——学习时应把「DiT 类骨干 + 流匹配目标」当作扩散模型的默认心智模型。

流匹配与整流流

DDPM 将去噪建模为随机过程（SDE 视角），需要大量步数积分；流匹配（Flow Matching，Lipman et al., arXiv:2210.02747, ICLR 2023）与整流流（Rectified Flow，Liu et al., arXiv:2209.03003, ICLR 2023）改为学习一个确定性速度场，用常微分方程把噪声 x0∼N(0,I)x_0 \sim \mathcal{N}(0, I)x0​∼N(0,I) 沿近似直线的路径输运到数据 x1x_1x1​：

dxtdt=vθ(xt,t),xt=(1−t) x0+t x1\frac{dx_t}{dt} = v_\theta(x_t, t), \qquad x_t = (1-t)\,x_0 + t\,x_1dtdxt​​=vθ​(xt​,t),xt​=(1−t)x0​+tx1​

训练只需在线性插值路径上做速度回归（条件流匹配目标）：

LCFM=Et, x0, x1[∥vθ(xt,t)−(x1−x0)∥2]\mathcal{L}_{\text{CFM}} = \mathbb{E}_{t,\,x_0,\,x_1}\left[\left\lVert v_\theta(x_t, t) - (x_1 - x_0)\right\rVert^2\right]LCFM​=Et,x0​,x1​​[∥vθ​(xt​,t)−(x1​−x0​)∥2]

轨迹越直，ODE 数值积分所需步数越少——这正是 SD3、FLUX 等新一代模型能在十几步内出图的理论基础。可以粗略记为：「经典扩散 = 弯曲路径的 SDE，流匹配 = 近直线路径的 ODE」，两者共享同一个神经网络去噪器的骨架，差别在于训练目标的参数化与采样动力学。

少步采样：一致性模型与蒸馏

2023 年起，研究重心从「更好的采样器」转向「让模型本身少步生成」。三条主线把文生图推理压到 1-4 步：

路线 代表工作 可核验锚点 典型步数 核心思想
一致性模型 Consistency Models Song et al., arXiv:2303.01469, ICML 2023 1-2 步 强制同一概率流轨迹上任意点都映射到同一起点
潜在一致性蒸馏 LCM / LCM-LoRA Luo et al., arXiv:2310.04378; arXiv:2311.05556 2-8 步 在潜在空间对预训练 SD 一致性蒸馏，LoRA 即插即用
对抗+分布匹配 ADD(SDXL-Turbo)、DMD2 Sauer et al., arXiv:2311.17027; Yin et al., arXiv:2405.14867, NeurIPS 2024 1-4 步 判别器对抗损失 + 分布匹配损失，单步保细节

放到同一张世代表里看步数演进：

技术世代 时间锚点 典型步数 备注
DDPM 2020 ~1000 原始反向过程逐步去噪
DDIM / Latent Diffusion 2021-2022 20-50 确定性采样 + 潜在空间压缩
DPM-Solver 类高阶求解器 2022-2023 10-25 不改模型、只改数值积分
LCM / SDXL-Turbo / FLUX schnell 等蒸馏 2023-2024 1-4 改模型本身，一步或四步出图

截至 2026 年的生产口径：交互式/实时场景普遍采用 1-4 步蒸馏模型；质量优先场景多在 20-50 步之间权衡求解器与步数（不同系统的默认值差异较大，以各自官方文档为准）。少步化的极限是把整条轨迹压成单次前向，这也使「采样成本」从固定开销变成可设计的变量。

  • VAE 通过变分推断在潜在空间上建模数据分布，训练稳定但生成质量有限
  • GAN 通过对抗训练生成高质量样本，但训练不稳定且易模式坍塌
  • 扩散模型通过迭代去噪生成极高质量的样本，是当前图像生成的最优范式
  • Latent Diffusion 在潜在空间操作大幅降低计算成本，Stable Diffusion 是其代表
  • 扩散骨干已从 U-Net 换代为 DiT/MM-DiT Transformer，训练目标从 SDE 去噪扩展到流匹配的直线 ODE（SD3、FLUX 为代表）
  • 一致性模型与对抗蒸馏把文生图推理压到 1-4 步，「步数 × 单步成本」成为新的设计变量
  • 自回归模型（GPT 系列）通过逐 token 预测实现了高质量文本生成
  • 不同生成范式各有优劣，选择取决于数据类型、质量要求和计算预算
