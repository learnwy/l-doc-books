评估与持续改进

核心概念

知识库系统的评估与持续改进是确保系统价值持续增长的核心机制。

  • 评估不是一次性的验收测试，而是嵌入系统运营的持续过程
  • 完善的评估体系覆盖知识质量、检索效果、回答质量和用户满意度四个维度
  • 通过数据驱动的方式识别改进方向和优先级

    KQ[知识质量] --> M[度量体系]
    RE[检索效果] --> M
    AQ[回答质量] --> M

四个评估维度

评估维度 核心指标 评估频率 数据来源
知识质量 覆盖率、新鲜度、准确性 每周 自动扫描
检索效果 NDCG、MAP、召回率 每日 标注数据集
回答质量 忠实度、相关性、完整性 每日 LLM-as-Judge
用户满意度 好评率、使用率、留存率 每周 用户反馈

离线评估方法

离线评估使用预先构建的评估数据集来系统性地测量知识库各组件的性能。

评估数据集

评估数据集是离线评估的基础。

  • 一组查询及其类别和难度（easy / medium / hard）
  • 对应的标准答案
  • 相关文档的等级标注（relevance 0-3）

检索效果指标

  • 检索系统对每个查询返回一个排序列表
  • 评估指标衡量该列表与标准相关文档列表的匹配程度
  • NDCG@K 考虑了文档的等级相关性和位置折扣，是最全面的检索质量指标
NDCG@K:
  DCG  = Σ (2^rel - 1) / log2(i + 2)
  IDCG = 按理想排序计算的 DCG
  NDCG = DCG / IDCG

评估执行流程

runOfflineEvaluation(dataset):
  对每个评估查询:
    检索 top-10
    计算 NDCG@10 与召回率
    若有标准答案:
      RAG 生成回答
      LLM 评忠实度与相关性
  汇总为评估报告

LLM-as-Judge

回答质量评估让一个独立的 LLM 对 RAG 系统的回答进行多维度评分。

维度 衡量内容
忠实度 答案是否忠于检索到的上下文
相关性 答案是否回答了用户的问题
完整性 答案是否覆盖了所有方面
有害性 答案是否包含不当内容

在线评估与 A/B 测试

在线评估通过真实用户流量来测量知识库系统的实际效果，能够捕获更多真实用户行为信号——用户是否点击了检索结果、是否在回答后继续追问、是否给出反馈。

A/B 测试设计要素

  • 流量分配：随机且均匀
  • 评估指标：定义清晰的 primary metric
  • 统计显著性：确保样本量足够
  • 实验周期：避免新鲜度效应

    R --> B[对照组 B 旧策略]

在线指标体系

在线指标 定义 计算方式 期望方向
点击率 (CTR) 用户点击检索结果的比例 点击数/展示数 提升
查询重写率 用户修改查询重新搜索的比例 重写次数/总查询 降低
问答好评率 用户对回答给出好评的比例 好评数/总回答 提升
平均会话长度 用户在知识库中的交互轮数 总轮数/总会话 适中
零结果率 检索不到任何结果的查询比例 空结果查询/总查询 降低

数据飞轮与持续改进

数据飞轮是知识库系统持续改进的核心机制——用户的每一次交互都产生数据，这些数据经过分析后反馈到系统的各个环节，形成正向循环。

三个飞轮

飞轮 循环路径
检索飞轮 点击/跳过 → 隐式相关性反馈 → 训练检索模型 → 检索质量提升
知识飞轮 高频未覆盖查询 → 知识缺口报告 → 驱动知识采集 → 扩大覆盖范围
质量飞轮 负面反馈/查询重写 → 识别低质量知识 → 审核改进 → 整体质量提升

知识缺口分析

GapReport 包含三类发现。

  • uncoveredTopics：未覆盖主题及查询量与紧迫度
  • lowQualityAreas：低质量区域及受影响查询数
  • emergingTopics：新兴话题及增长率

周度改进循环

runWeeklyImprovement(flywheel, 时间范围):
  gaps = 分析知识缺口
  tasks = 按优先级排序改进任务
  执行 priority > 0.7 的前 10 个:
    add / update / fix / retrain
  汇总质量提升幅度

小结

  • 评估体系覆盖知识质量、检索效果、回答质量和用户满意度四个维度
  • 离线评估通过标注数据集和 NDCG 等 IR 指标系统性测量各组件性能
  • LLM-as-Judge 方法自动评估 RAG 回答的忠实度、相关性和完整性
  • A/B 测试在真实流量中对比新旧方案，通过统计显著性确保决策可靠
  • 数据飞轮机制将用户交互转化为检索优化、知识扩展和质量提升的持续动力
  • 知识缺口分析自动识别未覆盖主题和新兴话题，驱动知识库的有机增长
