Part IV · 专项 AI (Specialized AI)具身智能 简介机器人学习与控制 简介全身控制

全身控制

核心概念

全身控制（Whole-Body Control, WBC）是高自由度机器人（人形机器人 30+ DoF、四足机器人 12-16 DoF）协调多个关节同时实现多个目标的核心技术。与单臂操作或轮式机器人不同，全身机器人面临"自由度过剩 + 强物理耦合 + 多目标冲突"的复杂控制问题——一个简单的"走一步"动作涉及十几个关节同时协调，一个目标（向前迈步）的实现可能与另一个目标（保持平衡）冲突。本节讲解全身控制的两条主要技术路线：基于优化的经典方法（MPC、QP-WBC）与基于学习的现代方法。

经典方法：MPC 与 QP-WBC
模型预测控制（MPC） 是全身控制的经典工具。它的核心思想是：在每个控制周期，基于当前状态和动力学模型，规划未来 N 步的最优动作序列，然后只执行第一步，下一周期重新规划。


MPC 的数学形式：


min⁡u0:N∑k=0N−1ℓ(xk,uk)+ℓf(xN)\min_{u_{0:N}} \sum_{k=0}^{N-1} \ell(x_k, u_k) + \ell_f(x_N)u0:N​min​k=0∑N−1​ℓ(xk​,uk​)+ℓf​(xN​)
约束：


    

  • 动力学约束：xk+1=f(xk,uk)x_{k+1} = f(x_k, u_k)xk+1​=f(xk​,uk​)
    • 

  • 物理约束：力矩上限、关节速度上限、摩擦锥
    • 

  • 接触约束：脚部不能穿透地面、必须保持非负法向力
    • 



MPC 在 MIT Cheetah 系列四足机器人上有过经典应用——通过精心建模动力学并实时求解 QP，能实现高速奔跑、跳跃、楼梯攀爬。Boston Dynamics 的 Atlas 也大量使用 MPC 方法。


MPC 的工程挑战：


    

  • 求解速度：每个控制周期（通常 1-10ms）必须求解一次优化问题。需要高效的 QP 求解器（OSQP、HPIPM 等）。
    • 

  • 模型精度：MPC 性能高度依赖动力学模型精度。建模误差会导致控制失稳。
    • 

  • 接触切换：步态中接触状态频繁切换（左脚落地→双脚→右脚落地），需要专门处理离散切换。
    • 



QP-WBC（Quadratic Programming Whole-Body Control） 是 MPC 的简化变体——只考虑当前瞬时的优化，不规划未来轨迹。它把多个任务（保持平衡、跟踪期望速度、避免关节限位）建模为带优先级的多目标 QP：


QP-WBC 的实时性比 MPC 更好（不规划未来），适合需要 1kHz+ 控制频率的场景。代价是失去了 MPC 的预瞻能力。


学习方法：端到端 RL
近年的趋势是用强化学习直接学习全身控制策略，绕过手工建模和优化。这条路线在 Tesla Optimus、ANYmal、宇树 H1 等人形/四足机器人上都有显著成功。


端到端 RL 全身控制的工程实践：


    

  • 仿真训练：用 Isaac Gym、MuJoCo Playground、Genesis 等高性能仿真平台并行训练数千个机器人，每秒模拟数百万步。
    • 

  • 简化奖励：奖励通常包括"速度跟踪 + 高度保持 + 姿态平稳 + 能耗最小"几项的加权和。复杂的奖励反而容易引入奖励黑客。
    • 

  • 域随机化：在仿真中随机化质量、摩擦、传感器噪声等参数，提升真实世界鲁棒性。
    • 

  • 教师-学生范式：先训练一个有特权信息（精确状态）的教师策略，再蒸馏出只用本体感知的学生策略，让真实部署可行。
    • 



端到端 RL 的优势是能处理 MPC 难以建模的复杂场景（不规则地形、外界扰动）；劣势是可解释性差，调试时难以定位问题。当前的工程姿态是"RL 做底层运动 + 经典方法做安全保障"——例如 ANYmal 用 RL 学习行走，但用 QP 处理紧急情况。


模仿学习全身：来自人类演示
另一条路线是从人类演示数据学习全身控制。Mobile ALOHA、Boston Dynamics 的部分工作都属于这条路线。


具体做法：


    

  • 遥操作采集：人类操作员通过 VR 或专用主臂控制机器人采集示范。
    • 

  • 大规模动捕数据：使用动作捕捉系统记录人类自然动作（走路、抓取、坐下），再迁移到机器人。
    • 

  • 跨形态迁移：人类骨骼结构与机器人关节结构不完全相同，需要专门的重定向算法（动作迁移）。
    • 



模仿学习全身的优势是能学到"自然的"人类动作（步态、姿态），相比 RL 学到的策略更接近人类直觉；劣势是受限于示范质量，且对未见过的场景泛化弱。


分层学习：高层 + 底层组合
实践中越来越多采用分层架构——高层用大模型或学习策略做语义决策，底层用 MPC 或 RL 学到的策略做关节控制：

这种分层让不同时间尺度的算法各司其职，避免一个大网络包打天下带来的工程难题。Boston Dynamics 的 Atlas、Tesla Optimus 都是这种分层架构的典型代表。


平衡控制的核心：ZMP 与捕获点
全身控制中最关键的子问题是平衡——双足机器人如何不摔倒。两个核心概念：


ZMP（零力矩点）：地面对脚部的支反力等效作用点。如果 ZMP 在脚的支撑多边形内，机器人保持平衡；如果 ZMP 越出支撑多边形，机器人开始倾倒。控制 ZMP 在期望位置是经典双足控制的核心目标。


捕获点（Capture Point）：如果机器人立即停止运动，理想脚步着地点的位置。捕获点的概念让"动态平衡"可以被量化——只要捕获点能落在合理的下一步位置，机器人就能保持动态平衡。


现代全身控制大量使用这些概念作为设计基础——MPC 中的代价函数、RL 中的奖励项都常常显式或隐式地利用 ZMP 与捕获点。


小结
全身控制是高自由度机器人（特别是人形、四足）的核心能力，面临"自由度过剩 + 物理耦合 + 多目标冲突"的复杂问题。当前的两条主要路线——经典优化方法（MPC、QP-WBC）与现代学习方法（端到端 RL、模仿学习）各有所长，且越来越融合在分层架构中。理解全身控制的核心概念（ZMP、捕获点、QP 任务层级）能让研究者更深入地阅读人形/四足机器人论文，把研究工作放到合适的技术谱系中评估。把"分层 + 学习 + 经典安全保障"作为工程默认范式，是从研究 demo 走向产品化人形机器人的关键路径。
