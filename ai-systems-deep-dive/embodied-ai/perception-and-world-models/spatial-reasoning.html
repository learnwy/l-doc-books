空间推理

核心概念

空间推理（spatial reasoning）是具身智能体在 3D 物理世界中导航、操作、交互的基础能力——理解距离、方向、相对位置、拓扑关系等空间属性。这种能力对人类是直觉，但对当前 LLM 仍是显著弱点。即使最强的多模态大模型，在简单的空间推理问题（"杯子在桌子的左边还是右边"、"从 A 到 B 多远"）上仍频繁失败。本节讲解空间推理的核心子问题（拓扑、距离、相对位置、视角）、当前研究方法、与具身智能体的应用。

拓扑推理
拓扑推理关注空间的连通性、邻接、包含等抽象关系，不依赖具体度量。它是导航和场景理解的基础——机器人需要知道"从客厅到厨房怎么走"、"杯子是否在抽屉里"。


拓扑推理的工程实现：


    

  • 拓扑地图：把场景表示为图（节点 = 区域，边 = 通路），机器人在图上规划路径。优点是抽象简洁；缺点是丢失几何细节。
    • 

  • 场景图（Scene Graph）：把场景表示为带语义的图（节点 = 物体，边 = 空间关系）。3D Scene Graph 等工作把场景图扩展到 3D。
    • 

  • 占用栅格 + 连通性分析：把空间离散为栅格，用图算法分析连通性。这是经典 SLAM 方法。
    • 



距离推理
距离推理对操作任务至关重要——机器人需要知道"末端到目标多远"才能规划合适的运动幅度。距离推理的难点在于：


    

  • 绝对距离 vs 相对距离：人类通常擅长相对距离（"A 比 B 远"），不擅长绝对距离（"3.5 米"）。机器人需要绝对距离做精确控制。
    • 

  • 从单图像估计距离：单 RGB 图像理论上无法精确估计距离（需要深度信息），但单目深度估计模型已经能做到合理估计。
    • 

  • 多视角融合：从多个相机视角融合得到精确深度，是当前最可靠的方法。
    • 



近年的视觉语言模型（VLM）在距离推理上的进展：


    

  • SpatialVLM（Google, 2024）：专门训练在距离推理任务上的 VLM，能给出"A 距 B 约 1.2 米"这类回答。
    • 

  • Spatial-Bot（清华, 2024）：把空间推理作为独立模块，与 LLM 协同。
    • 

  • 3D-VLM 类：直接在 3D 表征上训练 VLM，绕过单图像距离推理的根本困难。
    • 



相对位置推理
相对位置推理是日常语言中最常见的空间表达——"在...上面"、"在...左边"、"在...之间"。这类推理看似简单，但涉及多个微妙问题：


    

  • 参考系问题："在杯子的左边" 是从用户视角看还是杯子视角看？这种参考系歧义对机器人协作尤其关键。
    • 

  • 多对象推理："A 在 B 和 C 之间" 涉及三个物体的几何配置。
    • 

  • 不确定边界："靠近 A" 中的"靠近"边界模糊，需要根据场景动态推断。
    • 



机器人协作场景中，参考系问题尤其复杂——同一句"把杯子放到左边"，从用户视角、机器人视角、桌子视角，可能指向完全不同的位置。当前的工程实践通常默认"以用户为中心"，但需要主动确认歧义。


视角变换
视角变换是把场景从一个视角转换到另一个视角的能力。对具身智能体特别重要的是 egocentric（第一人称）与 allocentric（第三人称、地图视角）之间的转换：


    

  • Egocentric 视角：从机器人摄像头看到的世界，是直接感知输入。
    • 

  • Allocentric 视角：上帝视角、地图视角、世界坐标系下的描述，是规划与协作的常用框架。
    • 



视角变换的工程实现需要精确的相机外参（相机相对世界坐标系的位姿）和场景几何信息。SLAM 系统提供了这些基础，但语义级别的视角变换（"从用户的视角看"）仍然是研究难点。


当前 LLM 的空间推理能力
2024-2026 年的多模态大模型在空间推理上的进展与不足：


进展：


    

  • 简单的相对位置判断（"A 在 B 的左边") 准确率显著提升。
    • 

  • 多步空间推理（在场景图上的链式查询）可处理一定复杂度的问题。
    • 

  • 一些专门训练（如 SpatialVLM）让模型获得近人类水平的空间问答能力。
    • 



仍然薄弱的领域：


    

  • 精确距离估计：从图像估计具体米数仍然不准。
    • 

  • 3D 心理旋转：让模型"在脑中旋转一个物体"几乎不可能。
    • 

  • 长时空间记忆：在长对话中维持稳定的空间表征困难。
    • 

  • 物理一致性：模型可能给出违反物理的回答（"杯子在天花板上飘着")。
    •

人类与最强模型的差距说明空间推理仍是当前 AI 的明显弱项。这种弱项直接影响具身智能的能力上限——一个不能稳定做空间推理的模型很难在复杂操作任务上工作。


改善空间推理的研究方向
近年提升空间推理能力的主要研究方向：


    

  • 空间数据增强：在训练数据中加入大量空间推理任务，让模型学到空间表征。SpatialVLM 等工作就是这一思路。
    • 

  • 3D 表征学习：用 3D 数据（点云、NeRF、Gaussian Splatting）训练，让模型学到原生 3D 理解能力。
    • 

  • 几何先验注入：把已知的几何关系（变换矩阵、相对位置）作为显式约束注入模型。
    • 

  • 物理一致性损失：在训练中加入物理合理性约束，避免不合理的空间预测。
    • 

  • 认知科学启发：参考人类空间认知的研究（Tolman 的认知地图、Marr 的 3D 表征理论），设计更接近人类的空间表征。
    • 



小结
空间推理是具身智能体在物理世界中工作的基础能力，涵盖拓扑、距离、相对位置、视角变换等核心子问题。当前 LLM 在这一维度仍是显著弱点，特别是精确距离估计、3D 心理旋转、长时空间记忆等任务。理解空间推理的核心子问题、当前研究方法（SpatialVLM、3D-VLM、几何先验注入）、与典型评测基准，能让研究者评估具身系统的空间能力上限，避免对当前 AI 抱过高期望。把空间推理作为具身系统的独立评测维度（而不是混入"任务成功率"中），能更精确地指导改进方向。空间推理能力的进一步提升，是具身 AI 从演示走向产品级可靠性的关键瓶颈之一。
