世界模型

核心概念

世界模型（World Model）是具身智能体内部对环境动力学的预测能力——给定当前状态和候选动作，能预测未来状态会如何演化。这种预测能力让智能体可以"在脑中模拟"未来，而不必真正去执行每个动作。世界模型的工程化让两个长期困难的问题变得可解：样本效率（在内部模型中"想象"训练）与长时序规划（多步预测后选择最优动作）。本节讲解世界模型的两类主流路线（潜空间模型与生成式视频模型）、与它们在具身智能中的应用。

潜空间世界模型：Dreamer 系列
Dreamer（Hafner et al., 2020-2024）是最成功的潜空间世界模型范式。它的核心思想是：把高维观察（图像、点云）压缩到低维隐状态，在隐状态上学习动力学，再用规划或 RL 在隐空间训练策略。


Dreamer 的关键设计：


    

  • 变分编码：用变分自编码器把图像压缩为低维隐状态（典型 32-1024 维）。
    • 

  • 递归动力学：用 RSSM（Recurrent State-Space Model）在隐空间预测下一隐状态。RSSM 同时维护确定性和随机两部分，处理环境的部分不确定性。
    • 

  • 想象训练：在学到的世界模型中"想象" rollout，用想象数据训练 actor-critic。这是 Dreamer 数据效率高的核心原因。
    • 



Dreamer 的演进：


    

  • DreamerV1（2020）：基本框架建立，在 Atari 等 2D 任务上验证。
    • 

  • DreamerV2（2021）：用离散隐状态替代连续，性能显著提升。
    • 

  • DreamerV3（2023）：统一超参，无需任务特定调优，能解决 Minecraft 钻石获取等长时序任务。
    • 

  • DreamerV3 在机器人上：成功应用于真实机器人操作任务，证明了潜空间模型的实用性。
    • 



Dreamer 的优势是计算高效（在低维隐空间规划与训练）、可规划（隐状态支持显式 lookahead）；劣势是隐状态压缩可能丢失重要细节，对视觉细节敏感的任务不利。


DINO-WM 与新兴方向
DINO-WM（NYU, 2024）是潜空间世界模型的最新进展之一。它的创新是用 DINOv2 作为视觉编码器——直接利用大规模自监督预训练得到的视觉特征，而不是从零训练编码器。


DINO-WM 的优势：


    

  • 强视觉先验：DINOv2 在大量自然图像上预训练，特征对几何和语义都鲁棒。
    • 

  • 零样本泛化：在新场景、新物体上的泛化显著优于从零训练的编码器。
    • 

  • 零训练数据生成：只用观察序列就能训练世界模型，不需要动作标签。
    • 



DINO-WM 代表了一个重要趋势——把通用视觉基础模型作为世界模型的视觉主干，让世界模型从"任务特定"走向"通用"。


生成式视频模型作为世界模型
OpenAI Sora（2024）的发布提出了一个新视角——大规模视频生成模型本身就是一种世界模型。给定开始几帧加上语言描述，Sora 能生成连贯的视频续写——这种能力本质上是预测"如果在这种场景下做某事，会发生什么"。


类似工作：


    

  • GAIA-1（Wayve, 2023）：自动驾驶领域的生成式世界模型，能预测未来驾驶场景。
    • 

  • V-JEPA（Meta, 2024）：基于 JEPA 框架的视频预测模型，预测视频中遮蔽部分。
    • 

  • Genie（DeepMind, 2024）：从无标注视频学习可交互世界模型。
    • 



生成式视频世界模型的优势是视觉细节丰富、能捕捉复杂场景；劣势是计算量极大（视频生成本身就需要大模型）、几何一致性难以保证。当前更多被视为"概念验证"，距离实用化具身控制还有距离。


世界模型用于规划
世界模型最直接的应用是规划——在模型中模拟多种动作序列，选择期望奖励最高的执行。常见的规划方法：


采样规划（Sampling-based Planning）：随机采样大量动作序列，在模型中模拟，选择最优。MPC 中的 Cross-Entropy Method（CEM）就是这一类。优势是简单、能处理离散动作空间；劣势是采样需要大量计算。


MCTS（Monte Carlo Tree Search）：树搜索 + 模型展开，AlphaGo / MuZero 都属于这类。优势是高效搜索、能处理长时序；劣势是依赖准确的模型。


梯度规划（Gradient-based Planning）：把动作序列视为可微变量，通过模型反向传播梯度优化。优势是高效；劣势是需要可微的世界模型。


实践中规划方法的选择取决于动作空间维度、模型可微性、实时性要求。机器人操作任务常用 CEM；游戏类任务常用 MCTS；可微仿真环境用梯度规划。


与 RL 的协同
世界模型不是 RL 的替代而是补充。两者的协同方式：


    

  • Model-based RL：先学世界模型，在模型中训练 RL 策略。Dreamer 系列是典型代表。
    • 

  • Dyna 风格：交替使用真实数据和模型生成数据训练策略。
    • 

  • MPC + RL：用 RL 学到的策略作为 MPC 的初始化或终值估计。
    • 

  • 世界模型作为价值函数：用模型预测的状态分布估计长期价值。
    • 



关键挑战
世界模型在具身智能中仍面临核心挑战：


    

  • 预测漂移：模型预测多步后误差累积，远期预测变得不可靠。规避方法：限制规划步数、使用混合方法。
    • 

  • 罕见事件建模：世界模型在常见状态预测准确，但对罕见事件（突发故障、极端工况）几乎无能为力。
    • 

  • 可解释性：神经世界模型是黑盒，难以验证它学到了什么。如果世界模型有错误的物理直觉，规划结果会系统性偏差。
    • 

  • 从仿真到真实：在仿真中学到的世界模型不一定准确反映真实物理，需要域适应。
    • 



小结
世界模型是具身智能向"内部模拟未来"能力迈进的关键技术。从 Dreamer 系列的潜空间模型到 Sora 类的生成式视频模型，方法谱系不断扩展。当前最实用的工程范式是潜空间模型 + 模型基 RL（Dreamer）；生成式视频模型代表了未来潜力但仍处于早期。理解世界模型的核心思想——内部表征 + 动力学预测 + 在表征中规划——能让研究者把各种具身研究新方法放到正确的技术谱系中评估。把世界模型作为具身智能体的标配能力（而非可选附加），是从"反应式智能体"走向"规划式智能体"的关键一步。
