ASR 流水线

核心概念

自动语音识别（Automatic Speech Recognition, ASR）是将人类语音信号转换为文本的技术。ASR 流水线从原始音频出发，经过预处理、特征提取、声学建模、语言建模和解码等阶段，最终输出文本序列。近年来，端到端（End-to-End）模型逐渐替代了传统的模块化流水线，但理解完整的 ASR 处理链路仍然是优化系统性能的基础。

音频特征提取
特征提取将时域音频信号转换为适合模型处理的频域表示。梅尔频谱（Mel Spectrogram）和 MFCC 是两种最常用的特征：


import librosa
import numpy as np

audio, sr = librosa.load("speech.wav", sr=16000)

# 短时傅里叶变换（STFT）
stft = librosa.stft(audio, n_fft=512, hop_length=160, win_length=400)
magnitude = np.abs(stft)

# 梅尔频谱图
mel_spec = librosa.feature.melspectrogram(
    y=audio, sr=sr,
    n_fft=512, hop_length=160, win_length=400,
    n_mels=80, fmin=0, fmax=8000
)
log_mel = librosa.power_to_db(mel_spec)

# MFCC（梅尔频率倒谱系数）
mfcc = librosa.feature.mfcc(
    y=audio, sr=sr,
    n_mfcc=13, n_fft=512, hop_length=160
)
delta_mfcc = librosa.feature.delta(mfcc)
delta2_mfcc = librosa.feature.delta(mfcc, order=2)
features = np.concatenate([mfcc, delta_mfcc, delta2_mfcc], axis=0)

CTC 解码原理
CTC（Connectionist Temporal Classification）是端到端 ASR 的核心解码框架。它引入空白符（blank）来解决输入序列和输出序列长度不对齐的问题：


# CTC 解码示例
# 模型输出（每帧一个概率分布）：
# 帧1: h(0.8) e(0.1) blank(0.1)
# 帧2: h(0.1) e(0.7) blank(0.2)
# 帧3: e(0.1) l(0.6) blank(0.3)
# 帧4: l(0.7) o(0.2) blank(0.1)
# 帧5: l(0.2) o(0.6) blank(0.2)

# CTC 路径合并规则：
# 1. 去除所有 blank
# 2. 合并连续重复字符
# "hh-ell-lo" → "hello"
# "h-e-l-l-o" → "hello"

# 贪心解码
def ctc_greedy_decode(log_probs, blank_id=0):
    best_path = np.argmax(log_probs, axis=-1)
    decoded = []
    prev = blank_id
    for token in best_path:
        if token != blank_id and token != prev:
            decoded.append(token)
        prev = token
    return decoded

声学模型架构演进
# Conformer 编码器（Transformer + 卷积的混合架构）
# 2020 年 Google 提出，成为 ASR 声学模型的标准选择

# Conformer Block =
#   Feed Forward Module (1/2)
#   + Multi-Head Self-Attention Module
#   + Convolution Module
#   + Feed Forward Module (1/2)
#   + LayerNorm

# PyTorch 伪代码
class ConformerBlock(nn.Module):
    def __init__(self, d_model, n_heads, conv_kernel_size):
        self.ff1 = FeedForward(d_model)
        self.attn = MultiHeadAttention(d_model, n_heads)
        self.conv = ConvolutionModule(d_model, conv_kernel_size)
        self.ff2 = FeedForward(d_model)
        self.norm = nn.LayerNorm(d_model)

    def forward(self, x, mask=None):
        x = x + 0.5 * self.ff1(x)
        x = x + self.attn(x, mask=mask)
        x = x + self.conv(x)
        x = x + 0.5 * self.ff2(x)
        return self.norm(x)

小结
    

  • ASR 流水线从音频预处理、特征提取到声学建模、解码输出，形成完整的语音转文本链路
    • 

  • 梅尔频谱是现代端到端 ASR 的标准输入特征，模拟人耳感知的频率分辨率
    • 

  • CTC 通过引入 blank 符号解决输入输出长度不对齐问题，是端到端 ASR 的核心解码框架
    • 

  • Conformer（Attention + 卷积）是当前 ASR 声学模型的主流架构
    • 

  • Beam Search + 语言模型可在贪心解码基础上提升 10-20% 的准确率
    • 

  • WER（词错误率）是 ASR 系统的核心评估指标，顶尖系统在 LibriSpeech 上达到 1.5-2%
    •
