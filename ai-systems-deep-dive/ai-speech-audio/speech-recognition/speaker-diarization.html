说话人分离与识别

核心概念

说话人分离（Speaker Diarization）解决的是"谁在什么时候说话"的问题，即将一段多说话人音频按时间段标注为不同的说话人身份。它是会议转录、电话客服分析、法庭记录等场景的核心技术，通常与 ASR 系统串联使用，为识别结果附加说话人标签。

说话人分离与说话人识别（Speaker Recognition）是两个密切相关但目标不同的任务：

说话人嵌入模型
说话人分离的核心在于将语音片段映射到固定维度的向量空间，使得同一说话人的向量彼此接近，不同说话人的向量彼此远离。


d-vector 是早期的深度学习方法，使用 LSTM 网络在帧级别提取特征后取平均，得到固定维度的说话人嵌入。其训练使用分类损失（Softmax），将每个说话人作为一个类别。


x-vector 由 Kaldi 团队提出，使用 TDNN（Time-Delay Neural Network）架构，通过统计池化层（Statistics Pooling）将变长输入压缩为固定维度向量。统计池化层计算隐层输出的均值和标准差，拼接后通过全连接层得到嵌入。


ECAPA-TDNN 是当前最主流的说话人嵌入模型，引入了三个关键改进：


import torch
from speechbrain.inference.speaker import EncoderClassifier

classifier = EncoderClassifier.from_hparams(
    source="speechbrain/spkrec-ecapa-voxceleb",
    savedir="pretrained_models/spkrec-ecapa-voxceleb",
)

embedding1 = classifier.encode_batch(waveform1)
embedding2 = classifier.encode_batch(waveform2)

similarity = torch.nn.functional.cosine_similarity(
    embedding1.squeeze(), embedding2.squeeze(), dim=0
)
print(f"相似度: {similarity.item():.4f}")
    

  • SE-Res2Block：结合 Squeeze-and-Excitation 注意力和 Res2Net 多尺度特征提取

  • 多层特征聚合：将各层 SE-Res2Block 的输出拼接，捕获不同抽象层级的说话人信息

聚类与分离算法
获得说话人嵌入后，需要通过聚类算法将相似的嵌入分到同一组，每组对应一个说话人。


谱聚类（Spectral Clustering） 是传统方法的主流选择。首先计算嵌入之间的余弦相似度矩阵，通过阈值处理构建亲和矩阵，然后对其拉普拉斯矩阵进行特征分解，在特征空间中运行 K-Means。说话人数量可通过特征值间距（eigengap）自动估计。


聚合层次聚类（AHC） 采用自底向上的方式，初始每个片段为一个簇，迭代合并最相似的簇对，直到达到停止条件。AHC 不需要预设说话人数量，通过设定距离阈值即可自动确定。


VBx（贝叶斯 HMM 聚类） 是当前性能最优的传统聚类方法，将说话人分离建模为隐马尔可夫模型：每个状态对应一个说话人，观测为嵌入向量，使用变分贝叶斯推断进行参数估计。


EEND（End-to-End Neural Diarization） 直接将音频帧映射为每帧每个说话人的活动概率，使用自注意力机制隐式建模说话人关系。其核心优势是能够自然处理重叠语音（两人同时说话）。EEND-EDA（Encoder-Decoder Attractor）通过 LSTM 解码器生成说话人吸引子，解决了说话人数量未知的问题。

工程实践与评估
生产系统中的说话人分离需要处理多种工程挑战。


VAD 的关键作用：准确的语音活动检测直接影响分离质量。pyannote.audio 提供了基于 LSTM 的高性能 VAD 模型，在 DIHARD III 上达到 4.3% 的误报率。Silero VAD 则以极轻量（约 2MB）和快速推理著称，适合嵌入式场景。


处理重叠语音：真实会议场景中约 10-20% 的时间存在语音重叠。传统聚类方法假设每个时间段只有一个说话人，因此需要额外的重叠检测和分配模块。EEND 系列模型则原生支持重叠。


pyannote.audio 实战是当前最流行的开源说话人分离框架：


from pyannote.audio import Pipeline

pipeline = Pipeline.from_pretrained(
    "pyannote/speaker-diarization-3.1",
    use_auth_token="YOUR_HF_TOKEN",
)

diarization = pipeline("meeting.wav", num_speakers=4)

for turn, _, speaker in diarization.itertracks(yield_label=True):
    print(f"[{turn.start:.1f}s - {turn.end:.1f}s] {speaker}")
评估指标 DER（Diarization Error Rate） 是说话人分离的标准评价指标，由三部分组成：

DER = (FA + Miss + Confusion) / 总参考语音时长。通常使用 0.25s 的容忍窗口（collar）来减少边界判断的影响。


NeMo 的 Multi-Scale Diarization Decoder（MSDD） 通过在多个时间尺度上联合建模说话人嵌入和成对关系，在 CALLHOME 数据集上将 DER 从 11.2%（传统 ECAPA-TDNN + 聚类）降低到 5.9%。


小结
    

  • 说话人分离解决"谁在什么时候说话"，是多人语音场景的核心前处理技术
    • 

  • 说话人嵌入模型从 d-vector → x-vector → ECAPA-TDNN 演进，EER 从 3.8% 降至 0.87%
    • 

  • 聚类方法中 VBx 表现最优（DER ~8%），端到端 EEND-EDA 在支持重叠语音的同时达到 ~7% DER
    • 

  • pyannote.audio 3.1 是当前最易用的开源框架，集成了 VAD + 嵌入 + 聚类的完整流水线
    • 

  • 评估使用 DER 指标，说话人混淆是最主要的错误来源，重叠语音处理是提升的关键方向
    •
