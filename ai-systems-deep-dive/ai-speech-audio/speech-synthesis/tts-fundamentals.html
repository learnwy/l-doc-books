语音合成基础

核心概念

语音合成（Text-to-Speech, TTS）将文本转换为自然流畅的语音波形，是人机交互、有声读物、导航播报、语音助手等应用的核心技术。现代 TTS 系统通常采用两阶段架构：声学模型将文本转换为中间声学表示（梅尔频谱图），声码器将声学表示转换为最终的音频波形。

TTS 系统经历了从规则合成到统计参数再到深度学习的演进，每代技术在自然度上有质的飞跃：

文本前端处理
文本前端（Text Frontend）是 TTS 的第一步，负责将原始文本转换为声学模型可消费的语言学表示。其质量直接决定合成语音的准确性和自然度。


文本规范化（Text Normalization） 处理非标准文本：数字（"2024年" → "二零二四年"）、缩写（"Mr." → "Mister"）、特殊符号（"$100" → "一百美元"）。中文还需处理多音字消歧，如"重"在"重庆"中读 chóng，在"重量"中读 zhòng。


分词与词性标注对中文尤为重要，因为中文无天然词界：


import pypinyin
from pypinyin import Style

text = "他说的确实在理"
words = jieba.lcut(text)
pinyin = pypinyin.lazy_pinyin(text, style=Style.TONE3)

phonemes = []
for word, py in zip(words, pinyin):
    phonemes.append({
        "word": word,
        "pinyin": py,
        "initial": pypinyin.lazy_pinyin(word, style=Style.INITIALS)[0],
        "final": pypinyin.lazy_pinyin(word, style=Style.FINALS_TONE3)[0],
    })

多音字消歧（Polyphone Disambiguation） 是中文 TTS 的独特挑战。主流方法使用 BERT 等预训练模型，将多音字消歧建模为 token 级分类任务。例如输入"音乐"时，模型需判断"乐"的读音为 yuè 而非 lè。


自回归声学模型
自回归声学模型逐帧生成梅尔频谱图，通过注意力机制对齐文本和音频。


Tacotron 2 是该类模型的里程碑之作。编码器将字符/音素序列编码为隐状态，解码器每步基于前一帧输出和注意力上下文生成当前帧的梅尔频谱图。其核心组件包括：


    

  • Location-Sensitive Attention：在标准注意力基础上加入对历史注意力权重的卷积处理，帮助对齐向前推进，缓解重复或跳字问题
    • 

  • PreNet：解码器前的小型全连接网络，使用 dropout 引入随机性，防止解码器过度依赖前帧导致退化
    • 

  • PostNet：残差卷积网络，在频谱图上做后处理修正，提升频谱细节
    • 



注意力对齐问题是自回归 TTS 的核心痛点。训练时使用 teacher forcing（输入真实前帧），推理时输入模型自身预测，误差会累积导致注意力崩溃（表现为重复、跳字或提前截断）。缓解策略包括：使用 MAS（Monotonic Alignment Search）预提取对齐、Forward Attention 约束对齐单调递增、Guided Attention Loss 惩罚非对角注意力。


非自回归声学模型
非自回归（Non-Autoregressive, NAR）模型并行生成所有帧，从根本上解决了推理速度和注意力对齐问题。


FastSpeech 2 是最经典的非自回归声学模型。它需要外部对齐信息（通常从预训练的自回归模型提取），通过 Duration Predictor 控制每个音素的持续时间，通过 Length Regulator 将音素级表示扩展到帧级：

VITS（Variational Inference with adversarial learning for end-to-end TTS） 将声学模型和声码器统一为一个端到端模型，是当前开源 TTS 的标杆。它结合了三种生成模型的优势：


    

  • VAE（变分自编码器）：学习连续的潜在空间，捕获语音的多样性
    • 

  • Normalizing Flow：可逆变换提升 VAE 后验分布的表达力
    • 

  • GAN（对抗训练）：判别器监督波形生成的真实感
    • 



VITS 使用 MAS（Monotonic Alignment Search）在训练时自动学习文本与音频的对齐，无需外部对齐工具。推理时从先验分布采样，通过 flow 和解码器直接生成波形。


声码器
声码器（Vocoder）将梅尔频谱图转换为时域波形，是 TTS 系统的最后一环。


WaveNet 是深度学习声码器的开创之作，使用因果膨胀卷积逐采样点自回归生成波形。音质极佳但速度极慢（生成 1 秒音频需数分钟）。


HiFi-GAN 是当前最主流的声码器，使用全卷积生成器 + 多尺度/多周期判别器的 GAN 架构。生成器通过多级转置卷积进行上采样，Multi-Receptive Field Fusion 模块融合不同感受野的特征：


import torch
from torch import nn

class ResBlock(nn.Module):
    def __init__(self, channels: int, kernel_size: int, dilations: list[int]):
        super().__init__()
        self.convs = nn.ModuleList([
            nn.Sequential(
                nn.LeakyReLU(0.1),
                nn.Conv1d(channels, channels, kernel_size,
                         dilation=d, padding=(kernel_size * d - d) // 2),
            )
            for d in dilations
        ])

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        for conv in self.convs:
            x = x + conv(x)
        return x

Vocos 是新一代声码器的代表，不在时域逐点生成波形，而是预测 STFT 的幅度和相位，通过逆 STFT 恢复波形。这使得生成速度比 HiFi-GAN 还快 2 倍，同时保持相当的音质。


小结
    

  • 现代 TTS 采用文本前端 → 声学模型 → 声码器的三阶段架构，端到端模型（如 VITS）开始统一后两者
    • 

  • 文本前端的分词、多音字消歧和韵律预测直接影响合成质量，是中文 TTS 的独特挑战
    • 

  • 自回归模型（Tacotron 2）音质好但有注意力对齐问题，非自回归模型（FastSpeech 2）推理快但需外部对齐
    • 

  • VITS 通过 VAE + Flow + GAN 实现了端到端高音质合成，是当前开源 TTS 的标杆
    • 

  • 声码器从 WaveNet 到 HiFi-GAN 到 Vocos，实时系数从 0.001× 提升到 100×，实现了质量和速度的兼得
    •
