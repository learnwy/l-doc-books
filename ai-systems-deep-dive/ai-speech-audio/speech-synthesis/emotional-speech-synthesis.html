情感语音合成

核心概念

情感语音合成（Emotional Speech Synthesis）是在标准 TTS 基础上增加情感维度的控制能力，使合成语音不仅内容正确、音色自然，还能表达喜悦、悲伤、愤怒、恐惧、惊讶等情感状态。它是对话式 AI、有声读物、游戏 NPC、虚拟陪伴等场景中提升用户体验的关键技术。

情感表示与建模方法
情感的计算表示有两大体系——离散类别和连续维度，各有适用场景。


离散情感类别将情感分为 Ekman 六基本情感（高兴、悲伤、愤怒、恐惧、惊讶、厌恶）或更细的分类。优势是直观易用（用户直接选择"高兴"），劣势是无法表示混合情感（如"苦笑"是悲伤+高兴的混合）。


连续情感维度（VAD 模型） 用三个连续维度描述情感状态：


    

  • Valence（效价）：正面 ↔ 负面（高兴 vs 悲伤）
    • 

  • Arousal（唤醒度）：兴奋 ↔ 平静（愤怒 vs 无聊）
    • 

  • Dominance（支配度）：支配 ↔ 顺从（命令 vs 请求）
    • 



import torch
import torch.nn as nn

class EmotionEncoder(nn.Module):
    def __init__(self, input_dim: int, emotion_dim: int, num_emotions: int):
        super().__init__()
        self.discrete_embedding = nn.Embedding(num_emotions, emotion_dim)
        self.continuous_mlp = nn.Sequential(
            nn.Linear(3, 128),
            nn.ReLU(),
            nn.Linear(128, emotion_dim),
        )
        self.gate = nn.Linear(emotion_dim * 2, emotion_dim)

    def forward(
        self,
        emotion_id: torch.Tensor | None = None,
        vad: torch.Tensor | None = None,
    ) -> torch.Tensor:
        if emotion_id is not None and vad is not None:
            disc = self.discrete_embedding(emotion_id)
            cont = self.continuous_mlp(vad)
            combined = torch.cat([disc, cont], dim=-1)
            return torch.sigmoid(self.gate(combined)) * disc + \
                   (1 - torch.sigmoid(self.gate(combined))) * cont
        elif emotion_id is not None:
            return self.discrete_embedding(emotion_id)
        else:
            return self.continuous_mlp(vad)

情感可控 TTS 架构
将情感信息集成到 TTS 模型中有多种架构设计。


条件 VITS 在 VITS 的先验编码器中注入情感嵌入，使其学习情感相关的潜在分布。通过改变情感条件，同一文本可以生成不同情感的语音：


EmotiVoice（网易） 是开源的中英文情感 TTS 系统。它在 BERT 编码器后注入情感嵌入，通过 Prompt 风格的控制（如"开心地说"、"生气地说"）来指定情感。支持 2000+ 说话人和多种情感组合。


StyleTTS 2 将情感和风格建模统一为风格向量空间，使用扩散模型生成风格向量。它能在无情感标注的数据上通过对比学习自动发现情感维度，是当前情感 TTS 音质最高的系统之一。


情感强度控制是实用功能——用户不仅选择情感类别，还能调节情感的强度（如从"微笑"到"大笑"的渐变）。常见实现方式是在情感嵌入向量上做线性插值：

情感语音数据匮乏是该领域的核心瓶颈。解决方案包括：数据增强（改变语速/音调模拟情感变化）、跨语言迁移（用英文情感数据增强中文模型）、以及使用 GPT-4o 等大模型辅助生成情感标注。


评估维度需覆盖三个方面：


    

  • 自然度（MOS）：合成语音的整体自然程度，5 分制评价
    • 

  • 情感准确度：听者能否正确识别目标情感，通常用困惑矩阵评估
    • 

  • 情感强度：表达的情感是否足够强烈，通常用 1-5 分强度量表
    • 



客观评估可辅助主观评估：使用预训练的语音情感识别（SER）模型对合成语音进行自动情感分类，分类准确率可作为代理指标。


小结
    

  • 情感语音合成在标准 TTS 上增加情感维度控制，核心挑战是如何表示和注入情感信息
    • 

  • 情感表示有三种方法：离散类别（直观但不支持混合）、连续 VAD（细粒度但标注难）、参考音频（最灵活但不可解释）
    • 

  • 条件 VITS 和 StyleTTS 2 是当前主流架构，EmotiVoice 是中文场景最易用的开源方案
    • 

  • 情感数据匮乏是核心瓶颈，中文情感语音数据尤为稀缺，需要数据增强和跨语言迁移
    • 

  • 评估需综合自然度、情感准确度和情感强度，主观评价与 SER 自动评估结合使用
    •
