音频质量评估

核心概念

音频质量评估（Audio Quality Evaluation）是衡量语音和音频处理系统输出质量的系统化方法。它贯穿于 ASR、TTS、语音增强、音源分离等所有音频 AI 系统的开发和优化过程。评估方法分为主观评估（人类听感判断）和客观评估（算法自动计算），两者各有优势，实际工程中需要结合使用。

主观评估方法
主观评估是音频质量的金标准，因为最终用户是人。


MOS（Mean Opinion Score） 是最广泛使用的主观评估方法。听者对音频质量在 1-5 分之间打分，取所有评分的均值。ITU-T P.800 标准定义了 MOS 测试的详细流程：

CMOS（Comparative MOS） 用于比较两个系统的输出。听者听两段音频后在 -3 到 +3 之间评分（-3: 系统 B 远好于 A，+3: 系统 A 远好于 B）。CMOS 比绝对 MOS 更敏感，能检测出 0.1-0.2 分的微小差异。


MUSHRA（Multi-Stimulus with Hidden Reference and Anchor） 同时展示多个系统的输出（含隐藏的参考信号和低锚点），听者在 0-100 分之间评价每个系统。适合比较多个系统的相对质量。


import numpy as np
from scipy import stats

def analyze_mos(scores: dict[str, list[float]]) -> dict:
    results = {}
    for system, system_scores in scores.items():
        n = len(system_scores)
        mean = np.mean(system_scores)
        ci95 = stats.t.ppf(0.975, n - 1) * np.std(system_scores) / np.sqrt(n)
        results[system] = {
            "mean_mos": round(mean, 2),
            "ci_95": round(ci95, 2),
            "range": f"{round(mean - ci95, 2)} - {round(mean + ci95, 2)}",
            "n_ratings": n,
        }
    return results
MOS 测试的最佳实践：每个系统至少收集 20-30 个评分（不同听者）；使用耳机而非扬声器；评分前播放校准样本；随机化播放顺序；排除注意力不集中的评分者（通过隐藏参考检测）。


有参考客观指标
有参考（Intrusive）指标需要干净的参考信号，通过比较参考和处理后信号的差异来量化质量。


PESQ（Perceptual Evaluation of Speech Quality） 是 ITU-T P.862 标准，模拟人耳的感知模型计算语音质量分数（-0.5 到 4.5）。它对频谱失真、时间偏移和噪声残留敏感，是语音增强领域最常用的客观指标：


from pesq import pesq
import librosa

ref, sr = librosa.load("clean.wav", sr=16000)
deg, _ = librosa.load("enhanced.wav", sr=16000)

min_len = min(len(ref), len(deg))
ref, deg = ref[:min_len], deg[:min_len]

score_wb = pesq(sr, ref, deg, "wb")
score_nb = pesq(sr, ref, deg, "nb")

print(f"PESQ (宽带): {score_wb:.3f}")
print(f"PESQ (窄带): {score_nb:.3f}")

POLQA（Perceptual Objective Listening Quality Analysis） 是 PESQ 的下一代标准（ITU-T P.863），支持超宽带和全带音频评估，对现代通信系统（VoIP、HD Voice）的评估更准确。


无参考客观指标
无参考（Non-Intrusive）指标不需要干净参考信号，通过训练的 DNN 模型直接从处理后的音频预测质量分数。


DNSMOS（Deep Noise Suppression MOS） 是微软为 DNS Challenge 开发的自动 MOS 预测模型。输入含噪/增强后的音频，输出三个维度的 MOS 预测：整体质量（OVRL）、语音质量（SIG）和背景质量（BAK）。


import onnxruntime as ort
import librosa
import numpy as np

class DNSMOS:
    def __init__(self, model_path: str):
        self.session = ort.InferenceSession(model_path)

    def predict(self, audio_path: str) -> dict:
        audio, sr = librosa.load(audio_path, sr=16000)
        if len(audio) < sr:
            audio = np.pad(audio, (0, sr - len(audio)))

        input_features = self._extract_features(audio, sr)
        scores = self.session.run(None, {"input": input_features})

        return {
            "ovrl_mos": float(scores[0][0][0]),
            "sig_mos": float(scores[0][0][1]),
            "bak_mos": float(scores[0][0][2]),
        }

    def _extract_features(self, audio: np.ndarray, sr: int) -> np.ndarray:
        mel = librosa.feature.melspectrogram(y=audio, sr=sr, n_mels=120)
        log_mel = librosa.power_to_db(mel).T
        return log_mel[np.newaxis, :, :].astype(np.float32)

TTS 专项评估
TTS 系统的评估除了音质外，还需要关注内容准确性、说话人相似度和韵律自然度。


内容准确性通过 ASR 系统对合成语音进行转录，计算转录文本与原始文本之间的 CER（Character Error Rate）或 WER。高质量 TTS 系统的 CER 应低于 2%。


说话人相似度（Speaker Similarity） 评估语音克隆系统的音色保真度。使用预训练的说话人验证模型（如 ECAPA-TDNN）分别提取参考语音和合成语音的嵌入，计算余弦相似度。


韵律评估关注合成语音的节奏、重音和语调。客观指标包括 F0 相关系数、时长误差和能量对比。主观评估通常使用 CMOS 比较两个系统的韵律自然度。

小结
    

  • 音频质量评估分为主观（MOS、CMOS、MUSHRA）和客观（有参考 PESQ/SI-SDR、无参考 DNSMOS/UTMOS）两大类
    • 

  • MOS 是金标准但成本高，实际开发中用客观指标快速迭代，关键节点做主观评估
    • 

  • PESQ 是语音增强领域最常用的有参考指标，与主观 MOS 的相关性达到 r=0.93
    • 

  • DNSMOS 和 UTMOS 是最强的无参考 MOS 预测模型，分别针对增强和 TTS 场景优化
    • 

  • TTS 评估需要多维度覆盖：音质（MOS）+ 准确性（CER）+ 说话人相似度（cos_sim）+ 韵律自然度（CMOS）
    •
