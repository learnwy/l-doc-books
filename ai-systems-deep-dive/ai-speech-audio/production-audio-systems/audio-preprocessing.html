音频预处理与增强

核心概念

音频预处理（Audio Preprocessing）和语音增强（Speech Enhancement）是所有语音和音频 AI 系统的第一道关卡。真实环境中的音频通常包含背景噪声、混响、信道失真和多说话人干扰，如果不进行有效的前处理，后续的 ASR、TTS、说话人识别等系统的性能会大幅下降。预处理的目标是从含噪信号中恢复干净的目标语音，同时尽量保留语音的自然度和可懂度。

传统信号处理方法
传统方法基于统计信号处理理论，不需要训练数据，计算开销小，适合嵌入式和实时场景。


谱减法（Spectral Subtraction） 是最经典的降噪方法。假设噪声是平稳的，在无语音帧（由 VAD 检测）估计噪声功率谱，然后从含噪信号的功率谱中减去噪声估计，保留语音成分：


import numpy as np
import librosa

def spectral_subtraction(noisy: np.ndarray, sr: int, n_fft: int = 512):
    stft = librosa.stft(noisy, n_fft=n_fft)
    magnitude = np.abs(stft)
    phase = np.angle(stft)

    noise_frames = magnitude[:, :10]
    noise_estimate = np.mean(noise_frames, axis=1, keepdims=True)

    clean_magnitude = np.maximum(magnitude - noise_estimate * 1.5, 0.01 * magnitude)

    clean_stft = clean_magnitude * np.exp(1j * phase)
    clean_signal = librosa.istft(clean_stft)
    return clean_signal
维纳滤波（Wiener Filter） 从最小均方误差（MMSE）的角度设计最优滤波器。它估计信噪比（SNR），在高 SNR 帧保留更多信号，在低 SNR 帧更激进地压制噪声。


波束成形（Beamforming） 利用多麦克风阵列的空间信息，通过延时-求和或 MVDR（最小方差无畸变响应）等算法增强目标方向的信号。智能音箱（Amazon Echo、Apple HomePod）的远场语音识别核心依赖此技术。

深度学习降噪
深度学习方法将降噪建模为有监督回归问题——输入含噪特征，输出干净语音特征或掩码。


频域掩码估计是最主流的方法。模型预测每个时频点的掩码值（0-1），将掩码与含噪频谱相乘得到增强频谱。掩码类型包括理想比值掩码（IRM）、理想幅度掩码（IAM）和复数理想比值掩码（cIRM）。


DCCRN（Deep Complex CRN） 使用复数卷积直接处理复数频谱（同时建模幅度和相位），避免了传统方法中相位重建不准确的问题。在 DNS Challenge 2020 中取得优异成绩。


FullSubNet 结合全频带和子频带两个网络：全频带 LSTM 捕获全局频谱模式，子频带 LSTM 对每个频率组独立建模局部细节，两者的输出融合后预测最终掩码。


import torch
from torch import nn

class ConvTasNet(nn.Module):
    def __init__(self, n_sources: int = 2):
        super().__init__()
        self.encoder = nn.Conv1d(1, 256, kernel_size=20, stride=10)
        self.separator = nn.LSTM(256, 512, num_layers=4, bidirectional=True)
        self.mask_net = nn.Sequential(
            nn.Linear(1024, 256 * n_sources),
            nn.Sigmoid(),
        )
        self.decoder = nn.ConvTranspose1d(256, 1, kernel_size=20, stride=10)
        self.n_sources = n_sources

    def forward(self, mixture: torch.Tensor) -> torch.Tensor:
        encoded = self.encoder(mixture)
        B, N, T = encoded.shape
        lstm_out, _ = self.separator(encoded.permute(2, 0, 1))
        masks = self.mask_net(lstm_out).permute(1, 2, 0)
        masks = masks.view(B, self.n_sources, N, T)
        separated = encoded.unsqueeze(1) * masks
        return torch.stack([self.decoder(separated[:, i]) for i in range(self.n_sources)], dim=1)

去混响与回声消除
混响和回声是通信和录音场景中的重要退化因素。


加权预测误差（WPE） 是经典的去混响算法。它基于线性预测模型，利用当前帧之前的多帧信号预测并消除晚期混响成分。WPE 对早期反射保留较好，不会过度处理导致语音失真。


声学回声消除（AEC） 在全双工通话场景中尤为重要——麦克风会采集到扬声器播放的远端信号（回声），需要从近端信号中消除。自适应滤波器（NLMS、RLS）估计扬声器到麦克风的声学路径，生成回声估计并减去：

RNNoise（Mozilla） 是一个极轻量的实时降噪库（模型仅约 85KB），使用 GRU 网络在频域预测 22 个子带的增益值。它被集成到 WebRTC、Discord、OBS 等多个实时通信软件中。

重采样算法的质量差异很大。线性插值会引入混叠，应使用 sinc 插值（librosa.resample）或 polyphase 滤波器（torchaudio.transforms.Resample）。下采样前必须先低通滤波以防止混叠。


响度归一化确保不同来源的音频有一致的音量水平。ITU-R BS.1770 标准定义了响度度量单位 LUFS（Loudness Units Full Scale），音频流媒体平台通常归一化到 -14 到 -16 LUFS。


小结
    

  • 音频预处理是所有语音 AI 系统的基础，处理加性噪声、混响、回声和信道失真四类退化
    • 

  • 传统方法（谱减法、维纳滤波、波束成形）计算量小，适合嵌入式和实时场景
    • 

  • 深度学习方法（DCCRN、FullSubNet）通过频域掩码估计实现 15dB+ 的 SNR 改善，但需要 GPU 推理
    • 

  • RNNoise 以 85KB 模型大小实现了实用级实时降噪，被广泛集成到通信软件中
    • 

  • 工程实践中采样率选择（16kHz for ASR, 22kHz for TTS）和响度归一化（LUFS）不可忽视
