音频表示学习

核心概念

音频表示学习（Audio Representation Learning）是将原始音频波形转换为适合下游任务使用的特征表示的过程。从手工设计的声学特征（MFCC、Mel 频谱图）到自监督预训练模型（wav2vec 2.0、HuBERT），表示学习的进步是推动语音和音频 AI 发展的核心动力。好的音频表示应该同时捕获低层声学信息（音色、音质）和高层语义信息（语言内容、情感）。

频域特征工程
频域特征是音频处理的基础，理解其设计原理对选择和调优模型至关重要。


短时傅里叶变换（STFT） 是所有频域分析的基础。将音频信号按固定大小的窗口分帧，对每帧做 FFT 得到复数频谱。关键参数的选择直接影响时频分辨率：


import librosa
import numpy as np

y, sr = librosa.load("audio.wav", sr=16000)

stft = librosa.stft(y, n_fft=512, hop_length=160, win_length=400)
magnitude = np.abs(stft)
phase = np.angle(stft)
power_spectrum = magnitude ** 2

mel_filterbank = librosa.filters.mel(sr=sr, n_fft=512, n_mels=80, fmin=0, fmax=8000)
mel_spec = mel_filterbank @ power_spectrum
log_mel = librosa.power_to_db(mel_spec, ref=np.max)

mfcc = librosa.feature.mfcc(S=librosa.power_to_db(mel_spec), n_mfcc=13)
delta_mfcc = librosa.feature.delta(mfcc)
delta2_mfcc = librosa.feature.delta(mfcc, order=2)
features = np.concatenate([mfcc, delta_mfcc, delta2_mfcc], axis=0)
Mel 频率尺度模拟了人耳的听觉感知——低频段分辨率高、高频段分辨率低。这与人类对语音中不同频率成分的敏感程度一致。Mel 滤波器组将线性频率轴映射到 Mel 尺度：

MFCC 的局限性：虽然 MFCC 在传统机器学习中广泛使用，但 DCT 变换会丢失帧内的频率结构信息。现代深度学习模型更倾向直接使用 Log-Mel 频谱图或原始波形作为输入。


自监督预训练模型
自监督学习（Self-Supervised Learning, SSL）通过在无标注音频数据上设计预训练任务，学习通用的音频表示。这些表示可以通过少量标注数据微调到各种下游任务。


wav2vec 2.0 是该领域的里程碑模型。训练分两个阶段：首先用 CNN 特征提取器将原始波形转换为帧级表示，然后随机遮蔽部分帧（约 50%），通过 Transformer 编码器预测被遮蔽位置的量化表示。量化使用 Gumbel-Softmax 从码本中选择离散向量。


HuBERT 改进了预训练目标——使用离线聚类（K-Means）将音频帧聚类为伪标签，然后训练模型预测被遮蔽帧的伪标签。第一轮使用 MFCC 特征聚类，后续轮使用前一轮模型的中间层特征重新聚类，迭代提升伪标签质量。


WavLM 在 HuBERT 基础上增加了说话人相关任务（去噪、分离），使模型同时捕获内容和说话人信息。在 SUPERB 基准的全部任务上取得 SOTA。

多模态与跨模态表示
音频表示正在从单模态向多模态融合方向发展，与文本、图像等模态建立统一的表示空间。


CLAP（Contrastive Language-Audio Pre-training） 借鉴 CLIP 的思路，将音频和文本映射到共享的嵌入空间。通过对比学习使匹配的音频-文本对嵌入接近，不匹配的远离。训练后可以用自然语言文本检索音频（"一个人在弹钢琴"），或用音频检索描述文本。


import laion_clap

model = laion_clap.CLAP_Module(enable_fusion=False)
model.load_ckpt()

text_embed = model.get_text_embedding(
    ["a dog barking", "rain falling on a roof", "piano music"],
    use_tensor=True,
)

audio_embed = model.get_audio_embedding_from_filelist(
    ["dog.wav", "rain.wav", "piano.wav"],
    use_tensor=True,
)

similarity = audio_embed @ text_embed.T
print(similarity)
BEATs（Audio Pre-Training with Acoustic Tokenizers） 使用音频 Tokenizer + 知识蒸馏的训练方式，在 AudioSet 上不使用任何标注数据即达到了监督方法的性能（mAP 98.1%）。


Whisper 编码器作为通用特征提取器是一个实用技巧。虽然 Whisper 是为 ASR 训练的，但其编码器中间层的特征在说话人验证、情感识别、语言识别等任务上也表现优异，因为 68 万小时的多语言训练使其学会了丰富的声学表示。

小结
    

  • 音频表示从手工特征（MFCC、Mel 频谱图）发展到自监督学习（wav2vec 2.0、HuBERT、WavLM），表达能力大幅提升
    • 

  • Mel 频谱图仍是 TTS 和传统 ASR 的核心中间表示，理解 STFT 参数（n_fft、hop_length）的选择对工程实践很重要
    • 

  • 自监督模型在低资源场景下优势显著：仅 10 分钟标注数据即可达到 4-5% WER
    • 

  • WavLM 通过增加说话人相关任务成为 SUPERB 基准全能冠军
    • 

  • 多模态表示（CLAP、BEATs）开启了音频-文本联合理解的新范式，支持零样本分类和自然语言检索
    •
