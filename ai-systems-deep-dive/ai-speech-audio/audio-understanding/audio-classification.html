音频分类与事件检测

核心概念

音频分类（Audio Classification）和声音事件检测（Sound Event Detection, SED）是音频理解的两大基础任务。音频分类判断整段音频所属的类别（如"音乐"、"语音"、"噪声"），而声音事件检测进一步定位每个声音事件发生的时间区间（如"0.5-2.3s 有狗叫声"）。这两项技术在智能安防、自动驾驶、医疗监测、智能家居等领域有广泛应用。

这三个任务从粗到细，覆盖了不同的音频理解需求：

模型架构演进
音频分类模型从 CNN 到 Transformer，再到预训练大模型，性能持续提升。


CNN 架构时代：VGGish（Google）将音频问题转化为图像分类——将 Log-Mel 频谱图视为单通道"图像"，使用 VGG 网络提取特征。这种思路简单有效，但忽略了音频的时序特性。


PANNs（Pretrained Audio Neural Networks） 使用 CNN14 架构在 AudioSet（200 万条 10 秒音频，527 类）上预训练，是音频分类领域的长期基线。其核心创新是大规模预训练 + 迁移学习。


AST（Audio Spectrogram Transformer） 将 Vision Transformer 直接应用于音频。将 Mel 频谱图分割为 16×16 的 patch，使用 ImageNet 预训练的 ViT 进行微调。在 AudioSet 上达到 0.459 mAP，超过所有 CNN 方法。


import torch
from transformers import ASTModel, AutoFeatureExtractor

feature_extractor = AutoFeatureExtractor.from_pretrained(
    "MIT/ast-finetuned-audioset-10-10-0.4593"
)
model = ASTModel.from_pretrained(
    "MIT/ast-finetuned-audioset-10-10-0.4593"
)

inputs = feature_extractor(
    raw_speech=waveform,
    sampling_rate=16000,
    return_tensors="pt",
)

with torch.no_grad():
    outputs = model(**inputs)
    embeddings = outputs.last_hidden_state.mean(dim=1)
BEATs 通过自监督预训练 + 知识蒸馏在 AudioSet 上达到 98.1% mAP，是当前 SOTA。其训练不需要 AudioSet 的标签，仅使用音频数据进行自监督学习。

声音事件检测方法
SED 需要逐帧预测声音事件的存在，比 Clip 级分类更具挑战性。


弱监督 SED 是该领域的核心问题——训练数据只有 Clip 级标签（整段音频包含"狗叫"），没有精确的时间标注。需要模型自己学习定位事件的时间边界。


池化策略是弱监督 SED 的关键设计。模型先在帧级产生预测，再通过池化聚合为 Clip 级预测进行训练：

CRNN（Convolutional Recurrent Neural Network） 是 SED 的经典架构：CNN 提取频谱图的局部特征，RNN（通常是 BiGRU）建模时间依赖性，最后逐帧输出事件概率。


半监督 SED（Mean Teacher） 是 DCASE Challenge 的主流方案。使用少量强标注数据和大量弱标注/无标注数据。Teacher 模型是 Student 模型的指数移动平均（EMA），对无标注数据生成伪标签监督 Student 训练。一致性正则化要求 Student 和 Teacher 对同一音频的不同增强版本给出相似预测。


数据增强与工程实践
音频分类和 SED 的工程实践中，数据增强和后处理对最终性能至关重要。


频谱增强（SpecAugment） 在频谱图上随机遮蔽连续的时间帧和频率通道，类似图像中的随机擦除。它是 ASR 和音频分类中最基础也最有效的增强方法：


import torchaudio.transforms as T

spec_augment = torch.nn.Sequential(
    T.FrequencyMasking(freq_mask_param=24),
    T.FrequencyMasking(freq_mask_param=24),
    T.TimeMasking(time_mask_param=100),
    T.TimeMasking(time_mask_param=100),
)

augmented_mel = spec_augment(mel_spectrogram)
Mixup / CutMix 将两条音频及其标签按比例混合，生成新的训练样本。在多标签分类场景下特别有效，因为混合后的音频自然包含多个声音事件。

DCASE Challenge 是音频和声学场景分析领域最权威的竞赛系列，每年设置不同的任务：声学场景分类、声音事件检测、音频字幕生成等。竞赛推动了该领域的快速发展。


部署优化方面，音频分类模型通常较小（10-100M 参数），可以在边缘设备上实时运行。关键优化包括：8-bit 量化（精度损失 <1%）、ONNX Runtime 推理、批处理（多通道音频并行处理）。


小结
    

  • 音频分类从 VGGish 的频谱图当图片分类，到 AST 的 ViT 迁移，再到 BEATs 的自监督预训练，mAP 从 0.31 提升到 0.98
    • 

  • 声音事件检测的核心挑战是弱监督——只有 Clip 级标签需要学习帧级定位，注意力池化是关键技术
    • 

  • 半监督 Mean Teacher 框架充分利用了少量强标注 + 大量弱标注数据，是 DCASE 竞赛的主流方案
    • 

  • SpecAugment 和 Mixup 是最有效的数据增强方法，后处理（中值滤波、自适应阈值）可带来 2-5% 额外提升
    • 

  • 音频分类模型参数量小、推理快，适合边缘部署，是智能安防和环境监测的实用技术
    •
