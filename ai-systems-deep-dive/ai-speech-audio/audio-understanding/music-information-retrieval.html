音乐信息检索

核心概念

音乐信息检索（Music Information Retrieval, MIR）是一个跨学科领域，利用信号处理、机器学习和音乐理论从音频中自动提取、分析和组织音乐信息。它覆盖了从底层音频特征（音高、节拍）到高层语义理解（流派、情绪、相似性）的全栈分析，是音乐推荐、自动DJ、音乐生成、版权检测等应用的技术基础。

音频特征与基频检测
音乐分析的基础是从音频中提取准确的低层特征，其中基频（F0）检测和节拍追踪最为关键。


基频检测（Pitch Estimation） 确定音频每帧的基本频率，是旋律提取和音乐转录的基础。传统方法包括自相关函数（ACF）和 YIN 算法，它们利用信号的周期性来估计基频。


CREPE 是当前最准确的单音基频检测器，使用深度 CNN 直接从原始波形学习基频映射。在 6 层卷积后通过全连接层输出 360 个音高类别（对应 C1-B7，每个半音 20 cent 分辨率）：


import crepe
import librosa

audio, sr = librosa.load("music.wav", sr=16000)

time, frequency, confidence, activation = crepe.predict(
    audio, sr,
    viterbi=True,
    step_size=10,
)

voiced = confidence > 0.5
melody = frequency[voiced]
色度特征（Chroma Feature） 将频谱能量投影到 12 个音级（C, C#, D, ..., B），忽略八度信息。这使得相同和弦在不同八度上有相似的表示，非常适合和弦识别和翻唱检测。

音源分离
音源分离（Music Source Separation）将混音音频分解为独立的乐器音轨（人声、鼓、贝斯、其他），是 MIR 中最具工程价值的任务之一。


Open-Unmix 是经典的基于频谱图的方法。使用双向 LSTM 预测每个音源的频谱掩码（Mask），将掩码与混音频谱图相乘得到分离的音源频谱图，再通过逆 STFT 恢复波形。


Demucs（Meta） 是当前最先进的开源音源分离模型。从 v1 的时域 U-Net，到 v3 的混合（时域+频域）架构，再到 v4（Hybrid Transformer Demucs）引入 Transformer 注意力：


import torchaudio
from demucs.pretrained import get_model
from demucs.apply import apply_model

model = get_model("htdemucs")
wav, sr = torchaudio.load("song.mp3")
wav = wav.unsqueeze(0)

sources = apply_model(model, wav, device="cuda")

vocals = sources[:, 0]
drums = sources[:, 1]
bass = sources[:, 2]
other = sources[:, 3]

torchaudio.save("vocals.wav", vocals.squeeze(0), sr)

音乐理解与检索
高层音乐理解任务需要模型捕获音乐的语义和情感信息。


音乐流派分类是最经典的 MIR 任务。传统方法提取 MFCC + Chroma + 节奏特征，使用 SVM 或随机森林分类。现代方法使用预训练音频模型（如 MERT、MusicFM）的特征进行微调。


音乐情绪识别将音乐映射到情绪空间。Russell 的 VA 模型使用 Valence（正面/负面）和 Arousal（兴奋/平静）两个维度描述情绪。


MERT（Music undERstanding model with large-scale self-supervised Training） 是当前音乐理解领域最强的预训练模型。它在 HuBERT 架构基础上使用音乐特定的预训练策略——除了标准的帧级预测外，还使用 CQT（恒Q变换）作为教师信号，使模型学习音乐的谐波结构。


音乐指纹识别（Audio Fingerprinting） 是 Shazam 等听歌识曲应用的核心技术。经典方法（Chromaprint）基于频谱峰值的星座图（Constellation Map）构建指纹，通过哈希匹配实现毫秒级检索。现代方法（NeuralFP）使用对比学习训练的嵌入模型，支持在噪声、混响等退化条件下的鲁棒匹配。

翻唱检测（Cover Song Detection） 识别同一首歌的不同演绎版本。核心挑战是翻唱版本可能改变调性、速度、编曲和唱法。使用 CQT Chroma 特征 + 动态时间规整（DTW）或学习的嵌入空间进行匹配。


小结
    

  • MIR 覆盖从底层特征（F0、节拍）到高层语义（流派、情绪）的全栈音乐分析
    • 

  • CREPE 是最准确的单音基频检测器，Chroma 特征是和弦识别和翻唱检测的核心表示
    • 

  • HTDemucs v4 通过混合时频域 + Transformer 架构成为音源分离的 SOTA（人声 SDR 8.1dB）
    • 

  • MERT 是音乐理解的专用预训练模型，通过 CQT 教师信号学习谐波结构
    • 

  • 音乐指纹识别从频谱峰值哈希发展到神经嵌入，支持在退化条件下的鲁棒匹配
