图神经网络推荐

核心概念

图神经网络推荐（Graph Neural Network for Recommendation）通过将用户-物品交互建模为二部图结构，利用图上的消息传递和邻居聚合机制来学习高阶协同信号。传统协同过滤只能捕捉一阶交互（用户直接交互过的物品），而图神经网络通过多层邻居聚合，能够自然地融合二阶（用户-物品-用户）乃至更高阶的协同关系。从 GCN 到 GAT 再到 LightGCN，图推荐模型在表示学习的有效性和计算效率之间不断寻求平衡。

LightGCN 与轻量图卷积
LightGCN 是当前图推荐领域最具影响力的基线模型。它对 NGCF 进行了深入的消融实验，发现 GCN 中的特征变换和非线性激活对推荐任务不仅无益，反而引入了训练困难。LightGCN 仅保留最简单的邻居聚合：每一层中，节点的新表示等于其邻居表示的归一化加权平均。


interface LightGCNConfig {
  readonly numUsers: number;
  readonly numItems: number;
  readonly embeddingDim: number;
  readonly numLayers: number;
  readonly learningRate: number;
  readonly l2Reg: number;
}

interface AdjacencyInfo {
  readonly userNeighbors: ReadonlyMap<number, ReadonlyArray<number>>;
  readonly itemNeighbors: ReadonlyMap<number, ReadonlyArray<number>>;
  readonly userDegree: ReadonlyMap<number, number>;
  readonly itemDegree: ReadonlyMap<number, number>;
}

const lightGCNPropagate = (
  userEmbs: ReadonlyArray<ReadonlyArray<number>>,
  itemEmbs: ReadonlyArray<ReadonlyArray<number>>,
  adj: AdjacencyInfo,
): {
  readonly newUserEmbs: ReadonlyArray<ReadonlyArray<number>>;
  readonly newItemEmbs: ReadonlyArray<ReadonlyArray<number>>;
} => {
  const dim = userEmbs[0].length;
  const newUserEmbs = userEmbs.map((_, uid) => {
    const neighbors = adj.userNeighbors.get(uid) ?? [];
    const userDeg = adj.userDegree.get(uid) ?? 1;
    return Array.from({ length: dim }, (_, d) => {
      let sum = 0;
      for (const iid of neighbors) {
        const itemDeg = adj.itemDegree.get(iid) ?? 1;
        const normFactor = 1 / Math.sqrt(userDeg * itemDeg);
        sum += itemEmbs[iid][d] * normFactor;
      }
      return sum;
    });
  });
  const newItemEmbs = itemEmbs.map((_, iid) => {
    const neighbors = adj.itemNeighbors.get(iid) ?? [];
    const itemDeg = adj.itemDegree.get(iid) ?? 1;
    return Array.from({ length: dim }, (_, d) => {
      let sum = 0;
      for (const uid of neighbors) {
        const userDeg = adj.userDegree.get(uid) ?? 1;
        const normFactor = 1 / Math.sqrt(userDeg * itemDeg);
        sum += userEmbs[uid][d] * normFactor;
      }
      return sum;
    });
  });
  return { newUserEmbs, newItemEmbs };
};

const layerCombination = (
  allLayerEmbs: ReadonlyArray<ReadonlyArray<ReadonlyArray<number>>>,
  alpha: ReadonlyArray<number>,
): ReadonlyArray<ReadonlyArray<number>> => {
  const numNodes = allLayerEmbs[0].length;
  const dim = allLayerEmbs[0][0].length;
  return Array.from({ length: numNodes }, (_, n) =>
    Array.from({ length: dim }, (_, d) =>
      allLayerEmbs.reduce((sum, layerEmb, l) => sum + alpha[l] * layerEmb[n][d], 0),
    ),
  );
};
LightGCN 的层间组合策略是对所有层（包括第 0 层即初始嵌入）的输出做加权求和，权重通常设为均匀分布 α_l = 1/(L+1)。这种做法既融合了不同阶的协同信号，又起到了类似残差连接的正则化效果，有效防止过平滑（over-smoothing）。


知识增强图推荐
知识图谱（KG）为推荐系统提供了丰富的物品侧信息，知识增强图推荐将用户-物品交互图与知识图谱统一建模，通过属性关系和实体链接来缓解数据稀疏问题。


interface KGEnhancedConfig {
  readonly interactionGraph: AdjacencyInfo;
  readonly knowledgeTriples: ReadonlyArray<{
    readonly head: number;
    readonly relation: number;
    readonly tail: number;
  }>;
  readonly numRelations: number;
  readonly embeddingDim: number;
}

interface RippleNetLayer {
  readonly memories: ReadonlyArray<{
    readonly heads: ReadonlyArray<number>;
    readonly relations: ReadonlyArray<number>;
    readonly tails: ReadonlyArray<number>;
  }>;
  readonly attentionWeights: ReadonlyArray<number>;
}

const buildUserRippleSet = (
  userId: number,
  interactedItems: ReadonlyArray<number>,
  knowledgeTriples: KGEnhancedConfig['knowledgeTriples'],
  maxHops: number,
  maxMemorySize: number,
): ReadonlyArray<RippleNetLayer> => {
  const layers: RippleNetLayer[] = [];
  let currentEntities = new Set(interactedItems);

  for (let hop = 0; hop < maxHops; hop++) {
    const hopTriples = knowledgeTriples.filter((t) => currentEntities.has(t.head));
    const sampled = hopTriples.slice(0, maxMemorySize);
    layers.push({
      memories: [
        {
          heads: sampled.map((t) => t.head),
          relations: sampled.map((t) => t.relation),
          tails: sampled.map((t) => t.tail),
        },
      ],
      attentionWeights: [],
    });
    currentEntities = new Set(sampled.map((t) => t.tail));
  }
  return layers;
};

工业级图推荐系统
工业级图推荐面临的核心挑战是规模：数亿用户和数十亿物品构成的超大规模图无法在单机内存中完整存储和计算。PinSage 开创了工业级图推荐的范式，核心策略包括：基于随机游走的邻居采样（避免全图计算）、MapReduce 式分布式训练和渐进式增量更新。


采样策略直接决定了图推荐的可扩展性。Mini-batch 训练中，每个节点不计算完整的邻居聚合，而是通过采样固定数量的邻居来近似。随机游走采样通过从目标节点出发的多次短随机游走，按访问频次选取 Top-K 邻居，这些邻居比均匀随机采样更具信息量。


interface SamplingConfig {
  readonly numWalks: number;
  readonly walkLength: number;
  readonly topK: number;
  readonly numNeighborLayers: ReadonlyArray<number>;
}

const randomWalkSampling = (
  startNode: number,
  config: SamplingConfig,
  getNeighbors: (node: number) => ReadonlyArray<number>,
): ReadonlyArray<number> => {
  const visitCount = new Map<number, number>();

  for (let w = 0; w < config.numWalks; w++) {
    let current = startNode;
    for (let step = 0; step < config.walkLength; step++) {
      const neighbors = getNeighbors(current);
      if (neighbors.length === 0) break;
      current = neighbors[Math.floor(Math.random() * neighbors.length)];
      if (current !== startNode) {
        visitCount.set(current, (visitCount.get(current) ?? 0) + 1);
      }
    }
  }

  return [...visitCount.entries()]
    .sort((a, b) => b[1] - a[1])
    .slice(0, config.topK)
    .map(([node]) => node);
};
在线服务方面，图推荐模型通常采用预计算模式：离线完成所有节点的多层聚合并生成最终嵌入，将嵌入写入向量数据库（如 Milvus、Pinecone），线上通过 ANN 检索完成召回。增量更新场景下，只需重新计算发生交互变更的节点及其 K 跳邻居的嵌入。


小结
    

  • 图神经网络推荐通过邻居聚合和消息传递捕捉高阶协同信号
    • 

  • LightGCN 证明去除特征变换和非线性激活反而提升推荐效果，层间加权组合是关键设计
    • 

  • 知识增强图推荐通过融合 KG 结构信息缓解数据稀疏和冷启动问题
    • 

  • 工业级部署依赖随机游走采样、分布式训练和预计算嵌入三大工程策略
    • 

  • 过平滑是图推荐的核心理论挑战，限制了模型的有效层数
    • 

  • 前沿方向包括自监督图学习、异构图推荐和动态图推荐
