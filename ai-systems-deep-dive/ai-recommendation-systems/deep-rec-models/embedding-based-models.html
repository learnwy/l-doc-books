基于嵌入的推荐模型

核心概念

基于嵌入的推荐模型（Embedding-based Recommendation Models）是深度学习推荐的基础范式，核心思想是将用户、物品和各种特征（如类目、品牌、标签）映射到统一的低维稠密向量空间（Embedding Space），通过向量运算来计算用户-物品的匹配度。从最简单的双塔模型（Two-Tower）到复杂的特征交互网络（如 Wide & Deep、DCN），嵌入层始终是推荐模型的基石。

双塔模型
双塔模型（Two-Tower Model）是工业推荐系统中召回阶段的主力架构。用户塔和物品塔分别将各自的特征编码为固定维度的向量，两个向量的内积（或余弦相似度）作为匹配分数。双塔架构的核心优势在于：物品向量可以离线预计算并建立 ANN 索引，线上只需编码用户向量并执行近似最近邻检索，延迟极低。


interface TwoTowerConfig {
  readonly embeddingDim: number;
  readonly hiddenDims: ReadonlyArray<number>;
  readonly outputDim: number;
  readonly temperature: number;
  readonly negSampleRatio: number;
}

interface UserFeatures {
  readonly userId: string;
  readonly age: number;
  readonly gender: string;
  readonly recentItems: ReadonlyArray<string>;
  readonly recentCategories: ReadonlyArray<string>;
}

interface ItemFeatures {
  readonly itemId: string;
  readonly category: string;
  readonly brand: string;
  readonly price: number;
  readonly title: string;
}

interface EmbeddingTable {
  readonly lookup: (featureName: string, value: string) => Float32Array;
  readonly dim: number;
}

function encodeUserTower(
  features: UserFeatures,
  embeddings: EmbeddingTable,
  hiddenDims: ReadonlyArray<number>,
): Float32Array {
  const parts: Float32Array[] = [];
  parts.push(embeddings.lookup('user_id', features.userId));
  parts.push(embeddings.lookup('gender', features.gender));

  const recentEmbs = features.recentItems.map((id) => embeddings.lookup('item_id', id));
  parts.push(averagePooling(recentEmbs));

  const concat = concatenate(parts);
  return mlpForward(concat, hiddenDims);
}

function encodeItemTower(
  features: ItemFeatures,
  embeddings: EmbeddingTable,
  hiddenDims: ReadonlyArray<number>,
): Float32Array {
  const parts: Float32Array[] = [];
  parts.push(embeddings.lookup('item_id', features.itemId));
  parts.push(embeddings.lookup('category', features.category));
  parts.push(embeddings.lookup('brand', features.brand));

  const concat = concatenate(parts);
  return mlpForward(concat, hiddenDims);
}

function averagePooling(vectors: ReadonlyArray<Float32Array>): Float32Array {
  if (vectors.length === 0) return new Float32Array(vectors[0]?.length ?? 0);
  const result = new Float32Array(vectors[0].length);
  for (const v of vectors) {
    for (let i = 0; i < v.length; i++) result[i] += v[i];
  }
  for (let i = 0; i < result.length; i++) result[i] /= vectors.length;
  return result;
}

function concatenate(vectors: ReadonlyArray<Float32Array>): Float32Array {
  const totalLen = vectors.reduce((s, v) => s + v.length, 0);
  const result = new Float32Array(totalLen);
  let offset = 0;
  for (const v of vectors) {
    result.set(v, offset);
    offset += v.length;
  }
  return result;
}

function mlpForward(input: Float32Array, _hiddenDims: ReadonlyArray<number>): Float32Array {
  return input;
}
Wide & Deep 与特征交互
Wide & Deep 由 Google 在 2016 年提出，将浅层线性模型（Wide）和深度神经网络（Deep）联合训练。Wide 部分负责记忆（Memorization）——通过手工交叉特征直接学习高频模式；Deep 部分负责泛化（Generalization）——通过多层 MLP 自动发现特征组合。


DCN（Deep & Cross Network）用交叉网络（Cross Network）替代了 Wide 的手工特征工程。交叉网络在每一层显式地计算特征的高阶交叉：x_{l+1} = x_0 ⊗ x_l^T w_l + b_l + x_l，自动学习多阶交叉特征而无需手工设计。

注意力机制与 DIN
DIN（Deep Interest Network）由阿里巴巴提出，核心创新是将注意力机制引入推荐模型。传统模型将用户历史行为序列简单平均（如 sum/mean pooling），DIN 则根据候选物品动态计算历史行为中每个物品的注意力权重——与候选物品更相关的历史行为获得更高权重。


interface DINConfig {
  readonly embeddingDim: number;
  readonly attentionHiddenDim: number;
  readonly mlpDims: ReadonlyArray<number>;
}

function dinAttention(
  candidateEmb: Float32Array,
  historyEmbs: ReadonlyArray<Float32Array>,
  attentionDim: number,
): Float32Array {
  const weights: number[] = [];

  for (const histEmb of historyEmbs) {
    const diff = new Float32Array(candidateEmb.length);
    const prod = new Float32Array(candidateEmb.length);
    for (let i = 0; i < candidateEmb.length; i++) {
      diff[i] = candidateEmb[i] - histEmb[i];
      prod[i] = candidateEmb[i] * histEmb[i];
    }
    const concat = concatenate([candidateEmb, histEmb, diff, prod]);
    const score = attentionMLP(concat, attentionDim);
    weights.push(score);
  }

  const maxWeight = Math.max(...weights);
  const expWeights = weights.map((w) => Math.exp(w - maxWeight));
  const sumExp = expWeights.reduce((s, w) => s + w, 0);
  const normalizedWeights = expWeights.map((w) => w / sumExp);

  const result = new Float32Array(historyEmbs[0]?.length ?? 0);
  for (let i = 0; i < historyEmbs.length; i++) {
    for (let j = 0; j < result.length; j++) {
      result[j] += normalizedWeights[i] * historyEmbs[i][j];
    }
  }
  return result;
}

function attentionMLP(input: Float32Array, _hiddenDim: number): number {
  let sum = 0;
  for (let i = 0; i < input.length; i++) sum += input[i];
  return sum / input.length;
}
小结
    

  • Embedding 层是深度推荐模型的基石，将离散特征映射到连续向量空间
    • 

  • 双塔模型将用户和物品独立编码，支持 ANN 离线检索，适合召回阶段
    • 

  • Wide & Deep 结合记忆能力和泛化能力，DCN 用交叉网络自动化特征交互
    • 

  • DIN 通过注意力机制根据候选物品动态加权用户历史行为
    • 

  • 工业推荐系统通常采用「召回→粗排→精排→重排」的多阶段架构
    • 

  • Embedding 维度通常 32-128，过高导致过拟合和计算开销增大
    • 

  • 特征 Embedding 的预训练和共享是提升推荐系统效果的重要技术
    •
