矩阵分解进阶

核心概念

矩阵分解进阶涵盖了在基础 SVD 之上发展出的一系列改进方法，这些方法通过引入更丰富的信号（隐式反馈、时间动态、社交网络）和更灵活的模型结构来提升推荐效果。SVD++ 将隐式反馈作为额外信号注入模型，TimeSVD++ 捕获用户偏好随时间的漂移，非负矩阵分解（NMF）约束因子非负以增强可解释性。这些方法构成了从传统矩阵分解到深度学习推荐的过渡桥梁。

SVD++ 与隐式反馈增强
SVD++ 的核心洞察是：用户对哪些物品有过交互本身就包含偏好信息，即使没有显式评分。例如，用户看过科幻片 A、B、C（即使没有评分），这一行为本身就暗示了对科幻片的偏好。SVD++ 为每个物品额外学习一个隐式因子向量 y_i，用户的最终表示是显式因子加上所有交互物品隐式因子的聚合。


预测公式为：r̂_ui = μ + b_u + b_i + q_i^T(p_u + |I_u|^{-1/2} Σ_{j∈I_u} y_j)，其中 I_u 是用户 u 交互过的所有物品集合。隐式因子的聚合使用均方根归一化 |I_u|^{-1/2} 来消除活跃度差异的影响。


interface SVDPlusPlusConfig {
  readonly factors: number;
  readonly learningRate: number;
  readonly regularization: number;
  readonly epochs: number;
}

interface SVDPlusPlusModel {
  readonly userFactors: Float32Array[];
  readonly itemFactors: Float32Array[];
  readonly implicitFactors: Float32Array[];
  readonly userBias: Float32Array;
  readonly itemBias: Float32Array;
  readonly globalBias: number;
}

function predictSVDPlusPlus(
  userId: number,
  itemId: number,
  model: SVDPlusPlusModel,
  userImplicitItems: ReadonlyArray<number>,
): number {
  const norm = userImplicitItems.length > 0 ? 1.0 / Math.sqrt(userImplicitItems.length) : 0;

  const implicitSum = new Float32Array(model.userFactors[0].length);
  for (const j of userImplicitItems) {
    for (let f = 0; f < implicitSum.length; f++) {
      implicitSum[f] += model.implicitFactors[j][f];
    }
  }

  let dot = 0;
  for (let f = 0; f < model.userFactors[userId].length; f++) {
    const userComponent = model.userFactors[userId][f] + norm * implicitSum[f];
    dot += model.itemFactors[itemId][f] * userComponent;
  }

  return model.globalBias + model.userBias[userId] + model.itemBias[itemId] + dot;
}
因子化机器 FM
因子化机器（Factorization Machine, FM）是矩阵分解的泛化形式。矩阵分解只建模用户 ID 和物品 ID 两个特征的交互，而 FM 可以建模任意特征之间的二阶交互。FM 的预测公式为：ŷ = w_0 + Σ w_i·x_i + Σ Σ <v_i, v_j>·x_i·x_j，其中每个特征学习一个 k 维隐向量 v_i，交互项通过隐向量的内积计算。


FM 的计算复杂度可以通过数学变换从 O(kn²) 优化到 O(kn)：Σ Σ <v_i, v_j>·x_i·x_j = 1/2 Σ_{f=1}^{k} [(Σ v_{i,f}·x_i)² - Σ (v_{i,f}·x_i)²]。这使得 FM 在高维稀疏特征上也能高效训练。


interface FMConfig {
  readonly factors: number;
  readonly learningRate: number;
  readonly regularization: [number, number, number];
  readonly epochs: number;
}

interface FMModel {
  readonly w0: number;
  readonly weights: Float32Array;
  readonly factors: Float32Array[];
}

function fmPredict(features: ReadonlyArray<{ index: number; value: number }>, model: FMModel): number {
  let prediction = model.w0;

  for (const feat of features) {
    prediction += model.weights[feat.index] * feat.value;
  }

  const k = model.factors[0]?.length ?? 0;
  for (let f = 0; f < k; f++) {
    let sumSquare = 0;
    let squareSum = 0;
    for (const feat of features) {
      const vf = model.factors[feat.index][f] * feat.value;
      sumSquare += vf;
      squareSum += vf * vf;
    }
    prediction += 0.5 * (sumSquare * sumSquare - squareSum);
  }

  return prediction;
}

NMF 与可解释矩阵分解
非负矩阵分解（NMF, Non-negative Matrix Factorization）在矩阵分解的基础上增加了非负约束：R ≈ WH，其中 W ≥ 0, H ≥ 0。非负约束使得分解结果具有「部分-整体」的语义：每个因子可以解释为一种「主题」或「偏好模式」，用户向量的每个维度表示对该主题的偏好强度，物品向量的每个维度表示属于该主题的程度。


这种可解释性使得 NMF 在需要解释推荐理由的场景中特别有价值。例如，因子 1 可能对应「科幻动作片」偏好，因子 2 对应「文艺爱情片」偏好。用户在因子 1 上权重高就推荐科幻片，在因子 2 上权重高就推荐文艺片。


function nmfUpdate(rating: number, userFactors: Float32Array, itemFactors: Float32Array, learningRate: number): void {
  let predicted = 0;
  for (let f = 0; f < userFactors.length; f++) {
    predicted += userFactors[f] * itemFactors[f];
  }
  const error = rating - predicted;

  for (let f = 0; f < userFactors.length; f++) {
    const newU = userFactors[f] + learningRate * error * itemFactors[f];
    const newI = itemFactors[f] + learningRate * error * userFactors[f];
    userFactors[f] = Math.max(0, newU);
    itemFactors[f] = Math.max(0, newI);
  }
}
