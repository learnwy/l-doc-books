基于记忆的协同过滤

核心概念

基于记忆的协同过滤（Memory-based Collaborative Filtering）是推荐系统中最经典的方法，核心思想是「相似的用户喜欢相似的物品」或「被相似用户喜欢的物品可以互相推荐」。它直接使用用户-物品评分矩阵中的历史数据，通过计算用户间或物品间的相似度来生成推荐，不需要训练模型参数。基于记忆的方法分为两大类：User-based CF（基于用户相似度）和 Item-based CF（基于物品相似度）。

相似度计算方法
相似度计算是协同过滤的核心环节。对于 User-based CF，需要计算任意两个用户之间的相似度；对于 Item-based CF，需要计算任意两个物品之间的相似度。常用的相似度度量包括余弦相似度、Pearson 相关系数和 Jaccard 系数。


余弦相似度将评分向量视为高维空间中的方向，通过计算夹角余弦衡量方向的一致性。Pearson 相关系数在余弦相似度的基础上减去了均值，消除了用户评分偏差（有的用户习惯打高分，有的打低分）的影响。


interface RatingMatrix {
  readonly users: ReadonlyArray<string>;
  readonly items: ReadonlyArray<string>;
  readonly ratings: ReadonlyMap<string, ReadonlyMap<string, number>>;
}

type SimilarityMetric = 'cosine' | 'pearson' | 'jaccard' | 'adjusted-cosine';

function cosineSimilarity(ratingsA: ReadonlyMap<string, number>, ratingsB: ReadonlyMap<string, number>): number {
  let dotProduct = 0;
  let normA = 0;
  let normB = 0;

  const commonItems = new Set<string>();
  for (const item of ratingsA.keys()) {
    if (ratingsB.has(item)) commonItems.add(item);
  }

  if (commonItems.size === 0) return 0;

  for (const item of commonItems) {
    const a = ratingsA.get(item)!;
    const b = ratingsB.get(item)!;
    dotProduct += a * b;
    normA += a * a;
    normB += b * b;
  }

  const denominator = Math.sqrt(normA) * Math.sqrt(normB);
  return denominator > 0 ? dotProduct / denominator : 0;
}

function pearsonSimilarity(ratingsA: ReadonlyMap<string, number>, ratingsB: ReadonlyMap<string, number>): number {
  const commonItems = [...ratingsA.keys()].filter((k) => ratingsB.has(k));
  if (commonItems.length < 2) return 0;

  const meanA = commonItems.reduce((s, k) => s + ratingsA.get(k)!, 0) / commonItems.length;
  const meanB = commonItems.reduce((s, k) => s + ratingsB.get(k)!, 0) / commonItems.length;

  let numerator = 0;
  let denomA = 0;
  let denomB = 0;

  for (const item of commonItems) {
    const diffA = ratingsA.get(item)! - meanA;
    const diffB = ratingsB.get(item)! - meanB;
    numerator += diffA * diffB;
    denomA += diffA * diffA;
    denomB += diffB * diffB;
  }

  const denominator = Math.sqrt(denomA) * Math.sqrt(denomB);
  return denominator > 0 ? numerator / denominator : 0;
}

评分预测与推荐生成
计算出相似度后，通过加权聚合相似用户（或相似物品）的已知评分来预测目标评分。User-based CF 的预测公式为：r̂(u, i) = μ_u + Σ_{v∈N(u)} sim(u,v) × (r(v,i) - μ_v) / Σ_{v∈N(u)} |sim(u,v)|，其中 N(u) 是用户 u 的 top-k 相似用户集合。


interface CFConfig {
  readonly method: 'user-based' | 'item-based';
  readonly metric: SimilarityMetric;
  readonly neighborhoodSize: number;
  readonly minCommonItems: number;
  readonly defaultRating: number;
}

interface Recommendation {
  readonly itemId: string;
  readonly predictedRating: number;
  readonly confidence: number;
  readonly explanation: string;
}

function predictRatingUserBased(
  targetUser: string,
  targetItem: string,
  matrix: RatingMatrix,
  similarities: ReadonlyMap<string, ReadonlyArray<{ userId: string; similarity: number }>>,
  config: CFConfig,
): number {
  const userRatings = matrix.ratings.get(targetUser);
  if (!userRatings) return config.defaultRating;

  const userMean = computeMean(userRatings);
  const neighbors = similarities.get(targetUser) ?? [];

  let weightedSum = 0;
  let absWeightSum = 0;

  for (const neighbor of neighbors.slice(0, config.neighborhoodSize)) {
    const neighborRatings = matrix.ratings.get(neighbor.userId);
    if (!neighborRatings?.has(targetItem)) continue;

    const neighborMean = computeMean(neighborRatings);
    const deviation = neighborRatings.get(targetItem)! - neighborMean;

    weightedSum += neighbor.similarity * deviation;
    absWeightSum += Math.abs(neighbor.similarity);
  }

  return absWeightSum > 0 ? userMean + weightedSum / absWeightSum : userMean;
}

function computeMean(ratings: ReadonlyMap<string, number>): number {
  let sum = 0;
  for (const r of ratings.values()) sum += r;
  return ratings.size > 0 ? sum / ratings.size : 0;
}

function generateRecommendations(
  targetUser: string,
  matrix: RatingMatrix,
  similarities: ReadonlyMap<string, ReadonlyArray<{ userId: string; similarity: number }>>,
  config: CFConfig,
  topN: number,
): ReadonlyArray<Recommendation> {
  const userRatings = matrix.ratings.get(targetUser) ?? new Map();
  const candidates = matrix.items.filter((item) => !userRatings.has(item));

  const scored = candidates.map((item) => ({
    itemId: item,
    predictedRating: predictRatingUserBased(targetUser, item, matrix, similarities, config),
    confidence: 0,
    explanation: '',
  }));

  return scored.sort((a, b) => b.predictedRating - a.predictedRating).slice(0, topN);
}
冷启动与数据稀疏性
基于记忆的协同过滤面临两个根本挑战：冷启动（Cold Start）和数据稀疏性（Sparsity）。冷启动指新用户或新物品缺乏足够的交互记录，导致无法计算有意义的相似度。数据稀疏性指大规模系统中用户-物品评分矩阵极度稀疏（通常填充率不到 1%），大部分用户对间没有共同评分物品。

Amazon 在 2003 年的论文中提出 Item-based CF 比 User-based CF 更适合大规模场景：物品相似度矩阵可以离线预计算且相对稳定（物品间的关系变化较慢），而用户相似度随新行为不断变化。这一工程选择至今仍被广泛采用。


小结
    

  • 基于记忆的协同过滤直接使用评分矩阵中的历史数据，不需要训练模型
    • 

  • User-based CF 基于「相似用户」推荐，偶然发现性好但用户多时效率低
    • 

  • Item-based CF 基于「相似物品」推荐，可预计算且可解释性强
    • 

  • Pearson 相关系数消除了用户评分偏差，是显式评分场景的首选相似度
    • 

  • 评分预测通过相似邻居的加权聚合实现，邻居数 k 需要调优
    • 

  • 冷启动和数据稀疏是核心挑战，实际系统通过混合方法缓解
    • 

  • Item-based CF 因工程可行性好，在工业界广泛使用
