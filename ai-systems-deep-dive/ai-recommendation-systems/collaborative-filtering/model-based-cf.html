基于模型的协同过滤

核心概念

基于模型的协同过滤（Model-based Collaborative Filtering）通过训练参数化模型来学习用户-物品交互中的潜在模式，然后用模型预测未知的评分。与基于记忆的方法直接使用原始评分矩阵不同，基于模型的方法先从数据中「学习」一个压缩的表示，再用这个表示进行推荐。主流方法包括潜在因子模型（如 SVD、NMF）、聚类方法、贝叶斯方法和关联规则。

SVD 与 Funk-SVD
传统 SVD（Singular Value Decomposition）将评分矩阵 R 分解为三个矩阵的乘积 R = UΣV^T，但评分矩阵的稀疏性使得标准 SVD 无法直接应用（缺失值怎么处理？）。Simon Funk 在 2006 年 Netflix Prize 比赛中提出了 Funk-SVD：只对已知评分进行矩阵分解，通过 SGD 优化目标函数 min Σ (r_ui - p_u^T · q_i)²  + λ(||p_u||² + ||q_i||²)。


interface FunkSVDConfig {
  readonly factors: number;
  readonly learningRate: number;
  readonly regularization: number;
  readonly epochs: number;
  readonly minImprovement: number;
}

interface LatentFactors {
  readonly userFactors: Float32Array[];
  readonly itemFactors: Float32Array[];
  readonly userBias: Float32Array;
  readonly itemBias: Float32Array;
  readonly globalBias: number;
}

interface Rating {
  readonly userId: number;
  readonly itemId: number;
  readonly value: number;
}

function trainFunkSVD(
  ratings: ReadonlyArray<Rating>,
  numUsers: number,
  numItems: number,
  config: FunkSVDConfig,
): LatentFactors {
  const userFactors = initRandomFactors(numUsers, config.factors);
  const itemFactors = initRandomFactors(numItems, config.factors);
  const userBias = new Float32Array(numUsers);
  const itemBias = new Float32Array(numItems);
  const globalBias = ratings.reduce((s, r) => s + r.value, 0) / ratings.length;

  for (let epoch = 0; epoch < config.epochs; epoch++) {
    for (const rating of ratings) {
      const predicted = predictSVD(
        userFactors[rating.userId],
        itemFactors[rating.itemId],
        userBias[rating.userId],
        itemBias[rating.itemId],
        globalBias,
      );
      const error = rating.value - predicted;

      userBias[rating.userId] += config.learningRate * (error - config.regularization * userBias[rating.userId]);
      itemBias[rating.itemId] += config.learningRate * (error - config.regularization * itemBias[rating.itemId]);

      for (let f = 0; f < config.factors; f++) {
        const pu = userFactors[rating.userId][f];
        const qi = itemFactors[rating.itemId][f];
        userFactors[rating.userId][f] += config.learningRate * (error * qi - config.regularization * pu);
        itemFactors[rating.itemId][f] += config.learningRate * (error * pu - config.regularization * qi);
      }
    }
  }

  return { userFactors, itemFactors, userBias, itemBias, globalBias };
}

function predictSVD(
  userFactor: Float32Array,
  itemFactor: Float32Array,
  userBias: number,
  itemBias: number,
  globalBias: number,
): number {
  let dot = 0;
  for (let i = 0; i < userFactor.length; i++) {
    dot += userFactor[i] * itemFactor[i];
  }
  return globalBias + userBias + itemBias + dot;
}

function initRandomFactors(count: number, dim: number): Float32Array[] {
  return Array.from({ length: count }, () => {
    const factors = new Float32Array(dim);
    for (let i = 0; i < dim; i++) {
      factors[i] = (Math.random() - 0.5) * 0.01;
    }
    return factors;
  });
}
ALS 与隐式反馈
ALS（Alternating Least Squares）是另一种矩阵分解优化方法：固定物品因子矩阵 Q 求解用户因子矩阵 P 的最优解，然后固定 P 求解 Q 的最优解，交替迭代直至收敛。ALS 的优势在于每步求解是凸优化问题，有闭合解，且天然支持并行化。


对于隐式反馈数据（如点击、浏览、购买），Hu 等人提出了 iALS（implicit ALS）：将交互视为「置信度」而非「评分」，用户对物品有交互则置信度高（c_ui = 1 + α·r_ui），无交互则置信度为基线值 1。优化目标变为加权最小二乘：min Σ c_ui(p_ui - p_u^T·q_i)² + λ(||P||² + ||Q||²)。

概率矩阵分解
概率矩阵分解（PMF, Probabilistic Matrix Factorization）为矩阵分解提供了概率解释。PMF 假设评分值服从高斯分布：r_ui ~ N(p_u^T·q_i, σ²)，用户和物品因子分别服从先验分布：p_u ~ N(0, σ_P²I), q_i ~ N(0, σ_Q²I)。通过最大化后验概率（MAP）求解因子，等价于带 L2 正则的矩阵分解。


贝叶斯个性化排序（BPR, Bayesian Personalized Ranking）是隐式反馈场景中最有效的模型之一。BPR 的核心假设是：用户与之交互过的物品应该排在未交互物品之前。优化目标是最大化正样本和负样本评分差的 sigmoid：max Σ log σ(r̂_ui - r̂_uj)，其中 i 是正样本（有交互），j 是负样本（无交互）。


interface BPRConfig {
  readonly factors: number;
  readonly learningRate: number;
  readonly regularization: number;
  readonly epochs: number;
  readonly negSamplesPerPositive: number;
}

function bprUpdate(
  userFactor: Float32Array,
  posItemFactor: Float32Array,
  negItemFactor: Float32Array,
  config: BPRConfig,
): void {
  let xuij = 0;
  for (let f = 0; f < config.factors; f++) {
    xuij += userFactor[f] * (posItemFactor[f] - negItemFactor[f]);
  }

  const gradient = 1 / (1 + Math.exp(xuij));

  for (let f = 0; f < config.factors; f++) {
    const uf = userFactor[f];
    const pf = posItemFactor[f];
    const nf = negItemFactor[f];

    userFactor[f] += config.learningRate * (gradient * (pf - nf) - config.regularization * uf);
    posItemFactor[f] += config.learningRate * (gradient * uf - config.regularization * pf);
    negItemFactor[f] += config.learningRate * (-gradient * uf - config.regularization * nf);
  }
}
小结
    

  • 基于模型的协同过滤通过训练参数化模型学习交互数据中的潜在模式
    • 

  • Funk-SVD 通过 SGD 优化只对已知评分的矩阵分解，是 Netflix Prize 的里程碑
    • 

  • ALS 天然支持并行化，iALS 扩展到隐式反馈场景
    • 

  • BPR 使用排序损失优化，是隐式反馈推荐的经典方法
    • 

  • PMF 为矩阵分解提供了概率解释，MAP 估计等价于 L2 正则化
    • 

  • 隐因子数 k 通常在 50-200 之间，需要在表达能力和过拟合之间权衡
    • 

  • 基于模型的方法是深度学习推荐的基础，矩阵分解思想延续至今
    •
