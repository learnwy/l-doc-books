用户与物品建模

核心概念

用户与物品建模（User-Item Modeling）是推荐系统的基础，将用户和物品的各种特征转化为机器学习模型可处理的数值表示。用户模型刻画用户的兴趣偏好、行为模式和人口统计学特征；物品模型描述物品的内容属性、类别信息和交互统计。

用户画像体系
用户画像（User Profile）是用户兴趣和行为模式的结构化表示，是推荐系统个性化的基础。


interface UserProfile {
  userId: string;
  demographics: Demographics;
  interests: InterestProfile;
  behaviors: BehaviorProfile;
  realtimeProfile: RealtimeProfile;
}

interface Demographics {
  age: number;
  gender: string;
  city: string;
  device: string;
  registerDays: number;
}

interface InterestProfile {
  categories: Map<string, number>;
  tags: Map<string, number>;
  brands: Map<string, number>;
  priceRange: [number, number];
  lastUpdateTime: Date;
}

interface BehaviorProfile {
  totalClicks: number;
  totalPurchases: number;
  avgSessionDuration: number;
  activeHours: number[];
  clickHistory: string[];
  purchaseHistory: string[];
}

interface RealtimeProfile {
  currentSessionItems: string[];
  currentSessionCategories: Set<string>;
  sessionStartTime: Date;
  recentSearchQueries: string[];
}

function updateInterestProfile(
  profile: InterestProfile,
  interaction: UserInteraction,
  decayFactor: number = 0.95,
): InterestProfile {
  for (const [key, value] of profile.categories) {
    profile.categories.set(key, value * decayFactor);
  }

  const category = interaction.itemCategory;
  const weight = interactionWeight(interaction.type);
  const current = profile.categories.get(category) ?? 0;
  profile.categories.set(category, current + weight);

  profile.lastUpdateTime = new Date();
  return profile;
}

function interactionWeight(type: string): number {
  const weights: Record<string, number> = {
    click: 1,
    add_cart: 3,
    purchase: 5,
    favorite: 2,
    share: 4,
  };
  return weights[type] ?? 0;
}
用户兴趣的时间衰减是画像建模的关键设计。用户的兴趣会随时间变化，最近的行为更能反映当前偏好。指数衰减是最常用的方法：历史交互的权重按时间距离指数递减。






衰减策略
公式
特点
适用场景





指数衰减
w(t) = e^(-λΔt)
近期行为权重高
兴趣变化快（短视频）




线性衰减
w(t) = max(0, 1 - αΔt)
平滑递减
兴趣变化平缓（电商）




阶梯衰减
w(t) = w_period
按时间段分权重
周期性兴趣（节日消费）




不衰减
w(t) = 1
历史等权
长期稳定偏好（图书）





实时画像的构建对推荐系统的时效性至关重要。用户在当前 Session 中的行为（浏览了哪些商品、搜索了什么关键词）是预测即时兴趣的最强信号。工业系统通常使用 Flink 或 Kafka Streams 等流处理框架实时聚合用户行为，在毫秒级别更新用户的实时特征。实时特征与离线画像特征的融合方式通常采用 Concat 或 Attention 机制，让模型自动学习两类特征的权重。


物品表示学习
物品表示学习将物品的多维特征编码为稠密向量，使得语义相似的物品在向量空间中距离更近。


interface ItemFeatures {
  itemId: string;
  title: string;
  category: string[];
  tags: string[];
  price: number;
  imageUrl: string;
  description: string;
  statistics: ItemStatistics;
}

interface ItemStatistics {
  impressionCount: number;
  clickCount: number;
  purchaseCount: number;
  avgRating: number;
  reviewCount: number;
  ctr: number;
  cvr: number;
}

interface ItemEmbedding {
  itemId: string;
  idEmbedding: Float32Array;
  contentEmbedding: Float32Array;
  cfEmbedding: Float32Array;
  fusedEmbedding: Float32Array;
}

function fuseItemEmbeddings(
  idEmb: Float32Array,
  contentEmb: Float32Array,
  cfEmb: Float32Array,
  weights: [number, number, number],
): Float32Array {
  const dim = idEmb.length;
  const fused = new Float32Array(dim);
  for (let i = 0; i < dim; i++) {
    fused[i] = weights[0] * idEmb[i] + weights[1] * contentEmb[i] + weights[2] * cfEmb[i];
  }
  return l2Normalize(fused);
}

function item2vecTraining(sessions: string[][], embeddingDim: number, windowSize: number): Map<string, Float32Array> {
  const embeddings = new Map<string, Float32Array>();
  for (const session of sessions) {
    for (let i = 0; i < session.length; i++) {
      const center = session[i];
      const start = Math.max(0, i - windowSize);
      const end = Math.min(session.length, i + windowSize + 1);
      for (let j = start; j < end; j++) {
        if (j === i) continue;
        updateSkipGram(center, session[j], embeddings, embeddingDim);
      }
    }
  }
  return embeddings;
}
Item2Vec 是物品嵌入的经典方法，它将用户的行为序列类比为自然语言中的句子，物品类比为单词，使用 Skip-Gram 模型学习物品的分布式表示。同一个 session 中共现的物品在向量空间中会更接近。


小结
    

  • 用户与物品建模是推荐系统的基础，将多维特征转化为机器学习可处理的数值表示
    • 

  • 用户画像包含人口统计、兴趣偏好、行为模式和实时特征四个层次
    • 

  • 兴趣的时间衰减机制确保画像反映用户的最新偏好而非历史累积
    • 

  • 物品表示融合 ID 嵌入、内容嵌入和协同过滤嵌入，多维度刻画物品特征
    • 

  • Item2Vec 将行为序列类比为语言序列，通过 Skip-Gram 学习物品的语义嵌入
    •
