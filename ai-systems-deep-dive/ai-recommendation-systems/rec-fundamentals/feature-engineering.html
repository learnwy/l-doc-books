推荐特征工程

核心概念

特征工程（Feature Engineering）是推荐系统中将原始数据转化为模型输入特征的过程，直接决定了模型的性能上界。推荐系统的特征来源多样，包括用户侧、物品侧、上下文侧以及用户-物品交叉侧，需要从海量原始数据中提炼出有效的信号。

离散特征编码
推荐系统中大量特征是离散的（如用户 ID、物品 ID、品类、城市等），需要编码为数值向量。Embedding 是处理高基数离散特征的标准方法。


interface EmbeddingTable {
  vocabSize: number;
  embeddingDim: number;
  weights: Float32Array[];
  defaultEmbedding: Float32Array;
}

interface FeatureConfig {
  name: string;
  type: 'categorical' | 'numerical' | 'sequence' | 'multi_hot';
  vocabSize?: number;
  embeddingDim?: number;
  hashBuckets?: number;
}

function hashEmbedding(
  featureValue: string,
  numBuckets: number,
  embeddingDim: number,
  table: Float32Array[],
): Float32Array {
  const hashValue = murmurhash(featureValue) % numBuckets;
  return table[hashValue];
}

function multiHotEncoding(
  values: string[],
  embeddingTable: EmbeddingTable,
  pooling: 'mean' | 'sum' | 'max',
): Float32Array {
  const embeddings = values.map((v) => {
    const idx = hashString(v) % embeddingTable.vocabSize;
    return embeddingTable.weights[idx] ?? embeddingTable.defaultEmbedding;
  });

  if (pooling === 'sum') {
    return sumVectors(embeddings);
  }
  if (pooling === 'max') {
    return maxPoolVectors(embeddings);
  }
  return meanVectors(embeddings);
}

interface FeatureInteraction {
  features: string[];
  method: 'concat' | 'hadamard' | 'bilinear' | 'fm';
}

function fmInteraction(embeddings: Float32Array[]): Float32Array {
  const n = embeddings.length;
  const dim = embeddings[0].length;
  const sumOfSquare = new Float32Array(dim);
  const squareOfSum = new Float32Array(dim);

  for (let i = 0; i < n; i++) {
    for (let d = 0; d < dim; d++) {
      squareOfSum[d] += embeddings[i][d];
      sumOfSquare[d] += embeddings[i][d] * embeddings[i][d];
    }
  }

  const result = new Float32Array(dim);
  for (let d = 0; d < dim; d++) {
    result[d] = 0.5 * (squareOfSum[d] * squareOfSum[d] - sumOfSquare[d]);
  }
  return result;
}
Hash Embedding 通过哈希函数将高基数特征（如物品 ID）映射到固定大小的桶中，解决了 Embedding 表过大的内存问题。代价是可能产生哈希冲突，但实践表明适度的冲突对模型效果影响较小。


序列特征处理
用户的行为序列（浏览历史、购买历史、搜索历史）蕴含丰富的兴趣信号。序列特征的处理需要捕获用户兴趣的时序演变模式。


interface SequenceFeature {
  items: string[];
  timestamps: number[];
  actions: string[];
  maxLength: number;
}

function targetAttentionPooling(sequence: Float32Array[], target: Float32Array, mask: boolean[]): Float32Array {
  const scores: number[] = [];
  for (let i = 0; i < sequence.length; i++) {
    if (!mask[i]) {
      scores.push(-Infinity);
      continue;
    }
    scores.push(dotProduct(sequence[i], target));
  }

  const weights = softmax(new Float32Array(scores));
  const dim = target.length;
  const result = new Float32Array(dim);

  for (let i = 0; i < sequence.length; i++) {
    for (let d = 0; d < dim; d++) {
      result[d] += weights[i] * sequence[i][d];
    }
  }

  return result;
}

interface PositionalEncoding {
  type: 'sinusoidal' | 'learnable' | 'relative_time';
  maxLength: number;
  dimension: number;
}

function timeAwarePositionalEncoding(timestamps: number[], currentTime: number, dimension: number): Float32Array[] {
  return timestamps.map((t) => {
    const timeDiff = (currentTime - t) / 3600000;
    const encoding = new Float32Array(dimension);
    for (let i = 0; i < dimension; i += 2) {
      const freq = 1 / Math.pow(10000, i / dimension);
      encoding[i] = Math.sin(timeDiff * freq);
      if (i + 1 < dimension) encoding[i + 1] = Math.cos(timeDiff * freq);
    }
    return encoding;
  });
}
DIN（Deep Interest Network）引入了 Target Attention 机制：不是对用户历史行为序列做简单的平均池化，而是根据当前候选物品计算历史中每个行为的注意力权重。这使得模型能够根据不同的候选物品提取不同的用户兴趣。

小结
    

  • 特征工程是推荐系统性能的关键因素，包括用户、物品、上下文和交叉四类特征
    • 

  • Embedding 是处理高基数离散特征的标准方法，Hash Embedding 解决超大词表的内存问题
    • 

  • 序列特征通过 Target Attention（DIN）等机制捕获与当前候选相关的用户兴趣
    • 

  • FM 交叉提供了高效的二阶特征交互计算，是推荐模型的基础组件
    • 

  • 特征服务架构分为离线/近线/在线三层，保证低延迟下获取海量特征
