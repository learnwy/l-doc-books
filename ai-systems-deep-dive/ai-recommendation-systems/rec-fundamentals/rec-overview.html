推荐系统概述

核心概念

推荐系统（Recommendation System）是利用用户行为数据和物品属性信息，自动预测用户兴趣并主动推送个性化内容的信息过滤系统。推荐系统解决了信息过载问题，是电商、内容平台和社交媒体的核心技术引擎，直接影响用户体验和商业转化。

推荐系统架构
工业级推荐系统通常采用多阶段级联架构，从百万级候选物品中逐级筛选出最终展示给用户的少量推荐结果。每个阶段使用复杂度递增的模型处理逐渐减少的候选集。


interface RecPipeline {
  recall: RecallStage;
  preRank: PreRankStage;
  rank: RankStage;
  reRank: ReRankStage;
}

interface RecallStage {
  channels: RecallChannel[];
  totalQuota: number;
}

interface RecallChannel {
  name: string;
  type: 'cf' | 'content' | 'hot' | 'new' | 'personalized';
  quota: number;
  model: RecallModel;
}

interface RankStage {
  model: RankModel;
  features: FeatureConfig;
  batchSize: number;
  topK: number;
}

interface ReRankStage {
  diversityWeight: number;
  freshnessBoost: number;
  businessRules: BusinessRule[];
}

async function recommend(userId: string, context: RequestContext, pipeline: RecPipeline): Promise<RecItem[]> {
  const candidates = await multiChannelRecall(userId, context, pipeline.recall);
  const preRanked = await preRank(candidates, userId, pipeline.preRank);
  const ranked = await rank(preRanked, userId, context, pipeline.rank);
  const reRanked = await reRank(ranked, userId, context, pipeline.reRank);
  return reRanked;
}
召回层是推荐管线的入口，负责从全量物品库中快速筛选出千级候选。多路召回（协同过滤、热门、实时兴趣、向量召回）是工业标准，各路召回覆盖不同的推荐逻辑。


推荐目标与优化
推荐系统的优化目标不仅仅是 "用户是否会点击"，还需要考虑用户满意度、商业价值和平台生态等多维度目标。


粗排层对召回候选进行初步筛选，通常使用轻量级模型（双塔模型或简化版精排模型）将候选集从数千缩减至数百。精排层使用最复杂的深度学习模型进行逐条打分，是推荐效果的核心环节。重排层在精排结果基础上施加多样性约束、业务规则和实时策略，输出最终展示列表。

多目标优化是实际推荐系统的核心挑战。ESMM（Entire Space Multi-Task Model）通过 "曝光→点击→转化" 的任务链建模 CTR 和 CVR；MMOE（Multi-gate Mixture-of-Experts）通过专家网络和门控机制处理多任务之间的关系；PLE（Progressive Layered Extraction）进一步引入任务特定和共享的专家网络来解决多任务之间的跷跷板效应。


冷启动问题
冷启动（Cold Start）是推荐系统面临的经典挑战：新用户没有行为历史，新物品没有被交互过，系统无法进行有效的个性化推荐。


type ColdStartType = 'new_user' | 'new_item' | 'new_system';

interface ColdStartStrategy {
  type: ColdStartType;
  method: string;
  fallback: string;
}

const COLD_START_STRATEGIES: ColdStartStrategy[] = [
  { type: 'new_user', method: '注册信息画像', fallback: '热门推荐' },
  { type: 'new_user', method: '引导式兴趣选择', fallback: '分群推荐' },
  { type: 'new_user', method: '实时行为快速建模', fallback: 'Bandit 探索' },
  { type: 'new_item', method: '内容特征匹配', fallback: '同类热门' },
  { type: 'new_item', method: '物品侧信息嵌入', fallback: '随机曝光' },
];

function newUserRecommend(userProfile: BasicProfile, context: RequestContext): RecItem[] {
  if (userProfile.interactionCount === 0) {
    return popularItems(context.location, context.time);
  }

  if (userProfile.interactionCount < 5) {
    return contentBasedRecommend(userProfile.selectedInterests);
  }

  return personalizedRecommend(userProfile.userId, context);
}
解决用户冷启动的常见策略包括：利用注册信息和人口统计学特征进行初始画像、引导用户选择兴趣标签、利用用户的前几次交互快速更新模型（实时特征）以及 Bandit 探索（在推荐中混入探索性内容以快速了解用户偏好）。


小结
    

  • 推荐系统通过预测用户兴趣实现个性化内容分发，是解决信息过载的核心技术
    • 

  • 工业推荐采用召回→粗排→精排→重排的级联架构，逐级筛选候选物品
    • 

  • 多目标优化（CTR + CVR + 时长 + 多样性）是实际系统的核心挑战
    • 

  • 冷启动问题需要结合用户画像、内容特征和在线探索策略来解决
    • 

  • 推荐效果优化是一个持续迭代的过程，需要线上 A/B 测试验证每次改进
    •
