排序与重排序

核心概念

排序（Ranking）和重排序（Re-Ranking）是推荐系统级联架构中精细化决策的两个关键阶段。排序层使用复杂的深度学习模型对召回的候选物品进行个性化评分，重排序层在排序结果基础上考虑多样性、时效性和业务策略等因素进行最终调整。

精排模型设计
精排模型是推荐系统中最复杂的模型，需要利用丰富的特征进行精确的 CTR/CVR 预估。


interface RankModelConfig {
  userFeatures: FeatureConfig[];
  itemFeatures: FeatureConfig[];
  contextFeatures: FeatureConfig[];
  crossFeatures: FeatureConfig[];
  dnnLayers: number[];
  crossLayers: number;
  tasks: TaskConfig[];
}

interface TaskConfig {
  name: string;
  type: 'binary' | 'regression';
  lossWeight: number;
  tower: number[];
}

interface RankResult {
  itemId: string;
  ctrScore: number;
  cvrScore: number;
  durationScore: number;
  finalScore: number;
}

function computeFinalScore(ctr: number, cvr: number, duration: number, weights: ScoreWeights): number {
  return (
    weights.ctrWeight * ctr +
    weights.cvrWeight * (ctr * cvr) +
    weights.durationWeight * Math.log(1 + duration) +
    weights.bidPrice
  );
}

interface ScoreWeights {
  ctrWeight: number;
  cvrWeight: number;
  durationWeight: number;
  bidPrice: number;
}
精排的多目标融合通常使用加权组合公式。在电商场景中，常用 eCPM = pCTR × pCVR × bid 作为广告排序的核心公式；在内容推荐场景中，常用 score = w1 × pCTR + w2 × pDuration + w3 × pLike 进行综合排序。


重排序策略
重排序层不仅仅优化单个物品的得分，更关注推荐列表整体的质量。核心目标包括多样性（用户不希望看到一堆相似的物品）、时效性（新物品需要曝光机会）和业务策略（运营规则、广告插入）。精排模型的演进经历了从浅层到深层的过程。早期的逻辑回归（LR）和 GBDT 依赖手工特征交叉；Wide & Deep 引入了 DNN 自动学习高阶特征；DCN（Deep & Cross Network）通过显式交叉层替代 Wide 部分；DIN（Deep Interest Network）引入注意力机制捕获用户兴趣与候选物品的相关性；DIEN（Deep Interest Evolution Network）进一步建模用户兴趣的时序演化。

interface ReRankConfig {
  diversityMethod: 'mmr' | 'dpp' | 'category_balance';
  diversityWeight: number;
  freshnessDecay: number;
  businessRules: BusinessRule[];
  listSize: number;
}

function mmrReRank(
  items: RankResult[],
  lambda: number,
  listSize: number,
  similarityFn: (a: string, b: string) => number,
): RankResult[] {
  const selected: RankResult[] = [];
  const remaining = [...items];

  while (selected.length < listSize && remaining.length > 0) {
    let bestIdx = 0;
    let bestScore = -Infinity;

    for (let i = 0; i < remaining.length; i++) {
      const relevance = remaining[i].finalScore;
      const maxSim =
        selected.length === 0 ? 0 : Math.max(...selected.map((s) => similarityFn(remaining[i].itemId, s.itemId)));
      const mmrScore = lambda * relevance - (1 - lambda) * maxSim;
      if (mmrScore > bestScore) {
        bestScore = mmrScore;
        bestIdx = i;
      }
    }

    selected.push(remaining[bestIdx]);
    remaining.splice(bestIdx, 1);
  }

  return selected;
}

function categoryDiversify(items: RankResult[], maxPerCategory: number, categories: Map<string, string>): RankResult[] {
  const result: RankResult[] = [];
  const categoryCount = new Map<string, number>();

  for (const item of items) {
    const category = categories.get(item.itemId) ?? 'unknown';
    const count = categoryCount.get(category) ?? 0;
    if (count < maxPerCategory) {
      result.push(item);
      categoryCount.set(category, count + 1);
    }
  }

  return result;
}
DPP（Determinantal Point Process）是一种优雅的多样性建模方法，它同时考虑物品的质量和物品之间的多样性。DPP 选择的子集倾向于包含高质量且相互不相似的物品。


位置偏差与校准
用户的点击行为受到展示位置的强烈影响：靠前的位置获得更多关注，即使物品不太相关也可能被点击。如果不校正位置偏差，排序模型会学到 "排在前面的物品更好" 的错误信号。

位置偏差校正的核心思路是在训练时引入位置信息（让模型学会区分位置效应和物品效应），但在推理时不使用位置信息（只基于物品本身的质量进行排序）。


小结
    

  • 排序层使用复杂深度模型进行多目标预估（CTR、CVR、时长），通过加权公式融合多目标
    • 

  • 重排序层关注推荐列表整体质量，MMR 和 DPP 是常用的多样性优化方法
    • 

  • 品类均衡、时效性提升和业务规则是重排序层的重要组成部分
    • 

  • 位置偏差校正（IPW、位置塔）确保排序模型学到的是物品本身的质量而非位置效应
    • 

  • 排序和重排序的效果优化需要通过在线 A/B 测试验证，离线指标仅作参考
    •
