序列推荐

核心概念

序列推荐（Sequential Recommendation）将用户的行为序列建模为时序信号，预测用户下一个可能交互的物品。与传统推荐方法将用户行为视为无序集合不同，序列推荐捕获用户兴趣的时序演变模式和物品之间的顺序依赖关系。

基于自注意力的序列推荐
SASRec（Self-Attentive Sequential Recommendation）将 Transformer 的自注意力机制引入序列推荐，是当前最主流的序列推荐架构。它将用户的行为序列类比为 "句子"，每个物品类比为 "词"，通过自注意力捕获序列中任意位置之间的依赖关系。


interface SASRecConfig {
  maxSeqLength: number;
  embeddingDim: number;
  numHeads: number;
  numBlocks: number;
  dropout: number;
}

function sasrecForward(
  itemSequence: string[],
  itemEmbeddings: Map<string, Float32Array>,
  positionEmbeddings: Float32Array[],
  attentionBlocks: AttentionBlock[],
  mask: boolean[],
): Float32Array {
  let hidden = itemSequence.map((item, i) => {
    const itemEmb = itemEmbeddings.get(item) ?? new Float32Array(positionEmbeddings[0].length);
    return addVec(itemEmb, positionEmbeddings[i]);
  });

  for (const block of attentionBlocks) {
    hidden = causalSelfAttention(hidden, mask, block);
    hidden = hidden.map((h) => feedForward(h, block.ffn));
  }

  return hidden[hidden.length - 1];
}

function causalSelfAttention(sequences: Float32Array[], mask: boolean[], block: AttentionBlock): Float32Array[] {
  const seqLen = sequences.length;
  const dim = sequences[0].length;
  const headDim = dim / block.numHeads;

  const queries = sequences.map((s) => matVecMul(block.wQ, s));
  const keys = sequences.map((s) => matVecMul(block.wK, s));
  const values = sequences.map((s) => matVecMul(block.wV, s));

  const outputs: Float32Array[] = [];
  for (let i = 0; i < seqLen; i++) {
    const scores: number[] = [];
    for (let j = 0; j <= i; j++) {
      if (!mask[j]) {
        scores.push(-Infinity);
        continue;
      }
      scores.push(dotProduct(queries[i], keys[j]) / Math.sqrt(headDim));
    }
    for (let j = i + 1; j < seqLen; j++) {
      scores.push(-Infinity);
    }
    const weights = softmax(new Float32Array(scores));
    const output = weightedSum(values, weights);
    outputs.push(output);
  }

  return outputs;
}
SASRec 使用因果注意力掩码（Causal Mask），确保位置 i 的预测只能看到位置 i 之前的信息。训练时采用 next-item prediction 目标，对序列中每个位置预测下一个物品。


BERT4Rec 与双向建模
BERT4Rec 将 BERT 的掩码语言模型（MLM）思想应用到序列推荐中。与 SASRec 的单向（左到右）建模不同，BERT4Rec 采用双向注意力，在训练时随机掩码序列中的部分物品，让模型基于上下文预测被掩码的物品。


interface BERT4RecConfig {
  maxSeqLength: number;
  embeddingDim: number;
  numHeads: number;
  numBlocks: number;
  maskRatio: number;
}

function maskSequence(
  sequence: string[],
  maskRatio: number,
  maskToken: string,
): { maskedSequence: string[]; maskedPositions: number[]; originalItems: string[] } {
  const maskedSequence = [...sequence];
  const maskedPositions: number[] = [];
  const originalItems: string[] = [];

  for (let i = 0; i < sequence.length; i++) {
    if (Math.random() < maskRatio) {
      maskedPositions.push(i);
      originalItems.push(sequence[i]);
      maskedSequence[i] = maskToken;
    }
  }

  return { maskedSequence, maskedPositions, originalItems };
}

function bert4recLoss(predictions: Float32Array[], maskedPositions: number[], originalItemIds: number[]): number {
  let loss = 0;
  for (let i = 0; i < maskedPositions.length; i++) {
    const pos = maskedPositions[i];
    const logits = predictions[pos];
    loss += crossEntropyLoss(logits, originalItemIds[i]);
  }
  return loss / maskedPositions.length;
}
BERT4Rec 在推理时将目标位置设为 [MASK]，利用双向上下文预测该位置的物品。实验表明双向建模在某些场景下优于单向模型，但在线推理时需要额外处理（不能像 SASRec 那样直接用最后一个位置的输出）。


会话推荐与图序列
会话推荐（Session-based Recommendation）针对匿名短期会话场景，用户可能没有长期历史记录，只有当前 session 内的行为序列。SR-GNN 将 session 内的物品序列构建为图结构，用图神经网络捕获物品之间的复杂转移关系。

会话推荐的核心挑战是在极短的行为序列（通常只有几个到十几个物品）中准确捕获用户的短期意图。


小结
    

  • 序列推荐将用户行为建模为时序信号，捕获兴趣的演变模式和物品间的顺序依赖
    • 

  • SASRec 通过因果自注意力实现高效的单向序列建模，是工业界最广泛使用的基线
    • 

  • BERT4Rec 的双向掩码预训练在某些场景下优于单向模型，但推理时需额外处理
    • 

  • 会话推荐（SR-GNN）用图结构建模 session 内物品的复杂转移关系，适合匿名短期场景
    • 

  • 序列推荐与传统 CF、深度模型的融合（如 DIN + SASRec）是工业实践的趋势
