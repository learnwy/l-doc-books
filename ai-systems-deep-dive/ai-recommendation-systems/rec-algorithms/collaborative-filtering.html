协同过滤

核心概念

协同过滤（Collaborative Filtering, CF）是推荐系统中最经典的范式，其核心思想是利用用户群体的行为模式进行推荐。协同过滤基于一个假设：如果用户 A 和用户 B 在过去对相同的物品有相似的偏好，那么 A 在未来也可能喜欢 B 喜欢但 A 还没有接触过的物品。

基于记忆的协同过滤
UserCF 和 ItemCF 直接利用用户-物品交互矩阵中的相似性信息进行推荐，不需要训练模型参数。


interface RatingMatrix {
  users: string[];
  items: string[];
  ratings: Map<string, Map<string, number>>;
}

function userSimilarity(userId1: string, userId2: string, matrix: RatingMatrix): number {
  const ratings1 = matrix.ratings.get(userId1) ?? new Map();
  const ratings2 = matrix.ratings.get(userId2) ?? new Map();
  const commonItems = [...ratings1.keys()].filter((item) => ratings2.has(item));

  if (commonItems.length === 0) return 0;

  let dotProduct = 0,
    norm1 = 0,
    norm2 = 0;
  for (const item of commonItems) {
    const r1 = ratings1.get(item)!;
    const r2 = ratings2.get(item)!;
    dotProduct += r1 * r2;
    norm1 += r1 * r1;
    norm2 += r2 * r2;
  }

  return dotProduct / (Math.sqrt(norm1) * Math.sqrt(norm2) + 1e-8);
}

function userCFRecommend(
  targetUser: string,
  matrix: RatingMatrix,
  topK: number,
  numNeighbors: number = 20,
): Array<{ item: string; score: number }> {
  const similarities = matrix.users
    .filter((u) => u !== targetUser)
    .map((u) => ({ userId: u, sim: userSimilarity(targetUser, u, matrix) }))
    .sort((a, b) => b.sim - a.sim)
    .slice(0, numNeighbors);

  const targetRated = matrix.ratings.get(targetUser) ?? new Map();
  const scores = new Map<string, number>();
  const simSums = new Map<string, number>();

  for (const { userId, sim } of similarities) {
    const neighborRatings = matrix.ratings.get(userId) ?? new Map();
    for (const [item, rating] of neighborRatings) {
      if (targetRated.has(item)) continue;
      scores.set(item, (scores.get(item) ?? 0) + sim * rating);
      simSums.set(item, (simSums.get(item) ?? 0) + Math.abs(sim));
    }
  }

  return [...scores.entries()]
    .map(([item, score]) => ({ item, score: score / (simSums.get(item)! + 1e-8) }))
    .sort((a, b) => b.score - a.score)
    .slice(0, topK);
}
ItemCF 计算物品之间的相似度，然后根据用户历史喜欢的物品推荐相似物品。相比 UserCF，ItemCF 的物品相似度矩阵更加稳定（因为物品属性变化慢于用户兴趣变化），更适合工业场景。Amazon 的 "购买了此商品的用户还购买了" 就是 ItemCF 的经典应用。


矩阵分解
矩阵分解（Matrix Factorization, MF）将用户-物品交互矩阵分解为两个低秩矩阵的乘积，每个用户和物品都用一个 k 维的隐因子向量表示。


interface MFModel {
  userFactors: Map<string, Float32Array>;
  itemFactors: Map<string, Float32Array>;
  userBias: Map<string, number>;
  itemBias: Map<string, number>;
  globalBias: number;
  latentDim: number;
}

function mfPredict(model: MFModel, userId: string, itemId: string): number {
  const userFactor = model.userFactors.get(userId);
  const itemFactor = model.itemFactors.get(itemId);
  if (!userFactor || !itemFactor) return model.globalBias;

  let dot = 0;
  for (let k = 0; k < model.latentDim; k++) {
    dot += userFactor[k] * itemFactor[k];
  }

  return model.globalBias + (model.userBias.get(userId) ?? 0) + (model.itemBias.get(itemId) ?? 0) + dot;
}

function sgdUpdate(
  model: MFModel,
  userId: string,
  itemId: string,
  rating: number,
  learningRate: number,
  regularization: number,
): void {
  const predicted = mfPredict(model, userId, itemId);
  const error = rating - predicted;

  const userFactor = model.userFactors.get(userId)!;
  const itemFactor = model.itemFactors.get(itemId)!;

  for (let k = 0; k < model.latentDim; k++) {
    const uGrad = error * itemFactor[k] - regularization * userFactor[k];
    const iGrad = error * userFactor[k] - regularization * itemFactor[k];
    userFactor[k] += learningRate * uGrad;
    itemFactor[k] += learningRate * iGrad;
  }
}
BPR（Bayesian Personalized Ranking）是处理隐式反馈（点击/浏览，无显式评分）场景下的矩阵分解方法。它优化的目标是：对于用户交互过的物品应该排在未交互过的物品之前，而不是预测具体的评分值。


隐式反馈建模
实际推荐系统中的用户反馈大多是隐式的（浏览、点击、购买），而非显式评分。隐式反馈的特点是只有正样本（用户交互过的物品），缺失数据既可能是用户不喜欢，也可能是用户没看到。

WMF（Weighted Matrix Factorization）为每个 user-item 对设置不同的权重：交互过的给高权重，未交互的给低权重。iALS（implicit Alternating Least Squares）是 WMF 的高效求解算法，通过交替固定用户/物品因子进行最小二乘优化。


小结
    

  • 协同过滤是推荐系统的基石范式，利用群体行为模式发现个人可能的兴趣
    • 

  • UserCF 适合兴趣多变的小规模场景，ItemCF 更稳定适合工业应用
    • 

  • 矩阵分解将用户和物品表示为隐因子向量，是协同过滤的核心方法
    • 

  • 隐式反馈建模（BPR、WMF）解决了实际场景中缺少显式评分的问题
    • 

  • 协同过滤的核心局限是冷启动和数据稀疏，需要与内容特征和知识图谱结合
    •
