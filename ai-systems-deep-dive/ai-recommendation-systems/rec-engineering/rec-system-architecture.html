推荐系统工程架构

核心概念

工业级推荐系统的工程架构采用漏斗式多阶段级联设计，从海量候选池中逐步筛选出最终展示给用户的推荐结果。整个流程分为召回（Retrieval）、粗排（Pre-ranking）、精排（Ranking）和重排（Re-ranking）四个阶段，每个阶段在候选集规模和计算复杂度之间做精确的权衡。这种分层架构是推荐系统从实验室走向生产环境的核心工程范式。

多路召回架构
召回阶段的核心挑战是在亿级物品池中快速检索出用户可能感兴趣的万级候选集。工业系统通常采用多路召回策略，每一路使用不同的召回源和算法，最终通过合并去重形成统一的候选集。


interface RecallSource {
  readonly name: string;
  readonly type: 'embedding' | 'collaborative' | 'content' | 'hot' | 'realtime';
  readonly quota: number;
  readonly timeout: number;
}

interface RecallConfig {
  readonly sources: ReadonlyArray<RecallSource>;
  readonly totalQuota: number;
  readonly mergeStrategy: 'union' | 'weighted-union' | 'cascade';
}

const defaultRecallConfig: RecallConfig = {
  sources: [
    { name: 'i2i-swing', type: 'collaborative', quota: 200, timeout: 20 },
    { name: 'u2i-dssm', type: 'embedding', quota: 300, timeout: 30 },
    { name: 'u2i-mind', type: 'embedding', quota: 200, timeout: 30 },
    { name: 'u2tag2i', type: 'content', quota: 100, timeout: 15 },
    { name: 'hot-trending', type: 'hot', quota: 50, timeout: 10 },
    { name: 'realtime-seq', type: 'realtime', quota: 150, timeout: 25 },
  ],
  totalQuota: 1000,
  mergeStrategy: 'weighted-union',
};

interface RecallCandidate {
  readonly itemId: number;
  readonly source: string;
  readonly score: number;
  readonly retrievalTimestamp: number;
}

const mergeRecallResults = (
  results: ReadonlyMap<string, ReadonlyArray<RecallCandidate>>,
  config: RecallConfig,
): ReadonlyArray<RecallCandidate> => {
  const merged = new Map<number, RecallCandidate>();

  for (const [source, candidates] of results) {
    for (const candidate of candidates) {
      const existing = merged.get(candidate.itemId);
      if (!existing || candidate.score > existing.score) {
        merged.set(candidate.itemId, candidate);
      }
    }
  }

  return [...merged.values()].sort((a, b) => b.score - a.score).slice(0, config.totalQuota);
};
多路召回的关键设计决策包括：各路配额分配（根据在线 AB 测试的 RPV 贡献动态调整）、超时降级（某路超时不影响整体）和去重策略（同一物品被多路召回时保留最高分或合并分数）。


精排与特征交互
精排阶段是推荐效果的核心战场，需要在千级候选集上使用复杂的深度模型进行精细化排序。精排模型的核心挑战是高效地建模海量稀疏特征之间的交互关系。

多目标排序是工业精排的标准范式。推荐系统需要同时优化点击率（CTR）、转化率（CVR）、停留时长、点赞率等多个目标。ESMM 解决了 CVR 预估的样本选择偏差问题，MMoE 和 PLE 通过共享专家和任务特定门控来平衡多任务间的参数共享与冲突。

重排与多样性
重排阶段在精排输出的有序列表上进行全局调整，核心目标是在保持排序准确性的同时提升结果的多样性、新鲜度和业务约束满足度。与精排的 pointwise 评估不同，重排需要 listwise 地考虑物品之间的关系。


多样性是重排的核心优化维度。MMR（Maximal Marginal Relevance）在选择下一个展示物品时同时考虑相关性和与已选物品的差异性。DPP（Determinantal Point Process）从概率论角度建模集合的多样性，行列式值越大表示集合中元素间的相似度越低、多样性越高。


interface ReRankConfig {
  readonly diversityWeight: number;
  readonly freshness: {
    readonly boostNewItems: boolean;
    readonly newItemThresholdHours: number;
    readonly boostFactor: number;
  };
  readonly businessRules: ReadonlyArray<{
    readonly type: 'category-spread' | 'brand-limit' | 'price-mix';
    readonly param: number;
  }>;
}

const mmrReRank = (
  candidates: ReadonlyArray<{
    readonly itemId: number;
    readonly score: number;
    readonly embedding: ReadonlyArray<number>;
  }>,
  config: ReRankConfig,
  topK: number,
): ReadonlyArray<number> => {
  const selected: number[] = [];
  const remaining = new Set(candidates.map((_, i) => i));

  while (selected.length < topK && remaining.size > 0) {
    let bestIdx = -1;
    let bestMMR = -Infinity;

    for (const idx of remaining) {
      const relevance = candidates[idx].score;
      const maxSim =
        selected.length === 0
          ? 0
          : Math.max(
              ...selected.map((sIdx) => cosineSimilarity(candidates[idx].embedding, candidates[sIdx].embedding)),
            );
      const mmrScore = (1 - config.diversityWeight) * relevance - config.diversityWeight * maxSim;
      if (mmrScore > bestMMR) {
        bestMMR = mmrScore;
        bestIdx = idx;
      }
    }

    if (bestIdx >= 0) {
      selected.push(bestIdx);
      remaining.delete(bestIdx);
    }
  }

  return selected.map((idx) => candidates[idx].itemId);
};

const cosineSimilarity = (a: ReadonlyArray<number>, b: ReadonlyArray<number>): number => {
  const dot = a.reduce((sum, val, i) => sum + val * b[i], 0);
  const normA = Math.sqrt(a.reduce((sum, val) => sum + val * val, 0));
  const normB = Math.sqrt(b.reduce((sum, val) => sum + val * val, 0));
  return normA * normB > 0 ? dot / (normA * normB) : 0;
};
小结
    

  • 工业推荐系统采用召回→粗排→精排→重排的四阶段漏斗架构
    • 

  • 多路召回通过并行化不同算法来最大化候选覆盖，配额分配和超时降级是关键工程设计
    • 

  • 精排通过多目标排序（MMoE/PLE）同时优化 CTR、CVR 等多维指标
    • 

  • 重排通过 MMR、DPP 等算法提升结果多样性，同时满足业务约束
    • 

  • 各阶段之间通过 RPC 通信，特征服务和模型服务独立部署，支持独立迭代
    • 

  • 架构演进方向包括端到端学习、召回-排序联合优化和因果推断去偏
    •
