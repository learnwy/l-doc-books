推荐效果评估

核心概念

推荐效果评估是衡量推荐系统质量的系统方法论，贯穿模型开发、上线验证和持续优化的全生命周期。评估体系分为离线评估、在线评估和长期评估三个层次：离线评估基于历史数据快速筛选候选模型，在线评估通过 AB 测试验证真实效果，长期评估追踪推荐系统对用户留存和生态健康的影响。科学的评估体系是推荐系统持续进化的基础设施。

离线评估指标体系
离线评估使用历史用户行为数据来评估模型的预测准确性。根据评估粒度分为 pointwise、pairwise 和 listwise 三类指标，分别对应不同的评估视角。

const computeAUC = (predictions: ReadonlyArray<{ readonly score: number; readonly label: number }>): number => {
  const sorted = [...predictions].sort((a, b) => b.score - a.score);
  let posCount = 0;
  let negCount = 0;
  let posRankSum = 0;

  for (let i = 0; i < sorted.length; i++) {
    if (sorted[i].label === 1) {
      posCount++;
      posRankSum += i + 1;
    } else {
      negCount++;
    }
  }

  if (posCount === 0 || negCount === 0) return 0.5;
  return (posRankSum - (posCount * (posCount + 1)) / 2) / (posCount * negCount);
};

const computeGAUC = (
  userPredictions: ReadonlyMap<string, ReadonlyArray<{ readonly score: number; readonly label: number }>>,
): number => {
  let weightedAUCSum = 0;
  let totalImpressions = 0;

  for (const [_, predictions] of userPredictions) {
    const hasPos = predictions.some((p) => p.label === 1);
    const hasNeg = predictions.some((p) => p.label === 0);
    if (!hasPos || !hasNeg) continue;

    const auc = computeAUC(predictions);
    const weight = predictions.length;
    weightedAUCSum += auc * weight;
    totalImpressions += weight;
  }

  return totalImpressions > 0 ? weightedAUCSum / totalImpressions : 0.5;
};

const computeNDCG = (rankedItems: ReadonlyArray<number>, relevantItems: ReadonlySet<number>, k: number): number => {
  const dcg = rankedItems.slice(0, k).reduce((sum, itemId, i) => {
    const rel = relevantItems.has(itemId) ? 1 : 0;
    return sum + rel / Math.log2(i + 2);
  }, 0);

  const idealRanking = Math.min(k, relevantItems.size);
  const idcg = Array.from({ length: idealRanking }, (_, i) => 1 / Math.log2(i + 2)).reduce((a, b) => a + b, 0);

  return idcg > 0 ? dcg / idcg : 0;
};
GAUC（Group AUC）是工业推荐系统最重要的离线指标。与全局 AUC 不同，GAUC 先计算每个用户的 AUC，再按曝光量加权平均。这消除了不同用户行为活跃度差异带来的偏差，更真实地反映模型对每个用户的排序能力。

在线 AB 测试
在线 AB 测试是推荐系统效果验证的金标准。通过将线上用户流量随机分配到实验组和对照组，在相同条件下对比不同推荐策略的效果差异。


interface ABTestConfig {
  readonly experimentId: string;
  readonly experimentName: string;
  readonly groups: ReadonlyArray<{
    readonly groupId: string;
    readonly trafficPercent: number;
    readonly modelConfig: string;
  }>;
  readonly metrics: ReadonlyArray<{
    readonly name: string;
    readonly type: 'primary' | 'secondary' | 'guardrail';
    readonly direction: 'higher-better' | 'lower-better';
    readonly minimumDetectableEffect: number;
  }>;
  readonly duration: {
    readonly minDays: number;
    readonly maxDays: number;
    readonly earlyStoppingEnabled: boolean;
  };
  readonly hashSalt: string;
}

interface ABTestResult {
  readonly experimentId: string;
  readonly groupResults: ReadonlyArray<{
    readonly groupId: string;
    readonly sampleSize: number;
    readonly metrics: ReadonlyMap<
      string,
      {
        readonly mean: number;
        readonly variance: number;
        readonly confidenceInterval: readonly [number, number];
      }
    >;
  }>;
  readonly pValues: ReadonlyMap<string, number>;
  readonly significant: ReadonlyMap<string, boolean>;
}

const assignUserToGroup = (userId: string, config: ABTestConfig): string => {
  const hash = simpleHash(userId + config.hashSalt);
  const bucket = hash % 10000;
  let cumulative = 0;

  for (const group of config.groups) {
    cumulative += group.trafficPercent * 100;
    if (bucket < cumulative) return group.groupId;
  }

  return config.groups[config.groups.length - 1].groupId;
};

const simpleHash = (str: string): number => {
  let hash = 0;
  for (let i = 0; i < str.length; i++) {
    const char = str.charCodeAt(i);
    hash = (hash << 5) - hash + char;
    hash = hash & hash;
  }
  return Math.abs(hash);
};

const computeStatisticalSignificance = (
  controlMean: number,
  controlVariance: number,
  controlN: number,
  treatmentMean: number,
  treatmentVariance: number,
  treatmentN: number,
): { readonly zScore: number; readonly pValue: number } => {
  const seDiff = Math.sqrt(controlVariance / controlN + treatmentVariance / treatmentN);
  const zScore = seDiff > 0 ? (treatmentMean - controlMean) / seDiff : 0;
  const pValue = 2 * (1 - normalCDF(Math.abs(zScore)));
  return { zScore, pValue };
};

const normalCDF = (x: number): number => {
  const a1 = 0.254829592;
  const a2 = -0.284496736;
  const a3 = 1.421413741;
  const a4 = -1.453152027;
  const a5 = 1.061405429;
  const p = 0.3275911;
  const sign = x < 0 ? -1 : 1;
  const absX = Math.abs(x) / Math.sqrt(2);
  const t = 1.0 / (1.0 + p * absX);
  const y = 1.0 - ((((a5 * t + a4) * t + a3) * t + a2) * t + a1) * t * Math.exp(-absX * absX);
  return 0.5 * (1.0 + sign * y);
};
AB 测试的常见陷阱包括：样本量不足导致假阴性（需要预先做 Power Analysis）、网络效应导致 SUTVA 假设违反（社交推荐场景）、新奇效应导致短期指标虚高、以及 Simpson 悖论（整体指标提升但特定用户群下降）。


长期效果与生态评估
推荐系统的短期指标优化可能以牺牲长期用户体验为代价。过度优化 CTR 可能导致标题党泛滥，过度推荐热门物品可能导致马太效应和长尾生态萎缩。长期效果评估需要超越单次点击，关注用户留存、内容生态多样性和创作者激励等系统性指标。

const computeGiniCoefficient = (values: ReadonlyArray<number>): number => {
  const sorted = [...values].sort((a, b) => a - b);
  const n = sorted.length;
  const totalSum = sorted.reduce((a, b) => a + b, 0);
  if (totalSum === 0 || n === 0) return 0;

  let cumulativeSum = 0;
  let giniSum = 0;
  for (let i = 0; i < n; i++) {
    cumulativeSum += sorted[i];
    giniSum += (2 * (i + 1) - n - 1) * sorted[i];
  }

  return giniSum / (n * totalSum);
};

小结
    

  • 推荐评估体系分为离线评估、在线 AB 测试和长期生态评估三个层次
    • 

  • GAUC 是工业推荐最重要的离线指标，消除了用户间活跃度差异的偏差
    • 

  • AB 测试是效果验证的金标准，需要预先做 Power Analysis 并防范新奇效应等陷阱
    • 

  • 长期评估关注基尼系数、覆盖率等生态指标，防止短期优化损害系统健康
    • 

  • 科学的评估体系需要离线、在线和长期指标三者协同，避免单一维度优化
    • 

  • 因果推断方法（如 Debiased Evaluation）是解决离线评估偏差的前沿方向
