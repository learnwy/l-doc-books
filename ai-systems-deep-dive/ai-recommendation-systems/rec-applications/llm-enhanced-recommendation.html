LLM 增强推荐

核心概念

LLM 增强推荐（LLM-Enhanced Recommendation）是将大语言模型的强大语言理解和推理能力融入推荐系统的新范式。LLM 能够理解物品的文本描述、用户的自然语言偏好表达以及复杂的推荐上下文，为传统推荐系统带来语义理解和零样本泛化的新能力。

LLM 作为特征提取器
最直接的 LLM 增强方式是利用 LLM 为物品和用户生成高质量的语义特征。LLM 生成的文本嵌入、摘要和标签可以作为传统推荐模型的输入特征。


interface LLMFeatureConfig {
  model: string;
  batchSize: number;
  maxTokens: number;
  cacheEnabled: boolean;
}

async function generateItemFeatures(item: ItemInfo, llm: LLMClient): Promise<LLMItemFeatures> {
  const titleEmbedding = await llm.embed(item.title);
  const descEmbedding = await llm.embed(item.description);

  const tagsPrompt = `分析以下商品信息，生成5个精确的标签：
标题：${item.title}
描述：${item.description}
品类：${item.category}
请以JSON数组格式返回标签：`;

  const tagsResponse = await llm.generate(tagsPrompt);
  const tags = JSON.parse(tagsResponse);

  return {
    itemId: item.id,
    titleEmbedding,
    descEmbedding,
    llmTags: tags,
    enrichedDescription: await summarizeItem(item, llm),
  };
}

interface LLMItemFeatures {
  itemId: string;
  titleEmbedding: Float32Array;
  descEmbedding: Float32Array;
  llmTags: string[];
  enrichedDescription: string;
}

async function generateUserProfile(interactions: UserInteraction[], llm: LLMClient): Promise<string> {
  const recentItems = interactions
    .slice(-10)
    .map((i) => i.itemTitle)
    .join('\n');
  const prompt = `基于以下用户最近浏览的商品，总结用户的兴趣偏好（100字以内）：
${recentItems}`;
  return llm.generate(prompt);
}
LLM 生成的特征在冷启动场景（新物品没有行为数据）中尤为有价值。传统推荐系统对新物品只能依赖有限的属性信息，而 LLM 可以从商品标题和描述中提取丰富的语义信号。


对话式推荐
对话式推荐（Conversational Recommendation）利用 LLM 的自然语言对话能力，通过多轮交互理解用户需求并提供个性化推荐。


interface ConversationalRecConfig {
  llm: LLMClient;
  recEngine: RecEngine;
  maxTurns: number;
  slotSchema: SlotSchema;
}

interface SlotSchema {
  category: string[];
  priceRange: string[];
  brand: string[];
  features: string[];
  occasion: string[];
}

interface ConversationState {
  slots: Partial<Record<keyof SlotSchema, string>>;
  history: ChatMessage[];
  candidates: RecItem[];
  confidence: number;
}

async function conversationalRecommend(
  userMessage: string,
  state: ConversationState,
  config: ConversationalRecConfig,
): Promise<{ response: string; items: RecItem[]; newState: ConversationState }> {
  const extractedSlots = await extractSlots(userMessage, config.slotSchema, config.llm);
  const updatedSlots = { ...state.slots, ...extractedSlots };

  const filledCount = Object.values(updatedSlots).filter(Boolean).length;
  const totalSlots = Object.keys(config.slotSchema).length;

  if (filledCount / totalSlots < 0.4) {
    const clarifyQuestion = await generateClarification(updatedSlots, config.slotSchema, config.llm);
    return {
      response: clarifyQuestion,
      items: [],
      newState: { ...state, slots: updatedSlots },
    };
  }

  const candidates = await config.recEngine.search(updatedSlots);
  const topItems = candidates.slice(0, 5);
  const explanation = await generateRecExplanation(topItems, updatedSlots, config.llm);

  return {
    response: explanation,
    items: topItems,
    newState: { ...state, slots: updatedSlots, candidates: topItems },
  };
}
对话推荐的核心挑战包括：意图理解的准确性、多轮对话的一致性和推荐结果与对话的协调性。实际系统中，通常将 LLM 的对话能力与传统推荐引擎的召回排序能力结合，LLM 负责理解和表达，传统引擎负责检索和排序。


推荐解释生成
LLM 可以为推荐结果生成自然语言的解释，帮助用户理解为什么被推荐某个物品，提升用户对推荐系统的信任度和接受度。

小结
    

  • LLM 增强推荐将语言理解和推理能力融入推荐系统，带来语义理解和零样本泛化的新能力
    • 

  • LLM 作为特征提取器可以显著改善冷启动问题，为新物品提供丰富的语义特征
    • 

  • 对话式推荐通过多轮交互理解用户需求，适合复杂决策场景（如导购、旅行规划）
    • 

  • 推荐解释生成提升用户信任度，LLM 可以综合多维数据生成自然流畅的解释
    • 

  • LLM 在推荐中的应用仍面临延迟、成本和一致性等工程挑战，需要与传统方法互补使用
