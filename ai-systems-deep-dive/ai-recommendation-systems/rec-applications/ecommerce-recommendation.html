电商推荐

核心概念

电商推荐（E-commerce Recommendation）是推荐系统在电子商务场景中的核心应用，通过个性化的商品推荐提升用户购物体验和平台转化效率。电商推荐涵盖首页推荐、搜索结果页推荐、商品详情页推荐和购物车推荐等多个场景，每个场景有不同的用户意图和推荐策略。

多场景推荐架构
电商平台通常需要支持数十个推荐场景，每个场景有不同的数据分布和业务目标。多场景推荐通过共享底层模型和特征来提升效率，同时为每个场景定制上层策略。


interface MultiSceneConfig {
  scenes: SceneConfig[];
  sharedModel: SharedModelConfig;
  featureStore: FeatureStoreConfig;
}

interface SceneConfig {
  sceneId: string;
  name: string;
  recallChannels: RecallChannel[];
  rankModel: string;
  reRankStrategy: string;
  listSize: number;
  diversityWeight: number;
  businessRules: BusinessRule[];
}

interface SceneSpecificModel {
  sceneId: string;
  expertNetwork: MLPLayer[];
  gateNetwork: MLPLayer;
  towerNetwork: MLPLayer[];
}

async function multiSceneRecommend(
  userId: string,
  sceneId: string,
  context: RequestContext,
  config: MultiSceneConfig,
): Promise<RecItem[]> {
  const sceneConfig = config.scenes.find((s) => s.sceneId === sceneId)!;
  const userFeatures = await config.featureStore.getUserFeatures(userId);
  const candidates = await multiChannelRecall(userId, sceneConfig.recallChannels);
  const ranked = await sceneAwareRank(candidates, userFeatures, sceneId, config.sharedModel);
  return applySceneReRank(ranked, sceneConfig);
}
STAR（Star Topology Adaptive Recommender）是阿里巴巴提出的多场景推荐模型，使用星型拓扑结构共享中心网络的参数，同时为每个场景维护独立的辅助网络。


多场景推荐面临的核心挑战是场景之间的数据分布差异。首页推荐的用户以浏览为主，点击率相对较低但覆盖面广；搜索推荐的用户有明确的购买意图，转化率显著更高但流量较少。简单的模型共享会导致高流量场景主导模型训练，低流量场景效果不佳。STAR 通过场景特定的辅助网络解决这个问题，中心网络学习跨场景的通用知识，辅助网络捕获场景特有的分布模式。

商品属性与搭配推荐
商品属性理解和搭配推荐是电商推荐的特色需求。商品之间的关系不仅有替代关系（相似商品），还有互补关系（搭配商品），推荐系统需要区分这两种关系。


type ItemRelation = 'substitute' | 'complement' | 'accessory' | 'upgrade';

interface ItemRelationPair {
  item1: string;
  item2: string;
  relation: ItemRelation;
  confidence: number;
  source: 'co_purchase' | 'co_view' | 'expert' | 'model';
}

function computeComplementScore(
  item1: string,
  item2: string,
  coPurchaseData: Map<string, Map<string, number>>,
  coViewData: Map<string, Map<string, number>>,
): number {
  const coPurchase = coPurchaseData.get(item1)?.get(item2) ?? 0;
  const coView = coViewData.get(item1)?.get(item2) ?? 0;
  const viewToPurchaseRatio = coPurchase / (coView + 1);
  return viewToPurchaseRatio;
}
搭配推荐的典型应用包括 "购买了这件衬衫的用户还购买了这条领带"（协同过滤搭配）、"这件外套搭配推荐"（时尚搭配模型）和 "凑单推荐"（基于价格和满减规则的组合优化）。


凑单推荐是电商特有的推荐场景，当用户的购物车金额接近满减门槛时，系统推荐价格合适且用户可能感兴趣的商品帮助用户凑满减。这个问题可以建模为带约束的组合优化：在满足价格约束的前提下，最大化用户对推荐组合的兴趣得分。


interface CouponMatchConfig {
  threshold: number;
  currentCartValue: number;
  maxRecommendations: number;
}

function couponMatchRecommend(
  gap: number,
  candidates: Array<{ itemId: string; price: number; score: number }>,
  config: CouponMatchConfig,
): Array<{ itemId: string; price: number; score: number }> {
  const eligible = candidates.filter((c) => c.price >= gap * 0.8 && c.price <= gap * 1.5);
  return eligible
    .sort((a, b) => {
      const priceScoreA = 1 - Math.abs(a.price - gap) / gap;
      const priceScoreB = 1 - Math.abs(b.price - gap) / gap;
      return 0.6 * b.score + 0.4 * priceScoreB - (0.6 * a.score + 0.4 * priceScoreA);
    })
    .slice(0, config.maxRecommendations);
}
价格敏感度与促销策略
电商推荐需要深度理解用户的价格敏感度和促销响应模式。不同用户对价格的敏感程度差异巨大，推荐系统需要为每个用户推荐合适价位段的商品。

小结
    

  • 电商推荐覆盖首页、搜索、详情页、购物车等多个场景，各场景有不同的用户意图和策略
    • 

  • 多场景推荐通过共享底层模型和特征提效，STAR 等方法实现场景间的知识共享
    • 

  • 商品关系理解（替代/互补）是电商推荐的特色需求，搭配推荐直接提升客单价
    • 

  • 价格敏感度建模帮助为不同用户推荐合适价位段的商品，提升转化率
    • 

  • 电商推荐的终极目标是平衡用户体验（满意度）、商业价值（GMV）和生态健康（商家公平）
