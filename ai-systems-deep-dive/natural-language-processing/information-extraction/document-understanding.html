文档理解

核心概念

文档理解（Document Understanding）致力于从复杂版式文档中提取和理解信息。真实世界的文档——PDF 报告、扫描合同、发票、网页表单——不仅包含文本内容，还包含布局结构、字体样式、图表和图像等丰富的视觉信息。传统的 NLP 技术只处理纯文本，无法利用这些视觉线索。文档理解通过融合文本、布局和视觉三种模态的信息，实现对真实文档的深层理解，是金融、法律、医疗等行业数字化转型的关键技术。

文档理解的核心挑战在于多模态信息的有效融合。一个数字出现在文档的什么位置（左上角还是表格内）、用什么字体（加粗还是普通）、和哪些文字相邻——这些布局和视觉信息对理解文档语义至关重要。


版面分析与 OCR
版面分析（Layout Analysis）是文档理解的第一步，目标是将文档页面分割为不同的功能区域——标题、正文、图片、表格、页眉页脚等。传统方法基于规则和启发式算法（如连通组件分析、投影分析），现代方法使用目标检测模型（如 Faster R-CNN、YOLO）将版面分析建模为检测问题。


from dataclasses import dataclass

@dataclass
class LayoutBlock:
    block_type: str
    bbox: tuple[float, float, float, float]
    text: str
    confidence: float
    reading_order: int

@dataclass
class DocumentPage:
    page_id: int
    width: float
    height: float
    blocks: list[LayoutBlock]

    def get_blocks_by_type(self, block_type: str) -> list[LayoutBlock]:
        return [b for b in self.blocks if b.block_type == block_type]
OCR（Optical Character Recognition）将文档图像中的文字识别为可编辑的文本。现代 OCR 系统通常采用两阶段架构：文本检测（定位文字区域的位置和边界）和文本识别（将定位到的文字区域转换为字符串）。DBNet 是常用的文本检测模型，CRNN（CNN + RNN + CTC）是经典的文本识别架构。端到端的 OCR 模型直接从图像输出文字序列，省略了检测和识别的分离。

LayoutLM 系列模型
LayoutLM 系列是文档理解领域最具影响力的预训练模型族。核心思想是在 BERT 类模型中引入空间位置信息——除了文本嵌入和位置嵌入，还加入了二维布局嵌入（文字在页面上的 x, y 坐标和宽高信息）。


LayoutLM v1 在 BERT 的基础上添加了 2D 位置嵌入。每个 token 不仅有文本嵌入和一维序列位置嵌入，还有四个坐标嵌入（左上角 x, y 和右下角 x, y）。这使得模型能够理解文档的空间结构——例如，表格标题通常在表格上方，金额通常在发票右下角。


LayoutLM v2 引入了视觉嵌入——使用 CNN 编码器提取文档图像的视觉特征，与文本嵌入和布局嵌入一起输入 Transformer。视觉信息帮助模型识别加粗标题、表格线框和印章等纯文本无法表达的特征。


LayoutLM v3 统一了文本和图像的预训练——使用掩码语言模型（MLM）和掩码图像模型（MIM）联合训练，并引入了词-补丁对齐（Word-Patch Alignment）目标来对齐文本 token 和图像补丁。这使得模型能够更好地融合跨模态信息。


关键信息抽取
关键信息抽取（Key Information Extraction，KIE）是文档理解最重要的应用——从发票、收据、合同等文档中提取关键字段（如日期、金额、卖方名称等）。这一任务的核心挑战是：不同来源的文档布局差异巨大，但需要提取的字段类型是固定的。


序列标注方法将 KIE 建模为 token 级别的分类问题——每个 token 被标注为特定字段的开始（B）、内部（I）或非关键（O）。LayoutLM 系列模型在这种方法上取得了显著效果——在 FUNSD（表单理解）和 CORD（收据理解）数据集上，LayoutLM v3 的 F1 分数达到了 92% 以上。


图方法将文档建模为图结构——每个文本段作为节点，空间邻近关系和语义关系作为边。图神经网络在这个图上传播信息，利用全局的布局结构来辅助关键信息的定位和分类。这种方法特别适合处理键值对形式的信息——"日期："和"2024-03-15"在布局上相邻，图方法能有效捕捉这种空间关联。


大语言模型在 KIE 中展现出强大的零样本能力。通过将文档转换为结构化文本表示（包含坐标信息），配合精心设计的提示，GPT-4V 等多模态模型能够直接从文档图像中提取关键信息，无需任何领域特定训练。


小结
    

  • 文档理解融合文本、布局和视觉三种模态信息，理解真实文档的语义
    • 

  • 版面分析和 OCR 是文档理解的基础，为下游任务提供结构化输入
    • 

  • LayoutLM 系列通过二维布局嵌入和视觉嵌入将空间信息引入预训练模型
    • 

  • 关键信息抽取是最重要的应用，序列标注和图方法是两种主流技术路线
    • 

  • 大语言模型在文档理解中展现出强大的零样本能力，降低了领域适配成本
    • 

  • 工业应用需要处理文档质量差异、多语言混排和隐私合规等工程挑战
