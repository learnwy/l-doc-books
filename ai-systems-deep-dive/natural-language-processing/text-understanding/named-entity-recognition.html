命名实体识别

核心概念

命名实体识别（Named Entity Recognition，NER）是从非结构化文本中定位并分类命名实体的任务。实体类型通常包括人名（PER）、地名（LOC）、组织名（ORG）、时间（TIME）、数量（NUM）等。NER 是信息抽取的基石，为知识图谱构建、搜索引擎优化、智能客服意图理解等应用提供基础能力。从技术角度看，NER 是一个序列标注问题——为输入序列的每个 token 分配一个标签。

序列标注的标签体系是 NER 的基础。BIO 标注体系用三种标签标记每个 token：B-TYPE（实体开始）、I-TYPE（实体内部）、O（非实体）。BIOES 标注体系增加了 E-TYPE（实体结尾）和 S-TYPE（单字实体），提供更精细的边界信息。实践表明，BIOES 在大部分数据集上略优于 BIO，因为它为解码器提供了更明确的实体边界信号。


BiLSTM-CRF 架构
BiLSTM-CRF 是经典的 NER 架构，由三个组件构成：嵌入层将 token 映射为向量（可包括词向量、字符级向量和手工特征的拼接），BiLSTM 编码器将输入序列编码为上下文相关的隐状态序列，CRF 层建模标签之间的转移约束。


CRF 层的关键价值在于它学习了标签之间的合法转移模式。例如，I-PER 不应该出现在 B-LOC 之后（人名实体内部不应跟随地名开始标签）。没有 CRF 层的 Softmax 模型会独立预测每个位置的标签，可能产生这种非法序列。CRF 的转移矩阵 AAA 中，AijA_{ij}Aij​ 表示从标签 iii 转移到标签 jjj 的得分。


import torch
import torch.nn as nn

class BiLSTMCRF(nn.Module):
    def __init__(self, vocab_size: int, embed_dim: int, hidden_dim: int, num_tags: int):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden_dim // 2, bidirectional=True, batch_first=True)
        self.hidden2tag = nn.Linear(hidden_dim, num_tags)
        self.transitions = nn.Parameter(torch.randn(num_tags, num_tags))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        embeds = self.embedding(x)
        lstm_out, _ = self.lstm(embeds)
        emissions = self.hidden2tag(lstm_out)
        return emissions
维特比算法是 CRF 解码的标准方法。它利用动态规划在所有可能的标签序列中找到全局最优路径，时间复杂度为 O(T×K2)O(T \times K^2)O(T×K2)，其中 TTT 是序列长度，KKK 是标签数量。训练时使用前向-后向算法计算配分函数，损失函数为负对数似然。


BERT 时代的 NER
BERT 的引入大幅提升了 NER 的性能。标准做法是将 BERT 作为编码器，在其输出上接 CRF 层或简单的 Softmax 分类层。BERT-CRF 通常优于 BERT-Softmax，但在标注数据充足时差距缩小——BERT 的深层上下文表示已经隐式学习了很多标签转移规律。


子词分词带来了对齐问题。BERT 的 WordPiece 分词可能将一个词切分为多个子词 token（如 "Washington" → "Wash" + "##ington"），但 NER 的标注是词级别的。常见的处理策略是只取每个词的第一个子词 token 的输出进行标注，忽略后续子词。


微调策略对 NER 性能影响显著。使用 BERT 最后四层的加权和而非只用最后一层能提升约 0.5-1 个 F1 点。在低资源场景下，逐层解冻（先冻结 BERT 只训练 CRF 层，再逐步解冻 BERT 上层）能避免过拟合。学习率通常设为 2e-5 到 5e-5 之间，CRF 层可以使用更大的学习率。


嵌套实体与跨度方法
传统的序列标注方法无法处理嵌套实体——当一个实体内部包含另一个实体时（如"中国科学院上海分院"中，"中国科学院"和"上海"分别是 ORG 和 LOC 实体）。基于跨度（Span-based）的方法通过枚举所有可能的文本片段并对每个片段进行分类来解决这一问题。


Span-based NER 的核心思想是：枚举文本中所有长度不超过 LLL 的跨度（起始位置 iii 到结束位置 jjj），将每个跨度表示为对应位置隐状态的拼接或池化，然后用分类器判断该跨度是否是某种类型的实体。这种方法天然支持嵌套实体，因为不同跨度之间是独立分类的。

少样本 NER 是当前的热门研究方向。在新领域（如医学、法律）中，标注 NER 数据的成本极高。基于原型网络的方法为每个实体类型构建原型向量，通过距离度量进行分类；基于提示学习的方法将 NER 转化为阅读理解问题——"文本中有哪些人名？"——利用预训练模型的阅读理解能力进行零/少样本实体识别。


小结
    

  • NER 是序列标注问题，BIO/BIOES 标注体系定义了标签空间
    • 

  • BiLSTM-CRF 是经典架构，CRF 层确保标签序列的全局一致性
    • 

  • BERT 微调大幅提升了 NER 性能，子词对齐和层级特征融合是关键细节
    • 

  • 嵌套实体需要 Span-based 方法，突破了序列标注"每个 token 一个标签"的限制
    • 

  • 少样本 NER 通过原型网络和提示学习降低了对标注数据的依赖
    • 

  • 工业应用中，NER 往往需要与规则系统配合，处理地址、电话等格式化实体
