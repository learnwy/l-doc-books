文本分类

核心概念

文本分类是 NLP 中最基础也最广泛应用的任务——给定一段文本，将其归入一个或多个预定义的类别。从垃圾邮件过滤、新闻分类到意图识别、情感极性判断，文本分类无处不在。它之所以重要，不仅因为自身的应用价值，更因为它是理解"如何将预训练模型迁移到下游任务"的最佳入口。文本分类的技术演进——从特征工程到深度学习再到预训练微调——浓缩了整个 NLP 技术发展的缩影。

文本分类根据标签结构可分为：二分类（正/负）、多分类（互斥标签集）、多标签分类（非互斥标签集）和层次分类（标签具有树形结构）。不同的标签结构决定了损失函数的选择——单标签用交叉熵，多标签用二元交叉熵。


传统方法与特征工程
在深度学习之前，文本分类的核心挑战是特征工程——如何将文本转化为机器学习模型可以处理的数值特征。最基础的方法是词袋模型（Bag of Words），将文本表示为词频向量，完全忽略词序。TF-IDF 在词频基础上加入逆文档频率加权，降低高频但信息量低的词（如"的"、"是"）的权重，突出有区分力的词。


N-gram 特征通过引入连续词组来部分保留词序信息。Bigram "not good" 能够区分出否定语义，而 Unigram 单独看 "not" 和 "good" 无法做到。但 N-gram 的维度爆炸问题限制了 N 的大小——实践中通常只用到 Bigram 或 Trigram。


朴素贝叶斯分类器假设特征条件独立，虽然这个假设在文本数据上显然不成立，但朴素贝叶斯在许多分类任务上仍表现出色。多项式朴素贝叶斯适合词频特征，伯努利朴素贝叶斯适合二值特征。SVM 通过寻找最大间隔超平面来分离类别，配合 TF-IDF 特征和线性核函数，是深度学习之前文本分类的黄金标准。


from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import LinearSVC
from sklearn.pipeline import Pipeline

def build_text_classifier() -> Pipeline:
    return Pipeline([
        ('tfidf', TfidfVectorizer(
            max_features=50000,
            ngram_range=(1, 2),
            sublinear_tf=True
        )),
        ('clf', LinearSVC(C=1.0, max_iter=1000))
    ])
深度学习分类模型
TextCNN 是将卷积神经网络应用于文本分类的里程碑工作。其核心思想是用不同宽度的一维卷积核（通常为 3、4、5）在词向量序列上滑动，捕捉不同长度的局部 N-gram 特征。每个卷积核的输出经过最大池化（取序列中最显著的特征值），然后拼接所有卷积核的输出送入全连接分类层。TextCNN 的优点是训练速度快、并行度高，缺点是最大池化丢失了位置信息。


BiLSTM 模型用双向 LSTM 编码文本序列，将前向和后向最后时刻的隐状态拼接作为文本表示。注意力机制的引入（BiLSTM + Attention）让模型能够自动学习哪些词对分类更重要，比简单取最后隐状态更有效。


预训练模型的微调方案彻底改变了文本分类的实践方式。BERT 微调的标准做法是在 [CLS] token 的最后一层隐状态上接一个线性分类头，然后用任务数据端到端微调整个模型。这种方法在大多数基准数据集上大幅超越了之前所有方法，而且几乎不需要特征工程和模型设计，只需准备好标注数据。


微调的关键技巧包括：学习率分层衰减（底层用更小的学习率，避免破坏预训练特征）、渐进解冻（先固定底层只训练顶层，再逐步解冻更多层）和标签平滑（用软标签替代硬标签，提升模型泛化能力）。


多标签与长文本分类
多标签分类允许一个样本同时属于多个类别——例如一篇新闻既属于"科技"又属于"商业"。与多分类的 Softmax 不同，多标签分类对每个标签独立使用 Sigmoid 激活和二元交叉熵损失。阈值的选择是多标签分类的关键——固定阈值 0.5 通常不是最优的，可以在验证集上通过搜索找到每个标签的最佳阈值。


标签不平衡是多标签分类的常见挑战。某些标签（如"体育"）样本充足，而另一些标签（如"量子计算"）样本稀少。焦点损失（Focal Loss）通过降低易分类样本的损失权重来缓解不平衡问题，让模型更关注难分类的少数类样本。


长文本分类面临模型输入长度限制的挑战。BERT 的标准输入长度为 512 token，无法直接处理数千到数万字的文档。常见的解决方案包括：截断策略（取开头、结尾或开头+结尾拼接）、滑动窗口（将长文档切分为多个片段分别编码再聚合）和层次编码（先编码句子再编码文档）。Longformer 和 BigBird 等长文本 Transformer 通过稀疏注意力机制将输入长度扩展到 4096 甚至 16384 token。


零样本与少样本分类
在现实场景中，获取大量标注数据往往成本高昂。零样本分类和少样本分类技术让模型在极少甚至没有标注数据的情况下完成分类任务。


零样本分类将分类问题转化为自然语言推理（NLI）问题。给定文本 "苹果发布了新款 iPhone"，构造假设 "这段文本关于科技"，然后用 NLI 模型判断文本是否蕴含该假设。这种方法不需要任何分类标注数据，只需要一个训练好的 NLI 模型和类别的文字描述。

大语言模型的上下文学习（ICL）提供了另一种少样本分类方案。只需在提示中给出几个类别-示例对，模型就能在新文本上进行分类。这种方法的优势是完全不需要训练，但受限于模型上下文长度和推理成本。


小结
    

  • 文本分类是 NLP 最基础的任务，从朴素贝叶斯到 BERT 微调的演进反映了整个领域的技术发展
    • 

  • 传统方法依赖特征工程（TF-IDF、N-gram），深度学习方法（TextCNN、BiLSTM）自动学习表示
    • 

  • BERT 微调是当前全监督场景的标准方案，学习率分层衰减和渐进解冻是关键技巧
    • 

  • 多标签分类需要独立 Sigmoid 激活和阈值优化，长文本需要截断或层次编码策略
    • 

  • 零样本和少样本方法（NLI、提示学习、ICL）大幅降低了对标注数据的依赖
    • 

  • 选择哪种方法取决于数据量、延迟要求和计算预算的综合权衡
