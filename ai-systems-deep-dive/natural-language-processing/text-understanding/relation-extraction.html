关系抽取

核心概念

关系抽取（Relation Extraction，RE）是从文本中识别实体对之间语义关系的任务。给定句子"乔布斯创立了苹果公司"，关系抽取系统需要识别出三元组（乔布斯，创立，苹果公司）。关系抽取是知识图谱自动构建的核心技术，也是问答系统、搜索增强和智能分析的重要支撑。从技术角度看，关系抽取将文本中的隐式知识转化为结构化的关系三元组，是连接非结构化文本与结构化知识的桥梁。

关系抽取的评估通常使用精确率、召回率和 F1 指标。在远程监督场景下，由于标签天然存在噪声，常使用 Precision-Recall 曲线和 AUC 作为更全面的评估指标。


管道式关系抽取
管道式方法将关系抽取分解为两个独立的步骤：先用 NER 模型识别文本中的实体，再对每一对实体进行关系分类。关系分类的核心是判断给定实体对之间是否存在预定义的关系，以及是哪种关系。


传统的关系分类依赖丰富的特征工程——实体类型、实体间的词、依存路径、句法树结构等。深度学习方法自动学习这些特征。PCNN（Piecewise Convolutional Neural Network）将句子按两个实体的位置分为三段，分别做最大池化，捕捉实体前后的上下文模式。


import torch
import torch.nn as nn

class RelationClassifier(nn.Module):
    def __init__(self, encoder_dim: int, num_relations: int):
        super().__init__()
        self.head_proj = nn.Linear(encoder_dim, encoder_dim)
        self.tail_proj = nn.Linear(encoder_dim, encoder_dim)
        self.classifier = nn.Linear(encoder_dim * 3, num_relations)

    def forward(
        self,
        sequence_output: torch.Tensor,
        head_idx: torch.Tensor,
        tail_idx: torch.Tensor
    ) -> torch.Tensor:
        cls_output = sequence_output[:, 0]
        head_output = self.head_proj(sequence_output[range(len(head_idx)), head_idx])
        tail_output = self.tail_proj(sequence_output[range(len(tail_idx)), tail_idx])
        combined = torch.cat([cls_output, head_output, tail_output], dim=-1)
        return self.classifier(combined)
BERT 时代的关系分类通常将两个实体用特殊标记包裹（如 [E1]乔布斯[/E1]创立了[E2]苹果公司[/E2]），然后取两个实体标记位置的隐状态拼接进行分类。这种方式比使用 [CLS] token 效果更好，因为它直接编码了实体位置信息。


联合实体关系抽取
联合抽取方法同时识别实体和关系，避免了管道式方法的误差传播问题。CasRel（Cascade Relation Extraction）将关系抽取建模为主体-关系-客体的级联解码过程：先识别主体实体（Subject），然后对每种关系类型分别识别对应的客体实体（Object）。


TPLinker 提出了一种优雅的统一解码方案——将实体识别和关系抽取都建模为 token-pair 链接问题。对于长度为 nnn 的句子，构建 n×nn \times nn×n 的标注矩阵，其中 (i,j)(i, j)(i,j) 位置标注 token iii 和 token jjj 之间的关系。这种方法天然处理了重叠关系（一个实体参与多个关系）和单实体多角色（同一实体在不同三元组中分别作为主体和客体）的情况。

远程监督与噪声处理
远程监督（Distant Supervision）通过自动对齐知识库和文本来生成训练数据，解决了标注数据不足的问题。核心假设是：如果知识库中存在关系三元组（乔布斯，创立，苹果公司），那么所有同时提到"乔布斯"和"苹果公司"的句子都表达了"创立"关系。这个假设显然过强——"乔布斯用苹果公司的手机"并不表达"创立"关系——因此远程监督数据天然包含大量噪声。


多实例学习（Multi-Instance Learning，MIL）是处理远程监督噪声的经典框架。将所有包含同一实体对的句子组成一个"包"（bag），假设包中至少有一个句子真正表达了目标关系。训练时对包内句子进行注意力加权，高质量句子获得更高的权重。


强化学习去噪是另一种有效方案。训练一个实例选择器（instance selector）来过滤噪声句子——选择器为每个句子打分，只保留高分句子训练关系分类器。选择器本身通过关系分类器的反馈信号（如 F1 提升/下降）用策略梯度方法训练。这种方法将噪声过滤建模为序列决策问题，避免了硬阈值选择的困难。


文档级关系推理
传统关系抽取假设关系在单个句子内表达，但真实文本中约 40% 的关系需要跨句推理。"乔布斯出生于旧金山。他后来创立了苹果公司。"要推断（苹果公司，创立地，旧金山）需要跨两个句子的共指消解和推理。


文档级关系抽取的主要挑战包括：跨句共指消解（"他"指代"乔布斯"）、多跳推理（A-B 关系 + B-C 关系 → A-C 关系推断）和大量负样本（文档中大部分实体对之间没有关系）。


图神经网络是文档级关系推理的主流方法。将文档建模为图结构——实体作为节点，共现关系、共指关系和句法依赖作为边——然后用图注意力网络（GAT）或图卷积网络（GCN）进行消息传递，聚合跨句信息。DocRED 数据集是文档级关系抽取的标准基准，包含超过 5000 篇维基百科文章和 50 多种关系类型。


大语言模型在文档级关系抽取中展现出优势，因为长上下文理解和推理是 LLM 的强项。通过结构化提示设计，可以引导 LLM 逐步进行实体识别、共指消解和关系推理。


小结
    

  • 关系抽取从文本中提取结构化三元组，是知识图谱构建的核心技术
    • 

  • 管道式方法模块清晰但存在误差传播，联合抽取方法同时识别实体和关系
    • 

  • CasRel 和 TPLinker 等联合模型有效处理了重叠关系的挑战
    • 

  • 远程监督解决了标注数据不足问题，多实例学习和强化学习用于处理噪声
    • 

  • 文档级关系推理需要跨句共指消解和多跳推理，图神经网络是主流方法
    • 

  • 大语言模型在复杂关系推理中展现出优势，但推理成本仍是瓶颈
