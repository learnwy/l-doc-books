情感分析

核心概念

情感分析（Sentiment Analysis）致力于从文本中自动识别和提取主观信息——作者的情感、态度、观点和情绪。从电商评论的好评差评判断，到社交媒体的舆情监控，再到金融市场的投资者情绪追踪，情感分析是 NLP 商业价值最高的应用之一。这一领域的技术深度远超"判断正面还是负面"的简单印象——属性级情感分析、隐式情感识别和跨领域情感迁移等方向充满了技术挑战。

情感分析的核心挑战包括：否定处理（"不是不好"是正面还是负面）、讽刺和反语（"服务态度真'好'啊"）、隐式情感（"这个包等了三周才到"暗含不满）和领域迁移（电子产品领域学到的情感知识难以直接迁移到餐饮领域）。


文档级与句子级情感分类
文档级情感分类将整篇文本归入正面、负面或中性类别。在深度学习之前，基于情感词典的方法是主流——构建包含情感极性标注的词典（如 SentiWordNet、知网情感词典），通过统计文本中正面词和负面词的数量来判断整体情感。这种方法简单快速但严重依赖词典覆盖率，对新词和领域特定表达的处理能力有限。


深度学习方法将情感分类建模为标准的文本分类问题。TextCNN 用不同宽度的卷积核捕捉"非常好"、"太差了"等情感 N-gram 模式；BiLSTM 则通过序列建模捕捉"虽然...但是..."等远距离情感转折。注意力机制的加入让模型能够自动聚焦于情感强度高的片段。


BERT 微调显著提升了情感分类的精度。在 SST-2（Stanford Sentiment Treebank）数据集上，BERT-large 达到了 95.6% 的准确率，远超之前的最佳结果。对于中文情感分析，使用中文预训练模型（如 RoBERTa-wwm-ext）效果更佳。


from transformers import AutoTokenizer, AutoModelForSequenceClassification
import torch

def predict_sentiment(text: str, model_name: str = "bert-base-chinese") -> str:
    tokenizer = AutoTokenizer.from_pretrained(model_name)
    model = AutoModelForSequenceClassification.from_pretrained(model_name, num_labels=3)
    inputs = tokenizer(text, return_tensors="pt", truncation=True, max_length=512)
    with torch.no_grad():
        logits = model(**inputs).logits
    labels = ["负面", "中性", "正面"]
    return labels[logits.argmax().item()]
属性级情感分析
属性级情感分析（Aspect-Based Sentiment Analysis，ABSA）是情感分析最精细也最具挑战性的方向。一条评论"屏幕清晰，但电池续航太差了"同时包含对"屏幕"的正面情感和对"电池"的负面情感，文档级分析无法区分这种差异。


ABSA 包含三个子任务：属性提取（从文本中识别被评价的方面，如"屏幕"、"电池"）、情感极性判断（判断每个方面的情感极性）和属性-情感配对（将方面与其对应的情感关联起来）。早期方法将这三个子任务独立处理，但管道式方法存在误差传播问题——属性提取的错误会直接影响情感判断。


联合建模方法同时学习属性提取和情感分类。基于序列标注的方法用统一的 BIO 标签体系同时标注属性边界和情感极性（如 B-POS、I-POS、B-NEG 等）。基于生成的方法将 ABSA 转化为文本生成任务——模型直接生成"屏幕:正面;电池:负面"格式的输出。


注意力机制在 ABSA 中特别重要。给定属性词"电池"，注意力机制能够让模型聚焦于"续航太差了"这个与电池相关的情感表达，而忽略"屏幕清晰"这个无关片段。交互注意力（Interactive Attention）同时建模属性到上下文和上下文到属性的双向注意力，效果优于单向注意力。


情感知识增强与领域迁移
情感词典仍然是提升情感分析性能的有效工具。将词典中的情感极性信息作为额外特征注入深度学习模型，可以提供模型难以从有限训练数据中学到的先验知识。具体方式包括：将情感词的极性标注拼接到词向量中、在损失函数中加入情感词典约束、或用情感词典初始化注意力权重。

跨领域情感迁移是实际应用中的重要需求。在电子产品领域训练的情感模型，迁移到餐饮领域时性能通常会大幅下降——因为"辣"在餐饮评论中可能是正面的，但在电子产品领域没有这种语义。领域自适应方法包括：对抗训练（学习领域无关的特征表示）、枢纽特征（pivot features，识别跨领域共享的情感表达）和渐进式微调（在目标领域的无标注数据上继续预训练再微调）。


大语言模型为情感分析带来了新的范式。通过精心设计的提示，GPT-4 可以进行细粒度的情感分析，包括检测讽刺、理解隐式情感和处理多方面情感，而无需任何领域特定的训练数据。但大模型的推理成本限制了其在大规模实时场景中的应用。


小结
    

  • 情感分析从文档级到属性级，粒度越细技术挑战越大
    • 

  • 文档/句子级情感分类可视为文本分类的特例，BERT 微调是当前最佳方案
    • 

  • 属性级情感分析（ABSA）需要同时提取属性和判断情感，联合建模优于管道式方法
    • 

  • 情感词典和句法知识的融入能有效提升模型性能，尤其在低资源场景
    • 

  • 跨领域迁移需要对抗训练或渐进式微调来学习领域无关的情感表示
    • 

  • 大语言模型在复杂情感理解上展现出强大能力，但受限于推理成本
