说话人识别

核心概念

说话人识别（Speaker Recognition）解决"这段语音是谁说的"这一身份验证问题。它利用语音中独特的声纹特征来识别或验证说话人的身份。语音作为生物特征，具有非接触、自然便捷的优势，广泛应用于电话银行身份验证、智能家居用户区分、会议记录说话人标注和刑侦声纹鉴定等场景。从信号处理的角度看，说话人识别需要从语音中分离出与说话人身份相关的特征，同时抑制与内容、环境和情感相关的无关变化。

说话人验证（Speaker Verification）是最常见的应用模式——判断一段语音是否来自声称的说话人。系统输出接受或拒绝决策，性能用等错误率（EER，Equal Error Rate）衡量，即误接受率等于误拒绝率时的错误率。


说话人表示学习
说话人表示学习的目标是将变长的语音信号压缩为固定长度的向量（称为说话人嵌入或声纹向量），使得同一说话人的向量彼此接近、不同说话人的向量彼此远离。


i-vector 是深度学习之前的标准方法。它基于 GMM-UBM（通用背景模型）框架，用因子分析将高维的 GMM 超向量投影到低维的全差异空间中，得到固定长度的 i-vector。i-vector 隐式地混合了说话人信息和信道信息，需要通过 PLDA（Probabilistic Linear Discriminant Analysis）等后端模型来分离二者。


import torch
import torch.nn as nn

class SpeakerEncoder(nn.Module):
    def __init__(self, input_dim: int, hidden_dim: int, embed_dim: int):
        super().__init__()
        self.backbone = nn.Sequential(
            nn.Conv1d(input_dim, hidden_dim, kernel_size=5, padding=2),
            nn.BatchNorm1d(hidden_dim),
            nn.ReLU(),
            nn.Conv1d(hidden_dim, hidden_dim, kernel_size=3, padding=1),
            nn.BatchNorm1d(hidden_dim),
            nn.ReLU(),
        )
        self.pooling = nn.AdaptiveAvgPool1d(1)
        self.projection = nn.Linear(hidden_dim, embed_dim)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        features = self.backbone(x)
        pooled = self.pooling(features).squeeze(-1)
        return self.projection(pooled)
x-vector 是基于深度学习的说话人嵌入方法。它使用 TDNN（Time-Delay Neural Network）或 ResNet 编码帧级特征，然后通过统计池化层（计算所有帧的均值和标准差并拼接）得到话语级表示，最后通过全连接层得到固定维度的说话人嵌入。训练时使用大规模的说话人分类任务（数千个说话人类别）作为代理任务。


ECAPA-TDNN 与度量学习
ECAPA-TDNN 是当前说话人识别性能最强的模型之一。它在标准 TDNN 的基础上引入了三个关键改进：Squeeze-and-Excitation（SE）模块对通道进行自适应加权、Res2Net 多尺度特征融合和通道注意力统计池化。


度量学习是训练说话人嵌入的核心技术。与简单的分类损失不同，度量学习直接优化嵌入空间中的距离关系。

AAM-Softmax（Additive Angular Margin Softmax）是当前最常用的损失函数。它在标准 softmax 的角度空间中引入额外的角度间隔 mmm，强制模型学到更紧凑的类内分布和更大的类间间隔。角度间隔 mmm 通常设为 0.2-0.3，缩放因子 sss 设为 30。


说话人日志化
说话人日志化（Speaker Diarization）回答"谁在什么时候说话"的问题——将多人对话音频按说话人和时间段进行标注。这对会议记录、电话客服分析和访谈转写等场景至关重要。


传统的说话人日志化流程包括：语音活动检测（VAD，区分语音和静音段）→ 语音分割（将连续语音切分为均匀的短段）→ 说话人嵌入提取（为每个短段提取说话人向量）→ 聚类（将属于同一说话人的段聚合在一起）。聚类方法通常使用谱聚类或凝聚层次聚类，需要事先知道或估计说话人数量。


端到端的说话人日志化模型（EEND，End-to-End Neural Diarization）用单一神经网络直接输出每帧的说话人标签。基于自注意力的 EEND 模型能够处理重叠语音（多人同时说话）——传统的聚类方法对重叠语音束手无策，因为每帧只能分配给一个说话人。


日志化错误率（DER，Diarization Error Rate）是标准评估指标，由未检出语音、误检语音和说话人混淆三部分组成。NIST Rich Transcription 系列竞赛是日志化系统的标准评测。


小结
    

  • 说话人识别通过声纹特征识别说话人身份，验证和辨认是两种基本模式
    • 

  • x-vector 和 ECAPA-TDNN 是当前主流的说话人嵌入方法
    • 

  • AAM-Softmax 通过角度间隔增强了嵌入空间的区分能力
    • 

  • 说话人日志化解决"谁在什么时候说话"问题，端到端方法能处理重叠语音
    • 

  • 实际部署需要处理噪声环境、短语音和跨语言等挑战
    • 

  • 声纹认证的安全性需要结合活体检测防范语音合成攻击
    •
