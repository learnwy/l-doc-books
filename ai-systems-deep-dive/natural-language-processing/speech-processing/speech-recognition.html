语音识别

核心概念

语音识别（Automatic Speech Recognition，ASR）将语音信号转换为文字文本，是语音交互的第一步，也是人机对话、会议记录、字幕生成等应用的技术基础。语音识别的挑战在于语音信号的高维性和多变性——同一句话由不同人、在不同环境下说出，声学特征差异巨大。从 GMM-HMM 的统计时代到 CTC 和 Attention 的深度学习时代，再到 Whisper 的大规模弱监督预训练，语音识别技术经历了根本性的范式转变。

语音识别系统的性能用词错误率（Word Error Rate，WER）衡量：WER=S+D+INWER = \frac{S + D + I}{N}WER=NS+D+I​，其中 SSS、DDD、III 分别是替换、删除和插入错误数，NNN 是参考文本的总词数。中文语音识别通常使用字错误率（Character Error Rate，CER）。


声学特征与前端处理
语音信号是一维的时域波形，采样率通常为 16kHz（每秒 16000 个采样点）。直接用原始波形作为模型输入维度过高且包含大量冗余信息，需要先提取声学特征。


梅尔频率倒谱系数（MFCC）是最经典的声学特征。提取流程包括：预加重（高频增强）、分帧（通常 25ms 帧长、10ms 帧移）、加窗（汉明窗）、FFT、梅尔滤波器组、对数能量和离散余弦变换。MFCC 保留了语音中与语音内容相关的频谱包络信息，去除了与说话人相关的精细结构。


import numpy as np

def compute_mel_spectrogram(
    waveform: np.ndarray,
    sample_rate: int = 16000,
    n_fft: int = 400,
    hop_length: int = 160,
    n_mels: int = 80
) -> np.ndarray:
    frames = np.lib.stride_tricks.sliding_window_view(waveform, n_fft)[::hop_length]
    window = np.hanning(n_fft)
    spectrum = np.abs(np.fft.rfft(frames * window, n=n_fft))
    mel_basis = _mel_filterbank(sample_rate, n_fft, n_mels)
    mel_spec = np.dot(spectrum ** 2, mel_basis.T)
    return np.log(np.maximum(mel_spec, 1e-10))

def _mel_filterbank(sr: int, n_fft: int, n_mels: int) -> np.ndarray:
    low_freq = 0
    high_freq = sr / 2
    mel_low = 2595 * np.log10(1 + low_freq / 700)
    mel_high = 2595 * np.log10(1 + high_freq / 700)
    mel_points = np.linspace(mel_low, mel_high, n_mels + 2)
    hz_points = 700 * (10 ** (mel_points / 2595) - 1)
    bins = np.floor((n_fft + 1) * hz_points / sr).astype(int)
    fbank = np.zeros((n_mels, n_fft // 2 + 1))
    for i in range(n_mels):
        fbank[i, bins[i]:bins[i+1]] = np.linspace(0, 1, bins[i+1] - bins[i])
        fbank[i, bins[i+1]:bins[i+2]] = np.linspace(1, 0, bins[i+2] - bins[i+1])
    return fbank
FBank（梅尔滤波器组特征）省略了 MFCC 的 DCT 步骤，直接使用梅尔滤波器组的对数输出，保留了更多频域信息。在深度学习时代，FBank 已经取代 MFCC 成为主流特征，因为深度模型能够自动学习更优的特征变换。Whisper 等模型使用 80 维的 log-Mel spectrogram 作为输入。


CTC 与端到端模型
CTC（Connectionist Temporal Classification）是实现端到端语音识别的关键技术。它解决了语音识别中的对齐问题——训练数据只提供了音频和对应的文字，但没有逐帧的对齐标注。CTC 引入了空白符号（blank），允许模型在任意时刻输出空白来表示"当前帧不输出字符"。


Conformer 是当前语音识别最常用的编码器架构。它将卷积层和 Transformer 的自注意力层交替堆叠——卷积层捕捉局部的时频模式（如辅音的短时频谱特征），自注意力层建模全局依赖（如长距离的语义关系）。这种混合架构在多个基准上超越了纯 Transformer 和纯卷积模型。


联合 CTC-Attention 模型同时训练 CTC 分支和 Attention 解码器，在推理时用 CTC 前缀分数辅助 Attention 束搜索。CTC 提供了单调的对齐约束（输出顺序与输入顺序一致），Attention 提供了灵活的条件生成能力，二者互补。WeNet 和 ESPnet 等开源框架都采用了这种联合架构。


Whisper 与大规模预训练
Whisper 是 OpenAI 发布的大规模弱监督语音识别模型。它在 68 万小时的互联网音频数据上训练（涵盖 96 种语言），使用 Transformer Encoder-Decoder 架构。Whisper 的核心创新不在模型架构（标准 Transformer），而在训练策略——使用互联网上大规模的弱标注数据（如视频字幕）替代高成本的精标注数据。

流式语音识别是工程落地的核心需求。离线模型需要等待整段语音结束才能开始识别，而流式模型可以实时输出中间结果。分块注意力（Chunk-based Attention）将输入按固定时长分块，每个块只关注当前块和之前的块，实现了低延迟的流式输出。


小结
    

  • 语音识别将语音信号转换为文字，WER/CER 是标准评估指标
    • 

  • FBank 和梅尔频谱图是深度学习时代的主流声学特征
    • 

  • CTC 解决了帧级对齐问题，Conformer 结合卷积和注意力捕捉局部和全局模式
    • 

  • 联合 CTC-Attention 模型利用两者优势，是当前主流的端到端架构
    • 

  • Whisper 通过大规模弱监督预训练实现了 96 种语言的强大识别能力
    • 

  • 流式识别通过分块注意力实现低延迟输出，是工程落地的核心需求
