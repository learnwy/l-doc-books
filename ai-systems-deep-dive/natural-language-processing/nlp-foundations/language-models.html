语言模型

核心概念

语言模型是 NLP 最核心的技术概念之一——它用概率分布来刻画自然语言的生成过程。给定一个词序列 w1,w2,...,wnw_1, w_2, ..., w_nw1​,w2​,...,wn​，语言模型计算该序列出现的概率 P(w1,w2,...,wn)P(w_1, w_2, ..., w_n)P(w1​,w2​,...,wn​)。这一看似简单的定义，驱动了从拼写检查到机器翻译，从语音识别到文本生成的几乎所有 NLP 应用。更深远的意义在于，语言模型的发展路线——从 N-gram 到 RNN，再到 Transformer——就是整个 NLP 技术演进的缩影。

语言模型的核心是利用链式法则将联合概率分解为条件概率的乘积：P(w1,...,wn)=∏i=1nP(wi∣w1,...,wi−1)P(w_1, ..., w_n) = \prod_{i=1}^{n} P(w_i | w_1, ..., w_{i-1})P(w1​,...,wn​)=∏i=1n​P(wi​∣w1​,...,wi−1​)。不同类型的语言模型本质上是在用不同的方法来估计这些条件概率——统计方法靠计数和平滑，神经网络靠参数化的函数逼近。


N-gram 统计语言模型
N-gram 模型是最经典的统计语言模型。它做了一个关键的马尔可夫假设：一个词出现的概率只取决于其前面 N−1N-1N−1 个词，而非整个历史。例如 Bigram（N=2）模型中，P(wi∣w1,...,wi−1)≈P(wi∣wi−1)P(w_i | w_1, ..., w_{i-1}) \approx P(w_i | w_{i-1})P(wi​∣w1​,...,wi−1​)≈P(wi​∣wi−1​)。这一简化使得条件概率可以通过简单的频率统计来估计：


P(wi∣wi−1)=C(wi−1,wi)C(wi−1)P(w_i | w_{i-1}) = \frac{C(w_{i-1}, w_i)}{C(w_{i-1})}P(wi​∣wi−1​)=C(wi−1​)C(wi−1​,wi​)​
其中 CCC 表示语料中的出现次数。N 越大，模型捕捉的上下文越丰富，但也面临更严重的数据稀疏问题——很多合法的 N-gram 在训练语料中可能从未出现过，导致其概率为零。


平滑技术是解决数据稀疏问题的关键。加一平滑（Laplace Smoothing）给每个 N-gram 的计数加 1，简单但效果有限。Kneser-Ney 平滑是实践中最有效的方法，它的核心思想是用"续行计数"（continuation count）替代原始频率——一个词的概率不仅取决于它出现了多少次，还取决于它在多少种不同的上下文中出现过。例如 "Francisco" 虽然出现频率可能很高，但它几乎只出现在 "San" 之后，因此其续行概率很低。


from collections import defaultdict

class BigramLM:
    def __init__(self):
        self.bigram_count: dict[tuple[str, str], int] = defaultdict(int)
        self.unigram_count: dict[str, int] = defaultdict(int)
        self.vocab_size = 0

    def train(self, corpus: list[list[str]]) -> None:
        vocab = set()
        for sent in corpus:
            for i in range(len(sent) - 1):
                self.bigram_count[(sent[i], sent[i + 1])] += 1
                self.unigram_count[sent[i]] += 1
                vocab.update(sent)
        self.vocab_size = len(vocab)

    def prob(self, w1: str, w2: str, alpha: float = 0.01) -> float:
        numerator = self.bigram_count[(w1, w2)] + alpha
        denominator = self.unigram_count[w1] + alpha * self.vocab_size
        return numerator / denominator
N-gram 模型的评估使用困惑度（Perplexity）：PPL=P(w1,...,wn)−1/nPPL = P(w_1, ..., w_n)^{-1/n}PPL=P(w1​,...,wn​)−1/n。困惑度可以理解为模型在每个位置上的平均不确定性——困惑度为 100 意味着模型在每个位置上平均有 100 个等概率的选择。困惑度越低，模型对语言的预测越准确。


循环神经网络语言模型
RNN 语言模型彻底打破了 N-gram 的固定窗口限制。RNN 通过循环连接维护一个隐状态 hth_tht​，在每个时间步将当前输入和上一步的隐状态结合来更新状态：ht=f(Whht−1+Wxxt)h_t = f(W_h h_{t-1} + W_x x_t)ht​=f(Wh​ht−1​+Wx​xt​)。理论上，隐状态可以编码任意长度的历史信息。


然而，标准 RNN 在实践中面临梯度消失和梯度爆炸问题——当序列很长时，梯度在反向传播过程中要么指数级衰减（导致长距离依赖无法学习），要么指数级增长（导致训练不稳定）。


LSTM（Long Short-Term Memory）通过引入门控机制来解决梯度消失问题。它维护一个细胞状态 ctc_tct​ 和三个门：遗忘门决定丢弃哪些旧信息，输入门决定写入哪些新信息，输出门决定输出哪些状态。GRU（Gated Recurrent Unit）是 LSTM 的简化版，将遗忘门和输入门合并为更新门，参数更少但性能相当。


AWD-LSTM 是 RNN 语言模型的集大成者，它结合了权重绑定（weight tying）、变分 Dropout、ASGD 优化器等多种正则化技术，在 PTB 和 WikiText-103 等基准上取得了 RNN 时代的最佳结果。


Transformer 与预训练语言模型
Transformer 架构的出现从根本上改变了语言建模的范式。与 RNN 的顺序处理不同，Transformer 的自注意力机制允许序列中的每个位置直接关注所有其他位置，实现了真正的全局上下文建模。更重要的是，自注意力的计算可以完全并行化，大幅提升了训练效率。


基于 Transformer 的预训练语言模型形成了三大流派。自回归模型（如 GPT 系列）使用因果注意力掩码，从左到右逐词预测，天然适合文本生成任务。自编码模型（如 BERT）使用掩码语言模型（MLM）目标，通过预测被随机遮盖的 token 来学习双向上下文表示，擅长文本理解任务。编码器-解码器模型（如 T5、BART）结合两者优势，适用于条件生成任务如翻译和摘要。

缩放定律（Scaling Laws）是预训练语言模型最重要的经验发现之一。OpenAI 的研究表明，模型性能（以困惑度衡量）与模型参数量、训练数据量和计算量之间存在幂律关系。这意味着增大模型规模可以可预测地提升性能，为"大力出奇迹"的技术路线提供了理论支撑。


语言模型的应用范式
语言模型在 NLP 任务中的应用经历了三个范式阶段。第一阶段是特征提取：将预训练语言模型的输出作为固定特征，输入到下游任务的分类器中（如 ELMo 的使用方式）。第二阶段是微调（Fine-tuning）：在预训练模型的基础上，用少量任务数据进行端到端训练（如 BERT 的使用方式）。第三阶段是提示学习（Prompting）：通过精心设计的提示将任务转换为语言模型原生支持的生成问题，无需修改模型参数（如 GPT-3 的使用方式）。


上下文学习（In-Context Learning，ICL）是大语言模型最令人惊叹的涌现能力。只需在提示中给出几个输入-输出示例，模型就能学会新任务的模式并推广到新的输入。这种能力无需梯度更新，完全在推理阶段通过注意力机制实现。ICL 的机制仍在积极研究中，有假说认为 Transformer 在预训练过程中隐式学习了梯度下降算法。


小结
    

  • 语言模型用概率分布刻画自然语言，是 NLP 最核心的技术概念
    • 

  • N-gram 模型通过马尔可夫假设简化概率估计，平滑技术解决数据稀疏问题
    • 

  • RNN/LSTM 打破了固定窗口限制，但受限于顺序计算和长距离依赖
    • 

  • Transformer 的自注意力机制实现了全局上下文建模和并行计算
    • 

  • 预训练语言模型形成了自回归、自编码和编码-解码三大范式
    • 

  • 应用范式从特征提取到微调再到提示学习，逐步减少对任务数据的依赖
