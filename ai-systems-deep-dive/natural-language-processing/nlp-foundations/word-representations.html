词向量表示

核心概念

词向量表示是 NLP 的基石——它解决了一个根本性问题：如何将离散的文本符号转换为连续的数值向量，使其能够被数学模型处理。从最早的 One-Hot 编码到当今的上下文化词向量，表示学习的每一次突破都推动了 NLP 整体能力的飞跃。词向量的核心假设是分布式语义假说：词的含义由其上下文决定，出现在相似上下文中的词具有相似的语义。

One-Hot 编码将每个词表示为一个维度等于词表大小的稀疏向量，其中只有对应位置为 1。这种表示有两个致命缺陷：维度灾难（词表大小通常在数万到数十万级别）和语义缺失（任意两个词的向量都是正交的，无法度量相似度）。分布式词向量的出现正是为了解决这些问题。


Word2Vec 与分布式词向量
Word2Vec 是 2013 年 Google 提出的革命性模型，它证明了简单的浅层神经网络就能学习到高质量的词向量。Word2Vec 包含两种训练架构：CBOW（Continuous Bag of Words）和 Skip-gram。


CBOW 用上下文词预测中心词。给定窗口大小为 www，模型将中心词周围 2w2w2w 个上下文词的嵌入向量取平均，通过一个线性层和 softmax 预测中心词。Skip-gram 则反过来，用中心词预测上下文中的每个词。实践表明，Skip-gram 在小数据集和低频词上表现更好，而 CBOW 训练更快。


import torch
import torch.nn as nn

class SkipGram(nn.Module):
    def __init__(self, vocab_size: int, embed_dim: int):
        super().__init__()
        self.center_embed = nn.Embedding(vocab_size, embed_dim)
        self.context_embed = nn.Embedding(vocab_size, embed_dim)

    def forward(self, center: torch.Tensor, context: torch.Tensor) -> torch.Tensor:
        center_vec = self.center_embed(center)
        context_vec = self.context_embed(context)
        return torch.sum(center_vec * context_vec, dim=-1)
训练优化是 Word2Vec 成功的关键。完整的 softmax 在大词表上计算代价极高，负采样（Negative Sampling）通过将多分类问题转化为二分类来大幅降低计算量——对于每个正样本（真实的中心词-上下文词对），随机采样 kkk 个负样本（随机配对的词对）。采样概率通常按词频的 3/4 次方加权，避免高频词主导训练。层次 Softmax 是另一种优化方案，利用哈夫曼树将计算复杂度从 O(V)O(V)O(V) 降至 O(log⁡V)O(\log V)O(logV)。


Word2Vec 学到的词向量展现出迷人的代数性质。最著名的例子是"king - man + woman ≈ queen"，这说明词向量空间中的方向编码了语义关系。这种线性类比关系不仅存在于性别维度，还存在于国家-首都、动词时态、比较级-最高级等多种语义维度。


GloVe 与全局统计信息
GloVe（Global Vectors for Word Representation）是 Stanford 在 2014 年提出的词向量模型，它的核心洞察是：词向量应该同时捕捉局部上下文信息和全局共现统计信息。Word2Vec 通过滑动窗口隐式捕捉了局部共现关系，但没有显式利用全局统计信息；而传统的共现矩阵分解（如 LSA）只关注全局统计。GloVe 将二者统一。

FastText 是 Facebook 对 Word2Vec 的扩展，关键创新是引入子词信息。每个词被表示为其所有 n-gram 子词向量的和。例如 "where" 的 3-gram 子词为 "<wh"、"whe"、"her"、"ere"、"re>"（其中 "<" 和 ">" 是边界标记）。这使得 FastText 能够为训练时未见过的词（OOV）生成合理的向量，对于形态丰富的语言（如芬兰语、土耳其语）效果尤为显著。


上下文化词向量
静态词向量的根本局限是一词一向量——"bank" 在 "river bank" 和 "bank account" 中获得相同的向量，无法区分多义词的不同含义。上下文化词向量彻底解决了这一问题：每个词的向量取决于其在当前句子中的上下文。


ELMo（Embeddings from Language Models）是上下文化词向量的先驱。它使用双向 LSTM 语言模型，将前向和后向语言模型在每一层的隐状态拼接，作为该层的词表示。最终的 ELMo 向量是所有层表示的加权和，权重通过任务特定的 softmax 学习。不同层捕捉不同层次的语言信息——底层更接近词法和句法，高层更偏向语义。


BERT 将上下文化表示推向了新高度。基于 Transformer 编码器架构，BERT 通过掩码语言模型（MLM）和下一句预测（NSP）两个预训练任务学习深层双向表示。MLM 随机遮盖输入中 15% 的 token，模型需要根据上下文预测被遮盖的词；NSP 判断两个句子是否在原文中相邻。

GPT 系列模型采用自回归语言模型范式，使用 Transformer 解码器架构，从左到右逐词生成。虽然 GPT 的词向量也是上下文化的，但由于其单向特性，每个词只能"看到"左侧的上下文。GPT 和 BERT 代表了两种不同的预训练哲学——生成式和理解式——二者在下游任务中各有优势。


词向量评估与应用
词向量的质量评估分为内部评估和外部评估。内部评估直接衡量向量空间的性质，包括词类比任务（"king - man + woman = ?"）、词相似度任务（与人工标注的词对相似度排名比较，如 WS-353、SimLex-999 数据集）和聚类可视化（用 t-SNE 或 UMAP 降维后观察语义聚类）。外部评估则在下游任务上衡量词向量的实际效果——用预训练词向量初始化模型在分类、NER、情感分析等任务上的性能提升。


词向量偏差是近年来备受关注的问题。训练语料中的社会偏见会被编码到词向量中——例如 "man:computer_programmer :: woman:homemaker" 这样的类比关系反映了性别偏见。研究者提出了多种去偏方法，包括后处理投影（将偏见方向的分量去除）和对抗训练（在训练过程中惩罚偏见模式）。


在实际应用中，词向量的使用策略取决于任务和数据量。数据充足时，随机初始化并在任务数据上训练通常足够；数据有限时，使用预训练词向量初始化可以显著提升性能；在 BERT 时代，更常见的做法是直接微调预训练模型，而非使用固定的词向量。


小结
    

  • 词向量将离散文本符号映射为连续数值向量，是 NLP 的基础表示技术
    • 

  • Word2Vec 通过浅层神经网络学习分布式表示，Skip-gram 和 CBOW 是两种互补的架构
    • 

  • GloVe 统一了局部上下文和全局共现统计，FastText 引入子词信息处理 OOV 问题
    • 

  • 上下文化词向量（ELMo、BERT、GPT）解决了多义词问题，每个词的表示随上下文动态变化
    • 

  • 词向量评估包括内部评估（类比、相似度）和外部评估（下游任务性能），还需关注偏差问题
    • 

  • 在大模型时代，直接微调预训练模型已成为主流范式，但理解词向量的发展历程有助于把握 NLP 的技术脉络
