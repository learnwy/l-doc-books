多语言 NLP

核心概念

多语言 NLP 面对全球化场景下的语言多样性挑战。世界上有约 7000 种语言，但 NLP 技术资源高度集中于英语等少数高资源语言。如何用有限的标注数据支持数十上百种语言，如何实现跨语言的零样本迁移，如何处理低资源语言——这些问题的解答对构建全球化产品至关重要。多语言预训练模型的出现极大地推动了这一领域的发展，使得"一个模型服务所有语言"的愿景逐步成为现实。

多语言 NLP 的核心思想是利用语言之间的共性——虽然不同语言的表面形式（文字系统、语法结构）差异巨大，但它们表达的语义概念是相通的。多语言预训练模型正是通过在大量语言上联合训练来发现和编码这些跨语言的语义共性。


多语言预训练模型
mBERT（Multilingual BERT）是最早的多语言预训练模型。它使用与 BERT 相同的架构和训练方法，但在 104 种语言的维基百科数据上联合训练。令人惊讶的是，即使训练过程中没有任何显式的跨语言对齐信号（如平行语料），mBERT 仍然学到了跨语言的表示——用英语数据微调的 NER 模型可以在其他语言上有不错的零样本效果。


XLM-RoBERTa 是当前最广泛使用的多语言模型。它在 100 种语言的 Common Crawl 数据上训练（2.5TB 文本），使用 RoBERTa 的优化训练策略（更大批次、更多数据、去除 NSP 目标）。XLM-R 在 XNLI（跨语言自然语言推理）和 XTREME（跨语言基准套件）等多语言基准上显著超越 mBERT。


from transformers import AutoTokenizer, AutoModel
import torch

def encode_multilingual(texts: list[str], model_name: str = "xlm-roberta-base") -> torch.Tensor:
    tokenizer = AutoTokenizer.from_pretrained(model_name)
    model = AutoModel.from_pretrained(model_name)
    inputs = tokenizer(texts, padding=True, truncation=True, return_tensors="pt", max_length=512)
    with torch.no_grad():
        outputs = model(**inputs)
    return outputs.last_hidden_state[:, 0, :]
词表设计是多语言模型的关键决策。mBERT 使用 110K 大小的 WordPiece 词表，由所有语言共享。这导致了"词表瓶颈"——高资源语言（如英语）占据了大部分词表空间，低资源语言的覆盖率很低，同样的句子在低资源语言中被切分为更多的子词 token。XLM-R 使用 250K 的 SentencePiece 词表，通过增加词表大小来缓解这一问题。


跨语言零样本迁移
跨语言零样本迁移是多语言 NLP 最具实用价值的能力——在源语言（通常是英语，因为标注数据最丰富）上训练模型，然后直接在目标语言上使用，无需目标语言的任何标注数据。

翻译训练（Translate-Train）将英语训练数据翻译为目标语言，然后在翻译数据上训练目标语言模型。这种方法的效果通常优于零样本迁移，但受限于机器翻译的质量——翻译错误会引入噪声。翻译测试（Translate-Test）则在推理时将目标语言的输入翻译为英语，然后用英语模型处理。


对齐增强是提升跨语言迁移的关键技术。虽然 mBERT/XLM-R 的预训练过程中没有显式的跨语言对齐，但利用平行语料可以进一步对齐不同语言的表示空间。具体方法是在预训练模型上用平行句对进行对比学习——拉近平行句的表示，推远非平行句的表示。这种对齐微调显著提升了低资源语言的零样本迁移效果。


低资源语言处理
低资源语言面临数据稀缺、工具匮乏和研究关注不足的三重困境。然而，全球数十亿人使用这些语言——印度有 22 种官方语言，非洲有上千种语言——忽视低资源语言意味着将大量用户排除在 NLP 技术的受益范围之外。


数据增强策略包括：利用多语言模型从高资源语言迁移知识、使用机器翻译生成合成训练数据、利用相关高资源语言的数据（如用印地语数据辅助马拉地语模型训练）和主动学习（优先标注对模型提升最大的样本）。


多语言系统的工程架构需要处理多个实际挑战。语言检测是第一步——准确识别输入文本的语言，才能路由到正确的处理流水线。混合语言（code-switching，如中英混用的"这个feature很好"）是语言检测的难点。Unicode 处理需要正确处理不同文字系统的特殊字符、书写方向（阿拉伯语从右向左）和排版规则。

大语言模型为低资源语言提供了新的可能。GPT-4 等模型在预训练中接触了大量语言的文本，即使对于低资源语言也具备一定的理解和生成能力。通过精心设计的多语言提示，大模型可以在低资源语言上完成分类、翻译和信息抽取等任务。


小结
    

  • 多语言 NLP 解决全球化场景下的语言多样性挑战，核心是跨语言知识迁移
    • 

  • XLM-RoBERTa 是当前最强的多语言预训练模型，支持 100 种语言
    • 

  • 跨语言零样本迁移能在目标语言无标注数据的情况下达到源语言 70-85% 的效果
    • 

  • 翻译辅助和对齐增强能进一步提升跨语言迁移的效果
    • 

  • 低资源语言可通过迁移学习、数据增强和大模型提示来弥补数据不足
    • 

  • 多语言系统的工程实现需要处理语言检测、混合语言和 Unicode 等挑战
