机器翻译

核心概念

机器翻译（Machine Translation，MT）是将一种自然语言的文本自动翻译为另一种语言的任务。作为 NLP 历史最悠久的研究方向之一，机器翻译不仅推动了 Seq2Seq 模型和注意力机制的发明，还催生了 Transformer 架构，可以说是现代 NLP 技术革命的摇篮。从基于规则的翻译到统计翻译再到神经翻译，每一次范式转变都带来了翻译质量的飞跃。

翻译质量的评估以 BLEU 为标准自动指标，辅以人工评估。WMT（Workshop on Machine Translation）竞赛每年发布多语言翻译基准和排行榜，是学界和工业界衡量翻译系统性能的权威标准。


神经机器翻译架构
神经机器翻译（Neural Machine Translation，NMT）用端到端的神经网络替代了统计翻译中复杂的特征工程流水线。最初的 NMT 模型基于 RNN Seq2Seq 架构，编码器用双向 LSTM 编码源语言句子，解码器用单向 LSTM 逐词生成目标语言句子。


Bahdanau 注意力的引入是 NMT 的转折点。它让解码器在生成每个目标词时动态关注源句子的不同位置，有效解决了长句翻译中的信息丢失问题。在注意力机制之前，WMT 2014 英德翻译的 BLEU 分数约为 20；加入注意力后迅速攀升至 25 以上。


Transformer 架构（Vaswani et al., 2017）彻底取代了 RNN 在翻译中的地位。多头自注意力机制允许模型并行处理整个句子，而不是像 RNN 那样逐步处理。在 WMT 2014 英德翻译上，Transformer 以 28.4 BLEU 刷新了纪录，同时训练速度比 RNN 快数倍。


import torch
import torch.nn as nn

class TranslationModel(nn.Module):
    def __init__(self, src_vocab: int, tgt_vocab: int, d_model: int = 512, nhead: int = 8, num_layers: int = 6):
        super().__init__()
        self.src_embed = nn.Embedding(src_vocab, d_model)
        self.tgt_embed = nn.Embedding(tgt_vocab, d_model)
        self.transformer = nn.Transformer(d_model=d_model, nhead=nhead, num_encoder_layers=num_layers, num_decoder_layers=num_layers, batch_first=True)
        self.output_proj = nn.Linear(d_model, tgt_vocab)

    def forward(self, src: torch.Tensor, tgt: torch.Tensor) -> torch.Tensor:
        src_emb = self.src_embed(src)
        tgt_emb = self.tgt_embed(tgt)
        tgt_mask = nn.Transformer.generate_square_subsequent_mask(tgt.size(1), device=tgt.device)
        output = self.transformer(src_emb, tgt_emb, tgt_mask=tgt_mask)
        return self.output_proj(output)
数据增强与低资源翻译
平行语料是训练 NMT 模型的燃料，但高质量平行语料的获取成本很高。回译（Back-Translation）是最有效的数据增强方法——先训练一个目标到源语言的反向翻译模型，用它将目标语言的单语数据翻译为源语言，得到合成的平行语料。这种方法利用了丰富的单语数据来提升翻译质量。

低资源语言





低资源翻译是全球化产品的核心挑战。世界上约 7000 种语言中，只有少数语言有充足的平行语料。多语言翻译模型（如 mBART、M2M-100）通过在数十种语言上联合训练来实现跨语言迁移——即使某个语言对没有直接的平行语料，模型也能通过其他语言的桥接效应实现零样本翻译。


文档级翻译与上下文建模
传统 NMT 以句子为单位翻译，忽略了句子之间的上下文关系。这导致了多个问题：代词翻译不一致（"it"在不同句子中被翻译为不同的指代对象）、术语翻译不统一（同一术语在不同句子中翻译不同）和篇章连贯性不足（句间逻辑关系丢失）。


文档级翻译方法通过引入跨句上下文来解决这些问题。简单方法是将前几个句子作为额外上下文拼接到当前句子的输入中，让模型在翻译时参考上文信息。更复杂的方法使用独立的文档编码器来编码全文上下文，通过交叉注意力将文档信息注入句子级翻译模型。


大语言模型在文档级翻译中展现出独特优势。长上下文窗口让 LLM 能够同时看到整篇文档，自然地保持术语一致性和篇章连贯性。实验表明，GPT-4 在文学翻译等需要深层理解的场景中，已经接近甚至超越专业人类译者的水平。


翻译质量估计（Quality Estimation，QE）是不依赖参考译文评估翻译质量的技术。训练 QE 模型来预测翻译输出的质量分数，可以在没有参考答案的生产环境中自动监控翻译质量，将低质量翻译路由到人工审核流程。


小结
    

  • 机器翻译从规则到统计再到神经范式，Transformer 是当前的标准架构
    • 

  • 注意力机制解决了长句翻译的信息丢失问题，是 NMT 的关键创新
    • 

  • 回译是最有效的数据增强方法，多语言模型实现了低资源语言的跨语言迁移
    • 

  • 文档级翻译通过引入跨句上下文解决了代词一致性和篇章连贯性问题
    • 

  • 大语言模型在翻译质量上已接近人类水平，尤其在需要深层理解的文学翻译中
    • 

  • 翻译质量估计技术使生产环境中的自动质量监控成为可能
