文本摘要

核心概念

文本摘要是将长文档压缩为简洁、准确、连贯的短文本的任务。在信息爆炸的时代，人们每天面对海量的新闻、论文、报告和邮件，摘要技术帮助用户快速获取核心信息。从技术角度看，文本摘要要求模型具备深层的文本理解能力（读懂原文的核心内容）和高质量的文本生成能力（产生流畅准确的摘要），是 NLP 综合能力的试金石。

摘要质量的评估面临固有困难——同一篇文章可以有多种合理的摘要。ROUGE 是标准自动指标，但与人工评估的相关性有限。忠实度（生成的摘要是否忠实于原文）和信息性（摘要是否覆盖了原文的关键信息）是两个核心评估维度。


抽取式摘要
抽取式摘要直接从原文中选择最重要的句子组成摘要，不产生新的文字。这种方法的最大优势是保证了事实忠实度——摘要中的每句话都来自原文，不会产生幻觉。缺点是摘要可能读起来不够流畅，因为从不同位置选取的句子之间缺乏连贯的过渡。


TextRank 是最经典的无监督抽取式摘要方法。它借鉴了 PageRank 的思想，将文档中的句子作为图的节点，用句子相似度作为边的权重，通过迭代传播计算每个句子的重要性分数。相似度高的句子互相增强对方的重要性，最终选择得分最高的 kkk 个句子作为摘要。


import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

def textrank_summarize(sentence_embeddings: np.ndarray, num_sentences: int = 3) -> list[int]:
    sim_matrix = cosine_similarity(sentence_embeddings)
    np.fill_diagonal(sim_matrix, 0)
    scores = np.ones(len(sim_matrix))
    damping = 0.85
    for _ in range(30):
        new_scores = (1 - damping) + damping * sim_matrix @ (scores / sim_matrix.sum(axis=0).clip(min=1e-8))
        scores = new_scores
    return sorted(np.argsort(scores)[-num_sentences:])
BertSum 将 BERT 应用于句子级别的重要性评分。在句子之间插入 [SEP] 和 segment embedding 来区分不同句子，然后用每个句子对应的 [CLS] 位置的输出做二分类（选/不选）。为了避免选择内容高度重复的句子，解码时使用三元组阻塞（Trigram Blocking）策略——如果候选句子与已选句子有过多相同的三元组，则跳过该候选。


生成式摘要
生成式摘要用自己的语言重新表达原文的核心内容，可以融合多个句子的信息、改变句式结构、添加连接词使摘要更加流畅。但生成式方法面临一个严峻挑战——幻觉（Hallucination）：模型可能生成原文中不存在的事实信息。


BART（Bidirectional and Auto-Regressive Transformers）是生成式摘要的标杆模型。它采用编码器-解码器架构，预训练目标是从被破坏（删除、打乱、替换等多种噪声）的文本中重建原始文本。这种去噪自编码的预训练方式使 BART 同时具备了强大的文本理解和生成能力。


PEGASUS 专门为摘要任务设计了预训练目标——间隙句生成（Gap Sentence Generation，GSG）。在预训练时随机删除文档中最重要的句子（通过 ROUGE 分数与其他句子的重叠度来判断重要性），然后让模型生成被删除的句子。这个预训练目标直接模拟了摘要任务的核心：识别文档中最重要的内容并生成它。


忠实度控制是生成式摘要最关键的工程问题。常用的方法包括：复制机制（Copy Mechanism，允许模型直接从原文复制词汇，减少事实编造）、忠实度奖励（在训练或推理时引入基于 NLI 的忠实度评分作为约束）和事实后验证（用 NLI 模型或 QA 模型检查摘要中的每个声明是否被原文支持）。


长文档摘要与多文档摘要
标准 Transformer 的输入长度限制（512-2048 token）无法直接处理数千到数万字的长文档。长文档摘要需要专门的架构设计。


层次化方法先用句子编码器将每个句子编码为向量，再用文档编码器在句子向量之上建模文档结构。这种两阶段编码有效降低了计算复杂度，但可能丢失句子内部的细粒度信息。LED（Longformer Encoder-Decoder）使用稀疏注意力机制将输入长度扩展到 16384 token，在局部窗口注意力的基础上添加全局注意力位置，兼顾效率和全局信息捕捉。

多文档摘要从多篇相关文档中生成一个综合摘要。核心挑战是信息冗余——多篇文档可能重复描述同一事件，需要去重和融合。最大边际相关性（MMR）算法在选择句子时同时考虑与查询的相关性和与已选句子的差异性。图方法将多文档建模为统一的语义图，在图上进行信息聚合和选择。


小结
    

  • 文本摘要分为抽取式和生成式，前者忠实但不够流畅，后者流畅但面临幻觉风险
    • 

  • TextRank 是经典的无监督抽取方法，BertSum 利用预训练模型进行句子重要性评分
    • 

  • BART 和 PEGASUS 是生成式摘要的代表模型，后者专为摘要设计预训练目标
    • 

  • 幻觉是生成式摘要最大的挑战，复制机制和事实后验证是主要的缓解手段
    • 

  • 长文档摘要需要层次编码或稀疏注意力来突破输入长度限制
    • 

  • 多文档摘要的核心挑战是信息冗余处理和跨文档信息融合
    •
