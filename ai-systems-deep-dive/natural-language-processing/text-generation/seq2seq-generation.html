序列到序列生成

核心概念

序列到序列（Seq2Seq）生成是所有文本生成任务的技术基座。它的目标是将一个输入序列转换为一个输出序列——输入和输出的长度可以不同，内容也可以不同。机器翻译（中文→英文）、文本摘要（长文→短文）、对话系统（问题→回答）和代码生成（需求→代码）都可以统一建模为 Seq2Seq 问题。理解 Seq2Seq 的架构演进和解码策略，是掌握所有文本生成技术的必要前提。

Seq2Seq 的核心思想是将输入序列编码为一个中间表示（上下文向量或上下文序列），然后基于这个表示逐步生成输出序列。编码器负责理解输入，解码器负责产生输出，二者通过注意力机制紧密耦合。


注意力机制与信息瓶颈
早期 RNN Seq2Seq 模型的编码器将整个输入序列压缩为一个固定长度的上下文向量（编码器最后一个时间步的隐状态），解码器基于这个向量生成输出。这造成了信息瓶颈——无论输入多长，都被压缩到同一个固定维度的向量中。当输入序列很长时，早期信息不可避免地被遗忘。


注意力机制彻底解决了信息瓶颈问题。Bahdanau 注意力（加法注意力）允许解码器在每一步生成时动态关注编码器的所有位置——计算当前解码器隐状态与编码器每个位置隐状态的相关性分数，然后用 softmax 归一化得到注意力权重，加权求和编码器隐状态得到上下文向量。


import torch
import torch.nn as nn
import torch.nn.functional as F

class BahdanauAttention(nn.Module):
    def __init__(self, hidden_dim: int):
        super().__init__()
        self.W_q = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.W_k = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.v = nn.Linear(hidden_dim, 1, bias=False)

    def forward(self, query: torch.Tensor, keys: torch.Tensor) -> tuple[torch.Tensor, torch.Tensor]:
        scores = self.v(torch.tanh(self.W_q(query).unsqueeze(1) + self.W_k(keys)))
        weights = F.softmax(scores.squeeze(-1), dim=-1)
        context = torch.bmm(weights.unsqueeze(1), keys).squeeze(1)
        return context, weights
Luong 注意力（乘法注意力）用点积代替加法来计算相关性分数，计算更高效。Transformer 的缩放点积注意力进一步引入了 Query-Key-Value 的三角色分工和 dk\sqrt{d_k}dk​​ 缩放因子，多头注意力则允许模型同时从不同的表示子空间关注信息。


解码策略
解码策略决定了模型如何从概率分布中选择输出 token，直接影响生成文本的质量和多样性。自回归解码在每一步基于之前生成的所有 token 预测下一个 token，形成从左到右的逐步生成过程。


贪心解码每一步选择概率最高的 token，简单快速但容易陷入局部最优。束搜索（Beam Search）在每一步维护 kkk 个最优候选序列（beam），在局部搜索空间中寻找近似全局最优。束宽度 kkk 越大，搜索越充分但计算成本也越高。实践中束宽度通常设为 4-8。


随机采样方法在需要多样性和创造性的场景（如对话、故事生成）中更合适。温度参数 TTT 控制概率分布的锐利程度——T<1T < 1T<1 使分布更集中（高概率词更突出），T>1T > 1T>1 使分布更平坦（增加多样性）。Top-k 采样只从概率最高的 kkk 个 token 中采样，避免选择极低概率的 token。Top-p（Nucleus Sampling）动态确定候选集大小——选择累积概率达到阈值 ppp 的最小 token 集合。

受控生成与对齐技术
受控生成（Controlled Generation）让模型按照特定的约束或偏好生成文本——如控制生成文本的风格、主题、长度或情感。这在实际应用中极为重要——用户希望生成积极向上的客服回复，或符合特定格式的报告。


前缀调优（Prefix Tuning）在模型输入前添加可学习的连续向量作为"软提示"，只训练这些向量而不修改模型参数。不同的前缀向量对应不同的生成控制条件。LoRA（Low-Rank Adaptation）通过在 Transformer 层中插入低秩矩阵来高效微调，参数量远小于全量微调。


RLHF（Reinforcement Learning from Human Feedback）是将人类偏好注入语言模型的标准方法。流程包括三个阶段：收集人类对不同输出的偏好排序，训练一个奖励模型来预测人类偏好，然后用 PPO 算法优化语言模型使其生成高奖励的输出。RLHF 是 ChatGPT 等对话系统的核心对齐技术。


DPO（Direct Preference Optimization）简化了 RLHF 流程，跳过了奖励模型训练阶段，直接从偏好数据优化语言模型。其核心思想是将奖励函数隐式定义为策略模型与参考模型之间的对数概率比，从而将强化学习问题转化为简单的分类损失优化。


小结
    

  • Seq2Seq 是所有文本生成任务的统一框架，编码器理解输入、解码器产生输出
    • 

  • 注意力机制解决了固定长度上下文向量的信息瓶颈，Transformer 将其推向极致
    • 

  • 解码策略在质量和多样性之间权衡——束搜索适合精确任务，采样适合创造性任务
    • 

  • 受控生成通过前缀调优、LoRA 和 RLHF 等技术让模型按照人类期望生成文本
    • 

  • DPO 简化了 RLHF 流程，成为新一代对齐技术的主流选择
    • 

  • 理解 Seq2Seq 的基础知识是深入翻译、摘要和对话等具体任务的前提
