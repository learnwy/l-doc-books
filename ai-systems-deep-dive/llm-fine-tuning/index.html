LLM 微调与对齐实战 简介

LLM 微调与对齐实战是大语言模型从通用能力走向专业应用的核心技术路径。预训练模型虽然具备广泛的语言理解和生成能力，但在特定领域、特定任务或特定价值观对齐方面往往需要进一步优化。本知识库系统讲解微调与对齐的全流程技术体系，帮助读者掌握从数据准备到模型部署的完整实践链路。

本知识库适用于具备大语言模型基础知识的中高级开发者，包括希望在垂直领域定制模型的机器学习工程师、需要理解微调技术选型的技术架构师，以及关注模型对齐与安全的 AI 研究者。

全书共分为五章。前四章构成「基础 → 提效 → 对齐 → 收尾」的主线，第五章是第四章的工程深化篇，两者分工明确而非重复：

第一章微调基础，系统讲解微调的核心动机、数据准备方法论、训练基础设施选型，以及全量微调的原理与实践（含 MoE 与多模态等当代架构的微调要点），帮助读者建立扎实的微调知识基础。

第二章参数高效方法，深入剖析 LoRA、QLoRA、前缀调优和适配器方法等主流参数高效微调技术，这些方法以极低的计算成本实现接近全量微调的效果，是当前最具实用价值的微调范式。

第三章对齐技术，聚焦如何让模型行为符合人类偏好与价值观，涵盖 SFT、RLHF、DPO 及其变体和 Constitutional AI，并以专门小节追踪 2025 年以来的范式转变——GRPO、RLVR 与推理模型微调（DeepSeek-R1 路线），帮助读者理解从奖励建模到可验证奖励对齐的技术演进。

第四章评估与部署，从微调项目全流程收尾的视角展开：效果评估体系（能力保持/任务适配/安全对齐）、模型合并策略和部署优化总览，帮助读者完成从实验到生产的最后一公里。

第五章评估与部署工程，从工程实现视角深入同一主题的细节层：评估方法学（自动化基准、LLM-as-Judge、人工评估的组合策略）、量化技术（GPTQ/AWQ/GGUF）与推理服务化（引擎选型、批处理、扩缩容）。与第四章的关系是总览与深入：第四章回答「收尾阶段要做哪些事」，第五章回答「每件事在工程上怎么做」；两章的对应文档互相标注了衔接点。

推荐学习路径为：先通过第一章掌握微调的基础知识和全量微调实践，再通过第二章深入参数高效方法以优化资源利用，之后学习第三章的对齐技术（含 RLVR 与推理模型微调前沿）以提升模型行为质量，最后按「第四章总览 → 第五章深入」的顺序完成评估与部署闭环。已有微调经验的读者可直接从第二章或第三章切入；只关心推理模型训练的读者可直达第三章的 RLVR 小节。

与兄弟 hub 的边界

微调是 LLM 后训练的主干，但「后训练」的每个环节在本知识库中都有专职 hub 深入展开。本 hub 讲训练者视角的完整微调流程，以下主题只在交界处提及、不重复展开：

  • RLHF 与偏好对齐（54）：从数据与训练策略角度系统展开偏好对齐全流程；本 hub 第三章只讲对齐方法的机制与实现，偏好数据工程的深度内容归 54 号 hub。
  • 奖励建模（95）：奖励模型的架构、训练与评估是 RLHF 的上游专项；本 hub 将奖励模型视为 RLHF 流程中的一个阶段，不展开其内部设计。
  • 宪法 AI（92）：Anthropic 宪法式对齐的原理、原则库设计与 RLAIF 变体；本 hub 第三章仅收录 CAI 的机制性介绍作为对齐方法谱系的一环。
  • 推理与测试时计算（55）：推理模型的能力来源（CoT、测试时扩展、RLVR 训练配方）；本 hub 第三章的 RLVR 小节讲「怎么微调出推理行为」，推理能力本身的机理归 55 号 hub。
  • 服务与推理系统（58）：推理引擎内核、调度与集群级服务架构；本 hub 第四/五章的部署内容只到「把微调模型跑起来」的工程层，系统级深入归 58 号 hub。
  • 量化（86）：GPTQ/AWQ 等量化算法的数学原理与前沿变体；本 hub 第五章只讲量化在「微调后部署」流程中的位置与实操。
  • 模型合并（94）：合并算法（TIES/DARE/Model Stock）的完整谱系；本 hub 第四章只保留微调场景下的合并选型视角。
  • 蒸馏（77）：师生蒸馏的方法学、推理能力迁移与合规；本 hub 的蒸馏微调小节只讲「以教师输出为数据源的微调」这一窄切片。

前置知识

阅读本 hub 需要理解 Transformer 的基本结构与注意力机制、交叉熵损失与语言建模目标、以及 PyTorch 张量操作。不熟悉的读者建议先修 02_ai-llm 分类下的 LLM 基础类 hub。

延伸阅读

以下兄弟 hub 与本 hub 交界最深，按主题延伸（均为可选入口，本 hub 内容自成闭环）：

  • 奖励建模——RLHF 上游的奖励模型专项
  • 宪法 AI——宪法式对齐的完整方法学

  • 大模型服务与推理系统——系统级推理服务架构
  • LLM 量化技术——量化算法原理与前沿
  • 模型合并技术——合并算法完整谱系
