QLoRA 量化微调

核心概念

QLoRA（Quantized LoRA）在 LoRA 的基础上引入了 4-bit 量化技术，将基础模型的权重从 16-bit 压缩到 4-bit 存储，同时在 LoRA 层使用高精度计算。这使得在单张消费级 GPU（如 RTX 4090 24GB）上微调 70B 参数的模型成为可能，大幅降低了 LLM 微调的硬件门槛。

NormalFloat4 量化
QLoRA 使用 NormalFloat4（NF4）量化格式，这是一种信息论最优的 4-bit 数据类型。NF4 基于正态分布对量化区间进行非均匀划分，使得量化误差在权重的典型分布下最小化：


from transformers import BitsAndBytesConfig, AutoModelForCausalLM
import torch

quantization_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_use_double_quant=True,
)

model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3-70B",
    quantization_config=quantization_config,
    device_map="auto",
)
双重量化（Double Quantization）是 QLoRA 的另一个关键技术——它对量化常数（scaling factors）本身进行二次量化，在 65B 参数模型上平均每个参数节省约 0.37 bits，对显存进一步压缩。

QLoRA 完整训练流程
结合 bitsandbytes、PEFT 和 TRL 库实现 QLoRA 训练的完整流程：


from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig, TrainingArguments
from peft import LoraConfig, prepare_model_for_kbit_training, get_peft_model
from trl import SFTTrainer
from datasets import load_dataset
import torch

model_name = "meta-llama/Llama-3-8B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
tokenizer.pad_token = tokenizer.eos_token

bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_use_double_quant=True,
)

model = AutoModelForCausalLM.from_pretrained(
    model_name,
    quantization_config=bnb_config,
    device_map="auto",
)

model = prepare_model_for_kbit_training(model)

lora_config = LoraConfig(
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj", "gate_proj", "up_proj", "down_proj"],
    bias="none",
    task_type="CAUSAL_LM",
)

dataset = load_dataset("json", data_files="train.jsonl", split="train")

def format_chat(example):
    messages = example["messages"]
    text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=False)
    return {"text": text}

dataset = dataset.map(format_chat)

training_args = TrainingArguments(
    output_dir="./qlora-output",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,
    learning_rate=2e-4,
    warmup_ratio=0.03,
    lr_scheduler_type="cosine",
    bf16=True,
    optim="paged_adamw_8bit",
    logging_steps=10,
    save_strategy="epoch",
    max_grad_norm=0.3,
    gradient_checkpointing=True,
    gradient_checkpointing_kwargs={"use_reentrant": False},
)

trainer = SFTTrainer(
    model=model,
    args=training_args,
    train_dataset=dataset,
    peft_config=lora_config,
    max_seq_length=2048,
    dataset_text_field="text",
    tokenizer=tokenizer,
)

trainer.train()
trainer.save_model("./qlora-adapter")
prepare_model_for_kbit_training 是 QLoRA 特有的步骤——它冻结量化层的参数，将 Layer Norm 转换为 FP32，并启用梯度检查点。paged_adamw_8bit 优化器在 GPU 显存不足时自动将优化器状态分页到 CPU。


QLoRA 调优策略
QLoRA 的超参数调优与标准 LoRA 有一些关键差异：


interface QLoRAConfig {
  parameter: string;
  recommended: string;
  rationale: string;
}

const qloraGuidelines: QLoRAConfig[] = [
  {
    parameter: 'learning_rate',
    recommended: '1e-4 ~ 3e-4',
    rationale: '量化后梯度噪声更大，过高的学习率会导致不稳定',
  },
  {
    parameter: 'max_grad_norm',
    recommended: '0.3',
    rationale: '比标准 LoRA 更低，防止量化梯度的大幅波动',
  },
  {
    parameter: 'bnb_4bit_compute_dtype',
    recommended: 'bfloat16',
    rationale: 'BF16 比 FP16 在反量化计算中更稳定',
  },
  {
    parameter: 'gradient_checkpointing',
    recommended: 'True',
    rationale: '显存节省的核心手段，QLoRA 几乎必开',
  },
  {
    parameter: 'optim',
    recommended: 'paged_adamw_8bit',
    rationale: '8-bit 优化器配合分页机制进一步压缩显存',
  },
];

小结
    

  • QLoRA 通过 NF4 量化将基础模型压缩到 4-bit，使单张消费级 GPU 能微调 70B 模型
    • 

  • NormalFloat4 是信息论最优的 4-bit 格式，结合双重量化进一步压缩存储
    • 

  • prepare_model_for_kbit_training 和 paged_adamw_8bit 是 QLoRA 的关键配置
    • 

  • 超参数需要更保守：更低的梯度裁剪阈值（0.3），必开梯度检查点
    • 

  • 有足够 GPU 资源时优先选择标准 LoRA，QLoRA 的核心价值是降低硬件门槛
