Adapter 适配器方法

核心概念

Adapter Tuning 是最早提出的参数高效微调方法之一，其核心思想是在 Transformer 的每一层中插入小型的瓶颈网络（bottleneck module）。这些适配器模块由下投影、非线性激活和上投影组成，通过残差连接与原始层融合。训练时冻结所有预训练参数，只更新适配器参数，可训练参数量占模型总参数的 1-5%。

瓶颈网络设计
Adapter 的核心是瓶颈结构——先将维度从 d 降到 r（通常 r=64-256），经过非线性激活后再升回 d 维。残差连接确保了当适配器输出接近零时，模型行为退化为原始预训练模型。


import torch
import torch.nn as nn

class BottleneckAdapter(nn.Module):
    def __init__(self, d_model: int, bottleneck_dim: int, dropout: float = 0.1):
        super().__init__()
        self.down_proj = nn.Linear(d_model, bottleneck_dim)
        self.activation = nn.ReLU()
        self.up_proj = nn.Linear(bottleneck_dim, d_model)
        self.dropout = nn.Dropout(dropout)
        nn.init.zeros_(self.up_proj.weight)
        nn.init.zeros_(self.up_proj.bias)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        residual = x
        x = self.down_proj(x)
        x = self.activation(x)
        x = self.up_proj(x)
        x = self.dropout(x)
        return x + residual
上投影层的权重初始化为零是关键设计——它确保训练开始时适配器是一个恒等映射，不会破坏预训练模型的表示。随着训练进行，适配器逐渐学习任务特定的变换。

Parallel Adapter 与 AdapterFusion
传统的 Serial Adapter 串联在 Transformer 层之后，会增加模型的深度和推理延迟。Parallel Adapter 将适配器与原始层并行放置，通过加权求和融合输出，提供了更好的梯度流动：


class ParallelAdapter(nn.Module):
    def __init__(self, d_model: int, bottleneck_dim: int, scaling: float = 1.0):
        super().__init__()
        self.down_proj = nn.Linear(d_model, bottleneck_dim)
        self.activation = nn.GELU()
        self.up_proj = nn.Linear(bottleneck_dim, d_model)
        self.scaling = scaling

    def forward(self, x: torch.Tensor, original_output: torch.Tensor) -> torch.Tensor:
        adapter_out = self.up_proj(self.activation(self.down_proj(x)))
        return original_output + self.scaling * adapter_out
AdapterFusion 进一步扩展了适配器的能力，允许组合多个预训练适配器来处理新任务。它在多个适配器之上添加一个注意力层，学习不同适配器的动态组合权重：


class AdapterFusion(nn.Module):
    def __init__(self, d_model: int, num_adapters: int):
        super().__init__()
        self.query = nn.Linear(d_model, d_model)
        self.key = nn.Linear(d_model, d_model)
        self.value = nn.Linear(d_model, d_model)
        self.num_adapters = num_adapters

    def forward(self, hidden: torch.Tensor, adapter_outputs: list[torch.Tensor]) -> torch.Tensor:
        q = self.query(hidden)
        stacked = torch.stack(adapter_outputs, dim=-2)
        k = self.key(stacked)
        v = self.value(stacked)
        attn = torch.softmax(torch.matmul(q.unsqueeze(-2), k.transpose(-1, -2)) / (q.size(-1) ** 0.5), dim=-1)
        return torch.matmul(attn, v).squeeze(-2)

使用 PEFT 库实践
HuggingFace 的 PEFT 库通过 AdaLoRA 配置支持类似适配器的功能，同时 adapters 库提供了更完整的适配器生态：


from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import get_peft_model, AdaLoraConfig, TaskType

model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3-8B",
    torch_dtype="auto",
    device_map="auto",
)

adalora_config = AdaLoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=16,
    lora_alpha=32,
    target_modules=["q_proj", "v_proj", "k_proj", "o_proj"],
    init_r=12,
    target_r=8,
    beta1=0.85,
    beta2=0.85,
    tinit=200,
    tfinal=1000,
    deltaT=10,
)

model = get_peft_model(model, adalora_config)
model.print_trainable_parameters()
AdaLoRA 的创新在于自适应秩分配——它在训练过程中动态调整不同层的秩大小，对重要的层分配更高的秩，对不太重要的层降低秩。这种策略在参数预算固定的情况下能获得更好的效果。

对于大多数 LLM 微调场景，LoRA 因其推理零开销的特性成为默认选择。Adapter 方法在以下场景更有优势：需要更强的非线性表达能力、多任务组合（AdapterFusion）、或者需要在推理时动态选择不同适配策略。


小结
    

  • Adapter Tuning 通过瓶颈网络实现参数高效微调，可训练参数占 1-5%
    • 

  • 零初始化上投影层确保训练起始时不破坏预训练表示
    • 

  • Parallel Adapter 改善了梯度流，AdapterFusion 支持多适配器动态组合
    • 

  • AdaLoRA 通过自适应秩分配在固定参数预算下优化效果
    • 

  • 与 LoRA 相比，Adapter 表达能力更强但有推理延迟开销
    • 

  • 生产环境中 LoRA 更受欢迎，Adapter 适合需要非线性变换或多任务融合的场景
