参数高效方法 简介

本章深入讲解参数高效微调技术，这是当前大语言模型微调领域最具实用价值的技术方向。全量微调虽然效果优异，但对计算资源的要求极高，参数高效方法通过仅训练模型的少量参数或低秩近似来大幅降低训练成本，同时保持接近全量微调的效果。本章帮助读者掌握主流参数高效方法的原理与工程实践。

本章包含四个核心小节。

LoRA系统讲解低秩适配的核心原理、矩阵分解思想和实现细节，涵盖秩的选择策略、目标模块的确定方法，以及 LoRA 在不同模型架构上的应用实践，是参数高效微调领域最重要的基础方法。

QLoRA在 LoRA 基础上引入量化技术，讲解四比特量化与低秩适配的结合方式，包括 NormalFloat 量化、双重量化和分页优化器等核心技术，帮助读者在消费级 GPU 上完成大模型微调。

前缀调优介绍通过在模型输入序列前添加可学习的连续向量来实现任务适配的方法，涵盖 Prefix Tuning 和 Prompt Tuning 的设计差异、适用场景和超参数调优策略。

适配器方法讲解在模型层间插入小型可训练模块的适配器架构设计，包括 Adapter 的结构设计、插入位置选择和与其他参数高效方法的组合策略，帮助读者理解参数高效方法的完整技术谱系。

建议按照 LoRA、QLoRA、前缀调优、适配器方法的顺序学习，从最核心的技术逐步拓展到完整的技术全景。实际项目中建议优先考虑 LoRA 和 QLoRA。
