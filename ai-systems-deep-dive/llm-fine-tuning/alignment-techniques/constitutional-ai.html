Constitutional AI 宪法式 AI

核心概念

Constitutional AI（CAI）是 Anthropic 提出的一种 AI 对齐方法，通过定义一组明确的"宪法原则"来引导模型的自我批评和修正过程。与 RLHF 依赖大量人类偏好标注不同，CAI 让模型自身根据宪法原则对输出进行评估和改进，大幅减少了人工标注的需求。CAI 的两个核心阶段是"宪法监督的 SFT"和"基于 AI 反馈的强化学习（RLAIF）"。

宪法原则设计
宪法原则是 CAI 的核心，它定义了模型应该遵循的行为准则。好的原则应该明确、可操作、覆盖关键安全维度：

自我批评与修正流程
CAI 的第一阶段通过迭代的自我批评和修正来生成高质量的训练数据。模型首先生成一个初始回答，然后根据宪法原则自我评估，最后生成修正后的版本：


from transformers import AutoModelForCausalLM, AutoTokenizer

def constitutional_revision(
    model,
    tokenizer,
    prompt: str,
    principles: list[dict],
    max_revisions: int = 3,
) -> str:
    response = generate(model, tokenizer, prompt)

    for principle in principles[:max_revisions]:
        critique_prompt = (
            f"人类提问：{prompt}\n\n"
            f"AI 回答：{response}\n\n"
            f"批评要求：{principle['critique']}\n\n"
            f"请给出批评意见："
        )
        critique = generate(model, tokenizer, critique_prompt)

        revision_prompt = (
            f"人类提问：{prompt}\n\n"
            f"AI 原始回答：{response}\n\n"
            f"批评意见：{critique}\n\n"
            f"修正要求：{principle['revision']}\n\n"
            f"请给出修正后的回答："
        )
        response = generate(model, tokenizer, revision_prompt)

    return response


def generate(model, tokenizer, prompt: str) -> str:
    inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
    outputs = model.generate(**inputs, max_new_tokens=512, temperature=0.7)
    return tokenizer.decode(outputs[0], skip_special_tokens=True)
经过多轮修正后的回答通常在安全性和质量上都有显著提升。这些修正后的数据用于 SFT 训练，使模型内化宪法原则。


RLAIF 训练流程
CAI 的第二阶段用 AI 反馈替代人类反馈来训练奖励模型。对于同一个提示，模型生成多个候选回答，然后让模型自身根据宪法原则选择更好的那个：


from dataclasses import dataclass

@dataclass
class PreferencePair:
    prompt: str
    chosen: str
    rejected: str
    principle: str
    confidence: float

def generate_ai_preferences(
    model,
    tokenizer,
    prompts: list[str],
    principles: list[dict],
) -> list[PreferencePair]:
    pairs = []
    for prompt in prompts:
        response_a = generate(model, tokenizer, prompt)
        response_b = generate(model, tokenizer, prompt)

        for principle in principles:
            comparison_prompt = (
                f"根据以下原则，比较两个回答的质量：\n"
                f"原则：{principle['critique']}\n\n"
                f"回答 A：{response_a}\n\n"
                f"回答 B：{response_b}\n\n"
                f"哪个回答更好？请回答 A 或 B，并解释原因。"
            )
            judgment = generate(model, tokenizer, comparison_prompt)
            chosen = response_a if "A" in judgment[:10] else response_b
            rejected = response_b if chosen == response_a else response_a

            pairs.append(PreferencePair(
                prompt=prompt,
                chosen=chosen,
                rejected=rejected,
                principle=principle["name"],
                confidence=0.8,
            ))
    return pairs

CAI 的核心局限在于模型的"自我批评能力"受限于模型自身的理解水平。如果模型本身无法识别某类有害内容，宪法原则也无法帮助它修正。因此 CAI 通常与少量的人工审查结合使用，在关键安全维度上仍保留人类监督。


小结
    

  • Constitutional AI 通过宪法原则引导模型自我批评和修正，大幅减少人工标注需求
    • 

  • 宪法原则应覆盖无害性、诚实性、有用性、公平性等核心维度
    • 

  • 自我修正 SFT + RLAIF 两阶段训练是 CAI 的标准流程
    • 

  • AI 生成的偏好数据可直接用于 DPO 训练，简化了对齐流程
    • 

  • 核心局限是模型自我评估能力的上限，关键安全维度仍需人类监督
    • 

  • CAI 与 RLHF/DPO 互补，实践中常结合使用以平衡成本和质量
    •
