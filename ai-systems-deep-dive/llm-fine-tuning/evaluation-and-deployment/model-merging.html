模型合并技术

核心概念

模型合并（Model Merging）是将多个微调模型的能力组合到单个模型中的技术。不同于集成推理（需要运行多个模型），模型合并在权重空间中操作，生成一个拥有多模型能力的单一模型，推理成本与单模型相同。这项技术在 LLM 社区迅速流行，成为提升模型综合能力的重要手段。

线性插值与 SLERP
最简单的合并方法是线性插值（Linear Interpolation），将两个模型的权重按比例混合。SLERP（Spherical Linear Interpolation）在球面空间中插值，保持权重向量的范数，通常比线性插值效果更好：


import torch
from transformers import AutoModelForCausalLM

def linear_merge(model_a_path: str, model_b_path: str, alpha: float = 0.5) -> dict:
    model_a = AutoModelForCausalLM.from_pretrained(model_a_path)
    model_b = AutoModelForCausalLM.from_pretrained(model_b_path)

    merged_state = {}
    for key in model_a.state_dict():
        merged_state[key] = (1 - alpha) * model_a.state_dict()[key] + alpha * model_b.state_dict()[key]

    return merged_state


def slerp_merge(
    model_a_path: str,
    model_b_path: str,
    t: float = 0.5,
) -> dict:
    model_a = AutoModelForCausalLM.from_pretrained(model_a_path)
    model_b = AutoModelForCausalLM.from_pretrained(model_b_path)

    merged_state = {}
    for key in model_a.state_dict():
        w_a = model_a.state_dict()[key].float()
        w_b = model_b.state_dict()[key].float()

        if w_a.dim() >= 2:
            dot = torch.sum(w_a * w_b) / (torch.norm(w_a) * torch.norm(w_b))
            omega = torch.acos(torch.clamp(dot, -1, 1))
            if omega.abs() < 1e-10:
                merged_state[key] = (1 - t) * w_a + t * w_b
            else:
                merged_state[key] = (
                    torch.sin((1 - t) * omega) / torch.sin(omega) * w_a
                    + torch.sin(t * omega) / torch.sin(omega) * w_b
                )
        else:
            merged_state[key] = (1 - t) * w_a + t * w_b

    return merged_state

TIES 与 DARE
TIES（TRIM, Elect Sign, and Disjoint Merge）通过稀疏化和符号选举机制解决多模型合并时的参数冲突问题。DARE（Drop And REscale）则通过随机丢弃大部分微调增量来减少模型间的干扰：


def ties_merge(
    base_model_path: str,
    model_paths: list[str],
    density: float = 0.2,
    weights: list[float] | None = None,
) -> dict:
    base = AutoModelForCausalLM.from_pretrained(base_model_path)
    base_state = base.state_dict()

    if weights is None:
        weights = [1.0 / len(model_paths)] * len(model_paths)

    task_vectors = []
    for path in model_paths:
        model = AutoModelForCausalLM.from_pretrained(path)
        tv = {}
        for key in base_state:
            tv[key] = model.state_dict()[key] - base_state[key]
        task_vectors.append(tv)

    merged_state = {}
    for key in base_state:
        deltas = torch.stack([tv[key] for tv in task_vectors])

        magnitudes = deltas.abs()
        threshold = torch.quantile(magnitudes.flatten(), 1 - density)
        mask = magnitudes >= threshold
        trimmed = deltas * mask

        signs = torch.sign(trimmed)
        sign_sum = signs.sum(dim=0)
        elected_sign = torch.sign(sign_sum)

        aligned = trimmed * (signs == elected_sign.unsqueeze(0))
        weight_tensor = torch.tensor(weights).view(-1, *([1] * (deltas.dim() - 1)))
        merged_delta = (aligned * weight_tensor).sum(dim=0)

        merged_state[key] = base_state[key] + merged_delta

    return merged_state
DARE 的核心思想是：微调后的权重增量中存在大量冗余，随机丢弃 90-99% 的增量后重新缩放，模型仍能保持大部分微调能力。这种稀疏化显著减少了多模型合并时的干扰：

合并后必须进行评估，验证各项能力是否保持且没有出现冲突。常见的问题包括：合并后某些能力退化、生成质量下降、安全对齐丢失。


小结
    

  • 模型合并在权重空间中组合多模型能力，推理成本不增加
    • 

  • SLERP 球面插值优于简单线性平均，适合两模型合并
    • 

  • TIES 通过裁剪、符号选举和不相交合并解决多模型参数冲突
    • 

  • DARE 通过随机丢弃 90%+ 微调增量实现稀疏合并
    • 

  • mergekit 工具提供声明式配置，支持多种合并方法
    • 

  • 合并后必须评估各项能力保持情况，特别关注安全对齐是否丢失
