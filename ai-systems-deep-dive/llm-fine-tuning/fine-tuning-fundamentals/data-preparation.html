数据准备与质量工程

核心概念

数据质量是微调成功的第一决定因素——"垃圾进，垃圾出"在 LLM 微调中的体现尤为明显。训练数据的准备过程包括数据收集、清洗、格式化、质量评估和数据增强五个阶段。高质量的 500 条数据往往比低质量的 50,000 条数据产生更好的微调效果。

数据格式与对话模板
不同的微调平台和框架要求不同的数据格式。OpenAI 使用 JSONL 对话格式，HuggingFace 支持多种格式，而开源框架通常使用 Alpaca 或 ShareGPT 格式：


interface OpenAIFineTuneMessage {
  role: 'system' | 'user' | 'assistant';
  content: string;
}

interface OpenAIFineTuneSample {
  messages: OpenAIFineTuneMessage[];
}

interface AlpacaSample {
  instruction: string;
  input: string;
  output: string;
}

interface ShareGPTSample {
  conversations: Array<{
    from: 'human' | 'gpt' | 'system';
    value: string;
  }>;
}

const convertAlpacaToOpenAI = (sample: AlpacaSample): OpenAIFineTuneSample => ({
  messages: [
    { role: 'system', content: '你是一位专业的技术助手。' },
    {
      role: 'user',
      content: sample.input ? `${sample.instruction}\n\n${sample.input}` : sample.instruction,
    },
    { role: 'assistant', content: sample.output },
  ],
});

const convertShareGPTToOpenAI = (sample: ShareGPTSample): OpenAIFineTuneSample => ({
  messages: sample.conversations.map((c) => ({
    role: c.from === 'human' ? ('user' as const) : c.from === 'gpt' ? ('assistant' as const) : ('system' as const),
    content: c.value,
  })),
});
数据格式选择的关键原则是与目标部署平台保持一致。如果在 OpenAI 上微调，使用其原生 JSONL 格式；如果使用开源框架，Alpaca 格式最为通用。


数据清洗管道
数据清洗是确保训练数据质量的核心环节。一个系统化的清洗管道应该处理格式错误、内容重复、有害内容和长度异常：


interface CleaningResult {
  original: number;
  cleaned: number;
  removed: Map<string, number>;
}

const createCleaningPipeline = (config: { minLength: number; maxLength: number; deduplicateThreshold: number }) => {
  const cleaners = [
    {
      name: '格式修复',
      clean: (samples: OpenAIFineTuneSample[]) =>
        samples.filter((s) => {
          const hasSystem = s.messages.some((m) => m.role === 'system');
          const hasUser = s.messages.some((m) => m.role === 'user');
          const hasAssistant = s.messages.some((m) => m.role === 'assistant');
          return hasUser && hasAssistant;
        }),
    },
    {
      name: '长度过滤',
      clean: (samples: OpenAIFineTuneSample[]) =>
        samples.filter((s) => {
          const totalLen = s.messages.reduce((sum, m) => sum + m.content.length, 0);
          return totalLen >= config.minLength && totalLen <= config.maxLength;
        }),
    },
    {
      name: '内容去重',
      clean: (samples: OpenAIFineTuneSample[]) => {
        const seen = new Set<string>();
        return samples.filter((s) => {
          const key = s.messages.map((m) => m.content).join('|');
          if (seen.has(key)) return false;
          seen.add(key);
          return true;
        });
      },
    },
    {
      name: '质量检查',
      clean: (samples: OpenAIFineTuneSample[]) =>
        samples.filter((s) => {
          const assistantMsg = s.messages.find((m) => m.role === 'assistant');
          if (!assistantMsg) return false;
          const content = assistantMsg.content;
          if (content.length < 10) return false;
          if (/^(好的|是的|对|嗯)$/g.test(content.trim())) return false;
          return true;
        }),
    },
  ];

  return (samples: OpenAIFineTuneSample[]): CleaningResult => {
    let current = samples;
    const removed = new Map<string, number>();

    for (const cleaner of cleaners) {
      const before = current.length;
      current = cleaner.clean(current);
      removed.set(cleaner.name, before - current.length);
    }

    return { original: samples.length, cleaned: current.length, removed };
  };
};
数据增强技术
当原始数据不足时，数据增强可以扩大训练集的规模和多样性。LLM 自身就是强大的数据增强工具：


const createDataAugmenter = (model: {
  invoke: (messages: Array<{ role: string; content: string }>) => Promise<{ content: string }>;
}) => {
  const rephrase = async (sample: OpenAIFineTuneSample): Promise<OpenAIFineTuneSample> => {
    const userMsg = sample.messages.find((m) => m.role === 'user')!;
    const result = await model.invoke([
      {
        role: 'system',
        content: '将以下问题改写为不同的表述方式，保持含义不变。只输出改写后的问题。',
      },
      { role: 'user', content: userMsg.content },
    ]);

    return {
      messages: sample.messages.map((m) => (m.role === 'user' ? { ...m, content: result.content as string } : m)),
    };
  };

  const addEdgeCases = async (sample: OpenAIFineTuneSample): Promise<OpenAIFineTuneSample[]> => {
    const userMsg = sample.messages.find((m) => m.role === 'user')!;
    const result = await model.invoke([
      {
        role: 'system',
        content: `基于以下问题，生成 3 个相关但更具挑战性的变体（边界情况、歧义表述、复合问题）。
          每个变体占一行，不加编号。`,
      },
      { role: 'user', content: userMsg.content },
    ]);

    const variants = (result.content as string).split('\n').filter((l) => l.trim());
    return variants.map((v) => ({
      messages: sample.messages.map((m) => (m.role === 'user' ? { ...m, content: v.trim() } : m)),
    }));
  };

  return { rephrase, addEdgeCases };
};

数据集划分与版本管理
训练数据应该按 80/10/10 的比例划分为训练集、验证集和测试集。验证集用于训练过程中的早停判断，测试集用于最终效果评估：


const splitDataset = <T>(
  data: T[],
  ratios: { train: number; validation: number; test: number },
  seed = 42,
): { train: T[]; validation: T[]; test: T[] } => {
  const shuffled = [...data];
  let m = shuffled.length;
  while (m > 0) {
    const i = Math.floor(((seed = (seed * 1103515245 + 12345) & 0x7fffffff) / 0x7fffffff) * m--);
    [shuffled[m], shuffled[i]] = [shuffled[i], shuffled[m]];
  }

  const trainEnd = Math.floor(data.length * ratios.train);
  const valEnd = trainEnd + Math.floor(data.length * ratios.validation);

  return {
    train: shuffled.slice(0, trainEnd),
    validation: shuffled.slice(trainEnd, valEnd),
    test: shuffled.slice(valEnd),
  };
};
小结
    

  • 数据质量是微调成败的第一决定因素，500 条高质量数据胜过 50,000 条低质量数据
    • 

  • 数据格式需与目标平台一致，OpenAI 使用 JSONL 对话格式，开源框架常用 Alpaca 格式
    • 

  • 清洗管道应覆盖格式校验、长度过滤、内容去重和质量检查四个环节
    • 

  • LLM 驱动的数据增强（同义改写、边界用例生成）可有效扩大训练集
    • 

  • 训练集/验证集/测试集按 80/10/10 划分，验证集用于早停，测试集用于最终评估
