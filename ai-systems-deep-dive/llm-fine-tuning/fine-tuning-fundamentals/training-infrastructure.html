GPU 显存估算
准确估算 GPU 显存需求是避免训练中途 OOM（Out of Memory）的关键。显存消耗主要来自模型参数、优化器状态、梯度和激活值四个部分：


interface MemoryEstimate {
  modelParams: number;
  optimizerState: number;
  gradients: number;
  activations: number;
  total: number;
  unit: string;
}

const estimateMemory = (config: {
  paramsBillion: number;
  precision: 'fp32' | 'fp16' | 'bf16' | 'int8' | 'int4';
  optimizer: 'adam' | 'sgd' | 'adamw-8bit';
  batchSize: number;
  seqLength: number;
  method: 'full' | 'lora' | 'qlora';
  loraRank?: number;
}): MemoryEstimate => {
  const bytesPerParam: Record<string, number> = {
    fp32: 4,
    fp16: 2,
    bf16: 2,
    int8: 1,
    int4: 0.5,
  };

  const paramBytes = config.paramsBillion * 1e9 * bytesPerParam[config.precision];

  let trainableRatio = 1;
  if (config.method === 'lora') trainableRatio = ((config.loraRank ?? 16) * 2) / 4096;
  if (config.method === 'qlora') trainableRatio = ((config.loraRank ?? 16) * 2) / 4096;

  const optimizerMultiplier: Record<string, number> = {
    adam: 8,
    sgd: 0,
    'adamw-8bit': 4,
  };
  const optimizerBytes = config.paramsBillion * 1e9 * trainableRatio * optimizerMultiplier[config.optimizer];

  const gradientBytes = config.paramsBillion * 1e9 * trainableRatio * bytesPerParam[config.precision];
  const activationBytes = config.batchSize * config.seqLength * 4096 * 4;

  const totalGB = (paramBytes + optimizerBytes + gradientBytes + activationBytes) / 1e9;

  return {
    modelParams: paramBytes / 1e9,
    optimizerState: optimizerBytes / 1e9,
    gradients: gradientBytes / 1e9,
    activations: activationBytes / 1e9,
    total: totalGB,
    unit: 'GB',
  };
};

混合精度与梯度策略
混合精度训练（Mixed Precision Training）使用 FP16/BF16 进行前向和反向传播，用 FP32 维护主权重，在减少显存消耗的同时保持训练稳定性：


accelerate launch --mixed_precision=bf16 train.py \
  --model_name_or_path meta-llama/Llama-3-8B \
  --per_device_train_batch_size 4 \
  --gradient_accumulation_steps 4 \
  --learning_rate 2e-5 \
  --num_train_epochs 3 \
  --bf16 True \
  --gradient_checkpointing True \
  --output_dir ./output
梯度检查点（Gradient Checkpointing）通过在反向传播时重新计算中间激活值来减少显存占用，代价是约 30% 的训练速度下降。对于显存受限的场景，这是最有效的优化手段。


梯度累积（Gradient Accumulation）通过多个小批次累积梯度再更新参数，等效于使用更大的 batch size。当单 GPU 无法放下目标 batch size 时，这是必要的策略。

小结
    

  • GPU 显存需求由模型参数、优化器状态、梯度和激活值四部分决定，LoRA 可减少 70-90%
    • 

  • HF + PEFT 最通用灵活，Axolotl 配置最简，LLaMA-Factory 对中文最友好
    • 

  • 混合精度（BF16）是默认选择，梯度检查点用空间换时间，梯度累积模拟大 batch
    • 

  • 云端训练选择需平衡成本、易用性和地区可用性
    • 

  • 基础设施选型应从模型规模倒推：7B 以下单卡可训，13B+ 需要多卡或 QLoRA
