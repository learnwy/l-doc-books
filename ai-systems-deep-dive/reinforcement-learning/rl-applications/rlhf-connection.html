RLHF 与大模型对齐

核心概念

RLHF（Reinforcement Learning from Human Feedback）是将人类偏好信号融入大语言模型（LLM）训练的关键技术，也是 ChatGPT 等对话 AI 系统成功的核心因素之一。RLHF 解决的核心问题是：如何让语言模型的输出符合人类的价值观、有用性和安全性标准——这些标准难以用简单的数学公式定义，但人类可以通过比较两个回答来表达偏好。

RLHF 的基本流程分为三个阶段：监督微调（SFT）→ 奖励模型训练 → 强化学习优化。监督微调用高质量的人类标注数据教模型基本的对话能力，奖励模型从人类偏好比较中学习评估回答质量的能力，最后通过 PPO 等 RL 算法优化语言模型使其最大化奖励模型的评分。

奖励模型训练
奖励模型（Reward Model, RM）是 RLHF 的核心组件，它从人类偏好标注数据中学习评估语言模型输出质量的能力。偏好数据的形式是：给定同一个提示（Prompt），人类标注者从两个或多个模型回答中选择更优的一个。


奖励模型的训练使用 Bradley-Terry 模型：给定两个回答 y_w（被偏好）和 y_l（不被偏好），假设偏好概率为 P(y_w > y_l) = σ(r(x, y_w) - r(x, y_l))，其中 r 是奖励函数，σ 是 sigmoid 函数。损失函数为交叉熵损失：L = -E[log σ(r(x, y_w) - r(x, y_l))]。


奖励模型通常基于与策略模型相同架构的 LLM，去掉最后的语言模型头，替换为输出标量奖励的线性层。使用 SFT 模型的权重初始化奖励模型可以加速训练。


奖励模型的质量直接决定 RLHF 的效果。核心挑战包括：标注一致性（不同标注者的偏好可能不一致）、奖励黑客（策略模型利用奖励模型的弱点获取高分但回答质量差）、以及分布偏移（RL 优化后策略产生的输出超出奖励模型的训练分布）。


PPO 优化与 KL 约束
RLHF 的第三阶段使用 PPO 算法优化语言模型，最大化奖励模型的评分同时通过 KL 散度惩罚防止策略过度偏离 SFT 模型。优化目标为：


J(θ) = E*{xD, yπ*θ}[r_RM(x, y) - β · KL(π_θ(·|x) || π_ref(·|x))]


其中 r_RM 是奖励模型的评分，π_ref 是参考策略（通常是 SFT 模型），β 是 KL 惩罚系数。KL 约束的作用至关重要：它防止策略完全偏离预训练模型的语言能力，限制奖励黑客的程度，并保持输出的多样性和流畅性。

PPO 在 RLHF 中的实现与标准 PPO 有一些重要差异。语言模型的"动作"是整个回答的 token 序列（而非单步动作），奖励通常在回答完成后一次性给出（稀疏奖励）。价值函数用于估计每个 token 位置的期望未来奖励，帮助 PPO 进行逐 token 的信用分配。


DPO 与替代方法
DPO（Direct Preference Optimization） 是 RLHF 的一个重要替代方案，它绕过了显式的奖励模型训练和 RL 优化，直接从偏好数据中优化语言模型。DPO 的关键洞见是：RLHF 中带 KL 约束的优化问题存在闭式最优解，可以将奖励函数隐式地表示为策略和参考模型的对数概率比。


DPO 的损失函数为：L = -E[log σ(β · log(π_θ(y_w|x)/π_ref(y_w|x)) - β · log(π_θ(y_l|x)/π_ref(y_l|x)))]


这等价于 RLHF 的优化目标，但完全消除了奖励模型和 RL 训练循环。DPO 的优势包括：实现简单（仅需要标准的语言模型训练循环）、训练稳定（无需调节 PPO 超参数和处理奖励模型偏差）、计算高效（不需要维护四个模型：策略、参考、奖励和价值）。


然而 DPO 也有局限：它对偏好数据的质量更敏感（RLHF 中奖励模型可以在一定程度上平滑标注噪声），且在某些场景中 PPO 的灵活性（如在线采样和迭代优化）带来更好的最终性能。


RLAIF（RL from AI Feedback） 用 AI 评估（如强大的 LLM）替代人类偏好标注，大幅降低标注成本。Constitutional AI 用一组预定义的规则让 AI 自我评判和修正。这些方法代表了 RLHF 向更可扩展方向的发展。


RLHF 及其变体已成为大语言模型对齐的标准技术。随着模型能力的增强，如何更准确地传达人类价值观、防止更高级的奖励黑客、以及在开放式场景中保持对齐，仍是活跃的研究方向。


小结
    

  • RLHF 通过三阶段流程（SFT → 奖励模型 → PPO）将人类偏好融入大语言模型训练
    • 

  • 奖励模型从人类偏好比较中学习评估回答质量，是 RLHF 的核心组件
    • 

  • KL 约束防止策略过度偏离参考模型，是平衡奖励优化和语言质量的关键
    • 

  • DPO 绕过奖励模型和 RL 直接从偏好数据优化，实现简单但灵活性稍低
    • 

  • RLAIF 和 Constitutional AI 用 AI 替代人类反馈，提升可扩展性
    • 

  • 对齐技术正在从偏好学习向价值对齐和安全保证方向深入发展
    •
