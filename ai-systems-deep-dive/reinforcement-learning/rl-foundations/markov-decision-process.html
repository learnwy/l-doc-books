马尔可夫决策过程

核心概念

马尔可夫决策过程（Markov Decision Process, MDP）是强化学习最核心的数学框架。MDP 将序贯决策问题形式化为一个五元组 (S, A, P, R, γ)，其中 S 是状态空间、A 是动作空间、P 是状态转移概率、R 是奖励函数、γ 是折扣因子。MDP 的核心假设是马尔可夫性质：给定当前状态，未来的状态转移与历史无关。

这个看似简单的假设具有深远意义——它意味着当前状态包含了做出最优决策所需的所有信息，无需回溯历史。正是这一性质使得价值函数和 Bellman 方程的推导成为可能，也使得强化学习问题在数学上变得可处理。

马尔可夫性质与状态转移

马尔可夫性质的数学表述为：P(st+1∣st,at,st−1,at−1,…,s0,a0)=P(st+1∣st,at)P(s_{t+1} \mid s_t, a_t, s_{t-1}, a_{t-1}, \dots, s_0, a_0) = P(s_{t+1} \mid s_t, a_t)P(st+1​∣st​,at​,st−1​,at−1​,…,s0​,a0​)=P(st+1​∣st​,at​)。即下一个状态的概率分布仅取决于当前状态和动作，与到达当前状态的路径无关。

这一性质要求状态必须是充分统计量（Sufficient Statistic）。在实践中，设计满足马尔可夫性的状态表示是建模的关键挑战。例如，在 Atari 游戏中，单帧画面无法判断球的运动方向，必须使用连续多帧的堆叠来近似马尔可夫状态。

状态转移概率矩阵 P 完整描述了环境的动力学特性。对于有限 MDP，P 可以表示为三维张量 P(s'|s,a)，对每个状态-动作对给出下一状态的概率分布。确定性环境中 P 退化为确定性映射——每个 (s,a) 对唯一确定下一个状态。

理解状态转移矩阵有助于区分两类重要的强化学习方法：基于模型的方法（Model-Based） 显式学习或利用转移概率，而无模型方法（Model-Free） 绕过转移概率直接从采样经验中学习。基于模型的方法在转移概率已知时效率更高，但在复杂环境中准确估计转移概率本身就是巨大挑战。

状态转移的性质还决定了环境的类型。遍历性（Ergodicity） 保证从任意状态出发最终可以到达任意其他状态，这对策略评估的收敛性有重要影响。吸收状态（Absorbing State） 是回合制任务中的终止状态，到达后不再转移。

Bellman 方程

Bellman 方程是强化学习理论的基石，它建立了价值函数的递归关系。状态价值函数的 Bellman 期望方程为：

Vπ(s)=∑aπ(a∣s)∑s′P(s′∣s,a)[R(s,a,s′)+γVπ(s′)]V^\pi(s) = \sum_a \pi(a \mid s) \sum_{s'} P(s' \mid s, a)\left[R(s, a, s') + \gamma V^\pi(s')\right]Vπ(s)=a∑​π(a∣s)s′∑​P(s′∣s,a)[R(s,a,s′)+γVπ(s′)]

这个方程的直觉含义是：一个状态的价值等于在该状态下按策略选择动作后，即时奖励加上折扣后的下一状态价值的期望。

动作价值函数的 Bellman 期望方程为：

Qπ(s,a)=∑s′P(s′∣s,a)[R(s,a,s′)+γ∑a′π(a′∣s′) Qπ(s′,a′)]Q^\pi(s,a) = \sum_{s'} P(s' \mid s, a)\left[R(s, a, s') + \gamma \sum_{a'} \pi(a' \mid s')\, Q^\pi(s', a')\right]Qπ(s,a)=s′∑​P(s′∣s,a)[R(s,a,s′)+γa′∑​π(a′∣s′)Qπ(s′,a′)]

Bellman 方程的最优版本描述了最优价值函数必须满足的条件：

V∗(s)=max⁡a∑s′P(s′∣s,a)[R(s,a,s′)+γV∗(s′)]V^*(s) = \max_a \sum_{s'} P(s' \mid s, a)\left[R(s, a, s') + \gamma V^*(s')\right]V∗(s)=amax​s′∑​P(s′∣s,a)[R(s,a,s′)+γV∗(s′)]

Bellman 最优方程的意义在于：一旦求解出 V* 或 Q*，最优策略可以直接导出——在每个状态选择使 Q*(s,a) 最大的动作即可。然而，Bellman 最优方程通常是非线性的（因为 max 运算），无法直接求解析解，需要迭代算法来近似求解。

策略评估与策略改进

策略评估（Policy Evaluation）是指给定一个策略 π，计算其对应的价值函数 V^π。策略改进（Policy Improvement）是指根据当前价值函数构造更优策略。这两个操作交替执行构成了求解 MDP 的基本框架。

策略评估通过反复应用 Bellman 期望方程的迭代版本来实现。初始化任意 V0V_0V0​，然后对所有状态执行更新 Vk+1(s)=∑aπ(a∣s)∑s′P(s′∣s,a)[R(s,a,s′)+γVk(s′)]V_{k+1}(s) = \sum_a \pi(a \mid s) \sum_{s'} P(s' \mid s, a)\left[R(s, a, s') + \gamma V_k(s')\right]Vk+1​(s)=∑a​π(a∣s)∑s′​P(s′∣s,a)[R(s,a,s′)+γVk​(s′)]，直到收敛。在有限 MDP 中，这个过程保证收敛到 VπV^\piVπ。

策略改进定理保证了从贪心改进中获得更优策略。给定 VπV^\piVπ，构造贪心策略 π′(s)=arg⁡max⁡aQπ(s,a)\pi'(s) = \arg\max_a Q^\pi(s, a)π′(s)=argmaxa​Qπ(s,a)。策略改进定理证明 Vπ′(s)≥Vπ(s)V^{\pi'}(s) \ge V^\pi(s)Vπ′(s)≥Vπ(s) 对所有状态成立。当不等式取等号时，说明已经找到最优策略。

策略迭代（Policy Iteration） 交替执行策略评估和策略改进，在有限 MDP 中保证有限步收敛到最优策略。值迭代（Value Iteration） 将策略评估截断为单步更新，直接应用 Bellman 最优方程的迭代版本，在计算效率上更有优势。

折扣因子与最优性

折扣因子 γ 不仅是一个调节超参数，更是 MDP 理论中保证最优策略存在性和唯一性的关键要素。

当 γ < 1 时，Bellman 最优算子是一个 γ-压缩映射（Contraction Mapping）。根据 Banach 不动点定理，压缩映射存在唯一不动点，这保证了值迭代和策略迭代的收敛性。压缩系数 γ 同时决定了收敛速度——γ 越小收敛越快，但智能体的远见性也越差。

折扣因子的选择在实践中需要权衡多个因素。较大的 γ（如 0.99）使智能体考虑更长远的影响，适合需要长期规划的任务；较小的 γ（如 0.9）使智能体更关注近期收益，适合奖励信号衰减快的场景。在数学上，有效视野（Effective Horizon）约为 1/(1-γ)，γ=0.99 对应约 100 步的有效规划深度。

MDP 的一个核心理论结果是：对于有限折扣 MDP，至少存在一个确定性的最优策略。这意味着随机策略虽然在学习过程中有用（例如用于探索），但最终的最优解一定是确定性的。这一结论大大简化了最优策略的搜索空间。
