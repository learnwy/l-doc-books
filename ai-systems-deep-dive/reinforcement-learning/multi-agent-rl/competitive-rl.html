竞争强化学习

核心概念

竞争强化学习（Competitive Reinforcement Learning）研究智能体之间存在利益冲突的博弈场景。在零和博弈中，一个智能体的收益恰好是对手的损失；在一般和博弈中，利益冲突与合作机会并存。竞争场景的核心特征是对手的存在改变了优化目标的性质——智能体不再是对抗一个固定的环境，而是与一个同样在学习和适应的对手博弈。

竞争 RL 的理论基础是博弈论（Game Theory）。与合作 RL 追求团队最优不同，竞争 RL 追求的是均衡策略——在对手也在最优化的前提下，自身能获得的最佳保障。这种"最坏情况下的最优"思维贯穿了竞争 RL 的算法设计。

自博弈训练
自博弈（Self-Play） 是竞争 RL 中最成功的训练方法。其核心思想极其简洁：让智能体与自己的副本（或历史版本）对弈，通过不断击败过去的自己来持续进步。自博弈天然解决了对手策略分布的问题——对手就是自己的历史版本集合。


AlphaGo 和 AlphaZero 的巨大成功展示了自博弈的威力。AlphaZero 从零开始（无人类棋谱），仅通过自博弈训练就在围棋、象棋和将棋上达到超人水平。其训练循环是：使用当前策略自博弈生成对局 → 用 MCTS + 价值网络评估局面 → 用生成的数据训练策略网络和价值网络 → 更新策略后继续自博弈。


自博弈的关键挑战是策略遗忘（Policy Forgetting） 和循环动态（Cyclic Dynamics）。在非传递性博弈（石头剪刀布是最简单的例子）中，策略 A 击败 B，B 击败 C，C 击败 A，自博弈可能在三个策略之间无限循环而不收敛。


对手采样策略对自博弈的效果至关重要。始终与最新版本对弈（latest）可能导致过拟合和策略遗忘。更好的做法是从历史策略池中按一定分布采样对手：均匀采样所有历史版本提供多样性，优先采样近期版本保持训练效率，优先采样"难对手"加速改进。


虚拟博弈与 PSRO
虚拟博弈（Fictitious Play, FP） 是一种经典的博弈论学习算法。每个玩家维护对手策略的经验分布（即对手历史动作的频率统计），然后计算并执行对该经验分布的最优响应（Best Response）。在某些博弈中（如两人零和博弈），虚拟博弈保证收敛到纳什均衡。


深度虚拟博弈将虚拟博弈的思想与深度 RL 结合。神经虚拟博弈（Neural Fictitious Self-Play, NFSP）维护两个网络：一个最优响应网络（通过 DQN 训练）和一个平均策略网络（通过监督学习模仿历史动作的平均分布）。执行时以一定概率在两者之间切换。

PSRO（Policy Space Response Oracle） 是虚拟博弈的现代推广。PSRO 维护一个策略池，在每轮迭代中：计算当前策略池上的元博弈矩阵（策略之间的胜率矩阵）→ 用博弈论方法（如纳什均衡求解）找到元策略（策略的混合分布）→ 训练对元策略的最优响应策略 → 将新策略加入池中。PSRO 在非传递性博弈中特别有效，因为它自然地维护了一个多样化的策略种群。


对抗鲁棒性与安全博弈
竞争 RL 的思想不仅用于博弈对抗，还被用于提升策略的对抗鲁棒性（Adversarial Robustness）。基本思想是将环境中的不确定性建模为一个对抗者的行为——训练一个对抗者专门干扰智能体，迫使智能体学会在最坏情况下仍然表现良好。


鲁棒 MDP（Robust MDP） 假设转移概率属于一个不确定性集合，智能体的目标是最大化最坏情况下的累积奖励。这等价于一个两人零和博弈：智能体选择策略最大化奖励，"自然对手"选择转移概率最小化奖励。


对抗训练（Adversarial Training） 在仿真中引入对抗性扰动：向观测添加对抗噪声、向动作施加对抗力、或修改环境参数。通过在这些对抗条件下训练，策略获得更好的鲁棒性。RARL（Robust Adversarial RL）同时训练一个主智能体和一个对抗智能体，对抗智能体专门发现主智能体的弱点。


竞争 RL 与安全 AI 研究有深刻联系。理解和防御对抗性攻击、设计在不确定环境中安全运行的策略、以及构建多方博弈中的均衡机制，都是竞争 RL 理论和方法的重要应用方向。


小结
    

  • 竞争 RL 处理智能体之间存在利益冲突的博弈场景，追求均衡策略
    • 

  • 自博弈是最成功的竞争训练方法，AlphaZero 展示了从零开始达到超人水平的能力
    • 

  • 策略遗忘和循环动态是自博弈的核心挑战，对手采样策略是关键缓解手段
    • 

  • 虚拟博弈通过迭代最优响应逼近纳什均衡，PSRO 是其现代推广
    • 

  • 竞争 RL 的思想可用于提升策略的对抗鲁棒性，与安全 AI 研究密切相关
    • 

  • 非传递性博弈中不存在单一最强策略，需要维护多样化的策略种群
