合作强化学习

核心概念

合作强化学习（Cooperative Reinforcement Learning）研究多个智能体在共享奖励或共同目标下协同学习的问题。在完全合作博弈中，所有智能体共享相同的团队奖励函数，目标是最大化团队的累积收益。然而，即使目标一致，合作学习也面临巨大挑战：如何在只能看到本地观测的条件下做出对团队最优的决策？如何将团队奖励公平地分配给每个智能体的贡献？

合作 MARL 的核心范式是 CTDE（集中训练分布式执行）——训练时利用全局信息学习协作策略，执行时每个智能体只依赖本地观测独立行动。这一范式的关键挑战是信用分配（Credit Assignment）：团队获得的奖励是所有智能体联合行为的结果，如何判断每个智能体对团队奖励的贡献？

VDN 与 QMIX 值分解
值分解（Value Decomposition） 方法将团队的联合 Q 函数分解为各智能体局部 Q 函数的组合，使得分布式执行时每个智能体可以独立做贪心决策，同时保证联合贪心等价于全局最优。


VDN（Value Decomposition Networks） 是最简单的值分解方法，假设联合 Q 函数是各智能体局部 Q 函数的简单加法：Qtot(s, a_1,...,a_N) = Σ_i Q_i(o_i, a_i)。这保证了 argmax{a1,...,a_N} Q_tot = (argmax{a1} Q_1,...,argmax{a_N} Q_N)，即联合贪心等价于各自独立贪心。


VDN 的加法分解限制了表达能力——它无法表示智能体之间的非线性交互。QMIX 将加法约束放松为单调性约束：∂Q_tot/∂Q_i ≥ 0，即每个智能体的局部 Q 值增加一定导致团队 Q 值增加。QMIX 使用超网络（Hypernetwork）来生成满足单调性约束的混合网络权重，混合网络的输入是各智能体的局部 Q 值，输出是 Q_tot。全局状态信息通过超网络条件化混合权重来引入。

单调性约束也限制了 QMIX 的表达能力——它无法表示某些非单调的联合价值函数。QTRAN 和 QPLEX 等后续工作尝试在保证 IGM（Individual-Global-Max）一致性的前提下进一步放松约束，但通常以牺牲训练稳定性为代价。


MAPPO 与多智能体策略优化
MAPPO（Multi-Agent PPO） 将 PPO 算法直接扩展到多智能体设定，是当前最强大的合作 MARL 算法之一。MAPPO 的设计哲学是"简单但有效"——它表明，精心调优的 PPO 加上集中式价值函数就足以在许多 MARL 基准上取得顶尖性能，不需要复杂的值分解或通信机制。


MAPPO 的核心设计包括：共享的 Actor 网络（所有智能体使用相同的策略网络但输入不同的本地观测）、集中式 Critic（使用全局状态作为输入估计价值函数）、以及标准的 PPO 裁剪目标和 GAE 优势估计。


MAPPO 的成功很大程度上归功于一系列实现细节：全局状态的精心设计（包含所有智能体的可观测信息拼接）、合理的网络架构选择（隐藏层大小、激活函数）、以及超参数的系统调优。这些"工程细节"对最终性能的影响往往超过算法本身的选择。


合作 MARL 在许多实际场景中有重要应用：多机器人协同搬运、无人机编队、交通信号协同控制、以及多人协作游戏（如 StarCraft 的微操控制）。选择具体算法时需要权衡问题规模（智能体数量）、观测共享程度和执行时的通信约束。


角色分化与任务分配
在复杂的合作任务中，高效的团队合作往往需要智能体之间的角色分化（Role Specialization）——不同智能体承担不同的功能角色，而非所有智能体学习相同的行为。


参数共享与角色嵌入：当所有智能体使用共享参数的策略网络时，通过为每个智能体提供不同的角色嵌入（Role Embedding）来区分功能。角色嵌入可以是预定义的（基于智能体编号）或学习的（基于智能体的观测历史或任务分配）。


RODE（Role-Oriented Decomposition） 先将智能体分为不同角色类别，每个角色对应一个动作子空间。角色选择网络根据全局状态为每个智能体分配角色，然后智能体在对应角色的动作子空间内做决策。这既减小了每个智能体的搜索空间，又自然地实现了功能分化。


角色分化的涌现也可以不通过显式机制——在足够长的训练中，共享参数的智能体也可能自发地发展出不同的行为模式。这种自发分化的条件和机制是 MARL 研究中的有趣问题。


小结
    

  • 合作 MARL 中所有智能体共享团队奖励，核心挑战是信用分配
    • 

  • VDN 和 QMIX 通过值分解将团队 Q 函数分解为局部 Q 的组合
    • 

  • QMIX 的单调性约束保证了 IGM 一致性但限制了表达能力
    • 

  • MAPPO 展示了精心调优的 PPO + 集中式 Critic 的强大性能
    • 

  • 角色分化（显式或隐式）是复杂合作任务中高效团队合作的关键
    • 

  • 算法选择需要权衡智能体数量、观测共享和通信约束
