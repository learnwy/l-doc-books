策略梯度

核心概念

策略梯度（Policy Gradient）方法直接对参数化策略 π_θ(a|s) 进行优化，通过梯度上升调整参数 θ 使得期望累积奖励最大化。与基于值的方法先学习价值函数再导出策略不同，策略梯度方法跳过了价值函数这个中间步骤，直接在策略空间中搜索最优策略。

策略梯度方法的优势包括：天然支持连续动作空间（策略可以输出连续动作的概率分布参数）、能学习随机策略（在部分可观测或多智能体场景中可能是最优的）、策略参数化提供了更平滑的优化景观（相比基于值方法中 argmax 操作导致的不连续性）。

策略梯度定理
策略梯度定理是整个策略梯度方法家族的理论基石。定义目标函数 J(θ) = E*{τ~π*θ}[R(τ)]，其中 R(τ) 是轨迹 τ 的累积回报。策略梯度定理给出了 J(θ) 对 θ 的梯度的精确表达式：


∇θ J(θ) = E{τ~π*θ}[Σ_t ∇*θ log π_θ(a_t|s_t) · G_t]


这个公式的深刻之处在于：虽然 J(θ) 依赖于环境的转移概率 P(s'|s,a)，但梯度表达式中不包含转移概率的导数——梯度只涉及策略的对数概率梯度和回报，两者都可以从采样轨迹中直接计算。


直觉上，∇θ log πθ(a_t|s_t) 指示了增加动作 a_t 概率的参数调整方向，G_t 作为权重决定了调整幅度——回报高的动作被强化（概率增加），回报低的动作被弱化（概率降低）。这与生物学中的操作条件反射有惊人的相似之处。


策略梯度定理有多种等价形式。除了使用完整回报 G_t 外，还可以使用 Q^π(s_t,a_t)、优势函数 A^π(s_t,a_t) = Q^π(s_t,a_t) - V^π(s_t)、或 TD 误差 δ_t 作为加权因子。使用优势函数可以在不引入偏差的情况下降低方差，是实践中最常用的形式。


REINFORCE 算法
REINFORCE（Williams, 1992）是策略梯度定理最直接的实现：采样完整回合，计算每步的回报，用策略梯度定理更新参数。


REINFORCE 的更新规则为：θ ← θ + α · Σ*t ∇*θ log π_θ(a_t|s_t) · G_t


尽管简单优雅，REINFORCE 存在严重的高方差问题。G_t 作为整个后续轨迹的累积回报，受到从时间步 t 到回合结束所有随机性的影响。轨迹越长，方差越大，学习越不稳定。这限制了 REINFORCE 在复杂问题上的实际应用。


基线减除（Baseline Subtraction） 是降低方差最有效的技术之一。将更新规则修改为 θ ← θ + α · Σ*t ∇θ log πθ(a_t|s_t) · (G_t - b(s_t))，其中 b(s_t) 是与动作无关的基线函数。数学上可以证明基线不引入偏差（因为 E[∇*θ log π_θ · b(s)] = 0），但选择好的基线可以大幅降低方差。最常用的基线是状态价值函数 V(s_t) 的估计。


因果性技巧（Causality Trick） 利用"未来的奖励不依赖于过去的动作"这一因果关系，将 G_t 替换为从时刻 t 开始的"奖励到走"（Reward-to-Go），移除 t 之前的奖励项，进一步降低方差。


似然比技巧与得分函数
策略梯度定理的推导依赖于一个关键的数学工具——似然比技巧（Likelihood Ratio Trick），也称为得分函数估计器（Score Function Estimator）或 REINFORCE 技巧。


其核心等式为：∇θ E{xpθ}[f(x)] = E{xp*θ}[f(x) · ∇*θ log p_θ(x)]


这个等式将一个难以计算的期望梯度（因为期望本身依赖于 θ）转化为一个可以通过采样近似的期望。这一技巧不仅适用于强化学习，在变分推断、黑箱优化等领域也有广泛应用。


似然比估计器是无偏的但方差较大。除了基线减除外，其他方差缩减技术包括：**控制变量法（Control Variates）**引入与梯度相关但期望已知的辅助变量来缩减方差；**重参数化技巧（Reparameterization Trick）**在策略输出可重参数化时（如高斯策略），通过重参数化将随机性从策略中分离出来，使梯度可以直接通过样本回传，通常方差远低于似然比估计器。

重参数化技巧对于高斯策略的具体操作是：将动作 a = μθ(s) + σθ(s)·ε（其中 ε~N(0,1)）代入目标函数，梯度可以直接对 μθ 和 σθ 求导而无需通过对数概率。这在 SAC 和连续控制算法中被广泛采用。


策略参数化与动作分布
策略的参数化方式直接影响算法的适用性和效率。不同的动作空间类型需要不同的参数化策略。


对于离散动作空间，最常用的参数化是 Softmax 策略：πθ(a|s) = exp(fθ(s,a)) / Σ*{a'} exp(f*θ(s,a'))，其中 f_θ 是神经网络输出的动作偏好值（logits）。Softmax 保证了所有动作概率为正，天然具备探索性。


对于连续动作空间，最常用的是高斯策略：πθ(a|s) = N(μθ(s), σθ(s)²)。均值 μθ 和标准差 σ_θ 由神经网络参数化。训练初期 σ 较大鼓励探索，随着训练进行 σ 逐渐减小。对角高斯（各维度独立）是最简单的形式，混合高斯可以表达多模态分布。


对于有界连续动作空间（如关节角度在 [-π, π] 范围内），常用 Squashed Gaussian：先采样无界高斯分布，再通过 tanh 函数压缩到 [-1, 1] 范围，并校正雅可比行列式以保证概率密度的正确性。这是 SAC 算法中的标准做法。


策略梯度方法的核心局限是样本效率低——每次参数更新后之前的轨迹数据就过时了（因为策略已改变），需要重新采样。这一限制驱动了 Actor-Critic 和 PPO 等更高效算法的发展。


小结
    

  • 策略梯度方法直接优化参数化策略，天然支持连续动作空间和随机策略
    • 

  • 策略梯度定理是理论基石，梯度表达式不涉及环境转移概率的导数
    • 

  • REINFORCE 是最基本的实现但存在高方差问题，基线减除和因果性技巧是关键缓解手段
    • 

  • 似然比技巧和重参数化技巧是两种主要的梯度估计方法，后者方差更低
    • 

  • 策略参数化需要匹配动作空间类型：离散用 Softmax，连续用高斯或 Squashed Gaussian
    • 

  • 策略梯度方法的核心局限是样本效率低，推动了 Actor-Critic 等改进架构的发展
