Actor-Critic 架构

核心概念

Actor-Critic 是一种结合了策略优化和价值估计的混合架构，通过引入 Critic（价值函数估计器）来降低 Actor（策略）梯度估计的方差。Actor 负责选择动作，Critic 负责评估动作的好坏。这种分工使得策略梯度方法既保持了直接优化策略的灵活性，又获得了基于值方法的低方差优势。

Actor-Critic 的核心思想是用 Critic 提供的优势估计 A(s,a) 替代 REINFORCE 中的完整回报 G_t，在不引入偏差（或可控偏差）的前提下大幅降低梯度方差。优势函数 A^π(s,a) = Q^π(s,a) - V^π(s) 衡量的是在状态 s 选择动作 a 比"平均动作"好多少，天然具有零均值的性质，是方差缩减的理想选择。

优势函数与 TD 误差
优势函数 A^π(s,a) = Q^π(s,a) - V^π(s) 的核心作用是将策略梯度中的绝对值信号转化为相对值信号。使用绝对回报 G_t 作为梯度权重时，即使所有动作都获得正回报，概率更新的方向也可能受噪声主导。优势函数通过减去基线 V(s)，使得"好于平均"的动作获得正权重、"差于平均"的动作获得负权重，梯度方向更加准确。


在实践中，优势函数的精确计算需要知道 Q^π(s,a) 和 V^π(s)，两者都不直接可得。最简单的近似是使用 TD 误差 δt = r{t+1} + γ·Vw(s{t+1}) - V_w(s_t) 作为优势的单步估计。数学上可以证明 E[δ_t | s_t, a_t] = A^π(s_t, a_t)（当 V_w 是 V^π 的精确估计时），因此 TD 误差是优势函数的无偏估计。


然而，单步 TD 误差引入了自举偏差（因为 V_w 不是 V^π 的精确估计）。为了在偏差和方差之间找到更好的平衡，广义优势估计（Generalized Advantage Estimation, GAE） 将多步 TD 误差进行指数加权平均：


A^{GAE(γ,λ)}t = Σ{l=0}^{∞} (γλ)^l · δ_{t+l}


其中 λ∈[0,1] 控制偏差-方差权衡。λ=0 时退化为单步 TD 误差（低方差高偏差），λ=1 时等价于蒙特卡洛优势估计（高方差无偏差）。实践中 λ 通常设为 0.95-0.99，在大多数任务上效果良好。


GAE 是 PPO 和 A3C 等现代算法的标准优势估计方法，也是 Actor-Critic 架构在实践中成功的关键因素之一。


A2C 与 A3C
A2C（Advantage Actor-Critic） 是 Actor-Critic 架构的同步实现。多个环境实例并行运行，收集固定步数的经验后统一计算梯度并更新参数。同步更新保证了所有 worker 使用相同的策略版本，梯度估计稳定。


A3C（Asynchronous Advantage Actor-Critic） 是异步版本，每个 worker 独立地与自己的环境交互并计算梯度，然后异步地更新共享参数。异步更新的优势是无需等待最慢的 worker，吞吐量更高；但不同 worker 使用的策略版本可能不一致，引入了策略延迟（Policy Lag）。

实证研究表明，在现代 GPU 硬件上 A2C 的效果通常不逊于 A3C，且实现更简单、调试更方便。因此 A2C 成为了更主流的选择，特别是在 PPO 的实现中通常采用 A2C 风格的同步并行。


网络架构设计
Actor-Critic 架构中网络结构的设计对学习效果有重要影响。核心设计决策是 Actor 和 Critic 是否共享网络参数。


共享网络：Actor 和 Critic 共享底层特征提取网络，只在最后一层分别输出动作概率和状态价值。优势是参数更少、特征提取更高效（特别是从图像等高维输入学习时），且两个任务可以互相提供有用的梯度信号。缺点是两个优化目标可能互相干扰——Actor 需要的特征和 Critic 需要的特征不完全相同。


独立网络：Actor 和 Critic 使用完全独立的网络，各自有独立的参数和优化器。优势是避免了目标冲突，各自可以学到最适合自己任务的特征表示。缺点是参数量翻倍，且失去了特征共享带来的正则化效果。


实践中，图像输入通常使用共享网络（因为卷积特征提取的计算成本高），低维状态输入可以考虑独立网络。当使用共享网络时，需要仔细调节 Actor 和 Critic 损失的权重比例，以及添加熵正则化项防止策略过早收敛。


总损失函数通常为：L = L_actor + c_1 · L_critic + c_2 · H(π)，其中 c_1 是 Critic 损失权重（通常 0.5），c_2 是熵正则化系数（通常 0.01），H(π) 是策略的熵，鼓励探索。


小结
    

  • Actor-Critic 架构结合策略优化（Actor）和价值估计（Critic），大幅降低策略梯度的方差
    • 

  • 优势函数将绝对回报信号转化为相对信号，TD 误差是其简单有效的单步近似
    • 

  • GAE 通过 λ 参数在偏差和方差之间灵活权衡，是现代算法的标准优势估计方法
    • 

  • A2C（同步）在现代硬件上通常不逊于 A3C（异步），且实现更简单
    • 

  • 共享网络在高维输入时高效，独立网络在低维输入时更灵活
    • 

  • Actor-Critic 是 PPO、SAC 等现代算法的基础架构
