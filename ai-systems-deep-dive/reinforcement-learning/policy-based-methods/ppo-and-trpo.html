Part I · 机器学习与深度学习 (ML & Deep Learning)强化学习 简介基于策略的方法 简介PPO 与 TRPO

PPO 与 TRPO

核心概念

PPO（Proximal Policy Optimization）和 TRPO（Trust Region Policy Optimization）是深度强化学习中应用最广泛的一代策略优化算法，它们解决了策略梯度方法中的一个核心问题：如何控制策略更新的步幅？朴素的策略梯度可能因为一步过大的更新而导致策略性能崩溃——新策略在某些状态上的行为完全偏离，产生的数据质量急剧下降，形成恶性循环。TRPO 和 PPO 通过不同的机制限制策略变化幅度，确保每次更新都是"安全"的。

TRPO 提出了信赖域（Trust Region）的思想，通过 KL 散度约束新旧策略的距离。PPO 则用更简单的裁剪（Clipping）机制实现了类似的效果，在保持 TRPO 稳定性的同时大幅简化了实现和计算。PPO 因其优秀的性能-复杂度平衡，长期是工业界和学术界使用最广的策略优化算法：在游戏、机器人等经典控制任务中至今仍是默认基线之一。但有一个必须更新的认知——在 LLM 后训练这一当下规模最大的 RL 应用场景中，2024 年以来 PPO 的主流位置已被以 GRPO 为代表的简化策略优化算法取代（DeepSeek-R1 等公开技术报告均以 GRPO 训练推理模型），本文末节专门交代这段范式交接。

TRPO 信赖域优化

TRPO 的理论基础是单调改进定理（Monotonic Improvement Theorem）。该定理证明：如果新策略 π' 在所有状态上的优势函数 A^π(s,a) 的期望为非负，则新策略的性能不低于旧策略。但直接优化这一条件需要遍历所有状态，不可行。

TRPO 将其转化为一个有约束优化问题：最大化替代目标函数

LCPI(θ)=E^t[πθ(at∣st)πθold(at∣st) At]s.t.E^t[KL(πθold(⋅∣st) ∥ πθ(⋅∣st))]≤δL^{\mathrm{CPI}}(\theta) = \hat{\mathbb{E}}_t\left[\frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{\mathrm{old}}}(a_t \mid s_t)}\, A_t\right] \quad \text{s.t.}\quad \hat{\mathbb{E}}_t\left[\mathrm{KL}\big(\pi_{\theta_{\mathrm{old}}}(\cdot \mid s_t) \,\|\, \pi_\theta(\cdot \mid s_t)\big)\right] \le \deltaLCPI(θ)=E^t​[πθold​​(at​∣st​)πθ​(at​∣st​)​At​]s.t.E^t​[KL(πθold​​(⋅∣st​)∥πθ​(⋅∣st​))]≤δ

替代目标函数中的概率比 rt(θ)=πθ(at∣st) / πθold(at∣st)r_t(\theta) = \pi_\theta(a_t \mid s_t)\, /\, \pi_{\theta_{\mathrm{old}}}(a_t \mid s_t)rt​(θ)=πθ​(at​∣st​)/πθold​​(at​∣st​) 使得可以用旧策略收集的数据来评估新策略（离策略评估）。KL 散度约束确保新旧策略不会差距太大，保证替代目标是真实目标的良好近似。

TRPO 使用共轭梯度法（Conjugate Gradient） 近似求解约束优化问题，避免了显式计算和存储 Fisher 信息矩阵（Hessian 矩阵的自然梯度版本）。然后通过线搜索（Line Search） 回退到满足 KL 约束的步长。

虽然 TRPO 有严格的理论保证，但共轭梯度和线搜索的实现复杂度高，且不容易与多 GPU 并行训练结合。这些实际限制催生了 PPO 的诞生。

PPO 裁剪目标函数

PPO-Clip 是 PPO 的核心变体，通过裁剪概率比来限制策略更新幅度：

L^{CLIP}(θ) = E_t[min(r_t(θ)·A_t, clip(r_t(θ), 1-ε, 1+ε)·A_t)]

其中 ε 是裁剪参数（通常为 0.2）。这个目标函数的精妙之处在于：

当 A_t > 0（动作优于平均）时，目标鼓励增加该动作的概率（r_t 增大），但 r_t 被裁剪在 1+ε 以内，防止概率增加过多。当 A_t < 0（动作差于平均）时，目标鼓励降低该动作的概率（r_t 减小），但 r_t 被裁剪在 1-ε 以上，防止概率降低过多。

graph LR
    A[概率比 r_t] --> B{A_t > 0?}
    B -->|是| C[min: r_t 被上界 1+ε 裁剪]
    B -->|否| D[min: r_t 被下界 1-ε 裁剪]
    C --> E[防止贪心增加]
    D --> F[防止过度惩罚]
    E --> G[稳定策略更新]
    F --> G

PPO 的完整训练流程包括：用当前策略收集一批经验 → 计算 GAE 优势估计 → 对同一批数据进行多个 epoch 的小批量 SGD 更新（通常 3-10 个 epoch）→ 丢弃旧数据，用更新后的策略重新采样。多 epoch 复用数据是 PPO 的一个重要实践——虽然数据来自旧策略，但裁剪机制限制了更新幅度，使得旧数据仍然有效。

裁剪参数 ε 0.1-0.3 控制策略变化幅度
GAE λ 0.95-0.99 偏差-方差权衡

PPO 实践与调优

PPO 的实际性能高度依赖于正确的实现细节和超参数调优。以下是经过大量实践验证的关键技巧。

优势标准化：对每个小批量内的优势估计进行标准化（减均值除标准差），使梯度幅度与任务奖励尺度无关。这是 PPO 稳定训练最重要的技巧之一。

价值函数裁剪：类似于策略裁剪，对 Critic 的价值函数更新也进行裁剪，防止价值估计的剧烈变化。但实际效果存在争议，部分研究显示这一技巧并不总是有益的。

梯度范数裁剪：将梯度的 L2 范数限制在最大值（通常 0.5）以内，防止梯度爆炸导致的不稳定更新。

学习率退火：线性衰减学习率到零，在训练后期使策略更新越来越保守，有助于最终策略的精细调优。

正交初始化：用正交矩阵初始化网络权重（增益因子为 √2），策略输出层使用较小的增益（0.01），价值输出层使用增益 1。这种初始化使得初始策略接近均匀随机，有利于早期探索。

PPO 在 Atari 游戏、MuJoCo 连续控制和早期 RLHF（InstructGPT 一代的大语言模型对齐）等众多领域都展现了强大的性能。它的成功在于找到了理论严谨性和实现简洁性之间的最佳平衡点。

PPO 之后：GRPO 与 LLM 后训练的范式交接

在经典控制基准之外，PPO 曾长期占据 LLM 后训练的主舞台（InstructGPT 即用 PPO 做对齐训练）。但把 PPO 直接搬到 LLM 上有两个结构性负担：一是需要一个与策略模型同规模的价值网络做逐 token 信用分配，显存与计算开销巨大；二是优势估计依赖可学习的 Critic，在回答结束才给出的稀疏奖励下训练容易不稳定。

GRPO（Group Relative Policy Optimization） 对这两个负担做了减法。它最早见于 DeepSeekMath（arXiv:2402.03300），后因 DeepSeek-R1（arXiv:2501.12948）用它训练出推理模型而广为人知。GRPO 对同一提示采样一组 GGG 个回答，用组内奖励统计量直接构造优势，完全去掉价值网络：

策略优化思想是连续演进的：理解 PPO 的信赖域与裁剪直觉，是看懂 GRPO 为何如此设计的前提。LLM 后训练的完整叙事——可验证奖励（RLVR）、过程奖励模型、推理模型 RL 与 Agentic RL——在本 hub 第 6 章的 RLHF 与大模型对齐 中系统展开。

  • TRPO 通过 KL 散度约束保证策略更新的单调改进，但实现复杂
  • PPO-Clip 通过裁剪概率比实现类似的更新约束，极大简化了实现
  • PPO 的核心超参数是裁剪参数 ε（控制更新幅度）和 GAE λ（偏差-方差权衡）
  • 多 epoch 复用数据是 PPO 高样本效率的关键，裁剪机制保证了旧数据的有效性
  • 优势标准化、梯度裁剪和正交初始化是 PPO 稳定训练的核心实践技巧
  • PPO 在经典控制中仍是默认基线，但在 LLM 后训练场景，主流位置自 2024 年起已被 GRPO 系取代
  • GRPO 保留 PPO 裁剪目标的形状，用同提示多采样的组内统计量替代可学习基线；DAPO 等后续工作持续工程化改进
