基于模型的强化学习

核心概念

基于模型的强化学习（Model-Based Reinforcement Learning, MBRL）通过学习环境的动态模型（转移函数和奖励函数）来提升学习效率。与无模型方法（Model-Free）直接从经验中学习策略或价值函数不同，MBRL 先建立一个"世界模型"来模拟环境行为，然后利用这个模型进行规划或生成合成经验来辅助策略学习。

MBRL 的核心优势是样本效率——通过学习环境模型，智能体可以在"想象"中进行大量试验而不需要真实的环境交互。这在真实交互成本高昂的场景（如机器人控制、医疗决策）中至关重要。

Dyna 架构与模型集成
Dyna 架构（Sutton, 1991）是 MBRL 最经典的框架，它将真实经验学习和模型内模拟学习统一到一个循环中。Dyna 的核心思想简洁优雅：每次真实交互后，除了用真实经验更新价值函数（Direct RL），还从学习到的模型中生成多条合成经验，用这些合成经验进行额外的更新（Planning）。


Dyna-Q 的每步操作包括：与真实环境交互获得 (s,a,r,s') → 用真实经验更新 Q 函数 → 用真实经验更新模型 → 从模型中随机采样 n 个状态-动作对，生成合成经验 → 用合成经验更新 Q 函数。参数 n 控制了每步真实交互对应的模型内规划量——n 越大样本效率越高，但计算成本也越大。


模型误差是 MBRL 的核心挑战。当模型不准确时，基于模型生成的合成经验会包含系统性偏差，可能导致策略学到错误的行为——这被称为模型偏差（Model Bias） 或复合误差（Compounding Error）。在长期预测中，单步误差会逐步累积，使得长视野规划变得不可靠。


模型集成（Model Ensemble） 是缓解模型不确定性的主要技术。通过训练多个模型并聚合它们的预测来估计不确定性——模型之间预测分歧大的区域意味着模型不确定性高。PETS（Probabilistic Ensemble Trajectory Sampling）和 MBPO 都使用了集成模型。


世界模型与想象力学习
世界模型（World Model） 是一个能预测环境动态的神经网络，它学习从当前状态和动作预测下一状态和奖励。世界模型可以是确定性的（直接预测下一状态）或概率性的（预测状态的分布），后者能更好地处理环境的随机性和模型的不确定性。


Dreamer 系列（Hafner 等）是世界模型方法的代表。Dreamer 在潜在空间（Latent Space）中学习世界模型，避免了在高维观测空间（如像素）中直接做预测的困难。其核心组件包括：RSSM（Recurrent State Space Model）用于建模潜在动态、图像编码器/解码器用于感知、以及在潜在空间中通过反向传播直接优化的 Actor-Critic。


Dreamer v3 通过分类潜在表示（Categorical Latent）、对称正态损失和 KL 平衡等技巧，在 Atari、DM Control、Minecraft 等多个基准上用统一的超参数取得了当时最优或接近最优的性能，展示了 MBRL 的巨大潜力。

模型预测控制
模型预测控制（Model Predictive Control, MPC） 是利用世界模型进行在线规划的方法。MPC 在每个时间步使用模型向前展开多个候选动作序列，评估每个序列的累积奖励，选择最优序列的第一个动作执行，然后在下一步重新规划——这就是"滚动规划"（Receding Horizon）。


交叉熵方法（CEM） 是 MPC 中最常用的规划算法。它维护一个动作序列的分布（通常是高斯），通过迭代采样、评估、更新精英样本来逐步优化动作分布：初始化动作分布 → 采样 N 个动作序列 → 在模型中展开评估 → 选择 top-K（精英）→ 用精英样本更新分布参数 → 重复。


MPC 的优势在于它不需要训练策略网络，可以即时适应环境变化，且对模型误差有一定的鲁棒性（因为只执行第一个动作就重新规划）。但 MPC 的计算成本高（每步都需要大量模型推演），且规划深度受模型精度限制。


MBPO（Model-Based Policy Optimization） 结合了世界模型和无模型方法的优势。它用学习到的集成模型生成短轨迹合成数据，将合成数据混入真实数据的回放缓冲区中，然后用标准的 SAC 算法在混合数据上训练策略。MBPO 通过理论分析确定了安全的合成轨迹长度——当模型误差超过一定阈值时，停止生成更长的轨迹。


小结
    

  • 基于模型的 RL 通过学习环境动态模型大幅提升样本效率
    • 

  • Dyna 架构统一了真实经验学习和模型内规划，参数 n 控制规划量
    • 

  • 模型误差和复合误差是 MBRL 的核心挑战，集成模型是主要缓解手段
    • 

  • 世界模型在潜在空间中建模，Dreamer 系列展示了在高维视觉任务上的强大能力
    • 

  • MPC 利用模型进行在线规划，无需训练策略网络，对环境变化适应快
    • 

  • MBPO 等混合方法结合了模型学习和无模型优化的优势
