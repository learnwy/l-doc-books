Part I · 机器学习与深度学习 (ML & Deep Learning)强化学习 简介基于值的方法 简介时序差分学习

时序差分学习

核心概念

时序差分学习（Temporal-Difference Learning, TD）是强化学习中最核心的学习机制，它巧妙地结合了蒙特卡洛方法的无模型采样和动态规划的自举（Bootstrapping）更新。TD 方法无需等待回合结束，在每一个时间步都可以根据即时奖励和对下一状态价值的估计来更新当前状态的价值——这使得它既能应用于回合制任务，也能处理持续任务。

TD 学习的核心更新公式是：V(st) ← V(s_t) + α · [r{t+1} + γ·V(s*{t+1}) - V(s_t)]，其中 r*{t+1} + γ·V(s*{t+1}) 是 TD 目标（TD Target），r*{t+1} + γ·V(s*{t+1}) - V(s_t) 是 TD 误差（TD Error, δ_t）。TD 目标用 V(s*{t+1}) 的当前估计代替了蒙特卡洛方法中的完整回报 G_t，这就是"自举"——用估计值更新估计值。

TD(0) 算法
TD(0) 是最基本的时序差分方法，使用单步自举进行价值估计更新。它的名称中的"0"指的是只向前看一步——更新目标是 r*{t+1} + γ·V(s*{t+1})，其中 V(s_{t+1}) 是下一状态的当前估计值。


TD(0) 的核心优势在于它能在每一步交互后立即更新，不必等到回合结束。这意味着：长回合中的早期状态不必等到回合结束就能开始学习；持续任务（没有回合结束的任务）也能使用 TD 方法；在线学习场景中可以边交互边学习。


TD(0) 的收敛性已被严格证明：在适当的学习率条件下（学习率求和趋于无穷、学习率平方和有界），TD(0) 保证收敛到 V^π。虽然 TD 目标是有偏的（因为 V(s*{t+1}) 不是 V^π(s*{t+1}) 的精确值），但在收敛过程中偏差逐渐消除。


TD(0) 的一个重要理论性质是它收敛到**最大似然 MDP 估计（Certainty Equivalence Estimate）**的解——即它隐含地在估计环境模型并求解该模型的最优值，这通常比蒙特卡洛的纯样本均值估计更数据高效。


n 步 TD 与 TD(λ)
TD(0) 和蒙特卡洛方法分别位于自举程度的两个极端：TD(0) 完全自举（只看一步），MC 完全不自举（看到回合结束）。n 步 TD 方法提供了两者之间的连续谱。


n 步 TD 使用 n 步回报作为更新目标：Gt^{(n)} = r{t+1} + γ·r*{t+2} + ... + γ^{n-1}·r*{t+n} + γ^n·V(s_{t+n})。n=1 退化为 TD(0)，n→∞ 退化为 MC。选择合适的 n 可以在偏差和方差之间找到更好的平衡点——较小的 n 偏差大但方差小，较大的 n 偏差小但方差大。

TD(λ) 通过参数 λ∈[0,1] 对所有 n 步回报进行指数加权平均，形成 λ-回报：Gt^λ = (1-λ)·Σ{n=1}^{∞} λ^{n-1}·G_t^{(n)}。λ=0 等价于 TD(0)，λ=1 等价于 MC。TD(λ) 的优雅之处在于它可以通过资格迹（Eligibility Trace） 高效实现，无需真正计算所有 n 步回报。


资格迹 e_t(s) 记录了每个状态对当前 TD 误差的"贡献度"。当状态被访问时其资格迹增加（跳跃），随后每步按 γλ 衰减。更新规则变为对所有状态同时更新：V(s) ← V(s) + α·δ_t·e_t(s)。这种前向视角的等价性使得 TD(λ) 既能享受 λ-回报的统计优势，又能在每步高效地在线更新。


偏差-方差权衡
TD 方法与 MC 方法之间的核心差异体现为偏差-方差权衡（Bias-Variance Tradeoff），这是理解和选择强化学习算法的关键视角。


蒙特卡洛方法使用完整回报 G_t 作为更新目标。G_t 是 V^π(s_t) 的无偏估计（E[G_t] = V^π(s_t)），但方差很大（因为它受到策略随机性和环境随机性在整个轨迹上的累积影响）。


TD(0) 使用 r*{t+1} + γ·V(s*{t+1}) 作为更新目标。由于 V(s_{t+1}) 是估计值而非真实值，TD 目标是有偏的。但它的方差通常远低于 MC——因为只涉及单步随机性，而非整个轨迹。


在实践中，TD 方法几乎总是比 MC 方法更高效。这是因为较低的方差使得学习更加稳定，自举引入的偏差会随着学习的进行逐渐减小。特别是在长回合或随机性较大的环境中，TD 的优势更加显著。


然而，自举也带来了风险：如果初始价值估计严重偏离真实值，自举可能放大错误并导致收敛到错误的解。这就是为什么价值函数初始化和学习率调度在 TD 方法中特别重要。在函数近似场景下，这种风险更加突出——TD 方法与函数近似结合时可能不收敛（致命三角问题），这是深度强化学习面临的核心理论挑战之一。


小结
    

  • 时序差分学习结合了蒙特卡洛的无模型采样和动态规划的自举更新
    • 

  • TD(0) 在每步用即时奖励加下一状态估计值进行更新，方差低但有偏
    • 

  • n 步 TD 提供 TD(0) 和 MC 之间的连续谱，允许灵活的偏差-方差权衡
    • 

  • TD(λ) 通过资格迹高效实现对所有 n 步回报的指数加权平均
    • 

  • 偏差-方差权衡是理解 TD 与 MC 差异的关键：TD 低方差但有偏，MC 无偏但高方差
    • 

  • TD 方法在实践中几乎总是优于纯 MC 方法，是现代强化学习的核心学习机制
    •
