动态规划

核心概念

动态规划（Dynamic Programming, DP）是求解已知 MDP 的经典方法。它假设环境的转移概率 P(s'|s,a) 和奖励函数 R(s,a,s') 完全已知，通过系统地利用 Bellman 方程的递归结构来计算最优价值函数和最优策略。动态规划是强化学习算法的理论基石——虽然"已知模型"的假设在实际中很少成立，但 DP 的思想深刻影响了后续所有无模型方法的设计。

动态规划的核心原理是最优子结构（Optimal Substructure）：一个最优策略的子策略也必须是最优的。这一性质使得复杂的多步决策问题可以分解为简单的单步子问题，通过逐步求解子问题来构建全局最优解。

动态规划方法的特性对比：


| 方法     | 是否需要模型 | 更新方式                | 收敛速度       | 内存需求 | 适用规模 |
| -------- | ------------ | ----------------------- | -------------- | -------- | -------- | --- | ----- |
| 策略迭代 | 是           | 完全策略评估 + 贪心改进 | 快（策略空间） | O(       | S        | )   | 小-中 |
| 值迭代   | 是           | 单步 Bellman 最优更新   | 中（值空间）   | O(       | S        | )   | 小-中 |
| 异步 DP  | 是           | 选择性状态更新          | 取决于更新顺序 | O(       | S        | )   | 中    |
| 线性规划 | 是           | 凸优化求解              | 多项式时间     | O(       | S        | ²)  | 小    |


策略迭代算法
策略迭代（Policy Iteration）由两个交替执行的步骤组成：策略评估和策略改进。


策略评估（Policy Evaluation） 的目标是给定策略 π，计算其对应的状态价值函数 V^π。具体做法是反复对所有状态应用 Bellman 期望方程的更新规则：


V*{k+1}(s) ← Σ_a π(a|s) · Σ*{s'} P(s'|s,a) · [R(s,a,s') + γ · V_k(s')]


从任意初始值 V0 出发，反复迭代直到 max_s |V{k+1}(s) - V_k(s)| < θ（收敛阈值）。对于有限 MDP，策略评估保证收敛到真实的 V^π。策略评估也可以通过求解线性方程组 V = R^π + γ·P^π·V 直接得到精确解，但矩阵求逆的计算复杂度为 O(|S|³)，在大状态空间中不可行。


策略改进（Policy Improvement） 利用计算出的 V^π 构造更优的策略。对每个状态 s，贪心地选择使动作价值最大的动作：


π'(s) ← argmaxa Σ{s'} P(s'|s,a) · [R(s,a,s') + γ · V^π(s')]


策略改进定理保证 V^{π'} ≥ V^π 对所有状态成立。当 π' = π 时，说明已经达到最优，策略迭代终止。在有限 MDP 中，策略空间是有限的（最多 |A|^{|S|} 个确定性策略），加上每次改进严格不变差，保证了有限步收敛。


实践中策略迭代通常收敛很快——对于大多数问题，5-20 轮迭代即可找到最优策略。


值迭代算法
值迭代（Value Iteration）可以看作策略迭代的简化版本：将策略评估截断为仅一步更新，直接在每一步应用 Bellman 最优算子。


更新规则为：V*{k+1}(s) ← max_a Σ*{s'} P(s'|s,a) · [R(s,a,s') + γ · V_k(s')]


值迭代的收敛性由压缩映射定理（Contraction Mapping Theorem） 保证。Bellman 最优算子 T 满足 ||TV - TV'||∞ ≤ γ·||V - V'||∞，即每次应用算子后最大误差至少缩小 γ 倍。因此，经过 k 轮迭代后，误差上界为 γ^k · ||V0 - V*||∞。


值迭代与策略迭代的关键区别在于：策略迭代在策略空间中搜索（策略数量有限），每步可能需要多轮评估但策略改变大；值迭代在值空间中搜索（连续空间），每步计算轻量但收敛到精确值可能需要更多轮次。实践中两者的效率差异取决于具体问题，没有绝对优劣。

异步动态规划
标准的策略迭代和值迭代都是同步（Synchronous） 更新：每轮迭代需要扫描所有状态。当状态空间很大时，一轮完整扫描的计算成本极高。异步动态规划（Asynchronous DP）允许以任意顺序更新任意子集的状态，大幅降低每轮的计算负担。


原地值迭代（In-Place Value Iteration） 只维护一个价值函数数组，每次更新立即写入。与标准值迭代使用两个数组（旧值和新值）不同，原地更新使得后续状态能立即使用最新的估计值，通常加速收敛。


优先扫描（Prioritized Sweeping） 维护一个优先队列，优先更新那些 Bellman 误差最大的状态。直觉上，值变化大的状态最"需要"被更新，其更新也会对相邻状态产生最大影响。优先扫描可以将收敛所需的总更新次数减少一个数量级。


实时动态规划（Real-Time DP） 只更新智能体实际访问到的状态，将计算资源集中在相关状态子空间上。这对于大状态空间但智能体活动范围有限的问题特别有效。


异步 DP 的收敛性需要一个关键条件：每个状态必须被无限频繁地更新。只要满足这一条件，异步 DP 保证收敛到与同步 DP 相同的结果。


广义策略迭代
广义策略迭代（Generalized Policy Iteration, GPI）是对策略评估和策略改进交替执行这一模式的抽象概括。GPI 不要求策略评估必须收敛到精确的 V^π，也不要求策略改进必须是严格贪心——只要两个过程持续交互推动彼此改善，最终就会收敛到最优策略。


GPI 是几乎所有强化学习算法的统一框架。蒙特卡洛方法、时序差分学习、Q-learning、甚至策略梯度方法都可以看作 GPI 的不同实例化：它们在策略评估和策略改进的具体实现上各不相同，但都遵循"评估-改进"的基本交互模式。


GPI 的收敛直觉可以用"两力相向"来理解：策略评估使价值函数向当前策略的真实价值靠拢，策略改进使策略向当前价值函数的贪心策略靠拢。当且仅当两者同时稳定——即价值函数是当前策略的真实价值，且策略是当前价值函数的贪心策略——整个系统才达到不动点，此时必定是最优策略和最优价值函数。


动态规划在状态空间较小、模型已知的场景中是精确求解 MDP 的金标准。但其"完全已知模型"的假设在大多数实际场景中并不成立，且计算复杂度随状态空间大小呈多项式增长。这些限制推动了蒙特卡洛方法和时序差分学习等无模型方法的发展。


小结
    

  • 动态规划利用完全已知的环境模型精确求解 MDP，是强化学习算法的理论基石
    • 

  • 策略迭代交替执行策略评估和策略改进，在有限 MDP 上保证有限步收敛到最优
    • 

  • 值迭代通过反复应用 Bellman 最优算子逼近最优价值函数，收敛性由压缩映射定理保证
    • 

  • 异步动态规划通过选择性更新和优先扫描降低计算成本
    • 

  • 广义策略迭代（GPI）是几乎所有强化学习算法的统一框架
    • 

  • 动态规划的核心限制是要求已知模型和计算复杂度随状态空间增长
