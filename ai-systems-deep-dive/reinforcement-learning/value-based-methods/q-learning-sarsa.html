Q-learning 与 SARSA

核心概念

Q-learning 和 SARSA 是两种最经典的时序差分控制算法，它们将 TD 学习扩展到动作价值函数 Q(s,a) 的估计和策略优化。两者的核心区别在于更新目标的选择方式：Q-learning 是离策略（Off-Policy）算法，使用贪心动作的值作为更新目标；SARSA 是在策略（On-Policy）算法，使用实际执行的下一个动作的值作为更新目标。这一看似微小的差异导致了截然不同的学习行为和理论性质。

Q-learning 的更新规则：Q(st,a_t) ← Q(s_t,a_t) + α·[r{t+1} + γ·maxa Q(s{t+1},a) - Q(s_t,a_t)]

SARSA 的更新规则：Q(st,a_t) ← Q(s_t,a_t) + α·[r{t+1} + γ·Q(s*{t+1},a*{t+1}) - Q(s_t,a_t)]

Q-learning 算法详解
Q-learning 由 Watkins 于 1989 年提出，是强化学习历史上最重要的算法之一。它的核心洞见是：更新目标使用 maxa Q(s{t+1},a) 而非实际执行动作的 Q 值，使得学习过程独立于行为策略——无论智能体实际执行什么动作（包括随机探索动作），Q-learning 都在学习最优策略。


Q-learning 的完整算法流程是：初始化 Q 表，在每个时间步观察状态 st，按行为策略（通常是 ε-贪心）选择动作 a_t，执行后获得 r{t+1} 和 s*{t+1}，然后用 r*{t+1} + γ·maxa Q(s{t+1},a) 作为目标更新 Q(s_t,a_t)。


Q-learning 的收敛性定理指出：在表格情况下，如果所有状态-动作对被无限频繁地访问，且学习率满足 Robbins-Monro 条件（Σα = ∞, Σα² < ∞），Q-learning 保证以概率 1 收敛到最优动作价值函数 Q*。


Q-learning 的一个重要问题是最大化偏差（Maximization Bias）。由于更新目标中使用 max 操作，当 Q 估计存在噪声时，max 运算会系统性地高估价值——因为它总是选择噪声恰好为正的那个动作的估计值。这种偏差在早期学习阶段（Q 估计不准确时）特别严重。


Double Q-learning 通过维护两组 Q 值来解决最大化偏差。每次更新时随机选择一组来确定最优动作（选择），用另一组来评估该动作的值（评估）。这种解耦消除了系统性的高估偏差，在实践中显著提升了学习质量。


SARSA 算法详解
SARSA 的名称来源于其更新所需的五元组 (St, A_t, R{t+1}, S*{t+1}, A*{t+1})。与 Q-learning 不同，SARSA 使用实际在 s*{t+1} 执行的动作 a*{t+1} 的 Q 值作为更新目标，因此它学习的是当前策略（包括探索动作）的动作价值函数。


这一差异在有风险的环境中尤为显著。考虑一个悬崖行走（Cliff Walking）问题：沿悬崖边走是最短路径但有掉落风险（ε 概率随机动作可能导致坠崖）。Q-learning 会学到沿悬崖边走的最优路径（因为它在学最优策略的值），但在 ε-贪心执行时偶尔坠崖，实际累积奖励反而较低。SARSA 则会学到远离悬崖的安全路径（因为它在学包含 ε 探索的当前策略的值），虽然路径更长但实际累积奖励更高。

SARSA 的收敛条件是策略必须满足 GLIE（Greedy in the Limit with Infinite Exploration）：所有状态-动作对被无限探索，且策略在极限下收敛到贪心策略。常用的 ε-递减策略满足这一条件。


Expected SARSA 是 SARSA 的改进版本，用期望值代替采样值：更新目标变为 Σa π(a|s{t+1})·Q(s*{t+1},a)。这消除了采样 a*{t+1} 带来的额外方差，同时保持在策略学习的特性。当目标策略是贪心策略时，Expected SARSA 退化为 Q-learning，因此 Expected SARSA 可以看作 Q-learning 和 SARSA 的统一。


表格方法的局限与扩展
表格形式的 Q-learning 和 SARSA 要求为每个状态-动作对维护独立的 Q 值条目。当状态空间和动作空间较大时，这种方式面临严重的存储和效率问题。


状态空间爆炸：围棋有约 10^{170} 个合法状态，Atari 游戏的像素输入对应天文数字级别的状态空间。表格方法无法处理如此庞大的状态空间，更无法在合理时间内对每个状态-动作对进行充分的采样。


缺乏泛化能力：表格方法将每个状态完全独立对待，在一个状态上的学习经验无法迁移到相似状态。即使两个状态只有微小差异，它们的 Q 值估计也是完全独立的。


连续空间问题：许多实际问题的状态空间和/或动作空间是连续的（如机器人关节角度），表格方法完全无法处理。


这些局限催生了两个重要方向：线性函数近似用特征向量的线性组合来近似 Q 函数，Q(s,a) ≈ w^T·φ(s,a)，具有理论收敛保证但表达能力有限；**深度 Q 网络（DQN）**用深度神经网络近似 Q 函数，表达能力强大但失去了收敛保证。DQN 的成功开启了深度强化学习时代，将在后续章节详细讨论。


从表格方法到函数近似的跨越不仅是实现技术的变化，更带来了根本性的理论挑战。表格方法中的很多收敛保证在函数近似下不再成立，需要新的理论工具和实践技巧来确保学习的稳定性和有效性。


小结
    

  • Q-learning 是离策略 TD 控制算法，使用 max Q 作为更新目标，直接逼近最优策略
    • 

  • SARSA 是在策略 TD 控制算法，使用实际下一步动作的 Q 值更新，倾向学习安全策略
    • 

  • Q-learning 存在最大化偏差问题，Double Q-learning 通过解耦选择和评估来缓解
    • 

  • Expected SARSA 统一了 Q-learning 和 SARSA，用期望代替采样降低方差
    • 

  • 表格方法受限于状态空间大小和缺乏泛化能力，推动了函数近似方法的发展
    • 

  • 从表格到函数近似是深度强化学习的关键跨越，带来新的理论和实践挑战
