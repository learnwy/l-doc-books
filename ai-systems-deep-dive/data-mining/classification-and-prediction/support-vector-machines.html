支持向量机

核心概念

支持向量机（SVM, Support Vector Machine）是一种基于统计学习理论和结构风险最小化原则的分类方法。其核心思想是在特征空间中寻找一个最优超平面，使得两类数据之间的间隔（Margin）最大化。SVM 在高维空间和小样本场景下表现优异，是数据挖掘中理论基础最深厚的分类方法之一。

SVM 的关键创新在于"间隔最大化"——不仅要正确分类训练数据，还要使决策边界尽可能远离最近的训练样本。这些最近的样本被称为支持向量（Support Vectors），它们完全决定了分类超平面的位置。通过核函数技巧，SVM 能够在高维甚至无穷维空间中进行有效的非线性分类。

线性 SVM 与最大间隔
给定线性可分的训练数据 {(xᵢ, yᵢ)}，其中 yᵢ ∈ {-1, +1}，线性 SVM 寻找满足 yᵢ(w·xᵢ + b) ≥ 1 的超平面 w·x + b = 0，同时最小化 ‖w‖²/2（等价于最大化间隔 2/‖w‖）。


硬间隔 SVM要求所有训练样本都被正确分类且位于间隔之外。这是一个凸二次规划问题，通过拉格朗日乘子法转化为对偶问题求解。对偶问题中只有支持向量（对应的拉格朗日乘子 αᵢ > 0）参与超平面的确定。


软间隔 SVM引入松弛变量 ξᵢ ≥ 0 允许部分样本违反间隔约束：yᵢ(w·xᵢ + b) ≥ 1 - ξᵢ。目标函数变为 min ‖w‖²/2 + C·Σξᵢ，其中正则化参数 C 控制间隔最大化与误分类惩罚之间的权衡。C 越大越不容忍误分类（可能过拟合），C 越小允许更多误分类换取更大间隔（可能欠拟合）。


软间隔 SVM 对应的对偶问题约束为 0 ≤ αᵢ ≤ C。αᵢ = 0 的样本对决策无影响，0 < αᵢ < C 的样本恰好在间隔边界上（标准支持向量），αᵢ = C 的样本在间隔内部或被误分类。


核函数与非线性分类
现实数据通常不是线性可分的。核函数技巧（Kernel Trick）通过将数据映射到高维特征空间，在高维空间中寻找线性分离超平面，从而在原始空间实现非线性分类。


核函数 K(xᵢ, xⱼ) = φ(xᵢ)·φ(xⱼ) 直接计算映射后的内积，而不需要显式地计算映射函数 φ(x)。这使得 SVM 能够在极高维（甚至无穷维）的特征空间中工作，同时保持与原始空间相同的计算复杂度。


线性核 K(x,z) = x·z 即不做映射，适用于特征维度高、样本量大的线性可分或近似线性可分数据。文本分类（高维 TF-IDF 特征）是线性核的典型应用场景。


RBF 核（高斯核） K(x,z) = exp(-γ‖x-z‖²) 是最常用的非线性核。参数 γ 控制样本影响范围：γ 越大，每个支持向量的影响范围越小（容易过拟合）；γ 越小，影响范围越大（可能欠拟合）。RBF 核能够拟合任意复杂的决策边界，是"不确定用什么核时"的默认选择。


多项式核 K(x,z) = (x·z + c)^d 通过 d 次多项式映射实现非线性分类。d=1 退化为线性核，d=2 或 d=3 在某些图像特征上效果好。阶数越高映射维度越大，过拟合风险也越高。

SVM 参数调优与实践
SVM 的性能高度依赖于参数选择，主要包括正则化参数 C、核函数类型和核参数（如 RBF 的 γ）。


C 和 γ 的网格搜索是 RBF-SVM 最常用的调优方法。通常在对数尺度上搜索：C ∈ {0.01, 0.1, 1, 10, 100}，γ ∈ {0.001, 0.01, 0.1, 1}。使用 K 折交叉验证评估每组参数的泛化性能。搜索空间较大时可先用粗粒度搜索定位最优区域，再在该区域内细粒度搜索。


特征缩放的必要性：SVM 基于距离度量，特征量纲不同会导致大量纲特征主导距离计算。使用 SVM 前必须对特征进行标准化（Z-Score）或归一化（Min-Max）。缩放器应在训练集上拟合，用同一参数变换测试集。


大规模数据的挑战：标准 SVM 的训练复杂度为 O(n²) 到 O(n³)，不适合百万级以上的数据。解决方案包括：线性 SVM 使用 LibLinear（O(n) 复杂度）、核近似方法（Nyström、随机傅里叶特征）将核 SVM 转化为线性问题、分块训练和在线学习策略。


多分类扩展：SVM 原生只支持二分类。多分类通过 One-vs-One（OvO，训练 C(K,2) 个分类器投票）或 One-vs-Rest（OvR，训练 K 个分类器取最高分）实现。OvO 在小数据集上更准确，OvR 在大数据集上更高效。

SVM 与其他分类器的对比
在数据挖掘实践中，选择 SVM 还是其他分类器需要考虑数据特征和项目约束。


SVM 在以下场景表现出色：高维数据（特征数远大于样本数，如基因表达数据）、小样本学习（几百到几千个训练样本）、清晰的间隔结构（类别之间有明确的几何分隔）。SVM 的理论泛化界保证了在这些场景下的可靠性。


SVM 在以下场景不是最佳选择：大规模数据（百万级样本，训练时间过长）、需要概率输出（SVM 原生不输出概率，需要 Platt 校准）、需要高可解释性（支持向量集不如决策规则直观）、数据含大量噪声（支持向量容易被噪声点影响）。


在深度学习时代，SVM 的应用范围缩小，但在特定领域（生物信息学、小样本文本分类、异常检测）仍然具有竞争力。核 SVM 可以看作一种特殊的浅层神经网络，RBF-SVM 等价于一层隐藏层的径向基函数网络。


小结
    

  • SVM 通过最大间隔原则在特征空间中寻找最优分类超平面，支持向量决定决策边界
    • 

  • 软间隔 SVM 通过 C 参数平衡间隔最大化与误分类容忍，是实际应用的标准形式
    • 

  • 核函数技巧使 SVM 能在高维空间进行非线性分类，RBF 核是默认选择
    • 

  • SVM 在高维小样本场景表现优异，但训练复杂度 O(n²)-O(n³) 限制了大数据应用
    • 

  • 特征缩放是 SVM 的必要预处理步骤，C 和 γ 的联合调优决定模型性能
    • 

  • SVM 在特定领域仍有竞争力，但在大规模通用场景已被集成学习和深度学习取代
    •
