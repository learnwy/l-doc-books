标准化流模型

核心概念

标准化流（Normalizing Flows）是一类基于可逆变换的生成模型。其核心思想是将简单的基础分布（如标准高斯）通过一系列可逆、可微的变换映射为复杂的数据分布。由于每一步变换都是可逆的，数据的精确对数似然可以通过变量替换公式和雅可比行列式来计算，无需任何近似。

变量替换公式为：log p(x) = log p(z) - Σ log |det ∂fᵢ/∂fᵢ₋₁|，其中每一项是变换 fᵢ 的雅可比行列式的对数绝对值。关键的设计挑战是构造既有表达力又能高效计算雅可比行列式的可逆变换。

仿射耦合层与 RealNVP
RealNVP 提出了仿射耦合层（Affine Coupling Layer），这是标准化流中最常用的构建模块。它将输入 x 分为两部分 x₁ 和 x₂，然后 x₁ 保持不变，x₂ 通过由 x₁ 参数化的仿射变换进行变换：y₁ = x₁，y₂ = x₂ ⊙ exp(s(x₁)) + t(x₁)。其中 s 和 t 是任意神经网络。


这一设计的精妙之处在于：变换的雅可比矩阵是三角阵，其行列式仅为对角线元素的乘积 exp(Σ sᵢ)，计算复杂度为 O(D) 而非 O(D³)。逆变换同样简单：x₂ = (y₂ - t(y₁)) ⊙ exp(-s(y₁))。通过交替分割维度（偶数层和奇数层分割不同的维度），多个耦合层可以对所有维度施加非线性变换。


import torch
import torch.nn as nn

class AffineCouplingLayer(nn.Module):
    def __init__(self, dim, hidden_dim=256, mask_type='even'):
        super().__init__()
        self.mask = torch.arange(dim) % 2 == (0 if mask_type == 'even' else 1)
        half_dim = dim // 2
        self.net = nn.Sequential(
            nn.Linear(half_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, half_dim * 2),
        )

    def forward(self, x):
        x1 = x[:, self.mask]
        x2 = x[:, ~self.mask]
        st = self.net(x1)
        s, t = st.chunk(2, dim=-1)
        s = torch.tanh(s) * 2
        y2 = x2 * torch.exp(s) + t
        y = torch.zeros_like(x)
        y[:, self.mask] = x1
        y[:, ~self.mask] = y2
        log_det = s.sum(dim=-1)
        return y, log_det

    def inverse(self, y):
        y1 = y[:, self.mask]
        y2 = y[:, ~self.mask]
        st = self.net(y1)
        s, t = st.chunk(2, dim=-1)
        s = torch.tanh(s) * 2
        x2 = (y2 - t) * torch.exp(-s)
        x = torch.zeros_like(y)
        x[:, self.mask] = y1
        x[:, ~self.mask] = x2
        return x

class RealNVP(nn.Module):
    def __init__(self, dim, n_layers=6, hidden_dim=256):
        super().__init__()
        self.layers = nn.ModuleList()
        for i in range(n_layers):
            mask_type = 'even' if i % 2 == 0 else 'odd'
            self.layers.append(AffineCouplingLayer(dim, hidden_dim, mask_type))

    def forward(self, x):
        log_det_total = 0
        for layer in self.layers:
            x, log_det = layer(x)
            log_det_total += log_det
        return x, log_det_total

    def log_prob(self, x):
        z, log_det = self.forward(x)
        log_pz = -0.5 * (z ** 2 + torch.log(torch.tensor(2 * 3.14159))).sum(dim=-1)
        return log_pz + log_det
Glow 与 1×1 可逆卷积
Glow 在 RealNVP 基础上引入了两个关键改进。第一是 1×1 可逆卷积层，替代了 RealNVP 中简单的维度交替策略。1×1 卷积等价于通道维度上的线性变换，其雅可比行列式为权重矩阵的行列式。通过 LU 分解可以将行列式计算复杂度从 O(C³) 降至 O(C)。


第二个改进是 ActNorm（Activation Normalization），一种数据依赖的初始化归一化层。ActNorm 的仿射参数在第一个 mini-batch 时根据数据统计量初始化（使得输出均值为 0、方差为 1），之后作为可训练参数正常优化。这一层替代了 BatchNorm，在小 batch 和推理时表现更稳定。


Glow 的多尺度架构在每个尺度上堆叠 K 步流操作，然后通过 squeeze 操作将空间维度转化为通道维度（如 32×32×C → 16×16×4C），同时分出一半通道直接作为输出。这种设计使得早期层处理高频细节，后期层处理低频结构，类似小波变换的多分辨率分析。


连续标准化流与 Neural ODE
连续标准化流（Continuous Normalizing Flows, CNF）将离散的变换步骤推广为连续时间的常微分方程。数据点 x 的演化由 dx/dt = fθ(x, t) 描述，其中 fθ 是神经网络参数化的速度场。从时间 0 到时间 1 的积分将简单分布变换为数据分布。


CNF 的对数似然可以通过瞬时变量替换公式（instantaneous change of variables）计算：d log p(x)/dt = -tr(∂f/∂x)。瞬时公式只涉及雅可比矩阵的迹（而非行列式），可以通过 Hutchinson 估计器高效近似：tr(∂f/∂x) ≈ vᵀ(∂f/∂x)v，其中 v 是随机向量。


import torch
import torch.nn as nn
from torchdiffeq import odeint

class CNFDynamics(nn.Module):
    def __init__(self, dim, hidden_dim=128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(dim + 1, hidden_dim), nn.Tanh(),
            nn.Linear(hidden_dim, hidden_dim), nn.Tanh(),
            nn.Linear(hidden_dim, dim),
        )

    def forward(self, t, state):
        x, _ = state
        t_expand = t.expand(x.shape[0], 1)
        dx = self.net(torch.cat([x, t_expand], dim=-1))
        trace = self._hutchinson_trace(dx, x)
        return dx, -trace

    def _hutchinson_trace(self, dx, x):
        noise = torch.randn_like(x)
        grad = torch.autograd.grad(dx, x, noise, create_graph=True)[0]
        return (grad * noise).sum(dim=-1)

class ContinuousNF(nn.Module):
    def __init__(self, dim, hidden_dim=128):
        super().__init__()
        self.dynamics = CNFDynamics(dim, hidden_dim)

    def log_prob(self, x):
        x = x.requires_grad_(True)
        state = (x, torch.zeros(x.shape[0], device=x.device))
        z, delta_logp = odeint(self.dynamics, state, torch.tensor([1.0, 0.0]))
        z, delta_logp = z[-1], delta_logp[-1]
        log_pz = -0.5 * (z ** 2).sum(dim=-1) - 0.5 * z.shape[-1] * torch.log(torch.tensor(2 * 3.14159))
        return log_pz - delta_logp
Flow Matching 是 CNF 训练的最新方法，它避免了 ODE 求解器在训练中的高计算成本。核心思想是直接训练速度场 vθ(x, t) 去匹配一个条件最优传输路径的速度场。训练目标是简单的均方误差：L = E[||vθ(xₜ, t) - u(xₜ|x₁)||²]，其中 u 是从噪声到数据的线性插值速度。Stable Diffusion 3 和 FLUX 的训练就是基于 Flow Matching 的 Rectified Flow 框架。

小结
    

  • 标准化流通过可逆变换实现精确的对数似然计算，无需变分近似
    • 

  • 仿射耦合层通过三角雅可比矩阵实现高效的密度计算，是离散流的核心构件
    • 

  • Glow 的 1×1 可逆卷积和多尺度架构显著增强了模型的表达能力
    • 

  • 连续标准化流将离散变换推广为 ODE，Hutchinson 估计器实现高效的迹计算
    • 

  • Flow Matching 避免了训练时的 ODE 求解，成为最新的连续流训练范式
    • 

  • Rectified Flow 框架被 SD3 和 FLUX 采用，标准化流思想正在与扩散模型深度融合
