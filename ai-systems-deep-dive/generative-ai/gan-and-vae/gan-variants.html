GAN 变体与演进

核心概念

从 2014 年原始 GAN 到 2024 年的 GigaGAN，GAN 架构经历了十年的快速演进。这条技术路线围绕两个核心挑战展开：提升生成图像的分辨率和真实感，以及增强对生成过程的精确控制。DCGAN 奠定了卷积 GAN 的基础架构，ProGAN 引入渐进式训练突破了高分辨率生成的瓶颈，StyleGAN 系列通过风格注入机制实现了对生成图像各个层面的精细控制。

每一代 GAN 的改进都有明确的技术焦点，从网络结构设计到训练策略优化，从无条件生成到条件可控生成。

StyleGAN 架构体系
StyleGAN 是 GAN 发展史上最具影响力的架构创新。它引入映射网络和风格注入机制，将生成过程分解为"内容"和"风格"两个层面。输入噪声 z 首先通过 8 层 MLP 映射网络转化为中间隐空间 W 中的向量 w，然后 w 通过仿射变换生成缩放和偏移参数（风格向量），注入到合成网络每一层的 AdaIN（自适应实例归一化）中。


W 空间相比 Z 空间具有更好的解耦特性。由于映射网络可以学习非线性变换来"展开"隐空间中的纠缠结构，W 空间中的线性操作（如插值和方向编辑）对应更自然的语义变化。不同层的风格向量控制不同粒度的属性——浅层控制姿态和形状，中间层控制面部特征，深层控制颜色和微细节。


import torch
import torch.nn as nn

class MappingNetwork(nn.Module):
    def __init__(self, z_dim=512, w_dim=512, n_layers=8):
        super().__init__()
        layers = []
        for i in range(n_layers):
            in_dim = z_dim if i == 0 else w_dim
            layers.extend([nn.Linear(in_dim, w_dim), nn.LeakyReLU(0.2)])
        self.net = nn.Sequential(*layers)

    def forward(self, z):
        return self.net(z)

class AdaIN(nn.Module):
    def __init__(self, channels, w_dim=512):
        super().__init__()
        self.norm = nn.InstanceNorm2d(channels)
        self.style = nn.Linear(w_dim, channels * 2)

    def forward(self, x, w):
        style = self.style(w).unsqueeze(-1).unsqueeze(-1)
        gamma, beta = style.chunk(2, dim=1)
        return gamma * self.norm(x) + beta

class SynthesisBlock(nn.Module):
    def __init__(self, in_channels, out_channels, w_dim=512):
        super().__init__()
        self.conv = nn.Conv2d(in_channels, out_channels, 3, padding=1)
        self.adain = AdaIN(out_channels, w_dim)
        self.noise_scale = nn.Parameter(torch.zeros(1))

    def forward(self, x, w):
        x = self.conv(x)
        noise = torch.randn(x.shape[0], 1, x.shape[2], x.shape[3], device=x.device)
        x = x + self.noise_scale * noise
        return self.adain(x, w)
StyleGAN2 改进了三个关键方面：一是用权重调制（Weight Modulation/Demodulation）替代 AdaIN，消除了 AdaIN 引入的水滴伪影；二是引入路径长度正则化，鼓励 W 空间中的等距变化产生等比例的图像变化；三是改进了渐进式增长策略，采用跳跃连接和残差结构。StyleGAN3 进一步通过等变卷积设计消除了纹理粘连（texture sticking）伪影。


图像翻译与 CycleGAN
图像翻译任务的目标是学习从一个视觉域到另一个视觉域的映射。Pix2Pix 使用成对训练数据，通过条件 GAN 加 L1 重构损失实现精确的图像翻译。其 PatchGAN 判别器只在局部 patch 级别判断真假，而非整张图像，这一设计使判别器更高效且对图像尺寸不敏感。


CycleGAN 的突破在于无需成对训练数据即可实现域间翻译。它通过两个生成器 G: A→B 和 F: B→A 加循环一致性损失 ||F(G(x)) - x||₁ + ||G(F(y)) - y||₁ 来约束映射关系。循环一致性确保翻译是可逆的，避免了模式崩塌到无关图像的问题。


import torch
import torch.nn as nn

class ResnetGenerator(nn.Module):
    def __init__(self, input_nc=3, output_nc=3, ngf=64, n_blocks=9):
        super().__init__()
        model = [nn.ReflectionPad2d(3), nn.Conv2d(input_nc, ngf, 7), nn.InstanceNorm2d(ngf), nn.ReLU()]
        for i in range(2):
            mult = 2 ** i
            model += [nn.Conv2d(ngf * mult, ngf * mult * 2, 3, 2, 1),
                      nn.InstanceNorm2d(ngf * mult * 2), nn.ReLU()]
        mult = 4
        for _ in range(n_blocks):
            model += [ResnetBlock(ngf * mult)]
        for i in range(2):
            mult = 2 ** (2 - i)
            model += [nn.ConvTranspose2d(ngf * mult, ngf * mult // 2, 3, 2, 1, output_padding=1),
                      nn.InstanceNorm2d(ngf * mult // 2), nn.ReLU()]
        model += [nn.ReflectionPad2d(3), nn.Conv2d(ngf, output_nc, 7), nn.Tanh()]
        self.model = nn.Sequential(*model)

    def forward(self, x):
        return self.model(x)

class ResnetBlock(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.block = nn.Sequential(
            nn.ReflectionPad2d(1), nn.Conv2d(dim, dim, 3), nn.InstanceNorm2d(dim), nn.ReLU(),
            nn.ReflectionPad2d(1), nn.Conv2d(dim, dim, 3), nn.InstanceNorm2d(dim),
        )

    def forward(self, x):
        return x + self.block(x)
SPADE（Spatially-Adaptive Normalization）针对语义图引导的图像合成提出了空间自适应归一化层。与全局的 AdaIN 不同，SPADE 从语义分割图中为每个空间位置生成独立的归一化参数，实现了精确的空间语义控制。SPADE 在场景合成和图像编辑中广泛使用。


大规模 GAN 与 GigaGAN
尽管扩散模型在 2022 年后主导了图像生成领域，GAN 在大规模和高分辨率场景中仍然具有独特优势——特别是推理速度。GigaGAN 通过大规模条件 GAN 训练探索了 GAN 的 scaling law，展示了 GAN 在十亿参数规模下的竞争力。


GigaGAN 引入了多个架构创新：自适应核选择（Adaptive Kernel Selection）根据不同空间位置动态选择卷积核，实现了高效的高分辨率生成；交错注意力（Interleaved Attention）在卷积层之间插入注意力层，增强了全局一致性；视觉-语言对齐（Vision-Language Alignment）使用 CLIP 特征进行条件注入。

GAN 在实时应用中的速度优势仍然无可替代。在需要毫秒级响应的场景（如游戏实时材质生成、视频通话背景替换），GAN 的单步推理特性是决定性的优势。此外，GAN 的判别器在扩散模型的蒸馏和评估中扮演着重要角色——SDXL Turbo 的对抗蒸馏和 FID 评估中的特征提取都依赖判别器网络。


小结
    

  • StyleGAN 通过映射网络和风格注入实现了对生成过程各层面的精细控制
    • 

  • W 空间比 Z 空间具有更好的解耦特性，是图像编辑和操纵的理想操作空间
    • 

  • CycleGAN 通过循环一致性损失实现无配对图像翻译，是域适应的经典方法
    • 

  • GigaGAN 展示了 GAN 在十亿参数规模下的竞争力和独特的速度优势
    • 

  • GAN 的对抗训练思想和判别器网络在扩散模型时代仍然发挥着关键作用
