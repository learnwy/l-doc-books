VAE 基础原理

核心概念

变分自编码器（Variational Autoencoder, VAE）是一种基于概率图模型的生成框架，由 Kingma 和 Welling 在 2013 年提出。VAE 将生成过程建模为隐变量模型：数据 x 由隐变量 z 通过解码器 pθ(x|z) 生成，隐变量服从先验分布 p(z)。由于真实后验 p(z|x) 不可解析，VAE 引入编码器 qφ(z|x) 作为近似后验，并通过最大化证据下界（ELBO）同时训练编码器和解码器。

VAE 的核心创新在于将变分推断与深度学习无缝结合。编码器和解码器都是深度神经网络，通过重参数化技巧使得随机采样过程可微分，从而支持端到端的梯度优化。

ELBO 优化与训练实践
ELBO = Eq[log pθ(x|z)] - KL(qφ(z|x) || p(z)) 包含两项：重构损失鼓励解码器从隐变量准确还原输入数据，KL 散度正则项约束编码器输出的后验分布接近标准高斯先验。当 qφ(z|x) = N(μ, σ²I) 且 p(z) = N(0, I) 时，KL 散度有闭式解：KL = -½ Σ(1 + log σ² - μ² - σ²)。


import torch
import torch.nn as nn
import torch.nn.functional as F

class ConvVAE(nn.Module):
    def __init__(self, latent_dim=256, img_channels=3):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Conv2d(img_channels, 32, 4, 2, 1), nn.ReLU(),
            nn.Conv2d(32, 64, 4, 2, 1), nn.ReLU(),
            nn.Conv2d(64, 128, 4, 2, 1), nn.ReLU(),
            nn.Conv2d(128, 256, 4, 2, 1), nn.ReLU(),
        )
        self.fc_mu = nn.Linear(256 * 4 * 4, latent_dim)
        self.fc_logvar = nn.Linear(256 * 4 * 4, latent_dim)
        self.fc_decode = nn.Linear(latent_dim, 256 * 4 * 4)
        self.decoder = nn.Sequential(
            nn.ConvTranspose2d(256, 128, 4, 2, 1), nn.ReLU(),
            nn.ConvTranspose2d(128, 64, 4, 2, 1), nn.ReLU(),
            nn.ConvTranspose2d(64, 32, 4, 2, 1), nn.ReLU(),
            nn.ConvTranspose2d(32, img_channels, 4, 2, 1), nn.Sigmoid(),
        )

    def encode(self, x):
        h = self.encoder(x).flatten(1)
        return self.fc_mu(h), self.fc_logvar(h)

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        return mu + std * torch.randn_like(std)

    def decode(self, z):
        h = self.fc_decode(z).view(-1, 256, 4, 4)
        return self.decoder(h)

    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        return self.decode(z), mu, logvar

def elbo_loss(recon, target, mu, logvar, beta=1.0):
    recon_loss = F.mse_loss(recon, target, reduction='sum')
    kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return recon_loss + beta * kl_loss
训练中常见的问题是 KL 散度坍缩（posterior collapse）：解码器变得足够强大以至于忽略隐变量信息，导致 q(z|x) 退化为先验 p(z)。缓解策略包括 KL 退火（训练前期将 KL 系数从 0 逐步增大到 1）、自由比特（设置 KL 的最低阈值）、以及使用弱解码器（限制解码器容量迫使其依赖隐变量）。


VQ-VAE 与离散隐空间
VQ-VAE（Vector Quantized VAE）用离散码本（codebook）替代连续高斯隐空间。编码器输出连续向量 z_e，通过最近邻查找映射到码本中最接近的嵌入向量 z_q = e_k，其中 k = argmin ||z_e - e_i||。解码器从量化后的 z_q 重构数据。这种离散化带来了两个关键优势：完全避免了 KL 坍缩问题，以及为下游自回归模型提供了离散 token 序列。


import torch
import torch.nn as nn
import torch.nn.functional as F

class VectorQuantizer(nn.Module):
    def __init__(self, n_embeddings=512, embedding_dim=64, commitment_cost=0.25):
        super().__init__()
        self.embedding = nn.Embedding(n_embeddings, embedding_dim)
        self.commitment_cost = commitment_cost
        nn.init.uniform_(self.embedding.weight, -1 / n_embeddings, 1 / n_embeddings)

    def forward(self, z_e):
        b, c, h, w = z_e.shape
        flat = z_e.permute(0, 2, 3, 1).reshape(-1, c)
        distances = torch.cdist(flat, self.embedding.weight)
        indices = distances.argmin(dim=1)
        z_q = self.embedding(indices).view(b, h, w, c).permute(0, 3, 1, 2)
        loss = F.mse_loss(z_q.detach(), z_e) + self.commitment_cost * F.mse_loss(z_q, z_e.detach())
        z_q = z_e + (z_q - z_e).detach()
        return z_q, loss, indices.view(b, h, w)
VQ-VAE 的训练损失包含三项：重构损失 ||x - D(z_q)||²、码本更新损失 ||z_e.detach() - e_k||²（移动码本向量接近编码器输出）和承诺损失 ||z_e - e_k.detach()||²（鼓励编码器输出接近码本向量）。直通估计器（Straight-Through Estimator）用于将梯度从 z_q 直接复制到 z_e，绕过不可微的最近邻操作。


VQ-VAE-2 引入了多尺度码本层次结构：顶层码本编码全局结构，底层码本编码局部细节。结合 PixelCNN 先验模型对码本索引进行自回归建模，VQ-VAE-2 生成的图像质量可以与 GAN 媲美。这一架构启发了后来的 DALL-E（第一版），它使用 VQ-VAE 将图像编码为 token 序列，然后用 GPT 风格的 Transformer 进行自回归生成。


Hierarchical VAE 与 NVAE
层次化 VAE（Hierarchical VAE）通过引入多层隐变量来增强模型的表达能力。每一层隐变量捕获不同抽象层级的信息：底层编码像素级细节，中间层编码结构和纹理，顶层编码全局语义。层次化结构使得后验分布更加灵活，能够缩小变分间隙。


NVAE（Nouveau VAE）是层次化 VAE 的代表作品。它通过残差参数化的层次编码器-解码器结构、深度可分离卷积和谱正则化，首次证明纯 VAE 架构可以生成与 GAN 竞争的高分辨率图像。NVAE 使用 30+ 层的隐变量层次，每一层的编码器和解码器都是轻量级的残差网络。

VAE 在现代生成式 AI 中的角色已经从独立的生成模型转变为更大系统的组件。Stable Diffusion 的 VAE 编解码器、DALL-E 的 VQ-VAE tokenizer 和 Parti 的 ViT-VQGAN 编码器都是 VAE 作为隐空间提供者的典型应用。VAE 擅长学习紧凑、结构化的数据表示，这一能力在多模态生成和视觉 tokenization 中越来越重要。


小结
    

  • VAE 通过最大化 ELBO 同时训练编码器和解码器，重参数化技巧是可微分采样的关键
    • 

  • KL 坍缩是标准 VAE 的核心挑战，KL 退火和自由比特是有效的缓解策略
    • 

  • VQ-VAE 用离散码本替代连续隐空间，避免 KL 坍缩并支持自回归先验建模
    • 

  • 层次化 VAE（如 NVAE）通过多层隐变量增强表达能力，缩小变分间隙
    • 

  • VAE 在现代生成系统中的核心角色是提供结构化的隐空间表示，服务于扩散模型和视觉 token 化
