GAN 基础原理

核心概念

生成对抗网络（GAN）由 Ian Goodfellow 在 2014 年提出，开创了通过对抗博弈训练生成模型的范式。GAN 由两个网络组成：生成器 G 将随机噪声 z 映射为数据样本 G(z)，判别器 D 判断输入样本是真实的还是生成的。两个网络通过极小极大博弈（minimax game）共同优化：生成器试图欺骗判别器，判别器试图准确区分真假。当博弈达到纳什均衡时，生成器的输出分布理论上等于真实数据分布。

GAN 的核心创新在于回避了显式密度建模的困难。不需要计算配分函数，不需要变分近似，甚至不需要定义概率密度函数——只需要通过判别器提供的"真实性"信号来指导生成器学习。

极小极大目标函数
GAN 的原始目标函数为：min_G max_D V(D, G) = E[log D(x)] + E[log(1 - D(G(z)))]。判别器试图最大化该目标——对真实样本输出高概率，对生成样本输出低概率。生成器试图最小化该目标——使判别器对生成样本输出高概率。


在最优判别器 D*(x) = p_data(x) / (p_data(x) + p_g(x)) 条件下，生成器的优化等价于最小化 p_data 和 p_g 之间的 Jensen-Shannon 散度。当 p_g = p_data 时，JS 散度为零，D* 对所有输入输出 0.5，博弈达到均衡。


import torch
import torch.nn as nn

class Generator(nn.Module):
    def __init__(self, latent_dim=100, img_channels=1, features=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.ConvTranspose2d(latent_dim, features * 8, 4, 1, 0),
            nn.BatchNorm2d(features * 8), nn.ReLU(),
            nn.ConvTranspose2d(features * 8, features * 4, 4, 2, 1),
            nn.BatchNorm2d(features * 4), nn.ReLU(),
            nn.ConvTranspose2d(features * 4, features * 2, 4, 2, 1),
            nn.BatchNorm2d(features * 2), nn.ReLU(),
            nn.ConvTranspose2d(features * 2, img_channels, 4, 2, 1),
            nn.Tanh(),
        )

    def forward(self, z):
        return self.net(z.view(-1, z.size(1), 1, 1))

class Discriminator(nn.Module):
    def __init__(self, img_channels=1, features=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(img_channels, features, 4, 2, 1),
            nn.LeakyReLU(0.2),
            nn.Conv2d(features, features * 2, 4, 2, 1),
            nn.BatchNorm2d(features * 2), nn.LeakyReLU(0.2),
            nn.Conv2d(features * 2, features * 4, 4, 2, 1),
            nn.BatchNorm2d(features * 4), nn.LeakyReLU(0.2),
            nn.Conv2d(features * 4, 1, 4, 1, 0),
            nn.Sigmoid(),
        )

    def forward(self, x):
        return self.net(x).view(-1)
在实践中，原始目标函数的生成器梯度在训练初期可能消失（当判别器过强时，log(1-D(G(z))) 饱和）。常用的替代方案是非饱和损失：生成器最大化 E[log D(G(z))]，提供更强的梯度信号。


训练动态与模式崩塌
GAN 的训练本质上是一个双人非合作博弈，存在许多传统优化方法不会遇到的挑战。最核心的问题是模式崩塌（mode collapse）：生成器只学会产生数据分布中的少数几个模式，而忽略其他模式。


import torch
import torch.nn.functional as F

def train_gan_step(G, D, real_data, z, opt_G, opt_D, n_critic=1):
    for _ in range(n_critic):
        fake_data = G(z).detach()
        d_real = D(real_data)
        d_fake = D(fake_data)
        d_loss = -torch.mean(torch.log(d_real + 1e-8) + torch.log(1 - d_fake + 1e-8))
        opt_D.zero_grad()
        d_loss.backward()
        opt_D.step()

    fake_data = G(z)
    d_fake = D(fake_data)
    g_loss = -torch.mean(torch.log(d_fake + 1e-8))
    opt_G.zero_grad()
    g_loss.backward()
    opt_G.step()
    return d_loss.item(), g_loss.item()

def gradient_penalty(D, real_data, fake_data, lambda_gp=10):
    alpha = torch.rand(real_data.size(0), 1, 1, 1, device=real_data.device)
    interpolated = alpha * real_data + (1 - alpha) * fake_data
    interpolated.requires_grad_(True)
    d_interpolated = D(interpolated)
    gradients = torch.autograd.grad(
        outputs=d_interpolated, inputs=interpolated,
        grad_outputs=torch.ones_like(d_interpolated),
        create_graph=True, retain_graph=True
    )[0]
    grad_norm = gradients.view(gradients.size(0), -1).norm(2, dim=1)
    return lambda_gp * ((grad_norm - 1) ** 2).mean()
实用的训练稳定化技巧包括：判别器使用谱归一化（Spectral Normalization）约束 Lipschitz 常数；使用两个不同的学习率（判别器通常更大）；判别器训练多步后再更新一步生成器（n_critic > 1）；标签平滑（将真实标签从 1 降为 0.9）；以及渐进式增长训练（从低分辨率开始逐步增加）。


Wasserstein GAN 与最优传输
Wasserstein GAN（WGAN）用 Wasserstein-1 距离（Earth Mover's Distance）替代 JS 散度作为训练目标。Wasserstein 距离在两个分布没有重叠时仍然提供有意义的梯度信号，而 JS 散度在此情况下为常数。这一性质从根本上改善了训练稳定性。


WGAN 的目标函数为：minG max{D∈1-Lip} E[D(x)] - E[D(G(z))]，其中判别器（改称"评论器"）需要满足 1-Lipschitz 约束。原始 WGAN 通过权重裁剪实现 Lipschitz 约束，但这种粗暴的方法限制了网络容量。WGAN-GP 改用梯度惩罚——在真实和生成样本之间的插值点上约束梯度范数接近 1。

谱归一化（Spectral Normalization）是最实用的 Lipschitz 约束方法。它将每个权重矩阵除以其最大奇异值，确保每层的 Lipschitz 常数为 1。通过幂迭代法高效近似最大奇异值，计算开销几乎可以忽略。SNGAN 结合谱归一化和投影判别器，成为条件 GAN 训练的标准配置。


条件 GAN 框架
条件 GAN（cGAN）通过向生成器和判别器同时提供条件信息来实现可控生成。条件信息可以是类别标签、文本描述、参考图像或任何辅助信号。在数学上，cGAN 的目标是学习条件分布 p(x|c)，而非边际分布 p(x)。


条件注入的方式多种多样：拼接（将条件向量拼接到噪声或特征图上）、投影（将条件向量投影到判别器的中间特征上）和自适应归一化（通过条件向量调制归一化层的参数）。投影判别器（Projection Discriminator）通过内积操作将条件信息融入判别器，在条件图像生成中表现优异。


import torch
import torch.nn as nn

class ConditionalGenerator(nn.Module):
    def __init__(self, latent_dim=100, n_classes=10, embed_dim=50, features=64):
        super().__init__()
        self.label_embed = nn.Embedding(n_classes, embed_dim)
        self.net = nn.Sequential(
            nn.ConvTranspose2d(latent_dim + embed_dim, features * 4, 4, 1, 0),
            nn.BatchNorm2d(features * 4), nn.ReLU(),
            nn.ConvTranspose2d(features * 4, features * 2, 4, 2, 1),
            nn.BatchNorm2d(features * 2), nn.ReLU(),
            nn.ConvTranspose2d(features * 2, 1, 4, 2, 1),
            nn.Tanh(),
        )

    def forward(self, z, labels):
        embed = self.label_embed(labels)
        x = torch.cat([z, embed], dim=1)
        return self.net(x.unsqueeze(-1).unsqueeze(-1))

class ProjectionDiscriminator(nn.Module):
    def __init__(self, n_classes=10, features=64):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, features, 4, 2, 1), nn.LeakyReLU(0.2),
            nn.Conv2d(features, features * 2, 4, 2, 1), nn.LeakyReLU(0.2),
        )
        self.linear = nn.Linear(features * 2 * 7 * 7, 1)
        self.embed = nn.Embedding(n_classes, features * 2 * 7 * 7)

    def forward(self, x, labels):
        h = self.features(x).flatten(1)
        out = self.linear(h)
        proj = (h * self.embed(labels)).sum(dim=1, keepdim=True)
        return out + proj
条件 GAN 框架催生了大量重要应用：Pix2Pix 实现成对图像翻译（草图到照片、白天到夜晚），CycleGAN 通过循环一致性损失实现无配对图像翻译，SPADE 用语义图引导高分辨率图像合成。这些方法虽然在扩散模型时代使用频率降低，但其条件注入的设计思想仍被广泛采用。


小结
    

  • GAN 通过对抗博弈实现隐式密度建模，生成器和判别器在极小极大目标下交替优化
    • 

  • 模式崩塌和训练不稳定是 GAN 的核心挑战，谱归一化和梯度惩罚是有效的缓解策略
    • 

  • WGAN 用 Wasserstein 距离替代 JS 散度，从根本上改善了训练梯度信号
    • 

  • 条件 GAN 通过向生成器和判别器注入条件信息实现可控生成
    • 

  • GAN 的对抗训练思想和条件注入方法深刻影响了后续生成模型的设计
