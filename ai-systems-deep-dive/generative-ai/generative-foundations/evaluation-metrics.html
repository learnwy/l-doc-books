生成质量评估指标

核心概念

生成模型的评估是一个多维度的复杂问题。与分类或回归任务有明确的ground truth不同，生成质量的衡量涉及保真度（生成样本是否真实）、多样性（生成样本是否覆盖数据分布的所有模式）和条件一致性（生成结果是否符合输入条件）三个维度。没有单一指标能够全面衡量生成质量，实践中需要综合多个指标进行评估。

评估生成模型的挑战在于我们需要比较两个分布——真实数据分布和模型生成的分布——而不是逐样本比较。这要求评估指标具有分布级别的统计特性，同时对有限样本量保持鲁棒性。

Fréchet Inception Distance
FID（Fréchet Inception Distance）是目前最广泛使用的生成质量指标。它将真实图像和生成图像分别通过预训练的 Inception-v3 网络提取特征，然后计算两组特征的 Fréchet 距离（也称 Wasserstein-2 距离）。FID 假设两组特征服从多元高斯分布，并通过均值和协方差矩阵计算分布间距离。


FID = ||μ_r - μ_g||² + Tr(Σ_r + Σ_g - 2(Σ_r·Σ_g)^{1/2})，其中下标 r 和 g 分别表示真实和生成样本。FID 的优势在于同时捕获保真度和多样性：均值项反映两个分布中心的偏移（与保真度相关），协方差项反映分布形状的差异（与多样性相关）。


import numpy as np
from scipy import linalg
import torch
from torchvision.models import inception_v3

def compute_fid(real_features, gen_features):
    mu_r = np.mean(real_features, axis=0)
    mu_g = np.mean(gen_features, axis=0)
    sigma_r = np.cov(real_features, rowvar=False)
    sigma_g = np.cov(gen_features, rowvar=False)
    diff = mu_r - mu_g
    covmean, _ = linalg.sqrtm(sigma_r @ sigma_g, disp=False)
    if np.iscomplexobj(covmean):
        covmean = covmean.real
    fid = diff @ diff + np.trace(sigma_r + sigma_g - 2 * covmean)
    return fid

def extract_inception_features(images, model, device='cuda'):
    model.eval()
    features = []
    with torch.no_grad():
        for batch in images:
            batch = batch.to(device)
            feat = model(batch)
            features.append(feat.cpu().numpy())
    return np.concatenate(features)
FID 的局限性包括：对样本数量敏感（通常需要至少 10000 张图像才能稳定），依赖 Inception 网络的特征空间（对非自然图像可能不合适），以及高斯假设在特征分布非高斯时引入误差。改进方案包括 KID（Kernel Inception Distance）使用核方法避免高斯假设，CMMD 使用 CLIP 特征替代 Inception 特征以获得更好的语义对齐。


Inception Score 与条件熵分析
Inception Score（IS）基于两个直觉：高质量生成图像应该让分类器给出高置信度预测（低条件熵），同时生成图像集合应该涵盖多种类别（高边际熵）。IS = exp(E[KL(p(y|x) || p(y))])，其中 p(y|x) 是 Inception 网络对单张生成图像的类别预测分布，p(y) 是所有生成图像预测分布的平均。


IS 的问题在于它完全忽略了真实数据分布。一个只生成 1000 类中每类一张完美图像的模型可以获得很高的 IS，即使它与真实数据集毫无关系。此外，IS 对类内多样性不敏感，且与 ImageNet 类别体系绑定。因此，IS 通常作为辅助指标，主要用于验证生成样本是否包含可识别的语义内容。


在实际评估中，IS 和 FID 经常一起使用。FID 关注分布匹配，IS 关注样本质量和类别覆盖。两个指标的趋势通常一致，但在极端情况下可能矛盾——例如模式崩塌到少数高质量样本时，IS 可能较高但 FID 很差。


Precision-Recall 与分布覆盖
Precision 和 Recall 在生成模型评估中被重新定义为分布层面的概念。Precision 衡量生成分布中有多少比例落入真实数据的支撑集（保真度），Recall 衡量真实数据分布中有多少比例被生成分布覆盖（多样性）。这种分解比 FID 更直观，能够独立诊断保真度和多样性的问题。


Kynkäänniemi 等人提出了基于 k-NN 的 Precision/Recall 计算方法：在特征空间中，用 k 近邻定义每个样本的局部邻域。生成样本落入真实样本邻域的比例即为 Precision，真实样本落入生成样本邻域的比例即为 Recall。


import numpy as np
from sklearn.neighbors import NearestNeighbors

def compute_precision_recall(real_features, gen_features, k=5):
    knn_real = NearestNeighbors(n_neighbors=k).fit(real_features)
    knn_gen = NearestNeighbors(n_neighbors=k).fit(gen_features)
    real_distances, _ = knn_real.kneighbors(real_features)
    gen_distances, _ = knn_gen.kneighbors(gen_features)
    real_radii = real_distances[:, -1]
    gen_radii = gen_distances[:, -1]
    dist_gen_to_real, idx_gen_to_real = knn_real.kneighbors(gen_features)
    precision = np.mean(dist_gen_to_real[:, 0] <= real_radii[idx_gen_to_real[:, 0]])
    dist_real_to_gen, idx_real_to_gen = knn_gen.kneighbors(real_features)
    recall = np.mean(dist_real_to_gen[:, 0] <= gen_radii[idx_real_to_gen[:, 0]])
    return precision, recall

def compute_density_coverage(real_features, gen_features, k=5):
    knn_real = NearestNeighbors(n_neighbors=k).fit(real_features)
    real_distances, _ = knn_real.kneighbors(real_features)
    real_radii = real_distances[:, -1]
    dist_gen_to_real, idx_gen_to_real = knn_real.kneighbors(gen_features)
    density = np.mean(
        np.sum(dist_gen_to_real <= real_radii[idx_gen_to_real], axis=1) / k
    )
    coverage = np.mean(
        np.any(dist_gen_to_real <= real_radii[idx_gen_to_real[:, :1]], axis=0)
    )
    return density, coverage
Density 和 Coverage 是对 Precision/Recall 的改进指标。Density 衡量生成样本在真实流形上的平均密度（检测模式崩塌），Coverage 衡量真实流形被至少一个生成样本覆盖的比例（检测模式缺失）。这些指标对异常值更加鲁棒，并且能够区分轻微的分布偏移和严重的模式崩塌。


CLIP Score 与语义对齐评估
随着文本条件生成模型的普及，文图一致性成为核心评估维度。CLIP Score 利用预训练的 CLIP 模型计算生成图像与输入文本之间的语义相似度。CLIP 将图像和文本映射到共享的嵌入空间，二者的余弦相似度反映语义对齐程度。


CLIP Score = cos(CLIP_image(x), CLIP_text(c))，其中 x 是生成图像，c 是文本提示。更高的 CLIP Score 表示生成结果更好地遵循了文本描述。然而，CLIP Score 与 FID 之间存在内在张力：增大 Classifier-Free Guidance 强度会提高 CLIP Score（更严格遵循文本）但可能降低 FID（降低多样性、引入伪影）。

人类评估仍然是生成质量的最终标准。常用的人工评估方案包括 A/B 偏好测试、MOS（Mean Opinion Score）评分和对齐性评分。为了减少主观性，评估通常采用大规模众包标注并进行评估者一致性分析。


小结
    

  • FID 是最通用的生成质量指标，同时捕获保真度和多样性，但需要足够的样本量
    • 

  • IS 衡量类别清晰度和覆盖度，但忽略真实数据分布，应作为辅助指标使用
    • 

  • Precision/Recall 将生成质量分解为保真度和多样性两个独立维度，便于诊断问题
    • 

  • CLIP Score 是文本条件生成的核心评估指标，但需注意与多样性的权衡
    • 

  • 不同生成任务应选择匹配的指标组合，人工评估始终是最终标准
    • 

  • 实际评估中需关注指标的样本量依赖性、特征空间选择和统计显著性
