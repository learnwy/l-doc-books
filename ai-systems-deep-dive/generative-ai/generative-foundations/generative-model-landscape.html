生成模型全景

核心概念

生成模型的目标是学习数据的概率分布 p(x)，从而能够采样产生与训练数据同分布的新样本。与判别模型关注条件概率 p(y|x) 不同，生成模型需要捕获数据的完整统计结构，包括各维度之间的联合分布和依赖关系。这一根本差异使得生成模型的训练更加困难，但也赋予了它更强的表达能力和更广泛的应用潜力。

生成模型按照是否显式建模概率密度函数可以分为两大类。显式密度模型直接定义并优化数据的对数似然，包括精确推断的自回归模型和标准化流，以及近似推断的 VAE 和扩散模型。隐式密度模型不直接建模概率密度，而是通过对抗训练或能量函数间接学习数据分布，GAN 是其中最典型的代表。

自回归生成范式
自回归模型将联合分布分解为条件概率的连乘：p(x) = ∏ p(xᵢ | x₁, ..., xᵢ₋₁)。这种分解天然地满足概率的链式法则，因此能够提供精确的对数似然计算。在文本生成领域，GPT 系列模型正是基于这一范式取得了突破性进展。


在图像生成中，PixelCNN 将像素按照光栅扫描顺序排列，逐像素预测条件概率。每个像素的生成依赖于其左侧和上方已生成的像素，通过掩码卷积确保因果约束。PixelCNN++ 引入了门控机制和混合 Logistic 分布来改进离散概率建模。


import torch
import torch.nn as nn

class MaskedConv2d(nn.Conv2d):
    def __init__(self, mask_type, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.register_buffer('mask', self.weight.data.clone())
        _, _, h, w = self.weight.size()
        self.mask.fill_(1)
        self.mask[:, :, h // 2, w // 2 + (mask_type == 'B'):] = 0
        self.mask[:, :, h // 2 + 1:] = 0

    def forward(self, x):
        self.weight.data *= self.mask
        return super().forward(x)

class PixelCNN(nn.Module):
    def __init__(self, channels=64, n_layers=7):
        super().__init__()
        layers = [MaskedConv2d('A', 1, channels, 7, padding=3)]
        for _ in range(n_layers - 1):
            layers.extend([nn.ReLU(), MaskedConv2d('B', channels, channels, 7, padding=3)])
        layers.extend([nn.ReLU(), nn.Conv2d(channels, 256, 1)])
        self.net = nn.Sequential(*layers)

    def forward(self, x):
        return self.net(x)
自回归模型的主要局限在于顺序生成导致的推理速度瓶颈。生成一张 256×256 的图像需要 65536 步前向传播，这在实际应用中难以接受。WaveNet 在音频领域面临类似问题。虽然并行化技术（如 Parallel WaveNet 中的逆自回归流）可以一定程度上缓解，但在图像领域的并行化仍然是开放问题。


对抗生成与隐式建模
GAN 通过引入博弈论框架回避了显式密度建模的困难。生成器 G 将随机噪声映射为数据样本，判别器 D 区分真实样本和生成样本，二者通过极小极大博弈共同优化。这种对抗训练的精妙之处在于，当博弈达到纳什均衡时，生成器的输出分布理论上等于真实数据分布。


GAN 的优势在于生成速度快（单次前向传播）且生成质量高，尤其在人脸生成领域达到了照片级真实感。然而，GAN 的训练以不稳定著称，模式崩塌（mode collapse）是核心难题——生成器可能只学会产生少数几种输出而忽略数据分布的其他模式。Wasserstein GAN 通过改用 Earth Mover 距离作为目标函数，显著改善了训练稳定性，但并未完全解决问题。


GAN 的理论分析涉及最优传输理论、积分概率度量和 f-散度家族。不同的判别器目标函数对应不同的概率散度度量：原始 GAN 最小化 Jensen-Shannon 散度，f-GAN 推广到任意 f-散度，WGAN 使用 Wasserstein-1 距离。理解这些理论联系有助于选择合适的训练策略。


变分推断与隐变量模型
VAE 将生成过程建模为隐变量模型：先从先验分布 p(z) 采样隐变量 z，再通过解码器 p(x|z) 生成数据。由于后验分布 p(z|x) 通常不可解析计算，VAE 引入一个编码器 q(z|x) 来近似后验，并通过最大化证据下界（ELBO）来训练整个模型。


ELBO = E[log p(x|z)] - KL(q(z|x) || p(z))，其中第一项是重构损失，鼓励解码器准确还原输入；第二项是 KL 散度正则项，约束后验分布接近先验。这个目标函数的优雅之处在于同时训练了编码器和解码器，并保证了隐空间的正则性。


import torch
import torch.nn as nn
import torch.nn.functional as F

class VAE(nn.Module):
    def __init__(self, input_dim=784, hidden_dim=400, latent_dim=20):
        super().__init__()
        self.encoder = nn.Sequential(nn.Linear(input_dim, hidden_dim), nn.ReLU())
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, input_dim), nn.Sigmoid()
        )

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std

    def forward(self, x):
        h = self.encoder(x.view(-1, 784))
        mu, logvar = self.fc_mu(h), self.fc_logvar(h)
        z = self.reparameterize(mu, logvar)
        recon = self.decoder(z)
        return recon, mu, logvar

def vae_loss(recon, x, mu, logvar):
    bce = F.binary_cross_entropy(recon, x.view(-1, 784), reduction='sum')
    kld = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return bce + kld
重参数化技巧（Reparameterization Trick）是 VAE 的关键创新。它将随机采样过程 z = μ + σε 重写为确定性函数加外部噪声，使得梯度可以通过 μ 和 σ 反向传播到编码器。这一技巧解决了随机节点不可微分的问题，是变分推断与深度学习结合的桥梁。


VQ-VAE 引入向量量化（Vector Quantization）取代连续隐空间，将编码映射到离散码本中最近的向量。这避免了 KL 散度坍缩（posterior collapse）问题，并为自回归先验模型提供了离散token序列，在图像和语音合成中表现优异。


扩散模型的崛起
扩散模型（Diffusion Models）通过定义一个逐步向数据添加噪声的前向过程，以及学习逆向去噪的反向过程来实现生成。DDPM（Denoising Diffusion Probabilistic Models）将前向过程定义为马尔可夫链，每一步添加少量高斯噪声，经过 T 步后数据完全变为纯噪声。反向过程同样是马尔可夫链，由神经网络参数化每一步的去噪分布。


扩散模型在数学上与去噪得分匹配（denoising score matching）和随机微分方程（SDE）有深刻联系。Score-based 视角将生成过程理解为沿数据分布的得分函数（梯度方向）进行的 Langevin 动力学采样。这一统一框架由 Song 等人在 2021 年提出，将离散的扩散步骤推广为连续的 SDE。


扩散模型之所以在 2022 年后迅速崛起，主要得益于三个方面的突破：一是 Latent Diffusion Model（LDM）将扩散过程从像素空间迁移到隐空间，大幅降低计算成本；二是 Classifier-Free Guidance 提供了强大的条件生成控制机制；三是与大规模文本编码器（如 CLIP）结合，实现了高质量的文本到图像生成。Stable Diffusion 正是这些技术的集大成者。


与 GAN 相比，扩散模型的训练目标是简单的去噪均方误差，不存在对抗训练的不稳定性；与 VAE 相比，扩散模型的多步去噪过程提供了更强的生成能力。其主要代价是推理速度——标准 DDPM 需要数百到上千步采样。后续的 DDIM、DPM-Solver 等加速算法将采样步数缩减到 20-50 步甚至更少。


小结
    

  • 生成模型按密度建模方式分为显式（自回归、流、VAE、扩散）和隐式（GAN、能量模型）两大类
    • 

  • 自回归模型提供精确对数似然但推理速度受限于顺序生成
    • 

  • GAN 通过对抗博弈实现快速高质量生成，但训练不稳定且易模式崩塌
    • 

  • VAE 基于变分推断学习正则化隐空间，重参数化技巧是其核心创新
    • 

  • 扩散模型凭借训练稳定性和生成质量成为当前主流，隐空间扩散大幅降低了计算成本
    • 

  • 各类模型各有优劣，实际应用中需根据质量、速度和可控性需求选择合适的方案
