概率生成模型

核心概念

概率生成模型的数学基础建立在概率论和统计推断之上。生成模型的核心任务是从有限的训练样本 {x₁, x₂, ..., xₙ} 中估计数据的真实分布 pdata(x)，并构建一个参数化模型 pθ(x) 使其尽可能逼近真实分布。这一过程涉及最大似然估计、变分推断、蒙特卡洛采样等关键数学工具。

不同的概率推断方法适用于不同的模型结构和计算约束。选择合适的推断框架是设计生成模型的关键决策之一。

最大似然估计与 KL 散度
最大似然估计（MLE）是训练生成模型最基本的原则。给定参数化模型 pθ(x)，MLE 的目标是找到使训练数据对数似然最大的参数：θ* = argmax Σ log pθ(xᵢ)。从信息论角度，最大化对数似然等价于最小化模型分布与数据分布之间的 KL 散度：KL(pdata || pθ)。


KL 散度是非对称的，KL(p || q) ≠ KL(q || p)。前向 KL（KL(pdata || pθ)）对应 MLE，它倾向于覆盖数据分布的所有模式（mode covering），可能在无数据区域分配概率质量。反向 KL（KL(p_θ || p_data)）倾向于锁定单一模式（mode seeking），可能忽略部分数据模式。理解这种不对称性对于选择训练目标至关重要。


import torch
import torch.nn as nn
import torch.distributions as dist

class GaussianMixtureMLE(nn.Module):
    def __init__(self, n_components=5, dim=2):
        super().__init__()
        self.n_components = n_components
        self.means = nn.Parameter(torch.randn(n_components, dim))
        self.log_stds = nn.Parameter(torch.zeros(n_components, dim))
        self.logits = nn.Parameter(torch.zeros(n_components))

    def log_prob(self, x):
        weights = torch.softmax(self.logits, dim=0)
        stds = torch.exp(self.log_stds)
        log_probs = []
        for k in range(self.n_components):
            component = dist.Independent(
                dist.Normal(self.means[k], stds[k]), 1
            )
            log_probs.append(torch.log(weights[k]) + component.log_prob(x))
        return torch.logsumexp(torch.stack(log_probs, dim=-1), dim=-1)

    def sample(self, n_samples):
        weights = torch.softmax(self.logits, dim=0)
        indices = dist.Categorical(weights).sample((n_samples,))
        stds = torch.exp(self.log_stds)
        samples = self.means[indices] + stds[indices] * torch.randn_like(self.means[indices])
        return samples
然而直接计算对数似然 log p_θ(x) 在很多模型中是困难的，因为它涉及对隐变量的积分或配分函数的计算。不同模型采用了不同策略来绕过这一困难：自回归模型利用链式法则将联合概率分解为可计算的条件概率乘积；标准化流通过可逆变换和雅可比行列式精确计算密度；VAE 用变分下界代替精确似然。


变分推断与证据下界
当模型包含隐变量 z 时，边际似然 pθ(x) = ∫ pθ(x, z) dz 通常不可计算。变分推断引入一个近似后验分布 qφ(z|x) 来逼近真实后验 pθ(z|x)，并推导出证据下界（ELBO）作为可优化的替代目标。


ELBO 的推导过程揭示了生成模型中重构与正则化之间的本质权衡。从 log p(x) 出发，利用 Jensen 不等式可以得到：log p(x) ≥ E_q[log p(x|z)] - KL(q(z|x) || p(z))。等号成立的条件是 q(z|x) = p(z|x)，即近似后验等于真实后验。ELBO 与真实似然之间的间隙恰好等于 KL(q(z|x) || p(z|x))。


在实践中，ELBO 的优化面临几个挑战。KL 散度坍缩（posterior collapse）是最常见的问题：当解码器足够强大时，它可以忽略隐变量而直接从自回归结构中生成数据，导致编码器输出退化为先验分布。缓解策略包括 KL 退火（从 0 逐步增大 KL 项系数）、自由比特（设置 KL 的最低值）和 δ-VAE 等。


对于更复杂的近似后验分布，可以使用标准化流来增强 q(z|x) 的表达能力。IAF（Inverse Autoregressive Flow）将简单高斯分布通过可逆变换映射为复杂分布，从而缩小变分间隙。


蒙特卡洛采样方法
当直接计算概率密度或其梯度困难时，蒙特卡洛采样方法提供了一种通用的近似策略。在生成模型中，MCMC 采样既可以用于训练（如能量模型的对比散度），也可以用于推理（如 Langevin 动力学采样）。


Langevin 动力学是一种基于梯度的 MCMC 方法：xₜ₊₁ = xₜ + ε∇ₓ log p(xₜ) + √(2ε)η，其中 η ~ N(0, I)。它沿着对数概率密度的梯度方向移动，同时加入随机噪声以确保遍历性。当步长足够小、步数足够多时，采样分布收敛到目标分布。


import torch

def langevin_sampling(score_fn, n_samples, dim, n_steps=1000, step_size=0.01):
    x = torch.randn(n_samples, dim)
    for t in range(n_steps):
        noise = torch.randn_like(x)
        score = score_fn(x)
        x = x + step_size * score + (2 * step_size) ** 0.5 * noise
    return x

def annealed_langevin(score_fn, n_samples, dim, sigmas, n_steps_per_sigma=100):
    x = torch.randn(n_samples, dim)
    for sigma in sigmas:
        step_size = 0.5 * (sigma / sigmas[-1]) ** 2
        for _ in range(n_steps_per_sigma):
            noise = torch.randn_like(x)
            score = score_fn(x, sigma)
            x = x + step_size * score + (2 * step_size) ** 0.5 * noise
    return x
退火 Langevin 动力学（Annealed Langevin Dynamics）通过在不同噪声尺度下进行多轮采样来改善混合性。从高噪声开始有助于跨越模式之间的能量屏障，逐步降低噪声则精细化样本质量。这一思想与扩散模型的多步去噪过程有深刻的联系——事实上，扩散模型的反向采样可以理解为一种特殊的退火 Langevin 动力学。


对比散度（Contrastive Divergence）是训练能量模型和受限玻尔兹曼机的核心算法。它用 k 步 Gibbs 采样或 Langevin 采样近似 MLE 梯度中的模型期望项，避免了完整 MCMC 链收敛的高昂计算成本。CD-1（只用一步采样）虽然有偏但在实践中表现良好。


得分匹配与去噪目标
得分匹配（Score Matching）提供了一种绕过配分函数计算的密度估计方法。数据分布的得分函数定义为 ∇ₓ log p(x)，它描述了概率密度增长最快的方向。得分匹配的目标是训练一个得分网络 sθ(x) ≈ ∇ₓ log p_data(x)，使其在数据点处的值接近真实得分。


直接得分匹配需要计算 Hessian 矩阵的迹，计算成本高。去噪得分匹配（Denoising Score Matching, DSM）巧妙地将目标转化为：给定加噪数据 x̃ = x + σε，训练网络预测噪声的方向，即 sθ(x̃) ≈ ∇x̃ log pσ(x̃|x) = -(x̃ - x)/σ²。这等价于训练网络预测添加的噪声 ε。


这一结果具有深远意义：它直接联系了得分匹配与扩散模型的训练目标。DDPM 的训练损失 E[||ε - εθ(xₜ, t)||²] 本质上就是在不同噪声尺度下的去噪得分匹配。这一理论统一性意味着扩散模型不仅是一种特定的生成架构，更是概率建模框架中的自然产物。

小结
    

  • 最大似然估计等价于最小化 KL 散度，前向和反向 KL 具有不同的模式覆盖特性
    • 

  • 变分推断通过 ELBO 将不可计算的边际似然转化为可优化目标，但存在变分间隙
    • 

  • 蒙特卡洛采样和 Langevin 动力学为高维分布提供了通用的近似采样工具
    • 

  • 去噪得分匹配将密度估计转化为噪声预测，直接统一了得分函数学习与扩散模型训练
