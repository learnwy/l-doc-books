ControlNet 与适配器

核心概念

ControlNet 和各类适配器技术解决的核心问题是：如何在不重新训练基础模型的前提下，为预训练的文本到图像模型添加精确的空间控制能力。标准的文本提示难以精确描述物体的姿态、边缘、深度等空间信息，而 ControlNet 通过添加条件分支网络，允许用户以边缘图、深度图、姿态骨架等结构化信息为条件来引导生成。

ControlNet 的设计哲学是"不破坏原有能力"。通过克隆基础模型的编码器并使用零卷积（zero convolution）连接，ControlNet 在训练初期对基础模型的输出几乎没有影响，随着训练进行逐步学习条件控制能力。

ControlNet 架构与零卷积
ControlNet 的架构设计精妙而优雅。它将预训练 U-Net 的编码器完整克隆一份作为可训练的条件分支，冻结原始 U-Net 的所有参数。条件图像（如 Canny 边缘图）通过浅层卷积编码后输入条件分支，条件分支的各层输出通过零卷积（初始权重和偏置均为零的 1×1 卷积）叠加到原始 U-Net 对应层的输出上。


零卷积是 ControlNet 成功的关键技巧。由于初始权重为零，训练开始时条件分支对基础模型的输出完全没有影响，保护了预训练模型已学到的生成能力。随着训练进行，零卷积的参数从零开始缓慢增长，条件分支逐步影响生成过程。这种"从零开始学习控制"的策略比直接在预训练模型上微调更加安全和稳定。


from diffusers import StableDiffusionControlNetPipeline, ControlNetModel
from diffusers.utils import load_image
import torch
from PIL import Image
import numpy as np

controlnet = ControlNetModel.from_pretrained(
    "lllyasviel/sd-controlnet-canny", torch_dtype=torch.float16
)
pipe = StableDiffusionControlNetPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5",
    controlnet=controlnet,
    torch_dtype=torch.float16,
).to("cuda")

def get_canny_image(image, low=100, high=200):
    import cv2
    image_np = np.array(image)
    edges = cv2.Canny(image_np, low, high)
    return Image.fromarray(edges)

control_image = get_canny_image(load_image("input.png"))
image = pipe(
    prompt="a beautiful house in a garden, high quality, detailed",
    image=control_image,
    num_inference_steps=30,
    guidance_scale=7.5,
).images[0]
ControlNet 支持多种控制条件：Canny 边缘（精确轮廓控制）、深度图（空间结构控制）、OpenPose 骨架（人体姿态控制）、语义分割图（区域语义控制）、法线贴图（表面方向控制）和涂鸦（草图创意控制）。多个 ControlNet 可以同时使用，通过加权组合实现复合条件控制。


IP-Adapter 与图像条件注入
IP-Adapter（Image Prompt Adapter）使用参考图像作为条件，将图像的风格、内容或两者同时注入到生成过程中。与 ControlNet 通过特征叠加不同，IP-Adapter 通过额外的交叉注意力层实现图像条件注入。参考图像经过 CLIP 图像编码器得到图像嵌入，然后通过可训练的投影层转化为与文本嵌入兼容的 Key 和 Value。


IP-Adapter 的训练只需更新投影层和新增的交叉注意力层，基础模型完全冻结。由于参数量很小（约 22M），训练成本远低于 ControlNet。更重要的是，IP-Adapter 可以与 ControlNet 同时使用——IP-Adapter 提供风格引导，ControlNet 提供结构控制，文本提示提供语义描述。


from diffusers import StableDiffusionPipeline
from transformers import CLIPVisionModelWithProjection, CLIPImageProcessor
import torch

class IPAdapterInference:
    def __init__(self, pipe, ip_adapter_path):
        self.pipe = pipe
        self.image_encoder = CLIPVisionModelWithProjection.from_pretrained(
            "openai/clip-vit-large-patch14"
        ).to(pipe.device)
        self.image_processor = CLIPImageProcessor()
        self.pipe.load_ip_adapter(ip_adapter_path, subfolder="", weight_name="ip-adapter_sd15.bin")

    def generate(self, prompt, reference_image, ip_scale=0.6):
        self.pipe.set_ip_adapter_scale(ip_scale)
        image = self.pipe(
            prompt=prompt,
            ip_adapter_image=reference_image,
            num_inference_steps=30,
            guidance_scale=7.5,
        ).images[0]
        return image
IP-Adapter 的权重参数（ip_scale）控制参考图像对生成结果的影响程度。较低的值保留更多文本控制，较高的值更多地跟随参考图像的风格。IP-Adapter-FaceID 是针对人脸的变体，使用 InsightFace 的人脸特征替代 CLIP 图像特征，实现精确的面部特征保持。


T2I-Adapter 与轻量级控制
T2I-Adapter 是 ControlNet 的轻量级替代方案。与 ControlNet 克隆整个 U-Net 编码器不同，T2I-Adapter 使用小型的条件编码器（约 70M 参数，仅为 ControlNet 的 1/5），将条件信息编码为多尺度特征图后直接加到 U-Net 的对应层上。

LoRA（Low-Rank Adaptation）和 Textual Inversion 是两种更轻量的个性化方法。LoRA 通过低秩矩阵分解在注意力层注入可训练参数，实现风格和概念的微调；Textual Inversion 只训练一个新的文本嵌入向量来表示目标概念，参数量仅为几 KB。这些方法可以与 ControlNet/IP-Adapter 自由组合。


控制条件预处理管线
在实际应用中，控制条件的提取质量直接影响生成结果。不同的控制类型需要不同的预处理算法，选择合适的预处理器和参数是实现精确控制的关键。


import cv2
import numpy as np
from PIL import Image

def preprocess_canny(image, low_threshold=100, high_threshold=200):
    image_np = np.array(image.convert("L"))
    edges = cv2.Canny(image_np, low_threshold, high_threshold)
    return Image.fromarray(edges)

def preprocess_depth(image, model_type="MiDaS_small"):
    import torch
    midas = torch.hub.load("intel-isl/MiDaS", model_type)
    midas.eval()
    transform = torch.hub.load("intel-isl/MiDaS", "transforms").small_transform
    img = transform(np.array(image)).unsqueeze(0)
    with torch.no_grad():
        depth = midas(img)
    depth = depth.squeeze().numpy()
    depth = (depth - depth.min()) / (depth.max() - depth.min()) * 255
    return Image.fromarray(depth.astype(np.uint8))

def preprocess_hed(image):
    from controlnet_aux import HEDdetector
    hed = HEDdetector.from_pretrained("lllyasviel/Annotators")
    return hed(image)
预处理质量的常见问题包括：Canny 阈值不当导致边缘过多或过少、深度估计在透明物体和反射面上失效、OpenPose 在遮挡场景下姿态检测错误。在生产环境中，通常需要对预处理结果进行人工检查和调整，或使用多种预处理器的集成结果。


小结
    

  • ControlNet 通过零卷积和编码器克隆实现安全的条件注入，支持多种空间控制类型
    • 

  • IP-Adapter 通过交叉注意力注入参考图像特征，实现轻量级的风格和内容控制
    • 

  • T2I-Adapter 是 ControlNet 的轻量替代，适合计算资源受限的场景
    • 

  • 多种控制方法可以自由组合，同时利用文本、空间结构和参考图像三维条件
    • 

  • 控制条件的预处理质量直接影响生成结果，需要针对具体场景选择合适的预处理器
    •
