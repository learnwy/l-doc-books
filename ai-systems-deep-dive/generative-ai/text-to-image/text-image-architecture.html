Part III · 生成式与多模态 (Generative & Multimodal)生成式 AI 简介文本到图像 简介文图架构设计

文图架构设计

核心概念

文本到图像生成的核心挑战是建立自然语言与视觉内容之间的精确映射。当前主流的技术路线有两条：基于扩散模型的方法（Stable Diffusion、DALL-E 3、FLUX）在隐空间中进行条件去噪生成，基于自回归模型的方法（DALL-E、Parti、Emu）将图像编码为离散 token 后用 Transformer 逐 token 生成。两种范式各有优劣，且在实际演进中相互借鉴融合。

选择架构时需要在生成质量、推理速度、文图对齐精度和训练成本之间权衡。扩散模型在图像质量和训练稳定性上领先，自回归模型在统一多模态生成和文本理解上具有优势。

扩散范式的技术栈
扩散范式的文图生成系统由三层技术栈构成：文本编码层将提示词转化为稠密的语义表示，生成层在条件引导下执行去噪过程，解码层将隐空间结果还原为像素图像。不同模型在每一层的技术选择构成了差异化的竞争优势。


在文本编码层，CLIP（对比学习训练）和 T5（语言模型训练）代表两种不同的编码理念。CLIP 擅长视觉-语言对齐但语言理解能力有限，T5 语言理解更深入但可能缺乏视觉接地。SDXL 组合使用两个 CLIP 编码器，SD3 同时使用 CLIP 和 T5-XXL，DALL-E 3 使用 T5 并通过数据重标注（re-captioning）策略大幅提升了文图一致性。


from diffusers import StableDiffusion3Pipeline
import torch

pipe = StableDiffusion3Pipeline.from_pretrained(
    "stabilityai/stable-diffusion-3-medium-diffusers",
    torch_dtype=torch.float16,
).to("cuda")

image = pipe(
    prompt="A cat sitting on a windowsill, looking at the rain outside, warm lighting",
    negative_prompt="blurry, distorted, low quality",
    num_inference_steps=28,
    guidance_scale=7.0,
    width=1024, height=1024,
).images[0]
Stable Diffusion 3 引入了 MMDiT（Multi-Modal Diffusion Transformer）架构，用 Transformer 替代 U-Net 作为去噪网络。图像 token 和文本 token 在同一个 Transformer 中通过联合注意力（Joint Attention）交互，而非之前通过交叉注意力单向注入。这种双向交互使文本和图像特征能够更深入地对齐。


自回归范式与视觉 Token 化
自回归范式将图像生成转化为序列预测问题。首先通过视觉 tokenizer（如 VQ-VAE、ViT-VQGAN）将图像编码为离散 token 序列，然后用 Transformer 以自回归方式逐个生成 token，最后由 token 解码器还原为图像。文本条件通过将文本 token 拼接在图像 token 前面来实现。


Parti 使用 ViT-VQGAN 作为视觉 tokenizer，编码器-解码器 Transformer 作为序列模型。它展示了自回归范式在大规模（20B 参数）训练下的强大能力，在复杂场景描述上的文图一致性甚至超过了同期的扩散模型。自回归模型的一个独特优势是可以自然地处理可变分辨率和可变数量的输出。


import torch
import torch.nn as nn

class VisualTokenizer(nn.Module):
    def __init__(self, codebook_size=8192, embed_dim=256):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Conv2d(3, 128, 4, 2, 1), nn.ReLU(),
            nn.Conv2d(128, 256, 4, 2, 1), nn.ReLU(),
            nn.Conv2d(256, embed_dim, 3, 1, 1),
        )
        self.codebook = nn.Embedding(codebook_size, embed_dim)
        self.decoder = nn.Sequential(
            nn.ConvTranspose2d(embed_dim, 256, 4, 2, 1), nn.ReLU(),
            nn.ConvTranspose2d(256, 128, 4, 2, 1), nn.ReLU(),
            nn.Conv2d(128, 3, 3, 1, 1), nn.Tanh(),
        )

    def encode(self, x):
        z = self.encoder(x)
        b, c, h, w = z.shape
        flat = z.permute(0, 2, 3, 1).reshape(-1, c)
        distances = torch.cdist(flat, self.codebook.weight)
        indices = distances.argmin(dim=1)
        return indices.view(b, h * w)

    def decode(self, indices, h, w):
        z_q = self.codebook(indices).view(-1, h, w, self.codebook.embedding_dim)
        z_q = z_q.permute(0, 3, 1, 2)
        return self.decoder(z_q)
然而自回归范式面临两个核心挑战：一是 token 化引入的信息损失（码本大小有限），二是逐 token 生成的推理速度瓶颈。256×256 的图像在 16 倍下采样后仍有 256 个 token，自回归生成需要 256 次前向传播。最新的研究（如 MAR、Muse）通过掩码自回归和并行解码策略来缓解速度问题。


DALL-E 3 的数据工程突破
DALL-E 3 的最大创新不在模型架构，而在数据工程。通过训练一个专用的 image captioner 重新为训练图像生成详细的文本描述，DALL-E 3 大幅提升了文图对齐质量。这一 re-captioning 策略的核心洞见是：训练数据中的 alt-text 往往是粗略、不准确甚至与图像内容无关的，这种噪声标注是文图对齐不精确的根本原因。


重标注后的描述更加详细和准确，包含对象的数量、位置、颜色、动作和空间关系等信息。模型在高质量标注上训练后，能够更好地理解和执行复杂的文本指令。这一策略被后续的工作广泛采用——PixArt-α 使用 LLaVA 生成 re-caption，FLUX 和 Ideogram 也采用了类似策略。

小结
    

  • 扩散范式和自回归范式是文图生成的两大技术路线，各有独特优势
    • 

  • Stable Diffusion 3 的 MMDiT 通过联合注意力实现了更深入的文图交互
    • 

  • 视觉 token 化使图像生成可以复用语言模型架构，但面临信息损失和速度挑战
    • 

  • DALL-E 3 的 re-captioning 策略证明了数据质量对文图对齐的决定性影响
    • 

  • 现代文图系统的竞争力越来越取决于数据工程、训练策略和系统集成能力
