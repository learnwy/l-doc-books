图像编辑技术

核心概念

基于扩散模型的图像编辑技术允许用户对已有图像进行精确的局部或全局修改，同时保持未编辑区域的一致性。与从零生成不同，图像编辑需要平衡两个目标：忠实执行编辑指令，以及保留原始图像的内容和风格。当前的编辑方法可以分为三大类：基于 Inpainting 的区域替换、基于噪声注入的全局编辑（SDEdit）和基于指令的端到端编辑（InstructPix2Pix）。

每种方法在编辑精度、灵活性和保真度之间有不同的权衡。区域编辑最精确但需要用户提供掩码，全局编辑自动化程度高但控制粒度有限，指令编辑最自然但依赖模型的指令理解能力。

Inpainting 与区域重绘
Inpainting（图像修复/重绘）是最基本也最实用的编辑操作。用户提供原始图像和一个二值掩码指定需要重绘的区域，模型在保持掩码外区域不变的条件下，根据文本提示重新生成掩码内的内容。Stable Diffusion 的 Inpainting 模型在标准模型基础上额外接受掩码和被掩码图像作为输入，通道数从 4 增加到 9（4 隐变量 + 4 被掩码隐变量 + 1 掩码）。


from diffusers import StableDiffusionInpaintPipeline
import torch
from PIL import Image

pipe = StableDiffusionInpaintPipeline.from_pretrained(
    "runwayml/stable-diffusion-inpainting", torch_dtype=torch.float16
).to("cuda")

def inpaint_image(image, mask, prompt, strength=0.75):
    result = pipe(
        prompt=prompt,
        image=image,
        mask_image=mask,
        num_inference_steps=30,
        guidance_scale=7.5,
        strength=strength,
    ).images[0]
    return result

def create_smooth_mask(mask, blur_radius=5):
    import numpy as np
    from PIL import ImageFilter
    mask_np = np.array(mask.convert("L"))
    mask_pil = Image.fromarray(mask_np)
    return mask_pil.filter(ImageFilter.GaussianBlur(blur_radius))
Inpainting 的关键挑战是边缘过渡：重绘区域与保留区域之间的边界需要自然融合。常用的技巧包括掩码边缘模糊（使过渡更平滑）、扩大掩码范围（给模型更多上下文空间）和多次迭代重绘（逐步细化边缘区域）。Outpainting 是 Inpainting 的扩展——掩码覆盖图像边界外的区域，用于扩展图像尺寸。


SDEdit 与噪声空间编辑
SDEdit 的核心思想极其简洁：向原始图像添加一定程度的噪声，然后用扩散模型去噪。添加的噪声量（由强度参数控制）决定了编辑的程度——噪声越多，生成结果越偏离原始图像但越符合新提示；噪声越少，保真度越高但编辑效果越弱。


from diffusers import StableDiffusionImg2ImgPipeline
import torch

pipe = StableDiffusionImg2ImgPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", torch_dtype=torch.float16
).to("cuda")

def sdedit(image, prompt, strength=0.6, guidance_scale=7.5):
    result = pipe(
        prompt=prompt,
        image=image,
        strength=strength,
        guidance_scale=guidance_scale,
        num_inference_steps=30,
    ).images[0]
    return result

def style_transfer(content_image, style_prompt, strength=0.7):
    return sdedit(content_image, style_prompt, strength)
SDEdit 的 strength 参数是核心超参数。strength=0.3 适合轻微风格调整（如色调变化），strength=0.5-0.7 适合中等程度的风格迁移，strength=0.8+ 接近完全重新生成。在实践中，通常需要多次尝试不同的 strength 值来找到编辑程度与保真度之间的最佳平衡点。


Prompt-to-Prompt 与注意力操控
Prompt-to-Prompt 通过操控扩散过程中的交叉注意力图来实现精细的基于文本的编辑。核心观察是：交叉注意力图编码了文本 token 与图像空间位置之间的对应关系。通过在去噪过程中替换、重新加权或精炼特定 token 的注意力图，可以在不改变整体构图的情况下修改特定属性。


三种基本操作：词汇替换（将 "cat" 的注意力图替换为 "dog" 的注意力图，保持姿态和构图）、词汇重新加权（增大或减小某个词的注意力强度，控制该概念在图像中的突出程度）和注意力注入（将原始图像的结构注意力图注入到新提示的生成过程中，保持空间布局）。


import torch

def prompt_to_prompt_replace(pipe, source_prompt, target_prompt, source_word, target_word,
                             cross_replace_steps=0.8, self_replace_steps=0.4):
    source_tokens = pipe.tokenizer(source_prompt)["input_ids"]
    target_tokens = pipe.tokenizer(target_prompt)["input_ids"]
    source_idx = source_tokens.index(pipe.tokenizer.encode(source_word)[1])
    target_idx = target_tokens.index(pipe.tokenizer.encode(target_word)[1])
    config = {
        "cross_replace_steps": cross_replace_steps,
        "self_replace_steps": self_replace_steps,
        "source_word_idx": source_idx,
        "target_word_idx": target_idx,
    }
    return config

def attention_reweight(attn_maps, token_idx, scale=2.0):
    modified = attn_maps.clone()
    modified[:, :, token_idx] *= scale
    modified = modified / modified.sum(dim=-1, keepdim=True)
    return modified
Null-text Inversion 是 Prompt-to-Prompt 的重要补充技术。它通过优化无条件文本嵌入（null-text embedding）来实现对真实图像的精确 DDIM 反演。标准 DDIM 反演在 CFG 条件下不够精确，导致重建误差。Null-text Inversion 在每个时间步优化 null-text 嵌入，使得反演-重建过程近乎无损。


指令驱动编辑与 InstructPix2Pix
InstructPix2Pix 直接训练模型理解自然语言编辑指令并执行相应的图像修改。它的训练数据由 GPT-3 生成编辑指令、Prompt-to-Prompt 生成编辑后图像对构成。输入为原始图像和编辑指令（如"make it a sunset scene"），输出为编辑后的图像。

from diffusers import StableDiffusionInstructPix2PixPipeline
import torch

pipe = StableDiffusionInstructPix2PixPipeline.from_pretrained(
    "timbrooks/instruct-pix2pix", torch_dtype=torch.float16
).to("cuda")

def instruct_edit(image, instruction, image_guidance_scale=1.5, guidance_scale=7.5):
    result = pipe(
        prompt=instruction,
        image=image,
        num_inference_steps=30,
        image_guidance_scale=image_guidance_scale,
        guidance_scale=guidance_scale,
    ).images[0]
    return result
InstructPix2Pix 有两个引导强度参数：text_guidance_scale 控制对编辑指令的遵循程度，image_guidance_scale 控制对原始图像的保留程度。两个参数需要协同调优——增大 text_guidance 使编辑效果更明显但可能破坏原始内容，增大 image_guidance 保留更多原始信息但编辑效果减弱。


小结
    

  • Inpainting 通过掩码实现精确的区域替换，边缘融合是质量关键
    • 

  • SDEdit 利用噪声注入实现全局风格编辑，strength 参数控制编辑-保真权衡
    • 

  • Prompt-to-Prompt 通过注意力图操控实现细粒度的属性编辑，不改变整体构图
    • 

  • InstructPix2Pix 直接理解自然语言编辑指令，是用户体验最友好的编辑方式
    • 

  • 实际应用中常需组合多种编辑方法，并通过参数调优达到最佳效果
    •
