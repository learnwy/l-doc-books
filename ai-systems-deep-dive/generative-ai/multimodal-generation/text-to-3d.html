文本到三维生成

核心概念

文本到三维（Text-to-3D）生成的目标是从自然语言描述直接创建三维资产——包括几何形状、纹理贴图和材质属性。这一技术对游戏开发、影视制作、虚拟现实和电子商务具有巨大的应用价值。与图像和视频的像素化表示不同，三维资产有多种表示方式（网格、点云、NeRF、3D 高斯），每种表示对应不同的生成和渲染策略。

当前技术路线分为两大阵营：优化式方法利用预训练的 2D 扩散模型通过得分蒸馏来优化三维表示，前馈式方法直接训练端到端的三维生成网络。前者质量高但速度慢，后者速度快但需要大量三维训练数据。

Score Distillation Sampling
Score Distillation Sampling（SDS）是 DreamFusion 提出的核心技术，它允许使用预训练的 2D 图像扩散模型来优化三维场景表示。核心思想是：对三维场景的随机视角进行渲染，将渲染结果送入扩散模型计算去噪梯度，然后将该梯度反向传播到三维场景参数上进行更新。


SDS 的目标函数可以理解为：让三维场景从任意视角渲染出的图像都"看起来像"给定文本描述的图像。每次迭代随机采样一个相机视角和一个噪声时间步，将渲染图像加噪后用扩散模型预测噪声，得到的梯度指示了"如何修改渲染图像使其更符合文本描述"，这个梯度通过可微渲染器反向传播到三维表示的参数上。


import torch
import torch.nn.functional as F

def score_distillation_sampling(
    text_embeddings, nerf_model, diffusion_model, scheduler,
    camera_params, guidance_scale=100.0
):
    rendered = nerf_model.render(camera_params)
    latents = encode_to_latent(rendered)
    t = torch.randint(20, 980, (1,), device=latents.device)
    noise = torch.randn_like(latents)
    noisy_latents = scheduler.add_noise(latents, noise, t)
    with torch.no_grad():
        noise_pred_cond = diffusion_model(noisy_latents, t, text_embeddings)
        noise_pred_uncond = diffusion_model(noisy_latents, t, uncond_embeddings)
        noise_pred = noise_pred_uncond + guidance_scale * (noise_pred_cond - noise_pred_uncond)
    w = (1 - scheduler.alphas_cumprod[t])
    grad = w * (noise_pred - noise)
    latents.backward(gradient=grad)
    return grad.detach()

def dreamfusion_step(nerf, optimizer, diffusion, text_emb, scheduler):
    optimizer.zero_grad()
    camera = sample_random_camera()
    grad = score_distillation_sampling(text_emb, nerf, diffusion, scheduler, camera)
    optimizer.step()
SDS 存在已知的问题：过度饱和（Janus problem——物体的每个面都生成了正面特征，因为 2D 扩散模型没有三维一致性的概念）和模式平均（生成结果过度平滑）。Variational Score Distillation（VSD）通过引入粒子优化来缓解这些问题，但计算成本更高。


多视角扩散与三维重建
多视角扩散方法通过训练扩散模型直接生成物体的多个视角图像，然后使用三维重建算法（如 NeuS、3D Gaussian Splatting）从多视角图像恢复三维结构。这种两阶段方法绕过了 SDS 的优化问题，同时利用了大规模三维数据的训练优势。


Zero-1-to-3 和 Zero123++ 训练扩散模型以单张图像为条件生成指定视角的新视图。模型接收输入图像和目标相机参数（相对旋转和平移），输出对应视角的图像。通过生成足够多的视角（通常 8-16 个均匀分布的视角），可以使用多视图立体重建算法得到完整的三维模型。


import torch

class MultiViewReconstruction:
    def __init__(self, mv_diffusion, reconstruction_model):
        self.mv_model = mv_diffusion
        self.recon_model = reconstruction_model

    def generate_views(self, input_image, n_views=8):
        views = []
        azimuths = torch.linspace(0, 360, n_views + 1)[:-1]
        elevation = 15.0
        for azimuth in azimuths:
            camera_params = {
                "azimuth": azimuth.item(),
                "elevation": elevation,
                "distance": 2.0,
            }
            view = self.mv_model.generate(
                input_image, camera_params, num_inference_steps=30
            )
            views.append(view)
        return views

    def reconstruct_3d(self, views, cameras):
        mesh = self.recon_model(views, cameras)
        return mesh
SV3D（Stable Video 3D）将视频生成模型应用于三维：它将多视角图像生成视为一种特殊的视频生成（沿轨道运动的摄像机拍摄的视频），利用 SVD 的时序一致性来保证多视角之间的三维一致性。

前馈式三维生成与大型重建模型
前馈式方法通过训练端到端的三维生成网络实现单步（或少步）三维生成，推理速度比优化式方法快几个数量级。Large Reconstruction Model（LRM）是这一方向的代表工作。它将单张图像通过 Vision Transformer 编码为特征序列，然后通过 Transformer 解码器映射到 Triplane 表示（三个正交平面上的特征图），最后通过 NeRF 渲染器生成任意视角的图像。


LRM 在 Objaverse（约 80 万个三维模型）上训练，只需约 5 秒即可从单张图像生成三维模型。其后续工作 InstantMesh 结合了多视角扩散和前馈重建：先用 Zero123++ 生成多视角图像，再用 LRM 风格的网络从多视角重建三维模型。这种组合策略兼顾了生成质量和推理速度。


3D Gaussian Splatting 作为一种新的三维表示正在改变三维生成的技术路线。与 NeRF 通过体渲染隐式表示场景不同，3DGS 使用大量带有位置、颜色、协方差和不透明度的三维高斯来显式表示场景。3DGS 的优势是渲染速度极快（实时级别）且支持高效的梯度优化，使其成为 SDS 优化和三维编辑的理想载体。


小结
    

  • SDS 通过 2D 扩散模型的梯度来优化三维表示，无需三维训练数据但存在 Janus 问题
    • 

  • 多视角扩散方法先生成一致的多视角图像再重建三维，兼顾质量和速度
    • 

  • LRM 等前馈式方法实现了秒级三维生成，但依赖大规模三维训练数据
    • 

  • 3D Gaussian Splatting 凭借实时渲染和高效优化的特性成为三维生成的新标准表示
    • 

  • 文本到三维技术正在从分钟级优化向秒级生成快速演进
