跨模态统一生成

核心概念

跨模态统一生成（Cross-Modal Unified Generation）追求用单一模型同时处理文本、图像、音频、视频和三维等多种模态的理解和生成。这一方向的终极愿景是构建一个"通用生成器"——输入任意模态的条件，输出任意模态的内容。实现这一目标的关键挑战是建立统一的表示空间和生成框架，使得不同模态的数据能够在同一个模型中无缝交互。

统一生成模型的设计哲学是"一切皆为 Token"——将所有模态的数据都编码为离散或连续的 token 序列，然后在统一的序列模型中学习跨模态的联合分布。

统一 Token 化策略
统一 Token 化是实现跨模态生成的基础。不同模态的数据具有截然不同的结构——文本是离散符号序列，图像是二维像素阵列，音频是一维波形信号，视频是三维时空数据。将它们映射到统一的 token 空间需要为每种模态设计合适的编码器，同时确保不同模态的 token 在语义层面可以对齐。


Chameleon 采用了彻底的统一策略：文本使用 BPE tokenizer，图像使用 VQGAN 编码为离散 token（每张图像 1024 个 token），两种 token 共享同一个词汇表和同一个 Transformer。这种"早期融合"（early fusion）设计使模型从训练开始就学习跨模态的联合分布，理论上能够实现最深层次的模态交互。


import torch
import torch.nn as nn

class UnifiedTokenizer:
    def __init__(self, text_vocab_size=32000, image_codebook_size=8192, audio_codebook_size=2048):
        self.text_offset = 0
        self.image_offset = text_vocab_size
        self.audio_offset = text_vocab_size + image_codebook_size
        self.total_vocab = text_vocab_size + image_codebook_size + audio_codebook_size
        self.special_tokens = {
            "text_start": self.total_vocab,
            "image_start": self.total_vocab + 1,
            "audio_start": self.total_vocab + 2,
            "modality_end": self.total_vocab + 3,
        }

    def encode_text(self, text_tokens):
        return text_tokens + self.text_offset

    def encode_image(self, image_tokens):
        return image_tokens + self.image_offset

    def encode_audio(self, audio_tokens):
        return audio_tokens + self.audio_offset

    def build_sequence(self, modality_tokens_list):
        sequence = []
        for modality, tokens in modality_tokens_list:
            start_token = self.special_tokens[f"{modality}_start"]
            sequence.append(torch.tensor([start_token]))
            sequence.append(tokens)
            sequence.append(torch.tensor([self.special_tokens["modality_end"]]))
        return torch.cat(sequence)
"晚期融合"（late fusion）是另一种策略：不同模态使用独立的编码器和生成器，通过共享的隐空间或交叉注意力实现模态交互。CoDi 采用这种方法，每种模态有独立的扩散模型，通过训练一个跨模态注意力模块将不同模态的隐空间对齐。晚期融合的优势是可以复用现有的单模态模型，劣势是跨模态的交互深度不如早期融合。


自回归多模态生成
自回归范式天然适合多模态统一生成——所有模态的 token 序列拼接在一起，模型学习预测"下一个 token"。Emu3 展示了纯自回归模型在多模态生成中的潜力：它将文本、图像和视频统一编码为 token 序列，使用标准的下一个 token 预测目标训练，不需要扩散模型或额外的损失函数。


多模态自回归的关键挑战是模态间的序列组织方式。交错式（interleaved）排列将不同模态的 token 交替排列，适合生成图文混排内容；前缀式（prefix）将条件模态放在前面、生成模态放在后面，适合条件生成任务。实际系统通常根据任务灵活切换排列方式。


import torch
import torch.nn as nn

class MultiModalTransformer(nn.Module):
    def __init__(self, vocab_size, dim=1024, n_heads=16, n_layers=24):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, dim)
        self.pos_embedding = nn.Embedding(8192, dim)
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=dim, nhead=n_heads, dim_feedforward=dim * 4,
            batch_first=True, norm_first=True,
        )
        self.transformer = nn.TransformerEncoder(encoder_layer, n_layers)
        self.output_head = nn.Linear(dim, vocab_size)

    def forward(self, tokens):
        seq_len = tokens.shape[1]
        pos = torch.arange(seq_len, device=tokens.device).unsqueeze(0)
        x = self.embedding(tokens) + self.pos_embedding(pos)
        causal_mask = nn.Transformer.generate_square_subsequent_mask(seq_len, device=tokens.device)
        x = self.transformer(x, mask=causal_mask)
        return self.output_head(x)

    @torch.no_grad()
    def generate(self, prompt_tokens, max_new_tokens=1024, temperature=1.0):
        tokens = prompt_tokens.clone()
        for _ in range(max_new_tokens):
            logits = self.forward(tokens)[:, -1, :] / temperature
            next_token = torch.multinomial(torch.softmax(logits, dim=-1), 1)
            tokens = torch.cat([tokens, next_token], dim=1)
        return tokens
Gemini 是多模态统一生成的工业界代表。它从预训练阶段就在多模态混合数据上训练，原生支持文本、图像、音频、视频和代码的理解和生成。GPT-4o 则实现了端到端的语音理解和生成，将语音模态完全整合到统一模型中，而非传统的"ASR→LLM→TTS"级联管线。


Any-to-Any 生成的挑战与前沿
真正的 Any-to-Any 生成系统需要解决多个开放性挑战。首先是数据问题：不同模态的训练数据规模差异巨大（互联网文本>>图像>视频>音频>三维模型），如何在数据不平衡的情况下实现均衡的多模态能力是核心难题。其次是评估问题：缺乏统一的跨模态评估指标，不同模态的生成质量通常需要独立评估。

Mixture of Experts（MoE）是一种有希望的方法来应对计算效率挑战。通过将模型参数分为共享专家和模态特定专家，MoE 可以在不成比例增加计算量的情况下扩大模型容量。不同模态的输入激活不同的专家子集，实现了参数效率和模态特化的平衡。


世界模型（World Model）是 Any-to-Any 生成的更远期愿景。它不仅生成多模态内容，还需要理解物理规律、因果关系和时空一致性。Sora 被 OpenAI 定位为"世界模拟器"，体现了从内容生成到世界建模的方向性转变。实现这一愿景需要模型具备物理推理、长程规划和因果理解等深层能力。
