Part III · 生成式与多模态 (Generative & Multimodal)生成式 AI 简介多模态生成 简介文本到视频生成

文本到视频生成

核心概念

文本到视频生成在图像生成的基础上增加了时间维度，需要同时保证每一帧的视觉质量和帧间的时序一致性。视频可以理解为三维数据张量（时间×高度×宽度），生成模型需要在这个三维空间中学习联合分布。核心挑战在于：视频中存在复杂的运动模式、物理规律约束和长程时序依赖，这远比生成单帧图像困难。

graph TD
    A[文本到视频技术] --> B[时序扩散]
    A --> C[自回归帧生成]
    A --> D[图像动画化]
    B --> E[3D U-Net / DiT]
    B --> F[时序注意力]
    C --> G[帧间自回归]
    D --> H[运动场预测]
    D --> I[帧插值]

当前视频生成模型主要有三种架构策略：在图像扩散模型中增加时序层实现联合时空生成，将视频分解为关键帧生成加帧插值的级联管线，以及将视频编码为 token 序列后用自回归模型生成。

代际演进：Sora 冲击与开源浪潮（2024–2026）

视频生成在两年多的时间里完成了三次代际跨越，理解这条时间线比记住单个模型更重要：

timeline
    title 视频生成代际(2024-2026)
    2024 : Sora 预览引爆时空 patch 路线(02): 商用第一波--Kling、Runway Gen-3、Veo(06-12): 开源起点 CogVideoX、Mochi、LTX-Video
    2025 : 开源主力 HunyuanVideo 13B(2024-12 发布效应延续)与 Wan 2.1/2.2 开放权重 : Veo 3 引入原生同步音频(05): Sora 2 音画同步 + 社交应用(09)
    2026 : 商用单段 8-15 秒、1080p 成为常态 : 开源基线 720p、消费级显卡可跑、微调生态成熟

闭源商用线的三条竞争轴。一是音画同步：Veo 3（2025 年 Google I/O 发布）首次把对白、音效与环境声作为原生输出与画面联合生成，摆脱「生成视频再配音」的两步管线；Sora 2（2025-09 随同名社交应用发布，引入 Cameo 数字分身机制）据公开报道进一步强化了物理合理性——物体碰撞、浮力等场景不再频繁穿帮。二是角色与镜头一致性：Runway Gen-4 与 Kling 2.x 都转向以参考图为锚点的跨镜头生成。三是可控性：首尾帧约束、运镜指令、多主体参考成为商用产品标配。截至写作时（2026-08），商用模型单段时长主流落在 8–15 秒，长内容仍靠分段拼接。

开源浪潮的里程碑节奏。CogVideoX（2024-08）、Mochi 1（Genmo，2024-10，10B，Apache 2.0）和 LTX-Video（Lightricks，2024-11，轻量近实时）打开了局面；HunyuanVideo（腾讯，2024-12）以 13B 参数和双流转单流的宽→深 DiT 设计把开源质量拉到接近同期闭源水平；Wan 2.1（阿里，2025-02，Apache 2.0，含 1.3B 端侧档与 14B 全量档）及其 MoE 架构续作 Wan 2.2（2025-07）让「在家复现 Sora 级效果」从口号变成现实。配套生态同样关键：FramePack（2025-04）用 next-frame 预测把长视频生成的显存门槛压到约 6GB 的消费级显卡；SkyReels-V2（2025-04）用 Diffusion Forcing 实现分钟级无限长生成。截至写作时，「720p、5–10 秒、单卡可跑、社区微调活跃」已是开源视频模型的默认基线。

时序扩散与 3D 注意力

将图像扩散模型扩展到视频的最直接方法是在 U-Net 或 DiT 中插入时序处理层。在每个空间注意力层之后添加时序注意力层（在时间维度上计算自注意力），使模型能够捕获帧间的运动关系。时序卷积层（沿时间维度的 1D 卷积）提供局部时序建模，时序注意力提供全局时序建模。

import torch
import torch.nn as nn

class TemporalAttentionBlock(nn.Module):
    def __init__(self, dim, n_heads=8):
        super().__init__()
        self.norm = nn.LayerNorm(dim)
        self.attn = nn.MultiheadAttention(dim, n_heads, batch_first=True)

    def forward(self, x, n_frames):
        b_f, h_w, c = x.shape
        b = b_f // n_frames
        x = x.view(b, n_frames, h_w, c)
        x = x.permute(0, 2, 1, 3).reshape(b * h_w, n_frames, c)
        residual = x
        x = self.norm(x)
        x, _ = self.attn(x, x, x)
        x = x + residual
        x = x.reshape(b, h_w, n_frames, c).permute(0, 2, 1, 3)
        return x.reshape(b_f, h_w, c)

class SpatioTemporalBlock(nn.Module):
    def __init__(self, dim, n_heads=8):
        super().__init__()
        self.spatial_attn = nn.MultiheadAttention(dim, n_heads, batch_first=True)
        self.temporal_attn = TemporalAttentionBlock(dim, n_heads)
        self.temporal_conv = nn.Conv1d(dim, dim, 3, padding=1)
        self.norm1 = nn.LayerNorm(dim)
        self.norm2 = nn.LayerNorm(dim)

    def forward(self, x, n_frames):
        x = x + self.spatial_attn(self.norm1(x), self.norm1(x), self.norm1(x))[0]
        x = self.temporal_attn(x, n_frames)
        return x

Sora 的技术路线代表了视频生成的前沿方向。它将视频在时间和空间维度上同时分割为"时空 patch"，每个 patch 作为 Transformer 的 token 处理。这种设计允许模型在训练时处理不同分辨率和时长的视频，通过调整 patch 数量适应不同的输入规格。3D 因果 VAE 将视频压缩为时空隐表示，大幅降低计算成本。

帧间一致性与运动建模

时序一致性是视频生成质量的决定性因素。即使每一帧单独看都质量很高，帧间的闪烁、物体跳变和风格不一致都会严重影响视频质量。运动建模——学习和控制视频中物体的运动模式——是实现时序一致性的核心技术。

Stable Video Diffusion（SVD）采用图像到视频的范式：首先生成（或输入）一张关键帧图像，然后基于该图像生成一段视频。这种方法的优势是可以充分利用预训练图像模型的能力，通过微调学习运动建模。SVD 在 Stable Diffusion 的 U-Net 中插入时序注意力和时序卷积层，冻结空间层仅训练时序层。

from diffusers import StableVideoDiffusionPipeline
from diffusers.utils import load_image, export_to_video
import torch

pipe = StableVideoDiffusionPipeline.from_pretrained(
    "stabilityai/stable-video-diffusion-img2vid-xt",
    torch_dtype=torch.float16,
).to("cuda")

image = load_image("input_image.png").resize((1024, 576))
frames = pipe(
    image,
    decode_chunk_size=4,
    num_frames=25,
    motion_bucket_id=127,
    noise_aug_strength=0.02,
).frames[0]
export_to_video(frames, "output.mp4", fps=7)

运动强度控制（motion_bucket_id）允许用户指定视频的运动幅度。较低的值生成接近静态的视频，较高的值生成运动幅度更大的视频。噪声增强（noise_aug_strength）为输入图像添加轻微噪声，增加生成视频与输入图像之间的多样性。

长视频生成与级联策略

当前模型直接生成的视频通常限制在几秒到十几秒。生成更长视频需要级联策略：将长视频分解为多个短片段，通过条件重叠或自回归方式拼接。关键挑战是保持跨片段的一致性——角色外观、场景风格和运动连贯性不能在片段接缝处断裂。

常见的长视频策略包括：关键帧插值（先生成稀疏关键帧，再插值中间帧），自回归延展（以前一段的末尾帧为条件生成下一段），以及全局规划加局部生成（先生成粗粒度的全局轨迹，再在每个时间窗口内精细生成）。

策略 方法 一致性 计算成本 最大时长
直接生成 单次前向 最好 极高 ~10s
自回归延展 滑动窗口 好 线性增长 分钟级
关键帧插值 先稀后密 较好 中等 分钟级
层次生成 粗到细 好 中等 分钟级

视频生成的计算成本是一个核心制约因素。一段 1080p、30fps、10 秒的视频包含 300 帧，每帧约 200 万像素，总数据量是单张图像的数百倍。即使在隐空间中操作，时序注意力的计算复杂度也随帧数平方增长（O(T2)\mathcal{O}(T^2)O(T2)，其中 TTT 为压缩后的帧数），时空联合注意力更是达到 O((T⋅HW)2)\mathcal{O}((T \cdot HW)^2)O((T⋅HW)2) 量级。时序压缩（如 3D 因果 VAE 将时间维度压缩 4 倍）、注意力稀疏化和并行计算优化是应对这一挑战的关键技术。
