扩散过程的数学理论

核心概念

扩散模型的数学框架建立在两个互逆的随机过程之上：前向扩散过程逐步向数据添加高斯噪声直至完全破坏数据结构，反向去噪过程则学习逐步还原数据。DDPM（Denoising Diffusion Probabilistic Models）将这两个过程形式化为马尔可夫链，并通过变分推断推导出训练目标。这一框架的优雅之处在于：复杂的生成问题被分解为一系列简单的去噪子问题，每一步只需要预测并去除少量噪声。

前向过程是预定义的（无需学习），反向过程由神经网络参数化。训练时只需优化去噪网络预测噪声的能力，推理时从纯噪声出发逐步去噪即可生成新样本。

前向扩散与噪声调度
前向扩散过程定义为一系列高斯转移核的马尔可夫链。在每一步 t，数据 xₜ₋₁ 被添加少量噪声得到 xₜ：q(xₜ|xₜ₋₁) = N(xₜ; √(1-βₜ) xₜ₋₁, βₜI)，其中 βₜ 是噪声调度参数。令 αₜ = 1 - βₜ 且 ᾱₜ = ∏ᵢ₌₁ᵗ αᵢ，可以推导出从 x₀ 到任意 xₜ 的直接采样公式：q(xₜ|x₀) = N(xₜ; √ᾱₜ x₀, (1-ᾱₜ)I)。


这个闭式表达式是高效训练的关键——不需要逐步模拟前向过程，只需一步采样即可得到任意时间步的噪声数据：xₜ = √ᾱₜ x₀ + √(1-ᾱₜ) ε，其中 ε ~ N(0, I)。


import torch
import numpy as np

class NoiseScheduler:
    def __init__(self, n_steps=1000, beta_start=1e-4, beta_end=0.02, schedule='linear'):
        if schedule == 'linear':
            self.betas = torch.linspace(beta_start, beta_end, n_steps)
        elif schedule == 'cosine':
            steps = torch.arange(n_steps + 1, dtype=torch.float64) / n_steps
            alpha_bar = torch.cos((steps + 0.008) / 1.008 * np.pi / 2) ** 2
            alpha_bar = alpha_bar / alpha_bar[0]
            betas = 1 - alpha_bar[1:] / alpha_bar[:-1]
            self.betas = torch.clamp(betas, max=0.999).float()
        self.alphas = 1.0 - self.betas
        self.alpha_bars = torch.cumprod(self.alphas, dim=0)
        self.sqrt_alpha_bars = torch.sqrt(self.alpha_bars)
        self.sqrt_one_minus_alpha_bars = torch.sqrt(1.0 - self.alpha_bars)

    def add_noise(self, x0, t, noise=None):
        if noise is None:
            noise = torch.randn_like(x0)
        sqrt_ab = self.sqrt_alpha_bars[t].view(-1, 1, 1, 1)
        sqrt_omab = self.sqrt_one_minus_alpha_bars[t].view(-1, 1, 1, 1)
        return sqrt_ab * x0 + sqrt_omab * noise
噪声调度策略直接影响生成质量。原始 DDPM 使用线性调度 βₜ ∈ [0.0001, 0.02]，在 T=1000 步后信噪比接近零。Improved DDPM 提出余弦调度，使得信噪比在时间轴上更均匀地下降，避免了线性调度在末期噪声下降过快的问题。余弦调度在低分辨率图像生成上效果更好，而高分辨率任务通常需要更多的总步数和更精细的调度设计。


反向去噪与变分目标
反向过程的目标是学习 q(xₜ₋₁|xₜ) 的近似分布 pθ(xₜ₋₁|xₜ)。在贝叶斯框架下，当 βₜ 足够小时，反向转移核也近似为高斯分布。DDPM 将反向过程参数化为 pθ(xₜ₋₁|xₜ) = N(xₜ₋₁; μθ(xₜ, t), σₜ²I)，其中均值 μθ 由神经网络预测，方差 σₜ² 可以设为固定值或学习得到。


通过变分推断，DDPM 的训练目标（负 ELBO）可以分解为 T 个去噪匹配项的和。每一项要求 pθ(xₜ₋₁|xₜ) 逼近真实后验 q(xₜ₋₁|xₜ, x₀)。由于 q(xₜ₋₁|xₜ, x₀) 是可解析计算的高斯分布，训练目标可以进一步简化为预测添加的噪声：L_simple = E[‖ε - εθ(xₜ, t)‖²]。


import torch
import torch.nn.functional as F

def train_step(model, x0, scheduler, optimizer):
    batch_size = x0.shape[0]
    t = torch.randint(0, scheduler.n_steps, (batch_size,), device=x0.device)
    noise = torch.randn_like(x0)
    xt = scheduler.add_noise(x0, t, noise)
    noise_pred = model(xt, t)
    loss = F.mse_loss(noise_pred, noise)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss.item()

@torch.no_grad()
def sample(model, scheduler, shape, device):
    x = torch.randn(shape, device=device)
    for t in reversed(range(scheduler.n_steps)):
        t_batch = torch.full((shape[0],), t, device=device, dtype=torch.long)
        noise_pred = model(x, t_batch)
        alpha = scheduler.alphas[t]
        alpha_bar = scheduler.alpha_bars[t]
        beta = scheduler.betas[t]
        mean = (1 / alpha.sqrt()) * (x - (beta / (1 - alpha_bar).sqrt()) * noise_pred)
        if t > 0:
            sigma = beta.sqrt()
            x = mean + sigma * torch.randn_like(x)
        else:
            x = mean
    return x
噪声预测（ε-prediction）和数据预测（x₀-prediction）是两种等价但在实践中表现不同的参数化方式。ε-prediction 预测添加的噪声，在大多数时间步上表现良好；x₀-prediction 直接预测去噪后的数据，在低噪声时更稳定。v-prediction 是二者的线性组合：v = √ᾱₜ ε - √(1-ᾱₜ) x₀，在 Progressive Distillation 中被证明更利于蒸馏。


连续时间 SDE 框架
Song 等人提出的 Score SDE 框架将离散的扩散过程推广为连续时间的随机微分方程。前向过程由 SDE dx = f(x, t)dt + g(t)dw 描述，其中 f 是漂移系数，g 是扩散系数，w 是标准维纳过程。对应的反向过程也是 SDE：dx = [f(x, t) - g(t)² ∇ₓ log pₜ(x)]dt + g(t)dw̄。


这一框架的核心洞见是：反向 SDE 中唯一未知量是得分函数 ∇ₓ log pₜ(x)，可以通过训练得分网络来近似。不同的 f 和 g 选择对应不同的扩散模型：VE-SDE（Variance Exploding，对应 SMLD）使 f=0、g 递增；VP-SDE（Variance Preserving，对应 DDPM）使数据方差在整个过程中保持恒定。


import torch

class VPSDE:
    def __init__(self, beta_min=0.1, beta_max=20.0):
        self.beta_min = beta_min
        self.beta_max = beta_max

    def beta(self, t):
        return self.beta_min + t * (self.beta_max - self.beta_min)

    def marginal_params(self, t):
        log_mean_coeff = -0.25 * t ** 2 * (self.beta_max - self.beta_min) - 0.5 * t * self.beta_min
        mean_coeff = torch.exp(log_mean_coeff)
        std = torch.sqrt(1.0 - torch.exp(2.0 * log_mean_coeff))
        return mean_coeff, std

    def sde(self, x, t):
        beta_t = self.beta(t)
        drift = -0.5 * beta_t * x
        diffusion = torch.sqrt(beta_t)
        return drift, diffusion

    def reverse_sde(self, x, t, score):
        beta_t = self.beta(t)
        drift = -0.5 * beta_t * x - beta_t * score
        diffusion = torch.sqrt(beta_t)
        return drift, diffusion
连续 SDE 框架还引出了概率流 ODE（Probability Flow ODE）：dx = [f(x, t) - ½g(t)² ∇ₓ log pₜ(x)]dt。ODE 与 SDE 共享相同的边际分布 pₜ(x)，但采样过程是确定性的——给定相同的初始噪声，ODE 总是生成相同的图像。这一性质使得 ODE 采样更容易加速（使用自适应步长 ODE 求解器）并支持精确的似然计算。


去噪网络架构设计
扩散模型的去噪网络通常采用 U-Net 架构，它通过编码器-解码器结构加跳跃连接实现多尺度特征处理。时间步信息通过正弦位置编码转化为嵌入向量，然后通过 AdaGN（自适应组归一化）注入到每个残差块中。


U-Net 的编码路径逐步降低空间分辨率并增加通道数，捕获从细节到全局的多尺度特征。解码路径逐步恢复分辨率，跳跃连接保证精细信息不丢失。自注意力层通常只在低分辨率特征图（如 16×16 和 8×8）上使用，以平衡表达能力和计算成本。

DiT（Diffusion Transformer）用 Transformer 架构替代 U-Net，将图像分割为 patch 后作为 token 序列处理。DiT 在大规模训练中展现出更好的可扩展性，其性能随模型参数和训练计算量的增加而稳定提升，遵循类似 LLM 的 Scaling Law。Stable Diffusion 3 和 FLUX 已经采用了基于 Transformer 的架构。


小结
    

  • 扩散模型通过前向加噪和反向去噪的对偶过程实现生成，训练目标简化为噪声预测的均方误差
    • 

  • 噪声调度策略决定了信噪比的变化曲线，余弦调度比线性调度更均匀
    • 

  • 连续 SDE 框架统一了不同扩散模型的数学基础，概率流 ODE 提供了确定性采样路径
    • 

  • U-Net 是经典去噪架构，DiT 展示了 Transformer 在扩散模型中的可扩展性优势
    • 

  • ε-prediction、x₀-prediction 和 v-prediction 是三种等价但实践表现不同的参数化方式
