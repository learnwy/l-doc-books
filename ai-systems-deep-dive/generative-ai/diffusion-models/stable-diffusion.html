Stable Diffusion 架构解析

核心概念

Stable Diffusion 是由 Stability AI 发布的开源文本到图像生成模型，基于 Latent Diffusion Model（LDM）框架构建。其核心创新在于将扩散过程从高维像素空间迁移到低维隐空间，在保持生成质量的同时大幅降低计算成本。Stable Diffusion 由三个核心组件协作完成生成：VAE 负责图像与隐空间之间的编解码，U-Net 在隐空间中执行条件去噪，CLIP 文本编码器将自然语言提示转化为语义向量。

这种三阶段架构的设计哲学是"各司其职"：VAE 处理像素级细节的压缩与还原，U-Net 专注于语义级别的去噪生成，CLIP 桥接自然语言与视觉语义。三个组件可以独立训练和替换，这种模块化设计极大地促进了社区生态的繁荣。

VAE 编码器与解码器
Stable Diffusion 的 VAE 基于 KL-正则化的自编码器架构，将 512×512 的 RGB 图像编码为 64×64×4 的隐表示。空间维度压缩 8 倍，通道数从 3 增加到 4（编码后的隐通道数），总压缩比为 48 倍。这个压缩率经过精心设计：过大的压缩会丢失视觉细节，过小则无法充分降低计算成本。


编码器由一系列下采样残差块和自注意力层组成，逐步将空间分辨率从 512 降低到 64。解码器是编码器的镜像结构，通过上采样残差块将隐表示还原为像素图像。VAE 使用 KL 散度正则化，但正则化系数很小（KL weight = 1e-6），确保隐空间的连续性同时不过度牺牲重构质量。


from diffusers import AutoencoderKL
import torch

vae = AutoencoderKL.from_pretrained("stabilityai/sd-vae-ft-mse")

def encode_image(vae, image):
    with torch.no_grad():
        latent_dist = vae.encode(image).latent_dist
        latents = latent_dist.sample()
        latents = latents * vae.config.scaling_factor
    return latents

def decode_latents(vae, latents):
    with torch.no_grad():
        latents = latents / vae.config.scaling_factor
        image = vae.decode(latents).sample
    return image

image = torch.randn(1, 3, 512, 512)
latents = encode_image(vae, image)
print(f"Image: {image.shape} -> Latents: {latents.shape}")
reconstructed = decode_latents(vae, latents)
SDXL 的 VAE 进行了多项改进：更深的网络结构、更好的训练策略（使用 EMA 和更大的 batch size）以及更低的重构误差。SD 3.0 进一步将隐空间通道数增加到 16，提供更丰富的特征编码能力。VAE 的重构质量直接影响最终生成图像的清晰度和细节保真度，因此高质量 VAE 的训练是整个系统的基础。


U-Net 条件去噪网络
U-Net 是 Stable Diffusion 的核心组件，负责在隐空间中根据文本条件逐步去除噪声。它接收三个输入：带噪隐变量、时间步嵌入和文本条件嵌入，输出预测的噪声。U-Net 的编码器包含多个下采样阶段（分辨率从 64 到 8），每个阶段由残差块、自注意力块和交叉注意力块组成。


时间步通过正弦位置编码转化为嵌入向量，再经过两层 MLP 投影到各残差块的缩放和偏移参数。文本条件通过交叉注意力机制注入：图像特征作为 Query，文本嵌入作为 Key 和 Value。这种设计允许模型在不同空间位置关注不同的文本 token，实现精细的文图对齐。


from diffusers import UNet2DConditionModel
import torch

unet = UNet2DConditionModel.from_pretrained(
    "runwayml/stable-diffusion-v1-5", subfolder="unet"
)

latents = torch.randn(1, 4, 64, 64)
timestep = torch.tensor([500])
text_embeddings = torch.randn(1, 77, 768)

with torch.no_grad():
    noise_pred = unet(latents, timestep, encoder_hidden_states=text_embeddings).sample
print(f"Noise prediction: {noise_pred.shape}")
SDXL 的 U-Net 有两个主要改进：一是增大了模型容量（参数量从 860M 增至 2.6B），更多的注意力头和更深的 Transformer 块；二是引入了双文本编码器（OpenCLIP ViT-bigG + CLIP ViT-L），将两个编码器的输出拼接后作为条件。此外，SDXL 增加了尺寸和裁剪条件嵌入，缓解了训练数据中裁剪和缩放不一致的问题。


CLIP 文本编码器与文图对齐
CLIP 文本编码器将自然语言提示转化为连续的语义表示，是实现文本驱动生成的桥梁。Stable Diffusion 1.5 使用 CLIP ViT-L/14 的文本编码器，输出 77 个 token 位置的 768 维嵌入向量。每个 token 嵌入包含该词的语义信息及其在句子中的上下文关系。


文本编码的质量直接影响生成结果的语义准确性。CLIP 在大规模图文对上预训练的对比学习目标，使其能够将视觉概念和语言描述对齐到共享的语义空间。然而 CLIP 也有局限：它对数量词、空间关系和否定等抽象概念的理解较弱，这导致 Stable Diffusion 在处理 "two cats sitting on a red table" 这类组合语义时可能出错。


from transformers import CLIPTextModel, CLIPTokenizer
import torch

tokenizer = CLIPTokenizer.from_pretrained("openai/clip-vit-large-patch14")
text_encoder = CLIPTextModel.from_pretrained("openai/clip-vit-large-patch14")

def encode_prompt(prompt, tokenizer, text_encoder, max_length=77):
    tokens = tokenizer(
        prompt, padding="max_length", max_length=max_length,
        truncation=True, return_tensors="pt"
    )
    with torch.no_grad():
        text_embeddings = text_encoder(tokens.input_ids).last_hidden_state
    return text_embeddings

prompt_embed = encode_prompt("a photo of a cat", tokenizer, text_encoder)
uncond_embed = encode_prompt("", tokenizer, text_encoder)
print(f"Text embedding: {prompt_embed.shape}")
T5-XXL 是另一个重要的文本编码器选择。与 CLIP 的对比学习目标不同，T5 通过掩码语言模型任务训练，对复杂语法结构和长文本有更好的理解能力。Stable Diffusion 3 同时使用 CLIP 和 T5 编码器，通过拼接两种不同性质的文本表示来增强文图对齐。FLUX 模型则完全使用 T5-XXL 作为唯一文本编码器。


完整推理流程与采样策略
Stable Diffusion 的推理流程从随机高斯噪声开始，经过多步去噪迭代，最终由 VAE 解码为图像。标准流程使用 50 步 DDPM 采样，但实际应用中通常使用 20-30 步的加速调度器（如 DPM-Solver++、Euler 等）以平衡质量和速度。


Classifier-Free Guidance（CFG）是推理中的关键技术。每一步去噪时，模型分别在有条件和无条件下进行前向传播，然后将两次预测的差异按引导强度放大：ε = ε_uncond + w·(ε_cond - ε_uncond)。CFG 引导强度 w 通常设为 7.0-8.5，过低导致生成结果与文本不匹配，过高则产生过饱和和伪影。


from diffusers import StableDiffusionPipeline
import torch

pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", torch_dtype=torch.float16
).to("cuda")

image = pipe(
    prompt="a serene lake surrounded by mountains at sunset",
    negative_prompt="blurry, low quality, distorted",
    num_inference_steps=30,
    guidance_scale=7.5,
    width=512, height=512,
    generator=torch.Generator("cuda").manual_seed(42),
).images[0]
负面提示（Negative Prompt）替代空文本作为无条件输入，用于主动排除不期望的视觉元素。负面提示的原理是将无条件噪声预测偏向排除特定语义方向，从而引导生成远离低质量或不期望的属性。在社区实践中，精心设计的负面提示对最终质量的影响与正面提示同等重要。

小结
    

  • Stable Diffusion 通过 VAE-U-Net-CLIP 三组件架构在隐空间中实现高效的文本到图像生成
    • 

  • VAE 将 512×512 图像压缩为 64×64×4 隐表示，压缩比和重构质量的平衡是关键设计决策
    • 

  • U-Net 通过交叉注意力融合文本条件，时间步嵌入控制去噪强度
    • 

  • CLIP 文本编码器提供语义桥梁，但对组合语义的理解存在局限
    • 

  • CFG 引导强度是推理中最重要的超参数，需要在文图对齐与多样性之间权衡
    • 

  • 模块化架构设计使得各组件可以独立优化和替换，推动了社区生态的快速发展
    •
