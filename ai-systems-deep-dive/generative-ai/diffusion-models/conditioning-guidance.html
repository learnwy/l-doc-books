Part III · 生成式与多模态 (Generative & Multimodal)生成式 AI 简介扩散模型 简介条件引导机制

条件引导机制

核心概念

条件引导（Conditioning and Guidance）是扩散模型实现可控生成的核心技术。无条件扩散模型只能从数据分布中随机采样，而条件引导允许用户通过文本、图像、类别标签等信号精确控制生成结果。从数学角度，条件生成等价于从后验分布 p(x|c) 采样，其中 c 是条件信号。引导机制通过修改去噪过程的梯度方向，将无条件生成引导到满足条件约束的区域。

两种主流引导方法——Classifier Guidance 和 Classifier-Free Guidance——代表了不同的设计哲学。前者在推理时引入外部分类器的梯度信号，后者在训练时即内化了条件与无条件的关系，推理时仅需调整权重系数。

Classifier Guidance 原理
Classifier Guidance 由 Dhariwal 和 Nichol 在 2021 年提出。其核心思想是利用贝叶斯定理将条件分布分解为无条件分布和分类器的似然：∇ₓ log p(x|y) = ∇ₓ log p(x) + ∇ₓ log p(y|x)。在扩散模型中，这意味着条件生成的得分函数等于无条件得分函数加上分类器梯度。


实现中，需要训练一个在噪声数据上工作的分类器 p_φ(y|xₜ, t)。在每一步去噪时，除了用扩散模型预测噪声外，还需要计算分类器对当前噪声数据的梯度，并将其按引导强度 s 缩放后叠加到去噪方向上。


import torch
import torch.nn.functional as F

class NoisyClassifier(torch.nn.Module):
    def __init__(self, n_classes=1000, channels=256):
        super().__init__()
        self.net = torch.nn.Sequential(
            torch.nn.Conv2d(4, channels, 3, padding=1),
            torch.nn.SiLU(),
            torch.nn.AdaptiveAvgPool2d(1),
            torch.nn.Flatten(),
            torch.nn.Linear(channels, n_classes),
        )
        self.time_embed = torch.nn.Embedding(1000, channels)

    def forward(self, x, t):
        return self.net(x)

def classifier_guided_step(model, classifier, x, t, y, guidance_scale=3.0):
    with torch.no_grad():
        noise_pred = model(x, t)
    x_in = x.detach().requires_grad_(True)
    logits = classifier(x_in, t)
    log_prob = F.log_softmax(logits, dim=-1)
    selected = log_prob[range(len(y)), y]
    grad = torch.autograd.grad(selected.sum(), x_in)[0]
    noise_pred = noise_pred - guidance_scale * grad * (1 - scheduler.alpha_bars[t]).sqrt().view(-1, 1, 1, 1)
    return noise_pred
Classifier Guidance 的优势在于可以使用已有分类器进行引导，不需要重新训练扩散模型。但其局限也很明显：分类器必须在噪声数据上训练，需要额外的模型和计算成本；且只能基于分类标签进行引导，难以支持自由文本等复杂条件。


Classifier-Free Guidance 机制
Classifier-Free Guidance（CFG）消除了对外部分类器的依赖，将条件引导内化到扩散模型本身。训练时，以概率 p_uncond（通常 10%-20%）随机丢弃条件信号（将文本替换为空字符串），使得同一个模型同时学习条件和无条件生成。推理时，条件引导通过外推实现。


CFG 的数学形式为：ε̃ = εθ(xₜ, ∅) + w · (εθ(xₜ, c) - ε_θ(xₜ, ∅))，其中 ∅ 表示空条件，c 是文本条件，w 是引导强度。当 w=1 时等价于标准条件生成；w>1 时放大条件信号，生成更符合文本但多样性降低的结果；w<1 时弱化条件约束；w=0 时退化为无条件生成。


import torch

def classifier_free_guidance_step(model, x, t, text_embed, uncond_embed, guidance_scale=7.5):
    x_input = torch.cat([x, x])
    t_input = torch.cat([t, t])
    embed_input = torch.cat([uncond_embed, text_embed])
    noise_pred = model(x_input, t_input, encoder_hidden_states=embed_input)
    noise_pred_uncond, noise_pred_cond = noise_pred.chunk(2)
    guided = noise_pred_uncond + guidance_scale * (noise_pred_cond - noise_pred_uncond)
    return guided

def dynamic_cfg(noise_pred_cond, noise_pred_uncond, t, total_steps, min_scale=1.0, max_scale=7.5):
    progress = t / total_steps
    scale = min_scale + (max_scale - min_scale) * progress
    return noise_pred_uncond + scale * (noise_pred_cond - noise_pred_uncond)
CFG 引导强度的选择需要在保真度（fidelity）和多样性（diversity）之间权衡。较高的引导强度产生更清晰、更符合文本的图像，但会降低多样性并可能引入色彩过饱和。动态 CFG 在不同去噪阶段使用不同的引导强度——早期高引导确定全局语义，后期低引导保留细节多样性——是一种有效的改进策略。


多条件组合与 Compositional Generation
真实应用中往往需要同时满足多个条件约束：既要匹配文本描述，又要保持特定风格，还可能需要遵循空间布局。组合式条件生成（Compositional Generation）通过在得分函数空间中进行算术运算来实现多条件组合。


基本原理是：如果两个条件 c₁ 和 c₂ 相互独立，则联合条件的得分可以分解为两个独立条件得分的和：∇ log p(x|c₁, c₂) ≈ ∇ log p(x|c₁) + ∇ log p(x|c₂) - ∇ log p(x)。这意味着可以分别训练针对不同条件的模型，在推理时通过得分叠加实现组合生成。


import torch

def compose_conditions(model, x, t, conditions, weights, uncond_embed):
    noise_uncond = model(x, t, encoder_hidden_states=uncond_embed)
    guided = noise_uncond.clone()
    for cond_embed, weight in zip(conditions, weights):
        noise_cond = model(x, t, encoder_hidden_states=cond_embed)
        guided += weight * (noise_cond - noise_uncond)
    return guided

def attend_and_excite(attn_maps, token_indices, threshold=0.2):
    losses = []
    for idx in token_indices:
        attn = attn_maps[:, :, idx]
        max_attn = attn.max(dim=-1).values
        loss = torch.clamp(threshold - max_attn, min=0).mean()
        losses.append(loss)
    return sum(losses)
Attend-and-Excite 通过在去噪过程中优化交叉注意力图来确保每个文本概念都在图像中得到体现。它计算每个名词对应的注意力图的最大值，如果低于阈值则通过梯度更新增强对应区域的注意力。这种方法有效缓解了"属性泄漏"和"概念缺失"等组合语义错误。

负面提示与引导强度调优
负面提示（Negative Prompt）是 CFG 框架的自然延伸。标准 CFG 使用空文本 ∅ 作为无条件输入，而负面提示用具体的负面描述替代空文本，主动排斥不期望的视觉属性。从数学角度，负面提示将无条件预测偏向排斥方向：ε̃ = ε_neg + w · (ε_cond - ε_neg)，其中 ε_neg 编码了"不要什么"的语义。


常用的负面提示策略包括质量相关（"blurry, low quality, worst quality"）、内容相关（"text, watermark, signature"）和风格相关（"cartoon, painting" 用于写实场景）。社区实践中发现，系统性的负面提示模板对生成质量的提升效果显著，其影响力不亚于精心设计的正面提示。


引导强度的最佳值取决于多个因素：模型版本（SD1.5 通常 7-8，SDXL 通常 5-7）、内容类型（写实照片 5-7，艺术风格 8-12）和提示复杂度（简单提示可用较高值，复杂提示需要较低值以避免过拟合特定词汇）。在实践中，先以默认值生成，再根据结果微调是最高效的策略。


小结
    

  • Classifier Guidance 利用外部分类器梯度引导生成，灵活但需要额外训练噪声分类器
    • 

  • Classifier-Free Guidance 通过训练时随机丢弃条件实现内化引导，是当前主流方法
    • 

  • CFG 引导强度是生成质量与多样性之间的核心权衡参数，需根据场景调优
    • 

  • 组合式条件生成通过得分空间算术实现多条件协调，Attend-and-Excite 等方法改善语义一致性
    • 

  • 负面提示是正面提示的重要补充，系统性的负面提示模板显著提升生成质量
    • 

  • 动态引导强度在不同去噪阶段使用不同值，兼顾全局语义和局部细节
