扩散模型加速

核心概念

扩散模型的推理速度是其最主要的工程瓶颈。标准 DDPM 需要 1000 步采样才能生成一张图像，即使在 GPU 上也需要数十秒。这与 GAN 的单步生成形成鲜明对比。扩散模型加速研究的目标是在尽可能少的采样步数下保持生成质量，核心方法包括高效 ODE/SDE 求解器、知识蒸馏和一步生成模型三大方向。

加速方法的选择取决于质量-速度权衡需求。高效求解器将步数从 1000 降至 20-50 步，适合大多数应用；蒸馏方法进一步压缩到 4-8 步，适合对延迟敏感的场景；一致性模型实现 1-2 步生成，适合实时交互应用。

DDIM 与确定性采样
DDIM（Denoising Diffusion Implicit Models）是扩散模型加速的开创性工作。它将 DDPM 的马尔可夫采样过程推广为非马尔可夫过程，在保持相同训练目标的前提下，允许使用更大的步长进行采样。DDIM 的关键洞见是：前向过程不一定需要是马尔可夫的，只要边际分布 q(xₜ|x₀) 保持不变，就可以设计不同的采样路径。


DDIM 的采样公式为：xₜ₋₁ = √ᾱₜ₋₁ · x̂₀(xₜ) + √(1-ᾱₜ₋₁-σₜ²) · ε_θ(xₜ, t) + σₜεₜ。当 σₜ=0 时，采样过程完全确定性，给定初始噪声总是生成相同的图像。这一性质使得 DDIM 支持在隐空间中进行有意义的插值和编辑。


import torch

class DDIMSampler:
    def __init__(self, model, scheduler, n_steps=50):
        self.model = model
        self.scheduler = scheduler
        total_steps = len(scheduler.alpha_bars)
        self.timesteps = torch.linspace(total_steps - 1, 0, n_steps + 1).long()

    @torch.no_grad()
    def sample(self, shape, device, eta=0.0):
        x = torch.randn(shape, device=device)
        for i in range(len(self.timesteps) - 1):
            t = self.timesteps[i]
            t_prev = self.timesteps[i + 1]
            t_batch = torch.full((shape[0],), t, device=device, dtype=torch.long)
            noise_pred = self.model(x, t_batch)
            ab_t = self.scheduler.alpha_bars[t]
            ab_prev = self.scheduler.alpha_bars[t_prev] if t_prev >= 0 else torch.tensor(1.0)
            x0_pred = (x - (1 - ab_t).sqrt() * noise_pred) / ab_t.sqrt()
            sigma = eta * ((1 - ab_prev) / (1 - ab_t) * (1 - ab_t / ab_prev)).sqrt()
            dir_xt = (1 - ab_prev - sigma ** 2).sqrt() * noise_pred
            x = ab_prev.sqrt() * x0_pred + dir_xt
            if sigma > 0:
                x += sigma * torch.randn_like(x)
        return x
DDIM 的 eta 参数控制采样的随机性：eta=0 为完全确定性（ODE），eta=1 退化为 DDPM。中间值提供了确定性和随机性之间的连续谱。实践中，确定性采样（eta=0）在少步数下通常质量更好，因为随机噪声在步数不足时无法被有效消除。


DPM-Solver 与高阶数值方法
DPM-Solver 将扩散采样重新表述为求解常微分方程，并应用高阶数值方法来提高收敛速度。核心观察是：DDIM 等价于一阶 ODE 求解器（欧拉法），而通过使用多步方法或高阶泰勒展开，可以在更少步数内达到更高精度。


DPM-Solver 利用了扩散 ODE 的特殊结构——解的半线性形式——设计了一族专用求解器。一阶 DPM-Solver 等价于 DDIM，二阶和三阶版本通过多步预测修正（predictor-corrector）策略显著提高了精度。DPM-Solver++ 进一步在数据预测（x₀-prediction）空间中操作，对大引导强度更加稳定。


from diffusers import DPMSolverMultistepScheduler, StableDiffusionPipeline
import torch

pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", torch_dtype=torch.float16
).to("cuda")

pipe.scheduler = DPMSolverMultistepScheduler.from_config(
    pipe.scheduler.config,
    algorithm_type="dpmsolver++",
    solver_order=2,
    use_karras_sigmas=True,
)

image = pipe(
    "a beautiful landscape painting",
    num_inference_steps=20,
    guidance_scale=7.5,
).images[0]
Karras 噪声调度（也称 σ 调度）是另一个重要的加速技巧。它根据信噪比的变化规律重新分配采样时间点，使得在信噪比变化较快的区域分配更多采样步骤，而在变化平缓的区域减少步骤。这种自适应调度在 10-25 步范围内显著优于均匀调度。


渐进蒸馏与知识迁移
渐进蒸馏（Progressive Distillation）通过将教师模型的两步采样压缩为学生模型的一步采样，迭代地将步数减半。第一轮蒸馏将 1024 步教师压缩为 512 步学生，第二轮将 512 步压缩为 256 步，以此类推。经过 10 轮迭代，最终得到只需 1 步的学生模型。


import torch
import torch.nn.functional as F

def progressive_distillation_step(teacher, student, x0, scheduler, optimizer):
    batch_size = x0.shape[0]
    t = torch.randint(0, scheduler.n_steps // 2, (batch_size,), device=x0.device)
    t_teacher_start = t * 2
    t_teacher_mid = t * 2 + 1
    noise = torch.randn_like(x0)
    x_start = scheduler.add_noise(x0, t_teacher_start, noise)
    with torch.no_grad():
        noise_pred_1 = teacher(x_start, t_teacher_start)
        x_mid = scheduler.step(x_start, t_teacher_start, noise_pred_1)
        noise_pred_2 = teacher(x_mid, t_teacher_mid)
        x_target = scheduler.step(x_mid, t_teacher_mid, noise_pred_2)
    noise_pred_student = student(x_start, t)
    x_student = scheduler.step_student(x_start, t, noise_pred_student)
    loss = F.mse_loss(x_student, x_target)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss.item()
Guided Distillation 解决了 CFG 在蒸馏中的问题。标准 CFG 需要双重前向传播，这在蒸馏后的少步模型中成本尤其高。通过在蒸馏阶段将 CFG 的效果烘培到学生模型中，推理时只需单次前向传播。SDXL Turbo 和 SD Turbo 使用了对抗蒸馏（Adversarial Distillation），结合对抗损失和得分蒸馏损失，在 1-4 步内实现接近完整模型的质量。

一致性模型与单步生成
一致性模型（Consistency Models）由 Song 等人在 2023 年提出，基于一个关键约束：概率流 ODE 轨迹上的所有点应该映射到相同的起点（x₀）。这意味着模型 f_θ(xₜ, t) 对于同一条 ODE 轨迹上的任意 t 值都应该输出相同的结果。这个一致性约束允许模型在单步内直接预测 x₀，而不需要迭代去噪。


Latent Consistency Model（LCM）将一致性模型应用于隐空间扩散，结合了隐空间的计算效率和一致性模型的单步生成能力。LCM 从预训练的 Stable Diffusion 模型通过一致性蒸馏得到，训练成本远低于从头训练。LCM-LoRA 进一步将一致性蒸馏与 LoRA 微调结合，只需几十 MB 的适配器即可将任意 SD 模型转化为 2-4 步模型。


from diffusers import DiffusionPipeline
import torch

pipe = DiffusionPipeline.from_pretrained(
    "SimianLuo/LCM_Dreamshaper_v7", torch_dtype=torch.float16
).to("cuda")

image = pipe(
    prompt="a beautiful sunset over the ocean",
    num_inference_steps=4,
    guidance_scale=1.0,
).images[0]

from diffusers import LCMScheduler

base_pipe = DiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", torch_dtype=torch.float16
).to("cuda")
base_pipe.scheduler = LCMScheduler.from_config(base_pipe.scheduler.config)
base_pipe.load_lora_weights("latent-consistency/lcm-lora-sdv1-5")

image = base_pipe(
    "a photo of a mountain landscape",
    num_inference_steps=4,
    guidance_scale=1.5,
).images[0]
一致性模型在实时应用中有巨大潜力：1-2 步生成使得交互式图像编辑、实时预览和流式视频生成成为可能。然而，极少步数下的生成质量仍然不及完整采样，尤其在细节丰富度和多样性方面。实践中，4 步 LCM 是质量与速度的最佳平衡点。


小结
    

  • DDIM 通过非马尔可夫过程实现确定性采样，是扩散加速的基础方法
    • 

  • DPM-Solver 利用高阶数值方法将采样步数降至 10-25 步，配合 Karras 调度效果更佳
    • 

  • 渐进蒸馏通过迭代步数减半实现 4-8 步生成，对抗蒸馏进一步压缩至 1-4 步
    • 

  • 一致性模型通过 ODE 轨迹一致性约束实现单步生成，LCM 将其应用于隐空间扩散
    • 

  • LCM-LoRA 以极低成本将任意 SD 模型转化为少步模型，是当前最实用的加速方案
    • 

  • 加速方法的选择需根据应用场景在质量、速度和训练成本之间权衡
