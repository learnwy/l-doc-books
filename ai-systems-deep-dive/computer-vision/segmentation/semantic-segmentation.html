语义分割

核心概念

语义分割为图像中的每个像素分配一个类别标签，实现像素级的场景理解。与目标检测输出边界框不同，语义分割输出与输入图像同尺寸的标签图，精确勾勒出每个类别的空间范围。语义分割不区分同类别的不同实例——同类别的所有像素共享相同标签。

语义分割的核心架构是编码器-解码器结构。编码器逐步降低空间分辨率同时增加语义信息，解码器将低分辨率的语义特征恢复到原始分辨率。跳跃连接将编码器的高分辨率细节信息直接传递给解码器，帮助恢复精细的空间边界。

FCN 与全卷积架构
全卷积网络（FCN）是深度学习语义分割的开山之作。它将分类网络的全连接层替换为卷积层，使网络可以接受任意尺寸的输入并输出对应的空间预测图。FCN 通过反卷积（转置卷积）将低分辨率特征图上采样到原始尺寸，并引入跳跃连接融合不同层级的信息。


import torch
import torch.nn as nn
from torchvision.models import resnet50

class SimpleFCN(nn.Module):
    def __init__(self, num_classes):
        super().__init__()
        backbone = resnet50(weights='IMAGENET1K_V2')
        self.encoder = nn.Sequential(*list(backbone.children())[:-2])
        self.classifier = nn.Conv2d(2048, num_classes, 1)
        self.upsample = nn.Upsample(scale_factor=32, mode='bilinear', align_corners=False)

    def forward(self, x):
        features = self.encoder(x)
        logits = self.classifier(features)
        return self.upsample(logits)

model = SimpleFCN(num_classes=21)
dummy = torch.randn(1, 3, 512, 512)
output = model(dummy)
print(f"输入: {dummy.shape}, 输出: {output.shape}")
U-Net 是 FCN 思想在医学影像领域的经典实现。它的对称编码器-解码器结构和密集的跳跃连接使其在小数据集上也能取得出色效果。U-Net 的成功证明了跳跃连接对于恢复空间细节的重要性，这一设计被后续几乎所有分割架构采用。


DeepLab 与空洞卷积
DeepLab 系列是语义分割领域最具影响力的工作之一。其核心技术是空洞卷积（Atrous/Dilated Convolution），通过在卷积核中插入间隔（空洞）来增大感受野而不增加参数量和计算量。这使得网络在保持高分辨率特征图的同时获得大范围的上下文信息。


ASPP（Atrous Spatial Pyramid Pooling）在 DeepLabV3 中被提出，它使用多个不同空洞率的并行空洞卷积来捕获多尺度上下文信息。ASPP 通常包含 1×1 卷积、三个不同空洞率（6、12、18）的 3×3 空洞卷积和全局平均池化分支，最后将五个分支的特征拼接融合。


import torch
import torch.nn as nn

class ASPP(nn.Module):
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.conv1 = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, 1),
            nn.BatchNorm2d(out_channels), nn.ReLU())
        self.conv6 = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, 3, padding=6, dilation=6),
            nn.BatchNorm2d(out_channels), nn.ReLU())
        self.conv12 = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, 3, padding=12, dilation=12),
            nn.BatchNorm2d(out_channels), nn.ReLU())
        self.conv18 = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, 3, padding=18, dilation=18),
            nn.BatchNorm2d(out_channels), nn.ReLU())
        self.pool = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Conv2d(in_channels, out_channels, 1),
            nn.BatchNorm2d(out_channels), nn.ReLU())
        self.project = nn.Sequential(
            nn.Conv2d(out_channels * 5, out_channels, 1),
            nn.BatchNorm2d(out_channels), nn.ReLU())

    def forward(self, x):
        size = x.shape[2:]
        pool = nn.functional.interpolate(self.pool(x), size=size, mode='bilinear', align_corners=False)
        out = torch.cat([self.conv1(x), self.conv6(x), self.conv12(x), self.conv18(x), pool], dim=1)
        return self.project(out)
DeepLabV3+ 在 DeepLabV3 的基础上添加了简单而有效的解码器模块。编码器输出经过 ASPP 后与编码器浅层的特征通过跳跃连接融合，恢复物体边界的精细细节。这一改进使 DeepLabV3+ 在 Cityscapes 等基准上达到了当时的最佳水平。


SegFormer 与 Transformer 分割
SegFormer 将 Transformer 引入语义分割，提出了层级化的 Mix Transformer（MiT）编码器和极其轻量的全 MLP 解码器。MiT 编码器在四个阶段逐步降低分辨率，每个阶段使用高效的自注意力（Efficient Self-Attention）减少计算量。


SegFormer 的解码器设计极其简洁：将四个阶段的特征图统一上采样到 1/4 分辨率后拼接，通过 MLP 融合并输出分割结果。这种设计几乎不增加额外计算量，同时充分利用了多尺度特征。


from transformers import SegformerForSemanticSegmentation, SegformerImageProcessor
import torch

processor = SegformerImageProcessor.from_pretrained("nvidia/segformer-b0-finetuned-cityscapes-1024-1024")
model = SegformerForSemanticSegmentation.from_pretrained("nvidia/segformer-b0-finetuned-cityscapes-1024-1024")
model.eval()

dummy = torch.randn(1, 3, 1024, 1024)
with torch.no_grad():
    outputs = model(pixel_values=dummy)
    logits = outputs.logits
    print(f"SegFormer 输出: {logits.shape}")
Segment Anything Model（SAM）开创了通用分割的新范式。SAM 在超过 10 亿个掩码的 SA-1B 数据集上训练，能够通过点、框或文本提示分割任意物体。SAM 的设计包含重量级图像编码器（ViT-H）和轻量级掩码解码器，图像特征只需计算一次即可响应多次提示。

小结
    

  • FCN 开创了端到端语义分割，全卷积设计使网络可以处理任意尺寸输入
    • 

  • U-Net 的对称结构和跳跃连接在小数据集上尤其有效，是医学影像分割的首选
    • 

  • 空洞卷积在不降低分辨率的情况下增大感受野，ASPP 捕获多尺度上下文
    • 

  • SegFormer 以极轻量的 MLP 解码器达到了出色的精度-效率权衡
    • 

  • SAM 实现了通用的提示式分割，开创了视觉基础模型的新方向
    • 

  • 实际项目中根据数据量和任务需求选择：小数据用 U-Net，大数据用 SegFormer 或 Mask2Former
