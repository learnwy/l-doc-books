视频分割

核心概念

视频分割将图像分割扩展到时间维度，要求模型在视频的连续帧之间保持分割结果的时序一致性。视频分割不仅需要精确的空间分割能力，还需要跨帧追踪和关联实例的能力，使得同一物体在不同帧中保持一致的标识。

视频分割面临的核心挑战包括：物体外观变化（光照、姿态、遮挡）、目标遮挡和重现、快速运动导致的模糊、场景中新物体的出现和消失。这些问题使得简单地逐帧应用图像分割模型效果不佳——帧间的不一致性会导致闪烁和跳变。

半监督视频目标分割
半监督视频目标分割（Semi-supervised VOS）在第一帧提供目标的掩码标注，模型需要在后续所有帧中持续追踪和分割这些目标。这是视频分割中研究最成熟、应用最广泛的子任务。


基于记忆的方法是当前最主流的 VOS 范式。STM（Space-Time Memory Networks）构建了一个记忆库，将已处理帧的特征和掩码存入记忆，查询帧通过与记忆的注意力匹配来获取分割信息。XMem 在 STM 基础上引入了多层级记忆架构（工作记忆、长期记忆、感觉记忆），有效处理长视频中的记忆管理问题。


import torch
import torch.nn as nn

class MemoryBank:
    def __init__(self, max_size=50):
        self.max_size = max_size
        self.keys = []
        self.values = []

    def add(self, key, value):
        self.keys.append(key)
        self.values.append(value)
        if len(self.keys) > self.max_size:
            self.keys.pop(1)
            self.values.pop(1)

    def read(self, query):
        if not self.keys:
            return None
        keys = torch.cat(self.keys, dim=2)
        values = torch.cat(self.values, dim=2)
        affinity = torch.bmm(query.transpose(1, 2), keys)
        affinity = torch.softmax(affinity, dim=2)
        return torch.bmm(values, affinity.transpose(1, 2))
Cutie 是当前 VOS 领域的前沿方法，它引入了目标级别的记忆表示，为每个追踪目标维护独立的记忆 token。这种设计使得模型能够更好地处理多目标场景中的遮挡和交互问题。


SAM 2 与交互式视频分割
SAM 2（Segment Anything Model 2）将 SAM 的交互式分割能力从图像扩展到视频。用户可以在视频的任意帧上通过点击、框选或文本提示标注目标，SAM 2 自动将分割结果传播到整个视频序列。


SAM 2 的架构包含三个核心组件：图像编码器（Hiera，一种层级化的 ViT）、记忆模块（记忆编码器 + 记忆注意力 + 记忆库）和掩码解码器。图像编码器生成每帧的视觉特征，记忆模块维护时序上下文信息，掩码解码器结合当前帧特征和记忆信息生成分割掩码。


from sam2.build_sam import build_sam2_video_predictor
import torch

predictor = build_sam2_video_predictor("sam2_hiera_large.yaml", "sam2_hiera_large.pt")

with torch.inference_mode():
    state = predictor.init_state(video_path="video.mp4")

    predictor.add_new_points_or_box(
        inference_state=state,
        frame_idx=0,
        obj_id=1,
        points=[[200, 300]],
        labels=[1],
    )

    for frame_idx, obj_ids, masks in predictor.propagate_in_video(state):
        for obj_id, mask in zip(obj_ids, masks):
            print(f"帧 {frame_idx}, 目标 {obj_id}: {mask.shape}")
SAM 2 的记忆注意力机制使得当前帧的特征能够同时关注近期帧（短期记忆）和关键帧（长期记忆）的信息。当用户在后续帧上提供修正提示时，模型可以双向传播修正结果，提升整个视频的分割质量。

视频实例分割
视频实例分割（Video Instance Segmentation, VIS）要求模型在整个视频中检测、分割和追踪所有实例。与半监督 VOS 不同，VIS 不需要首帧标注，模型需要自动发现和追踪所有感兴趣的实例。


在线方法（如 MinVIS）逐帧运行实例分割，然后通过关联算法将帧间的实例匹配起来。关联策略通常基于实例嵌入的相似度、空间位置的一致性和掩码的 IoU。离线方法（如 VITA）将整个视频作为输入，通过时序注意力直接建模跨帧关系。


import torch
import torch.nn as nn

class TrackAssociation:
    def __init__(self, threshold=0.5):
        self.threshold = threshold
        self.tracks = {}
        self.next_id = 0

    def update(self, embeddings, masks, scores):
        if not self.tracks:
            for i in range(len(embeddings)):
                self.tracks[self.next_id] = {
                    'embedding': embeddings[i],
                    'mask': masks[i],
                }
                self.next_id += 1
            return list(range(self.next_id))

        track_embs = torch.stack([t['embedding'] for t in self.tracks.values()])
        similarity = torch.mm(embeddings, track_embs.T)

        assignments = []
        for i in range(len(embeddings)):
            max_sim, max_idx = similarity[i].max(0)
            track_id = list(self.tracks.keys())[max_idx]
            if max_sim > self.threshold:
                assignments.append(track_id)
                self.tracks[track_id]['embedding'] = embeddings[i]
            else:
                assignments.append(self.next_id)
                self.tracks[self.next_id] = {'embedding': embeddings[i], 'mask': masks[i]}
                self.next_id += 1
        return assignments
GenVIS 将视频实例分割建模为生成式序列预测问题，使用自回归的方式逐步生成每帧的实例掩码，自然地建立了跨帧的时序关联。DVIS 提出了将追踪和分割解耦的思路，先进行帧级分割再进行序列级关联，在长视频场景中表现出色。


小结
    

  • 视频分割的核心挑战是保持跨帧的时序一致性
    • 

  • 基于记忆的方法是半监督 VOS 的主流范式，XMem 有效处理长视频记忆管理
    • 

  • SAM 2 将交互式分割扩展到视频，支持多帧提示和双向传播
    • 

  • 视频实例分割需要同时解决检测、分割和追踪三个子问题
    • 

  • 在线方法（逐帧+关联）在实时场景中更实用，离线方法精度更高
    • 

  • SAM 2 是当前最通用的视频分割解决方案，支持零样本交互式分割
