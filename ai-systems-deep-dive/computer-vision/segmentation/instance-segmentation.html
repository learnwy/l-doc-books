实例分割

核心概念

实例分割在语义分割的基础上进一步区分同类别的不同实例。它为每个独立的物体实例生成一个精确的像素级掩码，同时输出该实例的类别标签和置信度。实例分割结合了目标检测（实例定位）和语义分割（像素分类）的能力，是场景理解中最具挑战性的任务之一。

实例分割有两条主要技术路线。自上而下方法先通过目标检测器定位每个实例的边界框，再在每个框内进行二值分割。自下而上方法先对每个像素预测嵌入向量，然后通过聚类将属于同一实例的像素分组。

Mask R-CNN 架构
Mask R-CNN 是实例分割的奠基性工作，在 Faster R-CNN 的基础上添加了一个并行的掩码预测分支。对于每个检测到的实例，掩码分支在 RoI Align 提取的特征上预测一个固定大小（通常 28×28）的二值掩码。掩码分支独立于分类和回归分支，使用二值交叉熵损失训练。


import torch
import torchvision
from torchvision.models.detection import maskrcnn_resnet50_fpn_v2
from torchvision.models.detection import MaskRCNN_ResNet50_FPN_V2_Weights

model = maskrcnn_resnet50_fpn_v2(weights=MaskRCNN_ResNet50_FPN_V2_Weights.COCO_V1)
model.eval()

dummy = torch.randn(3, 800, 600)
with torch.no_grad():
    predictions = model([dummy])
    masks = predictions[0]['masks']
    labels = predictions[0]['labels']
    scores = predictions[0]['scores']
    print(f"检测到 {len(masks)} 个实例")
    print(f"掩码形状: {masks[0].shape}")
Mask R-CNN 的关键设计决策是掩码分支对每个类别独立预测掩码（K 个类别生成 K 个掩码），而不是所有类别共享一个掩码。这种类别无关的掩码预测解耦了分类和分割任务，显著提升了性能。RoI Align 的精确空间对齐对掩码质量至关重要——使用 RoI Pooling 会导致掩码边缘出现明显的量化伪影。


PointRend 将实例分割的掩码精修建模为渲染问题。它不是对整个掩码区域均匀预测，而是在不确定的边界区域自适应地采样更多点进行精细预测。这种策略使得掩码在物体边缘处更加精确，同时减少了不必要的计算。


YOLACT 与实时实例分割
YOLACT（You Only Look At CoefficienTs）开创了实时实例分割。它的核心思想是将掩码生成分解为两个并行任务：全局的原型掩码生成和逐实例的系数预测。最终掩码通过原型掩码的线性组合得到。


import torch
import torch.nn as nn

class YOLACTHead(nn.Module):
    def __init__(self, in_channels, num_protos=32, num_classes=80):
        super().__init__()
        self.proto_net = nn.Sequential(
            nn.Conv2d(in_channels, 256, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(256, 256, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(256, num_protos, 1),
        )
        self.coeff_head = nn.Conv2d(in_channels, num_protos, 1)
        self.class_head = nn.Conv2d(in_channels, num_classes, 1)
        self.box_head = nn.Conv2d(in_channels, 4, 1)

    def forward(self, feature):
        protos = torch.sigmoid(self.proto_net(feature))
        coeffs = torch.tanh(self.coeff_head(feature))
        classes = self.class_head(feature)
        boxes = self.box_head(feature)
        return protos, coeffs, classes, boxes
YOLACT 的速度优势来自于原型掩码是全局共享的，不需要像 Mask R-CNN 那样对每个实例单独进行 RoI 操作。SOLOv2 采用了另一种思路：将实例分割转化为位置感知的语义分割，通过动态卷积核为每个网格位置生成掩码。CondInst 使用条件卷积（动态生成的卷积核）进一步提升了掩码质量。


Mask2Former 统一框架
Mask2Former 提出了统一的掩码分类框架，将语义分割、实例分割和全景分割统一为相同的架构。它使用一组可学习的 queries 通过掩码注意力（Masked Attention）与图像特征交互，每个 query 预测一个掩码和对应的类别。


Mask2Former 的核心创新是掩码注意力：在交叉注意力中，每个 query 只关注其预测掩码覆盖的图像区域，而不是全局注意力。这使得 queries 能够聚焦于各自负责的实例区域，提升了分割精度并加速了收敛。


from transformers import Mask2FormerForUniversalSegmentation, Mask2FormerImageProcessor
import torch

processor = Mask2FormerImageProcessor.from_pretrained("facebook/mask2former-swin-base-coco-instance")
model = Mask2FormerForUniversalSegmentation.from_pretrained("facebook/mask2former-swin-base-coco-instance")
model.eval()

dummy = torch.randn(1, 3, 800, 800)
with torch.no_grad():
    outputs = model(pixel_values=dummy)
    print(f"掩码: {outputs.masks_queries_logits.shape}")
    print(f"类别: {outputs.class_queries_logits.shape}")

小结
    

  • 实例分割结合了检测和分割能力，为每个物体实例生成精确的像素级掩码
    • 

  • Mask R-CNN 通过在 Faster R-CNN 上添加掩码分支建立了实例分割的标准框架
    • 

  • RoI Align 对掩码质量至关重要，避免了 RoI Pooling 的量化误差
    • 

  • YOLACT 通过原型掩码+系数分解实现了实时实例分割
    • 

  • Mask2Former 统一了语义、实例和全景分割三大任务
    • 

  • 实际项目中，精度优先选 Mask2Former，速度优先选 YOLACT 或 YOLOv8-seg
