全景分割

核心概念

全景分割（Panoptic Segmentation）统一了语义分割和实例分割两大任务，要求模型同时处理图像中的每一个像素：对于可数的"事物"（things，如人、车）需要区分不同实例，对于不可数的"背景"（stuff，如天空、道路）只需语义分类。全景分割为每个像素分配一个语义标签和一个实例 ID，提供了最完整的场景理解。

全景质量（Panoptic Quality, PQ）是全景分割的标准评估指标。PQ 同时衡量分割质量和识别质量：PQ = SQ × RQ，其中 SQ（Segmentation Quality）衡量匹配段的 IoU 均值，RQ（Recognition Quality）衡量匹配的 F1-Score。

Panoptic FPN 双分支架构
Panoptic FPN 是最直接的全景分割方案：在 FPN 特征金字塔上构建两个独立的分支——实例分割分支（Mask R-CNN 头）和语义分割分支（密集预测头），然后通过启发式的融合策略将两个分支的输出合并为全景结果。


import torch
import torch.nn as nn

class PanopticFPNHead(nn.Module):
    def __init__(self, in_channels, num_things, num_stuff):
        super().__init__()
        self.semantic_head = nn.Sequential(
            nn.Conv2d(in_channels, 128, 3, padding=1),
            nn.GroupNorm(32, 128),
            nn.ReLU(),
            nn.Conv2d(128, num_things + num_stuff, 1),
        )

    def forward(self, fpn_features):
        p2 = fpn_features['p2']
        semantic_logits = self.semantic_head(p2)
        return semantic_logits
融合策略的核心规则是：things 类别的预测以实例分割结果为准（保留实例区分性），stuff 类别以语义分割结果为准。当 things 和 stuff 预测在同一像素上冲突时，置信度高的优先。这种启发式融合虽然有效，但存在两个分支独立优化、目标不一致的问题。


Panoptic-DeepLab 采用自下而上的路线，不使用目标检测器。它在语义分割的基础上，为每个像素预测到所属实例中心的偏移量，然后通过聚类将像素分组为实例。这种方法更加简洁，且在 stuff 类别上表现更好。


MaskFormer 掩码分类范式
MaskFormer 提出了一个革命性的观点：语义分割、实例分割和全景分割本质上都是"掩码分类"问题——为图像生成一组二值掩码，每个掩码对应一个类别标签。这种统一视角使得一个模型可以同时处理三种分割任务。


MaskFormer 使用 Transformer 解码器生成 N 个 queries，每个 query 预测一个二值掩码和对应的类别。对于语义分割，将同类别的掩码合并；对于实例分割，每个 query 对应一个实例；对于全景分割，things queries 保留实例 ID，stuff queries 合并同类别。


from transformers import MaskFormerForInstanceSegmentation
import torch

model = MaskFormerForInstanceSegmentation.from_pretrained("facebook/maskformer-swin-base-coco")
model.eval()

dummy = torch.randn(1, 3, 800, 800)
with torch.no_grad():
    outputs = model(pixel_values=dummy)
    masks = outputs.masks_queries_logits
    classes = outputs.class_queries_logits
    print(f"查询掩码: {masks.shape}")
    print(f"查询类别: {classes.shape}")
MaskFormer 的训练使用匈牙利匹配算法将预测掩码与真实掩码进行一对一匹配，损失函数包含分类损失（交叉熵）和掩码损失（二值交叉熵 + Dice Loss）。这种集合级别的损失函数与 DETR 类似，避免了传统方法中复杂的正负样本分配。


开放词汇全景分割
传统全景分割模型只能识别训练时见过的固定类别集合。开放词汇全景分割（Open-Vocabulary Panoptic Segmentation）将识别能力扩展到任意文本描述的类别，借助 CLIP 等视觉-语言模型的语义对齐能力。


import torch

class OpenVocabPanoptic(torch.nn.Module):
    def __init__(self, image_encoder, text_encoder, mask_decoder):
        super().__init__()
        self.image_encoder = image_encoder
        self.text_encoder = text_encoder
        self.mask_decoder = mask_decoder

    def forward(self, images, text_queries):
        image_features = self.image_encoder(images)
        text_features = self.text_encoder(text_queries)
        masks = self.mask_decoder(image_features)
        mask_features = (masks.unsqueeze(2) * image_features.unsqueeze(1)).mean(dim=(-2, -1))
        logits = mask_features @ text_features.T
        return masks, logits
X-Decoder 和 SEEM 等模型进一步将全景分割与指代分割、图像描述等任务统一，通过自然语言、点击或区域等多种交互方式进行分割。Grounded SAM 将 Grounding DINO 的开放词汇检测能力与 SAM 的精确分割能力结合，实现了"说什么分什么"的交互体验。

小结
    

  • 全景分割统一了 things 和 stuff 的处理，提供最完整的场景理解
    • 

  • PQ 指标同时衡量分割质量和识别质量
    • 

  • MaskFormer 的掩码分类范式统一了三种分割任务，是当前最主流的架构
    • 

  • Mask2Former 通过掩码注意力在三种任务上都达到了最佳性能
    • 

  • 开放词汇方法借助视觉-语言模型打破了固定类别的限制
    • 

  • Grounded SAM 实现了文本驱动的任意物体分割，是实际应用中最灵活的方案
