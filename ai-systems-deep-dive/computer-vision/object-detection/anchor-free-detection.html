无锚框检测

核心概念

无锚框检测（Anchor-Free Detection）摆脱了预定义锚框的约束，通过直接预测目标的关键点或中心点来实现目标定位。锚框设计需要大量先验知识和超参数调优（尺度、宽高比、数量），无锚框方法消除了这些设计负担，同时在某些场景下展现出更好的泛化能力。

无锚框方法的核心优势是简洁性和灵活性。没有锚框意味着不需要预定义尺度和宽高比，模型可以自适应地检测任意形状的目标。同时，正负样本的分配也更加自然——锚框方法中的正负样本分配依赖于 IoU 阈值，而无锚框方法通常基于空间位置或学习式匹配。

FCOS 与逐像素预测
FCOS（Fully Convolutional One-Stage）将目标检测转化为逐像素的密集预测问题。对于特征图上的每个位置，FCOS 直接预测该位置到目标边界框四条边的距离（l, t, r, b），以及目标的类别。落在真实框内部的特征点被视为正样本，不需要任何锚框。


FCOS 引入了 center-ness 分支来抑制低质量预测。center-ness 衡量一个预测位置距离目标中心的远近程度，值域为 [0, 1]。距离中心近的位置 center-ness 接近 1，边缘位置接近 0。最终置信度 = 分类分数 × center-ness，这有效降低了远离中心的低质量检测框的得分。


import torch
import torch.nn as nn

class FCOSHead(nn.Module):
    def __init__(self, in_channels, num_classes):
        super().__init__()
        self.cls_tower = nn.Sequential(
            nn.Conv2d(in_channels, in_channels, 3, padding=1),
            nn.GroupNorm(32, in_channels),
            nn.ReLU(),
        )
        self.bbox_tower = nn.Sequential(
            nn.Conv2d(in_channels, in_channels, 3, padding=1),
            nn.GroupNorm(32, in_channels),
            nn.ReLU(),
        )
        self.cls_logits = nn.Conv2d(in_channels, num_classes, 3, padding=1)
        self.bbox_pred = nn.Conv2d(in_channels, 4, 3, padding=1)
        self.centerness = nn.Conv2d(in_channels, 1, 3, padding=1)

    def forward(self, x):
        cls_feat = self.cls_tower(x)
        bbox_feat = self.bbox_tower(x)
        cls_score = self.cls_logits(cls_feat)
        bbox_reg = torch.exp(self.bbox_pred(bbox_feat))
        center = self.centerness(cls_feat)
        return cls_score, bbox_reg, center
FCOS 在多尺度 FPN 上为不同尺度的目标分配不同层级：小目标在高分辨率层预测，大目标在低分辨率层预测。这种基于尺度的层级分配解决了一个位置被多个不同尺度目标覆盖的歧义问题。


CenterNet 与热力图回归
CenterNet 将目标检测建模为关键点检测问题：每个目标用其中心点表示，模型预测中心点的热力图和相关属性（宽高、偏移等）。这种"万物皆关键点"的思路极其简洁，不需要锚框、不需要 NMS（理论上），检测速度极快。


CenterNet 使用高斯核在中心点位置渲染热力图作为训练目标，热力图的峰值位置对应目标中心。推理时通过简单的 3×3 极大值池化提取热力图中的峰值点，每个峰值点即为一个检测目标。


import torch
import torch.nn as nn

def gaussian_radius(det_size, min_overlap=0.7):
    height, width = det_size
    a1 = 1
    b1 = (height + width)
    c1 = width * height * (1 - min_overlap) / (1 + min_overlap)
    sq1 = (b1 ** 2 - 4 * a1 * c1).sqrt()
    r1 = (b1 + sq1) / 2
    return min(r1, height, width)

class CenterNetHead(nn.Module):
    def __init__(self, in_channels, num_classes):
        super().__init__()
        self.heatmap = nn.Sequential(
            nn.Conv2d(in_channels, in_channels, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(in_channels, num_classes, 1),
        )
        self.wh = nn.Sequential(
            nn.Conv2d(in_channels, in_channels, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(in_channels, 2, 1),
        )
        self.offset = nn.Sequential(
            nn.Conv2d(in_channels, in_channels, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(in_channels, 2, 1),
        )

    def forward(self, x):
        hm = torch.sigmoid(self.heatmap(x))
        wh = self.wh(x)
        offset = self.offset(x)
        return hm, wh, offset
CenterNet 的扩展性极强：通过在中心点上预测不同属性，可以统一处理检测、姿态估计、3D 检测等多种任务。CornerNet 是另一种关键点方法，通过预测左上角和右下角两个关键点来定位目标，使用 associative embedding 将属于同一目标的角点配对。


DETR 与 Transformer 检测
DETR（Detection Transformer）彻底改变了目标检测的范式。它使用 Transformer 的编码器-解码器结构，将检测建模为集合预测问题：给定一组固定数量的 object queries，通过注意力机制与图像特征交互，直接输出检测结果。DETR 不需要锚框，不需要 NMS，是真正的端到端检测器。


DETR 的训练使用匈牙利匹配算法将预测与真实框进行一对一匹配，确保每个真实框恰好被一个预测负责。这种集合级别的损失函数避免了传统方法中复杂的正负样本分配策略。


import torch
from transformers import DetrForObjectDetection, DetrImageProcessor

processor = DetrImageProcessor.from_pretrained("facebook/detr-resnet-50")
model = DetrForObjectDetection.from_pretrained("facebook/detr-resnet-50")
model.eval()

dummy_image = torch.randn(3, 800, 600)
inputs = processor(images=dummy_image, return_tensors="pt")
with torch.no_grad():
    outputs = model(**inputs)
    logits = outputs.logits
    boxes = outputs.pred_boxes
    print(f"DETR 输出: {logits.shape}, {boxes.shape}")
原始 DETR 的训练收敛极慢（需要 500 个 epoch），Deformable DETR 通过引入可变形注意力机制大幅加速了收敛（50 个 epoch）。DINO-DETR 进一步引入了对比去噪训练、混合查询选择等技术，在 COCO 上达到了 63.3 mAP 的惊人成绩。

小结
    

  • 无锚框检测消除了锚框设计的超参数负担，模型更加简洁
    • 

  • FCOS 通过逐像素预测和 center-ness 机制实现了高效的无锚框检测
    • 

  • CenterNet 的中心点检测思路极为简洁，可扩展到多种视觉任务
    • 

  • DETR 开创了 Transformer 检测范式，实现了无 NMS 的端到端检测
    • 

  • DINO-DETR 代表了当前检测精度的最高水平
    • 

  • 实际项目中，YOLOv8（无锚框变体）和 DINO-DETR 是两个值得关注的方向
