两阶段检测器

核心概念

两阶段检测器（Two-Stage Detectors）将目标检测分解为候选区域生成和区域分类回归两个阶段。第一阶段生成可能包含目标的区域提议（Region Proposals），第二阶段对每个提议进行精确分类和边界框回归。这种分而治之的策略使得两阶段检测器在精度上长期保持领先地位。

两阶段检测器的核心优势在于：第一阶段过滤掉大量背景区域，使第二阶段能够专注于少量高质量候选框的精细处理。这种设计在处理复杂场景和小目标时特别有效。

R-CNN 到 Faster R-CNN 的演进
R-CNN（2014）首次证明了 CNN 特征在目标检测中的强大能力。它使用 Selective Search 算法生成约 2000 个候选区域，每个区域独立通过 CNN 提取特征，再用 SVM 分类和线性回归器修正边界框。但 R-CNN 的速度极慢，因为每个候选区域都需要单独通过 CNN 前向传播。


Fast R-CNN 的核心改进是共享特征计算。整张图像只需通过 CNN 一次，然后使用 RoI Pooling 从共享特征图中提取每个候选区域的特征。这将速度提升了约 20 倍，同时引入了多任务损失函数同时训练分类和回归。


import torch
import torchvision
from torchvision.models.detection import fasterrcnn_resnet50_fpn_v2
from torchvision.models.detection import FasterRCNN_ResNet50_FPN_V2_Weights

model = fasterrcnn_resnet50_fpn_v2(weights=FasterRCNN_ResNet50_FPN_V2_Weights.COCO_V1)
model.eval()

dummy_image = torch.randn(3, 800, 600)
with torch.no_grad():
    predictions = model([dummy_image])
    boxes = predictions[0]['boxes']
    labels = predictions[0]['labels']
    scores = predictions[0]['scores']
    print(f"检测到 {len(boxes)} 个目标")
Faster R-CNN 的突破性创新是用区域提议网络（RPN）替代了 Selective Search。RPN 是一个小型卷积网络，在特征图的每个位置上放置多个预定义锚框（不同尺度和宽高比），预测每个锚框包含目标的概率和边界框偏移量。RPN 与检测网络共享骨干特征，实现了真正的端到端训练。


RPN 与锚框机制
RPN 的设计体现了目标检测中"锚框"（Anchor）范式的核心思想。锚框是预定义的参考框，检测器不是直接预测目标的绝对坐标，而是预测相对于锚框的偏移量。这种间接回归方式降低了学习难度，因为偏移量的范围比绝对坐标小得多。


标准的 Faster R-CNN 在每个特征图位置放置 9 个锚框（3 个尺度 × 3 个宽高比）。锚框与真实框的 IoU（交并比）大于 0.7 的被标记为正样本，小于 0.3 的被标记为负样本，用于训练 RPN 的二分类和回归损失。


RoI Align 是对 RoI Pooling 的重要改进。RoI Pooling 通过整数量化引入了空间误差，而 RoI Align 使用双线性插值精确采样，消除了量化误差。这一改进对需要精确空间对齐的任务（如实例分割）至关重要。


import torch
from torchvision.ops import roi_align

features = torch.randn(1, 256, 50, 50)
boxes = torch.tensor([[0, 10.5, 20.3, 30.7, 40.2]])
pooled = roi_align(features, boxes, output_size=(7, 7), spatial_scale=1.0/16)
print(f"RoI Align 输出: {pooled.shape}")
Cascade R-CNN 与多阶段精修
Cascade R-CNN 发现了目标检测中的 IoU 阈值困境：用低 IoU 阈值（如 0.5）训练的检测器能检出更多目标但会产生较多误检，用高 IoU 阈值训练的检测器定位精度高但容易漏检。Cascade R-CNN 通过级联多个检测头来解决这一矛盾。


Cascade R-CNN 包含三个级联的检测阶段，每个阶段使用逐渐提高的 IoU 阈值（0.5→0.6→0.7）。前一阶段的回归输出作为后一阶段的输入提议，实现渐进式精修。这种设计使得每个阶段都能在与其训练分布匹配的提议上工作，避免了训练-测试分布不匹配的问题。


import torchvision
from torchvision.models.detection import fasterrcnn_resnet50_fpn

model = fasterrcnn_resnet50_fpn(weights=None)

cascade_config = {
    'stages': [
        {'iou_threshold': 0.5, 'weight': 1.0},
        {'iou_threshold': 0.6, 'weight': 0.5},
        {'iou_threshold': 0.7, 'weight': 0.25},
    ]
}
Dynamic R-CNN 进一步让 IoU 阈值在训练过程中自适应调整：随着模型能力增强，逐渐提高阈值要求。这种课程学习式的训练策略使模型在各质量层次的提议上都能表现出色。

NMS 与后处理优化
非极大值抑制（NMS）是目标检测后处理的核心环节。检测器通常对同一目标产生多个重叠的检测框，NMS 通过保留得分最高的框并抑制与其高度重叠的框来去除冗余检测。


标准 NMS 是贪心算法：按置信度降序排列检测框，依次选取当前最高分的框，删除与其 IoU 超过阈值的所有框。Soft-NMS 将硬删除改为软衰减：重叠框的得分按高斯函数或线性函数衰减，保留了被遮挡目标的检测机会。


import torch
from torchvision.ops import nms, batched_nms

boxes = torch.tensor([[10, 20, 100, 200],
                       [15, 25, 105, 205],
                       [300, 400, 500, 600]], dtype=torch.float)
scores = torch.tensor([0.9, 0.8, 0.7])

keep = nms(boxes, scores, iou_threshold=0.5)
print(f"NMS 保留的框索引: {keep}")

labels = torch.tensor([0, 0, 1])
keep_batched = batched_nms(boxes, scores, labels, iou_threshold=0.5)
DIoU-NMS 使用 DIoU（Distance IoU）替代标准 IoU 来衡量框的重叠程度，考虑了框中心距离，在密集场景中效果更好。Matrix NMS 将 NMS 操作并行化为矩阵运算，避免了逐框处理的串行瓶颈，在 GPU 上可以实现更高的吞吐量。


小结
    

  • 两阶段检测器通过先提议后分类的策略在精度上保持领先
    • 

  • Faster R-CNN 的 RPN 实现了端到端的区域提议，是两阶段检测器的里程碑
    • 

  • RoI Align 通过双线性插值消除量化误差，对精确定位至关重要
    • 

  • Cascade R-CNN 通过渐进式 IoU 阈值解决了精度-召回的权衡问题
    • 

  • NMS 后处理直接影响最终检测结果，Soft-NMS 在密集场景中更优
    • 

  • FPN 多尺度特征融合是处理不同尺度目标的标准方案
