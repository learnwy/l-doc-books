实时检测

核心概念

实时检测要求模型在严格的延迟约束下（通常 ≤33ms，即 ≥30 FPS）完成目标检测。这一需求广泛存在于自动驾驶、机器人导航、视频监控和增强现实等场景中。实时检测不仅需要高效的模型架构，还需要从模型压缩、推理优化到硬件部署的全链路工程能力。

实时检测的核心挑战是在精度和速度之间找到最佳权衡点。影响推理速度的因素包括：模型参数量（影响内存占用）、计算量 FLOPs（影响计算时间）、内存访问模式（影响带宽利用率）和算子效率（影响硬件利用率）。

轻量级骨干网络
轻量级骨干网络通过精心设计的卷积操作和网络结构来降低计算量，同时尽可能保持特征表达能力。深度可分离卷积是轻量化的核心技术，它将标准卷积分解为深度卷积（Depthwise）和逐点卷积（Pointwise）两步，计算量降低为原来的约 1/k²（k 为卷积核大小）。


MobileNetV3 结合了深度可分离卷积、SE 注意力和 NAS 搜索的网络结构，在移动端 CPU 上实现了出色的速度-精度权衡。ShuffleNetV2 通过通道重排（Channel Shuffle）实现了跨组信息交流，并总结了四条轻量化设计原则：等宽通道最快、过多分组卷积增加延迟、网络分支降低并行度、逐元素操作不可忽视。


import torch
import torchvision.models as models

mobilenet = models.mobilenet_v3_small(weights=models.MobileNet_V3_Small_Weights.IMAGENET1K_V1)
feature_extractor = mobilenet.features

    features = feature_extractor(dummy)

from torchvision.models.detection import fcos_resnet50_fpn

EfficientDet 将 EfficientNet 骨干与 BiFPN（双向特征金字塔）结合，通过复合缩放在不同计算预算下提供最优检测模型。PP-YOLOE 是百度的工业级实时检测器，使用 CSPRepResNet 骨干和 TAL（Task Alignment Learning）正样本选择策略，在速度和精度上达到了工业部署的最佳平衡。


模型量化与压缩
模型量化通过降低参数和计算的数值精度来加速推理。FP32→FP16 的混合精度推理几乎没有精度损失，在支持 FP16 的 GPU 上可以获得近 2 倍加速。INT8 量化将精度进一步降低到 8 位整数，在 CPU 和边缘设备上效果更显著。


训练后量化（PTQ）不需要重新训练模型，通过在少量校准数据上统计激活值的分布来确定量化参数。量化感知训练（QAT）在训练过程中模拟量化效果，使模型适应低精度计算，通常能比 PTQ 恢复更多精度。


import torch
from torch.quantization import quantize_dynamic, get_default_qconfig

model = torch.hub.load("ultralytics/yolov5", "yolov5s")

quantized_model = quantize_dynamic(
    model, {torch.nn.Linear, torch.nn.Conv2d}, dtype=torch.qint8
)

dummy_input = torch.randn(1, 3, 640, 640)
torch.onnx.export(

知识蒸馏通过让小模型（学生）学习大模型（教师）的输出分布来提升小模型的性能。在目标检测中，蒸馏可以应用在多个层面：分类蒸馏（软标签）、回归蒸馏（框坐标）、特征蒸馏（中间层特征图）。特征蒸馏通常效果最好，但需要对齐教师和学生的特征图尺寸。

推理引擎与边缘部署
推理引擎通过图优化、算子融合和硬件适配来最大化推理性能。TensorRT 是 NVIDIA GPU 上最快的推理引擎，支持 FP16/INT8 量化、层融合、动态批处理等优化。OpenVINO 针对 Intel CPU/GPU 优化，ONNX Runtime 提供跨平台兼容性。


from ultralytics import YOLO

model = YOLO("yolov8n.pt")

model.export(format="onnx", imgsz=640, half=True)
model.export(format="engine", imgsz=640, half=True)
model.export(format="coreml", imgsz=640)
model.export(format="tflite", imgsz=640, int8=True)
边缘设备部署需要特别关注内存限制和功耗约束。NVIDIA Jetson 系列提供了移动端 GPU 加速，支持 TensorRT 推理。Qualcomm 的 NPU（神经网络处理器）通过 SNPE/QNN 框架执行量化模型。Apple Neural Engine 通过 Core ML 框架运行，对 iOS 应用尤其重要。


在实际部署中，端到端延迟不仅包含模型推理时间，还包含图像预处理（解码、缩放、归一化）和后处理（NMS、框映射）的时间。预处理可以通过 GPU 解码（DALI）或 SIMD 指令加速；后处理的 NMS 可以使用 batched NMS 或在模型内完成（如 DETR 类方法无需 NMS）。


小结
    

  • 实时检测需要从模型架构、压缩优化到推理引擎的全链路优化
    • 

  • 深度可分离卷积是轻量化的核心技术，MobileNetV3 是移动端骨干的首选
    • 

  • INT8 量化在精度损失极小的情况下可以带来 2-3 倍加速
    • 

  • TensorRT 是 NVIDIA GPU 上推理速度最快的引擎
    • 

  • YOLOv8 的 Ultralytics 框架内置了 ONNX、TensorRT、Core ML 等多种导出格式
    • 

  • 端到端延迟优化需要同时关注预处理、推理和后处理三个环节
