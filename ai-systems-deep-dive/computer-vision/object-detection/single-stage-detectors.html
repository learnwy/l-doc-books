单阶段检测器

核心概念

单阶段检测器（Single-Stage Detectors）跳过候选区域生成步骤，直接在特征图上回归目标的类别和位置。这种端到端的设计大幅简化了检测流水线，带来了显著的速度优势。YOLO 系列和 SSD 是单阶段检测器的两大代表，前者强调极致速度，后者强调多尺度检测。

单阶段检测器的核心思想是将目标检测视为密集预测问题：在特征图的每个位置上预测固定数量的锚框或关键点的类别和偏移。这种设计避免了两阶段方法中 RoI 提取的计算开销，同时能够利用 GPU 的并行计算优势。

YOLO 系列演进
YOLO（You Only Look Once）是目标检测历史上最具影响力的系列工作。YOLOv1 将检测看作单次回归问题，将图像划分为 S×S 的网格，每个网格负责预测落在其中的目标。虽然 YOLOv1 的精度不如同期的 Faster R-CNN，但其速度快了数倍，开创了实时目标检测的先河。


YOLOv3 引入了多尺度检测：在三个不同分辨率的特征图上进行预测，分别检测大、中、小目标。它使用 Darknet-53 作为骨干网络，结合类似 FPN 的自顶向下融合路径，显著提升了小目标检测能力。


from ultralytics import YOLO

model = YOLO("yolov8n.pt")

results = model("image.jpg")
for result in results:
    boxes = result.boxes
    for box in boxes:
        cls = int(box.cls[0])
        conf = float(box.conf[0])
        xyxy = box.xyxy[0].tolist()
        print(f"类别: {cls}, 置信度: {conf:.2f}, 框: {xyxy}")

model.train(data="coco128.yaml", epochs=100, imgsz=640, batch=16)
YOLOv5 是工程化程度最高的版本，提供了从 nano 到 xlarge 五种模型尺寸，内置了完善的训练流水线、数据增强和部署工具。YOLOv8 进一步引入了解耦检测头（分类和回归使用独立的分支）和无锚框设计，在速度和精度上都达到了新的高度。


SSD 与多尺度检测
SSD（Single Shot MultiBox Detector）的核心创新是在骨干网络的多个层级上直接进行检测。浅层特征图分辨率高，负责检测小目标；深层特征图分辨率低但感受野大，负责检测大目标。这种金字塔式的多尺度检测策略被后续的检测器广泛采用。


SSD 在 VGG-16 的基础上添加了额外的卷积层，形成逐渐缩小的特征图序列。每个特征图上的每个位置都放置多个不同宽高比的默认框（类似锚框），通过 3×3 卷积预测每个默认框的类别和偏移。


import torch
import torchvision
from torchvision.models.detection import ssd300_vgg16

model = ssd300_vgg16(weights=torchvision.models.detection.SSD300_VGG16_Weights.COCO_V1)
model.eval()

dummy_image = torch.randn(3, 300, 300)
with torch.no_grad():
    predictions = model([dummy_image])
    print(f"SSD 检测到 {len(predictions[0]['boxes'])} 个目标")
DSSD（Deconvolutional SSD）在 SSD 的基础上添加了自顶向下的反卷积路径，将高层语义信息融合到低层特征中，改善了小目标的检测效果。Feature Pyramid Networks（FPN）进一步将这种多尺度融合方式标准化，成为现代检测器的基础组件。


Focal Loss 与正负样本均衡
RetinaNet 的核心贡献是 Focal Loss，它解决了单阶段检测器面临的严重类别不均衡问题。在密集预测中，大量的背景位置（负样本）远多于目标位置（正样本），导致训练被简单负样本主导，模型无法有效学习困难样本的特征。


Focal Loss 通过在标准交叉熵损失前添加调制因子 (1-p_t)^γ 来降低容易分类样本的损失权重。当 γ=2 时，一个置信度为 0.9 的正确分类样本的损失权重仅为标准交叉熵的 1%，而困难样本的损失权重几乎不变。


import torch
import torch.nn as nn
import torch.nn.functional as F

class FocalLoss(nn.Module):
    def __init__(self, alpha=0.25, gamma=2.0):
        super().__init__()
        self.alpha = alpha
        self.gamma = gamma

    def forward(self, inputs, targets):
        bce_loss = F.binary_cross_entropy_with_logits(inputs, targets, reduction='none')
        p_t = torch.exp(-bce_loss)
        focal_weight = self.alpha * (1 - p_t) ** self.gamma
        loss = focal_weight * bce_loss
        return loss.mean()

focal_loss = FocalLoss(alpha=0.25, gamma=2.0)
logits = torch.randn(100, 80)
targets = torch.zeros(100, 80)
targets[0, 5] = 1.0
loss = focal_loss(logits, targets)

ATSS（Adaptive Training Sample Selection）发现正样本的选择策略比锚框设计更重要。它根据锚框与真实框的 IoU 分布自适应地确定正负样本划分阈值，消除了锚框超参数对性能的影响，统一了有锚框和无锚框检测器的性能差距。


小结
    

  • 单阶段检测器通过密集预测实现了远超两阶段方法的推理速度
    • 

  • YOLO 系列从 v1 到 v8 不断迭代，YOLOv8 兼具速度和精度，是实际项目的首选
    • 

  • SSD 开创了多尺度检测范式，其思想被 FPN 标准化并广泛采用
    • 

  • Focal Loss 有效解决了正负样本严重不均衡问题，是单阶段检测器训练的关键
    • 

  • ATSS 证明了正样本选择策略比锚框设计更重要
    • 

  • 实际部署中，YOLOv8 的 Ultralytics 框架提供了最完善的训练和部署工具链
