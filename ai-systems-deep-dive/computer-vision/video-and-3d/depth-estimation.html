深度估计

核心概念

深度估计从二维图像中恢复场景的三维深度信息，为每个像素预测其到相机的距离。深度信息是三维重建、自动驾驶、机器人导航和增强现实等应用的基础。根据输入的不同，深度估计分为单目（单张图像）、双目（立体图像对）和多视图三种主要方法。

单目深度估计从单张图像推断深度，这是一个本质上的病态问题（无穷多个三维场景可以投影为同一张二维图像），需要依赖学习到的几何先验。双目深度估计利用两个视角的图像计算视差，通过三角测量恢复精确的度量深度。

单目深度估计
单目深度估计是计算机视觉中极具挑战性的任务。模型需要从单张图像的纹理梯度、遮挡关系、透视缩放、地面接触点等视觉线索中推断深度。深度学习方法通过在大规模深度数据上训练，隐式学习了这些几何先验。


MiDaS 是单目相对深度估计的标杆模型。它在混合数据集上训练，产生的深度图虽然不具有绝对尺度，但保持了正确的深度排序关系。MiDaS 的泛化能力极强，在未见过的场景上也能产生高质量的相对深度估计。


import torch

model = torch.hub.load("intel-isl/MiDaS", "DPT_Large")
model.eval()

midas_transforms = torch.hub.load("intel-isl/MiDaS", "transforms")
transform = midas_transforms.dpt_transform

import cv2
img = cv2.imread("scene.jpg")
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
input_batch = transform(img_rgb).unsqueeze(0)

with torch.no_grad():
    prediction = model(input_batch)
    prediction = torch.nn.functional.interpolate(
        prediction.unsqueeze(1), size=img.shape[:2],
        mode="bicubic", align_corners=False,
    ).squeeze()
Depth Anything 系列代表了当前单目深度估计的最高水平。Depth Anything V2 使用大规模合成数据和少量高精度真实数据进行训练，在保持优异泛化能力的同时提升了度量精度。其 ViT-L 版本在多个基准上全面超越 MiDaS，成为新的通用深度估计基线。


立体匹配与视差计算
立体匹配利用同一场景的左右两张图像，通过在对应行上搜索匹配像素来计算视差（disparity），再根据相机基线和焦距将视差转换为度量深度：depth = baseline × focal_length / disparity。


传统立体匹配使用块匹配（Block Matching）或半全局匹配（SGM）来搜索最优视差。深度学习方法通过构建代价体（Cost Volume）来评估不同视差值的匹配质量，然后通过 3D 卷积或递归优化来回归最终视差。


import torch
import torch.nn as nn

class CostVolume(nn.Module):
    def __init__(self, max_disp=192):
        super().__init__()
        self.max_disp = max_disp

    def forward(self, left_feat, right_feat):
        b, c, h, w = left_feat.shape
        cost = torch.zeros(b, c, self.max_disp // 4, h, w, device=left_feat.device)
        for d in range(self.max_disp // 4):
            if d == 0:
                cost[:, :, d] = left_feat * right_feat
            else:
                cost[:, :, d, :, d:] = left_feat[:, :, :, d:] * right_feat[:, :, :, :-d]
        return cost
RAFT-Stereo 将 RAFT（光流估计方法）的迭代优化思路应用于立体匹配。它构建全对相关体积（All-Pairs Correlation Volume），通过 GRU 迭代更新视差估计。CREStereo 进一步引入了自适应分组相关来处理纹理弱区域和遮挡区域的匹配困难。

Depth Anything 与基础模型
Depth Anything 系列代表了深度估计从任务专用模型向视觉基础模型的转变。它利用大规模无标签图像和自训练策略，构建了覆盖极广泛场景的通用深度估计能力。


Depth Anything V2 的训练策略包含三个关键创新：使用 VKITTI 和 Hypersim 等高质量合成数据提供精确的度量深度监督；使用教师-学生蒸馏在大规模真实图像上生成伪标签；通过混合训练将合成数据的精度和真实数据的多样性结合。


import torch
from depth_anything_v2.dpt import DepthAnythingV2

model = DepthAnythingV2(encoder='vitl', features=256, out_channels=[256, 512, 1024, 1024])
model.load_state_dict(torch.load('depth_anything_v2_vitl.pth'))
model.eval()

import cv2
raw_img = cv2.imread('scene.jpg')
depth = model.infer_image(raw_img)
print(f"深度图形状: {depth.shape}, 范围: [{depth.min():.2f}, {depth.max():.2f}]")
ZoeDepth 在相对深度模型的基础上添加了度量头，通过域特定的 bin 划分将相对深度转换为绝对度量深度。Metric3D 进一步引入了相机内参作为条件输入，使模型能够根据不同的相机参数产生准确的度量深度。UniDepth 统一了相对和度量深度估计，同时预测深度和相机内参。


小结
    

  • 深度估计是连接二维图像和三维世界的桥梁
    • 

  • 单目深度估计依赖学习到的几何先验，Depth Anything V2 是当前最强的通用方案
    • 

  • 立体匹配通过双目视差提供精确的度量深度，RAFT-Stereo 是主流方法
    • 

  • 基础模型路线通过大规模训练获得了惊人的泛化能力
    • 

  • 度量深度需要相机参数信息，ZoeDepth 和 Metric3D 提供了可行方案
    • 

  • 实际项目中，如果只需要相对深度关系用 Depth Anything，需要绝对距离用双目匹配
    •
