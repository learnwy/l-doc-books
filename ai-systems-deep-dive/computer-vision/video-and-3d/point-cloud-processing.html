点云处理

核心概念

点云（Point Cloud）是三维空间中的离散点集合，每个点包含三维坐标 (x, y, z) 以及可选的属性信息（颜色、法向量、反射率等）。点云数据由激光雷达（LiDAR）、深度相机（RGB-D）或多视图重建生成，是自动驾驶、机器人和三维重建的核心数据形式。

点云处理面临三个核心挑战：无序性（点的排列顺序不应影响结果）、稀疏性（三维空间中大部分区域没有点）和不均匀性（点的密度随距离衰减）。不同于图像的规则网格结构，点云的不规则性要求专门的网络架构设计。

PointNet 与置换不变性
PointNet 是点云深度学习的开创性工作。它的核心思想是：通过对每个点独立应用共享的 MLP（多层感知机），再通过对称函数（最大池化）聚合所有点的特征来保证置换不变性。无论输入点的顺序如何打乱，输出结果始终相同。


import torch
import torch.nn as nn

class PointNet(nn.Module):
    def __init__(self, num_classes):
        super().__init__()
        self.mlp1 = nn.Sequential(
            nn.Linear(3, 64), nn.ReLU(),
            nn.Linear(64, 128), nn.ReLU(),
            nn.Linear(128, 1024), nn.ReLU(),
        )
        self.classifier = nn.Sequential(
            nn.Linear(1024, 512), nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(512, 256), nn.ReLU(),
            nn.Linear(256, num_classes),
        )

    def forward(self, x):
        point_features = self.mlp1(x)
        global_feature = point_features.max(dim=1)[0]
        return self.classifier(global_feature)

model = PointNet(num_classes=40)
points = torch.randn(8, 1024, 3)
logits = model(points)
print(f"分类输出: {logits.shape}")
PointNet 的局限是每个点独立处理，缺乏局部几何结构的建模能力。PointNet++ 通过层级化的 Set Abstraction 模块解决了这一问题：在点云中采样中心点，对每个中心点的邻域应用 PointNet 提取局部特征，然后逐层聚合形成层级表示。


Point Transformer 将自注意力机制引入点云处理，使每个点能够根据与其他点的关系动态调整特征。Point Transformer V3 通过高效的序列化注意力大幅提升了处理速度，在多个点云理解基准上取得了最佳性能。


体素化与稀疏卷积
体素化将连续的三维空间离散化为规则的三维网格，每个体素（voxel）包含落入其中的点的聚合特征。体素表示使得三维点云可以使用类似图像的卷积操作来处理，但直接的稠密三维卷积计算量极大（O(N³)）。


稀疏卷积（Sparse Convolution）是解决这一问题的关键技术。由于三维空间中大部分体素是空的（稀疏率通常 >95%），稀疏卷积只在非空体素上执行卷积运算，计算量和内存消耗都大幅降低。SPConv（Spatio-temporal Sparse Convolution）库提供了高效的稀疏卷积实现。


import torch
import torch.nn as nn

class VoxelEncoder(nn.Module):
    def __init__(self, in_channels, voxel_size, point_cloud_range):
        super().__init__()
        self.voxel_size = voxel_size
        self.point_cloud_range = point_cloud_range
        self.pfn = nn.Sequential(
            nn.Linear(in_channels, 64),
            nn.BatchNorm1d(64),
            nn.ReLU(),
        )

    def voxelize(self, points):
        coords = ((points[:, :3] - self.point_cloud_range[:3]) / self.voxel_size).int()
        return coords

    def forward(self, points):
        coords = self.voxelize(points)
        features = self.pfn(points)
        return coords, features
SECOND（Sparsely Embedded Convolutional Detection）将稀疏卷积应用于自动驾驶的三维目标检测，实现了比 VoxelNet 快数倍的推理速度。CenterPoint 在 SECOND 的体素骨干上使用 CenterNet 的中心点检测思路，成为自动驾驶三维检测的主流方案。

多模态三维感知
在自动驾驶等实际应用中，通常同时配备激光雷达和相机，两种传感器提供互补的信息：相机提供丰富的纹理和语义信息，激光雷达提供精确的三维几何信息。多模态融合将两者的优势结合，实现更强大的三维感知。


BEV（Bird's Eye View）是多模态融合最流行的表示空间。相机图像通过 LSS（Lift-Splat-Shoot）或 BEVFormer 等方法投影到 BEV 空间，激光雷达点云通过体素化也转换到 BEV 空间，然后在统一的 BEV 特征图上进行融合和检测。


import torch
import torch.nn as nn

class BEVFusionHead(nn.Module):
    def __init__(self, lidar_channels, camera_channels, out_channels):
        super().__init__()
        self.lidar_encoder = nn.Conv2d(lidar_channels, out_channels, 1)
        self.camera_encoder = nn.Conv2d(camera_channels, out_channels, 1)
        self.fusion = nn.Sequential(
            nn.Conv2d(out_channels * 2, out_channels, 3, padding=1),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(),
        )

    def forward(self, lidar_bev, camera_bev):
        lidar_feat = self.lidar_encoder(lidar_bev)
        camera_feat = self.camera_encoder(camera_bev)
        fused = torch.cat([lidar_feat, camera_feat], dim=1)
        return self.fusion(fused)
BEVFusion（MIT）在 BEV 空间中对齐和融合激光雷达和相机特征，通过高效的 BEV 池化操作实现了实时的多模态三维检测。UniAD 在此基础上进一步统一了检测、追踪、预测和规划四大任务，构建了端到端的自动驾驶感知-决策系统。


小结
    

  • 点云的无序性、稀疏性和不均匀性要求专门的网络设计
    • 

  • PointNet 通过共享 MLP + 最大池化保证了置换不变性
    • 

  • 稀疏卷积是大规模点云处理的关键技术，仅在非空体素上计算
    • 

  • CenterPoint 是自动驾驶三维检测的主流方案
    • 

  • BEV 统一了多模态感知的表示空间，是自动驾驶感知的标准范式
    • 

  • 多模态融合（相机+激光雷达）比单一模态在安全性和精度上都有显著提升
