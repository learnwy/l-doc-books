视频理解

核心概念

视频理解的目标是让计算机理解视频中发生了什么、在哪里发生、何时发生。与图像理解的静态分析不同，视频理解需要建模时间维度的动态变化——运动模式、事件顺序和时序因果关系。视频理解涵盖视频分类、时序动作检测、视频描述和视频问答等多种任务。

视频的数据规模远大于图像——一段 10 秒 30fps 的视频包含 300 帧图像，直接处理所有帧的计算成本极高。因此，帧采样策略是视频理解的第一个关键决策：均匀采样、关键帧选择还是密集采样直接影响模型能够捕获的时序信息。

3D 卷积与时空特征
3D 卷积将 2D 卷积扩展到时间维度，卷积核同时在空间和时间方向滑动，能够捕获视频中的运动模式。I3D（Inflated 3D）通过将 ImageNet 预训练的 2D 卷积核"膨胀"为 3D 来初始化网络，有效地将图像预训练知识迁移到视频任务。


SlowFast 网络采用双流设计：Slow 路径以低帧率（如 4fps）处理视频，捕获空间语义信息；Fast 路径以高帧率（如 32fps）处理视频，捕获细粒度的运动信息。两条路径通过横向连接融合信息，在保持计算效率的同时实现了出色的时序建模。


import torch
import torch.nn as nn

class C3DBlock(nn.Module):
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.conv = nn.Conv3d(in_channels, out_channels, kernel_size=(3, 3, 3), padding=(1, 1, 1))
        self.bn = nn.BatchNorm3d(out_channels)
        self.relu = nn.ReLU()

    def forward(self, x):
        return self.relu(self.bn(self.conv(x)))

class SlowFastBlock(nn.Module):
    def __init__(self, slow_channels, fast_channels):
        super().__init__()
        self.slow_path = C3DBlock(slow_channels, slow_channels)
        self.fast_path = C3DBlock(fast_channels, fast_channels)
        self.lateral = nn.Conv3d(fast_channels, slow_channels // 4, kernel_size=(5, 1, 1), stride=(4, 1, 1), padding=(2, 0, 0))

    def forward(self, slow, fast):
        fast_out = self.fast_path(fast)
        lateral = self.lateral(fast_out)
        slow_in = torch.cat([slow, lateral], dim=1)
        slow_out = self.slow_path(slow_in)
        return slow_out, fast_out
R(2+1)D 将 3D 卷积分解为空间 2D 卷积和时间 1D 卷积的组合，减少了参数量同时增加了非线性变换次数，在相同计算量下取得了更好的效果。X3D 通过网络架构搜索在多个维度（时间、空间、宽度、深度）上同时缩放，找到了不同计算预算下的最优视频网络。


视频 Transformer
视频 Transformer 将 ViT 的自注意力机制扩展到时空域，通过建模帧内像素间和帧间 patch 间的长程依赖来理解视频内容。TimeSformer 探索了五种时空注意力变体，发现"分离注意力"（先空间注意力再时间注意力）在效率和效果之间取得了最佳平衡。


import torch
import torch.nn as nn

class DividedSpaceTimeAttention(nn.Module):
    def __init__(self, dim, num_heads, num_frames):
        super().__init__()
        self.spatial_attn = nn.MultiheadAttention(dim, num_heads, batch_first=True)
        self.temporal_attn = nn.MultiheadAttention(dim, num_heads, batch_first=True)
        self.num_frames = num_frames

    def forward(self, x, num_patches):
        b = x.shape[0]

        x_spatial = x.view(b * self.num_frames, num_patches, -1)
        x_spatial, _ = self.spatial_attn(x_spatial, x_spatial, x_spatial)
        x = x_spatial.view(b, self.num_frames * num_patches, -1)

        x_temporal = x.view(b * num_patches, self.num_frames, -1)
        x_temporal, _ = self.temporal_attn(x_temporal, x_temporal, x_temporal)
        x = x_temporal.view(b, self.num_frames * num_patches, -1)

        return x
VideoMAE 将掩码自编码器（MAE）扩展到视频预训练，通过遮挡极高比例（90%）的时空 patch 并预测被遮挡的像素来学习视频表示。由于视频帧间的时间冗余性，高掩码率不仅可行而且是必要的——低掩码率会让模型通过时间插值轻松恢复像素，无法学到有意义的表示。VideoMAE v2 在大规模数据上训练，在 Kinetics-400 上达到了 86.6% 的 Top-1 准确率。


时序动作检测
时序动作检测（Temporal Action Detection）不仅要识别视频中的动作类别，还要定位动作发生的起止时间。这类似于图像中的目标检测，只是从空间域转移到了时间域。


时序动作检测通常分为提议生成和分类两个阶段。BMN（Boundary-Matching Network）预测每个时间位置是动作开始或结束的概率，然后将开始-结束对组合为候选提议。ActionFormer 使用 Transformer 编码视频特征序列，直接预测每个时间位置的动作类别和时间范围。


import torch
import torch.nn as nn

class ActionFormerHead(nn.Module):
    def __init__(self, in_dim, num_classes, num_layers=3):
        super().__init__()
        self.cls_head = nn.Sequential(
            nn.Conv1d(in_dim, in_dim, 3, padding=1),
            nn.ReLU(),
            nn.Conv1d(in_dim, num_classes, 1),
        )
        self.reg_head = nn.Sequential(
            nn.Conv1d(in_dim, in_dim, 3, padding=1),
            nn.ReLU(),
            nn.Conv1d(in_dim, 2, 1),
        )

    def forward(self, features):
        cls_logits = self.cls_head(features)
        reg_offsets = self.reg_head(features)
        return cls_logits, reg_offsets

小结
    

  • 视频理解需要在空间和时间两个维度上建模，帧采样策略是第一个关键决策
    • 

  • SlowFast 的双流设计在效率和精度之间取得了出色的平衡
    • 

  • VideoMAE 的高掩码率预训练充分利用了视频的时间冗余性
    • 

  • 视频 Transformer 通过时空注意力分离实现了高效的长程依赖建模
    • 

  • 时序动作检测将目标检测的思路从空间域迁移到时间域
    • 

  • 实际项目中推荐使用 VideoMAE 预训练模型作为视频特征提取器
