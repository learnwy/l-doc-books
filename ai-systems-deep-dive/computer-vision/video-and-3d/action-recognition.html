动作识别

核心概念

动作识别（Action Recognition）是视频理解中最基础也最活跃的研究方向，其目标是识别视频中人体执行的动作类别。动作识别的技术挑战在于需要同时理解空间外观（人体姿态、场景环境）和时序动态（运动轨迹、节奏变化），而不同类型的动作对这两种信息的依赖程度各不相同。

动作识别的输入可以是 RGB 视频帧、骨架关节点序列或光流图。RGB 帧包含丰富的外观信息但冗余度高；骨架数据紧凑且对外观变化鲁棒但需要关节点检测作为前处理；光流显式编码了运动信息但计算成本高。现代方法往往融合多种模态以获得最佳效果。

基于骨架的动作识别
骨架（Skeleton）以人体关节点的二维或三维坐标序列来表示动作。相比 RGB 视频，骨架数据将人体抽象为结构化的关节图，天然屏蔽了背景干扰、光照变化和个体外观差异。


ST-GCN（Spatial-Temporal Graph Convolutional Network）是骨架动作识别的开创性工作。它将人体骨架建模为时空图：空间维度上，关节之间按照人体骨骼结构连接；时间维度上，同一关节在相邻帧之间连接。图卷积在空间和时间两个维度上传播信息，捕获运动模式。


import torch
import torch.nn as nn

class GraphConv(nn.Module):
    def __init__(self, in_channels, out_channels, adjacency):
        super().__init__()
        self.adjacency = adjacency
        self.num_subsets = adjacency.shape[0]
        self.convs = nn.ModuleList([
            nn.Conv2d(in_channels, out_channels, 1) for _ in range(self.num_subsets)
        ])
        self.bn = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU()

    def forward(self, x):
        out = 0
        for i, conv in enumerate(self.convs):
            a = self.adjacency[i]
            xa = torch.einsum('nctv,vw->nctw', x, a)
            out = out + conv(xa)
        return self.relu(self.bn(out))
CTR-GCN 通过学习通道级别的拓扑关系来动态调整图的连接结构，使模型能够自适应地发现不同动作所依赖的关节关系模式。InfoGCN 引入信息瓶颈原理，在骨架特征中保留与动作识别最相关的信息同时压缩冗余，达到了骨架方法的最佳性能。


双流网络与多模态融合
双流网络（Two-Stream Networks）是动作识别的经典架构范式。空间流处理单帧 RGB 图像，捕获场景和物体的外观特征；时间流处理堆叠的光流图，捕获短程运动信息。两个流的预测在决策层通过加权平均或级联融合。


光流是描述像素运动的密集矢量场，每个像素指向其在下一帧中的对应位置。传统光流（如 Farneback、TV-L1）计算慢但质量高，基于深度学习的光流（如 RAFT、FlowFormer）在速度和质量上都有大幅提升。


import torch
import torch.nn as nn

class TwoStreamFusion(nn.Module):
    def __init__(self, spatial_model, temporal_model, num_classes, fusion='late'):
        super().__init__()
        self.spatial = spatial_model
        self.temporal = temporal_model
        self.fusion = fusion
        if fusion == 'late':
            self.alpha = nn.Parameter(torch.tensor(0.5))

    def forward(self, rgb, flow):
        spatial_logits = self.spatial(rgb)
        temporal_logits = self.temporal(flow)

        if self.fusion == 'late':
            return self.alpha * spatial_logits + (1 - self.alpha) * temporal_logits
        elif self.fusion == 'concat':
            return torch.cat([spatial_logits, temporal_logits], dim=1)
PoseC3D 将骨架热力图作为输入，使用 3D CNN 而非图卷积来处理骨架信息。它将每个关节位置渲染为热力图堆叠在时间维度上，形成类似视频的 3D 输入。这种表示方式使得骨架信息可以直接利用成熟的视频理解架构和预训练权重，在 Kinetics-400 和 NTU RGB+D 等基准上取得了出色效果。

轻量化与实时动作识别
在移动设备和边缘端部署动作识别模型需要在精度和计算效率之间取得平衡。轻量化方法包括使用 2D CNN + 时序聚合替代 3D CNN、模型蒸馏和时序裁剪。


TSM（Temporal Shift Module）通过在通道维度上沿时间方向移位来实现零计算量的时序建模。它将每帧特征图的部分通道移位到相邻帧，使得 2D CNN 也能捕获时序信息。TSM 在 ResNet-50 上增加的计算量几乎为零，但在多个视频理解基准上取得了与 3D CNN 相当的效果。


import torch
import torch.nn as nn

class TemporalShift(nn.Module):
    def __init__(self, n_div=8):
        super().__init__()
        self.n_div = n_div

    def forward(self, x):
        nt, c, h, w = x.size()
        n_batch = nt // self.n_div
        x = x.view(n_batch, self.n_div, c, h, w)

        fold = c // 8
        out = x.clone()
        out[:, 1:, :fold] = x[:, :-1, :fold]
        out[:, :-1, fold:2*fold] = x[:, 1:, fold:2*fold]

        return out.view(nt, c, h, w)
MoViNet（Mobile Video Networks）通过因果卷积和流式推理实现了真正的在线视频识别。它不需要缓存多帧数据，而是逐帧处理并维护内部状态，非常适合在资源受限的设备上进行实时动作识别。


小结
    

  • 动作识别需要同时理解空间外观和时序动态两个维度
    • 

  • 骨架方法通过结构化的关节点表示屏蔽了外观干扰，适合对隐私敏感的场景
    • 

  • ST-GCN 开创了骨架图卷积范式，CTR-GCN 和 InfoGCN 持续推动性能提升
    • 

  • 多模态融合（RGB + 骨架）能获得最佳性能，但增加了系统复杂度
    • 

  • TSM 以零额外计算成本实现了时序建模，是轻量化部署的首选方案
    • 

  • MoViNet 通过流式推理实现了边缘设备上的实时动作识别
    •
