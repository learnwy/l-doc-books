数据增强

核心概念

数据增强通过对训练图像施加各种变换来人工扩大数据集规模和多样性，是深度学习中对抗过拟合、提升模型泛化能力的核心技术。正确使用数据增强通常能带来 2-5 个百分点的准确率提升，其效果往往超过更复杂的模型架构改进。

数据增强的核心原则是保持语义不变性：变换后的图像应该保留原始标签的语义。例如，水平翻转一张猫的图片仍然是猫（语义不变），但如果是数字识别任务，翻转 "6" 会变成 "9"（语义改变），此时就不应使用翻转增强。

几何变换增强
几何变换是最基础也是最常用的数据增强方式。水平翻转（概率通常设为 0.5）几乎适用于所有自然图像任务，是成本最低的增强手段。随机裁剪（Random Crop）通过在图像中随机截取子区域来模拟不同的观察视角和尺度变化，同时迫使模型学习局部特征而非依赖全局布局。


from torchvision import transforms

train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.08, 1.0)),
    transforms.RandomHorizontalFlip(p=0.5),
    transforms.RandomRotation(degrees=15),
    transforms.RandomAffine(degrees=0, translate=(0.1, 0.1), shear=10),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225])
])
在目标检测和实例分割任务中，几何变换必须同步应用于标注信息。翻转图像时，边界框的坐标也需要相应翻转；旋转图像时，边界框需要重新计算外接矩形。分割掩码需要与图像做完全相同的几何变换。这些同步操作在 Albumentations 等专业增强库中有完善的实现。


import albumentations as A

det_transform = A.Compose([
    A.HorizontalFlip(p=0.5),
    A.RandomResizedCrop(640, 640, scale=(0.5, 1.0)),
    A.Rotate(limit=15, border_mode=0),
    A.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
], bbox_params=A.BboxParams(format='pascal_voc', label_fields=['labels']))
随机缩放裁剪（RandomResizedCrop）是 ImageNet 训练的标准增强。它先随机确定裁剪区域的面积比（通常 0.08-1.0）和宽高比（通常 3/4-4/3），然后裁剪并缩放到目标尺寸。这种激进的裁剪策略迫使模型从部分信息中识别目标，极大增强了鲁棒性。


色彩扰动与光照模拟
色彩扰动通过随机调整图像的亮度、对比度、饱和度和色调来模拟不同的光照条件和拍摄设备差异。这类增强对于室外场景（光照变化大）和跨域迁移（不同相机色彩响应不同）特别有效。


from torchvision import transforms

color_transform = transforms.Compose([
    transforms.ColorJitter(
        brightness=0.4,
        contrast=0.4,
        saturation=0.4,
        hue=0.1
    ),
    transforms.RandomGrayscale(p=0.2),
    transforms.GaussianBlur(kernel_size=23, sigma=(0.1, 2.0)),
])
随机灰度化（Random Grayscale）以一定概率将彩色图像转为灰度，迫使模型不过度依赖颜色信息。这在颜色不是关键判别因素的任务中很有效。高斯模糊模拟镜头失焦和运动模糊，增强模型对图像清晰度变化的鲁棒性。


通道随机丢弃（Channel Dropout）和通道重排（Channel Shuffle）是更激进的色彩增强方式。通道丢弃将某个通道的值全部置零，强制模型利用剩余通道信息；通道重排打乱 RGB 通道顺序，防止模型对特定通道排列产生依赖。


Mixup 与 CutMix 混合策略
混合增强通过将两张或多张图像按照特定规则合成新的训练样本来扩展数据分布。这类方法不仅增加了数据多样性，还通过软标签训练起到了标签平滑的正则化效果。


Mixup 对两张图像及其标签进行凸组合：x_new = λ * x1 + (1-λ) * x2，y_new = λ * y1 + (1-λ) * y2，其中 λ 从 Beta 分布中采样。Mixup 生成的半透明混合图像迫使模型学习更平滑的决策边界，对对抗样本也有一定的防御效果。


import torch
import numpy as np

def mixup(images, labels, alpha=0.2):
    lam = np.random.beta(alpha, alpha)
    batch_size = images.size(0)
    index = torch.randperm(batch_size)
    mixed_images = lam * images + (1 - lam) * images[index]
    return mixed_images, labels, labels[index], lam

def cutmix(images, labels, alpha=1.0):
    lam = np.random.beta(alpha, alpha)
    batch_size, _, h, w = images.size()
    index = torch.randperm(batch_size)
    cut_ratio = np.sqrt(1.0 - lam)
    cut_w = int(w * cut_ratio)
    cut_h = int(h * cut_ratio)
    cx = np.random.randint(w)
    cy = np.random.randint(h)
    x1 = np.clip(cx - cut_w // 2, 0, w)
    y1 = np.clip(cy - cut_h // 2, 0, h)
    x2 = np.clip(cx + cut_w // 2, 0, w)
    y2 = np.clip(cy + cut_h // 2, 0, h)
    images[:, :, y1:y2, x1:x2] = images[index, :, y1:y2, x1:x2]
    lam = 1 - (x2 - x1) * (y2 - y1) / (w * h)
    return images, labels, labels[index], lam
CutMix 将一张图像的矩形区域替换为另一张图像的对应区域，标签按面积比混合。相比 Mixup 的全局混合，CutMix 保留了更清晰的局部信息，在分类和检测任务中效果更好。Mosaic 增强将四张图像拼接成一张，是 YOLOv4 引入的检测任务专用增强策略，能在一次前向传播中看到更多小目标。

AutoAugment 与自动搜索
手动设计增强策略需要大量专业知识和实验调参。AutoAugment 将数据增强策略的选择形式化为搜索问题，通过强化学习或其他搜索算法自动找到最优的增强组合。


AutoAugment 在一个包含 15 种基本变换和各自强度、概率的搜索空间中寻找最优策略。每个策略由多个子策略组成，每个子策略包含两个顺序执行的变换操作。搜索过程使用 PPO 强化学习算法，以验证集准确率作为奖励信号。AutoAugment 发现的策略在多个数据集上都超越了手工设计的增强方案。


from torchvision import transforms

auto_aug_transform = transforms.Compose([
    transforms.RandomResizedCrop(224),
    transforms.AutoAugment(policy=transforms.AutoAugmentPolicy.IMAGENET),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225])
])

rand_aug_transform = transforms.Compose([
    transforms.RandomResizedCrop(224),
    transforms.RandAugment(num_ops=2, magnitude=9),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225])
])
RandAugment 大幅简化了搜索空间，只需要两个超参数：每次应用的变换数量 N 和变换强度 M。实验表明，这种简单的随机策略在大多数场景下与 AutoAugment 搜索出的复杂策略效果相当，而且无需昂贵的搜索过程。TrivialAugment 进一步将其简化为单个变换的随机选择，被证明是最具性价比的增强方案。


在实际项目中，推荐的增强方案选择顺序是：首先使用基础的翻转+随机裁剪+色彩扰动，然后加入 RandAugment 或 TrivialAugment 作为自动增强，最后根据任务特点选择性加入 Mixup 或 CutMix。对于数据极度匮乏的场景，可以考虑使用生成模型（如 Stable Diffusion）合成训练数据作为补充。


小结
    

  • 数据增强是对抗过拟合最有效的正则化手段之一，通常能带来显著的性能提升
    • 

  • 几何变换增强需要同步处理标注信息，Albumentations 库提供了完善的支持
    • 

  • 混合增强（Mixup/CutMix）通过软标签训练带来额外的正则化效果
    • 

  • RandAugment 和 TrivialAugment 以极低的调参成本达到了接近自动搜索的效果
    • 

  • 增强策略的选择应遵循语义不变性原则，避免破坏标签语义
    • 

  • 训练时使用增强，推理时不使用增强——这是数据增强的基本使用规则
