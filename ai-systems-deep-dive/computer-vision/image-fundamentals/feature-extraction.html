特征提取

核心概念

特征提取是从原始图像中提取具有区分性的紧凑表示的过程，是连接低级像素数据和高级语义理解的桥梁。特征提取的发展经历了从手工设计到自动学习的范式转变，理解这一演进历程有助于深刻理解深度学习为何能在视觉任务中取得巨大成功。

特征的核心要求是区分性（能区分不同类别）和不变性（对无关变化保持稳定）。好的特征应该对光照变化、几何变换、遮挡等因素具有鲁棒性，同时对类别差异保持敏感。

SIFT 与关键点检测
SIFT（尺度不变特征变换）是计算机视觉历史上最具影响力的手工特征之一。它通过在尺度空间中检测极值点来定位关键点，并为每个关键点生成具有尺度和旋转不变性的 128 维描述子。


SIFT 的工作流程分为四步：尺度空间构建、关键点定位、方向分配和描述子生成。尺度空间通过不同 σ 的高斯模糊构建图像金字塔，然后计算相邻尺度的差分（DoG）来近似 LoG 算子。关键点在 DoG 空间中的极值位置被检测出来，经过亚像素精化和低对比度/边缘响应过滤后保留。每个关键点根据局部梯度统计分配主方向，然后在 16×16 的邻域内计算 4×4×8=128 维的梯度方向直方图作为描述子。


import cv2

img = cv2.imread("scene.jpg", cv2.IMREAD_GRAYSCALE)

sift = cv2.SIFT_create(nfeatures=500)
keypoints, descriptors = sift.detectAndCompute(img, None)

orb = cv2.ORB_create(nfeatures=1000)
kp_orb, des_orb = orb.detectAndCompute(img, None)

bf = cv2.BFMatcher(cv2.NORM_L2)
img2 = cv2.imread("scene2.jpg", cv2.IMREAD_GRAYSCALE)
kp2, des2 = sift.detectAndCompute(img2, None)
matches = bf.knnMatch(descriptors, des2, k=2)

good_matches = []
for m, n in matches:
    if m.distance < 0.75 * n.distance:
        good_matches.append(m)
ORB（Oriented FAST and Rotated BRIEF）是 SIFT 的高效替代方案。它结合 FAST 关键点检测器和 BRIEF 二进制描述子，速度比 SIFT 快两个数量级，同时保持了较好的匹配性能。ORB 使用汉明距离进行描述子匹配，可以利用硬件位运算加速，非常适合实时应用。


特征匹配是关键点特征的典型应用。通过比较两张图像的描述子集合，找到对应的关键点对，进而估计几何变换关系（如单应性矩阵）。Lowe's ratio test 是最常用的匹配筛选策略，通过比较最佳匹配和次佳匹配的距离比来过滤误匹配。


HOG 与梯度直方图特征
HOG（方向梯度直方图）通过统计图像局部区域的梯度方向分布来描述目标形状。它将图像划分为密集的 cell 网格，每个 cell 计算梯度方向的加权直方图，然后在 block 级别进行归一化以增强对光照变化的鲁棒性。


HOG 特征在行人检测中取得了里程碑式的成果。Dalal 和 Triggs 在 2005 年提出的 HOG+SVM 行人检测器是深度学习时代之前的标准方案。HOG 的成功在于它捕获了物体轮廓的形状信息，而不依赖于颜色或纹理的绝对值。


import cv2
import numpy as np

img = cv2.imread("pedestrian.jpg", cv2.IMREAD_GRAYSCALE)
img = cv2.resize(img, (64, 128))

hog = cv2.HOGDescriptor()
descriptor = hog.compute(img)
print(f"HOG 描述子维度: {descriptor.shape}")

hog_detector = cv2.HOGDescriptor()
hog_detector.setSVMDetector(cv2.HOGDescriptor_getDefaultPeopleDetector())
boxes, weights = hog_detector.detectMultiScale(img, winStride=(8, 8))
LBP（局部二值模式）是另一类重要的手工特征，通过比较中心像素与邻域像素的大小关系生成二进制编码。LBP 对灰度单调变化具有不变性，计算极为高效，在纹理分类和人脸识别中广泛使用。Uniform LBP 通过只保留二进制序列中跳变次数不超过 2 的模式来降低维度并提升鲁棒性。


手工特征的共同局限是需要人类专家根据先验知识设计特征提取规则，难以自适应地发现数据中最有价值的模式。这一局限正是深度学习特征提取能够胜出的根本原因。


CNN 特征提取
卷积神经网络（CNN）通过端到端学习自动发现数据驱动的分层特征表示。浅层提取边缘和纹理等低级特征，中间层组合出零件和形状等中级特征，深层则形成语义丰富的高级特征。这种分层特征抽象能力是 CNN 在视觉任务中取得突破性进展的关键。


CNN 的特征提取过程可以分解为卷积（提取局部模式）、非线性激活（引入表达能力）和池化（降维和不变性）三个基本操作的反复组合。残差连接（ResNet）和密集连接（DenseNet）等架构创新解决了深层网络的训练困难，使网络可以堆叠到数百甚至数千层。


import torch
import torchvision.models as models

resnet = models.resnet50(weights=models.ResNet50_Weights.IMAGENET1K_V2)
feature_extractor = torch.nn.Sequential(*list(resnet.children())[:-1])
feature_extractor.eval()

dummy_input = torch.randn(1, 3, 224, 224)
with torch.no_grad():
    features = feature_extractor(dummy_input)
    features = features.flatten(1)
    print(f"ResNet50 特征维度: {features.shape}")
特征金字塔网络（FPN）是多尺度特征提取的标准方案。FPN 通过自顶向下的路径和横向连接，将高分辨率低语义的浅层特征与低分辨率高语义的深层特征融合，生成每个尺度都具有丰富语义信息的特征图。FPN 已经成为目标检测和实例分割模型（如 Faster R-CNN、Mask R-CNN）的标准组件。


预训练特征的迁移是 CNN 特征提取的重要应用模式。在 ImageNet 上预训练的 CNN 提取的特征具有良好的通用性，可以直接用于下游任务的分类器训练（特征冻结），或者作为初始化进行微调。这种范式极大降低了对标注数据的需求。


ViT 与自监督特征
Vision Transformer（ViT）将 Transformer 架构引入视觉领域，通过将图像分割为 patch 序列并利用自注意力机制进行全局交互，获得了不同于 CNN 的特征表示。ViT 的特征具有更强的全局上下文建模能力，在大规模数据上训练时性能超越 CNN。


DINOv2 是当前最强大的视觉自监督学习方法之一。它通过教师-学生蒸馏框架，在不使用任何标签的情况下学习到高质量的视觉特征。DINOv2 的特征在分类、分割、深度估计等多种任务中展现出惊人的通用性，甚至可以直接用于零样本语义分割。


import torch

model = torch.hub.load("facebookresearch/dinov2", "dinov2_vitb14")
model.eval()

dummy_input = torch.randn(1, 3, 518, 518)
with torch.no_grad():
    features = model(dummy_input)
    print(f"DINOv2 特征维度: {features.shape}")

    patch_features = model.forward_features(dummy_input)
    print(f"Patch 特征: {patch_features['x_norm_patchtokens'].shape}")
自监督学习特征的崛起代表了特征提取的新范式。对比学习（SimCLR、MoCo）通过最大化同一图像不同增强视图的特征相似性来学习不变表示；掩码图像建模（MAE）通过预测被遮挡 patch 的像素值来学习重建能力。这些方法不依赖标注数据，能够利用海量无标签图像学习通用特征，正在逐步取代 ImageNet 有监督预训练成为视觉特征提取的新基线。

小结
    

  • 特征提取经历了从手工设计到深度学习自动学习的范式转变
    • 

  • SIFT 和 ORB 在图像匹配和 SLAM 中仍有不可替代的价值
    • 

  • HOG 特征揭示了形状描述的重要性，其思想影响了后续的 CNN 设计
    • 

  • CNN 通过分层卷积实现自动化的多层次特征抽象
    • 

  • FPN 解决了多尺度特征提取问题，成为检测和分割模型的标准组件
    • 

  • ViT 和自监督方法正在重新定义视觉特征提取的范式
    • 

  • DINOv2 等自监督模型产生的通用特征在多种下游任务中表现优异
