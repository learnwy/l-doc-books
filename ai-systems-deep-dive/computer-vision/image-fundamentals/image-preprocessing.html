图像预处理

核心概念

图像预处理是将原始图像转换为适合模型输入的标准化数据的过程。预处理的质量直接影响下游任务的精度和训练稳定性。从简单的尺寸调整到复杂的自适应滤波，预处理涵盖了图像在进入神经网络前的所有变换操作。

预处理管线需要根据具体任务和数据特点进行定制。关键原则是：训练和推理阶段必须使用完全相同的预处理流程，否则会导致训练-推理不一致（train-test skew），严重影响模型性能。

几何变换与尺寸调整
几何变换改变图像的空间排列而不改变像素值本身。最常见的操作包括缩放、旋转、翻转、裁剪和仿射变换。在深度学习中，缩放是最频繁使用的几何变换，因为模型通常要求固定的输入尺寸。


缩放操作的核心是插值算法。当目标尺寸大于原始尺寸时需要上采样（插值），反之需要下采样（抽取）。不同插值方法在速度和质量之间有不同的权衡。最近邻插值速度最快但会产生锯齿；双线性插值是最常用的折中方案；双三次插值质量最高但计算量大。对于分割任务的标签图（label map），必须使用最近邻插值以保持类别索引的整数性。


import cv2
import numpy as np

img = cv2.imread("input.jpg")

resized_bilinear = cv2.resize(img, (224, 224), interpolation=cv2.INTER_LINEAR)
resized_area = cv2.resize(img, (224, 224), interpolation=cv2.INTER_AREA)

h, w = img.shape[:2]
scale = 224 / max(h, w)
new_h, new_w = int(h * scale), int(w * scale)
resized = cv2.resize(img, (new_w, new_h))
padded = np.zeros((224, 224, 3), dtype=np.uint8) + 114
offset_y = (224 - new_h) // 2
offset_x = (224 - new_w) // 2
padded[offset_y:offset_y+new_h, offset_x:offset_x+new_w] = resized
保持宽高比的缩放（letterbox）在目标检测中非常重要。直接拉伸图像会改变目标的宽高比，导致检测框回归不准确。letterbox 方法先等比缩放再填充灰边，确保目标形状不变形。YOLO 系列模型普遍采用这种方式。


仿射变换和透视变换是更通用的几何变换。仿射变换保持平行关系，适用于旋转、缩放、错切等操作；透视变换可以校正拍摄角度导致的梯形畸变，在文档扫描和车牌识别中广泛使用。


滤波与噪声抑制
图像采集过程中不可避免地引入噪声，如传感器热噪声、光子散粒噪声等。滤波操作通过局部或全局的像素值重组来抑制噪声、平滑图像或增强特定频率成分。


线性滤波使用固定的卷积核对图像进行卷积运算。高斯滤波是最常用的平滑滤波器，其核权重服从高斯分布，σ 参数控制平滑程度。均值滤波对核区域内所有像素取平均，计算简单但容易模糊边缘。


import cv2

img = cv2.imread("noisy.jpg")

gaussian = cv2.GaussianBlur(img, (5, 5), sigmaX=1.0)
median = cv2.medianBlur(img, 5)
bilateral = cv2.bilateralFilter(img, d=9, sigmaColor=75, sigmaSpace=75)
中值滤波是非线性滤波器，取核区域的中值作为输出。它对椒盐噪声（脉冲噪声）有很好的抑制效果，同时比高斯滤波更能保持边缘清晰度。双边滤波同时考虑空间距离和像素值差异，在平滑区域进行平滑的同时保持边缘锐利，是保边去噪的经典方法。


在深度学习时代，基于神经网络的去噪方法（如 DnCNN、NAFNet）已经超越了传统滤波器的效果。这些模型可以学习复杂的噪声模式，处理传统方法难以应对的真实场景噪声。但在数据预处理管线中，传统滤波仍然因为速度快、无需训练而广泛使用。


频域滤波通过傅里叶变换将图像从空间域转换到频率域，然后设计频率响应函数进行滤波。低通滤波器抑制高频噪声，高通滤波器增强边缘和细节。在实际工程中，空间域卷积和频域滤波可以互换，但卷积核较大时频域方法计算效率更高。


对比度增强与直方图处理
对比度增强旨在改善图像的视觉质量和特征可区分性。在光照不均匀、低对比度等场景下，适当的对比度增强可以显著提升模型性能。


直方图均衡化是最经典的对比度增强方法。它通过重新映射像素值使输出图像的灰度直方图趋于均匀分布，从而扩展动态范围。全局直方图均衡化对整幅图像使用相同的映射函数，在局部对比度不一致的场景下效果有限。


import cv2
import numpy as np

gray = cv2.imread("dark_image.jpg", cv2.IMREAD_GRAYSCALE)
equalized = cv2.equalizeHist(gray)

clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
enhanced = clahe.apply(gray)

img_color = cv2.imread("dark_image.jpg")
lab = cv2.cvtColor(img_color, cv2.COLOR_BGR2Lab)
l, a, b = cv2.split(lab)
l_enhanced = clahe.apply(l)
enhanced_color = cv2.merge([l_enhanced, a, b])
enhanced_color = cv2.cvtColor(enhanced_color, cv2.COLOR_Lab2BGR)
CLAHE（对比度受限自适应直方图均衡化）解决了全局均衡的局限。它将图像分成小块分别进行直方图均衡，同时通过 clipLimit 参数限制对比度放大的上限，避免噪声过度放大。CLAHE 在医学影像、夜间场景等低对比度数据的预处理中效果显著。


Gamma 校正通过幂函数 output = input^γ 调整图像亮度。γ < 1 使暗部变亮（提亮），γ > 1 使亮部变暗（压暗）。自适应 Gamma 校正可以根据图像的整体亮度自动选择 γ 值，是一种简单有效的亮度归一化方法。


边缘检测与形态学操作
边缘检测提取图像中亮度突变的区域，是传统计算机视觉中最重要的底层操作之一。虽然深度学习可以端到端学习特征，但边缘信息作为辅助输入仍然能提升模型在结构化场景中的表现。


Sobel 算子通过一阶导数近似检测水平和垂直方向的边缘。Laplacian 算子使用二阶导数同时检测所有方向的边缘，但对噪声更加敏感。Canny 边缘检测是最常用的多阶段边缘检测算法，它结合高斯平滑、梯度计算、非极大值抑制和双阈值连接，能够产生细而连续的边缘线。


import cv2

gray = cv2.imread("input.jpg", cv2.IMREAD_GRAYSCALE)

sobel_x = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
sobel_y = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)
sobel_mag = cv2.magnitude(sobel_x, sobel_y)

edges = cv2.Canny(gray, threshold1=50, threshold2=150)

kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
dilated = cv2.dilate(edges, kernel, iterations=1)
closed = cv2.morphologyEx(edges, cv2.MORPH_CLOSE, kernel)
形态学操作基于结构元素对二值或灰度图像进行集合运算。膨胀扩展前景区域，腐蚀缩小前景区域，开运算（先腐蚀后膨胀）去除小噪点，闭运算（先膨胀后腐蚀）填充小孔洞。形态学操作在掩码后处理、连通区域分析和文档图像处理中广泛使用。

小结
    

  • 几何变换中缩放最为常见，保持宽高比的 letterbox 方法在检测任务中至关重要
    • 

  • 滤波选择取决于噪声类型：高斯噪声用高斯滤波，椒盐噪声用中值滤波，保边场景用双边滤波
    • 

  • CLAHE 是最实用的对比度增强方法，在低对比度图像预处理中效果显著
    • 

  • 边缘检测和形态学操作在后处理和辅助特征生成中仍有重要价值
    • 

  • 预处理管线必须保证训练和推理一致，否则会引入 train-test skew
    • 

  • 现代框架（如 torchvision.transforms）提供了便捷的预处理组合接口
