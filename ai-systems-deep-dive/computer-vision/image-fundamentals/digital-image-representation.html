数字图像表示

核心概念

数字图像是由离散像素点组成的二维或多维数组，每个像素携带颜色或亮度信息。计算机视觉的所有操作都建立在对这种离散表示的数学处理之上。理解像素排列方式、色彩空间转换和张量存储格式，是进行任何视觉任务的前提条件。

图像从物理世界到模型输入的过程包含采样、量化和编码三个关键步骤。采样决定了空间分辨率，量化决定了色彩精度，编码方式则影响存储效率和处理速度。

像素与采样量化
数字图像的本质是连续光信号经过空间采样和幅度量化后的离散近似。空间采样将连续的二维光场离散化为有限的像素网格，采样频率必须满足奈奎斯特定理以避免混叠伪影。幅度量化将连续的光强映射到有限的离散级别，8 位量化提供 256 个灰度级，能满足大多数视觉任务的精度需求。


像素坐标系通常以图像左上角为原点，x 轴向右，y 轴向下。需要注意的是，不同库的坐标约定有所差异：OpenCV 使用 (row, col) 即 (y, x) 顺序，而 PIL 使用 (x, y) 顺序。这种差异是图像处理代码中常见的 bug 来源。


import numpy as np
import cv2

img = cv2.imread("image.jpg")
h, w, c = img.shape
pixel = img[100, 200]
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

img_float = img.astype(np.float32) / 255.0
采样率与图像质量之间存在直接关系。低分辨率图像丢失高频细节，导致锯齿和模糊；过高分辨率则增加存储和计算成本。在深度学习中，输入分辨率的选择需要在精度和效率之间权衡。现代目标检测模型（如 YOLOv8）通常使用 640×640 的输入尺寸，而图像分类模型常用 224×224。


量化位深度同样影响信息保留程度。医学影像通常使用 12-16 位深度以保留更多组织对比度信息，而自然图像使用 8 位已经足够。在模型训练中，像素值通常会被归一化到 [0, 1] 或 [-1, 1] 范围，使用 float32 存储。


色彩空间与转换
色彩空间定义了颜色的数学表示方法。不同色彩空间在不同应用场景下各有优势，理解它们的特性和转换方法是图像处理的基本功。


RGB 是最直观的色彩空间，三个通道分别对应红、绿、蓝三原色。大多数显示设备和图像格式使用 RGB 编码。OpenCV 默认读取为 BGR 格式，这是一个重要的注意事项。HSV 色彩空间将颜色分解为色调（H）、饱和度（S）和明度（V），更接近人类对颜色的感知方式，在颜色检测和分割任务中非常实用。Lab 色彩空间设计为感知均匀，L 通道表示亮度，a 和 b 通道表示色度，常用于颜色差异度量和风格迁移。


import cv2

img_bgr = cv2.imread("image.jpg")
img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB)
img_hsv = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2HSV)
img_lab = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2Lab)
img_gray = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2GRAY)
img_yuv = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2YUV)
YCbCr 色彩空间在视频编码中广泛使用，它将亮度（Y）和色度（Cb、Cr）分离，利用人眼对亮度变化更敏感的特性进行色度下采样，从而实现高效压缩。在视频处理和目标检测的视频输入管线中，理解 YCbCr 格式有助于优化解码性能。


色彩空间转换的数学本质是线性或非线性映射。RGB 到灰度的转换是加权求和：Gray = 0.299R + 0.587G + 0.114B，权重反映了人眼对不同颜色的敏感度差异。RGB 到 HSV 的转换涉及非线性运算，需要注意色调角度的环绕特性。


张量表示与内存布局
深度学习框架以多维张量的形式处理图像数据。单张图像表示为 3 维张量，一个批次的图像则为 4 维张量。理解张量的维度顺序和内存布局对于高效数据处理至关重要。


两种主流的维度排列方式是 HWC（Height×Width×Channel）和 CHW（Channel×Height×Width）。OpenCV 和 TensorFlow 默认使用 HWC 格式，而 PyTorch 使用 CHW 格式。维度排列直接影响内存访问模式和卷积运算效率。CHW 格式使得同一通道的像素在内存中连续存放，有利于 GPU 上的卷积计算；HWC 格式则使得同一位置的不同通道值相邻，更适合像素级操作。


import torch
import numpy as np
from torchvision import transforms

img_np = np.random.randint(0, 255, (480, 640, 3), dtype=np.uint8)

transform = transforms.Compose([
    transforms.ToPILImage(),
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225])
])

tensor = transform(img_np)
batch = tensor.unsqueeze(0)
print(f"单张: {tensor.shape}")
print(f"批次: {batch.shape}")
批次维度（N）在训练中用于并行处理多张图像。NCHW 是 PyTorch 的标准格式，NHWC 是 TensorFlow 的标准格式。现代硬件（如 NVIDIA Tensor Core）对 NHWC 格式有原生加速支持，因此 PyTorch 也提供了 channels_last 内存格式作为可选优化。


归一化是将像素值从整数范围映射到浮点范围的过程。transforms.ToTensor() 会自动将 [0, 255] 映射到 [0.0, 1.0]。ImageNet 预训练模型通常还需要使用特定的均值和标准差进行标准化，使数据分布与训练时一致。这一步看似简单，但遗漏或使用错误的归一化参数是导致预训练模型表现异常的最常见原因之一。

JPEG 压缩基于离散余弦变换（DCT），通过丢弃高频信息实现压缩。压缩质量参数（通常为 1-100）控制信息丢弃程度。在构建训练数据集时，反复 JPEG 压缩会引入累积伪影，应尽量保留原始格式或使用无损格式存储。


在深度学习数据管线中，解码速度是瓶颈之一。NVIDIA DALI 和 TurboJPEG 等库提供 GPU 加速的 JPEG 解码，可以显著提升数据加载吞吐量。对于大规模数据集，将图像预先打包为 LMDB、TFRecord 或 WebDataset 等格式，可以减少文件系统 IO 开销。


import cv2
from pathlib import Path

img = cv2.imread("photo.png", cv2.IMREAD_UNCHANGED)
cv2.imwrite("output.jpg", img, [cv2.IMWRITE_JPEG_QUALITY, 95])
cv2.imwrite("output.png", img, [cv2.IMWRITE_PNG_COMPRESSION, 3])

img_16bit = cv2.imread("medical.tiff", cv2.IMREAD_ANYDEPTH)
print(f"dtype: {img_16bit.dtype}, range: [{img_16bit.min()}, {img_16bit.max()}]")
小结
    

  • 数字图像是连续光信号经采样量化后的离散表示，分辨率和位深度决定信息保留程度
    • 

  • 色彩空间的选择影响后续处理效果，RGB 通用、HSV 适合颜色检测、Lab 适合感知度量
    • 

  • 深度学习框架使用张量存储图像，HWC 和 CHW 两种布局各有性能特点
    • 

  • 正确的归一化和标准化是预训练模型正常工作的前提
    • 

  • 图像格式的选择需要在压缩率、质量和读取速度之间权衡
    • 

  • 大规模数据集应使用高效的打包格式和 GPU 解码加速数据加载
