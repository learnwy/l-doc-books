医学影像分析

核心概念

医学影像分析将计算机视觉技术应用于 X 光、CT、MRI、超声和病理切片等医学图像的自动解读。医学 AI 的目标是辅助医生提高诊断效率和准确性，而非替代医生。医学影像数据与自然图像存在显著差异——高位深度、三维体积、标注稀缺和分布偏移等特点使得通用视觉模型不能直接迁移，需要针对性的技术方案。

医学影像分析面临的核心挑战包括：标注数据极度稀缺（专家标注成本极高）、类别严重不均衡（正常远多于异常）、分布偏移（不同设备、不同医院的数据分布差异）和可解释性要求（医生需要理解 AI 的决策依据）。

U-Net 与医学影像分割
U-Net 是医学影像分割的经典基线模型，其对称的编码器-解码器结构配合密集跳跃连接，在小数据集上也能取得出色效果。U-Net 的成功证明了跳跃连接对于恢复医学图像中精细结构（如血管、组织边界）的重要性。


import torch
import torch.nn as nn

class DoubleConv(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(in_ch, out_ch, 3, padding=1),
            nn.BatchNorm2d(out_ch),
            nn.ReLU(),
            nn.Conv2d(out_ch, out_ch, 3, padding=1),
            nn.BatchNorm2d(out_ch),
            nn.ReLU(),
        )

    def forward(self, x):
        return self.conv(x)

class UNet(nn.Module):
    def __init__(self, in_channels=1, num_classes=2):
        super().__init__()
        self.enc1 = DoubleConv(in_channels, 64)
        self.enc2 = DoubleConv(64, 128)
        self.enc3 = DoubleConv(128, 256)
        self.bottleneck = DoubleConv(256, 512)
        self.up3 = nn.ConvTranspose2d(512, 256, 2, 2)
        self.dec3 = DoubleConv(512, 256)
        self.up2 = nn.ConvTranspose2d(256, 128, 2, 2)
        self.dec2 = DoubleConv(256, 128)
        self.up1 = nn.ConvTranspose2d(128, 64, 2, 2)
        self.dec1 = DoubleConv(128, 64)
        self.out = nn.Conv2d(64, num_classes, 1)
        self.pool = nn.MaxPool2d(2)

    def forward(self, x):
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        e3 = self.enc3(self.pool(e2))
        b = self.bottleneck(self.pool(e3))
        d3 = self.dec3(torch.cat([self.up3(b), e3], dim=1))
        d2 = self.dec2(torch.cat([self.up2(d3), e2], dim=1))
        d1 = self.dec1(torch.cat([self.up1(d2), e1], dim=1))
        return self.out(d1)
nnU-Net 是医学影像分割的"自适应框架"。它根据数据集的特性（图像尺寸、间距、类别数量等）自动配置网络架构、训练策略和后处理流水线，在 30+ 个医学分割基准上达到了最优或接近最优的性能，无需人工调参。


SwinUNETR 将 Swin Transformer 作为编码器引入医学影像分割，通过窗口化自注意力高效处理三维医学体积数据。在 BraTS 脑肿瘤分割和 BTCV 多器官分割等基准上，SwinUNETR 展现出了超越纯 CNN 方法的性能。


小数据学习与预训练策略
医学影像标注需要领域专家（放射科医生、病理医生），标注成本极高。解决标注数据稀缺问题的主要策略包括：自监督预训练、半监督学习和主动学习。


医学影像的自监督预训练方法包括：对比学习（将同一患者不同视角或时相的图像作为正样本对）、掩码建模（随机遮挡三维体积的部分区域并预测被遮挡内容）和生成式预训练（重建去噪图像）。这些方法在仅有少量标注数据时显著提升下游任务性能。


import torch
import torch.nn as nn

class MedicalSSL(nn.Module):
    def __init__(self, encoder, proj_dim=128):
        super().__init__()
        self.encoder = encoder
        self.projector = nn.Sequential(
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Linear(256, proj_dim),
        )

    def contrastive_loss(self, z1, z2, temperature=0.07):
        z1 = nn.functional.normalize(z1, dim=1)
        z2 = nn.functional.normalize(z2, dim=1)
        similarity = torch.mm(z1, z2.T) / temperature
        labels = torch.arange(z1.size(0), device=z1.device)
        loss = nn.functional.cross_entropy(similarity, labels)
        return loss

    def forward(self, view1, view2):
        h1 = self.encoder(view1).mean(dim=(-2, -1))
        h2 = self.encoder(view2).mean(dim=(-2, -1))
        z1 = self.projector(h1)
        z2 = self.projector(h2)
        return self.contrastive_loss(z1, z2)
SAM-Med2D 和 MedSAM 将 Segment Anything Model 适配到医学影像领域，通过在大规模医学分割数据上微调 SAM，实现了通用的交互式医学影像分割。用户可以通过点击或框选来指导分割，大幅降低了标注工作量。

小结
    

  • 医学影像与自然图像差异显著，需要针对性的技术方案
    • 

  • U-Net 是医学分割的经典基线，nnU-Net 通过自动配置在大量基准上达到最优
    • 

  • 标注数据稀缺是医学 AI 的核心瓶颈，自监督预训练和 MedSAM 是有效的解决方案
    • 

  • Dice Loss 和 Dice + CrossEntropy 组合是医学分割训练的标准损失函数
    • 

  • 可解释性对于临床部署至关重要，GradCAM 等方法帮助医生理解模型决策
    • 

  • 医学 AI 产品需要通过严格的监管审批流程才能用于临床
