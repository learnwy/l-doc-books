OCR 与文档处理

核心概念

OCR（Optical Character Recognition，光学字符识别）将图像中的文字内容转换为可编辑的电子文本。现代 OCR 系统已经从单纯的字符识别发展为完整的文档理解系统，涵盖文字检测、文字识别、版面分析和结构化信息提取四大能力。

OCR 面临的核心挑战包括：自然场景中的复杂背景、不规则排列的文字（弯曲、旋转、透视变形）、多语言混排、手写体识别以及低质量图像（模糊、低分辨率、光照不均）。文档级理解还需要处理表格、公式和图表等复杂版面结构。

文字检测方法
文字检测负责定位图像中所有文字区域的精确位置。不同于通用目标检测，文字具有极端的宽高比（细长文字行）和不规则形状（弯曲文字），需要专门设计的检测方法。


DBNet（Differentiable Binarization Network）是当前最流行的文字检测方法之一。它通过可微分的二值化操作替代了传统的后处理阈值化步骤，使得整个检测流水线可以端到端训练。DBNet 预测三个图：概率图（文字区域概率）、阈值图（自适应阈值）和二值图（最终检测结果），其中阈值图使得模型能够为不同区域学习不同的阈值。


import torch
import torch.nn as nn

class DBHead(nn.Module):
    def __init__(self, in_channels):
        super().__init__()
        self.probability = nn.Sequential(
            nn.Conv2d(in_channels, in_channels // 4, 3, padding=1),
            nn.BatchNorm2d(in_channels // 4),
            nn.ReLU(),
            nn.ConvTranspose2d(in_channels // 4, in_channels // 4, 2, 2),
            nn.Conv2d(in_channels // 4, 1, 1),
            nn.Sigmoid(),
        )
        self.threshold = nn.Sequential(
            nn.Conv2d(in_channels, in_channels // 4, 3, padding=1),
            nn.BatchNorm2d(in_channels // 4),
            nn.ReLU(),
            nn.ConvTranspose2d(in_channels // 4, in_channels // 4, 2, 2),
            nn.Conv2d(in_channels // 4, 1, 1),
            nn.Sigmoid(),
        )

    def forward(self, x):
        prob = self.probability(x)
        thresh = self.threshold(x)
        binary = self.step_function(prob, thresh)
        return prob, thresh, binary

    def step_function(self, prob, thresh, k=50):
        return torch.reciprocal(1.0 + torch.exp(-k * (prob - thresh)))
EAST（Efficient and Accurate Scene Text Detector）直接在每个像素位置回归到文字框四条边的距离和旋转角度，无需锚框设计。对于弯曲文字，FCENet 使用傅里叶轮廓编码来表示任意形状的文字区域。


文字识别与序列解码
文字识别将检测到的文字行图像转换为字符序列。这是一个图像到序列（Image-to-Sequence）的问题，核心挑战在于字符数量不固定、字符间距不均匀以及字体样式多变。


CRNN（Convolutional Recurrent Neural Network）是经典的文字识别架构。它由 CNN 特征提取器、BiLSTM 序列建模器和 CTC（Connectionist Temporal Classification）解码器三部分组成。CNN 将图像编码为特征序列，BiLSTM 建模字符间的上下文关系，CTC 解码处理输入-输出长度不对齐的问题。


import torch
import torch.nn as nn

class CRNNRecognizer(nn.Module):
    def __init__(self, num_chars, hidden_size=256):
        super().__init__()
        self.cnn = nn.Sequential(
            nn.Conv2d(1, 64, 3, 1, 1), nn.ReLU(), nn.MaxPool2d(2, 2),
            nn.Conv2d(64, 128, 3, 1, 1), nn.ReLU(), nn.MaxPool2d(2, 2),
            nn.Conv2d(128, 256, 3, 1, 1), nn.ReLU(),
            nn.Conv2d(256, 256, 3, 1, 1), nn.ReLU(), nn.MaxPool2d((2, 1)),
            nn.Conv2d(256, 512, 3, 1, 1), nn.BatchNorm2d(512), nn.ReLU(),
        )
        self.rnn = nn.LSTM(512, hidden_size, num_layers=2, bidirectional=True, batch_first=True)
        self.fc = nn.Linear(hidden_size * 2, num_chars)

    def forward(self, x):
        features = self.cnn(x)
        b, c, h, w = features.shape
        features = features.squeeze(2).permute(0, 2, 1)
        rnn_out, _ = self.rnn(features)
        output = self.fc(rnn_out)
        return output
基于注意力的方法（如 ABINet、PARSeq）使用 Transformer 解码器替代 CTC，通过注意力机制隐式对齐图像特征和字符序列。TrOCR 直接将预训练的视觉 Transformer 和语言模型组合，在打印体和手写体识别上都取得了最佳效果。

版面分析与文档理解
版面分析将文档图像划分为不同的语义区域（标题、段落、表格、图片等），是文档结构化理解的基础。传统方法使用规则匹配和连通域分析，现代方法则使用深度学习进行区域检测和分类。


LayoutLM 系列将文档的文本内容、视觉特征和空间位置信息融合进行多模态预训练，实现了文档理解的多种下游任务。LayoutLMv3 使用统一的 Transformer 架构同时处理文本和图像 patch，在文档分类、信息提取和表格理解等任务上都取得了出色效果。


from paddleocr import PaddleOCR

ocr = PaddleOCR(use_angle_cls=True, lang='ch')

result = ocr.ocr('document.jpg', cls=True)
for line in result[0]:
    bbox = line[0]
    text = line[1][0]
    confidence = line[1][1]
    print(f"文字: {text}, 置信度: {confidence:.3f}")
PaddleOCR 是百度开源的工业级 OCR 解决方案，提供了完整的文字检测（DB/EAST）、方向分类和文字识别（CRNN/SVTR）流水线，支持 80+ 语言，在中文场景下效果尤其出色。PP-OCRv4 通过知识蒸馏和模型压缩实现了移动端实时部署。


小结
    

  • OCR 系统由文字检测、识别和版面分析三大模块组成
    • 

  • DBNet 通过可微二值化实现了高效精确的文字检测
    • 

  • CRNN + CTC 是文字识别的经典架构，Transformer 方法正逐步取代
    • 

  • PaddleOCR 是最完善的开源 OCR 工具链，中文效果优异
    • 

  • 版面分析和文档理解需要多模态融合，LayoutLMv3 是主流方案
    • 

  • 实际项目中推荐使用 PaddleOCR 或 EasyOCR 作为起点快速构建原型
