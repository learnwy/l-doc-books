细粒度识别

核心概念

细粒度识别（Fine-Grained Visual Recognition）是图像分类的一个特殊子领域，其目标是区分外观高度相似的子类别，如不同品种的鸟类、不同型号的汽车、不同种类的花卉。与普通分类任务的类间差异显著不同，细粒度识别面临的核心挑战是类间差异小而类内差异大：同一品种的鸟在不同姿态和光照下可能差异巨大，而不同品种的鸟可能仅在喙部形状或羽毛颜色上有微小区别。

注意力驱动的特征聚焦
注意力机制是细粒度识别中最核心的技术方向。通过让模型自动发现和聚焦最具判别性的局部区域，注意力机制能够有效放大类间差异信号。


通道注意力（如 SE-Net）通过对每个通道的全局信息进行建模，学习不同特征通道的重要性权重。空间注意力则学习不同空间位置的重要性，引导模型关注判别性区域。CBAM 将两者串联使用，先进行通道注意力再进行空间注意力。


import torch
import torch.nn as nn

class ChannelAttention(nn.Module):
    def __init__(self, channels, reduction=16):
        super().__init__()
        self.avg_pool = nn.AdaptiveAvgPool2d(1)
        self.max_pool = nn.AdaptiveMaxPool2d(1)
        self.fc = nn.Sequential(
            nn.Linear(channels, channels // reduction),
            nn.ReLU(),
            nn.Linear(channels // reduction, channels),
        )
        self.sigmoid = nn.Sigmoid()

    def forward(self, x):
        b, c, _, _ = x.size()
        avg_out = self.fc(self.avg_pool(x).view(b, c))
        max_out = self.fc(self.max_pool(x).view(b, c))
        return x * self.sigmoid(avg_out + max_out).view(b, c, 1, 1)
多粒度注意力是细粒度识别的另一个重要方向。MA-CNN（Multi-Attention CNN）同时学习多个注意力图，每个关注图像的不同判别区域（如鸟的头部、翅膀、尾巴），然后将各区域的特征融合进行分类。这种方法不需要部件标注，通过正交约束或多样性损失确保不同注意力关注不同区域。


双线性池化与高阶特征
双线性池化（Bilinear Pooling）通过计算两个特征提取器输出的外积来捕获特征之间的二阶交互关系。这种高阶特征表示在细粒度识别中非常有效，因为它能够编码特征通道之间的相关性模式——例如"红色+尖喙"的共现模式对于识别特定鸟类至关重要。


原始双线性池化生成的特征维度极高（d²），计算和存储成本很大。紧凑双线性池化（Compact Bilinear Pooling）通过随机投影将特征维度降低到可接受的范围。低秩双线性池化进一步通过矩阵分解减少参数量。


import torch
import torch.nn as nn

class BilinearPooling(nn.Module):
    def __init__(self, in_features, out_features):
        super().__init__()
        self.proj = nn.Linear(in_features ** 2, out_features)

    def forward(self, x):
        b, c, h, w = x.size()
        x = x.view(b, c, h * w)
        bilinear = torch.bmm(x, x.transpose(1, 2))
        bilinear = bilinear.view(b, -1)
        bilinear = torch.sign(bilinear) * torch.sqrt(torch.abs(bilinear) + 1e-12)
        bilinear = nn.functional.normalize(bilinear, p=2, dim=1)
        return self.proj(bilinear)
iSQRT-COV 方法对协方差矩阵进行矩阵平方根归一化，比直接使用外积更稳定且效果更好。DeepKSPD 进一步探索了更丰富的核空间特征表示。这些方法的共同思路是利用特征的高阶统计量来提升表示的区分性。


ViT 与 Transformer 方法
Vision Transformer 的自注意力机制天然适合细粒度识别，因为它能够建模图像中任意两个 patch 之间的关系，自动发现和聚焦判别性区域。TransFG 将 ViT 的注意力图作为选择信号，从所有 patch token 中筛选出最重要的部分进行二次精细编码。


import torch
import torch.nn as nn

class TransFG(nn.Module):
    def __init__(self, vit_model, num_classes):
        super().__init__()
        self.vit = vit_model
        self.head = nn.Linear(768, num_classes)
        self.part_head = nn.Linear(768, num_classes)

    def forward(self, x):
        tokens, attn_weights = self.vit.forward_features_with_attn(x)
        cls_token = tokens[:, 0]

        last_attn = attn_weights[-1]
        cls_attn = last_attn[:, :, 0, 1:].mean(dim=1)

        top_k = 12
        _, top_indices = cls_attn.topk(top_k, dim=1)

        part_tokens = torch.gather(
            tokens[:, 1:], 1,
            top_indices.unsqueeze(-1).expand(-1, -1, 768)
        )
        part_feature = part_tokens.mean(dim=1)

        global_logits = self.head(cls_token)
        part_logits = self.part_head(part_feature)
        return global_logits + part_logits
HERBS（High-resolution Enhanced Robust Bilinear Softmax）结合了高分辨率输入和双线性特征，在细粒度基准测试中取得了领先结果。高分辨率输入保留了更多细节信息，而双线性特征捕获了通道间的高阶关系。

小结
    

  • 细粒度识别的核心挑战是类间差异小、类内差异大，需要聚焦局部判别区域
    • 

  • 注意力机制是最有效的技术方向，多粒度注意力能自动发现多个判别性部件
    • 

  • 双线性池化捕获特征的高阶交互关系，提升细粒度特征的区分能力
    • 

  • Vision Transformer 的自注意力天然适合细粒度任务，TransFG 等方法表现优异
    • 

  • 高分辨率输入对细粒度识别至关重要，因为关键判别信息常存在于微小细节中
    • 

  • 实际项目中推荐使用 ViT 预训练模型 + 注意力引导微调作为基线方案
