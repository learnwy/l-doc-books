分类流水线设计

核心概念

图像分类流水线是将原始图像转换为类别预测的端到端系统。一个完整的分类流水线包含数据准备、模型架构选择、训练策略配置、评估验证和部署推理五个阶段。理解每个阶段的关键决策点和最佳实践，是构建高质量分类系统的前提。

分类模型的核心思路是将图像通过特征提取器映射为高维特征向量，再通过分类头（通常是全连接层+Softmax）输出各类别的概率分布。交叉熵损失函数衡量预测分布与真实标签之间的差异，梯度下降优化器不断调整网络参数以最小化这一差异。

数据准备与类别均衡
高质量的训练数据是分类模型性能的根基。数据准备阶段需要关注数据清洗、标注质量验证、数据集划分和类别均衡四个方面。


数据集应划分为训练集、验证集和测试集三部分，且划分应保持类别比例一致（分层划分）。验证集用于超参数调优和早停判断，测试集仅在最终评估时使用一次，避免对测试集过拟合。在数据量不足的场景下，可以使用 k 折交叉验证来更稳定地评估模型性能。


from torch.utils.data import DataLoader, WeightedRandomSampler
import torchvision.datasets as datasets
import numpy as np

train_dataset = datasets.ImageFolder("data/train", transform=train_transform)

class_counts = np.bincount([label for _, label in train_dataset])
class_weights = 1.0 / class_counts
sample_weights = [class_weights[label] for _, label in train_dataset]

sampler = WeightedRandomSampler(sample_weights, len(sample_weights))
train_loader = DataLoader(train_dataset, batch_size=32, sampler=sampler, num_workers=4)
类别不均衡是实际项目中的常见问题。当某些类别的样本数远多于其他类别时，模型会倾向于预测多数类，导致少数类的召回率极低。解决方案包括：加权采样（WeightedRandomSampler）使每个类别被采样的频率相同；加权损失函数（将少数类的损失放大）；过采样少数类或欠采样多数类。Focal Loss 通过降低容易分类样本的权重来聚焦难样本，在极端不均衡场景下表现优异。


经典架构演进
图像分类模型架构经历了从浅层 CNN 到深层残差网络，再到 Transformer 的演进。理解这一演进脉络有助于在实际项目中做出正确的架构选择。


ResNet 通过引入跳跃连接解决了深层网络的梯度消失问题，使网络可以训练到 100 层以上。ResNet-50 至今仍是最常用的骨干网络之一，在速度和精度之间有着良好的平衡。EfficientNet 通过复合缩放（同时缩放深度、宽度和分辨率）实现了帕累托最优的效率-精度权衡。


import torch
import torchvision.models as models

resnet50 = models.resnet50(weights=models.ResNet50_Weights.IMAGENET1K_V2)
num_classes = 10
resnet50.fc = torch.nn.Linear(resnet50.fc.in_features, num_classes)

convnext = models.convnext_tiny(weights=models.ConvNeXt_Tiny_Weights.IMAGENET1K_V1)
convnext.classifier[2] = torch.nn.Linear(convnext.classifier[2].in_features, num_classes)
ConvNeXt 将 Transformer 的设计理念（大核卷积、LayerNorm、GELU 激活等）引入 CNN，在 ImageNet 上达到了与 Swin Transformer 相当的性能，同时保持了 CNN 的简洁性和推理效率。在部署约束较强的场景下，ConvNeXt 是比 ViT 更务实的选择。


训练策略与超参数调优
训练策略的选择对最终性能有着决定性影响。现代分类模型训练通常采用预训练+微调的范式，配合精心设计的学习率调度、正则化和数据增强策略。


学习率是最关键的超参数。余弦退火（Cosine Annealing）是当前最流行的学习率调度策略，它在训练过程中平滑地将学习率从初始值降至接近零，避免了阶梯式衰减的突变问题。Warmup 阶段在训练初期使用较小的学习率逐步增加到目标值，有助于稳定训练初期的梯度。


import torch
from torch.optim.lr_scheduler import CosineAnnealingLR

model = models.resnet50(weights=models.ResNet50_Weights.IMAGENET1K_V2)
model.fc = torch.nn.Linear(model.fc.in_features, num_classes)

optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.05)
scheduler = CosineAnnealingLR(optimizer, T_max=100, eta_min=1e-6)

criterion = torch.nn.CrossEntropyLoss(label_smoothing=0.1)
标签平滑（Label Smoothing）将硬标签 [0, 0, 1, 0] 软化为 [0.033, 0.033, 0.9, 0.033]，防止模型对训练集过度自信。结合 Mixup/CutMix 的软标签训练，可以进一步提升模型的泛化能力。

评估指标与错误分析
正确选择评估指标和进行系统的错误分析是提升模型性能的关键步骤。准确率（Accuracy）是最直观的指标，但在类别不均衡场景下可能产生误导。


精确率（Precision）衡量预测为正类的样本中实际为正的比例，召回率（Recall）衡量实际为正的样本中被正确检出的比例。F1-Score 是两者的调和平均数，在正负样本不均衡时比准确率更有参考价值。混淆矩阵可以直观展示每个类别的分类情况，帮助发现系统性的混淆模式。


from sklearn.metrics import classification_report, confusion_matrix
import numpy as np

y_true = np.array([0, 1, 2, 0, 1, 2, 0, 1, 2])
y_pred = np.array([0, 1, 1, 0, 2, 2, 0, 1, 0])

print(classification_report(y_true, y_pred, target_names=["cat", "dog", "bird"]))
cm = confusion_matrix(y_true, y_pred)
print(f"混淆矩阵:\n{cm}")
错误分析应从以下几个维度展开：首先查看混淆矩阵找出最容易混淆的类别对；然后可视化高置信度的错误预测样本，分析是标注错误、数据质量问题还是模型能力不足；最后统计不同子群体（如不同光照、不同角度）的准确率分布，发现模型的系统性弱点。GradCAM 等可视化工具可以展示模型关注的图像区域，帮助判断模型是否学到了正确的特征。


小结
    

  • 数据准备阶段需要关注类别均衡问题，WeightedRandomSampler 和 Focal Loss 是常用解决方案
    • 

  • ResNet-50 仍是通用性最好的骨干网络，ConvNeXt 在追求更高精度时值得考虑
    • 

  • AdamW + 余弦退火 + Warmup 是现代分类模型训练的标准配置
    • 

  • 标签平滑和 Mixup/CutMix 提供了有效的正则化效果
    • 

  • 评估时应结合准确率、F1-Score 和混淆矩阵进行多维分析
    • 

  • 错误分析和 GradCAM 可视化是迭代优化模型的重要工具
