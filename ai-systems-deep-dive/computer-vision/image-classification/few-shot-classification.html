小样本分类

核心概念

小样本分类（Few-Shot Classification）旨在解决"如何仅用少量标注样本学会识别新类别"的问题。传统深度学习模型需要大量标注数据才能有效训练，而人类仅凭几张甚至一张图片就能识别新物体。小样本学习试图弥合这一差距，使模型具备快速学习新概念的能力。

小样本分类的标准设置是 N-way K-shot：从未见过的类别中选取 N 个类，每个类只提供 K 个标注样本（支持集），模型需要对新的查询样本进行分类。常见的设置包括 5-way 1-shot（5 类各 1 样本）和 5-way 5-shot（5 类各 5 样本）。

度量学习方法
度量学习是小样本分类中最直观也最实用的方法族。核心思路是学习一个嵌入空间，在该空间中同类样本距离近、异类样本距离远，然后通过最近邻或原型比较进行分类。


Prototypical Networks 是度量学习方法的经典代表。它为每个类别计算支持集样本嵌入的均值作为类原型（prototype），查询样本通过与各类原型的欧氏距离进行分类。Prototypical Networks 简单高效且效果出色，是小样本分类的标准基线。


import torch
import torch.nn as nn
import torch.nn.functional as F

class PrototypicalNet(nn.Module):
    def __init__(self, encoder):
        super().__init__()
        self.encoder = encoder

    def forward(self, support, query, n_way, k_shot):
        support_emb = self.encoder(support)
        query_emb = self.encoder(query)

        support_emb = support_emb.view(n_way, k_shot, -1)
        prototypes = support_emb.mean(dim=1)

        dists = torch.cdist(query_emb, prototypes)
        logits = -dists
        return logits

def episodic_training(model, data_loader, optimizer, n_way=5, k_shot=1, n_query=15):
    model.train()
    for support, query, labels in data_loader:
        logits = model(support, query, n_way, k_shot)
        loss = F.cross_entropy(logits, labels)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
Matching Networks 使用注意力机制代替简单的最近邻，为支持集中每个样本分配不同权重。Relation Network 将距离度量替换为可学习的关系网络，通过 CNN 学习两个嵌入之间的相似度函数，理论上能捕获比欧氏距离更复杂的关系。


嵌入网络的质量是度量学习方法的关键。使用在大规模数据集上预训练的强大编码器（如 ResNet-12、ViT）作为嵌入网络，配合简单的 Prototypical Networks，通常就能达到非常好的效果。


MAML 与元学习
MAML（Model-Agnostic Meta-Learning）从元学习的视角解决小样本问题。其核心思想是：学习一组模型参数初始化，使得从这个初始化出发，仅需少量梯度更新步骤就能快速适应任何新任务。


MAML 的训练过程包含内循环和外循环两层优化。内循环在每个 episode 的支持集上进行少量梯度下降步骤（通常 1-5 步），得到任务特定的参数；外循环则根据这些适应后的参数在查询集上的表现来更新元参数（初始化参数）。这种"学习如何学习"的范式使模型获得了快速适应新任务的能力。


import torch
import torch.nn as nn
import torch.nn.functional as F

class MAML(nn.Module):
    def __init__(self, model, inner_lr=0.01, inner_steps=5):
        super().__init__()
        self.model = model
        self.inner_lr = inner_lr
        self.inner_steps = inner_steps

    def inner_loop(self, support_x, support_y):
        fast_weights = {name: param.clone() for name, param in self.model.named_parameters()}

        for _ in range(self.inner_steps):
            logits = self.model.functional_forward(support_x, fast_weights)
            loss = F.cross_entropy(logits, support_y)
            grads = torch.autograd.grad(loss, fast_weights.values(), create_graph=True)
            fast_weights = {
                name: param - self.inner_lr * grad
                for (name, param), grad in zip(fast_weights.items(), grads)
            }
        return fast_weights

    def forward(self, support_x, support_y, query_x):
        fast_weights = self.inner_loop(support_x, support_y)
        query_logits = self.model.functional_forward(query_x, fast_weights)
        return query_logits
MAML 的计算成本较高，因为外循环需要对内循环的梯度进行二阶求导。ANIL（Almost No Inner Loop）发现只需要对最后一层进行内循环更新就够了，大幅降低了计算量。Meta-SGD 进一步将内循环的学习率也作为可学习参数。

基于预训练模型的提示学习
随着 CLIP 等大规模视觉-语言预训练模型的出现，小样本分类迎来了新的范式。通过设计合适的提示（prompt），可以在几乎不修改模型参数的情况下将预训练模型适配到目标任务。


CoOp（Context Optimization）将 CLIP 的文本提示从手工设计改为可学习的连续向量。只需要在少量标注样本上优化这些提示向量，就能显著提升 CLIP 在特定任务上的分类性能。CoCoOp 进一步引入了条件化机制，使提示能够根据输入图像动态调整。


import torch
import torch.nn as nn

class CoOpPromptLearner(nn.Module):
    def __init__(self, clip_model, n_ctx=16, num_classes=10):
        super().__init__()
        ctx_dim = clip_model.text_encoder.embed_dim
        self.ctx = nn.Parameter(torch.randn(n_ctx, ctx_dim))
        self.class_token_ids = self._init_class_tokens(num_classes)
        self.clip_model = clip_model

    def forward(self):
        ctx = self.ctx.unsqueeze(0).expand(len(self.class_token_ids), -1, -1)
        class_embeddings = self.clip_model.token_embedding(self.class_token_ids)
        prompts = torch.cat([ctx, class_embeddings], dim=1)
        return prompts

class CLIPAdapter(nn.Module):
    def __init__(self, clip_model, alpha=0.2):
        super().__init__()
        self.clip_model = clip_model
        self.alpha = alpha
        self.adapter = nn.Sequential(
            nn.Linear(512, 128),
            nn.ReLU(),
            nn.Linear(128, 512)
        )

    def forward(self, images, text_features):
        image_features = self.clip_model.encode_image(images)
        adapted = self.adapter(image_features)
        image_features = self.alpha * adapted + (1 - self.alpha) * image_features
        logits = image_features @ text_features.T
        return logits
CLIP-Adapter 和 Tip-Adapter 通过在 CLIP 的特征空间中添加轻量级适配层来实现小样本适应。这些方法仅需优化极少量参数（几千到几万个），在 1-shot 和 few-shot 设置下都展现出了优异的性能。


小结
    

  • 小样本分类的标准设置是 N-way K-shot，通过 episode 训练评估模型的快速适应能力
    • 

  • Prototypical Networks 是最实用的基线方法，配合强大的预训练编码器效果出色
    • 

  • MAML 提供了优雅的元学习框架，但计算成本高且训练不稳定
    • 

  • 基于 CLIP 的提示学习方法代表了小样本分类的新范式，性能和效率都大幅领先
    • 

  • 实际项目中推荐优先尝试 CLIP + 提示学习/适配器方案
    • 

  • 嵌入网络的质量（预训练模型的选择）往往比学习算法本身更重要
