迁移学习在视觉中的应用

核心概念

迁移学习是将在大规模数据集（如 ImageNet）上预训练的模型知识迁移到目标任务的技术。在计算机视觉中，迁移学习已经成为默认的实践范式——几乎没有人会从零开始训练一个视觉模型。预训练模型提供的通用视觉特征能够显著减少对标注数据的需求，加速训练收敛，并提升最终性能。

迁移学习的有效性建立在一个重要假设上：低层视觉特征（边缘、纹理、颜色）具有跨任务的通用性。实证研究表明，CNN 的前几层学到的滤波器在不同任务间高度相似，而深层特征则逐渐变得任务特定。

预训练范式演进
视觉预训练经历了三个主要阶段。第一阶段是 ImageNet 有监督预训练，ResNet 等模型在 ImageNet-1K 的 128 万张图像上训练分类任务，学到的特征成为下游任务的标准初始化。第二阶段是大规模弱监督预训练，如 CLIP 使用 4 亿图文对进行对比学习，学到的特征具有零样本泛化能力。第三阶段是自监督预训练，MAE、DINOv2 等方法不依赖任何标签，仅通过图像自身的结构信息学习表示。


import torch
import torchvision.models as models
from torchvision.models import ResNet50_Weights

model = models.resnet50(weights=ResNet50_Weights.IMAGENET1K_V2)

for param in model.parameters():
    param.requires_grad = False
model.fc = torch.nn.Linear(model.fc.in_features, 10)
CLIP 模型通过对比学习将图像和文本映射到共享的嵌入空间，使得模型能够通过自然语言描述来理解图像内容。这种能力使 CLIP 可以在不进行任何微调的情况下完成零样本分类：只需将类别名称转换为文本嵌入，与图像嵌入计算相似度即可。


DINOv2 在 1.42 亿张无标签图像上训练，产生的特征在分类、分割、深度估计等多种任务中都表现优异。它使用教师-学生蒸馏框架，教师网络的参数是学生网络的指数移动平均。这种自监督方法不需要任何人工标注，代表了视觉预训练的未来方向。


微调策略与技巧
微调是迁移学习中最关键的环节。正确的微调策略能够在保留预训练知识的同时有效适应目标任务，错误的策略则可能导致灾难性遗忘或过拟合。


分层学习率（Layer-wise Learning Rate Decay）为网络的不同深度设置不同的学习率：浅层使用较小的学习率以保留通用特征，深层使用较大的学习率以适应目标任务。典型的衰减因子为 0.65-0.75，即每向浅一层学习率缩小为上一层的 65%-75%。


import torch

def get_layer_lr_decay_params(model, base_lr, decay_rate=0.7):
    param_groups = []
    layers = list(model.named_parameters())
    num_layers = len(set(name.split('.')[0] for name, _ in layers))

    for name, param in layers:
        depth = int(name.split('.')[1]) if name.split('.')[0] == 'layer' else 0
        lr = base_lr * (decay_rate ** (num_layers - depth))
        param_groups.append({'params': param, 'lr': lr})

    return param_groups

model = models.resnet50(weights=ResNet50_Weights.IMAGENET1K_V2)
model.fc = torch.nn.Linear(model.fc.in_features, 10)

optimizer = torch.optim.AdamW([
    {'params': model.layer1.parameters(), 'lr': 1e-5},
    {'params': model.layer2.parameters(), 'lr': 3e-5},
    {'params': model.layer3.parameters(), 'lr': 7e-5},
    {'params': model.layer4.parameters(), 'lr': 1e-4},
    {'params': model.fc.parameters(), 'lr': 3e-4},
], weight_decay=0.01)
渐进式解冻（Gradual Unfreezing）是另一种有效的微调策略。先冻结所有预训练层只训练分类头若干轮，然后从最后一层开始逐步解冻更多层。这种策略避免了训练初期因随机初始化的分类头产生的大梯度破坏预训练特征。


微调的学习率通常比从头训练低 10-100 倍。对于 ImageNet 预训练模型，分类头的学习率通常为 1e-3 到 3e-4，骨干网络为 1e-5 到 1e-4。使用过大的学习率会导致预训练知识被快速覆盖（灾难性遗忘），使用过小的学习率则适应不足。


领域自适应
当源域（预训练数据）和目标域（应用数据）之间存在显著的分布差异时（如自然图像→医学影像，白天→夜间），直接微调的效果可能不理想。领域自适应技术通过减小域间差异来提升迁移效果。


无监督领域自适应（UDA）在目标域没有标注数据的情况下进行迁移。核心思路是学习一个域不变的特征表示，使得来自不同域的同类样本在特征空间中相近。常用方法包括对抗训练（域判别器+梯度反转层）和分布对齐（MMD、CORAL）。


import torch
import torch.nn as nn

class DomainAdaptationModel(nn.Module):
    def __init__(self, backbone, num_classes):
        super().__init__()
        self.backbone = backbone
        self.classifier = nn.Linear(2048, num_classes)
        self.domain_discriminator = nn.Sequential(
            nn.Linear(2048, 1024),
            nn.ReLU(),
            nn.Linear(1024, 1)
        )

    def forward(self, x, alpha=1.0):
        features = self.backbone(x)
        class_output = self.classifier(features)
        reversed_features = GradientReversalLayer.apply(features, alpha)
        domain_output = self.domain_discriminator(reversed_features)
        return class_output, domain_output

class GradientReversalLayer(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, alpha):
        ctx.alpha = alpha
        return x.clone()

    @staticmethod
    def backward(ctx, grad_output):
        return -ctx.alpha * grad_output, None

小结
    

  • 迁移学习是视觉任务的默认范式，几乎不应该从零开始训练模型
    • 

  • 预训练范式正从有监督向自监督演进，DINOv2 代表了当前最先进的通用视觉表示
    • 

  • 分层学习率是最推荐的微调策略，浅层低学习率、深层高学习率
    • 

  • 微调学习率应比从头训练低 10-100 倍，避免灾难性遗忘
    • 

  • 领域差异显著时需要考虑领域自适应，对抗训练是最通用的方案
    • 

  • CLIP 的零样本能力为快速原型验证提供了全新的选择
    •
