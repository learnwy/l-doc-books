超参数调优

什么是超参数

超参数（Hyperparameters）是在训练开始之前设定的参数，不通过训练数据学习，而需要人工（或自动化方法）指定。它们直接影响模型的容量、训练速度和最终性能。

类型 模型参数 超参数
来源 训练中学习 训练前设定
示例 权重 w、偏置 b 学习率、层数、正则化强度
优化方式 梯度下降 网格搜索、贝叶斯优化 


网格搜索（Grid Search）
网格搜索是最直接的超参数搜索方法：穷举所有超参数组合，通过交叉验证评估每组性能。


from sklearn.model_selection import GridSearchCV
from sklearn.svm import SVC
from sklearn.datasets import load_iris

iris = load_iris()

param_grid = {
    'C': [0.1, 1, 10, 100],
    'gamma': [0.001, 0.01, 0.1, 1],
    'kernel': ['rbf'],
}

grid = GridSearchCV(
    SVC(), param_grid, cv=5,
    scoring='accuracy', verbose=0, n_jobs=-1
)
grid.fit(iris.data, iris.target)

print(f"最优参数:   {grid.best_params_}")
print(f"最优分数:   {grid.best_score_:.4f}")
print(f"搜索组合数: {len(grid.cv_results_['params'])}")

随机搜索（Random Search）
随机搜索从超参数分布中随机采样组合。Bergstra & Bengio (2012) 证明，随机搜索通常比网格搜索更高效。


from sklearn.model_selection import RandomizedSearchCV
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_wine
from scipy.stats import randint, uniform

wine = load_wine()

param_distributions = {
    'n_estimators': randint(50, 500),
    'max_depth': randint(3, 20),
    'min_samples_split': randint(2, 20),
    'min_samples_leaf': randint(1, 10),
    'max_features': uniform(0.1, 0.9),
}

random_search = RandomizedSearchCV(
    RandomForestClassifier(random_state=42),
    param_distributions,
    n_iter=50, cv=5,
    scoring='accuracy', random_state=42, n_jobs=-1
)
random_search.fit(wine.data, wine.target)

print(f"最优参数: {random_search.best_params_}")
print(f"最优分数: {random_search.best_score_:.4f}")
print(f"搜索次数: 50 (vs 网格搜索可能需要 {5*17*18*9*10} 组合)")


贝叶斯优化（Bayesian Optimization）
贝叶斯优化通过构建目标函数的概率代理模型（通常是高斯过程），基于已有评估结果智能选择下一组超参数。它能在更少的迭代中找到更好的超参数。


from sklearn.model_selection import cross_val_score
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.datasets import load_breast_cancer
import numpy as np

data = load_breast_cancer()

def objective(params):
    model = GradientBoostingClassifier(
        n_estimators=int(params['n_estimators']),
        max_depth=int(params['max_depth']),
        learning_rate=params['learning_rate'],
        min_samples_split=int(params['min_samples_split']),
        random_state=42
    )
    scores = cross_val_score(model, data.data, data.target, cv=5, scoring='accuracy')
    return scores.mean()

np.random.seed(42)
best_score = 0
best_params = None

for trial in range(30):
    params = {
        'n_estimators': np.random.randint(50, 300),
        'max_depth': np.random.randint(2, 8),
        'learning_rate': np.random.uniform(0.01, 0.3),
        'min_samples_split': np.random.randint(2, 15),
    }
    score = objective(params)
    if score > best_score:
        best_score = score
        best_params = params
        print(f"Trial {trial+1:2d}: score={score:.4f} ★ {params}")

print(f"\n最优分数: {best_score:.4f}")
print(f"最优参数: {best_params}")

Optuna
Optuna 是一个现代化的超参数优化框架，支持贝叶斯优化、剪枝、分布式计算等功能。


import optuna
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score
from sklearn.datasets import load_iris

iris = load_iris()

def objective(trial):
    params = {
        'n_estimators': trial.suggest_int('n_estimators', 50, 300),
        'max_depth': trial.suggest_int('max_depth', 2, 15),
        'min_samples_split': trial.suggest_int('min_samples_split', 2, 20),
        'min_samples_leaf': trial.suggest_int('min_samples_leaf', 1, 10),
        'max_features': trial.suggest_float('max_features', 0.1, 1.0),
    }

    model = RandomForestClassifier(**params, random_state=42)
    scores = cross_val_score(model, iris.data, iris.target, cv=5)
    return scores.mean()

study = optuna.create_study(direction='maximize')
study.optimize(objective, n_trials=50, show_progress_bar=False)

print(f"最优分数: {study.best_value:.4f}")
print(f"最优参数: {study.best_params}")
print(f"总试验数: {len(study.trials)}")

提示： 超参数调优的优先级为：学习率 > batch size > 模型架构 > 正则化参数。先粗略搜索确定量级范围，再在小范围内精搜。不要在不重要的超参数上浪费计算资源。






小结
    

  • 超参数不通过训练学习，需要手动或自动搜索，对模型性能影响巨大。
    • 

  • 网格搜索简单但效率低，随机搜索在高维空间更高效。
    • 

  • 贝叶斯优化通过代理模型智能选择超参数，在评估代价高时优势明显。
    • 

  • Optuna 是现代超参数优化的首选工具，支持剪枝、并行和可视化。
    • 

  • 调优时应优先关注学习率和模型架构等高影响参数。
