正则化

为什么需要正则化

正则化（Regularization）是防止模型过拟合的一系列技术。当模型在训练集上表现很好但在测试集上表现差时，就发生了过拟合。正则化通过约束模型复杂度，提升泛化能力。



L1 与 L2 正则化
L1 和 L2 正则化通过在损失函数中添加参数的惩罚项来限制模型复杂度。


L2 正则化（权重衰减）
Ltotal=Ldata+λ∑jwj2L_{total} = L_{data} + \lambda \sum_{j} w_j^2Ltotal​=Ldata​+λj∑​wj2​
L2 使参数趋向于较小的值，但不会变为零。


L1 正则化
Ltotal=Ldata+λ∑j∣wj∣L_{total} = L_{data} + \lambda \sum_{j} |w_j|Ltotal​=Ldata​+λj∑​∣wj​∣
L1 倾向于产生稀疏解，部分参数变为零，具有特征选择效果。

import torch
import torch.nn as nn
import torch.optim as optim

torch.manual_seed(42)
X = torch.randn(200, 50)
w_true = torch.zeros(50)
w_true[:5] = torch.tensor([3.0, -2.0, 1.5, -1.0, 0.5])
y = X @ w_true + torch.randn(200) * 0.1

model_l2 = nn.Linear(50, 1, bias=False)
optimizer_l2 = optim.SGD(model_l2.parameters(), lr=0.01, weight_decay=0.1)

for epoch in range(500):
    pred = model_l2(X)
    loss = nn.MSELoss()(pred, y.unsqueeze(1))
    optimizer_l2.zero_grad()
    loss.backward()
    optimizer_l2.step()

w_l2 = model_l2.weight.data.squeeze()
n_near_zero = (w_l2.abs() < 0.1).sum().item()
print(f"L2 正则化 → 接近零的参数: {n_near_zero}/50")
print(f"前 5 个参数: {w_l2[:5].tolist()}")


Dropout
Dropout（Srivastava et al., 2014）在训练过程中随机将一部分神经元的输出置为零，迫使网络学习更鲁棒的特征表示。


import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(20, 100),
    nn.ReLU(),
    nn.Dropout(p=0.5),
    nn.Linear(100, 50),
    nn.ReLU(),
    nn.Dropout(p=0.3),
    nn.Linear(50, 10),
)

x = torch.randn(1, 20)

model.train()
out_train1 = model(x)
out_train2 = model(x)
print(f"训练模式（两次前向传播结果不同）:")
print(f"  输出1: {out_train1[0, :5].tolist()}")
print(f"  输出2: {out_train2[0, :5].tolist()}")

model.eval()
out_eval1 = model(x)
out_eval2 = model(x)
print(f"\n推理模式（两次结果相同）:")
print(f"  输出1: {out_eval1[0, :5].tolist()}")
print(f"  输出2: {out_eval2[0, :5].tolist()}")
print(f"  结果一致: {torch.allclose(out_eval1, out_eval2)}")

Batch Normalization
Batch Normalization（BN）通过规范化每个 mini-batch 中的激活值来稳定训练过程，减少内部协变量偏移。


x^=x−μBσB2+ϵ,y=γx^+β\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \quad y = \gamma \hat{x} + \betax^=σB2​+ϵ​x−μB​​,y=γx^+β
import torch
import torch.nn as nn

model_no_bn = nn.Sequential(
    nn.Linear(20, 64), nn.ReLU(),
    nn.Linear(64, 32), nn.ReLU(),
    nn.Linear(32, 10),
)

model_bn = nn.Sequential(
    nn.Linear(20, 64), nn.BatchNorm1d(64), nn.ReLU(),
    nn.Linear(64, 32), nn.BatchNorm1d(32), nn.ReLU(),
    nn.Linear(32, 10),
)

X = torch.randn(500, 20)
y = torch.randint(0, 10, (500,))

for name, model in [("无 BN", model_no_bn), ("有 BN", model_bn)]:
    opt = torch.optim.Adam(model.parameters(), lr=0.01)
    losses = []
    for epoch in range(50):
        pred = model(X)
        loss = nn.CrossEntropyLoss()(pred, y)
        opt.zero_grad()
        loss.backward()
        opt.step()
        losses.append(loss.item())
    print(f"{name}: 初始损失={losses[0]:.4f} → 最终损失={losses[-1]:.4f}")

早停（Early Stopping）
早停是最简单但极其有效的正则化方法。当验证集损失不再下降时，停止训练并恢复最优参数。


import torch
import torch.nn as nn
import copy

class EarlyStopping:
    def __init__(self, patience=10, min_delta=1e-4):
        self.patience = patience
        self.min_delta = min_delta
        self.counter = 0
        self.best_loss = float('inf')
        self.best_model = None

    def __call__(self, val_loss, model):
        if val_loss < self.best_loss - self.min_delta:
            self.best_loss = val_loss
            self.best_model = copy.deepcopy(model.state_dict())
            self.counter = 0
            return False
        self.counter += 1
        return self.counter >= self.patience

model = nn.Sequential(nn.Linear(20, 50), nn.ReLU(), nn.Linear(50, 1))
early_stop = EarlyStopping(patience=5)

X_train = torch.randn(200, 20)
y_train = torch.randn(200, 1)
X_val = torch.randn(50, 20)
y_val = torch.randn(50, 1)
opt = torch.optim.Adam(model.parameters(), lr=0.01)

for epoch in range(200):
    model.train()
    pred = model(X_train)
    loss = nn.MSELoss()(pred, y_train)
    opt.zero_grad()
    loss.backward()
    opt.step()

    model.eval()
    with torch.no_grad():
        val_loss = nn.MSELoss()(model(X_val), y_val).item()

    if early_stop(val_loss, model):
        print(f"早停于 Epoch {epoch+1}, 最优验证损失: {early_stop.best_loss:.4f}")
        model.load_state_dict(early_stop.best_model)
        break


提示： 正则化技术不是互斥的，实际中常同时使用多种方法。典型组合：权重衰减 + Dropout + BN + 早停 + 数据增强，这样的"正则化组合拳"能最大限度地提升模型泛化能力。






小结
    

  • L1 正则化产生稀疏权重，具有特征选择能力；L2 正则化缩小权重，防止过大。
    • 

  • Dropout 通过随机关闭神经元迫使网络学习冗余表示，是深度学习最常用的正则化手段。
    • 

  • Batch Normalization 规范化激活值，加速收敛并提供隐式正则化效果。
    • 

  • 早停监控验证集表现，在过拟合发生之前终止训练，简单但有效。
    • 

  • 实际中应组合使用多种正则化技术以获得最佳泛化性能。
