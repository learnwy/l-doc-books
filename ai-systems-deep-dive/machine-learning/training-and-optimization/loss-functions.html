损失函数

什么是损失函数

损失函数（Loss Function）衡量模型预测值与真实值之间的差距，是训练优化的目标。模型训练的过程就是不断最小化损失函数的过程。选择合适的损失函数对模型性能有决定性影响。



回归损失函数
均方误差（MSE）
LMSE=1n∑i=1n(yi−y^i)2L_{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2LMSE​=n1​i=1∑n​(yi​−y^​i​)2
MSE 对大误差惩罚更重（平方效应），是最常用的回归损失。


平均绝对误差（MAE / L1 Loss）
LMAE=1n∑i=1n∣yi−y^i∣L_{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|LMAE​=n1​i=1∑n​∣yi​−y^​i​∣
MAE 对异常值更鲁棒，但在零点处不可导。


Huber Loss
LHuber={12(y−y^)2,∣y−y^∣≤δδ∣y−y^∣−12δ2,∣y−y^∣>δL_{Huber} = \begin{cases} \frac{1}{2}(y - \hat{y})^2, & |y - \hat{y}| \leq \delta \\ \delta|y - \hat{y}| - \frac{1}{2}\delta^2, & |y - \hat{y}| > \delta \end{cases}LHuber​={21​(y−y^​)2,δ∣y−y^​∣−21​δ2,​∣y−y^​∣≤δ∣y−y^​∣>δ​
Huber Loss 结合了 MSE 和 MAE 的优点：小误差时用 MSE（平滑），大误差时用 MAE（鲁棒）。


import torch
import torch.nn as nn

y_true = torch.tensor([1.0, 2.0, 3.0, 10.0])
y_pred = torch.tensor([1.1, 2.3, 2.7, 5.0])

mse = nn.MSELoss()(y_pred, y_true)
mae = nn.L1Loss()(y_pred, y_true)
huber = nn.HuberLoss(delta=1.0)(y_pred, y_true)

print(f"MSE Loss:   {mse.item():.4f}")
print(f"MAE Loss:   {mae.item():.4f}")
print(f"Huber Loss: {huber.item():.4f}")

分类损失函数
交叉熵损失（Cross-Entropy）
二分类交叉熵：


LBCE=−1n∑[ylog⁡(y^)+(1−y)log⁡(1−y^)]L_{BCE} = -\frac{1}{n}\sum[y\log(\hat{y}) + (1-y)\log(1-\hat{y})]LBCE​=−n1​∑[ylog(y^​)+(1−y)log(1−y^​)]
多分类交叉熵：


LCE=−1n∑i∑c=1Cyiclog⁡(y^ic)L_{CE} = -\frac{1}{n}\sum_{i}\sum_{c=1}^{C} y_{ic}\log(\hat{y}_{ic})LCE​=−n1​i∑​c=1∑C​yic​log(y^​ic​)
import torch
import torch.nn as nn

logits = torch.tensor([[2.0, 1.0, 0.1],
                       [0.5, 2.5, 0.3],
                       [0.3, 0.2, 3.0]])
labels = torch.tensor([0, 1, 2])

ce_loss = nn.CrossEntropyLoss()(logits, labels)
print(f"交叉熵损失: {ce_loss.item():.4f}")

probs = torch.softmax(logits, dim=1)
print(f"预测概率:\n{probs}")
Hinge Loss
LHinge=max⁡(0,1−y⋅y^)L_{Hinge} = \max(0, 1 - y \cdot \hat{y})LHinge​=max(0,1−y⋅y^​)
Hinge Loss 是 SVM 的损失函数，关注分类间隔而非概率。


import torch

def hinge_loss(y_true, y_pred):
    return torch.clamp(1 - y_true * y_pred, min=0).mean()

y_true = torch.tensor([1.0, -1.0, 1.0, -1.0])
y_pred = torch.tensor([0.8, -1.2, 0.3, 0.5])

loss = hinge_loss(y_true, y_pred)
print(f"Hinge Loss: {loss.item():.4f}")

for yt, yp in zip(y_true, y_pred):
    margin = yt * yp
    individual_loss = max(0, 1 - margin.item())
    print(f"  y={yt.item():+.0f}, ŷ={yp.item():+.1f}, "
          f"margin={margin.item():+.1f}, loss={individual_loss:.1f}")


Focal Loss
Focal Loss 是 Lin et al. (2017) 提出的用于处理类别不平衡的损失函数，通过降低易分类样本的权重，让模型更关注难分类样本。


LFL=−αt(1−pt)γlog⁡(pt)L_{FL} = -\alpha_t (1 - p_t)^\gamma \log(p_t)LFL​=−αt​(1−pt​)γlog(pt​)
import torch
import torch.nn.functional as F

def focal_loss(logits, targets, alpha=0.25, gamma=2.0):
    ce_loss = F.cross_entropy(logits, targets, reduction='none')
    pt = torch.exp(-ce_loss)
    loss = alpha * (1 - pt) ** gamma * ce_loss
    return loss.mean()

logits = torch.randn(10, 3)
targets = torch.randint(0, 3, (10,))

ce = F.cross_entropy(logits, targets)
fl = focal_loss(logits, targets)
print(f"交叉熵损失:  {ce.item():.4f}")
print(f"Focal Loss:  {fl.item():.4f}")

自定义损失函数
在特殊场景下，可以根据业务需求自定义损失函数。PyTorch 中只需保证损失函数可微分。


import torch
import torch.nn as nn

class WeightedMSELoss(nn.Module):
    def __init__(self, weight_high=5.0, threshold=0.5):
        super().__init__()
        self.weight_high = weight_high
        self.threshold = threshold

    def forward(self, pred, target):
        errors = (pred - target) ** 2
        weights = torch.where(
            target > self.threshold,
            torch.tensor(self.weight_high),
            torch.tensor(1.0)
        )
        return (weights * errors).mean()

pred = torch.tensor([0.3, 0.7, 0.5, 0.9])
target = torch.tensor([0.2, 0.8, 0.6, 0.1])

standard_loss = nn.MSELoss()(pred, target)
weighted_loss = WeightedMSELoss(weight_high=5.0)(pred, target)

print(f"标准 MSE:   {standard_loss.item():.4f}")
print(f"加权 MSE:   {weighted_loss.item():.4f}")


提示： 损失函数的选择需要与评估指标保持一致。如果评估指标是 F1，但损失函数是交叉熵，可能出现损失下降但 F1 不提升的情况。理解损失函数与评估指标之间的关系，是模型调优的重要一环。






小结
    

  • 回归任务中，MSE 最常用，MAE 对异常值鲁棒，Huber 兼顾两者优点。
    • 

  • 分类任务中，交叉熵是标准选择，Hinge Loss 关注间隔，适用于 SVM。
    • 

  • Focal Loss 通过动态加权解决类别不平衡问题，在目标检测中广泛使用。
    • 

  • 自定义损失函数可以根据业务需求灵活设计，需保证可微分以支持梯度计算。
    • 

  • 损失函数的选择应与任务目标和评估指标保持一致。
