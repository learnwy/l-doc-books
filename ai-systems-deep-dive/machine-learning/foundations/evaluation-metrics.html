评估指标

为什么需要评估指标

在机器学习中，评估指标（Evaluation Metrics）是衡量模型性能的量化工具。不同的任务需要不同的评估指标，选择合适的指标直接影响模型优化的方向和最终效果。



混淆矩阵
混淆矩阵（Confusion Matrix）是分类评估的基础工具，展示了模型预测结果与真实标签的对应关系。

预测为负

TN（真负例）





from sklearn.metrics import confusion_matrix, classification_report
from sklearn.datasets import load_breast_cancer
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

data = load_breast_cancer()
X_train, X_test, y_train, y_test = train_test_split(
    data.data, data.target, test_size=0.3, random_state=42
)

model = LogisticRegression(max_iter=10000)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

cm = confusion_matrix(y_test, y_pred)
print("混淆矩阵:")
print(cm)
print(f"\nTP={cm[1,1]}, FP={cm[0,1]}, FN={cm[1,0]}, TN={cm[0,0]}")


分类评估指标
准确率（Accuracy）
Accuracy=TP+TNTP+TN+FP+FN\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}Accuracy=TP+TN+FP+FNTP+TN​
准确率是最直观的指标，但在类别不平衡时可能产生误导。


精确率（Precision）
Precision=TPTP+FP\text{Precision} = \frac{TP}{TP + FP}Precision=TP+FPTP​
精确率衡量"被预测为正例的样本中有多少真的是正例"。当假正例代价高时（如垃圾邮件检测），应关注精确率。


召回率（Recall）
Recall=TPTP+FN\text{Recall} = \frac{TP}{TP + FN}Recall=TP+FNTP​
召回率衡量"所有正例中有多少被正确预测"。当假负例代价高时（如癌症筛查），应关注召回率。


F1 Score
F1=2×Precision×RecallPrecision+RecallF1 = 2 \times \frac{Precision \times Recall}{Precision + Recall}F1=2×Precision+RecallPrecision×Recall​
F1 是精确率和召回率的调和平均，在两者之间取得平衡。


from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

print(f"准确率: {accuracy_score(y_test, y_pred):.4f}")
print(f"精确率: {precision_score(y_test, y_pred):.4f}")
print(f"召回率: {recall_score(y_test, y_pred):.4f}")
print(f"F1 分数: {f1_score(y_test, y_pred):.4f}")

print("\n完整分类报告:")
print(classification_report(y_test, y_pred, target_names=data.target_names))

AUC-ROC 曲线
ROC 曲线（Receiver Operating Characteristic）展示了不同分类阈值下真正例率（TPR）与假正例率（FPR）的关系。AUC（Area Under Curve）是 ROC 曲线下的面积，取值范围为 [0, 1]。


TPR=TPTP+FN,FPR=FPFP+TNTPR = \frac{TP}{TP + FN}, \quad FPR = \frac{FP}{FP + TN}TPR=TP+FNTP​,FPR=FP+TNFP​
from sklearn.metrics import roc_auc_score, roc_curve
import numpy as np

y_proba = model.predict_proba(X_test)[:, 1]

auc = roc_auc_score(y_test, y_proba)
print(f"AUC-ROC: {auc:.4f}")

fpr, tpr, thresholds = roc_curve(y_test, y_proba)
optimal_idx = np.argmax(tpr - fpr)
optimal_threshold = thresholds[optimal_idx]
print(f"最优阈值: {optimal_threshold:.4f}")
print(f"对应 TPR: {tpr[optimal_idx]:.4f}, FPR: {fpr[optimal_idx]:.4f}")


提示： AUC 不受分类阈值影响，因此特别适合比较不同模型的整体区分能力。在类别严重不平衡时，建议同时参考 PR 曲线（Precision-Recall Curve）。






回归评估指标
均方误差（MSE）
MSE=1n∑i=1n(yi−y^i)2MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2MSE=n1​i=1∑n​(yi​−y^​i​)2
MSE 对大误差惩罚更重（平方效应），适合对异常值敏感的场景。


平均绝对误差（MAE）
MAE=1n∑i=1n∣yi−y^i∣MAE = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|MAE=n1​i=1∑n​∣yi​−y^​i​∣
MAE 对所有误差等权重处理，比 MSE 更鲁棒。


R² 决定系数
R2=1−∑(yi−y^i)2∑(yi−yˉ)2R^2 = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}R2=1−∑(yi​−yˉ​)2∑(yi​−y^​i​)2​
R² 衡量模型解释数据变异的比例，越接近 1 越好。


from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score
from sklearn.linear_model import LinearRegression
from sklearn.datasets import make_regression

X, y = make_regression(n_samples=200, n_features=5, noise=15, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

model = LinearRegression().fit(X_train, y_train)
y_pred = model.predict(X_test)

mse = mean_squared_error(y_test, y_pred)
rmse = mean_squared_error(y_test, y_pred, squared=False)
mae = mean_absolute_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

print(f"MSE:  {mse:.4f}")
print(f"RMSE: {rmse:.4f}")
print(f"MAE:  {mae:.4f}")
print(f"R²:   {r2:.4f}")

指标选择指南


小结
    

  • 混淆矩阵是分类评估的基础，从中可以推导出准确率、精确率、召回率等指标。
    • 

  • 精确率关注假正例，召回率关注假负例，F1 在两者间取平衡。
    • 

  • AUC-ROC 独立于阈值选择，适合模型间的整体比较。
    • 

  • 回归任务中，MSE 放大大误差，MAE 更鲁棒，R² 衡量模型的解释能力。
    • 

  • 指标选择取决于业务场景和错误类型的代价，没有万能指标。
    •
