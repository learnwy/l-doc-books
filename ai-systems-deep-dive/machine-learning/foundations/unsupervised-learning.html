无监督学习

什么是无监督学习

无监督学习（Unsupervised Learning）是在没有标签的数据上进行学习的方法。与监督学习不同，模型需要自主发现数据中隐藏的模式、结构和分布规律。

无监督学习的核心挑战在于：没有"正确答案"作为参照，模型的好坏评估往往依赖领域知识和间接指标。




聚类
聚类（Clustering）是将数据自动划分为若干组的过程，使得同组内的数据彼此相似，不同组的数据差异较大。


K-Means 聚类
K-Means 是最经典的聚类算法，通过迭代将数据点分配到最近的质心（centroid），并不断更新质心位置。


import numpy as np
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs

X, y_true = make_blobs(n_samples=300, centers=4, cluster_std=0.6, random_state=42)

kmeans = KMeans(n_clusters=4, random_state=42, n_init=10)
y_pred = kmeans.fit_predict(X)

print(f"簇中心:\n{kmeans.cluster_centers_}")
print(f"惯性（Inertia）: {kmeans.inertia_:.2f}")
print(f"各簇样本数: {np.bincount(y_pred)}")

DBSCAN 聚类
DBSCAN（Density-Based Spatial Clustering of Applications with Noise）基于密度进行聚类，能发现任意形状的簇并自动识别噪声点。


from sklearn.cluster import DBSCAN
from sklearn.datasets import make_moons

X, _ = make_moons(n_samples=300, noise=0.05, random_state=42)

dbscan = DBSCAN(eps=0.2, min_samples=5)
labels = dbscan.fit_predict(X)

n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
n_noise = (labels == -1).sum()
print(f"发现簇数: {n_clusters}")
print(f"噪声点数: {n_noise}")

降维
降维（Dimensionality Reduction）将高维数据映射到低维空间，同时尽量保留数据的关键信息。降维的目的包括数据可视化、去除噪声和加速后续算法。


主成分分析（PCA）
PCA 通过线性变换将数据投影到方差最大的方向上，是最常用的降维方法。


from sklearn.decomposition import PCA
from sklearn.datasets import load_digits
import numpy as np

digits = load_digits()
X = digits.data

pca = PCA(n_components=2)
X_2d = pca.fit_transform(X)

print(f"原始维度: {X.shape[1]}")
print(f"降维后维度: {X_2d.shape[1]}")
print(f"前 2 个主成分解释方差比: {pca.explained_variance_ratio_}")
print(f"累计解释方差: {pca.explained_variance_ratio_.sum():.2%}")

pca_full = PCA().fit(X)
cumsum = np.cumsum(pca_full.explained_variance_ratio_)
n_95 = np.argmax(cumsum >= 0.95) + 1
print(f"保留 95% 方差所需维度: {n_95}")
t-SNE
t-SNE（t-distributed Stochastic Neighbor Embedding）是一种非线性降维方法，特别适合数据可视化。


from sklearn.manifold import TSNE
from sklearn.datasets import load_digits

digits = load_digits()
tsne = TSNE(n_components=2, perplexity=30, random_state=42)
X_tsne = tsne.fit_transform(digits.data)

print(f"t-SNE 输出形状: {X_tsne.shape}")

异常检测
异常检测（Anomaly Detection）是识别数据中偏离正常模式的样本。无监督异常检测不需要异常标签，仅基于正常数据的分布特征来判断。


from sklearn.ensemble import IsolationForest
import numpy as np

np.random.seed(42)
X_normal = np.random.randn(200, 2)
X_outliers = np.random.uniform(-4, 4, (20, 2))
X = np.vstack([X_normal, X_outliers])

iso_forest = IsolationForest(contamination=0.1, random_state=42)
predictions = iso_forest.fit_predict(X)

n_anomalies = (predictions == -1).sum()
print(f"检测到的异常数量: {n_anomalies}")
print(f"总样本数: {len(X)}")
print(f"异常比例: {n_anomalies / len(X):.1%}")

提示： 在实际项目中，无监督学习常作为数据探索的第一步。通过聚类了解数据分布，通过降维进行可视化，可以为后续的监督学习任务提供有价值的洞察。






小结
    

  • 无监督学习在没有标签的情况下发现数据的内在结构，主要包括聚类、降维和异常检测。
    • 

  • K-Means 简单高效但局限于球形簇，DBSCAN 能发现任意形状的簇并处理噪声。
    • 

  • PCA 是线性降维的首选方法，t-SNE/UMAP 适合非线性可视化。
    • 

  • 异常检测在无标签场景下识别离群点，Isolation Forest 是通用性最强的方法之一。
    • 

  • 无监督学习常作为数据分析和特征工程的基础工具，为整个机器学习流程提供支撑。
