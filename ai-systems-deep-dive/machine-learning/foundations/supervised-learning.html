监督学习

什么是监督学习

监督学习（Supervised Learning）是机器学习中最常见的范式。模型从带有标签的训练数据中学习输入特征 XXX 到输出标签 yyy 之间的映射关系 f:X→yf: X \rightarrow yf:X→y，然后对新的未见数据进行预测。

"监督"一词的含义是：训练过程中有一个"老师"（即标签）不断告诉模型正确答案是什么。



分类与回归
监督学习的两大核心任务是分类和回归，它们的区别在于输出变量的类型。






特性
分类（Classification）
回归（Regression）





输出类型
离散类别
连续数值




目标
预测所属类别
预测数值大小




损失函数
交叉熵、Hinge Loss
MSE、MAE




评估指标
准确率、F1、AUC
MSE、R²、MAE




典型场景
垃圾邮件检测、图像识别
房价预测、股票走势





from sklearn.datasets import load_iris, load_diabetes
from sklearn.linear_model import LogisticRegression, LinearRegression
from sklearn.model_selection import train_test_split

iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.3, random_state=42
)
clf = LogisticRegression(max_iter=200)
clf.fit(X_train, y_train)
print(f"分类准确率: {clf.score(X_test, y_test):.2%}")

diabetes = load_diabetes()
X_train, X_test, y_train, y_test = train_test_split(
    diabetes.data, diabetes.target, test_size=0.3, random_state=42
)
reg = LinearRegression()
reg.fit(X_train, y_train)
print(f"回归 R² 分数: {reg.score(X_test, y_test):.4f}")


训练过程
监督学习的训练过程可以概括为以下步骤：


训练的核心目标是通过最小化损失函数来找到最优参数：


θ∗=arg⁡min⁡θ1N∑i=1NL(yi,f(xi;θ))\theta^* = \arg\min_\theta \frac{1}{N} \sum_{i=1}^{N} L(y_i, f(x_i; \theta))θ∗=argθmin​N1​i=1∑N​L(yi​,f(xi​;θ))
import numpy as np

np.random.seed(42)
X = 2 * np.random.rand(100, 1)
y = 4 + 3 * X.ravel() + np.random.randn(100) * 0.5

w, b = 0.0, 0.0
lr = 0.1
epochs = 100

for epoch in range(epochs):
    y_pred = w * X.ravel() + b
    loss = np.mean((y - y_pred) ** 2)
    dw = -2 * np.mean((y - y_pred) * X.ravel())
    db = -2 * np.mean(y - y_pred)
    w -= lr * dw
    b -= lr * db

print(f"学习到的参数: w={w:.2f}, b={b:.2f}")
print(f"真实参数:     w=3.00, b=4.00")


交叉验证
交叉验证（Cross-Validation）是评估模型泛化能力的标准方法。最常用的是 K 折交叉验证（K-Fold CV）。


from sklearn.model_selection import cross_val_score
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_iris

iris = load_iris()
clf = RandomForestClassifier(n_estimators=100, random_state=42)

scores = cross_val_score(clf, iris.data, iris.target, cv=5, scoring='accuracy')
print(f"各折准确率: {scores}")
print(f"平均准确率: {scores.mean():.4f} ± {scores.std():.4f}")

过拟合与欠拟合
过拟合（Overfitting）和欠拟合（Underfitting）是监督学习中最核心的挑战。


常用的过拟合缓解方法：

from sklearn.linear_model import Ridge, Lasso
from sklearn.datasets import make_regression
from sklearn.model_selection import train_test_split

X, y = make_regression(n_samples=100, n_features=50, noise=10, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

ridge = Ridge(alpha=1.0).fit(X_train, y_train)
lasso = Lasso(alpha=1.0).fit(X_train, y_train)

print(f"Ridge R²: {ridge.score(X_test, y_test):.4f}")
print(f"Lasso R²: {lasso.score(X_test, y_test):.4f}")
print(f"Lasso 非零系数数量: {(lasso.coef_ != 0).sum()}/{len(lasso.coef_)}")


提示： 观察训练集和验证集的学习曲线（Learning Curve），可以直观判断模型是过拟合还是欠拟合。如果两条曲线有较大间距，通常意味着过拟合。






小结
    

  • 监督学习从带标签数据中学习映射关系，分为分类（离散输出）和回归（连续输出）两大任务。
    • 

  • 训练过程的核心是通过最小化损失函数来寻找最优模型参数。
    • 

  • 交叉验证是评估模型泛化能力的标准方法，K-Fold 是最常用的策略。
    • 

  • 过拟合是最大的实践挑战，可通过正则化、早停、Dropout 等方法缓解。
    • 

  • 通过学习曲线和验证集表现来诊断模型状态，是构建可靠模型的关键技能。
    •
