数据增强

什么是数据增强

数据增强（Data Augmentation）是通过对现有数据进行变换来生成新训练样本的技术。它是解决数据不足和过拟合的有效手段，尤其在深度学习中几乎是标配。



提示： 数据增强应保持标签不变。增强后的样本应该仍然属于原始类别。例如，翻转一张猫的图片，它仍然是猫。






图像数据增强
图像增强是最成熟的数据增强领域，通过几何变换和颜色变换来增加样本多样性。

Mixup 与 CutMix
import torch
import numpy as np

def mixup(x1, y1, x2, y2, alpha=0.2):
    lam = np.random.beta(alpha, alpha)
    x_mixed = lam * x1 + (1 - lam) * x2
    y_mixed = lam * y1 + (1 - lam) * y2
    return x_mixed, y_mixed

x1 = torch.randn(3, 32, 32)
x2 = torch.randn(3, 32, 32)
y1 = torch.tensor([1.0, 0.0, 0.0])
y2 = torch.tensor([0.0, 1.0, 0.0])

x_mix, y_mix = mixup(x1, y1, x2, y2, alpha=0.2)
print(f"Mixup 标签: {y_mix.tolist()}")

import random
import re

def random_deletion(text, p=0.1):
    words = text.split()
    if len(words) == 1:
        return text
    remaining = [w for w in words if random.random() > p]
    return ' '.join(remaining) if remaining else random.choice(words)

def random_swap(text, n=1):
    words = text.split()
    for _ in range(n):
        if len(words) >= 2:
            i, j = random.sample(range(len(words)), 2)
            words[i], words[j] = words[j], words[i]
    return ' '.join(words)

text = "机器学习是人工智能的重要分支"
print(f"原始文本: {text}")
random.seed(42)
for i in range(3):
    print(f"  随机删除 {i+1}: {random_deletion(text, p=0.2)}")
    print(f"  随机交换 {i+1}: {random_swap(text, n=1)}")


合成数据生成
当真实数据极度稀缺时，可以通过算法生成合成数据。


SMOTE
SMOTE（Synthetic Minority Over-sampling Technique）通过在少数类样本之间插值生成合成样本，解决类别不平衡问题。


from sklearn.datasets import make_classification
import numpy as np

X, y = make_classification(
    n_samples=1000, n_features=10,
    weights=[0.95, 0.05],
    random_state=42
)

print(f"原始分布: 类别0={sum(y==0)}, 类别1={sum(y==1)}")

def simple_smote(X_minority, n_synthetic, k=5):
    from sklearn.neighbors import NearestNeighbors
    nn = NearestNeighbors(n_neighbors=k)
    nn.fit(X_minority)
    synthetic = []
    for _ in range(n_synthetic):
        idx = np.random.randint(len(X_minority))
        neighbors = nn.kneighbors([X_minority[idx]], return_distance=False)[0]
        neighbor_idx = np.random.choice(neighbors)
        diff = X_minority[neighbor_idx] - X_minority[idx]
        new_sample = X_minority[idx] + np.random.random() * diff
        synthetic.append(new_sample)
    return np.array(synthetic)

X_minority = X[y == 1]
X_synthetic = simple_smote(X_minority, n_synthetic=450)

X_new = np.vstack([X, X_synthetic])
y_new = np.concatenate([y, np.ones(len(X_synthetic))])
print(f"增强分布: 类别0={sum(y_new==0):.0f}, 类别1={sum(y_new==1):.0f}")

提示： 数据增强不能替代高质量的原始数据收集。增强最有效的场景是：原始数据质量好但数量不足，或需要模型对特定变换具有不变性时。过度增强反而会引入噪声。






小结
    

  • 图像增强是最成熟的领域，几何变换和颜色变换是标准操作，Mixup/CutMix 进一步提升效果。
    • 

  • 文本增强需要更谨慎，回译和同义词替换是相对安全的选择。
    • 

  • SMOTE 是解决类别不平衡的经典方法，通过插值生成合成少数类样本。
    • 

  • 增强策略需要根据数据类型和任务特点选择，核心原则是保持标签一致性。
    • 

  • 数据增强是正则化的一种形式，与 Dropout 等方法互补使用效果更佳。
