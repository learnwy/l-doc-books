特征选择

为什么需要特征选择

特征选择（Feature Selection）是从原始特征集中挑选出对预测最有价值的子集。过多的无关特征不仅增加计算成本，还可能引入噪声导致过拟合。



过滤法（Filter）
过滤法独立于模型，通过统计指标评估每个特征与目标变量的相关性，筛选出高相关特征。

from sklearn.datasets import load_breast_cancer
from sklearn.feature_selection import (
    SelectKBest, f_classif, mutual_info_classif, VarianceThreshold
)
import numpy as np

data = load_breast_cancer()
X, y = data.data, data.target

vt = VarianceThreshold(threshold=0.5)
X_var = vt.fit_transform(X)
print(f"方差过滤: {X.shape[1]} → {X_var.shape[1]} 特征")

selector_f = SelectKBest(f_classif, k=10)
X_f = selector_f.fit_transform(X, y)
scores_f = selector_f.scores_
top_f = np.argsort(scores_f)[::-1][:5]
print(f"\nF-test Top 5 特征:")
for idx in top_f:
    print(f"  {data.feature_names[idx]:30s} score={scores_f[idx]:.2f}")

selector_mi = SelectKBest(mutual_info_classif, k=10)
X_mi = selector_mi.fit_transform(X, y)
scores_mi = selector_mi.scores_
top_mi = np.argsort(scores_mi)[::-1][:5]
print(f"\n互信息 Top 5 特征:")
for idx in top_mi:
    print(f"  {data.feature_names[idx]:30s} MI={scores_mi[idx]:.4f}")


包裹法（Wrapper）
包裹法将特征选择过程嵌入模型训练中，通过迭代添加或移除特征来评估子集性能。


from sklearn.feature_selection import SequentialFeatureSelector
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import cross_val_score

data = load_breast_cancer()
X, y = data.data, data.target

model = RandomForestClassifier(n_estimators=50, random_state=42)

full_score = cross_val_score(model, X, y, cv=5).mean()
print(f"全部特征 ({X.shape[1]}): {full_score:.4f}")

sfs = SequentialFeatureSelector(
    model, n_features_to_select=10,
    direction='forward', cv=5, n_jobs=-1
)
sfs.fit(X, y)
selected_mask = sfs.get_support()
selected_names = [data.feature_names[i] for i, s in enumerate(selected_mask) if s]

subset_score = cross_val_score(model, X[:, selected_mask], y, cv=5).mean()
print(f"选择特征 ({sum(selected_mask)}): {subset_score:.4f}")
print(f"选中特征: {selected_names}")


嵌入法（Embedded）
嵌入法在模型训练过程中同时完成特征选择，利用模型自带的特征重要性或稀疏性。


from sklearn.ensemble import RandomForestClassifier
from sklearn.linear_model import LassoCV
from sklearn.datasets import load_breast_cancer
import numpy as np

data = load_breast_cancer()
X, y = data.data, data.target

rf = RandomForestClassifier(n_estimators=100, random_state=42)
rf.fit(X, y)

importances = rf.feature_importances_
indices = np.argsort(importances)[::-1]

print("Random Forest 特征重要性 Top 10:")
for i in range(10):
    idx = indices[i]
    bar = "█" * int(importances[idx] * 100)
    print(f"  {data.feature_names[idx]:30s} {importances[idx]:.4f} {bar}")

from sklearn.preprocessing import StandardScaler
X_scaled = StandardScaler().fit_transform(X)
lasso = LassoCV(cv=5, random_state=42)
lasso.fit(X_scaled, y)

n_selected = (lasso.coef_ != 0).sum()
print(f"\nLasso 选择的特征: {n_selected}/{X.shape[1]}")
print(f"最优 alpha: {lasso.alpha_:.4f}")

相关性分析
特征之间的高度相关（多重共线性）会影响模型稳定性。分析特征间相关性有助于去除冗余特征。


import numpy as np
from sklearn.datasets import load_breast_cancer

data = load_breast_cancer()
X = data.data

corr_matrix = np.corrcoef(X.T)

threshold = 0.95
high_corr_pairs = []
for i in range(len(corr_matrix)):
    for j in range(i + 1, len(corr_matrix)):
        if abs(corr_matrix[i][j]) > threshold:
            high_corr_pairs.append((
                data.feature_names[i],
                data.feature_names[j],
                corr_matrix[i][j]
            ))

print(f"高相关特征对 (|r| > {threshold}):")
for f1, f2, r in sorted(high_corr_pairs, key=lambda x: -abs(x[2]))[:5]:
    print(f"  {f1:30s} ↔ {f2:30s}  r={r:.4f}")


提示： 特征选择不仅提升模型性能，更重要的是提升可解释性。在医疗、金融等需要解释模型决策的领域，少量有意义的特征远比大量冗余特征更有价值。






小结
    

  • 过滤法速度快，基于统计指标独立评估特征，适合初步筛选。
    • 

  • 包裹法考虑特征交互，效果最好但计算成本高。
    • 

  • 嵌入法结合模型训练完成选择，Lasso 和树模型是常用方法。
    • 

  • 相关性分析帮助识别冗余特征，去除多重共线性。
    • 

  • 实践中建议先用过滤法粗筛，再用嵌入法或包裹法精选。
