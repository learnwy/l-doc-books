数据预处理

为什么需要数据预处理

数据预处理（Data Preprocessing）是机器学习流程中最关键的步骤之一。真实世界的数据通常存在缺失值、异常值、尺度不一致等问题。高质量的预处理直接影响模型的训练效果和泛化能力。



提示： "垃圾进，垃圾出"（Garbage In, Garbage Out）是机器学习的金科玉律。在模型调优之前，确保数据质量是获得好结果的前提。






归一化与标准化
不同特征的数值范围差异巨大（如年龄 0-100 vs 收入 0-1000000），会导致模型训练困难。缩放可以解决这个问题。


标准化（Standardization / Z-Score）
x′=x−μσx' = \frac{x - \mu}{\sigma}x′=σx−μ​
将数据转换为均值为 0、标准差为 1 的分布。


归一化（Min-Max Normalization）
x′=x−xminxmax−xminx' = \frac{x - x_{min}}{x_{max} - x_{min}}x′=xmax​−xmin​x−xmin​​
将数据缩放到 [0, 1] 区间。

import numpy as np
from sklearn.preprocessing import StandardScaler, MinMaxScaler, RobustScaler

np.random.seed(42)
X = np.array([
    [25, 50000, 3],
    [30, 65000, 5],
    [35, 80000, 7],
    [45, 120000, 10],
    [60, 300000, 15],
])

scalers = {
    "StandardScaler": StandardScaler(),
    "MinMaxScaler":   MinMaxScaler(),
    "RobustScaler":   RobustScaler(),
}

for name, scaler in scalers.items():
    X_scaled = scaler.fit_transform(X)
    print(f"\n{name}:")
    print(f"  均值: {X_scaled.mean(axis=0).round(4)}")
    print(f"  标准差: {X_scaled.std(axis=0).round(4)}")
    print(f"  范围: [{X_scaled.min(axis=0).round(4)}, {X_scaled.max(axis=0).round(4)}]")


特征编码
机器学习算法通常只接受数值输入，分类特征需要编码为数字。


Label Encoding
将类别映射为整数。适用于有序类别。


One-Hot Encoding
将每个类别转换为一个二进制向量。适用于无序类别。


import numpy as np
from sklearn.preprocessing import LabelEncoder, OneHotEncoder
import pandas as pd

colors = ['红', '蓝', '绿', '红', '绿']

le = LabelEncoder()
labels = le.fit_transform(colors)
print(f"Label Encoding: {colors} → {labels}")
print(f"类别映射: {dict(zip(le.classes_, range(len(le.classes_))))}")

ohe = OneHotEncoder(sparse_output=False)
one_hot = ohe.fit_transform(np.array(colors).reshape(-1, 1))
print(f"\nOne-Hot Encoding:")
for color, vec in zip(colors, one_hot):
    print(f"  {color} → {vec.astype(int).tolist()}")

缺失值处理
import numpy as np
from sklearn.impute import SimpleImputer, KNNImputer

np.random.seed(42)
X = np.array([
    [1.0, 2.0, 3.0],
    [4.0, np.nan, 6.0],
    [7.0, 8.0, np.nan],
    [np.nan, 11.0, 12.0],
    [13.0, 14.0, 15.0],
])

strategies = {
    "均值填充": SimpleImputer(strategy='mean'),
    "中位数填充": SimpleImputer(strategy='median'),
    "KNN 填充": KNNImputer(n_neighbors=2),
}

print(f"原始数据:\n{X}\n")
for name, imputer in strategies.items():
    X_filled = imputer.fit_transform(X)
    print(f"{name}:")
    print(f"{X_filled.round(2)}\n")


异常值处理
异常值（Outliers）可能是数据错误或真实极端值。处理方式取决于业务场景。


import numpy as np

np.random.seed(42)
data = np.concatenate([np.random.randn(100) * 10 + 50, [200, -50, 300]])

Q1 = np.percentile(data, 25)
Q3 = np.percentile(data, 75)
IQR = Q3 - Q1
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

outliers = data[(data < lower) | (data > upper)]
print(f"IQR 方法:")
print(f"  Q1={Q1:.2f}, Q3={Q3:.2f}, IQR={IQR:.2f}")
print(f"  有效范围: [{lower:.2f}, {upper:.2f}]")
print(f"  检测到 {len(outliers)} 个异常值: {outliers.round(2)}")

mean, std = np.mean(data), np.std(data)
z_scores = np.abs((data - mean) / std)
outliers_z = data[z_scores > 3]
print(f"\nZ-Score 方法 (|z| > 3):")
print(f"  检测到 {len(outliers_z)} 个异常值: {outliers_z.round(2)}")

小结
    

  • 标准化和归一化是消除特征尺度差异的基本手段，几乎所有模型都需要。
    • 

  • 特征编码将类别变量转为数值，One-Hot 适合无序类别，Label Encoding 适合有序类别。
    • 

  • 缺失值可通过均值、中位数或 KNN 填充处理，选择取决于缺失模式。
    • 

  • 异常值的检测可用 IQR 或 Z-Score 方法，处理方式需结合业务理解。
    • 

  • 所有预处理操作必须在训练集上 fit，避免数据泄露。
