决策树

什么是决策树

决策树（Decision Tree）是一种直观的监督学习算法，它通过不断对特征进行条件判断来划分数据，最终形成一个树形结构。每个内部节点表示一个特征上的测试，每个分支代表测试的结果，每个叶节点代表一个类别（分类）或数值（回归）。



特征选择标准
决策树的核心问题是：在每个节点上选择哪个特征进行划分？不同的算法使用不同的标准。

import numpy as np

def entropy(y):
    _, counts = np.unique(y, return_counts=True)
    probs = counts / len(y)
    return -np.sum(probs * np.log2(probs + 1e-10))

def gini(y):
    _, counts = np.unique(y, return_counts=True)
    probs = counts / len(y)
    return 1 - np.sum(probs ** 2)

y_pure = np.array([1, 1, 1, 1])
y_mixed = np.array([1, 1, 0, 0])
y_skewed = np.array([1, 1, 1, 0])

for label, y in [("纯净", y_pure), ("均匀", y_mixed), ("偏斜", y_skewed)]:
    print(f"{label}: Entropy={entropy(y):.4f}, Gini={gini(y):.4f}")


构建决策树
from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.3, random_state=42
)

tree_gini = DecisionTreeClassifier(criterion='gini', random_state=42)
tree_entropy = DecisionTreeClassifier(criterion='entropy', random_state=42)

tree_gini.fit(X_train, y_train)
tree_entropy.fit(X_train, y_train)

print(f"Gini 准确率:    {tree_gini.score(X_test, y_test):.4f}")
print(f"Entropy 准确率: {tree_entropy.score(X_test, y_test):.4f}")
print(f"树深度: Gini={tree_gini.get_depth()}, Entropy={tree_entropy.get_depth()}")
print(f"叶节点数: Gini={tree_gini.get_n_leaves()}, Entropy={tree_entropy.get_n_leaves()}")


剪枝
未经限制的决策树会一直生长到完美拟合训练数据，导致严重过拟合。剪枝（Pruning）是解决这个问题的关键手段。






剪枝方式
时机
方法





预剪枝
生长过程中
限制最大深度、最小样本数、最小分裂增益




后剪枝
生长完成后
CCP（Cost Complexity Pruning）、REP





from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split

wine = load_wine()
X_train, X_test, y_train, y_test = train_test_split(
    wine.data, wine.target, test_size=0.3, random_state=42
)

configs = [
    ("无限制", {}),
    ("max_depth=3", {"max_depth": 3}),
    ("min_samples_leaf=10", {"min_samples_leaf": 10}),
    ("max_depth=4 + min_leaf=5", {"max_depth": 4, "min_samples_leaf": 5}),
]

for name, params in configs:
    tree = DecisionTreeClassifier(random_state=42, **params)
    tree.fit(X_train, y_train)
    train_acc = tree.score(X_train, y_train)
    test_acc = tree.score(X_test, y_test)
    print(f"{name:30s} 训练={train_acc:.4f}  测试={test_acc:.4f}  "
          f"深度={tree.get_depth()}  叶节点={tree.get_n_leaves()}")
from sklearn.tree import DecisionTreeClassifier
import numpy as np

tree = DecisionTreeClassifier(random_state=42)
path = tree.cost_complexity_pruning_path(X_train, y_train)
ccp_alphas = path.ccp_alphas

best_alpha, best_score = 0, 0
for alpha in ccp_alphas[::5]:
    t = DecisionTreeClassifier(ccp_alpha=alpha, random_state=42)
    t.fit(X_train, y_train)
    score = t.score(X_test, y_test)
    if score > best_score:
        best_alpha, best_score = alpha, score

print(f"最优 ccp_alpha: {best_alpha:.4f}")
print(f"最优测试准确率: {best_score:.4f}")


特征重要性
决策树天然提供特征重要性度量，基于每个特征在分裂中带来的不纯度下降总量。


from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import load_iris
import numpy as np

iris = load_iris()
tree = DecisionTreeClassifier(max_depth=4, random_state=42)
tree.fit(iris.data, iris.target)

importances = tree.feature_importances_
for name, imp in sorted(zip(iris.feature_names, importances), key=lambda x: -x[1]):
    bar = "█" * int(imp * 40)
    print(f"{name:20s} {imp:.4f} {bar}")


提示： 决策树是许多强大集成方法（随机森林、XGBoost）的基础。理解决策树的分裂标准和过拟合控制，对掌握整个集成学习体系至关重要。






小结
    

  • 决策树通过递归分裂构建树形结构，每个节点选择最优特征进行划分。
    • 

  • 信息增益（ID3）、信息增益率（C4.5）和基尼不纯度（CART）是三种主要的分裂标准。
    • 

  • 剪枝是防止过拟合的关键，包括预剪枝（限制参数）和后剪枝（CCP）两类策略。
    • 

  • 决策树可解释性强，可以直观展示决策过程，并天然提供特征重要性排序。
    • 

  • 单棵决策树方差大且不稳定，通常作为集成方法的基学习器使用。
