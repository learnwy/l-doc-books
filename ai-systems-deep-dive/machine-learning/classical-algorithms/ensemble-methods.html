集成方法

什么是集成学习

集成学习（Ensemble Learning）是将多个弱学习器组合成一个强学习器的策略。核心思想是"三个臭皮匠，顶个诸葛亮"——多个模型的组合往往比单个模型更稳定、更准确。



Bagging
Bagging（Bootstrap Aggregating）通过有放回的自助采样生成多个训练子集，分别训练基学习器，最终通过投票（分类）或平均（回归）得到结果。


Bagging 的核心优势是降低方差，特别适合高方差的不稳定模型（如决策树）。


from sklearn.ensemble import BaggingClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split

wine = load_wine()
X_train, X_test, y_train, y_test = train_test_split(
    wine.data, wine.target, test_size=0.3, random_state=42
)

single_tree = DecisionTreeClassifier(random_state=42)
single_tree.fit(X_train, y_train)

bagging = BaggingClassifier(
    estimator=DecisionTreeClassifier(),
    n_estimators=50, random_state=42
)
bagging.fit(X_train, y_train)

print(f"单棵决策树: {single_tree.score(X_test, y_test):.4f}")
print(f"Bagging:    {bagging.score(X_test, y_test):.4f}")

from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
import numpy as np

data = load_breast_cancer()
X_train, X_test, y_train, y_test = train_test_split(
    data.data, data.target, test_size=0.3, random_state=42
)

rf = RandomForestClassifier(n_estimators=100, random_state=42)
rf.fit(X_train, y_train)
print(f"Random Forest 准确率: {rf.score(X_test, y_test):.4f}")

importances = rf.feature_importances_
top_k = 5
indices = np.argsort(importances)[::-1][:top_k]
print(f"\nTop {top_k} 重要特征:")
for i, idx in enumerate(indices):
    print(f"  {i+1}. {data.feature_names[idx]:30s} {importances[idx]:.4f}")

from sklearn.ensemble import AdaBoostClassifier, GradientBoostingClassifier
from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split

wine = load_wine()
X_train, X_test, y_train, y_test = train_test_split(
    wine.data, wine.target, test_size=0.3, random_state=42
)

ada = AdaBoostClassifier(n_estimators=100, random_state=42)
ada.fit(X_train, y_train)

gbdt.fit(X_train, y_train)

print(f"AdaBoost: {ada.score(X_test, y_test):.4f}")
print(f"GBDT:     {gbdt.score(X_test, y_test):.4f}")


XGBoost
XGBoost（eXtreme Gradient Boosting）是目前最流行的集成学习算法之一，在 Gradient Boosting 的基础上加入了正则化、二阶梯度优化、并行计算等改进。


from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.ensemble import GradientBoostingClassifier, RandomForestClassifier

data = load_breast_cancer()
X_train, X_test, y_train, y_test = train_test_split(
    data.data, data.target, test_size=0.3, random_state=42
)

models = {
    "Random Forest": RandomForestClassifier(n_estimators=100, random_state=42),
    "GBDT": GradientBoostingClassifier(n_estimators=100, random_state=42),
}

for name, model in models.items():
    model.fit(X_train, y_train)
    train_acc = model.score(X_train, y_train)
    test_acc = model.score(X_test, y_test)
    print(f"{name:20s} 训练={train_acc:.4f}  测试={test_acc:.4f}")

Stacking
Stacking（堆叠泛化）使用多个不同类型的基模型，将它们的输出作为新特征，输入到一个元模型（Meta-Learner）中进行最终预测。


from sklearn.ensemble import StackingClassifier, RandomForestClassifier
from sklearn.svm import SVC
from sklearn.neighbors import KNeighborsClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.3, random_state=42
)

estimators = [
    ('rf', RandomForestClassifier(n_estimators=50, random_state=42)),
    ('svc', SVC(probability=True, random_state=42)),
    ('knn', KNeighborsClassifier(n_neighbors=5)),
]

stacking = StackingClassifier(
    estimators=estimators,
    final_estimator=LogisticRegression(max_iter=200),
    cv=5
)
stacking.fit(X_train, y_train)

print(f"Stacking 准确率: {stacking.score(X_test, y_test):.4f}")

for name, model in estimators:
    model.fit(X_train, y_train)
    print(f"  {name:5s} 单独准确率: {model.score(X_test, y_test):.4f}")


提示： 在实际竞赛和工程中，集成方法几乎是标配。随机森林适合快速建立基线，XGBoost/LightGBM 适合精调性能，Stacking 适合最终冲刺。合理选择集成策略可以显著提升模型效果。






小结
    

  • 集成学习通过组合多个模型来提升性能，主要分为 Bagging 和 Boosting 两大路线。
    • 

  • Bagging 降低方差，通过并行训练和投票/平均聚合；Random Forest 是其最成功的代表。
    • 

  • Boosting 降低偏差，通过串行训练逐步修正错误；XGBoost 是当前最强的通用方法之一。
    • 

  • Stacking 通过分层组合不同类型的模型，充分利用各模型的互补优势。
    • 

  • 集成方法是机器学习竞赛和工业应用中性能最优的技术之一。
