SVM 与核方法

什么是支持向量机

支持向量机（Support Vector Machine, SVM）是一种基于最大间隔思想的分类算法。它寻找一个最优超平面将不同类别的数据分开，并使得离超平面最近的样本（支持向量）到超平面的距离最大化。

max⁡w,b2∥w∥s.t.yi(wTxi+b)≥1,∀i\max_{w,b} \frac{2}{\|w\|} \quad \text{s.t.} \quad y_i(\mathbf{w}^T\mathbf{x}_i + b) \geq 1, \forall iw,bmax​∥w∥2​s.t.yi​(wTxi​+b)≥1,∀i


最大间隔分类
SVM 的核心思想是在所有能正确分类的超平面中，选择间隔（margin）最大的那个。间隔定义为两个类别中距离超平面最近的点之间的距离。


from sklearn.svm import SVC
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
import numpy as np

X, y = make_classification(
    n_samples=200, n_features=2, n_redundant=0,
    n_clusters_per_class=1, random_state=42
)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

svm = SVC(kernel='linear')
svm.fit(X_train, y_train)

print(f"准确率: {svm.score(X_test, y_test):.4f}")
print(f"支持向量数量: {svm.n_support_}")
print(f"总训练样本数: {len(X_train)}")
print(f"支持向量占比: {sum(svm.n_support_) / len(X_train):.2%}")

核技巧（Kernel Trick）
当数据线性不可分时，SVM 通过核函数将数据映射到高维空间，在高维空间中寻找线性可分的超平面。核技巧的精妙之处在于：无需显式计算高维映射，只需计算内积。


K(xi,xj)=ϕ(xi)Tϕ(xj)K(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^T \phi(\mathbf{x}_j)K(xi​,xj​)=ϕ(xi​)Tϕ(xj​)

K(x,x′)=(γxTx′+r)dK(x,x') = (\gamma x^Tx' + r)^dK(x,x′)=(γxTx′+r)d

RBF（高斯核）
K(x,x′)=e−γ∣x−x′∣2K(x,x') = e^{-\gamma|x-x'|^2}K(x,x′)=e−γ∣x−x′∣2

Sigmoid 核
K(x,x′)=tanh⁡(γxTx′+r)K(x,x') = \tanh(\gamma x^Tx' + r)K(x,x′)=tanh(γxTx′+r)
类似神经网络





from sklearn.svm import SVC
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split

X, y = make_moons(n_samples=300, noise=0.15, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

kernels = ['linear', 'poly', 'rbf', 'sigmoid']
for kernel in kernels:
    svm = SVC(kernel=kernel, gamma='scale')
    svm.fit(X_train, y_train)
    acc = svm.score(X_test, y_test)
    n_sv = sum(svm.n_support_)
    print(f"{kernel:10s} 准确率={acc:.4f}  支持向量={n_sv}")


RBF 核参数
RBF 核有两个关键参数：C（正则化参数）和 gamma（核宽度参数）。






参数
值大
值小





C
小间隔，少误分类（容易过拟合）
大间隔，允许误分类（容易欠拟合）




gamma
决策边界复杂（容易过拟合）
决策边界平滑（容易欠拟合）





from sklearn.svm import SVC
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split, GridSearchCV

X, y = make_moons(n_samples=300, noise=0.2, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

param_grid = {
    'C': [0.1, 1, 10, 100],
    'gamma': [0.01, 0.1, 1, 10],
}

grid = GridSearchCV(SVC(kernel='rbf'), param_grid, cv=5, scoring='accuracy')
grid.fit(X_train, y_train)

print(f"最优参数: {grid.best_params_}")
print(f"交叉验证最优分数: {grid.best_score_:.4f}")
print(f"测试集准确率: {grid.score(X_test, y_test):.4f}")


软间隔（Soft Margin）
在实际数据中，往往存在噪声导致完全线性可分不可能。软间隔 SVM 允许一些样本违反间隔约束，通过引入松弛变量 ξi\xi_iξi​ 和参数 CCC 来控制违规程度。

s.t.yi(wTxi+b)≥1−ξi,ξi≥0\text{s.t.} \quad y_i(\mathbf{w}^T\mathbf{x}_i + b) \geq 1 - \xi_i, \quad \xi_i \geq 0s.t.yi​(wTxi​+b)≥1−ξi​,ξi​≥0
from sklearn.svm import SVC
import numpy as np

np.random.seed(42)
X = np.random.randn(100, 2)
y = (X[:, 0] + X[:, 1] > 0).astype(int)
noise_idx = np.random.choice(100, 10, replace=False)
y[noise_idx] = 1 - y[noise_idx]

for C in [0.01, 0.1, 1, 10, 100]:
    svm = SVC(kernel='linear', C=C)
    svm.fit(X, y)
    acc = svm.score(X, y)
    n_sv = sum(svm.n_support_)
    print(f"C={C:6.2f}  准确率={acc:.4f}  支持向量={n_sv}")


提示： SVM 的训练时间复杂度约为 O(n²) 到 O(n³)，不适合大规模数据集。对于大数据，可以考虑使用 LinearSVC（基于 liblinear）或在线学习版本的 SVM。






小结
    

  • SVM 通过寻找最大间隔超平面实现分类，支持向量是距离超平面最近的关键样本。
    • 

  • 核技巧让 SVM 能处理非线性问题，RBF 核是最常用的通用核函数。
    • 

  • C 控制正则化强度，gamma 控制核函数的作用范围，两者共同决定模型复杂度。
    • 

  • 软间隔允许部分样本违规，使 SVM 能处理含噪声的现实数据。
    • 

  • SVM 在中小规模数据上表现优秀，但大规模数据下的计算开销较大。
