逻辑回归

什么是逻辑回归

逻辑回归（Logistic Regression）虽然名字中带有"回归"，但它实际上是一种分类算法。它通过 Sigmoid 函数将线性输出映射到 (0, 1) 区间，输出样本属于正类的概率。

P(y=1∣x)=σ(wTx+b)=11+e−(wTx+b)P(y=1|\mathbf{x}) = \sigma(\mathbf{w}^T\mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T\mathbf{x} + b)}}P(y=1∣x)=σ(wTx+b)=1+e−(wTx+b)1​


Sigmoid 函数
Sigmoid 函数是逻辑回归的核心，它将任意实数映射到 (0, 1) 区间：


σ(z)=11+e−z\sigma(z) = \frac{1}{1 + e^{-z}}σ(z)=1+e−z1​

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

z = np.array([-5, -2, 0, 2, 5])
print("z 值:", z)
print("σ(z):", np.round(sigmoid(z), 4))
print("导数:", np.round(sigmoid(z) * (1 - sigmoid(z)), 4))


交叉熵损失
逻辑回归使用交叉熵（Cross-Entropy）作为损失函数，而非 MSE。这是因为 Sigmoid + MSE 会导致非凸优化问题。


L=−1n∑i=1n[yilog⁡(y^i)+(1−yi)log⁡(1−y^i)]L = -\frac{1}{n}\sum_{i=1}^{n}[y_i \log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)]L=−n1​i=1∑n​[yi​log(y^​i​)+(1−yi​)log(1−y^​i​)]
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.metrics import log_loss

data = load_breast_cancer()
X_train, X_test, y_train, y_test = train_test_split(
    data.data, data.target, test_size=0.3, random_state=42
)

model = LogisticRegression(max_iter=10000)
model.fit(X_train, y_train)

y_proba = model.predict_proba(X_test)
loss = log_loss(y_test, y_proba)
print(f"交叉熵损失: {loss:.4f}")
print(f"准确率: {model.score(X_test, y_test):.4f}")


提示： 交叉熵损失是凸函数，保证了梯度下降能收敛到全局最优解。这是逻辑回归使用交叉熵而非 MSE 的根本原因。






多分类扩展
逻辑回归可以从二分类扩展到多分类，常用的两种策略：

方法
说明





OvR (One-vs-Rest)
每个类别训练一个二分类器
K 个类别 → K 个分类器




Multinomial (Softmax)
同时建模所有类别
使用 Softmax 输出概率分布





Softmax 函数将 K 个类别的原始分数转化为概率分布：


P(y=k∣x)=ezk∑j=1KezjP(y=k|\mathbf{x}) = \frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}P(y=k∣x)=∑j=1K​ezj​ezk​​
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
import numpy as np

iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.3, random_state=42
)

ovr_model = LogisticRegression(multi_class='ovr', max_iter=200)
ovr_model.fit(X_train, y_train)
print(f"OvR 准确率: {ovr_model.score(X_test, y_test):.4f}")

softmax_model = LogisticRegression(multi_class='multinomial', max_iter=200)
softmax_model.fit(X_train, y_train)
print(f"Softmax 准确率: {softmax_model.score(X_test, y_test):.4f}")

sample = X_test[:1]
proba = softmax_model.predict_proba(sample)
print(f"\n样本预测概率: {np.round(proba[0], 4)}")
print(f"概率之和: {proba[0].sum():.4f}")


决策边界
逻辑回归的决策边界是一个线性超平面 wTx+b=0\mathbf{w}^T\mathbf{x} + b = 0wTx+b=0。当 σ(z)=0.5\sigma(z) = 0.5σ(z)=0.5 时，即 z=0z = 0z=0，模型在此处做出分类决定。


from sklearn.linear_model import LogisticRegression
from sklearn.datasets import make_classification
import numpy as np

X, y = make_classification(
    n_samples=200, n_features=2, n_redundant=0,
    n_clusters_per_class=1, random_state=42
)

model = LogisticRegression()
model.fit(X, y)

print(f"权重: w1={model.coef_[0][0]:.4f}, w2={model.coef_[0][1]:.4f}")
print(f"截距: b={model.intercept_[0]:.4f}")
print(f"决策边界方程: {model.coef_[0][0]:.2f}*x1 + {model.coef_[0][1]:.2f}*x2 + {model.intercept_[0]:.2f} = 0")

x1_range = np.linspace(X[:, 0].min(), X[:, 0].max(), 5)
x2_boundary = -(model.coef_[0][0] * x1_range + model.intercept_[0]) / model.coef_[0][1]
for x1, x2 in zip(x1_range, x2_boundary):
    print(f"  x1={x1:.2f} → x2={x2:.2f}")


小结
    

  • 逻辑回归通过 Sigmoid 函数将线性输出映射为概率，是经典的二分类算法。
    • 

  • 使用交叉熵损失函数，保证了凸优化性质，能收敛到全局最优。
    • 

  • 通过 OvR 或 Softmax 策略可扩展到多分类问题。
    • 

  • 决策边界是线性超平面，限制了逻辑回归只能处理线性可分或近似线性可分的问题。
    • 

  • 逻辑回归可解释性强、训练速度快，是工业界使用最广泛的基线分类模型之一。
