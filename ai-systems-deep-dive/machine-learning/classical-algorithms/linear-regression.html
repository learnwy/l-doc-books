线性回归

什么是线性回归

线性回归（Linear Regression）是最基础的监督学习算法，用于建模因变量 yyy 与一个或多个自变量 XXX 之间的线性关系。其目标是找到一条最佳拟合直线（或超平面），使得预测值与真实值之间的误差最小。

y^=w1x1+w2x2+⋯+wnxn+b=wTx+b\hat{y} = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b = \mathbf{w}^T\mathbf{x} + by^​=w1​x1​+w2​x2​+⋯+wn​xn​+b=wTx+b


最小二乘法（OLS）
普通最小二乘法（Ordinary Least Squares）通过最小化残差平方和来求解最优参数，有解析解（闭式解）：


w∗=(XTX)−1XTy\mathbf{w}^* = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}w∗=(XTX)−1XTy
import numpy as np

np.random.seed(42)
X = 2 * np.random.rand(100, 1)
y = 4 + 3 * X.ravel() + np.random.randn(100) * 0.5

X_b = np.c_[np.ones((100, 1)), X]
w_ols = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y
print(f"OLS 解析解: 截距={w_ols[0]:.4f}, 斜率={w_ols[1]:.4f}")

from sklearn.linear_model import LinearRegression
model = LinearRegression().fit(X, y)
print(f"sklearn 结果: 截距={model.intercept_:.4f}, 斜率={model.coef_[0]:.4f}")

梯度下降求解
当数据规模较大或特征维度较高时，使用梯度下降迭代优化更为实际。


w:=w−α∂L∂w,L=12n∑i=1n(yi−y^i)2w := w - \alpha \frac{\partial L}{\partial w}, \quad L = \frac{1}{2n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2w:=w−α∂w∂L​,L=2n1​i=1∑n​(yi​−y^​i​)2
import numpy as np

np.random.seed(42)
X = 2 * np.random.rand(100, 1)
y = 4 + 3 * X.ravel() + np.random.randn(100) * 0.5

w, b = 0.0, 0.0
lr = 0.1
n = len(y)

for epoch in range(1000):
    y_pred = w * X.ravel() + b
    dw = -(2 / n) * np.sum((y - y_pred) * X.ravel())
    db = -(2 / n) * np.sum(y - y_pred)
    w -= lr * dw
    b -= lr * db
    if (epoch + 1) % 200 == 0:
        loss = np.mean((y - y_pred) ** 2)
        print(f"Epoch {epoch+1:4d}: loss={loss:.4f}, w={w:.4f}, b={b:.4f}")


正则化
当特征较多时，线性回归容易过拟合。正则化通过在损失函数中添加惩罚项来约束参数大小。

from sklearn.linear_model import Ridge, Lasso, ElasticNet
from sklearn.datasets import make_regression
from sklearn.model_selection import train_test_split

X, y = make_regression(n_samples=100, n_features=50, n_informative=10, noise=10, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

models = {
    "Linear": LinearRegression(),
    "Ridge":  Ridge(alpha=1.0),
    "Lasso":  Lasso(alpha=1.0),
    "ElasticNet": ElasticNet(alpha=1.0, l1_ratio=0.5),
}

for name, model in models.items():
    model.fit(X_train, y_train)
    score = model.score(X_test, y_test)
    n_nonzero = np.sum(model.coef_ != 0) if hasattr(model, 'coef_') else '-'
    print(f"{name:12s} R²={score:.4f}  非零系数={n_nonzero}")


多项式回归
当数据关系不是线性的，可以通过构造多项式特征来捕捉非线性关系，同时仍然使用线性回归的框架。


from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline
from sklearn.linear_model import LinearRegression
import numpy as np

np.random.seed(42)
X = np.sort(np.random.rand(50, 1) * 6, axis=0)
y = np.sin(X).ravel() + np.random.randn(50) * 0.15

for degree in [1, 3, 10]:
    model = make_pipeline(PolynomialFeatures(degree), LinearRegression())
    model.fit(X, y)
    score = model.score(X, y)
    print(f"多项式阶数 {degree:2d} → R² = {score:.4f}")


提示： 多项式阶数不宜过高。高阶多项式虽然训练集拟合好，但在测试集上容易产生严重过拟合。建议配合交叉验证选择最优阶数，并结合正则化使用。






小结
    

  • 线性回归是最基础的回归算法，通过 y^=wTx+b\hat{y} = \mathbf{w}^T\mathbf{x} + by^​=wTx+b 建模线性关系。
    • 

  • OLS 提供解析解，适合小规模数据；梯度下降适合大规模场景。
    • 

  • Ridge 和 Lasso 正则化分别通过 L2 和 L1 惩罚防止过拟合，Lasso 还具有特征选择能力。
    • 

  • 多项式回归在线性框架内引入非线性能力，但需注意控制复杂度避免过拟合。
    • 

  • 线性回归是理解更复杂模型的基石，其核心思想贯穿整个机器学习领域。
