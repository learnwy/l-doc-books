TFLite 移动端部署

什么是 TensorFlow Lite

TensorFlow Lite（TFLite）是 Google 推出的轻量级推理框架，专为移动设备、嵌入式设备和物联网场景设计。它通过模型转换和量化技术，实现了在资源受限设备上的高效推理。



模型转换
将 TensorFlow 模型转换为 TFLite 格式是部署的第一步。


import numpy as np

def tflite_conversion_example():
    try:
        import tensorflow as tf

        model = tf.keras.Sequential([
            tf.keras.layers.Conv2D(16, 3, activation='relu', input_shape=(28, 28, 1)),
            tf.keras.layers.MaxPooling2D(2),
            tf.keras.layers.Conv2D(32, 3, activation='relu'),
            tf.keras.layers.GlobalAveragePooling2D(),
            tf.keras.layers.Dense(10, activation='softmax'),
        ])

        converter = tf.lite.TFLiteConverter.from_keras_model(model)
        tflite_model = converter.convert()

        with open('/tmp/model.tflite', 'wb') as f:
            f.write(tflite_model)

        print(f"TFLite 模型大小: {len(tflite_model) / 1024:.1f} KB")
    except ImportError:
        print("需要安装 tensorflow: pip install tensorflow")

def quantization_example():
    try:
        import tensorflow as tf
        import numpy as np

        model = tf.keras.Sequential([
            tf.keras.layers.Dense(64, activation='relu', input_shape=(20,)),
            tf.keras.layers.Dense(32, activation='relu'),
            tf.keras.layers.Dense(10, activation='softmax'),
        ])
        model.compile(optimizer='adam', loss='sparse_categorical_crossentropy')

        converter = tf.lite.TFLiteConverter.from_keras_model(model)

        tflite_fp32 = converter.convert()

        converter.optimizations = [tf.lite.Optimize.DEFAULT]
        tflite_dynamic = converter.convert()

        converter.optimizations = [tf.lite.Optimize.DEFAULT]
        converter.target_spec.supported_types = [tf.float16]
        tflite_fp16 = converter.convert()

        print(f"FP32 模型:  {len(tflite_fp32) / 1024:.1f} KB")
        print(f"动态量化:   {len(tflite_dynamic) / 1024:.1f} KB  "
              f"(压缩 {len(tflite_fp32)/len(tflite_dynamic):.1f}x)")
        print(f"FP16 量化:  {len(tflite_fp16) / 1024:.1f} KB  "
              f"(压缩 {len(tflite_fp32)/len(tflite_fp16):.1f}x)")
    except ImportError:
        print("需要安装 tensorflow: pip install tensorflow")

    "android": {
        "primary": "NNAPI Delegate",
        "fallback": "GPU Delegate → XNNPACK",
        "note": "NNAPI 自动路由到最优硬件（NPU/GPU/DSP）",

    },

for platform, config in delegate_config.items():
    print(f"\n{platform.upper()} 推理策略:")

性能优化清单


提示： 移动端部署的关键不仅是模型精度，更要关注推理延迟、模型大小和功耗。建议先用动态量化快速验证，再用静态量化或 QAT 进一步优化。






小结
    

  • TFLite 是移动端和嵌入式设备的主流推理框架，支持 Android 和 iOS。
    • 

  • 量化是减小模型体积和加速推理的核心技术，动态量化最简单，QAT 精度最好。
    • 

  • Delegate 机制将推理卸载到 GPU/NPU/DSP 等硬件加速器，显著提升速度。
    • 

  • Android 和 iOS 都有成熟的 TFLite SDK，集成流程标准化。
    • 

  • 移动端部署需要综合考虑精度、延迟、模型大小和功耗的平衡。
