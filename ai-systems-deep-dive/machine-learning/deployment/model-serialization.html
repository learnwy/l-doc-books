模型序列化

什么是模型序列化

模型序列化（Model Serialization）是将训练好的模型保存为文件，以便后续加载用于推理或继续训练。这是将模型从实验环境部署到生产环境的第一步。



Python Pickle
Pickle 是 Python 原生的序列化方式，scikit-learn 模型最常使用 pickle 或 joblib 保存。


import pickle
import joblib
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.3, random_state=42
)

model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(X_train, y_train)

with open('/tmp/model_pickle.pkl', 'wb') as f:
    pickle.dump(model, f)

joblib.dump(model, '/tmp/model_joblib.pkl')

model_loaded = joblib.load('/tmp/model_joblib.pkl')
print(f"原始模型准确率:   {model.score(X_test, y_test):.4f}")
print(f"加载模型准确率:   {model_loaded.score(X_test, y_test):.4f}")

import os
pickle_size = os.path.getsize('/tmp/model_pickle.pkl')
joblib_size = os.path.getsize('/tmp/model_joblib.pkl')
print(f"\nPickle 文件大小: {pickle_size / 1024:.1f} KB")
print(f"Joblib 文件大小: {joblib_size / 1024:.1f} KB")

提示： 永远不要加载不信任来源的 pickle 文件。Pickle 可以执行任意代码，存在严重的安全风险。






PyTorch 模型保存
PyTorch 提供两种保存模型的方式：保存完整模型和只保存权重（推荐）。


import torch
import torch.nn as nn

class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(10, 50)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(50, 3)

    def forward(self, x):
        return self.fc2(self.relu(self.fc1(x)))

model = SimpleNet()

torch.save(model.state_dict(), '/tmp/model_weights.pth')

model_loaded = SimpleNet()
model_loaded.load_state_dict(torch.load('/tmp/model_weights.pth'))
model_loaded.eval()

x = torch.randn(1, 10)
with torch.no_grad():
    out_original = model(x)
    out_loaded = model_loaded(x)
print(f"输出一致: {torch.allclose(out_original, out_loaded)}")

checkpoint = {
    'epoch': 50,
    'model_state_dict': model.state_dict(),
    'optimizer_state_dict': torch.optim.Adam(model.parameters()).state_dict(),
    'loss': 0.05,
}
torch.save(checkpoint, '/tmp/checkpoint.pth')
print(f"Checkpoint 已保存")

ONNX 格式
ONNX（Open Neural Network Exchange）是跨框架的模型交换标准。训练在 PyTorch 中完成，推理可以用 ONNX Runtime、TensorRT 等高效引擎。


import torch
import torch.nn as nn

class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(10, 50)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(50, 3)

    def forward(self, x):
        return self.fc2(self.relu(self.fc1(x)))

model = SimpleNet()
model.eval()

dummy_input = torch.randn(1, 10)

torch.onnx.export(
    model, dummy_input,
    '/tmp/model.onnx',
    input_names=['input'],
    output_names=['output'],
    dynamic_axes={'input': {0: 'batch'}, 'output': {0: 'batch'}},
    opset_version=13,
)
print("ONNX 模型已导出")


TorchScript
TorchScript 是 PyTorch 自带的模型序列化方案，支持脱离 Python 环境运行。


import torch
import torch.nn as nn

class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(10, 50)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(50, 3)

    def forward(self, x):
        return self.fc2(self.relu(self.fc1(x)))

model = SimpleNet()
model.eval()

scripted = torch.jit.script(model)
scripted.save('/tmp/model_scripted.pt')

traced = torch.jit.trace(model, torch.randn(1, 10))
traced.save('/tmp/model_traced.pt')

loaded = torch.jit.load('/tmp/model_scripted.pt')
x = torch.randn(1, 10)
with torch.no_grad():
    out = loaded(x)
print(f"TorchScript 输出形状: {list(out.shape)}")

提示： 在生产环境中，总是保存权重而非完整模型。完整模型与 Python 版本和库版本强绑定，容易在环境变化时出问题。同时，ONNX 是跨框架部署的最佳选择。






小结
    

  • Pickle/Joblib 是 scikit-learn 模型的标准保存方式，但有安全风险。
    • 

  • PyTorch 推荐保存 state_dict，Checkpoint 用于断点续训。
    • 

  • ONNX 是跨框架模型交换标准，搭配 ONNX Runtime 可实现高效推理。
    • 

  • TorchScript 支持脱离 Python 运行，适合 C++ 推理环境。
    • 

  • 版本控制确保模型的可追溯性，DVC 和 MLflow 是常用工具。
