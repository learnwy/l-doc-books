MLOps 基础

什么是 MLOps

MLOps（Machine Learning Operations）是将机器学习模型从实验阶段高效、可靠地部署到生产环境，并持续维护的一套实践和工具体系。它结合了 ML、DevOps 和数据工程的最佳实践。

实验追踪
实验追踪记录每次训练的超参数、指标、模型和数据集版本，确保实验可复现。


MLflow
def mlflow_tracking_example():
    try:
        import mlflow
        import mlflow.sklearn
        from sklearn.ensemble import RandomForestClassifier
        from sklearn.datasets import load_iris
        from sklearn.model_selection import train_test_split, cross_val_score

        iris = load_iris()
        X_train, X_test, y_train, y_test = train_test_split(
            iris.data, iris.target, test_size=0.3, random_state=42
        )

        mlflow.set_experiment("iris_classification")

        configs = [
            {"n_estimators": 50, "max_depth": 3},
            {"n_estimators": 100, "max_depth": 5},
            {"n_estimators": 200, "max_depth": None},
        ]

        for params in configs:
            with mlflow.start_run():
                model = RandomForestClassifier(**params, random_state=42)
                model.fit(X_train, y_train)

                accuracy = model.score(X_test, y_test)
                cv_scores = cross_val_score(model, iris.data, iris.target, cv=5)

                mlflow.log_params(params)
                mlflow.log_metric("accuracy", accuracy)
                mlflow.log_metric("cv_mean", cv_scores.mean())
                mlflow.log_metric("cv_std", cv_scores.std())
                mlflow.sklearn.log_model(model, "model")

                print(f"参数={params} → 准确率={accuracy:.4f}")
    except ImportError:
        print("需要安装 mlflow: pip install mlflow")

mlflow_tracking_example()

模型注册中心
模型注册中心（Model Registry）是管理模型生命周期的核心组件，记录模型的版本、状态和元数据。

import numpy as np

def detect_data_drift(reference_data, current_data, threshold=0.1):
    ref_mean = np.mean(reference_data, axis=0)
    ref_std = np.std(reference_data, axis=0) + 1e-8
    cur_mean = np.mean(current_data, axis=0)

    drift_scores = np.abs(cur_mean - ref_mean) / ref_std
    drifted_features = np.where(drift_scores > threshold)[0]

    return {
        "drift_scores": drift_scores.tolist(),
        "drifted_features": drifted_features.tolist(),
        "is_drifted": len(drifted_features) > 0,
    }

np.random.seed(42)
reference = np.random.randn(1000, 5)
current_normal = np.random.randn(100, 5)
current_drifted = np.random.randn(100, 5) + [0, 0, 2.0, 0, 0]

result_normal = detect_data_drift(reference, current_normal, threshold=0.5)
result_drifted = detect_data_drift(reference, current_drifted, threshold=0.5)

print("正常数据:")
print(f"  漂移检测: {result_normal['is_drifted']}")
print(f"  漂移分数: {[f'{s:.2f}' for s in result_normal['drift_scores']]}")

print("\n漂移数据:")
print(f"  漂移检测: {result_drifted['is_drifted']}")
print(f"  漂移分数: {[f'{s:.2f}' for s in result_drifted['drift_scores']]}")
print(f"  漂移特征: {result_drifted['drifted_features']}")


提示： MLOps 不是一蹴而就的，建议分阶段实施。Level 0：手动全部流程；Level 1：自动化训练流水线；Level 2：自动化 CI/CD + 持续监控。根据团队规模和业务需求选择合适的成熟度等级。






小结
    

  • MLOps 是 ML + DevOps + 数据工程的融合，解决模型从实验到生产的全生命周期管理。
    • 

  • 实验追踪（MLflow、W&B）确保实验可复现，是 MLOps 的基础。
    • 

  • CI/CD for ML 包括数据验证、模型训练、评估和自动部署的完整流水线。
    • 

  • 模型注册中心管理模型版本和生命周期，支持灰度发布和快速回滚。
    • 

  • 模型监控检测数据漂移和性能退化，触发自动重训练，保障线上模型质量。
