CNN 基础

什么是卷积神经网络

卷积神经网络（Convolutional Neural Network, CNN）是处理网格状数据（如图像）的专用深度学习架构。它通过卷积操作自动提取空间层次特征，从低级边缘纹理到高级语义概念，逐层抽象。

卷积操作
卷积（Convolution）是 CNN 的核心操作。一个小的卷积核（kernel/filter）在输入上滑动，在每个位置计算卷积核与局部区域的点积。


Output(i,j)=∑m∑nInput(i+m,j+n)⋅Kernel(m,n)+bias\text{Output}(i, j) = \sum_{m}\sum_{n} \text{Input}(i+m, j+n) \cdot \text{Kernel}(m, n) + \text{bias}Output(i,j)=m∑​n∑​Input(i+m,j+n)⋅Kernel(m,n)+bias
import torch
import torch.nn as nn

conv = nn.Conv2d(in_channels=1, out_channels=1, kernel_size=3, padding=1, bias=False)

input_image = torch.tensor([
    [1, 2, 3, 0, 1],
    [0, 1, 2, 3, 1],
    [1, 0, 1, 2, 0],
    [2, 1, 0, 1, 3],
    [1, 2, 1, 0, 2],
], dtype=torch.float32).unsqueeze(0).unsqueeze(0)

with torch.no_grad():
    conv.weight.copy_(torch.tensor([
        [1, 0, -1],
        [1, 0, -1],
        [1, 0, -1],
    ], dtype=torch.float32).unsqueeze(0).unsqueeze(0))

output = conv(input_image)
print(f"输入形状: {input_image.shape}")
print(f"输出形状: {output.shape}")
print(f"输出:\n{output.squeeze()}")

池化操作
池化（Pooling）对特征图进行降采样，减少空间维度和计算量，同时增强特征的平移不变性。


import torch
import torch.nn as nn

feature_map = torch.tensor([
    [1, 3, 2, 4],
    [5, 6, 1, 2],
    [3, 2, 7, 8],
    [4, 1, 5, 6],
], dtype=torch.float32).unsqueeze(0).unsqueeze(0)

max_pool = nn.MaxPool2d(kernel_size=2, stride=2)
avg_pool = nn.AvgPool2d(kernel_size=2, stride=2)

print(f"输入:\n{feature_map.squeeze()}")
print(f"\nMax Pooling:\n{max_pool(feature_map).squeeze()}")
print(f"\nAvg Pooling:\n{avg_pool(feature_map).squeeze()}")

特征图与感受野
随着网络层数的增加，每个神经元的感受野（Receptive Field）逐层扩大，即它"看到"的原始输入区域越来越大。


import torch
import torch.nn as nn

cnn = nn.Sequential(
    nn.Conv2d(1, 16, 3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2),
    nn.Conv2d(16, 32, 3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2),
    nn.Conv2d(32, 64, 3, padding=1),
    nn.ReLU(),
)

x = torch.randn(1, 1, 28, 28)
for i, layer in enumerate(cnn):
    x = layer(x)
    if isinstance(layer, (nn.Conv2d, nn.MaxPool2d)):
        print(f"Layer {i:2d} ({layer.__class__.__name__:10s}): {list(x.shape)}")


经典 CNN 架构
LeNet-5
LeNet-5（1998）是 Yann LeCun 设计的第一个成功的 CNN 架构，用于手写数字识别。


import torch
import torch.nn as nn

class LeNet5(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 6, 5),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(6, 16, 5),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.classifier = nn.Sequential(
            nn.Linear(16 * 4 * 4, 120),
            nn.ReLU(),
            nn.Linear(120, 84),
            nn.ReLU(),
            nn.Linear(84, 10),
        )

    def forward(self, x):
        x = self.features(x)
        x = x.view(x.size(0), -1)
        return self.classifier(x)

model = LeNet5()
x = torch.randn(1, 1, 28, 28)
output = model(x)
print(f"输入: {list(x.shape)} → 输出: {list(output.shape)}")
total_params = sum(p.numel() for p in model.parameters())
print(f"总参数量: {total_params:,}")
ResNet
ResNet（2015）引入了残差连接（Skip Connection），使得训练数百层的网络成为可能。


import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.block = nn.Sequential(
            nn.Conv2d(channels, channels, 3, padding=1),
            nn.BatchNorm2d(channels),
            nn.ReLU(),
            nn.Conv2d(channels, channels, 3, padding=1),
            nn.BatchNorm2d(channels),
        )
        self.relu = nn.ReLU()

    def forward(self, x):
        return self.relu(self.block(x) + x)

block = ResidualBlock(64)
x = torch.randn(1, 64, 16, 16)
output = block(x)
print(f"输入: {list(x.shape)} → 输出: {list(output.shape)}")

小结
    

  • CNN 通过卷积操作自动提取空间特征，利用权重共享大幅减少参数量。
    • 

  • 池化降低空间维度并增强平移不变性，Max Pooling 是最常用的选择。
    • 

  • 感受野随网络深度逐层增大，使深层特征能捕捉更大范围的语义信息。
    • 

  • LeNet 开创了 CNN 的先河，ResNet 的残差连接解决了深度网络的退化问题。
    • 

  • CNN 是计算机视觉领域的基础架构，理解其原理对后续学习 Transformer 等现代架构至关重要。
