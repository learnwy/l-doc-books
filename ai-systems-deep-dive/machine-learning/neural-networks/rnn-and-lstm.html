RNN 与 LSTM

序列建模

循环神经网络（Recurrent Neural Network, RNN）是处理序列数据的专用架构。与前馈网络不同，RNN 拥有隐藏状态（Hidden State），能记住之前时间步的信息，从而对时间序列、文本等具有时序依赖的数据进行建模。

RNN 的核心递推公式：


ht=tanh⁡(Whhht−1+Wxhxt+bh)h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)ht​=tanh(Whh​ht−1​+Wxh​xt​+bh​)
 


yt=Whyht+byy_t = W_{hy} h_t + b_yyt​=Why​ht​+by​


基本 RNN
import torch
import torch.nn as nn

rnn = nn.RNN(input_size=10, hidden_size=20, num_layers=1, batch_first=True)

x = torch.randn(4, 5, 10)
h0 = torch.zeros(1, 4, 20)

output, hn = rnn(x, h0)

print(f"输入形状:     {list(x.shape)}")
print(f"输出形状:     {list(output.shape)}")
print(f"最终隐藏状态: {list(hn.shape)}")
print(f"output[:, -1] == hn: {torch.allclose(output[:, -1], hn.squeeze(0))}")

RNN 的梯度问题
基本 RNN 在处理长序列时会遇到严重的梯度消失问题。因为梯度在时间步上连乘，Tanh 的导数 < 1 导致梯度指数级衰减。


∂hT∂h1=∏t=2T∂ht∂ht−1=∏t=2TWhh⋅diag(tanh⁡′(zt))\frac{\partial h_T}{\partial h_1} = \prod_{t=2}^{T} \frac{\partial h_t}{\partial h_{t-1}} = \prod_{t=2}^{T} W_{hh} \cdot \text{diag}(\tanh'(z_t))∂h1​∂hT​​=t=2∏T​∂ht−1​∂ht​​=t=2∏T​Whh​⋅diag(tanh′(zt​))
import torch
import torch.nn as nn

rnn = nn.RNN(10, 20, batch_first=True)

short_seq = torch.randn(1, 5, 10, requires_grad=True)
long_seq = torch.randn(1, 100, 10, requires_grad=True)

out_short, _ = rnn(short_seq)
loss_short = out_short[:, -1].sum()
loss_short.backward()
print(f"短序列 (len=5)   输入梯度范数: {short_seq.grad.norm():.6f}")

short_seq.grad = None
out_long, _ = rnn(long_seq)
loss_long = out_long[:, -1].sum()
loss_long.backward()
print(f"长序列 (len=100) 输入梯度范数: {long_seq.grad.norm():.6f}")


LSTM
长短期记忆网络（Long Short-Term Memory, LSTM）通过引入门控机制和细胞状态，有效解决了梯度消失问题。


LSTM 的门控方程：


ft=σ(Wf[ht−1,xt]+bf)遗忘门f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) \quad \text{遗忘门}ft​=σ(Wf​[ht−1​,xt​]+bf​)遗忘门
 


it=σ(Wi[ht−1,xt]+bi)输入门i_t = \sigma(W_i [h_{t-1}, x_t] + b_i) \quad \text{输入门}it​=σ(Wi​[ht−1​,xt​]+bi​)输入门
 


C~t=tanh⁡(WC[ht−1,xt]+bC)候选记忆\tilde{C}_t = \tanh(W_C [h_{t-1}, x_t] + b_C) \quad \text{候选记忆}C~t​=tanh(WC​[ht−1​,xt​]+bC​)候选记忆
 


Ct=ft⊙Ct−1+it⊙C~t更新细胞状态C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t \quad \text{更新细胞状态}Ct​=ft​⊙Ct−1​+it​⊙C~t​更新细胞状态
 


ot=σ(Wo[ht−1,xt]+bo)输出门o_t = \sigma(W_o [h_{t-1}, x_t] + b_o) \quad \text{输出门}ot​=σ(Wo​[ht−1​,xt​]+bo​)输出门
 


ht=ot⊙tanh⁡(Ct)隐藏状态h_t = o_t \odot \tanh(C_t) \quad \text{隐藏状态}ht​=ot​⊙tanh(Ct​)隐藏状态
import torch
import torch.nn as nn

lstm = nn.LSTM(input_size=10, hidden_size=20, num_layers=2, batch_first=True)

x = torch.randn(4, 50, 10)
h0 = torch.zeros(2, 4, 20)
c0 = torch.zeros(2, 4, 20)

output, (hn, cn) = lstm(x, (h0, c0))

print(f"输入形状:     {list(x.shape)}")
print(f"输出形状:     {list(output.shape)}")
print(f"最终 h 状态:  {list(hn.shape)}")
print(f"最终 c 状态:  {list(cn.shape)}")

GRU
门控循环单元（Gated Recurrent Unit, GRU）是 LSTM 的简化变体，将遗忘门和输入门合并为更新门，参数更少但效果相当。


zt=σ(Wz[ht−1,xt])更新门z_t = \sigma(W_z [h_{t-1}, x_t]) \quad \text{更新门}zt​=σ(Wz​[ht−1​,xt​])更新门
 


rt=σ(Wr[ht−1,xt])重置门r_t = \sigma(W_r [h_{t-1}, x_t]) \quad \text{重置门}rt​=σ(Wr​[ht−1​,xt​])重置门
 


h~t=tanh⁡(W[rt⊙ht−1,xt])\tilde{h}_t = \tanh(W [r_t \odot h_{t-1}, x_t])h~t​=tanh(W[rt​⊙ht−1​,xt​])
 


ht=(1−zt)⊙ht−1+zt⊙h~th_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_tht​=(1−zt​)⊙ht−1​+zt​⊙h~t​
import torch
import torch.nn as nn

rnn_model = nn.RNN(10, 20, batch_first=True)
lstm_model = nn.LSTM(10, 20, batch_first=True)
gru_model = nn.GRU(10, 20, batch_first=True)

for name, model in [("RNN", rnn_model), ("LSTM", lstm_model), ("GRU", gru_model)]:
    params = sum(p.numel() for p in model.parameters())
    print(f"{name:5s} 参数量: {params:,}")


双向 RNN
双向 RNN（Bidirectional RNN）同时从前向和后向处理序列，每个时间步可以利用过去和未来的上下文信息。


import torch
import torch.nn as nn

bi_lstm = nn.LSTM(
    input_size=10, hidden_size=20,
    num_layers=1, batch_first=True,
    bidirectional=True
)

x = torch.randn(4, 15, 10)
output, (hn, cn) = bi_lstm(x)

print(f"输入形状: {list(x.shape)}")
print(f"输出形状: {list(output.shape)}")
print(f"隐藏状态: {list(hn.shape)}")
print(f"输出维度 = hidden_size × 2 = {20 * 2}")


提示： 虽然 Transformer 在很多序列任务上已超越 RNN/LSTM，但 LSTM 在小数据量时序预测、流式处理、嵌入式设备等场景仍有不可替代的优势。理解 RNN 的递归机制和门控原理，也是理解现代序列模型的基础。






小结
    

  • RNN 通过隐藏状态实现序列建模，但存在严重的梯度消失问题，难以学习长期依赖。
    • 

  • LSTM 通过遗忘门、输入门、输出门和细胞状态，有效解决了长期依赖问题。
    • 

  • GRU 是 LSTM 的简化版本，参数更少，性能相当，适合资源受限场景。
    • 

  • 双向 RNN 同时利用前向和后向上下文，适合需要全局信息的任务（如 NER、情感分析）。
    • 

  • RNN 系列模型是序列建模的经典方法，其核心思想影响了包括 Transformer 在内的后续架构设计。
