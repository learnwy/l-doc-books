感知机与多层网络

感知机

感知机（Perceptron）是最早的神经网络模型（1957 年 Rosenblatt 提出），也是神经网络的基本构建单元。它接收多个输入，通过加权求和后经过激活函数输出结果。

y=f(∑i=1nwixi+b)=f(wTx+b)y = f(\sum_{i=1}^{n} w_i x_i + b) = f(\mathbf{w}^T\mathbf{x} + b)y=f(i=1∑n​wi​xi​+b)=f(wTx+b)
import numpy as np

class SimplePerceptron:
    def __init__(self, n_features, lr=0.1):
        self.w = np.zeros(n_features)
        self.b = 0.0
        self.lr = lr

    def predict(self, x):
        return 1 if np.dot(self.w, x) + self.b > 0 else 0

    def train(self, X, y, epochs=100):
        for epoch in range(epochs):
            errors = 0
            for xi, yi in zip(X, y):
                pred = self.predict(xi)
                if pred != yi:
                    self.w += self.lr * (yi - pred) * xi
                    self.b += self.lr * (yi - pred)
                    errors += 1
            if errors == 0:
                print(f"第 {epoch+1} 轮收敛")
                break

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
y_and = np.array([0, 0, 0, 1])

p = SimplePerceptron(2)
p.train(X, y_and)
for xi in X:
    print(f"AND({xi}) = {p.predict(xi)}")

XOR 问题的发现（Minsky & Papert, 1969）一度导致了神经网络研究的寒冬。直到多层网络和反向传播算法的出现，才重新点燃了这一领域。




多层感知机（MLP）
多层感知机（Multi-Layer Perceptron）通过引入一个或多个隐藏层，获得了表达非线性函数的能力。


import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(2, 4),
    nn.ReLU(),
    nn.Linear(4, 1),
    nn.Sigmoid()
)

X = torch.tensor([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=torch.float32)
y = torch.tensor([[0], [1], [1], [0]], dtype=torch.float32)

optimizer = torch.optim.Adam(model.parameters(), lr=0.05)
criterion = nn.BCELoss()

for epoch in range(2000):
    pred = model(X)
    loss = criterion(pred, y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

with torch.no_grad():
    predictions = model(X)
    for xi, yi, pi in zip(X, y, predictions):
        print(f"输入={xi.tolist()} 真实={int(yi.item())} 预测={pi.item():.4f}")

万能逼近定理
万能逼近定理（Universal Approximation Theorem）指出：一个具有单个隐藏层和足够多神经元的前馈网络，可以以任意精度逼近任何连续函数。


虽然理论上一层就够，但实践中深度网络（多个隐藏层）比宽而浅的网络更高效：

提示： MLP 是所有深度学习模型的基础。理解感知机的线性局限性、隐藏层引入非线性的机制，以及激活函数的作用，是深入学习 CNN、RNN 等架构的前提。






小结
    

  • 感知机是最简单的神经网络，只能处理线性可分问题。
    • 

  • XOR 问题证明了单层网络的局限性，推动了多层网络的发展。
    • 

  • 多层感知机通过隐藏层和激活函数获得了强大的非线性表达能力。
    • 

  • 激活函数是引入非线性的关键，ReLU 是目前最常用的选择。
    • 

  • 万能逼近定理提供了理论保证，但实际中深度网络比宽浅网络更高效。
