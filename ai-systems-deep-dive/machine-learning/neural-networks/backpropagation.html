反向传播

什么是反向传播

反向传播（Backpropagation）是训练神经网络的核心算法。它利用链式法则高效地计算损失函数对每一层参数的梯度，然后通过梯度下降更新参数。

flowchart LR
    A["输入 X"] --> B["前向传播"]
    B --> C["损失 L"]
    C --> D["反向传播"]
    D --> E["计算各层梯度"]
    E --> F["更新参数"]
    F -->|"下一轮"| A

反向传播的核心等式：

∂L∂wij=∂L∂aj⋅∂aj∂zj⋅∂zj∂wij\frac{\partial L}{\partial w_{ij}} = \frac{\partial L}{\partial a_j} \cdot \frac{\partial a_j}{\partial z_j} \cdot \frac{\partial z_j}{\partial w_{ij}}∂wij​∂L​=∂aj​∂L​⋅∂zj​∂aj​​⋅∂wij​∂zj​​

核心概念

反向传播围绕四个概念展开：

  • 链式法则（Chain Rule）：dfdx=dfdg⋅dgdx\frac{df}{dx} = \frac{df}{dg} \cdot \frac{dg}{dx}dxdf​=dgdf​⋅dxdg​，是整个算法的数学基础。多层复合函数的梯度就是各层导数的连乘。
  • 计算图（Computational Graph）：把前向计算表示为节点与边的有向图。它把"求梯度"变成了一个有明确规则的图遍历问题：前向算值，反向传递梯度。
  • 局部梯度：每个节点只需知道自己的导数，不必关心全局梯度。这正是反向传播高效的原因——复杂度与前向传播同阶。
  • 梯度流（Gradient Flow）：梯度从输出层向输入层传播的过程。它的稳定性决定训练能否成功：连乘使其指数级衰减（梯度消失）或增长（梯度爆炸）。

这四者串成一句结论：链式法则给出方法，计算图给出结构，局部梯度给出效率，而梯度流决定了深度。末尾的 ReLU、残差连接、BN 等技巧，本质上都是在改善梯度流。

链式法则

链式法则（Chain Rule）是微积分中的基本定理，也是反向传播的数学基础。对于复合函数 f(g(x))f(g(x))f(g(x))：

dfdx=dfdg⋅dgdx\frac{df}{dx} = \frac{df}{dg} \cdot \frac{dg}{dx}dxdf​=dgdf​⋅dxdg​

对于神经网络这样的多层复合函数，链式法则逐层传递梯度：

import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    s = sigmoid(x)
    return s * (1 - s)

x = 2.0
w1, w2 = 0.5, -0.3
b1, b2 = 0.1, 0.2
y_true = 1.0

z1 = w1 * x + b1
a1 = sigmoid(z1)
z2 = w2 * a1 + b2
a2 = sigmoid(z2)
loss = 0.5 * (y_true - a2) ** 2

dL_da2 = -(y_true - a2)
da2_dz2 = sigmoid_derivative(z2)
dz2_dw2 = a1
dz2_da1 = w2
da1_dz1 = sigmoid_derivative(z1)
dz1_dw1 = x

dL_dw2 = dL_da2 * da2_dz2 * dz2_dw2
dL_dw1 = dL_da2 * da2_dz2 * dz2_da1 * da1_dz1 * dz1_dw1

print(f"损失: {loss:.6f}")
print(f"∂L/∂w2 = {dL_dw2:.6f}")
print(f"∂L/∂w1 = {dL_dw1:.6f}")

计算图

计算图（Computational Graph）是理解反向传播的直观工具。前向传播沿计算图正向计算输出，反向传播沿计算图反向传递梯度。

flowchart LR
    X["x"] --> MUL1["×"]
    W1["w₁"] --> MUL1
    MUL1 --> ADD1["+"]
    B1["b₁"] --> ADD1
    ADD1 --> SIG1["σ"]
    SIG1 --> MUL2["×"]
    W2["w₂"] --> MUL2
    MUL2 --> ADD2["+"]
    B2["b₂"] --> ADD2
    ADD2 --> SIG2["σ"]
    SIG2 --> LOSS["L"]
    Y["y"] --> LOSS

PyTorch 使用动态计算图自动实现反向传播：

import torch
import torch.nn as nn

torch.manual_seed(42)

model = nn.Sequential(
    nn.Linear(2, 3),
    nn.ReLU(),
    nn.Linear(3, 1),
)

X = torch.randn(4, 2)
y = torch.randn(4, 1)

output = model(X)
loss = nn.MSELoss()(output, y)
loss.backward()

for name, param in model.named_parameters():
    if param.grad is not None:
        print(f"{name:20s} 参数形状={list(param.shape)}  "
              f"梯度范数={param.grad.norm().item():.4f}")

梯度流

梯度在网络中的流动直接影响训练效果。理想情况下，梯度应该稳定地从输出层传播到输入层。

flowchart RL
    L["损失层<br/>∂L/∂L = 1"] --> H3["隐藏层 3<br/>∂L/∂h₃"]
    H3 --> H2["隐藏层 2<br/>∂L/∂h₂"]
    H2 --> H1["隐藏层 1<br/>∂L/∂h₁"]
    H1 --> IN["输入层<br/>∂L/∂x"]
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(10, 50),
    nn.Sigmoid(),
    nn.Linear(50, 50),
    nn.Sigmoid(),
    nn.Linear(50, 50),
    nn.Sigmoid(),
    nn.Linear(50, 50),
    nn.Sigmoid(),
    nn.Linear(50, 1),
)

X = torch.randn(32, 10)
y = torch.randn(32, 1)

output = model(X)
loss = nn.MSELoss()(output, y)
loss.backward()

print("各层梯度范数（Sigmoid 激活）:")
for i, (name, param) in enumerate(model.named_parameters()):
    if 'weight' in name:
        grad_norm = param.grad.norm().item()
        bar = "█" * max(1, int(grad_norm * 1000))
        print(f"  {name:15s} {grad_norm:.6f} {bar}")

梯度消失与梯度爆炸

梯度消失和梯度爆炸是深度网络训练中的两个核心挑战。

问题 原因 表现 解决方案
梯度消失 Sigmoid/Tanh 导数 < 1 连乘 前层参数几乎不更新 ReLU、残差连接、BN
梯度爆炸 权重矩阵特征值 > 1 连乘 参数更新剧烈，NaN 梯度裁剪、权重初始化 
import torch
import torch.nn as nn

def check_gradients(activation_fn, name):
    layers = []
    for _ in range(10):
        layers.append(nn.Linear(20, 20))
        layers.append(activation_fn())
    layers.append(nn.Linear(20, 1))
    model = nn.Sequential(*layers)

    X = torch.randn(16, 20)
    y = torch.randn(16, 1)
    loss = nn.MSELoss()(model(X), y)
    loss.backward()

    grads = []
    for p_name, param in model.named_parameters():
        if 'weight' in p_name and param.grad is not None:
            grads.append(param.grad.norm().item())

    print(f"{name:12s} 第一层梯度={grads[0]:.2e}  "
          f"最后一层梯度={grads[-1]:.2e}  "
          f"比值={grads[0]/max(grads[-1], 1e-20):.2e}")

check_gradients(nn.Sigmoid, "Sigmoid")
check_gradients(nn.ReLU, "ReLU")
check_gradients(nn.Tanh, "Tanh")

提示： 现代深度学习中，通过 ReLU 激活函数、残差连接（ResNet）、Batch Normalization 和合理的权重初始化（He/Xavier），梯度消失/爆炸问题已经得到有效缓解，使得训练数百层的网络成为可能。

小结

  • 反向传播利用链式法则高效计算各层参数的梯度，是神经网络训练的核心算法。
  • 计算图提供了前向传播和反向传播的直观表示，PyTorch 通过动态计算图自动实现。
  • 梯度流从输出层向输入层传播，理想状态下梯度大小应保持稳定。
  • 梯度消失使前层无法学习，梯度爆炸使训练不稳定，两者都是深度网络的核心挑战。
  • ReLU、残差连接、BN 和合理初始化是解决梯度问题的标准工具箱。
