数据清洗流水线

核心概念

数据清洗流水线（Data Cleaning Pipeline）是将原始数据转化为可用于模型训练的高质量数据集的系统化处理流程。在 AI 项目中，数据科学家通常花费 60-80% 的时间在数据清洗上。一条设计良好的清洗流水线不仅能提高数据质量，还能确保清洗过程的可重复性、可追溯性和可扩展性。

数据清洗的核心原则是幂等性——同样的原始数据经过同一条流水线，必须始终产出相同的结果。

流水线架构

一条生产级数据清洗流水线由多个可组合的处理阶段组成，每个阶段负责一个特定的清洗任务。

interface CleaningStage<T> {
  name: string;
  process: (data: T[]) => T[];
  validate: (data: T[]) => ValidationResult;
}

interface ValidationResult {
  passed: boolean;
  metrics: Record<string, number>;
  errors: string[];
}

interface PipelineConfig {
  stages: CleaningStage<Record<string, unknown>>[];
  failureStrategy: 'stop' | 'skip' | 'quarantine';
  batchSize: number;
  enableCheckpoints: boolean;
}

const executePipeline = <T extends Record<string, unknown>>(
  data: T[],
  config: PipelineConfig,
): { result: T[]; report: PipelineReport } => {
  let current = data;
  const report: PipelineReport = { stages: [], totalInput: data.length, totalOutput: 0 };

  for (const stage of config.stages) {
    const before = current.length;
    current = stage.process(current) as T[];
    const validation = stage.validate(current as Record<string, unknown>[]);

    report.stages.push({
      name: stage.name,
      inputCount: before,
      outputCount: current.length,
      droppedCount: before - current.length,
      validation,
    });

    if (!validation.passed && config.failureStrategy === 'stop') {
      throw new Error(`Stage ${stage.name} validation failed`);
    }
  }

  report.totalOutput = current.length;
  return { result: current, report };
};

常见清洗操作

清洗类型 问题描述 处理方法 注意事项
缺失值 字段为空或 NULL 删除/填充/插值 区分随机缺失和系统性缺失
异常值 数值超出合理范围 截断/替换/删除 需要领域知识判断
重复记录 完全或部分重复 精确去重/模糊去重 保留最新或最完整版本
格式不一致 日期格式混乱、编码不统一 统一格式标准 保留原始格式备查
类型错误 字符串存数字 类型转换+验证 转换失败的处理策略 
const cleanMissingValues = (
  records: Record<string, unknown>[],
  strategy: Record<string, 'drop' | 'mean' | 'median' | 'mode' | 'default'>,
  defaults: Record<string, unknown>,
): Record<string, unknown>[] => {
  return records
    .filter((record) => {
      const dropFields = Object.entries(strategy)
        .filter(([, s]) => s === 'drop')
        .map(([field]) => field);
      return dropFields.every((f) => record[f] != null);
    })
    .map((record) => {
      const cleaned = { ...record };
      for (const [field, method] of Object.entries(strategy)) {
        if (cleaned[field] == null && method === 'default') {
          cleaned[field] = defaults[field];
        }
      }
      return cleaned;
    });
};

const detectOutliers = (values: number[], method: 'iqr' | 'zscore', threshold: number = 3): Set<number> => {
  const outlierIndices = new Set<number>();

  if (method === 'zscore') {
    const mean = values.reduce((a, b) => a + b, 0) / values.length;
    const std = Math.sqrt(values.reduce((sum, v) => sum + (v - mean) ** 2, 0) / values.length);
    values.forEach((v, i) => {
      if (Math.abs((v - mean) / std) > threshold) outlierIndices.add(i);
    });
  }

  if (method === 'iqr') {
    const sorted = [...values].sort((a, b) => a - b);
    const q1 = sorted[Math.floor(sorted.length * 0.25)];
    const q3 = sorted[Math.floor(sorted.length * 0.75)];
    const iqr = q3 - q1;
    values.forEach((v, i) => {
      if (v < q1 - 1.5 * iqr || v > q3 + 1.5 * iqr) outlierIndices.add(i);
    });
  }

  return outlierIndices;
};

数据质量监控

流水线的每个阶段都需要输出质量指标，用于监控数据健康状况。

指标 计算方法 告警阈值建议
完整率 非空字段数 / 总字段数 < 95%
唯一率 唯一值数 / 总行数 关键字段 < 99%
类型一致率 正确类型数 / 总行数 < 99%
范围合规率 范围内值数 / 总行数 < 98%
格式合规率 格式正确数 / 总行数 < 97%

  • 幂等性是清洗流水线的核心原则：相同输入必须产出相同结果
