数据去重

核心概念

数据去重（Data Deduplication）是从数据集中识别和移除重复或近似重复记录的过程。在 AI 训练数据中，重复数据会导致模型过拟合、训练效率降低和评估指标虚高。研究表明，互联网文本数据中约 30-50% 存在不同程度的重复，大规模语言模型的训练数据去重已成为标准实践。

去重的核心挑战是在召回率（找到所有重复）和精确率（不误判非重复）之间取得平衡，同时控制计算复杂度使其在大规模数据上可行。


精确去重方法
精确去重使用哈希函数将记录映射为固定长度的指纹，通过指纹比较快速识别完全相同的记录。


import { createHash } from 'crypto';

const exactDedup = (records: string[]): { unique: string[]; duplicateCount: number } => {
  const seen = new Set<string>();
  const unique: string[] = [];
  let duplicateCount = 0;

  for (const record of records) {
    const hash = createHash('md5').update(record.trim().toLowerCase()).digest('hex');

    if (seen.has(hash)) {
      duplicateCount++;
    } else {
      seen.add(hash);
      unique.push(record);
    }
  }

  return { unique, duplicateCount };
};

const contentHashDedup = (
  records: Array<{ id: string; content: string; metadata: Record<string, unknown> }>,
): typeof records => {
  const hashMap = new Map<string, (typeof records)[0]>();

  for (const record of records) {
    const normalized = record.content.replace(/\s+/g, ' ').trim().toLowerCase();

    const hash = createHash('sha256').update(normalized).digest('hex');

    if (!hashMap.has(hash)) {
      hashMap.set(hash, record);
    }
  }

  return Array.from(hashMap.values());
};

MinHash 与 LSH 近似去重
对于文本数据的近似去重，MinHash 结合局部敏感哈希（Locality-Sensitive Hashing, LSH）是业界标准方案。


const generateShingles = (text: string, k: number): Set<string> => {
  const shingles = new Set<string>();
  const words = text.split(/\s+/);
  for (let i = 0; i <= words.length - k; i++) {
    shingles.add(words.slice(i, i + k).join(' '));
  }
  return shingles;
};

const minHashSignature = (
  shingles: Set<string>,
  numHashes: number,
  hashFunctions: Array<(s: string) => number>,
): number[] => {
  const signature = new Array(numHashes).fill(Infinity);

  for (const shingle of shingles) {
    for (let i = 0; i < numHashes; i++) {
      const hashValue = hashFunctions[i](shingle);
      if (hashValue < signature[i]) {
        signature[i] = hashValue;
      }
    }
  }

  return signature;
};

const lshBuckets = (signature: number[], bands: number): string[] => {
  const rowsPerBand = Math.floor(signature.length / bands);
  const buckets: string[] = [];

  for (let b = 0; b < bands; b++) {
    const bandSlice = signature.slice(b * rowsPerBand, (b + 1) * rowsPerBand);
    const bucketKey = createHash('md5').update(bandSlice.join(',')).digest('hex');
    buckets.push(`${b}:${bucketKey}`);
  }

  return buckets;
};

interface BloomFilter {
  bits: Uint8Array;
  hashCount: number;
  size: number;
}

const createBloomFilter = (expectedItems: number, fpRate: number): BloomFilter => {
  const size = Math.ceil((-expectedItems * Math.log(fpRate)) / Math.log(2) ** 2);
  const hashCount = Math.round((size / expectedItems) * Math.log(2));
  return { bits: new Uint8Array(Math.ceil(size / 8)), hashCount, size };
};

const bloomFilterAdd = (filter: BloomFilter, item: string): void => {
  for (let i = 0; i < filter.hashCount; i++) {
    const hash = murmurhash(item, i) % filter.size;
    filter.bits[Math.floor(hash / 8)] |= 1 << (hash % 8);
  }
};

const bloomFilterCheck = (filter: BloomFilter, item: string): boolean => {
  for (let i = 0; i < filter.hashCount; i++) {
    const hash = murmurhash(item, i) % filter.size;
    if (!(filter.bits[Math.floor(hash / 8)] & (1 << (hash % 8)))) return false;
  }
  return true;
};
小结
    

  • 数据去重是 AI 训练数据质量保证的关键步骤，互联网数据中 30-50% 存在重复
    • 

  • 精确去重使用哈希比对，简单高效，适用于完全相同的记录
    • 

  • MinHash + LSH 是近似去重的业界标准，通过概率方法在大规模数据上可行
    • 

  • 布隆过滤器为大规模去重提供了低内存的概率型解决方案
    • 

  • 去重参数（shingle 大小、相似度阈值）需要根据具体数据特征调优
    • 

  • 生产环境需要支持增量去重，避免每次全量重新计算
