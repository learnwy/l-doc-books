流式数据接入

核心概念

流式数据接入（Streaming Data Ingestion）是实时或近实时地将持续产生的数据流接入到数据系统中的技术。与批量数据采集不同，流式接入处理的是无界的、持续到达的数据——用户行为日志、传感器数据、交易记录和社交媒体动态等。在 AI 系统中，流式接入使模型能够基于最新数据进行推理和持续学习。

流式数据接入的核心挑战是在低延迟、高吞吐和数据一致性之间取得平衡，同时处理乱序到达、数据积压和系统故障等现实问题。

流处理模式
interface StreamEvent<T> {
  key: string;
  value: T;
  timestamp: number;
  partition: number;
  offset: number;
}

interface WindowConfig {
  type: 'tumbling' | 'sliding' | 'session';
  sizeMs: number;
  slideMs?: number;
  gapMs?: number;
}

const processWindow = <T, R>(
  events: StreamEvent<T>[],
  windowConfig: WindowConfig,
  aggregator: (windowEvents: StreamEvent<T>[]) => R,
): R[] => {
  const results: R[] = [];

  if (windowConfig.type === 'tumbling') {
    const windows = new Map<number, StreamEvent<T>[]>();
    for (const event of events) {
      const windowKey = Math.floor(event.timestamp / windowConfig.sizeMs);
      const existing = windows.get(windowKey) ?? [];
      existing.push(event);
      windows.set(windowKey, existing);
    }
    for (const windowEvents of windows.values()) {
      results.push(aggregator(windowEvents));
    }
  }

  return results;
};

interface IdempotentProcessor<T> {
  processedIds: Set<string>;
  process: (event: StreamEvent<T>) => Promise<void>;
}

const createIdempotentProcessor = <T>(handler: (event: StreamEvent<T>) => Promise<void>): IdempotentProcessor<T> => {
  const processedIds = new Set<string>();

  return {
    processedIds,
    async process(event: StreamEvent<T>) {
      const eventId = `${event.partition}-${event.offset}`;
      if (processedIds.has(eventId)) return;
      await handler(event);
      processedIds.add(eventId);
    },
  };
};

小结
    

  • 流式数据接入使 AI 系统能够基于最新数据进行实时推理和持续学习
    • 

  • 消息队列（如 Kafka）是流式架构的基础，提供生产者和消费者之间的解耦缓冲
    • 

  • 窗口计算（滚动/滑动/会话）是流处理中聚合分析的核心模式
    • 

  • At-Least-Once + 幂等消费者是兼顾性能和正确性的最佳实践
    • 

  • 背压和流控机制防止消费者过载，保证系统稳定性
    • 

  • 流式与批量处理应互补使用，而非互相替代
