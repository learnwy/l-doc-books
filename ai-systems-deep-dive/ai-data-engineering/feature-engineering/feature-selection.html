特征选择与降维

核心概念

特征选择与降维是在保留关键信息的前提下减少特征数量的两大策略。特征选择从原始特征集中挑选最有价值的子集，降维则通过数学变换将高维空间映射到低维空间。两者共同解决维度灾难、过拟合和计算效率问题。

过滤法特征选择
过滤法（Filter Methods）通过统计指标独立评估每个特征的信息量，不依赖任何机器学习模型，计算效率高且适用于大规模特征集。


方差阈值 是最简单的过滤方法——低方差特征对模型贡献极小：


function varianceThreshold(
  features: number[][],
  threshold: number,
): { selectedIndices: number[]; variances: number[] } {
  const nFeatures = features[0].length;
  const variances: number[] = [];

  for (let j = 0; j < nFeatures; j++) {
    const values = features.map((row) => row[j]);
    const mean = values.reduce((s, v) => s + v, 0) / values.length;
    const variance = values.reduce((s, v) => s + (v - mean) ** 2, 0) / values.length;
    variances.push(variance);
  }

  const selectedIndices = variances.map((v, i) => (v > threshold ? i : -1)).filter((i) => i !== -1);

  return { selectedIndices, variances };
}
互信息（Mutual Information） 衡量特征与目标变量之间的非线性依赖关系，比相关系数更加通用：


interface MutualInformationResult {
  featureIndex: number;
  featureName: string;
  miScore: number;
  normalizedMI: number;
}

function calculateMutualInformation(feature: number[], target: number[], bins: number = 20): number {
  const featureHist = histogram(feature, bins);
  const targetHist = histogram(target, bins);
  const jointHist = jointHistogram(feature, target, bins);

  let mi = 0;
  const n = feature.length;

  for (let i = 0; i < bins; i++) {
    for (let j = 0; j < bins; j++) {
      const pxy = jointHist[i][j] / n;
      const px = featureHist[i] / n;
      const py = targetHist[j] / n;

      if (pxy > 0 && px > 0 && py > 0) {
        mi += pxy * Math.log(pxy / (px * py));
      }
    }
  }

  return mi;
}

包装法与嵌入法
包装法（Wrapper Methods） 将特征选择视为搜索问题，使用模型性能作为评价标准。虽然计算成本高，但能发现特征间的交互效应。


递归特征消除（RFE） 是最实用的包装法，通过模型权重反复删除最不重要的特征：


interface RFEConfig {
  targetFeatures: number;
  step: number;
  crossValidation: number;
  estimator: ModelConfig;
}

function recursiveFeatureElimination(X: number[][], y: number[], config: RFEConfig): RFEResult {
  let remainingFeatures = Array.from({ length: X[0].length }, (_, i) => i);
  const rankings: number[] = new Array(X[0].length).fill(0);
  let rank = X[0].length;

  while (remainingFeatures.length > config.targetFeatures) {
    const subX = X.map((row) => remainingFeatures.map((idx) => row[idx]));

    const model = trainModel(subX, y, config.estimator);
    const importances = model.featureImportances;

    const nToRemove = Math.min(config.step, remainingFeatures.length - config.targetFeatures);

    const sortedByImportance = importances
      .map((imp, i) => ({ importance: imp, originalIdx: remainingFeatures[i] }))
      .sort((a, b) => a.importance - b.importance);

    for (let i = 0; i < nToRemove; i++) {
      rankings[sortedByImportance[i].originalIdx] = rank--;
    }

    const removedSet = new Set(sortedByImportance.slice(0, nToRemove).map((s) => s.originalIdx));
    remainingFeatures = remainingFeatures.filter((idx) => !removedSet.has(idx));
  }

  for (const idx of remainingFeatures) {
    rankings[idx] = rank--;
  }

  return {
    selectedFeatures: remainingFeatures,
    rankings,
    finalScore: evaluateModel(
      X.map((row) => remainingFeatures.map((idx) => row[idx])),
      y,
      config,
    ),
  };
}

线性降维
PCA（主成分分析） 通过正交变换将数据投影到方差最大的方向，是最经典的线性降维方法：


interface PCAConfig {
  nComponents: number | 'auto';
  explainedVarianceThreshold: number;
  whiten: boolean;
}

interface PCAResult {
  components: number[][];
  explainedVariance: number[];
  explainedVarianceRatio: number[];
  cumulativeVariance: number[];
  nComponents: number;
  singularValues: number[];
}

function selectComponents(explainedVarianceRatio: number[], threshold: number): number {
  let cumulative = 0;
  for (let i = 0; i < explainedVarianceRatio.length; i++) {
    cumulative += explainedVarianceRatio[i];
    if (cumulative >= threshold) return i + 1;
  }
  return explainedVarianceRatio.length;
}

小结
    

  • 特征选择保留原始特征的可解释性，降维通过变换获得更紧凑的表示
    • 

  • 过滤法计算高效但忽略特征交互，包装法效果好但计算成本高
    • 

  • 嵌入法在模型训练中自然完成选择，L1 正则和树模型重要性最为实用
    • 

  • PCA 是线性降维的标准方法，累计方差解释率 95% 是常用阈值
    • 

  • UMAP 在兼顾局部和全局结构方面优于 t-SNE，且支持新数据投影
    • 

  • 实际工程中常采用分层策略：先用过滤法粗筛，再用嵌入法精选
    •
