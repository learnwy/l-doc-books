自动化特征工程

核心概念

深度特征合成
深度特征合成（Deep Feature Synthesis, DFS）是 Featuretools 框架的核心算法，通过在关系型数据的实体关系图上递归应用变换原语（Primitives）自动生成特征。


变换原语 是特征生成的基本操作单元，分为两类：


    

  • 变换原语（Transform）：对单个实体的列进行变换（如取绝对值、星期几、字符串长度）
    • 

  • 聚合原语（Aggregation）：对子实体进行聚合（如求均值、计数、最大值）
    • 



interface Primitive {
  name: string;
  type: 'transform' | 'aggregation';
  inputTypes: ColumnType[];
  outputType: ColumnType;
  apply(input: ColumnData): ColumnData;
}

interface EntitySet {
  entities: Map<string, Entity>;
  relationships: Relationship[];
}

interface Entity {
  id: string;
  dataFrame: DataFrame;
  index: string;
  timeIndex?: string;
  variableTypes: Map<string, ColumnType>;
}

interface Relationship {
  parentEntity: string;
  parentColumn: string;
  childEntity: string;
  childColumn: string;
}

interface DFSConfig {
  targetEntity: string;
  maxDepth: number;
  aggPrimitives: string[];
  transPrimitives: string[];
  maxFeatures: number;
  ignoreColumns: Record<string, string[]>;
  cutoffTime?: Date;
}
DFS 递归过程 在实体关系图上逐层生成特征：


function deepFeatureSynthesis(entitySet: EntitySet, config: DFSConfig): GeneratedFeature[] {
  const features: GeneratedFeature[] = [];
  const targetEntity = entitySet.entities.get(config.targetEntity);
  if (!targetEntity) return features;

  for (const col of targetEntity.dataFrame.columns) {
    features.push({
      name: col,
      depth: 0,
      primitives: [],
      entity: config.targetEntity,
    });
  }

  for (let depth = 1; depth <= config.maxDepth; depth++) {
    const newFeatures: GeneratedFeature[] = [];

    for (const rel of entitySet.relationships) {
      if (rel.parentEntity === config.targetEntity || depth > 1) {
        const childFeatures = features.filter((f) => f.entity === rel.childEntity && f.depth === depth - 1);

        for (const agg of config.aggPrimitives) {
          for (const childFeat of childFeatures) {
            newFeatures.push({
              name: `${agg}(${childFeat.name})`,
              depth,
              primitives: [...childFeat.primitives, agg],
              entity: config.targetEntity,
            });
          }
        }
      }
    }

    for (const trans of config.transPrimitives) {
      const parentFeatures = features.filter((f) => f.entity === config.targetEntity && f.depth === depth - 1);

      for (const feat of parentFeatures) {
        newFeatures.push({
          name: `${trans}(${feat.name})`,
          depth,
          primitives: [...feat.primitives, trans],
          entity: config.targetEntity,
        });
      }
    }

    features.push(...newFeatures);
    if (features.length >= config.maxFeatures) break;
  }

  return features.slice(0, config.maxFeatures);
}

基于搜索的特征工程
进化算法和贝叶斯优化等搜索方法将特征工程视为组合优化问题，在庞大的特征空间中高效搜索最优特征子集。


遗传算法特征工程 将特征组合编码为染色体，通过选择、交叉和变异操作进化出最优特征集：


interface GeneticFeatureConfig {
  populationSize: number;
  generations: number;
  crossoverRate: number;
  mutationRate: number;
  tournamentSize: number;
  maxFeatureComplexity: number;
  operators: FeatureOperator[];
  fitnessFunction: FitnessFunction;
}

type FeatureOperator =
  | { type: 'add'; arity: 2 }
  | { type: 'subtract'; arity: 2 }
  | { type: 'multiply'; arity: 2 }
  | { type: 'divide'; arity: 2 }
  | { type: 'log'; arity: 1 }
  | { type: 'sqrt'; arity: 1 }
  | { type: 'square'; arity: 1 }
  | { type: 'reciprocal'; arity: 1 };

interface Chromosome {
  genes: FeatureExpression[];
  fitness: number;
  complexity: number;
}

interface FeatureExpression {
  operator: FeatureOperator;
  operands: (string | FeatureExpression)[];
  depth: number;
}

function evolveFeatures(X: number[][], y: number[], config: GeneticFeatureConfig): Chromosome {
  let population = initializePopulation(X, config);

  for (let gen = 0; gen < config.generations; gen++) {
    population = evaluateFitness(population, X, y, config.fitnessFunction);
    const parents = tournamentSelection(population, config.tournamentSize);
    const offspring = crossover(parents, config.crossoverRate);
    mutate(offspring, config.mutationRate, config.operators);
    population = selectSurvivors(population, offspring, config.populationSize);
  }

  return population.sort((a, b) => b.fitness - a.fitness)[0];
}

端到端自动化管线
将特征生成、选择和优化整合为端到端的自动化管线，是生产环境中特征工程的最佳实践。


interface AutoFeaturePipeline {
  stages: PipelineStage[];
  budget: ComputeBudget;
  evaluate(X: number[][], y: number[]): PipelineReport;
}

type PipelineStage =
  | { type: 'dfs'; config: DFSConfig }
  | { type: 'genetic'; config: GeneticFeatureConfig }
  | { type: 'filter_selection'; config: FilterConfig }
  | { type: 'wrapper_selection'; config: WrapperConfig }
  | { type: 'neural_features'; config: AutoEncoderConfig }
  | { type: 'importance_pruning'; config: PruningConfig };

interface ComputeBudget {
  maxTimeSeconds: number;
  maxMemoryMB: number;
  maxFeatures: number;
  crossValidationFolds: number;
}

interface PipelineReport {
  generatedFeatures: number;
  selectedFeatures: number;
  originalScore: number;
  improvedScore: number;
  scoreImprovement: number;
  topFeatures: FeatureImportance[];
  computeTime: number;
  memoryPeak: number;
}

小结
    

  • 自动化特征工程通过算法替代人工探索，系统化发现高价值特征
    • 

  • DFS 在关系型数据上通过递归应用变换/聚合原语自动生成特征，推荐深度 2-3
    • 

  • 遗传算法适合探索复杂的特征组合空间，贝叶斯优化在小特征空间中更高效
    • 

  • 神经特征学习（TabNet、FT-Transformer）在表格数据上接近或超越手工特征
    • 

  • 端到端管线采用分层策略：先大量生成，再快速过滤，最后模型驱动精选
    • 

  • 自动化方法不完全替代领域知识，最佳实践是将领域先验与自动搜索结合
    •
