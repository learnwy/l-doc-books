数据质量度量

核心概念

数据质量度量是评估训练数据可靠性和可用性的系统化方法。低质量数据会导致模型性能下降、预测偏差和部署风险，因此建立完善的数据质量评估体系是 AI 数据工程的基础环节。

统计质量指标
统计质量指标从数据分布的角度评估质量，能够发现肉眼难以察觉的系统性问题。


分布偏移检测 是生产环境中最关键的质量指标。当新数据的分布与训练数据显著不同时，模型性能会急剧下降：


interface DistributionMetrics {
  feature: string;
  referenceStats: DescriptiveStats;
  currentStats: DescriptiveStats;
  drift: {
    psiScore: number;
    ksStatistic: number;
    ksPValue: number;
    wasserstein: number;
    jsDivergence: number;
  };
  alert: boolean;
}

function calculatePSI(reference: number[], current: number[], bins: number = 10): number {
  const refHist = histogram(reference, bins);
  const curHist = histogram(current, bins);

  let psi = 0;
  for (let i = 0; i < bins; i++) {
    const refPct = Math.max(refHist[i], 0.0001);
    const curPct = Math.max(curHist[i], 0.0001);
    psi += (curPct - refPct) * Math.log(curPct / refPct);
  }
  return psi;
}

function interpretPSI(psi: number): string {
  if (psi < 0.1) return 'no_significant_drift';
  if (psi < 0.25) return 'moderate_drift';
  return 'significant_drift';
}

类别平衡度量 评估标签分布的均衡性，严重不平衡会导致模型偏向多数类：


异常值检测 通过统计方法识别数据中的离群点：


interface OutlierDetectionResult {
  feature: string;
  method: 'zscore' | 'iqr' | 'isolation_forest' | 'lof';
  outlierIndices: number[];
  outlierRate: number;
  threshold: number;
}

function detectOutliersIQR(values: number[], factor: number = 1.5): OutlierDetectionResult {
  const sorted = [...values].sort((a, b) => a - b);
  const q1 = sorted[Math.floor(sorted.length * 0.25)];
  const q3 = sorted[Math.floor(sorted.length * 0.75)];
  const iqr = q3 - q1;
  const lowerBound = q1 - factor * iqr;
  const upperBound = q3 + factor * iqr;

  const outlierIndices = values.map((v, i) => (v < lowerBound || v > upperBound ? i : -1)).filter((i) => i !== -1);

  return {
    feature: '',
    method: 'iqr',
    outlierIndices,
    outlierRate: outlierIndices.length / values.length,
    threshold: factor,
  };
}
标注质量度量
标注质量直接决定监督学习的上限。除了标注者间一致性（IAA），还需要从多个维度评估标注结果的可靠性。


标注置信度评分 为每个标注结果计算可信度，低置信度样本需要重新审核：


interface AnnotationQualityReport {
  datasetId: string;
  totalSamples: number;
  metrics: {
    interAnnotatorAgreement: {
      cohensKappa: number;
      fleissKappa: number;
      krippendorffAlpha: number;
    };
    labelDistribution: Record<string, number>;
    imbalanceRatio: number;
    confidenceDistribution: {
      high: number;
      medium: number;
      low: number;
    };
    errorAnalysis: {
      systematicErrors: ErrorPattern[];
      randomErrorRate: number;
      annotatorBias: AnnotatorBiasReport[];
    };
  };
}

interface ErrorPattern {
  pattern: string;
  frequency: number;
  affectedAnnotators: string[];
  suggestedFix: string;
}

function calculateAnnotationConfidence(annotations: AnnotatorResult[]): number {
  if (annotations.length < 2) return 0.5;

  const labelCounts = new Map<string, number>();
  for (const ann of annotations) {
    labelCounts.set(ann.label, (labelCounts.get(ann.label) ?? 0) + 1);
  }

  const maxCount = Math.max(...labelCounts.values());
  const agreementRatio = maxCount / annotations.length;

  const annotatorWeights = annotations.map((a) => a.annotatorReliability);
  const weightedAgreement =
    annotations
      .filter((a) => a.label === getMajorityLabel(labelCounts))
      .reduce((sum, a) => sum + a.annotatorReliability, 0) / annotatorWeights.reduce((sum, w) => sum + w, 0);

  return 0.4 * agreementRatio + 0.6 * weightedAgreement;
}

数据质量监控系统
生产环境中的数据质量需要持续监控，而非一次性评估。数据质量监控系统通过自动化检查及时发现并预警质量问题。


数据质量规则引擎 定义声明式规则，自动检查数据质量：


interface QualityRule {
  id: string;
  name: string;
  severity: 'critical' | 'warning' | 'info';
  scope: 'row' | 'column' | 'dataset';
  check: QualityCheck;
  action: 'block' | 'flag' | 'log';
}

type QualityCheck =
  | { type: 'not_null'; columns: string[] }
  | { type: 'unique'; columns: string[] }
  | { type: 'range'; column: string; min: number; max: number }
  | { type: 'regex'; column: string; pattern: string }
  | { type: 'referential'; column: string; referenceTable: string }
  | { type: 'statistical'; column: string; metric: string; threshold: number }
  | { type: 'custom'; fn: (row: Record<string, unknown>) => boolean };

function evaluateQualityRules(data: Record<string, unknown>[], rules: QualityRule[]): QualityReport {
  const violations: Violation[] = [];

  for (const rule of rules) {
    for (let i = 0; i < data.length; i++) {
      if (!checkRule(data[i], rule.check)) {
        violations.push({
          ruleId: rule.id,
          rowIndex: i,
          severity: rule.severity,
          details: `Rule "${rule.name}" violated`,
        });
      }
    }
  }

  return {
    totalRows: data.length,
    totalViolations: violations.length,
    violationRate: violations.length / data.length,
    bySeverity: groupBySeverity(violations),
    byRule: groupByRule(violations),
    passRate: 1 - violations.length / (data.length * rules.length),
  };
}

数据调试与根因分析
当模型性能下降时，数据调试（Data Debugging）帮助定位质量问题的根源。与传统的模型调试不同，数据调试关注的是训练数据中的系统性问题。


影响函数（Influence Functions） 量化单个训练样本对模型预测的影响，帮助识别有害样本：


interface DataDebugResult {
  suspiciousSamples: {
    index: number;
    influenceScore: number;
    predictedImpact: string;
    suggestedAction: 'remove' | 'relabel' | 'review';
  }[];
  clusterAnalysis: {
    clusterId: number;
    avgQuality: number;
    dominantIssue: string;
    sampleCount: number;
  }[];
  rootCauses: {
    cause: string;
    confidence: number;
    affectedSamples: number;
    recommendation: string;
  }[];
}

function dataDebugPipeline(model: TrainedModel, trainData: LabeledData[], validData: LabeledData[]): DataDebugResult {
  const misclassified = validData.filter((d) => model.predict(d.features) !== d.label);

  const influences = trainData.map((sample, idx) => ({
    index: idx,
    influenceScore: estimateInfluence(model, sample, misclassified),
    label: sample.label,
  }));

  const suspicious = influences.filter((i) => i.influenceScore > 0).sort((a, b) => b.influenceScore - a.influenceScore);

  return {
    suspiciousSamples: suspicious.slice(0, 100).map((s) => ({
      ...s,
      predictedImpact: classifyImpact(s.influenceScore),
      suggestedAction: suggestAction(s),
    })),
    clusterAnalysis: clusterSuspiciousSamples(suspicious),
    rootCauses: identifyRootCauses(suspicious, trainData),
  };
}
数据切片分析 将验证数据按特征子集切片，找出模型性能最差的子群体。性能差异往往指向该子群体对应的训练数据存在质量问题。


小结
    

  • 数据质量度量需要从准确性、完整性、一致性、时效性和唯一性五个维度综合评估
    • 

  • PSI 是生产环境中检测分布偏移的标准指标，阈值 0.25 以上需立即干预
    • 

  • 标注质量评估需要结合 IAA 指标和标注者偏差分析，发现系统性标注问题
    • 

  • 数据质量监控应自动化运行，通过规则引擎实时检查和定期批量分析结合
    • 

  • 数据调试通过影响函数和切片分析定位质量问题的根源
    • 

  • 质量评分的权重应根据使用场景动态调整，训练场景更重视准确性，推理场景更重视完整性
