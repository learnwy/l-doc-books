主动学习与标注优化

核心概念

主动学习（Active Learning）是一种让模型主动选择最有价值的未标注样本进行标注的机器学习范式。与被动学习中随机选择样本不同，主动学习通过智能采样策略，用更少的标注数据达到更高的模型性能，从而大幅降低标注成本。

主动学习的核心假设是：并非所有数据对模型训练的贡献相同。处于决策边界附近的样本、模型最不确定的样本、以及能最大化信息增益的样本，往往比随机样本更有价值。


查询策略
查询策略是主动学习的核心，决定了从未标注数据池中选择哪些样本进行标注。不同策略适用于不同的模型类型和任务特征。


不确定性采样（Uncertainty Sampling） 选择模型最不确定的样本。这是最直观也最常用的策略：


interface UncertaintySampler {
  strategy: 'least_confidence' | 'margin' | 'entropy';
  batchSize: number;
}

function leastConfidence(predictions: number[][]): number[] {
  return predictions
    .map((probs, idx) => ({
      idx,
      uncertainty: 1 - Math.max(...probs),
    }))
    .sort((a, b) => b.uncertainty - a.uncertainty)
    .map((item) => item.idx);
}

function marginSampling(predictions: number[][]): number[] {
  return predictions
    .map((probs, idx) => {
      const sorted = [...probs].sort((a, b) => b - a);
      return { idx, margin: sorted[0] - sorted[1] };
    })
    .sort((a, b) => a.margin - b.margin)
    .map((item) => item.idx);
}

function entropySampling(predictions: number[][]): number[] {
  return predictions
    .map((probs, idx) => {
      const entropy = -probs.reduce((sum, p) => sum + (p > 0 ? p * Math.log2(p) : 0), 0);
      return { idx, entropy };
    })
    .sort((a, b) => b.entropy - a.entropy)
    .map((item) => item.idx);
}

多样性采样（Diversity Sampling） 确保选择的样本覆盖数据空间的不同区域，避免选择过于相似的样本：


查询委员会（Query by Committee, QBC） 维护一组模型的委员会，选择委员会成员分歧最大的样本：


interface CommitteeConfig {
  models: ModelConfig[];
  disagreementMetric: 'vote_entropy' | 'kl_divergence';
  samplingBudget: number;
}

function queryByCommittee(committee: Model[], unlabeledData: DataPoint[], budget: number): DataPoint[] {
  const disagreements = unlabeledData.map((point) => {
    const predictions = committee.map((model) => model.predict(point));
    const voteDistribution = aggregateVotes(predictions);
    const entropy = calculateEntropy(voteDistribution);
    return { point, disagreement: entropy };
  });

  return disagreements
    .sort((a, b) => b.disagreement - a.disagreement)
    .slice(0, budget)
    .map((item) => item.point);
}
批量主动学习
实际应用中，每次只标注一个样本效率太低。批量主动学习（Batch Active Learning）一次选择一批样本，但需要平衡样本的信息量和批次内的多样性。


贪心选择 逐个选择信息量最大的样本，但不考虑批次内多样性，容易选择相似的样本簇。


核心集方法（Core-Set） 将批量选择问题转化为集合覆盖问题，选择使标注数据最大化覆盖特征空间的样本：


function coreSetSelection(labeled: Float32Array[], unlabeled: Float32Array[], budget: number): number[] {
  const selected: number[] = [];

  for (let i = 0; i < budget; i++) {
    let maxMinDist = -Infinity;
    let bestIdx = -1;

    for (let u = 0; u < unlabeled.length; u++) {
      if (selected.includes(u)) continue;

      let minDist = Infinity;
      for (const l of labeled) {
        const dist = euclideanDistance(unlabeled[u], l);
        minDist = Math.min(minDist, dist);
      }
      for (const s of selected) {
        const dist = euclideanDistance(unlabeled[u], unlabeled[s]);
        minDist = Math.min(minDist, dist);
      }

      if (minDist > maxMinDist) {
        maxMinDist = minDist;
        bestIdx = u;
      }
    }

    selected.push(bestIdx);
  }

  return selected;
}

冷启动与停止策略
冷启动问题 是主动学习面临的关键挑战：初始阶段没有训练好的模型，查询策略无法有效工作。常见的冷启动解决方案包括：


    

  • 随机种子集：先随机标注少量样本建立初始模型，再切换到主动学习模式
    • 

  • 聚类预采样：对未标注数据聚类，从每个簇中选取代表性样本作为种子
    • 

  • 迁移学习嵌入：使用预训练模型的特征嵌入评估样本多样性
    • 



停止策略 决定何时终止标注循环。过早停止会导致模型欠拟合，过晚停止则浪费标注预算：


interface StoppingCriteria {
  maxBudget: number;
  performancePlateau: {
    metric: string;
    window: number;
    threshold: number;
  };
  uncertaintyThreshold: {
    avgUncertainty: number;
    maxUncertainty: number;
  };
  dataPoolExhaustion: {
    minPoolSize: number;
  };
}

function shouldStop(history: TrainingHistory, criteria: StoppingCriteria): { stop: boolean; reason: string } {
  if (history.totalLabeled >= criteria.maxBudget) {
    return { stop: true, reason: 'budget_exhausted' };
  }

  const recentScores = history.scores.slice(-criteria.performancePlateau.window);
  if (recentScores.length >= criteria.performancePlateau.window) {
    const improvement = recentScores[recentScores.length - 1] - recentScores[0];
    if (improvement < criteria.performancePlateau.threshold) {
      return { stop: true, reason: 'performance_plateau' };
    }
  }

  if (history.avgUncertainty < criteria.uncertaintyThreshold.avgUncertainty) {
    return { stop: true, reason: 'low_uncertainty' };
  }

  return { stop: false, reason: 'continue' };
}
实际工程集成
将主动学习集成到生产标注流水线中需要考虑模型更新频率、标注延迟和系统架构等工程问题。


在线与离线模式 的选择取决于标注速度和模型训练时间的比值。当标注速度远快于模型训练时，采用离线批量模式（积累一批标注后统一训练）；当单样本标注耗时较长时，可采用在线模式（每次标注后增量更新模型）。


生产级主动学习管线 通常包含以下组件：


interface ActiveLearningPipeline {
  dataPool: {
    unlabeled: DataStore;
    labeled: DataStore;
    queryBuffer: DataPoint[];
  };
  model: {
    current: TrainedModel;
    retrainInterval: number;
    retrainTrigger: 'batch_size' | 'time_interval' | 'performance_drop';
  };
  queryEngine: {
    strategy: QueryStrategy;
    batchSize: number;
    diversityWeight: number;
  };
  annotationInterface: {
    platform: AnnotationPlatform;
    qualityThreshold: number;
    redundancy: number;
  };
  monitoring: {
    learningCurve: DataPoint[];
    annotationSpeed: number;
    modelPerformance: MetricHistory;
    costTracker: CostRecord[];
  };
}
效果评估 通过学习曲线（Learning Curve）衡量主动学习的价值——在相同标注预算下，主动学习相比随机采样能达到多高的性能提升。经验表明，主动学习通常能减少 40%-70% 的标注量达到同等性能。


小结
    

  • 主动学习通过智能采样将标注成本降低 40%-70%，是高成本标注场景的标准方案
    • 

  • 不确定性采样是最常用的查询策略，熵采样考虑完整概率分布效果最佳
    • 

  • 批量主动学习需要平衡信息量和多样性，BADGE 等方法在梯度空间中实现两者兼顾
    • 

  • 冷启动阶段建议用聚类预采样建立初始模型，再切换到主动学习模式
    • 

  • 停止策略应结合性能收敛、预算限制和不确定性阈值多维度判断
    • 

  • 生产集成需要考虑模型更新频率、标注延迟和质量监控的协调
    •
