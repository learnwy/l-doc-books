合成数据生成

核心概念

合成数据（Synthetic Data）是通过算法、模型或规则生成的仿真数据，在统计特性上与真实数据高度相似，但不包含真实个体信息。合成数据在训练数据稀缺、隐私限制严格和类别不平衡等场景中发挥关键作用，正成为 AI 数据工程的核心技术之一。

基于规则与统计的生成
基于规则的生成方法通过预定义的模板和约束条件产生数据，适合结构化数据和特定领域的场景。虽然灵活性有限，但具有高可控性和可解释性。


模板生成 定义数据模板并通过参数化填充产生变体：


interface DataTemplate {
  schema: FieldSchema[];
  constraints: Constraint[];
  distributions: Record<string, Distribution>;
}

interface FieldSchema {
  name: string;
  type: 'numeric' | 'categorical' | 'text' | 'datetime' | 'composite';
  nullable: boolean;
  generator: GeneratorConfig;
}

type GeneratorConfig =
  | { type: 'uniform'; min: number; max: number }
  | { type: 'normal'; mean: number; std: number }
  | { type: 'categorical'; values: string[]; weights: number[] }
  | { type: 'regex'; pattern: string }
  | { type: 'foreign_key'; table: string; column: string }
  | { type: 'conditional'; condition: string; thenGen: GeneratorConfig; elseGen: GeneratorConfig };

function generateFromTemplate(template: DataTemplate, count: number): Record<string, unknown>[] {
  const results: Record<string, unknown>[] = [];

  for (let i = 0; i < count; i++) {
    const row: Record<string, unknown> = {};

    for (const field of template.schema) {
      row[field.name] = generateFieldValue(field, row);
    }

    if (satisfiesConstraints(row, template.constraints)) {
      results.push(row);
    } else {
      i--;
    }
  }

  return results;
}

深度生成模型
深度生成模型通过神经网络学习数据的底层分布，能够生成高保真度的复杂数据，包括图像、文本和表格数据。


生成对抗网络（GAN） 通过生成器和判别器的博弈训练，是最经典的深度生成方法：


条件生成 允许控制生成数据的特定属性，在数据增强中尤为重要。例如，在类别不平衡场景中，可以条件生成少数类样本：


interface ConditionalGANConfig {

LLM 驱动的数据生成
大语言模型的出现为合成数据生成带来了范式变革。LLM 能够根据自然语言描述生成高质量、多样化的训练数据，极大降低了合成数据的生成门槛。


指令驱动生成 通过精心设计的提示词引导 LLM 生成目标数据：


interface LLMDataGenerator {
  model: string;
  generateBatch(config: GenerationConfig): Promise<GeneratedSample[]>;
  validateAndFilter(samples: GeneratedSample[], criteria: QualityCriteria): GeneratedSample[];
}

interface GenerationConfig {
  taskDescription: string;
  labelSpace: string[];
  examplesPerLabel: number;
  diversityConstraints: {
    minLengthVariance: number;
    topicDistribution: Record<string, number>;
    styleVariation: boolean;
  };
  qualityFilters: {
    minLength: number;
    maxLength: number;
    deduplicationThreshold: number;
    coherenceThreshold: number;
  };
}

质量验证与隐私评估
合成数据的价值取决于两个关键维度：保真度（与真实数据的相似程度）和隐私性（不泄露真实数据信息）。系统化的质量验证是合成数据可用的前提。


保真度评估 从多个层次验证合成数据的质量：


interface SyntheticDataEvaluation {
  statisticalFidelity: {
    columnShapeSimilarity: Record<string, number>;
    pairwiseCorrelation: number;
    contingencyTableSimilarity: number;
  };
  mlUtility: {
    trainOnSyntheticTestOnReal: number;
    trainOnRealTestOnReal: number;
    utilityRatio: number;
  };
  privacy: {
    nearestNeighborDistance: number;
    membershipInferenceRisk: number;
    attributeDisclosureRisk: number;
    differentialPrivacyGuarantee?: { epsilon: number; delta: number };
  };
  diversity: {
    coverageScore: number;
    noveltyScore: number;
    duplicateRate: number;
  };
}

function evaluateSyntheticData(
  synthetic: Record<string, unknown>[],
  real: Record<string, unknown>[],
  holdout: Record<string, unknown>[],
): SyntheticDataEvaluation {
  const statFidelity = evaluateStatisticalFidelity(synthetic, real);
  const mlUtil = evaluateMLUtility(synthetic, real, holdout);
  const privacy = evaluatePrivacy(synthetic, real);
  const diversity = evaluateDiversity(synthetic);

  return {
    statisticalFidelity: statFidelity,
    mlUtility: mlUtil,
    privacy: privacy,
    diversity: diversity,
  };
}
TSTR（Train on Synthetic, Test on Real） 是衡量合成数据实用价值的黄金标准——在合成数据上训练模型，在真实数据上测试，与完全使用真实数据训练的性能对比。TSTR 比率越接近 1.0，说明合成数据质量越高。

小结
    

  • 合成数据是解决数据稀缺、隐私限制和类别不平衡的核心技术方案
    • 

  • 基于规则的生成适合结构化数据，可控性强但多样性有限
    • 

  • CTGAN 等专用表格 GAN 解决了混合数据类型和多模态分布的生成难题
    • 

  • LLM 驱动的生成极大降低了合成数据的门槛，改写增强和反事实生成是高价值模式
    • 

  • 质量验证必须同时评估保真度和隐私性，TSTR 是衡量实用价值的黄金标准
    • 

  • 差分隐私（DP）提供数学可证的隐私保证，但会降低数据保真度，需要权衡
    •
