基于模型的强化学习基础

核心概念

基于模型的强化学习（Model-Based RL, MBRL）是世界模型最直接的下游应用领域。与不学环境模型的 model-free RL（PPO、SAC、DQN）不同，MBRL 显式学习环境的转移函数 P(s′∣s,a)P(s'|s,a)P(s′∣s,a) 和奖励函数 R(s,a)R(s,a)R(s,a)，然后用这些模型支持决策。MBRL 的核心承诺是更高的样本效率——一旦有了准确模型，就可以无限制地"想象训练"，不再受真实交互的成本约束。本节系统讲解 MBRL 的算法谱系：从纯前向规划（MPC、CEM），到 Dyna 风格混合，再到现代端到端可微规划。

纯前向规划：模型即决策
最直接的 MBRL 方式是不训练策略——每次决策时用学到的模型在内部模拟多种动作序列，选择期望奖励最高的执行。这种方法常用于机器人控制场景。


Cross-Entropy Method（CEM） 是最常用的纯前向规划算法：


    

  1. 从动作分布 N(μ,σ)\mathcal{N}(\mu, \sigma)N(μ,σ) 采样 N 个动作序列。
    2. 

  2. 用世界模型模拟每个序列，计算累积奖励。
    3. 

  3. 选取奖励最高的 K 个序列，更新分布参数 μ,σ\mu, \sigmaμ,σ。
    4. 

  4. 重复 1-3 直到收敛，输出最优均值的第一步动作。
    5. 



CEM 的优势是简单、无需可微模型、能处理连续动作空间；劣势是每次决策都需要数百次模型调用，推理成本高。


Model Predictive Control（MPC） 是控制理论的经典方法，也属于纯前向规划范畴：在每个控制周期重新规划未来 H 步动作，只执行第一步，下一周期重新规划。MPC 的核心价值是闭环鲁棒性——即使模型有偏差，每周期重新规划能不断纠正。


PETS（Probabilistic Ensembles with Trajectory Sampling） 是 MBRL 的经典基准——用神经网络集合（ensemble）建模不确定性，配合 CEM 规划。在多种连续控制任务上都达到 SOTA 样本效率。


Dyna 风格：模型生成数据辅助
Dyna 是 Sutton 1990 年提出的经典思想：用世界模型生成虚拟数据，与真实数据混合训练 model-free RL 算法。这种"模型作为数据放大器"的思路是 MBRL 的另一主流路线。


Dyna-Q 是经典实现：


    

  1. 真实环境交互一步，更新 Q 值。
    2. 

  2. 用世界模型生成 K 个虚拟交互，每个都更新 Q 值。
    3. 

  3. 真实交互 1 步等效于训练 K+1 步。
    4. 



MBPO（Model-Based Policy Optimization） 是 Dyna 思想的现代复兴：


    

  • 用神经网络集合学世界模型，捕捉模型不确定性。
    • 

  • 用 SAC 在真实数据 + 模型生成的短轨迹（避免长 rollout 累积误差）上训练策略。
    • 

  • 实验证明在样本效率上显著优于纯 SAC。
    • 



Dyna 风格的核心权衡是"模型偏差与数据增益"：模型不准会引入偏差污染策略，但能放大数据；如果模型相对准，增益超过偏差，整体效果更好。MBPO 通过限制模型 rollout 长度（典型 1-15 步）来控制偏差。


端到端可微：当前最强范式
近年最成功的 MBRL 方法是端到端可微——把世界模型和策略联合训练，让梯度直接流过想象 rollout。Dreamer 是这一路线的代表，TD-MPC2 是另一重要工作。


端到端可微的优势：


    

  • 梯度直接利用模型：策略学习不依赖采样估计，方差小、收敛快。
    • 

  • 联合优化：模型与策略协同训练，模型更专注于策略需要的预测精度。
    • 

  • 想象任意 horizon：通过想象 rollout 让策略学到长期规划。
    • 



代价是实现复杂——需要可微的世界模型、稳定的 rollout 训练、KL 正则等多种工程技巧。Dreamer V3 用一系列工程改进（symlog、自适应 KL、对称归一化）让这一范式实用化。


TD-MPC2：MPC 与 Dreamer 的融合
TD-MPC2（南加州大学，2024）把 MPC 的规划能力与 Dreamer 的端到端训练结合，在多种基准上取得最佳效果。其核心思路：


    

  • 学习一个潜空间世界模型（类似 Dreamer 的 RSSM）。
    • 

  • 学一个策略网络作为 MPC 的初始化（warm start）。
    • 

  • 在每个决策时刻用 CEM 在世界模型中规划，用学到的策略作为 prior。
    • 

  • 把 MPC 的输出作为策略训练目标，让策略不断逼近 MPC 性能。
    • 



TD-MPC2 的优势是同时获得了规划的质量与策略的速度——决策时优先用快速策略，复杂场景下用 MPC 兜底。这种"规划 + 策略协同"的范式可能是 MBRL 的下一代主流方向。


模型偏差与不确定性
MBRL 的根本挑战是模型偏差——学到的世界模型不可能 100% 准确，策略基于不准模型训练出来的策略可能在真实环境失败。常见的应对方法：


模型集成（Ensemble）：训练多个独立模型，用模型间的预测分歧度量不确定性。当前 MBRL 工作几乎都用 ensemble。


保守目标：在不确定状态下使用悲观估计（最差模型预测），避免在不熟悉区域过度乐观。MOPO、COMBO 等离线 MBRL 算法采用这一思路。


短期 rollout：限制想象长度，避免误差累积。MBPO 用 1-15 步 rollout，远短于真实 episode。


真实数据兜底：保留 model-free 训练通道，在模型严重偏差时仍能学到合理策略。


工程实践指南
把 MBRL 用于实际项目的工程经验：


    

  • 从纯 model-free 出发：先用 PPO/SAC 跑通，作为 baseline。
    • 

  • 如果样本太昂贵再考虑 MBRL：MBRL 引入的复杂度只有在样本成本高（机器人、医疗）时才值得。
    • 

  • 优先尝试 MBPO 这类成熟方法：MBPO、Dreamer V3、TD-MPC2 都有开源实现，从这些起步比从零自实现稳。
    • 

  • 务必加 ensemble：单模型容易过拟合，ensemble 是 MBRL 的标配。
    • 

  • 监控模型质量：在训练中跟踪模型预测误差，模型质量下降时回退到 model-free。
    • 



小结
基于模型的强化学习是世界模型最直接的应用领域，提供了显著高于 model-free 的样本效率。从纯前向规划（CEM、MPC）、Dyna 风格（MBPO）、到端到端可微（Dreamer、TD-MPC2），方法谱系不断演进。当前最强的工程实践是端到端可微范式，配合模型集成与保守估计应对不确定性。理解 MBRL 的算法谱系能让具身研究者根据样本成本、任务复杂度、推理预算等约束选择合适方法，避免简单地默认 model-free。MBRL 与世界模型研究紧密共生——前者为后者提供应用动力，后者为前者提供能力上限。把两者作为"硬币的两面"理解，能让研究者更清晰地把握具身智能的发展方向。
