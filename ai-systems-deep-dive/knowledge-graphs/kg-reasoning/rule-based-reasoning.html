基于规则的推理

核心概念

基于规则的推理（Rule-based Reasoning）是从知识图谱中挖掘逻辑规则并利用这些规则推导新知识的技术。与图嵌入的「黑箱」向量运算不同，规则推理产生可解释的推理链条——例如从规则 出生于(X, Y) ∧ 国家(Y, Z) → 国籍(X, Z) 可以推导出「姚明的国籍是中国」，推理过程清晰透明。规则推理在需要高可信度和可审计性的场景（如医疗知识图谱、法律推理系统）中具有不可替代的价值。

Horn 规则与路径规则
知识图谱中最常用的规则形式是 Horn 规则（Horn Clause）。一条 Horn 规则的形式为：B1(X,Y) ∧ B2(Y,Z) ∧ ... → H(X,Z)，其中 B1, B2 是规则体（Body），H 是规则头（Head）。规则体中的变量通过共享变量连接，形成一条从 X 到 Z 的关系路径。


路径规则（Path Rules）是 Horn 规则的特例，规则体形成一条线性路径。例如：父亲(X,Y) ∧ 父亲(Y,Z) → 祖父(X,Z) 描述了一条长度为 2 的路径。路径规则在知识图谱中最为常见，因为大多数知识关联都可以通过关系链来表达。


interface HornRule {
  readonly head: Atom;
  readonly body: ReadonlyArray<Atom>;
  readonly confidence: number;
  readonly support: number;
  readonly headCoverage: number;
}

interface Atom {
  readonly predicate: string;
  readonly subject: string;
  readonly object: string;
}

interface RuleEvaluation {
  readonly rule: HornRule;
  readonly predictedFacts: number;
  readonly correctPredictions: number;
  readonly precision: number;
  readonly recall: number;
}

function instantiateRule(
  rule: HornRule,
  bindings: ReadonlyMap<string, string>,
): { head: GroundAtom; body: ReadonlyArray<GroundAtom> } {
  return {
    head: groundAtom(rule.head, bindings),
    body: rule.body.map((atom) => groundAtom(atom, bindings)),
  };
}

interface GroundAtom {
  readonly predicate: string;
  readonly subject: string;
  readonly object: string;
}

function groundAtom(atom: Atom, bindings: ReadonlyMap<string, string>): GroundAtom {
  return {
    predicate: atom.predicate,
    subject: bindings.get(atom.subject) ?? atom.subject,
    object: bindings.get(atom.object) ?? atom.object,
  };
}

function evaluateRuleQuality(
  rule: HornRule,
  knownFacts: ReadonlySet<string>,
  predictions: ReadonlyArray<GroundAtom>,
): RuleEvaluation {
  let correct = 0;
  for (const pred of predictions) {
    const key = `${pred.predicate}|${pred.subject}|${pred.object}`;
    if (knownFacts.has(key)) correct++;
  }

  return {
    rule,
    predictedFacts: predictions.length,
    correctPredictions: correct,
    precision: predictions.length > 0 ? correct / predictions.length : 0,
    recall: 0,
  };
}
AMIE 规则挖掘算法
AMIE（Association Rule Mining under Incomplete Evidence）是专门为知识图谱设计的规则挖掘系统。与传统关联规则挖掘不同，AMIE 考虑了知识图谱的开放世界假设（Open World Assumption，OWA）——不存在的三元组不一定是错误的，可能只是尚未被发现。


AMIE 通过自底向上的方式生成规则：从单个原子开始，逐步添加新原子来扩展规则体。在每一步中，通过三种操作添加新原子：悬挂原子（Dangling Atom，引入新变量）、实例化原子（Instantiated Atom，使用已知实体）和闭合原子（Closing Atom，连接已有变量使规则闭合）。


规则质量通过三个指标评估：支持度（Support，规则正确预测的事实数）、头覆盖率（Head Coverage，正确预测占头关系总实例的比例）和 PCA 置信度（PCA Confidence，考虑了部分完整性假设的置信度）。


interface AMIEConfig {
  readonly minSupport: number;
  readonly minHeadCoverage: number;
  readonly maxRuleLength: number;
  readonly confidenceMetric: 'standard' | 'pca';
  readonly topK: number;
}

interface RuleCandidate {
  readonly atoms: ReadonlyArray<Atom>;
  readonly headAtom: Atom;
  readonly isClosed: boolean;
  readonly support: number;
  readonly headCoverage: number;
  readonly pcaConfidence: number;
}

function mineRulesAMIE(triples: ReadonlyArray<Triple>, config: AMIEConfig): ReadonlyArray<HornRule> {
  const rules: HornRule[] = [];
  const factIndex = buildFactIndex(triples);

  const predicates = [...new Set(triples.map((t) => t.relation))];

  for (const headPredicate of predicates) {
    const seedRule: RuleCandidate = {
      atoms: [{ predicate: headPredicate, subject: 'X', object: 'Y' }],
      headAtom: { predicate: headPredicate, subject: 'X', object: 'Y' },
      isClosed: false,
      support: 0,
      headCoverage: 0,
      pcaConfidence: 0,
    };

    const expanded = expandRule(seedRule, factIndex, config);
    for (const candidate of expanded) {
      if (candidate.support >= config.minSupport && candidate.headCoverage >= config.minHeadCoverage) {
        rules.push({
          head: candidate.headAtom,
          body: candidate.atoms.slice(1),
          confidence: candidate.pcaConfidence,
          support: candidate.support,
          headCoverage: candidate.headCoverage,
        });
      }
    }
  }

  return rules.sort((a, b) => b.confidence - a.confidence).slice(0, config.topK);
}

interface FactIndex {
  readonly byPredicate: ReadonlyMap<string, ReadonlyArray<Triple>>;
  readonly bySubject: ReadonlyMap<string, ReadonlyArray<Triple>>;
  readonly byObject: ReadonlyMap<string, ReadonlyArray<Triple>>;
}

interface Triple {
  readonly head: string;
  readonly relation: string;
  readonly tail: string;
}

function buildFactIndex(triples: ReadonlyArray<Triple>): FactIndex {
  const byPredicate = new Map<string, Triple[]>();
  const bySubject = new Map<string, Triple[]>();
  const byObject = new Map<string, Triple[]>();

  for (const t of triples) {
    if (!byPredicate.has(t.relation)) byPredicate.set(t.relation, []);
    byPredicate.get(t.relation)!.push(t);
    if (!bySubject.has(t.head)) bySubject.set(t.head, []);
    bySubject.get(t.head)!.push(t);
    if (!byObject.has(t.tail)) byObject.set(t.tail, []);
    byObject.get(t.tail)!.push(t);
  }

  return { byPredicate, bySubject, byObject };
}

function expandRule(rule: RuleCandidate, _index: FactIndex, config: AMIEConfig): ReadonlyArray<RuleCandidate> {
  if (rule.atoms.length >= config.maxRuleLength) return [rule];
  return [rule];
}
规则应用与冲突消解
挖掘得到的规则需要应用于知识图谱来推导新事实。规则应用的过程是模式匹配：对规则体中的每个原子，在图谱中查找匹配的三元组，通过变量绑定传播获得规则头的具体化实例。


当多条规则推导出矛盾结论时（如规则 A 推导出「X 国籍中国」，规则 B 推导出「X 国籍美国」），需要冲突消解策略。常见策略包括：置信度优先（选择高置信度规则的结论）、多数投票（多条规则支持的结论优先）和基于本体约束的过滤（利用功能性属性约束「每个人只有一个国籍」排除矛盾）。

小结
    

  • 规则推理产生可解释的推理链条，适合高可信度需求场景
    • 

  • Horn 规则和路径规则是知识图谱中最常见的规则形式
    • 

  • AMIE 是专为知识图谱设计的规则挖掘系统，考虑了开放世界假设
    • 

  • 规则质量通过支持度、头覆盖率和 PCA 置信度三个指标评估
    • 

  • 规则应用需要高效的模式匹配和变量绑定传播
    • 

  • 冲突消解策略在多规则推导矛盾结论时至关重要
    • 

  • 规则推理常与图嵌入结合，形成「可解释 + 高准确」的混合系统
    •
