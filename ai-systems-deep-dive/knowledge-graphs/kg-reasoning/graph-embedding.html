图嵌入方法

核心概念

图嵌入（Graph Embedding）是将知识图谱中的实体和关系映射到低维连续向量空间的技术，使得图的结构信息和语义信息被编码在稠密向量中。图嵌入是知识图谱推理的基础——通过在向量空间中进行数学运算，可以预测缺失的边（链接预测）、发现实体类型（节点分类）和识别相似实体（实体对齐）。核心思想是：图中相连的节点在向量空间中应该彼此接近。

翻译距离模型
翻译距离模型（Translation-based Models）是图嵌入中最经典的模型族。TransE 的核心直觉是将关系视为实体间的平移操作：对于三元组 (h, r, t)，满足 h + r ≈ t。训练目标是最小化正确三元组中 h + r 与 t 的距离，同时最大化错误三元组的距离。


TransE 使用基于边界的排序损失：L = Σ [γ + d(h+r, t) - d(h'+r, t')]_+，其中 γ 是边界值，d 通常选择 L1 或 L2 距离，(h', r, t') 是通过随机替换头或尾实体得到的负样本。


interface KGEmbeddingConfig {
  readonly entityDim: number;
  readonly relationDim: number;
  readonly margin: number;
  readonly learningRate: number;
  readonly negSampleSize: number;
  readonly distanceFunction: 'L1' | 'L2';
  readonly normConstraint: boolean;
}

interface Triple {
  readonly head: number;
  readonly relation: number;
  readonly tail: number;
}

interface EmbeddingState {
  readonly entityEmbeddings: Float32Array[];
  readonly relationEmbeddings: Float32Array[];
}

function transEScore(h: Float32Array, r: Float32Array, t: Float32Array, distance: 'L1' | 'L2'): number {
  let score = 0;
  for (let i = 0; i < h.length; i++) {
    const diff = h[i] + r[i] - t[i];
    score += distance === 'L1' ? Math.abs(diff) : diff * diff;
  }
  return distance === 'L2' ? Math.sqrt(score) : score;
}

function generateNegativeSample(triple: Triple, entityCount: number): Triple {
  const replaceHead = Math.random() < 0.5;
  const randomEntity = Math.floor(Math.random() * entityCount);
  return replaceHead
    ? { head: randomEntity, relation: triple.relation, tail: triple.tail }
    : { head: triple.head, relation: triple.relation, tail: randomEntity };
}

function marginRankingLoss(posScore: number, negScore: number, margin: number): number {
  return Math.max(0, margin + posScore - negScore);
}
TransE 的主要局限是难以处理一对多、多对一和多对多关系。例如，如果多个实体 t1, t2, t3 都是 (h, r) 的正确尾实体，TransE 会迫使 t1 ≈ t2 ≈ t3，导致这些实体的表示退化为相同向量。TransH 和 TransR 通过引入关系特定的超平面投影和矩阵变换来解决这一问题。


语义匹配模型
语义匹配模型（Semantic Matching Models）通过实体和关系向量的交互来衡量三元组的合理性。DistMult 使用双线性对角模型：f(h, r, t) = h^T · diag(r) · t = Σ h_i · r_i · t_i。DistMult 天然适合对称关系（如「互为朋友」），因为 f(h, r, t) = f(t, r, h)，但无法区分非对称关系（如「父子关系」）。


ComplEx 通过引入复数空间来解决非对称问题。实体和关系被嵌入到复数空间 C^d 中，评分函数取实部：f(h, r, t) = Re(Σ h_i · r_i · t̄_i)，其中 t̄ 是 t 的复共轭。复共轭的引入打破了对称性，使得 f(h, r, t) ≠ f(t, r, h)。


interface ComplExEmbedding {
  readonly real: Float32Array;
  readonly imaginary: Float32Array;
}

function complExScore(h: ComplExEmbedding, r: ComplExEmbedding, t: ComplExEmbedding): number {
  let score = 0;
  const dim = h.real.length;

  for (let i = 0; i < dim; i++) {
    score += h.real[i] * r.real[i] * t.real[i];
    score += h.imaginary[i] * r.real[i] * t.imaginary[i];
    score += h.real[i] * r.imaginary[i] * t.imaginary[i];
    score -= h.imaginary[i] * r.imaginary[i] * t.real[i];
  }

  return score;
}

function rotatEScore(h: ComplExEmbedding, r: ComplExEmbedding, t: ComplExEmbedding): number {
  let score = 0;
  const dim = h.real.length;

  for (let i = 0; i < dim; i++) {
    const rotatedReal = h.real[i] * r.real[i] - h.imaginary[i] * r.imaginary[i];
    const rotatedImag = h.real[i] * r.imaginary[i] + h.imaginary[i] * r.real[i];

    const diffReal = rotatedReal - t.real[i];
    const diffImag = rotatedImag - t.imaginary[i];

    score += diffReal * diffReal + diffImag * diffImag;
  }

  return -Math.sqrt(score);
}
RotatE 将关系建模为复数空间中的旋转操作：t = h ∘ r（Hadamard 积），约束 |r_i| = 1。旋转操作可以同时建模对称、反对称、逆和组合关系，是目前表达能力最强的翻译类模型之一。


训练策略与评估
图嵌入的训练核心是负采样策略。均匀随机负采样可能生成「太容易」的负样本（如用无关实体替换），导致模型无法学习细粒度的区分能力。Self-Adversarial Negative Sampling 根据当前模型的评分为负样本分配权重，使更难区分的负样本获得更大的梯度贡献。


评估图嵌入模型通常使用链接预测任务：对于测试集中的三元组 (h, r, ?)，模型为所有候选尾实体打分并排序，然后计算 MRR（Mean Reciprocal Rank）和 Hits@k（正确实体排在前 k 名的比例）。

小结
    

  • 图嵌入将实体和关系映射到低维向量空间，是知识图谱推理的基础
    • 

  • TransE 是最经典的翻译距离模型，简单高效但难处理一对多关系
    • 

  • DistMult 适合对称关系，ComplEx 通过复数空间解决非对称问题
    • 

  • RotatE 将关系建模为旋转操作，可同时建模多种关系模式
    • 

  • 负采样策略直接影响模型训练效果，Self-Adversarial 采样表现最优
    • 

  • 链接预测是图嵌入的标准评估任务，MRR 和 Hits@k 是核心指标
    • 

  • 工业场景中图嵌入通常与 GNN 结合使用，充分利用图的结构信息
    •
