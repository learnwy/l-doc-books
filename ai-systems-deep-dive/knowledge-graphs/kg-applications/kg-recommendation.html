知识图谱增强推荐

核心概念

知识图谱增强推荐（KG-enhanced Recommendation）是将知识图谱的结构化信息引入推荐系统，解决数据稀疏和冷启动问题的技术。传统协同过滤仅依赖用户-物品交互矩阵，当新用户或新物品缺乏交互记录时推荐质量急剧下降。知识图谱通过为物品提供丰富的属性和关系信息（如「电影 A 的导演是 X，X 还导演了电影 B」），建立物品间的语义关联，即使在交互稀疏的情况下也能提供高质量推荐。

嵌入融合方法
嵌入融合是最直接的 KG 增强方式：先在知识图谱上预训练实体嵌入（使用 TransE、ComplEx 等），然后将嵌入向量作为推荐模型的额外特征。这种方法的优点是模块化设计，KG 嵌入和推荐模型可以独立训练和更新。


CKE（Collaborative Knowledge Embedding）同时学习协同过滤嵌入、KG 结构嵌入和文本嵌入，最终将三种嵌入融合用于评分预测。联合训练使得物品表示同时捕获了交互信号和语义信息。


interface KGEnhancedRecConfig {
  readonly embeddingDim: number;
  readonly kgEmbeddingModel: 'transE' | 'complEx' | 'rotatE';
  readonly fusionMethod: 'concat' | 'add' | 'attention' | 'gate';
  readonly kgWeight: number;
  readonly learningRate: number;
}

interface ItemRepresentation {
  readonly itemId: string;
  readonly collaborativeEmb: Float32Array;
  readonly kgStructuralEmb: Float32Array;
  readonly kgTextualEmb: Float32Array;
  readonly fusedEmb: Float32Array;
}

function fuseEmbeddings(
  cfEmb: Float32Array,
  kgEmb: Float32Array,
  method: 'concat' | 'add' | 'gate',
  kgWeight: number,
): Float32Array {
  switch (method) {
    case 'concat': {
      const result = new Float32Array(cfEmb.length + kgEmb.length);
      result.set(cfEmb, 0);
      result.set(kgEmb, cfEmb.length);
      return result;
    }
    case 'add': {
      const result = new Float32Array(cfEmb.length);
      for (let i = 0; i < cfEmb.length; i++) {
        result[i] = (1 - kgWeight) * cfEmb[i] + kgWeight * kgEmb[i];
      }
      return result;
    }
    case 'gate': {
      const result = new Float32Array(cfEmb.length);
      for (let i = 0; i < cfEmb.length; i++) {
        const gate = 1 / (1 + Math.exp(-(cfEmb[i] - kgEmb[i])));
        result[i] = gate * cfEmb[i] + (1 - gate) * kgEmb[i];
      }
      return result;
    }
  }
}
路径推理方法
路径推理方法利用知识图谱中从用户到候选物品的路径信息进行推荐。例如，用户 U 看过电影 A，电影 A 的导演是 D，导演 D 还拍了电影 B——这条路径 U → 看过 → A → 导演 → D → 导演 → B 就是推荐电影 B 给用户 U 的理由。路径推理方法天然具有可解释性。


RippleNet 将用户的历史交互作为「种子」，在知识图谱上进行多轮传播（类似水波纹扩散），逐步扩大用户兴趣的覆盖范围。每轮传播中，与用户兴趣相关的实体获得更高的注意力权重。


interface RecommendationPath {
  readonly userId: string;
  readonly itemId: string;
  readonly path: ReadonlyArray<{
    readonly entity: string;
    readonly relation: string;
  }>;
  readonly score: number;
  readonly explanation: string;
}

interface RippleNetConfig {
  readonly embeddingDim: number;
  readonly numHops: number;
  readonly neighborSize: number;
  readonly aggregation: 'sum' | 'concat' | 'neighbor';
}

function rippleNetPropagate(
  userHistory: ReadonlyArray<string>,
  kgNeighbors: ReadonlyMap<string, ReadonlyArray<{ relation: string; tail: string }>>,
  numHops: number,
  neighborSize: number,
): ReadonlyArray<ReadonlySet<string>> {
  const ripples: Set<string>[] = [];
  ripples.push(new Set(userHistory));

  for (let hop = 0; hop < numHops; hop++) {
    const prevRipple = ripples[ripples.length - 1];
    const nextRipple = new Set<string>();

    for (const entity of prevRipple) {
      const neighbors = kgNeighbors.get(entity) ?? [];
      const sampled = neighbors.slice(0, neighborSize);
      for (const n of sampled) {
        nextRipple.add(n.tail);
      }
    }

    ripples.push(nextRipple);
  }

  return ripples;
}

function generateExplanation(path: RecommendationPath): string {
  const steps = path.path.map((step, i) =>
    i === 0 ? `用户关注了「${step.entity}」` : `通过「${step.relation}」关系连接到「${step.entity}」`,
  );
  return steps.join('，');
}

GNN 融合方法
基于图神经网络的融合方法在统一的图结构上同时学习用户-物品交互和知识图谱信息。KGAT（Knowledge Graph Attention Network）构建一个融合图，包含用户-物品交互边和物品-属性关系边，在这个融合图上使用注意力机制进行消息传递。


KGIN（Knowledge Graph-based Intent Network）进一步将用户意图显式建模：每种用户意图对应知识图谱中的一组关系（如「喜欢某导演的电影」是一种意图），通过解耦不同意图下的物品表示来提升推荐准确性和可解释性。


interface KGATConfig {
  readonly embeddingDim: number;
  readonly numLayers: number;
  readonly numHeads: number;
  readonly dropout: number;
  readonly aggregation: 'bi-interaction' | 'graphsage' | 'gcn';
}

interface UnifiedGraph {
  readonly userNodes: ReadonlyArray<number>;
  readonly itemNodes: ReadonlyArray<number>;
  readonly entityNodes: ReadonlyArray<number>;
  readonly interactionEdges: ReadonlyArray<{ user: number; item: number }>;
  readonly kgEdges: ReadonlyArray<{ head: number; relation: number; tail: number }>;
}

function kgatAttention(headEmb: Float32Array, tailEmb: Float32Array, relationEmb: Float32Array): number {
  let score = 0;
  for (let i = 0; i < headEmb.length; i++) {
    score += (headEmb[i] + relationEmb[i]) * tailEmb[i];
  }
  return score;
}
小结
    

  • KG 增强推荐通过物品属性和关系信息解决数据稀疏和冷启动问题
    • 

  • 嵌入融合方法简单灵活，适合模块化系统架构
    • 

  • 路径推理方法天然具有可解释性，能生成推荐理由
    • 

  • GNN 融合方法在准确性上表现最优，但计算成本较高
    • 

  • RippleNet 通过多跳传播扩展用户兴趣覆盖范围
    • 

  • KGAT/KGIN 在统一图上同时学习交互信号和语义信息
    • 

  • 实际系统中 KG 增强推荐通常与协同过滤和内容推荐形成 ensemble
    •
