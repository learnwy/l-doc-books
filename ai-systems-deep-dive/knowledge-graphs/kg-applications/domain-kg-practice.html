领域知识图谱实践

核心概念

领域知识图谱（Domain Knowledge Graph）是聚焦特定行业或领域的专业知识图谱，与通用知识图谱相比，它具有更深的领域知识覆盖、更精细的本体设计和更高的知识准确度。领域知识图谱是企业智能化的核心基础设施，广泛应用于医疗、金融、法律、电商等行业。

医疗知识图谱
医疗知识图谱是领域 KG 中最成熟的方向之一。它整合了疾病、症状、药物、检查、基因等医学实体及其关系，为临床决策支持、药物研发和医学研究提供知识基础。


interface MedicalKGSchema {
  entityTypes: MedicalEntityType[];
  relationTypes: MedicalRelationType[];
  constraints: MedicalConstraint[];
}

type MedicalEntityType = 'Disease' | 'Symptom' | 'Drug' | 'Treatment' | 'Gene' | 'Protein' | 'LabTest' | 'BodyPart';

type MedicalRelationType =
  | 'has_symptom'
  | 'treats'
  | 'causes'
  | 'interacts_with'
  | 'contraindicated_for'
  | 'targets'
  | 'located_in';

interface ClinicalDecisionSupport {
  symptomChecker(symptoms: string[]): DiagnosisCandidate[];
  drugInteractionCheck(drugs: string[]): Interaction[];
  treatmentRecommendation(disease: string): Treatment[];
}

interface DiagnosisCandidate {
  disease: string;
  probability: number;
  matchedSymptoms: string[];
  suggestedTests: string[];
}

function symptomBasedDiagnosis(symptoms: string[], medicalKG: MedicalKG): DiagnosisCandidate[] {
  const candidateDiseases = new Map<string, { count: number; total: number }>();

  for (const symptom of symptoms) {
    const diseases = medicalKG.getRelated(symptom, 'has_symptom', 'reverse');
    for (const disease of diseases) {
      const current = candidateDiseases.get(disease.id) ?? { count: 0, total: 0 };
      current.count++;
      current.total = medicalKG.getRelatedCount(disease.id, 'has_symptom');
      candidateDiseases.set(disease.id, current);
    }
  }

  return [...candidateDiseases.entries()]
    .map(([diseaseId, stats]) => ({
      disease: diseaseId,
      probability: stats.count / Math.max(stats.total, symptoms.length),
      matchedSymptoms: symptoms.filter((s) => medicalKG.hasRelation(diseaseId, 'has_symptom', s)),
      suggestedTests: medicalKG.getRelated(diseaseId, 'diagnosed_by').map((t) => t.label),
    }))
    .sort((a, b) => b.probability - a.probability);
}
医疗 KG 的特殊挑战包括：医学术语的标准化（ICD-10、SNOMED CT）、数据隐私保护（HIPAA 合规）、知识的时效性（医学指南定期更新）和高准确度要求（错误知识可能危害患者健康）。


金融知识图谱
金融知识图谱整合了企业、人物、产品、事件等实体及其复杂关系网络，是智能风控、投资研究和合规监管的核心工具。


interface FinancialKGSchema {
  entityTypes: FinancialEntityType[];
  relationTypes: FinancialRelationType[];
}

type FinancialEntityType = 'Company' | 'Person' | 'Product' | 'Industry' | 'Event' | 'Risk' | 'Regulation';

type FinancialRelationType =
  | 'controls'
  | 'invests_in'
  | 'supplies'
  | 'competes_with'
  | 'executive_of'
  | 'guarantees'
  | 'sued_by';

interface RiskAssessment {
  entity: string;
  directRisks: RiskFactor[];
  indirectRisks: RiskFactor[];
  riskPropagationPaths: RiskPath[];
}

interface RiskPath {
  entities: string[];
  relations: string[];
  riskScore: number;
}

function assessSupplyChainRisk(company: string, financialKG: FinancialKG, maxDepth: number = 3): RiskAssessment {
  const directRisks = financialKG.getRelated(company, 'has_risk');
  const suppliers = financialKG.traverseBFS(company, ['supplies', 'depends_on'], maxDepth);

  const indirectRisks: RiskFactor[] = [];
  const propagationPaths: RiskPath[] = [];

  for (const supplier of suppliers) {
    const risks = financialKG.getRelated(supplier.entity, 'has_risk');
    for (const risk of risks) {
      const path = financialKG.shortestPath(company, supplier.entity);
      const riskScore = risk.severity / (path.length + 1);
      indirectRisks.push({ ...risk, source: supplier.entity, propagatedScore: riskScore });
      propagationPaths.push({ entities: path.entities, relations: path.relations, riskScore });
    }
  }

  return {
    entity: company,
    directRisks: directRisks.map((r) => ({ ...r, source: company, propagatedScore: r.severity })),
    indirectRisks,
    riskPropagationPaths: propagationPaths.sort((a, b) => b.riskScore - a.riskScore),
  };
}
金融 KG 的核心价值在于关系网络分析。通过图遍历可以发现隐性关联（如通过多层控股关系间接控制的企业）、识别担保圈和关联交易、追踪资金流向和风险传导路径。


电商知识图谱
电商知识图谱围绕商品、品牌、属性、用户构建知识网络，为搜索、推荐和导购提供结构化知识支持。

小结
    

  • 领域知识图谱聚焦特定行业，具有更深的领域覆盖和更高的知识准确度
    • 

  • 医疗 KG 支持辅助诊断和药物推荐，需要高准确度和标准化术语体系
    • 

  • 金融 KG 的核心价值在于关系网络分析，支持风控、投研和合规监管
    • 

  • 电商 KG 围绕商品属性和关联关系构建，增强搜索精准度和推荐相关性
    • 

  • 领域 KG 建设需要领域专家深度参与，数据质量和持续更新是长期挑战
