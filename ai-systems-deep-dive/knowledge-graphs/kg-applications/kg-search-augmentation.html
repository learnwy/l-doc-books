知识图谱搜索增强

核心概念

知识图谱搜索增强（KG-augmented Search）是将知识图谱的结构化知识融入搜索系统，提升查询理解、结果排序和答案展示质量的技术。传统搜索依赖关键词匹配和统计信号（如 TF-IDF、BM25），而知识图谱为搜索系统注入了语义理解能力——识别查询中的实体和意图、理解实体间的关系、在搜索结果页直接展示知识面板。Google Knowledge Panel、百度知识卡片和 Bing 知识回答都是 KG 搜索增强的典型应用。

实体链接与查询理解
实体链接（Entity Linking）是 KG 搜索增强的第一步：识别查询中的实体提及（Entity Mention），并将其链接到知识图谱中的标准实体。例如，查询「苹果股价」中的「苹果」应链接到「Apple Inc.」而非水果「苹果」。


实体链接的核心挑战是歧义消解（Disambiguation）。解决方法包括：基于上下文的消歧（利用查询中其他词汇判断）、基于流行度的消歧（选择最常见的含义）和基于用户画像的消歧（根据用户历史偏好判断）。


interface EntityMention {
  readonly text: string;
  readonly startPos: number;
  readonly endPos: number;
  readonly candidates: ReadonlyArray<EntityCandidate>;
}

interface EntityCandidate {
  readonly entityId: string;
  readonly label: string;
  readonly description: string;
  readonly popularity: number;
  readonly contextScore: number;
  readonly finalScore: number;
}

interface QueryUnderstanding {
  readonly originalQuery: string;
  readonly entities: ReadonlyArray<LinkedEntity>;
  readonly intent: QueryIntent;
  readonly expandedTerms: ReadonlyArray<string>;
}

interface LinkedEntity {
  readonly mention: string;
  readonly entityId: string;
  readonly entityLabel: string;
  readonly entityType: string;
  readonly confidence: number;
}

type QueryIntent = 'navigational' | 'informational' | 'transactional' | 'entity-seeking';

function disambiguateEntity(
  mention: EntityMention,
  queryContext: string,
  userProfile: ReadonlyMap<string, number>,
): EntityCandidate | null {
  if (mention.candidates.length === 0) return null;

  const scored = mention.candidates.map((candidate) => {
    const contextWeight = 0.4;
    const popularityWeight = 0.3;
    const userWeight = 0.3;

    const userScore = userProfile.get(candidate.entityId) ?? 0;
    const finalScore =
      contextWeight * candidate.contextScore +
      popularityWeight * Math.log(1 + candidate.popularity) +
      userWeight * userScore;

    return { ...candidate, finalScore };
  });

  return scored.sort((a, b) => b.finalScore - a.finalScore)[0];
}
查询扩展与语义匹配
知识图谱为查询扩展提供了丰富的语义信号。当用户搜索「头疼怎么办」时，知识图谱可以扩展出相关的医学术语（「偏头痛」「紧张性头痛」）、关联症状（「恶心」「畏光」）和治疗方法（「布洛芬」「休息」）。这种基于知识的扩展比纯统计方法（如伪相关反馈）更精确。


interface QueryExpansion {
  readonly originalQuery: string;
  readonly expandedTerms: ReadonlyArray<{
    readonly term: string;
    readonly source: 'synonym' | 'related-entity' | 'attribute' | 'hypernym';
    readonly weight: number;
  }>;
  readonly expandedQuery: string;
}

function expandQueryWithKG(
  query: string,
  linkedEntities: ReadonlyArray<LinkedEntity>,
  kg: ReadonlyMap<string, ReadonlyArray<{ relation: string; target: string; targetLabel: string }>>,
): QueryExpansion {
  const expandedTerms: QueryExpansion['expandedTerms'] = [];

  for (const entity of linkedEntities) {
    const neighbors = kg.get(entity.entityId) ?? [];

    for (const neighbor of neighbors) {
      if (neighbor.relation === 'alias' || neighbor.relation === 'synonym') {
        expandedTerms.push({
          term: neighbor.targetLabel,
          source: 'synonym',
          weight: 0.8,
        });
      } else if (neighbor.relation === 'related_to') {
        expandedTerms.push({
          term: neighbor.targetLabel,
          source: 'related-entity',
          weight: 0.5,
        });
      } else if (neighbor.relation === 'is_a') {
        expandedTerms.push({
          term: neighbor.targetLabel,
          source: 'hypernym',
          weight: 0.3,
        });
      }
    }
  }

  const topTerms = expandedTerms.sort((a, b) => b.weight - a.weight).slice(0, 5);

  const expandedQuery = `${query} ${topTerms.map((t) => t.term).join(' ')}`;

  return { originalQuery: query, expandedTerms: topTerms, expandedQuery };
}

知识面板与直接回答
知识面板（Knowledge Panel）是搜索结果页中展示实体结构化信息的模块。当用户搜索一个已知实体时（如「爱因斯坦」），搜索引擎在结果页右侧或顶部展示该实体的关键属性（出生日期、代表作、获奖信息等）和关联实体。


知识面板的生成包含三个步骤：实体识别（确认查询指向的 KG 实体）、属性选择（根据实体类型选择最相关的属性展示）和布局渲染（将结构化数据渲染为可视化面板）。


interface KnowledgePanel {
  readonly entityId: string;
  readonly entityLabel: string;
  readonly entityType: string;
  readonly description: string;
  readonly imageUrl?: string;
  readonly attributes: ReadonlyArray<{
    readonly label: string;
    readonly value: string;
    readonly source: string;
  }>;
  readonly relatedEntities: ReadonlyArray<{
    readonly entityId: string;
    readonly label: string;
    readonly relation: string;
  }>;
}

function generateKnowledgePanel(
  entityId: string,
  entityData: ReadonlyMap<string, ReadonlyArray<{ predicate: string; object: string }>>,
  typeTemplates: ReadonlyMap<string, ReadonlyArray<string>>,
): KnowledgePanel | null {
  const triples = entityData.get(entityId);
  if (!triples) return null;

  const typeTriple = triples.find((t) => t.predicate === 'type');
  const entityType = typeTriple?.object ?? 'Thing';
  const template = typeTemplates.get(entityType) ?? ['description'];

  const attributes = template
    .map((attr) => {
      const match = triples.find((t) => t.predicate === attr);
      return match ? { label: attr, value: match.object, source: 'KG' } : null;
    })
    .filter((a): a is NonNullable<typeof a> => a !== null);

  const labelTriple = triples.find((t) => t.predicate === 'label');
  const descTriple = triples.find((t) => t.predicate === 'description');

  return {
    entityId,
    entityLabel: labelTriple?.object ?? entityId,
    entityType,
    description: descTriple?.object ?? '',
    attributes,
    relatedEntities: [],
  };
}
小结
    

  • KG 搜索增强从查询理解、查询扩展、结果排序和答案展示四个维度提升搜索质量
    • 

  • 实体链接是搜索增强的第一步，歧义消解的准确性直接影响后续流程
    • 

  • 基于知识的查询扩展比纯统计方法更精确，但需控制语义漂移
    • 

  • 知识面板在搜索结果页直接展示结构化答案，大幅提升用户体验
    • 

  • 实体类型决定知识面板的属性选择模板（人物、地点、组织各有不同）
    • 

  • Google、百度和 Bing 的知识面板都依赖大规模知识图谱支撑
    • 

  • 知识图谱搜索增强正在与 LLM 结合，形成 RAG + KG 的下一代搜索架构
    •
