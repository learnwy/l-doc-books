知识图谱增强搜索

核心概念

知识图谱增强搜索（KG-Enhanced Search）将知识图谱的结构化知识融入搜索系统的各个环节，提升搜索的语义理解、结果质量和用户体验。知识图谱为搜索提供实体识别、实体消歧、查询扩展和结构化答案展示等能力。

实体链接与消歧
搜索场景下的实体链接需要在极低延迟内将查询中的实体提及映射到知识图谱实体。查询文本极短、上下文有限、用户表达多样化，使得搜索场景的实体链接比文档级实体链接更具挑战。


interface SearchEntityLinker {
  link(query: string): Promise<LinkedSearchEntity[]>;
  disambiguate(mention: string, context: string): Promise<DisambiguationResult>;
}

interface LinkedSearchEntity {
  mention: string;
  kgEntity: KGEntity;
  confidence: number;
  disambiguationMethod: string;
}

interface KGEntity {
  id: string;
  label: string;
  type: string;
  popularity: number;
  description: string;
  aliases: string[];
}

async function searchEntityLinking(
  query: string,
  kg: KnowledgeGraph,
  popularityWeight: number = 0.3,
): Promise<LinkedSearchEntity[]> {
  const mentions = detectMentions(query);
  const results: LinkedSearchEntity[] = [];

  for (const mention of mentions) {
    const candidates = await kg.searchEntities(mention.text, 10);

    const scored = candidates.map((c) => ({
      candidate: c,
      score:
        (1 - popularityWeight) * computeTextSimilarity(mention.text, c.label, c.aliases) +
        (popularityWeight * Math.log(c.popularity + 1)) / Math.log(1000000),
    }));

    const best = scored.sort((a, b) => b.score - a.score)[0];
    if (best && best.score > 0.5) {
      results.push({
        mention: mention.text,
        kgEntity: best.candidate,
        confidence: best.score,
        disambiguationMethod: 'popularity_weighted',
      });
    }
  }

  return results;
}
Google Knowledge Panel 是知识图谱增强搜索的典型应用。当用户搜索一个已知实体时，搜索结果页面右侧会展示一个知识面板，包含实体的基本属性、关联实体和相关图片。这种展示直接回答了用户的信息需求，无需点击任何搜索结果。搜索场景的实体消歧需要综合多种上下文信号。当用户搜索 "苹果" 时，如果搜索历史中包含 "iPhone 价格" 等科技类查询，则应该链接到 Apple Inc.；如果历史中包含 "水果批发" 等查询，则应链接到水果品类。消歧策略的优先级通常为：用户上下文 > 查询上下文 > 全局流行度。

KG 辅助排序与推荐
知识图谱为搜索排序提供丰富的结构化特征，包括实体类型、实体之间的关系、实体的图结构特征（度中心性、聚类系数）等。


interface KGRankingFeatures {
  entityPopularity: number;
  entityTypeMatch: boolean;
  pathLength: number;
  commonNeighbors: number;
  kgEmbeddingSimilarity: number;
  entityAuthority: number;
}

function extractKGFeatures(queryEntity: KGEntity, docEntity: KGEntity, kg: KnowledgeGraph): KGRankingFeatures {
  return {
    entityPopularity: Math.log(docEntity.popularity + 1),
    entityTypeMatch: queryEntity.type === docEntity.type,
    pathLength: kg.shortestPath(queryEntity.id, docEntity.id)?.length ?? -1,
    commonNeighbors: kg.commonNeighborCount(queryEntity.id, docEntity.id),
    kgEmbeddingSimilarity: cosineSimilarity(kg.getEmbedding(queryEntity.id), kg.getEmbedding(docEntity.id)),
    entityAuthority: kg.getPageRank(docEntity.id),
  };
}
知识图谱在推荐场景中同样有重要应用。基于 KG 的推荐系统利用用户与物品之间的图谱路径来解释推荐理由（"因为你喜欢 A 导演的电影，推荐同导演的 B"），同时利用图谱的多跳连接来缓解冷启动问题。


知识图谱的实时维护
在搜索系统中，知识图谱需要持续更新以保持信息的新鲜度。热点事件、人物变动和新实体的出现都需要实时反映到图谱中。

知识图谱辅助排序的一个关键挑战是特征的实时性。图结构特征（如 PageRank、度中心性）可以离线计算并定期更新，但查询与文档之间的图谱路径特征需要在线实时计算。为了满足搜索延迟要求，工业系统通常预计算高频实体对之间的路径特征并缓存，对于低频查询则降级为仅使用实体级别的静态特征。


| 热点事件 | 分钟级 | 新闻流 | 实时抽取+人工审核 | | 实体属性变更 | 小时级 | 权威数据源 | 定时同步 | | 新实体入库 | 天级 | 多源融合 | 批量导入 | | 关系更新 | 天级 | 抽取管线 | 增量更新 | | 图谱质量修正 | 周级 | 用户反馈 | 人工审核 |


小结
    

  • 知识图谱增强搜索的查询理解、排序和结果展示，提供结构化的精准答案
    • 

  • 搜索场景下的实体链接需要在极低延迟内处理短文本消歧，流行度加权是关键策略
    • 

  • KG 为排序提供实体权威度、路径距离等结构化特征，提升排序质量
    • 

  • 知识面板（Knowledge Panel）是 KG 增强搜索的标志性产品形态
    • 

  • 搜索系统中的 KG 需要实时维护，热点事件需分钟级更新，常规数据天级更新
