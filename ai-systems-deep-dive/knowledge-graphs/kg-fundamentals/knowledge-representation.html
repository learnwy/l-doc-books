知识表示

核心概念

知识表示（Knowledge Representation）是将现实世界的知识编码为计算机可处理的形式化结构的方法论。在知识图谱中，知识表示决定了知识的组织方式、表达能力和推理潜力。从逻辑表示到分布式表示，知识表示的范式经历了深刻的演进。

RDF 与语义 Web 标准
RDF（Resource Description Framework）是 W3C 制定的知识表示标准，它将知识建模为由主语（Subject）、谓语（Predicate）和宾语（Object）构成的三元组。RDF 是语义 Web 技术栈的基础。


interface RDFResource {
  uri: string;
  prefixedName?: string;
}

interface RDFLiteral {
  value: string;
  datatype?: string;
  language?: string;
}

type RDFNode = RDFResource | RDFLiteral;

interface RDFStatement {
  subject: RDFResource;
  predicate: RDFResource;
  object: RDFNode;
  graph?: RDFResource;
}

interface RDFGraph {
  statements: RDFStatement[];
  namespaces: Map<string, string>;
}

function serializeNTriples(graph: RDFGraph): string {
  return graph.statements
    .map((s) => {
      const subj = `<${s.subject.uri}>`;
      const pred = `<${s.predicate.uri}>`;
      const obj =
        'uri' in s.object
          ? `<${(s.object as RDFResource).uri}>`
          : `"${(s.object as RDFLiteral).value}"${(s.object as RDFLiteral).language ? `@${(s.object as RDFLiteral).language}` : ''}`;
      return `${subj} ${pred} ${obj} .`;
    })
    .join('\n');
}

function sparqlQuery(endpoint: string, query: string): Promise<QueryResult> {
  return fetch(endpoint, {
    method: 'POST',
    headers: { 'Content-Type': 'application/sparql-query' },
    body: query,
  }).then((r) => r.json());
}
RDFS（RDF Schema）和 OWL（Web Ontology Language）在 RDF 基础上提供了更丰富的表达能力。RDFS 定义了类和属性的层次关系（subClassOf、subPropertyOf），OWL 进一步支持等价关系、基数约束、析取和合取等描述逻辑特性。


知识嵌入表示
知识嵌入（Knowledge Embedding）将实体和关系映射到低维连续向量空间，使得图结构中的语义关系可以通过向量运算来近似。知识嵌入解决了符号表示无法进行数值计算和相似度度量的局限。


interface KGEmbeddingModel {
  entityDim: number;
  relationDim: number;
  entities: Map<string, Float32Array>;
  relations: Map<string, Float32Array>;
}

function transEScore(head: Float32Array, relation: Float32Array, tail: Float32Array): number {
  let distance = 0;
  for (let i = 0; i < head.length; i++) {
    distance += (head[i] + relation[i] - tail[i]) ** 2;
  }
  return -Math.sqrt(distance);
}

function rotatEScore(head: Float32Array, relation: Float32Array, tail: Float32Array): number {
  const dim = head.length / 2;
  let score = 0;
  for (let i = 0; i < dim; i++) {
    const hRe = head[i],
      hIm = head[i + dim];
    const rRe = relation[i],
      rIm = relation[i + dim];
    const tRe = tail[i],
      tIm = tail[i + dim];
    const rotRe = hRe * rRe - hIm * rIm;
    const rotIm = hRe * rIm + hIm * rRe;
    score += (rotRe - tRe) ** 2 + (rotIm - tIm) ** 2;
  }
  return -score;
}

图结构特征与表达
图结构本身蕴含丰富的语义信息。节点的中心性（Centrality）反映其重要程度，社区结构（Community）反映实体的聚类关系，路径模式（Path Patterns）反映实体间的间接关系。


interface GraphAnalytics {
  degreeCentrality(nodeId: string): number;
  betweennessCentrality(nodeId: string): number;
  pageRank(dampingFactor: number): Map<string, number>;
  communityDetection(method: 'louvain' | 'label_propagation'): Map<string, number>;
  shortestPath(from: string, to: string): string[];
}

function computePageRank(
  graph: AdjacencyList,
  dampingFactor: number = 0.85,
  maxIterations: number = 100,
  tolerance: number = 1e-6,
): Map<string, number> {
  const nodes = Array.from(graph.keys());
  const n = nodes.length;
  const ranks = new Map<string, number>();
  nodes.forEach((node) => ranks.set(node, 1 / n));

  for (let iter = 0; iter < maxIterations; iter++) {
    const newRanks = new Map<string, number>();
    let diff = 0;

    for (const node of nodes) {
      let incomingSum = 0;
      const incomingNodes = graph.getIncoming(node);
      for (const incoming of incomingNodes) {
        const outDegree = graph.getOutgoing(incoming).length;
        incomingSum += (ranks.get(incoming) ?? 0) / outDegree;
      }
      const newRank = (1 - dampingFactor) / n + dampingFactor * incomingSum;
      diff += Math.abs(newRank - (ranks.get(node) ?? 0));
      newRanks.set(node, newRank);
    }

    for (const [k, v] of newRanks) ranks.set(k, v);
    if (diff < tolerance) break;
  }

  return ranks;
}
图结构特征在知识图谱应用中有广泛用途：PageRank 可以衡量实体的全局重要性，用于搜索结果排序；社区检测可以发现相关实体的聚类，用于知识推荐；最短路径和图模式可以用于关系发现和解释。


小结
    

  • 知识表示从符号逻辑演进到分布式嵌入，两种范式各有优势，趋向融合
    • 

  • RDF/OWL 提供标准化的形式化知识表示，支持逻辑推理但计算成本高
    • 

  • 知识嵌入（TransE、RotatE）将实体和关系映射到向量空间，支持高效的相似度计算和链接预测
    • 

  • 图结构特征（PageRank、社区检测）蕴含丰富的语义信息，可用于实体重要性评估和关系发现
    • 

  • 实际系统通常结合符号表示（可解释性）和嵌入表示（计算效率）的互补优势
    •
