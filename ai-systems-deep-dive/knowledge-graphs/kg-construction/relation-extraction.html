关系抽取

核心概念

关系抽取（Relation Extraction, RE）是从文本中识别实体对之间语义关系的任务。给定一个句子和其中的两个实体，关系抽取模型判断这两个实体之间是否存在预定义的关系类型。关系抽取是知识图谱自动构建的核心环节，直接决定了图谱中三元组的质量和覆盖度。

基于预训练模型的关系分类
基于 BERT 的关系分类是当前最主流的方法。将句子和实体标记一起输入 BERT，利用实体标记位置的表示进行关系分类。


interface REInput {
  text: string;
  headEntity: EntityMention;
  tailEntity: EntityMention;
}

interface EntityMention {
  text: string;
  start: number;
  end: number;
  type: string;
}

interface REOutput {
  relation: string;
  confidence: number;
  headEntity: EntityMention;
  tailEntity: EntityMention;
}

function buildREInput(text: string, head: EntityMention, tail: EntityMention): string {
  const tokens = text.split('');
  const headStart = head.start;
  const headEnd = head.end;
  const tailStart = tail.start;
  const tailEnd = tail.end;

  let marked = '';
  for (let i = 0; i < tokens.length; i++) {
    if (i === headStart) marked += '[E1]';
    if (i === tailStart) marked += '[E2]';
    marked += tokens[i];
    if (i === headEnd - 1) marked += '[/E1]';
    if (i === tailEnd - 1) marked += '[/E2]';
  }

  return `[CLS] ${marked} [SEP]`;
}

interface REClassifier {
  model: TransformerModel;
  relations: string[];
  threshold: number;
}

async function classifyRelation(input: REInput, classifier: REClassifier): Promise<REOutput | null> {
  const markedText = buildREInput(input.text, input.headEntity, input.tailEntity);
  const logits = await classifier.model.forward(markedText);
  const probabilities = softmax(logits);
  const maxIdx = argmax(probabilities);
  const relation = classifier.relations[maxIdx];

  if (relation === 'no_relation' || probabilities[maxIdx] < classifier.threshold) {
    return null;
  }

  return {
    relation,
    confidence: probabilities[maxIdx],
    headEntity: input.headEntity,
    tailEntity: input.tailEntity,
  };
}
实体标记策略有多种变体：Entity Marker（在实体两端插入标记 token）、Typed Entity Marker（标记中包含实体类型）和 Punctuation Marker（使用特殊标点代替特殊 token）。研究表明 Typed Entity Marker 效果最优。


联合实体关系抽取
联合抽取（Joint Extraction）同时完成实体识别和关系分类，避免了管线式方法中 NER 错误向 RE 传播的问题。


interface JointExtractionOutput {
  triples: ExtractedTriple[];
  entities: ExtractedEntity[];
}

interface ExtractedTriple {
  head: ExtractedEntity;
  relation: string;
  tail: ExtractedEntity;
  confidence: number;
}

interface CasRelOutput {
  subjectSpans: Array<[number, number]>;
  objectRelationPairs: Map<string, Array<{ objectSpan: [number, number]; relation: string }>>;
}

interface TPLinkerOutput {
  entityHeadToTail: Map<number, number>;
  headToHead: Map<string, Array<[number, number]>>;
  tailToTail: Map<string, Array<[number, number]>>;
}

function decodeTPLinker(output: TPLinkerOutput, tokens: string[]): ExtractedTriple[] {
  const triples: ExtractedTriple[] = [];

  for (const [relation, headPairs] of output.headToHead) {
    for (const [subjectHead, objectHead] of headPairs) {
      const subjectTail = output.entityHeadToTail.get(subjectHead);
      const objectTail = output.entityHeadToTail.get(objectHead);

      if (subjectTail !== undefined && objectTail !== undefined) {
        const tailPairs = output.tailToTail.get(relation) ?? [];
        const matched = tailPairs.some(([st, ot]) => st === subjectTail && ot === objectTail);

        if (matched) {
          triples.push({
            head: {
              text: tokens.slice(subjectHead, subjectTail + 1).join(''),
              type: '',
              start: subjectHead,
              end: subjectTail + 1,
              confidence: 1,
            },
            relation,
            tail: {
              text: tokens.slice(objectHead, objectTail + 1).join(''),
              type: '',
              start: objectHead,
              end: objectTail + 1,
              confidence: 1,
            },
            confidence: 1,
          });
        }
      }
    }
  }

  return triples;
}

远程监督与降噪
远程监督（Distant Supervision）利用已有知识库自动生成训练数据。其核心假设是：如果知识库中存在三元组 (h, r, t)，那么任何同时提到 h 和 t 的句子都可能表达了关系 r。这个假设会引入大量噪声标签。


interface DistantSupervisionConfig {
  knowledgeBase: KnowledgeBase;
  corpus: TextCorpus;
  maxSentencesPerPair: number;
  negativeRatio: number;
}

function generateDSLabels(
  sentence: string,
  entityPairs: Array<[Entity, Entity]>,
  kb: KnowledgeBase,
): Array<{ head: Entity; tail: Entity; relation: string; isNoisy: boolean }> {
  const labels: Array<{ head: Entity; tail: Entity; relation: string; isNoisy: boolean }> = [];

  for (const [head, tail] of entityPairs) {
    const kbRelations = kb.getRelations(head.id, tail.id);
    if (kbRelations.length > 0) {
      for (const rel of kbRelations) {
        labels.push({ head, tail, relation: rel, isNoisy: true });
      }
    }
  }

  return labels;
}

interface BagLevelAttention {
  sentenceEmbeddings: Float32Array[];
  queryVector: Float32Array;
  temperature: number;
}

function bagAttention(bag: BagLevelAttention): Float32Array {
  const weights = bag.sentenceEmbeddings.map((emb) => dotProduct(emb, bag.queryVector) / bag.temperature);
  const attentionWeights = softmax(new Float32Array(weights));

  const dim = bag.sentenceEmbeddings[0].length;
  const aggregated = new Float32Array(dim);
  for (let i = 0; i < bag.sentenceEmbeddings.length; i++) {
    for (let j = 0; j < dim; j++) {
      aggregated[j] += attentionWeights[i] * bag.sentenceEmbeddings[i][j];
    }
  }
  return aggregated;
}
多实例学习（Multi-Instance Learning）是降低远程监督噪声的经典方法。它将同一实体对的所有句子组成一个 "包"（Bag），通过注意力机制自动学习每个句子的权重，降低噪声句子的影响。


小结
    

  • 关系抽取是知识图谱构建的核心任务，从文本中识别实体对之间的语义关系
    • 

  • 基于 BERT 的关系分类是主流方法，Typed Entity Marker 策略效果最优
    • 

  • 联合抽取（CasRel、TPLinker）同时完成实体和关系识别，避免管线式方法的错误传播
    • 

  • 远程监督利用已有知识库自动标注训练数据，多实例学习和去噪方法缓解标签噪声
    • 

  • 文档级关系抽取需要跨句推理能力，是当前的研究前沿
    •
