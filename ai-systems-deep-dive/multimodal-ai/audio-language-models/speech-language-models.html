语音语言模型

核心概念

语音语言模型（Speech Language Models）是将语音理解与大型语言模型的推理能力深度融合的前沿技术。传统的语音处理系统采用级联架构——先将语音转录为文本，再由语言模型处理文本。而语音语言模型追求端到端的整合，使模型能够直接从语音信号中理解语义、情感、说话人身份等丰富信息，并以语音或文本形式做出响应。

这一方向的兴起源于一个关键洞察：文本转录是有损压缩——语音中的韵律、情感、停顿、语速等副语言信息在转录过程中被丢弃。直接处理语音信号可以保留这些信息，实现更自然、更丰富的人机交互。

Whisper 与端到端语音理解
Whisper 是 OpenAI 开发的通用语音识别模型，在 68 万小时的多语言弱标注数据上训练，覆盖了 99 种语言的语音识别和翻译任务。Whisper 不仅是一个语音识别模型，更是一个多任务语音理解系统。


Whisper 采用标准的编码器-解码器 Transformer 架构。编码器接收 30 秒的对数梅尔频谱图（80 维），通过两层卷积下采样后送入 Transformer 编码器。解码器以自回归方式生成文本，使用特殊的 Token 序列控制任务类型（转录/翻译）、语言和时间戳。


import whisper

model = whisper.load_model("large-v3")

result = model.transcribe("audio.wav", language="zh")
print(result["text"])

result_en = model.transcribe("audio.wav", task="translate")
print(result_en["text"])
Whisper 的编码器输出可以被提取为语音表示，送入大语言模型进行更复杂的理解任务。这种"Whisper 编码器 + LLM"的组合已成为语音语言模型的标准架构之一。


Whisper 的成功关键在于训练数据的规模和多样性。68 万小时的数据覆盖了各种口音、语速、噪声环境和录音质量，使得 Whisper 在真实场景中的鲁棒性远超专门针对干净数据训练的模型。


语音 Token 化与离散语音模型
语音 Token 化（Speech Tokenization）是将连续语音信号转化为离散 Token 序列的技术，这使得语音可以像文本一样被自回归语言模型处理。


语义 Token 捕获语音的语言内容。HuBERT 或 Wav2Vec 2.0 的中间层表示经过 K-Means 聚类后得到离散的语义 Token，这些 Token 主要编码了"说了什么"（音素和词汇信息），去除了说话人音色和韵律等信息。


声学 Token 捕获语音的声学细节。EnCodec（Meta）和 SoundStream（Google）等神经音频编解码器使用残差向量量化（RVQ，Residual Vector Quantization）将音频压缩为多层离散 Token。第一层 Token 包含最粗粒度的信息，后续层逐步添加细节。


GSLM（Generative Spoken Language Model）是最早的纯语音语言模型之一。它先用 HuBERT 将语音转化为离散 Token，然后用 Transformer 语言模型在这些 Token 上训练。GSLM 能够直接生成语音 Token 序列，实现无需文本中介的语音到语音生成。


SpiRit-LM（Speech-Text Interleaved Language Model）将语音 Token 和文本 Token 交错训练，使模型同时理解文字和语音。它引入了表达性语音 Token（pitch Token、style Token），使生成的语音具有自然的韵律和情感变化。

语音对话系统架构
语音对话系统是语音语言模型最直接的应用形态。从 Siri 时代的意图识别框架到 GPT-4o 的自然语音交互，语音对话系统经历了深刻的架构变革。


GPT-4o 代表了语音对话的最高水平。它采用原生多模态架构，能够直接接收和生成语音，延迟低至 232 毫秒（接近人类对话的反应速度）。GPT-4o 可以理解语音中的情感、讽刺、犹豫等细微线索，并以恰当的语调和节奏做出回应。


开源社区的语音对话方案通常采用模块化架构。VITA 和 Mini-Omni 等项目将语音编码器（Whisper）、大语言模型（LLaMA/Qwen）和语音合成模型（VITS/CosyVoice）串联，通过端到端训练或适配器连接实现语音对话。


流式处理（Streaming）是语音对话的核心工程挑战。用户期望实时响应，但大语言模型的推理速度有限。自推测解码（Speculative Decoding）和分块处理（Chunk-based Processing）等技术被用于降低首字节延迟。Moshi（Kyutai）通过并行生成文本 Token 和音频 Token 实现了全双工语音对话，用户可以在模型说话时打断。


语音理解的前沿方向
语音情感识别（Speech Emotion Recognition，SER）要求模型从语音中判断说话人的情感状态。传统方法提取手工设计的声学特征（基频、能量、语速等），现代方法直接使用预训练语音表示。Emotion2Vec 在 HuBERT 基础上通过自蒸馏学习情感感知的表示，在多个 SER 基准上达到了最优性能。


语音翻译（Speech Translation）直接将一种语言的语音翻译为另一种语言的文本或语音，跳过中间的文本转录步骤。SeamlessM4T（Meta）支持约 100 种语言之间的语音到语音、语音到文本、文本到语音和文本到文本翻译。它使用统一的编码器处理语音和文本输入，通过多任务训练实现了前所未有的多语言覆盖。


语音中的副语言理解是一个新兴方向。除了"说了什么"，语音还携带了"怎么说"的丰富信息：语速变化暗示情感波动，停顿位置反映思考状态，声调变化表达疑问或强调。训练模型理解这些副语言特征，是实现真正自然的人机语音交互的关键。


小结
    

  • 语音语言模型将语音理解与大语言模型深度融合，追求超越文本转录的端到端交互
    • 

  • Whisper 在 68 万小时多语言数据上训练，其编码器已成为语音语言模型的标准组件
    • 

  • 语音 Token 化通过语义 Token 和声学 Token 的分层表示，使语音可被自回归模型处理
    • 

  • GPT-4o 实现了接近人类反应速度的原生语音对话，是当前语音交互的最高水平
    • 

  • 语音情感识别和副语言理解是实现自然人机交互的关键前沿方向
    • 

  • 从级联式到端到端，语音语言模型正在经历架构的根本性变革
