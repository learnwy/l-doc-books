多模态预训练

核心概念

多模态预训练（Multimodal Pre-training）是在大规模多模态数据上训练通用模型的范式，它使模型获得强大的跨模态理解和生成能力，能够迁移到多种下游任务。从 ViLBERT 开创性的双流架构到 CLIP 的对比学习革命，再到 GPT-4V 的统一生成式预训练，多模态预训练范式经历了深刻的演进。

预训练的核心价值在于数据效率和泛化能力。通过在数亿甚至数十亿图文对上学习，模型能够掌握视觉与语言之间的深层语义关联，这些知识可以通过微调或零样本方式迁移到各种具体任务。预训练数据的规模和质量是模型能力的决定性因素。

掩码语言-图像建模
掩码建模是多模态预训练的第一代主流范式，直接借鉴了 BERT 在 NLP 中的成功经验。其核心思想是随机掩码部分输入（文本 Token 或图像区域），让模型根据未被掩码的信息预测被掩码的内容，从而学习跨模态的上下文关联。


ViLBERT 首先提出了双流 Transformer 架构，文本和图像分别由独立的 Transformer 编码，通过交叉注意力层实现信息交换。预训练任务包括：掩码语言建模（MLM）、掩码区域分类（MRC）和图文匹配（ITM）。MLM 要求模型根据图像和未掩码文本恢复被掩码的文本 Token，MRC 要求根据文本恢复被掩码的图像区域类别，ITM 则判断图文对是否匹配。


UNITER 进一步统一了双流架构为单流架构，将文本和图像 Token 直接拼接输入单个 Transformer。它还引入了对齐更精细的训练目标：词-区域对齐（Word-Region Alignment，WRA），通过最优传输（Optimal Transport）算法计算文本 Token 和图像区域之间的最优匹配。


class MaskedMultimodalModel:
    def compute_mlm_loss(self, text_tokens, image_features, masked_positions):
        fused_output = self.encoder(text_tokens, image_features)
        masked_output = fused_output[masked_positions]
        logits = self.mlm_head(masked_output)
        return cross_entropy(logits, original_tokens[masked_positions])

    def compute_itm_loss(self, text_tokens, image_features, labels):
        fused_output = self.encoder(text_tokens, image_features)
        cls_output = fused_output[:, 0, :]
        logits = self.itm_head(cls_output)
        return binary_cross_entropy(logits, labels)
掩码建模范式的局限在于需要精心配对的图文数据，且图像侧通常依赖预提取的目标检测特征（如 Faster R-CNN），这引入了检测器的瓶颈和偏差。后续的 METER 和 ALBEF 通过直接使用 ViT 作为图像编码器消除了这一依赖。


对比预训练革命
CLIP（Contrastive Language-Image Pre-training）标志着多模态预训练的范式转变。它抛弃了复杂的掩码建模目标，采用简洁的图文对比损失，在 4 亿互联网图文对上训练，获得了惊人的零样本迁移能力。


CLIP 的成功有几个关键因素。首先是数据规模和多样性：4 亿图文对覆盖了极其广泛的视觉概念和语言描述，远超传统数据集的数百万量级。其次是训练效率：对比学习只需计算图文嵌入的相似度，不需要复杂的解码器，大 Batch 训练可以充分利用 GPU 并行性。最后是零样本能力：通过将分类标签转化为文本描述（Prompt），CLIP 可以直接在未见过的数据集上进行分类，无需任何微调。


ALIGN 将 CLIP 的理念推向更大规模，使用 18 亿未清洗的图文对进行训练。它证明了在足够大的数据规模下，即使数据质量较低（包含大量噪声配对），对比学习仍然能够学到高质量的跨模态表示。


SigLIP 对 CLIP 的损失函数进行了改进。CLIP 使用 Softmax 归一化的交叉熵损失，要求每个图像在整个 Batch 中只与一个文本匹配。SigLIP 改用 Sigmoid 损失，将每对图文的匹配视为独立的二分类问题。这种改变不仅简化了实现，还在大 Batch 下取得了更好的性能。

生成式多模态预训练
生成式预训练将多模态理解和生成统一到自回归框架中，是当前最前沿的预训练范式。其核心思想是将所有模态的数据转化为 Token 序列，通过预测下一个 Token 的方式进行训练。


Flamingo 开创了视觉条件语言生成的预训练范式。它在冻结的视觉编码器和语言模型之间插入可学习的 Perceiver Resampler 和门控交叉注意力层，通过在交错的图文序列上训练，获得了强大的少样本多模态学习能力。Flamingo 的设计哲学是"最小化修改，最大化复用"——冻结预训练好的视觉和语言基座，只训练连接两者的桥梁模块。


PaLI（Pathways Language and Image model）采用了更激进的统一方案，将视觉编码器和语言模型端到端联合训练。它使用 ViT-e（4B 参数）作为视觉编码器，PaLM 作为语言模型，在 100 多种语言的图文数据上训练，在 VQA、图像描述等任务上实现了全面领先。


CM3Leon 和 Chameleon 探索了真正的离散 Token 统一预训练。它们将图像通过 VQ-VAE 离散化为 Token，与文本 Token 混合后用统一的自回归模型训练。这种方法使得模型既能理解图像又能生成图像，实现了真正的多模态统一。


预训练数据工程
数据质量和规模是多模态预训练成功的关键，数据工程已经成为独立的研究方向。


网络爬取数据（如 LAION-5B、CommonCrawl）提供了海量图文对，但噪声极高。典型的噪声包括：Alt 文本与图像内容不相关、图像质量低劣、文本过短或过长、重复数据等。数据清洗管线通常包括 NSFW 过滤、图像分辨率过滤、CLIP 分数过滤（保留相似度高于阈值的图文对）和文本质量过滤。


DataComp 项目系统研究了数据选择策略对 CLIP 训练的影响。实验表明，在固定计算预算下，精心选择 30% 的高质量数据训练的模型，性能可以超过使用全部数据训练的模型。CLIP 分数过滤 + 图像聚类去重是效果最好的通用数据选择策略。


合成数据在多模态预训练中扮演越来越重要的角色。LLaVA 使用 GPT-4 生成高质量的图像对话数据用于视觉指令微调；ShareGPT4V 使用 GPT-4V 生成比人工标注更详细的图像描述；InternVL 则使用生成模型合成训练数据来增强特定能力。


数据混合比例（Data Mixing）也是重要的工程决策。多模态预训练通常混合多种数据源：图文对、交错图文序列、纯文本、视频文本等。Idefics2 的消融实验表明，交错图文数据对 few-shot 能力至关重要，而高质量图文对对零样本性能更重要。


小结
    

  • 多模态预训练经历了从掩码建模到对比学习再到生成式预训练的范式演进
    • 

  • 掩码建模借鉴 BERT 的成功，通过多种掩码重建任务学习跨模态关联，但依赖精标数据
    • 

  • CLIP 的对比预训练革命证明了大规模弱配对数据 + 简洁目标函数的巨大潜力
    • 

  • 生成式预训练将理解和生成统一到自回归框架，Flamingo 和 PaLI 代表了不同的架构选择
    • 

  • 数据工程是预训练成功的关键，数据质量、规模、混合比例和选择策略都需要精心设计
    • 

  • 预训练范式仍在快速演进，离散 Token 统一和更大规模的多模态训练是明确的发展方向
    •
