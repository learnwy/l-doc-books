Part III · 生成式与多模态 (Generative & Multimodal)多模态 AI 简介多模态基础 简介融合策略

融合策略

核心概念

多模态融合（Multimodal Fusion）是将来自不同模态的信息整合为统一表示的过程，是多模态系统从"多路输入"到"联合决策"的关键环节。融合策略的选择直接影响模型对跨模态交互的建模能力、计算效率和下游任务表现。

融合的核心挑战在于：不同模态的信息可能是互补的（文本描述物体名称、图像展示外观）、冗余的（文本和语音传达相同语义）或冲突的（音频情感与面部表情不一致）。好的融合策略需要自适应地处理这三种关系，提取跨模态的协同信息，同时抑制噪声和冲突。

早期融合：输入级联合编码
早期融合（Early Fusion）在模型最早期的阶段就将不同模态的信息合并。最简单的形式是将不同模态的特征向量拼接（Concatenation）后送入共享编码器。在 Transformer 架构下，早期融合通常将不同模态的 Token 序列直接拼接为一个长序列，让自注意力机制在所有模态的 Token 之间自由交互。


VisualBERT 是早期融合的经典范例。它将图像区域特征视为"视觉 Token"，与文本 Token 拼接后送入 BERT 编码器。这种方式使得视觉和文本信息从第一层就开始深度交互，模型可以学习到丰富的跨模态关联。


import torch
import torch.nn as nn

class EarlyFusion(nn.Module):
    def __init__(self, text_dim, image_dim, hidden_dim, num_layers):
        super().__init__()
        self.text_proj = nn.Linear(text_dim, hidden_dim)
        self.image_proj = nn.Linear(image_dim, hidden_dim)
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=hidden_dim, nhead=8, batch_first=True
        )
        self.encoder = nn.TransformerEncoder(encoder_layer, num_layers)

    def forward(self, text_features, image_features):
        text_emb = self.text_proj(text_features)
        image_emb = self.image_proj(image_features)
        fused = torch.cat([text_emb, image_emb], dim=1)
        return self.encoder(fused)
早期融合的优势在于模型能够学习到最深层的跨模态交互，因为所有层都可以建模模态间关系。但其缺陷同样明显：序列长度的增加导致自注意力的二次方计算复杂度急剧上升；不同模态的 Token 数量不平衡可能导致注意力偏向数量较多的模态；预训练的单模态模型难以直接复用。


Uniter 和 OSCAR 等模型在早期融合的基础上引入了更精细的设计。OSCAR 利用检测到的物体标签（Anchor Points）作为图像和文本之间的语义桥梁，通过三元组（文本 + 标签 + 图像区域）的拼接输入来增强对齐质量。


晚期融合：决策级聚合
晚期融合（Late Fusion）让每种模态先独立编码，得到各自的全局表示，然后在决策层进行融合。最简单的晚期融合是将各模态的表示向量通过加权求和、乘积或拼接后接全连接层来做最终预测。


CLIP 的零样本分类就是晚期融合的典型应用：图像编码器和文本编码器分别提取特征，通过余弦相似度计算完成图文匹配。这种方式的优势在于各模态编码器可以独立预训练和复用，编码器推理时可以缓存单模态特征，极大降低在线计算成本。


晚期融合在模态不完整（Modal Missing）场景中也具有天然优势。当某个模态缺失时，只需跳过该模态的编码器，用零向量或学习到的默认向量替代，不影响其他模态的处理。


然而，晚期融合的根本局限在于各模态在整个编码过程中没有交互，模型无法学习到深层的跨模态关联。例如，"那个穿红色衣服的人"需要文本中的"红色"与图像中的红色区域建立精确关联，这在晚期融合架构中很难实现。

交叉注意力融合
交叉注意力（Cross-Attention）融合是当前最主流的中间融合方法，它允许一种模态的表示通过注意力机制"查询"另一种模态的信息，实现灵活的跨模态信息交换。


在标准的交叉注意力中，一种模态提供 Query，另一种模态提供 Key 和 Value。例如，在视觉问答中，文本问题的每个 Token 作为 Query，图像的 Patch 特征作为 Key 和 Value，注意力权重揭示了问题的哪些部分关注图像的哪些区域。


Flamingo 是交叉注意力融合的杰出代表。它在冻结的语言模型层之间插入交叉注意力层（Gated Cross-Attention），使得语言模型在生成每个 Token 时都能参考视觉信息。门控机制（Gating）通过可学习的标量缩放交叉注意力的输出，初始化为零以保持预训练语言模型的原始行为，随着训练逐渐学习何时以及如何利用视觉信息。


class GatedCrossAttention(nn.Module):
    def __init__(self, dim, num_heads):
        super().__init__()
        self.cross_attn = nn.MultiheadAttention(dim, num_heads, batch_first=True)
        self.gate = nn.Parameter(torch.zeros(1))
        self.norm = nn.LayerNorm(dim)

    def forward(self, text_hidden, visual_features):
        normed = self.norm(text_hidden)
        attn_output, _ = self.cross_attn(
            query=normed, key=visual_features, value=visual_features
        )
        return text_hidden + torch.tanh(self.gate) * attn_output
Q-Former（Querying Transformer）是 BLIP-2 提出的创新融合模块。它使用一组可学习的 Query Token 通过交叉注意力从冻结的图像编码器中提取视觉信息，再将提取到的固定数量的视觉 Token 送入冻结的语言模型。Q-Former 巧妙地解决了视觉特征维度与语言模型输入维度不匹配的问题，同时大幅减少了送入语言模型的视觉 Token 数量。


自适应与动态融合
自适应融合方法根据输入内容动态调整融合策略和融合权重，克服了静态融合方法"一刀切"的局限。


Mixture of Experts（MoE）融合为不同的模态组合配置不同的专家网络。路由器根据当前输入自动选择激活哪些专家，使得模型可以为不同类型的跨模态交互使用不同的处理路径。这种设计在处理高度异构的多模态数据时表现出色。


动态权重融合通过注意力机制或门控网络动态计算各模态的融合权重。当视觉信息更重要时（如描述场景），模型增加图像模态的权重；当需要精确推理时（如数学问题），模型侧重文本模态。这种自适应能力在模态质量不均匀的实际应用中尤为重要。


模态缺失鲁棒性（Modal-Missing Robustness）是自适应融合的重要研究方向。真实应用中，某些模态可能因设备故障、数据缺失等原因不可用。Prompt 缺失策略通过为每种模态缺失情况学习特定的 Prompt，引导模型在不完整输入下仍能做出合理预测。


小结
    

  • 多模态融合的目标是将异构模态信息整合为统一表示，需要处理互补、冗余和冲突三种跨模态关系
    • 

  • 早期融合通过 Token 拼接实现深层交互，但计算成本高且难以复用预训练模型
    • 

  • 晚期融合保持模态独立编码，高效可复用但无法建模深层跨模态关联
    • 

  • 交叉注意力融合是当前主流方案，Flamingo 的门控机制和 BLIP-2 的 Q-Former 是代表性设计
    • 

  • 自适应融合通过 MoE、动态权重等机制实现输入感知的融合策略，提升鲁棒性
    • 

  • 融合策略的选择需要在交互深度、计算效率和模态独立性之间寻找平衡
    •
