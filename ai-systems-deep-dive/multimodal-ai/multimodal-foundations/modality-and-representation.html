模态与表示学习

核心概念

多模态 AI 的基石在于理解"模态"的本质以及如何将不同模态的信息转化为机器可处理的数学表示。模态（Modality）指信息传递的通道或形式，人类通过视觉、听觉、触觉、嗅觉等多种感官通道感知世界，而在 AI 领域中，最常见的模态包括文本、图像、音频和视频。每种模态都有其独特的数据结构和信息特征，如何将这些异构数据统一为高质量的向量表示，是所有多模态任务的起点。

表示学习（Representation Learning）的目标是从原始数据中自动提取有意义的特征向量，使得语义相近的内容在向量空间中距离相近。从早期的手工特征到深度神经网络的端到端学习，表示学习经历了革命性的演进。

文本表示：从词袋到上下文嵌入
文本是最早被深度学习革新的模态。早期的词袋模型（Bag of Words）将文本视为无序的词频统计，丢失了所有语序信息。Word2Vec 和 GloVe 的出现引入了分布式语义假设——"一个词的含义由其上下文决定"，将每个词映射为固定的稠密向量。


然而，静态词向量无法处理一词多义问题。Transformer 架构的出现彻底改变了文本表示的范式。BERT 通过双向自注意力机制，为每个 Token 生成上下文相关的动态表示；GPT 系列则通过自回归方式构建强大的语言理解与生成能力。


在多模态场景中，文本表示的关键挑战在于如何生成与视觉、听觉语义对齐的向量。CLIP 的文本编码器证明，通过对比学习训练的文本表示能够自然地与图像表示在同一空间中对齐。


import torch
from transformers import AutoTokenizer, AutoModel

tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")
model = AutoModel.from_pretrained("bert-base-uncased")

text = "A cat sitting on a mat"
inputs = tokenizer(text, return_tensors="pt")
outputs = model(**inputs)

cls_embedding = outputs.last_hidden_state[:, 0, :]
token_embeddings = outputs.last_hidden_state
文本表示的粒度选择也至关重要：CLS Token 表示适合句子级任务，Token 级表示适合细粒度匹配，而多层特征融合则可以同时捕获浅层语法和深层语义信息。


视觉表示：从卷积特征到视觉 Transformer
图像表示学习经历了从手工特征（SIFT、HOG）到卷积神经网络（CNN）再到视觉 Transformer（ViT）的三代演进。


CNN 时代的里程碑是 ResNet，它通过残差连接解决了深层网络的梯度消失问题，使得网络可以达到数百层深度。CNN 的层次化特征提取——从边缘、纹理到物体部件、整体语义——天然适合视觉任务。在多模态场景中，CNN 的最后一个卷积层输出常被用作区域特征（Region Features），为视觉问答等任务提供空间细粒度信息。


ViT 的出现将 Transformer 架构引入视觉领域。它将图像分割为固定大小的 Patch（通常 16×16 像素），将每个 Patch 线性投影为嵌入向量，再加上位置编码，作为 Transformer 的输入序列。这种设计使得视觉和文本共享相同的架构基础，极大地简化了多模态模型的设计。


DINOv2 和 MAE 等自监督视觉模型进一步推动了视觉表示的进步。DINOv2 通过自蒸馏学习到语义丰富的视觉特征，无需任何标注数据即可在多种下游任务中表现优异。MAE 则借鉴了 BERT 的掩码预训练思想，通过重建被掩码的图像 Patch 学习视觉表示，训练效率极高。


音频与视频表示：时序信息的编码
音频信号的数字化表示通常有两种形式：时域波形和频域频谱图。时域波形直接记录声压随时间的变化，采样率通常为 16kHz（语音）或 44.1kHz（音乐）。频谱图通过短时傅里叶变换（STFT）将时域信号转换为时频二维表示，其中梅尔频谱图（Mel Spectrogram）按照人耳感知特性对频率轴进行非线性变换，是最常用的音频特征。


自监督音频表示模型如 Wav2Vec 2.0 和 HuBERT 直接在原始波形上操作。Wav2Vec 2.0 通过对比学习在潜在空间中区分真实帧与干扰帧，HuBERT 则通过预测离散化的声学单元来学习表示。这些模型学到的表示在语音识别、说话人识别等任务中大幅超越传统特征。


视频是最复杂的常见模态，它本质上是图像帧的时序序列，通常还伴随音频轨道。视频表示需要同时建模空间信息（单帧内容）和时序信息（帧间运动）。

TimeSformer 提出了分离时空注意力（Divided Space-Time Attention），在每个 Transformer 层中先进行空间注意力再进行时间注意力，显著降低了计算复杂度。VideoMAE 则将掩码自编码扩展到视频域，通过极高的掩码率（90%）迫使模型学习时空语义。


统一表示空间的构建
多模态 AI 的核心目标之一是构建统一的表示空间——让不同模态的数据映射到同一个向量空间中，使得语义相关的多模态内容距离相近。实现这一目标有几种主流路径。


投影对齐（Projection Alignment）是最直接的方法。各模态先由各自的编码器提取特征，再通过线性投影层或轻量级 MLP 将特征映射到共享空间。CLIP 就采用了这种方法，分别用文本 Transformer 和视觉 Transformer 编码后，通过投影头映射到 512 维的共享空间。


共享编码器（Shared Encoder）则更为激进，让不同模态共享同一个 Transformer 编码器。这种方法的代表是 Perceiver 和 Perceiver IO，它们通过交叉注意力机制处理任意模态的输入，将其压缩为固定大小的潜在数组，从而实现真正的模态无关架构。


Token 化统一（Tokenization Unification）是最新的趋势。通过为每种模态设计特定的 Tokenizer（如图像的 VQ-VAE、音频的 SoundStream），将所有模态数据转化为离散 Token 序列，然后用统一的自回归模型处理。这种方法被 Gemini 等最新模型广泛采用。


选择哪种统一方法取决于具体场景：投影对齐简单高效，适合检索和零样本分类；共享编码器参数效率高，适合资源受限场景；Token 化统一最灵活，适合同时需要理解和生成的系统。


小结
    

  • 模态是信息传递的通道，文本、图像、音频、视频各有独特的数据结构与编码方式
    • 

  • 文本表示从静态词向量演进到上下文相关的 Transformer 嵌入，CLS Token 和 Token 级表示服务于不同粒度的任务
    • 

  • 视觉表示从 CNN 的层次化特征提取演进到 ViT 的 Patch Embedding，使视觉与文本共享架构基础
    • 

  • 音频表示以梅尔频谱图和自监督模型为核心，视频表示需要同时建模空间与时序信息
    • 

  • 统一表示空间的构建方法包括投影对齐、共享编码器和 Token 化统一，各有适用场景
    • 

  • 高质量的单模态表示是跨模态对齐和融合的前提，表示质量直接决定多模态系统的上限
    •
