Part III · 生成式与多模态 (Generative & Multimodal)多模态 AI 简介视觉语言模型 简介图像描述生成

图像描述生成

核心概念

图像描述生成（Image Captioning）是让机器"看图说话"的任务——给定一张图像，模型需要自动生成一段准确、流畅且信息丰富的自然语言描述。这是多模态 AI 中最经典的视觉-语言生成任务，它不仅要求模型识别图像中的物体和场景，还需要理解物体之间的关系、动作和属性，并将这些视觉信息组织为符合语法的自然语言。

图像描述生成的技术演进反映了整个多模态 AI 领域的发展轨迹：从基于检索和模板的早期方法，到编码器-解码器的神经网络架构，再到注意力机制的引入，直至当前基于大型预训练模型的生成范式。每一次技术跃升都带来了描述质量的显著提升。

编码器-解码器架构演进
Show and Tell（2015）是第一个成功的端到端神经图像描述模型。它使用 CNN（如 Inception）提取图像的全局特征向量，作为 LSTM 语言解码器的初始隐状态，然后逐词生成描述。这种"看一眼就写"的方式虽然简单，但首次证明了神经网络可以学习从视觉到语言的映射。


Show, Attend and Tell（2015）引入了视觉注意力机制，使解码器在生成每个词时能够关注图像的不同区域。软注意力（Soft Attention）对所有区域的特征加权求和，权重由当前解码器状态和区域特征的关联度决定；硬注意力（Hard Attention）则选择一个最相关的区域，但需要通过 REINFORCE 算法优化。注意力机制不仅提升了描述质量，还提供了直观的可解释性——可以可视化模型在生成每个词时"看"的图像区域。


class AttentionCaptioner(nn.Module):
    def __init__(self, encoder_dim, decoder_dim, attention_dim, vocab_size):
        super().__init__()
        self.attention = nn.Sequential(
            nn.Linear(encoder_dim + decoder_dim, attention_dim),
            nn.ReLU(),
            nn.Linear(attention_dim, 1)
        )
        self.lstm = nn.LSTMCell(encoder_dim + embedding_dim, decoder_dim)
        self.fc = nn.Linear(decoder_dim, vocab_size)

    def forward_step(self, encoder_features, prev_hidden, prev_word_emb):
        attn_input = torch.cat([
            encoder_features,
            prev_hidden.unsqueeze(1).expand_as(encoder_features)
        ], dim=-1)
        attn_weights = torch.softmax(self.attention(attn_input).squeeze(-1), dim=1)
        context = (attn_weights.unsqueeze(-1) * encoder_features).sum(dim=1)
        lstm_input = torch.cat([context, prev_word_emb], dim=-1)
        hidden, cell = self.lstm(lstm_input, (prev_hidden, prev_cell))
        output = self.fc(hidden)
        return output, hidden, cell, attn_weights
Transformer 架构的引入进一步提升了图像描述的质量。OSCAR 使用物体标签作为锚点桥接图像和文本，VinVL 通过更强大的目标检测器提取更丰富的视觉特征。这些工作将区域特征的质量推向新高，在 COCO 等标准基准上持续刷新记录。


预训练描述生成模型
BLIP（Bootstrapping Language-Image Pre-training）引入了创新的 CapFilt（Captioning and Filtering）机制。它先用噪声网络数据预训练图像描述生成器和过滤器，然后用描述生成器为大量未标注图像生成描述，再用过滤器剔除低质量的生成描述和原始噪声描述，循环往复提升数据质量和模型性能。


CoCa（Contrastive Captioner）将对比学习和描述生成统一在一个模型中。它的解码器同时训练两个目标：前半部分通过对比损失学习全局对齐，后半部分通过自回归损失学习序列生成。这种设计使 CoCa 同时具备强大的检索和生成能力。


GIT（Generative Image-to-text Transformer）追求架构的极致简洁——只用一个视觉编码器和一个语言解码器，不需要任何额外的融合模块或预训练目标。GIT 证明了在足够大的数据和模型规模下，简单的架构就能实现优异的性能。


描述质量评估指标
图像描述生成的评估是一个长期挑战。人类判断的描述质量涉及准确性、流畅性、信息量和多样性等多个维度，但自动化指标难以完全覆盖这些方面。


传统指标基于 n-gram 匹配。BLEU 计算生成描述与参考描述之间的 n-gram 精确率；METEOR 同时考虑精确率和召回率，并引入同义词匹配；ROUGE-L 基于最长公共子序列衡量相似度；CIDEr 使用 TF-IDF 加权的余弦相似度，专门为图像描述设计，是最常用的标准指标。

CLIPScore 和 RefCLIPScore 代表了基于预训练模型的新一代评估方法。CLIPScore 直接计算生成描述与图像的 CLIP 相似度，不需要参考描述；RefCLIPScore 结合了 CLIPScore 和参考描述的相似度。研究表明 CLIPScore 与人类判断的相关性甚至超过传统指标。


密集描述与细粒度生成
标准的图像描述通常生成一句话的简短描述，但许多应用场景需要更详细、更结构化的描述。


密集描述（Dense Captioning）为图像中的每个显著区域生成独立的描述。DenseCap 同时进行区域检测和描述生成，输出一组带有边界框的区域描述。这种任务与视觉定位形成互补——一个是"看图说话"，另一个是"听话找图"。


分段描述（Paragraph Captioning）生成多句话的详细段落描述，覆盖图像的整体场景、主要物体、空间关系和氛围。这对于辅助视障人士理解图像、自动生成 Alt 文本等应用至关重要。


多模态大模型时代的描述生成质量已经达到前所未有的水平。GPT-4V 和 Gemini 能够生成极为详细和准确的图像描述，包括对文字、品牌、情感氛围和文化背景的识别。ShareGPT4V 项目利用 GPT-4V 为大量图像生成详细描述，用于训练更小的开源模型。


小结
    

  • 图像描述生成是经典的视觉-语言生成任务，经历了五代技术演进
    • 

  • 注意力机制的引入使模型能够动态关注图像区域，是描述质量提升的关键
    • 

  • BLIP 的 CapFilt 机制和 CoCa 的双目标训练代表了预训练时代的方法创新
    • 

  • 评估指标从 n-gram 匹配发展到基于预训练模型的 CLIPScore，与人类判断的相关性不断提升
    • 

  • 密集描述和段落描述扩展了任务的应用范围，多模态大模型将描述质量推向新高度
    • 

  • 图像描述生成仍面临幻觉、偏见和多样性不足等挑战，需要在准确性和创造性之间寻找平衡
