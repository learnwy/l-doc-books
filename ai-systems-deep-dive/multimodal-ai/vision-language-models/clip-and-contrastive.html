CLIP 与对比学习

核心概念

CLIP（Contrastive Language-Image Pre-training）是 OpenAI 于 2021 年发布的里程碑式多模态模型，它通过在 4 亿互联网图文对上进行对比学习训练，实现了图像与自然语言之间的高质量语义对齐。CLIP 不仅在零样本图像分类上媲美监督学习模型，更重要的是它开创了一种全新的视觉模型训练范式——用自然语言作为监督信号，将视觉理解从固定标签分类拓展为开放世界的语义理解。

CLIP 的影响远超模型本身，它催生了整个多模态模型生态：Stable Diffusion 用 CLIP 文本编码器做条件生成，LLaVA 用 CLIP 视觉编码器做多模态大模型，DALL-E 用 CLIP 做图文评分。可以说，CLIP 是现代多模态 AI 的基石。

CLIP 双塔架构详解
CLIP 采用经典的双塔（Dual Encoder）架构：图像编码器和文本编码器分别将输入映射为固定维度的嵌入向量，通过投影层对齐到共享的嵌入空间中。


图像编码器有两种选择：ResNet 系列（RN50、RN101、RN50x4 等）和 ViT 系列（ViT-B/32、ViT-B/16、ViT-L/14 等）。实验表明 ViT-L/14 在计算效率和性能之间取得了最佳平衡。ViT 将图像分割为 Patch，通过线性投影加位置编码后送入 Transformer 编码器，CLS Token 的输出经过投影层映射为最终的图像嵌入。


文本编码器是一个标准的 Transformer，使用 BPE（Byte Pair Encoding）分词，最大序列长度 77 个 Token。文本的 [EOS] Token 经过投影层映射为文本嵌入。CLIP 的文本编码器虽然参数量不大，但通过对比学习获得了与大型语言模型相当的语义理解能力。


import torch
import torch.nn as nn

class CLIPModel(nn.Module):
    def __init__(self, image_encoder, text_encoder, embed_dim):
        super().__init__()
        self.image_encoder = image_encoder
        self.text_encoder = text_encoder
        self.image_projection = nn.Linear(image_encoder.output_dim, embed_dim)
        self.text_projection = nn.Linear(text_encoder.output_dim, embed_dim)
        self.logit_scale = nn.Parameter(torch.ones([]) * torch.log(torch.tensor(1 / 0.07)))

    def forward(self, images, texts):
        image_features = self.image_projection(self.image_encoder(images))
        text_features = self.text_projection(self.text_encoder(texts))
        image_features = image_features / image_features.norm(dim=-1, keepdim=True)
        text_features = text_features / text_features.norm(dim=-1, keepdim=True)
        logit_scale = self.logit_scale.exp()
        logits_per_image = logit_scale * image_features @ text_features.t()
        return logits_per_image, logits_per_image.t()
训练时，CLIP 使用对称的 InfoNCE 损失。在一个包含 N 个图文对的 Batch 中，产生 N 个正对和 N²-N 个负对。CLIP 使用了高达 32768 的 Batch 大小，在 256 块 V100 GPU 上训练了 12 天（约 400M 图文对的 32 个 Epoch）。大 Batch 是 CLIP 成功的关键——更多的负例意味着更强的对比信号。


零样本分类与 Prompt 工程
CLIP 最引人注目的能力是零样本分类：无需在目标数据集上做任何训练或微调，即可对新图像进行分类。实现方式极为简洁——将每个类别名称包装成自然语言描述（Prompt Template），计算图像与所有类别描述的相似度，选择最高相似度对应的类别。


def zero_shot_classify(image, class_names, clip_model, tokenizer):
    prompts = [f"a photo of a {name}" for name in class_names]
    text_inputs = tokenizer(prompts)

    image_features = clip_model.encode_image(image)
    text_features = clip_model.encode_text(text_inputs)

    image_features /= image_features.norm(dim=-1, keepdim=True)
    text_features /= text_features.norm(dim=-1, keepdim=True)

    similarity = (100.0 * image_features @ text_features.T).softmax(dim=-1)
    return similarity.argmax(dim=-1)
Prompt 模板的选择对零样本分类性能影响巨大。CLIP 论文实验表明，简单的"a photo of a {class}"模板比直接使用类别名称提升了 1-5 个百分点。更复杂的集成策略使用多个模板（如"a photo of a big {class}"、"a photo of a small {class}"、"a satellite photo of {class}"等），对多个模板的文本嵌入取平均后再做分类，可以进一步提升 3-5 个百分点。


在 ImageNet 零样本分类中，CLIP ViT-L/14 达到了 76.2% 的 Top-1 准确率，接近 ResNet-50 的有监督训练性能。在某些分布偏移的数据集上（如 ImageNet-Sketch、ImageNet-R），CLIP 的鲁棒性甚至超过了专门微调的模型。


后 CLIP 时代的对比学习演进
CLIP 之后，一系列工作在数据、架构和训练策略上进行了优化。


OpenCLIP 是 CLIP 的开源复现项目，证明了在 LAION-2B 等公开数据集上训练的模型可以达到甚至超过原始 CLIP 的性能。OpenCLIP 提供了丰富的模型变体（从 ViT-B/32 到 ViT-bigG/14），成为多模态研究的标准基础设施。


EVA-CLIP 通过改进视觉编码器的预训练来提升 CLIP 性能。它先用 EVA 方法对 ViT 进行自监督预训练，再进行 CLIP 对比训练。这种两阶段策略使得视觉编码器拥有更好的初始化，最终在多项评测中超越了同等规模的原始 CLIP。


SigLIP 的核心创新是将 Softmax 对比损失替换为 Sigmoid 损失。Softmax 损失假设每个图像在 Batch 中只与一个文本匹配，但实际数据中经常存在一图多描述的情况。Sigmoid 损失将每个图文对独立评估，更符合实际数据分布，且在实现上更简单（不需要跨 GPU 的 all-gather 操作）。

CLIP 在下游生态中的角色
CLIP 的影响力不仅限于检索和分类，它已成为整个多模态 AI 生态的基础组件。


在文本到图像生成中，Stable Diffusion 使用 CLIP 文本编码器将文本 Prompt 编码为条件向量，通过交叉注意力注入到 U-Net 去噪过程中。DALL-E 2 则同时使用 CLIP 图像编码器和文本编码器，通过 Prior 模型将文本嵌入映射为图像嵌入，再由解码器生成图像。


在多模态大模型中，LLaVA 系列使用 CLIP ViT 作为视觉编码器，通过简单的线性投影层将视觉特征送入大语言模型。InternVL 则在 CLIP 基础上进一步扩大视觉编码器规模至 6B 参数，获得了更强的视觉理解能力。


CLIP 还被广泛用于评估指标。CLIPScore 计算生成图像与文本描述的 CLIP 相似度，已成为图像生成质量评估的标准指标。FID + CLIPScore 的组合提供了图像质量和语义一致性的双重度量。


小结
    

  • CLIP 通过在 4 亿图文对上进行对比学习训练，开创了用自然语言监督视觉模型的范式
    • 

  • 双塔架构将图像和文本分别编码后投影到共享空间，对称 InfoNCE 损失驱动对齐
    • 

  • 零样本分类通过 Prompt Template 实现，多模板集成可以显著提升性能
    • 

  • 后 CLIP 时代的改进包括 SigLIP 的 Sigmoid 损失、EVA-CLIP 的视觉编码器优化和更大规模训练
    • 

  • CLIP 已成为多模态 AI 生态的基础组件，广泛应用于生成、理解和评估等场景
    • 

  • 从封闭标签分类到开放世界理解，CLIP 代表了视觉 AI 的范式转变
