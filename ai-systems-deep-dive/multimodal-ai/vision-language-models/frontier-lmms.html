旗舰多模态大模型：从 GPT-4V 到 GPT-5 与 Gemini 3

核心概念

旗舰多模态大模型指以 GPT-5、Claude Opus 4.x、Gemini 3 为代表的当代大型多模态模型（Large Multimodal Models，LMMs）。它们不再是针对单一视觉语言任务设计的专用模型，而是具备广泛视觉理解和推理能力的通用智能系统。从 OCR 文字识别到图表理解、从医学影像分析到代码生成、从空间推理到创意写作，这些模型展现了前所未有的多模态认知能力。

理解这一代模型需要建立"三代际"的时间线。第一代（2023 年）以 GPT-4V 为代表——视觉是"嫁接"到语言模型上的外挂能力；第二代（2024 年）以 GPT-4o 和 Gemini 1.5 为代表——原生多模态与实时语音交互成为主线；第三代（2025-2026 年，截至写作时的现状）以 GPT-5、Claude Opus 4.x、Gemini 3 Pro 为代表——统一推理系统与原生多模态深度融合，"以图思考"（thinking with images）成为新的推理范式。

从 GPT-4V 到 GPT-5：三代演进

历史节点：GPT-4V（2023）

GPT-4V（GPT-4 with Vision）于 2023 年 9 月由 OpenAI 上线，是"看图对话"这一交互形态的开创者。其具体架构细节未公开，但从行为特征和技术报告可以推断：它很可能采用了将视觉编码器（可能基于 ViT 的变体）的输出通过投影层映射为语言模型可处理的视觉 Token，然后与文本 Token 一起送入 GPT-4 的 Transformer 解码器——这正是后来 LLaVA 等开源模型沿用的"外挂式"路线。

GPT-4V 展现了多个维度的突破性能力。在空间理解方面，它能准确描述物体的相对位置、大小关系和空间布局。在文字识别方面，它能够识别图像中各种字体、方向和语言的文字，包括手写体。在图表理解方面，它能解读复杂的统计图表、流程图和架构图，提取关键数据点和趋势。

omni 一代：GPT-4o（2024）

GPT-4o（o = omni，2024 年 5 月发布）将视觉、音频和文本统一到单一神经网络中端到端训练，语音响应延迟最低约 232 毫秒、平均约 320 毫秒（OpenAI 官方公布的数据），接近人类对话的自然节奏。同年 10 月推出的 Realtime API 让开发者可以直接构建低延迟语音交互应用。omni 架构的意义在于：多模态不再是"附加能力"，而是与文本同等的原生输入输出通道。

推理一代：o 系列的"以图思考"与 GPT-5（2025-2026）

o1（2024 年 9 月预览）引入了推理时计算（test-time compute）范式——模型在回答前先生成长思维链。真正的突破来自 o3（2025 年 4 月）：它在推理过程中能够主动调用视觉工具，对图像进行缩放、裁剪、旋转等操作后再继续思考，即"thinking with images"。这使精细的视觉定位任务（如在小图中找特定细节）从感知问题变成了可分步验证的推理问题。

GPT-5（2025 年 8 月发布）将 o 系列的推理能力并入统一系统：由路由器根据问题难度自动在快速响应与深度推理之间切换，用户不再手动选择模型。据公开报道，消费端的 o 系列独立型号此后逐步被 GPT-5 系列取代，截至写作时 GPT-5.x 是 ChatGPT 的默认旗舰。对多模态而言，这意味着视觉输入直接进入统一的推理管线，复杂视觉任务的准确率显著提升。

调用这些模型的 API 形状自 GPT-4V 时代以来保持了良好稳定性：

from openai import OpenAI

client = OpenAI()

response = client.chat.completions.create(
    model="gpt-5",  # 同样的消息结构适用于 gpt-4o 及后续视觉模型
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Describe this image in detail."},
                {
                    "type": "image_url",
                    "image_url": {"url": "https://example.com/image.jpg"}
                }
            ]
        }
    ],
    max_tokens=1024
)

Gemini 的代际演进：从 1.0 到 3

Gemini 系列是 Google 推出的原生多模态大模型。与外挂式路线不同，Gemini 从架构设计之初就以多模态为核心目标。

Gemini 1.0（2023 年 12 月）包含三个规模等级：Ultra（最大）、Pro（中等）和 Nano（移动端）。它们共享相同的基础架构但参数规模不同。Gemini 使用改进的 Transformer 解码器架构，能够原生处理文本、图像、音频和视频输入。

Gemini 1.5 Pro（2024 年 2 月公布）的核心突破是超长上下文窗口——高达 100 万 Token（后续扩展到 200 万 Token）。这意味着它可以一次处理长达数小时的视频、数千页的文档或数十张高分辨率图像。这种能力基于 Mixture of Experts（MoE）架构的高效设计，使得模型在参数量不成比例增加的情况下支持超长上下文。

此后 Gemini 加速迭代。Gemini 2.0 Flash（2024 年 12 月）面向 agent 时代设计，实验性地引入原生图像生成与原生音频输出，并与实时多模态助手原型 Project Astra 配套发布；Gemini 2.5 Pro（2025 年 3 月）引入"思考"（thinking）机制，允许模型在作答前分配可控的推理预算。Gemini 3 Pro（2025 年 11 月）是截至写作时 Google 的最强旗舰，提供 Deep Think 高强度推理模式，据公开报道在 MMMU 等多模态推理基准上位居前列。

Gemini 在多模态推理基准 MMMU 上较早超过了人类专家的平均水平（MMMU 论文报告人类专家平均约 88.6%），展示了在科学、数学、人文等跨学科多模态推理中的强大能力。在视频理解方面，Gemini 可以直接处理视频流而不仅仅是抽帧图像，这使得它在时序推理任务上具有天然优势。

Claude Opus 4.x：长上下文与 agentic 视觉

Anthropic 的 Claude 自 3 系列（2024 年 3 月）起支持图像输入，此后沿 Opus/Sonnet 双线迭代。Claude 4 系列（2025 年 5 月起）强化了扩展思考模式下的工具使用能力，Opus 子系列持续更新至 4.x（截至写作时的最新迭代）。Claude 的视觉能力突出体现在文档与代码场景：阅读架构图后直接产出实现代码、分析长 PDF 截图、以及在计算机使用（computer use）模式下依据屏幕截图执行 GUI 操作。它与 GPT-5、Gemini 3 共同构成了 2026 年闭源旗舰的第一梯队。

开源多模态大模型生态

闭源旗舰的成功激发了开源社区的快速跟进，形成了丰富的开源多模态大模型生态。

LLaVA（Large Language and Vision Assistant）系列是开源范式的奠基者。LLaVA-1.5 使用 CLIP ViT-L 作为视觉编码器，通过 MLP 投影层将视觉特征送入 Vicuna/LLaMA 语言模型。它的训练策略极为高效——仅在约 60 万条视觉指令数据上微调就获得了接近当年闭源模型的性能，确立了"视觉编码器 + 投影层 + LLM"的最小可行架构。

InternVL 系列是另一条重要路线。早期版本将视觉编码器扩展到 6B 参数（InternViT-6B），采用动态分辨率策略支持任意分辨率输入。InternVL3（2025 年 4 月）进一步转向原生多模态预训练范式——视觉与文本从预训练阶段就联合学习，而非先训语言基座再补视觉；据公开资料，其后续版本 InternVL3.5 引入级联强化学习（Cascade RL），规格覆盖从 1B 到数百 B 的密集与 MoE 型号。

Qwen-VL 系列来自阿里云通义实验室。Qwen2-VL 引入了 Naive Dynamic Resolution 策略和多模态旋转位置编码（M-RoPE）；Qwen2.5-VL（2025 年初）强化了文档解析与 GUI agent 能力；Qwen3-VL（2025 年下半年发布）据官方发布说明提供最高 235B-A22B 的 MoE 旗舰，设 Instruct 与 Thinking 双变体（后者专为视觉推理优化），上下文原生 256K 可扩展至百万级，OCR 覆盖 32 种语言——截至写作时稳居开源第一梯队。

评测体系与能力边界

大型多模态模型的评测需要全面覆盖多种能力维度。

MMMU（Massive Multi-discipline Multimodal Understanding，论文编号 arXiv:2311.16502）曾是最权威的多学科评测基准，包含 11,500 道涵盖 30 个学科的大学级多模态问题。随着前沿闭源模型相继越过人类专家平均线、开源第一梯队逼近，MMMU 已趋饱和，评测重心转向更难的 MMMU-Pro、MathVista（数学视觉推理）、Humanity's Last Exam 以及 OSWorld/WebArena 等 GUI 与网页操作的 agentic 评测。

幻觉评测是另一个关键维度。POPE 通过构造是/否问题评估模型是否"看到"了不存在的物体；MMHal-Bench 评估模型描述中的事实性错误；CHAIR 量化生成描述中提到但图像中不存在的物体比例。

当前大型多模态模型的能力边界已明显收窄但并未消失。"以图思考"使精确计数和微小细节定位大幅改善，但在密集重复物体计数、复杂空间关系链式推理（如"A 在 B 的左上方，C 在 B 的右下方，A 和 C 谁更靠上？"）和抽象视觉推理（如 Raven's Progressive Matrices）等方面，模型表现仍不稳定。
