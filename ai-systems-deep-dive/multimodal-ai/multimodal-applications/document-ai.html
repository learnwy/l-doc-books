文档智能

核心概念

文档智能（Document AI / Document Intelligence）是多模态 AI 在企业场景中最具实用价值的应用方向之一。它将视觉理解、文字识别和语言推理能力融合，使机器能够像人类一样"阅读"和"理解"各种复杂文档——从扫描的发票和合同到排版精美的学术论文和技术报告。

传统的文档处理依赖 OCR（光学字符识别）将图像中的文字提取为纯文本，再用 NLP 技术处理文本。这种级联方式存在根本性缺陷：它丢弃了文档的视觉版面信息——标题的字体大小、表格的行列结构、图表的空间布局等对理解文档内容至关重要的信息。多模态文档智能模型直接在文档图像上操作，同时利用文字内容和视觉版面进行理解。

LayoutLM 系列：版面感知预训练
LayoutLM（Microsoft）系列开创了多模态文档预训练的范式。其核心思想是：将文字的语义信息和空间位置信息联合编码，使模型同时理解"文字说了什么"和"文字在哪里"。


LayoutLM v1 在 BERT 的基础上增加了二维位置嵌入——除了标准的一维序列位置外，还将每个 Token 的边界框坐标（x1, y1, x2, y2）编码为位置嵌入。这使得模型能够利用空间关系理解文档结构（如表格中同一行的内容通常是相关的）。


LayoutLMv2 进一步引入了视觉信息。它使用 CNN 提取文档图像的视觉特征，与文本 Token 拼接后送入 Transformer。预训练任务包括：掩码视觉-语言建模（MVLM）、文本-图像对齐（TIA）和文本-图像匹配（TIM）。这三个任务分别从文本重建、细粒度对齐和全局匹配三个维度训练模型。


class LayoutLMv2Embedding:
    def __init__(self, config):
        self.word_embedding = nn.Embedding(config.vocab_size, config.hidden_size)
        self.x_position_embedding = nn.Embedding(config.max_2d_position, config.hidden_size)
        self.y_position_embedding = nn.Embedding(config.max_2d_position, config.hidden_size)
        self.h_position_embedding = nn.Embedding(config.max_2d_position, config.hidden_size)
        self.w_position_embedding = nn.Embedding(config.max_2d_position, config.hidden_size)

    def forward(self, input_ids, bbox):
        word_emb = self.word_embedding(input_ids)
        x1, y1, x2, y2 = bbox[:, :, 0], bbox[:, :, 1], bbox[:, :, 2], bbox[:, :, 3]
        spatial_emb = (
            self.x_position_embedding(x1) + self.y_position_embedding(y1)
            + self.x_position_embedding(x2) + self.y_position_embedding(y2)
            + self.h_position_embedding(y2 - y1) + self.w_position_embedding(x2 - x1)
        )
        return word_emb + spatial_emb
LayoutLMv3 统一了文本和图像的预训练目标。它将文档图像也通过 Patch Embedding 离散化为视觉 Token，然后在文本 Token 和视觉 Token 上统一进行掩码建模。这种统一设计消除了 v2 中需要分别处理文本和图像特征的复杂性。


Donut 与无 OCR 文档理解
Donut（Document Understanding Transformer）提出了一种颠覆性的方法——完全不使用 OCR，直接从文档图像端到端地理解文档内容。


Donut 的架构包含视觉编码器（Swin Transformer）和文本解码器（BART 解码器）。视觉编码器将文档图像编码为特征序列，文本解码器以自回归方式生成结构化的输出文本。输出格式使用特殊的 XML 标签来表示键值对和层次结构。


Donut 的核心优势在于：消除了对 OCR 引擎的依赖（OCR 错误会级联影响下游理解），端到端优化避免了信息损失，且模型架构极为简洁。在多个文档理解基准上，Donut 在不使用 OCR 的情况下达到甚至超过了依赖 OCR 的方法。


Nougat（Neural Optical Understanding for Academic Documents）将 Donut 的思路专门应用于学术文档。它能将数学公式、表格和复杂排版的学术 PDF 直接转换为 Markdown 格式，对包含大量数学符号的文档效果尤为突出。


表格识别与结构化提取
表格是文档中最重要也最具挑战性的结构元素。表格识别需要解决三个子问题：表格检测（在文档中定位表格）、表格结构识别（识别行列关系和合并单元格）和表格内容提取（将表格转化为结构化数据）。


表格结构识别的难点在于复杂表格的多样性：跨行合并、跨列合并、多级表头、无线框表格等变化使得规则化方法难以泛化。TableFormer 使用 Transformer 序列生成方式直接预测表格的 HTML 结构标签（<tr>、<td>、colspan/rowspan 属性），将表格结构识别转化为序列生成问题。


GOT（General OCR Theory）是最新的通用 OCR 模型，基于视觉编码器-语言解码器架构，能够处理包括印刷体、手写体、数学公式、乐谱、分子式和表格在内的各种光学字符识别任务。它将所有 OCR 子任务统一到一个模型中，通过不同的 Prompt 切换任务模式。

文档大模型与智能审核
多模态大模型的出现将文档智能提升到了新的高度。GPT-4V、Gemini 和 Qwen-VL 等模型可以直接对文档截图进行问答、摘要和分析，无需任何微调即可处理各种类型的文档。


TextMonkey 专门针对高分辨率文档理解设计。它使用 Shifted Window Attention 高效处理大尺寸文档图像，支持滑动窗口方式处理超长文档。在 DocVQA 和 ChartQA 等基准上，TextMonkey 在文档级和图表级理解任务上均表现优异。


智能审核是文档智能的重要商业应用。在金融领域，AI 系统自动审核贷款申请、发票报销、合同条款，将审核时间从数小时降低到数分钟。在法律领域，合同审核系统自动识别风险条款、缺失条款和不合规内容。在医疗领域，处方审核系统自动核验药物剂量、过敏信息和禁忌症。


文档智能面临的持续挑战包括：长文档理解（数十页的合同或报告）、跨页面推理（表格跨页、引用跨章节）和手写体识别（签名验证、手写批注）。随着多模态大模型上下文窗口的增长，长文档理解正在快速改善。


小结
    

  • 文档智能融合视觉、文字和版面信息来理解复杂文档，超越了传统 OCR + NLP 的级联方式
    • 

  • LayoutLM 系列通过二维位置编码和视觉特征引入了版面感知的预训练范式
    • 

  • Donut 和 Nougat 证明了无 OCR 端到端文档理解的可行性和优越性
    • 

  • 表格识别是文档智能中最具挑战性的子任务，序列生成方式展现了强大的泛化能力
    • 

  • 多模态大模型将文档智能推向新高度，支持零样本的文档理解和分析
    • 

  • 智能审核是文档智能最成熟的商业落地场景，正在金融、法律、医疗等领域创造巨大价值
