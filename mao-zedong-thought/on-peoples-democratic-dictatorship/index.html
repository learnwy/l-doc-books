论人民民主专政 简介

本 hub 的定位

《论人民民主专政》是毛泽东一九四九年六月三十日为纪念中国共产党成立二十八周年而写的建国纲领文献，也是新中国的国体定义首次获得完整理论表述的场合。本 hub 是单篇精读 hub：只围绕这一篇文本，沿"历史现场 → 文本理论 → 制度遗产"三步展开。第一章还原一九四九年六月的军事、政治与理论语境，并梳理文中对二十八年革命经验的总结与阶级分析方法；第二章进入文本核心，解析人民民主专政的概念内涵、"对人民民主、对敌人专政"的双重职能与"一边倒"外交方针；第三章追踪理论落地——从《共同纲领》到一九五四年宪法的国体法条化，以及这一理论在当代国家治理中的转化。读完本 hub，读者应当能独立回答三个问题：这篇文章为什么诞生于一九四九年六月？人民民主专政相对经典无产阶级专政"新"在哪里？一个政治概念如何一步步变成今天宪法第一条？

与兄弟 hub 的分工边界

本 hub 属于 leaders/01_mao-zedong-studies 合集中的单篇精读层。建国理论的阅读最容易犯的范畴错误，是把"革命蓝图"（一九四〇年代前中期）与"国体定论"（一九四九年）混为一谈——这正是本 hub 与兄弟 hub 分工的意义所在：

hub 定位 与本 hub 的边界
本 hub：论人民民主专政 一篇建国纲领文献的三段式精读（语境 → 理论 → 制度） ——
论新民主主义 《新民主主义论》（一九四〇）精读：革命性质与新民主主义国家蓝图 革命胜利前的国家构想；本 hub 是胜利前夕的国体定论，两文构成建国理论的上下篇
论联合政府 《论联合政府》（一九四五）精读：联合政府方案的设计与命运 一九四五方案设想多党联合政府；本 hub 第一章交代它为何被一九四九方案取代
关于正确处理人民内部矛盾的问题 一九五七年讲话精读：两类矛盾学说 本文提出"人民／敌人"界限，该篇是对这一界限最系统的后续理论化
毛泽东选集（四卷） 一五九篇著作的全景综述与导读框架 该 hub 只给本文一个定位条目；逐节吃透原文在本 hub
毛泽东思想核心理论 思想体系的专题化梳理 单篇文本细读在本 hub；思想体系的整体展开在该 hub

一句话边界：想吃透这一篇文本本身 → 本 hub；要看它之前的建国构想 →《新民主主义论》《论联合政府》两个精读 hub；要追它之后的理论深化 →《关于正确处理人民内部矛盾的问题》hub；要全景与体系 → 毛泽东选集与思想核心理论两个 hub。

推荐学习路径

路径一：近现代史入门读者（目标＝读懂这篇经典在说什么）

  1. 从第一章 建国前夕的写作背景 读起，先记住三个背景问题：国家性质、阶级政策、外交方向。
  2. 读 二十八年革命经验总结，抓住"三大法宝"如何被论证为人民民主专政的历史依据。
  3. 进入第二章 人民民主专政的内涵，只需吃透一句话："对人民的民主和对反动派的专政结合起来，就是人民民主专政。"
  4. 最后读第三章 新中国宪政基础，看理论如何变成宪法条文。阶级分析框架 可暂缓，遇到概念困惑再回头补。

路径二：政治制度与宪法关注者（目标＝弄清国体如何入宪）

  1. 直接入第二章 人民民主专政的内涵，重点是它与经典无产阶级专政的异同对照表。
  2. 配合 阶级分析框架，理解国体条款背后"谁是人民"的界定逻辑。
  3. 精读第三章 新中国宪政基础，逐条对照《共同纲领》第一条到一九五四年宪法第一条的变化。
  4. 以 国家治理的当代启示 收尾，观察同一国体在当代治理中的制度演化。第一章可仅作检索用。

路径三：通读毛选的研究者／写作者（目标＝定位本文在建国理论谱系中的坐标）

  1. 先读第一章 建国前夕的写作背景，其中《新民主主义论》→《论联合政府》→ 本文的三篇递进链是论文框架的直接素材。
  2. 对读第二章 对内对外两种职能 与 "一边倒"外交战略，分别对应"建国纲领的对内面与对外面"，适合做双线结构。
  3. 用第三章 国家治理的当代启示 建立长时段视角：从一九四九到当代的理论转化史本身就是一条研究线索。
  4. 需要跨文本比较时，按上文分工边界转入论新民主主义、论联合政府等兄弟 hub，避免在同一 hub 内重复造轮子。

前置知识

  • 中国近代史基本线索（一八四〇—一九四九）：至少能排出鸦片战争、大革命、土地革命战争、抗日战争、解放战争的先后与大致年份。第一章的语境还原和第二章的历史论证都以这条线索为底；完全陌生的读者建议先补一段通史再进入。
  • 马克思主义国家学说的几个基本词：阶级、国家、专政、无产阶级。本 hub 不要求系统读过马克思或列宁的原著——这些概念在各篇中均就地解释，但知道"国家是阶级统治的工具"这一命题有助于快速进入第二章。
  • 不需要的：不必预读《论人民民主专政》原文——各篇导读自带背景交代与关键引文；也不需要宪法学专业基础，第三章涉及的法条均随文摘录并解释。

延伸阅读

以下入口属于同合集的其他 hub，供超出"本篇精读"范围时探索：

  • 论新民主主义——一九四〇年的国家蓝图精读：与本 hub 构成"构想 → 定论"的上下篇。
  • 论联合政府——一九四五年的多党联合方案及其被取代过程，本 hub 第一章方案调整的前史。
  • 关于正确处理人民内部矛盾的问题——"人民／敌人"界限在一九五七年的系统理论化，本文概念最重要的后续发展。
  • 毛泽东选集（四卷）——把本文放回一五九篇著作的全景时间轴与分类矩阵中定位。
  • 毛泽东思想核心理论——跳出单篇文本，查看人民民主专政学说在整个思想体系中的位置。
