《新民主主义论》精读 简介

《新民主主义论》是毛泽东1940年1月在延安发表的系统回答"中国向何处去"的纲领性文献。本 hub 不做泛泛的内容概述，而是围绕这一个文本做三层精读：先回到1940年的历史现场，看这篇文字为何而写、针对谁的方案（第一章）；再逐条拆解它给出的政治、经济、文化三大建国纲领（第二章）；最后把它放回马克思主义发展史与中国革命的实践进程中，评估其理论创新与实际兑现程度（第三章）。读完本 hub，你应当能独立回答三个问题：新民主主义革命"新"在哪里？三大纲领如何构成一个内在统一的社会蓝图？这套理论在此后十余年的实践中兑现了多少、又偏离了多少？

本 hub 与兄弟 hub 的分工边界

毛泽东研究合集按三种粒度组织：单篇精读、思想专题、文献全集。本 hub 属于单篇精读——只读一个文本，但读深读透。它与最常被混淆的几个兄弟 hub 的边界如下：

兄弟 hub 粒度与视角 与本 hub 的关系
毛泽东思想核心理论 思想体系总览：横向铺开哲学、军事、党建等各板块 想快速把握全貌先读它；想吃透其中"新民主主义理论"这一板块，读本 hub
《实践论》精读 / 《矛盾论》精读 哲学方法论专著：提供"具体问题具体分析"等分析工具 本 hub 是这些哲学工具在社会历史分析中的系统运用；工具本身见彼处
《论持久战》精读 军事战略维度：回答"仗怎么打" 本 hub 回答"革命什么性质、建成什么社会"，一军一政，互补而不重叠
论联合政府 1945年的承接之作：把新民主主义纲领细化为战后联合政府方案 先读本 hub 再读它，可见纲领如何从蓝图推进为"施工图"
论人民民主专政 1949年的定型之作：国家形态的最终理论表述 本 hub 的"各革命阶级联合专政"是它的直接理论前身
毛泽东选集（四卷）/ 毛泽东文集 原典全集导读：覆盖全部篇目与版本线索 本 hub 只精读其中一篇，但背景、纲领、影响三层展开远深于全集式导读

判断标准：若你的问题围绕"这个文本本身说了什么、为什么这样说、后来怎样"，读本 hub；若问题超出这一个文本，上表会告诉你该去哪个 hub。本 hub 各篇内容自身完整，不依赖上述任何兄弟 hub 即可读懂。

推荐学习路径

通读路径（按章节顺序，适合初次接触）：

  1. 第一章依次读方向之争、历史特点、革命定位三篇：先建立"为什么需要一个新理论"的问题意识，再理解理论的社会依据与核心命题；
  2. 第二章依次读政治、经济、文化三大纲领：把握蓝图全貌，注意三者共享同一逻辑——政治上联合专政、经济上多种成分并存、文化上兼收并蓄；
  3. 第三章先读理论创新、再读历史实践：完成从"文本说了什么"到"实践兑现了什么"的认知闭环。

分人群入口：

  • 近现代史学习者：走上述通读路径，重点放在第一章——半殖民地半封建的社会性质分析与五四运动的分水岭意义是全 hub 的史实地基。
  • 理论研究者：可直接从第三章"对马克思主义革命理论的创新"入手，抓住"过渡性社会形态"这一核心创见，再回读第一章革命定位篇与第二章纲领篇，考察这一创见如何落实为具体制度设计。
  • 只关心当代关联的读者：先读第三章"历史实践与当代启示"——混合经济与渐进改革的先声是全 hub 与当下对话最直接的部分，再按兴趣回补各纲领细节。

前置知识

  • 基本历史时间线：知道鸦片战争、辛亥革命、五四运动、抗日战争爆发这条线索的先后与大致因果即可；本 hub 第一章会补齐其余背景，不要求预先熟悉1939—1940年的政治细节。
  • 理论概念零门槛："半殖民地半封建""各革命阶级联合专政""节制资本"等术语均在首次出现处给出解释，无需任何马克思主义理论的预先训练。
  • 可选加分项：若读过《实践论》与《矛盾论》，对贯穿全 hub 的"具体问题具体分析"方法论会更亲切；未读也不影响主线理解，需要时再按下方延伸阅读入口前往即可。

延伸阅读（跨 hub 入口）

以下入口属于同合集的兄弟 hub，供超出本篇精读范围时探索；本 hub 内容自身闭合，删去这些链接不影响任何一篇的完整性：

  • 论联合政府——1945年中共七大政治报告精读，把本 hub 的三大纲领细化为战后联合政府的具体方案，是理论蓝本的第一次"施工图"化。
  • 论人民民主专政——1949年建国前夜的国家学说定论，与本 hub 构成"构想→定型"的上下篇。
  • 《实践论》精读与《矛盾论》精读——本 hub 方法论的哲学源头，"具体问题具体分析"的分析工具出自这两篇。
