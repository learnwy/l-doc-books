毛泽东选集（四卷） 简介

本 hub 的定位

《毛泽东选集》（四卷）收录毛泽东 1925—1949 年间撰写的 159 篇著作，覆盖从大革命到解放战争胜利的全部历史阶段。本 hub 回答一个核心问题：四卷里有什么、按什么结构组织、该怎么读。它提供的是"原典全景 + 导读框架"——不逐篇复述原文，而是先建立四卷的时间轴与"时期×主题"分类矩阵（第一章），再对理论含量最高的八篇文章做精读示范与写作现场还原（第二章），最后给出两条纵深线索：文本命题如何被实践检验并升华为毛泽东思想体系（第三章），以及这套理论的创新轨迹与当代方法论价值（第四章）。读完本 hub，读者应当能带着一张清晰的导航图回到原文。

与兄弟 hub 的分工边界

本 hub 属于 leaders/01_mao-zedong-studies 合集下的"全景导读层"。同合集内还有两类兄弟 hub：单篇精读 hub（吃透一篇原著）与专题体系 hub（跳出文本看一个领域），分工如下：

hub 定位 与本 hub 的关系
本 hub：毛泽东选集（四卷） 159 篇的全景综述、结构分类与导读框架 ——
毛泽东思想核心理论 思想体系的专题化梳理（理论组成部分与系统化历程） 本 hub 第三章只讲"选集文本如何通向体系"；体系的完整展开在该 hub
《实践论》精读 / 《矛盾论》精读 单篇原典逐段精读 本 hub 第二章的《实践论》《矛盾论》导读是"入门导引"；逐段细读去对应单篇 hub
《论持久战》精读 单篇军事政治论文的完整解析 本 hub 只在综述与代表作解析中给《论持久战》定位；全文精读在该 hub
毛泽东军事思想 军事领域专题（人民战争、游击战到正规战的体系化） 本 hub 把军事文章当作四卷的一条主题线索；军事思想的系统研究在该 hub
毛泽东文集 选集之外的著作补充（含建国后文献） 本 hub 严格限于四卷（1925—1949）；选集未收录与建国后的著述在该 hub

一句话边界：想知道**"四卷里有什么、从哪篇读起"→ 本 hub；想吃透某一篇原文** → 对应的单篇精读 hub；想跳出文本看体系或专题 → 思想体系 / 军事思想等专题 hub；找选集之外的文本 → 毛泽东文集 hub。

推荐学习路径

路径一：政治理论初学者（无党史基础，目标＝读懂经典在说什么）

  1. 读第一章 159篇核心文章综述，只记两件事：四卷各对应哪个历史阶段、"提出问题—探索道路—确立方法—实现目标"的主线。
  2. 跳读第二章 代表性理论文章深度解析，只精读其中《中国社会各阶级的分析》与《论持久战》两节，体会"问题导向"的写法。
  3. 读第四章 经典理论的当代诠释的"实事求是""持久战思维"两节，把经典接到自己的经验上。
  4. 暂时跳过第三章（体系性较强），待读过若干篇原文后再回头补。

路径二：历史爱好者（熟悉近代史脉络，目标＝文本与史实互证）

  1. 第一章 按历史时期与理论主题的分类结构：用交叉矩阵选定自己最感兴趣的时期—主题区域。
  2. 第二章 重要文章的历史背景与现实意义：还原《星星之火，可以燎原》《改造我们的学习》等篇的写作现场。
  3. 第三章 选集中的实践检验真理：对照理论预见与实际进程（尤其持久战三阶段与战争实录的吻合度分析）。
  4. 按第一章给出的研读路径回读原文，用 学习方法论：文本分析与历史背景结合 的三层框架做笔记。

路径三：研究者／写作者（目标＝选题、框架与体系定位）

  1. 通读本 hub 全部十章，重点吃透第三章 选集与毛泽东思想体系的关联：分清"选集文本"与"党的理论体系"两个层次，这是选题时不犯范畴错误的前提。
  2. 第四章 理论创新发展轨迹的五阶段框架可直接用作论文分期骨架。
  3. 用第一章的交叉矩阵法寻找研究缺口（如"抗战时期的哲学思考"这类交叉区域）。
  4. 需要逐字考证某篇时，转入对应的单篇精读 hub；需要选集之外的文献时，转入毛泽东文集 hub。

前置知识

  • 中国近代史基本线索（1919—1949）：至少能排出大革命、土地革命战争、抗日战争、解放战争四个阶段的先后与大致年份。第一章的时间轴、第二章的历史背景还原都以这条线索为底；完全陌生的读者建议先补一段党史通史再进入。
  • 马克思主义哲学常识：物质与意识、感性认识与理性认识、量变与质变这几组初步概念。读第二章《实践论》《矛盾论》导读和第三章时必需；不需要系统的哲学训练，导读中遇到概念会就地解释。
  • 不需要的：不必预先读过选集原文——每篇导读自带背景交代与核心引文；也不需要旧版注释学的专门知识，涉及版本修订处（如《星星之火，可以燎原》原为书信）文中均有说明。

延伸阅读

以下入口属于同合集的其他 hub，供超出"四卷导读"范围时探索：

  • 毛泽东思想核心理论——体系化梳理毛泽东思想的组成部分，承接本 hub 第三章的"体系关联"话题。
  • 《实践论》精读 与 《矛盾论》精读——本 hub 第二章两篇哲学导读的单篇深读版本。
  • 《论持久战》精读——五万字原典的完整解析，深化本 hub 对这篇"战略分析巅峰之作"的导读。
  • 毛泽东军事思想——把四卷中的军事文章线索扩展为完整专题。
  • 毛泽东文集——选集之外的著作补充，尤其覆盖建国后文献。
