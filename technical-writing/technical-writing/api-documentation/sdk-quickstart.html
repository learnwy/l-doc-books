SDK 快速入门指南

快速入门模板结构

一份高质量的 SDK 快速入门指南应让开发者在 5 分钟内完成首次 API 调用：

章节 目标 预期阅读时间
前置条件 明确环境要求与准备工作 30 秒
安装 安装 SDK 并验证 1 分钟
认证配置 获取并配置 API 密钥 1 分钟
首次调用 成功执行第一个 API 请求 2 分钟
下一步 引导开发者深入探索 30 秒

安装说明

安装部分应覆盖所有支持的语言和包管理器：

Node.js

npm install @example/sdk

Python

pip install example-sdk

Go

go get github.com/example/sdk-go

Java

<dependency>
  <groupId>com.example</groupId>
  <artifactId>sdk-java</artifactId>
  <version>2.1.0</version>
</dependency>

环境要求

语言 最低版本 包管理器
Node.js 18.0+ npm / yarn / pnpm
Python 3.9+ pip / poetry
Go 1.21+ go modules
Java 17+ Maven / Gradle

认证配置

获取 API 密钥

  1. 登录 开发者控制台
  2. 进入「API 密钥」页面
  3. 点击「创建密钥」，选择所需权限范围
  4. 复制生成的密钥，妥善保管

配置方式

推荐使用环境变量配置密钥，避免硬编码：

export EXAMPLE_API_KEY="sk_live_your_api_key_here"
export EXAMPLE_API_BASE="https://api.example.com/v2"
配置方式 安全性 适用场景
环境变量 高 生产环境、CI/CD
配置文件 (.env) 中 本地开发（需加入 .gitignore）
代码硬编码 低 仅限快速验证，严禁用于生产

首次 API 调用

以「获取当前用户信息」为例，展示各语言的首次调用：

Node.js

import { ExampleClient } from '@example/sdk';

const client = new ExampleClient({
  apiKey: process.env.EXAMPLE_API_KEY,
});

const user = await client.users.getCurrent();
console.log(`你好, ${user.name}!`);

Python

from example_sdk import ExampleClient

client = ExampleClient(api_key=os.environ["EXAMPLE_API_KEY"])

user = client.users.get_current()
print(f"你好, {user.name}!")

Go

package main

import (
	"fmt"
	"os"

	example "github.com/example/sdk-go"
)

func main() {
	client := example.NewClient(os.Getenv("EXAMPLE_API_KEY"))

	user, err := client.Users.GetCurrent()
	if err != nil {
		panic(err)
	}
	fmt.Printf("你好, %s!\n", user.Name)
}

Java

import com.example.sdk.ExampleClient;
import com.example.sdk.models.User;

public class QuickStart {
    public static void main(String[] args) {
        ExampleClient client = new ExampleClient(
            System.getenv("EXAMPLE_API_KEY")
        );

        User user = client.users().getCurrent();
        System.out.printf("你好, %s!%n", user.getName());
    }
}

常用模式

列表遍历与分页

let cursor = null;

do {
  const result = await client.orders.list({ cursor, limit: 100 });
  for (const order of result.items) {
    console.log(order.id, order.status);
  }
  cursor = result.cursor.next;
} while (cursor);

错误处理

import { ExampleClient, APIError } from '@example/sdk';

try {
  const order = await client.orders.create({ itemId: 'prod_123', quantity: 1 });
} catch (error) {
  if (error instanceof APIError) {
    console.error(`错误码: ${error.code}`);
    console.error(`描述: ${error.message}`);
    console.error(`请求 ID: ${error.requestId}`);
  }
}

请求配置与超时

const client = new ExampleClient({
  apiKey: process.env.EXAMPLE_API_KEY,
  timeout: 10000,
  retries: 3,
  baseURL: 'https://api.example.com/v2',
});

调试技巧

启用调试日志

语言 启用方式
Node.js EXAMPLE_DEBUG=true node app.js
Python logging.basicConfig(level=logging.DEBUG)
Go client.SetDebug(true)
Java -Dexample.debug=true

常见问题排查

问题 可能原因 解决方案
AUTH_TOKEN_INVALID API 密钥错误或未配置 检查环境变量是否正确设置
ETIMEDOUT 网络不可达 确认网络连接与防火墙配置
SSL_ERROR 证书验证失败 更新系统根证书或检查代理设置
RATE_LIMIT_EXCEEDED 请求频率超限 启用 SDK 内置的自动重试机制
响应数据为空 权限不足 确认 API 密钥包含所需 scope

请求追踪

每个 SDK 调用都会生成唯一的 requestId，排查问题时提供该 ID 可加速定位：

try {
  await client.users.getCurrent();
} catch (error) {
  console.error(`请联系技术支持，提供请求 ID: ${error.requestId}`);
}

最佳实践

  • 单例模式：全局复用同一个 client 实例，避免重复创建连接
  • 环境隔离：使用不同的 API 密钥区分开发、测试、生产环境
  • 版本锁定：在 lock 文件中锁定 SDK 版本，避免意外升级
  • 及时更新：关注 SDK 变更日志，及时升级以获取新功能与修复
  • 密钥轮换：定期轮换 API 密钥，被泄露时立即吊销
