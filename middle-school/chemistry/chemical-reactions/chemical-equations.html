九年级化学 — 化学方程式

知识要点

化学方程式是用化学式表示化学反应的式子，是化学的核心语言工具。九年级学生需要掌握化学方程式的书写、配平和计算。

要素 说明 示例
反应物 箭头左边 2H22H_22H2​ + O2O_2O2​
生成物 箭头右边 2H2O\text{2H}_2\text{O}2H2​O
条件 箭头上方 点燃
配平 各元素原子数相等 质量守恒

化学方程式的书写基于质量守恒定律：在化学反应中，反应前后各元素的原子种类和数目不变。

详细讲解

质量守恒定律

质量守恒定律的内容：参加化学反应的各物质的质量总和等于反应后生成的各物质的质量总和。

微观解释：化学反应前后，原子的种类、数目和质量都不变。只是原子的组合方式发生了变化。

宏观表现：反应前后物质的总质量不变。但如果有气体参与或生成，开放体系中称量的质量可能会变化（气体逸出或参与）。

化学方程式的书写步骤

第一步：写——根据事实写出反应物和生成物的化学式，中间用箭头连接。

第二步：配——配平化学方程式，使箭头两边各元素的原子数相等。

第三步：注——标明反应条件（点燃、加热△、催化剂等），标注气体符号↑和沉淀符号↓。

配平方法：最小公倍数法（找出两边某元素原子数的最小公倍数），观察法（从最复杂的化学式入手），奇数配偶法（先将奇数变为偶数）。

常见化学方程式

碳的燃烧：C + O2O_2O2​ →(点燃) CO2\text{CO}_2CO2​

铁在氧气中燃烧：3Fe + 2O22O_22O2​ →(点燃) Fe3O4\text{Fe}_3\text{O}_4Fe3​O4​

氢气燃烧：2H22H_22H2​ + O2O_2O2​ →(点燃) 2H2O\text{2H}_2\text{O}2H2​O

实验室制氧气（加热高锰酸钾）：2KMnO4\text{2KMnO}_42KMnO4​ →(加热) K2MnO4\text{K}_2\text{MnO}_4K2​MnO4​ + MnO2\text{MnO}_2MnO2​ + O2O_2O2​↑

实验室制氧气（过氧化氢分解）：2H2O2\text{2H}_2\text{O}_22H2​O2​ →(MnO2\text{MnO}_2MnO2​催化) 2H2O\text{2H}_2\text{O}2H2​O + O2O_2O2​↑

碳酸钙与盐酸反应：CaCO3\text{CaCO}_3CaCO3​ + 2HCl → CaCl2\text{CaCl}_2CaCl2​ + H2O\text{H}_2\text{O}H2​O + CO2\text{CO}_2CO2​↑

化学方程式的含义

以 2H22H_22H2​ + O2O_2O2​ →(点燃) 2H2O\text{2H}_2\text{O}2H2​O 为例：

定性含义：氢气和氧气在点燃条件下反应生成水。

定量含义（微观）：每2个氢分子和1个氧分子反应生成2个水分子。

定量含义（宏观）：每4份质量的氢气和32份质量的氧气反应生成36份质量的水（质量比为1:8:9）。

化学方程式的计算

利用化学方程式进行计算的步骤：设未知数→写出化学方程式并配平→写出相关物质的相对分子质量和已知量、未知量→列比例方程求解→写出答案。

注意：代入的量必须是纯净物的质量，如果题目给出的是含杂质的混合物质量，需要先换算成纯净物质量。

练习与思考

  1. 配平以下化学方程式：（1）Al + O2O_2O2​ → Al2O3\text{Al}_2\text{O}_3Al2​O3​；（2）Fe2O3\text{Fe}_2\text{O}_3Fe2​O3​ + CO → Fe + CO2\text{CO}_2CO2​。

  2. 写出实验室用过氧化氢溶液和二氧化锰制取氧气的化学方程式。

  3. 计算题：24g碳在充足的氧气中完全燃烧，可以生成多少克二氧化碳？（C-12, O-16）

  4. 中考模拟：在一个密闭容器中，12g碳与一定量的氧气恰好完全反应，生成二氧化碳和一氧化碳的混合气体，混合气体质量为34g。求参加反应的氧气质量以及混合气体中一氧化碳的质量。

拓展阅读

化学方程式是化学家交流的"通用语言"。从拉瓦锡建立定量化学开始，化学方程式的使用使化学从定性描述走向定量计算。掌握化学方程式的书写和计算，是进入化学殿堂的基本功。

小结

化学方程式是九年级化学的核心工具。掌握质量守恒定律、化学方程式的书写和配平方法、常见反应的化学方程式以及利用化学方程式进行计算。做到"方程式书写正确、配平准确、计算步骤规范"。
