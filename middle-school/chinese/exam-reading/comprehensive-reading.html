九年级语文 — 综合阅读

概览与定位

综合阅读是受《义务教育语文课程标准（2022 年版）》"跨学科学习""整本书阅读"两个拓展型学习任务群直接推动的新题型（来源：教育部，moe.gov.cn）。它打破"一篇文章一道题"的传统，要求学生在多材料、跨文体、含图表的真实情境里提取、整合、评价信息——这正是 PISA 阅读素养测评所定义的"为不同目的而读"的能力。多数省市以"非连续性文本"或"材料组"形式呈现，分值 6–12 分，且逐年加重。

本篇与 现代文阅读、议论文阅读 同属中考阅读三篇，但能力侧重不同：前两篇练"读懂单篇"，本篇练"整合多源"。其信息整合方法也支撑 材料作文 对多则材料的审读。

综合阅读类型 材料构成 核心能力 课标对应
非连续性文本 文字 + 图表 + 数据 + 说明书等 信息提取与整合 实用性阅读与交流
多文本对比 两篇及以上相关文本 比较分析与综合判断 文学/思辨性阅读
跨文体综合 记叙 + 说明 + 议论混编 多角度理解评价 跨学科学习
名著/整本书 整本书的局部 + 评论 整体把握与迁移 整本书阅读

知识要点

综合阅读考的是"整合多源信息"，其核心概念有三组：

  1. 非连续性文本：由文字、图表、数据、说明书等跳跃性材料拼合而成，材料之间用逻辑关系（互补、对比、因果/递进）而非叙事连贯性相连。读它必须先建"材料地图"。
  2. 材料间的三种关系：互补——各补一面拼成全貌；对比——需先确定比较维度；因果/递进——需排成逻辑链。判断关系是选择解题动作的前提。
  3. 图表阅读四看法：看标题（主题）、看坐标/表头（维度与单位）、看极值（最大/最小）、看趋势（上升/下降/波动），落点必须用准确数据语言，不能写"很多""差不多"。
  4. 开放探究题的四要素：明确观点 → 材料依据 → 合理分析 → 流畅表达；无唯一答案，但采点仍看"依据"，脱离材料空谈只得基础分。
  5. 常见误解：把综合阅读当成"多读几篇文章"，逐篇孤立理解而不建立材料间的关联；描述数据时用模糊词替换精确数值。

非连续性文本：先建"材料地图"

非连续性文本最忌一上来就找答案。正确顺序是先建材料地图：浏览全部材料，给每则贴上"主题 + 形式"标签（如"材料一·调查数据·手机使用时长"），再判断它们共同指向什么核心话题。

图表阅读的四看法

看什么 找什么 表达落点
看标题 图表主题 "该图反映……"
看坐标/表头 数据维度与单位 明确比较对象
看极值 最大/最小值 "……最高/最低"
看趋势 上升/下降/波动 "呈……趋势，从 X 增至 Y"

描述数据趋势要用准确语言："增长了 X 个百分点""由……增加到……""总体上升但 2024 年出现回落"，避免"很多""差不多"等模糊表述——这与 说明文 的"准确"要求一脉相承。

多文本对比：必须给出比较维度

对比阅读的反模式是笼统判断——只写"两篇相同/不同"而不指出从哪个维度比。正确做法是先选定维度（主题、写法、语言、立场），再逐维对照。

例如对比朱自清《春》与老舍《济南的冬天》（均为部编版七上）：

  • 写景方法：《春》多用排比、比喻铺陈五幅春景图；《济南的冬天》以"温晴"为总特征，由山到水层层勾勒。
  • 语言风格：《春》清新明丽、节奏跳跃；《济南的冬天》亲切平实、口语化。
  • 情感：前者赞美生机，后者饱含对济南的眷恋。

三个维度逐一对照，答案才"有理有据"，而非贴标签。

开放性试题：观点必须落回材料

综合阅读常以开放探究题收尾，要求结合材料谈看法。四要素缺一不可：明确观点 → 材料依据 → 合理分析 → 流畅表达。

为什么不能脱离材料空谈：开放题虽无唯一答案，但评分仍是"采点 + 看依据"。脱离材料的纯个人感想，即使文采好也只能得基础分。要点是"我的看法"必须由"材料中的事实"支撑。

名著与整本书阅读

课标将"整本书阅读"列为任务群后，中考名著题从"记书名作者"转向"整体把握 + 局部分析 + 迁移评价"。如《西游记》《骆驼祥子》《钢铁是怎样炼成的》等部编版推荐书目，常考"某情节的作用""人物成长轨迹""你从中获得的启示"。备考要点：读原著抓主线人物的命运曲线，而非只背"名著常识表"。这部分与八年级 古典文学 的整本书方法相承接。

练习与思考

  1. 找一组"青少年手机使用"非连续性文本（数据图表 + 专家访谈 + 新闻），先给每则贴"主题+形式"标签，再用四看法读懂图表，最后整合三则提出三条合理建议。
  2. 对比《春》与《济南的冬天》，从写景方法、语言风格、情感三个维度逐一作答，禁止只写"相同/不同"。
  3. 取一则科普材料（含图表），限 100 字向同学转述核心信息，须含一个准确的趋势描述句。
  4. 中考模拟：就"传统文化传承"材料组写一段开放探究答案（约 150 字），自查是否满足"观点+材料依据+分析"三要素。

小结

综合阅读考的是"整合"而非"读懂单篇"：非连续性文本先建材料地图、用四看法读图表；多文本对比必须给维度；开放题观点要落回材料。它是中考最贴近真实生活、最体现核心素养的板块，也是 材料作文 多材料审读的前置能力，并直接对接高中 现代文学阅读 的群文阅读。

课标依据：教育部《义务教育语文课程标准（2022 年版）》"实用性阅读与交流""跨学科学习""整本书阅读"学习任务群（moe.gov.cn）。
