九年级语文 — 文言文分析

概览与定位

文言文分析是中考文言文阅读的高阶能力：在 翻译 读懂字句的基础上，进一步分析内容主旨、人物形象、写作手法与思想价值。中考多以简答题形式出现，分值 4–6 分，近年"课内外比较阅读"成为主流命题方式（来源：教育部《义务教育语文课程标准（2022 年版）》"思辨性阅读与表达"任务群，moe.gov.cn）。

本篇位于文言文复习三篇的中段：上承 文言文翻译（读懂字句的基础），平行于 诗词鉴赏（古诗词赏析）。其"主旨—人物—手法—情感"分析框架与 现代文阅读 的散文赏析、议论文阅读 的论证分析相通，可统一迁移。向上对接高中 文言文学。

分析维度 考查内容 答题要求
内容理解 概括事件、归纳主旨 准确全面
人物分析 性格特征、品质评价 结合原文具体语句
写法赏析 表现手法、结构特点 术语准确
比较阅读 课内外对比 明确维度、有理有据

铁律：先读懂、再分析、后表述——分析必须建立在准确理解文意（即翻译）的基础上。

知识要点

文言文分析是在"读懂"之上的四维分析：

  1. 四个分析维度：内容理解（概括事件、归纳主旨）、人物分析（性格品质，须结合原文语句）、写法赏析（表现手法、结构特点）、比较阅读（课内外对比，须明确维度）。
  2. 铁律"先读懂、再分析、后表述"：分析必须建立在准确理解文意（即翻译）的基础上。
  3. 概括格式：事件用"谁 + 做了什么 + 结果如何"，主旨则要透过事件看到作者的思想情感或所阐道理。
  4. 人物分析格式："从文中……（具体行为/语言）可以看出，某某是一个……的人。"品质词要精准（"鞠躬尽瘁"优于笼统的"负责任"）。
  5. 常见误解：脱离原文贴标签（只写"诸葛亮很忠诚"而不引"受命于危难之间"）；无维度的笼统比较（"两篇都写得好"是无效答案）。

内容概括：从事件到主旨

概括事件用"谁 + 做了什么 + 结果如何"，概括主旨则要透过事件看到作者的思想情感或所阐道理。

以《出师表》（诸葛亮，227 年北伐前所上）为例：主旨可概括为"诸葛亮在出师北伐前，向后主刘禅提出开张圣听、严明赏罚、亲贤远佞三条建议，表达了对先帝知遇之恩的感激与北定中原、兴复汉室的决心"。注意：概括主旨不能只复述"诸葛亮上了一篇表"（停留事件层），必须点出"建议什么 + 表达什么情"。

人物形象：从言行到品质

分析人物须从具体言行入手，再提炼品质，答题格式："从文中……（具体行为/语言）可以看出，某某是一个……的人。"

常用品质词：忠诚正直、机智勇敢、勤政爱民、淡泊名利、坚毅不屈、虚心好学、刚正不阿、心忧天下。

反模式：脱离原文贴标签。只写"诸葛亮很忠诚"而不引"受任于败军之际，奉命于危难之间"作依据，会被判为空泛而扣分。品质词要精准——"鞠躬尽瘁"比笼统的"负责任"更贴《出师表》。

写作手法：四种高频手法

手法 例篇 效果
对比 《岳阳楼记》迁客骚人 vs 古仁人 反衬突出"不以物喜，不以己悲"的境界
借景抒情 《醉翁亭记》四时之景 寓"与民同乐"之情于山水
托物言志 《爱莲说》借莲 表"出淤泥而不染"的高洁品格
以小见大 《曹刿论战》一役 揭"取信于民"的制胜之道

识别手法后须落到"效果 + 主旨/情感"，不能只贴标签——这与 现代文阅读赏析三段式 完全同构。

课内外比较阅读：近年命题热点

比较阅读给一篇课内 + 一篇课外文言文，要求从某维度比较。三步法：①分别分析两篇在该维度的特点；②指出异同；③评价。

关键反模式：无维度的笼统比较。"两篇都写得好"是无效答案。必须先选定维度（思想主旨/人物形象/写法/语言风格），如比较《出师表》与《诫子书》中诸葛亮的形象——前者显"忠臣"之鞠躬尽瘁，后者显"严父"之"非淡泊无以明志"的训诫，维度清晰才有理有据。

课外文言虽陌生，但考点几乎都能在课内找到对应（同一实词、同类手法），关键在迁移——这正是 翻译篇 强调系统梳理课内篇目的原因。

开放性探究题

形如"读了本文你获得什么启示""你是否同意作者观点"。三步：亮观点 → 引原文或联系实际阐述 → 简要总结。如《岳阳楼记》"先天下之忧而忧，后天下之乐而乐"的当代意义，须先表态认同，再联系当代具体事例，最后收束，不能空喊口号。

练习与思考

  1. 读《岳阳楼记》，分析"先天下之忧而忧"的思想内涵，并联系一个当代具体事例谈现实意义（三步法作答）。
  2. 比较《出师表》与《诫子书》中诸葛亮的形象，分别从"忠臣"与"严父"两个维度，各引一句原文为据。
  3. 读一篇课外文言短文，完成：（1）概括主要内容；（2）分析主要人物品质（须引原文）；（3）指出所用写作手法及效果。
  4. 中考模拟：完成一组课内外比较阅读题，作答前先写下你选定的比较维度。

小结

文言文分析的核心是"读懂之上的多角度分析 + 规范表述"。概括要从事件升到主旨；人物分析必引原文、品质词要精准；写法识别后要落效果；比较阅读必须先定维度。其分析框架与 现代文阅读、议论文阅读 互通，基础在 文言文翻译，并向高中 文言文学 延伸。

课标依据：教育部《义务教育语文课程标准（2022 年版）》"思辨性阅读与表达"学习任务群（moe.gov.cn）。
