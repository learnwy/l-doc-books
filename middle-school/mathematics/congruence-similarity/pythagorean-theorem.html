八年级数学 — 勾股定理

知识要点

勾股定理是几何学中最重要的定理之一，它揭示了直角三角形三边之间的关系：在直角三角形中，两条直角边的平方和等于斜边的平方。如果直角三角形两直角边为 a、b，斜边为 c，则 a2a^2a2 + b2b^2b2 = c2c^2c2。

概念 内容 说明
勾股定理 a2a^2a2 + b2b^2b2 = c2c^2c2 直角三角形中成立
勾股定理逆定理 若 a2a^2a2 + b2b^2b2 = c2c^2c2，则三角形为直角三角形 用于判定直角三角形
勾股数 满足 a2a^2a2 + b2b^2b2 = c2c^2c2 的正整数组 如 (3,4,5)、(5,12,13)、(8,15,17)

勾股定理在我国古代被称为"商高定理"，西方则称为"毕达哥拉斯定理"，是人类最早发现的数学定理之一。

详细讲解

勾股定理的理解

勾股定理的几何含义是：以直角三角形的三条边分别为边长构成的三个正方形中，两个较小正方形的面积之和等于最大正方形的面积。

例如：直角边为3和4的直角三角形，斜边 c = √(323^232 + 424^242) = √(9 + 16) = √25 = 5。以三边为边的正方形面积分别为 9、16、25，确实有 9 + 16 = 25。

基本应用：已知直角三角形的任意两边，可以求第三边。

已知两直角边 a、b，求斜边：c = √(a2a^2a2 + b2b^2b2)。

已知斜边 c 和一直角边 a，求另一直角边：b = √(c2c^2c2 - a2a^2a2)。

勾股定理的证明

勾股定理有数百种证明方法，以下是最直观的一种（赵爽弦图法）：

用四个完全相同的直角三角形（直角边为 a、b，斜边为 c）拼成一个大正方形（外边长为 c），中间留出一个小正方形（边长为 a - b，假设 a > b）。

大正方形面积 = 四个三角形面积 + 小正方形面积，即 c2c^2c2 = 4 × (ab/2) + (a-b)2^22 = 2ab + a2a^2a2 - 2ab + b2b^2b2 = a2a^2a2 + b2b^2b2。

这个证明方法巧妙地利用了面积关系，我国古代数学家赵爽在注释《周髀算经》时就使用了这一方法。

勾股定理的逆定理

勾股定理的逆定理是：如果三角形的三边长 a、b、c 满足 a2a^2a2 + b2b^2b2 = c2c^2c2，那么这个三角形是直角三角形，其中 c 所对的角是直角。

应用：判断一个三角形是否为直角三角形。将最长边设为 c，其余两边为 a、b，验证 a2a^2a2 + b2b^2b2 是否等于 c2c^2c2。

例如：三边为 5、12、13。验证：525^252 + 12212^2122 = 25 + 144 = 169 = 13213^2132，成立，所以是直角三角形。

例如：三边为 4、5、6。验证：424^242 + 525^252 = 16 + 25 = 41 ≠ 36 = 626^262，不成立，所以不是直角三角形。

常见勾股数与应用

常用勾股数组：(3,4,5)、(5,12,13)、(8,15,17)、(7,24,25)。勾股数组的整数倍也是勾股数组，例如 (3,4,5) 的2倍 (6,8,10) 也满足勾股定理。

在坐标系中的应用：求两点之间的距离。点 A(x1x_1x1​, y1y_1y1​) 和点 B(x2x_2x2​, y2y_2y2​) 之间的距离为 d = √[(x2x_2x2​-x1x_1x1​)2^22 + (y2y_2y2​-y1y_1y1​)2^22]，这实际上是勾股定理在坐标系中的应用。

实际应用：工程中检验直角（用3:4:5的绳索法）、计算梯子靠墙的高度、求对角线长度等。

例如：一个矩形的长为8厘米，宽为6厘米，对角线长 d = √(828^282 + 626^262) = √(64 + 36) = √100 = 10 厘米。

练习与思考

  1. 一个直角三角形的两直角边分别为 6 和 8，求斜边长度。若斜边为 17，一直角边为 8，求另一直角边。

  2. 判断以下各组数能否构成直角三角形的三边：（1）9、40、41；（2）11、60、61；（3）7、10、12。

  3. 一架梯子长10米，斜靠在墙上，梯脚距墙6米。求梯子顶端距地面的高度。若梯脚向外滑动2米，梯子顶端会下滑多少？

  4. 在平面直角坐标系中，A(1, 2)、B(4, 6)，求线段 AB 的长度。

拓展阅读

勾股定理是数学史上最古老的定理之一。中国古代数学经典《周髀算经》中记载"勾三股四弦五"，这是勾股定理最早的具体实例之一。古巴比伦泥板上也记录了大量勾股数组，说明不同文明独立发现了这一真理。

勾股定理的推广——余弦定理 a2a^2a2 + b2b^2b2 - 2ab·cos C = c2c^2c2——适用于一般三角形，是高中数学的重要内容。费马大定理"当 n > 2 时，方程 xnx^nxn + yny^nyn = znz^nzn 没有正整数解"则是勾股定理启发下的一个著名数论问题，直到1995年才被英国数学家怀尔斯证明。

小结

勾股定理 a2a^2a2 + b2b^2b2 = c2c^2c2 是直角三角形三边关系的核心定理。掌握正向应用（已知两边求第三边）和逆定理（判定直角三角形）。熟记常用勾股数组有助于快速解题。勾股定理在坐标几何（求两点距离）和实际测量中有广泛应用。赵爽弦图法是理解定理证明的最直观方法。
