八年级数学 — 一次函数图像

知识要点

一次函数是最基本的函数类型，其解析式为 y = kx + b（k ≠ 0），图像是一条直线。当 b = 0 时，y = kx 称为正比例函数。掌握一次函数的图像性质是理解函数图像关系的基础。

参数 取值 对图像的影响
k > 0 正数 直线从左下向右上倾斜，y 随 x 增大而增大
k < 0 负数 直线从左上向右下倾斜，y 随 x 增大而减小
b > 0 正数 直线与 y 轴交点在原点上方
b < 0 负数 直线与 y 轴交点在原点下方
b = 0 零 直线经过原点（正比例函数）

一次函数图像的核心特征：k 决定倾斜方向和倾斜程度，b 决定直线与 y 轴的交点位置。

详细讲解

正比例函数 y = kx 的图像

正比例函数 y = kx（k ≠ 0）是一次函数的特殊情况（b = 0），其图像是经过原点 (0, 0) 的一条直线。

画正比例函数图像只需两个点：原点和另一个点。例如画 y = 2x 的图像，取 x = 1 得 y = 2，连接 (0, 0) 和 (1, 2) 即可。

当 k > 0 时，图像经过第一、三象限；当 k < 0 时，图像经过第二、四象限。|k| 越大，直线越陡（越接近 y 轴）；|k| 越小，直线越平缓（越接近 x 轴）。

一次函数 y = kx + b 的图像

一次函数 y = kx + b 的图像是一条不经过原点的直线（当 b ≠ 0 时）。

画图方法：取两个点连线即可。通常选取与坐标轴的交点——令 x = 0 得 y = b（与 y 轴的交点为 (0, b)），令 y = 0 得 x = -b/k（与 x 轴的交点为 (-b/k, 0)）。

图像的平移关系：y = kx + b 的图像可以看作 y = kx 的图像沿 y 轴方向平移 |b| 个单位。当 b > 0 时向上平移，当 b < 0 时向下平移。这说明 k 相同的一次函数，其图像是互相平行的直线。

k 和 b 的符号与图像位置

根据 k 和 b 的正负，一次函数图像在坐标系中的位置分为四种情况：

k > 0，b > 0：直线经过第一、二、三象限。直线向右上方倾斜，与 y 轴交于正半轴。

k > 0，b < 0：直线经过第一、三、四象限。直线向右上方倾斜，与 y 轴交于负半轴。

k < 0，b > 0：直线经过第一、二、四象限。直线向右下方倾斜，与 y 轴交于正半轴。

k < 0，b < 0：直线经过第二、三、四象限。直线向右下方倾斜，与 y 轴交于负半轴。

掌握这四种情况，就能根据 k、b 的符号快速判断图像的大致位置，或反过来从图像读取 k、b 的符号。

用图像求解实际问题

一次函数图像在解决实际问题中具有直观优势：

求交点：两条直线的交点坐标就是对应方程组的解。例如 y = 2x + 1 和 y = -x + 4 的交点，就是方程组 2x + 1 = -x + 4 的解 x = 1，y = 3，交点为 (1, 3)。

比较大小：从图像上可以直观看出，在交点左侧哪条线在上方（对应函数值较大），在交点右侧哪条线在上方。

求面积：直线与坐标轴围成三角形的面积可以利用截距直接计算。

练习与思考

  1. 画出下列函数的图像，并标注与坐标轴的交点坐标：（1）y = 3x；（2）y = -2x + 4；（3）y = x - 3。

  2. 不画图，直接判断下列函数图像经过哪些象限：（1）y = -3x + 5；（2）y = 2x - 1；（3）y = -x - 4。

  3. 已知一次函数 y = kx + b 的图像经过点 (2, 5) 和 (-1, -1)，求 k 和 b 的值，并画出图像。

  4. 甲从 A 地出发，以每小时4千米的速度步行前往 B 地；同时乙从 B 地出发，以每小时6千米的速度步行前往 A 地。A、B 两地相距20千米。分别写出甲和乙离 A 地距离 y（千米）与时间 x（小时）的函数关系式，在同一坐标系中画出图像，并从图像上找出两人相遇的时间和地点。

拓展阅读

一次函数的图像——直线——是最简单的函数图像，但它在数学和科学中有极其广泛的应用。物理中的匀速运动公式 s = vt + s0s_0s0​、经济学中的线性供需模型、统计学中的线性回归等，都是一次函数的应用。

法国数学家笛卡尔发明了坐标系，使代数和几何得以统一，函数图像就是这一伟大发明的直接产物。从此，方程不再只是抽象的符号，而有了直观的几何形象。

小结

一次函数 y = kx + b 的图像是一条直线。k 决定直线的倾斜方向（正则上升、负则下降）和倾斜程度（绝对值越大越陡），b 决定直线与 y 轴交点的位置。画图取两点连线即可，通常选坐标轴上的交点。根据 k、b 的正负可以判断图像经过的象限。一次函数图像是解决交点、比较大小、求面积等问题的直观工具。
