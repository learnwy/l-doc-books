七年级数学 — 不等式与不等式组

知识要点

不等式是表示不等关系的数学式子，用不等号（>、<、≥、≤、≠）连接两个代数式即构成不等式。一元一次不等式是最基本的不等式类型，它的解不是一个确定的值，而是一个范围（解集）。不等式组则是由两个或多个不等式组成的，需要同时满足所有不等式的解。

概念 定义 表示方法
不等式 用不等号连接的式子 ax + b > 0
不等式的解集 所有满足不等式的未知数的值的集合 x > 2
一元一次不等式 含一个未知数且最高次数为1的不等式 2x - 3 > 0
不等式组 几个不等式联立 x > 1 且 x < 5

详细讲解

不等式的基本性质

不等式的性质与等式的性质类似但有一个关键区别：

性质一：不等式两边同时加上（或减去）同一个数或式子，不等号的方向不变。即如果 a > b，那么 a + c > b + c。

性质二：不等式两边同时乘以（或除以）同一个正数，不等号的方向不变。即如果 a > b 且 c > 0，那么 ac > bc。

性质三：不等式两边同时乘以（或除以）同一个负数，不等号的方向改变。即如果 a > b 且 c < 0，那么 ac < bc。

性质三是不等式与等式最大的区别，也是解不等式时最容易出错的地方。在乘以或除以负数时，必须改变不等号的方向。

解一元一次不等式

解一元一次不等式的步骤与解一元一次方程基本相同：去分母、去括号、移项、合并同类项、系数化为1。唯一不同的是在"系数化为1"这一步：当系数为负数时，不等号要变向。

例如解不等式 -2x + 6 > 0： 移项：-2x > -6 系数化为1：两边除以-2（负数），不等号变向，得 x < 3

解集为 x < 3，在数轴上用空心圆圈标记3（表示不包含3），向左画射线表示。

不等式解集的表示

不等式的解集可以用三种方式表示：

不等式表示法：直接用不等式写出，如 x > 2。

数轴表示法：在数轴上用图形表示。空心圆圈"○"表示不包含该点（对应 > 或 <），实心圆点"●"表示包含该点（对应 ≥ 或 ≤）。然后向满足条件的方向画射线。

区间表示法（补充了解）：x > 2 可以写成 (2, +∞)，x ≤ 3 可以写成 (-∞, 3]。

一元一次不等式组

不等式组是由两个或多个一元一次不等式组成的。解不等式组就是求出同时满足所有不等式的x的值的范围。

解不等式组的步骤：先分别解出每个不等式的解集，然后取它们的公共部分（交集）。

求公共部分的口诀：

  • 同大取大：x > a 且 x > b（a < b），取 x > b
  • 同小取小：x < a 且 x < b（a < b），取 x < a
  • 大小小大取中间：x > a 且 x < b（a < b），取 a < x < b
  • 大大小小无解：x > b 且 x < a（a < b），无解

利用数轴直观地找公共部分是解不等式组的最佳方法。在数轴上分别画出各个不等式的解集，重叠的部分就是不等式组的解集。

不等式的应用

不等式在实际问题中用于处理"至少""至多""不超过""不低于"等含有不等关系的问题。

例如某商店进货单价为30元的商品，要求售价不低于进货价的120%且不超过进货价的150%，则售价x应满足：30×1.2 ≤ x ≤ 30×1.5，即 36 ≤ x ≤ 45。

列不等式解应用题的关键是准确翻译"不等关系"：大于、多于、超过对应 >；小于、少于、不足对应 <；不大于、不超过、至多对应 ≤；不小于、不低于、至少对应 ≥。

练习与思考

  1. 解下列不等式，并在数轴上表示解集：

    • 3x - 5 > x + 3
    • -2(x - 1) ≤ 4
    • (2x+1)/3 - 1 > (x-1)/2

  2. 解下列不等式组：

    • 2x - 1 > 3 且 x + 2 < 7
    • 3x ≤ 12 且 2x - 1 ≥ 3
    • x - 3 > 0 且 x - 7 > 0

  3. 某次考试共20道选择题，做对一题得5分，做错或不做扣2分。小华想要得分不低于60分，他至少要做对几道题？

  4. 找一个整数x，使得不等式组 3x - 1 > 8 且 2x + 3 < 15 成立。这样的整数有几个？分别是什么？

拓展阅读

不等式在优化问题中有重要应用。现实生活中，许多问题不是寻求精确的答案，而是确定一个可行的范围——预算的上限、产量的下限、温度的适宜区间等。不等式正是处理这类问题的数学工具。

在更高阶的数学学习中，不等式的概念会进一步推广。高中阶段会学习二次不等式、绝对值不等式等，大学数学中还有著名的柯西-施瓦茨不等式、均值不等式等。这些高级不等式都建立在七年级所学的基本不等式性质之上。

小结

本课学习了不等式的基本概念和求解方法：不等式三条基本性质中，最关键的是性质三——乘以负数时不等号变向；一元一次不等式的解法步骤与方程类似，但要注意系数为负时变号；不等式组的解集通过数轴求公共部分来确定，"同大取大、同小取小、大小小大取中间"的口诀简洁实用。
