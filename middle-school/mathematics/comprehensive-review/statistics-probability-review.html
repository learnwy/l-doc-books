九年级数学 — 统计与概率复习

知识要点

统计与概率是中考数学的必考板块，约占总分的15%。虽然分值占比不高，但题目难度相对较低，是中考得分的重要保障区。复习内容包括数据收集与整理、数据分析、概率计算三部分。

内容 核心概念 中考考查方式
数据收集 总体、样本、抽样方法 选择题、填空题
数据分析 平均数、中位数、众数、方差 计算题、分析题
概率 等可能事件、频率与概率 计算题、应用题

统计与概率的考查注重实际应用能力，题目往往以生活情境为背景。

详细讲解

统计量的计算与应用

平均数：所有数据之和除以数据个数。加权平均数：x̄ = (x1f1x_1f_1x1​f1​ + x2f2x_2f_2x2​f2​ + ... + xnfnx_nf_nxn​fn​) / (f1f_1f1​ + f2f_2f2​ + ... + fnf_nfn​)。

中位数：将数据从小到大排列后，处于最中间位置的数。数据个数为奇数时取中间那个数，为偶数时取中间两个数的平均值。

众数：数据中出现次数最多的数。一组数据可以有多个众数，也可以没有众数。

方差：衡量数据的波动程度。S2S^2S2 = [(x1−xˉ)2(x_{1}-x̄)^2(x1​−xˉ)2 + (x2−xˉ)2(x_{2}-x̄)^2(x2​−xˉ)2 + ... + (xn−xˉ)2(x_{n}-x̄)^2(xn​−xˉ)2] / n。方差越小，数据越稳定。

统计图表的解读

中考常考的统计图有四种：条形图（比较各类数据的多少）、折线图（反映数据变化趋势）、扇形图（反映各部分占总体的比例）、频率分布直方图（反映数据分布情况）。

解读统计图的方法：先看标题了解主题，再看坐标轴或图例了解数据含义，最后分析数据的特征和规律。中考中经常要求从统计图中提取数据进行计算。

抽样方法

简单随机抽样：每个个体被抽到的机会相等。常用方法有抽签法和随机数表法。

分层抽样：按照总体的某种特征分成若干层，从每层中按比例随机抽取。

系统抽样：将总体编号后按等间隔抽取。

中考中常考的是判断抽样方法是否合理，以及能否用样本估计总体。

概率计算

等可能事件的概率：P(A) = m/n（m为事件A包含的结果数，n为所有等可能结果的总数）。

列表法和树状图法是中考概率计算的两种基本方法。列表法适用于两步实验，树状图法适用于两步或三步实验。

中考概率题的常见情境：掷骰子、摸球、抽卡片、转盘等。解题时要注意分清"放回"与"不放回"抽样的区别。

频率与概率的关系

频率是实验中事件发生的比例，概率是理论上事件发生的可能性。当实验次数足够大时，频率趋近于概率。

中考中常给出实验数据，要求根据频率估计概率，或根据概率预测事件发生的次数。例如"某次调查中60%的人喜欢运动，从该地区1000人中随机选一人，估计喜欢运动的概率为0.6"。

练习与思考

  1. 五名同学的数学成绩为：85、90、78、92、85，求这组数据的平均数、中位数、众数和方差。

  2. 一个不透明的袋子中有2个红球和3个白球，随机取出两个球（不放回），用树状图列出所有可能的结果，求两个球颜色不同的概率。

  3. 某校对500名学生的课外阅读时间进行抽样调查，抽取50人的数据制成频率分布直方图。已知每天阅读1-2小时的频率为0.4，估计全校每天阅读1-2小时的学生人数。

  4. 中考模拟：某班级评选"三好学生"，投票箱中有选票，投票前随机检查了100张选票确认无标记，后投入10000张选票。投票结束后随机取出200张，其中甲同学得票120张。估计甲同学的总得票数。

拓展阅读

统计与概率在现代社会中有着广泛的应用，从天气预报到大数据分析，从保险精算到质量控制，都离不开统计和概率的知识。培养数据意识和统计思维，学会用数据说话、用概率判断，是现代公民的基本素养。

小结

统计与概率复习要掌握四种统计量的计算和应用、四种统计图的解读方法、概率的计算方法（列表法和树状图法）以及频率与概率的关系。这部分内容注重实际应用，题目难度不大但容易因审题不清而失分。考前要做好基础题的训练，确保在中考中拿到满分或接近满分。
