九年级数学 — 一元二次方程

知识要点

一元二次方程是九年级数学的核心内容之一，也是中考必考知识点。一元二次方程的一般形式为 ax2ax^2ax2 + bx + c = 0（a ≠ 0），其中 a、b、c 分别称为二次项系数、一次项系数和常数项。

解法 适用条件 特点
直接开平方法 (x+m)2(x + m)^2(x+m)2 = n 形式 简单快速
因式分解法 能提公因式或十字相乘 最常用
配方法 任何一元二次方程 通用但步骤多
公式法 任何一元二次方程 万能公式

判别式 Δ = b2b^2b2 - 4ac 决定方程根的情况：Δ > 0 时有两个不相等的实数根；Δ = 0 时有两个相等的实数根；Δ < 0 时无实数根。

详细讲解

因式分解法

因式分解法是解一元二次方程最常用的方法。其基本思路是将方程的一边化为零，另一边化为两个一次因式的乘积。

例如解方程 x2x^2x2 - 5x + 6 = 0：将左边因式分解得 (x - 2)(x - 3) = 0，所以 x - 2 = 0 或 x - 3 = 0，解得 x1x_1x1​ = 2，x2x_2x2​ = 3。

因式分解的常用方法有：提公因式法（当各项有公因式时）、十字相乘法（分解二次三项式）和公式法（完全平方式或平方差公式）。

配方法与公式法

配方法的核心步骤：将方程化为 x2x^2x2 + px = q 的形式，两边同时加上 (p/2)2(p/2)^2(p/2)2 使左边成为完全平方式，即 (x+p/2)2(x + p/2)^2(x+p/2)2 = q + (p/2)2(p/2)^2(p/2)2，然后开平方求解。

公式法是配方法的一般化结论。对于 ax2ax^2ax2 + bx + c = 0（a ≠ 0），求根公式为：x = (-b ± √(b2b^2b2 - 4ac)) / (2a)。使用公式法前要先判断 Δ = b2b^2b2 - 4ac 的符号，只有 Δ ≥ 0 时方程才有实数根。

韦达定理（根与系数的关系）

对于方程 ax2ax^2ax2 + bx + c = 0 的两个根 x1x_1x1​ 和 x2x_2x2​，韦达定理给出：x1x_1x1​ + x2x_2x2​ = -b/a，x1x_1x1​ · x2x_2x2​ = c/a。

韦达定理的应用非常广泛：可以不解方程就求出两根之和、两根之积；可以已知一个根求另一个根和某个系数；可以根据根的条件确定参数的值。

例如，已知方程 x2x^2x2 - 3x + k = 0 的一个根为1，由韦达定理知另一个根为 3 - 1 = 2，代入得 k = 1 × 2 = 2。

一元二次方程的应用

一元二次方程的实际应用题是中考的高频考点。解应用题的步骤为：审题→设未知数→列方程→解方程→验证→作答。

常见的应用场景有：面积问题（长方形面积公式）、利润问题（利润 = 售价 - 成本）、增长率问题（设增长率为x，连续增长用 (1+x)2(1+x)^2(1+x)2）、追及问题（路程关系）等。

注意：实际问题中要检验解的合理性，如长度不能为负、增长率不能超过100%等。

含参数的一元二次方程

含参数的方程是中考的难点题型。常见问题有：求参数的取值范围使方程有实数根（Δ ≥ 0）；求参数的值使方程有特定条件的根（如两个正根、一正一负根等）。

两个正根的条件：Δ ≥ 0 且 x1x_1x1​ + x2x_2x2​ > 0 且 x1x_1x1​ · x2x_2x2​ > 0。一正一负根的条件：x1x_1x1​ · x2x_2x2​ < 0，即 c/a < 0。

练习与思考

  1. 用因式分解法解方程：（1）x2x^2x2 - 7x + 12 = 0；（2）2x22x^22x2 + 5x - 3 = 0；（3）x2x^2x2 - 4x = 0。

  2. 已知方程 x2x^2x2 + mx + 3 = 0 的一个根为1，求 m 的值和另一个根。

  3. 某商品原价200元，经过两次降价后售价为128元，设每次降价的百分率为 x，列方程并求解。

  4. 中考模拟：关于 x 的方程 x2x^2x2 - 2(k-1)x + k2k^2k2 - 1 = 0 有两个实数根，求 k 的取值范围。若两根均为正数，k 的取值范围又是什么？

拓展阅读

一元二次方程是代数学的基础内容，其解法思想贯穿整个中学数学。韦达定理不仅在一元二次方程中有应用，在高中阶段还将推广到高次方程。建议同学们在掌握基本解法的同时，注重方程思想的理解，培养从实际问题中建立方程模型的能力。

小结

一元二次方程的核心知识包括四种解法、判别式的应用、韦达定理和实际应用。中考重点考查因式分解法和公式法的运用、判别式判断根的情况、韦达定理求根的关系以及列方程解应用题。要做到"方法选择得当、计算准确无误、验证必不可少"。
