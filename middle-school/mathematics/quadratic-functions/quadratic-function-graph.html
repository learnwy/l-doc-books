九年级数学 — 二次函数图像

知识要点

二次函数是初中函数学习的最高阶段，其图像为抛物线。二次函数的一般式为 y = ax2ax^2ax2 + bx + c（a ≠ 0），顶点式为 y = a(x−h)2a(x - h)^2a(x−h)2 + k，其中顶点坐标为 (h, k)，对称轴为 x = h。

表达式 特点 可直接读出的信息
y = ax2ax^2ax2 + bx + c 一般式 开口方向(a)、与y轴交点(c)
y = a(x−h)2a(x - h)^2a(x−h)2 + k 顶点式 顶点(h,k)、对称轴(x=h)
y = a(x - x1x_1x1​)(x - x2x_2x2​) 交点式 与x轴交点(x1x_1x1​,x2x_2x2​)

二次函数图像的基本特征由系数 a 决定：a > 0 时抛物线开口向上，a < 0 时开口向下；|a| 越大，抛物线开口越窄。

详细讲解

二次函数图像的画法

画二次函数图像的标准步骤：

第一步，确定开口方向（a的正负）和对称轴（x = -b/(2a)）。第二步，求顶点坐标，顶点的横坐标为 -b/(2a)，纵坐标为 (4ac - b2b^2b2)/(4a)。第三步，求与坐标轴的交点——令 x = 0 得与 y 轴交点 (0, c)，令 y = 0 解方程得与 x 轴交点。第四步，利用对称性再找几个关键点，连线成光滑的曲线。

图像与系数的关系

这是中考的高频考点，需要掌握 a、b、c 以及 Δ 与图像特征的对应关系：

a 的符号决定开口方向。b 与 a 的符号关系决定对称轴位置——当 ab > 0 时对称轴在 y 轴左侧，ab < 0 时在右侧，b = 0 时对称轴就是 y 轴。c 的符号决定图像与 y 轴的交点位置——c > 0 交于正半轴，c < 0 交于负半轴。Δ 决定图像与 x 轴的交点个数。

图像的平移变换

二次函数图像的平移规则是"左加右减、上加下减"：

y = ax2ax^2ax2 向右平移 h 个单位得 y = a(x−h)2a(x - h)^2a(x−h)2，向上平移 k 个单位得 y = ax2ax^2ax2 + k。综合平移后得 y = a(x−h)2a(x - h)^2a(x−h)2 + k。

平移只改变图像的位置，不改变图像的形状。平移后新的顶点坐标为 (h, k)，对称轴为 x = h。

二次函数的最值

当 a > 0 时，函数在顶点处取最小值 y_min = k = (4ac - b2b^2b2)/(4a)；当 a < 0 时，函数在顶点处取最大值 y_max = k。

在限定区间 [m, n] 上求最值时，需要分三种情况讨论：对称轴在区间左侧、在区间内、在区间右侧，分别比较端点值和顶点值。

由图像确定解析式

根据已知条件求二次函数解析式的方法：

已知顶点和另一个点——使用顶点式 y = a(x−h)2a(x - h)^2a(x−h)2 + k。已知三个点——使用一般式 y = ax2ax^2ax2 + bx + c，代入三点坐标列方程组。已知与 x 轴的两个交点和另一个点——使用交点式 y = a(x - x1x_1x1​)(x - x2x_2x2​)。

练习与思考

  1. 画出二次函数 y = x2x^2x2 - 4x + 3 的图像，标出顶点坐标、对称轴和与坐标轴的交点。

  2. 已知二次函数的图像开口向下，对称轴为 x = 1，且过点 (3, 0) 和 (0, 3)，求该函数的解析式。

  3. 将抛物线 y = 2x22x^22x2 先向右平移3个单位，再向下平移1个单位，写出平移后的函数解析式。

  4. 中考模拟：如图所示的抛物线（a > 0），判断 a、b、c、Δ、a+b+c、a-b+c 的符号。

拓展阅读

二次函数图像的研究方法体现了"数形结合"的重要数学思想。通过图像可以直观地理解函数的性质，而通过代数运算可以精确地求出图像的关键信息。这种数与形相互转化的思想在高中数学中会得到更广泛的应用，是数学学习的核心素养之一。

小结

二次函数图像是九年级数学的重点和难点。掌握三种表达式的特点和转化方法、理解图像与系数的对应关系、熟练运用平移变换规则、学会求最值和确定解析式，是应对中考的关键。要做到"看式知图、看图辨式"，实现代数与几何的灵活转化。
