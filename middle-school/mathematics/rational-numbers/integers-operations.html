七年级数学 — 整数与运算

知识要点

整数是数学学习的基础，七年级阶段将整数的范围从小学阶段的自然数扩展到包含负数的全体整数。正整数、零和负整数统称为整数。引入负数后，数的运算规则也发生了重要变化，学生需要重新理解加减乘除的意义和法则。

有理数是整数和分数的统称。在有理数的范围内，四则运算（加、减、乘、除）和乘方运算都有明确的运算法则。掌握这些法则是后续代数学习的前提。

数的分类 包含范围 举例
正整数 大于零的整数 1, 2, 3, 100
零 既不是正数也不是负数 0
负整数 小于零的整数 -1, -2, -3, -100
正分数 大于零的分数 1/2, 3.5, 0.7
负分数 小于零的分数 -1/2, -3.5, -0.7

详细讲解

正数与负数的概念

在实际生活中，许多量具有相反的意义：盈利与亏损、上升与下降、零上与零下等。为了表示这些相反意义的量，数学中引入了负数的概念。大于零的数叫做正数，小于零的数叫做负数，零既不是正数也不是负数。

正数可以在前面加"+"号表示，也可以省略"+"号。负数必须在前面加"-"号，不能省略。例如+5可以写成5，而-5不能省略负号。理解正数和负数在实际问题中的含义，是正确使用有理数的基础。

有理数的加法

有理数的加法法则分为三种情况：

同号两数相加，取相同的符号，并把绝对值相加。例如 (+3) + (+5) = +8，(-3) + (-5) = -8。

异号两数相加，取绝对值较大的数的符号，并用较大的绝对值减去较小的绝对值。例如 (+3) + (-5) = -2，(-3) + (+5) = +2。

一个数与零相加，仍得这个数。例如 (-5) + 0 = -5。

加法交换律 a + b = b + a 和加法结合律 (a + b) + c = a + (b + c) 在有理数范围内仍然成立，可以利用这两条运算律简化计算。

有理数的减法

有理数的减法法则：减去一个数，等于加上这个数的相反数。即 a - b = a + (-b)。

这条法则将减法运算转化为加法运算，使得所有的加减混合运算都可以统一用加法来处理。例如 (+3) - (-5) = (+3) + (+5) = +8，(-3) - (+5) = (-3) + (-5) = -8。

有理数的乘法与除法

有理数乘法法则：两数相乘，同号得正，异号得负，并把绝对值相乘。任何数与零相乘，积为零。例如 (+3) × (-5) = -15，(-3) × (-5) = +15。

有理数除法法则：除以一个不等于零的数，等于乘以这个数的倒数。除法的符号规则与乘法相同：同号得正，异号得负。例如 (-15) ÷ (-5) = +3，(+15) ÷ (-5) = -3。

有理数的乘方

乘方是一种特殊的乘法运算。ana^nan 表示 n 个 a 相乘，其中 a 叫做底数，n 叫做指数，运算结果叫做幂。

正数的任何次幂都是正数。负数的奇数次幂是负数，负数的偶数次幂是正数。例如 (−2)3(-2)^3(−2)3 = -8，(−2)4(-2)^4(−2)4 = 16。需要特别注意 (−2)2(-2)^2(−2)2 = 4 与 -222^222 = -4 的区别：前者是对-2求平方，后者是对2求平方后再取负。

拓展阅读

负数的发明经历了漫长的历史过程。中国古代数学家在《九章算术》中就已经使用正负数来表示盈亏，比西方早了一千多年。在公元三世纪，刘徽在《九章算术注》中明确提出了正负数的加减法则。负数在欧洲直到十七世纪才被广泛接受，之前许多欧洲数学家认为负数是"荒谬的数"。

掌握有理数运算后，可以尝试解决更复杂的实际问题，如温差计算、海拔变化、股市涨跌等。这些问题都需要灵活运用正负数的概念和运算法则。

小结

本课学习了有理数的基本概念和运算法则：正负数的引入扩展了数的范围，加法法则按同号异号分类处理，减法转化为加法计算，乘除法遵循"同号得正、异号得负"的规律，乘方运算要注意底数符号与指数奇偶的关系。这些运算法则是整个初中数学计算的基石。
