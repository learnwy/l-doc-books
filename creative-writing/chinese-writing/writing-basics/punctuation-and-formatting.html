标点与排版

中文标点规范（GB/T 15834）

GB/T 15834《标点符号用法》是中国国家标准，规定了标点符号的名称、形式和用法。

标点符号 名称 主要用法 示例
， 逗号 句中一般性停顿 天气晴朗，万里无云。
。 句号 陈述句末尾 今天是星期一。
！ 叹号 感叹句或语气强烈的祈使句末尾 太壮观了！
？ 问号 疑问句末尾 你去过北京吗？
； 分号 并列分句之间的停顿 春天温暖；夏天炎热。
： 冒号 提示下文或总结上文 他说："我同意。"
"" 双引号 引用、强调、特殊含义 "知识就是力量"是培根的名言。
'' 单引号 引号内再引用 他说："老师说'要努力学习'。"
—— 破折号 解释说明、话题转换 他——一个普通的教师——改变了一切。
…… 省略号 省略内容或表示语意未尽 花园里有玫瑰、月季、茉莉……

常见标点误用

错误类型 错误示例 正确写法 说明
逗号代替句号 他走了，她留下了 他走了。她留下了。 两个独立的句子需用句号
顿号滥用 他、就这样走了 他就这样走了。 顿号只用于并列词语之间
引号位置错误 他说"我同意。" 他说："我同意。" 引用需加冒号引导
省略号位数错 他沉默了... 他沉默了…… 中文省略号为六个点
书名号误用 他在《手机》上看新闻 他在手机上看新闻。 书名号只用于作品名称
破折号写法错 他-一个老人-站了起来 他——一个老人——站了起来 破折号占两个字符位

全角半角规则

中文写作中全角与半角的混用是最常见的排版问题之一。

场景 规则 正确示例 错误示例
中文标点 使用全角 他说："你好。" 他说:"你好."
英文标点 使用半角 Hello, world! Hello，world！
中文语境中的数字 半角数字 共有 128 人参加 共有１２８人参加
括号内为中文 全角括号 （详见附录） (详见附录)
括号内为英文 半角括号 使用 Markdown (MD) 格式 使用 Markdown（MD）格式

核心原则

  • 中文语境下所有标点一律使用全角
  • 英文和代码语境下一律使用半角
  • 全角标点后不加空格，半角标点后加一个空格

中英混排

中英文混排在技术写作和现代媒体中极为常见，需遵循以下规范。

规则 正确示例 错误示例
中英文之间加空格 使用 Python 编写脚本 使用Python编写脚本
数字与中文间加空格 共有 5 个选项 共有5个选项
专有名词保持原文 使用 GitHub 进行协作 使用 github 进行协作
英文标点跟随英文 包括 �TP (File Transfer Protocol) 包括 FTP（File Transfer Protocol）
单位与数字间加空格 文件大小为 100 MB 文件大小为100MB

特殊情况

  • 百分号紧跟数字，不加空格：增长了 15%
  • 度数符号紧跟数字：气温达到 35°C
  • 货币符号在数字前：价格为 ¥128

段落缩进与排版

排版风格 特点 适用场景
首行缩进两格 传统中文排版，正式感 印刷出版、公文
段间空行 现代网页排版，清晰 博客、技术文档
无缩进无空行 紧凑排版 即时消息、短评

网络排版建议

  • 段落之间用空行分隔，不使用首行缩进
  • 标题层级不超过四级（H1—H4）
  • 列表项控制在 3—7 条，超过则分组
  • 表格列数不超过 6 列，避免横向滚动
  • 正文行宽控制在 35—45 个中文字符，提升可读性

排版对比

传统印刷排版：

　　科技的发展日新月异，人工智能已经渗透到了我们生活的方方面面。从语音助手到自动驾驶，从医疗诊断到金融分析，AI 正在重塑每一个行业。

现代网络排版：

科技的发展日新月异，人工智能已经渗透到了我们生活的方方面面。

从语音助手到自动驾驶，从医疗诊断到金融分析，AI 正在重塑每一个行业。
