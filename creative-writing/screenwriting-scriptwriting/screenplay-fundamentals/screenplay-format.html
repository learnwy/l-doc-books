剧本格式与排版规范

核心概念

剧本格式是影视行业的通用语言，它不仅仅是排版美学，更是一套标准化的信息传递系统。从好莱坞到国内影视工业，规范的剧本格式直接决定了项目的专业度和可执行性。一页标准格式的剧本大约对应一分钟银幕时间，这一经验法则让制片人仅凭页数就能估算影片时长和拍摄周期。

理解剧本格式的关键在于认识到每个元素都有明确的功能定位——场景标题告诉导演拍摄地点和时间，动作描写指导摄影师和美术，对白指导演员，括号注释提供表演提示。

场景标题（Slug Line）的书写规范
场景标题是每个场景的起始标记，它以最简洁的方式传递三个关键信息：场景发生在室内还是室外、具体地点、时间段。标准英文格式使用全大写，中文格式则遵循国内行业惯例。


英文标准格式为 INT./EXT. LOCATION - TIME，其中 INT. 表示内景（Interior），EXT. 表示外景（Exterior）。时间通常使用 DAY、NIGHT、DAWN、DUSK 等标准词汇。


中文剧本中，场景标题的写法有所不同。常见格式为「场景序号. 内景/外景 地点 时间」，例如「1. 内景 李明的公寓-客厅 夜」。国内部分制片体系还要求在场景标题中加入日/夜标注和场景序号。


特殊场景标题的处理也很重要。当一个场景在室内外之间切换时，可以使用 INT./EXT. 的组合形式。连续场景（CONTINUOUS）表示时间上紧接前一场景，常用于角色从一个房间走到另一个房间的情况。闪回（FLASHBACK）和梦境（DREAM SEQUENCE）需要在场景标题中明确标注。


场景标题的地点描述应该尽量具体但简洁。不要写「一个漂亮的房间」，而应写「李明公寓-卧室」。层级地点用连字符分隔，从大到小排列。


动作描写的技巧与限制
动作描写（Action Lines）是剧本中描述视觉画面的部分，它承担着「用文字导演」的功能。优秀的动作描写应该是简洁、生动、富有画面感的，同时严格限制在「可拍摄」的范围内。


核心原则是「只写摄影机能捕捉到的内容」。这意味着不能写角色的内心想法（除非通过旁白），不能写观众无法从画面中感知的信息。例如，不能写「小王心里很紧张」，而应该写「小王的手微微发抖，他不停地揉搓衣角」。


动作描写的时态始终使用现在时。英文剧本使用一般现在时（He walks），中文剧本同样使用现在时态的表述方式。这是因为剧本描述的是观众「正在看到」的画面。


段落长度控制至关重要。每个动作段落不应超过四行，理想情况下控制在两到三行。长段落会减慢阅读节奏，也暗示着画面节奏的拖沓。当需要描述复杂场景时，将其拆分为多个短段落，每个段落聚焦一个视觉焦点。


角色首次出场时，名字需要全大写（英文）或加粗标注（中文），并附上简短的外貌和气质描述。这个描述应该突出角色最显著的视觉特征和给人的第一印象，而非详细的身体参数。例如「张伟（35），瘦削的脸上永远挂着一副金丝眼镜，说话时习惯性地推一下镜框」比「张伟，男，35岁，身高178cm，体重65kg」更具画面感和角色特征。


白空间（White Space）的运用是专业剧本的标志。适当的空行和短段落让页面看起来通透，阅读体验更好。好莱坞的评审读一个剧本只用几分钟，密密麻麻的文字块会直接导致剧本被放弃。


对白格式与音效标注
对白是剧本中最核心的部分之一，其格式要求严格且功能明确。标准对白由三部分组成：角色名、可选的括号注释、对白文本。


角色名居中排列，使用大写字母（英文）。当同一角色的对白被动作描写打断后继续时，需要在角色名后加注 (CONT'D)（英文）或「（续）」（中文）。当角色的声音来自画外（如电话另一端、旁白），使用 (V.O.) 表示画外音（Voice Over），使用 (O.S.) 或 (O.C.) 表示画外空间的声音（Off Screen / Off Camera）。


括号注释（Parenthetical）是对白中最容易被滥用的元素。它应该只在以下情况使用：对白的情绪与前文语境明显矛盾时，需要指明对白的对象时（对电话那头），或者涉及关键的物理动作时。过度使用括号注释是新手编剧的典型特征，它暗示编剧不信任导演和演员的判断力。

中文剧本的对白格式与英文有显著差异。国内常见的格式是在角色名后直接加冒号，然后跟对白内容，不需要居中排列。但随着国内影视工业化进程加速，越来越多的制片公司开始采用更接近好莱坞标准的格式。


专业软件与工作流
现代剧本写作几乎完全依赖专业排版软件，手动调整格式既低效又容易出错。理解主流工具的特点和选择逻辑，对于建立高效的写作工作流至关重要。


Final Draft 是好莱坞的行业标准软件，超过 95% 的好莱坞制片公司接受 .fdx 格式文件。它提供完善的自动格式化、场景导航、角色报告、大纲视图等功能。其 Beat Board 功能允许编剧在可视化面板上规划故事结构。


WriterSolo 和 Fountain 代表了轻量化趋势。Fountain 是一种纯文本标记语言，类似 Markdown，用简单的文本约定来表示剧本元素。它的核心优势在于文件可以用任何文本编辑器打开，不依赖特定软件，且支持版本控制。

工作流的核心环节包括：大纲阶段使用 Beat Sheet 或 Index Card 规划结构，初稿阶段专注内容产出不纠结格式（软件自动处理），修改阶段利用修订模式（Revision Mode）跟踪变更（不同修订版用不同颜色页标注），最终交付时导出为行业标准的 PDF 格式。


版本管理在专业环境中尤为重要。好莱坞使用彩色修订页系统：初稿为白色，第一次修订为蓝色，第二次为粉色，依次为黄色、绿色、橙色。每页标注修订日期，只替换有修改的页面，方便剧组人员快速定位变更内容。


对于有编程背景的编剧，Fountain 格式配合 Git 版本控制是一个极具吸引力的方案。每次修改都有完整的 diff 记录，分支功能可以用来探索不同的情节走向，合并功能方便多人协作时整合修改。


小结
    

  • 剧本格式是影视工业的标准化沟通语言，一页约等于一分钟银幕时间
    • 

  • 场景标题（Slug Line）包含三要素：内/外景、地点、时间，是每个场景的信息入口
    • 

  • 动作描写遵循「只写摄影机能看到的」原则，使用现在时，段落控制在四行以内
    • 

  • 对白格式严格区分角色名、括号注释、对白文本三层结构
    • 

  • 画外音（V.O.）、画外空间声（O.S.）、续接（CONT'D）是最常用的标注
    • 

  • 括号注释应极度克制使用，过度使用是新手标志
    • 

  • Final Draft 是行业标准工具，Fountain 是技术背景编剧的高效替代
    • 

  • 好莱坞的彩色修订页系统（白-蓝-粉-黄-绿-橙）用于版本追踪
    • 

  • 中文剧本格式正逐步向国际标准靠拢，但仍保留本土特色
