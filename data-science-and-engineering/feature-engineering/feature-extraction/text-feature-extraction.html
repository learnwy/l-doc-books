文本特征提取

核心概念

文本特征提取是将非结构化的自然语言文本转化为机器学习模型可处理的数值向量的过程。文本数据天然具有高维稀疏、语义多义和上下文依赖等特性，直接无法输入数学模型，必须通过特征化手段将其映射到向量空间。从早期的词袋模型到现代的预训练语言模型，文本特征提取技术经历了三代演进，每一代都在语义捕获能力上实现质的飞跃。

理解这三个层次的差异是选择文本特征提取策略的基础。在实际项目中，方法选择取决于数据规模、算力预算、语义精度要求以及下游任务的复杂度。


文本预处理流水线
文本预处理是特征提取的前置环节，处理质量直接决定特征的信噪比。一条完整的预处理流水线包含多个可插拔的步骤，不同任务可以选择性地启用或跳过某些步骤。


分词是中文文本处理的核心难点。中文没有天然的空格分隔符，必须依赖分词工具将连续字符串切分为有意义的词语单元。jieba 是最常用的中文分词库，支持精确模式、全模式和搜索引擎模式三种切分策略。


import jieba
import re

def preprocess_pipeline(text, stopwords=None):
    text = re.sub(r'[^\w\s]', '', text)
    text = text.lower()
    tokens = jieba.lcut(text, cut_all=False)
    if stopwords:
        tokens = [t for t in tokens if t not in stopwords and len(t) > 1]
    return tokens
英文文本预处理还涉及词干化（Stemming）和词形还原（Lemmatization）。词干化通过规则裁剪后缀（如 running → run），速度快但可能产生非真实词汇；词形还原通过词典查找还原为原形（如 better → good），准确但较慢。两者在不同场景下各有优势。

预处理流水线的设计应当遵循"先粗后细"的原则：先进行全局性的清洗操作（如去噪、编码统一），再执行粒度更细的语言学处理（如分词、词形还原），最后根据下游任务需求决定是否进行停用词过滤和词频阈值裁剪。


统计特征方法
统计方法是文本特征提取的经典基线，其核心思想是用词频信息构建文档向量。虽然不具备语义理解能力，但在许多实际场景中仍然表现出色，且计算成本极低。


词袋模型（Bag of Words）是最简单的文本向量化方法。它将每篇文档表示为词表大小的向量，每个位置记录对应词语的出现次数。词袋模型完全忽略词序信息，"我爱你"和"你爱我"在词袋模型中的表示完全相同。


TF-IDF（Term Frequency-Inverse Document Frequency）在词频基础上引入逆文档频率权重，降低高频常见词的影响，提升低频专业词的重要性。TF-IDF 的数学定义为：


TF-IDF(t,d)=TF(t,d)×log⁡NDF(t)+1\text{TF-IDF}(t, d) = \text{TF}(t, d) \times \log\frac{N}{\text{DF}(t) + 1}TF-IDF(t,d)=TF(t,d)×logDF(t)+1N​
其中 TF(t,d)\text{TF}(t, d)TF(t,d) 是词 ttt 在文档 ddd 中的频率，NNN 是总文档数，DF(t)\text{DF}(t)DF(t) 是包含词 ttt 的文档数。


from sklearn.feature_extraction.text import TfidfVectorizer

corpus = [
    "机器学习是人工智能的核心",
    "深度学习推动了自然语言处理",
    "特征工程是数据科学的关键步骤"
]

vectorizer = TfidfVectorizer(
    max_features=5000,
    ngram_range=(1, 2),
    min_df=1,
    max_df=0.95,
    sublinear_tf=True
)
tfidf_matrix = vectorizer.fit_transform(corpus)
N-gram 特征通过捕获连续 N 个词的组合来弥补词袋模型对词序信息的丢失。Bigram（N=2）可以捕获如"深度学习""特征工程"等短语级模式，Trigram（N=3）则能捕获更长的搭配关系。N-gram 的代价是特征空间急剧膨胀，通常需要配合特征选择或降维使用。

Hashing Trick 是一种无需维护词表的向量化方法，通过哈希函数将词语映射到固定维度的桶中。它的优势是内存效率高且支持在线学习，但存在哈希碰撞导致的信息损失，且不可逆（无法从特征向量还原词语）。


词嵌入与语义向量
词嵌入（Word Embedding）是浅层语义方法的核心技术，它将词语映射到低维稠密向量空间，使得语义相近的词在向量空间中距离也相近。这一突破性创新来自 Mikolov 在 2013 年提出的 Word2Vec 模型。


Word2Vec 包含两种训练架构：CBOW（Continuous Bag of Words）通过上下文预测中心词，Skip-gram 通过中心词预测上下文。Skip-gram 在小语料上表现更好，CBOW 在大语料上训练更快。


from gensim.models import Word2Vec

sentences = [
    ["机器", "学习", "是", "人工智能", "的", "核心"],
    ["深度", "学习", "推动", "自然语言", "处理"],
    ["特征", "工程", "是", "数据", "科学", "的", "关键"]
]

model = Word2Vec(
    sentences,
    vector_size=128,
    window=5,
    min_count=1,
    workers=4,
    sg=1
)

similar_words = model.wv.most_similar("学习", topn=5)
doc_vector = sum(model.wv[w] for w in sentences[0] if w in model.wv) / len(sentences[0])
GloVe（Global Vectors）采用不同的训练思路，它基于全局词共现矩阵进行矩阵分解，同时捕获局部上下文和全局统计信息。GloVe 在类比推理任务上表现尤为突出。FastText 是 Facebook 提出的改进方案，它将每个词拆分为字符级 N-gram，然后将所有子词向量求和得到词向量。这使得 FastText 能够处理未登录词（OOV）并捕获形态学信息。

将词向量聚合为文档向量是实际应用中的关键步骤。最简单的方法是平均池化（Mean Pooling），即对文档中所有词向量取平均值。加权平均池化使用 TF-IDF 权重对词向量加权，通常比简单平均效果更好。SIF（Smooth Inverse Frequency）方法进一步通过去除第一主成分来消除语料中的共同语义漂移。


预训练语言模型特征
预训练语言模型（PLM）代表了文本特征提取的第三代技术，以 BERT 为代表的模型通过大规模无监督预训练学习到深层的上下文语义表示。与静态词嵌入不同，PLM 为同一个词在不同上下文中生成不同的向量表示，真正解决了一词多义问题。


BERT 使用 Transformer 编码器架构，通过 Masked Language Model（MLM）和 Next Sentence Prediction（NSP）两个预训练目标学习双向上下文表示。对于特征提取任务，通常提取 BERT 最后一层或倒数几层的隐状态作为特征向量。


from transformers import AutoTokenizer, AutoModel
import torch

tokenizer = AutoTokenizer.from_pretrained("bert-base-chinese")
model = AutoModel.from_pretrained("bert-base-chinese")

def extract_bert_features(texts, pooling="cls"):
    inputs = tokenizer(texts, padding=True, truncation=True,
                       max_length=512, return_tensors="pt")
    with torch.no_grad():
        outputs = model(**inputs)

    if pooling == "cls":
        return outputs.last_hidden_state[:, 0, :]
    elif pooling == "mean":
        mask = inputs["attention_mask"].unsqueeze(-1)
        return (outputs.last_hidden_state * mask).sum(1) / mask.sum(1)

features = extract_bert_features(["特征工程是数据科学的核心"])
Sentence-BERT（SBERT）是专门为句子级语义相似度优化的 BERT 变体。标准 BERT 计算两个句子的相似度需要将它们拼接后输入模型，复杂度为 O(n2)O(n^2)O(n2)；SBERT 通过孪生网络结构独立编码每个句子，然后计算余弦相似度，复杂度降为 O(n)O(n)O(n)，适合大规模语义检索场景。


在实际生产环境中，直接使用 BERT 提取特征面临推理速度慢、资源消耗大等挑战。常见的优化策略包括模型蒸馏（DistilBERT 参数量减半，速度提升60%）、量化（FP16/INT8 减少显存占用）和 ONNX Runtime 加速推理。对于高吞吐场景，还可以使用 TensorRT 进行部署优化。


选择 CLS 池化还是 Mean 池化取决于具体任务。CLS token 在经过微调后效果通常更好，但在未微调的预训练模型上，Mean 池化往往表现更优，因为 CLS token 在预训练阶段主要用于 NSP 任务，其表示未必能代表整个句子的语义。


文本特征的工程实践
在真实项目中，文本特征提取不是一次性操作，而是需要嵌入到可维护、可复现的工程流水线中。实践中常见的架构模式是构建多层次特征金字塔：底层使用统计特征保证基线性能和可解释性，中层使用词嵌入特征捕获语义相似度，顶层使用 PLM 特征追求极致精度。


import numpy as np
from sklearn.decomposition import TruncatedSVD

class TextFeatureExtractor:
    def __init__(self, tfidf_dim=5000, embed_dim=128, bert_dim=768):
        self.tfidf_vectorizer = TfidfVectorizer(max_features=tfidf_dim)
        self.svd = TruncatedSVD(n_components=50)
        self.embed_dim = embed_dim
        self.bert_dim = bert_dim

    def extract_statistical(self, texts):
        tfidf = self.tfidf_vectorizer.fit_transform(texts)
        return self.svd.fit_transform(tfidf)

    def extract_meta(self, texts):
        return np.array([
            [len(t), len(t.split()), len(set(t.split())),
             len(set(t.split())) / max(len(t.split()), 1)]
            for t in texts
        ])

    def combine_features(self, texts):
        stat_feat = self.extract_statistical(texts)
        meta_feat = self.extract_meta(texts)
        return np.hstack([stat_feat, meta_feat])
特征缓存策略对大规模文本处理至关重要。BERT 特征提取的计算成本很高，对同一批文本反复提取是严重的资源浪费。推荐使用内容哈希作为缓存键，将提取结果持久化到特征存储中。缓存粒度的选择也很关键：句子级缓存灵活但缓存命中率低，文档级缓存命中率高但无法重用跨文档的公共句子。

小结
    

  • 文本特征提取经历了统计方法、词嵌入和预训练语言模型三代演进，每代在语义理解能力上显著提升
    • 

  • 文本预处理流水线遵循"先粗后细"原则，中文分词和英文词形还原是各自的关键步骤
    • 

  • TF-IDF 仍然是性价比极高的基线方法，配合 N-gram 和 SVD 降维可覆盖大部分传统 NLP 任务
    • 

  • Word2Vec、GloVe、FastText 三种词嵌入各有优势，FastText 在 OOV 处理上独具优势
    • 

  • BERT 等预训练模型提供上下文感知的动态语义表示，是高精度语义任务的首选
    • 

  • Sentence-BERT 将句子对比较从 O(n²) 降至 O(n)，适合大规模语义检索
    • 

  • 工程实践中推荐构建多层特征金字塔，兼顾性能、可解释性和精度
    • 

  • 特征缓存和批处理推理是生产环境中文本特征提取的关键优化手段
    •
