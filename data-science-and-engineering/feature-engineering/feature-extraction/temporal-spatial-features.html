时间与空间特征提取

核心概念

时间特征和空间特征是数据科学中两类极其重要的结构化特征，它们蕴含着事件的演化规律和地理分布模式。时间特征捕获数据随时间变化的周期性、趋势性和突变性；空间特征捕获地理位置之间的距离关系、区域聚集效应和空间自相关性。这两类特征在推荐系统、风控模型、物流优化和城市计算等领域发挥着核心作用。

时间特征和空间特征的提取不是简单的字段拆解，而是需要根据业务周期和地理尺度进行精心设计。好的时空特征能够让模型发现隐藏在时间序列和地理空间中的深层规律。


日历特征与时间拆解
日历特征是最基础也最重要的时间特征，通过将时间戳拆解为多个粒度的时间分量，为模型提供丰富的时间上下文信息。一个完整的日历特征集通常覆盖从年到秒的多个层级。


import pandas as pd
import numpy as np

def extract_calendar_features(df, col='timestamp'):
    ts = pd.to_datetime(df[col])

    features = pd.DataFrame()
    features['year'] = ts.dt.year
    features['month'] = ts.dt.month
    features['day'] = ts.dt.day
    features['hour'] = ts.dt.hour
    features['minute'] = ts.dt.minute
    features['day_of_week'] = ts.dt.dayofweek
    features['day_of_year'] = ts.dt.dayofyear
    features['week_of_year'] = ts.dt.isocalendar().week.astype(int)
    features['quarter'] = ts.dt.quarter

    features['is_weekend'] = (ts.dt.dayofweek >= 5).astype(int)
    features['is_month_start'] = ts.dt.is_month_start.astype(int)
    features['is_month_end'] = ts.dt.is_month_end.astype(int)

    return features
节假日特征是日历特征的重要补充。节假日期间的用户行为、交易量和物流需求与平日有显著差异。不同国家和地区的节假日体系各不相同，全球化业务需要维护多国节假日日历。中国的调休制度（如春节前后的周末上班日）使得"是否工作日"的判断比简单的周末检测更复杂。

直接将月份（1-12）或小时（0-23）作为数值输入模型会引入不合理的序关系，例如模型可能认为 12 月和 1 月相差很远，但实际上它们在年周期中是相邻的。周期编码通过正弦余弦变换解决了这个边界不连续问题。


周期编码与时间变换
周期编码是处理周期性时间特征的标准方法，它利用三角函数将环形时间映射到二维平面上，使得周期首尾的时间点在向量空间中保持邻近关系。


def cyclical_encode(values, period):
    sin_vals = np.sin(2 * np.pi * values / period)
    cos_vals = np.cos(2 * np.pi * values / period)
    return sin_vals, cos_vals

def add_cyclical_features(df, col='timestamp'):
    ts = pd.to_datetime(df[col])

    df['hour_sin'], df['hour_cos'] = cyclical_encode(ts.dt.hour, 24)
    df['dow_sin'], df['dow_cos'] = cyclical_encode(ts.dt.dayofweek, 7)
    df['month_sin'], df['month_cos'] = cyclical_encode(ts.dt.month, 12)
    df['doy_sin'], df['doy_cos'] = cyclical_encode(ts.dt.dayofyear, 365.25)

    return df
时间差特征（Time Delta）捕获事件之间的间隔信息，在用户行为建模和风控场景中尤为重要。用户的两次登录间隔、两次交易间隔、两次浏览间隔都蕴含着行为模式信号。异常短的交易间隔可能指示自动化攻击，异常长的登录间隔可能表示用户流失风险。


def extract_time_delta_features(df, time_col='timestamp', group_col='user_id'):
    df = df.sort_values([group_col, time_col])
    ts = pd.to_datetime(df[time_col])

    df['time_delta_seconds'] = ts.groupby(df[group_col]).diff().dt.total_seconds()
    df['time_delta_log'] = np.log1p(df['time_delta_seconds'].fillna(0))

    delta_stats = df.groupby(group_col)['time_delta_seconds'].agg(
        ['mean', 'std', 'min', 'max', 'median']
    ).add_prefix('delta_')

    return df.merge(delta_stats, on=group_col, how='left')
滑动窗口时间统计进一步捕获近期行为趋势。例如用户"最近7天下单次数""最近30天平均消费金额""最近3小时点击次数"等特征，能够反映用户的短期兴趣变化和活跃状态。窗口大小的选择需要根据业务周期来确定：电商场景中 1/7/30 天是常见窗口，金融场景中 5/20/60 分钟是常见窗口。


空间坐标与距离特征
空间特征的提取从地理坐标开始。GPS 坐标以经度（longitude）和纬度（latitude）表示地球表面的位置，但直接使用经纬度作为特征存在两个问题：一是经纬度在不同地区的尺度含义不同（赤道附近 1 度经度约 111 公里，高纬度地区可能只有几十公里）；二是两点之间的实际距离不等于经纬度差的欧氏距离。


Haversine 公式是计算地球表面两点间大圆距离的标准方法，它考虑了地球的曲率：


from math import radians, cos, sin, asin, sqrt

def haversine(lon1, lat1, lon2, lat2):
    lon1, lat1, lon2, lat2 = map(radians, [lon1, lat1, lon2, lat2])
    dlon = lon2 - lon1
    dlat = lat2 - lat1
    a = sin(dlat/2)**2 + cos(lat1) * cos(lat2) * sin(dlon/2)**2
    c = 2 * asin(sqrt(a))
    r = 6371
    return c * r

def add_distance_features(df, poi_lat, poi_lon):
    df['dist_to_poi'] = df.apply(
        lambda row: haversine(row['lon'], row['lat'], poi_lon, poi_lat), axis=1
    )
    df['dist_log'] = np.log1p(df['dist_to_poi'])
    df['dist_bucket'] = pd.cut(df['dist_to_poi'],
                                bins=[0, 1, 3, 5, 10, 20, 50, float('inf')],
                                labels=[0, 1, 2, 3, 4, 5, 6])
    return df
距离分桶是一种常用的特征工程技巧，将连续距离值离散化为若干区间。分桶边界的选择应基于业务含义：外卖场景中 0-1km、1-3km、3-5km、5km+ 是自然的配送距离分段。

区域编码与空间聚合
GeoHash 和 H3 是两种主流的空间编码体系，它们将连续的地理坐标离散化为可索引的区域编码，支持高效的空间查询和聚合统计。


GeoHash 将经纬度交替二进制编码后用 Base32 表示为字符串。GeoHash 的前缀匹配特性使得共享相同前缀的编码对应空间上邻近的区域。编码长度越长，代表的区域越精细：5位 GeoHash 约对应 4.9km × 4.9km 的格子，7位约对应 153m × 153m。


import geohash2

def add_geohash_features(df, precision=6):
    df['geohash'] = df.apply(
        lambda row: geohash2.encode(row['lat'], row['lon'], precision), axis=1
    )

    for p in range(3, precision + 1):
        df[f'geohash_{p}'] = df['geohash'].str[:p]

    geo_stats = df.groupby(f'geohash_{precision}').agg(
        geo_count=('geohash', 'count'),
        geo_mean_price=('price', 'mean'),
        geo_std_price=('price', 'std')
    ).reset_index()

    return df.merge(geo_stats, on=f'geohash_{precision}', how='left')
H3 是 Uber 开发的六边形全球网格系统，相比 GeoHash 的矩形网格，六边形网格具有各向同性的优势——每个格子到其所有相邻格子的距离相等，消除了矩形网格中对角线方向距离偏大的问题。H3 的分辨率从 0（全球一个格子）到 15（约 0.5m² 精度）共 16 级。


空间聚合统计将区域编码与数据指标结合，生成反映区域特征的统计量。例如"该 GeoHash 区域内的平均客单价""该 H3 格子中过去一小时的订单密度""该区域的商户数量"等。这些特征帮助模型学习空间维度上的分布规律和区域差异。


空间自相关性（Spatial Autocorrelation）描述的是"地理上相近的事物往往更相似"的 Tobler 地理学第一定律。Moran's I 指数是度量空间自相关性的经典指标，正值表示空间聚集（高值聚高值，低值聚低值），负值表示空间分散，接近零表示随机分布。


时空交叉特征
时空交叉特征是将时间维度和空间维度进行组合，捕获"特定时间在特定地点"的联合模式。这类特征在需求预测、交通流量预测和动态定价等场景中至关重要。


def extract_spatiotemporal_features(df, time_col='timestamp',
                                     geohash_col='geohash_5'):
    ts = pd.to_datetime(df[time_col])
    df['hour'] = ts.dt.hour
    df['day_of_week'] = ts.dt.dayofweek

    df['geo_hour'] = df[geohash_col] + '_' + df['hour'].astype(str)
    df['geo_dow'] = df[geohash_col] + '_' + df['day_of_week'].astype(str)

    geo_hour_stats = df.groupby('geo_hour').agg(
        geo_hour_count=('geo_hour', 'count'),
        geo_hour_avg_amount=('amount', 'mean')
    ).reset_index()

    geo_dow_stats = df.groupby('geo_dow').agg(
        geo_dow_count=('geo_dow', 'count'),
        geo_dow_avg_amount=('amount', 'mean')
    ).reset_index()

    df = df.merge(geo_hour_stats, on='geo_hour', how='left')
    df = df.merge(geo_dow_stats, on='geo_dow', how='left')

    return df
轨迹特征是从用户移动序列中提取的时空特征。一条轨迹是按时间排序的位置点序列，从中可以提取总行程距离、平均速度、最大速度、停留点数量、停留时长分布等丰富特征。轨迹简化算法（如 Douglas-Peucker）可以在保留轨迹形状特征的前提下减少噪声点。

在工程实践中，时空交叉特征容易引发特征爆炸问题。区域编码 × 时间段的组合数可能达到百万级，其中大量组合的样本量极少，统计不可靠。解决方案包括：降低空间分辨率（使用更粗的 GeoHash）、合并低频时段（如将 24 小时合并为早高峰/平峰/晚高峰/深夜四段）、以及使用贝叶斯平滑对低频组合的统计量进行收缩估计。


小结
    

  • 时间特征包含日历特征、周期编码和时间差特征三个层次，分别捕获时间位置、周期性和事件间隔信息
    • 

  • 周期编码使用正弦余弦变换解决周期边界不连续问题，是处理小时、星期几、月份等特征的标准方法
    • 

  • 时间差特征和滑动窗口统计能够刻画用户的行为频率和近期趋势，在风控和推荐场景中效果显著
    • 

  • 空间特征需要考虑地球曲率，Haversine 公式是计算两点距离的标准方法
    • 

  • GeoHash 和 H3 是两种主流的区域编码方案，六边形的 H3 在各向同性上优于矩形的 GeoHash
    • 

  • 空间聚合统计将区域编码与业务指标结合，生成反映区域特征的数值
    • 

  • 时空交叉特征通过组合时间段和区域编码捕获联合分布模式，但需警惕特征爆炸问题
    • 

  • 轨迹特征从移动序列中提取距离、速度和停留模式，是出行和物流场景的核心特征
    •
