包裹式与嵌入式特征选择

核心概念

包裹式（Wrapper）和嵌入式（Embedded）特征选择是过滤式方法之外的两种更精细的特征选择范式。包裹式方法以模型性能作为评估标准，通过反复训练模型来搜索最优特征子集；嵌入式方法则将特征选择融入模型训练过程本身，在学习模型参数的同时自动完成特征筛选。两者在选择精度和计算效率之间形成互补。

理解三种范式的边界和适用条件是特征选择工程中的关键决策。在实际项目中，通常采用分层策略：先用过滤式方法缩小特征空间到可管理的规模，再用嵌入式或包裹式方法精选最终特征子集。


前向选择与后向消除
前向选择（Forward Selection）从空集开始，每一步将最能提升模型性能的特征加入候选集，直到性能不再提升或达到预设特征数量。后向消除（Backward Elimination）从全集开始，每一步移除对模型性能影响最小的特征，直到性能开始显著下降。


from sklearn.model_selection import cross_val_score
from sklearn.linear_model import LogisticRegression
import numpy as np

def forward_selection(X, y, estimator=None, max_features=50, cv=5):
    if estimator is None:
        estimator = LogisticRegression(max_iter=1000)

    selected = []
    remaining = list(range(X.shape[1]))
    best_score = 0
    history = []

    for step in range(max_features):
        best_feat = None
        for feat in remaining:
            candidate = selected + [feat]
            score = cross_val_score(
                estimator, X[:, candidate], y, cv=cv, scoring='roc_auc'
            ).mean()
            if score > best_score:
                best_score = score
                best_feat = feat

        if best_feat is None:
            break

        selected.append(best_feat)
        remaining.remove(best_feat)
        history.append({'step': step, 'feature': best_feat, 'score': best_score})

    return selected, history

def backward_elimination(X, y, estimator=None, min_features=10, cv=5):
    if estimator is None:
        estimator = LogisticRegression(max_iter=1000)

    remaining = list(range(X.shape[1]))
    base_score = cross_val_score(
        estimator, X, y, cv=cv, scoring='roc_auc'
    ).mean()
    history = [{'step': 0, 'n_features': len(remaining), 'score': base_score}]

    while len(remaining) > min_features:
        worst_feat = None
        best_score = 0

        for feat in remaining:
            candidate = [f for f in remaining if f != feat]
            score = cross_val_score(
                estimator, X[:, candidate], y, cv=cv, scoring='roc_auc'
            ).mean()
            if score > best_score:
                best_score = score
                worst_feat = feat

        if best_score < base_score * 0.995:
            break

        remaining.remove(worst_feat)
        base_score = best_score
        history.append({
            'step': len(history),
            'removed': worst_feat,
            'n_features': len(remaining),
            'score': best_score
        })

    return remaining, history
前向选择的时间复杂度为 O(d2⋅T)O(d^2 \cdot T)O(d2⋅T)（ddd 为特征数，TTT 为单次模型训练时间），后向消除同样如此。当特征数量达到数百个时，两者的计算成本都非常高。双向搜索（Bidirectional Search）结合了前向选择和后向消除：每步先尝试添加最优特征，再尝试移除最差特征，在某些情况下可以跳出局部最优。

递归特征消除
递归特征消除（Recursive Feature Elimination, RFE）是最广泛使用的包裹式方法。它的核心思想是利用模型的特征重要性指标，每轮训练后移除重要性最低的一批特征，然后在剩余特征上重新训练模型，如此递归直到达到目标特征数量。


from sklearn.feature_selection import RFE, RFECV
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier

def rfe_selection(X, y, n_features=50, step=5):
    estimator = RandomForestClassifier(n_estimators=100, random_state=42)
    rfe = RFE(
        estimator=estimator,
        n_features_to_select=n_features,
        step=step
    )
    rfe.fit(X, y)

    ranking = rfe.ranking_
    selected_mask = rfe.support_
    return X[:, selected_mask], ranking

def rfecv_selection(X, y, step=5, cv=5, min_features=10):
    estimator = GradientBoostingClassifier(
        n_estimators=100, max_depth=5, random_state=42
    )
    rfecv = RFECV(
        estimator=estimator,
        step=step,
        cv=cv,
        scoring='roc_auc',
        min_features_to_select=min_features,
        n_jobs=-1
    )
    rfecv.fit(X, y)

    optimal_n = rfecv.n_features_
    cv_scores = rfecv.cv_results_['mean_test_score']
    return X[:, rfecv.support_], optimal_n, cv_scores
RFECV（RFE with Cross-Validation）是 RFE 的增强版本，它在递归消除过程中使用交叉验证来评估每个特征数量下的模型性能，自动确定最优特征数量而无需人工指定。RFECV 生成的性能曲线可以直观展示特征数量与模型性能的关系，帮助理解特征的边际贡献。


RFE 的关键参数 step 控制每轮消除的特征数量。step=1 最精确但最慢，step 设为总特征数的 5%-10% 可以在精度和速度之间取得平衡。基模型的选择也至关重要：随机森林和梯度提升树能够提供可靠的特征重要性排序，线性模型通过系数绝对值提供排序，SVM 通过权重向量提供排序。


L1 正则化与稀疏方法
L1 正则化（Lasso）是最经典的嵌入式特征选择方法。它在损失函数中添加权重的 L1 范数惩罚项，迫使模型将不重要特征的权重精确压缩为零，从而实现自动特征选择。


from sklearn.linear_model import LassoCV, LogisticRegressionCV
from sklearn.preprocessing import StandardScaler

def lasso_feature_selection(X, y, task='regression'):
    scaler = StandardScaler()
    X_scaled = scaler.fit_transform(X)

    if task == 'regression':
        model = LassoCV(
            cv=5,
            alphas=np.logspace(-4, 1, 50),
            max_iter=10000,
            random_state=42
        )
        model.fit(X_scaled, y)
        coef = model.coef_
        best_alpha = model.alpha_
    else:
        model = LogisticRegressionCV(
            cv=5,
            penalty='l1',
            solver='saga',
            Cs=np.logspace(-3, 2, 50),
            max_iter=10000,
            random_state=42
        )
        model.fit(X_scaled, y)
        coef = model.coef_[0]
        best_alpha = 1 / model.C_[0]

    selected = np.where(np.abs(coef) > 1e-6)[0]
    importance = pd.DataFrame({
        'feature': range(len(coef)),
        'coefficient': coef,
        'abs_coef': np.abs(coef)
    }).sort_values('abs_coef', ascending=False)

    return selected, importance, best_alpha
弹性网络（Elastic Net）结合了 L1 和 L2 正则化的优势。纯 L1 正则化在高度相关的特征组中倾向于只保留一个，丢弃其余；弹性网络通过 L2 项的"分组效应"（Group Effect）使得相关特征倾向于获得相似的权重，从而保留更多信息。混合比例参数 l1_ratio 控制 L1 和 L2 的权重配比。

Stability Selection 通过在多次随机子采样上运行 Lasso，统计每个特征被选中的频率来评估其稳定性。只有在大多数子采样中都被选中的特征才被认为是真正重要的。这种方法有效控制了误选的假阳性率，理论上提供了强大的误差界保证。


树模型嵌入式选择
基于树的模型（决策树、随机森林、GBDT、XGBoost、LightGBM）天然具备特征重要性评估能力，是最常用的嵌入式特征选择工具。树模型的特征重要性可以从两个角度衡量：分裂重要性（Impurity-based）和排列重要性（Permutation-based）。


分裂重要性统计每个特征在所有树的所有分裂节点上带来的纯度提升总和。它计算速度快但存在偏向高基数特征的问题——特征的取值越多，被选为分裂点的机会越大，即使它可能只是噪声。


from sklearn.ensemble import GradientBoostingClassifier
from sklearn.inspection import permutation_importance
import pandas as pd

def tree_based_selection(X, y, feature_names=None, top_k=50):
    model = GradientBoostingClassifier(
        n_estimators=200, max_depth=5, learning_rate=0.1,
        subsample=0.8, random_state=42
    )
    model.fit(X, y)

    impurity_imp = model.feature_importances_

    perm_result = permutation_importance(
        model, X, y, n_repeats=10, random_state=42, n_jobs=-1
    )
    perm_imp = perm_result.importances_mean

    if feature_names is None:
        feature_names = [f'f{i}' for i in range(X.shape[1])]

    importance_df = pd.DataFrame({
        'feature': feature_names,
        'impurity_importance': impurity_imp,
        'permutation_importance': perm_imp,
        'perm_std': perm_result.importances_std
    }).sort_values('permutation_importance', ascending=False)

    top_features = importance_df.head(top_k)['feature'].tolist()
    feature_indices = [feature_names.index(f) for f in top_features]

    return X[:, feature_indices], importance_df
排列重要性通过随机打乱某个特征的值然后观察模型性能的下降程度来衡量该特征的贡献。它不依赖模型内部结构，可以应用于任何模型，且不受特征基数的偏向影响。但排列重要性在存在高度相关特征时会低估每个相关特征的重要性，因为打乱其中一个后，相关特征仍然携带类似信息。


Boruta 是一种基于随机森林的全量特征选择算法。它为每个特征创建"影子特征"（Shadow Feature）——将原始特征值随机打乱得到的伪特征。然后训练随机森林并比较每个原始特征的重要性是否显著超过所有影子特征的最大重要性。经过多轮统计检验后，Boruta 将特征分为"确认重要""确认不重要"和"未决"三类。

小结
    

  • 包裹式方法以模型性能为直接优化目标，选择精度高但计算成本极大，适合特征数量较少的精细选择阶段
    • 

  • 前向选择和后向消除是基本的贪心搜索策略，均无法保证全局最优，双向搜索和遗传算法可部分缓解
    • 

  • RFE 通过递归移除低重要性特征，结合 RFECV 可自动确定最优特征数量
    • 

  • L1 正则化（Lasso）通过权重稀疏化实现嵌入式特征选择，弹性网络在分组效应上优于纯 Lasso
    • 

  • Stability Selection 通过多次子采样统计选中频率，有效控制假阳性率
    • 

  • 树模型分裂重要性计算快但偏向高基数特征，排列重要性更公平但在相关特征下可能低估
    • 

  • Boruta 通过影子特征统计检验提供严格的特征显著性判断
    • 

  • 实践中推荐"过滤式初筛 → 嵌入式精选 → 包裹式验证"的三阶段特征选择流程
    •
