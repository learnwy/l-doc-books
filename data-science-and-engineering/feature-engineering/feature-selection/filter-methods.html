过滤式特征选择

核心概念

过滤式特征选择（Filter Methods）是特征选择三大范式中计算效率最高的方法。它独立于任何机器学习模型，仅通过统计指标评估每个特征与目标变量之间的关联强度，然后按得分排序选取前 K 个特征。过滤式方法的核心优势在于速度快、可扩展性强，适合作为特征选择的第一道筛选环节。

过滤式方法的局限性在于它独立评估每个特征，忽略了特征之间的交互效应。两个单独看起来无用的特征组合在一起可能具有很强的预测能力（XOR 问题即为典型案例）。因此，过滤式方法通常作为初筛手段，后续再配合包裹式或嵌入式方法进行精细选择。


方差与相关性过滤
方差阈值是最简单的无监督特征过滤策略。如果一个特征在所有样本上的取值几乎相同（方差接近零），那么它不携带任何区分性信息，应当直接移除。对于布尔特征，方差阈值等价于频率阈值：方差为 p(1−p)p(1-p)p(1−p) 的伯努利分布中，如果某个取值的占比超过 95%，则该特征的区分度极低。


from sklearn.feature_selection import VarianceThreshold, SelectKBest
from sklearn.feature_selection import f_classif, mutual_info_classif
import numpy as np
import pandas as pd

def variance_filter(X, threshold=0.01):
    selector = VarianceThreshold(threshold=threshold)
    X_filtered = selector.fit_transform(X)
    mask = selector.get_support()
    return X_filtered, mask

def correlation_filter(X, y, method='pearson', top_k=50):
    df = pd.DataFrame(X)
    df['target'] = y

    if method == 'pearson':
        corr = df.corr()['target'].drop('target').abs()
    elif method == 'spearman':
        corr = df.corr(method='spearman')['target'].drop('target').abs()

    top_features = corr.nlargest(top_k).index.tolist()
    return df[top_features].values, top_features
Pearson 相关系数衡量两个变量之间的线性关系强度，取值范围 [-1, 1]。当特征与目标之间存在严格线性关系时，Pearson 相关系数能够准确捕获。但如果关系是非线性的（如二次函数、阶梯函数），Pearson 相关系数可能接近零，导致误判为无关特征。


Spearman 秩相关系数是 Pearson 相关系数在秩空间上的推广，它衡量两个变量之间的单调关系。即使关系不是线性的，只要是单调递增或单调递减的，Spearman 系数就能给出较高的得分。相比 Pearson，Spearman 对异常值更鲁棒，因为它只关注排序而非绝对数值。


多重共线性是高维特征集中的常见问题。当多个特征高度相关时，它们携带冗余信息，不仅浪费存储和计算资源，还会导致线性模型的系数不稳定。VIF（方差膨胀因子）是检测多重共线性的标准指标，VIF 值大于 10 通常被视为严重共线性的信号。


def remove_collinear_features(X, threshold=0.95):
    corr_matrix = pd.DataFrame(X).corr().abs()
    upper_tri = corr_matrix.where(
        np.triu(np.ones(corr_matrix.shape), k=1).astype(bool)
    )
    to_drop = [col for col in upper_tri.columns
               if any(upper_tri[col] > threshold)]
    return np.delete(X, to_drop, axis=1), to_drop
互信息与信息论方法
互信息（Mutual Information）是信息论中衡量两个随机变量之间依赖关系的指标，它能够捕获任意形式的统计依赖，不局限于线性或单调关系。互信息的数学定义为：


I(X;Y)=∑x∈X∑y∈Yp(x,y)log⁡p(x,y)p(x)p(y)I(X; Y) = \sum_{x \in X} \sum_{y \in Y} p(x, y) \log \frac{p(x, y)}{p(x)p(y)}I(X;Y)=x∈X∑​y∈Y∑​p(x,y)logp(x)p(y)p(x,y)​
互信息为零当且仅当两个变量完全独立，值越大表示依赖关系越强。对于连续变量，互信息通过 KNN 估计器（如 Kraskov 方法）进行近似计算。


from sklearn.feature_selection import mutual_info_classif, mutual_info_regression

def mutual_info_filter(X, y, task='classification', top_k=50, n_neighbors=5):
    if task == 'classification':
        mi_scores = mutual_info_classif(
            X, y, n_neighbors=n_neighbors, random_state=42
        )
    else:
        mi_scores = mutual_info_regression(
            X, y, n_neighbors=n_neighbors, random_state=42
        )

    mi_df = pd.DataFrame({
        'feature': range(X.shape[1]),
        'mi_score': mi_scores
    }).sort_values('mi_score', ascending=False)

    top_features = mi_df.head(top_k)['feature'].tolist()
    return X[:, top_features], mi_df

def conditional_mutual_info(X, y, z):
    mi_xy = mutual_info_classif(X, y, random_state=42)
    mi_xy_given_z = mutual_info_classif(
        np.column_stack([X, z]), y, random_state=42
    )[:X.shape[1]]
    return mi_xy - mi_xy_given_z
信息增益（Information Gain）是互信息在决策树特征选择中的应用形式。决策树的每次分裂选择信息增益最大的特征，等价于选择与目标变量互信息最大的特征。信息增益比（Gain Ratio）通过除以特征自身的熵来校正信息增益对多值特征的偏向。

mRMR（Minimum Redundancy Maximum Relevance）是一种结合相关性和冗余性的互信息特征选择方法。它不仅要求每个选入的特征与目标变量有高互信息（最大相关性），还要求与已选特征之间的互信息尽可能低（最小冗余性），从而选出信息互补的特征子集。


统计检验方法
统计检验是过滤式特征选择的另一大支柱，它通过假设检验的框架评估特征与目标变量之间是否存在显著的统计关联。不同的数据类型和目标变量类型对应不同的统计检验方法。


卡方检验（Chi-squared Test）适用于分类特征与分类目标变量之间的关联度量。它基于特征-目标的列联表，比较观测频数与期望频数之间的偏差。卡方统计量越大，说明特征与目标之间的关联越强，越不可能是独立的。


ANOVA F 检验适用于数值特征与分类目标变量之间的关联度量。它比较同一特征在不同目标类别下的均值差异：如果某个特征在不同类别中的均值差异显著大于组内方差，则该特征对分类有较强的区分能力。


from sklearn.feature_selection import chi2, f_classif, SelectKBest
from scipy.stats import ks_2samp

def statistical_test_filter(X, y, test='f_classif', k=50):
    if test == 'f_classif':
        selector = SelectKBest(f_classif, k=k)
    elif test == 'chi2':
        selector = SelectKBest(chi2, k=k)
    elif test == 'mutual_info':
        selector = SelectKBest(mutual_info_classif, k=k)

    X_selected = selector.fit_transform(X, y)
    scores = selector.scores_
    pvalues = selector.pvalues_ if hasattr(selector, 'pvalues_') else None

    return X_selected, scores, pvalues

def ks_test_filter(X, y, alpha=0.05):
    selected = []
    for i in range(X.shape[1]):
        positive = X[y == 1, i]
        negative = X[y == 0, i]
        stat, p_value = ks_2samp(positive, negative)
        if p_value < alpha:
            selected.append(i)
    return X[:, selected], selected
KS 检验（Kolmogorov-Smirnov Test）是风控领域常用的特征筛选方法。它比较某个特征在正负样本中的分布差异：KS 统计量等于两个累积分布函数之间的最大距离。KS 值越大，说明该特征对正负样本的区分能力越强。金融风控中通常要求 KS ≥ 0.2 才认为特征有效。

信用评分特征





WoE（Weight of Evidence）和 IV（Information Value）是信用评分模型中最经典的特征评估指标。WoE 衡量每个特征分箱中好坏样本的分布差异，IV 则是所有分箱 WoE 的加权汇总。IV 的经验阈值为：< 0.02 无预测力，0.02-0.1 弱预测力，0.1-0.3 中等预测力，> 0.3 强预测力。


多变量过滤与冗余消除
单变量过滤方法独立评估每个特征，无法发现特征之间的冗余和互补关系。多变量过滤方法通过引入特征间的交互信息来弥补这一缺陷，在保持计算效率的同时提升特征子集的整体质量。


CFS（Correlation-based Feature Selection）是经典的多变量过滤算法，它的目标函数同时考虑特征与目标的相关性和特征之间的冗余性。CFS 选择的特征子集满足"高特征-目标相关性 + 低特征间相关性"的准则。


def cfs_score(X, y, feature_indices):
    k = len(feature_indices)
    if k == 0:
        return 0

    X_sub = pd.DataFrame(X[:, feature_indices])
    X_sub['target'] = y
    corr = X_sub.corr().abs()

    rcf = corr['target'].drop('target').mean()

    feature_corr = corr.drop('target', axis=0).drop('target', axis=1)
    rff = feature_corr.values[np.triu_indices(k, k=1)].mean() if k > 1 else 0

    merit = (k * rcf) / np.sqrt(k + k * (k - 1) * rff)
    return merit

def forward_cfs(X, y, max_features=50):
    selected = []
    remaining = list(range(X.shape[1]))
    best_score = 0

    for _ in range(max_features):
        best_feat = None
        for feat in remaining:
            candidate = selected + [feat]
            score = cfs_score(X, y, candidate)
            if score > best_score:
                best_score = score
                best_feat = feat

        if best_feat is None:
            break
        selected.append(best_feat)
        remaining.remove(best_feat)

    return selected, best_score
FCBF（Fast Correlation-Based Filter）是一种快速多变量过滤算法，它使用对称不确定性（Symmetrical Uncertainty）作为相关性度量，通过两步筛选实现高效的特征选择：第一步选出与目标变量高度相关的特征，第二步在候选集中移除被其他特征"支配"（即冗余度高于相关度）的特征。


特征聚类是另一种消除冗余的策略。将高度相关的特征聚为一组，每组选取一个代表特征（如与目标相关性最高的特征）。常用的聚类方法包括基于相关系数矩阵的层次聚类和基于互信息矩阵的谱聚类。


小结
    

  • 过滤式方法通过统计指标独立评估特征，计算效率高，适合大规模特征集的初步筛选
    • 

  • 方差阈值和共线性过滤是数据预处理阶段的必备步骤，可快速消除无信息和冗余特征
    • 

  • Pearson 相关系数仅捕获线性关系，Spearman 秩相关可捕获单调关系，互信息可捕获任意依赖
    • 

  • 互信息是理论上最通用的过滤指标，但计算成本高于相关系数，且需要合理设置 KNN 参数
    • 

  • 统计检验（卡方、ANOVA、KS）提供了假设检验框架下的特征评估，在金融风控中广泛应用
    • 

  • WoE/IV 是信用评分模型的标准特征筛选工具，IV 阈值提供了直观的特征预测力判断
    • 

  • mRMR 和 CFS 等多变量方法同时考虑相关性和冗余性，选出的特征子集质量优于单变量方法
    • 

  • 实践中推荐采用"方差过滤 → 共线性消除 → 统计检验/互信息排序 → 多变量精筛"的分层策略
    •
