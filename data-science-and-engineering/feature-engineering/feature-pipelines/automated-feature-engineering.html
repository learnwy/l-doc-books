自动化特征工程

核心概念

自动化特征工程（Automated Feature Engineering, AutoFE）是将传统手工特征构造过程中的探索、生成和选择步骤自动化的技术体系。手工特征工程高度依赖领域经验和反复实验，是数据科学项目中最耗时的环节之一。AutoFE 通过算法驱动的方式系统性地搜索特征空间，大幅降低人力成本并发现人类难以想到的有效特征组合。

自动化特征工程并非完全替代人工特征工程，而是在两个层面提供价值：一是发现人类不容易想到的特征组合（如多表关联后的高阶聚合），二是大规模并行地探索特征空间，缩短特征工程的迭代周期。最终的特征集通常是自动生成特征和手工设计特征的混合。


深度特征合成
深度特征合成（Deep Feature Synthesis, DFS）是 Featuretools 库实现的核心算法，它自动地在关系数据库的实体-关系图上进行递归的特征聚合与变换操作，生成大量候选特征。DFS 的"深度"指的是特征合成的递归层数，每增加一层深度就在上一层特征基础上应用更多的聚合和变换操作。


import featuretools as ft
import pandas as pd

def auto_feature_synthesis(orders_df, customers_df, products_df,
                            max_depth=2, max_features=100):
    es = ft.EntitySet(id='ecommerce')

    es = es.add_dataframe(
        dataframe_name='orders',
        dataframe=orders_df,
        index='order_id',
        time_index='order_date'
    )
    es = es.add_dataframe(
        dataframe_name='customers',
        dataframe=customers_df,
        index='customer_id'
    )
    es = es.add_dataframe(
        dataframe_name='products',
        dataframe=products_df,
        index='product_id'
    )

    es = es.add_relationship('customers', 'customer_id', 'orders', 'customer_id')
    es = es.add_relationship('products', 'product_id', 'orders', 'product_id')

    feature_matrix, feature_defs = ft.dfs(
        entityset=es,
        target_dataframe_name='customers',
        max_depth=max_depth,
        max_features=max_features,
        trans_primitives=['month', 'weekday', 'num_words'],
        agg_primitives=['mean', 'sum', 'count', 'std', 'max', 'min',
                        'percent_true', 'num_unique', 'trend'],
        where_primitives=['mean', 'count'],
        n_jobs=-1
    )

    return feature_matrix, feature_defs
DFS 的核心参数包括聚合原语（agg_primitives）、变换原语（trans_primitives）和最大递归深度（max_depth）。聚合原语定义了如何将子表的多行数据汇总为父表的单个特征值（如 mean、sum、count）；变换原语定义了如何对单个特征进行变换（如 month 从日期中提取月份）。深度为 2 意味着可以生成"子表聚合结果的再聚合"这样的二阶特征。

DFS 生成的特征名具有自然语言可读性（如 MEAN(orders.amount)、STD(orders.WEEKDAY(order_date))），这是相比深度学习方法的显著优势。但 DFS 的局限在于它只能发现基于预定义操作符的特征，无法学习任意复杂的非线性变换。


时序与交叉特征自动提取
tsfresh 是时序数据自动特征提取的标准工具，它为每条时间序列自动计算数百个统计特征、频域特征和信息论特征，然后通过假设检验自动筛选与目标变量显著相关的特征。


from tsfresh import extract_features, select_features
from tsfresh.utilities.dataframe_functions import impute
from tsfresh.feature_extraction import ComprehensiveFCParameters, MinimalFCParameters

def auto_time_series_features(df, id_col='id', time_col='time',
                                value_col='value', y=None,
                                extraction_settings='efficient'):
    if extraction_settings == 'comprehensive':
        settings = ComprehensiveFCParameters()
    elif extraction_settings == 'minimal':
        settings = MinimalFCParameters()
    else:
        settings = {
            'mean': None,
            'standard_deviation': None,
            'maximum': None,
            'minimum': None,
            'median': None,
            'variance': None,
            'skewness': None,
            'kurtosis': None,
            'abs_energy': None,
            'mean_abs_change': None,
            'count_above_mean': None,
            'longest_strike_above_mean': None,
            'autocorrelation': [{'lag': lag} for lag in [1, 5, 10]],
            'partial_autocorrelation': [{'lag': lag} for lag in [1, 5]],
            'fft_coefficient': [{'coeff': c, 'attr': 'real'} for c in range(5)],
        }

    features = extract_features(
        df,
        column_id=id_col,
        column_sort=time_col,
        column_value=value_col,
        default_fc_parameters=settings,
        n_jobs=-1
    )

    features = impute(features)

    if y is not None:
        features = select_features(features, y)

    return features
OpenFE 是近年来兴起的交叉特征自动搜索框架，专门针对表格数据生成有效的二元交叉特征。它通过对特征对进行算术运算（加、减、乘、除）和聚合运算，结合 LightGBM 增量评估来快速筛选出对模型性能有正向提升的特征组合。


def openfe_style_cross_features(X, y, feature_names, top_k=50):
    import itertools
    from sklearn.model_selection import cross_val_score
    from sklearn.ensemble import GradientBoostingClassifier

    base_model = GradientBoostingClassifier(n_estimators=50, max_depth=3, random_state=42)
    base_score = cross_val_score(base_model, X, y, cv=3, scoring='roc_auc').mean()

    candidates = []
    ops = {
        'add': lambda a, b: a + b,
        'sub': lambda a, b: a - b,
        'mul': lambda a, b: a * b,
        'div': lambda a, b: a / (b + 1e-8),
    }

    for (i, j) in itertools.combinations(range(X.shape[1]), 2):
        for op_name, op_func in ops.items():
            new_feat = op_func(X[:, i], X[:, j]).reshape(-1, 1)
            X_aug = np.hstack([X, new_feat])
            score = cross_val_score(base_model, X_aug, y, cv=3, scoring='roc_auc').mean()
            gain = score - base_score
            if gain > 0.001:
                candidates.append({
                    'feature_1': feature_names[i],
                    'feature_2': feature_names[j],
                    'operation': op_name,
                    'gain': gain,
                    'new_score': score
                })

    candidates.sort(key=lambda x: x['gain'], reverse=True)
    return candidates[:top_k]
tsfresh 的 Comprehensive 模式可以为每条时间序列提取超过 700 个特征，但其中大量是冗余或噪声特征。内置的 FDR（False Discovery Rate）控制机制通过 Benjamini-Hochberg 过程自动筛选显著特征，通常将特征数量缩减到原来的 10-20%。


遗传编程与进化搜索
遗传编程（Genetic Programming, GP）将特征工程建模为符号回归问题：每个候选特征是一棵表达式树，通过进化算法（选择、交叉、变异）在表达式空间中搜索最优特征。GP 的独特优势在于它可以发现任意复杂度的非线性特征表达式，且结果具有数学可解释性。


from gplearn.genetic import SymbolicTransformer
import numpy as np

def genetic_feature_engineering(X, y, n_features=20, generations=20,
                                  population_size=2000):
    gp = SymbolicTransformer(
        generations=generations,
        population_size=population_size,
        hall_of_fame=n_features,
        n_components=n_features,
        function_set=['add', 'sub', 'mul', 'div', 'sqrt', 'log', 'abs'],
        parsimony_coefficient=0.01,
        max_samples=0.8,
        tournament_size=20,
        init_depth=(2, 4),
        metric='spearman',
        random_state=42,
        n_jobs=-1
    )

    gp.fit(X, y)
    gp_features = gp.transform(X)

    programs = []
    for program in gp._best_programs:
        programs.append({
            'expression': str(program),
            'fitness': program.fitness_,
            'depth': program.depth_,
            'length': program.length_
        })

    return gp_features, programs
简约性系数（parsimony_coefficient）是遗传编程中控制特征复杂度的关键参数。它在适应度函数中对表达式长度施加惩罚，防止进化过程产生过于复杂的特征表达式（膨胀问题）。较大的简约性系数倾向于产生简短但可解释的表达式，较小的系数允许产生更复杂但可能更准确的特征。

深度学习驱动的特征学习
深度学习方法通过端到端的方式自动学习数据的隐含表示，无需人工定义特征变换规则。自编码器（AutoEncoder）是最基础的无监督特征学习方法，它将高维输入压缩为低维隐层表示，然后再重构原始输入。隐层向量即为自动学习到的特征。


import torch
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset

class FeatureAutoEncoder(nn.Module):
    def __init__(self, input_dim, encoding_dim=32):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 128),
            nn.ReLU(),
            nn.BatchNorm1d(128),
            nn.Dropout(0.2),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.BatchNorm1d(64),
            nn.Linear(64, encoding_dim),
            nn.ReLU()
        )
        self.decoder = nn.Sequential(
            nn.Linear(encoding_dim, 64),
            nn.ReLU(),
            nn.BatchNorm1d(64),
            nn.Linear(64, 128),
            nn.ReLU(),
            nn.BatchNorm1d(128),
            nn.Linear(128, input_dim)
        )

    def forward(self, x):
        encoded = self.encoder(x)
        decoded = self.decoder(encoded)
        return decoded, encoded

    def extract_features(self, x):
        self.eval()
        with torch.no_grad():
            return self.encoder(x)

def train_autoencoder(X, encoding_dim=32, epochs=100, batch_size=256, lr=1e-3):
    tensor_x = torch.FloatTensor(X)
    dataset = TensorDataset(tensor_x, tensor_x)
    loader = DataLoader(dataset, batch_size=batch_size, shuffle=True)

    model = FeatureAutoEncoder(X.shape[1], encoding_dim)
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    criterion = nn.MSELoss()

    model.train()
    for epoch in range(epochs):
        total_loss = 0
        for batch_x, _ in loader:
            decoded, encoded = model(batch_x)
            loss = criterion(decoded, batch_x)
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            total_loss += loss.item()

    features = model.extract_features(tensor_x).numpy()
    return features, model
Entity Embedding 是处理高基数分类特征的深度学习方法。传统的 One-Hot 编码在类别数超过数百时会产生极其稀疏的高维向量，而 Entity Embedding 将每个类别映射到一个低维稠密向量，类似于 NLP 中的词嵌入。Embedding 向量可以提取出来作为下游模型的输入特征。


变分自编码器（VAE）在标准自编码器基础上引入概率隐空间，隐层不再是确定性向量而是一个正态分布。VAE 学到的隐空间更平滑、更有结构，生成的特征在降维和聚类任务上通常优于标准自编码器。去噪自编码器（DAE）通过在输入中添加噪声迫使网络学习更鲁棒的特征表示。


小结
    

  • 自动化特征工程通过算法驱动的方式系统性地探索特征空间，补充而非替代人工特征工程
    • 

  • DFS 基于关系图的递归聚合生成可解释的高阶特征，max_depth 和原语选择是关键参数
    • 

  • tsfresh 自动提取时序统计特征并通过 FDR 控制筛选，Comprehensive 模式可提取 700+ 特征
    • 

  • OpenFE 等交叉特征搜索工具通过增量评估高效发现有效的二元特征组合
    • 

  • 遗传编程在符号表达式空间中进化搜索，生成的特征具有数学可解释性
    • 

  • 自编码器和 Entity Embedding 通过深度学习自动学习隐含表示，适合高维和高基数特征
    • 

  • 实践中推荐混合策略：DFS/tsfresh 生成候选 → 特征选择筛选 → GP/DL 补充特殊特征
    • 

  • 自动化特征工程的输出需要经过领域专家审查，确保生成的特征具有业务可解释性
    •
