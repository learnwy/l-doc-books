数据类型与编码

核心概念

数据类型编码是特征工程的基础操作——将原始数据转化为机器学习算法能够处理的数值表示。不同的数据类型（数值型、分类型、序数型、文本型、时间型）需要不同的编码策略，选择错误的编码方式会引入虚假的数学关系或丢失重要信息。编码的本质是在保留语义信息的前提下，将非数值数据映射到数值空间。

分类特征编码
分类特征编码是特征工程中最常见的操作，不同的编码方法适用于不同的场景和算法。


Label 编码与 Ordinal 编码


Label 编码将每个类别映射为一个整数。它的优势是简单高效、不增加维度，但隐含了类别间的顺序关系——"红色=0，蓝色=1，绿色=2"暗示了红色<蓝色<绿色，这在大多数情况下是无意义的。对于树模型（决策树、随机森林、GBDT），Label 编码通常不会造成问题，因为树模型的分裂操作不依赖数值的顺序关系。但对于线性模型和 KNN 等基于距离的算法，Label 编码会引入错误的距离度量。


Ordinal 编码适用于确实有自然顺序的分类变量（如教育程度：小学<初中<高中<本科<硕士<博士），映射值应该反映类别间的合理间距。


One-Hot 编码


One-Hot 编码将每个类别扩展为一个独立的二值维度。对于 N 个类别的变量，生成 N 个（或 N-1 个，避免多重共线性）二值特征。One-Hot 是无序分类变量最标准的编码方式，保证了类别间的等距性，不引入虚假的顺序关系。


One-Hot 的主要局限是高基数场景下的维度爆炸——一个包含 10000 个城市的字段会生成 10000 个新特征。高维稀疏特征会增加模型的过拟合风险和计算成本。对于树模型，高基数 One-Hot 编码还会导致分裂偏向——算法倾向于选择类别多的变量进行分裂。


Target 编码


Target 编码（Mean Target Encoding）将每个类别替换为该类别下目标变量的均值。例如，在二分类任务中，将城市"北京"编码为北京用户的平均转化率 0.12。Target 编码的优势是信息密度高（将类别与目标的关系直接编码到一个数值中）、维度不增加。


Target 编码的核心风险是过拟合——特别是样本量少的类别，其目标均值估计不稳定。缓解策略包括：交叉验证编码（在 k-fold 中，用 k-1 折的数据计算编码值应用于第 k 折）、贝叶斯平滑（将类别均值与全局均值做加权平均，样本量越少全局均值权重越高）和噪声添加（在编码值上添加随机扰动）。

数值特征变换
虽然数值特征可以直接输入模型，但适当的变换可以显著提升模型性能。


分布变换


许多统计方法和机器学习算法假设特征服从正态分布（或至少是对称分布）。对于偏态分布的数值特征，对数变换（Log Transform）是最常用的矫正方法。对于包含零值的数据，使用 log(1+x) 避免无穷大。Box-Cox 变换是对数变换的泛化，通过优化参数 λ 找到最接近正态的变换。Yeo-Johnson 变换进一步支持了负值数据。


分桶/离散化


将连续数值转化为离散区间（分桶/Binning）是一种常见的变换策略。等宽分桶将数值范围等分为固定宽度的区间，等频分桶确保每个区间包含相同数量的样本。基于决策树的分桶利用监督信息找到最优的分割点，信息增益最大化的分桶结果通常比无监督方法更有预测价值。


分桶的主要价值是：处理非线性关系（将线性模型无法捕捉的非线性转化为分桶后的阶梯函数）、提高鲁棒性（降低异常值的影响）和增加可解释性（"高价值用户"比"客单价>500 元"更直觉）。


时间特征编码
时间数据包含丰富的信息，但原始时间戳对模型来说几乎无用。将时间戳分解为多个有意义的特征是时间编码的核心思路。


多维分解


一个时间戳可以分解为：年、月、日、小时、分钟、星期几、是否周末、是否节假日、月中第几周、一年中的第几天等多个维度。每个维度捕捉了不同粒度的时间模式——"星期几"捕捉了工作日/周末的行为差异，"小时"捕捉了一天内的活跃时段。


周期编码


时间的周期性（如一天中的小时、一年中的月份）不适合直接用整数编码——因为 23 点和 0 点在整数上差 23，但在实际时间上只差 1 小时。正弦/余弦编码通过 sin(2πx/period) 和 cos(2πx/period) 将周期性特征映射到连续的圆形空间，正确保留了周期边界的连续性。


时间差特征


与绝对时间相比，相对时间差往往更有预测价值。"距上次购买 15 天"比"上次购买日期 2024-03-15"包含更多的行为信息。常用的时间差特征包括：距今天数（Recency）、距上次行为的间隔、行为频率（每月平均次数）和行为加速度（频率的变化率）。


小结
    

  • 数据类型编码是将非数值数据映射到数值空间的基础操作，选择正确的编码方式至关重要
    • 

  • 分类特征编码需要根据基数、有序性和目标模型选择合适的方法
    • 

  • Target 编码信息密度高但需要防止过拟合，交叉验证编码和贝叶斯平滑是标准缓解策略
    • 

  • 数值特征的分布变换和分桶可以提升线性模型的性能和特征的鲁棒性
    • 

  • 时间特征应通过多维分解和周期编码提取丰富的时间模式
    • 

  • 编码方式的选择应考虑下游模型的特性——树模型和线性模型对编码的敏感度不同
    •
