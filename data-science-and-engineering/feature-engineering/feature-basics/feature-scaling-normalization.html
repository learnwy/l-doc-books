特征缩放与归一化

核心概念

特征缩放（Feature Scaling）是将不同量级的数值特征转化为可比较的尺度的过程。在原始数据中，不同特征的值域可能相差数个数量级——年龄范围 0-100，收入范围 0-1000000，转化率范围 0-1。如果不进行缩放，数值大的特征会在基于距离的算法中主导计算，梯度下降的收敛速度会因特征尺度差异而严重减慢。特征缩放的本质是消除量纲差异，让模型能够公平地对待每个特征。

StandardScaler 标准化
StandardScaler（Z-score 标准化）将特征转化为均值为 0、标准差为 1 的分布。这是最常用的缩放方法，也是许多算法的默认推荐。


工作原理


StandardScaler 的变换公式为 z = (x - μ) / σ，其中 μ 是训练集的均值，σ 是训练集的标准差。变换后的特征具有零均值和单位方差，这意味着不同特征在数值尺度上变得可比较。


对于近正态分布的数据，标准化后约 68% 的数据落在 [-1, 1] 范围内，约 95% 落在 [-2, 2] 范围内，约 99.7% 落在 [-3, 3] 范围内。这个特性使得标准化后的数值可以直观地解读为"偏离均值几个标准差"。


适用场景与限制


StandardScaler 在以下场景中表现最佳：特征近似正态分布，没有极端异常值，使用基于梯度的优化算法（线性回归、逻辑回归、神经网络、SVM）。


其主要限制是对异常值敏感——少数极端值会显著影响均值和标准差的计算，导致大部分正常数据被压缩到很小的范围内。在这种情况下，RobustScaler 是更好的选择。


实践注意事项


最关键的实践规则是：缩放参数（μ 和 σ）必须从训练集计算，然后应用于训练集和测试集。绝不能在全量数据上计算缩放参数——这会导致测试集信息泄露到训练过程中。在 Scikit-learn 中，Pipeline 机制确保了 fit 和 transform 的正确调用顺序。


交叉验证中的缩放同样需要注意。在 K 折交叉验证中，每一折的缩放参数应该从该折的训练部分计算，而非全量数据。Scikit-learn 的 Pipeline + cross_val_score 自动处理了这个问题。


MinMaxScaler 归一化
MinMaxScaler 将特征线性映射到固定范围（默认 [0, 1]），变换公式为 x' = (x - x_min) / (x_max - x_min)。


适用场景


MinMaxScaler 适用于：需要特征值在固定范围内的场景（如某些神经网络的激活函数对输入范围有要求）、特征的最大值和最小值有明确的物理含义（如概率值、百分比）、不存在极端异常值的数据。


在图像处理中，像素值的归一化（从 [0, 255] 到 [0, 1]）是 MinMaxScaler 的典型应用。在推荐系统中，将用户评分归一化到 [0, 1] 范围也是常见做法。


与 StandardScaler 的选择


如果数据近似正态分布且关心相对于均值的偏离程度，选 StandardScaler。如果需要特征值在确定的范围内（如 [0, 1]）且数据分布不太偏态，选 MinMaxScaler。如果数据包含异常值但不想删除它们，选 RobustScaler。

RobustScaler 鲁棒缩放
RobustScaler 使用中位数和四分位距（IQR）替代均值和标准差：x' = (x - Q₂) / (Q₃ - Q₁)。由于中位数和 IQR 对异常值不敏感，RobustScaler 在包含极端值的数据上表现更稳健。


鲁棒性的来源


均值受异常值的影响是 O(异常值大小/样本量)，而中位数的影响是 O(1/样本量)——中位数只关心排序位置，不关心具体数值。同理，IQR 只依赖于 Q1 和 Q3 的位置，不受极端值的影响。


在金融数据（收入、交易额、账户余额）和用户行为数据（访问频率、停留时间）中，偏态分布和异常值是常态。RobustScaler 在这类场景中比 StandardScaler 更可靠。


QuantileTransformer 分位数变换


QuantileTransformer 是一种更激进的鲁棒变换方法。它将每个特征的分布映射为均匀分布（output_distribution='uniform'）或正态分布（output_distribution='normal'）。变换过程基于经验累积分布函数（ECDF），对异常值完全不敏感。


QuantileTransformer 的优势是可以将任意分布的数据转化为目标分布，消除偏度和异常值的影响。劣势是变换是非线性的，可能改变特征间的关系结构，且在小样本上分位数估计不稳定。


缩放在不同模型中的影响
理解缩放对不同模型的影响，是做出正确缩放决策的基础。


线性模型


线性回归和逻辑回归的系数受特征尺度直接影响。如果不缩放，收入（万元级）的系数会比年龄（十级）小得多，但这并不意味着收入对预测的贡献小——只是尺度差异导致的。缩放后，系数的绝对值可以直接比较特征的相对重要性。正则化（L1/L2）也受尺度影响——未缩放时，惩罚项会不成比例地约束数值大的特征。


SVM 和 KNN


SVM 和 KNN 基于距离计算，对特征尺度极度敏感。未缩放时，数值范围大的特征会主导距离计算，使其他特征几乎失效。在使用这两类算法前，缩放几乎是强制的。


树模型


决策树、随机森林和 GBDT 基于特征值的排序进行分裂，不依赖特征的绝对尺度。因此，缩放对树模型的预测结果没有影响。但在某些使用场景中（如比较特征重要性、可视化特征分布），缩放仍然有辅助价值。


深度学习


神经网络的训练基于梯度下降，特征尺度差异会导致梯度在不同维度上的幅度差异巨大，使得训练不稳定或收敛缓慢。Batch Normalization 和 Layer Normalization 在网络内部实现了隐式的缩放，但输入特征的预缩放仍然有助于训练的稳定性和收敛速度。


小结
    

  • 特征缩放消除量纲差异，让模型公平对待每个特征，是基于距离和梯度的模型的必要预处理
    • 

  • StandardScaler 适合近正态分布，MinMaxScaler 适合需要固定范围的场景，RobustScaler 适合有异常值的数据
    • 

  • 缩放参数必须从训练集计算并应用于测试集，防止数据泄露
    • 

  • 树模型对缩放不敏感，但线性模型、SVM、KNN 和神经网络对缩放高度敏感
    • 

  • QuantileTransformer 可以将任意分布转化为目标分布，是处理极端偏态数据的有力工具
    • 

  • 选择缩放方法时需综合考虑数据分布、异常值情况和下游模型的特性
