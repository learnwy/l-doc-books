遥感数据处理与分析

核心概念

遥感（Remote Sensing）是通过传感器获取地表信息而无需物理接触的技术。对于数据科学家而言，遥感数据是最丰富的大尺度地表观测数据源——一颗 Sentinel-2 卫星每 5 天就能覆盖全球一次，产生的数据量以 PB 为单位。理解遥感数据的获取原理和处理方法，可以将分析能力从城市级别的 POI 数据扩展到全球级别的地表变化监测。

遥感传感器记录的是地表反射或发射的电磁辐射。不同的地物（植被、水体、建筑、裸土）在不同波长段的反射率不同——这正是遥感能区分地物的物理基础。可见光波段让我们看到地表的颜色，近红外波段对植被特别敏感（健康植被强烈反射近红外），热红外波段记录地表温度，微波波段可以穿透云层和夜间工作。

影像预处理流程
原始卫星影像需要经过一系列预处理步骤才能用于定量分析。预处理的目标是消除传感器、大气和地形因素的影响，使不同时间、不同传感器的影像具有可比性。


辐射校正将传感器记录的数字数值（DN, Digital Number）转换为有物理意义的量——辐射亮度（Radiance）或表观反射率（TOA Reflectance）。这个转换需要传感器的标定参数，通常包含在影像的元数据文件中。


大气校正进一步将表观反射率转换为地表反射率（Surface Reflectance）。大气中的气溶胶、水汽和气体会散射和吸收阳光，导致传感器接收到的信号不完全反映地表真实状态。大气校正模型（如 6S、FLAASH、Sen2Cor）利用大气参数模拟这些影响并从信号中去除。

云覆盖是光学遥感的最大敌人。全球平均云覆盖率约 67%，热带地区更高。处理云覆盖的策略包括：使用云掩膜排除有云区域、对多期无云影像进行合成（Compositing）取最优像元、使用 SAR 数据（不受云影响）替代或补充。


Google Earth Engine（GEE）革命性地简化了遥感数据处理。传统流程需要下载 TB 级数据到本地处理，GEE 将计算移到数据旁边——用户通过 JavaScript 或 Python API 编写分析脚本，计算在 Google 的云基础设施上执行。GEE 的数据目录包含了 Landsat、Sentinel、MODIS 等主要卫星的完整历史档案。


遥感指数与分类
遥感指数（Spectral Index）是将多个波段的反射率组合为单一数值的数学表达式，用于突出特定地物特征。最经典的遥感指数是 NDVI（归一化植被指数），它利用植被在近红外和红光波段的反射率差异来量化植被覆盖度。


NDVI = (NIR - Red) / (NIR + Red)，取值范围 -1 到 1。密集植被的 NDVI 通常在 0.6-0.9，稀疏植被 0.2-0.5，裸土接近 0，水体通常为负值。


影像分类将遥感影像中的每个像元分配到预定义的地物类别中。分类方法分为监督分类（需要训练样本）和非监督分类（自动聚类）。


监督分类的主流方法已经从传统的最大似然分类转向机器学习方法。随机森林（Random Forest）是当前遥感分类中使用最广泛的机器学习算法——它对训练样本的数量和质量不太敏感，能处理高维特征（多波段+多指数+纹理特征），且支持特征重要性评估。深度学习（CNN、U-Net）在高分辨率影像分类中表现更优，但需要大量标注数据。

变化检测是遥感的杀手级应用之一。通过比较不同时间的影像或分类结果，可以识别地表变化——城市扩张、森林砍伐、洪水范围、农作物生长。变化检测方法包括：影像差值法（两期影像相减）、分类后比较（两期分类结果对比）、时间序列分析（检测 NDVI 等指数的突变点）。


时间序列遥感分析
时间序列遥感利用卫星的重复观测能力，构建地表某一指标（如 NDVI）随时间变化的曲线，从中提取物候信息、检测趋势变化和异常事件。


NDVI 时间序列在农业监测中的应用最为成熟。作物生长季的 NDVI 曲线呈现「倒U型」——从播种期的低值上升到生长旺盛期的峰值再下降到收获期的低值。通过分析曲线的峰值时间、峰值高度、生长季长度等参数，可以监测作物长势、预估产量、检测干旱影响。


时间序列重建是应对云覆盖和数据缺失的核心技术。Savitzky-Golay 滤波是最常用的时间序列平滑方法，它在保持曲线主要特征的同时去除噪声和异常值。HANTS（Harmonic Analysis of Time Series）用傅里叶级数拟合时间序列，特别适合具有强季节性的植被数据。


BFAST（Breaks For Additive Season and Trend）算法是时间序列变化检测的代表性方法。它将时间序列分解为趋势分量、季节分量和残差分量，然后检测趋势和季节模式中的突变点。BFAST 可以区分「渐变」（长期趋势变化，如气候变化导致的物候移动）和「突变」（突然事件，如森林火灾或城市开发）。
