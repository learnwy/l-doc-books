网络分析与路径规划

核心概念

网络分析（Network Analysis）是在图结构上进行的空间分析，它将道路、管线、河流等线状地理要素抽象为由节点（Node）和边（Edge）组成的网络图，然后在这个图上解决路径规划、可达性评估、资源分配等问题。与纯粹的图论不同，地理网络分析需要考虑真实的空间约束——道路的物理长度、单行线限制、交通信号灯延迟、时变通行速度。

网络分析在商业场景中有广泛应用：外卖配送的路径优化、物流网络的站点选址、医院急救的服务覆盖、城市交通的拥堵分析。这些问题的共同特征是：决策需要考虑「通过网络到达」的真实距离而非直线距离。

道路网络建模
真实道路网络的建模远比教科书中的简单图复杂。道路有方向（单行线）、有速度限制、有转向限制（禁止左转）、有时变特性（早晚高峰速度不同），这些约束都需要在网络模型中正确表达。


OpenStreetMap（OSM）是全球最大的开源道路网络数据源。它的道路数据包含丰富的属性：道路等级（highway 标签）、车道数、速度限制、通行方向。但 OSM 数据的质量因地区而异——北美和欧洲的覆盖度极高，部分发展中国家可能存在缺失和错误。


将 OSM 数据转化为可路由的网络图需要专门的处理流程。OSMnx 是 Python 中最流行的 OSM 网络分析库，它可以直接从 OSM 下载指定区域的道路网络，构建 NetworkX 图对象，并提供最短路径、等时线等分析功能。


interface RoadEdge {
  source: number;
  target: number;
  length: number;
  maxSpeed: number;
  travelTime: number;
  oneway: boolean;
  roadClass: 'motorway' | 'primary' | 'secondary' | 'residential';
}

function estimateTravelTime(length: number, roadClass: string): number {
  const speedMap: Record<string, number> = {
    motorway: 100,
    primary: 60,
    secondary: 40,
    residential: 30,
  };
  const speed = speedMap[roadClass] ?? 30;
  return (length / 1000 / speed) * 60;
}
网络拓扑的正确性对路径分析结果至关重要。常见的拓扑问题包括：道路交叉处缺少节点（两条路在画面上交叉但网络上不连通）、悬挂端点（道路末端没有连接到网络）、重复边（同一段路被编码了两次）。QGIS 和 PostGIS 都提供了拓扑检查和修复工具。


权重函数的选择直接决定了「最优路径」的含义。以距离为权重得到最短路径，以时间为权重得到最快路径，以通行费为权重得到最便宜路径。实际应用中通常使用时间权重——用户关心的是「多久能到」而非「距离多远」。时间权重需要考虑路段的速度限制、实时交通状况和信号灯等待。


等时线与可达性分析
等时线（Isochrone）是从一个起点出发，在给定时间内所能到达的所有区域的边界。它是服务区分析的核心输出，直观地展示了「从这里出发，10分钟/20分钟/30分钟能到哪里」。


等时线的计算本质上是一个截断的 Dijkstra 搜索：从起点开始，沿网络扩展搜索，当累计时间超过阈值时停止。搜索结束后，所有被访问的节点构成可达区域，对这些节点进行凸包或凹包计算得到等时线边界。


多模式等时线考虑不同交通方式的组合。例如「步行15分钟+地铁+步行10分钟」的可达范围。多模式分析需要将不同交通网络（步行网络、公交网络、地铁网络）整合为一个多层网络，换乘点是连接不同层的关键节点。


等时线在选址决策中的应用非常直接。评估一个新门店位置时，计算其15分钟驾车等时线，然后与人口数据做空间连接，可以估算该门店的潜在服务人口。通过比较多个候选位置的等时线覆盖人口，可以量化选址方案的优劣。


可达性指数将等时线分析扩展为全域评估。对于研究区域内的每个网格单元，计算到最近设施（医院、学校、超市）的旅行时间，生成「到最近XX的时间」热力图。这是公共服务均等化评估和城市规划的核心工具。

车辆路径问题（VRP）
车辆路径问题（Vehicle Routing Problem, VRP）是网络分析中最具商业价值也最具计算挑战的问题。它的基本形式是：给定一组车辆和一组需要服务的客户，如何规划每辆车的路线使得总成本最小？


VRP 是 NP-hard 问题，大规模实例（数百个客户、数十辆车）无法在可接受时间内找到精确最优解。实际应用中使用启发式和元启发式算法来寻找近似最优解。


主流的 VRP 求解策略包括：构造启发式（如最近邻插入、Clarke-Wright 节约算法）快速生成初始可行解，然后用局部搜索（2-opt、or-opt、relocate）改进解的质量。更高级的元启发式如自适应大邻域搜索（ALNS）和遗传算法可以在更大的搜索空间中寻找更优解。


OSRM（Open Source Routing Machine）和 Valhalla 是两个主流的开源路由引擎，支持大规模网络上的快速最短路径和距离矩阵计算。它们预处理道路网络为紧凑的图结构，使得单次路径查询可以在毫秒级完成。VRP 求解通常先用路由引擎预计算所有客户之间的距离/时间矩阵，然后在这个矩阵上运行 VRP 算法。


Google OR-Tools 是最成熟的开源 VRP 求解框架，支持带时间窗、带容量约束、带取送货对、带车辆类型差异等各种 VRP 变体。它的 Routing 模块封装了高质量的搜索策略，用户只需定义约束和目标函数。


小结
    

  • 网络分析在图结构上解决路径规划和可达性问题，考虑真实空间约束
    • 

  • OSM 是全球最大的开源道路网络数据源，OSMnx 可直接构建可路由网络图
    • 

  • 权重函数决定「最优」的含义——距离权重得最短路径，时间权重得最快路径
    • 

  • 等时线是从起点出发固定时间内的可达边界，选址决策的核心分析工具
    • 

  • 可达性指数量化了空间上获取服务的便利程度，是城市规划的关键指标
    • 

  • VRP 是 NP-hard 问题，实践中使用构造启发式 + 局部搜索的组合策略
    • 

  • OSRM/Valhalla 提供毫秒级路径查询，是 VRP 距离矩阵预计算的基础
    • 

  • Google OR-Tools 是最成熟的开源 VRP 求解框架，支持多种约束变体
