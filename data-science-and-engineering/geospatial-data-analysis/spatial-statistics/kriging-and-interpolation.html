克里金与空间插值

核心概念

空间插值（Spatial Interpolation）利用已知采样点的值估算未采样位置的值。克里金（Kriging）是最经典的地统计插值方法，它不仅给出最优预测值，还提供预测不确定性的估计。克里金的核心思想是利用空间自相关结构（通过变异函数描述）来确定最优的加权组合。

变异函数分析
变异函数（Variogram）描述空间自相关随距离变化的规律，是克里金的理论基石。实验变异函数通过计算所有点对的半方差来估计：


import numpy as np
from pykrige.ok import OrdinaryKriging

def experimental_variogram(coords, values, n_lags=15):
    n = len(values)
    pairs = []
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt((coords[i, 0] - coords[j, 0])**2 +
                          (coords[i, 1] - coords[j, 1])**2)
            gamma = 0.5 * (values[i] - values[j])**2
            pairs.append((dist, gamma))

    pairs = np.array(pairs)
    max_dist = pairs[:, 0].max() / 2
    lag_edges = np.linspace(0, max_dist, n_lags + 1)

    lags, semivariances = [], []
    for k in range(n_lags):
        mask = (pairs[:, 0] >= lag_edges[k]) & (pairs[:, 0] < lag_edges[k + 1])
        if mask.sum() > 0:
            lags.append((lag_edges[k] + lag_edges[k + 1]) / 2)
            semivariances.append(pairs[mask, 1].mean())
    return np.array(lags), np.array(semivariances)
变异函数的三个关键参数决定了空间自相关的结构特征：


块金效应（Nugget）：变异函数在距离趋近于零时的截距，反映微尺度随机变异和测量误差。块金值越大，短距离内数据点之间的相关性越低。


偏基台（Partial Sill）：变异函数从块金值增长到基台值的增量，反映空间结构性变异的幅度。偏基台与块金之和为基台（Sill）。


变程（Range）：变异函数达到基台时的距离，超过变程的点对之间不再存在空间自相关。变程决定了空间插值的有效影响范围。

模型选择应基于实验变异函数的形态：如果半方差在短距离内快速增长然后趋平，球面模型适合；如果增长更平缓且渐近趋近基台，指数模型适合；如果半方差在零距离附近增长非常缓慢（近似抛物线形），高斯模型适合。


普通克里金
from pykrige.ok import OrdinaryKriging

ok = OrdinaryKriging(
    x, y, values,
    variogram_model='spherical',
    verbose=False,
    enable_plotting=False,
)

grid_x = np.linspace(x.min(), x.max(), 100)
grid_y = np.linspace(y.min(), y.max(), 100)

z_pred, z_var = ok.execute('grid', grid_x, grid_y)
z_std = np.sqrt(z_var)
普通克里金假设区域化变量的均值未知但恒定，通过构建克里金方程组求解最优权重，使预测方差最小化且满足无偏约束。克里金方差不依赖于观测值本身——只取决于点的空间分布和变异函数参数，这意味着即使不知道实际观测值也能评估采样设计的质量。


泛克里金（Universal Kriging）放松了均值恒定的假设，允许均值随空间位置呈多项式趋势变化。适用于存在明显空间趋势的数据，如海拔随纬度递变或污染浓度随距离源递减。


IDW 反距离加权
def idw_interpolation(known_coords, known_values, target_coord, power=2):
    distances = np.sqrt(np.sum((known_coords - target_coord)**2, axis=1))
    if np.any(distances == 0):
        return known_values[distances == 0][0]
    weights = 1.0 / distances**power
    return np.sum(weights * known_values) / np.sum(weights)
IDW 的幂参数控制距离衰减的速度：幂值越大，近邻点的影响越强，结果越局部化；幂值越小，远处点的影响越大，结果越平滑。幂值为 0 时退化为简单均值（所有点权重相等），幂值趋向无穷时退化为最近邻插值。

交叉验证与精度评估
空间插值结果的精度评估通常采用留一交叉验证（LOOCV）：依次移除每个采样点，用剩余点进行插值预测，然后比较预测值与实际值。常用评价指标包括均方根误差（RMSE）、平均绝对误差（MAE）和决定系数（R2R^2R2）。对于克里金，还需检查标准化预测误差的均值是否接近 0、方差是否接近 1——偏离说明变异函数模型不恰当。


小结
    

  • 克里金是基于变异函数的最优线性无偏估计方法，同时提供预测值和不确定性
    • 

  • 变异函数分析是克里金的前提，需要识别块金效应、偏基台和变程三个关键参数
    • 

  • 块金效应反映微尺度变异和测量误差，变程决定空间自相关的有效范围
    • 

  • IDW 简单高效但缺乏统计理论支撑，适合快速估算；克里金适合需要不确定性评估的场景
    • 

  • 变异函数模型选择（球面/指数/高斯）应基于实验变异函数的形态和交叉验证结果
    • 

  • 留一交叉验证是空间插值精度评估的标准方法
    • 

  • 大数据量场景下可使用局部克里金或降采样策略缓解 O(n³) 的计算瓶颈
    •
