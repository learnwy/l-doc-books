地理空间回归模型

核心概念

空间回归模型在经典回归的基础上显式纳入空间依赖性和空间异质性。当观测数据具有空间自相关时，普通最小二乘法（OLS）的残差独立性假设被违反，导致系数估计偏差和推断无效。空间回归通过空间滞后项、空间误差项或地理加权方法来捕捉这些空间效应。空间回归是房价建模、公共卫生、环境科学和犯罪学等领域的核心分析工具。

空间权重矩阵
空间权重矩阵 WWW 是空间回归的核心构建模块，定义了观测单元之间的空间邻接关系。权重矩阵的选择直接影响模型结果的解释。


邻接法：Queen 邻接（共享边或顶点）和 Rook 邻接（仅共享边）。适用于面状数据（如行政区划），区域之间要么相邻（权重为 1）要么不相邻（权重为 0）。


距离法：K 最近邻（KNN）和距离阈值。KNN 保证每个观测点有固定数量的邻居，适用于点密度不均的数据。距离阈值将阈值内的所有点视为邻居，但不同区域的邻居数可能差异很大。


权重矩阵通常进行行标准化——每行权重之和为 1，使得 WyWyWy 的含义变为"邻居值的加权平均"。行标准化使空间滞后项的解释更直观，但会改变矩阵的对称性。


空间诊断检验
import numpy as np
import geopandas as gpd
from libpysal.weights import Queen
from spreg import OLS, ML_Lag, ML_Error, GM_Lag

gdf = gpd.read_file("districts.shp")
w = Queen.from_dataframe(gdf)
w.transform = 'r'

y = gdf['house_price'].values.reshape(-1, 1)
X = gdf[['income', 'school_count', 'park_area', 'distance_cbd']].values

ols = OLS(y, X, w=w, spat_diag=True,
          name_y='house_price',
          name_x=['income', 'school_count', 'park_area', 'distance_cbd'])

空间滞后模型中，β\betaβ 系数不能直接解释为"X 变化一单位时 y 的边际效应"——因为 ρWy\rho WyρWy 项引入了反馈循环（邻居的 y 变化又影响自身）。LeSage 和 Pace 提出将效应分解为直接效应（自身 X 对自身 y）和间接效应（自身 X 通过空间溢出对邻居 y 的影响）。


地理加权回归 GWR
from mgwr.gwr import GWR
from mgwr.sel_bw import Sel_BW

coords = np.column_stack([gdf.geometry.centroid.x,
                          gdf.geometry.centroid.y])

sel = Sel_BW(coords, y, X, kernel='bisquare', fixed=False)
bw = sel.search()

gwr_model = GWR(coords, y, X, bw=bw, kernel='bisquare', fixed=False)
gwr_results = gwr_model.fit()

gdf['local_r2'] = gwr_results.localR2
for i, name in enumerate(['income', 'school', 'park', 'cbd']):
    gdf[f'coef_{name}'] = gwr_results.params[:, i + 1]

GWR 的输出核心是局部系数地图——通过将每个位置的回归系数映射到地图上，直观展示回归关系的空间变化。例如在房价模型中，学校对房价的影响可能在市中心很小（因为学校密集），在郊区很大（学校稀缺使其成为差异化因素）。


多尺度 GWR（MGWR）进一步允许每个解释变量有不同的带宽，反映不同变量的空间变化尺度不同。收入的影响可能在大尺度上平滑变化，而学校的影响可能在小尺度上快速变化。

模型选择的标准流程：先用 OLS 建立基准模型，检查残差的空间自相关（Moran's I）。如果显著，运行 LM 诊断选择 SLM 或 SEM。估计空间模型后检查残差是否消除了空间自相关。最后用 AICc 比较各模型的拟合优度。如果怀疑回归关系存在空间异质性，额外运行 GWR 进行探索性分析。


小结
    

  • 空间数据的回归分析必须考虑空间自相关，否则 OLS 估计可能有偏
    • 

  • 空间权重矩阵定义邻接关系，Queen、KNN 和距离阈值是最常用的构建方法
    • 

  • LM 诊断检验是选择 SLM 还是 SEM 的标准决策流程
    • 

  • 空间滞后模型的系数需要分解为直接效应和间接效应才能正确解释
    • 

  • GWR 揭示回归关系的空间异质性，适合探索性分析和局部效应可视化
    • 

  • MGWR 允许不同变量有不同的空间变化尺度，比标准 GWR 更灵活
    • 

  • 模型选择应基于理论假设和统计诊断，AICc 是模型比较的常用标准
    •
