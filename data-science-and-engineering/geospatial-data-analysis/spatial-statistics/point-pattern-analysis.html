点模式分析

核心概念

点模式分析（Point Pattern Analysis）研究空间中点事件（如犯罪事件、商铺位置、物种出现地）的分布规律。核心问题是判断点的分布是聚类、均匀还是随机，并量化聚类的程度和尺度。点模式分析是流行病学、犯罪学、生态学和零售选址中的重要工具。

完全空间随机性基准
点模式分析的第一步是确立基准——完全空间随机（Complete Spatial Randomness, CSR）。CSR 是齐次泊松过程生成的点模式，具有两个特征：任意子区域内点数服从泊松分布（强度恒定），且各点之间相互独立（无交互作用）。


所有统计检验都是将观测到的点模式与 CSR 对比。偏离 CSR 说明存在非随机机制：聚类意味着点之间存在吸引作用（或共享环境偏好），规则/离散意味着点之间存在排斥或竞争。


判断是否偏离 CSR 通常使用蒙特卡洛模拟：在同一研究区域内生成大量 CSR 模拟，计算每次模拟的统计量，构建置信包络线。如果观测统计量落在包络线之外，则在对应显著性水平上拒绝 CSR 假设。


核密度估计
import numpy as np
import geopandas as gpd
from sklearn.neighbors import KernelDensity

points = gpd.read_file("crime_points.shp")
coords = np.column_stack([points.geometry.x, points.geometry.y])

kde = KernelDensity(bandwidth=500, kernel='gaussian', metric='euclidean')
kde.fit(coords)

x_min, y_min, x_max, y_max = points.total_bounds
xx, yy = np.meshgrid(np.linspace(x_min, x_max, 200),
                      np.linspace(y_min, y_max, 200))
grid_points = np.column_stack([xx.ravel(), yy.ravel()])

log_density = kde.score_samples(grid_points)
density = np.exp(log_density).reshape(xx.shape)

带宽选择是 KDE 最关键的参数决策。带宽过小会产生尖刺状的噪声密度面，对单个点过度敏感；带宽过大则过度平滑，掩盖了真实的密度结构。在犯罪分析等应用中，带宽的物理含义是"事件的空间影响范围"——例如 500 米的带宽意味着每个犯罪事件在方圆 500 米内产生密度贡献。


边界效应也需要特别注意。当研究区域边界附近存在点时，标准 KDE 会低估边界处的真实密度（因为核函数的一部分被截断在区域外）。修正方法包括边界核方法、反射法和消化法。


Ripley's K 函数
from pointpats import PointPattern, Genv, Kenv

pp = PointPattern(coords)

kenv = Kenv(pp, intervals=50, realizations=99)

# K(d) > 期望值 → 聚类
# K(d) < 期望值 → 离散
# K(d) ≈ 期望值 → 随机
K 函数的定义：K(d)=λ−1E[某点距离 d 内其他点的数量]K(d) = \lambda^{-1} E[\text{某点距离 d 内其他点的数量}]K(d)=λ−1E[某点距离 d 内其他点的数量]，其中 λ\lambdaλ 是点模式的整体强度（每单位面积的点数）。在 CSR 下，K(d)=πd2K(d) = \pi d^2K(d)=πd2。K(d) 高于 CSR 期望表示在距离 d 下存在聚类。


实践中常用 L 函数代替 K 函数进行可视化。L 函数定义为 L(d)=K(d)/π−dL(d) = \sqrt{K(d)/\pi} - dL(d)=K(d)/π​−d，在 CSR 下 L(d) = 0，使得偏离程度更容易观察。L(d) > 0 表示聚类，L(d) < 0 表示离散。


K 函数的一个重要优势是多尺度分析能力——它可以同时检测在不同距离尺度上的聚类或离散模式。一个点模式可能在小尺度上聚类（如商铺聚集在商业区），同时在大尺度上离散（商业区之间间隔分布）。

DBSCAN 的两个核心参数 eps（邻域半径）和 min_samples（最小点数）直接影响聚类结果。eps 过小导致大量噪声点和碎片化的小簇，eps 过大导致不同聚类被合并。可以使用 k-距离图辅助选择：对每个点计算到第 k 个最近邻的距离，按距离排序并绘图，曲线的"拐点"对应合适的 eps 值。


HDBSCAN 是 DBSCAN 的层次化扩展，只需指定 min_cluster_size 参数，通过构建互达距离树自动发现不同密度水平下的聚类结构。它对参数选择更加稳健，特别适合密度差异大的点模式。


小结
    

  • 点模式分析区分一阶（强度变化）和二阶（点间交互）两个层面
    • 

  • 完全空间随机（CSR）是所有点模式统计检验的基准
    • 

  • 核密度估计是最直观的一阶分析方法，带宽选择是结果质量的关键
    • 

  • Ripley's K 函数通过多尺度分析揭示不同距离下的聚类/离散程度
    • 

  • L 函数是 K 函数的标准化版本，在 CSR 下值为 0，更便于解读
    • 

  • DBSCAN 是空间点聚类的首选算法，不需要预设簇数且能自动识别噪声
    • 

  • 所有点模式分析方法都需要与完全空间随机（CSR）基准对比来判断显著性
    •
