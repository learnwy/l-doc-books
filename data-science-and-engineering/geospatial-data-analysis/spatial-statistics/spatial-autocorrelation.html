空间自相关分析

核心概念

空间自相关（Spatial Autocorrelation）衡量地理邻近区域的属性值之间的关联程度。Tobler 地理学第一定律指出「万物皆相关，但距离近的事物比距离远的更相关」，空间自相关分析就是对这一规律的量化检验。它是空间统计学的基础，也是判断空间聚类、离散或随机分布模式的核心工具。

Moran's I 统计量
全局 Moran's I
import numpy as np
from libpysal.weights import Queen
from esda.moran import Moran

import geopandas as gpd

gdf = gpd.read_file("districts.shp")

w = Queen.from_dataframe(gdf)
w.transform = 'r'

mi = Moran(gdf['house_price'].values, w)
print(f"Moran's I: {mi.I:.4f}")
print(f"期望值 E[I]: {mi.EI:.4f}")
print(f"Z 分数: {mi.z_norm:.4f}")
print(f"P 值: {mi.p_norm:.4f}")

# Moran's I > 0 且 P < 0.05 → 显著正空间自相关（聚类）
# Moran's I < 0 且 P < 0.05 → 显著负空间自相关（离散）
# P > 0.05 → 空间随机分布

局部空间自相关 LISA
局部 Moran's I（LISA）将全局指标分解到每个空间单元，识别局部聚类和异常值：


from esda.moran import Moran_Local
import matplotlib.pyplot as plt

lisa = Moran_Local(gdf['house_price'].values, w)

fig, axes = plt.subplots(1, 2, figsize=(16, 8))

gdf['lisa_cluster'] = lisa.q
sig = lisa.p_sim < 0.05
gdf.loc[~sig, 'lisa_cluster'] = 0

cluster_labels = {0: '不显著', 1: '高-高', 2: '低-高', 3: '低-低', 4: '高-低'}
gdf['cluster_label'] = gdf['lisa_cluster'].map(cluster_labels)

gdf.plot(column='cluster_label', categorical=True,
         legend=True, ax=axes[0], cmap='RdBu')
axes[0].set_title('LISA 聚类图')

from splot.esda import moran_scatterplot
moran_scatterplot(lisa, p=0.05, ax=axes[1])
axes[1].set_title("Moran 散点图")
plt.tight_layout()

Getis-Ord 热点分析
from esda.getisord import G_Local

g_local = G_Local(gdf['house_price'].values, w, transform='B')

gdf['z_score'] = g_local.Zs
gdf['p_value'] = g_local.p_sim

gdf['hotspot'] = 'Not Significant'
gdf.loc[(gdf['z_score'] > 1.96) & (gdf['p_value'] < 0.05), 'hotspot'] = 'Hot Spot (95%)'
gdf.loc[(gdf['z_score'] > 2.58) & (gdf['p_value'] < 0.01), 'hotspot'] = 'Hot Spot (99%)'
gdf.loc[(gdf['z_score'] < -1.96) & (gdf['p_value'] < 0.05), 'hotspot'] = 'Cold Spot (95%)'
gdf.loc[(gdf['z_score'] < -2.58) & (gdf['p_value'] < 0.01), 'hotspot'] = 'Cold Spot (99%)'
小结
    

  • 空间自相关是空间统计的基石，量化地理近邻属性值的关联程度
    • 

  • Moran's I 是最常用的全局空间自相关指标，正值表示聚类、负值表示离散
    • 

  • 空间权重矩阵的选择直接影响分析结果，需根据数据特征选择合适的邻接定义
    • 

  • LISA 将全局指标分解到局部，识别高-高、低-低聚类和高-低、低-高异常值
    • 

  • Getis-Ord Gi* 热点分析直接输出 Z 分数，适合犯罪热点、疫情聚集等场景
    • 

  • 所有空间自相关分析都需要进行统计显著性检验（通常使用蒙特卡洛置换检验）
    •
