QGIS 与桌面 GIS 工具

核心概念

QGIS（Quantum GIS）是最强大的开源桌面 GIS 软件，提供完整的地理数据可视化、编辑和分析能力。对于数据科学家和程序员来说，QGIS 不仅是一个可视化工具——它是空间数据探索、质量检查和原型验证的核心平台，在编写代码之前用 QGIS 预览数据可以避免大量的调试时间。

GIS 工具链的选择取决于工作流的不同阶段。QGIS 擅长交互式探索和可视化，PostGIS 擅长大规模查询和分析，Python/GeoPandas 擅长自动化管道——三者不是替代关系而是互补关系。理解每个工具的最佳适用场景，才能构建高效的地理空间工作流。

QGIS 的核心操作
QGIS 的界面围绕「图层」（Layer）概念组织。每个图层代表一个数据源——可以是本地文件（Shapefile、GeoJSON、GeoTIFF）、数据库连接（PostGIS、SpatiaLite）或在线服务（WMS、WFS、XYZ Tiles）。图层按顺序堆叠渲染，上层遮挡下层。


数据加载是 QGIS 的起点操作。拖拽文件到画布是最直接的方式，但对于数据库连接和在线服务，需要通过「浏览器面板」或「数据源管理器」进行配置。加载数据后第一步应该检查坐标系——QGIS 的「即时投影」（On-the-fly CRS Transformation）功能允许不同坐标系的图层叠加显示，但这只是视觉上的对齐，底层数据仍保持原始坐标系。


属性表操作是 QGIS 中最常用的功能之一。属性表以表格形式展示每个要素的非空间属性，支持排序、过滤、选择和编辑。字段计算器（Field Calculator）支持用表达式创建新字段或更新现有字段，其表达式语法类似 SQL 但扩展了空间函数。


样式设计是 QGIS 的强项。通过「图层属性→符号化」面板，可以实现：分类符号化（按属性值着色）、分级符号化（按数值范围渐变着色）、基于规则的符号化（自定义条件着色）。样式可以保存为 QML 文件复用于其他项目。


Processing 工具框架是 QGIS 的分析引擎。它整合了 QGIS 原生算法、GDAL 工具、GRASS GIS 命令和 SAGA 算法，提供超过 400 个空间分析工具。所有 Processing 工具都支持批处理和模型构建器（Graphical Modeler），允许将多个工具串联为可重复执行的工作流。


数据质量检查工作流
QGIS 是空间数据质量检查的首选工具。在将数据导入生产数据库或分析管道之前，用 QGIS 进行视觉检查可以发现许多难以通过代码自动检测的问题。


坐标系检查是第一步。加载数据后，在「图层属性→信息」中确认坐标系是否正确。常见问题包括：没有设定坐标系（缺少 .prj 文件）、坐标系设定错误（经纬度数据被标为 UTM）、中国数据的 GCJ-02 偏移。将数据叠加到 OpenStreetMap 底图上可以快速判断是否存在偏移。


几何检查使用 QGIS 的「拓扑检查器」（Topology Checker）插件。它可以检测：自相交多边形、重叠区域、间隙（Gaps）、悬挂端点（Dangles）。对于面图层，还应检查是否有微型多边形（面积接近零的碎片），这些通常是数据加工过程中的残留错误。


属性完整性检查关注：空值比例（哪些字段有大量空值）、数据类型一致性（数字字段是否混入了文本）、值域合理性（经度是否在合理范围内）。QGIS 的统计面板可以快速生成各字段的统计摘要。


Python 集成与自动化
QGIS 内置了完整的 Python 环境（PyQGIS），允许通过脚本自动化几乎所有 QGIS 操作。Python 控制台可以直接在 QGIS 中执行代码，Processing 框架允许用 Python 编写自定义分析工具。


QGIS 的 Python API 分为几个核心模块：qgis.core 提供数据模型和分析功能、qgis.gui 提供界面组件、qgis.analysis 提供高级分析算法。对于数据科学家来说，最常用的是 qgis.core 中的数据读写和 Processing 框架的自动化调用。


独立脚本（不启动 QGIS 界面）也可以使用 QGIS 的 Python 库。这在批处理和 CI/CD 管道中非常有用——可以在服务器端执行空间分析而无需图形界面。配置独立 PyQGIS 环境需要正确设置 QGIS 的库路径和 Provider 初始化。

QGIS 的 Processing 工具可以直接从 Python 调用，这是批处理的最佳方式。每个 Processing 工具都有唯一的算法 ID 和参数定义，通过 processing.run(algorithm_id, parameters) 调用。这种方式比直接使用底层 API 更简洁，也更不容易出错。


GeoPandas 和 QGIS 的数据交换非常流畅。GeoPandas 的 GeoDataFrame 可以保存为 GeoPackage 后在 QGIS 中打开预览，QGIS 编辑的数据也可以直接用 GeoPandas 读取进入 Python 分析管道。GeoPackage 是两者之间最佳的交换格式——它是单文件、支持多图层、包含坐标系信息。


小结
    

  • QGIS 是最强大的开源桌面 GIS，适合数据探索、质量检查和制图输出
    • 

  • QGIS、PostGIS、Python/GeoPandas 三者互补而非替代
    • 

  • 数据加载后第一步必须检查坐标系，叠加 OSM 底图可快速发现偏移
    • 

  • 拓扑检查器和属性统计是数据质量检查的核心工具
    • 

  • Processing 框架整合 400+ 分析工具，支持批处理和模型构建器
    • 

  • PyQGIS 允许自动化所有 QGIS 操作，支持独立脚本不需图形界面
    • 

  • GeoPackage 是 QGIS 与 Python 之间最佳的数据交换格式
