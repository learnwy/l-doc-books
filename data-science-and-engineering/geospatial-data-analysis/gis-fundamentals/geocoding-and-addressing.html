地理编码与地址解析

核心概念

地理编码（Geocoding）是将文本地址转换为地理坐标（经纬度）的过程，逆地理编码（Reverse Geocoding）则是从坐标反推地址。地理编码是位置智能的基础能力，也是空间数据分析管线中最常见的数据预处理步骤。构建一个高质量的地理编码系统需要理解地址标准化、模糊匹配、坐标系转换和服务选型。

地址标准化与解析
地址数据在实际业务中格式千差万别，标准化是地理编码的第一步：


import re

def normalize_address(raw_address):
    addr = raw_address.strip()
    addr = re.sub(r'\s+', ' ', addr)
    addr = addr.replace('号楼', '号')
    addr = addr.replace('栋', '号')

    replacements = {
        '大道': '大道', '路': '路', '街': '街',
        '弄': '弄', '巷': '巷', '里': '里',
    }

    province_pattern = r'^(北京|上海|天津|重庆|[\u4e00-\u9fa5]{2,3}(?:省|自治区))'
    city_pattern = r'([\u4e00-\u9fa5]{2,4}(?:市|州|盟))'
    district_pattern = r'([\u4e00-\u9fa5]{2,6}(?:区|县|旗|市))'
    street_pattern = r'([\u4e00-\u9fa5]{2,10}(?:路|街|道|巷|弄|里))'
    number_pattern = r'(\d+号?)'

    components = {
        'province': re.search(province_pattern, addr),
        'city': re.search(city_pattern, addr),
        'district': re.search(district_pattern, addr),
        'street': re.search(street_pattern, addr),
        'number': re.search(number_pattern, addr),
    }

    return {k: v.group() if v else '' for k, v in components.items()}

地理编码服务
主流服务对比
# 使用高德地图地理编码 API
import requests

def geocode_gaode(address, key):
    url = "https://restapi.amap.com/v3/geocode/geo"
    params = {
        "key": key,
        "address": address,
        "output": "json"
    }
    response = requests.get(url, params=params).json()
    if response["status"] == "1" and response["geocodes"]:
        loc = response["geocodes"][0]["location"].split(",")
        return {"lng": float(loc[0]), "lat": float(loc[1]),
                "level": response["geocodes"][0]["level"]}
    return None

# 批量地理编码
def batch_geocode(addresses, key, batch_size=10):
    results = []
    for addr in addresses:
        result = geocode_gaode(addr, key)
        results.append({"address": addr, "result": result})
    return results

小结
    

  • 地理编码是位置智能的基础能力，将文本地址与地理坐标相互转换
    • 

  • 地址标准化是地理编码质量的关键，需要处理格式不一致、缩写和拼写错误
    • 

  • 国内推荐高德/百度地理编码服务，海外推荐 Google Maps 或自部署 Nominatim
    • 

  • 中国特有的坐标系差异（WGS-84/GCJ-02/BD-09）必须在数据对接时正确转换
    • 

  • 批量地理编码需要考虑 API 限流、失败重试和结果缓存策略
    • 

  • 地理编码精度从省市级到门牌级不等，精度评估应纳入数据质量监控体系
