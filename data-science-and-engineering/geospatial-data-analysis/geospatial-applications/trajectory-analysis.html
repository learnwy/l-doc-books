轨迹数据分析

核心概念

轨迹数据（Trajectory Data）记录了移动对象随时间变化的位置序列。出租车的 GPS 记录、用户的手机定位历史、船舶的 AIS 信号、候鸟的标记追踪——这些都是轨迹数据。轨迹分析的核心目标是从这些时空序列中提取移动模式、理解移动行为、预测未来位置。

轨迹数据的独特性在于它同时具有空间维度和时间维度。传统的空间分析处理的是静态快照（某一时刻的地理分布），轨迹分析处理的是动态过程（位置如何随时间演变）。这种时空双重性使得轨迹分析需要同时借鉴空间统计和时间序列分析的方法。

轨迹预处理
原始轨迹数据充满噪声、缺失和异常，直接分析会产生误导性结果。轨迹预处理是所有后续分析的基础。


GPS 噪声过滤是第一步。GPS 信号在城市峡谷（高楼之间）、室内和天桥下会产生显著偏差，单个点可能偏离真实位置数十甚至数百米。滤波方法包括：中值滤波（替换异常点为邻域中值）、卡尔曼滤波（基于运动模型的最优估计）、地图匹配（将点对齐到最近的道路网络）。


地图匹配（Map Matching）是城市轨迹预处理中最关键的步骤。它将散布在道路两侧的 GPS 点「吸附」到最可能的道路路段上。高质量的地图匹配不仅修正了定位误差，还为轨迹赋予了道路网络的语义——我们可以知道车辆在哪条路上行驶，而非仅仅知道它在哪个坐标。


interface TrajectoryPoint {
  lat: number;
  lng: number;
  timestamp: number;
  speed: number;
  heading: number;
}

interface StayPoint {
  lat: number;
  lng: number;
  arrivalTime: number;
  departureTime: number;
  duration: number;
  radius: number;
}

function detectStayPoints(points: TrajectoryPoint[], distThreshold: number, timeThreshold: number): StayPoint[] {
  const stayPoints: StayPoint[] = [];
  let i = 0;
  while (i < points.length) {
    let j = i + 1;
    while (j < points.length) {
      const dist = haversineDistance(points[i].lat, points[i].lng, points[j].lat, points[j].lng);
      if (dist > distThreshold) break;
      j++;
    }
    const duration = points[j - 1].timestamp - points[i].timestamp;
    if (duration >= timeThreshold) {
      stayPoints.push({
        lat: points.slice(i, j).reduce((s, p) => s + p.lat, 0) / (j - i),
        lng: points.slice(i, j).reduce((s, p) => s + p.lng, 0) / (j - i),
        arrivalTime: points[i].timestamp,
        departureTime: points[j - 1].timestamp,
        duration,
        radius: distThreshold,
      });
    }
    i = j;
  }
  return stayPoints;
}
停留点检测（Stay Point Detection）是轨迹语义分析的入口。停留点是轨迹中移动对象在一定空间范围内停留超过一定时间的区域。停留点对应着真实世界中的有意义行为——在餐厅吃饭、在办公室工作、在商场购物。经典的停留点检测算法使用距离阈值和时间阈值两个参数：如果连续的轨迹点在距离阈值内且总时间超过时间阈值，则识别为一个停留点。


轨迹分段（Trajectory Segmentation）将一条长轨迹拆分为多个有意义的子轨迹。分段依据可以是时间间隔（两点之间时间差超过阈值则断开）、交通模式变化（从驾车变为步行）或语义事件（到达目的地后开始新的出行）。


轨迹模式挖掘
轨迹模式挖掘的目标是从大量个体轨迹中发现群体级别的移动规律。这些规律对交通规划、城市治理和商业决策有直接价值。


频繁路径挖掘识别最多人选择的移动路线。将轨迹映射到道路网络后，使用序列模式挖掘算法（如 PrefixSpan）可以找到频繁出现的路段序列。频繁路径不仅反映了城市的主要通勤走廊，还可以用于导航推荐——「这条路线是大多数人的选择」。

OD（Origin-Destination）分析是宏观交通分析的基础。将每条轨迹的起点和终点提取出来，构建城市级别的出行 OD 矩阵——从区域 A 到区域 B 有多少出行，峰值在什么时间。OD 矩阵是交通规划、公交路线设计和共享出行供需匹配的核心数据输入。


异常轨迹检测在安全和监管领域有重要应用。出租车绕路检测（轨迹与最短路径偏差过大）、船舶违规捕捞检测（进入禁渔区的轨迹）、物流配送效率监控（配送轨迹的时间和距离异常）都属于异常轨迹检测的范畴。检测方法通常基于轨迹的统计特征（总距离、平均速度、轨迹形状）或与参考轨迹的偏差度量。


轨迹可视化与交互
轨迹数据的可视化比静态空间数据更具挑战性，因为需要同时表达空间和时间两个维度。


静态轨迹图将所有轨迹叠加在地图上，用颜色编码时间或速度。密集区域会形成「道路热力图」效果。这种可视化简单直观，但在轨迹数量多时会产生严重的视觉遮挡。


动画轨迹是展示轨迹时间维度最直观的方式。移动对象在地图上随时间移动，观众可以直观地感受到移动速度、方向变化和停留行为。deck.gl 的 TripsLayer 专门为轨迹动画设计，支持百万级轨迹点的流畅动画。


时空立方体（Space-Time Cube）是同时展示空间和时间的三维可视化方法。水平面表示地理空间，垂直轴表示时间。一条轨迹在时空立方体中呈现为一条三维曲线——水平移动表示空间位移，垂直上升表示时间流逝，水平段（垂直线）表示停留。时空立方体特别适合展示少量轨迹的详细时空结构。


隐私保护是轨迹数据分析的重要伦理考量。个体轨迹数据是高度敏感的个人信息——从轨迹中可以推断出一个人的家庭地址、工作地点、社交关系、健康状况。在分析和发布轨迹数据时，必须采取隐私保护措施：空间模糊化（降低坐标精度）、时间扰动（随机偏移时间戳）、K-匿名化（确保每条轨迹至少与 K-1 条其他轨迹相似）。
