空间机器学习

核心概念

空间机器学习（Spatial Machine Learning）是将机器学习方法应用于具有地理空间属性的数据。与传统机器学习不同，空间机器学习必须显式处理数据的空间依赖性和空间异质性——忽视这两个特性会导致模型过拟合、预测偏差和错误的特征重要性评估。

空间依赖性（Spatial Dependence）指的是地理上接近的观测值倾向于更相似——这违反了传统 ML 假设的样本独立性。空间异质性（Spatial Heterogeneity）指的是变量之间的关系在不同地理位置可能不同——一个特征在城市中心可能是强预测因子，在郊区可能毫无预测力。

空间特征工程
空间特征工程是空间机器学习中最关键且最具创造性的环节。它将原始的地理坐标和空间数据转化为模型可以理解的数值特征。


距离特征是最基础的空间特征类型。计算每个样本到特定地理实体的距离：到最近地铁站的距离、到市中心的距离、到最近水体的距离。距离特征可以使用欧几里得距离（直线）或网络距离（通过道路网络），后者在城市环境中更准确。


密度特征量化某个范围内特定实体的集中程度：500m 内的餐饮店数量、1km 内的住宅小区密度、3km 内的竞品门店密度。密度特征的关键参数是搜索半径——半径太小可能计数为零（稀疏区域），半径太大会失去空间分辨力。实践中通常测试多个半径并选择预测力最强的。


interface SpatialFeatures {
  distToNearestSubway: number;
  distToCBD: number;
  poiCount500m: number;
  poiCount1km: number;
  residentialDensity1km: number;
  competitorCount3km: number;
  avgIncome1km: number;
  roadDensity500m: number;
  greenSpaceRatio1km: number;
  elevationMean: number;
}

function extractSpatialFeatures(
  point: [number, number],
  poiIndex: SpatialIndex,
  rasterData: Map<string, RasterLayer>,
): SpatialFeatures {
  const subway = poiIndex.nearest(point, 'subway');
  const cbd = [116.461, 39.917];
  return {
    distToNearestSubway: haversineDistance(point[1], point[0], subway.lat, subway.lng),
    distToCBD: haversineDistance(point[1], point[0], cbd[1], cbd[0]),
    poiCount500m: poiIndex.withinRadius(point, 500, 'restaurant').length,
    poiCount1km: poiIndex.withinRadius(point, 1000).length,
    residentialDensity1km: poiIndex.withinRadius(point, 1000, 'residential').length,
    competitorCount3km: poiIndex.withinRadius(point, 3000, 'competitor').length,
    avgIncome1km: rasterData.get('income')!.sampleMean(point, 1000),
    roadDensity500m: rasterData.get('road')!.sampleSum(point, 500),
    greenSpaceRatio1km: rasterData.get('green')!.sampleMean(point, 1000),
    elevationMean: rasterData.get('dem')!.sampleAt(point),
  };
}
邻域聚合特征利用周围样本的属性来丰富每个样本的表示。例如，计算每个网格的「邻居平均房价」「邻居最大订单量」「邻居房价方差」。这种特征显式编码了空间自相关信息，让模型能够利用「近朱者赤」的空间规律。


位置编码是一个需要谨慎处理的特征。直接将经纬度作为特征输入模型看似合理，但实际上会导致「位置泄露」——模型可能仅凭坐标就能学到训练数据中的空间模式，而非学到真正的因果关系。更好的做法是用空间特征（距离、密度、邻域聚合）替代原始坐标，或者使用空间嵌入（如 Hex2Vec、Space2Vec）将位置编码为低维向量。


空间交叉验证
传统的随机交叉验证在空间数据上会严重高估模型性能。原因是空间自相关导致训练集和测试集中相邻的样本高度相似——测试集中的样本可以从训练集中的「邻居」获得信息泄露，模型不需要真正学会泛化就能在测试集上表现良好。


空间块交叉验证（Spatial Block Cross-Validation）将研究区域划分为空间块，以块为单位分配到训练集和测试集。这确保了训练样本和测试样本之间有空间距离，模拟了模型对新区域的预测能力。


缓冲区交叉验证在空间块的基础上进一步添加了隔离带——训练块和测试块之间的缓冲区内的样本被丢弃，确保更严格的空间隔离。缓冲区宽度应该基于数据的空间自相关范围来设定——使用变异函数（Variogram）可以估算空间自相关的有效距离。

图神经网络在空间分析中的应用
图神经网络（Graph Neural Network, GNN）是空间机器学习的前沿方向。它将空间数据天然的图结构（区域为节点，邻接或连接为边）直接编码到模型架构中，让模型自动学习空间依赖模式。


在交通流量预测中，道路网络天然是一个图——交叉口是节点，路段是边。时空图卷积网络（ST-GCN）在图的空间维度上做图卷积（聚合邻居信息），在时间维度上做序列建模（LSTM 或 Temporal Convolution），实现了对交通流量时空模式的联合建模。


在城市功能区识别中，城市被划分为网格单元，每个单元是一个节点，相邻单元之间连边。节点特征包括 POI 分布、人口特征、建筑类型。GNN 通过消息传递机制聚合邻居信息，自动学习到「一个区域的功能不仅由自身特征决定，还受周围区域影响」的空间规律。


空间嵌入（Spatial Embedding）是将地理位置编码为低维稠密向量的技术。类似 Word2Vec 将词语映射到语义空间，空间嵌入将位置映射到「位置语义空间」——功能相似的位置在嵌入空间中距离更近。Location2Vec、Hex2Vec 等方法使用 POI 共现、人流模式或遥感影像来学习空间嵌入，生成的向量可以作为下游 ML 模型的特征。


GNN 在空间领域的局限性也需要认识到：空间图通常非常大（百万级节点），训练效率是一个挑战；空间关系不像社交网络那样有明确的连边，邻接图的构建方式会显著影响结果；GNN 的可解释性较差，在需要理解「为什么」的业务场景中可能不如 GWR 等可解释模型。


小结
    

  • 空间 ML 必须处理空间依赖性（近处更相似）和空间异质性（关系因地而异）
    • 

  • 空间特征工程包括距离特征、密度特征和邻域聚合特征三大类
    • 

  • 直接用经纬度作为特征会导致位置泄露，应用空间特征或空间嵌入替代
    • 

  • 随机交叉验证在空间数据上严重高估性能，必须使用空间块或缓冲区 CV
    • 

  • 缓冲区宽度应基于变异函数估算的空间自相关距离来设定
    • 

  • GNN 将空间数据的图结构直接编码到模型中，适合交通预测和区域分析
    • 

  • 空间嵌入将位置映射到语义空间，功能相似的位置距离更近
    • 

  • GNN 在大规模空间图上的训练效率和可解释性是当前的主要局限
