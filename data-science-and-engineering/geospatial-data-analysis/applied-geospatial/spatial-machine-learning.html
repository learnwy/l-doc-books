空间机器学习

核心概念

空间机器学习（Spatial Machine Learning）将地理空间特征和空间关系融入机器学习模型，解决传统 ML 方法忽略空间依赖性和空间异质性的问题。空间数据的核心挑战在于观测值之间不独立（空间自相关），直接使用随机分割的交叉验证会导致信息泄漏和过于乐观的性能评估。

空间特征工程
import geopandas as gpd
import numpy as np
from sklearn.neighbors import BallTree

gdf = gpd.read_file("data.shp")
coords = np.column_stack([gdf.geometry.centroid.y, gdf.geometry.centroid.x])
coords_rad = np.radians(coords)

tree = BallTree(coords_rad, metric='haversine')

def spatial_features(gdf, tree, coords_rad, radii=[1000, 3000, 5000]):
    features = {}
    for r in radii:
        r_rad = r / 6371000
        indices = tree.query_radius(coords_rad, r=r_rad)
        for col in ['price', 'population']:
            values = gdf[col].values
            features[f'{col}_mean_{r}m'] = [
                values[idx].mean() if len(idx) > 1 else values[i]
                for i, idx in enumerate(indices)
            ]
            features[f'{col}_std_{r}m'] = [
                values[idx].std() if len(idx) > 1 else 0
                for i, idx in enumerate(indices)
            ]
    return features

空间交叉验证
from sklearn.model_selection import GroupKFold
import numpy as np

def spatial_block_cv(coords, n_splits=5):
    x_edges = np.linspace(coords[:, 0].min(), coords[:, 0].max(), n_splits + 1)
    y_edges = np.linspace(coords[:, 1].min(), coords[:, 1].max(), n_splits + 1)

    blocks = np.zeros(len(coords), dtype=int)
    for i, (x, y) in enumerate(coords):
        x_idx = min(np.searchsorted(x_edges[1:], x), n_splits - 1)
        y_idx = min(np.searchsorted(y_edges[1:], y), n_splits - 1)
        blocks[i] = (x_idx + y_idx) % n_splits

    cv = GroupKFold(n_splits=n_splits)
    return list(cv.split(coords, groups=blocks))

图神经网络与空间
import torch
from torch_geometric.data import Data
from torch_geometric.nn import GCNConv

class SpatialGNN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super().__init__()
        self.conv1 = GCNConv(in_channels, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, out_channels)

    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index).relu()
        x = self.conv2(x, edge_index)
        return x

def build_spatial_graph(coords, k=5):
    from sklearn.neighbors import NearestNeighbors
    nn = NearestNeighbors(n_neighbors=k + 1)
    nn.fit(coords)
    distances, indices = nn.kneighbors(coords)

    edges = []
    for i, neighbors in enumerate(indices[:, 1:]):
        for j in neighbors:
            edges.append([i, j])
    return torch.tensor(edges, dtype=torch.long).t()

小结
    

  • 空间机器学习的核心挑战是处理空间自相关导致的数据非独立性
    • 

  • 空间交叉验证（分块 CV、缓冲区 CV）是评估空间预测模型泛化能力的必要方法
    • 

  • 空间特征工程（邻域统计、距离特征、密度特征）是提升空间预测精度的有效手段
    • 

  • 图神经网络是建模复杂空间关系的前沿方法，将空间邻近关系编码为图结构
    • 

  • 使用空间 ML 时必须检查残差的空间自相关，确保模型已充分捕捉空间结构
