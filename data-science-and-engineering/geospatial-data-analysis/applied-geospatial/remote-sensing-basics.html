遥感数据分析基础

核心概念

遥感（Remote Sensing）是通过卫星或航空平台获取地表信息的技术。遥感数据以栅格影像的形式记录不同波段的电磁辐射，通过光谱特征分析可以识别地表覆盖类型、植被健康状况、城市扩张等信息。遥感是地球观测、环境监测和资源调查的核心技术手段。

电磁波谱与光谱特征
遥感的物理基础是地物对不同波段电磁辐射的反射、吸收和发射差异。理解光谱特征是正确解译遥感影像的前提。


植被在可见光红波段（620-690nm）有强吸收（叶绿素吸收），在近红外波段（760-900nm）有强反射（叶片细胞结构散射）——这一"红边"特征是植被遥感的基础。水体在近红外及更长波段几乎完全吸收，反射率极低。裸土在各波段的反射率相对均匀且随波长缓慢上升。城市不透水面在各波段反射率中等偏高。

遥感指数计算
植被指数
import rasterio
import numpy as np

with rasterio.open("sentinel2_B04.tif") as red_src:
    red = red_src.read(1).astype(np.float32)
    profile = red_src.profile

with rasterio.open("sentinel2_B08.tif") as nir_src:
    nir = nir_src.read(1).astype(np.float32)

ndvi = (nir - red) / (nir + red + 1e-10)

ndvi = np.clip(ndvi, -1, 1)

profile.update(dtype=rasterio.float32, count=1)
with rasterio.open("ndvi.tif", 'w', **profile) as dst:
    dst.write(ndvi, 1)

NDVI 是最基础的植被指数，但在高密度植被区域容易饱和。EVI 通过引入蓝光波段校正大气和土壤背景的影响，在高植被覆盖区域的灵敏度优于 NDVI。NDWI 利用绿光和近红外的差异有效区分水体和陆地。多指数联合分析可以更准确地分类地表覆盖类型。

分类精度评估使用混淆矩阵，从中计算总体精度（Overall Accuracy）、Kappa 系数、各类别的用户精度（User's Accuracy）和生产者精度（Producer's Accuracy）。总体精度反映整体分类质量，Kappa 系数排除了随机一致性的影响。用户精度衡量分类结果的可靠性（从结果看有多少是正确的），生产者精度衡量地物被正确识别的概率（从真实类别看有多少被找到）。

import ee
ee.Initialize()

image = ee.ImageCollection('COPERNICUS/S2_SR') \
    .filterDate('2024-06-01', '2024-08-31') \
    .filterBounds(ee.Geometry.Point([116.4, 39.9])) \
    .filter(ee.Filter.lt('CLOUDY_PIXEL_PERCENTAGE', 10)) \
    .median()

ndvi = image.normalizedDifference(['B8', 'B4']).rename('NDVI')

stats = ndvi.reduceRegion(
    reducer=ee.Reducer.mean(),

GEE 的编程模型是延迟计算（Lazy Evaluation）：代码定义计算图但不立即执行，调用 getInfo()、reduceRegion() 或导出时才触发服务端执行。这种模式要求避免在客户端循环中调用服务端计算——应尽量使用 map()、reduce() 等服务端操作保持计算在云端完成。


小结
    

  • 遥感数据通过电磁波段记录地表信息，不同波段组合可提取植被、水体和建筑等特征
    • 

  • 理解地物光谱特征是遥感影像解译的基础，红边效应是植被遥感的核心原理
    • 

  • NDVI 是最常用的植被指数，EVI 在高密度植被区域灵敏度更优
    • 

  • 影像分类分为监督和非监督两大类，随机森林是当前遥感分类的主流方法
    • 

  • 混淆矩阵和 Kappa 系数是分类精度评估的标准方法
    • 

  • Google Earth Engine 提供 PB 级遥感数据的云端分析能力，是大尺度遥感分析的首选平台
    • 

  • 遥感预处理（辐射校正、大气校正）是保证分析质量的前提步骤
    •
