位置智能

核心概念

位置智能（Location Intelligence）是将地理空间分析融入商业决策的实践。它结合地理数据、业务数据和空间分析技术，帮助企业回答「在哪里」的问题——从零售选址、物流优化到市场扩展策略。位置智能的核心价值在于将空间维度纳入传统商业分析框架，揭示数据中隐藏的地理模式和机会。

商圈与贸易区分析
Huff 引力模型
import numpy as np

def huff_model(store_areas, store_distances, alpha=1.0, beta=2.0):
    attractiveness = store_areas ** alpha
    distance_decay = store_distances ** beta
    utility = attractiveness / distance_decay
    probabilities = utility / utility.sum(axis=1, keepdims=True)
    return probabilities

store_areas = np.array([5000, 3000, 8000])
customer_distances = np.array([
    [1.0, 2.5, 3.0],
    [2.0, 1.5, 4.0],
    [3.5, 3.0, 1.0],
])

probs = huff_model(store_areas, customer_distances)
Huff 模型的两个关键参数需要根据实际业务校准：α\alphaα 控制吸引力指标（如面积）的影响强度，β\betaβ 控制距离衰减的速度。β\betaβ 值越大，消费者对距离越敏感——日常消费品（如便利店）的 β\betaβ 通常较大（2-3），而目的性消费（如家具卖场）的 β\betaβ 较小（1-2）。参数校准通常使用已知的客户来源数据进行最大似然估计。

贸易区的划定方法有多种：简单缓冲区法（等距圆形）最快但忽略了竞争和路网结构；驾驶时间等时圈更贴合实际出行行为；Huff 模型概率面则能精确反映竞争格局下每个区域的客户分流概率。


可达性分析
import osmnx as ox
import networkx as nx

G = ox.graph_from_point((39.9042, 116.4074), dist=5000, network_type='drive')

origin = ox.nearest_nodes(G, 116.4074, 39.9042)

iso_times = [5, 10, 15]  # 分钟
for time_limit in iso_times:
    subgraph = nx.ego_graph(G, origin, radius=time_limit * 60, distance='travel_time')
    nodes = list(subgraph.nodes())
    print(f"{time_limit}分钟可达节点数: {len(nodes)}")

可达性分析的精度很大程度上取决于路网数据的质量。OpenStreetMap 是最常用的开放路网数据源，但在某些区域覆盖不完整。商业路网数据（如高德、百度）通常包含更准确的通行时间和交通限制信息。


多模式出行分析需要整合不同交通方式的路网——步行网络、公交线路、地铁网络和驾车路网。GTFS（General Transit Feed Specification）是公共交通时刻表的标准数据格式，结合 OpenTripPlanner 等路由引擎可以计算多模式等时圈。


空间市场分析
import geopandas as gpd
from sklearn.cluster import KMeans

grid = gpd.read_file("city_grid.shp")

features = grid[['population_density', 'avg_income',
                  'competitor_count', 'traffic_flow']].values

kmeans = KMeans(n_clusters=5, random_state=42)
grid['segment'] = kmeans.fit_predict(features)

segment_profiles = grid.groupby('segment').agg({
    'population_density': 'mean',
    'avg_income': 'mean',
    'competitor_count': 'mean',
    'traffic_flow': 'mean',
})
空间市场分析的关键步骤：首先将城市划分为均匀网格或行政区块；然后为每个单元收集多维度特征（人口、收入、竞品、交通等）；接着使用聚类算法识别具有相似特征的区域群组；最后分析每个群组的商业潜力并与现有门店分布对比，识别过度竞争区域和空白市场机会。

  • 位置智能将空间分析融入商业决策，核心价值是揭示数据的地理维度洞察

  • Huff 引力模型是商圈分析的经典方法，平衡了设施吸引力和距离衰减效应

  • 贸易区划定从简单缓冲区到 Huff 概率面，精度逐步提升
    • 

  • 可达性分析（等时圈、最近设施距离）是选址和公共服务评估的基础工具
    • 

  • 多模式出行分析需要整合步行、公交和驾车等不同交通方式的路网数据
    • 

  • 空间市场细分结合聚类和地理空间，实现精准的区域营销策略
    • 

  • 位置数据的时效性和精度直接决定分析结论的可靠性
