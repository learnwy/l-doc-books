关系型图表

核心概念

关系型图表是数据可视化中用于揭示数据实体之间关联、相关性和网络结构的图表类型。与展示分布或趋势的图表不同，关系型图表的核心目标是回答"数据之间存在怎样的联系"这个问题。从简单的两变量散点图到复杂的多层网络图，关系型图表覆盖了从统计相关性到拓扑结构的广泛视觉表达。

关系型图表可按照关系的复杂度分为三个层次：变量关系（两个或多个数值变量之间的统计关系）、层级关系（树形或嵌套的包含关系）以及网络关系（多节点多边的复杂连接关系）。每个层次对应不同的图表类型和设计策略。

散点图与回归可视化
散点图是最基础也最强大的关系型图表，它通过将两个数值变量分别映射到 x 轴和 y 轴，用点的位置直观展示变量间的相关关系。散点图能够揭示线性相关、非线性相关、聚类结构以及异常值等多种模式。


散点图的进阶形式包括：气泡图（第三个变量映射到点的面积）、颜色编码散点图（用色彩区分类别或编码第四个变量）以及带回归线的散点图（叠加统计模型的拟合曲线）。


interface ScatterPoint {
  x: number;
  y: number;
  size?: number;
  category?: string;
}

interface RegressionResult {
  slope: number;
  intercept: number;
  rSquared: number;
}

function linearRegression(points: ScatterPoint[]): RegressionResult {
  const n = points.length;
  const sumX = points.reduce((s, p) => s + p.x, 0);
  const sumY = points.reduce((s, p) => s + p.y, 0);
  const sumXY = points.reduce((s, p) => s + p.x * p.y, 0);
  const sumX2 = points.reduce((s, p) => s + p.x ** 2, 0);
  const meanY = sumY / n;

  const slope = (n * sumXY - sumX * sumY) / (n * sumX2 - sumX ** 2);
  const intercept = (sumY - slope * sumX) / n;

  const ssRes = points.reduce((s, p) => s + (p.y - (slope * p.x + intercept)) ** 2, 0);
  const ssTot = points.reduce((s, p) => s + (p.y - meanY) ** 2, 0);
  const rSquared = 1 - ssRes / ssTot;

  return { slope, intercept, rSquared };
}
处理大规模散点图（万级以上数据点）时，直接渲染所有点会导致严重的过绘制问题。常用的解决策略包括：透明度叠加（alpha blending）让密集区域颜色更深；六边形分箱（hexbin）将点聚合到网格单元中用颜色深浅表示密度；以及密度等高线将点云转化为概率密度的等高线表示。


网络图与力导向布局
网络图是表达多实体间复杂连接关系的核心图表类型。网络图由节点（node）和边（edge）组成，节点代表实体，边代表实体间的关系。力导向布局是网络图最常用的自动布局算法，它通过模拟物理力场（弹簧力+电荷斥力）使网络达到视觉平衡。


interface GraphNode {
  id: string;
  x: number;
  y: number;
  vx: number;
  vy: number;
  group?: number;
}

interface GraphEdge {
  source: string;
  target: string;
  weight: number;
}

function applyForceIteration(nodes: GraphNode[], edges: GraphEdge[], repulsion: number, attraction: number): void {
  const nodeMap = new Map(nodes.map((n) => [n.id, n]));

  for (let i = 0; i < nodes.length; i++) {
    for (let j = i + 1; j < nodes.length; j++) {
      const dx = nodes[j].x - nodes[i].x;
      const dy = nodes[j].y - nodes[i].y;
      const dist = Math.max(Math.sqrt(dx * dx + dy * dy), 1);
      const force = repulsion / (dist * dist);
      const fx = (dx / dist) * force;
      const fy = (dy / dist) * force;
      nodes[i].vx -= fx;
      nodes[i].vy -= fy;
      nodes[j].vx += fx;
      nodes[j].vy += fy;
    }
  }

  for (const edge of edges) {
    const source = nodeMap.get(edge.source);
    const target = nodeMap.get(edge.target);
    if (!source || !target) continue;
    const dx = target.x - source.x;
    const dy = target.y - source.y;
    const dist = Math.sqrt(dx * dx + dy * dy);
    const force = (dist - 100) * attraction;
    const fx = (dx / dist) * force;
    const fy = (dy / dist) * force;
    source.vx += fx;
    source.vy += fy;
    target.vx -= fx;
    target.vy -= fy;
  }

  for (const node of nodes) {
    node.x += node.vx * 0.1;
    node.y += node.vy * 0.1;
    node.vx *= 0.9;
    node.vy *= 0.9;
  }
}
网络图的可读性高度依赖布局质量。当节点数超过 100 时，力导向布局的计算开销显著增大（O(n²) 复杂度），此时需要引入四叉树（Quadtree）或 Barnes-Hut 近似算法将复杂度降至 O(n log n)。

流量图与桑基图
桑基图是一种特殊的流量可视化图表，它通过带宽度的流线展示资源、能量或数量在多个节点之间的流动和转化。桑基图的核心视觉编码是流线的宽度与流量成正比，这使得读者可以直观比较不同路径上的流量大小。


桑基图由左向右排列多层节点，每层节点之间通过流线连接。每个节点的总入流等于总出流（除了源节点和汇节点），体现了流量守恒原则。


桑基图适用的典型场景包括：用户行为路径分析（从首页到最终转化的各步骤流量）、能源流动分析（从产出到消耗的能源分配）、预算分配可视化（从总预算到各部门子项的分配流向）以及人口迁移可视化。


桑基图的常见陷阱是层级过多或节点过多导致流线交叉严重，此时应考虑合并小流量节点、限制展示层级数量（建议 3-6 层）或引入交互式折叠功能。


相关性矩阵与热力图
相关性矩阵热力图是展示多变量间两两相关性的标准图表。矩阵的每个单元格对应两个变量之间的相关系数，用颜色深浅编码相关性的方向和强度。


function pearsonCorrelation(x: number[], y: number[]): number {
  const n = x.length;
  const meanX = x.reduce((a, b) => a + b) / n;
  const meanY = y.reduce((a, b) => a + b) / n;
  let num = 0;
  let denX = 0;
  let denY = 0;
  for (let i = 0; i < n; i++) {
    const dx = x[i] - meanX;
    const dy = y[i] - meanY;
    num += dx * dy;
    denX += dx * dx;
    denY += dy * dy;
  }
  return num / Math.sqrt(denX * denY);
}

function buildCorrelationMatrix(data: Record<string, number[]>): { labels: string[]; matrix: number[][] } {
  const labels = Object.keys(data);
  const matrix = labels.map((_, i) => labels.map((_, j) => pearsonCorrelation(data[labels[i]], data[labels[j]])));
  return { labels, matrix };
}
相关性热力图的设计要点包括：使用发散色板（如红蓝色板），中心值 0 对应白色或浅灰；对矩阵进行聚类排序使相关性相近的变量相邻；只显示下三角矩阵避免冗余；在单元格中同时显示数值标签提高精确度。


小结
    

  • 关系型图表覆盖变量关系、层级关系和网络关系三个层次，选择正确的图表类型取决于数据的关系结构
    • 

  • 散点图是最基础的关系型图表，通过回归线、密度编码等增强手段可以处理复杂场景和大规模数据
    • 

  • 网络图依赖力导向布局等自动布局算法，节点规模超过 200 时需引入 Barnes-Hut 等优化算法
    • 

  • 桑基图通过流线宽度编码流量大小，适用于路径分析、能源流动等流量守恒场景
    • 

  • 相关性矩阵热力图使用发散色板展示多变量间的两两相关性，聚类排序能显著提升可读性
    • 

  • 所有关系型图表在数据规模增大时都面临视觉混乱问题，交互式探索是应对大规模关系数据的关键策略
