D3.js 数据绑定与选择

核心概念

D3.js（Data-Driven Documents）是数据可视化领域最具影响力的 JavaScript 库，其核心思想是将数据直接绑定到 DOM 元素上，通过数据驱动的方式创建、更新和移除可视化元素。D3 不是一个图表库，而是一组底层的可视化原语，它提供了从数据到视觉的完整映射机制。

D3 的数据绑定机制基于三个核心概念：选择集（Selection）、数据连接（Data Join）和 Enter-Update-Exit 模式。选择集是 D3 对 DOM 元素的抽象封装，数据连接将数据数组与 DOM 元素进行配对，而 Enter-Update-Exit 模式则定义了数据变化时 DOM 元素的创建、更新和销毁行为。

选择集与链式操作
D3 的选择集是对一组 DOM 元素的封装，提供了统一的操作接口。d3.select() 选择第一个匹配元素，d3.selectAll() 选择所有匹配元素。选择集支持链式调用，每个方法返回当前选择集或新的选择集。


import * as d3 from 'd3';

const svg = d3.select('#chart').append('svg').attr('width', 800).attr('height', 400);

svg
  .selectAll('rect')
  .data([30, 86, 168, 234, 12, 98])
  .join('rect')
  .attr('x', (_, i) => i * 120 + 10)
  .attr('y', (d) => 400 - d)
  .attr('width', 100)
  .attr('height', (d) => d)
  .attr('fill', 'steelblue');
选择集的 attr() 和 style() 方法接受两种参数形式：静态值和函数。当传入函数时，D3 会为每个元素调用该函数，传入绑定的数据 d、索引 i 和节点组 nodes 作为参数。这种数据驱动的属性设置是 D3 的核心编程范式。


interface DataPoint {
  name: string;
  value: number;
  category: string;
}

function renderBarChart(container: string, data: DataPoint[]): void {
  const margin = { top: 20, right: 20, bottom: 30, left: 40 };
  const width = 800 - margin.left - margin.right;
  const height = 400 - margin.top - margin.bottom;

  const svg = d3
    .select(container)
    .append('svg')
    .attr('width', width + margin.left + margin.right)
    .attr('height', height + margin.top + margin.bottom)
    .append('g')
    .attr('transform', `translate(${margin.left},${margin.top})`);

  const x = d3
    .scaleBand()
    .domain(data.map((d) => d.name))
    .range([0, width])
    .padding(0.1);

  const y = d3
    .scaleLinear()
    .domain([0, d3.max(data, (d) => d.value) ?? 0])
    .nice()
    .range([height, 0]);

  svg.append('g').attr('transform', `translate(0,${height})`).call(d3.axisBottom(x));

  svg.append('g').call(d3.axisLeft(y));

  svg
    .selectAll('.bar')
    .data(data)
    .join('rect')
    .attr('class', 'bar')
    .attr('x', (d) => x(d.name) ?? 0)
    .attr('y', (d) => y(d.value))
    .attr('width', x.bandwidth())
    .attr('height', (d) => height - y(d.value));
}
D3 的选择集还支持嵌套选择和分组操作。selectAll 在已有选择集上调用时会产生嵌套结构，每个父元素的子选择形成一个分组，数据绑定会按分组独立进行。


数据连接与 Join 模式
D3 v5 之前，数据连接需要手动处理 Enter、Update、Exit 三个集合。D3 v5+ 引入的 selection.join() 方法大幅简化了这一过程，它接受三个回调函数分别处理进入、更新和退出阶段。


interface TimeSeriesPoint {
  date: Date;
  value: number;
}

function updateTimeSeries(
  svg: d3.Selection<SVGGElement, unknown, HTMLElement, unknown>,
  data: TimeSeriesPoint[],
  xScale: d3.ScaleTime<number, number>,
  yScale: d3.ScaleLinear<number, number>,
): void {
  const line = d3
    .line<TimeSeriesPoint>()
    .x((d) => xScale(d.date))
    .y((d) => yScale(d.value))
    .curve(d3.curveMonotoneX);

  svg
    .selectAll('.line-path')
    .data([data])
    .join(
      (enter) =>
        enter
          .append('path')
          .attr('class', 'line-path')
          .attr('fill', 'none')
          .attr('stroke', 'steelblue')
          .attr('stroke-width', 2)
          .attr('d', line),
      (update) => update.transition().duration(750).attr('d', line),
      (exit) => exit.transition().duration(300).attr('opacity', 0).remove(),
    );

  svg
    .selectAll('.data-point')
    .data(data, (d) => (d as TimeSeriesPoint).date.getTime().toString())
    .join(
      (enter) =>
        enter
          .append('circle')
          .attr('class', 'data-point')
          .attr('cx', (d) => xScale(d.date))
          .attr('cy', (d) => yScale(d.value))
          .attr('r', 0)
          .call((e) => e.transition().duration(500).attr('r', 4)),
      (update) =>
        update.call((u) =>
          u
            .transition()
            .duration(750)
            .attr('cx', (d) => xScale(d.date))
            .attr('cy', (d) => yScale(d.value)),
        ),
      (exit) => exit.call((ex) => ex.transition().duration(300).attr('r', 0).remove()),
    );
}
数据连接的 key 函数是实现稳定动画的关键。当数据项有唯一标识符时，key 函数确保同一数据项始终绑定到同一 DOM 元素上，即使数据的顺序发生变化。没有 key 函数时，D3 按索引进行配对，插入或删除数据会导致所有后续元素错位。

比例尺与轴生成器
比例尺是 D3 数据绑定的数学核心，它定义了数据域（domain）到视觉范围（range）的映射函数。D3 提供了丰富的比例尺类型，覆盖连续、离散和时间等多种数据类型。


function createScales(data: DataPoint[], width: number, height: number) {
  const linear = d3
    .scaleLinear()
    .domain([0, d3.max(data, (d) => d.value) ?? 100])
    .range([height, 0])
    .nice();

  const log = d3
    .scaleLog()
    .domain([1, d3.max(data, (d) => d.value) ?? 100])
    .range([height, 0]);

  const band = d3
    .scaleBand<string>()
    .domain(data.map((d) => d.name))
    .range([0, width])
    .padding(0.2);

  const color = d3
    .scaleOrdinal<string>()
    .domain(data.map((d) => d.category))
    .range(d3.schemeTableau10);

  const time = d3
    .scaleTime()
    .domain([new Date('2024-01-01'), new Date('2024-12-31')])
    .range([0, width]);

  return { linear, log, band, color, time };
}
轴生成器（Axis Generator）是比例尺的视觉伴侣，它根据比例尺的配置自动生成刻度线、刻度标签和轴线。D3 提供四个方向的轴生成器：axisTop、axisRight、axisBottom 和 axisLeft。


小结
    

  • D3.js 的核心编程模型是数据绑定：将数据数组与 DOM 元素通过选择集进行配对
    • 

  • Enter-Update-Exit 模式定义了数据变化时元素的创建、更新和销毁行为，join() 方法是现代 D3 的简化写法
    • 

  • Key 函数确保数据项与 DOM 元素的稳定映射，是实现流畅动画过渡的关键
    • 

  • 比例尺将数据域映射到视觉范围，是数据编码的数学基础
    • 

  • D3 不是图表库而是可视化原语集合，提供了最大的定制自由度但也要求更高的学习投入
    • 

  • 理解选择集的链式操作和嵌套分组机制是熟练使用 D3 的前提
    •
