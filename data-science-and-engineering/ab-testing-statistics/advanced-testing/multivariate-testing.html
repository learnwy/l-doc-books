多变量测试

核心概念

多变量测试（MVT, Multivariate Testing）同时测试多个因素的多个水平组合，以发现因素间的交互效应。与传统 A/B 测试一次只测一个变量不同，MVT 能在单次实验中评估多个设计元素的联合影响。例如，同时测试按钮颜色（红/绿/蓝）、文案（3 种）和布局（2 种），共 18 个组合。这种方法在页面优化、推荐策略调参等场景中能大幅缩短迭代周期。

全因子设计与分析
全因子设计枚举所有因素水平的组合，是最完整的多变量测试方案。对于 k 个因素各有 lil_ili​ 个水平，总组合数为 ∏li\prod l_i∏li​。全因子设计的优势在于可以估计所有主效应和交互效应。


import numpy as np
import pandas as pd
from itertools import product

def full_factorial_design(factors):
    levels = [range(f['levels']) for f in factors]
    combinations = list(product(*levels))

    df = pd.DataFrame(combinations, columns=[f['name'] for f in factors])
    for i, f in enumerate(factors):
        df[f['name']] = df[f['name']].map(dict(enumerate(f['labels'])))

    df['combination_id'] = range(len(df))
    return df

factors = [
    {'name': 'button_color', 'levels': 3, 'labels': ['red', 'green', 'blue']},
    {'name': 'cta_text', 'levels': 2, 'labels': ['buy_now', 'add_to_cart']},
    {'name': 'layout', 'levels': 2, 'labels': ['single_col', 'two_col']},
]

design = full_factorial_design(factors)
print(f"Total combinations: {len(design)}")
print(design)

def analyze_factorial(data, factors, metric='conversion_rate'):
    results = {}

    for factor in factors:
        group_means = data.groupby(factor)[metric].mean()
        grand_mean = data[metric].mean()
        main_effect = group_means - grand_mean
        results[f'main_{factor}'] = main_effect.to_dict()

    for i, f1 in enumerate(factors):
        for f2 in factors[i+1:]:
            interaction = data.groupby([f1, f2])[metric].mean().unstack()
            row_means = interaction.mean(axis=1)
            col_means = interaction.mean(axis=0)
            expected = pd.DataFrame(
                np.outer(row_means, col_means) / grand_mean,
                index=row_means.index, columns=col_means.index
            )
            interaction_effect = interaction - expected
            results[f'interaction_{f1}_{f2}'] = interaction_effect

    return results

当交互效应显著时，不能单独解读主效应。必须在不同水平组合下分别分析效应，即简单效应分析。


分数因子设计
当因素数量较多时，全因子设计的组合数呈指数增长。例如 6 个二水平因素需要 64 个组合，加上足够的样本量，流量需求巨大。分数因子设计通过牺牲高阶交互效应的估计来大幅减少组合数。


2k−p2^{k-p}2k−p 设计保留 2k2^k2k 全因子的 1/2p1/2^p1/2p 组合。设计的关键是选择合适的生成元（generators），使得混杂（aliasing）结构可以接受。分辨率（resolution）衡量了设计的质量：


import numpy as np
from itertools import combinations

def fractional_factorial_2k(k, p, generators=None):
    n_base = k - p
    base_design = np.array(list(product([-1, 1], repeat=n_base)))

    if generators is None:
        full_design = base_design
    else:
        extra_cols = []
        for gen in generators:
            col = np.ones(len(base_design))
            for idx in gen:
                col *= base_design[:, idx]
            extra_cols.append(col)
        full_design = np.column_stack([base_design] + extra_cols)

    return full_design

design_2_6_2 = fractional_factorial_2k(6, 2, generators=[[0, 1, 2], [0, 1, 3]])
print(f"2^(6-2) design: {design_2_6_2.shape[0]} runs (vs {2**6} full factorial)")

def resolution(design):
    n_runs, n_factors = design.shape
    for r in range(2, n_factors + 1):
        for cols in combinations(range(n_factors), r):
            product_col = np.ones(n_runs)
            for c in cols:
                product_col *= design[:, c]
            if np.abs(np.sum(product_col)) == n_runs:
                return r - 1
    return n_factors

res = resolution(design_2_6_2)
print(f"Resolution: {res}")

在实际的互联网实验中，分数因子设计的典型应用是推荐系统参数调优：同时测试多个超参数（如召回数量、排序权重、多样性系数等），用较少的实验组合找到最优参数区域，然后在该区域进行精细的全因子实验。


交互效应检测与解读
交互效应是多变量测试的核心价值所在。当两个因素的联合效应不等于各自主效应之和时，存在交互效应。忽略交互效应可能导致严重的决策错误。


import numpy as np
import pandas as pd

def simulate_interaction_experiment(n_per_cell=5000):
    np.random.seed(42)

    results = []
    effects = {
        ('old_design', 'generic_text'): 0.050,
        ('old_design', 'personalized_text'): 0.055,
        ('new_design', 'generic_text'): 0.048,
        ('new_design', 'personalized_text'): 0.072,
    }

    for (design, text), true_rate in effects.items():
        conversions = np.random.binomial(1, true_rate, n_per_cell)
        for conv in conversions:
            results.append({'design': design, 'text': text, 'converted': conv})

    df = pd.DataFrame(results)

    pivot = df.groupby(['design', 'text'])['converted'].mean().unstack()
    print("Cell means:")
    print(pivot)

    main_design = df.groupby('design')['converted'].mean()
    main_text = df.groupby('text')['converted'].mean()
    print(f"\nMain effect (design): {main_design['new_design'] - main_design['old_design']:.4f}")
    print(f"Main effect (text): {main_text['personalized_text'] - main_text['generic_text']:.4f}")

    interaction = (
        pivot.loc['new_design', 'personalized_text']
        - pivot.loc['new_design', 'generic_text']
        - pivot.loc['old_design', 'personalized_text']
        + pivot.loc['old_design', 'generic_text']
    )
    print(f"Interaction effect: {interaction:.4f}")

    return df, pivot

df, pivot = simulate_interaction_experiment()
上面的模拟展示了一个典型的协同交互：新设计搭配个性化文案时转化率大幅提升（7.2%），但新设计搭配通用文案反而略有下降（4.8%）。如果仅做两个独立的 A/B 测试，可能会得出"新设计无效"和"个性化文案略有效"的错误结论，错过了两者组合的最优方案。

流量分配与效率优化
多变量测试的最大挑战是流量需求。每个组合需要足够的样本量来检测有意义的效应，组合数的增加直接增大了总体流量需求。


import numpy as np
from scipy import stats

def mvt_sample_size(n_combinations, baseline_rate, mde, alpha=0.05, power=0.8):
    z_alpha = stats.norm.ppf(1 - alpha / (2 * n_combinations))
    z_beta = stats.norm.ppf(power)

    p1 = baseline_rate
    p2 = baseline_rate + mde

    n_per_cell = (
        (z_alpha * np.sqrt(2 * p1 * (1 - p1)) + z_beta * np.sqrt(p1*(1-p1) + p2*(1-p2)))**2
        / mde**2
    )

    total_n = n_per_cell * n_combinations
    return int(np.ceil(n_per_cell)), int(np.ceil(total_n))

n_cell, n_total = mvt_sample_size(
    n_combinations=12,
    baseline_rate=0.05,
    mde=0.005,
    alpha=0.05,
    power=0.8
)
print(f"Sample per cell: {n_cell:,}")
print(f"Total sample: {n_total:,}")
自适应流量分配（如 Thompson Sampling）可以在实验过程中将更多流量分配给表现好的组合，在发现最优组合的同时减少对劣势组合的流量浪费。但自适应分配会使传统的频率派推断失效，需要使用贝叶斯方法或特殊的推断技术。


分阶段实验策略：第一阶段用 Taguchi 或分数因子设计筛选重要因素，第二阶段对筛选出的 2-3 个重要因素进行全因子实验。这种策略在总流量有限时尤其有效。

小结
    

  • 多变量测试同时评估多个因素及其交互效应，能在单次实验中找到最优组合
    • 

  • 全因子设计提供完整的效应估计但流量需求高，分数因子设计通过牺牲高阶交互来降低成本
    • 

  • 交互效应是 MVT 的核心价值，无序交互可能导致单因素测试得出完全相反的结论
    • 

  • ANOVA 是标准分析工具，交互效应显著时必须进行简单效应分析，不能单独解读主效应
    • 

  • 分阶段实验策略（筛选 → 精细化）在流量有限时是最实用的多变量测试方案
    • 

  • 自适应流量分配提高效率但需配合贝叶斯推断框架
