序贯检验

核心概念

序贯检验（Sequential Testing）允许在数据积累过程中多次查看实验结果并做出决策，而不必等到预设的样本量收集完毕。在传统固定样本量检验中，每次中间查看都会膨胀整体的 I 类错误率；序贯检验通过调整每次分析的显著性边界来严格控制总体错误率。这对于需要快速迭代的互联网实验尤为重要——如果一个变体明显有害，尽早停止可以减少用户损失。

Group Sequential Design
Group Sequential Design（GSD）是最经典的序贯检验方法，将实验分为 K 个预定义的分析阶段（通常 3-5 个），在每个阶段计算检验统计量并与调整后的边界比较。


三种经典的边界生成方法：


Pocock 边界：所有中期分析使用相同的名义显著性水平。边界一致便于理解，但最终分析的 p 值阈值远低于 0.05（例如 5 次分析时约 0.016），导致如果前几次未早停，最终检验功效下降。


O'Brien-Fleming（OBF）边界：早期分析使用极严格的阈值，后期逐渐放松至接近 0.05。这意味着只有非常强的效应才会触发早停，最终分析的阈值几乎不受影响。OBF 是实践中最常用的方法。


import numpy as np
from scipy import stats

def obrien_fleming_bounds(alpha, n_analyses):
    bounds = []
    for k in range(1, n_analyses + 1):
        info_fraction = k / n_analyses
        z_bound = stats.norm.ppf(1 - alpha / 2) / np.sqrt(info_fraction)
        bounds.append({
            'analysis': k,
            'info_fraction': info_fraction,
            'z_boundary': z_bound,
            'nominal_alpha': 2 * (1 - stats.norm.cdf(z_bound)),
        })
    return bounds

def pocock_bounds(alpha, n_analyses):
    z_p = stats.norm.ppf(1 - alpha / (2 * n_analyses))
    bounds = []
    for k in range(1, n_analyses + 1):
        bounds.append({
            'analysis': k,
            'info_fraction': k / n_analyses,
            'z_boundary': z_p,
            'nominal_alpha': 2 * (1 - stats.norm.cdf(z_p)),
        })
    return bounds

obf = obrien_fleming_bounds(0.05, 5)
poc = pocock_bounds(0.05, 5)

print("O'Brien-Fleming bounds:")
for b in obf:
    print(f"  Analysis {b['analysis']}: Z = {b['z_boundary']:.3f}, nominal α = {b['nominal_alpha']:.6f}")
print("\nPocock bounds:")
for b in poc:
    print(f"  Analysis {b['analysis']}: Z = {b['z_boundary']:.3f}, nominal α = {b['nominal_alpha']:.6f}")

α 消耗函数方法
α 消耗函数（Alpha Spending Function）由 Lan 和 DeMets 提出，是对 Group Sequential Design 的重要推广。它不要求预先固定分析次数和时间点，而是通过一个连续函数 α(t) 控制到信息分数 t 时累计消耗的 I 类错误概率。


import numpy as np
from scipy import stats

def alpha_spending_obf(t, alpha=0.05):
    return 2 * (1 - stats.norm.cdf(stats.norm.ppf(1 - alpha/2) / np.sqrt(t)))

def alpha_spending_pocock(t, alpha=0.05):
    return alpha * np.log(1 + (np.e - 1) * t)

def compute_spending_bounds(info_fractions, alpha=0.05, spending_fn='obf'):
    fn = alpha_spending_obf if spending_fn == 'obf' else alpha_spending_pocock

    bounds = []
    alpha_spent_prev = 0

    for i, t in enumerate(info_fractions):
        alpha_spent = fn(t, alpha)
        incremental_alpha = alpha_spent - alpha_spent_prev

        z_bound = stats.norm.ppf(1 - incremental_alpha / 2)

        bounds.append({
            'analysis': i + 1,
            'info_fraction': t,
            'cumulative_alpha': alpha_spent,
            'incremental_alpha': incremental_alpha,
            'z_boundary': z_bound,
        })
        alpha_spent_prev = alpha_spent

    return bounds

info_fracs = [0.25, 0.5, 0.75, 1.0]
bounds = compute_spending_bounds(info_fracs, spending_fn='obf')
for b in bounds:
    print(f"Analysis {b['analysis']} (t={b['info_fraction']:.2f}): "
          f"Z = {b['z_boundary']:.3f}, Δα = {b['incremental_alpha']:.6f}, "
          f"cumulative α = {b['cumulative_alpha']:.6f}")
α 消耗函数的核心优势在于灵活性：即使实际分析时间点与计划不同，只要按照消耗函数分配 α，总体错误率仍然受控。这在实际实验运营中非常实用——数据采集速度不均匀，临时增加一次中期分析等情况都能处理。

Always-Valid Inference
传统的 Group Sequential 方法仍然需要预先计划分析次数。Always-Valid Inference（始终有效推断）更进一步，允许在任意时间点查看数据并做出有效推断，真正实现"随时查看，随时决策"。


置信序列（Confidence Sequences） 是 always-valid 推断的核心工具。与传统置信区间在固定时间点有效不同，置信序列在所有时间点同时有效，即对所有 n ≥ 1，真实参数以至少 1−α 的概率始终落在序列内。


import numpy as np

def confidence_sequence_bernoulli(successes, n, alpha=0.05):
    if n == 0:
        return 0, 1

    p_hat = successes / n

    rho = 1.0
    boundary = np.sqrt((2 * (n * np.log(np.log(max(n, np.e))) + np.log(2 / alpha))) / n)

    ci_lower = max(0, p_hat - boundary)
    ci_upper = min(1, p_hat + boundary)

    return ci_lower, ci_upper

def mixture_sequential_test(data_a, data_b, alpha=0.05):
    n = len(data_a)
    results = []

    cum_a, cum_b = 0, 0
    for i in range(1, n + 1):
        cum_a += data_a[i-1]
        cum_b += data_b[i-1]

        p_a = cum_a / i
        p_b = cum_b / i
        diff = p_b - p_a

        se = np.sqrt(p_a * (1-p_a) / i + p_b * (1-p_b) / i) if i > 1 else 1

        boundary = np.sqrt(2 * (np.log(np.log(max(i, np.e))) + 0.72 + np.log(5.2 / alpha)) / i)

        significant = abs(diff) > boundary * np.sqrt(p_a*(1-p_a)/i + p_b*(1-p_b)/i) if se > 0 else False

        results.append({
            'n': i,
            'diff': diff,
            'boundary': boundary,
            'significant': significant,
        })

    return results

np.random.seed(42)
data_a = np.random.binomial(1, 0.05, 50000)
data_b = np.random.binomial(1, 0.055, 50000)
results = mixture_sequential_test(data_a, data_b)

first_sig = next((r for r in results if r['significant']), None)
if first_sig:
    print(f"First significant at n={first_sig['n']}, diff={first_sig['diff']:.4f}")
E-values 和 E-processes：E-value 是假设检验的一种新范式，它衡量的是数据对备择假设相对于零假设的证据强度。E-value 序列天然支持任意停止，且可以直接相乘（组合多个独立证据），是构建 always-valid 检验的另一条路径。

实验平台中的实现
在实际实验平台中，序贯检验的实现需要解决工程和统计的交叉问题。


触发频率设计：虽然 always-valid 方法理论上允许任意频率查看，但实际中通常每天或每小时触发一次自动分析。分析频率影响计算成本和告警及时性的平衡。


import numpy as np
from datetime import datetime, timedelta

class SequentialMonitor:
    def __init__(self, alpha=0.05, max_analyses=10, method='obf'):
        self.alpha = alpha
        self.max_analyses = max_analyses
        self.method = method
        self.analyses_done = 0
        self.alpha_spent = 0
        self.history = []

    def compute_boundary(self, info_fraction):
        from scipy import stats

        if self.method == 'obf':
            z = stats.norm.ppf(1 - self.alpha / 2) / np.sqrt(info_fraction)
        else:
            z = stats.norm.ppf(1 - self.alpha / (2 * self.max_analyses))
        return z

    def check(self, z_stat, info_fraction, metadata=None):
        self.analyses_done += 1
        boundary = self.compute_boundary(info_fraction)

        decision = 'continue'
        if abs(z_stat) > boundary:
            decision = 'reject' if z_stat > 0 else 'reject_negative'
        elif info_fraction >= 1.0:
            decision = 'fail_to_reject'

        result = {
            'analysis': self.analyses_done,
            'info_fraction': info_fraction,
            'z_stat': z_stat,
            'boundary': boundary,
            'decision': decision,
            'timestamp': datetime.now().isoformat(),
        }
        if metadata:
            result.update(metadata)

        self.history.append(result)
        return result

monitor = SequentialMonitor(alpha=0.05, max_analyses=5, method='obf')
simulated_z = [1.2, 1.8, 2.1, 2.4]
for i, z in enumerate(simulated_z):
    info_frac = (i + 1) / 5
    result = monitor.check(z, info_frac)
    print(f"Analysis {result['analysis']}: Z={z:.1f}, boundary={result['boundary']:.3f}, "
          f"decision={result['decision']}")
护栏指标与序贯检验的结合：护栏指标（guardrail metrics）通常使用单侧序贯检验——只关心指标是否显著恶化。一旦护栏指标触发恶化告警，实验自动暂停，等待人工审查。

小结
    

  • 序贯检验允许在实验过程中多次查看数据并提前做出决策，同时严格控制整体 I 类错误率
    • 

  • O'Brien-Fleming 边界是最常用的经典方法，早期极保守，最终分析接近标准固定样本量检验
    • 

  • α 消耗函数不要求预先固定分析次数，提供了更大的操作灵活性
    • 

  • Always-Valid Inference（置信序列、E-value）允许真正的任意时间点查看，是序贯检验的前沿方向
    • 

  • 实际部署需要平衡分析频率、计算成本和告警及时性，通常每天自动触发一次分析
    • 

  • 序贯检验与护栏指标结合，可以在检测到指标恶化时自动暂停实验，保护用户体验
    •
