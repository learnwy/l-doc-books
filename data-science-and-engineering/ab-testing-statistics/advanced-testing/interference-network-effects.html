干扰效应与网络效应

核心概念

传统 A/B 测试的核心假设是 SUTVA（Stable Unit Treatment Value Assumption）：一个用户的实验分组不影响其他用户的结果。但在社交网络、双边市场、共享资源等场景中，这一假设被严重违反。例如，在社交 App 中给一部分用户推送新的分享功能，控制组用户也会看到实验组用户分享的内容，产生"溢出效应"。干扰效应使得标准 A/B 测试低估或高估了真实处理效应，甚至可能得出方向性错误的结论。

集群随机化
集群随机化（Cluster Randomization）是处理干扰效应最直接的方法：不以个体为随机化单元，而是以"集群"为单元进行分组。同一集群内的所有用户接受相同的处理，干扰效应被限制在集群内部，不会跨集群传播。


import numpy as np
import pandas as pd
from scipy import stats

class ClusterRandomizedExperiment:
    def __init__(self, n_clusters, users_per_cluster):
        self.n_clusters = n_clusters
        self.users_per_cluster = users_per_cluster

    def assign(self, treatment_fraction=0.5):
        n_treatment = int(self.n_clusters * treatment_fraction)
        assignments = np.array([1] * n_treatment + [0] * (self.n_clusters - n_treatment))
        np.random.shuffle(assignments)

        data = []
        for cluster_id in range(self.n_clusters):
            for user_id in range(self.users_per_cluster):
                data.append({
                    'cluster_id': cluster_id,
                    'user_id': f"{cluster_id}_{user_id}",
                    'treatment': assignments[cluster_id],
                })
        return pd.DataFrame(data)

    def analyze(self, data, outcome_col):
        cluster_means = data.groupby(['cluster_id', 'treatment'])[outcome_col].mean().reset_index()

        treated = cluster_means[cluster_means['treatment'] == 1][outcome_col]
        control = cluster_means[cluster_means['treatment'] == 0][outcome_col]

        t_stat, p_value = stats.ttest_ind(treated, control)

        diff = treated.mean() - control.mean()
        se = np.sqrt(treated.var() / len(treated) + control.var() / len(control))
        ci = (diff - 1.96 * se, diff + 1.96 * se)

        return {
            'diff': diff,
            'se': se,
            'ci': ci,
            't_stat': t_stat,
            'p_value': p_value,
            'icc': self._compute_icc(data, outcome_col),
        }

    def _compute_icc(self, data, outcome_col):
        cluster_means = data.groupby('cluster_id')[outcome_col].mean()
        grand_mean = data[outcome_col].mean()

        between_var = np.var(cluster_means, ddof=1)
        within_var = data.groupby('cluster_id')[outcome_col].var().mean()

        icc = between_var / (between_var + within_var) if (between_var + within_var) > 0 else 0
        return icc

np.random.seed(42)
exp = ClusterRandomizedExperiment(n_clusters=200, users_per_cluster=500)
data = exp.assign(treatment_fraction=0.5)

cluster_effect = np.random.normal(0, 0.02, 200)
data['outcome'] = data.apply(
    lambda row: np.random.binomial(1, 0.05 + 0.005 * row['treatment'] + cluster_effect[row['cluster_id']]),
    axis=1
)

result = exp.analyze(data, 'outcome')
print(f"Treatment effect: {result['diff']:.4f}")
print(f"95% CI: ({result['ci'][0]:.4f}, {result['ci'][1]:.4f})")
print(f"ICC: {result['icc']:.4f}")
print(f"p-value: {result['p_value']:.4f}")
集群选择是设计的关键。理想的集群应该满足：集群内干扰充分（用户间有强交互），集群间干扰最小（跨集群交互少）。常用的集群定义包括地理区域、社交网络社区（通过图分割算法）、时间段等。

设计效应（Design Effect） 量化了集群随机化相对于个体随机化的效率损失：


DE=1+(m−1)×ICCDE = 1 + (m - 1) \times ICCDE=1+(m−1)×ICC
其中 m 是平均集群大小，ICC 是类内相关系数。当 ICC = 0.01，m = 500 时，DE ≈ 6，意味着需要 6 倍的样本量才能达到个体随机化同等的统计功效。


Switchback 实验设计
Switchback 设计是一种特殊的集群随机化方法，以"时间段 × 区域"为随机化单元。在每个时间窗口（如每小时），每个区域被随机分配到实验组或对照组。这种设计特别适合双边市场（如打车、外卖），因为同一时间段内同一区域的供需双方自然形成一个集群。


import numpy as np
import pandas as pd

class SwitchbackDesign:
    def __init__(self, n_regions, n_time_slots, block_duration_hours=2):
        self.n_regions = n_regions
        self.n_time_slots = n_time_slots
        self.block_duration = block_duration_hours

    def generate_assignment(self):
        assignments = np.random.binomial(1, 0.5, (self.n_regions, self.n_time_slots))

        data = []
        for region in range(self.n_regions):
            for slot in range(self.n_time_slots):
                data.append({
                    'region': region,
                    'time_slot': slot,
                    'treatment': assignments[region, slot],
                })
        return pd.DataFrame(data)

    def analyze_did(self, data, outcome_col):
        region_means = data.groupby('region')[outcome_col].mean()
        time_means = data.groupby('time_slot')[outcome_col].mean()
        grand_mean = data[outcome_col].mean()

        data_adjusted = data.copy()
        data_adjusted['y_adj'] = data.apply(
            lambda row: row[outcome_col]
                - region_means[row['region']]
                - time_means[row['time_slot']]
                + grand_mean,
            axis=1
        )

        treated = data_adjusted[data_adjusted['treatment'] == 1]['y_adj']
        control = data_adjusted[data_adjusted['treatment'] == 0]['y_adj']

        diff = treated.mean() - control.mean()

        n_units = self.n_regions * self.n_time_slots
        n_treated = len(treated)
        n_control = len(control)
        se = np.sqrt(treated.var() / n_treated + control.var() / n_control)

        return {'diff': diff, 'se': se, 'ci': (diff - 1.96*se, diff + 1.96*se)}

np.random.seed(42)
design = SwitchbackDesign(n_regions=50, n_time_slots=168)
assignments = design.generate_assignment()

region_fe = np.random.normal(0, 0.1, 50)
time_fe = np.sin(np.arange(168) * 2 * np.pi / 24) * 0.05
assignments['outcome'] = assignments.apply(
    lambda row: 10 + region_fe[row['region']] + time_fe[row['time_slot']]
        + 0.3 * row['treatment'] + np.random.normal(0, 1),
    axis=1
)

result = design.analyze_did(assignments, 'outcome')
print(f"Switchback effect: {result['diff']:.4f}")
print(f"95% CI: ({result['ci'][0]:.4f}, {result['ci'][1]:.4f})")
Switchback 设计的关键参数是时间窗口的长度：窗口太短，切换效应（carryover effect）导致前一个处理的影响延续到下一个窗口；窗口太长，则可用的随机化单元减少，统计功效下降。通常需要在每个切换点丢弃一段"冲刷期"（wash-out period）的数据。

网络效应的因果估计
在社交网络中，处理效应可以分解为直接效应和间接效应。直接效应是用户自身接受处理的影响，间接效应是通过网络邻居传播的影响。精确估计这两种效应需要网络因果推断的专门方法。


import numpy as np

class NetworkExperiment:
    def __init__(self, n_users, edge_list):
        self.n_users = n_users
        self.adjacency = self._build_adjacency(edge_list)

    def _build_adjacency(self, edge_list):
        adj = {i: set() for i in range(self.n_users)}
        for u, v in edge_list:
            adj[u].add(v)
            adj[v].add(u)
        return adj

    def compute_exposure(self, treatment_assignment):
        exposure = np.zeros(self.n_users)
        for user in range(self.n_users):
            neighbors = self.adjacency[user]
            if len(neighbors) > 0:
                treated_neighbors = sum(1 for n in neighbors if treatment_assignment[n] == 1)
                exposure[user] = treated_neighbors / len(neighbors)
        return exposure

    def estimate_effects(self, treatment, outcome, exposure_threshold=0.5):
        exposure = self.compute_exposure(treatment)

        direct_treated = outcome[(treatment == 1) & (exposure < exposure_threshold)]
        direct_control = outcome[(treatment == 0) & (exposure < exposure_threshold)]
        direct_effect = np.mean(direct_treated) - np.mean(direct_control)

        indirect_high = outcome[(treatment == 0) & (exposure >= exposure_threshold)]
        indirect_low = outcome[(treatment == 0) & (exposure < exposure_threshold)]
        indirect_effect = np.mean(indirect_high) - np.mean(indirect_low)

        total_effect = direct_effect + indirect_effect

        return {
            'direct_effect': direct_effect,
            'indirect_effect': indirect_effect,
            'total_effect': total_effect,
            'mean_exposure_treated': np.mean(exposure[treatment == 1]),
            'mean_exposure_control': np.mean(exposure[treatment == 0]),
        }

np.random.seed(42)
n = 10000
edges = []
for i in range(n):
    n_friends = np.random.poisson(10)
    friends = np.random.choice(n, min(n_friends, 20), replace=False)
    for f in friends:
        if f != i:
            edges.append((i, f))

net_exp = NetworkExperiment(n, edges)
treatment = np.random.binomial(1, 0.3, n)
exposure = net_exp.compute_exposure(treatment)

outcome = (
    0.05
    + 0.01 * treatment
    + 0.005 * exposure
    + np.random.normal(0, 0.02, n)
)

effects = net_exp.estimate_effects(treatment, outcome)
print(f"Direct effect: {effects['direct_effect']:.4f}")
print(f"Indirect effect: {effects['indirect_effect']:.4f}")
print(f"Total effect: {effects['total_effect']:.4f}")

小结
    

  • SUTVA 假设在社交网络、双边市场、共享资源场景中被违反，标准 A/B 测试可能产生严重偏差
    • 

  • 集群随机化是处理干扰效应的基础方法，以用户群组为随机化单元隔离干扰
    • 

  • 设计效应 DE = 1 + (m−1)×ICC 量化了集群随机化的效率损失，ICC 越高损失越大
    • 

  • Switchback 设计以"时间段×区域"为单元，特别适合双边市场实验，需要设置冲刷期消除 carryover
    • 

  • 网络效应的因果估计需要区分直接效应和间接效应，暴露映射和 ego-cluster 是两种主要方法
    • 

  • 实际部署中，集群定义、集群大小和干扰隔离程度是实验设计的关键决策点
    •
