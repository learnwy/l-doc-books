实验设计原则

核心概念

A/B 测试的实验设计是连接业务假设和统计结论的桥梁。一个设计良好的实验能够在最短时间内以最小样本量获得可靠的因果推断结论；而设计不当的实验即使运行再长时间也可能得出错误的结论。实验设计的核心是在内部效度（因果推断的可靠性）、外部效度（结论的泛化能力）和实验效率（时间和资源成本）之间取得平衡。

实验设计的根本目标是隔离处理效应（Treatment Effect）——排除一切混淆因素后，精确衡量实验变量（处理）对目标指标（结果）的因果影响。费雪的随机化原则和 Neyman 的潜在结果框架是现代实验设计的两大理论基石。


假设与指标体系
实验假设应当遵循 SMART 原则：具体（Specific）、可衡量（Measurable）、可实现（Achievable）、相关（Relevant）和有时限（Time-bound）。一个好的假设应当明确指出"改变 X 将导致 Y 指标提升 Z%"。


from dataclasses import dataclass
from typing import List, Optional
from enum import Enum

class MetricType(Enum):
    PRIMARY = 'primary'
    SECONDARY = 'secondary'
    GUARDRAIL = 'guardrail'

@dataclass
class ExperimentMetric:
    name: str
    metric_type: MetricType
    description: str
    expected_effect: Optional[float] = None
    minimum_detectable_effect: Optional[float] = None
    direction: str = 'increase'

@dataclass
class ExperimentDesign:
    name: str
    hypothesis: str
    metrics: List[ExperimentMetric]
    experiment_unit: str
    traffic_allocation: float
    target_population: str
    exclusion_criteria: List[str]

    def validate(self):
        issues = []

        primary_metrics = [m for m in self.metrics if m.metric_type == MetricType.PRIMARY]
        if len(primary_metrics) != 1:
            issues.append(f"Should have exactly 1 primary metric, found {len(primary_metrics)}")

        guardrail_metrics = [m for m in self.metrics if m.metric_type == MetricType.GUARDRAIL]
        if len(guardrail_metrics) == 0:
            issues.append("Should have at least 1 guardrail metric")

        if self.traffic_allocation > 0.5:
            issues.append("Traffic allocation >50% is risky for new features")

        return issues
指标体系通常分为三层：主指标（Primary Metric）是实验的核心判断依据，每个实验应当且仅当有一个主指标——多个主指标会引入多重比较问题，降低统计功效。次要指标（Secondary Metric）提供补充洞察，帮助理解主指标变化的机制。护栏指标（Guardrail Metric）监控实验是否产生负面影响，如页面加载时间、崩溃率等——即使主指标提升，如果护栏指标显著恶化，实验也应当终止。


OEC（Overall Evaluation Criterion）是将多个指标综合为单一评判标准的方法。微软的实验平台使用加权 OEC 来平衡用户参与度、收入和性能等多个维度的指标。OEC 的权重设计需要业务判断，且应当在实验前确定，不能在看到结果后调整。

实验单元与流量分配
实验单元（Experiment Unit）是随机化分配的最小单位。选择合适的实验单元直接影响实验的内部效度。最常见的实验单元是用户（User），但根据场景不同，也可能选择会话（Session）、设备（Device）、页面访问（Page View）或地理区域（Geo Region）。


import hashlib
import numpy as np

def assign_user_to_group(user_id, experiment_id, n_groups=2, salt=''):
    hash_input = f"{experiment_id}_{salt}_{user_id}"
    hash_value = hashlib.md5(hash_input.encode()).hexdigest()
    bucket = int(hash_value[:8], 16) % 10000

    group_size = 10000 // n_groups
    group = bucket // group_size

    return min(group, n_groups - 1)

def check_sample_ratio_mismatch(control_count, treatment_count,
                                  expected_ratio=0.5, alpha=0.05):
    from scipy.stats import chi2

    total = control_count + treatment_count
    expected_control = total * (1 - expected_ratio)
    expected_treatment = total * expected_ratio

    chi2_stat = ((control_count - expected_control) ** 2 / expected_control +
                 (treatment_count - expected_treatment) ** 2 / expected_treatment)

    p_value = 1 - chi2.cdf(chi2_stat, df=1)

    actual_ratio = treatment_count / total

    return {
        'chi2_statistic': chi2_stat,
        'p_value': p_value,
        'is_mismatch': p_value < alpha,
        'expected_ratio': expected_ratio,
        'actual_ratio': actual_ratio,
        'deviation': abs(actual_ratio - expected_ratio)
    }
样本比率不匹配（Sample Ratio Mismatch, SRM）是实验可靠性的第一道检查。如果实验组和对照组的实际样本比例与预期比例显著偏离，说明实验的随机化过程出了问题——可能是代码 bug、用户过滤逻辑差异或日志丢失等原因。SRM 是实验结果不可信的强烈信号，必须先排查 SRM 才能解读实验结果。


流量分配策略需要考虑风险和效率的平衡。对于高风险变更（如核心算法替换），通常从 1% → 5% → 10% → 50% 逐步放量；对于低风险变更（如 UI 微调），可以直接 50/50 分配。多实验并行时，需要正交流量层（Orthogonal Traffic Layer）确保不同实验的随机化独立。


效应量与最小可检测效应
最小可检测效应（Minimum Detectable Effect, MDE）是实验能够以足够统计功效检测到的最小效应大小。MDE 的选择既是统计问题也是业务问题：太大的 MDE 意味着只能检测到大幅改进（可能错过有价值的小幅改进），太小的 MDE 需要巨大的样本量。


from scipy.stats import norm
import numpy as np

def compute_mde(baseline_rate, n_per_group, alpha=0.05, power=0.8):
    z_alpha = norm.ppf(1 - alpha / 2)
    z_beta = norm.ppf(power)

    se = np.sqrt(2 * baseline_rate * (1 - baseline_rate) / n_per_group)
    mde = (z_alpha + z_beta) * se

    return {
        'mde_absolute': mde,
        'mde_relative': mde / baseline_rate * 100,
        'baseline_rate': baseline_rate,
        'n_per_group': n_per_group,
        'alpha': alpha,
        'power': power
    }

def sensitivity_analysis(baseline_rate, n_options, alpha=0.05, power=0.8):
    results = []
    for n in n_options:
        mde = compute_mde(baseline_rate, n, alpha, power)
        results.append({
            'n_per_group': n,
            'mde_absolute': mde['mde_absolute'],
            'mde_relative': mde['mde_relative']
        })
    return results
效应量（Effect Size）的标准化表示使得不同实验之间可以进行比较。Cohen's d 是连续指标的标准化效应量，d = 0.2 被视为小效应，d = 0.5 为中等效应，d = 0.8 为大效应。对于比率指标，相对提升百分比（Relative Lift）是更直观的效应量表达。

小结
    

  • 实验设计的核心是在内部效度、外部效度和效率之间取得平衡
    • 

  • 每个实验应有且仅有一个主指标、若干次要指标和护栏指标
    • 

  • 实验单元的选择影响内部效度，用户级随机化是最常见的选择
    • 

  • 样本比率不匹配（SRM）是实验健康检查的第一步，SRM 存在时实验结果不可信
    • 

  • 最小可检测效应（MDE）的选择是统计和业务的联合决策，灵敏度分析帮助理解权衡
    • 

  • 流量分配应根据风险等级分阶段放量，多实验并行需要正交流量层
    • 

  • 好的实验设计在实验开始前就确定了分析计划（Pre-Analysis Plan），避免事后调整导致的 p-hacking
    •
