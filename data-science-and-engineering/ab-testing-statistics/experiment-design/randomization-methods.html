随机化方法

核心概念

随机化（Randomization）是 A/B 测试的根基——它确保处理组和对照组在所有已知和未知的混淆变量上统计等价，使得两组之间的差异可以归因于处理效应。随机化方法的选择直接影响实验的内部效度、统计功效和工程实现复杂度。从简单随机分配到自适应随机化，不同方法在不同场景下各有优势。

随机化的质量直接决定了因果推断的可信度。如果随机化过程有缺陷（如哈希碰撞、分桶不均匀、用户 ID 非均匀分布），即使统计分析再精确，结论也不可靠。因此，随机化实现的正确性验证是实验基础设施中最重要的质量保障环节。


哈希分桶随机化
哈希分桶是互联网公司实验平台中最常用的随机化实现方式。通过将用户 ID 与实验 ID 拼接后进行哈希运算，得到一个伪随机的数值，根据数值落入的桶决定用户的分组。哈希函数的确定性保证了同一用户在同一实验中始终被分配到相同的组。


import hashlib
import numpy as np

class HashBucketRandomizer:
    def __init__(self, n_buckets=10000):
        self.n_buckets = n_buckets

    def get_bucket(self, user_id, experiment_id, salt=''):
        hash_input = f"{experiment_id}.{salt}.{user_id}"
        hash_hex = hashlib.md5(hash_input.encode()).hexdigest()
        return int(hash_hex[:8], 16) % self.n_buckets

    def assign(self, user_id, experiment_id, groups, salt=''):
        bucket = self.get_bucket(user_id, experiment_id, salt)

        cumulative = 0
        for group_name, proportion in groups.items():
            cumulative += int(proportion * self.n_buckets)
            if bucket < cumulative:
                return group_name

        return list(groups.keys())[-1]

class OrthogonalTrafficLayer:
    def __init__(self, layer_id, n_buckets=10000):
        self.layer_id = layer_id
        self.n_buckets = n_buckets
        self.experiments = {}

    def register_experiment(self, experiment_id, traffic_fraction, n_groups=2):
        used_buckets = sum(e['n_buckets'] for e in self.experiments.values())
        needed = int(traffic_fraction * self.n_buckets)

        if used_buckets + needed > self.n_buckets:
            raise ValueError(f"Not enough traffic. Used: {used_buckets}, Needed: {needed}")

        self.experiments[experiment_id] = {
            'start_bucket': used_buckets,
            'n_buckets': needed,
            'n_groups': n_groups
        }

    def assign_user(self, user_id, experiment_id):
        if experiment_id not in self.experiments:
            return None

        exp = self.experiments[experiment_id]
        hash_input = f"{self.layer_id}.{experiment_id}.{user_id}"
        hash_hex = hashlib.md5(hash_input.encode()).hexdigest()
        bucket = int(hash_hex[:8], 16) % self.n_buckets

        if bucket < exp['start_bucket'] or bucket >= exp['start_bucket'] + exp['n_buckets']:
            return None

        local_bucket = bucket - exp['start_bucket']
        group = local_bucket * exp['n_groups'] // exp['n_buckets']

        return group
正交流量层（Orthogonal Traffic Layer）解决了多实验并行运行时的流量冲突问题。同一层内的实验共享互斥的流量——用户只能参与该层中的一个实验；不同层之间的实验正交——用户在不同层中的分组独立。这种设计确保了不同层的实验之间不会相互干扰。


盐值（Salt）的作用是确保同一用户在不同实验中的分桶独立。如果两个实验使用相同的哈希种子，那么在实验 A 中被分到处理组的用户也一定会在实验 B 中被分到处理组，导致两个实验的随机化不独立。每个实验使用唯一的盐值消除了这种耦合。

分层随机化与区组设计
分层随机化（Stratified Randomization）在随机化之前先将用户按照重要协变量分层（如新老用户、设备类型、地理区域），然后在每层内独立进行随机分配。分层确保了处理组和对照组在关键协变量上精确均衡，消除了简单随机化在小样本下可能产生的不均衡。


import pandas as pd
import numpy as np

def stratified_randomize(users_df, strata_cols, treatment_ratio=0.5, seed=42):
    np.random.seed(seed)
    users_df = users_df.copy()
    users_df['group'] = 'control'

    for _, stratum in users_df.groupby(strata_cols):
        n_treatment = int(len(stratum) * treatment_ratio)
        treatment_indices = np.random.choice(
            stratum.index, size=n_treatment, replace=False
        )
        users_df.loc[treatment_indices, 'group'] = 'treatment'

    return users_df

def check_balance(users_df, group_col, covariates):
    results = []
    for cov in covariates:
        control = users_df[users_df[group_col] == 'control'][cov]
        treatment = users_df[users_df[group_col] == 'treatment'][cov]

        if users_df[cov].dtype in ['float64', 'int64']:
            from scipy.stats import ttest_ind
            stat, p_value = ttest_ind(control, treatment)
            smd = (treatment.mean() - control.mean()) / np.sqrt(
                (control.var() + treatment.var()) / 2
            )
            results.append({
                'covariate': cov,
                'control_mean': control.mean(),
                'treatment_mean': treatment.mean(),
                'smd': smd,
                'p_value': p_value,
                'balanced': abs(smd) < 0.1
            })
        else:
            from scipy.stats import chi2_contingency
            contingency = pd.crosstab(users_df[group_col], users_df[cov])
            chi2, p_value, _, _ = chi2_contingency(contingency)
            results.append({
                'covariate': cov,
                'chi2': chi2,
                'p_value': p_value,
                'balanced': p_value > 0.05
            })

    return pd.DataFrame(results)
标准化均值差异（Standardized Mean Difference, SMD）是检验分组均衡性的标准指标。SMD < 0.1 通常被认为是可接受的均衡。如果多个协变量的 SMD 超过 0.1，即使 p 值不显著（小样本下功效不足），也应当怀疑随机化的质量。


区组随机化（Block Randomization）将用户按时间到达顺序分成固定大小的区组（如每 4 个用户一组），在每个区组内确保恰好有 2 个分到处理组、2 个分到对照组。区组设计消除了时间维度上的混淆效应，但区组大小不宜过小（否则可预测后续分配）也不宜过大（否则失去均衡优势）。


聚类随机化
聚类随机化（Cluster Randomization）以群体（如城市、学校、社交圈）而非个体为单位进行随机分配。当处理效应存在溢出（Spillover）时——即处理组用户的行为影响对照组用户的结果——个体级随机化会导致处理效应被低估（对照组被"污染"）。聚类随机化通过将整个群体分配到同一组来隔离溢出效应。


def cluster_randomize(clusters_df, cluster_col, treatment_ratio=0.5,
                       stratify_col=None, seed=42):
    np.random.seed(seed)

    clusters = clusters_df[cluster_col].unique()

    if stratify_col:
        cluster_features = clusters_df.groupby(cluster_col)[stratify_col].first()
        assignments = {}
        for stratum_value in cluster_features.unique():
            stratum_clusters = cluster_features[cluster_features == stratum_value].index
            n_treatment = int(len(stratum_clusters) * treatment_ratio)
            treatment_clusters = np.random.choice(
                stratum_clusters, size=n_treatment, replace=False
            )
            for c in stratum_clusters:
                assignments[c] = 'treatment' if c in treatment_clusters else 'control'
    else:
        n_treatment = int(len(clusters) * treatment_ratio)
        treatment_clusters = np.random.choice(clusters, size=n_treatment, replace=False)
        assignments = {c: 'treatment' if c in treatment_clusters else 'control' for c in clusters}

    clusters_df = clusters_df.copy()
    clusters_df['group'] = clusters_df[cluster_col].map(assignments)
    return clusters_df

def design_effect_icc(icc, cluster_size):
    return 1 + (cluster_size - 1) * icc
聚类随机化的代价是统计功效降低。有效样本量不再是个体数量，而是个体数量除以设计效应（Design Effect）。设计效应等于 1+(m−1)×ρ1 + (m-1) \times \rho1+(m−1)×ρ，其中 mmm 是聚类大小，ρ\rhoρ 是组内相关系数（ICC）。ICC 为 0.01、聚类大小为 100 时，设计效应约为 2，意味着有效样本量减半。

小结
    

  • 随机化是 A/B 测试因果推断的根基，哈希分桶是互联网实验平台的标准实现
    • 

  • 正交流量层确保多实验并行时不相互干扰，盐值确保不同实验的分桶独立
    • 

  • 分层随机化在关键协变量上实现精确均衡，SMD < 0.1 是均衡性的标准阈值
    • 

  • 聚类随机化解决溢出效应问题，但需要付出统计功效降低的代价
    • 

  • 设计效应量化了聚类随机化的功效损失，ICC 和聚类大小是关键参数
    • 

  • 均衡性检查应在分析结果前进行，SRM 和协变量均衡检查是实验健康的两道防线
    • 

  • 随机化方法的选择取决于实验场景、溢出风险和样本量约束的综合权衡
