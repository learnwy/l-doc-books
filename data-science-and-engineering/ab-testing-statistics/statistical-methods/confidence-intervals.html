置信区间

核心概念

置信区间是假设检验的补充视角，不仅回答"效应是否显著"，还回答"效应有多大"。一个 95% 置信区间表示：如果重复实验无数次，95% 的置信区间会包含真实参数值。在 A/B 测试中，置信区间帮助决策者理解效应的精确范围，是从"统计显著"到"业务可行"的关键桥梁。

比率差异的置信区间
在 A/B 测试中，比率差异（如转化率提升）是最常见的效应量指标。对于两组独立的二项比率 p^1\hat{p}_1p^​1​ 和 p^2\hat{p}_2p^​2​，差异 δ=p^1−p^2\delta = \hat{p}_1 - \hat{p}_2δ=p^​1​−p^​2​ 的渐近置信区间为：


δ±zα/2p^1(1−p^1)n1+p^2(1−p^2)n2\delta \pm z_{\alpha/2} \sqrt{\frac{\hat{p}_1(1-\hat{p}_1)}{n_1} + \frac{\hat{p}_2(1-\hat{p}_2)}{n_2}}δ±zα/2​n1​p^​1​(1−p^​1​)​+n2​p^​2​(1−p^​2​)​​
注意这里用各组自身的方差（而非合并方差），因为置信区间不假设 H₀ 成立。


import numpy as np
from scipy import stats

def proportion_ci(p1, n1, p2, n2, alpha=0.05):
    delta = p1 - p2
    se = np.sqrt(p1 * (1 - p1) / n1 + p2 * (1 - p2) / n2)
    z = stats.norm.ppf(1 - alpha / 2)
    ci_lower = delta - z * se
    ci_upper = delta + z * se

    relative_lift = delta / p2
    se_relative = relative_lift * np.sqrt(
        (1 - p1) / (p1 * n1) + (1 - p2) / (p2 * n2)
    )
    ci_rel_lower = relative_lift - z * se_relative
    ci_rel_upper = relative_lift + z * se_relative

    return {
        'absolute_diff': delta,
        'absolute_ci': (ci_lower, ci_upper),
        'relative_lift': relative_lift,
        'relative_ci': (ci_rel_lower, ci_rel_upper),
    }

result = proportion_ci(0.052, 100000, 0.048, 100000)
print(f"Absolute diff: {result['absolute_diff']:.4f}")
print(f"Absolute 95% CI: ({result['absolute_ci'][0]:.4f}, {result['absolute_ci'][1]:.4f})")
print(f"Relative lift: {result['relative_lift']:.2%}")
print(f"Relative 95% CI: ({result['relative_ci'][0]:.2%}, {result['relative_ci'][1]:.2%})")
除了绝对差异，相对提升（relative lift）的置信区间在业务沟通中更为直观。例如"转化率提升了 8.3%，95% 置信区间为 [2.1%, 14.8%]"比绝对值更容易被产品经理理解。


相对提升的 Delta Method 置信区间使用比率分布的近似方差。当对照组比率接近 0 时，Delta Method 可能不稳定，此时 Fieller 方法或 Bootstrap 更可靠。

连续指标的置信区间
连续指标（如人均消费、页面停留时长、点击次数）在 A/B 测试中同样常见。这些指标通常具有偏态分布和长尾特性，直接使用正态近似的置信区间可能不够准确。


对于均值差异，Welch's T 区间是参数方法的首选：


(Xˉ1−Xˉ2)±tν,α/2s12n1+s22n2(\bar{X}_1 - \bar{X}_2) \pm t_{\nu, \alpha/2} \sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}(Xˉ1​−Xˉ2​)±tν,α/2​n1​s12​​+n2​s22​​​
自由度 ν\nuν 使用 Welch-Satterthwaite 近似。在大样本下，T 区间和 Z 区间几乎一致。


import numpy as np
from scipy import stats

def mean_diff_ci(x1, x2, alpha=0.05):
    n1, n2 = len(x1), len(x2)
    mean_diff = np.mean(x1) - np.mean(x2)
    se = np.sqrt(np.var(x1, ddof=1) / n1 + np.var(x2, ddof=1) / n2)

    nu_num = (np.var(x1, ddof=1)/n1 + np.var(x2, ddof=1)/n2) ** 2
    nu_den = (np.var(x1, ddof=1)/n1)**2 / (n1-1) + (np.var(x2, ddof=1)/n2)**2 / (n2-1)
    nu = nu_num / nu_den

    t_crit = stats.t.ppf(1 - alpha/2, nu)
    ci_lower = mean_diff - t_crit * se
    ci_upper = mean_diff + t_crit * se

    return mean_diff, (ci_lower, ci_upper), nu

np.random.seed(42)
control_revenue = np.random.lognormal(mean=3, sigma=1.5, size=50000)
treatment_revenue = np.random.lognormal(mean=3, sigma=1.5, size=50000) * 1.03

diff, ci, df = mean_diff_ci(treatment_revenue, control_revenue)
print(f"Mean diff: {diff:.2f}")
print(f"95% CI: ({ci[0]:.2f}, {ci[1]:.2f})")
print(f"Degrees of freedom: {df:.0f}")
对于高度偏态的收入类指标，Bootstrap 置信区间是更稳健的选择。BCa（Bias-Corrected and accelerated）Bootstrap 在偏态和小样本情况下表现优于百分位法 Bootstrap。


import numpy as np

def bootstrap_ci(x1, x2, n_boot=10000, alpha=0.05):
    n1, n2 = len(x1), len(x2)
    observed_diff = np.mean(x1) - np.mean(x2)

    boot_diffs = np.zeros(n_boot)
    for i in range(n_boot):
        boot_x1 = np.random.choice(x1, size=n1, replace=True)
        boot_x2 = np.random.choice(x2, size=n2, replace=True)
        boot_diffs[i] = np.mean(boot_x1) - np.mean(boot_x2)

    ci_lower = np.percentile(boot_diffs, 100 * alpha / 2)
    ci_upper = np.percentile(boot_diffs, 100 * (1 - alpha / 2))

    boot_se = np.std(boot_diffs, ddof=1)

    return observed_diff, (ci_lower, ci_upper), boot_se

diff, ci, se = bootstrap_ci(treatment_revenue, control_revenue)
print(f"Bootstrap 95% CI: ({ci[0]:.2f}, {ci[1]:.2f})")
置信区间的业务解读
统计显著性和业务显著性是两个不同的维度。一个效应可能统计显著（p < 0.05）但业务上微不足道；也可能统计不显著但置信区间暗示潜在的大效应。置信区间将这两个维度统一在一个框架内。


最小可检测效应（MDE） 与置信区间的关系是决策的关键：


    

  • 如果置信区间的下界 > MDE：可以确信效应足够大，放心发布
    • 

  • 如果置信区间包含 MDE 但不包含 0：效应存在，但可能不够大，需要权衡
    • 

  • 如果置信区间同时包含 0 和 MDE：实验功效不足，需要更多数据
    • 

  • 如果置信区间的上界 < 0：变体有害，不应发布
    • 



在报告实验结果时，推荐同时展示绝对置信区间和相对置信区间。绝对值用于工程师评估技术影响，相对值用于产品和业务团队评估商业价值。

高级置信区间方法
同时置信区间（Simultaneous Confidence Intervals） 在多组比较时维持整体置信水平。Dunnett 方法专门用于多个实验组与单一对照组比较的场景，比 Bonferroni 调整更有统计功效。


import numpy as np
from scipy import stats

def dunnett_ci(control, treatments, alpha=0.05):
    k = len(treatments)
    n0 = len(control)
    mean0 = np.mean(control)
    var0 = np.var(control, ddof=1)

    results = []
    for i, trt in enumerate(treatments):
        ni = len(trt)
        mean_i = np.mean(trt)
        var_i = np.var(trt, ddof=1)
        diff = mean_i - mean0
        se = np.sqrt(var_i / ni + var0 / n0)

        bonf_z = stats.norm.ppf(1 - alpha / (2 * k))
        ci_lower = diff - bonf_z * se
        ci_upper = diff + bonf_z * se
        results.append({
            'variant': i + 1,
            'diff': diff,
            'ci': (ci_lower, ci_upper),
        })
    return results

np.random.seed(42)
ctrl = np.random.normal(100, 15, 10000)
trt_a = np.random.normal(102, 15, 10000)
trt_b = np.random.normal(99, 15, 10000)
trt_c = np.random.normal(103, 15, 10000)

results = dunnett_ci(ctrl, [trt_a, trt_b, trt_c])
for r in results:
    print(f"Variant {r['variant']}: diff={r['diff']:.2f}, CI=({r['ci'][0]:.2f}, {r['ci'][1]:.2f})")
预测区间（Prediction Intervals） 与置信区间不同，它预测的是单个未来观测值的范围。在实验平台中，预测区间可用于设置指标的异常检测阈值和护栏指标的预警范围。


分位数的置信区间：对于中位数或其他分位数的差异，标准的 Z/T 区间不适用。需要使用 Bootstrap 方法或基于 order statistics 的精确方法来构建分位数差异的置信区间。这在分析收入分位数或延迟 P99 变化时尤为重要。

小结
    

  • 置信区间提供效应大小的范围估计，比单纯的 p 值更具信息量，是实验决策的核心工具
    • 

  • 比率差异推荐使用 Newcombe-Wilson 方法构建置信区间，覆盖率优于 Wald 方法
    • 

  • 连续指标使用 Welch's T 区间或 Bootstrap BCa 区间，后者对偏态分布更稳健
    • 

  • 将置信区间与 MDE 结合进行业务决策：区间下界 > MDE 时放心发布，区间包含 0 时不发布
    • 

  • 多组比较时使用 Dunnett 同时置信区间，维持整体置信水平
    • 

  • 报告中同时展示绝对和相对置信区间，满足不同角色的决策需求
    •
