假设检验

核心概念

假设检验是 A/B 测试的统计基石，通过构建零假设与备择假设的对立框架，利用样本数据推断总体特征。在互联网实验中，假设检验决定了一个实验变体是否带来了真实的指标提升，而非随机波动。理解假设检验的数学原理和实际应用陷阱，是构建可信实验体系的前提。

Z 检验与 T 检验
在 A/B 测试中，Z 检验和 T 检验是最常用的两类参数检验方法。当样本量足够大（通常 n > 30）时，中心极限定理保证了样本均值近似正态分布，Z 检验适用；当样本量较小或总体方差未知时，T 检验更为稳健。


对于比率型指标（如转化率），双样本 Z 检验的统计量为：


Z=p^1−p^2p^(1−p^)(1n1+1n2)Z = \frac{\hat{p}_1 - \hat{p}_2}{\sqrt{\hat{p}(1-\hat{p})(\frac{1}{n_1} + \frac{1}{n_2})}}Z=p^​(1−p^​)(n1​1​+n2​1​)​p^​1​−p^​2​​
其中 p^\hat{p}p^​ 是合并比率。对于连续型指标（如人均消费），Welch's T 检验不假设等方差：


t=Xˉ1−Xˉ2s12n1+s22n2t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}}t=n1​s12​​+n2​s22​​​Xˉ1​−Xˉ2​​
import numpy as np
from scipy import stats

def z_test_proportions(p1, n1, p2, n2):
    p_pool = (p1 * n1 + p2 * n2) / (n1 + n2)
    se = np.sqrt(p_pool * (1 - p_pool) * (1/n1 + 1/n2))
    z = (p1 - p2) / se
    p_value = 2 * (1 - stats.norm.cdf(abs(z)))
    return z, p_value

def welch_t_test(x1, x2):
    t_stat, p_value = stats.ttest_ind(x1, x2, equal_var=False)
    return t_stat, p_value

z, pval = z_test_proportions(0.052, 50000, 0.048, 50000)
print(f"Z = {z:.4f}, p = {pval:.4f}")

实际应用中，互联网 A/B 测试的样本量通常非常大（数十万到数百万），此时 Z 检验和 T 检验的结果几乎完全一致。更重要的选择是单侧检验还是双侧检验：双侧检验更保守但避免了方向性偏见，推荐作为默认选择。


多重检验校正
当一个实验同时检验多个指标或多个变体时，每个检验都有 α 概率产生假阳性。如果检验 20 个指标且 α=0.05，期望有 1 个假阳性出现。多重检验校正通过调整显著性阈值来控制整体错误率。


三种主要的错误率控制策略：


族错误率（FWER）控制：Bonferroni 校正将每个检验的阈值调整为 α/m（m 为检验次数），确保至少一个假阳性的概率不超过 α。方法简单但过于保守，在检验数量多时统计功效大幅下降。


错误发现率（FDR）控制：Benjamini-Hochberg 方法控制的是假阳性占所有显著结果的期望比例。将 p 值从小到大排序，第 i 个 p 值与阈值 i·α/m 比较。FDR 控制在检验数量多时比 FWER 更有统计功效。


import numpy as np
from statsmodels.stats.multitest import multipletests

p_values = [0.001, 0.008, 0.039, 0.041, 0.062, 0.13, 0.45, 0.91]

reject_bonf, pvals_bonf, _, _ = multipletests(p_values, alpha=0.05, method='bonferroni')
reject_bh, pvals_bh, _, _ = multipletests(p_values, alpha=0.05, method='fdr_bh')
reject_holm, pvals_holm, _, _ = multipletests(p_values, alpha=0.05, method='holm')

for i, p in enumerate(p_values):
    print(f"p={p:.3f} | Bonferroni: {reject_bonf[i]} | Holm: {reject_holm[i]} | BH: {reject_bh[i]}")

在实际实验平台中，推荐的策略是：预先定义 1-2 个主要指标（不做多重校正或使用 Holm 校正），其余为辅助指标（使用 BH 校正），护栏指标单独监控。


非参数检验方法
当数据不满足正态性假设或存在严重偏态分布时（如收入数据、交易金额），非参数检验不依赖分布假设，更加稳健。常用方法包括 Mann-Whitney U 检验、置换检验和 Bootstrap 检验。


Mann-Whitney U 检验基于秩次比较两组数据的分布位置：


from scipy import stats
import numpy as np

np.random.seed(42)
control = np.random.exponential(scale=50, size=10000)
treatment = np.random.exponential(scale=52, size=10000)

u_stat, p_value = stats.mannwhitneyu(control, treatment, alternative='two-sided')
print(f"Mann-Whitney U = {u_stat:.0f}, p = {p_value:.6f}")

def permutation_test(x, y, n_perm=10000):
    observed_diff = np.mean(y) - np.mean(x)
    combined = np.concatenate([x, y])
    n_x = len(x)
    count = 0
    for _ in range(n_perm):
        np.random.shuffle(combined)
        perm_diff = np.mean(combined[n_x:]) - np.mean(combined[:n_x])
        if abs(perm_diff) >= abs(observed_diff):
            count += 1
    return count / n_perm

p_perm = permutation_test(control, treatment, n_perm=10000)
print(f"Permutation test p = {p_perm:.4f}")
置换检验的核心思想是：如果零假设成立（两组无差异），那么将数据标签随机打乱后计算出的统计量应与原始统计量相似。通过大量置换构建零分布，直接计算 p 值。置换检验是精确检验，不需要渐近近似，适用于任意指标形式。


Bootstrap 检验通过重采样估计统计量的分布，特别适合复杂指标（如比率的比率、分位数差异）。与置换检验不同，Bootstrap 主要用于构建置信区间而非直接进行假设检验。

方差缩减技术
在 A/B 测试中，方差缩减技术通过降低指标的波动性来提高检验的统计功效，等效于减少所需样本量或缩短实验周期。这对于流量有限或需要快速迭代的场景尤为重要。


CUPED（Controlled-experiment Using Pre-Experiment Data） 是目前业界最广泛使用的方差缩减方法。核心思想是利用实验前的协变量信息，构造一个方差更小的调整指标：


Yadj=Y−θ(X−Xˉ)Y_{adj} = Y - \theta(X - \bar{X})Yadj​=Y−θ(X−Xˉ)
其中 θ=Cov(Y,X)/Var(X)\theta = \text{Cov}(Y, X) / \text{Var}(X)θ=Cov(Y,X)/Var(X)，X 是实验前同一指标的值。方差缩减比例为 1−ρ21 - \rho^21−ρ2，ρ\rhoρ 是 Y 与 X 的相关系数。


import numpy as np
import pandas as pd

def cuped_adjustment(y_treatment, y_control, x_treatment, x_control):
    y = np.concatenate([y_treatment, y_control])
    x = np.concatenate([x_treatment, x_control])

    theta = np.cov(y, x)[0, 1] / np.var(x)

    y_adj_treatment = y_treatment - theta * (x_treatment - np.mean(x))
    y_adj_control = y_control - theta * (x_control - np.mean(x))

    var_reduction = 1 - np.corrcoef(y, x)[0, 1] ** 2

    return y_adj_treatment, y_adj_control, var_reduction

np.random.seed(42)
n = 50000
x_pre = np.random.normal(100, 30, 2 * n)
y_post = x_pre * 0.7 + np.random.normal(0, 20, 2 * n)
y_post[n:] += 2

y_adj_t, y_adj_c, var_red = cuped_adjustment(
    y_post[n:], y_post[:n], x_pre[n:], x_pre[:n]
)
print(f"Variance reduction: {var_red:.1%}")
分层分析（Stratification） 通过按预定义特征（如国家、平台、新老用户）将样本分层，在每一层内单独计算差异再加权合并，消除层间异质性带来的方差。分层分析通常能带来 5-15% 的方差缩减。


CUPAC（Controlled Using Predictions As Covariates） 是 CUPED 的机器学习扩展版本。使用实验前数据训练一个预测模型来预测实验期间的指标值，将预测值作为协变量进行调整。当指标与单一历史值的线性相关性不高时，CUPAC 能获得更大的方差缩减。

小结
    

  • 假设检验通过 H₀/H₁ 框架和 p 值判定实验变体是否带来了真实效应，是 A/B 测试的统计核心
    • 

  • Z 检验适用于比率型指标的大样本场景，Welch's T 检验适用于连续型指标且不假设等方差
    • 

  • 多重检验校正防止检验数量增多导致假阳性膨胀，Bonferroni 控制 FWER，BH 控制 FDR
    • 

  • 非参数检验（Mann-Whitney U、置换检验、Bootstrap）在数据分布偏态严重时比参数检验更稳健
    • 

  • CUPED 利用实验前数据进行方差缩减，能提升 20-50% 的统计功效，是大规模实验平台的标配技术
    • 

  • 实际 A/B 测试应预先定义主要指标和显著性水平，避免事后挖掘和 p-hacking
    •
