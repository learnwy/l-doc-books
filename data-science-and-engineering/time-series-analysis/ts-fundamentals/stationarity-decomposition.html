平稳性与时序分解

核心概念

平稳性（Stationarity）是时间序列分析中最基础也最关键的概念。绝大多数经典时间序列模型（如 ARIMA、GARCH）都建立在平稳性假设之上。一个平稳过程的统计性质不随时间推移而改变，这意味着均值、方差和自协方差函数在时间轴上保持恒定。非平稳序列必须通过差分、去趋势或变换等方法转化为平稳序列后才能使用这些模型。

平稳性检验是时间序列建模的第一步。如果将非平稳序列错误地当作平稳序列建模，会导致伪回归（Spurious Regression）——两个毫无关系的非平稳序列可能表现出统计上高度显著的相关性，这纯粹是因为它们各自的趋势而非真实的因果关系。


单位根检验
单位根检验是判断时间序列是否平稳的标准统计工具。ADF 检验（Augmented Dickey-Fuller Test）是最常用的单位根检验方法，它的零假设是序列存在单位根（非平稳），备择假设是序列平稳。当 ADF 统计量小于临界值（或 p 值小于 0.05）时，拒绝零假设，认为序列平稳。


from statsmodels.tsa.stattools import adfuller, kpss
import numpy as np
import pandas as pd

def adf_test(series, significance=0.05):
    result = adfuller(series.dropna(), autolag='AIC')

    return {
        'test_statistic': result[0],
        'p_value': result[1],
        'lags_used': result[2],
        'n_observations': result[3],
        'critical_values': result[4],
        'is_stationary': result[1] < significance,
        'conclusion': 'Stationary' if result[1] < significance else 'Non-stationary'
    }

def kpss_test(series, regression='c', significance=0.05):
    result = kpss(series.dropna(), regression=regression, nlags='auto')

    return {
        'test_statistic': result[0],
        'p_value': result[1],
        'lags_used': result[2],
        'critical_values': result[3],
        'is_stationary': result[1] > significance,
        'conclusion': 'Stationary' if result[1] > significance else 'Non-stationary'
    }

def comprehensive_stationarity_test(series):
    adf_result = adf_test(series)
    kpss_c_result = kpss_test(series, regression='c')
    kpss_ct_result = kpss_test(series, regression='ct')

    interpretation = 'ambiguous'
    if adf_result['is_stationary'] and kpss_c_result['is_stationary']:
        interpretation = 'stationary'
    elif not adf_result['is_stationary'] and not kpss_c_result['is_stationary']:
        interpretation = 'non_stationary'
    elif adf_result['is_stationary'] and not kpss_c_result['is_stationary']:
        interpretation = 'trend_stationary'
    elif not adf_result['is_stationary'] and kpss_c_result['is_stationary']:
        interpretation = 'difference_stationary'

    return {
        'adf': adf_result,
        'kpss_constant': kpss_c_result,
        'kpss_trend': kpss_ct_result,
        'interpretation': interpretation
    }
KPSS 检验（Kwiatkowski-Phillips-Schmidt-Shin Test）与 ADF 检验互补，它的零假设和 ADF 相反——零假设是序列平稳，备择假设是序列非平稳。联合使用 ADF 和 KPSS 检验可以更准确地判断平稳性：两者都支持平稳 → 确认平稳；两者都支持非平稳 → 确认非平稳；ADF 支持平稳但 KPSS 不支持 → 可能是趋势平稳；ADF 不支持平稳但 KPSS 支持 → 可能是差分平稳。

差分与去趋势
差分（Differencing）是将非平稳序列转化为平稳序列的最常用方法。一阶差分 Δxt=xt−xt−1\Delta x_t = x_t - x_{t-1}Δxt​=xt​−xt−1​ 消除线性趋势，二阶差分消除二次趋势。季节差分 Δsxt=xt−xt−s\Delta_s x_t = x_t - x_{t-s}Δs​xt​=xt​−xt−s​ 消除以 sss 为周期的季节性成分。


def find_diff_order(series, max_d=3, significance=0.05):
    for d in range(max_d + 1):
        if d == 0:
            diff_series = series
        else:
            diff_series = series.diff(d).dropna()

        adf_result = adfuller(diff_series, autolag='AIC')

        if adf_result[1] < significance:
            return {
                'optimal_d': d,
                'p_value': adf_result[1],
                'test_statistic': adf_result[0]
            }

    return {'optimal_d': max_d, 'p_value': adf_result[1], 'note': 'max_d reached'}

def seasonal_diff(series, period=12):
    return series.diff(period).dropna()

def detrend_methods(series, method='linear'):
    t = np.arange(len(series))

    if method == 'linear':
        coeffs = np.polyfit(t, series, 1)
        trend = np.polyval(coeffs, t)
    elif method == 'quadratic':
        coeffs = np.polyfit(t, series, 2)
        trend = np.polyval(coeffs, t)
    elif method == 'hp_filter':
        from statsmodels.tsa.filters.hp_filter import hpfilter
        _, trend = hpfilter(series, lamb=1600)

    detrended = series - trend
    return detrended, trend
过度差分是一个常见的错误。如果对已经平稳的序列继续差分，会引入不必要的负自相关，降低模型的预测精度。判断是否需要差分的实用规则是：如果差分后序列的方差增大而非减小，说明原序列可能已经平稳，不需要差分。


Box-Cox 变换是处理方差非平稳的标准方法。它通过参数 λ\lambdaλ 控制变换的形式：λ=0\lambda = 0λ=0 时为对数变换，λ=0.5\lambda = 0.5λ=0.5 时为平方根变换，λ=1\lambda = 1λ=1 时为恒等变换。最优 λ\lambdaλ 可以通过最大似然估计自动确定。


经典时序分解
时序分解（Time Series Decomposition）将原始序列拆分为趋势、季节和残差三个成分。经典分解法假设季节成分在每个周期内保持不变，使用移动平均提取趋势，季节成分为同期均值偏差，残差为分解后的剩余部分。


from statsmodels.tsa.seasonal import seasonal_decompose, STL

def classical_decomposition(series, period=12, model='additive'):
    result = seasonal_decompose(series, model=model, period=period)

    return {
        'trend': result.trend,
        'seasonal': result.seasonal,
        'residual': result.resid,
        'observed': result.observed,
        'strength_of_trend': 1 - np.nanvar(result.resid) / np.nanvar(result.trend + result.resid),
        'strength_of_seasonality': 1 - np.nanvar(result.resid) / np.nanvar(result.seasonal + result.resid)
    }

def stl_decomposition(series, period=12, robust=True):
    stl = STL(series, period=period, robust=robust)
    result = stl.fit()

    remainder_var = np.var(result.resid)
    deseason_var = np.var(result.trend + result.resid)
    detrend_var = np.var(result.seasonal + result.resid)

    return {
        'trend': result.trend,
        'seasonal': result.seasonal,
        'residual': result.resid,
        'trend_strength': max(0, 1 - remainder_var / deseason_var),
        'seasonal_strength': max(0, 1 - remainder_var / detrend_var)
    }
STL 分解（Seasonal and Trend decomposition using Loess）是经典分解法的现代改进版。STL 使用 LOESS 局部回归代替简单移动平均来估计趋势和季节成分，能够处理季节性随时间变化的情况。STL 的 robust 模式对异常值具有鲁棒性，通过迭代加权减小异常点对分解结果的影响。


趋势强度和季节强度是量化分解结果的有用指标。趋势强度定义为 FT=max⁡(0,1−Var(Rt)/Var(Tt+Rt))F_T = \max(0, 1 - \text{Var}(R_t) / \text{Var}(T_t + R_t))FT​=max(0,1−Var(Rt​)/Var(Tt​+Rt​))，季节强度定义为 FS=max⁡(0,1−Var(Rt)/Var(St+Rt))F_S = \max(0, 1 - \text{Var}(R_t) / \text{Var}(S_t + R_t))FS​=max(0,1−Var(Rt​)/Var(St​+Rt​))。值接近 1 表示该成分占主导，接近 0 表示该成分很弱。

小结
    

  • 平稳性是经典时间序列模型的基本假设，非平稳序列必须经过变换才能使用 ARIMA 等模型
    • 

  • ADF 和 KPSS 检验互补使用，能够更准确地判断序列的平稳性类型（趋势平稳 vs 差分平稳）
    • 

  • 一阶差分消除线性趋势，季节差分消除周期性成分，过度差分会引入不必要的负自相关
    • 

  • Box-Cox 变换通过参数 λ 自适应地稳定方差，对数变换是 λ=0 的特例
    • 

  • 经典分解法假设季节成分恒定，STL 分解允许季节性随时间变化且对异常值鲁棒
    • 

  • 趋势强度和季节强度指标量化各成分对原始序列的贡献程度，指导后续建模策略
    • 

  • 实践中推荐"ADF+KPSS 联合检验 → 确定差分阶数 → STL 分解 → 残差平稳性复验"的标准流程
