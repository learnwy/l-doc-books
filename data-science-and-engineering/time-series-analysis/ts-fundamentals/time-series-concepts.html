时间序列基本概念

核心概念

时间序列（Time Series）是按照时间顺序排列的一组观测数据，每个数据点对应一个特定的时间戳。时间序列数据在金融市场、气象监测、工业传感器、用户行为分析和供应链管理等领域无处不在。与横截面数据不同，时间序列数据具有天然的时序依赖性——当前时刻的观测值往往与历史观测值存在统计关联，这种时间相关性是时间序列分析的基础。

理解这些基本成分及其相互作用是进行任何时间序列分析的前提。一条真实的时间序列通常是多个成分叠加（加法模型）或相乘（乘法模型）的结果。加法模型 Yt=Tt+St+Ct+ϵtY_t = T_t + S_t + C_t + \epsilon_tYt​=Tt​+St​+Ct​+ϵt​ 适用于季节性振幅不随趋势变化的情况；乘法模型 Yt=Tt×St×Ct×ϵtY_t = T_t \times S_t \times C_t \times \epsilon_tYt​=Tt​×St​×Ct​×ϵt​ 适用于季节性振幅随趋势成比例放大的情况。


时间序列的数学表示
时间序列在数学上可以被形式化为一个随机过程（Stochastic Process）的一次实现。设 {Xt:t∈T}\{X_t: t \in T\}{Xt​:t∈T} 为定义在某概率空间上的随机变量族，其中索引集 TTT 表示时间。我们观测到的时间序列数据 {x1,x2,…,xn}\{x_1, x_2, \ldots, x_n\}{x1​,x2​,…,xn​} 是这个随机过程的一条样本路径。


import numpy as np
import pandas as pd

def generate_time_series_components(n=365, seed=42):
    np.random.seed(seed)
    t = np.arange(n)

    trend = 0.05 * t + 10
    seasonal = 5 * np.sin(2 * np.pi * t / 7) + 3 * np.sin(2 * np.pi * t / 365)
    noise = np.random.normal(0, 1, n)

    additive = trend + seasonal + noise
    multiplicative = trend * (1 + 0.3 * np.sin(2 * np.pi * t / 7)) * (1 + 0.05 * noise)

    return pd.DataFrame({
        'date': pd.date_range('2024-01-01', periods=n, freq='D'),
        'trend': trend,
        'seasonal': seasonal,
        'noise': noise,
        'additive': additive,
        'multiplicative': multiplicative
    })

def compute_basic_statistics(series):
    return {
        'mean': np.mean(series),
        'variance': np.var(series),
        'std': np.std(series),
        'skewness': float(pd.Series(series).skew()),
        'kurtosis': float(pd.Series(series).kurtosis()),
        'range': np.ptp(series),
        'coefficient_of_variation': np.std(series) / np.mean(series)
    }
均值函数 μt=E[Xt]\mu_t = E[X_t]μt​=E[Xt​] 和自协方差函数 γ(s,t)=Cov(Xs,Xt)\gamma(s, t) = \text{Cov}(X_s, X_t)γ(s,t)=Cov(Xs​,Xt​) 是描述时间序列统计特性的两个核心函数。如果均值函数和自协方差函数都不随时间变化（即 μt=μ\mu_t = \muμt​=μ，γ(s,t)=γ(∣s−t∣)\gamma(s, t) = \gamma(|s-t|)γ(s,t)=γ(∣s−t∣)），则称该时间序列为宽平稳（Weakly Stationary）的。平稳性假设极大地简化了时间序列建模问题。


时间序列的采样与频率
时间序列的采样频率（Sampling Frequency）决定了数据的时间分辨率。高频数据（如秒级交易数据）包含更多细节但也引入更多噪声，低频数据（如月度经济指标）信噪比高但可能丢失短期动态。采样频率的选择需要在信息密度和存储成本之间权衡。


def resample_time_series(df, time_col='date', value_col='value', target_freq='W'):
    df = df.set_index(time_col)

    resampled = df[value_col].resample(target_freq).agg(
        ['mean', 'median', 'min', 'max', 'std', 'count']
    )

    resampled['range'] = resampled['max'] - resampled['min']
    resampled['cv'] = resampled['std'] / resampled['mean'].abs()

    return resampled.reset_index()

def detect_missing_timestamps(df, time_col='date', freq='D'):
    df = df.set_index(time_col)
    full_range = pd.date_range(df.index.min(), df.index.max(), freq=freq)
    missing = full_range.difference(df.index)
    return missing, len(missing) / len(full_range)
时间序列数据中的缺失值处理比横截面数据更为复杂，因为时序上的缺失会破坏数据的连续性。常用的插补方法包括前向填充（用前一个非缺失值填充）、线性插值（假设相邻点之间线性变化）和样条插值（用多项式曲线拟合）。对于存在季节性的数据，季节性插值（用同一季节的历史值填充）通常更合理。

滑动窗口与时序统计量
滑动窗口（Rolling Window）分析是时间序列探索性分析的基础工具。通过在时间轴上移动固定长度的窗口并计算窗口内的统计量，可以观察统计特性随时间的变化情况。滑动均值揭示局部趋势，滑动方差揭示波动率变化，滑动相关系数揭示变量间关系的时变性。


def rolling_statistics(series, windows=[7, 14, 30]):
    result = pd.DataFrame({'original': series})

    for w in windows:
        result[f'rolling_mean_{w}'] = series.rolling(window=w, min_periods=1).mean()
        result[f'rolling_std_{w}'] = series.rolling(window=w, min_periods=1).std()
        result[f'rolling_min_{w}'] = series.rolling(window=w, min_periods=1).min()
        result[f'rolling_max_{w}'] = series.rolling(window=w, min_periods=1).max()
        result[f'rolling_skew_{w}'] = series.rolling(window=w, min_periods=1).skew()

    for w in windows:
        result[f'expanding_mean_{w}'] = series.expanding(min_periods=w).mean()

    for alpha in [0.1, 0.3, 0.5]:
        result[f'ewm_{alpha}'] = series.ewm(alpha=alpha).mean()

    return result

def compute_volatility(series, window=20):
    log_returns = np.log(series / series.shift(1)).dropna()

    realized_vol = log_returns.rolling(window=window).std() * np.sqrt(252)

    ewma_vol = log_returns.ewm(span=window).std() * np.sqrt(252)

    return pd.DataFrame({
        'log_returns': log_returns,
        'realized_volatility': realized_vol,
        'ewma_volatility': ewma_vol
    })
指数加权移动平均（EWMA）是滑动窗口方法的一个重要变体。与简单移动平均对窗口内所有点赋予相同权重不同，EWMA 对较近的数据点赋予更高的权重，权重按指数衰减。衰减因子 α\alphaα 控制了新旧数据的权重分配：α\alphaα 越大，新数据的影响越大，EWMA 越贴近原始序列；α\alphaα 越小，平滑效果越强。


时间序列可视化
可视化是理解时间序列模式的第一步。除了基本的线图之外，专业的时间序列可视化还包括季节性子图、滞后散点图和频谱分析图等工具。


滞后散点图（Lag Plot）将序列值与其滞后值画在二维散点图上。如果数据点形成明显的线性聚集，说明序列存在强自相关性；如果散点随机分布，说明序列接近白噪声。不同滞后阶数的散点图可以揭示不同时间尺度上的依赖结构。


def create_lag_features(series, max_lag=12):
    df = pd.DataFrame({'value': series})
    for lag in range(1, max_lag + 1):
        df[f'lag_{lag}'] = series.shift(lag)
    return df.dropna()

def seasonal_subseries_stats(series, period=12):
    n = len(series)
    results = []
    for s in range(period):
        subseries = series[s::period]
        results.append({
            'season': s + 1,
            'mean': np.mean(subseries),
            'std': np.std(subseries),
            'min': np.min(subseries),
            'max': np.max(subseries),
            'trend': np.polyfit(range(len(subseries)), subseries, 1)[0]
        })
    return pd.DataFrame(results)

小结
    

  • 时间序列由趋势、季节性、周期性和随机波动四个基本成分叠加或相乘构成
    • 

  • 加法模型适用于季节振幅恒定的场景，乘法模型适用于季节振幅随趋势变化的场景
    • 

  • 均值函数和自协方差函数是描述时间序列统计特性的核心工具，平稳性假设极大简化建模
    • 

  • 采样频率的选择影响信息密度和噪声水平，时序缺失值需要使用保持时间连续性的插补方法
    • 

  • 滑动窗口统计量揭示局部趋势和波动率变化，EWMA 通过指数衰减权重实现对近期数据的偏重
    • 

  • 滞后散点图、季节性子图和频谱图是时间序列专业可视化的核心工具
    • 

  • 时间序列分析的基本流程：可视化探索 → 成分识别 → 平稳性检验 → 模型选择 → 预测与评估
