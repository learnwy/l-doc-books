集成预测方法

核心概念

集成预测（Ensemble Forecasting）是将多个预测模型的输出组合成一个最终预测的方法论。在时间序列预测中，没有单一模型能够在所有场景下表现最优（No Free Lunch 定理），而集成方法通过聚合多个模型的预测结果，利用模型之间的互补性来提升整体预测的准确性和鲁棒性。

集成预测的理论基础是偏差-方差分解：单个模型可能有较高的偏差（系统性偏差）或较高的方差（对训练数据的敏感性），而合理的集成能够同时降低偏差和方差。研究表明，即使参与集成的单个模型质量一般，只要模型之间足够"不同"（即预测误差不相关），集成后的效果也能显著优于单个模型。

同质集成方法
同质集成（Homogeneous Ensemble）使用同一类基础模型的多个变体进行集成。在时间序列中，最常见的同质集成方法包括 Bagging（Bootstrap Aggregating）和基于不同超参数的模型池。


Bagging 通过对训练数据进行有放回采样生成多个子数据集，在每个子数据集上训练一个基础模型，最后聚合所有模型的预测。在时间序列场景中，标准的 Bagging 需要修改采样策略以保持时间依赖结构。


interface TimeSeriesBaggingConfig {
  numModels: number;
  blockLength: number;
  sampleRatio: number;
}

function movingBlockBootstrap(series: number[], blockLength: number, targetLength: number): number[] {
  const result: number[] = [];
  while (result.length < targetLength) {
    const start = Math.floor(Math.random() * (series.length - blockLength));
    const block = series.slice(start, start + blockLength);
    result.push(...block);
  }
  return result.slice(0, targetLength);
}

function baggingForecast(
  series: number[],
  config: TimeSeriesBaggingConfig,
  forecastHorizon: number,
  modelFn: (data: number[]) => number[],
): { mean: number[]; lower: number[]; upper: number[] } {
  const forecasts: number[][] = [];

  for (let i = 0; i < config.numModels; i++) {
    const bootstrapSeries = movingBlockBootstrap(
      series,
      config.blockLength,
      Math.floor(series.length * config.sampleRatio),
    );
    const forecast = modelFn(bootstrapSeries);
    forecasts.push(forecast.slice(0, forecastHorizon));
  }

  const mean = Array.from({ length: forecastHorizon }, (_, h) => {
    const vals = forecasts.map((f) => f[h]);
    return vals.reduce((a, b) => a + b) / vals.length;
  });

  const lower = Array.from({ length: forecastHorizon }, (_, h) => {
    const vals = forecasts.map((f) => f[h]).sort((a, b) => a - b);
    return vals[Math.floor(vals.length * 0.025)];
  });

  const upper = Array.from({ length: forecastHorizon }, (_, h) => {
    const vals = forecasts.map((f) => f[h]).sort((a, b) => a - b);
    return vals[Math.floor(vals.length * 0.975)];
  });

  return { mean, lower, upper };
}
移动块自助法（Moving Block Bootstrap）是时间序列 Bagging 的标准采样策略。它将原始序列切分为重叠的固定长度块，然后随机有放回地抽取这些块重新拼接成新序列。块长度的选择是关键超参数：太短会破坏时间依赖，太长会降低采样多样性。


异质集成方法
异质集成（Heterogeneous Ensemble）组合不同类型的基础模型，利用不同模型在不同数据模式上的互补优势。典型的异质集成包括统计模型（ARIMA、ETS）、机器学习模型（LightGBM、XGBoost）和深度学习模型（LSTM、Transformer）的组合。


interface EnsembleMember {
  name: string;
  predict: (history: number[], horizon: number) => number[];
  weight: number;
}

function computeOptimalWeights(
  models: EnsembleMember[],
  validationData: Array<{ history: number[]; actual: number[] }>,
): number[] {
  const n = models.length;
  const errors: number[][] = [];

  for (const model of models) {
    const modelErrors: number[] = [];
    for (const { history, actual } of validationData) {
      const forecast = model.predict(history, actual.length);
      const mse = actual.reduce((sum, a, i) => sum + (a - forecast[i]) ** 2, 0) / actual.length;
      modelErrors.push(mse);
    }
    errors.push(modelErrors);
  }

  const avgErrors = errors.map((e) => e.reduce((a, b) => a + b) / e.length);
  const invErrors = avgErrors.map((e) => 1 / Math.max(e, 1e-10));
  const sumInv = invErrors.reduce((a, b) => a + b);

  return invErrors.map((w) => w / sumInv);
}

function heterogeneousEnsemble(members: EnsembleMember[], history: number[], horizon: number): number[] {
  const forecasts = members.map((m) => m.predict(history, horizon));
  return Array.from({ length: horizon }, (_, h) => members.reduce((sum, m, i) => sum + m.weight * forecasts[i][h], 0));
}

Stacking 与元学习
Stacking（堆叠泛化）是集成学习中最强大的组合策略。它不是简单地加权平均基础模型的预测，而是训练一个元模型（meta-model）来学习如何最优地组合基础模型的输出。


Stacking 的标准流程分为两层：第一层包含多个不同的基础模型，每个模型对训练数据进行交叉验证生成元特征（out-of-fold predictions）；第二层的元模型以元特征为输入，学习最优组合策略。


interface StackingConfig {
  baseModels: Array<{
    name: string;
    train: (x: number[][], y: number[]) => (x: number[][]) => number[];
  }>;
  metaModel: {
    train: (x: number[][], y: number[]) => (x: number[][]) => number[];
  };
  cvFolds: number;
}

function timeSeriesStacking(trainX: number[][], trainY: number[], testX: number[][], config: StackingConfig): number[] {
  const n = trainX.length;
  const foldSize = Math.floor(n / config.cvFolds);
  const metaFeatures = Array.from({ length: n }, () => new Array(config.baseModels.length).fill(0));
  const testMetaFeatures = Array.from({ length: testX.length }, () => new Array(config.baseModels.length).fill(0));

  for (let m = 0; m < config.baseModels.length; m++) {
    const model = config.baseModels[m];

    for (let fold = 0; fold < config.cvFolds; fold++) {
      const valStart = fold * foldSize;
      const valEnd = valStart + foldSize;

      const foldTrainX = [...trainX.slice(0, valStart), ...trainX.slice(valEnd)];
      const foldTrainY = [...trainY.slice(0, valStart), ...trainY.slice(valEnd)];
      const foldValX = trainX.slice(valStart, valEnd);

      const predict = model.train(foldTrainX, foldTrainY);
      const valPreds = predict(foldValX);
      valPreds.forEach((p, i) => {
        metaFeatures[valStart + i][m] = p;
      });
    }

    const fullPredict = model.train(trainX, trainY);
    const testPreds = fullPredict(testX);
    testPreds.forEach((p, i) => {
      testMetaFeatures[i][m] = p;
    });
  }

  const metaPredict = config.metaModel.train(metaFeatures, trainY);
  return metaPredict(testMetaFeatures);
}
元学习的关键在于元特征的设计。除了基础模型的预测值，还可以加入序列统计特征（趋势强度、季节性强度、偏度等）作为元特征，帮助元模型判断"在什么类型的序列上应该更信任哪个模型"。


小结
    

  • 集成预测通过聚合多个模型的互补性来提升准确性和鲁棒性，是时序预测的核心策略
    • 

  • 同质集成（Bagging）通过数据扰动创造模型多样性，移动块自助法适用于保持时间依赖结构
    • 

  • 异质集成组合统计、ML 和 DL 模型的不同优势，M 竞赛获胜方案普遍使用集成策略
    • 

  • Stacking 通过元模型学习非线性组合策略，是最强大的集成方法但也最复杂
    • 

  • 集成的有效性取决于成员模型的多样性，高度相关的模型集成收益有限
    • 

  • 在实践中，简单加权平均往往是起点最佳的集成策略，Stacking 需要足够的验证数据支撑
    •
