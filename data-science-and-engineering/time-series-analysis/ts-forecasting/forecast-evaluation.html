预测评估与验证

核心概念

预测评估与验证是时间序列预测流程中至关重要的环节，它决定了我们能否客观地衡量模型的预测能力、比较不同模型的优劣以及判断预测结果是否可以信赖。与分类或回归任务不同，时间序列预测的评估面临独特挑战：时间依赖性使得传统的随机交叉验证失效，多步预测的误差随步数增长而累积，不同应用场景对误差的容忍度和偏好各不相同。

预测评估的三个核心维度是：精度评估（预测值与实际值的偏差度量）、验证策略（如何划分数据以避免信息泄露）和统计检验（如何判断模型差异是否具有统计显著性）。

精度指标体系
精度指标是预测评估的量化基础。不同的指标对误差的惩罚方式不同，选择合适的指标需要理解业务场景对误差的偏好。


MAE（Mean Absolute Error） 对所有误差等权处理，不受极端值影响，是最直觉的误差度量。RMSE（Root Mean Squared Error） 对大误差给予更高的惩罚，适合大误差代价高昂的场景。MAPE（Mean Absolute Percentage Error） 将误差标准化为百分比，便于跨序列比较，但在实际值接近零时会失效。


interface ForecastMetrics {
  mae: number;
  rmse: number;
  mape: number;
  smape: number;
  mase: number;
}

function computeMetrics(actual: number[], predicted: number[], trainSeries: number[]): ForecastMetrics {
  const n = actual.length;
  const errors = actual.map((a, i) => a - predicted[i]);
  const absErrors = errors.map(Math.abs);

  const mae = absErrors.reduce((a, b) => a + b) / n;

  const rmse = Math.sqrt(errors.reduce((sum, e) => sum + e * e, 0) / n);

  const mape = (actual.reduce((sum, a, i) => sum + Math.abs(errors[i]) / Math.max(Math.abs(a), 1e-10), 0) / n) * 100;

  const smape =
    (actual.reduce((sum, a, i) => sum + (2 * Math.abs(errors[i])) / (Math.abs(a) + Math.abs(predicted[i]) + 1e-10), 0) /
      n) *
    100;

  const naiveErrors = trainSeries.slice(1).map((v, i) => Math.abs(v - trainSeries[i]));
  const naiveMae = naiveErrors.reduce((a, b) => a + b) / naiveErrors.length;
  const mase = mae / Math.max(naiveMae, 1e-10);

  return { mae, rmse, mape, smape, mase };
}
MASE（Mean Absolute Scaled Error） 是 M 竞赛推荐的标准指标。它将 MAE 除以朴素预测（naive forecast，即"明天和今天一样"）的 MAE，得到一个无量纲的相对指标。MASE < 1 表示模型优于朴素预测，MASE > 1 表示模型不如朴素预测。MASE 的优势在于它既不受数据尺度影响，也不在零值附近失效。

时间序列交叉验证
时间序列的验证策略必须严格遵循时间顺序，不能使用标准的 K 折交叉验证（这会导致用未来数据训练模型，造成数据泄露）。时间序列交叉验证的三种主要策略是：固定窗口、滑动窗口和扩展窗口。


type WindowStrategy = 'fixed' | 'sliding' | 'expanding';

interface TSCVConfig {
  strategy: WindowStrategy;
  minTrainSize: number;
  testSize: number;
  step: number;
  maxFolds?: number;
}

interface CVFold {
  trainStart: number;
  trainEnd: number;
  testStart: number;
  testEnd: number;
}

function generateCVFolds(dataLength: number, config: TSCVConfig): CVFold[] {
  const folds: CVFold[] = [];
  let trainEnd = config.minTrainSize;

  while (trainEnd + config.testSize <= dataLength) {
    const testStart = trainEnd;
    const testEnd = testStart + config.testSize;

    let trainStart: number;
    switch (config.strategy) {
      case 'expanding':
        trainStart = 0;
        break;
      case 'sliding':
        trainStart = Math.max(0, trainEnd - config.minTrainSize);
        break;
      case 'fixed':
        trainStart = 0;
        break;
    }

    folds.push({ trainStart, trainEnd, testStart, testEnd });
    trainEnd += config.step;

    if (config.maxFolds && folds.length >= config.maxFolds) break;
  }

  return folds;
}

function runTimeSeriesCV(
  data: number[],
  config: TSCVConfig,
  trainAndPredict: (train: number[], horizon: number) => number[],
): { foldMetrics: ForecastMetrics[]; avgMetrics: ForecastMetrics } {
  const folds = generateCVFolds(data.length, config);
  const foldMetrics: ForecastMetrics[] = [];

  for (const fold of folds) {
    const train = data.slice(fold.trainStart, fold.trainEnd);
    const test = data.slice(fold.testStart, fold.testEnd);
    const predicted = trainAndPredict(train, test.length);
    foldMetrics.push(computeMetrics(test, predicted, train));
  }

  const avgMetrics = {
    mae: foldMetrics.reduce((s, m) => s + m.mae, 0) / foldMetrics.length,
    rmse: foldMetrics.reduce((s, m) => s + m.rmse, 0) / foldMetrics.length,
    mape: foldMetrics.reduce((s, m) => s + m.mape, 0) / foldMetrics.length,
    smape: foldMetrics.reduce((s, m) => s + m.smape, 0) / foldMetrics.length,
    mase: foldMetrics.reduce((s, m) => s + m.mase, 0) / foldMetrics.length,
  };

  return { foldMetrics, avgMetrics };
}
扩展窗口（expanding window）训练集不断增大，能够利用所有历史数据，适合数据量有限的场景。滑动窗口（sliding window）训练集大小固定，窗口向前移动，适合存在概念漂移的非平稳序列。固定窗口（fixed origin）只有一个划分点，最简单但评估稳定性最差。


概率预测评估
现代预测系统越来越重视概率预测（probabilistic forecasting），即不仅给出点预测，还要给出预测的不确定性区间。概率预测的评估需要专门的指标来衡量预测分布的质量。


CRPS（Continuous Ranked Probability Score） 是概率预测的标准评估指标，它衡量预测分布与实际观测值之间的距离。CRPS 可以看作是 MAE 的概率版本——当预测分布退化为点预测时，CRPS 等于 MAE。


校准图（Calibration Plot）是评估预测区间可靠性的可视化工具。对于一个理想的 90% 预测区间，约 90% 的实际观测值应该落在区间内。校准图将名义覆盖率与实际覆盖率进行对比，偏离对角线越远说明校准越差。

小结
    

  • 预测评估需要同时关注精度指标、验证策略和统计检验三个维度
    • 

  • MASE 是跨序列比较的推荐指标，MAPE 在零值附近不可靠
    • 

  • 时间序列交叉验证必须严格遵循时间顺序，扩展窗口和滑动窗口各有适用场景
    • 

  • 概率预测评估关注分布质量而非单一点预测，CRPS 是标准指标
    • 

  • 单一指标可能产生误导，建议同时使用 2-3 个互补的指标
    • 

  • 统计检验（如 Diebold-Mariano 检验）帮助判断模型差异是否具有统计显著性
    •
