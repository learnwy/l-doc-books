多步预测与层级预测

核心概念

多步预测（Multi-step Forecasting）和层级预测（Hierarchical Forecasting）是时间序列预测在实际业务中面临的两大核心挑战。多步预测需要生成未来多个时间步的预测值，面临误差累积和不确定性扩散的问题；层级预测需要在时间序列的层级结构（如全国→省→市→店铺）中保持预测的一致性，使得各层级的预测值满足聚合约束。

理解这些策略的权衡是实际预测项目中的关键决策。没有普遍最优的策略——递归策略在短步长和强自相关序列上表现好，直接策略在长步长和弱自相关序列上表现好。MIMO 策略在计算效率和性能之间提供了良好的平衡。


多步预测策略
递归策略（Recursive Strategy）使用单一的一步预测模型，将预测值作为下一步的输入循环迭代。它的核心问题是误差累积：第一步的预测误差会传递到第二步的输入中，经过多步迭代后误差可能急剧放大。


import numpy as np
import pandas as pd
from sklearn.ensemble import GradientBoostingRegressor

def recursive_forecast(model, last_window, n_steps, n_lags):
    forecasts = []
    current_window = list(last_window[-n_lags:])

    for step in range(n_steps):
        features = np.array(current_window[-n_lags:]).reshape(1, -1)
        pred = model.predict(features)[0]
        forecasts.append(pred)
        current_window.append(pred)

    return np.array(forecasts)

def direct_forecast(train_series, n_steps, n_lags=12):
    models = {}

    for h in range(1, n_steps + 1):
        X, y = [], []
        for i in range(n_lags, len(train_series) - h):
            X.append(train_series[i - n_lags:i])
            y.append(train_series[i + h - 1])

        X = np.array(X)
        y = np.array(y)

        model = GradientBoostingRegressor(n_estimators=100, random_state=42)
        model.fit(X, y)
        models[h] = model

    last_window = train_series[-n_lags:]
    forecasts = []
    for h in range(1, n_steps + 1):
        features = last_window.reshape(1, -1)
        forecasts.append(models[h].predict(features)[0])

    return np.array(forecasts), models

def mimo_forecast(train_series, n_steps, n_lags=12):
    X, Y = [], []
    for i in range(n_lags, len(train_series) - n_steps):
        X.append(train_series[i - n_lags:i])
        Y.append(train_series[i:i + n_steps])

    X = np.array(X)
    Y = np.array(Y)

    from sklearn.multioutput import MultiOutputRegressor
    base_model = GradientBoostingRegressor(n_estimators=100, random_state=42)
    model = MultiOutputRegressor(base_model)
    model.fit(X, Y)

    last_window = train_series[-n_lags:].reshape(1, -1)
    forecasts = model.predict(last_window)[0]

    return forecasts, model
直接策略（Direct Strategy）为每个预测步长训练独立的模型，第 h 步的模型直接预测 yt+hy_{t+h}yt+h​ 而不依赖中间步的预测值。它避免了误差累积，但代价是需要训练 h 个模型，且各步的预测之间可能缺乏时间一致性（如第 5 步的预测可能大于第 4 步和第 6 步的预测，形成不合理的锯齿形预测曲线）。


DirRec 策略结合了直接和递归的优点：每步训练独立模型，但输入特征中包含前面步骤的预测值。这样既利用了多步信息又避免了纯递归的严重误差累积。


层级时间序列预测
层级时间序列（Hierarchical Time Series）指的是一组时间序列之间存在聚合关系。例如公司的总销售额等于各部门销售额之和，各部门销售额又等于各产品线销售额之和。独立预测各层级的序列通常会导致不一致——各产品线的预测之和不等于部门的预测。


def bottom_up_forecast(bottom_level_forecasts, aggregation_matrix):
    bottom = np.array(bottom_level_forecasts)
    S = np.array(aggregation_matrix)
    return S @ bottom

def top_down_forecast(top_forecast, proportions):
    return top_forecast * np.array(proportions)

def mint_reconciliation(base_forecasts, S_matrix, residual_covariance):
    S = np.array(S_matrix)
    W = np.array(residual_covariance)

    W_inv = np.linalg.inv(W)

    P = np.linalg.inv(S.T @ W_inv @ S) @ S.T @ W_inv

    reconciled = S @ P @ np.array(base_forecasts)

    return reconciled

class HierarchicalForecaster:
    def __init__(self, S_matrix):
        self.S = np.array(S_matrix)
        self.n_bottom = self.S.shape[1]
        self.n_total = self.S.shape[0]

    def fit_base_forecasts(self, series_dict, model_fn):
        self.base_forecasts = {}
        self.base_residuals = {}

        for key, series in series_dict.items():
            model, forecast, residuals = model_fn(series)
            self.base_forecasts[key] = forecast
            self.base_residuals[key] = residuals

    def reconcile(self, method='ols'):
        y_hat = np.array(list(self.base_forecasts.values()))

        if method == 'ols':
            P = np.linalg.inv(self.S.T @ self.S) @ self.S.T
        elif method == 'wls':
            residuals = np.array(list(self.base_residuals.values()))
            W_diag = np.diag(np.var(residuals, axis=1))
            W_inv = np.diag(1.0 / np.diag(W_diag))
            P = np.linalg.inv(self.S.T @ W_inv @ self.S) @ self.S.T @ W_inv
        elif method == 'mint_shrink':
            residuals = np.array(list(self.base_residuals.values()))
            W = np.cov(residuals)
            n = W.shape[0]
            trace_W = np.trace(W)
            shrinkage = (np.sum(W**2) + trace_W**2) / ((n + 1) * (np.sum(W**2) - trace_W**2 / n))
            shrinkage = max(0, min(1, shrinkage))
            W_shrunk = shrinkage * np.diag(np.diag(W)) + (1 - shrinkage) * W
            W_inv = np.linalg.inv(W_shrunk)
            P = np.linalg.inv(self.S.T @ W_inv @ self.S) @ self.S.T @ W_inv

        reconciled = self.S @ P @ y_hat
        return reconciled
最优协调（Optimal Reconciliation）方法由 Hyndman 等人提出，它首先独立预测所有层级的序列（Base Forecasts），然后通过最小化某个目标函数找到满足聚合约束的最优调整。MinT（Minimum Trace）方法最小化协调后预测误差协方差矩阵的迹，是当前最推荐的协调方法。

间歇需求预测
间歇需求（Intermittent Demand）是指大量时间步的需求为零、偶尔出现非零需求的时间序列。这种模式在备件管理、长尾商品销售和低频事件预测中非常常见。传统的 ARIMA 和指数平滑方法在间歇需求上表现不佳，因为它们假设数据是连续的。


def croston_method(series, alpha=0.1, forecast_steps=12):
    demand = np.array(series)
    n = len(demand)

    z = demand[demand > 0]
    p_indices = np.where(demand > 0)[0]
    intervals = np.diff(p_indices)

    if len(z) < 2:
        return np.full(forecast_steps, np.mean(demand))

    z_hat = z[0]
    p_hat = intervals[0] if len(intervals) > 0 else 1

    forecasts_z = [z_hat]
    forecasts_p = [p_hat]

    for i in range(1, len(z)):
        z_hat = alpha * z[i] + (1 - alpha) * z_hat
        if i < len(intervals):
            p_hat = alpha * intervals[i] + (1 - alpha) * p_hat
        forecasts_z.append(z_hat)
        forecasts_p.append(p_hat)

    demand_rate = forecasts_z[-1] / max(forecasts_p[-1], 1)
    return np.full(forecast_steps, demand_rate)

def classify_demand_pattern(series, cv_threshold=0.49, adi_threshold=1.32):
    demand = np.array(series)
    non_zero = demand[demand > 0]

    if len(non_zero) == 0:
        return 'zero'

    cv = np.std(non_zero) / np.mean(non_zero) if np.mean(non_zero) > 0 else 0

    intervals = np.diff(np.where(demand > 0)[0])
    adi = np.mean(intervals) if len(intervals) > 0 else len(demand)

    if cv < cv_threshold and adi < adi_threshold:
        return 'smooth'
    elif cv >= cv_threshold and adi < adi_threshold:
        return 'erratic'
    elif cv < cv_threshold and adi >= adi_threshold:
        return 'intermittent'
    else:
        return 'lumpy'
Croston 方法将间歇需求分解为两个独立的子序列：非零需求大小序列和需求间隔序列，分别用简单指数平滑预测，最终的需求率预测为需求大小预测除以间隔预测。SBA（Syntetos-Boylan Approximation）是 Croston 方法的偏差修正版本，在实证研究中通常表现更好。


小结
    

  • 多步预测的递归策略误差累积严重，直接策略避免累积但缺乏步间一致性，MIMO 兼顾效率和性能
    • 

  • DirRec 策略结合直接和递归优点，在多数场景下是稳健的默认选择
    • 

  • 层级预测需要保持聚合一致性，最优协调（MinT）是当前最推荐的方法
    • 

  • 自底向上在底层数据丰富时效果好，自顶向下在底层数据稀疏时更稳健
    • 

  • 间歇需求预测需要专门的方法（Croston、SBA），传统方法在大量零值序列上失效
    • 

  • 需求模式分类（平滑/波动/间歇/块状）指导方法选择，不同模式适用不同预测方法
    • 

  • 实际项目中通常需要组合多种策略：层级协调 + 多步预测策略 + 间歇需求专门处理
    •
