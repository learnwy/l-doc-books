时序异常检测

核心概念

时序异常检测是从时间序列数据中识别偏离正常模式的数据点或时段的技术。在工业监控、网络安全、金融风控和运维等领域，及时发现时序数据中的异常模式是防止系统故障、安全入侵和业务损失的关键防线。与静态数据的异常检测不同，时序异常检测必须考虑数据的时间依赖性——同一个数值在不同时间上下文中可能是正常的也可能是异常的。

时序异常按照形态可分为三种类型：点异常（单个时间步的数值显著偏离预期）、上下文异常（数值本身不极端，但在特定时间上下文中异常，如夏天出现冬天的用电模式）和集合异常（一组连续的数据点共同构成异常模式，如系统性能的渐进恶化）。

统计方法与阈值检测
统计方法是时序异常检测的基础，其核心思想是建立正常数据的统计模型，将偏离模型预期的数据点标记为异常。最简单的方法是基于移动统计量（移动均值、移动标准差）设定动态阈值。


interface AnomalyResult {
  timestamp: number;
  value: number;
  isAnomaly: boolean;
  score: number;
  threshold: number;
}

function movingZScore(series: number[], windowSize: number, zThreshold: number): AnomalyResult[] {
  const results: AnomalyResult[] = [];

  for (let i = windowSize; i < series.length; i++) {
    const window = series.slice(i - windowSize, i);
    const mean = window.reduce((a, b) => a + b) / windowSize;
    const std = Math.sqrt(window.reduce((sum, v) => sum + (v - mean) ** 2, 0) / windowSize);

    const zScore = std > 0 ? Math.abs(series[i] - mean) / std : 0;
    results.push({
      timestamp: i,
      value: series[i],
      isAnomaly: zScore > zThreshold,
      score: zScore,
      threshold: zThreshold,
    });
  }

  return results;
}

function ewmaAnomalyDetection(series: number[], alpha: number, threshold: number): AnomalyResult[] {
  let ewma = series[0];
  let ewmVar = 0;
  const results: AnomalyResult[] = [];

  for (let i = 1; i < series.length; i++) {
    const residual = series[i] - ewma;
    ewma = alpha * series[i] + (1 - alpha) * ewma;
    ewmVar = alpha * residual ** 2 + (1 - alpha) * ewmVar;
    const ewmStd = Math.sqrt(ewmVar);

    const score = ewmStd > 0 ? Math.abs(residual) / ewmStd : 0;
    results.push({
      timestamp: i,
      value: series[i],
      isAnomaly: score > threshold,
      score,
      threshold,
    });
  }

  return results;
}
GESD（Generalized Extreme Studentized Deviate）检验是处理序列中可能存在多个异常值的统计方法。它通过迭代地移除最极端的值并重新计算统计量来避免"掩蔽效应"（一个异常值的存在使得其他异常值变得不那么极端）。


季节性分解后的残差分析是处理具有周期性模式的时序数据的常用策略：先用 STL（Seasonal-Trend decomposition using LOESS）将序列分解为趋势、季节性和残差，然后在残差序列上进行异常检测，避免周期性波动被误报为异常。


预测驱动的异常检测
预测驱动方法的核心思想是：用时间序列预测模型预测下一步的期望值和置信区间，如果实际观测值落在置信区间之外，则标记为异常。这种方法天然适合处理上下文异常，因为预测模型已经学习了序列的正常模式（趋势、季节性、自相关）。


interface PredictionBand {
  predicted: number;
  lower: number;
  upper: number;
  confidence: number;
}

function forecastBasedDetection(series: number[], windowSize: number, confidence: number): AnomalyResult[] {
  const results: AnomalyResult[] = [];

  for (let t = windowSize; t < series.length; t++) {
    const history = series.slice(t - windowSize, t);
    const band = computePredictionBand(history, confidence);

    const actual = series[t];
    const isAnomaly = actual < band.lower || actual > band.upper;
    const deviation = Math.abs(actual - band.predicted);
    const bandWidth = (band.upper - band.lower) / 2;
    const score = bandWidth > 0 ? deviation / bandWidth : 0;

    results.push({
      timestamp: t,
      value: actual,
      isAnomaly,
      score,
      threshold: 1,
    });
  }

  return results;
}

function computePredictionBand(history: number[], confidence: number): PredictionBand {
  const n = history.length;
  const mean = history.reduce((a, b) => a + b) / n;
  const trend = (history[n - 1] - history[0]) / n;
  const predicted = history[n - 1] + trend;

  const residuals = history.map((v, i) => v - (history[0] + trend * i));
  const std = Math.sqrt(residuals.reduce((s, r) => s + r * r, 0) / n);

  const zMap: Record<number, number> = { 0.9: 1.645, 0.95: 1.96, 0.99: 2.576 };
  const z = zMap[confidence] ?? 1.96;

  return {
    predicted,
    lower: predicted - z * std,
    upper: predicted + z * std,
    confidence,
  };
}
深度学习异常检测
深度学习方法在时序异常检测中展现了强大的模式学习能力，尤其适合处理多变量时间序列和复杂的非线性依赖。主流的深度学习异常检测方法包括自编码器（Autoencoder）、变分自编码器（VAE）和基于 GAN 的方法。


自编码器方法的核心思想是：在正常数据上训练一个编码器-解码器模型，使其学会压缩和重构正常模式。在推理时，异常数据的重构误差会显著高于正常数据，因此可以用重构误差作为异常分数。


interface AutoencoderConfig {
  inputDim: number;
  windowSize: number;
  encoderLayers: number[];
  latentDim: number;
}

interface AnomalyDetector {
  computeReconstructionError: (window: number[][]) => number;
  getThreshold: () => number;
}

function trainAutoencoder(normalWindows: number[][][], config: AutoencoderConfig): AnomalyDetector {
  const errors = normalWindows.map((window) => {
    const flatInput = window.flat();
    const reconstructed = simulateReconstruction(flatInput, config);
    return flatInput.reduce((sum, v, i) => sum + (v - reconstructed[i]) ** 2, 0) / flatInput.length;
  });

  const meanError = errors.reduce((a, b) => a + b) / errors.length;
  const stdError = Math.sqrt(errors.reduce((s, e) => s + (e - meanError) ** 2, 0) / errors.length);
  const threshold = meanError + 3 * stdError;

  return {
    computeReconstructionError: (window: number[][]) => {
      const flatInput = window.flat();
      const reconstructed = simulateReconstruction(flatInput, config);
      return flatInput.reduce((sum, v, i) => sum + (v - reconstructed[i]) ** 2, 0) / flatInput.length;
    },
    getThreshold: () => threshold,
  };
}

function simulateReconstruction(input: number[], config: AutoencoderConfig): number[] {
  return input.map((v) => v + (Math.random() - 0.5) * 0.1);
}

异常评估与告警优化
异常检测系统在生产环境中面临一个核心矛盾：过于敏感导致大量误报（false positive），运维人员产生"告警疲劳"而忽略真正的问题；过于迟钝则导致漏报（false negative），真正的异常被放过。告警优化的目标是在精确率和召回率之间找到适合业务场景的平衡点。


评估异常检测性能的标准指标包括精确率（Precision）、召回率（Recall）和 F1 分数。但在时序异常检测中，传统的逐点评估可能不合理——如果检测器在异常开始后 2 个时间步才发出告警，逐点评估会给出 2 个误报和 1 个漏报，但从业务角度看这个检测结果是有价值的。因此，时序异常检测领域引入了基于范围的评估方法。


告警去重和抑制是减少误报的工程策略：短时间内的连续告警合并为一个事件，已确认的异常在恢复前不重复告警，低优先级告警在高优先级告警存在时被抑制。


小结
    

  • 时序异常分为点异常、上下文异常和集合异常三类，检测难度依次递增
    • 

  • 统计方法（移动 Z-score、EWMA）是点异常检测的基础，季节性分解帮助区分周期性波动和真实异常
    • 

  • 预测驱动方法通过置信区间检测实际值的偏离，天然适合上下文异常
    • 

  • 深度学习方法（自编码器、VAE）在多变量复杂场景中表现突出，但需要大量正常数据训练
    • 

  • 告警优化是生产系统的核心挑战，需要在精确率和召回率之间找到业务合适的平衡点
    • 

  • 时序异常的评估应使用基于范围的方法，而非传统的逐点评估
