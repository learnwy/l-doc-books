时间序列因果推断

核心概念

时间序列因果推断（Causal Inference in Time Series）利用时序数据的天然时间排序来研究变量之间的因果关系。与横截面因果推断不同，时序数据提供了一个独特的优势：原因必须发生在结果之前（时间优先性原则），这为因果方向的判断提供了天然的约束。然而，时序因果推断也面临独特的挑战：虚假相关（两个趋势同步上升但无因果关系）、混淆变量（共同驱动因素）和反馈环路（双向因果）等。

时序因果推断的核心困难在于区分"真实因果"和"统计关联"。两个时间序列的高度相关可能源于共同驱动因素（如经济周期驱动的冰淇淋销量和溺水人数同升）、反向因果（价格影响需求，需求也影响价格）或纯粹的偶然趋势同步。


Granger 因果检验
Granger 因果（Granger Causality）是时序因果推断中最经典的方法。它的核心思想是：如果 XXX 的历史值在控制了 YYY 自身历史值后仍能显著改善对 YYY 的预测，则称 XXX Granger 因果于 YYY。Granger 因果的操作化定义基于 VAR（向量自回归）模型的嵌套比较。


import numpy as np
import pandas as pd
from statsmodels.tsa.stattools import grangercausalitytests
from statsmodels.tsa.api import VAR

def granger_causality_matrix(data, variables, max_lag=10, significance=0.05):
    results = pd.DataFrame(
        np.zeros((len(variables), len(variables))),
        index=variables, columns=variables
    )

    for target in variables:
        for cause in variables:
            if target == cause:
                continue

            test_data = data[[target, cause]].dropna()

            try:
                gc_result = grangercausalitytests(
                    test_data, maxlag=max_lag, verbose=False
                )

                min_pvalue = min(
                    gc_result[lag][0]['ssr_ftest'][1]
                    for lag in range(1, max_lag + 1)
                )
                results.loc[target, cause] = min_pvalue
            except Exception:
                results.loc[target, cause] = 1.0

    return results

def optimal_var_lag(data, max_lag=20):
    model = VAR(data)

    lag_order = model.select_order(maxlags=max_lag)

    return {
        'aic': lag_order.aic,
        'bic': lag_order.bic,
        'hqic': lag_order.hqic,
        'fpe': lag_order.fpe,
        'selected_orders': lag_order.selected_orders
    }

def conditional_granger_test(data, target, cause, conditions, max_lag=5):
    unrestricted_vars = [target, cause] + conditions
    restricted_vars = [target] + conditions

    unrestricted_data = data[unrestricted_vars].dropna()
    restricted_data = data[restricted_vars].dropna()

    n = min(len(unrestricted_data), len(restricted_data))
    unrestricted_data = unrestricted_data.tail(n)
    restricted_data = restricted_data.tail(n)

    var_full = VAR(unrestricted_data).fit(maxlags=max_lag)
    var_reduced = VAR(restricted_data).fit(maxlags=max_lag)

    rss_full = np.sum(var_full.resid[target] ** 2)
    rss_reduced = np.sum(var_reduced.resid[target] ** 2)

    k = max_lag
    n_obs = len(var_full.resid)
    f_stat = ((rss_reduced - rss_full) / k) / (rss_full / (n_obs - 2 * k - 1))

    from scipy.stats import f as f_dist
    p_value = 1 - f_dist.cdf(f_stat, k, n_obs - 2 * k - 1)

    return {
        'f_statistic': f_stat,
        'p_value': p_value,
        'significant': p_value < 0.05,
        'rss_full': rss_full,
        'rss_reduced': rss_reduced
    }
Granger 因果的局限性是明确的：它衡量的是"预测有用性"而非真实因果关系。条件 Granger 因果检验在控制了第三变量 ZZZ 后检验 XXX 对 YYY 的 Granger 因果，可以部分排除混淆变量的影响，但无法完全解决遗漏变量偏误。

间断时间序列分析
间断时间序列分析（Interrupted Time Series, ITS）是评估干预或政策效果的准实验方法。它利用干预前的时间趋势构建反事实（如果没有干预会怎样），然后与干预后的实际观测进行对比，差异即为干预效果的估计。


import statsmodels.api as sm

def interrupted_time_series(series, intervention_time,
                             pre_periods=None, post_periods=None):
    n = len(series)

    time = np.arange(n)
    intervention = (time >= intervention_time).astype(int)
    time_since_intervention = np.maximum(0, time - intervention_time)

    X = pd.DataFrame({
        'time': time,
        'intervention': intervention,
        'time_since_intervention': time_since_intervention
    })
    X = sm.add_constant(X)

    model = sm.OLS(series, X).fit(cov_type='HAC', cov_kwds={'maxlags': 5})

    counterfactual = model.params['const'] + model.params['time'] * time
    actual_post = series[intervention_time:]
    counterfactual_post = counterfactual[intervention_time:]

    level_change = model.params['intervention']
    slope_change = model.params['time_since_intervention']

    return {
        'model': model,
        'level_change': level_change,
        'level_change_pvalue': model.pvalues['intervention'],
        'slope_change': slope_change,
        'slope_change_pvalue': model.pvalues['time_since_intervention'],
        'counterfactual': counterfactual,
        'average_treatment_effect': float(np.mean(actual_post - counterfactual_post)),
        'summary': model.summary()
    }
ITS 的核心假设是"无干预情况下趋势不变"——如果没有干预，干预前的时间趋势会延续到干预后。这个假设的合理性需要通过分析干预前趋势的稳定性来验证。如果干预前已经存在趋势变化，ITS 的结果可能不可靠。


分段回归模型是 ITS 的标准实现。模型包含四个核心参数：截距（基线水平）、时间斜率（干预前趋势）、干预水平变化（干预导致的立即效果）和干预后斜率变化（干预导致的趋势改变）。Newey-West 标准误（HAC）用于处理残差中的自相关问题。


合成控制法
合成控制法（Synthetic Control Method, SCM）是评估区域性政策效果的强大工具。当某个"处理组"（如某城市实施新政策）没有完美的对照组时，合成控制法通过加权组合多个"控制组"来构造一个"合成控制组"，使其在干预前与处理组的特征尽可能匹配。


from scipy.optimize import minimize

def synthetic_control(treated, donors, intervention_time):
    pre_treated = treated[:intervention_time]
    pre_donors = donors[:intervention_time]

    n_donors = pre_donors.shape[1]

    def objective(weights):
        synthetic = pre_donors @ weights
        return np.sum((pre_treated - synthetic) ** 2)

    constraints = [
        {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
    ]
    bounds = [(0, 1)] * n_donors

    x0 = np.ones(n_donors) / n_donors
    result = minimize(objective, x0, method='SLSQP',
                      bounds=bounds, constraints=constraints)

    weights = result.x

    synthetic_full = donors @ weights

    treatment_effect = treated - synthetic_full
    post_effect = treatment_effect[intervention_time:]
    pre_fit_rmse = np.sqrt(np.mean(treatment_effect[:intervention_time] ** 2))

    return {
        'weights': dict(enumerate(weights)),
        'synthetic': synthetic_full,
        'treatment_effect': treatment_effect,
        'average_post_effect': float(np.mean(post_effect)),
        'pre_fit_rmse': pre_fit_rmse,
        'effect_ratio': float(np.mean(post_effect)) / (pre_fit_rmse + 1e-8)
    }

def placebo_test(treated, donors, intervention_time, n_placebo=None):
    base_result = synthetic_control(treated, donors, intervention_time)
    base_effect = base_result['average_post_effect']

    n_donors_total = donors.shape[1]
    if n_placebo is None:
        n_placebo = n_donors_total

    placebo_effects = []
    for i in range(min(n_placebo, n_donors_total)):
        placebo_treated = donors[:, i]
        placebo_donors = np.delete(donors, i, axis=1)

        try:
            placebo_result = synthetic_control(
                placebo_treated, placebo_donors, intervention_time
            )
            if placebo_result['pre_fit_rmse'] < base_result['pre_fit_rmse'] * 5:
                placebo_effects.append(placebo_result['average_post_effect'])
        except Exception:
            continue

    p_value = np.mean(np.abs(placebo_effects) >= np.abs(base_effect))

    return {
        'treatment_effect': base_effect,
        'placebo_effects': placebo_effects,
        'p_value': p_value,
        'significant': p_value < 0.1
    }
安慰剂检验（Placebo Test）是合成控制法的核心验证手段。它将每个控制组轮流假设为"处理组"，对其他控制组运行合成控制法，观察"伪处理效应"的分布。如果真实处理效应显著大于安慰剂效应的分布，则可以认为干预确实产生了效果。

小结
    

  • 时序因果推断利用时间先后关系约束因果方向，但仍需警惕虚假相关和混淆变量
    • 

  • Granger 因果衡量预测有用性而非真实因果，条件 Granger 可部分排除混淆变量
    • 

  • VAR 模型是多变量 Granger 因果分析的标准框架，滞后阶数选择影响检验结果
    • 

  • 间断时间序列分析（ITS）通过干预前趋势外推构建反事实，分段回归模型是标准实现
    • 

  • 合成控制法通过加权组合控制组构造"合成对照"，适用于缺乏完美对照组的场景
    • 

  • 安慰剂检验是合成控制法的核心验证手段，通过比较真实效应与伪效应分布判断显著性
    • 

  • 因果推断的结论强度取决于假设的合理性，应当通过多种方法交叉验证来增强可信度
    •
