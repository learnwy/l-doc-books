金融时间序列

核心概念

金融时间序列是时间序列分析中最具挑战性的应用领域之一。金融数据具有一系列独特的统计特性，使得传统时间序列方法往往表现不佳：收益率的尖峰厚尾分布、波动率聚集效应、杠杆效应、长记忆性以及市场微观结构噪声。理解这些特性是构建有效金融预测模型的前提。

金融时间序列按照研究目标可分为三大方向：价格/收益率预测（预测资产未来的价格走势）、波动率建模（估计和预测价格波动的幅度）和风险度量（量化投资组合面临的极端损失概率）。每个方向对应不同的模型体系和评估标准。

GARCH 族波动率模型
GARCH（Generalized Autoregressive Conditional Heteroskedasticity）是金融波动率建模的基石。它认为当前时刻的条件方差取决于过去的方差和过去的收益率平方（即冲击），从而捕获波动率聚集效应。


interface GARCHParams {
  omega: number;
  alpha: number[];
  beta: number[];
}

function garchVariance(returns: number[], params: GARCHParams): number[] {
  const p = params.alpha.length;
  const q = params.beta.length;
  const n = returns.length;
  const sigma2 = new Array(n).fill(0);

  const unconditionalVar = returns.reduce((sum, r) => sum + r * r, 0) / n;
  for (let i = 0; i < Math.max(p, q); i++) {
    sigma2[i] = unconditionalVar;
  }

  for (let t = Math.max(p, q); t < n; t++) {
    let variance = params.omega;
    for (let i = 0; i < p; i++) {
      variance += params.alpha[i] * returns[t - 1 - i] ** 2;
    }
    for (let j = 0; j < q; j++) {
      variance += params.beta[j] * sigma2[t - 1 - j];
    }
    sigma2[t] = variance;
  }

  return sigma2;
}

function computeLogReturns(prices: number[]): number[] {
  return prices.slice(1).map((price, i) => Math.log(price / prices[i]));
}
GARCH(1,1) 是最常用的 GARCH 变体，其条件方差公式为 σ²ₜ = ω + α·ε²ₜ₋₁ + β·σ²ₜ₋₁，其中 α 控制短期冲击的影响，β 控制波动率的持续性。α + β < 1 保证过程平稳，α + β 越接近 1 表示波动率的持续性越强。


EGARCH 和 GJR-GARCH 是为捕获杠杆效应而设计的非对称 GARCH 变体。在 EGARCH 中，对条件方差的对数建模，自动保证方差为正，且允许正负冲击对波动率的影响不同。GJR-GARCH 通过引入指示函数对负收益率给予额外的方差贡献。

风险价值与尾部建模
VaR（Value at Risk，在险价值）是金融风险管理中最广泛使用的风险度量指标。VaR 回答的问题是："在给定的置信水平下，投资组合在未来一段时间内的最大可能损失是多少？" 例如，95% VaR = 100 万表示在 95% 的情况下，损失不会超过 100 万。


interface VaRResult {
  historicalVaR: number;
  parametricVaR: number;
  cvar: number;
}

function computeVaR(returns: number[], confidence: number): VaRResult {
  const sorted = [...returns].sort((a, b) => a - b);
  const idx = Math.floor(returns.length * (1 - confidence));
  const historicalVaR = -sorted[idx];

  const mean = returns.reduce((a, b) => a + b) / returns.length;
  const std = Math.sqrt(returns.reduce((sum, r) => sum + (r - mean) ** 2, 0) / returns.length);
  const zScore = 1.645;
  const parametricVaR = -(mean - zScore * std);

  const tailReturns = sorted.slice(0, idx + 1);
  const cvar = -(tailReturns.reduce((a, b) => a + b) / tailReturns.length);

  return { historicalVaR, parametricVaR, cvar };
}

function rollingVaR(
  returns: number[],
  windowSize: number,
  confidence: number,
): Array<{ date: number; var95: number; actual: number }> {
  const results: Array<{ date: number; var95: number; actual: number }> = [];
  for (let t = windowSize; t < returns.length; t++) {
    const window = returns.slice(t - windowSize, t);
    const { historicalVaR } = computeVaR(window, confidence);
    results.push({
      date: t,
      var95: historicalVaR,
      actual: -returns[t],
    });
  }
  return results;
}
CVaR（Conditional VaR，条件在险价值）是 VaR 的补充指标，它衡量的是当损失超过 VaR 阈值时的平均损失大小。CVaR 比 VaR 更能反映尾部风险的严重程度，且具有次可加性（即组合的 CVaR 不超过各部分 CVaR 之和），这使得它成为投资组合优化中的首选风险度量。


高频数据与已实现波动率
随着交易所数据粒度从日频提升到毫秒级，高频金融数据为波动率估计提供了全新的视角。已实现波动率（Realized Volatility）利用日内高频收益率的平方和来直接估计日度波动率，相比 GARCH 模型从日度数据间接推断波动率更为精确。


已实现波动率的计算公式为 RV = Σᵢ rᵢ²，其中 rᵢ 是日内第 i 个采样间隔的对数收益率。HAR-RV（Heterogeneous Autoregressive Realized Volatility）模型进一步将已实现波动率分解为日、周、月三个时间尺度的移动平均，用简单的线性模型捕获波动率的长记忆性。


高频数据的一个核心挑战是市场微观结构噪声：买卖价差、离散报价和异步交易会使高频收益率偏离真实价格变动。常用的去噪方法包括稀疏采样（每 5 分钟采样一次而非逐笔）和已实现核估计（Realized Kernel）等统计方法。


小结
    

  • 金融时间序列具有尖峰厚尾、波动率聚集、杠杆效应和长记忆性等独特统计特性
    • 

  • GARCH 族模型是波动率建模的基石，EGARCH 和 GJR-GARCH 捕获非对称的杠杆效应
    • 

  • VaR 和 CVaR 是金融风险度量的核心指标，CVaR 比 VaR 更能反映尾部风险
    • 

  • 高频数据和已实现波动率为波动率估计提供了更精确的直接度量
    • 

  • HAR-RV 模型用简单的多尺度线性结构有效捕获波动率的长记忆性
    • 

  • 金融预测模型的有效性最终由经济价值（而非统计指标）来衡量
    •
