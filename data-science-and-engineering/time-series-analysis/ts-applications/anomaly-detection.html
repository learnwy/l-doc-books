时间序列异常检测

核心概念

时间序列异常检测（Time Series Anomaly Detection）是在时序数据中识别偏离正常模式的数据点或时间段的技术。异常可能指示设备故障、网络入侵、金融欺诈或系统性能退化等关键事件。与静态数据的异常检测不同，时序异常检测需要考虑数据的时序依赖性——一个在绝对值上完全正常的数据点如果出现在"错误的时间"也可能构成异常。

理解异常的类型是选择检测方法的基础。点异常用统计阈值即可有效检测，上下文异常需要时序模型捕获预期值，模式异常需要序列相似度或深度学习方法。


统计方法
基于统计的异常检测方法利用时间序列的统计特性建立正常行为的模型，将显著偏离模型预期的数据点标记为异常。


import numpy as np
import pandas as pd
from scipy.stats import zscore

def sigma_rule_detection(series, window=30, n_sigma=3):
    rolling_mean = series.rolling(window=window, center=True).mean()
    rolling_std = series.rolling(window=window, center=True).std()

    upper_bound = rolling_mean + n_sigma * rolling_std
    lower_bound = rolling_mean - n_sigma * rolling_std

    anomalies = (series > upper_bound) | (series < lower_bound)

    return pd.DataFrame({
        'value': series,
        'rolling_mean': rolling_mean,
        'upper_bound': upper_bound,
        'lower_bound': lower_bound,
        'is_anomaly': anomalies,
        'deviation': (series - rolling_mean) / rolling_std
    })

def stl_residual_detection(series, period=7, threshold=3):
    from statsmodels.tsa.seasonal import STL

    stl = STL(series, period=period, robust=True)
    result = stl.fit()

    residuals = result.resid
    median_res = np.median(residuals.dropna())
    mad = np.median(np.abs(residuals.dropna() - median_res))
    modified_z = 0.6745 * (residuals - median_res) / (mad + 1e-8)

    anomalies = np.abs(modified_z) > threshold

    return pd.DataFrame({
        'value': series,
        'trend': result.trend,
        'seasonal': result.seasonal,
        'residual': residuals,
        'modified_z_score': modified_z,
        'is_anomaly': anomalies
    })

def forecast_based_detection(series, train_size=None, threshold=3):
    from statsmodels.tsa.holtwinters import ExponentialSmoothing

    if train_size is None:
        train_size = int(len(series) * 0.7)

    model = ExponentialSmoothing(
        series[:train_size], trend='add', seasonal='add',
        seasonal_periods=7, damped_trend=True
    ).fit(optimized=True)

    fitted = model.fittedvalues
    predicted = model.predict(start=train_size, end=len(series) - 1)
    all_predicted = pd.concat([fitted, predicted])

    residuals = series - all_predicted
    std_res = residuals.std()
    anomalies = np.abs(residuals) > threshold * std_res

    return pd.DataFrame({
        'value': series,
        'predicted': all_predicted,
        'residual': residuals,
        'is_anomaly': anomalies
    })
STL 分解 + 残差检测是最稳健的统计异常检测方法之一。STL 的 robust 模式使用迭代加权最小二乘拟合，自动降低异常点对分解结果的影响，使得残差更准确地反映异常偏差。Modified Z-score 使用中位数和 MAD（中位数绝对偏差）代替均值和标准差，对异常值本身的鲁棒性更好。

机器学习方法
机器学习异常检测方法不依赖对数据分布的参数化假设，能够处理更复杂的异常模式。Isolation Forest 通过随机分割的方式隔离异常点——异常点因为"与众不同"所以更容易被隔离，需要的分割次数更少。


from sklearn.ensemble import IsolationForest
from sklearn.neighbors import LocalOutlierFactor

def isolation_forest_ts(series, window=10, contamination=0.05):
    features = []
    for i in range(window, len(series)):
        window_data = series[i - window:i]
        feat = [
            window_data.mean(), window_data.std(),
            window_data.min(), window_data.max(),
            window_data.iloc[-1] - window_data.iloc[0],
            window_data.diff().mean(),
            series.iloc[i]
        ]
        features.append(feat)

    X = np.array(features)

    iso_forest = IsolationForest(
        contamination=contamination,
        n_estimators=200,
        random_state=42
    )
    labels = iso_forest.fit_predict(X)
    scores = iso_forest.decision_function(X)

    result = pd.DataFrame({
        'value': series.iloc[window:].values,
        'anomaly_score': scores,
        'is_anomaly': labels == -1
    }, index=series.index[window:])

    return result

def lof_ts(series, window=10, n_neighbors=20, contamination=0.05):
    features = []
    for i in range(window, len(series)):
        window_data = series[i - window:i]
        feat = [
            window_data.mean(), window_data.std(),
            series.iloc[i],
            series.iloc[i] - window_data.mean(),
            (series.iloc[i] - window_data.mean()) / (window_data.std() + 1e-8)
        ]
        features.append(feat)

    X = np.array(features)

    lof = LocalOutlierFactor(
        n_neighbors=n_neighbors,
        contamination=contamination
    )
    labels = lof.fit_predict(X)
    scores = lof.negative_outlier_factor_

    return pd.DataFrame({
        'value': series.iloc[window:].values,
        'lof_score': scores,
        'is_anomaly': labels == -1
    }, index=series.index[window:])
时间序列数据输入 Isolation Forest 或 LOF 时，需要先进行特征化——将时间窗口内的统计量（均值、方差、趋势、当前值与窗口均值的偏差等）作为特征向量。这个特征化步骤将时序异常检测转化为标准的表格异常检测问题。


深度学习方法
深度学习异常检测方法通过在正常数据上训练模型来学习正常模式的表示，然后将重构误差或预测误差较大的数据点标记为异常。LSTM AutoEncoder 是时序异常检测中最流行的深度学习方法。


import torch
import torch.nn as nn

class LSTMAutoEncoder(nn.Module):
    def __init__(self, input_dim=1, hidden_dim=64, latent_dim=16,
                 num_layers=2, dropout=0.2):
        super().__init__()
        self.encoder = nn.LSTM(
            input_dim, hidden_dim, num_layers,
            batch_first=True, dropout=dropout
        )
        self.encoder_fc = nn.Linear(hidden_dim, latent_dim)

        self.decoder_fc = nn.Linear(latent_dim, hidden_dim)
        self.decoder = nn.LSTM(
            hidden_dim, hidden_dim, num_layers,
            batch_first=True, dropout=dropout
        )
        self.output_fc = nn.Linear(hidden_dim, input_dim)

    def forward(self, x):
        enc_out, _ = self.encoder(x)
        latent = self.encoder_fc(enc_out[:, -1, :])

        dec_input = self.decoder_fc(latent).unsqueeze(1).repeat(1, x.size(1), 1)
        dec_out, _ = self.decoder(dec_input)
        reconstruction = self.output_fc(dec_out)

        return reconstruction, latent

def detect_anomalies_autoencoder(model, data, threshold_percentile=95):
    model.eval()
    with torch.no_grad():
        reconstruction, _ = model(data)

    mse_per_sample = torch.mean((data - reconstruction) ** 2, dim=(1, 2))
    threshold = torch.quantile(mse_per_sample, threshold_percentile / 100)
    anomalies = mse_per_sample > threshold

    return {
        'reconstruction_errors': mse_per_sample.numpy(),
        'threshold': threshold.item(),
        'anomalies': anomalies.numpy(),
        'anomaly_rate': anomalies.float().mean().item()
    }
LSTM AutoEncoder 的核心思想是：编码器将输入序列压缩为低维隐表示，解码器从隐表示重构原始序列。在正常数据上训练后，正常模式能被准确重构（低重构误差），而异常模式由于与训练数据不同，无法被准确重构（高重构误差）。重构误差超过阈值的序列即被标记为异常。

在线异常检测
在线异常检测（Online Anomaly Detection）要求系统在数据流式到达时实时判断每个新数据点是否为异常，而不能等到所有数据收集完毕再做批量分析。这对算法的计算效率和增量更新能力提出了严格要求。


class OnlineAnomalyDetector:
    def __init__(self, window_size=100, n_sigma=3, decay=0.01):
        self.window_size = window_size
        self.n_sigma = n_sigma
        self.decay = decay
        self.buffer = []
        self.ewm_mean = None
        self.ewm_var = None

    def update(self, value):
        self.buffer.append(value)
        if len(self.buffer) > self.window_size:
            self.buffer.pop(0)

        if self.ewm_mean is None:
            self.ewm_mean = value
            self.ewm_var = 0
            return {'value': value, 'is_anomaly': False, 'score': 0}

        alpha = self.decay
        diff = value - self.ewm_mean
        self.ewm_mean = (1 - alpha) * self.ewm_mean + alpha * value
        self.ewm_var = (1 - alpha) * (self.ewm_var + alpha * diff ** 2)

        ewm_std = np.sqrt(self.ewm_var) + 1e-8
        z_score = abs(diff) / ewm_std
        is_anomaly = z_score > self.n_sigma

        return {
            'value': value,
            'is_anomaly': is_anomaly,
            'z_score': z_score,
            'ewm_mean': self.ewm_mean,
            'ewm_std': ewm_std
        }
在线检测器需要平衡灵敏度和鲁棒性：过度灵敏会产生大量误报（False Positive），过度迟钝会遗漏真实异常（False Negative）。自适应阈值策略通过根据历史误报率动态调整告警阈值来优化这一权衡。


小结
    

  • 时序异常分为点异常、上下文异常和模式异常三大类，不同类型需要不同的检测方法
    • 

  • STL 分解 + 残差检测是最稳健的统计方法，Modified Z-score 对异常值鲁棒
    • 

  • Isolation Forest 和 LOF 需要先将时序数据特征化为滑动窗口统计量
    • 

  • LSTM AutoEncoder 通过重构误差检测异常，在正常数据上训练，异常模式产生高重构误差
    • 

  • 在线异常检测要求增量更新和实时判断，EWMA 是计算效率最高的在线方法
    • 

  • 异常检测的评估需要同时关注精确率和召回率，F1 分数是综合指标
    • 

  • 实践中推荐分层策略：统计方法快速初筛 → ML/DL 方法精确检测 → 人工审核确认
