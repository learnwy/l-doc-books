需求预测

核心概念

需求预测是时间序列分析在商业领域最广泛的应用之一，它通过历史销售数据和外部因素预测未来一段时间内产品或服务的需求量。准确的需求预测直接影响库存管理、生产计划、供应链调度和营销策略的效果，是零售、制造、物流等行业的核心竞争力之一。

需求预测按照时间跨度分为三个层次：短期预测（1-4 周，用于库存补货和人员排班）、中期预测（1-6 个月，用于采购计划和产能规划）和长期预测（6 个月-2 年，用于战略决策和资本投资）。不同层次的预测对精度、粒度和更新频率的要求各不相同。

间歇性需求建模
间歇性需求（Intermittent Demand）是需求预测中最棘手的问题之一。许多产品（尤其是备件、长尾商品、新品）的销售呈现"大量零值夹杂偶尔非零值"的模式，传统的连续值预测方法在这类数据上表现极差。


interface IntermittentDemandStats {
  adi: number;
  cv2: number;
  classification: 'smooth' | 'erratic' | 'intermittent' | 'lumpy';
}

function classifyDemand(demand: number[]): IntermittentDemandStats {
  const nonZero = demand.filter((d) => d > 0);
  const intervals: number[] = [];
  let lastNonZero = -1;

  for (let i = 0; i < demand.length; i++) {
    if (demand[i] > 0) {
      if (lastNonZero >= 0) {
        intervals.push(i - lastNonZero);
      }
      lastNonZero = i;
    }
  }

  const adi = intervals.length > 0 ? intervals.reduce((a, b) => a + b) / intervals.length : Infinity;

  const meanNZ = nonZero.reduce((a, b) => a + b, 0) / nonZero.length;
  const varNZ = nonZero.reduce((s, v) => s + (v - meanNZ) ** 2, 0) / nonZero.length;
  const cv2 = varNZ / (meanNZ * meanNZ);

  let classification: IntermittentDemandStats['classification'];
  if (adi < 1.32 && cv2 < 0.49) classification = 'smooth';
  else if (adi < 1.32 && cv2 >= 0.49) classification = 'erratic';
  else if (adi >= 1.32 && cv2 < 0.49) classification = 'intermittent';
  else classification = 'lumpy';

  return { adi, cv2, classification };
}
Croston 方法是间歇性需求预测的经典方法。它将需求序列分解为两个子序列：非零需求的大小序列和需求间隔序列，分别用指数平滑预测，最后将两者的预测值相除得到平均需求率。


SBA（Syntetos-Boylan Approximation）是 Croston 方法的改进版，修正了 Croston 方法对均值的正偏估计。TSB（Teunter-Syntetos-Babai）方法进一步修正了需求概率的估计，在间歇性和块状需求上表现更优。

层级预测与协调
在实际业务中，需求预测往往需要在多个层级上保持一致性。例如，所有门店的预测之和应该等于区域级预测，所有 SKU 的预测之和应该等于品类级预测。这种跨层级一致性约束产生了层级预测协调（Hierarchical Forecast Reconciliation）问题。


interface HierarchyNode {
  id: string;
  children: string[];
  baseForecast: number[];
}

function bottomUpReconciliation(
  hierarchy: Map<string, HierarchyNode>,
  bottomForecasts: Map<string, number[]>,
): Map<string, number[]> {
  const reconciled = new Map<string, number[]>();

  for (const [id, forecast] of bottomForecasts) {
    reconciled.set(id, forecast);
  }

  const topSort = topologicalSort(hierarchy);
  for (const nodeId of topSort) {
    const node = hierarchy.get(nodeId);
    if (!node || node.children.length === 0) continue;

    const horizon = reconciled.get(node.children[0])!.length;
    const aggregated = new Array(horizon).fill(0);
    for (const childId of node.children) {
      const childForecast = reconciled.get(childId)!;
      for (let h = 0; h < horizon; h++) {
        aggregated[h] += childForecast[h];
      }
    }
    reconciled.set(nodeId, aggregated);
  }

  return reconciled;
}

function topologicalSort(hierarchy: Map<string, HierarchyNode>): string[] {
  const result: string[] = [];
  const visited = new Set<string>();

  function visit(id: string): void {
    if (visited.has(id)) return;
    visited.add(id);
    const node = hierarchy.get(id);
    if (node) {
      for (const child of node.children) visit(child);
    }
    result.push(id);
  }

  for (const id of hierarchy.keys()) visit(id);
  return result;
}
层级协调的三种基本策略是：自底向上（Bottom-Up，用最细粒度预测汇总到上层）、自顶向下（Top-Down，用最粗粒度预测按比例分配到下层）和最优协调（Optimal Reconciliation，用加权最小二乘法同时调整所有层级的预测使其一致）。


外部特征与因果预测
纯时间序列方法只利用历史需求数据，而因果预测方法引入外部特征（exogenous variables）来提升预测精度。常见的外部特征包括：促销活动（折扣力度、广告投放）、天气数据（温度、降水）、宏观经济指标（GDP、消费者信心指数）、竞品行为和社交媒体热度。


interface DemandFeatures {
  lagFeatures: number[];
  calendarFeatures: {
    dayOfWeek: number;
    monthOfYear: number;
    isHoliday: boolean;
    daysToHoliday: number;
  };
  promotionFeatures: {
    discountPct: number;
    isPromo: boolean;
    promoType: string;
  };
  externalFeatures: {
    temperature: number;
    precipitation: number;
    competitorPrice: number;
  };
}

function engineerFeatures(
  demand: number[],
  t: number,
  calendar: Record<string, unknown>,
  promotion: Record<string, unknown>,
  weather: Record<string, unknown>,
): DemandFeatures {
  const lagFeatures = [1, 7, 14, 28].map((lag) => (t - lag >= 0 ? demand[t - lag] : 0));

  const rollingMean7 = t >= 7 ? demand.slice(t - 7, t).reduce((a, b) => a + b) / 7 : 0;
  const rollingMean28 = t >= 28 ? demand.slice(t - 28, t).reduce((a, b) => a + b) / 28 : 0;
  lagFeatures.push(rollingMean7, rollingMean28);

  return {
    lagFeatures,
    calendarFeatures: {
      dayOfWeek: (calendar as { dow: number }).dow,
      monthOfYear: (calendar as { month: number }).month,
      isHoliday: (calendar as { holiday: boolean }).holiday,
      daysToHoliday: (calendar as { dth: number }).dth,
    },
    promotionFeatures: {
      discountPct: (promotion as { discount: number }).discount,
      isPromo: (promotion as { active: boolean }).active,
      promoType: (promotion as { type: string }).type,
    },
    externalFeatures: {
      temperature: (weather as { temp: number }).temp,
      precipitation: (weather as { precip: number }).precip,
      competitorPrice: 0,
    },
  };
}
梯度提升树（LightGBM、XGBoost）是当前需求预测中特征驱动方法的首选模型。它能够自动处理非线性关系、特征交互和缺失值，且在结构化数据上的表现通常优于深度学习方法。M5 竞赛（沃尔玛需求预测）的冠军方案均使用了 LightGBM 作为核心模型。


小结
    

  • 需求预测是时间序列在商业领域最广泛的应用，直接影响库存、采购和供应链决策
    • 

  • 间歇性需求需要专门的方法（Croston、SBA、TSB），传统连续值方法在此类数据上失效
    • 

  • 层级预测协调确保不同粒度的预测保持一致性，最优协调方法优于简单的自底向上或自顶向下
    • 

  • 外部特征（促销、天气、日历）显著提升预测精度，梯度提升树是特征驱动预测的首选模型
    • 

  • 需求预测的成功不仅取决于模型精度，更取决于预测系统与业务决策流程的深度整合
    • 

  • 不同时间跨度的预测服务不同的业务决策，应匹配相应的粒度和更新频率
    •
