变点检测与趋势分析

核心概念

变点检测（Change Point Detection）是在时间序列中识别统计性质发生突变的时间点的技术。变点可能表现为均值突变、方差突变、趋势方向改变或分布整体偏移。与异常检测关注单个偏离点不同，变点检测关注的是序列的"制度变化"（Regime Change）——从一种统计状态切换到另一种统计状态。变点检测在金融市场分析、工业过程监控、流行病学和气候变化研究中有广泛应用。

变点检测的核心挑战是在灵敏度（检测到所有真实变点）和特异性（不产生误报）之间取得平衡。过度灵敏的检测器会将随机波动误判为变点，过度迟钝的检测器会漏检真实的制度变化。


离线变点检测
离线变点检测方法在获得完整序列后进行全局分析，通过最优化目标函数找到最佳的变点位置集合。PELT（Pruned Exact Linear Time）算法是当前最高效的精确离线变点检测方法。


import ruptures as rpt
import numpy as np
import pandas as pd

def pelt_changepoint(series, penalty='bic', min_size=10):
    signal = np.array(series).reshape(-1, 1)

    model = rpt.Pelt(model='rbf', min_size=min_size).fit(signal)

    if penalty == 'bic':
        pen = np.log(len(signal)) * signal.var()
    elif penalty == 'aic':
        pen = 2 * signal.var()
    else:
        pen = penalty

    changepoints = model.predict(pen=pen)

    return changepoints[:-1]

def binary_segmentation(series, n_changepoints=5, min_size=10):
    signal = np.array(series).reshape(-1, 1)

    model = rpt.Binseg(model='l2', min_size=min_size).fit(signal)
    changepoints = model.predict(n_bkps=n_changepoints)

    return changepoints[:-1]

def analyze_segments(series, changepoints):
    segments = []
    boundaries = [0] + list(changepoints) + [len(series)]

    for i in range(len(boundaries) - 1):
        start, end = boundaries[i], boundaries[i + 1]
        segment = series[start:end]

        segments.append({
            'start': start,
            'end': end,
            'length': end - start,
            'mean': float(np.mean(segment)),
            'std': float(np.std(segment)),
            'trend': float(np.polyfit(range(len(segment)), segment, 1)[0]),
            'min': float(np.min(segment)),
            'max': float(np.max(segment))
        })

    return pd.DataFrame(segments)
PELT 的核心思想是将变点检测建模为最优分割问题：在满足惩罚约束的前提下，找到使得各段内数据最"均匀"的分割点集合。PELT 通过剪枝策略将复杂度从 O(n2)O(n^2)O(n2) 降低到 O(n)O(n)O(n)（线性时间），使得在百万级数据点上也能高效运行。


惩罚参数的选择直接影响检测到的变点数量。BIC 惩罚（βlog⁡n\beta \log nβlogn）倾向于检测较少的变点，AIC 惩罚（2β2\beta2β）倾向于检测较多的变点。在实践中，通常通过在不同惩罚值下运行 PELT 并观察变点数量的"肘部"来确定合适的惩罚。

在线变点检测
在线变点检测在数据流式到达时实时判断是否发生了变点，适用于需要快速响应的监控场景。CUSUM（Cumulative Sum）和 BOCPD（Bayesian Online Change Point Detection）是两种主流的在线方法。


class CUSUMDetector:
    def __init__(self, threshold=5, drift=0.5):
        self.threshold = threshold
        self.drift = drift
        self.reset()

    def reset(self):
        self.s_pos = 0
        self.s_neg = 0
        self.mean_estimate = None
        self.std_estimate = None
        self.buffer = []
        self.changepoints = []
        self.step = 0

    def update(self, value):
        self.buffer.append(value)
        self.step += 1

        if len(self.buffer) < 30:
            return {'is_changepoint': False, 'step': self.step}

        if self.mean_estimate is None:
            self.mean_estimate = np.mean(self.buffer[:30])
            self.std_estimate = np.std(self.buffer[:30])

        z = (value - self.mean_estimate) / (self.std_estimate + 1e-8)

        self.s_pos = max(0, self.s_pos + z - self.drift)
        self.s_neg = max(0, self.s_neg - z - self.drift)

        is_changepoint = self.s_pos > self.threshold or self.s_neg > self.threshold

        if is_changepoint:
            self.changepoints.append(self.step)
            recent = self.buffer[-30:]
            self.mean_estimate = np.mean(recent)
            self.std_estimate = np.std(recent)
            self.s_pos = 0
            self.s_neg = 0

        return {
            'is_changepoint': is_changepoint,
            'step': self.step,
            's_pos': self.s_pos,
            's_neg': self.s_neg,
            'z_score': z
        }

class BOCPDDetector:
    def __init__(self, hazard_rate=1/200, mu_prior=0, kappa_prior=1,
                 alpha_prior=1, beta_prior=1):
        self.hazard = 1 / hazard_rate
        self.mu0 = mu_prior
        self.kappa0 = kappa_prior
        self.alpha0 = alpha_prior
        self.beta0 = beta_prior
        self.run_length_probs = np.array([1.0])
        self.changepoint_probs = []

    def update(self, value):
        n = len(self.run_length_probs)

        predprobs = np.zeros(n)
        for i in range(n):
            predprobs[i] = self._predictive_prob(value, i)

        growth_probs = self.run_length_probs * predprobs * (1 - 1/self.hazard)
        cp_prob = np.sum(self.run_length_probs * predprobs * (1/self.hazard))

        new_probs = np.zeros(n + 1)
        new_probs[0] = cp_prob
        new_probs[1:] = growth_probs

        evidence = np.sum(new_probs)
        self.run_length_probs = new_probs / (evidence + 1e-300)

        self.changepoint_probs.append(float(self.run_length_probs[0]))

        return {
            'changepoint_probability': float(self.run_length_probs[0]),
            'most_likely_run_length': int(np.argmax(self.run_length_probs))
        }

    def _predictive_prob(self, value, run_length):
        from scipy.stats import t as t_dist
        kappa_n = self.kappa0 + run_length
        mu_n = self.mu0
        alpha_n = self.alpha0 + run_length / 2
        beta_n = self.beta0

        scale = np.sqrt(beta_n * (kappa_n + 1) / (alpha_n * kappa_n))
        return t_dist.pdf(value, df=2 * alpha_n, loc=mu_n, scale=scale + 1e-8)
BOCPD 是贝叶斯框架下的在线变点检测方法。它维护一个"运行长度"的后验分布——运行长度表示自上一个变点以来经过的时间步数。每当新数据到达时，BOCPD 同时更新运行长度为 0（发生变点）和运行长度增加 1（未发生变点）两种假设的后验概率。当运行长度为 0 的后验概率超过阈值时，检测到变点。


趋势分析方法
趋势分析旨在量化时间序列中长期变化的方向和速率。Mann-Kendall 检验是最广泛使用的非参数趋势检验方法，它不要求数据服从特定分布，只基于数据点的相对排序判断是否存在单调趋势。


from scipy.stats import norm

def mann_kendall_test(series, alpha=0.05):
    n = len(series)
    s = 0

    for i in range(n - 1):
        for j in range(i + 1, n):
            diff = series[j] - series[i]
            if diff > 0:
                s += 1
            elif diff < 0:
                s -= 1

    var_s = n * (n - 1) * (2 * n + 5) / 18

    if s > 0:
        z = (s - 1) / np.sqrt(var_s)
    elif s < 0:
        z = (s + 1) / np.sqrt(var_s)
    else:
        z = 0

    p_value = 2 * (1 - norm.cdf(abs(z)))

    trend = 'increasing' if z > 0 and p_value < alpha else (
        'decreasing' if z < 0 and p_value < alpha else 'no_trend'
    )

    slopes = []
    for i in range(n - 1):
        for j in range(i + 1, n):
            slopes.append((series[j] - series[i]) / (j - i))
    sen_slope = np.median(slopes)

    return {
        'z_statistic': z,
        'p_value': p_value,
        'trend': trend,
        'sen_slope': sen_slope,
        'kendall_s': s
    }
Sen 斜率是与 Mann-Kendall 检验配套的趋势斜率估计器，它计算所有数据点对之间斜率的中位数，对异常值非常鲁棒。

小结
    

  • 变点检测识别序列统计性质的突变位置，与异常检测关注单个偏离点不同
    • 

  • PELT 是离线变点检测的推荐方法，线性时间复杂度且精确求解
    • 

  • CUSUM 是工业过程监控的经典在线方法，BOCPD 提供贝叶斯概率化变点判断
    • 

  • 惩罚参数直接影响检测到的变点数量，BIC 惩罚较保守，AIC 惩罚较积极
    • 

  • Mann-Kendall 检验是非参数趋势检验的标准方法，不要求数据正态分布
    • 

  • Sen 斜率提供对异常值鲁棒的趋势斜率估计，比最小二乘回归斜率更可靠
    • 

  • 变点检测和趋势分析通常联合使用：先检测变点分割序列，再在每段内分析趋势
    •
