指数平滑与状态空间模型

核心概念

指数平滑（Exponential Smoothing）是与 ARIMA 并列的另一大经典时间序列预测方法族。与 ARIMA 基于序列的自相关结构建模不同，指数平滑直接对序列的水平、趋势和季节三个成分分别建模，并通过指数衰减的权重机制对历史数据进行加权平均。指数平滑方法在业界的应用极为广泛，特别是在零售预测、库存管理和需求规划等场景中表现优异。

ETS（Error-Trend-Seasonal）框架将所有指数平滑方法统一在状态空间模型中，每种方法对应误差（A/M）、趋势（N/A/Ad/M/Md）和季节（N/A/M）的一个特定组合。ETS 框架不仅提供了统一的参数估计方法（最大似然法），还支持通过 AIC/BIC 在所有 30 种可能的模型组合中自动选择最优模型。


简单指数平滑与 Holt 方法
简单指数平滑（SES）是所有指数平滑方法的基础。它的递推公式为：


y^t+1=αyt+(1−α)y^t=y^t+α(yt−y^t)\hat{y}_{t+1} = \alpha y_t + (1-\alpha) \hat{y}_t = \hat{y}_t + \alpha(y_t - \hat{y}_t)y^​t+1​=αyt​+(1−α)y^​t​=y^​t​+α(yt​−y^​t​)
其中 α∈[0,1]\alpha \in [0, 1]α∈[0,1] 为平滑参数。第二种形式清楚地展示了"误差修正"的思想：每步预测是上一步预测加上对预测误差的一个比例修正。α\alphaα 越大，新数据的影响越大，模型对变化的响应越快但也越敏感于噪声。


from statsmodels.tsa.holtwinters import ExponentialSmoothing, SimpleExpSmoothing
import numpy as np
import pandas as pd

def simple_exponential_smoothing(series, alpha=None, forecast_steps=12):
    model = SimpleExpSmoothing(series, initialization_method='estimated')
    if alpha is not None:
        fit = model.fit(smoothing_level=alpha, optimized=False)
    else:
        fit = model.fit(optimized=True)

    forecast = fit.forecast(steps=forecast_steps)

    return fit, forecast, {
        'alpha': fit.params['smoothing_level'],
        'sse': fit.sse,
        'aic': fit.aic
    }

def holt_linear_method(series, alpha=None, beta=None, damped=False,
                        forecast_steps=12):
    model = ExponentialSmoothing(
        series,
        trend='add',
        damped_trend=damped,
        initialization_method='estimated'
    )

    params = {}
    if alpha is not None:
        params['smoothing_level'] = alpha
    if beta is not None:
        params['smoothing_trend'] = beta

    if params:
        fit = model.fit(**params, optimized=len(params) < 2)
    else:
        fit = model.fit(optimized=True)

    forecast = fit.forecast(steps=forecast_steps)

    return fit, forecast, {
        'alpha': fit.params['smoothing_level'],
        'beta': fit.params['smoothing_trend'],
        'damping': fit.params.get('damping_trend', None),
        'aic': fit.aic
    }
Holt 线性趋势方法在 SES 基础上增加了趋势成分，使用两个平滑参数 α\alphaα 和 β\betaβ 分别更新水平和趋势：


lt=αyt+(1−α)(lt−1+bt−1)l_t = \alpha y_t + (1-\alpha)(l_{t-1} + b_{t-1})lt​=αyt​+(1−α)(lt−1​+bt−1​)
 


bt=β(lt−lt−1)+(1−β)bt−1b_t = \beta(l_t - l_{t-1}) + (1-\beta) b_{t-1}bt​=β(lt​−lt−1​)+(1−β)bt−1​
Holt 方法的线性趋势在长期预测中会无限延伸，这在实际中往往不合理。阻尼趋势（Damped Trend）通过引入阻尼参数 ϕ∈(0,1)\phi \in (0, 1)ϕ∈(0,1) 使趋势逐渐趋于平坦。大量实证研究表明，阻尼趋势方法在长期预测中通常优于非阻尼版本。


Holt-Winters 季节模型
Holt-Winters 方法在 Holt 趋势方法基础上增加了季节成分，是处理同时具有趋势和季节性的时间序列的标准方法。加法版本适用于季节振幅恒定的场景，乘法版本适用于季节振幅随水平成比例变化的场景。


def holt_winters(series, seasonal='add', seasonal_periods=12,
                  damped=True, forecast_steps=24):
    model = ExponentialSmoothing(
        series,
        trend='add',
        seasonal=seasonal,
        seasonal_periods=seasonal_periods,
        damped_trend=damped,
        initialization_method='estimated'
    )

    fit = model.fit(optimized=True)
    forecast = fit.forecast(steps=forecast_steps)

    residuals = fit.resid
    fitted = fit.fittedvalues

    return fit, forecast, {
        'alpha': fit.params['smoothing_level'],
        'beta': fit.params['smoothing_trend'],
        'gamma': fit.params['smoothing_seasonal'],
        'damping': fit.params.get('damping_trend', None),
        'aic': fit.aic,
        'bic': fit.bic,
        'mape': float(np.mean(np.abs(residuals / series)) * 100),
        'rmse': float(np.sqrt(np.mean(residuals**2)))
    }

def compare_seasonal_models(series, seasonal_periods=12, forecast_steps=12):
    models = {}

    for seasonal_type in ['add', 'mul']:
        for damped in [True, False]:
            name = f"HW_{seasonal_type}_{'damped' if damped else 'linear'}"
            try:
                model = ExponentialSmoothing(
                    series, trend='add', seasonal=seasonal_type,
                    seasonal_periods=seasonal_periods, damped_trend=damped,
                    initialization_method='estimated'
                )
                fit = model.fit(optimized=True)
                models[name] = {
                    'aic': fit.aic, 'bic': fit.bic,
                    'sse': fit.sse, 'model': fit
                }
            except Exception:
                continue

    return pd.DataFrame(models).T.sort_values('aic')
Holt-Winters 加法模型的更新方程为：


lt=α(yt−st−m)+(1−α)(lt−1+bt−1)l_t = \alpha(y_t - s_{t-m}) + (1-\alpha)(l_{t-1} + b_{t-1})lt​=α(yt​−st−m​)+(1−α)(lt−1​+bt−1​)
 


bt=β(lt−lt−1)+(1−β)bt−1b_t = \beta(l_t - l_{t-1}) + (1-\beta) b_{t-1}bt​=β(lt​−lt−1​)+(1−β)bt−1​
 


st=γ(yt−lt−1−bt−1)+(1−γ)st−ms_t = \gamma(y_t - l_{t-1} - b_{t-1}) + (1-\gamma) s_{t-m}st​=γ(yt​−lt−1​−bt−1​)+(1−γ)st−m​
其中 mmm 为季节周期长度，sts_tst​ 为季节成分。三个平滑参数 α\alphaα、β\betaβ、γ\gammaγ 分别控制水平、趋势和季节成分对新数据的响应速度。


ETS 状态空间框架
ETS 框架将所有指数平滑方法统一在状态空间模型的形式化语言中。每种 ETS 模型由三个字母标识：第一个字母描述误差类型（A=加法, M=乘法），第二个字母描述趋势类型（N=无, A=加法, Ad=阻尼加法），第三个字母描述季节类型（N=无, A=加法, M=乘法）。


from statsmodels.tsa.exponential_smoothing.ets import ETSModel

def auto_ets(series, seasonal_periods=12):
    candidates = []

    for error in ['add', 'mul']:
        for trend in ['add', 'mul', None]:
            for seasonal in ['add', 'mul', None]:
                for damped in [True, False]:
                    if trend is None and damped:
                        continue
                    try:
                        model = ETSModel(
                            series,
                            error=error,
                            trend=trend,
                            seasonal=seasonal,
                            seasonal_periods=seasonal_periods if seasonal else None,
                            damped_trend=damped
                        )
                        fit = model.fit(disp=False)
                        name = f"ETS({error[0].upper()},{trend[0].upper() if trend else 'N'}{'d' if damped else ''},{seasonal[0].upper() if seasonal else 'N'})"
                        candidates.append({
                            'model': name, 'aic': fit.aic,
                            'bic': fit.bic, 'fit': fit
                        })
                    except Exception:
                        continue

    results = pd.DataFrame(candidates).sort_values('aic')
    best = results.iloc[0]

    return best['fit'], results[['model', 'aic', 'bic']]
ETS 框架的理论贡献在于为每种指数平滑方法提供了：概率性预测（不仅给出点预测，还给出预测分布）、信息准则（AIC/BIC 用于模型选择）和最大似然参数估计。这使得指数平滑从直觉启发式方法提升为严格的统计建模框架。

小结
    

  • 指数平滑方法通过指数衰减权重对历史数据加权平均，直觉简单且预测效果优异
    • 

  • SES 仅建模水平成分，Holt 增加趋势，Holt-Winters 增加季节性，形成完整的方法族
    • 

  • 阻尼趋势方法在长期预测中通常优于非阻尼版本，是默认推荐的趋势处理方式
    • 

  • 加法季节模型适用于振幅恒定场景，乘法季节模型适用于振幅随水平变化场景
    • 

  • ETS 状态空间框架统一了所有指数平滑方法，提供概率预测、信息准则和最大似然估计
    • 

  • 自动 ETS 模型选择通过 AIC/BIC 在 30 种可能组合中找到最优模型
    • 

  • 指数平滑与 ARIMA 互补：指数平滑擅长捕获缓慢变化的趋势和季节性，ARIMA 擅长捕获自相关结构
    •
