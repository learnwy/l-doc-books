ARIMA 模型族

核心概念

ARIMA（AutoRegressive Integrated Moving Average）模型族是经典时间序列预测的基石，它将自回归（AR）、差分（I）和移动平均（MA）三个组件结合在统一的框架中。ARIMA 模型的核心假设是：一个非平稳时间序列经过适当阶数的差分后变为平稳序列，而平稳序列可以用 ARMA 模型描述。ARIMA(p,d,q) 中 p 为 AR 阶数，d 为差分阶数，q 为 MA 阶数。

ARIMA 模型族的建模流程遵循 Box-Jenkins 方法论：识别（通过 ACF/PACF 确定阶数）→ 估计（最大似然法估计参数）→ 诊断（残差检验是否为白噪声）→ 预测。这套方法论虽然提出于 1970 年代，至今仍然是时间序列分析的标准框架。


AR 与 MA 模型
AR(p) 模型将当前时刻的值表示为前 p 个时刻值的线性组合加上白噪声：


Xt=c+ϕ1Xt−1+ϕ2Xt−2+⋯+ϕpXt−p+ϵtX_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + \cdots + \phi_p X_{t-p} + \epsilon_tXt​=c+ϕ1​Xt−1​+ϕ2​Xt−2​+⋯+ϕp​Xt−p​+ϵt​
AR 模型的平稳性条件是特征方程 1−ϕ1z−ϕ2z2−⋯−ϕpzp=01 - \phi_1 z - \phi_2 z^2 - \cdots - \phi_p z^p = 01−ϕ1​z−ϕ2​z2−⋯−ϕp​zp=0 的所有根在单位圆外。AR(1) 模型中，平稳性条件简化为 ∣ϕ1∣<1|\phi_1| < 1∣ϕ1​∣<1。


from statsmodels.tsa.arima.model import ARIMA
from statsmodels.tsa.stattools import arma_order_select_ic
import pandas as pd
import numpy as np

def fit_ar_model(series, max_p=10):
    best_aic = np.inf
    best_order = 0
    results = []

    for p in range(1, max_p + 1):
        try:
            model = ARIMA(series, order=(p, 0, 0))
            fit = model.fit()
            results.append({
                'p': p, 'aic': fit.aic, 'bic': fit.bic,
                'log_likelihood': fit.llf
            })
            if fit.aic < best_aic:
                best_aic = fit.aic
                best_order = p
        except Exception:
            continue

    best_model = ARIMA(series, order=(best_order, 0, 0)).fit()
    return best_model, pd.DataFrame(results)

def fit_arima_model(series, order=(1, 1, 1)):
    model = ARIMA(series, order=order)
    fit = model.fit()

    diagnostics = {
        'aic': fit.aic,
        'bic': fit.bic,
        'log_likelihood': fit.llf,
        'params': dict(zip(fit.param_names, fit.params)),
        'residual_mean': float(fit.resid.mean()),
        'residual_std': float(fit.resid.std())
    }

    return fit, diagnostics
MA(q) 模型将当前值表示为当前和前 q 个时刻白噪声的线性组合：


Xt=μ+ϵt+θ1ϵt−1+θ2ϵt−2+⋯+θqϵt−qX_t = \mu + \epsilon_t + \theta_1 \epsilon_{t-1} + \theta_2 \epsilon_{t-2} + \cdots + \theta_q \epsilon_{t-q}Xt​=μ+ϵt​+θ1​ϵt−1​+θ2​ϵt−2​+⋯+θq​ϵt−q​
MA 模型天然平稳（它是有限个白噪声的线性组合），但存在可逆性问题。可逆性要求 MA 特征方程的根在单位圆外，保证同一个 ACF 对应唯一的 MA 模型。


ARIMA 阶数选择
阶数选择是 ARIMA 建模中最关键的步骤。两种主流方法是 ACF/PACF 图形法和信息准则法（AIC/BIC）。图形法依赖人工判断 ACF/PACF 的截尾和拖尾模式，需要一定的经验；信息准则法通过网格搜索所有候选阶数组合，选择 AIC 或 BIC 最小的模型。


def auto_arima_grid_search(series, max_p=5, max_d=2, max_q=5, criterion='aic'):
    best_score = np.inf
    best_order = None
    results = []

    for d in range(max_d + 1):
        for p in range(max_p + 1):
            for q in range(max_q + 1):
                if p == 0 and q == 0:
                    continue
                try:
                    model = ARIMA(series, order=(p, d, q))
                    fit = model.fit()
                    score = fit.aic if criterion == 'aic' else fit.bic
                    results.append({
                        'order': (p, d, q), criterion: score,
                        'log_likelihood': fit.llf
                    })
                    if score < best_score:
                        best_score = score
                        best_order = (p, d, q)
                except Exception:
                    continue

    best_model = ARIMA(series, order=best_order).fit()
    return best_model, best_order, pd.DataFrame(results).sort_values(criterion)

def stepwise_arima(series, start_p=1, start_q=1, max_p=5, max_q=5,
                    d=None, seasonal=False):
    from pmdarima import auto_arima

    model = auto_arima(
        series,
        start_p=start_p, start_q=start_q,
        max_p=max_p, max_q=max_q,
        d=d,
        seasonal=seasonal,
        stepwise=True,
        suppress_warnings=True,
        information_criterion='aic',
        trace=False
    )

    return model, {
        'order': model.order,
        'seasonal_order': model.seasonal_order if seasonal else None,
        'aic': model.aic(),
        'bic': model.bic()
    }
AIC（Akaike Information Criterion）倾向于选择预测精度更高的模型，可能导致过拟合；BIC（Bayesian Information Criterion）对参数数量的惩罚更重，倾向于更简约的模型。当样本量较大时，BIC 通常选择比 AIC 更低阶的模型。在实际应用中，推荐同时考虑 AIC 和 BIC，如果两者推荐不同阶数，倾向于选择更简约的模型。

SARIMA 季节模型
SARIMA 模型在 ARIMA 基础上增加了季节性成分，完整表示为 SARIMA(p,d,q)(P,D,Q,s)。其中小写参数 (p,d,q) 描述非季节性行为，大写参数 (P,D,Q) 描述季节性行为，s 为季节周期长度。


def fit_sarima(series, order=(1, 1, 1), seasonal_order=(1, 1, 1, 12)):
    model = ARIMA(series, order=order, seasonal_order=seasonal_order)
    fit = model.fit()

    forecast = fit.get_forecast(steps=seasonal_order[3])
    forecast_df = pd.DataFrame({
        'forecast': forecast.predicted_mean,
        'lower_ci': forecast.conf_int().iloc[:, 0],
        'upper_ci': forecast.conf_int().iloc[:, 1]
    })

    return fit, forecast_df

def diagnose_arima_residuals(fit_result, lags=20):
    residuals = fit_result.resid

    from statsmodels.stats.diagnostic import acorr_ljungbox
    lb_result = acorr_ljungbox(residuals, lags=lags, return_df=True)

    from scipy.stats import jarque_bera
    jb_stat, jb_pvalue = jarque_bera(residuals.dropna())

    return {
        'ljung_box': lb_result,
        'white_noise': (lb_result['lb_pvalue'] > 0.05).all(),
        'normality': {'jb_stat': jb_stat, 'jb_pvalue': jb_pvalue,
                      'is_normal': jb_pvalue > 0.05},
        'residual_stats': {
            'mean': float(residuals.mean()),
            'std': float(residuals.std()),
            'skew': float(residuals.skew()),
            'kurtosis': float(residuals.kurtosis())
        }
    }
SARIMA 的季节差分 DDD 消除季节性非平稳，季节 AR(P) 捕获跨季节的自回归关系，季节 MA(Q) 捕获跨季节的滑动平均关系。例如月度数据中 SARIMA(1,1,1)(1,1,1,12) 表示：非季节部分为 ARIMA(1,1,1)，季节部分在滞后 12 处有一个 AR 项和一个 MA 项，且进行了一次季节差分。


参数过多是 SARIMA 的实际挑战。SARIMA(2,1,2)(2,1,2,12) 有 8 个待估参数，在短序列上容易过拟合。pmdarima 库的 auto_arima 函数实现了自动化的逐步搜索算法，大幅减少人工调参的工作量。


模型诊断与预测
模型诊断的核心任务是验证残差是否满足白噪声假设。一个合格的 ARIMA 模型的残差应当满足：均值为零、方差恒定、无自相关、近似正态分布。如果残差不满足这些条件，说明模型结构不够充分或阶数选择不当。


预测结果应当包含点预测和预测区间。ARIMA 模型的预测区间随预测步数增大而扩展，反映了预测不确定性的增长。长期预测的区间会非常宽，实际意义有限，因此 ARIMA 模型更适合短期预测。

小结
    

  • ARIMA 模型族将自回归、差分和移动平均统一在 Box-Jenkins 框架中，是经典时间序列预测的标准方法
    • 

  • AR 模型通过历史值的线性组合预测，MA 模型通过历史误差的线性组合预测，ARIMA 是两者的整合
    • 

  • 阶数选择可通过 ACF/PACF 图形法和 AIC/BIC 信息准则法，pmdarima 的 auto_arima 实现自动化搜索
    • 

  • SARIMA 在 ARIMA 基础上增加季节性成分，适用于具有固定周期季节模式的时间序列
    • 

  • 模型诊断需要检验残差的无自相关性、正态性和方差齐性，任何不满足都需要调整模型
    • 

  • ARIMA 模型更适合短期预测，长期预测的不确定性区间会快速扩展
    • 

  • 实践中推荐"平稳性检验 → ACF/PACF 初步识别 → auto_arima 自动搜索 → 残差诊断 → 预测"的完整流程
    •
