时间序列机器学习方法

核心概念

传统的 ARIMA 和指数平滑方法基于线性假设和手工特征工程，在面对复杂非线性模式、高维外生变量和大规模多变量预测时存在局限。机器学习方法通过自动学习特征表示和非线性映射关系，为时间序列预测提供了更灵活和强大的工具集。从梯度提升树到深度学习，现代 ML 方法在时序预测竞赛和工业应用中已经展现出超越传统方法的能力。

机器学习方法在时间序列上的应用需要特别注意时序数据的独特性质：数据的时序依赖性要求严格的时间分割（不能随机分割）、特征工程需要避免未来信息泄露、多步预测的误差累积问题、以及不同序列可能需要不同模型。


树模型时序预测
梯度提升树（LightGBM、XGBoost）是当前工业界时序预测中最常用的 ML 方法。它们不直接处理时间序列的序列结构，而是通过手工构造滞后特征、滑动窗口统计特征和日历特征将时序预测转化为传统的表格回归问题。


import lightgbm as lgb
import numpy as np
import pandas as pd

def create_lag_features(df, target_col, lags, group_col=None):
    for lag in lags:
        if group_col:
            df[f'lag_{lag}'] = df.groupby(group_col)[target_col].shift(lag)
        else:
            df[f'lag_{lag}'] = df[target_col].shift(lag)
    return df

def create_rolling_features(df, target_col, windows, group_col=None):
    for w in windows:
        if group_col:
            rolling = df.groupby(group_col)[target_col].transform(
                lambda x: x.shift(1).rolling(w, min_periods=1).mean()
            )
        else:
            rolling = df[target_col].shift(1).rolling(w, min_periods=1).mean()

        df[f'rolling_mean_{w}'] = rolling

        if group_col:
            df[f'rolling_std_{w}'] = df.groupby(group_col)[target_col].transform(
                lambda x: x.shift(1).rolling(w, min_periods=1).std()
            )
        else:
            df[f'rolling_std_{w}'] = df[target_col].shift(1).rolling(w, min_periods=1).std()

    return df

def train_lightgbm_forecaster(train_df, val_df, features, target,
                                params=None):
    if params is None:
        params = {
            'objective': 'regression',
            'metric': 'rmse',
            'learning_rate': 0.05,
            'num_leaves': 31,
            'max_depth': -1,
            'feature_fraction': 0.8,
            'bagging_fraction': 0.8,
            'bagging_freq': 5,
            'verbose': -1
        }

    train_set = lgb.Dataset(train_df[features], train_df[target])
    val_set = lgb.Dataset(val_df[features], val_df[target], reference=train_set)

    model = lgb.train(
        params, train_set,
        num_boost_round=1000,
        valid_sets=[val_set],
        callbacks=[lgb.early_stopping(50), lgb.log_evaluation(0)]
    )

    predictions = model.predict(val_df[features])

    return model, predictions
时序数据的交叉验证不能使用随机 K 折，必须使用时间序列交叉验证（Time Series CV）。常见的策略包括：滑动窗口验证（固定窗口大小，每步向前滑动）、扩展窗口验证（训练集不断扩大）和嵌套时间验证（多层时间分割）。


多步预测有两种基本策略：递归策略（Recursive）将一步预测的输出作为下一步的输入，误差会逐步累积；直接策略（Direct）为每个预测步长训练独立的模型，避免误差累积但需要更多训练。

深度学习时序模型
LSTM（Long Short-Term Memory）和 GRU（Gated Recurrent Unit）是处理序列数据的经典深度学习架构。LSTM 通过门控机制（输入门、遗忘门、输出门）选择性地记忆和遗忘信息，能够捕获长距离的时序依赖关系。


import torch
import torch.nn as nn

class LSTMForecaster(nn.Module):
    def __init__(self, input_dim, hidden_dim=64, num_layers=2,
                 output_dim=1, dropout=0.2):
        super().__init__()
        self.lstm = nn.LSTM(
            input_dim, hidden_dim, num_layers,
            batch_first=True, dropout=dropout
        )
        self.fc = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim // 2),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(hidden_dim // 2, output_dim)
        )

    def forward(self, x):
        lstm_out, _ = self.lstm(x)
        last_hidden = lstm_out[:, -1, :]
        return self.fc(last_hidden)

class TransformerForecaster(nn.Module):
    def __init__(self, input_dim, d_model=64, nhead=4,
                 num_layers=2, output_dim=1, dropout=0.1):
        super().__init__()
        self.input_proj = nn.Linear(input_dim, d_model)
        self.pos_encoding = nn.Parameter(torch.randn(1, 512, d_model))

        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model, nhead=nhead,
            dim_feedforward=d_model * 4,
            dropout=dropout, batch_first=True
        )
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers)
        self.output_proj = nn.Linear(d_model, output_dim)

    def forward(self, x):
        seq_len = x.size(1)
        x = self.input_proj(x) + self.pos_encoding[:, :seq_len, :]
        x = self.transformer(x)
        return self.output_proj(x[:, -1, :])
Transformer 架构通过自注意力机制直接建模序列中任意两个时间步之间的依赖关系，避免了 RNN 的梯度消失问题和顺序计算限制。Informer、Autoformer 和 PatchTST 等专门为长序列时序预测设计的 Transformer 变体在多个基准数据集上取得了当前最佳性能。


N-BEATS（Neural Basis Expansion Analysis for Time Series）是一种纯时序深度学习架构，它不使用任何时序特征工程，直接从原始序列中学习预测。N-BEATS 的独特优势是其可解释版本可以自动将预测分解为趋势和季节成分。


Prophet 与混合方法
Prophet 是 Facebook 开源的时序预测工具，专为业务场景设计。它将时间序列建模为趋势、季节性、节假日效应和外生变量四个可加成分的组合，使用贝叶斯方法估计参数。Prophet 的最大优势是对非专业用户友好——默认参数即可获得不错的预测效果，且模型的每个成分都直观可解释。


from prophet import Prophet
import pandas as pd

def prophet_forecast(df, periods=30, yearly=True, weekly=True,
                      daily=False, changepoint_prior=0.05):
    model = Prophet(
        yearly_seasonality=yearly,
        weekly_seasonality=weekly,
        daily_seasonality=daily,
        changepoint_prior_scale=changepoint_prior,
        seasonality_mode='multiplicative'
    )

    model.fit(df)
    future = model.make_future_dataframe(periods=periods)
    forecast = model.predict(future)

    return model, forecast

def ensemble_forecast(series, forecast_steps=12):
    from statsmodels.tsa.holtwinters import ExponentialSmoothing
    from statsmodels.tsa.arima.model import ARIMA

    ets_model = ExponentialSmoothing(
        series, trend='add', seasonal='add', seasonal_periods=12,
        damped_trend=True, initialization_method='estimated'
    ).fit(optimized=True)
    ets_forecast = ets_model.forecast(steps=forecast_steps)

    arima_model = ARIMA(series, order=(1, 1, 1), seasonal_order=(1, 1, 1, 12)).fit()
    arima_forecast = arima_model.forecast(steps=forecast_steps)

    ensemble = 0.5 * ets_forecast.values + 0.5 * arima_forecast.values

    return pd.DataFrame({
        'ets': ets_forecast.values,
        'arima': arima_forecast.values,
        'ensemble': ensemble
    })
模型集成是提升时序预测精度的有效策略。M4 预测竞赛的获胜方案（ES-RNN）即是指数平滑和 RNN 的混合。简单的等权平均集成通常就能超越任何单一模型，加权集成根据验证集上的表现动态调整权重效果更好。

小结
    

  • 机器学习方法通过特征工程将时序预测转化为表格回归，梯度提升树是工业界最常用的方案
    • 

  • 时序交叉验证必须使用时间序列分割，绝不能随机打乱
    • 

  • 递归策略误差累积严重，直接策略需要多个模型，MIMO 是兼顾效率和精度的选择
    • 

  • LSTM/GRU 通过门控机制处理长距离依赖，Transformer 通过注意力机制直接建模任意时间步关系
    • 

  • N-BEATS 等纯时序深度学习架构无需手工特征工程，可解释版本支持趋势-季节分解
    • 

  • Prophet 面向业务用户，提供直观可解释的成分分解，默认参数即可获得较好效果
    • 

  • 模型集成是提升预测精度的通用策略，简单等权平均通常就能超越单一模型
    • 

  • 方法选择取决于数据规模、预测步长和可解释性需求：小数据用 ARIMA/ETS，大数据用 ML/DL
    •
