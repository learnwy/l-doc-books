深度学习时序模型

核心概念

深度学习在时间序列分析领域带来了革命性的突破。传统统计模型（ARIMA、指数平滑）依赖线性假设和手工特征工程，而深度学习模型能够自动从原始序列中学习复杂的非线性时间依赖关系、多尺度周期模式和跨变量交互。从 RNN/LSTM 到 Transformer 架构，深度学习时序模型的演进反映了序列建模能力的持续提升。

深度学习时序模型按架构演进可分为三代：循环架构（RNN、LSTM、GRU）通过隐状态传递时间信息；卷积架构（TCN、WaveNet）通过因果膨胀卷积捕获多尺度模式；注意力架构（Transformer 及其变体）通过自注意力机制直接建模任意时间步之间的依赖关系。

LSTM 与门控循环网络
LSTM（Long Short-Term Memory）通过引入门控机制解决了标准 RNN 的梯度消失问题，使得网络能够学习数十到数百步的长程依赖关系。LSTM 的三个门——遗忘门、输入门和输出门——分别控制信息的丢弃、写入和读取。


interface LSTMCell {
  forgetGate: (h: number[], x: number[]) => number[];
  inputGate: (h: number[], x: number[]) => number[];
  outputGate: (h: number[], x: number[]) => number[];
  cellCandidate: (h: number[], x: number[]) => number[];
}

function lstmForward(x: number[][], hiddenSize: number): { outputs: number[][]; finalState: number[] } {
  let h = new Array(hiddenSize).fill(0);
  let c = new Array(hiddenSize).fill(0);
  const outputs: number[][] = [];

  for (const xt of x) {
    const concat = [...h, ...xt];
    const ft = sigmoid(linearTransform(concat, hiddenSize));
    const it = sigmoid(linearTransform(concat, hiddenSize));
    const ct = tanh(linearTransform(concat, hiddenSize));
    const ot = sigmoid(linearTransform(concat, hiddenSize));

    c = c.map((ci, idx) => ft[idx] * ci + it[idx] * ct[idx]);
    h = c.map((ci, idx) => ot[idx] * Math.tanh(ci));
    outputs.push([...h]);
  }

  return { outputs, finalState: h };
}

function sigmoid(x: number[]): number[] {
  return x.map((v) => 1 / (1 + Math.exp(-v)));
}

function tanh(x: number[]): number[] {
  return x.map((v) => Math.tanh(v));
}

function linearTransform(input: number[], outputSize: number): number[] {
  return new Array(outputSize).fill(0).map(() => input.reduce((sum, v) => sum + v * (Math.random() - 0.5), 0));
}
DeepAR 是 Amazon 提出的基于自回归 LSTM 的概率预测模型。它的创新在于：不输出单一预测值，而是输出预测分布的参数（如高斯分布的均值和方差），从而支持概率预测和不确定性量化。DeepAR 还支持多序列联合训练，通过共享模型参数在多个相关序列之间迁移知识。


GRU（Gated Recurrent Unit）是 LSTM 的简化版本，将遗忘门和输入门合并为更新门，减少了参数量。在许多实际场景中，GRU 的性能与 LSTM 相当，但训练速度更快。


时序卷积网络
时序卷积网络（TCN, Temporal Convolutional Network）通过因果卷积和膨胀卷积在时间序列上实现高效的模式提取。因果卷积确保模型只使用过去的信息预测未来，膨胀卷积通过指数增长的膨胀率在有限层数内覆盖超长的感受野。


interface TCNConfig {
  inputChannels: number;
  outputChannels: number;
  kernelSize: number;
  numLayers: number;
  dilationBase: number;
}

function computeReceptiveField(config: TCNConfig): number {
  let receptiveField = 1;
  for (let i = 0; i < config.numLayers; i++) {
    const dilation = config.dilationBase ** i;
    receptiveField += (config.kernelSize - 1) * dilation;
  }
  return receptiveField;
}

function causalConv1d(input: number[], kernel: number[], dilation: number): number[] {
  const output: number[] = [];
  const kLen = kernel.length;
  for (let i = 0; i < input.length; i++) {
    let sum = 0;
    for (let j = 0; j < kLen; j++) {
      const idx = i - j * dilation;
      if (idx >= 0) {
        sum += input[idx] * kernel[j];
      }
    }
    output.push(sum);
  }
  return output;
}
TCN 相比 RNN 的主要优势是：支持并行计算（所有时间步可以同时处理），感受野大小可以精确控制（通过调整层数和膨胀率），训练更稳定（不存在梯度消失/爆炸问题）。WaveNet 是 TCN 架构的代表性应用，最初用于音频生成，后来被广泛应用于时间序列预测。

Transformer 时序变体
Transformer 架构凭借自注意力机制在 NLP 领域取得巨大成功后，迅速被引入时间序列领域。然而，标准 Transformer 的 O(T²) 注意力复杂度使其难以直接处理长时间序列。为解决这一问题，研究者提出了多种高效 Transformer 变体。


Informer 引入 ProbSparse 自注意力机制，只计算最"活跃"的 query-key 对，将注意力复杂度从 O(T²) 降至 O(T log T)。同时通过自注意力蒸馏（distilling）逐层缩短序列长度。


Autoformer 将时间序列分解（趋势+季节性）嵌入到 Transformer 架构中，用自相关注意力（Auto-Correlation）替代标准自注意力，更好地捕获周期模式。


PatchTST 借鉴 Vision Transformer 的思想，将时间序列切分为固定长度的 patch，每个 patch 作为一个 token 输入 Transformer。这种方法大幅减少了 token 数量，同时保留了局部时间模式。


值得注意的是，2023 年的研究（DLinear）发现，简单的线性模型在长程时序预测任务上可以超越许多复杂的 Transformer 变体。这一发现引发了对时序 Transformer 是否真正有效的广泛讨论，也推动了社区更加关注模型的公平比较和实验方法论。


训练策略与实践
深度学习时序模型的训练需要特别关注几个与传统深度学习不同的问题：时间序列的非平稳性、训练/验证的时间划分、多步预测的误差累积以及输入序列长度的选择。


时间序列的训练集/验证集/测试集划分必须严格遵循时间顺序，不能使用随机划分（这会导致数据泄露）。典型做法是按时间顺序取最后 20% 作为测试集，倒数 20%-30% 作为验证集。


interface TimeSeriesSplit {
  trainEnd: number;
  valEnd: number;
  windowSize: number;
  horizon: number;
}

function createSlidingWindows(
  data: number[],
  split: TimeSeriesSplit,
): { train: number[][][]; val: number[][][]; test: number[][][] } {
  const createWindows = (start: number, end: number) => {
    const windows: number[][][] = [];
    for (let i = start; i <= end - split.windowSize - split.horizon; i++) {
      const input = data.slice(i, i + split.windowSize).map((v) => [v]);
      const target = data.slice(i + split.windowSize, i + split.windowSize + split.horizon).map((v) => [v]);
      windows.push([input, target]);
    }
    return windows;
  };

  return {
    train: createWindows(0, split.trainEnd),
    val: createWindows(split.trainEnd, split.valEnd),
    test: createWindows(split.valEnd, data.length),
  };
}

  • 深度学习时序模型经历了从循环架构到卷积架构再到注意力架构的三代演进
    • 

  • LSTM 通过门控机制解决梯度消失问题，DeepAR 将其扩展为概率预测模型
    • 

  • TCN 通过因果膨胀卷积实现高效并行的长程时间依赖建模
    • 

  • Transformer 时序变体通过高效注意力、序列分解和 Patch 化应对长序列挑战
    • 

  • 简单线性模型在某些长程预测任务上可以超越复杂 Transformer 变体，提醒我们关注公平比较
    • 

  • 训练时序模型必须严格遵循时间顺序划分数据集，避免数据泄露
