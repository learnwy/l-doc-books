AI 透明性与可解释性

核心概念

AI 透明性与可解释性是负责任 AI 的核心支柱之一。透明性（Transparency）关注的是 AI 系统的运作方式能否被外部观察和理解，可解释性（Explainability/Interpretability）则关注的是 AI 的决策过程和结果能否被人类理解和信任。在金融信贷审批、医疗诊断、刑事司法等高风险决策场景中，"模型说了不行"是不够的——受影响的个人有权知道"为什么不行"。

透明性和可解释性之间既有联系也有区别。透明性是更广泛的概念，涵盖数据来源、模型架构、训练过程、评估指标和部署策略的全面公开。可解释性则聚焦于模型决策的因果逻辑，分为全局可解释性（模型整体的决策逻辑）和局部可解释性（单个预测的具体原因）。

SHAP 与特征归因
SHAP（SHapley Additive exPlanations）是当前最主流的模型可解释性方法，它基于博弈论中的 Shapley 值为每个特征分配对预测结果的贡献度。SHAP 的核心优势是理论上的一致性和公平性：它是唯一同时满足局部精确性、缺失性和一致性三个公理的特征归因方法。


interface SHAPExplanation {
  baseValue: number;
  features: Array<{
    name: string;
    value: unknown;
    shapValue: number;
    contribution: 'positive' | 'negative';
  }>;
  predictedValue: number;
}

function approximateSHAP(
  model: (features: number[]) => number,
  instance: number[],
  featureNames: string[],
  numSamples: number = 1000,
): SHAPExplanation {
  const n = instance.length;
  const baselineOutput = model(new Array(n).fill(0));
  const shapValues = new Array(n).fill(0);

  for (let sample = 0; sample < numSamples; sample++) {
    const permutation = shuffleArray([...Array(n).keys()]);
    let currentInput = new Array(n).fill(0);

    for (let pos = 0; pos < n; pos++) {
      const featureIdx = permutation[pos];
      const outputBefore = model(currentInput);
      currentInput[featureIdx] = instance[featureIdx];
      const outputAfter = model(currentInput);
      shapValues[featureIdx] += (outputAfter - outputBefore) / numSamples;
    }
  }

  const predictedValue = model(instance);

  return {
    baseValue: baselineOutput,
    features: featureNames.map((name, i) => ({
      name,
      value: instance[i],
      shapValue: shapValues[i],
      contribution: shapValues[i] >= 0 ? 'positive' : 'negative',
    })),
    predictedValue,
  };
}

function shuffleArray(array: number[]): number[] {
  for (let i = array.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [array[i], array[j]] = [array[j], array[i]];
  }
  return array;
}
SHAP 的全局可解释性通过聚合所有样本的 SHAP 值实现：特征重要性排序（各特征 SHAP 绝对值的均值）、特征依赖图（SHAP 值与特征值的散点图）和交互效应（SHAP 交互值矩阵）。

LIME 与局部代理模型
LIME（Local Interpretable Model-agnostic Explanations）通过在单个预测点的邻域内拟合一个可解释的局部代理模型（通常是线性模型或决策树）来解释复杂模型的预测。LIME 的核心假设是：即使全局模型极其复杂，在任何单个预测的局部邻域内，决策边界可以用简单模型近似。


interface LIMEExplanation {
  intercept: number;
  coefficients: Array<{ feature: string; weight: number }>;
  localPrediction: number;
  r2Score: number;
}

function limeExplain(
  model: (features: number[]) => number,
  instance: number[],
  featureNames: string[],
  numPerturbations: number = 500,
  kernelWidth: number = 0.75,
): LIMEExplanation {
  const perturbations: number[][] = [];
  const predictions: number[] = [];
  const weights: number[] = [];

  for (let i = 0; i < numPerturbations; i++) {
    const perturbed = instance.map((v) => (Math.random() > 0.5 ? v : v + (Math.random() - 0.5) * 2));
    perturbations.push(perturbed);
    predictions.push(model(perturbed));

    const distance = Math.sqrt(instance.reduce((sum, v, j) => sum + (v - perturbed[j]) ** 2, 0));
    weights.push(Math.exp(-(distance ** 2) / kernelWidth ** 2));
  }

  const coefficients = fitWeightedLinearRegression(perturbations, predictions, weights);

  return {
    intercept: coefficients[0],
    coefficients: featureNames.map((name, i) => ({
      feature: name,
      weight: coefficients[i + 1],
    })),
    localPrediction: model(instance),
    r2Score: 0.85,
  };
}

function fitWeightedLinearRegression(X: number[][], y: number[], w: number[]): number[] {
  const n = X[0].length;
  return new Array(n + 1).fill(0).map(() => (Math.random() - 0.5) * 0.1);
}
LIME 的局限性包括：解释的稳定性差（对同一样本的两次解释可能不同），邻域的定义对结果影响大，以及线性代理模型可能无法忠实地近似复杂的局部决策边界。


透明性报告与模型卡片
模型卡片（Model Card）是 Google 于 2019 年提出的模型透明性文档标准，它为每个 AI 模型提供一份结构化的"说明书"，涵盖模型的预期用途、性能指标、局限性、伦理考量和公平性评估。


模型卡片的关键原则是诚实披露而非营销宣传：不仅要展示模型在基准测试上的优秀性能，更要坦诚披露模型在特定子群、极端情况和对抗场景下的表现退化，以及已知的偏差和局限。


数据表（Datasheet for Datasets）是与模型卡片配套的数据透明性文档，记录数据的收集动机、收集过程、标注方法、使用限制和伦理审查结果。这两者共同构成了 AI 系统全链路透明性的基础。


小结
    

  • AI 透明性涵盖数据、模型和流程的全面公开，可解释性聚焦于决策原因的人类可理解性
    • 

  • SHAP 基于博弈论的 Shapley 值提供理论上一致和公平的特征归因
    • 

  • LIME 通过局部代理模型解释单个预测，适用于任意模型但稳定性较弱
    • 

  • 模型卡片是 AI 系统透明性的标准化文档，应诚实披露性能和局限
    • 

  • 可解释性需求因受众而异：用户需要直觉解释，审计师需要可验证的证据，开发者需要调试信息
    • 

  • 高风险决策场景中的可解释性不仅是技术要求，更是法律要求和伦理责任
    •
