算法公平性

核心概念

算法公平性（Algorithmic Fairness）是研究如何确保算法决策不对特定群体产生系统性歧视的领域。在信贷审批、招聘筛选、刑事司法、广告投放和内容推荐等高影响场景中，算法偏见可能导致严重的社会后果。算法偏见不是技术 Bug，而是数据、模型和评估指标中系统性不公平的体现。理解偏见的来源、掌握公平性的度量方法和缓解技术，是构建负责任 AI 系统的必备能力。

偏见来源与检测
算法偏见可能在数据收集、模型训练、评估和部署的每个环节引入。


**历史偏见（Historical Bias）**是最根本的偏见来源。训练数据反映的是历史社会的分布，包含了历史性的歧视和不平等。例如，如果过去的贷款审批数据中少数族裔的批准率较低（可能源于制度性歧视），基于这些数据训练的模型会将低批准率"学"为一种合理的预测规则。


**采样偏见（Sampling Bias）**发生在数据收集不能代表目标群体时。例如，计算机视觉模型在深色皮肤人脸上的错误率远高于浅色皮肤，核心原因是训练数据中深色皮肤的面部图像显著不足。MIT 的 Gender Shades 研究发现商业人脸识别 API 在深色皮肤女性上的错误率高达 34.7%，而在浅色皮肤男性上仅为 0.8%。


import numpy as np
from sklearn.metrics import confusion_matrix

np.random.seed(42)
n = 5000

group_a_n = 2500
group_b_n = 2500

y_true_a = np.random.binomial(1, 0.3, group_a_n)
y_pred_a = y_true_a.copy()
flip_idx = np.random.choice(group_a_n, size=int(0.1 * group_a_n), replace=False)
y_pred_a[flip_idx] = 1 - y_pred_a[flip_idx]

y_true_b = np.random.binomial(1, 0.3, group_b_n)
y_pred_b = y_true_b.copy()
flip_idx = np.random.choice(group_b_n, size=int(0.2 * group_b_n), replace=False)
y_pred_b[flip_idx] = 1 - y_pred_b[flip_idx]

tpr_a = np.sum((y_pred_a == 1) & (y_true_a == 1)) / max(np.sum(y_true_a == 1), 1)
tpr_b = np.sum((y_pred_b == 1) & (y_true_b == 1)) / max(np.sum(y_true_b == 1), 1)
fpr_a = np.sum((y_pred_a == 1) & (y_true_a == 0)) / max(np.sum(y_true_a == 0), 1)
fpr_b = np.sum((y_pred_b == 1) & (y_true_b == 0)) / max(np.sum(y_true_b == 0), 1)

print(f"Group A - TPR: {tpr_a:.3f}, FPR: {fpr_a:.3f}")
print(f"Group B - TPR: {tpr_b:.3f}, FPR: {fpr_b:.3f}")
print(f"Equal Opportunity gap: {abs(tpr_a - tpr_b):.3f}")
print(f"Equalized Odds gap (TPR + FPR): {abs(tpr_a - tpr_b) + abs(fpr_a - fpr_b):.3f}")
**反馈循环偏见（Feedback Loop Bias）**在部署后不断放大初始偏见。如果预测性警务系统预测某个社区犯罪率高，导致更多警力部署到该社区，更多的警力必然发现更多的犯罪，从而进一步"验证"了系统的预测——这是一个自我强化的恶性循环。


偏见缓解技术
偏见缓解可以在数据预处理、模型训练和后处理三个阶段进行。


预处理方法在训练前修正数据中的偏见。重新采样（Resampling）通过欠采样多数组或过采样少数组来平衡各组的表示。重新标注（Relabeling）修正带有偏见的标签。数据增强通过生成合成样本来增加少数群体的表示。Feldman et al. (2015) 的 Disparate Impact Remover 通过修改非敏感特征的分布来消除与敏感属性的关联。


训练中方法在模型优化过程中引入公平性约束。约束优化方法将公平性指标（如均等机会差距）作为优化约束条件，在准确率和公平性之间找到帕累托最优解。对抗性去偏（Adversarial Debiasing）训练一个对抗网络来消除模型表征中对敏感属性的编码——主模型学习预测目标，对抗模型学习从主模型的表征中预测敏感属性，两者博弈直到对抗模型无法从表征中提取敏感信息。


后处理方法在模型预测后调整输出以满足公平性要求。Hardt et al. (2016) 的均等赔率后处理方法为每个群体学习不同的阈值，使最终的 TPR 和 FPR 在各组间相等。后处理的优势是不需要修改模型本身，可以应用于任何现有模型；劣势是可能导致个体层面的不公平（相同的预测值在不同群体中得到不同的决策）。

公平性审计实践
公平性审计是系统性评估算法公平性的流程化方法。


审计框架通常包含四个步骤：(1) 定义受保护群体和公平性标准；(2) 收集分群评估数据；(3) 计算各群体的公平性指标并对比；(4) 记录结论并提出改进建议。


**模型卡片（Model Cards）**是 Google 提出的标准化文档格式，要求模型开发者公开披露模型在不同子群体上的性能表现、训练数据的构成、已知的局限性和适用范围。模型卡片的核心价值在于将公平性评估从"事后补救"转变为"标准流程"。


小结
    

  • 算法偏见可能在数据收集、模型训练、评估和部署的每个环节引入，不是单一技术问题
    • 

  • 公平性的多种数学定义（统计均等、均等机会、预测校准等）之间存在不可调和的数学冲突
    • 

  • 偏见缓解可在预处理、训练中和后处理三个阶段进行，各有优劣需要根据场景选择
    • 

  • 反馈循环偏见在部署后不断放大初始偏见，需要持续监控和定期审计
    • 

  • 模型卡片将公平性评估标准化为模型开发的常规流程，是行业最佳实践
    • 

  • 公平性不是技术问题而是社会技术问题，最终的公平性标准选择需要利益相关者共同参与
    •
