差分隐私

核心概念

差分隐私（Differential Privacy）是一种严格的数学隐私保护框架，它提供了可量化、可证明的隐私保证。差分隐私的核心思想是：对数据库中任意一条记录的加入或移除，不应该显著改变任何查询或分析的输出结果。这意味着攻击者无法通过观察输出来推断任何特定个人的数据是否包含在数据集中。

差分隐私由 Cynthia Dwork 于 2006 年正式提出，其数学定义为：一个随机算法 M 满足 ε-差分隐私，当且仅当对于任意两个只相差一条记录的数据集 D 和 D'，以及任意输出集合 S，都有 P[M(D) ∈ S] ≤ e^ε × P[M(D') ∈ S]。参数 ε（epsilon）被称为隐私预算，ε 越小隐私保护越强。

噪声添加机制
差分隐私通过向查询结果中添加校准过的随机噪声来实现隐私保护。噪声的量级由查询的全局敏感度和隐私预算共同决定。全局敏感度衡量的是添加或删除一条记录对查询结果的最大可能影响。


拉普拉斯机制适用于数值查询（如计数、求和、均值），它向真实查询结果添加服从拉普拉斯分布的噪声，噪声的尺度参数为 Δf/ε，其中 Δf 是查询的全局敏感度。


function laplaceMechanism(trueValue: number, sensitivity: number, epsilon: number): number {
  const scale = sensitivity / epsilon;
  const u = Math.random() - 0.5;
  const noise = -scale * Math.sign(u) * Math.log(1 - 2 * Math.abs(u));
  return trueValue + noise;
}

function gaussianMechanism(trueValue: number, sensitivity: number, epsilon: number, delta: number): number {
  const sigma = (sensitivity * Math.sqrt(2 * Math.log(1.25 / delta))) / epsilon;
  const noise = gaussianRandom() * sigma;
  return trueValue + noise;
}

function gaussianRandom(): number {
  let u = 0;
  let v = 0;
  while (u === 0) u = Math.random();
  while (v === 0) v = Math.random();
  return Math.sqrt(-2.0 * Math.log(u)) * Math.cos(2.0 * Math.PI * v);
}

interface DPQuery {
  type: 'count' | 'sum' | 'mean' | 'histogram';
  epsilon: number;
  delta?: number;
}

function dpCount(data: unknown[], predicate: (item: unknown) => boolean, epsilon: number): number {
  const trueCount = data.filter(predicate).length;
  return Math.round(laplaceMechanism(trueCount, 1, epsilon));
}

function dpSum(values: number[], lowerBound: number, upperBound: number, epsilon: number): number {
  const clipped = values.map((v) => Math.max(lowerBound, Math.min(upperBound, v)));
  const trueSum = clipped.reduce((a, b) => a + b, 0);
  const sensitivity = upperBound - lowerBound;
  return laplaceMechanism(trueSum, sensitivity, epsilon);
}

function dpMean(values: number[], lowerBound: number, upperBound: number, epsilon: number): number {
  const halfEps = epsilon / 2;
  const noisySum = dpSum(values, lowerBound, upperBound, halfEps);
  const noisyCount = dpCount(values, () => true, halfEps);
  return noisyCount > 0 ? noisySum / noisyCount : 0;
}
高斯机制适用于 (ε,δ)-差分隐私设置，它使用高斯噪声替代拉普拉斯噪声。在多维查询和深度学习训练中，高斯机制通常比拉普拉斯机制更实用，因为高斯噪声在高维空间中的性质更好。


指数机制适用于非数值查询（如选择最优类别），它不是直接在输出上加噪，而是根据每个候选输出的"质量分数"按概率选择输出，质量分数越高的候选输出被选中的概率越大。


隐私预算管理
隐私预算管理是差分隐私实践中最关键的工程挑战。组合定理（Composition Theorem）告诉我们，对同一数据集进行多次差分隐私查询时，总隐私损失会累积。


interface PrivacyBudget {
  totalEpsilon: number;
  totalDelta: number;
  consumed: Array<{
    queryId: string;
    epsilon: number;
    delta: number;
    timestamp: Date;
  }>;
}

class PrivacyAccountant {
  private budget: PrivacyBudget;

  constructor(totalEpsilon: number, totalDelta: number) {
    this.budget = {
      totalEpsilon: totalEpsilon,
      totalDelta: totalDelta,
      consumed: [],
    };
  }

  remaining(): { epsilon: number; delta: number } {
    const usedEpsilon = this.budget.consumed.reduce((sum, q) => sum + q.epsilon, 0);
    const usedDelta = this.budget.consumed.reduce((sum, q) => sum + q.delta, 0);
    return {
      epsilon: this.budget.totalEpsilon - usedEpsilon,
      delta: this.budget.totalDelta - usedDelta,
    };
  }

  canSpend(epsilon: number, delta: number = 0): boolean {
    const rem = this.remaining();
    return rem.epsilon >= epsilon && rem.delta >= delta;
  }

  spend(queryId: string, epsilon: number, delta: number = 0): boolean {
    if (!this.canSpend(epsilon, delta)) return false;
    this.budget.consumed.push({
      queryId,
      epsilon,
      delta,
      timestamp: new Date(),
    });
    return true;
  }
}

差分隐私与机器学习
将差分隐私应用于机器学习（DP-ML）是当前最活跃的研究和工程实践方向。核心方法是 DP-SGD（Differentially Private Stochastic Gradient Descent），它在每步梯度更新中对梯度进行裁剪和加噪。


DP-SGD 的三个关键步骤是：梯度裁剪（将每个样本的梯度范数限制在阈值 C 以内，控制敏感度）、梯度加噪（添加尺度为 σ·C 的高斯噪声）和隐私记账（使用 Rényi DP 或 GDP 精确追踪累积隐私损失）。


Google 的 TensorFlow Privacy 和 Meta 的 Opacus（PyTorch）是两个主流的 DP-ML 框架。在实践中，DP-SGD 训练的模型精度通常低于非隐私训练，但通过增大数据集规模、优化超参数和使用预训练模型，精度差距可以控制在可接受范围内。


Apple 在 iOS 输入法中使用局部差分隐私收集表情符号使用频率，Google 在 Chrome 中使用 RAPPOR 协议收集浏览器使用统计，这些都是差分隐私在工业界的成功应用案例。


小结
    

  • 差分隐私提供了可量化、可证明的数学隐私保证，是当前最严格的隐私保护框架
    • 

  • 隐私预算 ε 控制隐私与精度的权衡，ε 越小隐私越强但噪声越大
    • 

  • 拉普拉斯机制、高斯机制和指数机制分别适用于数值查询、高维查询和非数值查询
    • 

  • 组合定理使得隐私预算在多次查询中累积消耗，隐私记账是工程实践的核心挑战
    • 

  • DP-SGD 将差分隐私引入深度学习训练，通过梯度裁剪和加噪实现模型级隐私保护
    • 

  • Apple 和 Google 的实践证明差分隐私可以在工业规模上成功部署
    •
