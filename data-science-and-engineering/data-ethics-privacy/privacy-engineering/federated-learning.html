联邦学习与隐私计算

核心概念

联邦学习（Federated Learning, FL）和隐私计算（Privacy-Preserving Computation）是"数据不出域"范式的技术基石。传统的机器学习要求将数据集中到一处进行训练，这在数据孤岛和隐私法规的双重约束下日益困难。联邦学习的核心思想是"模型到数据"而非"数据到模型"——各参与方在本地数据上训练模型，仅共享模型参数（或梯度）而不共享原始数据。隐私计算则提供了在加密或受保护状态下进行计算的技术能力，使得多方可以在互不暴露各自原始数据的前提下进行联合分析和模型训练。这些技术正在重塑数据协作的方式，特别是在金融风控、医疗研究和广告联合建模等跨机构场景中。

联邦学习架构
联邦学习根据数据分布方式分为三种类型，每种适用于不同的跨机构协作场景。


**横向联邦学习（Horizontal FL）**适用于参与方拥有相同特征但不同样本的场景。例如，不同区域的医院拥有相同格式的患者诊疗记录（相同特征），但患者群体不重叠（不同样本）。Google 的 Federated Averaging（FedAvg）是横向联邦学习的经典算法：各客户端在本地数据上执行多轮 SGD 训练，然后将更新后的模型参数发送到中央服务器进行加权平均聚合。


import numpy as np

def federated_averaging(
    global_model: np.ndarray,
    client_data: list[tuple[np.ndarray, np.ndarray]],
    learning_rate: float = 0.01,
    local_epochs: int = 5,
    rounds: int = 10
) -> np.ndarray:
    n_clients = len(client_data)

    for round_idx in range(rounds):
        client_updates = []
        client_sizes = []

        for X, y in client_data:
            local_model = global_model.copy()

            for epoch in range(local_epochs):
                predictions = X @ local_model
                gradient = -2 / len(X) * X.T @ (y - predictions)
                local_model -= learning_rate * gradient

            client_updates.append(local_model)
            client_sizes.append(len(X))

        total_samples = sum(client_sizes)
        global_model = sum(
            (size / total_samples) * update
            for size, update in zip(client_sizes, client_updates)
        )

        total_loss = sum(
            np.mean((X @ global_model - y) ** 2)
            for X, y in client_data
        ) / n_clients

        if (round_idx + 1) % 5 == 0:
            print(f"Round {round_idx + 1}: avg_loss={total_loss:.4f}")

    return global_model

np.random.seed(42)
true_weights = np.array([3.0, -2.0, 1.5])

client_data = []
for _ in range(5):
    X = np.random.randn(200, 3)
    y = X @ true_weights + np.random.normal(0, 0.5, 200)
    client_data.append((X, y))

init_model = np.zeros(3)
final_model = federated_averaging(init_model, client_data, rounds=20)
print(f"True weights: {true_weights}")
print(f"Learned weights: {final_model.round(3)}")
**纵向联邦学习（Vertical FL）**适用于参与方拥有相同样本但不同特征的场景。例如，银行拥有用户的金融数据，电商平台拥有用户的购物数据，两者的用户群体有重叠。纵向联邦的核心挑战在于：如何在不暴露各自原始特征的前提下，利用双方的特征联合训练模型。常用方法包括基于秘密分享的安全分割学习和基于同态加密的安全梯度计算。


安全多方计算与同态加密
安全多方计算（Secure Multi-Party Computation, MPC）和同态加密（Homomorphic Encryption, HE）为联邦学习提供了更强的安全保证。


**秘密分享（Secret Sharing）**是 MPC 的基本构建块。Shamir 秘密分享将一个秘密值拆分为 n 份，任何 t 份（t ≤ n）可以恢复原始秘密，但少于 t 份无法获得任何信息。加法秘密分享更为简单：将 x 拆分为 x₁ + x₂ = x，两方各持一份。在此基础上可以高效实现加法、乘法等基本运算，进而构建复杂的联合计算协议。


**全同态加密（Fully Homomorphic Encryption, FHE）**允许在加密数据上直接进行任意计算，计算结果解密后与在明文上计算的结果一致。FHE 提供了最强的隐私保证——数据全程加密，甚至计算服务器也无法看到原始数据。但 FHE 的计算开销极大（通常比明文计算慢 1000-10000 倍），限制了其在大规模机器学习中的应用。


**可信执行环境（TEE）**如 Intel SGX 和 ARM TrustZone 提供了硬件级别的数据隔离。数据进入 TEE 的安全飞地（Enclave）后，即使操作系统和虚拟化层被攻破，飞地内的数据和计算仍然受到保护。TEE 的计算效率接近明文计算，但安全模型依赖于对硬件厂商的信任。


实际部署挑战
隐私计算技术从研究到生产部署面临多重工程和业务挑战。


通信效率是联邦学习的核心瓶颈。在移动设备场景中（如手机键盘预测），数百万设备需要周期性地与服务器交换模型参数。梯度压缩（Gradient Compression）、模型量化和异步更新是降低通信开销的主要技术。


**数据异质性（Non-IID）**是联邦学习中最棘手的统计挑战。不同参与方的数据分布可能差异巨大（如不同地区用户的消费习惯截然不同），导致局部模型的更新方向不一致，全局模型收敛困难。FedProx、SCAFFOLD 和 Per-FedAvg 等算法专门针对 Non-IID 数据设计。

小结
    

  • 联邦学习实现"数据不出域"的模型训练范式，分为横向、纵向和迁移联邦三种类型
    • 

  • FedAvg 是横向联邦的经典算法，通过本地训练 + 参数聚合避免原始数据共享
    • 

  • MPC（秘密分享）、HE（同态加密）和 TEE（可信执行环境）提供不同强度的隐私保证
    • 

  • 通信效率和数据异质性（Non-IID）是联邦学习生产部署的两大核心挑战
    • 

  • 梯度泄漏攻击表明仅共享梯度不能完全保护隐私，需要结合差分隐私或安全聚合
    • 

  • 隐私计算技术的安全性和计算效率之间存在根本性的权衡，需要根据场景选择合适的技术组合
