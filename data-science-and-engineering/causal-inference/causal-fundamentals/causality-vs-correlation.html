因果关系与相关关系

核心概念

"相关不等于因果"是数据科学中最重要却最容易被忽视的原则。相关关系描述两个变量的统计关联——当一个变量变化时另一个也倾向于变化；因果关系则要求一个变量的变化直接导致另一个变量的变化。在产品分析和业务决策中，混淆相关与因果会导致严重的决策错误：例如观察到"使用推荐功能的用户购买更多"并不意味着推荐功能提升了购买——可能只是购买意愿强的用户更倾向于使用推荐功能。

相关性的度量与局限
皮尔逊相关系数 r 衡量两个变量间的线性关联强度，范围为 [-1, 1]。但它有严重的局限性：只能捕捉线性关系、对离群值敏感、且完全无法区分因果方向。


import numpy as np
from scipy import stats

np.random.seed(42)
n = 1000

z = np.random.normal(0, 1, n)
x = z + np.random.normal(0, 0.5, n)
y = z + np.random.normal(0, 0.5, n)

r_xy, p_xy = stats.pearsonr(x, y)
r_xz, p_xz = stats.pearsonr(x, z)
r_yz, p_yz = stats.pearsonr(y, z)

print("Confounded correlation (X and Y share confounder Z):")
print(f"  r(X,Y) = {r_xy:.3f} (p = {p_xy:.2e})")
print(f"  r(X,Z) = {r_xz:.3f}")
print(f"  r(Y,Z) = {r_yz:.3f}")

from numpy.linalg import lstsq

X_design = np.column_stack([np.ones(n), z])
beta_x = lstsq(X_design, x, rcond=None)[0]
beta_y = lstsq(X_design, y, rcond=None)[0]
residual_x = x - X_design @ beta_x
residual_y = y - X_design @ beta_y
r_partial, _ = stats.pearsonr(residual_x, residual_y)
print(f"\nPartial correlation r(X,Y|Z) = {r_partial:.3f}")
print("After controlling for Z, X and Y are approximately uncorrelated.")
偏相关（Partial Correlation）通过控制第三个变量来消除混杂的影响。如果 X 和 Y 的相关性在控制 Z 后消失，说明它们的关联是由 Z 驱动的。但偏相关只能控制已观测到的混杂因素，无法处理未观测的混杂。


import numpy as np
from scipy import stats

np.random.seed(42)
n = 5000

x_nonlinear = np.random.uniform(-3, 3, n)
y_nonlinear = np.sin(x_nonlinear) + np.random.normal(0, 0.3, n)
r_linear, _ = stats.pearsonr(x_nonlinear, y_nonlinear)
r_spearman, _ = stats.spearmanr(x_nonlinear, y_nonlinear)

print("Non-linear relationship (Y = sin(X) + noise):")
print(f"  Pearson r = {r_linear:.3f}")
print(f"  Spearman ρ = {r_spearman:.3f}")
print("  Pearson misses the relationship, Spearman captures some monotonic trend.")

x_cause = np.random.normal(100, 10, n)
noise = np.random.normal(0, 5, n)
y_effect = 0.5 * x_cause + noise
r_causal, _ = stats.pearsonr(x_cause, y_effect)
r_reverse, _ = stats.pearsonr(y_effect, x_cause)
print(f"\nCausal direction ambiguity:")
print(f"  r(X→Y) = {r_causal:.3f}")
print(f"  r(Y→X) = {r_reverse:.3f}")
print("  Correlation is symmetric — cannot determine direction!")

混杂偏差的形式化分析
混杂偏差（Confounding Bias）是因果推断中最核心的挑战。当一个变量 Z 同时影响处理 X 和结果 Y 时，X 和 Y 之间的观察关联包含了 Z 的影响，朴素的比较会得到有偏的因果效应估计。


import numpy as np
from scipy import stats

def simulate_confounding(n=10000, confound_strength=2.0, true_effect=1.0):
    np.random.seed(42)

    z = np.random.normal(0, 1, n)

    prob_treatment = 1 / (1 + np.exp(-(confound_strength * z)))
    treatment = np.random.binomial(1, prob_treatment)

    y = true_effect * treatment + confound_strength * z + np.random.normal(0, 1, n)

    naive_effect = np.mean(y[treatment == 1]) - np.mean(y[treatment == 0])

    X_design = np.column_stack([np.ones(n), treatment, z])
    beta = np.linalg.lstsq(X_design, y, rcond=None)[0]
    adjusted_effect = beta[1]

    return {
        'true_effect': true_effect,
        'naive_effect': naive_effect,
        'adjusted_effect': adjusted_effect,
        'confound_bias': naive_effect - true_effect,
    }

result = simulate_confounding(confound_strength=2.0, true_effect=1.0)
print(f"True causal effect: {result['true_effect']:.2f}")
print(f"Naive estimate: {result['naive_effect']:.2f} (bias = {result['confound_bias']:+.2f})")
print(f"Adjusted estimate: {result['adjusted_effect']:.2f}")
混杂偏差的方向取决于混杂因素与处理和结果的关系方向。正向混杂（Z 正向影响 X 和 Y）导致高估因果效应，负向混杂导致低估。在实际问题中，混杂因素可能是多维的、非线性的，甚至是不可观测的。

因果推断的基本框架
因果推断有两大理论框架：Rubin 的潜在结果框架（Potential Outcomes）和 Pearl 的结构因果模型（SCM）。两者虽然出发点不同，但在许多问题上殊途同归。


Rubin 因果模型的核心概念是"因果效应 = 潜在结果的差异"。对于个体 i，潜在结果 Yi(1)Y_i(1)Yi​(1) 和 Yi(0)Y_i(0)Yi​(0) 分别表示接受和不接受处理的结果。因果效应为 τi=Yi(1)−Yi(0)\tau_i = Y_i(1) - Y_i(0)τi​=Yi​(1)−Yi​(0)。基本问题（Fundamental Problem of Causal Inference）是每个个体只能观察到一个潜在结果。


Pearl 因果模型使用有向无环图（DAG）表示变量间的因果关系，通过 do 算子 P(Y∣do(X=x))P(Y|do(X=x))P(Y∣do(X=x)) 定义因果效应。DAG 提供了系统的工具来判断哪些变量需要控制、哪些不能控制。

从相关到因果的路径
在实际数据分析中，从观察到的相关关系推断因果关系需要系统性的方法论。Hill 准则（Bradford Hill Criteria）提供了一组启发式标准来评估因果关系的可信度。


from dataclasses import dataclass

@dataclass
class HillCriteria:
    strength: float
    consistency: float
    specificity: float
    temporality: float
    biological_gradient: float
    plausibility: float
    coherence: float
    experiment: float
    analogy: float

    @property
    def overall_score(self):
        weights = {
            'temporality': 2.0,
            'experiment': 2.0,
            'strength': 1.5,
            'consistency': 1.5,
            'biological_gradient': 1.0,
            'plausibility': 1.0,
            'specificity': 0.5,
            'coherence': 0.5,
            'analogy': 0.5,
        }
        total = sum(getattr(self, k) * v for k, v in weights.items())
        max_total = sum(v for v in weights.values())
        return total / max_total

    @property
    def causal_assessment(self):
        score = self.overall_score
        if score > 0.8:
            return "Strong causal evidence"
        elif score > 0.6:
            return "Moderate causal evidence"
        elif score > 0.4:
            return "Weak causal evidence"
        return "Insufficient evidence"

assessment = HillCriteria(
    strength=0.7,
    consistency=0.8,
    specificity=0.5,
    temporality=1.0,
    biological_gradient=0.6,
    plausibility=0.8,
    coherence=0.7,
    experiment=0.9,
    analogy=0.5,
)
print(f"Overall score: {assessment.overall_score:.2f}")
print(f"Assessment: {assessment.causal_assessment}")
在互联网产品中，建立因果关系的黄金标准是随机对照实验（A/B 测试）。当无法做实验时，可以利用自然实验、断点回归、双重差分等准实验方法。关键是始终明确因果假设，并用多种方法交叉验证。

小结
    

  • 相关关系描述统计关联，因果关系要求一个变量的变化直接导致另一个变量变化，二者有本质区别
    • 

  • 混杂偏差是因果推断的核心挑战，当混杂因素同时影响处理和结果时，朴素比较会产生有偏估计
    • 

  • Rubin 潜在结果框架和 Pearl 因果图框架是因果推断的两大理论基础，各有优势
    • 

  • 偏相关和回归调整只能控制已观测的混杂因素，无法消除未观测混杂的影响
    • 

  • 从相关到因果需要系统的方法论评估（如 Hill 准则），随机实验是建立因果关系的黄金标准
    • 

  • 在无法做实验时，应利用准实验方法并明确因果假设，避免将观察到的相关直接解读为因果
    •
