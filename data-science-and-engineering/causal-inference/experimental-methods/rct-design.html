随机对照试验设计

核心概念

随机对照试验（Randomized Controlled Trial, RCT）是因果推断的金标准。其核心思想是通过随机化将受试者分配到处理组和对照组，使两组在所有可观测和不可观测的特征上在概率意义下相同，从而将结果差异归因于处理效应。在互联网行业中，RCT 最常见的形式是 A/B 测试——将用户随机分配到不同的产品版本中，通过统计检验比较版本间的指标差异。RCT 的力量在于它消除了所有混杂变量的影响，无需对数据生成过程做任何假设，是唯一能直接估计平均处理效应（ATE）的方法。

实验设计原则
一个严谨的 RCT 需要在设计阶段解决四个核心问题：样本量估计、随机化策略、实验持续时间和指标体系设计。


**样本量估计（Power Analysis）**是实验设计的第一步。统计功效（Power）定义为在效应真实存在时正确检测到它的概率，通常要求 ≥ 0.8。样本量取决于四个参数：显著性水平 α（通常 0.05）、统计功效 1-β（通常 0.8）、最小可检测效应（MDE）和指标的方差。


import numpy as np
from scipy import stats

def sample_size_two_proportion(p_control, mde, alpha=0.05, power=0.80):
    p_treatment = p_control + mde
    z_alpha = stats.norm.ppf(1 - alpha / 2)
    z_beta = stats.norm.ppf(power)

    p_bar = (p_control + p_treatment) / 2

    n = ((z_alpha * np.sqrt(2 * p_bar * (1 - p_bar)) +
          z_beta * np.sqrt(p_control * (1 - p_control) + p_treatment * (1 - p_treatment))) ** 2) / (mde ** 2)

    return int(np.ceil(n))

n = sample_size_two_proportion(p_control=0.10, mde=0.01)
print(f"Each group needs {n} samples")
print(f"Total: {2 * n} samples")
随机化策略选择需要根据实验场景确定。完全随机化最简单但可能产生不均衡的组，分层随机化按关键协变量（如新/老用户、平台、地区）分层后在每层内随机，能显著降低估计方差。在社交网络场景中，用户之间的干预会产生溢出效应（SUTVA 违背），需要使用集群随机化——以社交群组或地理区域为单位进行随机分配。


实验持续时间需要平衡统计功效和业务成本。过短的实验可能无法积累足够样本，且容易受到新奇效应（Novelty Effect）影响；过长的实验则浪费机会成本，且面临外部事件干扰的风险。实践中通常要求实验至少覆盖一个完整的业务周期（如电商的周末效应需要 ≥ 2 周）。


实验威胁与偏差控制
即使是设计良好的 RCT 也面临多种威胁，识别和控制这些偏差是实验成功的关键。


**选择偏差（Selection Bias）**在 A/B 测试中可能由于不完善的随机化引起。例如，如果随机分配依赖于用户 ID 的奇偶性，而用户 ID 的分配本身与注册时间相关，则新老用户在两组中的比例可能不均衡。最佳实践是使用密码学哈希函数（如 MD5/SHA256）对用户标识进行哈希后取模分配。


**溢出效应（Spillover/Interference）**是互联网实验中最棘手的问题。在社交网络中，如果处理组用户的行为影响了对照组用户（如推荐新功能的分享链接被对照组用户看到），则实验结果会被污染。解决方案包括：集群随机化、隔离实验（Geographic A/B）和双重随机化设计。


多重检验问题在大型实验平台中普遍存在。当同时检验多个指标时，假阳性率会随检验次数线性增长。如果检验 20 个指标，在 α=0.05 下至少出现一个假阳性的概率为 1-(1-0.05)^20 ≈ 64%。修正方法包括 Bonferroni 校正（保守）、Benjamini-Hochberg FDR 控制（推荐）和预注册主要指标。


from scipy import stats
import numpy as np

def benjamini_hochberg(p_values, alpha=0.05):
    n = len(p_values)
    sorted_indices = np.argsort(p_values)
    sorted_p = p_values[sorted_indices]

    thresholds = np.arange(1, n + 1) / n * alpha
    rejections = sorted_p <= thresholds

    if np.any(rejections):
        max_reject_idx = np.max(np.where(rejections))
        significant = np.zeros(n, dtype=bool)
        significant[sorted_indices[:max_reject_idx + 1]] = True
        return significant
    return np.zeros(n, dtype=bool)

p_values = np.array([0.001, 0.013, 0.029, 0.04, 0.06, 0.15, 0.23, 0.38])
significant = benjamini_hochberg(p_values, alpha=0.05)
for i, (p, sig) in enumerate(zip(p_values, significant)):
    print(f"Metric {i+1}: p={p:.3f}, significant={sig}")

高级实验设计
互联网场景催生了多种超越经典 RCT 的高级实验设计方法。


**CUPED（Controlled-experiment Using Pre-Experiment Data）**通过利用实验前的数据来降低估计方差，在不增加样本量的情况下提高实验的检测灵敏度。CUPED 的核心思想是：如果我们知道实验前用户的某个指标（如上周的购买次数），可以用它作为控制变量来"扣除"非处理因素导致的指标波动。在实践中 CUPED 通常能将方差降低 30-50%，等价于将所需样本量减半。


**多臂老虎机（Multi-Armed Bandit, MAB）**是自适应实验设计的代表。传统 A/B 测试在实验期间保持固定的流量分配比例，MAB 则根据已积累的数据动态调整流量，将更多流量分配给表现更好的变体。Thompson Sampling 和 UCB（Upper Confidence Bound）是两种主流的 MAB 算法。MAB 在探索-利用权衡上优于经典 A/B 测试，但统计推断更复杂且在非平稳环境下可能失效。


**交错实验（Interleaving）**特别适用于搜索和推荐系统的效果评估。在搜索结果中，交错实验将两个算法的结果混合展示给同一用户，通过用户对不同来源结果的点击偏好来评估算法优劣。相比经典 A/B 测试，交错实验的灵敏度高出一个数量级（所需样本量可降低 10-100 倍），原因在于它消除了用户间差异这一主要方差来源。


小结
    

  • 随机对照试验（RCT）是因果推断的金标准，通过随机化消除所有混杂变量的影响
    • 

  • 实验设计的四大核心要素：样本量估计（Power Analysis）、随机化策略、实验持续时间和指标体系
    • 

  • 选择偏差、溢出效应和多重检验是 A/B 测试面临的主要威胁，需要在设计阶段预防
    • 

  • CUPED 通过利用实验前数据降低方差，可在不增加样本量的情况下将检测灵敏度提升 30-50%
    • 

  • 多臂老虎机和交错实验是经典 RCT 的高级扩展，分别适用于快速优化和搜索推荐评估场景
    • 

  • 实验文化的核心是"数据驱动决策"——每一个产品变更都应该通过实验验证其因果效应
