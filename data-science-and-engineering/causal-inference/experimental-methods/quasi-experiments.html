准实验方法

核心概念

准实验（Quasi-Experiment）是指在无法实现完全随机分配时，通过巧妙的研究设计来逼近因果推断的方法。与 RCT 不同，准实验中的处理分配不是随机的，而是由某种自然过程或政策规则决定。准实验的核心挑战在于：如何在缺少随机化保证的情况下，构建合理的反事实（Counterfactual）来估计因果效应。互联网行业中，当 A/B 测试不可行（如平台级策略变更、政策合规要求、伦理约束）时，准实验方法就成为因果推断的主要工具。

断点回归设计
断点回归（Regression Discontinuity Design, RDD）利用处理分配规则中的断点来估计局部因果效应，是准实验方法中内部效度最高的设计。


Sharp RDD适用于处理分配完全由一个可观测的运行变量（Running Variable）在某个阈值处决定的情况。例如，当电商平台规定"信用分 ≥ 650 的商家获得流量加权"时，650 分就是断点。在断点附近，信用分为 649 的商家和 651 的商家在其他特征上几乎相同，唯一的差异在于是否获得了流量加权。通过比较断点两侧商家的销售额差异，就可以估计流量加权的因果效应。


import numpy as np
from sklearn.linear_model import LinearRegression

np.random.seed(42)
n = 2000
score = np.random.uniform(500, 800, n)
treatment = (score >= 650).astype(int)
noise = np.random.normal(0, 10, n)
y = 50 + 0.1 * score + 15 * treatment + noise

bandwidth = 30
mask = (score >= 650 - bandwidth) & (score <= 650 + bandwidth)
score_local = score[mask]
treatment_local = treatment[mask]
y_local = y[mask]

X = np.column_stack([score_local - 650, treatment_local, (score_local - 650) * treatment_local])
model = LinearRegression().fit(X, y_local)
ate_rdd = model.coef_[1]
print(f"RDD estimated treatment effect: {ate_rdd:.2f}")
print(f"True treatment effect: 15.00")
Fuzzy RDD处理断点不完全决定处理分配的情况——阈值以上的个体大多数但不是全部接受处理，阈值以下的个体大多数但不是全部不接受处理。Fuzzy RDD 等价于以断点作为工具变量的两阶段最小二乘估计（2SLS），估计的是断点处的局部平均处理效应（LATE）。


带宽选择是 RDD 的关键技术问题。带宽过窄导致可用样本量不足、估计方差大；带宽过宽则引入远离断点的样本、产生偏差。最优带宽的选择需要在偏差和方差之间取得平衡，常用的方法包括 Imbens-Kalyanaraman（IK）最优带宽和交叉验证（CV）方法。


间断时间序列分析
间断时间序列（Interrupted Time Series, ITS）通过分析干预前后时间序列的水平和趋势变化来估计因果效应，适用于只有一个群体、没有对照组的单组准实验。


基本 ITS 模型将时间序列分为干预前和干预后两段，通过回归模型估计干预导致的水平变化（Level Change）和趋势变化（Slope Change）。


import numpy as np
from sklearn.linear_model import LinearRegression

n_pre = 24
n_post = 12
time = np.arange(1, n_pre + n_post + 1)
intervention = (time > n_pre).astype(int)
time_after = np.maximum(time - n_pre, 0)

np.random.seed(42)
y = (100 + 2 * time +
     15 * intervention +
     3 * time_after +
     np.random.normal(0, 5, len(time)))

X = np.column_stack([time, intervention, time_after])
model = LinearRegression().fit(X, y)

print(f"Pre-intervention trend: {model.coef_[0]:.2f} per period")
print(f"Level change at intervention: {model.coef_[1]:.2f}")
print(f"Trend change after intervention: {model.coef_[2]:.2f}")
ITS 的有效性检验需要排除同期混杂事件的影响。如果在干预发生的同时有其他影响结果的事件发生（如新功能上线同时遇到行业大促），则无法将结果变化归因于干预。常用的检验方法包括：添加非等价对照组（CITS）、检验预干预趋势的稳定性、以及使用安慰剂检验（在非干预时点或非干预群体上重复分析）。


自回归模型扩展解决时间序列数据中的自相关问题。基本 ITS 的 OLS 估计在存在自相关时标准误会偏小，导致假阳性率升高。使用 ARIMA-ITS 或 Newey-West 稳健标准误可以修正这一问题。


合成控制法
合成控制法（Synthetic Control Method, SCM）通过将多个未受处理影响的对照单元加权组合来"合成"一个接近处理单元的虚拟对照组，适用于群组级（地区、平台、国家）干预的评估。


基本原理是寻找一组非负权重 w₁, w₂, ..., wₙ（∑wᵢ=1），使得对照单元的加权组合在干预前的指标趋势尽可能接近处理单元。如果合成对照在干预前能很好地拟合处理单元，则干预后两者的差异可以归因于干预效应。


SCM 的优势在于它提供了一个数据驱动的对照组构建方法，避免了研究者主观选择对照组的偏差。同时，SCM 通过可视化处理单元和合成对照单元的时间趋势图，使因果效应的大小和时间模式直观可见。


推断方法使用置换检验（Permutation Test）。将 SCM 逐一应用到每个对照单元上（假装每个对照单元是处理单元），计算每个对照单元的"安慰剂效应"。如果真正处理单元的效应远大于所有安慰剂效应，则说明处理效应是统计显著的。

小结
    

  • 准实验方法在无法进行随机实验时提供了逼近因果推断的研究设计
    • 

  • 断点回归（RDD）利用分配规则的断点估计局部因果效应，在准实验中内部效度最高
    • 

  • 间断时间序列（ITS）分析干预前后的水平和趋势变化，适用于单组无对照的政策评估
    • 

  • 合成控制法（SCM）通过加权组合构造虚拟对照组，适用于地区级或平台级干预的评估
    • 

  • 准实验的核心挑战在于不可检验的假设（如 RDD 的连续性、ITS 的无同期混杂），需要通过敏感性分析评估结果的稳健性
    • 

  • 方法选择应根据数据结构和可用性灵活决定，多方法交叉验证可增强结论的可信度
    •
