策略评估与反事实推理

核心概念

策略评估（Policy Evaluation）和反事实推理（Counterfactual Reasoning）是因果推断从"理解世界"走向"改变世界"的关键环节。策略评估回答的是"如果我们执行策略 π 而非策略 π'，结果会怎样？"这类问题。在互联网和电商业务中，策略评估的应用无处不在：评估一个新的定价策略的预期收入、预测一个推荐算法上线后的用户留存变化、或估计一项合规政策调整的商业影响。反事实推理则更进一步——它不仅评估尚未执行的策略，还解释已经发生的事件："如果当时采取了不同的行动，结果会有何不同？"

离线策略评估
离线策略评估（Off-Policy Evaluation, OPE）使用历史数据（由旧策略生成）来评估新策略的性能，是在不进行实际 A/B 测试的情况下做出上线决策的关键技术。


**直接方法（Direct Method, DM）**使用历史数据训练一个奖励预测模型 μ̂(x, a)，然后用新策略选择的动作来预测期望奖励。DM 的优势是方差低，劣势是完全依赖奖励模型的准确性——如果模型在新策略选择的动作分布上预测不准，DM 估计会有系统偏差。


**逆概率加权（Inverse Propensity Scoring, IPS）**利用重要性权重对历史数据重新赋权，使其分布匹配新策略的动作分布。


import numpy as np

np.random.seed(42)
n = 10000
n_actions = 5

contexts = np.random.normal(0, 1, (n, 3))

old_policy_probs = np.random.dirichlet(np.ones(n_actions), n)
actions = np.array([np.random.choice(n_actions, p=p) for p in old_policy_probs])

true_rewards = np.sin(contexts[:, 0]) + 0.5 * contexts[:, 1]
action_effects = np.array([0, 0.5, -0.3, 0.8, -0.1])
rewards = true_rewards + action_effects[actions] + np.random.normal(0, 0.5, n)

new_policy_action = 3

new_policy_probs = np.zeros_like(old_policy_probs)
for i in range(n):
    best_action = np.argmax([action_effects[a] + 0.1 * contexts[i, 0] for a in range(n_actions)])
    new_policy_probs[i, best_action] = 0.8
    new_policy_probs[i] += 0.2 / n_actions

importance_weights = np.array([
    new_policy_probs[i, actions[i]] / old_policy_probs[i, actions[i]]
    for i in range(n)
])

ips_estimate = np.mean(importance_weights * rewards)
print(f"IPS estimate of new policy value: {ips_estimate:.4f}")

clipped_weights = np.clip(importance_weights, 0, 10)
snips_estimate = np.sum(clipped_weights * rewards) / np.sum(clipped_weights)
print(f"SNIPS estimate (clipped): {snips_estimate:.4f}")
**双重稳健策略评估（DR-OPE）**结合了 DM 和 IPS 的优点。DR 估计量 = DM 估计 + IPS 修正项。当奖励模型或倾向模型中至少一个正确时，DR 估计量是一致的。

最优策略学习
从策略评估到策略优化，目标从"评估给定策略的效果"转变为"找到效果最好的策略"。


基于 CATE 的贪心策略是最直接的方法。使用因果机器学习估计每个用户在每个干预下的条件处理效应 τₐ(x)，然后为每个用户选择效应最大的干预 π*(x) = argmax_a τₐ(x)。在预算约束下，按 τₐ(x) 从高到低排序，优先干预 Uplift 最高的用户直到预算用尽。


约束优化策略在实际业务中更为实用。电商运营中的策略优化通常面临多重约束：总预算限制、每日发券量限制、品类均衡要求、最低利润率约束等。这类问题可以形式化为约束优化问题，使用线性规划或整数规划求解。


**因果强化学习（Causal RL）**处理序列决策场景中的策略优化。在用户交互过程中，当前的干预不仅影响即时结果，还影响用户的长期状态（如偏好变化、信任建立或疲劳效应）。因果强化学习将因果图的结构知识融入 MDP 建模，帮助识别状态转移中的因果关系，避免基于虚假相关的策略。


反事实推理与解释
反事实推理位于 Pearl 因果阶梯的最高层（第三层），处理的是关于特定个体在特定情境下的"如果当时不同"的假设性问题。


**结构因果模型（SCM）**是反事实推理的数学基础。SCM 由一组结构方程 Xᵢ = fᵢ(PAᵢ, Uᵢ) 定义，其中 PAᵢ 是 Xᵢ 的因变量（父节点），Uᵢ 是外生噪声。反事实推理通过三步完成：(1) 溯因（Abduction）——根据观测数据推断噪声 U 的值；(2) 干预（Action）——在 SCM 中施加假设性干预；(3) 预测（Prediction）——在干预后的 SCM 中推导反事实结果。


反事实解释在业务中的应用为决策提供可操作的因果解释。例如："如果该商品的价格降低 10%，该用户的购买概率会从 30% 提升到 45%"——这种反事实陈述直接指向了可执行的业务动作（降价 10%）和预期效果（+15pp 转化率）。


What-If 分析是反事实推理的业务化形式。通过构建因果仿真器（Causal Simulator），业务人员可以交互式地探索不同策略组合的预期效果："如果我们在东南亚市场将佣金率从 3% 降至 1%，同时将广告预算增加 20%，GMV 和利润率会如何变化？"因果仿真器基于历史数据训练的因果模型，为这类复杂的多变量假设提供量化预测。


小结
    

  • 策略评估使用历史数据评估新策略性能，是安全上线决策的关键技术
    • 

  • 离线策略评估（OPE）的 DR 方法结合了直接法和 IPS 的优点，是实践中最推荐的方法
    • 

  • 最优策略学习在 CATE 估计基础上通过约束优化实现资源最优分配
    • 

  • 反事实推理位于 Pearl 因果阶梯第三层，处理个体级别的"如果当时不同"假设性问题
    • 

  • 结构因果模型通过溯因-干预-预测三步实现反事实推理的形式化
    • 

  • What-If 分析和因果仿真器是反事实推理在业务决策中最直接的应用形式
    •
