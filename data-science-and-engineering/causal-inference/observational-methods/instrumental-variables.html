工具变量法

核心概念

工具变量法（Instrumental Variables, IV）是解决内生性问题的核心因果推断方法。当处理变量 T 与未观测的混杂因素 U 相关时（即存在内生性），普通最小二乘估计（OLS）会产生偏差。工具变量法通过引入一个外生变量 Z（工具变量），它影响处理变量 T 但不直接影响结果变量 Y（仅通过 T 间接影响 Y），来识别 T 对 Y 的因果效应。工具变量法在计量经济学中有深厚的理论基础，是劳动经济学、教育经济学和产业组织领域最常用的因果识别策略，近年来在互联网产品分析中也得到了越来越多的应用。

两阶段最小二乘法
两阶段最小二乘法（Two-Stage Least Squares, 2SLS）是工具变量估计的标准方法。


第一阶段将处理变量 T 回归到工具变量 Z 和其他控制变量 X 上，得到 T 的预测值 T̂。T̂ 只包含由 Z 引起的外生变异，消除了 T 与 U 的内生关联。


第二阶段将结果变量 Y 回归到第一阶段的预测值 T̂ 和控制变量 X 上。T̂ 的系数就是因果效应的 IV 估计量。


import numpy as np
from sklearn.linear_model import LinearRegression

np.random.seed(42)
n = 5000

unobserved_ability = np.random.normal(0, 1, n)

distance_to_school = np.random.exponential(10, n)
education_years = (16 - 0.3 * distance_to_school +
                   2 * unobserved_ability +
                   np.random.normal(0, 2, n))
education_years = np.clip(education_years, 6, 22)

wage = (20000 + 3000 * education_years +
        5000 * unobserved_ability +
        np.random.normal(0, 5000, n))

ols = LinearRegression().fit(education_years.reshape(-1, 1), wage)
print(f"OLS estimate (biased): {ols.coef_[0]:.0f} per year")

first_stage = LinearRegression().fit(distance_to_school.reshape(-1, 1), education_years)
f_stat_approx = (first_stage.score(distance_to_school.reshape(-1, 1), education_years) /
                 (1 - first_stage.score(distance_to_school.reshape(-1, 1), education_years))) * (n - 2)
print(f"First stage F-statistic: {f_stat_approx:.1f}")

edu_hat = first_stage.predict(distance_to_school.reshape(-1, 1))
second_stage = LinearRegression().fit(edu_hat.reshape(-1, 1), wage)
print(f"2SLS IV estimate: {second_stage.coef_[0]:.0f} per year")
print(f"True causal effect: 3000 per year")
IV 估计的解读需要注意：在存在异质性处理效应时，2SLS 估计的是局部平均处理效应（LATE）——即那些因工具变量的变化而改变处理状态的"遵从者"（Compliers）子群体的平均效应。LATE 不等于总体的平均处理效应（ATE），外推时需要谨慎。


弱工具变量问题
弱工具变量（Weak Instruments）是 IV 估计中最严重的威胁之一。当工具变量与处理变量的关联较弱时，即使样本量很大，IV 估计也会产生严重偏差且推断失效。


诊断标准方面，Stock 和 Yogo (2005) 提出的经验法则是第一阶段 F 统计量 > 10。当 F < 10 时，IV 估计的偏差可能接近 OLS 估计的偏差，失去了使用 IV 的意义。更严格的标准使用 Effective F 统计量和 Anderson-Rubin (AR) 检验。


弱 IV 的修正方法包括：(1) 寻找更强的工具变量；(2) 使用有限信息最大似然法（LIML）替代 2SLS，LIML 在弱 IV 下的偏差更小；(3) 使用 Anderson-Rubin 置信集，它在弱 IV 下仍然有效，但置信区间可能很宽。


互联网领域的工具变量应用
互联网产品分析中，工具变量法的应用场景正在快速扩展。


推送通知作为工具变量是评估用户参与度对转化影响的经典策略。如果我们想估计"用户查看推荐内容"对"购买行为"的因果效应，直接比较会面临选择偏差（更有购买意愿的用户更可能主动查看推荐）。将"是否收到推送通知"作为工具变量：推送通知影响用户查看推荐的概率（相关性），但推送本身不直接导致购买（排他性——通过查看推荐间接影响）。


广告曝光的外生变异在评估广告效果时提供了天然的工具变量。广告竞价系统中的随机性（如同一用户在不同时刻面临的竞价价格差异导致的广告展示差异）可以作为工具变量，来识别广告曝光对购买的因果效应。


系统延迟作为工具变量可以用来估计页面加载速度对用户行为的因果效应。用户端设备性能和网络质量造成的页面加载时间差异具有随机性，可以作为加载速度的工具变量。

小结
    

  • 工具变量法通过引入外生变量解决处理变量的内生性问题，是观测数据因果推断的重要工具
    • 

  • 有效 IV 需满足相关性、外生性和排他性三个条件，其中后两者不可直接检验
    • 

  • 两阶段最小二乘法（2SLS）是标准的 IV 估计方法，第一阶段 F > 10 是有效性的基本要求
    • 

  • IV 估计的是局部平均处理效应（LATE），仅适用于"遵从者"子群体，外推需谨慎
    • 

  • 弱工具变量会导致严重偏差，可通过 LIML 和 Anderson-Rubin 检验进行修正
    • 

  • 互联网领域中推送通知、广告竞价随机性和系统延迟为 IV 分析提供了丰富的应用场景
    •
