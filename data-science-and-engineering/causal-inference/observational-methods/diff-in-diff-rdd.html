双重差分与断点回归

核心概念

双重差分法（Difference-in-Differences, DID）和断点回归设计（Regression Discontinuity Design, RDD）是观测性因果推断中两种最经典、最广泛使用的方法。两者的共同点在于利用数据中天然存在的"准实验"结构来识别因果效应，但识别策略完全不同。DID 利用的是处理组和对照组在时间维度上的差异变化，通过"差分之差"消除组间固有差异和共同时间趋势。RDD 利用的是处理分配规则中的断点，通过比较断点两侧极为相似的个体来估计因果效应。在互联网和电商领域，DID 和 RDD 是评估产品策略、政策变更和平台规则调整效果的主力方法。

双重差分法详解
双重差分法的核心直觉是：将处理组在干预前后的变化减去对照组在同期的变化，两次差分分别消除了组间固有差异和共同时间趋势，剩余的就是处理效应。


经典 2×2 DID 框架考虑两组（处理/对照）×两期（前/后）的设定。DID 估计量 = (处理组后 - 处理组前) - (对照组后 - 对照组前)。


import numpy as np
from sklearn.linear_model import LinearRegression

np.random.seed(42)
n_per_group = 1000
n = 4 * n_per_group

treated = np.concatenate([np.ones(2 * n_per_group), np.zeros(2 * n_per_group)])
post = np.tile(np.concatenate([np.ones(n_per_group), np.zeros(n_per_group)]), 2)
interaction = treated * post

baseline_treated = 50
baseline_control = 40
time_trend = 5
treatment_effect = 10

y = (baseline_control +
     (baseline_treated - baseline_control) * treated +
     time_trend * post +
     treatment_effect * interaction +
     np.random.normal(0, 8, n))

X = np.column_stack([treated, post, interaction])
model = LinearRegression().fit(X, y)

print(f"Group difference (treated - control): {model.coef_[0]:.2f}")
print(f"Time trend (post - pre): {model.coef_[1]:.2f}")
print(f"DID estimate (treatment effect): {model.coef_[2]:.2f}")
print(f"True treatment effect: {treatment_effect}")
平行趋势假设是 DID 的核心假设——在没有处理的情况下，处理组和对照组的结果变量会遵循相同的时间趋势。这个假设不可直接检验（因为无法观测处理组在未处理下的反事实趋势），但可以通过检验干预前两组的趋势是否平行来间接评估。


**事件研究法（Event Study）**是检验平行趋势假设和刻画动态处理效应的标准工具。通过在回归中加入干预前各期的处理组虚拟变量，检验干预前系数是否显著为零（平行趋势检验）以及干预后系数的动态变化模式。


交错 DID 与最新进展
当处理在不同时间点对不同群体逐步推广时（Staggered Adoption），经典的双向固定效应 DID 估计量会产生严重偏差。


双向固定效应（TWFE）的问题被 Goodman-Bacon (2021) 和 de Chaisemartin & D'Haultfœuille (2020) 等研究揭示。TWFE 的 DID 估计量实际上是多个 2×2 DID 的加权平均，其中一些"有害的"比较使用先采纳组的采纳后数据作为对照，当处理效应随时间变化时会产生负权重，导致估计量甚至可能与真实效应符号相反。


新一代 DID 估计量解决了交错 DID 的偏差问题。Callaway & Sant'Anna (2021) 的方法按组别-时间对分别估计处理效应，再聚合为总体效应；Sun & Abraham (2021) 的交互加权估计量限制了比较的范围；Borusyak et al. (2024) 的插补方法使用尚未处理的观测来估计反事实。

RDD 的实践应用
断点回归在电商和互联网领域有丰富的应用场景，只要存在基于某个分数/指标的阈值决策规则，就可以考虑使用 RDD。


搜索排序的断点在电商平台中天然存在。当搜索结果分页展示时，第一页末尾（如第 20 位）和第二页开头（如第 21 位）之间存在曝光量的断点——排名 20 的商品获得的曝光量远高于排名 21 的商品。利用这个断点可以估计曝光量/排名对点击率和成交率的因果效应。


会员等级的阈值提供了评估会员权益效果的 RDD 机会。当用户消费金额达到某个阈值后升级为 VIP 并获得额外优惠时，可以比较阈值两侧用户的后续购买行为来估计 VIP 权益的因果效应。


RDD 的有效性检验包括三个标准检验：(1) 运行变量的密度检验（McCrary 检验）——如果断点附近存在密度跳跃，说明存在操纵，RDD 无效；(2) 预处理协变量在断点处的连续性检验——如果其他特征在断点处不连续，说明两侧个体不可比；(3) 带宽敏感性检验——估计结果应在不同带宽选择下保持稳健。


小结
    

  • DID 通过"差分之差"消除组间固有差异和共同时间趋势，核心假设是平行趋势
    • 

  • 事件研究法是检验平行趋势假设和刻画动态效应的标准工具
    • 

  • 交错 DID 中经典 TWFE 估计量存在严重偏差，新一代估计量（Callaway-Sant'Anna 等）正确处理异质效应
    • 

  • RDD 利用处理分配的阈值断点估计局部因果效应，在准实验方法中内部效度最高
    • 

  • 电商领域的搜索排名断点、会员等级阈值和商家信用分数为 RDD 提供了丰富的应用场景
    • 

  • McCrary 密度检验、协变量连续性检验和带宽敏感性检验是 RDD 有效性评估的三大支柱
