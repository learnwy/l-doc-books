匹配方法

核心概念

匹配方法（Matching Methods）是观测性因果推断中最直觉的方法族：对于每个接受处理的个体，从未处理个体中找到在协变量上最"相似"的一个或多个个体作为对照，通过比较匹配对之间的结果差异来估计因果效应。匹配方法的核心假设是条件独立性假设（Conditional Independence Assumption, CIA）——在控制了所有可观测的混杂变量后，处理分配与潜在结果独立。换言之，匹配方法假设"没有未观测的混杂因素"。这是一个不可检验但可以通过领域知识来论证其合理性的假设。

倾向得分匹配
倾向得分匹配（Propensity Score Matching, PSM）是观测性因果推断中最广泛使用的匹配方法。倾向得分 e(X) = P(T=1|X) 是给定协变量 X 时个体接受处理的概率。Rosenbaum 和 Rubin (1983) 证明了一个关键定理：如果条件独立性假设在给定 X 时成立，则在给定 e(X) 时也成立。这意味着匹配可以从高维协变量空间降低到一维倾向得分空间。


import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import NearestNeighbors

np.random.seed(42)
n = 2000

age = np.random.normal(35, 10, n)
income = np.random.normal(50000, 15000, n)
education = np.random.choice([0, 1, 2], n, p=[0.3, 0.5, 0.2])

logit = -3 + 0.05 * age + 0.00003 * income + 0.5 * education
prob = 1 / (1 + np.exp(-logit))
treatment = np.random.binomial(1, prob)

y0 = 100 + 0.5 * age + 0.001 * income + 10 * education + np.random.normal(0, 10, n)
treatment_effect = 15
y = y0 + treatment_effect * treatment

X = np.column_stack([age, income, education])
ps_model = LogisticRegression(max_iter=1000).fit(X, treatment)
ps = ps_model.predict_proba(X)[:, 1]

treated_idx = np.where(treatment == 1)[0]
control_idx = np.where(treatment == 0)[0]

nn = NearestNeighbors(n_neighbors=1, metric='euclidean')
nn.fit(ps[control_idx].reshape(-1, 1))
distances, indices = nn.kneighbors(ps[treated_idx].reshape(-1, 1))

matched_control_idx = control_idx[indices.flatten()]
att = np.mean(y[treated_idx] - y[matched_control_idx])
print(f"PSM estimated ATT: {att:.2f}")
print(f"True treatment effect: {treatment_effect}")
倾向得分估计的质量检验是 PSM 的关键步骤。匹配后需要检验协变量在处理组和对照组之间是否达到了平衡。标准化均值差异（SMD）< 0.1 是常用的经验阈值。如果匹配后某些协变量仍然不平衡，需要调整倾向得分模型（添加交互项、非线性项）或使用更灵活的匹配方法。


**共同支撑（Common Support/Overlap）**要求处理组和对照组的倾向得分分布有充分的重叠。如果某些处理组个体的倾向得分非常高（接近 1），则在对照组中找不到合适的匹配对象，导致外推偏差。实践中通常使用 Caliper 匹配（限制匹配距离上限）或裁剪极端倾向得分来确保共同支撑。


逆概率加权
逆概率加权（Inverse Probability Weighting, IPW）是倾向得分的另一种使用方式。IPW 不进行匹配，而是通过倾向得分对每个观测赋予权重来消除混杂偏差。


weights_treated = 1 / ps[treated_idx]
weights_control = 1 / (1 - ps[control_idx])

ate_ipw = (np.sum(y[treated_idx] * weights_treated) / np.sum(weights_treated) -
           np.sum(y[control_idx] * weights_control) / np.sum(weights_control))
print(f"IPW estimated ATE: {ate_ipw:.2f}")
IPW 的优势在于它估计的是平均处理效应（ATE）而非处理组的平均处理效应（ATT），且不会因匹配丢弃未匹配的观测值。IPW 的劣势在于当倾向得分接近 0 或 1 时，权重可能非常大，导致估计方差极大（极端权重问题）。稳定化权重（Stabilized Weights）和权重截断（Weight Truncation）是两种常用的修正方法。


**双重稳健估计（Doubly Robust, DR）**结合了 IPW 和结果回归模型的优点。DR 估计量在倾向得分模型或结果模型二者中至少一个正确时仍然是一致的，提供了额外的"保险"。

匹配质量评估与诊断
匹配方法的可靠性严重依赖于匹配质量的评估和诊断。


协变量平衡检验是匹配后最重要的诊断步骤。对每个协变量分别计算匹配前后的标准化均值差异（SMD），以及方差比。SMD < 0.1 且方差比在 [0.5, 2] 之间通常被认为是可接受的平衡。如果使用 IPW，则计算加权后的 SMD。


密度图对比直观展示匹配前后处理组和对照组在每个协变量上的分布差异。匹配后两组的分布应高度重叠。特别需要关注分布的尾部——即使均值差异很小，尾部的差异仍可能导致估计偏差。


敏感性分析评估结论对未观测混杂因素的稳健性。由于条件独立性假设不可检验，需要通过 Rosenbaum Sensitivity Analysis 来回答：需要多强的未观测混杂才能推翻当前的因果结论？如果结论在较大的敏感性参数范围内仍然成立，则增强了结论的可信度。


小结
    

  • 匹配方法通过在协变量上构造可比对照组来估计因果效应，核心假设是条件独立性
    • 

  • 倾向得分匹配将高维协变量空间降维到一维得分空间，是最广泛使用的匹配方法
    • 

  • 逆概率加权（IPW）通过倾向得分赋权来消除混杂，估计 ATE 但可能面临极端权重问题
    • 

  • 双重稳健估计结合了倾向得分和结果模型，在二者至少一个正确时仍然一致
    • 

  • 匹配后的协变量平衡检验（SMD < 0.1）是验证匹配质量的必要步骤
    • 

  • 条件独立性假设不可检验，需要通过敏感性分析评估结论对未观测混杂的稳健性
