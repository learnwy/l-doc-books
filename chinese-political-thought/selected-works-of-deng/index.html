邓小平文选 简介

《邓小平文选》是邓小平不同历史时期重要著作、讲话和谈话的权威汇编，共三卷。本知识库不是邓小平理论的"专题论述"，而是以原著文本为中心的逐卷导读——它的定位是带读者回到第一手文献，理解每一篇文章"写于何时、针对何事、提出了什么、为何重要"，而把成体系的专题展开交给同一 hub 群里的其它专题 hub。

本 hub 与兄弟 hub 的分工边界

邓小平理论 hub 群（leaders/02_deng-xiaoping-theory/）按"文本 / 总览 / 专题"三层组织。本 hub 处在"文本"层，是其它所有专题 hub 的史料底座。

Hub 切入角度 适合什么时候读
本 hub·邓小平文选 原著文本，逐卷逐篇 想读原文、追踪文献出处与历史语境时
邓小平思想总览 人物 + 概念地图 第一次接触，需要全局框架时
改革开放 政策史专题 想了解农村改革、特区、对外开放的来龙去脉
中国特色社会主义 理论命题专题 钻研本质论、初级阶段理论
南方谈话 单一事件专题 深挖 1992 年南巡的背景与影响
一国两制 统一方针专题 研究港澳台框架
社会主义市场经济理论 经济体制专题 研究计划/市场之争与体制建构
邓小平方法论 思维方法专题 提炼实事求是、摸石头过河等方法论
邓小平外交 对外战略专题 研究韬光养晦、中美/中日关系
邓小平的历史遗产 评价与比较 做历史定位、人物比较

一句话区分：专题 hub 回答"是什么、为什么"，本 hub 回答"原文在哪、原话怎么说"。 遇到专题 hub 中引用的论断，可回本 hub 查证文本出处与上下文。

三卷结构

卷 时间跨度 历史定位
第一卷 1938-1965 思想方法的萌芽期：根据地建设、党的建设、社会主义建设初探
第二卷 1975-1982 改革开放的奠基期：拨乱反正、解放思想、中国特色社会主义命题提出
第三卷 1982-1992 理论的成熟期：一国两制、市场经济论、南巡讲话

每卷下设三篇：概述（时代脉络与结构）、重要篇目解读（精读代表文献）、核心主题分析（提炼贯穿主题）。

推荐学习路径（分人群）

  • 初学者 / 通识读者：先读 邓小平思想总览 建立框架，再回到本 hub 按"第二卷 → 第三卷 → 第一卷"顺序读三篇概述即可，暂不必深究单篇文献。先读第二卷是因为它是转折关键、最易切入。
  • 党史 / 政治理论学习者：按"概述 → 核心主题分析 → 重要篇目解读"的顺序逐卷推进，三卷读完后横向对读三篇核心主题分析，把握同一主题在三卷中的演进轨迹。
  • 研究者 / 需要引证原文者：以本 hub 的重要篇目解读为索引，定位到《解放思想，实事求是》《党和国家领导制度的改革》《一个国家，两种制度》、南巡讲话等关键文本，再回到原著精读，并交叉参阅对应专题 hub。

前置知识

  • 历史背景：对抗日战争、解放战争、"文化大革命"、十一届三中全会、苏东剧变等关键节点有基本了解，否则文献的语境难以把握。
  • 理论基础：理解马克思主义的基本范畴——尤其是 实践与认识、生产力与生产关系 与 马克思主义在中国，是读懂邓小平论述深层逻辑的钥匙。
  • 阅读方法：每读一篇，先还原写作的历史背景，再细读原文，最后提炼方法论启示——这是研读邓小平著作最有效的三步法。
