剩余价值生产

核心概念

剩余价值理论是马克思政治经济学的核心，是理解资本主义生产方式本质的钥匙。剩余价值是工人在生产过程中创造的超过劳动力价值的那部分价值，它被资本家无偿占有，构成利润、利息、地租等各种剥削收入的统一来源。

理解剩余价值的前提是理解劳动力的商品化。在资本主义社会中，工人丧失了生产资料，只能将自己的劳动力作为商品出卖给资本家。劳动力成为商品是资本主义生产关系的根本标志。资本家购买劳动力的目的不是消费劳动力的使用价值本身，而是利用劳动力在生产过程中创造出大于其自身价值的价值——这就是剩余价值。

劳动力的商品化
劳动力成为商品需要两个历史前提：第一，劳动者在法律上是自由的，能够自由出卖自己的劳动力；第二，劳动者丧失了一切生产资料，除了出卖劳动力外没有其他谋生手段。


劳动力商品与普通商品一样具有价值和使用价值。劳动力的价值由维持劳动力再生产所需要的生活资料的价值决定，包括三个部分：一是维持工人自身生存所需的生活资料价值（衣食住行）；二是维持工人家属（劳动力后备军的再生产）所需的生活资料价值；三是工人的教育培训费用。劳动力的价值还有一个历史的和道德的因素——不同国家、不同时期的工人生活水平存在差异。


劳动力的使用价值在于它能够进行劳动，而劳动创造价值。劳动力的使用价值具有一个特殊性质：它在使用过程中不仅能够再生产出自身的价值，还能创造出比自身价值更大的价值。这种"价值增殖"能力正是资本家购买劳动力的动机。


在当代互联网行业，劳动力的商品化表现为程序员将自己的编码能力出卖给科技公司。程序员的工资（劳动力价值）由维持其生存和再生产所需的费用决定——包括一线城市的住房、饮食、子女教育和持续学习新技术的成本。但程序员在工作中创造的价值（通过代码实现的产品和服务带来的收益）远超过其工资。


必要劳动与剩余劳动
工人的整个工作日可以分为两部分：必要劳动时间和剩余劳动时间。


必要劳动时间是工人为再生产自己的劳动力价值所需的劳动时间。在这段时间内，工人创造的价值等于他的工资。从资本家角度看，这是"成本回收"的时间。


剩余劳动时间是超出必要劳动时间的部分。在这段时间内，工人继续劳动，但创造的价值全部归资本家所有。这就是剩余价值的来源。


假设一个程序员的日工资对应 4 小时的社会必要劳动时间（即 4 小时的产出足以覆盖其工资成本），而他每天工作 8 小时。那么前 4 小时是必要劳动，创造的价值用于支付其工资；后 4 小时是剩余劳动，创造的剩余价值被公司占有。


关键在于：这种划分在表面上是看不到的。工人出卖的是一定时间的劳动力使用权，工资按天、按月支付。整个工作日的劳动看起来都是"有酬的"，剩余劳动的无偿性被掩盖在工资形式之下。

剩余价值的隐蔽性
剩余价值之所以长期未被古典经济学家识破，根本原因在于资本主义工资制度制造了一种"等价交换"的假象。


在封建社会中，农奴的必要劳动和剩余劳动在时间和空间上是分开的：农奴在自己地上劳动 3 天（必要劳动），在领主地上劳动 3 天（剩余劳动）。剥削关系是赤裸裸的、一目了然的。


但在资本主义社会中，工人的必要劳动和剩余劳动在同一个劳动过程中混合在一起。工人每天工作 8 小时获得一天的工资，表面看来工资是"全部劳动的报酬"。实际上，工资只是劳动力价值的支付，而不是劳动创造的全部价值的支付。


这种隐蔽性在知识经济时代更加突出。一个程序员可能认为自己年薪 50 万已经"很高"了，但他帮公司创造的价值可能是 500 万甚至更多。工资的绝对水平掩盖了剩余价值的相对规模。股权激励、期权等现代薪酬工具虽然让工人分享到了一小部分剩余价值，但并没有改变劳资关系的本质。


资本的构成与增殖过程
在资本主义生产过程中，资本家的预付资本分为两部分：不变资本和可变资本。


**不变资本（c）**是用来购买生产资料（机器、原材料、厂房等）的那部分资本。生产资料在生产过程中将自身的价值转移到新产品中，但不创造新价值。机器的价值通过磨损逐渐转移到产品中（折旧），原材料的价值一次性转移到产品中。不变资本的价值量在生产过程中没有发生变化，因此称为"不变"资本。


**可变资本（v）**是用来购买劳动力的那部分资本。劳动力在生产过程中不仅再生产出自身的价值（v），还创造出剩余价值（m）。因此可变资本的价值量在生产过程中发生了变化（增殖），故称为"可变"资本。


商品的价值构成可以表示为：W = c + v + m，其中 c 是转移的生产资料价值，v 是再生产的劳动力价值，m 是剩余价值。新创造的价值是 v + m，剩余价值率 m' = m/v。

在互联网公司中，不变资本包括服务器成本、云服务费用、办公场地租金、开发工具许可证等；可变资本是员工的工资总额。只有工人的活劳动才创造新价值，服务器和代码库只是将已有的价值转移到最终产品中。这也解释了为什么人力密集型的互联网公司往往有更高的剩余价值率——可变资本占比大，活劳动创造的剩余价值多。


小结
    

  • 剩余价值是工人创造的超过劳动力价值的那部分价值，是利润的本质来源
    • 

  • 劳动力商品化需要工人的人身自由和生产资料的丧失两个历史前提
    • 

  • 工作日分为必要劳动时间和剩余劳动时间，后者创造的价值被资本家无偿占有
    • 

  • 资本主义工资制度制造了"等价交换"的假象，掩盖了剩余劳动的无偿性
    • 

  • 不变资本转移旧价值，可变资本创造新价值，剩余价值只来源于可变资本
    • 

  • 商品价值 W = c + v + m，剩余价值率 m' = m/v 衡量资本对劳动的剥削程度
    • 

  • 知识经济时代的高薪并未改变剩余价值生产的基本逻辑
    •
