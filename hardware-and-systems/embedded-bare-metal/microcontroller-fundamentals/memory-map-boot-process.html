存储器映射与启动流程

统一地址空间

ARM Cortex-M 采用 32 位统一编址的存储器映射模型，将 4 GB 地址空间划分为固定用途的区域。无论芯片厂商如何集成 Flash 和外设，其物理地址必须落在 ARM 定义的区域范围内，确保软件的可移植性。

向量表中存储的是函数地址（最低位置 1 表示 Thumb 模式），而非指令本身。硬件在响应异常时直接从表中读取地址加载到 PC。


向量表重定位
通过 SCB 的 VTOR（Vector Table Offset Register）寄存器可以将向量表重定位到 SRAM 或其他 Flash 区域：


VTOR=新向量表基址（必须对齐到表大小的2的幂次边界）\text{VTOR} = \text{新向量表基址}（必须对齐到表大小的 2 的幂次边界）VTOR=新向量表基址（必须对齐到表大小的2的幂次边界）
重定位场景包括：


    

  • Bootloader 跳转到应用程序时切换向量表
    • 

  • 运行时动态修改中断处理函数（向量表放 SRAM）
    • 

  • 多固件分区场景下各分区独立的向量表
    •

系统存储器中固化了 ST 出厂写入的 Bootloader 程序，支持通过 UART、USB、I2C、SPI 等接口进行固件下载，无需额外调试器。


C 运行时初始化
从 Reset_Handler 到 main() 之间的启动代码（通常称为 startup 文件或 crt0）完成以下初始化：


    

  1. 初始化 .data 段：将已初始化全局变量从 Flash（LMA）复制到 SRAM（VMA）
    2. 

  2. 清零 .bss 段：将未初始化全局变量区域填充为 0
    3. 

  3. 初始化堆栈：设置堆（heap）和栈（stack）的边界
    4. 

  4. 调用 SystemInit()：配置时钟系统（可选，CMSIS 标准接口）
    5. 

  5. 调用 __libc_init_array()：执行 C++ 全局构造函数（若使用 C++）
    6. 

  6. 跳转 main()：进入用户应用代码
    7. 



链接脚本
段与区域定义
链接脚本（.ld 文件）定义了代码和数据在存储器中的布局：


MEMORY {
    FLASH (rx)  : ORIGIN = 0x08000000, LENGTH = 512K
    SRAM  (rwx) : ORIGIN = 0x20000000, LENGTH = 128K
}

SECTIONS {
    .isr_vector : { *(.isr_vector) } > FLASH
    .text       : { *(.text*) } > FLASH
    .rodata     : { *(.rodata*) } > FLASH
    .data       : { *(.data*) } > SRAM AT> FLASH
    .bss        : { *(.bss*) } > SRAM
}
关键概念：


    

  • VMA（Virtual Memory Address）：运行时地址，程序访问时使用
    • 

  • LMA（Load Memory Address）：加载地址，固件烧写时的物理位置
    • 

  • .data 段的 VMA 在 SRAM 但 LMA 在 Flash，启动代码负责将内容从 LMA 复制到 VMA
    • 



栈与堆布局
典型的嵌入式栈堆布局采用"栈顶堆底"模型：


SRAM 布局=[.data][.bss][heap↑⋯空闲⋯↓stack]\text{SRAM 布局} = [\text{.data}][\text{.bss}][\text{heap} \uparrow \cdots \text{空闲} \cdots \downarrow \text{stack}]SRAM 布局=[.data][.bss][heap↑⋯空闲⋯↓stack]
栈向低地址增长，堆向高地址增长。两者相向生长意味着溢出时会互相覆盖，嵌入式系统中需要通过 MPU 或 canary 值检测栈溢出。

加速缓存机制
为缓解等待状态的性能损失，STM32 引入 ART Accelerator（自适应实时加速器）：


    

  • 预取缓冲：利用 128 位 Flash 数据宽度一次读取多条指令
    • 

  • 指令缓存：64 行 × 128 位 = 1 KB 指令缓存
    • 

  • 数据缓存：8 行 × 128 位 = 128 字节数据缓存
    • 



启用 ART 加速器后，对于线性执行的代码，等效访问延迟接近 0 等待状态。

MPU 在 RTOS 环境中实现任务间的内存隔离：每个任务切换时重新配置 MPU 区域，使任务只能访问自己的栈和全局数据段，越界访问触发 MemManage 异常。


区域大小约束=2n 字节（n≥5，即最小32字节）\text{区域大小约束} = 2^n \text{ 字节}（n \geq 5，即最小 32 字节）区域大小约束=2n 字节（n≥5，即最小32字节）
区域起始地址必须对齐到区域大小，子区域禁用（SRD）机制允许在大区域中禁用 1/8 的粒度块，提供更灵活的保护粒度。
