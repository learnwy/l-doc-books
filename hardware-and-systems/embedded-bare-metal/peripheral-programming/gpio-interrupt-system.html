GPIO 与中断系统

GPIO 基本概念

通用输入输出（GPIO）是 MCU 与外部世界交互的最基础接口。每个 GPIO 引脚都是一个可编程的数字 I/O 端口，通过配置其模式、速度和上下拉电阻来适应不同的硬件连接需求。

GPIO 工作模式
输入模式
输入模式下引脚通过施密特触发器读取外部电平：


    

  • 浮空输入：无内部上下拉，引脚电平完全由外部决定，未连接时呈现不确定状态
    • 

  • 上拉输入：内部上拉电阻（约 40 kΩ）使悬空引脚呈高电平
    • 

  • 下拉输入：内部下拉电阻使悬空引脚呈低电平
    • 



VIH_min≈0.7×VDD,VIL_max≈0.3×VDDV_{\text{IH\_min}} \approx 0.7 \times V_{\text{DD}}, \quad V_{\text{IL\_max}} \approx 0.3 \times V_{\text{DD}}VIH_min​≈0.7×VDD​,VIL_max​≈0.3×VDD​
输出模式
输出模式配置引脚驱动外部负载：


    

  • 推挽输出：P-MOS 和 N-MOS 交替导通，能主动驱动高电平和低电平
    • 

  • 开漏输出：仅有 N-MOS 下拉能力，高电平需外部上拉电阻，适用于"线与"逻辑和电平转换
    •

复用功能模式
当引脚用作外设功能时（如 UART_TX、SPI_CLK），需配置为复用模式并选择对应的 AF 编号：


GPIO 复用配置=MODER[AF]+AFR[AF_NUM]+OTYPER + OSPEEDR + PUPDR\text{GPIO 复用配置} = \text{MODER[AF]} + \text{AFR[AF\_NUM]} + \text{OTYPER + OSPEEDR + PUPDR}GPIO 复用配置=MODER[AF]+AFR[AF_NUM]+OTYPER + OSPEEDR + PUPDR
每个引脚可映射多达 16 种复用功能（AF0-AF15），具体映射关系由芯片数据手册的"Alternate Function Mapping"表给出。


BSRR 原子操作
GPIOx_BSRR（Bit Set/Reset Register）是 GPIO 编程中最重要的寄存器之一，它提供了无需关中断即可原子修改引脚电平的能力：


    

  • 低 16 位（BS[15:0]）：写 1 置位对应引脚（写 0 无效果）
    • 

  • 高 16 位（BR[15:0]）：写 1 清除对应引脚（写 0 无效果）
    • 



GPIOA->BSRR=(1<<5)→ PA5 置高\text{GPIOA->BSRR} = (1 << 5) \quad \text{→ PA5 置高}GPIOA->BSRR=(1<<5)→ PA5 置高
 


GPIOA->BSRR=(1<<(5+16))→ PA5 置低\text{GPIOA->BSRR} = (1 << (5+16)) \quad \text{→ PA5 置低}GPIOA->BSRR=(1<<(5+16))→ PA5 置低
相比直接操作 ODR（需要"读-改-写"三步），BSRR 的单次写入保证原子性，即使在中断嵌套场景下也不会出现数据竞争。


外部中断系统
EXTI 架构
外部中断/事件控制器（EXTI）监听 GPIO 引脚的电平变化并触发中断或事件：


关键配置要素：


    

  • 引脚映射：每条 EXTI 线只能连接一个端口的同编号引脚（PA0 或 PB0 或 PC0，不能同时选）
    • 

  • 触发边沿：上升沿（RTSR）、下降沿（FTSR）、双边沿（两者都使能）
    • 

  • 中断/事件选择：中断模式触发 CPU 响应，事件模式仅产生硬件脉冲（可唤醒 ADC 等外设）
    •

中断嵌套
抢占优先级不同的中断可以嵌套执行：高抢占优先级中断到来时，低优先级 ISR 被压栈暂停。设计嵌套中断时需注意：


    

  • 栈深度需足够容纳最大嵌套层数（每层约 32 字节自动压栈 + ISR 局部变量）
    • 

  • ISR 执行时间应尽量短，长操作推迟到主循环或低优先级任务
    • 

  • 共享数据的访问需使用临界区保护或原子操作
    • 



中断响应流程
硬件自动操作
当中断被接受时，Cortex-M 硬件自动完成以下操作：


    

  1. 压栈 8 个寄存器：xPSR、PC、LR、R12、R3、R2、R1、R0（8 × 4 = 32 字节）
    2. 

  2. 从向量表获取 ISR 入口地址加载到 PC
    3. 

  3. 更新 LR 为 EXC_RETURN 魔数值
    4. 

  4. 更新 IPSR 为当前异常编号
    5. 

  5. 切换到 Handler Mode
    6.

ISR 编写规范
嵌入式 ISR 遵循"快进快出"原则：


    

  • 禁止在 ISR 中使用阻塞操作（delay、等待信号量）
    • 

  • 禁止调用非可重入的库函数（如 printf、malloc）
    • 

  • 必须清除中断挂起标志（否则退出后立即重入）
    • 

  • 推荐仅设置标志位或写入环形缓冲区，将处理逻辑延迟到主循环
    • 



ISR 时间预算≤1f中断频率−上下文切换开销\text{ISR 时间预算} \leq \frac{1}{f_{\text{中断频率}}} - \text{上下文切换开销}ISR 时间预算≤f中断频率​1​−上下文切换开销
