定时器、PWM 与 ADC

定时器架构

定时器是 MCU 中最灵活的外设之一，通过计数器和比较器的组合实现精确的时间测量、波形生成和事件触发。STM32 系列定时器分为基本定时器、通用定时器和高级定时器三大类。

计数模式
向上计数
计数器从 0 递增到 ARR（自动重装载值），溢出时产生更新事件并回到 0：


fUEV=fTIM_CLK(PSC+1)×(ARR+1)f_{\text{UEV}} = \frac{f_{\text{TIM\_CLK}}}{(\text{PSC} + 1) \times (\text{ARR} + 1)}fUEV​=(PSC+1)×(ARR+1)fTIM_CLK​​
向下计数
计数器从 ARR 递减到 0，下溢时产生更新事件并重装为 ARR。


中央对齐模式
计数器先从 0 递增到 ARR，再从 ARR 递减到 0，每个周期产生两次比较匹配（上升沿和下降沿各一次），适用于中心对齐 PWM：


fUEV=fTIM_CLK(PSC+1)×(ARR+1)×2f_{\text{UEV}} = \frac{f_{\text{TIM\_CLK}}}{(\text{PSC} + 1) \times (\text{ARR} + 1) \times 2}fUEV​=(PSC+1)×(ARR+1)×2fTIM_CLK​​

互补 PWM 与死区
高级定时器（TIM1/8）支持互补输出通道（CHxN），用于驱动全桥/半桥电路中的上下管。死区时间（Dead Time）防止上下管直通：


tdead=DTG×tDTSt_{\text{dead}} = \text{DTG} \times t_{\text{DTS}}tdead​=DTG×tDTS​
DTG（Dead Time Generator）寄存器使用分段非线性编码，提供从数十纳秒到数微秒的死区配置范围。


ADC 模数转换
转换原理
ADC（模数转换器）将模拟电压转换为数字量。STM32 的逐次逼近型（SAR）ADC 工作原理：


Dout=Vin−Vref-Vref+−Vref-×2nD_{\text{out}} = \frac{V_{\text{in}} - V_{\text{ref-}}}{V_{\text{ref+}} - V_{\text{ref-}}} \times 2^nDout​=Vref+​−Vref-​Vin​−Vref-​​×2n
其中 nnn 为分辨率位数（12 位 ADC → 4096 级量化）。


采样时间配置
每次转换的总时间由采样时间和逐次逼近时间组成：


Tconv=Tsampling+12.5 ADC 周期（12位分辨率）T_{\text{conv}} = T_{\text{sampling}} + 12.5 \text{ ADC 周期}（12 位分辨率）Tconv​=Tsampling​+12.5 ADC 周期（12位分辨率）

配合 DMA（直接内存访问）实现零 CPU 干预的连续采样：


ADC→DMA 请求DMA 控制器→自动传输SRAM 缓冲区\text{ADC} \xrightarrow{\text{DMA 请求}} \text{DMA 控制器} \xrightarrow{\text{自动传输}} \text{SRAM 缓冲区}ADCDMA 请求​DMA 控制器自动传输​SRAM 缓冲区
DMA 双缓冲模式：一个缓冲区被 DMA 填充的同时，CPU 处理另一个缓冲区的数据，实现流水线式采集。

  • 注入组：最多 4 个通道，可打断规则组转换（类似中断嵌套），每通道有独立数据寄存器

过采样与精度提升
通过过采样和平均可在牺牲速度的前提下提高有效分辨率：


有效位数增加=12log⁡2(过采样倍率)\text{有效位数增加} = \frac{1}{2} \log_2(\text{过采样倍率})有效位数增加=21​log2​(过采样倍率)
例如 16 倍过采样可增加 2 位有效精度，将 12 位 ADC 提升为等效 14 位。
