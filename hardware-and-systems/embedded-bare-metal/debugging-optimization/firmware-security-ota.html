断电安全
OTA 更新必须考虑任何时刻的断电恢复：


原子性保证：更新要么完全成功，要么回滚到旧版本\text{原子性保证}：\text{更新要么完全成功，要么回滚到旧版本}原子性保证：更新要么完全成功，要么回滚到旧版本
关键设计要素：


    

  1. 标志位后置：固件完全写入并验证后才设置"更新就绪"标志
    2. 

  2. 确认机制：新固件首次启动后执行自检，通过后设置"确认"标志
    3. 

  3. 回滚窗口：若新固件未在 N 次启动内确认，自动回滚到旧版本
    4. 

  4. 写入校验：每写入一页立即回读验证，异常时标记该页重试
    5.

Bootloader 设计
最小 Bootloader
Bootloader 是 OTA 系统的信任锚点，其核心职责：


    

  1. 检查更新标志/条件
    2. 

  2. 验证固件完整性（CRC/哈希）和真实性（签名）
    3. 

  3. 执行固件交换或跳转
    4. 

  4. 处理回滚逻辑
    5. 



Bootloader 设计原则：越简单越安全，代码越少漏洞越少\text{Bootloader 设计原则}：\text{越简单越安全，代码越少漏洞越少}Bootloader 设计原则：越简单越安全，代码越少漏洞越少
应用跳转
Bootloader 跳转到应用程序的关键步骤：


    

  1. 关闭所有中断和外设
    2. 

  2. 重设 MSP 为应用向量表中的初始栈值
    3. 

  3. 设置 VTOR 为应用向量表地址
    4. 

  4. 跳转到应用的 Reset_Handler
    5.
