二进制与十六进制表示

核心概念

数字系统中所有信息最终以二进制形式存储和处理。二进制（基数 2）仅使用 0 和 1 两个符号，与电子电路的高低电平天然对应；十六进制（基数 16）则作为二进制的紧凑表示形式，广泛用于硬件调试和内存地址标注。

位置计数法原理
任何进位计数制都遵循位置计数法（Positional Notation），一个数的值等于各位数字与对应权重的加权和。对于基数为 rrr 的数制，整数部分有 nnn 位、小数部分有 mmm 位时：


N=∑i=−mn−1di⋅riN = \sum_{i=-m}^{n-1} d_i \cdot r^iN=i=−m∑n−1​di​⋅ri
其中 did_idi​ 是第 iii 位的数字符号，rir^iri 是该位的权重。


以二进制数 (1101.101)2(1101.101)_2(1101.101)2​ 为例：


1×23+1×22+0×21+1×20+1×2−1+0×2−2+1×2−3=13.625101 \times 2^3 + 1 \times 2^2 + 0 \times 2^1 + 1 \times 2^0 + 1 \times 2^{-1} + 0 \times 2^{-2} + 1 \times 2^{-3} = 13.625_{10}1×23+1×22+0×21+1×20+1×2−1+0×2−2+1×2−3=13.62510​
十六进制使用 A=10, B=11, C=12, D=13, E=14, F=15 扩展数字符号，使得每一位恰好对应 4 个二进制位。例如 (2F.8)16=2×161+15×160+8×16−1=47.510(2F.8)_{16} = 2 \times 16^1 + 15 \times 16^0 + 8 \times 16^{-1} = 47.5_{10}(2F.8)16​=2×161+15×160+8×16−1=47.510​。


进制转换方法
十进制转二进制
整数部分采用"除 2 取余，逆序排列"法：


42÷2=21⋯042 \div 2 = 21 \cdots 042÷2=21⋯0
 


21÷2=10⋯121 \div 2 = 10 \cdots 121÷2=10⋯1
 


10÷2=5⋯010 \div 2 = 5 \cdots 010÷2=5⋯0
 


5÷2=2⋯15 \div 2 = 2 \cdots 15÷2=2⋯1
 


2÷2=1⋯02 \div 2 = 1 \cdots 02÷2=1⋯0
 


1÷2=0⋯11 \div 2 = 0 \cdots 11÷2=0⋯1
结果：(42)10=(101010)2(42)_{10} = (101010)_2(42)10​=(101010)2​


小数部分采用"乘 2 取整，顺序排列"法：


0.375×2=0.75→00.375 \times 2 = 0.75 \rightarrow 00.375×2=0.75→0
 


0.75×2=1.5→10.75 \times 2 = 1.5 \rightarrow 10.75×2=1.5→1
 


0.5×2=1.0→10.5 \times 2 = 1.0 \rightarrow 10.5×2=1.0→1
结果：(0.375)10=(0.011)2(0.375)_{10} = (0.011)_2(0.375)10​=(0.011)2​

二进制算术运算
加法规则
二进制加法遵循：0+0=00+0=00+0=0，0+1=10+1=10+1=1，1+0=11+0=11+0=1，1+1=101+1=101+1=10（进位）。


多位加法示例：


    1 0 1 1 0 1    (45)
  + 0 1 1 0 1 1    (27)
  ─────────────
  1 0 0 1 0 0 0    (72)
进位链的传播是影响加法器速度的关键因素，后续章节将讨论超前进位加法器如何优化这一问题。


减法与乘法
二进制减法可通过加补码实现（详见补码章节）。二进制乘法则类似十进制竖式乘法，部分积只有"原数"或"零"两种情况，硬件实现上通过移位-加法完成：


1011×101=1011×(100+1)=101100+1011=1101111011 \times 101 = 1011 \times (100 + 1) = 101100 + 1011 = 1101111011×101=1011×(100+1)=101100+1011=110111
即 (11×5=55)10(11 \times 5 = 55)_{10}(11×5=55)10​。

十六进制在工程中的应用
十六进制在数字系统工程中有四个核心应用场景：


内存地址表示：32 位地址用 8 个十六进制字符即可完整表达，如 0x0040_1000 表示代码段起始地址。


寄存器值调试：查看 CPU 寄存器或外设配置寄存器时，十六进制让每个 Nibble 的含义一目了然。例如控制寄存器值 0xA5 = 1010_0101，可快速识别各位的使能状态。


颜色编码：RGB 颜色使用 6 位十六进制表示，如 #FF8000 表示每个通道 8 位的橙色。


MAC 地址与网络协议：网络设备的 48 位 MAC 地址以 AA:BB:CC:DD:EE:FF 格式标记。


小结
二进制与十六进制是数字电子学中最基础的数据表示方式。二进制直接映射电路物理状态，十六进制提供人类可读的紧凑表达。掌握位置计数法原理和各进制间的快速转换方法，是后续学习编码、运算电路和数字系统设计的必要前提。在实际工程中，熟练使用十六进制读写寄存器配置和分析内存数据是硬件工程师的日常技能。
