BCD 码与格雷码

核心概念

BCD（Binary-Coded Decimal）码和格雷码（Gray Code）是两种针对特定工程需求设计的编码方式。BCD 码保留十进制数的逐位对应关系，便于人机交互显示；格雷码确保相邻编码值仅有一位变化，用于消除机械编码器和异步信号传输中的毛刺问题。

余 3 码
余 3 码（Excess-3）是在 8421 BCD 基础上每位加 3 得到：


余3码=BCD+0011\text{余3码} = \text{BCD} + 0011余3码=BCD+0011
余 3 码的核心优势是自补特性：对一个余 3 码取反（每位取补），得到的恰好是 9−N9-N9−N 的余 3 码。这使得减法可以通过取补加法实现，无需额外修正电路。

格雷码原理

格雷码的工程应用
旋转编码器
机械旋转编码器中，码盘的多个光电传感器不可能在同一瞬间精确切换。若使用自然二进制编码，从 011011011 到 100100100 的跳变可能产生 000000000、001001001、110110110、111111111 等中间错误值。格雷码确保相邻位置仅一位变化，即使读取时刻有微小偏差，结果要么是当前值要么是相邻值，不会出现大幅度跳变。


异步 FIFO 的跨时钟域指针
在异步 FIFO 设计中，读写指针需要跨越时钟域传递。由于亚稳态问题，多位信号同时跳变可能导致错误采样。将指针编码为格雷码后：

小结
BCD 码在人机交互和金融精确计算场景中不可替代，其加法修正逻辑是组合电路设计的经典案例。格雷码通过单位距离特性解决了机械编码器的多位跳变问题和数字系统中跨时钟域的安全传输问题。理解这些特殊编码的设计动机和数学性质，有助于在实际工程中选择最适合的数据表示方案，在可靠性、面积和速度之间取得平衡。
