布尔代数与逻辑化简

核心概念

布尔代数是数字电路设计的数学基础，提供了描述和化简逻辑函数的完整理论框架。通过布尔代数公式法和卡诺图法，设计者可以将复杂的逻辑表达式化简为最简形式，从而减少所需的逻辑门数量、降低电路延迟和功耗。

德摩根定理
德摩根定理（De Morgan's Theorem）是逻辑化简和门电路转换的核心工具：


A⋅B‾=A‾+B‾\overline{A \cdot B} = \overline{A} + \overline{B}A⋅B=A+B
 


A+B‾=A‾⋅B‾\overline{A + B} = \overline{A} \cdot \overline{B}A+B​=A⋅B
推广形式：f(A,B,C,…,+,⋅)‾=f(A‾,B‾,C‾,…,⋅,+)\overline{f(A,B,C,\ldots,+,\cdot)} = f(\overline{A},\overline{B},\overline{C},\ldots,\cdot,+)f(A,B,C,…,+,⋅)​=f(A,B,C,…,⋅,+)


即：对任意布尔表达式取补，等价于所有变量取补、与或互换。


对偶原理
将一个布尔恒等式中的 ⋅\cdot⋅ 换成 +++、+++ 换成 ⋅\cdot⋅、000 换成 111、111 换成 000，得到的表达式仍然成立。对偶原理保证每条定律都有与/或两种对称形式。

卡诺图化简法
基本原理
卡诺图（Karnaugh Map）利用格雷码排列将逻辑上相邻的最小项在图中物理相邻，使得可合并的项一目了然。两个相邻最小项合并消去一个变量：


ABC‾+ABC=AB(C‾+C)=ABAB\overline{C} + ABC = AB(\overline{C} + C) = ABABC+ABC=AB(C+C)=AB
化简步骤
    

  1. 画出卡诺图，标记所有使函数值为 1 的格子
    2. 

  2. 圈选最大的矩形组（2k2^k2k 个格子，k=1,2,3,…k=1,2,3,\ldotsk=1,2,3,…）
    3. 

  3. 每组消去变化的变量，保留不变的变量
    4. 

  4. 所有组的或构成最简 SOP
    5. 



无关项的利用
实际设计中，某些输入组合不会出现（如 BCD 码的 101010101010 ~ 111111111111），对应的输出标记为"无关项"（don't care，记为 ddd 或 ×\times×）。无关项可以灵活地选择为 0 或 1，以获得更大的合并组，进一步简化表达式。


卡诺图的局限
卡诺图适用于 4~5 个变量的函数化简。更多变量时，相邻关系难以直观识别，需要使用 Quine-McCluskey（QM）算法或 Espresso 等计算机辅助工具。


多级逻辑与通用门
NAND 门的通用性
与非门（NAND）是通用门（Universal Gate），可以实现任意逻辑函数：


NOT: A‾=A⋅A‾\text{NOT: } \overline{A} = \overline{A \cdot A}NOT: A=A⋅A
 


AND: A⋅B=A⋅B‾‾\text{AND: } A \cdot B = \overline{\overline{A \cdot B}}AND: A⋅B=A⋅B
 


OR: A+B=A‾⋅B‾‾\text{OR: } A + B = \overline{\overline{A} \cdot \overline{B}}OR: A+B=A⋅B
CMOS 工艺中 NAND 门面积和延迟优于 AND 门（无需额外反相级），因此实际 ASIC/FPGA 标准单元库以 NAND/NOR 为基础。

竞争与冒险
静态冒险
当组合电路的一个输入变化时，由于不同路径的传播延迟差异，输出可能出现短暂的毛刺（glitch）。


静态 1 冒险：输出应恒为 1，但出现瞬间的 0 脉冲。 静态 0 冒险：输出应恒为 0，但出现瞬间的 1 脉冲。


消除方法
    

  • 添加冗余项：在卡诺图中覆盖相邻项组之间的"缝隙"

  • 同步设计：使用时钟边沿采样，在信号稳定后读取
    • 

  • 输出滤波：加电容滤除窄脉冲（模拟方法，不推荐）
    • 



小结
布尔代数和卡诺图为组合逻辑设计提供了从逻辑需求到最简电路实现的系统化方法。公式法适合简单表达式的快速化简，卡诺图法直观高效地处理 4~5 变量问题，QM 算法则覆盖任意变量数的自动化优化。理解通用门的概念和多级逻辑分解策略，有助于在实际工艺约束下设计出面积-速度最优的电路。竞争冒险的识别与消除则是保证电路可靠工作的重要环节。
