加法器与 ALU 设计

核心概念

加法器是数字系统中最基本的算术运算单元，而算术逻辑单元（ALU）在加法器基础上集成了减法、逻辑运算和比较等多种功能，构成处理器数据通路的运算核心。从半加器到超前进位加法器再到完整 ALU 的设计过程，展示了数字电路从简单到复杂的层次化构建方法。

半加器无法处理来自低位的进位输入，因此只能用于最低位运算。


全加器（Full Adder）
全加器增加进位输入 CinC_{in}Cin​，完整描述单位加法：


Si=Ai⊕Bi⊕CinS_i = A_i \oplus B_i \oplus C_{in}Si​=Ai​⊕Bi​⊕Cin​
 


Cout=AiBi+(Ai⊕Bi)CinC_{out} = A_i B_i + (A_i \oplus B_i) C_{in}Cout​=Ai​Bi​+(Ai​⊕Bi​)Cin​
定义进位生成（Generate）和进位传播（Propagate）：


Gi=Ai⋅BiG_i = A_i \cdot B_iGi​=Ai​⋅Bi​
 


Pi=Ai⊕BiP_i = A_i \oplus B_iPi​=Ai​⊕Bi​
则：Cout=Gi+Pi⋅CinC_{out} = G_i + P_i \cdot C_{in}Cout​=Gi​+Pi​⋅Cin​，Si=Pi⊕CinS_i = P_i \oplus C_{in}Si​=Pi​⊕Cin​


这两个概念是所有高级加法器架构的基础。


行波进位加法器（RCA）
将 nnn 个全加器串联，低位的 CoutC_{out}Cout​ 连接到高位的 CinC_{in}Cin​：


Ci=Gi+Pi⋅Ci−1,i=0,1,…,n−1C_i = G_i + P_i \cdot C_{i-1}, \quad i = 0, 1, \ldots, n-1Ci​=Gi​+Pi​⋅Ci−1​,i=0,1,…,n−1
关键延迟：最坏情况下进位需要从第 0 位传播到第 n−1n-1n−1 位。nnn 位 RCA 的进位传播延迟为 n⋅tFAn \cdot t_{FA}n⋅tFA​，对于 32 位或 64 位加法器来说延迟过大。


超前进位加法器（CLA）
核心思想
CLA 通过预先计算所有位的进位来消除串行传播：


C0=G0+P0CinC_0 = G_0 + P_0 C_{in}C0​=G0​+P0​Cin​
 


C1=G1+P1G0+P1P0CinC_1 = G_1 + P_1 G_0 + P_1 P_0 C_{in}C1​=G1​+P1​G0​+P1​P0​Cin​
 


C2=G2+P2G1+P2P1G0+P2P1P0CinC_2 = G_2 + P_2 G_1 + P_2 P_1 G_0 + P_2 P_1 P_0 C_{in}C2​=G2​+P2​G1​+P2​P1​G0​+P2​P1​P0​Cin​
 


C3=G3+P3G2+P3P2G1+P3P2P1G0+P3P2P1P0CinC_3 = G_3 + P_3 G_2 + P_3 P_2 G_1 + P_3 P_2 P_1 G_0 + P_3 P_2 P_1 P_0 C_{in}C3​=G3​+P3​G2​+P3​P2​G1​+P3​P2​P1​G0​+P3​P2​P1​P0​Cin​
所有进位仅依赖输入的 GiG_iGi​、PiP_iPi​ 和初始进位 CinC_{in}Cin​，可在两级门延迟内并行生成。

减法器与加减法共用电路
利用补码原理，减法 A−BA - BA−B 等价于 A+B‾+1A + \overline{B} + 1A+B+1。通过一组异或门和一个控制信号 SubSubSub 实现加减法共用：


Bi′=Bi⊕SubB_i' = B_i \oplus SubBi′​=Bi​⊕Sub
 


Cin=SubC_{in} = SubCin​=Sub
当 Sub=0Sub=0Sub=0 时执行加法 A+BA+BA+B；当 Sub=1Sub=1Sub=1 时执行减法 A−BA-BA−B（BBB 取反加 1）。


这种设计使得一个加法器同时支持加减法，无需独立的减法电路，大幅节省硬件资源。

小结
从半加器到全加器、从行波进位到超前进位，加法器设计展示了速度-面积权衡的经典工程思维。ALU 在加法器基础上通过 MUX 选择和控制逻辑的集成，实现了处理器所需的完整运算功能集。理解加法器的进位传播问题和各种加速架构，以及 ALU 的切片化设计方法，是掌握处理器微架构设计的重要基础。
