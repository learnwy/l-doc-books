对手模拟与 ATT&CK 映射

对手模拟的核心理念

对手模拟（Adversary Emulation）是红队操作的核心方法论，它不同于传统渗透测试中"发现所有漏洞"的目标导向——对手模拟要求红队精确复现特定威胁行为者（Threat Actor）的战术、技术和过程（TTPs），以此来测试组织防御体系对特定威胁的检测和响应能力。

这种方法的价值在于：真实世界中攻击你的不是"所有可能的攻击"，而是具有特定动机和能力集的威胁行为者。一个金融机构需要重点防御的是 FIN7、Carbanak 这类以金融犯罪为目标的 APT 组织；一个国防承包商需要关注的是 APT28（Fancy Bear）、APT29（Cozy Bear）等国家级行为者。对手模拟通过精确模拟这些特定对手的行为模式，帮助组织验证"面对最有可能攻击我们的对手，我们的防御到底有多有效"。

MITRE 在 2025 年更新的 Center for Threat-Informed Defense（CTID）报告中强调，基于威胁情报的安全验证（Threat-Informed Defense）已成为成熟安全组织的核心实践——对手模拟正是这一理念的操作化实现。

MITRE ATT&CK 框架深度解析

MITRE ATT&CK（Adversarial Tactics, Techniques, and Common Knowledge）是全球最广泛使用的网络威胁行为描述框架，它将攻击者的行为分解为标准化的战术（Tactics）和技术（Techniques），形成一个结构化的知识库。

截至 ATT&CK v17（2025 年 4 月发布），Enterprise 矩阵包含 14 个战术、212 个技术和 435 个子技术。v17 的重要更新包括新增 ESXi 平台矩阵和若干 AI 相关的攻击技术。


平台矩阵
ATT&CK 维护了多个平台矩阵：


Enterprise 矩阵覆盖传统 IT 环境，包括 Windows、macOS、Linux、Cloud（AWS/Azure/GCP/SaaS）、Network、Containers、ESXi（v17 新增）平台。


Mobile 矩阵覆盖 Android 和 iOS 移动平台的攻击技术。


ICS 矩阵覆盖工业控制系统（Industrial Control Systems）的攻击技术，适用于 OT/SCADA 环境的安全评估。


威胁组织知识库
ATT&CK 维护了超过 140 个已命名威胁组织的详细档案，记录了每个组织使用的具体技术和工具。这些信息来自全球安全社区的威胁情报共享，是对手模拟选择目标行为者的核心参考。


对手模拟规划流程
一个完整的对手模拟评估遵循以下规划流程：


威胁情报驱动的对手选择
第一步是基于组织面临的实际威胁景观选择要模拟的对手。这需要综合考虑：


行业威胁画像：不同行业面临的主要威胁行为者不同。MITRE CTID 发布的行业威胁报告是良好的起点。例如金融行业需要重点关注 FIN7、FIN12、Lazarus Group；医疗行业关注 Wizard Spider（Ryuk/Conti 勒索软件背后的组织）；政府和国防关注 APT28、APT29、APT41。


地缘政治因素：组织所在的国家和地区、业务涉及的敏感领域都会影响威胁行为者的选择。


历史事件分析：组织过去遭受的攻击事件、同行业的公开安全事件都是选择模拟对手的参考。


攻击剧本设计
选定对手后，需要将该对手的已知 TTPs 转化为可执行的攻击剧本（Attack Playbook）。


攻击剧本的核心结构：


TTPs 提取：从 ATT&CK 组织页面和威胁情报报告中提取目标对手使用的具体技术。例如 APT29 的典型技术包括 T1566.001（Spear Phishing Attachment）、T1059.001（PowerShell）、T1053.005（Scheduled Task）、T1003.001（LSASS Memory）、T1071.001（Web Protocols）。


场景设计：将提取的 TTPs 串联成完整的攻击场景，通常遵循 Cyber Kill Chain 的阶段模型。场景应包含主攻击路径和备选路径——如果主路径被防御阻断，红队应有预定的备选方案。


工具选择：每个 TTPs 需要映射到具体的模拟工具。理想情况下，应使用目标对手实际使用的工具或功能等价的替代品。例如模拟 APT29 可以使用 Cobalt Strike（该组织已知使用此工具）或 Sliver 作为 C2 框架。


MITRE Caldera 自动化对手模拟
MITRE Caldera 是一个开源的自动化对手模拟平台，它将 ATT&CK 技术编码为可自动执行的"能力"（Ability），并通过"对手档案"（Adversary Profile）将多个能力组合成完整的攻击序列。


Caldera 的核心组件：


Agent：部署在目标系统上的轻量级代理，支持 Windows、Linux 和 macOS。Agent 接收来自 Caldera 服务器的指令并执行攻击技术。


Ability：单个 ATT&CK 技术的实现，包含具体的命令和执行逻辑。Caldera 内置了 500+ 个 Ability，覆盖 ATT&CK 的大部分技术。


Adversary Profile：将多个 Ability 按照执行顺序组合成的攻击档案。可以直接使用预定义的威胁组织档案，也可以自定义组合。


Planner：决策引擎，控制 Ability 的执行顺序和条件逻辑。支持"原子"模式（按顺序执行）和"链式"模式（根据上一步的结果动态决定下一步）。


Caldera 的价值在于可重复性——同一个对手模拟可以在修复防御缺口后重新执行，量化防御改进效果。


Atomic Red Team
Atomic Red Team 是 Red Canary 维护的开源项目，提供了 ATT&CK 每个技术的最小化测试用例（称为"原子测试"）。与 Caldera 的全链路模拟不同，Atomic Red Team 聚焦单个技术的快速验证。


每个原子测试都是自包含的脚本，可以在几秒到几分钟内执行完毕。例如测试 T1003.001（LSASS Memory 凭据倾倒）的原子测试会直接执行 procdump -ma lsass.exe 并检查是否触发了安全告警。


Atomic Red Team 适合：日常的检测规则验证、新部署安全工具的基线测试、持续集成流水线中的安全检测回归测试。


ATT&CK 覆盖率评估
对手模拟的一个重要产出是 ATT&CK 覆盖率分析——评估组织的防御体系能够检测 ATT&CK 框架中多少比例的技术。


可见性矩阵
使用 ATT&CK Navigator（MITRE 提供的 Web 工具）创建可见性矩阵：

  • 黄色：有检测规则但未经验证
    • 

  • 红色：无检测能力
    • 

  • 灰色：不适用于本组织的技术

通过可见性矩阵，安全团队可以直观地看到防御的薄弱环节，并基于威胁优先级制定检测能力建设路线图。

理想目标不是 100% 覆盖所有 ATT&CK 技术（这既不现实也不经济），而是确保针对最可能面临的威胁行为者使用的技术达到 Level 2 以上的检测成熟度。


实战对手模拟案例
以模拟 APT29（Cozy Bear，俄罗斯对外情报局 SVR 关联）为例，说明一个完整的对手模拟场景设计：


初始访问：T1566.001 钓鱼邮件附件——使用含有恶意宏的 Word 文档，主题伪装为内部 IT 部门的软件更新通知。宏代码通过 WScript.Shell 执行 Base64 编码的 PowerShell 下载器。


执行与持久化：T1059.001 PowerShell 执行 Cobalt Strike Beacon 载荷 → T1053.005 通过计划任务实现持久化 → T1112 修改注册表存储加密的 C2 配置。


防御规避：T1027.010 命令混淆 → T1562.001 禁用 Windows Defender 实时保护 → T1036.005 伪装成合法的 Windows 服务名称。


凭据访问与横向移动：T1003.001 从 LSASS 进程内存中提取凭据 → T1558.003 Kerberoasting 获取服务账号哈希 → T1021.002 使用 SMB/Windows Admin Shares 横向移动到文件服务器。


数据收集与泄出：T1005 收集本地文件系统中的敏感文档 → T1560.001 使用 7-Zip 压缩和加密 → T1041 通过 HTTPS C2 通道将数据泄出。


每个步骤都记录防御体系的检测情况：是否产生告警、告警延迟时间、是否触发自动响应。最终形成详细的 ATT&CK 覆盖差距报告。
