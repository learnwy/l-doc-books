URDF 与机器人建模

核心概念

URDF（Unified Robot Description Format）是 ROS 生态中描述机器人物理结构的标准 XML 格式。它定义了机器人的连杆（Link）几何形状、质量属性，以及关节（Joint）的运动约束，形成完整的运动链模型。URDF 模型是仿真、可视化、运动规划和控制的共享基础。

URDF 的核心抽象是连杆-关节树：连杆是刚体（有质量、惯量和几何形状），关节是连杆间的约束（规定了运动类型和范围）。整个模型构成一棵有根树，根连杆通常是 base_link。

连杆定义与属性
每个连杆包含三个属性块：visual（可视化外观）、collision（碰撞检测几何）和 inertial（惯性属性）。三者可以使用不同的几何形状——碰撞模型通常比视觉模型简化，以提升仿真性能。


<link name="arm_link_1">
  <visual>
    <origin xyz="0 0 0.15" rpy="0 0 0"/>
    <geometry>
      <mesh filename="package://my_robot/meshes/arm_link_1.dae" scale="0.001 0.001 0.001"/>
    </geometry>
    <material name="blue">
      <color rgba="0.2 0.2 0.8 1.0"/>
    </material>
  </visual>

  <collision>
    <origin xyz="0 0 0.15" rpy="0 0 0"/>
    <geometry>
      <cylinder radius="0.04" length="0.3"/>
    </geometry>
  </collision>

  <inertial>
    <origin xyz="0 0 0.15" rpy="0 0 0"/>
    <mass value="2.5"/>
    <inertia
      ixx="0.019" ixy="0" ixz="0"
      iyy="0.019" iyz="0"
      izz="0.002"/>
  </inertial>
</link>
惯性参数的正确计算对仿真精度至关重要：


import numpy as np

def cylinder_inertia(mass, radius, length):
    ixx = mass * (3 * radius**2 + length**2) / 12
    iyy = ixx
    izz = mass * radius**2 / 2
    return {'ixx': ixx, 'iyy': iyy, 'izz': izz}

def box_inertia(mass, x, y, z):
    ixx = mass * (y**2 + z**2) / 12
    iyy = mass * (x**2 + z**2) / 12
    izz = mass * (x**2 + y**2) / 12
    return {'ixx': ixx, 'iyy': iyy, 'izz': izz}

def sphere_inertia(mass, radius):
    i = 2 * mass * radius**2 / 5
    return {'ixx': i, 'iyy': i, 'izz': i}

def mesh_inertia_from_cad(stl_path, mass, scale=1.0):
    from stl import mesh as stl_mesh

    m = stl_mesh.Mesh.from_file(stl_path)
    volume = m.get_mass_properties()[0] * scale**3
    density = mass / volume if volume > 0 else 1000

    _, cog, inertia = m.get_mass_properties()
    scale_factor = mass / (density * volume) if volume > 0 else 1.0

    return {
        'mass': mass,
        'cog': cog * scale,
        'ixx': inertia[0] * scale_factor,
        'iyy': inertia[4] * scale_factor,
        'izz': inertia[8] * scale_factor,
    }
Xacro 宏语言
Xacro（XML Macros）是 URDF 的预处理器，通过宏定义、参数化、条件判断等编程特性，大幅简化复杂机器人模型的编写。


<?xml version="1.0"?>
<robot xmlns:xacro="http://ros.org/wiki/xacro" name="manipulator">

  <xacro:property name="pi" value="3.14159265359"/>
  <xacro:property name="joint_effort" value="50.0"/>
  <xacro:property name="joint_velocity" value="2.0"/>

  <xacro:macro name="arm_link" params="name length radius mass color">
    <link name="${name}">
      <visual>
        <origin xyz="0 0 ${length/2}" rpy="0 0 0"/>
        <geometry><cylinder radius="${radius}" length="${length}"/></geometry>
        <material name="${color}"/>
      </visual>
      <collision>
        <origin xyz="0 0 ${length/2}" rpy="0 0 0"/>
        <geometry><cylinder radius="${radius}" length="${length}"/></geometry>
      </collision>
      <inertial>
        <origin xyz="0 0 ${length/2}"/>
        <mass value="${mass}"/>
        <xacro:property name="ixx" value="${mass*(3*radius*radius+length*length)/12}"/>
        <inertia ixx="${ixx}" ixy="0" ixz="0" iyy="${ixx}" iyz="0"
                 izz="${mass*radius*radius/2}"/>
      </inertial>
    </link>
  </xacro:macro>

  <xacro:macro name="revolute_joint" params="name parent child xyz rpy axis lower upper">
    <joint name="${name}" type="revolute">
      <parent link="${parent}"/>
      <child link="${child}"/>
      <origin xyz="${xyz}" rpy="${rpy}"/>
      <axis xyz="${axis}"/>
      <limit lower="${lower}" upper="${upper}"
             effort="${joint_effort}" velocity="${joint_velocity}"/>
      <dynamics damping="0.1" friction="0.05"/>
    </joint>
  </xacro:macro>

  <xacro:arm_link name="link_1" length="0.4" radius="0.04" mass="2.5" color="blue"/>
  <xacro:arm_link name="link_2" length="0.35" radius="0.035" mass="2.0" color="green"/>
  <xacro:arm_link name="link_3" length="0.2" radius="0.03" mass="1.0" color="red"/>

  <xacro:revolute_joint name="joint_1" parent="base_link" child="link_1"
    xyz="0 0 0.1" rpy="0 0 0" axis="0 0 1" lower="-3.14" upper="3.14"/>
  <xacro:revolute_joint name="joint_2" parent="link_1" child="link_2"
    xyz="0 0 0.4" rpy="0 0 0" axis="0 1 0" lower="-2.0" upper="2.0"/>
  <xacro:revolute_joint name="joint_3" parent="link_2" child="link_3"
    xyz="0 0 0.35" rpy="0 0 0" axis="0 1 0" lower="-2.5" upper="2.5"/>

</robot>
模型验证与调试
URDF 模型的验证是确保仿真和控制正确性的关键步骤。常见错误包括惯性参数不合理、关节轴方向错误、碰撞模型缺失等。


check_urdf robot.urdf

xacro robot.urdf.xacro > robot.urdf && check_urdf robot.urdf

urdf_to_graphviz robot.urdf
import xml.etree.ElementTree as ET
import numpy as np

class URDFValidator:
    def __init__(self, urdf_path):
        self.tree = ET.parse(urdf_path)
        self.root = self.tree.getroot()
        self.issues = []

    def validate(self):
        self.check_inertials()
        self.check_collisions()
        self.check_joint_limits()
        self.check_tree_structure()
        return self.issues

    def check_inertials(self):
        for link in self.root.findall('.//link'):
            name = link.get('name')
            inertial = link.find('inertial')

            if inertial is None:
                self.issues.append(f'[WARN] {name}: 缺少惯性属性')
                continue

            mass = float(inertial.find('mass').get('value', 0))
            if mass <= 0:
                self.issues.append(f'[ERROR] {name}: 质量为零或负值')

            inertia = inertial.find('inertia')
            if inertia is not None:
                ixx = float(inertia.get('ixx', 0))
                iyy = float(inertia.get('iyy', 0))
                izz = float(inertia.get('izz', 0))

                if ixx <= 0 or iyy <= 0 or izz <= 0:
                    self.issues.append(f'[ERROR] {name}: 惯量主对角线元素非正')

                if not (ixx + iyy >= izz and ixx + izz >= iyy and iyy + izz >= ixx):
                    self.issues.append(f'[WARN] {name}: 惯量不满足三角不等式')

    def check_collisions(self):
        for link in self.root.findall('.//link'):
            name = link.get('name')
            visual = link.find('visual')
            collision = link.find('collision')

            if visual is not None and collision is None:
                self.issues.append(f'[WARN] {name}: 有视觉模型但缺少碰撞模型')

    def check_joint_limits(self):
        for joint in self.root.findall('.//joint'):
            name = joint.get('name')
            jtype = joint.get('type')

            if jtype in ['revolute', 'prismatic']:
                limit = joint.find('limit')
                if limit is None:
                    self.issues.append(f'[ERROR] {name}: 缺少关节限位')
                else:
                    lower = float(limit.get('lower', 0))
                    upper = float(limit.get('upper', 0))
                    if lower >= upper:
                        self.issues.append(f'[ERROR] {name}: 关节限位无效 ({lower} >= {upper})')

    def check_tree_structure(self):
        parents = set()
        children = set()
        for joint in self.root.findall('.//joint'):
            parents.add(joint.find('parent').get('link'))
            child = joint.find('child').get('link')
            if child in children:
                self.issues.append(f'[ERROR] {child}: 存在多个父连杆（不是树结构）')
            children.add(child)
URDF 与 SDF 转换
Gazebo 使用 SDF 格式进行仿真，ROS2 工具链提供了 URDF 到 SDF 的自动转换。但某些仿真特性（如传感器插件、物理属性细调）需要在 SDF 中额外配置。


<gazebo reference="link_1">
  <mu1>0.5</mu1>
  <mu2>0.5</mu2>
  <material>Gazebo/Blue</material>
</gazebo>

<gazebo>
  <plugin filename="gz-sim-diff-drive-system" name="gz::sim::systems::DiffDrive">
    <left_joint>left_wheel_joint</left_joint>
    <right_joint>right_wheel_joint</right_joint>
    <wheel_separation>0.4</wheel_separation>
    <wheel_radius>0.08</wheel_radius>
    <odom_publish_frequency>50</odom_publish_frequency>
    <topic>/cmd_vel</topic>
    <odom_topic>/odom</odom_topic>
    <frame_id>odom</frame_id>
    <child_frame_id>base_link</child_frame_id>
  </plugin>
</gazebo>

小结
    

  • URDF 通过连杆-关节树结构描述机器人物理模型，是 ROS 生态的标准模型格式
    • 

  • 连杆的三个属性块（visual、collision、inertial）分别服务于可视化、碰撞检测和动力学仿真
    • 

  • Xacro 宏语言通过参数化和宏定义简化复杂模型编写，是工程实践中的必备工具
    • 

  • 惯性参数的正确性直接影响仿真精度，需通过 CAD 模型或公式计算
    • 

  • 模型验证工具和自定义检查脚本确保 URDF 模型的完整性和一致性
    • 

  • URDF 到 SDF 的转换通过 Gazebo 扩展标签补充仿真专属特性
    •
