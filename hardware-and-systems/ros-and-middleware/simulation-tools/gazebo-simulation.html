Gazebo 仿真环境

核心概念

Gazebo 是 ROS 生态中最主流的机器人仿真平台，提供物理引擎、传感器模拟、环境渲染等功能。仿真环境使得机器人算法可以在虚拟世界中进行开发和验证，大幅降低硬件开发成本和安全风险。Gazebo Fortress/Harmonic（Ignition 系列）是 ROS2 的推荐仿真器，取代了经典的 Gazebo Classic。

仿真在机器人开发中的价值体现在三个维度：安全性（避免真实硬件损坏）、效率（可并行运行数百个实例）和可重复性（相同条件下可精确复现结果）。

SDF 世界与模型定义
SDF（Simulation Description Format）是 Gazebo 的世界和模型描述格式，比 URDF 更强大，支持光照、传感器噪声模型、关节控制插件等仿真专属特性。

ROS2-Gazebo 桥接
ros_gz_bridge 负责在 Gazebo 话题和 ROS2 话题之间建立双向数据桥接。桥接配置决定了哪些仿真数据可以被 ROS2 节点访问。


from launch import LaunchDescription
from launch.actions import IncludeLaunchDescription, ExecuteProcess
from launch_ros.actions import Node
from launch.launch_description_sources import PythonLaunchDescriptionSource

def generate_launch_description():
    gz_sim = ExecuteProcess(
        cmd=['gz', 'sim', '-r', 'warehouse.sdf'],
        output='screen'
    )

    bridge = Node(
        package='ros_gz_bridge',
        executable='parameter_bridge',
        arguments=[
            '/scan@sensor_msgs/msg/LaserScan[gz.msgs.LaserScan',
            '/camera/image@sensor_msgs/msg/Image[gz.msgs.Image',
            '/camera/depth@sensor_msgs/msg/Image[gz.msgs.Image',
            '/camera/camera_info@sensor_msgs/msg/CameraInfo[gz.msgs.CameraInfo',
            '/imu@sensor_msgs/msg/Imu[gz.msgs.IMU',
            '/cmd_vel@geometry_msgs/msg/Twist]gz.msgs.Twist',
            '/odom@nav_msgs/msg/Odometry[gz.msgs.Odometry',
            '/clock@rosgraph_msgs/msg/Clock[gz.msgs.Clock',
        ],
        output='screen'
    )

    spawn_robot = Node(
        package='ros_gz_sim',
        executable='create',
        arguments=[
            '-name', 'my_robot',
            '-topic', '/robot_description',
            '-x', '0', '-y', '0', '-z', '0.1',
        ],
        output='screen'
    )

    return LaunchDescription([
        gz_sim,
        bridge,
        spawn_robot,
    ])

自动化测试与 CI 集成
仿真环境的核心价值之一是支持自动化测试。通过无头（headless）模式运行 Gazebo，可以在 CI/CD 流水线中自动验证机器人算法的正确性。


import rclpy
from rclpy.node import Node
from geometry_msgs.msg import PoseStamped
from nav_msgs.msg import Odometry
import numpy as np

class NavigationTest(Node):
    def __init__(self):
        super().__init__('navigation_test')

        self.goal_pub = self.create_publisher(
            PoseStamped, '/goal_pose', 10
        )

        self.odom_sub = self.create_subscription(
            Odometry, '/odom', self.odom_callback, 10
        )

        self.current_pose = None
        self.test_goals = [
            (2.0, 0.0, 0.0),
            (2.0, 2.0, 1.57),
            (0.0, 2.0, 3.14),
            (0.0, 0.0, 0.0),
        ]
        self.current_goal_idx = 0
        self.test_results = []

        self.create_timer(1.0, self.run_test)

    def odom_callback(self, msg):
        self.current_pose = msg.pose.pose

    def run_test(self):
        if self.current_goal_idx >= len(self.test_goals):
            self.report_results()
            return

        goal = self.test_goals[self.current_goal_idx]

        if self.current_pose and self.is_goal_reached(goal):
            self.test_results.append({
                'goal': goal,
                'reached': True,
                'error': self.compute_error(goal)
            })
            self.current_goal_idx += 1
            if self.current_goal_idx < len(self.test_goals):
                self.send_goal(self.test_goals[self.current_goal_idx])
        elif not self.current_pose:
            self.send_goal(goal)

    def send_goal(self, goal):
        msg = PoseStamped()
        msg.header.frame_id = 'map'
        msg.header.stamp = self.get_clock().now().to_msg()
        msg.pose.position.x = goal[0]
        msg.pose.position.y = goal[1]
        self.goal_pub.publish(msg)

    def is_goal_reached(self, goal, threshold=0.3):
        dx = self.current_pose.position.x - goal[0]
        dy = self.current_pose.position.y - goal[1]
        return np.sqrt(dx**2 + dy**2) < threshold

    def compute_error(self, goal):
        dx = self.current_pose.position.x - goal[0]
        dy = self.current_pose.position.y - goal[1]
        return np.sqrt(dx**2 + dy**2)

    def report_results(self):
        all_passed = all(r['reached'] for r in self.test_results)
        avg_error = np.mean([r['error'] for r in self.test_results])
        self.get_logger().info(
            f'测试完成: {"全部通过" if all_passed else "存在失败"}, '
            f'平均误差: {avg_error:.3f}m'
        )
小结
    

  • Gazebo 提供物理仿真、传感器模拟和可视化渲染，是 ROS2 机器人开发的标准仿真平台
    • 

  • SDF 格式比 URDF 更强大，支持世界定义、光照、传感器噪声等仿真特性
    • 

  • 传感器仿真通过噪声模型模拟真实传感器行为，缩小 sim-to-real 差距
    • 

  • ros_gz_bridge 实现 Gazebo 和 ROS2 之间的双向话题桥接
    • 

  • 无头仿真模式支持 CI/CD 自动化测试，提升开发效率和代码质量
    • 

  • 仿真环境的价值在于安全性、效率和可重复性的三重保障
