ROS 2 导航栈

核心概念

Nav2（Navigation2）是 ROS 2 的标准导航框架，提供从全局路径规划到局部避障的完整移动机器人导航能力。Nav2 采用行为树（Behavior Tree）作为任务编排引擎，将导航分解为可组合的模块化插件，支持从简单点到点导航到复杂多楼层巡逻的各种场景。

代价地图配置
代价地图是 Nav2 的感知基础——将传感器数据转化为可通行性信息。Nav2 使用分层代价地图架构，每一层负责维护不同来源的障碍物信息，最终合并为一张统一的代价地图。


global_costmap:
  ros__parameters:
    update_frequency: 1.0
    publish_frequency: 1.0
    global_frame: map
    robot_base_frame: base_link
    resolution: 0.05
    plugins: ['static_layer', 'obstacle_layer', 'inflation_layer']
    static_layer:
      plugin: 'nav2_costmap_2d::StaticLayer'
      map_subscribe_transient_local: true
    obstacle_layer:
      plugin: 'nav2_costmap_2d::ObstacleLayer'
      observation_sources: scan
      scan:
        topic: /scan
        max_obstacle_height: 2.0
        clearing: true
        marking: true
    inflation_layer:
      plugin: 'nav2_costmap_2d::InflationLayer'
      cost_scaling_factor: 3.0
      inflation_radius: 0.55

Inflation Layer 的参数直接影响路径规划行为。inflation_radius 决定了障碍物周围的"安全距离"——在此范围内代价值从致命（254）递减到自由（0）。cost_scaling_factor 控制递减速度：值越大代价衰减越快，规划器倾向于更靠近障碍物行驶；值越小衰减越慢，路径更保守。


全局代价地图和局部代价地图的区别：全局代价地图覆盖整个已知环境，更新频率较低，用于全局路径规划；局部代价地图以机器人为中心的滑动窗口，高频更新，用于局部避障。


路径规划器
#include <nav2_core/global_planner.hpp>

class CustomPlanner : public nav2_core::GlobalPlanner {
public:
    void configure(
        const rclcpp_lifecycle::LifecycleNode::WeakPtr &parent,
        std::string name,
        std::shared_ptr<tf2_ros::Buffer> tf,
        std::shared_ptr<nav2_costmap_2d::Costmap2DROS> costmap_ros) override {
        node_ = parent.lock();
        costmap_ = costmap_ros->getCostmap();
    }

    nav_msgs::msg::Path createPlan(
        const geometry_msgs::msg::PoseStamped &start,
        const geometry_msgs::msg::PoseStamped &goal) override {
        nav_msgs::msg::Path path;
        path.header.frame_id = "map";
        path.header.stamp = node_->now();
        // A* or custom algorithm
        return path;
    }
};

NavFn 是最简单的规划器，使用 A* 或 Dijkstra 搜索栅格地图上的最短路径，不考虑机器人的运动学约束——它假设机器人可以向任意方向移动。这对全向移动机器人（如麦克纳姆轮）足够，但对类车机器人（如 Ackermann 转向）会生成不可执行的路径。


Smac Hybrid A* 在搜索空间中增加了航向角维度，生成的路径天然满足非完整约束（最小转弯半径）。它使用 Dubins 或 Reeds-Shepp 曲线连接路径段，适合叉车、仓库 AGV 等类车机器人。


局部控制器
局部控制器负责沿全局路径行驶并实时避障。DWB（Dynamic Window-Based）是默认控制器，在速度空间中采样可行的速度组合，通过评价函数选择最优速度——平衡路径跟踪、目标趋近和障碍物规避。


MPPI（Model Predictive Path Integral）控制器是更先进的选择。它通过蒙特卡洛采样大量控制序列，在预测时域内评估每条轨迹的代价，加权平均得到最优控制输入。MPPI 在复杂动态环境中表现更好，但计算量更大。


RPP（Regulated Pure Pursuit）控制器基于纯追踪算法——沿路径前方设置一个"看点"，计算到达看点所需的转弯曲率。RPP 实现简单、行为可预测，适合低速和窄通道场景。


行为树编排
<root main_tree_to_execute="MainTree">
  <BehaviorTree ID="MainTree">
    <RecoveryNode number_of_retries="3">
      <PipelineSequence>
        <RateController hz="1.0">
          <ComputePathToPose goal="{goal}" path="{path}"
                             planner_id="GridBased"/>
        </RateController>
        <FollowPath path="{path}" controller_id="FollowPath"/>
      </PipelineSequence>
      <ReactiveFallback>
        <Spin spin_dist="1.57"/>
        <BackUp backup_dist="0.3" backup_speed="0.05"/>
        <Wait wait_duration="5"/>
      </ReactiveFallback>
    </RecoveryNode>
  </BehaviorTree>
</root>
行为树相比有限状态机（FSM）的优势在于模块化和可组合性。每个节点独立定义行为（条件、动作、控制流），通过树结构组合形成复杂的导航策略。添加新行为只需在树中插入新节点，不需要修改已有逻辑。Nav2 使用 BehaviorTree.CPP 库，行为树定义在 XML 文件中，可以在运行时动态加载。


小结
    

  • Nav2 是 ROS 2 的标准导航框架，采用行为树编排实现模块化和可扩展的导航任务
    • 

  • 代价地图通过分层架构（静态层 + 障碍物层 + 膨胀层）表征环境中的障碍物和可通行区域
    • 

  • Inflation Layer 的参数直接控制路径与障碍物的距离，需要根据机器人尺寸仔细调参
    • 

  • 全局规划器计算最优路径，局部控制器负责路径跟踪和动态避障
    • 

  • Smac 规划器系列（2D / Hybrid A* / Lattice）覆盖从全向到非完整约束的各种机器人
    • 

  • MPPI 控制器在复杂动态环境中优于传统 DWB，但计算量更大
    • 

  • 行为树的恢复节点机制使机器人能够在导航失败时自动执行旋转、后退等恢复动作
    •
