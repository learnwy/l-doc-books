ROS 2 组件架构

核心概念

ROS 2 的组件（Component）架构是一种将多个节点加载到同一进程中的技术，通过避免跨进程通信来显著降低消息传递延迟和 CPU 开销。在传统的 ROS 2 部署中，每个节点运行在独立进程中，节点间通过 DDS 中间件进行进程间通信（IPC）。组件化将相关节点合并到同一进程，使消息传递退化为进程内的指针传递。

组件节点开发
编写组件节点
#include <rclcpp/rclcpp.hpp>
#include <sensor_msgs/msg/image.hpp>
#include <rclcpp_components/register_node_macro.hpp>

namespace perception {

class ImageProcessor : public rclcpp::Node {
public:
    explicit ImageProcessor(const rclcpp::NodeOptions &options)
        : Node("image_processor", options) {
        sub_ = create_subscription<sensor_msgs::msg::Image>(
            "camera/image_raw", rclcpp::SensorDataQoS(),
            [this](sensor_msgs::msg::Image::UniquePtr msg) {
                process_image(std::move(msg));
            });

        pub_ = create_publisher<sensor_msgs::msg::Image>(
            "camera/image_processed", rclcpp::SensorDataQoS());
    }

private:
    void process_image(sensor_msgs::msg::Image::UniquePtr msg) {
        pub_->publish(std::move(*msg));
    }

    rclcpp::Subscription<sensor_msgs::msg::Image>::SharedPtr sub_;
    rclcpp::Publisher<sensor_msgs::msg::Image>::SharedPtr pub_;
};

}

RCLCPP_COMPONENTS_REGISTER_NODE(perception::ImageProcessor)
CMakeLists.txt 配置
find_package(rclcpp_components REQUIRED)

add_library(image_processor SHARED src/image_processor.cpp)
target_link_libraries(image_processor rclcpp::rclcpp rclcpp_components::component)

# Launch 文件中声明组件容器
from launch import LaunchDescription
from launch_ros.actions import ComposableNodeContainer
from launch_ros.descriptions import ComposableNode

def generate_launch_description():
    container = ComposableNodeContainer(
        name='perception_container',
        namespace='',
        package='rclcpp_components',
        executable='component_container_mt',
        composable_node_descriptions=[
            ComposableNode(
                package='perception',
                plugin='perception::ImageProcessor',
                name='image_processor',
            ),
            ComposableNode(
                package='perception',
                plugin='perception::ObjectDetector',
                name='object_detector',
            ),
        ],
    )
    return LaunchDescription([container])

零拷贝通信
组件模式下使用 UniquePtr 发布消息可实现真正的零拷贝——消息数据在发布者和订阅者之间通过移动语义传递：


auto msg = std::make_unique<sensor_msgs::msg::Image>();
msg->header.stamp = now();
msg->data = std::move(processed_data);
publisher_->publish(std::move(msg));

小结
    

  • ROS 2 组件架构通过将多个节点加载到同一进程实现零拷贝通信，大幅降低延迟
    • 

  • 组件节点通过 NodeOptions 构造函数和 REGISTER_NODE 宏实现插件化注册
    • 

  • 组件容器支持单线程、多线程和隔离执行器三种模式，适应不同性能需求
    • 

  • UniquePtr 消息传递是实现零拷贝的关键，发布者必须放弃消息所有权
    • 

  • 生产部署推荐混合模式：性能关键路径组件化，非关键节点独立进程
    •
