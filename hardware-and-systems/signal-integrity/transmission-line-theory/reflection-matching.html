反射与阻抗匹配

反射的物理本质

当电磁波沿传输线传播并遇到阻抗不连续点时，部分能量被反射回源端，这就是信号反射。反射是信号完整性问题中最基本、最常见的现象，直接导致信号过冲（Overshoot）、下冲（Undershoot）和振铃（Ringing），严重时会引起逻辑误判。

反射系数 Γ\GammaΓ 定义为反射波电压与入射波电压之比：

Γ=V−V+=ZL−Z0ZL+Z0\Gamma = \frac{V^-}{V^+} = \frac{Z_L - Z_0}{Z_L + Z_0}Γ=V+V−​=ZL​+Z0​ZL​−Z0​​

其中 Z0Z_0Z0​ 为传输线特征阻抗，ZLZ_LZL​ 为负载阻抗。几个关键特殊情况：

负载条件 ZLZ_LZL​ Γ\GammaΓ 物理现象
匹配负载 Z0Z_0Z0​ 0 无反射，信号完全被吸收
开路 ∞\infty∞ +1 电压翻倍，电流为零
短路 0 -1 电压为零，电流翻倍
容性负载 1/(jωC)1/(j\omega C)1/(jωC) 频率相关 高频反射小，低频反射大 
反射对信号波形的影响
单次反射分析
考虑一个简单场景：源阻抗为 RsR_sRs​、传输线特征阻抗为 Z0Z_0Z0​、负载为 ZLZ_LZL​ 的系统。初始入射波电压为：


Vinitial=Vs⋅Z0Rs+Z0V_{initial} = V_s \cdot \frac{Z_0}{R_s + Z_0}Vinitial​=Vs​⋅Rs​+Z0​Z0​​
在负载端产生反射后，反射波回到源端时，还会遇到源阻抗造成的第二次反射。源端反射系数：


Γs=Rs−Z0Rs+Z0\Gamma_s = \frac{R_s - Z_0}{R_s + Z_0}Γs​=Rs​+Z0​Rs​−Z0​​
多重反射与格图分析
对于未完全匹配的系统，信号在源端和负载端之间多次往返反射。格图（Lattice Diagram）或反弹图（Bounce Diagram）是分析多重反射的标准工具。


考虑实际案例：Vs=3.3V_s = 3.3Vs​=3.3 V，Rs=10R_s = 10Rs​=10 Ω，Z0=50Z_0 = 50Z0​=50 Ω，ZL=150Z_L = 150ZL​=150 Ω（未匹配）


    

  • 负载反射系数：ΓL=(150−50)/(150+50)=0.5\Gamma_L = (150-50)/(150+50) = 0.5ΓL​=(150−50)/(150+50)=0.5
    • 

  • 源端反射系数：Γs=(10−50)/(10+50)=−0.667\Gamma_s = (10-50)/(10+50) = -0.667Γs​=(10−50)/(10+50)=−0.667
    • 

  • 初始电压：3.3×50/60=2.753.3 \times 50/60 = 2.753.3×50/60=2.75 V
    • 

  • 负载端第一次反射后电压：2.75×(1+0.5)=4.1252.75 \times (1 + 0.5) = 4.1252.75×(1+0.5)=4.125 V
    • 

  • 回到源端后的反射电压变化：2.75×0.5×(−0.667)=−0.9172.75 \times 0.5 \times (-0.667) = -0.9172.75×0.5×(−0.667)=−0.917 V
    • 



信号在经历多次反弹后逐渐趋于稳态值 Vss=Vs⋅ZL/(Rs+ZL)=3.3×150/160=3.094V_{ss} = V_s \cdot Z_L/(R_s + Z_L) = 3.3 \times 150/160 = 3.094Vss​=Vs​⋅ZL​/(Rs​+ZL​)=3.3×150/160=3.094 V。

终端匹配策略
终端匹配是解决反射问题的核心手段。通过在传输线的源端或负载端添加阻抗匹配网络，使反射系数趋近于零。


串联终端匹配（Source Termination）
在源端串联电阻 RsR_sRs​，使 Rs+Rdriver=Z0R_s + R_{driver} = Z_0Rs​+Rdriver​=Z0​：


Rs=Z0−RdriverR_s = Z_0 - R_{driver}Rs​=Z0​−Rdriver​
优点：


    

  • 功耗最低（仅在信号跳变时消耗动态功率）
    • 

  • 元器件数量少
    • 

  • 适合点对点连接
    • 



缺点：


    

  • 传输线中间点的波形在第一次传播时仅为最终值的一半
    • 

  • 不适合多点总线拓扑
    • 



并联终端匹配（Parallel Termination）
在负载端并联电阻 RT=Z0R_T = Z_0RT​=Z0​ 到地或到 VTTV_{TT}VTT​：


优点：


    

  • 负载端信号质量最佳
    • 

  • 适合多点总线和高扇出拓扑
    • 

  • 适合双向总线
    • 



缺点：


    

  • 静态功耗大（P=V2/RTP = V^2/R_TP=V2/RT​）
    • 

  • 增加驱动电流需求
    • 

  • 降低信号摆幅
    • 



戴维南终端匹配
使用两个电阻分压到 VTTV_{TT}VTT​，等效阻抗为 R1∥R2=Z0R_1 \parallel R_2 = Z_0R1​∥R2​=Z0​：


R1=Z0⋅VCCVCC−VTT,R2=Z0⋅VCCVTTR_1 = Z_0 \cdot \frac{V_{CC}}{V_{CC} - V_{TT}}, \quad R_2 = Z_0 \cdot \frac{V_{CC}}{V_{TT}}R1​=Z0​⋅VCC​−VTT​VCC​​,R2​=Z0​⋅VTT​VCC​​
适用于需要定义直流偏置的场景，但功耗是简单并联终端的两倍。


AC 终端匹配
串联 RC 网络（R=Z0R = Z_0R=Z0​，CCC 选择使 RC>2⋅tpdRC > 2 \cdot t_{pd}RC>2⋅tpd​）放置在负载端：


    

  • 电容阻断直流通路，消除静态功耗
    • 

  • 适合信号摆幅敏感的低压接口
    • 

  • 缺点是需要额外电容面积，且对信号边沿有轻微退化
    • 



PCB 设计中的常见反射源
过孔不连续
过孔（Via）引入寄生电容和电感，造成局部阻抗偏离。通孔过孔的典型寄生参数：


    

  • 电容：0.3–0.8 pF（取决于焊盘尺寸和叠层）
    • 

  • 电感：0.5–1.5 nH（取决于过孔长度）
    • 



优化措施：


    

  • 使用 Back-drill 消除过孔残桩（Stub）
    • 

  • 减小过孔焊盘和反焊盘尺寸
    • 

  • 添加接地过孔提供回流路径
    • 



走线宽度变化
走线宽度突变导致阻抗阶跃。阻抗变化量与宽度变化的关系近似为：


ΔZ0/Z0≈−ΔW/W\Delta Z_0 / Z_0 \approx -\Delta W / WΔZ0​/Z0​≈−ΔW/W
设计规则：走线宽度变化应采用锥形过渡，过渡长度至少为走线宽度的 3 倍。


连接器和封装
连接器和 IC 封装是最大的阻抗不连续源：


    

  • 高速连接器的阻抗控制在 ±5% 以内
    • 

  • BGA 封装的引线和过孔阵列引入 0.5–2 nH 电感
    • 

  • 解决方案：选择阻抗受控连接器，优化封装出线扇出
    • 



时域与频域的反射分析
时域分析

  • 阻抗增大：TDR 波形向上偏移
    • 

  • 阻抗减小：TDR 波形向下偏移
    •

反射与匹配是信号完整性工程中最可控的因素——通过合理的终端匹配和连续的阻抗设计，可以将反射降低到不影响系统性能的水平。掌握反射分析方法和匹配技术，是高速 PCB 设计工程师的必备技能。
