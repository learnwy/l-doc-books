屏蔽与滤波设计

EMC 设计的三层防线

电磁兼容性设计的核心是在 EMI 传播的三个环节上建立防线：源头抑制、路径阻断、接收端加固。屏蔽和滤波是路径阻断中最重要的两种技术手段。

屏蔽原理
屏蔽效能定义
屏蔽效能（Shielding Effectiveness, SE）定义为屏蔽体存在时与不存在时接收点场强的比值：


SE=20log⁡10E0Es(dB)SE = 20\log_{10}\frac{E_0}{E_s} \quad \text{(dB)}SE=20log10​Es​E0​​(dB)
其中 E0E_0E0​ 为无屏蔽时的场强，EsE_sEs​ 为有屏蔽时的场强。SE 越大表示屏蔽效果越好。


屏蔽效能由三部分组成：


SE=A+R+B(dB)SE = A + R + B \quad \text{(dB)}SE=A+R+B(dB)

实际中 1 mm 厚金属壁的吸收损耗在 100 MHz 以上远超需求，真正的挑战在于缝隙和开口泄漏。


反射损耗
反射损耗取决于电磁波阻抗与金属固有阻抗的不匹配：


    

  • 电场主导（高阻抗源）：RE=322−10log⁡10(f3μrr2σr)R_E = 322 - 10\log_{10}\left(\frac{f^3 \mu_r r^2}{\sigma_r}\right)RE​=322−10log10​(σr​f3μr​r2​) dB
    • 

  • 磁场主导（低阻抗源）：RH=14.6+10log⁡10(fσrμrr2)R_H = 14.6 + 10\log_{10}\left(\frac{f \sigma_r}{\mu_r r^2}\right)RH​=14.6+10log10​(μr​r2fσr​​) dB
    • 

  • 平面波（远场）：RPW=168−10log⁡10(fμrσr)R_{PW} = 168 - 10\log_{10}\left(\frac{f \mu_r}{\sigma_r}\right)RPW​=168−10log10​(σr​fμr​​) dB
    • 



反射损耗在低频时很大（数百 dB），随频率升高而降低。


缝隙与开口的泄漏
缝隙泄漏原理
屏蔽体的实际 SE 通常不由金属壁本身决定，而是由缝隙和开口决定。经验规则：


SEaperture≈20log⁡10λ2lSE_{aperture} \approx 20\log_{10}\frac{\lambda}{2l}SEaperture​≈20log10​2lλ​
其中 lll 为最大缝隙尺寸（长边或对角线），λ\lambdaλ 为波长。当缝隙尺寸达到半波长时，SE 降至 0 dB。

缝隙阵列效应
当多个缝隙（如散热孔阵列）排列在一起时，总泄漏会增加：


SEarray=SEsingle−10log⁡10(N)SE_{array} = SE_{single} - 10\log_{10}(N)SEarray​=SEsingle​−10log10​(N)
其中 NNN 为缝隙数量。100 个相同缝隙比单个缝隙的 SE 降低 20 dB。


实用缝隙控制技术
    

  1. 导电衬垫（EMI Gasket）：在接缝处使用导电橡胶或弹簧片
    2. 

  2. 搭接设计：金属板间重叠区域≥ 5 倍缝隙宽度
    3. 

  3. 波导截止：通风孔设计为蜂窝结构（截止频率 > 最高关注频率）
    4. 

  4. 导电涂料/镀层：对塑料外壳喷涂导电材料
    5.

电源 EMI 滤波
开关电源产生的传导 EMI 是最常见的 EMC 问题。典型的电源输入 EMI 滤波器结构：


差模滤波（抑制电源线间噪声）：


    

  • X 电容：跨接在 L/N 线间，10–100 nF
    • 

  • 差模电感：单绕组电感，1–100 μH
    • 



共模滤波（抑制线-地噪声）：


    

  • Y 电容：L/N 线分别到地，1–4.7 nF（受安规限制）
    • 

  • 共模扼流圈：双线同向绕制，阻抗 > 1 kΩ @ 关注频率
    •

滤波器布局规则
    

  1. 靠近噪声源或接口：滤波器必须紧靠连接器或 IC，远离噪声源
    2. 

  2. 输入输出隔离：滤波器的输入和输出走线/区域必须物理隔离，避免耦合绕过
    3. 

  3. 良好接地：旁路电容接地路径必须短且低电感
    4. 

  4. 避免谐振：验证滤波器在整个频率范围内无寄生谐振
    5.

电源平面设计
电源平面与接地平面紧密耦合形成分布式电容，提供最低电感的高频去耦：


    

  • 电源/地平面间距 ≤ 4 mil，提供约 90 pF/cm² 的分布电容
    • 

  • 平面边缘后退（20H 规则）：电源平面边缘比接地平面内缩 20 倍介质厚度
    • 

  • 分割电源平面时，使用窄桥连接并在桥上放置去耦电容
    • 



板级屏蔽罩
对于辐射敏感的高速模块（如 RF 前端、时钟合成器），使用焊接式板级屏蔽罩（Board-Level Shield, BLS）：


    

  • 五面金属罩焊接到 PCB 上的接地焊盘
    • 

  • 典型 SE：30–80 dB（取决于缝隙控制）
    • 

  • 设计要点：地焊盘间距 < λ/20，周围有连续接地过孔栅栏
    • 



系统级 EMC 集成
EMC 设计必须从系统层面考虑，单靠 PCB 级手段往往不够：


    

  1. 分区设计：将系统分为安静区（模拟、RF）和嘈杂区（数字、电源）
    2. 

  2. I/O 接口集中：所有外部接口集中在 PCB 一侧，方便统一滤波
    3. 

  3. 电缆管理：差分信号使用屏蔽电缆，屏蔽层 360° 端接
    4. 

  4. 机箱完整性：金属机箱的缝隙控制、导电衬垫、通风蜂窝
    5. 



屏蔽与滤波是 EMC 工程的核心技术手段。优秀的 EMC 设计不是堆砌屏蔽和滤波元件，而是在理解 EMI 源与路径的基础上，精准地在正确位置施加最小成本的控制措施。
