TDR/VNA 测量原理

互连表征的测量需求

高速数字互连的设计验证需要准确的电气特性表征。两种核心测量工具——时域反射计（TDR）和矢量网络分析仪（VNA）——从不同角度提供互连信息：TDR 在时域直接揭示阻抗随空间位置的分布，VNA 在频域精确描述网络的传输和反射特性。

两种工具的互补关系：

工作域 时域 频域
核心输出 阻抗剖面 S 参数

TDR 工作原理
基本原理
TDR 向被测传输线注入一个快速上升沿的阶跃脉冲，然后记录反射回来的信号随时间的变化。由于信号以已知速度传播，反射到达的时间可以转换为空间位置，反射幅度则对应该位置的阻抗值。


阻抗计算公式：


Z(t)=Z0⋅1+ρ(t)1−ρ(t)Z(t) = Z_0 \cdot \frac{1 + \rho(t)}{1 - \rho(t)}Z(t)=Z0​⋅1−ρ(t)1+ρ(t)​
其中 ρ(t)\rho(t)ρ(t) 为反射系数的时域波形，Z0Z_0Z0​ 为系统参考阻抗（通常 50 Ω）。

VNA 工作原理
基本架构
VNA 通过扫频正弦信号激励被测网络，测量每个频率点的反射和透射响应。关键组成部分：


    

  1. 信号源：产生精确频率和幅度的扫频信号
    2. 

  2. 方向耦合器：分离入射波和反射波
    3. 

  3. 接收器：测量信号的幅度和相位
    4. 

  4. 参考通道：提供相位参考
    5. 



VNA 校准
精确的 VNA 测量依赖于高质量的校准。校准的目的是消除系统误差（电缆、适配器、夹具的影响），将测量参考面移至被测器件的端口。

TRL 校准详解
TRL 校准特别适用于 PCB 互连的在板测量：


    

  • Thru：直接连接两个测试端口（或已知长度的传输线）
    • 

  • Reflect：在参考面放置高反射标准（开路或短路）
    • 

  • Line：已知电长度的传输线段
    • 



TRL 的优势在于不需要精确已知校准件的阻抗，仅依赖传输线的特性，适合 PCB 环境中难以实现精密负载的情况。


去嵌入技术
去嵌入的必要性
实际测量中，被测器件（DUT）总是通过夹具、探针或连接器接入测量系统。这些非 DUT 部分的影响必须被移除（去嵌入），才能获得纯 DUT 的特性。

IEEE 370-2020 标准
IEEE 370-2020 定义了统一的高速互连表征方法，核心内容包括：


    

  • 2x-Thru 去嵌入：使用双倍长度的 Thru 结构提取夹具 S 参数
    • 

  • 1x-Reflect 去嵌入：结合 Thru 和 Reflect 测量
    • 

  • 质量度量：定义了去嵌入结果的验证准则
    • 



TDR 与 VNA 的相互转换
TDR → S 参数
通过对 TDR/TDT 时域波形进行 FFT，可以提取 S 参数：


    

  1. 采集 TDR 反射波形和 TDT 透射波形
    2. 

  2. 对参考信号和 DUT 响应分别做 FFT
    3. 

  3. 计算 S11(f)=FFT(反射)/FFT(入射)S_{11}(f) = FFT(反射)/FFT(入射)S11​(f)=FFT(反射)/FFT(入射)
    4. 

  4. 计算 S21(f)=FFT(透射)/FFT(入射)S_{21}(f) = FFT(透射)/FFT(入射)S21​(f)=FFT(透射)/FFT(入射)
    5. 



VNA → 时域
对 VNA 测量的 S 参数做 IFFT 可以获得时域响应：


    

  • S11(f)→IFFTS_{11}(f) \xrightarrow{IFFT}S11​(f)IFFT​ TDR 阻抗剖面
    • 

  • S21(f)→IFFTS_{21}(f) \xrightarrow{IFFT}S21​(f)IFFT​ 脉冲响应或阶跃响应
    • 



时域变换的注意事项：


    

  • 需要处理 DC 外推（VNA 不测 DC 点）
    • 

  • 窗函数选择影响时域分辨率和旁瓣
    • 

  • 频率步进决定时域窗口长度
    •

测量设置最佳实践
    

  1. 频率范围：覆盖 DC 到至少 3 倍奈奎斯特频率
    2. 

  2. 频率点数：足够密集以捕获谐振（至少 1601 点）
    3. 

  3. IF 带宽：在精度和速度间平衡（通常 1–10 kHz）
    4. 

  4. 平均次数：增加平均提高动态范围（每增加一倍约 3 dB）
    5. 

  5. 功率电平：避免过高功率引起非线性，过低功率降低 SNR
    6. 



TDR 和 VNA 是信号完整性工程师的核心测量工具。掌握两者的原理和使用方法，能够准确表征互连结构的电气特性，为设计验证和调试提供可靠数据支撑。
