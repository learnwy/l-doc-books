信号完整性仿真工具

仿真在 SI 设计中的角色

信号完整性仿真使工程师能在实际制板前预测系统性能，大幅降低设计迭代成本和周期。现代高速设计中，仿真已从"锦上添花"变为"必不可少"——当通道速率超过 10 Gbps 时，纯规则驱动的设计方法已无法保证首次成功。

SI 仿真的典型工作流程：

IBIS 与 IBIS-AMI 建模
IBIS 模型概述
IBIS（I/O Buffer Information Specification）是描述 IC I/O 缓冲器行为的工业标准模型格式。相比 SPICE 晶体管级模型，IBIS 具有：


    

  • 不泄露 IC 内部设计细节
    • 

  • 仿真速度快（行为级）
    • 

  • 标准化格式，工具兼容性好
    •

AMI 模型的两种工作模式：


    

  • Init 模式：使用通道脉冲响应快速计算统计眼图（毫秒级）

模型获取
IBIS/IBIS-AMI 模型的获取途径：

    2.

    3. 

  3. 定制开发：对于新器件或保密要求高的项目
    4. 

  4. IBIS Open Forum：标准组织维护的模型库
    5. 



2D 场求解器
用途

仿真设置要点
    

  1. 网格划分：在电流密度变化大的区域加密网格
    2. 

  2. 边界条件：辐射边界或 PML（完美匹配层）
    3. 

  3. 端口定义：波端口或集总端口，取决于结构
    4. 

  4. 收敛判据：S 参数变化 < 0.02 dB/步
    5. 

  5. 去嵌入：仿真结果需去除端口引出段的影响
    6. 



通道仿真与 COM 分析
全通道仿真流程
完整的 SerDes 通道仿真包含：


    

  1. 提取各段 S 参数（走线、过孔、连接器）
    2. 

  2. 级联所有段形成完整通道 S 参数
    3. 

  3. 加载 TX/RX 的 IBIS-AMI 模型
    4. 

  4. 运行 Init 或 GetWave 仿真
    5. 

  5. 生成眼图、BER、COM 等性能指标
    6. 



COM（Channel Operating Margin）

影响精度的因素
    

  1. 材料参数不确定性：εr\varepsilon_rεr​ 和 tan⁡δ\tan\deltatanδ 随频率、温度变化
    2. 

  2. 制造公差：走线宽度 ±0.5 mil，介质厚度 ±10%
    3. 

  3. 铜箔粗糙度模型：不同模型差异可达 1–2 dB @ 20 GHz
    4. 

  4. IBIS-AMI 模型质量：厂商模型与硅片实测的一致性
    5. 

  5. 网格收敛：不充分的网格导致数值误差
    6.
