变量检查

作用域与栈帧

当程序暂停时，编辑器通过 stackTrace → scopes → variables 的层级请求获取执行状态。

interface StackTraceArguments {
  threadId: number;
  startFrame?: number;
  levels?: number;
}

interface StackFrame {
  id: number;
  name: string;
  source?: Source;
  line: number;
  column: number;
  endLine?: number;
  endColumn?: number;
  canRestart?: boolean;
  presentationHint?: 'normal' | 'label' | 'subtle';
}

interface ScopesArguments {
  frameId: number;
}

interface Scope {
  name: string;
  presentationHint?: 'arguments' | 'locals' | 'registers';
  variablesReference: number;
  namedVariables?: number;
  indexedVariables?: number;
  expensive: boolean;
  source?: Source;
}
作用域类型：






presentationHint
名称
内容





arguments
参数
函数参数列表




locals
局部变量
当前栈帧的局部变量




registers
寄存器
CPU 寄存器值（底层调试）




(无)
闭包
闭包捕获的变量




(无)
全局
全局变量







提示： expensive: true 的作用域（如全局变量）不会自动展开，需要用户手动点击。这避免了加载大量全局状态的性能问题。






变量树
变量通过 variablesReference 形成树状结构。叶子节点的 variablesReference 为 0，非零值表示该变量可以展开查看子属性。


interface Variable {
  name: string;
  value: string;
  type?: string;
  presentationHint?: VariablePresentationHint;
  evaluateName?: string;
  variablesReference: number;
  namedVariables?: number;
  indexedVariables?: number;
}




字段
说明





variablesReference
0 = 叶子节点，非零 = 可展开




namedVariables
命名子变量数量（对象属性）




indexedVariables
索引子变量数量（数组元素）




evaluateName
可在 evaluate 请求中使用的表达式




memoryReference
变量的内存地址引用







提示： 当 indexedVariables 较大时（如长数组），客户端应使用分页请求：通过 variables 请求的 start 和 count 参数按需加载。






表达式求值
evaluate 请求允许在调试上下文中求值任意表达式，支持多种上下文场景。


interface EvaluateArguments {
  expression: string;
  frameId?: number;
  context?: 'watch' | 'repl' | 'hover' | 'clipboard' | 'variables';
}

interface EvaluateResponse {
  result: string;
  type?: string;
  presentationHint?: VariablePresentationHint;
  variablesReference: number;
  namedVariables?: number;
  indexedVariables?: number;
  memoryReference?: string;
}
各上下文的行为差异：






context
触发方式
副作用允许
典型用途





watch
监视面板表达式
不推荐
持续监视变量或表达式




repl
调试控制台输入
允许
执行代码、修改变量




hover
鼠标悬停变量
不允许
快速查看变量值




clipboard
复制值操作
不允许
生成适合粘贴的字符串




variables
变量面板修改
允许
用户在变量面板中设置新值







Watch 表达式
Watch 表达式是持续在监视面板中显示的表达式，每次暂停时自动重新求值。


class WatchManager {
  private watches: Map<string, string> = new Map();

  addWatch(expression: string): void {
    this.watches.set(expression, '');
  }

  async evaluateAll(frameId: number, session: DebugSession): Promise<void> {
    for (const [expression] of this.watches) {
      const result = await session.evaluate({
        expression,
        frameId,
        context: 'watch',
      });
      this.watches.set(expression, result.result);
    }
  }
}




特性
说明





自动求值
每次暂停时自动重新求值所有 Watch 表达式




值变化检测
编辑器高亮显示与上次不同的值




错误处理
表达式无效时显示错误信息而非崩溃




作用域感知
在不同栈帧上下文中求值结果可能不同







内存读取与反汇编
对于系统级调试，DAP 支持原始内存读取和指令级反汇编。


interface ReadMemoryArguments {
  memoryReference: string;
  offset?: number;
  count: number;
}

interface DisassembledInstruction {
  address: string;
  instructionBytes?: string;
  instruction: string;
  symbol?: string;
  location?: Source;
  line?: number;
}




能力
请求
前提条件





内存读取
readMemory
supportsReadMemoryRequest




反汇编
disassemble
supportsDisassembleRequest




指令级单步
next/stepIn
granularity: "instruction"




指令断点
setInstructionBreakpoints
supportsInstructionBreakpoints







提示： 内存读取返回的 data 是 Base64 编码的原始字节。反汇编的 resolveSymbols 参数让适配器在反汇编中解析函数名，使输出更可读。






小结
    

  • 变量检查通过 stackTrace → scopes → variables 的三级请求层层展开。
    • 

  • 变量通过 variablesReference 形成树状结构，0 表示叶子节点，非零表示可展开。
    • 

  • evaluate 请求支持 watch/repl/hover 等多种上下文，context 参数控制是否允许副作用。
    • 

  • Watch 表达式在每次暂停时自动重新求值，编辑器高亮显示值的变化。
    • 

  • 内存读取和反汇编支持系统级调试，需要适配器声明相应的能力。
    •
