高级调试

条件断点

条件断点只在指定条件为真时才暂停执行，避免在循环或高频代码中频繁暂停。

interface SourceBreakpoint {
  line: number;
  condition?: string;
  hitCondition?: string;
  logMessage?: string;
}

const breakpoints: SourceBreakpoint[] = [
  {
    line: 42,
    condition: "user.role === 'admin' && user.id > 100",
  },
  {
    line: 58,
    condition: 'items.length > 1000',
  },
];




断点特性
字段
表达式示例





条件断点
condition
user.id === 42




命中计数
hitCondition
> 10、== 100、% 5 == 0




日志点

User: {user.name}, ID: {id}





条件表达式的求值环境与被调试程序一致，可以使用当前作用域中的所有变量。




提示： 条件断点的性能影响取决于调试器实现。某些调试器在引擎层面优化了条件求值（如 V8 的条件断点），而另一些则需要每次命中时通过 DAP 往返求值。






日志点（Logpoints）
日志点是一种不暂停执行的特殊断点，它在命中时输出日志消息到调试控制台。花括号中的表达式会被求值替换。


const logpoint: SourceBreakpoint = {
  line: 35,
  logMessage: 'Processing order #{order.id}, total: {order.total}, items: {order.items.length}',
};

命中计数断点
命中计数断点在被命中特定次数后才暂停。hitCondition 支持多种比较表达式。


const hitCountBreakpoints: SourceBreakpoint[] = [
  { line: 20, hitCondition: '== 100' },
  { line: 30, hitCondition: '> 50' },
  { line: 40, hitCondition: '% 10 == 0' },
];




hitCondition
含义
暂停时机





== N
等于 N 次
第 N 次命中时暂停




> N
大于 N 次
第 N+1 次起每次都暂停




>= N
大于等于 N 次
第 N 次起每次都暂停




< N
小于 N 次
前 N-1 次命中暂停




% N == 0
N 的倍数
每 N 次命中暂停一次







提示： 条件断点和命中计数断点可以组合使用。同时设置 condition 和 hitCondition 时，只有条件为真的命中才计入命中计数。






反向调试
部分调试器支持反向执行（Time-Travel Debugging），允许用户回退到之前的执行状态。


interface Capabilities {
  supportsStepBack?: boolean;
}

type ReverseCommands = 'reverseContinue' | 'stepBack';

多目标调试
DAP 支持同时调试多个目标（如前端 + 后端、微服务集群），编辑器可以管理多个并行的调试会话。


{
  "version": "0.2.0",
  "compounds": [
    {
      "name": "Full Stack",
      "configurations": ["Launch Server", "Launch Client"],
      "stopAll": true,
      "preLaunchTask": "npm: build"
    }
  ],
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Launch Server",
      "program": "${workspaceFolder}/server/index.ts"
    },
    {
      "type": "chrome",
      "request": "launch",
      "name": "Launch Client",
      "url": "http://localhost:3000"
    }
  ]
}

内联值
内联值（Inline Values）在代码行旁直接显示变量的当前值，无需鼠标悬停或查看变量面板。


interface InlineValuesProvider {
  provideInlineValues(document: TextDocument, viewRange: Range, context: InlineValueContext): InlineValue[];
}

type InlineValue = InlineValueText | InlineValueVariableLookup | InlineValueEvaluatableExpression;

interface InlineValueText {
  range: Range;
  text: string;
}

interface InlineValueVariableLookup {
  range: Range;
  variableName?: string;
  caseSensitiveLookup: boolean;
}




内联值类型
说明





InlineValueText
直接显示固定文本




InlineValueVariableLookup
按变量名查找并显示值




InlineValueEvaluatable
求值表达式并显示结果







提示： 内联值是 LSP 协议（非 DAP）的一部分，但通常在调试模式下激活。编辑器通过 InlineValuesProvider 确定在哪些位置显示什么内联值。






小结
    

  • 条件断点只在条件表达式为真时暂停，condition 在被调试程序的作用域中求值。
    • 

  • 日志点不暂停执行而输出日志，{expression} 语法支持动态表达式插值。
    • 

  • 命中计数断点支持 ==、>、% 等比较运算，可与条件断点组合使用。
    • 

  • 反向调试允许回退执行状态，需要 rr 或 UndoDB 等专用录制重放工具支持。
    • 

  • 多目标调试通过 compounds 配置同时启动多个调试会话，stopAll 控制联动停止。
