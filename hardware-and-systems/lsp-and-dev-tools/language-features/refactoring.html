Code Actions 概览

Code Actions 是 LSP 中最灵活的功能之一，涵盖快速修复、代码重构和源操作三大类。编辑器在用户光标位置或选区范围内请求可用的操作。

interface CodeActionParams {
  textDocument: TextDocumentIdentifier;
  range: Range;
  context: CodeActionContext;
}

interface CodeActionContext {
  diagnostics: Diagnostic[];
  only?: CodeActionKind[];
  triggerKind?: CodeActionTriggerKind;
}

namespace CodeActionKind {
  export const QuickFix = 'quickfix';
  export const Refactor = 'refactor';
  export const RefactorExtract = 'refactor.extract';
  export const RefactorInline = 'refactor.inline';
  export const RefactorRewrite = 'refactor.rewrite';
  export const Source = 'source';
  export const SourceOrganizeImports = 'source.organizeImports';
  export const SourceFixAll = 'source.fixAll';
}

Code Action 实现
一个完整的 Code Action 实现通常包含条件检测和编辑生成两个阶段。


connection.onCodeAction((params): CodeAction[] => {
  const actions: CodeAction[] = [];
  const document = documents.get(params.textDocument.uri);
  if (!document) return actions;
  const selectedText = document.getText(params.range);

  if (selectedText && params.range.start.line !== params.range.end.line) {
    actions.push({
      title: 'Extract to function',
      kind: CodeActionKind.RefactorExtract,
      edit: createExtractFunctionEdit(document, params.range, selectedText),
    });
  }
  if (isArrowFunction(document, params.range)) {
    actions.push({
      title: 'Convert to named function',
      kind: CodeActionKind.RefactorRewrite,
      edit: createConvertToNamedFunctionEdit(document, params.range),
    });
  }
  for (const diag of params.context.diagnostics) {
    if (diag.code === 'missing-import') {
      actions.push({
        title: `Add import for '${extractSymbolName(diag)}'`,
        kind: CodeActionKind.QuickFix,
        diagnostics: [diag],
        isPreferred: true,
        edit: createAddImportEdit(document, diag),
      });
    }
  }
  return actions;
});

重命名
LSP 的重命名功能由两个请求组成：prepareRename 验证重命名的可行性并返回初始范围，rename 执行实际的重命名操作。


connection.onPrepareRename((params) => {
  const symbol = findSymbolAt(params.textDocument.uri, params.position);
  if (!symbol || !isRenameable(symbol)) return null;
  return { range: symbol.nameRange, placeholder: symbol.name };
});

connection.onRenameRequest((params): WorkspaceEdit | null => {
  const symbol = findSymbolAt(params.textDocument.uri, params.position);
  if (!symbol) return null;
  const changes: { [uri: string]: TextEdit[] } = {};
  for (const ref of findAllReferences(symbol)) {
    const edits = changes[ref.uri] ?? [];
    edits.push({ range: ref.range, newText: params.newName });
    changes[ref.uri] = edits;
  }
  return { changes };
});

作用

预览变更，用户确认后应用







提示： prepareRename 返回 null 表示当前位置不支持重命名（如关键字或字面量上），编辑器应据此禁用重命名输入框。






Code Lens
Code Lens 在代码行上方显示可操作的元信息，如引用计数、测试运行按钮、Git 作者等。


interface CodeLens {
  range: Range;
  command?: Command;
  data?: unknown;
}

interface Command {
  title: string;
  command: string;
  arguments?: unknown[];
}

connection.onCodeLens((params): CodeLens[] => {
  const symbols = getDocumentSymbols(params.textDocument.uri);
  return symbols
    .filter((s) => s.kind === SymbolKind.Function || s.kind === SymbolKind.Class)
    .map((s) => ({
      range: s.range,
      data: { uri: params.textDocument.uri, symbolName: s.name },
    }));
});

connection.onCodeLensResolve((codeLens): CodeLens => {
  const { uri, symbolName } = codeLens.data as { uri: string; symbolName: string };
  const refCount = countReferences(uri, symbolName);
  codeLens.command = {
    title: `${refCount} references`,
    command: 'editor.action.showReferences',
    arguments: [uri, codeLens.range.start],
  };
  return codeLens;
});




特性
说明





延迟 resolve
初始只返回位置，command 在 resolve 时计算




自动刷新
代码变更后自动重新请求




可操作
点击 CodeLens 执行绑定的 Command




性能注意
大文件中 CodeLens 数量可能很多，需优化







提示： Code Lens 的 resolve 与补全的 resolve 类似，都是为了避免在初始请求中计算昂贵的信息。尤其是引用计数，需要全项目扫描。






Source Actions
Source Actions 是在文件级别执行的操作，通常在保存时自动触发。


const saveActions: Record<string, () => WorkspaceEdit> = {
  'source.organizeImports': () => organizeImports(),
  'source.fixAll': () => fixAllDiagnostics(),
  'source.addMissingImports': () => addAllMissingImports(),
};

小结
    

  • Code Actions 分为 quickfix、refactor 和 source 三大类，通过 kind 层级结构分类。
    • 

  • 重构操作支持**提取（extract）、内联（inline）和改写（rewrite）**三种模式。
    • 

  • 重命名由 prepareRename + rename 两步组成，支持跨文件的 WorkspaceEdit 批量变更。
    • 

  • Code Lens 在代码行上方显示可操作的元信息，采用懒 resolve 模式延迟计算。
    • 

  • Source Actions 在文件级别运行，支持保存时自动执行（如整理导入和修复全部）。
