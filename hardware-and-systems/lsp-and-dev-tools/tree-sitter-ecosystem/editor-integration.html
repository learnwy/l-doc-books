编辑器集成

语法高亮

Tree-sitter 的查询系统为语法高亮提供了比正则表达式更精确、更语义化的着色方案。通过 highlights.scm 查询文件定义高亮规则。

; highlights.scm — TypeScript 高亮查询示例

; 关键字
["if" "else" "for" "while" "return" "function" "class" "const" "let" "var"] @keyword

; 类型
(type_identifier) @type
(predefined_type) @type.builtin

; 函数定义
(function_declaration
  name: (identifier) @function)
(method_definition
  name: (property_identifier) @function.method)

; 函数调用
(call_expression
  function: (identifier) @function.call)
(call_expression
  function: (member_expression
    property: (property_identifier) @function.method.call))

; 变量
(identifier) @variable
(shorthand_property_identifier) @variable

; 字面量
(string) @string
(template_string) @string
(number) @number
(true) @boolean
(false) @boolean
(null) @constant.builtin

; 注释
(comment) @comment

; 操作符
["+" "-" "*" "/" "=" "==" "!=" "<" ">" "&&" "||"] @operator

; 标点
["(" ")" "{" "}" "[" "]"] @punctuation.bracket
["," ";" ":" "."] @punctuation.delimiter

提示： 高亮捕获名称遵循约定层级结构（如 function.method.call）。编辑器主题按从具体到通用的顺序匹配——如果主题未定义 function.method.call，会回退到 function.method，再回退到 function。






代码折叠
Tree-sitter 的查询可以精确定义代码折叠区域，比传统的缩进级别或大括号匹配更准确。

(class_declaration

(if_statement

(for_statement
  body: (statement_block) @fold)

(object) @fold
(array) @fold

(comment) @fold

自动缩进
Tree-sitter 查询可以定义精确的缩进规则，替代传统的正则表达式缩进模式。


; indents.scm

(statement_block) @indent
(class_body) @indent
(object) @indent
(array) @indent
(arguments) @indent
(formal_parameters) @indent

"}" @outdent
"]" @outdent
")" @outdent

(if_statement
  condition: (_) @indent)
function calculateIndent(tree: Tree, cursorLine: number, tabSize: number): number {
  const node = tree.rootNode.descendantForPosition({ row: cursorLine, column: 0 });
  let indent = 0;
  let current = node;
  while (current.parent) {
    if (isIndentNode(current.parent)) indent += tabSize;
    current = current.parent;
  }
  return indent;
}

提示： Tree-sitter 缩进查询在换行时计算新行的缩进级别。结合编辑器的 onEnterRules，可以实现非常精准的自动缩进体验。

文本对象（Vim/Neovim）
在 Neovim 中，Tree-sitter 为 Vim 的文本对象系统提供了语义化扩展。


; textobjects.scm

(function_declaration
  body: (statement_block) @function.inner) @function.outer

(class_declaration
  body: (class_body) @class.inner) @class.outer

(if_statement
  consequence: (_) @conditional.inner) @conditional.outer

(for_statement
  body: (_) @loop.inner) @loop.outer

(call_expression
  arguments: (arguments) @call.inner) @call.outer

(parameters
  (parameter) @parameter.inner)

提示： Tree-sitter 文本对象相比传统的 {/} 段落对象更精确。它能正确处理嵌套结构，例如在嵌套函数中 vif 只选中最内层函数的内容。






小结
    

  • 语法高亮通过 highlights.scm 查询实现，捕获名称支持层级回退（如 function.method.call → function）。
    • 

  • 代码折叠基于语法节点类型（folds.scm），比传统缩进级别和大括号匹配更精确。
    • 

  • 自动缩进使用 @indent/@outdent 捕获，在换行时计算正确的缩进级别。
    • 

  • 局部变量通过 locals.scm 追踪作用域和定义-引用关系，支持语义化变量着色。
    • 

  • 文本对象为 Neovim 提供语义化的 inner/outer 选择操作，精确处理嵌套结构。
    •
