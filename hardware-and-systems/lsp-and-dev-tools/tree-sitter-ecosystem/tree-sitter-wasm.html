Tree-sitter WASM 浏览器端解析

web-tree-sitter 概述

web-tree-sitter 是 Tree-sitter 的 WebAssembly 编译版本，允许在浏览器和 Node.js 中使用 Tree-sitter 的全部解析能力。它为 Web IDE、在线代码编辑器和代码分析工具提供了基础。

import Parser from 'web-tree-sitter';

async function initParser(): Promise<Parser> {
  await Parser.init();
  const parser = new Parser();

  const Lang = await Parser.Language.load('/tree-sitter-typescript.wasm');
  parser.setLanguage(Lang);

  return parser;
}

async function parseCode(parser: Parser, code: string): Promise<Parser.Tree> {
  return parser.parse(code);
}

动态加载 .wasm 语法
web-tree-sitter 支持按需动态加载语法文件，这对于支持多种编程语言的 Web IDE 至关重要。


class LanguageManager {
  private languages: Map<string, Parser.Language> = new Map();
  private loading: Map<string, Promise<Parser.Language>> = new Map();

  async getLanguage(langId: string): Promise<Parser.Language> {
    const cached = this.languages.get(langId);
    if (cached) return cached;

    let loadPromise = this.loading.get(langId);
    if (!loadPromise) {
      loadPromise = Parser.Language.load(`/grammars/tree-sitter-${langId}.wasm`);
      this.loading.set(langId, loadPromise);
    }

    const language = await loadPromise;
    this.languages.set(langId, language);
    this.loading.delete(langId);
    return language;
  }
}

vscode.dev 中的 Tree-sitter
vscode.dev 是 VS Code 的浏览器版本，通过 web-tree-sitter 实现了部分语法分析功能。


class TreeSitterTokenProvider implements DocumentSemanticTokensProvider {
  private parser: Parser;
  private highlightQuery: Parser.Query;

  async provideDocumentSemanticTokens(document: TextDocument): Promise<SemanticTokens> {
    const tree = this.parser.parse(document.getText());
    const matches = this.highlightQuery.matches(tree.rootNode);
    const builder = new SemanticTokensBuilder();
    for (const match of matches) {
      for (const capture of match.captures) {
        const tokenType = mapCaptureToTokenType(capture.name);
        if (tokenType !== undefined) {
          builder.push(
            capture.node.startPosition.row,
            capture.node.startPosition.column,
            capture.node.endIndex - capture.node.startIndex,
            tokenType,
            0,
          );
        }
      }
    }
    return builder.build();
  }
}

Playground 集成
Tree-sitter Playground 是一个交互式的在线工具，用于开发和调试语法定义。


class TreeSitterPlayground {
  private parser: Parser;
  private language: Parser.Language;

  async updateTree(): Promise<void> {
    const code = this.editor.getValue();
    const tree = this.parser.parse(code);
    this.treeView.render(tree.rootNode);
    if (this.queryEditor.getValue()) this.highlightQueryMatches(tree);
  }

  private highlightQueryMatches(tree: Parser.Tree): void {
    const query = this.language.query(this.queryEditor.getValue());
    const matches = query.matches(tree.rootNode);
    const highlights = matches.flatMap((m) =>
      m.captures.map((c) => ({
        startRow: c.node.startPosition.row,
        startCol: c.node.startPosition.column,
        endRow: c.node.endPosition.row,
        endCol: c.node.endPosition.column,
        className: `capture-${c.name}`,
      })),
    );
    this.editor.setHighlights(highlights);
  }
}

Web Worker 中的 Tree-sitter
在生产环境中，Tree-sitter 解析应放在 Web Worker 中执行，避免阻塞主线程。


const worker = new Worker('tree-sitter-worker.js');
worker.postMessage({ type: 'parse', code: document.getText(), language: 'typescript' });
worker.onmessage = (event) => {
  const { type, data } = event.data;
  if (type === 'tree') updateSyntaxHighlighting(data.captures);
  if (type === 'symbols') updateOutline(data.symbols);
};
