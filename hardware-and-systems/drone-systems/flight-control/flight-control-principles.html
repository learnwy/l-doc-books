飞行控制原理

核心概念

飞行控制是无人机（Unmanned Aerial Vehicle, UAV）系统的核心技术，负责将高层的运动指令转化为电机转速命令，维持飞行器的姿态稳定和轨迹跟踪。多旋翼无人机（以四旋翼为典型）通过差动调节各电机转速产生升力差和力矩差来实现六自由度运动控制。

飞行控制系统的核心任务可以分解为三个层次：内环姿态控制——维持飞行器的横滚（Roll）、俯仰（Pitch）和偏航（Yaw）角度稳定；外环位置控制——控制飞行器在三维空间中的位置和速度；混控器（Mixer）——将姿态控制器输出的力矩命令分配到各个电机。

多旋翼动力学模型
理解飞行控制首先需要建立多旋翼的动力学模型。以四旋翼为例，飞行器有 6 个自由度（3 个平移 + 3 个旋转）但只有 4 个控制输入（4 个电机转速），属于欠驱动系统——水平移动必须通过倾斜机体实现。

四旋翼的构型分为 "+" 型和 "×" 型。"×" 型将四个电机布置在对角线方向，是目前主流的构型——前向运动时前后两对电机共同产生俯仰力矩，比 "+" 型更均匀地分配载荷。


陀螺效应：高速旋转的螺旋桨具有角动量，当飞行器偏航时，陀螺进动会产生额外的耦合力矩。多旋翼通过相邻电机反转的方式抵消大部分陀螺效应——四旋翼中对角线电机同向旋转，相邻电机反向旋转。


气动干扰：多旋翼各螺旋桨的下洗气流（Downwash）会影响邻近螺旋桨的气动效率。在低速飞行和悬停时影响较小，但在高速前飞或下降时（经过自身涡流场）可能导致明显的气动干扰，需要在控制器设计中考虑。


姿态控制器设计
姿态控制是飞行控制的内环，要求高带宽、低延迟和强鲁棒性。主流的姿态控制方案从经典 PID 到现代非线性控制都有应用。


串级 PID 控制 是最广泛使用的姿态控制方案。外环角度 PID 输出期望角速度，内环角速度 PID 输出力矩命令：


    

  • 角度环（P 或 PD 控制器）：ωcmd=Kpatt(qdes−q)+Kdatt(q˙des−q˙)\omega_{cmd} = K_p^{att}(q_{des} - q) + K_d^{att}(\dot{q}_{des} - \dot{q})ωcmd​=Kpatt​(qdes​−q)+Kdatt​(q˙​des​−q˙​)
    • 

  • 角速度环（PID 控制器）：τ=Kprate(ωcmd−ω)+Kirate∫(ωcmd−ω)dt+Kdrated(ωcmd−ω)dt\tau = K_p^{rate}(\omega_{cmd} - \omega) + K_i^{rate}\int(\omega_{cmd} - \omega)dt + K_d^{rate}\frac{d(\omega_{cmd} - \omega)}{dt}τ=Kprate​(ωcmd​−ω)+Kirate​∫(ωcmd​−ω)dt+Kdrate​dtd(ωcmd​−ω)​

PID 控制器的优势在于直觉化的参数调节和广泛的工程经验。PID 参数调节的经验规则：先调角速度环（高增益确保快速响应），再调角度环（适中增益避免超调）。

非线性控制方法：对于需要大机动飞行（如翻滚、急转弯）的场景，线性化后的 PID 控制器性能下降。非线性控制方法直接利用非线性动力学模型设计控制器：


    

  • 反步法（Backstepping）：逐层设计虚拟控制量，通过 Lyapunov 函数保证全局稳定性
    • 

  • 滑模控制（SMC）：定义滑动面，强制系统状态在有限时间内到达滑动面并保持，对模型不确定性和外部扰动鲁棒
    • 

  • INDI（增量非线性动态逆）：基于角加速度增量的控制方法，不需要精确的力矩模型，对气动变化和载荷变化鲁棒
    • 



位置控制与轨迹跟踪
位置控制是飞行控制的外环，将期望的空间位置和速度转化为期望的姿态角和总推力。


位置控制器通常采用 PID 或 PD + 前馈的结构。以水平面控制为例：


    

  1. 位置误差 → PD 控制器 → 期望加速度
    2. 

  2. 期望加速度 → 力/姿态解算 → 期望横滚角和俯仰角
    3. 

  3. 期望姿态 → 姿态控制器（内环）
    4. 



轨迹跟踪比定点悬停更具挑战性，因为需要同时跟踪时间参数化的位置、速度和加速度。最小化 snap（加加加速度）的多项式轨迹是多旋翼轨迹生成的标准方法——因为 snap 直接与电机推力变化率相关，最小化 snap 意味着最平滑的电机命令。


差分平坦性（Differential Flatness） 是多旋翼轨迹规划和控制的理论基础。四旋翼的平坦输出为 σ=[x,y,z,ψ]T\sigma = [x, y, z, \psi]^Tσ=[x,y,z,ψ]T（三维位置和偏航角），意味着所有状态和输入都可以用平坦输出及其导数表示。这使得轨迹规划可以在平坦输出空间中直接进行，无需考虑复杂的动力学约束。


故障检测与容错控制
多旋翼无人机在飞行中可能遭遇电机故障、螺旋桨损伤、传感器失效等异常情况。故障检测与隔离（FDI）和容错控制（FTC）技术确保在部分硬件失效时仍能安全降落。


电机故障检测 通过监测电机电流、转速反馈和 IMU 异常来判断。当某个电机失效时，飞行器会出现快速旋转和倾斜。基于模型的检测方法比较实际角速度与模型预测值，残差超过阈值则判定故障。


单电机失效的容错控制：四旋翼在丧失一个电机后仍有三个可控自由度——两个平移和一个平移/偏航的组合。通过放弃偏航控制（允许飞行器绕偏航轴旋转），利用剩余三个电机维持姿态稳定和位置控制，实现安全降落。这种"旋转降落"模式已在学术和商业系统中验证。


双电机失效：四旋翼丧失两个对角电机（对角失效）后几乎不可控，但丧失两个相邻电机时仍可通过剩余两个电机实现受控旋转降落。六旋翼和八旋翼由于冗余电机，在单电机甚至双电机失效时仍能保持完全可控。

小结
    

  • 飞行控制分为位置控制（外环）和姿态控制（内环），通过混控器将力矩命令分配到各电机
    • 

  • 四旋翼为欠驱动系统（6 DOF / 4 输入），水平移动必须通过倾斜机体实现
    • 

  • 串级 PID 是最广泛使用的姿态控制方案，非线性方法（Backstepping/SMC/INDI）适用于大机动飞行
    • 

  • 差分平坦性使轨迹规划可在平坦输出空间直接进行，最小 snap 轨迹是标准方法
    • 

  • 容错控制通过放弃偏航自由度实现单电机失效下的安全降落
    • 

  • 冗余设计（六旋翼/八旋翼）和多传感器融合是提升飞行安全性的工程手段
    •
