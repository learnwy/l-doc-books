DH 参数建模

核心概念

Denavit-Hartenberg（DH）参数法是描述串联机器人运动学的标准化方法，由 Jacques Denavit 和 Richard Hartenberg 于 1955 年提出。其核心思想是：用 4 个参数完整描述相邻两个连杆坐标系之间的相对位姿关系，从而将任意复杂的串联机构运动学问题系统化。

DH 参数法的强大之处在于将 6 个自由度的刚体变换（3 个旋转 + 3 个平移）压缩为 4 个参数，这得益于坐标系建立时的两个约束条件：xix_ixi​ 轴垂直于 zi−1z_{i-1}zi−1​ 轴，且 xix_ixi​ 轴与 zi−1z_{i-1}zi−1​ 轴相交。

标准 DH 与改进 DH 的差异
DH 参数法存在两种变体：标准 DH（Classic DH）和改进 DH（Modified DH, Craig Convention）。两者的核心区别在于坐标系附着位置和变换顺序的不同。


标准 DH 将坐标系 {i}\{i\}{i} 附着在连杆 iii 的远端（靠近关节 i+1i+1i+1），变换顺序为：


Tistd=Rotz(θi)⋅Transz(di)⋅Transx(ai)⋅Rotx(αi)T_i^{\text{std}} = Rot_z(\theta_i) \cdot Trans_z(d_i) \cdot Trans_x(a_i) \cdot Rot_x(\alpha_i)Tistd​=Rotz​(θi​)⋅Transz​(di​)⋅Transx​(ai​)⋅Rotx​(αi​)
改进 DH 将坐标系 {i}\{i\}{i} 附着在连杆 iii 的近端（靠近关节 iii），变换顺序为：


Timod=Rotx(αi−1)⋅Transx(ai−1)⋅Rotz(θi)⋅Transz(di)T_i^{\text{mod}} = Rot_x(\alpha_{i-1}) \cdot Trans_x(a_{i-1}) \cdot Rot_z(\theta_i) \cdot Trans_z(d_i)Timod​=Rotx​(αi−1​)⋅Transx​(ai−1​)⋅Rotz​(θi​)⋅Transz​(di​)
import numpy as np

def standard_dh_matrix(theta, d, a, alpha):
    ct, st = np.cos(theta), np.sin(theta)
    ca, sa = np.cos(alpha), np.sin(alpha)
    return np.array([
        [ct, -st * ca,  st * sa, a * ct],
        [st,  ct * ca, -ct * sa, a * st],
        [0,   sa,       ca,      d     ],
        [0,   0,        0,       1     ]
    ])

def modified_dh_matrix(theta, d, a_prev, alpha_prev):
    ct, st = np.cos(theta), np.sin(theta)
    ca, sa = np.cos(alpha_prev), np.sin(alpha_prev)
    return np.array([
        [ct,         -st,        0,   a_prev       ],
        [st * ca,     ct * ca,  -sa, -sa * d       ],
        [st * sa,     ct * sa,   ca,  ca * d       ],
        [0,           0,         0,   1            ]
    ])

坐标系建立规则
正确建立 DH 坐标系是整个建模过程中最容易出错的环节。以下是系统化的坐标系建立步骤：


步骤 1：标记所有关节轴。旋转关节的轴为旋转轴方向，移动关节的轴为滑动方向。将每个关节轴标记为 z0,z1,...,zn−1z_0, z_1, ..., z_{n-1}z0​,z1​,...,zn−1​。


步骤 2：确定原点位置。OiO_iOi​ 位于 ziz_izi​ 轴与 zi−1z_{i-1}zi−1​ 轴的公法线和 ziz_izi​ 轴的交点。若两轴相交，原点在交点处；若两轴平行，原点选择可有一定自由度。


步骤 3：确定 xix_ixi​ 轴方向。xix_ixi​ 沿 zi−1z_{i-1}zi−1​ 到 ziz_izi​ 的公法线方向。若两轴相交，xi=zi−1×zix_i = z_{i-1} \times z_ixi​=zi−1​×zi​；若两轴平行，xix_ixi​ 指向从 zi−1z_{i-1}zi−1​ 到 ziz_izi​ 的方向。


import numpy as np

def build_dh_frames(joint_axes, joint_origins):
    n = len(joint_axes)
    frames = []

    for i in range(n):
        z_prev = joint_axes[i - 1] if i > 0 else np.array([0, 0, 1])
        z_curr = joint_axes[i]

        cross = np.cross(z_prev, z_curr)
        cross_norm = np.linalg.norm(cross)

        if cross_norm > 1e-6:
            x_axis = cross / cross_norm
        else:
            perp = np.array([1, 0, 0]) if abs(z_curr[0]) < 0.9 else np.array([0, 1, 0])
            x_axis = np.cross(z_curr, perp)
            x_axis /= np.linalg.norm(x_axis)

        y_axis = np.cross(z_curr, x_axis)

        R = np.column_stack([x_axis, y_axis, z_curr])
        frames.append({
            'origin': joint_origins[i],
            'rotation': R,
            'z': z_curr,
            'x': x_axis
        })

    return frames

def extract_dh_params(frames):
    params = []
    for i in range(1, len(frames)):
        z_prev = frames[i-1]['z']
        z_curr = frames[i]['z']
        x_curr = frames[i]['x']
        o_prev = frames[i-1]['origin']
        o_curr = frames[i]['origin']

        diff = o_curr - o_prev
        d = np.dot(diff, z_prev)
        a = np.dot(diff, x_curr)

        cos_alpha = np.dot(z_prev, z_curr)
        alpha = np.arccos(np.clip(cos_alpha, -1, 1))

        cos_theta = np.dot(frames[i-1]['x'], x_curr)
        theta = np.arccos(np.clip(cos_theta, -1, 1))

        params.append({
            'theta': theta, 'd': d, 'a': a, 'alpha': alpha
        })

    return params
工业机器人 DH 建模实例
以 UR5e 六轴协作机器人为例，展示完整的 DH 参数建模流程。UR5e 的运动学结构特点是：6 个旋转关节，其中 z1z_1z1​、z2z_2z2​、z3z_3z3​ 平行（肩部-肘部平面），z4z_4z4​、z5z_5z5​ 与前三个轴垂直。


import numpy as np

ur5e_dh_params = [
    {'theta': 0, 'd': 0.1625,  'a': 0,       'alpha': np.pi/2},
    {'theta': 0, 'd': 0,       'a': -0.4250,  'alpha': 0},
    {'theta': 0, 'd': 0,       'a': -0.3922,  'alpha': 0},
    {'theta': 0, 'd': 0.1333,  'a': 0,       'alpha': np.pi/2},
    {'theta': 0, 'd': 0.0997,  'a': 0,       'alpha': -np.pi/2},
    {'theta': 0, 'd': 0.0996,  'a': 0,       'alpha': 0},
]

def ur5e_fk(joint_angles):
    T = np.eye(4)
    for i, params in enumerate(ur5e_dh_params):
        theta = joint_angles[i] + params['theta']
        T = T @ standard_dh_matrix(
            theta, params['d'], params['a'], params['alpha']
        )
    return T

DH 参数标定与误差分析
理论 DH 参数与实际机器人之间存在制造和装配误差，参数标定是缩小这种差距的关键步骤。标定的目标是通过实际测量数据修正 DH 参数，使正运动学模型的预测误差最小化。


import numpy as np
from scipy.optimize import least_squares

def calibration_residual(param_corrections, nominal_params, measurements):
    n_joints = len(nominal_params)
    n_measurements = len(measurements)
    residuals = []

    corrected_params = []
    for i in range(n_joints):
        corrected_params.append({
            'theta': nominal_params[i]['theta'] + param_corrections[4*i],
            'd': nominal_params[i]['d'] + param_corrections[4*i + 1],
            'a': nominal_params[i]['a'] + param_corrections[4*i + 2],
            'alpha': nominal_params[i]['alpha'] + param_corrections[4*i + 3],
        })

    for joint_angles, measured_pos in measurements:
        T = forward_kinematics_from_params(corrected_params, joint_angles)
        predicted_pos = T[:3, 3]
        residuals.extend(predicted_pos - measured_pos)

    return np.array(residuals)

def calibrate_robot(nominal_params, measurements):
    n_params = 4 * len(nominal_params)
    x0 = np.zeros(n_params)

    result = least_squares(
        calibration_residual,
        x0,
        args=(nominal_params, measurements),
        method='lm',
        ftol=1e-12,
        xtol=1e-12
    )

    corrections = result.x.reshape(-1, 4)
    print(f"标定残差 RMS: {np.sqrt(np.mean(result.fun**2))*1000:.4f} mm")

    return corrections, result

小结
    

  • DH 参数法用 4 个参数完整描述相邻连杆间的位姿关系，是串联机器人运动学建模的标准方法
    • 

  • 标准 DH 和改进 DH 的核心区别在于坐标系附着位置，改进 DH 与 ROS/URDF 兼容性更好
    • 

  • 坐标系建立遵循严格的规则：zzz 轴沿关节轴，xxx 轴沿公法线方向
    • 

  • 工业机器人（如 UR5e）的 DH 参数可直接从产品手册获取，但需注意约定差异
    • 

  • 参数标定通过最小二乘优化修正制造误差，可将定位精度提升一个数量级
    • 

  • DH 模型的局限在于无法直接处理柔性连杆和关节间隙等非刚体效应
    •
