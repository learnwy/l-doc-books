回环检测

核心概念

回环检测（Loop Closure Detection）是 SLAM 系统中消除累积漂移的关键技术。当机器人重新访问已探索过的区域时，回环检测通过识别这一事件，建立当前观测与历史观测之间的约束关系，从而全局校正轨迹和地图。没有回环检测的 SLAM 系统会随时间推移产生不可控的累积误差，导致地图前后不一致。

回环检测的核心挑战在于：如何在大规模场景中高效、准确地判断当前位置是否曾经到访过，同时避免错误的回环匹配导致地图崩溃。

视觉词袋模型
视觉词袋（Bag of Words, BoW）是最经典的回环检测方法，借鉴了自然语言处理中的文档检索思想。其核心是将图像中的视觉特征量化为离散的"视觉单词"，用单词的分布描述图像，通过比较分布的相似性判断回环。


词汇树（Vocabulary Tree）的构建流程如下：首先从大量训练图像中提取局部特征描述子（如 ORB、BRIEF），然后使用层次化 K-Means 聚类将描述子空间划分为树状结构。查询时，每个特征描述子沿树逐层下降到叶节点，叶节点即为视觉单词。


import numpy as np
from sklearn.cluster import KMeans

class VocabularyTree:
    def __init__(self, branch_factor=10, depth=6):
        self.branch_factor = branch_factor
        self.depth = depth
        self.nodes = {}

    def build(self, descriptors, level=0, node_id=0):
        if level >= self.depth or len(descriptors) < self.branch_factor:
            self.nodes[node_id] = {'leaf': True, 'weight': 0.0}
            return

        kmeans = KMeans(n_clusters=self.branch_factor, max_iter=100)
        labels = kmeans.fit_predict(descriptors)
        self.nodes[node_id] = {
            'leaf': False,
            'centers': kmeans.cluster_centers_
        }

        for i in range(self.branch_factor):
            child_id = node_id * self.branch_factor + i + 1
            child_desc = descriptors[labels == i]
            if len(child_desc) > 0:
                self.build(child_desc, level + 1, child_id)

    def transform(self, descriptors):
        bow_vector = {}
        for desc in descriptors:
            word_id = self._descend(desc, 0)
            bow_vector[word_id] = bow_vector.get(word_id, 0) + 1
        return bow_vector

    def _descend(self, descriptor, node_id):
        node = self.nodes.get(node_id)
        if node is None or node.get('leaf'):
            return node_id
        centers = node['centers']
        dists = np.linalg.norm(centers - descriptor, axis=1)
        best = np.argmin(dists)
        child_id = node_id * self.branch_factor + best + 1
        return self._descend(descriptor, child_id)
TF-IDF 加权在 BoW 回环检测中至关重要。TF（词频）衡量某个视觉单词在当前图像中的出现频率，IDF（逆文档频率）衡量该单词在所有图像中的区分度。高频且低区分度的单词（如地面纹理）权重被降低，而稀有且有辨识力的单词（如独特标志物）权重被提升。


DBoW2/DBoW3 库是 SLAM 社区广泛使用的实现，ORB-SLAM 系列正是基于 DBoW2 进行回环检测。它引入了直接索引（Direct Index）和逆向索引（Inverse Index）双重索引结构：逆向索引用于快速检索相似图像，直接索引用于加速特征匹配的几何验证。


基于学习的场景识别
近年来，深度学习方法在场景识别领域展现出超越传统 BoW 的性能，尤其在外观变化剧烈的场景下（光照变化、季节变化、视角变化）。


NetVLAD 是一种端到端的场景识别网络，它将 VLAD（Vector of Locally Aggregated Descriptors）编码过程嵌入到 CNN 中，通过可微的软分配替代硬分配，实现端到端训练。其架构包括 CNN 特征提取骨干网（如 VGG-16）和 NetVLAD 聚合层，输出一个紧凑的全局描述子。


import torch
import torch.nn as nn
import torch.nn.functional as F

class NetVLADLayer(nn.Module):
    def __init__(self, feature_dim, num_clusters=64):
        super().__init__()
        self.num_clusters = num_clusters
        self.conv = nn.Conv2d(feature_dim, num_clusters, kernel_size=1, bias=True)
        self.centroids = nn.Parameter(torch.randn(num_clusters, feature_dim))

    def forward(self, x):
        N, C, H, W = x.shape
        soft_assign = self.conv(x)
        soft_assign = F.softmax(soft_assign.view(N, self.num_clusters, -1), dim=2)

        x_flat = x.view(N, C, -1)
        vlad = torch.zeros(N, self.num_clusters, C, device=x.device)

        for k in range(self.num_clusters):
            residual = x_flat - self.centroids[k].unsqueeze(0).unsqueeze(2)
            weighted = soft_assign[:, k:k+1, :] * residual
            vlad[:, k, :] = weighted.sum(dim=2)

        vlad = F.normalize(vlad.view(N, -1), p=2, dim=1)
        return vlad

几何验证与一致性检查
候选回环仅通过外观相似性筛选是不够的，必须经过严格的几何验证才能被接受。错误的回环（False Positive）会向图优化注入错误约束，导致地图严重扭曲甚至崩溃，因此几何验证是回环检测的安全屏障。


几何验证的标准流程包括三个步骤：


第一步是特征匹配。在候选回环帧对之间进行特征匹配，获取初始匹配点对集合。使用互最近邻（Mutual Nearest Neighbor）策略并加上比率检验（Lowe's Ratio Test）可以过滤大量错误匹配。


第二步是 RANSAC 几何估计。对匹配点对使用 RANSAC 算法估计基础矩阵或本质矩阵。如果内点数量超过阈值，则认为几何验证通过。


import cv2
import numpy as np

def geometric_verification(kp1, kp2, matches, min_inliers=30):
    pts1 = np.float32([kp1[m.queryIdx].pt for m in matches])
    pts2 = np.float32([kp2[m.trainIdx].pt for m in matches])

    if len(pts1) < 8:
        return False, None, 0

    F, mask = cv2.findFundamentalMat(pts1, pts2, cv2.FM_RANSAC, 3.0, 0.99)

    if mask is None:
        return False, None, 0

    inlier_count = int(mask.sum())
    inlier_ratio = inlier_count / len(matches)

    passed = inlier_count >= min_inliers and inlier_ratio > 0.3
    return passed, F, inlier_count


def temporal_consistency_check(candidates, window_size=3):
    verified = []
    for i, cand in enumerate(candidates):
        start = max(0, i - window_size)
        end = min(len(candidates), i + window_size + 1)
        neighbors = candidates[start:end]

        consistent_count = sum(
            1 for n in neighbors
            if abs(n['target_frame'] - cand['target_frame']) < 10
        )

        if consistent_count >= window_size:
            verified.append(cand)
    return verified
第三步是时间一致性检查。单帧回环检测可能存在噪声，因此通常要求连续多帧都检测到相似区域的回环候选，才最终确认回环。ORB-SLAM2 使用连续三帧一致性检查策略，有效避免了偶发的错误检测。


对于 LiDAR 回环，几何验证通常使用 ICP（Iterative Closest Point）或 NDT（Normal Distributions Transform）对候选点云进行配准，若配准的收敛误差低于阈值则验证通过。Scan Context 是一种针对 LiDAR 的场景描述子，它将点云投影到极坐标 bin 中，以最大高度作为描述，不依赖特征匹配即可实现快速回环检索。


回环检测在大规模场景中的挑战
大规模场景（城市级别、数百公里轨迹）对回环检测提出了更严格的要求。随着数据库规模增长，检索效率、存储开销和感知别名（Perceptual Aliasing）问题都会显著加剧。


感知别名是指不同位置具有极其相似的外观特征，导致系统误判为同一位置。城市环境中重复的建筑立面、道路标线是典型的感知别名来源。应对策略包括多模态融合（视觉+LiDAR）、序列匹配（SeqSLAM 方法比较图像序列而非单帧）和几何一致性验证的多重过滤。


层次化检索策略可以在保持精度的同时提升效率。先使用轻量级全局描述子（如 BoW 分数）快速缩小候选范围，再对 Top-K 候选使用精确的局部特征匹配和几何验证。增量式索引技术（如 HNSW 图索引）支持在线插入新数据，适合持续运行的 SLAM 系统。

SeqSLAM 方法不依赖单帧匹配，而是比较连续图像序列的相似性矩阵，通过寻找矩阵中的最优路径来检测回环。这种方法在极端外观变化下（如白天 vs 夜晚）仍能保持较高的召回率，但计算复杂度较高，需要结合预筛选策略使用。


小结
    

  • 回环检测是 SLAM 系统消除累积漂移、保证全局一致性的核心组件
    • 

  • 视觉词袋（BoW）方法成熟高效，DBoW2/DBoW3 是当前工程实践的主流选择
    • 

  • 深度学习方法（NetVLAD、PointNetVLAD）在外观剧烈变化场景下表现更优
    • 

  • 几何验证（RANSAC + 时间一致性）是防止错误回环的关键安全机制
    • 

  • 大规模场景需要层次化检索、序列匹配和多模态融合等综合策略
    • 

  • 回环检测的精确率必须极高（> 99%），因为一个错误回环可能破坏整张地图
    • 

  • LiDAR 回环检测不受光照影响，Scan Context 等方法提供了高效的点云场景识别能力
    •
