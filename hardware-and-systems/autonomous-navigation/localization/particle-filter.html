粒子滤波

核心概念

粒子滤波（Particle Filter, PF），也称为蒙特卡洛定位（Monte Carlo Localization, MCL），是一种基于序贯蒙特卡洛采样的非参数状态估计方法。与卡尔曼滤波家族假设高斯分布不同，粒子滤波能够表示任意形状的概率分布，适用于高度非线性、非高斯噪声和多峰分布的场景。

粒子滤波的核心思想是用一组带权重的随机样本（粒子）来逼近后验概率分布。每个粒子代表状态空间中的一个假设，粒子的权重反映该假设与实际观测的吻合程度。通过迭代地预测、加权和重采样，粒子群逐渐聚集到真实状态附近。

标准粒子滤波与蒙特卡洛定位
蒙特卡洛定位（MCL）是粒子滤波在移动机器人定位中的经典应用。机器人的状态通常为 (x, y, θ)，粒子均匀分布在可能的状态空间中。随着机器人运动和观测，粒子逐步收敛到机器人的真实位置。


MCL 的三个核心步骤：采样（根据运动模型生成新粒子）、加权（根据传感器模型计算每个粒子的权重）、重采样（淘汰低权重粒子，复制高权重粒子）。


import numpy as np

class ParticleFilter:
    def __init__(self, num_particles, state_bounds, sensor_model):
        self.N = num_particles
        self.sensor_model = sensor_model
        self.particles = np.random.uniform(
            state_bounds[:, 0], state_bounds[:, 1],
            size=(num_particles, len(state_bounds))
        )
        self.weights = np.ones(num_particles) / num_particles

    def predict(self, control, noise_std):
        v, omega, dt = control
        theta = self.particles[:, 2]

        noise = np.random.randn(self.N, 3) * noise_std

        if abs(omega) < 1e-6:
            self.particles[:, 0] += (v * np.cos(theta) * dt + noise[:, 0])
            self.particles[:, 1] += (v * np.sin(theta) * dt + noise[:, 1])
            self.particles[:, 2] += noise[:, 2]
        else:
            r = v / omega
            self.particles[:, 0] += (r * (np.sin(theta + omega*dt) - np.sin(theta)) + noise[:, 0])
            self.particles[:, 1] += (r * (np.cos(theta) - np.cos(theta + omega*dt)) + noise[:, 1])
            self.particles[:, 2] += (omega * dt + noise[:, 2])

        self.particles[:, 2] = np.arctan2(
            np.sin(self.particles[:, 2]),
            np.cos(self.particles[:, 2])
        )

    def update(self, observation):
        for i in range(self.N):
            self.weights[i] = self.sensor_model(self.particles[i], observation)

        weight_sum = np.sum(self.weights)
        if weight_sum > 0:
            self.weights /= weight_sum
        else:
            self.weights = np.ones(self.N) / self.N

    def resample(self):
        n_eff = 1.0 / np.sum(self.weights ** 2)
        if n_eff < self.N * 0.5:
            indices = self._systematic_resample()
            self.particles = self.particles[indices]
            self.weights = np.ones(self.N) / self.N

    def _systematic_resample(self):
        cumsum = np.cumsum(self.weights)
        positions = (np.arange(self.N) + np.random.random()) / self.N
        indices = np.searchsorted(cumsum, positions)
        return np.clip(indices, 0, self.N - 1)

    def estimate(self):
        mean = np.average(self.particles, weights=self.weights, axis=0)
        diff = self.particles - mean
        cov = np.average(diff[:, :, None] * diff[:, None, :],
                        weights=self.weights, axis=0)
        return mean, cov

    def step(self, control, observation, noise_std):
        self.predict(control, noise_std)
        self.update(observation)
        self.resample()
        return self.estimate()
系统重采样（Systematic Resampling）是最常用的重采样算法，它在 O(N) 时间内完成，且比随机重采样的方差更低。其思想是在 [0, 1] 区间上等间隔放置 N 个采样点，只使用一个随机偏移量。


有效粒子数（Effective Sample Size, N_eff）用于判断是否需要重采样。当大量粒子的权重很小、少数粒子权重很大时，N_eff 下降，说明粒子退化严重，需要重采样。自适应重采样策略仅在 N_eff 低于阈值时触发，避免不必要的粒子多样性损失。


高级粒子滤波技术
标准粒子滤波在实际应用中面临两个主要问题：粒子退化（Particle Degeneracy）和采样不足（Sample Impoverishment）。高级技术通过改进采样策略和重采样方法来缓解这些问题。


自适应粒子滤波（KLD-Sampling）根据后验分布的复杂度动态调整粒子数量。当机器人位置不确定时（如初始化阶段）使用大量粒子，位置确定后减少粒子数量节省计算。KLD-Sampling 基于 Kullback-Leibler 散度确保有限粒子数下的近似精度。


import numpy as np

class AdaptiveParticleFilter:
    def __init__(self, min_particles, max_particles, state_bounds, sensor_model,
                 kld_epsilon=0.05, kld_z=2.326):
        self.min_N = min_particles
        self.max_N = max_particles
        self.state_bounds = state_bounds
        self.sensor_model = sensor_model
        self.kld_epsilon = kld_epsilon
        self.kld_z = kld_z

        self.resolution = np.array([0.5, 0.5, np.pi/6])
        self.N = max_particles
        self.particles = np.random.uniform(
            state_bounds[:, 0], state_bounds[:, 1],
            size=(self.N, len(state_bounds))
        )
        self.weights = np.ones(self.N) / self.N

    def adaptive_resample(self, observation):
        occupied_bins = set()
        new_particles = []
        cumsum = np.cumsum(self.weights)

        target_N = self.max_N

        while len(new_particles) < target_N:
            r = np.random.random()
            idx = np.searchsorted(cumsum, r)
            idx = min(idx, self.N - 1)

            particle = self.particles[idx].copy()
            particle += np.random.randn(len(particle)) * 0.01
            new_particles.append(particle)

            bin_idx = tuple((particle / self.resolution).astype(int))
            if bin_idx not in occupied_bins:
                occupied_bins.add(bin_idx)
                k = len(occupied_bins)
                if k > 1:
                    target_N = min(
                        self.max_N,
                        max(self.min_N, int(
                            (k - 1) / (2 * self.kld_epsilon) *
                            (1 - 2/(9*(k-1)) + self.kld_z * np.sqrt(2/(9*(k-1))))**3
                        ))
                    )

            if len(new_particles) >= target_N:
                break

        self.N = len(new_particles)
        self.particles = np.array(new_particles)
        self.weights = np.ones(self.N) / self.N


class AugmentedMCL:
    def __init__(self, num_particles, state_bounds, sensor_model,
                 alpha_slow=0.001, alpha_fast=0.1):
        self.pf = ParticleFilter(num_particles, state_bounds, sensor_model)
        self.state_bounds = state_bounds
        self.w_slow = 0.0
        self.w_fast = 0.0
        self.alpha_slow = alpha_slow
        self.alpha_fast = alpha_fast

    def step(self, control, observation, noise_std):
        self.pf.predict(control, noise_std)
        self.pf.update(observation)

        w_avg = np.mean(self.pf.weights)
        self.w_slow += self.alpha_slow * (w_avg - self.w_slow)
        self.w_fast += self.alpha_fast * (w_avg - self.w_fast)

        random_ratio = max(0.0, 1.0 - self.w_fast / (self.w_slow + 1e-10))

        n_random = int(random_ratio * self.pf.N)
        if n_random > 0:
            random_particles = np.random.uniform(
                self.state_bounds[:, 0], self.state_bounds[:, 1],
                size=(n_random, len(self.state_bounds))
            )
            self.pf.resample()
            self.pf.particles[:n_random] = random_particles

        else:
            self.pf.resample()

        return self.pf.estimate()
Augmented MCL（增强蒙特卡洛定位）解决了机器人被绑架（Kidnapped Robot Problem）的问题。它通过跟踪平均观测似然的短期和长期趋势，当短期似然显著低于长期时（说明粒子群与实际位置偏离），自动注入随机粒子到状态空间中，使机器人能够在被移动后重新定位。


Rao-Blackwellized 粒子滤波
Rao-Blackwellized 粒子滤波（RBPF）是粒子滤波在 SLAM 中的核心应用，也称为 FastSLAM。RBPF 的关键洞察是：SLAM 问题可以分解为定位问题和地图构建问题，如果机器人位置已知，地图构建问题的各路标是条件独立的。


RBPF 的每个粒子不仅包含一个位置假设，还维护一个独立的地图估计。由于利用了条件独立性，每个路标用一个小型 EKF（2×2 或 3×3）独立维护，避免了维护完整的 SLAM 协方差矩阵（O(n²) 存储和 O(n³) 更新，n 为路标数）。


import numpy as np

class FastSLAMParticle:
    def __init__(self, state, n_landmarks):
        self.state = state.copy()
        self.weight = 1.0
        self.landmarks = [
            {'mean': None, 'cov': None, 'observed': False}
            for _ in range(n_landmarks)
        ]

    def observe_landmark(self, landmark_id, measurement, R):
        lm = self.landmarks[landmark_id]

        if not lm['observed']:
            x, y, theta = self.state
            r, bearing = measurement
            lm['mean'] = np.array([
                x + r * np.cos(theta + bearing),
                y + r * np.sin(theta + bearing)
            ])
            H = self._observation_jacobian(lm['mean'])
            lm['cov'] = np.linalg.inv(H) @ R @ np.linalg.inv(H).T
            lm['observed'] = True
            self.weight = 1.0
        else:
            z_pred = self._predict_observation(lm['mean'])
            H = self._observation_jacobian(lm['mean'])
            Q = H @ lm['cov'] @ H.T + R
            innovation = measurement - z_pred
            innovation[1] = np.arctan2(np.sin(innovation[1]), np.cos(innovation[1]))

            K = lm['cov'] @ H.T @ np.linalg.inv(Q)
            lm['mean'] = lm['mean'] + K @ innovation
            lm['cov'] = (np.eye(2) - K @ H) @ lm['cov']

            self.weight = np.exp(-0.5 * innovation @ np.linalg.inv(Q) @ innovation) / \
                         np.sqrt(np.linalg.det(2 * np.pi * Q))

    def _predict_observation(self, landmark_pos):
        dx = landmark_pos[0] - self.state[0]
        dy = landmark_pos[1] - self.state[1]
        r = np.sqrt(dx**2 + dy**2)
        bearing = np.arctan2(dy, dx) - self.state[2]
        return np.array([r, bearing])

    def _observation_jacobian(self, landmark_pos):
        dx = landmark_pos[0] - self.state[0]
        dy = landmark_pos[1] - self.state[1]
        q = dx**2 + dy**2
        sq = np.sqrt(q)
        return np.array([
            [dx/sq, dy/sq],
            [-dy/q, dx/q]
        ])
FastSLAM 2.0 进一步改进了采样策略：在对粒子进行运动模型采样时，同时利用当前的观测信息（而不仅是运动模型）。这种改进使得新粒子位置更接近高似然区域，显著减少了所需的粒子数量。GMapping 是 FastSLAM 在 ROS 中的经典实现，使用 RBPF 结合激光雷达构建二维栅格地图。


小结
    

  • 粒子滤波能表示任意概率分布，适用于非线性、非高斯、多峰分布场景
    • 

  • 蒙特卡洛定位（MCL）是粒子滤波在机器人定位中的经典应用
    • 

  • 重采样是粒子滤波的关键步骤，系统重采样在效率和方差间取得最佳平衡
    • 

  • KLD-Sampling 根据后验复杂度自适应调整粒子数量，提升计算效率
    • 

  • Augmented MCL 通过注入随机粒子解决机器人绑架问题
    • 

  • RBPF（FastSLAM）利用条件独立性分解 SLAM 问题，每个粒子独立维护地图
    • 

  • 粒子滤波的主要局限是维度灾难——在高维状态空间中需要指数级粒子数
