卡尔曼滤波

核心概念

卡尔曼滤波（Kalman Filter, KF）是机器人定位中最基本也是最重要的状态估计算法。它提供了一种最优的递归方法，在存在过程噪声和观测噪声的情况下，融合系统运动模型的预测和传感器的观测，估计系统的真实状态。卡尔曼滤波在数学上被证明是线性高斯系统下的最小方差无偏估计器。

卡尔曼滤波的工作过程分为两步：预测步骤利用运动模型将上一时刻的状态估计传播到当前时刻，更新步骤利用传感器观测修正预测结果。两步交替执行，持续产生最优的状态估计。

标准卡尔曼滤波
标准卡尔曼滤波适用于线性动态系统。系统的状态转移和观测模型都是线性的，噪声服从高斯分布。在这些假设下，卡尔曼滤波给出的估计在所有线性无偏估计器中方差最小。


系统模型表述为：状态转移方程 xk = F·x{k-1} + B·u_k + w_k，观测方程 z_k = H·x_k + v_k。其中 w_k ~ N(0, Q) 是过程噪声，v_k ~ N(0, R) 是观测噪声。


import numpy as np

class KalmanFilter:
    def __init__(self, dim_x, dim_z):
        self.dim_x = dim_x
        self.dim_z = dim_z
        self.x = np.zeros(dim_x)
        self.P = np.eye(dim_x)
        self.F = np.eye(dim_x)
        self.H = np.zeros((dim_z, dim_x))
        self.Q = np.eye(dim_x) * 0.01
        self.R = np.eye(dim_z) * 0.1
        self.B = np.zeros((dim_x, 1))

    def predict(self, u=None):
        self.x = self.F @ self.x
        if u is not None:
            self.x += self.B @ u
        self.P = self.F @ self.P @ self.F.T + self.Q

    def update(self, z):
        y = z - self.H @ self.x
        S = self.H @ self.P @ self.H.T + self.R
        K = self.P @ self.H.T @ np.linalg.inv(S)
        self.x = self.x + K @ y
        I = np.eye(self.dim_x)
        self.P = (I - K @ self.H) @ self.P @ (I - K @ self.H).T + K @ self.R @ K.T

    def log_likelihood(self, z):
        y = z - self.H @ self.x
        S = self.H @ self.P @ self.H.T + self.R
        return -0.5 * (y @ np.linalg.inv(S) @ y + np.log(np.linalg.det(S)) +
                       self.dim_z * np.log(2 * np.pi))
卡尔曼增益 K 是滤波器的核心参数，它自动权衡模型预测和传感器观测的可信度。当观测噪声 R 较大时（传感器不可靠），K 变小，滤波器更相信模型预测；当过程噪声 Q 较大时（模型不精确），K 变大，滤波器更相信传感器观测。


一个实际的例子：一维匀速运动的目标跟踪。状态向量包含位置和速度 x = [p, v]ᵀ，状态转移矩阵 F = [[1, dt], [0, 1]]，观测矩阵 H = [[1, 0]]（只能观测位置）。卡尔曼滤波不仅能估计当前位置，还能估计不可直接观测的速度。


扩展卡尔曼滤波
扩展卡尔曼滤波（Extended Kalman Filter, EKF）将标准卡尔曼滤波推广到非线性系统。现实中绝大多数机器人系统是非线性的——旋转运动、传感器模型（如激光雷达的极坐标到笛卡尔坐标转换）都涉及非线性函数。


EKF 的核心思想是在当前状态估计点对非线性函数进行一阶 Taylor 展开（线性化），然后在线性化的系统上应用标准卡尔曼滤波。线性化通过计算 Jacobian 矩阵实现：Fk = ∂f/∂x|{x=x̂k}，H_k = ∂h/∂x|{x=x̂_k}。


import numpy as np

class ExtendedKalmanFilter:
    def __init__(self, dim_x, dim_z):
        self.dim_x = dim_x
        self.dim_z = dim_z
        self.x = np.zeros(dim_x)
        self.P = np.eye(dim_x)
        self.Q = np.eye(dim_x) * 0.01
        self.R = np.eye(dim_z) * 0.1

    def predict(self, f_func, F_jacobian, u=None):
        self.x = f_func(self.x, u)
        F = F_jacobian(self.x, u)
        self.P = F @ self.P @ F.T + self.Q

    def update(self, z, h_func, H_jacobian):
        z_pred = h_func(self.x)
        H = H_jacobian(self.x)
        y = z - z_pred
        S = H @ self.P @ H.T + self.R
        K = self.P @ H.T @ np.linalg.inv(S)
        self.x = self.x + K @ y
        I = np.eye(self.dim_x)
        self.P = (I - K @ H) @ self.P


class RobotEKF(ExtendedKalmanFilter):
    def __init__(self):
        super().__init__(dim_x=3, dim_z=2)

    def motion_model(self, x, u):
        v, omega = u[0], u[1]
        dt = u[2] if len(u) > 2 else 0.1
        theta = x[2]
        if abs(omega) < 1e-6:
            return x + np.array([v * np.cos(theta) * dt,
                                v * np.sin(theta) * dt,
                                0.0])
        return x + np.array([
            v / omega * (np.sin(theta + omega * dt) - np.sin(theta)),
            v / omega * (np.cos(theta) - np.cos(theta + omega * dt)),
            omega * dt
        ])

    def motion_jacobian(self, x, u):
        v, omega = u[0], u[1]
        dt = u[2] if len(u) > 2 else 0.1
        theta = x[2]
        F = np.eye(3)
        if abs(omega) < 1e-6:
            F[0, 2] = -v * np.sin(theta) * dt
            F[1, 2] = v * np.cos(theta) * dt
        else:
            F[0, 2] = v / omega * (np.cos(theta + omega * dt) - np.cos(theta))
            F[1, 2] = v / omega * (np.sin(theta + omega * dt) - np.sin(theta))
        return F

    def observation_model(self, x):
        return np.array([x[0], x[1]])

    def observation_jacobian(self, x):
        H = np.zeros((2, 3))
        H[0, 0] = 1.0
        H[1, 1] = 1.0
        return H

    def step(self, u, z):
        self.predict(self.motion_model, self.motion_jacobian, u)
        self.update(z, self.observation_model, self.observation_jacobian)
        return self.x.copy(), self.P.copy()
EKF 的局限性在于线性化引入的近似误差。当系统高度非线性或状态估计误差较大时，一阶线性化的精度可能不足。此外，EKF 假设线性化后的状态分布仍然是高斯的，这在强非线性情况下不成立。


无迹卡尔曼滤波
无迹卡尔曼滤波（Unscented Kalman Filter, UKF）是 EKF 的替代方案，它避免了显式的 Jacobian 计算。UKF 的核心思想是"近似概率分布比近似非线性函数更容易"——通过一组精心选取的 Sigma 点来捕捉高斯分布的统计特征，将这些点通过非线性函数传播后重新估计统计量。


UKF 使用 2n+1 个 Sigma 点（n 为状态维度），每个点都通过非线性函数传播。传播后的点通过加权平均重建均值和协方差。这种方法能够捕捉到非线性变换对分布的二阶效应，精度优于 EKF 的一阶近似。


import numpy as np

class UnscentedKalmanFilter:
    def __init__(self, dim_x, dim_z, alpha=1e-3, beta=2.0, kappa=0.0):
        self.dim_x = dim_x
        self.dim_z = dim_z
        self.x = np.zeros(dim_x)
        self.P = np.eye(dim_x)
        self.Q = np.eye(dim_x) * 0.01
        self.R = np.eye(dim_z) * 0.1

        self.alpha = alpha
        self.beta = beta
        self.kappa = kappa
        self.lam = alpha**2 * (dim_x + kappa) - dim_x
        self.n_sigma = 2 * dim_x + 1

        self.Wm = np.full(self.n_sigma, 1.0 / (2 * (dim_x + self.lam)))
        self.Wc = np.full(self.n_sigma, 1.0 / (2 * (dim_x + self.lam)))
        self.Wm[0] = self.lam / (dim_x + self.lam)
        self.Wc[0] = self.lam / (dim_x + self.lam) + (1 - alpha**2 + beta)

    def _sigma_points(self, x, P):
        n = self.dim_x
        sigma_pts = np.zeros((self.n_sigma, n))
        sqrt_P = np.linalg.cholesky((n + self.lam) * P)

        sigma_pts[0] = x
        for i in range(n):
            sigma_pts[i + 1] = x + sqrt_P[i]
            sigma_pts[n + i + 1] = x - sqrt_P[i]
        return sigma_pts

    def predict(self, f_func, u=None):
        sigma_pts = self._sigma_points(self.x, self.P)
        propagated = np.array([f_func(sp, u) for sp in sigma_pts])

        self.x = np.sum(self.Wm[:, None] * propagated, axis=0)
        self.P = self.Q.copy()
        for i in range(self.n_sigma):
            diff = propagated[i] - self.x
            self.P += self.Wc[i] * np.outer(diff, diff)

        self._propagated_sigma = propagated

    def update(self, z, h_func):
        sigma_pts = self._sigma_points(self.x, self.P)
        z_sigma = np.array([h_func(sp) for sp in sigma_pts])

        z_mean = np.sum(self.Wm[:, None] * z_sigma, axis=0)

        Pzz = self.R.copy()
        Pxz = np.zeros((self.dim_x, self.dim_z))
        for i in range(self.n_sigma):
            dz = z_sigma[i] - z_mean
            dx = sigma_pts[i] - self.x
            Pzz += self.Wc[i] * np.outer(dz, dz)
            Pxz += self.Wc[i] * np.outer(dx, dz)

        K = Pxz @ np.linalg.inv(Pzz)
        self.x = self.x + K @ (z - z_mean)
        self.P = self.P - K @ Pzz @ K.T
UKF 相比 EKF 的优势在于：不需要计算 Jacobian 矩阵（适用于难以求导的系统）、对非线性系统的近似精度更高（二阶 vs 一阶）、数值稳定性更好。缺点是 Sigma 点的数量随状态维度线性增长（2n+1），在高维系统中计算量增加。


误差状态卡尔曼滤波（Error State Kalman Filter, ESKF）是 EKF 在惯性导航中的特殊变体。ESKF 不直接估计完整状态，而是估计名义状态与真实状态之间的误差。由于误差通常很小，线性化的近似精度更高。ESKF 特别适合处理旋转状态——它在切空间（李代数）上进行滤波，避免了欧拉角万向锁和四元数归一化问题。


小结
    

  • 卡尔曼滤波是机器人定位的基石算法，提供了线性高斯系统下的最优状态估计
    • 

  • 标准 KF 适用于线性系统，EKF 通过 Jacobian 线性化扩展到非线性系统
    • 

  • UKF 通过 Sigma 点采样避免了显式 Jacobian 计算，精度优于 EKF 的一阶近似
    • 

  • 卡尔曼增益自动权衡模型预测和传感器观测的可信度
    • 

  • ESKF 在误差空间上滤波，适合惯性导航中的旋转状态估计
    • 

  • 所有 KF 变体都假设高斯噪声分布，对于非高斯噪声需要粒子滤波等方法
    • 

  • 实际系统中 EKF 仍是最广泛使用的方法，UKF 在强非线性场景下优势明显
    •
