避障技术

核心概念

避障（Obstacle Avoidance）是自主导航中保障机器人安全的关键技术。机器人在运动过程中需要实时感知周围环境中的障碍物，并快速调整运动策略以避免碰撞。与全局路径规划不同，避障强调实时性和反应速度，通常在局部范围内基于传感器数据做出决策。

避障系统的设计需要在安全性、效率和平滑性之间取得平衡。过于保守的策略会导致机器人频繁停止或绕行过远，过于激进的策略则可能导致碰撞。现代避障系统通常采用分层架构，结合反应式方法和预测式方法。

动态窗口法
动态窗口法（Dynamic Window Approach, DWA）是移动机器人最流行的局部避障方法之一，被 ROS Navigation Stack 作为默认的局部规划器。DWA 的核心思想是：在机器人当前速度附近的可达速度空间中搜索最优速度指令。


DWA 的工作流程分三步：首先根据机器人当前速度和加速度限制确定动态窗口（一个速度区间），然后对窗口内的速度进行离散化采样，对每个候选速度模拟短期轨迹（通常 1-2 秒），最后通过目标函数评估每条轨迹的质量。


import numpy as np

class DWAPlanner:
    def __init__(self, config):
        self.max_speed = config.get('max_speed', 0.5)
        self.min_speed = config.get('min_speed', 0.0)
        self.max_yaw_rate = config.get('max_yaw_rate', 1.0)
        self.max_accel = config.get('max_accel', 0.5)
        self.max_yaw_accel = config.get('max_yaw_accel', 2.0)
        self.v_resolution = config.get('v_resolution', 0.01)
        self.yaw_resolution = config.get('yaw_resolution', 0.02)
        self.predict_time = config.get('predict_time', 1.5)
        self.dt = config.get('dt', 0.1)
        self.heading_weight = config.get('heading_weight', 1.0)
        self.dist_weight = config.get('dist_weight', 1.0)
        self.velocity_weight = config.get('velocity_weight', 0.5)
        self.robot_radius = config.get('robot_radius', 0.3)

    def plan(self, state, goal, obstacles):
        dynamic_window = self._calc_dynamic_window(state)
        best_u = np.array([0.0, 0.0])
        best_cost = -float('inf')
        best_trajectory = None

        v_min, v_max, w_min, w_max = dynamic_window

        for v in np.arange(v_min, v_max, self.v_resolution):
            for w in np.arange(w_min, w_max, self.yaw_resolution):
                trajectory = self._predict_trajectory(state, v, w)

                heading_cost = self._heading_cost(trajectory, goal)
                dist_cost = self._obstacle_cost(trajectory, obstacles)
                velocity_cost = abs(v) / self.max_speed

                if dist_cost == float('-inf'):
                    continue

                total_cost = (self.heading_weight * heading_cost +
                            self.dist_weight * dist_cost +
                            self.velocity_weight * velocity_cost)

                if total_cost > best_cost:
                    best_cost = total_cost
                    best_u = np.array([v, w])
                    best_trajectory = trajectory

        return best_u, best_trajectory

    def _calc_dynamic_window(self, state):
        v, w = state[3], state[4]
        vs = [self.min_speed, self.max_speed, -self.max_yaw_rate, self.max_yaw_rate]
        vd = [v - self.max_accel * self.dt, v + self.max_accel * self.dt,
              w - self.max_yaw_accel * self.dt, w + self.max_yaw_accel * self.dt]
        return [max(vs[0], vd[0]), min(vs[1], vd[1]),
                max(vs[2], vd[2]), min(vs[3], vd[3])]

    def _predict_trajectory(self, state, v, w):
        trajectory = [state.copy()]
        curr = state.copy()
        for _ in np.arange(0, self.predict_time, self.dt):
            curr = self._motion_model(curr, v, w)
            trajectory.append(curr.copy())
        return np.array(trajectory)

    def _motion_model(self, state, v, w):
        x, y, yaw = state[0], state[1], state[2]
        x += v * np.cos(yaw) * self.dt
        y += v * np.sin(yaw) * self.dt
        yaw += w * self.dt
        return np.array([x, y, yaw, v, w])

    def _heading_cost(self, trajectory, goal):
        dx = goal[0] - trajectory[-1, 0]
        dy = goal[1] - trajectory[-1, 1]
        goal_angle = np.arctan2(dy, dx)
        cost = np.pi - abs(trajectory[-1, 2] - goal_angle)
        return cost

    def _obstacle_cost(self, trajectory, obstacles):
        min_dist = float('inf')
        for point in trajectory:
            for obs in obstacles:
                dist = np.sqrt((point[0]-obs[0])**2 + (point[1]-obs[1])**2)
                if dist <= self.robot_radius:
                    return float('-inf')
                min_dist = min(min_dist, dist)
        return min_dist
DWA 的目标函数通常由三部分加权组成：朝向目标的角度偏差（heading）、与最近障碍物的距离（clearance）和前进速度（velocity）。权重的调节直接影响机器人的行为特性——高 heading 权重使机器人更倾向于直奔目标，高 clearance 权重使机器人更保守地远离障碍物。


DWA 的局限在于它只考虑短期轨迹（通常 1-2 秒），容易陷入局部最优。在 U 形走廊等复杂环境中，DWA 可能无法找到通路。因此实际系统中 DWA 需要与全局规划器配合，全局规划器提供中间路标点，DWA 负责局部避障和路径跟踪。


速度障碍法
速度障碍法（Velocity Obstacle, VO）是处理动态障碍物（如行人、其他机器人）的经典方法。VO 的核心思想是：将障碍物在速度空间中表示为禁止区域，机器人需要选择一个不在任何速度障碍区域内的速度。


对于一个以速度 v_B 运动的障碍物 B，速度障碍 VO_A|B 定义为所有会导致机器人 A 在未来某一时刻与 B 碰撞的速度集合。在速度空间中，这是一个以 v_B 为顶点的锥形区域。


import numpy as np

class VelocityObstacle:
    def __init__(self, robot_radius, obstacle_radius, time_horizon=5.0):
        self.robot_radius = robot_radius
        self.obstacle_radius = obstacle_radius
        self.time_horizon = time_horizon
        self.combined_radius = robot_radius + obstacle_radius

    def compute_vo(self, robot_pos, obstacle_pos, obstacle_vel):
        rel_pos = obstacle_pos - robot_pos
        dist = np.linalg.norm(rel_pos)

        if dist < self.combined_radius:
            return None

        angle_to_obs = np.arctan2(rel_pos[1], rel_pos[0])
        half_angle = np.arcsin(min(self.combined_radius / dist, 1.0))

        left_bound = angle_to_obs + half_angle
        right_bound = angle_to_obs - half_angle

        return {
            'apex': obstacle_vel.copy(),
            'left_bound': left_bound,
            'right_bound': right_bound,
            'rel_pos': rel_pos
        }

    def is_in_vo(self, velocity, vo):
        if vo is None:
            return True
        rel_vel = velocity - vo['apex']
        angle = np.arctan2(rel_vel[1], rel_vel[0])
        return vo['right_bound'] <= angle <= vo['left_bound']


class ORCAPlanner:
    def __init__(self, robot_radius, max_speed, time_horizon=5.0):
        self.robot_radius = robot_radius
        self.max_speed = max_speed
        self.time_horizon = time_horizon

    def compute_velocity(self, robot_pos, robot_vel, preferred_vel,
                        neighbors_pos, neighbors_vel, neighbors_radius):
        orca_planes = []

        for i in range(len(neighbors_pos)):
            rel_pos = neighbors_pos[i] - robot_pos
            rel_vel = robot_vel - neighbors_vel[i]
            dist = np.linalg.norm(rel_pos)
            combined_r = self.robot_radius + neighbors_radius[i]

            if dist < combined_r:
                direction = rel_pos / (dist + 1e-6)
                orca_planes.append({
                    'point': robot_vel + 0.5 * direction * (combined_r - dist) / 0.1,
                    'normal': direction
                })
                continue

            leg = np.sqrt(max(dist**2 - combined_r**2, 0))
            angle = np.arctan2(rel_pos[1], rel_pos[0])
            half_angle = np.arcsin(min(combined_r / dist, 1.0))

            w = rel_vel - rel_pos / self.time_horizon
            w_len = np.linalg.norm(w)

            if w_len > 1e-6:
                direction = w / w_len
                u = direction * (combined_r / self.time_horizon - w_len)
                orca_planes.append({
                    'point': robot_vel + 0.5 * u,
                    'normal': direction
                })

        new_vel = preferred_vel.copy()
        for plane in orca_planes:
            if np.dot(new_vel - plane['point'], plane['normal']) < 0:
                proj = new_vel - np.dot(new_vel - plane['point'], plane['normal']) * plane['normal']
                new_vel = proj

        speed = np.linalg.norm(new_vel)
        if speed > self.max_speed:
            new_vel = new_vel / speed * self.max_speed

        return new_vel
ORCA（Optimal Reciprocal Collision Avoidance）是 VO 的改进版本，假设每个智能体各承担一半的避障责任。ORCA 将 VO 区域的边界向内收缩一半，每个智能体只需要调整自己速度的一半偏移量。这种对称策略避免了两个智能体同时过度反应导致的振荡问题。


在多机器人场景中，ORCA 能够保证在所有机器人都遵循 ORCA 协议的情况下不会发生碰撞。但在混合场景中（如机器人与不可预测的行人共存），需要将行人视为非合作智能体，机器人承担全部避障责任。


基于优化的避障
模型预测控制（MPC）是一种将避障融入轨迹优化的高级方法。MPC 在每个控制周期内求解一个有限时间域的优化问题，将碰撞避免作为约束条件或惩罚项加入目标函数，生成既跟踪目标又规避障碍的最优轨迹。


TEB（Timed Elastic Band）是 ROS 中另一种流行的局部规划器，它将轨迹表示为一系列时间标记的路径点（弹性带），通过优化这些路径点的位置和时间间隔，同时最小化多个目标：路径长度、与障碍物的距离、速度和加速度的平滑性。


import numpy as np
from scipy.optimize import minimize

class MPCObstacleAvoidance:
    def __init__(self, horizon=20, dt=0.1):
        self.N = horizon
        self.dt = dt
        self.Q = np.diag([10.0, 10.0, 1.0])
        self.R = np.diag([1.0, 0.5])
        self.obstacle_weight = 100.0
        self.safe_distance = 0.5

    def solve(self, state, goal, obstacles, v_max=0.5, w_max=1.0):
        n_controls = 2 * self.N

        def cost_function(u_flat):
            controls = u_flat.reshape(self.N, 2)
            total_cost = 0.0
            x = state.copy()

            for k in range(self.N):
                v, w = controls[k]
                x = self._simulate(x, v, w)

                state_error = np.array([x[0]-goal[0], x[1]-goal[1], x[2]-goal[2]])
                total_cost += state_error @ self.Q @ state_error
                total_cost += controls[k] @ self.R @ controls[k]

                for obs in obstacles:
                    dist = np.sqrt((x[0]-obs[0])**2 + (x[1]-obs[1])**2)
                    if dist < self.safe_distance:
                        total_cost += self.obstacle_weight * (self.safe_distance - dist)**2

            return total_cost

        u0 = np.zeros(n_controls)
        bounds = []
        for _ in range(self.N):
            bounds.extend([(0, v_max), (-w_max, w_max)])

        result = minimize(cost_function, u0, method='SLSQP', bounds=bounds)
        optimal_controls = result.x.reshape(self.N, 2)
        return optimal_controls[0]

    def _simulate(self, state, v, w):
        x, y, yaw = state
        x += v * np.cos(yaw) * self.dt
        y += v * np.sin(yaw) * self.dt
        yaw += w * self.dt
        return np.array([x, y, yaw])
MPC 避障的核心优势在于前瞻性——它考虑未来多步的状态演化，能够提前对即将到来的障碍物做出反应，生成更平滑、更高效的避障轨迹。但计算开销较大，需要高效的求解器（如 OSQP、IPOPT）和热启动策略。


在自动驾驶领域，基于优化的避障通常与预测模块紧密耦合。预测模块估计周围车辆和行人的未来轨迹，MPC 将这些预测轨迹作为时变约束纳入优化，实现对动态环境的主动预判和安全规避。


小结
    

  • 避障是自主导航的安全保障，需在安全性、效率和平滑性之间权衡
    • 

  • DWA 是最流行的局部避障方法，通过在速度空间中搜索最优指令实现实时避障
    • 

  • 速度障碍法（VO/ORCA）专门处理动态障碍物，在多机器人场景中保证无碰撞
    • 

  • MPC 避障具有前瞻性优势，通过优化未来轨迹实现主动预判
    • 

  • TEB 将轨迹表示为弹性带，通过多目标优化生成高质量的避障轨迹
    • 

  • 实际系统采用分层架构：反应式方法保证即时安全，预测式方法提供高质量规避
    • 

  • 避障算法需要与感知、预测和全局规划紧密协同
