Webview 集成

Webview 面板

Webview 是编辑器中嵌入任意 HTML/CSS/JavaScript 的机制，为扩展提供了超越编辑器原生 UI 的表达能力。VS Code 的 Webview 基于 Electron 的 iframe 隔离实现，Monaco Editor 在 Web 环境中使用 sandboxed iframe。

interface WebviewPanel {
  readonly viewType: string;
  title: string;
  readonly webview: Webview;
  readonly active: boolean;
  readonly visible: boolean;
  readonly viewColumn: ViewColumn | undefined;
  readonly onDidDispose: Event<void>;
  readonly onDidChangeViewState: Event<WebviewPanelOnDidChangeViewStateEvent>;
  reveal(viewColumn?: ViewColumn, preserveFocus?: boolean): void;
  dispose(): void;
}

interface Webview {
  html: string;
  options: WebviewOptions;
  cspSource: string;
  readonly onDidReceiveMessage: Event<unknown>;
  postMessage(message: unknown): Thenable<boolean>;
  asWebviewUri(localResource: Uri): Uri;
}

function createPreviewPanel(context: ExtensionContext): WebviewPanel {
  const panel = vscode.window.createWebviewPanel('markdownPreview', 'Markdown Preview', vscode.ViewColumn.Two, {
    enableScripts: true,
    localResourceRoots: [vscode.Uri.joinPath(context.extensionUri, 'media')],
    retainContextWhenHidden: true,
  });
  return panel;
}
选项 作用 默认值 性能影响
enableScripts 允许 JavaScript 执行 false 需评估安全风险
localResourceRoots 可访问的本地资源路径 无 限制文件访问范围
retainContextWhenHidden 隐藏时保留状态 false 增加内存占用
enableForms 允许表单元素 false 允许用户输入

提示： retainContextWhenHidden: true 会让 Webview 在切换标签页后保持活跃状态，避免重新加载。但这会持续占用内存，应仅在需要保持复杂状态（如编辑器中间状态）时使用。

消息传递机制

扩展与 Webview 之间的通信通过 postMessage API 实现。这是一个异步、单向的消息通道，双方各有发送和接收接口。

interface WebviewMessage {
  type: string;
  payload: unknown;
}

function activate(context: ExtensionContext): void {
  const panel = vscode.window.createWebviewPanel('dashboard', 'Dashboard', vscode.ViewColumn.One, {
    enableScripts: true,
  });

  panel.webview.onDidReceiveMessage(
    (message: WebviewMessage) => {
      switch (message.type) {
        case 'requestData':
          const data = loadDashboardData();
          panel.webview.postMessage({ type: 'dataLoaded', payload: data });
          break;
        case 'saveConfig':
          saveConfiguration(message.payload);
          break;
      }
    },
    undefined,
    context.subscriptions,
  );

  panel.webview.html = getWebviewContent(panel.webview);
}

Webview 内部的 JavaScript：

declare function acquireVsCodeApi(): {
  postMessage(message: unknown): void;
  getState(): unknown;
  setState(state: unknown): void;
};

const vscode = acquireVsCodeApi();

window.addEventListener('message', (event: MessageEvent<WebviewMessage>) => {
  const message = event.data;
  switch (message.type) {
    case 'dataLoaded':
      renderDashboard(message.payload);
      break;
    case 'themeChanged':
      applyTheme(message.payload);
      break;
  }
});

function requestData(): void {
  vscode.postMessage({ type: 'requestData' });
}

内容安全策略（CSP）
Webview 必须配置严格的内容安全策略（Content Security Policy），防止 XSS 攻击和未授权的资源加载。


function getWebviewContent(webview: Webview, extensionUri: Uri): string {
  const styleUri = webview.asWebviewUri(Uri.joinPath(extensionUri, 'media', 'style.css'));
  const scriptUri = webview.asWebviewUri(Uri.joinPath(extensionUri, 'media', 'main.js'));
  const nonce = generateNonce();

  return `<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta http-equiv="Content-Security-Policy"
    content="default-src 'none';
             style-src ${webview.cspSource} 'unsafe-inline';
             script-src 'nonce-${nonce}';
             img-src ${webview.cspSource} https:;
             font-src ${webview.cspSource};">
  <link href="${styleUri}" rel="stylesheet">
</head>
<body>
  <div id="app"></div>
  <script nonce="${nonce}" src="${scriptUri}"></script>
</body>
</html>`;
}

function generateNonce(): string {
  const array = new Uint8Array(16);
  crypto.getRandomValues(array);
  return Array.from(array, (b) => b.toString(16).padStart(2, '0')).join('');
}

仅允许扩展本地样式




img-src

允许本地和 HTTPS 图片




font-src
${cspSource}
仅允许本地字体







提示： 永远不要在 CSP 中使用 'unsafe-eval'。如果你的 Webview 框架（如 Vue）需要运行时编译，使用预编译版本代替。'unsafe-inline' 在 style-src 中有时不可避免，但在 script-src 中应严格用 nonce 替代。






自定义编辑器
自定义编辑器（Custom Editor）允许扩展替换特定文件类型的默认文本编辑器，提供完全自定义的编辑体验。


interface CustomReadonlyEditorProvider<T extends CustomDocument> {
  openCustomDocument(uri: Uri, openContext: CustomDocumentOpenContext, token: CancellationToken): T | Thenable<T>;

  resolveCustomEditor(document: T, webviewPanel: WebviewPanel, token: CancellationToken): void | Thenable<void>;
}

interface CustomEditorProvider<T extends CustomDocument> extends CustomReadonlyEditorProvider<T> {
  onDidChangeCustomDocument: Event<CustomDocumentEditEvent<T>>;
  saveCustomDocument(document: T, cancellation: CancellationToken): Thenable<void>;
  revertCustomDocument(document: T, cancellation: CancellationToken): Thenable<void>;
  backupCustomDocument(
    document: T,
    context: CustomDocumentBackupContext,
    cancellation: CancellationToken,
  ): Thenable<CustomDocumentBackup>;
}

class ImageEditorProvider implements CustomEditorProvider<ImageDocument> {
  static readonly viewType = 'myExt.imageEditor';

  static register(context: ExtensionContext): Disposable {
    return vscode.window.registerCustomEditorProvider(ImageEditorProvider.viewType, new ImageEditorProvider(context), {
      supportsMultipleEditorsPerDocument: false,
    });
  }

  async openCustomDocument(uri: Uri): Promise<ImageDocument> {
    const data = await vscode.workspace.fs.readFile(uri);
    return new ImageDocument(uri, data);
  }

  async resolveCustomEditor(document: ImageDocument, webviewPanel: WebviewPanel): Promise<void> {
    webviewPanel.webview.options = { enableScripts: true };
    webviewPanel.webview.html = this.getHtml(webviewPanel.webview, document);
  }
}

小结
    

  • Webview 通过 iframe 隔离提供了嵌入任意 HTML/CSS/JS 的能力，支持丰富的自定义 UI。
    • 

  • 扩展与 Webview 之间通过 postMessage 进行双向异步通信，setState/getState 管理持久化状态。
    • 

  • CSP 策略是 Webview 安全的基石，必须配置 nonce 脚本控制和严格的资源加载白名单。
    • 

  • 自定义编辑器替换默认文本编辑器，支持完整的编辑生命周期（打开、编辑、保存、撤销、备份）。
    • 

  • Webview 集成是扩展 UI 能力的终极武器，但需要谨慎平衡功能丰富性与安全/性能约束。
    •
