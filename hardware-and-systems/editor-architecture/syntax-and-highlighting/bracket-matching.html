括号对着色

括号对着色（Bracket Pair Colorization）为每一对匹配的括号分配不同的颜色，帮助开发者快速辨识嵌套层级。VS Code 在 2021 年将此功能从扩展升级为内置功能，并将性能提升了 10000 倍。

interface BracketPair {
  open: string;
  close: string;
}

const DEFAULT_PAIRS: BracketPair[] = [
  { open: '(', close: ')' },
  { open: '[', close: ']' },
  { open: '{', close: '}' },
];

const BRACKET_COLORS = ['#FFD700', '#DA70D6', '#179FFF'];

interface BracketInfo {
  offset: number;
  length: number;
  pairIndex: number;
  nestingLevel: number;
  isOpen: boolean;
}

function colorizeBrackets(text: string, pairs: BracketPair[]): BracketInfo[] {
  const result: BracketInfo[] = [];
  const stack: Array<{ pairIndex: number; offset: number }> = [];
  let level = 0;

  for (let i = 0; i < text.length; i++) {
    for (let p = 0; p < pairs.length; p++) {
      if (text.startsWith(pairs[p].open, i)) {
        result.push({
          offset: i,
          length: pairs[p].open.length,
          pairIndex: p,
          nestingLevel: level,
          isOpen: true,
        });
        stack.push({ pairIndex: p, offset: i });
        level++;
        break;
      }
      if (text.startsWith(pairs[p].close, i)) {
        level = Math.max(0, level - 1);
        result.push({
          offset: i,
          length: pairs[p].close.length,
          pairIndex: p,
          nestingLevel: level,
          isOpen: false,
        });
        if (stack.length > 0 && stack[stack.length - 1].pairIndex === p) {
          stack.pop();
        }
        break;
      }
    }
  }

  return result;
}

function getBracketColor(nestingLevel: number): string {
  return BRACKET_COLORS[nestingLevel % BRACKET_COLORS.length];
}


提示： VS Code 内置的括号着色之所以比扩展快 10000 倍，关键在于它与 Token 化管线深度集成。扩展需要使用 Decoration API 逐个设置颜色（涉及大量 DOM 操作），而内置版本将括号颜色信息直接嵌入 Token 数据，在渲染时零额外开销。






括号匹配算法
当光标位于括号旁边时，编辑器需要高亮显示匹配的括号对。这需要快速查找匹配括号的位置。


interface MatchResult {
  openOffset: number;
  closeOffset: number;
  isMatched: boolean;
}

function findMatchingBracket(text: string, cursorOffset: number, pairs: BracketPair[]): MatchResult | null {
  const char = text[cursorOffset];
  for (const pair of pairs) {
    if (char === pair.open[0]) return findClosing(text, cursorOffset, pair);
    if (char === pair.close[0]) return findOpening(text, cursorOffset, pair);
  }
  return null;
}

function findClosing(text: string, openOffset: number, pair: BracketPair): MatchResult {
  let depth = 1;
  for (let i = openOffset + pair.open.length; i < text.length; i++) {
    if (text.startsWith(pair.open, i)) depth++;
    if (text.startsWith(pair.close, i)) {
      depth--;
      if (depth === 0) return { openOffset, closeOffset: i, isMatched: true };
    }
  }
  return { openOffset, closeOffset: -1, isMatched: false };
}

function findOpening(text: string, closeOffset: number, pair: BracketPair): MatchResult {
  let depth = 1;
  for (let i = closeOffset - 1; i >= 0; i--) {
    if (text.startsWith(pair.close, i)) depth++;
    if (text.startsWith(pair.open, i)) {
      depth--;
      if (depth === 0) return { openOffset: i, closeOffset, isMatched: true };
    }
  }
  return { openOffset: -1, closeOffset, isMatched: false };
}

自动闭合与自动包围
当用户输入开括号时，编辑器自动插入对应的闭括号。当选中文本并输入括号时，自动用括号包围选中内容。


interface AutoClosePair {
  open: string;
  close: string;
  notIn?: string[];
}

const autoClosePairs: AutoClosePair[] = [
  { open: '(', close: ')' },
  { open: '[', close: ']' },
  { open: '{', close: '}' },
  { open: "'", close: "'", notIn: ['string', 'comment'] },
  { open: '"', close: '"', notIn: ['string', 'comment'] },
  { open: '`', close: '`', notIn: ['string', 'comment'] },
];

function shouldAutoClose(pair: AutoClosePair, currentTokenType: string, nextChar: string): boolean {
  if (pair.notIn?.includes(currentTokenType)) return false;
  return [' ', '\t', '\n', ')', ']', '}', ';', ',', '.', ''].includes(nextChar);
}

function handleBracketInput(
  input: string,
  selectedText: string,
  currentTokenType: string,
  nextChar: string,
): { text: string; cursorOffset: number } | null {
  for (const pair of autoClosePairs) {
    if (input === pair.open) {
      if (selectedText.length > 0) {
        return {
          text: pair.open + selectedText + pair.close,
          cursorOffset: pair.open.length + selectedText.length + pair.close.length,
        };
      }
      if (shouldAutoClose(pair, currentTokenType, nextChar)) {
        return { text: pair.open + pair.close, cursorOffset: pair.open.length };
      }
    }
    if (input === pair.close && nextChar === pair.close) return { text: '', cursorOffset: 1 };
  }
  return null;
}

提示： 自动闭合在字符串或注释内应该被禁用（通过 notIn 配置）。此外，当光标后面紧跟字母数字字符时也不应自动闭合，因为这可能是用户正在输入一个以该字符开头的标识符。VS Code 使用一种启发式规则：只在光标后面是空白字符、闭括号或行尾时才触发自动闭合。






基于缩进的代码折叠
代码折叠（Code Folding）允许用户折叠代码块以聚焦于特定区域。基于缩进的折叠是最通用的策略，它不依赖语法分析。


interface FoldingRange {
  startLine: number;
  endLine: number;
  kind: 'comment' | 'imports' | 'region' | 'indent';
}

function computeIndentFolding(lines: string[], tabSize: number): FoldingRange[] {
  const ranges: FoldingRange[] = [];
  const indent = (line: string) => {
    let n = 0;
    for (const c of line) {
      if (c === ' ') n++;
      else if (c === '\t') n += tabSize;
      else break;
    }
    return n;
  };

  for (let i = 0; i < lines.length; i++) {
    if (lines[i].trim().length === 0) continue;
    const level = indent(lines[i]);
    let endLine = i;
    for (let j = i + 1; j < lines.length; j++) {
      if (lines[j].trim().length === 0) continue;
      if (indent(lines[j]) <= level) break;
      endLine = j;
    }
    if (endLine > i) ranges.push({ startLine: i, endLine, kind: 'indent' });
  }
  return ranges;
}

小结
    

  • 括号对着色使用 3 色循环方案，VS Code 内置版本通过与 Token 管线集成实现了万倍性能提升。
    • 

  • 括号匹配使用栈式深度计数算法，需要跳过字符串和注释中的括号。
    • 

  • 自动闭合在输入开括号时补全闭括号，自动包围在选中文本时用括号包围。
    • 

  • 代码折叠支持缩进、语法树和标记三种策略，VS Code 使用混合策略获得最佳效果。
    • 

  • 所有括号操作都需要 Token 感知，避免在字符串和注释中误触发。
