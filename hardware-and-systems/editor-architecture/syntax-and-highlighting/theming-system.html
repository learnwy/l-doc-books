Token 分类与 Scope 选择器

编辑器的主题系统将语法 Token 映射到具体的颜色和样式。这个映射的基础是 scope 选择器——一种类似 CSS 选择器的层级命名体系，源自 TextMate 的设计。

Scope 匹配算法
当一个 Token 拥有具体的 scope（如 keyword.declaration.function.ts），主题引擎需要找到最佳匹配的规则。匹配遵循最长前缀匹配原则。


class ThemeResolver {
  private rules: Array<{ scopes: string[]; settings: TokenColorSettings }>;

  constructor(theme: Theme) {
    this.rules = theme.tokenColors.map((rule) => ({
      scopes: Array.isArray(rule.scope) ? rule.scope : [rule.scope],
      settings: rule.settings,
    }));
  }

  resolve(tokenScope: string): TokenColorSettings {
    let bestMatch: TokenColorSettings = {};
    let bestScore = -1;

    for (const rule of this.rules) {
      for (const ruleScope of rule.scopes) {
        const score = this.matchScore(ruleScope, tokenScope);
        if (score > bestScore) {
          bestScore = score;
          bestMatch = { ...bestMatch, ...rule.settings };
        }
      }
    }

    return bestMatch;
  }

  private matchScore(ruleScope: string, tokenScope: string): number {
    if (tokenScope === ruleScope) return ruleScope.length * 2;
    if (tokenScope.startsWith(ruleScope + '.')) return ruleScope.length;
    if (tokenScope.startsWith(ruleScope)) return ruleScope.length - 1;
    return -1;
  }

  buildColorMap(): Map<string, string> {
    const map = new Map<string, string>();
    for (const rule of this.rules) {
      for (const scope of rule.scopes) {
        if (rule.settings.foreground) {
          map.set(scope, rule.settings.foreground);
        }
      }
    }
    return map;
  }
}

语义 Token（Semantic Tokens）
TextMate 语法基于正则匹配，无法区分局部变量和全局变量、函数定义和函数调用等语义差异。LSP 的语义 Token（Semantic Tokens）机制弥补了这一缺陷。


interface SemanticToken {
  line: number;
  startChar: number;
  length: number;
  tokenType: number;
  tokenModifiers: number;
}

  'documentation',
  'defaultLibrary',

function decodeSemanticTokens(data: number[]): SemanticToken[] {
  const tokens: SemanticToken[] = [];
  let line = 0;
  let char = 0;

  for (let i = 0; i < data.length; i += 5) {
    const deltaLine = data[i];
    const deltaStart = data[i + 1];

    if (deltaLine > 0) {
      line += deltaLine;
      char = deltaStart;
    } else {
      char += deltaStart;
    }

    tokens.push({
      line,
      startChar: char,
      length: data[i + 2],
      tokenType: data[i + 3],
      tokenModifiers: data[i + 4],
    });
  }

  return tokens;
}

CSS 自定义属性映射
基于 Web 的编辑器（如 Monaco）可以利用 CSS 自定义属性（CSS Custom Properties）来实现动态主题切换。


function applyThemeToCSS(theme: Theme): void {
  const root = document.documentElement;

  for (const [key, value] of Object.entries(theme.colors)) {
    const cssVar = `--vscode-${key.replace(/\./g, '-')}`;
    root.style.setProperty(cssVar, value);
  }
}

function generateTokenCSS(theme: Theme): string {
  const resolver = new ThemeResolver(theme);
  const colorMap = resolver.buildColorMap();
  const rules: string[] = [];

  for (const [scope, color] of colorMap) {
    const className = `mtk-${scope.replace(/\./g, '-')}`;
    rules.push(`.${className} { color: ${color}; }`);
  }

  return rules.join('\n');
}

function buildTokenClassMap(theme: Theme): Map<string, string> {
  const resolver = new ThemeResolver(theme);
  const map = new Map<string, string>();

  const allScopes = [
    'keyword',
    'string',
    'comment',
    'variable',
    'type',
    'function',
    'number',
    'operator',
    'punctuation',
    'constant',
  ];

  for (const scope of allScopes) {
    const settings = resolver.resolve(scope);
    if (settings.foreground) {
      map.set(scope, `mtk-${scope.replace(/\./g, '-')}`);
    }
  }

  return map;
}

提示： VS Code 的 Monaco Editor 使用了一种混合方案：编辑器的 UI 元素（背景、边栏等）使用 CSS 自定义属性，Token 着色使用预生成的 CSS 类名（.mtk1 到 .mtkN），每个类名对应一种颜色。这种数字化的类名方案将类名长度压缩到最短，减少了 DOM 属性的内存占用。






小结
    

  • Scope 选择器使用点号分隔的层级命名体系，匹配遵循最长前缀优先原则。
    • 

  • 主题规则将 scope 映射到颜色和字体样式，启动时预计算为 color map 以优化运行时性能。
    • 

  • LSP 语义 Token 提供比 TextMate 更精确的 Token 分类，可以区分参数、局部变量、属性等语义差异。
    • 

  • CSS 自定义属性用于 UI 元素着色，预生成 CSS 类名用于 Token 着色，构成高性能的混合方案。
    • 

  • Monaco 使用数字化的 .mtk1 到 .mtkN 类名方案，最大限度压缩 DOM 属性的内存开销。
