Tree-sitter 集成

Tree-sitter 概述

Tree-sitter 是一个增量解析库，能够为源代码构建具体语法树（Concrete Syntax Tree, CST），并在每次编辑后以极低的成本更新语法树。它由 GitHub 的 Max Brunsfeld 开发，已被 Neovim、Helix、Zed 等编辑器采用作为核心语法引擎。

特性 TextMate 语法 Tree-sitter
解析方式 正则匹配 上下文无关文法解析
输出 扁平 Token 列表 完整语法树
增量更新 行级 endState 树级增量解析
错误恢复 跳过匹配失败 结构化错误节点
语义理解 无 可查询语法结构
性能 快（简单匹配） 快（增量优势）

增量解析机制

Tree-sitter 的核心优势在于增量解析：编辑后不需要重新解析整个文件，只需告诉解析器哪些字节发生了变化，它就能在 O(编辑大小 × log 文件大小) 的时间内更新语法树。

interface TreeSitterEdit {
  startIndex: number;
  oldEndIndex: number;
  newEndIndex: number;
  startPosition: { row: number; column: number };
  oldEndPosition: { row: number; column: number };
  newEndPosition: { row: number; column: number };
}

interface SyntaxNode {
  type: string;
  startIndex: number;
  endIndex: number;
  startPosition: { row: number; column: number };
  endPosition: { row: number; column: number };
  childCount: number;
  children: SyntaxNode[];
  parent: SyntaxNode | null;
  text: string;
  isNamed: boolean;
  hasError: boolean;
}

interface Tree {
  rootNode: SyntaxNode;
  edit(edit: TreeSitterEdit): void;
}

interface Parser {
  setLanguage(lang: unknown): void;
  parse(input: string | InputReader, oldTree?: Tree): Tree;
}

type InputReader = (index: number, position: { row: number; column: number }) => string | null;

class TreeSitterManager {
  private parser: Parser;
  private tree: Tree | null = null;

  constructor(parser: Parser) {
    this.parser = parser;
  }

  parseFullDocument(text: string): Tree {
    this.tree = this.parser.parse(text);
    return this.tree;
  }

  applyEdit(edit: TreeSitterEdit, newText: string): Tree {
    if (this.tree) {
      this.tree.edit(edit);
    }
    this.tree = this.parser.parse(newText, this.tree ?? undefined);
    return this.tree;
  }

  getNodeAtPosition(row: number, column: number): SyntaxNode | null {
    if (!this.tree) return null;
    return this.findDeepest(this.tree.rootNode, row, column);
  }

  private findDeepest(node: SyntaxNode, row: number, col: number): SyntaxNode {
    for (const child of node.children) {
      const start = child.startPosition;
      const end = child.endPosition;
      if (
        (row > start.row || (row === start.row && col >= start.column)) &&
        (row < end.row || (row === end.row && col <= end.column))
      ) {
        return this.findDeepest(child, row, col);
      }
    }
    return node;
  }
}

提示： Tree-sitter 的增量解析核心依赖于 GLR（Generalized LR）解析算法。它在编辑发生时标记受影响的子树为"脏"，然后从脏节点的祖先开始重新解析，直到新解析的结果与旧树的剩余部分对齐。这种"树拼接"策略使得大部分语法树节点可以被复用。






高亮查询
Tree-sitter 使用一种声明式查询语言（S-expression 格式）来从语法树中提取高亮信息。


interface QueryCapture {
  name: string;
  node: SyntaxNode;
}

interface QueryMatch {
  pattern: number;
  captures: QueryCapture[];
}

const highlightQueries = `
(function_declaration
  name: (identifier) @function)

(variable_declarator
  name: (identifier) @variable)

(call_expression
  function: (identifier) @function.call)

(string) @string
(number) @number
(comment) @comment
(type_identifier) @type

["const" "let" "var" "function" "return" "if" "else"] @keyword
["(" ")" "{" "}" "[" "]"] @punctuation.bracket
[";" "," "."] @punctuation.delimiter
`;

class HighlightProvider {
  private captures: Map<number, QueryCapture[]> = new Map();

  processMatches(matches: QueryMatch[], lineNumber: number): void {
    for (const match of matches) {
      for (const capture of match.captures) {
        if (capture.node.startPosition.row === lineNumber) {
          const existing = this.captures.get(lineNumber) ?? [];
          existing.push(capture);
          this.captures.set(lineNumber, existing);
        }
      }
    }
  }

  getHighlightsForLine(lineNumber: number): Array<{
    start: number;
    end: number;
    scope: string;
  }> {
    const captures = this.captures.get(lineNumber) ?? [];
    return captures.map((c) => ({
      start: c.node.startPosition.column,
      end: c.node.endPosition.column,
      scope: c.name,
    }));
  }
}

错误恢复
Tree-sitter 在遇到语法错误时不会停止解析，而是插入 ERROR 节点并尝试继续。这使得即使代码正在编辑中（语法不完整），编辑器仍能提供有意义的语法高亮。


function findErrors(node: SyntaxNode): SyntaxNode[] {
  const errors: SyntaxNode[] = [];

  function walk(n: SyntaxNode): void {
    if (n.hasError) {
      if (n.type === 'ERROR') {
        errors.push(n);
      }
      for (const child of n.children) {
        walk(child);
      }
    }
  }

  walk(node);
  return errors;
}

interface ErrorRecoveryInfo {
  errorNode: SyntaxNode;
  context: string;
  suggestion: string;
}

function analyzeError(error: SyntaxNode): ErrorRecoveryInfo {
  const parent = error.parent;
  const context = parent ? parent.type : 'root';

  return {
    errorNode: error,
    context,
    suggestion: getSuggestion(context, error),
  };
}

function getSuggestion(context: string, _error: SyntaxNode): string {
  const suggestions: Record<string, string> = {
    function_declaration: '缺少函数体或返回类型',
    if_statement: '缺少条件表达式或代码块',
    variable_declarator: '缺少初始化表达式',
    call_expression: '缺少闭合括号',
  };
  return suggestions[context] ?? '语法错误';
}

小结
    

  • Tree-sitter 是一个增量解析库，能在 O(编辑大小 × log 文件大小) 内更新语法树。
    • 

  • 具体语法树提供完整的语法结构信息，支持精确的节点定位和语义查询。
    • 

  • 高亮查询使用 S-expression 格式声明式地从语法树中提取 scope 信息。
    • 

  • 错误恢复机制确保即使代码不完整，编辑器仍能提供有意义的语法高亮。
    • 

  • WASM 版本使 Tree-sitter 可在浏览器中运行，性能约为原生版本的 60-70%。
