增量解析

增量词法分析

编辑器中每次按键只修改极少量文本，但语法高亮需要重新分析受影响的区域。增量词法分析（Incremental Tokenization）通过记录每行的起始状态，只重新分析从修改点到状态稳定处的行。

interface LineTokenState {
  lineNumber: number;
  endState: TokenizerState;
  tokens: Token[];
}

interface TokenizerState {
  stack: string[];
  ruleIndex: number;
}

class IncrementalTokenizer {
  private lineStates: LineTokenState[] = [];

  onTextChange(change: TextChange): InvalidRange {
    const startLine = change.range.start.line;
    this.lineStates.splice(startLine, change.range.end.line - startLine + 1);

    const previousState = startLine > 0 ? this.lineStates[startLine - 1].endState : this.initialState;

    let currentLine = startLine;
    let currentState = previousState;

    while (currentLine < this.document.lineCount) {
      const lineText = this.document.getLine(currentLine);
      const result = this.tokenizeLine(lineText, currentState);
      const existing = this.lineStates[currentLine];
      if (existing && this.statesEqual(result.endState, existing.endState)) break;

      this.lineStates[currentLine] = {
        lineNumber: currentLine,
        endState: result.endState,
        tokens: result.tokens,
      };
      currentState = result.endState;
      currentLine++;
    }

    return { startLine, endLine: currentLine };
  }
}

提示： VS Code 的 TextMate 词法分析器以行为单位缓存状态。当修改导致某行结束状态变化时，后续行需要重新分析，直到某行的新结束状态与旧状态相同。多行字符串和注释是状态传播最远的常见场景。






Tree-sitter 增量编辑
Tree-sitter 是一个增量解析框架，能在每次编辑后以 O(log n) 的复杂度更新语法树。它被 Atom、Zed、Helix 和 Neovim 等编辑器采用。


interface TreeSitterEdit {
  startIndex: number;
  oldEndIndex: number;
  newEndIndex: number;
  startPosition: Point;
  oldEndPosition: Point;
  newEndPosition: Point;
}

interface Tree {
  rootNode: SyntaxNode;
  edit(edit: TreeSitterEdit): void;
}

interface Parser {
  parse(input: string | InputReader, oldTree?: Tree): Tree;
  setLanguage(language: Language): void;
  setTimeoutMicros(timeout: number): void;
}

class TreeSitterManager {
  private parser: Parser;
  private currentTree: Tree | null = null;

  onDocumentChange(change: TextChange): Tree {
    if (this.currentTree) {
      this.currentTree.edit({
        startIndex: change.startOffset,
        oldEndIndex: change.oldEndOffset,
        newEndIndex: change.newEndOffset,
        startPosition: change.startPosition,
        oldEndPosition: change.oldEndPosition,
        newEndPosition: change.newEndPosition,
      });
    }

    const newTree = this.parser.parse(this.document.getText(), this.currentTree ?? undefined);
    this.currentTree = newTree;
    return newTree;
  }

  getChangedRanges(oldTree: Tree, newTree: Tree): Range[] {
    return oldTree.getChangedRanges(newTree);
  }
}

脏区域追踪
脏区域（Dirty Region）追踪系统记录需要重新处理的文档范围，避免对未修改的区域进行不必要的计算。


interface DirtyRegion {
  start: number;
  end: number;
  generation: number;
}

class DirtyRegionTracker {
  private regions: DirtyRegion[] = [];
  private generation = 0;

  markDirty(start: number, end: number): void {
    this.generation++;
    const newRegion: DirtyRegion = { start, end, generation: this.generation };
    this.regions = this.mergeRegions([...this.regions, newRegion]);
  }

  consumeDirty(): DirtyRegion[] {
    const result = [...this.regions];
    this.regions = [];
    return result;
  }

  private mergeRegions(regions: DirtyRegion[]): DirtyRegion[] {
    if (regions.length === 0) return [];
    const sorted = regions.sort((a, b) => a.start - b.start);
    const merged: DirtyRegion[] = [sorted[0]];

    for (let i = 1; i < sorted.length; i++) {
      const last = merged[merged.length - 1];
      if (sorted[i].start <= last.end) {
        last.end = Math.max(last.end, sorted[i].end);
        last.generation = Math.max(last.generation, sorted[i].generation);
      } else {
        merged.push(sorted[i]);
      }
    }
    return merged;
  }
}

每帧解析预算
为了保证 60fps 的 UI 流畅度，每帧只有约 16ms 的时间。解析器需要在预算内完成工作，否则分片到后续帧中继续。


class BudgetedParser {
  private readonly FRAME_BUDGET_MS = 8;
  private pendingWork: ParseWork | null = null;

  async parseWithBudget(document: TextDocument): Promise<void> {
    const work = this.createWork(document);
    this.pendingWork = work;

    while (!work.isDone) {
      const frameStart = performance.now();
      while (!work.isDone) {
        work.processNextChunk();
        if (performance.now() - frameStart > this.FRAME_BUDGET_MS) break;
      }
      if (!work.isDone) await this.yieldToMainThread();
    }

    this.pendingWork = null;
    this.applyResults(work.results);
  }

  private yieldToMainThread(): Promise<void> {
    return new Promise((resolve) => requestAnimationFrame(() => resolve()));
  }

  cancelPending(): void {
    if (this.pendingWork) {
      this.pendingWork.cancel();
      this.pendingWork = null;
    }
  }
}

按键取消机制
当用户快速输入时，前一次按键触发的解析可能还未完成。按键取消机制确保新输入立即中断旧任务，优先处理最新状态。


class KeystrokeCancellation {
  private currentVersion = 0;
  private activeTask: AbortController | null = null;

  async onKeystroke(document: TextDocument): Promise<void> {
    this.currentVersion++;
    const version = this.currentVersion;
    if (this.activeTask) this.activeTask.abort();

    const controller = new AbortController();
    this.activeTask = controller;

    try {
      await this.processKeystroke(document, controller.signal, version);
    } catch (error) {
      if (error instanceof DOMException && error.name === 'AbortError') return;
      throw error;
    } finally {
      if (this.currentVersion === version) this.activeTask = null;
    }
  }

  private async processKeystroke(document: TextDocument, signal: AbortSignal, version: number): Promise<void> {
    await this.incrementalTokenize(document, signal);
    if (signal.aborted) return;
    await this.updateSemanticHighlighting(document, signal);
    if (signal.aborted) return;
    await this.requestDiagnostics(document, signal);
  }
}
