Worker 线程

Web Workers 语法高亮

语法高亮是 CPU 密集型操作，在主线程上执行会阻塞用户交互。将词法分析和语义高亮卸载到 Web Worker 中，可以确保编辑器在处理大文件时保持流畅。

interface TokenizationWorkerMessage {
  type: 'tokenize';
  id: number;
  lines: string[];
  languageId: string;
  startState: SerializedState;
}

interface TokenizationWorkerResult {
  type: 'tokenized';
  id: number;
  tokens: Uint32Array[];
  endStates: SerializedState[];
}

class TokenizationWorker {
  private worker: Worker;
  private pendingRequests = new Map<
    number,
    {
      resolve: (result: TokenizationWorkerResult) => void;
    }
  >();
  private nextId = 0;

  constructor(workerUrl: string) {
    this.worker = new Worker(workerUrl, { type: 'module' });
    this.worker.onmessage = (e: MessageEvent<TokenizationWorkerResult>) => {
      const pending = this.pendingRequests.get(e.data.id);
      if (pending) {
        pending.resolve(e.data);
        this.pendingRequests.delete(e.data.id);
      }
    };
  }

  tokenize(lines: string[], languageId: string, startState: SerializedState): Promise<TokenizationWorkerResult> {
    const id = this.nextId++;
    return new Promise((resolve) => {
      this.pendingRequests.set(id, { resolve });
      this.worker.postMessage({
        type: 'tokenize',
        id,
        lines,
        languageId,
        startState,
      });
    });
  }
}

SharedArrayBuffer 文本缓冲区
SharedArrayBuffer 允许主线程和 Worker 线程共享同一块内存，避免了 postMessage 的数据复制开销。这对于大文件的文本缓冲区特别有价值。


class SharedTextBuffer {
  private buffer: SharedArrayBuffer;
  private view: Uint8Array;
  private encoder = new TextEncoder();
  private decoder = new TextDecoder();
  private lockView: Int32Array;

  constructor(initialSize: number) {
    this.buffer = new SharedArrayBuffer(initialSize + 4);
    this.view = new Uint8Array(this.buffer, 4);
    this.lockView = new Int32Array(this.buffer, 0, 1);
  }

  write(text: string, offset: number): void {
    Atomics.wait(this.lockView, 0, 1);
    Atomics.store(this.lockView, 0, 1);

    const encoded = this.encoder.encode(text);
    this.view.set(encoded, offset);

    Atomics.store(this.lockView, 0, 0);
    Atomics.notify(this.lockView, 0);
  }

  read(offset: number, length: number): string {
    Atomics.wait(this.lockView, 0, 1);
    const slice = this.view.slice(offset, offset + length);
    return this.decoder.decode(slice);
  }

  getSharedBuffer(): SharedArrayBuffer {
    return this.buffer;
  }
}

class WorkerWithSharedBuffer {
  private worker: Worker;

  initialize(buffer: SharedArrayBuffer): void {
    this.worker.postMessage({ type: 'init', buffer }, []);
  }

  requestAnalysis(offset: number, length: number): void {
    this.worker.postMessage({ type: 'analyze', offset, length });
  }
}

Worker 池模式
单个 Worker 可能不足以处理所有并发任务。Worker 池（Worker Pool）维护多个 Worker 实例，根据负载动态分配任务。


interface WorkerTask<T> {
  id: number;
  execute: () => T;
}

class WorkerPool {
  private workers: PoolWorker[] = [];
  private taskQueue: QueuedTask[] = [];
  private readonly maxWorkers: number;

  constructor(workerUrl: string, maxWorkers?: number) {
    this.maxWorkers = maxWorkers ?? navigator.hardwareConcurrency ?? 4;
    for (let i = 0; i < Math.min(2, this.maxWorkers); i++) {
      this.workers.push(this.createWorker(workerUrl));
    }
  }

  async execute<T>(task: WorkerTask<T>): Promise<T> {
    const availableWorker = this.findIdleWorker();

    if (availableWorker) {
      return this.runOnWorker(availableWorker, task);
    }

    if (this.workers.length < this.maxWorkers) {
      const newWorker = this.createWorker(this.workerUrl);
      this.workers.push(newWorker);
      return this.runOnWorker(newWorker, task);
    }

    return new Promise<T>((resolve, reject) => {
      this.taskQueue.push({ task, resolve, reject });
    });
  }

  private onWorkerIdle(worker: PoolWorker): void {
    if (this.taskQueue.length > 0) {
      const { task, resolve, reject } = this.taskQueue.shift()!;
      this.runOnWorker(worker, task).then(resolve, reject);
    }
  }

  terminate(): void {
    for (const worker of this.workers) {
      worker.terminate();
    }
    this.workers = [];
  }
}

Transferable 对象
Transferable 对象允许在主线程和 Worker 之间零拷贝传递数据，通过转移所有权而非复制实现。


class TransferableProtocol {
  sendToWorker(worker: Worker, data: Uint8Array): void {
    const buffer = data.buffer;
    worker.postMessage({ type: 'data', buffer }, [buffer]);
  }

  receiveFromWorker(event: MessageEvent): Uint8Array {
    return new Uint8Array(event.data.buffer);
  }
}

小结
    

  • Web Worker 将 CPU 密集型操作（词法分析、搜索、格式化）从主线程卸载，确保 UI 流畅。
    • 

  • SharedArrayBuffer 实现主线程与 Worker 之间的零拷贝内存共享，适用于大文件文本缓冲区。
    • 

  • Worker 池动态管理多个 Worker 实例，根据 CPU 核心数和当前负载自动扩缩容。
    • 

  • Transferable 对象通过所有权转移实现零拷贝数据传输，ArrayBuffer 是最常用的类型。
    • 

  • 理想架构中主线程仅处理输入和 DOM 渲染，所有计算任务分发到 Worker 池中执行。
