Part IV · 编辑器与编译器编辑器架构与实现 简介性能优化 简介懒加载

懒加载

核心概念

懒加载把「启动时的一次性成本」摊到「真正需要时」，是启动速度优化的第一道防线：

  • 扩展懒激活：通过激活事件机制让扩展仅在需要时加载，避免启动时载入全部扩展。
  • 功能代码分割：把编辑器功能拆成按需加载的代码块（code splitting）。
  • 语言特性按需加载：仅在打开对应语言文件时加载其语法与语言服务。
  • 启动时间优化：以首屏可交互时间为目标，推迟一切非关键路径的工作。
  • 权衡：懒加载以「首次使用的额外延迟」换取「启动更快」，需保证延迟不明显。

扩展懒激活

编辑器扩展的懒加载是保证启动速度的第一道防线。VS Code 平均安装 50+ 扩展，如果全部在启动时加载，将严重拖慢启动时间。激活事件机制确保扩展仅在需要时加载。

interface ActivationTiming {
  extensionId: string;
  activationEvent: string;
  activateCallTime: number;
  activateResolvedTime: number;
  startup: boolean;
}

class LazyActivationManager {
  private activationLog: ActivationTiming[] = [];
  private pendingExtensions = new Map<string, Set<string>>();

  registerExtension(id: string, events: string[]): void {
    for (const event of events) {
      if (!this.pendingExtensions.has(event)) {
        this.pendingExtensions.set(event, new Set());
      }
      this.pendingExtensions.get(event)!.add(id);
    }
  }

  async triggerEvent(event: string): Promise<void> {
    const extensionIds = this.pendingExtensions.get(event);
    if (!extensionIds || extensionIds.size === 0) return;

    const activations = [...extensionIds].map(async (id) => {
      const start = performance.now();
      await this.activateExtension(id);
      const end = performance.now();

      this.activationLog.push({
        extensionId: id,
        activationEvent: event,
        activateCallTime: start,
        activateResolvedTime: end,
        startup: event === '*' || event === 'onStartupFinished',
      });
    });

    await Promise.allSettled(activations);
    this.pendingExtensions.delete(event);
  }

  getActivationReport(): ActivationReport {
    const total = this.activationLog.reduce((sum, t) => sum + (t.activateResolvedTime - t.activateCallTime), 0);
    return {
      totalActivationTime: total,
      extensionCount: this.activationLog.length,
      slowest: this.activationLog
        .sort((a, b) => b.activateResolvedTime - b.activateCallTime - (a.activateResolvedTime - a.activateCallTime))
        .slice(0, 5),
    };
  }
}

提示： VS Code 的 "Developer: Startup Performance" 命令可以查看每个扩展的激活耗时。如果某个扩展激活超过 100ms，应检查是否存在同步 I/O 或不必要的模块导入。

编辑器功能代码分割

编辑器自身的功能模块也应采用代码分割，将非首屏功能延迟加载。

class FeatureRegistry {
  private features = new Map<string, () => Promise<Feature>>();
  private loadedFeatures = new Map<string, Feature>();

  register(id: string, loader: () => Promise<Feature>): void {
    this.features.set(id, loader);
  }

  async activate(id: string): Promise<Feature> {
    if (this.loadedFeatures.has(id)) {
      return this.loadedFeatures.get(id)!;
    }

    const loader = this.features.get(id);
    if (!loader) throw new Error(`Feature ${id} not registered`);

    const feature = await loader();
    this.loadedFeatures.set(id, feature);
    return feature;
  }
}

const registry = new FeatureRegistry();

registry.register('search', () => import('./features/search'));
registry.register('debug', () => import('./features/debug'));
registry.register('terminal', () => import('./features/terminal'));
registry.register('scm', () => import('./features/scm'));
registry.register('testing', () => import('./features/testing'));

语言特性按需加载

语言智能特性（补全、诊断、重构等）的加载也应该分层：先加载基础语法高亮，再按需加载高级语言特性。

interface LanguageFeatureLayers {
  basic: {
    tokenization: () => Promise<TokenizationSupport>;
    brackets: () => Promise<BracketPairConfig>;
    folding: () => Promise<FoldingProvider>;
  };
  enhanced: {
    completion: () => Promise<CompletionProvider>;
    diagnostics: () => Promise<DiagnosticProvider>;
    hover: () => Promise<HoverProvider>;
  };
  advanced: {
    refactoring: () => Promise<RefactoringProvider>;
    semanticTokens: () => Promise<SemanticTokensProvider>;
    inlayHints: () => Promise<InlayHintsProvider>;
  };
}

class LanguageFeatureManager {
  private layers = new Map<string, LanguageFeatureLayers>();

  async onFileOpen(languageId: string): Promise<void> {
    const layer = this.layers.get(languageId);
    if (!layer) return;

    await this.loadBasicFeatures(layer.basic);

    requestIdleCallback(async () => {
      await this.loadEnhancedFeatures(layer.enhanced);
    });

    requestIdleCallback(
      async () => {
        await this.loadAdvancedFeatures(layer.advanced);
      },
      { timeout: 5000 },
    );
  }

  private async loadBasicFeatures(basic: LanguageFeatureLayers['basic']): Promise<void> {
    const [tokenization, brackets, folding] = await Promise.all([
      basic.tokenization(),
      basic.brackets(),
      basic.folding(),
    ]);
    this.registerAll(tokenization, brackets, folding);
  }
}
加载层次 特性 加载时机 用户感知
基础层 语法高亮、括号匹配、折叠 文件打开时立即 必须即时
增强层 补全、诊断、悬停 空闲时或首次触发 可短暂延迟
高级层 重构、语义高亮、内联提示 空闲时或首次触发 可较长延迟

提示： requestIdleCallback 在浏览器空闲时执行回调，不会阻塞用户交互。VS Code 使用类似的 runWhenIdle 工具函数在主线程空闲时加载非关键功能。

启动时间优化

编辑器启动时间的优化是一个系统工程，涉及代码加载、缓存利用和启动顺序编排。

class StartupProfiler {
  private marks = new Map<string, number>();

  mark(name: string): void {
    this.marks.set(name, performance.now());
  }

  measure(name: string, startMark: string, endMark: string): number {
    const start = this.marks.get(startMark) ?? 0;
    const end = this.marks.get(endMark) ?? 0;
    return end - start;
  }

  generateReport(): StartupReport {
    return {
      windowVisible: this.measure('window', 'start', 'windowVisible'),
      workbenchReady: this.measure('workbench', 'start', 'workbenchReady'),
      editorReady: this.measure('editor', 'start', 'editorReady'),
      extensionsActivated: this.measure('extensions', 'start', 'extensionsReady'),
    };
  }
}

interface StartupOptimizations {
  v8CodeCache: boolean;
  snapshotBlob: boolean;
  preloadModules: string[];
  deferredModules: string[];
  cachedDataDir: string;
}

  • 扩展懒激活通过激活事件机制确保只加载用户需要的扩展，大幅减少启动时间。
