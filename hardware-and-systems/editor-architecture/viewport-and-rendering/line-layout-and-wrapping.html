行布局与折行

文本测量基础

代码编辑器的行布局引擎需要精确知道每个字符的像素宽度和位置，才能正确定位光标、绘制选区和处理鼠标点击。这一切的基础是文本测量（text measurement）。

测量方式 精度 性能 适用场景
Canvas measureText 高 快 单行文本宽度
DOM offsetWidth 高 慢 复杂布局
字体元数据查表 中 极快 等宽字体优化
Range.getBoundingClientRect 高 中 精确字符定位 
class TextMeasurer {
  private ctx: CanvasRenderingContext2D;
  private charWidthCache: Map<string, number> = new Map();

  constructor(font: string) {
    const canvas = document.createElement('canvas');
    this.ctx = canvas.getContext('2d')!;
    this.ctx.font = font;
  }

  measureChar(char: string): number {
    const cached = this.charWidthCache.get(char);
    if (cached !== undefined) return cached;

    const width = this.ctx.measureText(char).width;
    this.charWidthCache.set(char, width);
    return width;
  }

  measureString(text: string): number {
    let width = 0;
    for (const char of text) {
      width += this.measureChar(char);
    }
    return width;
  }

  getOffsetForX(text: string, targetX: number): number {
    let x = 0;
    let offset = 0;
    for (const char of text) {
      const charWidth = this.measureChar(char);
      if (x + charWidth / 2 > targetX) break;
      x += charWidth;
      offset += char.length;
    }
    return offset;
  }
}

等宽与比例字体

代码编辑器传统上使用等宽字体（monospace），每个字符占据相同宽度。但现代编辑器也开始支持比例字体（如 VS Code 的编辑器组件 Monaco 用于 diff 视图时）。

interface FontMetrics {
  fontFamily: string;
  fontSize: number;
  lineHeight: number;
  isMonospace: boolean;
  charWidth: number;
  spaceWidth: number;
  tabWidth: number;
}

function detectFontMetrics(font: string, fontSize: number): FontMetrics {
  const canvas = document.createElement('canvas');
  const ctx = canvas.getContext('2d')!;
  ctx.font = `${fontSize}px ${font}`;

  const mWidth = ctx.measureText('m').width;
  const iWidth = ctx.measureText('i').width;
  const isMonospace = Math.abs(mWidth - iWidth) < 0.01;

  return {
    fontFamily: font,
    fontSize,
    lineHeight: Math.ceil(fontSize * 1.5),
    isMonospace,
    charWidth: isMonospace ? mWidth : 0,
    spaceWidth: ctx.measureText(' ').width,
    tabWidth: ctx.measureText(' ').width * 4,
  };
}


提示： 等宽字体中 CJK 字符通常占据两倍字符宽度。编程连字（如 Fira Code 中的 => → ⇒）虽然是多个字符，但渲染为一个字形。处理连字时需要使用 Canvas.measureText 对连字序列整体测量，而非逐字符累加。






软折行算法
当一行文本超过编辑器宽度时，有两种处理方式：水平滚动（不折行）或软折行（word wrap）。软折行需要决定在哪些位置断行。

type WrapMode = 'none' | 'character' | 'word' | 'bounded';

interface WrapResult {
  visualLines: Array<{ startOffset: number; endOffset: number; width: number }>;
}

function computeWordWrap(text: string, maxWidth: number, measurer: TextMeasurer, mode: WrapMode): WrapResult {
  if (mode === 'none') {
    return { visualLines: [{ startOffset: 0, endOffset: text.length, width: measurer.measureString(text) }] };
  }
  const visualLines: WrapResult['visualLines'] = [];
  let lineStart = 0,
    lineWidth = 0,
    lastBreakPoint = 0,
    lastBreakWidth = 0;

  for (let i = 0; i < text.length; i++) {
    const charWidth = measurer.measureChar(text[i]);

    if (mode === 'word' && isBreakableChar(text[i])) {
      lastBreakPoint = i + 1;
      lastBreakWidth = lineWidth + charWidth;
    }

    if (lineWidth + charWidth > maxWidth) {
      if (mode === 'word' && lastBreakPoint > lineStart) {
        visualLines.push({
          startOffset: lineStart,
          endOffset: lastBreakPoint,
          width: lastBreakWidth,
        });
        lineStart = lastBreakPoint;
        lineWidth = lineWidth - lastBreakWidth + charWidth;
      } else {
        visualLines.push({
          startOffset: lineStart,
          endOffset: i,
          width: lineWidth,
        });
        lineStart = i;
        lineWidth = charWidth;
      }
      lastBreakPoint = lineStart;
      lastBreakWidth = 0;
    } else {
      lineWidth += charWidth;
    }
  }

  visualLines.push({
    startOffset: lineStart,
    endOffset: text.length,
    width: lineWidth,
  });

  return { visualLines };
}

function isBreakableChar(char: string): boolean {
  return char === ' ' || char === '\t' || char === '-' || char === '/';
}


行高计算
在等宽字体不折行的简单场景下，所有行高度相同。但引入折行、内联小部件（如 CodeLens）或块装饰后，行高可能各不相同。


interface LineLayout {
  lineNumber: number;
  top: number;
  height: number;
  visualLineCount: number;
}

class LineLayoutCache {
  private layouts: Map<number, LineLayout> = new Map();
  private defaultLineHeight: number;
  private totalHeight = 0;

  constructor(lineHeight: number) {
    this.defaultLineHeight = lineHeight;
  }

  setLineLayout(lineNumber: number, visualLineCount: number, extraHeight: number): void {
    const height = this.defaultLineHeight * visualLineCount + extraHeight;
    if (existing) this.totalHeight -= existing.height;

    this.layouts.set(lineNumber, { lineNumber, top: 0, height, visualLineCount });
    this.totalHeight += height;
    this.recalculateTops();
  }

  getLineTop(lineNumber: number): number {
    return this.layouts.get(lineNumber)?.top ?? lineNumber * this.defaultLineHeight;
  }

  private recalculateTops(): void {
    let top = 0;
    for (const [, layout] of [...this.layouts.entries()].sort((a, b) => a[0] - b[0])) {
      layout.top = top;
      top += layout.height;
    }
  }

  getTotalHeight(totalLines: number): number {
    return (totalLines - this.layouts.size) * this.defaultLineHeight + this.totalHeight;
  }
}




场景
行高计算





无折行
totalLines × lineHeight




均匀折行
Σ(visualLineCount × lineHeight)




带 CodeLens
正常行高 + lens 高度




带 diff 装饰

提示： 可变行高对虚拟滚动提出了额外挑战：无法用简单除法计算 scrollTop 对应的行号。VS Code 使用了一种"估算 + 修正"策略：先用平均行高估算，滚动到位后根据实际布局修正位置，用户几乎感知不到这种修正。






小结
    

  • 文本测量是行布局的基础，Canvas measureText 配合字符宽度缓存是最佳实践。
    • 

  • 等宽字体可以 O(1) 定位字符列，比例字体需要 O(n) 逐字符累积宽度。
    • 

  • 软折行需要决定断行位置，单词折行和 Unicode 智能折行是常用策略。
    • 

  • 可变行高场景下需要使用行布局缓存，虚拟滚动采用估算 + 修正策略。
    • 

  • 编程连字需要对连字序列整体测量，而非逐字符累加。
