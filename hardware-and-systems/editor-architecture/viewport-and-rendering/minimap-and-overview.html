Minimap 与全局预览

Minimap 的设计目标

Minimap（代码缩略图）是现代编辑器的标志性功能之一，它在编辑器右侧提供整个文件的鸟瞰视图。用户可以通过 Minimap 快速定位到文件的任意位置，同时直观地看到代码的整体结构和密度分布。

设计目标 实现要求
全文预览 在有限高度内渲染整个文件
字符级精度 每个字符用 1-2 像素表示
语法着色 保留语法高亮的颜色信息
交互能力 点击跳转、拖拽滚动
渲染性能 10 万行文件 < 50ms

Canvas 逐字符渲染

Minimap 使用 Canvas API 进行像素级渲染，每个字符被绘制为一个微小的色块。这种方式比 DOM 渲染高效得多。

interface MinimapConfig {
  charWidth: number;
  charHeight: number;
  maxColumn: number;
  backgroundColor: string;
}

interface MinimapChar {
  column: number;
  color: string;
}

interface MinimapLine {
  lineNumber: number;
  chars: MinimapChar[];
}

class MinimapRenderer {
  private canvas: HTMLCanvasElement;
  private ctx: CanvasRenderingContext2D;
  private config: MinimapConfig;

  constructor(canvas: HTMLCanvasElement, config: MinimapConfig) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d')!;
    this.config = config;
  }

  renderLines(lines: MinimapLine[], startY: number): void {
    const { charWidth, charHeight, maxColumn, backgroundColor } = this.config;
    this.ctx.fillStyle = backgroundColor;
    this.ctx.fillRect(0, startY, maxColumn * charWidth, lines.length * charHeight);
    for (let i = 0; i < lines.length; i++) {
      const y = startY + i * charHeight;
      for (const char of lines[i].chars) {
        if (char.column >= maxColumn) break;
        this.ctx.fillStyle = char.color;
        this.ctx.fillRect(char.column * charWidth, y, charWidth, charHeight);
      }
    }
  }

  renderViewportIndicator(startLine: number, endLine: number, totalLines: number): void {
    const scaleY = this.canvas.height / totalLines;
    const y = startLine * scaleY;
    const height = (endLine - startLine) * scaleY;

    this.ctx.fillStyle = 'rgba(121, 121, 121, 0.2)';
    this.ctx.fillRect(0, y, this.canvas.width, height);

    this.ctx.strokeStyle = 'rgba(121, 121, 121, 0.5)';
    this.ctx.strokeRect(0, y, this.canvas.width, height);
  }
}

提示： VS Code 的 Minimap 实际上使用了两种渲染模式。当文件行数 × charHeight 小于 Canvas 高度时，按实际大小渲染（1:1 模式）；当超出时自动切换为按比例缩放模式。1:1 模式下字符辨识度更高，缩放模式下能看到完整文件结构。






Overview Ruler（滚动条装饰）
Overview Ruler 是叠加在滚动条上的装饰层，用微小的色块标记文件中所有错误、警告、搜索结果和修改位置。它提供了不占额外空间的全文概览能力。


interface OverviewRulerEntry {
  startLine: number;
  endLine: number;
  color: string;
  lane: OverviewRulerLane;
}

enum OverviewRulerLane {
  Left = 1,
  Center = 2,
  Right = 4,
  Full = 7,
}

class OverviewRuler {
  private canvas: HTMLCanvasElement;
  private ctx: CanvasRenderingContext2D;

  constructor(canvas: HTMLCanvasElement) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d')!;
  }

  render(entries: OverviewRulerEntry[], totalLines: number): void {
    this.ctx.clearRect(0, 0, this.canvas.width, this.canvas.height);

    const lineHeight = this.canvas.height / totalLines;
    const laneWidth = this.canvas.width / 3;

    for (const entry of entries) {
      const y = entry.startLine * lineHeight;
      const height = Math.max(2, (entry.endLine - entry.startLine + 1) * lineHeight);
      let x = 0;
      let width = this.canvas.width;

      if (entry.lane === OverviewRulerLane.Left) {
        width = laneWidth;
      } else if (entry.lane === OverviewRulerLane.Center) {
        x = laneWidth;
        width = laneWidth;
      } else if (entry.lane === OverviewRulerLane.Right) {
        x = laneWidth * 2;
        width = laneWidth;
      }

      this.ctx.fillStyle = entry.color;
      this.ctx.fillRect(x, y, width, height);
    }
  }
}

视口指示器与交互
视口指示器（Viewport Indicator）在 Minimap 上标记当前可见区域的位置。用户可以通过点击和拖拽 Minimap 进行快速导航。


class MinimapInteraction {
  private isDragging = false;
  private dragStartY = 0;
  private dragStartScrollTop = 0;

  constructor(
    private canvas: HTMLCanvasElement,
    private totalLines: number,
    private onScroll: (line: number) => void,
  ) {
    canvas.addEventListener('mousedown', (e) => this.handleMouseDown(e));
    canvas.addEventListener('mousemove', (e) => this.handleMouseMove(e));
    window.addEventListener('mouseup', () => {
      this.isDragging = false;
    });
  }

  private yToLine(y: number): number {
    return Math.floor((y / this.canvas.height) * this.totalLines);
  }

  private handleMouseDown(e: MouseEvent): void {
    const y = e.clientY - this.canvas.getBoundingClientRect().top;
    if (this.isInViewportIndicator(y)) {
      this.isDragging = true;
      this.dragStartY = y;
      this.dragStartScrollTop = this.getCurrentScrollLine();
    } else {
      this.onScroll(this.yToLine(y));
    }
  }

  private handleMouseMove(e: MouseEvent): void {
    if (!this.isDragging) return;
    const y = e.clientY - this.canvas.getBoundingClientRect().top;
    this.onScroll(this.dragStartScrollTop + this.yToLine(y - this.dragStartY));
  }

  private isInViewportIndicator(_y: number): boolean {
    return false;
  }
  private getCurrentScrollLine(): number {
    return 0;
  }
}

性能优化策略
Minimap 需要渲染整个文件的缩略视图，对大文件来说这是一个性能挑战。


class MinimapCache {
  private lineCache: Map<number, ImageData> = new Map();
  private dirtyLines: Set<number> = new Set();

  markDirty(startLine: number, endLine: number): void {
    for (let i = startLine; i <= endLine; i++) {
      this.dirtyLines.add(i);
      this.lineCache.delete(i);
    }
  }

  getCachedLine(lineNumber: number): ImageData | undefined {
    return this.lineCache.get(lineNumber);
  }

  setCachedLine(lineNumber: number, data: ImageData): void {
    this.lineCache.set(lineNumber, data);
    this.dirtyLines.delete(lineNumber);
  }

  isDirty(lineNumber: number): boolean {
    return this.dirtyLines.has(lineNumber);
  }
  clear(): void {
    this.lineCache.clear();
    this.dirtyLines.clear();
  }
}

小结
    

  • Minimap 使用 Canvas API 逐字符渲染文件缩略图，每个字符用 1-2 像素色块表示。
    • 

  • Overview Ruler 叠加在滚动条上，用色块标记错误、搜索结果、Git 修改等全文信息。
    • 

  • 视口指示器标记当前可见区域，支持点击跳转和拖拽滚动导航。
    • 

  • 大文件的 Minimap 性能通过增量渲染、行缓存、行采样和双缓冲等策略优化。
    • 

  • VS Code 的 Minimap 在文件较短时使用 1:1 渲染，文件较长时自动切换为按比例缩放。
