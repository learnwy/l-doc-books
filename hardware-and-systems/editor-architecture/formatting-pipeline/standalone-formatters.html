独立格式化工具

格式化器生态概览

现代前端和后端开发中存在大量独立格式化工具，每种工具有不同的设计理念、支持语言和配置方式。编辑器需要与这些工具无缝集成。

Prettier 深入
Prettier 是 JavaScript/TypeScript 生态中最流行的格式化器。它的核心理念是"opinionated"——提供极少的配置选项，强制统一风格。


interface PrettierConfig {
  printWidth: number;
  tabWidth: number;
  useTabs: boolean;
  semi: boolean;
  singleQuote: boolean;
  quoteProps: 'as-needed' | 'consistent' | 'preserve';
  jsxSingleQuote: boolean;
  trailingComma: 'all' | 'es5' | 'none';
  bracketSpacing: boolean;
  bracketSameLine: boolean;
  arrowParens: 'always' | 'avoid';
  endOfLine: 'lf' | 'crlf' | 'cr' | 'auto';
}

class PrettierFormatter {
  async format(source: string, filePath: string): Promise<string> {
    const config = await this.resolveConfig(filePath);
    const parser = this.inferParser(filePath);
    return prettier.format(source, { ...config, parser, filepath: filePath });
  }

  private async resolveConfig(filePath: string): Promise<PrettierConfig> {
    const fileConfig = await prettier.resolveConfig(filePath, {
      editorconfig: true,
      useCache: true,
    });
    return { ...this.defaults, ...fileConfig };
  }

  private inferParser(filePath: string): string {
    const ext = path.extname(filePath);
    const parserMap: Record<string, string> = {
      '.ts': 'typescript',
      '.tsx': 'typescript',
      '.js': 'babel',
      '.jsx': 'babel',
      '.css': 'css',
      '.scss': 'scss',
      '.json': 'json',
      '.md': 'markdown',
      '.html': 'html',
      '.vue': 'vue',
    };
    return parserMap[ext] ?? 'babel';
  }
}

Biome：新一代工具链
Biome（原 Rome）是一个用 Rust 编写的全栈工具链，集成了格式化、Lint 和未来的编译功能。其格式化器采用 CST 保留策略，与 Prettier 输出高度兼容。


interface BiomeConfig {
  formatter: {
    enabled: boolean;
    indentStyle: 'tab' | 'space';
    indentWidth: number;
    lineWidth: number;
    lineEnding: 'lf' | 'crlf' | 'cr';
  };
  javascript: {
    formatter: {
      quoteStyle: 'double' | 'single';
      trailingCommas: 'all' | 'es5' | 'none';
      semicolons: 'always' | 'asNeeded';
      arrowParentheses: 'always' | 'asNeeded';
    };
  };
  linter: {
    enabled: boolean;
    rules: Record<string, 'error' | 'warn' | 'off'>;
  };
}

class BiomeIntegration {
  async formatWithBiome(filePath: string, source: string): Promise<string> {
    const result = await this.executeBiome(['format', '--stdin-file-path', filePath, '--write'], source);
    return result.stdout;
  }

  async checkWithBiome(filePath: string, source: string): Promise<Diagnostic[]> {
    const result = await this.executeBiome(['lint', '--stdin-file-path', filePath], source);
    return this.parseDiagnostics(result.stdout);
  }
}

配置文件解析与 .editorconfig
.editorconfig 是跨编辑器、跨工具的通用配置标准。格式化器应该尊重 .editorconfig 中的基础格式选项。


interface EditorConfig {
  indent_style?: 'tab' | 'space';
  indent_size?: number | 'tab';
  tab_width?: number;
  end_of_line?: 'lf' | 'crlf' | 'cr';
  charset?: 'utf-8' | 'utf-16be' | 'utf-16le' | 'latin1';
  trim_trailing_whitespace?: boolean;
  insert_final_newline?: boolean;
  max_line_length?: number | 'off';
  root?: boolean;
}

class EditorConfigResolver {
  async resolve(filePath: string): Promise<EditorConfig> {
    const configs: EditorConfig[] = [];
    let dir = path.dirname(filePath);

    while (true) {
      const configPath = path.join(dir, '.editorconfig');
      const config = await this.parseFile(configPath, filePath);
      if (config) {
        configs.unshift(config);
        if (config.root) break;
      }
      const parent = path.dirname(dir);
      if (parent === dir) break;
      dir = parent;
    }

    return Object.assign({}, ...configs);
  }

  private async parseFile(configPath: string, targetFile: string): Promise<EditorConfig | null> {
    const content = await this.readFile(configPath);
    if (!content) return null;
    const sections = this.parseINI(content);
    return this.matchSection(sections, targetFile);
  }
}

小结
    

  • 现代格式化器生态包括 Prettier、Biome、ESLint、Black、rustfmt 等，各有不同的设计理念和速度特性。
    • 

  • Prettier 以 "opinionated" 理念著称，极少配置选项，AST 重建策略确保输出一致性。
    • 

  • Biome 是 Rust 实现的新一代工具链，CST 保留策略兼顾速度和保留度，与 Prettier 97%+ 兼容。
    • 

  • .editorconfig 是跨编辑器的通用配置标准，格式化器应优先尊重其中的基础格式选项。
    • 

  • 配置文件解析通过向上搜索目录树并合并多级配置，root=true 标记终止搜索。
    •
