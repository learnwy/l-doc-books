LSP 格式化协议

textDocument/formatting

LSP 定义了三种格式化请求，覆盖全文档格式化、范围格式化和输入时格式化三种场景。textDocument/formatting 是最基础的全文档格式化请求。

interface DocumentFormattingParams {
  textDocument: TextDocumentIdentifier;
  options: FormattingOptions;
}

interface FormattingOptions {
  tabSize: number;
  insertSpaces: boolean;
  trimTrailingWhitespace?: boolean;
  insertFinalNewline?: boolean;
  trimFinalNewlines?: boolean;
  [key: string]: boolean | number | string | undefined;
}

type FormattingResult = TextEdit[] | null;
class FormattingHandler {
  async handleFormatting(params: DocumentFormattingParams): Promise<TextEdit[]> {
    const document = this.documents.get(params.textDocument.uri);
    if (!document) return [];

    const source = document.getText();
    const formatted = this.formatter.format(source, {
      tabSize: params.options.tabSize,
      insertSpaces: params.options.insertSpaces,
      trimTrailingWhitespace: params.options.trimTrailingWhitespace ?? false,
      insertFinalNewline: params.options.insertFinalNewline ?? false,
      trimFinalNewlines: params.options.trimFinalNewlines ?? false,
      endOfLine: 'lf',
    });

    return this.computeEdits(source, formatted);
  }

  private computeEdits(original: string, formatted: string): TextEdit[] {
    if (original === formatted) return [];
    const diffs = computeDiff(original, formatted);
    return diffs.map((d) => ({ range: d.range, newText: d.newText }));
  }
}

textDocument/rangeFormatting
范围格式化允许用户选中一段代码并只格式化选区部分。这对于在不想触动全文格式的情况下修复局部缩进非常有用。


interface DocumentRangeFormattingParams {
  textDocument: TextDocumentIdentifier;
  range: Range;
  options: FormattingOptions;
}

class RangeFormattingHandler {
  async handleRangeFormatting(params: DocumentRangeFormattingParams): Promise<TextEdit[]> {
    const document = this.documents.get(params.textDocument.uri);
    if (!document) return [];

    const expandedRange = this.expandRange(document, params.range);
    const regionText = document.getText(expandedRange);
    const baseIndent = this.detectBaseIndent(document, expandedRange);
    const formatted = this.formatter.formatRegion(regionText, {
      ...params.options,
      baseIndent,
    });

    return this.computeEditsInRange(regionText, formatted, expandedRange);
  }

  private expandRange(document: TextDocument, range: Range): Range {
    return {
      start: { line: range.start.line, character: 0 },
      end: {
        line: range.end.line,
        character: document.getLineLength(range.end.line),
      },
    };
  }

  private detectBaseIndent(document: TextDocument, range: Range): number {
    const firstLine = document.getLine(range.start.line);
    return firstLine.length - firstLine.trimStart().length;
  }
}

textDocument/onTypeFormatting
输入时格式化在用户输入特定字符后立即触发，提供即时的格式化反馈。典型场景是输入 } 后自动调整缩进，或输入 ; 后对齐语句。


interface DocumentOnTypeFormattingParams {
  textDocument: TextDocumentIdentifier;
  position: Position;
  ch: string;
  options: FormattingOptions;
}

interface DocumentOnTypeFormattingOptions {
  firstTriggerCharacter: string;
  moreTriggerCharacter?: string[];
}

class OnTypeFormattingHandler {
  private triggerCharacters = new Set(['}', ';', '\n']);

  async handleOnTypeFormatting(params: DocumentOnTypeFormattingParams): Promise<TextEdit[]> {
    if (!this.triggerCharacters.has(params.ch)) return [];

    const document = this.documents.get(params.textDocument.uri);
    if (!document) return [];

    switch (params.ch) {
      case '}':
        return this.formatClosingBrace(document, params.position, params.options);
      case ';':
        return this.formatStatement(document, params.position, params.options);
      case '\n':
        return this.formatNewLine(document, params.position, params.options);
      default:
        return [];
    }
  }

  private formatClosingBrace(document: TextDocument, position: Position, options: FormattingOptions): TextEdit[] {
    const matchingOpen = this.findMatchingBrace(document, position);
    if (!matchingOpen) return [];
    const expectedIndent = this.getIndentAt(document, matchingOpen.line);
    const currentIndent = this.getIndentAt(document, position.line);
    if (expectedIndent === currentIndent) return [];
    return [
      {
        range: { start: { line: position.line, character: 0 }, end: { line: position.line, character: currentIndent } },
        newText: ' '.repeat(expectedIndent),
      },
    ];
  }
}

提示： onTypeFormatting 必须极其快速（<10ms），因为它在每次按键时触发。复杂的格式化逻辑应该放在 didChange 的防抖诊断中，而不是 onTypeFormatting。






编辑计算与应用
格式化结果以 TextEdit[] 形式返回，编辑器需要正确地应用这些编辑。关键规则：编辑必须按逆序（从文件末尾到开头）应用，避免前面的编辑改变后面编辑的位置。


class EditApplier {
  apply(document: TextDocument, edits: TextEdit[]): string {
    const sorted = [...edits].sort((a, b) => {
      const lineDiff = b.range.start.line - a.range.start.line;
      return lineDiff !== 0 ? lineDiff : b.range.start.character - a.range.start.character;
    });

    let text = document.getText();
    for (const edit of sorted) {
      const startOffset = document.offsetAt(edit.range.start);
      const endOffset = document.offsetAt(edit.range.end);
      text = text.slice(0, startOffset) + edit.newText + text.slice(endOffset);
    }
    return text;
  }
}


多 Provider 解决
当多个格式化 Provider 都声明支持同一语言时，编辑器需要决定使用哪一个。VS Code 通过用户选择和默认格式化器配置来解决冲突。


interface FormatterSelector {
  select(document: TextDocument, providers: FormattingProvider[]): Promise<FormattingProvider | undefined>;
}

class DefaultFormatterSelector implements FormatterSelector {
  async select(document: TextDocument, providers: FormattingProvider[]): Promise<FormattingProvider | undefined> {
    const config = this.getConfiguration(document.uri);
    const defaultFormatter = config.get<string>(`[${document.languageId}].editor.defaultFormatter`);

    if (defaultFormatter) {
      const matched = providers.find((p) => p.extensionId === defaultFormatter);
      if (matched) return matched;
    }

    if (providers.length === 1) return providers[0];

    if (providers.length > 1) {
      return this.promptUserSelection(providers);
    }

    return undefined;
  }
}

小结
    

  • textDocument/formatting 返回 TextEdit 数组而非完整文本，精确修改保留编辑器状态。
    • 

  • 范围格式化需要将选区扩展到语法完整单元，并检测基础缩进级别。
    • 

  • onTypeFormatting 在每次按键时触发，必须在 10ms 内完成，只处理简单的缩进调整。
    • 

  • TextEdit 必须按逆序应用，避免前面的编辑影响后续编辑的位置计算。
    • 

  • 多 Provider 冲突通过 defaultFormatter 配置、唯一 Provider 自动选择和用户提示三级策略解决。
