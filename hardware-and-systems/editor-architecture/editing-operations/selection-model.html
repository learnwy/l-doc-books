Part IV · 编辑器与编译器编辑器架构与实现 简介编辑操作 简介选区模型

选区模型

Anchor 与 Head

编辑器中的选区（Selection）是用户与文本交互的基本单元。一个选区由两个位置定义：anchor（锚点，选区的起始位置）和 head（头部，光标当前位置）。当 anchor 等于 head 时，选区退化为一个光标。

interface Position {
  line: number;
  column: number;
}

interface Selection {
  anchor: Position;
  head: Position;
}

function isCollapsed(sel: Selection): boolean {
  return sel.anchor.line === sel.head.line && sel.anchor.column === sel.head.column;
}

function getSelectionStart(sel: Selection): Position {
  if (sel.anchor.line < sel.head.line) return sel.anchor;
  if (sel.anchor.line > sel.head.line) return sel.head;
  return sel.anchor.column <= sel.head.column ? sel.anchor : sel.head;
}

function getSelectionEnd(sel: Selection): Position {
  if (sel.anchor.line > sel.head.line) return sel.anchor;
  if (sel.anchor.line < sel.head.line) return sel.head;
  return sel.anchor.column >= sel.head.column ? sel.anchor : sel.head;
}

function getDirection(sel: Selection): 'ltr' | 'rtl' {
  const start = getSelectionStart(sel);
  return start === sel.anchor ? 'ltr' : 'rtl';
}

多选区集合
现代编辑器支持多个同时存在的选区，每个选区都有独立的 anchor 和 head。


interface SelectionSet {
  selections: Selection[];
  primaryIndex: number;
}

function createSelectionSet(initial: Selection): SelectionSet {
  return { selections: [initial], primaryIndex: 0 };
}

function addSelection(set: SelectionSet, sel: Selection): SelectionSet {
  const merged = mergeOverlapping([...set.selections, sel]);
  return { selections: merged, primaryIndex: merged.length - 1 };
}

function mergeOverlapping(selections: Selection[]): Selection[] {
  if (selections.length <= 1) return selections;
  const sorted = [...selections].sort((a, b) => {
    const aS = getSelectionStart(a),
      bS = getSelectionStart(b);
    return aS.line - bS.line || aS.column - bS.column;
  });
  const result: Selection[] = [sorted[0]];
  for (let i = 1; i < sorted.length; i++) {
    const last = result[result.length - 1],
      curr = sorted[i];
    const lastEnd = getSelectionEnd(last),
      currStart = getSelectionStart(curr);
    if (lastEnd.line > currStart.line || (lastEnd.line === currStart.line && lastEnd.column >= currStart.column)) {
      const currEnd = getSelectionEnd(curr);
      if (currEnd.line > lastEnd.line || (currEnd.line === lastEnd.line && currEnd.column > lastEnd.column)) {
        last.head = curr.head;
      }
    } else {
      result.push(curr);
    }
  }
  return result;
}


提示： VS Code 中 primaryIndex 指向"主选区"，状态栏显示的行列号信息来自主选区的 head 位置。当用户通过 Ctrl+D（添加下一个匹配项）创建多选区时，最后添加的选区成为主选区。






矩形选区（列选区）
矩形选区（Column Selection / Box Selection）允许用户选择一个矩形区域，而非连续的文本流。在 VS Code 中通过 Alt+Shift+拖拽或 Ctrl+Shift+方向键触发。


interface RectangleSelection {
  startLine: number;
  endLine: number;
  startColumn: number;
  endColumn: number;
}

function rectangleToSelections(rect: RectangleSelection): Selection[] {
  const selections: Selection[] = [];
  const minCol = Math.min(rect.startColumn, rect.endColumn);
  const maxCol = Math.max(rect.startColumn, rect.endColumn);

  for (let line = Math.min(rect.startLine, rect.endLine); line <= Math.max(rect.startLine, rect.endLine); line++) {
    selections.push({
      anchor: { line, column: minCol },
      head: { line, column: maxCol },
    });
  }
  return selections;
}

function expandRectangleSelection(
  rect: RectangleSelection,
  direction: 'up' | 'down' | 'left' | 'right',
): RectangleSelection {
  switch (direction) {
    case 'up':
      return { ...rect, startLine: rect.startLine - 1 };
    case 'down':
      return { ...rect, endLine: rect.endLine + 1 };
    case 'left':
      return { ...rect, endColumn: rect.endColumn - 1 };
    case 'right':
      return { ...rect, endColumn: rect.endColumn + 1 };
  }
}

选区亲和性
当光标位于折行边界时，同一个偏移量可能对应视觉上的两个位置：当前行的末尾或下一行的开头。选区亲和性（Selection Affinity）决定了光标在这种歧义情况下的显示位置。


enum CursorAffinity {
  Left = 0,
  Right = 1,
}

interface CursorState {
  position: Position;
  affinity: CursorAffinity;
  desiredColumn: number;
}

function moveCursorDown(
  cursor: CursorState,
  lineLayout: { visualLineCount: number; getOffsetForColumn: (vl: number, col: number) => number },
): CursorState {
  return {
    position: {
      line: cursor.position.line + 1,
      column: lineLayout.getOffsetForColumn(0, cursor.desiredColumn),
    },
    affinity: CursorAffinity.Left,
    desiredColumn: cursor.desiredColumn,
  };
}

提示： desiredColumn 是一个重要的辅助状态。当用户按上下方向键时，编辑器需要尝试保持光标在同一列。即使中间经过了较短的行（光标被推到行尾），desiredColumn 会记住用户"期望"的列位置，在后续行恢复。

interface MouseSelectionEvent {
  position: Position;
  button: 'left' | 'middle' | 'right';
  clickCount: 1 | 2 | 3;
  shiftKey: boolean;
  ctrlKey: boolean;
  altKey: boolean;
}

function handleMouseDown(event: MouseSelectionEvent, currentSelections: SelectionSet): SelectionSet {
  const pos = event.position;
  if (event.clickCount === 2) {
    const r = getWordRangeAtPosition(pos);
    return createSelectionSet({ anchor: r.start, head: r.end });
  }
  if (event.clickCount === 3) {
    return createSelectionSet({ anchor: { line: pos.line, column: 0 }, head: { line: pos.line + 1, column: 0 } });
  }
  if (event.ctrlKey) return addSelection(currentSelections, { anchor: pos, head: pos });
  if (event.shiftKey) {
    const primary = currentSelections.selections[currentSelections.primaryIndex];
    return createSelectionSet({ anchor: primary.anchor, head: pos });
  }
  return createSelectionSet({ anchor: pos, head: pos });
}

function getWordRangeAtPosition(_pos: Position) {
  return { start: _pos, end: _pos };
}


小结
    

  • 选区由 anchor（固定端）和 head（光标端）两个位置定义，collapse 时退化为光标。
    • 

  • 多选区支持任意数量的同时选区，重叠选区会自动合并。
    • 

  • 矩形选区选择一个行列矩形区域，在列编辑场景下非常高效。
    • 

  • 选区亲和性解决折行边界处光标位置的歧义，desiredColumn 维持上下移动时的列一致性。
    • 

  • 鼠标和键盘事件通过点击次数、修饰键组合触发不同的选区操作模式。
