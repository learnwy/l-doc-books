剪贴板与拖拽

核心概念

剪贴板与拖拽处理「文本如何在编辑器内外迁移」，涉及格式、模式与位置调整：

  • 系统剪贴板 API：navigator.clipboard 支持 text/plain、text/html 及自定义 MIME，旧 execCommand 仍是降级路径。
  • 复制模式：按选区状态分为 line（无选区复制整行）、stream（单选区）、block（多选区拼接）。
  • 粘贴智能分配：多光标粘贴时按复制段数与光标数匹配分配内容。
  • 粘贴自动缩进：检测源文本与目标上下文的缩进级别，逐行映射并处理 Tab/空格转换。
  • 拖放操作：区分移动与复制（Ctrl）语义，并处理源位置与目标位置的偏移关系。
  • 扩展点：Drop Provider 允许插件按文件类型定制拖入处理。

系统剪贴板 API

浏览器环境中访问系统剪贴板需要使用现代的 Clipboard API 或传统的 document.execCommand。编辑器需要处理纯文本和富文本两种格式的复制粘贴。

API 支持格式 权限要求 浏览器支持
navigator.clipboard text/plain, text/html, image 用户手势 + 权限 现代浏览器
document.execCommand text/plain 焦点元素 已废弃但仍可用
ClipboardEvent 自定义格式 事件处理器内 广泛支持
Clipboard API (Async) 任意 MIME 类型 权限策略 Chrome 76+ 
interface ClipboardData {
  text: string;
  html?: string;
  metadata?: EditorClipboardMetadata;
}

interface EditorClipboardMetadata {
  isFromEditor: boolean;
  mode: 'line' | 'block' | 'stream';
  selections: Array<{ text: string; startLine: number }>;
}

class EditorClipboard {
  private fallbackData: ClipboardData | null = null;

  async copy(data: ClipboardData): Promise<void> {
    try {
      const items: Record<string, Blob> = {
        'text/plain': new Blob([data.text], { type: 'text/plain' }),
      };
      if (data.html) items['text/html'] = new Blob([data.html], { type: 'text/html' });
      await navigator.clipboard.write([new ClipboardItem(items)]);
    } catch {
      this.fallbackData = data;
    }
  }

  async paste(): Promise<ClipboardData> {
    try {
      const items = await navigator.clipboard.read();
      let text = '',
        html: string | undefined;
      for (const item of items) {
        if (item.types.includes('text/plain')) text = await (await item.getType('text/plain')).text();
        if (item.types.includes('text/html')) html = await (await item.getType('text/html')).text();
      }
      return { text, html };
    } catch {
      return this.fallbackData ?? { text: '' };
    }
  }
}

复制模式与多光标

编辑器的复制行为因选区状态而异：无选区时复制整行，单选区时复制选中文本，多选区时复制所有选区文本拼接。

    COPY --> SINGLE["单选区<br/>复制选中文本<br/>标记为 stream 模式"]
    COPY --> MULTI["多选区<br/>复制所有选区文本<br/>换行分隔,标记为 block 模式"]
type CopyMode = 'line' | 'stream' | 'block';

function prepareCopy(text: string, selections: Selection[]): { content: string; mode: CopyMode } {
  const collapsedSelections = selections.filter(
    (s) => s.anchor.line === s.head.line && s.anchor.column === s.head.column,
  );

  if (collapsedSelections.length === selections.length) {
    const line = selections[0].head.line;
    const lineText = getLineText(text, line);
    return { content: lineText + '\n', mode: 'line' };
  }

  if (selections.length === 1) {
    const sel = selections[0];
    return { content: getTextInRange(text, sel), mode: 'stream' };
  }

  const parts = selections.map((sel) => getTextInRange(text, sel));
  return { content: parts.join('\n'), mode: 'block' };
}

  return '';
}

function getTextInRange(_text: string, _sel: Selection): string {

复制状态 复制内容 粘贴行为
无选区 当前行 + 换行符 在光标行上方插入整行
单选区 选中文本 替换当前选区
多选区 各选区文本拼接 按光标数分配粘贴内容

提示： VS Code 的一个巧妙设计是：当你使用多光标复制了 3 段文本，然后用 3 个光标粘贴时，每段文本会分别粘贴到对应的光标位置。如果光标数与复制段数不匹配，则所有光标粘贴完整内容。

粘贴时自动缩进

从外部粘贴代码时，缩进通常与当前上下文不匹配。智能粘贴应该自动调整缩进级别。

interface IndentInfo {
  level: number;
  type: 'space' | 'tab';
  size: number;
}

function detectIndent(text: string): IndentInfo {
  const lines = text.split('\n').filter((l) => l.trim().length > 0);
  let minIndent = Infinity;

  for (const line of lines) {
    const match = line.match(/^(\s+)/);
    if (match) {
      minIndent = Math.min(minIndent, match[1].length);
    } else {
      minIndent = 0;
    }
  }

  const hasTab = lines.some((l) => l.startsWith('\t'));
  return {
    level: hasTab ? minIndent : Math.floor(minIndent / 2),
    type: hasTab ? 'tab' : 'space',
    size: hasTab ? 1 : 2,
  };
}

function adjustIndent(pastedText: string, targetIndent: number, tabSize: number, insertSpaces: boolean): string {
  const source = detectIndent(pastedText);
  const lines = pastedText.split('\n');
  const indent = insertSpaces ? ' '.repeat(tabSize) : '\t';

  return lines
    .map((line, i) => {
      if (i === 0) return line.trimStart();
      const stripped = line.replace(/^[\t ]+/, '');
      const originalLevel = getIndentLevel(line, source.size, source.type);
      const newLevel = originalLevel - source.level + targetIndent;
      return indent.repeat(Math.max(0, newLevel)) + stripped;
    })
    .join('\n');
}

function getIndentLevel(line: string, size: number, type: 'space' | 'tab'): number {
  const match = line.match(/^(\s+)/);
  if (!match) return 0;
  if (type === 'tab') return match[1].split('\t').length - 1;
  return Math.floor(match[1].length / size);
}

缩进调整场景 处理方式
同文件复制粘贴 保持原始缩进（可能已正确）
跨文件粘贴 检测源缩进 → 映射到目标缩进
外部文本粘贴 检测最小缩进 → 以目标行为基准
Tab ↔ 空格转换 按目标文件设置转换

拖放操作

编辑器内的拖放操作允许用户通过鼠标拖动文本来移动或复制内容。

interface DragState {
  sourceSelection: Selection;
  isDragging: boolean;
  isCopy: boolean;
  dropPosition: { line: number; column: number } | null;
}

class DragDropController {
  private state: DragState = {
    sourceSelection: { anchor: { line: 0, column: 0 }, head: { line: 0, column: 0 } },
    isDragging: false,
    isCopy: false,
    dropPosition: null,
  };

  startDrag(selection: Selection): void {
    this.state = { sourceSelection: selection, isDragging: true, isCopy: false, dropPosition: null };
  }

  updateDrag(position: { line: number; column: number }, ctrlKey: boolean): void {
    this.state.dropPosition = position;
    this.state.isCopy = ctrlKey;
  }

  completeDrop(
    buffer: { insert(offset: number, text: string): void; remove(offset: number, length: number): void },
    getText: (sel: Selection) => string,
  ): void {
    if (!this.state.dropPosition) return;
    const text = getText(this.state.sourceSelection);
    const dropPos = this.state.dropPosition;

    if (this.state.isCopy) {
      buffer.insert(positionToOffset(dropPos), text);
    } else {
      const srcOff = positionToOffset(getSelectionStart(this.state.sourceSelection));
      const dstOff = positionToOffset(dropPos);
      if (srcOff < dstOff) {
        buffer.insert(dstOff, text);
        buffer.remove(srcOff, text.length);
      } else {
        buffer.remove(srcOff, text.length);
        buffer.insert(dstOff, text);
      }
    }
    this.state.isDragging = false;
  }

  cancelDrag(): void {
    this.state.isDragging = false;
  }
}

function positionToOffset(_pos: { line: number; column: number }): number {
  return 0;
}

function getSelectionStart(sel: Selection) {
  return sel.anchor.line < sel.head.line || (sel.anchor.line === sel.head.line && sel.anchor.column <= sel.head.column)
    ? sel.anchor
    : sel.head;
}
拖放操作 修饰键 行为
编辑器内拖放 无 移动文本
编辑器内拖放 Ctrl 复制文本
文件管理器拖入 — 插入文件路径
外部文本拖入 — 粘贴文本
图片拖入 — 插入图片引用

提示： VS Code 的拖放系统支持"Drop Provider"扩展点，插件可以注册自定义的拖入处理逻辑。例如 Markdown 插件可以将拖入的图片自动转换为 ![alt](path) 格式。这使得拖放行为可以根据文件类型智能适配。
