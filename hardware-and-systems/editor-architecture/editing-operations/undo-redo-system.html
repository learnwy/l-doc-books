Part IV · 编辑器与编译器编辑器架构与实现 简介编辑操作 简介撤销重做系统

撤销重做系统

操作模型基础

撤销重做（Undo/Redo）是编辑器最基本也最关键的功能之一。核心挑战在于如何高效地记录每一次编辑操作，并且能够在任意时刻可靠地逆向执行这些操作。

实现方式 原理 优点 缺点
全量快照 保存每次编辑后的完整文本 简单可靠 内存消耗巨大
命令模式 记录操作及其逆操作 内存高效 逆操作实现复杂
差异记录 记录每次编辑的 diff 内存高效 跨操作依赖
操作日志 记录原子操作序列 支持协同 实现最复杂

Command 模式实现

编辑器中最经典的撤销重做实现基于 Command 设计模式：每个编辑操作被封装为一个 Command 对象，同时提供 execute 和 undo 方法。

interface EditCommand {
  execute(): void;
  undo(): void;
}

interface TextEdit {
  offset: number;
  deletedText: string;
  insertedText: string;
}

class InsertCommand implements EditCommand {
  constructor(
    private buffer: { insert(offset: number, text: string): void; remove(offset: number, length: number): void },
    private edit: TextEdit,
  ) {}

  execute(): void {
    if (this.edit.deletedText.length > 0) {
      this.buffer.remove(this.edit.offset, this.edit.deletedText.length);
    }
    if (this.edit.insertedText.length > 0) {
      this.buffer.insert(this.edit.offset, this.edit.insertedText);
    }
  }

  undo(): void {
    if (this.edit.insertedText.length > 0) {
      this.buffer.remove(this.edit.offset, this.edit.insertedText.length);
    }
    if (this.edit.deletedText.length > 0) {
      this.buffer.insert(this.edit.offset, this.edit.deletedText);
    }
  }
}


撤销栈与重做栈
标准的线性撤销实现使用两个栈：undo 栈和 redo 栈。


class UndoRedoStack {
  private undoStack: EditCommand[] = [];
  private redoStack: EditCommand[] = [];
  private maxSize: number;

  constructor(maxSize = 1000) {
    this.maxSize = maxSize;
  }

  push(command: EditCommand): void {
    command.execute();
    this.undoStack.push(command);
    this.redoStack = [];

    if (this.undoStack.length > this.maxSize) {
      this.undoStack.shift();
    }
  }

  undo(): boolean {
    const command = this.undoStack.pop();
    if (!command) return false;
    command.undo();
    this.redoStack.push(command);
    return true;
  }

  redo(): boolean {
    const command = this.redoStack.pop();
    if (!command) return false;
    command.execute();
    this.undoStack.push(command);
    return true;
  }

  canUndo(): boolean {
    return this.undoStack.length > 0;
  }

  canRedo(): boolean {
    return this.redoStack.length > 0;
  }

  clear(): void {
    this.undoStack = [];
    this.redoStack = [];
  }
}

提示： 新编辑操作会清空 Redo 栈，这意味着撤销后再输入新内容，之前撤销的操作将无法重做。这是绝大多数编辑器的标准行为，但 Emacs 的撤销系统打破了这一限制——它的撤销本身也是一种操作，可以被再次撤销。






撤销分组
用户期望 Ctrl+Z 撤销的是"一次有意义的编辑"而非单个字符。撤销分组（Undo Group）将多个原子操作合并为一个逻辑单元。


class UndoGroupManager {
  private currentGroup: EditCommand[] = [];
  private groupTimer: ReturnType<typeof setTimeout> | null = null;
  private stack: UndoRedoStack;

  constructor(stack: UndoRedoStack) {
    this.stack = stack;
  }

  addEdit(command: EditCommand): void {
    this.currentGroup.push(command);
    command.execute();
    if (this.groupTimer) clearTimeout(this.groupTimer);
    this.groupTimer = setTimeout(() => this.flushGroup(), 300);
  }

  forceGroup(commands: EditCommand[]): void {
    this.flushGroup();
    for (const cmd of commands) cmd.execute();
    this.stack.push(new CompositeCommand(commands));
  }

  private flushGroup(): void {
    if (this.currentGroup.length === 0) return;
    this.stack.push(new CompositeCommand([...this.currentGroup]));
    this.currentGroup = [];
  }
}

class CompositeCommand implements EditCommand {
  constructor(private commands: EditCommand[]) {}

  execute(): void {
    for (const cmd of this.commands) cmd.execute();
  }

  undo(): void {
    for (let i = this.commands.length - 1; i >= 0; i--) this.commands[i].undo();
  }
}

撤销树 vs 线性栈
线性撤销栈在分支时丢弃 Redo 历史。撤销树（Undo Tree）保留所有历史分支，允许用户访问任何历史状态。


interface UndoTreeNode {
  id: number;
  command: EditCommand | null;
  parent: UndoTreeNode | null;
  children: UndoTreeNode[];
  timestamp: number;
}

class UndoTree {
  private root: UndoTreeNode;
  private current: UndoTreeNode;
  private nextId = 0;

  constructor() {
    this.root = { id: this.nextId++, command: null, parent: null, children: [], timestamp: Date.now() };
    this.current = this.root;
  }

  push(command: EditCommand): void {
    command.execute();
    const node: UndoTreeNode = {
      id: this.nextId++,
      command,
      parent: this.current,
      children: [],
      timestamp: Date.now(),
    };
    this.current.children.push(node);
    this.current = node;
  }

  undo(): boolean {
    if (!this.current.parent) return false;
    this.current.command?.undo();
    this.current = this.current.parent;
    return true;
  }

  redo(branchIndex = -1): boolean {
    if (this.current.children.length === 0) return false;
    const child = this.current.children[branchIndex >= 0 ? branchIndex : this.current.children.length - 1];
    child.command?.execute();
    this.current = child;
    return true;
  }

  getBranches(): number {
    return this.current.children.length;
  }
}

小结
    

  • 撤销重做基于 Command 模式，每个操作同时记录正向执行和逆向撤销的方法。
    • 

  • 标准实现使用 Undo/Redo 双栈，新编辑会清空 Redo 栈。
    • 

  • 撤销分组将连续的原子操作合并为一个逻辑单元，基于时间窗口或显式边界触发。
    • 

  • 撤销树保留所有历史分支但增加了复杂度，线性栈是大多数编辑器的选择。
    • 

  • 协同编辑场景下需要引入操作变换（OT）或 CRDT 来处理并发撤销的一致性问题。
