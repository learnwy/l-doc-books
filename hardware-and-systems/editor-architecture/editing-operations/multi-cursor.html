Part IV · 编辑器与编译器编辑器架构与实现 简介编辑操作 简介多光标

多光标

核心概念

多光标在多个位置同时编辑，核心难点是「一处编辑如何影响其余光标的位置」：

  • 独立光标集合：每个光标携带自己的选区、亲和性与 desiredColumn，主光标由 primaryIndex 标记。
  • 统一输入分发：一次按键分发到所有光标，CursorController 负责调度。
  • 偏移累积：按文档顺序排序后从前到后执行，并累积行/列偏移，避免后面的光标被前面的编辑推错位。
  • 光标去重：位置相同或选区重叠的光标自动合并，Ctrl+D 遇重叠匹配项时自动跳过。
  • 同步编辑（Linked Editing）：把多个关联范围绑定为整体，用于 HTML 标签同步、变量重命名等场景。
  • 撤销封装：一次 Ctrl+Z 撤销全部光标的编辑，因此所有操作属于同一个撤销组。

多光标的核心思想

多光标（Multi-Cursor）允许用户在文档的多个位置同时编辑，每个光标独立地响应输入事件。VS Code 中通过 Ctrl+Alt+Up/Down 添加上下光标，Ctrl+D 选中下一个匹配项。

    DISPATCH --> C1["光标 1: 在位置 (2,5) 插入 'x'"]

多光标编辑的核心挑战：当第一个光标执行插入后，后续光标的位置都需要偏移调整。

场景 挑战 解决方案
同行多光标 插入后后续光标列偏移 累积偏移量
跨行多光标 插入换行后后续光标行偏移 行+列双重偏移
多光标删除 删除范围与其他光标重叠 先排序再逆序执行
多光标撤销 一次 Ctrl+Z 撤销所有光标的操作 组合命令封装

光标控制器架构

VS Code 的多光标系统由 CursorController 统一管理，核心职责是接收用户输入事件、维护光标状态、分发编辑操作。

interface CursorState {
  selection: Selection;
  affinity: CursorAffinity;
  desiredColumn: number;
}

enum CursorAffinity {
  Left = 0,
  Right = 1,
}

interface Selection {
  anchor: { line: number; column: number };
  head: { line: number; column: number };
}

class CursorController {
  private cursors: CursorState[] = [];
  private primaryIndex = 0;

  addCursor(position: { line: number; column: number }): void {
    this.cursors.push({
      selection: { anchor: position, head: position },
      affinity: CursorAffinity.Left,
      desiredColumn: position.column,
    });
    this.primaryIndex = this.cursors.length - 1;
    this.deduplicate();
  }

  getPrimaryCursor(): CursorState {
    return this.cursors[this.primaryIndex];
  }

  getAllCursors(): CursorState[] {
    return [...this.cursors];
  }

  executeEdit(editFn: (cursor: CursorState, index: number) => TextEditResult): TextEditResult[] {
    const sortedIndices = this.getSortedIndices();
    const results: TextEditResult[] = [];
    let accumulatedLineDelta = 0;
    let accumulatedColumnDelta = 0;
    let lastEditLine = -1;

    for (const idx of sortedIndices) {
      const cursor = this.cursors[idx];
      const adjusted = this.adjustCursor(cursor, accumulatedLineDelta, accumulatedColumnDelta, lastEditLine);

      const result = editFn(adjusted, idx);
      results.push(result);

      accumulatedLineDelta += result.lineDelta;
      if (result.editLine === lastEditLine) {
        accumulatedColumnDelta += result.columnDelta;
      } else {
        accumulatedColumnDelta = result.columnDelta;
      }
      lastEditLine = result.editLine;
    }

    return results;
  }

  private getSortedIndices(): number[] {
    return [...this.cursors.keys()].sort((a, b) => {
      const ca = this.cursors[a].selection.head;
      const cb = this.cursors[b].selection.head;
      return ca.line - cb.line || ca.column - cb.column;
    });
  }

  private adjustCursor(cursor: CursorState, lineDelta: number, columnDelta: number, lastEditLine: number): CursorState {
    const line = cursor.selection.head.line + lineDelta;
    const column =
      cursor.selection.head.line === lastEditLine
        ? cursor.selection.head.column + columnDelta
        : cursor.selection.head.column;
    return {
      ...cursor,
      selection: {
        anchor: { line, column },
        head: { line, column },
      },
    };
  }

  private deduplicate(): void {
    this.cursors = deduplicateCursors(this.cursors);
  }
}

interface TextEditResult {
  editLine: number;
  lineDelta: number;
  columnDelta: number;
}

光标去重

当多个光标落在相同或重叠的位置时，需要自动合并（去重）。否则同一位置会被重复编辑。

graph LR
    BEFORE["3 个光标<br/>(2,5) (2,5) (3,10)"] --> DEDUP["去重处理"]
    DEDUP --> AFTER["2 个光标<br/>(2,5) (3,10)"]
function deduplicateCursors(cursors: CursorState[]): CursorState[] {
  if (cursors.length <= 1) return cursors;
  const sorted = [...cursors].sort((a, b) => {
    const ah = a.selection.head,
      bh = b.selection.head;
    return ah.line - bh.line || ah.column - bh.column;
  });
  const result: CursorState[] = [sorted[0]];
  for (let i = 1; i < sorted.length; i++) {
    const prev = result[result.length - 1],
      curr = sorted[i];
    if (selectionsOverlap(prev.selection, curr.selection)) {
      result[result.length - 1] = mergeCursorStates(prev, curr);
    } else {
      result.push(curr);
    }
  }
  return result;
}

function selectionsOverlap(a: Selection, b: Selection): boolean {
  const aStart = getSelectionStart(a);
  const aEnd = getSelectionEnd(a);
  const bStart = getSelectionStart(b);
  const bEnd = getSelectionEnd(b);

  return !(
    aEnd.line < bStart.line ||
    (aEnd.line === bStart.line && aEnd.column <= bStart.column) ||
    bEnd.line < aStart.line ||
    (bEnd.line === aStart.line && bEnd.column <= aStart.column)
  );
}

function mergeCursorStates(a: CursorState, b: CursorState): CursorState {
  return {
    selection: {
      anchor: a.selection.anchor,
      head: b.selection.head,
    },
    affinity: b.affinity,
    desiredColumn: b.desiredColumn,
  };
}

function getSelectionStart(sel: Selection) {
  return sel.anchor.line < sel.head.line || (sel.anchor.line === sel.head.line && sel.anchor.column <= sel.head.column)
    ? sel.anchor
    : sel.head;
}

function getSelectionEnd(sel: Selection) {
  return sel.anchor.line > sel.head.line || (sel.anchor.line === sel.head.line && sel.anchor.column >= sel.head.column)
    ? sel.anchor
    : sel.head;
}
去重场景 触发条件 处理方式
位置完全相同 两个光标 head 位置一致 保留后一个
选区重叠 两个选区有交集 合并为一个
选区相邻 一个选区的 end 等于另一个 start 可选合并
添加后重叠 Ctrl+D 匹配项与现有光标重叠 跳过该匹配

提示： VS Code 在处理 Ctrl+D（添加下一个匹配项）时，如果发现匹配项范围与已有光标重叠，会自动跳过该匹配项并继续搜索下一个。这避免了用户需要手动处理重叠选区的问题。

同步编辑模式

多光标的一个高级应用是同步编辑（Linked Editing），例如在修改 HTML 开标签时自动修改闭标签。

interface LinkedEditRange {
  ranges: Array<{ line: number; startColumn: number; endColumn: number }>;
  wordPattern: RegExp;
}

class LinkedEditingController {
  private linkedRanges: LinkedEditRange | null = null;

  setLinkedRanges(ranges: LinkedEditRange): void {
    this.linkedRanges = ranges;
  }

  handleEdit(
    editLine: number,
    editColumn: number,
    newText: string,
  ): Array<{ line: number; column: number; text: string }> {
    if (!this.linkedRanges) return [];
    return this.linkedRanges.ranges
      .filter((r) => !(r.line === editLine && r.startColumn === editColumn))
      .map((r) => ({ line: r.line, column: r.startColumn, text: newText }));
  }
}

  • 多光标允许同时在多个位置编辑，核心挑战是编辑后的偏移量累积调整。
  • CursorController 按文档顺序排序光标，从前到后执行编辑并累积偏移量。
