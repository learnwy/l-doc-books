Part I · 硬件电子FPGA 入门FPGA 架构片上资源详解

片上资源详解

除了可配置逻辑块（CLB）和互联网络外，现代 FPGA 还集成了大量硬核（Hardened）专用资源。这些资源通过专用硅电路实现特定功能，相比用通用逻辑实现同等功能，在性能、功耗和面积上都有数量级的优势。本文重点介绍三类核心片上资源：Block RAM（BRAM）、DSP Slice 和时钟管理单元（PLL/MMCM）。

Block RAM（BRAM）

BRAM 基本结构

Block RAM 是 FPGA 中的专用存储资源，以列状分布在芯片内部。每个 BRAM 原语（以 Xilinx 7 系列为例）提供 36 Kbit 的存储容量，可配置为多种宽度和深度组合。

配置模式 数据宽度 存储深度 总容量
36K×1 1 bit 36,864 36 Kbit
18K×2 2 bit 18,432 36 Kbit
4K×9 9 bit (8+1 奇偶) 4,096 36 Kbit
2K×18 18 bit (16+2) 2,048 36 Kbit
1K×36 36 bit (32+4) 1,024 36 Kbit
512×72 72 bit (64+8) 512 36 Kbit

每个 36Kb BRAM 还可以分裂为两个独立的 18Kb BRAM（RAMB18E1），以更灵活地适配不同存储需求。

BRAM 端口配置

BRAM 支持三种端口模式：


    

  • 单口模式：一个地址端口，读写共享，最简单但灵活性最低
    • 

  • 简单双口模式：一个只写端口 + 一个只读端口，适用于 FIFO 和生产者-消费者模式
    • 

  • 真双口模式：两个独立的读写端口（可使用不同时钟），最灵活但需处理写冲突
    •

经验法则：存储需求超过 256-bit 时优先使用 BRAM；低于 64-bit 且需要单周期读取时使用分布式 RAM。


UltraRAM（URAM）
在 UltraScale+ 及更新架构中，AMD 引入了 UltraRAM——一种容量为 288 Kbit（32K × 72-bit）的大容量片上存储原语。单个 UltraRAM 的容量是 BRAM 的 8 倍，且支持级联形成更大的存储阵列。在 Versal 系列中，片上存储总容量可超过 50 MB，足以缓存整个 AI 模型的权重数据。


DSP Slice
DSP48 架构
DSP Slice（以 Xilinx 的 DSP48E2 为例）是 FPGA 中用于高速数学运算的硬核乘加单元。每个 DSP48E2 提供：


    

  • 一个 27×18-bit 有符号乘法器
    • 

  • 一个 48-bit 累加器/加减器
    • 

  • 预加法器（27-bit）
    • 

  • 模式检测逻辑（用于收敛检测、溢出检测）
    • 

  • 级联接口（与相邻 DSP Slice 直连）
    •

资源推断与例化
综合工具会自动将 HDL 中的乘法和乘加运算映射到 DSP Slice：


// 自动推断 DSP — 乘法
wire [47:0] product = a * b;

// 自动推断 DSP — 乘累加（MAC）
always @(posedge clk)
    acc <= acc + (a * b);

// 强制使用 LUT 而非 DSP（属性标注）
(* use_dsp = "no" *) wire [15:0] small_mult = x * 3;
当乘法位宽超过 DSP 原生宽度（27×18）时，综合工具会自动拆分为多个 DSP 的级联实现。

时钟生成示例
MMCM 的频率合成公式：


fout=fin×MD×Of_{out} = f_{in} \times \frac{M}{D \times O}fout​=fin​×D×OM​
其中 MMM 为反馈倍频系数，DDD 为输入分频系数，OOO 为输出分频系数。VCO 频率 fVCO=fin×M/Df_{VCO} = f_{in} \times M / DfVCO​=fin​×M/D 必须处于器件允许的范围内（通常 600 MHz ~ 1600 MHz）。


时钟域与复位策略
合理的时钟架构设计需要考虑：


    

  • 最小化时钟域数量：每增加一个时钟域就引入 CDC（Clock Domain Crossing）风险
    • 

  • 异步 FIFO 跨时钟域：使用格雷码指针的双时钟 FIFO 是最安全的 CDC 方案
    • 

  • 同步复位优于异步复位：异步复位释放时可能违反恢复时间约束
    • 

  • MMCM LOCKED 信号：MMCM 锁定前系统不应开始工作，LOCKED 信号应作为全局复位的一部分
    •
