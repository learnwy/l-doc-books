组合与时序逻辑描述

数字电路分为两大类：组合逻辑（输出仅取决于当前输入）和时序逻辑（输出取决于当前输入和历史状态）。在 Verilog 中正确区分和描述这两类逻辑是编写可靠 RTL 代码的核心能力。本文详细介绍两者的描述范式、常见设计模式以及易错点。

组合逻辑描述
方法一：连续赋值（assign）
适用于简单的组合逻辑表达式：


// 基本逻辑门
assign and_out = a & b;
assign or_out  = a | b;
assign xor_out = a ^ b;

// 多路选择器
assign mux4_out = sel[1] ? (sel[0] ? d3 : d2)
                         : (sel[0] ? d1 : d0);

// 译码器
assign decode = 1'b1 << addr;  // 独热码译码

// 优先级编码器
assign priority = data[7] ? 3'd7 :
                  data[6] ? 3'd6 :
                  data[5] ? 3'd5 :
                  data[4] ? 3'd4 :
                  data[3] ? 3'd3 :
                  data[2] ? 3'd2 :
                  data[1] ? 3'd1 : 3'd0;
方法二：组合 always 块
适用于复杂条件逻辑（多分支 if-else、case）：


reg [7:0] alu_result;

always @(*) begin
    case (op)
        4'b0000: alu_result = a + b;
        4'b0001: alu_result = a - b;
        4'b0010: alu_result = a & b;
        4'b0011: alu_result = a | b;
        4'b0100: alu_result = a ^ b;
        4'b0101: alu_result = ~a;
        4'b0110: alu_result = a << 1;
        4'b0111: alu_result = a >> 1;
        default: alu_result = 8'h00;
    endcase
end
锁存器陷阱
组合 always 块中最危险的错误是无意中推断出锁存器（Latch）。锁存器在 FPGA 中几乎总是设计错误的标志：


// 错误：缺少 else 分支 → 推断锁存器
always @(*) begin
    if (en)
        q = d;
    // 当 en=0 时 q 需要"保持"→ 综合器推断锁存器
end

// 正确：所有路径都有赋值
always @(*) begin
    if (en)
        q = d;
    else
        q = 1'b0;  // 明确默认值
end
防止锁存器的三条规则：


    

  1. always @(*) 块中的每个信号在所有分支中都必须被赋值
    2. 

  2. case 语句必须有 default 分支
    3. 

  3. 在 always 块开头给所有输出信号赋默认值
    4. 



// 推荐的安全模式：开头赋默认值
always @(*) begin
    next_state = IDLE;   // 默认值
    data_out   = 8'h00;  // 默认值

    case (state)
        IDLE: begin
            if (start) next_state = RUN;
        end
        RUN: begin
            next_state = RUN;
            data_out = processed_data;
            if (done) next_state = IDLE;
        end
    endcase
end
时序逻辑描述
基本触发器
// D 触发器（同步复位）
always @(posedge clk) begin
    if (rst)
        q <= 1'b0;
    else
        q <= d;
end

// D 触发器（异步复位）
always @(posedge clk or posedge rst) begin
    if (rst)
        q <= 1'b0;
    else
        q <= d;
end

// 带使能的 D 触发器
always @(posedge clk) begin
    if (rst)
        q <= 1'b0;
    else if (en)
        q <= d;
end

有限状态机（FSM）
FSM 是组合逻辑与时序逻辑协作的典型范例。推荐使用三段式描述法，将状态寄存器、下一状态逻辑和输出逻辑分离：


三段式 FSM 代码模板
// 状态编码
localparam IDLE = 3'b001;
localparam READ = 3'b010;
localparam DONE = 3'b100;

reg [2:0] state, next_state;

// 第一段：状态寄存器（时序逻辑）
always @(posedge clk) begin
    if (rst)
        state <= IDLE;
    else
        state <= next_state;
end

// 第二段：下一状态逻辑（组合逻辑）
always @(*) begin
    next_state = state;  // 默认保持
    case (state)
        IDLE: if (start)  next_state = READ;
        READ: if (finish) next_state = DONE;
        DONE:             next_state = IDLE;
        default:          next_state = IDLE;
    endcase
end

// 第三段：输出逻辑（组合逻辑）
always @(*) begin
    rd_en   = 1'b0;
    done_o  = 1'b0;
    case (state)
        READ: rd_en  = 1'b1;
        DONE: done_o = 1'b1;
        default: ;
    endcase
end

流水线设计
流水线是用时序逻辑拆分长组合路径、提升工作频率的核心技术：


// 无流水线：组合路径过长
assign result = ((a * b) + c) * d;  // 两级乘法 + 一级加法

// 三级流水线
reg [31:0] pipe1, pipe2, pipe3;
reg [31:0] c_d1, d_d1, d_d2;

always @(posedge clk) begin
    // 第一级：乘法 a*b
    pipe1 <= a * b;
    c_d1  <= c;
    d_d1  <= d;

    // 第二级：加法
    pipe2 <= pipe1 + c_d1;
    d_d2  <= d_d1;

    // 第三级：乘法
    pipe3 <= pipe2 * d_d2;
end
流水线的代价是增加了延迟（latency，以时钟周期计）和 FF 资源消耗，但吞吐量（throughput）保持每周期一个结果。
