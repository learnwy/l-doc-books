模块化与参数化设计

随着 FPGA 设计规模从数千门增长到数百万门，单一模块已无法管理整个设计的复杂度。模块化设计通过层次化分解将大系统拆分为可独立开发、验证和复用的子模块；参数化设计则通过编译期参数使同一模块适配不同配置需求。这两种技术是构建可维护、可扩展 FPGA 工程的基础方法论。

模块例化（Instantiation）
module system_top (
    input  wire        clk,
    input  wire        rst,
    input  wire [7:0]  data_in,
    output wire [7:0]  data_out
);

wire [7:0] processed;
wire       valid;

// 命名端口连接（推荐）
data_processor u_processor (
    .clk      (clk),
    .rst      (rst),
    .din      (data_in),
    .dout     (processed),
    .valid_o  (valid)
);

// 输出选择
output_mux u_mux (
    .clk      (clk),
    .sel      (valid),
    .in0      (8'h00),
    .in1      (processed),
    .out      (data_out)
);

endmodule
命名端口连接（.port_name(signal_name)）相比位置端口连接的优势：


    

  • 端口顺序变化不会导致连接错误
    • 

  • 代码可读性强，一目了然
    • 

  • 综合工具可以更好地报告未连接端口
    •

parameter vs localparam




类型
可外部覆盖
使用场景





parameter
可以
对外暴露的配置参数（数据宽度、深度等）




localparam
不可以
模块内部派生的常量（地址宽度、状态编码等）





设计原则：只将用户需要调整的参数声明为 parameter，内部计算派生的值用 localparam，防止外部错误覆盖导致功能异常。


Generate 条件实例化
条件生成（if-generate）
module configurable_adder #(
    parameter USE_DSP = 1,
    parameter WIDTH   = 32
)(
    input  wire [WIDTH-1:0] a, b,
    output wire [WIDTH-1:0] sum
);

generate
    if (USE_DSP) begin : gen_dsp
        // 使用 DSP Slice 实现
        dsp_adder #(.WIDTH(WIDTH)) u_add (
            .a(a), .b(b), .sum(sum)
        );
    end else begin : gen_lut
        // 使用 LUT + 进位链实现
        assign sum = a + b;
    end
endgenerate

endmodule
循环生成（for-generate）
module parallel_comparator #(
    parameter NUM_CHANNELS = 8,
    parameter DATA_WIDTH   = 16
)(
    input  wire [NUM_CHANNELS*DATA_WIDTH-1:0] data_flat,
    input  wire [DATA_WIDTH-1:0]              threshold,
    output wire [NUM_CHANNELS-1:0]            exceed
);

genvar ch;
generate
    for (ch = 0; ch < NUM_CHANNELS; ch = ch + 1) begin : gen_comp
        assign exceed[ch] =
            data_flat[ch*DATA_WIDTH +: DATA_WIDTH] > threshold;
    end
endgenerate

endmodule
接口标准化
通用握手协议（Valid-Ready）
大型设计中模块间通信应遵循统一的接口协议，最常用的是 AXI-Stream 风格的 Valid-Ready 握手：


module stream_processor #(
    parameter DATA_WIDTH = 32
)(
    input  wire                    clk,
    input  wire                    rst,
    // 输入流接口
    input  wire [DATA_WIDTH-1:0]   s_data,
    input  wire                    s_valid,
    output wire                    s_ready,
    // 输出流接口
    output reg  [DATA_WIDTH-1:0]   m_data,
    output reg                     m_valid,
    input  wire                    m_ready
);

// 当下游准备好接收时，本模块准备好接收新数据
assign s_ready = m_ready || !m_valid;

always @(posedge clk) begin
    if (rst) begin
        m_valid <= 1'b0;
    end else if (s_valid && s_ready) begin
        m_data  <= s_data + 1;  // 示例处理
        m_valid <= 1'b1;
    end else if (m_ready) begin
        m_valid <= 1'b0;
    end
end

endmodule
