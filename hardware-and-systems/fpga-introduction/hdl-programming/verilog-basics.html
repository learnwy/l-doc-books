Verilog 基础语法

Verilog 是 FPGA 开发中使用最广泛的硬件描述语言（HDL）之一。与软件编程语言描述算法执行顺序不同，Verilog 描述的是硬件电路的结构和行为——所有描述在综合后将变成实际的数字电路。本文系统介绍 Verilog 的核心语法要素，为后续组合逻辑、时序逻辑和模块化设计打下基础。

模块（Module）：设计的基本单元

模块是 Verilog 中最基本的设计单元，对应一个可综合的硬件电路块。每个模块定义了输入输出端口和内部逻辑行为。

module adder_4bit (
    input  wire [3:0] a,
    input  wire [3:0] b,
    input  wire       cin,
    output wire [3:0] sum,
    output wire       cout
);
    assign {cout, sum} = a + b + cin;
endmodule

模块结构的三要素：

组成部分 作用 硬件对应
端口声明 定义模块的输入输出接口 芯片引脚或模块间连线
内部信号 模块内部的中间变量 模块内部导线或寄存器
逻辑描述 定义端口间的逻辑关系 实际的逻辑门和触发器

数据类型

wire 与 reg

Verilog 中两种最核心的数据类型：

关键误区澄清：reg 类型不一定综合为寄存器。reg 仅表示该信号在过程块（always/initial）中被赋值，最终是否综合为触发器取决于赋值行为：


    

  • 在 always @(posedge clk) 中赋值 → 综合为触发器（Flip-Flop）
    • 

  • 在 always @(*) 中赋值且所有路径都有赋值 → 综合为组合逻辑
    • 



向量（位宽声明）
wire [7:0]  data_byte;    // 8-bit 向量，MSB=data_byte[7]
wire [31:0] data_word;    // 32-bit 向量
reg  [15:0] counter;      // 16-bit 寄存器

// 部分选择（Part-Select）
wire [3:0] upper_nibble = data_byte[7:4];
wire [3:0] lower_nibble = data_byte[3:0];

移位运算的硬件含义
移位运算在硬件中的实现取决于移位量是否为常数：


    

  • 常数移位（a << 2）：纯布线重排，零资源消耗，零延迟
    • 

  • 变量移位（a << n）：综合为桶形移位器（Barrel Shifter），消耗 LUT 资源
    • 



赋值语句
连续赋值（Continuous Assignment）
// assign 语句 — 描述组合逻辑
assign y = a & b;                    // 与门
assign mux_out = sel ? in1 : in0;    // 2:1 多路选择器
assign {cout, sum} = a + b + cin;    // 全加器
连续赋值的特点：


    

  • 右侧任何信号变化时，左侧立即更新
    • 

  • 对应物理上的导线连接，无时钟依赖
    • 

  • 左侧必须是 wire 类型
    • 



过程赋值（Procedural Assignment）
// always 块 — 描述时序或组合逻辑
always @(posedge clk) begin
    if (reset)
        q <= 4'b0000;
    else
        q <= d;
end
两种赋值操作符：






操作符
名称

使用场景

黄金法则：组合逻辑用阻塞赋值（=），时序逻辑用非阻塞赋值（<=）。混用会导致仿真与综合行为不一致。


条件与分支
if-else 语句
always @(posedge clk) begin
    if (reset)
        state <= IDLE;
    else if (start)
        state <= RUN;
    else
        state <= state;
end
case 语句
always @(*) begin
    case (opcode)
        3'b000: result = a + b;
        3'b001: result = a - b;
        3'b010: result = a & b;
        3'b011: result = a | b;
        default: result = 32'h0;
    endcase
end
case 语句对应硬件中的多路选择器或优先级编码器。必须覆盖所有可能的输入情况（使用 default），否则综合工具可能推断出不期望的锁存器。


生成语句（generate）
生成语句用于在编译时根据参数创建重复或条件性硬件结构：


// 生成 N 个并行比较器
genvar i;
generate
    for (i = 0; i < 8; i = i + 1) begin : comp_gen
        assign match[i] = (data[i] == target);
    end
endgenerate
可综合性要点
并非所有 Verilog 语法都能被综合为硬件。以下是关键的可综合性规则：

理解可综合边界是从仿真正确到硬件正确的关键一步。编写 RTL 代码时始终应以"这段代码对应什么硬件"的思维来审视每一行。
