约束文件编写

约束文件是 FPGA 设计中连接逻辑世界与物理世界的桥梁。它告诉工具链时钟的频率是多少、信号应该分配到哪个引脚、信号之间的时序关系如何。没有正确的约束，即使 RTL 代码完美无误，综合实现后的硬件也可能无法正常工作。本文以 Xilinx/AMD 的 XDC 格式和通用的 SDC 格式为主，详解约束文件的编写方法。

时序约束
时钟定义（create_clock）
时钟约束是所有时序分析的基础。未定义时钟的设计无法进行有效的时序分析：


# 定义主时钟：100 MHz，周期 10 ns
create_clock -period 10.000 -name sys_clk [get_ports clk_100m]

# 定义差分时钟输入
create_clock -period 5.000 -name ddr_clk [get_ports clk_200m_p]

# 虚拟时钟（无物理端口，用于约束 IO 延迟参考）
create_clock -period 8.000 -name virt_clk
生成时钟（create_generated_clock）
对于 PLL/MMCM 输出的时钟，工具通常自动识别。对于分频器或门控时钟等特殊情况需要手动定义：


# MMCM 输出（通常自动推断，无需手动定义）
# 手动定义分频时钟
create_generated_clock -name clk_div2 \
    -source [get_pins mmcm_inst/CLKOUT0] \
    -divide_by 2 \
    [get_pins divider_reg/Q]

# 输入延迟：数据在时钟后 2ns 到达（源同步接口）
set_input_delay -clock sys_clk -max 2.0 [get_ports data_in[*]]
set_input_delay -clock sys_clk -min 0.5 [get_ports data_in[*]]

# 输出延迟：下游器件需要数据在时钟前 3ns 稳定
set_output_delay -clock sys_clk -max 3.0 [get_ports data_out[*]]
set_output_delay -clock sys_clk -min 0.2 [get_ports data_out[*]]
时序例外
时序例外用于处理不遵循单周期约束的特殊路径：


# 伪路径：两个时钟域之间用 FIFO 同步，无需检查直接路径
set_false_path -from [get_clocks clk_a] -to [get_clocks clk_b]

# 静态配置寄存器，仅在初始化时写入
set_false_path -from [get_cells config_reg[*]]

# 多周期路径：DSP 流水线需要 3 个时钟周期完成
set_multicycle_path 3 -setup \
    -from [get_cells dsp_stage1/*] \
    -to [get_cells dsp_stage3/*]
set_multicycle_path 2 -hold \
    -from [get_cells dsp_stage1/*] \
    -to [get_cells dsp_stage3/*]

物理约束
引脚分配
# 单端信号引脚分配
set_property PACKAGE_PIN E3 [get_ports clk_100m]
set_property PACKAGE_PIN H5 [get_ports rst_n]
set_property PACKAGE_PIN J5 [get_ports {led[0]}]
set_property PACKAGE_PIN T9 [get_ports {led[1]}]

# 差分信号
set_property PACKAGE_PIN C4 [get_ports clk_200m_p]
set_property PACKAGE_PIN C3 [get_ports clk_200m_n]
电气标准
# 通用 IO 标准
set_property IOSTANDARD LVCMOS33 [get_ports {led[*]}]
set_property IOSTANDARD LVCMOS18 [get_ports {data[*]}]
set_property IOSTANDARD LVDS_25  [get_ports clk_200m_p]

# 驱动强度与斜率
set_property DRIVE 12 [get_ports {data_out[*]}]
set_property SLEW FAST [get_ports {data_out[*]}]

# 内部上拉
set_property PULLUP TRUE [get_ports rst_n]
IO Bank 规划
同一 Bank 内所有 IO 必须使用相同的 VCCO 电压。不同电压标准的信号必须规划到不同 Bank。

约束优先级
XDC 约束按文件读入顺序和行号确定优先级：


    

  • 后读入的约束覆盖先读入的同类约束

  • 更具体的约束覆盖通用约束（如针对特定单元的约束优先于通配符）

正确的约束文件是 FPGA 设计质量的重要保障。约束不足会导致时序分析不充分（隐患），约束过度则会过度限制工具优化空间（性能损失）。理想的约束应当"完备但不过度"。
