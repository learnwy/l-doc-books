PLC 编程

核心概念

可编程逻辑控制器（Programmable Logic Controller, PLC）是工业自动化的核心控制设备。PLC 通过扫描循环的方式执行用户程序，读取输入信号（传感器、按钮）、执行逻辑运算、更新输出信号（执行器、指示灯），实现对工业过程的精确控制。PLC 的可靠性、实时性和抗干扰能力使其成为工厂自动化不可替代的组件。

PLC 编程遵循 IEC 61131-3 国际标准，定义了五种标准编程语言。不同语言适用于不同类型的控制逻辑：梯形图直观表达开关逻辑，功能块图适合连续控制，结构化文本适合复杂算法。

编程语言 类型 适用场景 IEC 标准
LD (Ladder Diagram) 图形 开关逻辑、继电器控制 梯形图
FBD (Function Block) 图形 PID 控制、信号处理 功能块图
ST (Structured Text) 文本 复杂算法、数据处理 结构化文本
IL (Instruction List) 文本 底层操作、优化 指令表
SFC (Sequential Function Chart) 图形 工艺流程、顺序控制 顺序功能图

梯形图与开关逻辑

梯形图（Ladder Diagram, LD）是最广泛使用的 PLC 编程语言，其语法模拟了继电器电路图。梯形图由左右两条垂直母线和水平的梯级组成，每个梯级包含触点（条件）和线圈（输出）。

class PLCSimulator:
    def __init__(self):
        self.inputs = {}
        self.outputs = {}
        self.memory = {}
        self.timers = {}
        self.counters = {}

    def set_input(self, address, value):
        self.inputs[address] = bool(value)

    def get_output(self, address):
        return self.outputs.get(address, False)

    def normally_open(self, address):
        return self.inputs.get(address, False) or self.memory.get(address, False)

    def normally_closed(self, address):
        return not (self.inputs.get(address, False) or self.memory.get(address, False))

    def coil(self, address, value):
        self.outputs[address] = value
        self.memory[address] = value

    def set_coil(self, address, value):
        if value:
            self.memory[address] = True

    def reset_coil(self, address, value):
        if value:
            self.memory[address] = False

    def timer_on_delay(self, timer_id, enable, preset_ms, cycle_ms):
        if timer_id not in self.timers:
            self.timers[timer_id] = {'elapsed': 0, 'done': False, 'running': False}

        timer = self.timers[timer_id]

        if enable:
            timer['running'] = True
            timer['elapsed'] += cycle_ms
            if timer['elapsed'] >= preset_ms:
                timer['done'] = True
        else:
            timer['elapsed'] = 0
            timer['done'] = False
            timer['running'] = False

        return timer['done']

    def counter_up(self, counter_id, count_pulse, reset, preset):
        if counter_id not in self.counters:
            self.counters[counter_id] = {'count': 0, 'done': False, 'prev_pulse': False}

        counter = self.counters[counter_id]

        if reset:
            counter['count'] = 0
            counter['done'] = False
        elif count_pulse and not counter['prev_pulse']:
            counter['count'] += 1
            if counter['count'] >= preset:
                counter['done'] = True

        counter['prev_pulse'] = count_pulse
        return counter['done'], counter['count']


class MotorControlProgram:
    def __init__(self, plc):
        self.plc = plc

    def scan(self):
        start = self.plc.normally_open('I0.0')
        stop = self.plc.normally_closed('I0.1')
        overload = self.plc.normally_closed('I0.2')
        running = self.plc.normally_open('M0.0')

        motor_run = (start or running) and stop and overload
        self.plc.coil('M0.0', motor_run)
        self.plc.coil('Q0.0', motor_run)

        emergency = self.plc.normally_open('I0.3')
        if emergency:
            self.plc.coil('M0.0', False)
            self.plc.coil('Q0.0', False)
            self.plc.coil('Q0.1', True)

定时器（Timer）和计数器（Counter）是梯形图中的常用功能块。TON（接通延时定时器）在使能信号持续一段时间后输出；TOF（断开延时定时器）在使能信号断开后延时一段时间再关闭输出；CTU（递增计数器）对上升沿进行计数。这些基本元素的组合能实现大多数工业控制逻辑。

结构化文本与高级编程

结构化文本（Structured Text, ST）是 IEC 61131-3 中最接近高级编程语言的选项，语法类似 Pascal。ST 适合实现复杂的数学运算、数据处理和算法逻辑，在现代 PLC 编程中使用越来越广泛。

class StructuredTextInterpreter:
    def __init__(self):
        self.variables = {}
        self.function_blocks = {}

    def declare_variable(self, name, var_type, initial_value=None):
        type_defaults = {
            'BOOL': False, 'INT': 0, 'REAL': 0.0, 'STRING': ''
        }
        self.variables[name] = initial_value or type_defaults.get(var_type, 0)

    def execute_assignment(self, var_name, expression_func):
        self.variables[var_name] = expression_func(self.variables)


class PIDFunctionBlock:
    def __init__(self, kp=1.0, ki=0.1, kd=0.01, output_min=0.0, output_max=100.0):
        self.kp = kp
        self.ki = ki
        self.kd = kd
        self.output_min = output_min
        self.output_max = output_max
        self.integral = 0.0
        self.prev_error = 0.0
        self.prev_pv = 0.0

    def execute(self, setpoint, process_value, dt):
        error = setpoint - process_value

        self.integral += error * dt
        max_integral = (self.output_max - self.output_min) / (self.ki + 1e-10)
        self.integral = max(min(self.integral, max_integral), -max_integral)

        derivative = -(process_value - self.prev_pv) / dt if dt > 0 else 0.0

        output = self.kp * error + self.ki * self.integral + self.kd * derivative
        output = max(self.output_min, min(self.output_max, output))

        self.prev_error = error
        self.prev_pv = process_value
        return output


class TemperatureController:
    def __init__(self):
        self.pid = PIDFunctionBlock(kp=2.0, ki=0.5, kd=0.1)
        self.setpoint = 200.0
        self.alarm_high = 250.0
        self.alarm_low = 50.0
        self.state = 'IDLE'

    def execute(self, temperature, dt):
        result = {
            'heater_output': 0.0,
            'alarm': False,
            'state': self.state
        }

        if self.state == 'IDLE':
            if temperature < self.setpoint - 5:
                self.state = 'HEATING'
        elif self.state == 'HEATING':
            output = self.pid.execute(self.setpoint, temperature, dt)
            result['heater_output'] = output
            if abs(temperature - self.setpoint) < 1.0:
                self.state = 'HOLDING'
        elif self.state == 'HOLDING':
            output = self.pid.execute(self.setpoint, temperature, dt)
            result['heater_output'] = output

        if temperature > self.alarm_high or temperature < self.alarm_low:
            result['alarm'] = True
            self.state = 'ALARM'
            result['heater_output'] = 0.0

        result['state'] = self.state
        return result

PLC 编程中的安全编程原则包括：所有输出默认安全状态（断电失效安全）、紧急停止电路硬连线不经过 PLC、关键安全功能使用安全 PLC（Safety PLC, SIL 认证）、程序中实现看门狗和心跳监控。

程序单元 含义 特点 应用
OB (组织块) 系统调用的入口 循环/中断/错误触发 主循环、中断处理
FB (功能块) 带实例数据的子程序 有状态、可复用 PID、电机控制
FC (功能) 无状态子程序 无实例数据 数据转换、计算
DB (数据块) 全局数据存储 持久化 配方、参数、日志

小结

  • PLC 是工业自动化的核心控制器，通过扫描循环实现可靠的实时控制
  • IEC 61131-3 定义了五种标准编程语言，梯形图和结构化文本最常用
  • 梯形图直观表达开关逻辑，定时器和计数器是基本构建块
  • 结构化文本适合复杂算法，PID 控制是温度、压力、流量调节的基础
  • 安全编程原则要求默认安全状态、硬件紧停和安全 PLC 认证
  • PLC 程序按 OB/FB/FC/DB 组织，实现模块化和复用
  • 现代 PLC 支持 OPC UA 通信、Web 可视化和 AI 推理扩展
