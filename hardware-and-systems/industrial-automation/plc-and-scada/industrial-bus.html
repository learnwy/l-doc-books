工业总线协议

核心概念

工业总线（Industrial Fieldbus）是连接工厂现场设备（传感器、执行器、PLC、驱动器）的通信网络。与办公网络的 TCP/IP 不同，工业总线专为实时性、确定性和可靠性设计，保证控制指令在确定的时间内送达。工业总线协议经历了从串行总线（RS-485）到现场总线（PROFIBUS、CAN）再到工业以太网（PROFINET、EtherCAT）的演进。

工业以太网是当前的主流趋势——它使用标准以太网物理层，但在数据链路层或应用层加入实时机制，同时保持与 IT 网络的兼容性。

EtherCAT 协议
EtherCAT（Ethernet for Control Automation Technology）是目前性能最高的工业以太网协议，由 Beckhoff 公司开发并推动为 IEC 61158 国际标准。EtherCAT 的核心创新是"飞读飞写"（Processing on the fly）机制——以太网帧在经过每个从站时，从站直接在帧传输过程中读取和写入数据，无需存储转发，实现了极低的通信延迟。


import struct
import time

class EtherCATFrame:
    ETHERCAT_TYPE = 0x88A4

    def __init__(self):
        self.datagrams = []

    def add_datagram(self, command, address, data, working_counter=0):
        self.datagrams.append({
            'command': command,
            'index': len(self.datagrams),
            'address': address,
            'data': data,
            'working_counter': working_counter
        })

    def serialize(self):
        frame_data = b''
        for dg in self.datagrams:
            header = struct.pack('<BBIHh',
                dg['command'], dg['index'],
                dg['address'], len(dg['data']),
                0)
            frame_data += header + dg['data'] + struct.pack('<H', dg['working_counter'])
        return frame_data


class EtherCATMaster:
    CMD_NOP = 0x00
    CMD_APRD = 0x01
    CMD_APWR = 0x02
    CMD_LRW = 0x0C

    def __init__(self):
        self.slaves = []
        self.process_data = bytearray(1024)
        self.cycle_time_us = 1000

    def scan_bus(self):
        slave_count = self._detect_slaves()
        for i in range(slave_count):
            info = self._read_slave_info(i)
            self.slaves.append(info)
        return slave_count

    def configure_dc(self):
        for i, slave in enumerate(self.slaves):
            if slave.get('dc_support'):
                self._setup_distributed_clock(i)

    def cyclic_exchange(self):
        frame = EtherCATFrame()
        frame.add_datagram(
            self.CMD_LRW,
            0x00000000,
            bytes(self.process_data),
        )
        response = self._send_frame(frame)
        if response:
            self._parse_response(response)

    def set_output(self, slave_idx, offset, data):
        slave = self.slaves[slave_idx]
        start = slave.get('output_offset', 0) + offset
        for i, byte in enumerate(data):
            self.process_data[start + i] = byte

    def get_input(self, slave_idx, offset, length):
        slave = self.slaves[slave_idx]
        start = slave.get('input_offset', 0) + offset
        return bytes(self.process_data[start:start + length])

    def _detect_slaves(self):
        return len(self.slaves)

    def _read_slave_info(self, index):
        return {'index': index, 'dc_support': True, 'input_offset': index * 32, 'output_offset': index * 32 + 512}

        pass

    def _send_frame(self, frame):
        return frame.serialize()

    def _parse_response(self, data):
        pass
EtherCAT 的分布式时钟（Distributed Clocks, DC）机制实现了所有从站的纳秒级时间同步。主站周期性发送参考时钟帧，每个从站根据帧传播延迟补偿本地时钟，确保所有从站在同一时刻执行 I/O 操作。这对于多轴同步运动控制至关重要。


PROFINET 与时间敏感网络
PROFINET 是西门子主导的工业以太网标准，在全球自动化市场占有最大份额。PROFINET 分为三个通信等级：PROFINET RT（实时，软件级实时）、PROFINET IRT（等时实时，硬件级实时）和基于 TCP/IP 的标准通信。


class PROFINETDevice:
    def __init__(self, device_name, ip_address):
        self.device_name = device_name
        self.ip_address = ip_address
        self.modules = []
        self.state = 'OFFLINE'
        self.cycle_counter = 0

    def add_module(self, slot, module_type, input_size, output_size):
        self.modules.append({
            'slot': slot,
            'type': module_type,
            'input_data': bytearray(input_size),
            'output_data': bytearray(output_size),
            'input_size': input_size,
            'output_size': output_size
        })

    def connect(self, controller_ip):
        self.state = 'PARAMETERIZING'
        self._load_parameters()
        self.state = 'DATA_EXCHANGE'

    def cyclic_io(self, output_data_map):
        if self.state != 'DATA_EXCHANGE':
            return None

        for slot, data in output_data_map.items():
            module = self._find_module(slot)
            if module:
                module['output_data'][:len(data)] = data

        self.cycle_counter += 1
        input_data_map = {}
        for module in self.modules:
            input_data_map[module['slot']] = bytes(module['input_data'])

        return input_data_map

    def _find_module(self, slot):
        for m in self.modules:
            if m['slot'] == slot:
                return m
        return None

    def _load_parameters(self):
        pass


class TSNScheduler:
    def __init__(self, cycle_time_us=1000):
        self.cycle_time = cycle_time_us
        self.streams = []
        self.gate_control_list = []

    def add_stream(self, stream_id, priority, period_us, max_frame_size):
        self.streams.append({
            'id': stream_id,
            'priority': priority,
            'period': period_us,
            'frame_size': max_frame_size,
            'phase_offset': 0
        })

    def compute_schedule(self):
        self.streams.sort(key=lambda s: s['priority'])
        current_offset = 0

        for stream in self.streams:
            stream['phase_offset'] = current_offset
            tx_time = stream['frame_size'] * 8 / 1_000_000
            current_offset += int(tx_time * 1_000_000) + 10

        self._generate_gate_control_list()

    def _generate_gate_control_list(self):
        self.gate_control_list = []
        for stream in self.streams:
            self.gate_control_list.append({
                'time_offset': stream['phase_offset'],
                'gate_state': 1 << stream['priority'],
                'duration': stream['frame_size'] * 8 // 100 + 5
            })
TSN（Time-Sensitive Networking）是 IEEE 802.1 工作组定义的一组以太网标准扩展，目标是在标准以太网上实现确定性传输。TSN 的核心标准包括 802.1AS（精确时钟同步）、802.1Qbv（时间感知调度）和 802.1CB（帧复制与消除）。TSN 被视为统一 IT 和 OT 网络的关键技术。

小结
    

  • 工业总线经历了串行→现场总线→工业以太网的演进，实时性和带宽持续提升
    • 

  • EtherCAT 通过飞读飞写和分布式时钟实现最高性能，适合高精度运动控制
    • 

  • PROFINET 是全球市场份额最大的工业以太网，三个通信等级覆盖不同实时需求
    • 

  • CAN/CANopen 简单可靠，在汽车电子和小型嵌入式系统中仍占主导
    • 

  • TSN 是统一 IT/OT 网络的关键技术，在标准以太网上实现确定性传输
    • 

  • 工业通信安全日益重要，OPC UA over TSN 成为 IT/OT 融合的标准方案
    • 

  • 选择工业总线需综合考虑实时性需求、设备生态和系统集成复杂度
