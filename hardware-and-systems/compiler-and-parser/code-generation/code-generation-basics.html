代码生成基础

AST 到目标代码

代码生成是将 AST（或 IR）转换为目标平台可执行代码的过程。目标可以是机器码、字节码、另一种高级语言（如 TypeScript→JavaScript），甚至是 SQL 或 HTML。代码生成的策略直接决定了产出代码的质量和编译速度。

interface CodegenContext {
  output: string[];
  indent: number;
  sourceMap: SourceMapping[];
}

interface SourceMapping {
  generatedLine: number;
  generatedColumn: number;
  originalLine: number;
  originalColumn: number;
}

const createContext = (): CodegenContext => ({
  output: [],
  indent: 0,
  sourceMap: [],
});

const emit = (ctx: CodegenContext, code: string): void => {
  const indentation = '  '.repeat(ctx.indent);
  ctx.output.push(indentation + code);
};

const emitLine = (ctx: CodegenContext, code: string): void => {
  emit(ctx, code + '\n');
};
生成策略 描述 优点 缺点
树遍历 递归遍历 AST 直接产出代码 实现简单 难以优化
模板生成 每种节点对应一个代码模板 可读性好 灵活性受限
字节码编译 AST→字节码→VM 执行 可移植、可优化 需要 VM 支持
IR 降级 AST→IR→优化→目标码 最佳优化机会 实现复杂 


提示： TypeScript 编译器使用树遍历策略将 TypeScript AST 转换为 JavaScript。由于 TypeScript→JavaScript 的转换相对直接（主要是擦除类型和降级语法），树遍历策略的简单性在这里是最优解。






树遍历代码生成
树遍历（Tree-walking）是最直观的代码生成方式。为 AST 的每种节点类型编写一个生成函数，递归遍历即可产出目标代码。


const generateProgram = (program: Program, ctx: CodegenContext): void => {
  for (const stmt of program.body) {
    generateStatement(stmt, ctx);
  }
};

const generateStatement = (stmt: Statement, ctx: CodegenContext): void => {
  switch (stmt.kind) {
    case 'VariableDeclaration':
      generateVarDecl(stmt as VariableDeclaration, ctx);
      break;
    case 'FunctionDeclaration':
      generateFuncDecl(stmt as FunctionDeclaration, ctx);
      break;
    case 'IfStatement':
      generateIf(stmt as IfStatement, ctx);
      break;
    case 'ReturnStatement':
      generateReturn(stmt as ReturnStatement, ctx);
      break;
    case 'ExpressionStatement':
      generateExprStmt(stmt as ExpressionStatement, ctx);
      break;
    case 'BlockStatement':
      generateBlock(stmt as BlockStatement, ctx);
      break;
  }
};

const generateVarDecl = (decl: VariableDeclaration, ctx: CodegenContext): void => {
  const keyword = decl.mutable ? 'let' : 'const';
  if (decl.init) {
    emitLine(ctx, `${keyword} ${decl.name.name} = ${generateExpr(decl.init)};`);
  } else {
    emitLine(ctx, `${keyword} ${decl.name.name};`);
  }
};

const generateFuncDecl = (decl: FunctionDeclaration, ctx: CodegenContext): void => {
  const params = decl.params.map((p) => p.name).join(', ');
  emitLine(ctx, `function ${decl.name.name}(${params}) {`);
  ctx.indent++;
  generateBlock(decl.body, ctx);
  ctx.indent--;
  emitLine(ctx, '}');
};

const generateIf = (stmt: IfStatement, ctx: CodegenContext): void => {
  emitLine(ctx, `if (${generateExpr(stmt.condition)}) {`);
  ctx.indent++;
  generateStatement(stmt.consequent, ctx);
  ctx.indent--;
  if (stmt.alternate) {
    emitLine(ctx, '} else {');
    ctx.indent++;
    generateStatement(stmt.alternate, ctx);
    ctx.indent--;
  }
  emitLine(ctx, '}');
};

const generateReturn = (stmt: ReturnStatement, ctx: CodegenContext): void => {
  if (stmt.value) {
    emitLine(ctx, `return ${generateExpr(stmt.value)};`);
  } else {
    emitLine(ctx, 'return;');
  }
};

const generateExprStmt = (stmt: ExpressionStatement, ctx: CodegenContext): void => {
  emitLine(ctx, `${generateExpr(stmt.expr)};`);
};

const generateBlock = (block: BlockStatement, ctx: CodegenContext): void => {
  for (const stmt of block.body) {
    generateStatement(stmt, ctx);
  }
};

const generateExpr = (expr: Expression): string => {
  switch (expr.kind) {
    case 'NumberLiteral':
      return String((expr as NumberLiteral).value);
    case 'StringLiteral':
      return JSON.stringify((expr as StringLiteral).value);
    case 'Identifier':
      return (expr as Identifier).name;
    case 'BinaryExpression': {
      const bin = expr as BinaryExpression;
      return `(${generateExpr(bin.left)} ${bin.operator} ${generateExpr(bin.right)})`;
    }
    case 'CallExpression': {
      const call = expr as CallExpression;
      const args = call.arguments.map(generateExpr).join(', ');
      return `${generateExpr(call.callee)}(${args})`;
    }
    default:
      return '<unknown>';
  }
};


字节码编译
字节码编译将 AST 转换为虚拟机可执行的紧凑指令序列。字节码是一种中间形态——比源代码更底层，但比机器码更抽象和可移植。


enum OpCode {
  CONST,
  ADD,
  SUB,
  MUL,
  DIV,
  LOAD,
  STORE,
  CALL,
  RET,
  JMP,
  JMP_IF_FALSE,
  POP,
  PRINT,
  HALT,
}

interface Chunk {
  code: number[];
  constants: unknown[];
  lines: number[];
}

class BytecodeCompiler {
  private chunk: Chunk = { code: [], constants: [], lines: [] };

  compile(node: BaseNode): Chunk {
    this.emitNode(node);
    this.emitOp(OpCode.HALT, 0);
    return this.chunk;
  }

  private emitOp(op: OpCode, line: number): void {
    this.chunk.code.push(op);
    this.chunk.lines.push(line);
  }

  private emitConstant(value: unknown, line: number): number {
    const index = this.chunk.constants.length;
    this.chunk.constants.push(value);
    this.emitOp(OpCode.CONST, line);
    this.chunk.code.push(index);
    this.chunk.lines.push(line);
    return index;
  }

  private emitNode(node: BaseNode): void {
    switch (node.kind) {
      case 'NumberLiteral':
        this.emitConstant((node as NumberLiteral).value, node.span.start);
        break;
      case 'BinaryExpression': {
        const bin = node as BinaryExpression;
        this.emitNode(bin.left);
        this.emitNode(bin.right);
        const opMap: Record<string, OpCode> = { '+': OpCode.ADD, '-': OpCode.SUB, '*': OpCode.MUL, '/': OpCode.DIV };
        this.emitOp(opMap[bin.operator] ?? OpCode.ADD, node.span.start);
        break;
      }
    }
  }
}

提示： V8 引擎的 Ignition 解释器和 JVM 都使用字节码作为执行格式。字节码的紧凑性带来了更好的缓存命中率，而其规整的指令格式也为 JIT 编译提供了便利。






寄存器式 vs 栈式虚拟机
// 栈式虚拟机：操作数在栈上
// a + b 编译为: LOAD a; LOAD b; ADD
const executeStack = (chunk: Chunk): number => {
  const stack: number[] = [];
  let ip = 0;

  while (ip < chunk.code.length) {
    const op = chunk.code[ip++];
    switch (op) {
      case OpCode.CONST:
        stack.push(chunk.constants[chunk.code[ip++]] as number);
        break;
      case OpCode.ADD: {
        const b = stack.pop()!;
        const a = stack.pop()!;
        stack.push(a + b);
        break;
      }
      case OpCode.MUL: {
        const b = stack.pop()!;
        const a = stack.pop()!;
        stack.push(a * b);
        break;
      }
      case OpCode.HALT:
        return stack.pop() ?? 0;
    }
  }
  return 0;
};

// 寄存器式虚拟机：操作数在寄存器中
// a + b 编译为: ADD r0, r1, r2
interface RegisterInstr {
  op: string;
  dest: number;
  src1?: number;
  src2?: number;
  value?: number;
}

const executeRegister = (instrs: RegisterInstr[]): number => {
  const regs = new Array<number>(256).fill(0);

  for (const instr of instrs) {
    switch (instr.op) {
      case 'LOADK':
        regs[instr.dest] = instr.value!;
        break;
      case 'ADD':
        regs[instr.dest] = regs[instr.src1!] + regs[instr.src2!];
        break;
      case 'RET':
        return regs[instr.dest];
    }
  }
  return 0;
};

小结
    

  • 树遍历是最直接的代码生成方式，为每种 AST 节点编写生成函数，递归即可。
    • 

  • 模板生成将代码模式参数化，适合规整的源到源转换。
    • 

  • 字节码编译产出紧凑的指令序列，适合虚拟机执行和 JIT 编译。
    • 

  • 栈式 VM 代码生成简单、指令紧凑；寄存器式 VM 指令更少、运行更高效。
    • 

  • TypeScript 编译器使用树遍历生成 JavaScript，V8 使用字节码编译 + JIT 执行 JavaScript。
