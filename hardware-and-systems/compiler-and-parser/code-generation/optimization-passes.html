优化 Pass

优化的分类与原则

编译器优化的目标是在保持程序语义不变的前提下，提升运行速度、减少内存占用或缩小产出体积。优化 Pass 通常以 IR 或 AST 为输入，产出等价但更高效的 IR 或 AST。

interface OptimizationPass {
  name: string;
  level: 'peephole' | 'local' | 'global' | 'interprocedural';
  apply: (ir: IRInstruction[]) => IRInstruction[];
}

const pipeline = (passes: OptimizationPass[], ir: IRInstruction[]): IRInstruction[] => {
  let current = ir;
  for (const pass of passes) {
    const before = current.length;
    current = pass.apply(current);
    const after = current.length;
    if (before !== after) {
      console.log(`${pass.name}: ${before} → ${after} 条指令`);
    }
  }
  return current;
};
优化层级 作用范围 示例 分析需求
窥孔优化 相邻几条指令 强度削减、指令合并 局部模式匹配
局部优化 单个基本块 常量折叠、公共子表达式消除 基本块内分析
全局优化 单个函数 死代码消除、循环优化 数据流分析
过程间优化 跨函数 内联、尾调用优化 调用图分析 


提示： 优化 Pass 的顺序非常重要。例如，内联可能创造新的常量折叠机会，而常量折叠可能使更多代码成为死代码。许多编译器会多次运行优化管线（"定点迭代"），直到不再有变化。






常量折叠
常量折叠（Constant Folding）在编译时计算常量表达式的值，避免运行时重复计算。这是最基础也最高收益的优化之一。


const constantFolding: OptimizationPass = {
  name: '常量折叠',
  level: 'local',
  apply: (ir) =>
    ir.map((instr) => {
      if (instr.op === 'add' || instr.op === 'sub' || instr.op === 'mul' || instr.op === 'div') {
        const leftConst = findConstValue(ir, instr.left);
        const rightConst = findConstValue(ir, instr.right);
        if (leftConst !== null && rightConst !== null) {
          const result = evaluate(instr.op, leftConst, rightConst);
          return { op: 'const' as const, dest: instr.dest, value: result };
        }
      }
      return instr;
    }),
};

const evaluate = (op: string, a: number, b: number): number => {
  switch (op) {
    case 'add':
      return a + b;
    case 'sub':
      return a - b;
    case 'mul':
      return a * b;
    case 'div':
      return b !== 0 ? a / b : 0;
    default:
      return 0;
  }
};

const findConstValue = (ir: IRInstruction[], name: string): number | null => {
  for (const instr of ir) {
    if (instr.op === 'const' && instr.dest === name) return instr.value;
  }
  return null;
};

const constantPropagation = (ir: IRInstruction[]): IRInstruction[] => {
  const constants = new Map<string, number>();

  return ir.map((instr) => {
    if (instr.op === 'const') {
      constants.set(instr.dest, instr.value);
      return instr;
    }

    const propagate = (name: string): string => {
      const val = constants.get(name);
      return val !== undefined ? String(val) : name;
    };

    if ('left' in instr && 'right' in instr) {
      return { ...instr, left: propagate(instr.left), right: propagate(instr.right) };
    }
    return instr;
  });
};

死代码消除
死代码消除（Dead Code Elimination，DCE）移除对程序输出没有影响的代码。一条指令是"死的"，如果它的结果永远不会被使用。


const deadCodeElimination: OptimizationPass = {
  name: '死代码消除',
  level: 'global',
  apply: (ir) => {
    const used = new Set<string>();

    for (const instr of ir) {
      if (instr.op === 'ret' && instr.value) used.add(instr.value);
      if (instr.op === 'call') instr.args.forEach((a) => used.add(a));
      if (instr.op === 'store') {
        used.add(instr.addr);
        used.add(instr.value);
      }
      if (instr.op === 'br_if') used.add(instr.cond);
    }

    let changed = true;
    while (changed) {
      changed = false;
      for (const instr of ir) {
        if ('dest' in instr && used.has(instr.dest)) {
          if ('left' in instr && !used.has(instr.left)) {
            used.add(instr.left);
            changed = true;
          }
          if ('right' in instr && !used.has(instr.right)) {
            used.add(instr.right);
            changed = true;
          }
        }
      }
    }

    return ir.filter((instr) => {
      if (
        instr.op === 'call' ||
        instr.op === 'store' ||
        instr.op === 'ret' ||
        instr.op === 'br' ||
        instr.op === 'br_if' ||
        instr.op === 'label'
      ) {
        return true;
      }
      return 'dest' in instr && used.has(instr.dest);
    });
  },
};

const unreachableCodeElimination = (blocks: BasicBlock[]): BasicBlock[] => {
  const reachable = new Set<string>();
  const queue = [blocks[0]?.id];

  while (queue.length > 0) {
    const id = queue.shift()!;
    if (reachable.has(id)) continue;
    reachable.add(id);
    const block = blocks.find((b) => b.id === id);
    if (block) queue.push(...block.successors);
  }

  return blocks.filter((b) => reachable.has(b.id));
};


提示： JavaScript 打包工具中的 Tree Shaking 本质上是模块级的死代码消除——它分析 ESM 的 import / export 依赖图，移除未被引用的导出。Rollup 是第一个实现 Tree Shaking 的打包工具。






内联与循环优化
函数内联（Inlining）将函数调用替换为函数体，消除调用开销并为后续优化创造机会。循环优化针对循环结构进行专门优化。


const shouldInline = (func: IRFunction): boolean => {
  const instrCount = func.body.length;
  const hasLoops = func.body.some((i) => i.op === 'br' || i.op === 'br_if');
  const isRecursive = func.body.some((i) => i.op === 'call' && i.func === func.name);

  if (isRecursive) return false;
  if (instrCount <= 10) return true;
  if (instrCount <= 30 && !hasLoops) return true;
  return false;
};

const inlineCall = (
  callInstr: IRInstruction & { op: 'call' },
  callee: IRFunction,
  uniqueId: number,
): IRInstruction[] => {
  const paramMap = new Map<string, string>();
  callee.params.forEach((p, i) => {
    paramMap.set(p, callInstr.args[i]);
  });

  return callee.body.map((instr) => {
    const rename = (name: string): string => paramMap.get(name) ?? `${name}_inline_${uniqueId}`;

    if (instr.op === 'ret') {
      return { op: 'const' as const, dest: callInstr.dest, value: 0 };
    }
    if ('dest' in instr && 'left' in instr && 'right' in instr) {
      return { ...instr, dest: rename(instr.dest), left: rename(instr.left), right: rename(instr.right) };
    }
    return instr;
  });
};

// 循环不变量外提 (LICM)
const loopInvariantCodeMotion = (loopBlocks: Set<string>, cfg: ControlFlowGraph): IRInstruction[] => {
  const hoisted: IRInstruction[] = [];

  for (const blockId of loopBlocks) {
    const block = cfg.blocks.get(blockId)!;
    for (const instr of block.instructions) {
      if ('left' in instr && 'right' in instr) {
        const leftDef = findDefinition(instr.left, cfg);
        const rightDef = findDefinition(instr.right, cfg);
        if (leftDef && !loopBlocks.has(leftDef) && rightDef && !loopBlocks.has(rightDef)) {
          hoisted.push(instr);
        }
      }
    }
  }
  return hoisted;
};

const findDefinition = (name: string, cfg: ControlFlowGraph): string | null => {
  for (const [blockId, block] of cfg.blocks) {
    if (block.instructions.some((i) => 'dest' in i && i.dest === name)) return blockId;
  }
  return null;
};

窥孔优化
interface PeepholeRule {
  name: string;
  windowSize: number;
  match: (instrs: IRInstruction[]) => boolean;
  replace: (instrs: IRInstruction[]) => IRInstruction[];
}

const peepholeRules: PeepholeRule[] = [
  {
    name: '乘以2→左移',
    windowSize: 1,
    match: (instrs) => instrs[0].op === 'mul' && findConstValue(instrs, instrs[0].right) === 2,
    replace: (instrs) => [{ ...instrs[0], op: 'shl', right: '1' }],
  },
  {
    name: '加0消除',
    windowSize: 1,
    match: (instrs) => instrs[0].op === 'add' && findConstValue(instrs, instrs[0].right) === 0,
    replace: (instrs) => [{ op: 'const' as const, dest: instrs[0].dest, value: 0 }],
  },
  {
    name: '连续跳转合并',
    windowSize: 2,
    match: (instrs) => instrs[0].op === 'br' && instrs[1].op === 'label' && instrs[0].target === instrs[1].name,
    replace: (instrs) => [instrs[1]],
  },
];

const applyPeephole = (ir: IRInstruction[], rules: PeepholeRule[]): IRInstruction[] => {
  const result = [...ir];
  let changed = true;
  while (changed) {
    changed = false;
    for (const rule of rules) {
      for (let i = 0; i <= result.length - rule.windowSize; i++) {
        const window = result.slice(i, i + rule.windowSize);
        if (rule.match(window)) {
          const replacement = rule.replace(window);
          result.splice(i, rule.windowSize, ...replacement);
          changed = true;
          break;
        }
      }
    }
  }
  return result;
};


小结
    

  • 常量折叠在编译时计算常量表达式，是收益最高的基础优化。
    • 

  • 死代码消除移除无用指令，Tree Shaking 是其在模块系统中的应用。
    • 

  • 函数内联消除调用开销并创造后续优化机会，是最强大的过程间优化。
    • 

  • 循环优化（展开、不变量外提、强度削减）针对热点循环产出显著的性能提升。
    • 

  • 窥孔优化通过滑动窗口模式匹配修正局部低效指令序列。
