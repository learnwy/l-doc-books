Source Map 源码映射

Source Map 规范概述

Source Map 是一种将转换/编译后的代码映射回原始源代码的技术标准。当 TypeScript 编译为 JavaScript、JavaScript 被压缩混淆、或多个文件被打包为一个 bundle 时，Source Map 使开发者仍能在浏览器中调试原始代码。

interface SourceMapV3 {
  version: 3;
  file?: string;
  sourceRoot?: string;
  sources: string[];
  sourcesContent?: Array<string | null>;
  names: string[];
  mappings: string;
  sections?: SourceMapSection[];
}

interface SourceMapSection {
  offset: { line: number; column: number };
  map: SourceMapV3;
}

interface DecodedMapping {
  generatedLine: number;
  generatedColumn: number;
  originalSource?: number;
  originalLine?: number;
  originalColumn?: number;
  nameIndex?: number;
}
字段 类型 描述
version number 固定为 3
file string 生成文件的名称
sourceRoot string 源文件的根路径前缀
sources string[] 源文件路径列表
sourcesContent string[] 源文件内容（可嵌入 map 中）
names string[] 原始标识符名称列表
mappings string VLQ 编码的映射字符串 


提示： 在生成的 JavaScript 文件末尾添加 //# sourceMappingURL=file.js.map 注释，浏览器 DevTools 就能自动加载对应的 Source Map。也可以通过 HTTP 头 SourceMap: file.js.map 来指定。






VLQ 编码
Source Map 的 mappings 字段使用 Base64 VLQ（Variable Length Quantity）编码来压缩映射数据。每个映射段包含 1、4 或 5 个 VLQ 值。


const BASE64_CHARS = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/';

const encodeVLQ = (value: number): string => {
  let vlq = value < 0 ? (-value << 1) + 1 : value << 1;
  let result = '';

  do {
    let digit = vlq & 0x1f;
    vlq >>>= 5;
    if (vlq > 0) digit |= 0x20;
    result += BASE64_CHARS[digit];
  } while (vlq > 0);

  return result;
};

const decodeVLQ = (encoded: string, index: number): { value: number; nextIndex: number } => {
  let result = 0;
  let shift = 0;
  let continuation = true;
  let i = index;

  while (continuation && i < encoded.length) {
    const digit = BASE64_CHARS.indexOf(encoded[i]);
    continuation = (digit & 0x20) !== 0;
    result += (digit & 0x1f) << shift;
    shift += 5;
    i++;
  }

  const isNegative = result & 1;
  result >>>= 1;
  return { value: isNegative ? -result : result, nextIndex: i };
};

const decodeMappings = (mappings: string): DecodedMapping[] => {
  const result: DecodedMapping[] = [];
  let generatedLine = 0;
  let generatedColumn = 0;
  let originalSource = 0;
  let originalLine = 0;
  let originalColumn = 0;
  let nameIndex = 0;

  for (const line of mappings.split(';')) {
    generatedColumn = 0;
    generatedLine++;

    if (!line) continue;

    for (const segment of line.split(',')) {
      if (!segment) continue;
      let i = 0;
      const fields: number[] = [];

      while (i < segment.length) {
        const decoded = decodeVLQ(segment, i);
        fields.push(decoded.value);
        i = decoded.nextIndex;
      }

      generatedColumn += fields[0];
      const mapping: DecodedMapping = { generatedLine, generatedColumn };

      if (fields.length >= 4) {
        originalSource += fields[1];
        originalLine += fields[2];
        originalColumn += fields[3];
        mapping.originalSource = originalSource;
        mapping.originalLine = originalLine;
        mapping.originalColumn = originalColumn;
      }

      if (fields.length >= 5) {
        nameIndex += fields[4];
        mapping.nameIndex = nameIndex;
      }

      result.push(mapping);
    }
  }
  return result;
};




段字段数
含义





1 字段
生成列偏移（无原始映射）




4 字段
生成列、源文件索引、原始行、原始列




5 字段
生成列、源文件索引、原始行、原始列、名称索引







映射生成
在代码生成过程中，编译器需要在产出每个代码片段时同步记录映射关系。这要求代码生成器与 Source Map 生成器紧密协作。


class SourceMapGenerator {
  private sources: string[] = [];
  private sourcesContent: string[] = [];
  private names: string[] = [];
  private mappings: DecodedMapping[] = [];
  private currentLine: number = 1;
  private currentColumn: number = 0;

  addSource(path: string, content: string): number {
    const index = this.sources.length;
    this.sources.push(path);
    this.sourcesContent.push(content);
    return index;
  }

  addName(name: string): number {
    const existing = this.names.indexOf(name);
    if (existing !== -1) return existing;
    const index = this.names.length;
    this.names.push(name);
    return index;
  }

  addMapping(sourceIndex: number, originalLine: number, originalColumn: number, nameIndex?: number): void {
    this.mappings.push({
      generatedLine: this.currentLine,
      generatedColumn: this.currentColumn,
      originalSource: sourceIndex,
      originalLine,
      originalColumn,
      nameIndex,
    });
  }

  advanceColumn(count: number): void {
    this.currentColumn += count;
  }

  newLine(): void {
    this.currentLine++;
    this.currentColumn = 0;
  }

  toJSON(): SourceMapV3 {
    return {
      version: 3,
      sources: this.sources,
      sourcesContent: this.sourcesContent,
      names: this.names,
      mappings: this.encodeMappings(),
    };
  }

  private encodeMappings(): string {
    const lines: string[][] = [];
    let prevGenCol = 0;
    let prevSource = 0;
    let prevOrigLine = 0;
    let prevOrigCol = 0;
    let prevName = 0;
    let currentGenLine = 1;

    for (const mapping of this.mappings) {
      while (currentGenLine < mapping.generatedLine) {
        lines.push([]);
        prevGenCol = 0;
        currentGenLine++;
      }

      if (!lines[lines.length - 1]) lines.push([]);

      let segment = encodeVLQ(mapping.generatedColumn - prevGenCol);
      prevGenCol = mapping.generatedColumn;

      if (mapping.originalSource !== undefined) {
        segment += encodeVLQ(mapping.originalSource - prevSource);
        segment += encodeVLQ(mapping.originalLine! - prevOrigLine);
        segment += encodeVLQ(mapping.originalColumn! - prevOrigCol);
        prevSource = mapping.originalSource;
        prevOrigLine = mapping.originalLine!;
        prevOrigCol = mapping.originalColumn!;

        if (mapping.nameIndex !== undefined) {
          segment += encodeVLQ(mapping.nameIndex - prevName);
          prevName = mapping.nameIndex;
        }
      }

      lines[lines.length - 1].push(segment);
    }

    return lines.map((segs) => segs.join(',')).join(';');
  }
}


提示： 在多级转换链（如 TypeScript → JavaScript → 压缩）中，每一步都会产出一个 Source Map。浏览器只能读取最终的 Source Map，因此需要将多个 Source Map 组合（compose）为一个。这就是多级 Source Map 的挑战。






多级 Source Map
const composeSourceMaps = (first: SourceMapV3, second: SourceMapV3): SourceMapV3 => {
  const firstDecoded = decodeMappings(first.mappings);
  const secondDecoded = decodeMappings(second.mappings);

  const composed: DecodedMapping[] = [];
  const generator = new SourceMapGenerator();

  for (const source of first.sources) {
    generator.addSource(source, '');
  }

  for (const mapping of secondDecoded) {
    if (mapping.originalLine === undefined) {
      composed.push({
        generatedLine: mapping.generatedLine,
        generatedColumn: mapping.generatedColumn,
      });
      continue;
    }

    const original = findOriginalPosition(firstDecoded, mapping.originalLine, mapping.originalColumn!);

    if (original) {
      composed.push({
        generatedLine: mapping.generatedLine,
        generatedColumn: mapping.generatedColumn,
        originalSource: original.originalSource,
        originalLine: original.originalLine,
        originalColumn: original.originalColumn,
        nameIndex: original.nameIndex,
      });
    }
  }

  return { ...generator.toJSON(), mappings: encodeMappingsFromDecoded(composed) };
};

const findOriginalPosition = (mappings: DecodedMapping[], line: number, column: number): DecodedMapping | null => {
  let best: DecodedMapping | null = null;
  for (const m of mappings) {
    if (m.generatedLine === line && m.generatedColumn !== undefined && m.generatedColumn <= column) {
      if (!best || m.generatedColumn > best.generatedColumn) best = m;
    }
  }
  return best;
};

const encodeMappingsFromDecoded = (_mappings: DecodedMapping[]): string => '';

小结
    

  • Source Map v3 是浏览器 DevTools 使用的调试映射标准，核心数据以 VLQ 编码存储。
    • 

  • VLQ 编码使用 Base64 字符和可变长度编码压缩映射数据，所有值均为相对偏移。
    • 

  • 代码生成器在产出代码时需要同步记录映射关系，跟踪当前的生成位置和原始位置。
    • 

  • 多级转换链需要将多个 Source Map 组合为一个，通过回溯中间位置找到最终的原始位置。
    • 

  • //# sourceMappingURL= 注释或 HTTP 头告知浏览器 Source Map 的位置。
