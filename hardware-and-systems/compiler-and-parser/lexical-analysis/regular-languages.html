正则语言

正则表达式与编译器

正则表达式在编译器中的地位远超"文本匹配工具"。在词法分析阶段，每一条词法规则本质上就是一个正则表达式，定义了某类 Token 的字符模式。理解正则语言的形式化理论，是深入词法分析器设计的必经之路。

const TOKEN_PATTERNS: Array<[TokenKind, RegExp]> = [
  [TokenKind.Number, /^[0-9]+(\.[0-9]+)?([eE][+-]?[0-9]+)?/],
  [TokenKind.String, /^"([^"\\]|\\.)*"/],
  [TokenKind.Identifier, /^[a-zA-Z_][a-zA-Z0-9_]*/],
  [TokenKind.Plus, /^\+/],
  [TokenKind.Minus, /^-/],
  [TokenKind.Star, /^\*/],
  [TokenKind.LeftParen, /^\(/],
  [TokenKind.RightParen, /^\)/],
];
正则运算 符号 示例 含义
连接 ab if 先匹配 a 再匹配 b
选择 a|b [0-9]|[a-z] 匹配 a 或 b
Kleene 闭包 a* [0-9]* 匹配零次或多次
正闭包 a+ [0-9]+ 匹配一次或多次
可选 a? [eE]? 匹配零次或一次
字符类 [a-z] [a-zA-Z_] 匹配范围内任一字符

提示： 正则语言恰好对应 Chomsky 层级中的第 3 类（正则文法）。词法分析可以用正则语言完成，但语法分析需要第 2 类（上下文无关文法）的能力。这就是编译器分为词法分析和语法分析两个阶段的理论根源。

有限自动机基础

正则表达式的执行模型是有限自动机。NFA（非确定性有限自动机）允许从一个状态通过同一字符转移到多个状态，或通过 ε（空转移）无需消费字符即可跳转。

interface NFAState {
  id: number;
  transitions: Map<string, Set<number>>;
  epsilonTransitions: Set<number>;
  accepting: boolean;
}

interface NFA {
  start: NFAState;
  accept: NFAState;
}

const createCharNFA = (ch: string): NFA => {
  const start: NFAState = {
    id: 0,
    transitions: new Map([[ch, new Set([1])]]),
    epsilonTransitions: new Set(),
    accepting: false,
  };
  const accept: NFAState = {
    id: 1,
    transitions: new Map(),
    epsilonTransitions: new Set(),
    accepting: true,
  };
  return { start, accept };
};

Thompson 构造法
Thompson 构造法是将正则表达式转换为 NFA 的经典算法。它为每种正则运算定义一个构造模板，通过递归组合生成完整的 NFA。


const concatenate = (a: NFA, b: NFA): NFA => {
  a.accept.accepting = false;
  a.accept.epsilonTransitions.add(b.start.id);
  return { start: a.start, accept: b.accept };
};

const alternate = (a: NFA, b: NFA, nextId: () => number): NFA => {
  const start: NFAState = {
    id: nextId(),
    transitions: new Map(),
    epsilonTransitions: new Set([a.start.id, b.start.id]),
    accepting: false,
  };
  const accept: NFAState = {
    id: nextId(),
    transitions: new Map(),
    epsilonTransitions: new Set(),
    accepting: true,
  };
  a.accept.accepting = false;
  b.accept.accepting = false;
  a.accept.epsilonTransitions.add(accept.id);
  b.accept.epsilonTransitions.add(accept.id);
  return { start, accept };
};

const kleeneStar = (a: NFA, nextId: () => number): NFA => {
  const start: NFAState = {
    id: nextId(),
    transitions: new Map(),
    epsilonTransitions: new Set([a.start.id]),
    accepting: false,
  };
  const accept: NFAState = {
    id: nextId(),
    transitions: new Map(),
    epsilonTransitions: new Set(),
    accepting: true,
  };
  start.epsilonTransitions.add(accept.id);
  a.accept.accepting = false;
  a.accept.epsilonTransitions.add(a.start.id);
  a.accept.epsilonTransitions.add(accept.id);
  return { start, accept };
};


提示： Thompson 构造法保证生成的 NFA 状态数与正则表达式长度成线性关系。这一性质使得从正则表达式到 NFA 的转换非常高效，是词法分析器生成器（如 flex）的核心算法之一。






DFA 最小化
子集构造法将 NFA 转换为 DFA 后，生成的 DFA 可能包含等价状态。DFA 最小化通过Hopcroft 算法合并等价状态，产生状态数最少的等价 DFA。


interface Partition {
  groups: Set<number>[];
}

const minimizeDFA = (dfa: DFAState[], alphabet: string[]): DFAState[] => {
  let partition: Set<number>[] = [];
  const accepting = new Set<number>();
  const nonAccepting = new Set<number>();

  for (const state of dfa) {
    if (state.accepting !== null) {
      accepting.add(state.id);
    } else {
      nonAccepting.add(state.id);
    }
  }

  if (accepting.size > 0) partition.push(accepting);
  if (nonAccepting.size > 0) partition.push(nonAccepting);

  let changed = true;
  while (changed) {
    changed = false;
    const newPartition: Set<number>[] = [];
    for (const group of partition) {
      const split = refineGroup(group, partition, dfa, alphabet);
      newPartition.push(...split);
      if (split.length > 1) changed = true;
    }
    partition = newPartition;
  }

  return buildMinimizedDFA(partition, dfa, alphabet);
};

const refineGroup = (
  group: Set<number>,
  partition: Set<number>[],
  dfa: DFAState[],
  alphabet: string[],
): Set<number>[] => {
  const groupArr = [...group];
  const representative = groupArr[0];
  const same = new Set([representative]);
  const different = new Set<number>();

  for (let i = 1; i < groupArr.length; i++) {
    const state = groupArr[i];
    let equivalent = true;
    for (const ch of alphabet) {
      const repTarget = dfa[representative].transitions.get(ch);
      const stateTarget = dfa[state].transitions.get(ch);
      if (findGroup(repTarget, partition) !== findGroup(stateTarget, partition)) {
        equivalent = false;
        break;
      }
    }
    if (equivalent) same.add(state);
    else different.add(state);
  }

  return different.size === 0 ? [same] : [same, different];
};

const findGroup = (stateId: number | undefined, partition: Set<number>[]): number =>
  stateId === undefined ? -1 : partition.findIndex((g) => g.has(stateId));

const buildMinimizedDFA = (partition: Set<number>[], dfa: DFAState[], alphabet: string[]): DFAState[] =>
  partition.map((group, i) => {
    const rep = dfa[[...group][0]];
    const transitions = new Map<string, number>();
    for (const ch of alphabet) {
      const target = rep.transitions.get(ch);
      if (target !== undefined) {
        transitions.set(ch, findGroup(target, partition));
      }
    }
    return { id: i, transitions, accepting: rep.accepting };
  });

小结
    

  • 正则表达式是词法规则的形式化表达，对应 Chomsky 层级的第 3 类语言。
    • 

  • NFA 允许非确定转移和 ε 转移，构造简单但执行需要模拟多路径。
    • 

  • Thompson 构造法以线性复杂度将正则表达式转换为 NFA，是词法生成器的核心算法。
    • 

  • 子集构造法将 NFA 转换为 DFA，保证 O(n) 的匹配性能，代价是可能的状态数指数增长。
    • 

  • Hopcroft 算法通过 O(n log n) 的 DFA 最小化消除等价状态，得到最优状态机。
