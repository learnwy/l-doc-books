TypeScript 编译器 API

编译器核心抽象

TypeScript 编译器不仅是一个命令行工具，更是一套功能完整的编程 API。通过 typescript 包，开发者可以编程式地创建 Program、解析源文件、执行类型检查、遍历 AST 和应用自定义转换。

import ts from 'typescript';

const createProgram = (filePaths: string[], options: ts.CompilerOptions): ts.Program => {
  return ts.createProgram(filePaths, options);
};

const analyzeProgram = (
  program: ts.Program,
): {
  fileCount: number;
  diagnosticCount: number;
  typeCount: number;
} => {
  const checker = program.getTypeChecker();
  const sourceFiles = program.getSourceFiles().filter((f) => !f.isDeclarationFile);
  const diagnostics = [...program.getSyntacticDiagnostics(), ...program.getSemanticDiagnostics()];

  let typeCount = 0;
  for (const sf of sourceFiles) {
    ts.forEachChild(sf, function visit(node) {
      if (ts.isIdentifier(node)) {
        checker.getTypeAtLocation(node);
        typeCount++;
      }
      ts.forEachChild(node, visit);
    });
  }

  return {
    fileCount: sourceFiles.length,
    diagnosticCount: diagnostics.length,
    typeCount,
  };
};
核心类型 职责
Program 编译单元的入口，管理所有源文件
SourceFile 单个文件的 AST 根节点
TypeChecker 类型检查与类型查询的核心引擎
Symbol 标识符的编译器内部表示
Type 类型的编译器内部表示
Node AST 节点基类，所有语法构造的共同接口 


提示： ts.createProgram 是单次编译的入口。对于 watch 模式或增量编译，应使用 ts.createWatchProgram 或 ts.createIncrementalProgram，它们能复用上一次编译的缓存，显著提升编译速度。






SourceFile 与 AST 遍历
SourceFile 是单个文件的 AST 根节点。TypeScript 的 AST 节点使用数字枚举 SyntaxKind 作为类型标识，提供丰富的类型守卫函数用于节点类型判断。


const parseSourceFile = (code: string, fileName: string = 'input.ts'): ts.SourceFile => {
  return ts.createSourceFile(fileName, code, ts.ScriptTarget.Latest, true);
};

const walkAST = (sourceFile: ts.SourceFile): void => {
  const visit = (node: ts.Node, depth: number): void => {
    const indent = '  '.repeat(depth);
    const kindName = ts.SyntaxKind[node.kind];
    const text = node.getText(sourceFile).slice(0, 40);
    console.log(`${indent}${kindName}: "${text}"`);
    ts.forEachChild(node, (child) => visit(child, depth + 1));
  };
  visit(sourceFile, 0);
};

const findAllFunctions = (sourceFile: ts.SourceFile): ts.FunctionDeclaration[] => {
  const functions: ts.FunctionDeclaration[] = [];
  const visit = (node: ts.Node): void => {
    if (ts.isFunctionDeclaration(node) && node.name) {
      functions.push(node);
    }
    ts.forEachChild(node, visit);
  };
  visit(sourceFile);
  return functions;
};

const getNodeInfo = (
  node: ts.Node,
  sourceFile: ts.SourceFile,
): {
  kind: string;
  text: string;
  pos: { line: number; character: number };
  children: number;
} => {
  const { line, character } = sourceFile.getLineAndCharacterOfPosition(node.getStart(sourceFile));
  let childCount = 0;
  ts.forEachChild(node, () => {
    childCount++;
  });
  return {
    kind: ts.SyntaxKind[node.kind],
    text: node.getText(sourceFile),
    pos: { line: line + 1, character: character + 1 },
    children: childCount,
  };
};

TypeChecker 查询
TypeChecker 是 TypeScript 编译器最强大的组件之一。它不仅负责类型检查，还提供了丰富的类型查询 API，让你可以在任意 AST 节点上获取类型信息。


const queryTypes = (program: ts.Program, sourceFile: ts.SourceFile): void => {
  const checker = program.getTypeChecker();

  const visit = (node: ts.Node): void => {
    if (ts.isVariableDeclaration(node) && node.name && ts.isIdentifier(node.name)) {
      const symbol = checker.getSymbolAtLocation(node.name);
      if (symbol) {
        const type = checker.getTypeOfSymbolAtLocation(symbol, node);
        const typeString = checker.typeToString(type);
        console.log(`${node.name.text}: ${typeString}`);
      }
    }

    if (ts.isCallExpression(node)) {
      const signature = checker.getResolvedSignature(node);
      if (signature) {
        const returnType = checker.getReturnTypeOfSignature(signature);
        console.log(`调用返回类型: ${checker.typeToString(returnType)}`);
      }
    }

    ts.forEachChild(node, visit);
  };
  visit(sourceFile);
};

const getTypeAtPosition = (program: ts.Program, sourceFile: ts.SourceFile, position: number): string | null => {
  const checker = program.getTypeChecker();
  const token = findTokenAtPosition(sourceFile, position);
  if (!token) return null;

  const symbol = checker.getSymbolAtLocation(token);
  if (!symbol) return null;

  const type = checker.getTypeOfSymbolAtLocation(symbol, token);
  return checker.typeToString(type, undefined, ts.TypeFormatFlags.NoTruncation);
};

const findTokenAtPosition = (sourceFile: ts.SourceFile, position: number): ts.Node | null => {
  const find = (node: ts.Node): ts.Node | null => {
    if (position >= node.getStart(sourceFile) && position < node.getEnd()) {
      const child = ts.forEachChild(node, find);
      return child ?? node;
    }
    return null;
  };
  return find(sourceFile);
};

提示： TypeChecker 是有状态的——它在首次类型检查时构建内部缓存。因此，同一个 Program 上的多次 TypeChecker 查询非常高效。但不同 Program 之间不能共享 TypeChecker。






自定义 Transform
TypeScript 的 Transform API 允许你在编译管线中插入自定义的 AST 变换，实现代码改写、宏展开、自动化注入等功能。


const createEnumToObjectTransform = (): ts.TransformerFactory<ts.SourceFile> => (context) => (sourceFile) => {
  const visitor = (node: ts.Node): ts.Node => {
    if (ts.isEnumDeclaration(node)) {
      return convertEnumToObject(node, context.factory);
    }
    return ts.visitEachChild(node, visitor, context);
  };
  return ts.visitNode(sourceFile, visitor) as ts.SourceFile;
};

const convertEnumToObject = (enumDecl: ts.EnumDeclaration, factory: ts.NodeFactory): ts.VariableStatement => {
  const properties = enumDecl.members.map((member, index) => {
    const name = member.name.getText();
    const value = member.initializer ?? factory.createNumericLiteral(index);
    return factory.createPropertyAssignment(name, value);
  });

  const objectLiteral = factory.createObjectLiteralExpression(properties, true);
  const asConst = factory.createAsExpression(objectLiteral, factory.createTypeReferenceNode('const'));

  return factory.createVariableStatement(
    enumDecl.modifiers,
    factory.createVariableDeclarationList(
      [factory.createVariableDeclaration(enumDecl.name, undefined, undefined, asConst)],
      ts.NodeFlags.Const,
    ),
  );
};

const applyTransform = (code: string, transforms: ts.TransformerFactory<ts.SourceFile>[]): string => {
  const sourceFile = ts.createSourceFile('input.ts', code, ts.ScriptTarget.Latest, true);
  const result = ts.transform(sourceFile, transforms);
  const printer = ts.createPrinter();
  return printer.printFile(result.transformed[0]);
};


小结
    

  • Program 是编译单元的入口，封装了所有源文件、配置和类型检查器。
    • 

  • SourceFile 包含单个文件的完整 AST，通过 ts.forEachChild 进行遍历。
    • 

  • TypeChecker 提供丰富的类型查询 API，可以在任意 AST 节点上获取类型信息。
    • 

  • Transform API 允许插入自定义 AST 变换，是实现编译时代码改写的标准机制。
    • 

  • TypeScript 编译器 API 的设计哲学是"编译器即库"——所有内部功能都通过公开 API 暴露。
