Lint 与 Codemod

ESLint 规则编写

ESLint 是 JavaScript/TypeScript 生态中最重要的静态分析工具。自定义 ESLint 规则让你可以针对团队规范、安全要求或性能最佳实践进行自动化检查。每条规则本质上是一个 AST Visitor。

interface ESLintRule {
  meta: RuleMeta;
  create: (context: RuleContext) => Record<string, (node: ESLintNode) => void>;
}

interface RuleMeta {
  type: 'problem' | 'suggestion' | 'layout';
  docs: { description: string; recommended: boolean };
  fixable?: 'code' | 'whitespace';
  schema: unknown[];
  messages: Record<string, string>;
}

interface RuleContext {
  report: (descriptor: ReportDescriptor) => void;
  getSourceCode: () => SourceCode;
  options: unknown[];
}

interface ReportDescriptor {
  node: ESLintNode;
  messageId: string;
  data?: Record<string, string>;
  fix?: (fixer: Fixer) => Fix | Fix[];
}

interface Fixer {
  replaceText(node: ESLintNode, text: string): Fix;
  replaceTextRange(range: [number, number], text: string): Fix;
  insertTextBefore(node: ESLintNode, text: string): Fix;
  insertTextAfter(node: ESLintNode, text: string): Fix;
  remove(node: ESLintNode): Fix;
}

interface Fix {
  range: [number, number];
  text: string;
}
interface SourceCode {
  getText(node?: ESLintNode): string;
  getScope(node: ESLintNode): unknown;
}
interface ESLintNode {
  type: string;
  range: [number, number];
  name?: string;
  [key: string]: unknown;
}

const noMagicNumbersRule: ESLintRule = {
  meta: {
    type: 'suggestion',
    docs: { description: '禁止使用魔术数字', recommended: true },
    fixable: undefined,
    schema: [{ type: 'object', properties: { ignore: { type: 'array', items: { type: 'number' } } } }],
    messages: { noMagicNumber: '避免使用魔术数字 {{value}}，请提取为命名常量' },
  },
  create: (context) => {
    const ignore = new Set((context.options[0] as { ignore?: number[] })?.ignore ?? [0, 1, -1]);
    return {
      Literal(node: ESLintNode) {
        if (typeof node.value === 'number' && !ignore.has(node.value)) {
          const parent = node.parent as ESLintNode | undefined;
          if (parent?.type !== 'VariableDeclarator' && parent?.type !== 'Property') {
            context.report({ node, messageId: 'noMagicNumber', data: { value: String(node.value) } });
          }
        }
      },
    };
  },
};
规则类型 描述 示例
problem 检测可能的错误 no-undef, no-dupe-keys
suggestion 建议更好的写法 prefer-const, eqeqeq
layout 代码格式问题 indent, semi 


提示： ESLint 的 AST 选择器语法让你可以用 CSS 选择器风格匹配 AST 节点。例如 'CallExpression[callee.name="require"]' 匹配所有 require() 调用，无需手动判断节点类型。






AST 选择器
ESLint 支持一种类似 CSS 选择器的语法来匹配 AST 节点，让规则编写更加声明式和简洁。


const astSelectorExamples: Record<string, string> = {
  CallExpression: '匹配所有函数调用',
  'CallExpression[callee.name="eval"]': '匹配 eval() 调用',
  'MemberExpression[object.name="console"]': '匹配 console.xxx',
  'VariableDeclaration[kind="var"]': '匹配 var 声明',
  'BinaryExpression[operator="=="]': '匹配 == 运算',
  'FunctionDeclaration > BlockStatement': '函数体直接子节点',
  'IfStatement IfStatement': '嵌套的 if 语句',
  ':matches(FunctionDeclaration, ArrowFunctionExpression)': '任意函数',
  ':not(ExportNamedDeclaration) > FunctionDeclaration': '未导出的函数',
  'ForStatement ~ VariableDeclaration': '紧跟 for 循环的声明',
};

const noEvalRule: ESLintRule = {
  meta: {
    type: 'problem',
    docs: { description: '禁止使用 eval', recommended: true },
    fixable: undefined,
    schema: [],
    messages: { noEval: '禁止使用 eval()，它会导致代码注入风险' },
  },
  create: (context) => ({
    'CallExpression[callee.name="eval"]'(node: ESLintNode) {
      context.report({ node, messageId: 'noEval' });
    },
  }),
};

const preferConstRule: ESLintRule = {
  meta: {
    type: 'suggestion',
    docs: { description: '优先使用 const', recommended: true },
    fixable: 'code',
    schema: [],
    messages: { preferConst: '变量 {{name}} 从未被重新赋值，应使用 const' },
  },
  create: (context) => ({
    'VariableDeclaration[kind="let"]'(node: ESLintNode) {
      const declarations = node.declarations as ESLintNode[];
      for (const decl of declarations) {
        const id = decl.id as ESLintNode;
        if (id.name) {
          const scope = context.getSourceCode().getScope(node);
          const binding = (scope as Record<string, unknown>).variables;
          if (binding) {
            context.report({
              node: decl,
              messageId: 'preferConst',
              data: { name: id.name },
              fix: (fixer) => fixer.replaceTextRange([node.range[0], node.range[0] + 3], 'const'),
            });
          }
        }
      }
    },
  }),
};

jscodeshift Codemod
Codemod 是大规模自动化代码重构的工具。jscodeshift 提供了一个强大的 API，让你可以编程式地搜索、匹配和变换 AST。


interface JSCodeshiftAPI {
  (source: string): Collection;
  Identifier: { name: string };
  CallExpression: unknown;
  MemberExpression: unknown;
}

interface Collection {
  find(type: unknown, filter?: Record<string, unknown>): Collection;
  filter(callback: (path: JSCSPath) => boolean): Collection;
  replaceWith(callback: (path: JSCSPath) => unknown): Collection;
  forEach(callback: (path: JSCSPath) => void): void;
  remove(): void;
  toSource(): string;
  length: number;
}

interface JSCSPath {
  node: Record<string, unknown>;
  value: Record<string, unknown>;
  parent: JSCSPath;
  scope: unknown;
}

const migrateApiV1ToV2 = (fileInfo: { source: string }, api: JSCodeshiftAPI): string => {
  const j = api;
  const root = j(fileInfo.source);

  root
    .find(j.CallExpression, {
      callee: { object: { name: 'api' }, property: { name: 'fetchData' } },
    })
    .replaceWith((path: JSCSPath) => {
      const args = path.value.arguments as unknown[];
      return {
        type: 'CallExpression',
        callee: {
          type: 'MemberExpression',
          object: { type: 'Identifier', name: 'api' },
          property: { type: 'Identifier', name: 'query' },
        },
        arguments: [
          {
            type: 'ObjectExpression',
            properties: [
              { type: 'ObjectProperty', key: { type: 'Identifier', name: 'url' }, value: args[0] },
              {
                type: 'ObjectProperty',
                key: { type: 'Identifier', name: 'params' },
                value: args[1] ?? { type: 'ObjectExpression', properties: [] },
              },
            ],
          },
        ],
      };
    });

  return root.toSource();
};

const renameImport = (
  fileInfo: { source: string },
  api: JSCodeshiftAPI,
  options: { from: string; to: string },
): string => {
  const j = api;
  const root = j(fileInfo.source);

  root
    .find(j.Identifier, { name: options.from })
    .filter((path: JSCSPath) => {
      const parent = path.parent.value;
      return (
        (parent as Record<string, unknown>).type === 'ImportSpecifier' ||
        (parent as Record<string, unknown>).type === 'ImportDefaultSpecifier'
      );
    })
    .forEach((path: JSCSPath) => {
      (path.node as Record<string, unknown>).name = options.to;
    });

  root.find(j.Identifier, { name: options.from }).forEach((path: JSCSPath) => {
    (path.node as Record<string, unknown>).name = options.to;
  });

  return root.toSource();
};

大规模重构实践
interface CodemodPipeline {
  name: string;
  description: string;
  transforms: Array<{
    name: string;
    glob: string;
    transform: (source: string) => string;
    dryRun?: boolean;
  }>;
}

const apiMigrationPipeline: CodemodPipeline = {
  name: 'API v1 → v2 迁移',
  description: '将所有 API v1 调用迁移到 v2',
  transforms: [
    {
      name: '重命名导入',
      glob: 'src/**/*.ts',
      transform: (source) => source.replace(/from 'api-v1'/g, "from 'api-v2'"),
    },
    {
      name: '更新调用签名',
      glob: 'src/**/*.ts',
      transform: (source) => source,
    },
    {
      name: '移除废弃 polyfill',
      glob: 'src/**/*.ts',
      transform: (source) => source.replace(/import.*polyfill-v1.*;\n/g, ''),
    },
  ],
};

const executePipeline = async (
  pipeline: CodemodPipeline,
): Promise<{
  filesProcessed: number;
  filesChanged: number;
  errors: string[];
}> => {
  let filesProcessed = 0;
  let filesChanged = 0;
  const errors: string[] = [];

  for (const step of pipeline.transforms) {
    console.log(`执行步骤: ${step.name} (${step.glob})`);
    filesProcessed += 10;
    filesChanged += 5;
  }

  return { filesProcessed, filesChanged, errors };
};

小结
    

  • ESLint 规则本质上是 AST Visitor，通过 context.report 报告问题，通过 fix 函数提供自动修复。
    • 

  • AST 选择器用 CSS 选择器风格匹配 AST 节点，使规则编写更加声明式和简洁。
    • 

  • jscodeshift 提供了编程式的 AST 搜索与变换 API，是大规模代码重构的标准工具。
    • 

  • 大规模重构应遵循原子变更、幂等性、渐进式验证的原则，配合版本控制保障安全性。
    • 

  • 编译器思维在日常开发中的最大应用场景就是 Lint 规则编写和 Codemod 自动化重构。
