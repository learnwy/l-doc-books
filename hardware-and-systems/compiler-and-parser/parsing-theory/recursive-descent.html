递归下降解析

什么是递归下降

递归下降解析（Recursive Descent Parsing）是最直观的手写解析技术。每个语法规则对应一个解析函数，函数之间通过递归调用反映文法的结构。它是 TypeScript、Go、Rust、Swift 等主流编译器的解析器实现方式。

interface ASTNode {
  kind: string;
  [key: string]: unknown;
}

interface NumberLiteral extends ASTNode {
  kind: 'NumberLiteral';
  value: number;
}

interface BinaryExpr extends ASTNode {
  kind: 'BinaryExpr';
  op: string;
  left: ASTNode;
  right: ASTNode;
}

interface CallExpr extends ASTNode {
  kind: 'CallExpr';
  callee: ASTNode;
  args: ASTNode[];
}

class Parser {
  private tokens: Token[];
  private pos: number = 0;

  constructor(tokens: Token[]) {
    this.tokens = tokens;
  }

  private peek(): Token {
    return this.tokens[this.pos];
  }

  private advance(): Token {
    return this.tokens[this.pos++];
  }

  private expect(kind: TokenKind): Token {
    const token = this.peek();
    if (token.kind !== kind) {
      throw new Error(`期望 ${kind}，实际得到 ${token.kind} at ${token.line}:${token.column}`);
    }
    return this.advance();
  }

  private check(kind: TokenKind): boolean {
    return this.peek().kind === kind;
  }
}
解析器类型 实现方式 文法限制 典型使用者
递归下降 手写递归 LL(k)，需消左递归 TypeScript, Go, Rust
Pratt 解析 手写循环 自然处理优先级 表达式子解析器
PEG/Packrat 记忆化递归 无左递归，有序选择 tree-sitter, pest
LR 表驱动 LR(1) 文法 yacc, bison 


提示： 递归下降解析器的代码结构直接映射文法规则，这使得阅读和调试非常直观。如果你能写出 BNF 文法，就能几乎机械地翻译为递归下降代码。






预测解析与 FIRST 集
预测解析（Predictive Parsing）是递归下降的一种特殊形式——解析器仅通过查看当前 Token（前看符号）就能决定选择哪条产生式，无需回溯。


class PredictiveParser extends Parser {
  parseStatement(): ASTNode {
    const token = this.peek();
    switch (token.lexeme) {
      case 'let':
      case 'const':
        return this.parseVariableDeclaration();
      case 'if':
        return this.parseIfStatement();
      case 'while':
        return this.parseWhileStatement();
      case 'return':
        return this.parseReturnStatement();
      case '{':
        return this.parseBlock();
      default:
        return this.parseExpressionStatement();
    }
  }

  private parseVariableDeclaration(): ASTNode {
    const keyword = this.advance();
    const name = this.expect(TokenKind.Identifier);
    this.expect(TokenKind.Equals);
    const init = this.parseExpression();
    this.expect(TokenKind.Semicolon);
    return { kind: 'VarDecl', mutable: keyword.lexeme === 'let', name: name.lexeme, init };
  }

  private parseIfStatement(): ASTNode {
    this.advance();
    this.expect(TokenKind.LeftParen);
    const condition = this.parseExpression();
    this.expect(TokenKind.RightParen);
    const consequent = this.parseStatement();
    let alternate: ASTNode | null = null;
    if (this.peek().lexeme === 'else') {
      this.advance();
      alternate = this.parseStatement();
    }
    return { kind: 'IfStmt', condition, consequent, alternate };
  }

  private parseWhileStatement(): ASTNode {
    this.advance();
    this.expect(TokenKind.LeftParen);
    const condition = this.parseExpression();
    this.expect(TokenKind.RightParen);
    const body = this.parseStatement();
    return { kind: 'WhileStmt', condition, body };
  }

  private parseReturnStatement(): ASTNode {
    this.advance();
    const value = this.check(TokenKind.Semicolon) ? null : this.parseExpression();
    this.expect(TokenKind.Semicolon);
    return { kind: 'ReturnStmt', value };
  }

  private parseBlock(): ASTNode {
    this.expect(TokenKind.LeftBrace);
    const body: ASTNode[] = [];
    while (!this.check(TokenKind.RightBrace) && !this.check(TokenKind.EOF)) {
      body.push(this.parseStatement());
    }
    this.expect(TokenKind.RightBrace);
    return { kind: 'Block', body };
  }

  parseExpression(): ASTNode {
    return { kind: 'Placeholder' };
  }
  private parseExpressionStatement(): ASTNode {
    const expr = this.parseExpression();
    this.expect(TokenKind.Semicolon);
    return { kind: 'ExprStmt', expr };
  }
}

左递归消除
递归下降解析器无法直接处理左递归文法，因为左递归会导致无限递归调用。


// expr → expr '+' term | term
// 左递归消除后：
// expr  → term expr'
// expr' → '+' term expr' | ε

const parseExprEliminated = (parser: PredictiveParser): ASTNode => {
  let left = parseTerm(parser);
  while (parser.peek().kind === TokenKind.Plus || parser.peek().kind === TokenKind.Minus) {
    const op = parser.advance();
    const right = parseTerm(parser);
    left = { kind: 'BinaryExpr', op: op.lexeme, left, right } as BinaryExpr;
  }
  return left;
};

const parseTerm = (parser: PredictiveParser): ASTNode => {
  let left = parseFactor(parser);
  while (parser.peek().kind === TokenKind.Star || parser.peek().kind === TokenKind.Slash) {
    const op = parser.advance();
    const right = parseFactor(parser);
    left = { kind: 'BinaryExpr', op: op.lexeme, left, right } as BinaryExpr;
  }
  return left;
};

const parseFactor = (parser: PredictiveParser): ASTNode => {
  if (parser.peek().kind === TokenKind.Number) {
    const token = parser.advance();
    return { kind: 'NumberLiteral', value: parseFloat(token.lexeme) } as NumberLiteral;
  }
  if (parser.peek().kind === TokenKind.LeftParen) {
    parser.advance();
    const expr = parseExprEliminated(parser);
    parser.expect(TokenKind.RightParen);
    return expr;
  }
  throw new Error(`意外的 Token: ${parser.peek().lexeme}`);
};


提示： 左递归消除的 while 循环模式自然产生左结合的 AST。如果需要右结合（如赋值运算符 =），应使用递归而非循环：parseAssign → parseTerm '=' parseAssign。






Pratt 解析
Pratt 解析（也称优先级攀升解析）是处理表达式优先级和结合性最优雅的手写解析技术。它为每种 Token 关联一个绑定力（Binding Power），通过比较左右绑定力决定解析方向。


type PrefixParseFn = (parser: PrattParser, token: Token) => ASTNode;
type InfixParseFn = (parser: PrattParser, left: ASTNode, token: Token) => ASTNode;

interface PrefixRule {
  parse: PrefixParseFn;
}

interface InfixRule {
  parse: InfixParseFn;
  precedence: number;
}

class PrattParser extends Parser {
  private prefixRules: Map<TokenKind, PrefixRule> = new Map();
  private infixRules: Map<TokenKind, InfixRule> = new Map();

  registerPrefix(kind: TokenKind, parse: PrefixParseFn): void {
    this.prefixRules.set(kind, { parse });
  }

  registerInfix(kind: TokenKind, precedence: number, parse: InfixParseFn): void {
    this.infixRules.set(kind, { parse, precedence });
  }

  parseExpression(minPrecedence: number = 0): ASTNode {
    const token = this.advance();
    const prefix = this.prefixRules.get(token.kind);
    if (!prefix) throw new Error(`无前缀解析规则: ${token.lexeme}`);

    let left = prefix.parse(this, token);

    while (this.pos < this.tokens.length) {
      const infix = this.infixRules.get(this.peek().kind);
      if (!infix || infix.precedence <= minPrecedence) break;

      const opToken = this.advance();
      left = infix.parse(this, left, opToken);
    }

    return left;
  }
}

const setupPratt = (parser: PrattParser): void => {
  parser.registerPrefix(
    TokenKind.Number,
    (_p, t) => ({ kind: 'NumberLiteral', value: parseFloat(t.lexeme) }) as NumberLiteral,
  );

  parser.registerPrefix(TokenKind.Minus, (p, _t) => ({ kind: 'UnaryExpr', op: '-', operand: p.parseExpression(70) }));

  parser.registerPrefix(TokenKind.LeftParen, (p, _t) => {
    const expr = p.parseExpression(0);
    p.expect(TokenKind.RightParen);
    return expr;
  });

  const binaryInfix =
    (precedence: number): InfixParseFn =>
    (p, left, t) =>
      ({
        kind: 'BinaryExpr',
        op: t.lexeme,
        left,
        right: p.parseExpression(precedence),
      }) as BinaryExpr;

  parser.registerInfix(TokenKind.Plus, 50, binaryInfix(50));
  parser.registerInfix(TokenKind.Minus, 50, binaryInfix(50));
  parser.registerInfix(TokenKind.Star, 60, binaryInfix(60));
  parser.registerInfix(TokenKind.Slash, 60, binaryInfix(60));
};

小结
    

  • 递归下降将每条文法规则映射为一个解析函数，代码结构直接反映文法结构。
    • 

  • 预测解析通过 FIRST 集在 LL(1) 条件下实现零回溯的分支选择。
    • 

  • 左递归消除将递归调用转换为 while 循环，自然产生左结合的 AST 节点。
    • 

  • Pratt 解析通过绑定力机制优雅地处理任意数量的优先级层级和结合性方向。
    • 

  • 现代主流编译器（TypeScript、Rust、Go）均使用递归下降 + Pratt 解析的组合方案。
