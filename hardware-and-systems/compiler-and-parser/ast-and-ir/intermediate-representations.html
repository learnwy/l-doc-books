Part IV · 编辑器与编译器编译原理与解析器 简介AST 与 IR 简介中间表示

中间表示

核心概念

IR（中间表示）是编译器前端与后端之间的桥梁：前端把源语言降级为 IR，后端把 IR 提升为目标代码，优化则在 IR 上统一进行。它的核心概念包括：

  • 分层抽象：高级 IR 接近源码（保留类型信息，便于类型检查与宏展开），中级 IR 服务于优化（三地址码、SSA），低级 IR 接近机器（寄存器分配后的指令）。
  • 三地址码：每条指令最多一个运算符、三个操作数，把复杂表达式拆成线性指令序列，是优化的理想形态。
  • SSA（静态单赋值）：每个变量只被赋值一次，用 phi 节点在控制流汇合处选择来源；它让「定义-使用」关系显式化，大幅简化数据流分析。
  • 控制流图（CFG）与基本块：把线性的指令组织成以基本块为节点、跳转为边的图，是全局优化的作用骨架。

IR 的设计取舍（偏向底层以支持多后端，还是偏向高层以保留语义）直接决定了一个编译器能做哪些优化、支持哪些目标。

为什么需要 IR

中间表示（Intermediate Representation，IR）是编译器前端与后端之间的桥梁。它将源语言的高层抽象转换为更接近目标机器的低层表示，使得优化 Pass 可以在统一的、语言无关的抽象层上工作。

type IRInstruction =
  | { op: 'const'; dest: string; value: number }
  | { op: 'add'; dest: string; left: string; right: string }
  | { op: 'sub'; dest: string; left: string; right: string }
  | { op: 'mul'; dest: string; left: string; right: string }
  | { op: 'div'; dest: string; left: string; right: string }
  | { op: 'load'; dest: string; addr: string }
  | { op: 'store'; addr: string; value: string }
  | { op: 'call'; dest: string; func: string; args: string[] }
  | { op: 'ret'; value: string | null }
  | { op: 'br'; target: string }
  | { op: 'br_if'; cond: string; thenTarget: string; elseTarget: string }
  | { op: 'phi'; dest: string; sources: Array<{ value: string; block: string }> }
  | { op: 'label'; name: string };

interface IRFunction {
  name: string;
  params: string[];
  body: IRInstruction[];
  locals: Map<string, IRType>;
}

type IRType = 'i32' | 'i64' | 'f32' | 'f64' | 'bool' | 'ptr';
IR 层级 抽象程度 示例 用途
高级 IR 接近源码 AST / 类型化 AST 类型检查、宏展开
中级 IR 中间层 三地址码 / SSA 大部分优化 Pass
低级 IR 接近机器 寄存器分配后的指令 指令选择、调度

提示： 经典的编译器教科书强调"IR 应该与源语言和目标机器都无关"。但在工程实践中，高质量的 IR 设计需要在抽象层级上做精心的取舍——LLVM IR 偏向底层以支持多后端，而 TypeScript 的 IR 偏向高层以保留类型信息。

三地址码

三地址码（Three-Address Code，TAC）是最经典的 IR 形式。每条指令最多包含三个地址（操作数），形如 x = y op z。

interface ThreeAddrInstr {
  dest: string;
  op: string;
  arg1: string;
  arg2?: string;
}

const astToTAC = (expr: BaseNode, tempCounter: { count: number }): { instrs: ThreeAddrInstr[]; result: string } => {
  if (expr.kind === 'NumberLiteral') {
    const temp = `t${tempCounter.count++}`;
    return {
      instrs: [{ dest: temp, op: 'const', arg1: String((expr as NumberLiteral).value) }],
      result: temp,
    };
  }

  if (expr.kind === 'BinaryExpression') {
    const bin = expr as BinaryExpression;
    const left = astToTAC(bin.left, tempCounter);
    const right = astToTAC(bin.right, tempCounter);
    const temp = `t${tempCounter.count++}`;
    return {
      instrs: [
        ...left.instrs,
        ...right.instrs,
        { dest: temp, op: bin.operator, arg1: left.result, arg2: right.result },
      ],
      result: temp,
    };
  }

  if (expr.kind === 'Identifier') {
    return { instrs: [], result: (expr as Identifier).name };
  }

  return { instrs: [], result: '<unknown>' };
};

// 示例：(a + b) * (c - d) 转换为三地址码
// t0 = a + b
// t1 = c - d
// t2 = t0 * t1
三地址码形式 示例 说明
赋值运算 x = y + z 二元运算
一元运算 x = -y 一元运算
复制 x = y 简单赋值
条件跳转 if x goto L 条件分支
无条件跳转 goto L 无条件分支
函数调用 x = call f(a,b) 带返回值调用
返回 return x 函数返回

SSA 形式

静态单赋值形式（Static Single Assignment，SSA）是现代编译器 IR 的标准形式。SSA 要求每个变量只被赋值一次，通过φ 函数（phi function）处理控制流汇合点的变量合并。

interface SSAInstruction {
  dest: string;
  op: string;
  args: string[];
  version: number;
}

interface PhiInstruction {
  dest: string;
  version: number;
  sources: Array<{ variable: string; version: number; fromBlock: string }>;
}

interface SSABlock {
  label: string;
  phis: PhiInstruction[];
  instructions: SSAInstruction[];
  terminator: Terminator;
}

type Terminator =
  | { type: 'return'; value: string }
  | { type: 'branch'; target: string }
  | { type: 'condBranch'; cond: string; thenBlock: string; elseBlock: string };

// 普通 IR:
// x = 1
// if cond goto L1 else L2
// L1: x = 2; goto L3
// L2: x = 3; goto L3
// L3: print(x)
//
// SSA 形式:
// x_1 = 1
// if cond goto L1 else L2
// L1: x_2 = 2; goto L3
// L2: x_3 = 3; goto L3
// L3: x_4 = φ(x_2 from L1, x_3 from L2)
//     print(x_4)

const toSSAExample: SSABlock[] = [
  {
    label: 'entry',
    phis: [],
    instructions: [{ dest: 'x', op: 'const', args: ['1'], version: 1 }],
    terminator: { type: 'condBranch', cond: 'cond', thenBlock: 'L1', elseBlock: 'L2' },
  },
  {
    label: 'L1',
    phis: [],
    instructions: [{ dest: 'x', op: 'const', args: ['2'], version: 2 }],
    terminator: { type: 'branch', target: 'L3' },
  },
  {
    label: 'L2',
    phis: [],
    instructions: [{ dest: 'x', op: 'const', args: ['3'], version: 3 }],
    terminator: { type: 'branch', target: 'L3' },
  },
  {
    label: 'L3',
    phis: [
      {
        dest: 'x',
        version: 4,
        sources: [
          { variable: 'x', version: 2, fromBlock: 'L1' },
          { variable: 'x', version: 3, fromBlock: 'L2' },
        ],
      },
    ],
    instructions: [{ dest: '_', op: 'call', args: ['print', 'x_4'], version: 0 }],
    terminator: { type: 'return', value: 'void' },
  },
];

    ENTRY["entry: x₁ = 1"] --> COND{"cond?"}
    COND -->|true| L1["L1: x₂ = 2"]

SSA 的优势 说明
简化数据流分析 每个定义唯一，def-use 链直接可得
简化优化 常量传播、死代码消除更易实现
寄存器分配友好 SSA 变量生命周期更清晰
并行优化友好 无写后写/读后写冲突

提示： 从普通 IR 到 SSA 形式的转换使用支配边界（Dominance Frontier）算法确定 φ 函数的插入位置。从 SSA 形式恢复到普通 IR 则需要φ 函数消除，将 φ 替换为在前驱块末尾的赋值指令。

控制流图与基本块

控制流图（Control Flow Graph，CFG）将程序分解为基本块（Basic Block），每个基本块是一段没有分支的直线代码序列。基本块之间通过有向边连接，表示控制流的走向。

interface BasicBlock {
  id: string;
  instructions: IRInstruction[];
  predecessors: string[];
  successors: string[];
}

interface ControlFlowGraph {
  entry: string;
  blocks: Map<string, BasicBlock>;
}

const buildCFG = (instructions: IRInstruction[]): ControlFlowGraph => {
  const blocks = new Map<string, BasicBlock>();
  let currentBlock: BasicBlock = { id: 'entry', instructions: [], predecessors: [], successors: [] };
  blocks.set('entry', currentBlock);

  for (const instr of instructions) {
    if (instr.op === 'label') {
      const newBlock: BasicBlock = { id: instr.name, instructions: [], predecessors: [], successors: [] };
      blocks.set(instr.name, newBlock);
      currentBlock.successors.push(instr.name);
      newBlock.predecessors.push(currentBlock.id);
      currentBlock = newBlock;
      continue;
    }

    currentBlock.instructions.push(instr);

    if (instr.op === 'br') {
      currentBlock.successors.push(instr.target);
      const target = blocks.get(instr.target);
      if (target) target.predecessors.push(currentBlock.id);
    } else if (instr.op === 'br_if') {
      currentBlock.successors.push(instr.thenTarget, instr.elseTarget);
    }
  }

  return { entry: 'entry', blocks };
};

CFG 概念 定义 用途
基本块 无分支的直线代码序列 局部优化的基本单元
支配 A 支配 B：所有到 B 的路径经过 A SSA 构造
支配边界 支配关系终止的边界 φ 函数插入位置
回边 从后向前的边 循环检测
自然循环 由回边定义的循环结构 循环优化

  • 三地址码以 x = y op z 的形式将表达式展平，是最经典的 IR 格式。
  • SSA 形式通过每变量单赋值约束和 φ 函数，极大简化了数据流分析和优化。
  • 控制流图将程序分解为基本块和有向边，是循环检测、活跃性分析等全局优化的基础。
  • 编译器通常使用多层 IR：高级 IR 保留语义信息，中级 IR 做核心优化，低级 IR 做指令选择。
  • LLVM IR 和 Rust MIR 是工业级 SSA IR 的代表性设计，各有不同的抽象层级和设计侧重。
