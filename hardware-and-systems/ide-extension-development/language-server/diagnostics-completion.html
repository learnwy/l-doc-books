诊断与代码补全

核心概念

诊断（Diagnostics）和代码补全（Completion）是语言服务器中使用频率最高的两项功能。诊断在用户编辑代码时实时反馈问题，代码补全在用户输入时提供智能建议。两者的实现质量直接决定了语言扩展的用户体验——诊断要准确且及时，补全要相关且高效。

flowchart TD
    A[用户编辑代码] --> B{触发类型}
    B --> C[内容变更 → 诊断分析]
    B --> D[输入触发字符 → 代码补全]
    C --> E[解析 + 分析]
    E --> F[publishDiagnostics]
    F --> G[编辑器波浪线标记]
    D --> H[收集候选项]
    H --> I[排序 + 过滤]
    I --> J[CompletionList]
    J --> K[编辑器补全菜单]

两项功能的核心差异：

维度 诊断 代码补全
触发方式 服务器主动推送 客户端请求
通信方向 Server → Client Client → Server → Client
消息类型 Notification Request/Response
频率 每次内容变更 每次按键（可防抖）
性能敏感度 高（影响实时反馈） 极高（影响输入流畅度）
数据量 通常 <100 条 可能 >1000 项

诊断功能深入实现

诊断不仅是简单的错误报告，还包括关联信息、修复建议和严重程度分级。

import {
  Diagnostic,
  DiagnosticSeverity,
  DiagnosticRelatedInformation,
  DiagnosticTag,
  Range,
  Location,
} from 'vscode-languageserver/node';

function createDiagnostic(
  range: Range,
  message: string,
  options: {
    severity?: DiagnosticSeverity;
    code?: string;
    tags?: DiagnosticTag[];
    relatedInfo?: Array<{ uri: string; range: Range; message: string }>;
  } = {},
): Diagnostic {
  const diagnostic: Diagnostic = {
    range,
    message,
    severity: options.severity ?? DiagnosticSeverity.Error,
    source: 'my-lang',
    code: options.code,
    tags: options.tags,
  };

  if (options.relatedInfo?.length) {
    diagnostic.relatedInformation = options.relatedInfo.map((info) => ({
      location: Location.create(info.uri, info.range),
      message: info.message,
    }));
  }

  return diagnostic;
}

诊断标签（Tags）支持特殊的视觉标记：

Tag 含义 编辑器表现
Unnecessary 不必要的代码 灰色/淡化显示
Deprecated 已弃用的 API 删除线 
function analyzeUnusedImports(ast: AST, document: TextDocument): Diagnostic[] {
  const diagnostics: Diagnostic[] = [];

  for (const importNode of ast.imports) {
    const usages = findUsages(ast, importNode.identifier);
    if (usages.length === 0) {
      diagnostics.push(
        createDiagnostic(importNode.range, `'${importNode.identifier}' 已导入但未使用`, {
          severity: DiagnosticSeverity.Warning,
          code: 'unused-import',
          tags: [DiagnosticTag.Unnecessary],
        }),
      );
    }
  }

  return diagnostics;
}

代码补全引擎

代码补全需要处理触发条件、候选项生成、排序过滤、和延迟解析四个环节。

import {
  CompletionItem,
  CompletionItemKind,
  CompletionList,
  InsertTextFormat,
  MarkupKind,
  TextEdit,
} from 'vscode-languageserver/node';

connection.onCompletion((params): CompletionList => {
  const document = documents.get(params.textDocument.uri);
  if (!document) return { isIncomplete: false, items: [] };

  const position = params.position;
  const context = params.context;
  const text = document.getText();
  const offset = document.offsetAt(position);

  const lineText = text.split('\n')[position.line];
  const prefix = lineText.slice(0, position.character);

  const items: CompletionItem[] = [];

  if (context?.triggerCharacter === '.') {
    const memberCompletions = getMemberCompletions(text, offset);
    items.push(...memberCompletions);
  } else if (context?.triggerCharacter === '/') {
    const pathCompletions = getPathCompletions(prefix);
    items.push(...pathCompletions);
  } else {
    const keywordCompletions = getKeywordCompletions(prefix);
    const identifierCompletions = getIdentifierCompletions(text, prefix);
    items.push(...keywordCompletions, ...identifierCompletions);
  }

  return {
    isIncomplete: items.length > 100,
    items: items.slice(0, 100),
  };
});

候选项的构造需要考虑多种属性：

function createSnippetCompletion(
  label: string,
  snippet: string,
  detail: string,
  documentation: string,
): CompletionItem {
  return {
    label,
    kind: CompletionItemKind.Snippet,
    detail,
    documentation: {
      kind: MarkupKind.Markdown,
      value: documentation,
    },
    insertText: snippet,
    insertTextFormat: InsertTextFormat.Snippet,
    sortText: `0_${label}`,
  };
}

function getKeywordCompletions(prefix: string): CompletionItem[] {
  const keywords = ['function', 'const', 'let', 'if', 'else', 'for', 'while', 'return', 'class', 'interface'];

  return keywords
    .filter((kw) => kw.startsWith(prefix.trim()))
    .map((kw) => ({
      label: kw,
      kind: CompletionItemKind.Keyword,
      sortText: `2_${kw}`,
    }));
}

延迟解析（Resolve） 优化补全性能——先返回基础信息，用户选中后再加载详细文档：

connection.onCompletionResolve((item): CompletionItem => {
  if (item.data?.type === 'function') {
    item.documentation = {
      kind: MarkupKind.Markdown,
      value: generateFunctionDoc(item.data.symbolId),
    };
    item.detail = getFunctionSignature(item.data.symbolId);
  }
  return item;
});
优化策略 说明 效果
延迟解析 选中后加载文档 减少首次响应时间
isIncomplete 标记为不完整列表 继续输入时重新请求
sortText 控制显示顺序 最相关的排在前面
filterText 自定义过滤文本 支持模糊匹配
preselect 预选第一项 最常用项直接回车

Code Action 与快速修复

Code Action 将诊断与修复关联起来，在编辑器中表现为灯泡图标或快速修复菜单：

import { CodeAction, CodeActionKind, CodeActionParams, TextEdit, WorkspaceEdit } from 'vscode-languageserver/node';

connection.onCodeAction((params: CodeActionParams): CodeAction[] => {
  const document = documents.get(params.textDocument.uri);
  if (!document) return [];

  const actions: CodeAction[] = [];

  for (const diagnostic of params.context.diagnostics) {
    if (diagnostic.code === 'unused-import') {
      actions.push({
        title: '移除未使用的导入',
        kind: CodeActionKind.QuickFix,
        diagnostics: [diagnostic],
        edit: {
          changes: {
            [params.textDocument.uri]: [TextEdit.del(extendRangeToFullLine(diagnostic.range, document))],
          },
        },
        isPreferred: true,
      });
    }

    if (diagnostic.code === 'missing-type') {
      const inferredType = inferType(document, diagnostic.range);
      if (inferredType) {
        actions.push({
          title: `添加类型注解: ${inferredType}`,
          kind: CodeActionKind.QuickFix,
          diagnostics: [diagnostic],
          edit: {
            changes: {
              [params.textDocument.uri]: [TextEdit.insert(diagnostic.range.end, `: ${inferredType}`)],
            },
          },
        });
      }
    }
  }

  return actions;
});
flowchart TD
    A[诊断报告问题] --> B[用户看到波浪线]
    B --> C[点击灯泡/快捷键]
    C --> D[textDocument/codeAction]
    D --> E{匹配诊断 code}
    E --> F["unused-import → 删除行"]
    E --> G["missing-type → 添加类型"]
    E --> H["可选的重构操作"]
    F --> I[WorkspaceEdit]
    G --> I
    I --> J[应用修改]

Hover 信息提供

悬停信息为用户提供符号的类型、文档和源码位置：

import { Hover, MarkupKind } from 'vscode-languageserver/node';

connection.onHover((params): Hover | null => {
  const document = documents.get(params.textDocument.uri);
  if (!document) return null;

  const word = getWordAtPosition(document, params.position);
  const symbolInfo = lookupSymbol(word, document.uri);
  if (!symbolInfo) return null;

  const contents = ['```typescript', symbolInfo.signature, '```', '', symbolInfo.documentation ?? ''].join('\n');

  return {
    contents: { kind: MarkupKind.Markdown, value: contents },
    range: getWordRange(document, params.position),
  };
});
