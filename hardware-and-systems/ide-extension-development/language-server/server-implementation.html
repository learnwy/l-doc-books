语言服务器实现

核心概念

实现一个语言服务器需要完成三个核心任务：建立 JSON-RPC 通信通道、处理 LSP 生命周期事件、实现各项语言智能功能。vscode-languageserver 库提供了 Node.js 环境下的完整框架，封装了底层通信细节，让开发者专注于语言特性的实现。

服务器初始化与连接
创建一个基础的语言服务器需要初始化连接、声明能力、设置事件监听：


import {
  createConnection,
  TextDocuments,
  ProposedFeatures,
  TextDocumentSyncKind,
  InitializeParams,
  InitializeResult,
} from 'vscode-languageserver/node';
import { TextDocument } from 'vscode-languageserver-textdocument';

const connection = createConnection(ProposedFeatures.all);
const documents = new TextDocuments(TextDocument);

connection.onInitialize((params: InitializeParams): InitializeResult => {
  const capabilities = params.capabilities;
  const hasWorkspaceFolders = !!capabilities.workspace?.workspaceFolders;

  return {
    capabilities: {
      textDocumentSync: TextDocumentSyncKind.Incremental,
      completionProvider: {
        resolveProvider: true,
        triggerCharacters: ['.', '/', '@'],
      },
      hoverProvider: true,
      definitionProvider: true,
      referencesProvider: true,
      documentFormattingProvider: true,
      codeActionProvider: {
        codeActionKinds: ['quickfix', 'refactor'],
      },
      workspace: {
        workspaceFolders: {
          supported: hasWorkspaceFolders,
          changeNotifications: true,
        },
      },
    },
    serverInfo: {
      name: 'My Language Server',
      version: '0.1.0',
    },
  };
});

connection.onInitialized(() => {
  connection.console.log('Language server initialized');
});

documents.listen(connection);
connection.listen();
文档管理与状态维护
TextDocuments 类自动管理编辑器中打开的文档集合，处理文档的打开、更改和关闭事件：


const documentSettings = new Map<string, LanguageSettings>();

interface LanguageSettings {
  maxDiagnostics: number;
  enableLinting: boolean;
  severityLevel: 'error' | 'warning' | 'info';
}

async function getDocumentSettings(uri: string): Promise<LanguageSettings> {
  let settings = documentSettings.get(uri);
  if (!settings) {
    settings = await connection.workspace.getConfiguration({
      scopeUri: uri,
      section: 'myLanguageServer',
    });
    documentSettings.set(uri, settings ?? { maxDiagnostics: 100, enableLinting: true, severityLevel: 'warning' });
  }
  return settings!;
}

documents.onDidChangeContent(async (change) => {
  const document = change.document;
  const settings = await getDocumentSettings(document.uri);

  if (settings.enableLinting) {
    const diagnostics = await analyzeDocument(document, settings);
    connection.sendDiagnostics({ uri: document.uri, diagnostics });
  }
});

documents.onDidClose((event) => {
  documentSettings.delete(event.document.uri);
  connection.sendDiagnostics({ uri: event.document.uri, diagnostics: [] });
});

  const uri = change.document.uri;
  const existing = pendingAnalysis.get(uri);
  if (existing) clearTimeout(existing);

    uri,
    setTimeout(async () => {
      pendingAnalysis.delete(uri);
      const diagnostics = await analyzeDocument(change.document);
      connection.sendDiagnostics({ uri, diagnostics });
    }, 300),
  );
});
诊断分析实现
诊断是语言服务器最基础也最重要的功能——它在用户编辑代码时实时报告错误和警告。


import { Diagnostic, DiagnosticSeverity, Range } from 'vscode-languageserver/node';
import type { TextDocument } from 'vscode-languageserver-textdocument';

interface AnalysisResult {
  line: number;
  column: number;
  endLine: number;
  endColumn: number;
  message: string;
  severity: 'error' | 'warning' | 'info';
  code: string;
}

async function analyzeDocument(document: TextDocument, settings?: LanguageSettings): Promise<Diagnostic[]> {
  const text = document.getText();
  const results = parseAndAnalyze(text);
  const maxDiagnostics = settings?.maxDiagnostics ?? 100;

  return results.slice(0, maxDiagnostics).map(
    (result): Diagnostic => ({
      range: Range.create(result.line, result.column, result.endLine, result.endColumn),
      severity: severityMap[result.severity],
      code: result.code,
      source: 'my-language-server',
      message: result.message,
    }),
  );
}

const severityMap: Record<string, DiagnosticSeverity> = {
  error: DiagnosticSeverity.Error,
  warning: DiagnosticSeverity.Warning,
  info: DiagnosticSeverity.Information,
};
跳转与引用实现
定义跳转和引用查找需要维护一个**符号表（Symbol Table）**来追踪声明和使用位置：


import { Location, Range, Position } from 'vscode-languageserver/node';

interface SymbolInfo {
  name: string;
  kind: 'variable' | 'function' | 'class' | 'interface';
  definitionUri: string;
  definitionRange: Range;
  references: Array<{ uri: string; range: Range }>;
}

const symbolTable = new Map<string, SymbolInfo[]>();

connection.onDefinition((params): Location | null => {
  const document = documents.get(params.textDocument.uri);
  if (!document) return null;

  const word = getWordAtPosition(document, params.position);
  const symbols = symbolTable.get(params.textDocument.uri) ?? [];

  const symbol = symbols.find((s) => s.name === word);
  if (!symbol) return null;

  return Location.create(symbol.definitionUri, symbol.definitionRange);
});

connection.onReferences((params): Location[] => {
  const document = documents.get(params.textDocument.uri);
  if (!document) return [];

  const word = getWordAtPosition(document, params.position);
  const allSymbols = Array.from(symbolTable.values()).flat();
  const symbol = allSymbols.find((s) => s.name === word);

  if (!symbol) return [];

  const locations = symbol.references.map((ref) => Location.create(ref.uri, ref.range));

  if (params.context.includeDeclaration) {
    locations.unshift(Location.create(symbol.definitionUri, symbol.definitionRange));
  }

  return locations;
});

function getWordAtPosition(document: TextDocument, position: Position): string {
  const text = document.getText();
  const offset = document.offsetAt(position);
  let start = offset;
  let end = offset;
  while (start > 0 && /\w/.test(text[start - 1])) start--;
  while (end < text.length && /\w/.test(text[end])) end++;
  return text.slice(start, end);
}

小结
    

  • 使用 vscode-languageserver 框架可以快速搭建 Node.js 语言服务器骨架
    • 

  • TextDocuments 类自动管理文档的打开、更改和关闭，是文档状态同步的核心
    • 

  • 诊断分析应使用防抖策略避免频繁的全量分析
    • 

  • 符号表是实现定义跳转、引用查找等功能的基础数据结构
    • 

  • 增量文档同步和缓存策略对语言服务器的响应性能至关重要
