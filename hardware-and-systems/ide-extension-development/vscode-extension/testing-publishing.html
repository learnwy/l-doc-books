扩展测试与发布

核心概念

VS Code 扩展的测试和发布是确保扩展质量和触达用户的最后环节。测试分为单元测试（不依赖 VS Code 环境）和集成测试（在真实 VS Code 实例中运行）两个层次。发布通过 VS Code Marketplace 或 Open VSX Registry 进行，使用 vsce CLI 工具完成打包和发布。

单元测试
单元测试覆盖扩展中不依赖 VS Code API 的纯逻辑部分——数据处理、格式转换、业务规则等。


import { describe, it, expect } from 'vitest';
import { parseConfig, validateRule, formatDiagnostic } from '../src/utils';

describe('parseConfig', () => {
  it('should parse valid configuration', () => {
    const raw = { rules: { 'no-unused': 'error' }, exclude: ['dist'] };
    const config = parseConfig(raw);
    expect(config.rules).toHaveLength(1);
    expect(config.rules[0].severity).toBe('error');
    expect(config.exclude).toContain('dist');
  });

  it('should handle empty config', () => {
    const config = parseConfig({});
    expect(config.rules).toHaveLength(0);
    expect(config.exclude).toHaveLength(0);
  });

  it('should reject invalid severity', () => {
    expect(() => parseConfig({ rules: { 'no-unused': 'invalid' } })).toThrow('Invalid severity');
  });
});

describe('formatDiagnostic', () => {
  it('should format diagnostic message', () => {
    const result = formatDiagnostic({
      line: 10,
      column: 5,
      message: 'Unused variable',
      severity: 'warning',
    });
    expect(result).toBe('[WARN] line 10:5 - Unused variable');
  });
});
对于依赖 VS Code API 的代码，可以使用 mock 策略：


import { vi, describe, it, expect } from 'vitest';

vi.mock('vscode', () => ({
  window: {
    showInformationMessage: vi.fn(),
    showErrorMessage: vi.fn(),
    activeTextEditor: {
      document: {
        getText: vi.fn(() => 'const x = 1;'),
        uri: { fsPath: '/test/file.ts' },
      },
    },
  },
  workspace: {
    getConfiguration: vi.fn(() => ({
      get: vi.fn((key: string) => {
        const defaults: Record<string, unknown> = { enable: true, maxWarnings: 10 };
        return defaults[key];
      }),
    })),
  },
  Uri: { file: (path: string) => ({ fsPath: path }) },
  Range: class {
    constructor(
      public start: unknown,
      public end: unknown,
    ) {}
  },
  Position: class {
    constructor(
      public line: number,
      public character: number,
    ) {}
  },
}));
集成测试
集成测试在真实的 VS Code 实例中运行，可以测试命令执行、Provider 注册、文件操作等完整流程。


import * as path from 'path';
import { runTests } from '@vscode/test-electron';

async function main(): Promise<void> {
  const extensionDevelopmentPath = path.resolve(__dirname, '../../');
  const extensionTestsPath = path.resolve(__dirname, './suite/index');
  const testWorkspace = path.resolve(__dirname, '../../test-fixtures');

  await runTests({
    extensionDevelopmentPath,
    extensionTestsPath,
    launchArgs: [testWorkspace, '--disable-extensions'],
  });
}

main().catch((err) => {
  console.error('Failed to run tests', err);
  process.exit(1);
});
测试套件入口：


import * as path from 'path';
import Mocha from 'mocha';
import { glob } from 'glob';

export function run(): Promise<void> {
  const mocha = new Mocha({ ui: 'tdd', timeout: 10000 });
  const testsRoot = path.resolve(__dirname, '.');

  return new Promise((resolve, reject) => {
    glob('**/**.test.js', { cwd: testsRoot }).then((files) => {
      files.forEach((f) => mocha.addFile(path.resolve(testsRoot, f)));
      mocha.run((failures) => {
        if (failures > 0) reject(new Error(`${failures} tests failed`));
        else resolve();
      });
    });
  });
}
import * as vscode from 'vscode';
import * as assert from 'assert';

suite('Extension Integration Tests', () => {
  test('Command should be registered', async () => {
    const commands = await vscode.commands.getCommands(true);
    assert.ok(commands.includes('myExtension.helloWorld'));
  });

  test('Command should show message', async () => {
    await vscode.commands.executeCommand('myExtension.helloWorld');
  });

  test('Should format document', async () => {
    const doc = await vscode.workspace.openTextDocument({
      content: 'const   x=1;',
      language: 'typescript',
    });
    const editor = await vscode.window.showTextDocument(doc);
    await vscode.commands.executeCommand('myExtension.formatSelection');
    const text = editor.document.getText();
    assert.strictEqual(text, 'const x = 1;');
  });
});

发布与 CI/CD
将打包和发布集成到 CI 流水线中实现自动化发布：


name: Publish Extension
on:
  push:
    tags: ['v*']

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 22 }

      - run: npm ci
      - run: npm run test

      - name: Publish to VS Code Marketplace
        run: npx @vscode/vsce publish
        env:
          VSCE_PAT: ${{ secrets.VSCE_PAT }}

      - name: Publish to Open VSX
        run: npx ovsx publish -p ${{ secrets.OVSX_PAT }}

  • vsce 工具处理打包（.vsix）和发布到 Marketplace
