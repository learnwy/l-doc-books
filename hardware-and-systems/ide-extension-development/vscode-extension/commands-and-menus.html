命令系统与菜单集成

核心概念

命令（Command）是 VS Code 扩展与用户交互的核心机制。每个命令由一个唯一标识符和一个处理函数组成，用户可以通过命令面板（Command Palette）、快捷键、菜单项或程序化调用来触发命令。菜单系统则将命令绑定到 UI 的特定位置——编辑器右键菜单、资源管理器上下文菜单、标题栏按钮等。

命令注册与参数传递
命令注册是扩展开发中最基础的操作。每个命令需要在 package.json 中声明元数据，在 activate 中注册处理函数。


import * as vscode from 'vscode';

export function activate(context: vscode.ExtensionContext): void {
  const formatCommand = vscode.commands.registerCommand(
    'myExtension.formatSelection',
    async (uri?: vscode.Uri, range?: vscode.Range) => {
      const editor = vscode.window.activeTextEditor;
      if (!editor) return;

      const selection = range ?? editor.selection;
      const text = editor.document.getText(selection);
      const formatted = await formatText(text);

      await editor.edit((editBuilder) => {
        editBuilder.replace(selection, formatted);
      });

      vscode.window.showInformationMessage('格式化完成');
    },
  );
  context.subscriptions.push(formatCommand);

  const textEditorCommand = vscode.commands.registerTextEditorCommand('myExtension.insertTimestamp', (editor, edit) => {
    const timestamp = new Date().toISOString();
    edit.insert(editor.selection.active, timestamp);
  });
  context.subscriptions.push(textEditorCommand);
}

菜单注册与 When 子句
菜单系统通过 contributes.menus 将命令绑定到 UI 的特定位置。VS Code 提供了十几个菜单位置：


{
  "contributes": {
    "menus": {
      "editor/context": [
        {
          "command": "myExtension.formatSelection",
          "when": "editorHasSelection",
          "group": "1_modification"
        }
      ],
      "editor/title": [
        {
          "command": "myExtension.toggleFeature",
          "when": "resourceLangId == typescript",
          "group": "navigation"
        }
      ],
      "explorer/context": [
        {
          "command": "myExtension.analyzeFile",
          "when": "resourceExtname == .ts"
        }
      ],
      "view/title": [
        {
          "command": "myExtension.refreshView",
          "when": "view == myExtension.treeView",
          "group": "navigation"
        }
      ],
      "commandPalette": [
        {
          "command": "myExtension.internalCommand",
          "when": "false"
        }
      ]
    }
  }
}

快捷键与键绑定
快捷键通过 contributes.keybindings 声明，支持跨平台的键位定义和 When 条件控制：


{
  "contributes": {
    "keybindings": [
      {
        "command": "myExtension.formatSelection",
        "key": "ctrl+shift+f",
        "mac": "cmd+shift+f",
        "when": "editorTextFocus && editorHasSelection"
      },
      {
        "command": "myExtension.quickAction",
        "key": "ctrl+.",
        "when": "editorTextFocus && resourceLangId == typescript"
      },
      {
        "command": "myExtension.togglePanel",
        "key": "ctrl+shift+m",
        "mac": "cmd+shift+m"
      }
    ]
  }
}

输入交互与用户反馈
VS Code 提供了丰富的用户输入和反馈 API：


async function interactiveCommand(): Promise<void> {
  const input = await vscode.window.showInputBox({
    prompt: '输入搜索关键词',
    placeHolder: '例如：function name',
    validateInput: (value) => {
      return value.length < 2 ? '至少输入 2 个字符' : null;
    },
  });
  if (!input) return;

  const choice = await vscode.window.showQuickPick(['选项 A', '选项 B', '选项 C'], {
    placeHolder: '选择一个操作',
    canPickMany: false,
  });
  if (!choice) return;

  await vscode.window.withProgress(
    {
      location: vscode.ProgressLocation.Notification,
      title: '处理中...',
      cancellable: true,
    },
    async (progress, token) => {
      for (let i = 0; i <= 100; i += 10) {
        if (token.isCancellationRequested) break;
        progress.report({ increment: 10, message: `${i}%` });
        await new Promise((r) => setTimeout(r, 200));
      }
    },
  );

  vscode.window.showInformationMessage('操作完成', '查看详情', '关闭').then((action) => {
    if (action === '查看详情') {
      vscode.commands.executeCommand('myExtension.showDetails');
    }
  });
}

小结
    

  • 命令是 VS Code 扩展的核心交互单元，支持命令面板、快捷键、菜单等多种触发方式
    • 

  • 菜单系统通过 contributes.menus 将命令绑定到十几种 UI 位置
    • 

  • When 子句控制命令和菜单的可见性，支持上下文变量和自定义条件
    • 

  • 快捷键定义需要考虑跨平台兼容性和冲突处理策略
    • 

  • VS Code 提供了 InputBox、QuickPick、Progress 等丰富的用户交互 API
