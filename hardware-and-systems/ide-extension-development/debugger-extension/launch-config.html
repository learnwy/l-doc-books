Launch 配置与调试启动

核心概念

Launch 配置是 VS Code 调试体验的入口——它定义了如何启动调试会话、使用哪个调试器、传递什么参数。launch.json 文件中的每个配置对象描述了一种调试场景，用户通过调试面板选择并运行。理解 Launch 配置的设计机制对于开发调试器扩展和提供良好的用户体验至关重要。

launch.json 配置详解
一个典型的 launch.json 文件包含多个调试配置：


{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Debug Server",
      "program": "${workspaceFolder}/src/server.ts",
      "outFiles": ["${workspaceFolder}/dist/**/*.js"],
      "sourceMaps": true,
      "preLaunchTask": "npm: build",
      "env": {
        "NODE_ENV": "development",
        "PORT": "3000"
      }
    },
    {
      "type": "node",
      "request": "attach",
      "name": "Attach to Process",
      "port": 9229,
      "restart": true,
      "sourceMaps": true
    },
    {
      "type": "chrome",
      "request": "launch",
      "name": "Debug in Chrome",
      "url": "http://localhost:5173",
      "webRoot": "${workspaceFolder}/src"
    }
  ],
  "compounds": [
    {
      "name": "Server + Client",
      "configurations": ["Debug Server", "Debug in Chrome"],
      "stopAll": true
    }
  ]
}
变量替换：launch.json 支持一系列预定义变量：

Compound 配置允许同时启动多个调试会话，适用于全栈调试（前端 + 后端）场景。


DebugConfigurationProvider
扩展通过 DebugConfigurationProvider 动态提供和修改调试配置：


import * as vscode from 'vscode';

class MyDebugConfigProvider implements vscode.DebugConfigurationProvider {
  resolveDebugConfiguration(
    folder: vscode.WorkspaceFolder | undefined,
    config: vscode.DebugConfiguration,
    token?: vscode.CancellationToken,
  ): vscode.ProviderResult<vscode.DebugConfiguration> {
    if (!config.type && !config.request && !config.name) {
      const editor = vscode.window.activeTextEditor;
      if (editor?.document.languageId === 'mylang') {
        config.type = 'myDebugger';
        config.name = 'Debug Current File';
        config.request = 'launch';
        config.program = '${file}';
      }
    }

    if (!config.program) {
      return vscode.window.showInformationMessage('未指定调试程序').then(() => undefined);
    }

    return config;
  }

  provideDebugConfigurations(
    folder: vscode.WorkspaceFolder | undefined,
    token?: vscode.CancellationToken,
  ): vscode.ProviderResult<vscode.DebugConfiguration[]> {
    return [
      {
        type: 'myDebugger',
        request: 'launch',
        name: 'Debug File',
        program: '${file}',
      },
      {
        type: 'myDebugger',
        request: 'attach',
        name: 'Attach to Process',
        port: 9229,
      },
    ];
  }
}
注册 Provider：


export function activate(context: vscode.ExtensionContext): void {
  const provider = new MyDebugConfigProvider();

  context.subscriptions.push(vscode.debug.registerDebugConfigurationProvider('myDebugger', provider));

  context.subscriptions.push(
    vscode.debug.registerDebugAdapterDescriptorFactory('myDebugger', {
      createDebugAdapterDescriptor(session) {
        return new vscode.DebugAdapterExecutable('node', [context.asAbsolutePath('out/debugAdapter.js')]);
      },
    }),
  );
}
Debug Adapter 启动方式
VS Code 支持三种方式启动 Debug Adapter：


type DebugAdapterDescriptor = DebugAdapterExecutable | DebugAdapterServer | DebugAdapterInlineImplementation;




方式
说明
适用场景





Executable
作为独立进程启动
最常见，适合大多数情况




Server
连接到已运行的服务器
远程调试适配器




Inline
在扩展进程内运行
轻量级调试器





class MyDebugAdapterFactory implements vscode.DebugAdapterDescriptorFactory {
  createDebugAdapterDescriptor(
    session: vscode.DebugSession,
    executable: vscode.DebugAdapterExecutable | undefined,
  ): vscode.ProviderResult<vscode.DebugAdapterDescriptor> {
    if (session.configuration.useInline) {
      return new vscode.DebugAdapterInlineImplementation(new MyDebugSession());
    }

    if (session.configuration.serverPort) {
      return new vscode.DebugAdapterServer(session.configuration.serverPort);
    }

    return executable;
  }
}
package.json 调试器声明
调试器扩展通过 contributes.debuggers 声明调试器的元信息：


{
  "contributes": {
    "debuggers": [
      {
        "type": "myDebugger",
        "label": "My Debugger",
        "program": "./out/debugAdapter.js",
        "runtime": "node",
        "languages": ["mylang"],
        "configurationAttributes": {
          "launch": {
            "required": ["program"],
            "properties": {
              "program": {
                "type": "string",
                "description": "要调试的程序路径"
              },
              "stopOnEntry": {
                "type": "boolean",
                "description": "是否在入口处暂停",
                "default": false
              },
              "trace": {
                "type": "boolean",
                "description": "启用调试日志",
                "default": false
              }
            }
          },
          "attach": {
            "required": ["port"],
            "properties": {
              "port": {
                "type": "number",
                "description": "调试端口"
              }
            }
          }
        },
        "configurationSnippets": [
          {
            "label": "My Debugger: Launch",
            "description": "启动调试",
            "body": {
              "type": "myDebugger",
              "request": "launch",
              "name": "Debug ${1:File}",
              "program": "^\"${2:\\${file\\}}\""
            }
          }
        ]
      }
    ]
  }
}

小结
    

  • launch.json 是 VS Code 调试配置的核心文件，支持变量替换和 Compound 复合配置
    • 

  • DebugConfigurationProvider 允许扩展动态生成和修改调试配置
    • 

  • Debug Adapter 支持 Executable、Server 和 Inline 三种启动方式
    • 

  • contributes.debuggers 在 package.json 中声明调试器的配置模式和代码补全片段
    • 

  • 良好的 Launch 配置设计应支持零配置调试（自动检测）和高级定制两种模式
