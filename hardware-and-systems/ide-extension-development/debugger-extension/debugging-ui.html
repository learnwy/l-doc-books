调试 UI 定制

核心概念

VS Code 的调试 UI 由多个可定制的组件组成——调试工具栏、变量视图、调用堆栈、断点面板和调试控制台。虽然调试 UI 的主体由 VS Code 根据 DAP 响应自动渲染，但扩展可以通过自定义视图、装饰器和 Inline Values等机制增强调试体验，使其更贴合特定语言或运行时的需求。

Inline Values 提供器
Inline Values 是 VS Code 调试时在代码行末尾显示变量当前值的功能。扩展可以通过 InlineValuesProvider 自定义哪些值显示在哪些位置：


import * as vscode from 'vscode';

class MyInlineValuesProvider implements vscode.InlineValuesProvider {
  provideInlineValues(
    document: vscode.TextDocument,
    viewPort: vscode.Range,
    context: vscode.InlineValueContext,
  ): vscode.InlineValue[] {
    const values: vscode.InlineValue[] = [];
    const stoppedLine = context.stoppedLocation.start.line;

    for (let line = viewPort.start.line; line <= Math.min(viewPort.end.line, stoppedLine); line++) {
      const lineText = document.lineAt(line).text;

      const variablePattern = /\b([a-zA-Z_]\w*)\s*=/g;
      let match: RegExpExecArray | null;

      while ((match = variablePattern.exec(lineText)) !== null) {
        const varName = match[1];
        const range = new vscode.Range(line, match.index, line, match.index + varName.length);

        values.push(new vscode.InlineValueVariableLookup(range, varName));
      }
    }

    return values;
  }
}

export function activate(context: vscode.ExtensionContext): void {
  context.subscriptions.push(vscode.languages.registerInlineValuesProvider('mylang', new MyInlineValuesProvider()));
}

编辑器装饰增强
通过 TextEditorDecorationType 可以在调试时为代码添加视觉标记：


const executionLineDecoration = vscode.window.createTextEditorDecorationType({
  isWholeLine: true,
  backgroundColor: new vscode.ThemeColor('editor.focusedStackFrameHighlightBackground'),
  gutterIconPath: vscode.Uri.file('/path/to/arrow.svg'),
  gutterIconSize: 'contain',
});

const exceptionDecoration = vscode.window.createTextEditorDecorationType({
  isWholeLine: true,
  backgroundColor: new vscode.ThemeColor('debugExceptionWidget.background'),
  after: {
    contentText: ' ← Exception thrown here',
    color: new vscode.ThemeColor('editorError.foreground'),
    fontStyle: 'italic',
  },
});

function updateDecorations(editor: vscode.TextEditor, currentLine: number, exceptionLine?: number): void {
  const executionRange = new vscode.Range(currentLine, 0, currentLine, 0);
  editor.setDecorations(executionLineDecoration, [executionRange]);

  if (exceptionLine !== undefined) {
    const exceptionRange = new vscode.Range(exceptionLine, 0, exceptionLine, 0);
    editor.setDecorations(exceptionDecoration, [exceptionRange]);
  }
}

自定义调试视图
通过 TreeView 或 Webview 创建专用的调试辅助面板：


class MemoryViewProvider implements vscode.TreeDataProvider<MemoryItem> {
  private _onDidChangeTreeData = new vscode.EventEmitter<MemoryItem | undefined>();
  readonly onDidChangeTreeData = this._onDidChangeTreeData.event;

  private memoryData: MemoryItem[] = [];

  constructor() {
    vscode.debug.onDidChangeActiveDebugSession(() => {
      this.refresh();
    });
  }

  refresh(): void {
    this._onDidChangeTreeData.fire(undefined);
  }

  getTreeItem(element: MemoryItem): vscode.TreeItem {
    const item = new vscode.TreeItem(element.label);
    item.description = element.value;
    item.tooltip = `${element.address}: ${element.value} (${element.type})`;
    item.contextValue = 'memoryItem';
    return item;
  }

  getChildren(element?: MemoryItem): MemoryItem[] {
    if (!element) return this.memoryData;
    return element.children ?? [];
  }

  async updateFromSession(session: vscode.DebugSession): Promise<void> {
    const response = await session.customRequest('readMemory', {
      memoryReference: '0x0000',
      count: 256,
    });
    this.memoryData = parseMemoryResponse(response);
    this.refresh();
  }
}

interface MemoryItem {
  label: string;
  value: string;
  address: string;
  type: string;
  children?: MemoryItem[];
}

Debug Console 定制
调试控制台支持通过 DAP 的 output 事件发送自定义输出：


class MyDebugSession extends DebugSession {
  protected evaluateRequest(response: DebugProtocol.EvaluateResponse, args: DebugProtocol.EvaluateArguments): void {
    if (args.context === 'repl') {
      this.handleReplCommand(args.expression, response);
      return;
    }
    // 常规表达式求值...
  }

  private handleReplCommand(input: string, response: DebugProtocol.EvaluateResponse): void {
    if (input.startsWith('.help')) {
      this.sendEvent(
        new OutputEvent(
          'Available commands:\n' +
            '  .help    - Show this help\n' +
            '  .memory  - Show memory usage\n' +
            '  .threads - List all threads\n',
          'console',
        ),
      );
      response.body = { result: '', variablesReference: 0 };
    } else if (input.startsWith('.memory')) {
      const memInfo = this.getMemoryInfo();
      response.body = {
        result: `Heap: ${memInfo.heapUsed}MB / ${memInfo.heapTotal}MB`,
        variablesReference: 0,
      };
    } else {
      response.body = {
        result: this.evaluateExpression(input),
        variablesReference: 0,
      };
    }
    this.sendResponse(response);
  }
}

小结
    

  • Inline Values Provider 在代码行内显示变量值，支持文本、变量查找和表达式求值三种模式
    • 

  • 编辑器装饰器为调试过程添加视觉标记，如执行行高亮、异常位置标记
    • 

  • 自定义 TreeView 可以在调试面板中添加内存查看器、寄存器面板等专用视图
    • 

  • Debug Console 的 REPL 上下文支持自定义命令（如 .help、.memory）
    • 

  • 所有调试 UI 定制都支持 when 条件，确保只在相关调试类型激活时显示
    •
