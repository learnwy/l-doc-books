江泽民：生平与时代

江泽民（1926年8月17日—2022年11月30日）是中华人民共和国第三代中央领导集体的核心。本 hub 是江泽民专题中的人物传记读本：以编年为经、专题为纬，完整讲述一个人从扬州书香门第的少年，到电机工程师、技术官僚，再到1989年被推上最高领导岗位、主政中国十余年、直至2022年逝世的一生。它回答四个问题——他是谁？他如何走到权力中心？他在任十三年间发生了什么？他身后留下了怎样的评价与争议？

如果你要找的不是人物生平，请先看下方的分工边界，避免走错入口。

本 hub 与兄弟 hub 的分工边界

「江泽民」专题下共设五个 hub，视角互补、内容各有侧重而非重复：

Hub 视角 回答的核心问题 什么时候读它
本 hub：生平与时代 人物传记 + 编年 这个人的一生轨迹与其执政时代的重大事件 想沿时间线完整了解其人其事
江泽民思想概论 思想与治理逻辑 时代提出了什么课题、形成什么理论、如何转化为政策 想理解政策设计背后的思想逻辑
三个代表重要思想 单一理论深挖 "三个代表"的提出背景、内涵结构与历史评价 想专门吃透这一个理论命题
江泽民：从政之路与权力崛起 政治进程史 技术官僚如何一步步完成权力崛起与权威巩固 想细抠权力运作、人事与派系脉络
江泽民：历史影响与评价 后世评价 经济、外交、党建各领域遗产的长时段影响与主要争议 想做跨领域的盖棺论定式综合评判

一句话区分：本 hub 讲"人的一生"，思想 hub 讲"治理的逻辑"，三个代表 hub 讲"一个理论的细节"，崛起 hub 讲"权力的路径"，遗产 hub 讲"身后的评说"。 与本 hub 边界最近的是崛起 hub：本 hub 按"生—起—治—退—逝"的完整人生展开、权力只是其中一环；崛起 hub 则把镜头拉近到权力技术与决策过程本身。读完本 hub 第一章觉得"还想往权力细节里钻"，就转去崛起 hub。

全书结构：三章八节

  • 第一章 早年生涯与崛起：出身、家世与求学 · 工程师生涯与主政上海 · 1989年的权力交替
  • 第二章 执政时代：社会主义市场经济的确立 · 国家统一与对外关系 · 党的建设与"三个代表"重要思想
  • 第三章 交班与身后：权力交接与晚年退休 · 逝世与历史评价

每一节均配有时间线、对照表与结构图。叙述依据可查证的公开史料（出生与任职日期、会议决议、政策文件、公开讲话），并对成就与代价、官方表述与外部观察作并置呈现，不替读者下结论。

推荐学习路径

一般历史读者（先搭骨架，约 3 篇）：

  1. 出身、家世与求学 —— 此人从哪里来；
  2. 1989年的权力交替 —— 他如何登上权力顶峰；
  3. 逝世与历史评价 —— 官方与外界各自如何盖棺。 之后再按兴趣回填第二章任意一篇专题。

关注经济改革的读者：社会主义市场经济的确立 → 权力交接与晚年退休，即"十四大定目标 → 十六大切换班子"的一条制度主线；想继续追理论源头，转去文末延伸阅读中的南方谈话专题。

关注外交与国家统一的读者：国家统一与对外关系 → 工程师生涯与主政上海，后者解释中俄战略协作的私人资本——留苏实习与俄语能力——从何而来。

政治学 / 当代史专业读者：按章序通读八篇；重点比对1989年的权力交替与权力交接与晚年退休这组方向相反的权力交接案例；理论部分以党的建设与"三个代表"重要思想为导引即可，命题级细节交给三个代表重要思想 hub。

时间有限的读者：每篇末尾的「小结」均可独立成摘要，八篇小结加本页结构清单即为最小可用版本。

前置知识

  • 必需：中国近现代史的基本坐标——1949 年建国、"文革"结束、1978 年十一届三中全会开启改革开放。缺这条时间轴，第一章的求学、入党与仕途节点都会失去参照。
  • 强烈建议：知道邓小平理论与 1992 年南方谈话的大致内容。江泽民时代的经济路线是南方谈话的制度化延续，不了解前者，就读不出第二章经济一篇中"谁定调、谁施工"的分工。可先读南方谈话专题补课。
  • 有帮助但非必需：冷战终结与苏联解体的国际背景——它是第二章外交线（中俄关系重建、中美数度危机）的共同语境。
