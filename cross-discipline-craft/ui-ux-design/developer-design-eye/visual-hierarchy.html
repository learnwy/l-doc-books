视觉层次

概述

视觉层次（Visual Hierarchy）是界面设计中最基础也最重要的概念——它决定了用户看到一个页面时，眼睛先看什么、再看什么、什么最重要、什么可以忽略。没有清晰视觉层次的界面就像一篇没有标题和段落的文章，用户在信息的海洋中迷失方向。对程序员来说，理解视觉层次意味着你在写代码时就能判断布局是否合理，在代码评审时就能发现视觉问题，甚至在没有设计师的情况下也能做出像样的界面。



C.R.A.P. 设计四大原则
C.R.A.P. 是 Robin Williams 在《写给大家看的设计书》中总结的四个设计基础原则，也是程序员学习设计最推荐的入门框架。


对比（Contrast）
对比是创造视觉层次的最强工具。两个元素如果不同，就让它们明显不同。

对比的黄金法则：




如果两个元素不是完全一样的，就让它们完全不同。中间状态（有点像又不太像）是最糟糕的——既没有一致性，也没有对比度。




对齐（Alignment）
页面上的每个元素都应该与其他元素有视觉上的连接。对齐创造秩序感和专业感。






对齐方式
适用场景

右对齐

两端对齐

对齐检查法：


在你的页面上画垂直线——好的设计中，大多数元素的左边缘或右边缘都落在少数几条隐形的垂直线上。如果你发现页面上有很多不同的对齐位置，说明需要整理。


重复（Repetition）
重复让设计有一致性和节奏感。在产品中重复使用相同的颜色、字体、间距和交互模式，用户会建立对产品"规则"的理解，学习成本降低。

格式塔（Gestalt）心理学研究人类如何感知和组织视觉信息。以下原则解释了用户"看到"界面时大脑自动进行的分组和解读。

视觉层次构建工具
眯眼测试
最简单有效的视觉层次检查方法——眯起眼睛看你的界面，你应该仍能分辨出页面的主要区域和最重要的信息。如果眯眼后一片模糊、分不出主次，说明视觉层次不足。


灰度测试
将页面转为灰度模式查看。如果去掉颜色后仍能分辨视觉层次，说明你的层次不是仅靠颜色建立的（这对色盲用户也更友好）。


5 秒测试
让一个从未见过你页面的人看 5 秒钟，然后问：






问题
期望答案





这个页面是做什么的？
能准确描述页面用途




你第一眼注意到什么？
是你希望他们注意到的元素




如果你想 [核心任务]，你会点哪里？
能指向正确的操作入口







实践清单
程序员的视觉层次检查清单




检查项
通过标准





页面有明确的视觉焦点
眯眼后能识别出 1-2 个主要元素




标题层级用大小和字重区分
至少 3 级视觉层次




相关内容通过间距分组
组内间距 < 组间间距




所有元素有明确的对齐线
左边缘落在 ≤ 3 条垂直线上

所有列表项、所有按钮样式统一




主操作按钮视觉突出
与次操作有明显的对比




页面不超过 3 种颜色
主色+辅助色+强调色







小结
视觉层次是程序员提升设计眼光的第一步。C.R.A.P. 四原则和格式塔理论提供了分析和改进任何界面布局的框架。核心行动是：在写 CSS 时有意识地运用对比创造层次、用间距传达分组关系、用一致的样式建立视觉规则。这些不需要审美天赋，只需要逻辑思维和有意识的练习。
