UX 原则 简介

用户体验原则是评判界面设计好坏的标尺。没有这套标尺，你对设计的评价只能停留在"好看不好看"的主观层面；有了它，你就能从可用性、可发现性、一致性、容错性等多个维度系统性地分析任何界面的优劣，给出有理有据的改进建议。

本章围绕四个核心主题展开。启发式评估是可用性领域最经典的评估方法，通过 Nielsen 总结的十条原则，你无需做用户测试就能快速发现界面中大部分的可用性问题。信息架构教你如何组织和呈现内容，让用户在复杂的产品中也能轻松找到自己需要的信息。交互模式为你提供一套经过无数产品验证的常见交互设计方案，让你在设计界面时不必从零发明轮子。无障碍设计则将你的视野扩展到所有用户群体，确保残障人士也能无障碍地使用你的产品。

第一节详解 Nielsen 十大可用性启发式原则及其在现代界面中的应用，同时介绍认知走查和专家评审的实操方法，帮你建立一套可重复使用的可用性评估流程。第二节深入信息架构领域，从卡片分类和树状测试等用户研究方法入手，到导航设计模式的选择策略，教你构建清晰直觉的信息结构。第三节梳理业界成熟的交互模式库，涵盖列表、表单、搜索、导航等高频场景，同时探讨手势设计和微交互的设计要点。第四节全面介绍 WCAG 2.1 无障碍标准和 ARIA 角色系统，从合规要求到包容性设计理念，帮助你构建所有人都能使用的产品。

掌握这四个主题后，你将拥有一套完整的 UX 评估工具箱。无论是在代码评审时发现界面问题，还是在需求讨论时提出体验改进方案，这些原则都能让你的观点更加专业和有说服力。
