无障碍设计

概述

无障碍设计（Accessibility，常缩写为 a11y）确保产品能被所有人使用，包括视觉障碍、听觉障碍、运动障碍和认知障碍的用户。全球约有 15% 的人口——超过 10 亿人——存在某种形式的残障。对程序员来说，无障碍不仅是道德义务，也是法律要求（在美国有 ADA、在欧盟有 EAA），更是提升所有用户体验的手段——无障碍优化往往同时改善了搜索引擎优化、移动端体验和极端使用场景下的可用性。



设计无障碍产品不是为"他们"设计，而是为"我们所有人"设计。每个人都会经历临时性或场景性的能力限制——在嘈杂环境中听不到声音、在强光下看不清屏幕、单手抱孩子时无法双手操作。

ARIA 角色系统
ARIA 的作用
WAI-ARIA（Accessible Rich Internet Applications）是一组 HTML 属性，用于增强自定义组件的无障碍性。当原生 HTML 元素无法满足需求时，ARIA 为辅助技术提供必要的语义信息。




ARIA 第一法则：如果可以使用原生 HTML 元素或属性来实现所需的语义和行为，就不要使用 ARIA。

无障碍开发工作流


小结
无障碍设计不是锦上添花的可选项，而是产品质量的基础指标。对程序员来说，最重要的三条实践是：使用语义化的 HTML 元素（这解决了大部分无障碍问题）、确保所有功能可通过键盘操作、保证足够的色彩对比度。将这三条纳入你的日常编码习惯，你就已经比绝大多数开发者做得更好了。
