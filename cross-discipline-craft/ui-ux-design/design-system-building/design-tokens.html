设计令牌

概述

设计令牌（Design Tokens）是设计系统的原子层——将颜色、字体、间距、阴影等视觉属性抽象为具名的、可编程的变量。它们是设计师和开发者之间的共同语言，确保了从 Figma 设计稿到前端代码的一致性。对程序员来说，设计令牌解决了一个长期痛点：不再需要在代码中硬编码 #1A73E8 或 16px，而是使用有语义的名称如 color-primary 或 spacing-md，让样式维护变得系统化和可预测。



设计令牌的本质是单一数据源（Single Source of Truth）——所有平台的视觉属性都从同一个地方获取，改一处则全局生效。






令牌分类体系
三层令牌架构
现代设计系统通常采用三层令牌架构，从底层到顶层依次是全局令牌、语义令牌和组件令牌。

小结
设计令牌是设计系统的基石，它将分散在代码各处的魔法数字转化为有语义、可管理、跨平台的设计变量。对程序员来说，最重要的实践是：用语义令牌代替硬编码值、维护三层令牌架构、建立自动化的令牌构建管线。这些投入在项目规模增长后会带来巨大的维护效率回报。
