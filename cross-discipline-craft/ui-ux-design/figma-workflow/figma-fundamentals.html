Figma 基础

概述

Figma 是当前最流行的界面设计工具，也是设计师与开发者协作的核心平台。作为程序员，你不需要学会如何从零设计一个界面，但你需要理解 Figma 的核心概念和数据模型，这样才能高效地从设计稿中提取信息、准确还原设计意图、以及在设计评审中给出有价值的技术反馈。本节从程序员最需要理解的核心概念出发，重点讲解与前端开发直接相关的自动布局和约束系统。

自动布局（Auto Layout）
与 CSS Flexbox 的映射
Figma 的自动布局系统在概念上与 CSS Flexbox 几乎一一对应。理解这个映射关系是程序员读懂 Figma 设计稿的关键。

约束系统（Constraints）
约束与响应式的关系
约束系统定义了当父容器尺寸变化时子元素如何响应。它直接对应前端的定位和响应式布局逻辑。

小结
Figma 的核心概念与前端技术有着天然的对应关系：Frame 对应 div、自动布局对应 Flexbox、约束对应 CSS 定位、样式和变量对应 Design Tokens。理解这些映射关系后，你就能在 Figma 中快速读懂设计师的布局意图，准确地将其转化为前端代码。
