Figma 组件系统

概述

Figma 的组件系统是设计复用和一致性的核心机制。对前端开发者来说，Figma 组件的概念与 React/Vue 组件高度相似——都有主定义（Main Component / Component Definition）和实例（Instance / Component Usage），都支持属性传递和变体切换。理解 Figma 组件系统能帮助你精确理解设计师的组件设计意图，并将其忠实地映射为前端代码。



自动布局基础
自动布局与 CSS Flexbox 的映射
自动布局（Auto Layout）是 Figma 中实现响应式组件的核心功能。它的行为与 CSS Flexbox 几乎一一对应，理解这种映射能让你在查看设计稿时秒懂布局意图。

嵌套自动布局
嵌套结构设计
真正强大的自动布局来自嵌套——多层自动布局组合能表达任何复杂的页面结构。这与前端中嵌套 Flex 容器的思路完全一致。


常见嵌套模式
| 模式               | 外层方向 | 内层方向 | 典型场景              |
| :----------------- | :------- | :------- | :-------------------- | -------------------- |
| 垂直 > 水平        | Column   | Row      | 表单（标签行+输入行） |
| 水平 > 垂直        | Row      | Column   | 侧边栏布局            |
| 垂直 > 水平 > 垂直 | Column   | Row      | Column                | 卡片列表中的每张卡片 |
| 水平 > 垂直 > 水平 | Row      | Column   | Row                   | 仪表盘多列面板       |

小结
Figma 组件系统与前端组件模型的相似性远超大多数人的想象。自动布局对应 Flexbox、变体对应 Props 枚举、组件属性对应 Props 类型、实例覆盖对应 Props 传值。理解这些映射后，你能精确地将 Figma 组件设计转化为前端组件接口，减少设计到开发的信息损耗。掌握嵌套自动布局的思维方式，更能让你在查看设计稿时快速理解布局结构并高效还原。
