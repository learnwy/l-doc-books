统计功效分析

核心概念

统计功效（Statistical Power）是假设检验中正确拒绝原假设的概率——即当新方案确实有效时，实验能够检测到这个效应的能力。功效 = 1 - β，其中 β 是第二类错误（假阴性）的概率。功效分析是实验设计中不可或缺的环节：低功效的实验是资源浪费，因为即使新方案有效，实验也很可能无法检测到。业界标准是功效 ≥ 0.80（80%），意味着如果效应真实存在，有 80% 的概率能被实验捕捉到。

功效曲线与最小可检测效应
功效曲线（Power Curve）展示了在给定样本量和显著性水平下，功效随效应量变化的关系。它是理解实验检测能力的核心可视化工具。


功效曲线的典型特征：


    

  • 当效应量为零时，功效等于 α（只能通过假阳性"检测到"效应）
    • 

  • 效应量增大，功效单调递增
    • 

  • 存在一个"拐点"区域，功效从接近 α 快速上升到接近 1.0
    • 

  • 这个拐点附近的效应量就是最小可检测效应（MDE）
    • 



MDE是在给定功效水平下能被检测到的最小效应。它是样本量计算的输入参数，也是评估实验灵敏度的关键指标。MDE 的选择需要结合业务判断：


    

  • MDE 太大：只能检测到非常明显的效应，微妙但有价值的改进会被忽略
    • 

  • MDE 太小：需要巨大的样本量和更长的实验周期，资源消耗过大
    •

先验功效分析与事后功效分析
先验功效分析（A Priori Power Analysis）在实验设计阶段进行，目的是确定所需的样本量。这是功效分析最重要的应用。给定 α、MDE 和方差，计算达到目标功效所需的最小样本量。


先验功效分析的步骤：


    

  1. 确定核心指标及其历史基线和方差
    2. 

  2. 确定业务可接受的最小效应量（MDE）
    3. 

  3. 选择显著性水平（通常 α = 0.05）和目标功效（通常 0.80）
    4. 

  4. 使用公式或模拟计算所需样本量
    5. 

  5. 评估是否在可接受的时间内能收集到足够样本
    6. 



事后功效分析（Post-hoc Power Analysis）在实验结束后进行，使用观测到的效应量来计算功效。这种分析在统计学上是有争议的，因为它本质上是 p 值的单调变换——p 值越小，事后功效越高，不提供额外信息。

更有价值的替代是灵敏度分析（Sensitivity Analysis）：给定当前的样本量和 α，计算实验能检测到的最小效应是多少。这帮助决策者判断实验的灵敏度是否满足业务需求。


提升功效的实用策略
当先验功效分析显示功效不足时，有以下策略可以提升功效：


增加样本量是最直接的方法。功效与 √n 成正比——要将功效从 0.50 提升到 0.80，样本量大约需要增加 2.7 倍。增加样本量的途径包括延长实验周期、增大流量分配比例、或减少同时运行的实验数。


降低指标方差是最优雅的方法。不增加样本量，通过统计技术减少噪声：


CUPED（Controlled-experiment Using Pre-Experiment Data） 是微软提出的方差缩减技术。核心思想是利用实验前的用户行为数据（协变量）来解释指标的部分方差：


调整后指标 Y_adj = Y - θ(X - E[X])


其中 X 是实验前的协变量（如过去 7 天的平均活跃度），θ 是回归系数。CUPED 可以将方差降低 50-70%，等效于将样本量放大 2-3 倍。


触发分析（Triggered Analysis）只分析实际触发了实验变更的用户。例如，如果实验修改了搜索结果页面，只分析进行了搜索的用户。这减少了不相关用户带来的噪声，相当于提高了信噪比。

当标准 A/B 测试的功效无法满足需求时，可以考虑替代实验方法：准实验设计（如差分中差分法）、多臂老虎机算法（自适应分配流量）、或者将多个小效应实验打包为一个综合实验。


小结
    

  • 统计功效是实验检测真实效应的概率，低功效实验是资源浪费
    • 

  • 功效由四个参数决定：α、样本量、效应量和方差
    • 

  • 先验功效分析是实验设计的必要步骤，事后功效分析价值有限
    • 

  • CUPED 是最有效的功效提升技术，等效于将样本量放大 2-3 倍
    • 

  • 触发分析通过减少不相关用户的噪声来提高信噪比
    • 

  • 功效分析应与业务可行性评估整合，使用可行性矩阵指导决策
    •
