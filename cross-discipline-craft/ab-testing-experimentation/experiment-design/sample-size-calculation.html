样本量计算与实验周期

核心概念

样本量计算是 A/B 测试设计中最关键的环节之一。样本量过小，实验无法检测出真实存在的效应（功效不足）；样本量过大，浪费时间和流量成本。样本量的计算依赖于四个核心参数：显著性水平（α）、统计功效（1-β）、最小可检测效应（MDE）和基准指标的方差。实验周期则是样本量与日均流量的函数，同时还需考虑季节性、用户行为周期等时间因素。

比例指标的样本量公式
在 A/B 测试中，最常见的指标类型是比例指标（如点击率、转化率、注册率）。对于两组比例的比较，样本量公式为：


每组所需样本量 n = (Zα/2 + Zβ)² × (p₁(1-p₁) + p₂(1-p₂)) / (p₂ - p₁)²


其中 p₁ 是对照组的基准比例，p₂ = p₁ + MDE 是实验组的预期比例。Zα/2 和 Zβ 分别是标准正态分布在 α/2 和 β 处的分位数。


以具体数字为例：如果当前注册率为 10%（p₁ = 0.10），希望检测 1 个百分点的提升（MDE = 0.01，即 p₂ = 0.11），α = 0.05，功效 = 0.80，那么每组需要约 14,752 个样本。

连续指标的样本量计算
对于连续型指标（如人均消费金额、页面停留时间），样本量公式为：


每组样本量 n = (Zα/2 + Zβ)² × 2σ² / δ²


其中 σ² 是指标的方差，δ 是最小可检测的均值差异。


连续指标的样本量计算有一个常见陷阱：方差的估计。互联网产品的收入类指标通常存在严重的右偏分布（少数高消费用户拉高方差），直接使用原始数据的方差会导致样本量需求过大。常用的解决方法包括：


    

  • 对数变换：对数据取对数后再计算方差，减少极端值的影响
    • 

  • Winsorization：将超过某个百分位的极端值截断到该百分位
    • 

  • 分位数指标：使用中位数而非均值，降低对极端值的敏感性
    • 

  • CUPED 方差缩减：利用实验前的协变量信息，减少指标方差
    •

实验周期的确定
样本量计算完成后，实验周期 = 总样本量 / 日均可用流量。但实际的实验周期还需要考虑以下因素：


最少运行时间：即使样本量在 2 天内就能达到，实验也应至少运行一个完整的周期（通常为 7 天），以覆盖工作日/周末的行为差异。对于受月度周期影响的指标（如付费指标），可能需要运行 2-4 周。


流量分配比例：并非所有流量都会进入实验。如果同时进行多个实验，每个实验可能只能获得 10-30% 的总流量，这会显著延长实验周期。


新鲜感效应（Novelty Effect）：用户可能因为好奇新设计而在初期表现出更高的参与度，但这种效应会随时间衰减。为了避免新鲜感效应的干扰，可以只分析实验开始一段时间后的数据，或者将实验周期延长到新鲜感消退之后。


首因效应（Primacy Effect）：与新鲜感效应相反，用户可能因为习惯了旧版本而对新版本产生抵触。这同样需要更长的实验周期来消除。


序贯检验与自适应样本量
传统的固定样本量方法在实验开始前就确定了所需样本量，必须等到收集完所有数据后才能做统计检验。序贯检验（Sequential Testing）允许在实验过程中多次查看数据并做出决策，是一种更灵活的方法。


序贯检验的核心思想是：通过调整每次检验的显著性阈值，控制整体的假阳性率。常用方法包括：


Pocock 边界：在每次中间分析时使用相同的临界值（比固定检验更严格），整体 α 仍然控制在目标水平。Pocock 边界在早期更容易拒绝原假设，适合希望尽早停止实验的场景。


O'Brien-Fleming 边界：早期分析使用非常严格的阈值，后期逐渐放松。最终分析的阈值接近固定检验的 0.05。这种方法更保守，但最终的检验能力几乎不受中间分析的影响。


Alpha Spending 函数：由 Lan-DeMets 提出的更一般化的框架，允许根据信息分数（已收集样本占总样本的比例）灵活分配 α 的消耗速度。

小结
    

  • 样本量计算依赖四个核心参数：α、1-β、MDE 和基准方差
    • 

  • 比例指标使用两比例 Z 检验公式，基准比例越低所需样本越多
    • 

  • 连续指标的方差估计容易被极端值干扰，需要使用方差缩减技术
    • 

  • CUPED 是最有效的方差缩减方法，可减少 50-70% 的方差
    • 

  • 实验周期不仅取决于样本量，还需覆盖完整周期并考虑新鲜感效应
    • 

  • 序贯检验允许在实验过程中多次查看数据，兼顾效率和统计严谨性
    •
