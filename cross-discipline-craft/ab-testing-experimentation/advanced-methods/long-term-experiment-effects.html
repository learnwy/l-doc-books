长期实验效应评估

核心概念

A/B 测试通常运行 1-4 周，但产品变更的真正影响往往需要数月甚至数年才能完全显现。长期效应（Long-term Effects）指的是那些在短期实验中无法被充分捕捉的用户行为变化。一个功能可能在短期内提升了点击率，但长期来看却导致用户疲劳和留存下降；反过来，一个短期看起来无效的改动可能培养了更健康的用户习惯，最终带来长期价值。理解和评估长期效应对于避免短视的产品决策至关重要。

新鲜感效应与首因效应
短期实验结果偏离长期稳态的两个主要原因是新鲜感效应和首因效应。


新鲜感效应（Novelty Effect）：用户因好奇心对新功能表现出过高的参与度，但随着新鲜感消退，参与度回落到接近原水平。新鲜感效应会导致实验高估真实的长期效果。


首因效应（Primacy Effect）：用户因习惯了旧版本而对新版本产生排斥或不适应，初期表现较差。但随着学习和适应，用户行为逐渐改善。首因效应会导致实验低估真实的长期效果。

长期持续实验
长期持续实验（Long-running Holdout / Holdback）是评估长期效应最直接的方法。在将新功能推广给所有用户后，保留一小部分用户（通常 1-5%）继续使用旧版本（holdout 组），定期比较两组的长期指标。


interface HoldoutConfig {
  experimentId: string;
  holdoutPercentage: number;
  metrics: LongTermMetric[];
  reportingCadence: 'weekly' | 'monthly' | 'quarterly';
  maxDuration: number;
}

interface LongTermMetric {
  name: string;
  type: 'retention' | 'revenue' | 'engagement' | 'satisfaction';
  lookbackDays: number;
}
持续实验的设计要点：


Holdout 比例：通常 1-5%。比例太大会影响推广效果和用户公平性；比例太小则统计功效不足。对于大流量产品，1% 可能就足够。


监控频率：按周或按月生成报告，关注留存率、活跃度、LTV 等长期指标的趋势。


退出条件：当长期指标趋于稳定且两组无显著差异时，或者维护 holdout 的成本过高时，结束持续实验。

代理指标与因果链
当直接测量长期效应不可行时，可以使用代理指标（Surrogate Metrics / Proxy Metrics）——与长期目标高度相关的短期可测量指标。


代理指标的有效性取决于它与最终目标之间的因果关系强度。好的代理指标应满足Prentice 准则：处理对最终目标的全部效应都是通过代理指标传递的（即代理指标"中介"了全部因果效应）。

OEC（Overall Evaluation Criterion） 是一种综合指标，试图用单一数字捕捉产品的长期健康度。OEC 通常是多个指标的加权组合，权重通过历史数据和业务判断确定。例如：


OEC = 0.4 × 转化率变化 + 0.3 × 7日留存变化 + 0.2 × 人均收入变化 + 0.1 × 页面性能变化


好的 OEC 应该具有方向性（指标提升 = 产品变好）、灵敏性（能检测到有意义的变化）和可信性（与长期业务结果一致）。


准实验方法
当无法进行随机对照实验时，准实验方法可以从观察性数据中估计因果效应：


差分中差分（Difference-in-Differences，DID）：比较处理组和对照组在处理前后的变化差异。DID 的核心假设是"平行趋势"——如果没有处理，两组的变化趋势应该是平行的。


断点回归（Regression Discontinuity，RDD）：利用某个阈值造成的"准随机化"。例如，如果活跃度超过某个阈值的用户被推荐了新功能，可以比较阈值两侧用户的行为差异。


合成控制（Synthetic Control）：当处理组只有一个或很少几个单位时（如一个城市），用其他未处理单位的加权组合构造一个"合成对照组"。

小结
    

  • 短期实验结果可能因新鲜感效应或首因效应而偏离长期稳态
    • 

  • 长期持续实验（Holdout）是评估长期效应最直接的方法，推荐 1-5% 比例
    • 

  • 代理指标可以用短期可测量的指标间接评估长期效果
    • 

  • OEC 是综合多维度指标的单一评估标准，需兼顾方向性、灵敏性和可信性
    • 

  • 准实验方法（DID、RDD、合成控制）在无法随机化时提供因果推断能力
    • 

  • 完整的长期效应评估应结合短期 A/B 测试、持续 Holdout 和代理指标三种方法
