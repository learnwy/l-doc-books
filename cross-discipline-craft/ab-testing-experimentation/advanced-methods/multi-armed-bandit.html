多臂老虎机算法

核心概念

多臂老虎机（Multi-Armed Bandit，MAB）是经典 A/B 测试的一种替代方法。传统 A/B 测试在实验期间将流量均匀分配给所有方案，即使某个方案已经明显优于其他方案，也要等到实验结束才能做出调整。MAB 算法通过动态调整流量分配来解决这个问题——将更多流量分配给表现更好的方案，从而在探索（exploration，尝试不确定的选项）和利用（exploitation，选择已知最优的选项）之间找到平衡。这种方法可以减少实验期间的机会成本（opportunity cost），即因为给表现差的方案分配流量而损失的收益。

经典 MAB 算法
ε-贪心（Epsilon-Greedy）是最简单的 MAB 算法。以 1-ε 的概率选择当前最优方案（利用），以 ε 的概率随机选择一个方案（探索）。ε 通常设为 0.05-0.10，随着数据积累可以逐步衰减。


function epsilonGreedy(arms: Array<{ conversions: number; impressions: number }>, epsilon: number): number {
  if (Math.random() < epsilon) {
    return Math.floor(Math.random() * arms.length);
  }

  let bestArm = 0;
  let bestRate = 0;
  for (let i = 0; i < arms.length; i++) {
    const rate = arms[i].impressions > 0 ? arms[i].conversions / arms[i].impressions : 0;
    if (rate > bestRate) {
      bestRate = rate;
      bestArm = i;
    }
  }
  return bestArm;
}
UCB（Upper Confidence Bound） 算法选择"置信上界"最高的方案。它为每个方案计算一个得分 = 观测均值 + 探索奖励。探索奖励与该方案被选择的次数成反比——选择次数越少，不确定性越大，UCB 值越高，从而鼓励探索。


UCB1 的选择公式：


选择 arm_i = argmax(X̄_i + √(2 ln(t) / n_i))


其中 X̄_i 是方案 i 的平均收益，t 是总轮次，n_i 是方案 i 被选择的次数。


Thompson Sampling
Thompson Sampling（汤普森采样）是目前被认为最优雅、效果最好的 MAB 算法。它使用贝叶斯框架——为每个方案维护一个后验概率分布，每次决策时从每个方案的后验分布中随机采样一个值，选择采样值最高的方案。


对于比例指标（如转化率），使用 Beta 分布作为后验：


    

  • 先验：Beta(1, 1)（均匀分布）
    • 

  • 观测 s 次成功和 f 次失败后，后验为 Beta(1 + s, 1 + f)
    • 



function thompsonSampling(arms: Array<{ successes: number; failures: number }>): number {
  let bestArm = 0;
  let bestSample = -Infinity;

  for (let i = 0; i < arms.length; i++) {
    const alpha = 1 + arms[i].successes;
    const beta = 1 + arms[i].failures;
    const sample = betaRandom(alpha, beta);

    if (sample > bestSample) {
      bestSample = sample;
      bestArm = i;
    }
  }

  return bestArm;
}
Thompson Sampling 的优势：


    

  • 自然地平衡探索与利用——不确定性高的方案被采样到较高值的概率更大
    • 

  • 随着数据积累，后验分布变窄，算法自动从探索转向利用
    • 

  • 数学上可证明其遗憾（regret）界接近最优
    •

上下文老虎机
上下文老虎机（Contextual Bandit）将用户特征（上下文）纳入决策。不同用户可能对不同方案有不同的偏好——25 岁的用户可能更喜欢方案 A，45 岁的用户可能更喜欢方案 B。上下文老虎机为每个上下文学习最优的方案选择策略。


经典的上下文老虎机算法是 LinUCB：假设每个方案的期望收益是用户特征的线性函数，使用岭回归估计系数，并加入置信上界进行探索。

MAB 的局限与适用场景
MAB 虽然减少了机会成本，但在某些场景下不适用。核心局限包括：


统计推断弱化：MAB 的动态流量分配使得传统的假设检验框架不再直接适用。如果实验目的是建立因果关系（"这个改动确实导致了转化率提升"），传统 A/B 测试提供更可靠的统计保证。


延迟反馈：MAB 假设每次决策后能立即观测到结果。但在许多场景下（如购买决策可能发生在浏览后的几天），反馈存在延迟，这会导致算法根据不完整的数据做出错误调整。


非平稳环境：标准 MAB 假设每个方案的收益分布是固定的。如果用户偏好随时间变化（如季节性效应），需要使用滑动窗口或折扣因子来适应变化。

小结
    

  • MAB 通过动态调整流量分配，在探索和利用之间找到平衡，减少机会成本
    • 

  • Thompson Sampling 是理论和实践中表现最好的 MAB 算法，基于贝叶斯后验采样
    • 

  • 上下文老虎机将用户特征纳入决策，实现个性化方案选择
    • 

  • MAB 不适合需要严格因果推断的场景——传统 A/B 测试的统计保证更强
    • 

  • 延迟反馈和非平稳环境是 MAB 在实际应用中需要特别处理的挑战
    • 

  • 选择 MAB 还是 A/B 测试取决于实验目的：优化选 MAB，因果推断选 A/B
    •
