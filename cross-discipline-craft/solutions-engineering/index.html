解决方案工程

解决方案工程（Solutions Engineering，简称 SE），在不同公司也叫销售工程师（Sales Engineer）、售前工程师（Pre-sales Engineer）、解决方案架构师（Solutions Architect）、解决方案顾问（Solutions Consultant）——是 B2B 软件销售的"技术发动机"。当客户经理（Account Executive，简称 AE）与客户谈商业条款，SE 与客户的工程、架构、安全团队谈技术——为客户业务定制 demo、回答 RFP 上百道安全合规题、设计 POC（Proof of Concept）证明产品能解决痛点、在签约后把客户交接给客户成功团队（CSM）。Stripe、Snowflake、Databricks、HashiCorp、MongoDB、Twilio 等企业级 SaaS 公司，SE 团队规模常达销售团队的 60% 至 100%，每年承担数百万美元的 ARR 配额。SE 不只是 demo 工程师——它是技术叙事者、架构顾问、客户工程参谋、deal 关键节点的关单人。本 Hub 面向希望从工程师转 SE、组建 SE 团队、或评估 SE 投入的工程师与销售管理者，从基础（SE 定义 / 与 DevRel 与销售的边界 / 客户发现与资格筛选 / 销售周期与 deal 阶段）、技术功底（定制 demo 工程 / POC 设计 / 集成与架构映射 / 白板与技术叙事）、客户互动（discovery call 机制 / 高层与技术干系人 / 异议处理与竞品定位 / 交接客户成功）、SE 运营（工具与 demo 环境 / 度量与配额 / ramping 与赋能）四个维度给一条工程化路径。
