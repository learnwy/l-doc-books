防腐层

核心概念

防腐层（Anti-Corruption Layer, ACL）是 DDD 战略模式中保护领域模型纯洁性的关键机制。当我们的系统需要与外部系统（遗留系统、第三方 API、其他团队的服务）交互时，防腐层在两个模型之间建立翻译屏障，防止外部模型的概念和约束"腐蚀"我们的领域模型。

没有防腐层，外部系统的每一次 API 变更、命名风格、数据格式变化都会直接冲击我们的核心代码。防腐层将这种冲击限制在一个隔离层内，核心领域代码始终使用自己的统一语言。

翻译层设计
防腐层的核心是翻译——将外部模型的概念、术语和数据结构映射为内部领域模型的对应物。


// 外部遗留系统的模型（我们无法控制其设计）
interface LegacyCrmCustomer {
  cust_no: string;
  f_name: string;
  l_name: string;
  addr_1: string;
  addr_2: string;
  zip_cd: string;
  cust_type: 'R' | 'B' | 'V';
  acct_bal: number;
  lst_login: string;
}

// 我们的领域模型
interface Customer {
  readonly id: CustomerId;
  readonly fullName: PersonName;
  readonly address: Address;
  readonly tier: CustomerTier;
  readonly accountBalance: Money;
  readonly lastActiveAt: Date;
}

type CustomerTier = 'regular' | 'business' | 'vip';

// 防腐层翻译器
class CrmCustomerTranslator {
  toDomain(legacy: LegacyCrmCustomer): Customer {
    return {
      id: CustomerId.create(legacy.cust_no),
      fullName: PersonName.create(legacy.f_name, legacy.l_name),
      address: Address.create({
        line1: legacy.addr_1,
        line2: legacy.addr_2,
        postalCode: legacy.zip_cd,
      }),
      tier: this.mapCustomerTier(legacy.cust_type),
      accountBalance: Money.create(legacy.acct_bal, 'CNY'),
      lastActiveAt: new Date(legacy.lst_login),
    };
  }

  toLegacy(customer: Customer): Partial<LegacyCrmCustomer> {
    return {
      cust_no: customer.id.value,
      f_name: customer.fullName.firstName,
      l_name: customer.fullName.lastName,
      cust_type: this.mapToLegacyType(customer.tier),
    };
  }

  private mapCustomerTier(legacyType: string): CustomerTier {
    const mapping: Record<string, CustomerTier> = {
      R: 'regular',
      B: 'business',
      V: 'vip',
    };
    const tier = mapping[legacyType];
    if (!tier) throw new TranslationError(`Unknown customer type: ${legacyType}`);
    return tier;
  }

  private mapToLegacyType(tier: CustomerTier): 'R' | 'B' | 'V' {
    const mapping: Record<CustomerTier, 'R' | 'B' | 'V'> = {
      regular: 'R',
      business: 'B',
      vip: 'V',
    };
    return mapping[tier];
  }
}
适配器实现模式
防腐层通常由三个组件组成：外观（Facade）、翻译器（Translator）和适配器（Adapter）。


// 适配器：处理协议和通信细节
class LegacyCrmApiAdapter {
  constructor(
    private readonly httpClient: HttpClient,
    private readonly baseUrl: string,
  ) {}

  async fetchCustomer(customerNo: string): Promise<LegacyCrmCustomer> {
    const response = await this.httpClient.get(`${this.baseUrl}/customers/${customerNo}`);
    if (response.status === 404) {
      throw new ExternalSystemError('Customer not found in CRM');
    }
    return response.body as LegacyCrmCustomer;
  }

  async updateCustomer(customerNo: string, data: Partial<LegacyCrmCustomer>): Promise<void> {
    await this.httpClient.put(`${this.baseUrl}/customers/${customerNo}`, data);
  }
}

// 外观：为领域层提供简洁的接口
class CustomerCrmFacade {
  constructor(
    private readonly adapter: LegacyCrmApiAdapter,
    private readonly translator: CrmCustomerTranslator,
  ) {}

  async getCustomer(customerId: CustomerId): Promise<Customer> {
    const legacyData = await this.adapter.fetchCustomer(customerId.value);
    return this.translator.toDomain(legacyData);
  }

  async syncCustomerTier(customer: Customer): Promise<void> {
    const legacyData = this.translator.toLegacy(customer);
    await this.adapter.updateCustomer(customer.id.value, legacyData);
  }
}

// 领域层只看到 Facade 的接口
interface CustomerExternalPort {
  getCustomer(customerId: CustomerId): Promise<Customer>;
  syncCustomerTier(customer: Customer): Promise<void>;
}
错误处理与容错
防腐层还负责将外部系统的错误转化为领域可理解的异常，并实现容错策略。


class ResilientCustomerFacade implements CustomerExternalPort {
  constructor(
    private readonly adapter: LegacyCrmApiAdapter,
    private readonly translator: CrmCustomerTranslator,
    private readonly cache: CachePort<Customer>,
    private readonly logger: LoggerPort,
  ) {}

  async getCustomer(customerId: CustomerId): Promise<Customer> {
    const cached = await this.cache.get(customerId.value);
    if (cached) return cached;

    try {
      const legacyData = await this.adapter.fetchCustomer(customerId.value);
      const customer = this.translator.toDomain(legacyData);
      await this.cache.set(customerId.value, customer, 300);
      return customer;
    } catch (error) {
      if (error instanceof ExternalSystemError) {
        this.logger.warn(`CRM unavailable for customer ${customerId.value}`, error);
        const fallback = await this.cache.getStale(customerId.value);
        if (fallback) return fallback;
      }
      throw new DomainError(`Unable to retrieve customer: ${customerId.value}`);
    }
  }

  async syncCustomerTier(customer: Customer): Promise<void> {
    try {
      const legacyData = this.translator.toLegacy(customer);
      await this.adapter.updateCustomer(customer.id.value, legacyData);
    } catch (error) {
      this.logger.error(`Failed to sync customer tier to CRM`, error);
      throw new DomainError('Customer tier sync failed');
    }
  }
}

多外部系统集成
当系统需要对接多个外部系统时，每个外部系统都应该有独立的防腐层。


// 支付网关 ACL
class PaymentGatewayACL implements PaymentPort {
  constructor(
    private readonly stripeAdapter: StripeApiAdapter,
    private readonly translator: PaymentTranslator,
  ) {}

  async charge(amount: Money, method: PaymentMethod): Promise<PaymentResult> {
    const stripeRequest = this.translator.toStripeCharge(amount, method);
    const stripeResponse = await this.stripeAdapter.createCharge(stripeRequest);
    return this.translator.fromStripeResponse(stripeResponse);
  }
}

// 物流服务 ACL
class ShippingServiceACL implements ShippingPort {
  constructor(
    private readonly sfExpressAdapter: SFExpressApiAdapter,
    private readonly translator: ShippingTranslator,
  ) {}

  async createShipment(order: ShipmentRequest): Promise<TrackingInfo> {
    const sfRequest = this.translator.toSFExpressRequest(order);
    const sfResponse = await this.sfExpressAdapter.createWaybill(sfRequest);
    return this.translator.fromSFExpressResponse(sfResponse);
  }
}
小结
    

  • 防腐层在内外模型之间建立翻译屏障，保护领域模型的纯洁性
    • 

  • 由翻译器、适配器和外观三个组件构成，职责清晰
    • 

  • 除了数据翻译，还负责错误转化和容错处理
    • 

  • 每个外部系统应有独立的防腐层，避免交叉污染
    • 

  • 防腐层是连接新旧系统、对接第三方服务的核心基础设施
    • 

  • 外部系统的任何变更只影响防腐层，核心领域代码不受冲击
    •
