DDD 与事件溯源

核心概念

事件溯源（Event Sourcing）是一种持久化模式：不存储当前状态，而是存储导致状态变化的所有事件。聚合的当前状态通过重放事件序列来重建。这与 DDD 的领域事件概念天然契合——聚合不再是"有状态的对象加上事件通知"，而是"事件流本身就是状态的权威来源"。

传统方式中，数据库存储的是聚合的最终状态快照。事件溯源中，数据库存储的是聚合经历的每一个事件。要获取当前状态，从第一个事件开始重放到最后一个事件。

聚合即事件流
在事件溯源中，聚合的实现方式发生根本变化。每次状态变更不再直接修改属性，而是先创建事件，再通过事件处理函数更新状态。


interface StoredEvent {
  eventId: string;
  aggregateId: string;
  eventType: string;
  payload: unknown;
  occurredAt: Date;
  version: number;
}

abstract class EventSourcedAggregate {
  private uncommittedEvents: StoredEvent[] = [];
  private version: number = 0;

  protected apply(event: StoredEvent): void {
    this.handleEvent(event);
    this.version = event.version;
    this.uncommittedEvents.push(event);
  }

  protected abstract handleEvent(event: StoredEvent): void;

  loadFromHistory(events: StoredEvent[]): void {
    for (const event of events) {
      this.handleEvent(event);
      this.version = event.version;
    }
  }

  getUncommittedEvents(): StoredEvent[] {
    return [...this.uncommittedEvents];
  }

  clearUncommittedEvents(): void {
    this.uncommittedEvents = [];
  }

  get currentVersion(): number {
    return this.version;
  }
}

class Order extends EventSourcedAggregate {
  private status: string = 'draft';
  private items: Map<string, { productId: string; quantity: number; unitPrice: number }> = new Map();
  private customerId: string = '';

  static create(orderId: string, customerId: string): Order {
    const order = new Order();
    order.apply({
      eventId: crypto.randomUUID(),
      aggregateId: orderId,
      eventType: 'OrderCreated',
      payload: { customerId },
      occurredAt: new Date(),
      version: 1,
    });
    return order;
  }

  addItem(productId: string, quantity: number, unitPrice: number): void {
    if (this.status !== 'draft') throw new Error('Order not editable');
    this.apply({
      eventId: crypto.randomUUID(),
      aggregateId: this.aggregateId,
      eventType: 'ItemAdded',
      payload: { productId, quantity, unitPrice },
      occurredAt: new Date(),
      version: this.currentVersion + 1,
    });
  }

  submit(): void {
    if (this.items.size === 0) throw new Error('Cannot submit empty order');
    this.apply({
      eventId: crypto.randomUUID(),
      aggregateId: this.aggregateId,
      eventType: 'OrderSubmitted',
      payload: { totalAmount: this.calculateTotal() },
      occurredAt: new Date(),
      version: this.currentVersion + 1,
    });
  }

  protected handleEvent(event: StoredEvent): void {
    switch (event.eventType) {
      case 'OrderCreated': {
        const data = event.payload as { customerId: string };
        this.customerId = data.customerId;
        this.status = 'draft';
        break;
      }
      case 'ItemAdded': {
        const data = event.payload as { productId: string; quantity: number; unitPrice: number };
        this.items.set(data.productId, data);
        break;
      }
      case 'OrderSubmitted':
        this.status = 'submitted';
        break;
    }
  }

  private aggregateId: string = '';
  private calculateTotal(): number {
    return [...this.items.values()].reduce((sum, i) => sum + i.quantity * i.unitPrice, 0);
  }
}
事件存储与仓储
事件溯源的仓储不再读写状态快照，而是操作事件流。


interface EventStore {
  append(aggregateId: string, events: StoredEvent[], expectedVersion: number): Promise<void>;
  getEvents(aggregateId: string): Promise<StoredEvent[]>;
  getEventsAfterVersion(aggregateId: string, afterVersion: number): Promise<StoredEvent[]>;
}

class EventSourcedOrderRepository {
  constructor(private readonly eventStore: EventStore) {}

  async findById(orderId: string): Promise<Order | null> {
    const events = await this.eventStore.getEvents(orderId);
    if (events.length === 0) return null;

    const order = new Order();
    order.loadFromHistory(events);
    return order;
  }

  async save(order: Order): Promise<void> {
    const uncommittedEvents = order.getUncommittedEvents();
    if (uncommittedEvents.length === 0) return;

    const expectedVersion = order.currentVersion - uncommittedEvents.length;
    await this.eventStore.append(uncommittedEvents[0].aggregateId, uncommittedEvents, expectedVersion);
    order.clearUncommittedEvents();
  }
}
快照优化
当事件数量很多时，每次重放所有事件会变慢。快照（Snapshot）定期保存聚合状态，加速重建。


interface Snapshot {
  aggregateId: string;
  version: number;
  state: unknown;
  createdAt: Date;
}

class SnapshotEventSourcedRepository {
  constructor(
    private readonly eventStore: EventStore,
    private readonly snapshotStore: SnapshotStore,
    private readonly snapshotInterval: number = 100,
  ) {}

  async findById(orderId: string): Promise<Order | null> {
    const snapshot = await this.snapshotStore.getLatest(orderId);
    let order: Order;
    let events: StoredEvent[];

    if (snapshot) {
      order = Order.fromSnapshot(snapshot.state);
      events = await this.eventStore.getEventsAfterVersion(orderId, snapshot.version);
    } else {
      const allEvents = await this.eventStore.getEvents(orderId);
      if (allEvents.length === 0) return null;
      order = new Order();
      events = allEvents;
    }

    order.loadFromHistory(events);
    return order;
  }

  async save(order: Order): Promise<void> {
    const uncommittedEvents = order.getUncommittedEvents();
    if (uncommittedEvents.length === 0) return;

    await this.eventStore.append(
      uncommittedEvents[0].aggregateId,
      uncommittedEvents,
      order.currentVersion - uncommittedEvents.length,
    );

    if (order.currentVersion % this.snapshotInterval === 0) {
      await this.snapshotStore.save({
        aggregateId: uncommittedEvents[0].aggregateId,
        version: order.currentVersion,
        state: order.toSnapshot(),
        createdAt: new Date(),
      });
    }

    order.clearUncommittedEvents();
  }
}

事件版本演进
随着业务演化，事件的结构可能需要变更。事件溯源必须处理新旧版本事件的兼容性。


// 事件上溯转换器（Upcaster）
interface EventUpcaster {
  canUpcast(eventType: string, version: number): boolean;
  upcast(event: StoredEvent): StoredEvent;
}

class ItemAddedV1ToV2Upcaster implements EventUpcaster {
  canUpcast(eventType: string, version: number): boolean {
    return eventType === 'ItemAdded' && version === 1;
  }

  upcast(event: StoredEvent): StoredEvent {
    const oldPayload = event.payload as { productId: string; quantity: number; price: number };
    return {
      ...event,
      payload: {
        productId: oldPayload.productId,
        quantity: oldPayload.quantity,
        unitPrice: oldPayload.price,
        currency: 'CNY',
      },
    };
  }
}

class UpcastingEventStore implements EventStore {
  constructor(
    private readonly inner: EventStore,
    private readonly upcasters: EventUpcaster[],
  ) {}

  async getEvents(aggregateId: string): Promise<StoredEvent[]> {
    const events = await this.inner.getEvents(aggregateId);
    return events.map((event) => this.applyUpcasters(event));
  }

  async append(aggregateId: string, events: StoredEvent[], expectedVersion: number): Promise<void> {
    return this.inner.append(aggregateId, events, expectedVersion);
  }

  async getEventsAfterVersion(aggregateId: string, afterVersion: number): Promise<StoredEvent[]> {
    const events = await this.inner.getEventsAfterVersion(aggregateId, afterVersion);
    return events.map((event) => this.applyUpcasters(event));
  }

  private applyUpcasters(event: StoredEvent): StoredEvent {
    let current = event;
    for (const upcaster of this.upcasters) {
      if (upcaster.canUpcast(current.eventType, current.version)) {
        current = upcaster.upcast(current);
      }
    }
    return current;
  }
}
小结
    

  • 事件溯源存储所有历史事件而非当前状态快照，天然支持审计和时间旅行
    • 

  • 聚合通过 apply 产生事件，通过 handleEvent 更新内部状态
    • 

  • 事件存储是 append-only 的，使用版本号实现乐观并发控制
    • 

  • 快照机制解决事件数量增长带来的重建性能问题
    • 

  • 事件版本演进通过 Upcaster 模式处理，确保新旧事件兼容
    • 

  • 事件溯源增加了显著的复杂度，仅在核心域且需要完整审计轨迹时使用
    •
