ETL 概述

ETL（Extract-Transform-Load）是数据仓库建设中最核心的工程环节，负责将数据从源系统抽取出来，经过清洗和转换后加载到目标数据仓库中。

CDC 实现
-- 基于时间戳的增量抽取
SELECT *
FROM source_orders
WHERE updated_at > '2025-03-14 00:00:00'
  AND updated_at <= '2025-03-15 00:00:00';

-- 基于自增 ID 的增量抽取
SELECT *
FROM source_events
WHERE id > (SELECT COALESCE(MAX(source_id), 0) FROM ods_events)
LIMIT 100000;
-- CDC 数据的合并处理（Merge/Upsert）
MERGE INTO dwd_orders AS target
USING (
    SELECT * FROM ods_orders_cdc
    WHERE dt = CURRENT_DATE
) AS source
ON target.order_id = source.order_id
WHEN MATCHED THEN
    UPDATE SET
        status = source.status,
        amount = source.amount,
        updated_at = source.updated_at
WHEN NOT MATCHED THEN
    INSERT (order_id, user_id, status, amount, created_at, updated_at)
    VALUES (source.order_id, source.user_id, source.status, source.amount, source.created_at, source.updated_at);

-- 典型的 DWD 层转换 SQL
INSERT INTO dwd_trade_order_detail
SELECT
    NEXTVAL('order_key_seq') AS order_key,
    o.order_id,
    COALESCE(u.user_key, -1) AS user_key,
    COALESCE(p.product_key, -1) AS product_key,
    CAST(TO_CHAR(o.created_at, 'YYYYMMDD') AS INT) AS date_key,
    o.amount AS order_amount,
    COALESCE(o.discount, 0) AS discount_amount,
    o.amount - COALESCE(o.discount, 0) AS actual_amount,
    CASE o.status
        WHEN 0 THEN 'pending'
        WHEN 1 THEN 'paid'
        WHEN 2 THEN 'shipped'
        WHEN 3 THEN 'completed'
        WHEN -1 THEN 'cancelled'
        ELSE 'unknown'
    END AS order_status,
    COALESCE(o.payment_method, 'unknown') AS payment_method,
    COALESCE(o.source, 'unknown') AS order_source,
    o.created_at,
    CURRENT_DATE AS dt
FROM ods_orders o
LEFT JOIN dim_user u ON o.user_id = u.user_id AND u.is_current = TRUE
LEFT JOIN dim_product p ON o.product_id = p.product_id AND p.is_current = TRUE
WHERE o.dt = CURRENT_DATE;

-- 拉链表实现
-- 步骤 1：将已变更的记录标记为过期
UPDATE dwd_user_zipper
SET end_date = CURRENT_DATE - INTERVAL '1 day',
    is_current = FALSE
WHERE user_id IN (
    SELECT user_id FROM ods_users WHERE dt = CURRENT_DATE
)
AND is_current = TRUE;

-- 步骤 2：插入最新版本
INSERT INTO dwd_user_zipper (user_id, user_name, city, vip_level, start_date, end_date, is_current)
SELECT
    user_id, user_name, city, vip_level,
    CURRENT_DATE AS start_date,
    '9999-12-31'::DATE AS end_date,
    TRUE AS is_current
FROM ods_users
WHERE dt = CURRENT_DATE;


小结
    

  • ETL 是数据仓库建设的核心工程，ELT 模式在云数据仓库场景下越来越流行
    • 

  • 数据抽取应优先使用 CDC（变更数据捕获），其次是时间戳增量，全量抽取仅适用于小表
    • 

  • 数据转换涵盖清洗、标准化、关联、聚合和脱敏，DWD 层是最重要的转换环节
    • 

  • 调度系统通过 DAG 管理任务依赖，幂等性和分区隔离是调度设计的核心原则
    • 

  • 增量处理策略包括分区追加、增量合并和拉链表，选择取决于数据特性和分析需求
    •
