OLAP 与 OLTP 的本质区别

OLAP（Online Analytical Processing）和 OLTP（Online Transaction Processing）是两种根本不同的数据处理范式，它们的设计目标、数据模型和技术实现有着本质的差异。

多维分析（OLAP 操作）
OLAP 基本操作
-- 上卷：从日粒度汇总到月粒度
SELECT
    DATE_TRUNC('month', order_date) AS month,
    SUM(amount) AS total_revenue
FROM orders
GROUP BY DATE_TRUNC('month', order_date);

-- 下钻：从月粒度展开到日粒度
SELECT
    DATE(order_date) AS date,
    SUM(amount) AS daily_revenue
FROM orders
WHERE DATE_TRUNC('month', order_date) = '2025-03-01'
GROUP BY DATE(order_date)
ORDER BY date;

-- 切片：固定时间维度
SELECT
    product_category,
    region,
    SUM(amount) AS revenue
FROM orders
WHERE DATE(order_date) = '2025-03-15'
GROUP BY product_category, region;

-- 切块：固定多个维度
SELECT
    DATE(order_date) AS date,
    SUM(amount) AS revenue
FROM orders
WHERE product_category = '数码'
  AND region = '华东'
  AND order_date BETWEEN '2025-03-01' AND '2025-03-31'
GROUP BY DATE(order_date);

-- ClickHouse 建表示例
CREATE TABLE events
(
    event_date Date,
    event_time DateTime,
    user_id UInt64,
    event_name LowCardinality(String),
    properties String
)
ENGINE = MergeTree()
PARTITION BY toYYYYMM(event_date)
ORDER BY (event_name, user_id, event_time)
SETTINGS index_granularity = 8192;


小结
    

  • OLTP 面向事务处理（点查询、高并发），OLAP 面向分析处理（聚合查询、大数据量扫描）
    • 

  • 列式存储是 OLAP 引擎的基础，通过只读需要的列、高压缩比和向量化执行实现高性能
    • 

  • OLAP 的核心操作包括切片、切块、上卷、下钻和旋转
    • 

  • ClickHouse 单表性能极致，Doris/StarRocks 兼顾多表 JOIN 和实时写入
    • 

  • 分区裁剪、预聚合和排序键设计是 OLAP 查询优化的核心策略
