北极星指标：如何定义北极星指标、指标树分解、输入/输出指标

什么是北极星指标

北极星指标（North Star Metric）是一个产品或业务最核心的衡量标准，它应该能够反映用户获得的核心价值，同时与公司的长期商业目标保持一致。就像北极星为航行者指明方向，北极星指标为整个团队提供统一的目标焦点。

-- 指标树的数据计算
WITH weekly_metrics AS (
    SELECT
        DATE_TRUNC('week', order_date) AS week,
        COUNT(DISTINCT CASE WHEN is_first_order THEN user_id END) AS new_buyers,
        COUNT(DISTINCT CASE WHEN NOT is_first_order THEN user_id END) AS repeat_buyers,
        COUNT(DISTINCT user_id) AS total_buyers
    FROM orders
    WHERE order_date >= CURRENT_DATE - INTERVAL '12 weeks'
    GROUP BY DATE_TRUNC('week', order_date)
),
weekly_traffic AS (
    SELECT
        DATE_TRUNC('week', visit_date) AS week,
        COUNT(DISTINCT CASE WHEN is_new_user THEN user_id END) AS new_visitors,
        COUNT(DISTINCT CASE WHEN NOT is_new_user THEN user_id END) AS return_visitors
    FROM visits
    WHERE visit_date >= CURRENT_DATE - INTERVAL '12 weeks'
    GROUP BY DATE_TRUNC('week', visit_date)
)
SELECT
    m.week,
    m.total_buyers AS north_star_metric,
    m.new_buyers,
    m.repeat_buyers,
    t.new_visitors,
    ROUND(m.new_buyers::NUMERIC / NULLIF(t.new_visitors, 0) * 100, 2) AS new_user_conversion_rate,
    t.return_visitors,
    ROUND(m.repeat_buyers::NUMERIC / NULLIF(t.return_visitors, 0) * 100, 2) AS repeat_purchase_rate
FROM weekly_metrics m
LEFT JOIN weekly_traffic t ON m.week = t.week
ORDER BY m.week;

-- 输入指标监控看板
SELECT
    DATE(event_time) AS date,
    -- 输入指标
    COUNT(DISTINCT CASE WHEN event_name = 'push_sent' THEN user_id END) AS push_sent_users,
    COUNT(DISTINCT CASE WHEN event_name = 'push_opened' THEN user_id END) AS push_opened_users,
    ROUND(
        COUNT(DISTINCT CASE WHEN event_name = 'push_opened' THEN user_id END)::NUMERIC
        / NULLIF(COUNT(DISTINCT CASE WHEN event_name = 'push_sent' THEN user_id END), 0) * 100, 2
    ) AS push_open_rate,
    COUNT(DISTINCT CASE WHEN event_name = 'onboarding_completed' THEN user_id END) AS onboarding_completions,
    COUNT(DISTINCT CASE WHEN event_name = 'core_feature_used' THEN user_id END) AS core_feature_users,
    -- 输出指标
    COUNT(DISTINCT user_id) AS dau,
    COUNT(DISTINCT CASE WHEN event_name = 'purchase' THEN user_id END) AS paying_users
FROM events
WHERE event_time >= CURRENT_DATE - INTERVAL '30 days'
GROUP BY DATE(event_time)
ORDER BY date;

小结
    

  • 北极星指标应反映用户核心价值、可衡量、可行动、不可博弈
    • 

  • 指标树通过乘法分解和加法分解将北极星指标拆解为可操作的子指标
    • 

  • 输入指标是团队可直接行动的领先指标，输出指标是业务的滞后结果指标
    • 

  • AARRR 框架从获取到推荐覆盖了用户生命周期的完整指标体系
    • 

  • 指标治理需要统一命名、明确口径、指定负责人和维护指标字典
