数据治理：数据目录、数据血缘、数据所有权、数据 SLA

数据治理概述

数据治理是一套确保数据资产质量、安全性、可发现性和可信赖性的组织体系和技术实践。随着数据规模和使用场景的增长，没有治理的数据将逐渐失去价值，甚至成为负担。

SLA 监控
-- 数据 SLA 监控：检查各表的数据新鲜度
WITH table_freshness AS (
    SELECT
        table_name,
        MAX(dt) AS latest_partition,
        MAX(etl_load_time) AS latest_load_time,
        NOW() - MAX(etl_load_time) AS data_age
    FROM information_schema.table_partitions
    GROUP BY table_name
)
SELECT
    table_name,
    latest_partition,
    latest_load_time,
    data_age,
    CASE
        WHEN data_age > INTERVAL '24 hours' THEN 'SLA 违反'
        WHEN data_age > INTERVAL '12 hours' THEN 'SLA 风险'
        ELSE 'SLA 达标'
    END AS sla_status
FROM table_freshness
ORDER BY data_age DESC;

小结
    

  • 数据目录是数据资产的索引系统，帮助用户发现、理解和使用数据

  • 数据血缘追踪数据从源到消费的完整链路，支持影响分析和根因追踪
