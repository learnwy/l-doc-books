基础图表类型

柱状图（Bar Chart）

柱状图是最基础也最常用的图表类型，通过柱体的长度编码数据的大小，适合比较不同类别的数值。

-- 生成柱状图数据：各产品类别月度销售额
SELECT
    product_category,
    DATE_TRUNC('month', order_date) AS month,
    SUM(amount) AS revenue
FROM orders
WHERE order_date >= '2025-01-01'
GROUP BY product_category, DATE_TRUNC('month', order_date)
ORDER BY month, revenue DESC;

-- 生成折线图数据：DAU 趋势（含 7 日移动平均）
SELECT
    DATE(event_time) AS date,
    COUNT(DISTINCT user_id) AS dau,
    AVG(COUNT(DISTINCT user_id)) OVER (
        ORDER BY DATE(event_time)
        ROWS BETWEEN 6 PRECEDING AND CURRENT ROW
    ) AS dau_7d_avg
FROM user_events
WHERE event_time >= CURRENT_DATE - INTERVAL '90 days'
GROUP BY DATE(event_time)
ORDER BY date;

-- 生成散点图数据：用户活跃度与消费金额的关系
SELECT
    u.user_id,
    COUNT(DISTINCT DATE(e.event_time)) AS active_days,
    COALESCE(SUM(o.amount), 0) AS total_spending,
    u.registration_source AS channel
FROM users u
LEFT JOIN user_events e ON u.user_id = e.user_id
    AND e.event_time >= CURRENT_DATE - INTERVAL '30 days'
LEFT JOIN orders o ON u.user_id = o.user_id
    AND o.order_date >= CURRENT_DATE - INTERVAL '30 days'
GROUP BY u.user_id, u.registration_source;

-- 生成热力图数据：每周各时段的用户活跃度
SELECT
    EXTRACT(DOW FROM event_time) AS day_of_week,
    EXTRACT(HOUR FROM event_time) AS hour_of_day,
    COUNT(DISTINCT user_id) AS active_users
FROM user_events
WHERE event_time >= CURRENT_DATE - INTERVAL '30 days'
GROUP BY EXTRACT(DOW FROM event_time), EXTRACT(HOUR FROM event_time)
ORDER BY day_of_week, hour_of_day;

-- 生成桑基图数据：用户页面流转
WITH page_sequences AS (
    SELECT
        user_id,
        session_id,
        page_name AS current_page,
        LEAD(page_name) OVER (
            PARTITION BY user_id, session_id ORDER BY event_time
        ) AS next_page
    FROM page_view_events
    WHERE DATE(event_time) = '2025-03-01'
)
SELECT
    current_page AS source,
    next_page AS target,
    COUNT(*) AS flow_count
FROM page_sequences
WHERE next_page IS NOT NULL
GROUP BY current_page, next_page
ORDER BY flow_count DESC
LIMIT 20;


统计图表类型
箱线图（Box Plot）
箱线图展示数据分布的五数概括（最小值、Q1、中位数、Q3、最大值），适合比较多组数据的分布特征。






箱线图元素
统计含义





箱体下边
第一四分位数（Q1）




箱体内线
中位数（Q2）




箱体上边
第三四分位数（Q3）




须线
1.5 × IQR 范围内的极值




离群点
超出须线范围的数据点





-- 生成箱线图数据：各渠道用户的订单金额分布
SELECT
    u.registration_source AS channel,
    o.amount,
    PERCENTILE_CONT(0.25) WITHIN GROUP (ORDER BY o.amount)
        OVER (PARTITION BY u.registration_source) AS q1,
    PERCENTILE_CONT(0.50) WITHIN GROUP (ORDER BY o.amount)
        OVER (PARTITION BY u.registration_source) AS median,
    PERCENTILE_CONT(0.75) WITHIN GROUP (ORDER BY o.amount)
        OVER (PARTITION BY u.registration_source) AS q3
FROM orders o
JOIN users u ON o.user_id = u.user_id;
直方图（Histogram）
直方图将连续数据分桶后统计频次，展示数据的分布形态。


-- 生成直方图数据：订单金额分布
WITH buckets AS (
    SELECT
        WIDTH_BUCKET(amount, 0, 1000, 20) AS bucket_id,
        COUNT(*) AS frequency
    FROM orders
    WHERE amount BETWEEN 0 AND 1000
    GROUP BY WIDTH_BUCKET(amount, 0, 1000, 20)
)
SELECT
    (bucket_id - 1) * 50 AS range_start,
    bucket_id * 50 AS range_end,
    frequency
FROM buckets
ORDER BY bucket_id;

小倍数（Small Multiples）
将数据按某个维度拆分为多个小图表，保持相同的坐标轴和比例尺，便于跨组比较。


-- 生成小倍数数据：按渠道拆分的每日转化率
SELECT
    registration_source AS channel,
    DATE(order_date) AS date,
    COUNT(DISTINCT CASE WHEN status = 'completed' THEN order_id END)::NUMERIC
        / NULLIF(COUNT(DISTINCT order_id), 0) * 100 AS conversion_rate
FROM orders o
JOIN users u ON o.user_id = u.user_id
WHERE order_date >= CURRENT_DATE - INTERVAL '30 days'
GROUP BY registration_source, DATE(order_date)
ORDER BY channel, date;


小结
    

  • 柱状图最适合类别比较，Y 轴必须从零开始；折线图最适合时间趋势，Y 轴可以不从零开始
    • 

  • 散点图揭示两个连续变量的关系，气泡图可以编码第三个维度
    • 

  • 热力图适合展示两个分类变量交叉的数值分布，如留存矩阵和活跃时段分布
    • 

  • 桑基图展示数据的流向和流量，是用户路径分析的最佳图表类型
    • 

  • 图表选择应基于分析目标而非美观偏好，复杂场景可使用组合图或小倍数
    • 

  • 单张图表中系列数不超过 5 条、颜色不超过 7 种、分类不超过 10 个
    •
