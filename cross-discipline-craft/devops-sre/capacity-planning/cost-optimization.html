成本优化

云计算成本的挑战

云计算带来了弹性和便利，但也带来了成本管理的新挑战。按需付费模式意味着如果不加管理，成本可能随业务增长失控。据行业调查，企业平均有 30-35% 的云支出是浪费的。成本优化不是一次性项目，而是需要持续关注的运营实践。



FinOps 实践框架
FinOps（Financial Operations）是一种将财务管理与云运营相结合的实践框架，目标是让每个工程团队都能理解和优化自己的云支出。

资源右 Sizing
什么是右 Sizing
右 Sizing 是指将资源配置（CPU、内存）调整到与实际使用量匹配的最佳大小。过度配置浪费资源，配置不足则影响性能。


实施步骤
# 查看 Pod 实际资源使用
kubectl top pods -n production

# 查看 VPA 的资源建议
kubectl get vpa -n production -o yaml

成本监控和告警
# 成本告警规则示例
alerts:
  - name: DailyCostSpike
    condition: daily_cost > 1.5 * daily_cost_7day_avg
    severity: warning
    message: '今日支出超过过去 7 天平均值的 150%'

  - name: MonthlyBudgetExceeded
    condition: monthly_cost > monthly_budget * 0.8
    severity: critical
    message: '月度支出已达预算的 80%'

  - name: UnusedResources
    condition: resource_utilization < 5% for 7 days
    severity: info
    message: '发现持续 7 天利用率低于 5% 的资源'

小结
云成本优化是一个持续的过程，遵循 FinOps 的"知情→优化→运营"循环。资源标签体系是成本归属的基础，右 Sizing 消除过度配置的浪费，Spot 实例和预留实例降低计算成本，存储分层和生命周期管理控制存储支出。成本优化不仅是运维团队的事，更需要建立全工程团队的成本意识文化。记住：最便宜的资源是不需要使用的资源。
