平台工程

什么是平台工程

平台工程是一种新兴的方法论，其核心思想是将基础设施能力产品化，构建内部开发者平台（Internal Developer Platform，IDP），让开发者通过自助服务完成环境搭建、部署、监控等操作，无需直接与底层基础设施打交道。

平台工程的核心理念可以用一句话概括："平台即产品"（Platform as a Product）——平台团队像产品团队一样运作，开发者是平台的用户。




为什么需要平台工程
DevOps 的认知负荷问题
随着云原生技术栈的不断膨胀，开发者需要了解的工具和概念越来越多。一个开发者可能需要掌握 Docker、Kubernetes、Terraform、Prometheus、Grafana、ArgoCD 等数十种工具才能完成从编码到上线的全过程。这种"认知负荷过载"严重影响了开发效率。

Backstage
什么是 Backstage
Backstage 是由 Spotify 开发并捐赠给 CNCF 的开源开发者门户平台。它提供了一个统一的界面来管理所有服务、文档、API 和工具。

软件模板
apiVersion: scaffolder.backstage.io/v1beta3
kind: Template
metadata:
  name: nodejs-service
  title: Node.js 微服务
  description: 创建一个标准化的 Node.js 微服务
spec:
  owner: platform-team
  type: service
  parameters:
    - title: 服务信息
      required:
        - name
        - owner
      properties:
        name:
          title: 服务名称
          type: string
        owner:
          title: 所属团队
          type: string
          ui:field: OwnerPicker
        description:
          title: 服务描述
          type: string
  steps:
    - id: create-repo
      name: 创建代码仓库
      action: publish:github
      input:
        repoUrl: 'github.com?repo=${{ parameters.name }}'
    - id: register-catalog
      name: 注册到服务目录
      action: catalog:register
通过软件模板，新服务的创建从"花一天时间手动搭建"变成"填写表单一键生成"，并且所有新服务都遵循统一的项目结构、CI/CD 配置和监控标准。

小结
平台工程通过构建内部开发者平台，将基础设施复杂性封装为简洁的自助服务，让开发者专注于业务代码。Backstage 是开源 IDP 的标准选择，提供了服务目录、软件模板和丰富的插件生态。"平台即产品"的理念要求平台团队以用户（开发者）为中心，持续衡量和提升开发者体验。平台工程不是一蹴而就的——从标准化工具链到自助服务再到完整 IDP，是一个渐进式的演进过程。
