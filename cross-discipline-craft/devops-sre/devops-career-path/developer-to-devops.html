从开发者到 DevOps

DevOps 领域的角色全景

DevOps 生态中存在多种角色，它们的名称常常让人困惑。DevOps 工程师、SRE（站点可靠性工程师）和平台工程师是三个最核心的角色方向，虽然职责有交叉，但侧重点各不相同。

小结
DevOps 领域的角色多样但有明确边界：DevOps 工程师聚焦交付效率，SRE 聚焦系统可靠性，平台工程师聚焦开发者体验。从开发者转型 DevOps，最大的优势是编程能力和系统设计经验，需要补充的是 Linux、网络、容器、监控等运维基础技能。DORA 四项指标是衡量团队 DevOps 成熟度的黄金标准。选择一个方向深耕，同时保持对其他方向的广度了解，是 DevOps 职业发展的最佳策略。
