开发者关系

开发者关系（Developer Relations，简称 DevRel）是面向开发者群体的非传统营销与产品职能——通过技术内容、社区运营、活动布道、文档与示例代码，帮助开发者理解、采用、并成功落地一个平台、API、SDK 或开源项目。它由 Sun Microsystems 90 年代的 Java Evangelist、Google Developer Relations 2005 年成型、Stripe / Twilio / Vercel / Supabase 在 2010-2020 把 DevRel 推向商业核心，成为 PLG（Product-Led Growth）时代最重要的获客与留存通道之一。DevRel 工程师跨越 Marketing、Product、Engineering、Customer Success 四方，既要写代码 demo、又要上台演讲、还要运营社区——是典型的 T 型人才岗位。本 Hub 从基础（DevRel 定义 / 开发者画像 / DevRel vs Marketing vs Pre-sales / 组织模型）、内容（技术写作 / 演讲 / 文档示例 / 视频直播）、社区（线上论坛 / 线下活动 / 大使项目 / 开源 stewardship）、项目与度量（开发者计划 / 度量与 OKR / 反馈闭环）四个维度，给希望转 DevRel、组建 DevRel 团队、或评估 DevRel 投入的工程师与管理者一条工程化路径。
