搜索与导航

核心概念

搜索与导航是文档站用户体验的两大支柱——导航帮助用户通过结构化路径浏览文档，搜索帮助用户通过关键词直达目标内容。研究表明，超过 60% 的文档站访问者首先使用搜索功能，而非逐层浏览导航树。一个设计良好的搜索与导航系统，能让用户在 10 秒内找到所需信息。

全文搜索实现
全文搜索是文档站最核心的功能。实现方案分为客户端搜索和服务端搜索两大类。


客户端搜索在构建时生成搜索索引文件，运行时完全在浏览器端执行搜索。无需后端服务，部署简单，隐私友好。代表方案包括 VitePress 内置的 MiniSearch、Docusaurus 的 @easyops-cn/docusearch-local、独立的 PageFind（基于 WASM，性能优异）。


客户端搜索的核心挑战是索引体积与搜索质量的平衡。完整的全文索引可能占据数 MB，影响首次加载性能。优化策略包括：只索引标题和首段（减小索引体积 70%）、延迟加载索引（用户打开搜索框时才加载）、分片索引（按章节拆分，按需加载）。


服务端搜索依赖外部搜索引擎，搜索质量更高但需要额外的基础设施。Algolia DocSearch 是文档站最常用的选择——对开源项目免费，提供定时爬虫自动索引文档站内容，搜索支持模糊匹配、同义词和权重调整。


Algolia DocSearch 的集成步骤：申请 DocSearch 服务并获取 API Key → 在文档站配置中注入 DocSearch 组件 → 配置爬虫规则（指定需要索引的页面区域和排除的内容）→ 爬虫定期更新索引。


导航架构设计
导航架构决定了文档站的信息层级和浏览路径。设计导航时需要同时考虑新手用户（需要引导式浏览）和资深用户（需要快速定位）。


顶部导航栏承载站点级别的导航——产品切换、文档版本选择、语言切换和搜索入口。顶部导航栏的链接数量应控制在 5-7 个以内，避免信息过载。


侧边栏是文档站的核心导航组件，展示当前文档集的层级结构。侧边栏设计的关键原则包括：层级不超过 3 层（超过则需要重新组织信息架构）；当前页面在侧边栏中高亮标识；支持折叠和展开控制可见范围；在移动端转换为抽屉式菜单。


面包屑导航展示当前页面在文档层级中的位置，帮助用户理解"我在哪里"并快速跳转到上级目录。面包屑在深层级文档中特别重要，它提供了从任意位置返回上级的快捷路径。


页面内导航（Table of Contents）展示当前页面的标题层级结构，通常作为右侧边栏的目录。滚动时自动高亮当前可见的标题，点击标题平滑滚动到对应位置。页面内导航对于长文档（超过 3 屏）的阅读体验至关重要。


搜索体验优化
搜索功能的体验细节直接影响用户的查找效率和满意度。


搜索触发方式：键盘快捷键（⌘K 或 /）是面向开发者文档站的标准触发方式。搜索框应在全局导航栏中可见，点击即可聚焦。搜索框中显示快捷键提示（如 "⌘K 搜索"）引导用户使用键盘操作。


即时搜索（Search-as-you-type）：用户输入关键词时实时展示搜索结果，无需按回车键。结果列表应包含标题、路径和内容摘要，关键词在摘要中高亮标记。搜索结果按相关度排序，完全匹配优先于部分匹配。


搜索结果分组：当文档站包含多种内容类型（指南、API 参考、博客）时，搜索结果应按类型分组展示。用户可以通过标签过滤特定类型的结果。


零结果处理：当搜索无结果时，提供有帮助的反馈——建议检查拼写、尝试相关关键词、提供常用页面的链接。避免显示空白页面或仅显示"未找到结果"的冷冰冰提示。


搜索分析：追踪用户的搜索行为——高频搜索词、零结果搜索词、搜索后的点击行为。高频零结果搜索词揭示了文档的内容缺口或搜索同义词配置的不足。


移动端导航适配
文档站的移动端访问量通常占 20-40%，导航在小屏幕上的可用性至关重要。


侧边栏转换为抽屉：在移动端将左侧边栏转换为从左侧滑入的抽屉菜单，通过汉堡按钮触发。抽屉菜单需要覆盖整个屏幕宽度的 80%，背景遮罩可点击关闭。


页面内目录折叠：右侧的目录栏在移动端折叠为页面顶部的可展开区域，或通过浮动按钮触发。避免目录占用宝贵的阅读空间。


搜索体验适配：移动端的搜索应全屏展示，输入框占据屏幕顶部，搜索结果占据剩余空间。支持触摸滑动浏览结果，结果项的触摸目标尺寸不小于 44×44px。


底部导航：在移动端添加底部固定导航栏，包含"上一篇/下一篇"快捷按钮和"回到顶部"按钮，改善长文档的导航体验。


小结
    

  • 超过 60% 的文档站访问者首先使用搜索，搜索功能的质量直接决定用户体验
    • 

  • 客户端搜索（MiniSearch、PageFind）适合中小型站点，无需后端服务
    • 

  • 导航架构应控制在 3 层以内，侧边栏、面包屑和页面目录协同服务不同导航需求
    • 

  • 搜索体验的关键细节包括快捷键触发、即时搜索、结果分组和零结果友好处理
    • 

  • 移动端需要将侧边栏转换为抽屉、目录折叠、搜索全屏化
    •
