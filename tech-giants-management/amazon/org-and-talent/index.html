组织与人才 简介

Amazon 的组织设计哲学可以用一句话概括：让组织架构像软件架构一样可组合、可解耦、可独立部署。这不是一个隐喻——Amazon 的组织变革实际上与其技术架构的微服务化转型同步发生，二者互为因果。

本章从三个角度解读 Amazon 的组织与人才体系。Two-Pizza Team 原则是 Amazon 组织设计的基本单元——团队规模不超过两个披萨能喂饱的人数（6-8人），每个团队端到端地拥有一项服务或客户体验，自主决策、自主交付。面向服务的组织架构揭示 Amazon 如何将 API 思维从技术层面延伸到组织层面——团队间通过明确定义的接口协作，而非通过层级汇报和跨部门会议。人才飞轮则呈现 Amazon 如何在大规模组织中维持人才活力——从内部转岗机制到技术 IC 双通道，从 Career Choice 项目到人才密度的持续提升。

Amazon 证明了一个命题：组织架构本身就是产品，需要像产品一样被设计、迭代和优化。
