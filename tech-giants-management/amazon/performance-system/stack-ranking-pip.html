Amazon Stack Ranking 与 PIP — 绩效淘汰文化

知识要点

Amazon 的绩效管理体系以严格著称，其核心机制包括 Stack Ranking（强制排名）和 PIP（Performance Improvement Plan，绩效改进计划）。这套体系的底层逻辑源自 Jeff Bezos 的一个核心信念：维持高人才密度是保持 Day 1 状态的必要条件，而容忍低绩效者是组织走向 Day 2 的危险信号。

Stack Ranking 要求管理者将团队成员按绩效从高到低排序，并将一定比例的员工标记为「需要改进」。被标记的员工将进入 PIP 流程——通常为 30-90 天的改进期，如果在规定时间内无法达到预期标准，可能面临离职。这一机制在 Amazon 内部被称为「URA」（Unregretted Attrition，不被遗憾的离职率），公司将一定比例的人员流动视为组织健康的标志。

这套体系引发了广泛的行业争议：支持者认为它确保了组织的持续进化和高标准维持；批评者认为它制造了过度竞争、削弱了团队协作，甚至导致了有毒的工作文化。理解这套体系需要跳出简单的好坏判断，深入分析其设计逻辑和运作机制。

详细讲解

Stack Ranking 的运作机制

Amazon 的绩效评估采用相对排名而非绝对标准。管理者需要将团队成员分布在一个强制曲线上：

绩效等级 典型占比 含义 后果
Top Tier (TT) ~15-20% 远超预期，是团队标杆 加速晋升、股票奖励
Highly Valued (HV) ~60-70% 达到或超出预期 正常调薪、保持现状
Least Effective (LE) ~10-15% 未达预期 进入 PIP 或 Pivot
Needs Improvement ~5% 严重低于预期 立即进入 PIP

关键特征：

  • 强制分布：即使团队整体表现优秀，也必须有人排在末位
  • 相对评估：不是与绝对标准比较，而是与同级别同事比较
  • 跨团队校准：通过 Calibration 会议确保不同团队的标准一致

PIP 的具体流程

PIP 的典型要素包括：


    

  • 明确的改进目标：与管理者协商制定可衡量的具体指标
    • 

  • 时间限制：通常 30 天（严重情况）或 60-90 天（一般情况）
    • 

  • 定期检查点：每周或每两周与管理者一对一review进展
    • 

  • 文档化：所有沟通和评估必须书面记录
    • 



URA 目标与组织健康
Amazon 对 URA（不被遗憾的离职率）设有组织级目标。这意味着：


    

  • 每年有一定比例的低绩效员工流出被视为组织健康的标志
    • 

  • 如果一个团队长期没有任何 URA，可能被质疑「标准是否够高」
    • 

  • 但 URA 不是「裁员指标」——它聚焦的是绩效持续无法达标的个体
    • 



与领导力准则的关联
Stack Ranking 直接对应多条领导力准则：


    

  • Insist on the Highest Standards：强制排名本身就是「不断提高标准」的制度化
    • 

  • Hire and Develop the Best：配合 Bar Raiser 确保进入的人才水平，PIP 确保无法提升的人才流出
    • 

  • Deliver Results：绩效评估的核心就是结果交付
    • 

  • Earn Trust：评估过程的透明和公正是赢得员工信任的基础
    • 



实践案例
案例一：2015年《纽约时报》报道风波
2015 年《纽约时报》发表长篇调查报告「Inside Amazon: Wrestling Big Ideas in a Bruising Workplace」，描绘了 Amazon 内部激烈的绩效竞争文化——员工被鼓励匿名举报同事表现不佳、PIP 被系统性地用于淘汰，形成了高压甚至有毒的工作环境。这篇报道引发了广泛的公众讨论，Bezos 本人发内部邮件回应，表示「如果这真的描述了Amazon，我也不想在这里工作」。


此事件之后，Amazon 对绩效管理体系做了若干调整：增加了申诉渠道、强调管理者与员工的持续反馈而非年终突袭式评估、以及更明确地禁止将 PIP 作为「赶走不想要的人」的工具。


案例二：Pivot 机制的引入
为了给被标记为低绩效的员工更多选择，Amazon 引入了 Pivot 机制。员工在收到 PIP 通知时可以选择：


    

  1. 接受 PIP，在当前团队中改进
    2. 

  2. 选择 Pivot——获得一定时间在公司内部寻找新岗位
    3. 



Pivot 的设计理念是承认一个现实：某些员工在当前团队/岗位表现不佳，未必是能力问题，可能是岗位匹配问题。给他们一个体面的内部流动机会，比直接 PIP 后淘汰更人性化。


案例三：疫情期间的调整
2020-2021 年疫情期间，Amazon 暂时放宽了绩效淘汰机制，暂停了大部分 PIP 流程。这一调整反映了两个现实：一是远程工作环境下的绩效评估更加困难；二是「Strive to be Earth's Best Employer」这条 2021 年新增的 LP 所带来的文化转向。

行业趋势：从 Stack Ranking 到持续反馈
微软在 2013 年废除了 Stack Ranking，转向更频繁的、发展导向的反馈机制。Google 也从未采用严格的强制排名。Amazon 则走了一条中间路线——保留了排名和淘汰机制的核心，但在执行上增加了更多灵活性和人性化元素（如 Pivot 选择）。


小结
    

  • Stack Ranking 是 Amazon 维持高人才密度的核心机制，本质是将「Insist on the Highest Standards」制度化
    • 

  • PIP 不仅是淘汰工具，也是给予员工明确改进方向和时间窗口的机制
    • 

  • Pivot 选择为低绩效员工提供了更人性化的替代路径
    • 

  • URA 目标反映了 Amazon 将一定比例的人员流动视为组织健康指标的理念
    • 

  • 这套体系的最大争议在于：在追求卓越和创造有毒工作环境之间的界限在哪里
    •
