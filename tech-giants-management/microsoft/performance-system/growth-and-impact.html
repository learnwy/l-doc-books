成长与影响力模型：微软新绩效体系的设计逻辑

知识要点

废除 Stack Ranking 后，微软面临一个紧迫问题：用什么来取代它？答案是一个以"成长与影响力"（Growth & Impact）为核心的新绩效框架。这个体系的设计原则是：评估应该激励协作而非惩罚合作，应该鼓励学习而非奖励确定性，应该关注贡献的质量而非排名的位置。新体系最核心的机制是 Connects——一种取代年度评审的持续对话模式，让绩效管理从"一年一次的审判"变为"日常的教练辅导"。

体系要素 设计意图 运作方式
Connects 对话 持续反馈替代年终评判 每季度至少一次 Manager-IC 深度对话
三维评估 超越单一产出维度 个人影响 + 他人贡献 + 借助他人力量
成长计划 从评判转向发展 每位员工有年度成长目标
奖励差异化 保持激励性 薪酬仍有差异，但不基于强制曲线
团队反馈 360 度视角 同事和跨团队协作者提供输入

Connects：持续对话机制

设计原理

Connects 是微软新绩效体系中最具特色的元素。它的核心思想是：绩效管理不是年终结算，而是持续的教练过程。

在旧体制下，员工全年努力工作，然后在年终的几周内被排名——这个排名决定薪酬、晋升和命运。这导致了一种"年终博弈"心理：员工倾向于在评估周期的最后几个月"冲刺"表现，而非持续、稳定地成长。

Connects 将全年分为多个对话节点：

每次 Connect 对话包含三个核心问题：


    

  1. 你在过去这段时间里最大的影响是什么？——关注实际贡献，而非"你有多忙"
    2. 

  2. 你学到了什么？你的成长在哪里？——直接呼应成长型思维的文化
    3. 

  3. 下一步你想重点投入什么？需要什么支持？——前瞻性而非回顾性
    4.

去除"打分"压力
Connects 有意识地避免了任何形式的数字评分。在旧体制中，员工收到的是一个 1-5 的数字等级（或类似的 Exceeds / Meets / Below 标签）。这个数字成为了身份标签——一个"3"的员工会本能地将自己定义为"中等水平的人"。


新体系中，反馈以叙事形式呈现：描述具体行为、具体影响、具体成长机会。没有数字，没有等级，没有与他人的比较。


三维评估框架
超越"个人英雄主义"
新体系最重要的设计创新是三维评估——员工的贡献被从三个角度审视：


维度一：个人影响（Your own impact） 你直接交付了什么有价值的成果？这是传统绩效评估中唯一的维度。


维度二：对他人的贡献（Contribution to others） 你帮助了其他团队或同事取得什么成果？你辅导了谁？你分享了什么知识？


维度三：借助他人力量（Leveraging others） 你是否有效地利用了他人的专长和贡献来放大自己的成果？还是独自扛下所有事情？


这三个维度的设计直接针对 Stack Ranking 时代的三大问题：

实际案例：Azure 团队的应用
以 Azure 的一位 Senior Software Engineer 为例，她的年度 Connect 总结可能包含：


    

  • 个人影响：主导了 Azure Kubernetes Service 的自动扩展功能，缩短了 70% 的客户部署时间
    • 

  • 对他人的贡献：为三名新入职工程师提供了为期两个月的 onboarding 辅导；在内部 Tech Talk 上分享了 K8s 最佳实践（80 人参加）
    • 

  • 借助他人力量：与 DevRel 团队合作，将客户反馈转化为产品需求——而非自己猜测客户需要什么
    • 



在旧体系中，"辅导新人"和"内部 Tech Talk"不会出现在绩效评估中——因为它们不直接产生"排名优势"。新体系明确将它们纳入"对他人的贡献"维度，使这些对组织有益的行为获得正式认可。


奖励机制的重新设计
保持差异化，去除零和性
一个常见误解是"取消排名 = 平均主义"。微软的新体系明确拒绝这一逻辑——薪酬和奖金仍然有差异，但差异化的依据不再是强制曲线：


旧体系：团队中必须有 X% 的人拿"超额"奖金，Y% 的人拿"标准"奖金，Z% 的人拿"低于标准"或无奖金——无论团队整体表现如何。


新体系：奖励基于绝对贡献评估——如果一个团队所有人都表现卓越，所有人都可以获得卓越的奖励。反之亦然。

Manager 的裁量权与校准
新体系给予 Manager 更大的裁量权——但也配套了校准机制（Calibration）防止偏差：


    

  1. Manager 初评：直属经理基于 Connects 对话和三维评估给出初步建议
    2. 

  2. 跨团队校准：同级别 Manager 坐在一起讨论，确保评估标准一致
    3. 

  3. VP 审核：高层领导审视整体分布，确保没有系统性偏差
    4. 

  4. HR 数据审计：检查是否存在性别、种族等维度的系统性差异
    5. 



体系的局限与持续演化
未完全解决的问题
新体系并非完美。几个持续存在的挑战包括：


    

  1. 模糊性焦虑：部分员工反馈"我不知道我到底表现如何"——没有明确的数字评分让一些人感到不安
    2. 

  2. Manager 差异：当评估高度依赖 Manager 的判断时，不同 Manager 的标准差异可能很大
    3. 

  3. 高绩效者的激励问题：顶尖贡献者可能感觉"干多干少差别不大"——尤其在薪酬信息不透明的环境中
    4. 



持续迭代
微软对绩效体系保持了"成长型思维"——承认它是一个需要持续改进的系统，而非一劳永逸的方案。从 2014 年至今，体系经历了多次微调：


    

  • 2016 年：增加了"Rewards Conversation"环节，让员工更清楚地了解奖励逻辑
    • 

  • 2018 年：强化了跨团队 feedback 的权重
    • 

  • 2020 年：远程工作背景下增加了异步 Connect 选项
    • 

  • 2023 年：AI 辅助的绩效反馈摘要工具开始试点
    • 



小结
微软的"成长与影响力"模型代表了科技行业绩效管理的范式转变：从年终审判式的强制排名，转向持续对话式的教练辅导。其设计的三个核心洞见是——第一，绩效评估的频率应该从年度变为持续；第二，评估维度应该从单一个人产出扩展到协作贡献；第三，奖励应该基于绝对贡献而非相对排名。这个体系的成功不在于它消除了所有问题，而在于它将绩效管理从"选择并淘汰最差的人"重新定向为"帮助每一个人成长"——与微软"赋能每一个人"的使命高度一致。
