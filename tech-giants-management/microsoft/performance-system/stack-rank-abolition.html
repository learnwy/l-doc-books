废除 Stack Ranking：微软绩效管理的历史性转折

知识要点

2013 年 11 月，微软人力资源负责人 Lisa Brummel 宣布废除实施了十余年的 Stack Ranking（强制排名）绩效体系。这一决定标志着微软组织管理理念的根本转向——从"通过内部竞争筛选精英"转向"通过协作创造集体价值"。Stack Ranking 的废除不是一个孤立的 HR 政策调整，而是微软文化重建的前奏曲——它发生在纳德拉正式就任 CEO 前三个月，为后续的成长型思维变革清除了制度障碍。

Stack Ranking 的起源与机制

从 GE 到微软：强制排名的扩散

Stack Ranking 的起源可以追溯到通用电气（GE）的杰克·韦尔奇。1980 年代，韦尔奇推行"活力曲线"（Vitality Curve）——每年将员工强制分为三档：顶部 20%（明星）、中间 70%（可靠贡献者）、底部 10%（需改进或淘汰）。韦尔奇认为，这种机制能保持组织的"新陈代谢"。

微软在 2000 年前后引入了自己的版本。具体机制是：

  1. 固定配额：每个团队必须按照预设比例分配绩效等级——不管团队实际表现如何
  2. 相对排名：员工的评级不取决于绝对贡献，而取决于他在同组中的相对位置
  3. 末位淘汰：连续处于底部的员工面临绩效改进计划（PIP）或离职压力

制度设计的"合理性"假设

Stack Ranking 背后有三个隐含假设：

  • 假设 1：人才分布天然服从正态曲线——任何团队中都有"明星"和"末位"
  • 假设 2：竞争产生动力——员工知道自己被排名会更努力工作
  • 假设 3：组织需要定期"修剪"——淘汰底部能保持团队精英化

这些假设在某些特定场景（如销售团队的个人业绩排名）可能成立，但当它被无差别地应用到需要深度协作的研发团队时，产生了灾难性后果。

毒化效应：Stack Ranking 如何摧毁协作

团队内部的博弈论困境

当同组同事的绩效等级是零和游戏时（你的"超越期望"意味着别人必须被归入"不及预期"），理性个体的最优策略不再是"最大化团队产出"，而是"最大化自己的相对排名"。

具体的毒化行为包括：


    

  1. 帮助规避：资深工程师不愿辅导新人——因为新人成长后会成为自己排名的竞争对手
    2. 

  2. 组队博弈：精明的员工会主动寻找"较弱"的团队加入，因为在强者如林的团队中更难排到前列
    3. 

  3. 风险回避：创新性项目失败概率高，员工倾向于选择"安全"的渐进式工作来保护排名
    4. 

  4. 功劳争夺：跨团队协作时，各方更关注"谁的名字出现在邮件 CC 的第一行"
    5. 



人才流失的加速器
Stack Ranking 最讽刺的后果是：它声称要淘汰"低绩效者"，实际上驱逐的往往是最优秀的人才。原因是：


    

  • A 类人才有选择权：顶尖工程师可以轻松跳槽到 Google、Facebook，不需要忍受有毒的内部竞争环境
    • 

  • B 类人才被困住：中间层员工跳槽风险较高，反而更可能留下
    • 

  • 系统性偏见：Stack Ranking 对少数族裔和女性工程师的影响尤为严重——当评估依赖"相对印象"而非客观产出时，unconscious bias 被放大
    •

媒体曝光与外部压力
2012 年，科技记者 Kurt Eichenwald 在《名利场》（Vanity Fair）发表了长篇调查报道，将微软的 Stack Ranking 公之于众。文中引用了多位匿名微软员工的证词，描述了这个系统如何将一群聪明人变成互相提防的政治动物。




"如果你把 10 个微软员工放在一个团队里，他们花的时间不是在想如何打败 Google，而是在想如何确保自己不是那个被排在最后的人。"——匿名微软工程师




这篇报道获得了广泛传播，给微软高层施加了巨大的舆论压力。


废除决定的过程
内部讨论与高层共识
Stack Ranking 的废除不是一夜之间的决定。从 2011 年开始，HR 团队就在进行内部调研，发现：


    

  • 超过 60% 的经理认为强制排名"降低了团队效能"
    • 

  • 退出面试（Exit Interview）中，"绩效体系不公平"是排名前三的离职原因
    • 

  • 顶尖研发团队（如 Azure 早期团队）已经在非正式地规避这个系统
    • 



2013 年中，新任 HR 负责人 Lisa Brummel 向 CEO 鲍尔默和董事会提交了改革方案。值得注意的是：鲍尔默批准了这一方案——这是他在任期末做出的最重要的制度性决策之一。


宣布与过渡
2013 年 11 月 12 日，Lisa Brummel 通过全员邮件宣布废除 Stack Ranking。邮件中的关键表述是："更强调团队合作与协作……不再有曲线和分配配额。"


过渡安排包括：


    

  1. 立即生效：下一个绩效周期（FY2014）起不再使用强制排名
    2. 

  2. 经理培训：所有 People Manager 必须在 90 天内完成新体系的培训
    3. 

  3. 薪酬脱钩：薪酬调整不再与单一排名挂钩，而是综合考虑影响力、成长和协作
    4. 



废除后的文化连锁反应
Stack Ranking 的废除产生了远超预期的文化连锁效应：


    

  1. 心理安全感提升：员工不再需要"保护自己的排名"，可以更坦诚地承认错误和寻求帮助
    2. 

  2. 知识流动加速：资深员工开始主动辅导新人——因为新人的成长不再威胁自己的排名
    3. 

  3. 跨团队协作恢复：当帮助其他团队不再有"排名成本"时，One Microsoft 的愿景开始有了制度基础
    4. 

  4. 为新 CEO 铺路：纳德拉 2014 年 2 月上任时，最大的制度障碍已经被移除——他可以直接推动成长型思维，而非先花一年时间解决绩效体系问题
    5. 



小结
Stack Ranking 的废除是微软文化转型的"制度性前奏"。它的教训对所有管理者都有警示价值：绩效管理系统不是中性工具，而是文化的编码器——它定义了"什么行为被奖励"，从而塑造了组织中每一个人的行为选择。当一个绩效系统奖励个人排名而非集体成果时，即使口头上强调"团队合作"，员工的实际行为也会偏向竞争和自保。微软的经验表明：文化变革的第一步往往不是"宣布新文化"，而是"拆除旧制度中与新文化冲突的部分"。
