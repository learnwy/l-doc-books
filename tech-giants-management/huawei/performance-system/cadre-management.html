干部四象限与干部管理

知识要点

华为将"干部管理"视为公司管理的核心命题。任正非多次强调："华为最大的浪费不是资金浪费，而是干部浪费。一个不称职的干部，贻误的是一个方向、一群人。"华为建立了一套从选拔、使用、考核到退出的完整干部管理体系，其中"干部四象限"模型是评价干部的核心工具。

干部四象限以"品德"和"能力"为两个维度，将干部分为四类：

象限 品德 能力 处理方式
第一象限 高品德 高能力 重用——优先提拔
第二象限 高品德 低能力 培养——给机会成长
第三象限 低品德 高能力 限制使用——严格监督
第四象限 低品德 低能力 坚决淘汰

详细讲解

华为干部标准的"三个优先"

华为选拔干部遵循三个优先原则：

1. 优先从成功实践中选拔干部

华为不相信"空降兵"和"纸上谈兵者"。所有干部必须有成功的实战经验，且这种经验必须经过验证。一个从未打过胜仗的人，无论学历多高、口才多好，都不能被提拔。

2. 优先从主攻战场、一线和艰苦地区选拔干部

华为鼓励干部到艰苦地区锻炼，并将"一线经验"作为晋升的必要条件。没有海外艰苦地区工作经验的人，难以进入中高层。

3. 优先从影响公司长远发展的关键事件中考察和选拔干部

华为关注干部在关键时刻的表现——危机处理、项目攻坚、战略转型等。日常工作中表现平平但关键时刻能顶上去的人，可能比日常表现优秀但遇到困难就退缩的人更值得提拔。

干部四象限的深层解读

品德的内涵：在华为语境中，"品德"不仅指狭义的道德品质，更包含：


    

  • 是否践行"以客户为中心"的价值观
    • 

  • 是否廉洁自律（"利出一孔"）
    • 

  • 是否具有团队精神而非个人英雄主义
    • 

  • 是否敢于自我批判
    • 



能力的内涵：华为对干部能力的要求涵盖四个方面：


    

  • 战略洞察：看清方向、把握趋势
    • 

  • 决断执行：关键时刻敢拍板、能落地
    • 

  • 人际连接：凝聚团队、跨部门协调
    • 

  • 学习成长：快速适应新环境、新挑战
    •

华为的干部管理覆盖"选、用、留、流"四个环节：

AT会（Administration Team）：干部的选拔和任命不由单一领导决定，而是由AT团队集体决策。AT会由上级主管和HR代表组成，通过讨论和投票决定干部任免。这防止了"任人唯亲"和"一言堂"。


"90天转身"机制
新干部到任后有90天的"转身期"。在此期间：


    

  • 必须完成对业务现状的全面了解
    • 

  • 制定任期内的工作规划
    • 

  • 与上下级建立信任关系
    • 

  • 接受"转身辅导员"的支持
    • 



90天后进行转身评估。如果未能成功转身，将重新考虑任命决定。


干部的退出机制
华为对干部的退出有明确的触发条件：


    

  1. 绩效退出：连续两年绩效排名后20%
    2. 

  2. 品德退出：违反廉洁底线（如受贿1万元即开除）
    3. 

  3. 能力退出：无法适应岗位升级要求
    4. 

  4. 年龄退出：鼓励高层管理者适时退休让贤
    5. 



任正非特别强调"干部能上能下"是华为的铁律。曾任某大区总裁的人可以被降为区域经理，且华为文化中不认为这是"耻辱"，而是正常的组织调配。


实践案例
"烧不死的鸟是凤凰"
华为有多位高层干部经历过"起落"——被降级后重新证明自己、再获提拔。任正非用"烧不死的鸟是凤凰"来鼓励这种精神。


一个著名的案例是：某位华为副总裁因为分管业务亏损被降为普通员工，到非洲一线从基层做起。三年后，他凭借在非洲市场的出色业绩重新被提拔为大区负责人。


这种"能上能下"的文化消除了干部的"只升不降"心态，让整个管理层保持危机感。


"利出一孔"的廉洁底线
华为对干部廉洁的要求极为严格。任正非明确规定：高管受贿1万元即开除。这一标准远低于法律对贿赂的追诉金额，体现了华为"零容忍"的态度。

华为设有独立的审计部门和"道德遵从委员会"，定期巡查各级干部的经济行为。


干部轮岗与"之字形成长"
华为鼓励干部在不同岗位间轮转，走"之字形"的成长路径而非"直线上升"。例如：


    

  • 研发主管 → 销售主管 → 区域总经理
    • 

  • 国内干部 → 海外代表处 → 总部职能部门
    • 

  • 业务线干部 → HR或财务 → 更高层级业务线
    • 



这种轮岗制度确保了干部具有全面的视野和综合管理能力，避免了"专业型干部"缺乏全局观的问题。


影响与启示
华为干部管理的核心贡献
华为的干部管理体系解决了中国企业普遍存在的几个痛点：


可借鉴的核心原则
    

  1. 实战检验优于理论考量：选干部看战功，不看学历和口才
    2. 

  2. 集体决策优于个人拍板：AT会机制防止腐败和偏见
    3. 

  3. 品德是底线，能力是条件：两者缺一不可
    4. 

  4. 流动是常态，固守是例外：能上能下才能保持组织活力
    5. 



小结
华为的干部管理体系以"四象限"为评价框架，以"三个优先"为选拔原则，以AT集体决策为程序保障，以"能上能下"为流动机制，构建了一套自我净化、自我更新的干部生态系统。其核心理念是：干部是公司最重要的资产，也是最大的风险来源——好干部能带领团队创造价值，差干部则会毁掉一个方向。因此，华为对干部的要求远高于普通员工，对干部的淘汰也更为果断。
