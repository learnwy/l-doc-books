Part II · 全球科技平台Uber 企业管理与组织文化 简介绩效体系 简介绩效变革：从"赢者通吃"到"负责任增长"

绩效变革：从"赢者通吃"到"负责任增长"

知识要点

Uber 的绩效管理变革是其文化转型中最具操作性的一环。在 Travis Kalanick 时代，绩效体系服务于一个单一目标——以最快速度赢得市场。员工被按照"是否能帮助公司赢得战争"来评判，业绩超标者享有几乎不受约束的自由，而未达标者则面临快速淘汰。这套体系在 2017 年的文化危机中被证明是问题的核心放大器：高绩效者的不当行为被容忍甚至默许，因为"他们在帮公司赢"。

Khosrowshahi 主导的绩效变革建立在一个核心认知上：绩效不仅是"做了什么"，更是"怎么做的"。新体系将文化行为与业务结果同等对待，创造了一种既追求卓越又坚守底线的绩效文化。

绩效维度 Kalanick 时代 Khosrowshahi 时代
评估周期 随时，非结构化 半年度正式评估 + 季度 Check-in
评估标准 业务结果（几乎唯一） 业务结果 + 文化行为 + 团队影响
反馈机制 自上而下，直接粗暴 360度多维反馈
淘汰机制 非正式但频繁 有程序的绩效改进计划（PIP）
奖励导向 赢家获得不成比例的奖励 团队贡献与个人贡献并重
管理者责任 交付结果即可 团队健康、人员发展、文化践行

详细讲解

Kalanick 时代的绩效"丛林法则"

在旧 Uber，绩效管理更像是一种达尔文主义的实践：

无底线的内部竞争：团队之间、个人之间的竞争被鼓励到极端。"Toe-Stepping"价值观赋予员工跨越边界抢夺项目的"权利"，导致内部资源争夺消耗了大量组织能量。

"Stack Ranking"的影子：虽然 Uber 从未正式宣布采用微软式的强制排名制度，但其文化暗示了类似的逻辑——每次评估都有人被标记为底部，面临淘汰压力。

高绩效者的豁免权：对业绩突出的员工，行为问题被系统性忽视。Susan Fowler 事件中的核心问题之一就是：她投诉的管理者因"是高绩效者"而免受处罚。HR 明确告知她"这是他的初犯"——言下之意是，高绩效者有犯错的"额度"。

结果至上的激励结构：薪酬和股权高度与增长指标挂钩，导致员工为达成目标不择手段。这在商业层面催生了 Greyball 工具等灰色操作，在人际层面催生了欺凌和排挤。

新绩效哲学的三大支柱

Khosrowshahi 的绩效变革建立在三大支柱之上：

支柱一：What（业务结果）


业务结果仍然重要——Uber 不是慈善机构。但评估标准从"绝对数字"转向"在约束条件下的成果"。这意味着：


    

  • 通过不合规手段取得的增长不计入正面绩效
    • 

  • 以团队健康为代价的个人突出表现会被打折
    • 

  • 短期业绩与长期可持续性的平衡被纳入考量
    • 



支柱二：How（文化行为）


这是最大的变化。每个员工在每次评估中都会收到关于八项文化准则践行情况的具体反馈。行为维度的权重在不同级别有所不同：初级 IC（Individual Contributor）约占 30%，高级 IC 约占 40%，管理者约占 50%。级别越高，"怎么做"的权重越大。


支柱三：Growth（个人发展）


新体系不再仅仅评判当前表现，还关注成长轨迹和对组织人才密度的贡献。这包括：


    

  • 个人技能的可衡量进步
    • 

  • 对初级同事的辅导和知识分享
    • 

  • 在舒适区之外的挑战性项目中的表现
    •

从"淘汰制"到"发展型 PIP"
旧 Uber 的淘汰更像是突然死亡——表现不佳的员工可能在毫无预警的情况下被通知离开。新体系引入了正式的绩效改进计划（Performance Improvement Plan），确保：


    

  1. 预警充分：在正式 PIP 之前，员工至少在两次 Check-in 中被告知问题
    2. 

  2. 计划明确：PIP 包含具体的改进目标、资源支持和时间线（通常60-90天）
    3. 

  3. 支持到位：配备辅导资源、培训机会和定期进展回顾
    4. 

  4. 结果透明：PIP 的通过/未通过标准在开始时即明确沟通
    5. 



实践案例
从"增长不惜代价"到"可持续增长"——巴西市场团队的转型


2018 年初，Uber 巴西团队在旧绩效文化的惯性下继续激进补贴以抢占市场份额。月度活跃用户增长 40%，但单位经济模型持续恶化。在旧体系下，团队负责人会因为"增长惊人"而获得最高绩效评级。


新绩效体系下的评估截然不同：增长数据固然正面，但"How"维度指出该团队忽视了单位经济的健康度（违反"We Act Like Owners"——主人翁不会烧别人的钱），且在内部多次被财务团队质疑后选择忽视（违反"We Value Ideas Over Hierarchy"）。


最终该团队负责人的评级被下调，并被要求在下一周期提交包含盈利路径的增长方案。这一决策向整个组织发送了清晰信号：增长本身不再是充分条件。


影响与启示
Uber 的绩效变革提供了以下管理启示：


    

  1. "How"的权重必须有制度保障：仅在口头强调行为不够，必须将其与薪酬、晋升直接挂钩
    2. 

  2. 管理者是变革的关键杠杆：对管理者设定更高的"How"权重，促使他们成为文化变革的传导者
    3. 

  3. 绩效变革需要容忍短期效率损失：新流程（360反馈、校准会议、PIP）增加了时间成本，但长期价值远超投入
    4. 

  4. 透明度是信任的基础：新体系的规则对所有人公开，消除了旧体系中"谁认识谁"的灰色地带
    5. 



小结
Uber 的绩效变革本质上是将企业价值观从"墙上的标语"转化为"有奖惩后果的行为标准"。通过 What + How + Growth 的三维评估框架、结构化的半年度评估流程、以及发展导向的 PIP 机制，Uber 建立了一套既能推动商业成果又能维护组织健康的绩效体系。这一体系是 Uber 从"有毒高增长"转向"健康可持续增长"的核心制度基础设施。
