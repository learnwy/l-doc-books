Anthropic 员工如何利用 AI

"吃自己的狗粮"文化

在 Anthropic，使用 Claude 不是可选项——它是日常工作的一部分。这种"dogfooding"文化有双重价值：第一，提升每个员工的工作效率；第二，让产品团队从内部用户那里获得最直接的反馈。

Anthropic 的员工可能是世界上最挑剔的 Claude 用户——他们同时是构建者和使用者，能够精确地指出模型在哪里好用、在哪里不够好。

内部工具与实践

Claude Code 的内部使用

Claude Code 不仅是 Anthropic 的商业产品，也是其工程师日常工作的核心工具。具体使用场景：

代码开发：

  • 使用 Claude Code 编写和重构代码
  • 利用 Claude 理解庞大的内部代码库
  • 用 Claude 生成和维护测试用例
  • 通过 /ultrareview 进行代码审查

调试与问题排查：

  • 分析复杂的错误日志和堆栈跟踪
  • 在分布式训练环境中追踪跨层级的问题
  • 辅助 on-call 期间的快速问题诊断

Claude 在研究工作中的应用

文献研究：

  • 快速摘要和比较多篇论文
  • 追踪特定研究方向的最新进展
  • 生成文献综述的初稿框架

实验设计与分析：

  • 辅助实验方案的头脑风暴
  • 使用 Code Execution 工具分析实验数据
  • 生成数据可视化图表

论文写作：

  • 初稿撰写和结构建议
  • 学术写作风格的改进
  • 参考文献管理

Claude 在运营工作中的应用

沟通与文档：

  • 起草内部和外部通信
  • 整理和总结会议纪要
  • 编写政策文件和流程文档

数据分析：

  • 分析业务指标和财务数据
  • 生成运营报告
  • 辅助招聘数据分析

项目管理：

  • 任务分解和项目规划
  • 风险识别和状态报告
  • 跨团队协调的信息整合

反馈循环：内部使用如何改进产品

Anthropic 的 dogfooding 文化创造了一个独特的反馈循环：

  1. 员工在日常工作中使用 Claude → 发现具体的痛点和不足
  2. 内部反馈传递给产品团队 → 产品团队优先修复影响内部使用的问题
  3. 改进后的 Claude 提升员工效率 → 更多使用、更多反馈
  4. 对外发布改进后的产品 → 外部用户获得经过内部验证的改进

这个循环的一个具体例子：Claude Code 的 /ultrareview 功能据说就是因为 Anthropic 内部工程师在代码审查中频繁使用 Claude 而产生的需求。

AI 使用的安全边界

即使在 Anthropic 内部，AI 的使用也有明确的安全边界：

  • 敏感信息处理：涉及模型权重、安全评估细节等敏感信息的工作有使用限制
  • 决策辅助而非决策替代：Claude 的建议始终需要人类判断——尤其在安全相关的决策中
  • 输出验证：任何 AI 生成的内容在正式使用前需要人类审查

这些边界不是对员工的不信任，而是对 AI 系统局限性的尊重——即使是最先进的模型也会犯错，在高风险场景中人类验证是不可或缺的。

生产力影响的量化

虽然 Anthropic 没有公开其内部 AI 使用对生产力的具体量化数据，但从以下信号可以推断影响是显著的：

  • 人均收入极高：约 2500 名员工支撑 ~300亿ARR，人均年收入贡献约300 亿 ARR，人均年收入贡献约300亿ARR，人均年收入贡献约1200 万——远超行业平均
  • 快速的产品迭代节奏：Claude 系列的更新频率（约每 2-3 个月一个重大版本）暗示了高效的开发流程
  • 精简的团队规模：相比竞争对手（OpenAI ~3000+、Google AI 数千人），Anthropic 用相对较少的人做出了同等甚至更大的商业成果

给其他组织的启示

Anthropic 的 AI 使用实践为其他组织提供了几个可借鉴的模式：

全员 AI 化：不要把 AI 工具限制在"技术团队"使用——从研究到运营，从法务到招聘，每个岗位都应该探索 AI 辅助的可能性。

安全边界先行：在大规模推广 AI 工具之前，先建立明确的使用边界——哪些场景可以使用、哪些不行、哪些需要人类审查。

反馈循环设计：建立从"员工使用 AI"到"产品改进"的正式反馈通道——不要让宝贵的内部使用经验沉没在个人笔记中。

文化引导：鼓励员工将 AI 视为提升效率的工具而非威胁。领导层的以身作则很重要——当 CEO 公开使用 AI 工具并分享使用心得时，整个组织的 AI 采纳速度会大幅加快。

Anthropic 的经验表明，"构建 AI 的公司如何使用 AI"的答案是：深度、广泛、持续、且有边界地使用。这种用法既是生产力的来源，也是产品改进的源泉。
