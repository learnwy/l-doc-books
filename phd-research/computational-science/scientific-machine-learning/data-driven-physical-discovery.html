博士阶段 计算科学前沿 — 数据驱动的物理发现

知识要点

科学的核心任务之一是从观测中提炼规律——开普勒从第谷的行星观测数据中发现了椭圆轨道定律，牛顿将其统一为万有引力。数据驱动的物理发现将这一过程部分自动化：给定系统的观测数据（轨迹、场分布、时间序列），算法自动识别支配系统行为的数学方程或物理结构。这不是用神经网络"黑箱"拟合数据，而是从数据中提取可解释的数学表达式。

三条主要技术路线：

  • 稀疏回归（SINDy）：构建候选函数库，通过稀疏优化筛选出最简单的方程
  • 符号回归（Symbolic Regression）：在数学表达式的空间中搜索，寻找最优的解析公式
  • 图神经网络发现（GNN-based Discovery）：从粒子系统的相互作用中学习力的函数形式
详细讲解
一、SINDy：稀疏识别非线性动力学
SINDy（Sparse Identification of Nonlinear Dynamics）由 Brunton 等人（2016）提出，核心思想简洁而强大：大多数物理系统的控制方程由少量项组成——牛顿第二定律只有一项，Lorenz 系统只有七项。稀疏性是先验知识，稀疏回归是实现工具。

弱形式 SINDy（WSINDy）：将 PDE 与测试函数积分后进行稀疏回归，避免了直接估计高阶导数的噪声放大问题。对于带噪声的 PDE 识别，WSINDy 的鲁棒性比原始 SINDy 高出一到两个数量级。


二、符号回归：搜索数学表达式
符号回归的目标是找到一个解析数学表达式 f(x1,...,xn)f(x_1, ..., x_n)f(x1​,...,xn​) 使其最佳拟合数据，同时保持表达式的简洁性。与数值回归（确定函数形式、拟合参数）不同，符号回归同时搜索函数形式和参数。


表达式树表示：数学公式自然地表示为树结构。叶节点是变量和常数，内部节点是运算符（+,−,×,÷,sin⁡,exp⁡,...+, -, \times, \div, \sin, \exp, ...+,−,×,÷,sin,exp,...）。


遗传编程（Genetic Programming） 是最经典的符号回归方法：


    

  1. 初始化：随机生成一个表达式树种群
    2. 

  2. 评估：计算每棵树对数据的拟合误差 + 复杂度惩罚
    3. 

  3. 选择：适应度高的个体被选中进入下一代
    4. 

  4. 交叉：交换两棵树的子树生成新个体
    5. 

  5. 变异：随机修改单个节点（运算符替换、常数扰动）
    6. 

  6. 迭代直到收敛
    7. 



PySR / SymbolicRegression.jl（Cranmer, 2023）是当前最先进的开源符号回归库，采用多种群进化策略和自适应复杂度控制。


AI Feynman（Udrescu 和 Tegmark, 2020）从物理学视角设计符号回归：利用物理对称性（平移、旋转、缩放不变性）和可分解性（变量分离）大幅缩减搜索空间。该系统成功从数据中重新发现了费曼物理学讲义中的 100 个方程。


基于强化学习的方法：将表达式生成建模为序列决策问题，使用 RNN 或 Transformer 逐步生成表达式树的前序遍历。Deep Symbolic Regression（Petersen 等, 2021）用风险自适应策略梯度训练策略网络，在标准基准上达到了遗传编程的竞争性能。


三、图神经网络与相互作用发现
许多物理系统由相互作用的实体组成：粒子系统（原子、星体、碰撞球）、多体系统、电路网络。图神经网络（GNN）天然适合建模这类系统的结构。


交互网络（Interaction Network, IN）（Battaglia 等, 2016）是开创性工作：


    

  1. 将物理系统建模为图：节点 = 粒子，边 = 相互作用
    2. 

  2. 消息传递：每条边计算交互效应 eij=fe(si,sj,rij)e_{ij} = f_e(s_i, s_j, r_{ij})eij​=fe​(si​,sj​,rij​)
    3. 

  3. 节点更新：si′=fn(si,∑jeij)s_i' = f_n(s_i, \sum_j e_{ij})si′​=fn​(si​,∑j​eij​)

其中 sis_isi​ 是粒子状态（位置、速度），rijr_{ij}rij​ 是关系属性（距离、类型），fef_efe​ 和 fnf_nfn​ 是学习的神经网络。


GNN 发现的进阶方向：


Lagrangian/Hamiltonian Neural Networks（Greydanus 等, 2019; Cranmer 等, 2020）：不直接学习加速度，而是学习系统的 Lagrangian L(q,q˙)L(q, \dot{q})L(q,q˙​) 或 Hamiltonian H(q,p)H(q, p)H(q,p)，然后通过 Euler-Lagrange 方程或 Hamilton 方程推导运动——这确保了能量守恒等物理对称性被精确保持。

Symbolic Distillation（Cranmer 等, 2020）：先用 GNN 学习黑箱交互函数 fef_efe​，然后对 GNN 的预测数据使用符号回归提取解析表达式。这种两步法——先用 GNN 去噪和归纳，再用符号回归提取公式——结合了两类方法的优势。


四、守恒律发现与对称性检测
物理定律与对称性深度关联——Noether 定理将连续对称性与守恒量一一对应。自动发现对称性和守恒律是数据驱动物理发现的高阶目标。


守恒律发现：


给定动力系统的轨迹数据，寻找沿轨迹不变的函数 C(x)C(\mathbf{x})C(x)，即 dCdt=∇C⋅x˙=0\frac{dC}{dt} = \nabla C \cdot \dot{\mathbf{x}} = 0dtdC​=∇C⋅x˙=0。


Liu 和 Tegmark（2021）提出用神经网络参数化 CCC，训练目标为最小化 ∣dCdt∣|\frac{dC}{dt}|∣dtdC​∣ 同时最大化 CCC 的非平凡性（梯度不为零）。该方法从 NNN 体引力系统的轨迹中自动发现了能量、动量和角动量守恒。


等变神经网络：


SE(3)-Equivariant Neural Networks 将旋转和平移对称性硬编码进网络架构。对于分子系统，如果输入坐标旋转 θ\thetaθ 度，输出力也精确旋转 θ\thetaθ 度——而不是依赖数据增强来近似学习这种对称性。代表性模型包括 NequIP、MACE、Allegro。


五、可发现性的边界
数据驱动发现并非万能。其有效性取决于：


数据质量：高噪声数据中的弱信号可能被淹没。稀疏回归的正则化参数 λ\lambdaλ 直接控制噪声容忍度与模型复杂度的权衡。


候选空间覆盖：SINDy 只能发现候选库中包含的函数形式。如果真实方程包含候选库中不存在的特殊函数，SINDy 无法发现它。符号回归的搜索空间理论上更大，但计算成本也随之爆炸。


可辨识性：某些系统可能有多个数学上等价的描述（如 Lagrangian 力学和 Newtonian 力学），数据不足以区分它们。


因果性 vs 相关性：数据驱动方法发现的是统计关联，不是因果关系。x˙=f(x,y)\dot{x} = f(x, y)x˙=f(x,y) 中 yyy 的出现不意味着 yyy 因果地影响 xxx——可能存在共同的隐变量。

小结
数据驱动的物理发现将机器学习从"黑箱预测"提升到"白箱发现"——从数据中提取可解释的数学规律。SINDy 通过稀疏回归在预定义的函数库中高效搜索，适合结构已知但系数未知的问题；符号回归在开放的表达式空间中搜索，能发现意想不到的公式但计算成本高；图神经网络从粒子系统的结构中学习相互作用，Hamiltonian/Lagrangian 网络确保物理守恒律被精确保持。这三条路线并非竞争关系——GNN 提供归纳偏置，符号回归提取解析表达式，SINDy 在噪声数据上高效识别方程——组合使用往往效果最佳。
