科学机器学习 简介

科学机器学习是深度学习与传统科学计算的交叉领域，旨在利用数据驱动方法加速或替代昂贵的数值模拟，同时保持物理一致性。与纯数据驱动的机器学习不同，科学机器学习将领域知识——守恒律、对称性、因果结构——编码进模型架构或训练过程中，从而在小数据条件下实现更好的泛化能力。

本章覆盖科学机器学习的三个核心方向。

物理信息神经网络介绍 PINN 的理论基础与实现方法。通过将偏微分方程残差作为损失函数的一部分，PINN 在无需网格的情况下求解正问题和逆问题。内容涵盖软约束与硬约束策略、自适应采样、多尺度损失平衡，以及 PINN 在流体力学、固体力学、传热学中的典型应用与已知局限。

神经算子与代理模型探讨从函数到函数的算子学习方法。DeepONet 通过分支-主干架构学习参数化输入到解的映射，Fourier Neural Operator 利用频域卷积实现分辨率无关的算子逼近。本节还讨论 Transformer 在科学模拟中的应用以及代理模型在优化和不确定性量化中的加速作用。

数据驱动的物理发现聚焦从观测数据中自动发现物理定律。SINDy（稀疏回归识别非线性动力学）从时间序列数据中提取控制方程，符号回归通过遗传编程或强化学习搜索解析表达式，图神经网络从粒子轨迹中学习相互作用规则。

建议在阅读时尝试用 PyTorch 或 JAX 实现关键算法的简化版本，以加深对方法本质的理解。
