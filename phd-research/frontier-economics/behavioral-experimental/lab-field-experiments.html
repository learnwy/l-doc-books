博士阶段 经济学前沿议题 — 实验室实验与田野实验

知识要点

实验方法的引入从根本上改变了经济学的认识论地位。在 Vernon Smith 于二十世纪六十年代开创实验室市场实验之前，经济学几乎完全依赖观测数据与结构模型进行推断——因果识别始终是一个无法回避的难题。实验室实验通过环境控制实现了内部有效性的最大化，而 Duflo、Banerjee 等人推动的田野随机对照试验（RCT）则将实验方法的适用范围从实验室扩展到真实的经济情境中。两种方法各有所长、互为补充，共同构成了当代经济学因果推断的方法论双支柱。

本节聚焦三个核心问题：实验室实验的设计原则与有效性边界；田野 RCT 的设计范式与统计基础设施；以及自然实验、断点回归与工具变量方法如何在无法随机化的场景中逼近因果推断。

详细讲解

实验室实验的设计逻辑

实验室实验的核心优势在于对环境变量的精确控制。通过"诱导价值法"（Induced Value Theory），实验者可以为被试创造具有已知参数的决策环境，从而将理论预测与实际行为之间的偏差直接归因于行为假设的失败，而非环境噪声。

Smith（1976）提出的实验设计三原则奠定了实验经济学的方法论基础：

原则 含义 操作要求
单调性（Monotonicity） 被试偏好更多的报酬 实际货币激励
显著性（Salience） 报酬取决于被试的决策 报酬与选择直接挂钩
支配性（Dominance） 实验激励支配其他动机 报酬足够大以压制社会期望效应

内部有效性与外部有效性的权衡是实验室实验的核心张力。高度控制的环境确保了因果推断的可靠性（内部有效性），但被试通常是大学生、决策情境高度抽象、利益金额有限——这些特征引发了对结论可推广性（外部有效性）的持续质疑。Levitt 与 List（2007）在一篇有影响力的论文中系统梳理了实验室结果可能失败的五种外推机制：选择效应、利益规模效应、决策框架效应、审查效应和背景效应。

自然实验与准实验方法
在许多重要的经济学问题上（如最低工资的就业效应、移民对本地劳动力的影响），随机化在伦理或实际操作上不可行。此时，研究者转向自然实验——利用外生的政策变化、制度规则或随机事件作为"类似随机分配"的识别来源。


断点回归设计（Regression Discontinuity, RD）利用处理分配的阈值规则来识别因果效应。当分配变量 XiX_iXi​ 跨越阈值 ccc 时，处理状态发生跳跃性变化：


τRD=lim⁡x↓cE[Yi∣Xi=x]−lim⁡x↑cE[Yi∣Xi=x]\tau_{RD} = \lim_{x \downarrow c} E[Y_i | X_i = x] - \lim_{x \uparrow c} E[Y_i | X_i = x]τRD​=x↓clim​E[Yi​∣Xi​=x]−x↑clim​E[Yi​∣Xi​=x]
RD 设计的核心假设是分配变量在阈值处的连续性（无精确操纵），实践中通过 McCrary（2008）密度检验和协变量平衡检验来验证。


双重差分（Difference-in-Differences, DiD）比较处理组与控制组在政策实施前后的结果变化差异：


τ^DiD=(YˉT,post−YˉT,pre)−(YˉC,post−YˉC,pre)\hat{\tau}_{DiD} = (\bar{Y}_{T,post} - \bar{Y}_{T,pre}) - (\bar{Y}_{C,post} - \bar{Y}_{C,pre})τ^DiD​=(YˉT,post​−YˉT,pre​)−(YˉC,post​−YˉC,pre​)
关键的平行趋势假设要求两组在没有处理时的结果变化趋势相同。近年来，Callaway 与 Sant'Anna（2021）、Sun 与 Abraham（2021）等人的工作揭示了交错处理时点下传统 TWFE（双向固定效应）估计量的严重偏误问题，推动了 DiD 方法论的重大更新。


多重假设检验与预注册
当同一实验同时检验多个假说时，家族错误率（Familywise Error Rate, FWER）的控制成为统计有效性的关键问题。Bonferroni 校正最为保守——将显著性阈值除以假设数量 kkk：α∗=α/k\alpha^* = \alpha / kα∗=α/k。更有力的替代方案包括 Holm 的分步下降程序和控制错误发现率（False Discovery Rate, FDR）的 Benjamini-Hochberg 程序：


BH procedure: reject H(i) if p(i)≤ik⋅q\text{BH procedure: reject } H_{(i)} \text{ if } p_{(i)} \leq \frac{i}{k} \cdot qBH procedure: reject H(i)​ if p(i)​≤ki​⋅q
其中 p(i)p_{(i)}p(i)​ 为排序后的 ppp 值，qqq 为目标 FDR 水平。


实验预注册（Pre-Registration）是应对 ppp-hacking 和选择性报告的制度性解决方案。AEA RCT Registry 和 OSF 平台要求研究者在数据收集前公开声明假说、样本量计算、主要结果变量和分析方案。预注册不限制探索性分析，但要求明确区分验证性与探索性结果。

拓展阅读
实验经济学的方法论基石由 Smith（1976）"Experimental Economics: Induced Value Theory" 奠定，发表于 American Economic Review。Kagel 与 Roth 编辑的 The Handbook of Experimental Economics（1995 年第一卷、2016 年第二卷）是该领域最全面的参考文献集。


田野 RCT 方面，Duflo, Glennerster 与 Kremer（2007）"Using Randomization in Development Economics Research: A Toolkit" 是实操指南的标准参考。Banerjee 与 Duflo（2011）的 Poor Economics 以通俗方式展示了 RCT 在发展经济学中的应用。Athey 与 Imbens（2017）"The Econometrics of Randomized Experiments" 提供了高级计量视角。


准实验方法方面，Angrist 与 Pischke（2009）Mostly Harmless Econometrics 是 DiD、IV、RD 的经典教材。关于交错 DiD 的最新进展，de Chaisemartin 与 D'Haultfoeuille（2020）发表于 American Economic Review 的论文和 Roth 等（2023）的综述文章 "What's Trending in Difference-in-Differences?" 是必读文献。


预注册运动的背景与实践，见 Christensen, Freese 与 Miguel（2019）Transparent and Reproducible Social Science Research，该书对可复制性危机的整体应对策略进行了系统讨论。


小结
本节围绕"如何在经济学中建立因果关系"这一核心方法论问题，系统介绍了实验室实验的诱导价值设计原则、田野 RCT 的统计基础设施（功效分析、整群随机、变体设计）、以及准实验方法（RD、DiD）在无法随机化场景中的应用。多重假设检验校正与预注册制度的讨论则着眼于实验科学的统计严谨性与制度保障。这些方法论工具不仅服务于行为经济学——它们是理解和评价本学习单元后续两章中大量实证文献的基础框架。下一节将讨论如何将行为洞见与实验证据转化为公共政策设计工具。
