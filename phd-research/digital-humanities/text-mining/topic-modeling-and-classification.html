博士阶段 数字人文前沿 — 主题建模与文本分类

知识要点

主题建模和文本分类是从大规模文本中提取结构和模式的两种互补策略。主题建模是无监督方法——不预设类别，让算法从数据中"发现"潜在主题；文本分类是有监督方法——基于人工标注的训练数据，教算法自动识别预定义的类别。两者在数字人文研究中各有适用场景。

LDA主题建模（Latent Dirichlet Allocation）的数学直觉是：每篇文档是多个"主题"的混合物，每个"主题"是词语的概率分布。算法通过迭代学习两组概率分布——文档-主题分布 θd\theta_dθd​ 和主题-词分布 ϕk\phi_kϕk​——使整个语料的联合概率最大化。

  1. 对文档 ddd，从先验分布 Dir(α)\text{Dir}(\alpha)Dir(α) 抽取主题分布 θd\theta_dθd​
    2. 

  2. 对文档中的每个词位 nnn：
      

    • 从 θd\theta_dθd​ 抽取主题 zd,nz_{d,n}zd,n​
      • 

    • 从该主题的词分布 ϕzd,n\phi_{z_{d,n}}ϕzd,n​​ 抽取词 wd,nw_{d,n}wd,n​

文本分类在数字人文中的典型应用：文类识别（这个文本是小说、诗歌还是戏剧？）、时期划分（这个文本属于哪个文学时期？）、情感分类（这段文本表达正面还是负面情感？）。分类器的选择——从传统的朴素贝叶斯、支持向量机到深度学习的BERT——取决于数据量、特征类型和可解释性需求。

预处理选择的影响。停用词表的选择（通用 vs. 领域定制）、是否进行词形还原、文档切分粒度（全文 vs. 章节 vs. 段落），都会显著影响主题的质量。没有"正确"的预处理方案——只有适合特定研究问题的方案。


结果解读的策略。LDA输出的是概率分布，不是人类可直接理解的"主题"。研究者需要：


    

  1. 检查每个主题的高概率词列表
    2. 

  2. 阅读该主题权重最高的文档片段
    3. 

  3. 给主题一个概括性的标签
    4. 

  4. 分析主题在时间、作者、文类等维度上的分布

有监督分类的文学应用
Ted Underwood在《Distant Horizons》中展示了有监督分类在文学史研究中的强大力量。他训练了一个分类器来区分被杂志评论关注的"声望小说"（prestige fiction）和未被关注的小说，然后分析区分两类的关键文本特征——发现"声望"不仅关乎主题选择，也关乎句子长度、词汇抽象度和叙事节奏。


有监督分类的标准流程：


    

  1. 标注数据准备：人工标注一组文本的类别（至少每类50-100个样本）
    2. 

  2. 特征提取：将文本转化为数值向量（词袋模型、TF-IDF、词嵌入）
    3. 

  3. 模型训练：选择分类算法，在标注数据上训练
    4. 

  4. 评估：使用交叉验证、混淆矩阵、F1分数等指标评估模型性能
    5. 

  5. 误差分析：检查被错误分类的文本——它们的共同特征往往比正确分类的更有学术洞察价值
    6. 



误差分析是数字人文特有的分析策略：被错误分类的文本可能是处于文类边界的"模糊"作品，其存在本身就挑战了现有的分类体系。


从统计模式到人文阐释
计算方法产生的是模式（patterns），不是意义（meaning）。从模式到意义的跨越是数字人文研究者最核心的学术技艺。


常见的阐释陷阱：


    

  • 过度阐释：将统计巧合赋予深层文化意义
    • 

  • 循环论证：用预设的理论来解释自己设计的分析
    • 

  • 确认偏差：只关注支持预期的发现，忽视矛盾的信号
    • 

  • 去语境化：将统计发现脱离文学和历史语境讨论
    • 



有效的阐释策略：


    

  • 始终回到文本本身——用细读验证远距离阅读的发现
    • 

  • 三角验证——用多种方法（不同算法、不同特征、不同语料切分）检验同一发现
    • 

  • 否定性结果同样有价值——模型无法区分的类别可能说明这些类别之间的界限比预想的更模糊
    • 



练习与思考
    

  1. 使用Python的gensim或scikit-learn库，对一个包含至少100个文档的语料运行LDA主题建模。分别尝试 K=10K=10K=10 和 K=30K=30K=30，比较结果。哪个更有可解释性？你发现了哪些出乎意料的主题？
    

    2. 

  2. 选择一个二分类任务（如区分两个时期的文学作品），手动标注30个训练样本，训练一个简单的分类器（如朴素贝叶斯）。检查被错误分类的文本——它们为什么"难以分类"？
    

    3. 

  3. 在一篇使用主题建模的数字人文论文中，评估作者从统计结果到人文阐释的跳跃是否合理。作者是否提供了足够的细读验证？是否考虑了替代解释？
    

    4. 

  4. 反思有监督分类中"类别"的本质。文学的"类别"（文类、时期、风格流派）是客观存在的还是人为建构的？如果是建构的，用机器学习来"发现"它们有什么意义？
    

    5.

小结
主题建模与文本分类为文学研究者提供了在大规模上发现文本模式的工具。LDA的无监督特性使其适合探索性研究——当你不知道语料中"有什么"时；有监督分类则适合验证性研究——当你有明确的假设需要在大样本上检验时。两种方法的共同挑战在于从统计输出到人文阐释的跨越——这一跨越不能被自动化，它需要研究者的文学素养、历史知识和阐释判断力。好的数字人文研究不是用算法替代思考，而是用算法拓展思考的范围。
