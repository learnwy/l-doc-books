实证研究设计框架

知识要点

实证研究设计的核心挑战在于一个根本性问题：我们永远无法同时观察到同一个体在接受处理和未接受处理两种状态下的结果。这就是 Rubin 因果模型中的"反事实基本问题"（Fundamental Problem of Causal Inference）。所有识别策略的本质，都是在寻找一种可信的方式来构造缺失的反事实。理解这一点，是区分"描述性统计分析"和"因果推断"的分水岭，也是博士阶段实证训练的起点。

详细讲解

因果推断的基本框架

令 Yi(1)Y_i(1)Yi​(1) 表示个体 iii 接受处理时的潜在结果，Yi(0)Y_i(0)Yi​(0) 表示未接受处理时的潜在结果。个体因果效应定义为：

τi=Yi(1)−Yi(0)\tau_i = Y_i(1) - Y_i(0)τi​=Yi​(1)−Yi​(0)

由于每个个体只能被观察到一种状态，我们通常关注的是平均处理效应（ATE）：

ATE=E[Yi(1)−Yi(0)]\text{ATE} = E[Y_i(1) - Y_i(0)]ATE=E[Yi​(1)−Yi​(0)]

或者处理组的平均处理效应（ATT）：

ATT=E[Yi(1)−Yi(0)∣Di=1]\text{ATT} = E[Y_i(1) - Y_i(0) \mid D_i = 1]ATT=E[Yi​(1)−Yi​(0)∣Di​=1]

其中 DiD_iDi​ 是处理变量。天真的比较 E[Yi∣Di=1]−E[Yi∣Di=0]E[Y_i \mid D_i = 1] - E[Y_i \mid D_i = 0]E[Yi​∣Di​=1]−E[Yi​∣Di​=0] 会引入选择偏误（Selection Bias）：

E[Yi∣Di=1]−E[Yi∣Di=0]⏟观察到的差异=ATT+E[Yi(0)∣Di=1]−E[Yi(0)∣Di=0]⏟选择偏误\underbrace{E[Y_i \mid D_i=1] - E[Y_i \mid D_i=0]}_{\text{观察到的差异}} = \text{ATT} + \underbrace{E[Y_i(0) \mid D_i=1] - E[Y_i(0) \mid D_i=0]}_{\text{选择偏误}}观察到的差异E[Yi​∣Di​=1]−E[Yi​∣Di​=0]​​=ATT+选择偏误E[Yi​(0)∣Di​=1]−E[Yi​(0)∣Di​=0]​​

识别策略的目标就是消除或最小化选择偏误项。

识别策略的分类体系

随机对照试验（RCT） 通过随机分配处理状态，确保 Di⊥(Yi(1),Yi(0))D_i \perp (Y_i(1), Y_i(0))Di​⊥(Yi​(1),Yi​(0))，从而使选择偏误为零。这是因果推断的"金标准"，但面临伦理约束、外部有效性、合规问题（noncompliance）和溢出效应等挑战。

选择偏误的来源与诊断
选择偏误并非单一现象，其来源包括：


遗漏变量偏误（OVB）：存在同时影响处理和结果的未观测因素。假设真实模型为 Yi=α+βDi+γXi+ϵiY_i = \alpha + \beta D_i + \gamma X_i + \epsilon_iYi​=α+βDi​+γXi​+ϵi​，但研究者遗漏了 XiX_iXi​，则短回归中 DiD_iDi​ 的系数为：


β^short=β+γ⋅δDX\hat{\beta}_{\text{short}} = \beta + \gamma \cdot \delta_{DX}β^​short​=β+γ⋅δDX​
其中 δDX\delta_{DX}δDX​ 是 XiX_iXi​ 对 DiD_iDi​ 回归的系数。OVB 的方向和大小取决于 γ\gammaγ（遗漏变量对结果的效应）和 δDX\delta_{DX}δDX​（遗漏变量与处理变量的相关性）的乘积。


自选择偏误：个体基于对处理效应的预期选择是否参与。例如，能力更高的人可能更倾向于接受高等教育。


幸存者偏误：仅在样本中幸存的观测被纳入分析。在公司层面数据中，倒闭企业往往不出现在面板数据后期。


测量误差偏误：处理变量的经典测量误差导致衰减偏误（attenuation bias），使系数向零偏倚：


plim  β^=β⋅σD2σD2+σu2\text{plim}\;\hat{\beta} = \beta \cdot \frac{\sigma_D^2}{\sigma_D^2 + \sigma_u^2}plimβ^​=β⋅σD2​+σu2​σD2​​
其中 σu2\sigma_u^2σu2​ 是测量误差的方差。


内部有效性与外部有效性
研究设计需要同时关注两个维度的有效性。


内部有效性 指因果估计在研究样本内是否可信。威胁包括：混淆因素、逆向因果、样本选择、溢出效应等。一个设计精良的 RDD 通常具有很高的内部有效性——阈值附近的随机化是"局部"的但"可信"的。


外部有效性 指研究结论能否推广到其他情境。即使内部有效性无懈可击，研究结论也可能因样本特殊性而难以推广。LATE（Local Average Treatment Effect）就是一个典型案例——IV 估计的是 complier 子群的效应，而非全体。


预分析计划（Pre-Analysis Plan）
预分析计划是应对"可信度革命"中 p-hacking 和选择性报告问题的制度创新。研究者在数据收集前注册研究设计，明确：


    

  • 主要假设和次要假设：区分确认性分析和探索性分析
    • 

  • 主要结果变量和协变量：防止事后选择显著的规格
    • 

  • 样本量计算（Power Analysis）：最小可检测效应量 MDE=(tα+tβ)σ2n⋅p(1−p)\text{MDE} = (t_\alpha + t_\beta) \sqrt{\frac{\sigma^2}{n \cdot p(1-p)}}MDE=(tα​+tβ​)n⋅p(1−p)σ2​​
    • 

  • 多重假设检验的调整方法：Bonferroni、Holm、False Discovery Rate
    • 

  • 异质性分析的预设子组：防止数据挖掘
    • 



主要注册平台包括 AEA RCT Registry、EGAP、OSF。越来越多的顶级期刊（如 AER、QJE）在审稿中会参考预分析计划的一致性。

小结
实证研究设计的本质是在给定数据和制度约束下，寻找最可信的方式来构造反事实。反事实框架提供了统一的思考语言——无论选择何种识别策略，最终都可以用潜在结果的语言来陈述假设和评估偏误。选择偏误不是一个可以一劳永逸解决的问题，而是需要在每个具体研究情境中被识别、论证和缓解的持续挑战。预分析计划作为制度工具，将研究者的主观自由度约束在合理范围内，是实证经济学向更高可信度标准演进的重要标志。
