数据处理与稳健性检验

知识要点

再精巧的识别策略，如果建立在有缺陷的数据处理之上，得到的也只是精确的错误答案。数据处理与稳健性检验是实证经济学中最容易被低估的环节——教科书花大量篇幅讨论估计量的渐近性质，却很少系统讲解如何从原始数据到回归样本之间做出一系列影响结论的决策。这些"数据清洗"决策的透明度和合理性，直接决定了研究的可重复性和可信度。

详细讲解

数据清洗的标准流程

实证研究的数据清洗不是简单的"去除异常值"，而是一个需要文档化的决策链条：

每一步都应该在代码中留下清晰的记录。一个好的实践是维护一个"数据日志"（data log），记录每步操作删除或修改了多少观测值，以及这些操作的理由。


变量定义的一致性问题：同一个概念在不同数据源中可能有不同的测量方式。例如，"失业率"在劳动力调查和行政登记中的定义就不同。在合并多个数据集时，变量定义的不一致是最常见的隐性错误来源。

聚类标准误
在面板数据和分组数据中，同一聚类（cluster）内的观测往往不独立。忽略这一点会导致标准误被严重低估。


聚类标准误的直觉：假设一个城市内所有个体都受到相同的政策冲击，那么有效样本量不是个体数 NNN，而是接近于城市数 GGG。当 GGG 较小时（例如 G<50G < 50G<50），聚类标准误本身也不可靠。


Cameron, Gelbach & Miller (2008) 给出的建议是：


    

  • 在最高可能的层级聚类（"cluster at the level of treatment assignment"）
    • 

  • 当 GGG 较小时使用 Wild Cluster Bootstrap
    • 



Wild Cluster Bootstrap 的核心思想：


    

  1. 在约束模型（H0H_0H0​）下估计残差 e^i\hat{e}_ie^i​
    2. 

  2. 对每个聚类随机分配 +1+1+1 或 −1-1−1（Rademacher 权重），生成伪残差
    3. 

  3. 构造伪样本并重新估计统计量
    4. 

  4. 重复 BBB 次（通常 B≥999B \geq 999B≥999），构造 bootstrap 分布
    5. 

  5. 计算 bootstrap p-value

稳健性检验与敏感性分析
稳健性检验的目标是展示主要结论不依赖于任何单一的数据处理或模型选择决策。


Oster (2019) bounds：量化遗漏变量偏误的潜在影响。假设 Rmax⁡2R^2_{\max}Rmax2​ 是包含所有遗漏变量后的 R2R^2R2，δ\deltaδ 是可观测变量和不可观测变量解释力的比例参数。偏误调整后的估计量为：


β∗=β~−δ⋅[β˙−β~]⋅Rmax⁡−R~2R~2−R˙2\beta^* = \tilde{\beta} - \delta \cdot [\dot{\beta} - \tilde{\beta}] \cdot \frac{R_{\max} - \tilde{R}^2}{\tilde{R}^2 - \dot{R}^2}β∗=β~​−δ⋅[β˙​−β~​]⋅R~2−R˙2Rmax​−R~2​
如果在 δ=1\delta = 1δ=1（等比例选择）和合理的 Rmax⁡2R^2_{\max}Rmax2​ 下 β∗\beta^*β∗ 的符号不变，则结论具有一定的稳健性。


安慰剂检验：在不应该存在效应的样本或时期中运行相同的分析。如果安慰剂检验显著，说明研究设计可能存在问题。DID 中的经典做法是检验处理前的"伪处理效应"。

小结
数据处理与稳健性检验不是实证研究的"苦差事"，而是决定研究可信度的核心环节。缺失数据的处理需要先诊断缺失机制，再选择对应策略——完整案例分析、多重插补和逆概率加权各有适用场景。异常值的处理应以经济学逻辑为先导，统计方法为辅助，所有决策必须透明并接受稳健性检验的考验。聚类标准误的选择直接影响统计推断的有效性——在小样本聚类环境下，Wild Cluster Bootstrap 是目前最可靠的替代方案。最终，稳健性检验的目的不是让审稿人"满意"，而是让研究者自己确信——核心结论经得起合理的替代假设的挑战。
