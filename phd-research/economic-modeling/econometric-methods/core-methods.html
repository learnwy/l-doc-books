面板数据、时间序列与准实验方法

知识要点

现代实证经济学研究越来越多地利用面板数据的纵向结构和准实验设计来识别因果效应。面板数据模型通过控制不可观测的个体异质性，显著改善了横截面回归中遗漏变量偏误的问题。时间序列计量经济学则为分析宏观经济变量的动态关系提供了专门工具。双重差分法（DID）和断点回归设计（RDD）作为两大核心准实验方法，在政策评估领域已成为因果推断的黄金标准。

详细讲解

面板数据模型

面板数据同时包含个体维度 i=1,…,Ni = 1, \ldots, Ni=1,…,N 和时间维度 t=1,…,Tt = 1, \ldots, Tt=1,…,T。基本模型为：

yit=Xit′β+αi+εity_{it} = X_{it}'\beta + \alpha_i + \varepsilon_{it}yit​=Xit′​β+αi​+εit​

其中 αi\alpha_iαi​ 是不可观测的个体固定效应，εit\varepsilon_{it}εit​ 是特质误差项。面板数据的关键优势在于可以控制时间不变的不可观测异质性 αi\alpha_iαi​。

固定效应模型（FE） 通过组内变换（within transformation）消除 αi\alpha_iαi​：

y~it=X~it′β+ε~it\tilde{y}_{it} = \tilde{X}_{it}'\beta + \tilde{\varepsilon}_{it}y~​it​=X~it′​β+ε~it​

其中 y~it=yit−yˉi\tilde{y}_{it} = y_{it} - \bar{y}_iy~​it​=yit​−yˉ​i​，yˉi=T−1∑t=1Tyit\bar{y}_i = T^{-1}\sum_{t=1}^T y_{it}yˉ​i​=T−1∑t=1T​yit​。FE估计量为：

β^FE=(∑i=1N∑t=1TX~itX~it′)−1(∑i=1N∑t=1TX~ity~it)\hat{\beta}_{FE} = \left(\sum_{i=1}^N \sum_{t=1}^T \tilde{X}_{it}\tilde{X}_{it}'\right)^{-1} \left(\sum_{i=1}^N \sum_{t=1}^T \tilde{X}_{it}\tilde{y}_{it}\right)β^​FE​=(i=1∑N​t=1∑T​X~it​X~it′​)−1(i=1∑N​t=1∑T​X~it​y~​it​)

FE允许 Cov(αi,Xit)≠0\text{Cov}(\alpha_i, X_{it}) \neq 0Cov(αi​,Xit​)=0，但代价是无法估计时间不变变量（如性别、出生地）的系数。

随机效应模型（RE） 假设 Cov(αi,Xit)=0\text{Cov}(\alpha_i, X_{it}) = 0Cov(αi​,Xit​)=0，通过广义最小二乘法（GLS）提高效率。RE估计量使用准去均值变换：

yit−θ^yˉi=(Xit−θ^Xˉi)′β+(1−θ^)αi+(εit−θ^εˉi)y_{it} - \hat{\theta}\bar{y}_i = (X_{it} - \hat{\theta}\bar{X}_i)'\beta + (1-\hat{\theta})\alpha_i + (\varepsilon_{it} - \hat{\theta}\bar{\varepsilon}_i)yit​−θ^yˉ​i​=(Xit​−θ^Xˉi​)′β+(1−θ^)αi​+(εit​−θ^εˉi​)

其中 θ^=1−σε2/(Tσα2+σε2)\hat{\theta} = 1 - \sqrt{\sigma_\varepsilon^2 / (T\sigma_\alpha^2 + \sigma_\varepsilon^2)}θ^=1−σε2​/(Tσα2​+σε2​)​。

Hausman检验 用于在FE和RE之间做出选择。原假设 H0H_0H0​：Cov(αi,Xit)=0\text{Cov}(\alpha_i, X_{it}) = 0Cov(αi​,Xit​)=0（RE一致），检验统计量为：

H=(β^FE−β^RE)′[Var^(β^FE)−Var^(β^RE)]−1(β^FE−β^RE)→dχ2(k)H = (\hat{\beta}_{FE} - \hat{\beta}_{RE})'[\widehat{\text{Var}}(\hat{\beta}_{FE}) - \widehat{\text{Var}}(\hat{\beta}_{RE})]^{-1}(\hat{\beta}_{FE} - \hat{\beta}_{RE}) \xrightarrow{d} \chi^2(k)H=(β^​FE​−β^​RE​)′[Var(β^​FE​)−Var(β^​RE​)]−1(β^​FE​−β^​RE​)d​χ2(k)
时间序列基础
时间序列分析的核心概念是平稳性。一个时间序列 {yt}\{y_t\}{yt​} 是协方差平稳的，当且仅当：


E[yt]=μ,Cov(yt,yt−j)=γj∀tE[y_t] = \mu, \quad \text{Cov}(y_t, y_{t-j}) = \gamma_j \quad \forall tE[yt​]=μ,Cov(yt​,yt−j​)=γj​∀t
单位根检验：Augmented Dickey-Fuller（ADF）检验的回归方程为：


Δyt=α+ρyt−1+∑j=1pϕjΔyt−j+ut\Delta y_t = \alpha + \rho y_{t-1} + \sum_{j=1}^p \phi_j \Delta y_{t-j} + u_tΔyt​=α+ρyt−1​+j=1∑p​ϕj​Δyt−j​+ut​
原假设 H0:ρ=0H_0: \rho = 0H0​:ρ=0（存在单位根）。ADF统计量在原假设下不服从标准正态分布，需要使用Dickey-Fuller分布的临界值。


协整与误差修正模型：当两个 I(1)I(1)I(1) 序列 yty_tyt​ 和 xtx_txt​ 存在线性组合 yt−βxt∼I(0)y_t - \beta x_t \sim I(0)yt​−βxt​∼I(0) 时，称二者协整。Engle-Granger两步法和Johansen极大似然法是检验协整关系的标准方法。协整关系意味着存在误差修正模型（ECM）：


Δyt=α(yt−1−βxt−1⏟误差修正项)+γΔxt+ut\Delta y_t = \alpha(\underbrace{y_{t-1} - \beta x_{t-1}}_{\text{误差修正项}}) + \gamma \Delta x_t + u_tΔyt​=α(误差修正项yt−1​−βxt−1​​​)+γΔxt​+ut​
参数 α<0\alpha < 0α<0 表示系统向长期均衡调整的速度。


双重差分法（DID）
DID利用政策冲击的时间和群组变异来识别因果效应。基本设定为：


yit=β0+β1⋅Treati+β2⋅Postt+β3⋅Treati×Postt+εity_{it} = \beta_0 + \beta_1 \cdot \text{Treat}_i + \beta_2 \cdot \text{Post}_t + \beta_3 \cdot \text{Treat}_i \times \text{Post}_t + \varepsilon_{it}yit​=β0​+β1​⋅Treati​+β2​⋅Postt​+β3​⋅Treati​×Postt​+εit​
其中 β3\beta_3β3​ 是政策处理效应的DID估计量：


β^3=(yˉ1,post−yˉ1,pre)−(yˉ0,post−yˉ0,pre)\hat{\beta}_3 = (\bar{y}_{1,\text{post}} - \bar{y}_{1,\text{pre}}) - (\bar{y}_{0,\text{post}} - \bar{y}_{0,\text{pre}})β^​3​=(yˉ​1,post​−yˉ​1,pre​)−(yˉ​0,post​−yˉ​0,pre​)
DID的核心识别假设是平行趋势假设（Parallel Trends）：在没有政策干预的情况下，处理组和控制组的结果变量会遵循相同的时间趋势。


事件研究法（Event Study） 是检验平行趋势假设和展示动态处理效应的标准工具：


yit=αi+λt+∑k≠−1γk⋅Ditk+εity_{it} = \alpha_i + \lambda_t + \sum_{k \neq -1} \gamma_k \cdot D_{it}^k + \varepsilon_{it}yit​=αi​+λt​+k=−1∑​γk​⋅Ditk​+εit​
其中 DitkD_{it}^kDitk​ 是事件时间虚拟变量，k<0k < 0k<0 的系数 γk\gamma_kγk​ 用于检验平行趋势，k≥0k \geq 0k≥0 的系数刻画动态处理效应。


交错DID与最新进展：当不同群组在不同时间接受处理时，传统双向固定效应（TWFE）估计量可能产生偏误。Callaway和Sant'Anna（2021）、Sun和Abraham（2021）、de Chaisemartin和D'Haultfœuille（2020）等提出了一系列修正方法，是当前DID文献的前沿议题。


断点回归设计（RDD）
RDD利用处理分配规则在某个临界值处的不连续性来识别局部因果效应。设 RiR_iRi​ 为驱动变量（running variable），ccc 为临界值，处理状态为：


Di=1(Ri≥c)D_i = \mathbb{1}(R_i \geq c)Di​=1(Ri​≥c)
Sharp RDD 的基本思想是比较临界值两侧个体的结果差异：


τSRD=lim⁡r↓cE[yi∣Ri=r]−lim⁡r↑cE[yi∣Ri=r]\tau_{SRD} = \lim_{r \downarrow c} E[y_i | R_i = r] - \lim_{r \uparrow c} E[y_i | R_i = r]τSRD​=r↓clim​E[yi​∣Ri​=r]−r↑clim​E[yi​∣Ri​=r]
实际估计中，通常使用局部线性回归在临界值附近拟合：


yi=α+τDi+β1(Ri−c)+β2Di(Ri−c)+εi,∣Ri−c∣≤hy_i = \alpha + \tau D_i + \beta_1(R_i - c) + \beta_2 D_i(R_i - c) + \varepsilon_i, \quad |R_i - c| \leq hyi​=α+τDi​+β1​(Ri​−c)+β2​Di​(Ri​−c)+εi​,∣Ri​−c∣≤h
其中 hhh 是带宽。Imbens和Kalyanaraman（2012）以及Calonico、Cattaneo和Titiunik（2014）提出了最优带宽选择和稳健推断方法。


Fuzzy RDD 适用于处理概率（而非处理状态本身）在临界值处发生跳跃的情形，估计量变为：


τFRD=lim⁡r↓cE[yi∣Ri=r]−lim⁡r↑cE[yi∣Ri=r]lim⁡r↓cE[Di∣Ri=r]−lim⁡r↑cE[Di∣Ri=r]\tau_{FRD} = \frac{\lim_{r \downarrow c} E[y_i | R_i = r] - \lim_{r \uparrow c} E[y_i | R_i = r]}{\lim_{r \downarrow c} E[D_i | R_i = r] - \lim_{r \uparrow c} E[D_i | R_i = r]}τFRD​=limr↓c​E[Di​∣Ri​=r]−limr↑c​E[Di​∣Ri​=r]limr↓c​E[yi​∣Ri​=r]−limr↑c​E[yi​∣Ri​=r]​
这本质上是在临界值处的Wald估计量，可以解释为遵从者（compliers）的局部平均处理效应（LATE）。

小结
本节拓展了基础计量方法到更丰富的数据结构和研究设计。面板数据模型通过固定效应控制不可观测异质性，时间序列方法处理宏观数据的动态特征，DID和RDD则提供了在观测数据中进行因果推断的准实验框架。选择合适的方法取决于数据结构和可用的识别变异来源——面板结构支持固定效应，政策时间变异支持DID，规则不连续性支持RDD。下一节将通过经典案例展示这些方法的实战应用。
