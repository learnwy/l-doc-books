宏观政策模拟案例

知识要点

结构模型最独特的应用价值在于回答反事实问题：如果政策改变，经济将如何反应？这类问题无法通过简约式回归回答，因为Lucas批判告诉我们，当政策规则改变时，经济主体的行为方程也会相应调整。本节通过三个政策模拟案例——货币政策规则评估、财政刺激乘数分析和贸易政策的一般均衡效应——展示DSGE和CGE模型如何从理论工具转化为政策分析的实用框架。

详细讲解

案例一：货币政策规则评估

政策问题：面对通胀冲击，央行应该采取激进的紧缩策略还是渐进的调整策略？不同的Taylor规则参数如何影响宏观经济波动？

模型设定：使用标准三方程新凯恩斯模型（IS曲线 + NKPC + Taylor规则），比较三种货币政策规则：

规则 ϕπ\phi_\piϕπ​ ϕy\phi_yϕy​ ρR\rho_RρR​ 特征
基准Taylor规则 1.5 0.5 0.0 标准反应
激进反通胀 3.0 0.5 0.0 对通胀强反应
利率平滑 1.5 0.5 0.8 渐进调整

含利率平滑的Taylor规则为：

R^t=ρRR^t−1+(1−ρR)[ϕππt+ϕyy^t]+vt\hat{R}_t = \rho_R \hat{R}_{t-1} + (1-\rho_R)[\phi_\pi \pi_t + \phi_y \hat{y}_t] + v_tR^t​=ρR​R^t−1​+(1−ρR​)[ϕπ​πt​+ϕy​y^​t​]+vt​

脉冲响应分析：对1%的正向成本推动冲击（cost-push shock），三种规则产生不同的宏观反应路径。

设成本推动冲击进入菲利普斯曲线：πt=βEt[πt+1]+κy^t+et\pi_t = \beta E_t[\pi_{t+1}] + \kappa \hat{y}_t + e_tπt​=βEt​[πt+1​]+κy^​t​+et​，其中 et=ρeet−1+ηte_t = \rho_e e_{t-1} + \eta_tet​=ρe​et−1​+ηt​，ρe=0.5\rho_e = 0.5ρe​=0.5。

激进反通胀规则下，利率上调幅度更大，产出下降更多但通胀回落更快。利率平滑规则下，利率调整更缓慢，通胀持续时间更长但产出波动更小。这体现了宏观经济学中经典的产出-通胀权衡。

福利分析：使用二次损失函数衡量不同规则的表现：


L=Var(πt)+λVar(y^t)+νVar(ΔR^t)\mathcal{L} = \text{Var}(\pi_t) + \lambda \text{Var}(\hat{y}_t) + \nu \text{Var}(\Delta \hat{R}_t)L=Var(πt​)+λVar(y^​t​)+νVar(ΔR^t​)
其中 λ\lambdaλ 是产出稳定权重，ν\nuν 是利率平滑权重。Woodford（2003）证明，在新凯恩斯框架下，该损失函数可以近似为代表性家庭效用损失的二阶近似。


最优货币政策：求解Ramsey问题——在模型约束下最小化福利损失。最优承诺（commitment）政策和最优相机抉择（discretion）政策之间的差异反映了货币政策的时间一致性问题。在承诺均衡下：


πt=−κλ(y^t−y^t−1)\pi_t = -\frac{\kappa}{\lambda}(\hat{y}_t - \hat{y}_{t-1})πt​=−λκ​(y^​t​−y^​t−1​)
通胀对产出缺口的变化而非水平做出反应——这是"历史依赖性"的体现，也是承诺政策优于相机抉择政策的关键。


案例二：财政刺激乘数分析
政策问题：在经济衰退期间，一单位政府支出增加能够带来多大的GDP增长？财政乘数在不同经济状态下如何变化？


模型框架：在基准新凯恩斯DSGE中加入政府部门。资源约束变为：


Yt=Ct+It+GtY_t = C_t + I_t + G_tYt​=Ct​+It​+Gt​
政府支出遵循AR(1)过程：g^t=ρgg^t−1+εtg\hat{g}_t = \rho_g \hat{g}_{t-1} + \varepsilon_t^gg^​t​=ρg​g^​t−1​+εtg​


财政乘数的定义：


影响乘数=dY0dG0\text{影响乘数} = \frac{dY_0}{dG_0}影响乘数=dG0​dY0​​
累积乘数(h)=∑t=0hΔYt/(1+r)t∑t=0hΔGt/(1+r)t\text{累积乘数}(h) = \frac{\sum_{t=0}^h \Delta Y_t / (1+r)^t}{\sum_{t=0}^h \Delta G_t / (1+r)^t}累积乘数(h)=∑t=0h​ΔGt​/(1+r)t∑t=0h​ΔYt​/(1+r)t​

零利率下界下的财政乘数：当名义利率触及零利率下界时，Taylor规则失效（Rt=max⁡{0,r∗+ϕππt+ϕyy^t}R_t = \max\{0, r^* + \phi_\pi \pi_t + \phi_y \hat{y}_t\}Rt​=max{0,r∗+ϕπ​πt​+ϕy​y^​t​}）。此时财政乘数可以远超1，甚至达到2-3。直觉在于：政府支出增加导致预期通胀上升，在名义利率固定为零的情况下，实际利率 rt=Rt−Et[πt+1]r_t = R_t - E_t[\pi_{t+1}]rt​=Rt​−Et​[πt+1​] 下降，进一步刺激私人消费和投资——形成正反馈循环。


Christiano、Eichenbaum和Rebelo（2011）系统分析了ZLB下的财政乘数。他们发现，在ZLB约束期越长，乘数越大。当ZLB约束持续8个季度时，影响乘数约为1.6；持续12个季度时可达2.3。


案例三：贸易政策的CGE分析
政策问题：提高关税对国内不同产业的产出、就业和福利有何影响？


模型设定：使用一个三部门（农业A、制造业M、服务业S）开放经济CGE模型。每个部门的生产函数为嵌套CES：


Yj=Aj[δjVAVAj(σj−1)/σj+(1−δjVA)INTj(σj−1)/σj]σj/(σj−1)Y_j = A_j \left[\delta_j^{VA} VA_j^{(\sigma_j-1)/\sigma_j} + (1-\delta_j^{VA}) INT_j^{(\sigma_j-1)/\sigma_j}\right]^{\sigma_j/(\sigma_j-1)}Yj​=Aj​[δjVA​VAj(σj​−1)/σj​​+(1−δjVA​)INTj(σj​−1)/σj​​]σj​/(σj​−1)
增加值 VAjVA_jVAj​ 由劳动和资本的CES复合构成，中间投入 INTjINT_jINTj​ 由各部门产品的Leontief复合构成。


贸易用Armington复合表示：


Qj=[δjDDj(σjM−1)/σjM+(1−δjD)Mj(σjM−1)/σjM]σjM/(σjM−1)Q_j = \left[\delta_j^D D_j^{(\sigma_j^M-1)/\sigma_j^M} + (1-\delta_j^D) M_j^{(\sigma_j^M-1)/\sigma_j^M}\right]^{\sigma_j^M/(\sigma_j^M-1)}Qj​=[δjD​Dj(σjM​−1)/σjM​​+(1−δjD​)Mj(σjM​−1)/σjM​​]σjM​/(σjM​−1)

福利分析：使用等价变异（Equivalent Variation）度量福利变化：

敏感性分析：CGE结果对关键弹性参数高度敏感。Armington替代弹性 σM\sigma^MσM 的取值直接影响贸易转移的幅度——弹性越高，进口替代越容易，国内产出扩张越大。进行系统的敏感性分析（systematic sensitivity analysis）是CGE研究的必要步骤。

小结
本节通过三个政策模拟案例展示了结构模型的核心应用价值。货币政策规则评估展示了DSGE模型如何比较不同政策规则的宏观经济后果并求解最优政策；财政乘数分析揭示了经济状态（特别是零利率下界）如何显著改变财政政策的效力；贸易政策的CGE分析展示了关税如何通过一般均衡机制在不同部门间传导。结构模型的独特优势在于回答"如果政策改变，经济会怎样"的反事实问题——这正是简约式方法难以企及的领域。
