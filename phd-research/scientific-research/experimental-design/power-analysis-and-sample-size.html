统计功效分析与样本量计算

知识要点

统计功效（statistical power）是一个实验在真实效应存在时正确拒绝零假设的概率。功效分析将四个相互关联的参数——效应量（effect size）、显著性水平（α\alphaα）、样本量（nnn）和统计功效（1−β1 - \beta1−β）——纳入一个统一框架，使研究者能够在实验开始之前回答"我需要多大的样本才能以足够的信心检测到感兴趣的效应？"这一关键的设计决策问题。

核心概念包括：

  • 效应量（Effect Size）：处理效应的标准化度量，独立于样本量。常用指标包括 Cohen's ddd（两组均值差除以合并标准差）、Pearson's rrr（相关系数）、η2\eta^2η2（方差分析中的效应量）和 odds ratio（比值比）
  • 第一类错误（α\alphaα）与第二类错误（β\betaβ）：α\alphaα 是零假设为真时错误拒绝的概率（假阳性率），β\betaβ 是备择假设为真时未能拒绝零假设的概率（假阴性率）。统计功效 =1−β= 1 - \beta=1−β
  • 最小可检测效应量（MDES）：给定 α\alphaα、nnn 和 1−β1-\beta1−β，实验能够检测到的最小效应量。MDES 比样本量更直观地描述了实验的"灵敏度"
  • 先验功效分析 vs. 后验功效分析：先验（a priori）功效分析在实验前确定所需样本量——这是标准实践；后验（post hoc）功效分析在实验后计算已达到的功效——统计学家普遍认为后验功效分析没有意义（它本质上是 p 值的单调变换）
详细讲解
功效分析的数学基础
以最简单的场景为例：比较两个独立组均值的双侧 ttt 检验。零假设 H0:μ1=μ2H_0: \mu_1 = \mu_2H0​:μ1​=μ2​，备择假设 H1:μ1≠μ2H_1: \mu_1 \neq \mu_2H1​:μ1​=μ2​。


在零假设下，检验统计量 ttt 服从自由度为 n1+n2−2n_1 + n_2 - 2n1​+n2​−2 的 ttt 分布。在备择假设下，ttt 服从非中心 ttt 分布，非中心参数为：


λ=d⋅n1⋅n2n1+n2\lambda = d \cdot \sqrt{\frac{n_1 \cdot n_2}{n_1 + n_2}}λ=d⋅n1​+n2​n1​⋅n2​​​
其中 d=(μ1−μ2)/σd = (\mu_1 - \mu_2) / \sigmad=(μ1​−μ2​)/σ 是 Cohen's ddd。


统计功效就是非中心 ttt 分布超过临界值的概率：


1−β=P(∣Tλ∣>tα/2,df)1 - \beta = P(|T_\lambda| > t_{\alpha/2, df})1−β=P(∣Tλ​∣>tα/2,df​)
这个方程包含四个参数（ddd、α\alphaα、nnn、1−β1-\beta1−β），给定其中三个可以求解第四个。先验功效分析给定 ddd、α\alphaα 和 1−β1-\beta1−β，求解所需的 nnn。

这些基准是便利的参考，但不应机械套用。更好的做法是：


    

  1. 基于先前研究：查阅同领域已发表研究中类似效应的大小。注意发表偏倚可能导致文献中的效应量被高估（显著结果更容易发表）
    2. 

  2. 基于实际意义：确定在你的研究领域中，多大的效应才具有实际重要性。临床研究中的"最小临床重要差异"（MCID）是一个好例子
    3. 

  3. 基于资源约束：计算给定资源（时间、预算、可用受试者）下能够检测到的最小效应量（MDES），然后判断这个灵敏度对你的研究问题是否足够
    4. 



样本量计算的实用公式
独立样本 ttt 检验（两组等样本量）：


n=2(zα/2+zβ)2d2n = \frac{2(z_{\alpha/2} + z_\beta)^2}{d^2}n=d22(zα/2​+zβ​)2​
其中 zα/2z_{\alpha/2}zα/2​ 和 zβz_\betazβ​ 分别是标准正态分布的临界值。对于 α=0.05\alpha = 0.05α=0.05（z0.025=1.96z_{0.025} = 1.96z0.025​=1.96）和 1−β=0.801 - \beta = 0.801−β=0.80（z0.20=0.84z_{0.20} = 0.84z0.20​=0.84）：


n≈2×(1.96+0.84)2d2=15.68d2n \approx \frac{2 \times (1.96 + 0.84)^2}{d^2} = \frac{15.68}{d^2}n≈d22×(1.96+0.84)2​=d215.68​
代入 d=0.5d = 0.5d=0.5：n≈63n \approx 63n≈63（每组 63 人，总共 126 人）。代入 d=0.3d = 0.3d=0.3：n≈175n \approx 175n≈175（每组）——效应量减小 40% 导致样本量增加近 3 倍。


配对样本 ttt 检验：


n=(zα/2+zβ)2d2n = \frac{(z_{\alpha/2} + z_\beta)^2}{d^2}n=d2(zα/2​+zβ​)2​
配对设计消除了个体间变异，所需样本量约为独立设计的一半。


卡方检验和比例比较、ANOVA 和回归分析的样本量公式更复杂，通常使用 G*Power 等软件计算。


功效分析的实践工作流
一个规范的先验功效分析包括以下步骤：


    

  1. 明确统计检验类型：ttt 检验、ANOVA、回归、卡方、生存分析——不同检验有不同的功效函数
    2. 

  2. 确定效应量：基于先前研究的元分析估计、理论预期或最小实际重要差异
    3. 

  3. 设定 α\alphaα 和 1−β1-\beta1−β：惯例为 α=0.05\alpha = 0.05α=0.05 和 1−β=0.801-\beta = 0.801−β=0.80，但应根据错误后果的严重性调整——如果假阳性的后果很严重（如批准无效药物），降低 α\alphaα；如果假阴性的后果很严重（如错过有效治疗），提高功效
    4. 

  4. 计算样本量：使用公式或软件
    5. 

  5. 灵敏度分析：在不同效应量假设下重复计算，报告一个样本量范围而非单一值
    6. 

  6. 调整因素：考虑流失率（attrition）、不依从（non-compliance）和多重比较校正对有效样本量的影响——通常在计算基础上增加 10-20%
    7. 



功效分析中的常见错误
错误一：使用后验功效分析辩护阴性结果。 实验完成后发现 p>0.05p > 0.05p>0.05，然后计算"观察到的功效"只有 30%30\%30%，于是声称"样本量不够，不能否定备择假设"。这是循环论证——观察到的功效是 p 值的单调函数，不提供任何额外信息。正确的做法是报告效应量的置信区间。


错误二：效应量的估计过于乐观。 研究者倾向于使用先前研究中最大的效应量估计来降低所需样本量——但先前研究的效应量可能因发表偏倚而被高估。建议使用效应量估计的下界或元分析中的保守估计。


错误三：忽略多重比较。 如果实验包含 5 个比较，每个比较的 α=0.05\alpha = 0.05α=0.05，家族错误率（familywise error rate）上升到约 0.230.230.23。功效分析应基于校正后的 α\alphaα（如 Bonferroni 校正 α′=0.01\alpha' = 0.01α′=0.01），这会显著增加所需样本量。


错误四：混淆统计显著性与实际重要性。 一个超大样本可以使微小的效应达到统计显著性——但 d=0.05d = 0.05d=0.05 的效应即使 p<0.001p < 0.001p<0.001 也可能没有实际意义。功效分析应始终围绕"值得检测的最小效应量"而非"能达到显著的最小效应量"。


贝叶斯替代方案
频率主义功效分析的一个根本局限是它依赖于固定的效应量假设——但在实验前，我们对效应量的信念通常是不确定的。贝叶斯方法允许将效应量建模为先验分布而非点估计。


**分析先验功效（Assurance / Bayesian Power）**计算的是"在效应量服从先验分布的条件下，实验达到预定结论的概率"——它整合了效应量的不确定性，通常比频率主义功效分析给出更大的样本量建议。


贝叶斯自适应设计使用后验概率而非 p 值作为决策标准——当处理效应的后验概率超过预设阈值（如 P(效应>0∣数据)>0.975P(\text{效应} > 0 | \text{数据}) > 0.975P(效应>0∣数据)>0.975）时宣布成功。这避免了频率主义中期分析的多重检验问题。


练习与思考
    

  1. 使用 G*Power 或 R 的 pwr 包计算以下场景的样本量：双侧独立样本 ttt 检验，d=0.4d = 0.4d=0.4，α=0.05\alpha = 0.05α=0.05，1−β=0.901-\beta = 0.901−β=0.90。然后将功效降至 0.800.800.80，样本量减少多少？将 α\alphaα 收紧至 0.010.010.01，样本量增加多少？
    2. 

  2. 一项元分析报告某干预的平均效应量为 d=0.6d = 0.6d=0.6，95%95\%95% 置信区间为 [0.3,0.9][0.3, 0.9][0.3,0.9]。你会使用哪个值作为功效分析的输入？为什么？使用上下界分别计算样本量，比较差异。
    3. 

  3. 批评以下做法：一位研究者完成实验后发现 p=0.12p = 0.12p=0.12，随后进行后验功效分析得到功效为 0.450.450.45，并在论文中写道"本研究功效不足，需要更大样本的后续研究"。这一推理的逻辑问题在哪里？应该如何正确报告？
    4. 

  4. 思考"样本量膨胀"的社会后果：如果所有研究都追求 1−β=0.951-\beta = 0.951−β=0.95 和 d=0.2d = 0.2d=0.2（小效应），临床试验的样本量将达到数千人。从资源分配和伦理角度，你认为应如何在功效和效率之间取得平衡？
    5.

小结
功效分析是实验设计中最重要的定量决策工具——它将"样本量选择"从随意猜测提升为有原则的推理。掌握功效分析，需要理解效应量、显著性水平、样本量和统计功效之间的数学关系，更需要理解这些参数选择背后的实质性判断——什么样的效应值得检测？什么样的错误后果更严重？功效分析不是机械计算，而是将统计推理与研究判断整合的决策过程。
