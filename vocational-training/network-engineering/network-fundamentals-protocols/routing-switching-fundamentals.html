          路由交换基础技术

          知识要点

          路由和交换是构建所有企业网络的两大基石技术——交换机负责局域网内部的高速帧转发，路由器负责不同网络之间的IP分组选路。掌握VLAN、STP、静态路由、OSPF和ACL这五项核心技术，便能独立完成中小型企业网络的规划配置与故障排查。

          VLAN与Trunk技术

          VLAN（虚拟局域网）通过逻辑划分将一台物理交换机分割为多个独立的广播域，实现部门隔离和广播风暴抑制。

          VLAN工作原理：
          

            

          • Access端口：连接终端设备，收到无标签帧时打上PVID标签，发出时剥离标签
            • 

          • Trunk端口：连接交换机之间，承载多VLAN流量，使用802.1Q协议在帧中插入4字节标签字段（TPID + Priority + CFI + VLAN ID）
            • 

          • VLAN ID范围：0-4095，其中1为默认VLAN，2-1001为标准范围，1006-4094为扩展范围
            • 

          

          802.1Q标签结构中VLAN ID字段为12位，因此理论最大VLAN数量为：
          

          Nmax=212=4096N_{max} = 2^{12} = 4096Nmax​=212=4096
          实际可用范围去除保留值后约为4094个。
          

          STP生成树协议
          当交换网络存在冗余链路时，会形成二层环路导致广播风暴。STP（Spanning Tree Protocol, IEEE 802.1D）通过选举和阻塞机制消除环路：
          

          STP选举过程：
          

            

          1. 选举根桥（Root Bridge）：Bridge ID最小的交换机（优先级 + MAC地址）
            2. 

          2. 选举根端口（Root Port）：非根桥上到根桥路径开销最小的端口
            3. 

          3. 选举指定端口（Designated Port）：每个网段上到根桥开销最小的端口
            4. 

          4. 阻塞非指定端口（Blocked Port）：其余端口进入阻塞状态
            5.

          RSTP（802.1w）将收敛时间从30-50秒缩短到1-2秒，MSTP（802.1s）支持按VLAN组实例化生成树，实现负载均衡。
          

          静态路由与默认路由
          静态路由由管理员手动配置，适用于拓扑简单或需要精确控制流量路径的场景。
          

          路由表匹配遵循最长前缀匹配原则。对于目标地址 192.168.10.5，路由表中存在：
          

            

          • 192.168.10.0/24 → 下一跳A
            • 

          • 192.168.10.0/28 → 下一跳B
            • 

          

          由于 /28 掩码更长（匹配更精确），流量将转发至下一跳B。
          

          默认路由 0.0.0.0/0 匹配所有目标地址，作为"最后的出口"使用，通常配置在企业出口路由器指向ISP网关。
          

          子网划分计算示例：将 172.16.0.0/16 划分为256个子网，每个子网需要的额外位数为：
          

          n=⌈log⁡2(256)⌉=8 位n = \lceil \log_2(256) \rceil = 8 \text{ 位}n=⌈log2​(256)⌉=8 位
          新子网掩码为 /16+8=/24/16 + 8 = /24/16+8=/24，每个子网可用主机数为 28−2=2542^{8} - 2 = 25428−2=254 台。
          

          OSPF动态路由协议
          OSPF（Open Shortest Path First）是企业网络最主流的内部网关协议（IGP），基于链路状态算法（Dijkstra SPF）计算最优路径。
          

          OSPF核心概念：
          

            

          • 区域（Area）：将大型网络分割为多个区域减少LSA泛洪范围，Area 0为骨干区域
            • 

          • Router ID：唯一标识OSPF路由器，通常为最大Loopback接口IP
            • 

          • 邻居建立：Hello包（默认10秒间隔）发现邻居 → 双向邻接 → 数据库同步（DBD/LSR/LSU）→ Full状态
            • 

          • 开销计算：Cost=108Bandwidth(bps)Cost = \frac{10^8}{Bandwidth(bps)}Cost=Bandwidth(bps)108​（参考带宽可修改）
            • 

          

          对于1Gbps链路：Cost=108109=0.1Cost = \frac{10^8}{10^9} = 0.1Cost=109108​=0.1，取整为1。
          

          OSPF使用五种报文类型：Hello、DBD（数据库描述）、LSR（链路状态请求）、LSU（链路状态更新）、LSAck（链路状态确认）。
          

          ACL访问控制列表
          ACL实现对网络流量的精细化过滤控制，按照规则序号从上到下逐条匹配，匹配即停止（隐含末尾deny all）。
          

          ACL分类：
          

            

          • 标准ACL（2000-2999）：仅匹配源IP地址
            • 

          • 高级ACL（3000-3999）：匹配源/目的IP、协议类型、端口号
            • 

          • 二层ACL（4000-4999）：匹配MAC地址、以太网类型
            • 

          

          通配符掩码：与子网掩码相反，0表示精确匹配，1表示忽略。例如匹配 192.168.1.0/24 网段使用通配符 0.0.0.255。
          

          ACL规则设计原则：将匹配频率高的规则放前面以提升转发性能，将更精确的规则放在宽泛规则之前，并在最末尾添加显式的 permit/deny 规则以增强可读性。
          

          前沿动态
          EVPN-VXLAN正在取代传统VLAN+STP成为新一代数据中心和大型园区的二层网络方案，通过BGP EVPN控制面实现MAC/IP路由学习，消除了STP的收敛缺陷。Segment Routing（SR）技术在运营商和大型企业网络中快速部署，通过源路由方式简化网络转发，SR-MPLS和SRv6两种实现各有应用场景。
          

          练习与思考
            

          1. 在模拟器中配置包含3个VLAN的交换网络，验证不同VLAN之间无法直接通信，然后通过三层交换机实现VLAN间路由
            2. 

          2. 构建含有冗余链路的拓扑，观察STP的根桥选举过程和端口角色分配，然后手动修改优先级改变根桥位置
            3. 

          3. 设计一个包含4个区域的OSPF网络拓扑，配置区域间路由汇总，观察路由表变化
            4. 

          4. 编写ACL规则：允许研发部（192.168.10.0/24）访问服务器区（10.0.1.0/24）的SSH和HTTP服务，拒绝其他一切流量
            5. 

          

          小结
          VLAN通过逻辑隔离实现灵活的广播域控制，STP在冗余拓扑中消除环路保障网络稳定，静态路由和OSPF动态路由分别满足简单网络和复杂网络的选路需求，ACL则在流量转发层面实现安全策略的精细执行。这五项技术相互配合，构成了所有企业级交换路由网络的基础骨架，是网络工程师日常运维和故障排查中使用频率最高的技术栈。
