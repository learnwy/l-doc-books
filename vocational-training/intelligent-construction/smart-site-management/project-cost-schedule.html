    项目造价与进度管控

    知识要点

    项目成功的衡量标准最终落在"按时交付、不超预算"八个字上。数字化时代的造价与进度管控不再依赖工程师的经验直觉，而是通过BIM算量、智能排程和挣值分析等工具，构建起"早发现、早预警、早纠偏"的精细化管理体系。

    数字化进度管理
    **关键路径法（CPM）**是进度管理的理论基础。活动总时差为零的路径即为关键路径：
    

    TFi=LSi−ESi=LFi−EFiTF_i = LS_i - ES_i = LF_i - EF_iTFi​=LSi​−ESi​=LFi​−EFi​
    其中 TFTFTF 为总时差，LSLSLS 为最迟开始，ESESES 为最早开始，LFLFLF 为最迟完成，EFEFEF 为最早完成。

    挣值分析（EVM）
    挣值管理通过三个核心参数衡量项目绩效：
    

      

    • PV（Planned Value）：计划值——截至某时间点应完成的预算工作量
      • 

    • EV（Earned Value）：挣值——截至某时间点实际完成工作的预算价值
      • 

    • AC（Actual Cost）：实际成本——完成已有工作的实际花费
      • 

    

    进度偏差：
    

    SV=EV−PVSV = EV - PVSV=EV−PV
    SV>0SV > 0SV>0 表示进度超前，SV<0SV < 0SV<0 表示进度滞后。
    

    费用偏差：
    

    CV=EV−ACCV = EV - ACCV=EV−AC
    CV>0CV > 0CV>0 表示节约，CV<0CV < 0CV<0 表示超支。
    

    进度绩效指数：
    

    SPI=EVPVSPI = \frac{EV}{PV}SPI=PVEV​
    费用绩效指数：
    

    CPI=EVACCPI = \frac{EV}{AC}CPI=ACEV​
    完工估算：
    

    EAC=BACCPIEAC = \frac{BAC}{CPI}EAC=CPIBAC​
    其中 BACBACBAC 为完工总预算。当 CPI<1CPI < 1CPI<1 时，项目存在超支风险。

    某智慧工地项目第6个月末数据：

    分析：
    

      

    • SV=2200−2500=−300SV = 2200 - 2500 = -300SV=2200−2500=−300 万（进度滞后）

    前沿动态
    2026年项目管控领域的显著变化：AI驱动的进度预测系统通过历史项目数据训练，可预测当前项目各工序的实际完成概率和延误风险；基于大语言模型的造价咨询AI能回答"增加一层地下室对总造价的影响有多大"这类复杂问题；数字人民币在工程款支付中的试点应用实现了资金的穿透式监管；供应链金融平台与智慧工地数据打通，分包商可凭进度确认函秒获融资。
