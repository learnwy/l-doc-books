机器视觉检测

知识要点

机器视觉是智能产线的"眼睛"，通过工业相机和图像处理算法替代人工目检，实现高速、高精度、不疲劳的在线检测。2026年，深度学习质检方案已成为主流，但传统算法在特定场景仍不可替代。理解从光学成像到算法判定的完整链路，是视觉工程师的核心能力。

相机选型

工业相机的选型直接决定系统性能上限：

分辨率计算：

像素分辨率=视野范围(mm)传感器像素数\text{像素分辨率} = \frac{\text{视野范围(mm)}}{\text{传感器像素数}}像素分辨率=传感器像素数视野范围(mm)​

检测精度要求：每个缺陷至少覆盖 3×33 \times 33×3 像素，因此：

需要像素数≥视野最小缺陷尺寸/3\text{需要像素数} \geq \frac{\text{视野}}{最小缺陷尺寸 / 3}需要像素数≥最小缺陷尺寸/3视野​

关键参数选择：

参数 选型依据 典型值
分辨率 缺陷尺寸/视野 500万-2000万像素
帧率 产线速度/触发频率 30-500fps
靶面尺寸 镜头匹配/景深需求 1/1.8"-4/3"
接口 带宽/距离/多相机 GigE/CoaXPress/Camera Link
快门 运动模糊控制 全局快门（运动场景必选）

线阵 vs 面阵：

  • 面阵相机：适合静态或步进式检测
  • 线阵相机：适合连续运动物体（如卷材、印刷品），扫描拼接成像

光源设计

"好的光源设计抵得上复杂的算法"——这是视觉工程的第一定律：

照明方式：

光源类型选择：


    

  • LED条形光：通用性最强，可组合多角度
    • 

  • LED环形光：适合垂直俯视检测
    • 

  • 激光结构光：三维轮廓扫描、高度测量
    • 

  • 频闪控制器：与相机触发同步，消除环境光干扰
    • 



光学系统参数：


    

  • 工作距离（WD）：镜头到被测物距离
    • 

  • 景深（DOF）：光圈越小景深越大，但通光量降低
    • 

  • 远心镜头：消除透视畸变，适合精密尺寸测量
    • 



图像处理算法
经典图像处理算法是视觉检测的基础工具箱：


预处理：


    

  • 灰度化、ROI提取
    • 

  • 高斯滤波/中值滤波：去噪
    • 

  • 直方图均衡化：改善对比度
    • 



特征提取：


    

  • 边缘检测：Canny、Sobel算子
    • 

  • 阈值分割：Otsu自适应阈值、区域生长
    • 

  • 形态学运算：腐蚀、膨胀、开闭运算
    • 

  • 连通域分析：标记连通区域，统计面积/周长
    • 



模板匹配与测量：


    

  • 归一化互相关（NCC）：定位目标位置和角度
    • 

  • 亚像素边缘定位：精度达 0.010.010.01 像素
    • 

  • 卡尺工具：沿法线方向搜索边缘对
    • 



Blob分析检测流程：


原图 → 灰度转换 → 高斯平滑 → 阈值分割 → 形态学闭运算 
→ 连通域标记 → 面积/形状因子筛选 → 缺陷判定
缺陷识别与分类
传统算法处理规则缺陷效果好，但面对复杂纹理背景或多类型混合缺陷时局限明显，此时深度学习方案优势突出。


传统方法适用场景：


    

  • 尺寸超差（边缘→测量）
    • 

  • 缺料/多料（面积比对）
    • 

  • 位置偏移（模板匹配）
    • 

  • 简单划痕（方向滤波增强）
    • 



深度学习方案：


    

  • 检测架构：YOLOv8/RT-DETR 实时目标检测
    • 

  • 分割架构：U-Net/Segment Anything 像素级缺陷标注
    • 

  • 异常检测：只需正样本训练（PatchCore/FastFlow），适合缺陷样本稀少场景
    • 



数据管理：


    

  • 标注工具：CVAT、LabelImg
    • 

  • 数据增强：旋转、翻转、亮度扰动、CutMix
    • 

  • 类别不平衡：Focal Loss、过采样
    • 



深度学习质检部署
从模型训练到产线部署的完整链路：


部署平台选择：


    

  • NVIDIA Jetson：边缘AI推理，TensorRT加速
    • 

  • Intel OpenVINO：x86工控机部署优化
    • 

  • 国产方案：瑞芯微NPU/寒武纪加速卡
    • 



关键性能指标：


    

  • 推理时间：<50ms<50\text{ms}<50ms/帧（20fps产线要求）
    • 

  • 检出率：≥99.9%\geq 99.9\%≥99.9%（漏检代价极高）
    • 

  • 误检率：<0.5%<0.5\%<0.5%（过高导致产能损失）
    • 



前沿动态
2026年机器视觉领域的最新发展：


    

  • Foundation Model for Defect：大规模预训练缺陷检测模型，少样本即可适配新产品
    • 

  • 3D点云深度学习：直接在三维数据上检测缺陷，解决2D投影信息丢失
    • 

  • Event Camera：事件相机超高动态范围，解决高速运动场景模糊问题
    • 

  • 多光谱/高光谱：超越可见光波段，检测人眼不可见的化学成分差异
    • 

  • 云边协同：边缘设备实时判定，复杂case上传云端二次分析
    • 



练习与思考
    

  1. 设计一个PCB焊点检测方案：选择相机（分辨率、帧率）、光源（类型、角度）和镜头（焦距），并说明选型依据。
    2. 

  2. 使用OpenCV实现一个简单的Blob缺陷检测：读取带有黑色污点的白色产品图片，输出缺陷数量、面积和位置。
    3. 

  3. 对比在同一数据集上使用传统阈值分割和YOLOv8的检出率/误检率差异，分析各自的适用场景。
    4. 

  4. 讨论：在检出率99.9%的要求下，系统的经济回报如何计算？漏检一件不良品的成本如何量化？
    5. 



小结
机器视觉检测从光学成像、图像处理到智能判定形成完整的技术栈。相机和光源的正确选型是"硬件决定上限"，经典算法处理规则明确的检测任务效率最高，而深度学习则在复杂场景中提供了突破性的检测能力。2026年的趋势是"传统+AI"混合方案——简单特征用经典算法快速处理，复杂模式交给深度学习模型判定，两者互补构建高可靠的在线质检体系。
