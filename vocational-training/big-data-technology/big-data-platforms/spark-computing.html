Spark 计算引擎

知识要点

Apache Spark 以其内存计算优势和统一的编程模型，成为企业级大数据处理的首选引擎。相比 MapReduce 频繁的磁盘 I/O，Spark 将中间结果缓存在内存中，在迭代计算场景下性能提升 10-100 倍。

RDD 弹性分布式数据集

RDD（Resilient Distributed Dataset）是 Spark 最底层的数据抽象，代表一个不可变的、可并行操作的元素集合：

from pyspark import SparkContext

sc = SparkContext("local[*]", "RDD Demo")

# 创建 RDD
lines = sc.textFile("hdfs:///logs/access.log")

# Transformation（惰性求值，不会立即执行）
words = lines.flatMap(lambda line: line.split(" "))
pairs = words.map(lambda w: (w, 1))
counts = pairs.reduceByKey(lambda a, b: a + b)

# Action（触发实际计算）
top10 = counts.top(10, key=lambda x: x[1])

RDD 的核心特性：惰性求值（Transformation 只记录计算图，Action 才触发执行）、血缘关系（Lineage）用于容错恢复、分区（Partition）决定并行度。

DataFrame 与 Dataset API

DataFrame 是带有 Schema 的分布式数据表，提供比 RDD 更高级的声明式 API 和更强的优化能力：

from pyspark.sql import SparkSession
from pyspark.sql import functions as F
from pyspark.sql.window import Window

spark = SparkSession.builder.appName("DataFrame Demo").getOrCreate()

# 读取 Parquet 数据
df = spark.read.parquet("hdfs:///dw/dwd/user_orders")

# 链式转换
result = (
    df.filter(F.col("status") == "completed")
      .withColumn("order_month", F.date_format("created_at", "yyyy-MM"))
      .groupBy("order_month", "category")
      .agg(
          F.sum("amount").alias("total_revenue"),
          F.countDistinct("user_id").alias("buyers"),
          F.avg("amount").alias("avg_order_value")
      )
      .orderBy(F.desc("total_revenue"))
)

# 窗口函数
window_spec = Window.partitionBy("user_id").orderBy("created_at")
df_with_rank = df.withColumn(
    "order_seq", F.row_number().over(window_spec)
)

DataFrame API 经过 Catalyst 优化器和 Tungsten 执行引擎的双重加持，在大多数场景下性能优于手写 RDD 代码。

Spark SQL 查询引擎

Spark SQL 让 SQL 分析师无需学习编程即可利用 Spark 的分布式计算能力：

-- 注册临时视图
CREATE OR REPLACE TEMP VIEW active_users AS
SELECT user_id, COUNT(*) AS order_count, SUM(amount) AS total_spent
FROM user_orders
WHERE status = 'completed'
  AND created_at >= '2026-01-01'
GROUP BY user_id
HAVING COUNT(*) >= 3;

-- 用户分层分析
SELECT 
    CASE 
        WHEN total_spent >= 10000 THEN '高价值'
        WHEN total_spent >= 3000 THEN '中价值'
        ELSE '低价值'
    END AS user_tier,
    COUNT(*) AS user_count,
    AVG(total_spent) AS avg_spent
FROM active_users
GROUP BY 1;

Spark SQL 支持 ANSI SQL 标准，并扩展了 LATERAL VIEW、TRANSFORM 等大数据特有语法。

MLlib 机器学习库

MLlib 提供开箱即用的分布式机器学习算法，适合大规模数据集上的模型训练：

from pyspark.ml import Pipeline
from pyspark.ml.feature import VectorAssembler, StandardScaler
from pyspark.ml.classification import RandomForestClassifier
from pyspark.ml.evaluation import BinaryClassificationEvaluator

# 特征工程
assembler = VectorAssembler(
    inputCols=["age", "income", "login_days", "order_count"],
    outputCol="raw_features"
)
scaler = StandardScaler(inputCol="raw_features", outputCol="features")

# 模型定义
rf = RandomForestClassifier(
    labelCol="is_churn", featuresCol="features",
    numTrees=100, maxDepth=8
)

# Pipeline 管道
pipeline = Pipeline(stages=[assembler, scaler, rf])
model = pipeline.fit(train_df)

# 评估
predictions = model.transform(test_df)
evaluator = BinaryClassificationEvaluator(labelCol="is_churn")
auc = evaluator.evaluate(predictions)
print(f"AUC: {auc:.4f}")

结构化流处理

Structured Streaming 将流数据视为无限增长的 DataFrame，复用批处理 API：

# 从 Kafka 读取实时数据
stream_df = (
    spark.readStream
         .format("kafka")
         .option("kafka.bootstrap.servers", "kafka:9092")
         .option("subscribe", "user_events")
         .load()
)

# 解析 JSON 并计算实时指标
from pyspark.sql.types import StructType, StringType, TimestampType

schema = StructType() \
    .add("user_id", StringType()) \
    .add("event", StringType()) \
    .add("timestamp", TimestampType())

parsed = stream_df.select(
    F.from_json(F.col("value").cast("string"), schema).alias("data")
).select("data.*")

# 5 分钟滑动窗口统计
windowed = (
    parsed.groupBy(
        F.window("timestamp", "5 minutes", "1 minute"),
        "event"
    ).count()
)

性能调优

Spark 作业性能优化的核心策略：

问题 诊断方法 解决方案
数据倾斜 Spark UI 中 Task 执行时间极度不均 Salting（加盐打散 key）
Shuffle 过多 Stage 间数据传输量大 减少宽依赖，使用 broadcast join
内存不足 Executor OOM 调整 spark.executor.memory，优化序列化
小文件问题 输入 Split 数量过多 coalesce() 或 repartition()

关键配置：spark.sql.shuffle.partitions（默认 200，需根据数据量调整）、spark.sql.adaptive.enabled=true（AQE 自适应查询执行）。

前沿动态

  • Spark Connect（Spark 4.x）：客户端-服务端分离架构，多语言客户端连接远程 Spark 集群
  • Photon 引擎：Databricks 的 C++ 向量化执行引擎，查询性能提升 2-8 倍
  • GPU 加速：RAPIDS Accelerator 将 Spark SQL 操作下推到 GPU 执行
  • AI 一体化：Spark 集成 MLflow + LLM 推理，成为数据 + AI 统一平台

练习与思考

  1. 在本地模式下创建一个 Spark Session，读取 CSV 文件用 DataFrame API 完成数据清洗和分组聚合
  2. 使用 Spark SQL 实现一个电商用户 RFM 模型：计算最近消费时间（Recency）、消费频率（Frequency）、消费金额（Monetary）
  3. 构建一个 MLlib Pipeline，对用户特征数据训练分类模型并评估 AUC
  4. 思考：Spark 的 cache() 和 persist() 有什么区别？什么时候应该缓存 DataFrame？缓存的代价是什么？

小结

Spark 通过统一的编程模型整合了批处理、SQL 查询、机器学习和流计算四大场景。RDD 提供灵活的底层控制，DataFrame/Spark SQL 通过优化器实现声明式高性能查询，MLlib 使大规模模型训练开箱即用，Structured Streaming 实现了批流一体。掌握 Spark 意味着拥有了处理 90% 大数据计算需求的能力。
