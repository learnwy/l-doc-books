PLC编程基础

知识要点

可编程逻辑控制器（PLC）在二十世纪六十年代末诞生于美国通用汽车公司的生产改造需求，如今已成为工业自动化领域最核心的控制设备。从简单的电机启停到复杂的多轴运动协调，PLC 以其可靠性高、编程灵活、环境适应性强的特点，稳坐工厂控制系统的"大脑"位置。

PLC 工作原理与硬件结构

PLC 采用循环扫描的工作方式，每个扫描周期分为三个阶段：

    

  • 输入采样：读取所有输入端子的状态，存入输入映像寄存器
    • 

  • 程序执行：按照用户程序从上到下、从左到右逐条执行
    • 

  • 输出刷新：将输出映像寄存器的结果一次性送到输出端子
    • 



扫描周期通常在 1-100ms 之间，对于多数机电控制任务已足够快速。

梯形图编程（LD）
梯形图是 PLC 最常用的编程语言，形式上类似继电器控制电路图。左母线代表电源正极，右母线代表负极，中间用触点和线圈表达逻辑关系。


基本元素：


    

  • 常开触点（-| |-）：对应的位为 1 时导通
    • 

  • 常闭触点（-|/|-）：对应的位为 0 时导通
    • 

  • 输出线圈（-( )-）：逻辑条件满足时置位
    • 



逻辑关系对应：


    

  • 串联 = 与逻辑（AND）
    • 

  • 并联 = 或逻辑（OR）
    • 

  • 常闭触点 = 非逻辑（NOT）
    • 



编程示例——电动机启保停控制：


    

  • X0（启动按钮）与 X1（停止按钮，常闭）串联
    • 

  • Y0（接触器线圈）输出
    • 

  • Y0 自身常开触点并联在 X0 旁边实现自保持
    • 



这个最基础的程序体现了 PLC 编程的核心思想：用软件逻辑替代硬件继电器的接线关系。


基本指令应用
定时器（TON）：通电延时型，当输入条件持续满足达到设定时间后，输出触点动作。


应用场景：电机星三角启动延时切换（通常设置 5-10 秒）。


设定值计算：若时基为 100ms，需要延时 3 秒，则设定值 K=3000100=30K = \frac{3000}{100} = 30K=1003000​=30。


计数器（CTU）：每接收一个上升沿脉冲计数加 1，达到设定值后输出触点动作。


应用场景：产线计数，每满 12 个零件触发一次装箱动作。


比较指令：将当前值与设定值比较，常用于模拟量控制。


当D100≥500时，M10=ON当 D100 \geq 500 时，M10 = ON当D100≥500时，M10=ON
实际含义：当温度传感器读数（存于 D100）达到 500（对应 50.0°C）时，启动冷却风扇。

实训建议：从三菱 FX 系列入门（指令简单直观），掌握基本编程方法后再学习西门子系统（功能更强大，在大中型项目中占主导）。


前沿动态
2026 年 PLC 技术呈现几个显著趋势：一是边缘计算能力增强，新一代 PLC（如西门子 S7-1500 系列）集成了 OPC UA 通信和边缘分析功能，可在本地完成数据预处理；二是云端编程和远程运维成为常态，工程师可以通过云平台远程监控和调试 PLC 程序；三是 IEC 61131-3 标准的结构化文本（ST）语言因其接近高级编程语言的特性而使用比例持续上升；四是低代码/可视化编程工具降低了 PLC 编程门槛，但理解底层扫描机制和时序逻辑仍然是排除复杂故障的必备能力。

    2. 

  2. 某灌装生产线需要计数：每灌满 6 瓶为一组，传送带暂停 2 秒等待装箱后继续。请用定时器和计数器指令完成编程。
    3. 

  3. 解释 PLC 扫描周期对高速计数的影响——如果扫描周期为 20ms，普通输入能检测到的最高脉冲频率是多少？如何解决高速信号检测问题？
    4. 

  4. 对比继电器控制与 PLC 控制的优缺点，说明在什么情况下仍然适合使用纯继电器方案。
    5. 

  5. 实训任务：在实训台上完成交通灯控制程序——东西方向绿 30 秒→黄 3 秒→红 33 秒，南北方向与之相反。要求有手动/自动切换功能。
    6. 



小结
PLC 编程是机电技术应用专业最核心的职业技能。理解循环扫描的工作原理是正确编程和排故的基础；梯形图以直观的方式表达逻辑控制关系；定时器、计数器和比较指令覆盖了绝大多数工业控制需求；熟悉主流品牌的编程环境和操作方法则是快速上岗的实际保障。后续的自动化产线控制和设备维修都将以 PLC 为核心展开。
