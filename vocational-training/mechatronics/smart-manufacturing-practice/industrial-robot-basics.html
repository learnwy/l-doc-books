工业机器人基础

知识要点

工业机器人是智能制造产线的核心执行单元，能在人类难以持续作业的高速、高精度、高重复性场景中稳定工作。2026 年国内工业机器人年装机量已突破 50 万台，中职机电专业学生掌握机器人基本操作技能已成为就业竞争力的重要加分项。

机器人结构与分类

工业机器人按机械结构可分为四大类型，各有其最佳适用场景：

多关节机器人（Articulated Robot）


最常见的工业机器人类型，通常具有 6 个旋转关节（6-DOF），运动空间接近球形。典型品牌包括 FANUC、ABB、KUKA、安川。


关节配置与运动范围：


    

  • J1（腰部旋转）：±170°\pm 170°±170°
    • 

  • J2（大臂俯仰）：+60°/−140°+60°/-140°+60°/−140°（典型值）
    • 

  • J3（小臂俯仰）：+80°/−170°+80°/-170°+80°/−170°
    • 

  • J4（腕部旋转）：±190°\pm 190°±190°
    • 

  • J5（腕部摆动）：±120°\pm 120°±120°
    • 

  • J6（末端旋转）：±360°\pm 360°±360°
    • 



负载范围从 3kg 小型机器人到 1000kg+ 重载搬运机器人不等。


SCARA 机器人（Selective Compliance Assembly Robot Arm）


在水平方向柔顺、垂直方向刚性的 4 轴机器人。结构特点使其在平面定位-垂直插装类任务中速度极快，节拍可达 0.3s/次。典型应用：电子元器件插装、螺丝锁付、芯片搬运。


Delta 并联机器人


由三组平行四边形连杆构成的并联结构，动平台质量极小，加速度可达 a=100m/s2a = 100\text{m/s}^2a=100m/s2 以上。适用于食品、药品、电子产品的高速分拣与装盒，节拍可达 120 次/分钟。


协作机器人（Cobot）


设计上允许与人类在同一空间无隔离栅作业。通过关节力矩传感器实时感知外力，碰撞时立即停止。负载通常 3-16kg，重复定位精度 ±0.03mm\pm 0.03\text{mm}±0.03mm，适用于柔性装配、质检、物料递送等场景。

示教器操作
示教器（Teach Pendant）是操作工业机器人的主要人机接口。中职实训中需要掌握以下两种示教方式：


手动引导示教（协作机器人）


操作员直接用手推拉机器人末端，机器人通过关节力矩传感器记录运动轨迹。操作步骤：


    

  1. 切换到引导模式（按住示教器上的使能按钮）
    2. 

  2. 手动将机器人末端引导至目标位置
    3. 

  3. 按下"记录点位"按钮保存当前关节角度
    4. 

  4. 重复 2-3 步完成所有路径点
    5. 

  5. 回放验证轨迹
    6. 



示教盒编程（传统工业机器人）


通过示教器上的按键和摇杆控制机器人移动，手动记录关键点位后编写程序：


; FANUC 示教程序示例——搬运任务
1: J P[1] 100% FINE    ; 关节运动到待机位
2: L P[2] 500mm/s CNT50 ; 直线运动到取料上方
3: L P[3] 100mm/s FINE  ; 缓速下降到取料位
4: RO[1]=ON             ; 真空吸盘开启
5: WAIT 0.3(sec)        ; 等待吸附稳定
6: L P[2] 500mm/s CNT50 ; 提升到安全高度
7: L P[4] 800mm/s CNT80 ; 移动到放料上方
8: L P[5] 100mm/s FINE  ; 下降到放料位
9: RO[1]=OFF            ; 释放工件
10: L P[4] 500mm/s CNT50 ; 提升
坐标系选择：


    

  • 关节坐标系（Joint）：直接控制各关节角度，用于快速移动到大致位置
    • 

  • 直角坐标系（World/User）：控制末端在 XYZ 空间的直线运动，用于精确定位
    • 

  • 工具坐标系（Tool）：以工具尖端为原点，便于沿工具方向微调
    • 



基本编程任务
搬运程序设计要点：


    

  • 提升-平移-下降三阶段运动，避免拖拽工件
    • 

  • 取放料点使用 FINE（精确到位），过渡点使用 CNT（连续运动不停顿）
    • 

  • 进给速度逐步降低，接近工件时速度 v≤200mm/sv \leq 200\text{mm/s}v≤200mm/s
    • 



码垛程序设计要点：


    

  • 利用寄存器计数实现行列偏移
    • 

  • 偏移量计算：Xoffset=(i−1)×ΔxX_{\text{offset}} = (i-1) \times \Delta xXoffset​=(i−1)×Δx，Yoffset=(j−1)×ΔyY_{\text{offset}} = (j-1) \times \Delta yYoffset​=(j−1)×Δy
    • 

  • 层间高度：Zoffset=(k−1)×hZ_{\text{offset}} = (k-1) \times hZoffset​=(k−1)×h
    • 

  • 码垛满层后暂停等待托盘切换信号
    • 



焊接程序设计要点：


    

  • 起弧-焊接-收弧各阶段独立设置参数
    • 

  • 焊接速度 vfv_fvf​ 与送丝速度匹配关系需根据焊缝宽度调整
    • 

  • 多层多道焊接使用坐标偏移叠加

  1. 操作前检查急停按钮功能有效

  2. 示教速度不超过 250mm/s

前沿动态
2026 年协作机器人市场增速超过传统工业机器人，国产品牌（节卡、遨博、艾利特）在性价比上持续突破，10 万元以下的六轴协作臂已进入中小企业产线。AI 视觉引导技术使机器人能处理无序抓取（bin-picking）场景，不再需要精确定位的供料装置。大语言模型辅助编程正在试点——操作员用自然语言描述任务意图，AI 自动生成机器人运动轨迹和程序代码。移动复合机器人（AGV+机械臂）打破了固定工位的限制，一台机器人可以服务多个工位。这些趋势意味着未来机器人操作岗位对编程和系统集成能力的要求将高于简单示教。


练习与思考
    

  1. 某工位需要将传送带上随机摆放的圆柱形工件（直径 50mm、高 80mm、重 0.5kg）拾取后放入料盒（5×4 矩阵排列），选择哪种类型的机器人最合适？说明理由。
    2. 

  2. 编写一段搬运程序伪代码：机器人从 A 点取料、经过 B 点（过渡点）、放置到 C 点，要求取放料精确到位，过渡点不停顿。标注每段运动的速度和到位方式。
    3. 

  3. 协作机器人末端安装了一把金属去毛刺刀具，操作员需要在旁边放置工件。分析该场景的安全风险，并提出至少 3 条安全改进措施。
    4. 

  4. 计算一个 3 层×4 行×3 列的码垛任务中，工件间距 X=120mm、Y=100mm、层高 Z=90mm，第 2 层第 3 行第 2 列工件相对于第 1 层第 1 行第 1 列的坐标偏移量。
    5. 

  5. 实训任务：在协作机器人上完成手动引导示教——记录 5 个路径点，形成一个矩形轨迹，回放验证路径精度。
    6. 



小结
工业机器人按结构分为多关节、SCARA、Delta 和协作四大类型，各自适用于不同的生产场景。操作机器人的核心技能包括示教器的手动操控与基本程序编写，搬运、码垛、焊接是中职阶段最常见的实训任务类型。人机协作安全以 ISO/TS 15066 为规范框架，功率与力限制模式是当前最普遍的协作方案。掌握这些基础后，后续可向视觉引导、离线编程、多机协同等方向深入发展。
