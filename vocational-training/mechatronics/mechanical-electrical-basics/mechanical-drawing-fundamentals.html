机械制图基础

知识要点

机械制图是工程师和技术工人之间沟通的"通用语言"，一张合格的图纸能够准确传达零件的形状、尺寸、精度要求和加工方法。在机电技术应用的实际工作中，无论是设备安装、维修排故还是零件加工，第一步都是"看懂图纸"。

投影原理与三视图

正投影法是机械制图的理论基础。将空间物体向三个互相垂直的投影面投射，得到主视图（从前向后看）、俯视图（从上向下看）和左视图（从左向右看）三个基本视图。

三视图的投影规律可以概括为：

  • 主视图与俯视图——长对正
  • 主视图与左视图——高平齐
  • 俯视图与左视图——宽相等
绘制三视图的步骤：确定主视图方向（选择最能反映物体形状特征的方向）→ 画出各视图的外轮廓 → 补充内部结构（虚线表示不可见轮廓）→ 标注尺寸。


公差配合与标注
实际加工中，任何尺寸都不可能绝对精确。公差是允许尺寸变动的范围，用上偏差和下偏差来表示：


实际尺寸范围=基本尺寸+下偏差∼基本尺寸+上偏差实际尺寸范围 = 基本尺寸 + 下偏差 \sim 基本尺寸 + 上偏差实际尺寸范围=基本尺寸+下偏差∼基本尺寸+上偏差
配合是指基本尺寸相同的孔和轴装配在一起时的松紧关系，分为三类：

标注示例：ϕ30H7/f6\phi30H7/f6ϕ30H7/f6 表示基本尺寸 30mm，孔的公差带为 H7，轴的公差带为 f6，属于间隙配合。


零件图与装配图识读
零件图包含四个要素：一组视图（表达形状）、完整的尺寸标注、技术要求（表面粗糙度、热处理等）、标题栏（名称、材料、比例）。


识读零件图的步骤：


    

  1. 看标题栏，了解零件名称、材料和用途
    2. 

  2. 分析视图，想象零件的立体形状
    3. 

  3. 读尺寸，确定各部分的大小和位置关系
    4. 

  4. 看技术要求，明确加工精度和表面质量
    5. 



装配图在零件图基础上表达多个零件的装配关系、工作原理和技术要求。识读时需关注零件之间的配合关系、运动关系和密封要求。


CAD 软件初步
计算机辅助设计（CAD）已经取代手工绘图成为工程制图的主流方式。中职阶段常用 AutoCAD 或中望 CAD 进行二维绘图训练：


基本操作流程：设置图幅和图层 → 使用直线、圆、圆弧等基本命令绘制轮廓 → 修剪、镜像、阵列等编辑操作 → 标注尺寸和技术要求 → 填写标题栏 → 打印出图。


熟练掌握快捷键能显著提高绘图效率：L（直线）、C（圆）、TR（修剪）、MI（镜像）、DIM（标注）。


前沿动态
2026 年制造业数字化转型加速，三维建模软件（如 SolidWorks、Fusion 360）在中小企业中加速普及。部分职业院校已经开设三维建模课程，将传统二维制图与三维参数化建模结合教学。此外，AI 辅助制图工具开始进入工程领域，能够根据三维模型自动生成符合国标的二维工程图纸，但理解投影原理和识读图纸的基本功仍然不可替代。MBD（基于模型的定义）技术让尺寸和公差信息直接附着在三维模型上，正在改变传统的二维出图流程。

小结
机械制图是机电技术人员必须熟练掌握的基本技能。三视图的投影规律（长对正、高平齐、宽相等）是识图画图的核心法则；公差配合知识确保零件能按设计意图正确装配；零件图和装配图的系统识读能力是参与实际生产的前提；CAD 软件操作则是现代制图的必备工具。三者结合，形成完整的工程图纸读写能力。
