Web 前端基础

知识要点

Web 前端开发是将数据和功能"可视化呈现"给用户的技术。当你打开任何网页、使用任何 Web 应用时，看到的文字排版、色彩搭配、按钮交互和动画效果，都是前端代码的产物。掌握 HTML + CSS + JavaScript 三件套，你就拥有了独立制作网页和简单 Web 应用的完整能力。

HTML5 结构与语义标签

HTML（超文本标记语言）定义网页的骨架结构。HTML5 引入了语义化标签，让代码本身就能表达内容的含义：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的作品集</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header>
        <nav>
            <a href="#about">关于我</a>
            <a href="#projects">项目</a>
            <a href="#contact">联系</a>
        </nav>
    </header>
    
    <main>
        <section id="about">
            <h1>你好，我是张三</h1>
            <p>计算机应用专业学生，热爱前端开发。</p>
        </section>
        
        <section id="projects">
            <h2>我的项目</h2>
            <article>
                <h3>校园导航系统</h3>
                <p>基于 HTML5 Canvas 的校园地图应用。</p>
            </article>
        </section>
    </main>
    
    <footer>
        <p>&copy; 2026 张三的作品集</p>
    </footer>
</body>
</html>

语义化标签的优势：

  • <header> <nav> <main> <footer> 比 <div> 更有可读性
  • 搜索引擎更容易理解页面结构（有利于 SEO）
  • 屏幕阅读器能正确朗读内容（无障碍）

常用 HTML 元素速查：

元素 用途 注意事项
<h1>-<h6> 标题层级 一个页面只用一个 <h1>
<p> 段落 不要用 <br> 代替段落分隔
<img> 图片 必须添加 alt 属性
<a> 链接 target="_blank" 在新窗口打开
<ul>/<ol> 列表 导航菜单优先用列表结构
<table> 表格 仅用于展示表格数据，不用于布局
<form> 表单 配合 <input> <select> <textarea>

CSS3 样式与布局

CSS（层叠样式表）控制网页的视觉呈现——颜色、字体、间距、布局。

盒模型——CSS 布局的基础概念：

每个 HTML 元素都是一个盒子，由内到外依次为：内容（content）→ 内边距（padding）→ 边框（border）→ 外边距（margin）。

/* 推荐使用 border-box 计算方式 */
* {
    box-sizing: border-box;
}

.card {
    width: 300px;        /* 总宽度就是300px（含padding和border） */
    padding: 20px;
    border: 1px solid #e0e0e0;
    margin: 16px;
    border-radius: 8px;
    box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}

Flexbox 弹性布局——一维布局利器：

.navbar {
    display: flex;
    justify-content: space-between;  /* 主轴两端对齐 */
    align-items: center;             /* 交叉轴居中 */
    padding: 0 24px;
    height: 60px;
    background: #1a1a2e;
}

.nav-links {
    display: flex;
    gap: 24px;  /* 子元素间距 */
}

Grid 网格布局——二维布局利器：

.project-grid {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
    gap: 24px;
    padding: 24px;
}

Grid 适合卡片列表、图片画廊、仪表板等需要行列同时控制的布局场景。

JavaScript 交互基础

JavaScript 赋予网页动态交互能力——响应用户操作、修改页面内容、与服务器通信。

DOM 操作——修改页面内容：

// 获取元素
const title = document.querySelector('h1');
const buttons = document.querySelectorAll('.btn');

// 修改内容和样式
title.textContent = '欢迎回来！';
title.style.color = '#2563eb';

// 创建新元素
const newCard = document.createElement('div');
newCard.className = 'card';
newCard.innerHTML = '<h3>新项目</h3><p>项目描述</p>';
document.querySelector('.project-grid').appendChild(newCard);

事件处理——响应用户操作：

// 按钮点击
document.querySelector('#submit-btn').addEventListener('click', function() {
    const name = document.querySelector('#name-input').value;
    if (name.trim() === '') {
        alert('请输入姓名！');
        return;
    }
    alert(`你好，${name}！`);
});

// 表单验证
document.querySelector('form').addEventListener('submit', function(e) {
    const email = document.querySelector('#email').value;
    if (!email.includes('@')) {
        e.preventDefault();  // 阻止提交
        document.querySelector('#error-msg').textContent = '邮箱格式不正确';
    }
});

实用案例——待办事项列表：

const todoInput = document.querySelector('#todo-input');
const todoList = document.querySelector('#todo-list');
const addBtn = document.querySelector('#add-btn');

addBtn.addEventListener('click', function() {
    const text = todoInput.value.trim();
    if (!text) return;
    
    const li = document.createElement('li');
    li.innerHTML = `
        <span>${text}</span>
        <button class="delete-btn">删除</button>
    `;
    
    li.querySelector('.delete-btn').addEventListener('click', function() {
        li.remove();
    });
    
    li.querySelector('span').addEventListener('click', function() {
        this.classList.toggle('completed');
    });
    
    todoList.appendChild(li);
    todoInput.value = '';
});

响应式设计入门

响应式设计让同一个网页在手机、平板、电脑上都能良好显示。

媒体查询（Media Queries）：

/* 默认样式（移动端优先） */
.container {
    padding: 16px;
}

.project-grid {
    grid-template-columns: 1fr;
}

/* 平板及以上（≥768px） */
@media (min-width: 768px) {
    .project-grid {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* 桌面端（≥1024px） */
@media (min-width: 1024px) {
    .container {
        max-width: 1200px;
        margin: 0 auto;
    }
    .project-grid {
        grid-template-columns: repeat(3, 1fr);
    }
}

响应式图片：

img {
    max-width: 100%;
    height: auto;
}

视口设置——必须在 HTML <head> 中包含：

<meta name="viewport" content="width=device-width, initial-scale=1.0">

没有这行代码，移动端浏览器会按桌面宽度缩放页面，导致文字极小。

前沿动态

2026 年 Web 前端的技术趋势：CSS 原生嵌套语法和容器查询（Container Queries）已获得所有主流浏览器支持，减少了对预处理器的依赖；View Transitions API 让页面切换动画只需几行 CSS；AI 辅助前端开发工具（v0.dev、Bolt.new）可根据自然语言或截图生成完整页面代码；WebAssembly 让浏览器中运行高性能应用成为现实；"1+X" Web 前端开发证书的考核标准已更新为 Vue 3 / React 18 + TypeScript 技术栈。

练习与思考

  1. 制作一个完整的个人作品集网页：包含导航栏、自我介绍区、项目展示（至少 3 个卡片）、联系方式表单。要求使用语义化标签、Flexbox/Grid 布局、响应式设计。
  2. 实现一个"倒计时器"网页应用：用户输入目标时间，页面实时显示剩余的天、时、分、秒，到达时间后弹出提醒。
  3. 使用纯 CSS 实现以下效果：鼠标悬停时卡片向上浮起并显示阴影（transition + transform + box-shadow 组合）。
  4. 不使用任何框架，用原生 HTML + CSS + JavaScript 实现一个完整的"学生信息管理"单页应用：支持添加学生、显示列表、搜索过滤、删除记录，数据保存在 localStorage 中。
  5. 对比分析：同样实现一个响应式导航栏，Flexbox 方案和 Grid 方案各自的代码量和灵活性差异是什么？

小结

Web 前端开发的三大支柱——HTML 负责结构、CSS 负责样式、JavaScript 负责交互——协同工作，将数据转化为用户可感知的视觉界面。掌握语义化标签构建可访问的页面骨架，运用 Flexbox/Grid 实现灵活的现代布局，通过 DOM 操作和事件处理赋予页面动态能力，配合媒体查询实现跨设备适配——这些技能的组合足以独立制作专业水准的静态网站和轻量级 Web 应用，也为进一步学习 Vue/React 等前端框架打下坚实基础。
