编程逻辑与 Python

知识要点

编程的本质是用精确的指令告诉计算机"做什么"和"怎么做"。在学习任何编程语言之前，首先需要建立算法思维——将一个复杂问题拆解为计算机可执行的有序步骤。Python 因其语法简洁、上手快、生态丰富，成为中职学生接触编程的最佳入门语言。

算法三大基本结构

所有程序逻辑都可以用三种基本结构的组合来表达：

顺序结构：指令按从上到下的顺序逐行执行，这是最基础的结构。

选择结构（分支）：根据条件判断决定执行哪条路径。

temperature = float(input("请输入当前温度："))
if temperature >= 35:
    print("高温预警，注意防暑！")
elif temperature >= 20:
    print("气温适宜，适合户外活动。")
else:
    print("气温较低，注意保暖。")

循环结构：重复执行某段代码直到条件不满足。

# for 循环：已知次数
total = 0
for i in range(1, 101):  # 计算 1+2+3+...+100
    total += i
print(f"1到100的和为：{total}")  # 输出 5050

# while 循环：条件控制
password = ""
while password != "abc123":
    password = input("请输入密码：")
print("登录成功！")

函数定义——代码复用的基本单位：


def calculate_bmi(weight, height):
    """计算BMI指数"""
    bmi = weight / (height ** 2)
    if bmi < 18.5:
        category = "偏瘦"
    elif bmi < 24:
        category = "正常"
    elif bmi < 28:
        category = "偏胖"
    else:
        category = "肥胖"
    return bmi, category

result, level = calculate_bmi(70, 1.75)
print(f"BMI: {result:.1f}, 分类: {level}")

with open("scores.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        if float(row["成绩"]) >= 90:
            print(f"{row['姓名']} 成绩优秀：{row['成绩']}")
实用自动化案例——批量重命名文件：


import os

folder = "./photos"
files = os.listdir(folder)
for i, filename in enumerate(files, start=1):
    ext = os.path.splitext(filename)[1]  # 获取扩展名
    new_name = f"旅行照片_{i:03d}{ext}"  # 格式化序号
    os.rename(
        os.path.join(folder, filename),
        os.path.join(folder, new_name)
    )
    print(f"重命名: {filename} → {new_name}")
实用小项目
项目：简易记账本


import json
from datetime import date

FILENAME = "accounts.json"

def load_records():
    try:
        with open(FILENAME, "r") as f:
            return json.load(f)
    except FileNotFoundError:
        return []

def save_records(records):
    with open(FILENAME, "w", encoding="utf-8") as f:
        json.dump(records, f, ensure_ascii=False, indent=2)

def add_record(records):
    amount = float(input("金额（支出为负数）："))
    category = input("类别（餐饮/交通/学习/其他）：")
    records.append({
        "date": str(date.today()),
        "amount": amount,
        "category": category
    })
    save_records(records)
    print("记录成功！")

def show_summary(records):
    total_income = sum(r["amount"] for r in records if r["amount"] > 0)
    total_expense = sum(r["amount"] for r in records if r["amount"] < 0)
    print(f"总收入: {total_income:.2f}")
    print(f"总支出: {abs(total_expense):.2f}")
    print(f"结余:   {total_income + total_expense:.2f}")
前沿动态
2026 年 Python 编程领域的新变化：Python 3.13 引入了自由线程模式（Free-threading），解决了 GIL 限制多核并行的历史问题；AI 编程助手（GitHub Copilot、Cursor）让编程效率大幅提升，但理解代码逻辑的能力仍然不可替代；MicroPython 在物联网设备中广泛应用，中职学生可用 Python 控制传感器和硬件；自动化测试（pytest）和 CI/CD 已成为团队开发的基本要求；数据科学（pandas、matplotlib）和 Web 开发（FastAPI）是 Python 最热门的两个就业方向。

小结
编程能力的核心不在于记住语法细节，而在于掌握"分解问题 → 设计算法 → 编写代码 → 测试调试"的完整思维过程。Python 以其直观的语法降低了入门门槛，让学生能够快速将想法转化为可运行的程序。从简单的条件判断到文件自动化处理再到完整的小项目开发，每一步都在强化逻辑思维和动手能力——这是未来职业发展中最具迁移性的核心素养。
