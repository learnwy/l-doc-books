操作系统管理

知识要点

操作系统是硬件与应用软件之间的桥梁，负责管理计算机的全部资源。IT 运维岗位要求技术人员能够独立完成系统安装部署、驱动适配、性能调优和数据保护等全套操作。本节以 Windows 11 和 Linux（Ubuntu）双平台为主线，辅以虚拟化技术实训。

Windows 系统安装与配置

制作启动U盘：使用 Rufus 或微软官方 Media Creation Tool，将 Windows 11 ISO 写入 8GB 以上 U 盘，分区方案选择 GPT（适配 UEFI 启动）。

安装流程关键步骤：

  1. BIOS 中设置 U 盘为第一启动项
  2. 选择"自定义安装" → 删除旧分区 → 新建系统分区（建议 ≥100GB\geq 100\text{GB}≥100GB）
  3. 系统自动创建 EFI 分区（100MB）和恢复分区
  4. 完成 OOBE 初始设置：地区、键盘、网络、微软账户或本地账户
  5. 进入桌面后立即检查 Windows Update

驱动程序管理：Windows 11 能自动识别大部分硬件，但以下设备通常需要手动安装官方驱动：独立显卡（NVIDIA/AMD 官网下载）、声卡（Realtek）、网卡（特别是 Wi-Fi 6E 模块）。使用设备管理器检查是否有黄色感叹号标识的未识别设备。

Linux 系统安装（Ubuntu）

Ubuntu 是中职教学中最常用的 Linux 发行版，界面友好且社区支持完善。

双系统安装方案：先装 Windows 再装 Ubuntu，安装时选择"与 Windows 共存"选项，Ubuntu 安装程序会自动调整分区。建议为 Linux 分配至少 50GB 空间。

基础命令行操作：

命令 功能 示例
ls -la 列出目录详情 ls -la /home
cd 切换目录 cd /etc/nginx
sudo apt update 更新软件源 每次安装前执行
sudo apt install 安装软件包 sudo apt install vim
chmod 修改文件权限 chmod 755 script.sh
systemctl 管理系统服务 systemctl status ssh

系统性能优化

Windows 优化要点：

  • 关闭不必要的开机启动项（任务管理器 → 启动）
  • 调整视觉效果为"最佳性能"（大幅提升低配机响应速度）
  • 定期清理临时文件（%TEMP% 目录、磁盘清理工具）
  • SSD 用户关闭磁盘碎片整理、开启 TRIM

Linux 优化要点：

  • 使用 htop 监控 CPU 和内存占用
  • 通过 systemctl disable 关闭无用服务
  • 调整 swappiness 值（SSD 建议设为 10）：echo 'vm.swappiness=10' | sudo tee -a /etc/sysctl.conf

数据备份与还原

数据备份遵循 3-2-1 原则：至少 3 份副本、存储在 2 种不同介质上、其中 1 份保存在异地。

Windows 备份方案：

  • 系统映像备份：控制面板 → 备份和还原 → 创建系统映像
  • 文件历史记录：自动备份用户文件夹中的文档变更
  • 第三方工具：傲梅轻松备份（免费版）、Macrium Reflect

Linux 备份方案：

  • tar 命令打包关键目录：tar -czf backup.tar.gz /home /etc
  • rsync 增量同步到外部存储
  • Timeshift 工具：类似 Windows 系统还原点

虚拟化基础

虚拟化技术允许在一台物理机上同时运行多个操作系统，是 IT 运维人员的必备技能。

VirtualBox 实训步骤：

  1. 下载安装 VirtualBox（免费开源）
  2. 新建虚拟机 → 分配 CPU 核心（2核）和内存（4GB）
  3. 创建虚拟硬盘（VDI 格式，动态分配 50GB）
  4. 挂载 ISO 镜像 → 启动安装
  5. 安装增强功能包（Guest Additions）实现共享文件夹和剪贴板

VMware Workstation Player 操作类似，性能略优于 VirtualBox，但商业用途需要付费许可。

虚拟化的实际用途：搭建网络实验环境、测试软件兼容性、隔离恶意软件分析、快速部署多台服务器。

前沿动态

2026 年操作系统领域的新变化：Windows 11 深度集成 Copilot AI 助手，支持自然语言执行系统管理任务（如"帮我清理磁盘空间"）；Linux 内核 6.x 系列在桌面体验上持续进步，Steam Deck 带动游戏兼容层 Proton 成熟度大幅提升；容器化技术（Docker）从服务器延伸到桌面开发环境，WSL2（Windows Subsystem for Linux 2）让 Windows 用户无缝使用 Linux 工具链；云桌面（DaaS）在教育领域加速落地，学生可通过瘦客户端访问高性能云端系统。

练习与思考

  1. 在 VirtualBox 中分别安装 Windows 11 和 Ubuntu 24.04，配置共享文件夹实现双系统间文件传输，记录完整操作步骤。
  2. 对比 Windows 任务管理器和 Linux htop 命令，列出它们各自能显示哪些系统资源信息，有哪些功能差异。
  3. 某公司新入职员工电脑需要安装 Windows 11 + Office + 杀毒软件 + 业务系统客户端，请设计一套标准化部署方案，要求能在 30 分钟内完成一台。
  4. 模拟场景：某台电脑系统崩溃无法启动，但硬盘数据完好。请设计两种数据恢复方案（不重装系统的方式）。

小结

本节覆盖了 Windows 和 Linux 双平台的安装部署、驱动管理、性能优化与数据保护全流程，并通过虚拟化技术提供了安全的实验环境。操作系统管理能力是所有上层应用（办公、网络、开发）的运行基础，熟练掌握这些技能将直接提升日常运维效率和故障应对速度。
