计算机组成与装配

知识要点

计算机硬件组装是每位 IT 从业者的入门必修课。一台计算机由中央处理器（CPU）、内存（RAM）、主板、存储设备、显卡、电源、机箱及散热系统组成，各部件通过总线和接口协同工作。掌握每个部件的技术指标、选购要点和正确安装方法，是胜任计算机维修工岗位的第一步。

CPU 选型与安装

CPU 是计算机的运算核心。2026 年主流桌面平台为 Intel 第 14/15 代酷睿和 AMD Ryzen 7000/8000 系列。选型时关注以下参数：

参数 说明 选型建议
核心/线程数 并行处理能力 办公 4核8线程足够，设计/开发建议 8核以上
基础/睿频频率 单核性能指标 日常使用关注睿频，fboost≥4.5GHzf_{boost} \geq 4.5\text{GHz}fboost​≥4.5GHz 为佳
TDP 功耗 散热需求参考 65W 适合静音方案，125W+ 需要塔式散热器
插槽类型 与主板兼容性 LGA 1700（Intel）/ AM5（AMD）

安装步骤：打开主板 CPU 插槽压杆 → 对准防呆缺口放入 CPU → 压下固定杆 → 涂抹导热硅脂（米粒大小）→ 安装散热器并连接风扇供电线。

内存选型与安装

2026 年主流内存规格为 DDR5，频率从 4800MHz 到 8000MHz 不等。中职实训推荐配置：

  • 办公/学习用途：DDR5 4800MHz × 2（双通道 16GB）
  • 设计/开发用途：DDR5 5600MHz × 2（双通道 32GB）

内存条安装需对准防呆槽位，两端卡扣打开后垂直按入直至"咔嗒"锁定。双通道配置应插在相同颜色的插槽中（通常为第 2、4 槽）。

主板与存储设备

主板是连接所有部件的枢纽。选型要点：芯片组兼容性、扩展插槽数量（PCIe 5.0 x16 显卡槽、M.2 固态槽）、USB/网口接口规格、供电相数。

显卡与电源
独立显卡按需选配：纯办公可依赖核显，图形处理选择 NVIDIA RTX 4060 或 AMD RX 7600 级别。电源功率计算公式：


Precommended=(PCPU+PGPU+Pother)×1.3P_{recommended} = (P_{CPU} + P_{GPU} + P_{other}) \times 1.3Precommended​=(PCPU​+PGPU​+Pother​)×1.3
其中 PotherP_{other}Pother​ 包含主板、内存、风扇、硬盘等，通常估算为 80-120W。建议选择 80PLUS 铜牌以上认证的电源。


整机组装流程
标准组装顺序：①安装 CPU 和散热器到主板 → ②插入内存条 → ③将主板固定到机箱 → ④安装电源 → ⑤安装存储设备 → ⑥安装显卡 → ⑦连接所有供电线和数据线 → ⑧理线扎带整理 → ⑨接通电源首次点亮。


BIOS/UEFI 设置

前沿动态
2026 年硬件领域的关键趋势：DDR5 内存全面普及，PCIe 5.0 固态硬盘读写速度突破 12GB/s；AI 加速成为消费级硬件标配，Intel 和 AMD 的最新 CPU 均内置 NPU（神经网络处理单元）；模块化 PC 概念开始进入教育市场，如 Framework 笔记本允许用户自行更换 CPU 和 GPU 模块；散热技术方面，液态金属导热和半导体制冷片在高端平台获得应用。

小结
本节以实际岗位需求为导向，系统讲解了计算机各核心部件的技术参数、选型策略和标准化组装流程。重点掌握 CPU/内存/存储/显卡的兼容性匹配、规范的安装手法以及 BIOS 基础配置，为后续的系统部署和故障排除打下硬件层面的坚实基础。
