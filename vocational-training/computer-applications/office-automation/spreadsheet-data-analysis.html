电子表格与数据分析

知识要点

Excel 是职场中数据处理的第一工具。从简单的考勤统计到复杂的财务分析，从库存管理到销售预测，几乎所有需要处理数字的岗位都离不开电子表格。掌握函数运算、数据透视和图表展示三大能力，你就拥有了从海量数据中提取有价值信息的钥匙。

核心函数体系

查找引用类——解决"跨表取数据"问题：

=VLOOKUP(查找值, 查找范围, 返回列号, 匹配方式)

示例：根据工号从员工信息表中自动填入姓名

=VLOOKUP(A2, 员工表!A:C, 2, FALSE)

2026 年推荐使用更强大的替代函数 XLOOKUP：

=XLOOKUP(A2, 员工表!A:A, 员工表!B:B, "未找到")

条件判断类——实现自动分类和评级：

=IF(B2>=90, "优秀", IF(B2>=70, "良好", IF(B2>=60, "及格", "不及格")))

多条件计数/求和组合：

  • =COUNTIFS(部门列, "销售部", 业绩列, ">10000") —— 销售部业绩过万的人数
  • =SUMIFS(金额列, 月份列, "3月", 类型列, "收入") —— 3月总收入

数据透视表

数据透视表是 Excel 最强大的数据汇总工具，三步完成复杂的多维分析：

  1. 选中数据区域 → 插入 → 数据透视表
  2. 拖拽字段：行区域放分类维度（如"部门"），值区域放汇总指标（如"销售额"）
  3. 右键值字段 → 值字段设置 → 选择汇总方式（求和/平均值/计数）

进阶技巧：

  • 行区域放两个字段实现分组嵌套（如"地区→门店"）
  • 添加切片器实现可视化筛选交互
  • 值显示方式改为"占总计的百分比"进行占比分析

图表制作与数据可视化

选择图表类型的原则：

分析目的 推荐图表 适用场景
趋势变化 折线图 月度销售额走势
构成占比 饼图/环形图 费用结构分析
对比排名 柱状图/条形图 各部门业绩对比
相关关系 散点图 广告投入与销量关系
多维对比 雷达图 员工能力评估

图表美化要点：删除多余网格线、添加数据标签、使用统一配色方案、标题直接表达结论（如"华东区Q3销售额增长27%"优于"Q3销售数据"）。

数据验证与保护

数据验证（下拉列表）：数据 → 数据验证 → 序列 → 输入"男,女"——限制输入范围，减少录入错误。

条件格式：自动高亮异常数据。如标红所有 <60< 60<60 分的成绩：开始 → 条件格式 → 突出显示单元格规则 → 小于 → 输入 60。

工作表保护：审阅 → 保护工作表 → 设置密码。可选择允许用户编辑的区域（如只开放数据录入列，锁定公式列）。

VBA 宏初步

当某个操作需要重复执行数十次时，录制宏可以大幅提升效率：

视图 → 宏 → 录制宏 → 执行一遍操作 → 停止录制 → 后续按快捷键即可重复。

VBA 代码示例——批量重命名工作表：

Sub RenameSheets()
    Dim i As Integer
    For i = 1 To Sheets.Count
        Sheets(i).Name = "第" & i & "周"
    Next i
End Sub

前沿动态

2026 年电子表格领域的新发展：Excel 内置 Copilot 可通过自然语言生成公式和图表（如"帮我计算每个部门的平均工资并生成柱状图"）；Python in Excel 正式发布，允许在单元格中直接编写 Python 代码处理数据；Google Sheets 持续强化实时协作和 AI 辅助功能；国产办公软件 WPS 的智能数据分析功能在简单统计场景中已接近 Excel 水平；低代码平台（如飞书多维表格、Notion Database）正在部分替代简单的 Excel 数据管理场景。

练习与思考

  1. 下载一份包含 1000 条销售记录的练习数据集（含日期、地区、产品、金额字段），完成以下任务：用 SUMIFS 统计每个地区的季度销售额；创建数据透视表进行多维分析；制作仪表板式的图表组合。
  2. 设计一份班级成绩管理表：输入各科成绩后自动计算总分和平均分，自动判定等级（优/良/中/差），用条件格式标红不及格科目，生成班级成绩分布图。
  3. 录制一个宏，功能为：选中的数据区域自动添加边框、标题行加粗并填充蓝色背景、列宽自适应。然后查看生成的 VBA 代码，理解每行的含义。
  4. 对比 VLOOKUP 和 XLOOKUP 的优缺点，在什么场景下 XLOOKUP 明显优于 VLOOKUP？

小结

电子表格技能的价值在于将零散数据转化为可决策的信息。函数公式解决自动化计算问题，数据透视表解决多维汇总问题，图表解决可视化传达问题，VBA 解决重复操作问题。四项能力组合运用，即可应对绝大多数职场数据处理需求。关键在于多练——处理的数据越多样，对函数和工具的组合应用就越灵活。
