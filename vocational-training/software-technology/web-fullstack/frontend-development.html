前端开发

知识要点

前端开发是用户与软件系统交互的第一触点，直接影响产品体验和商业转化。现代前端已从"切图写样式"进化为工程化程度极高的技术领域，需要掌握 HTML5 语义化标签、CSS3 布局与动画、JavaScript 核心机制以及 Vue3 框架的组件化开发模式。

HTML5 语义化与结构

HTML5 引入的语义化标签让页面结构更清晰，同时提升了 SEO 和无障碍访问：

<header>
  <nav aria-label="主导航">
    <ul>
      <li><a href="/">首页</a></li>
      <li><a href="/courses">课程</a></li>
    </ul>
  </nav>
</header>
<main>
  <article>
    <h1>Vue3 组合式 API 入门</h1>
    <section>
      <h2>响应式数据</h2>
      <p>使用 ref 和 reactive 创建响应式状态...</p>
    </section>
  </article>
</main>
<footer>© 2026 软件技术学院</footer>

CSS3 布局与响应式设计

Flexbox 和 Grid 是现代 CSS 布局的两大支柱：

/* Flexbox — 一维布局 */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 0 2rem;
}

/* Grid — 二维布局 */
.dashboard {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 64px 1fr;
  min-height: 100vh;
}

/* 响应式断点 */
@media (max-width: 768px) {
  .dashboard {
    grid-template-columns: 1fr;
  }
}

CSS 自定义属性（变量）实现主题切换：

:root {
  --color-primary: #4f46e5;
  --color-bg: #ffffff;
}
[data-theme="dark"] {
  --color-primary: #818cf8;
  --color-bg: #1e1e2e;
}

JavaScript 核心机制

闭包、原型链、事件循环是理解 JavaScript 运行行为的三把钥匙：

// 闭包 — 函数记住创建时的词法环境
function createCounter(initial) {
  let count = initial;
  return {
    increment: () => ++count,
    getCount: () => count
  };
}
const counter = createCounter(0);
counter.increment(); // 1

// Promise 与 async/await
async function fetchUserData(userId) {
  try {
    const response = await fetch(`/api/users/${userId}`);
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    return await response.json();
  } catch (error) {
    console.error('获取用户数据失败:', error.message);
    throw error;
  }
}

ES Module 是现代 JavaScript 的模块化标准，Vite 利用浏览器原生 ESM 实现毫秒级热更新。

Vue3 组合式 API 与组件化

Vue3 的组合式 API（Composition API）通过 setup() 函数组织逻辑，替代了 Options API 的分散式代码组织：

<script setup>
import { ref, computed, onMounted } from 'vue'

const todos = ref([])
const newTodo = ref('')

const activeTodos = computed(() => 
  todos.value.filter(t => !t.completed)
)

function addTodo() {
  if (!newTodo.value.trim()) return
  todos.value.push({ 
    id: Date.now(), 
    text: newTodo.value, 
    completed: false 
  })
  newTodo.value = ''
}

onMounted(async () => {
  const res = await fetch('/api/todos')
  todos.value = await res.json()
})
</script>

<template>
  <div class="todo-app">
    <input v-model="newTodo" @keyup.enter="addTodo" placeholder="添加任务...">
    <ul>
      <li v-for="todo in activeTodos" :key="todo.id">
        {{ todo.text }}
      </li>
    </ul>
    <p>剩余 {{ activeTodos.length }} 项</p>
  </div>
</template>

组件通信方式：props 向下传递数据，emit 向上发送事件，provide/inject 跨层级共享状态，Pinia 管理全局状态。

小结
前端开发已从简单的页面编写发展为系统化的工程实践。HTML5 提供语义结构，CSS3 实现灵活布局与视觉表现，JavaScript 承载交互逻辑，Vue3 框架将这一切组织为可维护的组件树。掌握前端开发后，配合后端 API 即可构建完整的 Web 应用——这正是全栈工程师能力链条的前半段。
