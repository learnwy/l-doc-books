Java 程序设计

知识要点

Java 作为强类型、面向对象的编程语言，凭借"一次编写、到处运行"的跨平台特性和完善的生态体系，在企业级后端开发中占据主导地位。高职软件技术专业的 Java 课程从语法基础出发，逐步深入面向对象设计、集合与泛型、IO 操作、并发编程，最终过渡到 Spring Boot 快速开发框架。

面向对象编程核心

Java 的类与对象机制是整个语言的基石。封装、继承、多态三大特性决定了代码的组织方式：

public abstract class Shape {
    protected String color;
    
    public Shape(String color) {
        this.color = color;
    }
    
    public abstract double area();
    
    @Override
    public String toString() {
        return getClass().getSimpleName() + "(color=" + color + ", area=" + area() + ")";
    }
}

public class Circle extends Shape {
    private double radius;
    
    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }
    
    @Override
    public double area() {
        return Math.PI * radius * radius;
    }
}

接口与抽象类的区别在于：接口定义行为契约（implements），抽象类提供部分实现（extends）。Java 8 之后接口可包含 default 方法，模糊了两者的界限但各自的设计语义仍然不同。

集合框架与泛型

Java 集合框架分为 Collection（List、Set、Queue）和 Map 两大体系：

接口 常用实现 特性 时间复杂度
List ArrayList 随机访问快 get O(1)O(1)O(1), add O(n)O(n)O(n)
List LinkedList 插入删除快 get O(n)O(n)O(n), add O(1)O(1)O(1)
Set HashSet 无序去重 add/contains O(1)O(1)O(1)
Map HashMap 键值对存储 get/put O(1)O(1)O(1)
Map TreeMap 有序键值对 get/put O(log⁡n)O(\log n)O(logn)

泛型通过类型参数化避免了强制类型转换，编译期即可发现类型错误：

List<String> names = new ArrayList<>();
names.add("Spring");
// names.add(123); // 编译错误，类型安全

IO 与 NIO

传统 IO 基于字节流（InputStream/OutputStream）和字符流（Reader/Writer），采用阻塞式模型。NIO 引入 Channel、Buffer、Selector 三组件，支持非阻塞多路复用：

// NIO 文件读取
Path path = Path.of("data.txt");
List<String> lines = Files.readAllLines(path, StandardCharsets.UTF_8);

多线程与并发

Java 并发编程的核心概念包括线程生命周期、同步机制和线程池：

ExecutorService pool = Executors.newFixedThreadPool(4);
Future<Integer> future = pool.submit(() -> {
    // 耗时计算
    return computeResult();
});
Integer result = future.get(); // 阻塞获取结果

synchronized 关键字和 ReentrantLock 解决临界区互斥问题；volatile 保证变量可见性；ConcurrentHashMap 提供线程安全的高性能 Map 实现。

Spring Boot 初步

Spring Boot 通过"约定优于配置"思想极大降低了企业级应用的搭建门槛：

@RestController
@RequestMapping("/api/users")
public class UserController {
    
    @Autowired
    private UserService userService;
    
    @GetMapping("/{id}")
    public ResponseEntity<User> getUser(@PathVariable Long id) {
        return ResponseEntity.ok(userService.findById(id));
    }
}

Spring Boot Starter 机制将常用功能（Web、JPA、Security）封装为开箱即用的依赖包，开发者只需在 pom.xml 或 build.gradle 中引入即可。

前沿动态

2026 年 Java 生态的主要演进方向：

  • Java 23/24 LTS：虚拟线程（Virtual Threads）正式进入 LTS 版本，彻底改变了 Java 并发编程模型，百万级并发连接不再需要响应式框架
  • GraalVM Native Image：Spring Boot 3.x 原生支持 AOT 编译，启动时间降至毫秒级，容器化部署更轻量
  • AI 辅助 Java 开发：Copilot 和 Cursor 可自动生成 CRUD 代码、单元测试和文档注释，开发者角色从"逐行编码"转向"设计与审查"
  • Project Loom + Structured Concurrency：结构化并发 API 让异步代码像同步代码一样易读易调试

练习与思考

  1. 设计一个图书管理系统的类层次：Book、EBook、AudioBook 继承自抽象类，实现 Searchable 接口。要求使用泛型集合存储图书，并提供按书名和 ISBN 两种查找方式。

  2. 使用 CompletableFuture 实现并行调用三个外部 API（获取用户信息、订单列表、推荐商品），将结果聚合为一个 DTO 返回。对比串行调用与并行调用的耗时差异。

  3. 创建一个 Spring Boot 项目，实现用户注册登录的 RESTful API，要求使用分层架构（Controller → Service → Repository），并编写至少 3 个单元测试。

小结

Java 程序设计是软件技术专业的第一门核心课程。面向对象设计赋予代码良好的结构和可维护性；集合与泛型提供了类型安全的数据操作手段；IO/NIO 和多线程解决了实际应用中的性能与并发需求；Spring Boot 则将这些能力整合为可快速交付的企业级应用。掌握 Java 编程后，后续的 Web 开发、微服务架构、软件测试等课程都将建立在这一基础之上。
