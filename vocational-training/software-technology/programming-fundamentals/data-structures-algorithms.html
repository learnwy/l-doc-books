数据结构与算法

知识要点

数据结构与算法是计算机科学的核心素养，直接决定了程序的运行效率和可扩展性。对于高职软件技术专业的学生而言，掌握常用数据结构的实现原理和典型算法的设计思路，既能提升日常编码质量，也为技术面试和系统设计奠定基础。

线性结构

线性表是最基本的数据结构，元素按顺序排列，每个元素最多有一个前驱和一个后继。

数组（Array） 在内存中连续存储，支持 O(1)O(1)O(1) 随机访问，但插入和删除需要移动元素，平均时间复杂度 O(n)O(n)O(n)。

链表（Linked List） 通过指针连接节点，插入删除为 O(1)O(1)O(1)（已知位置），但随机访问需 O(n)O(n)O(n) 遍历：

public class ListNode {
    int val;
    ListNode next;
    
    public ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}

// 反转链表 — 经典面试题
public ListNode reverse(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}

栈与队列

栈（Stack） 遵循后进先出（LIFO）原则，典型应用包括括号匹配、表达式求值、函数调用栈：

// 括号匹配
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') stack.push(')');
        else if (c == '[') stack.push(']');
        else if (c == '{') stack.push('}');
        else if (stack.isEmpty() || stack.pop() != c) return false;
    }
    return stack.isEmpty();
}

队列（Queue） 遵循先进先出（FIFO）原则，BFS 遍历、任务调度、消息队列都基于此结构。优先队列（PriorityQueue）底层为堆结构，出队时间 O(log⁡n)O(\log n)O(logn)。

树结构

二叉搜索树（BST）满足左子树所有节点值小于根，右子树所有节点值大于根。查找、插入的平均时间复杂度为 O(log⁡n)O(\log n)O(logn)，最坏退化为 O(n)O(n)O(n)。

平衡二叉树（AVL）和红黑树通过旋转操作保证树高度为 O(log⁡n)O(\log n)O(logn)，Java 的 TreeMap 底层即为红黑树实现。

快速排序的核心思想是分治——选取基准元素，将数组分为两部分递归排序：


public void quickSort(int[] arr, int lo, int hi) {
    if (lo >= hi) return;
    int pivot = arr[lo + (hi - lo) / 2];
    int i = lo, j = hi;
    while (i <= j) {
        while (arr[i] < pivot) i++;
        while (arr[j] > pivot) j--;
        if (i <= j) {
            int tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp;
            i++; j--;
        }
    }
    quickSort(arr, lo, j);
    quickSort(arr, i, hi);
}
查找算法与复杂度分析
二分查找要求数据有序，每次将搜索范围缩小一半，时间复杂度 O(log⁡n)O(\log n)O(logn)。哈希查找通过散列函数直接定位，平均 O(1)O(1)O(1)，但需处理冲突。


算法复杂度使用大 O 表示法描述增长趋势：


    

  • 常数 O(1)O(1)O(1)：数组下标访问
    • 

  • 对数 O(log⁡n)O(\log n)O(logn)：二分查找
    • 

  • 线性 O(n)O(n)O(n)：遍历
    • 

  • 线性对数 O(nlog⁡n)O(n \log n)O(nlogn)：高效排序
    • 

  • 平方 O(n2)O(n^2)O(n2)：嵌套循环

小结
数据结构与算法的核心价值在于教会开发者"如何高效地组织和处理数据"。线性结构解决顺序存取问题，树结构解决层次化检索问题，排序与查找算法是几乎所有业务逻辑的底层构建块。理解复杂度分析后，才能在实际工程中做出正确的数据结构选型决策——这是从"能写代码"到"写好代码"的关键跨越。
