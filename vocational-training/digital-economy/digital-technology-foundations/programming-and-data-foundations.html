编程与数据基础

知识要点

Python 已成为数字经济领域数据处理与分析的通用语言，其简洁语法和丰富生态使得非计算机背景的学生也能快速上手，将商业直觉转化为可执行的数据操作流程。本节从 Python 基础语法出发，逐步建立面向数据处理的编程能力体系。

NumPy 向量化计算

当数据量级从千级跃升到百万级，逐行循环处理将面临严重的性能瓶颈。NumPy 通过底层 C 语言实现的向量化运算，将计算效率提升 101010-100100100 倍。

核心概念是 ndarray（N维数组），支持广播（broadcasting）机制：

Revenue=Price×Quantity=p⃗⋅q⃗\text{Revenue} = \text{Price} \times \text{Quantity} = \vec{p} \cdot \vec{q}Revenue=Price×Quantity=p​⋅q​
import numpy as np

prices = np.array([29.9, 59.9, 99.0, 199.0])
quantities = np.array([1000, 500, 300, 100])
revenue = prices * quantities  # 向量化运算，无需循环
total = np.sum(revenue)        # 总收入

NumPy 的切片与布尔索引在数据清洗中极为实用：

# 过滤异常值：价格 > 0 且 < 10000
valid_mask = (prices > 0) & (prices < 10000)
clean_prices = prices[valid_mask]

实战案例：电商数据清洗流水线
将以上知识整合为一个完整的数据处理流水线：


import pandas as pd
import numpy as np

def clean_ecommerce_data(filepath):
    """电商数据清洗标准流程"""
    df = pd.read_csv(filepath)
    
    # 1. 去除完全重复行
    df = df.drop_duplicates()
    
    # 2. 处理缺失值
    df["category"].fillna("未分类", inplace=True)
    df = df.dropna(subset=["user_id", "amount"])
    
    # 3. 类型转换与异常值处理
    df["amount"] = pd.to_numeric(df["amount"], errors="coerce")
    df = df[(df["amount"] > 0) & (df["amount"] < 100000)]
    
    # 4. 时间字段标准化
    df["order_time"] = pd.to_datetime(df["order_time"])
    
    return df
前沿动态
2026 年 Python 生态的重要演进对数字经济从业者影响深远。Polars 作为新一代 DataFrame 库，在大数据集处理上性能超越 Pandas 数倍，其惰性计算（Lazy Evaluation）模式特别适合处理 GB 级的交易流水数据。DuckDB 嵌入式数据库允许直接在 Python 中使用 SQL 查询 CSV/Parquet 文件，模糊了编程与数据库的边界。


Jupyter AI 的发布使得数据分析师可以用自然语言描述需求，由 LLM 生成 Pandas 代码并自动执行。这不会取代编程能力——你需要能够审查和修正生成的代码——但它极大加速了探索性数据分析的效率。


Python 3.13 引入的自由线程（Free-threading）模式，有望解决 GIL 限制下多核并行处理的性能瓶颈，对大规模数据 ETL 任务意义重大。
