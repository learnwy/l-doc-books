Python 编程与数据处理

知识要点

Python 凭借其简洁语法和丰富的数据科学生态，已成为数字经济领域最主流的编程语言。掌握 Python 编程与数据处理能力，是数字经济专业学生进入数据分析、机器学习和自动化运营的第一道门槛。

基础语法与数据结构

Python 的核心数据结构包括列表（list）、字典（dict）、元组（tuple）和集合（set）。理解它们的时间复杂度差异是高效编程的前提：

  • 列表索引访问 O(1)O(1)O(1)，插入/删除 O(n)O(n)O(n)
  • 字典查找/插入/删除均为 O(1)O(1)O(1)（哈希表实现）
  • 集合支持 O(1)O(1)O(1) 的成员判断，适合去重与交集运算
# 字典推导式：快速构建映射
sales_data = {"北京": 1200, "上海": 1500, "深圳": 980}
high_sales = {city: val for city, val in sales_data.items() if val > 1000}

函数式编程与模块化

数据处理管道通常由多个转换步骤组成，函数式风格可以提升代码的可读性和可测试性：

from functools import reduce

transactions = [100, -50, 200, -30, 150]
# 累计余额计算
balances = list(accumulate(transactions))

Lambda 表达式配合 map()、filter() 可以构造简洁的数据转换链。但当逻辑复杂时，应优先使用具名函数以保持可维护性。

NumPy 向量化计算

NumPy 的 ndarray 通过连续内存布局和 SIMD 指令实现高效计算。向量化操作比 Python 原生循环快 10-100 倍：

import numpy as np

# 计算收益率
prices = np.array([100, 105, 103, 110, 108])
returns = np.diff(prices) / prices[:-1]  # 向量化除法

关键概念包括广播（broadcasting）机制：当两个数组形状不同时，NumPy 自动扩展较小维度：

shape(3,1)+shape(1,4)→shape(3,4)\text{shape}(3,1) + \text{shape}(1,4) \rightarrow \text{shape}(3,4)shape(3,1)+shape(1,4)→shape(3,4)

Pandas 数据分析

Pandas 的 DataFrame 是结构化数据处理的核心工具。典型的数据清洗流程包括：

  1. 缺失值处理：dropna()、fillna(method='ffill')
  2. 类型转换：astype()、pd.to_datetime()
  3. 数据聚合：groupby().agg()
  4. 透视表：pivot_table(values, index, columns, aggfunc)
import pandas as pd

df = pd.read_csv("ecommerce_orders.csv")
# 按月份统计各品类销售额
monthly_sales = df.groupby([df['date'].dt.to_period('M'), 'category'])['amount'].sum()

数据处理管道设计

实际项目中，数据处理通常形成多步骤管道。良好的管道设计应遵循：输入输出明确、步骤可独立测试、错误可追溯。

小结
Python 编程与数据处理是数字经济专业的技术基石。从基础语法到 NumPy/Pandas 生态，学生需要建立"数据即资产、代码即工具"的思维模式，通过反复的实操练习将编程能力内化为解决经济问题的核心手段。
