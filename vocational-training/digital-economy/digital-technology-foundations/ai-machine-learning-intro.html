人工智能与机器学习导论

知识要点

人工智能（AI）正在深刻改变数字经济的各个领域——从智能推荐到风控反欺诈，从自动定价到供应链预测。理解机器学习的基本原理和应用范式，是数字经济专业学生的必备素养。

机器学习基本范式

机器学习按照学习方式分为三大范式：

范式 数据要求 典型任务 数字经济应用
监督学习 标注数据 分类、回归 信用评分、销量预测
无监督学习 无标注 聚类、降维 用户分群、异常检测
强化学习 环境反馈 序列决策 动态定价、广告投放

监督学习：回归与分类

线性回归是最基础的监督学习算法，通过最小化损失函数拟合数据：

y^=w0+w1x1+w2x2+⋯+wnxn\hat{y} = w_0 + w_1 x_1 + w_2 x_2 + \cdots + w_n x_ny^​=w0​+w1​x1​+w2​x2​+⋯+wn​xn​

损失函数采用均方误差（MSE）：

L(w)=1m∑i=1m(yi−y^i)2L(w) = \frac{1}{m} \sum_{i=1}^{m} (y_i - \hat{y}_i)^2L(w)=m1​i=1∑m​(yi​−y^​i​)2

梯度下降法通过迭代更新参数：

wj:=wj−α∂L∂wjw_j := w_j - \alpha \frac{\partial L}{\partial w_j}wj​:=wj​−α∂wj​∂L​

其中 α\alphaα 为学习率，控制每次更新的步长。

逻辑回归用于分类任务，通过 Sigmoid 函数将输出映射到 [0,1][0,1][0,1] 区间：

P(y=1∣x)=11+e−(wTx+b)P(y=1|x) = \frac{1}{1 + e^{-(w^T x + b)}}P(y=1∣x)=1+e−(wTx+b)1​

决策树与集成学习

决策树通过信息增益或基尼不纯度选择最优分割特征。单棵决策树容易过拟合，集成方法通过组合多棵树提升泛化能力：

  • 随机森林：Bagging + 特征随机采样，降低方差
  • XGBoost/LightGBM：Boosting 策略，逐步修正残差，在结构化数据竞赛中表现卓越
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

model = RandomForestClassifier(n_estimators=100, max_depth=10)
scores = cross_val_score(model, X_train, y_train, cv=5, scoring='f1')

模型评估与调优
评估指标的选择取决于业务场景：


    

  • 准确率（Accuracy）：适合类别均衡的场景
    • 

  • 精确率/召回率：适合正负样本不平衡（如欺诈检测）
    • 

  • AUC-ROC：综合评估模型排序能力
    • 

  • RMSE：回归任务的标准度量
    •

大语言模型与数字经济
2024-2026 年，大语言模型（LLM）为数字经济带来新的应用范式：


    

  • 智能客服与对话式商务
    • 

  • 自动化报告生成与商业分析
    • 

  • Prompt Engineering 作为新兴技能纳入数字经济课程体系
    • 

  • RAG（检索增强生成）在企业知识管理中的广泛应用
    • 



前沿动态
    

  • 2026 年多模态大模型（GPT-5、Claude 4）能力边界持续扩展，Agent 自主完成复杂商业分析
    • 

  • AutoML 工具（AutoGluon、H2O）使非专业人员也能构建生产级模型
    • 

  • 联邦学习在金融数据合规场景中落地加速，解决"数据可用不可见"难题
    • 

  • AI 能耗问题引发行业对高效推理（量化、蒸馏）的持续投入
    • 

  • 各国 AI 监管法规（EU AI Act、中国算法备案）对模型部署提出合规要求
    •

小结
人工智能与机器学习为数字经济提供了从数据到智能决策的核心技术路径。从经典的监督学习到深度学习再到大语言模型，算法能力的边界不断扩展。数字经济专业学生应建立"理解原理→选择方法→评估效果→合规部署"的系统思维，将 AI 作为解决经济问题的高效工具。
