光栅化与片段处理

核心概念

光栅化（Rasterization）是将几何图元（三角形、线段、点）转化为离散片段（Fragment）的过程，是连接几何处理和像素处理的桥梁。每个片段对应屏幕上的一个潜在像素，携带插值后的顶点属性数据。片段着色器随后对每个片段进行光照计算、纹理采样等操作，最终确定其颜色值。

光栅化阶段的核心挑战在于效率：一个全屏三角形可能覆盖数百万像素，而每个像素都需要执行片段着色器。因此，尽早丢弃不可见的片段是优化的关键。


光栅化算法与边方程
现代 GPU 使用基于边方程（Edge Function）的并行光栅化算法。对于三角形的三条边，每条边定义一个半平面方程，一个点如果同时位于三条边的正半平面内，则该点在三角形内部。


边方程的数学表达为：


E(x, y) = (x - x₀)(y₁ - y₀) - (y - y₀)(x₁ - x₀)


当 E > 0 时点在边的左侧（内侧），E = 0 时点在边上，E < 0 时点在边的右侧（外侧）。


interface Edge {
  x0: number;
  y0: number;
  x1: number;
  y1: number;
}

function edgeFunction(edge: Edge, px: number, py: number): number {
  return (px - edge.x0) * (edge.y1 - edge.y0) - (py - edge.y0) * (edge.x1 - edge.x0);
}

function rasterizeTriangle(
  v0: [number, number],
  v1: [number, number],
  v2: [number, number],
  width: number,
  height: number,
): Array<{ x: number; y: number; bary: [number, number, number] }> {
  const fragments: Array<{ x: number; y: number; bary: [number, number, number] }> = [];

  const minX = Math.max(0, Math.floor(Math.min(v0[0], v1[0], v2[0])));
  const maxX = Math.min(width - 1, Math.ceil(Math.max(v0[0], v1[0], v2[0])));
  const minY = Math.max(0, Math.floor(Math.min(v0[1], v1[1], v2[1])));
  const maxY = Math.min(height - 1, Math.ceil(Math.max(v0[1], v1[1], v2[1])));

  const area = edgeFunction({ x0: v0[0], y0: v0[1], x1: v1[0], y1: v1[1] }, v2[0], v2[1]);

  for (let y = minY; y <= maxY; y++) {
    for (let x = minX; x <= maxX; x++) {
      const px = x + 0.5;
      const py = y + 0.5;

      const w0 = edgeFunction({ x0: v1[0], y0: v1[1], x1: v2[0], y1: v2[1] }, px, py);
      const w1 = edgeFunction({ x0: v2[0], y0: v2[1], x1: v0[0], y1: v0[1] }, px, py);
      const w2 = edgeFunction({ x0: v0[0], y0: v0[1], x1: v1[0], y1: v1[1] }, px, py);

      if (w0 >= 0 && w1 >= 0 && w2 >= 0) {
        fragments.push({
          x,
          y,
          bary: [w0 / area, w1 / area, w2 / area],
        });
      }
    }
  }
  return fragments;
}
这段代码演示了软光栅化中的基本三角形遍历。实际 GPU 使用 Tile-Based 遍历和层次化测试加速这一过程，以 8×8 或 16×16 的块为单位批量测试，大幅减少逐像素计算量。


重心坐标（Barycentric Coordinates）不仅用于内外判定，还用于对顶点属性进行插值。片段的任何属性值都可以通过三个顶点值的重心加权得到。


深度测试与 Early-Z 优化
深度测试（Depth Test）是确定片段可见性的核心机制。每个片段都有一个深度值，与深度缓冲中已有的值比较，决定是否更新颜色缓冲。


Early-Z 是一项关键优化：在片段着色器执行前进行深度测试，提前丢弃不可见的片段，避免无效的着色计算。但以下情况会导致 Early-Z 失效：

为了最大化 Early-Z 的收益，应当从前向后（Front-to-Back）排序不透明物体。距离相机最近的物体先绘制，其深度值写入深度缓冲后，后续被遮挡的物体在 Early-Z 阶段直接被丢弃。


预深度 Pass（Depth Pre-pass / Z-Prepass）是另一种常用优化：先用极简着色器只写入深度缓冲，不做任何颜色计算；随后在正式渲染 Pass 中使用 depthCompare: 'equal'，只对恰好可见的片段执行复杂着色。这在片段着色器非常昂贵的场景（如 PBR 光照）下效果显著。


片段着色器与纹理采样
片段着色器是逐片段执行的可编程阶段，负责计算最终的颜色输出。它接收光栅化阶段插值后的顶点属性，执行纹理采样、光照计算、法线映射等操作。


纹理采样是片段着色器中最常用的操作。GPU 的纹理单元（Texture Unit）提供硬件加速的采样和过滤功能：

Mipmap 是预计算的纹理分辨率金字塔，GPU 根据片段覆盖的纹理区域面积自动选择合适的 Mipmap 等级。这既减少了纹理走样，也提高了纹理缓存命中率。


#version 450

layout(set = 0, binding = 0) uniform sampler2D albedoMap;
layout(set = 0, binding = 1) uniform sampler2D normalMap;
layout(set = 0, binding = 2) uniform sampler2D roughnessMetallicMap;

layout(location = 0) in vec3 fragWorldPos;
layout(location = 1) in vec3 fragNormal;
layout(location = 2) in vec2 fragTexCoord;
layout(location = 3) in mat3 fragTBN;

layout(location = 0) out vec4 outColor;

layout(set = 1, binding = 0) uniform LightData {
    vec3 lightDir;
    vec3 lightColor;
    vec3 cameraPos;
};

void main() {
    vec3 albedo = texture(albedoMap, fragTexCoord).rgb;
    vec3 normalTS = texture(normalMap, fragTexCoord).rgb * 2.0 - 1.0;
    vec3 N = normalize(fragTBN * normalTS);
    vec2 rm = texture(roughnessMetallicMap, fragTexCoord).rg;

    vec3 L = normalize(-lightDir);
    vec3 V = normalize(cameraPos - fragWorldPos);
    vec3 H = normalize(L + V);

    float NdotL = max(dot(N, L), 0.0);
    float NdotH = max(dot(N, H), 0.0);

    vec3 diffuse = albedo * NdotL * lightColor;
    float spec = pow(NdotH, mix(8.0, 256.0, 1.0 - rm.r));
    vec3 specular = lightColor * spec * rm.g;

    outColor = vec4(diffuse + specular, 1.0);
}
这个片段着色器演示了法线贴图和简化 PBR 光照的结合使用。法线贴图中的切线空间法线通过 TBN 矩阵转换到世界空间后参与光照计算，使得低多边形模型也能呈现丰富的表面细节。


抗锯齿技术
光栅化生成的图像本质上是离散采样的结果，不可避免地产生锯齿（Aliasing）。抗锯齿（Anti-Aliasing）技术通过不同方式减轻这一问题。

MSAA（Multi-Sample Anti-Aliasing）在光栅化阶段对每个像素生成多个采样点，但只执行一次片段着色器。覆盖率信息决定了采样点的颜色混合比例。在 WebGPU 中启用 MSAA：


const msaaTexture = device.createTexture({
  size: [canvas.width, canvas.height],
  format: presentationFormat,
  sampleCount: 4,
  usage: GPUTextureUsage.RENDER_ATTACHMENT,
});

const renderPassDescriptor: GPURenderPassDescriptor = {
  colorAttachments: [
    {
      view: msaaTexture.createView(),
      resolveTarget: context.getCurrentTexture().createView(),
      loadOp: 'clear',
      storeOp: 'discard',
      clearValue: { r: 0, g: 0, b: 0, a: 1 },
    },
  ],
};
TAA（Temporal Anti-Aliasing）已成为现代游戏引擎的主流选择。它通过在连续帧之间应用亚像素级抖动（Jitter），并将历史帧与当前帧进行指数加权混合，实现超采样效果。TAA 的关键挑战在于运动向量的准确性和 Ghosting 伪影的抑制。


小结
    

  • 光栅化通过边方程将三角形转化为离散片段，重心坐标用于属性插值
    • 

  • Early-Z 优化可在片段着色前丢弃不可见片段，前向后排序和 Z-Prepass 是关键策略
    • 

  • 片段着色器执行纹理采样和光照计算，法线贴图通过 TBN 矩阵实现切线空间变换
    • 

  • Mipmap 和各向异性过滤平衡纹理质量与性能
    • 

  • 抗锯齿技术从硬件 MSAA 发展到后处理 FXAA/SMAA，TAA 已成为现代引擎的标配
    • 

  • 光栅化阶段的优化核心是尽早丢弃不可见片段，减少片段着色器的执行次数
