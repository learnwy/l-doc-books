顶点处理与变换

核心概念

顶点处理是渲染管线中最前端的 GPU 可编程阶段，负责将输入的顶点数据进行坐标变换、属性计算和数据传递。顶点着色器对每个顶点独立运行，执行从模型空间到裁剪空间的变换，同时计算光照所需的法线、切线等属性并传递给后续阶段。

顶点处理阶段的效率由顶点数量和每顶点的计算复杂度共同决定。在现代 GPU 上，顶点着色器的执行速度通常远快于片段着色器，但当场景包含数百万顶点时，顶点处理仍然可能成为瓶颈。


顶点属性与缓冲区布局
顶点数据由多个属性（Attribute）组成，常见的包括位置、法线、纹理坐标、切线、骨骼权重等。这些属性在显存中的排列方式对缓存命中率和带宽利用率有直接影响。


顶点缓冲区有两种常见的布局方式：交错布局（Interleaved）和分离布局（Separate）。

在 WebGPU 中，配置交错顶点布局：


const vertexBufferLayout: GPUVertexBufferLayout = {
  arrayStride: 44,

    { shaderLocation: 2, offset: 24, format: 'float32x2' },
    { shaderLocation: 3, offset: 32, format: 'float32x3' },

索引缓冲区（Index Buffer）通过复用顶点数据避免重复存储。一个立方体如果不使用索引缓冲需要 36 个顶点（6面 × 2三角形 × 3顶点），而使用索引缓冲只需要 8 个唯一顶点加上 36 个索引值，显著降低显存占用和带宽消耗。


顶点获取阶段还支持基地址偏移（Base Vertex）和实例偏移（Base Instance），这使得多个网格可以共享同一个大顶点缓冲，通过不同的偏移量来索引各自的数据，从而减少缓冲切换次数。


顶点着色器编程模型
顶点着色器是最基础也是最重要的可编程着色器阶段。它对每个顶点独立执行，不能访问相邻顶点的信息。这种无依赖的执行模型使得 GPU 能够完全并行处理所有顶点。


顶点着色器的典型职责包括：MVP 坐标变换、法线和切线变换、骨骼蒙皮动画计算、纹理坐标生成或变换、逐顶点光照计算（Gouraud Shading）等。


#version 450

layout(set = 0, binding = 0) uniform SceneUniforms {
    mat4 viewProjection;
    vec3 cameraPos;
    float time;
};

layout(set = 1, binding = 0) uniform ObjectUniforms {
    mat4 model;
    mat4 normalMatrix;
};

layout(location = 0) in vec3 inPosition;
layout(location = 1) in vec3 inNormal;
layout(location = 2) in vec2 inTexCoord;
layout(location = 3) in vec3 inTangent;

layout(location = 0) out vec3 fragWorldPos;
layout(location = 1) out vec3 fragNormal;
layout(location = 2) out vec2 fragTexCoord;
layout(location = 3) out mat3 fragTBN;

void main() {
    vec4 worldPos = model * vec4(inPosition, 1.0);
    fragWorldPos = worldPos.xyz;

    vec3 N = normalize(mat3(normalMatrix) * inNormal);
    vec3 T = normalize(mat3(model) * inTangent);
    T = normalize(T - dot(T, N) * N);
    vec3 B = cross(N, T);
    fragTBN = mat3(T, B, N);

    fragNormal = N;
    fragTexCoord = inTexCoord;
    gl_Position = viewProjection * worldPos;
}
这个着色器演示了 TBN 矩阵（Tangent-Bitangent-Normal）的构建过程。TBN 矩阵用于将法线贴图中的切线空间法线转换到世界空间，是法线贴图技术的核心。Gram-Schmidt 正交化过程（T = normalize(T - dot(T, N) * N)）确保切线与法线严格正交。


曲面细分着色器
曲面细分（Tessellation）是在管线中动态增加几何细节的技术。它由三个子阶段组成：曲面细分控制着色器（TCS / Hull Shader）、固定功能曲面细分器（Tessellator）和曲面细分求值着色器（TES / Domain Shader）。


曲面细分的关键参数是细分因子（Tessellation Factor），它控制每条边被分割成多少段。在实际应用中，常根据距离相机的远近动态调整细分等级，实现 LOD（Level of Detail）效果：


#version 450

layout(vertices = 3) out;

layout(set = 0, binding = 0) uniform TessParams {
    vec3 cameraPos;
    float maxTessLevel;
    float minTessLevel;
    float maxDistance;
    float minDistance;
};

layout(location = 0) in vec3 inWorldPos[];
layout(location = 0) out vec3 outWorldPos[];

float calcTessLevel(vec3 pos) {
    float dist = distance(cameraPos, pos);
    float t = clamp((dist - minDistance) / (maxDistance - minDistance), 0.0, 1.0);
    return mix(maxTessLevel, minTessLevel, t);
}

void main() {
    outWorldPos[gl_InvocationID] = inWorldPos[gl_InvocationID];

    if (gl_InvocationID == 0) {
        vec3 mid01 = (inWorldPos[0] + inWorldPos[1]) * 0.5;
        vec3 mid12 = (inWorldPos[1] + inWorldPos[2]) * 0.5;
        vec3 mid20 = (inWorldPos[2] + inWorldPos[0]) * 0.5;

        gl_TessLevelOuter[0] = calcTessLevel(mid12);
        gl_TessLevelOuter[1] = calcTessLevel(mid20);
        gl_TessLevelOuter[2] = calcTessLevel(mid01);
        gl_TessLevelInner[0] = max(
            gl_TessLevelOuter[0],
            max(gl_TessLevelOuter[1], gl_TessLevelOuter[2])
        );
    }
}
曲面细分常用于地形渲染和角色模型的动态 LOD。对于地形，可以配合位移贴图（Displacement Map）在 Domain Shader 中沿法线偏移顶点位置，以极低的基础网格生成丰富的几何细节。


几何着色器与图元生成
几何着色器在曲面细分之后、光栅化之前执行，它以完整的图元（点、线、三角形）为输入，可以生成零个或多个新图元。虽然几何着色器功能强大，但由于其串行执行特性和对 GPU 并行性的影响，在现代渲染中应谨慎使用。


几何着色器的典型应用包括：线框渲染叠加、公告板（Billboard）生成、阴影体（Shadow Volume）挤出、法线/切线可视化调试等。


#version 450

layout(triangles) in;
layout(line_strip, max_vertices = 6) out;

layout(set = 0, binding = 0) uniform DebugParams {
    mat4 viewProjection;
    float normalLength;
};

layout(location = 0) in vec3 inNormal[];
layout(location = 0) out vec3 outColor;

void main() {
    for (int i = 0; i < 3; i++) {
        vec3 pos = gl_in[i].gl_Position.xyz;

        gl_Position = viewProjection * vec4(pos, 1.0);
        outColor = vec3(0.0, 1.0, 0.0);
        EmitVertex();

        gl_Position = viewProjection * vec4(pos + inNormal[i] * normalLength, 1.0);
        outColor = vec3(1.0, 0.0, 0.0);
        EmitVertex();

        EndPrimitive();
    }
}
在现代渲染实践中，几何着色器正逐渐被 Compute Shader + 间接绘制（Indirect Draw）方案替代。Mesh Shader（DirectX 12 Ultimate / Vulkan）更进一步，将顶点处理和图元生成统一到一个可编程阶段，提供更灵活的并行控制和更高的几何吞吐量。

小结
    

  • 顶点处理是 GPU 管线最前端的可编程阶段，对每个顶点独立并行执行
    • 

  • 交错布局更利于缓存命中，索引缓冲通过复用顶点显著降低显存占用
    • 

  • 顶点着色器负责 MVP 变换和 TBN 矩阵构建，是法线贴图等技术的基础
    • 

  • 曲面细分通过动态细分因子实现距离自适应的 LOD，适用于地形和角色模型
    • 

  • 几何着色器功能强大但并行性低，正逐步被 Compute Shader 和 Mesh Shader 替代
    • 

  • 现代 GPU 架构趋向统一可编程模型，Mesh Shader 代表了顶点处理的未来方向
    •
