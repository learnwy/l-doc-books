全局光照

核心概念

全局光照（Global Illumination, GI）模拟光线在场景中多次反弹的效果，包括间接光照、颜色渗透（Color Bleeding）和环境遮蔽等。与仅计算光源直接照射的局部光照不同，全局光照考虑了光子在物体表面之间的多次散射，是实现照片级真实感渲染的关键。在游戏中，全局光照的挑战在于将这种本质上非常昂贵的计算在实时帧率下近似实现。

实时全局光照的核心思路是在不同层面进行近似：用预计算捕捉静态场景的 GI 信息，用低分辨率探针或体积结构存储空间变化的间接光照，用屏幕空间方法补充动态对象的 GI 贡献。


环境遮蔽
环境遮蔽（Ambient Occlusion, AO）是全局光照中最简单但视觉效果最显著的分量，描述了场景中每个点接收环境光的程度。凹角、缝隙和物体接触面处 AO 值较低（较暗），暴露的平面 AO 值较高（较亮）。


屏幕空间环境遮蔽（SSAO）是实时 AO 的标准方案，在屏幕空间使用深度和法线缓冲来估计每个像素周围的遮蔽程度：


#version 450

layout(set = 0, binding = 0) uniform sampler2D depthBuffer;
layout(set = 0, binding = 1) uniform sampler2D normalBuffer;
layout(set = 0, binding = 2) uniform sampler2D noiseTexture;

layout(set = 0, binding = 3) uniform SSAOParams {
    mat4 projection;
    vec3 samples[64];
    float radius;
    float bias;
    float power;
    vec2 noiseScale;
};

layout(location = 0) in vec2 texCoord;
layout(location = 0) out float outAO;

vec3 reconstructPosition(vec2 uv, float depth) {
    vec4 clipPos = vec4(uv * 2.0 - 1.0, depth, 1.0);
    vec4 viewPos = inverse(projection) * clipPos;
    return viewPos.xyz / viewPos.w;
}

void main() {
    float depth = texture(depthBuffer, texCoord).r;
    vec3 fragPos = reconstructPosition(texCoord, depth);
    vec3 normal = texture(normalBuffer, texCoord).rgb * 2.0 - 1.0;
    vec3 randomVec = texture(noiseTexture, texCoord * noiseScale).rgb;

    vec3 tangent = normalize(randomVec - normal * dot(randomVec, normal));
    vec3 bitangent = cross(normal, tangent);
    mat3 TBN = mat3(tangent, bitangent, normal);

    float occlusion = 0.0;
    for (int i = 0; i < 64; i++) {
        vec3 samplePos = fragPos + TBN * samples[i] * radius;
        vec4 offset = projection * vec4(samplePos, 1.0);
        offset.xyz /= offset.w;
        offset.xyz = offset.xyz * 0.5 + 0.5;

        float sampleDepth = texture(depthBuffer, offset.xy).r;
        vec3 sampleViewPos = reconstructPosition(offset.xy, sampleDepth);
        float rangeCheck = smoothstep(0.0, 1.0, radius / abs(fragPos.z - sampleViewPos.z));
        occlusion += (sampleViewPos.z >= samplePos.z + bias ? 1.0 : 0.0) * rangeCheck;
    }
    outAO = pow(1.0 - occlusion / 64.0, power);
}
SSAO 的结果通常需要模糊处理来消除采样噪声。4×4 的噪声纹理配合双边模糊（Bilateral Blur）可以在保持边缘锐利的同时平滑噪声。


GTAO（Ground Truth Ambient Occlusion）和 HBAO+（Horizon-Based Ambient Occlusion）是 SSAO 的改进方案，通过更好的采样策略和更准确的遮蔽估计提供更高质量的结果。


光照探针与辐照度场
光照探针（Light Probe）在场景中的离散点采集全方向的光照信息，存储为球谐函数（Spherical Harmonics, SH）系数。运行时物体根据其位置对最近的探针进行插值，获得该位置的间接光照估计。


二阶球谐函数（L2 SH，9 个系数）能够以极少的存储量表示低频的间接光照分布。对于漫反射材质，L2 精度已经足够：


interface SHCoefficients {
  r: Float32Array;
  g: Float32Array;
  b: Float32Array;
}

function evaluateSH(sh: SHCoefficients, normal: [number, number, number]): [number, number, number] {
  const [x, y, z] = normal;

  const basis = [
    0.282095,
    0.488603 * y,
    0.488603 * z,
    0.488603 * x,
    1.092548 * x * y,
    1.092548 * y * z,
    0.315392 * (3.0 * z * z - 1.0),
    1.092548 * x * z,
    0.546274 * (x * x - y * y),
  ];

  let r = 0,
    g = 0,
    b = 0;
  for (let i = 0; i < 9; i++) {
    r += sh.r[i] * basis[i];
    g += sh.g[i] * basis[i];
    b += sh.b[i] * basis[i];
  }

  return [Math.max(0, r), Math.max(0, g), Math.max(0, b)];
}
辐照度场（Irradiance Field）是光照探针的扩展，使用规则网格布置探针并存储全方向的辐照度数据。DDGI（Dynamic Diffuse Global Illumination）是 NVIDIA 提出的实时方案，每帧使用少量光线追踪更新探针数据，支持动态场景的全局光照。

屏幕空间全局光照
屏幕空间全局光照（SSGI / Screen Space Global Illumination）利用当前帧的颜色缓冲和深度缓冲来估计间接光照，无需额外的场景数据结构。SSGI 能够捕捉动态物体的颜色渗透效果，但受限于屏幕空间信息的不完整性。


屏幕空间反射（SSR, Screen Space Reflections）是 SSGI 的一个特例，通过屏幕空间的光线步进（Ray Marching）来寻找反射点：


#version 450

layout(set = 0, binding = 0) uniform sampler2D colorBuffer;
layout(set = 0, binding = 1) uniform sampler2D depthBuffer;

layout(set = 0, binding = 2) uniform SSRParams {
    mat4 projection;
    mat4 invProjection;
    float stepSize;
    int maxSteps;
    float thickness;
};

layout(location = 0) in vec2 texCoord;
layout(location = 0) out vec4 outReflection;

vec3 viewPosFromDepth(vec2 uv, float depth) {
    vec4 clip = vec4(uv * 2.0 - 1.0, depth, 1.0);
    vec4 view = invProjection * clip;
    return view.xyz / view.w;
}

void main() {
    float depth = texture(depthBuffer, texCoord).r;
    if (depth >= 1.0) { outReflection = vec4(0.0); return; }

    vec3 viewPos = viewPosFromDepth(texCoord, depth);
    vec3 viewNormal = texture(normalBuffer, texCoord).rgb;
    vec3 reflectDir = reflect(normalize(viewPos), viewNormal);

    vec3 currentPos = viewPos;
    for (int i = 0; i < maxSteps; i++) {
        currentPos += reflectDir * stepSize;
        vec4 projPos = projection * vec4(currentPos, 1.0);
        projPos.xyz /= projPos.w;
        vec2 sampleUV = projPos.xy * 0.5 + 0.5;

        if (sampleUV.x < 0.0 || sampleUV.x > 1.0 || sampleUV.y < 0.0 || sampleUV.y > 1.0) break;

        float sampleDepth = texture(depthBuffer, sampleUV).r;
        vec3 sampleViewPos = viewPosFromDepth(sampleUV, sampleDepth);

        if (currentPos.z < sampleViewPos.z && currentPos.z > sampleViewPos.z - thickness) {
            outReflection = vec4(texture(colorBuffer, sampleUV).rgb, 1.0);
            return;
        }
    }
    outReflection = vec4(0.0);
}
SSR 的常见问题包括：屏幕边缘缺失信息导致反射消失、步长过大导致错过交点、步长过小导致性能不足。Hi-Z 加速（Hierarchical Z-Buffer Tracing）通过利用深度缓冲的 Mipmap 链实现自适应步长，在保持精度的同时大幅提高光线步进效率。


体素化全局光照
体素全局光照（Voxel Global Illumination, VXGI）将场景体素化为三维网格，在体素空间中追踪光线的传播和散射。VXGI 能够提供完整的多次反弹间接光照，包括漫反射和镜面反射分量。


VXGI 的工作流程分为三个阶段：场景体素化、体素光照注入和锥体追踪（Cone Tracing）。锥体追踪使用体素 Mipmap 的不同层级来近似不同角度宽度的锥形光线积分：

VXGI 的主要限制是显存占用大（512³ 体素 × 4 通道 × 6 个 Mipmap 级别可达数百 MB）和对小物体的精度不足（体素分辨率限制）。Sparse Voxel Octree 是一种优化方案，仅在有内容的区域存储体素数据。


Unreal Engine 5 的 Lumen 系统结合了软件光线追踪、网格距离场（Mesh Distance Field）、屏幕空间追踪和全局光照探针等多种技术，实现了兼顾性能和质量的动态全局光照方案。


小结
    

  • 全局光照模拟光线多次反弹的间接照明效果，是实现真实感渲染的关键
    • 

  • SSAO/GTAO 是成本最低且效果最显著的 GI 分量，通过屏幕空间采样估计遮蔽
    • 

  • 球谐函数以极少的存储量编码低频辐照度分布，L2 SH 仅需 9 个系数即可表示漫反射间接光
    • 

  • DDGI 通过每帧少量光线追踪更新探针数据，实现了动态场景的实时间接光照
    • 

  • SSR 通过屏幕空间光线步进实现反射效果，Hi-Z 加速是提高效率的关键
    • 

  • VXGI 提供最完整的多次反弹 GI，但显存和性能开销较大
    •
