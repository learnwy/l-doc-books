光照模型

核心概念

光照模型（Lighting Model）描述了光线与物体表面的交互方式，决定了渲染图像的视觉真实感。从经典的经验模型到基于物理的 BRDF，光照模型的演进反映了实时渲染对物理准确性的不断追求。理解不同光照模型的数学原理和适用场景，是实现高质量游戏画面的关键。

光照计算的基础是渲染方程（Rendering Equation），描述了从表面某点沿特定方向出射的辐射度等于该点的自发光加上来自所有方向的入射光经表面反射后沿该方向的贡献之和。实时渲染中使用的光照模型都是对完整渲染方程的不同程度简化。


Lambert 与 Blinn-Phong 经验模型
Lambert 漫反射是最简单的光照模型，基于 Lambert 余弦定律：表面接收到的光照强度与入射光方向和表面法线夹角的余弦成正比。漫反射是视角无关的，即从任何方向观察表面亮度相同。


Phong 模型在 Lambert 漫反射基础上增加了镜面反射项，使用反射向量与视线方向的点积来计算高光。Blinn-Phong 模型是其改进版，使用半角向量（Half Vector）替代反射向量，计算更高效且在掠射角处表现更好。


#version 450

layout(location = 0) in vec3 fragWorldPos;
layout(location = 1) in vec3 fragNormal;
layout(location = 2) in vec2 fragTexCoord;

layout(set = 0, binding = 0) uniform LightParams {
    vec3 lightDir;
    vec3 lightColor;
    vec3 ambientColor;
    vec3 cameraPos;
    float shininess;
};

layout(set = 0, binding = 1) uniform sampler2D diffuseMap;

layout(location = 0) out vec4 outColor;

void main() {
    vec3 albedo = texture(diffuseMap, fragTexCoord).rgb;
    vec3 N = normalize(fragNormal);
    vec3 L = normalize(-lightDir);
    vec3 V = normalize(cameraPos - fragWorldPos);
    vec3 H = normalize(L + V);

    vec3 ambient = ambientColor * albedo;
    float NdotL = max(dot(N, L), 0.0);
    vec3 diffuse = lightColor * albedo * NdotL;
    float NdotH = max(dot(N, H), 0.0);
    vec3 specular = lightColor * pow(NdotH, shininess);

    outColor = vec4(ambient + diffuse + specular, 1.0);
}
Blinn-Phong 模型中的 shininess 参数控制高光的集中程度：值越大高光越小越锐利，模拟越光滑的表面。虽然这个参数缺乏物理意义，但通过经验调节可以产生令人满意的视觉效果。


经验模型的主要局限是无法正确处理能量守恒。当增加高光强度时，表面反射的总能量可能超过入射能量，导致不自然的亮度。这正是基于物理的光照模型要解决的核心问题。


微表面理论与 BRDF
基于物理的渲染（PBR）建立在微表面理论（Microfacet Theory）之上：宏观上平滑的表面在微观尺度由无数微小的镜面组成，每个微表面都是完美的平面反射器。表面的粗糙度决定了微表面法线分布的集中程度。


双向反射分布函数（BRDF）描述了入射光在不同出射方向上的能量分配。Cook-Torrance 微表面 BRDF 是目前实时渲染中最广泛使用的镜面反射模型：


f_spec = D(h) × F(v,h) × G(l,v,h) / (4 × (n·l) × (n·v))


其中 D 是法线分布函数，F 是菲涅尔项，G 是几何遮蔽项。

GGX（Trowbridge-Reitz）法线分布因其具有更长的高光尾部而被广泛采用，能更真实地模拟真实材质的高光衰减特性。


Cook-Torrance 着色器实现
将 Cook-Torrance BRDF 的三个分量组合起来，可以实现完整的 PBR 镜面反射计算。以下是在片段着色器中的完整实现：


#version 450

const float PI = 3.14159265359;

float distributionGGX(vec3 N, vec3 H, float roughness) {
    float a = roughness * roughness;
    float a2 = a * a;
    float NdotH = max(dot(N, H), 0.0);
    float NdotH2 = NdotH * NdotH;
    float denom = NdotH2 * (a2 - 1.0) + 1.0;
    return a2 / (PI * denom * denom);
}

vec3 fresnelSchlick(float cosTheta, vec3 F0) {
    return F0 + (1.0 - F0) * pow(clamp(1.0 - cosTheta, 0.0, 1.0), 5.0);
}

float geometrySchlickGGX(float NdotV, float roughness) {
    float r = roughness + 1.0;
    float k = (r * r) / 8.0;
    return NdotV / (NdotV * (1.0 - k) + k);
}

float geometrySmith(vec3 N, vec3 V, vec3 L, float roughness) {
    float NdotV = max(dot(N, V), 0.0);
    float NdotL = max(dot(N, L), 0.0);
    return geometrySchlickGGX(NdotV, roughness) * geometrySchlickGGX(NdotL, roughness);
}

layout(location = 0) in vec3 fragWorldPos;
layout(location = 1) in vec3 fragNormal;
layout(location = 2) in vec2 fragTexCoord;

layout(set = 0, binding = 0) uniform sampler2D albedoMap;
layout(set = 0, binding = 1) uniform sampler2D normalMap;
layout(set = 0, binding = 2) uniform sampler2D metallicRoughnessMap;

layout(set = 1, binding = 0) uniform SceneData {
    vec3 cameraPos;
    vec3 lightPositions[4];
    vec3 lightColors[4];
    int lightCount;
};

layout(location = 0) out vec4 outColor;

void main() {
    vec3 albedo = pow(texture(albedoMap, fragTexCoord).rgb, vec3(2.2));
    float metallic = texture(metallicRoughnessMap, fragTexCoord).b;
    float roughness = texture(metallicRoughnessMap, fragTexCoord).g;
    vec3 N = normalize(fragNormal);
    vec3 V = normalize(cameraPos - fragWorldPos);

    vec3 F0 = mix(vec3(0.04), albedo, metallic);
    vec3 Lo = vec3(0.0);

    for (int i = 0; i < lightCount; i++) {
        vec3 L = normalize(lightPositions[i] - fragWorldPos);
        vec3 H = normalize(V + L);
        float distance = length(lightPositions[i] - fragWorldPos);
        float attenuation = 1.0 / (distance * distance);
        vec3 radiance = lightColors[i] * attenuation;

        float D = distributionGGX(N, H, roughness);
        vec3 F = fresnelSchlick(max(dot(H, V), 0.0), F0);
        float G = geometrySmith(N, V, L, roughness);

        vec3 numerator = D * G * F;
        float denominator = 4.0 * max(dot(N, V), 0.0) * max(dot(N, L), 0.0) + 0.0001;
        vec3 specular = numerator / denominator;

        vec3 kD = (vec3(1.0) - F) * (1.0 - metallic);
        float NdotL = max(dot(N, L), 0.0);
        Lo += (kD * albedo / PI + specular) * radiance * NdotL;
    }

    vec3 ambient = vec3(0.03) * albedo;
    vec3 color = ambient + Lo;
    color = color / (color + vec3(1.0));
    color = pow(color, vec3(1.0 / 2.2));

    outColor = vec4(color, 1.0);
}
这段着色器包含了完整的 PBR 工作流：Albedo 纹理从 sRGB 转换到线性空间、金属度决定 F0 基础反射率、粗糙度控制 NDF 和几何项的衰减、能量守恒通过漫反射系数 kD 与菲涅尔项的互补保证、最终输出经过 Reinhard 色调映射和 Gamma 校正。


光源类型与衰减函数
游戏中常见的光源类型各有不同的数学模型和衰减特性。正确选择衰减函数对于光照的真实感和性能都至关重要。

物理正确的点光源衰减遵循平方反比定律（Inverse Square Law），但在实时渲染中通常需要添加影响半径截断，以便进行空间裁剪优化：


float calculateAttenuation(float distance, float radius) {
    float d2 = distance * distance;
    float r2 = radius * radius;
    float factor = d2 / r2;
    float smoothFactor = max(1.0 - factor * factor, 0.0);
    return (smoothFactor * smoothFactor) / max(d2, 0.0001);
}
这个衰减函数在物理平方反比的基础上乘以一个平滑截断因子，确保在影响半径边缘光照强度平滑衰减到零，避免视觉上的突变。


面光源（Area Light）是近年来实时渲染的研究热点。与点光源和方向光不同，面光源的照明区域有实际面积，其光照积分无法解析求解。线性变换余弦（LTC, Linearly Transformed Cosines）是目前实时面光源光照的主流方案，通过预计算查找表近似面光源的 BRDF 积分。


小结
    

  • 经验模型（Lambert + Blinn-Phong）计算简单但缺乏物理正确性，不满足能量守恒
    • 

  • 微表面理论将粗糙表面建模为微小镜面的集合，BRDF 由 NDF、菲涅尔和几何项三部分组成
    • 

  • GGX 法线分布因其自然的高光尾部成为 PBR 标准选择
    • 

  • Cook-Torrance 着色器通过金属度区分导体和电介质，漫反射系数与菲涅尔项互补保证能量守恒
    • 

  • 光源衰减需要在物理平方反比基础上添加平滑截断以支持空间裁剪优化
    • 

  • 面光源通过 LTC 等技术实现实时近似，是提升光照真实感的前沿方向
