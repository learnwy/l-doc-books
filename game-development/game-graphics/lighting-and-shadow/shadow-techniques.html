阴影技术

核心概念

阴影是场景中物体遮挡光源产生的视觉效果，对于建立场景的空间关系和深度感至关重要。没有阴影的场景中，物体看起来像是悬浮在空中。实时阴影渲染的核心挑战是在精度、性能和视觉质量之间取得平衡。阴影贴图（Shadow Map）是目前最主流的实时阴影技术，其基本思想是从光源视角渲染深度图，然后在正式渲染时比较片段深度与阴影贴图中的值来判断是否在阴影中。

阴影贴图的核心挑战包括分辨率不足导致的锯齿（Shadow Acne）、深度偏移带来的 Peter Panning 问题、以及阴影边缘的硬切割感。


基础阴影贴图实现
阴影贴图算法分为两个 Pass：第一个 Pass 从光源视角渲染场景的深度信息到纹理；第二个 Pass 在正式渲染时将片段世界坐标变换到光源空间，与阴影贴图中的深度值比较。


光源视角的投影矩阵取决于光源类型。方向光使用正交投影，点光源使用立方体贴图（6 个面的透视投影），聚光灯使用透视投影。


#version 450

layout(set = 0, binding = 0) uniform sampler2D shadowMap;

layout(set = 0, binding = 1) uniform ShadowData {
    mat4 lightViewProjection;
    float shadowBias;
    float shadowMapSize;
};

layout(location = 0) in vec3 fragWorldPos;
layout(location = 1) in vec3 fragNormal;

float calculateShadow(vec3 worldPos, vec3 normal, vec3 lightDir) {
    vec4 lightSpacePos = lightViewProjection * vec4(worldPos, 1.0);
    vec3 projCoords = lightSpacePos.xyz / lightSpacePos.w;
    projCoords = projCoords * 0.5 + 0.5;

    if (projCoords.z > 1.0) return 0.0;

    float bias = max(0.05 * (1.0 - dot(normal, lightDir)), shadowBias);
    float currentDepth = projCoords.z;
    float closestDepth = texture(shadowMap, projCoords.xy).r;

    return currentDepth - bias > closestDepth ? 1.0 : 0.0;
}
自适应偏移（Adaptive Bias）根据表面法线与光线方向的夹角动态调整偏移量。当表面几乎平行于光线方向时，阴影走样最严重，此时需要更大的偏移；当表面正对光源时，偏移可以很小。


法线偏移（Normal Offset）是另一种有效的反走样策略：沿表面法线方向将片段位置偏移一小段距离后再投影到光源空间，能有效减少大面积表面上的阴影粉刺：


float calculateShadowWithNormalOffset(vec3 worldPos, vec3 normal, vec3 lightDir) {
    float NdotL = dot(normal, lightDir);
    float normalOffsetScale = clamp(1.0 - NdotL, 0.0, 1.0);
    vec3 offsetPos = worldPos + normal * normalOffsetScale * 0.05;
    vec4 lightSpacePos = lightViewProjection * vec4(offsetPos, 1.0);
    vec3 projCoords = lightSpacePos.xyz / lightSpacePos.w;
    projCoords = projCoords * 0.5 + 0.5;

    if (projCoords.z > 1.0) return 0.0;

    float currentDepth = projCoords.z;
    float closestDepth = texture(shadowMap, projCoords.xy).r;
    float bias = 0.001;
    return currentDepth - bias > closestDepth ? 1.0 : 0.0;
}
级联阴影贴图
级联阴影贴图（Cascaded Shadow Maps, CSM）是开放世界游戏中方向光阴影的标准方案。它将视锥体沿深度方向切分为多个区间（Cascade），每个区间使用独立的阴影贴图，近处 Cascade 覆盖较小范围但提供更高分辨率，远处 Cascade 覆盖更大范围但分辨率较低。


Cascade 切分策略直接影响阴影质量。常用的方案是对数分布（Logarithmic Split）与均匀分布（Uniform Split）的加权混合：


interface CascadeSplit {
  near: number;
  far: number;
  lightViewProjection: Float32Array;
}

function calculateCascadeSplits(cameraNear: number, cameraFar: number, cascadeCount: number, lambda: number): number[] {
  const splits: number[] = [];
  for (let i = 0; i < cascadeCount; i++) {
    const p = (i + 1) / cascadeCount;
    const log = cameraNear * Math.pow(cameraFar / cameraNear, p);
    const uniform = cameraNear + (cameraFar - cameraNear) * p;
    splits.push(lambda * log + (1 - lambda) * uniform);
  }
  return splits;
}
lambda 参数控制对数和均匀分布的混合比例。lambda = 1 为纯对数分布，近处精度最高但远近差异大；lambda = 0 为纯均匀分布，各级精度均匀但近处不足。实际使用中 lambda = 0.5 ~ 0.7 是常见选择。


Cascade 之间的过渡可能产生可见的接缝。常用的解决方案是在 Cascade 边界附近混合两级阴影的结果，或者使用抖动采样来模糊接缝。


PCF 与软阴影
硬阴影（Hard Shadow）边缘锐利不自然，现实中由于光源具有面积，阴影边缘存在由本影到半影的渐变过渡。百分比近似过滤（Percentage Closer Filtering, PCF）通过在阴影贴图上多次采样并计算遮挡比例来实现软阴影效果。


float pcfShadow(vec3 projCoords, float currentDepth, float bias) {
    float shadow = 0.0;
    float texelSize = 1.0 / shadowMapSize;

    for (int x = -2; x <= 2; x++) {
        for (int y = -2; y <= 2; y++) {
            float depth = texture(shadowMap, projCoords.xy + vec2(x, y) * texelSize).r;
            shadow += currentDepth - bias > depth ? 1.0 : 0.0;
        }
    }
    return shadow / 25.0;
}
5×5 的 PCF 核提供了基础的软阴影效果，但采样数量固定导致半影宽度恒定，不符合物理规律。百分比接近软阴影（PCSS, Percentage Closer Soft Shadows）通过先估计遮挡物距离来动态调整 PCF 核大小，实现近处硬阴影、远处软阴影的物理效果。

PCSS 的实现分为三步：遮挡物搜索（Blocker Search）确定平均遮挡距离、半影估计（Penumbra Estimation）计算 PCF 核大小、PCF 过滤计算最终阴影值：


float pcssSearch(vec2 uv, float receiverDepth, float searchRadius) {
    float blockerSum = 0.0;
    float blockerCount = 0.0;
    float texelSize = 1.0 / shadowMapSize;

    for (int i = 0; i < 16; i++) {
        vec2 offset = poissonDisk[i] * searchRadius * texelSize;
        float depth = texture(shadowMap, uv + offset).r;
        if (depth < receiverDepth) {
            blockerSum += depth;
            blockerCount += 1.0;
        }
    }
    return blockerCount > 0.0 ? blockerSum / blockerCount : -1.0;
}

float pcssShadow(vec3 projCoords, float bias) {
    float receiverDepth = projCoords.z - bias;
    float avgBlockerDepth = pcssSearch(projCoords.xy, receiverDepth, 8.0);

    if (avgBlockerDepth < 0.0) return 0.0;

    float penumbraWidth = (receiverDepth - avgBlockerDepth) / avgBlockerDepth * lightSize;
    return pcfShadow(projCoords, receiverDepth, bias);
}
点光源阴影与立方体贴图
点光源向所有方向发射光线，其阴影贴图需要覆盖完整的球面。标准方案是使用立方体阴影贴图（Cube Shadow Map），从点光源位置向六个方向分别渲染深度图。


在采样阶段，将片段到光源的方向向量作为立方体贴图的采样方向，取得该方向上最近遮挡物的深度。与方向光不同，点光源阴影比较的是距离而非投影深度：


float pointLightShadow(vec3 fragPos, vec3 lightPos, float farPlane) {
    vec3 fragToLight = fragPos - lightPos;
    float currentDepth = length(fragToLight);
    float closestDepth = texture(shadowCubeMap, fragToLight).r * farPlane;
    float bias = 0.05;
    return currentDepth - bias > closestDepth ? 1.0 : 0.0;
}
六个面的渲染 Pass 开销较大。双抛物面阴影贴图（Dual Paraboloid Shadow Map）将球面映射到两张抛物面贴图上，仅需 2 个 Pass，但在边缘处有接缝和精度问题。另一种优化是使用几何着色器的分层渲染（Layered Rendering），一个 Draw Call 同时输出到立方体贴图的六个面。


小结
    

  • 阴影贴图是最通用的实时阴影技术，从光源视角渲染深度图后在相机渲染时进行深度比较
    • 

  • Shadow Acne 和 Peter Panning 是阴影贴图的两大经典问题，自适应偏移和法线偏移是标准解决方案
    • 

  • CSM 将视锥体分级，每级独立阴影贴图，是开放世界方向光阴影的行业标准
    • 

  • PCF 通过多次采样实现软阴影，PCSS 根据遮挡距离动态调整半影宽度实现物理准确的软阴影
    • 

  • 点光源使用立方体阴影贴图覆盖全方向，分层渲染可优化六面渲染的开销
    • 

  • 软阴影方案的选择需要在采样质量和性能之间权衡，PCSS 是视觉质量最佳的实时方案
    •
