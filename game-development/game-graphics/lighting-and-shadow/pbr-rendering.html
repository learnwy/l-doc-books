PBR 渲染

核心概念

基于物理的渲染（Physically Based Rendering, PBR）是现代游戏图形的标准光照方案。PBR 遵循物理光学定律——能量守恒、微表面理论和菲涅尔效应——确保材质在任何光照条件下都呈现一致且真实的视觉效果。PBR 的关键优势在于材质参数具有物理意义，艺术家可以使用统一的工作流创建在不同环境中都表现正确的材质。

金属度/粗糙度（Metal/Roughness）工作流是当前的行业标准。金属度（Metallic）是二值参数：金属（1.0）或非金属（0.0），中间值仅用于过渡区域。粗糙度（Roughness）控制表面微表面的起伏程度，从完美镜面（0.0）到完全粗糙（1.0）。


PBR 的两大基础原则是：能量守恒——物体反射的光不会超过接收的光；以及微表面模型——表面由无数朝向各异的微镜面组成，粗糙度决定了微面法线的分散程度。

在实际项目中，多个单通道贴图通常打包到一张纹理的不同通道中以减少纹理采样次数。常见的打包方式是 ORM 贴图：R 通道存储 AO，G 通道存储 Roughness，B 通道存储 Metallic。


Albedo 贴图的制作要求是不包含任何光照信息（无阴影、无高光、无 AO），只有材质固有的漫反射颜色。对于非金属材质，Albedo 值通常在 50-240 sRGB 范围内（过暗或过亮都不物理）；对于金属材质，Albedo 表示的是反射颜色（如金色、铜色），其亮度通常在 180-255 sRGB 范围。


interface PBRMaterial {
  albedoMap: GPUTexture;
  normalMap: GPUTexture;
  ormMap: GPUTexture;
  emissiveMap: GPUTexture | null;
  albedoFactor: [number, number, number, number];
  metallicFactor: number;
  roughnessFactor: number;
  emissiveFactor: [number, number, number];
}

function createPBRBindGroup(
  device: GPUDevice,
  layout: GPUBindGroupLayout,
  material: PBRMaterial,
  sampler: GPUSampler,
): GPUBindGroup {
  const entries: GPUBindGroupEntry[] = [
    { binding: 0, resource: sampler },
    { binding: 1, resource: material.albedoMap.createView() },
    { binding: 2, resource: material.normalMap.createView() },
    { binding: 3, resource: material.ormMap.createView() },
  ];

  if (material.emissiveMap) {
    entries.push({ binding: 4, resource: material.emissiveMap.createView() });
  }

  return device.createBindGroup({ layout, entries });
}
图像基础光照
图像基础光照（Image-Based Lighting, IBL）使用环境贴图作为光源，为 PBR 材质提供来自所有方向的间接光照。IBL 是 PBR 渲染不可或缺的组成部分，没有 IBL 的 PBR 材质在暗角处会显得不自然地黑暗。


IBL 分为漫反射和镜面反射两部分：


漫反射 IBL 使用辐照度贴图（Irradiance Map），它是环境贴图在半球上积分的结果，可以预计算为低分辨率立方体贴图（32×32 足够）。镜面反射 IBL 使用预过滤环境贴图（Pre-filtered Environment Map），不同的 Mipmap 级别对应不同的粗糙度。


#version 450

layout(set = 0, binding = 0) uniform samplerCube irradianceMap;
layout(set = 0, binding = 1) uniform samplerCube prefilteredMap;
layout(set = 0, binding = 2) uniform sampler2D brdfLUT;

vec3 fresnelSchlickRoughness(float cosTheta, vec3 F0, float roughness) {
    return F0 + (max(vec3(1.0 - roughness), F0) - F0) * pow(clamp(1.0 - cosTheta, 0.0, 1.0), 5.0);
}

vec3 calculateIBL(vec3 N, vec3 V, vec3 albedo, float metallic, float roughness, float ao) {
    vec3 F0 = mix(vec3(0.04), albedo, metallic);
    float NdotV = max(dot(N, V), 0.0);
    vec3 F = fresnelSchlickRoughness(NdotV, F0, roughness);

    vec3 kD = (1.0 - F) * (1.0 - metallic);
    vec3 irradiance = texture(irradianceMap, N).rgb;
    vec3 diffuseIBL = kD * irradiance * albedo;

    vec3 R = reflect(-V, N);
    float maxLod = textureQueryLevels(prefilteredMap) - 1.0;
    vec3 prefilteredColor = textureLod(prefilteredMap, R, roughness * maxLod).rgb;
    vec2 brdf = texture(brdfLUT, vec2(NdotV, roughness)).rg;
    vec3 specularIBL = prefilteredColor * (F * brdf.x + brdf.y);

    return (diffuseIBL + specularIBL) * ao;
}
BRDF 查找表（BRDF LUT）是预计算的二维纹理，横轴为 NdotV，纵轴为粗糙度。它存储了 Split-Sum 近似中的镜面反射积分缩放因子和偏移因子，避免了运行时昂贵的半球积分。

次表面散射（Subsurface Scattering, SSS）模拟光线穿透半透明材质后在内部多次散射的效果。实时 SSS 常用屏幕空间模糊（Screen-Space Blur）或预积分散射轮廓（Pre-Integrated SSS Profile）来近似：


vec3 calculateSSS(vec3 N, vec3 L, vec3 V, vec3 albedo, vec3 scatterColor, float scatterWidth) {
    float NdotL = dot(N, L);
    float wrapDiffuse = max(0.0, (NdotL + scatterWidth) / (1.0 + scatterWidth));
    vec3 scatter = scatterColor * wrapDiffuse;

    vec3 H = normalize(L + N * 0.6);
    float VdotH = pow(clamp(dot(V, -H), 0.0, 1.0), 3.0);
    vec3 backlight = albedo * VdotH * scatterColor;

    return scatter + backlight;
}
各向异性反射（Anisotropic Reflection）出现在具有微观方向性纹理的材质上，如拉丝金属、唱片表面和头发。GGX 各向异性 NDF 使用两个独立的粗糙度参数控制切线和副切线方向的高光拉伸。


色调映射与颜色管理
PBR 渲染在线性 HDR 颜色空间中计算光照，最终需要通过色调映射（Tone Mapping）压缩到 LDR 范围并进行 Gamma 校正后输出到显示器。色调映射的选择直接影响画面的整体氛围和色彩风格。

ACES（Academy Color Encoding System）是目前游戏行业最常用的色调映射曲线，提供电影级的色彩风格：


vec3 acesFilm(vec3 x) {
    float a = 2.51;
    float b = 0.03;
    float c = 2.43;
    float d = 0.59;
    float e = 0.14;
    return clamp((x * (a * x + b)) / (x * (c * x + d) + e), 0.0, 1.0);
}

vec3 linearToSRGB(vec3 color) {
    return pow(color, vec3(1.0 / 2.2));
}

vec3 finalOutput(vec3 hdrColor) {
    vec3 mapped = acesFilm(hdrColor);
    return linearToSRGB(mapped);
}
正确的颜色管理要求整个渲染管线保持一致：Albedo 纹理从 sRGB 解码到线性空间、所有光照计算在线性空间进行、色调映射后编码回 sRGB。混淆颜色空间是 PBR 实现中最常见的错误之一。


小结
    

  • PBR 基于能量守恒和微表面理论，材质参数具有物理意义，确保跨场景的一致性
    • 

  • 金属度/粗糙度工作流是行业标准，ORM 通道打包减少纹理采样次数
    • 

  • IBL 为 PBR 提供不可或缺的间接光照，辐照度贴图和预过滤环境贴图可高效预计算
    • 

  • BRDF LUT 通过 Split-Sum 近似避免了运行时的昂贵半球积分
    • 

  • Clear Coat、SSS、各向异性等高级特性扩展了标准 PBR 的材质表现力
    • 

  • 整个管线必须在线性颜色空间中计算光照，通过 ACES 等色调映射输出到显示器
    •
