后处理管线

核心概念

后处理（Post-Processing）是在场景渲染完成后，对最终图像进行全屏像素级处理的技术。后处理管线由一系列效果 Pass 串联而成，每个 Pass 读取前一阶段的输出纹理，执行特定的图像变换后写入新的纹理。后处理效果包括色调映射、辉光、景深、运动模糊、色彩校正等，是现代游戏画面风格化和电影感的核心手段。

后处理管线的设计需要考虑效果之间的依赖关系和执行顺序。例如 Bloom 必须在 HDR 空间中计算（色调映射之前），而 FXAA 必须在最终 LDR 输出上执行。


全屏 Pass 架构
后处理的每个效果本质上是一个全屏绘制：渲染一个覆盖整个屏幕的四边形（或三角形），片段着色器对输入纹理的每个像素执行处理。现代实现通常使用一个大三角形替代两个三角形组成的四边形，避免对角线上的重复光栅化。


interface PostProcessPass {
  name: string;
  pipeline: GPURenderPipeline;
  bindGroupLayout: GPUBindGroupLayout;
  enabled: boolean;
}

interface PostProcessStack {
  passes: PostProcessPass[];
  pingPongTextures: [GPUTexture, GPUTexture];
  outputFormat: GPUTextureFormat;
}

function createPostProcessStack(
  device: GPUDevice,
  width: number,
  height: number,
  format: GPUTextureFormat,
): PostProcessStack {
  const createTexture = () =>
    device.createTexture({
      size: [width, height],
      format,
      usage: GPUTextureUsage.TEXTURE_BINDING | GPUTextureUsage.RENDER_ATTACHMENT,
    });

  return {
    passes: [],
    pingPongTextures: [createTexture(), createTexture()],
    outputFormat: format,
  };
}

function executePostProcessStack(
  stack: PostProcessStack,
  encoder: GPUCommandEncoder,
  inputTexture: GPUTextureView,
  outputTexture: GPUTextureView,
  sampler: GPUSampler,
  device: GPUDevice,
): void {
  const activePasses = stack.passes.filter((p) => p.enabled);
  let currentInput = inputTexture;

  for (let i = 0; i < activePasses.length; i++) {
    const pass = activePasses[i];
    const isLast = i === activePasses.length - 1;
    const target = isLast ? outputTexture : stack.pingPongTextures[i % 2].createView();

    const bindGroup = device.createBindGroup({
      layout: pass.bindGroupLayout,
      entries: [
        { binding: 0, resource: sampler },
        { binding: 1, resource: currentInput },
      ],
    });

    const renderPass = encoder.beginRenderPass({
      colorAttachments: [
        {
          view: target,
          loadOp: 'clear',
          storeOp: 'store',
        },
      ],
    });

    renderPass.setPipeline(pass.pipeline);
    renderPass.setBindGroup(0, bindGroup);
    renderPass.draw(3);
    renderPass.end();

    currentInput = target;
  }
}
Ping-Pong 缓冲是后处理管线的标准模式：两个纹理交替作为输入和输出，避免每个 Pass 都创建新纹理。当效果链较长时，这种方式显著减少显存分配。


Bloom 辉光效果
Bloom 模拟人眼和相机镜头对强光源的感知——高亮区域的光向周围扩散，产生发光的视觉效果。Bloom 是最能提升画面品质感的后处理效果之一。


标准 Bloom 流程是：亮度提取 → 降采样模糊链 → 升采样合并链 → 与原图混合。


亮度提取使用阈值过滤，只保留超过一定亮度的像素进入模糊链。软阈值（Soft Threshold）使用 knee 曲线避免亮度截断处的突变：


#version 450

layout(set = 0, binding = 0) uniform sampler2D inputTexture;
layout(set = 0, binding = 1) uniform BloomParams {
    float threshold;
    float knee;
    float intensity;
};

layout(location = 0) in vec2 texCoord;
layout(location = 0) out vec4 outColor;

void main() {
    vec3 color = texture(inputTexture, texCoord).rgb;
    float brightness = max(color.r, max(color.g, color.b));

    float soft = brightness - threshold + knee;
    soft = clamp(soft, 0.0, 2.0 * knee);
    soft = soft * soft / (4.0 * knee + 0.00001);
    float contribution = max(soft, brightness - threshold) / max(brightness, 0.00001);

    outColor = vec4(color * contribution, 1.0);
}
降采样使用 13-tap 高斯核或双线性过滤的 4-tap 模式来实现高效模糊。每次降采样将分辨率减半，等效于增大模糊半径。升采样时使用帐篷过滤（Tent Filter）与上一级结果混合，产生平滑的多级辉光。

景深效果
景深（Depth of Field, DOF）模拟相机镜头的对焦行为，焦平面内的物体清晰，焦外物体根据散焦圆（Circle of Confusion, CoC）大小模糊。DOF 极大增强画面的摄影感和空间层次。


散焦圆大小的计算基于薄透镜模型：


CoC = |S₂ - S₁| / S₂ × f² / (N × (S₁ - f))


其中 S₁ 是对焦距离，S₂ 是物体深度，f 是焦距，N 是光圈值。


#version 450

layout(set = 0, binding = 0) uniform sampler2D colorTexture;
layout(set = 0, binding = 1) uniform sampler2D depthTexture;

layout(set = 0, binding = 2) uniform DOFParams {
    float focusDistance;
    float focusRange;
    float bokehRadius;
    float nearPlane;
    float farPlane;
};

layout(location = 0) in vec2 texCoord;
layout(location = 0) out vec4 outColor;

float linearizeDepth(float depth) {
    return (2.0 * nearPlane * farPlane) / (farPlane + nearPlane - depth * (farPlane - nearPlane));
}

float calculateCoC(float depth) {
    float linearDepth = linearizeDepth(depth);
    float coc = (linearDepth - focusDistance) / focusRange;
    return clamp(coc, -1.0, 1.0);
}

void main() {
    float depth = texture(depthTexture, texCoord).r;
    float coc = abs(calculateCoC(depth));

    vec3 color = vec3(0.0);
    float totalWeight = 0.0;
    float radius = coc * bokehRadius;

    for (int i = 0; i < 22; i++) {
        vec2 offset = poissonDisk22[i] * radius / textureSize(colorTexture, 0);
        float sampleDepth = texture(depthTexture, texCoord + offset).r;
        float sampleCoC = abs(calculateCoC(sampleDepth));

        float weight = smoothstep(0.0, 1.0, sampleCoC);
        color += texture(colorTexture, texCoord + offset).rgb * weight;
        totalWeight += weight;
    }

    outColor = vec4(color / max(totalWeight, 0.001), 1.0);
}
高质量的散景（Bokeh）效果需要模拟真实光圈的形状。圆形光圈产生圆形散景点，而多边形光圈（六角形、八角形）产生对应形状的散景。六角形散景可以通过三个方向的分离模糊高效近似。


色彩分级与 LUT
色彩分级（Color Grading）是后处理链中最后的色彩调整环节，用于建立画面的整体色调和氛围。在专业制作中，色彩分级通常使用三维颜色查找表（3D Color LUT）实现，将输入的 RGB 值映射到调整后的 RGB 值。


3D LUT 通常为 32×32×32 或 64×64×64 的三维纹理，在片段着色器中通过一次纹理采样完成任意复杂的色彩变换：


#version 450

layout(set = 0, binding = 0) uniform sampler2D inputTexture;
layout(set = 0, binding = 1) uniform sampler3D colorLUT;

layout(set = 0, binding = 2) uniform GradingParams {
    float lutIntensity;
    float contrast;
    float saturation;
    float brightness;
};

layout(location = 0) in vec2 texCoord;
layout(location = 0) out vec4 outColor;

vec3 applyLUT(vec3 color, float intensity) {
    float lutSize = 32.0;
    vec3 scaled = color * (lutSize - 1.0) / lutSize + 0.5 / lutSize;
    vec3 lutColor = texture(colorLUT, scaled).rgb;
    return mix(color, lutColor, intensity);
}

vec3 adjustContrast(vec3 color, float value) {
    return (color - 0.5) * value + 0.5;
}

vec3 adjustSaturation(vec3 color, float value) {
    float luminance = dot(color, vec3(0.2126, 0.7152, 0.0722));
    return mix(vec3(luminance), color, value);
}

void main() {
    vec3 color = texture(inputTexture, texCoord).rgb;
    color = applyLUT(color, lutIntensity);
    color = adjustContrast(color, contrast);
    color = adjustSaturation(color, saturation);
    color *= brightness;
    outColor = vec4(clamp(color, 0.0, 1.0), 1.0);
}
3D LUT 的优势在于可以在 Photoshop、DaVinci Resolve 等专业工具中由艺术家调整后导出，直接在游戏中加载使用。不同的 LUT 可以表达不同的视觉风格——冷色调、暖色调、复古胶片、赛博朋克等。


小结
    

  • 后处理管线由多个全屏 Pass 串联构成，Ping-Pong 缓冲交替读写优化显存使用
    • 

  • Bloom 通过多级降采样模糊和升采样合并实现高效的大范围辉光，软阈值避免亮度截断
    • 

  • 景深基于薄透镜模型计算散焦圆大小，通过散景采样模拟真实相机焦外效果
    • 

  • 色彩分级使用 3D LUT 实现任意复杂的色彩变换，是建立画面风格的关键工具
    • 

  • 后处理效果的执行顺序很重要：Bloom 在 HDR 空间、色调映射在 Bloom 之后、FXAA 在最后
    • 

  • 每个效果应支持独立开关和参数调节，以适应不同硬件和画质设置
    •
