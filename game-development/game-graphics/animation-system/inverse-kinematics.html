反向动力学

核心概念

反向动力学（Inverse Kinematics, IK）是根据末端效应器（End Effector）的目标位置反算骨骼链各关节角度的技术。与正向动力学（FK）从根节点到末端逐级计算不同，IK 从期望的末端位置反向求解各关节的旋转。在游戏中，IK 使角色能够动态适应环境——脚踩在不平整地面上、手准确抓取物体、头部跟踪注视目标。

IK 求解器的选择取决于骨骼链的长度和精度需求。两骨骼 IK 有解析解，最快最精确，适用于四肢；FABRIK 对任意长度的链状结构收敛快且实现简单；CCD 在有关节约束时表现良好。


两骨骼 IK
两骨骼 IK（Two-Bone IK）是游戏中最常用的 IK 解算器，专门处理由两段骨骼（如大腿+小腿、大臂+小臂）和一个目标位置组成的问题。由于只有两段骨骼，可以使用余弦定理直接计算解析解，无需迭代。


极轴（Pole Vector）是两骨骼 IK 的关键参数，定义了中间关节（肘部/膝盖）的朝向。当大腿和小腿长度确定、目标位置确定时，膝盖可以在一个圆上的任意位置——极轴限制了这个自由度。


interface TwoBoneIKResult {
  rootRotation: [number, number, number, number];
  midRotation: [number, number, number, number];
  solved: boolean;
}

function solveTwoBoneIK(
  rootPos: [number, number, number],
  midPos: [number, number, number],
  endPos: [number, number, number],
  targetPos: [number, number, number],
  poleVector: [number, number, number],
): TwoBoneIKResult {
  const upperLength = vec3Distance(rootPos, midPos);
  const lowerLength = vec3Distance(midPos, endPos);
  const targetDist = vec3Distance(rootPos, targetPos);

  const maxReach = upperLength + lowerLength - 0.001;
  const minReach = Math.abs(upperLength - lowerLength) + 0.001;

  const clampedDist = Math.max(minReach, Math.min(maxReach, targetDist));

  const cosAngle =
    (upperLength * upperLength + clampedDist * clampedDist - lowerLength * lowerLength) /
    (2 * upperLength * clampedDist);
  const upperAngle = Math.acos(Math.max(-1, Math.min(1, cosAngle)));

  const cosKnee =
    (upperLength * upperLength + lowerLength * lowerLength - clampedDist * clampedDist) /
    (2 * upperLength * lowerLength);
  const kneeAngle = Math.acos(Math.max(-1, Math.min(1, cosKnee)));

  const toTarget = vec3Normalize(vec3Sub(targetPos, rootPos));
  const toPole = vec3Normalize(vec3Sub(poleVector, rootPos));

  const forward = toTarget;
  const side = vec3Normalize(vec3Cross(forward, toPole));
  const up = vec3Cross(side, forward);

  const midTarget: [number, number, number] = [
    rootPos[0] + forward[0] * Math.cos(upperAngle) * upperLength + up[0] * Math.sin(upperAngle) * upperLength,
    rootPos[1] + forward[1] * Math.cos(upperAngle) * upperLength + up[1] * Math.sin(upperAngle) * upperLength,
    rootPos[2] + forward[2] * Math.cos(upperAngle) * upperLength + up[2] * Math.sin(upperAngle) * upperLength,
  ];

  const rootRotation = quatFromToRotation(
    vec3Normalize(vec3Sub(midPos, rootPos)),
    vec3Normalize(vec3Sub(midTarget, rootPos)),
  );

  const currentEndDir = vec3Normalize(vec3Sub(endPos, midTarget));
  const desiredEndDir = vec3Normalize(vec3Sub(targetPos, midTarget));
  const midRotation = quatFromToRotation(currentEndDir, desiredEndDir);

  return { rootRotation, midRotation, solved: targetDist <= maxReach };
}

function vec3Distance(a: [number, number, number], b: [number, number, number]): number {
  const dx = a[0] - b[0],
    dy = a[1] - b[1],
    dz = a[2] - b[2];
  return Math.sqrt(dx * dx + dy * dy + dz * dz);
}

function vec3Sub(a: [number, number, number], b: [number, number, number]): [number, number, number] {
  return [a[0] - b[0], a[1] - b[1], a[2] - b[2]];
}

function vec3Normalize(v: [number, number, number]): [number, number, number] {
  const len = Math.sqrt(v[0] * v[0] + v[1] * v[1] + v[2] * v[2]);
  return len > 0.0001 ? [v[0] / len, v[1] / len, v[2] / len] : [0, 0, 0];
}

function vec3Cross(a: [number, number, number], b: [number, number, number]): [number, number, number] {
  return [a[1] * b[2] - a[2] * b[1], a[2] * b[0] - a[0] * b[2], a[0] * b[1] - a[1] * b[0]];
}

function quatFromToRotation(
  from: [number, number, number],
  to: [number, number, number],
): [number, number, number, number] {
  const dot = from[0] * to[0] + from[1] * to[1] + from[2] * to[2];
  const cross = vec3Cross(from, to);
  const w = 1 + dot;
  const len = Math.sqrt(cross[0] * cross[0] + cross[1] * cross[1] + cross[2] * cross[2] + w * w);
  return [cross[0] / len, cross[1] / len, cross[2] / len, w / len];
}
当目标距离超过骨骼链的最大伸展长度时，IK 无法精确到达目标。此时应将目标距离夹到最大长度，使骨骼链尽量伸向目标方向，而不是产生异常姿态。


FABRIK 算法
FABRIK（Forward And Backward Reaching Inverse Kinematics）是一种直观且高效的迭代 IK 算法，通过交替执行前向（从末端到根）和后向（从根到末端）两个阶段来收敛到目标位置。每个阶段沿骨骼链逐节点移动到目标方向，同时保持骨骼长度不变。


FABRIK 的核心操作极其简单：将点 A 移动到点 B 方向上距离为 d 的位置。整个算法由这一个基本操作反复应用构成：


interface FABRIKChain {
  positions: Array<[number, number, number]>;
  lengths: number[];
  tolerance: number;
  maxIterations: number;
}

function solveFABRIK(chain: FABRIKChain, target: [number, number, number]): Array<[number, number, number]> {
  const { positions, lengths, tolerance, maxIterations } = chain;
  const n = positions.length;
  const root: [number, number, number] = [...positions[0]];

  const totalLength = lengths.reduce((sum, l) => sum + l, 0);
  const targetDist = vec3Distance(positions[0], target);

  if (targetDist > totalLength) {
    const dir = vec3Normalize(vec3Sub(target, positions[0]));
    for (let i = 1; i < n; i++) {
      positions[i] = [
        positions[i - 1][0] + dir[0] * lengths[i - 1],
        positions[i - 1][1] + dir[1] * lengths[i - 1],
        positions[i - 1][2] + dir[2] * lengths[i - 1],
      ];
    }
    return positions;
  }

  for (let iter = 0; iter < maxIterations; iter++) {
    const endError = vec3Distance(positions[n - 1], target);
    if (endError < tolerance) break;

    positions[n - 1] = [...target];
    for (let i = n - 2; i >= 0; i--) {
      const dir = vec3Normalize(vec3Sub(positions[i], positions[i + 1]));
      positions[i] = [
        positions[i + 1][0] + dir[0] * lengths[i],
        positions[i + 1][1] + dir[1] * lengths[i],
        positions[i + 1][2] + dir[2] * lengths[i],
      ];
    }

    positions[0] = [...root];
    for (let i = 1; i < n; i++) {
      const dir = vec3Normalize(vec3Sub(positions[i], positions[i - 1]));
      positions[i] = [
        positions[i - 1][0] + dir[0] * lengths[i - 1],
        positions[i - 1][1] + dir[1] * lengths[i - 1],
        positions[i - 1][2] + dir[2] * lengths[i - 1],
      ];
    }
  }
  return positions;
}

脚部 IK 与地面适应
脚部 IK（Foot IK）是游戏中最常见的 IK 应用，使角色的脚准确踩在不平整的地面上，而不是穿透地面或浮空。脚部 IK 的工作流程是：射线检测脚底位置的地面高度 → 计算目标位置 → 两骨骼 IK 求解腿部姿态 → 调整骨盆高度。


interface FootIKSetup {
  hipJointIndex: number;
  kneeJointIndex: number;
  ankleJointIndex: number;
  footLength: number;
  raycastOffset: number;
  maxCorrection: number;
}

interface FootIKResult {
  ankleTarget: [number, number, number];
  hipOffset: number;
  groundNormal: [number, number, number];
  footRotation: [number, number, number, number];
}

function computeFootIK(
  setup: FootIKSetup,
  ankleWorldPos: [number, number, number],
  raycast: (
    origin: [number, number, number],
    direction: [number, number, number],
  ) => { hit: boolean; point: [number, number, number]; normal: [number, number, number] } | null,
): FootIKResult | null {
  const rayOrigin: [number, number, number] = [
    ankleWorldPos[0],
    ankleWorldPos[1] + setup.raycastOffset,
    ankleWorldPos[2],
  ];
  const result = raycast(rayOrigin, [0, -1, 0]);
  if (!result || !result.hit) return null;

  const groundHeight = result.point[1];
  const correction = groundHeight - ankleWorldPos[1];

  if (Math.abs(correction) > setup.maxCorrection) return null;

  const ankleTarget: [number, number, number] = [ankleWorldPos[0], groundHeight + setup.footLength, ankleWorldPos[2]];

  const footRotation = quatFromToRotation([0, 1, 0], result.normal);

  return {
    ankleTarget,
    hipOffset: correction < 0 ? correction : 0,
    groundNormal: result.normal,
    footRotation,
  };
}
脚部 IK 还需要处理骨盆（Hip）的高度调整。当两只脚踩在不同高度的地面上时，需要将骨盆整体下移（取两只脚中较低的偏移量），确保较低的那只脚能到达地面。骨盆调整后再对每条腿分别应用两骨骼 IK。


脚部旋转适应（Foot Rotation）使脚掌与地面法线对齐。在斜坡上，脚掌应该平贴斜面而非保持水平。将地面法线转换为脚部关节的旋转偏移量即可实现这一效果。


注视 IK 与头部追踪
注视 IK（Look-At IK）使角色的头部和眼睛追踪指定目标，是提升角色生动感的重要细节。注视 IK 通常涉及脊柱、颈部和头部三段骨骼的协调旋转，每段骨骼承担一部分总旋转量。

角度限制（Joint Constraints）防止骨骼旋转到不自然的角度。例如颈部不能旋转超过 60°，膝盖只能在一个方向弯曲。约束通常在 IK 求解的每次迭代后应用，将关节角度夹到允许范围内。


注视 IK 还需要处理平滑过渡。当目标快速移动时，头部不应瞬间跳转，而应以有限的角速度追踪。使用弹簧阻尼模型（Spring-Damper）可以产生自然的追踪运动，包括过冲和回弹效果。


小结
    

  • IK 从末端目标位置反算骨骼链关节角度，使角色能动态适应环境
    • 

  • 两骨骼 IK 使用余弦定理直接求解，是四肢 IK 的最优选择
    • 

  • FABRIK 通过简单的前向后向迭代处理任意长度的链状结构，收敛快实现简单
    • 

  • 脚部 IK 结合射线检测和骨盆调整使角色脚底贴合不平整地面
    • 

  • 注视 IK 通过多段骨骼分配旋转量和角度约束实现自然的头部追踪
    • 

  • 关节约束防止不自然的姿态，弹簧阻尼模型提供平滑的追踪运动
    •
