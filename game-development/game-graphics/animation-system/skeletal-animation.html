骨骼动画

核心概念

骨骼动画（Skeletal Animation）是游戏中角色和生物动画的核心技术。它通过定义一组层级结构的骨骼（Skeleton），将网格顶点绑定到骨骼上（Skinning），然后通过旋转和平移骨骼来驱动网格变形。这种方式比逐顶点存储动画关键帧高效得多——几十根骨骼的变换数据远小于数万个顶点的位置数据。

骨骼动画系统的核心数据流是：动画片段 → 采样关键帧 → 计算每根骨骼的本地变换 → 递归计算全局变换 → 生成蒙皮矩阵 → 在顶点着色器中变换顶点。


骨骼层级与绑定姿态
骨骼（Bone / Joint）以树状层级结构组织，每根骨骼相对于父骨骼定义本地变换。根骨骼通常位于角色的髋部或脚底，四肢骨骼沿肢体方向层级展开。


绑定姿态（Bind Pose / T-Pose）是角色建模时骨骼的初始姿态。绑定姿态矩阵（Inverse Bind Matrix）记录了每根骨骼从模型空间到骨骼空间的逆变换，用于计算蒙皮矩阵：


interface Joint {
  name: string;
  parentIndex: number;
  localTransform: {
    translation: [number, number, number];
    rotation: [number, number, number, number];
    scale: [number, number, number];
  };
  inverseBindMatrix: Float32Array;
}

interface Skeleton {
  joints: Joint[];
  rootIndex: number;
}

function computeGlobalTransforms(skeleton: Skeleton, localTransforms: Float32Array[]): Float32Array[] {
  const globals: Float32Array[] = new Array(skeleton.joints.length);

  for (let i = 0; i < skeleton.joints.length; i++) {
    const joint = skeleton.joints[i];
    if (joint.parentIndex < 0) {
      globals[i] = new Float32Array(localTransforms[i]);
    } else {
      globals[i] = new Float32Array(16);
      mat4Multiply(globals[i], globals[joint.parentIndex], localTransforms[i]);
    }
  }
  return globals;
}

function computeSkinningMatrices(skeleton: Skeleton, globalTransforms: Float32Array[]): Float32Array {
  const matrices = new Float32Array(skeleton.joints.length * 16);

  for (let i = 0; i < skeleton.joints.length; i++) {
    const offset = i * 16;
    mat4Multiply(
      matrices.subarray(offset, offset + 16) as unknown as Float32Array,
      globalTransforms[i],
      skeleton.joints[i].inverseBindMatrix,
    );
  }
  return matrices;
}

function mat4Multiply(out: Float32Array, a: Float32Array, b: Float32Array): void {
  for (let i = 0; i < 4; i++) {
    for (let j = 0; j < 4; j++) {
      let sum = 0;
      for (let k = 0; k < 4; k++) {
        sum += a[i * 4 + k] * b[k * 4 + j];
      }
      out[i * 4 + j] = sum;
    }
  }
}
蒙皮矩阵的计算公式为：SkinningMatrix[i] = GlobalTransform[i] × InverseBindMatrix[i]。它表示"先将顶点从模型空间变换到骨骼的绑定空间，再变换到骨骼的当前世界空间"。


关键帧插值与动画采样
动画片段（Animation Clip）由一系列关键帧组成，每个关键帧记录了特定时间点各骨骼的姿态。运行时动画系统根据当前播放时间在相邻关键帧之间插值，得到连续平滑的动画。


骨骼变换由三个分量组成：平移（Translation）、旋转（Rotation）、缩放（Scale）。其中旋转使用四元数（Quaternion）表示，因为四元数支持球面线性插值（Slerp），避免了欧拉角的万向锁问题和矩阵插值的非均匀缩放问题。


interface AnimationChannel {
  jointIndex: number;
  translationKeys: Array<{ time: number; value: [number, number, number] }>;
  rotationKeys: Array<{ time: number; value: [number, number, number, number] }>;
  scaleKeys: Array<{ time: number; value: [number, number, number] }>;
}

function sampleChannel(
  channel: AnimationChannel,
  time: number,
): {
  translation: [number, number, number];
  rotation: [number, number, number, number];
  scale: [number, number, number];
} {
  return {
    translation: interpolateVec3(channel.translationKeys, time),
    rotation: interpolateQuat(channel.rotationKeys, time),
    scale: interpolateVec3(channel.scaleKeys, time),
  };
}

function interpolateQuat(
  keys: Array<{ time: number; value: [number, number, number, number] }>,
  time: number,
): [number, number, number, number] {
  if (keys.length === 0) return [0, 0, 0, 1];
  if (keys.length === 1 || time <= keys[0].time) return keys[0].value;
  if (time >= keys[keys.length - 1].time) return keys[keys.length - 1].value;

  let i = 0;
  while (i < keys.length - 1 && keys[i + 1].time < time) i++;

  const t = (time - keys[i].time) / (keys[i + 1].time - keys[i].time);
  return quatSlerp(keys[i].value, keys[i + 1].value, t);
}

function quatSlerp(
  a: [number, number, number, number],
  b: [number, number, number, number],
  t: number,
): [number, number, number, number] {
  let dot = a[0] * b[0] + a[1] * b[1] + a[2] * b[2] + a[3] * b[3];
  const nb: [number, number, number, number] = dot < 0 ? [-b[0], -b[1], -b[2], -b[3]] : [...b];
  dot = Math.abs(dot);

  if (dot > 0.9995) {
    return [a[0] + t * (nb[0] - a[0]), a[1] + t * (nb[1] - a[1]), a[2] + t * (nb[2] - a[2]), a[3] + t * (nb[3] - a[3])];
  }

  const theta = Math.acos(dot);
  const sinTheta = Math.sin(theta);
  const wa = Math.sin((1 - t) * theta) / sinTheta;
  const wb = Math.sin(t * theta) / sinTheta;

  return [wa * a[0] + wb * nb[0], wa * a[1] + wb * nb[1], wa * a[2] + wb * nb[2], wa * a[3] + wb * nb[3]];
}

function interpolateVec3(
  keys: Array<{ time: number; value: [number, number, number] }>,
  time: number,
): [number, number, number] {
  if (keys.length === 0) return [0, 0, 0];
  if (keys.length === 1 || time <= keys[0].time) return keys[0].value;
  if (time >= keys[keys.length - 1].time) return keys[keys.length - 1].value;

  let i = 0;
  while (i < keys.length - 1 && keys[i + 1].time < time) i++;

  const t = (time - keys[i].time) / (keys[i + 1].time - keys[i].time);
  return [
    keys[i].value[0] + t * (keys[i + 1].value[0] - keys[i].value[0]),
    keys[i].value[1] + t * (keys[i + 1].value[1] - keys[i].value[1]),
    keys[i].value[2] + t * (keys[i + 1].value[2] - keys[i].value[2]),
  ];
}

GPU 蒙皮着色器
蒙皮（Skinning）是将骨骼变换应用到网格顶点的过程。每个顶点通常绑定到 1~4 根骨骼，使用权重值混合多根骨骼的变换。线性混合蒙皮（Linear Blend Skinning, LBS）是最常用的方案：


#version 450

layout(set = 0, binding = 0) uniform SceneData {
    mat4 viewProjection;
};

layout(set = 1, binding = 0) readonly buffer JointMatrices {
    mat4 jointMatrices[];
};

layout(location = 0) in vec3 inPosition;
layout(location = 1) in vec3 inNormal;
layout(location = 2) in vec2 inTexCoord;
layout(location = 3) in uvec4 inJointIndices;
layout(location = 4) in vec4 inJointWeights;

layout(location = 0) out vec3 fragWorldPos;
layout(location = 1) out vec3 fragNormal;
layout(location = 2) out vec2 fragTexCoord;

void main() {
    mat4 skinMatrix =
        inJointWeights.x * jointMatrices[inJointIndices.x] +
        inJointWeights.y * jointMatrices[inJointIndices.y] +
        inJointWeights.z * jointMatrices[inJointIndices.z] +
        inJointWeights.w * jointMatrices[inJointIndices.w];

    vec4 worldPos = skinMatrix * vec4(inPosition, 1.0);
    fragWorldPos = worldPos.xyz;

    mat3 normalMatrix = mat3(skinMatrix);
    fragNormal = normalize(normalMatrix * inNormal);
    fragTexCoord = inTexCoord;

    gl_Position = viewProjection * worldPos;
}
LBS 的已知缺陷是在关节大角度旋转时产生"糖纸扭曲"效应（Candy Wrapper Effect），尤其在肘部和肩部明显。双四元数蒙皮（Dual Quaternion Skinning, DQS）通过使用对偶四元数替代矩阵混合来解决这一问题，能更好地保持体积。


动画压缩与优化
动画数据的存储和传输是动画系统的重要优化点。一个有 100 根骨骼的角色，30fps 的 10 秒动画需要存储约 100 × 300 × (3+4+3) × 4 = 1.2MB 的原始关键帧数据。对于包含大量角色和动画的游戏，压缩至关重要。

四元数量化是最基本且高效的压缩方式。由于四元数是单位四元数（长度为 1），可以省略一个分量并从其余三个恢复。最小三分量法（Smallest Three）选择绝对值最大的分量省略，其余三个量化为 16 位整数：


关键帧削减（Keyframe Reduction）移除可以通过插值近似还原的冗余关键帧。对于线性运动，只需保留起点和终点；对于复杂运动，保留误差超过阈值的关键帧。


ACL（Animation Compression Library）是开源的工业级动画压缩库，被 Unreal Engine 等主流引擎采用。它结合了范围缩减、比特率优化、分段压缩等多种技术，在保持极低误差的同时实现了 10~20 倍的压缩率。


小结
    

  • 骨骼动画通过层级骨骼变换驱动网格变形，蒙皮矩阵是全局变换与绑定逆矩阵的乘积
    • 

  • 四元数球面线性插值保证旋转平滑连续，避免欧拉角的万向锁问题
    • 

  • LBS 是最常用的 GPU 蒙皮方案，每顶点绑定 1~4 根骨骼进行加权混合
    • 

  • 双四元数蒙皮解决了 LBS 在大角度关节处的体积塌陷问题
    • 

  • 动画压缩通过量化、关键帧削减和曲线拟合显著降低数据量
    • 

  • ACL 等工业级压缩库在保持极低误差的同时实现了 10~20 倍压缩率
