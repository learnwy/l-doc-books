程序化动画

核心概念

程序化动画（Procedural Animation）是通过算法和物理规则在运行时实时生成的动画，不依赖预先录制的关键帧数据。它能够让角色和物体动态响应环境变化，产生无限变化的运动效果。程序化动画与手工动画不是对立关系，而是互补——手工动画提供精心设计的基础动作，程序化动画在此基础上添加环境适应、物理响应和细节变化。

程序化动画的核心优势是适应性：同一套规则可以在不同地形、不同速度、不同环境条件下自动产生合理的动画响应，而手工动画需要为每种情况单独制作。


弹簧阻尼系统
弹簧阻尼系统（Spring-Damper System）是程序化动画中最基础也最万能的工具。它模拟一个理想弹簧的物理行为——当当前值与目标值之间存在差异时，弹簧产生恢复力将其拉回目标，阻尼力防止过度振荡。


临界阻尼（Critical Damping）是最常用的阻尼模式，它以最快速度到达目标而不产生过冲。欠阻尼会产生振荡（摇晃效果），过阻尼会使响应变慢。


interface SpringState {
  value: number;
  velocity: number;
}

interface SpringConfig {
  stiffness: number;
  damping: number;
}

function springCriticalDamping(frequency: number): SpringConfig {
  const stiffness = (2 * Math.PI * frequency) ** 2;
  const damping = 2 * Math.sqrt(stiffness);
  return { stiffness, damping };
}

function updateSpring(state: SpringState, target: number, config: SpringConfig, deltaTime: number): SpringState {
  const displacement = state.value - target;
  const springForce = -config.stiffness * displacement;
  const dampingForce = -config.damping * state.velocity;
  const acceleration = springForce + dampingForce;

  const newVelocity = state.velocity + acceleration * deltaTime;
  const newValue = state.value + newVelocity * deltaTime;

  return { value: newValue, velocity: newVelocity };
}

interface Spring3D {
  value: [number, number, number];
  velocity: [number, number, number];
}

function updateSpring3D(state: Spring3D, target: [number, number, number], config: SpringConfig, dt: number): Spring3D {
  const newValue: [number, number, number] = [0, 0, 0];
  const newVelocity: [number, number, number] = [0, 0, 0];

  for (let i = 0; i < 3; i++) {
    const disp = state.value[i] - target[i];
    const acc = -config.stiffness * disp - config.damping * state.velocity[i];
    newVelocity[i] = state.velocity[i] + acc * dt;
    newValue[i] = state.value[i] + newVelocity[i] * dt;
  }

  return { value: newValue, velocity: newVelocity };
}
弹簧系统在游戏中的应用非常广泛：摄像机平滑跟随角色（位置弹簧）、角色转身时的惯性（旋转弹簧）、UI 元素的弹性动画、车辆悬挂的弹跳感、布料和头发的次级运动等。

Verlet 积分与约束求解
Verlet 积分是一种基于位置的物理模拟方法，特别适合绳索、布料和头发等可变形物体。与传统的速度-位置积分不同，Verlet 积分直接从当前和上一帧的位置推导运动，天然保持能量稳定。


Verlet 积分的核心公式：newPos = currentPos + (currentPos - oldPos) + acceleration × dt²


interface VerletPoint {
  current: [number, number, number];
  previous: [number, number, number];
  pinned: boolean;
}

interface DistanceConstraint {
  pointA: number;
  pointB: number;
  restLength: number;
}

interface VerletSimulation {
  points: VerletPoint[];
  constraints: DistanceConstraint[];
  gravity: [number, number, number];
  iterations: number;
}

function simulateVerlet(sim: VerletSimulation, dt: number): void {
  for (const point of sim.points) {
    if (point.pinned) continue;

    const vx = point.current[0] - point.previous[0];
    const vy = point.current[1] - point.previous[1];
    const vz = point.current[2] - point.previous[2];

    point.previous[0] = point.current[0];
    point.previous[1] = point.current[1];
    point.previous[2] = point.current[2];

    point.current[0] += vx + sim.gravity[0] * dt * dt;
    point.current[1] += vy + sim.gravity[1] * dt * dt;
    point.current[2] += vz + sim.gravity[2] * dt * dt;
  }

  for (let iter = 0; iter < sim.iterations; iter++) {
    for (const c of sim.constraints) {
      const a = sim.points[c.pointA];
      const b = sim.points[c.pointB];

      const dx = b.current[0] - a.current[0];
      const dy = b.current[1] - a.current[1];
      const dz = b.current[2] - a.current[2];
      const dist = Math.sqrt(dx * dx + dy * dy + dz * dz);

      if (dist < 0.0001) continue;

      const diff = ((dist - c.restLength) / dist) * 0.5;
      const offsetX = dx * diff;
      const offsetY = dy * diff;
      const offsetZ = dz * diff;

      if (!a.pinned) {
        a.current[0] += offsetX;
        a.current[1] += offsetY;
        a.current[2] += offsetZ;
      }
      if (!b.pinned) {
        b.current[0] -= offsetX;
        b.current[1] -= offsetY;
        b.current[2] -= offsetZ;
      }
    }
  }
}
绳索（Rope）模拟使用一串 Verlet 点和距离约束，固定一端即可得到自然悬垂和摇摆的效果。布料（Cloth）模拟在二维网格上添加横向、纵向和对角线距离约束。约束求解的迭代次数越多，布料越僵硬。


噪声驱动动画
Perlin 噪声和 Simplex 噪声生成时间和空间上连续的随机值，非常适合驱动自然界中看似随机但具有连续性的运动——草木在风中摇摆、火焰的跳动、水面的波纹、角色的微小随机运动。


function proceduralSway(
  time: number,
  position: [number, number, number],
  windStrength: number,
  windDirection: [number, number, number],
): [number, number, number] {
  const freqPrimary = 1.2;
  const freqSecondary = 2.7;
  const freqTertiary = 0.4;

  const phase = position[0] * 0.3 + position[2] * 0.3;

  const primary = Math.sin(time * freqPrimary + phase) * windStrength;
  const secondary = Math.sin(time * freqSecondary + phase * 1.3) * windStrength * 0.3;
  const tertiary = Math.sin(time * freqTertiary + phase * 0.7) * windStrength * 0.15;

  const totalSway = primary + secondary + tertiary;

  return [windDirection[0] * totalSway, Math.abs(totalSway) * 0.1, windDirection[2] * totalSway];
}

function jiggleBone(
  parentVelocity: [number, number, number],
  state: Spring3D,
  config: SpringConfig,
  dt: number,
  gravity: number,
): Spring3D {
  const target: [number, number, number] = [0, -gravity, 0];
  const inertia: [number, number, number] = [
    -parentVelocity[0] * 0.5,
    -parentVelocity[1] * 0.5,
    -parentVelocity[2] * 0.5,
  ];

  const combined: [number, number, number] = [target[0] + inertia[0], target[1] + inertia[1], target[2] + inertia[2]];

  return updateSpring3D(state, combined, config, dt);
}
多层频率叠加（Layered Frequencies）是让程序化运动看起来自然的关键技巧。低频分量提供大幅缓慢的基础运动，中频分量添加中等尺度的变化，高频分量增加细微的颤动。正如自然界中风的运动是多个频率叠加的结果。

Ragdoll 物理与动画混合
Ragdoll 物理使角色在失去控制时（死亡、击飞、摔倒）呈现物理真实的运动效果。每根骨骼作为一个刚体（Rigid Body），骨骼之间通过关节约束（Joint Constraint）连接，整个身体在重力和碰撞力的作用下自然运动。


完全的 Ragdoll 切换（Active Ragdoll）会让角色瞬间失去所有动画控制，看起来像一个布娃娃。更先进的方案是 Powered Ragdoll（驱动型 Ragdoll），在物理关节上施加扭矩使其趋向动画姿态，同时保持物理响应。这样角色可以在保持基础动画的同时被外力推动、被子弹击中时局部反应。

Ragdoll 到动画的恢复（Get-Up）是另一个技术难点。角色从 Ragdoll 状态恢复到站立时，需要先检测身体朝向（正面/背面朝上），选择对应的起身动画，然后将 Ragdoll 的最终姿态混合过渡到起身动画的第一帧。
