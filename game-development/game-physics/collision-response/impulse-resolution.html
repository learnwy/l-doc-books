冲量求解

核心概念

碰撞响应的核心任务是在检测到碰撞后，计算并施加适当的力或冲量，使物体产生物理上合理的反弹与分离行为。冲量求解（Impulse Resolution）是实时物理引擎中最常用的碰撞响应方法，它通过在单一时刻施加瞬时速度变化来模拟碰撞效果，避免了力积分的复杂性。

碰撞信息与接触点
冲量求解的第一步是从碰撞检测阶段获取完整的接触信息。一个标准的接触点（Contact Point）包含碰撞法线、穿透深度、接触位置等关键数据。


interface ContactPoint {
  normal: Vector3;
  penetration: number;
  pointOnA: Vector3;
  pointOnB: Vector3;
}

interface ContactManifold {
  bodyA: RigidBody;
  bodyB: RigidBody;
  contacts: ContactPoint[];
  friction: number;
  restitution: number;
}

class CollisionInfo {
  static computeRelativeVelocity(manifold: ContactManifold, contact: ContactPoint): Vector3 {
    const { bodyA, bodyB } = manifold;
    const rA = contact.pointOnA.sub(bodyA.position);
    const rB = contact.pointOnB.sub(bodyB.position);

    const velA = bodyA.linearVelocity.add(bodyA.angularVelocity.cross(rA));
    const velB = bodyB.linearVelocity.add(bodyB.angularVelocity.cross(rB));

    return velB.sub(velA);
  }

  static computeEffectiveMass(manifold: ContactManifold, contact: ContactPoint, direction: Vector3): number {
    const { bodyA, bodyB } = manifold;
    const rA = contact.pointOnA.sub(bodyA.position);
    const rB = contact.pointOnB.sub(bodyB.position);

    const invMassSum = bodyA.inverseMass + bodyB.inverseMass;

    const rACrossN = rA.cross(direction);
    const rBCrossN = rB.cross(direction);
    const angularA = bodyA.inverseInertia.mulVector(rACrossN).cross(rA).dot(direction);
    const angularB = bodyB.inverseInertia.mulVector(rBCrossN).cross(rB).dot(direction);

    return invMassSum + angularA + angularB;
  }
}
接触法线始终指向从物体 A 到物体 B 的方向，穿透深度为正值表示两物体存在重叠。接触流形（Contact Manifold）聚合了一对物体之间所有活跃的接触点，通常维护 1-4 个点以保证求解稳定性。


法线冲量推导
法线方向的冲量求解是碰撞响应的核心。根据牛顿恢复系数定义，碰撞后沿法线方向的相对速度与碰撞前相对速度之比为 −e-e−e（e 为恢复系数）。结合动量守恒和角动量守恒，可以推导出法线冲量的大小。


class ImpulseResolver {
  resolveNormalImpulse(manifold: ContactManifold, contact: ContactPoint): number {
    const relVel = CollisionInfo.computeRelativeVelocity(manifold, contact);
    const normalVel = relVel.dot(contact.normal);

    if (normalVel > 0) return 0;

    const effectiveMass = CollisionInfo.computeEffectiveMass(manifold, contact, contact.normal);

    const restitution = manifold.restitution;
    let j = (-(1 + restitution) * normalVel) / effectiveMass;

    j = Math.max(j, 0);

    return j;
  }

  applyImpulse(body: RigidBody, impulse: Vector3, contactPoint: Vector3, sign: number): void {
    const scaledImpulse = impulse.scale(sign);
    body.linearVelocity = body.linearVelocity.add(scaledImpulse.scale(body.inverseMass));

    const r = contactPoint.sub(body.position);
    const torque = r.cross(scaledImpulse);
    body.angularVelocity = body.angularVelocity.add(body.inverseInertia.mulVector(torque));
  }

  resolveContact(manifold: ContactManifold, contact: ContactPoint): void {
    const j = this.resolveNormalImpulse(manifold, contact);
    if (j <= 0) return;

    const impulse = contact.normal.scale(j);
    this.applyImpulse(manifold.bodyA, impulse, contact.pointOnA, -1);
    this.applyImpulse(manifold.bodyB, impulse, contact.pointOnB, 1);
  }
}
恢复系数 e 的取值范围为 [0, 1]，其中 0 表示完全非弹性碰撞（物体不反弹），1 表示完全弹性碰撞（动能守恒）。实际游戏中通常取两物体恢复系数的最大值或几何平均值。


接触流形管理
单个碰撞对之间可能存在多个接触点，接触流形负责管理这些点的生命周期和缓存策略。良好的流形管理能显著提升物理模拟的稳定性。


class PersistentContactManifold {
  private contacts: ContactPoint[] = [];
  private readonly maxContacts = 4;
  private normalImpulseCache: number[] = [];
  private tangentImpulseCache: number[] = [];

  addContact(newContact: ContactPoint): void {
    for (let i = 0; i < this.contacts.length; i++) {
      const dist = newContact.pointOnA.sub(this.contacts[i].pointOnA).lengthSq();
      if (dist < 0.001) {
        this.updateContact(i, newContact);
        return;
      }
    }

    if (this.contacts.length < this.maxContacts) {
      this.contacts.push(newContact);
      this.normalImpulseCache.push(0);
      this.tangentImpulseCache.push(0);
    } else {
      const replaceIdx = this.findDeepestPenetrationIndex(newContact);
      this.contacts[replaceIdx] = newContact;
      this.normalImpulseCache[replaceIdx] = 0;
      this.tangentImpulseCache[replaceIdx] = 0;
    }
  }

  private updateContact(index: number, newContact: ContactPoint): void {
    this.contacts[index].normal = newContact.normal;
    this.contacts[index].penetration = newContact.penetration;
  }

  private findDeepestPenetrationIndex(candidate: ContactPoint): number {
    let maxArea = -Infinity;
    let replaceIdx = 0;

    for (let i = 0; i < this.contacts.length; i++) {
      const area = this.computeContactArea(i, candidate);
      if (area > maxArea) {
        maxArea = area;
        replaceIdx = i;
      }
    }
    return replaceIdx;
  }

  private computeContactArea(skipIndex: number, candidate: ContactPoint): number {
    const points: Vector3[] = [];
    for (let i = 0; i < this.contacts.length; i++) {
      if (i !== skipIndex) points.push(this.contacts[i].pointOnA);
    }
    points.push(candidate.pointOnA);
    if (points.length < 3) return 0;
    return points[1].sub(points[0]).cross(points[2].sub(points[0])).length();
  }

  warmStart(resolver: ImpulseResolver, manifold: ContactManifold): void {
    for (let i = 0; i < this.contacts.length; i++) {
      const cachedNormal = this.normalImpulseCache[i];
      if (cachedNormal > 0) {
        const impulse = this.contacts[i].normal.scale(cachedNormal * 0.8);
        resolver.applyImpulse(manifold.bodyA, impulse, this.contacts[i].pointOnA, -1);
        resolver.applyImpulse(manifold.bodyB, impulse, this.contacts[i].pointOnB, 1);
      }
    }
  }
}
接触点缓存的关键策略是"暖启动"（Warm Starting），即将上一帧求解得到的冲量作为本帧迭代的初始值，大幅减少收敛所需的迭代次数。


穿透修正
即使施加了正确的冲量，数值误差仍可能导致物体之间出现微小穿透。穿透修正（Penetration Correction）通过额外的位置调整来消除这些视觉瑕疵。


class PenetrationCorrection {
  private baumgarte = 0.2;
  private slop = 0.005;
  private maxCorrection = 0.2;

  applyBaumgarteStabilization(manifold: ContactManifold, contact: ContactPoint, dt: number): number {
    const penetration = contact.penetration;
    if (penetration < this.slop) return 0;

    const correction = (this.baumgarte / dt) * Math.max(penetration - this.slop, 0);
    return Math.min(correction, this.maxCorrection / dt);
  }

  applySplitImpulse(manifold: ContactManifold, contact: ContactPoint, dt: number): void {
    const penetration = contact.penetration;
    if (penetration < this.slop) return;

    const bias = (this.baumgarte / dt) * Math.max(penetration - this.slop, 0);
    const effectiveMass = CollisionInfo.computeEffectiveMass(manifold, contact, contact.normal);

    const positionImpulse = bias / effectiveMass;

    const { bodyA, bodyB } = manifold;
    const correctionA = contact.normal.scale(-positionImpulse * bodyA.inverseMass);
    const correctionB = contact.normal.scale(positionImpulse * bodyB.inverseMass);

    bodyA.position = bodyA.position.add(correctionA);
    bodyB.position = bodyB.position.add(correctionB);
  }
}

穿透容差（Slop）允许物体间存在微小重叠而不触发修正，避免在静止状态下因反复修正产生抖动。典型值为 0.5-5 毫米。


小结
    

  • 冲量法通过瞬时速度修正实现碰撞响应，避免了力积分的数值问题
    • 

  • 法线冲量的推导基于恢复系数和有效质量，有效质量包含平动和转动分量
    • 

  • 接触流形维护多个接触点并通过暖启动加速收敛
    • 

  • 穿透修正通过 Baumgarte 稳定化或分离冲量消除数值误差造成的重叠
    • 

  • 穿透容差（Slop）参数防止静止物体的修正抖动
