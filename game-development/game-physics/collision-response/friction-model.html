摩擦力模型

核心概念

摩擦力是碰撞响应中不可或缺的组成部分，它阻止接触面上的相对滑动，使物体能够在斜面上停留、轮子能够滚动而非滑动、角色能够在地面上行走。游戏物理引擎中的摩擦力模型基于库仑摩擦定律，将摩擦力约束在法线力所定义的摩擦锥内。

库仑摩擦力学原理
库仑摩擦定律将摩擦力分为静摩擦和动摩擦两个阶段。静摩擦力维持物体静止，其大小可以从零到最大静摩擦力之间变化；当外力超过最大静摩擦力时，物体开始滑动，此时摩擦力变为动摩擦力。


interface FrictionParams {
  staticFriction: number;
  dynamicFriction: number;
}

class CoulombFriction {
  computeFrictionCoefficient(a: FrictionParams, b: FrictionParams): FrictionParams {
    return {
      staticFriction: Math.sqrt(a.staticFriction * b.staticFriction),
      dynamicFriction: Math.sqrt(a.dynamicFriction * b.dynamicFriction),
    };
  }

  computeTangent(relativeVelocity: Vector3, normal: Vector3): Vector3 | null {
    const normalVel = normal.scale(relativeVelocity.dot(normal));
    const tangentVel = relativeVelocity.sub(normalVel);
    const tangentSpeed = tangentVel.length();

    if (tangentSpeed < 1e-6) return null;
    return tangentVel.scale(1 / tangentSpeed);
  }

  computeTangentImpulse(
    manifold: ContactManifold,
    contact: ContactPoint,
    normalImpulse: number,
    friction: FrictionParams,
  ): number {
    const relVel = CollisionInfo.computeRelativeVelocity(manifold, contact);
    const tangent = this.computeTangent(relVel, contact.normal);

    if (!tangent) return 0;

    const tangentVel = relVel.dot(tangent);
    const effectiveMass = CollisionInfo.computeEffectiveMass(manifold, contact, tangent);

    let jt = -tangentVel / effectiveMass;
    const maxStaticFriction = friction.staticFriction * normalImpulse;

    if (Math.abs(jt) <= maxStaticFriction) {
      return jt;
    }

    return -Math.sign(tangentVel) * friction.dynamicFriction * normalImpulse;
  }
}
两物体之间的有效摩擦系数通常取两者摩擦系数的几何平均值（μeff=μa×μb\mu_{eff} = \sqrt{\mu_a \times \mu_b}μeff​=μa​×μb​​），这在大多数情况下给出合理的物理行为。


摩擦锥与 Box 近似
精确的库仑摩擦锥是一个以法线方向为轴的圆锥，切线方向的摩擦力矢量必须位于锥内。在三维空间中，直接求解圆锥约束需要非线性优化。Box 近似将圆锥替换为正方形截面的棱锥，允许沿两个正交切线方向独立求解，大幅简化计算。


class BoxFrictionSolver {
  private tangent1: Vector3 = new Vector3();
  private tangent2: Vector3 = new Vector3();

  computeTangentBasis(normal: Vector3): void {
    if (Math.abs(normal.x) > 0.9) {
      this.tangent1 = new Vector3(0, 1, 0).cross(normal).normalize();
    } else {
      this.tangent1 = new Vector3(1, 0, 0).cross(normal).normalize();
    }
    this.tangent2 = normal.cross(this.tangent1).normalize();
  }

  solve(
    manifold: ContactManifold,
    contact: ContactPoint,
    normalImpulse: number,
    friction: FrictionParams,
  ): { impulse1: number; impulse2: number } {
    this.computeTangentBasis(contact.normal);
    const relVel = CollisionInfo.computeRelativeVelocity(manifold, contact);

    const vel1 = relVel.dot(this.tangent1);
    const vel2 = relVel.dot(this.tangent2);
    const effMass1 = CollisionInfo.computeEffectiveMass(manifold, contact, this.tangent1);
    const effMass2 = CollisionInfo.computeEffectiveMass(manifold, contact, this.tangent2);

    let jt1 = -vel1 / effMass1;
    let jt2 = -vel2 / effMass2;

    const maxFriction = friction.dynamicFriction * normalImpulse;
    jt1 = Math.max(-maxFriction, Math.min(jt1, maxFriction));
    jt2 = Math.max(-maxFriction, Math.min(jt2, maxFriction));

    return { impulse1: jt1, impulse2: jt2 };
  }
}
Box 近似的误差在大多数游戏场景中可以接受，因为玩家很难感知圆锥与方锥之间的微小差异。但在需要精确模拟的场景（如台球），可能需要使用更精确的锥投影方法。


累积冲量钳位
在迭代求解器中，每次迭代都会计算增量冲量并累加到总冲量上。为了保证物理正确性，累积的切线冲量必须始终位于摩擦锥内，这就需要对累积冲量进行钳位（Clamping）而非仅对增量冲量钳位。


class AccumulatedFrictionSolver {
  private accumulatedNormal: number[] = [];
  private accumulatedTangent1: number[] = [];
  private accumulatedTangent2: number[] = [];

  initializeContact(contactCount: number): void {
    this.accumulatedNormal = new Array(contactCount).fill(0);
    this.accumulatedTangent1 = new Array(contactCount).fill(0);
    this.accumulatedTangent2 = new Array(contactCount).fill(0);
  }

  solveFriction(
    contactIdx: number,
    lambdaTangent1: number,
    lambdaTangent2: number,
    friction: number,
  ): { delta1: number; delta2: number } {
    const maxFriction = friction * this.accumulatedNormal[contactIdx];

    const oldT1 = this.accumulatedTangent1[contactIdx];
    const newT1 = Math.max(-maxFriction, Math.min(oldT1 + lambdaTangent1, maxFriction));
    this.accumulatedTangent1[contactIdx] = newT1;
    const delta1 = newT1 - oldT1;

    const oldT2 = this.accumulatedTangent2[contactIdx];
    const newT2 = Math.max(-maxFriction, Math.min(oldT2 + lambdaTangent2, maxFriction));
    this.accumulatedTangent2[contactIdx] = newT2;
    const delta2 = newT2 - oldT2;

    return { delta1, delta2 };
  }

  solveNormal(contactIdx: number, lambdaNormal: number): number {
    const oldN = this.accumulatedNormal[contactIdx];
    const newN = Math.max(0, oldN + lambdaNormal);
    this.accumulatedNormal[contactIdx] = newN;
    return newN - oldN;
  }
}
累积冲量钳位确保了求解器的单调收敛性：每次迭代后系统的约束违反量只会减小或不变，永远不会增大。这是 Sequential Impulse 求解器稳定性的关键保证。


各向异性摩擦
某些游戏场景需要方向相关的摩擦系数，例如轮胎在纵向和横向的摩擦特性完全不同，冰面上冰刀的前后方向几乎无摩擦而侧向摩擦很大。


interface AnisotropicFriction {
  primaryDirection: Vector3;
  primaryFriction: number;
  secondaryFriction: number;
}

class AnisotropicFrictionSolver {
  solve(manifold: ContactManifold, contact: ContactPoint, normalImpulse: number, aniso: AnisotropicFriction): Vector3 {
    const relVel = CollisionInfo.computeRelativeVelocity(manifold, contact);
    const normalComponent = contact.normal.scale(relVel.dot(contact.normal));
    const tangentVel = relVel.sub(normalComponent);

    const primaryDir = aniso.primaryDirection;
    const secondaryDir = contact.normal.cross(primaryDir).normalize();

    const velPrimary = tangentVel.dot(primaryDir);
    const velSecondary = tangentVel.dot(secondaryDir);

    const maxPrimary = aniso.primaryFriction * normalImpulse;
    const maxSecondary = aniso.secondaryFriction * normalImpulse;

    const effMassPrimary = CollisionInfo.computeEffectiveMass(manifold, contact, primaryDir);
    const effMassSecondary = CollisionInfo.computeEffectiveMass(manifold, contact, secondaryDir);

    let jtPrimary = Math.max(-maxPrimary, Math.min(-velPrimary / effMassPrimary, maxPrimary));
    let jtSecondary = Math.max(-maxSecondary, Math.min(-velSecondary / effMassSecondary, maxSecondary));

    return primaryDir.scale(jtPrimary).add(secondaryDir.scale(jtSecondary));
  }
}

小结
    

  • 库仑摩擦模型将摩擦分为静摩擦和动摩擦，切线冲量受法线冲量约束
    • 

  • Box 近似用方形截面替代圆锥，允许沿两个正交方向独立求解
    • 

  • 累积冲量钳位而非增量钳位是迭代求解器单调收敛的关键
    • 

  • 各向异性摩擦支持方向相关的摩擦系数，适用于轮胎和冰面等特殊场景
    • 

  • 有效摩擦系数通常取两物体系数的几何平均值
