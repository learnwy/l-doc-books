约束系统

核心概念

约束系统（Constraint System）限制刚体的运动自由度，使物体之间保持特定的几何关系。关节、铰链、弹簧和接触点都是约束的具体表现。约束求解是物理引擎中计算最密集的部分，直接决定模拟的稳定性和真实感。

距离约束求解
距离约束是最基本的约束类型，它要求两个锚点之间的距离保持恒定。约束方程 C(x) = |p2 - p1| - L = 0，其中 L 是目标距离。


interface Vec3 {
  x: number;
  y: number;
  z: number;
}
interface ConstraintBody {
  position: Vec3;
  velocity: Vec3;
  inverseMass: number;
}

class DistanceConstraint {
  bodyA: ConstraintBody;
  bodyB: ConstraintBody;
  targetDistance: number;
  stiffness: number;
  damping: number;

  constructor(a: ConstraintBody, b: ConstraintBody, distance: number, stiffness = 1.0, damping = 0.1) {
    this.bodyA = a;
    this.bodyB = b;
    this.targetDistance = distance;
    this.stiffness = stiffness;
    this.damping = damping;
  }

  solve(dt: number): void {
    const dx = this.bodyB.position.x - this.bodyA.position.x;
    const dy = this.bodyB.position.y - this.bodyA.position.y;
    const dz = this.bodyB.position.z - this.bodyA.position.z;
    const currentDist = Math.sqrt(dx * dx + dy * dy + dz * dz);
    if (currentDist < 0.0001) return;

    const nx = dx / currentDist;
    const ny = dy / currentDist;
    const nz = dz / currentDist;
    const error = currentDist - this.targetDistance;
    const relVelN =
      (this.bodyB.velocity.x - this.bodyA.velocity.x) * nx +
      (this.bodyB.velocity.y - this.bodyA.velocity.y) * ny +
      (this.bodyB.velocity.z - this.bodyA.velocity.z) * nz;
    const totalInvMass = this.bodyA.inverseMass + this.bodyB.inverseMass;
    if (totalInvMass === 0) return;

    const lambda = -(this.stiffness * error + this.damping * relVelN) / totalInvMass;
    const impulseX = nx * lambda;
    const impulseY = ny * lambda;
    const impulseZ = nz * lambda;

    this.bodyA.velocity.x -= impulseX * this.bodyA.inverseMass;
    this.bodyA.velocity.y -= impulseY * this.bodyA.inverseMass;
    this.bodyA.velocity.z -= impulseZ * this.bodyA.inverseMass;
    this.bodyB.velocity.x += impulseX * this.bodyB.inverseMass;
    this.bodyB.velocity.y += impulseY * this.bodyB.inverseMass;
    this.bodyB.velocity.z += impulseZ * this.bodyB.inverseMass;
  }
}
顺序脉冲求解器
顺序脉冲法（Sequential Impulse, SI）是游戏物理引擎最常用的约束求解算法。它逐个处理约束，为每个约束计算修正脉冲并立即应用到相关物体。通过多次迭代，系统逐渐收敛到满足所有约束的状态。


interface ContactConstraint {
  bodyA: ConstraintBody;
  bodyB: ConstraintBody;
  normal: Vec3;
  penetration: number;
  restitution: number;
  friction: number;
  accumulatedNormalImpulse: number;
  accumulatedTangentImpulse: number;
}

class SequentialImpulseSolver {
  private iterations: number;
  private biasFactor: number;
  private slop: number;

  constructor(iterations = 10, biasFactor = 0.2, slop = 0.005) {
    this.iterations = iterations;
    this.biasFactor = biasFactor;
    this.slop = slop;
  }

  solve(contacts: ContactConstraint[], dt: number): void {
    for (let iter = 0; iter < this.iterations; iter++) {
      for (const contact of contacts) {
        this.solveContact(contact, dt);
      }
    }
  }

  private solveContact(c: ContactConstraint, dt: number): void {
    const relVelX = c.bodyB.velocity.x - c.bodyA.velocity.x;
    const relVelY = c.bodyB.velocity.y - c.bodyA.velocity.y;
    const relVelZ = c.bodyB.velocity.z - c.bodyA.velocity.z;
    const relVelN = relVelX * c.normal.x + relVelY * c.normal.y + relVelZ * c.normal.z;
    const bias = (this.biasFactor / dt) * Math.max(0, c.penetration - this.slop);
    const totalInvMass = c.bodyA.inverseMass + c.bodyB.inverseMass;
    if (totalInvMass === 0) return;

    let lambda = -(relVelN + bias) / totalInvMass;
    const oldAccum = c.accumulatedNormalImpulse;
    c.accumulatedNormalImpulse = Math.max(0, oldAccum + lambda);
    lambda = c.accumulatedNormalImpulse - oldAccum;

    c.bodyA.velocity.x -= c.normal.x * lambda * c.bodyA.inverseMass;
    c.bodyA.velocity.y -= c.normal.y * lambda * c.bodyA.inverseMass;
    c.bodyA.velocity.z -= c.normal.z * lambda * c.bodyA.inverseMass;
    c.bodyB.velocity.x += c.normal.x * lambda * c.bodyB.inverseMass;
    c.bodyB.velocity.y += c.normal.y * lambda * c.bodyB.inverseMass;
    c.bodyB.velocity.z += c.normal.z * lambda * c.bodyB.inverseMass;
  }
}
关节约束实现
关节（Joint）是连接两个刚体的约束，限制它们之间的相对运动。不同类型的关节通过不同的约束方程实现。


interface JointConfig {
  bodyA: ConstraintBody;
  bodyB: ConstraintBody;
  anchorA: Vec3;
  anchorB: Vec3;
  breakForce?: number;
}

class HingeJoint {
  config: JointConfig;
  axis: Vec3;
  minAngle: number;
  maxAngle: number;
  motorSpeed: number;
  motorMaxTorque: number;
  broken: boolean;

  constructor(config: JointConfig, axis: Vec3, minAngle = -Math.PI, maxAngle = Math.PI) {
    this.config = config;
    this.axis = axis;
    this.minAngle = minAngle;
    this.maxAngle = maxAngle;
    this.motorSpeed = 0;
    this.motorMaxTorque = 0;
    this.broken = false;
  }

  solve(dt: number): void {
    if (this.broken) return;
    this.solvePositionConstraint(dt);
    this.solveAngleLimit();
    this.solveMotor(dt);
  }

  private solvePositionConstraint(_dt: number): void {
    const worldAnchorA = this.getWorldAnchor(this.config.bodyA, this.config.anchorA);
    const worldAnchorB = this.getWorldAnchor(this.config.bodyB, this.config.anchorB);
    const errorX = worldAnchorB.x - worldAnchorA.x;
    const errorY = worldAnchorB.y - worldAnchorA.y;
    const errorZ = worldAnchorB.z - worldAnchorA.z;
    const force = Math.sqrt(errorX * errorX + errorY * errorY + errorZ * errorZ);
    if (this.config.breakForce && force > this.config.breakForce) {
      this.broken = true;
    }
  }

  private solveAngleLimit(): void {}
  private solveMotor(_dt: number): void {}
  private getWorldAnchor(body: ConstraintBody, local: Vec3): Vec3 {
    return { x: body.position.x + local.x, y: body.position.y + local.y, z: body.position.z + local.z };
  }
}
小结
    

  • 约束系统通过限制自由度实现物体间的几何关系
    • 

  • 距离约束是最基本的约束类型，通过脉冲修正距离偏差
    • 

  • 顺序脉冲法通过多次迭代逐步收敛，是游戏物理的主流求解器
    • 

  • 脉冲累加（Accumulated Impulse）确保约束不违反物理限制
    • 

  • 关节支持角度限制、电机驱动和断裂检测等高级功能
