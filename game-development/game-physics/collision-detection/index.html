碰撞检测 简介

碰撞检测是游戏物理系统中计算量最大、最具技术挑战的环节。它需要在每一帧判断场景中哪些物体发生了接触或重叠，并提供精确的碰撞信息供后续响应使用。本章将系统讲解碰撞检测的完整流水线和核心算法。

本章涵盖四个主题，按照碰撞检测流水线的各阶段展开。

包围体与宽阶段检测介绍 AABB、OBB、球体等常见包围体类型及其构建方法，讲解宽阶段如何通过包围体快速排除不可能碰撞的物体对，将候选碰撞对数量从 O(n²) 大幅降低。

窄阶段精确检测深入讲解 GJK、EPA、SAT 等精确碰撞检测算法，分析如何判断凸多面体之间的相交关系，以及如何计算碰撞点、碰撞法线和穿透深度等关键信息。

空间加速结构探讨用于加速碰撞检测的空间数据结构，包括均匀网格、动态 AABB 树、扫掠剪裁算法等，分析不同方案在动态场景下的性能特点和适用条件。

连续碰撞检测讲解离散碰撞检测的隧穿问题及其解决方案，介绍 CCD 的基本原理、保守前进算法以及时间细分策略，确保高速运动的物体不会穿过薄墙或小物体。

学习本章时，建议先理解包围体和宽阶段检测建立整体认知，然后深入窄阶段算法掌握精确检测的核心技术，再通过空间加速结构优化检测性能，最后学习连续碰撞检测解决特殊场景下的疑难问题。
