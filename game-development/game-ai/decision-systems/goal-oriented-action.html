目标导向行动规划

核心概念

目标导向行动规划（Goal-Oriented Action Planning，GOAP）是一种让 AI 自主构建行动序列的决策系统。与 FSM 和行为树需要设计师手动连接行为不同，GOAP 只需定义"动作的前置条件和效果"以及"目标状态"，规划器会自动搜索出一条从当前世界状态到目标状态的动作链。这种方法最早由 Jeff Orkin 为《F.E.A.R.》开发，使 AI 能根据环境变化产生新颖的行为组合。

GOAP 的核心价值在于"解耦"——动作的定义与使用完全分离。添加一个新动作（如"拾取手雷"）不需要修改任何已有代码，规划器会自动发现它可以作为"消灭敌人"目标的一个中间步骤。


世界状态与动作定义
GOAP 的基础数据结构包括世界状态（一组布尔/数值属性）和动作（定义前置条件、效果和成本）。规划器在这些数据上进行搜索。


type WorldState = Map<string, boolean | number>;

interface GOAPAction {
  name: string;
  cost: number;
  preconditions: WorldState;
  effects: WorldState;
  isValid(state: WorldState): boolean;
  getDynamicCost(state: WorldState): number;
}

class Action implements GOAPAction {
  name: string;
  cost: number;
  preconditions: WorldState;
  effects: WorldState;

  constructor(
    name: string,
    cost: number,
    preconditions: Record<string, boolean | number>,
    effects: Record<string, boolean | number>,
  ) {
    this.name = name;
    this.cost = cost;
    this.preconditions = new Map(Object.entries(preconditions));
    this.effects = new Map(Object.entries(effects));
  }

  isValid(state: WorldState): boolean {
    for (const [key, value] of this.preconditions) {
      if (state.get(key) !== value) return false;
    }
    return true;
  }

  getDynamicCost(_state: WorldState): number {
    return this.cost;
  }
}

function applyEffects(state: WorldState, effects: WorldState): WorldState {
  const newState = new Map(state);
  for (const [key, value] of effects) {
    newState.set(key, value);
  }
  return newState;
}

function stateMatches(current: WorldState, goal: WorldState): boolean {
  for (const [key, value] of goal) {
    if (current.get(key) !== value) return false;
  }
  return true;
}

const combatActions: GOAPAction[] = [
  new Action('MoveToCover', 2, { hasTarget: true }, { inCover: true, nearEnemy: false }),
  new Action('MoveToEnemy', 3, { hasTarget: true }, { nearEnemy: true }),
  new Action('RangedAttack', 4, { hasAmmo: true, hasTarget: true }, { targetDead: true }),
  new Action('MeleeAttack', 5, { nearEnemy: true, hasTarget: true }, { targetDead: true }),

动作设计的关键是前置条件和效果的粒度。粒度过细（如区分"左手武器"和"右手武器"）会导致搜索空间爆炸，粒度过粗（如只有"能战斗"和"不能战斗"）则限制了规划的灵活性。


反向搜索规划器
GOAP 规划器通常采用反向搜索（Regressive Planning）：从目标状态出发，反向查找哪些动作的效果能满足未达成的目标条件，直到所有条件都在当前世界状态中被满足。反向搜索比正向搜索更高效，因为它只探索与目标相关的动作子集。


interface PlanNode {
  state: WorldState;
  action: GOAPAction | null;
  parent: PlanNode | null;
  gCost: number;
  hCost: number;
  fCost: number;
}

class GOAPPlanner {
  private actions: GOAPAction[];

  constructor(actions: GOAPAction[]) {
    this.actions = actions;
  }

  plan(currentState: WorldState, goal: WorldState): GOAPAction[] | null {
    const openSet: PlanNode[] = [];
    const closedSet = new Set<string>();

    const startNode: PlanNode = {
      state: new Map(currentState),
      action: null,
      parent: null,
      gCost: 0,
      hCost: this.heuristic(currentState, goal),
      fCost: 0,
    };
    startNode.fCost = startNode.gCost + startNode.hCost;
    openSet.push(startNode);

    while (openSet.length > 0) {
      openSet.sort((a, b) => a.fCost - b.fCost);
      const current = openSet.shift()!;

      if (stateMatches(current.state, goal)) {
        return this.extractPlan(current);
      }

      const stateKey = this.stateToKey(current.state);
      if (closedSet.has(stateKey)) continue;
      closedSet.add(stateKey);

      for (const action of this.actions) {
        if (!action.isValid(current.state)) continue;

        const newState = applyEffects(current.state, action.effects);
        const newStateKey = this.stateToKey(newState);
        if (closedSet.has(newStateKey)) continue;

        const gCost = current.gCost + action.getDynamicCost(current.state);
        const hCost = this.heuristic(newState, goal);

        openSet.push({
          state: newState,
          action,
          parent: current,
          gCost,
          hCost,
          fCost: gCost + hCost,
        });
      }
    }
    return null;
  }

  private heuristic(state: WorldState, goal: WorldState): number {
    let unsatisfied = 0;
    for (const [key, value] of goal) {
      if (state.get(key) !== value) unsatisfied++;
    }
    return unsatisfied;
  }

  private extractPlan(node: PlanNode): GOAPAction[] {
    const plan: GOAPAction[] = [];
    let current: PlanNode | null = node;
    while (current?.action) {
      plan.unshift(current.action);
      current = current.parent;
    }
    return plan;
  }

  private stateToKey(state: WorldState): string {
    const entries = Array.from(state.entries()).sort(([a], [b]) => a.localeCompare(b));
    return JSON.stringify(entries);
  }
}

const planner = new GOAPPlanner(combatActions);

规划器使用 A* 搜索，启发式函数为"未满足的目标条件数量"。这个简单的启发式在大多数游戏场景中足够有效。动态成本（getDynamicCost）允许动作根据当前状态调整优先级——例如"远程攻击"在有掩体时成本更低。


多目标优先级管理
实际游戏中 AI 通常有多个目标（消灭敌人、保持存活、完成任务），需要根据当前情况动态调整目标优先级。GOAP 通常结合效用评分来选择当前最重要的目标。


interface GOAPGoal {
  name: string;
  conditions: WorldState;
  priority: (state: WorldState) => number;
  isRelevant: (state: WorldState) => boolean;
}

class GOAPAgent {
  private planner: GOAPPlanner;
  private goals: GOAPGoal[];
  private currentPlan: GOAPAction[] = [];
  private currentPlanIndex = 0;
  private worldState: WorldState;

  constructor(actions: GOAPAction[], goals: GOAPGoal[], initialState: WorldState) {
    this.planner = new GOAPPlanner(actions);
    this.goals = goals;
    this.worldState = new Map(initialState);
  }

  update(): void {
    if (this.currentPlan.length === 0 || this.needsReplan()) {
      this.replan();
    }

    if (this.currentPlanIndex < this.currentPlan.length) {
      const action = this.currentPlan[this.currentPlanIndex];
      if (action.isValid(this.worldState)) {
        this.worldState = applyEffects(this.worldState, action.effects);
        this.currentPlanIndex++;
      } else {
        this.replan();
      }
    }
  }

  private needsReplan(): boolean {
    if (this.currentPlanIndex >= this.currentPlan.length) return true;
    const action = this.currentPlan[this.currentPlanIndex];
    return !action.isValid(this.worldState);
  }

  private replan(): void {
    const sortedGoals = this.goals
      .filter((g) => g.isRelevant(this.worldState))
      .sort((a, b) => b.priority(this.worldState) - a.priority(this.worldState));

    for (const goal of sortedGoals) {
      const plan = this.planner.plan(this.worldState, goal.conditions);
      if (plan && plan.length > 0) {
        this.currentPlan = plan;
        this.currentPlanIndex = 0;
        return;
      }
    }
    this.currentPlan = [];
    this.currentPlanIndex = 0;
  }

  setWorldState(key: string, value: boolean | number): void {
    this.worldState.set(key, value);
  }
}

const soldierGoals: GOAPGoal[] = [

小结
    

  • GOAP 通过"前置条件-效果"模型定义动作，规划器自动搜索动作链达成目标
    • 

  • 反向搜索从目标出发找满足条件的动作，比正向搜索更高效
    • 

  • 新增行为只需定义动作的前置条件和效果，不修改任何已有逻辑
    • 

  • 多目标系统结合效用评分动态调整目标优先级，适应战场变化
    • 

  • 重规划机制确保环境变化时 AI 能及时调整策略
    • 

  • GOAP 计算开销较高，适合精英 AI（Boss、队长）而非大量小兵
