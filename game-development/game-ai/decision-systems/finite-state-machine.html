有限状态机

核心概念

有限状态机（Finite State Machine，FSM）是游戏 AI 中最基础、最直观的决策模型。它将 AI 角色的行为分解为有限个离散状态，每个状态定义一组行为逻辑，状态之间通过条件触发的转换进行切换。FSM 的核心思想是"在某个状态下做某件事，满足条件就切换到另一个状态"。

FSM 的优势在于概念简单、调试直观、执行高效，适合行为模式固定且状态数量有限的 AI（如小兵、陷阱、简单 NPC）。


基础 FSM 实现
一个完整的 FSM 由状态（State）、转换（Transition）和上下文（Context）三部分组成。每个状态有进入、执行和退出三个生命周期回调，转换条件在每帧更新时检查。


interface AIContext {
  health: number;
  maxHealth: number;
  position: { x: number; y: number };
  target: { position: { x: number; y: number }; alive: boolean } | null;
  alertLevel: number;
  homePosition: { x: number; y: number };
}

type ConditionFn = (ctx: AIContext) => boolean;

interface State {
  name: string;
  enter(ctx: AIContext): void;
  execute(ctx: AIContext, dt: number): void;
  exit(ctx: AIContext): void;
}

interface Transition {
  from: string;
  to: string;
  condition: ConditionFn;
  priority: number;
}

class FiniteStateMachine {
  private states: Map<string, State> = new Map();
  private transitions: Transition[] = [];
  private currentState: State | null = null;
  private context: AIContext;

  constructor(context: AIContext) {
    this.context = context;
  }

  addState(state: State): void {
    this.states.set(state.name, state);
  }

  addTransition(from: string, to: string, condition: ConditionFn, priority = 0): void {
    this.transitions.push({ from, to, condition, priority });
  }

  start(initialState: string): void {
    this.currentState = this.states.get(initialState) ?? null;
    this.currentState?.enter(this.context);
  }

  update(dt: number): void {
    if (!this.currentState) return;

    const validTransitions = this.transitions
      .filter((t) => t.from === this.currentState!.name && t.condition(this.context))
      .sort((a, b) => b.priority - a.priority);

    if (validTransitions.length > 0) {
      const transition = validTransitions[0];
      const nextState = this.states.get(transition.to);
      if (nextState) {
        this.currentState.exit(this.context);
        this.currentState = nextState;
        this.currentState.enter(this.context);
      }
    }

    this.currentState.execute(this.context, dt);
  }

  getCurrentStateName(): string {
    return this.currentState?.name ?? 'none';
  }
}
这种实现将状态逻辑和转换条件分离，每帧按优先级检查所有从当前状态出发的转换。优先级机制确保紧急情况（如"逃跑"）优先于常规转换。


守卫 AI 实战
用 FSM 实现一个守卫 AI，包含巡逻、调查、追击、攻击和撤退五个状态。这个例子展示了 FSM 在实际游戏中如何组织多种行为。


function distanceTo(a: { x: number; y: number }, b: { x: number; y: number }): number {
  return Math.sqrt((a.x - b.x) ** 2 + (a.y - b.y) ** 2);
}

const patrolState: State = {
  name: 'patrol',
  enter(ctx) {
    ctx.alertLevel = 0;
  },
  execute(ctx, dt) {
    const angle = Date.now() * 0.001;
    ctx.position.x = ctx.homePosition.x + Math.cos(angle) * 100;
    ctx.position.y = ctx.homePosition.y + Math.sin(angle) * 100;
  },
  exit() {},
};

const investigateState: State = {
  name: 'investigate',
  enter(ctx) {
    ctx.alertLevel = 50;
  },
  execute(ctx, dt) {
    if (ctx.target) {
      const dir = {
        x: ctx.target.position.x - ctx.position.x,
        y: ctx.target.position.y - ctx.position.y,
      };
      const len = Math.sqrt(dir.x ** 2 + dir.y ** 2);
      if (len > 0) {
        ctx.position.x += (dir.x / len) * 60 * dt;
        ctx.position.y += (dir.y / len) * 60 * dt;
      }
    }
  },
  exit() {},
};

const chaseState: State = {
  name: 'chase',
  enter(ctx) {
    ctx.alertLevel = 100;
  },
  execute(ctx, dt) {
    if (ctx.target) {
      const dir = {
        x: ctx.target.position.x - ctx.position.x,
        y: ctx.target.position.y - ctx.position.y,
      };
      const len = Math.sqrt(dir.x ** 2 + dir.y ** 2);
      if (len > 0) {
        ctx.position.x += (dir.x / len) * 120 * dt;
        ctx.position.y += (dir.y / len) * 120 * dt;
      }
    }
  },
  exit() {},
};

const attackState: State = {
  name: 'attack',
  enter() {},
  execute() {},
  exit() {},
};

const retreatState: State = {
  name: 'retreat',
  enter() {},
  execute(ctx, dt) {
    const dir = {
      x: ctx.homePosition.x - ctx.position.x,
      y: ctx.homePosition.y - ctx.position.y,
    };
    const len = Math.sqrt(dir.x ** 2 + dir.y ** 2);
    if (len > 0) {
      ctx.position.x += (dir.x / len) * 80 * dt;
      ctx.position.y += (dir.y / len) * 80 * dt;
    }
  },
  exit() {},
};

function createGuardFSM(context: AIContext): FiniteStateMachine {
  const fsm = new FiniteStateMachine(context);

  fsm.addState(patrolState);
  fsm.addState(investigateState);
  fsm.addState(chaseState);
  fsm.addState(attackState);
  fsm.addState(retreatState);

  fsm.addTransition(
    'patrol',
    'investigate',
    (ctx) => ctx.target !== null && distanceTo(ctx.position, ctx.target.position) < 200,
  );
  fsm.addTransition('investigate', 'chase', (ctx) => ctx.target !== null && ctx.alertLevel >= 80);
  fsm.addTransition(
    'chase',
    'attack',
    (ctx) => ctx.target !== null && distanceTo(ctx.position, ctx.target.position) < 30,
  );
  fsm.addTransition(
    'attack',
    'chase',
    (ctx) => ctx.target !== null && distanceTo(ctx.position, ctx.target.position) > 50,
  );
  fsm.addTransition('chase', 'patrol', (ctx) => ctx.target === null || !ctx.target.alive);
  fsm.addTransition('investigate', 'patrol', (ctx) => ctx.target === null);
  fsm.addTransition('attack', 'retreat', (ctx) => ctx.health < ctx.maxHealth * 0.2, 10);
  fsm.addTransition('chase', 'retreat', (ctx) => ctx.health < ctx.maxHealth * 0.2, 10);
  fsm.addTransition('retreat', 'patrol', (ctx) => distanceTo(ctx.position, ctx.homePosition) < 10);

  fsm.start('patrol');
  return fsm;
}
守卫 AI 的状态转换图展示了 FSM 的典型模式：感知→决策→行动的循环。撤退转换设置了更高的优先级（10），确保低血量时无论处于攻击还是追击状态都会立即撤退。


层级有限状态机
当 AI 行为复杂度增长时，简单 FSM 面临"状态爆炸"问题：N 个状态可能需要 N² 个转换。层级有限状态机（HFSM）通过将相关状态组织为嵌套层级来缓解这一问题，子状态机共享父级的公共转换。


class HierarchicalFSM {
  private name: string;
  private states: Map<string, State | HierarchicalFSM> = new Map();
  private transitions: Transition[] = [];
  private currentChild: string | null = null;
  private parentTransitions: Transition[] = [];

  constructor(name: string) {
    this.name = name;
  }

  addState(name: string, state: State | HierarchicalFSM): void {
    this.states.set(name, state);
  }

  addTransition(from: string, to: string, condition: ConditionFn, priority = 0): void {
    this.transitions.push({ from, to, condition, priority });
  }

  addGlobalTransition(to: string, condition: ConditionFn, priority = 0): void {
    this.parentTransitions.push({ from: '*', to, condition, priority });
  }

  enter(ctx: AIContext): void {
    if (this.currentChild) {
      const child = this.states.get(this.currentChild);
      if (child) {
        if ('enter' in child) child.enter(ctx);
      }
    }
  }

  execute(ctx: AIContext, dt: number): void {
    for (const t of this.parentTransitions.sort((a, b) => b.priority - a.priority)) {
      if (t.condition(ctx)) {
        this.switchTo(t.to, ctx);
        break;
      }
    }

    if (this.currentChild) {
      const validTransitions = this.transitions
        .filter((t) => t.from === this.currentChild && t.condition(ctx))
        .sort((a, b) => b.priority - a.priority);

      if (validTransitions.length > 0) {
        this.switchTo(validTransitions[0].to, ctx);
      }

      const child = this.states.get(this.currentChild);
      if (child && 'execute' in child) {
        child.execute(ctx, dt);
      }
    }
  }

  exit(ctx: AIContext): void {
    if (this.currentChild) {
      const child = this.states.get(this.currentChild);
      if (child && 'exit' in child) child.exit(ctx);
    }
  }

  start(initialChild: string, ctx: AIContext): void {
    this.currentChild = initialChild;
    const child = this.states.get(initialChild);
    if (child && 'enter' in child) child.enter(ctx);
  }

  private switchTo(target: string, ctx: AIContext): void {
    if (this.currentChild) {
      const old = this.states.get(this.currentChild);
      if (old && 'exit' in old) old.exit(ctx);
    }
    this.currentChild = target;
    const next = this.states.get(target);
    if (next && 'enter' in next) next.enter(ctx);
  }
}
HFSM 的关键优势是全局转换（addGlobalTransition）：无论子状态机内部处于何种状态，当满足全局条件时都会触发转换。例如"血量低于 20%"触发全局撤退，不需要在每个子状态中重复定义。


事件驱动 FSM
每帧轮询所有转换条件的做法在状态和转换数量多时效率低下。事件驱动 FSM 将轮询改为监听，只有当相关事件发生时才检查转换条件，大幅减少无效计算。


type EventType = 'enemy_spotted' | 'enemy_lost' | 'damage_taken' | 'health_restored' | 'arrived' | 'timer_expired';

interface AIEvent {
  type: EventType;
  data: Record<string, unknown>;
}

interface EventDrivenState {
  name: string;
  enter(ctx: AIContext): void;
  execute(ctx: AIContext, dt: number): void;
  exit(ctx: AIContext): void;
  handleEvent(ctx: AIContext, event: AIEvent): string | null;
}

class EventDrivenFSM {
  private states: Map<string, EventDrivenState> = new Map();
  private currentState: EventDrivenState | null = null;
  private context: AIContext;
  private eventQueue: AIEvent[] = [];

  constructor(context: AIContext) {
    this.context = context;
  }

  addState(state: EventDrivenState): void {
    this.states.set(state.name, state);
  }

  start(initialState: string): void {
    this.currentState = this.states.get(initialState) ?? null;
    this.currentState?.enter(this.context);
  }

  pushEvent(event: AIEvent): void {
    this.eventQueue.push(event);
  }

  update(dt: number): void {
    while (this.eventQueue.length > 0) {
      const event = this.eventQueue.shift()!;
      if (this.currentState) {
        const nextStateName = this.currentState.handleEvent(this.context, event);
        if (nextStateName) {
          const nextState = this.states.get(nextStateName);
          if (nextState) {
            this.currentState.exit(this.context);
            this.currentState = nextState;
            this.currentState.enter(this.context);
          }
        }
      }
    }
    this.currentState?.execute(this.context, dt);
  }
}

const eventPatrolState: EventDrivenState = {
  name: 'patrol',
  enter(ctx) {
    ctx.alertLevel = 0;
  },
  execute(ctx, dt) {
    const angle = Date.now() * 0.001;
    ctx.position.x = ctx.homePosition.x + Math.cos(angle) * 100;
    ctx.position.y = ctx.homePosition.y + Math.sin(angle) * 100;
  },
  exit() {},
  handleEvent(_ctx, event) {
    if (event.type === 'enemy_spotted') return 'chase';
    if (event.type === 'damage_taken') return 'alert';
    return null;
  },
};

事件驱动 FSM 在大量 AI 角色同时运行的场景中优势明显——如果 1000 个守卫中只有 10 个发现了敌人，只需处理 10 个事件而非检查 1000×N 个转换条件。


小结
    

  • FSM 将 AI 行为分解为离散状态和条件转换，概念直观、调试方便
    • 

  • 基础 FSM 适合 3-8 个状态的简单 AI，超过 10 个状态需考虑层级化
    • 

  • 层级 FSM 通过嵌套子状态机和全局转换缓解状态爆炸问题
    • 

  • 事件驱动 FSM 将轮询改为监听，在大量 AI 并发场景中性能更优
    • 

  • FSM 是其他决策系统的基础——行为树的节点、效用 AI 的动作选择都可用 FSM 实现
    • 

  • 当状态数量超过 20-30 个或需要高度动态的行为组合时，应考虑升级为行为树或 GOAP
