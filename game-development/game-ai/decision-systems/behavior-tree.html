行为树

核心概念

行为树（Behavior Tree，BT）是现代游戏 AI 中最主流的决策架构，它用树状结构组织 AI 行为，通过组合节点（Composite）、装饰节点（Decorator）和叶节点（Leaf）的嵌套形成复杂的行为逻辑。行为树克服了 FSM 的状态爆炸问题，具有模块化、可复用、易调试的特点，是 Unreal Engine、Unity 等主流引擎的标准 AI 方案。

行为树的执行遵循 tick 模式：每帧从根节点开始向下遍历，节点返回三种状态之一——SUCCESS（成功）、FAILURE（失败）或 RUNNING（执行中）。RUNNING 状态允许行为跨多帧执行。


节点系统实现
行为树的核心是节点的多态设计。所有节点实现统一的 tick 接口，组合节点管理子节点的执行策略，装饰节点修饰单个子节点的行为。


enum NodeStatus {
  SUCCESS = 'success',
  FAILURE = 'failure',
  RUNNING = 'running',
}

interface Blackboard {
  get<T>(key: string): T | undefined;
  set<T>(key: string, value: T): void;
  has(key: string): boolean;
}

class SimpleBlackboard implements Blackboard {
  private data = new Map<string, unknown>();
  get<T>(key: string): T | undefined {
    return this.data.get(key) as T | undefined;
  }
  set<T>(key: string, value: T): void {
    this.data.set(key, value);
  }
  has(key: string): boolean {
    return this.data.has(key);
  }
}

abstract class BTNode {
  abstract tick(blackboard: Blackboard, dt: number): NodeStatus;
}

class SequenceNode extends BTNode {
  private children: BTNode[];
  private runningIdx = 0;

  constructor(children: BTNode[]) {
    super();
    this.children = children;
  }

  tick(blackboard: Blackboard, dt: number): NodeStatus {
    for (let i = this.runningIdx; i < this.children.length; i++) {
      const status = this.children[i].tick(blackboard, dt);
      if (status === NodeStatus.RUNNING) {
        this.runningIdx = i;
        return NodeStatus.RUNNING;
      }
      if (status === NodeStatus.FAILURE) {
        this.runningIdx = 0;
        return NodeStatus.FAILURE;
      }
    }
    this.runningIdx = 0;
    return NodeStatus.SUCCESS;
  }
}

class SelectorNode extends BTNode {
  private children: BTNode[];
  private runningIdx = 0;

  constructor(children: BTNode[]) {
    super();
    this.children = children;
  }

  tick(blackboard: Blackboard, dt: number): NodeStatus {
    for (let i = this.runningIdx; i < this.children.length; i++) {
      const status = this.children[i].tick(blackboard, dt);
      if (status === NodeStatus.RUNNING) {
        this.runningIdx = i;
        return NodeStatus.RUNNING;
      }
      if (status === NodeStatus.SUCCESS) {
        this.runningIdx = 0;
        return NodeStatus.SUCCESS;
      }
    }
    this.runningIdx = 0;
    return NodeStatus.FAILURE;
  }
}

class ParallelNode extends BTNode {
  private children: BTNode[];
  private successThreshold: number;

  constructor(children: BTNode[], successThreshold: number) {
    super();
    this.children = children;
    this.successThreshold = successThreshold;
  }

  tick(blackboard: Blackboard, dt: number): NodeStatus {
    let successCount = 0;
    let failureCount = 0;

    for (const child of this.children) {
      const status = child.tick(blackboard, dt);
      if (status === NodeStatus.SUCCESS) successCount++;
      if (status === NodeStatus.FAILURE) failureCount++;
    }

    if (successCount >= this.successThreshold) return NodeStatus.SUCCESS;
    if (failureCount > this.children.length - this.successThreshold) return NodeStatus.FAILURE;
    return NodeStatus.RUNNING;
  }
}
Sequence 实现了记忆功能（runningIdx）：当某个子节点返回 RUNNING 时，下一帧直接从该节点继续执行，而不是从头开始。这对于"移动到目标"这类需要多帧完成的行为至关重要。


装饰器与条件节点
装饰节点是行为树灵活性的关键，它们修改子节点的执行逻辑——反转结果、限制执行次数、添加冷却时间等。条件节点则负责感知检测，充当行为的前置门控。


class InverterNode extends BTNode {
  private child: BTNode;
  constructor(child: BTNode) {
    super();
    this.child = child;
  }

  tick(blackboard: Blackboard, dt: number): NodeStatus {
    const status = this.child.tick(blackboard, dt);
    if (status === NodeStatus.SUCCESS) return NodeStatus.FAILURE;
    if (status === NodeStatus.FAILURE) return NodeStatus.SUCCESS;
    return NodeStatus.RUNNING;
  }
}

class RepeatNode extends BTNode {
  private child: BTNode;
  private maxRepeats: number;
  private currentRepeat = 0;

  constructor(child: BTNode, maxRepeats: number) {
    super();
    this.child = child;
    this.maxRepeats = maxRepeats;
  }

  tick(blackboard: Blackboard, dt: number): NodeStatus {
    while (this.currentRepeat < this.maxRepeats) {
      const status = this.child.tick(blackboard, dt);
      if (status === NodeStatus.RUNNING) return NodeStatus.RUNNING;
      if (status === NodeStatus.FAILURE) {
        this.currentRepeat = 0;
        return NodeStatus.FAILURE;
      }
      this.currentRepeat++;
    }
    this.currentRepeat = 0;
    return NodeStatus.SUCCESS;
  }
}

class CooldownNode extends BTNode {
  private child: BTNode;
  private cooldownTime: number;
  private lastExecutionTime = -Infinity;

  constructor(child: BTNode, cooldownTime: number) {
    super();
    this.child = child;
    this.cooldownTime = cooldownTime;
  }

  tick(blackboard: Blackboard, dt: number): NodeStatus {
    const now = blackboard.get<number>('time') ?? 0;
    if (now - this.lastExecutionTime < this.cooldownTime) {
      return NodeStatus.FAILURE;
    }
    const status = this.child.tick(blackboard, dt);
    if (status !== NodeStatus.RUNNING) {
      this.lastExecutionTime = now;
    }
    return status;
  }
}

class ConditionNode extends BTNode {
  private predicate: (bb: Blackboard) => boolean;
  constructor(predicate: (bb: Blackboard) => boolean) {
    super();
    this.predicate = predicate;
  }
  tick(blackboard: Blackboard): NodeStatus {
    return this.predicate(blackboard) ? NodeStatus.SUCCESS : NodeStatus.FAILURE;
  }
}

class ActionNode extends BTNode {
  private action: (bb: Blackboard, dt: number) => NodeStatus;
  constructor(action: (bb: Blackboard, dt: number) => NodeStatus) {
    super();
    this.action = action;
  }
  tick(blackboard: Blackboard, dt: number): NodeStatus {
    return this.action(blackboard, dt);
  }
}
装饰器的组合是行为树强大的根源。例如 Cooldown(3s, Sequence([Condition("hasTarget"), Action("castFireball")])) 表达了"每 3 秒检测目标并释放火球"这一行为，无需任何状态管理代码。


黑板数据共享
黑板（Blackboard）是行为树节点之间共享数据的标准机制。它是一个键值存储，节点可以读写其中的数据，实现感知系统与决策系统的解耦。


interface BlackboardKey<T> {
  name: string;
  defaultValue?: T;
}

const BB_TARGET = { name: 'target' } as BlackboardKey<{ x: number; y: number; id: number }>;
const BB_HEALTH = { name: 'health', defaultValue: 100 } as BlackboardKey<number>;
const BB_ALERT = { name: 'alertLevel', defaultValue: 0 } as BlackboardKey<number>;

class TypedBlackboard {
  private data = new Map<string, unknown>();
  private observers = new Map<string, ((value: unknown) => void)[]>();

  get<T>(key: BlackboardKey<T>): T {
    if (this.data.has(key.name)) return this.data.get(key.name) as T;
    return key.defaultValue as T;
  }

  set<T>(key: BlackboardKey<T>, value: T): void {
    this.data.set(key.name, value);
    const callbacks = this.observers.get(key.name);
    if (callbacks) {
      for (const cb of callbacks) cb(value);
    }
  }

  observe<T>(key: BlackboardKey<T>, callback: (value: T) => void): () => void {
    const callbacks = this.observers.get(key.name) ?? [];
    callbacks.push(callback as (value: unknown) => void);
    this.observers.set(key.name, callbacks);
    return () => {
      const idx = callbacks.indexOf(callback as (value: unknown) => void);
      if (idx >= 0) callbacks.splice(idx, 1);
    };
  }
}

function buildSoldierBT(): BTNode {
  return new SelectorNode([
    new SequenceNode([
      new ConditionNode((bb) => (bb as TypedBlackboard).get(BB_HEALTH) < 20),
      new ActionNode((bb) => {
        const typed = bb as TypedBlackboard;
        const target = typed.get(BB_TARGET);
        if (!target) return NodeStatus.FAILURE;
        return NodeStatus.RUNNING;
      }),
    ]),
    new SequenceNode([
      new ConditionNode((bb) => (bb as TypedBlackboard).get(BB_TARGET) !== undefined),
      new ConditionNode((bb) => (bb as TypedBlackboard).get(BB_ALERT) >= 80),
      new CooldownNode(new ActionNode(() => NodeStatus.SUCCESS), 2.0),
    ]),
    new SequenceNode([
      new ActionNode((bb, dt) => {
        const typed = bb as TypedBlackboard;
        const patrol = typed.get({ name: 'patrolProgress', defaultValue: 0 } as BlackboardKey<number>);
        typed.set({ name: 'patrolProgress' } as BlackboardKey<number>, patrol + dt * 0.1);
        return patrol >= 1.0 ? NodeStatus.SUCCESS : NodeStatus.RUNNING;
      }),
    ]),
  ]);
}

黑板的 observe 方法支持响应式更新——当感知系统写入新的目标信息时，相关行为可以被主动通知而非被动轮询。


小结
    

  • 行为树用树状结构组织 AI 行为，通过 Sequence/Selector/Parallel 三种组合策略实现复杂逻辑
    • 

  • 三态返回（SUCCESS/FAILURE/RUNNING）支持跨帧行为，RUNNING 记忆机制避免重复执行
    • 

  • 装饰节点（Inverter、Repeat、Cooldown）提供灵活的行为修饰能力
    • 

  • 黑板模式实现节点间的数据解耦，类型安全键和观察者增强工程质量
    • 

  • 行为树是 Unreal Engine、Unity 等引擎的标准 AI 方案，行业接受度最高
    • 

  • 对于需要更高灵活性的场景，可结合效用 AI 实现动态优先级选择
