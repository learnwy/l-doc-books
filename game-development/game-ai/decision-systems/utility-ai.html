效用 AI

核心概念

效用 AI（Utility AI）是一种基于评分的决策系统，它为每个可选行为计算一个效用值（Utility Score），然后选择效用最高的行为执行。与 FSM 的硬编码状态转换和行为树的固定优先级不同，效用 AI 让 AI 角色的决策具有连续性和自然的权衡能力，能够在多种需求之间做出平滑的优先级调整。

效用 AI 的核心优势在于"权衡"——当 AI 同时面临多种需求时（饥饿、恐惧、愤怒、好奇），它不需要显式编写优先级规则，而是通过评分曲线自动产生合理的行为选择。


评估函数与响应曲线
效用 AI 的质量取决于评估函数（Scoring Function）的设计。评估函数将游戏状态映射到 [0, 1] 区间的分数，不同的响应曲线（Response Curve）产生不同的行为特征。


type CurveType = 'linear' | 'quadratic' | 'exponential' | 'logistic' | 'step' | 'piecewise';

interface CurveConfig {
  type: CurveType;
  slope?: number;
  exponent?: number;
  offset?: number;
  steepness?: number;
  midpoint?: number;
  threshold?: number;
  invert?: boolean;
}

class ResponseCurve {
  private config: CurveConfig;

  constructor(config: CurveConfig) {
    this.config = config;
  }

  evaluate(x: number): number {
    const clamped = Math.max(0, Math.min(1, x));
    let result: number;

    switch (this.config.type) {
      case 'linear':
        result = (this.config.slope ?? 1) * clamped + (this.config.offset ?? 0);
        break;
      case 'quadratic':
        result = Math.pow(clamped, this.config.exponent ?? 2) * (this.config.slope ?? 1) + (this.config.offset ?? 0);
        break;
      case 'exponential':
        result = Math.pow(this.config.exponent ?? 2, this.config.slope ?? 1 * clamped) - 1;
        break;
      case 'logistic': {
        const k = this.config.steepness ?? 10;
        const m = this.config.midpoint ?? 0.5;
        result = 1 / (1 + Math.exp(-k * (clamped - m)));
        break;
      }
      case 'step':
        result = clamped >= (this.config.threshold ?? 0.5) ? 1 : 0;
        break;
      default:
        result = clamped;
    }

    result = Math.max(0, Math.min(1, result));
    return this.config.invert ? 1 - result : result;
  }
}

interface ConsiderationConfig {
  name: string;
  inputFn: (context: GameContext) => number;
  curve: ResponseCurve;
  weight: number;
}

interface GameContext {
  health: number;
  maxHealth: number;
  ammo: number;
  maxAmmo: number;
  distanceToEnemy: number;
  maxEngageDistance: number;
  distanceToAlly: number;
  coverAvailable: boolean;
  enemyCount: number;
  threatLevel: number;
}

class Consideration {
  private config: ConsiderationConfig;

  constructor(config: ConsiderationConfig) {
    this.config = config;
  }

  score(context: GameContext): number {
    const rawInput = this.config.inputFn(context);
    const normalizedInput = Math.max(0, Math.min(1, rawInput));
    return this.config.curve.evaluate(normalizedInput) * this.config.weight;
  }

  get name(): string {
    return this.config.name;
  }
}

曲线选择直接影响 AI 的"性格"：使用二次曲线的血量评估让 AI 在半血时不太紧张、低血时极度紧张，这比线性反应更接近人类直觉。


行为评估与选择
效用 AI 的行为（Action）由多个考量因素（Consideration）组合评分。每个行为的最终分数是其所有考量因素分数的聚合结果，系统选择最高分的行为执行。


type AggregationMethod = 'multiply' | 'average' | 'min' | 'max';

interface ActionConfig {
  name: string;
  considerations: Consideration[];
  aggregation: AggregationMethod;
  basePriority: number;
  cooldown: number;
}

class UtilityAction {
  private config: ActionConfig;
  private lastExecutionTime = -Infinity;

  constructor(config: ActionConfig) {
    this.config = config;
  }

  score(context: GameContext, currentTime: number): number {
    if (currentTime - this.lastExecutionTime < this.config.cooldown) return 0;

    const scores = this.config.considerations.map((c) => c.score(context));

    if (scores.some((s) => s <= 0)) return 0;

    let aggregated: number;
    switch (this.config.aggregation) {
      case 'multiply': {
        const modFactor = 1 - 1 / this.config.considerations.length;
        const product = scores.reduce((acc, s) => acc * s, 1);
        aggregated = product + (1 - product) * modFactor * product;
        break;
      }
      case 'average':
        aggregated = scores.reduce((a, b) => a + b, 0) / scores.length;
        break;
      case 'min':
        aggregated = Math.min(...scores);
        break;
      case 'max':
        aggregated = Math.max(...scores);
        break;
    }

    return aggregated * this.config.basePriority;
  }

  markExecuted(time: number): void {
    this.lastExecutionTime = time;
  }

  get name(): string {
    return this.config.name;
  }
}

type SelectionStrategy = 'highest' | 'weighted_random' | 'top_n_random';

class UtilityAI {
  private actions: UtilityAction[];
  private strategy: SelectionStrategy;
  private topN: number;

  constructor(actions: UtilityAction[], strategy: SelectionStrategy = 'highest', topN = 3) {
    this.actions = actions;
    this.strategy = strategy;
    this.topN = topN;
  }

  decide(context: GameContext, currentTime: number): UtilityAction | null {
    const scored = this.actions
      .map((action) => ({ action, score: action.score(context, currentTime) }))
      .filter((entry) => entry.score > 0)
      .sort((a, b) => b.score - a.score);

    if (scored.length === 0) return null;

    switch (this.strategy) {
      case 'highest':
        return scored[0].action;
      case 'weighted_random': {
        const totalScore = scored.reduce((sum, e) => sum + e.score, 0);
        let roll = Math.random() * totalScore;
        for (const entry of scored) {
          roll -= entry.score;
          if (roll <= 0) return entry.action;
        }
        return scored[0].action;
      }
      case 'top_n_random': {
        const candidates = scored.slice(0, this.topN);
        const totalScore = candidates.reduce((sum, e) => sum + e.score, 0);
        let roll = Math.random() * totalScore;
        for (const entry of candidates) {
          roll -= entry.score;
          if (roll <= 0) return entry.action;
        }
        return candidates[0].action;
      }
    }
  }
}
weighted_random 策略在得分接近的行为之间引入随机性，让同类型的 AI 角色表现出不同的行为倾向，避免所有敌人同时做出完全相同的决策。top_n_random 进一步限制随机范围，确保不会选到明显不合理的低分行为。


多需求系统设计
效用 AI 最擅长模拟多需求驱动的行为，例如模拟人生（Sims）风格的需求系统。每个需求随时间衰减，AI 选择最能满足当前最紧迫需求的行为。


interface Need {
  name: string;
  value: number;
  decayRate: number;
  weight: number;
}

interface NeedSatisfaction {
  needName: string;
  amount: number;
  duration: number;
}

interface UtilityBehavior {
  name: string;
  satisfactions: NeedSatisfaction[];
  prerequisites: (needs: Map<string, Need>) => boolean;
}

class NeedBasedAI {
  private needs: Map<string, Need>;
  private behaviors: UtilityBehavior[];
  private currentBehavior: UtilityBehavior | null = null;
  private behaviorTimer = 0;

  constructor(needs: Need[], behaviors: UtilityBehavior[]) {
    this.needs = new Map(needs.map((n) => [n.name, { ...n }]));
    this.behaviors = behaviors;
  }

  update(dt: number): void {
    for (const need of this.needs.values()) {
      need.value = Math.max(0, need.value - need.decayRate * dt);
    }

    if (this.behaviorTimer > 0) {
      this.behaviorTimer -= dt;
      return;
    }

    const bestBehavior = this.selectBehavior();
    if (bestBehavior) {
      this.executeBehavior(bestBehavior);
    }
  }

  private selectBehavior(): UtilityBehavior | null {
    let bestScore = -Infinity;
    let best: UtilityBehavior | null = null;

    for (const behavior of this.behaviors) {
      if (!behavior.prerequisites(this.needs)) continue;

      let score = 0;
      for (const sat of behavior.satisfactions) {
        const need = this.needs.get(sat.needName);
        if (!need) continue;
        const urgency = 1 - need.value;
        const satisfaction = Math.min(sat.amount, 1 - need.value);
        score += urgency * satisfaction * need.weight;
      }

      if (score > bestScore) {
        bestScore = score;
        best = behavior;
      }
    }
    return best;
  }

  private executeBehavior(behavior: UtilityBehavior): void {
    this.currentBehavior = behavior;
    let maxDuration = 0;
    for (const sat of behavior.satisfactions) {
      const need = this.needs.get(sat.needName);
      if (need) {
        need.value = Math.min(1, need.value + sat.amount);
        maxDuration = Math.max(maxDuration, sat.duration);
      }
    }
    this.behaviorTimer = maxDuration;
  }

  getNeedStatus(): { name: string; value: number; urgency: number }[] {
    return Array.from(this.needs.values()).map((n) => ({
      name: n.name,
      value: n.value,
      urgency: (1 - n.value) * n.weight,
    }));
  }
}

const villagerAI = new NeedBasedAI(
  [
    { name: 'hunger', value: 0.8, decayRate: 0.05, weight: 1.5 },
    { name: 'energy', value: 0.9, decayRate: 0.03, weight: 1.2 },
    { name: 'social', value: 0.6, decayRate: 0.02, weight: 0.8 },
    { name: 'safety', value: 1.0, decayRate: 0.01, weight: 2.0 },
  ],
  [
    {
      name: 'eat',
      satisfactions: [{ needName: 'hunger', amount: 0.6, duration: 3 }],
      prerequisites: () => true,
    },
    {
      name: 'sleep',
      satisfactions: [{ needName: 'energy', amount: 0.8, duration: 8 }],
      prerequisites: (needs) => (needs.get('energy')?.value ?? 1) < 0.4,
    },
    {
      name: 'chat',
      satisfactions: [{ needName: 'social', amount: 0.4, duration: 2 }],
      prerequisites: () => true,
    },
    {
      name: 'seek_shelter',
      satisfactions: [{ needName: 'safety', amount: 0.5, duration: 1 }],
      prerequisites: (needs) => (needs.get('safety')?.value ?? 1) < 0.5,
    },
  ],
);
安全需求的权重（2.0）最高，意味着即使饥饿值更低，当安全感跌破阈值时 AI 仍会优先寻找庇护。这种权重机制让设计师无需编写复杂的优先级代码就能调控 AI 的行为倾向。


小结
    

  • 效用 AI 通过评分函数为每个行为计算效用值，选择最优行为执行
    • 

  • 响应曲线（线性、二次、Logistic 等）决定了输入到分数的映射关系，直接影响 AI 性格
    • 

  • 考量因素的聚合方式（乘法、平均、最小值）控制"所有条件都满足"还是"任一条件满足"的决策风格
    • 

  • 加权随机和 Top-N 随机策略为相似评分的行为引入变化性
    • 

  • 多需求系统适合模拟人生类游戏，权重机制实现需求间的优先级自动调控
    • 

  • 效用 AI 可与行为树结合：用效用评分选择行为树的分支，兼顾灵活性和结构化
    •
