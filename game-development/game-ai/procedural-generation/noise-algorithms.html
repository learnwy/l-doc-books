噪声算法

核心概念

噪声算法是程序化生成的数学基石，通过伪随机函数产生视觉上连续、自然的数值分布。与纯随机数不同，噪声函数在相邻输入点上产生相近的输出值，这种空间连贯性使其能够模拟自然界中的地形起伏、云层变化和水面波纹等现象。

噪声算法的核心思想是在离散的晶格点上生成随机梯度向量，然后通过插值函数将这些离散值平滑地连接起来。不同的噪声算法在晶格结构、梯度分布和插值方式上各有差异，由此产生了不同的视觉效果和计算性能。

Perlin 噪声原理
Perlin 噪声由 Ken Perlin 于 1983 年提出，是最具影响力的梯度噪声算法。其核心流程分为四步：确定晶格坐标、计算梯度向量、求点积距离、执行平滑插值。


对于二维 Perlin 噪声，给定输入坐标 (x, y)，算法首先找到包含该点的四个整数晶格顶点。每个顶点通过哈希函数映射到一个伪随机梯度向量。然后计算输入点到每个顶点的距离向量，与对应梯度向量求点积，最后通过缓和曲线 6t^5 - 15t^4 + 10t^3 进行双线性插值。


function fade(t: number): number {
  return t * t * t * (t * (t * 6 - 15) + 10);
}

function lerp(a: number, b: number, t: number): number {
  return a + t * (b - a);
}

function grad(hash: number, x: number, y: number): number {
  const h = hash & 3;
  const u = h < 2 ? x : -x;
  const v = h === 0 || h === 3 ? y : -y;
  return u + v;
}

function perlin2D(x: number, y: number, perm: Uint8Array): number {
  const xi = Math.floor(x) & 255;
  const yi = Math.floor(y) & 255;
  const xf = x - Math.floor(x);
  const yf = y - Math.floor(y);

  const u = fade(xf);
  const v = fade(yf);

  const aa = perm[perm[xi] + yi];
  const ab = perm[perm[xi] + yi + 1];
  const ba = perm[perm[xi + 1] + yi];
  const bb = perm[perm[xi + 1] + yi + 1];

  const x1 = lerp(grad(aa, xf, yf), grad(ba, xf - 1, yf), u);
  const x2 = lerp(grad(ab, xf, yf - 1), grad(bb, xf - 1, yf - 1), u);

  return lerp(x1, x2, v);
}
Perlin 噪声的改进版本采用了更好的缓和曲线，消除了原版中二阶导数不连续的视觉伪影。实际游戏开发中，通常使用改进版 Perlin 噪声作为基础噪声源。


Simplex 噪声与现代替代
Simplex 噪声是 Ken Perlin 在 2001 年提出的改进算法，用单纯形网格替代了超立方体网格。在 N 维空间中，单纯形只有 N+1 个顶点（而超立方体有 2^N 个），这使得高维计算效率大幅提升。


二维 Simplex 噪声使用等边三角形网格。对于输入坐标，算法首先通过倾斜变换将其映射到三角形网格空间，确定所在三角形的三个顶点，然后在这三个顶点上计算贡献并求和。


const F2 = 0.5 * (Math.sqrt(3) - 1);
const G2 = (3 - Math.sqrt(3)) / 6;

function simplex2D(x: number, y: number, perm: Uint8Array): number {
  const s = (x + y) * F2;
  const i = Math.floor(x + s);
  const j = Math.floor(y + s);

  const t = (i + j) * G2;
  const x0 = x - (i - t);
  const y0 = y - (j - t);

  const i1 = x0 > y0 ? 1 : 0;
  const j1 = x0 > y0 ? 0 : 1;

  const x1 = x0 - i1 + G2;
  const y1 = y0 - j1 + G2;
  const x2 = x0 - 1 + 2 * G2;
  const y2 = y0 - 1 + 2 * G2;

  const ii = i & 255;
  const jj = j & 255;

  let n0 = 0,
    n1 = 0,
    n2 = 0;
  let t0 = 0.5 - x0 * x0 - y0 * y0;
  if (t0 > 0) {
    t0 *= t0;
    n0 = t0 * t0 * grad(perm[ii + perm[jj]], x0, y0);
  }

  let t1 = 0.5 - x1 * x1 - y1 * y1;
  if (t1 > 0) {
    t1 *= t1;
    n1 = t1 * t1 * grad(perm[ii + i1 + perm[jj + j1]], x1, y1);
  }

  let t2 = 0.5 - x2 * x2 - y2 * y2;
  if (t2 > 0) {
    t2 *= t2;
    n2 = t2 * t2 * grad(perm[ii + 1 + perm[jj + 1]], x2, y2);
  }

  return 70 * (n0 + n1 + n2);
}

近年来 OpenSimplex2 成为游戏开发中的主流选择，它在 Simplex 的基础上消除了专利限制，同时进一步减少了视觉伪影。


分形布朗运动
单层噪声只能产生单一频率的变化，无法表现自然界中多尺度叠加的复杂纹理。分形布朗运动（fractal Brownian Motion，fBM）通过将多个不同频率和振幅的噪声层叠加，模拟自然界中的自相似分形结构。


fBM 的核心参数包括：八度数（octaves）控制叠加层数，持续度（persistence）控制每层振幅衰减比，空隙度（lacunarity）控制每层频率增长比。典型配置为 6-8 个八度，持续度 0.5，空隙度 2.0。


function fbm(x: number, y: number, octaves: number, persistence: number, lacunarity: number, perm: Uint8Array): number {
  let total = 0;
  let frequency = 1;
  let amplitude = 1;
  let maxValue = 0;

  for (let i = 0; i < octaves; i++) {
    total += perlin2D(x * frequency, y * frequency, perm) * amplitude;
    maxValue += amplitude;
    amplitude *= persistence;
    frequency *= lacunarity;
  }

  return total / maxValue;
}
通过调整 fBM 参数可以生成截然不同的地形风格：低八度数产生平缓的丘陵，高八度数产生崎岖的山脉；高持续度增加细节丰富度，低持续度产生更平滑的表面。


在此基础上还有多种变体：湍流噪声对每层取绝对值产生尖锐的山脊效果，域变形（Domain Warping）将一次 fBM 的输出作为另一次 fBM 的输入偏移，产生旋涡般的有机纹理。


沃罗诺伊图与细胞噪声
沃罗诺伊图（Voronoi Diagram）是另一类重要的程序化生成工具。给定一组种子点，沃罗诺伊图将空间划分为若干区域，每个区域包含距离某个种子点最近的所有点。这种划分天然适合模拟细胞结构、碎石纹理和地图分区。


细胞噪声（Worley Noise）基于沃罗诺伊图，通过计算每个点到最近种子点的距离来生成噪声值。不同的距离度量和组合方式可以产生丰富的纹理效果。


interface VoronoiResult {
  f1: number;
  f2: number;
  cellId: number;
}

function worleyNoise(x: number, y: number, seed: number): VoronoiResult {
  const ix = Math.floor(x);
  const iy = Math.floor(y);

  let minDist1 = Infinity;
  let minDist2 = Infinity;
  let closestCell = 0;

  for (let dx = -1; dx <= 1; dx++) {
    for (let dy = -1; dy <= 1; dy++) {
      const cx = ix + dx;
      const cy = iy + dy;

      const hash = pseudoRandom(cx, cy, seed);
      const px = cx + hash;
      const py = cy + pseudoRandom(cx + 1000, cy + 1000, seed);

      const dist = Math.sqrt((x - px) ** 2 + (y - py) ** 2);

      if (dist < minDist1) {
        minDist2 = minDist1;
        minDist1 = dist;
        closestCell = hash * 1000;
      } else if (dist < minDist2) {
        minDist2 = dist;
      }
    }
  }

  return { f1: minDist1, f2: minDist2, cellId: Math.floor(closestCell) };
}

function pseudoRandom(x: number, y: number, seed: number): number {
  const n = Math.sin(x * 127.1 + y * 311.7 + seed * 573.9) * 43758.5453;
  return n - Math.floor(n);
}
通过组合 F1（最近距离）和 F2（次近距离），可以产生多种纹理效果：F1 生成光滑的细胞图案，F2 - F1 生成细胞边界线条，F1 + F2 混合则产生有机的泡沫纹理。在游戏中，沃罗诺伊图常用于生成城市街区布局、生物群落划分和破碎效果。


噪声在游戏地形中的实战应用
将各类噪声算法组合应用是游戏地形生成的关键。一个典型的地形生成管线会分为多个阶段：大陆形状、海拔分布、湿度计算、生物群落分配和细节叠加。


interface TerrainConfig {
  continentScale: number;
  elevationOctaves: number;
  moistureScale: number;
  detailStrength: number;
}

interface TerrainSample {
  elevation: number;
  moisture: number;
  temperature: number;
  biome: string;
}

function sampleTerrain(x: number, y: number, config: TerrainConfig, perm: Uint8Array): TerrainSample {
  const continent = fbm(x / config.continentScale, y / config.continentScale, 4, 0.5, 2.0, perm);

  const warpX = fbm(x * 0.01, y * 0.01, 3, 0.5, 2.0, perm) * 50;
  const warpY = fbm(x * 0.01 + 5.2, y * 0.01 + 1.3, 3, 0.5, 2.0, perm) * 50;

  const elevation = fbm((x + warpX) * 0.005, (y + warpY) * 0.005, config.elevationOctaves, 0.45, 2.1, perm);

  const moisture = fbm(x / config.moistureScale, y / config.moistureScale + 1000, 4, 0.5, 2.0, perm);

  const temperature = 1 - elevation * 0.7 + fbm(x * 0.002, y * 0.002 + 2000, 3, 0.5, 2.0, perm) * 0.3;

  const detail = fbm(x * 0.1, y * 0.1, 3, 0.3, 2.5, perm) * config.detailStrength;
  const finalElevation = Math.max(0, Math.min(1, continent * 0.3 + elevation * 0.6 + detail * 0.1));

  const biome = getBiome(finalElevation, moisture, temperature);

  return { elevation: finalElevation, moisture, temperature, biome };
}

function getBiome(elevation: number, moisture: number, temperature: number): string {
  if (elevation < 0.3) return 'ocean';
  if (elevation < 0.35) return 'beach';
  if (elevation > 0.8) return temperature < 0.3 ? 'snow-peak' : 'mountain';
  if (moisture > 0.7) return temperature > 0.6 ? 'rainforest' : 'swamp';
  if (moisture < 0.2) return temperature > 0.7 ? 'desert' : 'tundra';
  return temperature > 0.5 ? 'grassland' : 'forest';
}
实际项目中还需要考虑性能优化。常见策略包括：预计算噪声值存入纹理贴图、使用分块加载按需生成地形、在 GPU 上通过计算着色器并行计算噪声、以及对远处地形使用低八度数的简化版本实现 LOD（Level of Detail）。


小结
    

  • Perlin 噪声通过梯度插值产生空间连贯的伪随机值，是最经典的噪声算法
    • 

  • Simplex 噪声用单纯形替代超立方体，在高维场景下计算效率显著提升
    • 

  • 分形布朗运动通过多层噪声叠加模拟自然界的自相似分形结构
    • 

  • 沃罗诺伊图基于距离划分空间，适合生成细胞、区块和破碎效果
    • 

  • 实际地形生成需要组合多种噪声算法构建完整的生成管线
    • 

  • 性能优化策略包括 GPU 计算、分块加载和 LOD 简化
