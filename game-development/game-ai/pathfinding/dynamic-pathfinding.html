动态寻路

核心概念

动态寻路解决的是游戏运行时环境持续变化的路径规划问题。静态寻路假设地图在搜索期间不变，但真实游戏中障碍物会移动、门会开关、桥会坍塌，AI 角色需要在毫秒级时间内重新规划路径。动态寻路的核心挑战是在保证路径质量的同时最小化重新计算的开销。

动态寻路的关键思想是"增量式更新"——不从头重新搜索，而是基于之前的搜索结果，仅修正受环境变化影响的部分。


D* Lite 增量搜索
D* Lite 是动态环境中最重要的增量式搜索算法。它从目标节点向起点反向搜索，当边权值变化时，仅更新受影响的节点，避免全局重计算。算法维护两个关键值：g 值（从目标到该节点的已知最短距离）和 rhs 值（基于邻居的一步前瞻估计）。


interface DStarNode {
  id: number;
  g: number;
  rhs: number;
  key: [number, number];
}

class DStarLite {
  private nodes: Map<number, DStarNode> = new Map();
  private openList: Map<number, [number, number]> = new Map();
  private km = 0;
  private start: number;
  private goal: number;
  private graph: Map<number, { id: number; cost: number }[]>;

  constructor(graph: Map<number, { id: number; cost: number }[]>, start: number, goal: number) {
    this.graph = graph;
    this.start = start;
    this.goal = goal;
    this.initialize();
  }

  private initialize(): void {
    for (const [id] of this.graph) {
      this.nodes.set(id, { id, g: Infinity, rhs: Infinity, key: [Infinity, Infinity] });
    }
    const goalNode = this.nodes.get(this.goal)!;
    goalNode.rhs = 0;
    goalNode.key = this.calculateKey(this.goal);
    this.openList.set(this.goal, goalNode.key);
  }

  private calculateKey(nodeId: number): [number, number] {
    const node = this.nodes.get(nodeId)!;
    const minGRhs = Math.min(node.g, node.rhs);
    return [minGRhs + this.heuristic(this.start, nodeId) + this.km, minGRhs];
  }

  private heuristic(a: number, b: number): number {
    return Math.abs(a - b);
  }

  computeShortestPath(): void {
    while (this.openList.size > 0) {
      const [uId] = this.getTopKey();
      const u = this.nodes.get(uId)!;
      const startNode = this.nodes.get(this.start)!;
      const startKey = this.calculateKey(this.start);

      if (this.compareKeys(u.key, startKey) >= 0 && startNode.rhs === startNode.g) break;

      const kOld = u.key;
      const kNew = this.calculateKey(uId);

      if (this.compareKeys(kOld, kNew) < 0) {
        this.openList.set(uId, kNew);
        u.key = kNew;
      } else if (u.g > u.rhs) {
        u.g = u.rhs;
        this.openList.delete(uId);
        for (const pred of this.getPredecessors(uId)) {
          this.updateVertex(pred);
        }
      } else {
        u.g = Infinity;
        for (const pred of [...this.getPredecessors(uId), uId]) {
          this.updateVertex(pred);
        }
      }
    }
  }

  private updateVertex(nodeId: number): void {
    const node = this.nodes.get(nodeId)!;
    if (nodeId !== this.goal) {
      let minRhs = Infinity;
      for (const succ of this.graph.get(nodeId) ?? []) {
        const succNode = this.nodes.get(succ.id)!;
        minRhs = Math.min(minRhs, succ.cost + succNode.g);
      }
      node.rhs = minRhs;
    }
    this.openList.delete(nodeId);
    if (node.g !== node.rhs) {
      node.key = this.calculateKey(nodeId);
      this.openList.set(nodeId, node.key);
    }
  }

  onEdgeChanged(from: number, to: number, newCost: number): void {
    this.km += this.heuristic(this.start, from);
    const neighbors = this.graph.get(from);
    if (neighbors) {
      const edge = neighbors.find((n) => n.id === to);
      if (edge) edge.cost = newCost;
    }
    this.updateVertex(from);
    this.computeShortestPath();
  }

  getPath(): number[] {
    const path: number[] = [this.start];
    let current = this.start;
    while (current !== this.goal) {
      let bestNext = -1;
      let bestCost = Infinity;
      for (const succ of this.graph.get(current) ?? []) {
        const succNode = this.nodes.get(succ.id)!;
        const totalCost = succ.cost + succNode.g;
        if (totalCost < bestCost) {
          bestCost = totalCost;
          bestNext = succ.id;
        }
      }
      if (bestNext === -1) return [];
      path.push(bestNext);
      current = bestNext;
    }
    return path;
  }

  private getTopKey(): [number, [number, number]] {
    let topId = -1;
    let topKey: [number, number] = [Infinity, Infinity];
    for (const [id, key] of this.openList) {
      if (this.compareKeys(key, topKey) < 0) {
        topId = id;
        topKey = key;
      }
    }
    return [topId, topKey];
  }

  private compareKeys(a: [number, number], b: [number, number]): number {
    if (a[0] !== b[0]) return a[0] - b[0];
    return a[1] - b[1];
  }

  private getPredecessors(nodeId: number): number[] {
    const preds: number[] = [];
    for (const [id, neighbors] of this.graph) {
      if (neighbors.some((n) => n.id === nodeId)) preds.push(id);
    }
    return preds;
  }
}
D* Lite 的核心在于 g 值和 rhs 值的一致性检测。当 g !== rhs 时节点为"不一致"状态，需要被重新扩展。km 变量补偿了起点移动造成的启发式偏移，使得机器人在前进过程中无需重新初始化。


流场寻路
当大量单位需要向同一目标移动时（如 RTS 中的军队调动），为每个单位单独执行 A* 搜索代价极高。流场寻路（Flow Field Pathfinding）预先为整个地图计算一个方向场，每个格子存储指向目标的最优方向，单位只需查询所在格子的方向即可移动。


interface Vector2 {
  x: number;
  y: number;
}

class FlowField {
  private width: number;
  private height: number;
  private costField: number[];
  private integrationField: number[];
  private flowField: Vector2[];

  constructor(width: number, height: number) {
    this.width = width;
    this.height = height;
    this.costField = new Array(width * height).fill(1);
    this.integrationField = new Array(width * height).fill(Infinity);
    this.flowField = new Array(width * height).fill({ x: 0, y: 0 });
  }

  setObstacle(x: number, y: number): void {
    this.costField[y * this.width + x] = 255;
  }

  setTerrainCost(x: number, y: number, cost: number): void {
    this.costField[y * this.width + x] = cost;
  }

  generate(goalX: number, goalY: number): void {
    this.computeIntegrationField(goalX, goalY);
    this.computeFlowField();
  }

  private computeIntegrationField(goalX: number, goalY: number): void {
    this.integrationField.fill(Infinity);
    const goalIdx = goalY * this.width + goalX;
    this.integrationField[goalIdx] = 0;

    const queue: number[] = [goalIdx];
    while (queue.length > 0) {
      const current = queue.shift()!;
      const cx = current % this.width;
      const cy = Math.floor(current / this.width);

      const dirs = [
        { dx: 0, dy: -1 },
        { dx: 1, dy: 0 },
        { dx: 0, dy: 1 },
        { dx: -1, dy: 0 },
      ];

      for (const { dx, dy } of dirs) {
        const nx = cx + dx;
        const ny = cy + dy;
        if (nx < 0 || nx >= this.width || ny < 0 || ny >= this.height) continue;
        const nIdx = ny * this.width + nx;
        if (this.costField[nIdx] === 255) continue;

        const newCost = this.integrationField[current] + this.costField[nIdx];
        if (newCost < this.integrationField[nIdx]) {
          this.integrationField[nIdx] = newCost;
          queue.push(nIdx);
        }
      }
    }
  }

  private computeFlowField(): void {
    for (let y = 0; y < this.height; y++) {
      for (let x = 0; x < this.width; x++) {
        const idx = y * this.width + x;
        if (this.costField[idx] === 255) {
          this.flowField[idx] = { x: 0, y: 0 };
          continue;
        }

        let bestDir: Vector2 = { x: 0, y: 0 };
        let bestCost = this.integrationField[idx];

        const dirs = [
          { dx: 0, dy: -1 },
          { dx: 1, dy: -1 },
          { dx: 1, dy: 0 },
          { dx: 1, dy: 1 },
          { dx: 0, dy: 1 },
          { dx: -1, dy: 1 },
          { dx: -1, dy: 0 },
          { dx: -1, dy: -1 },
        ];

        for (const { dx, dy } of dirs) {
          const nx = x + dx;
          const ny = y + dy;
          if (nx < 0 || nx >= this.width || ny < 0 || ny >= this.height) continue;
          const nIdx = ny * this.width + nx;
          if (this.integrationField[nIdx] < bestCost) {
            bestCost = this.integrationField[nIdx];
            const len = Math.sqrt(dx * dx + dy * dy);
            bestDir = { x: dx / len, y: dy / len };
          }
        }
        this.flowField[idx] = bestDir;
      }
    }
  }

  getDirection(x: number, y: number): Vector2 {
    if (x < 0 || x >= this.width || y < 0 || y >= this.height) return { x: 0, y: 0 };
    return this.flowField[y * this.width + x];
  }

  getBilinearDirection(px: number, py: number): Vector2 {
    const x0 = Math.floor(px);
    const y0 = Math.floor(py);
    const x1 = Math.min(x0 + 1, this.width - 1);
    const y1 = Math.min(y0 + 1, this.height - 1);
    const fx = px - x0;
    const fy = py - y0;

    const d00 = this.getDirection(x0, y0);
    const d10 = this.getDirection(x1, y0);
    const d01 = this.getDirection(x0, y1);
    const d11 = this.getDirection(x1, y1);

    return {
      x: d00.x * (1 - fx) * (1 - fy) + d10.x * fx * (1 - fy) + d01.x * (1 - fx) * fy + d11.x * fx * fy,
      y: d00.y * (1 - fx) * (1 - fy) + d10.y * fx * (1 - fy) + d01.y * (1 - fx) * fy + d11.y * fx * fy,
    };
  }
}
流场的优势在于查询时间为 O(1)，无论地图上有多少个单位，每个单位只需一次数组查找。对于 RTS 游戏中数百个单位向同一点移动的场景，流场寻路比逐个 A* 搜索高效数个数量级。


局部避障与 RVO
全局寻路解决"从哪里走"的问题，局部避障解决"怎么不撞到别人"的问题。相互速度障碍算法（Reciprocal Velocity Obstacles，RVO）是最常用的多智能体局部避障方法，它让每个角色只需调整自身速度的一半就能避免碰撞，因为对方也会做对等调整。


interface Agent {
  position: Vector2;
  velocity: Vector2;
  preferredVelocity: Vector2;
  radius: number;
  maxSpeed: number;
}

class ORCASimulator {
  private agents: Agent[];
  private timeHorizon: number;

  constructor(agents: Agent[], timeHorizon: number) {
    this.agents = agents;
    this.timeHorizon = timeHorizon;
  }

  computeNewVelocities(): void {
    for (const agent of this.agents) {
      const orcaLines = this.computeORCALines(agent);
      agent.velocity = this.linearProgram(orcaLines, agent.preferredVelocity, agent.maxSpeed);
    }
  }

  private computeORCALines(agent: Agent): { point: Vector2; direction: Vector2 }[] {
    const lines: { point: Vector2; direction: Vector2 }[] = [];

    for (const other of this.agents) {
      if (other === agent) continue;

      const relPos: Vector2 = {
        x: other.position.x - agent.position.x,
        y: other.position.y - agent.position.y,
      };
      const relVel: Vector2 = {
        x: agent.velocity.x - other.velocity.x,
        y: agent.velocity.y - other.velocity.y,
      };
      const combinedRadius = agent.radius + other.radius;
      const dist = Math.sqrt(relPos.x ** 2 + relPos.y ** 2);

      if (dist > combinedRadius) {
        const w: Vector2 = {
          x: relVel.x - relPos.x / this.timeHorizon,
          y: relVel.y - relPos.y / this.timeHorizon,
        };
        const wLen = Math.sqrt(w.x ** 2 + w.y ** 2);
        if (wLen === 0) continue;

        const unitW: Vector2 = { x: w.x / wLen, y: w.y / wLen };
        const direction: Vector2 = { x: unitW.y, y: -unitW.x };
        const u: Vector2 = {
          x: unitW.x * (combinedRadius / this.timeHorizon - wLen),
          y: unitW.y * (combinedRadius / this.timeHorizon - wLen),
        };

        lines.push({
          point: { x: agent.velocity.x + u.x * 0.5, y: agent.velocity.y + u.y * 0.5 },
          direction,
        });
      }
    }
    return lines;
  }

  private linearProgram(
    lines: { point: Vector2; direction: Vector2 }[],
    preferred: Vector2,
    maxSpeed: number,
  ): Vector2 {
    let result = { ...preferred };
    for (const line of lines) {
      const dotProduct = (line.point.x - result.x) * line.direction.y - (line.point.y - result.y) * line.direction.x;
      if (dotProduct > 0) {
        const t = (line.point.x - result.x) * line.direction.x + (line.point.y - result.y) * line.direction.y;
        result = {
          x: line.point.x + t * line.direction.x,
          y: line.point.y + t * line.direction.y,
        };
      }
    }
    const speed = Math.sqrt(result.x ** 2 + result.y ** 2);
    if (speed > maxSpeed) {
      result.x = (result.x / speed) * maxSpeed;
      result.y = (result.y / speed) * maxSpeed;
    }
    return result;
  }
}

ORCA 是 RVO 的数学精确化版本，它将避障问题转化为线性规划，能保证在所有智能体都遵守协议的情况下不会发生碰撞。


小结
    

  • 动态寻路的核心是增量式更新，避免环境变化时完全重新搜索
    • 

  • D* Lite 通过反向搜索和不一致性检测实现高效的增量路径修复
    • 

  • 流场寻路为大量同目标单位提供 O(1) 查询的移动方向，适合 RTS 游戏
    • 

  • ORCA 通过线性规划实现多智能体局部避障，保证无碰撞
    • 

  • 实际游戏通常采用分层架构：全局寻路（A*/D* Lite）+ 局部避障（ORCA）
    • 

  • 对于大规模场景，还需要时间切片和异步计算来控制每帧 CPU 开销
    •
