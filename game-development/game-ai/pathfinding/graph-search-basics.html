图搜索基础

核心概念

图搜索是游戏 AI 寻路的基础，它将游戏世界抽象为由节点和边组成的图结构，然后使用搜索算法找到从起点到终点的最优路径。理解广度优先搜索（BFS）、深度优先搜索（DFS）和 Dijkstra 算法是掌握高级寻路算法的前提。

图的表示方式
游戏中的图表示决定了搜索算法的效率和适用范围。最常见的三种表示方式分别适用于不同类型的游戏地图。


interface GraphNode {
  id: number;
  position: Vector2;
  walkable: boolean;
}

interface GraphEdge {
  from: number;
  to: number;
  cost: number;
}

class GridGraph {
  private width: number;
  private height: number;
  private walkable: boolean[];

  constructor(width: number, height: number) {
    this.width = width;
    this.height = height;
    this.walkable = new Array(width * height).fill(true);
  }

  getNeighbors(nodeId: number): { id: number; cost: number }[] {
    const x = nodeId % this.width;
    const y = Math.floor(nodeId / this.width);
    const neighbors: { id: number; cost: number }[] = [];

    const dirs = [
      { dx: 0, dy: -1, cost: 1 },
      { dx: 1, dy: 0, cost: 1 },
      { dx: 0, dy: 1, cost: 1 },
      { dx: -1, dy: 0, cost: 1 },
      { dx: 1, dy: -1, cost: Math.SQRT2 },
      { dx: 1, dy: 1, cost: Math.SQRT2 },
      { dx: -1, dy: 1, cost: Math.SQRT2 },
      { dx: -1, dy: -1, cost: Math.SQRT2 },
    ];

    for (const { dx, dy, cost } of dirs) {
      const nx = x + dx;
      const ny = y + dy;
      if (nx >= 0 && nx < this.width && ny >= 0 && ny < this.height) {
        const nid = ny * this.width + nx;
        if (this.walkable[nid]) {
          neighbors.push({ id: nid, cost });
        }
      }
    }
    return neighbors;
  }

  setWalkable(x: number, y: number, value: boolean): void {
    this.walkable[y * this.width + x] = value;
  }
}

class WaypointGraph {
  private nodes: GraphNode[] = [];
  private adjacency: Map<number, GraphEdge[]> = new Map();

  addNode(node: GraphNode): void {
    this.nodes.push(node);
    this.adjacency.set(node.id, []);
  }

  addEdge(from: number, to: number, cost: number): void {
    this.adjacency.get(from)?.push({ from, to, cost });
    this.adjacency.get(to)?.push({ from: to, to: from, cost });
  }

  getNeighbors(nodeId: number): GraphEdge[] {
    return this.adjacency.get(nodeId) ?? [];
  }
}
网格图适合规则地形（如 RTS 游戏），路点图适合开放世界中的稀疏导航点，导航网格适合复杂三维地形。


BFS 与 DFS
广度优先搜索（BFS）以层级方式展开搜索，保证在无权图中找到最短路径。深度优先搜索（DFS）沿单条路径尽可能深入，在寻路中较少直接使用，但在迷宫生成和可达性检测中非常有用。


class BFS {
  search(graph: GridGraph, start: number, goal: number): number[] | null {
    const queue: number[] = [start];
    const visited = new Set<number>([start]);
    const parent = new Map<number, number>();

    while (queue.length > 0) {
      const current = queue.shift()!;
      if (current === goal) return this.reconstructPath(parent, start, goal);

      for (const neighbor of graph.getNeighbors(current)) {
        if (!visited.has(neighbor.id)) {
          visited.add(neighbor.id);
          parent.set(neighbor.id, current);
          queue.push(neighbor.id);
        }
      }
    }
    return null;
  }

  private reconstructPath(parent: Map<number, number>, start: number, goal: number): number[] {
    const path: number[] = [];
    let current = goal;
    while (current !== start) {
      path.unshift(current);
      current = parent.get(current)!;
    }
    path.unshift(start);
    return path;
  }
}

class FloodFill {
  static findReachable(graph: GridGraph, start: number, maxCost: number): Set<number> {
    const reachable = new Set<number>();
    const queue: { id: number; cost: number }[] = [{ id: start, cost: 0 }];
    const costs = new Map<number, number>([[start, 0]]);

    while (queue.length > 0) {
      const { id, cost } = queue.shift()!;
      reachable.add(id);

      for (const neighbor of graph.getNeighbors(id)) {
        const newCost = cost + neighbor.cost;
        if (newCost <= maxCost && (!costs.has(neighbor.id) || newCost < costs.get(neighbor.id)!)) {
          costs.set(neighbor.id, newCost);
          queue.push({ id: neighbor.id, cost: newCost });
        }
      }
    }
    return reachable;
  }
}
BFS 的队列使用 FIFO 顺序保证层级展开，而 Dijkstra 算法将其替换为优先队列，使算法能处理加权图。


Dijkstra 算法
Dijkstra 算法是加权图中最经典的最短路径算法，它维护一个优先队列，每次取出当前距离最小的节点进行松弛操作，直到到达目标或队列为空。


class MinHeap<T> {
  private data: { value: T; priority: number }[] = [];

  push(value: T, priority: number): void {
    this.data.push({ value, priority });
    this.bubbleUp(this.data.length - 1);
  }

  pop(): T | undefined {
    if (this.data.length === 0) return undefined;
    const top = this.data[0].value;
    const last = this.data.pop()!;
    if (this.data.length > 0) {
      this.data[0] = last;
      this.bubbleDown(0);
    }
    return top;
  }

  get size(): number {
    return this.data.length;
  }

  private bubbleUp(idx: number): void {
    while (idx > 0) {
      const parent = Math.floor((idx - 1) / 2);
      if (this.data[parent].priority <= this.data[idx].priority) break;
      [this.data[parent], this.data[idx]] = [this.data[idx], this.data[parent]];
      idx = parent;
    }
  }

  private bubbleDown(idx: number): void {
    const n = this.data.length;
    while (true) {
      let smallest = idx;
      const left = 2 * idx + 1;
      const right = 2 * idx + 2;
      if (left < n && this.data[left].priority < this.data[smallest].priority) smallest = left;
      if (right < n && this.data[right].priority < this.data[smallest].priority) smallest = right;
      if (smallest === idx) break;
      [this.data[smallest], this.data[idx]] = [this.data[idx], this.data[smallest]];
      idx = smallest;
    }
  }
}

class Dijkstra {
  search(graph: GridGraph, start: number, goal: number): { path: number[]; cost: number } | null {
    const openSet = new MinHeap<number>();
    const gScore = new Map<number, number>([[start, 0]]);
    const parent = new Map<number, number>();
    openSet.push(start, 0);

    while (openSet.size > 0) {
      const current = openSet.pop()!;
      if (current === goal) {
        return {
          path: this.reconstructPath(parent, start, goal),
          cost: gScore.get(goal)!,
        };
      }

      for (const neighbor of graph.getNeighbors(current)) {
        const tentativeG = gScore.get(current)! + neighbor.cost;
        if (!gScore.has(neighbor.id) || tentativeG < gScore.get(neighbor.id)!) {
          gScore.set(neighbor.id, tentativeG);
          parent.set(neighbor.id, current);
          openSet.push(neighbor.id, tentativeG);
        }
      }
    }
    return null;
  }

  private reconstructPath(parent: Map<number, number>, start: number, goal: number): number[] {
    const path: number[] = [];
    let current = goal;
    while (current !== start) {
      path.unshift(current);
      current = parent.get(current)!;
    }
    path.unshift(start);
    return path;
  }
}
Dijkstra 算法保证在非负权图上找到最短路径，但它向所有方向均匀展开搜索，效率不如使用启发式的 A* 算法。A* 通过添加启发式估计函数 h(n) 引导搜索朝目标方向进行，是 Dijkstra 的有向扩展。


小结
    

  • 游戏世界通过网格图、路点图或导航网格抽象为图结构
    • 

  • BFS 在等权图中找到最短路径，使用 FIFO 队列层级展开
    • 

  • Dijkstra 使用优先队列处理加权图，保证非负权边的最短路径
    • 

  • 洪泛填充可用于计算可移动范围，广泛应用于策略游戏
    • 

  • A* 是 Dijkstra 的启发式扩展，是游戏寻路中最常用的算法
