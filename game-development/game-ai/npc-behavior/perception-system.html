感知系统

核心概念

感知系统（Perception System）是游戏 AI 获取世界信息的"感官"，它决定了 AI 角色能"看到"、"听到"和"感觉到"什么。一个设计良好的感知系统不是简单的距离检测，而是模拟真实生物的感知局限——有视野范围、有盲区、有记忆衰减、有注意力分配。感知系统的输出直接驱动决策系统的输入，是 AI 可信度的关键因素。

真实感的感知系统是"有限的"——玩家可以利用 AI 的视野盲区潜行，利用噪音掩盖脚步声，这种可预测的局限性是好的游戏设计。


视觉感知实现
视觉是最重要的感知通道。标准实现包括三个阶段：距离检测、视野锥检测和遮挡检测。三重检测从粗到细逐步过滤，既保证准确性又控制计算开销。


interface Vector2 {
  x: number;
  y: number;
}

interface PerceptionTarget {
  id: string;
  position: Vector2;
  velocity: Vector2;
  faction: string;
  isVisible: boolean;
}

interface VisionConfig {
  maxDistance: number;
  fovAngle: number;
  peripheralAngle: number;
  peripheralDistanceFactor: number;
}

class VisionSensor {
  private config: VisionConfig;
  private position: Vector2 = { x: 0, y: 0 };
  private forward: Vector2 = { x: 1, y: 0 };

  constructor(config: VisionConfig) {
    this.config = config;
  }

  update(position: Vector2, forward: Vector2): void {
    this.position = position;
    this.forward = forward;
  }

  detect(targets: PerceptionTarget[], occlusionTest: (from: Vector2, to: Vector2) => boolean): PerceptionTarget[] {
    const detected: PerceptionTarget[] = [];

    for (const target of targets) {
      const offset = { x: target.position.x - this.position.x, y: target.position.y - this.position.y };
      const distance = Math.sqrt(offset.x * offset.x + offset.y * offset.y);
      if (distance > this.config.maxDistance) continue;

      const dotProduct = this.forward.x * offset.x + this.forward.y * offset.y;
      const angle = Math.acos(Math.max(-1, Math.min(1, dotProduct / distance)));
      const halfFov = (this.config.fovAngle / 2) * (Math.PI / 180);
      const halfPeripheral = (this.config.peripheralAngle / 2) * (Math.PI / 180);

      let inVision = false;
      if (angle <= halfFov) {
        inVision = true;
      } else if (angle <= halfPeripheral) {
        const peripheralMaxDist = this.config.maxDistance * this.config.peripheralDistanceFactor;
        inVision = distance <= peripheralMaxDist;
      }

      if (!inVision) continue;
      if (!occlusionTest(this.position, target.position)) continue;

      detected.push(target);
    }
    return detected;
  }

  getAwareness(targetDistance: number, angleFromForward: number): number {
    const distanceFactor = 1 - targetDistance / this.config.maxDistance;
    const angleFactor = 1 - angleFromForward / (((this.config.peripheralAngle / 2) * Math.PI) / 180);
    return Math.max(0, distanceFactor * 0.6 + angleFactor * 0.4);
  }
}

const guardVision: VisionConfig = {
  maxDistance: 200,
  fovAngle: 90,
  peripheralAngle: 160,
  peripheralDistanceFactor: 0.3,
};

const sniperVision: VisionConfig = {
  maxDistance: 500,
  fovAngle: 30,
  peripheralAngle: 60,
  peripheralDistanceFactor: 0.2,
};
视觉配置直接影响 AI 的"性格"：守卫有宽视野但短距离（警戒型），狙击手有窄视野但长距离（专注型）。getAwareness 方法计算对目标的感知强度——正前方近处目标感知最强，边缘远处最弱。


听觉感知与声音传播
听觉感知模拟声音在游戏世界中的传播。声音有音量和衰减属性，穿过墙壁会减弱，多个声源可以叠加。听觉系统不提供精确位置，只给出方向和大致距离，迫使 AI 做出"调查"行为。


interface SoundEvent {
  id: string;
  position: Vector2;
  volume: number;
  type: 'footstep' | 'gunshot' | 'explosion' | 'voice' | 'environmental';
  sourceId: string;
  timestamp: number;
}

interface HearingConfig {
  maxHearingDistance: number;
  volumeThreshold: number;
  attenuationFactor: number;
  wallDampening: number;
  directionAccuracy: number;
}

class HearingSensor {
  private config: HearingConfig;
  private position: Vector2 = { x: 0, y: 0 };

  constructor(config: HearingConfig) {
    this.config = config;
  }

  update(position: Vector2): void {
    this.position = position;
  }

  processSound(
    sound: SoundEvent,
    wallCount: number,
  ): { heard: boolean; perceivedVolume: number; estimatedDirection: Vector2; accuracy: number } | null {
    const offset = { x: sound.position.x - this.position.x, y: sound.position.y - this.position.y };
    const distance = Math.sqrt(offset.x * offset.x + offset.y * offset.y);

    if (distance > this.config.maxHearingDistance) return null;

    const distanceAttenuation = 1 / (1 + this.config.attenuationFactor * distance * distance);
    const wallAttenuation = Math.pow(this.config.wallDampening, wallCount);
    const perceivedVolume = sound.volume * distanceAttenuation * wallAttenuation;

    if (perceivedVolume < this.config.volumeThreshold) return null;

    const dirLen = Math.sqrt(offset.x * offset.x + offset.y * offset.y);
    const baseDirection = dirLen > 0 ? { x: offset.x / dirLen, y: offset.y / dirLen } : { x: 0, y: 0 };

    const accuracy = Math.min(1, perceivedVolume * this.config.directionAccuracy);
    const noise = (1 - accuracy) * (Math.random() - 0.5);
    const estimatedDirection = {
      x: baseDirection.x + noise,
      y: baseDirection.y + noise,
    };
    const estLen = Math.sqrt(estimatedDirection.x ** 2 + estimatedDirection.y ** 2);

    return {
      heard: true,
      perceivedVolume,
      estimatedDirection:
        estLen > 0 ? { x: estimatedDirection.x / estLen, y: estimatedDirection.y / estLen } : baseDirection,
      accuracy,
    };
  }
}

const soundVolumes: Record<string, number> = {
  footstep_walk: 0.3,
  footstep_run: 0.6,
  footstep_crouch: 0.1,
  gunshot_pistol: 1.0,
  gunshot_rifle: 1.2,
  gunshot_silenced: 0.4,
  explosion: 2.0,
  door_open: 0.5,
  glass_break: 0.8,

听觉系统的精度故意设计为不完美——方向估算有噪声，且噪声随音量降低而增大。这迫使 AI 在听到声响后进入"调查"状态而非直接精确定位，创造了更有趣的潜行玩法。


感知记忆与注意力
感知记忆（Perception Memory）存储 AI 曾经感知到的信息，即使目标离开视野后仍保留一段时间的记忆。注意力系统控制 AI 同时能关注的目标数量和对每个目标的关注程度。


interface PerceptionRecord {
  targetId: string;
  lastKnownPosition: Vector2;
  lastKnownVelocity: Vector2;
  lastSeenTime: number;
  lastHeardTime: number;
  awareness: number;
  confidence: number;
  faction: string;
  threat: number;
}

class PerceptionMemory {
  private records: Map<string, PerceptionRecord> = new Map();
  private maxRecords: number;
  private memoryDuration: number;
  private decayRate: number;

  constructor(maxRecords: number, memoryDuration: number, decayRate: number) {
    this.maxRecords = maxRecords;
    this.memoryDuration = memoryDuration;
    this.decayRate = decayRate;
  }

  updateVisual(target: PerceptionTarget, awareness: number, currentTime: number): void {
    const existing = this.records.get(target.id);
    if (existing) {
      existing.lastKnownPosition = { ...target.position };
      existing.lastKnownVelocity = { ...target.velocity };
      existing.lastSeenTime = currentTime;
      existing.awareness = Math.min(1, existing.awareness + awareness * 0.5);
      existing.confidence = 1;
    } else {
      this.records.set(target.id, {
        targetId: target.id,
        lastKnownPosition: { ...target.position },
        lastKnownVelocity: { ...target.velocity },
        lastSeenTime: currentTime,
        lastHeardTime: 0,
        awareness: awareness,
        confidence: awareness,
        faction: target.faction,
        threat: 0,
      });
    }
    this.evictOldest();
  }

  updateAudio(sourceId: string, estimatedPos: Vector2, accuracy: number, currentTime: number): void {
    const existing = this.records.get(sourceId);
    if (existing) {
      if (accuracy > 0.5) {
        existing.lastKnownPosition = estimatedPos;
      }
      existing.lastHeardTime = currentTime;
      existing.awareness = Math.min(1, existing.awareness + accuracy * 0.3);
    } else {
      this.records.set(sourceId, {
        targetId: sourceId,
        lastKnownPosition: estimatedPos,
        lastKnownVelocity: { x: 0, y: 0 },
        lastSeenTime: 0,
        lastHeardTime: currentTime,
        awareness: accuracy * 0.5,
        confidence: accuracy * 0.3,
        faction: 'unknown',
        threat: 0.5,
      });
    }
  }

  decay(currentTime: number): void {
    const toRemove: string[] = [];
    for (const [id, record] of this.records) {
      const timeSinceSeen = currentTime - record.lastSeenTime;
      const timeSinceHeard = currentTime - record.lastHeardTime;
      const minTimeSince = Math.min(
        record.lastSeenTime > 0 ? timeSinceSeen : Infinity,
        record.lastHeardTime > 0 ? timeSinceHeard : Infinity,
      );

      if (minTimeSince > this.memoryDuration) {
        toRemove.push(id);
        continue;
      }

      record.confidence = Math.max(0, record.confidence - this.decayRate);
      record.awareness = Math.max(0, record.awareness - this.decayRate * 0.5);
    }
    for (const id of toRemove) {
      this.records.delete(id);
    }
  }

  getThreats(minAwareness: number): PerceptionRecord[] {
    return Array.from(this.records.values())
      .filter((r) => r.awareness >= minAwareness && r.faction === 'enemy')
      .sort((a, b) => b.threat - a.threat);
  }

  getPrimaryTarget(): PerceptionRecord | null {
    const threats = this.getThreats(0.3);
    return threats[0] ?? null;
  }

  private evictOldest(): void {
    if (this.records.size <= this.maxRecords) return;
    let oldestId = '';
    let oldestTime = Infinity;
    for (const [id, record] of this.records) {
      const t = Math.max(record.lastSeenTime, record.lastHeardTime);
      if (t < oldestTime) {
        oldestTime = t;
        oldestId = id;
      }
    }
    if (oldestId) this.records.delete(oldestId);
  }
}

awareness 值的渐进增长机制让 AI 不会"瞬间发现"玩家——短暂暴露只会引起怀疑，持续暴露才会被确认，这创造了潜行游戏的核心张力。


小结
    

  • 感知系统模拟视觉（扇形+射线）、听觉（距离衰减+墙壁阻隔）和触觉等多通道输入
    • 

  • 视觉配置（视距、FOV、周边视觉）直接定义 AI 的"性格"和游戏玩法空间
    • 

  • 听觉系统故意引入方向噪声，创造"调查"行为而非全知定位
    • 

  • 感知记忆的 awareness 渐进机制是潜行游戏核心——短暂暴露只引起怀疑，持续暴露才被确认
    • 

  • 注意力预算限制同时追踪的目标数量，防止 AI "超人"感知
    • 

  • 工程上常用分帧检测和空间分区优化大量 AI 的感知计算
