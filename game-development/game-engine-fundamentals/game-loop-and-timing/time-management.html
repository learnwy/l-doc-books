时间管理系统

核心概念

时间管理系统为游戏引擎提供统一的时间查询和控制接口。它不仅追踪真实时间，还管理游戏时间缩放（慢动作、暂停）、多时钟源和帧计数等功能。一个健壮的时间管理系统是引擎可靠运行的基础。

时间缩放与慢动作
时间缩放（Time Scale）是实现慢动作、快进和暂停的核心机制。通过调整时间缩放因子，引擎可以在不修改游戏逻辑的情况下改变游戏运行速度。


class TimeManager {
  private realTime = 0;
  private gameTime = 0;
  private frameCount = 0;
  private deltaTime = 0;
  private unscaledDeltaTime = 0;
  private timeScale = 1.0;
  private paused = false;
  private clocks = new Map<string, Clock>();

  constructor() {
    this.clocks.set('default', new Clock('default', true, true));
    this.clocks.set('ui', new Clock('ui', false, false));
    this.clocks.set('physics', new Clock('physics', true, false));
  }

  update(realDt: number): void {
    this.unscaledDeltaTime = realDt;
    this.realTime += realDt;
    this.frameCount++;

    if (this.paused) {
      this.deltaTime = 0;
    } else {
      this.deltaTime = realDt * this.timeScale;
      this.gameTime += this.deltaTime;
    }

    for (const clock of this.clocks.values()) {
      clock.update(realDt, this.timeScale, this.paused);
    }
  }

  setTimeScale(scale: number): void {
    this.timeScale = Math.max(0, Math.min(scale, 10));
  }

  setPaused(paused: boolean): void {
    this.paused = paused;
  }

  getClock(name: string): Clock | undefined {
    return this.clocks.get(name);
  }

  getDeltaTime(): number {
    return this.deltaTime;
  }
  getUnscaledDeltaTime(): number {
    return this.unscaledDeltaTime;
  }
  getRealTime(): number {
    return this.realTime;
  }
  getGameTime(): number {
    return this.gameTime;
  }
  getTimeScale(): number {
    return this.timeScale;
  }
  getFrameCount(): number {
    return this.frameCount;
  }
  isPaused(): boolean {
    return this.paused;
  }
}

class Clock {
  name: string;
  private affectedByPause: boolean;
  private affectedByScale: boolean;
  private elapsed = 0;
  private deltaTime = 0;
  private localScale = 1.0;

  constructor(name: string, affectedByPause: boolean, affectedByScale: boolean) {
    this.name = name;
    this.affectedByPause = affectedByPause;
    this.affectedByScale = affectedByScale;
  }

  update(realDt: number, globalScale: number, paused: boolean): void {
    if (this.affectedByPause && paused) {
      this.deltaTime = 0;
      return;
    }
    const scale = this.affectedByScale ? globalScale * this.localScale : this.localScale;
    this.deltaTime = realDt * scale;
    this.elapsed += this.deltaTime;
  }

  setLocalScale(scale: number): void {
    this.localScale = Math.max(0, scale);
  }

  getDeltaTime(): number {
    return this.deltaTime;
  }
  getElapsed(): number {
    return this.elapsed;
  }
}
定时器与延时调度
定时器系统允许在未来某个时间点或经过特定时间间隔后执行回调。它构建在时间管理器之上，支持一次性定时器和重复定时器。


interface TimerHandle {
  id: number;
  cancel(): void;
}

class TimerScheduler {
  private nextId = 0;
  private timers: TimerEntry[] = [];

  setTimeout(callback: () => void, delay: number, useGameTime = true): TimerHandle {
    const id = this.nextId++;
    const entry: TimerEntry = {
      id,
      callback,
      remaining: delay,
      interval: 0,
      repeat: false,
      useGameTime,
      cancelled: false,
    };
    this.timers.push(entry);
    return {
      id,
      cancel: () => {
        entry.cancelled = true;
      },
    };
  }

  setInterval(callback: () => void, interval: number, useGameTime = true): TimerHandle {
    const id = this.nextId++;
    const entry: TimerEntry = {
      id,
      callback,
      remaining: interval,
      interval,
      repeat: true,
      useGameTime,
      cancelled: false,
    };
    this.timers.push(entry);
    return {
      id,
      cancel: () => {
        entry.cancelled = true;
      },
    };
  }

  update(gameDt: number, realDt: number): void {
    const expired: TimerEntry[] = [];

    this.timers = this.timers.filter((timer) => {
      if (timer.cancelled) return false;
      const dt = timer.useGameTime ? gameDt : realDt;
      timer.remaining -= dt;
      if (timer.remaining <= 0) {
        expired.push(timer);
        if (timer.repeat) {
          timer.remaining += timer.interval;
          return true;
        }
        return false;
      }
      return true;
    });

    for (const timer of expired) {
      timer.callback();
    }
  }

  cancelAll(): void {
    for (const timer of this.timers) {
      timer.cancelled = true;
    }
    this.timers = [];
  }
}

interface TimerEntry {
  id: number;
  callback: () => void;
  remaining: number;
  interval: number;
  repeat: boolean;
  useGameTime: boolean;
  cancelled: boolean;
}
帧时间平滑
帧时间平滑（Frame Time Smoothing）用于消除偶发的帧率跳跃对游戏逻辑的影响。例如，当操作系统临时占用 CPU 导致某一帧特别长时，未经平滑的 deltaTime 会导致物体瞬间移动过大距离。


class FrameTimeSmoothing {
  private history: number[] = [];
  private readonly windowSize: number;
  private readonly outlierThreshold: number;

  constructor(windowSize = 11, outlierThreshold = 2.0) {
    this.windowSize = windowSize;
    this.outlierThreshold = outlierThreshold;
  }

  smooth(rawDt: number): number {
    this.history.push(rawDt);
    if (this.history.length > this.windowSize) {
      this.history.shift();
    }
    if (this.history.length < 3) return rawDt;

    const sorted = [...this.history].sort((a, b) => a - b);
    const median = sorted[Math.floor(sorted.length / 2)];

    const filtered = this.history.filter((dt) => Math.abs(dt - median) < median * this.outlierThreshold);

    if (filtered.length === 0) return median;
    return filtered.reduce((sum, dt) => sum + dt, 0) / filtered.length;
  }

  reset(): void {
    this.history = [];
  }
}
帧时间平滑使用滑动窗口中位数和异常值剔除来生成稳定的 deltaTime。这对于动画系统和缓动（Tweening）函数尤为重要，因为它们对时间连续性非常敏感。


时间回放与调试
时间回放系统记录每帧的时间和输入数据，支持游戏状态的完整回放。这对调试和性能分析非常有价值。


interface FrameRecord {
  frameNumber: number;
  realDt: number;
  gameDt: number;
  timeScale: number;
  paused: boolean;
  inputs: Record<string, unknown>;
}

class TimeRecorder {
  private recording = false;
  private records: FrameRecord[] = [];
  private maxRecords = 36000;

  startRecording(): void {
    this.recording = true;
    this.records = [];
  }

  stopRecording(): FrameRecord[] {
    this.recording = false;
    return [...this.records];
  }

  recordFrame(record: FrameRecord): void {
    if (!this.recording) return;
    this.records.push(record);
    if (this.records.length > this.maxRecords) {
      this.records.shift();
    }
  }

  getRecordAt(frameNumber: number): FrameRecord | undefined {
    return this.records.find((r) => r.frameNumber === frameNumber);
  }

  getTotalDuration(): number {
    return this.records.reduce((sum, r) => sum + r.gameDt, 0);
  }
}
