帧率控制

核心概念

帧率控制是游戏引擎管理渲染频率和系统资源消耗的关键机制。合理的帧率控制不仅影响画面流畅度，还关系到设备功耗、散热和电池寿命。引擎需要在视觉质量和系统资源之间找到最佳平衡点。

垂直同步机制
垂直同步（VSync）将渲染帧的提交与显示器的刷新周期对齐。当渲染帧准备好后不立即显示，而是等待显示器的垂直回扫（Vertical Blank）信号。


VSync 消除了画面撕裂——当渲染中途切换帧缓冲区时，屏幕上半部分显示旧帧、下半部分显示新帧的现象。但 VSync 引入了额外的输入延迟，对竞技游戏影响显著。


class VSyncController {
  private useVSync = true;
  private targetFps = 60;
  private frameBuffer: 'double' | 'triple' = 'double';

  configure(options: { vsync: boolean; targetFps: number; tripleBuffer: boolean }): void {
    this.useVSync = options.vsync;
    this.targetFps = options.targetFps;
    this.frameBuffer = options.tripleBuffer ? 'triple' : 'double';
  }

  getSwapInterval(): number {
    if (!this.useVSync) return 0;
    return 1;
  }

  estimateInputLatency(): number {
    const frameTime = 1000 / this.targetFps;
    if (!this.useVSync) return frameTime * 0.5;
    if (this.frameBuffer === 'triple') return frameTime * 2;
    return frameTime * 1.5;
  }

  getRecommendation(gameType: 'competitive' | 'casual' | 'cinematic'): VSyncConfig {
    switch (gameType) {
      case 'competitive':
        return { vsync: false, targetFps: 144, tripleBuffer: false };
      case 'casual':
        return { vsync: true, targetFps: 60, tripleBuffer: false };
      case 'cinematic':
        return { vsync: true, targetFps: 30, tripleBuffer: true };
    }
  }
}

interface VSyncConfig {
  vsync: boolean;
  targetFps: number;
  tripleBuffer: boolean;
}
帧率限制器实现
帧率限制器通过控制每帧的最短执行时间来限制帧率上限。实现的核心挑战在于精确计时——操作系统的 sleep 函数通常有 1-15ms 的精度误差，需要结合忙等待（Busy Wait）来补偿。


class FrameRateLimiter {
  private targetFrameTime: number;
  private lastFrameEnd = 0;
  private sleepGranularity = 2;

  constructor(targetFps: number) {
    this.targetFrameTime = 1000 / targetFps;
  }

  setTargetFps(fps: number): void {
    this.targetFrameTime = 1000 / fps;
  }

  async waitForNextFrame(): Promise<number> {
    const now = performance.now();
    const elapsed = now - this.lastFrameEnd;
    const remaining = this.targetFrameTime - elapsed;

    if (remaining > this.sleepGranularity) {
      await this.sleep(remaining - this.sleepGranularity);
    }

    while (performance.now() - this.lastFrameEnd < this.targetFrameTime) {
      // Busy wait for precision
    }

    const frameEnd = performance.now();
    const actualDt = frameEnd - this.lastFrameEnd;
    this.lastFrameEnd = frameEnd;
    return actualDt / 1000;
  }

  private sleep(ms: number): Promise<void> {
    return new Promise((resolve) => setTimeout(resolve, ms));
  }

  calibrateSleepGranularity(): void {
    const samples: number[] = [];
    for (let i = 0; i < 10; i++) {
      const start = performance.now();
      setTimeout(() => {
        samples.push(performance.now() - start);
        if (samples.length === 10) {
          this.sleepGranularity = Math.max(...samples) + 1;
        }
      }, 1);
    }
  }
}
自适应帧率系统
自适应帧率系统根据当前系统负载动态调整目标帧率和画质设置，确保在不同场景复杂度下都能维持流畅体验。


interface QualityPreset {
  name: string;
  shadowResolution: number;
  drawDistance: number;
  particleCount: number;
  postProcessing: boolean;
  targetFps: number;
}

class AdaptiveFrameRate {
  private presets: QualityPreset[] = [
    {
      name: 'ultra',
      shadowResolution: 4096,
      drawDistance: 1000,
      particleCount: 10000,
      postProcessing: true,
      targetFps: 60,
    },
    {
      name: 'high',
      shadowResolution: 2048,
      drawDistance: 500,
      particleCount: 5000,
      postProcessing: true,
      targetFps: 60,
    },
    {
      name: 'medium',
      shadowResolution: 1024,
      drawDistance: 300,
      particleCount: 2000,
      postProcessing: false,
      targetFps: 30,
    },
    { name: 'low', shadowResolution: 512, drawDistance: 150, particleCount: 500, postProcessing: false, targetFps: 30 },
  ];

  private currentPresetIndex = 0;
  private frameTimes: number[] = [];
  private readonly windowSize = 60;
  private readonly dropThreshold = 0.8;
  private readonly raiseThreshold = 0.6;
  private cooldownFrames = 0;

  recordFrameTime(dt: number): void {
    this.frameTimes.push(dt);
    if (this.frameTimes.length > this.windowSize) {
      this.frameTimes.shift();
    }
    if (this.cooldownFrames > 0) {
      this.cooldownFrames--;
      return;
    }
    this.evaluate();
  }

  private evaluate(): void {
    if (this.frameTimes.length < this.windowSize) return;
    const currentPreset = this.presets[this.currentPresetIndex];
    const targetTime = 1 / currentPreset.targetFps;
    const overBudget = this.frameTimes.filter((t) => t > targetTime).length / this.windowSize;

    if (overBudget > this.dropThreshold && this.currentPresetIndex < this.presets.length - 1) {
      this.currentPresetIndex++;
      this.cooldownFrames = 120;
    } else if (overBudget < this.raiseThreshold && this.currentPresetIndex > 0) {
      this.currentPresetIndex--;
      this.cooldownFrames = 180;
    }
  }

  getCurrentPreset(): QualityPreset {
    return this.presets[this.currentPresetIndex];
  }
}
移动平台节能策略
移动平台对帧率控制有特殊需求：电池寿命和散热是核心约束。引擎需要在画面质量和功耗之间动态平衡，支持根据电量和温度自动降级。


interface DeviceState {
  batteryLevel: number;
  isCharging: boolean;
  thermalState: 'nominal' | 'fair' | 'serious' | 'critical';
  cpuUsage: number;
}

class MobilePowerManager {
  private state: DeviceState = {
    batteryLevel: 1.0,
    isCharging: false,
    thermalState: 'nominal',
    cpuUsage: 0,
  };

  updateDeviceState(state: Partial<DeviceState>): void {
    Object.assign(this.state, state);
  }

  getTargetFps(): number {
    if (this.state.thermalState === 'critical') return 20;
    if (this.state.thermalState === 'serious') return 30;
    if (!this.state.isCharging && this.state.batteryLevel < 0.15) return 30;
    if (!this.state.isCharging && this.state.batteryLevel < 0.3) return 45;
    return 60;
  }

  shouldReduceQuality(): boolean {
    return (
      this.state.thermalState === 'serious' ||
      this.state.thermalState === 'critical' ||
      (!this.state.isCharging && this.state.batteryLevel < 0.2)
    );
  }

  getResolutionScale(): number {
    if (this.state.thermalState === 'critical') return 0.5;
    if (this.state.thermalState === 'serious') return 0.75;
    if (!this.state.isCharging && this.state.batteryLevel < 0.15) return 0.75;
    return 1.0;
  }
}
小结
    

  • VSync 通过同步渲染与显示刷新消除画面撕裂，但增加输入延迟
    • 

  • 帧率限制器结合系统睡眠和忙等待实现精确的帧时间控制
    • 

  • 自适应帧率系统根据负载动态调整画质预设，保持流畅体验
    • 

  • 移动平台需要考虑电量和温度约束，通过降帧和分辨率缩放控制功耗
    • 

  • 不同游戏类型对帧率控制有不同需求，竞技游戏优先低延迟，休闲游戏优先稳定性
