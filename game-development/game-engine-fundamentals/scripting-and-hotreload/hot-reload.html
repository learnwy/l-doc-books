热重载

核心概念

热重载（Hot Reload）是在游戏运行过程中替换代码或资源而无需重启的技术。它极大地缩短了开发迭代周期——修改脚本后秒级生效，而非等待数分钟的编译重启。热重载是现代游戏引擎提升开发效率的核心功能之一。

文件变化监控
热重载的第一步是检测文件系统的变化。引擎需要高效地监控项目目录中的文件修改、创建和删除事件。


interface FileChangeEvent {
  path: string;
  type: 'modified' | 'created' | 'deleted';
  timestamp: number;
}

class FileWatcherService {
  private watchers = new Map<string, ReturnType<typeof setInterval>>();
  private fileHashes = new Map<string, string>();
  private listeners: Array<(events: FileChangeEvent[]) => void> = [];
  private debounceMs = 100;
  private pendingEvents: FileChangeEvent[] = [];
  private debounceTimer: ReturnType<typeof setTimeout> | null = null;

  watch(directory: string, extensions: string[]): void {
    const intervalId = setInterval(async () => {
      await this.scanDirectory(directory, extensions);
    }, 200);
    this.watchers.set(directory, intervalId);
  }

  onChanges(listener: (events: FileChangeEvent[]) => void): void {
    this.listeners.push(listener);
  }

  private async scanDirectory(_directory: string, _extensions: string[]): Promise<void> {
    const files = await this.getFiles(_directory, _extensions);
    for (const file of files) {
      const hash = await this.computeHash(file);
      const prevHash = this.fileHashes.get(file);
      if (prevHash === undefined) {
        this.queueEvent({ path: file, type: 'created', timestamp: Date.now() });
      } else if (prevHash !== hash) {
        this.queueEvent({ path: file, type: 'modified', timestamp: Date.now() });
      }
      this.fileHashes.set(file, hash);
    }
  }

  private queueEvent(event: FileChangeEvent): void {
    this.pendingEvents.push(event);
    if (this.debounceTimer) clearTimeout(this.debounceTimer);
    this.debounceTimer = setTimeout(() => {
      const events = [...this.pendingEvents];
      this.pendingEvents = [];
      for (const listener of this.listeners) {
        listener(events);
      }
    }, this.debounceMs);
  }

  private async getFiles(_dir: string, _ext: string[]): Promise<string[]> {
    return [];
  }
  private async computeHash(_path: string): Promise<string> {
    return '';
  }

  dispose(): void {
    for (const intervalId of this.watchers.values()) {
      clearInterval(intervalId);
    }
    this.watchers.clear();
  }
}
状态保存与恢复
热重载最大的挑战是状态保留——替换代码后，游戏对象的位置、生命值、动画状态等数据不应丢失。这需要在代码替换前序列化状态，替换后反序列化恢复。


interface SerializableState {
  entityId: number;
  scriptName: string;
  state: Record<string, unknown>;
}

class HotReloadManager {
  private watcher: FileWatcherService;
  private scriptSystem: ScriptSystemRef;
  private stateBuffer: SerializableState[] = [];

  constructor(watcher: FileWatcherService, scriptSystem: ScriptSystemRef) {
    this.watcher = watcher;
    this.scriptSystem = scriptSystem;
    this.watcher.onChanges((events) => this.handleChanges(events));
  }

  private async handleChanges(events: FileChangeEvent[]): Promise<void> {
    const scriptEvents = events.filter((e) => e.path.endsWith('.ts') || e.path.endsWith('.js'));
    if (scriptEvents.length === 0) return;

    this.saveState();

    for (const event of scriptEvents) {
      if (event.type === 'modified' || event.type === 'created') {
        await this.reloadScript(event.path);
      }
    }

    this.restoreState();
  }

  private saveState(): void {
    this.stateBuffer = [];
    const instances = this.scriptSystem.getAllInstances();
    for (const instance of instances) {
      if (instance.getSerializableState) {
        this.stateBuffer.push({
          entityId: instance.entityId,
          scriptName: instance.scriptName,
          state: instance.getSerializableState(),
        });
      }
    }
  }

  private restoreState(): void {
    for (const saved of this.stateBuffer) {
      const instance = this.scriptSystem.getInstance(saved.entityId, saved.scriptName);
      if (instance?.restoreState) {
        try {
          instance.restoreState(saved.state);
        } catch (error) {
          console.error(`Failed to restore state for ${saved.scriptName}:`, error);
        }
      }
    }
    this.stateBuffer = [];
  }

  private async reloadScript(_path: string): Promise<void> {}
}

interface ScriptSystemRef {
  getAllInstances(): Array<{ entityId: number; scriptName: string; getSerializableState?(): Record<string, unknown> }>;
  getInstance(entityId: number, scriptName: string): { restoreState?(state: Record<string, unknown>): void } | null;
}
模块替换策略
模块替换的实现取决于脚本语言和运行时环境。Web 环境下可以利用 ES Module 的动态导入和模块缓存清除来实现热替换。


class ModuleHotReplacer {
  private moduleCache = new Map<string, { module: unknown; version: number }>();
  private onReplace: (path: string, newModule: unknown) => void;

  constructor(onReplace: (path: string, newModule: unknown) => void) {
    this.onReplace = onReplace;
  }

  async replaceModule(path: string): Promise<boolean> {
    try {
      const cacheBuster = `?v=${Date.now()}`;
      const newModule = await import(path + cacheBuster);

      const entry = this.moduleCache.get(path);
      const version = (entry?.version ?? 0) + 1;
      this.moduleCache.set(path, { module: newModule, version });
      this.onReplace(path, newModule);
      return true;
    } catch (error) {
      console.error(`Hot replace failed for ${path}:`, error);
      return false;
    }
  }

  getModuleVersion(path: string): number {
    return this.moduleCache.get(path)?.version ?? 0;
  }
}

class IncrementalCompiler {
  private compiledFiles = new Map<string, { hash: string; output: string }>();

  async compile(sourcePath: string, sourceCode: string): Promise<string> {
    const hash = await this.computeHash(sourceCode);
    const cached = this.compiledFiles.get(sourcePath);
    if (cached && cached.hash === hash) {
      return cached.output;
    }

    const output = await this.transpile(sourceCode);
    this.compiledFiles.set(sourcePath, { hash, output });
    return output;
  }

  invalidate(sourcePath: string): void {
    this.compiledFiles.delete(sourcePath);
  }

  private async transpile(_source: string): Promise<string> {
    return '';
  }
  private async computeHash(_content: string): Promise<string> {
    return '';
  }
}
热重载的边界与限制
热重载并非万能——某些变更无法通过热重载安全应用，需要完整重启。理解热重载的边界有助于合理设计代码结构以最大化热重载的覆盖范围。


interface HotReloadDiagnostic {
  path: string;
  reloadable: boolean;
  reason?: string;
  changes: ChangeType[];
}

type ChangeType =
  | 'function_body'
  | 'new_function'
  | 'removed_function'
  | 'type_change'
  | 'global_state'
  | 'import_change'
  | 'class_hierarchy';

class ReloadabilityAnalyzer {
  analyze(oldSource: string, newSource: string, path: string): HotReloadDiagnostic {
    const changes = this.detectChanges(oldSource, newSource);
    const unreloadable = changes.filter((c) => c === 'type_change' || c === 'class_hierarchy' || c === 'global_state');

    return {
      path,
      reloadable: unreloadable.length === 0,
      reason: unreloadable.length > 0 ? `Non-reloadable changes: ${unreloadable.join(', ')}` : undefined,
      changes,
    };
  }

  private detectChanges(_oldSrc: string, _newSrc: string): ChangeType[] {
    return ['function_body'];
  }
}
