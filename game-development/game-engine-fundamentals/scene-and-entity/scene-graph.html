场景图

核心概念

场景图（Scene Graph）是一种用于组织和管理游戏世界中所有对象的层级数据结构。它以树形结构表示对象之间的父子关系，子节点的变换（位置、旋转、缩放）相对于父节点，实现了变换的自动级联传播。

节点与变换系统
场景图中每个节点包含局部变换（相对于父节点）和世界变换（相对于世界原点）。当父节点的变换改变时，所有子孙节点的世界变换需要重新计算。


class Transform {
  position: Vec3 = { x: 0, y: 0, z: 0 };
  rotation: Quat = { x: 0, y: 0, z: 0, w: 1 };
  scale: Vec3 = { x: 1, y: 1, z: 1 };

  getMatrix(): Mat4 {
    return Mat4.compose(this.position, this.rotation, this.scale);
  }
}

class SceneNode {
  name: string;
  localTransform = new Transform();
  worldTransform = new Transform();
  parent: SceneNode | null = null;
  children: SceneNode[] = [];
  dirty = true;
  visible = true;
  layer = 0;

  constructor(name: string) {
    this.name = name;
  }

  addChild(child: SceneNode): void {
    if (child.parent) {
      child.parent.removeChild(child);
    }
    child.parent = this;
    this.children.push(child);
    child.markDirty();
  }

  removeChild(child: SceneNode): void {
    const index = this.children.indexOf(child);
    if (index >= 0) {
      this.children.splice(index, 1);
      child.parent = null;
    }
  }

  markDirty(): void {
    if (this.dirty) return;
    this.dirty = true;
    for (const child of this.children) {
      child.markDirty();
    }
  }

  setPosition(x: number, y: number, z: number): void {
    this.localTransform.position = { x, y, z };
    this.markDirty();
  }

  updateWorldTransform(): void {
    if (!this.dirty) return;
    if (this.parent) {
      const parentMatrix = this.parent.worldTransform.getMatrix();
      const localMatrix = this.localTransform.getMatrix();
      const worldMatrix = Mat4.multiply(parentMatrix, localMatrix);
      Mat4.decompose(
        worldMatrix,
        this.worldTransform.position,
        this.worldTransform.rotation,
        this.worldTransform.scale,
      );
    } else {
      this.worldTransform.position = { ...this.localTransform.position };
      this.worldTransform.rotation = { ...this.localTransform.rotation };
      this.worldTransform.scale = { ...this.localTransform.scale };
    }
    this.dirty = false;
    for (const child of this.children) {
      child.updateWorldTransform();
    }
  }
}

interface Vec3 {
  x: number;
  y: number;
  z: number;
}
interface Quat {
  x: number;
  y: number;
  z: number;
  w: number;
}
interface Mat4 {
  elements: number[];
}

const Mat4 = {
  compose(_pos: Vec3, _rot: Quat, _scale: Vec3): Mat4 {
    return { elements: [] };
  },
  multiply(_a: Mat4, _b: Mat4): Mat4 {
    return { elements: [] };
  },
  decompose(_m: Mat4, _pos: Vec3, _rot: Quat, _scale: Vec3): void {},
};
脏标记（Dirty Flag）优化是场景图性能的关键——只有变换实际改变的节点及其子孙才会重新计算世界变换，未改变的子树直接跳过。


场景遍历与渲染队列
场景图的遍历方式决定了渲染和更新的执行顺序。深度优先遍历（DFS）最常用，先处理父节点再处理子节点，确保世界变换在子节点需要时已经就绪。


interface RenderCommand {
  node: SceneNode;
  worldMatrix: Mat4;
  material: string;
  mesh: string;
  sortKey: number;
}

class SceneRenderer {
  private opaqueQueue: RenderCommand[] = [];
  private transparentQueue: RenderCommand[] = [];

  collectRenderCommands(root: SceneNode, cameraPosition: Vec3): void {
    this.opaqueQueue = [];
    this.transparentQueue = [];
    this.traverse(root, cameraPosition);
    this.opaqueQueue.sort((a, b) => a.sortKey - b.sortKey);
    this.transparentQueue.sort((a, b) => b.sortKey - a.sortKey);
  }

  private traverse(node: SceneNode, cameraPos: Vec3): void {
    if (!node.visible) return;
    node.updateWorldTransform();

    if (this.hasRenderable(node)) {
      const distance = this.distanceTo(node.worldTransform.position, cameraPos);
      const command: RenderCommand = {
        node,
        worldMatrix: node.worldTransform.getMatrix(),
        material: this.getMaterial(node),
        mesh: this.getMesh(node),
        sortKey: distance,
      };

      if (this.isTransparent(node)) {
        this.transparentQueue.push(command);
      } else {
        this.opaqueQueue.push(command);
      }
    }

    for (const child of node.children) {
      this.traverse(child, cameraPos);
    }
  }

  private distanceTo(a: Vec3, b: Vec3): number {
    return Math.sqrt((a.x - b.x) ** 2 + (a.y - b.y) ** 2 + (a.z - b.z) ** 2);
  }

  private hasRenderable(_node: SceneNode): boolean {
    return true;
  }
  private getMaterial(_node: SceneNode): string {
    return 'default';
  }
  private getMesh(_node: SceneNode): string {
    return 'default';
  }
  private isTransparent(_node: SceneNode): boolean {
    return false;
  }
}
不透明物体从前到后排序以利用深度测试的早期剔除（Early-Z），减少无效像素着色。透明物体从后到前排序以确保正确的混合顺序。


场景图查询与检索
游戏逻辑经常需要在场景图中查找特定节点——按名称、按标签、按区域或按组件类型。高效的查询机制对性能至关重要。


class SceneQuery {
  static findByName(root: SceneNode, name: string): SceneNode | null {
    if (root.name === name) return root;
    for (const child of root.children) {
      const found = this.findByName(child, name);
      if (found) return found;
    }
    return null;
  }

  static findAllByLayer(root: SceneNode, layer: number): SceneNode[] {
    const results: SceneNode[] = [];
    const stack: SceneNode[] = [root];
    while (stack.length > 0) {
      const node = stack.pop()!;
      if (node.layer === layer) {
        results.push(node);
      }
      for (const child of node.children) {
        stack.push(child);
      }
    }
    return results;
  }

  static findInRadius(root: SceneNode, center: Vec3, radius: number): SceneNode[] {
    const results: SceneNode[] = [];
    const radiusSq = radius * radius;
    const stack: SceneNode[] = [root];
    while (stack.length > 0) {
      const node = stack.pop()!;
      const pos = node.worldTransform.position;
      const distSq = (pos.x - center.x) ** 2 + (pos.y - center.y) ** 2 + (pos.z - center.z) ** 2;
      if (distSq <= radiusSq) {
        results.push(node);
      }
      for (const child of node.children) {
        stack.push(child);
      }
    }
    return results;
  }
}
小结
    

  • 场景图以树形层级组织游戏对象，子节点变换相对于父节点
    • 

  • 脏标记优化避免不必要的世界变换重计算
    • 

  • 渲染队列将不透明物体前到后排序，透明物体后到前排序
    • 

  • 场景查询支持按名称、层级和空间范围快速检索节点
    • 

  • 大型场景需要结合空间索引（如四叉树、八叉树）提升查询性能
