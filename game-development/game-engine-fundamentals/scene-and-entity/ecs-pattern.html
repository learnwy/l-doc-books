实体组件系统

核心概念

实体组件系统（Entity Component System, ECS）是一种面向数据的架构模式，将游戏对象分解为三个核心概念：实体（Entity）是唯一标识符，组件（Component）是纯数据容器，系统（System）包含处理逻辑。这种分离使得游戏对象的行为通过组合而非继承来定义。

组件存储与原型
组件存储的方式直接影响 ECS 的性能。稀疏集合（Sparse Set）和原型（Archetype）是两种主流实现。原型将具有相同组件组合的实体存储在连续内存中，极大提升了遍历时的缓存命中率。


type Entity = number;
type ComponentType = string;

interface ComponentArray<T> {
  get(entity: Entity): T | undefined;
  set(entity: Entity, data: T): void;
  remove(entity: Entity): void;
  has(entity: Entity): boolean;
}

class SparseSet<T> implements ComponentArray<T> {
  private sparse: (number | undefined)[] = [];
  private dense: Entity[] = [];
  private data: T[] = [];

  get(entity: Entity): T | undefined {
    const index = this.sparse[entity];
    if (index === undefined) return undefined;
    return this.data[index];
  }

  set(entity: Entity, value: T): void {
    const existing = this.sparse[entity];
    if (existing !== undefined) {
      this.data[existing] = value;
      return;
    }
    this.sparse[entity] = this.dense.length;
    this.dense.push(entity);
    this.data.push(value);
  }

  remove(entity: Entity): void {
    const index = this.sparse[entity];
    if (index === undefined) return;
    const lastIndex = this.dense.length - 1;
    const lastEntity = this.dense[lastIndex];
    this.dense[index] = lastEntity;
    this.data[index] = this.data[lastIndex];
    this.sparse[lastEntity] = index;
    this.dense.pop();
    this.data.pop();
    this.sparse[entity] = undefined;
  }

  has(entity: Entity): boolean {
    return this.sparse[entity] !== undefined;
  }

  entries(): Array<[Entity, T]> {
    return this.dense.map((entity, i) => [entity, this.data[i]]);
  }
}
查询与系统执行
系统通过查询（Query）声明它需要哪些组件，ECS 框架负责高效地找到满足条件的所有实体。查询的性能直接决定了系统更新的效率。


interface Position {
  x: number;
  y: number;
  z: number;
}
interface Velocity {
  dx: number;
  dy: number;
  dz: number;
}
interface Health {
  current: number;
  max: number;
}

class World {
  private nextEntity = 0;
  private components = new Map<ComponentType, SparseSet<unknown>>();
  private systems: GameSystem[] = [];

  createEntity(): Entity {
    return this.nextEntity++;
  }

  addComponent<T>(entity: Entity, type: ComponentType, data: T): void {
    if (!this.components.has(type)) {
      this.components.set(type, new SparseSet<unknown>());
    }
    this.components.get(type)!.set(entity, data);
  }

  getComponent<T>(entity: Entity, type: ComponentType): T | undefined {
    return this.components.get(type)?.get(entity) as T | undefined;
  }

  removeComponent(entity: Entity, type: ComponentType): void {
    this.components.get(type)?.remove(entity);
  }

  query(...types: ComponentType[]): Entity[] {
    if (types.length === 0) return [];
    const sets = types.map((t) => this.components.get(t)).filter(Boolean) as SparseSet<unknown>[];
    if (sets.length !== types.length) return [];
    const smallest = sets.reduce((min, set) => (set.entries().length < min.entries().length ? set : min));
    return smallest
      .entries()
      .map(([entity]) => entity)
      .filter((entity) => sets.every((set) => set.has(entity)));
  }

  registerSystem(system: GameSystem): void {
    this.systems.push(system);
    this.systems.sort((a, b) => a.priority - b.priority);
  }

  update(dt: number): void {
    for (const system of this.systems) {
      system.update(this, dt);
    }
  }
}

interface GameSystem {
  priority: number;
  update(world: World, dt: number): void;
}

class MovementSystem implements GameSystem {
  priority = 10;

  update(world: World, dt: number): void {
    const entities = world.query('position', 'velocity');
    for (const entity of entities) {
      const pos = world.getComponent<Position>(entity, 'position')!;
      const vel = world.getComponent<Velocity>(entity, 'velocity')!;
      pos.x += vel.dx * dt;
      pos.y += vel.dy * dt;
      pos.z += vel.dz * dt;
    }
  }
}
实体生命周期管理
实体的创建和销毁需要特殊处理——直接删除实体可能导致正在遍历的系统出错。延迟销毁（Deferred Destruction）将实体标记为待删除，在当前帧所有系统更新完成后统一清理。


class EntityManager {
  private alive = new Set<Entity>();
  private pendingDestroy: Entity[] = [];
  private pendingCreate: Array<{ entity: Entity; components: Array<[ComponentType, unknown]> }> = [];
  private nextEntity = 0;

  create(): Entity {
    const entity = this.nextEntity++;
    this.alive.add(entity);
    return entity;
  }

  destroy(entity: Entity): void {
    if (this.alive.has(entity)) {
      this.pendingDestroy.push(entity);
    }
  }

  deferCreate(components: Array<[ComponentType, unknown]>): Entity {
    const entity = this.nextEntity++;
    this.pendingCreate.push({ entity, components });
    return entity;
  }

  flush(world: World): void {
    for (const { entity, components } of this.pendingCreate) {
      this.alive.add(entity);
      for (const [type, data] of components) {
        world.addComponent(entity, type, data);
      }
    }
    this.pendingCreate = [];

    for (const entity of this.pendingDestroy) {
      this.alive.delete(entity);
    }
    this.pendingDestroy = [];
  }

  isAlive(entity: Entity): boolean {
    return this.alive.has(entity);
  }

  getCount(): number {
    return this.alive.size;
  }
}
小结
    

  • ECS 通过数据与逻辑分离实现高度灵活的对象组合，避免了深层继承的弊端
    • 

  • 稀疏集合提供 O(1) 的组件访问，原型分组优化了连续内存遍历性能
    • 

  • 系统通过查询声明依赖的组件类型，框架负责高效匹配实体
    • 

  • 延迟创建和销毁确保遍历过程中数据结构的一致性
    • 

  • ECS 是现代游戏引擎的主流架构选择，尤其适合大量同质实体的场景
