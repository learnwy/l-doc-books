对象生命周期管理

核心概念

游戏对象的生命周期管理涵盖对象的创建、初始化、激活、更新、停用和销毁等阶段。正确管理生命周期是避免内存泄漏、悬空引用和状态不一致的关键。

    Init --> Active["激活"]
    Active --> Update["更新循环"]
    Update --> Deactivate["停用"]
    Deactivate --> Pool
    Deactivate --> Destroy["销毁"]
    Destroy --> Free["释放内存"]
生命周期阶段 内存状态 逻辑状态 可见性 触发时机
池化等待 已分配 未初始化 不可见 对象回收后
创建 已分配 默认值 不可见 工厂方法调用
初始化 已分配 已配置 不可见 加载数据完成
激活 已分配 运行中 可见 进入场景
更新 已分配 运行中 可见 每帧
停用 已分配 暂停 不可见 离开场景
销毁 待释放 无效 不可见 不再需要

对象工厂与原型

对象工厂封装了创建过程的复杂性，确保每个对象在创建时都经过完整的初始化流程。原型模式通过克隆预配置的模板对象来加速创建过程。

interface GameObjectConfig {
  type: string;
  position: { x: number; y: number; z: number };
  properties: Record<string, unknown>;
}

interface GameObject {
  id: number;
  type: string;
  active: boolean;
  components: Map<string, unknown>;
  init(config: GameObjectConfig): void;
  activate(): void;
  update(dt: number): void;
  deactivate(): void;
  destroy(): void;
  reset(): void;
}

class GameObjectFactory {
  private nextId = 0;
  private prototypes = new Map<string, GameObjectConfig>();
  private creators = new Map<string, (id: number) => GameObject>();

  registerPrototype(type: string, config: GameObjectConfig): void {
    this.prototypes.set(type, config);
  }

  registerCreator(type: string, creator: (id: number) => GameObject): void {
    this.creators.set(type, creator);
  }

  create(type: string, overrides?: Partial<GameObjectConfig>): GameObject {
    const creator = this.creators.get(type);
    if (!creator) throw new Error(`Unknown type: ${type}`);

    const id = this.nextId++;
    const obj = creator(id);

    const prototype = this.prototypes.get(type);
    const config: GameObjectConfig = {
      type,
      position: overrides?.position ?? prototype?.position ?? { x: 0, y: 0, z: 0 },
      properties: { ...prototype?.properties, ...overrides?.properties },
    };

    obj.init(config);
    return obj;
  }

  createBatch(type: string, count: number, configFn: (index: number) => Partial<GameObjectConfig>): GameObject[] {
    const objects: GameObject[] = [];
    for (let i = 0; i < count; i++) {
      objects.push(this.create(type, configFn(i)));
    }
    return objects;
  }
}

对象池技术

对象池（Object Pool）通过预分配和重用对象来避免频繁的内存分配和垃圾回收。在游戏开发中，子弹、粒子、敌人等高频创建/销毁的对象特别适合使用对象池。

class ObjectPool<T extends Poolable> {
  private available: T[] = [];
  private inUse = new Set<T>();
  private factory: () => T;
  private maxSize: number;

  constructor(factory: () => T, initialSize: number, maxSize: number) {
    this.factory = factory;
    this.maxSize = maxSize;
    for (let i = 0; i < initialSize; i++) {
      this.available.push(factory());
    }
  }

  acquire(): T | null {
    let obj: T;
    if (this.available.length > 0) {
      obj = this.available.pop()!;
    } else if (this.inUse.size < this.maxSize) {
      obj = this.factory();
    } else {
      return null;
    }
    obj.onAcquire();
    this.inUse.add(obj);
    return obj;
  }

  release(obj: T): void {
    if (!this.inUse.has(obj)) return;
    this.inUse.delete(obj);
    obj.onRelease();
    this.available.push(obj);
  }

  releaseAll(): void {
    for (const obj of this.inUse) {
      obj.onRelease();
      this.available.push(obj);
    }
    this.inUse.clear();
  }

  getActiveCount(): number {
    return this.inUse.size;
  }
  getAvailableCount(): number {
    return this.available.length;
  }
  getTotalCount(): number {
    return this.inUse.size + this.available.length;
  }
}

interface Poolable {
  onAcquire(): void;
  onRelease(): void;
}

class Bullet implements Poolable {
  x = 0;
  y = 0;
  vx = 0;
  vy = 0;
  active = false;
  lifetime = 0;

  onAcquire(): void {
    this.active = true;
    this.lifetime = 0;
  }

  onRelease(): void {
    this.active = false;
    this.x = 0;
    this.y = 0;
    this.vx = 0;
    this.vy = 0;
  }

  update(dt: number): boolean {
    this.x += this.vx * dt;
    this.y += this.vy * dt;
    this.lifetime += dt;
    return this.lifetime < 5.0;
  }
}

引用计数与弱引用

在复杂的对象关系网中，引用计数帮助追踪对象是否仍被需要。弱引用允许引用对象而不阻止其被销毁，避免了循环引用导致的内存泄漏。

class RefCounted {
  private refCount = 0;
  private destroyed = false;

  addRef(): void {
    if (this.destroyed) throw new Error('Cannot reference destroyed object');
    this.refCount++;
  }

  release(): void {
    this.refCount--;
    if (this.refCount <= 0) {
      this.dispose();
    }
  }

  getRefCount(): number {
    return this.refCount;
  }
  isDestroyed(): boolean {
    return this.destroyed;
  }

  protected dispose(): void {
    this.destroyed = true;
  }
}

class WeakRef<T extends { isDestroyed(): boolean }> {
  private target: T | null;

  constructor(target: T) {
    this.target = target;
  }

  get(): T | null {
    if (this.target && this.target.isDestroyed()) {
      this.target = null;
    }
    return this.target;
  }

  isValid(): boolean {
    return this.get() !== null;
  }
}

class Handle<T> {
  private generation: number;
  private index: number;
  private store: HandleStore<T>;

  constructor(index: number, generation: number, store: HandleStore<T>) {
    this.index = index;
    this.generation = generation;
    this.store = store;
  }

  resolve(): T | null {
    return this.store.resolve(this.index, this.generation);
  }
}

class HandleStore<T> {
  private entries: Array<{ value: T | null; generation: number }> = [];
  private freeIndices: number[] = [];

  allocate(value: T): Handle<T> {
    let index: number;
    if (this.freeIndices.length > 0) {
      index = this.freeIndices.pop()!;
      this.entries[index].value = value;
      this.entries[index].generation++;
    } else {
      index = this.entries.length;
      this.entries.push({ value, generation: 0 });
    }
    return new Handle(index, this.entries[index].generation, this);
  }

  free(index: number): void {
    if (index < this.entries.length) {
      this.entries[index].value = null;
      this.freeIndices.push(index);
    }
  }

  resolve(index: number, generation: number): T | null {
    const entry = this.entries[index];
    if (!entry || entry.generation !== generation) return null;
    return entry.value;
  }
}

句柄（Handle）模式结合了索引和代际计数器，当对象被回收后代际递增，旧句柄自动失效，有效防止了悬空引用。

延迟操作队列

修改对象状态（创建、销毁、组件变更）不应在系统遍历过程中立即执行，否则可能导致迭代器失效或数据不一致。延迟操作队列将所有修改操作缓冲，在安全时点统一执行。

type DeferredAction = () => void;

class DeferredQueue {
  private queues: DeferredAction[][] = [[], []];
  private writeIndex = 0;

  enqueue(action: DeferredAction): void {
    this.queues[this.writeIndex].push(action);
  }

  flush(): void {
    const readIndex = this.writeIndex;
    this.writeIndex = 1 - this.writeIndex;

    const actions = this.queues[readIndex];
    this.queues[readIndex] = [];

    for (const action of actions) {
      action();
    }
  }

  getPendingCount(): number {
    return this.queues[this.writeIndex].length;
  }
}
