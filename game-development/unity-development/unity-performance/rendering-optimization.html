渲染优化

核心概念

渲染是游戏运行时最消耗 GPU 资源的环节。Unity 的渲染管线将场景中的 3D 对象转化为屏幕像素，经历裁剪、排序、批处理、光照计算和后处理等步骤。渲染优化的目标是在视觉质量和帧率之间找到最佳平衡点，核心策略包括减少 Draw Call、降低 Overdraw、优化 Shader 复杂度和控制分辨率。

Draw Call 与批处理优化
Draw Call 是 CPU 向 GPU 发送的渲染指令。每次 Draw Call 都有固定的 CPU 开销（状态切换、数据传输），因此减少 Draw Call 数量是渲染优化的首要目标。Unity 提供了静态批处理、动态批处理、GPU Instancing 和 SRP Batcher 四种合批机制。

using UnityEngine;

public class InstancedRenderer : MonoBehaviour
{
    [SerializeField] private Mesh mesh;
    [SerializeField] private Material material;
    [SerializeField] private int count = 1000;
    [SerializeField] private float range = 50f;

    private Matrix4x4[] matrices;
    private MaterialPropertyBlock propertyBlock;
    private Vector4[] colors;

    private void Awake()
    {
        matrices = new Matrix4x4[count];
        colors = new Vector4[count];
        propertyBlock = new MaterialPropertyBlock();

        for (int i = 0; i < count; i++)
        {
            Vector3 position = new Vector3(
                Random.Range(-range, range),
                0f,
                Random.Range(-range, range)
            );
            Quaternion rotation = Quaternion.Euler(0f, Random.Range(0f, 360f), 0f);
            float scale = Random.Range(0.8f, 1.2f);

            matrices[i] = Matrix4x4.TRS(position, rotation, Vector3.one * scale);
            colors[i] = new Vector4(
                Random.Range(0.5f, 1f),
                Random.Range(0.5f, 1f),
                Random.Range(0.5f, 1f),
                1f
            );
        }

        propertyBlock.SetVectorArray("_Color", colors);
    }

    private void Update()
    {
        Graphics.DrawMeshInstanced(mesh, 0, material, matrices, count, propertyBlock);
    }
}
Graphics.DrawMeshInstanced 在一个 Draw Call 中渲染最多 1023 个相同 Mesh 实例，配合 MaterialPropertyBlock 可以为每个实例设置不同的颜色等属性，而不会打断批处理。


LOD 与视距优化
LOD（Level of Detail）系统根据物体与相机的距离自动切换不同精度的模型，远处物体使用低面数模型，近处使用高面数模型。这直接减少了 GPU 需要处理的顶点和三角面数量。


using UnityEngine;

public class LODConfigHelper : MonoBehaviour
{
    [SerializeField] private LODGroup lodGroup;

    public void SetupLODGroup(Renderer[] lod0Renderers,
        Renderer[] lod1Renderers, Renderer[] lod2Renderers)
    {
        LOD[] lods = new LOD[4];

        lods[0] = new LOD(0.6f, lod0Renderers);
        lods[1] = new LOD(0.3f, lod1Renderers);
        lods[2] = new LOD(0.1f, lod2Renderers);
        lods[3] = new LOD(0.01f, new Renderer[0]);

        lodGroup.SetLODs(lods);
        lodGroup.RecalculateBounds();
    }

    public void SetAggressiveLOD()
    {
        lodGroup.fadeMode = LODFadeMode.CrossFade;
        lodGroup.animateCrossFading = true;
    }
}
Camera 的 Far Clip Plane 设置也直接影响渲染负载。将远裁剪面设置为合理值（如 500 米而非默认 1000 米），可以减少大量远处物体的渲染。

遮挡剔除与可见性管理
遮挡剔除（Occlusion Culling）自动跳过被其他物体完全遮挡的对象的渲染，减少 GPU 不必要的计算。Unity 内置了基于预计算的遮挡剔除系统，适合室内场景和密集建筑群。


using UnityEngine;

public class VisibilityOptimizer : MonoBehaviour
{
    [SerializeField] private float checkInterval = 0.5f;
    [SerializeField] private float activateDistance = 100f;
    [SerializeField] private Transform player;

    private Renderer[] managedRenderers;
    private float nextCheckTime;

    private void Awake()
    {
        managedRenderers = GetComponentsInChildren<Renderer>();
    }

    private void Update()
    {
        if (Time.time < nextCheckTime) return;
        nextCheckTime = Time.time + checkInterval;

        float sqrDist = (transform.position - player.position).sqrMagnitude;
        float sqrThreshold = activateDistance * activateDistance;
        bool shouldBeVisible = sqrDist <= sqrThreshold;

        for (int i = 0; i < managedRenderers.Length; i++)
        {
            if (managedRenderers[i].enabled != shouldBeVisible)
            {
                managedRenderers[i].enabled = shouldBeVisible;
            }
        }
    }
}
视锥体剔除（Frustum Culling）是 Unity 自动执行的，不在相机视野内的物体不会提交渲染。但对于大型开放世界场景，仍需配合手动距离检测来管理远处对象的激活状态。


光照与阴影优化
实时光源和阴影是渲染开销最大的组成部分之一。每个实时光源都会增加额外的渲染 Pass，实时阴影需要渲染 Shadow Map，开销随阴影分辨率和光源数量线性增长。

using UnityEngine;

public class ShadowOptimizer : MonoBehaviour
{
    [SerializeField] private Light mainLight;
    [SerializeField] private float highQualityDistance = 30f;
    [SerializeField] private float mediumQualityDistance = 60f;

    private Transform playerTransform;

    private void Start()
    {
        playerTransform = Camera.main.transform;
        QualitySettings.shadowDistance = mediumQualityDistance;
    }

    public void SetShadowQuality(int level)
    {
        switch (level)
        {
            case 0:
                mainLight.shadows = LightShadows.None;
                break;
            case 1:
                mainLight.shadows = LightShadows.Hard;
                mainLight.shadowResolution = LightShadowResolution.Low;
                QualitySettings.shadowDistance = highQualityDistance;
                break;
            case 2:
                mainLight.shadows = LightShadows.Soft;
                mainLight.shadowResolution = LightShadowResolution.Medium;
                QualitySettings.shadowDistance = mediumQualityDistance;
                break;
            case 3:
                mainLight.shadows = LightShadows.Soft;
                mainLight.shadowResolution = LightShadowResolution.High;
                QualitySettings.shadowDistance = 100f;
                break;
        }
    }
}
小结
    

  • Draw Call 优化是渲染性能的首要目标，GPU Instancing 可在一个调用中渲染上千个实例
    • 

  • LOD 系统根据距离自动切换模型精度，远处物体使用低面数模型或直接剔除
    • 

  • 遮挡剔除通过多层级过滤（视锥体→遮挡→LOD）减少最终渲染的对象数量
    • 

  • 光照优化优先使用烘焙光照，动态物体使用 Light Probe 获取间接光
    • 

  • 阴影距离和分辨率是可调节的性能旋钮，按需配置不同质量等级
    • 

  • Frame Debugger 和 Stats 窗口是验证渲染优化效果的关键工具
    •
