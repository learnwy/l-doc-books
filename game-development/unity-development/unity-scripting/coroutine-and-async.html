协程与异步编程

核心概念

Unity 的协程（Coroutine）是一种基于迭代器的协作式多任务机制，允许将需要跨越多帧执行的操作写成顺序代码。协程并非多线程，它运行在主线程上，通过 yield return 语句在每帧之间暂停和恢复执行。除了协程之外，Unity 还支持 C# 原生的 async/await 异步编程模式以及 UniTask 等第三方方案，各有适用场景。

协程调度机制
协程的核心在于 IEnumerator 迭代器和 yield return 关键字。Unity 引擎维护了一个协程调度器，每帧在特定时间点检查所有活跃协程的等待条件，条件满足时恢复执行到下一个 yield 语句。


不同的 yield 指令决定了协程在帧循环中的恢复时机。理解这些时机对于编写正确的协程逻辑至关重要：

using UnityEngine;
using System.Collections;

public class WaveSpawner : MonoBehaviour
{
    [SerializeField] private GameObject enemyPrefab;
    [SerializeField] private Transform[] spawnPoints;
    [SerializeField] private int enemiesPerWave = 5;
    [SerializeField] private float spawnInterval = 0.5f;
    [SerializeField] private float waveCooldown = 10f;

    private void Start()
    {
        StartCoroutine(SpawnWaves());
    }

    private IEnumerator SpawnWaves()
    {
        int waveNumber = 0;

        while (true)
        {
            waveNumber++;
            yield return StartCoroutine(SpawnWave(waveNumber));
            yield return new WaitForSeconds(waveCooldown);
        }
    }

    private IEnumerator SpawnWave(int wave)
    {
        int count = enemiesPerWave + wave * 2;

        for (int i = 0; i < count; i++)
        {
            Transform point = spawnPoints[Random.Range(0, spawnPoints.Length)];
            Instantiate(enemyPrefab, point.position, point.rotation);
            yield return new WaitForSeconds(spawnInterval);
        }
    }
}
协程的生命周期管理
协程的启动与停止需要精确管理，否则容易出现内存泄漏或逻辑残留。协程与启动它的 MonoBehaviour 绑定，当 GameObject 被禁用或销毁时，所有绑定的协程自动停止。


正确管理协程引用是避免问题的关键。通过缓存 Coroutine 引用可以精确控制特定协程的停止：


using UnityEngine;
using System.Collections;

public class AbilitySystem : MonoBehaviour
{
    [SerializeField] private float cooldownDuration = 3f;
    [SerializeField] private float channelDuration = 2f;

    private Coroutine cooldownRoutine;
    private Coroutine channelRoutine;
    private bool isCoolingDown;
    private bool isChanneling;

    public void UseAbility()
    {
        if (isCoolingDown || isChanneling) return;

        channelRoutine = StartCoroutine(ChannelAbility());
    }

    public void CancelChannel()
    {
        if (channelRoutine != null)
        {
            StopCoroutine(channelRoutine);
            channelRoutine = null;
            isChanneling = false;
        }
    }

    private IEnumerator ChannelAbility()
    {
        isChanneling = true;
        yield return new WaitForSeconds(channelDuration);
        isChanneling = false;

        ExecuteAbility();

        cooldownRoutine = StartCoroutine(Cooldown());
    }

    private IEnumerator Cooldown()
    {
        isCoolingDown = true;
        yield return new WaitForSeconds(cooldownDuration);
        isCoolingDown = false;
        cooldownRoutine = null;
    }

    private void ExecuteAbility()
    {
        Debug.Log("技能释放！");
    }

    private void OnDisable()
    {
        isCoolingDown = false;
        isChanneling = false;
        cooldownRoutine = null;
        channelRoutine = null;
    }
}
需要注意的关键陷阱：SetActive(false) 会停止所有协程且重新激活后不会恢复；禁用组件（enabled = false）不会停止协程但 OnDisable 会被调用；StopCoroutine 传入字符串和传入引用是不同的 API。


async/await 与 Awaitable
Unity 2023+ 引入了原生的 Awaitable 类型，使得 async/await 可以直接在 Unity 生命周期中使用，无需第三方库。Awaitable 提供了与协程 yield 指令对应的异步等待方法，同时支持 CancellationToken 实现优雅的取消机制。


using UnityEngine;
using System.Threading;

public class AsyncDialogueSystem : MonoBehaviour
{
    [SerializeField] private DialogueUI dialogueUI;
    [SerializeField] private float typingSpeed = 0.05f;

    private CancellationTokenSource cts;

    public async void StartDialogue(string[] lines)
    {
        cts?.Cancel();
        cts = new CancellationTokenSource();

        try
        {
            foreach (string line in lines)
            {
                await TypeText(line, cts.Token);
                await WaitForInput(cts.Token);
            }
            dialogueUI.Hide();
        }
        catch (OperationCanceledException)
        {
            dialogueUI.Hide();
        }
    }

    private async Awaitable TypeText(string text, CancellationToken token)
    {
        dialogueUI.ClearText();

        foreach (char c in text)
        {
            token.ThrowIfCancellationRequested();
            dialogueUI.AppendChar(c);
            await Awaitable.WaitForSecondsAsync(typingSpeed, token);
        }
    }

    private async Awaitable WaitForInput(CancellationToken token)
    {
        while (!Input.GetButtonDown("Submit"))
        {
            token.ThrowIfCancellationRequested();
            await Awaitable.NextFrameAsync(token);
        }
    }

    private void OnDestroy()
    {
        cts?.Cancel();
        cts?.Dispose();
    }
}

协程性能优化策略
协程每次 yield return new WaitForSeconds() 都会产生堆内存分配，在高频调用场景下会加重 GC 压力。通过缓存 yield 对象可以显著降低分配：


using UnityEngine;
using System.Collections;
using System.Collections.Generic;

public static class YieldCache
{
    private static readonly Dictionary<float, WaitForSeconds> waitCache = new();
    private static readonly WaitForEndOfFrame endOfFrame = new();
    private static readonly WaitForFixedUpdate fixedUpdate = new();

    public static WaitForSeconds Seconds(float time)
    {
        if (!waitCache.TryGetValue(time, out var wait))
        {
            wait = new WaitForSeconds(time);
            waitCache[time] = wait;
        }
        return wait;
    }

    public static WaitForEndOfFrame EndOfFrame => endOfFrame;
    public static WaitForFixedUpdate FixedUpdate => fixedUpdate;
}

public class OptimizedSpawner : MonoBehaviour
{
    private IEnumerator SpawnLoop()
    {
        while (true)
        {
            SpawnEnemy();
            yield return YieldCache.Seconds(2f);
        }
    }

    private void SpawnEnemy()
    {
        Debug.Log("敌人生成");
    }
}
分帧处理是协程的另一个重要应用场景，可以将大量计算分散到多帧中执行，避免单帧卡顿：


using UnityEngine;
using System.Collections;
using System.Collections.Generic;

public class ChunkLoader : MonoBehaviour
{
    [SerializeField] private int itemsPerFrame = 50;

    public IEnumerator LoadItems<T>(List<T> items, System.Action<T> processAction)
    {
        for (int i = 0; i < items.Count; i++)
        {
            processAction(items[i]);

            if ((i + 1) % itemsPerFrame == 0)
            {
                yield return null;
            }
        }
    }
}
小结
    

  • 协程是基于迭代器的协作式多任务机制，运行在主线程上，通过 yield return 暂停和恢复
    • 

  • 不同 yield 指令决定协程在帧循环中的恢复时机，理解时机是编写正确协程的关键
    • 

  • 协程与 MonoBehaviour 生命周期绑定，GameObject 禁用会停止协程且不可恢复
    • 

  • async/await 配合 Awaitable 提供了异常处理、返回值和取消机制的完整异步方案
    • 

  • 缓存 WaitForSeconds 等 yield 对象可以避免重复的堆内存分配
    • 

  • 分帧处理模式适合将大量数据加载或计算分散到多帧执行
