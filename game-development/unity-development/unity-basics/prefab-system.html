预制体系统

核心概念

预制体（Prefab）是 Unity 的资源模板系统，允许将完整配置的 GameObject（包括组件、属性、子对象）保存为可复用的资源文件。预制体实例与源预制体保持关联，修改源预制体会自动传播到所有实例，实现了"一处修改、处处更新"的工作流。预制体是 Unity 项目中管理可复用对象的核心机制。

创建与实例化
创建预制体的方式有两种：将场景中已配置好的 GameObject 拖入 Project 面板，或通过代码在运行时实例化。Instantiate 是 Unity 中最常用的运行时对象创建方法。


using UnityEngine;

public class PrefabSpawner : MonoBehaviour
{
    [SerializeField] private GameObject bulletPrefab;
    [SerializeField] private Transform firePoint;
    [SerializeField] private float bulletSpeed = 20f;

    public GameObject SpawnBullet()
    {
        GameObject bullet = Instantiate(
            bulletPrefab,
            firePoint.position,
            firePoint.rotation
        );

        var rb = bullet.GetComponent<Rigidbody>();
        if (rb != null)
            rb.linearVelocity = firePoint.forward * bulletSpeed;

        Destroy(bullet, 5f);
        return bullet;
    }

    public T SpawnAs<T>(T prefab, Vector3 pos, Quaternion rot) where T : Object
    {
        return Instantiate(prefab, pos, rot);
    }
}
Instantiate 支持泛型重载，可以直接返回具体组件类型而非 GameObject，减少后续 GetComponent 调用。将 prefab 字段类型声明为具体组件类型（如 Rigidbody）而非 GameObject，可以在 Inspector 中限制只能拖入包含该组件的预制体。


Override 与 Apply 工作流
预制体实例支持局部覆写（Override）：修改实例的属性值、添加新组件或新子对象时，这些修改作为覆写层存储在实例上，不影响源预制体和其他实例。Inspector 中覆写的属性以蓝色竖条标识。

using UnityEngine;

#if UNITY_EDITOR
using UnityEditor;
#endif

public class PrefabUtilityHelper : MonoBehaviour
{
    public static bool IsPrefabInstance(GameObject go)
    {
#if UNITY_EDITOR
        return PrefabUtility.IsPartOfPrefabInstance(go);
#else
        return false;
#endif
    }

    public static void ApplyOverrides(GameObject instance)
    {
#if UNITY_EDITOR
        var prefabRoot = PrefabUtility.GetOutermostPrefabInstanceRoot(instance);
        if (prefabRoot != null)
        {
            string prefabPath = PrefabUtility.GetPrefabAssetPathOfNearestInstanceRoot(instance);
            PrefabUtility.ApplyPrefabInstance(prefabRoot, InteractionMode.UserAction);
        }
#endif
    }
}
预制体编辑模式（Prefab Mode）提供隔离的编辑环境，在此模式下的修改直接作用于源预制体。可以通过双击 Project 中的预制体或点击 Hierarchy 中实例右侧的箭头进入。


Nested Prefab 与 Variant
嵌套预制体（Nested Prefab）允许预制体包含子预制体，实现模块化组装。预制体变体（Prefab Variant）基于另一预制体派生，继承其所有设置并添加覆写，类似面向对象的继承关系。


using UnityEngine;

public class WeaponSystem : MonoBehaviour
{
    [SerializeField] private GameObject baseWeaponPrefab;
    [SerializeField] private GameObject[] attachmentPrefabs;

    public GameObject AssembleWeapon(int[] attachmentIndices)
    {
        GameObject weapon = Instantiate(baseWeaponPrefab);

        foreach (int index in attachmentIndices)
        {
            if (index >= 0 && index < attachmentPrefabs.Length)
            {
                Transform mountPoint = weapon.transform.Find($"Mount_{index}");
                if (mountPoint != null)
                {
                    Instantiate(
                        attachmentPrefabs[index],
                        mountPoint.position,
                        mountPoint.rotation,
                        mountPoint
                    );
                }
            }
        }

        return weapon;
    }
}

变体链不宜过深（建议不超过 3 层），过深的变体链会增加修改追踪的复杂度，也可能影响编辑器性能。


对象池与性能优化
频繁的 Instantiate/Destroy 会产生大量 GC 分配和内存碎片。对象池（Object Pool）模式通过预创建和回收复用对象来避免运行时的频繁创建销毁，是游戏开发中的关键性能优化手段。


using System.Collections.Generic;
using UnityEngine;

public class ObjectPool : MonoBehaviour
{
    [SerializeField] private GameObject prefab;
    [SerializeField] private int initialSize = 20;

    private readonly Queue<GameObject> pool = new();

    private void Awake()
    {
        for (int i = 0; i < initialSize; i++)
        {
            GameObject obj = Instantiate(prefab, transform);
            obj.SetActive(false);
            pool.Enqueue(obj);
        }
    }

    public GameObject Get(Vector3 position, Quaternion rotation)
    {
        GameObject obj;
        if (pool.Count > 0)
        {
            obj = pool.Dequeue();
        }
        else
        {
            obj = Instantiate(prefab, transform);
        }

        obj.transform.SetPositionAndRotation(position, rotation);
        obj.SetActive(true);
        return obj;
    }

    public void Return(GameObject obj)
    {
        obj.SetActive(false);
        pool.Enqueue(obj);
    }
}
Unity 2021+ 提供了内置的 UnityEngine.Pool 命名空间，包含 ObjectPool<T> 和 LinkedPool<T> 等通用对象池实现，支持自动扩容和最大容量限制。

小结
    

  • 预制体是 Unity 的核心资源模板系统，一处修改可传播到所有实例
    • 

  • Override 机制允许实例在保持预制体关联的前提下进行局部定制
    • 

  • Nested Prefab 实现模块化组装，Variant 实现类型派生，变体链不宜超过 3 层
    • 

  • 频繁创建销毁场景必须使用对象池，Unity 2021+ 可直接使用内置 ObjectPool
    • 

  • 预制体编辑模式提供隔离的编辑环境，修改直接作用于源预制体
    • 

  • 合理的预制体组织结构是大型项目资源管理的基础
