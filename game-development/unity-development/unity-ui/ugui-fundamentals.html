UGUI 基础

核心概念

UGUI（Unity GUI）是 Unity 内置的 UI 系统，基于 Canvas 画布和 RectTransform 矩形变换构建。与传统的 IMGUI（OnGUI）不同，UGUI 采用 GameObject 驱动的组件化设计，UI 元素本身就是场景中的对象，可以使用 Inspector 进行可视化编辑。UGUI 的渲染、布局和交互三大子系统协同工作，构成完整的 UI 解决方案。

Canvas 渲染模式
Canvas 是所有 UI 元素的根容器，定义了 UI 的渲染方式。Unity 提供三种 Canvas 渲染模式，每种模式决定了 UI 在世界空间中的表现形式。


Screen Space - Overlay 是最常用的模式，UI 直接叠加在屏幕最顶层，不受相机影响。Screen Space - Camera 将 UI 绑定到指定相机，支持 3D 物体遮挡 UI。World Space 让 UI 成为 3D 世界的一部分，适合血条、对话框等场景内 UI。

using UnityEngine;
using UnityEngine.UI;

public class WorldSpaceHealthBar : MonoBehaviour
{
    [SerializeField] private Canvas worldCanvas;
    [SerializeField] private Slider healthSlider;
    [SerializeField] private Transform target;
    [SerializeField] private Vector3 offset = new Vector3(0f, 2.5f, 0f);

    private Camera mainCamera;

    private void Awake()
    {
        mainCamera = Camera.main;
        worldCanvas.worldCamera = mainCamera;
    }

    private void LateUpdate()
    {
        transform.position = target.position + offset;
        transform.LookAt(transform.position + mainCamera.transform.forward);
    }

    public void SetHealth(float normalized)
    {
        healthSlider.value = normalized;
    }
}
多 Canvas 架构是大型项目的标准实践。将频繁更新的动态 UI（如计时器、血条）与静态 UI（如背景框架）分离到不同的 Canvas 中，可以避免整个 Canvas 的 Mesh 重建。


RectTransform 与锚点系统
RectTransform 是 UGUI 布局系统的核心，它扩展了 Transform，增加了锚点（Anchor）、轴心（Pivot）和尺寸（SizeDelta）的概念。锚点定义了 UI 元素相对于父级的定位方式，是实现多分辨率适配的关键。


锚点由 anchorMin 和 anchorMax 两个归一化向量定义（范围 0~1），Pivot 决定元素的旋转和缩放中心：


using UnityEngine;

public class DynamicPanel : MonoBehaviour
{
    [SerializeField] private RectTransform panel;

    public void SetFullScreen()
    {
        panel.anchorMin = Vector2.zero;
        panel.anchorMax = Vector2.one;
        panel.offsetMin = Vector2.zero;
        panel.offsetMax = Vector2.zero;
    }

    public void SetTopBar(float height)
    {
        panel.anchorMin = new Vector2(0f, 1f);
        panel.anchorMax = Vector2.one;
        panel.pivot = new Vector2(0.5f, 1f);
        panel.sizeDelta = new Vector2(0f, height);
        panel.anchoredPosition = Vector2.zero;
    }

    public void SetCenterFixed(float width, float height)
    {
        panel.anchorMin = new Vector2(0.5f, 0.5f);
        panel.anchorMax = new Vector2(0.5f, 0.5f);
        panel.pivot = new Vector2(0.5f, 0.5f);
        panel.sizeDelta = new Vector2(width, height);
        panel.anchoredPosition = Vector2.zero;
    }
}

交互组件与事件处理
UGUI 提供了一套完整的交互组件，包括 Button、Toggle、Slider、InputField、Dropdown 和 ScrollRect。这些组件通过 Selectable 基类统一管理选中状态和导航逻辑，支持键盘、手柄和触屏多种输入方式。


using UnityEngine;
using UnityEngine.UI;
using TMPro;

public class SettingsPanel : MonoBehaviour
{
    [Header("音频设置")]
    [SerializeField] private Slider masterVolumeSlider;
    [SerializeField] private Slider musicVolumeSlider;
    [SerializeField] private Toggle muteToggle;

    [Header("画面设置")]
    [SerializeField] private TMP_Dropdown resolutionDropdown;
    [SerializeField] private Toggle fullscreenToggle;

    [Header("显示")]
    [SerializeField] private TMP_Text volumeValueText;

    private void OnEnable()
    {
        masterVolumeSlider.onValueChanged.AddListener(OnMasterVolumeChanged);
        musicVolumeSlider.onValueChanged.AddListener(OnMusicVolumeChanged);
        muteToggle.onValueChanged.AddListener(OnMuteChanged);
        resolutionDropdown.onValueChanged.AddListener(OnResolutionChanged);
        fullscreenToggle.onValueChanged.AddListener(OnFullscreenChanged);
    }

    private void OnDisable()
    {
        masterVolumeSlider.onValueChanged.RemoveListener(OnMasterVolumeChanged);
        musicVolumeSlider.onValueChanged.RemoveListener(OnMusicVolumeChanged);
        muteToggle.onValueChanged.RemoveListener(OnMuteChanged);
        resolutionDropdown.onValueChanged.RemoveListener(OnResolutionChanged);
        fullscreenToggle.onValueChanged.RemoveListener(OnFullscreenChanged);
    }

    private void OnMasterVolumeChanged(float value)
    {
        AudioListener.volume = value;
        volumeValueText.text = $"{Mathf.RoundToInt(value * 100)}%";
    }

    private void OnMusicVolumeChanged(float value)
    {
        Debug.Log($"音乐音量: {value}");
    }

    private void OnMuteChanged(bool isMuted)
    {
        AudioListener.pause = isMuted;
    }

    private void OnResolutionChanged(int index)
    {
        var res = Screen.resolutions[index];
        Screen.SetResolution(res.width, res.height, Screen.fullScreen);
    }

    private void OnFullscreenChanged(bool isFullscreen)
    {
        Screen.fullScreen = isFullscreen;
    }
}
自定义交互行为可以通过实现 IPointerClickHandler、IDragHandler 等接口来扩展。这些接口属于 EventSystem 的事件通道，比直接检测 Input 更可靠：


using UnityEngine;
using UnityEngine.EventSystems;

public class DraggableItem : MonoBehaviour, IBeginDragHandler, IDragHandler, IEndDragHandler
{
    private RectTransform rectTransform;
    private CanvasGroup canvasGroup;
    private Vector2 originalPosition;

    private void Awake()
    {
        rectTransform = GetComponent<RectTransform>();
        canvasGroup = GetComponent<CanvasGroup>();
    }

    public void OnBeginDrag(PointerEventData eventData)
    {
        originalPosition = rectTransform.anchoredPosition;
        canvasGroup.blocksRaycasts = false;
        canvasGroup.alpha = 0.6f;
    }

    public void OnDrag(PointerEventData eventData)
    {
        rectTransform.anchoredPosition += eventData.delta;
    }

    public void OnEndDrag(PointerEventData eventData)
    {
        canvasGroup.blocksRaycasts = true;
        canvasGroup.alpha = 1f;
    }
}
布局组件与自动排列
UGUI 的 Layout Group 组件实现了自动布局功能，子元素按照指定规则自动排列，省去手动计算位置的繁琐工作。三种核心布局组件覆盖了绝大多数场景。






布局组件

VerticalLayoutGroup
垂直排列

GridLayoutGroup
网格排列
背包、技能栏





using UnityEngine;
using UnityEngine.UI;

public class InventoryGrid : MonoBehaviour
{
    [SerializeField] private GridLayoutGroup gridLayout;
    [SerializeField] private GameObject slotPrefab;
    [SerializeField] private int slotCount = 24;
    [SerializeField] private int columns = 6;

    private void Start()
    {
        float containerWidth = GetComponent<RectTransform>().rect.width;
        float spacing = gridLayout.spacing.x;
        float padding = gridLayout.padding.left + gridLayout.padding.right;
        float cellWidth = (containerWidth - padding - spacing * (columns - 1)) / columns;

        gridLayout.cellSize = new Vector2(cellWidth, cellWidth);
        gridLayout.constraintCount = columns;
        gridLayout.constraint = GridLayoutGroup.Constraint.FixedColumnCount;

        for (int i = 0; i < slotCount; i++)
        {
            Instantiate(slotPrefab, transform);
        }
    }
}
ContentSizeFitter 组件让元素根据内容自动调整尺寸，常与 LayoutGroup 配合实现聊天气泡、动态列表等自适应内容的 UI：


using UnityEngine;
using UnityEngine.UI;
using TMPro;

public class ChatBubble : MonoBehaviour
{
    [SerializeField] private TMP_Text messageText;
    [SerializeField] private RectTransform bubbleRect;
    [SerializeField] private float maxWidth = 400f;
    [SerializeField] private float padding = 20f;

    public void SetMessage(string message)
    {
        messageText.text = message;

        float preferredWidth = messageText.preferredWidth + padding * 2f;
        float width = Mathf.Min(preferredWidth, maxWidth);
        bubbleRect.sizeDelta = new Vector2(width, bubbleRect.sizeDelta.y);

        LayoutRebuilder.ForceRebuildLayoutImmediate(bubbleRect);
    }
}
小结
    

  • UGUI 基于 Canvas + RectTransform 构建，采用 GameObject 驱动的组件化设计
    • 

  • 三种 Canvas 渲染模式适配不同场景，多 Canvas 架构是大型项目的性能优化基础
    • 

  • RectTransform 的锚点系统是多分辨率适配的核心，配合 CanvasScaler 实现自动缩放
    • 

  • 交互组件通过 Selectable 基类统一管理，IPointerHandler 接口支持自定义交互行为
    • 

  • Layout Group 和 ContentSizeFitter 实现自动排列和内容自适应布局
    • 

  • 事件监听应在 OnEnable 中注册、OnDisable 中注销，遵循对称管理原则
    •
