数论

数论是关于整数性质的研究——素数的分布、同余方程的求解、丢番图方程的可解性。它被高斯誉为"数学的女王"，不仅因为它的问题极其优美且难以攻克，更因为它的方法深刻地渗透到了代数、分析、几何等几乎所有数学分支中。

知识要点

整除与素数：整数 aaa 整除 bbb（记作 a∣ba \mid ba∣b）意味着存在整数 kkk 使得 b=kab = kab=ka。算术基本定理断言每个大于 111 的整数都可以唯一地（不计顺序）分解为素数之积：

n=p1a1p2a2⋯prarn = p_1^{a_1} p_2^{a_2} \cdots p_r^{a_r}n=p1a1​​p2a2​​⋯prar​​

素数的个数是无穷的——Euclid 的证明是数学中最简洁的论证之一：若素数只有有限个 p1,…,pkp_1, \ldots, p_kp1​,…,pk​，则 N=p1p2⋯pk+1N = p_1 p_2 \cdots p_k + 1N=p1​p2​⋯pk​+1 不能被任何 pip_ipi​ 整除，矛盾。

同余与模运算：a≡b(modm)a \equiv b \pmod{m}a≡b(modm) 意味着 m∣(a−b)m \mid (a - b)m∣(a−b)。模运算将无穷的整数问题压缩到有限集合上，是数论计算的核心工具。

Euler 函数：φ(n)\varphi(n)φ(n) 表示 111 到 nnn 中与 nnn 互素的整数个数。Euler 定理给出：若 gcd⁡(a,n)=1\gcd(a, n) = 1gcd(a,n)=1，则

aφ(n)≡1(modn)a^{\varphi(n)} \equiv 1 \pmod{n}aφ(n)≡1(modn)

Fermat 小定理是其特例：若 ppp 为素数且 p∤ap \nmid ap∤a，则 ap−1≡1(modp)a^{p-1} \equiv 1 \pmod{p}ap−1≡1(modp)。

素数分布与素数定理

素数在自然数中的分布是数论的核心问题。设 π(x)\pi(x)π(x) 表示不超过 xxx 的素数个数，素数定理给出了 π(x)\pi(x)π(x) 的渐近行为：

π(x)∼xln⁡x(x→∞)\pi(x) \sim \frac{x}{\ln x} \quad (x \to \infty)π(x)∼lnxx​(x→∞)

更精确的估计涉及对数积分 Li(x)=∫2xdtln⁡t\text{Li}(x) = \int_2^x \frac{dt}{\ln t}Li(x)=∫2x​lntdt​，素数定理等价于 π(x)∼Li(x)\pi(x) \sim \text{Li}(x)π(x)∼Li(x)。

素数定理的经典证明依赖于复分析——Riemann ζ\zetaζ 函数 ζ(s)=∑n=1∞n−s\zeta(s) = \sum_{n=1}^{\infty} n^{-s}ζ(s)=∑n=1∞​n−s 在临界线 Re(s)=1\text{Re}(s) = 1Re(s)=1 上没有零点。Riemann 假设——ζ\zetaζ 函数的非平凡零点全部位于 Re(s)=12\text{Re}(s) = \frac{1}{2}Re(s)=21​ 上——是数学中最重要的未解决问题之一，它将给出 π(x)\pi(x)π(x) 与 Li(x)\text{Li}(x)Li(x) 之间误差项的最优估计。

代数数论初步

代数数论将整数的性质推广到代数整数——代数数域中的"整数"。例如在 Q(−5)\mathbb{Q}(\sqrt{-5})Q(−5​) 中，代数整数环是 Z[−5]\mathbb{Z}[\sqrt{-5}]Z[−5​]。

在这个环中，唯一因子分解失败（如 6=2×3=(1+−5)(1−−5)6 = 2 \times 3 = (1+\sqrt{-5})(1-\sqrt{-5})6=2×3=(1+−5​)(1−−5​)）。Dedekind 和 Kummer 发现，虽然元素的唯一分解失败了，但理想的唯一分解仍然成立——每个非零理想都可以唯一地分解为素理想之积。这一发现催生了代数数论和交换代数两大分支。

类数h(K)h(K)h(K) 衡量了数域 KKK 的整数环偏离唯一因子分解的程度：h(K)=1h(K) = 1h(K)=1 当且仅当整数环是唯一分解整环。计算类数和理解类群的结构是代数数论的核心问题。

小结
数论的魅力在于"问题简单、答案深刻"。从 Euclid 的素数无穷性到 Riemann 假设，从 Fermat 大定理到 Langlands 纲领，数论的发展始终在推动数学的前进。初等方法（同余、二次互反律）、解析方法（ζ\zetaζ 函数、LLL-函数）和代数方法（理想论、类域论）三条路径在现代数论中深度交织。掌握数论的基本工具，就是打开了通向现代数学最深层结构的大门。
