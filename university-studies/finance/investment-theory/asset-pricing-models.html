02 经济学 (Economics)金融学 简介投资学 简介资产定价模型

资产定价模型

一项资产的合理预期回报应该是多少？这个问题是金融学的核心。资产定价模型试图建立风险与回报之间的精确关系——不是所有风险都应获得补偿，只有不可分散的系统性风险才有对应的风险溢价。

知识要点

资本资产定价模型（CAPM）是最经典的资产定价模型。在投资组合理论的基础上，夏普（1964）、林特纳（1965）和莫辛（1966）独立推导出：

E(ri)=rf+βi[E(rM)−rf]E(r_i) = r_f + \beta_i [E(r_M) - r_f]E(ri​)=rf​+βi​[E(rM​)−rf​]

其中 βi=Cov(ri,rM)Var(rM)\beta_i = \frac{\text{Cov}(r_i, r_M)}{\text{Var}(r_M)}βi​=Var(rM​)Cov(ri​,rM​)​ 衡量资产 iii 对市场系统性风险的敏感度。

CAPM的含义是：资产的预期超额回报与其 β\betaβ 成正比。β=1\beta = 1β=1 的资产与市场同步波动，β>1\beta > 1β>1 的资产放大市场波动，β<1\beta < 1β<1 的资产缓冲市场波动。

证券市场线（SML）在 (β,E(r))(\beta, E(r))(β,E(r)) 空间中是一条过 (0,rf)(0, r_f)(0,rf​) 和 (1,E(rM))(1, E(r_M))(1,E(rM​)) 的直线。位于SML上方的资产被低估（回报高于风险补偿），位于下方的被高估。

详细讲解

CAPM的推导逻辑

CAPM建立在以下假设之上：所有投资者持有均值-方差有效的组合，市场出清，投资者对收益分布有一致预期，可以无风险利率自由借贷。

在均衡状态下，每个投资者持有市场组合的一部分。市场组合是所有风险资产按市值加权的组合。对于市场组合中的任何资产 iii，其边际风险贡献必须与边际收益贡献成比例，否则投资者会调整持仓。这一均衡条件直接导出CAPM公式。

从数学上看，市场组合位于有效前沿上且是切点组合，因此对于任意资产 iii：

E(ri)−rf=Cov(ri,rM)σM2[E(rM)−rf]E(r_i) - r_f = \frac{\text{Cov}(r_i, r_M)}{\sigma_M^2} [E(r_M) - r_f]E(ri​)−rf​=σM2​Cov(ri​,rM​)​[E(rM​)−rf​]

Beta的估计与解读

实践中 β\betaβ 通过回归估计：

rit−rft=αi+βi(rMt−rft)+εitr_{it} - r_{ft} = \alpha_i + \beta_i (r_{Mt} - r_{ft}) + \varepsilon_{it}rit​−rft​=αi​+βi​(rMt​−rft​)+εit​

如果CAPM成立，αi\alpha_iαi​（詹森阿尔法）应为零。α>0\alpha > 0α>0 表示资产在风险调整后获得了超额回报。

行业 β\betaβ 的典型值：

行业 典型 β\betaβ 原因
公用事业 0.5-0.7 需求稳定，受经济周期影响小
消费必需品 0.7-0.9 需求刚性
银行 1.0-1.3 杠杆放大系统性风险
科技 1.2-1.8 高增长但不确定性大
生物医药 0.8-1.5 取决于产品管线成熟度

β\betaβ 也可以通过基本面估算。无杠杆 β\betaβ（资产Beta）与有杠杆 β\betaβ（权益Beta）的关系为：

βE=βA[1+(1−Tc)DE]\beta_E = \beta_A \left[1 + (1-T_c)\frac{D}{E}\right]βE​=βA​[1+(1−Tc​)ED​]

CAPM的实证检验

CAPM的实证表现令人失望。法玛和麦克白斯（1973）的截面检验发现：β\betaβ 与平均回报之间的关系比理论预测的平坦得多，低 β\betaβ 股票的实际回报高于CAPM预测，高 β\betaβ 股票的实际回报低于CAPM预测。

罗尔（1977）更进一步指出了"罗尔批评"：CAPM实际上是不可检验的，因为真实的市场组合（包括所有资产——股票、债券、房地产、人力资本等）永远无法观察到。我们检验的只是某个股票指数（如标普500）是否处于均值-方差有效前沿上。

Fama-French三因子模型

法玛和弗伦奇（1993）在CAPM基础上增加了两个因子：

E(ri)−rf=βiMKT[E(rM)−rf]+βiSMBE(SMB)+βiHMLE(HML)E(r_i) - r_f = \beta_i^{MKT} [E(r_M) - r_f] + \beta_i^{SMB} E(SMB) + \beta_i^{HML} E(HML)E(ri​)−rf​=βiMKT​[E(rM​)−rf​]+βiSMB​E(SMB)+βiHML​E(HML)

SMBSMBSMB（Small Minus Big）：小市值组合与大市值组合的收益差，捕捉规模效应。

HMLHMLHML（High Minus Low）：高账面市值比组合与低账面市值比组合的收益差，捕捉价值效应。

三因子模型大幅提高了截面回报差异的解释力，从CAPM的约70%提升到约90%以上。

进一步的因子扩展

卡哈特四因子模型（1997）加入了动量因子 UMDUMDUMD（Up Minus Down）：过去12个月涨幅最大的股票组合减去跌幅最大的股票组合的收益。

Fama-French五因子模型（2015）进一步加入了盈利因子 RMWRMWRMW（Robust Minus Weak）和投资因子 CMACMACMA（Conservative Minus Aggressive）。

因子模型的激增引发了"因子动物园"的批评——学术文献中已发现超过400个据称能预测股票回报的因子。哈维、刘和朱（2016）认为其中大多数是数据挖掘的产物，经过多重检验校正后不再显著。

套利定价理论

罗斯（1976）提出的套利定价理论（APT）是CAPM的替代框架。APT不依赖均值-方差效用函数和市场组合假设，仅要求不存在套利机会。

E(ri)=rf+∑k=1KβikλkE(r_i) = r_f + \sum_{k=1}^{K} \beta_{ik} \lambda_kE(ri​)=rf​+k=1∑K​βik​λk​

其中 λk\lambda_kλk​ 是第 kkk 个系统性因子的风险价格。APT没有指定哪些因子应该进入模型，这既是灵活性也是局限性。

常见的宏观因子包括：GDP增长率意外、通胀率意外、信用利差变动、期限利差变动和石油价格变动。

练习与思考

  1. 某股票 β=1.5\beta = 1.5β=1.5，无风险利率3%，市场预期回报10%。根据CAPM，该股票的预期回报是多少？如果该股票实际预期回报为15%，它是被高估还是低估？

  2. 一家公司的权益 β=1.2\beta = 1.2β=1.2，负债率（D/E）= 0.5，税率25%。如果公司将负债率提高到1.0，新的权益 β\betaβ 是多少？WACC会如何变化？

  3. 价值投资策略（买入高B/M股票）历史上获得了超额回报。从三因子模型的角度，这是"风险溢价"还是"市场异象"？两种解释各有什么证据？

  4. 如果市场中存在大量使用CAPM的投资者，他们的行为如何影响CAPM的有效性？这是否形成了某种自我实现预言？

拓展阅读

夏普因CAPM获1990年诺贝尔经济学奖（与马科维茨、米勒共同获奖）。法玛因有效市场假说和因子模型获2013年诺贝尔经济学奖（与席勒、汉森共同获奖——有趣的是，法玛和席勒对市场效率持截然相反的观点）。

约翰·科克伦的《资产定价》是该领域最权威的研究生教材，将所有定价模型统一在随机折现因子框架下。安德鲁·昂的《金融工程学》则从实践角度介绍因子投资。

小结

资产定价模型从CAPM的单因子框架发展到多因子模型，核心逻辑始终是：只有系统性风险才获得补偿。CAPM虽然在实证上存在不足，但其概念框架（Beta、风险溢价、阿尔法）已成为金融行业的通用语言。多因子模型提高了解释力，但也引发了"数据挖掘vs真实风险因子"的持续争论。
