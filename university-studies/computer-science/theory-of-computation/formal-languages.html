大学计算机科学与技术 — 形式语言

知识要点

形式语言理论为描述和分析语言的结构提供了严格的数学框架。这里的"语言"不仅指编程语言或自然语言，而是泛指任何符号串的集合——从正则表达式描述的文本模式到编程语言的语法规范，再到 DNA 序列的模式特征，都可以纳入形式语言的分析范畴。形式语言理论与自动机理论紧密耦合：每一类形式语言恰好对应一类自动机，形成了 Noam Chomsky 在 1956 年提出的经典Chomsky 层次。

形式语言理论的实际意义集中在编译器构造领域：词法分析基于正则语言，语法分析基于上下文无关语言，类型检查涉及更高阶的语言约束。理解形式语言为设计新的编程语言和领域特定语言（DSL）提供了理论工具。

Chomsky 层次 文法类型 产生式限制 对应自动机 封闭运算
Type 3 正则文法 A→aBA \to aBA→aB 或 A→aA \to aA→a 有限自动机 并、交、补、连接、Kleene 星
Type 2 上下文无关文法 A→αA \to \alphaA→α 下推自动机 并、连接、Kleene 星（不封闭于交、补）
Type 1 上下文相关文法 αAβ→αγβ\alpha A \beta \to \alpha \gamma \betaαAβ→αγβ 线性有界自动机 并、交、补、连接、Kleene 星
Type 0 无限制文法 α→β\alpha \to \betaα→β 图灵机 并、连接、Kleene 星

详细讲解

文法的形式定义

形式文法是一个四元组 G=(V,Σ,R,S)G = (V, \Sigma, R, S)G=(V,Σ,R,S)：

  • VVV：变量（非终结符）的有限集
  • Σ\SigmaΣ：终结符的有限集（V∩Σ=∅V \cap \Sigma = \emptysetV∩Σ=∅）
  • RRR：产生式规则的有限集，形如 α→β\alpha \to \betaα→β，其中 α∈(V∪Σ)∗V(V∪Σ)∗\alpha \in (V \cup \Sigma)^* V (V \cup \Sigma)^*α∈(V∪Σ)∗V(V∪Σ)∗，β∈(V∪Σ)∗\beta \in (V \cup \Sigma)^*β∈(V∪Σ)∗
  • S∈VS \in VS∈V：起始变量

文法 GGG 生成的语言 L(G)L(G)L(G) 是所有可以从 SSS 通过产生式推导出的终结符串的集合：

L(G)={w∈Σ∗∣S⇒∗w}L(G) = \{w \in \Sigma^* \mid S \Rightarrow^* w\}L(G)={w∈Σ∗∣S⇒∗w}

其中 ⇒∗\Rightarrow^*⇒∗ 表示零步或多步推导。

正则文法与正则语言

正则文法（Type 3）的产生式限制为两种形式之一：

  • 右线性：A→wBA \to wBA→wB 或 A→wA \to wA→w（w∈Σ∗w \in \Sigma^*w∈Σ∗，A,B∈VA, B \in VA,B∈V）
  • 左线性：A→BwA \to BwA→Bw 或 A→wA \to wA→w

右线性文法直接对应 NFA 的构造：每个变量对应一个状态，每条产生式对应一组转移。例如文法：

S→aS∣bAS \to aS \mid bAS→aS∣bA
A→aA∣ϵA \to aA \mid \epsilonA→aA∣ϵ

生成语言 {amban∣m≥0,n≥0}\{a^m b a^n \mid m \geq 0, n \geq 0\}{amban∣m≥0,n≥0}：任意数量的 aaa 后接一个 bbb 再接任意数量的 aaa。

正则语言在所有布尔运算下封闭。特别地，正则语言对补运算封闭：给定识别 LLL 的 DFA，将接受状态和非接受状态互换，得到识别 L‾=Σ∗∖L\overline{L} = \Sigma^* \setminus LL=Σ∗∖L 的 DFA。这一性质在上下文无关语言中不成立。

Myhill-Nerode 定理给出了正则语言的另一种等价刻画：语言 LLL 是正则的当且仅当等价关系 ≡L\equiv_L≡L​ 的等价类数量有限。其中 x≡Lyx \equiv_L yx≡L​y 定义为：∀z∈Σ∗,xz∈L  ⟺  yz∈L\forall z \in \Sigma^*, xz \in L \iff yz \in L∀z∈Σ∗,xz∈L⟺yz∈L。等价类的数量恰好等于识别 LLL 的最小 DFA 的状态数。

上下文无关文法与解析

上下文无关文法（CFG, Type 2）的产生式形式为 A→αA \to \alphaA→α，其中 AAA 是单个变量，α\alphaα 是变量和终结符的任意串。"上下文无关"意味着变量 AAA 可以在任何上下文中被替换，不受周围符号的限制。

CFG 是编程语言语法规范的标准工具。例如 JSON 的简化文法：

Value→String∣Number∣Object∣Array∣true∣false∣null\text{Value} \to \text{String} \mid \text{Number} \mid \text{Object} \mid \text{Array} \mid \texttt{true} \mid \texttt{false} \mid \texttt{null}Value→String∣Number∣Object∣Array∣true∣false∣null
Object→{Members}∣{}\text{Object} \to \texttt{\{} \text{Members} \texttt{\}} \mid \texttt{\{}\texttt{\}}Object→{Members}∣{}
Array→[Elements]∣[]\text{Array} \to \texttt{[} \text{Elements} \texttt{]} \mid \texttt{[}\texttt{]}Array→[Elements]∣[]

Chomsky 范式（CNF）要求每条产生式形如 A→BCA \to BCA→BC 或 A→aA \to aA→a（以及 S→ϵS \to \epsilonS→ϵ 如果空串在语言中）。任何 CFG 都可以转化为等价的 CNF 文法。CNF 的重要性在于它使 CYK 算法（Cocke-Younger-Kasami）成为可能——一种基于动态规划的通用解析算法，时间复杂度 O(n3∣G∣)O(n^3 |G|)O(n3∣G∣)，其中 nnn 是输入长度，∣G∣|G|∣G∣ 是文法大小。

CYK 算法的核心思想：维护一个表 T[i][j]T[i][j]T[i][j]，记录能够生成子串 wi⋯wjw_i \cdots w_jwi​⋯wj​ 的所有变量。状态转移为：

A∈T[i][j]  ⟺  ∃k,i≤k<j,B∈T[i][k]∧C∈T[k+1][j]∧(A→BC)∈RA \in T[i][j] \iff \exists k, i \leq k < j, B \in T[i][k] \land C \in T[k+1][j] \land (A \to BC) \in RA∈T[i][j]⟺∃k,i≤k<j,B∈T[i][k]∧C∈T[k+1][j]∧(A→BC)∈R

二义性是 CFG 的重要问题。如果一个字符串有两棵不同的解析树（对应两种不同的最左推导），则文法是二义的。经典的悬空 else 问题就是二义性的体现。某些上下文无关语言是固有二义的——不存在无二义文法能生成该语言。例如 {aibjck∣i=j 或 j=k}\{a^i b^j c^k \mid i = j \text{ 或 } j = k\}{aibjck∣i=j 或 j=k} 是固有二义的。

实际解析技术

工业级编译器使用的解析技术比通用 CYK 更高效：

LL 解析（自顶向下）：从起始符号出发，向左扫描输入，构建最左推导。LL(kkk) 解析器使用 kkk 个前瞻符号决定采用哪条产生式。手写递归下降解析器本质上是 LL(1) 解析器。LL(1) 的限制是不能处理左递归文法——例如 E→E+TE \to E + TE→E+T 需要改写为 E→TE′E \to T E'E→TE′, E′→+TE′∣ϵE' \to + T E' \mid \epsilonE′→+TE′∣ϵ。

LR 解析（自底向上）：从输入符号出发，逐步归约（reduce）到起始符号，构建最右推导的逆序。LR(kkk) 比 LL(kkk) 更强大，能处理更大类的文法。LALR(1)（Lookahead LR with 1 symbol）是实践中最常用的 LR 变体，工具如 yacc/bison 生成 LALR(1) 解析表。

PEG（Parsing Expression Grammar）是近年来的替代方案，与 CFG 的关键区别是有序选择（/）而非无序选择（|）。PEG 不存在二义性，且可以用 Packrat 解析器在 O(n)O(n)O(n) 时间内解析（代价是 O(n)O(n)O(n) 的空间用于记忆化）。

上下文相关语言与 Chomsky 层次

上下文相关文法（CSG, Type 1）的产生式形式为 αAβ→αγβ\alpha A \beta \to \alpha \gamma \betaαAβ→αγβ（∣γ∣≥1|\gamma| \geq 1∣γ∣≥1），即 AAA 只有在上下文 α⋯β\alpha \cdots \betaα⋯β 中才能被替换为 γ\gammaγ。CSG 对应线性有界自动机（LBA），即磁带长度受输入长度线性限制的图灵机。

上下文相关语言的典型例子是 {anbncn∣n≥1}\{a^n b^n c^n \mid n \geq 1\}{anbncn∣n≥1}，它既不是正则语言也不是上下文无关语言（可用 CFL 的泵引理证明），但可以用 CSG 生成。

Chomsky 层次的严格包含关系：

正则⊊上下文无关⊊上下文相关⊊递归可枚举\text{正则} \subsetneq \text{上下文无关} \subsetneq \text{上下文相关} \subsetneq \text{递归可枚举}正则⊊上下文无关⊊上下文相关⊊递归可枚举

每一层严格包含的证明都需要找到属于更高层但不属于更低层的语言，并用对应的泵引理或对角化论证排除。

练习与思考

  1. 给定文法 GGG：S→aSb∣SS∣ϵS \to aSb \mid SS \mid \epsilonS→aSb∣SS∣ϵ，分析 GGG 生成的语言是什么。证明它等价于所有匹配括号串的集合（将 aaa 视为左括号，bbb 视为右括号）。

  2. 将以下文法转化为 Chomsky 范式：S→ASB∣ϵS \to ASB \mid \epsilonS→ASB∣ϵ，A→aAS∣aA \to aAS \mid aA→aAS∣a，B→SbS∣A∣bbB \to SbS \mid A \mid bbB→SbS∣A∣bb。展示每一步的转化过程。

  3. 使用 CFL 泵引理证明 L={anbncn∣n≥0}L = \{a^n b^n c^n \mid n \geq 0\}L={anbncn∣n≥0} 不是上下文无关语言。提示：CFL 泵引理中字符串被分解为 uvxyzuvxyzuvxyz，满足 ∣vy∣≥1|vy| \geq 1∣vy∣≥1，∣vxy∣≤p|vxy| \leq p∣vxy∣≤p。

  4. 构造一个 LL(1) 文法来描述简单的赋值语句语言：id = expr ;，其中 expr 支持加法和乘法且乘法优先级高于加法。写出消除左递归后的文法，并构造 FIRST 和 FOLLOW 集。

  5. 比较 PEG 的有序选择 / 和 CFG 的无序选择 |。给出一个例子说明两者对同一输入可能产生不同的解析结果。讨论 PEG 无二义性保证的优缺点。

拓展阅读

  • 《Introduction to the Theory of Computation》（Sipser）：第 2 章和第 4 章系统讲解 CFG、PDA 和 CFL 的封闭性与判定性质。
  • 《Compilers: Principles, Techniques, and Tools》（龙书，Aho, Lam, Sethi, Ullman）：第 2-4 章深入讲解词法分析和语法分析的工程实现，是编译器课程的权威教材。
  • 《Formal Languages and Automata Theory》（Peter Linz）：偏重于形式语言的数学理论，证明详尽。
  • Bryan Ford 的 PEG 论文：Parsing Expression Grammars: A Recognition-Based Syntactic Foundation（POPL 2004），PEG 理论的奠基之作。

小结

形式语言理论通过 Chomsky 层次将语言的复杂度组织为四个严格递增的层次，每层对应特定的文法限制和自动机能力。正则语言支撑了词法分析和文本匹配，上下文无关语言是编程语言语法的理论基础，上下文相关语言和递归可枚举语言则刻画了更复杂的计算现象。CFG 的解析技术——从通用的 CYK 到高效的 LL/LR/PEG——直接驱动了编译器前端的工程实践。理解形式语言不仅是掌握编译原理的前提，更是培养精确的形式化思维能力的重要训练。
