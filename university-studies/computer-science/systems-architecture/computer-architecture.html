大学计算机科学与技术 — 计算机体系结构

知识要点

计算机体系结构研究的是如何设计和组织计算机硬件系统，使其在给定的技术约束下实现最佳的性能、功耗和成本平衡。从冯·诺依曼在 1945 年提出存储程序概念至今，体系结构经历了从简单的单周期处理器到超标量、乱序执行和多核并行的深刻演进。这门学科是软件与硬件的交汇点——理解体系结构能让程序员写出缓存友好的代码，也能让系统设计者在硬件约束下做出合理的架构决策。

体系结构的核心主题围绕指令集架构（ISA）、流水线、存储层次和并行计算四大支柱展开。

层次 关注点 关键指标
指令集架构（ISA） 软硬件接口定义 指令格式、寻址模式、寄存器数量
微架构 ISA 的硬件实现 CPI、时钟频率、流水线深度
存储系统 数据访问效率 命中率、访问延迟、带宽
并行架构 多处理单元协作 加速比、可扩展性、一致性

详细讲解

指令集架构：CISC vs RISC

ISA 是程序员可见的硬件接口，定义了指令格式、操作类型、寄存器组和寻址模式。两种主要设计哲学：

CISC（复杂指令集，如 x86）：提供大量功能丰富的指令，单条指令可以完成复杂操作（如内存到内存的加法）。指令长度可变，解码复杂。设计理念是缩小语义鸿沟——让机器指令尽可能接近高级语言语句。

RISC（精简指令集，如 ARM、RISC-V）：指令数量少、格式固定、操作简单。只有 Load/Store 指令访问内存，算术运算仅操作寄存器。设计理念是简化硬件实现以提高时钟频率和流水线效率。

两种哲学的量化比较（执行时间公式）：

CPU Time=IC×CPI×Tclk\text{CPU Time} = \text{IC} \times \text{CPI} \times T_{\text{clk}}CPU Time=IC×CPI×Tclk​

其中 IC\text{IC}IC 是指令条数，CPI\text{CPI}CPI 是每条指令的平均时钟周期数，TclkT_{\text{clk}}Tclk​ 是时钟周期。CISC 的 IC 较低但 CPI 较高，RISC 的 IC 较高但 CPI 接近 1。现代 x86 处理器内部将 CISC 指令解码为类 RISC 的微操作（micro-ops），融合了两种哲学的优点。

RISC-V 是近年来最受关注的开源 ISA，模块化设计允许根据应用场景选择指令扩展（M-乘除法、A-原子操作、F/D-浮点等），从嵌入式微控制器到高性能服务器均可适配。

流水线与指令级并行

流水线（Pipeline）是提高处理器吞吐量的核心技术。经典五级流水线将指令执行分为：取指（IF）→ 译码（ID）→ 执行（EX）→ 访存（MEM）→ 写回（WB）。理想情况下，流水线的吞吐量提升为：

Speedupideal=流水线级数=k\text{Speedup}_{\text{ideal}} = \text{流水线级数} = kSpeedupideal​=流水线级数=k

但三类冒险（Hazard）会破坏流水线的理想吞吐：

冒险类型 原因 解决方案
数据冒险 指令依赖前序指令的结果 转发（Forwarding）、流水线停顿
控制冒险 分支指令导致取指方向不确定 分支预测、延迟槽
结构冒险 多条指令争用同一硬件资源 资源复制、分时共享

分支预测对现代处理器性能至关重要。两位饱和计数器的预测正确率约 85%85\%85%，而现代处理器使用感知器预测器或 TAGE 预测器，正确率可达 97%97\%97% 以上。预测失败的代价是冲刷流水线，损失约 10-2010\text{-}2010-20 个周期。

超标量处理器每个周期发射多条指令（如 4-wide），结合乱序执行（Out-of-Order Execution）和寄存器重命名，动态挖掘指令级并行性（ILP）。Tomasulo 算法通过保留站（Reservation Station）实现动态调度，消除了假依赖（WAR 和 WAW 冒险）。

缓存的核心参数是关联度和替换策略。对于一个容量为 CCC、块大小为 BBB、关联度为 NNN 的缓存，组数 S=C/(B×N)S = C / (B \times N)S=C/(B×N)。地址映射：

组索引=⌊地址B⌋ mod S\text{组索引} = \left\lfloor \frac{\text{地址}}{B} \right\rfloor \bmod S组索引=⌊B地址​⌋modS

缓存一致性是多核处理器的关键挑战。MESI 协议定义了缓存行的四种状态（Modified、Exclusive、Shared、Invalid），通过总线监听或目录协议保证所有核心看到一致的内存视图。

平均内存访问时间（AMAT）的计算：

AMAT=Thit+Miss Rate×Tmiss penalty\text{AMAT} = T_{\text{hit}} + \text{Miss Rate} \times T_{\text{miss penalty}}AMAT=Thit​+Miss Rate×Tmiss penalty​

对于多级缓存：AMAT=TL1+rL1×(TL2+rL2×Tmem)\text{AMAT} = T_{L1} + r_{L1} \times (T_{L2} + r_{L2} \times T_{\text{mem}})AMAT=TL1​+rL1​×(TL2​+rL2​×Tmem​)，其中 rLir_{Li}rLi​ 是第 iii 级缓存的缺失率。

并行架构

Flynn 分类将计算机架构按指令流和数据流维度划分：

分类 指令流 数据流 示例
SISD 单 单 传统单核 CPU
SIMD 单 多 GPU、AVX 向量指令
MISD 多 单 罕见（容错系统）
MIMD 多 多 多核 CPU、集群

Amdahl 定律量化了并行化的理论上限：

Speedup=1(1−f)+f/p\text{Speedup} = \frac{1}{(1-f) + f/p}Speedup=(1−f)+f/p1​

其中 fff 是可并行化的比例，ppp 是处理器数量。即使 p→∞p \to \inftyp→∞，加速比上限为 1/(1−f)1/(1-f)1/(1−f)。例如程序有 5%5\%5% 串行部分，理论最大加速比仅为 20×20\times20×。

GPU 架构采用 SIMT（单指令多线程）模型，数千个轻量级线程分组为 Warp（NVIDIA）或 Wavefront（AMD），同一 Warp 中的线程执行相同指令。这使得 GPU 在矩阵运算、深度学习训练等数据并行场景下吞吐量远超 CPU。

练习与思考

  1. 一个程序在单核处理器上运行 100 秒，其中 80 秒可以并行化。根据 Amdahl 定律，使用 8 核处理器后的加速比和执行时间分别是多少？如果要达到 10×10\times10× 加速比，需要多少个核？

  2. 一个直接映射缓存（1-way）有 256 个缓存行，每行 64 字节。地址长度 32 位。请计算标签（Tag）、组索引（Index）和块内偏移（Offset）各占多少位。如果访问地址 0x12345678\texttt{0x12345678}0x12345678，映射到哪一组？

  3. 解释为什么数组按行遍历比按列遍历更快（假设 C 语言的行优先存储）。用缓存行和空间局部性的概念定量分析两者的缓存命中率差异。

  4. 一个 5 级流水线处理器执行一段包含 20%20\%20% 分支指令的程序。如果分支预测准确率为 90%90\%90%，每次预测失败导致 3 个周期的气泡。计算实际 CPI（忽略其他冒险）。

  5. 比较 CPU 和 GPU 在执行矩阵乘法 C=A×BC = A \times BC=A×B（n×nn \times nn×n 矩阵）时的性能特征差异。为什么 GPU 更适合这类计算？从线程模型、内存带宽和指令执行模式三个角度分析。

拓展阅读

  • 《Computer Organization and Design: RISC-V Edition》（Patterson & Hennessy）：体系结构入门经典，以 RISC-V 为载体讲解处理器设计、流水线和存储层次。
  • 《Computer Architecture: A Quantitative Approach》（Hennessy & Patterson）：进阶版，深入超标量、乱序执行和并行架构的量化分析方法。
  • Nand2Tetris 课程（nand2tetris.org）：从与非门开始，逐步构建完整的计算机系统——包括处理器、汇编器和编译器。极佳的动手实践体验。
  • RISC-V 官方规范（riscv.org）：开源 ISA 规范文档，适合深入了解现代指令集设计。

小结

计算机体系结构连接了软件的抽象世界与硬件的物理实现。ISA 定义了软硬件的契约，流水线和超标量技术挖掘指令级并行性以提高单线程性能，存储层次通过缓存机制弥合处理器与内存的速度差距，多核和 GPU 并行架构则应对了摩尔定律放缓后的性能增长需求。Amdahl 定律提醒我们并行化存在固有上限，而实际系统设计需要在性能、功耗和面积（PPA）之间精心权衡。理解这些硬件原理，是写出高性能软件和做出合理系统设计的基础。
