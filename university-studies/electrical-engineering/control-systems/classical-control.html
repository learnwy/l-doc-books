大学电气工程 — 经典控制理论

知识要点

经典控制理论是自动控制学科的基石，它以传递函数为核心数学模型，以频率响应和根轨迹为主要分析工具，研究单输入-单输出（SISO）线性时不变系统的稳定性、动态性能和稳态精度。从工业温度调节到航天器姿态控制，从电机转速调节到化工过程控制，经典控制理论提供了一套成熟而实用的设计方法论。

经典控制的核心问题可以归结为三个层次：系统是否稳定？动态响应是否快速且平滑？稳态误差是否足够小？PID 控制器作为工业控制中最广泛使用的控制器，通过比例、积分、微分三种作用的组合来同时优化这三个指标。

拉普拉斯变换与传递函数

拉普拉斯变换将时域微分方程转化为频域代数方程。对于零初始条件下的线性时不变系统，传递函数定义为输出的拉普拉斯变换与输入的拉普拉斯变换之比：

G(s)=Y(s)U(s)=bmsm+bm−1sm−1+⋯+b0ansn+an−1sn−1+⋯+a0G(s) = \frac{Y(s)}{U(s)} = \frac{b_m s^m + b_{m-1}s^{m-1} + \cdots + b_0}{a_n s^n + a_{n-1}s^{n-1} + \cdots + a_0}G(s)=U(s)Y(s)​=an​sn+an−1​sn−1+⋯+a0​bm​sm+bm−1​sm−1+⋯+b0​​

传递函数的极点（分母为零的根）完全决定了系统的自由响应模态。一个极点 s=σ+jωs = \sigma + j\omegas=σ+jω 对应的时域分量为 eσt(cos⁡ωt+jsin⁡ωt)e^{\sigma t}(\cos\omega t + j\sin\omega t)eσt(cosωt+jsinωt)。因此：

  • 极点在左半平面（σ<0\sigma < 0σ<0）：该模态衰减，系统稳定
  • 极点在虚轴上：该模态等幅振荡，系统临界稳定
  • 极点在右半平面（σ>0\sigma > 0σ>0）：该模态发散，系统不稳定

稳定性判据

劳斯-赫尔维茨判据（Routh-Hurwitz Criterion）通过检查特征多项式系数构成的劳斯阵列，判断是否所有极点都在左半平面。规则：劳斯阵列第一列所有元素同号，则系统稳定；第一列变号次数等于右半平面极点数。

PID 控制器

PID 控制器的传递函数为：

Gc(s)=Kp+Kis+Kds=Kp(1+1Tis+Tds)G_c(s) = K_p + \frac{K_i}{s} + K_d s = K_p\left(1 + \frac{1}{T_i s} + T_d s\right)Gc​(s)=Kp​+sKi​​+Kd​s=Kp​(1+Ti​s1​+Td​s)

三个参数的作用：

  • 比例（P）：与误差成正比的控制量。增大 KpK_pKp​ 可以减小稳态误差但会降低稳定裕度
  • 积分（I）：消除稳态误差。积分作用使系统类型提高一阶，但引入额外的相位滞后
  • 微分（D）：预测误差趋势，提供阻尼。增大 KdK_dKd​ 可以改善动态响应但会放大噪声

Ziegler-Nichols 整定法是最经典的 PID 参数经验整定方法。临界比例法的步骤：先将 Ki=0K_i = 0Ki​=0，Kd=0K_d = 0Kd​=0，逐渐增大 KpK_pKp​ 直到系统出现等幅振荡，记录此时的临界增益 KuK_uKu​ 和振荡周期 TuT_uTu​。PID 参数为：

根轨迹法

根轨迹描绘了当开环增益 KKK 从 0 变化到 ∞\infty∞ 时，闭环极点在 sss 平面上的运动轨迹。它提供了增益对闭环极点位置（从而对稳定性和动态特性）影响的直观图景。

根轨迹的基本规则包括：

  • 起于开环极点，终于开环零点（或无穷远）
  • 实轴上的根轨迹：右侧开环零极点总数为奇数的实轴段属于根轨迹
  • 渐近线：n−mn - mn−m 条渐近线（nnn 为极点数，mmm 为零点数），交于 σa=∑pi−∑zjn−m\sigma_a = \frac{\sum p_i - \sum z_j}{n - m}σa​=n−m∑pi​−∑zj​​

拓展阅读

  • "Modern Control Engineering" by Ogata：经典控制理论的全球标准教材，例题丰富。
  • 《自动控制原理》（胡寿松 主编）：国内最权威的控制理论教材，理论推导严谨。
  • "Feedback Control of Dynamic Systems" by Franklin, Powell & Emami-Naeini：注重直觉和工程应用。
  • MATLAB Control System Toolbox：提供 bode, rlocus, nyquist, step 等函数，是学习控制理论的利器。

小结

经典控制理论以传递函数为数学工具，通过时域分析理解二阶系统的动态特性，通过劳斯判据和奈奎斯特判据判断系统稳定性，通过伯德图和根轨迹进行控制器设计。PID 控制器以其简洁有效的结构覆盖了工业控制的绝大多数场景。增益裕度和相位裕度提供了量化的稳定性余量评估，是控制系统设计中的关键规格指标。
