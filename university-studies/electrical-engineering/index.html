08 工学 (Engineering)电气工程 简介

电气工程 简介

电气工程研究电能的产生、变换、传输、控制与利用，是"强电"与"弱电"的共同源头：上至千伏特高压电网，下至纳米级晶体管，都由同一套电磁理论与电路分析方法驱动。本 hub 以"电路 → 器件 → 系统 → 控制"为主线组织四个章节，每章自成闭环，可独立阅读。

本 hub 与兄弟 hub 的分工边界

工程类 hub 之间主题常有交叠，下表划清本 hub 的覆盖范围，避免读者走错入口：

兄弟 hub 边界划分 归属示例
计算机科学 本 hub 的数字电路止于逻辑门、触发器与状态机这一硬件电路层；处理器体系结构、算法与软件归计算机科学 CMOS 反相器在本 hub；RISC-V 流水线在计算机科学
自动化 本 hub 讲控制理论（传递函数、状态空间、稳定性判据）；PLC 编程、传感器选型与产线集成等工程实施归自动化 劳斯判据与 PID 整定在本 hub；PLC 梯形图在自动化
通信工程 本 hub 只提供电路与功率层面的信号基础；调制、编码、信道与信息论归通信工程 RLC 谐振与滤波器在本 hub；QAM 调制在通信工程
机器人工程 本 hub 提供电机驱动与反馈控制的理论基础；机械结构、运动学与感知融合归机器人工程 直流电机建模在本 hub；机械臂逆运动学在机器人工程
机械工程 机电能量转换中"电"的一侧（电机电路、电磁转矩）在本 hub；热力学、流体与结构设计归机械工程 同步发电机等效电路在本 hub；汽轮机热力循环在机械工程

前置知识

开始前建议具备以下基础，缺哪项补哪项即可，不必等全部就绪：

  • 数学：微积分（会解一阶/二阶常微分方程）、复数四则运算。第一章只用到这两样。
  • 线性代数：矩阵运算与秩的概念——第四章现代控制部分必需，其余章节用不到。
  • 物理：高中电磁学（欧姆定律、电磁感应）。大学电磁理论可在学习中按需回补。
  • 工具：不要求编程基础；若会用 LTspice 或 MATLAB/Simulink 做仿真，学习效率会显著提高。

推荐学习路径

四章存在依赖关系：第一章是全 hub 的地基，第二、三章各自依赖第一章但相互独立，第四章依赖第一章并建议在学完任一应用章节后进入。

路径 A · 在校电类专业学生（修课配套） 按 1 → 2 → 3 → 4 的章节顺序完整推进，与《电路》《模电/数电》《电力系统》《自控原理》课程同步。每篇的「练习与思考」先做再对答案。

路径 B · 跨专业自学者（目标：看懂智能硬件与新能源产品） 1_circuit-theory 的直流与交流两篇 → 2_electronics 的半导体器件与数字电路 → 3_power-systems 的电力电子。跳过网络定理的互易定理部分和潮流计算，不影响主线。

路径 C · 目标电力与能源行业 1_circuit-theory 全部 → 3_power-systems 全部 → 4_control-systems 的经典控制一篇。发电、输电、电力电子构成完整行业图景，励磁与调速系统需要经典控制打底。

路径 D · 目标芯片与硬件设计 1_circuit-theory 全部 → 2_electronics 全部 → 4_control-systems 的数字控制一篇。器件物理决定电路性能上限，数字控制补充时序与离散实现视角。

延伸阅读

以下兄弟 hub 是本 hub 内容的自然出口，按需探索：

  • 计算机科学：从数字电路继续向上进入处理器体系结构与软件世界。
  • 自动化：把本 hub 的控制理论落到 PLC、传感器与产线的工程实施。
  • 通信工程：从滤波器与频谱概念延伸到调制、编码与信道。
  • 机器人工程：以电机驱动与反馈控制为基础，进入机电一体化系统。
