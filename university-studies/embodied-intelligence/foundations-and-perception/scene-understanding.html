场景理解与语义建图

知识要点

当机器人进入一间陌生的客厅，它需要的不仅是一堆点云坐标——它需要知道"沙发在左边，茶几上有一杯水，水杯可以被抓取，茶几不能被穿越"。将原始几何感知提升为这种结构化、可推理的语义表示，就是场景理解的核心目标。

三维物体检测与分割

从点云或 RGB-D 数据中定位并识别物体是场景理解的第一步：

3D 物体检测将目标物体用三维边界框（Bounding Box）标注：

B=(x,y,z,l,w,h,θ)B = (x, y, z, l, w, h, \theta)B=(x,y,z,l,w,h,θ)

其中 (x,y,z)(x, y, z)(x,y,z) 为中心坐标，(l,w,h)(l, w, h)(l,w,h) 为尺寸，θ\thetaθ 为航向角。代表性方法包括：

  • VoteNet：从点云中学习投票方向，聚合投票生成候选框
  • 3DETR：将 DETR 的 Transformer 架构扩展到三维空间
  • 点云分割：PointNet++ 的层次化特征聚合 + 实例分割头

开放词汇检测允许使用自然语言描述来定位任意物体，突破了固定类别的限制。典型方法：

  • CLIP + 3D 特征对齐（如 OpenScene）
  • 2D 基础模型检测结果反投影到 3D（Grounding DINO → 3D Lifting）

语义 SLAM

传统 SLAM 只估计几何结构（稀疏/稠密地图），语义 SLAM 在此基础上为地图元素附加语义标签：

M={(pi,li,ci)}\mathcal{M} = \{(p_i, l_i, c_i)\}M={(pi​,li​,ci​)}

其中 pip_ipi​ 为空间位置，lil_ili​ 为语义标签，cic_ici​ 为置信度。

关键技术组件：

  1. 实时语义分割：在 SLAM 前端中嵌入轻量语义网络（如 FastSAM）
  2. 语义数据关联：利用语义一致性辅助回环检测与重定位
  3. 增量式语义融合：贝叶斯更新每个体素/surfel 的类别概率
三维场景图
三维场景图（3D Scene Graph）是比语义地图更高层的结构化表示，将场景编码为节点（物体、区域、建筑）和边（空间关系、功能关系）：


G=(V,E)\mathcal{G} = (\mathcal{V}, \mathcal{E})G=(V,E)
节点属性包括：类别、位姿、尺寸、外观特征、功能标注（affordance）。
边的类型包括：on_top_of、inside、next_to、part_of 等。

空间推理与 Affordance
场景理解的最终目标是支撑机器人的行为决策。两个关键能力：


空间推理：回答"杯子在桌子上方吗？""从这里能看到门吗？"等空间关系查询。形式化为场景图上的图查询或基于嵌入的空间关系预测。


Affordance 检测：判断物体的可操作属性——"这个把手可以被抓取"、"这个按钮可以被按压"。通常通过视觉特征学习 affordance heatmap：


A(p)=P(action∣visual features at p)A(p) = P(\text{action} | \text{visual features at } p)A(p)=P(action∣visual features at p)
神经隐式场景表示
NeRF 及其后续工作提供了另一种场景表示范式：


FΘ:(x,y,z,θ,ϕ)→(c,σ)F_\Theta: (x, y, z, \theta, \phi) \rightarrow (c, \sigma)FΘ​:(x,y,z,θ,ϕ)→(c,σ)
将空间坐标映射为颜色 ccc 和密度 σ\sigmaσ。对具身智能的价值：


    

  • 新视角合成：规划相机移动路径前预测观察效果
    • 

  • 语义 NeRF：每个采样点附加语义标签，实现任意视角的语义渲染
    • 

  • 3D Gaussian Splatting：2024-2025年兴起的显式辐射场表示，实时渲染性能达 200+ FPS
    • 



前沿动态
    

  • ConceptGraphs (2024)：利用 LLM 将开放词汇检测结果组织为语义场景图，支持自然语言查询（"找到最近的可以坐的东西"）
    • 

  • SayPlan / SQA3D：将场景图与大语言模型结合，实现基于场景理解的任务规划
    • 

  • OK-Robot (2024)：零样本开放世界物体抓取，依赖预训练视觉模型和语义记忆
    • 

  • 实时动态场景图：面向非静态环境（有人活动的家庭），实现物体状态变化的在线追踪
    • 

  • 多模态场景基础模型：统一 2D、3D、语言的大规模预训练模型（如 PQ3D）
    • 



练习与思考
    

  1. 对比 TSDF（Truncated Signed Distance Field）和 3D Gaussian Splatting 两种三维表示方法的优劣。它们各自在什么具身任务场景中更适用？
    

    2. 

  2. 设计实验：使用 Habitat 仿真器加载一个室内场景，运行一个简单的语义 SLAM 系统（前端用 ORB-SLAM3 + 语义分割），构建带语义标签的三维地图。评估语义标注的准确率与 SLAM 定位精度之间的关系。
    

    3. 

  3. 思考：场景图中的空间关系（如 on_top_of）在真实世界中往往是连续的而非离散的。一个杯子"几乎"要从桌子上掉下来——如何在场景图中表示这种不确定性？这对机器人决策有什么影响？
    

    4. 

  4. 对比两种场景记忆方案：（a）保存完整三维地图 + 离线查询，（b）保存语义场景图 + 在线增量更新。从存储效率、查询速度、信息保真度三个维度分析各自的适用场景。
    

    5. 



小结
场景理解将原始几何数据转化为结构化、可推理、可查询的语义表示。从三维物体检测到语义 SLAM，再到层次化场景图与 affordance 检测，本节系统梳理了具身智能体理解环境的技术栈。这一"世界模型"为后续的任务规划、导航与操作提供了决策所需的环境知识。
