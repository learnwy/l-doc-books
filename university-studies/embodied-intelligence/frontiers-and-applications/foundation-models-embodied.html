基础模型与具身智能

知识要点

当 GPT-4 能理解自然语言、DALL-E 能生成图像、SAM 能分割万物时，一个自然的问题浮现：这些大规模预训练模型能否赋予机器人"通用智能"——像人一样听懂指令、理解环境、规划行动并执行操作？2024-2026年，视觉-语言-动作（VLA）模型的爆发正在回答这个问题。

从语言模型到具身模型

传统机器人策略是为特定任务训练的窄模型。基础模型的变革在于：

  • 互联网规模知识：从海量文本和图像中获得世界常识（"杯子是用来喝水的"）
  • 语言作为接口：自然语言指令替代硬编码的任务 ID
  • 零样本泛化：处理训练时未见过的物体、场景和指令

关键范式转变：

传统:π(a∣s)→VLA:π(a∣oimg,olang,oproprio)\text{传统}: \pi(a|s) \quad \rightarrow \quad \text{VLA}: \pi(a|o_{img}, o_{lang}, o_{proprio})传统:π(a∣s)→VLA:π(a∣oimg​,olang​,oproprio​)

策略的输入从低维状态向量扩展为多模态观测（图像、语言指令、本体感知）。

RT-2：VLM 直接控制
RT-2 的核心洞察是将机器人动作视为"另一种语言"——将连续动作离散化为 token，与文本 token 在同一词表中联合训练：


at=de-tokenize(LLM(oimg,"pick up the red cup"))a_t = \text{de-tokenize}(\text{LLM}(o_{img}, \text{"pick up the red cup"}))at​=de-tokenize(LLM(oimg​,"pick up the red cup"))
动作 token 化方案：将每个自由度的连续值量化为 256 个 bin：


token(ai)=round(ai−aminamax−amin×255)\text{token}(a_i) = \text{round}\left(\frac{a_i - a_{min}}{a_{max} - a_{min}} \times 255\right)token(ai​)=round(amax​−amin​ai​−amin​​×255)
Flow Matching 动作生成
π0\pi_0π0​ 引入 Flow Matching 取代 token 化，直接在连续空间中生成动作：


vθ(xt,t)=dxtdt,x0∼N(0,I),x1=atargetv_\theta(x_t, t) = \frac{dx_t}{dt}, \quad x_0 \sim \mathcal{N}(0, I), \quad x_1 = a_{target}vθ​(xt​,t)=dtdxt​​,x0​∼N(0,I),x1​=atarget​
通过学习从噪声到动作的流映射，避免了离散化带来的精度损失。相比扩散模型，Flow Matching 的优势：


    

  • 推理时步数更少（通常 5-10 步 vs. 扩散的 50-100 步）
    • 

  • 训练目标更简单（直接回归速度场）
    • 

  • 适合实时控制的低延迟需求
    • 



开放词汇指令跟随
基础模型赋予机器人理解开放词汇指令的能力：


    

  • 具象化语言（Grounded Language）：将"拿桌上的红杯子"映射到具体的物体实例和动作参数
    • 

  • 隐含知识推理：理解"帮我倒杯水"需要找到水壶→拿水壶→找杯子→倒水→放回
    • 

  • 否定与约束理解："不要碰那个易碎的花瓶"
    • 



SayCan 框架将 LLM 的任务分解能力与机器人的可行性评估结合：


score(ai)=PLLM(ai∣instruction)×Pafford(ai∣state)\text{score}(a_i) = P_{LLM}(a_i | \text{instruction}) \times P_{afford}(a_i | \text{state})score(ai​)=PLLM​(ai​∣instruction)×Pafford​(ai​∣state)
LLM 负责"说什么有道理"，affordance 模型负责"做什么可行"。


数据规模与多机器人学习
VLA 模型的训练数据来源：


    

  • 真实机器人操作数据：Open X-Embodiment 汇聚了 22 种机器人、160K+ 任务的数据
    • 

  • 互联网视频：人类操作视频提供丰富的视觉-语言-动作关联
    • 

  • 仿真生成数据：通过仿真器大规模生成多样化任务数据
    •

跨具身泛化
一个关键科学问题：不同形态的机器人之间能否共享知识？


πuniversal(a∣o,embodiment_token)\pi_{universal}(a | o, \text{embodiment\_token})πuniversal​(a∣o,embodiment_token)
通过 embodiment token 或 adapter 机制，让单一模型适配不同机器人平台（不同关节数、传感器配置、动作空间）。


前沿动态
    

  • π0\pi_0π0​ (Physical Intelligence, 2025)：首个展示"穿衣、叠衣、收拾桌面"等真正家务能力的通用策略
    • 

  • GR-2 (ByteDance, 2025)：基于视频生成模型的世界模型，预测动作结果用于规划
    • 

  • Scaling Laws for Robotics：类似语言模型的 scaling law 开始在机器人数据上显现
    • 

  • VLA + Tool Use：机器人学会使用工具（如用铲子翻煎蛋），泛化到训练中未见的工具
    • 

  • 自我改进：机器人通过自主练习生成训练数据，bootstrapping 提升能力
    • 

  • 多机器人协作 VLA：多台机器人共享信息完成单机无法完成的任务
    • 



练习与思考
    

  1. 分析 RT-2 中动作 token 化的精度损失：若一个关节的范围是 [−π,π][-\pi, \pi][−π,π]，量化为 256 bin，最大量化误差是多少？这个误差对精细操作（如插入 USB）是否可接受？
    

    2. 

  2. 对比两种将预训练 VLM 适配为机器人策略的路线：（a）全模型微调，（b）冻结视觉-语言部分 + 训练动作头。从数据效率、泛化能力、计算成本三个维度分析。
    

    3. 

  3. 设计一个实验验证 VLA 模型的"常识推理"能力：给出一组越来越抽象的指令（从"拿红色杯子"到"帮我准备喝茶"），测试模型在哪个抽象层级开始失败。
    

    4. 

  4. 思考：基础模型路线是否会完全取代传统的感知-规划-控制流水线？讨论各自的优势和适用边界。什么类型的任务仍然需要经典方法？
    

    5. 



小结
基础模型正在重塑具身智能的研究范式——从为每个任务从头训练，到在海量多模态数据上预训练通用策略。VLA 模型通过统一视觉、语言和动作空间，实现了前所未有的指令理解和零样本泛化能力。从 RT-2 到 π0\pi_0π0​，从 token 化到 flow matching，动作生成的精度和效率持续提升。虽然距离真正的"通用机器人基础模型"仍有差距，但 2024-2026 年的进展表明这条路线的巨大潜力。
