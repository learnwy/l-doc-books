人机协作与社会机器人

知识要点

具身智能的终极目标不是让机器人独自工作，而是让它与人类共存、协作并服务于人。当一个机器人需要与工人配合装配汽车零件、在老人家中提供护理辅助、或在餐厅中穿梭服务时，它面对的不再是物理环境的确定性约束，而是人类行为的不可预测性、社会规范的隐含性以及安全交互的绝对底线。

安全交互原则

人机协作的第一要务是安全。ISO/TS 15066 标准定义了协作机器人的四种安全模式：

安全模式 机制 适用场景
安全监控停止 人进入区域时暂停 大型工业臂
手动引导 人直接接触引导 示教编程
速度与距离监控 保持安全距离 共享工作空间
功率与力限制 限制接触力 直接物理交互

接触力安全阈值根据人体部位不同而变化：

身体部位 最大准静态力 最大瞬态力
头部/前额 130 N 260 N
胸部 140 N 280 N
手掌 260 N 520 N
手指 140 N 280 N

机器人控制器必须实时监控接触力并在超限时立即退让：

人体姿态预测：给定过去 TobsT_{obs}Tobs​ 帧人体骨骼序列，预测未来 TpredT_{pred}Tpred​ 帧：

情感计算与社交信号
社会机器人需要理解和适当回应人类的情感状态：


多模态情感识别：

融合面部表情（AU 单元）、语音韵律、语言内容和身体姿态。


社交距离（Proxemics）：Edward Hall 的空间距离理论应用于机器人行为：


    

  • 亲密距离：< 0.45m（仅限护理/辅助场景）
    • 

  • 个人距离：0.45-1.2m（对话交互）
    • 

  • 社交距离：1.2-3.6m（服务递送）
    • 

  • 公共距离：> 3.6m（导引）

自然语言交互
服务机器人需要流畅的语音/文字对话能力：


    

  • 多轮对话管理：维护对话状态、处理上下文引用
    • 

  • 澄清与确认：面对模糊指令主动提问（"你说的杯子是红色那个还是蓝色那个？"）
    • 

  • 非言语沟通：通过注视方向、手势、LED 灯效传达意图
    • 



具身对话的特殊挑战：对话内容与物理环境紧密耦合，机器人需要边说边做、边做边观察反馈。

  • 人负责精密操作和质量判断

  • 辅助行走（外骨骼）、进食辅助、康复训练

家庭服务
    

  • 整理物品、端茶送水、陪伴对话
    • 

  • 关键：多样化环境适应、长期自主运行、用户偏好学习

教育与陪伴
    

  • 面向儿童或老人的互动式教学与陪伴

    •

  • Figure 02 + ChatGPT (2025)：人形机器人通过自然对话理解复杂指令并协作完成厨房任务

小结
人机协作与社会机器人代表了具身智能走向真实应用的"最后一公里"——不仅要求机器人具备感知、规划和操作能力，还要求它理解人类意图、遵守社会规范、保障物理安全并建立信任关系。从工业协作到家庭服务，每个场景都对安全性、自然性和适应性提出了独特需求。随着基础模型赋予机器人语言理解和常识推理能力，真正的"与人共处"的机器人正从实验走向日常。
