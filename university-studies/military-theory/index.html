11 军事学 (Military Science)军事理论

军事理论

军事理论是高校公共军事课的理论支柱，回答"为什么要国防、靠什么观念建军、当代战争怎么打"这一组根本问题。本 hub 不讲武器参数、不讲条文细则，而是讲思想、观念与战争形态——它是理解军事科学其余分支的"操作系统"。

本 hub 讲什么 / 不讲什么

本 hub 按"思想根基 → 国防总论 → 安全观 → 战争形态"四章组织，从历史思想脉络一路推进到智能化战争前沿：

章节 核心问题 主要内容
军事思想 中国军事文化从何而来 中国古代军事思想（《孙子兵法》）、毛泽东军事思想、习近平强军思想
国防概述 国防是什么、谁来建 国防概念与历史、国防法规与政策、国防建设与武装力量
国家安全 安全的内涵如何拓展 总体国家安全观、国际安全形势、非传统安全威胁
现代战争 当代战争怎么打 新军事变革、信息化战争、智能化战争

与兄弟 hub 的分工边界

军事科学（11_military-science）下设三个并列 hub，分工互补，避免内容重叠：

hub 定位 典型问题 与本 hub 的关系
军事理论（本 hub） 思想 · 观念 · 战争形态 为何而战、战争怎样演变 提供理论框架与战略视角
国防（2_national-defense） 制度 · 法规 · 动员 武装力量怎么编、兵役怎么服、平战怎么转 本 hub 概述的体制，国防 hub 做专题展开
军事技术（3_military-technology） 装备 · 技术 · 武器系统 导弹、电子战、无人机如何工作 本 hub 谈的战争形态，技术 hub 给出物质支撑

简言之：遇到"思想/形态"问题看本 hub，遇到"制度/编成"看国防 hub，遇到"装备/原理"看军事技术 hub。 三者通过各篇末尾的"延伸阅读与跨学科链接"相互引用。

推荐学习路径

面向高校军事理论课学生（必修 4 学分）：按章顺序通读即可——先用"军事思想"建立文化自觉，再用"国防概述"理解国防的法理与体制，然后用"国家安全"建立总体安全视野，最后用"现代战争"把握战争演变趋势。配合每篇的"练习与思考"自测。

面向只想快速建立战略素养的非军事专业读者：走精读路线——中国古代军事思想 → 总体国家安全观 → 新军事变革，三篇即可建立"古代智慧—当代安全观—未来战争"的主干认知。

面向对前沿最感兴趣的科技读者：直接从新军事变革 → 信息化战争 → 智能化战争切入，再回溯思想章理解"中国为何选择机械化信息化智能化融合发展道路"。

前置知识

  • 中国近现代史基础：理解"近代国防屈辱""人民战争""强军思想"都需要对鸦片战争至今的历史脉络有基本把握。
  • 马克思主义基本原理：毛泽东军事思想以唯物辩证法为方法论，强军思想是马克思主义军事理论中国化的最新成果，相关篇章已给出到马克思主义 hub 的链接。
  • 当代国际关系常识：国家安全与现代战争两章涉及大国竞争、地缘格局，了解基本的国际格局有助理解，相关篇章链接到政治学与地缘政治 hub。

无需任何军事专业背景，所有概念均从零讲起。
