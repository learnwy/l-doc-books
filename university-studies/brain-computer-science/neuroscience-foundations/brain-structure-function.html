脑结构与功能分区

知识要点

人类大脑重约1.4千克，包含约860亿神经元和数万亿突触连接，是已知宇宙中最复杂的信息处理系统。对于脑机接口工程师而言，精确理解大脑的三维空间组织与功能区划，是确定电极放置位置、解释信号来源、以及设计空间滤波算法的第一步。

大脑皮层的层状结构

大脑皮层（cerebral cortex）厚度约2-4mm，从外到内分为六层（I-VI层），每层有不同的细胞类型与连接模式：

  • 第I层（分子层）：主要含树突与轴突纤维，胞体稀少
  • 第II层（外颗粒层）：小锥体细胞和星形细胞，接收局部皮层输入
  • 第III层（外锥体层）：中型锥体细胞，是皮层-皮层（cortico-cortical）连接的主要来源
  • 第IV层（内颗粒层）：星形细胞密集，接收丘脑传入——初级感觉皮层该层特别发达
  • 第V层（内锥体层）：大型锥体细胞（Betz细胞位于运动皮层第V层），向脊髓和脑干投射
  • 第VI层（多形层）：多种形态细胞，向丘脑反馈投射

对BCI的意义：ECoG电极贴附皮层表面时，主要记录II-III层锥体细胞的局部场电位（LFP）；穿刺式微电极阵列（如Utah阵列）插入深度约1.5mm，可记录IV-V层单个神经元的动作电位（spike）。

Brodmann分区与功能定位

1909年Korbinian Brodmann基于细胞构筑学将皮层划分为52个区域，至今仍是神经科学的基础参考框架：

Brodmann区 位置 功能 BCI相关性
BA4 中央前回 初级运动皮层（M1） 运动想象BCI核心靶区
BA6 M1前方 前运动区/辅助运动区 运动规划信号源
BA17 枕极 初级视觉皮层（V1） SSVEP信号源
BA41/42 颞横回 初级听觉皮层 听觉BCI范式
BA7/40 顶叶 后顶叶皮层 注意力与空间导航

功能柱组织

大脑皮层以垂直于表面的"柱"（column）为基本功能单元，每柱直径约0.3-0.5mm，包含约80-100个神经元。Hubel和Wiesel在视觉皮层发现的方位柱（orientation column）证明了柱内神经元共享相似的刺激偏好。功能柱概念对BCI的启示在于：

空间分辨率要求≈dcolumn2≈0.15-0.25 mm\text{空间分辨率要求} \approx \frac{d_{\text{column}}}{2} \approx 0.15\text{-}0.25 \text{ mm}空间分辨率要求≈2dcolumn​​≈0.15-0.25 mm

只有侵入式电极阵列（如Utah阵列，电极间距400μm）才能达到单柱级分辨率，而EEG的空间分辨率约为2-3cm，只能反映数万个柱的协同活动。

白质纤维束与脑区连接

大脑白质由髓鞘包裹的轴突纤维组成，形成脑区间的远距离通信通道：

主要纤维束分类：


    

  1. 投射纤维：连接皮层与皮层下结构（如皮质脊髓束、丘脑辐射）
    2. 

  2. 联合纤维：同侧半球内不同皮层区之间的连接（如弓状束、上纵束）
    3. 

  3. 连合纤维：两半球间的连接（如胼胝体，含约2亿根轴突）
    4. 



弥散张量成像（DTI）可以活体重建白质纤维束走向，为术前BCI植入规划提供结构连接信息。


皮层下结构
BCI设计还需考虑关键皮层下核团：


    

  • 基底节（尾状核、壳核、苍白球）：运动选择与动作起始，帕金森病DBS靶点
    • 

  • 丘脑：几乎所有感觉信息的中继站，调节皮层兴奋性
    • 

  • 海马：情景记忆编码，是记忆增强BCI的潜在靶点
    • 

  • 杏仁核：情绪处理，情绪识别BCI的信号源
    • 



前沿动态
2025-2026年脑结构研究领域出现多项突破：


    

  1. Allen Brain Atlas 2.0：Allen研究所发布了迄今最高分辨率的人类全脑细胞图谱，在单细胞水平标注了超过3000种细胞类型的空间分布，为精确定位BCI靶区提供了前所未有的参考。
    

    2. 

  2. 连接组学进展：Human Connectome Project的后续研究利用7T MRI和先进示踪技术，将人脑白质连接图谱的空间分辨率提升至亚毫米级，揭示了个体间连接模式差异与认知能力的关联。
    

    3. 

  3. Neuralink N1植入位置优化：Neuralink 2024年首例人体植入（PRIME试验）选择了运动皮层手部控制区，2025年的后续病例开始探索多区域植入策略，以实现更自然的多自由度控制。
    

    4. 

  4. 体素水平功能定位：基于深度学习的个体化脑区分割算法（如FreeSurfer 8.0）能够根据单个被试的功能MRI数据，在15分钟内完成高精度个体化Brodmann分区映射。
    

    5. 



练习与思考
    

  1. 解剖定位练习：给定一个10-20系统的EEG电极位置（如C3），说明该电极下方对应的Brodmann区域和主要功能。如果被试执行右手运动想象任务，C3电极会检测到什么信号变化？
    

    2. 

  2. 分辨率计算：某Utah阵列包含96个电极，排列为10×1010 \times 1010×10网格（四角无电极），电极间距400μm。计算该阵列覆盖的皮层面积，并估算它能同时记录多少个功能柱的活动。
    

    3. 

  3. 连接组分析：一位患者因中风导致左侧内囊损伤，皮质脊髓束中断。设计一个BCI方案，绕过受损通路，利用完好的运动皮层信号控制右侧肢体的功能电刺激（FES）系统。需要考虑哪些解剖结构？
    

    4. 

  4. 批判性思考：Brodmann分区是基于20世纪初的组织染色技术建立的。讨论其在现代BCI电极定位中的局限性，以及多模态成像（fMRI + DTI + 术中电刺激映射）如何改进个体化定位精度。
    

    5. 



小结
大脑的空间组织遵循从微观（神经元→功能柱→层状结构）到宏观（脑区→纤维束连接→全脑网络）的多尺度层级架构。BCI系统设计的第一步是根据目标功能确定信号源的解剖位置和所需的空间分辨率，进而选择匹配的采集技术。理解皮层层状结构解释了为什么不同深度的电极记录到不同信号类型；Brodmann分区和功能柱概念指导了电极阵列的靶区选择；白质连接图谱则揭示了脑区间信息流动的路径，对于多区域BCI的协调解码至关重要。
