神经信号采集技术

知识要点

脑机接口系统的性能上限由信号采集前端决定——再强大的算法也无法从低质量信号中提取不存在的信息。神经信号采集技术的选择是BCI系统设计中最关键的架构决策之一，它直接限定了可达到的空间分辨率、时间分辨率、信号带宽以及长期稳定性。本节系统对比三大类采集技术的原理、性能指标与适用场景。

EEG：头皮脑电图
EEG记录的是大量锥体细胞突触后电位的空间叠加，信号经过颅骨、脑脊液和头皮的体积传导后到达电极。


10-20国际电极放置系统：


基于头骨标志点（鼻根nasion、枕外隆凸inion、左右耳前点）按10%和20%比例放置电极。标准系统包含21个电极位置：


    

  • F系列（额区）：Fp1/Fp2, F3/F4, F7/F8, Fz
    • 

  • C系列（中央区）：C3/C4, Cz — 运动想象BCI核心通道
    • 

  • P系列（顶区）：P3/P4, Pz — P300 BCI核心通道
    • 

  • O系列（枕区）：O1/O2, Oz — SSVEP BCI核心通道
    • 

  • T系列（颞区）：T3/T4, T5/T6
    • 



EEG信号特征：


节律性活动按频段分类：

运动想象BCI利用的核心现象是事件相关去同步化（ERD）和事件相关同步化（ERS）：


ERD%=Preference−PactivePreference×100%ERD\% = \frac{P_{reference} - P_{active}}{P_{reference}} \times 100\%ERD%=Preference​Preference​−Pactive​​×100%
左手运动想象时，右侧感觉运动区（C4电极）的mu节律（8-12Hz）出现ERD，这一模式是运动想象BCI分类的基础。


EEG的工程挑战：


    

  1. 体积传导模糊：单个电极记录的是数cm半径内数万神经元的混合信号
    2. 

  2. 伪迹干扰：眼动（EOG, 100μV级）、肌电（EMG）、工频噪声（50/60Hz）
    3. 

  3. 导联阻抗：干电极>5kΩ vs 湿电极<5kΩ — 影响信噪比
    4. 

  4. 非平稳性：信号统计特性随疲劳、注意力波动而变化
    5. 



ECoG：皮层脑电图
ECoG电极直接铺设在硬脑膜下的皮层表面，绕过了颅骨的空间滤波效应：


ECoG相对EEG的优势：


    

  • 高频gamma活动（>70Hz）可被可靠记录 — EEG中该频段被颅骨严重衰减
    • 

  • 空间分辨率提升一个数量级（mm级 vs cm级）
    • 

  • 信号幅度大5-10倍，SNR显著提升
    • 

  • 较少受肌电和眼动伪迹影响
    • 



高频gamma（High Gamma, 70-200Hz）：


HG活动与局部神经元群体的放电率高度相关，被称为ECoG的"spike proxy"：


HG power(t)∝∑iri(t)\text{HG power}(t) \propto \sum_{i} r_i(t)HG power(t)∝i∑​ri​(t)
这一特性使得ECoG-BCI能达到接近侵入式系统的解码性能，同时保持更好的长期稳定性。


微电极阵列
微电极阵列穿入皮层组织，直接记录单个或少量神经元的动作电位：


Utah阵列（Blackrock Microsystems）：


    

  • 96通道硅基阵列，10×1010 \times 1010×10排列
    • 

  • 电极长度1.0-1.5mm，间距400μm
    • 

  • 记录单元活动（single-unit）和多元活动（multi-unit）
    • 

  • PRIME试验中Neuralink N1使用类似原理但采用柔性聚合物线束
    • 



信号类型：

spike sorting算法通过波形模板匹配或主成分分析将混合信号分解为单个神经元的活动：


    

  1. 带通滤波（300-5000Hz）提取spike频段
    2. 

  2. 阈值检测（通常为噪声RMS的−4σ-4\sigma−4σ）
    3. 

  3. 波形对齐与特征提取（PCA降维）
    4. 

  4. 聚类（GMM或在线排序算法）
    5. 



长期稳定性挑战：


植入后的胶质细胞疤痕形成导致信号质量随时间衰退：


    

  • 急性期（0-2周）：信号最优
    • 

  • 慢性期（>1月）：阻抗升高，可记录单元数下降
    • 

  • 长期（>1年）：可能丢失50%以上的单元信号
    • 



解决方案包括：抗炎涂层、柔性电极（减少微运动）、自适应解码算法（补偿信号漂移）。

前沿动态
    

  1. Neuralink N2线束技术：2026年Neuralink公布了第二代植入设备N2的技术细节，采用1024通道超柔性聚合物线束（直径仅5μm），配合机器人手术系统精确避开血管植入，胶质疤痕反应较Utah阵列显著降低。
    

    2. 

  2. 石墨烯干电极：基于石墨烯纳米片的新型EEG干电极实现了与传统湿电极相当的信号质量（阻抗<1kΩ），同时无需导电膏，支持长期连续监测。2025年多个商业化产品进入市场。
    

    3. 

  3. 神经尘埃（Neural Dust）：UC Berkeley团队的无线超微型传感器（体积<1mm³）通过超声波供电和数据回传，无需引线穿过颅骨，在灵长类实验中展示了稳定的慢性记录能力。
    

    4. 

  4. 内血管电极（Stentrode）：Synchron公司的血管内BCI电极通过颈静脉植入到运动皮层附近的上矢状窦，无需开颅手术。2025年完成了渐冻症患者的首次居家使用试验，患者成功控制计算机操作。
    

    5. 



练习与思考
    

  1. 电极选型决策：一位C4脊髓损伤患者（四肢瘫痪）希望通过BCI控制轮椅和计算机。分析EEG、ECoG和微电极阵列三种方案各自的优缺点。考虑因素包括：控制自由度需求、用户长期使用意愿、手术风险承受度、系统维护成本。
    

    2. 

  2. SNR计算：某EEG通道的原始信号功率为Praw=100 μV2P_{raw} = 100\,\mu V^2Praw​=100μV2，经ICA去除眼动伪迹后功率降为Pclean=40 μV2P_{clean} = 40\,\mu V^2Pclean​=40μV2，已知ERP信号功率为PERP=4 μV2P_{ERP} = 4\,\mu V^2PERP​=4μV2。计算去伪迹前后的SNR变化。
    

    3. 

  3. 采样定理应用：根据Nyquist采样定理，记录高频gamma活动（最高200Hz）至少需要多高的采样率？考虑实际工程中的抗混叠滤波器滚降特性，推荐的实际采样率应该是多少？
    

    4. 

  4. 设计思考：为什么Neuralink选择柔性聚合物线束而非传统硅基电极？从力学匹配（电极杨氏模量 vs 脑组织杨氏模量）的角度分析长期稳定性优势。
    

    5. 



小结
神经信号采集是BCI系统的物理接口层，直接决定了系统能获取的信息量上限。EEG以零手术风险和高便携性换取低空间分辨率和窄带宽；ECoG在中等侵入性下提供了出色的信号质量；微电极阵列以最高的信息密度面对最严峻的长期稳定性挑战。技术选择没有绝对优劣，需要根据临床需求（控制自由度）、用户条件（手术承受力）和系统约束（长期维护能力）进行权衡。未来趋势是向更微创、更高通道数、更长期稳定的方向演进。
