量子纠缠与Bell不等式

知识要点

纠缠是量子力学区别于经典物理最根本的特征之一——一个复合量子系统可以处于无法分解为各子系统独立状态乘积的整体状态。这种非经典关联是量子计算提供指数加速、量子密钥分发保证无条件安全的物理根源。

纠缠态的定义

对于二体系统 HA⊗HB\mathcal{H}_A \otimes \mathcal{H}_BHA​⊗HB​，若纯态 ∣Ψ⟩AB|\Psi\rangle_{AB}∣Ψ⟩AB​ 不能写成乘积形式：

∣Ψ⟩AB≠∣ϕ⟩A⊗∣χ⟩B|\Psi\rangle_{AB} \neq |\phi\rangle_A \otimes |\chi\rangle_B∣Ψ⟩AB​=∣ϕ⟩A​⊗∣χ⟩B​

则称 ∣Ψ⟩AB|\Psi\rangle_{AB}∣Ψ⟩AB​ 为纠缠态。最重要的纠缠态是四个Bell态（EPR对）：

∣Φ+⟩=12(∣00⟩+∣11⟩)|\Phi^+\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)∣Φ+⟩=2​1​(∣00⟩+∣11⟩)
∣Φ−⟩=12(∣00⟩−∣11⟩)|\Phi^-\rangle = \frac{1}{\sqrt{2}}(|00\rangle - |11\rangle)∣Φ−⟩=2​1​(∣00⟩−∣11⟩)
∣Ψ+⟩=12(∣01⟩+∣10⟩)|\Psi^+\rangle = \frac{1}{\sqrt{2}}(|01\rangle + |10\rangle)∣Ψ+⟩=2​1​(∣01⟩+∣10⟩)
∣Ψ−⟩=12(∣01⟩−∣10⟩)|\Psi^-\rangle = \frac{1}{\sqrt{2}}(|01\rangle - |10\rangle)∣Ψ−⟩=2​1​(∣01⟩−∣10⟩)

这四个态构成 HA⊗HB\mathcal{H}_A \otimes \mathcal{H}_BHA​⊗HB​ 的一组正交归一基（Bell基）。

EPR佯谬与局域实在论

1935年，Einstein、Podolsky和Rosen提出了著名的EPR论证：如果量子力学是完备的，那么对纠缠粒子的远距离测量结果之间的关联似乎违反了局域性原则。他们的结论是量子力学不完备，应该存在"隐变量"来补全描述。

EPR论证的核心假设：

  1. 实在性：如果可以确定无疑地预测物理量的值（不扰动系统），则该物理量有确定的物理实在
  2. 局域性：对一个系统的测量不能瞬时影响远处另一系统的物理实在

Bell不等式

1964年，John Bell证明了任何满足局域实在论的隐变量理论都必须满足一个不等式约束，而量子力学的预言违反了这一约束。

考虑CHSH（Clauser-Horne-Shimony-Holt）形式的Bell不等式。Alice可以测量 A1A_1A1​ 或 A2A_2A2​，Bob可以测量 B1B_1B1​ 或 B2B_2B2​，测量结果为 ±1\pm 1±1。定义关联函数：

E(Ai,Bj)=⟨AiBj⟩E(A_i, B_j) = \langle A_i B_j \rangleE(Ai​,Bj​)=⟨Ai​Bj​⟩

CHSH不等式为：

∣S∣=∣E(A1,B1)+E(A1,B2)+E(A2,B1)−E(A2,B2)∣≤2|S| = |E(A_1, B_1) + E(A_1, B_2) + E(A_2, B_1) - E(A_2, B_2)| \leq 2∣S∣=∣E(A1​,B1​)+E(A1​,B2​)+E(A2​,B1​)−E(A2​,B2​)∣≤2

对于Bell态 ∣Φ+⟩|\Phi^+\rangle∣Φ+⟩，选择适当的测量基：

  • A1=σzA_1 = \sigma_zA1​=σz​，A2=σxA_2 = \sigma_xA2​=σx​
  • B1=σz+σx2B_1 = \frac{\sigma_z + \sigma_x}{\sqrt{2}}B1​=2​σz​+σx​​，B2=σz−σx2B_2 = \frac{\sigma_z - \sigma_x}{\sqrt{2}}B2​=2​σz​−σx​​

量子力学预言：

SQM=22≈2.828S_{QM} = 2\sqrt{2} \approx 2.828SQM​=22​≈2.828

这称为Tsirelson界，是量子力学允许的最大CHSH值。22>22\sqrt{2} > 222​>2 证明量子力学与任何局域隐变量理论不相容。

纠缠度量

von Neumann纠缠熵

对于纯态 ∣Ψ⟩AB|\Psi\rangle_{AB}∣Ψ⟩AB​，通过约化密度矩阵度量纠缠：

ρA=TrB(∣Ψ⟩⟨Ψ∣)\rho_A = \text{Tr}_B(|\Psi\rangle\langle\Psi|)ρA​=TrB​(∣Ψ⟩⟨Ψ∣)

纠缠熵定义为：

E(∣Ψ⟩)=S(ρA)=−Tr(ρAlog⁡2ρA)E(|\Psi\rangle) = S(\rho_A) = -\text{Tr}(\rho_A \log_2 \rho_A)E(∣Ψ⟩)=S(ρA​)=−Tr(ρA​log2​ρA​)

对Bell态，ρA=I2\rho_A = \frac{I}{2}ρA​=2I​，因此 E=1E = 1E=1 ebit（最大纠缠）。

Schmidt分解

任意二体纯态都可以进行Schmidt分解：

∣Ψ⟩AB=∑i=1rλi∣ai⟩A∣bi⟩B|\Psi\rangle_{AB} = \sum_{i=1}^{r} \lambda_i |a_i\rangle_A |b_i\rangle_B∣Ψ⟩AB​=i=1∑r​λi​∣ai​⟩A​∣bi​⟩B​

其中 λi>0\lambda_i > 0λi​>0，∑iλi2=1\sum_i \lambda_i^2 = 1∑i​λi2​=1，rrr 为Schmidt秩。r=1r = 1r=1 对应乘积态（无纠缠），r>1r > 1r>1 对应纠缠态。

共生纠缠度（Concurrence）

对于二量子比特混合态 ρ\rhoρ，Wootters给出了可计算的纠缠度量——共生纠缠度：

C(ρ)=max⁡(0,λ1−λ2−λ3−λ4)C(\rho) = \max(0, \lambda_1 - \lambda_2 - \lambda_3 - \lambda_4)C(ρ)=max(0,λ1​−λ2​−λ3​−λ4​)

其中 λi\lambda_iλi​ 是矩阵 ρ(σy⊗σy)ρ∗(σy⊗σy)\rho(\sigma_y \otimes \sigma_y)\rho^*(\sigma_y \otimes \sigma_y)ρ(σy​⊗σy​)ρ∗(σy​⊗σy​) 的特征值的平方根（降序排列）。

纠缠作为资源

纠缠在量子信息协议中作为核心物理资源：

前沿动态

2026年纠缠技术的重要进展：

  • 千公里纠缠分发：基于"墨子号"的星地链路实现了超过1200公里的纠缠光子对分发，Bell不等式违背的统计显著性达到 50σ50\sigma50σ
  • 多体纠缠：Google Quantum AI团队在其最新72量子比特处理器上制备了含48个量子比特的GHZ态并验证了真多体纠缠
  • 纠缠蒸馏：实验室首次在光纤通信距离上演示了高效的纠缠纯化协议，保真度从85%提升至97%，向实用量子中继迈进关键一步
  • 无漏洞Bell实验：2026年新一轮实验同时关闭了探测效率漏洞和局域性漏洞，进一步巩固了量子力学的非局域性结论

练习与思考

  1. 验证题：对Bell态 ∣Ψ−⟩=12(∣01⟩−∣10⟩)|\Psi^-\rangle = \frac{1}{\sqrt{2}}(|01\rangle - |10\rangle)∣Ψ−⟩=2​1​(∣01⟩−∣10⟩)，计算约化密度矩阵 ρA\rho_AρA​，验证纠缠熵 E=1E = 1E=1 ebit。

  2. 计算题：对态 ∣ψ⟩=12∣00⟩+32∣11⟩|\psi\rangle = \frac{1}{2}|00\rangle + \frac{\sqrt{3}}{2}|11\rangle∣ψ⟩=21​∣00⟩+23​​∣11⟩，求其Schmidt系数和纠缠熵。

  3. 推导题：从CHSH不等式出发，证明Tsirelson界 Smax=22S_{max} = 2\sqrt{2}Smax​=22​（提示：将 SSS 写成算符形式，利用 S2≤4I+[A1,A2][B1,B2]S^2 \leq 4I + [A_1, A_2][B_1, B_2]S2≤4I+[A1​,A2​][B1​,B2​]）。

  4. 思考题：为什么纠缠不能用于超光速通信？请从约化密度矩阵的角度说明。

小结

量子纠缠是量子信息科学最核心的物理资源。本节从纠缠态的定义出发，通过EPR佯谬和Bell不等式建立了量子非局域性的理论框架，介绍了纠缠熵、Schmidt分解和共生纠缠度等定量工具，并展示了纠缠在量子隐形传态、超密编码等信息协议中的关键角色。对Bell不等式实验违背的理解，标志着从"量子力学的哲学困惑"到"量子信息的技术资源"这一认识转变。
