后量子密码学

知识要点

后量子密码学（Post-Quantum Cryptography, PQC）研究能够抵抗量子计算机攻击的经典密码算法。Shor算法对RSA和椭圆曲线密码的威胁已非遥远假设——随着量子硬件的加速发展，全球密码基础设施正面临"先收集后解密"（harvest now, decrypt later）的现实风险，密码体系的量子安全迁移已成为各国战略优先事项。

量子威胁分析

Shor算法对当前主流公钥密码的影响：

密码方案 经典安全性 量子攻击复杂度 状态
RSA-2048 O(2112)O(2^{112})O(2112) O(n3)O(n^3)O(n3) 多项式 不安全
ECC (P-256) O(2128)O(2^{128})O(2128) O(n3)O(n^3)O(n3) 多项式 不安全
AES-128 O(2128)O(2^{128})O(2128) O(264)O(2^{64})O(264) Grover 需加倍密钥长度
SHA-256 O(2128)O(2^{128})O(2128) 碰撞 O(285)O(2^{85})O(285) 仍然安全

对称密码和哈希函数受Grover算法影响较小（仅平方根加速），加倍密钥长度即可保持安全。公钥密码则需要全面替换。

格密码（Lattice-Based Cryptography）

格密码是NIST PQC标准化中最重要的方向，基于格上困难问题的计算复杂性。

基本概念：nnn 维格 L\mathcal{L}L 是 Rn\mathbb{R}^nRn 中的离散加法子群：

L(B)={∑i=1nzibi:zi∈Z}\mathcal{L}(\mathbf{B}) = \left\{\sum_{i=1}^n z_i \mathbf{b}_i : z_i \in \mathbb{Z}\right\}L(B)={i=1∑n​zi​bi​:zi​∈Z}

其中 B=[b1,…,bn]\mathbf{B} = [\mathbf{b}_1, \ldots, \mathbf{b}_n]B=[b1​,…,bn​] 为格基。

核心困难问题：

  • 最短向量问题（SVP）：找到格中最短非零向量
  • 学习有误差问题（LWE）：给定 (A,b=As+e)(\mathbf{A}, \mathbf{b} = \mathbf{A}\mathbf{s} + \mathbf{e})(A,b=As+e)，恢复秘密 s\mathbf{s}s

其中 A∈Zqm×n\mathbf{A} \in \mathbb{Z}_q^{m \times n}A∈Zqm×n​ 随机，s∈Zqn\mathbf{s} \in \mathbb{Z}_q^ns∈Zqn​ 为秘密，e\mathbf{e}e 为小高斯噪声。

LWE的困难性可以归约到最坏情况格问题，这是格密码安全性的理论基础。

NIST标准算法：

ML-KEM（原CRYSTALS-Kyber）—密钥封装：

  • 基于Module-LWE问题
  • 密钥大小：800-1568 bytes
  • 密文大小：768-1568 bytes
  • 安全级别：128/192/256 bit

ML-DSA（原CRYSTALS-Dilithium）—数字签名：

  • 基于Module-LWE和Module-SIS
  • 签名大小：2420-4595 bytes
  • 公钥大小：1312-2592 bytes

基于哈希的签名

哈希签名方案的安全性仅依赖于哈希函数的安全性，是最保守的PQC候选。

SPHINCS+（SLH-DSA）：

  • 无状态哈希签名
  • 安全性仅假设哈希函数抗原像
  • 签名较大（~17KB-50KB）但安全假设最少
  • 适合作为"备份方案"（hedging strategy）

XMSS和LMS：

  • 有状态哈希签名（更小的签名）
  • 要求严格维护状态计数器（不能重复使用密钥）
  • 已被NIST SP 800-208批准用于特定场景

其他PQC方向

基于编码的密码（Code-Based）：

  • 代表：Classic McEliece（NIST候选）
  • 基于随机线性码解码问题
  • 公钥极大（~260KB-1MB）但密文小且加解密快
  • 安全假设历史悠久（1978年McEliece系统）

基于多变量多项式（Multivariate）：

  • 求解多变量二次方程组（MQ问题）
  • 签名小且验证快
  • 公钥较大

基于同源映射（Isogeny-Based）：

  • 基于椭圆曲线同源问题
  • SIKE方案在2022年被经典攻击攻破
  • 新方案（如SQIsign）仍在研究中，密钥和签名非常紧凑

NIST标准化进程

NIST PQC标准化于2016年启动，经过多轮筛选：

时间线 事件
2016 征集提案（82个候选）
2019 第二轮（26个）
2020 第三轮（7+8个）
2024 FIPS 203/204/205发布（ML-KEM, ML-DSA, SLH-DSA）
2025-26 第4轮附加签名标准（HQC等）

量子安全迁移

迁移的紧迫性来自"Y2Q"（Years to Quantum）估计和数据保密期限的关系：

if Tharvest+Tmigration>Tquantum⇒现在就必须行动\text{if } T_{\text{harvest}} + T_{\text{migration}} > T_{\text{quantum}} \Rightarrow \text{现在就必须行动}if Tharvest​+Tmigration​>Tquantum​⇒现在就必须行动

混合方案（Hybrid）：在过渡期同时使用经典和PQC算法，确保即使PQC方案被攻破，经典方案仍提供保护：

Kfinal=KDF(Kclassical∥KPQC)K_{\text{final}} = \text{KDF}(K_{\text{classical}} \| K_{\text{PQC}})Kfinal​=KDF(Kclassical​∥KPQC​)

迁移优先级：

  1. 长期保密数据（政府/医疗/金融）→ 立即迁移
  2. TLS/VPN通信 → 部署混合方案
  3. 代码签名/固件更新 → 过渡到PQC签名
  4. 身份认证 → 最后阶段

  • 格密码参数调整：在对抗新型格攻击（如BKZ 2.0改进）的安全分析中，部分参数集进行了保守调整

小结
后量子密码学为量子计算威胁提供了经典密码学的解决方案。格密码（ML-KEM/ML-DSA）凭借效率和成熟度成为NIST标准的核心选择，哈希签名（SLH-DSA）提供了最保守的安全保障。全球密码基础设施的量子安全迁移已经启动——这不是一个是否需要迁移的问题，而是如何在保持系统可用性的前提下尽快完成迁移的工程挑战。
