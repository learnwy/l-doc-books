AIGC 创意应用

知识要点

生成式AI概述

AIGC（AI Generated Content）是指通过人工智能模型自动或辅助生成文本、图像、音频、视频、3D模型等内容的技术总称。2024—2026年间，AIGC从实验室走向大规模商业应用，正在重塑整个数字内容创作行业的工作流程和岗位结构。

核心技术路线：

  • 扩散模型（Diffusion Models）：当前图像/视频生成的主流架构。通过在噪声中逐步去噪恢复清晰图像。代表：Stable Diffusion、DALL-E 3、Midjourney
  • Transformer 架构：大语言模型（GPT-4、Claude）和多模态模型的基础。Attention 机制使模型能理解长距离语义依赖关系
  • 变分自编码器（VAE）：将高维数据压缩到低维潜空间再解码，常与扩散模型配合使用
  • 对抗生成网络（GAN）：生成器与判别器对抗训练。虽然已被扩散模型在图像质量上超越，但在实时生成和特定编辑任务中仍有优势

Prompt Engineering 作为创作语言

Prompt（提示词）是人类意图向AI模型的传达媒介。掌握 Prompt Engineering 已成为数字媒体创作者的必备技能：

文生图 Prompt 结构：

  1. 主体描述（Subject）：核心对象和动作
  2. 环境/场景（Environment）：背景、氛围、光照条件
  3. 风格指定（Style）：艺术风格、参考艺术家、媒介模拟
  4. 技术参数（Technical）：相机参数、渲染质量、画面比例
  5. 负面提示（Negative Prompt）：排除不想要的元素

示例结构分析：

主体: A cyberpunk samurai standing on a rooftop
环境: neon-lit Tokyo skyline at night, rain, volumetric fog
风格: in the style of Blade Runner, cinematic lighting, hyper-detailed
技术: 8K, octane render, dramatic composition, wide angle lens
负面: blurry, low quality, deformed hands, extra fingers

进阶技巧：

  • 权重控制：(element:1.5) 增强某元素影响力
  • 步骤控制：不同去噪阶段使用不同Prompt实现构图与细节分离
  • ControlNet：通过额外条件（边缘图、深度图、姿态骨架）精确控制生成结果的空间结构
  • IP-Adapter / Style Reference：上传参考图控制风格一致性
AI 图像生成工具链
Stable Diffusion 生态（开源生态最完善）：


    

  • ComfyUI：节点式工作流，精确控制生成管线每个环节。适合高级用户和生产环境
    • 

  • Automatic1111 WebUI：图形化界面，功能全面，社区插件丰富
    • 

  • 模型类型：Checkpoint（基础模型）、LoRA（轻量微调适配器）、Embedding（概念注入）
    • 

  • 关键工作流：txt2img → img2img → Inpainting → Outpainting → ControlNet
    • 



Midjourney（最强美学质量）：


    

  • 通过 Discord 或 Web 界面调用，无需本地算力
    • 

  • 擅长概念艺术、场景设计、角色概念图
    • 

  • V6.1 版本支持 --style raw 减少默认美化，--chaos 控制随机性
    • 



商业集成工具：


    

  • Adobe Firefly：原生集成到 PS/AI/Premiere，版权安全（仅用授权素材训练）
    • 

  • Canva AI：面向非专业用户的一键生成
    • 

  • Runway ML：视频生成和编辑专精（Gen-3 Alpha）
    • 



AI 视频与动画生成
2025—2026年视频生成领域取得突破性进展：


    

  • Sora（OpenAI）：支持60秒连贯视频生成，理解物理规律和镜头语言
    • 

  • Runway Gen-3 Alpha：10秒高质量视频，支持运动控制和风格迁移
    • 

  • Kling / 可灵（快手）：国产文生视频代表，动作流畅度领先
    • 

  • Pika：短视频生成+编辑一体化平台
    • 



当前局限：


    

  • 长视频一致性（角色/场景在多镜头间保持统一）仍是难题
    • 

  • 精确的物理模拟和手指/文字细节仍有瑕疵
    • 

  • 商业版权问题尚未完全解决
    • 



AI 辅助创作工作流设计
AIGC 最大的价值不是"替代人类"而是"重构工作流"：


概念设计阶段：


    

  • 传统：手绘草图(2天) → 精稿(3天) → 选定方向 → 精修(5天)
    • 

  • AI辅助：Prompt生成100个变体(30分钟) → 筛选方向 → 精修调整(2天)
    • 



素材生产阶段：


    

  • 纹理贴图：Substance Designer + AI 生成无缝贴图
    • 

  • 背景填充：Stable Diffusion Outpainting 扩展画面
    • 

  • 风格统一：IP-Adapter 确保系列作品的视觉一致性
    • 



后期优化阶段：


    

  • 超分辨率：4x放大低分辨率素材
    • 

  • 去背景：AI自动生成精确alpha通道
    • 

  • 画面修复：智能移除瑕疵和不需要的元素
    • 



伦理与版权边界
AIGC 创作面临的核心伦理问题：


    

  • 训练数据版权：模型使用互联网图片训练是否构成侵权？各国法律判定不一。欧盟 AI Act 要求标注 AI 生成内容
    • 

  • 作品归属：使用 AI 生成的图片，版权属于 Prompt 编写者、模型开发者、还是训练数据原作者？美国版权局2024年裁定"纯AI生成内容不受版权保护"
    • 

  • 深度伪造（Deepfake）：AI换脸和声音克隆的滥用风险。各国正在立法限制
    • 

  • 对就业市场的影响：初级概念设计师、素材摄影师、基础插画师等岗位面临重大冲击
    • 



前沿动态
2025—2026年，多模态大模型（如 GPT-4o、Gemini Ultra）实现了文本、图像、音频、视频的统一理解与生成，"对话式创作"成为现实——用户可以通过自然语言对话持续迭代一个创意项目。


"可控生成"是当前技术研究的核心方向。Character Consistency（角色一致性）技术允许AI在不同场景/姿态/光照下保持同一角色的外观统一，这使得AI辅助创作连续性叙事内容（漫画、动画分镜）成为可能。


中国的 AIGC 工具生态快速发展：字节跳动的即梦、百度的文心一格、智谱的 CogView、阿里的通义万相等平台在中文理解和国风美学方面展现出差异化优势。国内数字媒体艺术教育正在将 AIGC 素养纳入核心课程体系。


练习与思考
    

  1. 使用 Midjourney 或 Stable Diffusion 为一部虚构的科幻电影创建一套概念设计：5张角色概念图 + 5张场景概念图 + 3张道具设计图。保持视觉风格统一，记录最终使用的 Prompt 和关键参数。
    

    2. 

  2. 设计一个 ComfyUI 工作流节点图：输入一张人物照片和一种艺术风格参考图，输出保持人物特征但转换为目标艺术风格的图像。尝试 IP-Adapter + ControlNet 组合方案。
    

    3. 

  3. 对比纯手工创作和 AI 辅助创作的效率差异：选择一个插画主题，分别用纯手绘（Procreate）和 AI 辅助（AI生成底图→手动精修）两种方式完成，记录各阶段耗时和最终质量对比。
    

    4. 

  4. 研究一个 AIGC 版权争议案例（如 Getty Images v. Stability AI），分析双方论点，撰写 800 字的个人立场阐述。作为数字媒体艺术创作者，你认为合理的版权框架应该是什么？
    

    5. 

  5. 使用文生视频工具（Runway/Pika/可灵）尝试生成一个15秒的短片段。分析当前技术的能力边界：哪些镜头效果可以做到？哪些仍然失败？物理准确度如何？
    

    6. 



小结
AIGC 不是数字媒体艺术的终结者，而是一次范式转移——它将创作的瓶颈从"执行能力"转移到"审美判断力"和"创意方向力"。掌握 Prompt Engineering 只是起点，真正重要的是理解AI工具的能力边界、设计高效的人机协作工作流、以及在"一切都可以生成"的时代依然保持清晰的创作立场和独特的美学追求。
