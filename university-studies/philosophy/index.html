01 哲学 (Philosophy)哲学 简介

哲学 简介

本 hub 是哲学学科的全景地图：第一章西方哲学、第二章东方哲学铺出两千五百年思想的时间纵轴，第三章形而上学与认识论、第四章哲学方法论铺出核心问题与研究方法的横轴。它的目标是让自学者在十二篇文档内建立"谁在何时、用什么方法回答了什么问题"的整体框架——而不是替代任何一门分支课的系统训练。需要深入某个分支时，请按下面的分工边界进入对应的兄弟 hub。

与兄弟 hub 的分工边界

01_philosophy 目录下共有五个 hub，按"总—分"排列：本 hub 承担"总"的角色，其余四个各自深入一个分支。

Hub 核心问题 与本 hub 的边界
1_philosophy（本 hub） 哲学整体：东西方哲学史脉络 + 存在、知识、心灵等核心议题 + 三种方法论 只做地图与骨架，每个分支点到为止，并给出继续深入的接口
2_logic 逻辑学 推理的有效性本身：命题/谓词/模态逻辑的形式系统、非形式谬误、数学逻辑 本 hub 第四章只把"逻辑分析"当作一种哲学方法来介绍；要做符号推演、真值表与谬误识别训练，去逻辑学 hub
3_ethics 伦理学 应当如何生活与行动：美德/义务论/后果主义、应用伦理、元伦理 本 hub 只在哲学史中顺带遇到伦理立场（如亚里士多德的中道、孔子的仁）；系统的道德推理与当代议题在伦理学 hub
4_philosophy-of-science 科学技术哲学 科学何以是知识典范：划界问题、范式革命、技术哲学、科学技术与社会 本 hub 提到波普尔的可证伪性时只作为哲学史环节；归纳难题、库恩与技术之思在科技哲学 hub 展开
5_religious-studies 宗教学 宗教作为人类现象：世界宗教、宗教与社会、中国宗教 本 hub 讲佛教与印度哲学是在哲学体系内部梳理概念（缘起、梵我）；宗教学 hub 处理信仰实践与社会组织，不做教义辨析

一句话记忆：先在本 hub 看懂地图，再按需进入四个分支 hub 深耕。

推荐学习路径

四条路径覆盖不同起点，章节编号对应本 hub 目录：

零基础通识（最常见的读法）

  1. 第一章西方哲学三篇：建立"问题如何被提出、又如何被改造"的历史感；
  2. 第二章东方哲学三篇：在对照中意识到"哲学"不等于西方哲学；
  3. 第三章形而上学与认识论：把历史中反复出现的追问提炼为概念工具；
  4. 第四章方法论三篇：最后回头看，会发现哲学史同时也是方法的历史。

东方思想优先者：第二章 → 第一章 → 第三章 → 第四章。先在熟悉的中国、佛教、印度语境中建立信心，再进入西方脉络；第三、四章顺序不变。

技术 / AI 从业者：第三章《心灵哲学》 → 第四章《逻辑分析方法》 → 第一章三篇补历史语境 → 第二章选读《佛教哲学》（关于意识与自我的另一套分析）。这条路径直指当下争论：大模型有没有"理解"、意识能否被功能化、语法与语义的关系。

备考 / 系统学习者：严格按一至四章顺序推进，每篇完成"练习与思考"后再进入下一篇；第三章可与第一章同时段对读（如读康德时回看《近代西方哲学》），第四章收尾后即可无缝衔接逻辑学 hub 的形式逻辑训练。

前置知识

  • 没有硬性门槛：十二篇均为中文写作，专业术语首次出现时都附原文与解释，高中水平即可从第一、二章开始。
  • 有帮助的背景：中学历史的三条线索（古希腊、春秋战国、近代欧洲）能让哲学史章节的时间坐标立刻落地。
  • 第三章注意：本体论与认识论抽象度最高，建议至少读完前两章再进入；《心灵哲学》只涉及思想实验推理，不需要任何科学公式。
  • 第四章注意：《逻辑分析方法》出现谓词逻辑符号，若感到吃力，可先去逻辑学 hub 补形式逻辑第一课再回来，不影响主线。
  • 原典意识：每篇的"拓展阅读"都注明了中译本出处；本 hub 是地图，真正的功夫仍要回到柏拉图、孔子、康德这些原典本身。

延伸阅读（兄弟 hub 入口）

  • 逻辑学——把本 hub 第四章的"逻辑分析"变成可操练的形式系统。
  • 伦理学——接续亚里士多德的中道与孔子的仁，进入系统的道德推理。
  • 科学技术哲学——深挖波普尔、库恩与划界问题的完整论证。
  • 宗教学——换一种经验科学的目光，重新审视佛教与印度诸传统。
