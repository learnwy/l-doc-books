大学材料科学 — 相图

知识要点

相图是材料科学家和冶金工程师最重要的工具之一，它以图形方式表示在给定成分和温度下系统中稳定存在的相及其比例。无论是设计合金成分、制定热处理工艺还是预测凝固组织，相图都是不可或缺的参考依据。本节从热力学基础出发，系统讲解一元和二元相图的读取与应用。

基本概念

  • 相（Phase）：系统中物理和化学性质均匀的部分，如液相、α\alphaα 固溶体、Fe3C\text{Fe}_3\text{C}Fe3​C 化合物等
  • 组元（Component）：描述系统成分所需的最少独立化学物质数
  • 自由度（Degree of Freedom）：在不改变相数的前提下可以独立变化的热力学变量数

吉布斯相律

吉布斯相律是相图分析的理论基石：

F=C−P+2F = C - P + 2F=C−P+2

其中 FFF 为自由度，CCC 为组元数，PPP 为相数。对于压力恒定的凝聚态系统（大多数冶金场景），简化为：

F=C−P+1F = C - P + 1F=C−P+1

详细讲解

一元相图

以纯铁为例，一元相图（温度-压力图）展示了单一组元的相稳定区域。纯铁在常压下的相变序列为：

δ-Fe (1538°C)→γ-Fe (1394°C)→α-Fe (912°C)\delta\text{-Fe}\,(1538°\text{C}) \to \gamma\text{-Fe}\,(1394°\text{C}) \to \alpha\text{-Fe}\,(912°\text{C})δ-Fe(1538°C)→γ-Fe(1394°C)→α-Fe(912°C)

其中 γ\gammaγ-Fe 为 FCC 结构（奥氏体），α\alphaα-Fe 为 BCC 结构（铁素体）。这些同素异构转变是钢铁热处理的物理基础。

二元匀晶相图

当两种组元在液态和固态均完全互溶时，形成匀晶相图（如 Cu-Ni 系统）。相图由液相线和固相线将温度-成分空间划分为三个区域：

  • 液相线以上：完全液相
  • 固相线以下：完全固溶体
  • 两线之间：液相 + 固溶体两相共存

在两相区内，利用杠杆定律（Lever Rule） 计算各相的相对含量。设总成分为 C0C_0C0​，液相成分为 CLC_LCL​，固相成分为 CSC_SCS​：

固相质量分数=C0−CLCS−CL\text{固相质量分数} = \frac{C_0 - C_L}{C_S - C_L}固相质量分数=CS​−CL​C0​−CL​​
液相质量分数=CS−C0CS−CL\text{液相质量分数} = \frac{C_S - C_0}{C_S - C_L}液相质量分数=CS​−CL​CS​−C0​​

共晶相图

共晶相图（如 Pb-Sn 系统）是工程中最常见的二元相图类型。其核心特征是存在一个共晶点，在该成分和温度下液相同时结晶出两种固相：

L→α+β(共晶反应)L \to \alpha + \beta \quad (\text{共晶反应})L→α+β(共晶反应)

共晶反应是恒温反应（F=0F = 0F=0），在冷却曲线上表现为一段温度平台。

共晶组织通常呈层片状或棒状，两相交替排列，层片间距 λ\lambdaλ 与冷却速率 T˙\dot{T}T˙ 的关系为：

λ2T˙≈const\lambda^2 \dot{T} \approx \text{const}λ2T˙≈const

快速冷却产生细小层片，力学性能更优。

Fe-C 相图

Fe-C 相图是材料科学中应用最广泛的相图，它是所有钢铁热处理的理论基础。关键特征点：

特征 温度 碳含量 反应类型
共晶点 1148°C1148°\text{C}1148°C 4.3%4.3\%4.3% C L→γ+Fe3CL \to \gamma + \text{Fe}_3\text{C}L→γ+Fe3​C
共析点 727°C727°\text{C}727°C 0.77%0.77\%0.77% C γ→α+Fe3C\gamma \to \alpha + \text{Fe}_3\text{C}γ→α+Fe3​C
包晶点 1495°C1495°\text{C}1495°C 0.17%0.17\%0.17% C L+δ→γL + \delta \to \gammaL+δ→γ

共析反应是钢的热处理核心：奥氏体在缓冷过程中分解为铁素体和渗碳体的层片状混合物，即珠光体（Pearlite）。

按碳含量，钢分为：

  • 亚共析钢（C<0.77%C < 0.77\%C<0.77%）：先析出铁素体，剩余奥氏体发生共析转变
  • 共析钢（C=0.77%C = 0.77\%C=0.77%）：全部转变为珠光体
  • 过共析钢（C>0.77%C > 0.77\%C>0.77%）：先析出渗碳体网，剩余奥氏体发生共析转变

相图的热力学基础

相图本质上是自由能最低原理的图形表达。在给定温度下，系统总自由能为各相自由能的加权和：

Gtotal=∑ifiGiG_{\text{total}} = \sum_i f_i G_iGtotal​=i∑​fi​Gi​

系统自发地趋向总自由能最低的状态。两相共存的条件是两相的化学势相等：

μAα=μAβ,μBα=μBβ\mu_A^{\alpha} = \mu_A^{\beta}, \quad \mu_B^{\alpha} = \mu_B^{\beta}μAα​=μAβ​,μBα​=μBβ​

利用自由能-成分曲线的公切线法，可以从热力学数据计算出相图。CALPHAD 方法正是基于这一原理，利用热力学数据库计算多元合金的相图。

练习与思考

  1. 在 Cu-Ni 相图中，成分为 40% Ni40\%\,\text{Ni}40%Ni 的合金在 1250°C1250°\text{C}1250°C 时处于两相区。若此时液相含 32% Ni32\%\,\text{Ni}32%Ni，固相含 45% Ni45\%\,\text{Ni}45%Ni，利用杠杆定律计算液相和固相的质量分数。
  2. 解释为什么共晶合金的流动性好、凝固温度范围窄，因此常被用作焊料和铸造合金。
  3. 含 0.4%0.4\%0.4% C 的亚共析钢从 900°C900°\text{C}900°C 缓慢冷却至室温，画出冷却过程中的组织变化示意图，并计算室温下铁素体和珠光体的比例。
  4. 在 Fe-C 相图中，为什么碳含量超过 2.11%2.11\%2.11% 的合金称为铸铁而非钢？从力学性能角度分析。
  5. 查阅 CALPHAD 方法的基本原理。它如何从二元相图数据外推计算三元及多元合金的相平衡？

拓展阅读

  • Porter, Easterling & Sherif,《Phase Transformations in Metals and Alloys》全面覆盖了相变的热力学和动力学
  • ASM International 的 Alloy Phase Diagrams 数据库收录了数千个合金体系的实验相图
  • Thermo-Calc 和 PANDAT 是基于 CALPHAD 方法的商业相图计算软件，广泛应用于合金设计
  • Fe-C 相图虽然是最经典的相图，但真实钢中还含有 Mn、Si、Cr 等合金元素，需要使用多元相图或热力学软件来精确预测

小结

相图将热力学原理转化为直观的工程工具，通过温度-成分坐标清晰展示相的稳定区域和转变反应。吉布斯相律提供了分析框架，杠杆定律实现了定量计算，而 Fe-C 相图则是钢铁材料所有热处理工艺的理论地图。理解相图不仅需要记住特征点和温度，更要从自由能的角度理解为什么在特定条件下会形成特定的相组合。
