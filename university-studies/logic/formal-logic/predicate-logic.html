谓词逻辑

知识要点

谓词逻辑（Predicate Logic），又称一阶逻辑（First-Order Logic, FOL），是命题逻辑的自然扩展。命题逻辑将原子命题视为不可分割的整体，而谓词逻辑深入命题内部，分析个体、性质和关系的结构，并引入量词来表达「所有」和「存在」这两类关键断言。弗雷格在1879年创建的概念文字标志着谓词逻辑的诞生，它从根本上改变了逻辑学的面貌，使亚里士多德三段论无法处理的推理形式得到了精确的形式化。一阶谓词逻辑至今仍是数学基础、计算机科学和哲学论证分析的标准工具。

详细讲解

从命题逻辑到谓词逻辑

命题逻辑的表达力有一个明显的瓶颈。考虑经典的三段论推理：「所有人都会死；苏格拉底是人；所以苏格拉底会死。」在命题逻辑中，三个句子只能被表示为三个独立的命题变元 ppp, qqq, rrr，它们之间的逻辑关联完全无法被捕捉——命题逻辑无法「看到」这三个句子共享「人」和「苏格拉底」这些成分。

谓词逻辑通过引入以下要素解决了这个问题：

个体变元与常元：x,y,z,…x, y, z, \ldotsx,y,z,… 是个体变元，代表论域中的不确定对象；a,b,c,…a, b, c, \ldotsa,b,c,… 是个体常元，代表特定对象。例如，sss 可以代表苏格拉底。

谓词符号：P,Q,R,…P, Q, R, \ldotsP,Q,R,… 是谓词，表示性质或关系。P(x)P(x)P(x) 表示「xxx 具有性质 PPP」；R(x,y)R(x, y)R(x,y) 表示「xxx 和 yyy 之间有关系 RRR」。例如，H(x)H(x)H(x) 表示「xxx 是人」，M(x)M(x)M(x) 表示「xxx 会死」。

函数符号：f,g,…f, g, \ldotsf,g,… 是函数，将个体映射到个体。例如，f(x)f(x)f(x) 可以表示「xxx 的父亲」。

量词

量词是谓词逻辑的核心创新：

全称量词（∀\forall∀）：∀x P(x)\forall x \, P(x)∀xP(x) 表示「对论域中所有 xxx，P(x)P(x)P(x) 成立」。「所有人都会死」形式化为 ∀x(H(x)→M(x))\forall x (H(x) \rightarrow M(x))∀x(H(x)→M(x))。

存在量词（∃\exists∃）：∃x P(x)\exists x \, P(x)∃xP(x) 表示「论域中存在某个 xxx，使得 P(x)P(x)P(x) 成立」。「有人是哲学家」形式化为 ∃x(H(x)∧Ph(x))\exists x (H(x) \wedge Ph(x))∃x(H(x)∧Ph(x))。

全称命题使用蕴涵（→\rightarrow→）而非合取（∧\wedge∧）来连接谓词，这是初学者常犯的错误。∀x(H(x)∧M(x))\forall x (H(x) \wedge M(x))∀x(H(x)∧M(x)) 的含义是「一切东西都既是人又会死」——这显然过强了。而 ∀x(H(x)→M(x))\forall x (H(x) \rightarrow M(x))∀x(H(x)→M(x)) 正确地表达了「凡是人的东西就会死」。

存在命题则使用合取：∃x(H(x)∧Ph(x))\exists x (H(x) \wedge Ph(x))∃x(H(x)∧Ph(x)) 意为「存在某个东西，它既是人又是哲学家」。若写成 ∃x(H(x)→Ph(x))\exists x (H(x) \rightarrow Ph(x))∃x(H(x)→Ph(x))，则只要存在任何非人之物（如一块石头），命题就为真——这太弱了。

自由变元与约束变元

在公式 ∀x P(x,y)\forall x \, P(x, y)∀xP(x,y) 中，xxx 被全称量词约束，称为约束变元；yyy 没有被任何量词约束，称为自由变元。含有自由变元的公式不是命题（没有确定真值），而是一个开公式；所有变元都被约束的公式称为闭公式（句子），具有确定的真值。

变元的约束范围（辖域）由量词后面的公式决定。在 ∀x P(x)∧Q(x)\forall x \, P(x) \wedge Q(x)∀xP(x)∧Q(x) 中，如果理解为 (∀x P(x))∧Q(x)(\forall x \, P(x)) \wedge Q(x)(∀xP(x))∧Q(x)，则第二个 Q(x)Q(x)Q(x) 中的 xxx 是自由的；但如果理解为 ∀x (P(x)∧Q(x))\forall x \, (P(x) \wedge Q(x))∀x(P(x)∧Q(x))，则两个 xxx 都被约束。因此，量词辖域的括号不可省略。

形式化表达实例

谓词逻辑的表达力通过以下实例可以直观感受：

「没有人能同时欺骗所有人」：

¬∃x(H(x)∧∀y(H(y)→D(x,y)))\neg \exists x (H(x) \wedge \forall y (H(y) \rightarrow D(x, y)))¬∃x(H(x)∧∀y(H(y)→D(x,y)))

其中 D(x,y)D(x, y)D(x,y) 表示「xxx 欺骗 yyy」。

「每个人都有至少一个朋友」：

∀x(H(x)→∃y(H(y)∧F(x,y)∧x≠y))\forall x (H(x) \rightarrow \exists y (H(y) \wedge F(x, y) \wedge x \neq y))∀x(H(x)→∃y(H(y)∧F(x,y)∧x=y))

「恰好存在一个满足 PPP 的个体」：

∃x(P(x)∧∀y(P(y)→y=x))\exists x (P(x) \wedge \forall y (P(y) \rightarrow y = x))∃x(P(x)∧∀y(P(y)→y=x))

这正是罗素摹状词理论中「唯一性条件」的形式化表达，它在分析哲学中扮演了关键角色。

语义：结构与解释

谓词逻辑的语义通过结构（Structure，也称模型或解释）来定义。一个结构 M=(D,I)\mathcal{M} = (D, I)M=(D,I) 包含：

  • 论域 DDD：一个非空集合，包含所有讨论对象。
  • 解释函数 III：为每个常元指派 DDD 中的元素，为每个 nnn 元谓词指派 DnD^nDn 的一个子集，为每个 nnn 元函数指派 Dn→DD^n \to DDn→D 的一个映射。

例如，论域 D={1,2,3}D = \{1, 2, 3\}D={1,2,3}，PPP 解释为「是偶数」（即 {2}\{2\}{2}），则 ∀x P(x)\forall x \, P(x)∀xP(x) 为假，∃x P(x)\exists x \, P(x)∃xP(x) 为真。

一个公式在某个结构中为真，称该结构满足（satisfy）该公式。一个公式在所有结构中为真，称其为逻辑有效的（logically valid）。

推理规则

谓词逻辑在命题逻辑推理规则的基础上增加了四条量词规则：

全称实例化（∀\forall∀-消除）：从 ∀x P(x)\forall x \, P(x)∀xP(x) 可得 P(t)P(t)P(t)，其中 ttt 是论域中的任意项。

全称概括（∀\forall∀-引入）：若 P(a)P(a)P(a) 对任意的 aaa 成立（aaa 在推理过程中无特殊假设），可得 ∀x P(x)\forall x \, P(x)∀xP(x)。

存在实例化（∃\exists∃-消除）：从 ∃x P(x)\exists x \, P(x)∃xP(x) 可引入一个新常元 ccc，假设 P(c)P(c)P(c) 成立（ccc 不能在推理其他地方出现）。

存在概括（∃\exists∃-引入）：从 P(t)P(t)P(t) 可得 ∃x P(x)\exists x \, P(x)∃xP(x)。

利用这些规则，苏格拉底三段论可以形式化证明：

  1. ∀x(H(x)→M(x))\forall x (H(x) \rightarrow M(x))∀x(H(x)→M(x)) （前提）
  2. H(s)H(s)H(s) （前提）
  3. H(s)→M(s)H(s) \rightarrow M(s)H(s)→M(s) （由1，∀\forall∀-消除）
  4. M(s)M(s)M(s) （由2、3，肯定前件式）

一阶逻辑的元理论

哥德尔在1930年证明了一阶逻辑的完备性定理：所有逻辑有效的公式都可以在形式系统中被证明。这是一个极为深刻的结果——语义上的「真」和语法上的「可证」在一阶逻辑中完美对齐。

然而，一阶逻辑也有其局限。Church和图灵在1936年分别独立证明了一阶逻辑的不可判定性：不存在一个算法能判定任意一阶公式是否为逻辑有效的。与命题逻辑的可判定性相比，这标志着表达力提升所带来的计算代价。

练习与思考

  1. 将以下自然语言句子形式化为一阶逻辑公式：(a)「所有猫都怕水」；(b)「有些鸟不会飞」；(c)「如果一个人是所有人的朋友，那么他是快乐的」。

  2. 判断以下公式是否逻辑等值：¬∀x P(x)\neg \forall x \, P(x)¬∀xP(x) 与 ∃x ¬P(x)\exists x \, \neg P(x)∃x¬P(x)。用语义直觉解释为什么。

  3. 为什么全称命题用 →\rightarrow→ 连接谓词，而存在命题用 ∧\wedge∧？如果反过来写会出什么问题？请用具体例子说明。

  4. 哥德尔完备性定理说的是一阶逻辑「足够强」——所有真理都可证。但他的不完备性定理说的是什么？两者是否矛盾？

  5. 为什么说谓词逻辑是弗雷格对逻辑学最重大的贡献？它解决了亚里士多德逻辑的哪些局限？

拓展阅读

  • 弗雷格《概念文字》（Begriffsschrift）：现代谓词逻辑的创始文献，尽管符号系统已过时，但思想仍具启发性。
  • Enderton《A Mathematical Introduction to Logic》第2章：谓词逻辑的标准数学处理。
  • 陈波《逻辑学导论》第4-5章：中文教材中对谓词逻辑的系统讲解。
  • van Dalen《Logic and Structure》：兼具数学严谨性和哲学洞察力的逻辑教材。
  • 汉密尔顿《数理逻辑》（Hamilton, Logic for Mathematicians）：适合有一定数学基础的读者。

小结

谓词逻辑通过引入个体、谓词和量词，突破了命题逻辑的表达瓶颈，使复杂的推理形式——从三段论到数学证明——得以精确形式化。它的完备性保证了形式推理的可靠性，而其不可判定性则揭示了表达力与计算复杂度之间的深层张力。一阶谓词逻辑至今仍是逻辑学的「标准语言」，是进入模态逻辑、数学逻辑和计算机科学形式化方法的必经之路。
