集合论基础

知识要点

集合论是现代数学的基础语言。几乎所有数学概念——数、函数、关系、空间——都可以用集合论的语言来定义。策梅洛-弗兰克尔集合论加上选择公理（简称 ZFC）是当前数学界最广泛接受的公理化集合论系统。理解 ZFC 的基本框架，对于把握现代数学和逻辑学的根基至关重要。

集合论的基本直觉很简单：一个集合是由确定的、彼此不同的对象组成的整体。这些对象称为集合的元素。用符号 a∈Aa \in Aa∈A 表示 aaa 是集合 AAA 的元素。但这个朴素直觉存在严重问题——罗素悖论（Russell's Paradox）表明，允许随意构造集合会导致矛盾。

罗素悖论的构造如下：令 R={x∣x∉x}R = \{x \mid x \notin x\}R={x∣x∈/x}，即所有不包含自身的集合的集合。那么 R∈RR \in RR∈R 吗？如果 R∈RR \in RR∈R，则按定义 R∉RR \notin RR∈/R；如果 R∉RR \notin RR∈/R，则按定义 R∈RR \in RR∈R。这是一个真正的逻辑矛盾。ZFC 公理系统的目标之一就是在保留集合论强大表达能力的同时，避免这类悖论。

ZFC 系统的核心思想是：不允许"所有集合的集合"这样的对象存在，集合只能通过受限的方式从已有集合中构造出来。这就是所谓的迭代集合观——集合是从空集出发、层层构造的。

详细讲解

ZFC 公理系统

ZFC 包含以下公理（或公理模式）：

公理 名称 核心内容
外延公理 Extensionality 两个集合相等当且仅当它们有完全相同的元素
空集公理 Empty Set 存在一个没有任何元素的集合 ∅\emptyset∅
配对公理 Pairing 对任意 a,ba, ba,b，存在集合 {a,b}\{a, b\}{a,b}
并集公理 Union 对任意集合族，存在其并集
幂集公理 Power Set 对任意集合 AAA，存在 AAA 的所有子集组成的集合 P(A)\mathcal{P}(A)P(A)
分离公理模式 Separation 可以从已有集合中筛选满足某性质的元素组成子集
替换公理模式 Replacement 函数作用于集合上的像仍是集合
无穷公理 Infinity 存在一个包含所有自然数的无穷集合
正则公理 Foundation/Regularity 每个非空集合都有一个关于 ∈\in∈ 的极小元素
选择公理 Choice (AC) 对任意非空集合族，存在选择函数

外延公理确立了集合的同一性标准：集合完全由其元素决定。两个集合 AAA 和 BBB 相等，记为 A=BA = BA=B，当且仅当：

∀x(x∈A↔x∈B)\forall x(x \in A \leftrightarrow x \in B)∀x(x∈A↔x∈B)

分离公理模式（也称概括公理模式）是避免罗素悖论的关键。朴素集合论允许 {x∣φ(x)}\{x \mid \varphi(x)\}{x∣φ(x)} 的构造（对任意性质 φ\varphiφ），分离公理将其限制为 {x∈A∣φ(x)}\{x \in A \mid \varphi(x)\}{x∈A∣φ(x)}——只能从已有集合 AAA 中分离出满足条件的子集，不能凭空构造。

正则公理（基础公理）禁止集合的"自我包含"。它保证不存在无穷下降的 ∈\in∈ 链：⋯∈a3∈a2∈a1\cdots \in a_3 \in a_2 \in a_1⋯∈a3​∈a2​∈a1​。这也意味着没有集合可以是自身的元素。

序数理论

序数（ordinal number）是 ZFC 中最重要的概念之一。直观地说，序数编码了"排列的类型"——它不关心集合中的元素是什么，只关心元素之间的排列顺序。

一个集合 α\alphaα 是序数，当且仅当：

  1. α\alphaα 对 ∈\in∈ 关系是传递的：若 β∈α\beta \in \alphaβ∈α 且 γ∈β\gamma \in \betaγ∈β，则 γ∈α\gamma \in \alphaγ∈α。
  2. α\alphaα 对 ∈\in∈ 关系是良序的。

最小的几个序数用冯·诺依曼构造如下：

0=∅,1={0}={∅},2={0,1}={∅,{∅}},3={0,1,2},…0 = \emptyset, \quad 1 = \{0\} = \{\emptyset\}, \quad 2 = \{0, 1\} = \{\emptyset, \{\emptyset\}\}, \quad 3 = \{0, 1, 2\}, \quad \ldots0=∅,1={0}={∅},2={0,1}={∅,{∅}},3={0,1,2},…

每个自然数 nnn 的后继是 n+1=n∪{n}n + 1 = n \cup \{n\}n+1=n∪{n}。所有有限序数就是自然数。

第一个无穷序数是 ω\omegaω，它是所有自然数的集合 {0,1,2,3,…}\{0, 1, 2, 3, \ldots\}{0,1,2,3,…}。无穷公理保证了 ω\omegaω 的存在。在 ω\omegaω 之后，序数继续延伸：ω+1=ω∪{ω}\omega + 1 = \omega \cup \{\omega\}ω+1=ω∪{ω}，ω+2\omega + 2ω+2，…\ldots…，ω⋅2\omega \cdot 2ω⋅2，…\ldots…，ω2\omega^2ω2，…\ldots…，ωω\omega^\omegaωω，…\ldots…

序数分为三类：

  • 零：0=∅0 = \emptyset0=∅
  • 后继序数：形如 α+1\alpha + 1α+1 的序数
  • 极限序数：不是零也不是后继序数，如 ω,ω⋅2,ωω\omega, \omega \cdot 2, \omega^{\omega}ω,ω⋅2,ωω

超穷递归（transfinite recursion）是序数上最强大的构造原则。如果我们定义了：

  • 初始值 f(0)f(0)f(0)
  • 后继步骤 f(α+1)f(\alpha + 1)f(α+1) 取决于 f(α)f(\alpha)f(α)
  • 极限步骤 f(λ)f(\lambda)f(λ) 取决于 {f(β)∣β<λ}\{f(\beta) \mid \beta < \lambda\}{f(β)∣β<λ}

那么函数 fff 在所有序数上就被唯一确定了。

基数理论

基数（cardinal number）衡量集合的"大小"。两个集合 AAA 和 BBB 是等势的（equinumerous），记为 ∣A∣=∣B∣|A| = |B|∣A∣=∣B∣，当且仅当存在从 AAA 到 BBB 的双射。

对于有限集合，基数就是元素个数。但对于无穷集合，情况变得微妙。康托尔的关键发现是：

康托尔定理：对任意集合 AAA，∣A∣<∣P(A)∣|A| < |\mathcal{P}(A)|∣A∣<∣P(A)∣。

这意味着幂集总是严格"更大"。特别地，∣N∣<∣P(N)∣=∣R∣|\mathbb{N}| < |\mathcal{P}(\mathbb{N})| = |\mathbb{R}|∣N∣<∣P(N)∣=∣R∣——实数集严格大于自然数集。

无穷基数用 ℵ\alephℵ（aleph）符号表示：

  • ℵ0=∣N∣\aleph_0 = |\mathbb{N}|ℵ0​=∣N∣，最小的无穷基数
  • ℵ1\aleph_1ℵ1​ 是比 ℵ0\aleph_0ℵ0​ 大的最小无穷基数
  • ℵα\aleph_{\alpha}ℵα​ 对应第 α\alphaα 个无穷基数

连续统假设（Continuum Hypothesis, CH）断言 ∣R∣=ℵ1|\mathbb{R}| = \aleph_1∣R∣=ℵ1​，即自然数集与实数集之间不存在中间大小的无穷集合。哥德尔（1940）证明 CH 与 ZFC 相容，科恩（1963）证明 CH 的否定也与 ZFC 相容。因此 CH 独立于 ZFC——在 ZFC 中既不能证明也不能反驳。

选择公理

选择公理（AC）是 ZFC 中最具争议性的公理。它说：对任意非空集合的集合族 {Ai}i∈I\{A_i\}_{i \in I}{Ai​}i∈I​（每个 Ai≠∅A_i \neq \emptysetAi​=∅），存在一个选择函数 fff 使得 f(i)∈Aif(i) \in A_if(i)∈Ai​。

对于有限集合族，选择函数的存在不需要额外公理。AC 的力量在于它保证了无穷集合族的选择函数存在——即使我们无法写出一个具体的选择规则。

AC 的等价命题包括：

  • 佐恩引理：每个非空偏序集，若其每条链都有上界，则有极大元。
  • 良序定理：每个集合都可以被良序化。
  • 基数可比较性：任意两个基数 ∣A∣|A|∣A∣ 和 ∣B∣|B|∣B∣ 要么 ∣A∣≤∣B∣|A| \leq |B|∣A∣≤∣B∣ 要么 ∣B∣≤∣A∣|B| \leq |A|∣B∣≤∣A∣。

AC 的争议在于它是纯粹的存在性断言——它保证选择函数存在，但不提供构造方法。接受 AC 会导致一些直觉上令人不安的结论，如巴拿赫-塔斯基悖论：一个球可以被分成有限多块，重新组合成两个与原来一样大的球。

练习与思考

  1. 证明罗素悖论：假设存在"所有集合的集合" VVV，利用分离公理构造 R={x∈V∣x∉x}R = \{x \in V \mid x \notin x\}R={x∈V∣x∈/x}，推出矛盾。然后解释为什么 ZFC 中不存在这样的 VVV。

  2. 写出前五个序数 0,1,2,3,40, 1, 2, 3, 40,1,2,3,4 的冯·诺依曼表示，并验证每个序数确实是其所有元素的集合。

  3. 证明 ∣N∣=∣Z∣|\mathbb{N}| = |\mathbb{Z}|∣N∣=∣Z∣（构造一个从自然数到整数的双射）。然后思考：∣Q∣|\mathbb{Q}|∣Q∣ 与 ∣N∣|\mathbb{N}|∣N∣ 的关系如何？提示：使用对角线方法。

  4. 思考选择公理的哲学问题：一个数学定理如果依赖选择公理，它的"真实性"与不依赖 AC 的定理有什么不同？构造主义数学家为什么反对 AC？

  5. 连续统假设独立于 ZFC，这对"数学真理"的本质意味着什么？是否意味着数学中存在"永远无法确定"的命题？

拓展阅读

  • 库能（Kenneth Kunen）《集合论导引》——研究生阶段集合论的标准教材，涵盖力迫法和大基数。
  • 恩德顿（Herbert Enderton）《集合论基础》——适合本科生的集合论入门，证明清晰详细。
  • 科恩（Paul Cohen）《集合论与连续统假设》——力迫法发明者的原始论述，适合了解 CH 独立性证明的思路。
  • 康托尔的对角线论证是数学史上最优美的证明之一，建议阅读原始论文的现代解读版本。
  • 对集合论哲学问题感兴趣的读者，可以了解"多元宇宙观"（multiverse view）——认为存在多个同样合法的集合论宇宙。

小结

ZFC 集合论通过精心设计的公理系统，在避免罗素悖论等困难的同时，为数学提供了统一的基础语言。序数编码了良序结构，基数衡量集合的大小，两者共同构成了无穷数学的骨架。选择公理和连续统假设的独立性则揭示了公理化方法的深刻局限——有些数学命题在特定公理系统中是不可判定的，这迫使我们重新思考数学真理的本质。
