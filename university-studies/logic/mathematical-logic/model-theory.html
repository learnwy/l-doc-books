模型论

知识要点

模型论研究形式语言与其解释之间的关系。如果说语法（syntax）关注的是符号串的形式规则，那么模型论关注的是语义（semantics）——这些符号串在什么意义上为"真"。模型论的核心问题是：给定一个形式理论，什么样的数学结构能够满足这个理论的所有公理？

一个结构（structure）是模型论的基本对象。对于一阶语言 L\mathcal{L}L，一个 L\mathcal{L}L-结构 A\mathfrak{A}A 包含：

  • 一个非空集合 AAA，称为论域（domain/universe）
  • 对 L\mathcal{L}L 中每个常量符号 ccc，一个元素 cA∈Ac^{\mathfrak{A}} \in AcA∈A
  • 对每个 nnn 元关系符号 RRR，一个 nnn 元关系 RA⊆AnR^{\mathfrak{A}} \subseteq A^nRA⊆An
  • 对每个 nnn 元函数符号 fff，一个函数 fA:An→Af^{\mathfrak{A}}: A^n \to AfA:An→A

满足关系（satisfaction）是连接语法和语义的桥梁。给定一个结构 A\mathfrak{A}A 和一个赋值 sss（将变量映射到论域元素），满足关系 A⊨φ[s]\mathfrak{A} \models \varphi[s]A⊨φ[s] 递归地定义了"公式 φ\varphiφ 在结构 A\mathfrak{A}A 中、在赋值 sss 下为真"的含义。如果一个语句（没有自由变量的公式）σ\sigmaσ 在结构 A\mathfrak{A}A 中为真，我们写作 A⊨σ\mathfrak{A} \models \sigmaA⊨σ，称 A\mathfrak{A}A 是 σ\sigmaσ 的一个模型。

详细讲解

满足关系的递归定义

满足关系的定义遵循公式的结构归纳：

对原子公式：

  • A⊨(t1=t2)[s]\mathfrak{A} \models (t_1 = t_2)[s]A⊨(t1​=t2​)[s] 当且仅当 t1A[s]=t2A[s]t_1^{\mathfrak{A}}[s] = t_2^{\mathfrak{A}}[s]t1A​[s]=t2A​[s]
  • A⊨R(t1,…,tn)[s]\mathfrak{A} \models R(t_1, \ldots, t_n)[s]A⊨R(t1​,…,tn​)[s] 当且仅当 (t1A[s],…,tnA[s])∈RA(t_1^{\mathfrak{A}}[s], \ldots, t_n^{\mathfrak{A}}[s]) \in R^{\mathfrak{A}}(t1A​[s],…,tnA​[s])∈RA

对复合公式：

  • A⊨¬φ[s]\mathfrak{A} \models \neg\varphi[s]A⊨¬φ[s] 当且仅当 A⊭φ[s]\mathfrak{A} \not\models \varphi[s]A⊨φ[s]
  • A⊨(φ∧ψ)[s]\mathfrak{A} \models (\varphi \land \psi)[s]A⊨(φ∧ψ)[s] 当且仅当 A⊨φ[s]\mathfrak{A} \models \varphi[s]A⊨φ[s] 且 A⊨ψ[s]\mathfrak{A} \models \psi[s]A⊨ψ[s]
  • A⊨∀xφ[s]\mathfrak{A} \models \forall x \varphi[s]A⊨∀xφ[s] 当且仅当对每个 a∈Aa \in Aa∈A，A⊨φ[s(x∣a)]\mathfrak{A} \models \varphi[s(x|a)]A⊨φ[s(x∣a)]

其中 s(x∣a)s(x|a)s(x∣a) 表示将赋值 sss 中变量 xxx 的值改为 aaa 的新赋值。

一个理论 TTT（一组语句）的模型是满足 TTT 中所有语句的结构。TTT 的模型类记为 Mod(T)\text{Mod}(T)Mod(T)。反过来，给定一类结构 K\mathcal{K}K，Th(K)\text{Th}(\mathcal{K})Th(K) 表示在 K\mathcal{K}K 中所有结构上都为真的语句集合。

紧致性定理

紧致性定理（Compactness Theorem）是一阶逻辑最深刻的元定理之一：

如果 Σ 的每个有限子集都有模型，则 Σ 本身有模型。\text{如果 } \Sigma \text{ 的每个有限子集都有模型，则 } \Sigma \text{ 本身有模型。}如果 Σ 的每个有限子集都有模型，则 Σ 本身有模型。

等价地：如果 Σ⊨φ\Sigma \models \varphiΣ⊨φ（Σ\SigmaΣ 语义蕴涵 φ\varphiφ），则存在 Σ\SigmaΣ 的有限子集 Σ0\Sigma_0Σ0​ 使得 Σ0⊨φ\Sigma_0 \models \varphiΣ0​⊨φ。

紧致性定理有两种经典证明路径：

  1. 通过完备性定理（Gödel, 1930）：Σ⊨φ\Sigma \models \varphiΣ⊨φ 当且仅当 Σ⊢φ\Sigma \vdash \varphiΣ⊢φ。由于形式推导只使用有限多个前提，Σ⊢φ\Sigma \vdash \varphiΣ⊢φ 意味着某个有限子集 Σ0⊢φ\Sigma_0 \vdash \varphiΣ0​⊢φ。
  2. 通过超积构造（ultraproduct construction）：利用超滤子将一族结构合并成一个新结构。

紧致性定理有很多重要的非平凡推论：

非标准模型的存在：在自然数理论的语言中，加入常量 ccc 和公理 c>0,c>1,c>2,…c > 0, c > 1, c > 2, \ldotsc>0,c>1,c>2,… 这个扩展理论的每个有限子集都有模型（取足够大的自然数解释 ccc），所以由紧致性定理，整个理论有模型。在这个模型中，ccc 是一个比所有标准自然数都大的"无穷大"元素。这就是非标准自然数。

有限性不可一阶表达：不存在一阶语句的集合 Σ\SigmaΣ 使得 Σ\SigmaΣ 的模型恰好是所有有限结构。如果这样的 Σ\SigmaΣ 存在，那么 Σ\SigmaΣ 加上"至少有 nnn 个元素"的语句（对所有 nnn）的每个有限子集都有模型，由紧致性就有一个无穷模型，矛盾。

洛文海姆-斯科伦定理

洛文海姆-斯科伦定理（Löwenheim-Skolem Theorem）揭示了一阶逻辑在区分不同无穷基数方面的局限性。

向下洛文海姆-斯科伦：如果一个可数语言的理论 TTT 有无穷模型，则 TTT 有可数模型。

向上洛文海姆-斯科伦：如果 TTT 有一个无穷模型，则对任意基数 κ≥∣T∣\kappa \geq |T|κ≥∣T∣，TTT 有基数为 κ\kappaκ 的模型。

这些定理意味着一阶理论无法"锁定"模型的基数。例如，ZFC 集合论——如果它是一致的——就有可数模型。但在这个可数模型内部，"不可数集合"仍然存在。这就是著名的斯科伦悖论（Skolem's Paradox）：在可数模型中怎么会有"不可数集合"？解答是："不可数"是模型内部的概念——在可数模型中，某个集合被该模型判定为不可数，因为模型中不存在从自然数到该集合的双射，但从模型外部看，该集合确实是可数的。

初等等价与初等子结构

两个结构 A\mathfrak{A}A 和 B\mathfrak{B}B 是初等等价的，记为 A≡B\mathfrak{A} \equiv \mathfrak{B}A≡B，如果对所有一阶语句 σ\sigmaσ，A⊨σ\mathfrak{A} \models \sigmaA⊨σ 当且仅当 B⊨σ\mathfrak{B} \models \sigmaB⊨σ。

如果 A\mathfrak{A}A 是 B\mathfrak{B}B 的子结构，且对所有公式 φ(x1,…,xn)\varphi(x_1, \ldots, x_n)φ(x1​,…,xn​) 和所有 a1,…,an∈Aa_1, \ldots, a_n \in Aa1​,…,an​∈A：

A⊨φ[a1,…,an]  ⟺  B⊨φ[a1,…,an]\mathfrak{A} \models \varphi[a_1, \ldots, a_n] \iff \mathfrak{B} \models \varphi[a_1, \ldots, a_n]A⊨φ[a1​,…,an​]⟺B⊨φ[a1​,…,an​]

则称 A\mathfrak{A}A 是 B\mathfrak{B}B 的初等子结构，记为 A⪯B\mathfrak{A} \preceq \mathfrak{B}A⪯B。

塔斯基-沃特判准（Tarski-Vaught Test）给出了一个实用的判定条件：子结构 A⊆B\mathfrak{A} \subseteq \mathfrak{B}A⊆B 是初等子结构当且仅当，对每个公式 φ(x,y1,…,yn)\varphi(x, y_1, \ldots, y_n)φ(x,y1​,…,yn​) 和每组 a1,…,an∈Aa_1, \ldots, a_n \in Aa1​,…,an​∈A，如果存在 b∈Bb \in Bb∈B 使得 B⊨φ[b,a1,…,an]\mathfrak{B} \models \varphi[b, a_1, \ldots, a_n]B⊨φ[b,a1​,…,an​]，则存在这样的 bbb 在 AAA 中。

量词消去与可判定性

一个理论 TTT 允许量词消去（quantifier elimination），如果每个公式都等价于一个无量词公式。量词消去是判定理论可判定性的有力工具。

经典例子包括：

  • 稠密线序理论（DLO, Dense Linear Order without endpoints）允许量词消去，因此是可判定的。有理数上的通常序 (Q,<)(\mathbb{Q}, <)(Q,<) 是 DLO 的唯一可数模型（康托尔回退论证）。
  • 代数封闭域理论（ACF）允许量词消去。ACFp\text{ACF}_pACFp​（特征为 ppp 的代数封闭域理论）是完备的，因此可判定。
  • 普雷斯伯格算术（Presburger Arithmetic），即只有加法的自然数理论，允许量词消去，因此可判定。

练习与思考

  1. 构造一个语言 L={<}\mathcal{L} = \{<\}L={<} 的结构，使其论域为 Z\mathbb{Z}Z，<<< 解释为通常的整数小于关系。写出三个在该结构中为真的一阶语句和一个为假的一阶语句。

  2. 利用紧致性定理证明：如果一个一阶理论 TTT 有任意大的有限模型，则 TTT 有无穷模型。

  3. 解释斯科伦悖论：ZFC 的可数模型中怎么可能存在"不可数集合"？用自己的话说明"不可数"这一性质的相对性。

  4. 研究以下问题：为什么二阶逻辑没有紧致性定理？这对二阶逻辑的表达能力和推理系统意味着什么？

  5. 思考模型论与科学哲学的联系：物理理论的"模型"概念与模型论中的"模型"概念有何异同？

拓展阅读

  • 霍奇斯（Wilfrid Hodges）《模型论简短教程》（A Shorter Model Theory）——模型论的标准入门教材，覆盖面广且证明清晰。
  • 马克（David Marker）《模型论导引》（Model Theory: An Introduction）——现代模型论教材，包含稳定性理论的介绍。
  • 恩德顿（Herbert Enderton）《数理逻辑导论》第二部分——涵盖模型论基础，适合作为第一本读物。
  • 对非标准分析感兴趣的读者，可以了解罗宾逊（Abraham Robinson）如何利用模型论为莱布尼茨的无穷小量提供严格基础。
  • 谢拉赫（Saharon Shelah）的分类理论是当代模型论的核心，虽然技术要求很高，但了解其基本问题和目标很有价值。

小结

模型论通过研究形式语言与其数学解释之间的关系，揭示了一阶逻辑的深层性质。紧致性定理和洛文海姆-斯科伦定理展示了一阶逻辑的表达能力界限——它足够强大以表达丰富的数学内容，但又不足以区分某些结构性质（如基数、有限性）。这些局限性不是缺陷，而是一阶逻辑优良元理论性质的代价。模型论的方法已经远超纯逻辑范畴，成为代数几何、数论等数学分支的有力工具。
