运动控制算法

知识要点

运动控制的层次结构

机器人运动控制通常采用级联结构，从内到外依次为电流环、速度环和位置环。每一层控制器的输出作为下一层的设定值，形成多层嵌套的闭环控制系统。

各环典型带宽要求：


    

  • 电流环：fbw≥1kHzf_{bw} \geq 1\text{kHz}fbw​≥1kHz（控制频率 ≥10kHz\geq 10\text{kHz}≥10kHz）
    • 

  • 速度环：fbw≥100Hzf_{bw} \geq 100\text{Hz}fbw​≥100Hz（控制频率 ≥1kHz\geq 1\text{kHz}≥1kHz）
    • 

  • 位置环：fbw≥10Hzf_{bw} \geq 10\text{Hz}fbw​≥10Hz（控制频率 ≥100Hz\geq 100\text{Hz}≥100Hz）

PID 控制
PID（比例-积分-微分）控制器是工业机器人中最广泛使用的控制算法。


连续域表达：


u(t)=Kp⋅e(t)+Ki∫0te(τ)dτ+Kdde(t)dtu(t) = K_p \cdot e(t) + K_i \int_0^t e(\tau)d\tau + K_d \frac{de(t)}{dt}u(t)=Kp​⋅e(t)+Ki​∫0t​e(τ)dτ+Kd​dtde(t)​
离散化实现（增量式）：


Δu[k]=Kp(e[k]−e[k−1])+Ki⋅e[k]+Kd(e[k]−2e[k−1]+e[k−2])\Delta u[k] = K_p(e[k] - e[k-1]) + K_i \cdot e[k] + K_d(e[k] - 2e[k-1] + e[k-2])Δu[k]=Kp​(e[k]−e[k−1])+Ki​⋅e[k]+Kd​(e[k]−2e[k−1]+e[k−2])
增量式PID的优点：无积分饱和问题、输出增量有界、切换时无冲击。


PID 参数整定方法：


    

  • Ziegler-Nichols 临界比例法：确定临界增益 KuK_uKu​ 和振荡周期 TuT_uTu​

  • 频率响应法：根据开环Bode图确定增益和相位裕度

  • 自整定：基于继电反馈自动识别过程模型

关节空间控制
关节空间控制在每个关节上独立实施PID控制，忽略关节间的动力学耦合。这是最基本的控制方案。


对于单关节系统，动力学方程为：


Jθ¨+bθ˙+g(θ)=τJ\ddot{\theta} + b\dot{\theta} + g(\theta) = \tauJθ¨+bθ˙+g(θ)=τ
其中 JJJ 为等效惯量，bbb 为阻尼系数，g(θ)g(\theta)g(θ) 为重力项，τ\tauτ 为驱动力矩。


独立关节PID控制的局限：当机器人高速运动时，惯性力和科氏力/离心力使各关节之间产生强耦合，简单PID难以保证轨迹跟踪精度。


计算力矩法（Computed Torque Control）
计算力矩法基于完整的动力学模型进行前馈补偿，将非线性多体系统转化为一组解耦的线性系统。


机器人动力学方程（拉格朗日形式）：


M(q)q¨+C(q,q˙)q˙+G(q)=τM(\mathbf{q})\ddot{\mathbf{q}} + C(\mathbf{q}, \dot{\mathbf{q}})\dot{\mathbf{q}} + G(\mathbf{q}) = \boldsymbol{\tau}M(q)q¨​+C(q,q˙​)q˙​+G(q)=τ
其中 MMM 为惯性矩阵，CCC 为科氏力/离心力矩阵，GGG 为重力向量。


计算力矩控制律：


τ=M(q)a+C(q,q˙)q˙+G(q)\boldsymbol{\tau} = M(\mathbf{q})\mathbf{a} + C(\mathbf{q}, \dot{\mathbf{q}})\dot{\mathbf{q}} + G(\mathbf{q})τ=M(q)a+C(q,q˙​)q˙​+G(q)
a=q¨d+Kd(q˙d−q˙)+Kp(qd−q)\mathbf{a} = \ddot{\mathbf{q}}_d + K_d(\dot{\mathbf{q}}_d - \dot{\mathbf{q}}) + K_p(\mathbf{q}_d - \mathbf{q})a=q¨​d​+Kd​(q˙​d​−q˙​)+Kp​(qd​−q)
在精确模型下，闭环误差方程变为：


e¨+Kde˙+Kpe=0\ddot{\mathbf{e}} + K_d\dot{\mathbf{e}} + K_p\mathbf{e} = 0e¨+Kd​e˙+Kp​e=0
通过选择 KpK_pKp​ 和 KdK_dKd​ 使特征根具有负实部，即可保证跟踪误差指数收敛到零。


滑模变结构控制
滑模控制对模型不确定性和外界干扰具有强鲁棒性，适合存在参数摄动的机器人系统。


定义滑模面：


s=e˙+Λe\mathbf{s} = \dot{\mathbf{e}} + \Lambda \mathbf{e}s=e˙+Λe
其中 Λ\LambdaΛ 为正定对角矩阵。


控制律设计确保系统状态到达滑模面后沿滑模面滑动至原点：


τ=M^ar+C^q˙r+G^−K⋅sgn(s)\boldsymbol{\tau} = \hat{M}\mathbf{a}_r + \hat{C}\dot{\mathbf{q}}_r + \hat{G} - K \cdot \text{sgn}(\mathbf{s})τ=M^ar​+C^q˙​r​+G^−K⋅sgn(s)
其中 q˙r=q˙d+Λe\dot{\mathbf{q}}_r = \dot{\mathbf{q}}_d + \Lambda \mathbf{e}q˙​r​=q˙​d​+Λe，ar=q¨d+Λe˙\mathbf{a}_r = \ddot{\mathbf{q}}_d + \Lambda\dot{\mathbf{e}}ar​=q¨​d​+Λe˙。


抖振问题：符号函数 sgn(s)\text{sgn}(\mathbf{s})sgn(s) 造成控制输入高频切换。解决方法：


    

  • 边界层法：将 sgn(s)\text{sgn}(s)sgn(s) 替换为饱和函数 sat(s/ϕ)\text{sat}(s/\phi)sat(s/ϕ)

阻抗控制
阻抗控制不追求精确的位置跟踪，而是建立末端力与位移之间的动态关系——使机器人表现为一个具有期望刚度、阻尼和惯量的"虚拟弹簧-阻尼器"系统。


目标阻抗模型：


Md(x¨−x¨d)+Bd(x˙−x˙d)+Kd(x−xd)=FextM_d(\ddot{\mathbf{x}} - \ddot{\mathbf{x}}_d) + B_d(\dot{\mathbf{x}} - \dot{\mathbf{x}}_d) + K_d(\mathbf{x} - \mathbf{x}_d) = \mathbf{F}_{ext}Md​(x¨−x¨d​)+Bd​(x˙−x˙d​)+Kd​(x−xd​)=Fext​
其中 Md,Bd,KdM_d, B_d, K_dMd​,Bd​,Kd​ 分别为期望惯量、阻尼和刚度矩阵，Fext\mathbf{F}_{ext}Fext​ 为外部接触力。


阻抗控制的核心优势：


    

  • 接触安全：碰撞时机器人"让步"，限制接触力
    • 

  • 力位混合：在自由空间跟踪位置，接触时调节力
    • 

  • 适应性：自然适应环境刚度的不确定性
    •

在关节空间控制基础上，需要将任务空间（笛卡尔空间）的目标轨迹转换为关节空间的参考输入。

自适应控制
当机器人动力学参数未知或变化时（如抓取不同重量的物体），自适应控制可在线估计参数并调整控制律。


基于模型参考自适应控制（MRAC）的机器人控制：


τ=Y(q,q˙,q˙r,ar)θ^−Kss\boldsymbol{\tau} = Y(\mathbf{q}, \dot{\mathbf{q}}, \dot{\mathbf{q}}_r, \mathbf{a}_r)\hat{\boldsymbol{\theta}} - K_s\mathbf{s}τ=Y(q,q˙​,q˙​r​,ar​)θ^−Ks​s
参数更新律：


θ^˙=−ΓYTs\dot{\hat{\boldsymbol{\theta}}} = -\Gamma Y^T\mathbf{s}θ^˙=−ΓYTs
其中 YYY 为回归矩阵，θ^\hat{\boldsymbol{\theta}}θ^ 为参数估计值，Γ\GammaΓ 为正定学习率矩阵。


前沿动态
2025-2026年，机器人运动控制领域出现了学习型控制的兴起。基于强化学习的运动控制策略直接从交互中学习最优控制律，在腿足机器人（四足、人形）的平衡和行走中表现出远超传统方法的鲁棒性。


模型预测控制（MPC）的实时化取得重大进展。基于 ADMM 和 Interior Point 的高效求解器使 MPC 能在毫秒级完成优化，已在四足机器人和机械臂的实时控制中实现工程部署。


扩散策略（Diffusion Policy）等生成式模型开始应用于机器人操作策略学习。与传统基于轨迹优化的方法不同，扩散策略通过学习动作分布来生成多模态的控制序列，在复杂操作任务中展现出显著优势。

小结
运动控制算法是机器人实现精确、稳定和安全运动的核心。从经典PID到计算力矩法，从滑模控制到阻抗控制，每种方法都有其独特的适用场景和性能边界。理解控制理论的本质——如何在不确定性中保持系统稳定并实现期望行为——是设计高性能机器人控制系统的关键。随着学习型控制的兴起，传统模型驱动与数据驱动方法的融合正在定义下一代机器人运动控制的新范式。
