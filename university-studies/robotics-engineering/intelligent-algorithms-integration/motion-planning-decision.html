运动规划与决策

知识要点

运动规划的层次体系

机器人运动规划将高层任务目标转化为可执行的运动轨迹。现代机器人系统通常采用分层规划架构，从任务层逐步细化到运动执行层：

配置空间与障碍物表示
运动规划在配置空间（C-space）中进行，而非在物理工作空间中。


对于 nnn 个关节的机器人，配置空间是 nnn 维空间 C⊆Rn\mathcal{C} \subseteq \mathbb{R}^nC⊆Rn。障碍物在配置空间中的映射 Cobs\mathcal{C}_{obs}Cobs​ 是使机器人与环境发生碰撞的所有配置的集合。自由空间为：


Cfree=C∖Cobs\mathcal{C}_{free} = \mathcal{C} \setminus \mathcal{C}_{obs}Cfree​=C∖Cobs​
运动规划的目标：找到一条从 qstartq_{start}qstart​ 到 qgoalq_{goal}qgoal​ 的连续路径 σ:[0,1]→Cfree\sigma: [0,1] \rightarrow \mathcal{C}_{free}σ:[0,1]→Cfree​。


碰撞检测是规划的瓶颈——通常使用以下加速方法：


    

  • 层次包围盒（AABB/OBB树）：快速剔除不可能碰撞的对
    • 

  • GJK算法：计算凸体间的最小距离
    • 

  • FCL（Flexible Collision Library）：ROS2 中的标准碰撞检测库
    • 



基于采样的规划算法
基于采样的方法通过在配置空间中随机采样来探索自由空间，避免了高维空间的完整表示。


RRT（Rapidly-exploring Random Tree）：


算法流程：


    

  1. 初始化树 TTT 包含起点 qstartq_{start}qstart​
    2. 

  2. 随机采样 qrand∈Cq_{rand} \in \mathcal{C}qrand​∈C
    3. 

  3. 找到树中距 qrandq_{rand}qrand​ 最近的节点 qnearq_{near}qnear​
    4. 

  4. 从 qnearq_{near}qnear​ 向 qrandq_{rand}qrand​ 方向扩展步长 ϵ\epsilonϵ 得到 qnewq_{new}qnew​
    5. 

  5. 如果 qnear→qnewq_{near} \rightarrow q_{new}qnear​→qnew​ 无碰撞，将 qnewq_{new}qnew​ 加入树
    6. 

  6. 重复直到到达 qgoalq_{goal}qgoal​ 邻域
    7. 



RRT*（渐近最优版本）：


在 RRT 基础上增加两个操作：


    

  • Choose Parent：在 qnewq_{new}qnew​ 的邻域中选择使路径代价最小的父节点
    • 

  • Rewire：检查邻域中其他节点是否通过 qnewq_{new}qnew​ 中转可获得更短路径
    • 



RRT* 保证随着采样数趋于无穷，找到的路径代价收敛到最优值。


PRM（Probabilistic Roadmap）：


    

  • 预处理阶段：构建自由空间的路线图
    • 

  • 查询阶段：将起止点连接到路线图，搜索最短路径
    • 

  • 适合多次查询同一环境的场景
    • 



基于搜索的规划算法
A* 算法：在离散化的配置空间（栅格）上搜索最优路径。


评估函数：


f(n)=g(n)+h(n)f(n) = g(n) + h(n)f(n)=g(n)+h(n)
其中 g(n)g(n)g(n) 为从起点到 nnn 的实际代价，h(n)h(n)h(n) 为从 nnn 到目标的启发式估计。


当 h(n)h(n)h(n) 是可容纳的（never overestimates）时，A* 保证找到最优路径。


D* Lite：增量式搜索，适合动态环境——当发现新障碍物时，只重新计算受影响的部分路径，而非从头规划。


Hybrid A*：结合连续状态和离散搜索，输出满足运动学约束的路径（如非完整约束的车辆）。


局部规划与避障
DWA（Dynamic Window Approach）：


在速度空间 (v,ω)(v, \omega)(v,ω) 中采样可行速度命令：


    

  1. 确定动态窗口：由加速度限制确定的可达速度范围
    2. 

  2. 对窗口内的每个候选速度，前向模拟轨迹
    3. 

  3. 评估每条轨迹的目标函数并选择最优
    4. 



G(v,ω)=σ(α⋅heading+β⋅clearance+γ⋅velocity)G(v, \omega) = \sigma(\alpha \cdot \text{heading} + \beta \cdot \text{clearance} + \gamma \cdot \text{velocity})G(v,ω)=σ(α⋅heading+β⋅clearance+γ⋅velocity)
TEB（Timed Elastic Band）：


将轨迹表示为时间参数化的位姿序列 {xi,ti}\{x_i, t_i\}{xi​,ti​}，通过非线性优化同时满足：


    

  • 动力学约束（速度/加速度/曲率上限）
    • 

  • 障碍物避碰约束
    • 

  • 目标到达约束
    • 

  • 时间最短目标
    • 



TEB 的优势：输出时间最优轨迹，天然考虑动力学约束。


MPPI（Model Predictive Path Integral）：


基于随机控制理论的采样式MPC方法：


    

  1. 生成大量随机控制序列扰动
    2. 

  2. 前向仿真每条轨迹
    3. 

  3. 以代价的指数权重对控制序列加权平均
    4. 

  4. 得到最优控制命令
    5. 



u∗=∑iwi⋅ui∑iwi,wi=exp⁡(−1λS(ui))u^* = \frac{\sum_i w_i \cdot u_i}{\sum_i w_i}, \quad w_i = \exp\left(-\frac{1}{\lambda} S(u_i)\right)u∗=∑i​wi​∑i​wi​⋅ui​​,wi​=exp(−λ1​S(ui​))
MPPI 在GPU上并行计算数千条轨迹，实现高频实时规划。


机械臂运动规划
机械臂规划在高维关节空间中进行，特有挑战包括：


    

  • 高维度（6-7维甚至更多）
    • 

  • 自碰撞检测
    • 

  • 末端约束（保持杯子水平、沿表面滑动）
    • 



MoveIt2 是 ROS2 的机械臂规划框架：


    

  • 支持 OMPL（RRT*/BiRRT/PRM）采样规划
    • 

  • 支持 Pilz 工业运动规划（PTP/LIN/CIRC）
    • 

  • 约束规划：任务空间约束投影到关节空间
    • 

  • 运动学求解器集成（KDL/TracIK/IKFast）
    • 



行为树决策框架
行为树（Behavior Tree, BT）是一种分层的任务编排框架，用于机器人的高层行为决策。


核心节点类型：


    

  • Sequence（顺序节点）：依次执行子节点，全部成功才成功
    • 

  • Fallback/Selector（选择节点）：依次尝试子节点，有一个成功即成功
    • 

  • Action（动作节点）：执行具体行为（移动、抓取、说话）
    • 

  • Condition（条件节点）：检查条件是否满足
    • 

  • Decorator（装饰器）：修饰子节点行为（重试、超时、反转）
    • 



行为树相比有限状态机（FSM）的优势：


    

  • 模块化：子树可复用和组合
    • 

  • 可扩展：新增行为不影响已有逻辑
    • 

  • 可读性：树形结构直观反映执行逻辑
    • 

  • 反应性：每 tick 从根节点重新评估，响应环境变化
    • 



BehaviorTree.CPP 是 Nav2 使用的行为树库，支持 XML 定义和在线编辑。


有限状态机（FSM）
FSM 适合简单的顺序决策，由状态和转移条件组成：


(S,E,δ,s0,F)(\mathcal{S}, \mathcal{E}, \delta, s_0, \mathcal{F})(S,E,δ,s0​,F)
其中 S\mathcal{S}S 为状态集合，E\mathcal{E}E 为事件集合，δ\deltaδ 为转移函数，s0s_0s0​ 为初始状态。


对于复杂任务，层次状态机（HFSM）通过状态嵌套减少状态爆炸问题。SMACH 是 ROS 中常用的状态机库。


前沿动态
2025-2026年，运动规划领域最显著的趋势是学习型规划方法的崛起。基于扩散模型（Diffusion Policy）的规划器可以从演示数据中学习复杂的操作策略，生成多模态的运动轨迹。在灵巧操作（如翻转、插入、折叠）任务中表现远超传统规划方法。


大语言模型开始承担任务规划的角色。SayCan、Code as Policies 等框架利用 LLM 的常识推理能力将自然语言指令分解为机器人可执行的子任务序列，无需人工设计行为树或状态机。


实时高维规划取得突破。NVIDIA cuRoBot 利用 GPU 并行加速碰撞检测和轨迹优化，将7轴机械臂的规划时间从秒级降至毫秒级，使"移动中规划"成为可能。

小结
运动规划与决策是连接高层任务理解和底层运动控制的桥梁。从配置空间的数学抽象，到采样与搜索的算法实现，从局部避障的实时响应，到行为树的任务编排——多层次的规划体系使机器人能够在复杂环境中自主完成各种任务。传统几何规划与学习型方法的融合正在开创"通用操作规划"的新范式，使机器人能够应对更加开放和动态的现实世界。
