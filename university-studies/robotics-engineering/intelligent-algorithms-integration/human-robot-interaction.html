人机交互

知识要点

人机交互概述

人机交互（Human-Robot Interaction, HRI）研究人类与机器人之间安全、高效、自然的协作方式。随着机器人从工业隔离走向人类共存空间，HRI 已成为机器人系统设计中不可回避的核心问题。

HRI 的交互模态覆盖多个层面：


    

  • 物理交互：直接接触（协作搬运、手把手示教）
    • 

  • 非接触交互：语音、手势、眼神、表情
    • 

  • 认知交互：意图理解、共享计划、信任建模
    • 



力控柔顺交互
在人机物理接触场景中，机器人必须表现出"柔顺"——即对外力有顺应性的响应，而非刚性抵抗。


阻抗控制实现虚拟柔顺行为：


Mde¨+Bde˙+Kde=FhumanM_d\ddot{\mathbf{e}} + B_d\dot{\mathbf{e}} + K_d\mathbf{e} = \mathbf{F}_{human}Md​e¨+Bd​e˙+Kd​e=Fhuman​
通过调节 Md,Bd,KdM_d, B_d, K_dMd​,Bd​,Kd​，可以设计不同的交互"手感"：


    

  • 高刚度 KdK_dKd​：精确位置保持（如打磨抛光）
    • 

  • 低刚度 KdK_dKd​：容易被人推动（如手把手示教）
    • 

  • 高阻尼 BdB_dBd​：运动平滑但响应慢
    • 

  • 低阻尼 BdB_dBd​：响应快但可能振荡
    • 



导纳控制是阻抗控制的对偶形式——测量外力，输出位移：


x=G(s)⋅Fext\mathbf{x} = G(s) \cdot \mathbf{F}_{ext}x=G(s)⋅Fext​
G(s)=1Mds2+Bds+KdG(s) = \frac{1}{M_d s^2 + B_d s + K_d}G(s)=Md​s2+Bd​s+Kd​1​
导纳控制适合位置控制型机器人（工业机器人），阻抗控制适合力矩控制型机器人（协作机器人）。


安全约束与碰撞检测
ISO/TS 15066 标准定义了协作机器人的安全要求：


功率与力限制（PFL）：


Fmax⁡≤FthresholdF_{\max} \leq F_{\text{threshold}}Fmax​≤Fthreshold​
人体不同部位的最大允许接触力/压强不同：


    

  • 头部/前额：130N
    • 

  • 胸部：140N
    • 

  • 手/手指：140N
    • 



安全策略的层次：


    

  1. 速度监控：当人靠近时降速
    2. 

  2. 力/功率限制：接触力不超过安全阈值
    3. 

  3. 碰撞检测：检测到碰撞后立即反转运动
    4.

自然语言交互
语言是人类最自然的交互方式。机器人语言交互系统通常包含：


语音识别（ASR）：将语音转化为文本


    

  • Whisper（OpenAI）：多语言、高精度
    • 

  • 端侧部署：Sherpa-ONNX 在嵌入式设备上实时运行
    • 



自然语言理解（NLU）：提取意图和实体


    

  • 传统方法：意图分类 + 槽位填充
    • 

  • LLM方法：直接理解开放域指令
    • 



任务接地（Grounding）：将语言指令映射到机器人可执行的动作


例如，"把桌上的红色杯子递给我"需要解决：


    

  • 空间接地："桌上" → 特定区域
    • 

  • 物体接地："红色杯子" → 具体物体检测
    • 

  • 动作接地："递给我" → 抓取+递送动作序列
    • 

  • 人员接地："我" → 说话者位置估计
    • 



LLM 作为任务规划器的pipeline：

手势识别与姿态理解
手势识别使机器人能够通过视觉感知人类的非语言指令。


基于骨骼关键点的方法：


    

  • MediaPipe Hands：实时21点手部关键点检测
    • 

  • OpenPose/MMPose：全身骨骼检测
    • 

  • 从关键点序列识别静态手势（比划数字）和动态手势（挥手、指向）
    • 



指向手势理解：


人指向某个方向时，机器人需要计算指向射线与环境的交点：


ptarget=phand+t⋅dpointing\mathbf{p}_{target} = \mathbf{p}_{hand} + t \cdot \mathbf{d}_{pointing}ptarget​=phand​+t⋅dpointing​
其中 dpointing\mathbf{d}_{pointing}dpointing​ 为指向方向单位向量（从肘到指尖），ttt 为深度参数。


人体意图预测：


通过人体姿态和运动趋势预测未来动作意图：


    

  • 躯干朝向预测行走方向
    • 

  • 手臂预备动作预测抓取意图
    • 

  • 步态分析预测接近/远离趋势
    • 



示教与学习
运动学示教（Kinesthetic Teaching）：


操作者直接拖动机器人运动，系统记录关节轨迹。要求机器人具备：


    

  • 零/低重力补偿模式
    • 

  • 高反向驱动性或力矩控制
    • 

  • 轨迹记录与平滑
    • 



从演示中学习（Learning from Demonstration, LfD）：


通过多次示教学习泛化的运动技能：


DMP（Dynamic Movement Primitive）将运动编码为微分方程：


τz˙=αz(βz(g−y)−z)+f(x)\tau\dot{z} = \alpha_z(\beta_z(g - y) - z) + f(x)τz˙=αz​(βz​(g−y)−z)+f(x)
τy˙=z\tau\dot{y} = zτy˙​=z
其中 ggg 为目标位置，f(x)f(x)f(x) 为从示教中学习的强迫项，τ\tauτ 为时间缩放因子。


DMP 的优势：


    

  • 时间缩放：同一运动可快可慢
    • 

  • 空间缩放：自动适应不同起止点
    • 

  • 稳定性保证：系统天然收敛到目标点
    • 



社交机器人与情感计算
社交机器人需要理解和表达情感，建立与人类的信任关系。


情感识别：


    

  • 面部表情识别（FER）：7种基本情绪分类
    • 

  • 语音情感识别：语调、语速、能量特征
    • 

  • 多模态融合：结合表情+语音+文本
    • 



信任模型：


人对机器人的信任 TTT 是动态变化的：


Tt+1=Tt+α(performancet−expectationt)T_{t+1} = T_t + \alpha(\text{performance}_t - \text{expectation}_t)Tt+1​=Tt​+α(performancet​−expectationt​)
信任过低导致人类不愿接受机器人帮助，信任过高则可能导致过度依赖。适度校准信任（Calibrated Trust）是 HRI 设计的重要目标。


共享自主（Shared Autonomy）
共享自主是人类操作与机器人自主能力的融合——机器人部分自主但允许人类干预和引导。


混合主动控制：


u=α⋅uhuman+(1−α)⋅urobot\mathbf{u} = \alpha \cdot \mathbf{u}_{human} + (1-\alpha) \cdot \mathbf{u}_{robot}u=α⋅uhuman​+(1−α)⋅urobot​
自主权分配 α\alphaα 可以是固定的，也可以根据上下文动态调整：


    

  • 人类操作精确时 → 提高 α\alphaα
    • 

  • 接近障碍物时 → 降低 α\alphaα（机器人接管避障）
    • 

  • 任务接近完成时 → 降低 α\alphaα（机器人辅助对准）
    • 



前沿动态
2025-2026年，大语言模型彻底改变了人机交互的范式。GPT-4o/Claude 等多模态模型使机器人能够理解开放词汇的自然语言指令并进行多轮对话，极大降低了非专业用户操作机器人的门槛。Google DeepMind 的 RT-2/RT-X 将视觉-语言模型直接输出机器人动作token，实现了端到端的"看-说-做"。


具身智能（Embodied AI）的爆发推动了全身触觉交互的发展。Sanctuary AI 的 Phoenix 人形机器人配备了全身1000+触觉传感器，能够感知人类的轻触并做出柔顺响应，实现了前所未有的物理亲密交互。


脑机接口（BCI）在辅助机器人控制中取得了里程碑式进展。Neuralink 的植入式 BCI 已能够让瘫痪患者通过意念精确控制机械臂完成日常抓取任务，非侵入式 EEG-BCI 也在轮椅和外骨骼控制中实现了实用化。

小结
人机交互是机器人从"工具"进化为"伙伴"的关键技术。力控柔顺保证了物理安全，自然语言和手势提供了直觉化的交互通道，示教学习降低了编程门槛，信任模型和共享自主优化了协作体验。随着大语言模型和具身智能的交汇，机器人正在学会像人类伙伴一样理解意图、预判需求和自然协作——这代表着人机交互从"人适应机器"到"机器适应人"的根本转变。
