02 经济学 (Economics)经济学 简介微观经济学 简介供给与需求均衡

供给与需求均衡

经济学中最基础也最具解释力的框架之一，就是供给与需求的分析。无论是菜市场里蔬菜价格的涨落，还是国际石油市场的剧烈波动，背后都可以用供给和需求的相互作用来理解。掌握这一框架，相当于拿到了解读市场现象的第一把钥匙。

知识要点

需求（Demand）描述的是消费者在不同价格水平下愿意且能够购买的商品数量。需求定律指出：在其他条件不变时，商品价格越高，需求量越低；价格越低，需求量越高。用数学语言表达：

Qd=f(P),dQddP<0Q_d = f(P), \quad \frac{dQ_d}{dP} < 0Qd​=f(P),dPdQd​​<0

供给（Supply）描述的是生产者在不同价格水平下愿意且能够提供的商品数量。供给定律指出：价格越高，供给量越大。即：

Qs=g(P),dQsdP>0Q_s = g(P), \quad \frac{dQ_s}{dP} > 0Qs​=g(P),dPdQs​​>0

市场均衡发生在供给量等于需求量的价格水平上：

Qd(P∗)=Qs(P∗)Q_d(P^*) = Q_s(P^*)Qd​(P∗)=Qs​(P∗)

此时的价格 P∗P^*P∗ 称为均衡价格，对应的数量 Q∗Q^*Q∗ 称为均衡数量。

影响需求的因素包括消费者收入、相关商品价格、偏好、预期和消费者数量。影响供给的因素包括投入品价格、技术水平、预期、生产者数量和政府政策。

详细讲解

需求曲线的推导

假设一个线性需求函数：

Qd=a−bPQ_d = a - bPQd​=a−bP

其中 a>0a > 0a>0 表示当价格为零时的最大需求量，b>0b > 0b>0 衡量价格变动对需求量的影响程度。在坐标图上，经济学惯例将价格放在纵轴、数量放在横轴，因此需求曲线的斜率为 −1b-\frac{1}{b}−b1​（注意这是反函数的斜率）。

需求曲线的移动与沿曲线的移动有本质区别。价格变化引起沿着需求曲线的滑动——这只改变需求量（quantity demanded）。而收入增加、偏好变化等非价格因素，则使整条需求曲线向右或向左平移——这改变的是需求（demand）本身。

供给曲线的推导

类似地，线性供给函数为：

Qs=c+dPQ_s = c + dPQs​=c+dP

其中 ccc 可以为负（表示价格低于某个水平时无人愿意生产），d>0d > 0d>0 表示价格上升对供给量的正向作用。技术进步会使供给曲线右移，意味着在同一价格下厂商能提供更多产品。

均衡的求解

将需求与供给联立：

a−bP=c+dPa - bP = c + dPa−bP=c+dP

解得均衡价格：

P∗=a−cb+dP^* = \frac{a - c}{b + d}P∗=b+da−c​

均衡数量：

Q∗=a−b⋅a−cb+d=ad+bcb+dQ^* = a - b \cdot \frac{a - c}{b + d} = \frac{ad + bc}{b + d}Q∗=a−b⋅b+da−c​=b+dad+bc​

举一个具体例子：假设某市场的需求函数为 Qd=100−2PQ_d = 100 - 2PQd​=100−2P，供给函数为 Qs=−20+3PQ_s = -20 + 3PQs​=−20+3P。令 Qd=QsQ_d = Q_sQd​=Qs​：

100−2P=−20+3P  ⟹  5P=120  ⟹  P∗=24100 - 2P = -20 + 3P \implies 5P = 120 \implies P^* = 24100−2P=−20+3P⟹5P=120⟹P∗=24
Q∗=100−2×24=52Q^* = 100 - 2 \times 24 = 52Q∗=100−2×24=52

均衡的稳定性

当市场价格高于均衡价格时，供给过剩（surplus）出现，卖家竞争压低价格；当价格低于均衡价格时，需求过剩（shortage）出现，买家竞争推高价格。这种自动调节机制被亚当·斯密称为"看不见的手"。

瓦尔拉斯（Walras）的价格调整机制可以写为：

dPdt=α[Qd(P)−Qs(P)],α>0\frac{dP}{dt} = \alpha [Q_d(P) - Q_s(P)], \quad \alpha > 0dtdP​=α[Qd​(P)−Qs​(P)],α>0

当 Qd>QsQ_d > Q_sQd​>Qs​ 时价格上升，当 Qd<QsQ_d < Q_sQd​<Qs​ 时价格下降，最终收敛到 P∗P^*P∗。

弹性与均衡

需求价格弹性衡量需求量对价格变动的敏感程度：

εd=%ΔQd%ΔP=dQddP⋅PQd\varepsilon_d = \frac{\%\Delta Q_d}{\%\Delta P} = \frac{dQ_d}{dP} \cdot \frac{P}{Q_d}εd​=%ΔP%ΔQd​​=dPdQd​​⋅Qd​P​

∣εd∣>1|\varepsilon_d| > 1∣εd​∣>1 为富有弹性，∣εd∣<1|\varepsilon_d| < 1∣εd​∣<1 为缺乏弹性，∣εd∣=1|\varepsilon_d| = 1∣εd​∣=1 为单位弹性。弹性的大小直接影响均衡价格和数量对外部冲击的响应幅度。

政府干预与均衡偏离

价格上限（price ceiling）设定低于均衡价格时，会造成持续短缺。例如房租管制使得 Pceiling<P∗P_{ceiling} < P^*Pceiling​<P∗，此时 Qd(Pceiling)>Qs(Pceiling)Q_d(P_{ceiling}) > Q_s(P_{ceiling})Qd​(Pceiling​)>Qs​(Pceiling​)，市场无法出清。

价格下限（price floor）设定高于均衡价格时，会造成持续过剩。最低工资法就是劳动市场中的价格下限，当最低工资高于均衡工资时，劳动供给超过需求，产生失业。

税收会在买方价格和卖方价格之间打入一个楔子。若对每单位商品征税 ttt，新的均衡满足：

Qd(Pb)=Qs(Ps),Pb=Ps+tQ_d(P_b) = Q_s(P_s), \quad P_b = P_s + tQd​(Pb​)=Qs​(Ps​),Pb​=Ps​+t

税负在买卖双方之间的分配取决于供给和需求弹性的相对大小：弹性越小的一方承担越大比例的税负。

消费者剩余与生产者剩余

消费者剩余（CS）是消费者愿意支付的最高价格与实际支付价格之间的差额总和：

CS=∫0Q∗Pd(Q) dQ−P∗Q∗CS = \int_0^{Q^*} P_d(Q) \, dQ - P^* Q^*CS=∫0Q∗​Pd​(Q)dQ−P∗Q∗

生产者剩余（PS）是实际收入与生产者愿意接受的最低价格之间的差额总和：

PS=P∗Q∗−∫0Q∗Ps(Q) dQPS = P^* Q^* - \int_0^{Q^*} P_s(Q) \, dQPS=P∗Q∗−∫0Q∗​Ps​(Q)dQ

两者之和为社会总剩余，是衡量市场效率的重要指标。在完全竞争均衡下，社会总剩余达到最大。

练习与思考

  1. 某商品的需求函数为 Qd=200−4PQ_d = 200 - 4PQd​=200−4P，供给函数为 Qs=−40+6PQ_s = -40 + 6PQs​=−40+6P。求均衡价格和均衡数量，并计算消费者剩余和生产者剩余。

  2. 如果政府对上题中的商品每单位征收 555 元的税，新的均衡价格和数量是多少？税收收入是多少？无谓损失（deadweight loss）是多少？

  3. 思考：为什么"谷贱伤农"？用供给弹性和需求弹性的概念解释，当粮食丰收导致供给曲线右移时，农民总收入反而下降的原因。

  4. 试分析：石油输出国组织（OPEC）限产保价的策略，本质上是在操纵供给曲线的哪个方面？这一策略在短期和长期的效果会有什么不同？

拓展阅读

供给与需求模型虽然简洁，但其应用范围远超教科书例题。劳动经济学用它分析工资决定和就业，国际经济学用它解释汇率波动，公共经济学用它评估税收的效率损失。

阿尔弗雷德·马歇尔（Alfred Marshall）在1890年出版的《经济学原理》中系统化了供需分析框架，提出了著名的"剪刀"比喻——供给和需求如同剪刀的两片刀刃，共同决定价格。

进一步学习可参考曼昆《经济学原理》第4-6章，或范里安《微观经济学：现代观点》第1-2章。对弹性理论感兴趣的读者，可以深入研究马歇尔需求函数与希克斯需求函数的区别。

小结

供给与需求均衡是微观经济分析的基石。需求曲线反映消费者行为，供给曲线反映生产者行为，两者交叉决定均衡价格和数量。弹性概念帮助我们量化市场反应的灵敏度，而政府干预（价格管制、税收）则使市场偏离效率均衡，产生无谓损失。理解这些基本原理，是进入更复杂经济分析的必要准备。
