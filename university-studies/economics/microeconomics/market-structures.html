02 经济学 (Economics)经济学 简介微观经济学 简介市场结构

市场结构

现实经济中，不同行业的竞争程度差异巨大。街角的便利店面对激烈竞争，而自来水公司却几乎是唯一的供应者。市场结构理论将这些千差万别的行业归纳为几种典型模型，揭示竞争程度如何影响价格、产量和社会福利。

知识要点

市场结构主要按照厂商数量、产品差异化程度和进入壁垒三个维度来分类。四种基本类型分别是完全竞争、垄断竞争、寡头垄断和完全垄断。

在完全竞争市场中，大量厂商出售同质产品，单个厂商是价格接受者（price taker），面临的需求曲线是一条水平线。利润最大化条件为边际成本等于价格：

MC=PMC = PMC=P

垄断厂商是市场上唯一的供应者，面临的需求曲线就是市场需求曲线。垄断厂商的利润最大化条件为边际收益等于边际成本：

MR=MCMR = MCMR=MC

由于 MR<PMR < PMR<P（向下倾斜的需求曲线下），垄断价格高于完全竞争价格，产量低于完全竞争产量，产生无谓损失。

详细讲解

完全竞争的长期均衡

短期内，完全竞争厂商可以获得经济利润或经济亏损。如果行业存在经济利润，新厂商会进入，供给增加，市场价格下降；如果存在亏损，厂商退出，供给减少，价格上升。长期均衡要求：

P=MC=ACmin⁡P = MC = AC_{\min}P=MC=ACmin​

即价格等于最低平均成本，经济利润为零。这一结论意味着完全竞争在长期中实现了生产效率（在最低成本处生产）和配置效率（P=MCP = MCP=MC，资源配置到消费者最看重的用途）。

垄断的定价与福利损失

垄断厂商面临向下倾斜的需求曲线 P=a−bQP = a - bQP=a−bQ，总收益为：

TR=PQ=aQ−bQ2TR = PQ = aQ - bQ^2TR=PQ=aQ−bQ2

边际收益为：

MR=dTRdQ=a−2bQMR = \frac{dTR}{dQ} = a - 2bQMR=dQdTR​=a−2bQ

注意 MR 曲线的斜率是需求曲线斜率的两倍。设边际成本为常数 ccc，则最优产量：

a−2bQ∗=c  ⟹  Q∗=a−c2ba - 2bQ^* = c \implies Q^* = \frac{a - c}{2b}a−2bQ∗=c⟹Q∗=2ba−c​

对应价格：

P∗=a−bQ∗=a+c2P^* = a - bQ^* = \frac{a + c}{2}P∗=a−bQ∗=2a+c​

与完全竞争均衡（P=cP = cP=c，Q=a−cbQ = \frac{a-c}{b}Q=ba−c​）相比，垄断产量恰好是竞争产量的一半，垄断价格高于竞争价格。无谓损失（DWL）为：

DWL=12(P∗−c)(Qc−Q∗)=(a−c)28bDWL = \frac{1}{2}(P^* - c)(Q_c - Q^*) = \frac{(a-c)^2}{8b}DWL=21​(P∗−c)(Qc​−Q∗)=8b(a−c)2​

衡量垄断力的常用指标是勒纳指数（Lerner Index）：

L=P−MCP=1∣εd∣L = \frac{P - MC}{P} = \frac{1}{|\varepsilon_d|}L=PP−MC​=∣εd​∣1​

勒纳指数越大，垄断力越强。在完全竞争中 L=0L = 0L=0。

垄断竞争

爱德华·张伯伦提出的垄断竞争模型融合了竞争与垄断的特征。大量厂商出售有差异化的产品，每个厂商面临一条向下倾斜但相当平坦的需求曲线。

短期内厂商可以获得利润，但自由进入使得长期中需求曲线左移直到与平均成本曲线相切：

P=AC,MR=MCP = AC, \quad MR = MCP=AC,MR=MC

长期利润为零，但与完全竞争不同的是，垄断竞争的均衡产量低于平均成本最低点对应的产量，存在"过剩产能"（excess capacity）。这是产品多样性的代价——消费者为了更多选择而支付略高的价格。

寡头垄断

寡头市场由少数几家大厂商主导，每家厂商的决策都会影响其他厂商的利润，因此策略互动成为核心分析要素。

古诺模型（Cournot）假设厂商同时选择产量。两个厂商面对市场需求 P=a−b(q1+q2)P = a - b(q_1 + q_2)P=a−b(q1​+q2​)，各自利润为：

πi=(a−b(qi+qj)−c)qi\pi_i = (a - b(q_i + q_j) - c)q_iπi​=(a−b(qi​+qj​)−c)qi​

一阶条件给出反应函数：

qi∗=a−c−bqj2bq_i^* = \frac{a - c - bq_j}{2b}qi∗​=2ba−c−bqj​​

纳什均衡为：

q1∗=q2∗=a−c3b,Q∗=2(a−c)3bq_1^* = q_2^* = \frac{a - c}{3b}, \quad Q^* = \frac{2(a-c)}{3b}q1∗​=q2∗​=3ba−c​,Q∗=3b2(a−c)​

古诺均衡的总产量介于垄断产量和竞争产量之间。

伯特兰模型（Bertrand）假设厂商同时选择价格。在同质产品情况下，结果是均衡价格等于边际成本——仅两个厂商就能实现完全竞争结果，这被称为"伯特兰悖论"。

斯塔克尔伯格模型（Stackelberg）引入了先行者优势：一家厂商先选择产量，另一家随后选择。先行者通过承诺大产量来挤压追随者的空间，获得更高利润。

博弈论视角下的合谋

寡头厂商有合谋（collusion）的动机——如果它们联合行动像一个垄断者那样定价，总利润最大。但合谋协议面临内在的不稳定性：每个参与者都有偏离协议、暗中增产以获取更大份额的激励。这构成了一个经典的囚徒困境。

在重复博弈中，如果折现因子 δ\deltaδ 足够大（即厂商足够看重未来利润），"触发策略"（trigger strategy）可以维持合谋均衡。Folk定理指出，当 δ→1\delta \to 1δ→1 时，几乎任何可行且个体理性的支付向量都可以作为子博弈完美均衡的结果。

练习与思考

  1. 某垄断厂商的需求函数为 P=120−2QP = 120 - 2QP=120−2Q，成本函数为 TC=20Q+Q2TC = 20Q + Q^2TC=20Q+Q2。求利润最大化的价格和产量，以及垄断利润。

  2. 在古诺双寡头模型中，市场需求为 P=200−QP = 200 - QP=200−Q，两厂商边际成本均为 404040。求纳什均衡产量、价格和利润，并与垄断和完全竞争结果比较。

  3. 解释为什么航空业经常出现价格战，而钻石行业（戴比尔斯）长期维持高价？从市场结构的角度分析。

  4. 互联网平台（如搜索引擎、社交网络）属于哪种市场结构？网络效应如何改变了传统市场结构分析？

拓展阅读

产业组织理论（Industrial Organization）是市场结构分析的学科深化。让·梯若尔（Jean Tirole）因在产业组织和规制经济学方面的贡献获得2014年诺贝尔经济学奖。他的分析框架特别强调了信息不对称和博弈论在理解市场竞争中的作用。

数字经济的崛起带来了新的市场结构特征：零边际成本、网络外部性、平台双边市场等。这些特征使得传统的四分类法需要扩展和修正。

推荐阅读泰勒尔《产业组织理论》，或卡尔顿和佩洛夫《现代产业组织》。博弈论基础可参考吉本斯《博弈论基础》。

小结

市场结构从完全竞争到完全垄断构成一个连续谱。竞争程度决定了厂商的定价能力和社会福利水平。完全竞争实现效率最优，垄断造成无谓损失，垄断竞争以过剩产能换取产品多样性，寡头垄断中策略互动成为关键。理解不同市场结构的运行逻辑，是分析反垄断政策和产业规制的基础。
