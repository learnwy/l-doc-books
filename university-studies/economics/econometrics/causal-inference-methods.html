因果推断方法

"相关不等于因果"可能是统计学中被引用最多的警句。吸烟与肺癌相关，但如何证明吸烟导致了肺癌？最低工资提高后失业率下降了，但这真的是因为最低工资的提高吗？因果推断方法是现代计量经济学的核心前沿，它提供了一套从观察数据中识别因果效应的严格框架。

知识要点

因果推断的基本框架是鲁宾因果模型（Rubin Causal Model），也称潜在结果框架。对于个体 iii，定义：

  • Yi(1)Y_i(1)Yi​(1)：接受处理时的潜在结果
  • Yi(0)Y_i(0)Yi​(0)：未接受处理时的潜在结果
  • 个体因果效应：τi=Yi(1)−Yi(0)\tau_i = Y_i(1) - Y_i(0)τi​=Yi​(1)−Yi​(0)

因果推断的根本困难在于：对于每个个体，我们只能观察到一个潜在结果（实际接受或未接受处理），另一个是反事实（counterfactual），永远无法直接观察。这被称为"因果推断的根本问题"。

因此，我们转而估计平均处理效应（ATE）：

ATE=E[Yi(1)−Yi(0)]\text{ATE} = E[Y_i(1) - Y_i(0)]ATE=E[Yi​(1)−Yi​(0)]

或者处理组的平均处理效应（ATT）：

ATT=E[Yi(1)−Yi(0)∣Di=1]\text{ATT} = E[Y_i(1) - Y_i(0) \mid D_i = 1]ATT=E[Yi​(1)−Yi​(0)∣Di​=1]

其中 Di=1D_i = 1Di​=1 表示个体 iii 接受了处理。

简单比较处理组和控制组的均值差异通常不能识别因果效应，因为存在选择偏差——处理组和控制组在处理之前就可能系统性地不同。

详细讲解

随机控制试验

随机控制试验（RCT）是因果推断的"金标准"。通过随机分配处理，确保处理组和控制组在统计上相同（除了处理本身），从而消除选择偏差。

随机化保证了 E[Yi(0)∣Di=1]=E[Yi(0)∣Di=0]E[Y_i(0) \mid D_i = 1] = E[Y_i(0) \mid D_i = 0]E[Yi​(0)∣Di​=1]=E[Yi​(0)∣Di​=0]，因此：

E[Yi∣Di=1]−E[Yi∣Di=0]=ATEE[Y_i \mid D_i = 1] - E[Y_i \mid D_i = 0] = \text{ATE}E[Yi​∣Di​=1]−E[Yi​∣Di​=0]=ATE

简单的均值比较就能识别因果效应。

RCT在发展经济学中的应用彻底改变了政策评估的方式。阿比吉特·班纳吉和埃斯特·迪弗洛在肯尼亚、印度等国开展了大量田野实验，评估教育补贴、驱虫药物、小额信贷等干预的效果。他们因此获得2019年诺贝尔经济学奖。

然而RCT并非万能：伦理约束（不能随机分配某些处理）、外部有效性（实验结果能否推广）、合规性（参与者可能不遵守分配）和成本都是实际限制。

工具变量法

当处理变量 DDD 与误差项相关（内生性问题）时，OLS估计有偏。工具变量（IV）法通过引入一个满足特定条件的变量 ZZZ 来解决这一问题。

有效工具变量需要满足两个条件：

相关性：Cov(Z,D)≠0（Z 影响 D）\text{相关性}：\text{Cov}(Z, D) \neq 0 \quad \text{（$Z$ 影响 $D$）}相关性：Cov(Z,D)=0（Z 影响 D）
排他性：Cov(Z,u)=0（Z 只通过 D 影响 Y）\text{排他性}：\text{Cov}(Z, u) = 0 \quad \text{（$Z$ 只通过 $D$ 影响 $Y$）}排他性：Cov(Z,u)=0（Z 只通过 D 影响 Y）

两阶段最小二乘法（2SLS）的步骤：

第一阶段：Di=π0+π1Zi+viD_i = \pi_0 + \pi_1 Z_i + v_iDi​=π0​+π1​Zi​+vi​

第二阶段：Yi=β0+β1D^i+uiY_i = \beta_0 + \beta_1 \hat{D}_i + u_iYi​=β0​+β1​D^i​+ui​

经典例子：安格里斯特和克鲁格（1991）用出生季度作为教育年限的工具变量。义务教育法规定入学年龄，出生季度因此影响实际受教育年限，但出生季度本身（在假设下）与个人能力等不可观测因素无关。

IV估计量在存在异质性处理效应时识别的是局部平均处理效应（LATE）——只针对那些因工具变量变化而改变处理状态的"顺从者"（compliers）。

断点回归设计

断点回归（Regression Discontinuity, RD）利用的是政策或规则在某个阈值处产生的跳跃。如果处理分配由某个变量 XXX（称为驱动变量或运行变量）是否超过阈值 ccc 决定：

Di=1(Xi≥c)D_i = \mathbf{1}(X_i \geq c)Di​=1(Xi​≥c)

则在阈值附近，刚好高于和刚好低于阈值的个体几乎相同（除了处理状态），构成了一个"局部随机实验"。

精确断点（Sharp RD）：处理完全由是否超过阈值决定。因果效应通过阈值处结果变量的跳跃来识别：

τRD=lim⁡x↓cE[Yi∣Xi=x]−lim⁡x↑cE[Yi∣Xi=x]\tau_{RD} = \lim_{x \downarrow c} E[Y_i \mid X_i = x] - \lim_{x \uparrow c} E[Y_i \mid X_i = x]τRD​=x↓clim​E[Yi​∣Xi​=x]−x↑clim​E[Yi​∣Xi​=x]

模糊断点（Fuzzy RD）：超过阈值增加了接受处理的概率但不是100%。此时RD估计等价于以超过阈值为工具变量的IV估计。

经典应用：蒂斯图（Thistlethwaite）和坎贝尔最早用奖学金分数线的RD设计研究了获奖对学业成就的影响。

双重差分法

双重差分（Difference-in-Differences, DID）是面板数据中最常用的因果推断方法。核心思想是比较处理组和控制组在政策实施前后的变化之差：

τ^DID=(Yˉtreat,post−Yˉtreat,pre)−(Yˉcontrol,post−Yˉcontrol,pre)\hat{\tau}_{DID} = (\bar{Y}_{treat,post} - \bar{Y}_{treat,pre}) - (\bar{Y}_{control,post} - \bar{Y}_{control,pre})τ^DID​=(Yˉtreat,post​−Yˉtreat,pre​)−(Yˉcontrol,post​−Yˉcontrol,pre​)

关键假设是平行趋势：如果没有处理，处理组和控制组的结果变量会遵循相同的时间趋势。

回归框架下：

Yit=α+β1Di+β2Postt+δ(Di×Postt)+uitY_{it} = \alpha + \beta_1 D_i + \beta_2 Post_t + \delta (D_i \times Post_t) + u_{it}Yit​=α+β1​Di​+β2​Postt​+δ(Di​×Postt​)+uit​

其中 δ\deltaδ 就是DID估计的因果效应。

卡德和克鲁格（1994）的经典研究用DID比较了新泽西州（提高最低工资）和宾夕法尼亚州（未提高）快餐店的就业变化，发现最低工资提高并未显著减少就业——这一结论挑战了传统经济学教科书的预测。大卫·卡德因此获2021年诺贝尔经济学奖。

匹配与倾向得分

当无法进行随机实验时，匹配方法试图在观察数据中构造可比较的处理组和控制组。倾向得分匹配（PSM）首先估计每个个体接受处理的概率（倾向得分）：

e(Xi)=P(Di=1∣Xi)e(X_i) = P(D_i = 1 \mid X_i)e(Xi​)=P(Di​=1∣Xi​)

然后将倾向得分相近的处理组和控制组个体配对比较。罗森鲍姆和鲁宾证明，在给定倾向得分的条件下，处理分配与协变量独立（条件独立性假设成立时）。

匹配方法的根本局限是只能控制可观测变量。如果存在不可观测的混杂因素，匹配无法消除偏差——这一点与RCT和IV有本质区别。

练习与思考

  1. 一所大学发现参加辅导项目的学生成绩平均高出15分。这能说明辅导项目的因果效应吗？可能存在什么选择偏差？如何设计RCT来正确评估？

  2. 某州将法定饮酒年龄从18岁提高到21岁。如何用RD设计评估饮酒年龄法对交通事故率的因果效应？驱动变量和阈值分别是什么？

  3. 2008年中国实施了新劳动合同法。如果你想评估该法律对企业用工行为的因果效应，如何设计DID策略？什么可以作为控制组？平行趋势假设在这里是否合理？

  4. 为什么"好的工具变量难以找到"？排他性限制为什么无法直接检验？

拓展阅读

因果推断革命从根本上改变了应用经济学的研究范式。2021年诺贝尔经济学奖授予大卫·卡德、约书亚·安格里斯特和吉多·因本斯，表彰他们对因果推断方法论和劳动经济学实证研究的贡献。

推荐阅读安格里斯特和皮施克《基本无害的计量经济学》（方法导向）和《精通计量》（更通俗的入门书）。斯科特·坎宁安《因果推断：混合磁带》是近年来广受好评的新教材。

小结

因果推断是现代计量经济学的核心议题。潜在结果框架提供了统一的概念基础，RCT是因果识别的金标准但受到实际限制。工具变量、断点回归和双重差分提供了从观察数据中识别因果效应的准实验方法，各有其适用条件和识别假设。掌握这些方法，是进行严谨的经验研究和政策评估的必备能力。
