时间序列计量

经济数据很大一部分是按时间顺序排列的：GDP季度数据、日度股价、月度通胀率。时间序列计量经济学专门处理这类数据的特殊性——观测值之间存在时间依赖性，今天的值受昨天的影响，明天的值受今天的影响。忽视这种依赖结构会导致错误的推断。

知识要点

时间序列 {Yt}\{Y_t\}{Yt​} 的一个核心概念是平稳性（stationarity）。严格平稳要求联合分布不随时间平移而改变。实践中常用的是弱平稳（协方差平稳），要求：

E(Yt)=μ（均值不变）E(Y_t) = \mu \quad \text{（均值不变）}E(Yt​)=μ（均值不变）
Var(Yt)=σ2（方差不变）\text{Var}(Y_t) = \sigma^2 \quad \text{（方差不变）}Var(Yt​)=σ2（方差不变）
Cov(Yt,Yt−k)=γk（自协方差只依赖于滞后阶数 k）\text{Cov}(Y_t, Y_{t-k}) = \gamma_k \quad \text{（自协方差只依赖于滞后阶数 $k$）}Cov(Yt​,Yt−k​)=γk​（自协方差只依赖于滞后阶数 k）

自回归模型 AR(ppp) 是最基本的时间序列模型：

Yt=c+ϕ1Yt−1+ϕ2Yt−2+⋯+ϕpYt−p+εtY_t = c + \phi_1 Y_{t-1} + \phi_2 Y_{t-2} + \cdots + \phi_p Y_{t-p} + \varepsilon_tYt​=c+ϕ1​Yt−1​+ϕ2​Yt−2​+⋯+ϕp​Yt−p​+εt​

其中 εt\varepsilon_tεt​ 是白噪声（均值为零、方差恒定、无自相关）。AR(1) 模型 Yt=c+ϕYt−1+εtY_t = c + \phi Y_{t-1} + \varepsilon_tYt​=c+ϕYt−1​+εt​ 在 ∣ϕ∣<1|\phi| < 1∣ϕ∣<1 时平稳。

移动平均模型 MA(qqq) 将当期值表示为当期和过去冲击的线性组合：

Yt=μ+εt+θ1εt−1+⋯+θqεt−qY_t = \mu + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \cdots + \theta_q \varepsilon_{t-q}Yt​=μ+εt​+θ1​εt−1​+⋯+θq​εt−q​

两者结合得到 ARMA(p,qp, qp,q) 模型。

详细讲解

自相关函数与模型识别

自相关函数（ACF）衡量 YtY_tYt​ 与 Yt−kY_{t-k}Yt−k​ 之间的线性相关程度：

ρk=γkγ0=Cov(Yt,Yt−k)Var(Yt)\rho_k = \frac{\gamma_k}{\gamma_0} = \frac{\text{Cov}(Y_t, Y_{t-k})}{\text{Var}(Y_t)}ρk​=γ0​γk​​=Var(Yt​)Cov(Yt​,Yt−k​)​

偏自相关函数（PACF）衡量控制了中间变量后 YtY_tYt​ 与 Yt−kY_{t-k}Yt−k​ 的直接相关程度。

模型识别的经典规则：

模型 ACF 特征 PACF 特征
AR(ppp) 指数衰减或正弦衰减 ppp 阶后截尾
MA(qqq) qqq 阶后截尾 指数衰减或正弦衰减
ARMA(p,qp,qp,q) 逐渐衰减 逐渐衰减

Box-Jenkins方法论将时间序列建模分为三步：识别（用ACF/PACF确定 p,qp, qp,q）、估计（极大似然估计参数）、诊断检验（检查残差是否为白噪声）。

单位根与非平稳性

许多经济时间序列（如GDP、价格指数、汇率）表现出趋势行为，不是平稳的。考虑AR(1)模型 Yt=ϕYt−1+εtY_t = \phi Y_{t-1} + \varepsilon_tYt​=ϕYt−1​+εt​：

  • 当 ∣ϕ∣<1|\phi| < 1∣ϕ∣<1 时序列平稳
  • 当 ϕ=1\phi = 1ϕ=1 时序列为随机游走：Yt=Yt−1+εtY_t = Y_{t-1} + \varepsilon_tYt​=Yt−1​+εt​

随机游走具有以下性质：E(Yt)=Y0E(Y_t) = Y_0E(Yt​)=Y0​，Var(Yt)=tσ2\text{Var}(Y_t) = t\sigma^2Var(Yt​)=tσ2。方差随时间无限增长，序列会远离初始值而不回归。

对随机游走进行回归会产生伪回归（spurious regression）问题。格兰杰和纽博尔德（1974）证明，两个相互独立的随机游走之间的OLS回归经常会得到高 R2R^2R2 和显著的 ttt 统计量，但这种"关系"纯属虚假。

单位根检验判断序列是否含有单位根。最常用的是ADF检验（Augmented Dickey-Fuller），回归方程为：

ΔYt=α+γYt−1+∑j=1pδjΔYt−j+εt\Delta Y_t = \alpha + \gamma Y_{t-1} + \sum_{j=1}^{p} \delta_j \Delta Y_{t-j} + \varepsilon_tΔYt​=α+γYt−1​+j=1∑p​δj​ΔYt−j​+εt​

原假设 H0:γ=0H_0: \gamma = 0H0​:γ=0（有单位根），备择假设 H1:γ<0H_1: \gamma < 0H1​:γ<0（平稳）。注意ADF检验的临界值不同于标准正态分布，需要使用Dickey-Fuller分布表。

协整与误差修正模型

虽然两个非平稳序列不能直接用OLS回归，但如果它们存在长期均衡关系，则可以进行有意义的分析。如果 Yt∼I(1)Y_t \sim I(1)Yt​∼I(1) 且 Xt∼I(1)X_t \sim I(1)Xt​∼I(1)，但存在某个 β\betaβ 使得 Yt−βXt∼I(0)Y_t - \beta X_t \sim I(0)Yt​−βXt​∼I(0)，则称 YtY_tYt​ 和 XtX_tXt​ 协整。

协整意味着两个变量虽然各自具有随机趋势，但它们不会长期偏离——就像一个喝醉酒的人和他的狗，各自走随机路径，但被牵狗绳限制了距离。

恩格尔-格兰杰两步法检验协整：第一步，OLS回归 Yt=α+βXt+utY_t = \alpha + \beta X_t + u_tYt​=α+βXt​+ut​；第二步，对残差 u^t\hat{u}_tu^t​ 做ADF检验。如果残差平稳，则两个序列协整。

误差修正模型（ECM）描述了短期动态如何向长期均衡调整：

ΔYt=α+λ(Yt−1−βXt−1)+γΔXt+εt\Delta Y_t = \alpha + \lambda(Y_{t-1} - \beta X_{t-1}) + \gamma \Delta X_t + \varepsilon_tΔYt​=α+λ(Yt−1​−βXt−1​)+γΔXt​+εt​

其中 λ<0\lambda < 0λ<0 是误差修正系数，表示偏离均衡后的调整速度。λ\lambdaλ 越大（绝对值），调整越快。

恩格尔和格兰杰因协整理论获2003年诺贝尔经济学奖。

VAR模型

向量自回归（VAR）模型同时处理多个时间序列变量的动态交互。二变量VAR(1)为：

(Y1tY2t)=(c1c2)+(a11a12a21a22)(Y1,t−1Y2,t−1)+(u1tu2t)\begin{pmatrix} Y_{1t} \\ Y_{2t} \end{pmatrix} = \begin{pmatrix} c_1 \\ c_2 \end{pmatrix} + \begin{pmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{pmatrix} \begin{pmatrix} Y_{1,t-1} \\ Y_{2,t-1} \end{pmatrix} + \begin{pmatrix} u_{1t} \\ u_{2t} \end{pmatrix}(Y1t​Y2t​​)=(c1​c2​​)+(a11​a21​​a12​a22​​)(Y1,t−1​Y2,t−1​​)+(u1t​u2t​​)

VAR的三个核心工具：

格兰杰因果检验：XXX 格兰杰因果于 YYY，如果加入 XXX 的滞后值能显著改善对 YYY 的预测。注意"格兰杰因果"是预测因果，不等于真实因果。

脉冲响应函数：分析一个变量受到冲击后，其他变量在未来各期的响应路径。

方差分解：将预测误差方差分解为来自不同冲击的贡献，揭示变量之间的相互影响力度。

GARCH模型

金融时间序列通常表现出波动聚集现象——高波动时期和低波动时期交替出现。GARCH(1,1) 模型刻画了条件方差的时变性：

σt2=ω+αut−12+βσt−12\sigma_t^2 = \omega + \alpha u_{t-1}^2 + \beta \sigma_{t-1}^2σt2​=ω+αut−12​+βσt−12​

其中 ω>0\omega > 0ω>0，α,β≥0\alpha, \beta \geq 0α,β≥0，α+β<1\alpha + \beta < 1α+β<1（保证方差平稳）。α\alphaα 衡量新信息对波动的冲击效应，β\betaβ 衡量波动的持续性。

拓展阅读

时间序列计量经济学的发展与宏观经济分析密切相关。克里斯托弗·西姆斯因VAR方法论获2011年诺贝尔经济学奖。罗伯特·恩格尔因ARCH/GARCH模型获2003年诺贝尔经济学奖。

推荐教材：汉密尔顿《时间序列分析》是经典参考书（数学严谨但内容全面），恩德斯《应用计量经济学：时间序列分析》更注重直觉和应用。

小结

时间序列计量处理的是具有时间依赖结构的数据。平稳性是核心概念，ARMA模型适用于平稳序列。非平稳序列需要通过单位根检验来识别，协整理论为非平稳变量之间的长期关系提供了严格框架。VAR模型是分析多变量动态交互的标准工具，GARCH模型则捕捉了金融数据的波动聚集特征。
