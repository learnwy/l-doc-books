回归分析

如何从数据中量化变量之间的关系？教育年限增加一年能提高多少收入？广告投入每增加一万元能带来多少销售额增长？回归分析是计量经济学最基础也最常用的工具，它提供了一套从噪声数据中提取信号的系统方法。

知识要点

简单线性回归模型描述因变量 YYY 与一个自变量 XXX 之间的线性关系：

Yi=β0+β1Xi+ui,i=1,2,…,nY_i = \beta_0 + \beta_1 X_i + u_i, \quad i = 1, 2, \ldots, nYi​=β0​+β1​Xi​+ui​,i=1,2,…,n

其中 β0\beta_0β0​ 是截距，β1\beta_1β1​ 是斜率（XXX 每变化一个单位，YYY 的平均变化量），uiu_iui​ 是误差项（包含了所有影响 YYY 但未被 XXX 捕捉的因素）。

多元线性回归扩展到多个自变量：

Yi=β0+β1X1i+β2X2i+⋯+βkXki+uiY_i = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + \cdots + \beta_k X_{ki} + u_iYi​=β0​+β1​X1i​+β2​X2i​+⋯+βk​Xki​+ui​

矩阵形式更为紧凑：

Y=Xβ+u\mathbf{Y} = \mathbf{X}\boldsymbol{\beta} + \mathbf{u}Y=Xβ+u

最小二乘法（OLS）的核心思想是最小化残差平方和：

β^=arg⁡min⁡β∑i=1n(Yi−Xi′β)2=(X′X)−1X′Y\hat{\boldsymbol{\beta}} = \arg\min_{\boldsymbol{\beta}} \sum_{i=1}^n (Y_i - \mathbf{X}_i'\boldsymbol{\beta})^2 = (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\mathbf{Y}β^​=argβmin​i=1∑n​(Yi​−Xi′​β)2=(X′X)−1X′Y

详细讲解

高斯-马尔科夫假设

OLS估计量的优良性质依赖于一组经典假设（高斯-马尔科夫假设）：

假设 数学表达 直觉含义
线性 Y=Xβ+uY = X\beta + uY=Xβ+u 参数进入模型是线性的
随机抽样 (Yi,Xi)(Y_i, X_i)(Yi​,Xi​) i.i.d. 观测值之间独立
无完全多重共线性 rank(X)=k+1\text{rank}(X) = k+1rank(X)=k+1 自变量之间非精确线性关系
零条件均值 E(ui∣Xi)=0E(u_i \mid X_i) = 0E(ui​∣Xi​)=0 误差项与自变量无系统关联
同方差 Var(ui∣Xi)=σ2\text{Var}(u_i \mid X_i) = \sigma^2Var(ui​∣Xi​)=σ2 误差的波动不随X变化

在这些假设下，高斯-马尔科夫定理保证OLS估计量是最佳线性无偏估计量（BLUE）——在所有线性无偏估计量中方差最小。

OLS的几何直觉

从线性代数的视角看，OLS做的是将 YYY 向量投影到由 XXX 列向量张成的子空间上。残差向量 u^=Y−Xβ^\hat{u} = Y - X\hat{\beta}u^=Y−Xβ^​ 与这个子空间正交：

X′u^=0X'\hat{u} = 0X′u^=0

这一正交条件正是一阶条件的几何表达。投影矩阵 P=X(X′X)−1X′P = X(X'X)^{-1}X'P=X(X′X)−1X′ 将 YYY 映射为拟合值 Y^=PY\hat{Y} = PYY^=PY，剩余矩阵 M=I−PM = I - PM=I−P 将 YYY 映射为残差 u^=MY\hat{u} = MYu^=MY。

假设检验与置信区间

在正态误差假设 ui∼N(0,σ2)u_i \sim N(0, \sigma^2)ui​∼N(0,σ2) 下，OLS估计量也服从正态分布：

β^j∼N(βj,σ2[(X′X)−1]jj)\hat{\beta}_j \sim N\left(\beta_j, \sigma^2 [(X'X)^{-1}]_{jj}\right)β^​j​∼N(βj​,σ2[(X′X)−1]jj​)

t=β^j−βj,0se(β^j)∼tn−k−1t = \frac{\hat{\beta}_j - \beta_{j,0}}{se(\hat{\beta}_j)} \sim t_{n-k-1}t=se(β^​j​)β^​j​−βj,0​​∼tn−k−1​

其中 se(β^j)=σ^2[(X′X)−1]jjse(\hat{\beta}_j) = \sqrt{\hat{\sigma}^2 [(X'X)^{-1}]_{jj}}se(β^​j​)=σ^2[(X′X)−1]jj​​，σ^2=∑u^i2n−k−1\hat{\sigma}^2 = \frac{\sum \hat{u}_i^2}{n-k-1}σ^2=n−k−1∑u^i2​​。

F=(SSRr−SSRur)/qSSRur/(n−k−1)∼Fq,n−k−1F = \frac{(SSR_r - SSR_{ur})/q}{SSR_{ur}/(n-k-1)} \sim F_{q, n-k-1}F=SSRur​/(n−k−1)(SSRr​−SSRur​)/q​∼Fq,n−k−1​

拟合优度

决定系数 R2R^2R2 衡量模型解释了因变量总变异的多大比例：

R2=1−SSRSST=1−∑u^i2∑(Yi−Yˉ)2R^2 = 1 - \frac{SSR}{SST} = 1 - \frac{\sum \hat{u}_i^2}{\sum (Y_i - \bar{Y})^2}R2=1−SSTSSR​=1−∑(Yi​−Yˉ)2∑u^i2​​

R2R^2R2 的问题在于它永远不会因为增加变量而下降，即使新变量毫无解释力。调整 R2R^2R2 对变量个数施加惩罚：

Rˉ2=1−SSR/(n−k−1)SST/(n−1)\bar{R}^2 = 1 - \frac{SSR/(n-k-1)}{SST/(n-1)}Rˉ2=1−SST/(n−1)SSR/(n−k−1)​

但即使是调整 R2R^2R2，也不应作为模型选择的唯一标准。一个 R2R^2R2 很低的模型仍可能产生有意义的系数估计——例如在教育回报率研究中，个人收入的大部分变异来自不可观测因素，R2R^2R2 很少超过0.3，但教育变量的系数仍然有重要的政策含义。

经典违背与修正

异方差：当 Var(ui∣Xi)=σi2\text{Var}(u_i \mid X_i) = \sigma_i^2Var(ui​∣Xi​)=σi2​ 不是常数时，OLS仍然无偏但不再有效，且标准误估计有偏。怀特（White）异方差稳健标准误提供了一种不依赖同方差假设的推断方法：

Var^(β^)=(X′X)−1(∑u^i2XiXi′)(X′X)−1\widehat{\text{Var}}(\hat{\beta}) = (X'X)^{-1}\left(\sum \hat{u}_i^2 X_i X_i'\right)(X'X)^{-1}Var(β^​)=(X′X)−1(∑u^i2​Xi​Xi′​)(X′X)−1

多重共线性：自变量之间高度相关时，(X′X)(X'X)(X′X) 接近奇异，估计量方差膨胀。方差膨胀因子（VIF）衡量共线性的严重程度：VIFj=11−Rj2VIF_j = \frac{1}{1 - R_j^2}VIFj​=1−Rj2​1​，其中 Rj2R_j^2Rj2​ 是 XjX_jXj​ 对其他自变量回归的 R2R^2R2。VIF > 10 通常被认为有严重共线性。

遗漏变量偏差：如果真实模型包含变量 ZZZ 但回归中遗漏了它，OLS估计量将有偏：

E(β^1)=β1+β2⋅Cov(X,Z)Var(X)E(\hat{\beta}_1) = \beta_1 + \beta_2 \cdot \frac{\text{Cov}(X, Z)}{\text{Var}(X)}E(β^​1​)=β1​+β2​⋅Var(X)Cov(X,Z)​

偏差的方向取决于遗漏变量 ZZZ 与 YYY 和 XXX 的相关性。这是因果推断的核心难题之一。

拓展阅读

回归分析的统计基础可以追溯到高尔顿（Galton）1886年关于父子身高"回归均值"的研究——"回归"这个名称正是由此而来。现代计量经济学的发展以Frisch和Haavelmo的工作为基础，Haavelmo因将概率方法引入计量经济学获1989年诺贝尔经济学奖。

推荐教材：伍德里奇《计量经济学导论：现代方法》（入门）和格林《计量经济分析》（进阶）。安格里斯特和皮施克《基本无害的计量经济学》则以因果推断为主线重新组织了回归方法。

小结

回归分析是计量经济学的基石。OLS通过最小化残差平方和估计参数，在高斯-马尔科夫假设下具有最佳线性无偏性。ttt 检验和 FFF 检验提供了统计推断工具。异方差、多重共线性和遗漏变量偏差是实践中需要特别警惕的问题。掌握回归分析不仅是计量经济学的起点，也是数据分析和因果推断的基本功。
