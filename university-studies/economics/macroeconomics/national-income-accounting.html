国民收入核算

一个国家的经济表现如何？GDP增长了多少？居民收入有没有提高？这些看似简单的问题背后，是一套精密的统计核算体系。国民收入核算（National Income Accounting）为宏观经济分析提供了数据基础，就像企业的财务报表之于公司管理——没有准确的账本，任何决策都是盲目的。

知识要点

国内生产总值（GDP）是一个经济体在特定时期内生产的所有最终商品和服务的市场价值总和。这个定义中的每个词都有精确含义："特定时期"指的是流量而非存量，"最终"排除了中间产品以避免重复计算，"市场价值"意味着用价格加权。

GDP有三种等价的核算方法：

支出法从需求侧计算：

GDP=C+I+G+NXGDP = C + I + G + NXGDP=C+I+G+NX

其中 CCC 为消费支出，III 为投资支出（包括固定资产投资和存货变动），GGG 为政府购买，NX=X−MNX = X - MNX=X−M 为净出口。

收入法从供给侧计算：

GDP=W+R+i+π+D+TindGDP = W + R + i + \pi + D + T_{ind}GDP=W+R+i+π+D+Tind​

其中 WWW 为工资，RRR 为租金，iii 为利息，π\piπ 为利润，DDD 为折旧，TindT_{ind}Tind​ 为间接税净额。

生产法（增加值法）将各行业增加值加总：

GDP=∑i(总产出i−中间投入i)GDP = \sum_{i} (总产出_i - 中间投入_i)GDP=i∑​(总产出i​−中间投入i​)

三种方法在理论上必然得到相同结果，因为一个人的支出必然是另一个人的收入。

详细讲解

名义GDP与实际GDP

名义GDP（nominal GDP）使用当期价格计算，实际GDP（real GDP）使用基期价格计算，从而剔除了价格变动的影响。两者的关系为：

实际GDP=名义GDPGDP平减指数×100实际GDP = \frac{名义GDP}{GDP平减指数} \times 100实际GDP=GDP平减指数名义GDP​×100

GDP平减指数（GDP deflator）衡量的是所有最终产品价格的综合变动：

GDP平减指数=名义GDP实际GDP×100GDP平减指数 = \frac{名义GDP}{实际GDP} \times 100GDP平减指数=实际GDP名义GDP​×100

假设一个经济体只生产苹果和香蕉，2020年为基期：

年份 苹果数量 苹果价格 香蕉数量 香蕉价格
2020 100 2元 200 1元
2023 120 3元 180 1.5元

2020年名义GDP = 100×2+200×1=400100 \times 2 + 200 \times 1 = 400100×2+200×1=400 元

2023年名义GDP = 120×3+180×1.5=630120 \times 3 + 180 \times 1.5 = 630120×3+180×1.5=630 元

2023年实际GDP（以2020年价格）= 120×2+180×1=420120 \times 2 + 180 \times 1 = 420120×2+180×1=420 元

GDP平减指数（2023）= 630420×100=150\frac{630}{420} \times 100 = 150420630​×100=150

实际GDP增长率 = 420−400400=5%\frac{420 - 400}{400} = 5\%400420−400​=5%，而名义GDP增长率为 630−400400=57.5%\frac{630 - 400}{400} = 57.5\%400630−400​=57.5%。差异来自价格上涨。

消费者价格指数（CPI）

CPI衡量一个固定商品篮子的价格变动，计算方法为拉斯佩尔指数：

CPIt=∑ptiq0i∑p0iq0i×100CPI_t = \frac{\sum p_t^i q_0^i}{\sum p_0^i q_0^i} \times 100CPIt​=∑p0i​q0i​∑pti​q0i​​×100

CPI与GDP平减指数的区别在于：CPI使用固定的基期商品篮子（拉斯佩尔指数），存在替代偏差——当某种商品涨价时，消费者会转向替代品，但CPI仍按原来的权重计算，因而高估了生活成本的上升。GDP平减指数使用当期数量权重（帕氏指数），涵盖所有最终产品而非仅消费品。

GDP的局限性

GDP作为经济指标有明显的缺陷。它不计入家务劳动和志愿服务等非市场活动，不扣除环境污染等负外部性，不反映收入分配状况，也不衡量休闲和生活质量。一个极端的例子：交通事故会增加GDP（修车、医疗支出），但显然不增加社会福利。

正因如此，经济学家开发了许多补充指标。人类发展指数（HDI）综合考虑预期寿命、教育水平和人均收入。绿色GDP试图扣除环境成本。不丹提出了国民幸福总值（GNH）的概念。

国民收入恒等式与储蓄-投资

从支出法出发，在封闭经济中（NX=0NX = 0NX=0）：

Y=C+I+GY = C + I + GY=C+I+G

由于国民收入要么消费、要么储蓄、要么纳税：

Y=C+S+TY = C + S + TY=C+S+T

因此：

C+I+G=C+S+TC + I + G = C + S + TC+I+G=C+S+T
I=S+(T−G)I = S + (T - G)I=S+(T−G)

即投资等于私人储蓄加政府储蓄。在开放经济中：

I=S+(T−G)+(M−X)I = S + (T - G) + (M - X)I=S+(T−G)+(M−X)

多了一项来自国外的储蓄（即贸易逆差对应的资本流入）。

这一恒等式揭示了储蓄与投资的必然联系。如果政府出现财政赤字（T<GT < GT<G），在储蓄总量不变的情况下，私人投资必然被挤出——这就是"挤出效应"的核算基础。

流量与存量的区别

GDP是流量概念（一段时间内的产出），而国民财富是存量概念（某一时点的资产总值）。类似的区别还有：储蓄（流量）与财富（存量），投资（流量）与资本（存量），赤字（流量）与债务（存量）。

某年的投资 III 增加资本存量 KKK，减去折旧 δK\delta KδK：

Kt+1=Kt+It−δKt=(1−δ)Kt+ItK_{t+1} = K_t + I_t - \delta K_t = (1 - \delta)K_t + I_tKt+1​=Kt​+It​−δKt​=(1−δ)Kt​+It​

这一资本积累方程是增长理论的基础。

练习与思考

  1. 某经济体2023年的数据如下：消费8000亿，投资2000亿，政府购买1500亿，出口1200亿，进口1000亿。计算GDP。如果间接税为500亿，折旧为800亿，计算国民收入（NI）和国内生产净值（NDP）。

  2. 一位程序员辞去年薪50万的工作，在家全职开发开源软件。从GDP核算角度，这对GDP有什么影响？这是否反映了真实经济贡献的变化？

  3. 如果2023年名义GDP增长8%，GDP平减指数上升3%，实际GDP增长率约为多少？精确公式和近似公式各给出什么结果？

  4. 中国2023年GDP约126万亿人民币，人口14亿。但按购买力平价（PPP）调整后，中国人均GDP排名大幅上升。解释PPP调整的原理和意义。

拓展阅读

国民收入核算体系（SNA）由联合国主导制定，最新版本为2008年SNA。中国从1985年开始采用与国际接轨的核算体系，2016年起将研发支出计入GDP（之前作为中间消耗），这一调整使当年GDP增加约1.3万亿元。

西蒙·库兹涅茨（Simon Kuznets）是国民收入核算的奠基人，他在1930年代为美国建立了系统的国民收入统计。有趣的是，库兹涅茨本人多次警告不要将GDP等同于福利指标。

推荐阅读曼昆《宏观经济学》第2章，或布兰查德《宏观经济学》第2章。对核算技术细节感兴趣的读者可参考联合国《2008年国民账户体系》。

小结

国民收入核算通过支出法、收入法和生产法三种途径衡量经济活动总量。名义GDP与实际GDP的区分消除了价格变动的干扰。储蓄-投资恒等式揭示了宏观经济中各部门之间的内在联系。GDP虽有局限，但仍是最广泛使用的经济健康指标，理解其核算逻辑是学习宏观经济学的必要第一步。
