化学平衡

知识要点

可逆反应在封闭体系中最终会达到一种动态平衡状态——正反应速率与逆反应速率相等，各物质浓度不再随时间变化。理解化学平衡不仅需要掌握平衡常数的数学表达，更要深入领会 Le Chatelier 原理背后的热力学逻辑。酸碱平衡作为化学平衡最常见的应用场景，贯穿了从溶液化学到生物化学的广泛领域。

核心概念 数学工具 实际应用
平衡常数 KKK KcK_cKc​, KpK_pKp​ 表达式 判断反应方向与程度
Le Chatelier 原理 反应商 QQQ 与 KKK 的比较 工业条件优化
酸碱平衡 KaK_aKa​, KbK_bKb​, KwK_wKw​, Henderson-Hasselbalch 缓冲溶液设计
溶度积 KspK_{sp}Ksp​ 沉淀生成与溶解

详细讲解

平衡常数的定义

对于一般反应：

aA+bB⇌cC+dDaA + bB \rightleftharpoons cC + dDaA+bB⇌cC+dD

以浓度表示的平衡常数为：

Kc=[C]c[D]d[A]a[B]bK_c = \frac{[C]^c [D]^d}{[A]^a [B]^b}Kc​=[A]a[B]b[C]c[D]d​

以分压表示的平衡常数为：

Kp=pCc⋅pDdpAa⋅pBbK_p = \frac{p_C^c \cdot p_D^d}{p_A^a \cdot p_B^b}Kp​=pAa​⋅pBb​pCc​⋅pDd​​

两者之间的关系：

Kp=Kc(RT)ΔnK_p = K_c (RT)^{\Delta n}Kp​=Kc​(RT)Δn

其中 Δn=(c+d)−(a+b)\Delta n = (c + d) - (a + b)Δn=(c+d)−(a+b) 是气态产物与反应物计量系数之差。KKK 值只与温度有关，与浓度、压力无关。

KKK 的数值大小直接反映反应进行的程度：

KKK 范围 平衡位置 含义
K≫1K \gg 1K≫1 偏向产物 反应几乎完全
K≈1K \approx 1K≈1 中间位置 反应物与产物共存
K≪1K \ll 1K≪1 偏向反应物 反应进行程度很小

反应商与平衡判据

反应商 QQQ 的表达式与 KKK 完全相同，但使用任意时刻的浓度（而非平衡浓度）：

Qc=[C]c[D]d[A]a[B]b∣任意时刻Q_c = \frac{[C]^c [D]^d}{[A]^a [B]^b} \bigg|_{\text{任意时刻}}Qc​=[A]a[B]b[C]c[D]d​​任意时刻​
Le Chatelier 原理
当外界条件改变打破平衡时，系统将自发地向减弱这种改变的方向移动，以建立新的平衡。


浓度变化：增加反应物浓度 → 平衡正移；增加产物浓度 → 平衡逆移。本质是使 Q<KQ < KQ<K 或 Q>KQ > KQ>K，系统调节至 Q=KQ = KQ=K。


压力变化（仅影响气态组分）：增大压力（减小体积）→ 平衡向气体分子数减少的方向移动。对 Δn=0\Delta n = 0Δn=0 的反应无影响。


温度变化：升温有利于吸热方向。从热力学角度：


ln⁡K=−ΔrG∘RT=−ΔrH∘RT+ΔrS∘R\ln K = -\frac{\Delta_r G^\circ}{RT} = -\frac{\Delta_r H^\circ}{RT} + \frac{\Delta_r S^\circ}{R}lnK=−RTΔr​G∘​=−RTΔr​H∘​+RΔr​S∘​
van't Hoff 方程描述了 KKK 随温度的变化：


dln⁡KdT=ΔrH∘RT2\frac{d \ln K}{dT} = \frac{\Delta_r H^\circ}{RT^2}dTdlnK​=RT2Δr​H∘​
积分形式：


ln⁡K2K1=−ΔrH∘R(1T2−1T1)\ln\frac{K_2}{K_1} = -\frac{\Delta_r H^\circ}{R}\left(\frac{1}{T_2} - \frac{1}{T_1}\right)lnK1​K2​​=−RΔr​H∘​(T2​1​−T1​1​)

拓展阅读
    

  • 多重平衡耦合：当体系中同时存在多个平衡（如沉淀-配位平衡），总平衡常数等于各分步平衡常数之积。这是分析化学中分离与检测的理论基础。
    • 

  • 活度与浓度：严格意义上，平衡常数应使用活度 aaa 而非浓度 ccc。对于稀溶液，a≈c/c∘a \approx c / c^\circa≈c/c∘（其中 c∘=1  mol/Lc^\circ = 1\;\text{mol/L}c∘=1mol/L），但在高离子强度溶液中必须引入活度系数 γ\gammaγ。

小结
化学平衡的核心在于理解 KKK 作为反应热力学标尺的意义：它告诉我们反应"能走多远"。反应商 QQQ 则提供了判断系统当前偏离平衡程度和方向的工具。Le Chatelier 原理将这种数学关系转化为直觉性的预测规则。酸碱平衡、缓冲溶液和溶度积是化学平衡在水溶液化学中的三大具体应用，它们构成了分析化学、生物化学和环境化学的基础工具箱。
