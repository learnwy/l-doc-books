原子结构与化学键

知识要点

理解原子内部的电子排布方式，是打开化学世界大门的第一把钥匙。从玻尔模型到量子力学模型，人类对原子结构的认识经历了深刻变革。掌握电子构型后，我们能够理解元素周期表中的规律性变化——原子半径、电离能、电负性——这些性质直接决定了元素如何形成化学键，进而构建出我们所见的万千物质。

本节覆盖三大核心主题：

主题 关键概念 应用场景
电子构型 量子数、轨道填充规则、屏蔽效应 预测元素化学性质
周期趋势 原子半径、电离能、电子亲和能、电负性 比较元素活性
化学键 离子键、共价键、金属键、分子间作用力 解释物质物理化学性质

详细讲解

电子填充规则

三条规则决定了多电子原子的电子构型：

构造原理（Aufbau Principle）：电子按能量从低到高依次填入轨道。轨道能量的近似顺序为：

1s<2s<2p<3s<3p<4s<3d<4p<5s<4d<5p<6s<4f<5d<6p1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p1s<2s<2p<3s<3p<4s<3d<4p<5s<4d<5p<6s<4f<5d<6p

泡利不相容原理：同一原子中，不存在四个量子数完全相同的两个电子。换言之，每个轨道最多容纳 2 个自旋相反的电子。

洪特规则：在等价轨道（如三个 2p2p2p 轨道）中，电子尽可能分占不同轨道且自旋平行，以获得最低能量状态。

以铁（Fe, Z=26Z = 26Z=26）为例，其电子构型为：

简写为 [Ar] 4s2 3d6[\text{Ar}]\, 4s^2\, 3d^6[Ar]4s23d6。

有效核电荷与屏蔽效应
外层电子感受到的核电荷并非完整的 ZZZ，而是被内层电子部分屏蔽后的有效核电荷 ZeffZ_{\text{eff}}Zeff​：


Zeff=Z−σZ_{\text{eff}} = Z - \sigmaZeff​=Z−σ
其中 σ\sigmaσ 是屏蔽常数，可由 Slater 规则近似估算。ZeffZ_{\text{eff}}Zeff​ 越大，电子被束缚得越紧，原子半径越小。


周期趋势
原子半径：同一周期从左到右，ZeffZ_{\text{eff}}Zeff​ 增大，原子半径减小；同一族从上到下，主量子数 nnn 增大，原子半径增大。


第一电离能 I1I_1I1​：气态原子失去最外层一个电子所需的最低能量：

化学键的类型
离子键：电负性差大的原子间，电子从金属转移到非金属，形成阳离子与阴离子之间的库仑引力。晶格能 UUU 可由 Born-Landé 方程估算：

拓展阅读
    

  • Slater 规则的局限：对于过渡金属元素，Slater 规则给出的屏蔽常数误差较大，更精确的方法包括 Clementi-Raimondi 参数和自洽场（SCF）计算。
    • 

  • 相对论效应：对于重元素（如 Au\text{Au}Au、Hg\text{Hg}Hg），内层电子速度接近光速，导致 sss 轨道收缩和 ddd 轨道膨胀，这解释了金的颜色和汞在常温下为液态。
    • 

  • 元素周期表的扩展：第 7 周期和第 8 周期的超重元素（如 Og\text{Og}Og, Z=118Z = 118Z=118）的电子构型预测需要考虑强烈的自旋-轨道耦合效应。

  • 推荐自学资源：P. Atkins《化学原理》第 1-3 章；MIT OpenCourseWare 5.111 课程视频。

小结
原子结构是一切化学现象的微观基础。从四个量子数出发，我们建立了电子构型的完整图景；通过有效核电荷的概念理解了周期趋势的内在逻辑；最后将这些知识应用于化学键的形成机制——离子键依靠电子转移、共价键依靠电子共享、金属键依靠电子离域。掌握这些基础概念后，便能自如地分析物质的结构与性质，为后续的化学平衡、反应动力学和有机化学学习打下坚实根基。
