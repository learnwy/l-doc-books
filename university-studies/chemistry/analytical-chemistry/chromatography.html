色谱分析

色谱法是一类基于物质在两相（固定相和流动相）间分配差异来实现分离的技术。从混合药物的纯度检测到环境污染物的痕量分析，从蛋白质的分离纯化到食品中农药残留的检测，色谱法是分析化学中应用最广泛的分离与检测手段。

知识要点

色谱的基本原理：样品混合物随流动相通过固定相时，各组分因与固定相相互作用的强弱不同而以不同速度移动，最终实现分离。分配系数 KKK 定义为组分在固定相和流动相中浓度的比值：

K=cscmK = \frac{c_s}{c_m}K=cm​cs​​

KKK 值越大，组分在固定相上保留越强，出峰越晚。

色谱柱效与分离度：理论塔板数 NNN 衡量色谱柱的分离效率：

N=16(tRW)2N = 16\left(\frac{t_R}{W}\right)^2N=16(WtR​​)2

其中 tRt_RtR​ 是保留时间，WWW 是峰宽。NNN 越大，柱效越高。van Deemter 方程描述了板高 HHH 与流速 uuu 的关系：

H=A+Bu+CuH = A + \frac{B}{u} + CuH=A+uB​+Cu

其中 AAA 是涡流扩散项，BBB 是纵向分子扩散项，CCC 是传质阻力项。最佳流速 uopt=B/Cu_{\text{opt}} = \sqrt{B/C}uopt​=B/C​。

色谱类型 流动相 固定相 适用范围
气相色谱（GC） 载气（He, N2_22​） 液膜/固体吸附剂 挥发性有机物
高效液相色谱（HPLC） 液体溶剂 键合硅胶等 非挥发性、热不稳定物质
薄层色谱（TLC） 液体溶剂 硅胶/氧化铝薄层 快速定性筛查
离子色谱（IC） 电解质溶液 离子交换树脂 无机离子
凝胶渗透色谱（GPC） 有机溶剂/水 多孔凝胶 聚合物分子量分布

详细讲解

气相色谱（GC）

GC 适用于沸点低于约 300°C 的化合物。样品在进样口气化后，被载气带入色谱柱。现代 GC 主要使用毛细管柱（内径 0.1-0.5 mm，长度 15-60 m），内壁涂覆固定液。

程序升温是 GC 分析的常用技术——柱温从低温开始线性升高，使不同沸点的组分依次洗脱。低沸点组分在低温时就被分离，高沸点组分在高温时才出峰。

GC 的检测器类型：

检测器 缩写 检测原理 灵敏度 选择性
氢火焰离子化 FID 有机物燃烧产生离子 pg 级 通用（有机）
热导 TCD 热导率变化 ng 级 通用
电子捕获 ECD 电负性化合物捕获电子 fg 级 卤代物、硝基化合物
质谱 MS 质荷比分离 pg 级 结构鉴定

GC-MS 联用是最强大的分析工具之一——GC 提供分离能力，MS 提供结构鉴定能力。

高效液相色谱（HPLC）

HPLC 使用高压（通常 100-400 bar）将流动相泵入填充柱。按分离机制分为：

  • 反相色谱（RP-HPLC）：非极性固定相（如 C18）+ 极性流动相（水/有机溶剂梯度）。极性强的组分先出峰。覆盖约 80% 的 HPLC 应用。
  • 正相色谱（NP-HPLC）：极性固定相（硅胶）+ 非极性流动相。极性弱的组分先出峰。
  • 离子交换色谱：带电固定相，通过静电作用分离离子。
  • 体积排阻色谱（SEC）：多孔凝胶，按分子大小分离。

梯度洗脱是 HPLC 中的重要技术——流动相组成在分析过程中连续变化（如水/乙腈比例），类似于 GC 的程序升温。

薄层色谱（TLC）

TLC 是最简单快速的色谱方法。将样品点在硅胶板上，放入含展开剂的缸中，溶剂通过毛细作用上升，将不同组分带到不同高度。RfR_fRf​ 值（前沿比移值）用于定性鉴定：

Rf=组分移动距离溶剂前沿移动距离R_f = \frac{\text{组分移动距离}}{\text{溶剂前沿移动距离}}Rf​=溶剂前沿移动距离组分移动距离​

TLC 常用于反应监控（确认反应是否完成）和柱色谱条件的预筛选。

小结
色谱法的核心思想是"分配差异导致分离"。从简单的薄层色谱到高效液相色谱和气相色谱-质谱联用，技术的进步不断提升分离效率和检测灵敏度。理解 van Deemter 方程和选择合适的固定相/流动相组合是优化色谱条件的关键。掌握色谱技术，就是掌握了"从混合物中提取信息"的系统方法。
