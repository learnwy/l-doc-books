计算机视觉基础

知识要点

计算机视觉（Computer Vision, CV）致力于让机器像人类一样"看懂"图像和视频。这个目标看似简单——我们每时每刻都在毫不费力地识别物体、理解场景——但对计算机而言，图像不过是一个巨大的数值矩阵，从中提取有意义的信息需要精妙的算法设计。从传统的手工特征方法到深度学习驱动的端到端系统，计算机视觉已经在人脸识别、自动驾驶、医学影像分析等领域达到甚至超越人类水平。

本节涵盖以下核心知识点：

  • 图像预处理技术
  • 边缘检测与传统特征提取（SIFT/HOG）
  • 图像分类的发展
  • 语义分割
  • 实例分割
  • 图像生成（GAN 与扩散模型）

详细讲解

图像预处理

数字图像本质上是一个三维数组——高度 × 宽度 × 通道（RGB），每个像素值通常在 [0,255][0, 255][0,255] 范围内。图像预处理的目标是将原始图像转化为更适合模型处理的形式。

常用预处理操作：

操作 目的 方法
归一化 统一数值范围 像素值除以 255 或减均值除标准差
缩放 统一输入尺寸 双线性插值、bicubic 插值
灰度化 减少通道维度 Y=0.299R+0.587G+0.114BY = 0.299R + 0.587G + 0.114BY=0.299R+0.587G+0.114B
直方图均衡化 增强对比度 累积分布函数映射
高斯模糊 去噪 高斯卷积核

对于深度学习模型，标准的预处理流程通常是：缩放到固定尺寸（如 224×224224 \times 224224×224）→ 转换为浮点数 → 减去 ImageNet 均值 → 除以 ImageNet 标准差。这种标准化方式源于大多数预训练模型都在 ImageNet 上训练的事实。

色彩空间转换也是重要的预处理手段。除了 RGB 之外，HSV（色调-饱和度-明度）空间在颜色检测中更直观；Lab 空间在颜色差异计算中更符合人类感知。

边缘检测与传统特征提取

在深度学习兴起之前，计算机视觉严重依赖手工设计的特征提取器。

边缘检测是最基础的低级视觉任务。边缘出现在图像灰度值急剧变化的地方，对应数学上的梯度：

Gx=∂I∂x,Gy=∂I∂yG_x = \frac{\partial I}{\partial x}, \quad G_y = \frac{\partial I}{\partial y}Gx​=∂x∂I​,Gy​=∂y∂I​

Canny 边缘检测器（1986）至今仍是最常用的边缘检测算法，它包含五个步骤：高斯平滑 → 计算梯度幅值和方向 → 非极大值抑制 → 双阈值处理 → 边缘跟踪。

SIFT（Scale-Invariant Feature Transform）：Lowe 于 1999 年提出，能检测并描述图像中的局部特征点，具有尺度不变性和旋转不变性。SIFT 的核心步骤：

  1. 尺度空间极值检测：在不同尺度的高斯差分（DoG）金字塔中寻找极值点
  2. 关键点精确定位：通过二次拟合精确确定关键点的位置和尺度
  3. 方向分配：基于关键点邻域的梯度方向直方图确定主方向
  4. 特征描述：提取 4×44 \times 44×4 个子区域的梯度方向直方图，形成 128 维的描述向量

SIFT 特征在图像匹配、全景拼接和三维重建中曾是核心工具。

HOG（Histogram of Oriented Gradients）：Dalal 和 Triggs 于 2005 年提出，专为行人检测设计。它将图像划分为小的单元格（cell），在每个单元格内计算梯度方向直方图，然后在更大的块（block）内进行归一化。HOG + SVM 的组合在行人检测上表现优异，是 DPM（Deformable Parts Model）等经典检测器的基础。

图像分类

图像分类是计算机视觉的核心任务：给定一张图像，判断它属于哪个预定义类别。

传统方法的流程是：手工特征提取（SIFT/HOG）→ 特征编码（词袋模型/Fisher Vector）→ 分类器（SVM）。这种流程需要大量的领域知识来设计特征，且难以泛化到新的领域。

深度学习方法打破了这一范式：让网络自动从原始像素中学习层次化的特征表示。AlexNet（2012）在 ImageNet 竞赛上的胜利标志着这一转折点。

ImageNet 大规模视觉识别挑战赛（ILSVRC）上的 top-5 错误率演变清晰地展示了进步的速度：

年份 模型 Top-5 错误率
2011 传统方法 25.8%
2012 AlexNet 15.3%
2014 GoogLeNet 6.7%
2015 ResNet 3.6%
人类 — ~5.1%

2015 年 ResNet 的错误率已低于人类水平。此后的研究重心逐渐转向效率（EfficientNet）、自监督学习和 Vision Transformer。

语义分割

**语义分割（Semantic Segmentation）**对图像中的每个像素进行分类，输出一张与输入同尺寸的标签图。与图像分类（整图一个标签）不同，语义分割提供了像素级别的理解。

关键架构：

FCN（Fully Convolutional Network, 2015）：将分类网络中的全连接层替换为卷积层，通过反卷积（转置卷积）将低分辨率的特征图上采样到原始尺寸。FCN 是端到端语义分割的开创性工作。

U-Net（2015）：为医学图像分割设计的编码器-解码器架构。其标志性特征是跳跃连接——将编码器各层的高分辨率特征直接拼接到解码器对应层，保留了精细的空间信息。

DeepLab 系列：引入了**空洞卷积（Atrous/Dilated Convolution）来扩大感受野而不减少分辨率，以及ASPP（Atrous Spatial Pyramid Pooling）**来捕捉多尺度上下文。


语义分割的评估指标是平均交并比（mIoU）：


IoUc=∣Pc∩Gc∣∣Pc∪Gc∣\text{IoU}_c = \frac{|P_c \cap G_c|}{|P_c \cup G_c|}IoUc​=∣Pc​∪Gc​∣∣Pc​∩Gc​∣​
mIoU=1C∑c=1CIoUc\text{mIoU} = \frac{1}{C}\sum_{c=1}^{C} \text{IoU}_cmIoU=C1​c=1∑C​IoUc​
其中 PcP_cPc​ 和 GcG_cGc​ 分别是类别 ccc 的预测像素集合和真实像素集合。


实例分割
**实例分割（Instance Segmentation）**在语义分割的基础上进一步区分同一类别的不同实例。例如，语义分割会将所有人标记为"人"类，而实例分割会将每个人标记为不同的实例。


Mask R-CNN（2017）是实例分割的里程碑方法，它在 Faster R-CNN 的基础上增加了一个掩码预测分支：


    

  1. 骨干网络（如 ResNet-FPN）提取多尺度特征
    2. 

  2. RPN 生成候选区域
    3. 

  3. RoI Align（替代原来的 RoI Pooling）精确提取每个候选区域的特征
    4. 

  4. 三个并行头：分类头、边界框回归头、掩码头（为每个实例生成像素级掩码）
    5. 



RoI Align 通过双线性插值替代了 RoI Pooling 中的量化操作，消除了像素对齐误差，对掩码质量至关重要。


后续方法如 SOLO、Panoptic Segmentation 进一步统一了语义分割和实例分割：全景分割同时输出"stuff"类别（天空、草地等不可数区域）的语义标签和"thing"类别（人、车等可数物体）的实例标签。


图像生成
图像生成是计算机视觉中最令人兴奋的方向之一——让机器创造逼真的新图像。


GAN（Generative Adversarial Network, 2014）：Goodfellow 提出的对抗训练框架，包含两个相互博弈的网络：


    

  • 生成器 GGG：从随机噪声 zzz 生成假图像
    • 

  • 判别器 DDD：判断图像是真是假
    • 



训练目标是一个极小极大博弈：


min⁡Gmax⁡D Ex∼pdata[log⁡D(x)]+Ez∼pz[log⁡(1−D(G(z)))]\min_G \max_D \, \mathbb{E}_{x \sim p_\text{data}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]Gmin​Dmax​Ex∼pdata​​[logD(x)]+Ez∼pz​​[log(1−D(G(z)))]
GAN 的变体（StyleGAN、CycleGAN、Pix2Pix 等）在人脸生成、风格迁移、图像修复等任务上取得了惊人的效果。但 GAN 训练不稳定，容易出现模式坍塌（mode collapse）——生成器只学会生成少数几种样本。


**扩散模型（Diffusion Model, 2020-2022）**逐渐取代 GAN 成为图像生成的主流方法。其核心思想：


前向过程（加噪）：逐步向图像添加高斯噪声，直到变成纯噪声：


q(xt∣xt−1)=N(xt;1−βt xt−1,βtI)q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1 - \beta_t} \, x_{t-1}, \beta_t I)q(xt​∣xt−1​)=N(xt​;1−βt​​xt−1​,βt​I)
反向过程（去噪）：训练一个神经网络学习逆过程——从噪声中逐步恢复出清晰图像：


pθ(xt−1∣xt)=N(xt−1;μθ(xt,t),σt2I)p_\theta(x_{t-1} | x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \sigma_t^2 I)pθ​(xt−1​∣xt​)=N(xt−1​;μθ​(xt​,t),σt2​I)
扩散模型的训练目标简化为预测每一步添加的噪声：


L=Et,x0,ϵ[∥ϵ−ϵθ(xt,t)∥2]L = \mathbb{E}_{t, x_0, \epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]L=Et,x0​,ϵ​[∥ϵ−ϵθ​(xt​,t)∥2]
DALL-E 2、Stable Diffusion 和 Midjourney 都基于扩散模型。与 GAN 相比，扩散模型训练更稳定、生成的多样性更好，但推理速度较慢（需要多步迭代去噪）。

练习与思考
    

  1. 特征提取对比：选择一张图像，分别使用 Canny 边缘检测和预训练 CNN（如 VGG-16 第一层）提取特征。可视化结果，讨论手工特征和学习特征的异同。
    

    2. 

  2. 语义分割实践：使用 PyTorch 的 torchvision 中预训练的 DeepLabV3 模型，对一张街景图像进行语义分割。可视化分割结果，观察模型在不同类别上的表现差异。
    

    3. 

  3. IoU 计算：给定一个 4×44 \times 44×4 的像素网格，真实标签和预测标签如下。手动计算每个类别的 IoU 和 mIoU。
    

    4. 

  4. GAN vs 扩散模型：从理论角度分析为什么 GAN 容易出现模式坍塌而扩散模型不会。提示：考虑两者的训练目标和优化方式的区别。
    

    5. 

  5. 应用思考：自动驾驶系统中同时需要目标检测和语义分割。如果只能选择一种方法，你会选择哪种？如果资源允许同时使用两种，如何有效融合它们的输出？

小结
计算机视觉从底层的图像预处理和边缘检测出发，经过特征提取（SIFT/HOG）和分类器的传统范式，进入了深度学习驱动的端到端学习时代。图像分类、语义分割和实例分割分别在不同粒度上理解图像内容——从整图标签到像素级别的类别和实例区分。图像生成领域的 GAN 和扩散模型则展示了 AI 不仅能"看懂"图像，还能"创造"图像。这些技术共同构成了现代视觉 AI 的完整技术栈，从感知到理解再到生成，为自动驾驶、医疗诊断、创意设计等应用提供了强大的基础能力。
