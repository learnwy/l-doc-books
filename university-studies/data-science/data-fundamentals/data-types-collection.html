数据科学 — 数据类型与采集

知识要点

数据是数据科学一切工作的起点，理解不同数据类型的特征以及掌握高效的数据采集方法，是构建可靠分析流程的第一步。现实世界中的数据来源极为多样——从企业数据库中的结构化表格，到社交媒体上的文本和图片，再到物联网传感器不断产生的实时流数据。作为自学者，你需要建立一套完整的数据分类框架，并学会根据具体场景选择合适的采集策略。

按结构维度划分，数据可分为三大类：

  • 结构化数据：以行列形式存储于关系型数据库或电子表格中，每条记录有固定的字段和类型。典型例子包括用户注册表、交易流水、传感器读数表等。
  • 半结构化数据：具有一定组织形式但不遵循严格的表格模式，常见的有 JSON、XML、YAML 文件以及日志文本。它们可以嵌套、可以有可选字段。
  • 非结构化数据：没有预定义模式的数据，如图片、音频、视频、自由文本。这类数据占全球数据总量的 80%80\%80% 以上，是当今 AI 和深度学习的主要输入。

数据质量决定了分析结论的可信度。衡量数据质量的四个核心维度是：

维度 含义 典型问题
完整性 数据是否存在缺失 用户地址字段为空
准确性 数据值是否反映真实情况 年龄字段出现 −5-5−5
一致性 同一实体在不同系统中是否一致 姓名拼写不统一
时效性 数据是否反映最新状态 库存数据延迟 242424 小时

详细讲解

结构化、半结构化与非结构化数据

结构化数据最早出现在 1970 年代关系模型诞生之后。Edgar Codd 提出的关系代数奠定了 SQL 数据库的理论基础，使得结构化数据拥有严格的 Schema 约束。每一列都有明确的数据类型（整数、浮点、字符串、日期等），这让查询优化器可以高效地执行 JOIN、GROUP BY 等操作。

半结构化数据在 Web 2.0 时代迅速增长。JSON 成为 REST API 的事实标准，一个典型的响应可能长这样：

{
  "user_id": 42,
  "name": "张三",
  "tags": ["数据分析", "Python"],
  "address": null
}

注意 tags 是一个数组，address 可能缺失——这种灵活性正是半结构化数据的优势，但也给下游处理带来挑战。

非结构化数据的处理通常需要先进行特征提取。例如图像可以通过卷积神经网络（CNN）转化为向量表示，文本可以通过词嵌入（Word2Vec、BERT）映射到高维空间。自学者在接触非结构化数据时，建议先从文本数据入手，因为 Python 的 pandas + re 就能完成大部分基础操作。

数据采集方法

不同的数据来源对应不同的采集技术：

API 采集：大多数互联网平台提供 RESTful 或 GraphQL API。使用 Python 的 requests 库可以快速完成数据拉取。需要注意的是速率限制（Rate Limit）、鉴权方式（API Key、OAuth 2.0）以及分页策略（offset/cursor）。

网络爬虫：当没有公开 API 时，爬虫是常用的替代方案。Scrapy 和 BeautifulSoup 是 Python 生态中最流行的工具。爬虫开发中需要特别关注 robots.txt 协议、请求频率控制以及反爬机制（验证码、IP 封禁）。

传感器与 IoT 设备：温度、湿度、加速度等物理量通过传感器采集后，经由 MQTT 或 HTTP 协议传输到数据平台。边缘计算的兴起使得部分预处理可以在设备端完成，减少网络传输量。

日志采集：服务器日志、应用日志是运维和用户行为分析的重要数据源。ELK 栈（Elasticsearch + Logstash + Kibana）和 Fluentd 是业界主流的日志采集架构。

抽样方法

当总体数据量过大或获取成本过高时，抽样成为必要手段。常见的概率抽样方法包括：

  • 简单随机抽样：每个样本被选中的概率相等，即 P(xi)=1NP(x_i) = \frac{1}{N}P(xi​)=N1​
  • 分层抽样：先将总体按某个属性分层，再在每层内随机抽样。适用于各层差异较大的场景，如按地区分层调查收入水平
  • 系统抽样：从随机起点开始，每隔固定间隔 kkk 抽取一个样本。间隔 k=⌊N/n⌋k = \lfloor N/n \rfloork=⌊N/n⌋，其中 NNN 为总体大小，nnn 为样本大小

非概率抽样（如便利抽样、滚雪球抽样）在探索性研究中也有应用，但其统计推断能力有限。

数据标注与众包

在监督学习场景下，数据标注是获取训练标签的关键步骤。标注方式包括：

  • 人工标注：准确率高但成本大，适合医学影像等高精度需求
  • 众包标注：通过 Amazon Mechanical Turk、Toloka 等平台分发标注任务。关键在于设计合理的标注指南、引入一致性校验（如 Cohen's Kappa 系数 κ\kappaκ）和质量控制机制
  • 半自动标注：先用模型预标注，再由人工修正。Active Learning 策略可以优先标注模型最不确定的样本

数据伦理

数据采集不是技术问题这么简单。GDPR（欧盟通用数据保护条例）、CCPA（加州消费者隐私法案）等法规对数据采集和使用提出了严格要求。核心原则包括：

  • 知情同意：用户必须明确知道数据如何被收集和使用
  • 最小必要：只采集完成目的所需的最少数据
  • 匿名化：通过 kkk-匿名、差分隐私（ϵ\epsilonϵ-DP）等技术保护个人隐私
  • 可解释性：数据使用决策应当可追溯和解释

练习与思考

  1. 在你常用的某个网站或 App 上，尝试区分它可能收集的结构化、半结构化和非结构化数据各有哪些。
  2. 使用 Python requests 库调用一个公开 API（如 GitHub API 或天气 API），获取 JSON 数据并用 pandas 转化为 DataFrame。观察哪些字段是嵌套的，如何展平。
  3. 假设你要对某大学食堂的满意度做调查，有 500050005000 名学生分布在 444 个校区。设计一个分层抽样方案，说明分层依据和每层的样本量计算方法。
  4. 思考：如果一个爬虫项目采集了用户的公开社交媒体数据用于情感分析研究，这是否涉及伦理问题？应该如何规避风险？
  5. Cohen's Kappa 系数定义为 κ=po−pe1−pe\kappa = \frac{p_o - p_e}{1 - p_e}κ=1−pe​po​−pe​​，其中 pop_opo​ 是观察一致率，pep_epe​ 是期望一致率。如果两个标注员对 100100100 张图片分类的一致率为 0.850.850.85，而随机一致率为 0.500.500.50，计算 κ\kappaκ 并评价标注质量。

拓展阅读

  • 《Python for Data Analysis》（Wes McKinney）：pandas 创始人的经典著作，涵盖了数据加载、清洗和初步分析的全流程
  • Google Dataset Search（https://datasetsearch.research.google.com）：寻找公开数据集的强大工具
  • Kaggle Datasets：数千个开放数据集，附带社区讨论和 Notebook 示例，是实践数据采集和处理的理想平台
  • Data Ethics 课程（fast.ai）：从实践角度探讨数据伦理问题，适合技术背景的自学者
  • 《Designing Data-Intensive Applications》（Martin Kleppmann）：深入理解数据系统的设计原则，第一部分对数据模型的讨论非常精彩

小结

数据类型与采集是数据科学旅程的第一站。结构化数据适合传统统计分析，半结构化数据需要灵活的解析策略，非结构化数据则依赖特征提取技术。在采集方面，API、爬虫、传感器和日志各有适用场景。抽样方法帮助我们在资源有限时获得有代表性的数据子集。数据标注是监督学习的关键环节，而数据伦理则提醒我们技术能力必须与责任意识并行。掌握这些基础知识后，你就可以进入下一步——数据清洗与预处理，将原始数据转化为可分析的形式。
