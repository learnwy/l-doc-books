数据科学 — 数据清洗与预处理

知识要点

真实世界的数据几乎不会以完美的形式出现在你面前。缺失值、重复记录、格式不一致、异常值——这些"脏数据"问题在任何数据项目中都不可避免。数据科学界有一个广为流传的说法：数据科学家将 80%80\%80% 的时间花在数据清洗上，只有 20%20\%20% 的时间用于建模和分析。虽然这个比例因项目而异，但它准确反映了数据预处理的重要性。

数据清洗与预处理的核心任务包括：

  • 缺失值处理：识别数据中的空缺并采取合理策略填补或删除
  • 异常值检测：发现偏离正常分布的极端观测值并决定如何处理
  • 数据标准化与归一化：将不同量纲的特征映射到统一的尺度范围
  • 特征编码：将类别型变量转化为模型可处理的数值表示
  • 特征工程：从原始特征中构造更具预测力的新特征
  • 数据管道自动化：将清洗和转换步骤封装为可重复执行的流水线

掌握这些技能意味着你能够将杂乱无章的原始数据转化为干净、规范、可建模的数据集。

详细讲解

缺失值处理

缺失值的产生原因多种多样：用户跳过了某个表单字段、传感器暂时故障、系统间数据同步延迟等。在 Python 中，pandas 用 NaN（Not a Number）表示缺失值，isnull() 和 info() 是排查的第一步。

常见的处理策略：

删除法适用于缺失比例较小的情况。如果某列的缺失率超过 50%50\%50%，通常建议直接删除该列。如果某行的缺失字段过多，也可以删除该行。但删除法会减少样本量，可能引入选择偏差。

统计插补法是最常用的方案：

  • 数值型特征：用均值 xˉ=1n∑i=1nxi\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_ixˉ=n1​∑i=1n​xi​ 或中位数填充。中位数对异常值更鲁棒
  • 类别型特征：用众数填充
  • 时间序列：用前向填充（ffill）或后向填充（bfill），保持时间连续性

模型预测法将缺失字段视为目标变量，用其他完整字段作为输入特征训练模型（如 KNN、随机森林）来预测缺失值。sklearn.impute.KNNImputer 提供了开箱即用的实现。

多重插补法（MICE）通过多次迭代生成多个填补数据集，最终合并结果以反映缺失带来的不确定性。Python 的 fancyimpute 库实现了此方法。

异常值检测

异常值可能是真实的极端事件（如股市闪崩），也可能是数据录入错误。关键在于区分这两种情况。

IQR 方法基于四分位距：

IQR=Q3−Q1IQR = Q_3 - Q_1IQR=Q3​−Q1​

将低于 Q1−1.5×IQRQ_1 - 1.5 \times IQRQ1​−1.5×IQR 或高于 Q3+1.5×IQRQ_3 + 1.5 \times IQRQ3​+1.5×IQR 的观测视为异常值。这正是箱线图中"须"的计算方式。

Z-score 方法衡量每个观测偏离均值的标准差数：

z=x−μσz = \frac{x - \mu}{\sigma}z=σx−μ​

通常取 ∣z∣>3|z| > 3∣z∣>3 作为异常阈值，前提是数据近似正态分布。

Isolation Forest是一种基于树的无监督方法，其核心思想是异常点更容易被孤立——随机分割时，异常点所需的分割次数更少。sklearn.ensemble.IsolationForest 是常用实现，特别适合高维数据。

数据标准化与归一化

不同特征的量纲差异会严重影响基于距离的算法（KNN、SVM、K-Means）。两种常见的缩放方法：

Min-Max 归一化将数据缩放到 [0,1][0, 1][0,1] 区间：

x′=x−xminxmax−xminx' = \frac{x - x_{min}}{x_{max} - x_{min}}x′=xmax​−xmin​x−xmin​​

Z-score 标准化使数据均值为 000、标准差为 111：

x′=x−μσx' = \frac{x - \mu}{\sigma}x′=σx−μ​

归一化适合有明确边界的场景（如像素值 000-255255255），标准化适合特征分布接近正态的场景。在 sklearn 中分别对应 MinMaxScaler 和 StandardScaler。

特征编码

机器学习模型需要数值输入，因此类别型特征必须经过编码：

编码方式 适用场景 优劣
独热编码（One-Hot） 无序类别，类别数较少 维度爆炸风险，但不引入虚假顺序
标签编码（Label） 有序类别（如学历等级） 简洁，但可能误导模型认为数值有距离含义
目标编码（Target） 高基数类别特征 利用目标信息，但容易过拟合，需交叉验证

独热编码会将一个有 kkk 个类别的特征扩展为 kkk（或 k−1k-1k−1）个二值列。当类别数达到数千时（如城市名），这种方式会导致极高的维度。此时目标编码是更好的选择——将每个类别替换为该类别下目标变量的均值。

特征工程

特征工程是从原始数据中提取隐含信息的艺术：

  • 交叉特征：将两个特征组合。例如电商场景中，将"浏览次数"和"购买次数"组合为"浏览转化率" =购买次数浏览次数= \frac{\text{购买次数}}{\text{浏览次数}}=浏览次数购买次数​
  • 聚合特征：对时间窗口或分组进行统计聚合。例如"用户最近 777 天的平均消费金额"
  • 时间特征：从时间戳中提取小时、星期几、是否节假日、距离某事件的天数等
  • 文本特征：TF-IDF、词频统计、文本长度、情感得分等
  • 交互特征：多项式组合，如 x1×x2x_1 \times x_2x1​×x2​、x12x_1^2x12​ 等

sklearn.preprocessing.PolynomialFeatures 可以自动生成多项式交互特征，featuretools 库则支持自动化特征工程。

数据管道自动化

手动执行清洗步骤容易出错且不可重复。sklearn.pipeline.Pipeline 允许你将多个预处理步骤和模型训练串联成一条流水线：

from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.impute import SimpleImputer

pipe = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler()),
])
X_clean = pipe.fit_transform(X_raw)

Pipeline 的优势在于：所有变换在训练集上 fit，在测试集上只 transform，避免数据泄露。对于更复杂的场景，ColumnTransformer 可以对不同列应用不同的变换策略。

练习与思考

  1. 加载一个含缺失值的公开数据集（如 Titanic），分别使用删除法、均值填充和 KNN 插补处理缺失值，比较三种方法对后续分类模型准确率的影响。
  2. 对某个数值特征同时计算 IQR 和 Z-score 检测结果，看两种方法标记的异常值是否一致。什么样的数据分布下它们差异最大？
  3. 创建一个包含数值列和类别列的混合数据集，使用 ColumnTransformer 对数值列做标准化、对类别列做独热编码，封装成 Pipeline。
  4. 在电商数据场景中，你认为哪些交叉特征或聚合特征可能对预测"用户是否会在下周复购"有帮助？列出至少 555 个候选特征并说明理由。
  5. 思考：为什么在交叉验证中，预处理步骤必须放在 Pipeline 内部而不能在外部全局执行？这与"数据泄露"有什么关系？

拓展阅读

  • 《Feature Engineering and Selection》（Max Kuhn & Kjell Johnson）：特征工程领域的权威参考书，涵盖从基础到高级的各种技术
  • Kaggle Learn — Data Cleaning：Kaggle 官方出品的交互式教程，边学边练
  • sklearn 官方文档 — Preprocessing：最全面的 API 参考，每个 Transformer 都有详细的数学说明和代码示例
  • PyJanitor：一个基于 pandas 的数据清洗库，提供链式调用风格的清洗 API，让代码更简洁
  • Great Expectations：数据质量验证框架，可以在管道中自动检查数据是否满足预期约束

小结

数据清洗与预处理是从"原始数据"到"可建模数据"的关键桥梁。缺失值处理需要根据缺失机制选择策略，异常值检测要结合业务背景判断，标准化和归一化确保特征在统一尺度上被公平比较，特征编码让模型理解类别信息，特征工程则创造性地挖掘隐含模式。最终，Pipeline 将所有步骤自动化，保证流程的可重复性和可维护性。下一节我们将进入探索性数据分析（EDA），用可视化和统计方法深入理解数据的分布特征与内在关系。
