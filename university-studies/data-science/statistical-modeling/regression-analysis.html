大学数据科学 — 回归分析

知识要点

回归分析是统计建模中最基础也最强大的工具之一，它揭示了变量之间的定量关系，帮助我们从数据中提取预测能力。从最简单的一元线性回归到广义线性模型，回归方法构成了几乎所有预测建模的理论基石。

核心概念速览：

方法 响应变量类型 损失函数 典型应用
线性回归 (OLS) 连续 ∑(yi−y^i)2\sum(y_i - \hat{y}_i)^2∑(yi​−y^​i​)2 房价预测、销量预测
逻辑回归 二分类 / 多分类 交叉熵 信用评分、疾病诊断
Ridge 回归 连续 OLS+λ∑βj2\text{OLS} + \lambda\sum\beta_j^2OLS+λ∑βj2​ 高维共线性场景
Lasso 回归 连续 $\text{OLS} + \lambda\sum \beta_j
ElasticNet 连续 Ridge + Lasso 混合 基因组学、文本回归
广义线性模型 指数族分布 最大似然 计数数据、比例数据

详细讲解

一、线性回归与 OLS 估计

普通最小二乘法（Ordinary Least Squares）是线性回归的经典求解方式。给定 nnn 个样本 (xi,yi)(x_i, y_i)(xi​,yi​)，模型假设：

y=Xβ+εy = X\beta + \varepsilony=Xβ+ε

其中 ε∼N(0,σ2I)\varepsilon \sim N(0, \sigma^2 I)ε∼N(0,σ2I)。OLS 估计量为：

β^=(XTX)−1XTy\hat{\beta} = (X^TX)^{-1}X^Tyβ^​=(XTX)−1XTy

Gauss-Markov 五大假设：

  1. 线性性：yyy 与 XXX 之间存在线性关系
  2. 随机抽样：样本独立同分布
  3. 无完全共线性：设计矩阵 XXX 列满秩
  4. 零条件均值：E(ε∣X)=0E(\varepsilon | X) = 0E(ε∣X)=0
  5. 同方差性：Var(ε∣X)=σ2I\text{Var}(\varepsilon | X) = \sigma^2 IVar(ε∣X)=σ2I

满足这五条假设时，OLS 是最佳线性无偏估计量（BLUE）。

回归诊断四步法：

  • 残差图：检查残差是否随机分布，若呈现扇形则违反同方差假设
  • Q-Q 图：检验残差正态性，偏离对角线表示分布偏态
  • Cook's Distance：识别高影响力观测点，Di>4/nD_i > 4/nDi​>4/n 需重点关注
  • VIF（方差膨胀因子）：VIFj=11−Rj2\text{VIF}_j = \frac{1}{1 - R_j^2}VIFj​=1−Rj2​1​，VIF > 10 表示严重共线性

二、多元线性回归与多重共线性

当模型包含多个预测变量时，共线性问题可能导致系数估计不稳定、标准误膨胀。

多重共线性的信号：

  • 某个自变量 ttt 检验不显著，但整体 FFF 检验显著
  • 系数符号与领域知识矛盾
  • 增减一个变量导致其他系数剧烈变化

应对策略：

1. 删除冗余变量（基于 VIF 或领域知识）
2. 主成分回归（PCR）：先 PCA 降维，再回归
3. 偏最小二乘（PLS）：同时考虑 X 和 y 的协方差
4. 正则化回归（Ridge / Lasso）

三、逻辑回归

逻辑回归将线性模型输出通过 Sigmoid 函数映射到 [0,1][0, 1][0,1] 区间，用于分类任务：

P(y=1∣x)=σ(xTβ)=11+e−xTβP(y=1|x) = \sigma(x^T\beta) = \frac{1}{1 + e^{-x^T\beta}}P(y=1∣x)=σ(xTβ)=1+e−xTβ1​

对数几率（log-odds）形式：

ln⁡P(y=1∣x)1−P(y=1∣x)=xTβ\ln\frac{P(y=1|x)}{1 - P(y=1|x)} = x^T\betaln1−P(y=1∣x)P(y=1∣x)​=xTβ

参数通过最大似然估计（MLE）求解，损失函数为交叉熵：

L(β)=−∑i=1n[yiln⁡p^i+(1−yi)ln⁡(1−p^i)]L(\beta) = -\sum_{i=1}^{n}\left[y_i \ln \hat{p}_i + (1-y_i)\ln(1-\hat{p}_i)\right]L(β)=−i=1∑n​[yi​lnp^​i​+(1−yi​)ln(1−p^​i​)]

决策边界：当 xTβ=0x^T\beta = 0xTβ=0 时 P=0.5P = 0.5P=0.5，这条超平面就是分类的决策边界。调整阈值可以在精确率和召回率之间权衡。

四、正则化回归

当特征维度较高或存在共线性时，OLS 容易过拟合。正则化通过在损失函数中添加惩罚项来约束系数大小：

Ridge 回归（L2 正则化）：

β^ridge=arg⁡min⁡β{∑i=1n(yi−xiTβ)2+λ∑j=1pβj2}\hat{\beta}_{\text{ridge}} = \arg\min_\beta \left\{ \sum_{i=1}^n (y_i - x_i^T\beta)^2 + \lambda \sum_{j=1}^p \beta_j^2 \right\}β^​ridge​=argβmin​{i=1∑n​(yi​−xiT​β)2+λj=1∑p​βj2​}

闭式解为 β^=(XTX+λI)−1XTy\hat{\beta} = (X^TX + \lambda I)^{-1}X^Tyβ^​=(XTX+λI)−1XTy，几何上等价于将系数向原点收缩。

Lasso 回归（L1 正则化）：

β^lasso=arg⁡min⁡β{∑i=1n(yi−xiTβ)2+λ∑j=1p∣βj∣}\hat{\beta}_{\text{lasso}} = \arg\min_\beta \left\{ \sum_{i=1}^n (y_i - x_i^T\beta)^2 + \lambda \sum_{j=1}^p |\beta_j| \right\}β^​lasso​=argβmin​{i=1∑n​(yi​−xiT​β)2+λj=1∑p​∣βj​∣}

L1 惩罚的菱形约束区域使得部分系数恰好为零，因此 Lasso 具有自动特征选择能力。

ElasticNet（混合正则化）：

Loss=OLS+λ1∑∣βj∣+λ2∑βj2\text{Loss} = \text{OLS} + \lambda_1 \sum|\beta_j| + \lambda_2 \sum\beta_j^2Loss=OLS+λ1​∑∣βj​∣+λ2​∑βj2​

通过 α\alphaα 参数控制 L1 与 L2 的比例，兼顾变量选择和分组效应。

五、广义线性模型（GLM）

GLM 将线性回归推广到非正态响应变量，统一框架包含三个组件：

  1. 随机成分：yyy 服从指数族分布（正态、二项、泊松、伽马等）
  2. 系统成分：线性预测子 η=Xβ\eta = X\betaη=Xβ
  3. 连接函数：g(μ)=ηg(\mu) = \etag(μ)=η，将均值映射到线性预测子
分布 连接函数 应用场景
正态 恒等 g(μ)=μg(\mu) = \mug(μ)=μ 连续数据
二项 Logit g(μ)=ln⁡μ1−μg(\mu) = \ln\frac{\mu}{1-\mu}g(μ)=ln1−μμ​ 二分类
泊松 对数 g(μ)=ln⁡μg(\mu) = \ln\mug(μ)=lnμ 计数数据
伽马 倒数 g(μ)=1/μg(\mu) = 1/\mug(μ)=1/μ 正偏态连续数据

GLM 使用迭代加权最小二乘（IRLS）算法求解，实际上逻辑回归和泊松回归都是 GLM 的特例。

六、模型评估指标

回归模型评估：

  • R2R^2R2：R2=1−SSresSStotR^2 = 1 - \frac{SS_{\text{res}}}{SS_{\text{tot}}}R2=1−SStot​SSres​​，表示模型解释的方差比例
  • 调整 R2R^2R2：Radj2=1−(1−R2)(n−1)n−p−1R^2_{\text{adj}} = 1 - \frac{(1-R^2)(n-1)}{n-p-1}Radj2​=1−n−p−1(1−R2)(n−1)​，惩罚过多变量
  • RMSE：1n∑(yi−y^i)2\sqrt{\frac{1}{n}\sum(y_i - \hat{y}_i)^2}n1​∑(yi​−y^​i​)2​，与因变量同量纲
  • MAE：1n∑∣yi−y^i∣\frac{1}{n}\sum|y_i - \hat{y}_i|n1​∑∣yi​−y^​i​∣，对离群值更鲁棒

模型选择准则：

  • AIC：AIC=−2ln⁡L+2k\text{AIC} = -2\ln L + 2kAIC=−2lnL+2k，平衡拟合度与模型复杂度
  • BIC：BIC=−2ln⁡L+kln⁡n\text{BIC} = -2\ln L + k\ln nBIC=−2lnL+klnn，对参数数量惩罚更重

AIC 倾向选择预测能力强的模型，BIC 倾向选择更简洁的模型。实践中两者互补使用。

练习与思考

  1. 用 Python 加载波士顿房价数据集（或类似回归数据集），分别拟合 OLS、Ridge、Lasso 模型，比较三者的 RMSE 和非零系数数量。调节 λ\lambdaλ 从 0.01 到 100，绘制正则化路径图。

  2. 构造一个包含高度共线性的模拟数据集（如 x2=2x1+noisex_2 = 2x_1 + \text{noise}x2​=2x1​+noise），观察 OLS 系数的不稳定性，然后用 Ridge 回归验证系数是否变得稳定。

  3. 对一个二分类数据集（如信用卡欺诈检测）训练逻辑回归，绘制 ROC 曲线，计算 AUC。尝试不同的分类阈值，分析精确率-召回率权衡。

  4. 思考：为什么 Lasso 可以产生稀疏解（系数恰好为零），而 Ridge 不能？从几何约束的角度画图解释。

  5. 用泊松回归分析一份计数数据（如网站日访问量与广告投入的关系），检查过散（overdispersion）现象，讨论何时应该改用负二项回归。

拓展阅读

  • Hastie, Tibshirani, Friedman 的《The Elements of Statistical Learning》第三章系统讲解了线性方法和正则化，是理解回归分析的经典参考
  • Andrew Ng 的 Stanford CS229 课程笔记中关于线性回归和逻辑回归的推导清晰易懂，适合初学者建立直觉
  • scikit-learn 官方文档的 Linear Models 部分提供了完整的 API 参考和实际代码示例
  • 关于 GLM 的深入理解，推荐 McCullagh 和 Nelder 的《Generalized Linear Models》
  • Kaggle 上的 House Prices 竞赛是练习回归建模的经典场景，包含特征工程和正则化的完整实战流程
  • 正则化路径的可视化工具 glmnet（R 语言）或 sklearn 的 lasso_path 函数可以直观展示系数随 λ\lambdaλ 变化的轨迹

小结

回归分析从 OLS 出发，逐步扩展到处理共线性的正则化方法、处理分类问题的逻辑回归、以及处理非正态响应的广义线性模型。掌握回归的关键在于理解假设条件——每个假设的违反都有对应的诊断方法和修正策略。在实践中，模型选择需要同时考虑预测精度（RMSE）、可解释性（系数数量）和理论合理性（AIC/BIC），三者之间的平衡是建模的核心艺术。下一步建议深入学习正则化路径的调参技巧，以及从 GLM 过渡到广义可加模型（GAM）。
