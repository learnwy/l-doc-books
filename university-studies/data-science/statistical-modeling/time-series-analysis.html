大学数据科学 — 时间序列分析

知识要点

时间序列分析是处理按时间顺序排列的观测数据的核心技术。从股票价格到天气预报，从网站流量到工厂设备监控，时间维度上的数据模式无处不在。与截面数据不同，时间序列的核心挑战在于观测值之间存在时间依赖性——昨天的数据会影响今天的预测。

关键概念对照：

概念 定义 检验方法
平稳性 统计特性不随时间变化 ADF / KPSS 检验
趋势 长期上升或下降方向 移动平均 / HP 滤波
季节性 固定周期的重复模式 季节性分解 / ACF 图
自相关 序列与自身滞后值的相关性 ACF / PACF 图
白噪声 均值为零、无自相关的随机序列 Ljung-Box 检验
异方差性 方差随时间变化 ARCH 效应检验

详细讲解

一、时间序列分解

任何时间序列都可以分解为三个（或四个）基本成分：

Yt=Tt+St+Rt（加法模型）Y_t = T_t + S_t + R_t \quad \text{（加法模型）}Yt​=Tt​+St​+Rt​（加法模型）
Yt=Tt×St×Rt（乘法模型）Y_t = T_t \times S_t \times R_t \quad \text{（乘法模型）}Yt​=Tt​×St​×Rt​（乘法模型）

其中 TtT_tTt​ 为趋势成分，StS_tSt​ 为季节成分，RtR_tRt​ 为残差成分。

经典分解法：先用移动平均提取趋势，再从去趋势序列中提取季节均值，最后得到残差。

STL 分解（Seasonal and Trend decomposition using Loess）：基于局部加权回归的迭代分解方法，优势在于：

  • 季节成分可以随时间缓慢变化（经典分解假设季节固定）
  • 对离群值更鲁棒
  • 可控制季节窗口和趋势窗口的平滑程度

选择加法还是乘法模型的经验法则：如果季节波动幅度随趋势水平增大而增大，用乘法模型；否则用加法模型。对乘法序列取对数后可转化为加法结构。

二、平稳性检验

绝大多数时间序列模型要求数据平稳（至少弱平稳），即均值和自协方差不随时间变化。

ADF 检验（Augmented Dickey-Fuller）：

检验假设：H0H_0H0​：序列存在单位根（非平稳） vs H1H_1H1​：序列平稳

回归方程：

Δyt=α+βt+γyt−1+∑i=1pδiΔyt−i+εt\Delta y_t = \alpha + \beta t + \gamma y_{t-1} + \sum_{i=1}^{p} \delta_i \Delta y_{t-i} + \varepsilon_tΔyt​=α+βt+γyt−1​+i=1∑p​δi​Δyt−i​+εt​

若 γ\gammaγ 显著小于零（p 值 < 0.05），则拒绝原假设，认为序列平稳。

KPSS 检验：与 ADF 互补，原假设为序列平稳。两个检验结合使用可以更可靠地判断平稳性：

ADF 结果 KPSS 结果 结论
拒绝 H0H_0H0​ 不拒绝 H0H_0H0​ 平稳
不拒绝 H0H_0H0​ 拒绝 H0H_0H0​ 非平稳
都拒绝 — 趋势平稳
都不拒绝 — 证据不足

差分：对非平稳序列进行 ddd 阶差分使其平稳。一阶差分 Δyt=yt−yt−1\Delta y_t = y_t - y_{t-1}Δyt​=yt​−yt−1​，季节差分 Δmyt=yt−yt−m\Delta_m y_t = y_t - y_{t-m}Δm​yt​=yt​−yt−m​。

三、ARIMA 模型族

ARIMA(p,d,qp, d, qp,d,q) 是最经典的时间序列预测模型：

  • AR(ppp)：自回归，当前值由前 ppp 个值的线性组合决定
yt=c+ϕ1yt−1+ϕ2yt−2+⋯+ϕpyt−p+εty_t = c + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \cdots + \phi_p y_{t-p} + \varepsilon_tyt​=c+ϕ1​yt−1​+ϕ2​yt−2​+⋯+ϕp​yt−p​+εt​
  • I(ddd)：差分阶数，使序列平稳
  • MA(qqq)：移动平均，当前值由前 qqq 个误差项的线性组合决定
yt=c+εt+θ1εt−1+⋯+θqεt−qy_t = c + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \cdots + \theta_q \varepsilon_{t-q}yt​=c+εt​+θ1​εt−1​+⋯+θq​εt−q​

定阶方法：

图形 AR(ppp) 特征 MA(qqq) 特征 ARMA 特征
ACF 拖尾衰减 qqq 阶截尾 拖尾衰减
PACF ppp 阶截尾 拖尾衰减 拖尾衰减

实践中常用 auto_arima（pmdarima 库）自动搜索最佳 (p,d,qp, d, qp,d,q) 组合，以 AIC 或 BIC 为准则。

SARIMA(p,d,qp, d, qp,d,q)(P,D,QP, D, QP,D,Q)m_mm​ 扩展了季节性建模能力，其中大写字母代表季节阶数，mmm 为季节周期。

四、指数平滑法（ETS）

指数平滑赋予近期观测更高的权重，权重按指数衰减。

简单指数平滑（SES）：

y^t+1=αyt+(1−α)y^t\hat{y}_{t+1} = \alpha y_t + (1-\alpha)\hat{y}_ty^​t+1​=αyt​+(1−α)y^​t​

参数 α∈[0,1]\alpha \in [0, 1]α∈[0,1] 控制平滑程度，α\alphaα 越大对近期数据越敏感。

Holt 线性趋势法：增加趋势方程

ℓt=αyt+(1−α)(ℓt−1+bt−1)\ell_t = \alpha y_t + (1-\alpha)(\ell_{t-1} + b_{t-1})ℓt​=αyt​+(1−α)(ℓt−1​+bt−1​)
bt=β(ℓt−ℓt−1)+(1−β)bt−1b_t = \beta(\ell_t - \ell_{t-1}) + (1-\beta)b_{t-1}bt​=β(ℓt​−ℓt−1​)+(1−β)bt−1​

Holt-Winters 方法：进一步增加季节方程，分加法季节和乘法季节两种。

ETS 框架统一了所有指数平滑方法，用三元组 (Error, Trend, Seasonal) 命名：

  • Error: A（加法）或 M（乘法）
  • Trend: N（无）、A（加法）、AdA_dAd​（阻尼加法）
  • Seasonal: N（无）、A（加法）、M（乘法）

共 30 种模型组合，通过最大似然估计参数，用 AIC 选择最佳组合。

五、Prophet 与神经网络预测

Facebook Prophet：

Prophet 将时间序列分解为趋势、季节性和假日效应：

y(t)=g(t)+s(t)+h(t)+εty(t) = g(t) + s(t) + h(t) + \varepsilon_ty(t)=g(t)+s(t)+h(t)+εt​

其中 g(t)g(t)g(t) 是分段线性或逻辑增长趋势，s(t)s(t)s(t) 使用傅里叶级数建模周期性，h(t)h(t)h(t) 处理节假日效应。

Prophet 的优势在于对缺失值和离群值鲁棒、自动检测变点、支持自定义季节性和假日，且接口简单易用。

神经网络方法：

  • LSTM（长短期记忆网络）：通过门控机制捕捉长程依赖，适合复杂非线性序列
  • Transformer：注意力机制并行处理所有时间步，训练效率高于 LSTM
  • N-BEATS：纯前馈网络，通过残差学习和可解释架构实现竞争力性能
  • Temporal Fusion Transformer（TFT）：融合注意力机制和门控残差网络，支持多变量输入和可解释预测

实际比较发现，在中短期预测任务中，调参良好的 ARIMA 或 ETS 常常不输深度学习方法。深度学习的优势主要体现在多变量、长序列和大规模数据场景。

六、时序交叉验证

时间序列不能用标准的随机交叉验证（会造成数据泄漏），需要使用时间感知的验证策略：

滚动窗口法（Rolling Window / Walk-Forward Validation）：

训练集: [1, ..., t]    → 预测: [t+1, ..., t+h]
训练集: [1, ..., t+1]  → 预测: [t+2, ..., t+h+1]
训练集: [1, ..., t+2]  → 预测: [t+3, ..., t+h+2]
...

每轮训练集扩展一步，预测窗口向前滑动。也可以固定训练窗口大小（滑动窗口法）。

评估指标：

指标 公式 特点
MAE 1n∑∣yt−y^t∣\frac{1}{n}\sum|y_t - \hat{y}_t|n1​∑∣yt​−y^​t​∣ 直观，与数据同量纲
RMSE 1n∑(yt−y^t)2\sqrt{\frac{1}{n}\sum(y_t - \hat{y}_t)^2}n1​∑(yt​−y^​t​)2​ 对大误差更敏感
MAPE 100n∑∣yt−y^tyt∣\frac{100}{n}\sum|\frac{y_t - \hat{y}_t}{y_t}|n100​∑∣yt​yt​−y^​t​​∣ 百分比形式，yt=0y_t=0yt​=0 时失效
SMAPE 200n∑∣yt−y^t∣∣yt∣+∣y^t∣\frac{200}{n}\sum\frac{|y_t - \hat{y}_t|}{|y_t| + |\hat{y}_t|}n200​∑∣yt​∣+∣y^​t​∣∣yt​−y^​t​∣​ 对称版 MAPE
MASE 以朴素预测的 MAE 为基准 适合跨序列比较

练习与思考

  1. 下载一份带明显季节性的时间序列数据（如航空旅客数量或月度零售额），用 STL 分解提取趋势和季节成分。分别用加法和乘法模型分解，对比残差的随机性。

  2. 对上述数据进行 ADF 和 KPSS 检验，确认是否需要差分。然后用 ACF 和 PACF 图初步判断 ARIMA 的阶数，再用 auto_arima 验证你的判断。

  3. 分别用 SARIMA、Holt-Winters 和 Prophet 预测未来 12 个月的数据，使用滚动窗口验证比较三者的 RMSE。哪个模型在你的数据上表现最好？

  4. 思考：为什么简单的移动平均和指数平滑在很多实际业务场景中仍然广泛使用，甚至优于复杂的深度学习模型？从数据量、可解释性和维护成本的角度分析。

  5. 构造一个带变点（change point）的模拟时间序列（前半段线性增长，后半段增速放缓），用 Prophet 的变点检测功能定位变点位置。

拓展阅读

  • Hyndman 和 Athanasopoulos 的《Forecasting: Principles and Practice》（fpp3.otexts.org）是时间序列预测的最佳入门教材，免费在线阅读
  • Box, Jenkins, Reinsel 的《Time Series Analysis: Forecasting and Control》是 ARIMA 方法的经典著作
  • Facebook Prophet 的官方文档和 Taylor & Letham 的论文《Forecasting at Scale》详细介绍了 Prophet 的设计理念
  • Makridakis 竞赛系列（M3/M4/M5）的结果分析揭示了不同预测方法在大规模实证比较中的表现
  • 对于深度学习预测方法，Lim 和 Zohren 的综述《Time-series forecasting with deep learning: a survey》提供了全面的方法对比
  • statsmodels 和 pmdarima 是 Python 中进行经典时间序列分析的主力库

小结

时间序列分析的工作流从分解和平稳性检验开始，经过模型选择（ARIMA、ETS、Prophet 或深度学习），到时序交叉验证评估结束。核心原则是尊重时间的方向性——训练数据永远在预测目标之前。在模型选择上，经典统计方法在数据量有限时往往更可靠，而深度学习方法在大规模多变量场景中展现优势。实践中建议总是从简单模型（如 ETS 或 ARIMA）开始建立基线，再逐步尝试复杂方法。下一步建议学习多变量时间序列（VAR 模型）和概率预测（分位数回归、贝叶斯结构时间序列模型）。
