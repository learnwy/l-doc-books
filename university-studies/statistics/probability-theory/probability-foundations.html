概率论基础

知识要点

概率论是统计推断的数学基石。它用精确的数学语言描述随机现象的规律，从"明天可能下雨"这样的日常直觉到保险精算和量子力学中的概率计算，都建立在相同的公理体系之上。理解样本空间、事件、概率公理以及条件概率与独立性的概念，是进入统计学深水区的必经之路。

详细讲解

随机试验与样本空间

随机试验是结果不确定但所有可能结果已知的可重复过程。抛硬币、掷骰子是经典例子，但更广泛地，每一次医学检测、每一轮股票交易、每一批产品的质量抽检都是随机试验。

样本空间 Ω\OmegaΩ 是所有可能结果的集合。掷一个骰子的样本空间为 Ω={1,2,3,4,5,6}\Omega = \{1, 2, 3, 4, 5, 6\}Ω={1,2,3,4,5,6}。抛两枚硬币的样本空间为 Ω={HH,HT,TH,TT}\Omega = \{HH, HT, TH, TT\}Ω={HH,HT,TH,TT}。

事件是样本空间的子集。"掷出偶数"对应事件 A={2,4,6}A = \{2, 4, 6\}A={2,4,6}。事件之间的运算遵循集合论规则：

运算 符号 含义
并集 A∪BA \cup BA∪B AAA 或 BBB 至少发生一个
交集 A∩BA \cap BA∩B AAA 和 BBB 同时发生
补集 AcA^cAc AAA 不发生
差集 A∖BA \setminus BA∖B AAA 发生且 BBB 不发生

概率公理与性质

Kolmogorov 在 1933 年建立的概率公理体系是现代概率论的基础。概率函数 PPP 满足三条公理：

  1. 非负性：P(A)≥0P(A) \geq 0P(A)≥0，对所有事件 AAA
  2. 规范性：P(Ω)=1P(\Omega) = 1P(Ω)=1
  3. 可列可加性：若 A1,A2,…A_1, A_2, \ldotsA1​,A2​,… 两两互斥，则 P(⋃i=1∞Ai)=∑i=1∞P(Ai)P\left(\bigcup_{i=1}^{\infty}A_i\right) = \sum_{i=1}^{\infty}P(A_i)P(⋃i=1∞​Ai​)=∑i=1∞​P(Ai​)

从三条公理可推导出所有概率性质：

P(Ac)=1−P(A)P(A^c) = 1 - P(A)P(Ac)=1−P(A)
P(A∪B)=P(A)+P(B)−P(A∩B)P(A \cup B) = P(A) + P(B) - P(A \cap B)P(A∪B)=P(A)+P(B)−P(A∩B)
P(∅)=0P(\emptyset) = 0P(∅)=0

更一般的容斥原理对三个事件：

P(A∪B∪C)=P(A)+P(B)+P(C)−P(A∩B)−P(A∩C)−P(B∩C)+P(A∩B∩C)P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(A \cap B) - P(A \cap C) - P(B \cap C) + P(A \cap B \cap C)P(A∪B∪C)=P(A)+P(B)+P(C)−P(A∩B)−P(A∩C)−P(B∩C)+P(A∩B∩C)

概率的解释

对"概率"的含义存在不同学派的解释：

频率论解释：概率是大量重复试验中事件发生的频率极限。P(正面)=0.5P(\text{正面}) = 0.5P(正面)=0.5 意味着抛足够多次硬币后，正面出现的比例趋近 0.50.50.5。

贝叶斯解释：概率是主观的信念程度。P(明天下雨)=0.7P(\text{明天下雨}) = 0.7P(明天下雨)=0.7 表达的是个人基于现有信息对降雨事件的确信度。不同个体可以对同一事件赋予不同概率。

古典解释：当所有基本结果等可能时，P(A)=∣A∣/∣Ω∣P(A) = |A| / |\Omega|P(A)=∣A∣/∣Ω∣（有利结果数除以总结果数）。这是最直觉的定义，但适用范围有限。

条件概率与贝叶斯定理

条件概率是在已知某事件发生的条件下，另一事件发生的概率：

P(A∣B)=P(A∩B)P(B),P(B)>0P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0P(A∣B)=P(B)P(A∩B)​,P(B)>0

条件概率可以理解为"缩小样本空间"：在已知 BBB 发生的前提下，将注意力限制在 BBB 内部，看 AAA 占多大比例。

全概率公式将复杂事件的概率分解为多个条件概率的加权平均。若 B1,B2,…,BnB_1, B_2, \ldots, B_nB1​,B2​,…,Bn​ 是 Ω\OmegaΩ 的一个划分（互斥且穷尽），则：

P(A)=∑i=1nP(A∣Bi)P(Bi)P(A) = \sum_{i=1}^{n}P(A \mid B_i)P(B_i)P(A)=i=1∑n​P(A∣Bi​)P(Bi​)

贝叶斯定理将条件概率"翻转"：

P(Bj∣A)=P(A∣Bj)P(Bj)∑i=1nP(A∣Bi)P(Bi)P(B_j \mid A) = \frac{P(A \mid B_j)P(B_j)}{\sum_{i=1}^{n}P(A \mid B_i)P(B_i)}P(Bj​∣A)=∑i=1n​P(A∣Bi​)P(Bi​)P(A∣Bj​)P(Bj​)​

经典应用：医学诊断。假设某罕见病患病率为 0.1%0.1\%0.1%，检测灵敏度（真阳性率）为 99%99\%99%，特异度（真阴性率）为 95%95\%95%。一个检测阳性的人实际患病的概率是多少？

P(患病∣阳性)=0.99×0.0010.99×0.001+0.05×0.999≈0.019P(\text{患病} \mid \text{阳性}) = \frac{0.99 \times 0.001}{0.99 \times 0.001 + 0.05 \times 0.999} \approx 0.019P(患病∣阳性)=0.99×0.001+0.05×0.9990.99×0.001​≈0.019

尽管检测看似很准确，阳性结果中实际患病的概率仅约 1.9%1.9\%1.9%。这个反直觉的结果来自基础率极低（0.1%0.1\%0.1%），是贝叶斯定理最著名的教学案例。

独立性

两个事件 AAA 和 BBB 独立，当且仅当：

P(A∩B)=P(A)⋅P(B)P(A \cap B) = P(A) \cdot P(B)P(A∩B)=P(A)⋅P(B)

等价地，P(A∣B)=P(A)P(A \mid B) = P(A)P(A∣B)=P(A)——知道 BBB 是否发生不影响 AAA 的概率。

独立性是概率论中最关键也最容易被误用的概念。互斥事件（A∩B=∅A \cap B = \emptysetA∩B=∅）和独立事件是完全不同的概念——互斥事件一定不独立（除非其中一个概率为零），因为知道 AAA 发生就确定了 BBB 不发生。

多个事件的相互独立要求所有子集的乘法公式成立，不仅仅是两两独立。三个事件 AAA、BBB、CCC 的相互独立需要同时满足四个等式：

P(A∩B)=P(A)P(B),P(A∩C)=P(A)P(C)P(A \cap B) = P(A)P(B), \quad P(A \cap C) = P(A)P(C)P(A∩B)=P(A)P(B),P(A∩C)=P(A)P(C)
P(B∩C)=P(B)P(C),P(A∩B∩C)=P(A)P(B)P(C)P(B \cap C) = P(B)P(C), \quad P(A \cap B \cap C) = P(A)P(B)P(C)P(B∩C)=P(B)P(C),P(A∩B∩C)=P(A)P(B)P(C)

计数原理

计数是计算古典概型概率的核心工具：

排列：从 nnn 个不同对象中有序选取 kkk 个的方式数：

P(n,k)=n!(n−k)!P(n, k) = \frac{n!}{(n-k)!}P(n,k)=(n−k)!n!​

组合：从 nnn 个不同对象中无序选取 kkk 个的方式数：

(nk)=n!k!(n−k)!\binom{n}{k} = \frac{n!}{k!(n-k)!}(kn​)=k!(n−k)!n!​

组合数满足对称性 (nk)=(nn−k)\binom{n}{k} = \binom{n}{n-k}(kn​)=(n−kn​) 和递推关系 (nk)=(n−1k−1)+(n−1k)\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}(kn​)=(k−1n−1​)+(kn−1​)（帕斯卡三角形）。

练习与思考

  1. 两颗骰子同时投掷。求事件 AAA"点数之和为 777"和事件 BBB"至少有一颗为 666"的概率。AAA 和 BBB 是否独立？

  2. 一个盒子里有 333 个红球和 777 个白球，不放回地连续取 222 个球。求两个都是红球的概率。如果改为有放回抽样，结果如何变化？为什么？

  3. 将贝叶斯定理应用于以下场景：一家公司 60%60\%60% 的邮件是垃圾邮件，垃圾邮件包含"免费"一词的概率是 80%80\%80%，正常邮件包含"免费"一词的概率是 10%10\%10%。收到一封含有"免费"的邮件时，它是垃圾邮件的概率是多少？

  4. 证明：如果 AAA 和 BBB 独立，则 AAA 和 BcB^cBc、AcA^cAc 和 BBB、AcA^cAc 和 BcB^cBc 也分别独立。

  5. 思考："生日问题"——一个教室中需要多少人，才有超过 50%50\%50% 的概率至少两人生日相同？为什么答案远小于 365365365？

拓展阅读

概率论的历史始于 1654 年 Pascal 和 Fermat 关于赌博问题的通信。但严格的数学化要等到 Kolmogorov 1933 年用测度论建立公理化体系。概率空间 (Ω,F,P)(\Omega, \mathcal{F}, P)(Ω,F,P) 中的 σ\sigmaσ-代数 F\mathcal{F}F 确保了概率可以在无穷维空间中自洽地定义。

条件概率的深层含义远超表面定义。条件期望 E(Y∣X)E(Y \mid X)E(Y∣X) 作为 XXX 的函数，是回归分析的理论基础；条件独立 X⊥Y∣ZX \perp Y \mid ZX⊥Y∣Z 是因果推断和图模型的核心概念。

主观概率论（de Finetti 的可交换性理论）为贝叶斯统计提供了哲学基础。de Finetti 定理表明，如果一组随机变量满足可交换性，它们的联合分布可以表示为独立同分布模型在某个先验分布上的混合。

推荐阅读 Sheldon Ross 的《A First Course in Probability》作为系统入门。

小结

概率论通过样本空间、事件和概率函数描述随机现象。Kolmogorov 公理为概率赋予了严格的数学基础。条件概率和贝叶斯定理揭示了"先验信息如何影响后验判断"，而独立性则刻画了"无关联"的精确含义。计数原理是计算古典概型概率的核心工具。这些基础概念构成了推断统计、机器学习和决策科学的共同语言。
