02 经济学 (Economics)统计学 简介描述统计 简介数据类型与分布

数据类型与分布

统计学的起点是数据。在分析任何问题之前，你需要知道手头的数据属于什么类型、它们来自什么过程、以什么模式分布。选择错误的统计方法往往始于对数据类型的误判。理解数据类型和常见分布是统计分析的第一课。

知识要点

数据按测量层次分为四类：

类型 特征 运算 示例
定类（Nominal） 仅分类，无顺序 相等比较 性别、血型、国籍
定序（Ordinal） 有顺序，间距不等 排序 教育程度、满意度等级
定距（Interval） 等间距，无真零点 加减 温度（摄氏度）、日期
定比（Ratio） 等间距，有真零点 加减乘除 身高、收入、距离

数据类型决定了可以使用的统计方法。对定类数据计算均值毫无意义（"平均血型"没有含义），只能使用众数和频率分布。

详细讲解

正态分布

正态分布（Normal Distribution）是统计学中最重要的分布。密度函数为：

f(x)=1σ2πe−(x−μ)22σ2f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}f(x)=σ2π​1​e−2σ2(x−μ)2​

其中 μ\muμ 是均值（决定中心位置），σ\sigmaσ 是标准差（决定分散程度）。

标准正态分布 Z=(X−μ)/σ∼N(0,1)Z = (X - \mu)/\sigma \sim N(0, 1)Z=(X−μ)/σ∼N(0,1)。68-95-99.7法则：约68%的数据落在 μ±σ\mu \pm \sigmaμ±σ 内，95%落在 μ±2σ\mu \pm 2\sigmaμ±2σ 内，99.7%落在 μ±3σ\mu \pm 3\sigmaμ±3σ 内。

正态分布之所以重要，是因为中心极限定理（CLT）：无论总体分布如何，大量独立同分布随机变量之和的分布趋近于正态分布。样本均值 Xˉ\bar{X}Xˉ 的抽样分布在大样本下近似正态：

Xˉ∼N(μ,σ2n)\bar{X} \sim N\left(\mu, \frac{\sigma^2}{n}\right)Xˉ∼N(μ,nσ2​)

P(X=k)=(nk)pk(1−p)n−kP(X = k) = \binom{n}{k} p^k (1-p)^{n-k}P(X=k)=(kn​)pk(1−p)n−k

泊松分布

描述单位时间（或空间）内稀有事件发生次数：

P(X=k)=λke−λk!P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}P(X=k)=k!λke−λ​

均值和方差均为 λ\lambdaλ。泊松分布适用于呼叫中心每小时来电数、网站每分钟访问量、一年内自然灾害次数等情景。

指数分布与均匀分布

指数分布描述事件之间的等待时间：f(x)=λe−λxf(x) = \lambda e^{-\lambda x}f(x)=λe−λx，x≥0x \geq 0x≥0。具有无记忆性：P(X>s+t∣X>s)=P(X>t)P(X > s + t \mid X > s) = P(X > t)P(X>s+t∣X>s)=P(X>t)。

均匀分布 U(a,b)U(a, b)U(a,b)：f(x)=1b−af(x) = \frac{1}{b-a}f(x)=b−a1​，在 [a,b][a, b][a,b] 上等概率。常用于模拟和随机数生成。

分布的形状特征

偏度（Skewness）衡量分布的不对称性：

γ1=E[(X−μσ)3]\gamma_1 = E\left[\left(\frac{X - \mu}{\sigma}\right)^3\right]γ1​=E[(σX−μ​)3]

γ1>0\gamma_1 > 0γ1​>0 右偏（右尾长），γ1<0\gamma_1 < 0γ1​<0 左偏，γ1=0\gamma_1 = 0γ1​=0 对称。收入分布通常强烈右偏。

峰度（Kurtosis）衡量分布尾部的厚薄：

γ2=E[(X−μσ)4]−3\gamma_2 = E\left[\left(\frac{X - \mu}{\sigma}\right)^4\right] - 3γ2​=E[(σX−μ​)4]−3

正态分布的超额峰度为0。金融收益率通常具有正超额峰度（厚尾），意味着极端事件比正态假设下更频繁。

练习与思考

  1. 将以下变量分类为定类、定序、定距或定比：(a) 邮政编码 (b) GDP (c) 客户满意度（1-5分）(d) 温度（开尔文）(e) 教育程度。

  2. 某城市日均交通事故数服从泊松分布，λ=3\lambda = 3λ=3。一天内发生5起或以上事故的概率是多少？

  3. 某公司员工月薪数据的均值为8000元，中位数为6000元。这暗示了什么分布形状？均值和中位数哪个更能代表"典型"员工的收入？

  4. 金融收益率的厚尾特性对风险管理有什么影响？如果使用正态分布假设计算VaR，风险会被高估还是低估？

拓展阅读

约翰·图基的《探索性数据分析》是EDA方法的开创性著作。对于概率分布的全面参考，推荐约翰逊等的《连续单变量分布》和《离散单变量分布》。

弗朗西斯·安斯科姆用"安斯科姆四重奏"（四组统计量完全相同但图形差异巨大的数据集）生动地说明了"先看数据"的重要性。

小结

数据类型和分布是统计分析的基础。四种测量层次决定了可用的统计方法，正态分布因中心极限定理而居于核心地位。偏度和峰度捕捉了分布偏离正态的特征。探索性数据分析通过可视化揭示数据的结构和异常，是任何正式分析之前不可省略的步骤。
