大学机械工程 — 机构设计

知识要点

机构是由刚性构件通过运动副连接而成的系统，用以实现特定的运动变换——将一种形式的运动（如旋转）转化为另一种形式（如往复直线运动）。从内燃机的曲柄连杆机构到机器人的多连杆手臂，机构设计决定了机器实现预期功能的方式与效率。

核心概念：

  • 自由度 FFF：机构独立运动的数目，决定了需要多少个驱动器
  • 运动副：两个构件之间的可动连接，低副（面接触，如转动副 R、移动副 P）和高副（点或线接触，如齿轮副、凸轮副）
  • 切比雪夫-格吕布勒公式：平面机构自由度 F=3(n−1)−2pl−phF = 3(n-1) - 2p_l - p_hF=3(n−1)−2pl​−ph​，其中 nnn 为构件数，plp_lpl​ 为低副数，php_hph​ 为高副数
  • 连杆机构：仅含低副的闭链机构，如四杆机构、曲柄滑块机构
  • 凸轮机构：利用凸轮轮廓直接驱动从动件按预定运动规律运动

详细讲解

自由度分析

自由度分析是机构设计的第一步。平面机构的自由度由格吕布勒公式计算：

F=3(n−1)−2pl−phF = 3(n - 1) - 2p_l - p_hF=3(n−1)−2pl​−ph​

计算时需注意三种特殊情况：

  • 复合铰链：kkk 个构件汇聚于同一铰链点，构成 k−1k-1k−1 个转动副
  • 局部自由度：不影响整体运动的附加自由度（如滚子从动件中滚子的自转），应在计算前去除
  • 虚约束：重复约束不产生独立限制，计算时应扣除

空间机构的自由度公式为 F=6(n−1)−∑i=15(6−i)piF = 6(n-1) - \sum_{i=1}^{5} (6-i) p_iF=6(n−1)−∑i=15​(6−i)pi​，其中 pip_ipi​ 为 iii 级运动副（限制 6−i6-i6−i 个自由度）的数量。

四杆机构

平面四杆机构由四个刚性杆件和四个转动副组成，是最基本也最通用的连杆机构。

格拉肖夫定理：四杆机构中，若最短杆长度 sss 与最长杆长度 lll 满足：

s+l≤p+qs + l \le p + qs+l≤p+q

（ppp、qqq 为另外两杆长度），则最短杆可以做整周旋转。根据固定杆（机架）的选取，有三种运动形式：

类型 机架选取 运动特征 典型应用
曲柄摇杆机构 最短杆的邻杆 曲柄整周旋转，摇杆往复摆动 缝纫机脚踏板、雨刮器
双曲柄机构 最短杆本身 两曲柄均做整周旋转 机车车轮联动
双摇杆机构 最短杆对杆 两杆均只能摆动 电风扇摇头机构

急回特性：当曲柄等速旋转时，摇杆的前进行程与返回行程所用时间不同。行程速度变化系数 K=θ1θ2K = \frac{\theta_1}{\theta_2}K=θ2​θ1​​（θ1>θ2\theta_1 > \theta_2θ1​>θ2​ 分别为前进和返回对应的曲柄转角），极位夹角 θ=180°(K−1)K+1\theta = \frac{180°(K-1)}{K+1}θ=K+1180°(K−1)​。

传动角 γ\gammaγ 是衡量机构传力性能的指标，定义为连杆作用于从动件的力与从动件速度方向的夹角。为保证良好的传力性能，一般要求最小传动角 γmin⁡≥40°∼50°\gamma_{\min} \ge 40° \sim 50°γmin​≥40°∼50°。

曲柄滑块机构

将四杆机构中某一摇杆改为滑块，即得到曲柄滑块机构——内燃机、压缩机、冲床等机械的核心机构。

运动学关系（偏距为零时）：

x=rcos⁡θ+l1−(rlsin⁡θ)2x = r\cos\theta + l\sqrt{1 - \left(\frac{r}{l}\sin\theta\right)^2}x=rcosθ+l1−(lr​sinθ)2​
v=−rωsin⁡θ(1+rcos⁡θl2−r2sin⁡2θ)v = -r\omega\sin\theta\left(1 + \frac{r\cos\theta}{\sqrt{l^2 - r^2\sin^2\theta}}\right)v=−rωsinθ(1+l2−r2sin2θ​rcosθ​)

其中 rrr 为曲柄长度，lll 为连杆长度，θ\thetaθ 为曲柄转角，ω\omegaω 为曲柄角速度。

当杆长比 λ=r/l\lambda = r/lλ=r/l 较小时（λ<1/4\lambda < 1/4λ<1/4），可近似为：

x≈rcos⁡θ+l+r24lcos⁡2θx \approx r\cos\theta + l + \frac{r^2}{4l}\cos 2\thetax≈rcosθ+l+4lr2​cos2θ

此近似将滑块位移分解为一次谐波和二次谐波，在发动机动力学分析中非常实用。

凸轮机构

凸轮机构通过凸轮轮廓直接控制从动件运动规律，设计灵活度极高。

常用从动件运动规律：

运动规律 位移方程（推程 hhh，推程角 δ\deltaδ） 特点
等速运动 s=hθδs = h\frac{\theta}{\delta}s=hδθ​ 存在刚性冲击（速度突变）
等加速等减速 分段抛物线 存在柔性冲击（加速度突变）

多项式（3-4-5） s=h(10ξ3−15ξ4+6ξ5)s = h\left(10\xi^3 - 15\xi^4 + 6\xi^5\right)s=h(10ξ3−15ξ4+6ξ5)，ξ=θ/δ\xi = \theta/\deltaξ=θ/δ 无冲击，平滑过渡

凸轮轮廓设计采用反转法：假设凸轮不动，从动件反向转动，从动件尖端（或滚子中心）在凸轮坐标系中的轨迹即为理论轮廓。滚子从动件需将理论轮廓向法线方向内缩一个滚子半径 rrr_rrr​ 得到实际工作轮廓。

压力角 α\alphaα 是凸轮法线方向与从动件运动方向的夹角，设计时要求 αmax⁡≤30°\alpha_{\max} \le 30°αmax​≤30°（直动从动件）或 αmax⁡≤45°\alpha_{\max} \le 45°αmax​≤45°（摆动从动件），以避免自锁。增大基圆半径 r0r_0r0​ 可有效减小压力角。

间歇运动机构

某些场合需要将连续旋转转化为间歇运动：

  • 棘轮机构：通过棘爪与棘轮齿的配合实现单向间歇回转，步距角等于齿距角的整数倍
  • 槽轮机构（日内瓦机构）：拨盘上的圆柱销进入槽轮径向槽中驱动其旋转。zzz 槽的槽轮每次转过 360°/z360°/z360°/z，运动系数 τ=1/z\tau = 1/zτ=1/z
  • 不完全齿轮机构：主动齿轮仅部分齿弧有齿，啮合段驱动从动轮转动，非啮合段从动轮静止

练习与思考

  1. 一个平面机构有 5 个构件（含机架）、5 个转动副、1 个移动副和 1 个高副。计算其自由度，判断是否为确定运动机构。

  2. 已知四杆机构的四杆长度分别为 a=40 mma = 40\,\text{mm}a=40mm，b=100 mmb = 100\,\text{mm}b=100mm，c=80 mmc = 80\,\text{mm}c=80mm，d=120 mmd = 120\,\text{mm}d=120mm。以 ddd 为机架时，判断机构类型。若改以 aaa 为机架呢？

  3. 设计一个盘形凸轮机构，要求推程角 δ0=120°\delta_0 = 120°δ0​=120°，远休止角 δs=30°\delta_s = 30°δs​=30°，回程角 δ0′=90°\delta_0' = 90°δ0′​=90°，升程 h=20 mmh = 20\,\text{mm}h=20mm，采用正弦加速度运动规律。写出推程段的位移、速度和加速度表达式。

  4. 思考题：汽车雨刮器通常采用曲柄摇杆机构实现。为什么设计者需要利用急回特性，使刮片在往返两个方向上速度不同？

拓展阅读

  • 机构综合：给定从动件的运动轨迹或函数关系，反求机构尺寸参数（如 Burmester 理论解析综合四杆机构经过指定精确位置），是机构学研究的核心问题之一。
  • 柔性机构（柔顺机构）：利用弹性变形代替运动副实现运动，消除间隙和摩擦，在 MEMS、精密仪器中广泛应用。
  • 并联机构：Stewart 平台、Delta 机器人等并联机构通过多条运动链同时连接平台与基座，刚度高、承载大，但工作空间有限。
  • 推荐教材：孙桓《机械原理》、Norton Design of Machinery

小结

机构设计的核心是通过构件和运动副的合理组合实现期望的运动变换。格吕布勒公式 F=3(n−1)−2pl−phF = 3(n-1) - 2p_l - p_hF=3(n−1)−2pl​−ph​ 确定自由度。四杆机构通过格拉肖夫条件判断运动类型，传动角 γ\gammaγ 衡量传力性能。曲柄滑块机构是旋转-直线运动转换的经典方案。凸轮机构通过轮廓设计实现任意从动件运动规律，压力角和基圆半径是关键设计参数。掌握这些基本机构后，可通过组合与变异派生出满足各种工程需求的复杂机构系统。
