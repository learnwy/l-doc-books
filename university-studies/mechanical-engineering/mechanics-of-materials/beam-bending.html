大学机械工程 — 梁的弯曲理论

知识要点

梁是工程中最常见的承载构件之一，从建筑楼板的承重梁到汽车底盘的纵梁，弯曲问题无处不在。弯曲分析的核心任务是确定梁在横向载荷作用下的内力分布（剪力与弯矩）、应力分布以及挠度变形。

关键概念：

  • 剪力 VVV 与弯矩 MMM：通过截面法建立，满足微分关系 dMdx=V\frac{dM}{dx} = VdxdM​=V，dVdx=−q(x)\frac{dV}{dx} = -q(x)dxdV​=−q(x)
  • 弯曲正应力：σ=MyI\sigma = \frac{M y}{I}σ=IMy​，其中 III 为截面对中性轴的惯性矩，yyy 为到中性轴距离
  • 弯曲切应力：τ=VQIb\tau = \frac{V Q}{I b}τ=IbVQ​，QQQ 为截面面积矩，bbb 为截面宽度
  • 挠曲线方程：EId2ydx2=M(x)EI \frac{d^2 y}{dx^2} = M(x)EIdx2d2y​=M(x)
  • 截面惯性矩：矩形截面 I=bh312I = \frac{bh^3}{12}I=12bh3​，圆形截面 I=πd464I = \frac{\pi d^4}{64}I=64πd4​

详细讲解

剪力图与弯矩图

分析梁弯曲的第一步是绘制剪力图（SFD）和弯矩图（BMD）。对于静定梁，先由平衡方程求支反力，再沿梁长逐段建立剪力和弯矩的表达式。

以简支梁中点受集中力 PPP 为例：

V(x)={P20≤x<L2−P2L2<x≤LV(x) = \begin{cases} \frac{P}{2} & 0 \le x < \frac{L}{2} \\[6pt] -\frac{P}{2} & \frac{L}{2} < x \le L \end{cases}V(x)=⎩⎨⎧​2P​−2P​​0≤x<2L​2L​<x≤L​

最大弯矩出现在加载点，Mmax⁡=PL4M_{\max} = \frac{PL}{4}Mmax​=4PL​。

弯曲正应力

基于平截面假设（Euler-Bernoulli 假设），纯弯曲时截面保持平面并绕中性轴旋转。距中性轴为 yyy 的纤维上正应力：

σ=MyI\sigma = \frac{M y}{I}σ=IMy​

最大正应力出现在截面最远处 ymax⁡y_{\max}ymax​：

σmax⁡=MW\sigma_{\max} = \frac{M}{W}σmax​=WM​

其中 W=Iymax⁡W = \frac{I}{y_{\max}}W=ymax​I​ 为截面抗弯模量。

弯曲切应力

横向载荷产生剪力 VVV，截面上分布有切应力：

τ=VQIb\tau = \frac{V Q}{I b}τ=IbVQ​

其中 Q=∫yymax⁡y dAQ = \int_{y}^{y_{\max}} y \, dAQ=∫yymax​​ydA 是截面面积的静矩。矩形截面的切应力沿高度呈抛物线分布，中性轴处最大：

τmax⁡=3V2A=3V2bh\tau_{\max} = \frac{3V}{2A} = \frac{3V}{2bh}τmax​=2A3V​=2bh3V​

对于工字梁，几乎全部剪力由腹板承担，翼缘切应力很小。

挠度与挠曲线

挠曲线微分方程将弯矩 M(x)M(x)M(x) 和梁的变形 y(x)y(x)y(x) 联系起来：

EId2ydx2=M(x)EI \frac{d^2 y}{dx^2} = M(x)EIdx2d2y​=M(x)

通过二次积分并利用边界条件（如简支梁两端挠度为零）可求得挠曲线。

简支梁中点集中力 PPP 的最大挠度：

δmax⁡=PL348EI\delta_{\max} = \frac{PL^3}{48EI}δmax​=48EIPL3​

简支梁均布载荷 qqq 的最大挠度：

δmax⁡=5qL4384EI\delta_{\max} = \frac{5qL^4}{384EI}δmax​=384EI5qL4​

悬臂梁自由端集中力 PPP 的最大挠度：

δmax⁡=PL33EI\delta_{\max} = \frac{PL^3}{3EI}δmax​=3EIPL3​

叠加法可用于组合载荷——将各简单载荷情况的挠度代数相加。工程手册中有大量标准载荷情况的挠度公式可供直接查阅。

超静定梁

当支反力数目超过平衡方程数目时，梁为超静定结构。需要补充变形协调条件（兼容方程）求解多余约束力。常用方法包括：

  • 力法：以多余约束力为未知数，利用变形兼容条件列方程
  • 叠加法：将超静定梁分解为基本静定结构加多余力的组合
  • 三弯矩方程：连续梁分析的经典方法

练习与思考

  1. 一根简支梁跨度 L=4 mL = 4\,\text{m}L=4m，承受均布载荷 q=10 kN/mq = 10\,\text{kN/m}q=10kN/m。绘制剪力图和弯矩图，求最大弯矩值。

  2. 矩形截面梁宽 b=80 mmb = 80\,\text{mm}b=80mm，高 h=160 mmh = 160\,\text{mm}h=160mm，已知截面最大弯矩 M=25 kN⋅mM = 25\,\text{kN·m}M=25kN⋅m。求最大弯曲正应力和中性轴处最大切应力（剪力 V=30 kNV = 30\,\text{kN}V=30kN）。

  3. 比较同等截面面积条件下，实心圆截面与空心圆截面（D/d=2D/d = 2D/d=2）的抗弯模量，说明为什么空心截面更高效。

  4. 思考题：为什么高层建筑的钢梁大多采用工字型截面而非矩形截面？从材料效率和应力分布角度分析。

拓展阅读

  • Timoshenko 梁理论：考虑截面剪切变形的影响（Euler-Bernoulli 梁理论忽略剪切变形），适用于短粗梁和夹层结构。
  • 曲梁弯曲：当梁的曲率半径与截面尺寸相当时，应力分布不再是线性的，需要使用弯曲梁公式进行修正。
  • 复合材料梁：由多种材料组合的梁（如钢筋混凝土梁），分析时需将不同材料等效转换为同一种材料。
  • 有限元梁单元：现代结构软件中梁单元（beam element）的理论基础就是 Euler-Bernoulli 理论和 Timoshenko 理论。

小结

梁弯曲分析的核心流程为：先由平衡方程和载荷条件绘制剪力图、弯矩图，然后用 σ=My/I\sigma = My/Iσ=My/I 和 τ=VQ/(Ib)\tau = VQ/(Ib)τ=VQ/(Ib) 分别计算弯曲正应力和切应力，最后通过挠曲线方程 EIy′′=M(x)EI y'' = M(x)EIy′′=M(x) 求解变形。截面的惯性矩 III 是影响梁强度和刚度的关键参数，合理设计截面形状（如工字型）可以在相同材料用量下大幅提高承载能力。
