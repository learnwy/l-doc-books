03 法学 (Law & Social Sciences)法学 简介

法学 简介

法学是一门关于规则应当如何的学问：它追问什么样的行为规则具有约束力、国家权力凭什么可以被行使又必须被限制、权利受到侵害时如何获得救济。与描述社会实际如何运行的社会科学不同，法学的核心工作是在规范体系内部做精确推理——从条文到事实，从原则到判决——同时对这套体系本身的正当性保持反思。

本 hub 是大学法学门类下的法学基础 hub，覆盖法理学、宪法与行政法、民法与刑法、国际法四块内容，目标是让自学者建立完整的法学概念框架和规范推理能力。

本 hub 与兄弟 hub 的分工边界

法学门类下还有政治学、社会学、公安学等兄弟 hub。它们与法学共享研究对象（国家、社会、冲突、秩序），但提问方式不同。选错 hub 会浪费时间，先用下表定位你的需求：

你想弄清楚的问题 应去的 hub 与本 hub 的边界
权力实际如何运行、制度为何这样设计 政治学 政治学研究权力的实然（谁在决策、如何博弈）；本 hub 的宪法与行政法研究权力的应然（依据什么规范、受什么限制）。同一个全国人大制度，政治学讲它如何形成，宪法原理讲它如何被规范。
国家之间为何冲突与合作 国际关系 国际关系解释国家行为的规律（权力转移、结盟逻辑）；本 hub 第四章讲国家间的义务（条约约束、管辖权、争端解决）。面对中美贸易摩擦，国关问实力结构如何演变，国际贸易法问谁违反了世贸组织规则。
犯罪为何发生、如何侦查与预防 公安学 公安学是事实与操作层面的学科（犯罪成因、侦查技术、治安管理）；本 hub 的刑法原理是它的规范前提——先知道什么构成犯罪、如何处罚，再谈如何发现和预防。
社会结构与变迁的普遍规律 社会学 社会学提供理解法律实效的背景（为什么"书本上的法"与"行动中的法"有差距）；本 hub 法理学概论的"法律与社会"一节正是两科交界，但法学始终落脚在规范上。
马克思主义如何分析社会 马克思主义理论 马克思主义理论提供中国法律体系的指导思想底色（法的阶级性、社会主义法治）；本 hub 在法系比较中处理这一定位，但不展开理论体系本身。
具体的助人与救助实务 社会工作 社会工作处理法律救济覆盖不到的日常困境；本 hub 的行政救济、国家赔偿是它的制度环境之一，两科是"制度框架 vs 实务操作"的关系。

一句话总结：法学管"依什么规则"，兄弟学科管"实际怎么样"。 需要规范推理时回到本 hub，需要事实解释时去对应学科。

知识结构

本 hub 共四章十二篇，从抽象到具体、从国内到国际：

  1. 法学理论——法理学概论、法系比较、法哲学。回答"法是什么、效力从何而来"，为一切部门法提供概念工具。
  2. 宪法与行政法——宪法原理、行政法、基本权利。公法领域：国家权力如何被授权、被约束，公民权利如何被保障。
  3. 民法与刑法——民法基础、刑法原理、侵权法。与日常生活最贴近的部门法：私人自治、犯罪与刑罚、损害赔偿。
  4. 国际法——国际公法、国际人道法、国际贸易法。法律如何在无"世界政府"的主权国家体系中运作。

推荐学习路径

零基础通识读者（想建立法治观念，不追求专业深度）：只读三篇——法理学概论（法律推理与解释方法）→ 宪法原理（权力如何被限制）→ 基本权利（你有哪些权利、国家何时可以限制）。每篇约一小时，读时重点做各篇"练习与思考"第一题。

系统自学者（法学入门、备考法学类课程）：按章顺序通读全部十二篇，第一章必须先行（法理学概念贯穿后续所有章节），第三章放慢速度（概念密度最高），每篇完成两道以上练习题并查阅文中提到的法条原文。

实务向读者（关注民商事与日常维权）：法理学概论（先掌握解释方法）→ 民法基础 → 侵权法 → 行政法（重点读行政救济一节）。这条线覆盖"签合同、买东西受损害、和行政机关打交道"三类高频场景。

国际向读者（涉外工作、国际贸易、新闻分析）：法理学概论 → 法系比较（先理解两大法系差异，涉外法律检索必备）→ 国际公法 → 国际贸易法与国际人道法按兴趣选读。

前置知识

  • 高中道德与法治的基本常识：违法与犯罪的区分、权利义务概念、国家机构框架。本 hub 不再重复这些内容。
  • 基本逻辑能力：能识别三段论结构（大前提—小前提—结论）。法律推理大量使用三段论，法理学概论的演绎推理一节默认你具备此能力。
  • 查阅法条的耐心：多篇练习要求查阅《宪法》《民法典》《行政诉讼法》条文原文作答，这是法学学习的必要动作，不可跳过。
  • 无需任何部门法基础——专业概念（如物权、构成要件、条约相对性）在各篇首次出现处均有定义。

延伸阅读

以下兄弟 hub 与法学存在真实的学科交界，可作为跨学科探索的入口（本 hub 各 L4 篇章保持内容自足，不依赖这些链接）：

  • 政治学——读完宪法原理后，从政治学视角理解权力配置的现实动力，规范与事实互为参照。
  • 国际关系——读完国际法后对照国际关系理论，理解规则背后的实力结构与博弈逻辑。
  • 公安学——读完刑法原理后进入犯罪学与侦查学，从规范走向事实与操作。
  • 社会学——对"法律为何在现实中失灵"感兴趣的读者，社会学的结构视角是法社会学研究的根基。
