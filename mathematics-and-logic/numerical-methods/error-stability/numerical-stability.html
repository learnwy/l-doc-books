数值稳定性

核心概念

数值稳定性描述的是算法在有限精度算术下的行为特征。一个数值稳定的算法能够在浮点运算的舍入误差积累下，仍然产出可靠的结果；而不稳定的算法会让微小的舍入误差在计算过程中指数级放大，最终完全淹没真实信号。

稳定性与条件数是互补的概念：条件数衡量问题本身的敏感性（不依赖算法），稳定性衡量算法对舍入误差的抵抗能力。一个好的数值方法需要同时考虑两者——用稳定的算法求解良态问题，才能获得可靠的结果。

后向稳定性理论
后向稳定性是数值线性代数中最重要的稳定性概念，由 Wilkinson 在 20 世纪 60 年代系统发展。一个算法 f^\hat{f}f^​ 是后向稳定的，如果对任意输入 xxx，存在微小扰动 Δx\Delta xΔx，使得 f^(x)=f(x+Δx)\hat{f}(x) = f(x + \Delta x)f^​(x)=f(x+Δx)，且 ∥Δx∥/∥x∥=O(εmach)\|\Delta x\| / \|x\| = O(\varepsilon_{\text{mach}})∥Δx∥/∥x∥=O(εmach​)。


后向稳定性的核心价值在于它将精度分析简化为两步：首先证明算法是后向稳定的（纯算法分析），然后用条件数将后向误差转化为前向误差界。


import numpy as np

def demo_backward_stability():
    np.random.seed(42)
    n = 100
    A = np.random.randn(n, n)
    x_true = np.random.randn(n)
    b = A @ x_true

    x_comp = np.linalg.solve(A, b)

    forward_err = np.linalg.norm(x_comp - x_true) / np.linalg.norm(x_true)

    residual = b - A @ x_comp
    backward_err = np.linalg.norm(residual) / (np.linalg.norm(A) * np.linalg.norm(x_comp))

    cond_A = np.linalg.cond(A)

    print(f"矩阵条件数: {cond_A:.4e}")
    print(f"后向误差: {backward_err:.4e}")
    print(f"前向误差: {forward_err:.4e}")
    print(f"条件数 × 后向误差: {cond_A * backward_err:.4e}")
    print(f"前向误差 ≤ 条件数 × 后向误差: {forward_err <= 2 * cond_A * backward_err}")

经典不稳定算法案例
理解不稳定性的最好方式是分析具体的失败案例。以下几个经典例子展示了不稳定算法如何在实践中崩溃。


第一个经典案例是不选主元的高斯消去法。当主元素接近零时，消去过程中的乘数可以变得任意大，导致舍入误差被极度放大：


import numpy as np

A_bad = np.array([
    [1e-20, 1.0],
    [1.0,   1.0]
], dtype=np.float64)
b = np.array([1.0, 2.0], dtype=np.float64)

m = A_bad[1, 0] / A_bad[0, 0]
A_elim = A_bad.copy()
b_elim = b.copy()
A_elim[1] = A_elim[1] - m * A_elim[0]
b_elim[1] = b_elim[1] - m * b_elim[0]
x2 = b_elim[1] / A_elim[1, 1]
x1 = (b_elim[0] - A_elim[0, 1] * x2) / A_elim[0, 0]
print(f"无选主元: x = [{x1:.15f}, {x2:.15f}]")

x_correct = np.linalg.solve(A_bad, b)
print(f"有选主元: x = [{x_correct[0]:.15f}, {x_correct[1]:.15f}]")
第二个经典案例是递推关系的数值不稳定性。考虑计算积分 En=∫01xnex−1dxE_n = \int_0^1 x^n e^{x-1} dxEn​=∫01​xnex−1dx 的递推公式 En=1−nEn−1E_n = 1 - n E_{n-1}En​=1−nEn−1​：


import numpy as np
from scipy import integrate

def forward_recurrence(n_max):
    E = [1 - 1/np.e]
    for n in range(1, n_max + 1):
        E.append(1 - n * E[-1])
    return E

def exact_integral(n):
    result, _ = integrate.quad(lambda x: x**n * np.exp(x - 1), 0, 1)
    return result

E_forward = forward_recurrence(25)
for n in [5, 10, 15, 20, 25]:
    exact = exact_integral(n)
    print(f"E_{n:2d}: 递推={E_forward[n]:.10f}, 精确={exact:.10f}, "
          f"相对误差={abs(E_forward[n] - exact) / exact:.2e}")
这个递推关系中，每步乘以 nnn 会将上一步的误差放大 nnn 倍，经过 20 步后误差放大 20!≈2.4×101820! \approx 2.4 \times 10^{18}20!≈2.4×1018 倍，远超双精度可承受的范围。解决方法是从大的 nnn 开始反向递推，利用 En−1=(1−En)/nE_{n-1} = (1 - E_n) / nEn−1​=(1−En​)/n 的衰减特性使误差逐步缩小。


稳定性改进技术
将不稳定算法改造为稳定算法，通常有几种系统性的方法。


选主元策略是高斯消去法稳定化的关键。部分选主元（partial pivoting）在每步消去前选择当前列中绝对值最大的元素作为主元，防止了小主元导致的误差放大。完全选主元（complete pivoting）在剩余子矩阵中搜索全局最大元素，理论上更优但实际中部分选主元已足够。


import numpy as np

def lu_no_pivot(A):
    n = A.shape[0]
    L = np.eye(n)
    U = A.astype(np.float64).copy()
    for k in range(n - 1):
        for i in range(k + 1, n):
            L[i, k] = U[i, k] / U[k, k]
            U[i, k:] -= L[i, k] * U[k, k:]
    return L, U

def lu_partial_pivot(A):
    n = A.shape[0]
    P = np.eye(n)
    L = np.zeros((n, n))
    U = A.astype(np.float64).copy()
    for k in range(n - 1):
        pivot = np.argmax(np.abs(U[k:, k])) + k
        if pivot != k:
            U[[k, pivot]] = U[[pivot, k]]
            P[[k, pivot]] = P[[pivot, k]]
            if k > 0:
                L[[k, pivot], :k] = L[[pivot, k], :k]
        for i in range(k + 1, n):
            L[i, k] = U[i, k] / U[k, k]
            U[i, k:] -= L[i, k] * U[k, k:]
    np.fill_diagonal(L, 1)
    return P, L, U

A = np.array([[1e-18, 1], [1, 1]], dtype=np.float64)
b = np.array([1.0, 2.0])

L, U = lu_no_pivot(A)
y = np.linalg.solve(L, b)
x_no = np.linalg.solve(U, y)
print(f"无选主元: {x_no}")

P, L, U = lu_partial_pivot(A)
y = np.linalg.solve(L, P @ b)
x_pp = np.linalg.solve(U, y)
print(f"部分选主元: {x_pp}")

迭代精化方法
迭代精化（iterative refinement）是一种通过残差修正来提高求解精度的技术。其基本思想是：先用普通精度求出近似解，然后计算残差，在更高精度下求解残差方程，最后用修正量更新解。


import numpy as np

def iterative_refinement(A, b, max_iter=5, tol=1e-14):
    x = np.linalg.solve(A, b)
    results = [(0, np.linalg.norm(b - A @ x) / np.linalg.norm(b))]

    for k in range(1, max_iter + 1):
        r = b - A @ x
        dx = np.linalg.solve(A, r)
        x = x + dx
        rel_res = np.linalg.norm(b - A @ x) / np.linalg.norm(b)
        results.append((k, rel_res))
        if rel_res < tol:
            break

    return x, results

np.random.seed(42)
n = 50
A = np.random.randn(n, n)
A = A + A.T + n * np.eye(n)
x_true = np.random.randn(n)
b = A @ x_true

x_refined, history = iterative_refinement(A, b)
print("迭代精化过程:")
for step, res in history:
    print(f"  迭代 {step}: 相对残差 = {res:.4e}")

print(f"\n最终前向误差: {np.linalg.norm(x_refined - x_true) / np.linalg.norm(x_true):.4e}")
小结
    

  • 数值稳定性衡量算法对舍入误差的抵抗能力，与问题的条件数互补构成精度分析的完整框架
    • 

  • 后向稳定性是最重要的稳定性概念，它保证计算结果等于稍加扰动输入的精确解
    • 

  • 不选主元的高斯消去和前向递推是经典的不稳定算法案例，展示了误差指数级放大的危害
    • 

  • 选主元、正交化、反向递推等技术可以系统性地将不稳定算法改造为稳定算法
    • 

  • 迭代精化通过残差修正提高求解精度，是工程实践中常用的精度增强手段
    • 

  • 稳定算法 + 良态问题 = 可靠结果，这一原则是数值方法设计的根本指导思想
