误差传播

核心概念

误差传播（error propagation）研究输入数据中的误差如何通过数学运算传递并放大到最终结果中。在数值计算中，初始数据往往包含测量误差或舍入误差，理解这些误差在运算链中如何演化，是评估计算结果可靠性的关键。

误差传播分析的核心工具是条件数（condition number），它量化了问题本身对输入扰动的敏感程度。条件数大的问题称为病态问题（ill-conditioned），即使使用精确的算法，小的输入扰动也会导致结果的巨大偏差。

误差的度量方式分为绝对误差和相对误差，二者在不同场景下各有适用性：

减法是误差传播中最危险的运算。当两个相近的数相减时，有效数字大量抵消，相对误差可能被放大数个数量级，这就是灾难性抵消。


import numpy as np

x_true = 1.000000001
y_true = 1.000000000

x = np.float64(x_true)
y = np.float64(y_true)

z_true = x_true - y_true
z_comp = x - y

abs_err = abs(z_comp - z_true)
rel_err = abs_err / abs(z_true) if z_true != 0 else float('inf')

print(f"真实差值: {z_true:.15e}")
print(f"计算差值: {z_comp:.15e}")
print(f"相对误差: {rel_err:.6e}")

条件数分析
条件数是误差传播理论中最重要的概念，它描述了问题本身（而非算法）对输入扰动的敏感性。一个问题的条件数越大，任何算法在求解该问题时都面临更大的精度挑战。


对于函数 y=f(x)y = f(x)y=f(x)，相对条件数定义为：


κ=∣xf′(x)f(x)∣\kappa = \left| \frac{x f'(x)}{f(x)} \right|κ=​f(x)xf′(x)​​
条件数的物理含义是：输入的相对扰动被放大 κ\kappaκ 倍传递到输出。当 κ≫1\kappa \gg 1κ≫1 时，问题是病态的。


import numpy as np

def condition_number_func(f, df, x):
    return abs(x * df(x) / f(x))

f = lambda x: np.sqrt(x)
df = lambda x: 0.5 / np.sqrt(x)
print(f"sqrt(x) 在 x=1 处的条件数: {condition_number_func(f, df, 1.0):.4f}")
print(f"sqrt(x) 在 x=100 处的条件数: {condition_number_func(f, df, 100.0):.4f}")

g = lambda x: 1.0 / (x - 1.0)
dg = lambda x: -1.0 / (x - 1.0)**2
for x in [2.0, 1.1, 1.01, 1.001]:
    kappa = condition_number_func(g, dg, x)
    print(f"1/(x-1) 在 x={x} 处的条件数: {kappa:.2f}")
对于线性方程组 Ax=bAx = bAx=b，矩阵的条件数定义为 κ(A)=∥A∥⋅∥A−1∥\kappa(A) = \|A\| \cdot \|A^{-1}\|κ(A)=∥A∥⋅∥A−1∥。条件数越大，方程组对右端向量 bbb 的扰动越敏感：


import numpy as np

A_good = np.array([[2, 1], [1, 3]], dtype=np.float64)
A_bad = np.array([[1, 1], [1, 1.0001]], dtype=np.float64)

print(f"良态矩阵条件数: {np.linalg.cond(A_good):.2f}")
print(f"病态矩阵条件数: {np.linalg.cond(A_bad):.2f}")

b = np.array([3.0, 4.0])
x1 = np.linalg.solve(A_bad, b)
b_perturbed = b + np.array([0.0001, 0.0001])
x2 = np.linalg.solve(A_bad, b_perturbed)
print(f"\n扰动前解: {x1}")
print(f"扰动后解: {x2}")
print(f"解的变化: {np.linalg.norm(x2 - x1) / np.linalg.norm(x1):.6f}")
前向误差与后向误差
误差分析有两种互补的视角：前向分析和后向分析。前向分析直接估计计算结果与真实结果的偏差；后向分析则反过来问：计算结果是某个稍微不同的输入的精确解吗？


后向误差分析由 Wilkinson 提出，是现代数值分析的基石。一个算法如果满足"计算结果等于稍加扰动的输入的精确解"，就称为后向稳定的（backward stable）。

后向分析的威力在于将"算法误差"和"问题敏感度"分离：总前向误差 ≤ 后向误差 × 条件数。这意味着一个后向稳定的算法在良态问题上一定能给出好的结果。


import numpy as np

n = 5
A = np.random.randn(n, n)
x_true = np.random.randn(n)
b = A @ x_true

x_computed = np.linalg.solve(A, b)

forward_error = np.linalg.norm(x_computed - x_true) / np.linalg.norm(x_true)

residual = b - A @ x_computed
backward_error = np.linalg.norm(residual) / (np.linalg.norm(A) * np.linalg.norm(x_computed) + np.linalg.norm(b))

cond = np.linalg.cond(A)
print(f"条件数: {cond:.4e}")
print(f"前向误差: {forward_error:.4e}")
print(f"后向误差: {backward_error:.4e}")
print(f"前向误差 ≤ 条件数 × 后向误差: {forward_error <= cond * backward_error}")
误差传播的实用策略
在实际数值程序中，控制误差传播需要系统性的策略。以下是几种常用的误差控制方法。


避免灾难性抵消是最重要的原则。通过数学恒等变换，可以将减法转化为其他运算。例如求解一元二次方程 ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0 时，标准公式在判别式接近零时会产生灾难性抵消：


import numpy as np

def quadratic_naive(a, b, c):
    disc = b**2 - 4*a*c
    sqrt_disc = np.sqrt(disc)
    x1 = (-b + sqrt_disc) / (2*a)
    x2 = (-b - sqrt_disc) / (2*a)
    return x1, x2

def quadratic_stable(a, b, c):
    disc = b**2 - 4*a*c
    sqrt_disc = np.sqrt(disc)
    if b >= 0:
        q = -0.5 * (b + sqrt_disc)
    else:
        q = -0.5 * (b - sqrt_disc)
    x1 = q / a
    x2 = c / q
    return x1, x2

a, b, c = 1.0, -1e8, 1.0
x1_n, x2_n = quadratic_naive(a, b, c)
x1_s, x2_s = quadratic_stable(a, b, c)
print(f"朴素解: x1={x1_n:.15e}, x2={x2_n:.15e}")
print(f"稳定解: x1={x1_s:.15e}, x2={x2_s:.15e}")
print(f"验证 x1*x2 = c/a = {c/a}: 朴素={x1_n*x2_n:.6e}, 稳定={x1_s*x2_s:.6e}")

小结
    

  • 误差传播研究输入误差通过运算链传递和放大的规律，条件数是核心度量指标
    • 

  • 减法是最危险的运算，两个相近数相减会导致灾难性抵消，相对误差急剧放大
    • 

  • 条件数 κ\kappaκ 描述问题本身的敏感性，κ≫1\kappa \gg 1κ≫1 的问题是病态的
    • 

  • 后向误差分析将算法误差与问题敏感度分离，是评估算法稳定性的标准框架
    • 

  • 控制误差传播的关键策略包括避免灾难性抵消、合理排序求和、以及条件数预检
    • 

  • 总前向误差的上界等于后向误差乘以条件数，这一关系是数值算法设计的理论基础
