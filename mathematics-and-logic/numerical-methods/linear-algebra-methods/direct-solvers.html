直接求解法

核心概念

直接求解法是指通过有限步精确运算（在无舍入误差的理想情况下）得到线性方程组 Ax=bAx = bAx=b 精确解的算法。与迭代法不同，直接法的计算步数是确定的，不依赖收敛条件。高斯消去法及其变体是直接求解法的核心。

直接求解法的基本思想是将原方程组通过行变换转化为容易求解的等价形式——通常是上三角或下三角形式，然后通过回代（back substitution）得到解。这一思想的矩阵分解表述就是 LU 分解：A=LUA = LUA=LU，将一次求解分解为两次三角方程组的求解。

高斯消去与 LU 分解
高斯消去法是最基础的直接求解法。它通过逐列消去下三角部分的元素，将增广矩阵 [A∣b][A|b][A∣b] 化为行阶梯形，然后回代求解。将消去过程中的乘数记录下来，就构成了 LU 分解。


LU 分解将矩阵 AAA 分解为下三角矩阵 LLL 和上三角矩阵 UUU 的乘积。分解完成后，求解 Ax=bAx = bAx=b 转化为先解 Ly=bLy = bLy=b（前代）再解 Ux=yUx = yUx=y（回代），各需 O(n2)O(n^2)O(n2) 次运算。当需要对同一个 AAA 求解多个不同的 bbb 时，LU 分解的优势尤其明显。


import numpy as np

def lu_decomposition(A):
    n = A.shape[0]
    L = np.eye(n)
    U = A.astype(np.float64).copy()

    for k in range(n - 1):
        for i in range(k + 1, n):
            L[i, k] = U[i, k] / U[k, k]
            U[i, k:] -= L[i, k] * U[k, k:]

    return L, U

def forward_substitution(L, b):
    n = len(b)
    y = np.zeros(n)
    for i in range(n):
        y[i] = (b[i] - L[i, :i] @ y[:i]) / L[i, i]
    return y

def back_substitution(U, y):
    n = len(y)
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):
        x[i] = (y[i] - U[i, i+1:] @ x[i+1:]) / U[i, i]
    return x

A = np.array([[2, 1, 1], [4, 3, 3], [8, 7, 9]], dtype=np.float64)
b = np.array([1, 1, 1], dtype=np.float64)

L, U = lu_decomposition(A)
y = forward_substitution(L, b)
x = back_substitution(U, y)

print(f"L =\n{L}")
print(f"U =\n{U}")
print(f"解 x = {x}")
print(f"残差 ||Ax-b|| = {np.linalg.norm(A @ x - b):.2e}")
部分选主元（partial pivoting）在每步消去前选择当前列中绝对值最大的元素作为主元，交换对应行，确保乘数 ∣lik∣≤1|l_{ik}| \leq 1∣lik​∣≤1。这使得高斯消去法在实践中是后向稳定的：


import numpy as np

def lu_partial_pivot(A):
    n = A.shape[0]
    P = np.eye(n)
    L = np.zeros((n, n))
    U = A.astype(np.float64).copy()

    for k in range(n - 1):
        pivot_row = np.argmax(np.abs(U[k:, k])) + k
        if pivot_row != k:
            U[[k, pivot_row]] = U[[pivot_row, k]]
            P[[k, pivot_row]] = P[[pivot_row, k]]
            if k > 0:
                L[[k, pivot_row], :k] = L[[pivot_row, k], :k]
        for i in range(k + 1, n):
            L[i, k] = U[i, k] / U[k, k]
            U[i, k:] -= L[i, k] * U[k, k:]

    np.fill_diagonal(L, 1)
    return P, L, U

A = np.array([[1e-18, 1], [1, 1]], dtype=np.float64)
b = np.array([1.0, 2.0])

P, L, U = lu_partial_pivot(A)
y = forward_substitution(L, P @ b)
x = back_substitution(U, y)
print(f"PLU 分解解: {x}")
print(f"NumPy 解: {np.linalg.solve(A, b)}")
Cholesky 分解
当矩阵 AAA 是对称正定（SPD）时，可以利用 Cholesky 分解 A=LLTA = LL^TA=LLT，其中 LLL 是下三角矩阵。Cholesky 分解的计算量仅为一般 LU 分解的一半（n3/6n^3/6n3/6 vs n3/3n^3/3n3/3），且天然数值稳定，无需选主元。


Cholesky 分解的存在性与矩阵的正定性等价——如果分解过程中出现负的对角元素，则表明矩阵不是正定的。这一性质使得 Cholesky 分解也可以作为正定性检测工具。


import numpy as np

def cholesky(A):
    n = A.shape[0]
    L = np.zeros((n, n))

    for j in range(n):
        for i in range(j, n):
            if i == j:
                val = A[i, i] - np.sum(L[i, :j]**2)
                if val <= 0:
                    raise ValueError(f"矩阵非正定，第 {j} 步对角元素 = {val}")
                L[i, j] = np.sqrt(val)
            else:
                L[i, j] = (A[i, j] - np.sum(L[i, :j] * L[j, :j])) / L[j, j]

    return L

A = np.array([[4, 2, 1], [2, 5, 3], [1, 3, 6]], dtype=np.float64)
L = cholesky(A)
print(f"L =\n{L}")
print(f"L @ L^T =\n{L @ L.T}")
print(f"重构误差: {np.linalg.norm(A - L @ L.T):.2e}")

b = np.array([1.0, 2.0, 3.0])
y = forward_substitution(L, b)
x = back_substitution(L.T, y)
print(f"解 x = {x}")
print(f"验证: {np.allclose(A @ x, b)}")
QR 分解与最小二乘
QR 分解将矩阵 AAA 分解为正交矩阵 QQQ 和上三角矩阵 RRR 的乘积：A=QRA = QRA=QR。由于正交变换不改变向量范数，QR 分解具有优异的数值稳定性，是解决最小二乘问题 min⁡x∥Ax−b∥2\min_x \|Ax - b\|_2minx​∥Ax−b∥2​ 的标准方法。


Householder 变换是构造 QR 分解最常用的方法。每个 Householder 变换 H=I−2vvT/vTvH = I - 2vv^T/v^TvH=I−2vvT/vTv 是一个关于超平面的镜像反射，它能将一个向量的某些分量清零。通过 n−1n-1n−1 次 Householder 变换，可以将 AAA 化为上三角形式。


import numpy as np

def householder_qr(A):
    m, n = A.shape
    R = A.astype(np.float64).copy()
    Q = np.eye(m)

    for k in range(min(m - 1, n)):
        x = R[k:, k].copy()
        e1 = np.zeros_like(x)
        e1[0] = np.linalg.norm(x) * (1 if x[0] >= 0 else -1)
        v = x + e1
        v = v / np.linalg.norm(v)

        R[k:, k:] -= 2 * np.outer(v, v @ R[k:, k:])
        Q[:, k:] -= 2 * np.outer(Q[:, k:] @ v, v)

    return Q, R

A = np.array([[1, 1], [1, 2], [1, 3]], dtype=np.float64)
b = np.array([1, 2, 2], dtype=np.float64)

Q, R = householder_qr(A)
print(f"Q =\n{Q[:, :2]}")
print(f"R =\n{R[:2]}")
print(f"正交性检验: ||Q^TQ - I|| = {np.linalg.norm(Q.T @ Q - np.eye(3)):.2e}")

x_qr = back_substitution(R[:2, :2], (Q.T @ b)[:2])
x_np, _, _, _ = np.linalg.lstsq(A, b, rcond=None)
print(f"\nQR 最小二乘解: {x_qr}")
print(f"NumPy 最小二乘解: {x_np}")

三角方程组与带状矩阵
许多实际问题产生的矩阵具有特殊结构——三对角矩阵、带状矩阵、上/下 Hessenberg 矩阵等。利用这些结构可以大幅减少计算量和存储需求。


三对角方程组是最常见的结构化方程组，可以用 Thomas 算法（追赶法）在 O(n)O(n)O(n) 时间内求解，比一般高斯消去法的 O(n3)O(n^3)O(n3) 快了两个数量级：


import numpy as np

def thomas_algorithm(a, b, c, d):
    n = len(b)
    c_prime = np.zeros(n)
    d_prime = np.zeros(n)

    c_prime[0] = c[0] / b[0]
    d_prime[0] = d[0] / b[0]

    for i in range(1, n):
        m = b[i] - a[i - 1] * c_prime[i - 1]
        c_prime[i] = c[i] / m if i < n - 1 else 0
        d_prime[i] = (d[i] - a[i - 1] * d_prime[i - 1]) / m

    x = np.zeros(n)
    x[-1] = d_prime[-1]
    for i in range(n - 2, -1, -1):
        x[i] = d_prime[i] - c_prime[i] * x[i + 1]

    return x

n = 100
a = -np.ones(n - 1)
b = 2 * np.ones(n)
c = -np.ones(n - 1)
d = np.random.randn(n)

x_thomas = thomas_algorithm(a, b, c, d)

A_full = np.diag(b) + np.diag(a, -1) + np.diag(c, 1)
x_direct = np.linalg.solve(A_full, d)

print(f"Thomas vs 直接求解误差: {np.linalg.norm(x_thomas - x_direct):.2e}")
print(f"残差: {np.linalg.norm(A_full @ x_thomas - d):.2e}")

小结
    

  • 直接求解法通过有限步运算精确求解线性方程组，LU 分解是最基本的矩阵分解形式
    • 

  • 部分选主元使高斯消去法成为后向稳定算法，是工业级实现的标准配置
    • 

  • Cholesky 分解利用对称正定性质将计算量减半，且天然数值稳定
    • 

  • QR 分解通过正交变换保持数值稳定性，是最小二乘问题的标准求解方法
    • 

  • 三对角等结构化矩阵可以利用 Thomas 算法等特殊方法实现 O(n)O(n)O(n) 求解
    • 

  • 选择合适的直接求解法需要综合考虑矩阵的结构、规模和精度要求
