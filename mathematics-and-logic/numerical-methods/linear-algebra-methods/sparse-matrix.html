稀疏矩阵

核心概念

稀疏矩阵是指大多数元素为零的矩阵。在科学计算和工程应用中，有限元方法、图论算法、网络分析等产生的矩阵通常只有 O(n)O(n)O(n) 个非零元素，远少于 n2n^2n2 个总元素。利用稀疏性可以将存储从 O(n2)O(n^2)O(n2) 降至 O(nnz)O(\text{nnz})O(nnz)，计算复杂度也相应大幅降低。

稀疏矩阵的关键挑战不仅是存储效率，还包括如何在避免填入（fill-in）的同时保持数值稳定性。填入是指在矩阵分解过程中，原本为零的位置变为非零的现象。好的稀疏算法通过重排序和特殊数据结构来最小化填入。

CSR 与 CSC 格式
压缩行存储（CSR, Compressed Sparse Row）是最常用的稀疏矩阵格式，由三个一维数组组成：values（非零元素值）、col_indices（列索引）、row_ptr（行起始指针）。CSC 是其列优先的对偶形式。


CSR 格式的核心优势是行遍历高效——访问第 iii 行的所有非零元素只需读取 values[row_ptr[i]:row_ptr[i+1]]，这使得稀疏矩阵-向量乘法（SpMV）y=Axy = Axy=Ax 可以在 O(nnz)O(\text{nnz})O(nnz) 时间内完成。


import numpy as np
from scipy import sparse

class SimpleCSR:
    def __init__(self, values, col_indices, row_ptr, shape):
        self.values = np.array(values, dtype=np.float64)
        self.col_indices = np.array(col_indices, dtype=np.int32)
        self.row_ptr = np.array(row_ptr, dtype=np.int32)
        self.shape = shape

    def matvec(self, x):
        y = np.zeros(self.shape[0])
        for i in range(self.shape[0]):
            start, end = self.row_ptr[i], self.row_ptr[i + 1]
            for j in range(start, end):
                y[i] += self.values[j] * x[self.col_indices[j]]
        return y

    @property
    def nnz(self):
        return len(self.values)

    @property
    def density(self):
        return self.nnz / (self.shape[0] * self.shape[1])

A_csr = SimpleCSR(
    values=[2, -1, -1, 2, -1, -1, 2, -1, -1, 2],
    col_indices=[0, 1, 0, 1, 2, 1, 2, 3, 2, 3],
    row_ptr=[0, 2, 5, 8, 10],
    shape=(4, 4)
)

x = np.array([1.0, 2.0, 3.0, 4.0])
y = A_csr.matvec(x)
print(f"SpMV 结果: {y}")
print(f"非零元素: {A_csr.nnz}, 密度: {A_csr.density:.2%}")

A_dense = np.array([[2,-1,0,0],[-1,2,-1,0],[0,-1,2,-1],[0,0,-1,2]])
print(f"验证: {A_dense @ x}")

import numpy as np
from scipy import sparse
from scipy.sparse import linalg as spla

n = 1000
diag = 2 * np.ones(n)
off_diag = -np.ones(n - 1)
A = sparse.diags([off_diag, diag, off_diag], [-1, 0, 1], format='csr')

print(f"矩阵维度: {A.shape}")
print(f"非零元素: {A.nnz}")
print(f"密度: {A.nnz / n**2:.6f}")

b = np.ones(n)
x = spla.spsolve(A, b)
print(f"残差: {np.linalg.norm(A @ x - b):.2e}")
稀疏矩阵的填入与重排序
在对稀疏矩阵进行 LU 或 Cholesky 分解时，原本为零的位置可能变为非零，这就是填入（fill-in）。填入的多少取决于矩阵的非零模式和消去顺序。重排序策略通过找到合适的行/列置换来最小化填入。


import numpy as np
from scipy import sparse
from scipy.sparse import linalg as spla
from scipy.sparse.csgraph import reverse_cuthill_mckee

n = 100
np.random.seed(42)
A = sparse.random(n, n, density=0.05, format='csr')
A = A + A.T + 10 * sparse.eye(n)
A = A.tocsr()

perm = reverse_cuthill_mckee(A)
A_reordered = A[perm][:, perm]

print(f"原始矩阵非零元素: {A.nnz}")
print(f"原始矩阵带宽: {max(abs(r - c) for r, c in zip(*A.nonzero()))}")
print(f"重排后带宽: {max(abs(r - c) for r, c in zip(*A_reordered.nonzero()))}")

预条件技术
预条件是加速迭代求解器收敛的关键技术。预条件子 MMM 是 AAA 的某种近似逆，将原方程组 Ax=bAx = bAx=b 转化为 M−1Ax=M−1bM^{-1}Ax = M^{-1}bM−1Ax=M−1b，使得预条件矩阵 M−1AM^{-1}AM−1A 的条件数显著小于 AAA 的条件数。


好的预条件子需要在"接近 A−1A^{-1}A−1"和"容易计算 M−1vM^{-1}vM−1v"之间取得平衡。


import numpy as np
from scipy import sparse
from scipy.sparse import linalg as spla

n = 500
diag = 4 * np.ones(n)
off1 = -np.ones(n - 1)
A = sparse.diags([off1, diag, off1], [-1, 0, 1], format='csr')
b = np.ones(n)

counter_no = [0]
counter_ilu = [0]
counter_diag = [0]

def count_no(x):
    counter_no[0] += 1
def count_ilu(x):
    counter_ilu[0] += 1
def count_diag(x):
    counter_diag[0] += 1

x_no, _ = spla.cg(A, b, tol=1e-10, callback=count_no)
print(f"无预条件 CG: {counter_no[0]} 次迭代")

M_diag = spla.LinearOperator(A.shape, matvec=lambda v: v / A.diagonal())
x_diag, _ = spla.cg(A, b, tol=1e-10, M=M_diag, callback=count_diag)
print(f"对角预条件 CG: {counter_diag[0]} 次迭代")

ilu = spla.spilu(A.tocsc())
M_ilu = spla.LinearOperator(A.shape, matvec=ilu.solve)
x_ilu, _ = spla.cg(A, b, tol=1e-10, M=M_ilu, callback=count_ilu)
print(f"ILU 预条件 CG: {counter_ilu[0]} 次迭代")

稀疏矩阵在实际应用中的模式
不同应用领域产生的稀疏矩阵具有不同的结构特征，选择合适的算法和数据结构需要理解这些模式。


有限差分和有限元方法产生的矩阵具有规则的带状或块状结构，有限差分通常产生对称正定的三对角或五对角矩阵，有限元产生块稀疏矩阵。


import numpy as np
from scipy import sparse

def laplacian_2d(nx, ny):
    N = nx * ny
    diag = 4 * np.ones(N)
    off1 = -np.ones(N - 1)
    for i in range(1, ny):
        off1[i * nx - 1] = 0
    off_nx = -np.ones(N - nx)
    A = sparse.diags([off_nx, off1, diag, off1, off_nx],
                     [-nx, -1, 0, 1, nx], format='csr')
    return A

for nx in [10, 50, 100, 200]:
    A = laplacian_2d(nx, nx)
    n = A.shape[0]
    print(f"网格 {nx}×{nx}: n={n:6d}, nnz={A.nnz:8d}, "
          f"密度={A.nnz/n**2:.6f}, 每行平均非零={A.nnz/n:.1f}")
图和网络问题产生的邻接矩阵和拉普拉斯矩阵具有不规则的稀疏模式，但每行的非零元素数通常有上界（节点度数）：


import numpy as np
from scipy import sparse
from scipy.sparse import linalg as spla

def random_graph_laplacian(n, avg_degree=6):
    p = avg_degree / n
    A = sparse.random(n, n, density=p, format='csr')
    A = (A + A.T) / 2
    A.data[:] = 1.0
    D = sparse.diags(np.array(A.sum(axis=1)).flatten())
    L = D - A
    return L

for n in [100, 1000, 5000]:
    L = random_graph_laplacian(n)
    eigenvalues = spla.eigsh(L, k=6, which='SM', return_eigenvectors=False)
    print(f"n={n:5d}: nnz={L.nnz:8d}, 最小6个特征值={np.sort(eigenvalues)[:3]}")
小结
    

  • 稀疏矩阵在科学计算中无处不在，利用稀疏性可以将存储和计算从 O(n2)O(n^2)O(n2) 降至 O(nnz)O(\text{nnz})O(nnz)
    • 

  • CSR 是最常用的稀疏存储格式，支持高效的行遍历和矩阵-向量乘法
    • 

  • 填入是稀疏直接法的核心挑战，RCM 和 AMD 等重排序策略可以有效减少填入量
    • 

  • 预条件技术是加速迭代求解器的关键，ILU 和 AMG 是最常用的预条件子
    • 

  • 不同应用领域产生的稀疏矩阵具有不同的结构特征，算法选择需要匹配矩阵模式
    • 

  • 大规模稀疏系统通常优先选择预条件迭代法，直接法则适用于中等规模或需要多次求解的场景
    •
