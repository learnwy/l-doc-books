特征值算法

核心概念

特征值问题是数值线性代数的核心问题之一。给定方阵 AAA，求标量 λ\lambdaλ 和非零向量 vvv 使得 Av=λvAv = \lambda vAv=λv，其中 λ\lambdaλ 称为特征值，vvv 称为特征向量。特征值问题在振动分析、主成分分析、Google PageRank、量子力学等领域有广泛应用。

直接计算特征多项式 det⁡(A−λI)=0\det(A - \lambda I) = 0det(A−λI)=0 的根在理论上可行，但对于 n>4n > 4n>4 的矩阵，这种方法在数值上极不稳定且计算量巨大。现代特征值算法全部采用迭代方法，将矩阵逐步变换为更简单的形式，直到特征值显露出来。

幂迭代与反幂迭代
幂迭代（power iteration）是最简单的特征值算法。给定初始向量 v0v_0v0​，反复执行 vk+1=Avk/∥Avk∥v_{k+1} = Av_k / \|Av_k\|vk+1​=Avk​/∥Avk​∥，序列收敛到 AAA 的模最大特征值对应的特征向量。收敛速度由最大和次大特征值之比决定：∣λ2/λ1∣k|\lambda_2/\lambda_1|^k∣λ2​/λ1​∣k。


import numpy as np

def power_iteration(A, tol=1e-12, max_iter=1000):
    n = A.shape[0]
    v = np.random.randn(n)
    v = v / np.linalg.norm(v)
    eigenvalue_old = 0
    history = []

    for k in range(max_iter):
        w = A @ v
        eigenvalue = v @ w
        v = w / np.linalg.norm(w)
        rel_change = abs(eigenvalue - eigenvalue_old) / (abs(eigenvalue) + 1e-30)
        history.append((k, eigenvalue, rel_change))
        if rel_change < tol:
            return eigenvalue, v, history
        eigenvalue_old = eigenvalue

    return eigenvalue, v, history

A = np.array([[4, 1, 0], [1, 3, 1], [0, 1, 2]], dtype=np.float64)
lam, v, hist = power_iteration(A)
exact = np.sort(np.linalg.eigvalsh(A))[::-1]
print(f"幂迭代: λ = {lam:.12f} ({len(hist)} 步)")
print(f"精确值: λ₁ = {exact[0]:.12f}")
print(f"特征向量: {v}")
反幂迭代（inverse iteration）求解 (A−σI)−1v(A - \sigma I)^{-1}v(A−σI)−1v 的最大特征值，等价于求 AAA 最接近 σ\sigmaσ 的特征值。当 σ\sigmaσ 接近某个特征值时，收敛速度极快（三次收敛）。反幂迭代与 QR 算法的位移策略结合，构成了实用 QR 算法的核心组件。


import numpy as np

def inverse_iteration(A, sigma, tol=1e-12, max_iter=100):
    n = A.shape[0]
    v = np.random.randn(n)
    v = v / np.linalg.norm(v)
    B = A - sigma * np.eye(n)
    history = []

    for k in range(max_iter):
        w = np.linalg.solve(B, v)
        v_new = w / np.linalg.norm(w)
        eigenvalue = v_new @ A @ v_new
        rel_change = np.linalg.norm(v_new - v * np.sign(v_new @ v))
        history.append((k, eigenvalue, rel_change))
        if rel_change < tol:
            return eigenvalue, v_new, history
        v = v_new

    return eigenvalue, v, history

A = np.array([[4, 1, 0], [1, 3, 1], [0, 1, 2]], dtype=np.float64)
sigma = 2.1
lam, v, hist = inverse_iteration(A, sigma)
print(f"反幂迭代 (σ={sigma}): λ = {lam:.12f} ({len(hist)} 步)")
print(f"精确特征值: {np.sort(np.linalg.eigvalsh(A))}")
QR 算法
QR 算法是计算矩阵全部特征值的标准方法，被誉为"20 世纪十大算法"之一。算法的基本形式极其简洁：反复对矩阵做 QR 分解 Ak=QkRkA_k = Q_k R_kAk​=Qk​Rk​，然后反序相乘 Ak+1=RkQkA_{k+1} = R_k Q_kAk+1​=Rk​Qk​。序列 AkA_kAk​ 收敛到上三角矩阵（一般矩阵）或对角矩阵（对称矩阵），对角线上的元素就是特征值。


import numpy as np

def basic_qr_algorithm(A, max_iter=100):
    n = A.shape[0]
    Ak = A.astype(np.float64).copy()
    history = []

    for k in range(max_iter):
        Q, R = np.linalg.qr(Ak)
        Ak = R @ Q
        off_diag = np.sqrt(np.sum(np.tril(Ak, -1)**2))
        history.append(off_diag)
        if off_diag < 1e-14:
            break

    return np.diag(Ak), history

A = np.array([[4, 1, 0, 0],
              [1, 3, 1, 0],
              [0, 1, 2, 1],
              [0, 0, 1, 1]], dtype=np.float64)

eigenvalues, hist = basic_qr_algorithm(A)
exact = np.sort(np.linalg.eigvalsh(A))[::-1]
print(f"QR 算法: {np.sort(eigenvalues)[::-1]}")
print(f"精确值: {exact}")
print(f"迭代次数: {len(hist)}")
实用的 QR 算法包含三个关键加速技术：Hessenberg 预化简将每步 QR 分解从 O(n3)O(n^3)O(n3) 降至 O(n2)O(n^2)O(n2)；位移策略（通常使用 Wilkinson 位移）加速收敛；隐式 QR 步避免显式构造 QR 分解。

对称矩阵的特征值算法
对称矩阵的特征值问题具有特殊的优良性质：所有特征值都是实数，特征向量构成正交基。这些性质使得对称矩阵的特征值算法比一般矩阵高效得多。


对称矩阵的标准处理流程是先通过 Householder 变换将矩阵化简为三对角形式（O(n3)O(n^3)O(n3) 但只需一次），然后用专门的三对角矩阵特征值算法。


import numpy as np

def tridiagonalize(A):
    n = A.shape[0]
    T = A.astype(np.float64).copy()
    Q = np.eye(n)

    for k in range(n - 2):
        x = T[k+1:, k].copy()
        alpha = -np.sign(x[0]) * np.linalg.norm(x)
        e1 = np.zeros_like(x)
        e1[0] = 1.0
        v = x - alpha * e1
        if np.linalg.norm(v) < 1e-14:
            continue
        v = v / np.linalg.norm(v)

        T[k+1:, k:] -= 2 * np.outer(v, v @ T[k+1:, k:])
        T[:, k+1:] -= 2 * np.outer(T[:, k+1:] @ v, v)
        Q[:, k+1:] -= 2 * np.outer(Q[:, k+1:] @ v, v)

    return T, Q

A = np.array([[4, 1, 2, 0],
              [1, 3, 0, 1],
              [2, 0, 2, 1],
              [0, 1, 1, 5]], dtype=np.float64)

T, Q = tridiagonalize(A)
print(f"三对角矩阵对角线: {np.diag(T)}")
print(f"三对角矩阵次对角线: {np.diag(T, 1)}")
print(f"正交性: ||Q^TQ - I|| = {np.linalg.norm(Q.T @ Q - np.eye(4)):.2e}")
print(f"精确特征值: {np.sort(np.linalg.eigvalsh(A))}")
三对角矩阵可以用二分法（bisection）精确定位每个特征值的区间，结合 Sturm 序列计数确定区间内的特征值个数，实现高精度计算：


import numpy as np

def sturm_count(diag, off_diag, mu):
    n = len(diag)
    count = 0
    d = diag[0] - mu
    if d < 0:
        count += 1
    for i in range(1, n):
        if abs(d) < 1e-30:
            d = 1e-30
        d = diag[i] - mu - off_diag[i-1]**2 / d
        if d < 0:
            count += 1
    return count

diag = np.array([4.0, 3.0, 2.0, 1.0])
off_diag = np.array([1.0, 1.0, 1.0])

print(f"μ=0 以下的特征值个数: {sturm_count(diag, off_diag, 0)}")
print(f"μ=3 以下的特征值个数: {sturm_count(diag, off_diag, 3)}")
print(f"μ=5 以下的特征值个数: {sturm_count(diag, off_diag, 5)}")

T = np.diag(diag) + np.diag(off_diag, 1) + np.diag(off_diag, -1)
print(f"精确特征值: {np.sort(np.linalg.eigvalsh(T))}")
Krylov 子空间方法
当矩阵规模极大（n>104n > 10^4n>104）且只需要少量极端特征值时，Krylov 子空间方法是唯一可行的选择。Lanczos 算法（对称矩阵）和 Arnoldi 算法（一般矩阵）是两种基本的 Krylov 特征值方法。


Lanczos 算法利用对称矩阵的性质，通过短递推关系构造正交基，将大矩阵的特征值问题投影到小的三对角矩阵上：


import numpy as np

def lanczos(A, k, v0=None):
    n = A.shape[0]
    V = np.zeros((n, k + 1))
    alpha = np.zeros(k)
    beta = np.zeros(k)

    v = np.random.randn(n) if v0 is None else v0.copy()
    v = v / np.linalg.norm(v)
    V[:, 0] = v

    w = A @ v
    alpha[0] = w @ v
    w = w - alpha[0] * v
    beta[0] = np.linalg.norm(w)

    for j in range(1, k):
        if beta[j-1] < 1e-14:
            break
        V[:, j] = w / beta[j-1]
        w = A @ V[:, j]
        alpha[j] = w @ V[:, j]
        w = w - alpha[j] * V[:, j] - beta[j-1] * V[:, j-1]

        for i in range(j + 1):
            w -= (w @ V[:, i]) * V[:, i]

        beta[j] = np.linalg.norm(w)

    T = np.diag(alpha) + np.diag(beta[:k-1], 1) + np.diag(beta[:k-1], -1)
    return T, V[:, :k]

n = 500
A = np.random.randn(n, n)
A = A + A.T

k = 30
T, V = lanczos(A, k)
lanczos_eigs = np.sort(np.linalg.eigvalsh(T))
exact_eigs = np.sort(np.linalg.eigvalsh(A))

print(f"最大 5 个特征值比较:")
print(f"  Lanczos ({k} 步): {lanczos_eigs[-5:][::-1]}")
print(f"  精确值:          {exact_eigs[-5:][::-1]}")
小结
    

  • 特征值问题是数值线性代数的核心，现代算法全部采用迭代方法而非直接求特征多项式的根
    • 

  • 幂迭代和反幂迭代是最基本的特征值算法，收敛速度由特征值间距决定
    • 

  • QR 算法是计算全部特征值的标准方法，Hessenberg 预化简和位移策略是实用化的关键
    • 

  • 对称矩阵的特征值算法利用三对角化简和 Sturm 序列实现高效精确计算
    • 

  • Lanczos 和 Arnoldi 算法通过 Krylov 子空间投影处理大规模稀疏矩阵的部分特征值问题
    • 

  • 算法选择取决于矩阵的对称性、规模、稀疏性以及需要计算的特征值数量
