迭代求解法

核心概念

迭代求解法从一个初始猜测出发，通过反复应用迭代格式逐步逼近线性方程组 Ax=bAx = bAx=b 的精确解。与直接法的 O(n3)O(n^3)O(n3) 复杂度不同，迭代法每步仅需 O(n2)O(n^2)O(n2)（稠密矩阵）或 O(nnz)O(\text{nnz})O(nnz)（稀疏矩阵）的计算量，在大规模稀疏系统中具有明显优势。

迭代法的核心思想是将 Ax=bAx = bAx=b 改写为不动点形式 x=Gx+cx = Gx + cx=Gx+c，其中 GGG 是迭代矩阵。从初始向量 x(0)x^{(0)}x(0) 出发，反复执行 x(k+1)=Gx(k)+cx^{(k+1)} = Gx^{(k)} + cx(k+1)=Gx(k)+c，当 GGG 的谱半径 ρ(G)<1\rho(G) < 1ρ(G)<1 时，迭代序列收敛到唯一不动点。

Jacobi 与 Gauss-Seidel 迭代
Jacobi 迭代是最简单的定常迭代法。它将矩阵 AAA 分裂为对角部分 DDD 和非对角部分 L+UL + UL+U，迭代格式为 x(k+1)=D−1(b−(L+U)x(k))x^{(k+1)} = D^{-1}(b - (L+U)x^{(k)})x(k+1)=D−1(b−(L+U)x(k))。每个分量的更新只使用上一步的值，因此可以完全并行化。


Gauss-Seidel 迭代改进了 Jacobi 方法——在计算第 iii 个分量时，使用当前迭代中已经更新的分量值，而不是上一步的旧值。这种"立即使用最新信息"的策略通常使收敛速度加倍。


import numpy as np

def jacobi(A, b, x0=None, tol=1e-10, max_iter=1000):
    n = len(b)
    x = np.zeros(n) if x0 is None else x0.copy()
    D_inv = 1.0 / np.diag(A)
    R = A - np.diag(np.diag(A))
    history = []

    for k in range(max_iter):
        x_new = D_inv * (b - R @ x)
        rel_err = np.linalg.norm(x_new - x) / (np.linalg.norm(x_new) + 1e-30)
        history.append(rel_err)
        if rel_err < tol:
            return x_new, history
        x = x_new

    return x, history

def gauss_seidel(A, b, x0=None, tol=1e-10, max_iter=1000):
    n = len(b)
    x = np.zeros(n) if x0 is None else x0.copy()
    history = []

    for k in range(max_iter):
        x_old = x.copy()
        for i in range(n):
            sigma = A[i, :i] @ x[:i] + A[i, i+1:] @ x_old[i+1:]
            x[i] = (b[i] - sigma) / A[i, i]
        rel_err = np.linalg.norm(x - x_old) / (np.linalg.norm(x) + 1e-30)
        history.append(rel_err)
        if rel_err < tol:
            return x, history
        x_old = x.copy()

    return x, history

A = np.random.randn(n, n)
A = A.T @ A + 10 * np.eye(n)

SOR 松弛方法
逐次超松弛法（SOR, Successive Over-Relaxation）在 Gauss-Seidel 迭代的基础上引入松弛因子 ω\omegaω，通过对新旧迭代值进行加权平均来加速收敛：xi(k+1)=(1−ω)xi(k)+ω⋅xiGSx_i^{(k+1)} = (1-\omega)x_i^{(k)} + \omega \cdot x_i^{GS}xi(k+1)​=(1−ω)xi(k)​+ω⋅xiGS​。


当 ω=1\omega = 1ω=1 时退化为 Gauss-Seidel 方法，1<ω<21 < \omega < 21<ω<2 为超松弛（加速收敛），0<ω<10 < \omega < 10<ω<1 为欠松弛（提高稳定性）。对于对称正定三对角矩阵，最优松弛因子可以精确计算。


import numpy as np

def sor(A, b, omega, x0=None, tol=1e-10, max_iter=1000):
    n = len(b)
    x = np.zeros(n) if x0 is None else x0.copy()
    history = []

    for k in range(max_iter):
        x_old = x.copy()
        for i in range(n):
            sigma = A[i, :i] @ x[:i] + A[i, i+1:] @ x_old[i+1:]
            x_gs = (b[i] - sigma) / A[i, i]
            x[i] = (1 - omega) * x_old[i] + omega * x_gs
        rel_err = np.linalg.norm(x - x_old) / (np.linalg.norm(x) + 1e-30)
        history.append(rel_err)
        if rel_err < tol:
            return x, history

    return x, history

n = 100
h = 1.0 / (n + 1)
A = np.zeros((n, n))
for i in range(n):
    A[i, i] = 2.0
    if i > 0:
        A[i, i-1] = -1.0
    if i < n-1:
        A[i, i+1] = -1.0
b = h**2 * np.ones(n)

rho_jacobi = np.cos(np.pi * h)
omega_opt = 2.0 / (1.0 + np.sqrt(1.0 - rho_jacobi**2))
print(f"Jacobi 谱半径: {rho_jacobi:.6f}")
print(f"最优 omega: {omega_opt:.6f}")

for omega in [0.8, 1.0, omega_opt, 1.5, 1.9]:
    _, hist = sor(A, b, omega)
    print(f"omega={omega:.4f}: {len(hist):4d} 次迭代")

共轭梯度法
共轭梯度法（CG, Conjugate Gradient）是求解对称正定方程组的最优 Krylov 子空间方法。它在理论上至多 nnn 步精确收敛，但在实践中通常远少于 nnn 步就能达到足够的精度。


CG 方法的核心思想是：将求解 Ax=bAx = bAx=b 转化为最小化二次函数 ϕ(x)=12xTAx−bTx\phi(x) = \frac{1}{2}x^TAx - b^Txϕ(x)=21​xTAx−bTx，然后在一系列关于 AAA 共轭的方向上依次做精确线搜索。共轭方向保证了每步的搜索都是最优的，不会破坏之前步骤的进展。


import numpy as np

def conjugate_gradient(A, b, x0=None, tol=1e-10, max_iter=None):
    n = len(b)
    if max_iter is None:
        max_iter = 2 * n
    x = np.zeros(n) if x0 is None else x0.copy()
    r = b - A @ x
    p = r.copy()
    rs_old = r @ r
    history = [np.sqrt(rs_old)]

    for k in range(max_iter):
        Ap = A @ p
        alpha = rs_old / (p @ Ap)
        x = x + alpha * p
        r = r - alpha * Ap
        rs_new = r @ r
        history.append(np.sqrt(rs_new))

        if np.sqrt(rs_new) < tol * history[0]:
            return x, history
        p = r + (rs_new / rs_old) * p
        rs_old = rs_new

    return x, history

CG 方法的收敛速度由矩阵的条件数 κ(A)\kappa(A)κ(A) 决定：经过 kkk 步迭代后，误差的上界为初始误差的 2(κ−1κ+1)k2(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1})^k2(κ​+1κ​−1​)k 倍。条件数越小，收敛越快。


GMRES 与非对称方程组
对于一般的非对称方程组，共轭梯度法不再适用。广义最小残差法（GMRES, Generalized Minimum Residual）是处理非对称方程组的标准 Krylov 子空间方法。


GMRES 在 Krylov 子空间 Kk=span{r0,Ar0,A2r0,…,Ak−1r0}\mathcal{K}_k = \text{span}\{r_0, Ar_0, A^2r_0, \ldots, A^{k-1}r_0\}Kk​=span{r0​,Ar0​,A2r0​,…,Ak−1r0​} 中寻找使残差范数最小的近似解。它通过 Arnoldi 过程构造正交基，然后求解一个小规模的最小二乘问题。


import numpy as np

def gmres(A, b, x0=None, tol=1e-10, max_iter=None):
    n = len(b)
    if max_iter is None:
        max_iter = min(n, 100)
    x = np.zeros(n) if x0 is None else x0.copy()
    r = b - A @ x
    beta = np.linalg.norm(r)
    history = [beta]

    if beta < tol:
        return x, history

    V = np.zeros((n, max_iter + 1))
    H = np.zeros((max_iter + 1, max_iter))
    V[:, 0] = r / beta

    for k in range(max_iter):
        w = A @ V[:, k]
        for j in range(k + 1):
            H[j, k] = V[:, j] @ w
            w -= H[j, k] * V[:, j]
        H[k + 1, k] = np.linalg.norm(w)

        if H[k + 1, k] < 1e-14:
            break
        V[:, k + 1] = w / H[k + 1, k]

        e1 = np.zeros(k + 2)
        e1[0] = beta
        y, _, _, _ = np.linalg.lstsq(H[:k+2, :k+1], e1, rcond=None)
        res = np.linalg.norm(H[:k+2, :k+1] @ y - e1)
        history.append(res)

        if res < tol * history[0]:
            x = x + V[:, :k+1] @ y
            return x, history

    y, _, _, _ = np.linalg.lstsq(H[:k+2, :k+1], e1, rcond=None)
    x = x + V[:, :k+1] @ y
    return x, history

A = np.random.randn(n, n) + 5 * np.eye(n)
x_true = np.random.randn(n)
b = A @ x_true

x_gm, hist_gm = gmres(A, b)
print(f"GMRES: {len(hist_gm)-1} 次迭代")
print(f"相对残差: {hist_gm[-1] / hist_gm[0]:.2e}")
print(f"前向误差: {np.linalg.norm(x_gm - x_true) / np.linalg.norm(x_true):.2e}")

小结
    

  • 迭代法通过反复迭代逼近精确解，在大规模稀疏系统中比直接法更高效
    • 

  • Jacobi 和 Gauss-Seidel 是最基本的定常迭代法，收敛条件是谱半径小于 1
    • 

  • SOR 通过松弛因子加速收敛，最优参数可以对特定矩阵结构精确计算
    • 

  • 共轭梯度法是对称正定方程组的最优 Krylov 方法，收敛速度由条件数决定
    • 

  • GMRES 是非对称方程组的标准方法，但存储需求随迭代增长
    • 

  • 实践中预条件技术是加速迭代法收敛的关键，好的预条件子能大幅减少迭代次数
    •
