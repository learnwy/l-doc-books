插值方法

核心概念

插值是数值分析中最基本的工具之一，其目标是根据已知的离散数据点 (x0,y0),(x1,y1),…,(xn,yn)(x_0, y_0), (x_1, y_1), \ldots, (x_n, y_n)(x0​,y0​),(x1​,y1​),…,(xn​,yn​) 构造一个函数 p(x)p(x)p(x)，使得 p(xi)=yip(x_i) = y_ip(xi​)=yi​ 对所有数据点成立。插值广泛应用于数据拟合、数值积分、微分方程数值解以及计算机图形学中。

插值问题的核心挑战在于平衡精度与稳定性：节点越多，多项式次数越高，理论上近似精度越高，但 Runge 现象表明高次多项式插值可能在区间端点附近产生剧烈振荡。这一矛盾推动了从全局多项式插值到分段插值（特别是样条插值）的发展。

Lagrange 插值与基函数
Lagrange 插值的核心思想是构造一组基函数 ℓi(x)\ell_i(x)ℓi​(x)，使得 ℓi(xj)=δij\ell_i(x_j) = \delta_{ij}ℓi​(xj​)=δij​（在第 iii 个节点取 1，在其他节点取 0）。插值多项式就是 p(x)=∑i=0nyiℓi(x)p(x) = \sum_{i=0}^{n} y_i \ell_i(x)p(x)=∑i=0n​yi​ℓi​(x)。每个基函数的构造利用了节点处的零点条件：


ℓi(x)=∏j≠ix−xjxi−xj\ell_i(x) = \prod_{j \neq i} \frac{x - x_j}{x_i - x_j}ℓi​(x)=j=i∏​xi​−xj​x−xj​​
Lagrange 形式的优点是结构清晰、便于理论分析，但每次增加新节点时需要重新计算所有基函数，不适合增量场景。


import numpy as np
import matplotlib.pyplot as plt

def lagrange_basis(x_nodes, i, x):
    n = len(x_nodes)
    basis = np.ones_like(x, dtype=np.float64)
    for j in range(n):
        if j != i:
            basis *= (x - x_nodes[j]) / (x_nodes[i] - x_nodes[j])
    return basis

def lagrange_interpolation(x_nodes, y_nodes, x):
    result = np.zeros_like(x, dtype=np.float64)
    for i in range(len(x_nodes)):
        result += y_nodes[i] * lagrange_basis(x_nodes, i, x)
    return result

x_nodes = np.array([0, 1, 2, 3, 4], dtype=np.float64)
y_nodes = np.sin(x_nodes)
x_eval = np.linspace(0, 4, 200)

y_interp = lagrange_interpolation(x_nodes, y_nodes, x_eval)
y_exact = np.sin(x_eval)

max_error = np.max(np.abs(y_interp - y_exact))
print(f"5 节点 Lagrange 插值最大误差: {max_error:.6e}")

这个公式揭示了两个关键因素：被插函数的光滑性 f(n+1)f^{(n+1)}f(n+1) 以及节点分布对误差乘积 ∏∣x−xi∣\prod |x - x_i|∏∣x−xi​∣ 的影响。


Newton 差商插值
Newton 插值采用递推结构，使用差商（divided differences）构造插值多项式。其核心优势是增量性：当新增一个数据点时，只需在已有多项式上追加一项，不必从头计算。


kkk 阶差商的递推定义为：


f[xi,xi+1,…,xi+k]=f[xi+1,…,xi+k]−f[xi,…,xi+k−1]xi+k−xif[x_i, x_{i+1}, \ldots, x_{i+k}] = \frac{f[x_{i+1}, \ldots, x_{i+k}] - f[x_i, \ldots, x_{i+k-1}]}{x_{i+k} - x_i}f[xi​,xi+1​,…,xi+k​]=xi+k​−xi​f[xi+1​,…,xi+k​]−f[xi​,…,xi+k−1​]​
Newton 插值多项式的形式为：


pn(x)=f[x0]+f[x0,x1](x−x0)+f[x0,x1,x2](x−x0)(x−x1)+⋯p_n(x) = f[x_0] + f[x_0, x_1](x - x_0) + f[x_0, x_1, x_2](x - x_0)(x - x_1) + \cdotspn​(x)=f[x0​]+f[x0​,x1​](x−x0​)+f[x0​,x1​,x2​](x−x0​)(x−x1​)+⋯
import numpy as np

def divided_differences(x_nodes, y_nodes):
    n = len(x_nodes)
    table = np.zeros((n, n))
    table[:, 0] = y_nodes

    for j in range(1, n):
        for i in range(n - j):
            table[i, j] = (table[i + 1, j - 1] - table[i, j - 1]) / (x_nodes[i + j] - x_nodes[i])

    return table[0]

def newton_interpolation(x_nodes, coeffs, x):
    n = len(coeffs)
    result = coeffs[-1] * np.ones_like(x, dtype=np.float64)
    for i in range(n - 2, -1, -1):
        result = result * (x - x_nodes[i]) + coeffs[i]
    return result

x_nodes = np.array([0.0, 0.5, 1.0, 1.5, 2.0])
y_nodes = np.exp(x_nodes)

coeffs = divided_differences(x_nodes, y_nodes)
print("差商系数:", coeffs)

x_test = np.array([0.25, 0.75, 1.25, 1.75])
y_newton = newton_interpolation(x_nodes, coeffs, x_test)
y_exact = np.exp(x_test)
print(f"最大误差: {np.max(np.abs(y_newton - y_exact)):.6e}")

x_new = 2.5
y_new = np.exp(x_new)
x_ext = np.append(x_nodes, x_new)
y_ext = np.append(y_nodes, y_new)
coeffs_ext = divided_differences(x_ext, y_ext)
print(f"增量扩展后新系数: {coeffs_ext[-1]:.6e}")
差商具有对称性——差商的值与节点的排列顺序无关。这一性质在理论分析中非常有用，也意味着差商本质上度量的是函数在节点集上的"平均变化率"。


Runge 现象与 Chebyshev 节点
Runge 现象是高次多项式插值的核心障碍。以经典的 Runge 函数 f(x)=11+25x2f(x) = \frac{1}{1+25x^2}f(x)=1+25x21​ 为例，在 [−1,1][-1,1][−1,1] 上等距节点插值时，随着节点数增加，插值误差在端点附近不减反增，产生剧烈振荡。


import numpy as np

def runge_function(x):
    return 1 / (1 + 25 * x**2)

for n in [5, 10, 15, 20]:
    x_uniform = np.linspace(-1, 1, n + 1)
    y_uniform = runge_function(x_uniform)

    x_cheb = np.cos(np.pi * np.arange(n + 1) / n)
    y_cheb = runge_function(x_cheb)

    x_eval = np.linspace(-1, 1, 1000)
    y_exact = runge_function(x_eval)

    coeffs_uniform = divided_differences(x_uniform, y_uniform)
    y_uniform_interp = newton_interpolation(x_uniform, coeffs_uniform, x_eval)
    err_uniform = np.max(np.abs(y_uniform_interp - y_exact))

    coeffs_cheb = divided_differences(x_cheb, y_cheb)
    y_cheb_interp = newton_interpolation(x_cheb, coeffs_cheb, x_eval)
    err_cheb = np.max(np.abs(y_cheb_interp - y_exact))

    print(f"n={n:2d}  等距误差: {err_uniform:.4e}  Chebyshev 误差: {err_cheb:.4e}")
Chebyshev 节点 xk=cos⁡(kπn)x_k = \cos\left(\frac{k\pi}{n}\right)xk​=cos(nkπ​) 是 [−1,1][-1,1][−1,1] 上使节点多项式 ∏(x−xi)\prod(x - x_i)∏(x−xi​) 的最大值最小化的最优分布。它们在端点处密集、中间稀疏，有效抑制了 Runge 现象。

三次样条插值
三次样条插值是工程实践中最常用的插值方法。它在每个子区间 [xi,xi+1][x_i, x_{i+1}][xi​,xi+1​] 上用三次多项式 Si(x)S_i(x)Si​(x) 逼近，同时要求整体函数在节点处满足 C2C^2C2 连续性（函数值、一阶导数、二阶导数均连续）。


在 n+1n+1n+1 个节点上，有 nnn 段三次多项式共 4n4n4n 个未知系数。插值条件提供 n+1n+1n+1 个方程，内部节点的 C2C^2C2 连续性提供 3(n−1)3(n-1)3(n−1) 个方程，共 4n−24n-24n−2 个方程，还需要 2 个边界条件。常见的边界条件包括：自然边界（S′′(x0)=S′′(xn)=0S''(x_0) = S''(x_n) = 0S′′(x0​)=S′′(xn​)=0）、固定边界（给定端点导数值）、周期边界等。


import numpy as np

def natural_cubic_spline(x, y):
    n = len(x) - 1
    h = np.diff(x)

    alpha = np.zeros(n + 1)
    for i in range(1, n):
        alpha[i] = 3/h[i] * (y[i+1] - y[i]) - 3/h[i-1] * (y[i] - y[i-1])

    l = np.ones(n + 1)
    mu = np.zeros(n + 1)
    z = np.zeros(n + 1)

    for i in range(1, n):
        l[i] = 2*(x[i+1] - x[i-1]) - h[i-1]*mu[i-1]
        mu[i] = h[i] / l[i]
        z[i] = (alpha[i] - h[i-1]*z[i-1]) / l[i]

    c = np.zeros(n + 1)
    b = np.zeros(n)
    d = np.zeros(n)

    for j in range(n - 1, -1, -1):
        c[j] = z[j] - mu[j]*c[j+1]
        b[j] = (y[j+1] - y[j])/h[j] - h[j]*(c[j+1] + 2*c[j])/3
        d[j] = (c[j+1] - c[j]) / (3*h[j])

    return y[:n], b, c[:n], d

def evaluate_spline(x_nodes, a, b, c, d, x_eval):
    result = np.zeros_like(x_eval)
    for k, xv in enumerate(x_eval):
        i = np.searchsorted(x_nodes[1:], xv, side='right')
        i = min(i, len(a) - 1)
        dx = xv - x_nodes[i]
        result[k] = a[i] + b[i]*dx + c[i]*dx**2 + d[i]*dx**3
    return result

x = np.array([0, 1, 2, 3, 4, 5], dtype=np.float64)
y = np.sin(x)

a, b, c, d = natural_cubic_spline(x, y)
x_eval = np.linspace(0, 5, 200)
y_spline = evaluate_spline(x, a, b, c, d, x_eval)
y_exact = np.sin(x_eval)

print(f"自然三次样条最大误差: {np.max(np.abs(y_spline - y_exact)):.6e}")
三次样条的误差阶为 O(h4)O(h^4)O(h4)，其中 hhh 是最大子区间长度。这意味着节点数翻倍时，误差缩小约 16 倍。同时，三次样条具有最小弯曲能量性质——在所有通过给定节点的 C2C^2C2 函数中，自然三次样条的二阶导数积分 ∫[S′′(x)]2dx\int [S''(x)]^2 dx∫[S′′(x)]2dx 最小。

小结
    

  • Lagrange 插值通过构造正交基函数实现，结构清晰但不适合增量计算
    • 

  • Newton 差商形式支持增量添加节点，适合在线或自适应场景
    • 

  • Runge 现象是高次等距多项式插值的本质障碍，Chebyshev 节点可有效抑制
    • 

  • 三次样条插值以 O(h4)O(h^4)O(h4) 精度和 C2C^2C2 连续性成为工程实践中的首选方法
    • 

  • 样条的三对角方程组可用 Thomas 算法在 O(n)O(n)O(n) 时间内求解
    • 

  • 选择插值方法需权衡精度、稳定性、光滑性和计算效率
