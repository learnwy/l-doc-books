求积公式

核心概念

数值积分（求积）是用离散点处的函数值加权求和来近似定积分 ∫abf(x)dx\int_a^b f(x) dx∫ab​f(x)dx 的方法。与数值微分相比，数值积分具有天然的稳定性——积分是平滑算子，微小的函数值扰动不会被放大。这使得数值积分在实际计算中更加可靠。

求积公式的一般形式为 ∫abf(x)dx≈∑i=0nwif(xi)\int_a^b f(x) dx \approx \sum_{i=0}^{n} w_i f(x_i)∫ab​f(x)dx≈∑i=0n​wi​f(xi​)，其中 xix_ixi​ 是求积节点，wiw_iwi​ 是对应权重。不同的求积公式在节点选取和权重确定上各有策略：Newton-Cotes 公式使用等距节点，Gauss 求积选择使精度最优的特殊节点，两者代表了数值积分中"简单实用"与"理论最优"的两条路线。

Newton-Cotes 公式族
Newton-Cotes 公式在 [a,b][a,b][a,b] 上取 n+1n+1n+1 个等距节点 xi=a+ihx_i = a + ihxi​=a+ih（h=(b−a)/nh = (b-a)/nh=(b−a)/n），用通过这些节点的 nnn 次插值多项式的积分作为原积分的近似。


当 n=1n=1n=1 时得到梯形公式 ∫abf(x)dx≈h2[f(a)+f(b)]\int_a^b f(x)dx \approx \frac{h}{2}[f(a) + f(b)]∫ab​f(x)dx≈2h​[f(a)+f(b)]，几何意义是用梯形面积近似曲线下面积。当 n=2n=2n=2 时得到 Simpson 公式 ∫abf(x)dx≈h3[f(a)+4f(m)+f(b)]\int_a^b f(x)dx \approx \frac{h}{3}[f(a) + 4f(m) + f(b)]∫ab​f(x)dx≈3h​[f(a)+4f(m)+f(b)]，其中 m=(a+b)/2m = (a+b)/2m=(a+b)/2，使用抛物线逼近。


import numpy as np

def trapezoid_single(f, a, b):
    return (b - a) / 2 * (f(a) + f(b))

def simpson_single(f, a, b):
    m = (a + b) / 2
    return (b - a) / 6 * (f(a) + 4*f(m) + f(b))

def simpson38_single(f, a, b):
    h = (b - a) / 3
    return (b - a) / 8 * (f(a) + 3*f(a + h) + 3*f(a + 2*h) + f(b))

def boole_single(f, a, b):
    h = (b - a) / 4
    return (b - a) / 90 * (7*f(a) + 32*f(a+h) + 12*f(a+2*h) + 32*f(a+3*h) + 7*f(b))

f = lambda x: np.exp(-x**2)
a, b = 0, 1
from scipy.integrate import quad
exact, _ = quad(f, a, b)

methods = {
    "梯形公式": trapezoid_single(f, a, b),
    "Simpson 公式": simpson_single(f, a, b),
    "Simpson 3/8 公式": simpson38_single(f, a, b),
    "Boole 公式": boole_single(f, a, b),
}

for name, val in methods.items():
    err = abs(val - exact)
    print(f"{name}: {val:.10f}, 误差 = {err:.2e}")
Newton-Cotes 公式的权重可以通过积分 Lagrange 基函数获得：wi=∫abℓi(x)dxw_i = \int_a^b \ell_i(x) dxwi​=∫ab​ℓi​(x)dx。当 n≥8n \geq 8n≥8 时，等距 Newton-Cotes 公式出现负权重，导致数值不稳定，这与插值中的 Runge 现象同源。因此实际中很少使用高阶 Newton-Cotes 公式，而是采用复合策略。


复合求积公式
复合求积的思想是将积分区间 [a,b][a,b][a,b] 分成 NNN 个小区间，在每个小区间上应用低阶求积公式，然后求和。这避免了高阶公式的不稳定性，同时通过增加子区间数来提高精度。


import numpy as np

def composite_trapezoid(f, a, b, N):
    h = (b - a) / N
    x = np.linspace(a, b, N + 1)
    y = f(x)
    return h * (y[0]/2 + np.sum(y[1:-1]) + y[-1]/2)

def composite_simpson(f, a, b, N):
    if N % 2 != 0:
        N += 1
    h = (b - a) / N
    x = np.linspace(a, b, N + 1)
    y = f(x)
    return h/3 * (y[0] + 4*np.sum(y[1::2]) + 2*np.sum(y[2:-1:2]) + y[-1])

f = lambda x: np.exp(-x**2)
a, b = 0, 1
from scipy.integrate import quad
exact, _ = quad(f, a, b)

print(f"{'N':<8} {'梯形误差':<15} {'Simpson误差':<15} {'梯形收敛阶':<12} {'Simpson收敛阶':<12}")
prev_trap = prev_simp = None
for N in [4, 8, 16, 32, 64, 128, 256]:
    err_trap = abs(composite_trapezoid(f, a, b, N) - exact)
    err_simp = abs(composite_simpson(f, a, b, N) - exact)

    rate_trap = "" if prev_trap is None else f"{np.log2(prev_trap/err_trap):.2f}"
    rate_simp = "" if prev_simp is None else f"{np.log2(prev_simp/err_simp):.2f}"

    print(f"{N:<8} {err_trap:<15.2e} {err_simp:<15.2e} {rate_trap:<12} {rate_simp:<12}")
    prev_trap, prev_simp = err_trap, err_simp
复合梯形公式的误差为 −(b−a)h212f′′(ξ)-\frac{(b-a)h^2}{12}f''(\xi)−12(b−a)h2​f′′(ξ)，复合 Simpson 公式的误差为 −(b−a)h4180f(4)(ξ)-\frac{(b-a)h^4}{180}f^{(4)}(\xi)−180(b−a)h4​f(4)(ξ)，收敛阶分别为 2 和 4。这意味着 Simpson 公式在步长减半时误差缩小约 16 倍，效率显著高于梯形公式。


Gauss 求积法
Gauss 求积是数值积分理论中的精华。其核心思想是：既然节点位置和权重都是自由变量，为什么不同时优化两者使精度最大化？nnn 个 Gauss 节点的求积公式能精确积分所有次数 ≤2n−1\leq 2n-1≤2n−1 的多项式，这是 nnn 点求积公式所能达到的理论上限。


Gauss-Legendre 求积在标准区间 [−1,1][-1,1][−1,1] 上进行，节点是 nnn 次 Legendre 多项式 Pn(x)P_n(x)Pn​(x) 的零点。对于一般区间 [a,b][a,b][a,b]，通过线性变换 x=b−a2t+a+b2x = \frac{b-a}{2}t + \frac{a+b}{2}x=2b−a​t+2a+b​ 映射到 [−1,1][-1,1][−1,1]。


import numpy as np

def gauss_legendre_nodes_weights(n):
    beta = np.array([i / np.sqrt(4*i**2 - 1) for i in range(1, n)])
    T = np.diag(beta, 1) + np.diag(beta, -1)
    nodes, V = np.linalg.eigh(T)
    weights = 2 * V[0, :]**2
    return nodes, weights

def gauss_quadrature(f, a, b, n):
    nodes, weights = gauss_legendre_nodes_weights(n)
    mapped_nodes = (b - a) / 2 * nodes + (a + b) / 2
    return (b - a) / 2 * np.sum(weights * f(mapped_nodes))

f = lambda x: np.exp(-x**2)
a, b = 0, 1
from scipy.integrate import quad
exact, _ = quad(f, a, b)

print(f"Gauss-Legendre 求积精度:")
print(f"{'节点数':<8} {'近似值':<20} {'误差':<15} {'代数精度':<10}")
for n in range(1, 11):
    val = gauss_quadrature(f, a, b, n)
    err = abs(val - exact)
    print(f"{n:<8} {val:<20.15f} {err:<15.2e} {2*n-1:<10}")

print("\n多项式精确性验证:")
for n in [3, 4, 5]:
    nodes, weights = gauss_legendre_nodes_weights(n)
    for deg in range(2*n - 1, 2*n + 2):
        f_poly = lambda x, d=deg: x**d
        exact_val = 2 / (deg + 1) if deg % 2 == 0 else 0
        approx = np.sum(weights * f_poly(nodes))
        match = "✓" if abs(approx - exact_val) < 1e-12 else "✗"
        print(f"  n={n}, deg={deg}: 近似={approx:.6e}, 精确={exact_val:.6e} {match}")

Romberg 积分
Romberg 积分将 Richardson 外推技术应用于复合梯形公式，系统地提高积分精度。其理论基础是 Euler-Maclaurin 展开：复合梯形公式的误差可以展开为 h2h^2h2 的幂级数。


通过逐步将步长减半并外推消去低阶误差项，Romberg 积分可以达到任意高精度。第一级外推等价于 Simpson 公式，第二级外推等价于 Boole 公式，高级外推产生更高阶的求积公式。


import numpy as np

def romberg_integration(f, a, b, max_level):
    R = np.zeros((max_level, max_level))

    h = b - a
    R[0, 0] = h / 2 * (f(a) + f(b))

    for i in range(1, max_level):
        h = (b - a) / 2**i
        new_points = np.array([a + (2*k - 1)*h for k in range(1, 2**(i-1) + 1)])
        R[i, 0] = R[i-1, 0] / 2 + h * np.sum(f(new_points))

        for j in range(1, i + 1):
            R[i, j] = (4**j * R[i, j-1] - R[i-1, j-1]) / (4**j - 1)

    return R

f = lambda x: np.exp(-x**2)
a, b = 0, 1
from scipy.integrate import quad
exact, _ = quad(f, a, b)

R = romberg_integration(f, a, b, 6)

print("Romberg 积分表:")
print(f"{'级别':<6}", end="")
for j in range(6):
    print(f"{'R[·,'+str(j)+']':<18}", end="")
print()

for i in range(6):
    print(f"{i:<6}", end="")
    for j in range(i + 1):
        err = abs(R[i, j] - exact)
        print(f"{R[i,j]:.12f}({err:.0e}) ", end="")
    print()
Romberg 积分的优势在于它可以自动控制精度——当相邻两级外推结果之差小于给定容差时停止计算。这种自适应策略在实际中非常实用。

小结
    

  • Newton-Cotes 公式使用等距节点，梯形和 Simpson 是最常用的低阶公式
    • 

  • 复合求积通过区间细分避免高阶不稳定性，Simpson 复合公式以 O(h4)O(h^4)O(h4) 收敛
    • 

  • Gauss 求积同时优化节点和权重，nnn 点公式达到 2n−12n-12n−1 的最优代数精度
    • 

  • Gauss 节点是对应正交多项式的零点，可通过特征值问题高效计算
    • 

  • Romberg 积分通过 Richardson 外推系统提升复合梯形公式的精度，支持自适应控制
    • 

  • 选择求积公式需综合考虑被积函数的光滑性、积分区间、精度要求和计算预算
    •
