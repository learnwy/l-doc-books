拉格朗日乘数法

核心概念

拉格朗日乘数法（Lagrange Multiplier Method）是处理等式约束优化问题的经典分析工具。给定目标函数 f(x) 和等式约束 g_i(x) = 0，通过引入拉格朗日乘子 λ_i 构造拉格朗日函数 L(x, λ) = f(x) + Σλ_i g_i(x)，将约束优化问题转化为对 L 求驻点的无约束问题。拉格朗日乘子的几何含义是：在最优解处，目标函数的梯度是约束函数梯度的线性组合，即 ∇f = -Σλ_i ∇g_i。

拉格朗日乘数法的核心思想是：在约束曲面上的极值点处，目标函数的等值线必然与约束曲面相切。如果不相切，沿约束曲面移动总能找到更优的方向。这一几何直觉可以推广到高维空间和不等式约束，形成 KKT（Karush-Kuhn-Tucker）条件这一更一般的最优性理论框架。

等式约束与拉格朗日函数
等式约束优化问题的标准形式为：min f(x) s.t. g*i(x) = 0, i = 1, ..., m。拉格朗日函数定义为 L(x, λ) = f(x) + Σλ_i g_i(x)。一阶必要条件要求 ∇_x L = 0 且 ∇*λ L = 0，后者等价于约束本身 g_i(x) = 0。


对于二维问题 min f(x,y) s.t. g(x,y) = 0，拉格朗日条件为三个方程：∂f/∂x + λ ∂g/∂x = 0，∂f/∂y + λ ∂g/∂y = 0，g(x,y) = 0。求解这个方程组即可得到候选极值点和对应的乘子值。


function solveLagrange2D(
  gradF: (x: number, y: number) => [number, number],
  gradG: (x: number, y: number) => [number, number],
  g: (x: number, y: number) => number,
  x0: number,
  y0: number,
  lambda0: number,
  maxIter: number = 200,
  tol: number = 1e-10,
): { x: number; y: number; lambda: number; fVal: number } {
  let x = x0,
    y = y0,
    lam = lambda0;
  const lr = 0.01;

  for (let k = 0; k < maxIter; k++) {
    const [fx, fy] = gradF(x, y);
    const [gx, gy] = gradG(x, y);
    const gVal = g(x, y);

    const rx = fx + lam * gx;
    const ry = fy + lam * gy;

    if (Math.abs(rx) + Math.abs(ry) + Math.abs(gVal) < tol) break;

    x -= lr * rx;
    y -= lr * ry;
    lam += lr * gVal;
  }

  return { x, y, lambda: lam, fVal: x * x + y * y };
}

const gradF = (x: number, y: number): [number, number] => [2 * x, 2 * y];
const gradG = (x: number, y: number): [number, number] => [1, 1];
const g = (x: number, y: number): number => x + y - 1;

const result = solveLagrange2D(gradF, gradG, g, 2, 2, 0);
console.log(`最优解: (${result.x.toFixed(4)}, ${result.y.toFixed(4)}), λ=${result.lambda.toFixed(4)}`);
二阶充分条件通过加边 Hessian 矩阵（Bordered Hessian）来判断。对于一个等式约束的情形，加边 Hessian 为：


| 0    g_x   g_y  |
| g_x  L_xx  L_xy |
| g_y  L_xy  L_yy |
如果这个矩阵的行列式为正，候选点为极小值；为负则为极大值。

KKT 条件与不等式约束
当问题包含不等式约束 h_j(x) ≤ 0 时，拉格朗日乘数法推广为 Karush-Kuhn-Tucker（KKT）条件。KKT 条件包含四组方程：


    

  • 驻点条件（Stationarity）：∇f + Σλ_i ∇g_i + Σμ_j ∇h_j = 0
    • 

  • 原始可行性（Primal Feasibility）：g_i(x) = 0, h_j(x) ≤ 0
    • 

  • 对偶可行性（Dual Feasibility）：μ_j ≥ 0
    • 

  • 互补松弛条件（Complementary Slackness）：μ_j h_j(x) = 0
    • 



互补松弛条件的含义是：对于每个不等式约束，要么约束在最优解处取等号（激活约束），要么对应的乘子为零（非激活约束）。


interface KKTResult {
  x: number[];
  eqMultipliers: number[];
  ineqMultipliers: number[];
  active: boolean[];
  kktViolation: number;
}

function checkKKT(
  gradF: (x: number[]) => number[],
  eqConstraints: { g: (x: number[]) => number; grad: (x: number[]) => number[] }[],
  ineqConstraints: { h: (x: number[]) => number; grad: (x: number[]) => number[] }[],
  x: number[],
  eqLam: number[],
  ineqMu: number[],
  tol: number = 1e-6,
): KKTResult {
  const n = x.length;
  const gf = gradF(x);

  let stationarity = [...gf];
  for (let i = 0; i < eqConstraints.length; i++) {
    const gc = eqConstraints[i].grad(x);
    stationarity = stationarity.map((s, j) => s + eqLam[i] * gc[j]);
  }
  for (let j = 0; j < ineqConstraints.length; j++) {
    const hc = ineqConstraints[j].grad(x);
    stationarity = stationarity.map((s, k) => s + ineqMu[j] * hc[k]);
  }

  const stationarityNorm = Math.sqrt(stationarity.reduce((s, v) => s + v * v, 0));

  const eqViolation = eqConstraints.reduce((sum, c) => sum + Math.abs(c.g(x)), 0);

  const ineqViolation = ineqConstraints.reduce((sum, c) => sum + Math.max(0, c.h(x)), 0);

  const dualViolation = ineqMu.reduce((sum, mu) => sum + Math.max(0, -mu), 0);

  const compSlack = ineqConstraints.reduce((sum, c, j) => sum + Math.abs(ineqMu[j] * c.h(x)), 0);

  const active = ineqConstraints.map((c) => Math.abs(c.h(x)) < tol);

  return {
    x,
    eqMultipliers: eqLam,
    ineqMultipliers: ineqMu,
    active,
    kktViolation: stationarityNorm + eqViolation + ineqViolation + dualViolation + compSlack,
  };
}
对偶理论与强对偶性
拉格朗日对偶问题通过最大化对偶函数 d(λ, μ) = inf_x L(x, λ, μ) 来获得原始问题最优值的下界。弱对偶性（d* ≤ f*）总是成立的；强对偶性（d* = f*）在凸问题满足 Slater 条件（存在严格可行的内点）时成立。


对偶间隙（Duality Gap）δ = f* - d* 衡量原始问题与对偶问题最优值之间的差距。在强对偶性成立时 δ = 0，这意味着可以通过求解对偶问题来间接求解原始问题——当对偶问题更容易求解时，这是一种重要的计算策略。


function lagrangianDual(
  f: (x: number[]) => number,
  constraints: ((x: number[]) => number)[],
  xDomain: { min: number; max: number }[],
  gridSize: number = 50,
): {
  dualValue: number;
  optimalMultipliers: number[];
  dualityGap: (primalOpt: number) => number;
} {
  const n = xDomain.length;
  const m = constraints.length;

  function dualFunction(mu: number[]): number {
    let minVal = Infinity;
    const enumerate = (dim: number, x: number[]): void => {
      if (dim === n) {
        const lagrangian = f(x) + mu.reduce((sum, mi, i) => sum + mi * constraints[i](x), 0);
        if (lagrangian < minVal) minVal = lagrangian;
        return;
      }
      const { min, max } = xDomain[dim];
      for (let i = 0; i <= gridSize; i++) {
        x[dim] = min + ((max - min) * i) / gridSize;
        enumerate(dim + 1, x);
      }
    };
    enumerate(0, new Array(n));
    return minVal;
  }

  let bestDual = -Infinity;
  let bestMu = new Array(m).fill(0);

  const muRange = 10;
  const muSteps = 30;
  const searchMu = (dim: number, current: number[]): void => {
    if (dim === m) {
      const d = dualFunction(current);
      if (d > bestDual) {
        bestDual = d;
        bestMu = [...current];
      }
      return;
    }
    for (let i = 0; i <= muSteps; i++) {
      current[dim] = (muRange * i) / muSteps;
      searchMu(dim + 1, current);
    }
  };
  searchMu(0, new Array(m));

  return {
    dualValue: bestDual,
    optimalMultipliers: bestMu,
    dualityGap: (primalOpt: number) => primalOpt - bestDual,
  };
}

灵敏度分析与经济学解释
拉格朗日乘子具有重要的经济学含义：λ_i 等于约束 g_i 微小放松时目标函数最优值的变化率，即 λ_i = -df*/db_i（当约束为 g_i(x) = b_i 时）。这被称为约束的影子价格（Shadow Price）。


在资源分配问题中，如果约束代表资源容量，那么乘子 λ 就是每增加一单位资源所能带来的目标函数改善量。乘子越大，说明该约束越"紧"，放松它能带来更大的收益。


function sensitivityAnalysis(
  solve: (b: number[]) => { optVal: number; multipliers: number[] },
  b0: number[],
  delta: number = 0.001,
): { multipliers: number[]; sensitivity: number[] } {
  const base = solve(b0);
  const sensitivity: number[] = [];

  for (let i = 0; i < b0.length; i++) {
    const bPlus = [...b0];
    bPlus[i] += delta;
    const perturbed = solve(bPlus);
    sensitivity.push((perturbed.optVal - base.optVal) / delta);
  }

  return { multipliers: base.multipliers, sensitivity };
}

const portfolioSolve = (b: number[]) => {
  const budget = b[0];
  const riskLimit = b[1];
  const optVal = -Math.sqrt(budget) * (1 - 0.1 / riskLimit);
  return {
    optVal,
    multipliers: [
      (-0.5 / Math.sqrt(budget)) * (1 - 0.1 / riskLimit),
      (-Math.sqrt(budget) * 0.1) / (riskLimit * riskLimit),
    ],
  };
};

const analysis = sensitivityAnalysis(portfolioSolve, [100, 0.5]);
console.log(`乘子: [${analysis.multipliers.map((m) => m.toFixed(4))}]`);
console.log(`灵敏度: [${analysis.sensitivity.map((s) => s.toFixed(4))}]`);
小结
    

  • 拉格朗日乘数法通过引入乘子将等式约束优化转化为无约束驻点问题
    • 

  • 几何直觉是最优解处目标函数等值线与约束曲面相切
    • 

  • KKT 条件将方法推广到不等式约束，互补松弛条件区分激活与非激活约束
    • 

  • 在凸问题满足 Slater 条件时，KKT 条件是全局最优的充要条件
    • 

  • 对偶理论提供了下界估计和替代求解路径，强对偶保证零对偶间隙
    • 

  • 乘子的影子价格含义为约束管理和资源分配提供了经济学视角
