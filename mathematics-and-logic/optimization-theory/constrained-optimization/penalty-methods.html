罚函数方法

核心概念

罚函数方法（Penalty Methods）是将约束优化问题转化为一系列无约束优化问题的通用技术。核心思想是在目标函数中添加一个惩罚项，当解违反约束时产生额外的"代价"，从而引导搜索过程趋向可行域。通过逐步增大惩罚参数 ρ，无约束子问题的最优解逐渐逼近原始约束问题的最优解。

罚函数方法分为两大类：外罚函数法（Exterior Penalty）从不可行区域出发，通过惩罚约束违反量逐步逼近可行域；内罚函数法（Interior Penalty / Barrier Method）从可行域内部出发，通过在边界附近设置"障碍"阻止搜索离开可行域。两种方法各有优劣，选择取决于问题结构和初始点的可行性。

外罚函数法
外罚函数法构造辅助函数 P(x; ρ) = f(x) + ρ/2 · Σ max(0, h_j(x))² + ρ/2 · Σ g_i(x)²，其中 ρ 是递增的惩罚参数。当 ρ → ∞ 时，P 的无约束最优解趋近于原问题的约束最优解。


外罚函数法的主要优势是不要求初始点可行，但缺点是中间迭代产生的解通常不满足约束。此外，随着 ρ 增大，子问题的条件数恶化，导致无约束优化求解器的收敛变慢。


function exteriorPenalty(
  f: (x: number[]) => number,
  gradF: (x: number[]) => number[],
  ineqConstraints: {
    h: (x: number[]) => number;
    grad: (x: number[]) => number[];
  }[],
  eqConstraints: {
    g: (x: number[]) => number;
    grad: (x: number[]) => number[];
  }[],
  x0: number[],
  options: {
    rho0?: number;
    rhoMultiplier?: number;
    maxOuter?: number;
    maxInner?: number;
    tol?: number;
  } = {},
): { x: number[]; fVal: number; rhoHistory: number[]; violation: number } {
  const { rho0 = 1, rhoMultiplier = 10, maxOuter = 20, maxInner = 500, tol = 1e-8 } = options;

  let x = [...x0];
  let rho = rho0;
  const rhoHistory: number[] = [];

  for (let outer = 0; outer < maxOuter; outer++) {
    rhoHistory.push(rho);

    const penaltyF = (x: number[]): number => {
      let p = f(x);
      for (const c of ineqConstraints) {
        const v = Math.max(0, c.h(x));
        p += (rho / 2) * v * v;
      }
      for (const c of eqConstraints) {
        const v = c.g(x);
        p += (rho / 2) * v * v;
      }
      return p;
    };

    const penaltyGrad = (x: number[]): number[] => {
      const g = gradF(x);
      for (const c of ineqConstraints) {
        const hVal = c.h(x);
        if (hVal > 0) {
          const cg = c.grad(x);
          for (let i = 0; i < g.length; i++) g[i] += rho * hVal * cg[i];
        }
      }
      for (const c of eqConstraints) {
        const gVal = c.g(x);
        const cg = c.grad(x);
        for (let i = 0; i < g.length; i++) g[i] += rho * gVal * cg[i];
      }
      return g;
    };

    const lr = Math.min(0.01, 1 / rho);
    for (let inner = 0; inner < maxInner; inner++) {
      const g = penaltyGrad(x);
      const norm = Math.sqrt(g.reduce((s, v) => s + v * v, 0));
      if (norm < tol) break;
      x = x.map((xi, i) => xi - lr * g[i]);
    }

    const violation =
      ineqConstraints.reduce((s, c) => s + Math.max(0, c.h(x)), 0) +
      eqConstraints.reduce((s, c) => s + Math.abs(c.g(x)), 0);

    if (violation < tol) break;
    rho *= rhoMultiplier;
  }

  const finalViolation =
    ineqConstraints.reduce((s, c) => s + Math.max(0, c.h(x)), 0) +
    eqConstraints.reduce((s, c) => s + Math.abs(c.g(x)), 0);

  return { x, fVal: f(x), rhoHistory, violation: finalViolation };
}

const result = exteriorPenalty(
  (x) => (x[0] - 2) ** 2 + (x[1] - 1) ** 2,
  (x) => [2 * (x[0] - 2), 2 * (x[1] - 1)],
  [{ h: (x) => x[0] * x[0] + x[1] * x[1] - 1, grad: (x) => [2 * x[0], 2 * x[1]] }],
  [],
  [2, 2],
);
console.log(`外罚: x*=[${result.x.map((v) => v.toFixed(4))}], f*=${result.fVal.toFixed(4)}`);
内罚函数法（障碍函数法）
内罚函数法（Barrier Method）在可行域内部构造辅助函数 B(x; ρ) = f(x) - (1/ρ) · Σ log(-h_j(x))，当 x 接近约束边界时 log 项趋于 -∞，产生"障碍"效应阻止解离开可行域。随着 ρ → ∞，障碍效应减弱，最优解逐步逼近约束边界上的真正最优解。


对数障碍是内点法（Interior Point Method）的理论基础，在线性规划和二次规划中有着核心地位。内罚函数的显著优势是所有中间迭代点都是严格可行的，这在工程实践中非常有价值。


function barrierMethod(
  f: (x: number[]) => number,
  gradF: (x: number[]) => number[],
  ineqConstraints: {
    h: (x: number[]) => number;
    grad: (x: number[]) => number[];
  }[],
  x0: number[],
  options: {
    t0?: number;
    mu?: number;
    maxOuter?: number;
    maxInner?: number;
    tol?: number;
  } = {},
): { x: number[]; fVal: number; path: number[][]; tHistory: number[] } {
  const { t0 = 1, mu = 10, maxOuter = 30, maxInner = 300, tol = 1e-8 } = options;

  let x = [...x0];
  let t = t0;
  const path: number[][] = [[...x]];
  const tHistory: number[] = [];
  const m = ineqConstraints.length;

  for (let outer = 0; outer < maxOuter; outer++) {
    tHistory.push(t);

    const barrierF = (x: number[]): number => {
      let val = t * f(x);
      for (const c of ineqConstraints) {
        const hv = c.h(x);
        if (hv >= 0) return Infinity;
        val -= Math.log(-hv);
      }
      return val;
    };

    const barrierGrad = (x: number[]): number[] => {
      const g = gradF(x).map((gi) => t * gi);
      for (const c of ineqConstraints) {
        const hv = c.h(x);
        const hg = c.grad(x);
        for (let i = 0; i < g.length; i++) {
          g[i] -= hg[i] / hv;
        }
      }
      return g;
    };

    const lr = 0.001;
    for (let inner = 0; inner < maxInner; inner++) {
      const g = barrierGrad(x);
      const norm = Math.sqrt(g.reduce((s, v) => s + v * v, 0));
      if (norm < tol * t) break;
      const xNew = x.map((xi, i) => xi - lr * g[i]);

      let feasible = true;
      for (const c of ineqConstraints) {
        if (c.h(xNew) >= 0) {
          feasible = false;
          break;
        }
      }
      if (feasible) x = xNew;
      else break;
    }

    path.push([...x]);

    if (m / t < tol) break;
    t *= mu;
  }

  return { x, fVal: f(x), path, tHistory };
}
增广拉格朗日方法
增广拉格朗日方法（Augmented Lagrangian Method, ALM）结合了拉格朗日乘数法和二次罚函数法的优点。辅助函数为 L_A(x; λ, ρ) = f(x) + Σλ_i g_i(x) + (ρ/2) Σ g_i(x)²，不仅包含罚项还包含乘子估计。每轮外迭代求解无约束子问题后，用 λ_i ← λ_i + ρ g_i(x*) 更新乘子估计。


增广拉格朗日方法的关键优势是：即使 ρ 保持有限值，当乘子估计收敛到真正的最优乘子时，子问题的最优解也会收敛到原问题的最优解。这避免了纯罚函数法中 ρ → ∞ 带来的数值病态问题。


function augmentedLagrangian(
  f: (x: number[]) => number,
  gradF: (x: number[]) => number[],
  eqConstraints: {
    g: (x: number[]) => number;
    grad: (x: number[]) => number[];
  }[],
  x0: number[],
  options: {
    rho0?: number;
    maxOuter?: number;
    maxInner?: number;
    tol?: number;
  } = {},
): {
  x: number[];
  fVal: number;
  multipliers: number[];
  outerIters: number;
} {
  const { rho0 = 1, maxOuter = 50, maxInner = 300, tol = 1e-8 } = options;
  const m = eqConstraints.length;

  let x = [...x0];
  let lambda = new Array(m).fill(0);
  let rho = rho0;

  for (let outer = 0; outer < maxOuter; outer++) {
    const currentRho = rho;
    const currentLambda = [...lambda];

    const augGrad = (x: number[]): number[] => {
      const g = gradF(x);
      for (let i = 0; i < m; i++) {
        const gVal = eqConstraints[i].g(x);
        const cg = eqConstraints[i].grad(x);
        const coeff = currentLambda[i] + currentRho * gVal;
        for (let j = 0; j < g.length; j++) g[j] += coeff * cg[j];
      }
      return g;
    };

    const lr = Math.min(0.01, 1 / (1 + rho));
    for (let inner = 0; inner < maxInner; inner++) {
      const g = augGrad(x);
      const norm = Math.sqrt(g.reduce((s, v) => s + v * v, 0));
      if (norm < tol * 0.1) break;
      x = x.map((xi, i) => xi - lr * g[i]);
    }

    const violation = eqConstraints.reduce((s, c) => s + Math.abs(c.g(x)), 0);

    for (let i = 0; i < m; i++) {
      lambda[i] += rho * eqConstraints[i].g(x);
    }

    if (violation < tol) {
      return { x, fVal: f(x), multipliers: lambda, outerIters: outer + 1 };
    }

    if (outer > 0 && violation > 0.25 * eqConstraints.reduce((s, c) => s + Math.abs(c.g(x)), 0)) {
      rho *= 2;
    }
  }

  return { x, fVal: f(x), multipliers: lambda, outerIters: maxOuter };
}

const almResult = augmentedLagrangian(
  (x) => x[0] * x[0] + x[1] * x[1],
  (x) => [2 * x[0], 2 * x[1]],
  [{ g: (x) => x[0] + x[1] - 1, grad: () => [1, 1] }],
  [2, 2],
);
console.log(`ALM: x*=[${almResult.x.map((v) => v.toFixed(4))}], λ=[${almResult.multipliers.map((v) => v.toFixed(4))}]`);

罚参数选择与收敛性
罚参数 ρ 的选择策略直接影响算法性能。ρ 过小时惩罚不足，解远离可行域；ρ 过大时子问题条件数恶化。实践中常用的策略是从较小的 ρ 开始，按几何级数 ρ_{k+1} = β ρ_k（β ∈ [2, 10]）递增。


外罚函数法的收敛性定理：设 {x_k} 是罚参数 ρ_k → ∞ 对应的子问题最优解序列，{x_k} 的任何聚点都是原始约束问题的最优解。收敛速率取决于约束违反量的衰减速度，通常为 O(1/√ρ)。


增广拉格朗日方法的收敛性更强：在约束规格条件下，当乘子估计 λ_k → λ* 时，收敛速率可以达到超线性。ADMM（交替方向乘子法）是增广拉格朗日方法在可分离问题上的推广，以 O(1/k) 速率收敛。


function comparePenaltyStrategies(
  f: (x: number[]) => number,
  gradF: (x: number[]) => number[],
  constraint: {
    g: (x: number[]) => number;
    grad: (x: number[]) => number[];
  },
  x0: number[],
): void {
  const strategies = [
    { name: '慢增长 (β=2)', beta: 2, rho0: 0.1 },
    { name: '中等增长 (β=5)', beta: 5, rho0: 0.1 },
    { name: '快增长 (β=10)', beta: 10, rho0: 0.1 },
    { name: '大初始值 (ρ₀=100)', beta: 5, rho0: 100 },
  ];

  for (const s of strategies) {
    let rho = s.rho0;
    let x = [...x0];
    let outerIters = 0;
    let totalInner = 0;

    for (let outer = 0; outer < 30; outer++) {
      outerIters++;
      const lr = Math.min(0.01, 1 / rho);
      for (let inner = 0; inner < 500; inner++) {
        totalInner++;
        const gf = gradF(x);
        const gVal = constraint.g(x);
        const cg = constraint.grad(x);
        const grad = gf.map((gi, i) => gi + rho * gVal * cg[i]);
        x = x.map((xi, i) => xi - lr * grad[i]);
      }
      if (Math.abs(constraint.g(x)) < 1e-8) break;
      rho *= s.beta;
    }

    console.log(`${s.name}: ${outerIters}外 ${totalInner}内 violation=${Math.abs(constraint.g(x)).toExponential(2)}`);
  }
}
小结
    

  • 外罚函数法通过惩罚约束违反量将约束优化转化为无约束问题，不要求可行初始点
    • 

  • 内罚函数法通过对数或逆障碍保持中间解始终可行，是内点法的理论基础
    • 

  • 增广拉格朗日方法通过迭代更新乘子估计避免 ρ → ∞ 的数值病态
    • 

  • 罚参数的几何递增策略（β ∈ [2, 10]）是实践中最常用的调度方案
    • 

  • 外罚函数法的收敛速率为 O(1/√ρ)，增广拉格朗日可达超线性收敛
    • 

  • ADMM 将增广拉格朗日推广到可分离问题，广泛应用于分布式优化和机器学习
