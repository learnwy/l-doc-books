KKT 条件

核心概念

KKT 条件（Karush-Kuhn-Tucker Conditions）是约束优化问题最优性的一阶必要条件，在凸优化中也是充分条件。KKT 条件将原始可行性、对偶可行性和互补松弛条件统一为一组方程和不等式，构成了约束优化理论的核心。

对于问题 min f₀(x) s.t. fᵢ(x) ≤ 0, hⱼ(x) = 0，KKT 条件包括：(1) 平稳性：∇f₀ + ∑λᵢ∇fᵢ + ∑νⱼ∇hⱼ = 0；(2) 原始可行性：fᵢ(x) ≤ 0, hⱼ(x) = 0；(3) 对偶可行性：λᵢ ≥ 0；(4) 互补松弛：λᵢfᵢ(x) = 0。

KKT 条件的求解
KKT 系统是一组非线性方程和不等式。对于二次规划（QP），KKT 系统可以化简为线性方程组。


interface KKTResult {
  x: number[];
  lambda: number[];
  nu: number[];
  satisfied: boolean;
  violations: string[];
}

function solveKKT_QP(
  H: number[][],
  c: number[],
  A: number[][],
  b: number[],
  Aeq: number[][],
  beq: number[],
): KKTResult {
  const n = c.length;
  const m = A.length;
  const p = Aeq.length;

  let x = Array(n).fill(0);
  let lambda = Array(m).fill(0.1);
  let nu = Array(p).fill(0);

  const lr = 0.01;
  for (let iter = 0; iter < 2000; iter++) {
    const grad = Array(n).fill(0);
    for (let i = 0; i < n; i++) {
      grad[i] = c[i];
      for (let j = 0; j < n; j++) {
        grad[i] += H[i][j] * x[j];
      }
      for (let k = 0; k < m; k++) {
        grad[i] += lambda[k] * A[k][i];
      }
      for (let k = 0; k < p; k++) {
        grad[i] += nu[k] * Aeq[k][i];
      }
    }

    x = x.map((xi, i) => xi - lr * grad[i]);

    for (let k = 0; k < m; k++) {
      const constraint = A[k].reduce((s, a, i) => s + a * x[i], 0) - b[k];
      lambda[k] = Math.max(0, lambda[k] + lr * constraint);
    }

    for (let k = 0; k < p; k++) {
      const constraint = Aeq[k].reduce((s, a, i) => s + a * x[i], 0) - beq[k];
      nu[k] = nu[k] + lr * constraint;
    }
  }

  const violations: string[] = [];
  for (let k = 0; k < m; k++) {
    const val = A[k].reduce((s, a, i) => s + a * x[i], 0) - b[k];
    if (val > 1e-4) violations.push(`不等式约束 ${k} 违反: ${val.toFixed(6)}`);
    if (lambda[k] < -1e-4) violations.push(`对偶变量 λ${k} 为负`);
    if (Math.abs(lambda[k] * val) > 1e-4) violations.push(`互补松弛 ${k} 违反`);
  }

  return {
    x,
    lambda,
    nu,
    satisfied: violations.length === 0,
    violations,
  };
}

const H_qp = [
  [2, 0],
  [0, 4],
];
const c_qp = [-4, -6];
const A_qp = [
  [1, 1],
  [-1, 0],
  [0, -1],
];
const b_qp = [3, 0, 0];

const kkt = solveKKT_QP(H_qp, c_qp, A_qp, b_qp, [], []);
console.log(`x* = [${kkt.x.map((x) => x.toFixed(4))}]`);
console.log(`λ* = [${kkt.lambda.map((l) => l.toFixed(4))}]`);
console.log(`KKT 满足: ${kkt.satisfied}`);
if (kkt.violations.length > 0) {
  kkt.violations.forEach((v) => console.log(`  违反: ${v}`));
}
活跃集方法
活跃集方法（Active Set Method）利用 KKT 条件中的互补松弛性：在最优解处，只有活跃约束（fᵢ(x*) = 0 的约束）的乘子可能非零。算法通过动态维护活跃约束集合来求解。


function activeSetQP(
  H: number[][],
  c: number[],
  A: number[][],
  b: number[],
  maxIter: number = 100,
): { x: number[]; activeSet: number[] } {
  const n = c.length;
  const m = A.length;
  let x = Array(n).fill(0);
  let activeSet: number[] = [];

  for (let iter = 0; iter < maxIter; iter++) {
    const grad = c.map((ci, i) => {
      let sum = ci;
      for (let j = 0; j < n; j++) {
        sum += H[i][j] * x[j];
      }
      return sum;
    });

    if (activeSet.length > 0) {
      const Aact = activeSet.map((i) => A[i]);
      const lambda = solveActiveKKT(H, grad, Aact);

      const minLambda = Math.min(...lambda);
      if (minLambda < -1e-6) {
        const removeIdx = lambda.indexOf(minLambda);
        activeSet.splice(removeIdx, 1);
        continue;
      }
    }

    const gradNorm = Math.sqrt(grad.reduce((s, g) => s + g * g, 0));
    if (gradNorm < 1e-6) break;

    const direction = grad.map((g) => -g);

    let maxStep = Infinity;
    let blockingConstraint = -1;
    for (let i = 0; i < m; i++) {
      if (activeSet.includes(i)) continue;
      const Ad = A[i].reduce((s, a, j) => s + a * direction[j], 0);
      if (Ad > 1e-10) {
        const slack = b[i] - A[i].reduce((s, a, j) => s + a * x[j], 0);
        const step = slack / Ad;
        if (step < maxStep) {
          maxStep = step;
          blockingConstraint = i;
        }
      }
    }

    const step = Math.min(1, maxStep);
    x = x.map((xi, j) => xi + step * direction[j]);

    if (blockingConstraint >= 0 && step === maxStep) {
      activeSet.push(blockingConstraint);
    }
  }

  return { x, activeSet };
}

function solveActiveKKT(H: number[][], grad: number[], Aact: number[][]): number[] {
  const m = Aact.length;
  if (m === 0) return [];
  const lambda = Array(m).fill(0);
  for (let i = 0; i < m; i++) {
    lambda[i] = Aact[i].reduce((s, a, j) => s + a * grad[j], 0);
  }
  return lambda;
}

const result2 = activeSetQP(H_qp, c_qp, A_qp, b_qp);
console.log(`活跃集法: x* = [${result2.x.map((x) => x.toFixed(4))}]`);
console.log(`活跃约束: [${result2.activeSet}]`);
KKT 条件在机器学习中的应用
KKT 条件在正则化机器学习模型中有直接应用。L1 正则化（Lasso）的 KKT 条件导致了稀疏解的理论解释，弹性网络通过 KKT 条件实现了特征选择和系数收缩的统一。


function lassoKKT(X: number[][], y: number[], lambdaReg: number): { beta: number[]; kktViolation: number } {
  const n = X.length;
  const p = X[0].length;
  const beta = Array(p).fill(0);

  for (let iter = 0; iter < 100; iter++) {
    for (let j = 0; j < p; j++) {
      let residual = 0;
      for (let i = 0; i < n; i++) {
        let pred = 0;
        for (let k = 0; k < p; k++) {
          if (k !== j) pred += X[i][k] * beta[k];
        }
        residual += X[i][j] * (y[i] - pred);
      }
      residual /= n;

      let xjNormSq = 0;
      for (let i = 0; i < n; i++) {
        xjNormSq += X[i][j] * X[i][j];
      }
      xjNormSq /= n;

      if (residual > lambdaReg) {
        beta[j] = (residual - lambdaReg) / xjNormSq;
      } else if (residual < -lambdaReg) {
        beta[j] = (residual + lambdaReg) / xjNormSq;
      } else {
        beta[j] = 0;
      }
    }
  }

  let maxViolation = 0;
  for (let j = 0; j < p; j++) {
    let grad = 0;
    for (let i = 0; i < n; i++) {
      let pred = 0;
      for (let k = 0; k < p; k++) pred += X[i][k] * beta[k];
      grad += X[i][j] * (pred - y[i]);
    }
    grad /= n;

    if (beta[j] > 0) maxViolation = Math.max(maxViolation, Math.abs(grad + lambdaReg));
    else if (beta[j] < 0) maxViolation = Math.max(maxViolation, Math.abs(grad - lambdaReg));
    else maxViolation = Math.max(maxViolation, Math.max(0, Math.abs(grad) - lambdaReg));
  }

  return { beta, kktViolation: maxViolation };
}

const X_lasso = [
  [1, 2, 0],
  [2, 1, 3],
  [3, 0, 1],
  [4, 3, 2],
];
const y_lasso = [3, 5, 4, 9];
const lasso = lassoKKT(X_lasso, y_lasso, 0.5);
console.log(`Lasso β: [${lasso.beta.map((b) => b.toFixed(4))}]`);
console.log(`KKT 违反度: ${lasso.kktViolation.toFixed(6)}`);
console.log(`稀疏性: ${lasso.beta.filter((b) => Math.abs(b) < 1e-6).length}/${lasso.beta.length} 个零系数`);

小结
    

  • KKT 条件统一了平稳性、可行性和互补松弛，是约束优化的核心最优性条件
    • 

  • 在凸优化中 KKT 条件是充分必要的，在非凸问题中仅为必要条件
    • 

  • 活跃集方法利用互补松弛性质动态管理约束，适用于中等规模问题
    • 

  • Lasso 的 KKT 条件直接解释了 L1 正则化产生稀疏解的机制
    • 

  • 内点法和 SQP 方法通过迭代求解 KKT 系统实现高效优化
    • 

  • KKT 条件在 SVM、正则化回归和核方法中有直接的算法应用
