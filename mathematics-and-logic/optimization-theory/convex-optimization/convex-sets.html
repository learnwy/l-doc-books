凸集

核心概念

凸集（Convex Set）是凸优化理论的几何基础。一个集合 S ⊂ ℝⁿ 是凸集，当且仅当对于任意两点 x, y ∈ S 和任意 λ ∈ [0, 1]，有 λx + (1-λ)y ∈ S。直觉上说，连接集合中任意两点的线段完全包含在集合内部。

凸集的概念贯穿整个优化理论：凸集上的凸函数最小化是优化理论中最"好"的问题类别——局部最优即全局最优，且存在高效的多项式时间算法。

透视函数
P(x,t) = x/t, t>0
透视变换保持凸性




线性分式
f(x) = (Ax+b)/(cᵀx+d)
在定义域内保持凸性





基本凸集与凸集运算
常见的凸集包括超平面、半空间、多面体、椭球和范数球。理解这些基本凸集是构造和分析更复杂凸集的基础。


function isConvex2D(
  points: Array<[number, number]>,
  testFn: (x: number, y: number) => boolean,
  nTests: number = 1000,
): boolean {
  for (let i = 0; i < nTests; i++) {
    const idx1 = Math.floor(Math.random() * points.length);
    const idx2 = Math.floor(Math.random() * points.length);
    const [x1, y1] = points[idx1];
    const [x2, y2] = points[idx2];

    if (!testFn(x1, y1) || !testFn(x2, y2)) continue;

    const lambda = Math.random();
    const mx = lambda * x1 + (1 - lambda) * x2;
    const my = lambda * y1 + (1 - lambda) * y2;

    if (!testFn(mx, my)) return false;
  }
  return true;
}

function hyperplane(a: number[], b: number): (x: number[]) => boolean {
  return (x) => {
    const dot = a.reduce((s, ai, i) => s + ai * x[i], 0);
    return Math.abs(dot - b) < 1e-10;
  };
}

function halfspace(a: number[], b: number): (x: number[]) => boolean {
  return (x) => a.reduce((s, ai, i) => s + ai * x[i], 0) <= b;
}

function ellipsoid(center: number[], semiAxes: number[]): (x: number[]) => boolean {
  return (x) => {
    let sum = 0;
    for (let i = 0; i < center.length; i++) {
      sum += ((x[i] - center[i]) / semiAxes[i]) ** 2;
    }
    return sum <= 1;
  };
}

function normBall(center: number[], radius: number, p: number): (x: number[]) => boolean {
  return (x) => {
    const norm = Math.pow(
      x.reduce((s, xi, i) => s + Math.pow(Math.abs(xi - center[i]), p), 0),
      1 / p,
    );
    return norm <= radius;
  };
}

分离超平面与支撑超平面
分离超平面定理是凸分析中最重要的理论工具之一：如果两个凸集不相交，则存在一个超平面将它们分开。这一定理是对偶理论、KKT 条件和凸规划求解算法的基础。


function separatingHyperplane2D(
  setA: Array<[number, number]>,
  setB: Array<[number, number]>,
): { a: [number, number]; b: number } | null {
  const centerA: [number, number] = [
    setA.reduce((s, p) => s + p[0], 0) / setA.length,
    setA.reduce((s, p) => s + p[1], 0) / setA.length,
  ];
  const centerB: [number, number] = [
    setB.reduce((s, p) => s + p[0], 0) / setB.length,
    setB.reduce((s, p) => s + p[1], 0) / setB.length,
  ];

  const a: [number, number] = [centerB[0] - centerA[0], centerB[1] - centerA[1]];
  const norm = Math.sqrt(a[0] * a[0] + a[1] * a[1]);
  if (norm < 1e-10) return null;
  a[0] /= norm;
  a[1] /= norm;

  const projA = setA.map((p) => a[0] * p[0] + a[1] * p[1]);
  const projB = setB.map((p) => a[0] * p[0] + a[1] * p[1]);

  const maxA = Math.max(...projA);
  const minB = Math.min(...projB);

  if (maxA > minB) return null;

  const b = (maxA + minB) / 2;
  return { a, b };
}

function supportingHyperplane2D(
  convexSet: Array<[number, number]>,
  point: [number, number],
): { a: [number, number]; b: number } {
  const center: [number, number] = [
    convexSet.reduce((s, p) => s + p[0], 0) / convexSet.length,
    convexSet.reduce((s, p) => s + p[1], 0) / convexSet.length,
  ];

  const a: [number, number] = [point[0] - center[0], point[1] - center[1]];
  const norm = Math.sqrt(a[0] * a[0] + a[1] * a[1]);
  a[0] /= norm;
  a[1] /= norm;

  const b = a[0] * point[0] + a[1] * point[1];
  return { a, b };
}

const circlePoints: Array<[number, number]> = Array.from({ length: 20 }, (_, i) => {
  const theta = (2 * Math.PI * i) / 20;
  return [Math.cos(theta), Math.sin(theta)];
});

const shiftedCircle: Array<[number, number]> = circlePoints.map(([x, y]) => [x + 3, y]);

const sep = separatingHyperplane2D(circlePoints, shiftedCircle);
if (sep) {

}

凸锥与锥规划
凸锥（Convex Cone）是既是凸集又是锥的集合：若 x ∈ K，则对所有 λ ≥ 0 有 λx ∈ K。常见的凸锥包括非负象限、半定锥（正半定矩阵的集合）和二阶锥。锥规划是凸优化的重要子类。


function isInNonnegativeOrthant(x: number[]): boolean {
  return x.every((xi) => xi >= 0);
}

function isInSecondOrderCone(x: number[], t: number): boolean {
  const norm = Math.sqrt(x.reduce((s, xi) => s + xi * xi, 0));
  return norm <= t;
}

function isPositiveSemidefinite(matrix: number[][]): boolean {
  const n = matrix.length;
  for (let size = 1; size <= n; size++) {
    for (let i = 0; i <= n - size; i++) {
      let det = 0;
      if (size === 1) {
        det = matrix[i][i];
      } else if (size === 2) {
        det = matrix[i][i] * matrix[i + 1][i + 1] - matrix[i][i + 1] * matrix[i + 1][i];
      } else {
        const sub = matrix.slice(i, i + size).map((row) => row.slice(i, i + size));
        det = computeDeterminant(sub);
      }
      if (det < -1e-10) return false;
    }
  }
  return true;
}

function computeDeterminant(m: number[][]): number {
  if (m.length === 1) return m[0][0];
  if (m.length === 2) return m[0][0] * m[1][1] - m[0][1] * m[1][0];
  let det = 0;
  for (let j = 0; j < m.length; j++) {
    const sub = m.slice(1).map((row) => [...row.slice(0, j), ...row.slice(j + 1)]);
    det += (j % 2 === 0 ? 1 : -1) * m[0][j] * computeDeterminant(sub);
  }
  return det;
}

function dualCone(generators: number[][]): string {
  const dim = generators[0].length;
  return `K* = {y ∈ ℝ${dim} : yᵀx ≥ 0, ∀x ∈ K}`;
}

小结
    

  • 凸集是凸优化的几何基础，其核心定义是线段包含性
    • 

  • 凸集在交集、仿射变换、透视函数等运算下保持凸性
    • 

  • 分离超平面定理保证不相交的凸集可以被超平面分开
    • 

  • 凸锥（非负象限、半定锥、二阶锥）定义了锥规划的可行域
    • 

  • 对偶锥概念连接了原始问题与对偶问题的几何结构
    • 

  • 掌握凸集理论是理解凸优化算法和对偶理论的必要前提
