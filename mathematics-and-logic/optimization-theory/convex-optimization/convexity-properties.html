凸性与凸函数

核心概念

凸函数（Convex Function）是凸优化中最核心的概念。函数 f: ℝⁿ → ℝ 是凸函数，当且仅当 dom f 是凸集且对所有 x, y ∈ dom f 和 λ ∈ [0,1]，有 f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y)。凸函数的本质特征是：函数图形上方的区域（上境图 epigraph）是凸集。

凸函数最重要的性质是局部最小值即全局最小值。这意味着对凸优化问题，任何下降算法找到的稳定点都是全局最优。这一性质使得凸优化问题在理论和实践中都远比一般非凸问题容易处理。

凸函数的判定与构造
掌握凸函数的判定方法和保凸运算是构造和分析优化问题的基本技能。常见的保凸运算包括非负加权和、复合运算、逐点上确界和透视函数。


function checkConvexity1D(f: (x: number) => number, range: [number, number], nTests: number = 1000): boolean {
  const [a, b] = range;
  for (let i = 0; i < nTests; i++) {
    const x = a + Math.random() * (b - a);
    const y = a + Math.random() * (b - a);
    const lambda = Math.random();
    const lhs = f(lambda * x + (1 - lambda) * y);
    const rhs = lambda * f(x) + (1 - lambda) * f(y);
    if (lhs > rhs + 1e-10) return false;
  }
  return true;
}

function numericalHessian(f: (x: number[]) => number, x: number[], h: number = 1e-5): number[][] {
  const n = x.length;
  const H: number[][] = Array.from({ length: n }, () => Array(n).fill(0));
  const fx = f(x);

  for (let i = 0; i < n; i++) {
    for (let j = i; j < n; j++) {
      const xpp = [...x];
      xpp[i] += h;
      xpp[j] += h;
      const xpm = [...x];
      xpm[i] += h;
      xpm[j] -= h;
      const xmp = [...x];
      xmp[i] -= h;
      xmp[j] += h;
      const xmm = [...x];
      xmm[i] -= h;
      xmm[j] -= h;
      H[i][j] = (f(xpp) - f(xpm) - f(xmp) + f(xmm)) / (4 * h * h);
      H[j][i] = H[i][j];
    }
  }
  return H;
}

function isPositiveDefinite(H: number[][]): boolean {
  const n = H.length;
  const L: number[][] = Array.from({ length: n }, () => Array(n).fill(0));
  for (let i = 0; i < n; i++) {
    for (let j = 0; j <= i; j++) {
      let sum = H[i][j];
      for (let k = 0; k < j; k++) {
        sum -= L[i][k] * L[j][k];
      }
      if (i === j) {
        if (sum <= 0) return false;
        L[i][j] = Math.sqrt(sum);
      } else {
        L[i][j] = sum / L[j][j];
      }
    }
  }
  return true;
}

const quadratic = (x: number[]) => x[0] * x[0] + 2 * x[1] * x[1] + x[0] * x[1];
const rosenbrock = (x: number[]) => (1 - x[0]) ** 2 + 100 * (x[1] - x[0] ** 2) ** 2;

const H1 = numericalHessian(quadratic, [1, 1]);
const H2 = numericalHessian(rosenbrock, [1, 1]);

console.log(`二次函数 Hessian PD: ${isPositiveDefinite(H1)}`);
console.log(`Rosenbrock 在 (1,1) Hessian PD: ${isPositiveDefinite(H2)}`);
console.log(`x² 凸性: ${checkConvexity1D((x) => x * x, [-10, 10])}`);
console.log(`sin(x) 凸性: ${checkConvexity1D((x) => Math.sin(x), [0, Math.PI])}`);
console.log(`exp(x) 凸性: ${checkConvexity1D((x) => Math.exp(x), [-5, 5])}`);
强凸性与光滑性
强凸性和光滑性是分析优化算法收敛速率的两个关键性质。函数 f 是 μ-强凸的，如果 f(x) - (μ/2)||x||² 是凸函数；f 是 L-光滑的，如果 ∇f 是 L-Lipschitz 连续的。条件数 κ = L/μ 决定了梯度下降的收敛速率。


function estimateStrongConvexity(
  f: (x: number[]) => number,
  grad: (x: number[]) => number[],
  points: number[][],
): number {
  let minMu = Infinity;
  for (let i = 0; i < points.length; i++) {
    for (let j = i + 1; j < points.length; j++) {
      const x = points[i];
      const y = points[j];
      const gx = grad(x);
      const diff = y.map((yi, k) => yi - x[k]);
      const gradDiff = diff.reduce((s, d, k) => s + gx[k] * d, 0);
      const normSq = diff.reduce((s, d) => s + d * d, 0);
      const fDiff = f(y) - f(x) - gradDiff;
      if (normSq > 1e-10) {
        minMu = Math.min(minMu, (2 * fDiff) / normSq);
      }
    }
  }
  return Math.max(0, minMu);
}

function estimateSmoothness(grad: (x: number[]) => number[], points: number[][]): number {
  let maxL = 0;
  for (let i = 0; i < points.length; i++) {
    for (let j = i + 1; j < points.length; j++) {
      const gx = grad(points[i]);
      const gy = grad(points[j]);
      const gradDiffNorm = Math.sqrt(gx.reduce((s, gi, k) => s + (gi - gy[k]) ** 2, 0));
      const xDiffNorm = Math.sqrt(points[i].reduce((s, xi, k) => s + (xi - points[j][k]) ** 2, 0));
      if (xDiffNorm > 1e-10) {
        maxL = Math.max(maxL, gradDiffNorm / xDiffNorm);
      }
    }
  }
  return maxL;
}

const quadGrad = (x: number[]): number[] => [2 * x[0] + x[1], 4 * x[1] + x[0]];
const testPoints = Array.from({ length: 50 }, () => Array.from({ length: 2 }, () => Math.random() * 4 - 2));

const mu = estimateStrongConvexity(quadratic, quadGrad, testPoints);
const L = estimateSmoothness(quadGrad, testPoints);
console.log(`强凸参数 μ ≈ ${mu.toFixed(4)}`);
console.log(`光滑参数 L ≈ ${L.toFixed(4)}`);
console.log(`条件数 κ = L/μ ≈ ${(L / mu).toFixed(4)}`);

次梯度与非光滑分析
当函数不可微时（如 L1 范数 |x|），经典梯度不存在，但凸函数在每一点都存在次梯度。次梯度是一阶条件的推广：g 是 f 在 x 处的次梯度当且仅当 f(y) ≥ f(x) + gᵀ(y-x) 对所有 y 成立。


function subgradientL1(x: number[]): number[][] {
  const n = x.length;
  const subgrad: number[][] = [Array(n).fill(0)];

  for (let i = 0; i < n; i++) {
    const newSubgrads: number[][] = [];
    for (const sg of subgrad) {
      if (x[i] > 0) {
        newSubgrads.push([...sg.slice(0, i), 1, ...sg.slice(i + 1)]);
      } else if (x[i] < 0) {
        newSubgrads.push([...sg.slice(0, i), -1, ...sg.slice(i + 1)]);
      } else {
        newSubgrads.push([...sg.slice(0, i), -1, ...sg.slice(i + 1)]);
        newSubgrads.push([...sg.slice(0, i), 0, ...sg.slice(i + 1)]);
        newSubgrads.push([...sg.slice(0, i), 1, ...sg.slice(i + 1)]);
      }
    }
    subgrad.length = 0;
    subgrad.push(...newSubgrads);
  }
  return subgrad;
}

function subgradientDescent(
  f: (x: number[]) => number,
  subgrad: (x: number[]) => number[],
  x0: number[],
  iterations: number = 100,
): { x: number[]; fBest: number; history: number[] } {
  let x = [...x0];
  let fBest = f(x);
  let xBest = [...x];
  const history: number[] = [fBest];

  for (let k = 1; k <= iterations; k++) {
    const stepSize = 1 / Math.sqrt(k);
    const g = subgrad(x);
    const gNorm = Math.sqrt(g.reduce((s, gi) => s + gi * gi, 0));

    if (gNorm > 1e-10) {
      x = x.map((xi, i) => xi - (stepSize * g[i]) / gNorm);
    }

    const fx = f(x);
    if (fx < fBest) {
      fBest = fx;
      xBest = [...x];
    }
    history.push(fBest);
  }

  return { x: xBest, fBest, history };
}

const l1Norm = (x: number[]): number => x.reduce((s, xi) => s + Math.abs(xi), 0);
const l1Subgrad = (x: number[]): number[] => x.map((xi) => (xi > 0 ? 1 : xi < 0 ? -1 : 0));

const result = subgradientDescent(l1Norm, l1Subgrad, [3, -2, 1]);
console.log(`次梯度下降: x*=[${result.x.map((x) => x.toFixed(4))}], f*=${result.fBest.toFixed(6)}`);
小结
    

  • 凸函数的核心性质是局部最小值即全局最小值，使优化问题本质上更简单
    • 

  • 一阶条件（切线在图下方）和二阶条件（Hessian 半正定）是判定凸性的主要工具
    • 

  • 强凸性和光滑性决定了梯度下降的收敛速率，条件数 κ = L/μ 是关键参数
    • 

  • 保凸运算（非负加权和、逐点上确界、仿射复合）是构造复杂凸问题的基础
    • 

  • 非光滑凸函数通过次梯度推广了微分概念，支持次梯度下降等优化方法
    • 

  • 近端算子是处理非光滑正则化（如 L1 范数）的核心工具
    •
