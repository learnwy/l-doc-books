SGD 变体

核心概念

随机梯度下降（Stochastic Gradient Descent, SGD）用单个样本或小批量样本的梯度估计替代全批量梯度，将每步计算量从 O(n) 降低到 O(1) 或 O(b)（b 为批量大小）。SGD 的更新规则为 x*{k+1} = x_k - α_k ∇f*{i_k}(x_k)，其中 i_k 是随机选取的样本索引。梯度估计的无偏性 E[∇f_i] = ∇f 保证了 SGD 在期望意义下沿正确方向移动。

SGD 的梯度噪声既是挑战也是优势：噪声导致 SGD 无法以标准梯度下降的速率收敛（固定步长下只能收敛到最优值邻域），但同时帮助逃离鞍点和局部极小值，提供隐式正则化效果。Mini-batch SGD、学习率调度、梯度累积等变体针对不同场景优化了噪声-效率的平衡。

Mini-batch 策略与方差控制
Mini-batch SGD 用 b 个样本的平均梯度作为估计：gk = (1/b) Σ{i∈B_k} ∇f_i(x_k)。批量大小 b 控制了梯度方差：Var(g_k) = σ²/b。增大 b 降低方差但增加计算量，存在最优的方差-效率权衡。


在 GPU 并行计算环境下，增大批量大小在一定范围内不会增加实际时间（因为并行度未饱和），因此实践中倾向于使用较大的批量。但大批量训练面临泛化性能下降的挑战——批量越大，噪声越小，正则化效果越弱。


interface SGDConfig {
  lr: number;
  batchSize: number;
  epochs: number;
  lrSchedule?: (epoch: number, baseLr: number) => number;
}

function miniBatchSGD(
  data: { x: number[]; y: number }[],
  w0: number[],
  loss: (w: number[], xi: number[], yi: number) => number,
  gradLoss: (w: number[], xi: number[], yi: number) => number[],
  config: SGDConfig,
): { w: number[]; lossHistory: number[] } {
  const { lr, batchSize, epochs, lrSchedule } = config;
  let w = [...w0];
  const lossHistory: number[] = [];
  const n = data.length;

  for (let epoch = 0; epoch < epochs; epoch++) {
    const shuffled = [...data].sort(() => Math.random() - 0.5);
    const currentLr = lrSchedule ? lrSchedule(epoch, lr) : lr;

    for (let i = 0; i < n; i += batchSize) {
      const batch = shuffled.slice(i, Math.min(i + batchSize, n));
      const bSize = batch.length;

      const avgGrad = new Array(w.length).fill(0);
      for (const sample of batch) {
        const g = gradLoss(w, sample.x, sample.y);
        for (let j = 0; j < w.length; j++) avgGrad[j] += g[j] / bSize;
      }

      w = w.map((wj, j) => wj - currentLr * avgGrad[j]);
    }

    const epochLoss = data.reduce((sum, d) => sum + loss(w, d.x, d.y), 0) / n;
    lossHistory.push(epochLoss);
  }

  return { w, lossHistory };
}

function gradientVariance(
  data: { x: number[]; y: number }[],
  w: number[],
  gradLoss: (w: number[], xi: number[], yi: number) => number[],
  batchSize: number,
  numTrials: number = 100,
): number {
  const n = data.length;
  const d = w.length;
  const means = new Array(d).fill(0);
  const variances = new Array(d).fill(0);

  const grads: number[][] = [];
  for (let t = 0; t < numTrials; t++) {
    const indices = Array.from({ length: batchSize }, () => Math.floor(Math.random() * n));
    const batchGrad = new Array(d).fill(0);
    for (const idx of indices) {
      const g = gradLoss(w, data[idx].x, data[idx].y);
      for (let j = 0; j < d; j++) batchGrad[j] += g[j] / batchSize;
    }
    grads.push(batchGrad);
    for (let j = 0; j < d; j++) means[j] += batchGrad[j] / numTrials;
  }

  for (const g of grads) {
    for (let j = 0; j < d; j++) {
      variances[j] += (g[j] - means[j]) ** 2 / numTrials;
    }
  }

  return variances.reduce((s, v) => s + v, 0);
}
学习率调度策略
学习率调度（Learning Rate Schedule）是 SGD 训练中最重要的超参数策略。固定学习率下 SGD 只能收敛到 O(α σ²) 的邻域；衰减学习率（如 α_k = α₀/k）可以使 SGD 精确收敛，但过早衰减会导致训练不充分。


现代深度学习中最流行的调度策略是余弦退火（Cosine Annealing）和带 warmup 的调度。Warmup 在训练初期线性增大学习率，避免大学习率导致的初始不稳定；余弦退火平滑地将学习率降低到接近零。


type LRScheduler = (step: number, totalSteps: number, baseLr: number) => number;

const constantLR: LRScheduler = (_, __, baseLr) => baseLr;

const stepDecay: LRScheduler = (step, totalSteps, baseLr) => {
  const milestones = [0.3, 0.6, 0.9].map((r) => Math.floor(r * totalSteps));
  let lr = baseLr;
  for (const m of milestones) {
    if (step >= m) lr *= 0.1;
  }
  return lr;
};

const cosineAnnealing: LRScheduler = (step, totalSteps, baseLr) => {
  return baseLr * 0.5 * (1 + Math.cos((Math.PI * step) / totalSteps));
};

const warmupCosine: LRScheduler = (step, totalSteps, baseLr) => {
  const warmupSteps = Math.floor(totalSteps * 0.1);
  if (step < warmupSteps) {
    return (baseLr * step) / warmupSteps;
  }
  const progress = (step - warmupSteps) / (totalSteps - warmupSteps);
  return baseLr * 0.5 * (1 + Math.cos(Math.PI * progress));
};

const linearWarmupDecay: LRScheduler = (step, totalSteps, baseLr) => {
  const warmupSteps = Math.floor(totalSteps * 0.1);
  if (step < warmupSteps) return (baseLr * step) / warmupSteps;
  return baseLr * (1 - (step - warmupSteps) / (totalSteps - warmupSteps));
};

const cyclicLR: LRScheduler = (step, totalSteps, baseLr) => {
  const cycleLength = Math.floor(totalSteps / 5);
  const cyclePos = step % cycleLength;
  return baseLr * 0.5 * (1 + Math.cos((Math.PI * cyclePos) / cycleLength));
};

function compareLRSchedules(totalSteps: number, baseLr: number): void {
  const schedulers: { name: string; fn: LRScheduler }[] = [
    { name: '常量', fn: constantLR },
    { name: '阶梯衰减', fn: stepDecay },
    { name: '余弦退火', fn: cosineAnnealing },
    { name: 'Warmup+余弦', fn: warmupCosine },
    { name: '循环学习率', fn: cyclicLR },
  ];

  for (const s of schedulers) {
    const lrs = [0, totalSteps / 4, totalSteps / 2, (totalSteps * 3) / 4, totalSteps - 1].map((step) =>
      s.fn(step, totalSteps, baseLr).toFixed(6),
    );
    console.log(`${s.name}: [${lrs.join(', ')}]`);
  }
}

方差缩减方法
方差缩减（Variance Reduction）方法利用有限和结构 f(x) = (1/n) Σ f_i(x)，通过存储和重用历史梯度信息来降低梯度估计的方差。代表性算法包括 SVRG（Stochastic Variance Reduced Gradient）和 SAGA。


SVRG 维护一个参考点 x̃ 及其全梯度 ∇f(x̃)，每步更新使用修正梯度 gk = ∇f{ik}(x_k) - ∇f{i_k}(x̃) + ∇f(x̃)。由于 x_k → x* 时修正项趋于零，方差随着算法进展自然缩减到零，使得 SVRG 以线性速率 O((κ + n) log(1/ε)) 收敛。


function svrg(
  data: number[][],
  labels: number[],
  w0: number[],
  gradLoss: (w: number[], x: number[], y: number) => number[],
  lr: number = 0.01,
  outerEpochs: number = 20,
  innerSteps?: number,
): { w: number[]; history: number[] } {
  const n = data.length;
  const d = w0.length;
  const m = innerSteps ?? 2 * n;
  let w = [...w0];
  const history: number[] = [];

  for (let s = 0; s < outerEpochs; s++) {
    const wRef = [...w];
    const fullGrad = new Array(d).fill(0);
    for (let i = 0; i < n; i++) {
      const g = gradLoss(wRef, data[i], labels[i]);
      for (let j = 0; j < d; j++) fullGrad[j] += g[j] / n;
    }

    for (let t = 0; t < m; t++) {
      const i = Math.floor(Math.random() * n);
      const gCurrent = gradLoss(w, data[i], labels[i]);
      const gRef = gradLoss(wRef, data[i], labels[i]);

      const correctedGrad = gCurrent.map((gc, j) => gc - gRef[j] + fullGrad[j]);
      w = w.map((wj, j) => wj - lr * correctedGrad[j]);
    }

    const loss =
      data.reduce((sum, xi, i) => {
        const pred = w.reduce((s, wj, j) => s + wj * xi[j], 0);
        return sum + (pred - labels[i]) ** 2;
      }, 0) /
      (2 * n);
    history.push(loss);
  }

  return { w, history };
}

function saga(
  data: number[][],
  labels: number[],
  w0: number[],
  gradLoss: (w: number[], x: number[], y: number) => number[],
  lr: number = 0.001,
  epochs: number = 50,
): { w: number[]; history: number[] } {
  const n = data.length;
  const d = w0.length;
  let w = [...w0];
  const history: number[] = [];

  const storedGrads: number[][] = data.map((xi, i) => gradLoss(w, xi, labels[i]));
  const avgGrad = new Array(d).fill(0);
  for (const g of storedGrads) {
    for (let j = 0; j < d; j++) avgGrad[j] += g[j] / n;
  }

  for (let epoch = 0; epoch < epochs; epoch++) {
    for (let t = 0; t < n; t++) {
      const i = Math.floor(Math.random() * n);
      const gNew = gradLoss(w, data[i], labels[i]);
      const gOld = storedGrads[i];

      const direction = gNew.map((gnj, j) => gnj - gOld[j] + avgGrad[j]);

      for (let j = 0; j < d; j++) {
        avgGrad[j] += (gNew[j] - gOld[j]) / n;
      }
      storedGrads[i] = gNew;

      w = w.map((wj, j) => wj - lr * direction[j]);
    }

    const loss =
      data.reduce((sum, xi, i) => {
        const pred = w.reduce((s, wj, j) => s + wj * xi[j], 0);
        return sum + (pred - labels[i]) ** 2;
      }, 0) /
      (2 * n);
    history.push(loss);
  }

  return { w, history };
}
小结
    

  • SGD 通过随机采样将每步计算量从 O(n) 降到 O(b)，是大规模优化的基础
    • 

  • Mini-batch 大小 b 控制方差-效率权衡，梯度方差以 O(1/b) 速率下降
    • 

  • 学习率调度至关重要：warmup 稳定初始阶段，余弦退火实现平滑收敛
    • 

  • 大批量训练需要配合学习率缩放（线性缩放规则）和 warmup 策略
    • 

  • SVRG 和 SAGA 通过方差缩减技术实现线性收敛速率，适用于有限和优化
    • 

  • 梯度噪声具有隐式正则化效果，有助于泛化但需要适当控制
    •
