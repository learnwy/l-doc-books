微积分在图形学中的应用

核心概念

计算机图形学是微积分最密集的工程应用领域之一。参数曲线和曲面由微分几何描述——切线、法线、曲率都是导数的几何化身。光线追踪中的着色方程（渲染方程）本质是一个半球面上的积分。物理模拟中物体的运动由常微分方程控制，需要数值积分来推进时间步。从 Bézier 曲线的求值到全局光照的蒙特卡洛采样，微积分贯穿图形学的每个核心环节。

| 图形学领域 | 微积分工具 | 核心运算            | 典型算法         |
| ---------- | ---------- | ------------------- | ---------------- | --- | --- | --- | -------- |
| 曲线造型   | 参数导数   | de Casteljau + 求导 | Bézier, B-spline |
| 光线追踪   | 半球积分   | 渲染方程求解        | Path tracing     |
| 物理模拟   | ODE 积分   | 欧拉/RK4 时间步进   | Verlet, RK4      |
| 法线计算   | 偏导叉积   | ∂r/∂u × ∂r/∂v       | Phong 着色       |
| 曲率分析   | 二阶导数   | κ =                 | r'×r''           | /   | r'  | ³   | 网格简化 |


Bézier 曲线与参数微分
Bézier 曲线是图形学中最基础的参数曲线。n 次 Bézier 曲线由 n+1 个控制点和 Bernstein 基函数定义：B(t) = Σ Cᵢ Bᵢ,ₙ(t)。它的导数 B'(t) 是一条 n-1 次 Bézier 曲线，控制点为 n(Cᵢ₊₁ - Cᵢ)。这个递推性质使得切线、加速度和曲率的计算非常优雅。


type Vec2 = [number, number];
type Vec3 = [number, number, number];

const bernstein = (n: number, i: number, t: number): number => {
  let coeff = 1;
  for (let k = 0; k < i; k++) coeff = (coeff * (n - k)) / (k + 1);
  return coeff * Math.pow(t, i) * Math.pow(1 - t, n - i);
};

const bezierEval = (points: Vec2[], t: number): Vec2 => {
  const n = points.length - 1;
  let x = 0,
    y = 0;
  for (let i = 0; i <= n; i++) {
    const b = bernstein(n, i, t);
    x += points[i][0] * b;
    y += points[i][1] * b;
  }
  return [x, y];
};

const bezierDerivativePoints = (points: Vec2[]): Vec2[] => {
  const n = points.length - 1;
  return Array.from(
    { length: n },
    (_, i) => [n * (points[i + 1][0] - points[i][0]), n * (points[i + 1][1] - points[i][1])] as Vec2,
  );
};

const bezierTangent = (points: Vec2[], t: number): Vec2 => {
  const derivPoints = bezierDerivativePoints(points);
  return bezierEval(derivPoints, t);
};

const bezierNormal = (points: Vec2[], t: number): Vec2 => {
  const [tx, ty] = bezierTangent(points, t);
  const len = Math.sqrt(tx * tx + ty * ty);
  return [-ty / len, tx / len];
};

const bezierCurvature = (points: Vec2[], t: number): number => {
  const d1Points = bezierDerivativePoints(points);
  const d2Points = bezierDerivativePoints(d1Points);
  const [dx, dy] = bezierEval(d1Points, t);
  const [ddx, ddy] = bezierEval(d2Points, t);
  const cross = dx * ddy - dy * ddx;
  const speed = Math.pow(dx * dx + dy * dy, 1.5);
  return Math.abs(cross) / speed;
};

const bezierArcLength = (points: Vec2[], tRange: [number, number] = [0, 1], n: number = 1000): number => {
  const [ta, tb] = tRange;
  const dt = (tb - ta) / n;
  const derivPoints = bezierDerivativePoints(points);
  let length = 0;
  for (let i = 0; i <= n; i++) {
    const t = ta + i * dt;
    const w = i === 0 || i === n ? 0.5 : 1;
    const [dx, dy] = bezierEval(derivPoints, t);
    length += w * Math.sqrt(dx * dx + dy * dy);
  }
  return length * dt;
};
渲染方程与光线积分
渲染方程描述了场景中每个点的出射辐射亮度 Lₒ(x, ωₒ)，它等于自发光加上入射光经 BRDF 反射后在半球面上的积分：Lₒ(x, ωₒ) = Lₑ + ∫_Ω f(ωᵢ, ωₒ) Lᵢ(x, ωᵢ) (ωᵢ · n) dωᵢ。这个积分没有解析解，路径追踪通过蒙特卡洛方法来估计它。


const uniformHemisphereSample = (): Vec3 => {
  const u1 = Math.random();
  const u2 = Math.random();
  const cosTheta = u1;
  const sinTheta = Math.sqrt(1 - cosTheta * cosTheta);
  const phi = 2 * Math.PI * u2;
  return [sinTheta * Math.cos(phi), sinTheta * Math.sin(phi), cosTheta];
};

const cosineWeightedSample = (): Vec3 => {
  const u1 = Math.random();
  const u2 = Math.random();
  const cosTheta = Math.sqrt(u1);
  const sinTheta = Math.sqrt(1 - u1);
  const phi = 2 * Math.PI * u2;
  return [sinTheta * Math.cos(phi), sinTheta * Math.sin(phi), cosTheta];
};

const lambertianBRDF = (albedo: Vec3): Vec3 => albedo.map((a) => a / Math.PI) as Vec3;

const estimateDirectLighting = (
  point: Vec3,
  normal: Vec3,
  brdf: Vec3,
  sampleLight: () => { direction: Vec3; radiance: Vec3; pdf: number },
  numSamples: number = 64,
): Vec3 => {
  const result: Vec3 = [0, 0, 0];
  for (let i = 0; i < numSamples; i++) {
    const { direction, radiance, pdf } = sampleLight();
    const cosTheta = direction[0] * normal[0] + direction[1] * normal[1] + direction[2] * normal[2];
    if (cosTheta > 0 && pdf > 0) {
      for (let c = 0; c < 3; c++) {
        result[c] += (brdf[c] * radiance[c] * cosTheta) / pdf;
      }
    }
  }
  return result.map((r) => r / numSamples) as Vec3;
};

const pathTrace = (
  origin: Vec3,
  direction: Vec3,
  maxBounces: number = 5,
  scene: {
    intersect: (o: Vec3, d: Vec3) => { point: Vec3; normal: Vec3; albedo: Vec3 } | null;
    sampleLight: () => { direction: Vec3; radiance: Vec3; pdf: number };
  },
): Vec3 => {
  let throughput: Vec3 = [1, 1, 1];
  const radiance: Vec3 = [0, 0, 0];
  let o = origin;
  let d = direction;
  for (let bounce = 0; bounce < maxBounces; bounce++) {
    const hit = scene.intersect(o, d);
    if (!hit) break;
    const brdf = lambertianBRDF(hit.albedo);
    const direct = estimateDirectLighting(hit.point, hit.normal, brdf, scene.sampleLight, 1);
    for (let c = 0; c < 3; c++) radiance[c] += throughput[c] * direct[c];
    const newDir = cosineWeightedSample();
    const cosTheta = newDir[2];
    const pdf = cosTheta / Math.PI;
    for (let c = 0; c < 3; c++) throughput[c] *= (brdf[c] * cosTheta) / pdf;
    o = hit.point;
    d = newDir;
    const maxComponent = Math.max(...throughput);
    if (bounce > 2 && Math.random() > maxComponent) break;
    if (maxComponent > 0) throughput = throughput.map((t) => t / maxComponent) as Vec3;
  }
  return radiance;
};
物理模拟与 ODE 求解
物理模拟的核心是求解常微分方程 dx/dt = f(t, x)。欧拉方法是最简单的一阶方法，但误差随时间累积。四阶 Runge-Kutta（RK4）方法以每步 4 次函数求值的代价获得 O(h⁴) 精度，是游戏和动画中最常用的积分器。Verlet 积分保持能量守恒，特别适合粒子系统和约束求解。


type State = { position: Vec3; velocity: Vec3 };
type Force = (state: State, t: number) => Vec3;

const eulerStep = (state: State, force: Force, t: number, dt: number): State => {
  const f = force(state, t);
  return {
    position: state.position.map((p, i) => p + state.velocity[i] * dt) as Vec3,
    velocity: state.velocity.map((v, i) => v + f[i] * dt) as Vec3,
  };
};

const rk4Step = (state: State, force: Force, t: number, dt: number): State => {
  const evaluate = (s: State, t: number): { dp: Vec3; dv: Vec3 } => ({
    dp: [...s.velocity] as Vec3,
    dv: force(s, t),
  });
  const k1 = evaluate(state, t);
  const s2: State = {
    position: state.position.map((p, i) => p + k1.dp[i] * dt * 0.5) as Vec3,
    velocity: state.velocity.map((v, i) => v + k1.dv[i] * dt * 0.5) as Vec3,
  };
  const k2 = evaluate(s2, t + dt * 0.5);
  const s3: State = {
    position: state.position.map((p, i) => p + k2.dp[i] * dt * 0.5) as Vec3,
    velocity: state.velocity.map((v, i) => v + k2.dv[i] * dt * 0.5) as Vec3,
  };
  const k3 = evaluate(s3, t + dt * 0.5);
  const s4: State = {
    position: state.position.map((p, i) => p + k3.dp[i] * dt) as Vec3,
    velocity: state.velocity.map((v, i) => v + k3.dv[i] * dt) as Vec3,
  };
  const k4 = evaluate(s4, t + dt);
  return {
    position: state.position.map((p, i) => p + (dt / 6) * (k1.dp[i] + 2 * k2.dp[i] + 2 * k3.dp[i] + k4.dp[i])) as Vec3,
    velocity: state.velocity.map((v, i) => v + (dt / 6) * (k1.dv[i] + 2 * k2.dv[i] + 2 * k3.dv[i] + k4.dv[i])) as Vec3,
  };
};

const verletStep = (
  positions: Vec3[],
  prevPositions: Vec3[],
  accelerations: Vec3[],
  dt: number,
): { newPositions: Vec3[]; newPrevPositions: Vec3[] } => {
  const newPositions = positions.map(
    (pos, i) => pos.map((p, j) => 2 * p - prevPositions[i][j] + accelerations[i][j] * dt * dt) as Vec3,
  );
  return { newPositions, newPrevPositions: positions };
};

const simulateSpring = (
  anchor: Vec3,
  initial: State,
  stiffness: number,
  damping: number,
  dt: number,
  steps: number,
): State[] => {
  const springForce: Force = (state) => {
    const displacement = state.position.map((p, i) => anchor[i] - p);
    return displacement.map((d, i) => stiffness * d - damping * state.velocity[i]) as Vec3;
  };
  const trajectory: State[] = [initial];
  let current = initial;
  for (let i = 0; i < steps; i++) {
    current = rk4Step(current, springForce, i * dt, dt);
    trajectory.push(current);
  }
  return trajectory;
};
小结
    

  • Bézier 曲线的导数仍是 Bézier 曲线，使得切线、法线和曲率的计算具有递推优雅性
    • 

  • 渲染方程是半球面上的积分，路径追踪通过蒙特卡洛采样来估计全局光照
    • 

  • RK4 以 O(h⁴) 精度成为物理模拟的标准积分器，Verlet 积分保持能量守恒

  • 重要性采样通过匹配 BRDF 分布大幅降低渲染噪声
