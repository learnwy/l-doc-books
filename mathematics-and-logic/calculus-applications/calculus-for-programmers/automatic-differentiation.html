自动微分

核心概念

自动微分（Automatic Differentiation, AD）是一种精确计算函数导数的技术，它既不是符号微分（展开求导公式），也不是数值微分（差分近似），而是通过分解复合函数并系统地应用链式法则来计算导数。自动微分的核心洞察是：任何可计算函数，无论多复杂，都可以分解为有限个基本运算（加减乘除、三角函数、指数等），而每个基本运算的导数是已知的。通过链式法则将这些局部导数组合起来，就得到整个函数的精确导数。

前向模式自动微分
前向模式 AD 基于对偶数（Dual Number）实现。对偶数 a + bε 中 ε² = 0，通过在普通计算中附带一个"微分分量"，可以在一次前向传播中同时计算函数值和某个方向的导数。前向模式每次计算一个输入变量的导数，因此适合输入维度小于输出维度的场景。


class Dual {
  constructor(
    readonly value: number,
    readonly deriv: number,
  ) {}

  static variable(x: number): Dual {
    return new Dual(x, 1);
  }

  static constant(x: number): Dual {
    return new Dual(x, 0);
  }

  add(other: Dual): Dual {
    return new Dual(this.value + other.value, this.deriv + other.deriv);
  }

  sub(other: Dual): Dual {
    return new Dual(this.value - other.value, this.deriv - other.deriv);
  }

  mul(other: Dual): Dual {
    return new Dual(this.value * other.value, this.value * other.deriv + this.deriv * other.value);
  }

  div(other: Dual): Dual {
    return new Dual(
      this.value / other.value,
      (this.deriv * other.value - this.value * other.deriv) / (other.value * other.value),
    );
  }

  sin(): Dual {
    return new Dual(Math.sin(this.value), this.deriv * Math.cos(this.value));
  }

  cos(): Dual {
    return new Dual(Math.cos(this.value), -this.deriv * Math.sin(this.value));
  }

  exp(): Dual {
    const e = Math.exp(this.value);
    return new Dual(e, this.deriv * e);
  }

  log(): Dual {
    return new Dual(Math.log(this.value), this.deriv / this.value);
  }

  pow(n: number): Dual {
    return new Dual(Math.pow(this.value, n), this.deriv * n * Math.pow(this.value, n - 1));
  }
}

const forwardModeJacobian = (f: (x: Dual[]) => Dual[], x: number[]): number[][] => {
  const n = x.length;
  const jacobian: number[][] = [];
  const baseInput = x.map((v) => Dual.constant(v));
  const y0 = f(baseInput);
  for (let j = 0; j < n; j++) {
    const input = x.map((v, i) => (i === j ? Dual.variable(v) : Dual.constant(v)));
    const output = f(input);
    if (jacobian.length === 0) {
      for (let i = 0; i < output.length; i++) jacobian.push(new Array(n));
    }
    for (let i = 0; i < output.length; i++) {
      jacobian[i][j] = output[i].deriv;
    }
  }
  return jacobian;
};
反向模式自动微分
反向模式 AD 是深度学习反向传播的数学基础。它先进行前向传播记录计算图，然后从输出开始反向传播梯度。反向模式每次计算一个输出对所有输入的梯度，因此当输出维度远小于输入维度时（如标量损失函数），反向模式比前向模式高效得多。


type Op = 'add' | 'mul' | 'sin' | 'cos' | 'exp' | 'log' | 'pow' | 'relu' | 'const';

interface TapeEntry {
  value: number;
  grad: number;
  op: Op;
  parents: number[];
  extra?: number;
}

class ReverseModeAD {
  private tape: TapeEntry[] = [];

  variable(value: number): number {
    const idx = this.tape.length;
    this.tape.push({ value, grad: 0, op: 'const', parents: [] });
    return idx;
  }

  add(a: number, b: number): number {
    const idx = this.tape.length;
    this.tape.push({
      value: this.tape[a].value + this.tape[b].value,
      grad: 0,
      op: 'add',
      parents: [a, b],
    });
    return idx;
  }

  mul(a: number, b: number): number {
    const idx = this.tape.length;
    this.tape.push({
      value: this.tape[a].value * this.tape[b].value,
      grad: 0,
      op: 'mul',
      parents: [a, b],
    });
    return idx;
  }

  sin(a: number): number {
    const idx = this.tape.length;
    this.tape.push({ value: Math.sin(this.tape[a].value), grad: 0, op: 'sin', parents: [a] });
    return idx;
  }

  exp(a: number): number {
    const idx = this.tape.length;
    this.tape.push({ value: Math.exp(this.tape[a].value), grad: 0, op: 'exp', parents: [a] });
    return idx;
  }

  relu(a: number): number {
    const idx = this.tape.length;
    this.tape.push({ value: Math.max(0, this.tape[a].value), grad: 0, op: 'relu', parents: [a] });
    return idx;
  }

  backward(outputIdx: number): void {
    this.tape[outputIdx].grad = 1;
    for (let i = outputIdx; i >= 0; i--) {
      const entry = this.tape[i];
      if (entry.grad === 0) continue;
      const [a, b] = entry.parents;
      switch (entry.op) {
        case 'add':
          this.tape[a].grad += entry.grad;
          this.tape[b].grad += entry.grad;
          break;
        case 'mul':
          this.tape[a].grad += entry.grad * this.tape[b].value;
          this.tape[b].grad += entry.grad * this.tape[a].value;
          break;
        case 'sin':
          this.tape[a].grad += entry.grad * Math.cos(this.tape[a].value);
          break;
        case 'exp':
          this.tape[a].grad += entry.grad * entry.value;
          break;
        case 'relu':
          this.tape[a].grad += entry.grad * (this.tape[a].value > 0 ? 1 : 0);
          break;
      }
    }
  }

  getGrad(idx: number): number {
    return this.tape[idx].grad;
  }

  getValue(idx: number): number {
    return this.tape[idx].value;
  }
}
高阶导数与 Hessian 向量积
高阶自动微分通过嵌套对偶数或对反向模式再做一次微分来实现。Hessian 向量积 Hv 可以通过"先反向再前向"高效计算，复杂度与函数求值相同量级，避免了显式构造 O(n²) 的 Hessian 矩阵。


class HigherOrderDual {
  constructor(
    readonly value: number,
    readonly d1: number,
    readonly d2: number,
  ) {}

  static variable(x: number): HigherOrderDual {
    return new HigherOrderDual(x, 1, 0);
  }

  static constant(x: number): HigherOrderDual {
    return new HigherOrderDual(x, 0, 0);
  }

  add(other: HigherOrderDual): HigherOrderDual {
    return new HigherOrderDual(this.value + other.value, this.d1 + other.d1, this.d2 + other.d2);
  }

  mul(other: HigherOrderDual): HigherOrderDual {
    return new HigherOrderDual(
      this.value * other.value,
      this.value * other.d1 + this.d1 * other.value,
      this.value * other.d2 + 2 * this.d1 * other.d1 + this.d2 * other.value,
    );
  }

  sin(): HigherOrderDual {
    const s = Math.sin(this.value);
    const c = Math.cos(this.value);
    return new HigherOrderDual(s, this.d1 * c, this.d2 * c - this.d1 * this.d1 * s);
  }

  exp(): HigherOrderDual {
    const e = Math.exp(this.value);
    return new HigherOrderDual(e, this.d1 * e, (this.d2 + this.d1 * this.d1) * e);
  }
}

const hessianVectorProduct = (f: (x: number[]) => number, x: number[], v: number[], h: number = 1e-5): number[] => {
  const grad = (x: number[]): number[] =>
    x.map((_, i) => {
      const xp = [...x];
      xp[i] += h;
      const xm = [...x];
      xm[i] -= h;
      return (f(xp) - f(xm)) / (2 * h);
    });
  const xpv = x.map((xi, i) => xi + h * v[i]);
  const xmv = x.map((xi, i) => xi - h * v[i]);
  const gp = grad(xpv);
  const gm = grad(xmv);
  return gp.map((g, i) => (g - gm[i]) / (2 * h));
};
计算图优化
实际 AD 框架（PyTorch、JAX）通过计算图优化来提升性能。常见优化包括：公共子表达式消除（CSE）避免重复计算；算子融合将多个小算子合并为一个内核调用；检查点策略（gradient checkpointing）在内存与计算之间做权衡——丢弃中间结果，需要时重新计算。


interface GraphNode {
  id: number;
  op: string;
  inputs: number[];
  value?: number;
  refCount: number;
}

class ComputeGraph {
  private nodes: GraphNode[] = [];

  addNode(op: string, inputs: number[]): number {
    const id = this.nodes.length;
    for (const i of inputs) this.nodes[i].refCount++;
    this.nodes.push({ id, op, inputs, refCount: 0 });
    return id;
  }

  input(value: number): number {
    const id = this.nodes.length;
    this.nodes.push({ id, op: 'input', inputs: [], value, refCount: 0 });
    return id;
  }

  eliminateCSE(): Map<number, number> {
    const canonical = new Map<string, number>();
    const remap = new Map<number, number>();
    for (const node of this.nodes) {
      const remappedInputs = node.inputs.map((i) => remap.get(i) ?? i);
      const key = `${node.op}(${remappedInputs.join(',')})`;
      if (node.op === 'input') {
        remap.set(node.id, node.id);
      } else if (canonical.has(key)) {
        remap.set(node.id, canonical.get(key)!);
      } else {
        canonical.set(key, node.id);
        remap.set(node.id, node.id);
      }
    }
    return remap;
  }

  findCheckpointNodes(memoryBudget: number): Set<number> {
    const checkpoints = new Set<number>();
    const sortedByRef = [...this.nodes].filter((n) => n.op !== 'input').sort((a, b) => b.refCount - a.refCount);
    let savedMemory = 0;
    for (const node of sortedByRef) {
      if (savedMemory >= memoryBudget) break;
      if (node.refCount > 1) {
        checkpoints.add(node.id);
        savedMemory += node.refCount - 1;
      }
    }
    return checkpoints;
  }
}
小结
    

  • 自动微分通过分解复合函数并系统应用链式法则，精确到机器精度地计算导数
    • 

  • 前向模式基于对偶数，每次计算一个输入方向的导数，适合输入少输出多的场景
    • 

  • 反向模式通过记录计算图并反向传播梯度，是深度学习框架的核心算法
    •
