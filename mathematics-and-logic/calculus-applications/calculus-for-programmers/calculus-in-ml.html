微积分在机器学习中的应用

核心概念

微积分是机器学习的数学引擎。梯度下降通过求损失函数的偏导数来更新参数；反向传播通过链式法则计算深层网络中每个权重的梯度；概率模型中的积分用于计算边缘似然和期望值。从线性回归到 Transformer，几乎所有机器学习模型的训练都建立在微积分之上。理解这些数学基础，是从"调参"走向"设计"的关键一步。

| 微积分工具  | ML 中的角色 | 具体应用               | 关键公式                     |
| ----------- | ----------- | ---------------------- | ---------------------------- | --------- |
| 偏导数      | 参数敏感度  | 损失对权重的梯度       | ∂L/∂wᵢ                       |
| 链式法则    | 梯度传播    | 反向传播算法           | ∂L/∂w = ∂L/∂z · ∂z/∂w        |
| 积分        | 期望计算    | 边缘似然、ELBO         | ∫ p(x                        | z)p(z) dz |
| Taylor 展开 | 近似        | 二阶优化、损失曲面分析 | f(x+δ) ≈ f(x) + ∇f·δ + ½δᵀHδ |
| 极值条件    | 解析解      | 正规方程、闭式更新     | ∇L = 0 → w*                 |


损失函数与梯度下降
损失函数度量模型预测与真实值之间的差距。均方误差（MSE）用于回归，交叉熵用于分类。梯度下降通过计算损失函数对每个参数的偏导数，沿负梯度方向更新参数。随机梯度下降（SGD）用小批量样本估计梯度，在大规模数据上实现高效训练。


const mseLoss = (predictions: number[], targets: number[]): number =>
  predictions.reduce((sum, pred, i) => sum + (pred - targets[i]) ** 2, 0) / predictions.length;

const crossEntropyLoss = (probs: number[], targets: number[]): number =>
  -targets.reduce((sum, t, i) => sum + t * Math.log(probs[i] + 1e-15), 0) / targets.length;

const linearRegressionGradient = (
  X: number[][],
  y: number[],
  w: number[],
  b: number,
): { gradW: number[]; gradB: number } => {
  const n = X.length;
  const dim = w.length;
  const gradW = new Array(dim).fill(0);
  let gradB = 0;
  for (let i = 0; i < n; i++) {
    const pred = X[i].reduce((s, x, j) => s + x * w[j], 0) + b;
    const error = pred - y[i];
    for (let j = 0; j < dim; j++) {
      gradW[j] += (2 / n) * error * X[i][j];
    }
    gradB += (2 / n) * error;
  }
  return { gradW, gradB };
};

const sgd = (
  X: number[][],
  y: number[],
  lr: number = 0.01,
  epochs: number = 100,
  batchSize: number = 32,
): { w: number[]; b: number; lossHistory: number[] } => {
  const dim = X[0].length;
  const w = new Array(dim).fill(0);
  let b = 0;
  const lossHistory: number[] = [];
  for (let epoch = 0; epoch < epochs; epoch++) {
    const indices = Array.from({ length: X.length }, (_, i) => i);
    for (let i = indices.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [indices[i], indices[j]] = [indices[j], indices[i]];
    }
    for (let start = 0; start < X.length; start += batchSize) {
      const batch = indices.slice(start, start + batchSize);
      const batchX = batch.map((i) => X[i]);
      const batchY = batch.map((i) => y[i]);
      const { gradW, gradB } = linearRegressionGradient(batchX, batchY, w, b);
      for (let j = 0; j < dim; j++) w[j] -= lr * gradW[j];
      b -= lr * gradB;
    }
    const predictions = X.map((xi) => xi.reduce((s, x, j) => s + x * w[j], 0) + b);
    lossHistory.push(mseLoss(predictions, y));
  }
  return { w, b, lossHistory };
};
反向传播与链式法则
反向传播是链式法则在计算图上的系统应用。前向传播计算每层的输出，反向传播从输出层开始，逐层将梯度传回输入层。每层的梯度等于上游梯度乘以该层操作的局部梯度。这种结构化的梯度计算使得任意深度网络的训练成为可能。


class DenseLayer {
  W: number[][];
  b: number[];
  input: number[] = [];
  z: number[] = [];
  gradW: number[][] = [];
  gradB: number[] = [];

  constructor(inputDim: number, outputDim: number) {
    this.W = Array.from({ length: outputDim }, () =>
      Array.from({ length: inputDim }, () => (Math.random() - 0.5) * Math.sqrt(2 / inputDim)),
    );
    this.b = new Array(outputDim).fill(0);
    this.gradW = Array.from({ length: outputDim }, () => new Array(inputDim).fill(0));
    this.gradB = new Array(outputDim).fill(0);
  }

  forward(x: number[]): number[] {
    this.input = x;
    this.z = this.W.map((row, i) => row.reduce((s, w, j) => s + w * x[j], 0) + this.b[i]);
    return this.z;
  }

  backward(gradOutput: number[]): number[] {
    const inputDim = this.input.length;
    this.gradW = gradOutput.map((g) => this.input.map((x) => g * x));
    this.gradB = [...gradOutput];
    const gradInput = new Array(inputDim).fill(0);
    for (let j = 0; j < inputDim; j++) {
      for (let i = 0; i < gradOutput.length; i++) {
        gradInput[j] += gradOutput[i] * this.W[i][j];
      }
    }
    return gradInput;
  }

  update(lr: number): void {
    for (let i = 0; i < this.W.length; i++) {
      for (let j = 0; j < this.W[i].length; j++) {
        this.W[i][j] -= lr * this.gradW[i][j];
      }
      this.b[i] -= lr * this.gradB[i];
    }
  }
}

const relu = (z: number[]): number[] => z.map((v) => Math.max(0, v));
const reluGrad = (z: number[], gradOutput: number[]): number[] => z.map((v, i) => (v > 0 ? gradOutput[i] : 0));

const softmax = (z: number[]): number[] => {
  const maxZ = Math.max(...z);
  const expZ = z.map((v) => Math.exp(v - maxZ));
  const sumExp = expZ.reduce((a, b) => a + b, 0);
  return expZ.map((e) => e / sumExp);
};
正则化的微积分视角
正则化通过在损失函数中添加惩罚项来防止过拟合。L2 正则化（权重衰减）等价于在损失函数中添加 λ‖w‖²，其梯度为 2λw，效果是每步将权重缩小一个比例。从贝叶斯角度看，L2 正则化等价于对权重施加零均值高斯先验。L1 正则化 λ|w| 的梯度为 λ·sign(w)，促进权重稀疏。


const l2Regularization = (w: number[], lambda: number): { penalty: number; gradient: number[] } => ({
  penalty: lambda * w.reduce((s, wi) => s + wi * wi, 0),
  gradient: w.map((wi) => 2 * lambda * wi),
});

const l1Regularization = (w: number[], lambda: number): { penalty: number; gradient: number[] } => ({
  penalty: lambda * w.reduce((s, wi) => s + Math.abs(wi), 0),
  gradient: w.map((wi) => lambda * Math.sign(wi)),
});

const elasticNet = (w: number[], lambda: number, alpha: number = 0.5): { penalty: number; gradient: number[] } => {
  const l1 = l1Regularization(w, lambda * alpha);
  const l2 = l2Regularization(w, lambda * (1 - alpha));
  return {
    penalty: l1.penalty + l2.penalty,
    gradient: l1.gradient.map((g, i) => g + l2.gradient[i]),
  };
};

const trainWithRegularization = (
  X: number[][],
  y: number[],
  lambda: number = 0.01,
  lr: number = 0.01,
  epochs: number = 100,
): { w: number[]; lossHistory: number[] } => {
  const dim = X[0].length;
  const w = new Array(dim).fill(0);
  const lossHistory: number[] = [];
  for (let epoch = 0; epoch < epochs; epoch++) {
    const predictions = X.map((xi) => xi.reduce((s, x, j) => s + x * w[j], 0));
    const dataLoss = mseLoss(predictions, y);
    const reg = l2Regularization(w, lambda);
    lossHistory.push(dataLoss + reg.penalty);
    const n = X.length;
    for (let j = 0; j < dim; j++) {
      let grad = 0;
      for (let i = 0; i < n; i++) {
        grad += (2 / n) * (predictions[i] - y[i]) * X[i][j];
      }
      w[j] -= lr * (grad + reg.gradient[j]);
    }
  }
  return { w, lossHistory };
};
概率模型中的积分
在概率机器学习中，积分用于计算边缘似然、后验分布和期望值。最大似然估计通过对数似然的导数为零得到参数估计。变分推断通过优化证据下界（ELBO）来近似不可解的后验积分。这些积分通常没有解析解，需要数值近似或蒙特卡洛采样。


const logLikelihoodGaussian = (data: number[], mu: number, sigma: number): number =>
  data.reduce((s, x) => s - 0.5 * Math.log(2 * Math.PI * sigma * sigma) - (x - mu) ** 2 / (2 * sigma * sigma), 0);

const mleGaussian = (data: number[]): { mu: number; sigma: number } => {
  const n = data.length;
  const mu = data.reduce((a, b) => a + b, 0) / n;
  const sigma = Math.sqrt(data.reduce((s, x) => s + (x - mu) ** 2, 0) / n);
  return { mu, sigma };
};

const numericalExpectation = (
  pdf: (x: number) => number,
  g: (x: number) => number,
  range: [number, number],
  n: number = 10000,
): number => {
  const [a, b] = range;
  const h = (b - a) / n;
  let sum = 0;
  for (let i = 0; i <= n; i++) {
    const x = a + i * h;
    const w = i === 0 || i === n ? 0.5 : 1;
    sum += w * g(x) * pdf(x);
  }
  return sum * h;
};

const elboEstimate = (
  logPrior: (z: number[]) => number,
  logLikelihood: (x: number[], z: number[]) => number,
  qSample: () => number[],
  logQ: (z: number[]) => number,
  x: number[],
  numSamples: number = 1000,
): number => {
  let elbo = 0;
  for (let i = 0; i < numSamples; i++) {
    const z = qSample();
    elbo += logLikelihood(x, z) + logPrior(z) - logQ(z);
  }
  return elbo / numSamples;
};

const kLDivergence = (
  p: (x: number) => number,
  q: (x: number) => number,
  range: [number, number],
  n: number = 10000,
): number => {
  const [a, b] = range;
  const h = (b - a) / n;
  let sum = 0;
  for (let i = 0; i <= n; i++) {
    const x = a + i * h;
    const w = i === 0 || i === n ? 0.5 : 1;
    const px = p(x);
    const qx = q(x);
    if (px > 1e-15 && qx > 1e-15) {
      sum += w * px * Math.log(px / qx);
    }
  }
  return sum * h;
};
小结
    

  • 梯度下降通过偏导数迭代优化损失函数，是所有神经网络训练的核心
    • 

  • 反向传播是链式法则在计算图上的系统应用，使深层网络训练成为可能
    • 

  • L2 正则化等价于高斯先验，L1 正则化促进权重稀疏，弹性网结合两者优势
    • 

  • 概率模型中的积分通常不可解，需要变分推断或蒙特卡洛方法近似
    • 

  • 数值稳定性（log-sum-exp、梯度裁剪）是实际 ML 系统中的关键工程问题
