导数与求导法则

核心概念

导数是微积分的核心概念，它描述了函数在某点处的瞬时变化率。几何上，导数是函数图形在该点切线的斜率。定义为极限 f'(a) = lim_{h→0} [f(a+h) - f(a)] / h。导数在编程中无处不在：梯度下降需要计算损失函数的导数，物理模拟需要速度（位置的导数）和加速度（速度的导数），金融中的 Delta 和 Gamma 是期权价格对标的资产价格的导数。

数值微分方法
数值微分通过有限差分近似导数。前向差分 f'(x) ≈ [f(x+h)-f(x)]/h 的精度为 O(h)，中心差分 f'(x) ≈ [f(x+h)-f(x-h)]/(2h) 的精度为 O(h²)。步长 h 的选择需要权衡截断误差（h 越小越好）和舍入误差（h 越大越好），最优步长约为 h* ≈ ε^(1/2)·|x|（前向差分）或 h* ≈ ε^(1/3)·|x|（中心差分），其中 ε 是机器精度。


const forwardDifference = (f: (x: number) => number, x: number, h?: number): number => {
  h = h ?? Math.max(Math.abs(x), 1) * Math.sqrt(Number.EPSILON);
  return (f(x + h) - f(x)) / h;
};

const centralDifference = (f: (x: number) => number, x: number, h?: number): number => {
  h = h ?? Math.max(Math.abs(x), 1) * Math.cbrt(Number.EPSILON);
  return (f(x + h) - f(x - h)) / (2 * h);
};

const secondDerivative = (f: (x: number) => number, x: number, h?: number): number => {
  h = h ?? Math.max(Math.abs(x), 1) * Math.pow(Number.EPSILON, 0.25);
  return (f(x + h) - 2 * f(x) + f(x - h)) / (h * h);
};

const gradient = (f: (x: number[]) => number, x: number[], h?: number): number[] => {
  return x.map((xi, i) => {
    const hi = h ?? Math.max(Math.abs(xi), 1) * Math.cbrt(Number.EPSILON);
    const xPlus = [...x];
    xPlus[i] += hi;
    const xMinus = [...x];
    xMinus[i] -= hi;
    return (f(xPlus) - f(xMinus)) / (2 * hi);
  });
};

const hessian = (f: (x: number[]) => number, x: number[], h?: number): number[][] => {
  const n = x.length;
  const H: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));
  for (let i = 0; i < n; i++) {
    for (let j = i; j < n; j++) {
      const hi = h ?? Math.max(Math.abs(x[i]), 1) * Math.pow(Number.EPSILON, 0.25);
      const hj = h ?? Math.max(Math.abs(x[j]), 1) * Math.pow(Number.EPSILON, 0.25);
      const pp = [...x];
      pp[i] += hi;
      pp[j] += hj;
      const pm = [...x];
      pm[i] += hi;
      pm[j] -= hj;
      const mp = [...x];
      mp[i] -= hi;
      mp[j] += hj;
      const mm = [...x];
      mm[i] -= hi;
      mm[j] -= hj;
      H[i][j] = (f(pp) - f(pm) - f(mp) + f(mm)) / (4 * hi * hj);
      H[j][i] = H[i][j];
    }
  }
  return H;
};
链式法则与反向传播
链式法则 (f∘g)'(x) = f'(g(x))·g'(x) 是深度学习反向传播算法的数学基础。在多层神经网络中，损失函数对每一层参数的梯度通过链式法则逐层计算。


interface DualNumber {
  value: number;
  derivative: number;
}

const dual = (value: number, derivative: number = 0): DualNumber => ({
  value,
  derivative,
});

const dualAdd = (a: DualNumber, b: DualNumber): DualNumber => ({
  value: a.value + b.value,
  derivative: a.derivative + b.derivative,
});

const dualMul = (a: DualNumber, b: DualNumber): DualNumber => ({
  value: a.value * b.value,
  derivative: a.derivative * b.value + a.value * b.derivative,
});

const dualDiv = (a: DualNumber, b: DualNumber): DualNumber => ({
  value: a.value / b.value,
  derivative: (a.derivative * b.value - a.value * b.derivative) / (b.value * b.value),
});

const dualSin = (a: DualNumber): DualNumber => ({
  value: Math.sin(a.value),
  derivative: a.derivative * Math.cos(a.value),
});

const dualExp = (a: DualNumber): DualNumber => ({
  value: Math.exp(a.value),
  derivative: a.derivative * Math.exp(a.value),
});

const dualLog = (a: DualNumber): DualNumber => ({
  value: Math.log(a.value),
  derivative: a.derivative / a.value,
});

const dualPow = (a: DualNumber, n: number): DualNumber => ({
  value: a.value ** n,
  derivative: n * a.value ** (n - 1) * a.derivative,
});

const forwardModeAD = (f: (x: DualNumber) => DualNumber, x: number): { value: number; derivative: number } => {
  const result = f(dual(x, 1));
  return { value: result.value, derivative: result.derivative };
};
高阶导数与 Taylor 近似
高阶导数 f^(n)(x) 描述了函数变化率的变化率。Taylor 定理将函数在某点附近展开为多项式：f(x) ≈ Σ f^(k)(a)/k! · (x-a)^k，余项控制了近似精度。Taylor 近似是数值计算中用多项式逼近复杂函数的理论基础。


const taylorCoefficients = (f: (x: number) => number, a: number, order: number, h: number = 1e-3): number[] => {
  const coeffs: number[] = [f(a)];
  let currentF = f;
  for (let k = 1; k <= order; k++) {
    const prev = currentF;
    currentF = (x: number) => centralDifference(prev, x, h);
    coeffs.push(currentF(a) / factorial(k));
    h *= 1.5;
  }
  return coeffs;
};

const taylorApproximation =
  (coeffs: number[], a: number) =>
  (x: number): number => {
    let result = 0;
    let power = 1;
    for (const c of coeffs) {
      result += c * power;
      power *= x - a;
    }
    return result;
  };

const factorial = (n: number): number => {
  let result = 1;
  for (let i = 2; i <= n; i++) result *= i;
  return result;
};

const padéApproximant = (coeffs: number[], m: number, n: number): { numerator: number[]; denominator: number[] } => {
  const p = new Array(m + 1).fill(0);
  const q = new Array(n + 1).fill(0);
  q[0] = 1;
  for (let i = 0; i <= m; i++) p[i] = coeffs[i] || 0;
  return { numerator: p, denominator: q };
};
导数检验与梯度验证
在实现自动微分或手动推导梯度后，数值微分提供了验证工具。梯度检验（Gradient Checking）是深度学习开发中的标准实践。


const gradientCheck = (
  f: (x: number[]) => number,
  analyticGrad: (x: number[]) => number[],
  x: number[],
  epsilon: number = 1e-5,
): { maxRelError: number; passed: boolean; errors: number[] } => {
  const numGrad = gradient(f, x, epsilon);
  const anaGrad = analyticGrad(x);
  const errors = numGrad.map((ng, i) => {
    const denom = Math.max(Math.abs(ng), Math.abs(anaGrad[i]), 1e-8);
    return Math.abs(ng - anaGrad[i]) / denom;
  });
  const maxRelError = Math.max(...errors);
  return { maxRelError, passed: maxRelError < 1e-5, errors };
};

  • 数值微分的最优步长需要权衡截断误差和舍入误差

  • 前向模式自动微分通过对偶数实现精确且高效的导数计算

  • 梯度检验通过比较解析梯度和数值梯度来验证实现的正确性
