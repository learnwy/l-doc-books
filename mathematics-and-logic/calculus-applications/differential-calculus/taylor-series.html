Taylor 级数与幂级数

核心概念

Taylor 级数将一个光滑函数表示为无穷多项式的和：f(x) = Σ_{n=0}^∞ f^(n)(a)/n! · (x-a)^n。当 a=0 时称为 Maclaurin 级数。Taylor 级数是数值计算的基石——计算机中几乎所有超越函数（sin, cos, exp, log）的实现都基于 Taylor 展开或其变体（Chebyshev 逼近、Padé 近似）。

Taylor 级数的核心价值在于用多项式（计算机最擅长的运算）逼近任意光滑函数，而且可以精确控制逼近误差。对程序员而言，理解 Taylor 级数意味着理解数值库的内部工作原理。

收敛半径与收敛性分析
Taylor 级数在某点展开后，不一定在整个定义域上收敛。收敛半径 R 决定了级数收敛的范围：|x - a| < R 时绝对收敛，|x - a| > R 时发散。R 可以通过比值判别法或 Hadamard 公式计算。


const estimateConvergenceRadius = (coefficients: (n: number) => number, maxN: number = 100): number => {
  let ratios: number[] = [];
  for (let n = 1; n < maxN; n++) {
    const an = coefficients(n);
    const an1 = coefficients(n + 1);
    if (Math.abs(an1) > 1e-300) {
      ratios.push(Math.abs(an / an1));
    }
  }
  if (ratios.length === 0) return Infinity;
  return ratios.slice(-10).reduce((a, b) => a + b, 0) / Math.min(ratios.length, 10);
};

const taylorSeriesEval = (
  derivatives: (n: number) => number,
  center: number,
  x: number,
  maxTerms: number = 50,
  tolerance: number = Number.EPSILON,
): { value: number; terms: number; error: number } => {
  let sum = 0;
  let power = 1;
  let factorial = 1;
  let lastTerm = 0;

  for (let n = 0; n < maxTerms; n++) {
    if (n > 0) {
      power *= x - center;
      factorial *= n;
    }
    const term = (derivatives(n) * power) / factorial;
    sum += term;
    lastTerm = Math.abs(term);
    if (lastTerm < tolerance * Math.abs(sum) && n > 0) {
      return { value: sum, terms: n + 1, error: lastTerm };
    }
  }
  return { value: sum, terms: maxTerms, error: lastTerm };
};

const commonTaylorSeries = {
  exp: (x: number, n: number): number => {
    let sum = 1,
      term = 1;
    for (let k = 1; k <= n; k++) {
      term *= x / k;
      sum += term;
    }
    return sum;
  },
  sin: (x: number, n: number): number => {
    x = (((x % (2 * Math.PI)) + 3 * Math.PI) % (2 * Math.PI)) - Math.PI;
    let sum = x,
      term = x;
    for (let k = 1; k <= n; k++) {
      term *= (-x * x) / (2 * k * (2 * k + 1));
      sum += term;
    }
    return sum;
  },
  cos: (x: number, n: number): number => {
    x = (((x % (2 * Math.PI)) + 3 * Math.PI) % (2 * Math.PI)) - Math.PI;
    let sum = 1,
      term = 1;
    for (let k = 1; k <= n; k++) {
      term *= (-x * x) / ((2 * k - 1) * (2 * k));
      sum += term;
    }
    return sum;
  },
  log1p: (x: number, n: number): number => {
    if (Math.abs(x) >= 1) throw new Error('|x| must be < 1');
    let sum = 0,
      power = x;
    for (let k = 1; k <= n; k++) {
      sum += ((k % 2 === 1 ? 1 : -1) * power) / k;
      power *= x;
    }
    return sum;
  },
};
Padé 近似与有理逼近
Padé 近似用有理函数 P_m(x)/Q_n(x) 逼近函数，比 Taylor 多项式在更大范围内保持精度。[m/n] Padé 近似的分子是 m 次多项式，分母是 n 次多项式，总共 m+n+1 个系数通过匹配 Taylor 展开的前 m+n+1 项确定。


const padeApproximant = (taylorCoeffs: number[], m: number, n: number): { eval: (x: number) => number } => {
  const p = new Array(m + 1).fill(0);
  const q = new Array(n + 1).fill(0);
  q[0] = 1;

  for (let i = 0; i <= m; i++) {
    p[i] = taylorCoeffs[i] || 0;
    for (let j = 1; j <= Math.min(i, n); j++) {
      p[i] -= q[j] * (taylorCoeffs[i - j] || 0);
    }
  }

  for (let i = 1; i <= n; i++) {
    let sum = taylorCoeffs[m + i] || 0;
    for (let j = 1; j < i; j++) {
      sum += q[j] * (taylorCoeffs[m + i - j] || 0);
    }
    q[i] = -sum;
  }

  return {
    eval: (x: number): number => {
      let num = 0,
        den = 0,
        xPow = 1;
      for (let i = 0; i <= m; i++) {
        num += p[i] * xPow;
        xPow *= x;
      }
      xPow = 1;
      for (let i = 0; i <= n; i++) {
        den += q[i] * xPow;
        xPow *= x;
      }
      return num / den;
    },
  };
};

const compareApproximations = (
  f: (x: number) => number,
  taylorCoeffs: number[],
  xRange: [number, number],
  points: number = 100,
): Array<{ x: number; exact: number; taylor: number; pade: number }> => {
  const [a, b] = xRange;
  const n = Math.floor(taylorCoeffs.length / 2);
  const pade = padeApproximant(taylorCoeffs, n, n);

  return Array.from({ length: points }, (_, i) => {
    const x = a + ((b - a) * i) / (points - 1);
    let taylorVal = 0,
      xPow = 1;
    for (const c of taylorCoeffs) {
      taylorVal += c * xPow;
      xPow *= x;
    }
    return { x, exact: f(x), taylor: taylorVal, pade: pade.eval(x) };
  });
};
计算机中超越函数的实现
现代数学库中 sin、cos、exp 等函数的实现通常结合了参数缩减（Argument Reduction）和多项式/有理逼近。以 sin(x) 为例：首先将 x 缩减到 [-π/4, π/4]，然后用 minimax 多项式逼近。


const sinImplementation = (x: number): number => {
  x = x % (2 * Math.PI);
  if (x < 0) x += 2 * Math.PI;

  let sign = 1;
  if (x > Math.PI) {
    x -= Math.PI;
    sign = -1;
  }
  if (x > Math.PI / 2) x = Math.PI - x;

  const x2 = x * x;
  const result =
    x *
    (1 +
      x2 * (-1 / 6 + x2 * (1 / 120 + x2 * (-1 / 5040 + x2 * (1 / 362880 + x2 * (-1 / 39916800 + x2 / 6227020800))))));
  return sign * result;
};

const expImplementation = (x: number): number => {
  if (x === 0) return 1;
  const ln2 = Math.LN2;
  const k = Math.round(x / ln2);
  const r = x - k * ln2;
  const r2 = r * r;
  const poly = 1 + r + r2 / 2 + (r2 * r) / 6 + (r2 * r2) / 24 + (r2 * r2 * r) / 120 + (r2 * r2 * r2) / 720;
  return poly * 2 ** k;
};
小结
    

  • Taylor 级数用多项式逼近光滑函数，是数值计算和函数求值的理论基础
    • 

  • 收敛半径决定了 Taylor 级数的有效范围，超出范围需要参数缩减
    • 

  • Padé 近似在相同阶数下比 Taylor 多项式在更大范围内保持精度
    • 

  • 计算机中的超越函数实现结合参数缩减和多项式逼近，达到机器精度
    • 

  • 理解 Taylor 级数对程序员意味着理解浮点运算精度的理论边界
