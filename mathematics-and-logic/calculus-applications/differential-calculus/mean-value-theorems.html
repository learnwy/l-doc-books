中值定理族

核心概念

中值定理是微积分中连接函数局部行为（导数）与全局行为（函数值变化）的桥梁。Rolle 定理、Lagrange 中值定理和 Cauchy 中值定理构成了层层递进的定理族。它们不仅是理论分析的基石，更在数值分析中提供了误差估计的关键工具。

中值定理的核心洞察：如果函数足够"光滑"，那么在任意两点之间，必存在某点的瞬时变化率等于平均变化率。

Lagrange 中值定理与误差分析
Lagrange 中值定理指出：如果 f 在 [a,b] 上连续，在 (a,b) 上可微，则存在 c ∈ (a,b) 使得 f'(c) = [f(b)-f(a)]/(b-a)。这个定理是数值分析中误差估计的核心工具。


插值误差：如果用多项式 p(x) 在节点 x₀,...,xₙ 处插值 f(x)，则误差为 f(x)-p(x) = f^(n+1)(ξ)/(n+1)! · Π(x-xᵢ)，其中 ξ 依赖于 x。


const verifyMVT = (
  f: (x: number) => number,
  fPrime: (x: number) => number,
  a: number,
  b: number,
  numSearch: number = 10000,
): { found: boolean; c: number; slope: number; fPrimeC: number } => {
  const slope = (f(b) - f(a)) / (b - a);
  let bestC = a;
  let bestDiff = Infinity;

  for (let i = 0; i < numSearch; i++) {
    const c = a + ((b - a) * (i + 0.5)) / numSearch;
    const diff = Math.abs(fPrime(c) - slope);
    if (diff < bestDiff) {
      bestDiff = diff;
      bestC = c;
    }
  }

  return {
    found: bestDiff < 1e-6,
    c: bestC,
    slope,
    fPrimeC: fPrime(bestC),
  };
};

const interpolationError = (f: (x: number) => number, nodes: number[], x: number, nPlus1Derivative: number): number => {
  const omega = nodes.reduce((prod, xi) => prod * (x - xi), 1);
  const factorial = Array.from({ length: nodes.length + 1 }, (_, i) => i).reduce((a, b) => a * Math.max(b, 1), 1);
  return Math.abs((nPlus1Derivative * omega) / factorial);
};

const numericalErrorBound = (
  f: (x: number) => number,
  a: number,
  b: number,
  method: 'trapezoidal' | 'simpson' | 'midpoint',
  n: number,
): { estimate: number; errorBound: number } => {
  const h = (b - a) / n;
  let integral = 0;

  switch (method) {
    case 'trapezoidal': {
      integral = (f(a) + f(b)) / 2;
      for (let i = 1; i < n; i++) integral += f(a + i * h);
      integral *= h;
      const M2 = estimateMaxDerivative(f, a, b, 2);
      return { estimate: integral, errorBound: (M2 * (b - a) * h * h) / 12 };
    }
    case 'simpson': {
      integral = f(a) + f(b);
      for (let i = 1; i < n; i += 2) integral += 4 * f(a + i * h);
      for (let i = 2; i < n; i += 2) integral += 2 * f(a + i * h);
      integral *= h / 3;
      const M4 = estimateMaxDerivative(f, a, b, 4);
      return { estimate: integral, errorBound: (M4 * (b - a) * h ** 4) / 180 };
    }
    case 'midpoint': {
      for (let i = 0; i < n; i++) integral += f(a + (i + 0.5) * h);
      integral *= h;
      const M2m = estimateMaxDerivative(f, a, b, 2);
      return { estimate: integral, errorBound: (M2m * (b - a) * h * h) / 24 };
    }
  }
};

const estimateMaxDerivative = (
  f: (x: number) => number,
  a: number,
  b: number,
  order: number,
  samples: number = 1000,
): number => {
  let maxDeriv = 0;
  const h = Math.pow(Number.EPSILON, 1 / (order + 2));
  for (let i = 0; i <= samples; i++) {
    const x = a + ((b - a) * i) / samples;
    let deriv: number;
    if (order === 2) {
      deriv = Math.abs((f(x + h) - 2 * f(x) + f(x - h)) / (h * h));
    } else {
      deriv = Math.abs((f(x + 2 * h) - 4 * f(x + h) + 6 * f(x) - 4 * f(x - h) + f(x - 2 * h)) / h ** 4);
    }
    maxDeriv = Math.max(maxDeriv, deriv);
  }
  return maxDeriv;
};
微分中值定理在优化中的应用
中值定理为优化算法的收敛性分析提供了理论基础。Lipschitz 条件 |f(x)-f(y)| ≤ L|x-y| 是中值定理的直接推论（L = max|f'|），它保证了梯度下降的收敛性。


const estimateLipschitzConstant = (
  grad: (x: number[]) => number[],
  region: Array<[number, number]>,
  samples: number = 5000,
): number => {
  let maxL = 0;
  for (let i = 0; i < samples; i++) {
    const x = region.map(([lo, hi]) => lo + Math.random() * (hi - lo));
    const y = region.map(([lo, hi]) => lo + Math.random() * (hi - lo));
    const gx = grad(x);
    const gy = grad(y);
    const gradDiff = Math.sqrt(gx.reduce((a, g, k) => a + (g - gy[k]) ** 2, 0));
    const xDiff = Math.sqrt(x.reduce((a, xi, k) => a + (xi - y[k]) ** 2, 0));
    if (xDiff > 1e-10) {
      maxL = Math.max(maxL, gradDiff / xDiff);
    }
  }
  return maxL;
};

const verifyConvexity = (
  f: (x: number) => number,
  a: number,
  b: number,
  samples: number = 10000,
): { convex: boolean; minSecondDeriv: number } => {
  let minD2 = Infinity;
  const h = Math.pow(Number.EPSILON, 0.25);
  for (let i = 0; i < samples; i++) {
    const x = a + (b - a) * Math.random();
    const d2 = (f(x + h) - 2 * f(x) + f(x - h)) / (h * h);
    minD2 = Math.min(minD2, d2);
  }
  return { convex: minD2 >= -1e-6, minSecondDeriv: minD2 };
};
Newton 法的二次收敛
Newton 法 xₙ₊₁ = xₙ - f(xₙ)/f'(xₙ) 的二次收敛性可以通过 Taylor 展开和中值定理证明。设 x* 是根，eₙ = xₙ - x*，则 eₙ₊₁ ≈ f''(x*)/(2f'(x*)) · eₙ²。这解释了为什么 Newton 法在根附近收敛如此之快——每步有效数字翻倍。


const newtonWithAnalysis = (
  f: (x: number) => number,
  fPrime: (x: number) => number,
  fDoublePrime: (x: number) => number,
  x0: number,
  tolerance: number = 1e-14,
  maxIter: number = 50,
): {
  root: number;
  iterations: number;
  errors: number[];
  convergenceOrders: number[];
} => {
  const errors: number[] = [];
  let x = x0;

  for (let i = 0; i < maxIter; i++) {
    const fx = f(x);
    errors.push(Math.abs(fx));
    if (Math.abs(fx) < tolerance) {
      const orders =
        errors.length > 2
          ? errors
              .slice(2)
              .map((e, k) =>
                errors[k + 1] > 1e-15 && errors[k] > 1e-15
                  ? Math.log(e / errors[k + 1]) / Math.log(errors[k + 1] / errors[k])
                  : 2,
              )
          : [];
      return { root: x, iterations: i, errors, convergenceOrders: orders };
    }
    x = x - fx / fPrime(x);
  }

  return { root: x, iterations: maxIter, errors, convergenceOrders: [] };
};
