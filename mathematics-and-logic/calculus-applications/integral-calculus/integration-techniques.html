积分技巧与方法

核心概念

积分技巧是求解不定积分和定积分的方法论体系。与导数计算的机械性不同，积分更像是"艺术"——需要模式识别和创造性变换。主要技巧包括换元积分法（对应链式法则的逆运算）、分部积分法（对应乘积法则的逆运算）、部分分式分解和三角换元。对程序员而言，符号积分引擎（如 SymPy）的内部实现正是这些技巧的算法化。

数值换元与坐标变换
换元积分法在数值计算中的对应是坐标变换——通过变量替换将难以积分的函数变为容易处理的形式。经典的 Gauss-Legendre 求积就是将任意区间 [a,b] 映射到标准区间 [-1,1]。


const substitutionIntegral = (
  f: (x: number) => number,
  u: (x: number) => number,
  uInverse: (u: number) => number,
  duDx: (x: number) => number,
  a: number,
  b: number,
  n: number = 1000,
): number => {
  const ua = u(a),
    ub = u(b);
  const transformedF = (t: number) => {
    const x = uInverse(t);
    return f(x) / duDx(x);
  };
  const h = (ub - ua) / n;
  let sum = (transformedF(ua) + transformedF(ub)) / 2;
  for (let i = 1; i < n; i++) sum += transformedF(ua + i * h);
  return sum * h;
};

const tanhSinhQuadrature = (f: (x: number) => number, a: number, b: number, levels: number = 6): number => {
  const mid = (a + b) / 2;
  const half = (b - a) / 2;
  let h = 2;
  let prevResult = 0;

  for (let level = 0; level < levels; level++) {
    h /= 2;
    let sum = 0;
    for (let k = -100; k <= 100; k++) {
      const t = k * h;
      const sinhT = Math.sinh(t);
      const coshT = Math.cosh(t);
      const x = Math.tanh((Math.PI / 2) * sinhT);
      const w = ((Math.PI / 2) * coshT) / Math.cosh((Math.PI / 2) * sinhT) ** 2;
      if (Math.abs(w) < 1e-20) continue;
      const xi = mid + half * x;
      if (xi > a && xi < b) {
        sum += w * f(xi) * half * h;
      }
    }
    if (level > 0 && Math.abs(sum - prevResult) < 1e-14) return sum;
    prevResult = sum;
  }
  return prevResult;
};
分部积分与递推公式
分部积分 ∫u dv = uv - ∫v du 的数值对应是将复杂积分转化为更简单的积分加上边界项。递推公式 Iₙ = f(Iₙ₋₁) 可以将高阶积分化为低阶积分的迭代计算。


const integrationByPartsNumerical = (
  u: (x: number) => number,
  vPrime: (x: number) => number,
  a: number,
  b: number,
  n: number = 10000,
): number => {
  const h = (b - a) / n;
  const v = (x: number) => {
    let sum = 0;
    const m = Math.round((x - a) / h);
    for (let i = 0; i < m; i++) {
      sum += ((vPrime(a + i * h) + vPrime(a + (i + 1) * h)) / 2) * h;
    }
    return sum;
  };
  const boundaryTerm = u(b) * v(b) - u(a) * v(a);
  const uPrime = (x: number) => (u(x + h / 10) - u(x - h / 10)) / (h / 5);
  let integral = 0;
  for (let i = 0; i < n; i++) {
    const x = a + (i + 0.5) * h;
    integral += uPrime(x) * v(x) * h;
  }
  return boundaryTerm - integral;
};

const walliFormula = (n: number): number => {
  if (n === 0) return Math.PI;
  if (n === 1) return 2;
  let result = 1;
  if (n % 2 === 0) {
    for (let k = 2; k <= n; k += 2) result *= (k - 1) / k;
    result *= Math.PI / 2;
  } else {
    for (let k = 3; k <= n; k += 2) result *= (k - 1) / k;
    result *= 2;
  }
  return result;
};

const gammaFunction = (x: number): number => {
  if (x <= 0 && x === Math.floor(x)) return Infinity;
  if (x < 0.5) return Math.PI / (Math.sin(Math.PI * x) * gammaFunction(1 - x));
  x -= 1;
  const g = 7;
  const c = [
    0.99999999999980993, 676.5203681218851, -1259.1392167224028, 771.32342877765313, -176.61502916214059,
    12.507343278686905, -0.13857109526572012, 9.9843695780195716e-6, 1.5056327351493116e-7,
  ];
  let sum = c[0];
  for (let i = 1; i < g + 2; i++) sum += c[i] / (x + i);
  const t = x + g + 0.5;
  return Math.sqrt(2 * Math.PI) * Math.pow(t, x + 0.5) * Math.exp(-t) * sum;
};
蒙特卡洛积分
蒙特卡洛积分用随机采样来估计积分值。对高维积分，蒙特卡洛方法的收敛速率 O(1/√N) 与维度无关，使其成为高维积分的首选。


const monteCarloIntegral = (
  f: (x: number[]) => number,
  bounds: Array<[number, number]>,
  samples: number,
): { estimate: number; standardError: number } => {
  const dim = bounds.length;
  const volumes = bounds.reduce((v, [a, b]) => v * (b - a), 1);
  let sum = 0,
    sumSq = 0;

  for (let i = 0; i < samples; i++) {
    const x = bounds.map(([a, b]) => a + Math.random() * (b - a));
    const val = f(x);
    sum += val;
    sumSq += val * val;
  }

  const mean = sum / samples;
  const variance = sumSq / samples - mean * mean;
  return {
    estimate: mean * volumes,
    standardError: Math.sqrt(variance / samples) * volumes,
  };
};

const importanceSampling = (
  f: (x: number) => number,
  proposal: (x: number) => number,
  sampleFromProposal: () => number,
  samples: number,
): { estimate: number; standardError: number } => {
  let sum = 0,
    sumSq = 0;
  for (let i = 0; i < samples; i++) {
    const x = sampleFromProposal();
    const w = f(x) / proposal(x);
    sum += w;
    sumSq += w * w;
  }
  const mean = sum / samples;
  const variance = sumSq / samples - mean * mean;
  return { estimate: mean, standardError: Math.sqrt(variance / samples) };
};
小结
    

  • 换元法和分部积分是解析积分的两大基本技巧，对应链式法则和乘积法则的逆运算
    • 

  • tanh-sinh 求积是处理端点奇异性的高效数值方法
    • 

  • 递推公式将高阶积分化为低阶迭代，Gamma 函数推广了阶乘
    • 

  • 蒙特卡洛积分在高维问题中优势明显，收敛速率与维度无关
    • 

  • 重要性采样通过选择合适的提议分布来降低方差
