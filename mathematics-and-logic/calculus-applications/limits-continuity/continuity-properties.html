连续性与性质

核心概念

连续性是函数的一个基本性质，直觉上意味着函数图形可以"不抬笔"地画出来。精确定义是：函数 f 在点 a 处连续，当且仅当 lim_{x→a} f(x) = f(a)。这包含三个条件：f(a) 有定义、极限存在、极限值等于函数值。连续函数具有一系列优美的性质——介值定理、极值定理、一致连续性——这些性质是数值计算算法正确性的理论保障。

对程序员而言，连续性决定了函数是否可以被数值方法可靠地处理。二分查找求根、数值优化、插值逼近等算法都依赖于连续性假设。

连续性的判定与分类
连续性的判定通过检查 ε-δ 条件或利用极限运算法则。函数在某点不连续时，不连续类型对数值处理有不同影响。


type DiscontinuityType = 'removable' | 'jump' | 'essential' | 'continuous';

const classifyDiscontinuity = (f: (x: number) => number, a: number, h: number = 1e-8): DiscontinuityType => {
  const leftLimit = numericalLeftLimit(f, a, h);
  const rightLimit = numericalRightLimit(f, a, h);
  const fA = f(a);

  if (!isFinite(leftLimit) || !isFinite(rightLimit)) {
    return 'essential';
  }
  if (Math.abs(leftLimit - rightLimit) > 1e-6) {
    return 'jump';
  }
  if (Math.abs(leftLimit - fA) > 1e-6 || isNaN(fA)) {
    return 'removable';
  }
  return 'continuous';
};

const numericalLeftLimit = (f: (x: number) => number, a: number, h: number): number => {
  const hs = [h, h / 10, h / 100, h / 1000];
  const values = hs.map((hi) => f(a - hi));
  return values[values.length - 1];
};

const numericalRightLimit = (f: (x: number) => number, a: number, h: number): number => {
  const hs = [h, h / 10, h / 100, h / 1000];
  const values = hs.map((hi) => f(a + hi));
  return values[values.length - 1];
};

const checkContinuity = (
  f: (x: number) => number,
  a: number,
  epsilon: number = 1e-6,
): { continuous: boolean; leftLimit: number; rightLimit: number; fValue: number } => {
  const leftLimit = numericalLeftLimit(f, a, 1e-8);
  const rightLimit = numericalRightLimit(f, a, 1e-8);
  const fValue = f(a);
  const limitsAgree = Math.abs(leftLimit - rightLimit) < epsilon;
  const limitEqualsFValue = Math.abs(leftLimit - fValue) < epsilon;
  return {
    continuous: limitsAgree && limitEqualsFValue,
    leftLimit,
    rightLimit,
    fValue,
  };
};
介值定理与二分法
介值定理（Intermediate Value Theorem）指出：如果 f 在 [a,b] 上连续，且 f(a) ≤ c ≤ f(b)（或 f(b) ≤ c ≤ f(a)），则存在 ξ ∈ [a,b] 使得 f(ξ) = c。零点定理是其特例：如果 f(a)·f(b) < 0，则存在零点。


二分法求根是介值定理的直接算法实现，保证收敛，每步将搜索区间减半。


interface RootResult {
  root: number;
  iterations: number;
  fValue: number;
  converged: boolean;
}

const bisection = (
  f: (x: number) => number,
  a: number,
  b: number,
  tolerance: number = 1e-12,
  maxIter: number = 100,
): RootResult => {
  let fa = f(a),
    fb = f(b);
  if (fa * fb > 0) {
    throw new Error('f(a) and f(b) must have opposite signs');
  }
  if (Math.abs(fa) < tolerance) return { root: a, iterations: 0, fValue: fa, converged: true };
  if (Math.abs(fb) < tolerance) return { root: b, iterations: 0, fValue: fb, converged: true };

  for (let i = 0; i < maxIter; i++) {
    const m = (a + b) / 2;
    const fm = f(m);
    if (Math.abs(fm) < tolerance || (b - a) / 2 < tolerance) {
      return { root: m, iterations: i + 1, fValue: fm, converged: true };
    }
    if (fa * fm < 0) {
      b = m;
      fb = fm;
    } else {
      a = m;
      fa = fm;
    }
  }

  return { root: (a + b) / 2, iterations: maxIter, fValue: f((a + b) / 2), converged: false };
};

const brent = (
  f: (x: number) => number,
  a: number,
  b: number,
  tolerance: number = 1e-12,
  maxIter: number = 100,
): RootResult => {
  let fa = f(a),
    fb = f(b);
  if (fa * fb > 0) throw new Error('Signs must differ');
  let c = a,
    fc = fa;
  let d = b - a,
    e = d;

  for (let i = 0; i < maxIter; i++) {
    if (fb * fc > 0) {
      c = a;
      fc = fa;
      d = b - a;
      e = d;
    }
    if (Math.abs(fc) < Math.abs(fb)) {
      a = b;
      b = c;
      c = a;
      fa = fb;
      fb = fc;
      fc = fa;
    }
    const tol = 2 * Number.EPSILON * Math.abs(b) + tolerance;
    const m = (c - b) / 2;
    if (Math.abs(m) <= tol || fb === 0) {
      return { root: b, iterations: i + 1, fValue: fb, converged: true };
    }
    if (Math.abs(e) >= tol && Math.abs(fa) > Math.abs(fb)) {
      const s = fb / fa;
      let p: number, q: number;
      if (a === c) {
        p = 2 * m * s;
        q = 1 - s;
      } else {
        const r = fb / fc;
        q = fa / fc;
        p = s * (2 * m * q * (q - r) - (b - a) * (r - 1));
        q = (q - 1) * (r - 1) * (s - 1);
      }
      if (p > 0) q = -q;
      else p = -p;
      if (2 * p < Math.min(3 * m * q - Math.abs(tol * q), Math.abs(e * q))) {
        e = d;
        d = p / q;
      } else {
        d = m;
        e = m;
      }
    } else {
      d = m;
      e = m;
    }
    a = b;
    fa = fb;
    b += Math.abs(d) > tol ? d : m > 0 ? tol : -tol;
    fb = f(b);
  }

  return { root: b, iterations: maxIter, fValue: fb, converged: false };
};
一致连续性
一致连续性比点连续性更强：δ 的选择只依赖于 ε，而不依赖于具体的点。形式化地，f 在集合 S 上一致连续，如果 ∀ε > 0, ∃δ > 0, ∀x,y ∈ S: |x - y| < δ ⟹ |f(x) - f(y)| < ε。


Heine-Cantor 定理保证了闭区间上的连续函数一定一致连续。一致连续性对数值计算的意义在于：可以选择统一的网格步长 h < δ，保证整个区间上的逼近精度。


const testUniformContinuity = (
  f: (x: number) => number,
  a: number,
  b: number,
  epsilon: number,
  deltaCandidate: number,
  numTests: number = 100000,
): { satisfied: boolean; maxViolation: number } => {
  let maxViolation = 0;
  for (let i = 0; i < numTests; i++) {
    const x = a + Math.random() * (b - a);
    const y = x + (Math.random() * 2 - 1) * deltaCandidate;
    if (y < a || y > b) continue;
    if (Math.abs(x - y) < deltaCandidate) {
      const diff = Math.abs(f(x) - f(y));
      if (diff > epsilon) {
        maxViolation = Math.max(maxViolation, diff - epsilon);
      }
    }
  }
  return { satisfied: maxViolation === 0, maxViolation };
};

const lipschitzConstant = (f: (x: number) => number, a: number, b: number, numSamples: number = 10000): number => {
  let maxRatio = 0;
  for (let i = 0; i < numSamples; i++) {
    const x = a + Math.random() * (b - a);
    const y = a + Math.random() * (b - a);
    if (Math.abs(x - y) < 1e-15) continue;
    const ratio = Math.abs(f(x) - f(y)) / Math.abs(x - y);
    maxRatio = Math.max(maxRatio, ratio);
  }
  return maxRatio;
};
连续函数在编程中的应用
连续性假设是许多数值算法的前提条件。优化算法（梯度下降、牛顿法）需要目标函数连续甚至光滑。插值算法（拉格朗日、样条）保持或提升连续性阶数。数值积分（梯形法、Simpson 法）的误差分析依赖于连续性。

const demonstrateContinuityImportance = () => {
  const continuous = (x: number): number => x * x - 2;
  const discontinuous = (x: number): number => (x < 1.414 ? x * x - 2 : x * x - 2 + 0.1);

  const resultCont = bisection(continuous, 0, 2);
  let resultDiscont: RootResult;
  try {
    resultDiscont = bisection(discontinuous, 0, 2);
  } catch {
    resultDiscont = { root: NaN, iterations: -1, fValue: NaN, converged: false };
  }

  return {
    continuous: { root: resultCont.root, converged: resultCont.converged },
    discontinuous: { root: resultDiscont.root, converged: resultDiscont.converged },
  };
};
小结
    

  • 连续性是数值算法正确性的基本保障，介值定理支撑了二分法等根查找算法
    • 

  • 一致连续性允许统一选择网格步长，是数值逼近精度控制的理论基础
    • 

  • 不连续类型（可去、跳跃、本质）决定了数值处理的难度和策略
    • 

  • Brent 法结合了二分法的可靠性和割线法的快速收敛，是工程中的首选求根方法
    • 

  • 连续性假设是梯度下降、插值和数值积分等算法的前提条件
