极限在编程中的应用

核心概念

极限思想渗透在编程的每个角落：迭代算法的收敛判断、数值精度的控制、无穷级数的截断求和、以及机器学习中的损失函数收敛。理解极限的数学本质使程序员能够设计更鲁棒的数值算法、正确设置收敛条件、以及诊断算法不收敛的原因。

本节聚焦于极限概念在实际编程中的四大应用领域：迭代收敛判断、级数求和、数值稳定性技巧和机器学习中的收敛分析。

不动点迭代与收敛速率
不动点迭代 xₙ₊₁ = g(xₙ) 是许多数值算法的核心。如果 g 在不动点 x* 附近满足 |g'(x*)| < 1，则迭代收敛。收敛速率取决于 g'(x*) 的值：|g'(x*)| = 0 对应二次收敛（如牛顿法），|g'(x*)| < 1 对应线性收敛。


interface ConvergenceResult {
  value: number;
  iterations: number;
  converged: boolean;
  convergenceRate: number;
  history: number[];
}

const fixedPointIteration = (
  g: (x: number) => number,
  x0: number,
  tolerance: number = 1e-12,
  maxIter: number = 1000,
): ConvergenceResult => {
  const history: number[] = [x0];
  let x = x0;
  for (let i = 0; i < maxIter; i++) {
    const xNext = g(x);
    history.push(xNext);
    if (Math.abs(xNext - x) < tolerance) {
      const rate = estimateConvergenceRate(history);
      return { value: xNext, iterations: i + 1, converged: true, convergenceRate: rate, history };
    }
    x = xNext;
  }
  return { value: x, iterations: maxIter, converged: false, convergenceRate: 0, history };
};

const estimateConvergenceRate = (history: number[]): number => {
  if (history.length < 4) return 0;
  const n = history.length;
  const errors = history.slice(0, -1).map((x, i) => Math.abs(history[i + 1] - x));
  const validErrors = errors.filter((e) => e > 1e-15);
  if (validErrors.length < 3) return 0;
  const ratios = validErrors.slice(1).map((e, i) => {
    const prev = validErrors[i];
    return prev > 0 ? Math.log(e) / Math.log(prev) : 0;
  });
  return (
    ratios.filter((r) => isFinite(r) && r > 0).reduce((a, b) => a + b, 0) /
    ratios.filter((r) => isFinite(r) && r > 0).length
  );
};

const newtonRaphson = (
  f: (x: number) => number,
  fPrime: (x: number) => number,
  x0: number,
  tolerance: number = 1e-12,
  maxIter: number = 100,
): ConvergenceResult => {
  const g = (x: number) => x - f(x) / fPrime(x);
  return fixedPointIteration(g, x0, tolerance, maxIter);
};
级数求和与截断误差
无穷级数的计算需要截断到有限项，截断误差的控制是核心问题。对交错级数，Leibniz 定理保证截断误差不超过第一个被舍弃的项。对一般级数，需要估计余项。


const taylorExp = (x: number, maxTerms: number = 50): number => {
  let sum = 1;
  let term = 1;
  for (let n = 1; n < maxTerms; n++) {
    term *= x / n;
    sum += term;
    if (Math.abs(term) < Number.EPSILON * Math.abs(sum)) break;
  }
  return sum;
};

const taylorSin = (x: number, maxTerms: number = 30): number => {
  x = x % (2 * Math.PI);
  if (x > Math.PI) x -= 2 * Math.PI;
  if (x < -Math.PI) x += 2 * Math.PI;
  let sum = x;
  let term = x;
  for (let n = 1; n < maxTerms; n++) {
    term *= (-x * x) / (2 * n * (2 * n + 1));
    sum += term;
    if (Math.abs(term) < Number.EPSILON * Math.abs(sum)) break;
  }
  return sum;
};

const taylorLog1p = (x: number, maxTerms: number = 100): number => {
  if (Math.abs(x) >= 1) throw new Error('|x| must be < 1');
  let sum = 0;
  let power = x;
  for (let n = 1; n <= maxTerms; n++) {
    sum += ((n % 2 === 1 ? 1 : -1) * power) / n;
    power *= x;
    if (Math.abs(power / n) < Number.EPSILON * Math.abs(sum)) break;
  }
  return sum;
};

interface SeriesSummation {
  sum: number;
  terms: number;
  lastTerm: number;
  estimatedError: number;
}

const eulerMaclaurin = (f: (k: number) => number, a: number, b: number): SeriesSummation => {
  let sum = 0;
  let terms = 0;
  for (let k = a; k <= b; k++) {
    sum += f(k);
    terms++;
  }
  const correction = (f(a) + f(b)) / 2;
  return {
    sum: sum - correction,
    terms,
    lastTerm: f(b),
    estimatedError: Math.abs(f(b)),
  };
};
收敛加速技术
当级数收敛缓慢时，收敛加速方法可以显著减少所需项数。Aitken Δ² 方法和 Richardson 外推是最常用的加速技术。


const aitkenAcceleration = (s: number[]): number[] => {
  const accelerated: number[] = [];
  for (let n = 0; n < s.length - 2; n++) {
    const denom = s[n + 2] - 2 * s[n + 1] + s[n];
    if (Math.abs(denom) < 1e-15) continue;
    accelerated.push(s[n] - (s[n + 1] - s[n]) ** 2 / denom);
  }
  return accelerated;
};

const shanksTransform = (partialSums: number[]): number => {
  const n = partialSums.length;
  if (n < 3) return partialSums[n - 1];
  const accelerated = aitkenAcceleration(partialSums);
  if (accelerated.length >= 3) {
    return shanksTransform(accelerated);
  }
  return accelerated[accelerated.length - 1] ?? partialSums[n - 1];
};

const computePiByLeibniz = (terms: number): { direct: number; accelerated: number } => {
  const partialSums: number[] = [];
  let sum = 0;
  for (let k = 0; k < terms; k++) {
    sum += (k % 2 === 0 ? 1 : -1) / (2 * k + 1);
    partialSums.push(4 * sum);
  }
  return {
    direct: partialSums[partialSums.length - 1],
    accelerated: shanksTransform(partialSums),
  };
};
机器学习中的收敛判断
机器学习训练过程本质上是一个迭代优化过程，需要判断损失函数是否收敛。早停（Early Stopping）是通过监控验证集损失的极限行为来防止过拟合的技术。


class ConvergenceMonitor {
  private history: number[] = [];
  private patience: number;
  private minDelta: number;
  private bestValue: number = Infinity;
  private counter: number = 0;

  constructor(patience: number = 10, minDelta: number = 1e-4) {
    this.patience = patience;
    this.minDelta = minDelta;
  }

  update(value: number): { converged: boolean; shouldStop: boolean } {
    this.history.push(value);
    if (value < this.bestValue - this.minDelta) {
      this.bestValue = value;
      this.counter = 0;
    } else {
      this.counter++;
    }
    return {
      converged: this.counter >= this.patience,
      shouldStop: this.counter >= this.patience,
    };
  }

  getConvergenceRate(): number {
    if (this.history.length < 10) return 0;
    const recent = this.history.slice(-10);
    const diffs = recent.slice(1).map((v, i) => Math.abs(v - recent[i]));
    return diffs.reduce((a, b) => a + b, 0) / diffs.length;
  }

  getSmoothedLoss(window: number = 5): number[] {
    return this.history.map((_, i) => {
      const start = Math.max(0, i - window + 1);
      const slice = this.history.slice(start, i + 1);
      return slice.reduce((a, b) => a + b, 0) / slice.length;
    });
  }
}

const learningRateSchedulers = {
  exponentialDecay:
    (lr0: number, decay: number) =>
    (epoch: number): number =>
      lr0 * Math.exp(-decay * epoch),

  cosineAnnealing:
    (lrMax: number, lrMin: number, T: number) =>
    (epoch: number): number =>
      lrMin + 0.5 * (lrMax - lrMin) * (1 + Math.cos((Math.PI * epoch) / T)),

  warmupCosine:
    (lrMax: number, warmupSteps: number, totalSteps: number) =>
    (step: number): number => {
      if (step < warmupSteps) return lrMax * (step / warmupSteps);
      const progress = (step - warmupSteps) / (totalSteps - warmupSteps);
      return lrMax * 0.5 * (1 + Math.cos(Math.PI * progress));
    },
};
小结
    

  • 不动点迭代的收敛性由 |g'(x*)| < 1 保证，收敛速率由导数零点阶数决定
    • 

  • Taylor 级数的截断误差通过余项估计和自适应项数控制
    • 

  • Aitken Δ² 加速和 Shanks 变换可将线性收敛提升至超线性收敛
    • 

  • 机器学习中的早停本质上是对验证损失序列极限行为的监控
    • 

  • 学习率调度器（余弦退火、warmup）通过控制步长的渐近行为改善收敛
