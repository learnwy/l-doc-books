无穷极限与渐近行为

核心概念

无穷极限描述了函数在自变量趋向无穷或函数值趋向无穷时的行为。它包括两种情形：x → ±∞ 时 f(x) 的行为（水平渐近线）和 x → a 时 f(x) → ±∞ 的行为（垂直渐近线）。渐近分析是算法复杂度理论的数学基础——大 O 记号就是对函数无穷远处行为的精确刻画。

对程序员来说，无穷极限直接关联到算法的渐近复杂度分析（O, Ω, Θ 记号）、数值计算中的溢出和下溢处理、以及函数在极端输入下的行为预测。

渐近展开与 Stirling 公式
渐近展开将函数在无穷远处用更简单的函数序列逼近。与 Taylor 级数不同，渐近级数可能发散，但截断后的前几项提供了极好的近似。


Stirling 公式 n! ~ √(2πn)(n/e)ⁿ 是最经典的渐近展开，在组合数学和概率论中无处不在。


const stirling = (n: number): number => {
  return Math.sqrt(2 * Math.PI * n) * Math.pow(n / Math.E, n);
};

const stirlingExtended = (n: number): number => {
  const base = Math.sqrt(2 * Math.PI * n) * Math.pow(n / Math.E, n);
  return base * (1 + 1 / (12 * n) + 1 / (288 * n * n) - 139 / (51840 * n * n * n));
};

const logFactorial = (n: number): number => {
  if (n <= 1) return 0;
  return 0.5 * Math.log(2 * Math.PI * n) + n * (Math.log(n) - 1) + 1 / (12 * n) - 1 / (360 * n * n * n);
};

const asymptoticCompare = (
  f: (n: number) => number,
  g: (n: number) => number,
  ns: number[] = [10, 100, 1000, 10000, 100000],
): Array<{ n: number; f: number; g: number; ratio: number }> => {
  return ns.map((n) => {
    const fn = f(n);
    const gn = g(n);
    return { n, f: fn, g: gn, ratio: fn / gn };
  });
};

const growthHierarchy = (n: number) => ({
  constant: 1,

});
L'Hôpital 法则
L'Hôpital 法则处理 0/0 或 ∞/∞ 型不定式：如果 lim f(x) = lim g(x) = 0（或都趋向 ∞），且 lim f'(x)/g'(x) = L，则 lim f(x)/g(x) = L。这个法则将不定式的求解转化为导数的计算。


数值实现中，L'Hôpital 法则的思想体现为：当直接计算遇到 0/0 型时，使用导数（差分）近似。


const lhopitalNumerical = (
  f: (x: number) => number,
  g: (x: number) => number,
  a: number,
  h: number = 1e-8,
  maxIterations: number = 10,
): number => {
  for (let i = 0; i < maxIterations; i++) {
    const fVal = f(a);
    const gVal = g(a);

    if (Math.abs(gVal) > 1e-10 && isFinite(fVal / gVal)) {
      return fVal / gVal;
    }

    const fPrime = (x: number) => (f(x + h) - f(x - h)) / (2 * h);
    const gPrime = (x: number) => (g(x + h) - g(x - h)) / (2 * h);

    const fPrimeVal = fPrime(a);
    const gPrimeVal = gPrime(a);

    if (Math.abs(gPrimeVal) > 1e-10) {
      return fPrimeVal / gPrimeVal;
    }
    h /= 10;
  }
  return NaN;
};

type IndeterminateForm = '0/0' | 'inf/inf' | '0*inf' | 'inf-inf' | '0^0' | 'inf^0' | '1^inf';

const classifyIndeterminate = (
  f: (x: number) => number,
  g: (x: number) => number,
  a: number,
  h: number = 1e-8,
): IndeterminateForm | 'determinate' => {
  const fVal = Math.abs(f(a + h));
  const gVal = Math.abs(g(a + h));
  if (fVal < 1e-6 && gVal < 1e-6) return '0/0';
  if (fVal > 1e6 && gVal > 1e6) return 'inf/inf';
  return 'determinate';
};
数值溢出与渐近替代
在实际编程中，无穷极限的概念直接关联到数值溢出和下溢问题。当函数值趋向极大或极小时，浮点数的有限表示范围可能导致溢出（Infinity）或下溢（0）。渐近分析指导我们使用数学上等价但数值上稳定的替代公式。


const logSumExp = (values: number[]): number => {
  const max = Math.max(...values);
  if (!isFinite(max)) return max;
  const sum = values.reduce((a, v) => a + Math.exp(v - max), 0);
  return max + Math.log(sum);
};

const softmax = (logits: number[]): number[] => {
  const max = Math.max(...logits);
  const exps = logits.map((l) => Math.exp(l - max));
  const sum = exps.reduce((a, b) => a + b, 0);
  return exps.map((e) => e / sum);
};

const logBinomial = (n: number, k: number): number => {
  if (k === 0 || k === n) return 0;
  return logFactorial(n) - logFactorial(k) - logFactorial(n - k);
};

const stableExpit = (x: number): number => {
  if (x >= 0) {
    const ex = Math.exp(-x);
    return 1 / (1 + ex);
  }
  const ex = Math.exp(x);
  return ex / (1 + ex);
};

const stableLogExpit = (x: number): number => {
  if (x >= 0) return -Math.log(1 + Math.exp(-x));
  return x - Math.log(1 + Math.exp(x));
};

const overflowSafeCompute = {
  logGamma: logFactorial,
  logBinomial,
  logSumExp,
  softmax,
  sigmoid: stableExpit,
  logSigmoid: stableLogExpit,
};

  • 无穷极限和渐近分析是算法复杂度理论的数学基础
    • 

  • 大 O、Ω、Θ 记号精确刻画了函数的渐近增长行为

  • L'Hôpital 法则是处理不定式极限的标准工具
