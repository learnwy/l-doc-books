极限的定义与 ε-δ 语言

核心概念

极限是微积分的基石，所有微积分的概念——导数、积分、级数——都建立在极限之上。直觉上，函数 f(x) 在 x → a 时的极限为 L，意味着当 x 足够接近 a 时，f(x) 可以任意接近 L。ε-δ 定义将这个直觉精确化：对任意 ε > 0，存在 δ > 0，使得当 0 < |x - a| < δ 时，有 |f(x) - L| < ε。

ε-δ 语言对程序员而言并不陌生——它本质上是一种"规约"（specification）：给定精度要求 ε，保证存在满足条件的输入范围 δ。这种思维方式在数值计算中无处不在。

ε-δ 定义的精确刻画
ε-δ 定义的核心逻辑是全称-存在量词的嵌套：∀ε > 0, ∃δ > 0, ∀x: 0 < |x - a| < δ ⟹ |f(x) - L| < ε。这里 ε 由"挑战者"给出，δ 由"证明者"找到。对每个 ε，δ 的选择可能不同（通常 δ 是 ε 的函数）。


用程序验证极限思想：给定 ε，搜索满足条件的 δ。虽然无法真正"证明"极限，但可以进行数值验证。


const verifyLimit = (
  f: (x: number) => number,
  a: number,
  L: number,
  epsilon: number,
  delta: number,
  numSamples: number = 10000,
): { verified: boolean; maxError: number; worstX: number } => {
  let maxError = 0;
  let worstX = a;

  for (let i = 0; i < numSamples; i++) {
    const offset = (Math.random() * 2 - 1) * delta;
    if (Math.abs(offset) < 1e-15) continue;
    const x = a + offset;
    const error = Math.abs(f(x) - L);
    if (error > maxError) {
      maxError = error;
      worstX = x;
    }
  }

  return { verified: maxError < epsilon, maxError, worstX };
};

const findDelta = (
  f: (x: number) => number,
  a: number,
  L: number,
  epsilon: number,
  initialDelta: number = 1,
  tolerance: number = 1e-10,
): number => {
  let lo = 0,
    hi = initialDelta;
  while (hi - lo > tolerance) {
    const mid = (lo + hi) / 2;
    const result = verifyLimit(f, a, L, epsilon, mid, 100000);
    if (result.verified) {
      lo = mid;
    } else {
      hi = mid;
    }
  }
  return lo;
};

const numericalLimit = (
  f: (x: number) => number,
  a: number,
  steps: number = 20,
): { estimate: number; convergenceRate: number } => {
  const values: number[] = [];
  for (let k = 1; k <= steps; k++) {
    const h = 10 ** -k;
    const left = f(a - h);
    const right = f(a + h);
    values.push((left + right) / 2);
  }

  const diffs = values.slice(1).map((v, i) => Math.abs(v - values[i]));
  const rates = diffs.slice(1).map((d, i) => (diffs[i] > 0 ? Math.log(d) / Math.log(diffs[i]) : 0));
  const avgRate =
    rates.filter((r) => isFinite(r) && r > 0).reduce((a, b) => a + b, 0) /
    rates.filter((r) => isFinite(r) && r > 0).length;

  return { estimate: values[values.length - 1], convergenceRate: avgRate };
};
极限运算法则
极限的四则运算法则是计算极限的基本工具。设 lim f(x) = L, lim g(x) = M，则：和的极限 = 极限的和，积的极限 = 极限的积，商的极限 = 极限的商（分母极限 ≠ 0）。


夹逼定理（Squeeze Theorem）在直接计算困难时特别有用：如果 g(x) ≤ f(x) ≤ h(x) 且 lim g(x) = lim h(x) = L，则 lim f(x) = L。


interface LimitExpression {
  evaluate: (x: number) => number;
  simplify?: () => string;
}

const limitAdd = (f: LimitExpression, g: LimitExpression): LimitExpression => ({
  evaluate: (x) => f.evaluate(x) + g.evaluate(x),
});

const limitMul = (f: LimitExpression, g: LimitExpression): LimitExpression => ({
  evaluate: (x) => f.evaluate(x) * g.evaluate(x),
});

const limitDiv = (f: LimitExpression, g: LimitExpression): LimitExpression => ({
  evaluate: (x) => {
    const denom = g.evaluate(x);
    if (Math.abs(denom) < 1e-15) return NaN;
    return f.evaluate(x) / denom;
  },
});

const squeezeVerify = (
  lower: (x: number) => number,
  f: (x: number) => number,
  upper: (x: number) => number,
  a: number,
  L: number,
): boolean => {
  const hs = [0.1, 0.01, 0.001, 0.0001, 0.00001];
  return hs.every((h) => {
    for (const sign of [-1, 1]) {
      const x = a + sign * h;
      const lo = lower(x),
        mid = f(x),
        hi = upper(x);
      if (lo > mid + 1e-10 || mid > hi + 1e-10) return false;
    }
    return true;
  });
};
重要极限与渐近分析

const importantLimits = {
  sinOverX: (x: number): number => {
    if (Math.abs(x) < 1e-8) return 1 - (x * x) / 6;
    return Math.sin(x) / x;
  },

  expMinusOneOverX: (x: number): number => {
    if (Math.abs(x) < 1e-8) return 1 + x / 2 + (x * x) / 6;
    return (Math.exp(x) - 1) / x;
  },

  logOnePlusXOverX: (x: number): number => {
    if (Math.abs(x) < 1e-8) return 1 - x / 2 + (x * x) / 3;
    return Math.log(1 + x) / x;
  },

  compoundInterest: (n: number): number => {
    return (1 + 1 / n) ** n;
  },
};

const asymptoticAnalysis = (
  f: (n: number) => number,
  g: (n: number) => number,
  startN: number = 100,
  endN: number = 100000,
  steps: number = 10,
): { ratios: Array<{ n: number; ratio: number }>; order: string } => {
  const ratios: Array<{ n: number; ratio: number }> = [];
  for (let i = 0; i <= steps; i++) {
    const n = Math.round(startN * (endN / startN) ** (i / steps));
    const ratio = f(n) / g(n);
    ratios.push({ n, ratio });
  }

  const lastRatio = ratios[ratios.length - 1].ratio;
  let order: string;
  if (Math.abs(lastRatio) < 0.01) order = 'f = o(g)';
  else if (Math.abs(lastRatio) > 100) order = 'g = o(f)';
  else order = `f ~ ${lastRatio.toFixed(4)} · g`;

  return { ratios, order };
};
数值极限计算中的陷阱
在计算机上计算极限时，浮点数的有限精度会导致各种数值陷阱。当 x 非常接近 a 时，f(x) - L 的计算可能因取消误差（Catastrophic Cancellation）而失去所有有效数字。


const catastrophicCancellation = () => {
  const naive = (x: number): number => (1 - Math.cos(x)) / (x * x);
  const stable = (x: number): number => {
    if (Math.abs(x) < 1e-4) return 0.5 - (x * x) / 24;
    return (2 * Math.sin(x / 2) ** 2) / (x * x);
  };

  const testPoints = [1e-1, 1e-4, 1e-7, 1e-10, 1e-13, 1e-15];
  return testPoints.map((x) => ({
    x,
    naive: naive(x),
    stable: stable(x),
    trueValue: 0.5,
    naiveError: Math.abs(naive(x) - 0.5),
    stableError: Math.abs(stable(x) - 0.5),
  }));
};

const richardsonExtrapolation = (
  f: (h: number) => number,
  h: number,
  order: number = 2,
  levels: number = 4,
): number => {
  const table: number[][] = [];
  table[0] = [];
  for (let i = 0; i <= levels; i++) {
    table[0][i] = f(h / 2 ** i);
  }
  for (let j = 1; j <= levels; j++) {
    table[j] = [];
    for (let i = 0; i <= levels - j; i++) {
      const r = 2 ** (j * order);
      table[j][i] = (r * table[j - 1][i + 1] - table[j - 1][i]) / (r - 1);
    }
  }
  return table[levels][0];
};
小结
    

  • ε-δ 定义将极限的直觉概念精确化为量词逻辑，是数学分析的基础语言
    • 

  • 极限的四则运算法则和夹逼定理是计算极限的基本工具
    • 

  • 重要极限（sin(x)/x, (1+1/n)^n 等）是微积分推导和数值近似的基础
    • 

  • 数值极限计算面临浮点精度陷阱，需要稳定公式和 Richardson 外推等技术
    • 

  • 极限思维对程序员意味着理解迭代收敛性、数值稳定性和算法渐近行为
