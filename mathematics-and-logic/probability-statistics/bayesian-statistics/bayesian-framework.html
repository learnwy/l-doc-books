贝叶斯推断框架

核心概念

贝叶斯推断（Bayesian Inference）是统计学的另一大范式，与频率学派的假设检验形成对比。其核心思想是将参数视为随机变量，通过贝叶斯定理将先验信息与观测数据结合，得到参数的后验分布。贝叶斯框架的优势在于：自然地融合先验知识、提供完整的不确定性量化、避免了 p 值的诸多解释困难。

贝叶斯定理的参数推断形式为：P(θ|X) ∝ P(X|θ) · P(θ)，即后验 ∝ 似然 × 先验。后验分布 P(θ|X) 完整描述了在观测数据后对参数的信念更新。

贝叶斯定理的数学形式
贝叶斯定理在参数推断中的完整形式为：


P(θ|X) = P(X|θ) · P(θ) / P(X)


其中 P(X) = ∫ P(X|θ)P(θ)dθ 是边际似然（Evidence），通常难以计算。在实际中，我们利用正比关系 P(θ|X) ∝ P(X|θ)·P(θ) 来确定后验分布的形状，然后通过归一化或数值方法得到完整的后验分布。


interface BayesianModel<T> {
  logPrior: (theta: number[]) => number;
  logLikelihood: (data: T[], theta: number[]) => number;
  logPosterior: (data: T[], theta: number[]) => number;
}

const createNormalModel = (priorMean: number, priorVariance: number, knownVariance: number): BayesianModel<number> => ({
  logPrior: ([mu]) => {
    return (-0.5 * (mu - priorMean) ** 2) / priorVariance;
  },
  logLikelihood: (data, [mu]) => {
    return data.reduce((acc, x) => acc - (0.5 * (x - mu) ** 2) / knownVariance, 0);
  },
  logPosterior: function (data, theta) {
    return this.logPrior(theta) + this.logLikelihood(data, theta);
  },
});

const normalConjugateUpdate = (
  data: number[],
  priorMean: number,
  priorVariance: number,
  knownVariance: number,
): { posteriorMean: number; posteriorVariance: number } => {
  const n = data.length;
  const sampleMean = data.reduce((a, b) => a + b, 0) / n;
  const precision0 = 1 / priorVariance;
  const precisionData = n / knownVariance;
  const posteriorPrecision = precision0 + precisionData;
  const posteriorMean = (precision0 * priorMean + precisionData * sampleMean) / posteriorPrecision;
  const posteriorVariance = 1 / posteriorPrecision;
  return { posteriorMean, posteriorVariance };
};
贝叶斯更新的关键洞察：后验精度 = 先验精度 + 数据精度。当数据量增大时，数据精度主导，后验趋近于最大似然估计；当数据稀少时，先验发挥更大作用。


先验分布的选择
先验分布的选择是贝叶斯推断中最具争议也最具灵活性的部分。先验可以分为三大类：


共轭先验（Conjugate Prior）：选择使后验与先验属于同一分布族的先验，使得后验有解析解。这是计算最高效的选择。

const betaBinomialUpdate = (
  successes: number,
  trials: number,
  priorAlpha: number,
  priorBeta: number,
): { alpha: number; beta: number; mean: number; mode: number; ci95: [number, number] } => {
  const alpha = priorAlpha + successes;
  const beta = priorBeta + (trials - successes);
  const mean = alpha / (alpha + beta);
  const mode = alpha > 1 && beta > 1 ? (alpha - 1) / (alpha + beta - 2) : mean;
  const variance = (alpha * beta) / ((alpha + beta) ** 2 * (alpha + beta + 1));
  const sd = Math.sqrt(variance);
  return {
    alpha,
    beta,
    mean,
    mode,
    ci95: [Math.max(0, mean - 1.96 * sd), Math.min(1, mean + 1.96 * sd)],
  };
};

const gammaPoissonUpdate = (
  observations: number[],
  priorAlpha: number,
  priorBeta: number,
): { alpha: number; beta: number; mean: number } => {
  const n = observations.length;
  const total = observations.reduce((a, b) => a + b, 0);
  const alpha = priorAlpha + total;
  const beta = priorBeta + n;
  return { alpha, beta, mean: alpha / beta };
};
无信息先验（Non-informative Prior）试图让数据"自己说话"，常见的有 Jeffreys 先验 π(θ) ∝ √I(θ)，其中 I(θ) 是 Fisher 信息量。弱信息先验（Weakly Informative Prior）则提供适度的正则化，在实际中最受推荐。


后验推断与可信区间
后验分布提供了参数的完整不确定性描述。从后验分布可以得到多种点估计：


    

  • 后验均值（Posterior Mean）：最小化平方损失
    • 

  • 后验中位数（Posterior Median）：最小化绝对损失
    • 

  • 最大后验估计（MAP）：后验分布的众数
    • 



贝叶斯可信区间（Credible Interval）与频率学派的置信区间有本质区别：95% 可信区间意味着参数落在该区间的后验概率为 95%，这正是人们直觉上期望的解释。


interface PosteriorSummary {
  mean: number;
  median: number;
  map: number;
  ci95: [number, number];
  hpd95: [number, number];
}

const summarizeBetaPosterior = (alpha: number, beta: number): PosteriorSummary => {
  const mean = alpha / (alpha + beta);
  const mode = alpha > 1 && beta > 1 ? (alpha - 1) / (alpha + beta - 2) : mean;
  const samples = Array.from({ length: 10000 }, () => betaSample(alpha, beta));
  samples.sort((a, b) => a - b);
  const median = samples[5000];
  const ci95: [number, number] = [samples[250], samples[9750]];
  const hpd = computeHPD(samples, 0.95);
  return { mean, median, map: mode, ci95, hpd95: hpd };
};

const computeHPD = (sortedSamples: number[], credMass: number): [number, number] => {
  const n = sortedSamples.length;
  const interval = Math.floor(credMass * n);
  let minWidth = Infinity;
  let bestLo = 0;
  for (let i = 0; i < n - interval; i++) {
    const width = sortedSamples[i + interval] - sortedSamples[i];
    if (width < minWidth) {
      minWidth = width;
      bestLo = i;
    }
  }
  return [sortedSamples[bestLo], sortedSamples[bestLo + interval]];
};

const betaSample = (alpha: number, beta: number): number => {
  const x = gammaSample(alpha);
  const y = gammaSample(beta);
  return x / (x + y);
};

const gammaSample = (shape: number): number => {
  if (shape < 1) {
    return gammaSample(shape + 1) * Math.random() ** (1 / shape);
  }
  const d = shape - 1 / 3;
  const c = 1 / Math.sqrt(9 * d);
  while (true) {
    let x: number, v: number;
    do {
      x = gaussianRandom();
      v = 1 + c * x;
    } while (v <= 0);
    v = v * v * v;
    const u = Math.random();
    if (u < 1 - 0.0331 * (x * x) * (x * x)) return d * v;
    if (Math.log(u) < 0.5 * x * x + d * (1 - v + Math.log(v))) return d * v;
  }
};

const gaussianRandom = (): number => {
  const u1 = Math.random();
  const u2 = Math.random();
  return Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
};
贝叶斯模型比较
贝叶斯模型比较通过贝叶斯因子（Bayes Factor）在两个模型之间做选择。贝叶斯因子 BF₁₂ = P(X|M₁)/P(X|M₂) 是两个模型的边际似然之比，自然地惩罚过于复杂的模型（奥卡姆剃刀效应）。

const bayesFactor = (
  data: number[],
  model1: BayesianModel<number>,
  model2: BayesianModel<number>,
  thetaGrid1: number[][],
  thetaGrid2: number[][],
): number => {
  const logMarginal = (model: BayesianModel<number>, grid: number[][]) => {
    const logWeights = grid.map((theta) => model.logPrior(theta) + model.logLikelihood(data, theta));
    const maxLogW = Math.max(...logWeights);
    const sumExp = logWeights.reduce((a, lw) => a + Math.exp(lw - maxLogW), 0);
    return maxLogW + Math.log(sumExp) - Math.log(grid.length);
  };

  const lm1 = logMarginal(model1, thetaGrid1);
  const lm2 = logMarginal(model2, thetaGrid2);
  return Math.exp(lm1 - lm2);
};
小结
    

  • 贝叶斯推断将参数视为随机变量，通过后验分布完整描述不确定性
    • 

  • 共轭先验使后验有解析解，是计算最高效的贝叶斯方法
    • 

  • 后验均值、MAP 和可信区间是最常用的推断输出
    • 

  • 贝叶斯因子提供了自然的模型比较框架，内置复杂度惩罚
    • 

  • 贝叶斯方法在小样本、在线学习和需要融合先验知识的场景中优势明显
