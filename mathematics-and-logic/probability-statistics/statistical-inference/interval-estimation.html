区间估计与置信区间

核心概念

区间估计不再给出参数的单个值，而是给出一个随机区间 [L, U]，使得真实参数以一定概率（置信水平 1-α）落在该区间内。置信区间的正确解读是：如果重复抽样并构建区间，约 100(1-α)% 的区间包含真实参数值。

置信区间的宽度反映了估计的精度：样本量越大、方差越小、置信水平越低，区间越窄。在 A/B 测试、临床试验、调查报告中，置信区间比点估计提供更完整的信息——它同时传达了估计值和不确定性。

正态总体的置信区间
当总体服从正态分布时，可以基于精确的枢轴量分布构造置信区间。总体均值 μ 的区间依赖于方差是否已知：已知时用 Z 分布，未知时用 t 分布。


const zQuantile = (p: number): number => {
  const a = [
    -3.969683028665376e1, 2.209460984245205e2, -2.759285104469687e2, 1.38357751867269e2, -3.066479806614716e1,
    2.506628277459239,
  ];
  const b = [
    -5.447609879822406e1, 1.615858368580409e2, -1.556989798598866e2, 6.680131188771972e1, -1.328068155288572e1,
  ];
  const c = [
    -7.784894002430293e-3, -3.223964580411365e-1, -2.400758277161838, -2.549732539343734, 4.374664141464968,
    2.938163982698783,
  ];
  const d = [7.784695709041462e-3, 3.224671290700398e-1, 2.445134137142996, 3.754408661907416];
  const pLow = 0.02425;
  const pHigh = 1 - pLow;
  let q: number;
  if (p < pLow) {
    q = Math.sqrt(-2 * Math.log(p));
    return (
      (((((c[0] * q + c[1]) * q + c[2]) * q + c[3]) * q + c[4]) * q + c[5]) /
      ((((d[0] * q + d[1]) * q + d[2]) * q + d[3]) * q + 1)
    );
  } else if (p <= pHigh) {
    q = p - 0.5;
    const r = q * q;
    return (
      ((((((a[0] * r + a[1]) * r + a[2]) * r + a[3]) * r + a[4]) * r + a[5]) * q) /
      (((((b[0] * r + b[1]) * r + b[2]) * r + b[3]) * r + b[4]) * r + 1)
    );
  } else {
    q = Math.sqrt(-2 * Math.log(1 - p));
    return (
      -(((((c[0] * q + c[1]) * q + c[2]) * q + c[3]) * q + c[4]) * q + c[5]) /
      ((((d[0] * q + d[1]) * q + d[2]) * q + d[3]) * q + 1)
    );
  }
};

const tQuantile = (p: number, df: number): number => {
  if (df > 30) return zQuantile(p);
  const z = zQuantile(p);
  const g1 = (z * z * z + z) / 4;
  const g2 = (5 * z ** 5 + 16 * z ** 3 + 3 * z) / 96;
  return z + g1 / df + g2 / (df * df);
};

const confidenceIntervalMean = (
  samples: number[],
  confidence: number = 0.95,
  knownSigma?: number,
): { lower: number; upper: number; mean: number; marginOfError: number } => {
  const n = samples.length;
  const mean = samples.reduce((s, x) => s + x, 0) / n;
  const alpha = 1 - confidence;

  if (knownSigma !== undefined) {
    const z = zQuantile(1 - alpha / 2);
    const moe = (z * knownSigma) / Math.sqrt(n);
    return { lower: mean - moe, upper: mean + moe, mean, marginOfError: moe };
  }

  const s = Math.sqrt(samples.reduce((s, x) => s + (x - mean) ** 2, 0) / (n - 1));
  const t = tQuantile(1 - alpha / 2, n - 1);
  const moe = (t * s) / Math.sqrt(n);
  return { lower: mean - moe, upper: mean + moe, mean, marginOfError: moe };
};

const samples = Array.from({ length: 25 }, () => {
  const u1 = Math.random(),
    u2 = Math.random();
  return 100 + 15 * Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
});
const ci = confidenceIntervalMean(samples, 0.95);
console.log(`95% CI: [${ci.lower.toFixed(2)}, ${ci.upper.toFixed(2)}], 均值=${ci.mean.toFixed(2)}`);
比例的置信区间
二项比例 p 的置信区间在 A/B 测试中最为常用。Wald 区间 p̂ ± z·√(p̂q̂/n) 计算简单但在 p 接近 0 或 1 时表现不佳。Wilson 区间和 Clopper-Pearson 精确区间是更好的替代。


const proportionCI = (
  successes: number,
  total: number,
  confidence: number = 0.95,
): { wald: { lower: number; upper: number }; wilson: { lower: number; upper: number } } => {
  const pHat = successes / total;
  const z = zQuantile(1 - (1 - confidence) / 2);
  const z2 = z * z;

  const waldSE = Math.sqrt((pHat * (1 - pHat)) / total);
  const wald = {
    lower: Math.max(0, pHat - z * waldSE),
    upper: Math.min(1, pHat + z * waldSE),
  };

  const denominator = 1 + z2 / total;
  const center = (pHat + z2 / (2 * total)) / denominator;
  const halfWidth = (z * Math.sqrt((pHat * (1 - pHat) + z2 / (4 * total)) / total)) / denominator;
  const wilson = {
    lower: Math.max(0, center - halfWidth),
    upper: Math.min(1, center + halfWidth),
  };

  return { wald, wilson };
};

const { wald, wilson } = proportionCI(73, 100, 0.95);
console.log(`Wald:   [${wald.lower.toFixed(4)}, ${wald.upper.toFixed(4)}]`);
console.log(`Wilson: [${wilson.lower.toFixed(4)}, ${wilson.upper.toFixed(4)}]`);
Bootstrap 置信区间
Bootstrap 是一种强大的非参数方法，通过有放回重采样模拟抽样分布，不需要假设总体分布形式。Bootstrap 百分位法和 BCa（偏差校正加速）法是两种常用的 Bootstrap 置信区间。


const bootstrapCI = (
  samples: number[],
  statistic: (s: number[]) => number,
  confidence: number = 0.95,
  B: number = 10000,
): { percentile: { lower: number; upper: number }; basic: { lower: number; upper: number } } => {
  const n = samples.length;
  const observed = statistic(samples);
  const bootstrapStats: number[] = [];

  for (let b = 0; b < B; b++) {
    const resample = Array.from({ length: n }, () => samples[Math.floor(Math.random() * n)]);
    bootstrapStats.push(statistic(resample));
  }

  bootstrapStats.sort((a, b) => a - b);
  const alpha = 1 - confidence;
  const lo = Math.floor((alpha / 2) * B);
  const hi = Math.floor((1 - alpha / 2) * B);

  return {
    percentile: { lower: bootstrapStats[lo], upper: bootstrapStats[hi] },
    basic: { lower: 2 * observed - bootstrapStats[hi], upper: 2 * observed - bootstrapStats[lo] },
  };
};

const median = (s: number[]): number => {
  const sorted = [...s].sort((a, b) => a - b);
  const mid = Math.floor(sorted.length / 2);
  return sorted.length % 2 ? sorted[mid] : (sorted[mid - 1] + sorted[mid]) / 2;
};

const expSamples = Array.from({ length: 50 }, () => -Math.log(1 - Math.random()) / 0.5);
const bci = bootstrapCI(expSamples, median);
console.log(`Bootstrap 中位数 95% CI: [${bci.percentile.lower.toFixed(3)}, ${bci.percentile.upper.toFixed(3)}]`);

样本量确定
在实验设计阶段，需要确定满足精度要求的最小样本量。给定置信水平 1-α 和允许误差 E，正态均值的样本量为 n = (z*{α/2}·σ/E)²，比例的样本量为 n = z²*{α/2}·p(1-p)/E²。


const sampleSizeForMean = (sigma: number, marginOfError: number, confidence: number = 0.95): number => {
  const z = zQuantile(1 - (1 - confidence) / 2);
  return Math.ceil(((z * sigma) / marginOfError) ** 2);
};

const sampleSizeForProportion = (p: number, marginOfError: number, confidence: number = 0.95): number => {
  const z = zQuantile(1 - (1 - confidence) / 2);
  return Math.ceil((z * z * p * (1 - p)) / (marginOfError * marginOfError));
};

console.log(`均值 CI±2, σ=10, 95%: n=${sampleSizeForMean(10, 2)}`);
console.log(`比例 CI±3%, p=0.5, 95%: n=${sampleSizeForProportion(0.5, 0.03)}`);
console.log(`比例 CI±3%, p=0.1, 95%: n=${sampleSizeForProportion(0.1, 0.03)}`);
小结
    

  • 置信区间同时传达估计值和不确定性，比点估计信息更完整
    • 

  • σ 未知时用 t 分布构造均值区间，自由度 n-1
    • 

  • 比例的 Wilson 区间优于 Wald 区间，特别是 p 接近 0 或 1 时
    • 

  • Bootstrap 是非参数置信区间的通用方法，适用于任意统计量
    • 

  • 样本量确定在实验设计阶段至关重要，直接影响结论的可靠性
    • 

  • 置信水平的正确理解：重复实验时约 95% 的区间覆盖真值
