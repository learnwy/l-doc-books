Part III · 概率统计与优化概率论与数理统计 简介统计推断 简介点估计

点估计

核心概念

点估计是统计推断的基础任务：给定样本数据，用一个统计量（估计量）来估计总体参数的具体值。估计量 θ̂ 是样本的函数，其优劣通过无偏性、一致性、有效性等准则来评判。选择好的估计量不仅关系到参数估计的准确性，更直接影响后续假设检验和置信区间的可靠性。

在数据科学和机器学习中，模型训练的本质就是参数的点估计：最小二乘法估计回归系数、最大似然法估计分布参数、矩估计提供快速近似。理解点估计的理论基础，有助于选择合适的估计方法并评估其可靠性。

矩估计法
矩估计（Method of Moments）的思想简单直接：用样本矩替代总体矩，建立方程组求解参数。k 阶样本矩 m_k = (1/n)Σx_i^k 作为总体矩 μ_k = E[X^k] 的估计。


const sampleMoment = (samples: number[], k: number): number =>
  samples.reduce((sum, x) => sum + Math.pow(x, k), 0) / samples.length;

const normalMoM = (samples: number[]): { mu: number; sigma2: number } => {
  const m1 = sampleMoment(samples, 1);
  const m2 = sampleMoment(samples, 2);
  return { mu: m1, sigma2: m2 - m1 * m1 };
};

const gammaMoM = (samples: number[]): { alpha: number; beta: number } => {
  const m1 = sampleMoment(samples, 1);
  const m2 = sampleMoment(samples, 2);
  const variance = m2 - m1 * m1;
  const alpha = (m1 * m1) / variance;
  const beta = m1 / variance;
  return { alpha, beta };
};

const poissonMoM = (samples: number[]): { lambda: number } => ({
  lambda: sampleMoment(samples, 1),
});

const generateGamma = (alpha: number, beta: number): number => {
  const shape = alpha;
  if (shape < 1) {
    return generateGamma(alpha + 1, beta) * Math.pow(Math.random(), 1 / alpha);
  }
  const d = shape - 1 / 3;
  const c = 1 / Math.sqrt(9 * d);
  while (true) {
    let x: number, v: number;
    do {
      const u1 = Math.random(),
        u2 = Math.random();
      x = Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
      v = 1 + c * x;
    } while (v <= 0);
    v = v * v * v;
    const u = Math.random();
    if (u < 1 - 0.0331 * x * x * x * x || Math.log(u) < 0.5 * x * x + d * (1 - v + Math.log(v))) {
      return (d * v) / beta;
    }
  }
};

const gammaSamples = Array.from({ length: 5000 }, () => generateGamma(3, 2));
const est = gammaMoM(gammaSamples);
console.log(`Gamma MoM: α=${est.alpha.toFixed(3)} (真值3), β=${est.beta.toFixed(3)} (真值2)`);
矩估计的优点是计算简单、不需要假设分布形式；缺点是可能不是最有效的估计，且高阶矩的估计方差较大。


最大似然估计
最大似然估计（MLE）选择使似然函数 L(θ|x₁,...,xₙ) = Π f(xᵢ|θ) 最大的参数值。实际计算中通常最大化对数似然 ℓ(θ) = Σ log f(xᵢ|θ)，通过求导令 ∂ℓ/∂θ = 0 得到估计值。


MLE 具有优良的渐近性质：(1) 一致性；(2) 渐近正态性 √n(θ̂-θ) →ᵈ N(0, I(θ)⁻¹)；(3) 渐近有效性（达到 Cramér-Rao 下界）。


const normalMLE = (samples: number[]): { mu: number; sigma2: number } => {
  const n = samples.length;
  const mu = samples.reduce((s, x) => s + x, 0) / n;
  const sigma2 = samples.reduce((s, x) => s + (x - mu) ** 2, 0) / n;
  return { mu, sigma2 };
};

const exponentialMLE = (samples: number[]): { lambda: number } => ({
  lambda: samples.length / samples.reduce((s, x) => s + x, 0),
});

const bernoulliMLE = (samples: number[]): { p: number } => ({
  p: samples.reduce((s, x) => s + x, 0) / samples.length,
});

const numericalMLE = (
  logLikelihood: (params: number[]) => number,
  initial: number[],
  stepSize: number = 0.001,
  maxIter: number = 10000,
): number[] => {
  let params = [...initial];
  const n = params.length;

  for (let iter = 0; iter < maxIter; iter++) {
    const grad = Array(n).fill(0);
    const ll = logLikelihood(params);

    for (let i = 0; i < n; i++) {
      const delta = [...params];
      delta[i] += 1e-6;
      grad[i] = (logLikelihood(delta) - ll) / 1e-6;
    }

    const gradNorm = Math.sqrt(grad.reduce((s, g) => s + g * g, 0));
    if (gradNorm < 1e-8) break;

    params = params.map((p, i) => p + stepSize * grad[i]);
  }
  return params;
};

const trueNormalSamples = Array.from({ length: 1000 }, () => {
  const u1 = Math.random(),
    u2 = Math.random();
  return 5 + 2 * Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
});
const mle = normalMLE(trueNormalSamples);
console.log(`正态 MLE: μ=${mle.mu.toFixed(3)} (真值5), σ²=${mle.sigma2.toFixed(3)} (真值4)`);
Cramér-Rao 下界
Cramér-Rao 不等式给出了无偏估计量方差的下界：Var(θ̂) ≥ 1/I(θ)，其中 I(θ) = -E[∂²logf/∂θ²] 是 Fisher 信息量。达到下界的估计量称为有效估计量（UMVUE 的候选）。


const fisherInformation = (
  logPDFDerivative2: (x: number, theta: number) => number,
  theta: number,
  samples: number[],
): number => {
  const avgSecondDeriv = samples.reduce((s, x) => s + logPDFDerivative2(x, theta), 0) / samples.length;
  return -avgSecondDeriv;
};

const cramerRaoBound = (fisherInfo: number, n: number): number => 1 / (n * fisherInfo);

const normalFisherInfo = (sigma2: number): { muInfo: number; sigma2Info: number } => ({
  muInfo: 1 / sigma2,
  sigma2Info: 1 / (2 * sigma2 * sigma2),
});

const sigma2 = 4;
const info = normalFisherInfo(sigma2);
const nSample = 100;
console.log(`正态分布 Fisher 信息: I(μ)=${info.muInfo}, I(σ²)=${info.sigma2Info}`);
console.log(`CR 下界: Var(μ̂)≥${cramerRaoBound(info.muInfo, nSample).toFixed(6)}`);
console.log(`实际 Var(X̄)=${(sigma2 / nSample).toFixed(6)}`);

小结
    

  • 矩估计用样本矩替代总体矩，计算简单但可能不够有效
    • 

  • MLE 选择使数据出现概率最大的参数值，渐近最优且一致
    • 

  • 无偏性和有效性可能冲突：有偏估计可能有更小的 MSE（偏差-方差权衡）
    • 

  • Fisher 信息量度量参数在数据中的"信息含量"
    • 

  • Cramér-Rao 下界是无偏估计方差的理论极限
    • 

  • MLE 渐近达到 CR 下界，是大样本下的最佳选择
