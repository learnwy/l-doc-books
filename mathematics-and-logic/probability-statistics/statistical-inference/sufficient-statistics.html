充分统计量

核心概念

充分统计量（Sufficient Statistic）是统计推断中的核心概念，它回答了一个关键问题：如何在不损失信息的前提下对数据进行压缩？一个统计量 T(X) 被称为参数 θ 的充分统计量，当且仅当在给定 T(X) 的条件下，样本 X 的条件分布与 θ 无关。换言之，T(X) 已经"吸收"了样本中关于 θ 的全部信息。

充分统计量的意义在于数据降维——面对海量数据时，我们不需要保留全部原始数据，只需保留充分统计量即可进行等效的参数推断。这一思想在大数据时代的流式计算、在线学习中尤为重要。

因子分解定理
因子分解定理（Fisher-Neyman Factorization Theorem）是判断充分统计量的核心工具。它指出：T(X) 是 θ 的充分统计量，当且仅当联合密度（或概率质量函数）可以分解为：


f(x|θ) = g(T(x), θ) · h(x)


其中 g 仅通过 T(x) 和 θ 交互，h 与 θ 无关。这个定理将充分性的验证从条件分布的复杂计算简化为密度函数的因式分解。


以正态分布 N(μ, σ²) 为例，当 σ² 已知时，样本均值 X̄ 是 μ 的充分统计量：


f(x₁,...,xₙ|μ) = (2πσ²)^(-n/2) · exp(-Σ(xᵢ-μ)²/(2σ²)) = (2πσ²)^(-n/2) · exp(-n(x̄-μ)²/(2σ²)) · exp(-Σ(xᵢ-x̄)²/(2σ²))


interface SufficientStat<T, S> {
  compute: (data: T[]) => S;
  merge: (s1: S, s2: S) => S;
}

const normalSufficient: SufficientStat<number, { sum: number; n: number }> = {
  compute: (data) => ({
    sum: data.reduce((a, b) => a + b, 0),
    n: data.length,
  }),
  merge: (s1, s2) => ({
    sum: s1.sum + s2.sum,
    n: s1.n + s2.n,
  }),
};

const normalFullSufficient: SufficientStat<number, { sum: number; sumSq: number; n: number }> = {
  compute: (data) => ({
    sum: data.reduce((a, b) => a + b, 0),
    sumSq: data.reduce((a, b) => a + b * b, 0),
    n: data.length,
  }),
  merge: (s1, s2) => ({
    sum: s1.sum + s2.sum,
    sumSq: s1.sumSq + s2.sumSq,
    n: s1.n + s2.n,
  }),
};

const estimateFromSufficient = (stat: { sum: number; sumSq: number; n: number }) => {
  const mean = stat.sum / stat.n;
  const variance = stat.sumSq / stat.n - mean * mean;
  return { mean, variance };
};
因子分解定理的编程意义在于：如果一个统计量是充分的，那么所有基于该统计量的计算都可以在聚合后进行，而不需要回溯原始数据。这正是 MapReduce 和流式计算中聚合操作的理论基础。


最小充分统计量与完备性
最小充分统计量是所有充分统计量中"最精简"的——它是任何其他充分统计量的函数。形式化地说，T 是最小充分统计量，当且仅当对任何充分统计量 S，存在函数 φ 使得 T = φ(S)。


寻找最小充分统计量的常用方法是似然比法：如果 f(x|θ)/f(y|θ) 与 θ 无关当且仅当 T(x) = T(y)，则 T 是最小充分统计量。


完备性是比充分性更强的条件。统计量 T 是完备的，如果对任意函数 g，Eθ[g(T)] = 0 对所有 θ 成立蕴含 Pθ(g(T) = 0) = 1 对所有 θ 成立。完备充分统计量的重要性在于 Lehmann-Scheffé 定理：基于完备充分统计量的无偏估计是唯一的最小方差无偏估计（UMVUE）。

指数族与自然充分统计量
指数族（Exponential Family）是统计学中最重要的分布族，几乎所有常见分布（正态、泊松、伯努利、指数、Gamma 等）都属于指数族。指数族的一般形式为：


f(x|θ) = h(x) · c(θ) · exp(η(θ)ᵀ · T(x))


其中 T(x) 自动成为 η 的充分统计量，且在正则条件下是完备充分的。自然参数 η(θ) 和自然充分统计量 T(x) 是指数族的核心要素。


interface ExponentialFamily<T> {
  naturalParameter: (theta: number[]) => number[];
  sufficientStat: (x: T) => number[];
  logPartition: (eta: number[]) => number;
  baseMeasure: (x: T) => number;
}

const poissonFamily: ExponentialFamily<number> = {
  naturalParameter: (theta) => [Math.log(theta[0])],
  sufficientStat: (x) => [x],
  logPartition: (eta) => Math.exp(eta[0]),
  baseMeasure: (x) => {
    let logFact = 0;
    for (let i = 2; i <= x; i++) logFact += Math.log(i);
    return Math.exp(-logFact);
  },
};

const normalFamily: ExponentialFamily<number> = {
  naturalParameter: ([mu, sigma2]) => [mu / sigma2, -1 / (2 * sigma2)],
  sufficientStat: (x) => [x, x * x],
  logPartition: (eta) => {
    const mu = -eta[0] / (2 * eta[1]);
    const sigma2 = -1 / (2 * eta[1]);
    return (mu * mu) / (2 * sigma2) + 0.5 * Math.log(2 * Math.PI * sigma2);
  },
  baseMeasure: () => 1,
};

const computeSufficientFromData = <T>(family: ExponentialFamily<T>, data: T[]): number[] => {
  const dim = family.sufficientStat(data[0]).length;
  const result = new Array(dim).fill(0);
  for (const x of data) {
    const t = family.sufficientStat(x);
    for (let i = 0; i < dim; i++) result[i] += t[i];
  }
  return result;
};
指数族的实际意义在于：广义线性模型（GLM）的整个框架建立在指数族之上，而充分统计量的维度决定了模型参数的自由度。


Rao-Blackwell 定理与 UMVUE
Rao-Blackwell 定理将充分统计量与估计量的优化联系起来：给定参数 θ 的任意无偏估计量 δ(X) 和充分统计量 T(X)，定义改进估计量 δ*(T) = E[δ(X)|T]，则 δ* 仍然无偏，且方差不大于 δ 的方差。


这意味着在寻找最优估计量时，只需在充分统计量的函数空间中搜索。结合完备性条件（Lehmann-Scheffé 定理），完备充分统计量的任意无偏函数自动就是 UMVUE。


const raoBlackwellize = (rawEstimates: number[], sufficientValues: number[]): Map<number, number> => {
  const groups = new Map<number, number[]>();
  for (let i = 0; i < rawEstimates.length; i++) {
    const key = sufficientValues[i];
    if (!groups.has(key)) groups.set(key, []);
    groups.get(key)!.push(rawEstimates[i]);
  }
  const improved = new Map<number, number>();
  for (const [key, values] of groups) {
    improved.set(key, values.reduce((a, b) => a + b, 0) / values.length);
  }
  return improved;
};

const demonstrateRaoBlackwell = () => {
  const n = 10000;
  const trueLambda = 3;
  const samples: number[][] = [];
  for (let i = 0; i < n; i++) {
    const sample: number[] = [];
    for (let j = 0; j < 5; j++) {
      let L = Math.exp(-trueLambda);
      let k = 0;
      let p = 1;
      do {
        k++;
        p *= Math.random();
      } while (p > L);
      sample.push(k - 1);
    }
    samples.push(sample);
  }
  const rawEstimates = samples.map((s) => (s[0] === 0 ? 1 : 0));
  const sufficientSums = samples.map((s) => s.reduce((a, b) => a + b, 0));
  const rawVariance = rawEstimates.reduce((a, b) => a + (b - Math.exp(-trueLambda)) ** 2, 0) / n;
  const improved = raoBlackwellize(rawEstimates, sufficientSums);
  const improvedEstimates = sufficientSums.map((s) => improved.get(s) ?? 0);
  const improvedVariance = improvedEstimates.reduce((a, b) => a + (b - Math.exp(-trueLambda)) ** 2, 0) / n;
  return { rawVariance, improvedVariance, reduction: 1 - improvedVariance / rawVariance };
};
充分统计量在流式计算中的应用
充分统计量的可合并性使其成为分布式和流式计算的天然工具。在大数据场景下，数据分散在多个节点，无法一次性加载。如果我们计算的是充分统计量，那么各节点独立计算后合并即可得到全局结果。

class StreamingEstimator {
  private sum = 0;
  private sumSq = 0;
  private count = 0;

  update(value: number): void {
    this.sum += value;
    this.sumSq += value * value;
    this.count += 1;
  }

  merge(other: StreamingEstimator): StreamingEstimator {
    const merged = new StreamingEstimator();
    merged.sum = this.sum + other.sum;
    merged.sumSq = this.sumSq + other.sumSq;
    merged.count = this.count + other.count;
    return merged;
  }

  estimate(): { mean: number; variance: number; n: number } {
    const mean = this.sum / this.count;
    const variance = this.sumSq / this.count - mean * mean;
    return { mean, variance, n: this.count };
  }

  confidenceInterval(alpha: number): { lower: number; upper: number } {
    const { mean, variance, n } = this.estimate();
    const z = alpha === 0.05 ? 1.96 : 2.576;
    const se = Math.sqrt(variance / n);
    return { lower: mean - z * se, upper: mean + z * se };
  }
}

const distributedEstimation = (chunks: number[][]): { mean: number; variance: number } => {
  const estimators = chunks.map((chunk) => {
    const est = new StreamingEstimator();
    chunk.forEach((v) => est.update(v));
    return est;
  });
  const merged = estimators.reduce((a, b) => a.merge(b));
  return merged.estimate();
};
