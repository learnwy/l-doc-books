参数检验方法

核心概念

参数检验（Parametric Tests）是假设检验中最经典的一类方法，它假设数据来自某个已知分布族（通常是正态分布），并对该分布的参数（如均值、方差）进行检验。参数检验的优势在于当模型假设成立时，它具有最高的检验功效；代价是当假设不成立时，检验结果可能不可靠。

参数检验的核心思路是：在零假设下，检验统计量服从某个已知的理论分布（如 t 分布、F 分布、χ² 分布），从而可以精确计算 p 值。三大经典参数检验——Z 检验、t 检验、F 检验——分别用于不同的场景。

Z 检验与 t 检验
Z 检验是最基本的参数检验，适用于总体方差已知的情形。在实际中更常用的是 t 检验，因为总体方差通常未知，需要用样本标准差估计。


t 检验由 William Sealy Gosset（笔名 Student）提出，其关键创新是用样本标准差替代总体标准差时，检验统计量不再服从正态分布，而是服从自由度为 n-1 的 t 分布。t 分布比正态分布的尾部更厚，反映了额外的不确定性。


const zTest = (
  sample: number[],
  mu0: number,
  sigma: number,
  alternative: 'two-sided' | 'less' | 'greater' = 'two-sided',
): TestResult => {
  const n = sample.length;
  const mean = sample.reduce((a, b) => a + b, 0) / n;
  const z = (mean - mu0) / (sigma / Math.sqrt(n));
  let pValue: number;
  switch (alternative) {
    case 'two-sided':
      pValue = 2 * (1 - normalCDF(Math.abs(z)));
      break;
    case 'less':
      pValue = normalCDF(z);
      break;
    case 'greater':
      pValue = 1 - normalCDF(z);
      break;
  }
  return {
    statistic: z,
    pValue,
    rejectH0: pValue <= 0.05,
    alpha: 0.05,
    effectSize: (mean - mu0) / sigma,
  };
};

const tTest = (
  sample: number[],
  mu0: number,
  alternative: 'two-sided' | 'less' | 'greater' = 'two-sided',
): TestResult => {
  const n = sample.length;
  const mean = sample.reduce((a, b) => a + b, 0) / n;
  const variance = sample.reduce((a, x) => a + (x - mean) ** 2, 0) / (n - 1);
  const se = Math.sqrt(variance / n);
  const t = (mean - mu0) / se;
  const df = n - 1;
  const pValue = tDistPValue(t, df, alternative);
  return {
    statistic: t,
    pValue,
    rejectH0: pValue <= 0.05,
    alpha: 0.05,
    effectSize: (mean - mu0) / Math.sqrt(variance),
  };
};

const tDistPValue = (t: number, df: number, alternative: 'two-sided' | 'less' | 'greater'): number => {
  const x = df / (df + t * t);
  const ibeta = incompleteBeta(df / 2, 0.5, x);
  const cdf = t >= 0 ? 1 - 0.5 * ibeta : 0.5 * ibeta;
  switch (alternative) {
    case 'two-sided':
      return 2 * Math.min(cdf, 1 - cdf);
    case 'less':
      return cdf;
    case 'greater':
      return 1 - cdf;
  }
};

const incompleteBeta = (a: number, b: number, x: number): number => {
  if (x === 0 || x === 1) return x;
  const lbeta = lgamma(a) + lgamma(b) - lgamma(a + b);
  const front = Math.exp(Math.log(x) * a + Math.log(1 - x) * b - lbeta) / a;
  let sum = 0,
    term = 1;
  for (let n = 0; n <= 200; n++) {
    sum += term;
    term *= ((n + 1 - b) * x) / (n + 1 + a);
    if (Math.abs(term) < 1e-12) break;
  }
  return front * sum;
};

const lgamma = (x: number): number => {
  const c = [
    76.18009172947146, -86.50532032941677, 24.01409824083091, -1.231739572450155, 0.1208650973866179e-2,
    -0.5395239384953e-5,
  ];
  let y = x,
    tmp = x + 5.5;
  tmp -= (x + 0.5) * Math.log(tmp);
  let ser = 1.000000000190015;
  for (let j = 0; j < 6; j++) ser += c[j] / ++y;
  return -tmp + Math.log((2.5066282746310005 * ser) / x);
};
独立两样本与配对检验
两样本 t 检验用于比较两个独立组的均值差异。根据两组方差是否相等，分为等方差（pooled）和不等方差（Welch）两种形式。Welch 的 t 检验使用 Satterthwaite 近似自由度，在大多数情况下更稳健。


配对 t 检验适用于同一对象的前后测量、匹配对比等场景，将问题转化为对差值的单样本 t 检验。


const twoSampleTTest = (sample1: number[], sample2: number[], equalVariance: boolean = false): TestResult => {
  const n1 = sample1.length,
    n2 = sample2.length;
  const m1 = sample1.reduce((a, b) => a + b, 0) / n1;
  const m2 = sample2.reduce((a, b) => a + b, 0) / n2;
  const v1 = sample1.reduce((a, x) => a + (x - m1) ** 2, 0) / (n1 - 1);
  const v2 = sample2.reduce((a, x) => a + (x - m2) ** 2, 0) / (n2 - 1);

  let t: number, df: number;
  if (equalVariance) {
    const sp2 = ((n1 - 1) * v1 + (n2 - 1) * v2) / (n1 + n2 - 2);
    t = (m1 - m2) / Math.sqrt(sp2 * (1 / n1 + 1 / n2));
    df = n1 + n2 - 2;
  } else {
    const se = Math.sqrt(v1 / n1 + v2 / n2);
    t = (m1 - m2) / se;
    df = (v1 / n1 + v2 / n2) ** 2 / ((v1 / n1) ** 2 / (n1 - 1) + (v2 / n2) ** 2 / (n2 - 1));
  }

  const pooledSD = Math.sqrt(((n1 - 1) * v1 + (n2 - 1) * v2) / (n1 + n2 - 2));
  return {
    statistic: t,
    pValue: tDistPValue(t, df, 'two-sided'),
    rejectH0: tDistPValue(t, df, 'two-sided') <= 0.05,
    alpha: 0.05,
    effectSize: (m1 - m2) / pooledSD,
  };
};

const pairedTTest = (before: number[], after: number[]): TestResult => {
  const differences = before.map((b, i) => after[i] - b);
  return tTest(differences, 0);
};
方差检验与 F 检验
F 检验用于比较两个正态总体的方差是否相等，在进行两样本 t 检验前常作为前置检验。F 统计量是两个样本方差的比值，服从 F 分布。


χ²（卡方）检验用于单个正态总体的方差检验，检验统计量 (n-1)S²/σ₀² 服从 χ²(n-1) 分布。


const fTest = (sample1: number[], sample2: number[]): TestResult => {
  const n1 = sample1.length,
    n2 = sample2.length;
  const m1 = sample1.reduce((a, b) => a + b, 0) / n1;
  const m2 = sample2.reduce((a, b) => a + b, 0) / n2;
  const v1 = sample1.reduce((a, x) => a + (x - m1) ** 2, 0) / (n1 - 1);
  const v2 = sample2.reduce((a, x) => a + (x - m2) ** 2, 0) / (n2 - 1);
  const f = v1 / v2;
  const df1 = n1 - 1,
    df2 = n2 - 1;
  const pValue = 2 * Math.min(fDistCDF(f, df1, df2), 1 - fDistCDF(f, df1, df2));
  return {
    statistic: f,
    pValue,
    rejectH0: pValue <= 0.05,
    alpha: 0.05,
    effectSize: Math.log(f),
  };
};

const fDistCDF = (x: number, d1: number, d2: number): number => {
  const z = (d1 * x) / (d1 * x + d2);
  return incompleteBeta(d1 / 2, d2 / 2, z);
};

const chiSquareVarianceTest = (sample: number[], sigma0Sq: number): TestResult => {
  const n = sample.length;
  const mean = sample.reduce((a, b) => a + b, 0) / n;
  const sampleVar = sample.reduce((a, x) => a + (x - mean) ** 2, 0) / (n - 1);
  const chiSq = ((n - 1) * sampleVar) / sigma0Sq;
  const df = n - 1;
  const pValue = 1 - chiSquareCDF(chiSq, df);
  return {
    statistic: chiSq,
    pValue,
    rejectH0: pValue <= 0.05,
    alpha: 0.05,
    effectSize: sampleVar / sigma0Sq - 1,
  };
};

const chiSquareCDF = (x: number, k: number): number => {
  return incompleteBeta(k / 2, 0.5, 1 - x / (x + k)) > 0.5
    ? 1 - incompleteBeta(k / 2, 0.5, x / (x + k)) * 0.5
    : incompleteBeta(k / 2, 0.5, x / (x + k)) * 0.5;
};
正态性检验与鲁棒性
参数检验的有效性依赖于正态性假设。在应用参数检验之前，通常需要检验数据是否近似正态。常用方法包括 Shapiro-Wilk 检验、Kolmogorov-Smirnov 检验和 Q-Q 图。


中心极限定理保证了当样本量足够大时（通常 n ≥ 30），样本均值近似正态，这使得 t 检验对非正态数据具有一定的鲁棒性。但方差检验对正态性假设非常敏感。

const jarqueBeraTest = (data: number[]): { jb: number; pValue: number } => {
  const n = data.length;
  const mean = data.reduce((a, b) => a + b, 0) / n;
  const m2 = data.reduce((a, x) => a + (x - mean) ** 2, 0) / n;
  const m3 = data.reduce((a, x) => a + (x - mean) ** 3, 0) / n;
  const m4 = data.reduce((a, x) => a + (x - mean) ** 4, 0) / n;
  const skewness = m3 / m2 ** 1.5;
  const kurtosis = m4 / m2 ** 2;
  const jb = (n / 6) * (skewness ** 2 + (kurtosis - 3) ** 2 / 4);
  const pValue = 1 - chiSquareCDF(jb, 2);
  return { jb, pValue };
};
小结
    

  • 参数检验在分布假设成立时具有最高功效，Z/t/F/χ² 是四大经典检验
    • 

  • t 检验是最常用的均值检验，Welch 修正版不要求等方差假设
    • 

  • F 检验和 χ² 检验用于方差比较和检验，对正态性假设敏感
    • 

  • 正态性检验是参数检验的前置步骤，中心极限定理为大样本提供鲁棒性保障
    • 

  • 效应量（Cohen's d）是补充 p 值的关键指标，衡量实际意义而非仅统计显著性
