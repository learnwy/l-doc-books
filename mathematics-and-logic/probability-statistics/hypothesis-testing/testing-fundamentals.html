假设检验基本原理

核心概念

假设检验（Hypothesis Testing）是统计推断的两大支柱之一，它提供了一套严格的框架来基于样本数据对总体参数做出决策。核心思想是"反证法"——先假设某个关于总体的陈述（零假设 H₀）为真，然后观察数据是否与该假设矛盾。如果矛盾程度超过预设的阈值（显著性水平 α），则拒绝 H₀。

假设检验在 A/B 测试、模型评估、异常检测等场景中无处不在。对程序员而言，理解假设检验的逻辑框架，不仅能正确设计实验，还能避免常见的统计误用（如 p-hacking、多重比较谬误）。

第一类与第二类错误
假设检验的决策可能犯两种错误。第一类错误（Type I Error, α 错误）是在 H₀ 为真时错误地拒绝了它，相当于"误报"（False Positive）。第二类错误（Type II Error, β 错误）是在 H₁ 为真时未能拒绝 H₀，相当于"漏报"（False Negative）。


两类错误之间存在权衡关系：降低 α（减少误报）通常会增加 β（增加漏报），反之亦然。唯一同时减少两者的方法是增大样本量。

interface TestResult {
  statistic: number;
  pValue: number;
  rejectH0: boolean;
  alpha: number;
  effectSize: number;
}

const simulateErrors = (
  trueMean: number,
  h0Mean: number,
  sigma: number,
  n: number,
  alpha: number,
  simulations: number,
): { typeI: number; typeII: number; power: number } => {
  let typeICount = 0;
  let typeIICount = 0;
  let h0TrueTrials = 0;
  let h1TrueTrials = 0;

  for (let sim = 0; sim < simulations; sim++) {
    const isH0True = Math.random() < 0.5;
    const mean = isH0True ? h0Mean : trueMean;
    let sum = 0;
    for (let i = 0; i < n; i++) {
      sum += mean + sigma * gaussianRandom();
    }
    const sampleMean = sum / n;
    const zStat = (sampleMean - h0Mean) / (sigma / Math.sqrt(n));
    const pValue = 2 * (1 - normalCDF(Math.abs(zStat)));

    if (isH0True) {
      h0TrueTrials++;
      if (pValue <= alpha) typeICount++;
    } else {
      h1TrueTrials++;
      if (pValue > alpha) typeIICount++;
    }
  }

  return {
    typeI: typeICount / h0TrueTrials,
    typeII: typeIICount / h1TrueTrials,
    power: 1 - typeIICount / h1TrueTrials,
  };
};

const gaussianRandom = (): number => {
  const u1 = Math.random();
  const u2 = Math.random();
  return Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
};

const normalCDF = (x: number): number => {
  const a1 = 0.254829592,
    a2 = -0.284496736,
    a3 = 1.421413741;
  const a4 = -1.453152027,
    a5 = 1.061405429,
    p = 0.3275911;
  const sign = x < 0 ? -1 : 1;
  x = Math.abs(x) / Math.sqrt(2);
  const t = 1.0 / (1.0 + p * x);
  const y = 1.0 - ((((a5 * t + a4) * t + a3) * t + a2) * t + a1) * t * Math.exp(-x * x);
  return 0.5 * (1.0 + sign * y);
};
p 值的正确解读
p 值是假设检验中最容易被误解的概念。p 值的正确定义是：在零假设为真的条件下，观测到当前统计量值或更极端值的概率。它不是"H₀ 为真的概率"，也不是"结果由随机产生的概率"。


p 值的常见误解与正确理解：






误解
正确理解





p 值是 H₀ 为真的概率
p 值是假设 H₀ 为真时数据的极端程度




p = 0.05 意味着 5% 概率出错
长期来看，若 H₀ 总是真的，有 5% 的实验会误报




p 值越小效应越大
p 值受样本量影响，大样本下微小效应也能显著




不显著 = 无效果
可能只是样本量不够（功效不足）




p 值可以比较不同实验
p 值依赖于实验设计，不具可比性





const calculatePValue = (testStatistic: number, testType: 'two-sided' | 'left' | 'right'): number => {
  switch (testType) {
    case 'two-sided':
      return 2 * (1 - normalCDF(Math.abs(testStatistic)));
    case 'left':
      return normalCDF(testStatistic);
    case 'right':
      return 1 - normalCDF(testStatistic);
  }
};

const interpretPValue = (pValue: number, alpha: number, effectSize: number) => {
  const significant = pValue <= alpha;
  const practicallyImportant = Math.abs(effectSize) > 0.2;

  if (significant && practicallyImportant) {
    return '统计显著且具有实际意义';
  } else if (significant && !practicallyImportant) {
    return '统计显著但效应量小，可能是大样本导致';
  } else if (!significant && practicallyImportant) {
    return '未达显著但效应量较大，可能需要更大样本';
  } else {
    return '既不显著也无实际意义';
  }
};
检验功效与样本量计算
检验功效（Power）是在备择假设为真时正确拒绝零假设的概率，即 1 - β。功效分析是实验设计的关键步骤，它决定了需要多少样本才能以足够高的概率检测出给定大小的效应。


功效受四个因素影响：显著性水平 α、效应量 δ、样本量 n 和总体方差 σ²。其中效应量和样本量是设计者可以控制的（通过选择研究对象和增加数据收集）。


const calculatePower = (
  effectSize: number,
  n: number,
  alpha: number,
  sigma: number,
  testType: 'two-sided' | 'one-sided' = 'two-sided',
): number => {
  const se = sigma / Math.sqrt(n);
  const noncentrality = effectSize / se;

  if (testType === 'one-sided') {
    const criticalZ = inverseNormalCDF(1 - alpha);
    return 1 - normalCDF(criticalZ - noncentrality);
  }

  const criticalZ = inverseNormalCDF(1 - alpha / 2);
  const powerRight = 1 - normalCDF(criticalZ - noncentrality);
  const powerLeft = normalCDF(-criticalZ - noncentrality);
  return powerRight + powerLeft;
};

const calculateSampleSize = (effectSize: number, alpha: number, power: number, sigma: number): number => {
  const zAlpha = inverseNormalCDF(1 - alpha / 2);
  const zBeta = inverseNormalCDF(power);
  const n = Math.ceil((((zAlpha + zBeta) * sigma) / effectSize) ** 2);
  return n;
};

const inverseNormalCDF = (p: number): number => {
  if (p <= 0 || p >= 1) throw new Error('p must be in (0,1)');
  if (p < 0.5) return -inverseNormalCDF(1 - p);
  const a = [
    -3.969683028665376e1, 2.209460984245205e2, -2.759285104469687e2, 1.38357751867269e2, -3.066479806614716e1,
    2.506628277459239,
  ];
  const b = [
    -5.447609879822406e1, 1.615858368580409e2, -1.556989798598866e2, 6.680131188771972e1, -1.328068155288572e1,
  ];
  const q = p - 0.5;
  const r = q * q;
  return (
    ((((((a[0] * r + a[1]) * r + a[2]) * r + a[3]) * r + a[4]) * r + a[5]) * q) /
    (((((b[0] * r + b[1]) * r + b[2]) * r + b[3]) * r + b[4]) * r + 1)
  );
};

const powerAnalysisReport = (effectSize: number, sigma: number, alpha: number) => {
  const sampleSizes = [10, 20, 50, 100, 200, 500, 1000];
  return sampleSizes.map((n) => ({
    n,
    power: calculatePower(effectSize, n, alpha, sigma),
  }));
};
A/B 测试中的假设检验
A/B 测试是假设检验在互联网产品中的最典型应用。其核心流程是：将用户随机分为对照组（A）和实验组（B），施加不同策略，收集关键指标数据，然后通过假设检验判断差异是否显著。


interface ABTestConfig {
  alpha: number;
  power: number;
  mde: number;
  baselineRate: number;
}

interface ABTestResult {
  controlCount: number;
  treatmentCount: number;
  controlConversions: number;
  treatmentConversions: number;
  controlRate: number;
  treatmentRate: number;
  zStatistic: number;
  pValue: number;
  significant: boolean;
  relativeChange: number;
  confidenceInterval: { lower: number; upper: number };
}

const runABTest = (control: boolean[], treatment: boolean[], alpha: number = 0.05): ABTestResult => {
  const n1 = control.length;
  const n2 = treatment.length;
  const x1 = control.filter(Boolean).length;
  const x2 = treatment.filter(Boolean).length;
  const p1 = x1 / n1;
  const p2 = x2 / n2;
  const pPooled = (x1 + x2) / (n1 + n2);
  const se = Math.sqrt(pPooled * (1 - pPooled) * (1 / n1 + 1 / n2));
  const z = (p2 - p1) / se;
  const pValue = 2 * (1 - normalCDF(Math.abs(z)));
  const seDiff = Math.sqrt((p1 * (1 - p1)) / n1 + (p2 * (1 - p2)) / n2);
  const zCrit = inverseNormalCDF(1 - alpha / 2);

  return {
    controlCount: n1,
    treatmentCount: n2,
    controlConversions: x1,
    treatmentConversions: x2,
    controlRate: p1,
    treatmentRate: p2,
    zStatistic: z,
    pValue,
    significant: pValue <= alpha,
    relativeChange: (p2 - p1) / p1,
    confidenceInterval: {
      lower: p2 - p1 - zCrit * seDiff,
      upper: p2 - p1 + zCrit * seDiff,
    },
  };
};

const calculateABTestSampleSize = (config: ABTestConfig): number => {
  const p1 = config.baselineRate;
  const p2 = p1 * (1 + config.mde);
  const zAlpha = inverseNormalCDF(1 - config.alpha / 2);
  const zBeta = inverseNormalCDF(config.power);
  const pBar = (p1 + p2) / 2;
  const n = Math.ceil(
    (zAlpha * Math.sqrt(2 * pBar * (1 - pBar)) + zBeta * Math.sqrt(p1 * (1 - p1) + p2 * (1 - p2))) ** 2 /
      (p2 - p1) ** 2,
  );
  return n;
};
小结
    

  • 假设检验通过反证法逻辑，基于样本数据对总体参数做出统计决策
    • 

  • 第一类错误（误报）和第二类错误（漏报）之间存在固有权衡，增大样本量是同时改善的唯一途径
    • 

  • p 值是在 H₀ 为真时数据极端程度的度量，不是 H₀ 为真的概率
    • 

  • 功效分析是实验设计的关键步骤，决定所需样本量以检测给定效应
    • 

  • A/B 测试是假设检验在产品迭代中的标准应用，需同时关注统计显著性和实际意义
    •
