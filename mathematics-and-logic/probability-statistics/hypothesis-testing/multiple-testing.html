多重检验校正

核心概念

多重检验问题（Multiple Testing Problem）是现代统计学中最重要的议题之一。当同时进行多个假设检验时，即使每个检验的 α 水平控制在 0.05，整体犯至少一次第一类错误的概率会急剧上升。进行 m 个独立检验时，至少一个假阳性的概率为 1 - (1-α)^m，当 m = 20 时这个概率高达 64%。

多重检验校正在基因组学（数万个基因同时检验）、A/B 测试（多个指标同时评估）、神经影像学（数十万体素同时检验）等场景中至关重要。没有校正的多重检验结果是不可信的。

FWER 控制方法
族错误率（Family-Wise Error Rate, FWER）是在所有 m 个检验中犯至少一个第一类错误的概率。FWER 控制方法力求将这个概率控制在 α 水平。


Bonferroni 校正是最简单的 FWER 控制方法：将每个检验的显著性阈值调整为 α/m。虽然简单，但过于保守——当检验数量很大时，几乎无法发现任何显著结果。


Holm 逐步下降法（Step-down）是 Bonferroni 的改进版：将 p 值从小到大排序，第 i 个 p 值与 α/(m-i+1) 比较。它在控制 FWER 的同时具有更高的功效。


interface MultipleTestResult {
  originalPValues: number[];
  adjustedPValues: number[];
  rejections: boolean[];
  method: string;
}

const bonferroni = (pValues: number[], alpha: number = 0.05): MultipleTestResult => {
  const m = pValues.length;
  const adjusted = pValues.map((p) => Math.min(p * m, 1));
  return {
    originalPValues: pValues,
    adjustedPValues: adjusted,
    rejections: adjusted.map((p) => p <= alpha),
    method: 'Bonferroni',
  };
};

const sidak = (pValues: number[], alpha: number = 0.05): MultipleTestResult => {
  const m = pValues.length;
  const adjusted = pValues.map((p) => 1 - (1 - p) ** m);
  return {
    originalPValues: pValues,
    adjustedPValues: adjusted,
    rejections: adjusted.map((p) => p <= alpha),
    method: 'Šidák',
  };
};

const holm = (pValues: number[], alpha: number = 0.05): MultipleTestResult => {
  const m = pValues.length;
  const indices = pValues.map((_, i) => i);
  indices.sort((a, b) => pValues[a] - pValues[b]);

  const adjusted = new Array(m).fill(0);
  let maxSoFar = 0;
  for (let i = 0; i < m; i++) {
    const adj = pValues[indices[i]] * (m - i);
    maxSoFar = Math.max(maxSoFar, adj);
    adjusted[indices[i]] = Math.min(maxSoFar, 1);
  }

  return {
    originalPValues: pValues,
    adjustedPValues: adjusted,
    rejections: adjusted.map((p) => p <= alpha),
    method: 'Holm',
  };
};

const hochberg = (pValues: number[], alpha: number = 0.05): MultipleTestResult => {
  const m = pValues.length;
  const indices = pValues.map((_, i) => i);
  indices.sort((a, b) => pValues[a] - pValues[b]);

  const adjusted = new Array(m).fill(0);
  let minSoFar = 1;
  for (let i = m - 1; i >= 0; i--) {
    const adj = pValues[indices[i]] * (m - i);
    minSoFar = Math.min(minSoFar, adj);
    adjusted[indices[i]] = Math.min(minSoFar, 1);
  }

  return {
    originalPValues: pValues,
    adjustedPValues: adjusted,
    rejections: adjusted.map((p) => p <= alpha),
    method: 'Hochberg',
  };
};
FDR 控制方法
错误发现率（False Discovery Rate, FDR）是被拒绝假设中假阳性所占的期望比例。相比 FWER，FDR 控制更加宽松但也更加实用——在大规模检验中，我们通常能容忍一定比例的假阳性，只要这个比例可控。


Benjamini-Hochberg (BH) 过程是最经典的 FDR 控制方法：将 p 值从小到大排序为 p*(1) ≤ ... ≤ p*(m)，找到最大的 k 使得 p*(k) ≤ kα/m，然后拒绝 H*(1), ..., H_(k)。


const benjaminiHochberg = (pValues: number[], alpha: number = 0.05): MultipleTestResult => {
  const m = pValues.length;
  const indices = pValues.map((_, i) => i);
  indices.sort((a, b) => pValues[a] - pValues[b]);

  const adjusted = new Array(m).fill(0);
  let minSoFar = 1;
  for (let i = m - 1; i >= 0; i--) {
    const adj = (pValues[indices[i]] * m) / (i + 1);
    minSoFar = Math.min(minSoFar, adj);
    adjusted[indices[i]] = Math.min(minSoFar, 1);
  }

  return {
    originalPValues: pValues,
    adjustedPValues: adjusted,
    rejections: adjusted.map((p) => p <= alpha),
    method: 'Benjamini-Hochberg',
  };
};

const benjaminiYekutieli = (pValues: number[], alpha: number = 0.05): MultipleTestResult => {
  const m = pValues.length;
  const harmonic = Array.from({ length: m }, (_, i) => 1 / (i + 1)).reduce((a, b) => a + b, 0);
  const indices = pValues.map((_, i) => i);
  indices.sort((a, b) => pValues[a] - pValues[b]);

  const adjusted = new Array(m).fill(0);
  let minSoFar = 1;
  for (let i = m - 1; i >= 0; i--) {
    const adj = (pValues[indices[i]] * m * harmonic) / (i + 1);
    minSoFar = Math.min(minSoFar, adj);
    adjusted[indices[i]] = Math.min(minSoFar, 1);
  }

  return {
    originalPValues: pValues,
    adjustedPValues: adjusted,
    rejections: adjusted.map((p) => p <= alpha),
    method: 'Benjamini-Yekutieli',
  };
};
q 值与局部 FDR
q 值（q-value）是 FDR 框架下对单个假设的显著性度量，类似于 p 值在 FWER 框架中的角色。假设 H_i 的 q 值定义为：在拒绝集中包含 H_i 时，FDR 的最小值。直观地说，q 值回答了"如果拒绝这个假设及所有更显著的假设，期望的假阳性比例是多少？"


局部 FDR（local FDR, lfdr）进一步精细化，给出每个具体假设是零假设的后验概率。

const computeQValues = (pValues: number[]): number[] => {
  const m = pValues.length;
  const indices = pValues.map((_, i) => i);
  indices.sort((a, b) => pValues[a] - pValues[b]);

  const qValues = new Array(m);
  let minQ = 1;
  for (let i = m - 1; i >= 0; i--) {
    const q = (pValues[indices[i]] * m) / (i + 1);
    minQ = Math.min(minQ, q);
    qValues[indices[i]] = Math.min(minQ, 1);
  }
  return qValues;
};

const estimatePi0 = (pValues: number[], lambda: number = 0.5): number => {
  const m = pValues.length;
  const count = pValues.filter((p) => p > lambda).length;
  return count / (m * (1 - lambda));
};

const storey_qValues = (pValues: number[]): number[] => {
  const pi0 = Math.min(estimatePi0(pValues), 1);
  const m = pValues.length;
  const indices = pValues.map((_, i) => i);
  indices.sort((a, b) => pValues[a] - pValues[b]);

  const qValues = new Array(m);
  let minQ = 1;
  for (let i = m - 1; i >= 0; i--) {
    const q = (pi0 * pValues[indices[i]] * m) / (i + 1);
    minQ = Math.min(minQ, q);
    qValues[indices[i]] = Math.min(minQ, 1);
  }
  return qValues;
};
多重检验在工程中的应用
多重检验校正在现代数据分析中无处不在。在 A/B 测试平台中，一次实验通常监控多个指标（转化率、留存率、收入等），每个指标的检验都需要校正。在特征选择中，候选特征的显著性检验也面临多重比较问题。


interface ABTestMultiMetric {
  metric: string;
  pValue: number;
  effectSize: number;
  adjustedP: number;
  significant: boolean;
}

const analyzeMultiMetricABTest = (
  metrics: Array<{ name: string; pValue: number; effectSize: number }>,
  alpha: number = 0.05,
  method: 'bonferroni' | 'holm' | 'bh' = 'bh',
): ABTestMultiMetric[] => {
  const pValues = metrics.map((m) => m.pValue);
  let result: MultipleTestResult;

  switch (method) {
    case 'bonferroni':
      result = bonferroni(pValues, alpha);
      break;
    case 'holm':
      result = holm(pValues, alpha);
      break;
    case 'bh':
      result = benjaminiHochberg(pValues, alpha);
      break;
  }

  return metrics.map((m, i) => ({
    metric: m.name,
    pValue: m.pValue,
    effectSize: m.effectSize,
    adjustedP: result.adjustedPValues[i],
    significant: result.rejections[i],
  }));
};

const featureSelection = (features: string[], pValues: number[], fdrThreshold: number = 0.1): string[] => {
  const result = benjaminiHochberg(pValues, fdrThreshold);
  return features.filter((_, i) => result.rejections[i]);
};
小结
    

  • 多重检验问题导致整体第一类错误率远超单个检验的 α 水平
    • 

  • FWER 控制（Bonferroni、Holm）适合少量检验场景，FDR 控制（BH）适合大规模筛选
    • 

  • q 值提供了每个假设在 FDR 框架下的显著性度量，是 p 值的多重检验版本
    • 

  • 在多指标 A/B 测试和特征选择中，多重校正是保证结论可靠性的必要步骤
    • 

  • 选择校正方法需权衡控制严格性和检验功效
