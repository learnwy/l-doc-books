贝叶斯定理

核心概念

贝叶斯定理是概率论中最具应用价值的定理，它描述了如何用新证据更新信念。公式 P(H|E) = P(E|H)P(H) / P(E) 将先验概率 P(H) 通过似然 P(E|H) 更新为后验概率 P(H|E)。

贝叶斯定理不仅是一个数学公式，更是一种认识论框架——它形式化了"根据证据修正信念"的过程。在机器学习中，贝叶斯方法提供了不确定性量化、正则化解释和模型选择的统一框架。

| 术语      | 含义             | 公式位置         | 编程对应   |
| --------- | ---------------- | ---------------- | ---------- | ---------- |
| 先验 P(H) | 看到证据前的信念 | 分子因子         | 初始参数   |
| 似然 P(E  | H)               | 假设下证据的概率 | 分子因子   | 模型输出   |
| 证据 P(E) | 证据的边际概率   | 分母             | 归一化常数 |
| 后验 P(H  | E)               | 看到证据后的信念 | 结果       | 更新后参数 |


贝叶斯定理的推导与应用
贝叶斯定理从条件概率定义直接推出：P(H|E) = P(H∩E)/P(E) = P(E|H)P(H)/P(E)。分母 P(E) 通过全概率公式计算：P(E) = Σ P(E|Hᵢ)P(Hᵢ)。


const bayesUpdate = (prior: number, likelihood: number, evidence: number): number => (likelihood * prior) / evidence;

const bayesWithPartition = (priors: number[], likelihoods: number[], targetIdx: number): number => {
  const evidence = priors.reduce((s, p, i) => s + likelihoods[i] * p, 0);
  return (likelihoods[targetIdx] * priors[targetIdx]) / evidence;
};

const spamFilter = (pSpam: number, wordLikelihoods: { spam: number; ham: number }[]): number => {
  let logOdds = Math.log(pSpam / (1 - pSpam));
  for (const word of wordLikelihoods) {
    logOdds += Math.log(word.spam / word.ham);
  }
  return 1 / (1 + Math.exp(-logOdds));
};

const words = [
  { spam: 0.8, ham: 0.1 },
  { spam: 0.6, ham: 0.2 },
  { spam: 0.3, ham: 0.5 },
];
console.log('垃圾邮件概率:', spamFilter(0.3, words).toFixed(4));
朴素贝叶斯分类器假设各特征在给定类别下条件独立，将联合似然分解为各特征似然的乘积。尽管独立性假设通常不成立，朴素贝叶斯在文本分类、垃圾邮件过滤等任务中表现出色。


序贯更新与信念演化
贝叶斯更新是可迭代的：今天的后验就是明天的先验。当数据逐个到达时，可以序贯地更新信念，无需重新处理所有历史数据。


const sequentialBayesUpdate = (
  prior: number,
  observations: boolean[],
  likelihoodTrue: number,
  likelihoodFalse: number,
): number[] => {
  const posteriors: number[] = [];
  let currentPrior = prior;

  for (const obs of observations) {
    const likelihood = obs ? likelihoodTrue : 1 - likelihoodTrue;
    const likelihoodH0 = obs ? likelihoodFalse : 1 - likelihoodFalse;
    const evidence = likelihood * currentPrior + likelihoodH0 * (1 - currentPrior);
    currentPrior = (likelihood * currentPrior) / evidence;
    posteriors.push(currentPrior);
  }
  return posteriors;
};

const coinBias = sequentialBayesUpdate(0.5, [true, true, false, true, true, true, false, true, true, true], 0.7, 0.5);
console.log(
  '序贯后验:',
  coinBias.map((p) => p.toFixed(3)),
);
贝叶斯因子与模型比较
贝叶斯因子 BF = P(E|H₁)/P(E|H₂) 衡量证据对两个竞争假设的相对支持程度。BF > 10 表示强支持 H₁，BF < 0.1 表示强支持 H₂。


const bayesFactor = (likelihoodH1: number, likelihoodH2: number): { bf: number; interpretation: string } => {
  const bf = likelihoodH1 / likelihoodH2;
  let interpretation: string;
  if (bf > 100) interpretation = '极强支持 H1';
  else if (bf > 10) interpretation = '强支持 H1';
  else if (bf > 3) interpretation = '中等支持 H1';
  else if (bf > 1) interpretation = '弱支持 H1';
  else if (bf > 1 / 3) interpretation = '弱支持 H2';
  else if (bf > 1 / 10) interpretation = '中等支持 H2';
  else interpretation = '强支持 H2';
  return { bf, interpretation };
};

const posteriorOdds = (priorOdds: number, bf: number): number => priorOdds * bf;
贝叶斯模型比较自动实现了"奥卡姆剃刀"：复杂模型虽然能更好地拟合数据（更高似然），但先验分布更分散（每个参数值分配的先验概率更低），边际似然可能更低。
