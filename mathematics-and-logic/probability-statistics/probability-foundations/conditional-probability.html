Part III · 概率统计与优化概率论与数理统计 简介概率基础 简介条件概率与独立性

条件概率与独立性

核心概念

条件概率是在已知某些信息的前提下重新计算概率的工具。给定事件 B 已发生（P(B) > 0），事件 A 的条件概率定义为 P(A|B) = P(A∩B) / P(B)。条件概率本质上是在缩小的样本空间 B 上重新定义的概率度量。

独立性是概率论中最重要的结构性概念之一。事件 A 和 B 独立意味着知道 B 是否发生不改变 A 的概率：P(A|B) = P(A)，等价于 P(A∩B) = P(A)·P(B)。独立性大幅简化了联合概率的计算。

| 概念     | 定义            | 公式              | 编程意义   |
| -------- | --------------- | ----------------- | ---------- | -------- | --- | ---------- |
| 条件概率 | B发生下A的概率  | P(A∩B)/P(B)       | 过滤后统计 |
| 独立性   | A与B互不影响    | P(A∩B) = P(A)P(B) | 可分解计算 |
| 条件独立 | 给定C下A与B独立 | P(A∩B             | C) = P(A   | C)P(B    | C)  | 贝叶斯网络 |
| 乘法规则 | 联合概率展开    | P(A∩B) = P(B)P(A  | B)         | 链式分解 |


条件概率的计算与直觉
条件概率的直觉是"聚焦"：当我们知道 B 已发生，就将注意力限制在 B 内，然后看 A 在 B 中占多大比例。这等价于在缩小的样本空间 B 上重新定义均匀概率。


const conditionalProbability = (pAandB: number, pB: number): number => {
  if (pB === 0) throw new Error('条件事件概率不能为零');
  return pAandB / pB;
};

const conditionalFromData = (data: boolean[][], colA: number, colB: number): number => {
  let countB = 0;
  let countAB = 0;
  for (const row of data) {
    if (row[colB]) {
      countB++;
      if (row[colA]) countAB++;
    }
  }
  return countB > 0 ? countAB / countB : 0;
};

const chainRule = (conditionals: number[]): number => conditionals.reduce((product, p) => product * p, 1);

const montyHallSimulation = (switchDoor: boolean, trials: number): number => {
  let wins = 0;
  for (let i = 0; i < trials; i++) {
    const car = Math.floor(Math.random() * 3);
    const pick = Math.floor(Math.random() * 3);
    let opened: number;
    do {
      opened = Math.floor(Math.random() * 3);
    } while (opened === car || opened === pick);

    if (switchDoor) {
      const remaining = [0, 1, 2].find((d) => d !== pick && d !== opened)!;
      if (remaining === car) wins++;
    } else {
      if (pick === car) wins++;
    }
  }
  return wins / trials;
};

console.log('不换门:', montyHallSimulation(false, 100000).toFixed(4));
console.log('换门:', montyHallSimulation(true, 100000).toFixed(4));
蒙提霍尔问题完美展示了条件概率的反直觉性：换门的胜率是 2/3，不换只有 1/3。关键在于主持人打开空门的行为提供了新信息，改变了条件概率。


独立性的判定与应用
两个事件的独立性可以通过三个等价条件判定：P(A∩B) = P(A)P(B)、P(A|B) = P(A)、P(B|A) = P(B)。多个事件的相互独立要求任意子集的交的概率等于各自概率的乘积。


const areIndependent = (pA: number, pB: number, pAB: number, tol: number = 1e-6): boolean =>
  Math.abs(pAB - pA * pB) < tol;

const testIndependenceFromData = (
  data: boolean[][],
  col1: number,
  col2: number,
): { independent: boolean; pA: number; pB: number; pAB: number; expected: number } => {
  const n = data.length;
  let countA = 0,
    countB = 0,
    countAB = 0;
  for (const row of data) {
    if (row[col1]) countA++;
    if (row[col2]) countB++;
    if (row[col1] && row[col2]) countAB++;
  }
  const pA = countA / n;
  const pB = countB / n;
  const pAB = countAB / n;
  const expected = pA * pB;
  return {
    independent: Math.abs(pAB - expected) < 3 * Math.sqrt((expected * (1 - expected)) / n),
    pA,
    pB,
    pAB,
    expected,
  };
};
在编程和系统设计中，独立性假设极为重要：哈希函数假设输入的各位独立，负载均衡假设请求到达独立，随机化算法假设随机选择独立。当独立性假设被违反时，系统性能可能大幅偏离预期。


全概率公式与链式法则
全概率公式将复杂事件的概率通过完备事件组分解：如果 B₁, B₂, ..., Bₙ 构成 Ω 的划分，则 P(A) = Σ P(A|Bᵢ)P(Bᵢ)。链式法则将联合概率展开为条件概率的乘积：P(A₁∩A₂∩...∩Aₙ) = P(A₁)P(A₂|A₁)P(A₃|A₁∩A₂)...


const totalProbability = (pAGivenB: number[], pB: number[]): number => {
  let total = 0;
  for (let i = 0; i < pB.length; i++) {
    total += pAGivenB[i] * pB[i];
  }
  return total;
};

const diseaseScreening = (
  prevalence: number,
  sensitivity: number,
  specificity: number,
): { ppv: number; npv: number; totalPositive: number } => {
  const pPositive = sensitivity * prevalence + (1 - specificity) * (1 - prevalence);
  const ppv = (sensitivity * prevalence) / pPositive;
  const pNegative = 1 - pPositive;
  const npv = (specificity * (1 - prevalence)) / pNegative;
  return { ppv, npv, totalPositive: pPositive };
};

const screening = diseaseScreening(0.001, 0.99, 0.99);
console.log('阳性预测值:', (screening.ppv * 100).toFixed(1) + '%');
疾病筛查例子展示了全概率公式和贝叶斯定理的实际威力：即使检测灵敏度和特异性都高达 99%，当疾病患病率仅 0.1% 时，阳性预测值也只有约 9%——这个反直觉的结果被称为"基率忽略"（base rate neglect）。


小结
    

  • 条件概率 P(A|B) = P(A∩B)/P(B) 是在缩小的样本空间上重新定义的概率
    • 

  • 独立性 P(A∩B) = P(A)P(B) 大幅简化联合概率计算
    • 

  • 全概率公式通过划分分解复杂事件，是贝叶斯定理的基础
    • 

  • 蒙提霍尔问题和疾病筛查展示条件概率的反直觉性
    • 

  • 独立性假设在系统设计中至关重要，违反时性能可能大幅偏离
    • 

  • 链式法则是概率图模型和序列生成（如语言模型）的数学基础
    •
