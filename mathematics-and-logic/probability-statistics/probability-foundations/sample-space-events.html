Part III · 概率统计与优化概率论与数理统计 简介概率基础 简介样本空间与事件

样本空间与事件

核心概念

样本空间和事件是概率论的基石。样本空间 Ω 是随机试验所有可能结果的集合，事件是样本空间的子集（即部分结果的集合），概率是从事件到 [0,1] 区间的函数。这三者构成了概率空间 (Ω, F, P) 的基本框架，也称为 Kolmogorov 公理化体系。

理解样本空间的选择对后续建模至关重要。同一个现实问题，选择不同的样本空间会导致不同的数学模型。掷骰子可以用 Ω = {1,2,3,4,5,6}，也可以用 Ω = {奇,偶}——选择取决于我们关心的问题。

样本空间的构造
样本空间可以是有限的（掷骰子）、可数无限的（首次成功的试验次数）或不可数无限的（等待时间）。选择样本空间时需要包含所有可能的观测结果，同时保持足够精细以描述关心的事件。


type SampleSpace<T> = Set<T>;
type Event<T> = Set<T>;

const diceSpace: SampleSpace<number> = new Set([1, 2, 3, 4, 5, 6]);

const twoDiceSpace = (): SampleSpace<string> => {
  const space = new Set<string>();
  for (let i = 1; i <= 6; i++) {
    for (let j = 1; j <= 6; j++) {
      space.add(`${i},${j}`);
    }
  }
  return space;
};

const coinFlipSpace = (n: number): SampleSpace<string> => {
  const space = new Set<string>();
  for (let i = 0; i < Math.pow(2, n); i++) {
    space.add(i.toString(2).padStart(n, '0'));
  }
  return space;
};

const isEvent = <T>(subset: Event<T>, space: SampleSpace<T>): boolean => {
  for (const element of subset) {
    if (!space.has(element)) return false;
  }
  return true;
};

console.log('掷两个骰子:', twoDiceSpace().size, '个样本点');
console.log('抛3次硬币:', coinFlipSpace(3).size, '个样本点');
对于连续样本空间（如 Ω = [0, ∞)），不能为每个单点赋予正概率（否则总概率超过1），必须对区间赋予概率。这引出了概率密度函数和 σ-代数的概念。


事件运算与集合代数
事件运算遵循集合论的规则。事件的并 A∪B 表示"A 或 B 至少一个发生"，交 A∩B 表示"A 和 B 同时发生"，补 Aᶜ 表示"A 不发生"。De Morgan 定律连接并、交与补：(A∪B)ᶜ = Aᶜ∩Bᶜ。


const union = <T>(A: Event<T>, B: Event<T>): Event<T> => {
  const result = new Set(A);
  for (const b of B) result.add(b);
  return result;
};

const intersection = <T>(A: Event<T>, B: Event<T>): Event<T> => {
  const result = new Set<T>();
  for (const a of A) {
    if (B.has(a)) result.add(a);
  }
  return result;
};

const complement = <T>(A: Event<T>, omega: SampleSpace<T>): Event<T> => {
  const result = new Set<T>();
  for (const w of omega) {
    if (!A.has(w)) result.add(w);
  }
  return result;
};

const areMutuallyExclusive = <T>(A: Event<T>, B: Event<T>): boolean => intersection(A, B).size === 0;

const deMorgan = <T>(A: Event<T>, B: Event<T>, omega: SampleSpace<T>): boolean => {
  const lhs = complement(union(A, B), omega);
  const rhs = intersection(complement(A, omega), complement(B, omega));
  if (lhs.size !== rhs.size) return false;
  for (const x of lhs) if (!rhs.has(x)) return false;
  return true;
};
互斥事件（disjoint events）满足 A∩B = ∅，即不能同时发生。完备事件组（partition）将 Ω 分成互不相交的事件，且并为 Ω。全概率公式和贝叶斯定理都建立在完备事件组之上。


Kolmogorov 概率公理
Kolmogorov 的三条公理定义了概率函数 P：(1) 非负性 P(A) ≥ 0；(2) 规范性 P(Ω) = 1；(3) 可数可加性：对互不相交的事件序列 A₁, A₂, ...，P(∪Aᵢ) = ΣP(Aᵢ)。


type ProbabilityFunction<T> = (event: Event<T>) => number;

const createUniformProb =
  <T>(omega: SampleSpace<T>): ProbabilityFunction<T> =>
  (event: Event<T>) => {
    let count = 0;
    for (const e of event) {
      if (omega.has(e)) count++;
    }
    return count / omega.size;
  };

const verifyAxioms = <T>(P: ProbabilityFunction<T>, omega: SampleSpace<T>, events: Event<T>[]): boolean => {
  if (Math.abs(P(omega) - 1) > 1e-10) return false;

  for (const A of events) {
    if (P(A) < -1e-10) return false;
  }

  for (let i = 0; i < events.length; i++) {
    for (let j = i + 1; j < events.length; j++) {
      if (areMutuallyExclusive(events[i], events[j])) {
        const pUnion = P(union(events[i], events[j]));
        const pSum = P(events[i]) + P(events[j]);
        if (Math.abs(pUnion - pSum) > 1e-10) return false;
      }
    }
  }
  return true;
};
从公理可以推导出许多基本性质：P(∅) = 0，P(Aᶜ) = 1 - P(A)，P(A∪B) = P(A) + P(B) - P(A∩B)（容斥原理），A ⊆ B 则 P(A) ≤ P(B)（单调性）。


容斥原理的一般形式用于计算多个事件的并的概率：P(A₁∪...∪Aₙ) = ΣP(Aᵢ) - ΣP(Aᵢ∩Aⱼ) + ΣP(Aᵢ∩Aⱼ∩Aₖ) - ... + (-1)ⁿ⁻¹P(A₁∩...∩Aₙ)。这在算法分析中经常用到。


概率模型与编程应用
在编程中，概率模型常用于随机模拟、AB 测试、算法分析等场景。蒙特卡洛模拟通过大量随机采样估计概率，是验证理论结果的有效工具。


const monteCarloEstimate = (
  sampleFn: () => boolean,
  trials: number,
): { probability: number; standardError: number } => {
  let successes = 0;
  for (let i = 0; i < trials; i++) {
    if (sampleFn()) successes++;
  }
  const p = successes / trials;
  const se = Math.sqrt((p * (1 - p)) / trials);
  return { probability: p, standardError: se };
};

const birthdayProblem = (n: number): number => {
  let prob = 1;
  for (let i = 1; i < n; i++) {
    prob *= (365 - i) / 365;
  }
  return 1 - prob;
};

const birthdayMC = (n: number, trials: number): number => {
  let matches = 0;
  for (let t = 0; t < trials; t++) {
    const birthdays = new Set<number>();
    let found = false;
    for (let i = 0; i < n; i++) {
      const b = Math.floor(Math.random() * 365);
      if (birthdays.has(b)) {
        found = true;
        break;
      }
      birthdays.add(b);
    }
    if (found) matches++;
  }
  return matches / trials;
};

console.log('23人生日问题（精确）:', birthdayProblem(23).toFixed(4));
console.log('23人生日问题（MC）:', birthdayMC(23, 100000).toFixed(4));
生日问题是一个反直觉的经典例子：23人中至少两人同生日的概率约50.7%。这在密码学（碰撞攻击）和哈希函数设计中有重要应用。


小结
    

  • 样本空间 Ω 包含所有可能结果，事件是 Ω 的子集，概率映射事件到 [0,1]
    • 

  • Kolmogorov 三条公理（非负、规范、可加）是概率论的逻辑基础
    • 

  • 事件运算遵循集合代数，De Morgan 定律连接并、交与补
    • 

  • 容斥原理是计算多个事件并的概率的一般工具
    • 

  • 蒙特卡洛模拟通过大量随机采样估计概率，是验证理论的有效手段
    • 

  • 概率模型的选择（样本空间的确定）直接影响后续分析的正确性
