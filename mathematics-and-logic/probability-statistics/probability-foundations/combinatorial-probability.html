组合概率与计数方法

核心概念

组合概率将计数方法应用于等可能概型（古典概型），其核心公式是 P(A) = |A| / |Ω|，即有利结果数除以总结果数。排列、组合和多项式系数是计算有利结果数和总结果数的基本工具。

组合计数在算法分析中至关重要：分析哈希碰撞概率、随机化算法的成功率、网络路由方案数、密码强度等，都需要精确的组合计数。掌握这些工具不仅帮助解决概率问题，也是理解算法复杂度的基础。

排列与组合的计算
排列 P(n,k) 计算从 n 个不同元素中选出 k 个的有序排列数。组合 C(n,k) 计算无序选择数。C(n,k) = P(n,k) / k!，因为每组 k 个元素有 k! 种排列方式。


const factorial = (n: number): number => {
  let result = 1;
  for (let i = 2; i <= n; i++) result *= i;
  return result;
};

const permutation = (n: number, k: number): number => {
  let result = 1;
  for (let i = n; i > n - k; i--) result *= i;
  return result;
};

const combination = (n: number, k: number): number => {
  if (k > n) return 0;
  if (k > n - k) k = n - k;
  let result = 1;
  for (let i = 0; i < k; i++) {
    result = (result * (n - i)) / (i + 1);
  }
  return Math.round(result);
};

const multinomial = (n: number, groups: number[]): number => {
  let result = factorial(n);
  for (const g of groups) result /= factorial(g);
  return result;
};

console.log('C(52,5):', combination(52, 5));
console.log('P(10,3):', permutation(10, 3));
二项式系数的重要恒等式：帕斯卡恒等式 C(n,k) = C(n-1,k-1) + C(n-1,k) 是动态规划计算组合数的基础。范德蒙恒等式 C(m+n,r) = Σ C(m,k)C(n,r-k) 在概率论中用于超几何分布的推导。


经典组合概率问题
const pokerHandProbability = (handType: string): number => {
  const totalHands = combination(52, 5);
  const handCounts: Record<string, number> = {
    'royal-flush': 4,
    'straight-flush': 36,
    'four-of-a-kind': 624,
    'full-house': 3744,
    flush: 5108,
    straight: 10200,
    'three-of-a-kind': 54912,
    'two-pair': 123552,
    'one-pair': 1098240,
    'high-card': 1302540,
  };
  return (handCounts[handType] ?? 0) / totalHands;
};

const couponCollector = (n: number): number => {
  let expected = 0;
  for (let i = 1; i <= n; i++) {
    expected += n / i;
  }
  return expected;
};

const derangements = (n: number): number => {
  if (n === 0) return 1;
  if (n === 1) return 0;
  let prev2 = 1,
    prev1 = 0;
  for (let i = 2; i <= n; i++) {
    const current = (i - 1) * (prev1 + prev2);
    prev2 = prev1;
    prev1 = current;
  }
  return prev1;
};

console.log('同花顺概率:', pokerHandProbability('straight-flush').toFixed(6));
console.log('集齐6种优惠券期望次数:', couponCollector(6).toFixed(1));
console.log('5封信全错排数:', derangements(5));
优惠券收集问题（Coupon Collector）的期望次数为 n·Hₙ ≈ n·ln(n)，其中 Hₙ 是调和级数。这在分析随机化算法覆盖率和缓存预热时间中有重要应用。


生成函数与渐近分析
当精确计数困难时，生成函数和斯特林近似提供了强大的工具。斯特林公式 n! ≈ √(2πn)·(n/e)ⁿ 用于近似大阶乘，在信息论和统计力学中广泛使用。


const stirlingApprox = (n: number): number => Math.sqrt(2 * Math.PI * n) * Math.pow(n / Math.E, n);

const logCombination = (n: number, k: number): number => {
  let logResult = 0;
  for (let i = 0; i < k; i++) {
    logResult += Math.log(n - i) - Math.log(i + 1);
  }
  return logResult;
};

const entropy = (p: number): number => (p === 0 || p === 1 ? 0 : -p * Math.log2(p) - (1 - p) * Math.log2(1 - p));

console.log('20! 精确:', factorial(20));
console.log('20! Stirling:', stirlingApprox(20).toFixed(0));
console.log('C(100,50) log:', logCombination(100, 50).toFixed(2));
对数组合数 log C(n,k) ≈ nH(k/n)（其中 H 是二元熵函数）是信息论的基础关系，连接了组合计数和信息量度。


小结
    

  • P(n,k) 和 C(n,k) 是排列和组合的基本计数工具
    • 

  • 帕斯卡恒等式 C(n,k) = C(n-1,k-1) + C(n-1,k) 是动态规划基础
    • 

  • 优惠券收集问题期望 n·ln(n)，在缓存和覆盖分析中广泛应用
    • 

  • 全错排列 D(n) ≈ n!/e，概率趋近 1/e ≈ 0.368
    • 

  • 斯特林近似 n! ≈ √(2πn)(n/e)ⁿ 处理大阶乘计算
    • 

  • 对数组合数与二元熵的关系是信息论的核心
