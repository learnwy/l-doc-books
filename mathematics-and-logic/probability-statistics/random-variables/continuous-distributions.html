连续型随机变量与分布

核心概念

连续型随机变量的取值是不可数的（通常是一个区间），通过概率密度函数（PDF）f(x) 描述。与离散分布不同，连续分布中单个点的概率为零，只有区间上的概率才有意义：P(a ≤ X ≤ b) = ∫[a,b] f(x)dx。累积分布函数（CDF）F(x) = P(X ≤ x) 是 PDF 的积分，单调非递减且值域为 [0,1]。

连续分布在统计推断、机器学习、信号处理中是基石。正态分布是自然界最常见的分布，均匀分布是随机数生成的起点，指数分布描述无记忆等待时间，Beta 分布和 Gamma 分布则是贝叶斯统计的基础。

正态分布与中心极限定理
正态分布（高斯分布）N(μ, σ²) 是最重要的连续分布。其 PDF 呈钟形曲线，由均值 μ 和方差 σ² 完全确定。标准正态分布 N(0,1) 的 CDF 记为 Φ(z)，任何正态分布可通过标准化 Z = (X-μ)/σ 转化为标准正态。


中心极限定理（CLT）是正态分布如此重要的根本原因：无论原始分布如何，大量独立同分布随机变量之和（适当标准化后）趋向正态分布。


const normalPDF = (x: number, mu: number = 0, sigma: number = 1): number => {
  const z = (x - mu) / sigma;
  return Math.exp(-0.5 * z * z) / (sigma * Math.sqrt(2 * Math.PI));
};

const normalCDF = (x: number, mu: number = 0, sigma: number = 1): number => {
  const z = (x - mu) / sigma;
  const t = 1 / (1 + 0.2316419 * Math.abs(z));
  const d = 0.3989422804014327;
  const p =
    d *
    Math.exp(-0.5 * z * z) *
    (t * (0.31938153 + t * (-0.356563782 + t * (1.781477937 + t * (-1.821255978 + t * 1.330274429)))));
  return z > 0 ? 1 - p : p;
};

const boxMullerSample = (mu: number = 0, sigma: number = 1): [number, number] => {
  const u1 = Math.random();
  const u2 = Math.random();
  const r = Math.sqrt(-2 * Math.log(u1));
  const theta = 2 * Math.PI * u2;
  return [mu + sigma * r * Math.cos(theta), mu + sigma * r * Math.sin(theta)];
};

const demonstrateCLT = (sampleSize: number, numSamples: number): { mean: number; std: number } => {
  const sums: number[] = [];
  for (let i = 0; i < numSamples; i++) {
    let sum = 0;
    for (let j = 0; j < sampleSize; j++) {
      sum += Math.random();
    }
    sums.push((sum - sampleSize * 0.5) / Math.sqrt(sampleSize / 12));
  }
  const mean = sums.reduce((s, x) => s + x, 0) / numSamples;
  const std = Math.sqrt(sums.reduce((s, x) => s + (x - mean) ** 2, 0) / (numSamples - 1));
  return { mean, std };
};

const clt = demonstrateCLT(30, 10000);
console.log(`CLT 验证: mean=${clt.mean.toFixed(4)} (理论 0), std=${clt.std.toFixed(4)} (理论 1)`);
正态分布的 68-95-99.7 法则：约 68% 的数据落在 μ±σ 内，95% 在 μ±2σ 内，99.7% 在 μ±3σ 内。这个法则在异常检测、质量控制、置信区间构建中广泛应用。


指数分布与无记忆性
指数分布 Exp(λ) 描述泊松过程中两次事件之间的等待时间。它是连续分布中唯一具有无记忆性的分布：P(X > s+t | X > s) = P(X > t)。参数 λ 是事件发生的速率，期望等待时间为 1/λ。


const exponentialPDF = (x: number, lambda: number): number => (x >= 0 ? lambda * Math.exp(-lambda * x) : 0);

const exponentialCDF = (x: number, lambda: number): number => (x >= 0 ? 1 - Math.exp(-lambda * x) : 0);

const exponentialSample = (lambda: number): number => -Math.log(1 - Math.random()) / lambda;

const verifyMemoryless = (lambda: number, s: number, t: number, numSamples: number): void => {
  const samples = Array.from({ length: numSamples }, () => exponentialSample(lambda));
  const survived = samples.filter((x) => x > s);
  const conditional = survived.filter((x) => x > s + t).length / survived.length;
  const marginal = samples.filter((x) => x > t).length / numSamples;
  console.log(`P(X>${s + t}|X>${s})=${conditional.toFixed(4)}, P(X>${t})=${marginal.toFixed(4)}`);
};

verifyMemoryless(0.5, 2, 3, 100000);
指数分布在可靠性工程中描述部件寿命（恒定故障率），在排队论中描述服务时间（M/M/1 队列），在网络中描述请求间隔时间。


Gamma 与 Beta 分布
Gamma 分布 Γ(α, β) 可以看作 α 个独立 Exp(β) 随机变量之和。当 α 为正整数时称为 Erlang 分布。χ² 分布是 Gamma 分布的特例：χ²(k) = Γ(k/2, 1/2)。


Beta 分布 B(α, β) 定义在 [0,1] 上，是贝叶斯统计中最常用的先验分布。Beta 分布是二项分布的共轭先验——观测到成功/失败后，后验仍是 Beta 分布，参数简单更新。


const gammaFunction = (z: number): number => {
  if (z < 0.5) return Math.PI / (Math.sin(Math.PI * z) * gammaFunction(1 - z));
  const g = 7;
  const c = [
    0.99999999999980993, 676.5203681218851, -1259.1392167224028, 771.32342877765313, -176.61502916214059,
    12.507343278686905, -0.13857109526572012, 9.9843695780195716e-6, 1.5056327351493116e-7,
  ];
  const x = c.slice(1).reduce((sum, ci, i) => sum + ci / (z + i), c[0]);
  const t = z + g - 0.5;
  return Math.sqrt(2 * Math.PI) * Math.pow(t, z - 0.5) * Math.exp(-t) * x;
};

const betaPDF = (x: number, alpha: number, beta: number): number => {
  if (x <= 0 || x >= 1) return 0;
  const B = (gammaFunction(alpha) * gammaFunction(beta)) / gammaFunction(alpha + beta);
  return (Math.pow(x, alpha - 1) * Math.pow(1 - x, beta - 1)) / B;
};

const betaSample = (alpha: number, beta: number): number => {
  const gammaSample = (shape: number): number => {
    if (shape < 1) {
      return gammaSample(shape + 1) * Math.pow(Math.random(), 1 / shape);
    }
    const d = shape - 1 / 3;
    const c = 1 / Math.sqrt(9 * d);
    while (true) {
      let x: number, v: number;
      do {
        x = boxMullerSample()[0];
        v = 1 + c * x;
      } while (v <= 0);
      v = v * v * v;
      const u = Math.random();
      if (u < 1 - 0.0331 * x * x * x * x) return d * v;
      if (Math.log(u) < 0.5 * x * x + d * (1 - v + Math.log(v))) return d * v;
    }
  };
  const x = gammaSample(alpha);
  const y = gammaSample(beta);
  return x / (x + y);
};

const bayesianUpdate = (priorAlpha: number, priorBeta: number, successes: number, failures: number) => ({
  alpha: priorAlpha + successes,
  beta: priorBeta + failures,
  mean: (priorAlpha + successes) / (priorAlpha + priorBeta + successes + failures),
});

const prior = { alpha: 2, beta: 2 };
const posterior = bayesianUpdate(prior.alpha, prior.beta, 7, 3);
console.log(`先验 Beta(${prior.alpha},${prior.beta}), 观测 7/10`);
console.log(`后验 Beta(${posterior.alpha},${posterior.beta}), E[p]=${posterior.mean.toFixed(4)}`);
小结
    

  • 连续随机变量通过 PDF 描述，单点概率为零，只有区间概率有意义
    • 

  • 正态分布因中心极限定理而成为最重要的分布，大量独立随机变量之和趋向正态
    • 

  • 指数分布是唯一无记忆的连续分布，描述恒定速率下的等待时间
    • 

  • Gamma 分布是指数分布之和，χ² 分布是其特例
    • 

  • Beta 分布是二项分布的共轭先验，在贝叶斯推断中参数更新极为简洁
    • 

  • 逆变换采样是从均匀分布生成任意连续分布样本的通用方法
