联合分布与边际分布

核心概念

联合分布描述多个随机变量同时取值的概率规律。对离散型随机变量 (X,Y)，联合 PMF 为 P(X=x, Y=y)；对连续型，联合 PDF 为 f(x,y)，满足 ∫∫ f(x,y)dxdy = 1。从联合分布可以导出边际分布（对其中一个变量积分/求和）和条件分布（固定一个变量的值）。

联合分布在多变量统计分析、机器学习特征建模、金融风险计算中至关重要。多维正态分布是最重要的联合分布，其边际分布和条件分布都是正态分布，且由均值向量和协方差矩阵完全确定。

离散联合分布
离散联合分布可以用概率表格完整表示。每个单元格是一对取值的联合概率，行（或列）求和得到边际概率。


type JointPMF = Map<string, number>;

const createJointPMF = (data: Array<[number, number, number]>): JointPMF => {
  const pmf = new Map<string, number>();
  for (const [x, y, p] of data) {
    pmf.set(`${x},${y}`, p);
  }
  return pmf;
};

const marginalX = (joint: JointPMF, yValues: number[]): Map<number, number> => {
  const marginal = new Map<number, number>();
  for (const [key, p] of joint) {
    const x = Number(key.split(',')[0]);
    marginal.set(x, (marginal.get(x) ?? 0) + p);
  }
  return marginal;
};

const conditionalYGivenX = (joint: JointPMF, xVal: number, yValues: number[]): Map<number, number> => {
  let pX = 0;
  const conditional = new Map<number, number>();
  for (const [key, p] of joint) {
    const [x, y] = key.split(',').map(Number);
    if (x === xVal) {
      pX += p;
      conditional.set(y, p);
    }
  }
  for (const [y, p] of conditional) {
    conditional.set(y, p / pX);
  }
  return conditional;
};

const isIndependent = (joint: JointPMF, xValues: number[], yValues: number[]): boolean => {
  const mX = marginalX(joint, yValues);
  const mY = new Map<number, number>();
  for (const [key, p] of joint) {
    const y = Number(key.split(',')[1]);
    mY.set(y, (mY.get(y) ?? 0) + p);
  }
  for (const [key, p] of joint) {
    const [x, y] = key.split(',').map(Number);
    const expected = (mX.get(x) ?? 0) * (mY.get(y) ?? 0);
    if (Math.abs(p - expected) > 1e-10) return false;
  }
  return true;
};

const joint = createJointPMF([
  [0, 0, 0.2],
  [0, 1, 0.1],
  [1, 0, 0.3],
  [1, 1, 0.4],
]);
console.log('独立性检验:', isIndependent(joint, [0, 1], [0, 1]));
const condY = conditionalYGivenX(joint, 1, [0, 1]);
console.log('P(Y|X=1):', Object.fromEntries(condY));
多维正态分布
多维正态分布 N(μ, Σ) 由均值向量 μ 和协方差矩阵 Σ 完全确定。二维情形下，协方差矩阵包含两个方差和一个协方差（或相关系数 ρ）。多维正态的核心性质：(1) 边际分布仍是正态；(2) 条件分布仍是正态；(3) 不相关等价于独立。


type Matrix = number[][];

const multivariateNormalPDF = (x: number[], mu: number[], sigma: Matrix): number => {
  const n = x.length;
  const diff = x.map((xi, i) => xi - mu[i]);
  const det = sigma[0][0] * sigma[1][1] - sigma[0][1] * sigma[1][0];
  const inv: Matrix = [
    [sigma[1][1] / det, -sigma[0][1] / det],
    [-sigma[1][0] / det, sigma[0][0] / det],
  ];
  const exponent = -0.5 * diff.reduce((s, di, i) => s + di * inv[i].reduce((ss, aij, j) => ss + aij * diff[j], 0), 0);
  return Math.exp(exponent) / (Math.pow(2 * Math.PI, n / 2) * Math.sqrt(Math.abs(det)));
};

const bivariateNormalSample = (mu: [number, number], sigma1: number, sigma2: number, rho: number): [number, number] => {
  const u1 = Math.random(),
    u2 = Math.random();
  const z1 = Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
  const z2 = Math.sqrt(-2 * Math.log(u1)) * Math.sin(2 * Math.PI * u2);
  const x1 = mu[0] + sigma1 * z1;
  const x2 = mu[1] + sigma2 * (rho * z1 + Math.sqrt(1 - rho * rho) * z2);
  return [x1, x2];
};

const conditionalNormal = (
  mu: [number, number],
  sigma1: number,
  sigma2: number,
  rho: number,
  x1Given: number,
): { muCond: number; sigmaCond: number } => ({
  muCond: mu[1] + rho * (sigma2 / sigma1) * (x1Given - mu[0]),
  sigmaCond: sigma2 * Math.sqrt(1 - rho * rho),
});

const samples = Array.from({ length: 10000 }, () => bivariateNormalSample([0, 0], 1, 1, 0.7));
const empCorr = (() => {
  const xs = samples.map((s) => s[0]),
    ys = samples.map((s) => s[1]);
  const mx = xs.reduce((s, x) => s + x, 0) / xs.length;
  const my = ys.reduce((s, y) => s + y, 0) / ys.length;
  const cov = xs.reduce((s, x, i) => s + (x - mx) * (ys[i] - my), 0) / (xs.length - 1);
  const sx = Math.sqrt(xs.reduce((s, x) => s + (x - mx) ** 2, 0) / (xs.length - 1));
  const sy = Math.sqrt(ys.reduce((s, y) => s + (y - my) ** 2, 0) / (ys.length - 1));
  return cov / (sx * sy);
})();
console.log(`经验相关系数: ${empCorr.toFixed(4)} (理论值 0.7)`);

const cond = conditionalNormal([0, 0], 1, 1, 0.7, 2);
console.log(`X₂|X₁=2: μ=${cond.muCond.toFixed(3)}, σ=${cond.sigmaCond.toFixed(3)}`);
边际化与变量变换
从联合分布求边际分布的过程称为边际化（Marginalization）。在贝叶斯推断中，边际化用于计算证据 p(data) = ∫ p(data|θ)p(θ)dθ，消除模型参数。


变量变换公式将一个分布转换为另一个分布。若 Y = g(X) 且 g 单调，则 f_Y(y) = f_X(g⁻¹(y)) · |d(g⁻¹)/dy|。多维情形使用 Jacobian 行列式。


const marginalize = (
  jointSamples: [number, number][],
  bins: number = 50,
  range: [number, number] = [-5, 5],
): { xHist: number[]; yHist: number[]; binEdges: number[] } => {
  const binWidth = (range[1] - range[0]) / bins;
  const binEdges = Array.from({ length: bins + 1 }, (_, i) => range[0] + i * binWidth);
  const xHist = Array(bins).fill(0);
  const yHist = Array(bins).fill(0);

  for (const [x, y] of jointSamples) {
    const xi = Math.floor((x - range[0]) / binWidth);
    const yi = Math.floor((y - range[0]) / binWidth);
    if (xi >= 0 && xi < bins) xHist[xi]++;
    if (yi >= 0 && yi < bins) yHist[yi]++;
  }

  const total = jointSamples.length * binWidth;
  return {
    xHist: xHist.map((c) => c / total),
    yHist: yHist.map((c) => c / total),
    binEdges,
  };
};

const transformedDistribution = (samples: number[], transform: (x: number) => number): number[] =>
  samples.map(transform);

const normalSamples = Array.from({ length: 50000 }, () => {
  const u1 = Math.random(),
    u2 = Math.random();
  return Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
});
const lognormalSamples = transformedDistribution(normalSamples, (x) => Math.exp(x));
const lnMean = lognormalSamples.reduce((s, x) => s + x, 0) / lognormalSamples.length;
console.log(`对数正态均值: ${lnMean.toFixed(4)} (理论值 e^0.5≈${Math.exp(0.5).toFixed(4)})`);
Copula 与依赖结构
Copula 函数将边际分布和依赖结构分离。Sklar 定理指出：任何联合分布可以分解为边际分布和一个 Copula 函数 C：F(x,y) = C(F_X(x), F_Y(y))。Copula 在金融风险建模中广泛使用，可以独立建模每个变量的分布和它们之间的依赖关系。


const gaussianCopulaSample = (rho: number, n: number): [number, number][] => {
  const samples: [number, number][] = [];
  for (let i = 0; i < n; i++) {
    const u1 = Math.random(),
      u2 = Math.random();
    const z1 = Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
    const z2 = Math.sqrt(-2 * Math.log(u1)) * Math.sin(2 * Math.PI * u2);
    const w1 = z1;
    const w2 = rho * z1 + Math.sqrt(1 - rho * rho) * z2;
    const normalCDF = (x: number): number => {
      const t = 1 / (1 + 0.2316419 * Math.abs(x));
      const d = 0.3989422804014327;
      const p =
        d *
        Math.exp(-0.5 * x * x) *
        (t * (0.31938153 + t * (-0.356563782 + t * (1.781477937 + t * (-1.821255978 + t * 1.330274429)))));
      return x > 0 ? 1 - p : p;
    };
    samples.push([normalCDF(w1), normalCDF(w2)]);
  }
  return samples;
};

const copulaSamples = gaussianCopulaSample(0.8, 5000);
const u1s = copulaSamples.map((s) => s[0]);
const u2s = copulaSamples.map((s) => s[1]);
const rankCorr = (() => {
  const mx = u1s.reduce((s, x) => s + x, 0) / u1s.length;
  const my = u2s.reduce((s, y) => s + y, 0) / u2s.length;
  const cov = u1s.reduce((s, x, i) => s + (x - mx) * (u2s[i] - my), 0) / (u1s.length - 1);
  const sx = Math.sqrt(u1s.reduce((s, x) => s + (x - mx) ** 2, 0) / (u1s.length - 1));
  const sy = Math.sqrt(u2s.reduce((s, y) => s + (y - my) ** 2, 0) / (u2s.length - 1));
  return cov / (sx * sy);
})();
console.log(`Gaussian Copula(ρ=0.8) 相关系数: ${rankCorr.toFixed(4)}`);
小结
    

  • 联合分布完整描述多变量概率关系，边际分布通过积分/求和消除变量
    • 

  • 条件分布是贝叶斯推断的数学基础：f(θ|data) ∝ f(data|θ)·f(θ)
    • 

  • 多维正态分布的边际和条件分布仍是正态，且不相关等价于独立
    • 

  • 变量变换通过 Jacobian 行列式将一个分布映射到另一个分布
    • 

  • Copula 将边际分布和依赖结构解耦，适用于复杂相关性建模
    • 

  • 理解联合分布是掌握多元统计、贝叶斯推断和机器学习的前提
