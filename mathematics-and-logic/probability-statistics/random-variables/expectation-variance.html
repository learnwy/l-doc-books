期望与方差

核心概念

期望（Expectation）和方差（Variance）是描述随机变量最重要的两个数字特征。期望 E[X] 刻画了随机变量的"中心位置"——大量独立重复试验的算术平均值趋向期望（大数定律）。方差 Var(X) = E[(X-E[X])²] 刻画了随机变量围绕期望的"离散程度"。标准差 σ = √Var(X) 与原始数据同量纲，更便于直观解读。

在工程和数据科学中，期望是预测的基准，方差度量不确定性。风险管理中"收益的期望 vs 方差"构成均值-方差框架；机器学习中"偏差-方差权衡"决定模型复杂度；信号处理中"信噪比"本质上是信号方差与噪声方差之比。

期望的计算与线性性
离散型随机变量 X 的期望定义为 E[X] = Σ x·P(X=x)，连续型为 E[X] = ∫ x·f(x)dx。期望最强大的性质是线性性：E[aX + bY + c] = aE[X] + bE[Y] + c，这对任意随机变量成立，不要求独立性。


const discreteExpectation = (values: number[], probs: number[]): number =>
  values.reduce((sum, x, i) => sum + x * probs[i], 0);

const discreteVariance = (values: number[], probs: number[]): number => {
  const mu = discreteExpectation(values, probs);
  return values.reduce((sum, x, i) => sum + (x - mu) ** 2 * probs[i], 0);
};

const sampleExpectation = (samples: number[]): number => samples.reduce((sum, x) => sum + x, 0) / samples.length;

const sampleVariance = (samples: number[], ddof: number = 1): number => {
  const mean = sampleExpectation(samples);
  const sumSq = samples.reduce((sum, x) => sum + (x - mean) ** 2, 0);
  return sumSq / (samples.length - ddof);
};

const monteCarloExpectation = (
  sampler: () => number,
  g: (x: number) => number,
  n: number,
): { mean: number; se: number } => {
  const values = Array.from({ length: n }, () => g(sampler()));
  const mean = sampleExpectation(values);
  const variance = sampleVariance(values);
  return { mean, se: Math.sqrt(variance / n) };
};

const diceValues = [1, 2, 3, 4, 5, 6];
const diceProbs = Array(6).fill(1 / 6);
console.log(`骰子 E[X]=${discreteExpectation(diceValues, diceProbs).toFixed(4)}`);
console.log(`骰子 Var(X)=${discreteVariance(diceValues, diceProbs).toFixed(4)}`);

const mc = monteCarloExpectation(
  () => Math.random(),
  (x) => x * x,
  100000,
);
console.log(`E[U²]=${mc.mean.toFixed(4)} ± ${mc.se.toFixed(4)} (理论值 1/3≈0.3333)`);
期望的线性性使得复杂期望的计算变得简单。例如，计算 n 次掷骰子总和的期望不需要枚举所有可能：E[X₁+...+Xₙ] = nE[X₁] = n × 3.5 = 3.5n。指示变量技巧是线性性的经典应用：将复杂事件分解为指示变量之和，分别求期望再加总。


方差与标准差
方差的计算公式 Var(X) = E[X²] - E[X]² 在编程中更高效（单遍扫描），但数值上可能因为"大数减大数"而损失精度。Welford 在线算法可以在单遍扫描中稳定地计算方差。


const welfordVariance = (samples: number[]): { mean: number; variance: number } => {
  let n = 0;
  let mean = 0;
  let m2 = 0;

  for (const x of samples) {
    n++;
    const delta = x - mean;
    mean += delta / n;
    const delta2 = x - mean;
    m2 += delta * delta2;
  }

  return { mean, variance: n > 1 ? m2 / (n - 1) : 0 };
};

const chebyshevBound = (k: number): number => 1 / (k * k);

const verifyChebyshev = (samples: number[], k: number): void => {
  const { mean, variance } = welfordVariance(samples);
  const sigma = Math.sqrt(variance);
  const empirical = samples.filter((x) => Math.abs(x - mean) >= k * sigma).length / samples.length;
  const bound = chebyshevBound(k);
  console.log(`|X-μ|≥${k}σ: 实际=${empirical.toFixed(4)}, Chebyshev 上界=${bound.toFixed(4)}`);
};

const normalSamples = Array.from({ length: 100000 }, () => {
  const u1 = Math.random(),
    u2 = Math.random();
  return Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
});

verifyChebyshev(normalSamples, 2);
verifyChebyshev(normalSamples, 3);
切比雪夫不等式 P(|X-μ| ≥ kσ) ≤ 1/k² 对任意分布成立，给出了"距离均值 k 个标准差以外"的概率上界。这个界对正态分布是松的（实际概率远小于上界），但对任意未知分布已经提供了有用的信息。


协方差与相关系数
协方差 Cov(X,Y) = E[(X-E[X])(Y-E[Y])] = E[XY] - E[X]E[Y] 度量两个随机变量的线性关联程度。相关系数 ρ(X,Y) = Cov(X,Y)/(σ_X·σ_Y) 是标准化的协方差，取值在 [-1, 1]。


方差的可加性依赖于独立性：Var(X+Y) = Var(X) + Var(Y) + 2Cov(X,Y)。当 X, Y 独立时 Cov(X,Y) = 0，方差可加。但协方差为零不一定意味着独立——协方差只度量线性关联。


const covariance = (x: number[], y: number[]): number => {
  const n = x.length;
  const meanX = x.reduce((s, v) => s + v, 0) / n;
  const meanY = y.reduce((s, v) => s + v, 0) / n;
  return x.reduce((s, xi, i) => s + (xi - meanX) * (y[i] - meanY), 0) / (n - 1);
};

const correlation = (x: number[], y: number[]): number => {
  const cov = covariance(x, y);
  const { variance: varX } = welfordVariance(x);
  const { variance: varY } = welfordVariance(y);
  return cov / (Math.sqrt(varX) * Math.sqrt(varY));
};

const n = 10000;
const x = Array.from({ length: n }, () => Math.random() * 10);
const yLinear = x.map((xi) => 2 * xi + 3 + (Math.random() - 0.5));
const yQuadratic = x.map((xi) => (xi - 5) ** 2 + Math.random());

console.log(`线性关系: ρ=${correlation(x, yLinear).toFixed(4)}`);
console.log(`二次关系: ρ=${correlation(x, yQuadratic).toFixed(4)}`);

条件期望与全期望公式
条件期望 E[X|Y=y] 是给定 Y 值时 X 的期望，它是 Y 的函数。全期望公式（迭代期望法则）E[X] = E[E[X|Y]] 是概率论中最强大的计算工具之一——将复杂期望分解为条件期望，再对条件求期望。


const conditionalExpectation = (
  xSamples: number[],
  ySamples: number[],
  yValue: number,
  bandwidth: number = 0.5,
): number => {
  let sumWeighted = 0;
  let sumWeights = 0;
  for (let i = 0; i < xSamples.length; i++) {
    const weight = Math.exp(-0.5 * ((ySamples[i] - yValue) / bandwidth) ** 2);
    sumWeighted += weight * xSamples[i];
    sumWeights += weight;
  }
  return sumWeighted / sumWeights;
};

const totalExpectation = (xSamples: number[], ySamples: number[], yValues: number[], yProbs: number[]): number => {
  let total = 0;
  for (let i = 0; i < yValues.length; i++) {
    const condE = conditionalExpectation(xSamples, ySamples, yValues[i]);
    total += condE * yProbs[i];
  }
  return total;
};

console.log('全期望公式: E[X] = E[E[X|Y]]');
条件方差公式：Var(X) = E[Var(X|Y)] + Var(E[X|Y])。第一项是"组内方差的期望"，第二项是"组间均值的方差"，两者之和等于总方差。这个分解在方差分析（ANOVA）中是核心。


小结
    

  • 期望的线性性对任意随机变量成立，是最强大的计算工具
    • 

  • 方差度量不确定性，Welford 算法可在线单遍计算且数值稳定
    • 

  • 切比雪夫不等式对任意分布给出尾概率的通用上界
    • 

  • 协方差度量线性关联，ρ=0 表示不相关但不一定独立
    • 

  • 全期望公式将复杂期望分解为条件期望的期望
    • 

  • 条件方差分解 Var(X) = E[Var(X|Y)] + Var(E[X|Y]) 是 ANOVA 的数学基础
