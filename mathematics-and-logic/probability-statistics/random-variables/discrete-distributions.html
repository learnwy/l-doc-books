离散型随机变量与分布

核心概念

离散型随机变量是取值为可数集（有限个或可列无穷个）的随机变量。每个取值对应一个概率，所有概率之和为 1。离散分布通过概率质量函数（PMF）P(X = x) 完整描述随机变量的统计特性。掌握常见离散分布是理解概率论和统计推断的基础，也是数据科学、算法分析和系统建模的必备知识。

在编程中，离散分布无处不在：伯努利分布描述 A/B 测试中的成功/失败、二项分布统计一批请求中的失败数、泊松分布建模单位时间内的事件到达数、几何分布描述"首次成功"的等待时间。

伯努利与二项分布
伯努利分布是最简单的离散分布，描述单次试验的两种结果。二项分布描述 n 次独立伯努利试验中成功的总次数。当 n 很大而 p 很小时，二项分布可以用泊松分布近似（λ = np）。


const factorial = (n: number): number => {
  let result = 1;
  for (let i = 2; i <= n; i++) result *= i;
  return result;
};

const combination = (n: number, k: number): number => {
  if (k > n || k < 0) return 0;
  if (k === 0 || k === n) return 1;
  let result = 1;
  for (let i = 0; i < Math.min(k, n - k); i++) {
    result = (result * (n - i)) / (i + 1);
  }
  return Math.round(result);
};

const binomialPMF = (n: number, p: number, k: number): number =>
  combination(n, k) * Math.pow(p, k) * Math.pow(1 - p, n - k);

const binomialCDF = (n: number, p: number, k: number): number => {
  let sum = 0;
  for (let i = 0; i <= k; i++) sum += binomialPMF(n, p, i);
  return sum;
};

const binomialSample = (n: number, p: number): number => {
  let successes = 0;
  for (let i = 0; i < n; i++) {
    if (Math.random() < p) successes++;
  }
  return successes;
};

const n = 100,
  p = 0.3;
console.log(`B(${n}, ${p}): E[X]=${n * p}, Var[X]=${n * p * (1 - p)}`);
console.log(`P(X=30)=${binomialPMF(n, p, 30).toFixed(6)}`);
console.log(`P(X≤30)=${binomialCDF(n, p, 30).toFixed(6)}`);
二项分布的正态近似：当 np ≥ 5 且 n(1-p) ≥ 5 时，B(n,p) ≈ N(np, np(1-p))，这个近似使得大规模概率计算变得高效。


泊松分布与稀有事件
泊松分布描述固定时间（或空间）区间内独立事件发生次数的分布。参数 λ 同时是期望和方差——这个"均值=方差"的特性是泊松分布的标志性特征。


泊松分布可以看作二项分布的极限情形：n → ∞, p → 0, np → λ。在实际中，当事件独立、均匀发生，且发生概率很小时，计数服从泊松分布。


const poissonPMF = (lambda: number, k: number): number => {
  let logP = -lambda;
  for (let i = 1; i <= k; i++) {
    logP += Math.log(lambda) - Math.log(i);
  }
  return Math.exp(logP);
};

const poissonCDF = (lambda: number, k: number): number => {
  let sum = 0;
  for (let i = 0; i <= k; i++) sum += poissonPMF(lambda, i);
  return sum;
};

const poissonSample = (lambda: number): number => {
  const L = Math.exp(-lambda);
  let k = 0;
  let p = 1;
  do {
    k++;
    p *= Math.random();
  } while (p > L);
  return k - 1;
};

const lambda = 5;
console.log(`Pois(${lambda}): E[X]=${lambda}, Var[X]=${lambda}`);
console.log(`P(X=5)=${poissonPMF(lambda, 5).toFixed(6)}`);
console.log(`P(X≤3)=${poissonCDF(lambda, 3).toFixed(6)}`);

const samples = Array.from({ length: 10000 }, () => poissonSample(lambda));
const mean = samples.reduce((s, x) => s + x, 0) / samples.length;
const variance = samples.reduce((s, x) => s + (x - mean) ** 2, 0) / (samples.length - 1);
console.log(`蒙特卡洛: mean=${mean.toFixed(3)}, var=${variance.toFixed(3)}`);
几何分布与等待时间
几何分布描述"直到首次成功所需的试验次数"。如果每次试验成功概率为 p，那么首次成功在第 k 次试验的概率为 P(X=k) = (1-p)^{k-1}·p。几何分布是唯一具有无记忆性的离散分布：P(X > s+t | X > s) = P(X > t)。


const geometricPMF = (p: number, k: number): number => Math.pow(1 - p, k - 1) * p;

const geometricCDF = (p: number, k: number): number => 1 - Math.pow(1 - p, k);

const geometricSample = (p: number): number => {
  let k = 1;
  while (Math.random() >= p) k++;
  return k;
};

const geometricMean = (p: number): number => 1 / p;
const geometricVariance = (p: number): number => (1 - p) / (p * p);

const pSuccess = 0.1;
console.log(`Geo(${pSuccess}): E[X]=${geometricMean(pSuccess)}, Var[X]=${geometricVariance(pSuccess).toFixed(2)}`);
console.log(`P(X=5)=${geometricPMF(pSuccess, 5).toFixed(6)}`);
console.log(`P(X≤10)=${geometricCDF(pSuccess, 10).toFixed(6)}`);

const geoSamples = Array.from({ length: 10000 }, () => geometricSample(pSuccess));
const geoMean = geoSamples.reduce((s, x) => s + x, 0) / geoSamples.length;
console.log(`蒙特卡洛 E[X]=${geoMean.toFixed(2)} (理论值 ${geometricMean(pSuccess)})`);
无记忆性在系统设计中意味着：如果故障在每个时间步独立发生，那么"已经等了很久没故障"并不意味着即将发生故障。这就是为什么指数退避重试策略在无记忆场景下是合理的。


分布间的关系网络
离散分布之间存在丰富的数学关系。理解这些关系有助于选择正确的模型和进行近似计算。

小结
    

  • 离散型随机变量通过概率质量函数 PMF 完整描述，所有概率之和为 1
    • 

  • 二项分布是 n 次独立伯努利试验的成功总数，期望 np、方差 np(1-p)
    • 

  • 泊松分布描述稀有事件计数，其"均值=方差"特性是重要标志
    • 

  • 几何分布具有无记忆性，是离散分布中唯一满足此性质的分布
    • 

  • 各分布间通过求和、极限、近似构成丰富的关系网络
    • 

  • 选择分布模型时需考虑：独立性、放回/不放回、计数/等待等场景特征
