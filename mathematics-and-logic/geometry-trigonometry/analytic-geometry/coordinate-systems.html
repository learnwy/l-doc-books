坐标系统

核心概念

坐标系统是将几何空间中的点与数组（坐标）对应的规则。不同的坐标系适用于不同的问题场景——笛卡尔坐标适合线性运算，极坐标适合旋转对称问题，球坐标适合 3D 空间中的方向表示。理解坐标系之间的转换是图形编程、物理模拟和地理计算的基础。

选择合适的坐标系可以极大简化问题。例如，在笛卡尔坐标下描述圆需要二次方程 x² + y² = r²，而在极坐标下只需 r = R。同样，GPS 导航使用球坐标（经纬度），而屏幕渲染使用笛卡尔坐标。坐标系转换是连接这些不同表示的桥梁。

笛卡尔坐标系
笛卡尔坐标系（直角坐标系）由互相垂直的坐标轴定义。2D 空间用 (x, y) 表示，3D 空间用 (x, y, z) 表示。它是编程中最常用的坐标系——屏幕像素、DOM 元素位置、3D 模型顶点都使用笛卡尔坐标。


笛卡尔坐标的优势在于线性运算的简洁性：向量加法、标量乘法、矩阵变换都可以逐分量计算。但对于涉及角度和距离的问题（如碰撞检测中的圆形区域），笛卡尔坐标可能不是最优选择。


interface Point2D {
  x: number;
  y: number;
}

interface Point3D {
  x: number;
  y: number;
  z: number;
}

function distance2D(a: Point2D, b: Point2D): number {
  return Math.sqrt((a.x - b.x) ** 2 + (a.y - b.y) ** 2);
}

function distance3D(a: Point3D, b: Point3D): number {
  return Math.sqrt((a.x - b.x) ** 2 + (a.y - b.y) ** 2 + (a.z - b.z) ** 2);
}

function midpoint2D(a: Point2D, b: Point2D): Point2D {
  return { x: (a.x + b.x) / 2, y: (a.y + b.y) / 2 };
}

function lerp2D(a: Point2D, b: Point2D, t: number): Point2D {
  return {
    x: a.x + (b.x - a.x) * t,
    y: a.y + (b.y - a.y) * t,
  };
}

function sectionPoint(a: Point2D, b: Point2D, m: number, n: number): Point2D {
  return {
    x: (n * a.x + m * b.x) / (m + n),
    y: (n * a.y + m * b.y) / (m + n),
  };
}
在计算机图形学中，需要注意不同坐标系的约定差异：数学坐标系 y 轴向上，而屏幕坐标系 y 轴向下；3D 图形中存在左手坐标系（DirectX）和右手坐标系（OpenGL）的区别。


极坐标系
极坐标用距离 r 和角度 θ 描述平面上的点。极坐标在处理旋转对称图形、螺旋曲线和周期运动时特别自然。


极坐标与笛卡尔坐标的转换：


    

  • 极→笛卡尔：x = r cos θ, y = r sin θ
    • 

  • 笛卡尔→极：r = √(x² + y²), θ = atan2(y, x)
    • 



interface PolarPoint {
  r: number;
  theta: number;
}

function polarToCartesian(p: PolarPoint): Point2D {
  return {
    x: p.r * Math.cos(p.theta),
    y: p.r * Math.sin(p.theta),
  };
}

function cartesianToPolar(p: Point2D): PolarPoint {
  return {
    r: Math.sqrt(p.x * p.x + p.y * p.y),
    theta: Math.atan2(p.y, p.x),
  };
}

function polarCurve(rFunc: (theta: number) => number, thetaStart: number, thetaEnd: number, steps: number): Point2D[] {
  const points: Point2D[] = [];
  for (let i = 0; i <= steps; i++) {
    const theta = thetaStart + (thetaEnd - thetaStart) * (i / steps);
    const r = rFunc(theta);
    points.push(polarToCartesian({ r, theta }));
  }
  return points;
}

function rosesCurve(theta: number, petals: number): number {
  return Math.cos(petals * theta);
}

function spiralCurve(theta: number, a: number, b: number): number {
  return a + b * theta;
}

function lemniscateCurve(theta: number, a: number): number {
  const cos2t = Math.cos(2 * theta);
  return cos2t >= 0 ? a * Math.sqrt(cos2t) : 0;
}

柱坐标与球坐标
柱坐标 (r, θ, z) 是极坐标向三维空间的自然延伸：在水平面上使用极坐标 (r, θ)，垂直方向使用高度 z。适用于轴对称问题。


球坐标 (r, θ, φ) 用径向距离 r、极角 θ（从 z 轴量起）和方位角 φ（在 xy 平面上从 x 轴量起）描述空间点。适用于球对称问题和方向表示。


interface CylindricalPoint {
  r: number;
  theta: number;
  z: number;
}

interface SphericalPoint {
  r: number;
  theta: number;
  phi: number;
}

function cylindricalToCartesian(p: CylindricalPoint): Point3D {
  return {
    x: p.r * Math.cos(p.theta),
    y: p.r * Math.sin(p.theta),
    z: p.z,
  };
}

function cartesianToCylindrical(p: Point3D): CylindricalPoint {
  return {
    r: Math.sqrt(p.x * p.x + p.y * p.y),
    theta: Math.atan2(p.y, p.x),
    z: p.z,
  };
}

function sphericalToCartesian(s: SphericalPoint): Point3D {
  return {
    x: s.r * Math.sin(s.theta) * Math.cos(s.phi),
    y: s.r * Math.sin(s.theta) * Math.sin(s.phi),
    z: s.r * Math.cos(s.theta),
  };
}

function cartesianToSpherical(p: Point3D): SphericalPoint {
  const r = Math.sqrt(p.x ** 2 + p.y ** 2 + p.z ** 2);
  return {
    r,
    theta: r > 1e-15 ? Math.acos(Math.max(-1, Math.min(1, p.z / r))) : 0,
    phi: Math.atan2(p.y, p.x),
  };
}
坐标变换与齐次坐标
在计算机图形学中，坐标变换（平移、旋转、缩放）是最基本的操作。使用齐次坐标可以将所有仿射变换统一为矩阵乘法，这对 GPU 流水线极为重要。


2D 齐次坐标将 (x, y) 扩展为 (x, y, 1)，使平移变换也能用矩阵乘法表示。


type Matrix3x3 = [[number, number, number], [number, number, number], [number, number, number]];

function identityMatrix(): Matrix3x3 {
  return [
    [1, 0, 0],
    [0, 1, 0],
    [0, 0, 1],
  ];
}

function translationMatrix(tx: number, ty: number): Matrix3x3 {
  return [
    [1, 0, tx],
    [0, 1, ty],
    [0, 0, 1],
  ];
}

function rotationMatrix(angle: number): Matrix3x3 {
  const c = Math.cos(angle);
  const s = Math.sin(angle);
  return [
    [c, -s, 0],
    [s, c, 0],
    [0, 0, 1],
  ];
}

function scalingMatrix(sx: number, sy: number): Matrix3x3 {
  return [
    [sx, 0, 0],
    [0, sy, 0],
    [0, 0, 1],
  ];
}

function multiplyMatrix(a: Matrix3x3, b: Matrix3x3): Matrix3x3 {
  const result: Matrix3x3 = [
    [0, 0, 0],
    [0, 0, 0],
    [0, 0, 1],
  ];
  for (let i = 0; i < 3; i++) {
    for (let j = 0; j < 3; j++) {
      result[i][j] = a[i][0] * b[0][j] + a[i][1] * b[1][j] + a[i][2] * b[2][j];
    }
  }
  return result;
}

function transformPoint(m: Matrix3x3, p: Point2D): Point2D {
  return {
    x: m[0][0] * p.x + m[0][1] * p.y + m[0][2],
    y: m[1][0] * p.x + m[1][1] * p.y + m[1][2],
  };
}

小结
    

  • 笛卡尔坐标系是编程中最常用的坐标系，适合线性运算和矩阵变换
    • 

  • 极坐标系用 (r, θ) 描述平面点，适合旋转对称和曲线描述（玫瑰线、螺旋线）
    • 

  • 柱坐标是极坐标的三维延伸，球坐标用径向距离和两个角度描述空间点
    • 

  • 坐标系之间的转换依赖三角函数和反三角函数，是图形编程的基础操作
    • 

  • 齐次坐标将仿射变换统一为矩阵乘法，使 GPU 可以高效处理所有变换
    • 

  • 选择合适的坐标系可以极大简化问题——圆用极坐标、球用球坐标、直线用笛卡尔坐标
    • 

  • 注意不同系统的坐标系约定差异：屏幕 y 轴向下、左手/右手坐标系、角度起点方向
    •
