参数方程与极坐标

核心概念

参数方程用一个或多个参数来表达曲线上点的坐标，而极坐标用距离和角度描述平面上的点。这两种表示方法是解析几何中除直角坐标外最重要的工具。在计算机图形学中，参数方程是曲线绘制和动画的核心——贝塞尔曲线、B 样条曲线都是参数方程的形式；在信号处理和物理模拟中，极坐标下的曲线描述更为自然。

参数方程的优势在于它可以表达直角坐标方程无法直接描述的曲线（如自交曲线、参数化运动轨迹），并且天然支持沿曲线的等参数步进——这对动画和路径跟随非常有用。

经典参数曲线
参数方程可以描述许多优美而实用的曲线。这些曲线在数学史上有重要地位，在现代编程中也有实际应用。


摆线（cycloid）：车轮边缘上一点在车轮滚动时的轨迹。x = r(t - sin t), y = r(1 - cos t)。摆线是等时降线（最速降线）——物体沿摆线从高处滑到低处的时间最短，与起点无关。


利萨茹图形（Lissajous）：两个正弦振动的合成。x = A sin(at + δ), y = B sin(bt)。不同频率比产生不同的图案，在示波器中用于频率比较。


螺旋线：阿基米德螺旋 r = a + bθ（等间距），对数螺旋 r = ae^(bθ)（等角，自然界常见）。


interface Point {
  x: number;
  y: number;
}

function cycloid(t: number, r: number): Point {
  return {
    x: r * (t - Math.sin(t)),
    y: r * (1 - Math.cos(t)),
  };
}

function epicycloid(t: number, R: number, r: number): Point {
  return {
    x: (R + r) * Math.cos(t) - r * Math.cos(((R + r) / r) * t),
    y: (R + r) * Math.sin(t) - r * Math.sin(((R + r) / r) * t),
  };
}

function hypocycloid(t: number, R: number, r: number): Point {
  return {
    x: (R - r) * Math.cos(t) + r * Math.cos(((R - r) / r) * t),
    y: (R - r) * Math.sin(t) - r * Math.sin(((R - r) / r) * t),
  };
}

function lissajous(t: number, A: number, B: number, a: number, b: number, delta: number): Point {
  return {
    x: A * Math.sin(a * t + delta),
    y: B * Math.sin(b * t),
  };
}

function generateCurve(curveFunc: (t: number) => Point, tStart: number, tEnd: number, steps: number): Point[] {
  const points: Point[] = [];
  for (let i = 0; i <= steps; i++) {
    const t = tStart + (tEnd - tStart) * (i / steps);
    points.push(curveFunc(t));
  }
  return points;
}

贝塞尔曲线
贝塞尔曲线是计算机图形学中最重要的参数曲线。它由控制点定义，曲线通过起点和终点，中间控制点决定曲线的形状。


二阶贝塞尔（二次）：B(t) = (1-t)²P₀ + 2t(1-t)P₁ + t²P₂


三阶贝塞尔（三次）：B(t) = (1-t)³P₀ + 3t(1-t)²P₁ + 3t²(1-t)P₂ + t³P₃


function quadraticBezier(p0: Point, p1: Point, p2: Point, t: number): Point {
  const mt = 1 - t;
  return {
    x: mt * mt * p0.x + 2 * mt * t * p1.x + t * t * p2.x,
    y: mt * mt * p0.y + 2 * mt * t * p1.y + t * t * p2.y,
  };
}

function cubicBezier(p0: Point, p1: Point, p2: Point, p3: Point, t: number): Point {
  const mt = 1 - t;
  const mt2 = mt * mt;
  const t2 = t * t;
  return {
    x: mt2 * mt * p0.x + 3 * mt2 * t * p1.x + 3 * mt * t2 * p2.x + t2 * t * p3.x,
    y: mt2 * mt * p0.y + 3 * mt2 * t * p1.y + 3 * mt * t2 * p2.y + t2 * t * p3.y,
  };
}

function bezierDerivative(p0: Point, p1: Point, p2: Point, p3: Point, t: number): Point {
  const mt = 1 - t;
  return {
    x: 3 * mt * mt * (p1.x - p0.x) + 6 * mt * t * (p2.x - p1.x) + 3 * t * t * (p3.x - p2.x),
    y: 3 * mt * mt * (p1.y - p0.y) + 6 * mt * t * (p2.y - p1.y) + 3 * t * t * (p3.y - p2.y),
  };
}

function deCasteljau(points: Point[], t: number): Point {
  if (points.length === 1) return points[0];
  const next: Point[] = [];
  for (let i = 0; i < points.length - 1; i++) {
    next.push({
      x: (1 - t) * points[i].x + t * points[i + 1].x,
      y: (1 - t) * points[i].y + t * points[i + 1].y,
    });
  }
  return deCasteljau(next, t);
}
CSS 的 transition-timing-function: cubic-bezier(x1, y1, x2, y2) 就是三阶贝塞尔曲线。SVG 路径命令中的 C（三次贝塞尔）和 Q（二次贝塞尔）也直接对应这些公式。


弧长计算
参数曲线的弧长计算是从 t₁ 到 t₂ 的积分：L = ∫√(dx/dt)² + (dy/dt)² dt。大多数情况下这个积分没有解析解，需要数值方法。


极坐标曲线的弧长：L = ∫√(r² + (dr/dθ)²) dθ


function arcLengthParametric(
  xFunc: (t: number) => number,
  yFunc: (t: number) => number,
  t1: number,
  t2: number,
  steps: number,
): number {
  let length = 0;
  const dt = (t2 - t1) / steps;
  let prevX = xFunc(t1);
  let prevY = yFunc(t1);

  for (let i = 1; i <= steps; i++) {
    const t = t1 + i * dt;
    const currX = xFunc(t);
    const currY = yFunc(t);
    length += Math.sqrt((currX - prevX) ** 2 + (currY - prevY) ** 2);
    prevX = currX;
    prevY = currY;
  }
  return length;
}

function arcLengthPolar(
  rFunc: (theta: number) => number,
  drFunc: (theta: number) => number,
  theta1: number,
  theta2: number,
  steps: number,
): number {
  let length = 0;
  const dTheta = (theta2 - theta1) / steps;

  for (let i = 0; i < steps; i++) {
    const theta = theta1 + (i + 0.5) * dTheta;
    const r = rFunc(theta);
    const dr = drFunc(theta);
    length += Math.sqrt(r * r + dr * dr) * dTheta;
  }
  return length;
}

function polarArea(rFunc: (theta: number) => number, theta1: number, theta2: number, steps: number): number {
  let area = 0;
  const dTheta = (theta2 - theta1) / steps;

  for (let i = 0; i < steps; i++) {
    const theta = theta1 + (i + 0.5) * dTheta;
    const r = rFunc(theta);
    area += 0.5 * r * r * dTheta;
  }
  return area;
}
极坐标下的面积
极坐标下封闭曲线围成的面积公式为：S = ½∫r²dθ。这个公式来源于将区域分割为无穷多个微小扇形，每个扇形面积为 ½r²dθ。


对于两条极坐标曲线 r₁(θ) 和 r₂(θ)（r₂ > r₁）之间的区域，面积为 ½∫(r₂² - r₁²)dθ。

function polarAreaBetween(
  r1: (theta: number) => number,
  r2: (theta: number) => number,
  theta1: number,
  theta2: number,
  steps: number,
): number {
  let area = 0;
  const dTheta = (theta2 - theta1) / steps;
  for (let i = 0; i < steps; i++) {
    const theta = theta1 + (i + 0.5) * dTheta;
    const outer = r2(theta);
    const inner = r1(theta);
    area += 0.5 * (outer * outer - inner * inner) * dTheta;
  }
  return Math.abs(area);
}

function cardioidArea(a: number): number {
  return 1.5 * Math.PI * a * a;
}
小结
    

  • 参数方程用参数 t 表达曲线，天然支持逐点生成和动画，可表达自交曲线等复杂形状
    • 

  • 摆线是最速降线（等时降线），利萨茹图形用于频率比较，螺旋线在自然界广泛存在
    • 

  • 贝塞尔曲线是计算机图形学的核心，de Casteljau 算法是其数值稳定的求值方法
    • 

  • 弧长计算通常需要数值积分，线段累加法简单有效，Simpson 法精度更高
    • 

  • 极坐标下面积公式 S = ½∫r²dθ 将面积计算转化为一维积分
    • 

  • 参数方程和极坐标在曲线设计、动画制作、信号分析和物理模拟中有广泛应用
    • 

  • CSS 动画的 cubic-bezier 和 SVG 路径都直接使用贝塞尔曲线参数方程
