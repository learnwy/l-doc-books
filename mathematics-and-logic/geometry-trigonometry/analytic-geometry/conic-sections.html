圆锥曲线

核心概念

圆锥曲线（椭圆、双曲线、抛物线）是解析几何的核心研究对象。它们不仅是数学上的优美曲线，更在物理、工程和计算机科学中有广泛应用：行星轨道是椭圆，卫星天线是抛物面，GPS 定位利用双曲线原理。在计算机图形学中，圆锥曲线用于路径规划、字体渲染和曲线拟合。

圆锥曲线的统一定义基于焦点-准线性质：平面上到焦点的距离与到准线的距离之比为常数 e（离心率）的点的轨迹。离心率 e 完全决定了曲线的类型和形状。同时，圆锥曲线也可以用二次方程 Ax² + Bxy + Cy² + Dx + Ey + F = 0 统一表示。

椭圆的性质与编程
椭圆是到两个焦点距离之和为常数（2a）的点的轨迹。标准方程 x²/a² + y²/b² = 1（a > b > 0），焦距 c = √(a²-b²)，离心率 e = c/a。


椭圆的参数方程形式对编程更友好：x = a cos t, y = b sin t（t ∈ [0, 2π)）。


开普勒第一定律：行星绕太阳运行的轨道是椭圆，太阳位于椭圆的一个焦点上。


interface Ellipse {
  centerX: number;
  centerY: number;
  a: number;
  b: number;
  rotation: number;
}

function ellipsePoint(e: Ellipse, t: number): { x: number; y: number } {
  const cos = Math.cos(e.rotation);
  const sin = Math.sin(e.rotation);
  const px = e.a * Math.cos(t);
  const py = e.b * Math.sin(t);
  return {
    x: e.centerX + px * cos - py * sin,
    y: e.centerY + px * sin + py * cos,
  };
}

function ellipseEccentricity(a: number, b: number): number {
  return Math.sqrt(1 - (b * b) / (a * a));
}

function ellipseFoci(e: Ellipse): [{ x: number; y: number }, { x: number; y: number }] {
  const c = Math.sqrt(e.a * e.a - e.b * e.b);
  const cos = Math.cos(e.rotation);
  const sin = Math.sin(e.rotation);
  return [
    { x: e.centerX + c * cos, y: e.centerY + c * sin },
    { x: e.centerX - c * cos, y: e.centerY - c * sin },
  ];
}

function pointOnEllipse(e: Ellipse, px: number, py: number): boolean {
  const cos = Math.cos(-e.rotation);
  const sin = Math.sin(-e.rotation);
  const dx = px - e.centerX;
  const dy = py - e.centerY;
  const lx = dx * cos - dy * sin;
  const ly = dx * sin + dy * cos;
  const val = (lx * lx) / (e.a * e.a) + (ly * ly) / (e.b * e.b);
  return Math.abs(val - 1) < 1e-8;
}

function ellipseArea(a: number, b: number): number {
  return Math.PI * a * b;
}

抛物线的焦点性质
抛物线是到焦点和准线距离相等的点的轨迹。标准方程 y² = 4px，焦点在 (p, 0)，准线为 x = -p。


抛物线最重要的性质是焦点反射性质：平行于对称轴的入射线经抛物线反射后必过焦点。这一性质是卫星天线、汽车前灯和太阳能集热器的设计原理。


interface Parabola {
  p: number;
  vertexX: number;
  vertexY: number;
  direction: 'right' | 'left' | 'up' | 'down';
}

function parabolaPoint(pb: Parabola, t: number): { x: number; y: number } {
  switch (pb.direction) {
    case 'right':
      return { x: pb.vertexX + (t * t) / (4 * pb.p), y: pb.vertexY + t };
    case 'left':
      return { x: pb.vertexX - (t * t) / (4 * pb.p), y: pb.vertexY + t };
    case 'up':
      return { x: pb.vertexX + t, y: pb.vertexY + (t * t) / (4 * pb.p) };
    case 'down':
      return { x: pb.vertexX + t, y: pb.vertexY - (t * t) / (4 * pb.p) };
  }
}

function parabolaFocus(pb: Parabola): { x: number; y: number } {
  switch (pb.direction) {
    case 'right':
      return { x: pb.vertexX + pb.p, y: pb.vertexY };
    case 'left':
      return { x: pb.vertexX - pb.p, y: pb.vertexY };
    case 'up':
      return { x: pb.vertexX, y: pb.vertexY + pb.p };
    case 'down':
      return { x: pb.vertexX, y: pb.vertexY - pb.p };
  }
}

function reflectRayOffParabola(
  incidentY: number,
  p: number,
): { reflectAngle: number; hitPoint: { x: number; y: number } } {
  const x = (incidentY * incidentY) / (4 * p);
  const slopeAtPoint = (2 * p) / incidentY;
  const normalAngle = Math.atan(slopeAtPoint);
  return {
    reflectAngle: 2 * normalAngle - Math.PI,
    hitPoint: { x, y: incidentY },
  };
}

双曲线与渐近线
双曲线是到两个焦点距离之差的绝对值为常数（2a）的点的轨迹。标准方程 x²/a² - y²/b² = 1，焦距 c = √(a²+b²)，离心率 e = c/a > 1。


双曲线有两条渐近线 y = ±(b/a)x，当点沿双曲线趋向无穷远时，曲线趋近于渐近线但永远不相交。


interface Hyperbola {
  centerX: number;
  centerY: number;
  a: number;
  b: number;
  rotation: number;
}

function hyperbolaPoints(h: Hyperbola, tMin: number, tMax: number, steps: number): { x: number; y: number }[] {
  const points: { x: number; y: number }[] = [];
  const cos = Math.cos(h.rotation);
  const sin = Math.sin(h.rotation);
  for (let i = 0; i <= steps; i++) {
    const t = tMin + (tMax - tMin) * (i / steps);
    const px = h.a / Math.cos(t);
    const py = h.b * Math.tan(t);
    points.push({
      x: h.centerX + px * cos - py * sin,
      y: h.centerY + px * sin + py * cos,
    });
  }
  return points;
}

function hyperbolaAsymptotes(h: Hyperbola): { slope1: number; slope2: number } {
  const baseSlope = h.b / h.a;
  return { slope1: baseSlope, slope2: -baseSlope };
}

function hyperbolaEccentricity(a: number, b: number): number {
  return Math.sqrt(1 + (b * b) / (a * a));
}
GPS 定位原理：接收器到两颗卫星的信号到达时间差对应距离差常数，确定了一条双曲线。三颗卫星确定三条双曲线，交点即为接收器位置。


一般二次曲线与旋转
一般二次方程 Ax² + Bxy + Cy² + Dx + Ey + F = 0 可以表示任意位置和方向的圆锥曲线。判别式 Δ = B² - 4AC 决定曲线类型。


当 B ≠ 0 时，曲线的主轴发生了旋转。通过坐标旋转可以消去 xy 项，将方程化为标准形式。旋转角 θ 满足 tan 2θ = B/(A-C)。


interface GeneralConic {
  A: number;
  B: number;
  C: number;
  D: number;
  E: number;
  F: number;
}

function classifyGeneralConic(conic: GeneralConic): 'ellipse' | 'parabola' | 'hyperbola' | 'degenerate' {
  const { A, B, C } = conic;
  const discriminant = B * B - 4 * A * C;
  const eps = 1e-10;

  if (Math.abs(discriminant) < eps) return 'parabola';
  if (discriminant < 0) return 'ellipse';
  return 'hyperbola';
}

function conicRotationAngle(conic: GeneralConic): number {
  const { A, B, C } = conic;
  if (Math.abs(B) < 1e-10) return 0;
  return 0.5 * Math.atan2(B, A - C);
}

function evaluateConic(conic: GeneralConic, x: number, y: number): number {
  const { A, B, C, D, E, F } = conic;
  return A * x * x + B * x * y + C * y * y + D * x + E * y + F;
}

function isPointOnConic(conic: GeneralConic, x: number, y: number, eps: number = 1e-8): boolean {
  return Math.abs(evaluateConic(conic, x, y)) < eps;
}

小结
    

  • 圆锥曲线通过离心率 e 统一分类：圆(0)、椭圆(0,1)、抛物线(1)、双曲线(>1)
    • 

  • 椭圆描述行星轨道，参数方程 (a cosθ, b sinθ) 便于编程生成
    • 

  • 抛物线具有焦点反射性质，是卫星天线和太阳能集热器的设计原理
    • 

  • 双曲线用于 GPS 定位，三组距离差确定三条双曲线的交点
    • 

  • 一般二次方程通过判别式 B²-4AC 分类，旋转角 θ = ½ arctan(B/(A-C)) 消去 xy 项
    • 

  • 圆锥曲线的编程实现需要注意退化情况（点、直线、空集）的处理
    • 

  • 理解圆锥曲线是掌握曲线拟合、轨道力学和信号处理的必要基础
