向量与几何

核心概念

向量是既有大小又有方向的量，是连接代数和几何的核心桥梁。在编程中，向量运算是游戏引擎、物理模拟、机器学习和图形渲染的基础——从碰撞检测到光照计算，从神经网络到路径规划，向量无处不在。

向量的几何意义直观明了：点积度量两个向量的相似度（夹角），叉积度量它们张成的平行四边形面积（法向量）。这两个运算几乎覆盖了计算几何中所有基本操作。3D 空间中的直线和平面方程也建立在向量的基础上。

点积与投影
点积（内积、数量积）是向量运算中最基本的工具。两个向量 a 和 b 的点积定义为：a · b = |a||b|cos θ = a₁b₁ + a₂b₂ + a₃b₃。


点积的几何含义是一个向量在另一个向量方向上的投影长度乘以后者的长度。点积为零意味着两个向量正交。


interface Vec2 {
  x: number;
  y: number;
}

interface Vec3 {
  x: number;
  y: number;
  z: number;
}

function dot2(a: Vec2, b: Vec2): number {
  return a.x * b.x + a.y * b.y;
}

function dot3(a: Vec3, b: Vec3): number {
  return a.x * b.x + a.y * b.y + a.z * b.z;
}

function magnitude2(v: Vec2): number {
  return Math.sqrt(v.x * v.x + v.y * v.y);
}

function magnitude3(v: Vec3): number {
  return Math.sqrt(v.x * v.x + v.y * v.y + v.z * v.z);
}

function normalize2(v: Vec2): Vec2 {
  const m = magnitude2(v);
  return m > 1e-15 ? { x: v.x / m, y: v.y / m } : { x: 0, y: 0 };
}

function normalize3(v: Vec3): Vec3 {
  const m = magnitude3(v);
  return m > 1e-15 ? { x: v.x / m, y: v.y / m, z: v.z / m } : { x: 0, y: 0, z: 0 };
}

function angleBetween(a: Vec3, b: Vec3): number {
  const d = dot3(a, b);
  const m = magnitude3(a) * magnitude3(b);
  return m > 1e-15 ? Math.acos(Math.max(-1, Math.min(1, d / m))) : 0;
}

function project(a: Vec3, onto: Vec3): Vec3 {
  const d = dot3(a, onto);
  const m2 = dot3(onto, onto);
  if (m2 < 1e-15) return { x: 0, y: 0, z: 0 };
  const scale = d / m2;
  return { x: onto.x * scale, y: onto.y * scale, z: onto.z * scale };
}
点积在图形学中的应用极为广泛：


| 应用       | 公式              | 含义              |
| ---------- | ----------------- | ----------------- | --- | --- | --- | ------------ |
| 夹角计算   | cos θ = a·b/(     | a                 |     | b   | )   | 向量间的角度 |

| 视锥裁剪   | d = N·P + D       | 点到平面的距离    |


叉积与法向量
叉积（外积、向量积）只在 3D 空间中完整定义。两个向量 a 和 b 的叉积 a × b 是一个垂直于两者的向量，其模等于两向量张成的平行四边形的面积。


在 2D 中，叉积退化为标量（z 分量），等于 a₁b₂ - a₂b₁，可以判断点的位置关系和旋转方向。


function cross2(a: Vec2, b: Vec2): number {
  return a.x * b.y - a.y * b.x;
}

function cross3(a: Vec3, b: Vec3): Vec3 {
  return {
    x: a.y * b.z - a.z * b.y,
    y: a.z * b.x - a.x * b.z,
    z: a.x * b.y - a.y * b.x,
  };
}

function triangleNormal(p0: Vec3, p1: Vec3, p2: Vec3): Vec3 {
  const u: Vec3 = { x: p1.x - p0.x, y: p1.y - p0.y, z: p1.z - p0.z };
  const v: Vec3 = { x: p2.x - p0.x, y: p2.y - p0.y, z: p2.z - p0.z };
  return normalize3(cross3(u, v));
}

function parallelogramArea(a: Vec3, b: Vec3): number {
  return magnitude3(cross3(a, b));
}

function triangleArea3D(p0: Vec3, p1: Vec3, p2: Vec3): number {
  const u: Vec3 = { x: p1.x - p0.x, y: p1.y - p0.y, z: p1.z - p0.z };
  const v: Vec3 = { x: p2.x - p0.x, y: p2.y - p0.y, z: p2.z - p0.z };
  return magnitude3(cross3(u, v)) / 2;
}

function isLeftTurn(a: Vec2, b: Vec2, c: Vec2): boolean {
  return cross2({ x: b.x - a.x, y: b.y - a.y }, { x: c.x - a.x, y: c.y - a.y }) > 0;
}
2D 叉积的符号判断是计算几何的基础操作：正值表示左转（逆时针），负值表示右转（顺时针），零表示共线。凸包算法、线段相交判断等都依赖这一操作。

3D 平面方程：n · (P - P₀) = 0，展开为 ax + by + cz + d = 0，其中 (a,b,c) 是法向量。


interface Line2D {
  point: Vec2;
  direction: Vec2;
}

interface Plane {
  normal: Vec3;
  d: number;
}

function pointToLineDistance(p: Vec2, line: Line2D): number {
  const v: Vec2 = { x: p.x - line.point.x, y: p.y - line.point.y };
  const cross = Math.abs(cross2(v, line.direction));
  return cross / magnitude2(line.direction);
}

function lineIntersection(l1: Line2D, l2: Line2D): Vec2 | null {
  const d = cross2(l1.direction, l2.direction);
  if (Math.abs(d) < 1e-10) return null;
  const diff: Vec2 = { x: l2.point.x - l1.point.x, y: l2.point.y - l1.point.y };
  const t = cross2(diff, l2.direction) / d;
  return {
    x: l1.point.x + t * l1.direction.x,
    y: l1.point.y + t * l1.direction.y,
  };
}

function planeFromThreePoints(p0: Vec3, p1: Vec3, p2: Vec3): Plane {
  const normal = triangleNormal(p0, p1, p2);
  const d = -(normal.x * p0.x + normal.y * p0.y + normal.z * p0.z);
  return { normal, d };
}

function pointToPlaneDistance(p: Vec3, plane: Plane): number {
  return Math.abs(plane.normal.x * p.x + plane.normal.y * p.y + plane.normal.z * p.z + plane.d);
}

function rayPlaneIntersection(origin: Vec3, direction: Vec3, plane: Plane): Vec3 | null {
  const denom = dot3(plane.normal, direction);
  if (Math.abs(denom) < 1e-10) return null;
  const t = -(dot3(plane.normal, origin) + plane.d) / denom;
  if (t < 0) return null;
  return {
    x: origin.x + t * direction.x,
    y: origin.y + t * direction.y,
    z: origin.z + t * direction.z,
  };
}
向量在光照模型中的应用
向量运算是 3D 光照计算的核心。Phong 光照模型使用法向量 N、光照方向 L、视线方向 V 和反射方向 R 四个向量来计算光照强度。


interface LightResult {
  ambient: number;
  diffuse: number;
  specular: number;
  total: number;
}

function phongLighting(
  normal: Vec3,
  lightDir: Vec3,
  viewDir: Vec3,
  ambientStrength: number,
  specularStrength: number,
  shininess: number,
): LightResult {
  const N = normalize3(normal);
  const L = normalize3(lightDir);
  const V = normalize3(viewDir);

  const ambient = ambientStrength;
  const diff = Math.max(0, dot3(N, L));

  const reflectDir: Vec3 = {
    x: 2 * dot3(N, L) * N.x - L.x,
    y: 2 * dot3(N, L) * N.y - L.y,
    z: 2 * dot3(N, L) * N.z - L.z,
  };
  const spec = specularStrength * Math.pow(Math.max(0, dot3(V, reflectDir)), shininess);

  return {
    ambient,
    diffuse: diff,
    specular: spec,
    total: ambient + diff + spec,
  };
}

小结
    

  • 向量是连接代数和几何的桥梁，点积度量相似度和投影，叉积度量面积和法向量
    • 

  • 点积 a·b = |a||b|cos θ，叉积 |a×b| = |a||b|sin θ，两者互补地描述了向量间的关系
    • 

  • 2D 叉积的符号判断（左转/右转/共线）是凸包、线段相交等算法的基础
    • 

  • 直线的参数方程适合射线追踪，一般式适合距离计算，平面方程由法向量唯一确定
    • 

  • 点到直线/平面的距离公式是碰撞检测和视锥裁剪的核心工具
    • 

  • Phong 光照模型完全建立在向量点积之上：漫反射 = N·L，镜面反射 = (V·R)ⁿ
    • 

  • 向量运算的高效实现是游戏引擎和图形渲染管线性能的关键
    •
