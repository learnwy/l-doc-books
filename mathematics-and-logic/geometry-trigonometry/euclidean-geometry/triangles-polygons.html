三角形与多边形

核心概念

三角形是最简单的多边形，也是几何学中最基本的图形单元。在计算机图形学中，几乎所有 3D 模型都由三角形网格（triangle mesh）构成——GPU 的光栅化流水线以三角形为基本渲染图元。理解三角形和多边形的性质，对于碰撞检测、路径规划、有限元分析等领域至关重要。

三角形的核心性质包括全等、相似、面积计算、特殊线段（中线、高、角平分线）等。多边形则是三角形的推广，从凸多边形到凹多边形，其性质逐渐复杂，但都可以通过三角剖分回归到三角形的分析。

相似意味着两个三角形形状相同但大小可能不同，即对应角相等、对应边成比例。相似在图形缩放、LOD（Level of Detail）系统中广泛应用。


interface Triangle {
  a: number;
  b: number;
  c: number;
}

function isCongruent(t1: Triangle, t2: Triangle): boolean {
  const sides1 = [t1.a, t1.b, t1.c].sort((x, y) => x - y);
  const sides2 = [t2.a, t2.b, t2.c].sort((x, y) => x - y);
  const eps = 1e-10;
  return sides1.every((s, i) => Math.abs(s - sides2[i]) < eps);
}

function isSimilar(t1: Triangle, t2: Triangle): boolean {
  const sides1 = [t1.a, t1.b, t1.c].sort((x, y) => x - y);
  const sides2 = [t2.a, t2.b, t2.c].sort((x, y) => x - y);
  const ratio = sides1[0] / sides2[0];
  const eps = 1e-10;
  return sides1.every((s, i) => Math.abs(s / sides2[i] - ratio) < eps);
}

function triangleArea(t: Triangle): number {
  const s = (t.a + t.b + t.c) / 2;
  return Math.sqrt(s * (s - t.a) * (s - t.b) * (s - t.c));
}
海伦公式（Heron's formula）通过三边长直接计算面积：S = √(s(s-a)(s-b)(s-c))，其中 s = (a+b+c)/2 是半周长。这个公式在计算几何中极为常用，因为它不需要先求角度或高。

interface Point {
  x: number;
  y: number;
}

function centroid(a: Point, b: Point, c: Point): Point {
  return {
    x: (a.x + b.x + c.x) / 3,
    y: (a.y + b.y + c.y) / 3,
  };
}

function circumcenter(a: Point, b: Point, c: Point): Point {
  const ax = a.x,
    ay = a.y;
  const bx = b.x,
    by = b.y;
  const cx = c.x,
    cy = c.y;
  const D = 2 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by));
  const ux = ((ax * ax + ay * ay) * (by - cy) + (bx * bx + by * by) * (cy - ay) + (cx * cx + cy * cy) * (ay - by)) / D;
  const uy = ((ax * ax + ay * ay) * (cx - bx) + (bx * bx + by * by) * (ax - cx) + (cx * cx + cy * cy) * (bx - ax)) / D;
  return { x: ux, y: uy };
}

function incenter(a: Point, b: Point, c: Point): Point {
  const sideA = Math.hypot(b.x - c.x, b.y - c.y);
  const sideB = Math.hypot(a.x - c.x, a.y - c.y);
  const sideC = Math.hypot(a.x - b.x, a.y - b.y);
  const perimeter = sideA + sideB + sideC;
  return {
    x: (sideA * a.x + sideB * b.x + sideC * c.x) / perimeter,
    y: (sideA * a.y + sideB * b.y + sideC * c.y) / perimeter,
  };
}
欧拉线（Euler line）是一个优美的结果：重心、外心和垂心共线，且重心将外心到垂心的线段分为 1:2。这一性质在计算几何中用于验证算法的正确性。


多边形面积与三角剖分
多边形面积计算的核心工具是鞋带公式（Shoelace formula），它将面积计算转化为顶点坐标的交叉乘积之和。


设多边形顶点按顺序为 (x₁,y₁), (x₂,y₂), ..., (xₙ,yₙ)，则面积为：


S = ½ |∑(xᵢyᵢ₊₁ - xᵢ₊₁yᵢ)|


function polygonArea(vertices: Point[]): number {
  const n = vertices.length;
  let area = 0;
  for (let i = 0; i < n; i++) {
    const j = (i + 1) % n;
    area += vertices[i].x * vertices[j].y;
    area -= vertices[j].x * vertices[i].y;
  }
  return Math.abs(area) / 2;
}

function signedPolygonArea(vertices: Point[]): number {
  const n = vertices.length;
  let area = 0;
  for (let i = 0; i < n; i++) {
    const j = (i + 1) % n;
    area += vertices[i].x * vertices[j].y;
    area -= vertices[j].x * vertices[i].y;
  }
  return area / 2;
}

function isCounterClockwise(vertices: Point[]): boolean {
  return signedPolygonArea(vertices) > 0;
}
三角剖分是将多边形分割为不重叠三角形的过程。对于凸多边形，从一个顶点出发连接所有非相邻顶点即可得到 n-2 个三角形。对于凹多边形，常用耳切法（ear clipping）。


耳切法的核心思想：多边形的"耳"是一个顶点，其相邻两个顶点的连线完全在多边形内部。每次切掉一个耳得到一个三角形，直到多边形被完全分解。


function isEar(vertices: Point[], i: number): boolean {
  const n = vertices.length;
  const prev = (i - 1 + n) % n;
  const next = (i + 1) % n;
  const a = vertices[prev];
  const b = vertices[i];
  const c = vertices[next];

  const cross = (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x);
  if (cross <= 0) return false;

  for (let j = 0; j < n; j++) {
    if (j === prev || j === i || j === next) continue;
    if (pointInTriangle(vertices[j], a, b, c)) return false;
  }
  return true;
}

function pointInTriangle(p: Point, a: Point, b: Point, c: Point): boolean {
  const d1 = sign(p, a, b);
  const d2 = sign(p, b, c);
  const d3 = sign(p, c, a);
  const hasNeg = d1 < 0 || d2 < 0 || d3 < 0;
  const hasPos = d1 > 0 || d2 > 0 || d3 > 0;
  return !(hasNeg && hasPos);
}

function sign(p1: Point, p2: Point, p3: Point): number {
  return (p1.x - p3.x) * (p2.y - p3.y) - (p2.x - p3.x) * (p1.y - p3.y);
}
正多边形与对称性
正多边形的所有边和所有角都相等。正 n 边形的每个内角为 (n-2)×180°/n，外角为 360°/n。正多边形具有 n 条对称轴和 n 重旋转对称性，构成二面体群 Dₙ。

在游戏开发中，正多边形常用于近似圆形碰撞体（增加边数提高精度），以及生成程序化地形的六边形网格（如 Civilization 系列）。


function regularPolygonVertices(n: number, radius: number, center: Point): Point[] {
  const vertices: Point[] = [];
  for (let i = 0; i < n; i++) {
    const angle = (2 * Math.PI * i) / n - Math.PI / 2;
    vertices.push({
      x: center.x + radius * Math.cos(angle),
      y: center.y + radius * Math.sin(angle),
    });
  }
  return vertices;
}

function regularPolygonArea(n: number, sideLength: number): number {
  return (n * sideLength * sideLength) / (4 * Math.tan(Math.PI / n));
}

function regularPolygonPerimeter(n: number, sideLength: number): number {
  return n * sideLength;
}
小结
    

  • 三角形是最基本的多边形，GPU 以三角形为基本渲染图元，三角形网格是 3D 建模的基础
    • 

  • 全等判定有 SSS、SAS、ASA、AAS、HL 五种方法，相似判定基于对应角相等或对应边成比例
    • 

  • 海伦公式 S = √(s(s-a)(s-b)(s-c)) 通过三边直接计算面积，不需要求角度
    • 

  • 三角形的四心（重心、外心、内心、垂心）在不同计算几何场景中发挥重要作用
    • 

  • 鞋带公式将多边形面积计算转化为 O(n) 的坐标运算，是计算几何的基础工具
    • 

  • 三角剖分将复杂多边形分解为三角形，耳切法是处理简单多边形的经典算法
    • 

  • 正多边形具有高度对称性，在游戏开发中广泛用于碰撞检测和程序化生成
