圆与圆锥曲线

核心概念

圆是平面上到定点（圆心）距离等于定值（半径）的点的集合，是最完美的几何图形之一。圆锥曲线——椭圆、双曲线和抛物线——则是圆的推广，它们由平面截圆锥面的不同方式产生。在计算机图形学中，圆和圆锥曲线是基本绘图图元；在物理模拟中，天体运行轨道就是圆锥曲线；在信号处理中，椭圆滤波器的设计依赖于椭圆函数。

从统一的视角看，圆锥曲线可以用离心率（eccentricity）来分类：离心率为 0 是圆，0 到 1 之间是椭圆，等于 1 是抛物线，大于 1 是双曲线。这种统一性体现了数学的优雅，也为编程实现提供了通用框架。

圆的基本定理
圆具有许多优美的几何性质，这些性质在碰撞检测、路径规划和图形渲染中都有直接应用。


圆周角定理：同弧上的圆周角等于圆心角的一半。这意味着同弧上所有圆周角相等——这一性质在确定点是否在圆上时非常有用。


切线定理：从圆外一点引两条切线，切线长相等。切点与圆心的连线垂直于切线。


圆幂定理：对于圆外一点 P，过 P 的任何割线与圆的两个交点 A、B，PA × PB 为常数。这个常数称为点 P 关于圆的幂，在判断点与圆的位置关系时非常实用。


interface Point {
  x: number;
  y: number;
}

interface Circle {
  center: Point;
  radius: number;
}

function distanceSq(a: Point, b: Point): number {
  return (a.x - b.x) ** 2 + (a.y - b.y) ** 2;
}

function distance(a: Point, b: Point): number {
  return Math.sqrt(distanceSq(a, b));
}

function pointToCircleRelation(p: Point, c: Circle): 'inside' | 'on' | 'outside' {
  const d = distance(p, c.center);
  const eps = 1e-10;
  if (d < c.radius - eps) return 'inside';
  if (d > c.radius + eps) return 'outside';
  return 'on';
}

function tangentLength(p: Point, c: Circle): number {
  const d = distance(p, c.center);
  if (d <= c.radius) return 0;
  return Math.sqrt(d * d - c.radius * c.radius);
}

function power(p: Point, c: Circle): number {
  return distanceSq(p, c.center) - c.radius * c.radius;
}

弧长与扇形面积
弧长和扇形面积的计算是圆形运动轨迹、饼图绘制、雷达扫描等场景的基础。


弧长公式：L = rθ（θ 为弧度制下的圆心角）


扇形面积：S = ½r²θ


弓形面积（扇形减去三角形）：S = ½r²(θ - sinθ)


function arcLength(radius: number, angleDeg: number): number {
  const angleRad = (angleDeg * Math.PI) / 180;
  return radius * angleRad;
}

function sectorArea(radius: number, angleDeg: number): number {
  const angleRad = (angleDeg * Math.PI) / 180;
  return 0.5 * radius * radius * angleRad;
}

function segmentArea(radius: number, angleDeg: number): number {
  const angleRad = (angleDeg * Math.PI) / 180;
  return 0.5 * radius * radius * (angleRad - Math.sin(angleRad));
}

function pointOnCircle(center: Point, radius: number, angleDeg: number): Point {
  const angleRad = (angleDeg * Math.PI) / 180;
  return {
    x: center.x + radius * Math.cos(angleRad),
    y: center.y + radius * Math.sin(angleRad),
  };
}

function arcPoints(center: Point, radius: number, startDeg: number, endDeg: number, segments: number): Point[] {
  const points: Point[] = [];
  for (let i = 0; i <= segments; i++) {
    const t = i / segments;
    const angle = startDeg + t * (endDeg - startDeg);
    points.push(pointOnCircle(center, radius, angle));
  }
  return points;
}
在计算机图形学中，圆弧的绘制通常不是直接计算每个像素，而是使用 Bresenham 圆算法或参数化方法生成离散点。对于高质量的曲线渲染，贝塞尔曲线可以近似圆弧——一段 90° 的圆弧可以用三阶贝塞尔曲线以非常小的误差近似。


圆与圆的位置关系
两个圆的位置关系由两圆心距 d 与两半径 r₁、r₂ 的关系决定。这在碰撞检测中是最常用的判定之一——圆形包围盒检测只需比较距离和半径之和。


type CircleRelation = 'external' | 'external_tangent' | 'intersecting' | 'internal_tangent' | 'internal';

function circleRelation(c1: Circle, c2: Circle): CircleRelation {
  const d = distance(c1.center, c2.center);
  const sumR = c1.radius + c2.radius;
  const diffR = Math.abs(c1.radius - c2.radius);
  const eps = 1e-10;

  if (d > sumR + eps) return 'external';
  if (Math.abs(d - sumR) < eps) return 'external_tangent';
  if (d > diffR + eps) return 'intersecting';
  if (Math.abs(d - diffR) < eps) return 'internal_tangent';
  return 'internal';
}

function circleIntersections(c1: Circle, c2: Circle): Point[] {
  const d = distance(c1.center, c2.center);
  const r1 = c1.radius,
    r2 = c2.radius;

  if (d > r1 + r2 + 1e-10 || d < Math.abs(r1 - r2) - 1e-10) return [];

  const a = (r1 * r1 - r2 * r2 + d * d) / (2 * d);
  const h = Math.sqrt(Math.max(0, r1 * r1 - a * a));

  const px = c1.center.x + (a * (c2.center.x - c1.center.x)) / d;
  const py = c1.center.y + (a * (c2.center.y - c1.center.y)) / d;

  if (Math.abs(h) < 1e-10) return [{ x: px, y: py }];

  const dx = (h * (c2.center.y - c1.center.y)) / d;
  const dy = (h * (c2.center.x - c1.center.x)) / d;

  return [
    { x: px + dx, y: py - dy },
    { x: px - dx, y: py + dy },
  ];
}

function circleCircleCollision(c1: Circle, c2: Circle): boolean {
  return distanceSq(c1.center, c2.center) <= (c1.radius + c2.radius) ** 2;
}
圆锥曲线初步
圆锥曲线是平面截圆锥面产生的曲线族。除了几何定义外，圆锥曲线还有焦点-准线定义：平面上到定点（焦点）的距离与到定直线（准线）距离之比为常数 e（离心率）的点的轨迹。


椭圆的标准方程为 x²/a² + y²/b² = 1（a > b > 0），焦距 c = √(a²-b²)，离心率 e = c/a。开普勒第一定律指出行星运行轨道是以太阳为焦点的椭圆。


抛物线的标准方程为 y² = 4px，焦点在 (p, 0)。抛物面天线和汽车前灯反射器利用了抛物线的焦点反射性质：所有平行于对称轴的入射线经反射后汇聚于焦点。


双曲线的标准方程为 x²/a² - y²/b² = 1，两焦点之间的距离为 2c = 2√(a²+b²)。GPS 定位系统利用双曲线原理——接收器到两个卫星的距离差为常数，确定了一条双曲线。


interface ConicSection {
  type: 'circle' | 'ellipse' | 'parabola' | 'hyperbola';
  eccentricity: number;
}

function classifyConic(e: number): ConicSection['type'] {
  if (Math.abs(e) < 1e-10) return 'circle';
  if (e < 1 - 1e-10) return 'ellipse';
  if (Math.abs(e - 1) < 1e-10) return 'parabola';
  return 'hyperbola';
}

function ellipsePoint(a: number, b: number, t: number): Point {
  return {
    x: a * Math.cos(t),
    y: b * Math.sin(t),
  };
}

function parabolaPoint(p: number, t: number): Point {
  return {
    x: (t * t) / (4 * p),
    y: t,
  };
}

function hyperbolaPoint(a: number, b: number, t: number): Point {
  return {
    x: a / Math.cos(t),
    y: b * Math.tan(t),
  };
}

function ellipseArea(a: number, b: number): number {
  return Math.PI * a * b;
}

function ellipsePerimeterApprox(a: number, b: number): number {
  return Math.PI * (3 * (a + b) - Math.sqrt((3 * a + b) * (a + 3 * b)));
}
小结
    

  • 圆是到定点等距的点集，具有完美对称性，是碰撞检测中最常用的包围体
    • 

  • 圆周角定理、切线定理和圆幂定理是圆的三大核心定理，在几何算法中广泛应用
    • 

  • 弧长 L = rθ 和扇形面积 S = ½r²θ 是圆弧计算的基础公式
    • 

  • 两圆位置关系（外离、外切、相交、内切、内含）由圆心距与半径的关系决定
    • 

  • 圆锥曲线通过离心率统一分类：e=0 圆、0<e<1 椭圆、e=1 抛物线、e>1 双曲线
    • 

  • 椭圆描述天体轨道，抛物线具有焦点反射性质，双曲线应用于 GPS 定位
    • 

  • 理解圆与圆锥曲线为后续学习解析几何和计算几何奠定坚实基础
