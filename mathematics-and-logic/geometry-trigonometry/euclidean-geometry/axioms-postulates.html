公理与公设

核心概念

几何学作为数学中最古老的分支之一，其严谨性建立在公理化方法之上。欧几里得在《几何原本》中首次系统地采用了公理化体系，从少量不证自明的命题出发，通过逻辑推理推导出整个几何学大厦。这种方法深刻影响了数学乃至计算机科学的发展——从形式化验证到类型系统，公理化思维无处不在。

公理（axiom）是被接受为不需要证明的基本事实，公设（postulate）则是针对特定学科的基本假设。在欧几里得体系中，五条公设构成了平面几何的基础，而第五公设（平行公设）的独特性催生了非欧几何，彻底改变了人类对空间的认知。

欧几里得五大公设
欧几里得在《几何原本》中提出了五条公设，前四条简洁直观，第五条却复杂得多，这种不对称性暗示了深刻的数学结构。


公设一：两点确定一条直线。 从任意一点到任意另一点可以画一条直线。这是最基本的几何构造，对应计算机图形学中的线段绘制基元。


公设二：线段可以无限延长。 有限直线可以沿直线连续延长。这个公设保证了几何空间的无界性，在光线追踪算法中，射线的无限延伸就体现了这一思想。


公设三：圆由圆心和半径确定。 以任意点为圆心、任意长度为半径可以画一个圆。碰撞检测中的圆形包围盒就是这一公设的直接应用。


公设四：所有直角都相等。 这保证了角度度量的一致性，是坐标系正交性的基础。


公设五：平行公设。 若一条直线与两条直线相交，同侧内角之和小于两个直角，则这两条直线在该侧必定相交。这条公设的等价表述是：过直线外一点，有且仅有一条直线与已知直线平行。


interface Point {
  x: number;
  y: number;
}

interface Line {
  start: Point;
  direction: Point;
}

function areParallel(l1: Line, l2: Line): boolean {
  const cross = l1.direction.x * l2.direction.y - l1.direction.y * l2.direction.x;
  return Math.abs(cross) < 1e-10;
}

function lineThrough(p1: Point, p2: Point): Line {
  return {
    start: p1,
    direction: { x: p2.x - p1.x, y: p2.y - p1.y },
  };
}

function parallelLine(point: Point, line: Line): Line {
  return {
    start: point,
    direction: { ...line.direction },
  };
}
公理化方法的逻辑结构
公理化方法的核心在于建立一个一致的、完备的、独立的公理系统。一致性意味着不能同时推出命题和它的否命题；完备性意味着所有真命题都可以从公理推导；独立性意味着每条公理不能由其他公理推导。


希尔伯特在 1899 年发表的《几何基础》中重新构建了欧几里得几何的公理体系，将其严格化为 5 组共 20 条公理：

在软件工程中，公理化思维同样重要。类型系统的设计就遵循类似原则：基本类型（公理）通过类型构造器（推理规则）产生复合类型（定理）。一个健全的类型系统不会将正确的程序判定为错误（一致性），也不会遗漏所有正确程序的验证（完备性）。


平行公设与非欧几何
两千多年来，数学家们试图用前四条公设证明第五公设，但都失败了。19 世纪，罗巴切夫斯基、鲍耶和高斯各自独立地发现：否定第五公设可以得到完全自洽的新几何。

双曲几何中，过直线外一点可以画无穷多条不与已知直线相交的直线。这在网络科学中有重要应用——互联网的拓扑结构更接近双曲空间而非欧几里得空间，双曲嵌入算法因此被广泛用于图表示学习。


椭圆几何（球面几何）中，任意两条"直线"（大圆弧）都会相交，不存在平行线。地球上的航线规划就是典型的球面几何问题。


type GeometryType = 'euclidean' | 'hyperbolic' | 'elliptic';

interface GeometryProperties {
  type: GeometryType;
  curvature: number;
  parallelLines: string;
  triangleAngleSum: string;
}

function getGeometryProperties(curvature: number): GeometryProperties {
  if (Math.abs(curvature) < 1e-10) {
    return {
      type: 'euclidean',
      curvature: 0,
      parallelLines: 'exactly one',
      triangleAngleSum: '= π',
    };
  }
  if (curvature < 0) {
    return {
      type: 'hyperbolic',
      curvature,
      parallelLines: 'infinitely many',
      triangleAngleSum: '< π',
    };
  }
  return {
    type: 'elliptic',
    curvature,
    parallelLines: 'none',
    triangleAngleSum: '> π',
  };
}

function sphericalDistance(lat1: number, lon1: number, lat2: number, lon2: number, radius: number): number {
  const dLat = lat2 - lat1;
  const dLon = lon2 - lon1;
  const a = Math.sin(dLat / 2) ** 2 + Math.cos(lat1) * Math.cos(lat2) * Math.sin(dLon / 2) ** 2;
  return 2 * radius * Math.asin(Math.sqrt(a));
}
公理化方法在计算机科学中的应用
公理化方法不仅是几何学的基础工具，在计算机科学中同样有广泛应用。形式化验证、定理证明器、类型理论都深植于公理化传统。


Curry-Howard 同构将命题与类型对应、证明与程序对应，使得编写类型正确的程序等价于构造数学证明。TypeScript 的类型系统虽然不如 Coq 或 Lean 那样强大，但其条件类型和映射类型已经展现了类型级编程的能力。


type Equals<A, B> = A extends B ? (B extends A ? true : false) : false;

type Assert<T extends true> = T;

type Test1 = Assert<Equals<1, 1>>;

interface Vector2D {
  x: number;
  y: number;
}

interface Vector3D extends Vector2D {
  z: number;
}

function dotProduct2D(a: Vector2D, b: Vector2D): number {
  return a.x * b.x + a.y * b.y;
}

function isOrthogonal(a: Vector2D, b: Vector2D): boolean {
  return Math.abs(dotProduct2D(a, b)) < 1e-10;
}
在游戏开发中，几何公理直接对应着物理引擎的基本假设。例如，碰撞检测依赖于"两点确定一条线段"（公设一）和距离度量的一致性（公设四的推广）。当游戏世界从平面扩展到球面（如星球模拟），就需要切换到椭圆几何体系。

小结
    

  • 公理化方法是从不证自明的基本命题出发，通过逻辑推理构建完整理论体系的方法
    • 

  • 欧几里得五大公设构成平面几何的基础，其中前四条简洁直观，第五条（平行公设）复杂且独特
    • 

  • 希尔伯特重新严格化了欧几里得体系，将其组织为 5 组 20 条公理，满足一致性、独立性和完备性
    • 

  • 否定平行公设产生了双曲几何（负曲率）和椭圆几何（正曲率），它们在网络科学和地理计算中有重要应用
    • 

  • 公理化思维在计算机科学中的体现包括：类型系统设计、形式化验证、Curry-Howard 同构
    • 

  • 理解公理化方法有助于程序员设计更严谨的接口契约和类型系统，从根本上提高代码的正确性
    •
