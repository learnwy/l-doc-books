几何证明方法

核心概念

几何证明是从已知公理、定理出发，通过逻辑推理得出新结论的过程。对于程序员而言，几何证明的思维方式与编写正确性证明、设计不变量、构建测试用例高度一致。掌握不同的证明策略，不仅能解决几何问题，更能培养严谨的逻辑推理能力。

主要的几何证明方法包括：直接证明法（从条件出发逐步推导）、反证法（假设结论不成立推出矛盾）、坐标证明法（将几何问题转化为代数运算）和变换证明法（利用几何变换的不变性）。每种方法各有优势，选择合适的证明策略往往是解题的关键。

直接证明法
直接证明法从已知条件出发，利用定义、公理和已证定理，逐步推导直到得出结论。这是最基本也最常用的证明方法，对应编程中的"从输入推导到输出"的正向逻辑。


综合法（顺推法）：从条件 A 出发，推出 B，再推出 C，直到得到结论。


分析法（逆推法）：从结论出发，分析需要什么条件成立，逐步回溯到已知条件。


例：证明三角形中位线定理——三角形中位线平行于第三边且等于第三边的一半。


设三角形 ABC，M、N 分别是 AB、AC 的中点。用向量法：


MN = AN - AM = ½AC - ½AB = ½(AC - AB) = ½BC


因此 MN 平行于 BC 且 |MN| = ½|BC|。


interface Point {
  x: number;
  y: number;
}

interface Vector {
  x: number;
  y: number;
}

function vectorFromPoints(from: Point, to: Point): Vector {
  return { x: to.x - from.x, y: to.y - from.y };
}

function midpoint(a: Point, b: Point): Point {
  return { x: (a.x + b.x) / 2, y: (a.y + b.y) / 2 };
}

function vectorLength(v: Vector): number {
  return Math.sqrt(v.x * v.x + v.y * v.y);
}

function areParallel(v1: Vector, v2: Vector): boolean {
  return Math.abs(v1.x * v2.y - v1.y * v2.x) < 1e-10;
}

function verifyMidlineTheorem(a: Point, b: Point, c: Point): boolean {
  const m = midpoint(a, b);
  const n = midpoint(a, c);
  const mn = vectorFromPoints(m, n);
  const bc = vectorFromPoints(b, c);
  const isParallel = areParallel(mn, bc);
  const isHalfLength = Math.abs(vectorLength(mn) - vectorLength(bc) / 2) < 1e-10;
  return isParallel && isHalfLength;
}
直接证明的关键在于选择正确的中间步骤。就像编程中选择合适的数据结构和算法一样，选择合适的辅助线或辅助图形往往是证明成功的关键。


反证法
反证法（proof by contradiction）假设结论不成立，然后从这个假设出发推导出与已知条件或公理的矛盾。反证法特别适合证明唯一性、不存在性以及含有"至少"、"至多"等量词的命题。


经典例题：证明 √2 是无理数。


假设 √2 = p/q（p、q 互素），则 2q² = p²，所以 p 是偶数。设 p = 2k，则 2q² = 4k²，q² = 2k²，所以 q 也是偶数。这与 p、q 互素矛盾。


在几何中，反证法常用于证明线段不相交、点不共线等否定形式的命题。


function proofByContradiction<T>(assumption: () => T, deriveContradiction: (assumed: T) => boolean): boolean {
  const assumed = assumption();
  const contradiction = deriveContradiction(assumed);
  return contradiction;
}

function verifyIrrationalSqrt2(): boolean {
  for (let q = 1; q <= 1000; q++) {
    for (let p = 1; p <= 1500; p++) {
      if (p * p === 2 * q * q) {
        return false;
      }
    }
  }
  return true;
}

function areCollinear(a: Point, b: Point, c: Point): boolean {
  const cross = (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x);
  return Math.abs(cross) < 1e-10;
}

function verifyNonCollinear(points: Point[]): boolean {
  if (points.length < 3) return true;
  for (let i = 0; i < points.length - 2; i++) {
    if (!areCollinear(points[i], points[i + 1], points[i + 2])) {
      return true;
    }
  }
  return false;
}

坐标证明法
坐标证明法将几何问题转化为代数问题：在图形上建立坐标系，用坐标表示点和图形，然后用代数运算证明几何结论。这种方法的最大优势是可以完全程序化——计算机可以自动执行代数验证。

function coordinateProofParallelogram(a: Point, b: Point, c: Point, d: Point): { isDiagonalBisect: boolean } {
  const midAC: Point = { x: (a.x + c.x) / 2, y: (a.y + c.y) / 2 };
  const midBD: Point = { x: (b.x + d.x) / 2, y: (b.y + d.y) / 2 };
  const isDiagonalBisect = Math.abs(midAC.x - midBD.x) < 1e-10 && Math.abs(midAC.y - midBD.y) < 1e-10;
  return { isDiagonalBisect };
}

function distancePointToLine(p: Point, lineP1: Point, lineP2: Point): number {
  const a = lineP2.y - lineP1.y;
  const b = lineP1.x - lineP2.x;
  const c = lineP2.x * lineP1.y - lineP1.x * lineP2.y;
  return Math.abs(a * p.x + b * p.y + c) / Math.sqrt(a * a + b * b);
}

function verifyAngleBisectorProperty(
  vertex: Point,
  sidePoint1: Point,
  sidePoint2: Point,
  bisectorPoint: Point,
): boolean {
  const d1 = distancePointToLine(bisectorPoint, vertex, sidePoint1);
  const d2 = distancePointToLine(bisectorPoint, vertex, sidePoint2);
  return Math.abs(d1 - d2) < 1e-10;
}
坐标证明法在计算机辅助证明中极为重要。自动几何定理证明器（如吴文俊方法）就基于将几何条件转化为多项式方程组，然后通过代数方法验证。

type Transform = (p: Point) => Point;

function translate(dx: number, dy: number): Transform {
  return (p: Point) => ({ x: p.x + dx, y: p.y + dy });
}

function rotate(angle: number, center: Point = { x: 0, y: 0 }): Transform {
  const cos = Math.cos(angle);
  const sin = Math.sin(angle);
  return (p: Point) => ({
    x: center.x + (p.x - center.x) * cos - (p.y - center.y) * sin,
    y: center.y + (p.x - center.x) * sin + (p.y - center.y) * cos,
  });
}

function reflect(axisAngle: number, axisPoint: Point = { x: 0, y: 0 }): Transform {
  const cos2 = Math.cos(2 * axisAngle);
  const sin2 = Math.sin(2 * axisAngle);
  return (p: Point) => {
    const dx = p.x - axisPoint.x;
    const dy = p.y - axisPoint.y;
    return {
      x: axisPoint.x + dx * cos2 + dy * sin2,
      y: axisPoint.y + dx * sin2 - dy * cos2,
    };
  };
}

function scale(factor: number, center: Point = { x: 0, y: 0 }): Transform {
  return (p: Point) => ({
    x: center.x + (p.x - center.x) * factor,
    y: center.y + (p.y - center.y) * factor,
  });
}

function compose(...transforms: Transform[]): Transform {
  return (p: Point) => transforms.reduce((acc, t) => t(acc), p);
}
经典应用：反射法求最短路径。 河边取水问题——从 A 点到河边再到 B 点的最短路径，可以通过将 B 关于河岸做镜像反射得到 B'，然后 AB' 的直线距离就是最短路径长度。这一方法在光线追踪和网络路由中都有应用。


function shortestPathViaLine(a: Point, b: Point, lineY: number): { totalDist: number; reflectionPoint: Point } {
  const bReflected: Point = { x: b.x, y: 2 * lineY - b.y };
  const totalDist = Math.hypot(bReflected.x - a.x, bReflected.y - a.y);
  const t = (lineY - a.y) / (bReflected.y - a.y);
  const reflectionPoint: Point = {
    x: a.x + t * (bReflected.x - a.x),
    y: lineY,
  };
  return { totalDist, reflectionPoint };
}
小结
    

  • 直接证明法从条件正向推导到结论，是最基本的证明方法，包括综合法和分析法两种策略
    • 

  • 反证法假设结论不成立并推出矛盾，适合唯一性、不存在性等否定形式的命题
    • 

  • 坐标证明法将几何转化为代数，可以完全程序化，是自动定理证明的基础
    • 

  • 变换证明法利用平移、旋转、反射、缩放的不变性简化证明，揭示几何结构
    • 

  • 反射法求最短路径是变换证明法的经典应用，在光线追踪和路由优化中有直接价值
    • 

  • 选择合适的证明策略是解题的关键，正如选择合适的算法是编程的关键
    • 

  • 几何证明训练的逻辑推理能力直接迁移到程序正确性证明和测试设计中
