三角函数基础

核心概念

三角函数是将角度映射到实数的函数族，是数学中最重要的周期函数。对于程序员而言，三角函数无处不在——从游戏中的角色旋转到信号处理中的频谱分析，从 CSS 动画到机器人运动学。深入理解三角函数的定义、图像和性质，是掌握众多计算领域的基础。

三角函数的现代定义基于单位圆：在以原点为圆心、半径为 1 的圆上，角度 θ 对应的点坐标为 (cos θ, sin θ)。这一定义将三角函数从直角三角形的限制中解放出来，扩展到任意实数角度。

单位圆与弧度制
弧度制是角度度量的自然单位。一个完整的圆对应 2π 弧度，即弧度等于弧长与半径的比值。弧度制使得三角函数的导数和泰勒展开具有最简洁的形式。

function degToRad(degrees: number): number {
  return (degrees * Math.PI) / 180;
}

function radToDeg(radians: number): number {
  return (radians * 180) / Math.PI;
}

function normalizeAngle(radians: number): number {
  const TWO_PI = 2 * Math.PI;
  let result = radians % TWO_PI;
  if (result < 0) result += TWO_PI;
  return result;
}

function unitCirclePoint(angleRad: number): { x: number; y: number } {
  return {
    x: Math.cos(angleRad),
    y: Math.sin(angleRad),
  };
}

function angleBetweenVectors(ax: number, ay: number, bx: number, by: number): number {
  const dot = ax * bx + ay * by;
  const magA = Math.sqrt(ax * ax + ay * ay);
  const magB = Math.sqrt(bx * bx + by * by);
  return Math.acos(Math.max(-1, Math.min(1, dot / (magA * magB))));
}
在大多数编程语言中，三角函数的参数都使用弧度制。忘记转换弧度和角度是最常见的 bug 来源之一——特别是在混合使用数学公式和用户输入时。


周期性与图像变换
三角函数的核心特征是周期性。sin 和 cos 的基本周期为 2π，tan 的基本周期为 π。通过参数变换，可以调整三角函数的振幅、周期、相位和垂直偏移。

interface WaveParams {
  amplitude: number;
  frequency: number;
  phase: number;
  offset: number;
}

function sineWave(params: WaveParams, t: number): number {
  return params.amplitude * Math.sin(params.frequency * t + params.phase) + params.offset;
}

function generateWaveform(params: WaveParams, duration: number, sampleRate: number): number[] {
  const samples = Math.floor(duration * sampleRate);
  const result: number[] = new Array(samples);
  for (let i = 0; i < samples; i++) {
    const t = i / sampleRate;
    result[i] = sineWave(params, 2 * Math.PI * t);
  }
  return result;
}

function addWaves(waves: WaveParams[], t: number): number {
  return waves.reduce((sum, w) => sum + sineWave(w, 2 * Math.PI * t), 0);
}
傅里叶定理告诉我们，任何周期函数都可以分解为不同频率的正弦波之和。这是信号处理、音频编解码和图像压缩的理论基础。


三角函数在旋转中的应用
在 2D 图形学中，点的旋转是最基本的变换之一。将点 (x, y) 绕原点旋转角度 θ 后得到新坐标：


x' = x cos θ - y sin θ y' = x sin θ + y cos θ


这等价于将坐标向量左乘旋转矩阵。


interface Point {
  x: number;
  y: number;
}

function rotatePoint(p: Point, angle: number, center: Point = { x: 0, y: 0 }): Point {
  const cos = Math.cos(angle);
  const sin = Math.sin(angle);
  const dx = p.x - center.x;
  const dy = p.y - center.y;
  return {
    x: center.x + dx * cos - dy * sin,
    y: center.y + dx * sin + dy * cos,
  };
}

function rotatePolygon(vertices: Point[], angle: number, center: Point): Point[] {
  return vertices.map((v) => rotatePoint(v, angle, center));
}

function spiralPoint(t: number, a: number, b: number): Point {
  const r = a + b * t;
  return {
    x: r * Math.cos(t),
    y: r * Math.sin(t),
  };
}

function lissajousCurve(t: number, ax: number, ay: number, freqX: number, freqY: number, phase: number): Point {
  return {
    x: ax * Math.sin(freqX * t + phase),
    y: ay * Math.sin(freqY * t),
  };
}
在游戏开发中，旋转变换用于：角色朝向计算、摄像机旋转、粒子系统的发射角度、UI 元素的动画效果等。CSS 的 transform: rotate() 本质上就是这个矩阵运算。


三角函数的特殊值与恒等式预览
掌握特殊角度的三角函数值和基本恒等式，可以在编程中避免不必要的数值计算，提高精度和效率。


毕达哥拉斯恒等式（最基本的三角恒等式）：


sin²θ + cos²θ = 1


由此可推导：1 + tan²θ = sec²θ 和 1 + cot²θ = csc²θ


互余关系：sin(π/2 - θ) = cos θ，cos(π/2 - θ) = sin θ


诱导公式：利用对称性，可以将任意角度的三角函数值归结为第一象限的值。


function sinFromCos(cosVal: number): number {
  return Math.sqrt(1 - cosVal * cosVal);
}

function cosFromSin(sinVal: number): number {
  return Math.sqrt(1 - sinVal * sinVal);
}

function tanFromSinCos(sinVal: number, cosVal: number): number {
  if (Math.abs(cosVal) < 1e-15) {
    return sinVal > 0 ? Infinity : -Infinity;
  }
  return sinVal / cosVal;
}

function quadrant(angleRad: number): 1 | 2 | 3 | 4 {
  const normalized = normalizeAngle(angleRad);
  if (normalized < Math.PI / 2) return 1;
  if (normalized < Math.PI) return 2;
  if (normalized < (3 * Math.PI) / 2) return 3;
  return 4;
}

function sinSign(q: 1 | 2 | 3 | 4): 1 | -1 {
  return q <= 2 ? 1 : -1;
}

function cosSign(q: 1 | 2 | 3 | 4): 1 | -1 {
  return q === 1 || q === 4 ? 1 : -1;
}

小结
    

  • 三角函数的单位圆定义将角度映射为坐标，是最通用的定义方式
    • 

  • 弧度制是编程中的标准角度单位，1 弧度 = 180°/π ≈ 57.3°
    • 

  • 正弦波的四个参数（振幅、频率、相位、偏移）控制波形的全部特征，是信号处理的基础
    • 

  • 旋转变换公式 (x cosθ - y sinθ, x sinθ + y cosθ) 是 2D 图形学的核心运算
    • 

  • 毕达哥拉斯恒等式 sin²θ + cos²θ = 1 是最基本的三角关系，由此衍生出全部三角恒等式
    • 

  • 掌握特殊角度的精确值可以避免数值误差，提高程序的精度和性能
    • 

  • 三角函数是连接几何和分析的桥梁，后续的傅里叶分析、微分方程都建立在此基础上
    •
