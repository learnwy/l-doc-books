反三角函数

核心概念

反三角函数是三角函数的逆运算——给定一个三角函数值，求对应的角度。在编程中，反三角函数的使用频率甚至超过三角函数本身：计算两个向量之间的夹角、从坐标求方位角、从像素坐标还原相机角度，都需要反三角函数。

由于三角函数是周期函数，不是一一映射，反三角函数必须限制定义域才能保证单值性。每个反三角函数都有严格的定义域和值域约束，忽略这些约束是常见的编程错误来源。

arcsin 与 arccos
arcsin（反正弦）返回正弦值为 x 的角度，范围限制在 [-π/2, π/2]。arccos（反余弦）返回余弦值为 x 的角度，范围限制在 [0, π]。它们满足互补关系：arcsin x + arccos x = π/2。


arcsin 和 arccos 的输入必须在 [-1, 1] 范围内。在实际编程中，由于浮点数精度问题，计算结果可能略超出这个范围，需要进行截断处理。


function safeAsin(x: number): number {
  return Math.asin(Math.max(-1, Math.min(1, x)));
}

function safeAcos(x: number): number {
  return Math.acos(Math.max(-1, Math.min(1, x)));
}

function angleBetweenVectors(ax: number, ay: number, bx: number, by: number): number {
  const dot = ax * bx + ay * by;
  const magA = Math.sqrt(ax * ax + ay * ay);
  const magB = Math.sqrt(bx * bx + by * by);
  if (magA < 1e-15 || magB < 1e-15) return 0;
  return safeAcos(dot / (magA * magB));
}

function angleBetweenVectors3D(a: [number, number, number], b: [number, number, number]): number {
  const dot = a[0] * b[0] + a[1] * b[1] + a[2] * b[2];
  const magA = Math.sqrt(a[0] ** 2 + a[1] ** 2 + a[2] ** 2);
  const magB = Math.sqrt(b[0] ** 2 + b[1] ** 2 + b[2] ** 2);
  if (magA < 1e-15 || magB < 1e-15) return 0;
  return safeAcos(dot / (magA * magB));
}

atan2：四象限角度计算
atan2(y, x) 是编程中最重要的反三角函数。与 atan(y/x) 不同，atan2 接受两个参数，能正确判断全部四个象限的角度，返回 (-π, π] 范围内的值。


atan(y/x) 的问题在于：当 x 为零时除法未定义；当 x 为负时，atan 返回的角度在错误的象限。atan2 通过分别传入 y 和 x 来解决这些问题。


function heading(dx: number, dy: number): number {
  return Math.atan2(dy, dx);
}

function headingDegrees(dx: number, dy: number): number {
  const rad = Math.atan2(dy, dx);
  const deg = (rad * 180) / Math.PI;
  return deg < 0 ? deg + 360 : deg;
}

function directionVector(angle: number): { x: number; y: number } {
  return { x: Math.cos(angle), y: Math.sin(angle) };
}

function lookAt(fromX: number, fromY: number, toX: number, toY: number): number {
  return Math.atan2(toY - fromY, toX - fromX);
}

function angleDifference(a: number, b: number): number {
  let diff = b - a;
  while (diff > Math.PI) diff -= 2 * Math.PI;
  while (diff < -Math.PI) diff += 2 * Math.PI;
  return diff;
}

function lerpAngle(a: number, b: number, t: number): number {
  const diff = angleDifference(a, b);
  return a + diff * t;
}
atan2 在游戏开发中的典型应用包括：计算角色面朝方向、子弹飞行角度、雷达扫描方位、操纵杆输入方向等。angleDifference 函数处理角度的环绕问题——从 359° 到 1° 的差应该是 2° 而非 358°。

arctan 的泰勒级数为：arctan x = x - x³/3 + x⁵/5 - x⁷/7 + ...（|x| ≤ 1）


这个级数在 x = 1 时给出 π/4 = 1 - 1/3 + 1/5 - 1/7 + ...（莱布尼茨公式），这是计算 π 的经典方法之一，虽然收敛速度很慢。


function atanTaylor(x: number, terms: number): number {
  if (Math.abs(x) > 1) {
    const sign = x > 0 ? 1 : -1;
    return (sign * Math.PI) / 2 - atanTaylor(1 / x, terms);
  }
  let result = 0;
  let power = x;
  for (let n = 0; n < terms; n++) {
    const divisor = 2 * n + 1;
    result += ((n % 2 === 0 ? 1 : -1) * power) / divisor;
    power *= x * x;
  }
  return result;
}

function computePi(terms: number): number {
  return 4 * atanTaylor(1, terms);
}

function machinFormulaPi(terms: number): number {
  return 4 * (4 * atanTaylor(1 / 5, terms) - atanTaylor(1 / 239, terms));
}

function asinTaylor(x: number, terms: number): number {
  let result = x;
  let coeff = x;
  for (let n = 1; n < terms; n++) {
    coeff *= (x * x * (2 * n - 1) * (2 * n - 1)) / (2 * n * (2 * n + 1));
    result += coeff;
  }
  return result;
}
Machin 公式 π/4 = 4 arctan(1/5) - arctan(1/239) 利用较小的 arctan 参数来加速收敛，是历史上计算 π 的高效方法。


反三角函数在坐标变换中的应用
反三角函数是在不同坐标系之间转换的核心工具。笛卡尔坐标到极坐标、球坐标的转换都依赖于反三角函数。


interface CartesianPoint {
  x: number;
  y: number;
}

interface PolarPoint {
  r: number;
  theta: number;
}

function cartesianToPolar(p: CartesianPoint): PolarPoint {
  return {
    r: Math.sqrt(p.x * p.x + p.y * p.y),
    theta: Math.atan2(p.y, p.x),
  };
}

function polarToCartesian(p: PolarPoint): CartesianPoint {
  return {
    x: p.r * Math.cos(p.theta),
    y: p.r * Math.sin(p.theta),
  };
}

interface SphericalPoint {
  r: number;
  theta: number;
  phi: number;
}

function cartesianToSpherical(x: number, y: number, z: number): SphericalPoint {
  const r = Math.sqrt(x * x + y * y + z * z);
  return {
    r,
    theta: r > 1e-15 ? safeAcos(z / r) : 0,
    phi: Math.atan2(y, x),
  };
}

function sphericalToCartesian(s: SphericalPoint): { x: number; y: number; z: number } {
  return {
    x: s.r * Math.sin(s.theta) * Math.cos(s.phi),
    y: s.r * Math.sin(s.theta) * Math.sin(s.phi),
    z: s.r * Math.cos(s.theta),
  };
}
在 3D 图形学中，球坐标常用于实现轨道相机（orbital camera）：用户通过拖拽控制 theta（俯仰角）和 phi（偏航角），相机绕目标点旋转。

小结
    

  • 反三角函数将三角函数值映射回角度，每个函数都有严格的值域限制以保证单值性
    • 

  • Math.asin 和 Math.acos 的输入必须在 [-1, 1] 内，实际编程中需要 clamp 处理浮点溢出
    • 

  • atan2(y, x) 是最实用的反三角函数，能正确处理所有四个象限，避免 atan 的除零和象限错误
    • 

  • angleDifference 函数正确处理角度环绕问题，是游戏开发中的必备工具
    • 

  • 反三角函数的泰勒级数可用于计算 π，Machin 公式利用小参数加速收敛
    • 

  • 笛卡尔坐标到极坐标/球坐标的转换是反三角函数的核心应用场景
    • 

  • 在数值计算中，靠近边界值时反三角函数精度下降，应选择精度最高的变体
