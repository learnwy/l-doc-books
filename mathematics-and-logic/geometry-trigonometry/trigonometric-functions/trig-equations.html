三角方程求解

核心概念

三角方程是含有三角函数的方程。求解三角方程意味着找到满足方程的所有角度值。与代数方程不同，三角方程由于三角函数的周期性，通常具有无穷多个解。在编程中，三角方程的求解出现在逆运动学（机器人手臂角度计算）、碰撞检测（求射线与曲线的交点）、信号处理（频率估计）等场景。

求解三角方程的基本策略是：先通过恒等式化简为基本形式（如 sin x = a），再利用反三角函数求出特解，最后加上周期得到通解。对于复杂方程，则需要换元法、辅助角法或数值方法。

基本三角方程的通解
三个基本三角方程的通解公式是所有三角方程求解的基础。


sin x = a (|a| ≤ 1)：


    

  • x = arcsin a + 2kπ，或 x = π - arcsin a + 2kπ
    • 

  • 统一写法：x = (-1)ⁿ arcsin a + nπ（n ∈ ℤ）
    • 



cos x = a (|a| ≤ 1)：


    

  • x = ± arccos a + 2kπ（k ∈ ℤ）
    • 



tan x = a：


    

  • x = arctan a + kπ（k ∈ ℤ）
    • 



function solveSinEquation(a: number): number[] | null {
  if (Math.abs(a) > 1) return null;
  const base = Math.asin(a);
  return [base, Math.PI - base];
}

function solveCosEquation(a: number): number[] | null {
  if (Math.abs(a) > 1) return null;
  const base = Math.acos(a);
  return [base, -base];
}

function solveTanEquation(a: number): number[] {
  const base = Math.atan(a);
  return [base];
}

function allSolutions(baseSolutions: number[], period: number, rangeMin: number, rangeMax: number): number[] {
  const solutions: number[] = [];
  for (const base of baseSolutions) {
    let k = Math.ceil((rangeMin - base) / period);
    while (true) {
      const x = base + k * period;
      if (x > rangeMax + 1e-10) break;
      if (x >= rangeMin - 1e-10) {
        solutions.push(x);
      }
      k++;
    }
  }
  return solutions.sort((a, b) => a - b);
}

function solveSinInRange(a: number, min: number, max: number): number[] {
  const bases = solveSinEquation(a);
  if (!bases) return [];
  return allSolutions(bases, 2 * Math.PI, min, max);
}

换元法求解高次方程
当三角方程可以表示为某个三角函数的多项式时，可以通过换元将其转化为代数方程。


例：2sin²x - sin x - 1 = 0


设 t = sin x，则 2t² - t - 1 = 0，解得 t = 1 或 t = -1/2。


    

  • sin x = 1 → x = π/2 + 2kπ
    • 

  • sin x = -1/2 → x = -π/6 + 2kπ 或 x = π + π/6 + 2kπ
    • 



function solveQuadraticTrig(a: number, b: number, c: number, trigType: 'sin' | 'cos' | 'tan'): number[] {
  const discriminant = b * b - 4 * a * c;
  if (discriminant < 0) return [];

  const sqrtD = Math.sqrt(discriminant);
  const t1 = (-b + sqrtD) / (2 * a);
  const t2 = (-b - sqrtD) / (2 * a);

  const roots: number[] = [];

  for (const t of [t1, t2]) {
    let solutions: number[] | null;
    switch (trigType) {
      case 'sin':
        solutions = solveSinEquation(t);
        break;
      case 'cos':
        solutions = solveCosEquation(t);
        break;
      case 'tan':
        solutions = solveTanEquation(t);
        break;
    }
    if (solutions) roots.push(...solutions);
  }

  return roots;
}

function solveLinearSinCos(a: number, b: number, c: number): number[] {
  const R = Math.sqrt(a * a + b * b);
  if (R < 1e-15) return [];
  const ratio = c / R;
  if (Math.abs(ratio) > 1) return [];
  const phi = Math.atan2(b, a);
  const bases = solveSinEquation(ratio);
  if (!bases) return [];
  return bases.map((x) => x - phi);
}
万能代换是另一种强大的换元技巧：设 t = tan(x/2)，则：


    

  • sin x = 2t/(1+t²)
    • 

  • cos x = (1-t²)/(1+t²)
    • 



这将三角方程完全转化为 t 的有理方程。


function universalSubstitution(t: number): { sin: number; cos: number } {
  const t2 = t * t;
  return {
    sin: (2 * t) / (1 + t2),
    cos: (1 - t2) / (1 + t2),
  };
}
数值方法求解超越方程
许多实际应用中的三角方程没有解析解，需要使用数值方法。最常用的是牛顿法和二分法。


二分法：要求函数在区间两端异号，通过不断缩小区间逼近零点。收敛慢但稳定。


牛顿法：利用导数信息快速逼近零点。收敛快但需要良好的初始值。


function bisect(
  f: (x: number) => number,
  a: number,
  b: number,
  tolerance: number = 1e-12,
  maxIterations: number = 100,
): number {
  let lo = a,
    hi = b;
  let fLo = f(lo);

  for (let i = 0; i < maxIterations; i++) {
    const mid = (lo + hi) / 2;
    const fMid = f(mid);

    if (Math.abs(fMid) < tolerance || (hi - lo) / 2 < tolerance) {
      return mid;
    }

    if (fLo * fMid < 0) {
      hi = mid;
    } else {
      lo = mid;
      fLo = fMid;
    }
  }
  return (lo + hi) / 2;
}

function newton(
  f: (x: number) => number,
  df: (x: number) => number,
  x0: number,
  tolerance: number = 1e-12,
  maxIterations: number = 50,
): number {
  let x = x0;
  for (let i = 0; i < maxIterations; i++) {
    const fx = f(x);
    if (Math.abs(fx) < tolerance) return x;
    const dfx = df(x);
    if (Math.abs(dfx) < 1e-15) break;
    x = x - fx / dfx;
  }
  return x;
}

function solveXEqualsCosX(): number {
  return bisect((x) => x - Math.cos(x), 0, Math.PI / 2);
}

function findIntersections(
  f: (x: number) => number,
  g: (x: number) => number,
  start: number,
  end: number,
  steps: number,
): number[] {
  const h = (x: number) => f(x) - g(x);
  const results: number[] = [];
  const dx = (end - start) / steps;

  for (let i = 0; i < steps; i++) {
    const a = start + i * dx;
    const b = a + dx;
    if (h(a) * h(b) <= 0) {
      results.push(bisect(h, a, b));
    }
  }
  return results;
}
逆运动学中的三角方程
逆运动学（Inverse Kinematics, IK）是三角方程在游戏开发和机器人学中最典型的应用。给定末端执行器的目标位置，求解各关节的角度。


对于二连杆机械臂（长度为 l₁ 和 l₂），末端点 (x, y) 需要满足：


    

  • x = l₁ cos θ₁ + l₂ cos(θ₁ + θ₂)
    • 

  • y = l₁ sin θ₁ + l₂ sin(θ₁ + θ₂)
    • 



通过余弦定理和三角方程求解关节角度：


interface IKSolution {
  theta1: number;
  theta2: number;
}

function solveIK2Link(l1: number, l2: number, targetX: number, targetY: number): IKSolution[] {
  const distSq = targetX * targetX + targetY * targetY;
  const dist = Math.sqrt(distSq);

  if (dist > l1 + l2 || dist < Math.abs(l1 - l2)) return [];

  const cosTheta2 = (distSq - l1 * l1 - l2 * l2) / (2 * l1 * l2);
  const clampedCos = Math.max(-1, Math.min(1, cosTheta2));
  const theta2 = Math.acos(clampedCos);

  const k1 = l1 + l2 * Math.cos(theta2);
  const k2 = l2 * Math.sin(theta2);
  const theta1 = Math.atan2(targetY, targetX) - Math.atan2(k2, k1);

  const k2Neg = l2 * Math.sin(-theta2);
  const k1Neg = l1 + l2 * Math.cos(-theta2);
  const theta1Neg = Math.atan2(targetY, targetX) - Math.atan2(k2Neg, k1Neg);

  return [
    { theta1, theta2 },
    { theta1: theta1Neg, theta2: -theta2 },
  ];
}

function forwardKinematics(l1: number, l2: number, theta1: number, theta2: number): { x: number; y: number } {
  return {
    x: l1 * Math.cos(theta1) + l2 * Math.cos(theta1 + theta2),
    y: l1 * Math.sin(theta1) + l2 * Math.sin(theta1 + theta2),
  };
}

小结
    

  • 三角方程因周期性通常有无穷多解，通解 = 特解 + 整数倍周期
    • 

  • 基本方程 sin x = a, cos x = a, tan x = a 的通解公式是一切三角方程求解的基础
    • 

  • 换元法将高次三角方程转化为代数方程，万能代换 t = tan(x/2) 可处理一般情况
    • 

  • 辅助角公式将 a sin x + b cos x = c 化为 R sin(x + φ) = c 的简洁形式
    • 

  • 超越方程无解析解时使用数值方法：二分法稳定、牛顿法快速
    • 

  • 逆运动学是三角方程在游戏和机器人中的核心应用，二连杆 IK 有解析解
    • 

  • 数值求解时需注意收敛性和初始值选择，多解情况下需要在搜索区间内全面扫描
    •
