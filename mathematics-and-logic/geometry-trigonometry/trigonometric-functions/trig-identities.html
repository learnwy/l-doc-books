三角恒等式

核心概念

三角恒等式是对任意角度都成立的三角函数等式。它们是三角学的核心工具，在化简表达式、求解方程、证明等式以及信号处理中不可或缺。对于程序员而言，熟练运用三角恒等式可以优化计算、减少数值误差、简化几何算法。

三角恒等式可以按复杂度分为基本恒等式（毕达哥拉斯族）、和差恒等式、倍角恒等式、半角恒等式和积化和差恒等式。这些恒等式之间存在严密的推导关系——从最基本的 sin²θ + cos²θ = 1 出发，可以推导出全部其他恒等式。

和差角公式
和差角公式是三角恒等式中最重要的一组，所有其他高级恒等式都由它们推导而来。


正弦和差：


    

  • sin(α + β) = sin α cos β + cos α sin β
    • 

  • sin(α - β) = sin α cos β - cos α sin β
    • 



余弦和差：


    

  • cos(α + β) = cos α cos β - sin α sin β
    • 

  • cos(α - β) = cos α cos β + sin α sin β
    • 



正切和差：


    

  • tan(α + β) = (tan α + tan β) / (1 - tan α tan β)
    • 

  • tan(α - β) = (tan α - tan β) / (1 + tan α tan β)
    • 



这些公式的几何含义是两次旋转的复合：先旋转 α 再旋转 β 等价于旋转 α+β。旋转矩阵的乘法直接给出和差公式。


function sinSum(sinA: number, cosA: number, sinB: number, cosB: number): number {
  return sinA * cosB + cosA * sinB;
}

function cosSum(sinA: number, cosA: number, sinB: number, cosB: number): number {
  return cosA * cosB - sinA * sinB;
}

function sinDiff(sinA: number, cosA: number, sinB: number, cosB: number): number {
  return sinA * cosB - cosA * sinB;
}

function cosDiff(sinA: number, cosA: number, sinB: number, cosB: number): number {
  return cosA * cosB + sinA * sinB;
}

function tanSum(tanA: number, tanB: number): number {
  return (tanA + tanB) / (1 - tanA * tanB);
}

function rotationMatrix(angle: number): [number, number, number, number] {
  const c = Math.cos(angle);
  const s = Math.sin(angle);
  return [c, -s, s, c];
}

function composeRotations(a1: number, a2: number): [number, number, number, number] {
  const [c1, ms1, s1, c1b] = rotationMatrix(a1);
  const [c2, ms2, s2, c2b] = rotationMatrix(a2);
  return [c1 * c2 + ms1 * s2, c1 * ms2 + ms1 * c2b, s1 * c2 + c1b * s2, s1 * ms2 + c1b * c2b];
}
倍角与半角公式
倍角公式是和差公式中 α = β 的特例，但在实际应用中极为频繁。


二倍角：


    

  • sin 2θ = 2 sin θ cos θ
    • 

  • cos 2θ = cos²θ - sin²θ = 2cos²θ - 1 = 1 - 2sin²θ
    • 

  • tan 2θ = 2tan θ / (1 - tan²θ)
    • 



cos 2θ 有三种等价形式，在不同场景中选择最方便的一种：


    

  • 含 sin 和 cos 时用第一种
    • 

  • 需要消去 sin 时用第二种
    • 

  • 需要消去 cos 时用第三种
    • 



半角公式（由二倍角公式逆推）：


    

  • sin²(θ/2) = (1 - cos θ) / 2
    • 

  • cos²(θ/2) = (1 + cos θ) / 2
    • 

  • tan(θ/2) = sin θ / (1 + cos θ) = (1 - cos θ) / sin θ
    • 



function sin2(sinT: number, cosT: number): number {
  return 2 * sinT * cosT;
}

function cos2FromSinCos(sinT: number, cosT: number): number {
  return cosT * cosT - sinT * sinT;
}

function cos2FromCos(cosT: number): number {
  return 2 * cosT * cosT - 1;
}

function cos2FromSin(sinT: number): number {
  return 1 - 2 * sinT * sinT;
}

function halfAngleSin(cosTheta: number): number {
  return Math.sqrt((1 - cosTheta) / 2);
}

function halfAngleCos(cosTheta: number): number {
  return Math.sqrt((1 + cosTheta) / 2);
}

function halfAngleTan(sinTheta: number, cosTheta: number): number {
  return sinTheta / (1 + cosTheta);
}

function powerReduction(sinT: number): number {
  return (1 - Math.cos(2 * Math.asin(sinT))) / 2;
}

Haversine 公式是半角公式在球面距离计算中的经典应用：


function haversine(lat1: number, lon1: number, lat2: number, lon2: number, radius: number): number {
  const dLat = lat2 - lat1;
  const dLon = lon2 - lon1;
  const a = Math.sin(dLat / 2) ** 2 + Math.cos(lat1) * Math.cos(lat2) * Math.sin(dLon / 2) ** 2;
  return 2 * radius * Math.asin(Math.sqrt(a));
}
积化和差与和差化积
积化和差将三角函数的乘积转换为和或差，和差化积则是其逆变换。这在信号处理中对应调制和解调。


积化和差：


    

  • sin α cos β = ½[sin(α+β) + sin(α-β)]
    • 

  • cos α sin β = ½[sin(α+β) - sin(α-β)]
    • 

  • cos α cos β = ½[cos(α+β) + cos(α-β)]
    • 

  • sin α sin β = -½[cos(α+β) - cos(α-β)]
    • 



和差化积：


    

  • sin A + sin B = 2 sin((A+B)/2) cos((A-B)/2)
    • 

  • sin A - sin B = 2 cos((A+B)/2) sin((A-B)/2)
    • 

  • cos A + cos B = 2 cos((A+B)/2) cos((A-B)/2)
    • 

  • cos A - cos B = -2 sin((A+B)/2) sin((A-B)/2)
    • 



function productToSum(
  sinA: number,
  cosA: number,
  a: number,
  sinB: number,
  cosB: number,
  b: number,
): { sinCos: number; cosSin: number; cosCos: number; sinSin: number } {
  return {
    sinCos: 0.5 * (Math.sin(a + b) + Math.sin(a - b)),
    cosSin: 0.5 * (Math.sin(a + b) - Math.sin(a - b)),
    cosCos: 0.5 * (Math.cos(a + b) + Math.cos(a - b)),
    sinSin: -0.5 * (Math.cos(a + b) - Math.cos(a - b)),
  };
}

function amplitudeModulation(carrier: number, signal: number, t: number, depth: number): number {
  return (1 + depth * Math.cos(signal * t)) * Math.cos(carrier * t);
}

function beatFrequency(f1: number, f2: number, t: number): number {
  return 2 * Math.cos(((f1 + f2) / 2) * t) * Math.cos(((f1 - f2) / 2) * t);
}
在音频处理中，两个频率接近的正弦波叠加会产生拍频现象——声音的振幅按两个频率之差的一半周期性变化。这正是和差化积公式的物理体现。


辅助角公式与恒等式应用
辅助角公式将 a sin θ + b cos θ 的形式统一为一个正弦或余弦函数，是化简三角表达式的利器。


a sin θ + b cos θ = √(a² + b²) sin(θ + φ)


其中 tan φ = b/a。


这个公式在信号处理中用于将同频正弦波和余弦波合并为单一正弦波，在结构力学中用于合成同频振动。


function auxiliaryAngle(a: number, b: number): { amplitude: number; phase: number } {
  const amplitude = Math.sqrt(a * a + b * b);
  const phase = Math.atan2(b, a);
  return { amplitude, phase };
}

function combineSinCos(a: number, b: number, theta: number): number {
  const { amplitude, phase } = auxiliaryAngle(a, b);
  return amplitude * Math.sin(theta + phase);
}

function verifyCombination(a: number, b: number, theta: number): { direct: number; combined: number; error: number } {
  const direct = a * Math.sin(theta) + b * Math.cos(theta);
  const combined = combineSinCos(a, b, theta);
  return {
    direct,
    combined,
    error: Math.abs(direct - combined),
  };
}
小结
    

  • 和差角公式是三角恒等式的基石，对应旋转矩阵的乘法，所有其他恒等式都由此推导
    • 

  • 倍角公式将 2θ 的三角函数表示为 θ 的函数，cos 2θ 有三种等价形式适用于不同场景
    • 

  • 半角公式是倍角公式的逆运算，Haversine 公式利用半角计算球面距离
    • 

  • 积化和差对应信号调制，和差化积对应信号解调，拍频现象是其物理体现
    • 

  • 辅助角公式 a sinθ + b cosθ = R sin(θ+φ) 将两个同频分量合成为单一波形
    • 

  • 合理选择恒等式形式可以显著优化数值计算的精度和效率
    • 

  • 三角恒等式是傅里叶分析、信号处理、图形学等领域的数学基础
    •
