凸包算法

核心概念

凸包（Convex Hull）是包含给定点集的最小凸多边形，可以形象地理解为用一根橡皮筋套住所有点后自然收缩形成的形状。凸包是计算几何中最基础且最重要的数据结构之一——碰撞检测中的 GJK 算法以凸包为前提，路径规划中凸包用于定义障碍物边界，机器学习中凸包用于数据分类的可视化。

凸包算法的核心思想是从点集中识别出位于边界上的点，并按顺序连接。经典算法包括 Graham 扫描法、Andrew 单调链法和 Jarvis 行进法，它们在时间复杂度和实现难度上各有特点。

Graham 扫描法
Graham 扫描法是最经典的凸包算法。它首先选择 y 坐标最小的点作为基准点，然后按极角排序所有点，最后用栈维护凸包边界——每次加入新点时，检查前两个点是否构成右转（非左转），如果是则弹出。


interface Point {
  x: number;
  y: number;
}

function cross(o: Point, a: Point, b: Point): number {
  return (a.x - o.x) * (b.y - o.y) - (a.y - o.y) * (b.x - o.x);
}

function distanceSq(a: Point, b: Point): number {
  return (a.x - b.x) ** 2 + (a.y - b.y) ** 2;
}

function grahamScan(points: Point[]): Point[] {
  const n = points.length;
  if (n < 3) return [...points];

  let pivot = 0;
  for (let i = 1; i < n; i++) {
    if (points[i].y < points[pivot].y || (points[i].y === points[pivot].y && points[i].x < points[pivot].x)) {
      pivot = i;
    }
  }

  const p0 = points[pivot];
  const sorted = points
    .filter((_, i) => i !== pivot)
    .sort((a, b) => {
      const angleA = Math.atan2(a.y - p0.y, a.x - p0.x);
      const angleB = Math.atan2(b.y - p0.y, b.x - p0.x);
      if (Math.abs(angleA - angleB) > 1e-10) return angleA - angleB;
      return distanceSq(p0, a) - distanceSq(p0, b);
    });

  const stack: Point[] = [p0, sorted[0]];

  for (let i = 1; i < sorted.length; i++) {
    while (stack.length > 1 && cross(stack[stack.length - 2], stack[stack.length - 1], sorted[i]) <= 0) {
      stack.pop();
    }
    stack.push(sorted[i]);
  }

  return stack;
}
Graham 扫描法的关键在于栈操作：当新加入的点使得最近的边不再是左转时，说明栈顶点不在凸包上，需要弹出。这个过程保证了栈中始终维护一个凸包的前缀。


Andrew 单调链法
Andrew 单调链法是 Graham 扫描的变体，通过 x 坐标排序（而非极角排序）避免了浮点角度计算。它分别构建上凸包和下凸包，然后合并。这是实践中最推荐的实现方式。


function andrewMonotoneChain(points: Point[]): Point[] {
  const pts = [...points].sort((a, b) => (a.x !== b.x ? a.x - b.x : a.y - b.y));
  const n = pts.length;
  if (n < 3) return pts;

  const lower: Point[] = [];
  for (const p of pts) {
    while (lower.length >= 2 && cross(lower[lower.length - 2], lower[lower.length - 1], p) <= 0) {
      lower.pop();
    }
    lower.push(p);
  }

  const upper: Point[] = [];
  for (let i = n - 1; i >= 0; i--) {
    while (upper.length >= 2 && cross(upper[upper.length - 2], upper[upper.length - 1], pts[i]) <= 0) {
      upper.pop();
    }
    upper.push(pts[i]);
  }

  lower.pop();
  upper.pop();
  return [...lower, ...upper];
}
Andrew 单调链的优势在于：排序只比较 x/y 坐标（整数比较），不涉及浮点角度计算，数值稳定性更好。下凸包从左到右扫描，上凸包从右到左扫描，两者拼接形成完整凸包。

Jarvis 行进法
Jarvis 行进法（gift wrapping）模拟了"包礼物"的过程：从最左边的点开始，每次找到相对于当前方向最逆时针的下一个点，直到回到起点。


时间复杂度为 O(nh)，其中 h 是凸包上的点数。当 h 远小于 n 时（如大量内部点），Jarvis 行进法很高效；但最坏情况下 h = n，退化为 O(n²)。


function jarvisMarch(points: Point[]): Point[] {
  const n = points.length;
  if (n < 3) return [...points];

  let leftmost = 0;
  for (let i = 1; i < n; i++) {
    if (points[i].x < points[leftmost].x) leftmost = i;
  }

  const hull: Point[] = [];
  let current = leftmost;

  do {
    hull.push(points[current]);
    let next = 0;

    for (let i = 1; i < n; i++) {
      if (i === current) continue;
      if (next === current) {
        next = i;
        continue;
      }
      const c = cross(points[current], points[next], points[i]);
      if (c > 0) {
        next = i;
      } else if (
        Math.abs(c) < 1e-10 &&
        distanceSq(points[current], points[i]) > distanceSq(points[current], points[next])
      ) {
        next = i;
      }
    }

    current = next;
  } while (current !== leftmost);

  return hull;
}
凸包的应用与扩展
凸包在实际编程中有广泛应用。碰撞检测中，GJK（Gilbert-Johnson-Keerthi）算法利用 Minkowski 差的凸包来检测两个凸体是否相交。路径规划中，凸包用于定义可通行区域的边界。


function convexHullArea(hull: Point[]): number {
  let area = 0;
  const n = hull.length;
  for (let i = 0; i < n; i++) {
    const j = (i + 1) % n;
    area += hull[i].x * hull[j].y;
    area -= hull[j].x * hull[i].y;
  }
  return Math.abs(area) / 2;
}

function convexHullPerimeter(hull: Point[]): number {
  let perimeter = 0;
  const n = hull.length;
  for (let i = 0; i < n; i++) {
    const j = (i + 1) % n;
    perimeter += Math.sqrt(distanceSq(hull[i], hull[j]));
  }
  return perimeter;
}

function isPointInConvexHull(hull: Point[], p: Point): boolean {
  const n = hull.length;
  for (let i = 0; i < n; i++) {
    const j = (i + 1) % n;
    if (cross(hull[i], hull[j], p) < -1e-10) return false;
  }
  return true;
}

function minkowskiSum(hullA: Point[], hullB: Point[]): Point[] {
  const allPoints: Point[] = [];
  for (const a of hullA) {
    for (const b of hullB) {
      allPoints.push({ x: a.x + b.x, y: a.y + b.y });
    }
  }
  return andrewMonotoneChain(allPoints);
}

小结
    

  • 凸包是包含点集的最小凸多边形，是计算几何最基础的数据结构
    • 

  • Graham 扫描用极角排序 + 栈实现，O(n log n) 时间，是最经典的算法
    • 

  • Andrew 单调链用 x 坐标排序，分别构建上下凸包，数值稳定性最好，推荐用于实际编程
    • 

  • Jarvis 行进时间复杂度 O(nh)，适合凸包点数 h 远小于 n 的场景
    • 

  • 叉积的符号判断（左转/右转）是所有凸包算法的核心操作
    • 

  • 凸包广泛应用于碰撞检测（GJK）、路径规划、最小包围矩形和异常检测
    • 

  • Minkowski 和/差是凸包在碰撞检测中的关键扩展，将两个凸体的碰撞判定转化为原点包含判定
