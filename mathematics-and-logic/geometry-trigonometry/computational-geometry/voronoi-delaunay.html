Voronoi 图与 Delaunay 三角剖分

核心概念

Voronoi 图和 Delaunay 三角剖分是计算几何中最重要的对偶结构。Voronoi 图将平面划分为若干区域，每个区域对应一个生成点，区域内的所有点到该生成点的距离最近。Delaunay 三角剖分则是 Voronoi 图的对偶——连接所有共享 Voronoi 边的生成点对，得到的三角剖分满足"空圆性质"。

这两种结构在实际应用中极为重要：游戏中的地图分区、地形生成、AI 导航网格、最近邻搜索、资源分配优化，甚至蛋白质结构分析都依赖它们。Voronoi 图回答"最近的是哪个"的问题，Delaunay 三角剖分则提供最优的网格划分。

Voronoi 图的定义与性质
给定平面上 n 个点（称为站点或生成点），每个点 pᵢ 的 Voronoi 区域定义为：V(pᵢ) = {x ∈ ℝ² : d(x, pᵢ) ≤ d(x, pⱼ), ∀j ≠ i}。


每个 Voronoi 区域是一个凸多边形（可能无界）。两个相邻区域的边界（Voronoi 边）是两个站点的垂直平分线的一段。三个 Voronoi 区域的交点（Voronoi 顶点）是三个站点的外接圆圆心。


interface Point {
  x: number;
  y: number;
}

interface VoronoiEdge {
  start: Point;
  end: Point;
  leftSite: number;
  rightSite: number;
}

interface VoronoiCell {
  site: Point;
  vertices: Point[];
  neighbors: number[];
}

function perpendicularBisector(a: Point, b: Point): { point: Point; direction: Point } {
  const mid: Point = { x: (a.x + b.x) / 2, y: (a.y + b.y) / 2 };
  const direction: Point = { x: -(b.y - a.y), y: b.x - a.x };
  return { point: mid, direction };
}

function circumcenter(a: Point, b: Point, c: Point): Point {
  const ax = a.x,
    ay = a.y;
  const bx = b.x,
    by = b.y;
  const cx = c.x,
    cy = c.y;
  const D = 2 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by));
  if (Math.abs(D) < 1e-10) return { x: Infinity, y: Infinity };
  return {
    x: ((ax * ax + ay * ay) * (by - cy) + (bx * bx + by * by) * (cy - ay) + (cx * cx + cy * cy) * (ay - by)) / D,
    y: ((ax * ax + ay * ay) * (cx - bx) + (bx * bx + by * by) * (ax - cx) + (cx * cx + cy * cy) * (bx - ax)) / D,
  };
}

function nearestSite(point: Point, sites: Point[]): number {
  let minDist = Infinity;
  let nearest = 0;
  for (let i = 0; i < sites.length; i++) {
    const d = (point.x - sites[i].x) ** 2 + (point.y - sites[i].y) ** 2;
    if (d < minDist) {
      minDist = d;
      nearest = i;
    }
  }
  return nearest;
}

Delaunay 三角剖分
Delaunay 三角剖分的核心性质是空圆性质（empty circle property）：每个三角形的外接圆内部不包含其他任何站点。这保证了 Delaunay 三角剖分最大化了所有三角形的最小角——即它避免了"瘦长"三角形，是有限元分析和地形渲染的最优网格。


Delaunay 三角剖分是 Voronoi 图的对偶：两个站点共享一条 Voronoi 边，当且仅当它们是 Delaunay 三角剖分中某条边的端点。


interface Triangle {
  a: number;
  b: number;
  c: number;
}

function isInCircumcircle(p: Point, a: Point, b: Point, c: Point): boolean {
  const ax = a.x - p.x,
    ay = a.y - p.y;
  const bx = b.x - p.x,
    by = b.y - p.y;
  const cx = c.x - p.x,
    cy = c.y - p.y;

  const det =
    (ax * ax + ay * ay) * (bx * cy - cx * by) -
    (bx * bx + by * by) * (ax * cy - cx * ay) +
    (cx * cx + cy * cy) * (ax * by - bx * ay);

  return det > 0;
}

function bowyerWatson(points: Point[]): Triangle[] {
  const superA: Point = { x: -1e6, y: -1e6 };
  const superB: Point = { x: 1e6, y: -1e6 };
  const superC: Point = { x: 0, y: 1e6 };

  const allPoints = [superA, superB, superC, ...points];
  let triangles: Triangle[] = [{ a: 0, b: 1, c: 2 }];

  for (let i = 3; i < allPoints.length; i++) {
    const p = allPoints[i];
    const badTriangles: Triangle[] = [];
    const goodTriangles: Triangle[] = [];

    for (const tri of triangles) {
      if (isInCircumcircle(p, allPoints[tri.a], allPoints[tri.b], allPoints[tri.c])) {
        badTriangles.push(tri);
      } else {
        goodTriangles.push(tri);
      }
    }

    const boundary: [number, number][] = [];
    for (const tri of badTriangles) {
      const edges: [number, number][] = [
        [tri.a, tri.b],
        [tri.b, tri.c],
        [tri.c, tri.a],
      ];
      for (const [ea, eb] of edges) {
        const shared = badTriangles.some((other) => other !== tri && hasEdge(other, ea, eb));
        if (!shared) boundary.push([ea, eb]);
      }
    }

    const newTriangles = boundary.map(([ea, eb]) => ({
      a: ea,
      b: eb,
      c: i,
    }));

    triangles = [...goodTriangles, ...newTriangles];
  }

  return triangles
    .filter((tri) => tri.a > 2 && tri.b > 2 && tri.c > 2)
    .map((tri) => ({ a: tri.a - 3, b: tri.b - 3, c: tri.c - 3 }));
}

function hasEdge(tri: Triangle, a: number, b: number): boolean {
  const verts = [tri.a, tri.b, tri.c];
  return verts.includes(a) && verts.includes(b);
}
Fortune 扫描线算法
Fortune 算法是构建 Voronoi 图的高效算法，时间复杂度 O(n log n)。它使用一条从上到下的扫描线和一条抛物线弧组成的"海滩线"（beach line）来增量构建 Voronoi 图。


算法维护两种事件：


    

  1. 站点事件：扫描线遇到新站点，在海滩线上插入新的抛物线弧
    2. 

  2. 圆事件：三条相邻弧的消失点，产生新的 Voronoi 顶点

实际应用与扩展
Voronoi 图和 Delaunay 三角剖分的应用覆盖了游戏开发、地理信息系统、科学计算等众多领域。


function createNavigationMesh(
  obstacles: Point[][],
  bounds: { minX: number; minY: number; maxX: number; maxY: number },
): { vertices: Point[]; triangles: Triangle[] } {
  const navPoints: Point[] = [];

  for (const obstacle of obstacles) {
    navPoints.push(...obstacle);
  }

  const step = 50;
  for (let x = bounds.minX; x <= bounds.maxX; x += step) {
    for (let y = bounds.minY; y <= bounds.maxY; y += step) {
      navPoints.push({ x, y });
    }
  }

  const triangles = bowyerWatson(navPoints);

  return { vertices: navPoints, triangles };
}

function naturalNeighborInterpolation(sites: Point[], values: number[], query: Point): number {
  const nearest = nearestSite(query, sites);
  let totalWeight = 0;
  let weightedSum = 0;

  for (let i = 0; i < sites.length; i++) {
    const dx = sites[i].x - query.x;
    const dy = sites[i].y - query.y;
    const dist = Math.sqrt(dx * dx + dy * dy);
    if (dist < 1e-10) return values[i];
    const weight = 1 / (dist * dist);
    totalWeight += weight;
    weightedSum += weight * values[i];
  }

  return weightedSum / totalWeight;
}

小结
    

  • Voronoi 图将平面按最近邻原则划分为凸多边形区域，回答"最近的是哪个"的问题
    • 

  • Delaunay 三角剖分是 Voronoi 图的对偶，满足空圆性质，最大化最小角
    • 

  • Voronoi 顶点是三个站点的外接圆圆心，Voronoi 边是两个站点的垂直平分线段
    • 

  • Bowyer-Watson 算法通过增量插入构建 Delaunay 三角剖分，实现简单但最坏 O(n²)
    • 

  • Fortune 扫描线算法在 O(n log n) 时间内构建 Voronoi 图，是最优算法
    • 

  • 导航网格、地形生成、最近邻搜索、自然邻域插值是最常见的应用场景
    • 

  • isInCircumcircle 测试是 Delaunay 三角剖分正确性的核心判断，需要高精度浮点运算
