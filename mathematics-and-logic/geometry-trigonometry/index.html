几何与三角学 简介

本 hub 处理 13 号「数学与统计」分区里与空间形状、角度、坐标直接相关的可计算几何：欧氏几何的公理与定理、三角函数与恒等式、把代数引入几何的解析几何，以及面向工程落地的计算几何算法。它的核心立场是几何作为程序员的日常工具——碰撞检测、坐标变换、寻路、光照、逆运动学背后那一层「形状与角度的数学」，都在这里讲清楚原理并给出可实现的算法。

本 hub 与兄弟 hub 的分工边界

几何相关的内容散落在 13 号分区的多个 hub，最常被混淆的边界如下：

你的问题 应去的 hub 原因
三角形怎么算、向量点积叉积、凸包/线段相交怎么写 本 hub 初等几何 + 三角 + 解析几何 + 计算几何算法
矩阵、特征值、SVD、线性变换的一般理论 线性代数 几何变换的代数引擎，比「向量与几何」一节更系统
极限、导数、积分、梯度、弧长积分 微积分及其应用 连续变化与累积；本 hub 只在需要时引用其结论
曲率、测地线、流形、黎曼度量 微分几何 用微积分研究「弯曲」，是本 hub 的进阶延伸
连续变换下的不变量、同胚、亏格 拓扑学入门 抛开距离与角度的「橡皮几何」
中学代数、函数、方程不等式的运算基本功 基础代数与函数 全分区的入门基石，本 hub 默认你已掌握
浮点误差、数值求根、数值积分的算法细节 数值方法 本 hub 的计算几何章只点到 epsilon 与鲁棒性，深入在此

一句话：本 hub 管「形状/角度的具体几何与算法」，把「一般线性理论」交给线性代数，把「连续/弯曲」交给微积分与微分几何，把「数值工程细节」交给数值方法。

推荐学习路径（分人群）

四章按「严谨基础 → 周期工具 → 代数化 → 工程落地」递进，但不同目标的读者侧重不同：

  • 图形/游戏程序员（最常见）：第 2 章三角函数 → 第 3 章解析几何（重点向量与坐标系）→ 第 4 章计算几何。第 1 章欧氏几何可按需查阅。这条路径直通碰撞检测、坐标变换、光照与寻路。
  • 算法竞赛选手：直接第 3 章「向量与几何」→ 第 4 章全章（凸包、线段相交、Voronoi/Delaunay、几何编程的鲁棒性）。三角函数与解析几何作为工具按需补。
  • 机器人/SLAM 方向：第 2 章（尤其三角方程与逆运动学）→ 第 3 章坐标系统 → 配合 逆运动学 与 ROS2 坐标变换。
  • 数学基础补强者：从第 1 章欧氏几何（公理化与证明方法）顺序读完，建立严格推理习惯，再进入后三章。

每章末的 INDEX 给出该章内部顺序；每篇 L4 文末的「延伸阅读与跨学科链接」标出了到兄弟篇与其它 hub 的真实跳转。

前置知识

  • 必备：基础代数与函数级别的代数运算、函数与方程；任一门编程语言的基本能力（示例多用伪代码/JS 风格）。
  • 第 3 章建议：线性代数的向量与矩阵基础，会让「向量与几何」「坐标系统」理解得更深。
  • 第 4 章建议：对时间复杂度有基本概念；遇到浮点鲁棒性问题时可回查 数值方法。
  • 进阶出口：学完本 hub，想继续深入「弯曲空间」走 微分几何，想要「连续变换的不变量」走 拓扑学入门。
