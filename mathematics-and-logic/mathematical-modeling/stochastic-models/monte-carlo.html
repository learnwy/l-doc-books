蒙特卡罗方法

核心概念

蒙特卡罗方法是一类基于随机采样的数值计算技术。其核心思想是：通过大量随机样本的统计平均来近似计算确定性问题的解。蒙特卡罗方法特别适合高维积分、复杂概率计算和组合优化问题——这些问题用传统解析或网格方法要么不可行，要么计算成本过高。

蒙特卡罗方法的理论基础是大数定律：当样本量 N 趋向无穷时，样本均值几乎必然收敛到期望值。其收敛速度为 O(1/√N)，与问题维度无关——这是蒙特卡罗方法在高维问题上碾压网格方法的核心优势。

随机采样与数值积分
蒙特卡罗积分的基本思想是将定积分转化为期望值计算。对于积分 I = ∫f(x)dx，在积分域上均匀采样 N 个点 x₁,...,xₙ，则 I ≈ (b-a)/N × Σf(xᵢ)。


function monteCarloIntegrate1D(
  f: (x: number) => number,
  a: number,
  b: number,
  samples: number,
): { estimate: number; standardError: number } {
  let sum = 0;
  let sumSq = 0;

  for (let i = 0; i < samples; i++) {
    const x = a + Math.random() * (b - a);
    const fx = f(x);
    sum += fx;
    sumSq += fx * fx;
  }

  const mean = sum / samples;
  const estimate = (b - a) * mean;
  const variance = sumSq / samples - mean * mean;
  const standardError = (b - a) * Math.sqrt(variance / samples);

  return { estimate, standardError };
}

function monteCarloIntegrateND(
  f: (...x: number[]) => number,
  bounds: { min: number; max: number }[],
  samples: number,
): { estimate: number; standardError: number } {
  const dim = bounds.length;
  const volume = bounds.reduce((v, b) => v * (b.max - b.min), 1);

  let sum = 0;
  let sumSq = 0;

  for (let i = 0; i < samples; i++) {
    const point = bounds.map((b) => b.min + Math.random() * (b.max - b.min));
    const fx = f(...point);
    sum += fx;
    sumSq += fx * fx;
  }

  const mean = sum / samples;
  const estimate = volume * mean;
  const variance = sumSq / samples - mean * mean;
  const standardError = volume * Math.sqrt(variance / samples);

  return { estimate, standardError };
}

function estimatePi(samples: number): {
  piEstimate: number;
  error: number;
} {
  let inside = 0;

  for (let i = 0; i < samples; i++) {
    const x = Math.random() * 2 - 1;
    const y = Math.random() * 2 - 1;
    if (x * x + y * y <= 1) inside++;
  }

  const piEstimate = (4 * inside) / samples;
  return {
    piEstimate,
    error: Math.abs(piEstimate - Math.PI),
  };
}
经典示例——用蒙特卡罗方法估算 π：在单位正方形中随机撒点，落在内切圆中的比例 ≈ π/4。这个简单的例子展示了蒙特卡罗方法的核心逻辑：用随机采样的频率近似概率，用概率近似面积。


重要性采样
标准蒙特卡罗方法在被积函数值变化剧烈时方差很大，收敛缓慢。重要性采样通过选择一个更好的采样分布 q(x) 来集中采样到函数值大的区域，显著降低方差。


核心公式：E[f(X)] = ∫f(x)p(x)dx = ∫f(x)(p(x)/q(x))q(x)dx = E_q[f(X)·w(X)]，其中 w(x) = p(x)/q(x) 是重要性权重。


interface ImportanceSamplingResult {
  estimate: number;
  standardError: number;
  effectiveSampleSize: number;
}

function importanceSampling(
  target: (x: number) => number,
  proposal: {
    sample: () => number;
    density: (x: number) => number;
  },
  targetDensity: (x: number) => number,
  samples: number,
): ImportanceSamplingResult {
  let weightedSum = 0;
  let weightedSumSq = 0;
  let weightSum = 0;
  let weightSqSum = 0;

  for (let i = 0; i < samples; i++) {
    const x = proposal.sample();
    const w = targetDensity(x) / proposal.density(x);
    const fx = target(x);

    weightedSum += w * fx;
    weightedSumSq += w * w * fx * fx;
    weightSum += w;
    weightSqSum += w * w;
  }

  const estimate = weightedSum / samples;
  const variance = weightedSumSq / samples - estimate * estimate;
  const standardError = Math.sqrt(variance / samples);

  const ess = (weightSum * weightSum) / weightSqSum;

  return {
    estimate,
    standardError,
    effectiveSampleSize: ess,
  };
}

function gaussianProposal(mean: number, std: number) {
  return {
    sample: () => {
      const u1 = Math.random();
      const u2 = Math.random();
      return mean + std * Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
    },
    density: (x: number) => Math.exp(-((x - mean) ** 2) / (2 * std * std)) / (std * Math.sqrt(2 * Math.PI)),
  };
}
重要性采样的陷阱是权重方差可能极大。如果提议分布 q(x) 的尾部比目标分布 p(x) 轻（即存在 p(x)/q(x) → ∞ 的区域），少数极大权重会主导估计，导致有效样本量远小于实际样本量。

MCMC 基础
马尔可夫链蒙特卡罗（MCMC）是从复杂概率分布中采样的通用方法。当目标分布 π(x) 难以直接采样时，MCMC 构造一个以 π 为平稳分布的马尔可夫链，通过长时间运行链来获得 π 的样本。


Metropolis-Hastings 算法是最基础的 MCMC 方法。在每一步，从提议分布 q(x'|x) 生成候选状态 x'，以概率 α = min(1, π(x')q(x|x') / (π(x)q(x'|x))) 接受或拒绝。


interface MCMCResult {
  chain: number[];
  acceptanceRate: number;
  burnIn: number;
}

function metropolisHastings(
  targetLogDensity: (x: number) => number,
  proposalStd: number,
  initial: number,
  iterations: number,
  burnIn: number = 1000,
): MCMCResult {
  const chain: number[] = [initial];
  let current = initial;
  let accepted = 0;

  for (let i = 0; i < iterations; i++) {
    const u1 = Math.random();
    const u2 = Math.random();
    const proposal = current + proposalStd * Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);

    const logAlpha = targetLogDensity(proposal) - targetLogDensity(current);

    if (Math.log(Math.random()) < logAlpha) {
      current = proposal;
      accepted++;
    }

    chain.push(current);
  }

  return {
    chain,
    acceptanceRate: accepted / iterations,
    burnIn,
  };
}

function mcmcDiagnostics(
  chain: number[],
  burnIn: number,
): {
  mean: number;
  std: number;
  autocorrelation: number[];
  effectiveSampleSize: number;
} {
  const samples = chain.slice(burnIn);
  const n = samples.length;
  const mean = samples.reduce((a, b) => a + b, 0) / n;
  const variance = samples.reduce((sum, x) => sum + (x - mean) ** 2, 0) / (n - 1);
  const std = Math.sqrt(variance);

  const maxLag = Math.min(50, Math.floor(n / 4));
  const autocorrelation: number[] = [];

  for (let lag = 0; lag <= maxLag; lag++) {
    let sum = 0;
    for (let i = 0; i < n - lag; i++) {
      sum += (samples[i] - mean) * (samples[i + lag] - mean);
    }
    autocorrelation.push(sum / ((n - lag) * variance));
  }

  let tau = 1;
  for (let lag = 1; lag <= maxLag; lag++) {
    if (autocorrelation[lag] < 0.05) break;
    tau += 2 * autocorrelation[lag];
  }

  return {
    mean,
    std,
    autocorrelation,
    effectiveSampleSize: n / tau,
  };
}
MCMC 的关键实践要点：设置合适的 burn-in 期（丢弃初始的不稳定样本）；调整提议分布的步长使接受率在 20-50% 之间；使用自相关分析和有效样本量评估链的混合效果。


小结
    

  • 蒙特卡罗方法通过随机采样的统计平均近似计算确定性问题
    • 

  • 核心优势：收敛速度 O(1/√N) 与维度无关，在高维问题上远优于网格方法
    • 

  • 估算 π 是蒙特卡罗方法的经典入门示例，展示了用频率近似概率的核心思想
    • 

  • 重要性采样通过偏向高贡献区域采样显著降低方差，但需要合适的提议分布
    • 

  • 方差缩减技术（对偶变量、控制变量、分层采样）可在标准蒙特卡罗基础上进一步提高效率
    • 

  • MCMC 通过构造马尔可夫链从复杂分布中采样，Metropolis-Hastings 是基础算法
    • 

  • MCMC 诊断关注接受率（20-50%）、burn-in 期和有效样本量
    • 

  • 蒙特卡罗方法在金融定价、贝叶斯推断、物理模拟和优化中广泛应用
    •
