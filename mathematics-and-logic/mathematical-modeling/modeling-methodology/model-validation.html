模型验证与评估

核心概念

模型验证与评估是确保数学模型可靠性的关键环节。验证（Validation）关注模型是否正确反映了现实系统，评估（Evaluation）则量化模型的预测精度和适用范围。二者构成模型质量保证的两大支柱。

理解验证与校验的区别是避免建模陷阱的第一步。校验是内部一致性检查（"我们正确地解了方程吗？"），验证是外部有效性检查（"我们建立了正确的方程吗？"）。一个通过校验但未通过验证的模型意味着数学计算虽然正确，但模型本身与现实不符。

拟合优度与误差度量
拟合优度衡量模型对已有数据的解释能力。最常用的拟合优度指标是决定系数 R²，其值域为 (-∞, 1]，1 表示完美拟合，0 表示模型与简单均值一样好，负值表示模型比均值还差。


interface FitMetrics {
  r2: number;
  adjustedR2: number;
  rmse: number;
  mae: number;
  mape: number;
  aic: number;
  bic: number;
}

function computeFitMetrics(observed: number[], predicted: number[], numParams: number): FitMetrics {
  const n = observed.length;
  const mean = observed.reduce((a, b) => a + b, 0) / n;

  const ssTot = observed.reduce((sum, y) => sum + (y - mean) ** 2, 0);
  const ssRes = observed.reduce((sum, y, i) => sum + (y - predicted[i]) ** 2, 0);
  const r2 = 1 - ssRes / ssTot;
  const adjustedR2 = 1 - ((1 - r2) * (n - 1)) / (n - numParams - 1);

  const rmse = Math.sqrt(ssRes / n);
  const mae = observed.reduce((sum, y, i) => sum + Math.abs(y - predicted[i]), 0) / n;
  const mape = (observed.reduce((sum, y, i) => sum + (y !== 0 ? Math.abs((y - predicted[i]) / y) : 0), 0) / n) * 100;

  const logLikelihood = (-n / 2) * (Math.log((2 * Math.PI * ssRes) / n) + 1);
  const aic = 2 * numParams - 2 * logLikelihood;
  const bic = numParams * Math.log(n) - 2 * logLikelihood;

  return { r2, adjustedR2, rmse, mae, mape, aic, bic };
}
单一指标无法全面反映模型质量。R² 高并不意味着模型正确——过拟合的高次多项式可以达到接近 1 的 R²，但在新数据上表现极差。因此需要结合多个指标综合判断。

交叉验证方法
交叉验证是评估模型泛化能力的标准方法。其核心思想是将数据分为互不重叠的子集，轮流使用不同子集作为测试集，其余作为训练集。


K 折交叉验证是最常用的方法。数据被随机分为 K 个等份，每次用 K-1 份训练、1 份测试，重复 K 次后取平均误差。K 的典型取值为 5 或 10。


interface CrossValidationResult {
  foldScores: number[];
  meanScore: number;
  stdScore: number;
  bestFoldIndex: number;
  worstFoldIndex: number;
}

function kFoldCrossValidation(
  data: { x: number[]; y: number }[],
  k: number,
  trainAndPredict: (train: { x: number[]; y: number }[], test: { x: number[]; y: number }[]) => number[],
): CrossValidationResult {
  const n = data.length;
  const shuffled = [...data].sort(() => Math.random() - 0.5);
  const foldSize = Math.floor(n / k);
  const foldScores: number[] = [];

  for (let i = 0; i < k; i++) {
    const testStart = i * foldSize;
    const testEnd = i === k - 1 ? n : (i + 1) * foldSize;
    const testSet = shuffled.slice(testStart, testEnd);
    const trainSet = [...shuffled.slice(0, testStart), ...shuffled.slice(testEnd)];

    const predictions = trainAndPredict(trainSet, testSet);
    const mse = testSet.reduce((sum, point, j) => sum + (point.y - predictions[j]) ** 2, 0) / testSet.length;
    foldScores.push(Math.sqrt(mse));
  }

  const meanScore = foldScores.reduce((a, b) => a + b, 0) / k;
  const stdScore = Math.sqrt(foldScores.reduce((sum, s) => sum + (s - meanScore) ** 2, 0) / k);

  return {
    foldScores,
    meanScore,
    stdScore,
    bestFoldIndex: foldScores.indexOf(Math.min(...foldScores)),
    worstFoldIndex: foldScores.indexOf(Math.max(...foldScores)),
  };
}
留一法（LOO）是 K-Fold 的极端情况（K=N），每次只留一个样本作为测试集。LOO 的偏差最小，但方差最大且计算成本极高。时间序列数据不能使用标准 K-Fold，因为随机打乱会破坏时间顺序，应使用滚动窗口交叉验证。

残差分析
残差分析是模型诊断的核心工具。残差 = 观测值 - 预测值。一个好的模型，其残差应满足四个条件：零均值（无系统偏差）、等方差（方差不随预测值变化）、独立性（残差间无相关）、正态性（近似正态分布）。


interface ResidualDiagnostics {
  mean: number;
  std: number;
  isZeroMean: boolean;
  isHomoscedastic: boolean;
  isIndependent: boolean;
  isNormal: boolean;
  diagnosis: string;
}

function diagnoseResiduals(residuals: number[], predicted: number[], alpha: number = 0.05): ResidualDiagnostics {
  const n = residuals.length;
  const mean = residuals.reduce((a, b) => a + b, 0) / n;
  const std = Math.sqrt(residuals.reduce((sum, r) => sum + (r - mean) ** 2, 0) / (n - 1));

  const tStat = (mean / std) * Math.sqrt(n);
  const isZeroMean = Math.abs(tStat) < 1.96;

  const mid = Math.floor(n / 2);
  const sorted = predicted.map((p, i) => ({ p, r: residuals[i] })).sort((a, b) => a.p - b.p);
  const var1 = sorted.slice(0, mid).reduce((s, v) => s + v.r ** 2, 0) / mid;
  const var2 = sorted.slice(mid).reduce((s, v) => s + v.r ** 2, 0) / (n - mid);
  const fStat = var1 > var2 ? var1 / var2 : var2 / var1;
  const isHomoscedastic = fStat < 2.0;

  let concordant = 0;
  let discordant = 0;
  for (let i = 0; i < n - 1; i++) {
    for (let j = i + 1; j < n; j++) {
      const sign = (residuals[i] - residuals[j]) * (i - j);
      if (sign > 0) concordant++;
      else if (sign < 0) discordant++;
    }
  }
  const dw =
    residuals.slice(1).reduce((s, r, i) => s + (r - residuals[i]) ** 2, 0) / residuals.reduce((s, r) => s + r ** 2, 0);
  const isIndependent = dw > 1.5 && dw < 2.5;

  const sortedRes = [...residuals].sort((a, b) => a - b);
  let isNormal = true;
  for (let i = 0; i < n; i++) {
    const expected = mean + std * quantileNormal((i + 0.5) / n);
    if (Math.abs(sortedRes[i] - expected) > 3 * std) {
      isNormal = false;
      break;
    }
  }

  const issues: string[] = [];
  if (!isZeroMean) issues.push('存在系统偏差');
  if (!isHomoscedastic) issues.push('异方差性');
  if (!isIndependent) issues.push('残差自相关');
  if (!isNormal) issues.push('非正态分布');

  return {
    mean,
    std,
    isZeroMean,
    isHomoscedastic,
    isIndependent,
    isNormal,
    diagnosis: issues.length === 0 ? '残差诊断通过' : `问题: ${issues.join(', ')}`,
  };
}

function quantileNormal(p: number): number {
  const a1 = -3.969683028665376e1;
  const a2 = 2.209460984245205e2;
  const a3 = -2.759285104469687e2;
  const a4 = 1.38357751867269e2;
  const a5 = -3.066479806614716e1;
  const a6 = 2.506628277459239;
  const t = p < 0.5 ? Math.sqrt(-2 * Math.log(p)) : Math.sqrt(-2 * Math.log(1 - p));
  const c = ((((a1 * (1 / t) + a2) * (1 / t) + a3) * (1 / t) + a4) * (1 / t) + a5) * (1 / t) + a6;
  return p < 0.5 ? -t + c / (1 + t * 0.3193815) : t - c / (1 + t * 0.3193815);
}

模型选择准则
当多个候选模型都能拟合数据时，需要模型选择准则来决定最终采用哪个模型。核心原则是奥卡姆剃刀——在同等拟合质量下，选择最简单的模型。


AIC（赤池信息准则）和 BIC（贝叶斯信息准则）是两个最广泛使用的模型选择准则。它们都在拟合优度和模型复杂度之间取平衡，区别在于对复杂度的惩罚力度不同。


interface ModelCandidate {
  name: string;
  numParams: number;
  logLikelihood: number;
  aic: number;
  bic: number;
  cvScore: number;
}

function compareModels(
  candidates: {
    name: string;
    numParams: number;
    residuals: number[];
  }[],
  n: number,
): ModelCandidate[] {
  return candidates
    .map((c) => {
      const ssRes = c.residuals.reduce((sum, r) => sum + r ** 2, 0);
      const sigmaSquared = ssRes / n;
      const logLik = (-n / 2) * (Math.log(2 * Math.PI * sigmaSquared) + 1);
      const aic = 2 * c.numParams - 2 * logLik;
      const bic = c.numParams * Math.log(n) - 2 * logLik;

      return {
        name: c.name,
        numParams: c.numParams,
        logLikelihood: logLik,
        aic,
        bic,
        cvScore: Math.sqrt(ssRes / n),
      };
    })
    .sort((a, b) => a.aic - b.aic);
}
小结
    

  • 验证（模型是否正确）与校验（求解是否正确）是两个独立过程，都不可省略
    • 

  • R² 不是万能指标，需结合 AIC/BIC、交叉验证等多维度评估
    • 

  • K-Fold 交叉验证（K=10）是评估泛化能力的标准方法
    • 

  • 时间序列数据需用滚动窗口交叉验证，不能随机打乱
    • 

  • 残差分析检查四个条件：零均值、等方差、独立性、正态性
    • 

  • 残差的系统性模式（U形、漏斗形、周期性）指向具体的模型改进方向
    • 

  • 模型选择遵循奥卡姆剃刀：同等拟合质量下选最简单的模型
    • 

  • AIC 和 BIC 是平衡拟合与复杂度的标准准则，BIC 对参数惩罚更重
