模型分类

核心概念

数学模型可以从多个维度进行分类，每个维度反映了问题的不同特征。理解模型分类的意义不在于记忆标签，而在于根据问题特性选择最合适的数学框架。四个核心分类维度是：确定性与随机性、连续与离散、静态与动态、经验与机理。

这四个维度并非相互排斥，而是可以自由组合。例如，SIR 传染病模型是"确定性 + 连续 + 动态 + 机理"的组合；而基于历史数据的股价预测模型可能是"随机 + 离散 + 动态 + 经验"的组合。

确定性模型与随机模型
确定性模型假设系统的演化完全由初始条件和参数决定，相同输入总是产生相同输出。这类模型适用于噪声影响可忽略或被平均效应消除的场景。经典力学方程、化学反应方程、热传导方程都是确定性模型的典型代表。


随机模型承认系统中存在不可消除的随机性，使用概率分布描述系统状态。随机模型的输出不是单一值，而是概率分布或置信区间。在金融市场、量子物理、生态系统等领域，随机模型往往比确定性模型更贴近现实。


interface DeterministicModel {
  kind: 'deterministic';
  evolve: (state: number[], params: number[], dt: number) => number[];
}

interface StochasticModel {
  kind: 'stochastic';
  evolve: (state: number[], params: number[], dt: number) => number[];
  noise: (state: number[], dt: number) => number[];
}

function simulateDeterministic(
  model: DeterministicModel,
  initial: number[],
  params: number[],
  dt: number,
  steps: number,
): number[][] {
  const trajectory: number[][] = [initial];
  let state = [...initial];
  for (let i = 0; i < steps; i++) {
    state = model.evolve(state, params, dt);
    trajectory.push([...state]);
  }
  return trajectory;
}

function simulateStochastic(
  model: StochasticModel,
  initial: number[],
  params: number[],
  dt: number,
  steps: number,
  trials: number,
): number[][][] {
  const results: number[][][] = [];
  for (let t = 0; t < trials; t++) {
    const trajectory: number[][] = [initial];
    let state = [...initial];
    for (let i = 0; i < steps; i++) {
      const drift = model.evolve(state, params, dt);
      const diffusion = model.noise(state, dt);
      state = drift.map((d, j) => d + diffusion[j] * Math.sqrt(dt));
      trajectory.push([...state]);
    }
    results.push(trajectory);
  }
  return results;
}
确定性与随机模型的选择并非非此即彼。实际建模中，常常先建立确定性模型获得基本理解，再引入随机扰动分析系统的鲁棒性。这种"确定性骨架 + 随机扰动"的策略在工程和科学计算中广泛使用。

连续模型与离散模型
连续模型使用连续数学工具（微积分、微分方程）描述系统，假设状态变量在连续域上取值。离散模型则使用离散数学工具（差分方程、图论、组合数学）描述系统，状态变量只取有限或可数个值。


选择连续还是离散模型取决于两个因素：状态变量的自然属性和建模目的。温度、浓度等物理量天然是连续的，但如果我们只关心"高温/低温"这样的分类决策，离散化处理反而更高效。相反，大规模人口虽然是离散个体的集合，但当数量足够大时，连续近似（如微分方程）更易分析。


function continuousLogistic(N: number, r: number, K: number, dt: number): number {
  const dN = r * N * (1 - N / K) * dt;
  return N + dN;
}

function discreteLogistic(N: number, r: number, K: number): number {
  return N + r * N * (1 - N / K);
}

function compareModels(N0: number, r: number, K: number, steps: number): { continuous: number[]; discrete: number[] } {
  const dt = 1.0;
  const continuous: number[] = [N0];
  const discrete: number[] = [N0];

  let Nc = N0;
  let Nd = N0;

  for (let i = 0; i < steps; i++) {
    Nc = continuousLogistic(Nc, r, K, dt);
    Nd = discreteLogistic(Nd, r, K);
    continuous.push(Nc);
    discrete.push(Nd);
  }

  return { continuous, discrete };
}
值得注意的是，离散模型有时能展现连续模型无法捕捉的行为。例如，离散 Logistic 映射在参数 r 超过某个临界值时会出现混沌行为，而对应的连续微分方程解则始终单调收敛。这提醒我们，离散化不仅仅是"近似"，它可能改变系统的本质动力学特征。


静态模型与动态模型
静态模型描述系统在某一时刻的平衡状态或稳态关系，不涉及时间演化。线性规划、回归分析、结构力学中的平衡方程都属于静态模型。动态模型则追踪系统状态随时间的变化，微分方程和差分方程是其核心工具。


动态模型的关键特征是系统具有"记忆"——当前状态依赖于历史状态。这种记忆可以是短期的（马尔可夫性，仅依赖前一时刻）或长期的（非马尔可夫过程）。

在实际建模中，静态分析常作为动态分析的前奏——先找到平衡点，再分析平衡点的稳定性。如果平衡点是稳定的，那么系统最终会趋近这个状态；如果不稳定，则需要完整的动态模拟来理解系统行为。


经验模型与机理模型
机理模型（白盒模型）基于已知的物理、化学或生物规律建立，每个方程都有明确的物理含义。牛顿第二定律 F=ma、化学反应速率方程、种群增长的 Logistic 方程都是机理模型。其优势在于可解释性强、外推能力好，但要求建模者对系统机理有深入理解。


经验模型（黑盒模型）不依赖系统机理，而是直接从数据中提取输入输出关系。多项式拟合、神经网络、支持向量机都属于经验模型。其优势在于灵活性高、不需要领域知识，但缺乏物理可解释性且外推风险大。


interface MechanisticModel {
  kind: 'mechanistic';
  name: string;
  equation: string;
  parameters: { name: string; physicalMeaning: string; unit: string }[];
  predict: (x: number, params: number[]) => number;
}

interface EmpiricalModel {
  kind: 'empirical';
  name: string;
  coefficients: number[];
  predict: (x: number) => number;
}

function polynomialFit(xData: number[], yData: number[], degree: number): EmpiricalModel {
  const n = xData.length;
  const matrix: number[][] = [];
  const rhs: number[] = [];

  for (let i = 0; i <= degree; i++) {
    matrix.push([]);
    rhs.push(0);
    for (let j = 0; j <= degree; j++) {
      let sum = 0;
      for (let k = 0; k < n; k++) {
        sum += Math.pow(xData[k], i + j);
      }
      matrix[i].push(sum);
    }
    for (let k = 0; k < n; k++) {
      rhs[i] += yData[k] * Math.pow(xData[k], i);
    }
  }

  const coefficients = solveLinearSystem(matrix, rhs);

  return {
    kind: 'empirical',
    name: `${degree}阶多项式拟合`,
    coefficients,
    predict: (x: number) => coefficients.reduce((sum, c, i) => sum + c * Math.pow(x, i), 0),
  };
}

function solveLinearSystem(A: number[][], b: number[]): number[] {
  const n = A.length;
  const aug = A.map((row, i) => [...row, b[i]]);
  for (let col = 0; col < n; col++) {
    let maxRow = col;
    for (let row = col + 1; row < n; row++) {
      if (Math.abs(aug[row][col]) > Math.abs(aug[maxRow][col])) maxRow = row;
    }
    [aug[col], aug[maxRow]] = [aug[maxRow], aug[col]];
    for (let row = col + 1; row < n; row++) {
      const factor = aug[row][col] / aug[col][col];
      for (let j = col; j <= n; j++) aug[row][j] -= factor * aug[col][j];
    }
  }
  const x = new Array(n).fill(0);
  for (let i = n - 1; i >= 0; i--) {
    x[i] = aug[i][n];
    for (let j = i + 1; j < n; j++) x[i] -= aug[i][j] * x[j];
    x[i] /= aug[i][i];
  }
  return x;
}
现代建模实践中，灰盒模型日益流行。灰盒模型结合机理知识和数据驱动方法：用物理方程确定模型结构，用数据拟合未知参数。例如，物理信息神经网络（PINN）将微分方程约束嵌入神经网络的损失函数中，兼具机理模型的可解释性和经验模型的灵活性。


小结
    

  • 模型分类的四个核心维度：确定性/随机、连续/离散、静态/动态、经验/机理
    • 

  • 分类维度可以自由组合，实际模型通常同时具有多个维度的标签
    • 

  • 确定性模型适合噪声可忽略的系统，随机模型适合存在本质随机性的系统
    • 

  • 连续与离散的选择取决于状态变量的自然属性和建模粒度需求
    • 

  • 离散化可能引入新的动力学行为（如混沌），并非简单的"近似"
    • 

  • 静态模型描述平衡态，动态模型追踪时间演化，二者常配合使用
    • 

  • 机理模型可解释性强但需要领域知识，经验模型灵活但外推风险大
    • 

  • 灰盒模型（机理结构 + 数据驱动参数）是当前建模的重要趋势
    •
