常微分方程模型

核心概念

常微分方程（ODE）是连续模型的基础工具，描述一个或多个未知函数关于单一自变量（通常是时间）的导数关系。ODE 模型的核心思想是用"变化率"刻画系统演化规律——知道当前状态和变化率，就能推算未来状态。

ODE 模型按阶数分为一阶和高阶，按线性性分为线性和非线性。一阶线性 ODE 有完整的解析理论，而非线性 ODE 通常需要数值方法求解。建模中最常见的形式是一阶 ODE 系统：dy/dt = f(t, y)。

增长与衰变模型
最基本的 ODE 模型是指数增长/衰变：dy/dt = ky。当 k > 0 时系统指数增长（如早期传染病传播），k < 0 时指数衰变（如放射性衰变）。解为 y(t) = y₀eᵏᵗ。


指数模型虽然简单，但揭示了一个关键概念——正反馈导致指数增长，负反馈导致指数衰变。理解这一点是分析更复杂系统的基础。


function exponentialGrowth(y0: number, k: number, t: number): number {
  return y0 * Math.exp(k * t);
}

function logisticGrowth(y0: number, r: number, K: number, t: number, dt: number): number[] {
  const steps = Math.ceil(t / dt);
  const trajectory: number[] = [y0];
  let y = y0;

  for (let i = 0; i < steps; i++) {
    const dydt = r * y * (1 - y / K);
    y += dydt * dt;
    trajectory.push(y);
  }

  return trajectory;
}

function newtonCooling(T0: number, Tenv: number, k: number, t: number): number {
  return Tenv + (T0 - Tenv) * Math.exp(-k * t);
}
Logistic 模型 dy/dt = ry(1 - y/K) 是指数增长的自然扩展。引入容量限制 K 后，增长率随着 y 接近 K 而逐渐降低，最终系统趋向稳定。这个模型在种群动力学、产品扩散、学习曲线等领域广泛应用。

SIR 传染病模型
SIR 模型是流行病学中的经典 ODE 系统模型，将人群分为三个仓室：易感者（S）、感染者（I）、康复者（R）。模型假设感染率与 S 和 I 的乘积成正比，康复率与 I 成正比。


模型方程为：dS/dt = -βSI，dI/dt = βSI - γI，dR/dt = γI。其中 β 是传染率，γ 是康复率，基本再生数 R₀ = β/γ 是判断疫情是否爆发的关键阈值。


interface SIRState {
  S: number;
  I: number;
  R: number;
  t: number;
}

interface SIRParams {
  beta: number;
  gamma: number;
  N: number;
}

function sirModel(initial: SIRState, params: SIRParams, tEnd: number, dt: number): SIRState[] {
  const trajectory: SIRState[] = [initial];
  let { S, I, R, t } = initial;
  const { beta, gamma, N } = params;

  while (t < tEnd) {
    const dSdt = (-beta * S * I) / N;
    const dIdt = (beta * S * I) / N - gamma * I;
    const dRdt = gamma * I;

    S += dSdt * dt;
    I += dIdt * dt;
    R += dRdt * dt;
    t += dt;

    trajectory.push({ S, I, R, t });
  }

  return trajectory;
}

function computeR0(beta: number, gamma: number): number {
  return beta / gamma;
}

function peakInfection(S0: number, I0: number, R0Value: number, N: number): number {
  return I0 + S0 - (N / R0Value) * (1 + Math.log((R0Value * S0) / N));
}

function herdImmunityThreshold(R0Value: number): number {
  return 1 - 1 / R0Value;
}
SIR 模型的关键洞察是：当 R₀ > 1 时疫情爆发，当 R₀ < 1 时疫情自然消退。群体免疫阈值为 1 - 1/R₀，这意味着只要足够比例的人群具有免疫力，疫情就无法持续传播。SIR 模型可以扩展为 SEIR（加入潜伏期）、SIS（感染后不产生永久免疫）等变体。


数值求解方法
当 ODE 没有解析解时，数值方法是唯一的求解途径。核心思想是将连续的微分方程离散化为递推关系。


Euler 法是最简单的数值方法：yₙ₊₁ = yₙ + h·f(tₙ, yₙ)，其中 h 是时间步长。Euler 法是一阶方法，局部截断误差为 O(h²)，全局误差为 O(h)。它简单直观但精度有限，大步长下容易数值不稳定。


**四阶 Runge-Kutta 法（RK4）**是实际应用中最常用的方法，通过在每个时间步内计算四个斜率的加权平均来提高精度，全局误差为 O(h⁴)。


type ODEFunction = (t: number, y: number[]) => number[];

function eulerMethod(
  f: ODEFunction,
  y0: number[],
  t0: number,
  tEnd: number,
  h: number,
): { t: number[]; y: number[][] } {
  const ts: number[] = [t0];
  const ys: number[][] = [y0];
  let t = t0;
  let y = [...y0];

  while (t < tEnd) {
    const dy = f(t, y);
    y = y.map((yi, i) => yi + h * dy[i]);
    t += h;
    ts.push(t);
    ys.push([...y]);
  }

  return { t: ts, y: ys };
}

function rk4Method(f: ODEFunction, y0: number[], t0: number, tEnd: number, h: number): { t: number[]; y: number[][] } {
  const ts: number[] = [t0];
  const ys: number[][] = [y0];
  let t = t0;
  let y = [...y0];
  const n = y0.length;

  while (t < tEnd) {
    const k1 = f(t, y);
    const k2 = f(
      t + h / 2,
      y.map((yi, i) => yi + (h / 2) * k1[i]),
    );
    const k3 = f(
      t + h / 2,
      y.map((yi, i) => yi + (h / 2) * k2[i]),
    );
    const k4 = f(
      t + h,
      y.map((yi, i) => yi + h * k3[i]),
    );

    y = y.map((yi, i) => yi + (h / 6) * (k1[i] + 2 * k2[i] + 2 * k3[i] + k4[i]));
    t += h;
    ts.push(t);
    ys.push([...y]);
  }

  return { t: ts, y: ys };
}

function adaptiveRK45(
  f: ODEFunction,
  y0: number[],
  t0: number,
  tEnd: number,
  tol: number = 1e-6,
): { t: number[]; y: number[][] } {
  const ts: number[] = [t0];
  const ys: number[][] = [y0];
  let t = t0;
  let y = [...y0];
  let h = (tEnd - t0) / 100;

  while (t < tEnd) {
    if (t + h > tEnd) h = tEnd - t;

    const fullStep = rk4Step(f, t, y, h);
    const halfStep1 = rk4Step(f, t, y, h / 2);
    const halfStep2 = rk4Step(f, t + h / 2, halfStep1, h / 2);

    const error = Math.max(...y.map((_, i) => Math.abs(fullStep[i] - halfStep2[i])));

    if (error <= tol) {
      y = halfStep2;
      t += h;
      ts.push(t);
      ys.push([...y]);
    }

    const scale = error > 0 ? 0.9 * Math.pow(tol / error, 0.2) : 2.0;
    h *= Math.min(Math.max(scale, 0.1), 4.0);
  }

  return { t: ts, y: ys };
}

function rk4Step(f: ODEFunction, t: number, y: number[], h: number): number[] {
  const k1 = f(t, y);
  const k2 = f(
    t + h / 2,
    y.map((yi, i) => yi + (h / 2) * k1[i]),
  );
  const k3 = f(
    t + h / 2,
    y.map((yi, i) => yi + (h / 2) * k2[i]),
  );
  const k4 = f(
    t + h,
    y.map((yi, i) => yi + h * k3[i]),
  );
  return y.map((yi, i) => yi + (h / 6) * (k1[i] + 2 * k2[i] + 2 * k3[i] + k4[i]));
}

小结
    

  • ODE 模型通过变化率描述系统演化，是连续模型的核心工具
    • 

  • 指数增长/衰变模型揭示正反馈和负反馈的基本动力学行为
    • 

  • Logistic 模型引入容量限制，产生 S 型增长曲线
    • 

  • SIR 模型是流行病学的经典框架，R₀ 是判断疫情爆发的关键阈值
    • 

  • Euler 法简单但精度低（一阶），RK4 是实际应用的标准选择（四阶）
    • 

  • 自适应步长方法根据局部误差自动调整步长，兼顾精度和效率
    • 

  • 数值方法的选择取决于精度要求、计算预算和方程的刚性程度
    •
