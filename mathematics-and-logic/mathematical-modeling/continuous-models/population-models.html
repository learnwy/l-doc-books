种群模型

核心概念

种群模型用数学方程描述生物种群数量随时间的变化规律。从最简单的指数增长到复杂的多物种竞争，种群模型展示了如何从基本假设出发，逐步构建能解释真实生态现象的数学框架。这些模型的思想远超生物学范畴——市场竞争、技术扩散、语言演化都遵循类似的动力学机制。

种群模型的核心建模思想是"率的平衡"：种群变化率 = 出生率 - 死亡率 + 迁入率 - 迁出率。不同假设条件下，这些率的函数形式不同，产生截然不同的动力学行为。

Malthus 模型与 Logistic 模型
Malthus 模型 dN/dt = rN 是最简单的种群模型，假设人均增长率 r 为常数。当 r > 0 时种群指数增长，r < 0 时趋于灭绝。这个模型在资源充裕的短期内是合理的，但长期必然失效——没有什么可以无限增长。


Logistic 模型 dN/dt = rN(1 - N/K) 通过引入环境容量 K 修正了这个缺陷。当种群数量 N 接近 K 时，增长率趋于零。模型展示了经典的 S 型增长曲线，在 N = K/2 处增长速度最快。


interface PopulationTrajectory {
  time: number[];
  population: number[];
  growthRate: number[];
}

function malthusModel(N0: number, r: number, tEnd: number, dt: number): PopulationTrajectory {
  const time: number[] = [];
  const population: number[] = [];
  const growthRate: number[] = [];
  let N = N0;

  for (let t = 0; t <= tEnd; t += dt) {
    time.push(t);
    population.push(N);
    growthRate.push(r * N);
    N += r * N * dt;
  }

  return { time, population, growthRate };
}

function logisticModel(N0: number, r: number, K: number, tEnd: number, dt: number): PopulationTrajectory {
  const time: number[] = [];
  const population: number[] = [];
  const growthRate: number[] = [];
  let N = N0;

  for (let t = 0; t <= tEnd; t += dt) {
    time.push(t);
    population.push(N);
    const dNdt = r * N * (1 - N / K);
    growthRate.push(dNdt);
    N += dNdt * dt;
  }

  return { time, population, growthRate };
}

function logisticAnalytical(N0: number, r: number, K: number, t: number): number {
  return K / (1 + ((K - N0) / N0) * Math.exp(-r * t));
}

function alleeEffect(N0: number, r: number, K: number, A: number, tEnd: number, dt: number): PopulationTrajectory {
  const time: number[] = [];
  const population: number[] = [];
  const growthRate: number[] = [];
  let N = N0;

  for (let t = 0; t <= tEnd; t += dt) {
    time.push(t);
    population.push(N);
    const dNdt = r * N * (1 - N / K) * (N / A - 1);
    growthRate.push(dNdt);
    N += dNdt * dt;
    if (N < 0) N = 0;
  }

  return { time, population, growthRate };
}
Allee 效应模型 dN/dt = rN(1 - N/K)(N/A - 1) 引入了最小可存活种群大小 A。当种群数量低于 A 时，由于难以找到配偶、合作效率下降等原因，种群增长率为负，导致灭绝。这个模型在濒危物种保护中有重要应用，因为它揭示了存在灭绝的临界阈值。


Lotka-Volterra 捕食-猎物模型
Lotka-Volterra 模型是第一个描述两个物种相互作用的数学模型。猎物（x）在没有捕食者时指数增长，捕食者（y）在没有猎物时指数衰亡。两者的相互作用通过 xy 项耦合。


方程组：dx/dt = αx - βxy，dy/dt = δxy - γy。其中 α 是猎物增长率，β 是捕食效率，δ 是捕食者从猎物获得的增长效率，γ 是捕食者自然死亡率。


interface PredatorPreyState {
  t: number;
  prey: number;
  predator: number;
}

interface LotkaVolterraParams {
  alpha: number;
  beta: number;
  delta: number;
  gamma: number;
}

function lotkaVolterra(
  x0: number,
  y0: number,
  params: LotkaVolterraParams,
  tEnd: number,
  dt: number,
): PredatorPreyState[] {
  const { alpha, beta, delta, gamma } = params;
  const trajectory: PredatorPreyState[] = [];
  let x = x0;
  let y = y0;

  for (let t = 0; t <= tEnd; t += dt) {
    trajectory.push({ t, prey: x, predator: y });

    const k1x = alpha * x - beta * x * y;
    const k1y = delta * x * y - gamma * y;

    const x2 = x + (dt / 2) * k1x;
    const y2 = y + (dt / 2) * k1y;
    const k2x = alpha * x2 - beta * x2 * y2;
    const k2y = delta * x2 * y2 - gamma * y2;

    const x3 = x + (dt / 2) * k2x;
    const y3 = y + (dt / 2) * k2y;
    const k3x = alpha * x3 - beta * x3 * y3;
    const k3y = delta * x3 * y3 - gamma * y3;

    const x4 = x + dt * k3x;
    const y4 = y + dt * k3y;
    const k4x = alpha * x4 - beta * x4 * y4;
    const k4y = delta * x4 * y4 - gamma * y4;

    x += (dt / 6) * (k1x + 2 * k2x + 2 * k3x + k4x);
    y += (dt / 6) * (k1y + 2 * k2y + 2 * k3y + k4y);
  }

  return trajectory;
}

function lvEquilibria(params: LotkaVolterraParams): { trivial: [number, number]; coexistence: [number, number] } {
  const { alpha, beta, delta, gamma } = params;
  return {
    trivial: [0, 0],
    coexistence: [gamma / delta, alpha / beta],
  };
}
Lotka-Volterra 模型的经典预测是猎物和捕食者数量呈周期性振荡，且捕食者的峰值滞后于猎物。相平面上，轨迹形成闭合曲线围绕共存平衡点。然而，这些闭合轨道是结构不稳定的——任何微小的扰动都会使系统跳到不同的轨道上。


竞争模型与共存条件
当两个物种竞争相同的资源时，Lotka-Volterra 竞争模型描述了可能的结局：竞争排斥（一方胜出）或稳定共存。


方程组：dN₁/dt = r₁N₁(1 - N₁/K₁ - α₁₂N₂/K₁)，dN₂/dt = r₂N₂(1 - N₂/K₂ - α₂₁N₁/K₂)。其中 αᵢⱼ 是物种 j 对物种 i 的竞争系数。


interface CompetitionParams {
  r1: number;
  r2: number;
  K1: number;
  K2: number;
  alpha12: number;
  alpha21: number;
}

function competitionModel(
  N1_0: number,
  N2_0: number,
  params: CompetitionParams,
  tEnd: number,
  dt: number,
): { t: number; N1: number; N2: number }[] {
  const { r1, r2, K1, K2, alpha12, alpha21 } = params;
  const trajectory: { t: number; N1: number; N2: number }[] = [];
  let N1 = N1_0;
  let N2 = N2_0;

  for (let t = 0; t <= tEnd; t += dt) {
    trajectory.push({ t, N1, N2 });
    const dN1 = r1 * N1 * (1 - N1 / K1 - (alpha12 * N2) / K1);
    const dN2 = r2 * N2 * (1 - N2 / K2 - (alpha21 * N1) / K2);
    N1 += dN1 * dt;
    N2 += dN2 * dt;
    if (N1 < 0) N1 = 0;
    if (N2 < 0) N2 = 0;
  }

  return trajectory;
}

function analyzeCompetitionOutcome(params: CompetitionParams): string {
  const { K1, K2, alpha12, alpha21 } = params;
  const cond1 = K1 > alpha12 * K2;
  const cond2 = K2 > alpha21 * K1;

  if (cond1 && cond2) return '稳定共存：两物种种内竞争强于种间竞争';
  if (!cond1 && !cond2) return '双稳态：初始条件决定谁胜出';
  if (cond1 && !cond2) return '物种1获胜：物种1竞争优势';
  return '物种2获胜：物种2竞争优势';
}
共存条件的核心洞察是：当每个物种对自己的抑制效应强于对竞争者的抑制效应时（即种内竞争 > 种间竞争），两个物种可以稳定共存。这等价于两个零增长等值线（nullclines）以正确的方式相交。

模型扩展与现实应用
基本种群模型可以通过多种方式扩展以更贴近现实：加入时间延迟（妊娠期、成熟期）、年龄结构（Leslie 矩阵模型）、空间分布（反应-扩散方程）、随机性（种群的随机波动）。


interface LeslieMatrix {
  fecundity: number[];
  survival: number[];
}

function leslieProjection(matrix: LeslieMatrix, initial: number[], steps: number): number[][] {
  const n = matrix.fecundity.length;
  const trajectory: number[][] = [initial];
  let current = [...initial];

  for (let t = 0; t < steps; t++) {
    const next = new Array(n).fill(0);
    next[0] = matrix.fecundity.reduce((sum, f, i) => sum + f * current[i], 0);
    for (let i = 1; i < n; i++) {
      next[i] = matrix.survival[i - 1] * current[i - 1];
    }
    current = next;
    trajectory.push([...current]);
  }

  return trajectory;
}

function delayedLogistic(
  N0: number,
  r: number,
  K: number,
  tau: number,
  tEnd: number,
  dt: number,
): PopulationTrajectory {
  const time: number[] = [];
  const population: number[] = [];
  const growthRate: number[] = [];
  const delaySteps = Math.round(tau / dt);
  const history = new Array(delaySteps + 1).fill(N0);
  let N = N0;

  for (let t = 0; t <= tEnd; t += dt) {
    time.push(t);
    population.push(N);
    const Ndelayed = history[0];
    const dNdt = r * N * (1 - Ndelayed / K);
    growthRate.push(dNdt);
    N += dNdt * dt;
    if (N < 0) N = 0;
    history.push(N);
    history.shift();
  }

  return { time, population, growthRate };
}
延迟效应可以显著改变系统行为。当延迟时间 τ 足够大时（rτ > π/2），Logistic 模型的稳定平衡点可能变得不稳定，产生周期振荡甚至混沌。这解释了为什么某些种群会出现规律性的数量波动。


小结
    

  • Malthus 模型描述无限制指数增长，是种群建模的起点但长期不现实
    • 

  • Logistic 模型通过环境容量 K 引入自我调节，产生 S 型增长曲线
    • 

  • Allee 效应模型揭示了低密度种群面临的灭绝风险，存在最小可存活阈值
    • 

  • Lotka-Volterra 捕食模型产生猎物-捕食者的周期振荡，捕食者峰值滞后于猎物
    • 

  • 竞争共存的条件是种内竞争强于种间竞争，否则竞争排斥占主导
    • 

  • Leslie 矩阵模型引入年龄结构，适用于具有复杂生命史的种群
    • 

  • 时间延迟可以将稳定平衡转变为振荡甚至混沌
    • 

  • 种群模型的思想广泛应用于市场竞争、技术扩散、流行病学等非生物学领域
    •
