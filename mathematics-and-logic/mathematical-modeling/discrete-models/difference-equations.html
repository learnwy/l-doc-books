差分方程

核心概念

差分方程是离散时间系统的基本建模工具，描述序列中相邻项之间的递推关系。如果微分方程刻画的是连续变化率，差分方程刻画的则是离散时间步之间的状态转移。许多现实系统——年度人口统计、月度财务数据、迭代算法的收敛行为——天然以离散时间运作，差分方程是它们的原生数学语言。

差分方程与微分方程有深层对应关系，但也有本质区别。差分方程的解是离散序列而非连续函数，且非线性差分方程可以在低维系统中产生混沌行为——这是连续 ODE 无法做到的（至少需要三维才可能出现混沌）。

线性递推关系
线性差分方程的一般形式为 aₖxₙ₊ₖ + aₖ₋₁xₙ₊ₖ₋₁ + ... + a₀xₙ = f(n)。当 f(n) = 0 时为齐次方程，其求解方法是特征方程法：将 xₙ = rⁿ 代入方程，得到关于 r 的多项式方程。


最经典的例子是 Fibonacci 数列 xₙ₊₂ = xₙ₊₁ + xₙ，其特征方程 r² - r - 1 = 0 的两个根 φ = (1+√5)/2（黄金比例）和 ψ = (1-√5)/2 给出了通解 xₙ = Aφⁿ + Bψⁿ。


interface LinearRecurrence {
  coefficients: number[];
  initialValues: number[];
}

function solveByIteration(recurrence: LinearRecurrence, steps: number): number[] {
  const { coefficients, initialValues } = recurrence;
  const order = initialValues.length;
  const sequence = [...initialValues];

  for (let n = order; n < steps; n++) {
    let value = 0;
    for (let k = 0; k < order; k++) {
      value += coefficients[k] * sequence[n - 1 - k];
    }
    sequence.push(value);
  }

  return sequence;
}

function characteristicRoots(coefficients: number[]): {
  real: number;
  imag: number;
}[] {
  if (coefficients.length === 2) {
    const [a, b] = coefficients;
    const disc = a * a + 4 * b;
    if (disc >= 0) {
      return [
        { real: (a + Math.sqrt(disc)) / 2, imag: 0 },
        { real: (a - Math.sqrt(disc)) / 2, imag: 0 },
      ];
    }
    return [
      { real: a / 2, imag: Math.sqrt(-disc) / 2 },
      { real: a / 2, imag: -Math.sqrt(-disc) / 2 },
    ];
  }
  return companionMatrixEigenvalues(coefficients);
}

function companionMatrixEigenvalues(coefficients: number[]): { real: number; imag: number }[] {
  const n = coefficients.length;
  let roots: { real: number; imag: number }[] = [];
  for (let i = 0; i < n; i++) {
    const angle = (2 * Math.PI * i) / n;
    roots.push({
      real: Math.pow(Math.abs(coefficients[0]), 1 / n) * Math.cos(angle),
      imag: Math.pow(Math.abs(coefficients[0]), 1 / n) * Math.sin(angle),
    });
  }
  return roots;
}

function fibonacci(n: number): number {
  const phi = (1 + Math.sqrt(5)) / 2;
  const psi = (1 - Math.sqrt(5)) / 2;
  return Math.round((Math.pow(phi, n) - Math.pow(psi, n)) / Math.sqrt(5));
}
特征根的模（绝对值）决定了解的长期行为：所有特征根模小于 1 时解趋向零（稳定），存在模大于 1 的特征根时解发散（不稳定），模等于 1 时解有界振荡。


| 特征根类型  | 条件 | 解的行为 | 稳定性   |
| ----------- | ---- | -------- | -------- | ------------ | ------ |
| 实数，      | r    | < 1      | 衰减     | 指数衰减到零 | 稳定   |
| 实数，      | r    | > 1      | 增长     | 指数增长     | 不稳定 |
| 实数，r < 0 | 振荡 | 交替正负 | 取决于   | r            |        |
| 复数，      | r    | < 1      | 螺旋衰减 | 阻尼振荡     | 稳定   |
| 复数，      | r    | = 1      | 等幅振荡 | 周期行为     | 临界   |
| 复数，      | r    | > 1      | 螺旋增长 | 增幅振荡     | 不稳定 |


非齐次差分方程
非齐次差分方程 xₙ₊ₖ + aₖ₋₁xₙ₊ₖ₋₁ + ... + a₀xₙ = f(n) 的通解 = 齐次通解 + 特解。特解的形式取决于驱动函数 f(n) 的类型。


interface NonhomogeneousSolution {
  homogeneousPart: (n: number) => number;
  particularPart: (n: number) => number;
  totalSolution: (n: number) => number;
}

function solveFirstOrderLinear(a: number, forcing: (n: number) => number, x0: number, steps: number): number[] {
  const sequence: number[] = [x0];
  for (let n = 0; n < steps; n++) {
    sequence.push(a * sequence[n] + forcing(n));
  }
  return sequence;
}

function annuityModel(
  principal: number,
  monthlyRate: number,
  monthlyPayment: number,
  months: number,
): { balance: number[]; totalInterest: number } {
  const balance: number[] = [principal];
  let totalInterest = 0;

  for (let n = 0; n < months; n++) {
    const interest = balance[n] * monthlyRate;
    totalInterest += interest;
    const newBalance = balance[n] * (1 + monthlyRate) - monthlyPayment;
    balance.push(Math.max(0, newBalance));
    if (newBalance <= 0) break;
  }

  return { balance, totalInterest };
}

function computeMonthlyPayment(principal: number, annualRate: number, years: number): number {
  const r = annualRate / 12;
  const n = years * 12;
  return (principal * r * Math.pow(1 + r, n)) / (Math.pow(1 + r, n) - 1);
}
贷款还款模型是非齐次差分方程的经典应用。设第 n 月的欠款为 Bₙ，月利率为 r，月还款额为 M，则 Bₙ₊₁ = (1+r)Bₙ - M。这是一阶线性非齐次差分方程，其解揭示了等额还款策略下本金和利息的动态变化。


Z 变换基础
Z 变换是差分方程的系统化求解工具，类似于 Laplace 变换之于微分方程。序列 {xₙ} 的 Z 变换定义为 X(z) = Σ xₙz⁻ⁿ。Z 变换将差分方程的递推关系转化为代数方程，大大简化了求解过程。

function transferFunction(
  numerator: number[],
  denominator: number[],
): (z: { real: number; imag: number }) => { real: number; imag: number } {
  return (z) => {
    let numReal = 0;
    let numImag = 0;
    let denReal = 0;
    let denImag = 0;

    for (let i = 0; i < numerator.length; i++) {
      const power = numerator.length - 1 - i;
      const zPow = complexPow(z, power);
      numReal += numerator[i] * zPow.real;
      numImag += numerator[i] * zPow.imag;
    }

    for (let i = 0; i < denominator.length; i++) {
      const power = denominator.length - 1 - i;
      const zPow = complexPow(z, power);
      denReal += denominator[i] * zPow.real;
      denImag += denominator[i] * zPow.imag;
    }

    const denMag = denReal * denReal + denImag * denImag;
    return {
      real: (numReal * denReal + numImag * denImag) / denMag,
      imag: (numImag * denReal - numReal * denImag) / denMag,
    };
  };
}

function complexPow(z: { real: number; imag: number }, n: number): { real: number; imag: number } {
  if (n === 0) return { real: 1, imag: 0 };
  let result = { real: 1, imag: 0 };
  for (let i = 0; i < n; i++) {
    const newReal = result.real * z.real - result.imag * z.imag;
    const newImag = result.real * z.imag + result.imag * z.real;
    result = { real: newReal, imag: newImag };
  }
  return result;
}
Z 变换在数字信号处理和控制系统中至关重要。系统的传递函数 H(z) = Y(z)/X(z) 完全描述了离散线性系统的输入输出关系，其极点位置决定了系统的稳定性——所有极点在单位圆内时系统稳定。

小结
    

  • 差分方程描述离散时间系统的状态转移，是序列数据建模的原生工具
    • 

  • 线性差分方程通过特征方程求解，特征根的模决定解的稳定性
    • 

  • Fibonacci 数列是二阶线性递推的经典例子，其通解涉及黄金比例
    • 

  • 非齐次方程的通解 = 齐次通解 + 特解，贷款还款是典型应用
    • 

  • Z 变换将时域递推关系转化为 z 域代数方程，是系统化求解工具
    • 

  • 传递函数的极点位置决定离散系统的稳定性——极点必须在单位圆内
    • 

  • 差分方程的一维非线性版本可以产生混沌，这是连续 ODE 需要至少三维才能实现的
    • 

  • 在数字信号处理和金融建模中，差分方程比微分方程更自然
    •
