元胞自动机

核心概念

元胞自动机（Cellular Automata, CA）是一类离散的动态系统模型，由规则排列的细胞格子组成，每个细胞在每个时间步根据自身状态和邻居状态按照确定性规则更新。尽管个体规则极其简单，元胞自动机能涌现出令人惊叹的复杂集体行为——从自组织图案到通用计算，展示了"简单规则产生复杂行为"的深刻原理。

元胞自动机的四个组成要素：格子（通常是一维或二维规则网格）、状态集合（每个细胞可取的有限状态）、邻域（影响细胞更新的周围细胞集合）、转移规则（根据当前状态和邻域状态确定下一时刻状态）。

Wolfram 基本规则
Stephen Wolfram 系统地研究了所有 256 种一维二态最近邻元胞自动机（称为"基本规则"）。每种规则由一个 8 位二进制数编码，编号 0-255。Wolfram 将这些规则分为四类，对应从简单到复杂的不同行为。


type CellState = 0 | 1;

interface WolframCA {
  rule: number;
  width: number;
  boundary: 'periodic' | 'fixed';
}

function getRuleTable(ruleNumber: number): Map<string, CellState> {
  const table = new Map<string, CellState>();
  const patterns = ['111', '110', '101', '100', '011', '010', '001', '000'];

  for (let i = 0; i < 8; i++) {
    table.set(patterns[i], ((ruleNumber >> (7 - i)) & 1) as CellState);
  }

  return table;
}

function stepWolfram(
  state: CellState[],
  ruleTable: Map<string, CellState>,
  boundary: 'periodic' | 'fixed',
): CellState[] {
  const n = state.length;
  const next: CellState[] = new Array(n).fill(0);

  for (let i = 0; i < n; i++) {
    let left: CellState;
    let right: CellState;

    if (boundary === 'periodic') {
      left = state[(i - 1 + n) % n];
      right = state[(i + 1) % n];
    } else {
      left = i > 0 ? state[i - 1] : 0;
      right = i < n - 1 ? state[i + 1] : 0;
    }

    const pattern = `${left}${state[i]}${right}`;
    next[i] = ruleTable.get(pattern) ?? 0;
  }

  return next;
}

function simulateWolfram(ca: WolframCA, initial: CellState[], steps: number): CellState[][] {
  const ruleTable = getRuleTable(ca.rule);
  const history: CellState[][] = [initial];
  let current = [...initial];

  for (let t = 0; t < steps; t++) {
    current = stepWolfram(current, ruleTable, ca.boundary);
    history.push([...current]);
  }

  return history;
}

规则 110 被证明是图灵完备的——这意味着一个极其简单的一维元胞自动机规则在理论上可以执行任何计算。规则 30 则被用作随机数生成器（Wolfram Mathematica 曾使用）。


Conway 生命游戏
生命游戏（Game of Life）是最著名的二维元胞自动机，由 John Conway 于 1970 年提出。每个细胞有两种状态（存活/死亡），使用 Moore 邻域（8 个邻居），规则极其简单但能产生极其丰富的动态行为。


规则：存活细胞有 2 或 3 个存活邻居则继续存活，否则死亡（过疏或过密）；死亡细胞恰好有 3 个存活邻居则复活（繁殖）。


interface GameOfLife {
  width: number;
  height: number;
  grid: boolean[][];
}

function createGameOfLife(width: number, height: number): GameOfLife {
  return {
    width,
    height,
    grid: Array.from({ length: height }, () => new Array(width).fill(false)),
  };
}

function countNeighbors(gol: GameOfLife, x: number, y: number): number {
  let count = 0;
  for (let dy = -1; dy <= 1; dy++) {
    for (let dx = -1; dx <= 1; dx++) {
      if (dx === 0 && dy === 0) continue;
      const nx = (x + dx + gol.width) % gol.width;
      const ny = (y + dy + gol.height) % gol.height;
      if (gol.grid[ny][nx]) count++;
    }
  }
  return count;
}

function stepGameOfLife(gol: GameOfLife): GameOfLife {
  const next = createGameOfLife(gol.width, gol.height);

  for (let y = 0; y < gol.height; y++) {
    for (let x = 0; x < gol.width; x++) {
      const neighbors = countNeighbors(gol, x, y);
      if (gol.grid[y][x]) {
        next.grid[y][x] = neighbors === 2 || neighbors === 3;
      } else {
        next.grid[y][x] = neighbors === 3;
      }
    }
  }

  return next;
}

function simulateLife(initial: GameOfLife, steps: number): { states: boolean[][][]; populations: number[] } {
  const states: boolean[][][] = [initial.grid.map((row) => [...row])];
  const populations: number[] = [initial.grid.flat().filter(Boolean).length];
  let current = initial;

  for (let t = 0; t < steps; t++) {
    current = stepGameOfLife(current);
    states.push(current.grid.map((row) => [...row]));
    populations.push(current.grid.flat().filter(Boolean).length);
  }

  return { states, populations };
}

function placePattern(gol: GameOfLife, pattern: boolean[][], offsetX: number, offsetY: number): void {
  for (let y = 0; y < pattern.length; y++) {
    for (let x = 0; x < pattern[y].length; x++) {
      const gx = (offsetX + x) % gol.width;
      const gy = (offsetY + y) % gol.height;
      gol.grid[gy][gx] = pattern[y][x];
    }
  }
}

生命游戏中涌现出三类典型结构：静物（Static，不变化的稳定结构如方块）、振荡子（Oscillator，周期性变化如闪烁器）、飞船（Spaceship，在网格中移动的结构如滑翔机）。更复杂的结构如滑翔机枪（Gosper Gun）能持续产生滑翔机。生命游戏已被证明是图灵完备的。


元胞自动机的应用
元胞自动机在交通流模拟、森林火灾蔓延、城市增长、材料科学等领域有广泛应用。其优势在于用简单的局部规则捕捉复杂的全局行为，且天然适合并行计算。


interface TrafficCA {
  road: number[];
  maxSpeed: number;
  slowdownProb: number;
}

function nagSchreckenberg(ca: TrafficCA, steps: number): { states: number[][]; avgSpeed: number[] } {
  const n = ca.road.length;
  const states: number[][] = [[...ca.road]];
  const avgSpeed: number[] = [];

  let road = [...ca.road];

  for (let t = 0; t < steps; t++) {
    const newRoad = [...road];
    const speeds: number[] = [];

    for (let i = 0; i < n; i++) {
      if (road[i] < 0) continue;

      let speed = Math.min(road[i] + 1, ca.maxSpeed);

      let gap = 0;
      for (let j = 1; j <= ca.maxSpeed; j++) {
        if (road[(i + j) % n] >= 0) break;
        gap++;
      }
      speed = Math.min(speed, gap);

      if (speed > 0 && Math.random() < ca.slowdownProb) {
        speed = Math.max(0, speed - 1);
      }

      newRoad[i] = -1;
      newRoad[(i + speed) % n] = speed;
      speeds.push(speed);
    }

    road = newRoad;
    states.push([...road]);
    avgSpeed.push(speeds.length > 0 ? speeds.reduce((a, b) => a + b, 0) / speeds.length : 0);
  }

  return { states, avgSpeed };
}

function forestFire(
  width: number,
  height: number,
  treeDensity: number,
  fireProb: number,
  growProb: number,
  steps: number,
): number[][][] {
  const EMPTY = 0;
  const TREE = 1;
  const FIRE = 2;

  let grid = Array.from({ length: height }, () =>
    Array.from({ length: width }, () => (Math.random() < treeDensity ? TREE : EMPTY)),
  );

  const history: number[][][] = [grid.map((row) => [...row])];

  for (let t = 0; t < steps; t++) {
    const next = grid.map((row) => [...row]);

    for (let y = 0; y < height; y++) {
      for (let x = 0; x < width; x++) {
        if (grid[y][x] === FIRE) {
          next[y][x] = EMPTY;
        } else if (grid[y][x] === TREE) {
          let hasFireNeighbor = false;
          for (const [dy, dx] of [
            [-1, 0],
            [1, 0],
            [0, -1],
            [0, 1],
          ]) {
            const ny = y + dy;
            const nx = x + dx;
            if (ny >= 0 && ny < height && nx >= 0 && nx < width) {
              if (grid[ny][nx] === FIRE) hasFireNeighbor = true;
            }
          }
          next[y][x] = hasFireNeighbor || Math.random() < fireProb ? FIRE : TREE;
        } else {
          next[y][x] = Math.random() < growProb ? TREE : EMPTY;
        }
      }
    }

    grid = next;
    history.push(grid.map((row) => [...row]));
  }

  return history;
}

小结
    

  • 元胞自动机通过简单的局部规则产生复杂的全局涌现行为
    • 

  • Wolfram 基本规则将一维 CA 分为四类：稳态、周期、混沌、复杂性边缘
    • 

  • 规则 110 是图灵完备的，证明了极简系统可以执行任意计算
    • 

  • Conway 生命游戏用三条规则产生静物、振荡子和飞船等丰富结构
    • 

  • 生命游戏也是图灵完备的，可以构造逻辑门和计算机
    • 

  • Nagel-Schreckenberg 模型成功捕捉了交通流中的幽灵堵车现象
    • 

  • 元胞自动机天然适合并行计算，是大规模空间模拟的高效工具
