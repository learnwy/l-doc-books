图的基本概念

核心概念

图（Graph）是离散数学中最重要的抽象结构之一，由顶点（Vertex）集合和边（Edge）集合组成。图论研究图的性质、结构和算法，是计算机科学中网络分析、路径规划、社交网络、编译器优化和硬件设计的数学基础。

形式化地，图 G = (V, E) 由顶点集 V 和边集 E ⊆ V × V 组成。根据边是否有方向、是否允许重边和自环，图可分为多种类型。理解图的基本概念是学习所有图算法的前提。

图的表示与遍历
图的两种主要表示方式：邻接矩阵和邻接表。


邻接矩阵：V×V 的矩阵 A，A[i][j] = 1 表示边 (i,j) 存在。空间 O(V²)，适合稠密图。判断边存在 O(1)。


邻接表：每个顶点维护一个邻居列表。空间 O(V+E)，适合稀疏图。遍历邻居高效。


class Graph {
  private adjacencyList: Map<number, Set<number>>;
  private directed: boolean;

  constructor(directed = false) {
    this.adjacencyList = new Map();
    this.directed = directed;
  }

  addVertex(v: number): void {
    if (!this.adjacencyList.has(v)) {
      this.adjacencyList.set(v, new Set());
    }
  }

  addEdge(u: number, v: number): void {
    this.addVertex(u);
    this.addVertex(v);
    this.adjacencyList.get(u)!.add(v);
    if (!this.directed) {
      this.adjacencyList.get(v)!.add(u);
    }
  }

  neighbors(v: number): number[] {
    return [...(this.adjacencyList.get(v) ?? [])];
  }

  vertices(): number[] {
    return [...this.adjacencyList.keys()];
  }

  bfs(start: number): number[] {
    const visited = new Set<number>();
    const queue: number[] = [start];
    const order: number[] = [];
    visited.add(start);

    while (queue.length > 0) {
      const v = queue.shift()!;
      order.push(v);
      for (const neighbor of this.neighbors(v)) {
        if (!visited.has(neighbor)) {
          visited.add(neighbor);
          queue.push(neighbor);
        }
      }
    }
    return order;
  }

  dfs(start: number): number[] {
    const visited = new Set<number>();
    const order: number[] = [];

    const visit = (v: number): void => {
      visited.add(v);
      order.push(v);
      for (const neighbor of this.neighbors(v)) {
        if (!visited.has(neighbor)) {
          visit(neighbor);
        }
      }
    };

    visit(start);
    return order;
  }
}
BFS（广度优先搜索）按层次遍历，适合求最短路径（无权图）和层次结构。时间 O(V+E)。


DFS（深度优先搜索）深入探索每条路径，适合检测环、拓扑排序和连通分量。时间 O(V+E)。


度序列与握手定理
度（Degree）是与顶点关联的边数。在有向图中分为入度（in-degree）和出度（out-degree）。


握手定理：无向图中所有顶点的度之和等于边数的两倍：Σ deg(v) = 2|E|。


推论：度数为奇数的顶点个数必为偶数。


Erdős–Gallai 定理：非负整数序列 d₁ ≥ d₂ ≥ ... ≥ dₙ 是简单图的度序列当且仅当序列和为偶数，且对每个 k：Σᵢ₌₁ᵏ dᵢ ≤ k(k-1) + Σᵢ₌ₖ₊₁ⁿ min(dᵢ, k)


function isGraphicalSequence(degrees: number[]): boolean {
  const d = [...degrees].sort((a, b) => b - a);
  const n = d.length;
  const sum = d.reduce((a, b) => a + b, 0);
  if (sum % 2 !== 0) return false;

  for (let k = 1; k <= n; k++) {
    let leftSum = 0;
    for (let i = 0; i < k; i++) leftSum += d[i];

    let rightSum = k * (k - 1);
    for (let i = k; i < n; i++) rightSum += Math.min(d[i], k);

    if (leftSum > rightSum) return false;
  }
  return true;
}

function computeDegreeDistribution(graph: Graph): Map<number, number> {
  const dist = new Map<number, number>();
  for (const v of graph.vertices()) {
    const deg = graph.neighbors(v).length;
    dist.set(deg, (dist.get(deg) ?? 0) + 1);
  }
  return dist;
}
特殊图类型
完全图 Kₙ：每对顶点之间都有边。边数 = n(n-1)/2。


二部图：顶点可分为两组，边只连接不同组的顶点。判定方法：图是二部图当且仅当不含奇数长度的环。


树：连通无环图。n 个顶点的树恰好有 n-1 条边。


平面图：可以画在平面上使得边不交叉。欧拉公式：V - E + F = 2（F 为面数）。


function isBipartite(graph: Graph): { result: boolean; partition?: [number[], number[]] } {
  const color = new Map<number, number>();
  const vertices = graph.vertices();
  if (vertices.length === 0) return { result: true, partition: [[], []] };

  const queue: number[] = [];

  for (const start of vertices) {
    if (color.has(start)) continue;
    color.set(start, 0);
    queue.push(start);

    while (queue.length > 0) {
      const v = queue.shift()!;
      for (const neighbor of graph.neighbors(v)) {
        if (!color.has(neighbor)) {
          color.set(neighbor, 1 - color.get(v)!);
          queue.push(neighbor);
        } else if (color.get(neighbor) === color.get(v)) {
          return { result: false };
        }
      }
    }
  }

  const part0 = vertices.filter((v) => color.get(v) === 0);
  const part1 = vertices.filter((v) => color.get(v) === 1);
  return { result: true, partition: [part0, part1] };
}

function isTree(graph: Graph): boolean {
  const vertices = graph.vertices();
  const n = vertices.length;
  if (n === 0) return true;

  let edgeCount = 0;
  for (const v of vertices) {
    edgeCount += graph.neighbors(v).length;
  }
  edgeCount /= 2;

  if (edgeCount !== n - 1) return false;

  const visited = new Set<number>();
  const stack: number[] = [vertices[0]];
  visited.add(vertices[0]);

  while (stack.length > 0) {
    const v = stack.pop()!;
    for (const neighbor of graph.neighbors(v)) {
      if (!visited.has(neighbor)) {
        visited.add(neighbor);
        stack.push(neighbor);
      }
    }
  }
  return visited.size === n;
}

欧拉公式与平面图
欧拉公式对连通平面图成立：V - E + F = 2，其中 V 是顶点数，E 是边数，F 是面数（包括外部无限面）。


推论：简单平面图满足 E ≤ 3V - 6（V ≥ 3）。进一步，若图不含三角形，则 E ≤ 2V - 4。


库拉托夫斯基定理：图是平面图当且仅当它不包含 K₅ 或 K₃,₃ 的细分子图。这是平面图判定的理论基础。


function eulerFormulaCheck(V: number, E: number, F: number): boolean {
  return V - E + F === 2;
}

function isPlanarBound(V: number, E: number): boolean {
  if (V < 3) return true;
  return E <= 3 * V - 6;
}

function eulerCharacteristic(V: number, E: number, F: number): number {
  return V - E + F;
}
小结
    

  • 图是顶点和边组成的离散结构，邻接矩阵适合稠密图，邻接表适合稀疏图
    • 

  • BFS 和 DFS 是图遍历的两种基本策略，时间复杂度均为 O(V+E)
    • 

  • 握手定理建立了顶点度数与边数的基本关系，度序列刻画了图的整体特征
    • 

  • 二部图、树、平面图等特殊图类具有独特的结构性质和高效算法
    • 

  • 欧拉公式 V - E + F = 2 是平面图理论的基石
