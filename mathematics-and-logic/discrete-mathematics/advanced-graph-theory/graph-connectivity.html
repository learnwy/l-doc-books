Part IV · 离散数学与逻辑离散数学 简介图论进阶 简介图的连通性

图的连通性

核心概念

连通性（Connectivity）是图论中最基本的全局性质，研究图中顶点之间的可达性。连通性分析在网络可靠性评估、电路设计、社交网络分析和分布式系统中有核心应用。一个网络的健壮性取决于其连通性——需要移除多少顶点或边才能使网络断开。

无向图的连通性通过连通分量描述，有向图则区分弱连通和强连通。点连通度和边连通度量化了图的"坚固程度"。Whitney 定理建立了这些概念之间的基本不等式。

割点与桥的发现
割点（Articulation Point / Cut Vertex）：移除该顶点后图的连通分量数增加。


桥（Bridge / Cut Edge）：移除该边后图的连通分量数增加。


Tarjan 算法通过 DFS 树和回退边（back edge）高效地发现所有割点和桥。核心思想：维护每个顶点的发现时间 disc[v] 和能回溯到的最早祖先 low[v]。


function findArticulationPointsAndBridges(
  adj: Map<number, number[]>,
  n: number,
): { articulationPoints: Set<number>; bridges: Array<[number, number]> } {
  const disc = new Array(n).fill(-1);
  const low = new Array(n).fill(-1);
  const parent = new Array(n).fill(-1);
  const ap = new Set<number>();
  const bridges: Array<[number, number]> = [];
  let timer = 0;

  function dfs(u: number): void {
    disc[u] = low[u] = timer++;
    let children = 0;

    for (const v of adj.get(u) ?? []) {
      if (disc[v] === -1) {
        children++;
        parent[v] = u;
        dfs(v);
        low[u] = Math.min(low[u], low[v]);

        if (parent[u] === -1 && children > 1) ap.add(u);
        if (parent[u] !== -1 && low[v] >= disc[u]) ap.add(u);
        if (low[v] > disc[u]) bridges.push([u, v]);
      } else if (v !== parent[u]) {
        low[u] = Math.min(low[u], disc[v]);
      }
    }
  }

  for (let i = 0; i < n; i++) {
    if (disc[i] === -1) dfs(i);
  }

  return { articulationPoints: ap, bridges };
}
割点判定条件：


    

  • 若 u 是 DFS 树的根且有 ≥2 个子树，则 u 是割点
    • 

  • 若 u 不是根且存在子节点 v 使得 low[v] ≥ disc[u]，则 u 是割点
    • 



桥判定条件：边 (u, v) 是桥当且仅当 low[v] > disc[u]


强连通分量
在有向图中，强连通分量（SCC, Strongly Connected Component）是最大的顶点子集，使得其中任意两个顶点之间存在双向路径。SCC 分解将有向图压缩为 DAG，是依赖分析和循环检测的基础。


Kosaraju 算法：两次 DFS


    

  1. 第一次 DFS 记录完成顺序
    2. 

  2. 在反向图上按完成顺序逆序进行第二次 DFS
    3. 

  3. 第二次 DFS 的每棵树就是一个 SCC
    4. 



function kosaraju(adj: Map<number, number[]>, n: number): number[][] {
  const visited = new Array(n).fill(false);
  const order: number[] = [];

  function dfs1(u: number): void {
    visited[u] = true;
    for (const v of adj.get(u) ?? []) {
      if (!visited[v]) dfs1(v);
    }
    order.push(u);
  }

  for (let i = 0; i < n; i++) {
    if (!visited[i]) dfs1(i);
  }

  const radj = new Map<number, number[]>();
  for (let u = 0; u < n; u++) radj.set(u, []);
  for (let u = 0; u < n; u++) {
    for (const v of adj.get(u) ?? []) {
      radj.get(v)!.push(u);
    }
  }

  visited.fill(false);
  const sccs: number[][] = [];

  function dfs2(u: number, component: number[]): void {
    visited[u] = true;
    component.push(u);
    for (const v of radj.get(u) ?? []) {
      if (!visited[v]) dfs2(v, component);
    }
  }

  for (let i = order.length - 1; i >= 0; i--) {
    if (!visited[order[i]]) {
      const component: number[] = [];
      dfs2(order[i], component);
      sccs.push(component);
    }
  }

  return sccs;
}
Tarjan SCC 算法是另一种单次 DFS 的 SCC 算法，使用栈和 low 值在同一次遍历中识别所有 SCC，实践中常比 Kosaraju 更高效。


双连通分量与 2-边连通
双连通分量（Biconnected Component）是没有割点的最大连通子图。一个图的双连通分量可以通过割点将图分解得到。


2-边连通分量是没有桥的最大连通子图。缩桥后得到的图是一棵树（桥树），常用于处理路径查询问题。


function biconnectedComponents(
  adj: Map<number, number[]>,
  n: number,
): { components: Array<Array<[number, number]>>; articulationPoints: Set<number> } {
  const disc = new Array(n).fill(-1);
  const low = new Array(n).fill(-1);
  const parent = new Array(n).fill(-1);
  const stack: Array<[number, number]> = [];
  const components: Array<Array<[number, number]>> = [];
  const ap = new Set<number>();
  let timer = 0;

  function dfs(u: number): void {
    disc[u] = low[u] = timer++;
    let children = 0;

    for (const v of adj.get(u) ?? []) {
      if (disc[v] === -1) {
        children++;
        parent[v] = u;
        stack.push([u, v]);
        dfs(v);
        low[u] = Math.min(low[u], low[v]);

        if ((parent[u] === -1 && children > 1) || (parent[u] !== -1 && low[v] >= disc[u])) {
          ap.add(u);
          const component: Array<[number, number]> = [];
          while (true) {
            const edge = stack.pop()!;
            component.push(edge);
            if (edge[0] === u && edge[1] === v) break;
          }
          components.push(component);
        }
      } else if (v !== parent[u] && disc[v] < disc[u]) {
        stack.push([u, v]);
        low[u] = Math.min(low[u], disc[v]);
      }
    }
  }

  for (let i = 0; i < n; i++) {
    if (disc[i] === -1) dfs(i);
  }
  if (stack.length > 0) components.push(stack.splice(0));

  return { components, articulationPoints: ap };
}

小结
    

  • 连通性是图论最基本的全局性质，决定了网络的可达性和可靠性
    • 

  • 割点和桥是网络的脆弱点，Tarjan 算法在 O(V+E) 时间内高效识别
    • 

  • 强连通分量将有向图压缩为 DAG，是依赖分析和循环检测的核心工具
    • 

  • 双连通分量和 2-边连通分量分析了更高层次的冗余性，在网络设计中至关重要
    • 

  • Whitney 定理建立了点连通度、边连通度和最小度之间的基本不等式 κ(G) ≤ λ(G) ≤ δ(G)
    •
