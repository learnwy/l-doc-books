Part IV · 离散数学与逻辑离散数学 简介图论进阶 简介图着色

图着色

核心概念

图着色（Graph Coloring）是图论中一类经典的组合优化问题，研究如何用最少的颜色给图的顶点（或边）着色，使得相邻元素颜色不同。图着色在编译器寄存器分配、调度问题、地图着色、频率分配和冲突解决中有广泛应用。

图 G 的色数（Chromatic Number）χ(G) 是使 G 可正常着色的最少颜色数。判定 χ(G) ≤ k（k ≥ 3）是 NP 完全问题，但对于特殊图类存在多项式时间算法。

贪心着色与界
贪心着色算法：按某种顺序遍历顶点，每个顶点分配与其所有已着色邻居不同的最小颜色编号。


function greedyColoring(adj: Map<number, number[]>, order: number[]): Map<number, number> {
  const color = new Map<number, number>();

  for (const v of order) {
    const usedColors = new Set<number>();
    for (const neighbor of adj.get(v) ?? []) {
      if (color.has(neighbor)) {
        usedColors.add(color.get(neighbor)!);
      }
    }

    let c = 0;
    while (usedColors.has(c)) c++;
    color.set(v, c);
  }

  return color;
}

function welshPowellColoring(adj: Map<number, number[]>): Map<number, number> {
  const vertices = [...adj.keys()];
  vertices.sort((a, b) => (adj.get(b)?.length ?? 0) - (adj.get(a)?.length ?? 0));
  return greedyColoring(adj, vertices);
}
贪心着色的颜色数取决于顶点排列顺序。Welsh-Powell 算法按度数递减排序，通常能给出较好的结果。


色数的界：


    

  • 下界：ω(G) ≤ χ(G)（ω 是最大团大小）
    • 

  • 上界：χ(G) ≤ Δ(G) + 1（Δ 是最大度，贪心保证）
    • 

  • Brooks 定理：若 G 不是完全图也不是奇环，则 χ(G) ≤ Δ(G)
    •

色多项式
色多项式 P(G, k) 是图 G 用 k 种颜色进行正常着色的方案数。色多项式完整编码了图的着色信息，χ(G) 就是使 P(G, k) > 0 的最小正整数 k。


删缩递推（Deletion-Contraction）：对图中任意一条边 e = (u,v)：


P(G, k) = P(G - e, k) - P(G / e, k)


其中 G - e 是删除边 e，G / e 是收缩边 e（合并 u 和 v）。


function chromaticPolynomial(adj: Map<number, Set<number>>, k: number): number {
  const vertices = [...adj.keys()];
  if (vertices.length === 0) return 1;

  let hasEdge = false;
  let edgeU = -1;
  let edgeV = -1;

  for (const u of vertices) {
    for (const v of adj.get(u) ?? new Set()) {
      if (u < v) {
        hasEdge = true;
        edgeU = u;
        edgeV = v;
        break;
      }
    }
    if (hasEdge) break;
  }

  if (!hasEdge) {
    return Math.pow(k, vertices.length);
  }

  const adjMinus = new Map<number, Set<number>>();
  for (const [v, neighbors] of adj) {
    adjMinus.set(v, new Set(neighbors));
  }
  adjMinus.get(edgeU)!.delete(edgeV);
  adjMinus.get(edgeV)!.delete(edgeU);

  const adjContract = new Map<number, Set<number>>();
  for (const [v, neighbors] of adj) {
    if (v === edgeV) continue;
    const newNeighbors = new Set<number>();
    for (const n of neighbors) {
      if (n === edgeV) newNeighbors.add(edgeU);
      else if (n !== v) newNeighbors.add(n);
    }
    newNeighbors.delete(v === edgeU ? edgeU : v);
    adjContract.set(v, newNeighbors);
  }
  for (const n of adj.get(edgeV) ?? new Set()) {
    if (n !== edgeU && n !== edgeV) {
      adjContract.get(edgeU)!.add(n);
      adjContract.get(n)!.add(edgeU);
    }
  }

  return chromaticPolynomial(adjMinus, k) - chromaticPolynomial(adjContract, k);
}
常见图的色多项式：


    

  • 完全图：P(Kₙ, k) = k(k-1)(k-2)...(k-n+1)
    • 

  • 树（n 个顶点）：P(T, k) = k(k-1)^{n-1}
    • 

  • 环 Cₙ：P(Cₙ, k) = (k-1)ⁿ + (-1)ⁿ(k-1)
    • 



四色定理与平面图着色
四色定理：每个平面图都可以用至多 4 种颜色正常着色。这是数学史上第一个由计算机辅助证明的重要定理（1976 年，Appel 和 Haken）。


五色定理的证明相对简单，基于欧拉公式推出的 E ≤ 3V - 6，可知平面图一定存在度 ≤ 5 的顶点，然后用 Kempe 链论证。


function fiveColorPlanarGraph(adj: Map<number, Set<number>>): Map<number, number> {
  const color = new Map<number, number>();
  const vertices = [...adj.keys()];

  if (vertices.length <= 5) {
    return greedyColoring(new Map([...adj].map(([k, v]) => [k, [...v]])), vertices);
  }

  let minDegVertex = vertices[0];
  let minDeg = adj.get(vertices[0])!.size;
  for (const v of vertices) {
    if (adj.get(v)!.size < minDeg) {
      minDeg = adj.get(v)!.size;
      minDegVertex = v;
    }
  }

  const subAdj = new Map<number, Set<number>>();
  for (const [v, neighbors] of adj) {
    if (v === minDegVertex) continue;
    const newNeighbors = new Set<number>();
    for (const n of neighbors) {
      if (n !== minDegVertex) newNeighbors.add(n);
    }
    subAdj.set(v, newNeighbors);
  }

  const subColor = fiveColorPlanarGraph(subAdj);

  const usedColors = new Set<number>();
  for (const neighbor of adj.get(minDegVertex) ?? new Set()) {
    if (subColor.has(neighbor)) {
      usedColors.add(subColor.get(neighbor)!);
    }
  }

  let c = 0;
  while (usedColors.has(c)) c++;

  for (const [v, col] of subColor) color.set(v, col);
  color.set(minDegVertex, c);

  return color;
}
边着色与 Vizing 定理
边着色给图的边着色，使得共享顶点的边颜色不同。边着色数称为色指数 χ'(G)。


Vizing 定理：对简单图 G，Δ(G) ≤ χ'(G) ≤ Δ(G) + 1。图根据色指数分为两类：


    

  • 第一类图：χ'(G) = Δ(G)
    • 

  • 第二类图：χ'(G) = Δ(G) + 1
    • 



判定一个图属于哪一类是 NP 完全问题。但二部图总是第一类图（König 边着色定理）。

小结
    

  • 图着色问题的核心是求色数 χ(G)，判定 χ(G) ≤ 3 已经是 NP 完全问题
    • 

  • 贪心着色保证 χ(G) ≤ Δ(G) + 1，Brooks 定理将上界改进为 Δ(G)（除完全图和奇环外）
    • 

  • 色多项式通过删缩递推计算，完整编码了图的着色信息
    • 

  • 四色定理保证每个平面图可 4 着色，是图论和数学史上的里程碑
    • 

  • 边着色的 Vizing 定理将色指数限制在 Δ 或 Δ+1，二部图总是第一类图
    •
