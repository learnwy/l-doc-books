网络流

核心概念

网络流（Network Flow）是图论中最具应用价值的理论之一，研究在容量约束下如何在网络中传输最多的"流量"。网络流模型统一了大量看似不同的优化问题：最大匹配、最小割、项目选择、交通规划、通信带宽分配等都可以归约为网络流问题。

流网络 G = (V, E) 是一个有向图，每条边 (u, v) 有非负容量 c(u,v)。网络有一个源点 s 和汇点 t。流 f 满足容量约束 0 ≤ f(u,v) ≤ c(u,v) 和流量守恒 Σf(u,v) = Σf(v,w)（对非源汇顶点）。最大流问题求从 s 到 t 的最大流量。

最大流算法
Ford-Fulkerson 方法的核心思想是反复寻找从 s 到 t 的增广路径（residual path），沿路径增加流量，直到不存在增广路径。


残量图（Residual Graph）：对于当前流 f，残量图中边 (u,v) 的残量容量为 c_f(u,v) = c(u,v) - f(u,v)，反向边 (v,u) 的残量容量为 f(u,v)。反向边的存在使得算法能够"撤销"之前的决策。


class MaxFlow {
  private capacity: number[][];
  private flow: number[][];
  private n: number;

  constructor(n: number) {
    this.n = n;
    this.capacity = Array.from({ length: n }, () => new Array(n).fill(0));
    this.flow = Array.from({ length: n }, () => new Array(n).fill(0));
  }

  addEdge(u: number, v: number, cap: number): void {
    this.capacity[u][v] += cap;
  }

  bfs(source: number, sink: number, parent: number[]): boolean {
    const visited = new Array(this.n).fill(false);
    visited[source] = true;
    const queue = [source];

    while (queue.length > 0) {
      const u = queue.shift()!;
      for (let v = 0; v < this.n; v++) {
        if (!visited[v] && this.residual(u, v) > 0) {
          visited[v] = true;
          parent[v] = u;
          if (v === sink) return true;
          queue.push(v);
        }
      }
    }
    return false;
  }

  private residual(u: number, v: number): number {
    return this.capacity[u][v] - this.flow[u][v];
  }

  edmondsKarp(source: number, sink: number): number {
    let maxFlow = 0;
    const parent = new Array(this.n).fill(-1);

    while (this.bfs(source, sink, parent)) {
      let pathFlow = Infinity;
      for (let v = sink; v !== source; v = parent[v]) {
        pathFlow = Math.min(pathFlow, this.residual(parent[v], v));
      }

      for (let v = sink; v !== source; v = parent[v]) {
        this.flow[parent[v]][v] += pathFlow;
        this.flow[v][parent[v]] -= pathFlow;
      }

      maxFlow += pathFlow;
      parent.fill(-1);
    }
    return maxFlow;
  }
}
Dinic 算法在 Edmonds-Karp 基础上引入分层图（Level Graph）和阻塞流（Blocking Flow），将复杂度从 O(VE²) 提升到 O(V²E)。对单位容量图，Dinic 达到 O(E√V) 的优秀复杂度。


class Dinic {
  private graph: Array<Array<{ to: number; cap: number; rev: number }>>;
  private level: number[];
  private iter: number[];

  constructor(n: number) {
    this.graph = Array.from({ length: n }, () => []);
    this.level = new Array(n);
    this.iter = new Array(n);
  }

  addEdge(from: number, to: number, cap: number): void {
    this.graph[from].push({ to, cap, rev: this.graph[to].length });
    this.graph[to].push({ to: from, cap: 0, rev: this.graph[from].length - 1 });
  }

  private bfs(s: number): boolean {
    this.level.fill(-1);
    const queue = [s];
    this.level[s] = 0;

    while (queue.length > 0) {
      const v = queue.shift()!;
      for (const e of this.graph[v]) {
        if (e.cap > 0 && this.level[e.to] < 0) {
          this.level[e.to] = this.level[v] + 1;
          queue.push(e.to);
        }
      }
    }
    return this.level[this.level.length - 1] >= 0;
  }

  private dfs(v: number, t: number, f: number): number {
    if (v === t) return f;
    for (; this.iter[v] < this.graph[v].length; this.iter[v]++) {
      const e = this.graph[v][this.iter[v]];
      if (e.cap > 0 && this.level[v] < this.level[e.to]) {
        const d = this.dfs(e.to, t, Math.min(f, e.cap));
        if (d > 0) {
          e.cap -= d;
          this.graph[e.to][e.rev].cap += d;
          return d;
        }
      }
    }
    return 0;
  }

  maxflow(s: number, t: number): number {
    let flow = 0;
    while (this.bfs(s)) {
      this.iter.fill(0);
      let d: number;
      while ((d = this.dfs(s, t, Infinity)) > 0) {
        flow += d;
      }
    }
    return flow;
  }
}
最大流最小割定理
最大流最小割定理（Max-Flow Min-Cut Theorem）：网络中最大流的值等于最小割的容量。这是组合优化中最深刻的对偶定理之一。


割（Cut）：将顶点分为两组 S 和 T（s ∈ S, t ∈ T），割的容量为所有从 S 到 T 的边的容量之和。最小割是容量最小的割。


找到最大流后，从源点 s 在残量图中 BFS 可达的顶点构成 S，不可达的构成 T。S 到 T 的边就是最小割边。


function findMinCut(maxFlowSolver: MaxFlow, source: number, n: number): { S: Set<number>; T: Set<number> } {
  const S = new Set<number>();
  const queue = [source];
  S.add(source);

  while (queue.length > 0) {
    const u = queue.shift()!;
    for (let v = 0; v < n; v++) {
      if (!S.has(v) && maxFlowSolver.residual(u, v) > 0) {
        S.add(v);
        queue.push(v);
      }
    }
  }

  const T = new Set<number>();
  for (let i = 0; i < n; i++) {
    if (!S.has(i)) T.add(i);
  }

  return { S, T };
}
二部图匹配
二部图最大匹配可以归约为最大流问题：添加超级源点连接左部所有顶点，超级汇点连接右部所有顶点，所有边容量为 1。最大流即为最大匹配。


匈牙利算法（Hungarian Algorithm）是专门求解二部图最大匹配的算法：


function hungarianMatching(adj: Map<number, number[]>, leftSize: number, rightSize: number): Map<number, number> {
  const match = new Map<number, number>();

  function augment(u: number, visited: Set<number>): boolean {
    for (const v of adj.get(u) ?? []) {
      if (visited.has(v)) continue;
      visited.add(v);

      if (!match.has(v) || augment(match.get(v)!, visited)) {
        match.set(v, u);
        return true;
      }
    }
    return false;
  }

  for (let u = 0; u < leftSize; u++) {
    augment(u, new Set());
  }

  return match;
}
König 定理：二部图中最大匹配数等于最小点覆盖数。这是最大流最小割定理在二部图上的特例。

小结
    

  • 网络流通过容量约束和流量守恒建模，最大流问题是组合优化的核心问题
    • 

  • Dinic 算法通过分层图和阻塞流达到 O(V²E) 的复杂度，是实践中最常用的最大流算法
    • 

  • 最大流最小割定理揭示了流和割的深刻对偶关系，是网络分析的理论基石
    • 

  • 二部图匹配通过网络流或匈牙利算法求解，König 定理建立了匹配与覆盖的等价性
    • 

  • 网络流模型能够统一表达大量组合优化问题，是算法竞赛和工程实践的核心工具
