命题逻辑

核心概念

命题逻辑（Propositional Logic）是数理逻辑的基础分支，研究命题之间的逻辑关系。命题是具有确定真值（真或假）的陈述句。命题逻辑通过逻辑联结词将简单命题组合成复合命题，并研究复合命题的真值如何由其组成命题的真值决定。

在计算机科学中，命题逻辑是布尔代数的理论基础，直接应用于电路设计、程序验证、数据库查询优化和人工智能推理系统。每个 if-else 分支、每个布尔表达式、每个断言都是命题逻辑的实例。

逻辑联结词与真值表
命题逻辑的五个基本联结词构成了完备的逻辑表达系统。理解它们的语义是掌握命题逻辑的关键。


否定（Negation, ¬）：一元联结词，将真变假、假变真。对应编程中的 ! 运算符。


合取（Conjunction, ∧）：二元联结词，当且仅当两个操作数都为真时结果为真。对应 &&。


析取（Disjunction, ∨）：二元联结词，当至少一个操作数为真时结果为真。对应 ||。注意这是"或包含"（inclusive or），而非日常语言中常见的"或排斥"。


蕴涵（Implication, →）：p → q 为假当且仅当 p 为真且 q 为假。这是初学者最容易误解的联结词——当前提为假时，蕴涵永远为真（空真，vacuous truth）。


等价（Biconditional, ↔）：p ↔ q 为真当且仅当 p 和 q 的真值相同。


type TruthValue = boolean;

interface PropFormula {
  type: 'var' | 'not' | 'and' | 'or' | 'implies' | 'iff';
  name?: string;
  operand?: PropFormula;
  left?: PropFormula;
  right?: PropFormula;
}

function evaluate(formula: PropFormula, assignment: Map<string, TruthValue>): TruthValue {
  switch (formula.type) {
    case 'var':
      return assignment.get(formula.name!) ?? false;
    case 'not':
      return !evaluate(formula.operand!, assignment);
    case 'and':
      return evaluate(formula.left!, assignment) && evaluate(formula.right!, assignment);
    case 'or':
      return evaluate(formula.left!, assignment) || evaluate(formula.right!, assignment);
    case 'implies':
      return !evaluate(formula.left!, assignment) || evaluate(formula.right!, assignment);
    case 'iff':
      return evaluate(formula.left!, assignment) === evaluate(formula.right!, assignment);
  }
}

function generateTruthTable(
  formula: PropFormula,
  variables: string[],
): Array<{ assignment: Record<string, boolean>; result: boolean }> {
  const rows: Array<{ assignment: Record<string, boolean>; result: boolean }> = [];
  const n = variables.length;

  for (let i = 0; i < 1 << n; i++) {
    const assignment = new Map<string, boolean>();
    const record: Record<string, boolean> = {};
    for (let j = 0; j < n; j++) {
      const val = Boolean((i >> (n - 1 - j)) & 1);
      assignment.set(variables[j], val);
      record[variables[j]] = val;
    }
    rows.push({ assignment: record, result: evaluate(formula, assignment) });
  }
  return rows;
}
蕴涵的等价形式在实际编程中极为重要：p → q ≡ ¬p ∨ q。这意味着"如果条件不满足，就不需要检查结论"，这正是短路求值的理论基础。


范式与等价变换
任何命题公式都可以转化为标准形式（范式），这是命题逻辑中最重要的规范化技术。


合取范式（CNF, Conjunctive Normal Form）：子句的合取，每个子句是文字的析取。形如 (l₁ ∨ l₂) ∧ (l₃ ∨ l₄)。CNF 是 SAT 求解器的标准输入格式。


析取范式（DNF, Disjunctive Normal Form）：子句的析取，每个子句是文字的合取。形如 (l₁ ∧ l₂) ∨ (l₃ ∧ l₄)。DNF 直接对应电路中的"与或"结构。


转换为 CNF 的三个步骤：


    

  1. 消除蕴涵和等价：p → q 替换为 ¬p ∨ q；p ↔ q 替换为 (¬p ∨ q) ∧ (p ∨ ¬q)
    2. 

  2. 否定号推入（德摩根定律）：¬(A ∧ B) = ¬A ∨ ¬B，¬(A ∨ B) = ¬A ∧ ¬B，¬¬A = A
    3. 

  3. 分配律展开：A ∨ (B ∧ C) = (A ∨ B) ∧ (A ∨ C)
    4. 



function eliminateImplication(formula: PropFormula): PropFormula {
  if (formula.type === 'var') return formula;
  if (formula.type === 'not') {
    return { type: 'not', operand: eliminateImplication(formula.operand!) };
  }
  const left = formula.left ? eliminateImplication(formula.left) : undefined;
  const right = formula.right ? eliminateImplication(formula.right) : undefined;
  if (formula.type === 'implies') {
    return { type: 'or', left: { type: 'not', operand: left! }, right: right! };
  }
  if (formula.type === 'iff') {
    return {
      type: 'and',
      left: { type: 'or', left: { type: 'not', operand: left! }, right: right! },
      right: { type: 'or', left: left!, right: { type: 'not', operand: right! } },
    };
  }
  return { ...formula, left, right };
}

function pushNegation(formula: PropFormula): PropFormula {
  if (formula.type !== 'not') {
    if (formula.type === 'var') return formula;
    return {
      ...formula,
      left: formula.left ? pushNegation(formula.left) : undefined,
      right: formula.right ? pushNegation(formula.right) : undefined,
    };
  }
  const inner = formula.operand!;
  if (inner.type === 'var') return formula;
  if (inner.type === 'not') return pushNegation(inner.operand!);
  if (inner.type === 'and') {
    return pushNegation({
      type: 'or',
      left: { type: 'not', operand: inner.left! },
      right: { type: 'not', operand: inner.right! },
    });
  }
  if (inner.type === 'or') {
    return pushNegation({
      type: 'and',
      left: { type: 'not', operand: inner.left! },
      right: { type: 'not', operand: inner.right! },
    });
  }
  return formula;
}
重言式与可满足性
命题公式根据其真值特性分为三类：


重言式（Tautology）：在所有赋值下都为真的公式。如 p ∨ ¬p。


矛盾式（Contradiction）：在所有赋值下都为假的公式。如 p ∧ ¬p。


可满足式（Satisfiable）：存在使其为真的赋值。


可满足性判定（SAT 问题）是计算机科学中第一个被证明为 NP 完全的问题（Cook-Levin 定理）。现代 SAT 求解器基于 DPLL 算法及其变体 CDCL：


type Literal = { variable: string; negated: boolean };
type Clause = Literal[];
type CNF = Clause[];

function dpll(cnf: CNF, assignment: Map<string, boolean>): boolean {
  const simplified = unitPropagation(cnf, assignment);
  if (simplified === null) return false;
  if (simplified.length === 0) return true;

  const variable = chooseVariable(simplified);
  if (!variable) return false;

  const tryTrue = new Map(assignment);
  tryTrue.set(variable, true);
  if (dpll(simplified, tryTrue)) {
    for (const [k, v] of tryTrue) assignment.set(k, v);
    return true;
  }

  const tryFalse = new Map(assignment);
  tryFalse.set(variable, false);
  if (dpll(simplified, tryFalse)) {
    for (const [k, v] of tryFalse) assignment.set(k, v);
    return true;
  }

  return false;
}

function unitPropagation(cnf: CNF, assignment: Map<string, boolean>): CNF | null {
  let changed = true;
  let current = [...cnf];

  while (changed) {
    changed = false;
    for (const clause of current) {
      if (clause.length === 1) {
        const lit = clause[0];
        assignment.set(lit.variable, !lit.negated);
        current = propagate(current, lit);
        changed = true;
        break;
      }
    }
    if (current.some((c) => c.length === 0)) return null;
  }
  return current;
}

function propagate(cnf: CNF, literal: Literal): CNF {
  return cnf
    .filter((clause) => !clause.some((l) => l.variable === literal.variable && l.negated === literal.negated))
    .map((clause) => clause.filter((l) => l.variable !== literal.variable));
}

function chooseVariable(cnf: CNF): string | undefined {
  for (const clause of cnf) {
    for (const lit of clause) {
      return lit.variable;
    }
  }
  return undefined;
}

命题逻辑推理规则
命题逻辑的推理系统提供了从前提推导结论的形式化方法。核心推理规则包括：


假言推理（Modus Ponens）：从 p 和 p → q 推出 q。这是最基本的推理规则。


假言否定（Modus Tollens）：从 ¬q 和 p → q 推出 ¬p。


假言三段论（Hypothetical Syllogism）：从 p → q 和 q → r 推出 p → r。


析取三段论（Disjunctive Syllogism）：从 p ∨ q 和 ¬p 推出 q。


消解规则（Resolution）：从 (p ∨ q) 和 (¬p ∨ r) 推出 (q ∨ r)。消解是自动定理证明的核心。


interface ProofStep {
  formula: PropFormula;
  justification: string;
  premises: number[];
}

function modusPonens(p: PropFormula, pImpliesQ: PropFormula): PropFormula | null {
  if (pImpliesQ.type !== 'implies') return null;
  if (formulaEquals(p, pImpliesQ.left!)) return pImpliesQ.right!;
  return null;
}

function resolution(clause1: Clause, clause2: Clause): Clause | null {
  for (const lit1 of clause1) {
    for (const lit2 of clause2) {
      if (lit1.variable === lit2.variable && lit1.negated !== lit2.negated) {
        const resolvent = [...clause1.filter((l) => l !== lit1), ...clause2.filter((l) => l !== lit2)];
        const unique = new Map<string, Literal>();
        for (const lit of resolvent) {
          const key = `${lit.negated ? '!' : ''}${lit.variable}`;
          unique.set(key, lit);
        }
        return [...unique.values()];
      }
    }
  }
  return null;
}

function formulaEquals(a: PropFormula, b: PropFormula): boolean {
  if (a.type !== b.type) return false;
  if (a.type === 'var') return a.name === b.name;
  if (a.type === 'not') return formulaEquals(a.operand!, b.operand!);
  return formulaEquals(a.left!, b.left!) && formulaEquals(a.right!, b.right!);
}
小结
    

  • 命题逻辑通过五个基本联结词（¬、∧、∨、→、↔）构建完整的逻辑表达系统
    • 

  • 蕴涵的语义（p → q ≡ ¬p ∨ q）是理解条件推理的关键，空真现象需要特别注意
    • 

  • CNF 和 DNF 范式是命题公式的标准化形式，CNF 是 SAT 求解的基础
    • 

  • SAT 问题是第一个 NP 完全问题，DPLL 算法和消解法是自动推理的核心技术
    • 

  • 命题逻辑的推理规则为程序验证和自动定理证明提供了严格的形式化框架
