关系与函数

核心概念

关系和函数是集合论的核心构造，也是离散数学中最具应用价值的概念。关系描述了元素之间的联系方式，函数是特殊的关系——每个输入恰好对应一个输出。在计算机科学中，关系直接映射到数据库的关系模型，而函数则是编程的基本抽象单元。

从集合论角度看，集合 A 到集合 B 的二元关系 R 是笛卡尔积 A × B 的一个子集。若 (a, b) ∈ R，则记为 aRb。函数 f: A → B 是一种特殊的关系，满足对每个 a ∈ A，存在唯一的 b ∈ B 使得 (a, b) ∈ f。

关系的性质与分类
二元关系的四个核心性质决定了其分类和应用价值：


自反性（Reflexive）：∀a ∈ A, aRa。即每个元素与自身相关。等于关系（=）、小于等于关系（≤）都是自反的。


对称性（Symmetric）：∀a,b ∈ A, aRb → bRa。相等关系是对称的，但小于关系不是。


反对称性（Antisymmetric）：∀a,b ∈ A, (aRb ∧ bRa) → a = b。子集关系（⊆）和整除关系（|）都是反对称的。


传递性（Transitive）：∀a,b,c ∈ A, (aRb ∧ bRc) → aRc。大多数常见关系都是传递的。


type Relation<T> = Set<string>;

function encode<T>(a: T, b: T): string {
  return JSON.stringify([a, b]);
}

function isReflexive<T>(relation: Relation<T>, domain: T[]): boolean {
  return domain.every((a) => relation.has(encode(a, a)));
}

function isSymmetric<T>(relation: Relation<T>, domain: T[]): boolean {
  for (const a of domain) {
    for (const b of domain) {
      if (relation.has(encode(a, b)) && !relation.has(encode(b, a))) {
        return false;
      }
    }
  }
  return true;
}

function isAntisymmetric<T>(relation: Relation<T>, domain: T[]): boolean {
  for (const a of domain) {
    for (const b of domain) {
      if (a !== b && relation.has(encode(a, b)) && relation.has(encode(b, a))) {
        return false;
      }
    }
  }
  return true;
}

function isTransitive<T>(relation: Relation<T>, domain: T[]): boolean {
  for (const a of domain) {
    for (const b of domain) {
      for (const c of domain) {
        if (relation.has(encode(a, b)) && relation.has(encode(b, c)) && !relation.has(encode(a, c))) {
          return false;
        }
      }
    }
  }
  return true;
}

等价关系与划分
等价关系是同时满足自反性、对称性和传递性的关系。等价关系在集合上定义了一种"相等"的概念，将集合划分为互不相交的等价类。


对于等价关系 R，元素 a 的等价类 [a] = {b ∈ A | aRb}。等价关系与集合划分之间存在一一对应：每个等价关系唯一确定一个划分，每个划分也唯一确定一个等价关系。


在编程中，等价关系的应用极为广泛：


class UnionFind {
  private parent: number[];
  private rank: number[];

  constructor(n: number) {
    this.parent = Array.from({ length: n }, (_, i) => i);
    this.rank = new Array(n).fill(0);
  }

  find(x: number): number {
    if (this.parent[x] !== x) {
      this.parent[x] = this.find(this.parent[x]);
    }
    return this.parent[x];
  }

  union(x: number, y: number): boolean {
    const px = this.find(x);
    const py = this.find(y);
    if (px === py) return false;
    if (this.rank[px] < this.rank[py]) {
      this.parent[px] = py;
    } else if (this.rank[px] > this.rank[py]) {
      this.parent[py] = px;
    } else {
      this.parent[py] = px;
      this.rank[px]++;
    }
    return true;
  }

  areEquivalent(x: number, y: number): boolean {
    return this.find(x) === this.find(y);
  }

  getPartition(): Map<number, number[]> {
    const partition = new Map<number, number[]>();
    for (let i = 0; i < this.parent.length; i++) {
      const root = this.find(i);
      if (!partition.has(root)) partition.set(root, []);
      partition.get(root)!.push(i);
    }
    return partition;
  }
}
偏序与全序
偏序关系（Partial Order）是满足自反性、反对称性和传递性的关系。偏序集（Poset）是配备了偏序关系的集合，记为 (A, ≤)。


偏序集中的重要概念：


极大元和极小元：没有比它更大（小）的元素。


最大元和最小元：与所有元素都可比且最大（小）。


上界和下界：子集 S 的上界是大于等于 S 中所有元素的元素。


上确界（最小上界）和下确界（最大下界）：上界中最小的和下界中最大的。


偏序关系可以用哈斯图（Hasse Diagram）直观表示，省略自反和传递的边：


interface Poset<T> {
  elements: T[];
  leq: (a: T, b: T) => boolean;
}

function hasseEdges<T>(poset: Poset<T>): Array<[T, T]> {
  const edges: Array<[T, T]> = [];
  const { elements, leq } = poset;

  for (const a of elements) {
    for (const b of elements) {
      if (a !== b && leq(a, b)) {
        let isCover = true;
        for (const c of elements) {
          if (c !== a && c !== b && leq(a, c) && leq(c, b)) {
            isCover = false;
            break;
          }
        }
        if (isCover) edges.push([a, b]);
      }
    }
  }
  return edges;
}

function topologicalSort<T>(poset: Poset<T>): T[] {
  const result: T[] = [];
  const visited = new Set<T>();
  const { elements, leq } = poset;

  function dfs(node: T): void {
    if (visited.has(node)) return;
    visited.add(node);
    for (const next of elements) {
      if (next !== node && leq(node, next)) {
        dfs(next);
      }
    }
    result.unshift(node);
  }

  for (const elem of elements) {
    dfs(elem);
  }
  return result;
}
全序（Total Order）是任意两个元素都可比的偏序。排序算法本质上是在数据上构建全序关系。


函数的性质与复合
函数 f: A → B 是一种特殊的关系，其核心性质包括：


单射（Injective）：∀a₁,a₂ ∈ A, f(a₁) = f(a₂) → a₁ = a₂。不同输入映射到不同输出，即"一对一"。


满射（Surjective）：∀b ∈ B, ∃a ∈ A, f(a) = b。每个输出都有至少一个输入对应，即"映上"。


双射（Bijective）：同时是单射和满射。双射函数存在逆函数。


function isInjective<A, B>(f: (a: A) => B, domain: A[], eq: (b1: B, b2: B) => boolean = (a, b) => a === b): boolean {
  for (let i = 0; i < domain.length; i++) {
    for (let j = i + 1; j < domain.length; j++) {
      if (eq(f(domain[i]), f(domain[j]))) return false;
    }
  }
  return true;
}

function isSurjective<A, B>(
  f: (a: A) => B,
  domain: A[],
  codomain: B[],
  eq: (b1: B, b2: B) => boolean = (a, b) => a === b,
): boolean {
  return codomain.every((b) => domain.some((a) => eq(f(a), b)));
}

function compose<A, B, C>(f: (b: B) => C, g: (a: A) => B): (a: A) => C {
  return (a: A) => f(g(a));
}

function inverse<A, B>(
  f: (a: A) => B,
  domain: A[],
  eq: (b1: B, b2: B) => boolean = (a, b) => a === b,
): (b: B) => A | undefined {
  return (b: B) => domain.find((a) => eq(f(a), b));
}
函数复合是构建复杂计算的基本手段。若 f: A → B 且 g: B → C，则复合函数 g ∘ f: A → C。复合运算满足结合律但不满足交换律。在函数式编程中，pipe 和 compose 操作直接对应函数复合。


小结
    

  • 关系是笛卡尔积的子集，四大性质（自反、对称、反对称、传递）决定了关系的分类
    • 

  • 等价关系将集合划分为互不相交的等价类，并查集是其高效实现
    • 

  • 偏序关系定义了元素间的部分可比性，拓扑排序是偏序的线性化
    • 

  • 函数的单射、满射、双射性质决定了逆函数的存在性和唯一性
    • 

  • 函数复合是函数式编程的核心抽象，满足结合律但不满足交换律
    •
