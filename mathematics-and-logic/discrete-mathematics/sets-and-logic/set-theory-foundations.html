集合论基础

核心概念

集合论是现代数学的基石，由康托尔在 19 世纪末创立。集合是一组确定的、互不相同的对象组成的整体，这些对象称为集合的元素。集合论为离散数学、数据库理论、类型系统和编程语言的形式化提供了统一框架。

在计算机科学中，集合无处不在：数据库的关系模型建立在集合论之上，类型系统本质上是集合的抽象，而算法中的去重、交集、并集操作都是集合运算的直接应用。

集合的表示与运算
集合的表示方法分为列举法和描述法。列举法直接给出所有元素，如 A = {1, 2, 3}；描述法通过性质定义，如 B = {x | x > 0 且 x 为偶数}。


集合的基本运算构成了一个完整的代数系统：


并集（Union）：A ∪ B = {x | x ∈ A 或 x ∈ B}，对应逻辑析取（OR）。在数据库中，UNION 操作直接对应集合并集。


交集（Intersection）：A ∩ B = {x | x ∈ A 且 x ∈ B}，对应逻辑合取（AND）。SQL 中的 INTERSECT 即为交集操作。


差集（Difference）：A - B = {x | x ∈ A 且 x ∉ B}，对应逻辑蕴涵的否定形式。SQL 中的 EXCEPT 对应差集。


补集（Complement）：在全集 U 下，A 的补集 Ā = U - A，对应逻辑否定（NOT）。


对称差（Symmetric Difference）：A △ B = (A - B) ∪ (B - A)，对应逻辑异或（XOR）。


class MathSet<T> {
  private elements: Set<T>;

  constructor(items: Iterable<T>) {
    this.elements = new Set(items);
  }

  union(other: MathSet<T>): MathSet<T> {
    return new MathSet([...this.elements, ...other.elements]);
  }

  intersection(other: MathSet<T>): MathSet<T> {
    const result: T[] = [];
    for (const elem of this.elements) {
      if (other.has(elem)) result.push(elem);
    }
    return new MathSet(result);
  }

  difference(other: MathSet<T>): MathSet<T> {
    const result: T[] = [];
    for (const elem of this.elements) {
      if (!other.has(elem)) result.push(elem);
    }
    return new MathSet(result);
  }

  symmetricDifference(other: MathSet<T>): MathSet<T> {
    return this.difference(other).union(other.difference(this));
  }

  has(elem: T): boolean {
    return this.elements.has(elem);
  }

  isSubsetOf(other: MathSet<T>): boolean {
    for (const elem of this.elements) {
      if (!other.has(elem)) return false;
    }
    return true;
  }

  powerSet(): MathSet<MathSet<T>>[] {
    const items = [...this.elements];
    const result: MathSet<T>[] = [];
    for (let i = 0; i < 1 << items.length; i++) {
      const subset: T[] = [];
      for (let j = 0; j < items.length; j++) {
        if (i & (1 << j)) subset.push(items[j]);
      }
      result.push(new MathSet(subset));
    }
    return result as unknown as MathSet<MathSet<T>>[];
  }
}
集合代数定律
集合运算满足一系列重要的代数定律，这些定律与布尔代数和逻辑运算完全对应，是编译器优化和电路设计的理论基础。


交换律：A ∪ B = B ∪ A，A ∩ B = B ∩ A


结合律：(A ∪ B) ∪ C = A ∪ (B ∪ C)，(A ∩ B) ∩ C = A ∩ (B ∩ C)


分配律：A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)，A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)


德摩根定律：这是最重要的等价关系之一，直接对应逻辑中的德摩根律。


吸收律：A ∪ (A ∩ B) = A，A ∩ (A ∪ B) = A


幂等律：A ∪ A = A，A ∩ A = A


同一律：A ∪ ∅ = A，A ∩ U = A


零律：A ∪ U = U，A ∩ ∅ = ∅


互补律：A ∪ Ā = U，A ∩ Ā = ∅


这些定律在数据库查询优化中有直接应用。SQL 查询优化器利用集合代数定律重写查询计划：


type SetExpression<T> =
  | { type: 'base'; set: Set<T> }
  | { type: 'union'; left: SetExpression<T>; right: SetExpression<T> }
  | { type: 'intersection'; left: SetExpression<T>; right: SetExpression<T> }
  | { type: 'complement'; operand: SetExpression<T> };

function applyDeMorgan<T>(expr: SetExpression<T>): SetExpression<T> {
  if (expr.type === 'complement') {
    const inner = expr.operand;
    if (inner.type === 'union') {
      return {
        type: 'intersection',
        left: { type: 'complement', operand: inner.left },
        right: { type: 'complement', operand: inner.right },
      };
    }
    if (inner.type === 'intersection') {
      return {
        type: 'union',
        left: { type: 'complement', operand: inner.left },
        right: { type: 'complement', operand: inner.right },
      };
    }
  }
  return expr;
}
幂集与基数
幂集（Power Set）是一个集合所有子集构成的集合。若集合 A 有 n 个元素，则幂集 P(A) 有 2^n 个元素。幂集概念直接对应于计算机科学中的位向量表示。


基数（Cardinality）衡量集合的大小。有限集的基数就是元素个数，但无穷集的基数需要通过双射来定义。


可数集与不可数集：自然数集 ℕ 是最小的无穷集，其基数记为 ℵ₀（阿列夫零）。若一个集合与 ℕ 之间存在双射，则该集合是可数的。实数集 ℝ 是不可数的，其基数记为 c（连续统基数）。


康托尔对角线论证是证明实数不可数的经典方法，也是停机问题不可判定性证明的核心思想：


function cantorDiagonalization(sequences: string[][]): string[] {
  const diagonal: string[] = [];
  for (let i = 0; i < sequences.length; i++) {
    diagonal.push(sequences[i][i] === '0' ? '1' : '0');
  }
  return diagonal;
}

function demonstrateCountability(): void {
  const integers = (n: number): number => {
    return n % 2 === 0 ? n / 2 : -(n + 1) / 2;
  };

  const rationals = (n: number): [number, number] => {
    let k = 0;
    let diagonal = 1;
    while (k + diagonal <= n) {
      k += diagonal;
      diagonal++;
    }
    const pos = n - k;
    return [pos + 1, diagonal - pos];
  };

  console.log(
    '整数枚举:',
    Array.from({ length: 10 }, (_, i) => integers(i)),
  );
  console.log(
    '有理数枚举:',
    Array.from({ length: 10 }, (_, i) => rationals(i)),
  );
}

公理化集合论基础
朴素集合论存在悖论问题，最著名的是罗素悖论：设 R = {x | x ∉ x}，则 R ∈ R 当且仅当 R ∉ R。为了规避悖论，数学家建立了公理化集合论，最常用的是 ZFC（Zermelo-Fraenkel + 选择公理）系统。


ZFC 的核心公理包括：


外延公理：两个集合相等当且仅当它们拥有完全相同的元素。这个公理为集合相等提供了判定标准。


配对公理：对任意两个集合 a 和 b，存在集合 {a, b}。


并集公理：对任意集合族，存在其所有成员的并集。


幂集公理：对任意集合 A，存在 A 的幂集 P(A)。


无穷公理：存在一个包含空集且对后继运算封闭的集合（保证自然数集的存在）。


分离公理模式：给定集合 A 和性质 P，{x ∈ A | P(x)} 构成集合。这替代了导致悖论的无限制概括原理。


选择公理：对任意非空集合族，存在选择函数从每个集合中选出一个元素。


选择公理在计算机科学中的意义深远。它保证了良序定理（每个集合可以被良序化）和佐恩引理（每个偏序集中的链都有上界，则该偏序集有极大元）。佐恩引理在不动点理论和语义学中有核心应用。


小结
    

  • 集合论是现代数学和计算机科学的共同基础，集合运算直接映射到逻辑运算和数据库操作
    • 

  • 集合代数定律（交换律、结合律、分配律、德摩根定律）是查询优化和电路简化的理论依据
    • 

  • 幂集与基数理论揭示了有限与无穷之间的本质差异，康托尔对角线论证启发了停机问题的证明
    • 

  • 公理化集合论通过严格的公理系统规避了朴素集合论的悖论，为数学和类型系统提供了坚实基础
    • 

  • 选择公理的非构造性本质在构造性数学和类型论中引发了重要的哲学讨论
