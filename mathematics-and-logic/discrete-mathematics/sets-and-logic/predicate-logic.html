谓词逻辑

核心概念

谓词逻辑（Predicate Logic），也称一阶逻辑（First-Order Logic, FOL），是对命题逻辑的本质性扩展。命题逻辑只能处理整个命题的真假，而谓词逻辑引入了个体、谓词和量词，能够表达"所有"和"存在"这类涉及对象内部结构的陈述。

谓词逻辑是数据库查询语言（SQL）、程序规约（Hoare Logic）、类型系统和定理证明器的理论基础。SQL 的 WHERE 子句本质上是谓词逻辑公式，而 SELECT ... FROM ... WHERE ... 的结构直接对应谓词逻辑中的量化和过滤。

项、公式与量词
谓词逻辑的语法由三层构成：项（term）、原子公式（atomic formula）和复合公式（formula）。


项是指代对象的表达式：常量（如 0, a）、变量（如 x, y）、或函数应用（如 f(x), g(x, y)）。


原子公式是谓词符号应用于项，如 P(x)、LessThan(x, y)、Equal(f(x), g(y))。


复合公式由逻辑联结词和量词构成：


    

  • 全称量词 ∀x P(x)：对论域中的所有 x，P(x) 成立
    • 

  • 存在量词 ∃x P(x)：论域中存在某个 x 使得 P(x) 成立
    • 



量词之间的关系：¬∀x P(x) ≡ ∃x ¬P(x)，¬∃x P(x) ≡ ∀x ¬P(x)


type Term =
  | { type: 'constant'; name: string }
  | { type: 'variable'; name: string }
  | { type: 'function'; name: string; args: Term[] };

type Formula =
  | { type: 'predicate'; name: string; args: Term[] }
  | { type: 'not'; operand: Formula }
  | { type: 'and'; left: Formula; right: Formula }
  | { type: 'or'; left: Formula; right: Formula }
  | { type: 'implies'; left: Formula; right: Formula }
  | { type: 'forall'; variable: string; body: Formula }
  | { type: 'exists'; variable: string; body: Formula };

function freeVariables(formula: Formula): Set<string> {
  switch (formula.type) {
    case 'predicate':
      return termFreeVars(formula.args);
    case 'not':
      return freeVariables(formula.operand);
    case 'and':
    case 'or':
    case 'implies': {
      const left = freeVariables(formula.left);
      const right = freeVariables(formula.right);
      return new Set([...left, ...right]);
    }
    case 'forall':
    case 'exists': {
      const bodyVars = freeVariables(formula.body);
      bodyVars.delete(formula.variable);
      return bodyVars;
    }
  }
}

function termFreeVars(terms: Term[]): Set<string> {
  const vars = new Set<string>();
  for (const term of terms) {
    if (term.type === 'variable') vars.add(term.name);
    if (term.type === 'function') {
      for (const v of termFreeVars(term.args)) vars.add(v);
    }
  }
  return vars;
}
约束变量与自由变量：被量词绑定的变量是约束变量，否则是自由变量。一个公式如果没有自由变量，称为闭公式（句子）。闭公式在给定解释下有确定的真值。


解释与模型
谓词逻辑公式的语义由解释（Interpretation）定义。一个解释 I 包括：


    

  1. 论域 D：一个非空集合，表示"对象的全体"
    2. 

  2. 常量解释：每个常量符号映射到 D 中的一个元素
    3. 

  3. 函数解释：每个 n 元函数符号映射到 D^n → D 的函数
    4. 

  4. 谓词解释：每个 n 元谓词符号映射到 D^n 的一个子集（即 n 元关系）
    5. 



如果公式 φ 在解释 I 下为真，则 I 是 φ 的模型，记为 I ⊨ φ。


interface Interpretation {
  domain: unknown[];
  constants: Map<string, unknown>;
  functions: Map<string, (...args: unknown[]) => unknown>;
  predicates: Map<string, (...args: unknown[]) => boolean>;
}

function evaluateTerm(term: Term, interp: Interpretation, env: Map<string, unknown>): unknown {
  switch (term.type) {
    case 'constant':
      return interp.constants.get(term.name);
    case 'variable':
      return env.get(term.name);
    case 'function': {
      const fn = interp.functions.get(term.name)!;
      const args = term.args.map((a) => evaluateTerm(a, interp, env));
      return fn(...args);
    }
  }
}

function evaluateFormula(formula: Formula, interp: Interpretation, env: Map<string, unknown>): boolean {
  switch (formula.type) {
    case 'predicate': {
      const pred = interp.predicates.get(formula.name)!;
      const args = formula.args.map((a) => evaluateTerm(a, interp, env));
      return pred(...args);
    }
    case 'not':
      return !evaluateFormula(formula.operand, interp, env);
    case 'and':
      return evaluateFormula(formula.left, interp, env) && evaluateFormula(formula.right, interp, env);
    case 'or':
      return evaluateFormula(formula.left, interp, env) || evaluateFormula(formula.right, interp, env);
    case 'implies':
      return !evaluateFormula(formula.left, interp, env) || evaluateFormula(formula.right, interp, env);
    case 'forall':
      return interp.domain.every((d) => {
        const newEnv = new Map(env);
        newEnv.set(formula.variable, d);
        return evaluateFormula(formula.body, interp, newEnv);
      });
    case 'exists':
      return interp.domain.some((d) => {
        const newEnv = new Map(env);
        newEnv.set(formula.variable, d);
        return evaluateFormula(formula.body, interp, newEnv);
      });
  }
}
合一与消解
合一（Unification）是谓词逻辑自动推理的核心算法。给定两个项或公式，合一找到一个最一般的替换（Most General Unifier, MGU），使得两者在该替换下变为相同。


type Substitution = Map<string, Term>;

function unify(s: Term, t: Term, subst: Substitution = new Map()): Substitution | null {
  s = applySubst(s, subst);
  t = applySubst(t, subst);

  if (termEquals(s, t)) return subst;

  if (s.type === 'variable') {
    if (occursIn(s.name, t)) return null;
    subst.set(s.name, t);
    return subst;
  }

  if (t.type === 'variable') {
    if (occursIn(t.name, s)) return null;
    subst.set(t.name, s);
    return subst;
  }

  if (s.type === 'function' && t.type === 'function') {
    if (s.name !== t.name || s.args.length !== t.args.length) return null;
    for (let i = 0; i < s.args.length; i++) {
      const result = unify(s.args[i], t.args[i], subst);
      if (result === null) return null;
    }
    return subst;
  }

  return null;
}

function applySubst(term: Term, subst: Substitution): Term {
  if (term.type === 'variable') {
    const replacement = subst.get(term.name);
    return replacement ? applySubst(replacement, subst) : term;
  }
  if (term.type === 'function') {
    return { ...term, args: term.args.map((a) => applySubst(a, subst)) };
  }
  return term;
}

function occursIn(varName: string, term: Term): boolean {
  if (term.type === 'variable') return term.name === varName;
  if (term.type === 'function') return term.args.some((a) => occursIn(varName, a));
  return false;
}

function termEquals(a: Term, b: Term): boolean {
  if (a.type !== b.type) return false;
  if (a.type === 'constant' && b.type === 'constant') return a.name === b.name;
  if (a.type === 'variable' && b.type === 'variable') return a.name === b.name;
  if (a.type === 'function' && b.type === 'function') {
    return a.name === b.name && a.args.every((arg, i) => termEquals(arg, b.args[i]));
  }
  return false;
}
合一算法是 Prolog 语言的核心引擎，也是类型推导算法 Algorithm W 的基础。Hindley-Milner 类型推导本质上是在类型表达式上的合一操作。


前束范式与 Skolem 化
前束范式（Prenex Normal Form）将所有量词移到公式最前面。每个一阶逻辑公式都等价于一个前束范式。


转换步骤：消除蕴涵 → 推入否定 → 提取量词到前面。


Skolem 化消除存在量词，将公式转化为只含全称量词的形式。对于 ∀x∃y P(x,y)，引入 Skolem 函数 f，得到 ∀x P(x, f(x))。Skolem 化保持可满足性（但不保持等价性）。

这三步变换构成了一阶逻辑自动推理的预处理管道，将任意一阶公式转化为消解法可以处理的子句集形式。


小结
    

  • 谓词逻辑通过引入个体、谓词和量词，大幅扩展了命题逻辑的表达能力
    • 

  • 全称量词和存在量词的对偶关系（¬∀ ≡ ∃¬）是逻辑推理的核心工具
    • 

  • 合一算法是自动推理的基石，也是类型推导和逻辑编程的核心引擎
    • 

  • 前束范式和 Skolem 化将任意公式转化为消解法可处理的标准形式
    • 

  • 谓词逻辑的半可判定性意味着定理证明可以终止，但反驳可能永不终止
    •
