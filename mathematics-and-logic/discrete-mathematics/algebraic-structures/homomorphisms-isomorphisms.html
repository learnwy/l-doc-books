同态与同构

核心概念

同态（Homomorphism）和同构（Isomorphism）是代数学中最核心的概念，描述了代数结构之间的"保结构映射"。同态保持运算关系，同构则进一步要求映射是双射——同构的结构在代数意义上完全等价。

理解同态与同构的关键在于"结构保持"：不是看元素本身是什么，而是看元素之间的关系是否被映射所保持。这种"忘掉具体实现，只看接口"的抽象思想，与编程中的接口抽象和多态完全一致。

群同态定理
群同态定理（同构定理）是代数学的核心结果，揭示了核、像和商群之间的深刻关系。


第一同构定理：若 φ: G → H 是群同态，则 G/ker(φ) ≅ im(φ)。


第二同构定理：若 H ≤ G 且 N ◁ G，则 HN/N ≅ H/(H ∩ N)。


第三同构定理：若 N ◁ K ◁ G，则 (G/N)/(K/N) ≅ G/K。


interface GroupHomo<S, T> {
  source: Group<S>;
  target: Group<T>;
  map: (s: S) => T;
}

function verifyHomomorphism<S, T>(homo: GroupHomo<S, T>): boolean {
  const { source, target, map } = homo;
  return source.elements.every((a) =>
    source.elements.every((b) => target.equals(map(source.operation(a, b)), target.operation(map(a), map(b)))),
  );
}

function computeKernel<S, T>(homo: GroupHomo<S, T>): S[] {
  return homo.source.elements.filter((a) => homo.target.equals(homo.map(a), homo.target.identity));
}

function computeImage<S, T>(homo: GroupHomo<S, T>): T[] {
  const seen = new Set<string>();
  const result: T[] = [];
  for (const a of homo.source.elements) {
    const img = homo.map(a);
    const key = JSON.stringify(img);
    if (!seen.has(key)) {
      seen.add(key);
      result.push(img);
    }
  }
  return result;
}

function computeCosets<T>(group: Group<T>, subgroup: T[]): T[][] {
  const cosets: T[][] = [];
  const assigned = new Set<string>();

  for (const g of group.elements) {
    const key = JSON.stringify(g);
    if (assigned.has(key)) continue;

    const coset: T[] = [];
    for (const h of subgroup) {
      const product = group.operation(g, h);
      coset.push(product);
      assigned.add(JSON.stringify(product));
    }
    cosets.push(coset);
  }
  return cosets;
}
环同态与理想
环同态 f: R → S 是同时保持加法和乘法的映射：f(a+b) = f(a)+f(b) 且 f(a×b) = f(a)×f(b)。


环同态的核 ker(f) 是 R 的双边理想。环的第一同构定理：R/ker(f) ≅ im(f)。


interface RingHomo<S, T> {
  source: Ring<S>;
  target: Ring<T>;
  map: (s: S) => T;
}

function verifyRingHomomorphism<S, T>(
  homo: RingHomo<S, T>,
): {
  preservesAdd: boolean;
  preservesMul: boolean;
} {
  const { source, target, map } = homo;

  const preservesAdd = source.elements.every((a) =>
    source.elements.every((b) => target.equals(map(source.add(a, b)), target.add(map(a), map(b)))),
  );

  const preservesMul = source.elements.every((a) =>
    source.elements.every((b) => target.equals(map(source.multiply(a, b)), target.multiply(map(a), map(b)))),
  );

  return { preservesAdd, preservesMul };
}

function naturalHomomorphism<T>(ring: Ring<T>, idealElements: T[]): RingHomo<T, T[]> {
  const cosets = computeRingCosets(ring, idealElements);

  function findCoset(element: T): T[] {
    for (const coset of cosets) {
      if (coset.some((c) => ring.equals(c, element))) return coset;
    }
    return [];
  }

  return {
    source: ring,
    target: {
      elements: cosets,
      add: (a, b) => findCoset(ring.add(a[0], b[0])),
      multiply: (a, b) => findCoset(ring.multiply(a[0], b[0])),
      zero: findCoset(ring.zero),
      one: findCoset(ring.one),
      negate: (a) => findCoset(ring.negate(a[0])),
      equals: (a, b) => a.some((x) => b.some((y) => ring.equals(x, y))),
    },
    map: (s) => findCoset(s),
  };
}

function computeRingCosets<T>(ring: Ring<T>, ideal: T[]): T[][] {
  const cosets: T[][] = [];
  const assigned = new Set<string>();

  for (const r of ring.elements) {
    const key = JSON.stringify(r);
    if (assigned.has(key)) continue;

    const coset: T[] = [];
    for (const i of ideal) {
      const sum = ring.add(r, i);
      coset.push(sum);
      assigned.add(JSON.stringify(sum));
    }
    cosets.push(coset);
  }
  return cosets;
}

同构判定与不变量
判定两个结构是否同构是一个基本问题。对有限群，图同构可以归约为群同构，因此群同构一般没有已知的多项式时间算法。


同构不变量：如果两个结构同构，它们必须具有相同的不变量。不变量可以用来排除不同构的情况：


interface GroupInvariants {
  order: number;
  isAbelian: boolean;
  orderProfile: Map<number, number>;
  center: number;
  subgroupOrders: number[];
}

function computeGroupInvariants<T>(g: Group<T>): GroupInvariants {
  const order = g.elements.length;

  const isAbelian = g.elements.every((a) => g.elements.every((b) => g.equals(g.operation(a, b), g.operation(b, a))));

  const orderProfile = new Map<number, number>();
  for (const a of g.elements) {
    const ord = elementOrder(g, a);
    orderProfile.set(ord, (orderProfile.get(ord) ?? 0) + 1);
  }

  const center = g.elements.filter((z) =>
    g.elements.every((a) => g.equals(g.operation(z, a), g.operation(a, z))),
  ).length;

  return {
    order,
    isAbelian,
    orderProfile,
    center,
    subgroupOrders: [],
  };
}

function elementOrder<T>(g: Group<T>, a: T): number {
  let current = a;
  for (let i = 1; i <= g.elements.length; i++) {
    if (g.equals(current, g.identity)) return i;
    current = g.operation(current, a);
  }
  return g.elements.length;
}

function couldBeIsomorphic<S, T>(g1: Group<S>, g2: Group<T>): boolean {
  const inv1 = computeGroupInvariants(g1);
  const inv2 = computeGroupInvariants(g2);

  if (inv1.order !== inv2.order) return false;
  if (inv1.isAbelian !== inv2.isAbelian) return false;
  if (inv1.center !== inv2.center) return false;

  for (const [ord, count] of inv1.orderProfile) {
    if (inv2.orderProfile.get(ord) !== count) return false;
  }
  return true;
}
常用的同构不变量包括：阶（元素个数）、是否交换、元素的阶的分布、中心的大小、子群的格结构等。不变量不同则一定不同构，但不变量全部相同不保证同构。


范畴论视角
从范畴论（Category Theory）的角度看，同态是范畴中的态射（morphism），同构是可逆的态射。范畴论提供了统一描述各种代数结构及其映射的语言。


核心概念：


    

  • 对象（Object）：各种代数结构（群、环、向量空间等）
    • 

  • 态射（Morphism）：结构之间的保结构映射
    • 

  • 函子（Functor）：范畴之间的映射
    • 

  • 自然变换（Natural Transformation）：函子之间的映射
    • 



在编程中，范畴论的概念随处可见：函子对应 Functor（如 Array.map），单子对应 Monad（如 Promise），自然变换对应多态函数。

小结
    

  • 同态是保持运算关系的映射，同构是同态中的双射，同构的结构在代数意义上等价
    • 

  • 三个同构定理揭示了核、像、商结构之间的深刻关系，是代数学的核心结果
    • 

  • 同构判定依赖于不变量比较，阶、交换性、元素阶分布等是常用的不变量
    • 

  • 范畴论从更高层次统一了各种代数结构的映射理论，对编程中的接口抽象有直接启示
    • 

  • 理解同态与同构的关键在于"忘掉具体实现，只关注结构关系"的抽象思维
