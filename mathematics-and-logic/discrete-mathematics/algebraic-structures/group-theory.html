群论基础

核心概念

群（Group）是代数学中最基本也最重要的结构，由一个集合 G 和一个二元运算 · 组成，满足封闭性、结合律、存在单位元和每个元素存在逆元四条公理。群论统一了数学中大量看似不同的对称性现象，在计算机科学中应用于密码学、纠错编码、图形变换和置换算法。

群论的核心思想是"对称性的代数化"。一个对象的所有对称变换构成一个群，群的结构反映了对象的对称结构。从正方形的旋转翻转到密码学中的椭圆曲线群，群论提供了描述和利用对称性的统一语言。

群的公理与基本性质
群的四条公理：设 (G, ·) 是一个代数系统，若满足以下条件则称其为群：


    

  1. 封闭性：∀a,b ∈ G, a·b ∈ G
    2. 

  2. 结合律：∀a,b,c ∈ G, (a·b)·c = a·(b·c)
    3. 

  3. 单位元：∃e ∈ G, ∀a ∈ G, e·a = a·e = a
    4. 

  4. 逆元：∀a ∈ G, ∃a⁻¹ ∈ G, a·a⁻¹ = a⁻¹·a = e
    5. 



若还满足交换律 a·b = b·a，则称为阿贝尔群（交换群）。


interface Group<T> {
  elements: T[];
  operation: (a: T, b: T) => T;
  identity: T;
  inverse: (a: T) => T;
  equals: (a: T, b: T) => boolean;
}

function verifyGroup<T>(g: Group<T>): {
  closure: boolean;
  associativity: boolean;
  identity: boolean;
  inverse: boolean;
} {
  const { elements, operation, identity, inverse, equals } = g;

  const closure = elements.every((a) => elements.every((b) => elements.some((c) => equals(c, operation(a, b)))));

  const associativity = elements.every((a) =>
    elements.every((b) => elements.every((c) => equals(operation(operation(a, b), c), operation(a, operation(b, c))))),
  );

  const identityCheck = elements.every((a) => equals(operation(identity, a), a) && equals(operation(a, identity), a));

  const inverseCheck = elements.every((a) => {
    const inv = inverse(a);
    return equals(operation(a, inv), identity) && equals(operation(inv, a), identity);
  });

  return { closure, associativity, identity: identityCheck, inverse: inverseCheck };
}

function createZnGroup(n: number): Group<number> {
  return {
    elements: Array.from({ length: n }, (_, i) => i),
    operation: (a, b) => (a + b) % n,
    identity: 0,
    inverse: (a) => (n - a) % n,
    equals: (a, b) => a === b,
  };
}
群的阶：群 G 的元素个数称为群的阶，记为 |G|。元素 a 的阶是使 aⁿ = e 的最小正整数 n。


子群与 Lagrange 定理
子群：群 G 的非空子集 H 若在 G 的运算下也构成群，则 H 是 G 的子群。


子群判定：H ⊆ G 是子群当且仅当 ∀a,b ∈ H, a·b⁻¹ ∈ H。


Lagrange 定理：有限群 G 的子群 H 的阶整除 G 的阶。即 |H| 整除 |G|。


推论：元素 a 的阶整除 |G|。特别地，对任意 a ∈ G，a^|G| = e。这是费马小定理和欧拉定理的群论推广。


function findSubgroups<T>(g: Group<T>): T[][] {
  const subgroups: T[][] = [];
  const n = g.elements.length;

  for (let mask = 1; mask < 1 << n; mask++) {
    const subset: T[] = [];
    for (let i = 0; i < n; i++) {
      if (mask & (1 << i)) subset.push(g.elements[i]);
    }

    if (isSubgroup(g, subset)) {
      subgroups.push(subset);
    }
  }
  return subgroups;
}

function isSubgroup<T>(g: Group<T>, subset: T[]): boolean {
  if (!subset.some((a) => g.equals(a, g.identity))) return false;

  for (const a of subset) {
    for (const b of subset) {
      const product = g.operation(a, g.inverse(b));
      if (!subset.some((c) => g.equals(c, product))) return false;
    }
  }
  return true;
}

function elementOrder<T>(g: Group<T>, a: T): number {
  let current = a;
  for (let i = 1; i <= g.elements.length; i++) {
    if (g.equals(current, g.identity)) return i;
    current = g.operation(current, a);
  }
  return -1;
}
群同态与同构
群同态（Group Homomorphism）：f: G → H 满足 f(a·b) = f(a)·f(b)。同态保持群的代数结构。


群同构（Group Isomorphism）：既是同态又是双射。同构的群在代数意义上"完全相同"。


核（Kernel）：ker(f) = {a ∈ G | f(a) = e_H}。核是 G 的正规子群。


像（Image）：im(f) = {f(a) | a ∈ G}。像是 H 的子群。


第一同构定理：若 f: G → H 是群同态，则 G/ker(f) ≅ im(f)。


function isHomomorphism<S, T>(source: Group<S>, target: Group<T>, f: (s: S) => T): boolean {
  return source.elements.every((a) =>
    source.elements.every((b) => target.equals(f(source.operation(a, b)), target.operation(f(a), f(b)))),
  );
}

function kernel<S, T>(source: Group<S>, target: Group<T>, f: (s: S) => T): S[] {
  return source.elements.filter((a) => target.equals(f(a), target.identity));
}

function image<S, T>(source: Group<S>, target: Group<T>, f: (s: S) => T): T[] {
  const img = new Set<string>();
  const result: T[] = [];
  for (const a of source.elements) {
    const fa = f(a);
    const key = JSON.stringify(fa);
    if (!img.has(key)) {
      img.add(key);
      result.push(fa);
    }
  }
  return result;
}

置换群与 Cayley 定理
对称群 Sₙ 是 {1, 2, ..., n} 上所有排列构成的群，运算为排列复合。|Sₙ| = n!。


Cayley 定理：每个群都同构于某个对称群的子群。这意味着群论本质上就是排列的理论。


type Permutation = number[];

function composePermutations(p: Permutation, q: Permutation): Permutation {
  return p.map((i) => q[i]);
}

function inversePermutation(p: Permutation): Permutation {
  const inv = new Array(p.length);
  for (let i = 0; i < p.length; i++) {
    inv[p[i]] = i;
  }
  return inv;
}

function cycleDecomposition(p: Permutation): number[][] {
  const visited = new Array(p.length).fill(false);
  const cycles: number[][] = [];

  for (let i = 0; i < p.length; i++) {
    if (visited[i]) continue;
    const cycle: number[] = [];
    let j = i;
    while (!visited[j]) {
      visited[j] = true;
      cycle.push(j);
      j = p[j];
    }
    if (cycle.length > 1) cycles.push(cycle);
  }
  return cycles;
}

function isEvenPermutation(p: Permutation): boolean {
  const cycles = cycleDecomposition(p);
  const transpositions = cycles.reduce((sum, c) => sum + c.length - 1, 0);
  return transpositions % 2 === 0;
}

function permutationOrder(p: Permutation): number {
  const cycles = cycleDecomposition(p);
  if (cycles.length === 0) return 1;
  return cycles.reduce((lcm, c) => lcmFn(lcm, c.length), 1);
}

function lcmFn(a: number, b: number): number {
  return (a * b) / gcd(a, b);
}

function gcd(a: number, b: number): number {
  while (b) {
    [a, b] = [b, a % b];
  }
  return a;
}
置换的循环分解是理解置换结构的关键工具。每个排列可以唯一地分解为不相交循环的乘积，排列的阶等于各循环长度的最小公倍数。


小结
    

  • 群是满足封闭性、结合律、单位元和逆元四条公理的代数系统，是对称性的代数化
    • 

  • Lagrange 定理保证子群阶整除群阶，是费马小定理和欧拉定理的群论推广
    • 

  • 群同态保持代数结构，第一同构定理建立了商群与像之间的对应关系
    • 

  • Cayley 定理表明每个群都可以用排列来实现，置换群是群论的核心研究对象
    • 

  • 循环分解将排列的结构可视化，排列的阶等于循环长度的最小公倍数
    •
