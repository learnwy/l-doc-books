格与布尔代数

核心概念

格（Lattice）是一种特殊的偏序集，其中任意两个元素都有最小上界（上确界，join）和最大下界（下确界，meet）。布尔代数是满足补律的分配格，是数字逻辑和集合运算的代数抽象。

从计算机科学视角看，格理论直接应用于程序分析中的抽象解释、类型推导中的类型格、数据库理论中的函数依赖以及形式概念分析。布尔代数则是数字电路设计、逻辑门优化和集合操作的理论基础。

格的定义与运算
格可以从两个等价角度定义：


偏序定义：偏序集 (L, ≤) 若任意两个元素 a, b 的上确界 a ∨ b（join）和下确界 a ∧ b（meet）都存在，则 L 是格。


代数定义：集合 L 配备两个二元运算 ∨（join）和 ∧（meet），满足交换律、结合律和吸收律：a ∨ (a ∧ b) = a，a ∧ (a ∨ b) = a。


interface Lattice<T> {
  elements: T[];
  join: (a: T, b: T) => T;
  meet: (a: T, b: T) => T;
  leq: (a: T, b: T) => boolean;
  equals: (a: T, b: T) => boolean;
  top?: T;
  bottom?: T;
}

function createPowerSetLattice<T>(baseSet: T[]): Lattice<Set<T>> {
  const allSubsets: Set<T>[] = [];
  for (let mask = 0; mask < 1 << baseSet.length; mask++) {
    const subset = new Set<T>();
    for (let i = 0; i < baseSet.length; i++) {
      if (mask & (1 << i)) subset.add(baseSet[i]);
    }
    allSubsets.push(subset);
  }

  return {
    elements: allSubsets,
    join: (a, b) => new Set([...a, ...b]),
    meet: (a, b) => new Set([...a].filter((x) => b.has(x))),
    leq: (a, b) => [...a].every((x) => b.has(x)),
    equals: (a, b) => a.size === b.size && [...a].every((x) => b.has(x)),
    top: new Set(baseSet),
    bottom: new Set(),
  };
}

function verifyLattice<T>(l: Lattice<T>): {
  commutative: boolean;
  associative: boolean;
  absorption: boolean;
} {
  const { elements, join, meet, equals } = l;

  const commutative = elements.every((a) =>
    elements.every((b) => equals(join(a, b), join(b, a)) && equals(meet(a, b), meet(b, a))),
  );

  const associative = elements.every((a) =>
    elements.every((b) =>
      elements.every(
        (c) => equals(join(join(a, b), c), join(a, join(b, c))) && equals(meet(meet(a, b), c), meet(a, meet(b, c))),
      ),
    ),
  );

  const absorption = elements.every((a) =>
    elements.every((b) => equals(join(a, meet(a, b)), a) && equals(meet(a, join(a, b)), a)),
  );

  return { commutative, associative, absorption };
}
分配格与模格
分配格满足分配律：a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c)。等价地，a ∨ (b ∧ c) = (a ∨ b) ∧ (a ∨ c)。


模格满足模律：若 a ≤ c，则 a ∨ (b ∧ c) = (a ∨ b) ∧ c。每个分配格都是模格，但反过来不成立。


判定定理：


    

  • 格是模格当且仅当不含 N₅（五角形）作为子格
    • 

  • 格是分配格当且仅当不含 N₅ 或 M₃（钻石格）作为子格
    • 



function isDistributive<T>(l: Lattice<T>): boolean {
  const { elements, join, meet, equals } = l;
  return elements.every((a) =>
    elements.every((b) => elements.every((c) => equals(meet(a, join(b, c)), join(meet(a, b), meet(a, c))))),
  );
}

function isModular<T>(l: Lattice<T>): boolean {
  const { elements, join, meet, leq, equals } = l;
  return elements.every((a) =>
    elements.every((b) =>
      elements.every((c) => {
        if (!leq(a, c)) return true;
        return equals(join(a, meet(b, c)), meet(join(a, b), c));
      }),
    ),
  );
}
布尔代数
布尔代数是有补的有界分配格。即对每个元素 a，存在补元素 a'，使得 a ∨ a' = 1（最大元）且 a ∧ a' = 0（最小元）。


布尔代数的公理系统：


    

  1. 交换律：a ∨ b = b ∨ a，a ∧ b = b ∧ a
    2. 

  2. 分配律：a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c)
    3. 

  3. 同一律：a ∨ 0 = a，a ∧ 1 = a
    4. 

  4. 补律：a ∨ a' = 1，a ∧ a' = 0
    5. 



每个有限布尔代数都同构于某个集合的幂集代数 𝒫(S)。有限布尔代数的阶必为 2 的幂。


interface BooleanAlgebra<T> extends Lattice<T> {
  top: T;
  bottom: T;
  complement: (a: T) => T;
}

function createBitBooleanAlgebra(n: number): BooleanAlgebra<number> {
  const maxVal = (1 << n) - 1;
  const elements = Array.from({ length: 1 << n }, (_, i) => i);

  return {
    elements,
    join: (a, b) => a | b,
    meet: (a, b) => a & b,
    leq: (a, b) => (a & b) === a,
    equals: (a, b) => a === b,
    top: maxVal,
    bottom: 0,
    complement: (a) => a ^ maxVal,
  };
}

function verifyDeMorgan<T>(ba: BooleanAlgebra<T>): boolean {
  const { elements, join, meet, complement, equals } = ba;
  return elements.every((a) =>
    elements.every(
      (b) =>
        equals(complement(join(a, b)), meet(complement(a), complement(b))) &&
        equals(complement(meet(a, b)), join(complement(a), complement(b))),
    ),
  );
}

function booleanExpression(vars: boolean[], expr: (v: boolean[]) => boolean): boolean {
  return expr(vars);
}

function minimizeDNF(truthTable: boolean[], numVars: number): number[][] {
  const minterms: number[] = [];
  for (let i = 0; i < truthTable.length; i++) {
    if (truthTable[i]) minterms.push(i);
  }
  return quineMcCluskey(minterms, numVars);
}

function quineMcCluskey(minterms: number[], numVars: number): number[][] {
  const primes: number[][] = [];

  const groups = new Map<number, Set<number>>();
  for (const m of minterms) {
    const ones = m
      .toString(2)
      .split('')
      .filter((b) => b === '1').length;
    if (!groups.has(ones)) groups.set(ones, new Set());
    groups.get(ones)!.add(m);
  }

  for (const m of minterms) {
    primes.push([m]);
  }

  return primes;
}

不动点理论与程序分析
完备格中任意子集都有上确界和下确界。完备格上的不动点定理是程序分析的数学基础。


Knaster-Tarski 定理：完备格上的单调函数至少有一个不动点，且所有不动点构成一个完备格。最小不动点可以通过从底元素迭代计算得到。


function leastFixedPoint<T>(lattice: Lattice<T> & { bottom: T }, f: (x: T) => T): T {
  let current = lattice.bottom;
  let next = f(current);

  while (!lattice.equals(current, next)) {
    current = next;
    next = f(current);
  }

  return current;
}
在数据流分析中，程序的状态空间构成一个格，传递函数是格上的单调函数，数据流方程的解就是传递函数的最小不动点。


小结
    

  • 格是任意两个元素都有 join 和 meet 的偏序集，吸收律是格的核心特征
    • 

  • 分配格满足分配律，布尔代数是有补的分配格，有限布尔代数同构于幂集
    • 

  • 布尔代数的德摩根律直接对应数字电路中 NAND/NOR 门的等价变换
    • 

  • 完备格上的 Knaster-Tarski 不动点定理是数据流分析和抽象解释的数学基础
    • 

  • 格论为程序分析提供了统一的数学框架，类型推导中的类型格是其重要应用
