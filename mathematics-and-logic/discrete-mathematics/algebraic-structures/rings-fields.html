环与域

核心概念

环（Ring）和域（Field）是建立在群结构之上的更丰富的代数系统。环在加法群的基础上引入了满足结合律和分配律的乘法运算，域则进一步要求非零元素对乘法构成群，从而支持除法运算。这一层次化的代数结构为数论、密码学和编码理论提供了坚实的数学基础。

有限域（Galois 域）GF(pⁿ) 是现代密码学的基石——AES 加密工作在 GF(2⁸) 上，椭圆曲线密码学建立在素域 GF(p) 之上，Reed-Solomon 纠错码基于有限域上的多项式运算。理解环与域的结构，是掌握这些关键技术的必要前提。

环的理想与商环
理想（Ideal）是环论中与群论"正规子群"对应的概念。环 R 的子集 I 是理想，当且仅当 I 是 (R, +) 的子群，且 ∀r ∈ R, ∀a ∈ I，有 ra ∈ I 和 ar ∈ I。


理想允许构造商环 R/I = {r + I | r ∈ R}，运算为 (r₁ + I)(r₂ + I) = r₁r₂ + I。


主理想：由单个元素 a 生成的理想 ⟨a⟩ = {ra | r ∈ R}。在主理想整环（PID）中，每个理想都是主理想。


function modularArithmetic(n: number) {
  const add = (a: number, b: number): number => (((a + b) % n) + n) % n;
  const multiply = (a: number, b: number): number => (((a * b) % n) + n) % n;
  const negate = (a: number): number => (n - a) % n;

  const isUnit = (a: number): boolean => gcd(a, n) === 1;

  const inverse = (a: number): number => {
    const [g, x] = extendedGcd(a, n);
    if (g !== 1) return -1;
    return ((x % n) + n) % n;
  };

  return { add, multiply, negate, isUnit, inverse };
}

function extendedGcd(a: number, b: number): [number, number, number] {
  if (b === 0) return [a, 1, 0];
  const [g, x1, y1] = extendedGcd(b, a % b);
  return [g, y1, x1 - Math.floor(a / b) * y1];
}

function gcd(a: number, b: number): number {
  while (b) {
    [a, b] = [b, a % b];
  }
  return a;
}

function findIdeals(n: number): number[][] {
  const ideals: number[][] = [];
  for (let d = 1; d <= n; d++) {
    if (n % d === 0) {
      const ideal: number[] = [];
      for (let k = 0; k < n; k += d) ideal.push(k);
      ideals.push(ideal);
    }
  }
  return ideals;
}
环同态基本定理：若 φ: R → S 是环同态，则 R/ker(φ) ≅ im(φ)。这与群的第一同构定理完全类比。


有限域的构造与性质
有限域存在性定理：有限域的元素个数必为素数幂 pⁿ，且对每个素数幂 q = pⁿ，恰好存在一个（同构意义下）q 元有限域，记为 GF(q) 或 𝔽_q。


素域 GF(p)：当 p 为素数时，ℤ_p = {0, 1, ..., p-1} 在模 p 运算下构成域。每个非零元素都有乘法逆元。


扩域 GF(pⁿ)：当 n > 1 时，GF(pⁿ) 通过不可约多项式构造。在 GF(p)[x] 中选取 n 次不可约多项式 f(x)，则 GF(pⁿ) ≅ GF(p)[x]/⟨f(x)⟩。


function createGaloisField(p: number) {
  const mod = (a: number): number => ((a % p) + p) % p;

  const add = (a: number, b: number): number => mod(a + b);
  const sub = (a: number, b: number): number => mod(a - b);
  const mul = (a: number, b: number): number => mod(a * b);

  const pow = (base: number, exp: number): number => {
    let result = 1;
    let b = mod(base);
    let e = exp;
    while (e > 0) {
      if (e & 1) result = mul(result, b);
      b = mul(b, b);
      e >>= 1;
    }
    return result;
  };

  const inv = (a: number): number => pow(a, p - 2);
  const div = (a: number, b: number): number => mul(a, inv(b));

  const primitiveRoot = (): number => {
    for (let g = 2; g < p; g++) {
      let isPrimitive = true;
      const factors = primeFactors(p - 1);
      for (const f of factors) {
        if (pow(g, (p - 1) / f) === 1) {
          isPrimitive = false;
          break;
        }
      }
      if (isPrimitive) return g;
    }
    return -1;
  };

  return { add, sub, mul, div, pow, inv, primitiveRoot };
}

function primeFactors(n: number): number[] {
  const factors: number[] = [];
  let temp = n;
  for (let p = 2; p * p <= temp; p++) {
    if (temp % p === 0) {
      factors.push(p);
      while (temp % p === 0) temp /= p;
    }
  }
  if (temp > 1) factors.push(temp);
  return factors;
}

多项式环与不可约性
多项式环 R[x] 是环论中最重要的构造之一。域 F 上的多项式环 F[x] 是欧几里得整环，可以执行带余除法和因式分解。


不可约多项式在多项式环中扮演素数的角色。f(x) ∈ F[x] 是不可约的，当且仅当 f(x) 不能分解为两个次数更低的非常数多项式之积。


type Polynomial = number[];

function polyAdd(a: Polynomial, b: Polynomial, p: number): Polynomial {
  const maxLen = Math.max(a.length, b.length);
  const result: Polynomial = new Array(maxLen).fill(0);
  for (let i = 0; i < maxLen; i++) {
    result[i] = ((((a[i] ?? 0) + (b[i] ?? 0)) % p) + p) % p;
  }
  while (result.length > 1 && result[result.length - 1] === 0) result.pop();
  return result;
}

function polyMul(a: Polynomial, b: Polynomial, p: number): Polynomial {
  const result: Polynomial = new Array(a.length + b.length - 1).fill(0);
  for (let i = 0; i < a.length; i++) {
    for (let j = 0; j < b.length; j++) {
      result[i + j] = (((result[i + j] + a[i] * b[j]) % p) + p) % p;
    }
  }
  while (result.length > 1 && result[result.length - 1] === 0) result.pop();
  return result;
}

function polyMod(a: Polynomial, b: Polynomial, p: number): Polynomial {
  const result = [...a];
  const bDeg = b.length - 1;

  while (result.length - 1 >= bDeg) {
    const coeff = (result[result.length - 1] * modInverse(b[bDeg], p)) % p;
    const shift = result.length - 1 - bDeg;
    for (let i = 0; i <= bDeg; i++) {
      result[shift + i] = (((result[shift + i] - coeff * b[i]) % p) + p) % p;
    }
    result.pop();
  }
  return result;
}

function modInverse(a: number, p: number): number {
  let result = 1;
  let base = ((a % p) + p) % p;
  let exp = p - 2;
  while (exp > 0) {
    if (exp & 1) result = (result * base) % p;
    base = (base * base) % p;
    exp >>= 1;
  }
  return result;
}

function isIrreducible(poly: Polynomial, p: number): boolean {
  const n = poly.length - 1;
  let xPowerP: Polynomial = [0, 1];

  for (let i = 1; i <= Math.floor(n / 2); i++) {
    xPowerP = polyPow(xPowerP, p, poly, p);
    const diff = polyAdd(xPowerP, [0, p - 1], p);
    const g = polyGcd(diff, poly, p);
    if (g.length > 1) return false;
  }
  return true;
}

function polyPow(base: Polynomial, exp: number, mod: Polynomial, p: number): Polynomial {
  let result: Polynomial = [1];
  let b = [...base];
  let e = exp;
  while (e > 0) {
    if (e & 1) result = polyMod(polyMul(result, b, p), mod, p);
    b = polyMod(polyMul(b, b, p), mod, p);
    e >>= 1;
  }
  return result;
}

function polyGcd(a: Polynomial, b: Polynomial, p: number): Polynomial {
  let [x, y] = [a, b];
  while (y.length > 1 || y[0] !== 0) {
    [x, y] = [y, polyMod(x, y, p)];
  }
  return x;
}
小结
    

  • 环在群的基础上增加了乘法和分配律，理想是环中的"正规子群"，支持商环构造
    • 

  • 有限域的元素个数必为素数幂，对每个 q = pⁿ 恰有一个 GF(q)，通过不可约多项式构造
    • 

  • GF(2⁸) 是 AES 加密的运算基础，GF(p) 是椭圆曲线密码学的底层数学
    • 

  • 多项式环 F[x] 上的不可约多项式扮演素数角色，是有限域构造和纠错编码的核心
    • 

  • 环-整环-域的层次关系对应越来越强的代数性质约束，反映了从整数到有理数的推广过程
