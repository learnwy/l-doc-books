群论基础

核心概念

群（Group）是代数学的基石，它将"对称性"转化为精确的数学语言。一个群 (G, ·) 由集合 G 和满足封闭性、结合律、单位元、逆元四条公理的二元运算组成。群论的力量在于，看似不同的数学对象——整数加法、矩阵乘法、置换组合、模运算——在群论框架下展现出统一的结构规律。

在计算机科学中，群论渗透于密码学（椭圆曲线群、离散对数）、编码理论（循环码基于循环群）、图形学（旋转群、对称群）、算法设计（Burnside 引理计数）等核心领域。理解群的结构理论，是掌握这些应用的数学前提。

循环群与生成元
循环群是结构最简单但应用最广泛的群。群 G 是循环群，当且仅当存在元素 g ∈ G 使得 G = ⟨g⟩ = {gⁿ | n ∈ ℤ}，此时 g 称为生成元。


有限循环群 ℤₙ 包含 n 个元素 {0, 1, ..., n-1}，运算为模 n 加法。ℤₙ 的子群恰好是 ⟨d⟩ = {0, d, 2d, ..., n-d}，其中 d 整除 n。


生成元的数量：ℤₙ 的生成元恰好是与 n 互素的元素，生成元个数为欧拉函数 φ(n)。


function eulerTotient(n: number): number {
  let result = n;
  let temp = n;
  for (let p = 2; p * p <= temp; p++) {
    if (temp % p === 0) {
      while (temp % p === 0) temp /= p;
      result -= result / p;
    }
  }
  if (temp > 1) result -= result / temp;
  return result;
}

function findGenerators(n: number): number[] {
  const generators: number[] = [];
  for (let a = 1; a < n; a++) {
    if (gcd(a, n) === 1) generators.push(a);
  }
  return generators;
}

function gcd(a: number, b: number): number {
  while (b) {
    [a, b] = [b, a % b];
  }
  return a;
}

function cyclicSubgroups(n: number): Map<number, number[]> {
  const subgroups = new Map<number, number[]>();
  for (let d = 1; d <= n; d++) {
    if (n % d === 0) {
      const subgroup: number[] = [];
      for (let k = 0; k < n; k += d) subgroup.push(k);
      subgroups.set(n / d, subgroup);
    }
  }
  return subgroups;
}
循环群的基本定理：


    

  1. 循环群的子群仍是循环群
    2. 

  2. |ℤₙ| = n 的子群与 n 的因子一一对应
    3. 

  3. 若 gcd(m, n) = 1，则 ℤₘ × ℤₙ ≅ ℤₘₙ（中国剩余定理的群论表述）
    4. 



群作用与 Burnside 引理
群作用是群论中最有力的工具之一。群 G 在集合 X 上的作用是映射 G × X → X，记作 g·x，满足 e·x = x 且 (gh)·x = g·(h·x)。


群作用将抽象的群运算转化为集合上的具体变换，架起了代数与几何之间的桥梁。


轨道与稳定子：


    

  • 轨道 Orb(x) = {g·x | g ∈ G}：x 在群作用下能到达的所有位置
    • 

  • 稳定子 Stab(x) = {g ∈ G | g·x = x}：保持 x 不动的所有群元素
    • 



轨道-稳定子定理：|Orb(x)| · |Stab(x)| = |G|。


Burnside 引理（计数定理）：在群 G 作用下，不等价的着色方案数为各群元素不动点数的平均值：


|X/G| = (1/|G|) Σ_{g∈G} |Fix(g)|


function burnsideCount(
  groupElements: number[][],
  colorings: number[][],
  applyAction: (action: number[], coloring: number[]) => number[],
  coloringEquals: (a: number[], b: number[]) => boolean,
): number {
  let totalFixed = 0;

  for (const g of groupElements) {
    let fixedCount = 0;
    for (const c of colorings) {
      const transformed = applyAction(g, c);
      if (coloringEquals(c, transformed)) fixedCount++;
    }
    totalFixed += fixedCount;
  }

  return totalFixed / groupElements.length;
}

function squareRotations(): number[][] {
  return [
    [0, 1, 2, 3],
    [1, 2, 3, 0],
    [2, 3, 0, 1],
    [3, 0, 1, 2],
  ];
}

function countDistinctNecklaces(n: number, k: number): number {
  let total = 0;
  for (let r = 0; r < n; r++) {
    total += Math.pow(k, gcd(r, n));
  }
  return total / n;
}
Burnside 引理在组合计数中至关重要：计算旋转等价的项链方案、着色方案、化学分子构型等问题。


直积与群的分类
直积：给定群 G₁ 和 G₂，直积 G₁ × G₂ 的元素为有序对 (g₁, g₂)，运算逐分量进行。直积是从小群构造大群的基本手段。


有限阿贝尔群基本定理：每个有限阿贝尔群都同构于循环群的直积 ℤ*{n₁} × ℤ*{n₂} × ... × ℤ*{nₖ}，其中 n*{i+1} | nᵢ（不变因子分解），或等价地，同构于素数幂阶循环群的直积（初等因子分解）。


function decomposeAbelianGroup(n: number): number[][] {
  const factors = primeFactorization(n);
  const invariantFactors: number[][] = [];

  for (const [p, e] of factors) {
    const partitions = integerPartitions(e);
    for (const partition of partitions) {
      invariantFactors.push(partition.map((k) => Math.pow(p, k)));
    }
  }
  return invariantFactors;
}

function primeFactorization(n: number): [number, number][] {
  const factors: [number, number][] = [];
  let temp = n;
  for (let p = 2; p * p <= temp; p++) {
    if (temp % p === 0) {
      let exp = 0;
      while (temp % p === 0) {
        temp /= p;
        exp++;
      }
      factors.push([p, exp]);
    }
  }
  if (temp > 1) factors.push([temp, 1]);
  return factors;
}

function integerPartitions(n: number): number[][] {
  const result: number[][] = [];
  function backtrack(remaining: number, maxPart: number, current: number[]) {
    if (remaining === 0) {
      result.push([...current]);
      return;
    }
    for (let i = Math.min(remaining, maxPart); i >= 1; i--) {
      current.push(i);
      backtrack(remaining - i, i, current);
      current.pop();
    }
  }
  backtrack(n, n, []);
  return result;
}

正规子群与商群
正规子群：N 是 G 的正规子群（记 N ◁ G），当且仅当对所有 g ∈ G，gNg⁻¹ = N，即 N 在共轭作用下不变。


正规子群的重要性在于它允许构造商群 G/N = {gN | g ∈ G}，其中 gN 是 g 的左陪集。商群的运算为 (gN)(hN) = (gh)N，只有当 N 是正规子群时这个运算才是良定义的。


function isNormalSubgroup<T>(
  g: { elements: T[]; operation: (a: T, b: T) => T; inverse: (a: T) => T; equals: (a: T, b: T) => boolean },
  subgroup: T[],
): boolean {
  for (const element of g.elements) {
    for (const h of subgroup) {
      const conjugate = g.operation(g.operation(element, h), g.inverse(element));
      if (!subgroup.some((s) => g.equals(s, conjugate))) return false;
    }
  }
  return true;
}

function leftCosets<T>(
  g: { elements: T[]; operation: (a: T, b: T) => T; equals: (a: T, b: T) => boolean },
  subgroup: T[],
): T[][] {
  const cosets: T[][] = [];
  const assigned = new Set<number>();

  for (let i = 0; i < g.elements.length; i++) {
    if (assigned.has(i)) continue;
    const coset: T[] = [];
    for (const h of subgroup) {
      const product = g.operation(g.elements[i], h);
      const idx = g.elements.findIndex((e) => g.equals(e, product));
      assigned.add(idx);
      coset.push(product);
    }
    cosets.push(coset);
  }
  return cosets;
}
同构定理（群论三大同构定理的核心）：


    

  1. 第一同构定理：若 φ: G → H 是群同态，则 G/ker(φ) ≅ im(φ)
    2. 

  2. 第二同构定理：若 H ≤ G 且 N ◁ G，则 HN/N ≅ H/(H ∩ N)
    3. 

  3. 第三同构定理：若 N ◁ K ◁ G 且 N ◁ G，则 (G/N)/(K/N) ≅ G/K
    4. 



这些定理揭示了群的商结构与子群结构之间的深层联系，是分析群结构的核心工具。


小结
    

  • 循环群由单个生成元生成，其子群与生成元阶的因子一一对应，生成元个数为欧拉函数 φ(n)
    • 

  • 群作用将代数运算转化为几何变换，Burnside 引理是等价类计数的核心工具
    • 

  • 有限阿贝尔群基本定理将任意有限阿贝尔群分解为循环群的直积，给出完整分类
    • 

  • 正规子群允许构造商群，三大同构定理揭示了群结构的层次关系
    • 

  • 群论为密码学、纠错编码、组合计数和对称分析提供了统一的数学框架
    •
