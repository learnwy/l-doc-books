代数结构在计算机科学中的应用

核心概念

代数结构不仅是纯数学的抽象工具，更是计算机科学诸多核心领域的理论基石。从密码学中的群和有限域运算，到编码理论中的多项式环，从形式语言中的幺半群（Monoid），到函数式编程中的半群和幺半群抽象，代数结构以各种形式渗透于计算机科学的方方面面。

掌握代数结构的应用价值在于：它提供了统一的抽象框架——相同的代数定律在不同领域反复出现，一旦理解了底层结构，就能将一个领域的技术迁移到另一个领域。密码学家看到的是群上的离散对数问题，编码理论家看到的是有限域上的多项式插值，函数式程序员看到的是幺半群的可结合折叠——它们本质上是同一种数学结构的不同投影。

密码学中的群论应用
现代公钥密码学的安全性建立在某些群上特定计算问题的困难性之上。最核心的两个假设是离散对数问题（DLP）和大整数分解问题。


Diffie-Hellman 密钥交换基于循环群中的离散对数问题：给定 g, gᵃ, gᵇ，计算 gᵃᵇ 在计算上不可行。


RSA 加密基于 ℤₙ* 群（n = pq，p、q 为大素数），利用欧拉定理 a^φ(n) ≡ 1 (mod n) 实现加解密。


function modPow(base: bigint, exp: bigint, mod: bigint): bigint {
  let result = 1n;
  let b = base % mod;
  let e = exp;
  while (e > 0n) {
    if (e & 1n) result = (result * b) % mod;
    b = (b * b) % mod;
    e >>= 1n;
  }
  return result;
}

function diffieHellman(p: bigint, g: bigint) {
  const generatePrivateKey = (): bigint => {
    const bytes = 32;
    let key = 0n;
    for (let i = 0; i < bytes; i++) {
      key = (key << 8n) | BigInt(Math.floor(Math.random() * 256));
    }
    return (key % (p - 2n)) + 2n;
  };

  const computePublicKey = (privateKey: bigint): bigint => modPow(g, privateKey, p);

  const computeSharedSecret = (privateKey: bigint, otherPublic: bigint): bigint => modPow(otherPublic, privateKey, p);

  return { generatePrivateKey, computePublicKey, computeSharedSecret };
}

function rsaKeyGen(p: bigint, q: bigint) {
  const n = p * q;
  const phi = (p - 1n) * (q - 1n);
  const e = 65537n;
  const d = modInverse(e, phi);

  const encrypt = (m: bigint): bigint => modPow(m, e, n);
  const decrypt = (c: bigint): bigint => modPow(c, d, n);

  return { publicKey: { n, e }, privateKey: { n, d }, encrypt, decrypt };
}

function modInverse(a: bigint, m: bigint): bigint {
  const [g, x] = extGcd(a, m);
  if (g !== 1n) throw new Error('No inverse');
  return ((x % m) + m) % m;
}

function extGcd(a: bigint, b: bigint): [bigint, bigint, bigint] {
  if (b === 0n) return [a, 1n, 0n];
  const [g, x1, y1] = extGcd(b, a % b);
  return [g, y1, x1 - (a / b) * y1];
}
纠错编码中的有限域运算
纠错编码利用代数冗余来检测和修复数据传输中的错误。其中最重要的 Reed-Solomon 码工作在有限域 GF(2⁸) 上，广泛应用于 QR 码、CD/DVD、深空通信和分布式存储系统。


Reed-Solomon 码的核心思想：将数据视为有限域上多项式的系数，通过在多个点求值来产生冗余，利用多项式插值（超定方程组）来恢复丢失的数据。


**CRC（循环冗余校验）**基于 GF(2)[x] 上的多项式除法，将数据视为 GF(2) 上的多项式，用生成多项式做除法取余数作为校验码。


const GF256_PRIMITIVE = 0x11d;

function gf256Mul(a: number, b: number): number {
  let result = 0;
  let x = a;
  let y = b;
  while (y > 0) {
    if (y & 1) result ^= x;
    x <<= 1;
    if (x & 0x100) x ^= GF256_PRIMITIVE;
    y >>= 1;
  }
  return result;
}

function buildLogTables(): { log: Uint8Array; exp: Uint8Array } {
  const log = new Uint8Array(256);
  const exp = new Uint8Array(256);
  let x = 1;
  for (let i = 0; i < 255; i++) {
    exp[i] = x;
    log[x] = i;
    x = gf256Mul(x, 2);
  }
  exp[255] = exp[0];
  return { log, exp };
}

function rsEncode(data: number[], nsym: number): number[] {
  const { log, exp } = buildLogTables();
  const gen = rsGeneratorPoly(nsym, log, exp);
  const encoded = new Array(data.length + nsym).fill(0);

  for (let i = 0; i < data.length; i++) encoded[i] = data[i];

  for (let i = 0; i < data.length; i++) {
    const coef = encoded[i];
    if (coef !== 0) {
      for (let j = 0; j < gen.length; j++) {
        encoded[i + j] ^= gf256MulLog(coef, gen[j], log, exp);
      }
    }
    encoded[i] = data[i];
  }
  return encoded;
}

function gf256MulLog(a: number, b: number, log: Uint8Array, exp: Uint8Array): number {
  if (a === 0 || b === 0) return 0;
  return exp[(log[a] + log[b]) % 255];
}

function rsGeneratorPoly(nsym: number, log: Uint8Array, exp: Uint8Array): number[] {
  let gen = [1];
  for (let i = 0; i < nsym; i++) {
    const factor = [1, exp[i]];
    const result = new Array(gen.length + 1).fill(0);
    for (let j = 0; j < gen.length; j++) {
      for (let k = 0; k < factor.length; k++) {
        result[j + k] ^= gf256MulLog(gen[j], factor[k], log, exp);
      }
    }
    gen = result;
  }
  return gen;
}

幺半群与函数式编程抽象
幺半群（Monoid）是具有结合律和单位元的代数结构——正是群去掉逆元要求后的结构。在函数式编程中，幺半群是最基础的抽象接口之一，因为结合律保证了并行折叠的正确性。


任何满足结合律和单位元的类型都可以抽象为幺半群：字符串连接（单位元为空串）、数字加法（单位元为 0）、列表拼接（单位元为空列表）、布尔 AND（单位元为 true）。


interface Monoid<T> {
  empty: T;
  concat: (a: T, b: T) => T;
}

const sumMonoid: Monoid<number> = {
  empty: 0,
  concat: (a, b) => a + b,
};

const productMonoid: Monoid<number> = {
  empty: 1,
  concat: (a, b) => a * b,
};

const stringMonoid: Monoid<string> = {
  empty: '',
  concat: (a, b) => a + b,
};

function foldMap<A, M>(items: A[], monoid: Monoid<M>, f: (a: A) => M): M {
  return items.reduce((acc, item) => monoid.concat(acc, f(item)), monoid.empty);
}

function parallelFold<T>(items: T[], monoid: Monoid<T>, chunkSize: number): T {
  if (items.length <= chunkSize) {
    return items.reduce((acc, item) => monoid.concat(acc, item), monoid.empty);
  }

  const chunks: T[][] = [];
  for (let i = 0; i < items.length; i += chunkSize) {
    chunks.push(items.slice(i, i + chunkSize));
  }

  const partialResults = chunks.map((chunk) => chunk.reduce((acc, item) => monoid.concat(acc, item), monoid.empty));

  return partialResults.reduce((acc, r) => monoid.concat(acc, r), monoid.empty);
}

interface Semigroup<T> {
  concat: (a: T, b: T) => T;
}

const maxSemigroup: Semigroup<number> = {
  concat: (a, b) => Math.max(a, b),
};

const minSemigroup: Semigroup<number> = {
  concat: (a, b) => Math.min(a, b),
};
MapReduce 框架本质上就是幺半群折叠：Map 阶段将数据转化为幺半群元素，Reduce 阶段利用结合律进行并行归约。结合律保证了无论数据如何分区、归约顺序如何，最终结果一致。


小结
    

  • 公钥密码学建立在群论之上，离散对数问题和大整数分解问题是安全性的数学保证
    • 

  • 有限域 GF(2⁸) 是 AES 的运算基础，Reed-Solomon 码利用有限域多项式插值实现纠错
    • 

  • CRC 校验基于 GF(2)[x] 上的多项式除法，是网络协议和存储系统的基础错误检测手段
    • 

  • 幺半群的结合律是并行计算正确性的代数保证，MapReduce 本质上是幺半群折叠
    • 

  • 代数结构提供了跨领域的统一抽象，理解底层结构后可将技术从一个领域迁移到另一个领域
