环与域

核心概念

环（Ring）和域（Field）是在群的基础上增加第二个运算（乘法）而得到的代数结构。环具有加法群结构和乘法满足结合律，域则进一步要求非零元素对乘法构成群。这些结构在计算机科学中无处不在：整数运算基于环论，有限域是密码学和纠错编码的数学基础，多项式环是符号计算和编码理论的核心工具。

从实际应用看，模运算构成的 ℤₙ 是最重要的有限环，而当 p 是素数时，ℤₚ 构成有限域，这正是 RSA 加密和椭圆曲线密码学的理论基础。

环的定义与性质
环的定义：(R, +, ×) 是一个环，若满足：


    

  1. (R, +) 是阿贝尔群
    2. 

  2. 乘法满足结合律
    3. 

  3. 分配律：a×(b+c) = a×b + a×c 和 (a+b)×c = a×c + b×c
    4. 



若乘法有单位元 1，称为含幺环。若乘法交换，称为交换环。


interface Ring<T> {
  elements: T[];
  add: (a: T, b: T) => T;
  multiply: (a: T, b: T) => T;
  zero: T;
  one: T;
  negate: (a: T) => T;
  equals: (a: T, b: T) => boolean;
}

function createZnRing(n: number): Ring<number> {
  return {
    elements: Array.from({ length: n }, (_, i) => i),
    add: (a, b) => (a + b) % n,
    multiply: (a, b) => (a * b) % n,
    zero: 0,
    one: 1,
    negate: (a) => (n - a) % n,
    equals: (a, b) => a === b,
  };
}

function findZeroDivisors<T>(ring: Ring<T>): Array<[T, T]> {
  const zeroDivisors: Array<[T, T]> = [];
  for (const a of ring.elements) {
    if (ring.equals(a, ring.zero)) continue;
    for (const b of ring.elements) {
      if (ring.equals(b, ring.zero)) continue;
      if (ring.equals(ring.multiply(a, b), ring.zero)) {
        zeroDivisors.push([a, b]);
      }
    }
  }
  return zeroDivisors;
}

function findUnits<T>(ring: Ring<T>): T[] {
  return ring.elements.filter((a) => ring.elements.some((b) => ring.equals(ring.multiply(a, b), ring.one)));
}
零因子：非零元素 a, b 满足 a×b = 0。整环是没有零因子的交换含幺环。


可逆元（单位）：元素 a 若存在 b 使得 a×b = b×a = 1，则 a 是可逆元。ℤₙ 中 a 可逆当且仅当 gcd(a, n) = 1。


有限域理论
域是每个非零元素都可逆的交换含幺环。有限域（也称 Galois 域）在密码学和编码理论中有核心地位。


有限域存在定理：有限域的阶必为素数幂 p^k。对每个素数幂 q = p^k，恰好存在一个（同构意义下）q 阶有限域，记为 GF(q) 或 𝔽q。


function createGFp(p: number): Ring<number> & { inverse: (a: number) => number } {
  const ring = createZnRing(p);

  function modPow(base: number, exp: number, mod: number): number {
    let result = 1;
    base %= mod;
    while (exp > 0) {
      if (exp & 1) result = (result * base) % mod;
      exp >>= 1;
      base = (base * base) % mod;
    }
    return result;
  }

  return {
    ...ring,
    inverse: (a: number) => {
      if (a === 0) throw new Error('Zero has no inverse');
      return modPow(a, p - 2, p);
    },
  };
}

function extendedGcd(a: number, b: number): { gcd: number; x: number; y: number } {
  if (a === 0) return { gcd: b, x: 0, y: 1 };
  const { gcd, x, y } = extendedGcd(b % a, a);
  return { gcd, x: y - Math.floor(b / a) * x, y: x };
}

function modularInverse(a: number, m: number): number {
  const { gcd, x } = extendedGcd(a % m, m);
  if (gcd !== 1) throw new Error('Inverse does not exist');
  return ((x % m) + m) % m;
}
多项式环
多项式环 R[x] 是系数在环 R 中的多项式构成的环。多项式运算（加法和乘法）继承了系数环的结构。


当 R 是域时，R[x] 是欧几里得整环，可以进行带余除法。这是 GF(p^k) 构造的基础：GF(p^k) = GF(p)[x] / (f(x))，其中 f(x) 是 GF(p) 上的 k 次不可约多项式。


class Polynomial {
  readonly coeffs: number[];
  private readonly mod: number;

  constructor(coeffs: number[], mod: number) {
    this.mod = mod;
    this.coeffs = coeffs.map((c) => ((c % mod) + mod) % mod);
    while (this.coeffs.length > 1 && this.coeffs[this.coeffs.length - 1] === 0) {
      this.coeffs.pop();
    }
  }

  degree(): number {
    return this.coeffs.length - 1;
  }

  add(other: Polynomial): Polynomial {
    const maxLen = Math.max(this.coeffs.length, other.coeffs.length);
    const result = new Array(maxLen).fill(0);
    for (let i = 0; i < maxLen; i++) {
      result[i] = ((this.coeffs[i] ?? 0) + (other.coeffs[i] ?? 0)) % this.mod;
    }
    return new Polynomial(result, this.mod);
  }

  multiply(other: Polynomial): Polynomial {
    const result = new Array(this.coeffs.length + other.coeffs.length - 1).fill(0);
    for (let i = 0; i < this.coeffs.length; i++) {
      for (let j = 0; j < other.coeffs.length; j++) {
        result[i + j] = (result[i + j] + this.coeffs[i] * other.coeffs[j]) % this.mod;
      }
    }
    return new Polynomial(result, this.mod);
  }

  divmod(divisor: Polynomial): { quotient: Polynomial; remainder: Polynomial } {
    let remainder = [...this.coeffs];
    const quotient = new Array(Math.max(0, remainder.length - divisor.coeffs.length + 1)).fill(0);
    const leadInv = modularInverse(divisor.coeffs[divisor.coeffs.length - 1], this.mod);

    while (remainder.length >= divisor.coeffs.length) {
      const coeff = (remainder[remainder.length - 1] * leadInv) % this.mod;
      const pos = remainder.length - divisor.coeffs.length;
      quotient[pos] = coeff;

      for (let i = 0; i < divisor.coeffs.length; i++) {
        remainder[pos + i] = (remainder[pos + i] - ((coeff * divisor.coeffs[i]) % this.mod) + this.mod) % this.mod;
      }
      remainder.pop();
    }

    return {
      quotient: new Polynomial(quotient, this.mod),
      remainder: new Polynomial(remainder.length ? remainder : [0], this.mod),
    };
  }
}

理想与商环
理想（Ideal）是环中满足特殊吸收性质的子环。理想 I 满足：对任意 r ∈ R 和 a ∈ I，有 r×a ∈ I 和 a×r ∈ I。


商环 R/I 是通过理想 I 对环 R 进行"模运算"得到的新环。ℤ/nℤ = ℤₙ 就是最常见的商环。


理想在代数几何和编码理论中有深刻应用。多项式的理想对应代数簇（零点集），这是代数几何的出发点。

小结
    

  • 环在群的基础上增加了乘法运算和分配律，域进一步要求非零元素可逆
    • 

  • 有限域的阶必为素数幂，GF(p) = ℤₚ 是最基本的有限域，GF(p^k) 通过不可约多项式构造
    • 

  • 多项式环在域上可进行欧几里得除法，是构造扩域和编码理论的核心工具
    • 

  • 理想是环论中的核心概念，商环 R/I 推广了模运算
    • 

  • 有限域理论是现代密码学（RSA、ECC）和纠错编码（RS 码、BCH 码）的数学基础
