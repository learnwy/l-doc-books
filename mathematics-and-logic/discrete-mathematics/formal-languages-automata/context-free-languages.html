上下文无关语言

核心概念

上下文无关语言（Context-Free Language, CFL）是形式语言层次中正则语言的上一级，由上下文无关文法（Context-Free Grammar, CFG）生成，也可以由下推自动机（Pushdown Automaton, PDA）识别。CFG 是编程语言语法定义的标准工具——几乎所有编程语言的语法都用 CFG 或其变体描述。

CFL 比正则语言强大得多，能够表达嵌套结构（如括号匹配、嵌套的 if-else）和递归结构。编译器的语法分析（parsing）阶段就是将 token 流按照 CFG 构建语法树的过程。

上下文无关文法
CFG 定义：G = (V, Σ, P, S)，其中 V 是变量集（非终结符），Σ 是终结符集，P 是产生式规则集（形如 A → α），S 是起始变量。


产生式的形式是 A → α，其中 A ∈ V，α ∈ (V ∪ Σ)*。"上下文无关"的含义是：替换 A 时不需要考虑 A 的上下文。


interface CFG {
  variables: Set<string>;
  terminals: Set<string>;
  productions: Map<string, string[][]>;
  startSymbol: string;
}

function generateStrings(cfg: CFG, maxDepth: number): Set<string> {
  const results = new Set<string>();

  function derive(sentential: string[], depth: number): void {
    if (depth > maxDepth) return;

    const variableIdx = sentential.findIndex((s) => cfg.variables.has(s));
    if (variableIdx === -1) {
      results.add(sentential.join(''));
      return;
    }

    const variable = sentential[variableIdx];
    for (const production of cfg.productions.get(variable) ?? []) {
      const newSentential = [...sentential.slice(0, variableIdx), ...production, ...sentential.slice(variableIdx + 1)];
      derive(newSentential, depth + 1);
    }
  }

  derive([cfg.startSymbol], 0);
  return results;
}

function isAmbiguous(cfg: CFG, word: string, maxDepth: number): boolean {
  let parseCount = 0;

  function countDerivations(sentential: string[], depth: number): void {
    if (depth > maxDepth || parseCount > 1) return;

    const variableIdx = sentential.findIndex((s) => cfg.variables.has(s));
    if (variableIdx === -1) {
      if (sentential.join('') === word) parseCount++;
      return;
    }

    const variable = sentential[variableIdx];
    for (const production of cfg.productions.get(variable) ?? []) {
      const newSentential = [...sentential.slice(0, variableIdx), ...production, ...sentential.slice(variableIdx + 1)];
      countDerivations(newSentential, depth + 1);
    }
  }

  countDerivations([cfg.startSymbol], 0);
  return parseCount > 1;
}
Chomsky 范式与 CYK 算法
Chomsky 范式（CNF）：每个产生式形如 A → BC 或 A → a（B, C 是变量，a 是终结符）。任何 CFG 都可以转换为 CNF。


CNF 的重要性在于它使 CYK 算法（Cocke-Younger-Kasami）成为可能，这是一个 O(n³) 时间的成员判定算法，基于动态规划。


function cykParse(cfg: CFG, input: string[]): boolean {
  const n = input.length;
  if (n === 0) return false;

  const table: Set<string>[][] = Array.from({ length: n }, () => Array.from({ length: n }, () => new Set()));

  for (let i = 0; i < n; i++) {
    for (const [variable, prods] of cfg.productions) {
      for (const prod of prods) {
        if (prod.length === 1 && prod[0] === input[i]) {
          table[i][i].add(variable);
        }
      }
    }
  }

  for (let len = 2; len <= n; len++) {
    for (let i = 0; i <= n - len; i++) {
      const j = i + len - 1;
      for (let k = i; k < j; k++) {
        for (const [variable, prods] of cfg.productions) {
          for (const prod of prods) {
            if (prod.length === 2) {
              if (table[i][k].has(prod[0]) && table[k + 1][j].has(prod[1])) {
                table[i][j].add(variable);
              }
            }
          }
        }
      }
    }
  }

  return table[0][n - 1].has(cfg.startSymbol);
}
下推自动机
下推自动机（PDA）是带有无限栈的有限自动机。PDA = (Q, Σ, Γ, δ, q₀, Z₀, F)，其中 Γ 是栈字母表，Z₀ 是栈底符号。


非确定性 PDA 与 CFG 在表达能力上等价。但确定性 PDA（DPDA）严格弱于非确定性 PDA——存在 CFL 无法被 DPDA 识别（如 {ww^R | w ∈ Σ*}）。


interface PDA {
  states: number[];
  inputAlphabet: string[];
  stackAlphabet: string[];
  transitions: Array<{
    fromState: number;
    inputSymbol: string | null;
    stackTop: string;
    toState: number;
    stackPush: string[];
  }>;
  startState: number;
  initialStackSymbol: string;
  acceptStates: Set<number>;
}

function pdaAccepts(pda: PDA, input: string): boolean {
  type Config = { state: number; pos: number; stack: string[] };
  const initial: Config = {
    state: pda.startState,
    pos: 0,
    stack: [pda.initialStackSymbol],
  };

  const queue: Config[] = [initial];
  const visited = new Set<string>();

  while (queue.length > 0) {
    const config = queue.shift()!;
    const key = `${config.state},${config.pos},${config.stack.join('')}`;
    if (visited.has(key)) continue;
    visited.add(key);

    if (config.pos === input.length && pda.acceptStates.has(config.state)) {
      return true;
    }

    if (config.stack.length === 0) continue;
    const stackTop = config.stack[config.stack.length - 1];

    for (const trans of pda.transitions) {
      if (trans.fromState !== config.state) continue;
      if (trans.stackTop !== stackTop) continue;

      const matchesInput =
        trans.inputSymbol === null || (config.pos < input.length && input[config.pos] === trans.inputSymbol);

      if (matchesInput) {
        const newStack = [...config.stack.slice(0, -1), ...trans.stackPush.reverse()];
        queue.push({
          state: trans.toState,
          pos: config.pos + (trans.inputSymbol !== null ? 1 : 0),
          stack: newStack,
        });
      }
    }
  }
  return false;
}

CFL 的封闭性与判定问题
CFL 在并集、连接和 Kleene 星下封闭，但在交集和补集下不封闭。这与正则语言形成鲜明对比。


CFL 的泵引理：若 L 是 CFL，则存在常数 p，对 L 中任何长度 ≥ p 的字符串 w，可以分解为 w = uvxyz，满足：|vy| > 0，|vxy| ≤ p，∀i ≥ 0，uv^i xy^i z ∈ L。

小结
    

  • 上下文无关文法是编程语言语法定义的标准工具，能表达嵌套和递归结构
    • 

  • CYK 算法基于 Chomsky 范式在 O(n³) 时间内判定成员问题
    • 

  • 非确定性 PDA 与 CFG 等价，但确定性 PDA 严格弱于非确定性 PDA
    • 

  • CFL 在并、连接、星下封闭，但在交集和补集下不封闭
    • 

  • CFL 的等价性和包含性判定不可判定，这限制了自动化分析的能力
