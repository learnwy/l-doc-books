图灵机

核心概念

图灵机（Turing Machine）是 Alan Turing 在 1936 年提出的抽象计算模型，它定义了"可计算"的数学边界。图灵机由有限状态控制器、无限读写带和读写头组成，能够读取、写入和移动读写头。Church-Turing 论题断言：任何直觉上"可计算"的函数都可以被图灵机计算，这意味着图灵机的计算能力等价于所有合理的计算模型。

图灵机的意义远超纯理论：它是现代计算机的理论原型，是算法复杂性理论的基础模型，也是可判定性理论的核心工具。理解图灵机，就是理解"计算的本质与极限"——什么可以被计算，什么原则上不可能被计算。

图灵机的形式化定义与模拟
图灵机 M = (Q, Σ, Γ, δ, q₀, q_accept, q_reject) 由七元组定义：


    

  • Q：有限状态集
    • 

  • Σ：输入字母表（不含空白符 ⊔）
    • 

  • Γ：带字母表（Σ ⊂ Γ，⊔ ∈ Γ）
    • 

  • δ: Q × Γ → Q × Γ × {L, R}：转移函数
    • 

  • q₀：初始状态
    • 

  • q_accept：接受状态
    • 

  • q_reject：拒绝状态（q_accept ≠ q_reject）
    • 



type Direction = 'L' | 'R';

interface TuringMachine {
  states: string[];
  inputAlphabet: string[];
  tapeAlphabet: string[];
  transition: Map<string, { nextState: string; write: string; move: Direction }>;
  startState: string;
  acceptState: string;
  rejectState: string;
}

interface TMConfiguration {
  tape: Map<number, string>;
  head: number;
  state: string;
}

function simulateTM(
  tm: TuringMachine,
  input: string,
  maxSteps: number,
): { accepted: boolean; halted: boolean; steps: number; tape: string } {
  const tape = new Map<number, string>();
  for (let i = 0; i < input.length; i++) tape.set(i, input[i]);

  let head = 0;
  let state = tm.startState;
  let steps = 0;

  while (steps < maxSteps) {
    if (state === tm.acceptState) return { accepted: true, halted: true, steps, tape: tapeToString(tape) };
    if (state === tm.rejectState) return { accepted: false, halted: true, steps, tape: tapeToString(tape) };

    const symbol = tape.get(head) ?? '⊔';
    const key = `${state},${symbol}`;
    const rule = tm.transition.get(key);

    if (!rule) return { accepted: false, halted: true, steps, tape: tapeToString(tape) };

    tape.set(head, rule.write);
    state = rule.nextState;
    head += rule.move === 'R' ? 1 : -1;
    steps++;
  }

  return { accepted: false, halted: false, steps, tape: tapeToString(tape) };
}

function tapeToString(tape: Map<number, string>): string {
  if (tape.size === 0) return '⊔';
  const keys = [...tape.keys()].sort((a, b) => a - b);
  const min = keys[0];
  const max = keys[keys.length - 1];
  let result = '';
  for (let i = min; i <= max; i++) result += tape.get(i) ?? '⊔';
  return result;
}

function createBinaryAdder(): TuringMachine {
  return {
    states: ['start', 'carry0', 'carry1', 'done', 'accept', 'reject'],
    inputAlphabet: ['0', '1', '+'],
    tapeAlphabet: ['0', '1', '+', '=', '⊔'],
    transition: new Map([
      ['start,0', { nextState: 'start', write: '0', move: 'R' as Direction }],
      ['start,1', { nextState: 'start', write: '1', move: 'R' as Direction }],
      ['start,⊔', { nextState: 'carry0', write: '⊔', move: 'L' as Direction }],
      ['carry0,0', { nextState: 'carry0', write: '0', move: 'L' as Direction }],
      ['carry0,1', { nextState: 'carry0', write: '1', move: 'L' as Direction }],
      ['carry0,⊔', { nextState: 'accept', write: '⊔', move: 'R' as Direction }],
    ]),
    startState: 'start',
    acceptState: 'accept',
    rejectState: 'reject',
  };
}
通用图灵机与可枚举性
通用图灵机（Universal Turing Machine, UTM）是能够模拟任何其他图灵机的图灵机。UTM 的输入是目标图灵机 M 的编码 ⟨M⟩ 和输入 w，UTM 模拟 M 在 w 上的计算。


UTM 的存在具有深远意义：它是存储程序计算机的理论原型——程序和数据都是带上的符号串，不需要为每个问题制造不同的硬件。


function encodeTransition(state: number, read: number, nextState: number, write: number, move: number): string {
  return `${'1'.repeat(state + 1)}0${'1'.repeat(read + 1)}0${'1'.repeat(nextState + 1)}0${'1'.repeat(write + 1)}0${'1'.repeat(move + 1)}`;
}

function encodeTM(tm: TuringMachine): string {
  const stateMap = new Map<string, number>();
  tm.states.forEach((s, i) => stateMap.set(s, i));

  const symbolMap = new Map<string, number>();
  tm.tapeAlphabet.forEach((s, i) => symbolMap.set(s, i));

  const rules: string[] = [];
  for (const [key, value] of tm.transition) {
    const [state, symbol] = key.split(',');
    rules.push(
      encodeTransition(
        stateMap.get(state)!,
        symbolMap.get(symbol)!,
        stateMap.get(value.nextState)!,
        symbolMap.get(value.write)!,
        value.move === 'R' ? 0 : 1,
      ),
    );
  }
  return rules.join('00');
}

interface UniversalTM {
  simulate: (encoded: string, input: string, maxSteps: number) => boolean | null;
}

function createUTM(): UniversalTM {
  return {
    simulate(encoded: string, input: string, maxSteps: number): boolean | null {
      const rules = encoded.split('00').map((rule) => {
        const parts = rule.split('0').map((s) => s.length - 1);
        return { state: parts[0], read: parts[1], nextState: parts[2], write: parts[3], move: parts[4] };
      });

      const tape = new Map<number, number>();
      for (let i = 0; i < input.length; i++) tape.set(i, input.charCodeAt(i) - 48);

      let state = 0;
      let head = 0;

      for (let step = 0; step < maxSteps; step++) {
        const symbol = tape.get(head) ?? 0;
        const rule = rules.find((r) => r.state === state && r.read === symbol);
        if (!rule) return false;

        tape.set(head, rule.write);
        state = rule.nextState;
        head += rule.move === 0 ? 1 : -1;
      }
      return null;
    },
  };
}
停机问题与不可判定性
停机问题（Halting Problem）是最著名的不可判定问题：不存在图灵机 H，对任意图灵机 M 和输入 w，H 都能判定 M 在 w 上是否停机。


Turing 的证明使用了对角化论证：假设存在判定停机问题的图灵机 H，构造图灵机 D，D 在输入 ⟨M⟩ 上调用 H(⟨M, ⟨M⟩⟩)——若 H 说"停机"则 D 进入无限循环，若 H 说"不停机"则 D 停机。考虑 D(⟨D⟩) 的行为导致矛盾。


function haltingProblemReduction() {
  type Oracle = (machineCode: string, input: string) => boolean;

  function constructParadox(halt: Oracle): (input: string) => boolean {
    return (input: string): boolean => {
      const doesHalt = halt(input, input);
      if (doesHalt) {
        while (true) {}
      }
      return true;
    };
  }

  return { constructParadox };
}

计算复杂性初步
图灵机不仅定义了可计算性的边界，还提供了衡量计算效率的框架。时间复杂度 T(n) 和空间复杂度 S(n) 分别衡量图灵机在长度为 n 的输入上使用的步数和带格数。


P 与 NP：P 类包含所有多项式时间可判定的语言，NP 类包含所有多项式时间可验证的语言。P ⊆ NP 显然成立，但 P ≟ NP 是计算机科学最重要的未解决问题。

小结
    

  • 图灵机是定义"可计算"的标准模型，Church-Turing 论题断言其计算能力等价于所有合理计算模型
    • 

  • 通用图灵机能模拟任意图灵机，是存储程序计算机的理论原型
    • 

  • 停机问题是最基本的不可判定问题，Rice 定理将不可判定性推广到所有非平凡的语言性质
    • 

  • 图灵机变体（多带、非确定性）在计算能力上与标准图灵机等价，但提供了复杂性分析的不同视角
    • 

  • P vs NP 问题建立在图灵机模型之上，是计算机科学最重要的理论问题
