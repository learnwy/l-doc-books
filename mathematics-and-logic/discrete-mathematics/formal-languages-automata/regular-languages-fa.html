正则语言与有限自动机

核心概念

正则语言（Regular Language）和有限自动机（Finite Automaton, FA）是形式语言理论的基础层。正则语言是最简单的一类形式语言，可以用正则表达式描述，也可以用有限自动机识别。这三种等价描述——正则表达式、确定性有限自动机（DFA）和非确定性有限自动机（NFA）——构成了正则语言理论的核心三位一体。

在计算机科学中，正则语言的应用无处不在：词法分析器（lexer）将源代码分解为 token，文本编辑器的搜索功能使用正则匹配，网络协议的报文格式验证基于正则模式，编译器的前端就是从正则语言出发构建的。

DFA 与 NFA
确定性有限自动机 DFA = (Q, Σ, δ, q₀, F)：状态集 Q、字母表 Σ、转移函数 δ: Q × Σ → Q、初始状态 q₀、接受状态集 F。DFA 对每个输入符号恰好有一个转移。


非确定性有限自动机 NFA 允许同一状态对同一输入有多个转移（包括无输入的 ε-转移）。NFA 接受一个字符串当且仅当存在某条路径到达接受状态。


interface DFA {
  states: number[];
  alphabet: string[];
  transition: Map<string, number>;
  startState: number;
  acceptStates: Set<number>;
}

function dfaAccepts(dfa: DFA, input: string): boolean {
  let current = dfa.startState;

  for (const char of input) {
    const key = `${current},${char}`;
    const next = dfa.transition.get(key);
    if (next === undefined) return false;
    current = next;
  }

  return dfa.acceptStates.has(current);
}

interface NFA {
  states: number[];
  alphabet: string[];
  transition: Map<string, Set<number>>;
  startState: number;
  acceptStates: Set<number>;
}

function nfaAccepts(nfa: NFA, input: string): boolean {
  let currentStates = epsilonClosure(nfa, new Set([nfa.startState]));

  for (const char of input) {
    const nextStates = new Set<number>();
    for (const state of currentStates) {
      const key = `${state},${char}`;
      for (const next of nfa.transition.get(key) ?? []) {
        nextStates.add(next);
      }
    }
    currentStates = epsilonClosure(nfa, nextStates);
  }

  for (const state of currentStates) {
    if (nfa.acceptStates.has(state)) return true;
  }
  return false;
}

function epsilonClosure(nfa: NFA, states: Set<number>): Set<number> {
  const closure = new Set(states);
  const stack = [...states];

  while (stack.length > 0) {
    const state = stack.pop()!;
    for (const next of nfa.transition.get(`${state},ε`) ?? []) {
      if (!closure.has(next)) {
        closure.add(next);
        stack.push(next);
      }
    }
  }
  return closure;
}
子集构造与 NFA 到 DFA 转换
子集构造（Subset Construction）将 NFA 转换为等价的 DFA。核心思想：DFA 的每个状态对应 NFA 的一个状态子集。


function nfaToDfa(nfa: NFA): DFA {
  const startClosure = epsilonClosure(nfa, new Set([nfa.startState]));
  const stateMap = new Map<string, number>();
  const dfaTransition = new Map<string, number>();
  const dfaAccept = new Set<number>();
  let stateCounter = 0;

  function stateKey(states: Set<number>): string {
    return [...states].sort().join(',');
  }

  function getOrCreateState(states: Set<number>): number {
    const key = stateKey(states);
    if (stateMap.has(key)) return stateMap.get(key)!;
    const id = stateCounter++;
    stateMap.set(key, id);

    for (const s of states) {
      if (nfa.acceptStates.has(s)) {
        dfaAccept.add(id);
        break;
      }
    }
    return id;
  }

  const startId = getOrCreateState(startClosure);
  const queue: Array<{ states: Set<number>; id: number }> = [{ states: startClosure, id: startId }];
  const visited = new Set<string>();

  while (queue.length > 0) {
    const { states, id } = queue.shift()!;
    const key = stateKey(states);
    if (visited.has(key)) continue;
    visited.add(key);

    for (const char of nfa.alphabet) {
      const nextStates = new Set<number>();
      for (const s of states) {
        for (const next of nfa.transition.get(`${s},${char}`) ?? []) {
          nextStates.add(next);
        }
      }
      const closure = epsilonClosure(nfa, nextStates);
      if (closure.size === 0) continue;

      const nextId = getOrCreateState(closure);
      dfaTransition.set(`${id},${char}`, nextId);
      queue.push({ states: closure, id: nextId });
    }
  }

  return {
    states: Array.from({ length: stateCounter }, (_, i) => i),
    alphabet: nfa.alphabet,
    transition: dfaTransition,
    startState: startId,
    acceptStates: dfaAccept,
  };
}
DFA 最小化
DFA 最小化算法找到与给定 DFA 等价的状态数最少的 DFA。基于 Myhill-Nerode 定理：正则语言 L 的最小 DFA 的状态数等于 L 关于右同余的等价类数目。


Hopcroft 算法（划分细化法）：从"接受状态"和"非接受状态"两个分区开始，反复细化分区，直到不能再分为止。


function minimizeDFA(dfa: DFA): DFA {
  const { states, alphabet, transition, startState, acceptStates } = dfa;
  const nonAccept = new Set(states.filter((s) => !acceptStates.has(s)));
  let partitions: Set<number>[] = [];

  if (acceptStates.size > 0) partitions.push(new Set(acceptStates));
  if (nonAccept.size > 0) partitions.push(nonAccept);

  let changed = true;
  while (changed) {
    changed = false;
    const newPartitions: Set<number>[] = [];

    for (const partition of partitions) {
      const splits = splitPartition(partition, partitions, alphabet, transition);
      if (splits.length > 1) changed = true;
      newPartitions.push(...splits);
    }
    partitions = newPartitions;
  }

  const stateToPartition = new Map<number, number>();
  for (let i = 0; i < partitions.length; i++) {
    for (const s of partitions[i]) stateToPartition.set(s, i);
  }

  const newTransition = new Map<string, number>();
  const newAccept = new Set<number>();
  const newStart = stateToPartition.get(startState)!;

  for (let i = 0; i < partitions.length; i++) {
    const rep = [...partitions[i]][0];
    if (acceptStates.has(rep)) newAccept.add(i);

    for (const char of alphabet) {
      const next = transition.get(`${rep},${char}`);
      if (next !== undefined) {
        newTransition.set(`${i},${char}`, stateToPartition.get(next)!);
      }
    }
  }

  return {
    states: Array.from({ length: partitions.length }, (_, i) => i),
    alphabet,
    transition: newTransition,
    startState: newStart,
    acceptStates: newAccept,
  };
}

function splitPartition(
  partition: Set<number>,
  allPartitions: Set<number>[],
  alphabet: string[],
  transition: Map<string, number>,
): Set<number>[] {
  for (const char of alphabet) {
    const groups = new Map<number, Set<number>>();
    for (const state of partition) {
      const next = transition.get(`${state},${char}`);
      const targetPartition = next !== undefined ? allPartitions.findIndex((p) => p.has(next)) : -1;
      if (!groups.has(targetPartition)) groups.set(targetPartition, new Set());
      groups.get(targetPartition)!.add(state);
    }
    if (groups.size > 1) return [...groups.values()];
  }
  return [partition];
}

泵引理与正则语言局限性
正则语言的泵引理（Pumping Lemma）用于证明某些语言不是正则的。


若 L 是正则语言，则存在常数 p（泵长度），对 L 中任何长度 ≥ p 的字符串 w，可以分解为 w = xyz，满足：|y| > 0，|xy| ≤ p，∀i ≥ 0，xy^i z ∈ L。


经典的非正则语言包括：{aⁿbⁿ | n ≥ 0}、{ww | w ∈ Σ*}、{aⁿ | n 是素数}。


function pumpingLemmaCheck(language: (s: string) => boolean, p: number, testWord: string): boolean {
  for (let i = 1; i <= Math.min(p, testWord.length); i++) {
    for (let j = i; j <= Math.min(p, testWord.length); j++) {
      const x = testWord.slice(0, i - 1);
      const y = testWord.slice(i - 1, j);
      const z = testWord.slice(j);

      if (y.length === 0 || x.length + y.length > p) continue;

      let allInLanguage = true;
      for (let k = 0; k <= 5; k++) {
        const pumped = x + y.repeat(k) + z;
        if (!language(pumped)) {
          allInLanguage = false;
          break;
        }
      }
      if (allInLanguage) return true;
    }
  }
  return false;
}
小结
    

  • DFA 和 NFA 在表达能力上等价，但 DFA 匹配效率为 O(n)，NFA 转 DFA 可能导致状态指数爆炸
    • 

  • 子集构造将 NFA 转换为 DFA，Hopcroft 算法将 DFA 最小化到唯一的最优形式
    • 

  • 正则语言在并、交、补、连接、Kleene 星下封闭，这些封闭性质是词法分析器设计的基础
    • 

  • 泵引理提供了证明非正则性的工具，{aⁿbⁿ} 等语言超出了有限自动机的能力
    • 

  • 正则语言理论是编译器前端、文本处理和协议验证的数学基础
    •
