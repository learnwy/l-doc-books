递推关系

核心概念

递推关系（Recurrence Relation）是用序列前面的项来定义后续项的等式。递推关系是算法分析的核心数学工具——每一个递归算法都对应一个递推关系，而分析算法复杂度的本质就是求解递推关系。从 Fibonacci 数列到归并排序的 T(n) = 2T(n/2) + O(n)，递推关系无处不在。

求解递推关系的方法包括：迭代法、特征方程法、主定理、生成函数法和递推树法。不同的递推形式适合不同的求解方法。

线性齐次递推
线性齐次递推的一般形式为：aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ + ... + cₖaₙ₋ₖ


求解步骤：


    

  1. 写出特征方程：xᵏ - c₁xᵏ⁻¹ - c₂xᵏ⁻² - ... - cₖ = 0
    2. 

  2. 求特征根 r₁, r₂, ..., rₖ
    3. 

  3. 写出通解，用初始条件确定系数
    4. 



若特征根互不相同：aₙ = A₁r₁ⁿ + A₂r₂ⁿ + ... + Aₖrₖⁿ


若有重根 r 的重数为 m：对应 (A₁ + A₂n + ... + Aₘnᵐ⁻¹)rⁿ


interface RecurrenceSolution {
  roots: Array<{ value: number; multiplicity: number }>;
  coefficients: number[];
}

function solveQuadraticCharacteristic(c1: number, c2: number, a0: number, a1: number): RecurrenceSolution {
  const discriminant = c1 * c1 + 4 * c2;

  if (Math.abs(discriminant) < 1e-10) {
    const r = c1 / 2;
    const A = a0;
    const B = (a1 - a0 * r) / r;
    return {
      roots: [{ value: r, multiplicity: 2 }],
      coefficients: [A, B],
    };
  }

  const r1 = (c1 + Math.sqrt(discriminant)) / 2;
  const r2 = (c1 - Math.sqrt(discriminant)) / 2;

  const A = (a1 - a0 * r2) / (r1 - r2);
  const B = a0 - A;

  return {
    roots: [
      { value: r1, multiplicity: 1 },
      { value: r2, multiplicity: 1 },
    ],
    coefficients: [A, B],
  };
}

function evaluateClosedForm(solution: RecurrenceSolution, n: number): number {
  let result = 0;
  let coeffIdx = 0;

  for (const root of solution.roots) {
    for (let j = 0; j < root.multiplicity; j++) {
      result += solution.coefficients[coeffIdx] * Math.pow(n, j) * Math.pow(root.value, n);
      coeffIdx++;
    }
  }
  return Math.round(result);
}

function matrixExponentiation(matrix: number[][], power: number, mod: number): number[][] {
  const n = matrix.length;
  let result = Array.from({ length: n }, (_, i) => Array.from({ length: n }, (_, j) => (i === j ? 1 : 0)));

  let base = matrix.map((row) => [...row]);

  while (power > 0) {
    if (power & 1) result = matMul(result, base, mod);
    base = matMul(base, base, mod);
    power >>= 1;
  }
  return result;
}

function matMul(a: number[][], b: number[][], mod: number): number[][] {
  const n = a.length;
  const result = Array.from({ length: n }, () => new Array(n).fill(0));
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) {
      for (let k = 0; k < n; k++) {
        result[i][j] = (result[i][j] + a[i][k] * b[k][j]) % mod;
      }
    }
  }
  return result;
}
矩阵快速幂：k 阶线性递推可以表示为矩阵形式 [aₙ, aₙ₋₁, ..., aₙ₋ₖ₊₁]ᵀ = M · [aₙ₋₁, ..., aₙ₋ₖ]ᵀ。通过矩阵快速幂，可以在 O(k³ log n) 时间内计算第 n 项。


分治递推与主定理
分治算法产生形如 T(n) = aT(n/b) + f(n) 的递推关系。主定理（Master Theorem）提供了直接求解此类递推的公式：


令 c = log_b(a)，则：


    

  • 情况 1：若 f(n) = O(n^{c-ε})，则 T(n) = Θ(n^c)
    • 

  • 情况 2：若 f(n) = Θ(n^c logᵏn)，则 T(n) = Θ(n^c log^{k+1}n)
    • 

  • 情况 3：若 f(n) = Ω(n^{c+ε}) 且 af(n/b) ≤ cf(n)，则 T(n) = Θ(f(n))
    • 



interface MasterTheoremInput {
  a: number;
  b: number;
  fExponent: number;
  fLogFactor: number;
}

function masterTheorem(input: MasterTheoremInput): string {
  const { a, b, fExponent, fLogFactor } = input;
  const c = Math.log(a) / Math.log(b);

  if (fExponent < c - 0.001) {
    return `Case 1: T(n) = Θ(n^${c.toFixed(2)})`;
  }
  if (Math.abs(fExponent - c) < 0.001) {
    return `Case 2: T(n) = Θ(n^${c.toFixed(2)} · log^${fLogFactor + 1}(n))`;
  }
  return `Case 3: T(n) = Θ(n^${fExponent} · log^${fLogFactor}(n))`;
}

递推树与摊还分析
递推树法（Recursion Tree Method）通过可视化递推的展开过程来估计总代价。每个节点代表一次子问题的开销，将所有层的开销相加即得总复杂度。


interface RecursionTreeLevel {
  level: number;
  subproblems: number;
  subproblemSize: number;
  workPerSubproblem: number;
  totalWork: number;
}

function analyzeRecursionTree(a: number, b: number, fOfN: (n: number) => number, n: number): RecursionTreeLevel[] {
  const levels: RecursionTreeLevel[] = [];
  let currentSize = n;
  let currentCount = 1;
  let level = 0;

  while (currentSize >= 1) {
    const workPer = fOfN(currentSize);
    levels.push({
      level,
      subproblems: currentCount,
      subproblemSize: currentSize,
      workPerSubproblem: workPer,
      totalWork: currentCount * workPer,
    });
    currentSize = Math.floor(currentSize / b);
    currentCount *= a;
    level++;
  }
  return levels;
}

function amortizedAnalysis(operations: number[]): {
  actual: number[];
  amortized: number[];
  potential: number[];
} {
  const actual = [...operations];
  const potential = [0];
  const amortized: number[] = [];

  for (let i = 0; i < operations.length; i++) {
    const phi_i = potential[i];
    const phi_next = phi_i + 1 - (operations[i] > 1 ? operations[i] - 1 : 0);
    potential.push(Math.max(0, phi_next));
    amortized.push(actual[i] + potential[i + 1] - phi_i);
  }

  return { actual, amortized, potential: potential.slice(1) };
}
递推树法对于非标准形式的分治递推特别有效，因为它不要求递推严格符合主定理的形式。通过画出前几层并识别模式，通常可以猜出答案，然后用数学归纳法证明。


经典递推序列
许多重要的组合序列由递推关系定义，这些序列在算法和数据结构中反复出现：


function catalanRecurrence(n: number): bigint[] {
  const c: bigint[] = [1n];
  for (let i = 1; i <= n; i++) {
    c.push((2n * BigInt(2 * i - 1) * c[i - 1]) / BigInt(i + 1));
  }
  return c;
}

function hanoiTower(n: number): number {
  if (n === 0) return 0;
  return 2 * hanoiTower(n - 1) + 1;
}

function derangements(n: number): bigint[] {
  const d: bigint[] = [1n, 0n];
  for (let i = 2; i <= n; i++) {
    d.push(BigInt(i - 1) * (d[i - 1] + d[i - 2]));
  }
  return d;
}

function eulerNumbers(n: number): bigint[][] {
  const e: bigint[][] = Array.from({ length: n + 1 }, () => new Array(n + 1).fill(0n));
  e[0][0] = 1n;
  for (let i = 1; i <= n; i++) {
    e[i][0] = 0n;
    for (let j = 1; j <= i; j++) {
      e[i][j] = BigInt(j) * e[i - 1][j] + BigInt(i - j + 1) * e[i - 1][j - 1];
    }
  }
  return e;
}

小结
    

  • 线性齐次递推通过特征方程求解，通项公式由特征根和初始条件唯一确定
    • 

  • 主定理是分析分治算法复杂度的核心工具，通过比较 f(n) 与 n^{log_b(a)} 确定增长阶
    • 

  • 矩阵快速幂将线性递推的计算从 O(n) 加速到 O(k³ log n)，适合计算超大项
    • 

  • 递推树法通过可视化递推展开来估计总代价，对非标准递推特别有效
    • 

  • Catalan 数、错排数等经典递推序列在组合数学和算法设计中反复出现
