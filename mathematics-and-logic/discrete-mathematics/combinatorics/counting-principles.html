计数原理

核心概念

计数原理是组合数学的基石，研究"有多少种方式"这一根本问题。从最基本的加法原理和乘法原理出发，发展出排列、组合、多重集合计数等一系列强大工具。在计算机科学中，计数原理直接应用于算法复杂度分析、密码学安全性评估、概率计算和数据结构设计。

理解计数的关键在于识别问题的结构：是"分步完成"（乘法原理）还是"多种选择"（加法原理）？元素是否有序？是否允许重复？这些基本问题的组合决定了应该使用哪种计数工具。

加法原理与乘法原理
加法原理（Sum Rule）：如果任务可以用 n₁ 种方式完成方案 A，或用 n₂ 种方式完成方案 B，且两种方案互斥，则总方式数为 n₁ + n₂。


乘法原理（Product Rule）：如果任务分为两个连续步骤，第一步有 n₁ 种方式，第二步有 n₂ 种方式，则总方式数为 n₁ × n₂。


这两个原理看似简单，但在复杂问题中正确识别它们是计数的关键挑战：


function countPasswords(
  length: number,
  options: {
    lowercase: boolean;
    uppercase: boolean;
    digits: boolean;
    special: boolean;
  },
): bigint {
  let charsetSize = 0;
  if (options.lowercase) charsetSize += 26;
  if (options.uppercase) charsetSize += 26;
  if (options.digits) charsetSize += 10;
  if (options.special) charsetSize += 32;

  return BigInt(charsetSize) ** BigInt(length);
}

function factorial(n: number): bigint {
  let result = 1n;
  for (let i = 2n; i <= BigInt(n); i++) {
    result *= i;
  }
  return result;
}

function permutation(n: number, r: number): bigint {
  return factorial(n) / factorial(n - r);
}

function combination(n: number, r: number): bigint {
  return factorial(n) / (factorial(r) * factorial(n - r));
}

function multisetPermutation(n: number, groups: number[]): bigint {
  let denominator = 1n;
  for (const g of groups) {
    denominator *= factorial(g);
  }
  return factorial(n) / denominator;
}

function multisetCombination(n: number, r: number): bigint {
  return combination(n + r - 1, r);
}
补数原理：有时直接计数很困难，可以用全集减去不满足条件的情况数。这在计算"至少一个"类型的问题中尤其有用。


二项式定理与恒等式
二项式定理：(x + y)^n = Σ C(n,k) x^k y^(n-k)，其中求和从 k=0 到 n。


二项式系数 C(n,k) 具有丰富的性质和恒等式：


帕斯卡恒等式：C(n,k) = C(n-1,k-1) + C(n-1,k)，这是帕斯卡三角形（杨辉三角）的生成规则，也是动态规划计算组合数的基础。


function pascalTriangle(n: number): bigint[][] {
  const triangle: bigint[][] = [];
  for (let i = 0; i <= n; i++) {
    triangle[i] = [];
    triangle[i][0] = 1n;
    triangle[i][i] = 1n;
    for (let j = 1; j < i; j++) {
      triangle[i][j] = triangle[i - 1][j - 1] + triangle[i - 1][j];
    }
  }
  return triangle;
}

function binomialCoeffModP(n: number, k: number, p: number): number {
  if (k > n) return 0;
  if (k === 0 || k === n) return 1;

  const dp: number[][] = Array.from({ length: n + 1 }, () => new Array(k + 1).fill(0));
  for (let i = 0; i <= n; i++) {
    dp[i][0] = 1;
    for (let j = 1; j <= Math.min(i, k); j++) {
      dp[i][j] = (dp[i - 1][j - 1] + dp[i - 1][j]) % p;
    }
  }
  return dp[n][k];
}
卢卡斯定理：在模素数 p 下，C(n,k) mod p = Π C(nᵢ, kᵢ) mod p，其中 nᵢ 和 kᵢ 是 n 和 k 的 p 进制表示。这在大数组合数取模问题中极为重要。


function lucasTheorem(n: number, k: number, p: number): number {
  if (k === 0) return 1;
  const ni = n % p;
  const ki = k % p;
  if (ki > ni) return 0;
  return (smallComb(ni, ki, p) * lucasTheorem(Math.floor(n / p), Math.floor(k / p), p)) % p;
}

function smallComb(n: number, k: number, p: number): number {
  if (k === 0) return 1;
  let num = 1;
  let den = 1;
  for (let i = 0; i < k; i++) {
    num = (num * (n - i)) % p;
    den = (den * (i + 1)) % p;
  }
  return (num * modInverse(den, p)) % p;
}

function modInverse(a: number, p: number): number {
  return modPow(a, p - 2, p);
}

function modPow(base: number, exp: number, mod: number): number {
  let result = 1;
  base %= mod;
  while (exp > 0) {
    if (exp & 1) result = (result * base) % mod;
    exp >>= 1;
    base = (base * base) % mod;
  }
  return result;
}

function stirlingSecond(n: number, k: number): bigint {
  if (n === 0 && k === 0) return 1n;
  if (n === 0 || k === 0) return 0n;

  const dp: bigint[][] = Array.from({ length: n + 1 }, () => new Array(k + 1).fill(0n));
  dp[0][0] = 1n;
  for (let i = 1; i <= n; i++) {
    for (let j = 1; j <= Math.min(i, k); j++) {
      dp[i][j] = BigInt(j) * dp[i - 1][j] + dp[i - 1][j - 1];
    }
  }
  return dp[n][k];
}

function bellNumber(n: number): bigint {
  let result = 0n;
  for (let k = 0; k <= n; k++) {
    result += stirlingSecond(n, k);
  }
  return result;
}

function integerPartitions(n: number, maxPart: number = n): number {
  if (n === 0) return 1;
  if (n < 0 || maxPart === 0) return 0;

  const dp: number[][] = Array.from({ length: n + 1 }, () => new Array(maxPart + 1).fill(0));
  for (let j = 0; j <= maxPart; j++) dp[0][j] = 1;

  for (let i = 1; i <= n; i++) {
    for (let j = 1; j <= maxPart; j++) {
      dp[i][j] = dp[i][j - 1] + (i >= j ? dp[i - j][j] : 0);
    }
  }
  return dp[n][maxPart];
}
多项式定理与扩展
多项式定理：(x₁ + x₂ + ... + xₖ)^n = Σ [n!/(n₁!n₂!...nₖ!)] x₁^n₁ x₂^n₂ ... xₖ^nₖ


其中求和遍历所有满足 n₁ + n₂ + ... + nₖ = n 的非负整数组。多项系数 n!/(n₁!n₂!...nₖ!) 也等于 C(n,n₁) × C(n-n₁,n₂) × ... 的连乘积。


function multinomialCoeff(n: number, groups: number[]): bigint {
  let result = factorial(n);
  for (const g of groups) {
    result /= factorial(g);
  }
  return result;
}

function enumerateMultinomial(n: number, k: number): number[][] {
  const results: number[][] = [];

  function backtrack(remaining: number, parts: number, current: number[]): void {
    if (parts === 1) {
      results.push([...current, remaining]);
      return;
    }
    for (let i = 0; i <= remaining; i++) {
      current.push(i);
      backtrack(remaining - i, parts - 1, current);
      current.pop();
    }
  }

  backtrack(n, k, []);
  return results;
}
小结
    

  • 加法原理和乘法原理是一切计数问题的基础，正确识别问题结构是解题关键
    • 

  • 二项式系数满足丰富的恒等式，帕斯卡恒等式驱动动态规划计算，卢卡斯定理处理大数取模
    • 

  • 分球入盒的 8 种模型统一了排列组合的各种变体，第二类 Stirling 数和整数分拆是其中的核心
    • 

  • 计数结果直接应用于算法复杂度分析、密码学安全性评估和概率计算
    • 

  • 多项式定理将二项式定理推广到多元情况，是多维计数问题的理论基础
