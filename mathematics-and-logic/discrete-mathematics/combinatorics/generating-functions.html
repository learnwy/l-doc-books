生成函数

核心概念

生成函数（Generating Function）是组合数学中最优雅也最强大的工具之一。其核心思想是将一个数列 {aₙ} 编码为一个形式幂级数 A(x) = Σ aₙxⁿ，从而将计数问题转化为代数运算。这种"序列到函数"的映射将离散的组合恒等式转化为连续的代数等式，使得许多复杂的计数问题变得易于处理。

在计算机科学中，生成函数用于分析算法的平均复杂度、求解递推关系、分析概率分布以及设计高效的多项式乘法算法（FFT）。

普通生成函数
普通生成函数（Ordinary Generating Function, OGF）是最基本的生成函数类型。数列 {a₀, a₁, a₂, ...} 的 OGF 定义为 A(x) = Σ aₙxⁿ。


核心的封闭形式包括：


    

  • 常数列 {1, 1, 1, ...}：A(x) = 1/(1-x)
    • 

  • 几何级数 {1, r, r², ...}：A(x) = 1/(1-rx)
    • 

  • 自然数 {0, 1, 2, 3, ...}：A(x) = x/(1-x)²
    • 

  • Fibonacci 数列：F(x) = x/(1-x-x²)
    • 



class FormalPowerSeries {
  private coeffs: number[];

  constructor(coeffs: number[]) {
    this.coeffs = [...coeffs];
  }

  coefficient(n: number): number {
    return n < this.coeffs.length ? this.coeffs[n] : 0;
  }

  add(other: FormalPowerSeries, maxTerms: number): FormalPowerSeries {
    const result: number[] = [];
    for (let i = 0; i < maxTerms; i++) {
      result.push(this.coefficient(i) + other.coefficient(i));
    }
    return new FormalPowerSeries(result);
  }

  multiply(other: FormalPowerSeries, maxTerms: number): FormalPowerSeries {
    const result: number[] = new Array(maxTerms).fill(0);
    for (let i = 0; i < maxTerms; i++) {
      for (let j = 0; j <= i; j++) {
        result[i] += this.coefficient(j) * other.coefficient(i - j);
      }
    }
    return new FormalPowerSeries(result);
  }

  inverse(maxTerms: number): FormalPowerSeries {
    const result: number[] = [1 / this.coeffs[0]];
    for (let n = 1; n < maxTerms; n++) {
      let sum = 0;
      for (let k = 1; k <= n; k++) {
        sum += this.coefficient(k) * result[n - k];
      }
      result.push(-sum / this.coeffs[0]);
    }
    return new FormalPowerSeries(result);
  }

  static geometric(r: number, maxTerms: number): FormalPowerSeries {
    const coeffs: number[] = [];
    let power = 1;
    for (let i = 0; i < maxTerms; i++) {
      coeffs.push(power);
      power *= r;
    }
    return new FormalPowerSeries(coeffs);
  }
}
卷积定理：两个 OGF 的乘积 C(x) = A(x)·B(x) 对应数列的卷积 cₙ = Σ aₖb_{n-k}。这个性质使得生成函数成为求解卷积型递推的利器。


指数生成函数
指数生成函数（Exponential Generating Function, EGF）将数列 {aₙ} 编码为 A(x) = Σ aₙxⁿ/n!。EGF 特别适合处理有标号（labeled）对象的计数。


EGF 乘积的组合含义是二项卷积：cₙ = Σ C(n,k) aₖ b_{n-k}。这对应将 n 个标号对象分成两组，一组按 A 的规则计数，另一组按 B 的规则计数。


重要的 EGF 包括：


    

  • 排列 {n!}：A(x) = 1/(1-x)
    • 

  • 错排 Dₙ：A(x) = e^{-x}/(1-x)
    • 

  • 贝尔数：A(x) = e^{e^x - 1}
    • 



function derangementEGF(maxTerms: number): number[] {
  const result: number[] = [];
  let derangement = 1;
  result.push(derangement);

  for (let n = 1; n < maxTerms; n++) {
    derangement = (n - 1) * (result[n - 1] + (n >= 2 ? result[n - 2] : 0));
    result.push(derangement);
  }
  return result;
}

function catalanNumbers(maxTerms: number): number[] {
  const result: number[] = [1];
  for (let n = 1; n < maxTerms; n++) {
    let cn = 0;
    for (let k = 0; k < n; k++) {
      cn += result[k] * result[n - 1 - k];
    }
    result.push(cn);
  }
  return result;
}

function partitionFunction(n: number): number {
  const dp: number[] = new Array(n + 1).fill(0);
  dp[0] = 1;
  for (let k = 1; k <= n; k++) {
    for (let j = k; j <= n; j++) {
      dp[j] += dp[j - k];
    }
  }
  return dp[n];
}
生成函数求解递推关系
生成函数最强大的应用之一是将递推关系转化为代数方程求解。对于线性递推 aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ + ... + cₖaₙ₋ₖ：


    

  1. 设 A(x) = Σ aₙxⁿ
    2. 

  2. 用递推关系乘以 xⁿ 并求和
    3. 

  3. 识别出 A(x) 的代数关系
    4. 

  4. 求解 A(x) 的封闭形式
    5. 

  5. 展开为幂级数得到通项公式
    6. 



以 Fibonacci 数列为例：F(n) = F(n-1) + F(n-2)，F(0) = 0，F(1) = 1


function solveLinearRecurrence(coefficients: number[], initialValues: number[], n: number): number {
  const k = coefficients.length;
  if (n < initialValues.length) return initialValues[n];

  const values = [...initialValues];
  for (let i = initialValues.length; i <= n; i++) {
    let sum = 0;
    for (let j = 0; j < k; j++) {
      sum += coefficients[j] * values[i - 1 - j];
    }
    values.push(sum);
  }
  return values[n];
}

function fibonacciClosedForm(n: number): number {
  const phi = (1 + Math.sqrt(5)) / 2;
  const psi = (1 - Math.sqrt(5)) / 2;
  return Math.round((phi ** n - psi ** n) / Math.sqrt(5));
}

function characteristicRoots(coefficients: number[]): number[] {
  if (coefficients.length === 2) {
    const [c1, c2] = coefficients;
    const discriminant = c1 * c1 + 4 * c2;
    if (discriminant >= 0) {
      return [(c1 + Math.sqrt(discriminant)) / 2, (c1 - Math.sqrt(discriminant)) / 2];
    }
  }
  return [];
}

快速多项式乘法
生成函数的乘法对应数列的卷积，而卷积可以通过快速傅里叶变换（FFT）在 O(n log n) 时间内完成。这是计算机科学中最重要的算法之一。


function fft(a: [number, number][], invert: boolean): void {
  const n = a.length;
  if (n === 1) return;

  for (let i = 1, j = 0; i < n; i++) {
    let bit = n >> 1;
    for (; j & bit; bit >>= 1) {
      j ^= bit;
    }
    j ^= bit;
    if (i < j) [a[i], a[j]] = [a[j], a[i]];
  }

  for (let len = 2; len <= n; len <<= 1) {
    const ang = ((2 * Math.PI) / len) * (invert ? -1 : 1);
    const wlen: [number, number] = [Math.cos(ang), Math.sin(ang)];

    for (let i = 0; i < n; i += len) {
      let w: [number, number] = [1, 0];
      for (let j = 0; j < len / 2; j++) {
        const u = a[i + j];
        const v: [number, number] = [
          a[i + j + len / 2][0] * w[0] - a[i + j + len / 2][1] * w[1],
          a[i + j + len / 2][0] * w[1] + a[i + j + len / 2][1] * w[0],
        ];
        a[i + j] = [u[0] + v[0], u[1] + v[1]];
        a[i + j + len / 2] = [u[0] - v[0], u[1] - v[1]];
        w = [w[0] * wlen[0] - w[1] * wlen[1], w[0] * wlen[1] + w[1] * wlen[0]];
      }
    }
  }

  if (invert) {
    for (const x of a) {
      x[0] /= n;
      x[1] /= n;
    }
  }
}

function polyMultiply(a: number[], b: number[]): number[] {
  let n = 1;
  while (n < a.length + b.length) n <<= 1;

  const fa: [number, number][] = Array.from({ length: n }, (_, i) => [i < a.length ? a[i] : 0, 0]);
  const fb: [number, number][] = Array.from({ length: n }, (_, i) => [i < b.length ? b[i] : 0, 0]);

  fft(fa, false);
  fft(fb, false);

  for (let i = 0; i < n; i++) {
    const real = fa[i][0] * fb[i][0] - fa[i][1] * fb[i][1];
    const imag = fa[i][0] * fb[i][1] + fa[i][1] * fb[i][0];
    fa[i] = [real, imag];
  }

  fft(fa, true);
  return fa.map(([re]) => Math.round(re)).slice(0, a.length + b.length - 1);
}
小结
    

  • 生成函数将计数序列编码为形式幂级数，将离散组合问题转化为代数运算
    • 

  • OGF 适合无标号对象计数，EGF 适合有标号对象计数，两者乘积含义不同
    • 

  • 线性递推关系可以通过生成函数转化为代数方程求解，得到通项公式
    • 

  • FFT 实现 O(n log n) 的多项式乘法，是卷积计算的核心加速技术
    • 

  • Catalan 数、分拆数等经典序列都有优雅的生成函数表示
    •
