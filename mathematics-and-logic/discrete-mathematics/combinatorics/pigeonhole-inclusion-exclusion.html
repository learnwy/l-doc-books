鸽巢原理与容斥原理

核心概念

鸽巢原理（Pigeonhole Principle）和容斥原理（Inclusion-Exclusion Principle）是组合数学中两个互补的计数工具。鸽巢原理证明"某种情况一定存在"，而容斥原理精确计算"满足条件的数量"。两者在算法设计、概率论和数论中有广泛应用。

鸽巢原理指出：若将 n+1 个对象放入 n 个容器，则至少有一个容器包含两个以上的对象。这个看似显然的原理在数学证明中威力巨大——它能证明存在性，而无需构造性地找出具体解。

容斥原理则解决"至少满足一个条件"的计数问题：|A₁ ∪ A₂ ∪ ... ∪ Aₙ| = Σ|Aᵢ| - Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| - ...

鸽巢原理的应用
简单鸽巢原理：n+1 个对象放入 n 个盒子，至少一个盒子有 ≥2 个对象。


广义鸽巢原理：n 个对象放入 k 个盒子，至少一个盒子有 ≥⌈n/k⌉ 个对象。


鸽巢原理在计算机科学中的经典应用：


哈希冲突：若哈希表大小为 m，存入 m+1 个键，则必存在至少一对冲突。


生日悖论：在 23 个人中，至少两人同一天生日的概率超过 50%。这是密码学中碰撞攻击的理论基础。


循环检测：有限状态序列一定存在循环（Floyd 判环算法的理论基础）。


function birthdayProbability(n: number, d: number = 365): number {
  let prob = 1;
  for (let i = 0; i < n; i++) {
    prob *= (d - i) / d;
  }
  return 1 - prob;
}

function findBirthdayThreshold(targetProb: number, d: number = 365): number {
  let n = 1;
  while (birthdayProbability(n, d) < targetProb) {
    n++;
  }
  return n;
}

function floydCycleDetection<T>(
  f: (x: T) => T,
  x0: T,
  eq: (a: T, b: T) => boolean = (a, b) => a === b,
): { cycleStart: T; cycleLength: number } {
  let slow = f(x0);
  let fast = f(f(x0));

  while (!eq(slow, fast)) {
    slow = f(slow);
    fast = f(f(fast));
  }

  slow = x0;
  while (!eq(slow, fast)) {
    slow = f(slow);
    fast = f(fast);
  }
  const cycleStart = slow;

  let length = 1;
  fast = f(slow);
  while (!eq(slow, fast)) {
    fast = f(fast);
    length++;
  }

  return { cycleStart, cycleLength: length };
}

function pigeonholeProof(items: number[], boxes: number): Map<number, number[]> {
  const distribution = new Map<number, number[]>();
  for (const item of items) {
    const box = item % boxes;
    if (!distribution.has(box)) distribution.set(box, []);
    distribution.get(box)!.push(item);
  }
  return distribution;
}
容斥原理与精确计数
容斥原理的一般形式：


|A₁ ∪ A₂ ∪ ... ∪ Aₙ| = Σᵢ|Aᵢ| - Σᵢ<ⱼ|Aᵢ ∩ Aⱼ| + Σᵢ<ⱼ<ₖ|Aᵢ ∩ Aⱼ ∩ Aₖ| - ... + (-1)^{n-1}|A₁ ∩ A₂ ∩ ... ∩ Aₙ|


function inclusionExclusion(universalSize: number, setSizes: number[], intersectionSizes: Map<string, number>): number {
  const n = setSizes.length;
  let result = 0;

  for (let mask = 1; mask < 1 << n; mask++) {
    const bits: number[] = [];
    for (let i = 0; i < n; i++) {
      if (mask & (1 << i)) bits.push(i);
    }

    const key = bits.sort().join(',');
    let size: number;

    if (bits.length === 1) {
      size = setSizes[bits[0]];
    } else {
      size = intersectionSizes.get(key) ?? 0;
    }

    if (bits.length % 2 === 1) {
      result += size;
    } else {
      result -= size;
    }
  }

  return result;
}

function countSurjections(n: number, k: number): bigint {
  let result = 0n;
  for (let i = 0; i <= k; i++) {
    const sign = i % 2 === 0 ? 1n : -1n;
    const choose = combinationBigInt(k, i);
    const power = BigInt(k - i) ** BigInt(n);
    result += sign * choose * power;
  }
  return result;
}

function combinationBigInt(n: number, k: number): bigint {
  if (k > n - k) k = n - k;
  let result = 1n;
  for (let i = 0; i < k; i++) {
    result = (result * BigInt(n - i)) / BigInt(i + 1);
  }
  return result;
}
错排问题与子集计数
错排（Derangement）是没有元素在原位的排列。错排数 Dₙ 可以通过容斥原理推导：


Dₙ = n! - C(n,1)(n-1)! + C(n,2)(n-2)! - ... = n! Σ (-1)ᵏ/k! (k 从 0 到 n)


当 n 趋向无穷时，Dₙ/n! → 1/e ≈ 0.3679。即随机排列是错排的概率约为 36.79%。


function derangementCount(n: number): bigint {
  if (n === 0) return 1n;
  if (n === 1) return 0n;

  let factN = 1n;
  for (let i = 2; i <= n; i++) factN *= BigInt(i);

  let sum = 0n;
  let sign = 1n;
  let factK = 1n;
  for (let k = 0; k <= n; k++) {
    sum += (sign * factN) / factK;
    sign *= -1n;
    factK *= BigInt(k + 1);
  }
  return sum;
}

function eulerTotient(n: number): number {
  let result = n;
  let temp = n;

  for (let p = 2; p * p <= temp; p++) {
    if (temp % p === 0) {
      while (temp % p === 0) temp /= p;
      result -= result / p;
    }
  }
  if (temp > 1) result -= result / temp;
  return result;
}

function sieveEulerTotient(limit: number): number[] {
  const phi = Array.from({ length: limit + 1 }, (_, i) => i);

  for (let i = 2; i <= limit; i++) {
    if (phi[i] === i) {
      for (let j = i; j <= limit; j += i) {
        phi[j] -= phi[j] / i;
      }
    }
  }
  return phi;
}
Euler 函数 φ(n) 计算小于 n 且与 n 互素的正整数个数。通过容斥原理：φ(n) = n · Π(1 - 1/p)，其中乘积遍历 n 的所有素因子 p。

莫比乌斯反演
莫比乌斯反演是容斥原理在数论中的推广。莫比乌斯函数 μ(n) 定义为：


    

  • μ(1) = 1
    • 

  • μ(n) = (-1)ᵏ 若 n 是 k 个不同素数的乘积
    • 

  • μ(n) = 0 若 n 有平方因子
    • 



莫比乌斯反演公式：若 f(n) = Σ*{d|n} g(d)，则 g(n) = Σ*{d|n} μ(n/d) f(d)


function mobiusFunction(n: number): number {
  if (n === 1) return 1;
  let primeFactors = 0;
  let temp = n;

  for (let p = 2; p * p <= temp; p++) {
    if (temp % p === 0) {
      temp /= p;
      primeFactors++;
      if (temp % p === 0) return 0;
    }
  }
  if (temp > 1) primeFactors++;
  return primeFactors % 2 === 0 ? 1 : -1;
}

function mobiusInversion(f: (n: number) => number, n: number): number {
  let result = 0;
  for (let d = 1; d * d <= n; d++) {
    if (n % d === 0) {
      result += mobiusFunction(n / d) * f(d);
      if (d !== n / d) {
        result += mobiusFunction(d) * f(n / d);
      }
    }
  }
  return result;
}

function countPrimitiveNecklaces(n: number, k: number): number {
  let result = 0;
  for (let d = 1; d * d <= n; d++) {
    if (n % d === 0) {
      result += mobiusFunction(n / d) * Math.pow(k, d);
      if (d !== n / d) {
        result += mobiusFunction(d) * Math.pow(k, n / d);
      }
    }
  }
  return result / n;
}
莫比乌斯反演在竞赛算法中用于求解 GCD 相关的计数问题。例如，计算满足 gcd(i, j) = 1 的有序对 (i, j) 的数量。


小结
    

  • 鸽巢原理提供存在性证明，其广义形式给出定量下界，是哈希分析和密码学的理论基础
    • 

  • 容斥原理通过交替加减精确计算满足条件的数量，核心在于控制交集的计算
    • 

  • 错排公式和 Euler 函数是容斥原理最经典的应用，展示了精确计数的威力
    • 

  • 莫比乌斯反演将容斥推广到数论函数上，是数论计数问题的核心工具
    • 

  • 生日悖论揭示了碰撞概率随样本增长的超线性特征，是密码学安全性分析的基石
    •
