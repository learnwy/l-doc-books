信道容量

核心概念

信道容量（Channel Capacity）是信息论中最核心的概念之一，定义为在给定信道模型下，输入和输出之间互信息的最大值：C = max_{p(x)} I(X;Y)。Shannon 信道编码定理证明了：当传输速率 R < C 时，存在编码方案使错误概率趋于零；当 R > C 时，错误概率必然大于零。

信道容量的物理含义是：通过有噪信道可靠传输信息的最大速率。它不依赖于特定的编码方案，而是信道本身的固有属性。

离散无记忆信道容量
离散无记忆信道（DMC）由输入字母表 X、输出字母表 Y 和转移概率 p(y|x) 完全描述。信道容量通过对输入分布 p(x) 优化互信息得到。


function bscCapacity(p: number): number {
  if (p <= 0 || p >= 1) return 1;
  return 1 + p * Math.log2(p) + (1 - p) * Math.log2(1 - p);
}

function becCapacity(epsilon: number): number {
  return 1 - epsilon;
}

function dmcCapacity(transition: number[][], iterations: number = 1000): { capacity: number; optimalInput: number[] } {
  const nX = transition.length;
  const nY = transition[0].length;
  let px = Array(nX).fill(1 / nX);

  for (let iter = 0; iter < iterations; iter++) {
    const py: number[] = Array(nY).fill(0);
    for (let x = 0; x < nX; x++) {
      for (let y = 0; y < nY; y++) {
        py[y] += px[x] * transition[x][y];
      }
    }

    const qx: number[] = Array(nX).fill(0);
    for (let x = 0; x < nX; x++) {
      let exponent = 0;
      for (let y = 0; y < nY; y++) {
        if (transition[x][y] > 0 && py[y] > 0) {
          exponent += transition[x][y] * Math.log(transition[x][y] / py[y]);
        }
      }
      qx[x] = Math.exp(exponent);
    }

    const qSum = qx.reduce((a, b) => a + b, 0);
    px = qx.map((q) => q / qSum);
  }

  const py: number[] = Array(nY).fill(0);
  for (let x = 0; x < nX; x++) {
    for (let y = 0; y < nY; y++) {
      py[y] += px[x] * transition[x][y];
    }
  }

  let capacity = 0;
  for (let x = 0; x < nX; x++) {
    for (let y = 0; y < nY; y++) {
      if (transition[x][y] > 0 && py[y] > 0) {
        capacity += px[x] * transition[x][y] * Math.log2(transition[x][y] / py[y]);
      }
    }
  }

  return { capacity, optimalInput: px };
}

console.log(`BSC(0.1) 容量: ${bscCapacity(0.1).toFixed(4)} bits`);
console.log(`BSC(0.5) 容量: ${bscCapacity(0.5).toFixed(4)} bits`);
console.log(`BEC(0.3) 容量: ${becCapacity(0.3).toFixed(4)} bits`);

const bscTransition = [
  [0.9, 0.1],
  [0.1, 0.9],
];
const result = dmcCapacity(bscTransition);
console.log(`BSC(0.1) Blahut-Arimoto: ${result.capacity.toFixed(4)} bits`);
console.log(`最优输入: [${result.optimalInput.map((p) => p.toFixed(4)).join(', ')}]`);
Blahut-Arimoto 算法是计算离散信道容量的经典迭代方法，它交替优化输入分布和辅助分布，保证收敛到全局最优。


高斯信道与 Shannon 极限
加性高斯白噪声（AWGN）信道是连续信道中最重要的模型：Y = X + N，其中 N ~ N(0, σ²)。在功率约束 E[X²] ≤ P 下，信道容量为 C = ½ log₂(1 + P/σ²) = ½ log₂(1 + SNR)。


function awgnCapacity(snrDb: number): number {
  const snrLinear = Math.pow(10, snrDb / 10);
  return 0.5 * Math.log2(1 + snrLinear);
}

function awgnCapacityBandwidth(bandwidth: number, snrDb: number): number {
  const snrLinear = Math.pow(10, snrDb / 10);
  return bandwidth * Math.log2(1 + snrLinear);
}

function shannonLimit(rate: number): number {
  const snrRequired = Math.pow(2, 2 * rate) - 1;
  return 10 * Math.log10(snrRequired);
}

function spectralEfficiency(snrDb: number): number {
  return awgnCapacity(snrDb);
}

for (const snr of [-3, 0, 3, 6, 10, 20, 30]) {
  const cap = awgnCapacity(snr);
  console.log(`SNR=${snr}dB: C=${cap.toFixed(4)} bits/symbol, SE=${spectralEfficiency(snr).toFixed(4)} bits/s/Hz`);
}

for (const rate of [0.5, 1, 2, 3]) {
  const limit = shannonLimit(rate);
  console.log(`R=${rate} bits/symbol: Shannon limit = ${limit.toFixed(2)} dB`);
}
Shannon 极限描述了在给定信噪比下理论上可达的最大信息传输速率。现代编码技术（如 Turbo 码、LDPC 码和 Polar 码）已经非常接近这一极限，差距仅为零点几 dB。

多用户信道容量
实际通信系统通常涉及多个用户，多用户信道容量理论描述了这些场景下的性能极限。


function macCapacityRegion(snr1: number, snr2: number, points: number = 100): Array<{ r1: number; r2: number }> {
  const region: Array<{ r1: number; r2: number }> = [];
  const c1 = 0.5 * Math.log2(1 + snr1);
  const c2 = 0.5 * Math.log2(1 + snr2);
  const cSum = 0.5 * Math.log2(1 + snr1 + snr2);

  for (let i = 0; i <= points; i++) {
    const alpha = i / points;
    const r1 = Math.min(c1, alpha * cSum);
    const r2 = Math.min(c2, (1 - alpha) * cSum);
    if (r1 + r2 <= cSum + 1e-10) {
      region.push({ r1, r2 });
    }
  }

  region.push({ r1: 0, r2: cSum });
  region.push({ r1: cSum, r2: 0 });
  region.push({ r1: c1, r2: cSum - c1 });
  region.push({ r1: cSum - c2, r2: c2 });

  return region;
}

function broadcastCapacity(
  totalPower: number,
  noise: number,
  alpha: number,
): {
  r1: number;
  r2: number;
} {
  const p1 = alpha * totalPower;
  const p2 = (1 - alpha) * totalPower;
  const r2 = 0.5 * Math.log2(1 + p2 / (p1 + noise));
  const r1 = 0.5 * Math.log2(1 + p1 / noise);
  return { r1, r2 };
}

const macRegion = macCapacityRegion(10, 5);
console.log(`MAC 容量区域边界点数: ${macRegion.length}`);
console.log(`单用户容量: C1=${(0.5 * Math.log2(1 + 10)).toFixed(4)}, C2=${(0.5 * Math.log2(1 + 5)).toFixed(4)}`);
console.log(`总和容量: ${(0.5 * Math.log2(1 + 15)).toFixed(4)}`);

const bc = broadcastCapacity(10, 1, 0.7);
console.log(`广播信道 (α=0.7): R1=${bc.r1.toFixed(4)}, R2=${bc.r2.toFixed(4)}`);

小结
    

  • 信道容量 C = max I(X;Y) 是可靠传输的速率上限，由 Shannon 编码定理保证
    • 

  • Blahut-Arimoto 算法通过交替优化计算离散信道容量，保证全局收敛
    • 

  • AWGN 信道容量 C = ½ log₂(1+SNR) 是通信工程中的基本公式
    • 

  • 现代编码（LDPC、Polar）已接近 Shannon 极限，差距仅约 0.1 dB
    • 

  • 多用户信道容量理论描述了 MAC、广播、中继等多用户场景的性能极限
    • 

  • 信道容量理论不仅指导通信系统设计，也影响了数据压缩和机器学习领域
