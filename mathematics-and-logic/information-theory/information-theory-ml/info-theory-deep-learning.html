信息论与深度学习

核心概念

信息论与深度学习的交叉是当代机器学习理论最活跃的研究方向之一。信息论为深度学习提供了理解模型学习过程、设计损失函数、分析泛化能力和构建生成模型的理论框架。从 Shannon 信息到变分推断，信息论的核心概念在深度学习的每个层面都有深刻应用。

深度神经网络可以看作一系列信息处理单元，每一层对输入信息进行变换和压缩。信息论视角帮助我们理解：网络学到了什么信息、丢弃了什么信息、以及这些信息选择如何影响泛化性能。

变分自编码器与 ELBO
变分自编码器（VAE）是信息论在生成模型中最直接的应用。VAE 通过最大化证据下界（ELBO）进行训练，ELBO 分解为重构项（保真度）和 KL 正则项（编码效率），这正是率失真理论在深度学习中的体现。


ELBO = E_q[log p(x|z)] - D_KL(q(z|x) || p(z))


function vaeLoss(
  reconLogits: number[][],
  targets: number[][],
  mu: number[],
  logVar: number[],
  beta: number = 1.0,
): { total: number; recon: number; kl: number } {
  let recon = 0;
  for (let i = 0; i < targets.length; i++) {
    for (let j = 0; j < targets[i].length; j++) {
      const p = 1 / (1 + Math.exp(-reconLogits[i][j]));
      const t = targets[i][j];
      recon -= t * Math.log(Math.max(p, 1e-10)) + (1 - t) * Math.log(Math.max(1 - p, 1e-10));
    }
  }
  recon /= targets.length;

  let kl = 0;
  for (let i = 0; i < mu.length; i++) {
    kl += -0.5 * (1 + logVar[i] - mu[i] * mu[i] - Math.exp(logVar[i]));
  }

  return {
    total: recon + beta * kl,
    recon,
    kl,
  };
}

function reparameterize(mu: number[], logVar: number[]): number[] {
  return mu.map((m, i) => {
    const std = Math.exp(0.5 * logVar[i]);
    const u1 = Math.random();
    const u2 = Math.random();
    const eps = Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
    return m + std * eps;
  });
}

function annealBeta(epoch: number, warmupEpochs: number): number {
  return Math.min(1.0, epoch / warmupEpochs);
}

const mu2 = [0.5, -0.3, 1.2, -0.8];
const logVar2 = [-1.0, -0.5, -1.5, -0.2];

for (const beta of [0.0, 0.1, 0.5, 1.0, 4.0]) {
  const mockRecon = [
    [0.8, 0.2],
    [0.3, 0.7],
  ];
  const mockTarget = [
    [1, 0],
    [0, 1],
  ];
  const loss = vaeLoss(mockRecon, mockTarget, mu2, logVar2, beta);
  console.log(`β=${beta}: total=${loss.total.toFixed(4)}, recon=${loss.recon.toFixed(4)}, KL=${loss.kl.toFixed(4)}`);
}
对比学习与互信息
对比学习（Contrastive Learning）的理论基础是互信息最大化。InfoNCE 损失是互信息的一个下界估计，通过区分正样本对（相关的）和负样本对（不相关的）来学习有用的表示。


InfoNCE loss = -E[log(exp(f(x,y⁺)) / ∑ exp(f(x,yⁱ)))]，其中 I(X;Y) ≥ log(N) - L_NCE。


function infoNCELoss(anchor: number[], positive: number[], negatives: number[][], temperature: number = 0.07): number {
  const sim = (a: number[], b: number[]): number => {
    let dot = 0;
    let normA = 0;
    let normB = 0;
    for (let i = 0; i < a.length; i++) {
      dot += a[i] * b[i];
      normA += a[i] * a[i];
      normB += b[i] * b[i];
    }
    return dot / (Math.sqrt(normA) * Math.sqrt(normB));
  };

  const posSim = sim(anchor, positive) / temperature;
  const negSims = negatives.map((neg) => sim(anchor, neg) / temperature);

  const maxSim = Math.max(posSim, ...negSims);
  const logSumExp =
    maxSim + Math.log(Math.exp(posSim - maxSim) + negSims.reduce((s, ns) => s + Math.exp(ns - maxSim), 0));

  return -(posSim - logSumExp);
}

function miBound(lossValue: number, numNegatives: number): number {
  return Math.log2(numNegatives + 1) - lossValue / Math.LN2;
}

const dim = 128;
const randVec = (): number[] => Array.from({ length: dim }, () => (Math.random() - 0.5) * 2);

const anchor = randVec();
const positive = anchor.map((a) => a + (Math.random() - 0.5) * 0.2);
const negatives = Array.from({ length: 255 }, () => randVec());

const loss = infoNCELoss(anchor, positive, negatives);
const bound = miBound(loss, negatives.length);
console.log(`InfoNCE loss: ${loss.toFixed(4)}`);
console.log(`MI 下界: ${bound.toFixed(4)} bits`);
console.log(`log(N+1): ${Math.log2(negatives.length + 1).toFixed(4)} bits`);

信息论视角的泛化界
信息论提供了理解深度学习泛化能力的新视角。PAC-Bayes 界和互信息泛化界建立了模型复杂度、训练数据信息量与泛化误差之间的定量关系。


function pacBayesBound(empiricalRisk: number, klDivergence: number, nSamples: number, delta: number = 0.05): number {
  const complexity = (klDivergence + Math.log((2 * Math.sqrt(nSamples)) / delta)) / nSamples;
  return empiricalRisk + Math.sqrt(complexity / 2);
}

function miGeneralizationBound(mutualInformation: number, nSamples: number): number {
  return Math.sqrt((2 * mutualInformation) / nSamples);
}

function compressionBound(compressedBits: number, nSamples: number, delta: number = 0.05): number {
  return Math.sqrt((compressedBits + Math.log(1 / delta)) / (2 * nSamples));
}

function flatnessEstimate(lossValues: number[], perturbScale: number): number {
  const mean = lossValues.reduce((a, b) => a + b, 0) / lossValues.length;
  const variance = lossValues.reduce((s, l) => s + (l - mean) ** 2, 0) / lossValues.length;
  return variance / (perturbScale * perturbScale);
}

const n = 10000;
for (const [empRisk, kl] of [
  [0.05, 100],
  [0.05, 1000],
  [0.01, 100],
  [0.01, 10000],
]) {
  const bound = pacBayesBound(empRisk, kl, n);
  console.log(`经验风险=${empRisk}, KL=${kl}: PAC-Bayes 界=${bound.toFixed(4)}`);
}

for (const mi of [1, 10, 100, 1000]) {
  const bound = miGeneralizationBound(mi, n);
  console.log(`MI=${mi} bits: 泛化间隙上界=${bound.toFixed(4)}`);
}

小结
    

  • 交叉熵损失、ELBO 和 InfoNCE 都是信息论概念在深度学习中的直接应用
    • 

  • VAE 通过最大化 ELBO 训练，本质上是率失真理论在生成模型中的体现
    • 

  • 对比学习通过 InfoNCE 最大化互信息，MI 下界为 log(N) - L_NCE
    • 

  • PAC-Bayes 和互信息泛化界从信息论角度解释深度学习的泛化能力
    • 

  • β-VAE 和 VIB 通过调节信息约束控制学习到的表示的性质
    • 

  • 信息论为理解和改进深度学习提供了统一的数学语言
