交叉熵损失

核心概念

交叉熵损失（Cross-Entropy Loss）是机器学习中最广泛使用的分类损失函数，它直接源于信息论中的交叉熵概念。给定真实分布 P 和模型预测分布 Q，交叉熵定义为 H(P,Q) = -∑ P(x) log Q(x)。在分类任务中，P 是独热编码的标签，Q 是模型的 softmax 输出。

交叉熵损失 = 信源熵 H(P) + KL 散度 D_KL(P||Q)。由于训练标签的熵 H(P) 是常数（对于独热标签为 0），最小化交叉熵等价于最小化 KL 散度，即让模型分布尽可能接近真实分布。

交叉熵的数值实现
直接计算 softmax + log 容易产生数值溢出。实际实现中使用 LogSumExp 技巧确保数值稳定性。


function softmax(logits: number[]): number[] {
  const maxLogit = Math.max(...logits);
  const exps = logits.map((l) => Math.exp(l - maxLogit));
  const sum = exps.reduce((a, b) => a + b, 0);
  return exps.map((e) => e / sum);
}

function logSoftmax(logits: number[]): number[] {
  const maxLogit = Math.max(...logits);
  const shifted = logits.map((l) => l - maxLogit);
  const logSumExp = Math.log(shifted.reduce((s, l) => s + Math.exp(l), 0));
  return shifted.map((l) => l - logSumExp);
}

function crossEntropyLoss(logits: number[], target: number): number {
  const logProbs = logSoftmax(logits);
  return -logProbs[target];
}

function binaryCrossEntropy(predicted: number, target: number): number {
  const eps = 1e-15;
  const p = Math.max(eps, Math.min(1 - eps, predicted));
  return -(target * Math.log(p) + (1 - target) * Math.log(1 - p));
}

function crossEntropyGradient(logits: number[], target: number): number[] {
  const probs = softmax(logits);
  return probs.map((p, i) => p - (i === target ? 1 : 0));
}

const logits = [2.0, 1.0, 0.5, -1.0];
const target = 0;
console.log(`Softmax: [${softmax(logits).map((p) => p.toFixed(4))}]`);
console.log(`交叉熵损失: ${crossEntropyLoss(logits, target).toFixed(6)}`);
console.log(`梯度: [${crossEntropyGradient(logits, target).map((g) => g.toFixed(4))}]`);

console.log(`\n二元交叉熵 (p=0.9, y=1): ${binaryCrossEntropy(0.9, 1).toFixed(6)}`);

标签平滑与知识蒸馏
标签平滑（Label Smoothing）是一种正则化技术，将独热标签 P 替换为 P_smooth = (1-ε)P + εU，其中 U 是均匀分布，ε 是平滑参数。这避免了模型对训练标签过度自信，改善了泛化性能。


function labelSmoothing(target: number, numClasses: number, epsilon: number = 0.1): number[] {
  const smooth = Array(numClasses).fill(epsilon / numClasses);
  smooth[target] += 1 - epsilon;
  return smooth;
}

function smoothCrossEntropy(logits: number[], target: number, epsilon: number = 0.1): number {
  const logProbs = logSoftmax(logits);
  const numClasses = logits.length;
  const smoothLabel = labelSmoothing(target, numClasses, epsilon);

  let loss = 0;
  for (let i = 0; i < numClasses; i++) {
    loss -= smoothLabel[i] * logProbs[i];
  }
  return loss;
}

function distillationLoss(
  studentLogits: number[],
  teacherLogits: number[],
  target: number,
  temperature: number = 4,
  alpha: number = 0.5,
): number {
  const studentSoft = softmax(studentLogits.map((l) => l / temperature));
  const teacherSoft = softmax(teacherLogits.map((l) => l / temperature));

  let klLoss = 0;
  for (let i = 0; i < studentSoft.length; i++) {
    if (teacherSoft[i] > 0) {
      klLoss += teacherSoft[i] * Math.log(teacherSoft[i] / studentSoft[i]);
    }
  }
  klLoss *= temperature * temperature;

  const hardLoss = crossEntropyLoss(studentLogits, target);

  return alpha * klLoss + (1 - alpha) * hardLoss;
}

const logits2 = [3.0, 1.0, 0.5, -1.0];
console.log(`标准交叉熵: ${crossEntropyLoss(logits2, 0).toFixed(6)}`);
console.log(`平滑交叉熵 (ε=0.1): ${smoothCrossEntropy(logits2, 0, 0.1).toFixed(6)}`);
console.log(`平滑交叉熵 (ε=0.2): ${smoothCrossEntropy(logits2, 0, 0.2).toFixed(6)}`);

交叉熵与最大似然估计
交叉熵损失与最大似然估计（MLE）在数学上完全等价。最小化交叉熵等价于最大化数据的对数似然。


function negLogLikelihood(predictions: number[][], targets: number[]): number {
  let nll = 0;
  for (let i = 0; i < targets.length; i++) {
    const logProbs = logSoftmax(predictions[i]);
    nll -= logProbs[targets[i]];
  }
  return nll / targets.length;
}

function perplexity(crossEntropyLoss: number): number {
  return Math.pow(2, crossEntropyLoss);
}

function bitsPerCharacter(crossEntropyLoss: number): number {
  return crossEntropyLoss / Math.LN2;
}

function calibrationError(predictions: number[][], targets: number[], nBins: number = 10): number {
  const confidences: number[] = predictions.map((p) => {
    const probs = softmax(p);
    return Math.max(...probs);
  });
  const correct: boolean[] = predictions.map((p, i) => {
    const probs = softmax(p);
    return probs.indexOf(Math.max(...probs)) === targets[i];
  });

  let ece = 0;
  for (let b = 0; b < nBins; b++) {
    const lo = b / nBins;
    const hi = (b + 1) / nBins;
    const inBin = confidences.map((c, i) => ({ c, correct: correct[i] })).filter(({ c }) => c >= lo && c < hi);

    if (inBin.length > 0) {
      const avgConf = inBin.reduce((s, { c }) => s + c, 0) / inBin.length;
      const avgAcc = inBin.filter(({ correct: cr }) => cr).length / inBin.length;
      ece += (inBin.length / confidences.length) * Math.abs(avgConf - avgAcc);
    }
  }
  return ece;
}

const preds = [
  [3.0, 0.5, -1.0],
  [0.5, 2.5, -0.5],
  [-1.0, 0.5, 3.0],
];
const tgts = [0, 1, 2];
const avgLoss = negLogLikelihood(preds, tgts);
console.log(`平均交叉熵: ${avgLoss.toFixed(4)}`);
console.log(`困惑度: ${perplexity(avgLoss).toFixed(4)}`);
console.log(`ECE: ${calibrationError(preds, tgts).toFixed(4)}`);
小结
    

  • 交叉熵损失是信息论与机器学习的核心桥梁，最小化它等价于最小化 KL 散度
    • 

  • 数值实现中必须使用 LogSumExp 技巧避免溢出，直接计算 exp+log 不安全
    • 

  • 标签平滑通过增加标签熵防止过拟合，是 Transformer 训练的标准配置
    • 

  • 知识蒸馏本质上是最小化教师与学生分布的 KL 散度，温度参数控制软分布的锐度
    • 

  • 困惑度 = 2^(交叉熵) 是语言模型的标准评估指标
    • 

  • 校准误差（ECE）衡量预测概率与实际准确率的匹配程度
    •
