信息不等式

核心概念

信息不等式是信息论中连接熵、互信息和其他信息度量的一系列基本约束关系。这些不等式不仅揭示了信息量的内在结构，更在编码理论、统计推断和机器学习中提供了理论保障和性能界限。

最根本的信息不等式是 Gibbs 不等式：对任意两个概率分布 P 和 Q，-∑ P(x) log P(x) ≤ -∑ P(x) log Q(x)，即 H(P) ≤ H(P,Q)，其中 H(P,Q) 是交叉熵。等号成立当且仅当 P = Q。

Fano 不等式
Fano 不等式建立了条件熵 H(X|Y) 与估计误差概率 Pₑ 之间的定量关系。若 X̂ = g(Y) 是 X 的估计，错误概率为 Pₑ = Pr(X̂ ≠ X)，则 H(X|Y) ≤ H(Pₑ) + Pₑ log(|X| - 1)，其中 H(Pₑ) = -Pₑ log Pₑ - (1-Pₑ) log(1-Pₑ) 是二元熵函数。


function binaryEntropy(p: number): number {
  if (p <= 0 || p >= 1) return 0;
  return -p * Math.log2(p) - (1 - p) * Math.log2(1 - p);
}

function fanoUpperBound(pe: number, alphabetSize: number): number {
  return binaryEntropy(pe) + pe * Math.log2(alphabetSize - 1);
}

function fanoLowerBoundPe(conditionalEntropy: number, alphabetSize: number): number {
  let lo = 0;
  let hi = 1 - 1 / alphabetSize;
  for (let i = 0; i < 100; i++) {
    const mid = (lo + hi) / 2;
    if (fanoUpperBound(mid, alphabetSize) < conditionalEntropy) {
      lo = mid;
    } else {
      hi = mid;
    }
  }
  return lo;
}

const alphabetSize = 10;
for (const pe of [0.01, 0.05, 0.1, 0.2, 0.5]) {
  const bound = fanoUpperBound(pe, alphabetSize);
  console.log(`Pₑ=${pe}: H(X|Y) ≤ ${bound.toFixed(4)} bits`);
}

const hxy = 2.0;
const minPe = fanoLowerBoundPe(hxy, alphabetSize);
console.log(`H(X|Y)=${hxy}: Pₑ ≥ ${minPe.toFixed(4)}`);
Fano 不等式的逆向使用更为实用：给定条件熵 H(X|Y)，可以推导出任何估计器的错误概率的下界。这在通信理论中用于证明信道编码定理的逆定理。


数据处理不等式与马尔可夫链
数据处理不等式（DPI）是信息论中最深刻的结果之一：对于马尔可夫链 X → Y → Z，有 I(X;Z) ≤ I(X;Y) 和 I(X;Z) ≤ I(Y;Z)。这意味着数据处理（从 Y 到 Z 的变换）不可能创造新的信息。


function verifyDPI(
  pXY: number[][],
  transitionYZ: number[][],
): { ixz: number; ixy: number; iyz: number; dpiSatisfied: boolean } {
  const nX = pXY.length;
  const nY = pXY[0].length;
  const nZ = transitionYZ[0].length;

  const pY: number[] = Array(nY).fill(0);
  for (let i = 0; i < nX; i++) {
    for (let j = 0; j < nY; j++) {
      pY[j] += pXY[i][j];
    }
  }

  const pYZ: number[][] = Array.from({ length: nY }, (_, j) =>
    Array.from({ length: nZ }, (_, k) => pY[j] * transitionYZ[j][k]),
  );

  const pXYZ: number[][][] = Array.from({ length: nX }, (_, i) =>
    Array.from({ length: nY }, (_, j) => Array.from({ length: nZ }, (_, k) => pXY[i][j] * transitionYZ[j][k])),
  );

  const pXZ: number[][] = Array.from({ length: nX }, () => Array(nZ).fill(0));
  for (let i = 0; i < nX; i++) {
    for (let j = 0; j < nY; j++) {
      for (let k = 0; k < nZ; k++) {
        pXZ[i][k] += pXYZ[i][j][k];
      }
    }
  }

  const computeMI = (joint: number[][]): number => {
    const rows = joint.length;
    const cols = joint[0].length;
    const mx: number[] = Array(rows).fill(0);
    const my: number[] = Array(cols).fill(0);
    for (let i = 0; i < rows; i++) {
      for (let j = 0; j < cols; j++) {
        mx[i] += joint[i][j];
        my[j] += joint[i][j];
      }
    }
    let mi = 0;
    for (let i = 0; i < rows; i++) {
      for (let j = 0; j < cols; j++) {
        if (joint[i][j] > 0 && mx[i] > 0 && my[j] > 0) {
          mi += joint[i][j] * Math.log2(joint[i][j] / (mx[i] * my[j]));
        }
      }
    }
    return mi;
  };

  const ixy = computeMI(pXY);
  const iyz = computeMI(pYZ);
  const ixz = computeMI(pXZ);

  return {
    ixz,
    ixy,
    iyz,
    dpiSatisfied: ixz <= ixy + 1e-10 && ixz <= iyz + 1e-10,
  };
}

const pXY = [
  [0.3, 0.1],
  [0.05, 0.55],
];
const transitionYZ = [
  [0.8, 0.2],
  [0.3, 0.7],
];
const result = verifyDPI(pXY, transitionYZ);
console.log(`I(X;Y) = ${result.ixy.toFixed(4)}`);
console.log(`I(Y;Z) = ${result.iyz.toFixed(4)}`);
console.log(`I(X;Z) = ${result.ixz.toFixed(4)}`);
console.log(`DPI 满足: ${result.dpiSatisfied}`);
DPI 的一个重要推论是：对于充分统计量 T(X) 相对于参数 θ，有 I(θ;X) = I(θ;T(X))。充分统计量不损失任何关于参数的信息。


熵幂不等式与 Fisher 信息
熵幂不等式（Entropy Power Inequality, EPI）是连续信息论中最深刻的不等式之一，它给出了独立随机变量之和的熵的下界。对于独立的 X 和 Y，2^(2h(X+Y)) ≥ 2^(2h(X)) + 2^(2h(Y))，其中 h 是微分熵。


Fisher 信息 J(X) = E[(∂/∂x log f(x))²] 与熵通过 de Bruijn 恒等式和 Cramér-Rao 下界联系。这些关系揭示了信息论和统计估计理论之间的深层联系。


function fisherInformationGaussian(variance: number): number {
  return 1 / variance;
}

function cramerRaoLowerBound(fisherInfo: number): number {
  return 1 / fisherInfo;
}

function entropyPowerGaussian(variance: number): number {
  return 2 * Math.PI * Math.E * variance;
}

function verifyEPI(var1: number, var2: number): boolean {
  const sumVar = var1 + var2;
  const leftSide = entropyPowerGaussian(sumVar);
  const rightSide = entropyPowerGaussian(var1) + entropyPowerGaussian(var2);
  return leftSide >= rightSide - 1e-10;
}

console.log(`高斯 σ²=1 的 Fisher 信息: ${fisherInformationGaussian(1)}`);
console.log(`Cramér-Rao 下界: ${cramerRaoLowerBound(fisherInformationGaussian(1))}`);
console.log(`EPI 对 (1,1) 成立: ${verifyEPI(1, 1)}`);
console.log(`EPI 对 (2,3) 成立: ${verifyEPI(2, 3)}`);

小结
    

  • Gibbs 不等式是所有信息不等式的根基，保证 KL 散度非负
    • 

  • Fano 不等式将条件熵与错误概率联系起来，为估计问题提供基本下界
    • 

  • 数据处理不等式保证信息处理不创造新信息，约束马尔可夫链的信息流
    • 

  • 熵幂不等式描述独立变量和的熵增长，高斯分布是等号条件
    • 

  • Fisher 信息通过 Cramér-Rao 界和 de Bruijn 恒等式连接估计理论与信息论
    • 

  • 这些不等式共同构建了信息论的理论骨架，支撑编码定理和统计推断的基本限制
    •
