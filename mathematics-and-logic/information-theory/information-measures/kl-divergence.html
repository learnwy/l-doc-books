Part III · 概率统计与优化信息论 简介信息度量基础 简介KL 散度

KL 散度

核心概念

KL 散度（Kullback-Leibler Divergence），也称相对熵，度量一个概率分布 Q 相对于另一个概率分布 P 的"距离"。对于离散分布，D_KL(P || Q) = ∑ P(x) log(P(x) / Q(x))。KL 散度不是真正的距离度量，因为它不满足对称性 D_KL(P || Q) ≠ D_KL(Q || P) 和三角不等式。

KL 散度的本质含义是：当真实分布为 P，却使用基于 Q 的编码方案时，平均需要额外的比特数。它始终非负（Gibbs 不等式），当且仅当 P = Q 时等于零。

前向 KL 与反向 KL
前向 KL D_KL(P || Q) 和反向 KL D_KL(Q || P) 在优化中表现出截然不同的行为。前向 KL 是"均值寻找"的（mean-seeking），倾向于让 Q 覆盖 P 的所有模式；反向 KL 是"模式寻找"的（mode-seeking），倾向于让 Q 集中在 P 的某个模式上。


function klDivergence(p: number[], q: number[]): number {
  let kl = 0;
  for (let i = 0; i < p.length; i++) {
    if (p[i] > 0) {
      if (q[i] <= 0) return Infinity;
      kl += p[i] * Math.log2(p[i] / q[i]);
    }
  }
  return kl;
}

function forwardKL(p: number[], q: number[]): number {
  return klDivergence(p, q);
}

function reverseKL(p: number[], q: number[]): number {
  return klDivergence(q, p);
}

const bimodal = [0.3, 0.0, 0.0, 0.4, 0.0, 0.0, 0.3];
const gaussian1 = [0.05, 0.1, 0.2, 0.3, 0.2, 0.1, 0.05];
const narrowMode = [0.0, 0.0, 0.1, 0.8, 0.1, 0.0, 0.0];

console.log(`前向 KL(P||Q_broad): ${forwardKL(bimodal, gaussian1).toFixed(4)}`);
console.log(`前向 KL(P||Q_narrow): ${forwardKL(bimodal, narrowMode).toFixed(4)}`);
console.log(`反向 KL(Q_broad||P): ${reverseKL(bimodal, gaussian1).toFixed(4)}`);
在变分推断中，最小化反向 KL D_KL(Q || P) 是标准做法（变分下界 ELBO），因为前向 KL 需要对真实后验进行积分，通常不可行。然而反向 KL 的模式寻找行为意味着变分近似可能会忽略后验分布的部分模式。

KL 散度与指数族分布
对于指数族分布，KL 散度有优雅的封闭形式。指数族分布可以写为 p(x|θ) = h(x) exp(θᵀT(x) - A(θ))，其中 A(θ) 是对数配分函数。两个同族指数族分布之间的 KL 散度为 DKL(pθ₁ || p_θ₂) = A(θ₂) - A(θ₁) - ∇A(θ₁)ᵀ(θ₂ - θ₁)，即 Bregman 散度。


function klGaussian(mu1: number, sigma1: number, mu2: number, sigma2: number): number {
  return Math.log(sigma2 / sigma1) + (sigma1 * sigma1 + (mu1 - mu2) * (mu1 - mu2)) / (2 * sigma2 * sigma2) - 0.5;
}

function klMultivariateGaussian(mu1: number[], sigma1: number[][], mu2: number[], sigma2: number[][]): number {
  const k = mu1.length;
  const detSigma1 = determinant(sigma1);
  const detSigma2 = determinant(sigma2);
  const sigma2Inv = invertMatrix(sigma2);

  let trace = 0;
  for (let i = 0; i < k; i++) {
    for (let j = 0; j < k; j++) {
      trace += sigma2Inv[i][j] * sigma1[j][i];
    }
  }

  const muDiff = mu1.map((m, i) => m - mu2[i]);
  let quadForm = 0;
  for (let i = 0; i < k; i++) {
    for (let j = 0; j < k; j++) {
      quadForm += muDiff[i] * sigma2Inv[i][j] * muDiff[j];
    }
  }

  return 0.5 * (Math.log(detSigma2 / detSigma1) - k + trace + quadForm);
}

function determinant(m: number[][]): number {
  if (m.length === 1) return m[0][0];
  if (m.length === 2) return m[0][0] * m[1][1] - m[0][1] * m[1][0];
  let det = 0;
  for (let j = 0; j < m.length; j++) {
    const sub = m.slice(1).map((row) => [...row.slice(0, j), ...row.slice(j + 1)]);
    det += (j % 2 === 0 ? 1 : -1) * m[0][j] * determinant(sub);
  }
  return det;
}

function invertMatrix(m: number[][]): number[][] {
  const n = m.length;
  const aug = m.map((row, i) => [
    ...row,
    ...Array(n)
      .fill(0)
      .map((_, j) => (i === j ? 1 : 0)),
  ]);
  for (let i = 0; i < n; i++) {
    const pivot = aug[i][i];
    for (let j = 0; j < 2 * n; j++) aug[i][j] /= pivot;
    for (let k = 0; k < n; k++) {
      if (k !== i) {
        const factor = aug[k][i];
        for (let j = 0; j < 2 * n; j++) aug[k][j] -= factor * aug[i][j];
      }
    }
  }
  return aug.map((row) => row.slice(n));
}

KL 散度的变体与替代
由于 KL 散度的不对称性和在 Q(x) = 0 处的奇异性，实践中发展了多种替代度量。


function jensenShannonDivergence(p: number[], q: number[]): number {
  const m = p.map((pi, i) => (pi + q[i]) / 2);
  return (klDivergence(p, m) + klDivergence(q, m)) / 2;
}

function jsDistance(p: number[], q: number[]): number {
  return Math.sqrt(jensenShannonDivergence(p, q));
}

function renyiDivergence(p: number[], q: number[], alpha: number): number {
  if (alpha === 1) return klDivergence(p, q);
  let sum = 0;
  for (let i = 0; i < p.length; i++) {
    if (p[i] > 0 && q[i] > 0) {
      sum += Math.pow(p[i], alpha) * Math.pow(q[i], 1 - alpha);
    }
  }
  return Math.log2(sum) / (alpha - 1);
}

function totalVariation(p: number[], q: number[]): number {
  let tv = 0;
  for (let i = 0; i < p.length; i++) {
    tv += Math.abs(p[i] - q[i]);
  }
  return tv / 2;
}

const p = [0.4, 0.3, 0.2, 0.1];
const q = [0.25, 0.25, 0.25, 0.25];

console.log(`JS(P,Q): ${jensenShannonDivergence(p, q).toFixed(4)}`);
console.log(`JS distance: ${jsDistance(p, q).toFixed(4)}`);
console.log(`Rényi (α=0.5): ${renyiDivergence(p, q, 0.5).toFixed(4)}`);

小结
    

  • KL 散度度量使用近似分布 Q 替代真实分布 P 时的额外信息代价
    • 

  • 前向 KL 是均值寻找的，反向 KL 是模式寻找的，两者优化行为截然不同
    • 

  • 对于指数族分布，KL 散度等价于对数配分函数的 Bregman 散度，有封闭形式
    • 

  • Jensen-Shannon 散度是对称的、有界的 KL 变体，其平方根满足三角不等式
    • 

  • Rényi 散度通过参数 α 控制对尾部差异的敏感度，在差分隐私中有重要应用
    • 

  • 选择合适的散度度量取决于具体问题：变分推断用反向 KL，GAN 用 JS/Wasserstein
    •
