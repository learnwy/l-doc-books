Part III · 概率统计与优化信息论 简介信息度量基础 简介互信息

互信息

核心概念

互信息（Mutual Information, MI）度量两个随机变量之间的统计依赖程度，定义为 I(X;Y) = H(X) + H(Y) - H(X,Y) = H(X) - H(X|Y)。它衡量知道一个变量后另一个变量不确定性减少的量。与相关系数不同，互信息能捕捉任意形式的统计依赖，而非仅仅线性关系。

互信息等价于联合分布 p(x,y) 与边际分布乘积 p(x)p(y) 之间的 KL 散度：I(X;Y) = D_KL(p(x,y) || p(x)p(y))。当且仅当 X 与 Y 独立时，I(X;Y) = 0。





性质
数学表达
含义





非负性
I(X;Y) ≥ 0
知道 Y 不会增加 X 的不确定性




对称性
I(X;Y) = I(Y;X)
X 关于 Y 的信息等于 Y 关于 X 的




上界
I(X;Y) ≤ min(H(X), H(Y))
互信息不超过任一变量的熵




与熵关系
I(X;Y) = H(X) + H(Y) - H(X,Y)
通过维恩图理解




独立条件
I(X;Y) = 0 ⟺ X ⊥ Y
互信息为零等价于独立





互信息的计算方法
在离散情形下，互信息可以直接通过概率质量函数计算。连续情形下通常需要核密度估计或 k-近邻方法。


function mutualInformation(jointProbs: number[][]): number {
  const rows = jointProbs.length;
  const cols = jointProbs[0].length;

  const marginalX: number[] = Array(rows).fill(0);
  const marginalY: number[] = Array(cols).fill(0);

  for (let i = 0; i < rows; i++) {
    for (let j = 0; j < cols; j++) {
      marginalX[i] += jointProbs[i][j];
      marginalY[j] += jointProbs[i][j];
    }
  }

  let mi = 0;
  for (let i = 0; i < rows; i++) {
    for (let j = 0; j < cols; j++) {
      const pxy = jointProbs[i][j];
      if (pxy > 0 && marginalX[i] > 0 && marginalY[j] > 0) {
        mi += pxy * Math.log2(pxy / (marginalX[i] * marginalY[j]));
      }
    }
  }
  return mi;
}

function normalizedMI(jointProbs: number[][]): number {
  const mi = mutualInformation(jointProbs);
  const rows = jointProbs.length;
  const cols = jointProbs[0].length;

  const marginalX: number[] = Array(rows).fill(0);
  const marginalY: number[] = Array(cols).fill(0);
  for (let i = 0; i < rows; i++) {
    for (let j = 0; j < cols; j++) {
      marginalX[i] += jointProbs[i][j];
      marginalY[j] += jointProbs[i][j];
    }
  }

  const hx = -marginalX.filter((p) => p > 0).reduce((s, p) => s + p * Math.log2(p), 0);
  const hy = -marginalY.filter((p) => p > 0).reduce((s, p) => s + p * Math.log2(p), 0);
  const denom = Math.sqrt(hx * hy);
  return denom > 0 ? mi / denom : 0;
}

对于连续变量，KSG（Kraskov-Stögbauer-Grassberger）估计器基于 k-近邻距离来估计互信息，避免了核密度估计的带宽选择问题。


function ksgMutualInformation(x: number[], y: number[], k: number = 3): number {
  const n = x.length;
  const digamma = (val: number): number => {
    let result = 0;
    let v = val;
    while (v < 6) {
      result -= 1 / v;
      v += 1;
    }
    result += Math.log(v) - 1 / (2 * v);
    for (let i = 1; i <= 4; i++) {
      const power = 2 * i;
      result -= 1 / (power * Math.pow(v, power));
    }
    return result;
  };

  const chebyshevDist = (i: number, j: number): number => Math.max(Math.abs(x[i] - x[j]), Math.abs(y[i] - y[j]));

  let miSum = 0;
  for (let i = 0; i < n; i++) {
    const distances = Array.from({ length: n }, (_, j) => ({
      idx: j,
      dist: chebyshevDist(i, j),
    }))
      .filter((d) => d.idx !== i)
      .sort((a, b) => a.dist - b.dist);

    const epsilon = distances[k - 1].dist;

    let nx = 0;
    let ny = 0;
    for (let j = 0; j < n; j++) {
      if (j === i) continue;
      if (Math.abs(x[i] - x[j]) < epsilon) nx++;
      if (Math.abs(y[i] - y[j]) < epsilon) ny++;
    }

    miSum += digamma(nx + 1) + digamma(ny + 1);
  }

  return digamma(k) - miSum / n + digamma(n);
}
条件互信息与多变量推广
条件互信息 I(X;Y|Z) 度量在给定 Z 的条件下 X 和 Y 之间的依赖关系。它定义为 I(X;Y|Z) = H(X|Z) - H(X|Y,Z) = H(X|Z) + H(Y|Z) - H(X,Y|Z)。


数据处理不等式（Data Processing Inequality）是互信息最重要的性质之一：如果 X → Y → Z 构成马尔可夫链，则 I(X;Z) ≤ I(X;Y)。这意味着对数据的后处理不可能增加信息量。


function conditionalMI(jointXYZ: number[][][]): number {
  const nX = jointXYZ.length;
  const nY = jointXYZ[0].length;
  const nZ = jointXYZ[0][0].length;

  const pZ: number[] = Array(nZ).fill(0);
  const pXZ: number[][] = Array.from({ length: nX }, () => Array(nZ).fill(0));
  const pYZ: number[][] = Array.from({ length: nY }, () => Array(nZ).fill(0));

  for (let i = 0; i < nX; i++) {
    for (let j = 0; j < nY; j++) {
      for (let k = 0; k < nZ; k++) {
        pZ[k] += jointXYZ[i][j][k];
        pXZ[i][k] += jointXYZ[i][j][k];
        pYZ[j][k] += jointXYZ[i][j][k];
      }
    }
  }

  let cmi = 0;
  for (let i = 0; i < nX; i++) {
    for (let j = 0; j < nY; j++) {
      for (let k = 0; k < nZ; k++) {
        const pxyz = jointXYZ[i][j][k];
        if (pxyz > 0 && pZ[k] > 0 && pXZ[i][k] > 0 && pYZ[j][k] > 0) {
          cmi += pxyz * Math.log2((pxyz * pZ[k]) / (pXZ[i][k] * pYZ[j][k]));
        }
      }
    }
  }
  return cmi;
}

互信息在特征选择中的应用
互信息在机器学习的特征选择中扮演核心角色。最大相关最小冗余（mRMR）方法通过最大化特征与目标的互信息、同时最小化特征间的冗余来选择最优特征子集。


function discretizeContinuous(values: number[], bins: number = 10): number[] {
  const min = Math.min(...values);
  const max = Math.max(...values);
  const binWidth = (max - min) / bins;
  return values.map((v) => Math.min(Math.floor((v - min) / binWidth), bins - 1));
}

function empiricalMI(x: number[], y: number[]): number {
  const n = x.length;
  const counts = new Map<string, number>();
  const xCounts = new Map<number, number>();
  const yCounts = new Map<number, number>();

  for (let i = 0; i < n; i++) {
    const key = `${x[i]},${y[i]}`;
    counts.set(key, (counts.get(key) ?? 0) + 1);
    xCounts.set(x[i], (xCounts.get(x[i]) ?? 0) + 1);
    yCounts.set(y[i], (yCounts.get(y[i]) ?? 0) + 1);
  }

  let mi = 0;
  for (const [key, count] of counts) {
    const [xi, yi] = key.split(',').map(Number);
    const pxy = count / n;
    const px = (xCounts.get(xi) ?? 0) / n;
    const py = (yCounts.get(yi) ?? 0) / n;
    if (pxy > 0 && px > 0 && py > 0) {
      mi += pxy * Math.log2(pxy / (px * py));
    }
  }
  return mi;
}

function mrmrFeatureSelection(features: number[][], target: number[], k: number): number[] {
  const nFeatures = features.length;
  const selected: number[] = [];

  const relevance = features.map((f) => empiricalMI(f, target));
  let bestIdx = relevance.indexOf(Math.max(...relevance));
  selected.push(bestIdx);

  while (selected.length < k) {
    let bestScore = -Infinity;
    let bestFeature = -1;

    for (let i = 0; i < nFeatures; i++) {
      if (selected.includes(i)) continue;
      const rel = relevance[i];
      const redundancy = selected.reduce((sum, s) => sum + empiricalMI(features[i], features[s]), 0) / selected.length;
      const score = rel - redundancy;
      if (score > bestScore) {
        bestScore = score;
        bestFeature = i;
      }
    }

    if (bestFeature >= 0) selected.push(bestFeature);
  }

  return selected;
}
互信息特征选择的优势在于它能发现非线性关系，而传统的 Pearson 相关系数只能检测线性依赖。在高维数据中，结合前向选择和互信息估计可以有效降维。


小结
    

  • 互信息 I(X;Y) 度量两个变量间的全部统计依赖，不局限于线性关系
    • 

  • I(X;Y) = D_KL(p(x,y) || p(x)p(y))，当且仅当 X 与 Y 独立时为零
    • 

  • 数据处理不等式保证后处理不增加信息量，是信息论的基本约束
    • 

  • KSG 估计器是连续变量互信息估计的标准方法，避免带宽选择问题
    • 

  • mRMR 方法通过最大相关最小冗余原则实现互信息驱动的特征选择
    • 

  • 条件互信息在因果推断和条件独立性检验中起关键作用
