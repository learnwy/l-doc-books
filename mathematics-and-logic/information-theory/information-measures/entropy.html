Part III · 概率统计与优化信息论 简介信息度量基础 简介信息熵

信息熵

核心概念

信息熵（Entropy）是信息论的核心度量，由 Claude Shannon 于 1948 年提出。它量化了一个随机变量的不确定性，即描述一个随机事件平均需要多少比特的信息。对于离散随机变量 X，其熵定义为 H(X) = -∑ p(x) log₂ p(x)，其中求和遍历所有可能的取值。

熵的直觉理解：如果一个事件几乎确定发生（如掷一枚两面都是正面的硬币），其熵为 0；如果所有事件等概率发生（如掷一枚公平硬币），熵达到最大值。

| 属性     | 数学表达                               | 直觉含义                 |
| -------- | -------------------------------------- | ------------------------ | ------------------------ |
| 非负性   | H(X) ≥ 0                               | 不确定性不可能为负       |
| 最大熵   | H(X) ≤ log₂(n)                         | 均匀分布时不确定性最大   |
| 可加性   | H(X,Y) = H(X) + H(Y) （独立时）        | 独立事件的不确定性可叠加 |
| 凹性     | H(λp₁ + (1-λ)p₂) ≥ λH(p₁) + (1-λ)H(p₂) | 混合分布增加不确定性     |
| 条件递减 | H(X                                    | Y) ≤ H(X)                | 额外信息不会增加不确定性 |


离散熵与连续熵
离散熵和连续熵（也称微分熵）在形式上相似但本质不同。离散熵始终非负，而微分熵可以为负值。


离散随机变量 X 的熵：H(X) = -∑ᵢ p(xᵢ) log₂ p(xᵢ)


连续随机变量 X 的微分熵：h(X) = -∫ f(x) log₂ f(x) dx


function discreteEntropy(probs: number[]): number {
  let h = 0;
  for (const p of probs) {
    if (p > 0) {
      h -= p * Math.log2(p);
    }
  }
  return h;
}

function differentialEntropyGaussian(variance: number): number {
  return 0.5 * Math.log2(2 * Math.PI * Math.E * variance);
}

const fairCoin = discreteEntropy([0.5, 0.5]);
const biasedCoin = discreteEntropy([0.9, 0.1]);
const fairDie = discreteEntropy([1 / 6, 1 / 6, 1 / 6, 1 / 6, 1 / 6, 1 / 6]);

console.log(`公平硬币: ${fairCoin.toFixed(4)} bits`);
console.log(`偏差硬币: ${biasedCoin.toFixed(4)} bits`);
console.log(`公平骰子: ${fairDie.toFixed(4)} bits`);
console.log(`高斯分布 (σ²=1): ${differentialEntropyGaussian(1).toFixed(4)} bits`);
微分熵的关键区别在于它不具有离散熵的某些性质：它可以为负（例如均匀分布 U(0, a) 当 a < 1 时 h(X) = log₂(a) < 0），且它不是坐标变换不变的。在连续情形下，高斯分布在给定方差的所有分布中具有最大微分熵，这一结论在信号处理和通信理论中至关重要。

联合熵与条件熵
联合熵 H(X,Y) 度量同时观察两个随机变量时的总不确定性，条件熵 H(X|Y) 度量在已知 Y 的情况下 X 的剩余不确定性。


链式法则将它们联系起来：H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)。


function jointEntropy(jointProbs: number[][]): number {
  let h = 0;
  for (const row of jointProbs) {
    for (const p of row) {
      if (p > 0) {
        h -= p * Math.log2(p);
      }
    }
  }
  return h;
}

function conditionalEntropy(jointProbs: number[][]): number {
  const marginalY: number[] = [];
  for (let j = 0; j < jointProbs[0].length; j++) {
    let sum = 0;
    for (let i = 0; i < jointProbs.length; i++) {
      sum += jointProbs[i][j];
    }
    marginalY.push(sum);
  }

  let hXGivenY = 0;
  for (let j = 0; j < jointProbs[0].length; j++) {
    for (let i = 0; i < jointProbs.length; i++) {
      if (jointProbs[i][j] > 0 && marginalY[j] > 0) {
        const pXGivenY = jointProbs[i][j] / marginalY[j];
        hXGivenY -= jointProbs[i][j] * Math.log2(pXGivenY);
      }
    }
  }
  return hXGivenY;
}

const joint = [
  [0.25, 0.05],
  [0.1, 0.6],
];
console.log(`联合熵 H(X,Y): ${jointEntropy(joint).toFixed(4)} bits`);
console.log(`条件熵 H(X|Y): ${conditionalEntropy(joint).toFixed(4)} bits`);
条件熵满足以下不等式：0 ≤ H(X|Y) ≤ H(X)。等号 H(X|Y) = 0 当且仅当 X 是 Y 的确定性函数；等号 H(X|Y) = H(X) 当且仅当 X 与 Y 独立。


最大熵原理
最大熵原理由 E.T. Jaynes 提出：在满足已知约束的所有概率分布中，应选择具有最大熵的分布。这一原则的哲学基础是：不应假设任何未知的信息，最大熵分布是满足约束条件下最"无偏"的分布。


常见的最大熵分布：


    

  • 给定支撑集 → 均匀分布
    • 

  • 给定均值和方差 → 高斯分布
    • 

  • 给定均值（非负变量） → 指数分布
    • 



function maxEntropyUniform(n: number): number[] {
  return Array(n).fill(1 / n);
}

function maxEntropyWithMeanConstraint(n: number, targetMean: number, iterations: number = 1000): number[] {
  let lambda = 0;
  const lr = 0.01;

  for (let iter = 0; iter < iterations; iter++) {
    const unnormalized = Array.from({ length: n }, (_, i) => Math.exp(-lambda * i));
    const Z = unnormalized.reduce((a, b) => a + b, 0);
    const probs = unnormalized.map((u) => u / Z);
    const currentMean = probs.reduce((sum, p, i) => sum + p * i, 0);
    lambda += lr * (currentMean - targetMean);
  }

  const unnormalized = Array.from({ length: n }, (_, i) => Math.exp(-lambda * i));
  const Z = unnormalized.reduce((a, b) => a + b, 0);
  return unnormalized.map((u) => u / Z);
}

const uniform = maxEntropyUniform(6);
console.log(`均匀分布熵: ${discreteEntropy(uniform).toFixed(4)} bits`);

const constrainedDist = maxEntropyWithMeanConstraint(6, 2.5);
console.log(`约束均值=2.5 的最大熵分布: [${constrainedDist.map((p) => p.toFixed(3)).join(', ')}]`);
console.log(`其熵: ${discreteEntropy(constrainedDist).toFixed(4)} bits`);
最大熵原理在机器学习中有广泛应用，例如最大熵模型（MaxEnt）本质上就是逻辑回归的推广，条件随机场（CRF）也建立在最大熵原理的基础上。


熵的计算性质与应用
在实际应用中，熵的估计面临有限样本的挑战。直接用经验频率替代真实概率（插件估计器）会系统性地低估真实熵。


function pluginEntropyEstimate(counts: number[]): number {
  const total = counts.reduce((a, b) => a + b, 0);
  const probs = counts.map((c) => c / total);
  return discreteEntropy(probs);
}

function millerMadowCorrection(counts: number[]): number {
  const total = counts.reduce((a, b) => a + b, 0);
  const nonZero = counts.filter((c) => c > 0).length;
  const plugin = pluginEntropyEstimate(counts);
  return plugin + (nonZero - 1) / (2 * total * Math.LN2);
}

function bootstrapEntropyCI(
  counts: number[],
  nBootstrap: number = 1000,
): { mean: number; lower: number; upper: number } {
  const total = counts.reduce((a, b) => a + b, 0);
  const probs = counts.map((c) => c / total);
  const estimates: number[] = [];

  for (let b = 0; b < nBootstrap; b++) {
    const sample = Array(counts.length).fill(0);
    for (let i = 0; i < total; i++) {
      let r = Math.random();
      let cumSum = 0;
      for (let j = 0; j < probs.length; j++) {
        cumSum += probs[j];
        if (r <= cumSum) {
          sample[j]++;
          break;
        }
      }
    }
    estimates.push(pluginEntropyEstimate(sample));
  }

  estimates.sort((a, b) => a - b);
  const mean = estimates.reduce((a, b) => a + b, 0) / nBootstrap;
  return {
    mean,
    lower: estimates[Math.floor(0.025 * nBootstrap)],
    upper: estimates[Math.floor(0.975 * nBootstrap)],
  };
}

const observed = [45, 30, 15, 10];
console.log(`插件估计: ${pluginEntropyEstimate(observed).toFixed(4)} bits`);
console.log(`Miller-Madow 校正: ${millerMadowCorrection(observed).toFixed(4)} bits`);
const ci = bootstrapEntropyCI(observed);
console.log(`Bootstrap 95% CI: [${ci.lower.toFixed(4)}, ${ci.upper.toFixed(4)}]`);

小结
    

  • 信息熵量化随机变量的平均不确定性，单位为比特（bit）
    • 

  • 离散熵始终非负且有上界 log₂(n)，微分熵可以为负且没有绝对意义
    • 

  • 联合熵和条件熵通过链式法则联系：H(X,Y) = H(X) + H(Y|X)
    • 

  • 最大熵原理提供了在约束条件下选择概率分布的准则
    • 

  • 实际估计中需注意有限样本偏差，可用 Miller-Madow 校正或 Bootstrap 方法
    • 

  • 熵在决策树、数据压缩、特征选择和语言模型评估等领域有广泛应用
    •
