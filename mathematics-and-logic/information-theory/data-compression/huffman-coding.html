Huffman 编码

核心概念

Huffman 编码是由 David Huffman 于 1952 年提出的最优前缀码构造算法。给定信源符号的概率分布，Huffman 编码通过贪心策略自底向上构建二叉树，保证在所有前缀码中达到最小平均码长。其核心思想是：高概率符号分配短码字，低概率符号分配长码字。

Huffman 编码的最优性保证了：对于任何其他前缀码，其平均码长不可能低于 Huffman 码的平均码长。然而 Huffman 码的最优性仅限于单符号编码（逐符号分配码字），不适用于块编码或算术编码等更灵活的方案。

Huffman 树构造算法
Huffman 树的构造过程是一个贪心算法：反复合并概率最小的两个节点，直到只剩一个根节点。这个过程可以用优先队列（最小堆）高效实现。


interface HuffmanNode {
  symbol: string | null;
  prob: number;
  left: HuffmanNode | null;
  right: HuffmanNode | null;
}

function buildHuffmanTree(symbols: string[], probs: number[]): HuffmanNode {
  const nodes: HuffmanNode[] = symbols.map((s, i) => ({
    symbol: s,
    prob: probs[i],
    left: null,
    right: null,
  }));

  while (nodes.length > 1) {
    nodes.sort((a, b) => a.prob - b.prob);
    const left = nodes.shift()!;
    const right = nodes.shift()!;
    nodes.push({
      symbol: null,
      prob: left.prob + right.prob,
      left,
      right,
    });
  }

  return nodes[0];
}

function generateCodes(node: HuffmanNode, prefix: string = ''): Map<string, string> {
  const codes = new Map<string, string>();

  if (node.symbol !== null) {
    codes.set(node.symbol, prefix || '0');
    return codes;
  }

  if (node.left) {
    for (const [s, c] of generateCodes(node.left, prefix + '0')) {
      codes.set(s, c);
    }
  }
  if (node.right) {
    for (const [s, c] of generateCodes(node.right, prefix + '1')) {
      codes.set(s, c);
    }
  }

  return codes;
}

function huffmanEncode(text: string, codes: Map<string, string>): string {
  return text
    .split('')
    .map((ch) => codes.get(ch) ?? '')
    .join('');
}

function huffmanDecode(bits: string, root: HuffmanNode): string {
  let result = '';
  let node = root;

  for (const bit of bits) {
    node = bit === '0' ? node.left! : node.right!;
    if (node.symbol !== null) {
      result += node.symbol;
      node = root;
    }
  }

  return result;
}

const symbols = ['A', 'B', 'C', 'D', 'E'];
const probs = [0.35, 0.25, 0.2, 0.12, 0.08];
const tree = buildHuffmanTree(symbols, probs);
const codes = generateCodes(tree);

let avgLen = 0;
for (const [s, c] of codes) {
  const idx = symbols.indexOf(s);
  avgLen += probs[idx] * c.length;
  console.log(`${s}: p=${probs[idx]} → code="${c}" (${c.length} bits)`);
}

const h = -probs.reduce((s, p) => s + p * Math.log2(p), 0);
console.log(`\n平均码长: ${avgLen.toFixed(4)} bits`);
console.log(`信源熵: ${h.toFixed(4)} bits`);
console.log(`冗余度: ${(avgLen - h).toFixed(4)} bits`);
console.log(`编码效率: ${((h / avgLen) * 100).toFixed(2)}%`);
自适应 Huffman 编码
标准 Huffman 编码需要预先知道符号概率分布，自适应 Huffman 编码（Adaptive Huffman）在编码过程中动态更新 Huffman 树，适用于概率未知或随时间变化的信源。


class AdaptiveHuffman {
  private root: HuffmanNode;
  private symbolNodes: Map<string, HuffmanNode>;
  private nytNode: HuffmanNode;

  constructor() {
    this.nytNode = { symbol: 'NYT', prob: 0, left: null, right: null };
    this.root = this.nytNode;
    this.symbolNodes = new Map();
  }

  encode(symbol: string): string {
    if (this.symbolNodes.has(symbol)) {
      const node = this.symbolNodes.get(symbol)!;
      const code = this.getCode(node);
      this.updateTree(symbol);
      return code;
    }

    const nytCode = this.root === this.nytNode ? '' : this.getCode(this.nytNode);
    const asciiCode = symbol.charCodeAt(0).toString(2).padStart(8, '0');
    this.addSymbol(symbol);
    return nytCode + asciiCode;
  }

  private getCode(target: HuffmanNode): string {
    const path: string[] = [];
    const findPath = (node: HuffmanNode | null, current: string[]): boolean => {
      if (node === null) return false;
      if (node === target) {
        path.push(...current);
        return true;
      }
      current.push('0');
      if (findPath(node.left, current)) return true;
      current.pop();
      current.push('1');
      if (findPath(node.right, current)) return true;
      current.pop();
      return false;
    };
    findPath(this.root, []);
    return path.join('');
  }

  private addSymbol(symbol: string): void {
    const newInternal: HuffmanNode = {
      symbol: null,
      prob: 1,
      left: this.nytNode,
      right: { symbol, prob: 1, left: null, right: null },
    };

    if (this.root === this.nytNode) {
      this.root = newInternal;
    }

    this.symbolNodes.set(symbol, newInternal.right!);
    this.nytNode = { symbol: 'NYT', prob: 0, left: null, right: null };
    newInternal.left = this.nytNode;
  }

  private updateTree(symbol: string): void {
    const node = this.symbolNodes.get(symbol);
    if (node) {
      node.prob++;
    }
  }
}

const adaptive = new AdaptiveHuffman();
const text = 'AABCAABD';
let totalBits = '';
for (const ch of text) {
  const bits = adaptive.encode(ch);
  totalBits += bits;
  console.log(`编码 '${ch}': ${bits}`);
}
console.log(`总比特数: ${totalBits.length}`);
console.log(`每符号平均: ${(totalBits.length / text.length).toFixed(2)} bits`);

Huffman 编码的局限与扩展
Huffman 编码的主要局限是每个符号至少分配 1 比特，当某个符号的概率非常高时（如 p > 0.5），冗余度会增大。解决方案包括扩展 Huffman 编码（对符号块编码）和使用算术编码。


function extendedHuffman(
  symbols: string[],
  probs: number[],
  blockSize: number,
): { avgBitsPerSymbol: number; entropy: number } {
  const n = symbols.length;
  const blockSymbols: string[] = [];
  const blockProbs: number[] = [];

  function generateBlocks(prefix: string, prob: number, depth: number): void {
    if (depth === blockSize) {
      blockSymbols.push(prefix);
      blockProbs.push(prob);
      return;
    }
    for (let i = 0; i < n; i++) {
      generateBlocks(prefix + symbols[i], prob * probs[i], depth + 1);
    }
  }
  generateBlocks('', 1, 0);

  const tree = buildHuffmanTree(blockSymbols, blockProbs);
  const codes = generateCodes(tree);

  let avgBlockLen = 0;
  for (const [s, c] of codes) {
    const idx = blockSymbols.indexOf(s);
    avgBlockLen += blockProbs[idx] * c.length;
  }

  const h = -probs.filter((p) => p > 0).reduce((s, p) => s + p * Math.log2(p), 0);

  return {
    avgBitsPerSymbol: avgBlockLen / blockSize,
    entropy: h,
  };
}

const syms = ['0', '1'];
const ps = [0.9, 0.1];

for (const block of [1, 2, 3, 4]) {
  const result = extendedHuffman(syms, ps, block);
  console.log(`块大小=${block}: ${result.avgBitsPerSymbol.toFixed(4)} bits/symbol (H=${result.entropy.toFixed(4)})`);
}
当信源高度偏斜时，扩展 Huffman 通过增大块大小逐步逼近熵。但块大小为 k 时，需要处理 |Σ|^k 个扩展符号，复杂度指数增长。算术编码没有这个限制，可以直接编码非整数比特。


小结
    

  • Huffman 编码是信息论中最经典的最优前缀码构造算法
    • 

  • 贪心策略保证了在所有前缀码中平均码长最小，冗余度不超过 p_max + 0.086 bits
    • 

  • 自适应 Huffman 无需预知分布，通过动态更新树实现单遍编码
    • 

  • 扩展 Huffman 对符号块编码，每符号平均码长趋近熵，但复杂度指数增长
    • 

  • Huffman 编码广泛用于 DEFLATE（gzip）、JPEG 等标准中的熵编码阶段
    • 

  • 对于高度偏斜分布，算术编码比 Huffman 更高效，因其可以处理非整数比特
    •
