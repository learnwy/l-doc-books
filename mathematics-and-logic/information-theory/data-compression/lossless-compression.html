无损压缩算法

核心概念

无损压缩（Lossless Compression）是一类能够完美恢复原始数据的压缩方法。所有无损压缩算法的理论基础都是信源编码定理：平均压缩比不可能超过信源熵。实际的无损压缩系统通常组合多种技术：先用预处理（如 BWT、差分编码）减少数据冗余，再用熵编码（Huffman、算术编码）进行最终压缩。

现代无损压缩算法的发展经历了从理论最优到工程实用的演进。理论上最优的算术编码虽然压缩率最高，但实际系统需要在压缩率、速度、内存消耗之间取得平衡。

Burrows-Wheeler 变换

BWT（Burrows-Wheeler Transform）是一种可逆的文本变换，通过对输入的所有循环移位排序，将相似的字符聚集在一起，从而提高后续熵编码的效率。BWT 本身不压缩数据，但它将数据重排为更易压缩的形式。

function bwtEncode(input: string): { transformed: string; index: number } {
  const n = input.length;
  const rotations: string[] = [];

  for (let i = 0; i < n; i++) {
    rotations.push(input.slice(i) + input.slice(0, i));
  }

  rotations.sort();
  const transformed = rotations.map((r) => r[n - 1]).join('');
  const index = rotations.indexOf(input);

  return { transformed, index };
}

function bwtDecode(transformed: string, index: number): string {
  const n = transformed.length;
  const table: string[] = Array(n).fill('');

  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) {
      table[j] = transformed[j] + table[j];
    }
    table.sort();
  }

  return table[index];
}

function moveToFront(input: number[]): number[] {
  const alphabet = Array.from({ length: 256 }, (_, i) => i);
  const output: number[] = [];

  for (const ch of input) {
    const idx = alphabet.indexOf(ch);
    output.push(idx);
    alphabet.splice(idx, 1);
    alphabet.unshift(ch);
  }

  return output;
}

function inverseMoveToFront(input: number[]): number[] {
  const alphabet = Array.from({ length: 256 }, (_, i) => i);
  const output: number[] = [];

  for (const idx of input) {
    const ch = alphabet[idx];
    output.push(ch);
    alphabet.splice(idx, 1);
    alphabet.unshift(ch);
  }

  return output;
}

const text = 'banana';
const { transformed, index } = bwtEncode(text);
console.log(`BWT("${text}") = "${transformed}", index=${index}`);
console.log(`逆 BWT = "${bwtDecode(transformed, index)}"`);

const mtfInput = transformed.split('').map((c) => c.charCodeAt(0));
const mtfOutput = moveToFront(mtfInput);
console.log(`MTF 变换: [${mtfOutput}]`);

DEFLATE 与 LZ77

DEFLATE 是最广泛使用的无损压缩格式，结合了 LZ77 字典匹配和 Huffman 编码。它是 gzip、ZIP 和 PNG 的核心压缩算法。

interface LZ77Match {
  type: 'literal' | 'match';
  value?: number;
  distance?: number;
  length?: number;
}

function lz77Parse(data: number[], windowSize: number = 32768, minMatch: number = 3): LZ77Match[] {
  const tokens: LZ77Match[] = [];
  let pos = 0;

  while (pos < data.length) {
    let bestLen = 0;
    let bestDist = 0;

    const searchStart = Math.max(0, pos - windowSize);
    for (let i = searchStart; i < pos; i++) {
      let len = 0;
      while (pos + len < data.length && len < 258 && data[i + (len % (pos - i))] === data[pos + len]) {
        len++;
      }
      if (len > bestLen) {
        bestLen = len;
        bestDist = pos - i;
      }
    }

    if (bestLen >= minMatch) {
      tokens.push({ type: 'match', distance: bestDist, length: bestLen });
      pos += bestLen;
    } else {
      tokens.push({ type: 'literal', value: data[pos] });
      pos++;
    }
  }

  return tokens;
}

function analyzeCompression(
  tokens: LZ77Match[],
  originalSize: number,
): {
  literals: number;
  matches: number;
  matchBytes: number;
  ratio: number;
} {
  let literals = 0;
  let matches = 0;
  let matchBytes = 0;

  for (const token of tokens) {
    if (token.type === 'literal') {
      literals++;
    } else {
      matches++;
      matchBytes += token.length!;
    }
  }

  const compressedEstimate = literals * 9 + matches * 24;
  const ratio = compressedEstimate / (originalSize * 8);

  return { literals, matches, matchBytes, ratio };
}

const testData = 'the quick brown fox jumps over the lazy dog the quick brown fox'
  .split('')
  .map((c) => c.charCodeAt(0));
const tokens = lz77Parse(testData, 64);
const stats = analyzeCompression(tokens, testData.length);
console.log(`原始大小: ${testData.length} bytes`);
console.log(`字面量: ${stats.literals}, 匹配: ${stats.matches}`);
console.log(`匹配覆盖: ${stats.matchBytes} bytes`);

Zstandard 与现代压缩

Zstandard（zstd）由 Facebook 的 Yann Collet 开发，结合了 LZ77 匹配、有限状态熵编码（FSE/tANS）和高效的匹配查找器（hash chain + binary tree），在压缩率和速度上都优于 DEFLATE。

function estimateZstdCompression(data: number[], level: number): { ratio: number; speed: string } {
  const uniqueBytes = new Set(data).size;
  const entropy = -Array.from(
    data.reduce((map, b) => {
      map.set(b, (map.get(b) ?? 0) + 1);
      return map;
    }, new Map<number, number>()),
  )
    .map(([, count]) => count / data.length)
    .filter((p) => p > 0)
    .reduce((s, p) => s + p * Math.log2(p), 0);

  let matchRatio = 0;
  const windowSize = Math.min(data.length, level < 10 ? 65536 : 4194304);
  for (let i = 4; i < Math.min(data.length, 1000); i++) {
    for (let j = Math.max(0, i - windowSize); j < i - 3; j++) {
      if (data[j] === data[i] && data[j + 1] === data[i + 1]) {
        matchRatio += 0.001;
        break;
      }
    }
  }

  const entropyRatio = entropy / 8;
  const ratio = entropyRatio * (1 - Math.min(matchRatio, 0.5));

  const speeds = ['极快', '很快', '快', '中等', '较慢', '慢'];
  const speedIdx = Math.min(Math.floor(level / 4), speeds.length - 1);

  return { ratio: Math.max(0.05, Math.min(ratio, 0.95)), speed: speeds[speedIdx] };
}

const sampleData = Array.from({ length: 10000 }, (_, i) => {
  if (i % 100 < 50) return (i % 26) + 65;
  return Math.floor(Math.random() * 256);
});

for (const level of [1, 3, 9, 19]) {
  const result = estimateZstdCompression(sampleData, level);
  console.log(`zstd -${level}: 压缩比≈${(result.ratio * 100).toFixed(1)}%, 速度=${result.speed}`);
}

  • 无损压缩的理论极限由信源熵决定，实际系统通过组合多种技术逼近极限
  • BWT 通过重排数据使相似字符聚集，配合 MTF 和熵编码形成 bzip2 的核心流水线
  • DEFLATE 结合 LZ77 和 Huffman 编码，是互联网最广泛使用的压缩格式
  • Zstandard 通过 ANS 熵编码和高效匹配器在压缩率和速度上全面超越 DEFLATE
  • 选择压缩算法需权衡压缩率、速度和内存，不同场景有不同的最优选择
  • 实时传输场景优先选择 Zstandard，静态资源优先选择 Brotli，归档优先选择 LZMA
