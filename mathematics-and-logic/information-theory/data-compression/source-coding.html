信源编码

核心概念

信源编码（Source Coding）是数据压缩的理论基础，目标是用尽可能少的比特表示信源输出。Shannon 信源编码定理指出：对于离散无记忆信源，无损压缩的平均码长不可能低于信源熵 H(X)，且存在编码方案使平均码长任意接近 H(X)。

信源编码分为无损编码（可完美恢复原始数据）和有损编码（允许一定失真以获得更高压缩率）。无损编码的理论极限由熵确定，有损编码的理论极限由率失真函数 R(D) 确定。

前缀码与 Kraft 不等式
前缀码（Prefix Code）是一种特殊的唯一可译码，其中没有任何码字是其他码字的前缀。前缀码可以即时解码，无需等待后续符号。Kraft 不等式给出了码字长度的必要充分条件。


Kraft 不等式：存在码字长度为 l₁, l₂, ..., lₘ 的前缀码，当且仅当 ∑ᵢ 2^(-lᵢ) ≤ 1。


function verifyKraftInequality(lengths: number[]): {
  sum: number;
  valid: boolean;
} {
  const sum = lengths.reduce((s, l) => s + Math.pow(2, -l), 0);
  return { sum, valid: sum <= 1 + 1e-10 };
}

function shannonCodeLengths(probs: number[]): number[] {
  return probs.map((p) => Math.ceil(-Math.log2(p)));
}

function optimalCodeLengths(probs: number[]): number[] {
  return probs.map((p) => -Math.log2(p));
}

function averageCodeLength(probs: number[], lengths: number[]): number {
  return probs.reduce((s, p, i) => s + p * lengths[i], 0);
}

function entropy(probs: number[]): number {
  return -probs.filter((p) => p > 0).reduce((s, p) => s + p * Math.log2(p), 0);
}

const probs = [0.4, 0.3, 0.2, 0.1];
const shannonLens = shannonCodeLengths(probs);
const h = entropy(probs);

console.log(`概率分布: [${probs}]`);
console.log(`熵: ${h.toFixed(4)} bits`);
console.log(`Shannon 码长: [${shannonLens}]`);
console.log(`平均码长: ${averageCodeLength(probs, shannonLens).toFixed(4)}`);

const kraft = verifyKraftInequality(shannonLens);
console.log(`Kraft 和: ${kraft.sum.toFixed(4)}, 有效: ${kraft.valid}`);
Shannon 码长公式 lᵢ = ⌈-log₂ pᵢ⌉ 保证了 H(X) ≤ L < H(X) + 1，其中 L 是平均码长。通过对 n 个符号的扩展信源编码（块编码），可以使每符号平均码长 L/n < H(X) + 1/n，从而任意逼近熵下界。


渐近等分性质
渐近等分性质（Asymptotic Equipartition Property, AEP）是信源编码定理的核心工具。它描述了长序列的统计规律性：对于 i.i.d. 信源，长度为 n 的序列可以分为"典型集"和"非典型集"。


function typicalSetSize(
  entropy: number,
  n: number,
  epsilon: number,
): {
  lower: number;
  upper: number;
} {
  return {
    lower: Math.pow(2, n * (entropy - epsilon)),
    upper: Math.pow(2, n * (entropy + epsilon)),
  };
}

function isTypical(sequence: number[], probs: number[], entropy: number, epsilon: number): boolean {
  const n = sequence.length;
  let logProb = 0;
  for (const s of sequence) {
    logProb += Math.log2(probs[s]);
  }
  const empiricalEntropy = -logProb / n;
  return Math.abs(empiricalEntropy - entropy) < epsilon;
}

function simulateAEP(probs: number[], n: number, nTrials: number = 10000): number {
  const h = entropy(probs);
  const epsilon = 0.5;
  let typicalCount = 0;

  for (let trial = 0; trial < nTrials; trial++) {
    const sequence: number[] = [];
    for (let i = 0; i < n; i++) {
      let r = Math.random();
      for (let s = 0; s < probs.length; s++) {
        r -= probs[s];
        if (r <= 0) {
          sequence.push(s);
          break;
        }
      }
    }
    if (isTypical(sequence, probs, h, epsilon)) {
      typicalCount++;
    }
  }
  return typicalCount / nTrials;
}

const sourceProbs = [0.6, 0.3, 0.1];
const h2 = entropy(sourceProbs);

for (const n of [10, 50, 100, 500]) {
  const typProb = simulateAEP(sourceProbs, n);
  const setSize = typicalSetSize(h2, n, 0.5);
  console.log(
    `n=${n}: 典型概率=${typProb.toFixed(4)}, 典型集大小≈[2^${(n * (h2 - 0.5)).toFixed(1)}, 2^${(n * (h2 + 0.5)).toFixed(1)}]`,
  );
}
AEP 的核心结论：当 n 足够大时，典型集包含约 2^(nH) 个序列，其总概率接近 1。因此，只需 nH + o(n) 比特就能无损表示几乎所有序列。

通用信源编码
通用信源编码（Universal Source Coding）不需要预先知道信源的概率分布，而是在编码过程中自适应地学习统计特性。Lempel-Ziv 系列算法是最著名的通用无损压缩方法。


function lz77Compress(
  input: string,
  windowSize: number = 256,
  lookaheadSize: number = 16,
): Array<{ offset: number; length: number; next: string }> {
  const result: Array<{ offset: number; length: number; next: string }> = [];
  let pos = 0;

  while (pos < input.length) {
    let bestOffset = 0;
    let bestLength = 0;

    const searchStart = Math.max(0, pos - windowSize);
    for (let i = searchStart; i < pos; i++) {
      let len = 0;
      while (pos + len < input.length && len < lookaheadSize && input[i + len] === input[pos + len]) {
        len++;
      }
      if (len > bestLength) {
        bestLength = len;
        bestOffset = pos - i;
      }
    }

    const next = pos + bestLength < input.length ? input[pos + bestLength] : '';
    result.push({ offset: bestOffset, length: bestLength, next });
    pos += bestLength + 1;
  }

  return result;
}

function lz77Decompress(compressed: Array<{ offset: number; length: number; next: string }>): string {
  let result = '';
  for (const { offset, length, next } of compressed) {
    const start = result.length - offset;
    for (let i = 0; i < length; i++) {
      result += result[start + i];
    }
    result += next;
  }
  return result;
}

const text = 'abracadabra_abracadabra';
const compressed = lz77Compress(text, 32, 8);
const decompressed = lz77Decompress(compressed);
console.log(`原始: "${text}" (${text.length} 字符)`);
console.log(`压缩: ${compressed.length} 个三元组`);
console.log(`解压: "${decompressed}"`);
console.log(`验证: ${text === decompressed}`);
Lempel-Ziv 算法的渐近最优性：对于任何平稳遍历信源，LZ78 的压缩率以概率 1 收敛到信源熵率。这意味着无需知道信源分布，LZ 编码也能渐近达到最优压缩。


小结
    

  • 信源编码定理确立了无损压缩的极限：平均码长不低于信源熵 H(X)
    • 

  • Kraft 不等式给出前缀码存在的充要条件，连接码长分配与数学约束
    • 

  • AEP 揭示了长序列的统计规律性，典型集的大小约为 2^(nH)
    • 

  • 通用编码（如 LZ 系列）无需预知分布即可渐近达到最优压缩率
    • 

  • 块编码通过增大编码单元可以使平均码长任意接近熵下界
    • 

  • 信源编码理论是数据压缩技术（gzip、zstd）的数学基础
    •
