Catalan 数与经典序列

Catalan 数的定义与基本性质

Catalan 数是组合数学中出现频率最高的序列之一，它在看似无关的众多计数问题中反复出现，展示了组合结构之间深刻的同构关系。

定义：第 nnn 个 Catalan 数为：

Cn=1n+1(2nn)=(2n)!(n+1)!⋅n!C_n = \frac{1}{n+1}\binom{2n}{n} = \frac{(2n)!}{(n+1)! \cdot n!}Cn​=n+11​(n2n​)=(n+1)!⋅n!(2n)!​

前几项为：C0=1,C1=1,C2=2,C3=5,C4=14,C5=42,C6=132C_0 = 1, C_1 = 1, C_2 = 2, C_3 = 5, C_4 = 14, C_5 = 42, C_6 = 132C0​=1,C1​=1,C2​=2,C3​=5,C4​=14,C5​=42,C6​=132。

递推关系

Catalan 数满足：

Cn=∑k=0n−1Ck⋅Cn−1−k,C0=1C_n = \sum_{k=0}^{n-1} C_k \cdot C_{n-1-k}, \quad C_0 = 1Cn​=k=0∑n−1​Ck​⋅Cn−1−k​,C0​=1

也可以写成另一种递推形式：

Cn=2(2n−1)n+1Cn−1,C0=1C_n = \frac{2(2n-1)}{n+1} C_{n-1}, \quad C_0 = 1Cn​=n+12(2n−1)​Cn−1​,C0​=1

第一个递推的组合含义：将 nnn 对括号的匹配分解——第一个左括号与第 2k+22k+22k+2 个位置的右括号匹配，内部有 kkk 对，外部有 n−1−kn-1-kn−1−k 对。

Catalan 数的生成函数推导

设 C(x)=∑n=0∞CnxnC(x) = \sum_{n=0}^{\infty} C_n x^nC(x)=∑n=0∞​Cn​xn 为 Catalan 数的 OGF。

由递推 Cn=∑k=0n−1CkCn−1−kC_n = \sum_{k=0}^{n-1}C_k C_{n-1-k}Cn​=∑k=0n−1​Ck​Cn−1−k​，右边恰好是 {Cn}\{C_n\}{Cn​} 与自身的卷积（平移一项）。

C(x)−1=x⋅C(x)2C(x) - 1 = x \cdot C(x)^2C(x)−1=x⋅C(x)2

即 xC(x)2−C(x)+1=0x C(x)^2 - C(x) + 1 = 0xC(x)2−C(x)+1=0。用求根公式：

C(x)=1−1−4x2xC(x) = \frac{1 - \sqrt{1-4x}}{2x}C(x)=2x1−1−4x​​

取负号根是因为需要 C(0)=C0=1C(0) = C_0 = 1C(0)=C0​=1（正号根在 x→0x \to 0x→0 时趋于无穷）。

从生成函数提取系数

利用广义二项式定理展开 1−4x\sqrt{1-4x}1−4x​：

(1−4x)1/2=∑n=0∞(1/2n)(−4x)n(1-4x)^{1/2} = \sum_{n=0}^{\infty}\binom{1/2}{n}(-4x)^n(1−4x)1/2=n=0∑∞​(n1/2​)(−4x)n

其中 (1/2n)=(1/2)(1/2−1)⋯(1/2−n+1)n!=(−1)n−122n−1⋅n(2n−2n−1)\binom{1/2}{n} = \frac{(1/2)(1/2-1)\cdots(1/2-n+1)}{n!} = \frac{(-1)^{n-1}}{2^{2n-1} \cdot n}\binom{2n-2}{n-1}(n1/2​)=n!(1/2)(1/2−1)⋯(1/2−n+1)​=22n−1⋅n(−1)n−1​(n−12n−2​)。

经过化简，[xn]C(x)=1n+1(2nn)[x^n]C(x) = \frac{1}{n+1}\binom{2n}{n}[xn]C(x)=n+11​(n2n​)，验证了定义。

渐近估计

由 Stirling 公式：

Cn∼4nn3/2πC_n \sim \frac{4^n}{n^{3/2}\sqrt{\pi}}Cn​∼n3/2π​4n​

Catalan 数以 4n4^n4n 为底指数增长，增长速度与中心二项式系数 (2nn)∼4nπn\binom{2n}{n} \sim \frac{4^n}{\sqrt{\pi n}}(n2n​)∼πn​4n​ 相当（慢一个 nnn 因子）。

Catalan 数的组合解释

Catalan 数至少有两百多种不同的组合解释。以下是最经典的几种：

1. 括号匹配

nnn 对括号的合法匹配数（Dyck 字符串数）为 CnC_nCn​。

例如 n=3n=3n=3 时的 5 种匹配：((())), (()()), (())(), ()(()), ()()()

2. 格路计数（Dyck 路径）

从 (0,0)(0,0)(0,0) 到 (2n,0)(2n,0)(2n,0) 的格路，每步向右上 (+1,+1)(+1,+1)(+1,+1) 或向右下 (+1,−1)(+1,-1)(+1,−1)，且路径不穿越 xxx 轴以下（即任何时刻纵坐标 ≥0\geq 0≥0），这样的路径数为 CnC_nCn​。

3. 二叉树

nnn 个内部节点的不同满二叉树（每个内部节点恰好有两个子节点）的数量为 CnC_nCn​。

递推解释：根节点将 n−1n-1n−1 个内部节点分给左子树（kkk 个）和右子树（n−1−kn-1-kn−1−k 个）。

4. 三角剖分

凸 (n+2)(n+2)(n+2) 边形的三角剖分数为 CnC_nCn​。

用对角线将凸多边形划分为三角形，n+2n+2n+2 边形需要 n−1n-1n−1 条对角线，产生 nnn 个三角形。

5. 栈排序

nnn 个元素通过一个栈可以产生的合法输出排列数。序列 1,2,…,n1, 2, \ldots, n1,2,…,n 中，可由栈排序输出的排列数为 CnC_nCn​。一个排列可栈排序当且仅当它避免模式 231231231。

双射证明

不同组合解释之间存在自然的双射关系，这是 Catalan 数之美的核心所在。例如：

  • 括号匹配 → Dyck 路径：( 对应上升步，) 对应下降步
  • 括号匹配 → 二叉树：嵌套结构对应子树结构
  • 二叉树 → 三角剖分：通过"旋转对应"构造

反射原理与 Catalan 数的证明

定理：从 (0,0)(0,0)(0,0) 到 (2n,0)(2n,0)(2n,0) 的 Dyck 路径数为 Cn=1n+1(2nn)C_n = \frac{1}{n+1}\binom{2n}{n}Cn​=n+11​(n2n​)。

证明（反射法）：

从 (0,0)(0,0)(0,0) 到 (2n,0)(2n,0)(2n,0) 的所有格路（不论是否合法）共 (2nn)\binom{2n}{n}(n2n​) 条（从 2n2n2n 步中选 nnn 步上升）。

坏路径（某时刻纵坐标 <0< 0<0）的数量：对坏路径，设首次到达 y=−1y = -1y=−1 的点为 PPP。将 PPP 之前的路径关于 y=−1y = -1y=−1 做反射，得到一条从 (0,−2)(0, -2)(0,−2) 到 (2n,0)(2n, 0)(2n,0) 的路径。

从 (0,−2)(0,-2)(0,−2) 到 (2n,0)(2n,0)(2n,0) 的路径共 (2nn−1)\binom{2n}{n-1}(n−12n​) 条（需要 n+1n+1n+1 步上升和 n−1n-1n−1 步下降）。反射构造是坏路径与这些路径之间的双射。

因此好路径数为：

(2nn)−(2nn−1)=(2nn)−nn+1(2nn)=1n+1(2nn)=Cn\binom{2n}{n} - \binom{2n}{n-1} = \binom{2n}{n} - \frac{n}{n+1}\binom{2n}{n} = \frac{1}{n+1}\binom{2n}{n} = C_n(n2n​)−(n−12n​)=(n2n​)−n+1n​(n2n​)=n+11​(n2n​)=Cn​

Stirling 数

第一类 Stirling 数

定义：nnn 个元素的排列中恰好有 kkk 个轮换（cycle）的方案数，记为 [nk]\left[n \atop k\right][kn​] 或 c(n,k)c(n,k)c(n,k)。

递推：

[nk]=(n−1)[n−1k]+[n−1k−1]\left[n \atop k\right] = (n-1)\left[n-1 \atop k\right] + \left[n-1 \atop k-1\right][kn​]=(n−1)[kn−1​]+[k−1n−1​]

解释：元素 nnn 要么独自成一个新轮换（[n−1k−1]\left[n-1 \atop k-1\right][k−1n−1​]），要么插入到前 n−1n-1n−1 个元素形成的某个排列中某个元素的前面（n−1n-1n−1 种位置）。

与升阶乘的关系：

x(x+1)(x+2)⋯(x+n−1)=∑k=0n[nk]xkx(x+1)(x+2)\cdots(x+n-1) = \sum_{k=0}^{n}\left[n \atop k\right] x^kx(x+1)(x+2)⋯(x+n−1)=k=0∑n​[kn​]xk

第二类 Stirling 数

定义：nnn 个元素分成 kkk 个非空无序子集（块）的方案数，记为 {nk}\left\{n \atop k\right\}{kn​} 或 S(n,k)S(n,k)S(n,k)。

递推：

{nk}=k{n−1k}+{n−1k−1}\left\{n \atop k\right\} = k\left\{n-1 \atop k\right\} + \left\{n-1 \atop k-1\right\}{kn​}=k{kn−1​}+{k−1n−1​}

显式公式（容斥）：

{nk}=1k!∑j=0k(−1)j(kj)(k−j)n\left\{n \atop k\right\} = \frac{1}{k!}\sum_{j=0}^{k}(-1)^j\binom{k}{j}(k-j)^n{kn​}=k!1​j=0∑k​(−1)j(jk​)(k−j)n

Stirling 数之间的关系

第一类和第二类 Stirling 数互为"逆矩阵"关系：

xn=∑k=0n{nk}x(x−1)⋯(x−k+1)x^n = \sum_{k=0}^{n}\left\{n \atop k\right\} x(x-1)\cdots(x-k+1)xn=k=0∑n​{kn​}x(x−1)⋯(x−k+1)
x(x−1)⋯(x−n+1)=∑k=0n(−1)n−k[nk]xkx(x-1)\cdots(x-n+1) = \sum_{k=0}^{n}(-1)^{n-k}\left[n \atop k\right] x^kx(x−1)⋯(x−n+1)=k=0∑n​(−1)n−k[kn​]xk

Bell 数

定义：nnn 元集的所有分划数（即所有可能的块数 kkk 的 Stirling 数之和）：

Bn=∑k=0n{nk}B_n = \sum_{k=0}^{n}\left\{n \atop k\right\}Bn​=k=0∑n​{kn​}

前几项：B0=1,B1=1,B2=2,B3=5,B4=15,B5=52B_0=1, B_1=1, B_2=2, B_3=5, B_4=15, B_5=52B0​=1,B1​=1,B2​=2,B3​=5,B4​=15,B5​=52。

递推（Bell 三角形/Aitken 递推）：

Bn+1=∑k=0n(nk)BkB_{n+1} = \sum_{k=0}^{n}\binom{n}{k}B_kBn+1​=k=0∑n​(kn​)Bk​

EGF：∑n=0∞Bnxnn!=eex−1\sum_{n=0}^{\infty}B_n \frac{x^n}{n!} = e^{e^x - 1}∑n=0∞​Bn​n!xn​=eex−1

Motzkin 数

定义：从 (0,0)(0,0)(0,0) 到 (n,0)(n,0)(n,0) 的格路，每步可以向右上 (+1,+1)(+1,+1)(+1,+1)、向右 (+1,0)(+1,0)(+1,0) 或向右下 (+1,−1)(+1,-1)(+1,−1)，且不穿越 xxx 轴以下，这样的路径数为 Motzkin 数 MnM_nMn​。

前几项：M0=1,M1=1,M2=2,M3=4,M4=9,M5=21M_0=1, M_1=1, M_2=2, M_3=4, M_4=9, M_5=21M0​=1,M1​=1,M2​=2,M3​=4,M4​=9,M5​=21。

递推：

Mn=Mn−1+∑k=0n−2MkMn−2−kM_n = M_{n-1} + \sum_{k=0}^{n-2}M_k M_{n-2-k}Mn​=Mn−1​+k=0∑n−2​Mk​Mn−2−k​

或等价地：Mn=Mn−1+∑k=2n∑Mk−2⋅Mn−kM_n = M_{n-1} + \sum_{k=2}^{n}\sum M_{k-2} \cdot M_{n-k}Mn​=Mn−1​+∑k=2n​∑Mk−2​⋅Mn−k​。

更简洁的形式：(n+2)Mn=(2n+1)Mn−1+3(n−1)Mn−2(n+2)M_n = (2n+1)M_{n-1} + 3(n-1)M_{n-2}(n+2)Mn​=(2n+1)Mn−1​+3(n−1)Mn−2​。

OGF：M(x)=1−x−1−2x−3x22x2M(x) = \frac{1-x-\sqrt{1-2x-3x^2}}{2x^2}M(x)=2x21−x−1−2x−3x2​​

与 Catalan 数的关系：Motzkin 路径比 Dyck 路径多了"水平步"。Mn=∑k=0⌊n/2⌋(n2k)CkM_n = \sum_{k=0}^{\lfloor n/2 \rfloor}\binom{n}{2k}C_kMn​=∑k=0⌊n/2⌋​(2kn​)Ck​。
