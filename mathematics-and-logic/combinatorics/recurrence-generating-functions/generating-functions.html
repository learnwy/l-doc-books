生成函数基础与技巧

形式幂级数与生成函数

生成函数是组合数学中最强大的分析工具之一。它的核心思想是：将一个数列 {an}\{a_n\}{an​} 编码为一个形式幂级数，然后利用代数运算来推导数列的性质。

定义：序列 a0,a1,a2,…a_0, a_1, a_2, \ldotsa0​,a1​,a2​,… 的普通生成函数（Ordinary Generating Function, OGF）为形式幂级数：

A(x)=∑n=0∞anxn=a0+a1x+a2x2+⋯A(x) = \sum_{n=0}^{\infty} a_n x^n = a_0 + a_1 x + a_2 x^2 + \cdotsA(x)=n=0∑∞​an​xn=a0​+a1​x+a2​x2+⋯

这里的 xxx 是形式变量——我们不关心级数的收敛性，而是将其视为一种记号系统。"形式"意味着所有运算都在系数层面进行。

定义：序列的指数生成函数（Exponential Generating Function, EGF）为：

A^(x)=∑n=0∞anxnn!\hat{A}(x) = \sum_{n=0}^{\infty} a_n \frac{x^n}{n!}A^(x)=n=0∑∞​an​n!xn​

EGF 在处理有标号的组合对象（如排列）时特别方便。

一般方法总结

使用 OGF 求解线性递推的步骤：

  1. 设 A(x)=∑anxnA(x) = \sum a_n x^nA(x)=∑an​xn
  2. 利用递推关系建立关于 A(x)A(x)A(x) 的方程（通过乘以 xnx^nxn 并求和）
  3. 解出 A(x)A(x)A(x) 的封闭形式（通常是有理函数）
  4. 对 A(x)A(x)A(x) 做部分分式分解
  5. 将每个部分分式展开为幂级数，提取 xnx^nxn 的系数

EGF 的乘法意义

若 A^(x)=∑anxnn!\hat{A}(x) = \sum a_n \frac{x^n}{n!}A^(x)=∑an​n!xn​ 和 B^(x)=∑bnxnn!\hat{B}(x) = \sum b_n \frac{x^n}{n!}B^(x)=∑bn​n!xn​，则：

A^(x)⋅B^(x)=∑n=0∞(∑k=0n(nk)akbn−k)xnn!\hat{A}(x) \cdot \hat{B}(x) = \sum_{n=0}^{\infty}\left(\sum_{k=0}^{n}\binom{n}{k}a_k b_{n-k}\right)\frac{x^n}{n!}A^(x)⋅B^(x)=n=0∑∞​(k=0∑n​(kn​)ak​bn−k​)n!xn​

系数中的 (nk)\binom{n}{k}(kn​) 恰好对应"将 nnn 个有标号对象分成两组（大小 kkk 和 n−kn-kn−k）并分别计数"的方案数。这就是 EGF 适合处理有标号对象的原因。

分配问题

从 rrr 种物品中选取若干（允许重复），每种物品的可选数量有限制。若第 iii 种物品可选 Si⊆{0,1,2,…}S_i \subseteq \{0, 1, 2, \ldots\}Si​⊆{0,1,2,…} 个，则选取总数为 nnn 的方案数由以下 OGF 给出：

渐近分析初步

当我们无法得到封闭公式时，可以从生成函数推导系数的渐近行为。

定理（指数增长率）：若 A(x)=P(x)Q(x)A(x) = \frac{P(x)}{Q(x)}A(x)=Q(x)P(x)​ 是有理函数，Q(x)Q(x)Q(x) 的最小模根为 rrr（重数为 mmm），则：
