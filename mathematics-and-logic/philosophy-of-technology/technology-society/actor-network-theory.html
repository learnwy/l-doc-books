Part VI · 哲学与逻辑技术哲学 简介技术与社会 简介行动者网络理论

行动者网络理论

核心概念

行动者网络理论（Actor-Network Theory，简称 ANT）是由布鲁诺·拉图尔（Bruno Latour）、米歇尔·卡龙（Michel Callon）和约翰·劳（John Law）在 20 世纪 80 年代共同发展起来的社会理论框架。ANT 提出了一个激进的本体论主张：社会世界不是纯粹由人类行动者构成的，而是由人类和非人类行动者（技术物、自然实体、文本、制度）共同编织的异质性网络。

ANT 对技术哲学的革命性贡献在于它取消了人与物之间的本体论等级。在 ANT 看来，一个减速带和一个交警执行的是同一种"行动"——让驾驶员减速。一段代码和一个项目经理都可以是"行动者"——它们都在网络中转译利益、传递力量、改变其他行动者的行为。

转译的四个时刻
米歇尔·卡龙在对法国圣布里厄湾扇贝养殖的经典研究中，系统阐述了"转译"（translation）的四个时刻。这一分析框架至今仍是 ANT 方法论的核心。


问题化（problematization）是转译的第一步。三位海洋生物学家试图说服渔民、扇贝和科学共同体，只有通过他们的研究项目才能解决各方面临的问题——渔民需要可持续的扇贝资源，扇贝种群需要保护，科学界需要新的研究成果。生物学家将自己定位为"必经通道"（obligatory passage point），声称只有他们的方案能同时满足所有行动者的利益。


利益关联（interessement）是将其他行动者锁定在网络中的过程。生物学家使用收集器装置来"说服"扇贝幼虫附着生长，通过会议和报告来争取渔民的支持，通过学术论文来获得科学共同体的认可。每一种关联策略都针对特定的行动者类型。


征召（enrolment）是行动者被成功纳入网络并接受分配角色的过程。扇贝幼虫"同意"附着在收集器上，渔民"同意"暂停捕捞，科学委员会"同意"资助研究。这里的"同意"不限于人类的有意识决定——扇贝的行为模式同样构成了一种"回应"。


动员（mobilization）是已征召的行动者能否代表其更广泛群体的问题。少数参加会议的渔民能代表所有渔民吗？实验中附着的扇贝能代表整个种群吗？


卡龙研究的戏剧性结局是：扇贝最终"拒绝"合作——幼虫没有按预期附着生长，渔民恢复了捕捞，整个网络瓦解。这个案例完美地展示了 ANT 的核心洞见：网络的成败不仅取决于人类行动者的意愿，也取决于非人类行动者的"配合"。


技术作为凝固的社会关系
ANT 的另一个核心洞见是：技术物是"凝固的"或"代理的"社会关系。当社会秩序被铭刻（inscribed）到技术物中时，它获得了一种持久性和强制力，超越了纯粹社会性安排的脆弱性。


拉图尔以宾馆钥匙的例子来说明这一点。宾馆经营者想让住客离开时归还钥匙。他可以口头提醒（纯社会方案），也可以在钥匙上挂一个笨重的金属牌（技术方案）。金属牌将"请归还钥匙"的社会规范铭刻到了物质形式中——笨重的钥匙牌让你不想把它放在口袋里带走。


这一分析对理解软件架构具有直接的启示意义。代码中的权限系统将"谁能做什么"的社会规范铭刻到技术结构中；数据库的外键约束将"数据一致性"的规范铭刻到存储层；CI/CD 流水线中的自动化测试将"质量标准"铭刻到交付过程中。

铭刻的关键特征是"预设"（prescription）——技术物预设了使用者应该如何行为。一个设计良好的 API 通过其接口设计"引导"开发者以正确的方式调用它；一个差劲的 API 则可能"引诱"开发者写出脆弱的代码。维贝克称这种现象为"技术调解"，它揭示了技术设计中隐含的道德维度。


ANT 对传统社会理论的挑战
ANT 对传统社会理论提出了根本性的挑战。它拒绝了社会学中根深蒂固的二元对立——自然与社会、人类与非人类、微观与宏观、结构与能动性。


传统社会学假定社会由人类行动者和社会关系构成，非人类实体（如技术、自然）只是工具或背景。ANT 则主张"广义对称性"原则：在分析中不预先区分人类和非人类行动者，而是追踪网络中的关系和效果。一段有影响力的代码和一个有影响力的程序员，在分析层面上应该获得同等的关注。


ANT 也挑战了社会学的"微观-宏观"区分。传统观点认为社会存在不同的层级——个体、组织、国家、全球体系。ANT 认为不存在固有的层级差异，只有网络延伸的长度和稳固性的差异。一个"大公司"之所以"大"，不是因为它处于某个更高的存在层级，而是因为它成功地将更多的行动者（员工、技术系统、法律框架、客户网络）征召到了自己的网络中。


这些理论立场引发了广泛的争论。批评者指出，将人类和非人类置于相同的分析地位似乎是一种荒谬的"平面本体论"——扇贝真的和科学家一样是"行动者"吗？支持者则反驳说，ANT 并不主张扇贝和科学家在道德上平等，只是在方法论上不预设等级差异。

小结
    

  • ANT 将非人类实体（技术物、自然实体）纳入社会分析，打破了人类中心的社会理论传统
    • 

  • 转译的四个时刻（问题化、利益关联、征召、动员）提供了分析网络建构过程的系统方法
    • 

  • 技术物通过"铭刻"将社会规范凝固为物质形式，获得了持久的行动能力
    • 

  • ANT 拒绝自然/社会、人类/非人类、微观/宏观等二元对立
    • 

  • 对程序员而言，ANT 揭示了代码和技术架构本身就是具有"能动性"的行动者，能够塑造组织行为和社会关系
    •
