最短路径算法

最短路径问题的定义

给定加权图 G=(V,E,w)G = (V, E, w)G=(V,E,w)，其中 w:E→Rw: E \to \mathbb{R}w:E→R 为边权函数，两顶点 u,vu, vu,v 之间的最短路径是所有 uuu-vvv 路径中权重总和最小的路径。路径 P=v0,v1,…,vkP = v_0, v_1, \ldots, v_kP=v0​,v1​,…,vk​ 的权重定义为：

w(P)=∑i=1kw(vi−1,vi)w(P) = \sum_{i=1}^{k} w(v_{i-1}, v_i)w(P)=i=1∑k​w(vi−1​,vi​)

最短路径问题有多个变体：

  • 单源最短路径（SSSP）：从一个源顶点到所有其他顶点的最短路径
  • 单对最短路径：从特定源到特定目标的最短路径
  • 全源最短路径（APSP）：所有顶点对之间的最短路径

最优子结构性质：最短路径的任何子路径也是最短路径。即若 P=s→⋯→u→⋯→v→⋯→tP = s \to \cdots \to u \to \cdots \to v \to \cdots \to tP=s→⋯→u→⋯→v→⋯→t 是 sss 到 ttt 的最短路径，则 PPP 中 uuu 到 vvv 的子路径也是 uuu 到 vvv 的最短路径。这一性质是所有最短路径算法正确性的基础。

负权边的影响：当图中存在负权边时，最短路径可能不经过直觉上"最短"的边。更严重的是，如果图中存在负权环（总权为负的环），则不存在有意义的最短路径（可以绕负环无限多次使路径权趋于 −∞-\infty−∞）。

Dijkstra 算法

算法描述

Dijkstra 算法解决非负权图上的单源最短路径问题。核心思想是贪心：维护一个已确定最短距离的顶点集合 SSS，每次从未处理的顶点中选取距离估计最小的顶点加入 SSS。

初始化：d(s)=0d(s) = 0d(s)=0，d(v)=∞d(v) = \inftyd(v)=∞ 对所有 v≠sv \neq sv=s，S=∅S = \emptysetS=∅

主循环：

  1. 从 V∖SV \setminus SV∖S 中选取 d(u)d(u)d(u) 最小的顶点 uuu
  2. 将 uuu 加入 SSS
  3. 对 uuu 的每条出边 (u,v)(u, v)(u,v)，执行松弛操作：
if d(u)+w(u,v)<d(v) then d(v)←d(u)+w(u,v)\text{if } d(u) + w(u, v) < d(v) \text{ then } d(v) \leftarrow d(u) + w(u, v)if d(u)+w(u,v)<d(v) then d(v)←d(u)+w(u,v)
  1. 重复直到 S=VS = VS=V 或目标顶点被加入 SSS

正确性证明

引理：当顶点 uuu 被加入 SSS 时，d(u)d(u)d(u) 等于从 sss 到 uuu 的真实最短距离。

证明（反证法）：假设 uuu 是第一个加入 SSS 时 d(u)d(u)d(u) 不正确的顶点。则存在更短的 sss-uuu 路径 PPP。设 PPP 离开 SSS 的第一条边为 (x,y)(x, y)(x,y)（x∈Sx \in Sx∈S, y∉Sy \notin Sy∈/S）。由于 xxx 加入 SSS 时 d(x)d(x)d(x) 正确（uuu 是第一个出错的），松弛后 d(y)≤d(x)+w(x,y)≤w(P)<d(u)d(y) \leq d(x) + w(x, y) \leq w(P) < d(u)d(y)≤d(x)+w(x,y)≤w(P)<d(u)（因为所有权非负，PPP 中 yyy 到 uuu 的部分权重 ≥0\geq 0≥0）。但此时应选 yyy 而非 uuu（d(y)<d(u)d(y) < d(u)d(y)<d(u)），矛盾。□\square□

Dijkstra 的局限性

Dijkstra 算法不适用于含负权边的图。直觉原因：贪心策略假设"已确定的最短距离不会再被更新"，但负权边可能使通过更远顶点绕行反而更短。

反例：三角形图 s→as \to as→a 权 2，s→bs \to bs→b 权 4，b→ab \to ab→a 权 −3-3−3。Dijkstra 先确定 d(a)=2d(a) = 2d(a)=2，但实际最短路径 s→b→as \to b \to as→b→a 权为 4+(−3)=14 + (-3) = 14+(−3)=1。

Bellman-Ford 算法

算法描述

Bellman-Ford 算法解决可含负权边的单源最短路径问题，并能检测负权环。

初始化：d(s)=0d(s) = 0d(s)=0，d(v)=∞d(v) = \inftyd(v)=∞ 对所有 v≠sv \neq sv=s

主循环：重复 ∣V∣−1|V| - 1∣V∣−1 次：

  • 对图中每条边 (u,v)(u, v)(u,v)：执行松弛 d(v)←min⁡(d(v),d(u)+w(u,v))d(v) \leftarrow \min(d(v), d(u) + w(u, v))d(v)←min(d(v),d(u)+w(u,v))

负环检测：再执行一轮松弛。如果仍有距离被更新，则图中存在从 sss 可达的负权环。

正确性论证

引理：第 iii 轮松弛后，d(v)d(v)d(v) 不超过从 sss 到 vvv 的至多经过 iii 条边的最短路径权重。

由于无负权环时最短路径最多 ∣V∣−1|V| - 1∣V∣−1 条边（不重复顶点），∣V∣−1|V| - 1∣V∣−1 轮后所有最短距离正确。

复杂度

时间复杂度：O(∣V∣⋅∣E∣)O(|V| \cdot |E|)O(∣V∣⋅∣E∣)。每轮对所有边松弛，共 ∣V∣−1|V| - 1∣V∣−1 轮。

优化：如果某一轮没有任何距离被更新，可以提前终止。实践中，对随机图通常远不需要 ∣V∣−1|V| - 1∣V∣−1 轮。

SPFA 优化

SPFA（Shortest Path Faster Algorithm）是 Bellman-Ford 的队列优化版本。维护一个队列存放"距离刚被更新"的顶点，每次只对这些顶点的出边做松弛。平均情况下时间复杂度为 O(∣E∣)O(|E|)O(∣E∣)，但最坏情况仍为 O(∣V∣⋅∣E∣)O(|V| \cdot |E|)O(∣V∣⋅∣E∣)。

Floyd-Warshall 算法

算法描述

Floyd-Warshall 算法通过动态规划解决全源最短路径问题。定义 d(k)[i][j]d^{(k)}[i][j]d(k)[i][j] 为从顶点 iii 到顶点 jjj，中间顶点编号不超过 kkk 的最短路径权重。

递推关系：

d(k)[i][j]=min⁡(d(k−1)[i][j],  d(k−1)[i][k]+d(k−1)[k][j])d^{(k)}[i][j] = \min\left(d^{(k-1)}[i][j], \; d^{(k-1)}[i][k] + d^{(k-1)}[k][j]\right)d(k)[i][j]=min(d(k−1)[i][j],d(k−1)[i][k]+d(k−1)[k][j])

直觉：从 iii 到 jjj 的最短路径要么不经过顶点 kkk，要么先从 iii 到 kkk 再从 kkk 到 jjj。

初始化：d(0)[i][j]=w(i,j)d^{(0)}[i][j] = w(i, j)d(0)[i][j]=w(i,j)（若有边），d(0)[i][i]=0d^{(0)}[i][i] = 0d(0)[i][i]=0，其余为 ∞\infty∞。

实现：三层循环，外层枚举中间顶点 kkk，内两层枚举起终点 i,ji, ji,j。可以原地更新（不需要保留上一轮结果的独立副本）。

复杂度与特性

时间复杂度：O(∣V∣3)O(|V|^3)O(∣V∣3)，与边数无关。

空间复杂度：O(∣V∣2)O(|V|^2)O(∣V∣2)。

负环检测：算法结束后，若 d[i][i]<0d[i][i] < 0d[i][i]<0 对某个 iii，则存在经过 iii 的负权环。

适用场景：当需要所有顶点对的最短距离，且图不太大（∣V∣≤|V| \leq∣V∣≤ 几千）时，Floyd-Warshall 实现简单且高效。对于稀疏图的 APSP，运行 ∣V∣|V|∣V∣ 次 Dijkstra 可能更快（O(∣V∣⋅∣E∣log⁡∣V∣)O(|V| \cdot |E| \log |V|)O(∣V∣⋅∣E∣log∣V∣)）。

Johnson 算法

Johnson 算法结合了 Bellman-Ford 和 Dijkstra，可以处理含负权边的 APSP：

  1. 添加虚拟源点 qqq，向所有顶点连权为 0 的边
  2. 从 qqq 运行 Bellman-Ford，得到 h(v)=d(q,v)h(v) = d(q, v)h(v)=d(q,v)
  3. 对每条边 (u,v)(u, v)(u,v)，重新赋权 w^(u,v)=w(u,v)+h(u)−h(v)≥0\hat{w}(u, v) = w(u, v) + h(u) - h(v) \geq 0w^(u,v)=w(u,v)+h(u)−h(v)≥0
  4. 对每个顶点运行 Dijkstra（使用非负的 w^\hat{w}w^）
  5. 恢复原始距离：d(u,v)=d^(u,v)−h(u)+h(v)d(u, v) = \hat{d}(u, v) - h(u) + h(v)d(u,v)=d^(u,v)−h(u)+h(v)

重新赋权后所有边权非负（由三角不等式保证），因此可以使用高效的 Dijkstra。总时间复杂度 O(∣V∣⋅∣E∣log⁡∣V∣)O(|V| \cdot |E| \log |V|)O(∣V∣⋅∣E∣log∣V∣)，对稀疏图优于 Floyd-Warshall。

实际工程应用

导航系统：Google Maps 等导航使用分层最短路径算法（Contraction Hierarchies），预处理时间 O(nlog⁡n)O(n \log n)O(nlogn)，查询时间接近 O(1)O(1)O(1)，远优于原始 Dijkstra。核心思想是按"重要性"对顶点分层，查询时只在高层级搜索。

网络路由：OSPF 协议使用 Dijkstra 算法计算域内最短路径；BGP 协议使用类似 Bellman-Ford 的距离向量方法在自治系统之间路由。

社交网络：六度分隔理论的验证需要计算大规模图的平均最短路径长度。Facebook 在 2016 年的研究表明，其社交图的平均距离约为 3.57。
