图着色理论

顶点着色的基本概念

图着色（Graph Coloring）是为图的每个顶点分配一种"颜色"，使得相邻顶点不同色的过程。形式化地，图 G=(V,E)G = (V, E)G=(V,E) 的一个正常 kkk-着色是函数 c:V→{1,2,…,k}c: V \to \{1, 2, \ldots, k\}c:V→{1,2,…,k}，满足对每条边 {u,v}∈E\{u, v\} \in E{u,v}∈E 都有 c(u)≠c(v)c(u) \neq c(v)c(u)=c(v)。

色数（Chromatic Number）χ(G)\chi(G)χ(G) 是使 GGG 可正常着色的最小颜色数。确定一般图的色数是 NP 困难问题。

基本上下界：

ω(G)≤χ(G)≤Δ(G)+1\omega(G) \leq \chi(G) \leq \Delta(G) + 1ω(G)≤χ(G)≤Δ(G)+1

其中 ω(G)\omega(G)ω(G) 是最大团大小（完全子图的最大顶点数），Δ(G)\Delta(G)Δ(G) 是最大度。左边的下界是显然的（团中每个顶点需要不同颜色），右边是贪心着色的保证。

贪心着色算法

最简单的着色方法是贪心着色：按某个顺序处理顶点，为每个顶点分配"不与已着色邻居冲突的最小颜色编号"。

算法：

  1. 固定顶点的某个排列 v1,v2,…,vnv_1, v_2, \ldots, v_nv1​,v2​,…,vn​
  2. 对每个 viv_ivi​：c(vi)=min⁡{k≥1:k 未被 vi 的已着色邻居使用}c(v_i) = \min\{k \geq 1 : k \text{ 未被 } v_i \text{ 的已着色邻居使用}\}c(vi​)=min{k≥1:k 未被 vi​ 的已着色邻居使用}

使用颜色数上界：贪心着色最多使用 Δ(G)+1\Delta(G) + 1Δ(G)+1 种颜色（因为每个顶点最多有 Δ\DeltaΔ 个邻居，所以 {1,2,…,Δ+1}\{1, 2, \ldots, \Delta + 1\}{1,2,…,Δ+1} 中至少有一个可用）。

顺序的重要性：贪心着色的结果强烈依赖顶点排列顺序。最优顺序可以达到 χ(G)\chi(G)χ(G)，但最差顺序可能用远多于 χ(G)\chi(G)χ(G) 的颜色。找最优顺序本身就是 NP 困难的。

Welsh-Powell 启发式：按度数递减排序。直觉是先处理约束最多的顶点，通常能得到较好（但不保证最优）的着色。

Brooks 定理

定理（Brooks, 1941）：对于连通图 GGG，若 GGG 既不是完全图也不是奇数环，则 χ(G)≤Δ(G)\chi(G) \leq \Delta(G)χ(G)≤Δ(G)。

即除了两个例外情况，色数严格小于最大度加一。这比贪心着色的上界 Δ+1\Delta + 1Δ+1 改进了一步。

证明思路：关键是找到一个"好的"顶点排序。如果 GGG 不是完全图且不是奇数环，可以找到两个不相邻的顶点 u,vu, vu,v 和一个特殊的排序，使得 u,vu, vu,v 排在最前面（染相同颜色），而最后一个顶点 www 的所有邻居在它之前已经着色，且至少两个邻居同色。这样 www 只需要 Δ−1\Delta - 1Δ−1 种颜色之外的选择空间。

四色定理

定理（四色定理，Appel-Haken, 1976）：每个平面图都可以用至多 4 种颜色正常着色，即 χ(G)≤4\chi(G) \leq 4χ(G)≤4 对所有平面图 GGG 成立。

历史背景

四色猜想由 Francis Guthrie 在 1852 年提出，是数学史上最著名的猜想之一。经历了多次错误证明后，1976 年 Kenneth Appel 和 Wolfgang Haken 给出了第一个完整证明，但依赖计算机检验 1936 个（后简化为 633 个）"不可避免的可约构型"。

这是数学史上第一个本质上依赖计算机的证明，引发了关于"什么是证明"的哲学讨论。

五色定理

五色定理的证明（Kempe, 1890 简化版）相对简短，作为四色定理的弱化版本有教学价值：

证明（对顶点数归纳）：

  • 基础：∣V∣≤5|V| \leq 5∣V∣≤5 显然。
  • 归纳步：平面图有度数 ≤5\leq 5≤5 的顶点 vvv（由 E≤3V−6E \leq 3V - 6E≤3V−6）。删除 vvv，剩余图可 5-着色（归纳假设）。
    • 若 vvv 的邻居使用了至多 4 种颜色，vvv 用第 5 种颜色。
    • 若 vvv 的 5 个邻居恰好用了 5 种颜色：利用 Kempe 链交换技术——考虑颜色 iii 和 jjj 的交替子图（Kempe 链），若两个特定邻居不在同一条 Kempe 链上，可以交换其中一条链的颜色，为 vvv 腾出一种颜色。平面性保证了不可能所有对都在同一条 Kempe 链上。□\square□

色多项式

色多项式 P(G,k)P(G, k)P(G,k) 计算图 GGG 的正常 kkk-着色的总数（包括颜色排列）。

基本递推（删边-缩边公式）：对任何边 e={u,v}e = \{u, v\}e={u,v}：

P(G,k)=P(G−e,k)−P(G/e,k)P(G, k) = P(G - e, k) - P(G / e, k)P(G,k)=P(G−e,k)−P(G/e,k)

其中 G−eG - eG−e 是删去边 eee，G/eG / eG/e 是收缩边 eee（将 u,vu, vu,v 合并为一个顶点）。

边着色与 Vizing 定理

边着色（Edge Coloring）是为每条边分配颜色，使得共享端点的边不同色。边色数（Chromatic Index）记为 χ′(G)\chi'(G)χ′(G)。

显然 χ′(G)≥Δ(G)\chi'(G) \geq \Delta(G)χ′(G)≥Δ(G)（度数最大的顶点的所有关联边必须不同色）。

定理（Vizing, 1964）：对简单图 GGG，χ′(G)∈{Δ(G),Δ(G)+1}\chi'(G) \in \{\Delta(G), \Delta(G) + 1\}χ′(G)∈{Δ(G),Δ(G)+1}。

即边色数只有两种可能值！据此将简单图分为两类：

  • Class 1（第一类）：χ′(G)=Δ(G)\chi'(G) = \Delta(G)χ′(G)=Δ(G)
  • Class 2（第二类）：χ′(G)=Δ(G)+1\chi'(G) = \Delta(G) + 1χ′(G)=Δ(G)+1

判断一个图属于哪一类是 NP 完全问题，但某些图类有简单判据：

  • 二部图一定是 Class 1（König 边着色定理）
  • 奇数阶正则图一定是 Class 2
  • 彼得森图是 Class 2

图着色的应用

寄存器分配：编译器优化中，将变量的生命期建模为图（同时活跃的变量相邻），图着色对应寄存器分配。kkk 种颜色 = kkk 个寄存器。若 χ(G)>k\chi(G) > kχ(G)>k，需要将部分变量"溢出"到内存。

频率分配：无线通信中，地理位置靠近的基站不能使用相同频率（会干扰）。将基站建模为图的顶点、干扰关系为边，频率分配就是图着色问题。最小化频率数 = 最小化色数。

时间表调度：考试安排中，有共同考生的科目不能安排在同一时段。将科目作为顶点、冲突关系为边，时间段分配 = 图着色。色数 = 最少需要的时间段数。

地图着色：虽然四色定理保证 4 色足够，但在实际地图印刷中，有时使用更多颜色以提高可辨识度。色数的精确计算帮助确定最少颜色需求。

Sudoku：数独可以建模为图着色问题——81 个格子为顶点，同行/同列/同宫的格子之间有边，9 种数字 = 9 种颜色。预填的数字 = 已固定的着色约束。
