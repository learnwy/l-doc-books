路径、连通性与图的结构

路径与回路的基本概念

在图 G=(V,E)G = (V, E)G=(V,E) 中，途径（walk）是一个顶点和边的交替序列 v0,e1,v1,e2,v2,…,ek,vkv_0, e_1, v_1, e_2, v_2, \ldots, e_k, v_kv0​,e1​,v1​,e2​,v2​,…,ek​,vk​，其中每条边 eie_iei​ 连接 vi−1v_{i-1}vi−1​ 和 viv_ivi​。途径的长度为 kkk（经过的边数）。

基于途径的不同约束，产生几个关键概念：

  • 迹（trail）：边不重复的途径
  • 路径（path）：顶点不重复（从而边也不重复）的途径
  • 回路（cycle）：起点等于终点（v0=vkv_0 = v_kv0​=vk​）且除首尾外顶点不重复的途径，长度至少为 3

命题：若 uuu 和 vvv 之间存在途径，则它们之间必存在路径。

证明：取 uuu 到 vvv 的最短途径。如果有重复顶点 www（出现在位置 iii 和 jjj，i<ji < ji<j），则删除 viv_ivi​ 到 vjv_jvj​ 之间的部分，得到更短的途径。重复此过程直到无重复顶点。□\square□

距离：两顶点 u,vu, vu,v 之间的距离 d(u,v)d(u, v)d(u,v) 定义为最短路径的长度。若不存在路径，则 d(u,v)=∞d(u, v) = \inftyd(u,v)=∞。距离函数满足度量空间的三个公理：

  1. d(u,v)≥0d(u, v) \geq 0d(u,v)≥0，且 d(u,v)=0⇔u=vd(u, v) = 0 \Leftrightarrow u = vd(u,v)=0⇔u=v
  2. d(u,v)=d(v,u)d(u, v) = d(v, u)d(u,v)=d(v,u)（对无向图）
  3. d(u,w)≤d(u,v)+d(v,w)d(u, w) \leq d(u, v) + d(v, w)d(u,w)≤d(u,v)+d(v,w)（三角不等式）

直径：图 GGG 的直径 diam(G)=max⁡u,v∈Vd(u,v)\text{diam}(G) = \max_{u, v \in V} d(u, v)diam(G)=maxu,v∈V​d(u,v)，即所有顶点对之间最短距离的最大值。

连通性

无向图的连通性

无向图 GGG 是连通的（connected），如果任意两个顶点之间都存在路径。图的连通分量（connected component）是极大连通子图——不能再添加任何顶点和边使其仍然连通。

命题：nnn 个顶点的连通图至少有 n−1n - 1n−1 条边。

证明：对 nnn 归纳。n=1n = 1n=1 时显然。对 n>1n > 1n>1，取任意顶点 vvv，删除 vvv 及其关联边。若剩余图连通，则由归纳假设有至少 n−2n - 2n−2 条边，加上 vvv 至少关联 1 条边，总计至少 n−1n - 1n−1。若剩余图不连通，则 vvv 至少连接两个分量，度数至少 2，各分量加起来至少 n−2n - 2n−2 条边加上 vvv 的至少 2 条边，仍满足条件。□\square□

恰好有 n−1n - 1n−1 条边的连通图就是树，这是图论中最重要的结构之一。

有向图的连通性

有向图的连通性更为精细，分为两个层次：

  • 弱连通：忽略边的方向后，底层无向图是连通的
  • 强连通：对任意两个顶点 u,vu, vu,v，既存在从 uuu 到 vvv 的有向路径，也存在从 vvv 到 uuu 的有向路径

强连通分量（Strongly Connected Component, SCC）是有向图中的极大强连通子图。将每个 SCC 缩为一个点，得到的缩点图（condensation）一定是有向无环图（DAG）。

割点、桥与块结构

割点

顶点 vvv 是图 GGG 的割点（cut vertex / articulation point），如果删除 vvv 及其关联边后，图的连通分量数增加。

定理：对于连通图 GGG，vvv 是割点当且仅当存在与 vvv 不同的两个顶点 u,wu, wu,w，使得 vvv 在 uuu 到 www 的每条路径上。

割点的存在意味着网络的脆弱性——单点故障就能使网络分裂。在通信网络设计中，消除割点（即提高连通度）是提升可靠性的关键。

桥

边 eee 是图 GGG 的桥（bridge），如果删除 eee 后连通分量数增加。

定理：边 e={u,v}e = \{u, v\}e={u,v} 是桥，当且仅当 eee 不属于 GGG 中的任何回路。

证明：

  • (⇒\Rightarrow⇒) 若 eee 属于某个回路 CCC，则删除 eee 后 uuu 和 vvv 仍可通过 CCC 的另一半相连，eee 不是桥，矛盾。
  • (⇐\Leftarrow⇐) 若 eee 不是桥，则删除 eee 后 uuu 和 vvv 仍连通，存在不经过 eee 的路径 PPP，则 P+eP + eP+e 构成包含 eee 的回路，矛盾。□\square□

块结构

块（block）是没有割点的极大连通子图。图的块结构可以用块-割点树（block-cut tree）来描述：

  • 节点分为两类：块节点和割点节点
  • 块节点与割点节点之间有边，当且仅当该割点属于该块

块-割点树揭示了图的层次分解结构，每个块内部是"坚固的"（双连通），块之间通过割点"脆弱地"连接。

连通度

顶点连通度 κ(G)\kappa(G)κ(G)：使图不连通所需删除的最少顶点数。若 κ(G)≥k\kappa(G) \geq kκ(G)≥k，称图是 kkk-连通的。

边连通度 λ(G)\lambda(G)λ(G)：使图不连通所需删除的最少边数。若 λ(G)≥k\lambda(G) \geq kλ(G)≥k，称图是 kkk-边连通的。

Whitney 不等式：

κ(G)≤λ(G)≤δ(G)\kappa(G) \leq \lambda(G) \leq \delta(G)κ(G)≤λ(G)≤δ(G)

即顶点连通度不超过边连通度，边连通度不超过最小度。

Menger 定理：uuu 和 vvv 之间的最大内部顶点不相交路径数等于最小的 uuu-vvv 分离集大小。这是图论中最深刻的定理之一，它将连通度（全局性质）与局部路径结构联系起来，也是最大流最小割定理的离散版本。

Tarjan 算法求强连通分量

Tarjan 算法利用 DFS 的时间戳和回溯特性，在 O(n+m)O(n + m)O(n+m) 时间内求出有向图的所有强连通分量。

核心思想：在 DFS 过程中，维护一个栈存放当前路径上的顶点。每个顶点 vvv 记录两个值：

  • dfn(v)\text{dfn}(v)dfn(v)：DFS 访问 vvv 的时间戳
  • low(v)\text{low}(v)low(v)：从 vvv 出发，通过树边和至多一条回边，能到达的最小 DFS 时间戳

当 DFS 完成对 vvv 的所有后代的访问后，若 low(v)=dfn(v)\text{low}(v) = \text{dfn}(v)low(v)=dfn(v)，则 vvv 是某个 SCC 的根，栈中从 vvv 到栈顶的所有顶点构成一个 SCC。

算法步骤：

  1. 对未访问的顶点调用 DFS
  2. 进入顶点时：分配 dfn 和 low，入栈
  3. 对每条出边 (v,w)(v, w)(v,w)：
    • 若 www 未访问：递归 DFS，回溯时 low(v)=min⁡(low(v),low(w))\text{low}(v) = \min(\text{low}(v), \text{low}(w))low(v)=min(low(v),low(w))
    • 若 www 在栈中：low(v)=min⁡(low(v),dfn(w))\text{low}(v) = \min(\text{low}(v), \text{dfn}(w))low(v)=min(low(v),dfn(w))
  4. 若 low(v)=dfn(v)\text{low}(v) = \text{dfn}(v)low(v)=dfn(v)：弹出栈顶直到 vvv，形成一个 SCC

时间复杂度：O(∣V∣+∣E∣)O(|V| + |E|)O(∣V∣+∣E∣)，每个顶点和每条边恰好被处理一次。

连通性在实际系统中的意义

互联网路由：互联网的 AS 级拓扑需要高连通度来保证鲁棒性。Tier-1 ISP 之间通常是多路径连接（高边连通度），而末端网络可能只有单一上游连接（桥边），这是网络可靠性的薄弱点。

社交网络分析：强连通分量对应"紧密社区"——社区内部任意两人都可以通过关系链互相到达。弱连通分量中连接不同 SCC 的"桥梁节点"在信息传播中扮演关键角色（Granovetter 的"弱连接力量"理论）。

供应链管理：将供应商和客户建模为有向图的顶点，割点代表供应链中的单点故障风险。识别和冗余化这些关键节点是供应链韧性设计的核心。

编译器优化：程序控制流图中的强连通分量对应循环结构，支配树（基于连通性分析）用于指导循环不变量外提、代码移动等优化。
