图论在计算机科学中的应用

编译器与程序分析

控制流图

编译器将程序的执行逻辑表示为控制流图（Control Flow Graph, CFG）：基本块为顶点，控制转移（跳转、分支、函数调用）为有向边。CFG 是几乎所有程序分析和优化的基础数据结构。

支配树（Dominator Tree）：在 CFG 中，若从入口到达 vvv 的每条路径都经过 uuu，则 uuu 支配 vvv。支配关系形成树结构。Lengauer-Tarjan 算法在 O(∣E∣⋅α(∣V∣))O(|E| \cdot \alpha(|V|))O(∣E∣⋅α(∣V∣)) 时间内构造支配树。

支配树的应用：

  • 循环识别：自然循环的入口是循环体的支配节点
  • 代码移动：支配关系决定了安全移动代码的位置
  • SSA 构造：静态单赋值形式的 ϕ\phiϕ 函数插入位置由支配边界决定

数据流分析

数据流分析在 CFG 上定义格值方程组，通过迭代求不动点：

out(B)=fB(in(B)),in(B)=⨆P∈pred(B)out(P)\text{out}(B) = f_B(\text{in}(B)), \quad \text{in}(B) = \bigsqcup_{P \in \text{pred}(B)} \text{out}(P)out(B)=fB​(in(B)),in(B)=P∈pred(B)⨆​out(P)

其中 ⨆\bigsqcup⨆ 是格上的合并操作（如并集或交集）。

经典数据流分析问题：

  • 到达定义：哪些赋值语句的结果可能在某点被使用
  • 活跃变量：哪些变量在某点后还会被读取
  • 可用表达式：哪些表达式在某点已计算且未被修改

数据流分析的收敛速度与 CFG 的结构密切相关——按逆后序（reverse postorder，本质是拓扑排序的近似）遍历节点可以加速收敛。

寄存器分配

寄存器分配本质上是图着色问题。构造干涉图（Interference Graph）：变量为顶点，两个变量在程序某点同时活跃则相邻。kkk 种颜色对应 kkk 个物理寄存器。

若干涉图的色数 χ>k\chi > kχ>k，需要"溢出"某些变量到内存。Chaitin 的寄存器分配器使用简化规则：度数 <k< k<k 的顶点总能着色，可以先移除再逐步还原。

现代编译器（如 LLVM）使用更复杂的方法（线性扫描、PBQP），但图着色仍是理论基础。

数据库系统

查询优化

SQL 查询涉及多表连接（JOIN），连接顺序对性能影响巨大。查询优化器将可能的连接计划建模为图结构：

连接图（Join Graph）：表为顶点，连接条件为边。查询优化的目标是找到最优的连接树——一个覆盖所有表的树结构。

对星型查询（中心事实表 + 维度表），连接图是星形的，最优计划通常以事实表为中心。对复杂的环形查询，找最优连接顺序是 NP 困难的，需要动态规划或贪心启发式。

事务依赖与串行化

并发事务之间的冲突关系可以建模为冲突图（Conflict Graph / Precedence Graph）：

  • 事务为顶点
  • 若事务 TiT_iTi​ 和 TjT_jTj​ 有冲突操作且 TiT_iTi​ 的冲突操作先执行，则 Ti→TjT_i \to T_jTi​→Tj​

定理：调度是冲突可串行化的当且仅当冲突图是无环的（DAG）。

此时拓扑排序给出等价的串行执行顺序。数据库系统（如 PostgreSQL）使用此图来检测死锁和保证事务隔离。

死锁检测

事务的等待关系形成等待图（Wait-For Graph）：事务 TiT_iTi​ 等待 TjT_jTj​ 持有的锁时，Ti→TjT_i \to T_jTi​→Tj​。等待图中的环 = 死锁。

数据库定期（或事件驱动地）检测等待图中的环。发现死锁后选择代价最小的事务回滚（打破环）。

机器学习与人工智能

概率图模型

贝叶斯网络是 DAG，节点为随机变量，边表示条件依赖关系。DAG 结构编码了条件独立性：

P(X1,…,Xn)=∏i=1nP(Xi∣Parents(Xi))P(X_1, \ldots, X_n) = \prod_{i=1}^n P(X_i \mid \text{Parents}(X_i))P(X1​,…,Xn​)=i=1∏n​P(Xi​∣Parents(Xi​))

关键算法：

  • 信念传播（Belief Propagation）：在树结构图上精确推理，O(n)O(n)O(n)
  • 变量消元：按特定顺序消除变量，复杂度取决于图的树宽（treewidth）
  • 最大后验推断：等价于最大权匹配或最小割问题（对特定图结构）

马尔可夫随机场（MRF）是无向图模型，节点间的势函数定义联合分布。图像分割、去噪等任务常建模为 MRF，通过图割（min-cut）算法高效求解。

图神经网络（GNN）

图神经网络直接在图结构数据上进行学习：

消息传递范式：每个节点通过聚合邻居的特征来更新自身表示：

hv(l+1)=UPDATE(hv(l),AGGREGATE({hu(l):u∈N(v)}))h_v^{(l+1)} = \text{UPDATE}\left(h_v^{(l)}, \text{AGGREGATE}\left(\{h_u^{(l)} : u \in N(v)\}\right)\right)hv(l+1)​=UPDATE(hv(l)​,AGGREGATE({hu(l)​:u∈N(v)}))

主要架构：

  • GCN（Graph Convolutional Network）：H(l+1)=σ(D~−1/2A~D~−1/2H(l)W(l))H^{(l+1)} = \sigma(\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}H^{(l)}W^{(l)})H(l+1)=σ(D~−1/2A~D~−1/2H(l)W(l))
  • GAT（Graph Attention Network）：注意力权重的邻居聚合
  • GraphSAGE：采样邻居 + 聚合函数

应用：分子性质预测、社交网络推荐、知识图谱推理、交通流量预测。

知识图谱

知识图谱以三元组 (h,r,t)(h, r, t)(h,r,t) 表示实体间关系，本质上是有向标签图。

  • 链接预测：预测缺失的边（如 TransE 将关系建模为向量平移 h+r≈th + r \approx th+r≈t）
  • 实体对齐：在不同知识图谱间匹配相同实体（图匹配问题）
  • 推理：沿图中路径进行逻辑推理

社交网络分析

社区检测

社交网络中"社区"对应图中内部连接密集、与外部连接稀疏的子图。

模块度（Modularity）QQQ 衡量社区划分质量：

Q=12m∑ij[Aij−didj2m]δ(ci,cj)Q = \frac{1}{2m}\sum_{ij}\left[A_{ij} - \frac{d_i d_j}{2m}\right]\delta(c_i, c_j)Q=2m1​ij∑​[Aij​−2mdi​dj​​]δ(ci​,cj​)

其中 δ(ci,cj)=1\delta(c_i, c_j) = 1δ(ci​,cj​)=1 当 i,ji, ji,j 在同一社区。

经典算法：

  • Louvain 算法：贪心优化模块度，O(nlog⁡n)O(n \log n)O(nlogn)，适合大规模图
  • 谱聚类：利用图拉普拉斯矩阵的特征向量
  • 标签传播：每个节点采用邻居中最频繁的标签

影响力传播

独立级联模型（IC）和线性阈值模型（LT）在图上模拟信息/疾病传播：

  • IC 模型：已激活节点以概率 puvp_{uv}puv​ 激活邻居
  • LT 模型：节点在邻居激活比例超过阈值时激活

影响力最大化：选择 kkk 个种子节点使期望传播范围最大。Kempe 等人证明此问题是 NP 困难的，但目标函数是单调子模函数，贪心算法可保证 (1−1/e)(1 - 1/e)(1−1/e) 近似比。

PageRank

Google 的 PageRank 算法将网页重要性建模为有向图上的随机游走稳态分布：

PR(v)=1−d∣V∣+d∑u→vPR(u)d+(u)\text{PR}(v) = \frac{1-d}{|V|} + d \sum_{u \to v} \frac{\text{PR}(u)}{d^+(u)}PR(v)=∣V∣1−d​+du→v∑​d+(u)PR(u)​

其中 d≈0.85d \approx 0.85d≈0.85 是阻尼因子。从线性代数角度，PageRank 向量是随机矩阵的主特征向量。

其他应用领域

计算几何：Voronoi 图和 Delaunay 三角剖分是平面图，许多几何算法（最近点对、凸包）利用图结构。

形式验证：模型检测将系统建模为状态转移图，通过图算法（可达性、环检测）验证时态逻辑性质。

自然语言处理：依存句法分析将句子表示为有向树（依存树），最大生成树算法用于非投射依存分析。

生物信息学：蛋白质相互作用网络、代谢通路、进化树都是图结构。de Bruijn 图在基因组组装中是核心数据结构，欧拉路径对应完整基因组序列。

量子计算：量子电路可以表示为 DAG（量子门为顶点），电路优化本质上是 DAG 的变换和化简。图态（Graph State）是量子纠错和测量基量子计算的基础。
