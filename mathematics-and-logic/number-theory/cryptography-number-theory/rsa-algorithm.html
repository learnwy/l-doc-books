RSA 算法的数学原理

核心概念

RSA（Rivest-Shamir-Adleman）是第一个实用的公钥密码体制，于 1977 年提出，至今仍是互联网安全的基石。RSA 的数学基础完全建立在数论之上：大素数生成、欧拉定理、模逆运算、大整数分解的计算困难性。理解 RSA 不仅需要掌握这些数论工具，更需要理解"单向陷门函数"的思想——一个方向计算容易（加密），反方向计算困难（破解），但拥有"陷门"（私钥）时反方向也变得容易（解密）。

RSA 的安全性假设是：给定 n = p·q（p, q 是大素数），从 n 分解出 p 和 q 在计算上是不可行的。目前已知最高效的经典分解算法（通用数域筛法）对 2048 位的 n 需要的计算量远超人类当前算力。

密钥生成过程
RSA 密钥生成是整个算法的核心步骤，直接决定了系统的安全性。生成过程涉及四个关键数论操作：大素数生成、欧拉函数计算、互素性检验、模逆计算。


步骤一：随机选择两个大素数 p 和 q。实际中通过生成随机奇数再用 Miller-Rabin 素性检验确认。p 和 q 的位长应大致相等（各约 1024 位），且 |p - q| 应足够大以防止费马分解法。


步骤二：计算 n = p · q 和 φ(n) = (p-1)(q-1)。注意 φ(n) 必须保密——知道 φ(n) 等价于知道 p 和 q（因为 p+q = n - φ(n) + 1 且 p·q = n，联立即可解出 p 和 q）。


步骤三：选择公钥指数 e，满足 1 < e < φ(n) 且 gcd(e, φ(n)) = 1。工业标准选择 e = 65537 = 2¹⁶ + 1（费马素数），因为二进制表示中只有两个 1，使得模幂运算只需 17 次平方和 1 次乘法，非常高效。


步骤四：通过扩展欧几里得算法计算 d = e⁻¹ mod φ(n)，即 e·d ≡ 1 (mod φ(n))。


const gcd = (a: number, b: number): number => (b === 0 ? a : gcd(b, a % b));

const extGcd = (a: number, b: number): { g: number; x: number; y: number } => {
  if (b === 0) return { g: a, x: 1, y: 0 };
  const { g, x, y } = extGcd(b, a % b);
  return { g, x: y, y: x - Math.floor(a / b) * y };
};

const modInverse = (a: number, m: number): number => {
  const { g, x } = extGcd(a, m);
  if (g !== 1) throw new Error('逆元不存在');
  return ((x % m) + m) % m;
};

const modPow = (base: number, exp: number, mod: number): number => {
  let result = 1;
  base = ((base % mod) + mod) % mod;
  while (exp > 0) {
    if (exp & 1) result = (result * base) % mod;
    exp >>= 1;
    base = (base * base) % mod;
  }
  return result;
};

const generateRSAKeys = (p: number, q: number) => {
  const n = p * q;
  const phiN = (p - 1) * (q - 1);
  const e = 65537 < phiN && gcd(65537, phiN) === 1 ? 65537 : 17;
  const d = modInverse(e, phiN);

  return {
    publicKey: { e, n },
    privateKey: { d, n },
    params: { p, q, phiN },
  };
};

const keys = generateRSAKeys(61, 53);
console.log('公钥 (e, n):', keys.publicKey);
console.log('私钥 (d, n):', keys.privateKey);
console.log('参数:', keys.params);
console.log('验证 e·d mod φ(n):', (keys.publicKey.e * keys.privateKey.d) % keys.params.phiN);
加密解密与正确性证明
加密：持有公钥 (e, n) 的任何人可以将明文 m（0 ≤ m < n）加密为密文 c = m^e mod n。解密：持有私钥 (d, n) 的人可以恢复明文 m = c^d mod n。


正确性证明依赖欧拉定理。需要证明 (m^e)^d ≡ m (mod n)，即 m^{ed} ≡ m (mod n)。


因为 ed ≡ 1 (mod φ(n))，所以 ed = 1 + k·φ(n)。当 gcd(m, n) = 1 时，由欧拉定理 m^{φ(n)} ≡ 1 (mod n)，得 m^{ed} = m^{1+k·φ(n)} = m · (m^{φ(n)})^k ≡ m · 1^k = m (mod n)。


当 gcd(m, n) > 1 时（即 m 是 p 或 q 的倍数），需要分别用 p 和 q 作为模数验证。若 p | m，则 m^{ed} ≡ 0 ≡ m (mod p)。若 p ∤ m，由费马小定理 m^{p-1} ≡ 1 (mod p)，因此 m^{ed} = m^{1+k(p-1)(q-1)} ≡ m · (m^{p-1})^{k(q-1)} ≡ m (mod p)。同理对 q 成立。由中国剩余定理，m^{ed} ≡ m (mod n)。


const rsaEncrypt = (m: number, e: number, n: number): number => modPow(m, e, n);
const rsaDecrypt = (c: number, d: number, n: number): number => modPow(c, d, n);

const { publicKey, privateKey } = generateRSAKeys(61, 53);
const testMessages = [0, 1, 42, 100, 1000, 3000];

for (const m of testMessages) {
  if (m >= publicKey.n) continue;
  const c = rsaEncrypt(m, publicKey.e, publicKey.n);
  const decrypted = rsaDecrypt(c, privateKey.d, privateKey.n);
  console.log(`m=${m} → c=${c} → m'=${decrypted} ${m === decrypted ? '✓' : '✗'}`);
}

RSA 数字签名
RSA 不仅能加密，还能实现数字签名。签名的思路是"用私钥加密"：签名者用私钥 d 对消息哈希 h(m) 计算签名 s = h(m)^d mod n，验证者用公钥 e 验证 s^e mod n = h(m)。


数字签名提供了三个安全属性：认证性（只有私钥持有者能生成有效签名）、完整性（消息被篡改后签名验证失败）、不可否认性（签名者无法否认曾签署过的消息）。


实际中不直接对消息签名，而是对消息的哈希值签名（如 SHA-256），因为哈希值长度固定且远小于 n。PKCS#1 v2.1 标准定义了 RSA-PSS 签名方案，增加了随机填充以提供更强的安全证明。


const simpleHash = (message: string): number => {
  let hash = 0;
  for (let i = 0; i < message.length; i++) {
    hash = ((hash << 5) - hash + message.charCodeAt(i)) & 0x7fffffff;
  }
  return hash;
};

const rsaSign = (messageHash: number, d: number, n: number): number => modPow(messageHash % n, d, n);

const rsaVerify = (messageHash: number, signature: number, e: number, n: number): boolean =>
  modPow(signature, e, n) === messageHash % n;

const message = 'Hello RSA';
const hash = simpleHash(message) % publicKey.n;
const signature = rsaSign(hash, privateKey.d, privateKey.n);
const isValid = rsaVerify(hash, signature, publicKey.e, publicKey.n);

console.log(`消息: "${message}"`);
console.log(`哈希: ${hash}`);
console.log(`签名: ${signature}`);
console.log(`验证: ${isValid ? '有效' : '无效'}`);

const tamperedHash = simpleHash('Hello RSB') % publicKey.n;
const tamperedValid = rsaVerify(tamperedHash, signature, publicKey.e, publicKey.n);
console.log(`篡改验证: ${tamperedValid ? '有效(危险!)' : '无效(正确拒绝)'}`);
安全性分析与攻击向量
RSA 的安全性归结为大整数分解问题（Integer Factorization Problem）：给定 n = p·q，找到 p 和 q。目前没有已知的经典多项式时间算法能解决这个问题。


主要攻击方式和防御措施：


小公钥指数攻击：若 e 过小（如 e=3）且消息未填充，攻击者可以直接开 e 次根恢复明文。防御：使用标准填充方案（OAEP）。


共模攻击：如果两个用户共享同一个 n 但使用不同的 e₁、e₂（且 gcd(e₁,e₂)=1），攻击者可以通过扩展欧几里得算法从两个密文恢复明文。防御：每个用户使用独立的 n。


时序攻击：通过测量解密时间推断私钥位。防御：恒定时间实现 + RSA 盲化。


const trialDivision = (n: number): { p: number; q: number } | null => {
  for (let i = 2; i * i <= n; i++) {
    if (n % i === 0) return { p: i, q: Math.floor(n / i) };
  }
  return null;
};

const fermatFactor = (n: number): { p: number; q: number } | null => {
  let a = Math.ceil(Math.sqrt(n));
  let b2 = a * a - n;
  const maxIter = 10000;
  for (let i = 0; i < maxIter; i++) {
    const b = Math.sqrt(b2);
    if (Math.abs(b - Math.round(b)) < 1e-6) {
      const bInt = Math.round(b);
      return { p: a + bInt, q: a - bInt };
    }
    a++;
    b2 = a * a - n;
  }
  return null;
};

const n = 61 * 53;
console.log(`n = ${n}`);
console.log('试除法分解:', trialDivision(n));
console.log('费马分解:', fermatFactor(n));

const closeN = 101 * 103;
console.log(`\n近似素数 n = ${closeN}`);
console.log('费马分解:', fermatFactor(closeN));

小结
    

  • RSA 是基于大整数分解困难性的公钥密码体制，密钥生成依赖素数选择和欧拉函数
    • 

  • 加密 c = m^e mod n 和解密 m = c^d mod n 的正确性由欧拉定理保证
    • 

  • 数字签名利用 RSA 的对称结构：私钥签名 s = h^d mod n，公钥验证 s^e mod n = h
    • 

  • 工业标准选择 e = 65537 兼顾安全性和计算效率，密钥长度至少 2048 位
    • 

  • RSA 面临多种攻击向量，合理的参数选择和标准填充方案（OAEP/PSS）是安全使用的前提
    • 

  • 量子计算机的 Shor 算法可在多项式时间内分解大整数，是 RSA 的长期威胁
    •
