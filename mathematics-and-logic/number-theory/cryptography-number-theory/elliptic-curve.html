椭圆曲线密码学

核心概念

椭圆曲线密码学（Elliptic Curve Cryptography, ECC）是现代密码学中最高效的公钥密码体制。ECC 基于椭圆曲线上离散对数问题（ECDLP）的困难性，核心优势是用更短的密钥达到与 RSA 同等甚至更高的安全性——256 位 ECC 密钥的安全强度相当于 3072 位 RSA 密钥。TLS 1.3 将 ECC（特别是 X25519 和 P-256）作为默认密钥交换方案，比特币和以太坊的数字签名也基于椭圆曲线（secp256k1）。

椭圆曲线不是椭圆，而是满足 Weierstrass 方程 y² = x³ + ax + b 的点集加上一个无穷远点 O。在有限域 F_p 上，这些点构成一个加法群，群运算通过几何上的"弦切法"定义。ECDLP 问题是：给定基点 G 和点 Q = kG（k 次标量乘法），求整数 k。与 Z_p* 上的 DLP 不同，椭圆曲线群上没有已知的亚指数时间经典算法（没有 Index Calculus 的类比），因此 ECC 能用更短的密钥保证安全。

椭圆曲线方程与点群
椭圆曲线的 Weierstrass 方程为 y² = x³ + ax + b，其中判别式 Δ = -16(4a³ + 27b²) ≠ 0（确保曲线无奇异点）。在实数域上，曲线呈现出优美的对称形态；在有限域 F_p（p > 3 为素数）上，曲线退化为一组离散的点。


椭圆曲线上的点集 E(F_p) = {(x, y) ∈ F_p × F_p : y² ≡ x³ + ax + b (mod p)} ∪ {O} 构成一个加法群。群运算的几何定义：两点 P, Q 的"加法"是通过 P, Q 画直线，与曲线交于第三点 R'，再取 R' 关于 x 轴的对称点 R = P + Q。无穷远点 O 是群的零元素。


点加法的代数公式：设 P = (x₁, y₁), Q = (x₂, y₂)。当 P ≠ Q 时，斜率 λ = (y₂ - y₁)/(x₂ - x₁)；当 P = Q 时（切线），λ = (3x₁² + a)/(2y₁)。结果点 R = (x₃, y₃)，x₃ = λ² - x₁ - x₂, y₃ = λ(x₁ - x₃) - y₁。所有运算在 F_p 上进行（除法即模逆）。


const modPow = (base: number, exp: number, mod: number): number => {
  let result = 1;
  base = ((base % mod) + mod) % mod;
  while (exp > 0) {
    if (exp & 1) result = (result * base) % mod;
    exp >>= 1;
    base = (base * base) % mod;
  }
  return result;
};

const modInverse = (a: number, p: number): number => modPow(((a % p) + p) % p, p - 2, p);

type Point = { x: number; y: number } | 'O';

const pointAdd = (P: Point, Q: Point, a: number, p: number): Point => {
  if (P === 'O') return Q;
  if (Q === 'O') return P;
  if (P.x === Q.x && (P.y + Q.y) % p === 0) return 'O';

  let lambda: number;
  if (P.x === Q.x && P.y === Q.y) {
    lambda = (((3 * P.x * P.x + a) % p) * modInverse(2 * P.y, p)) % p;
  } else {
    lambda = (((((Q.y - P.y) % p) + p) % p) * modInverse((((Q.x - P.x) % p) + p) % p, p)) % p;
  }

  const x3 = (((lambda * lambda - P.x - Q.x) % p) + p) % p;
  const y3 = (((lambda * (P.x - x3) - P.y) % p) + p) % p;
  return { x: x3, y: y3 };
};

const scalarMult = (k: number, P: Point, a: number, p: number): Point => {
  let result: Point = 'O';
  let current = P;
  while (k > 0) {
    if (k & 1) result = pointAdd(result, current, a, p);
    current = pointAdd(current, current, a, p);
    k >>= 1;
  }
  return result;
};

const a = 2,
  b = 3,
  p = 97;
const G: Point = { x: 3, y: 6 };
const verify = (pt: Point): boolean => {
  if (pt === 'O') return true;
  const lhs = (pt.y * pt.y) % p;
  const rhs = (((pt.x * pt.x * pt.x + a * pt.x + b) % p) + p) % p;
  return lhs === rhs;
};

console.log(
  `基点 G = (${(G as { x: number; y: number }).x}, ${(G as { x: number; y: number }).y}), 在曲线上: ${verify(G)}`,
);
for (let k = 1; k <= 10; k++) {
  const Q = scalarMult(k, G, a, p);
  const onCurve = verify(Q);
  console.log(`${k}G = ${Q === 'O' ? 'O' : `(${Q.x}, ${Q.y})`} ${onCurve ? '✓' : '✗'}`);
}
ECDLP 与标量乘法
椭圆曲线离散对数问题（ECDLP）是 ECC 安全性的核心：给定曲线上的点 G（基点）和点 Q = kG，求标量 k。正向计算 kG 通过"倍加法"（Double-and-Add）在 O(log k) 步完成，但反向求解 k 在一般椭圆曲线群上的最优算法是 Pollard ρ，复杂度为 O(√n)（n 是群的阶），没有亚指数时间的经典算法。


这个差异是 ECC 高效性的根源：RSA 的安全性依赖的大整数分解可以用 GNFS（亚指数时间 L[1/3]）攻击，因此需要很长的密钥；而 ECDLP 的最优攻击是指数时间的 O(√n)，256 位的群阶就足以提供 128 位安全性。


标量乘法是 ECC 中最核心的运算，它的效率直接决定了密码协议的性能。倍加法类似于整数的快速幂：将 k 的二进制位从高到低扫描，每一步做一次倍增（P → 2P），遇到 1 就额外做一次加法。


const findGroupOrder = (G: Point, a: number, p: number): number => {
  let Q = G;
  for (let k = 1; k <= p + 1 + 2 * Math.sqrt(p); k++) {
    if (Q === 'O') return k;
    Q = pointAdd(Q, G, a, p);
  }
  return -1;
};

const order = findGroupOrder(G, a, p);
console.log(`基点 G 的阶: ${order}`);

const kG = scalarMult(order, G, a, p);
console.log(`${order}·G = ${kG === 'O' ? 'O (零元)' : `(${(kG as any).x}, ${(kG as any).y})`}`);

const bruteForceDLP = (G: Point, Q: Point, a: number, p: number, maxK: number): number | null => {
  let current: Point = 'O';
  for (let k = 0; k <= maxK; k++) {
    if (
      current !== 'O' &&
      Q !== 'O' &&
      (current as { x: number }).x === (Q as { x: number }).x &&
      (current as { y: number }).y === (Q as { y: number }).y
    ) {
      return k;
    }
    if (k === 0 && Q === 'O') return 0;
    current = pointAdd(current, G, a, p);
  }
  return null;
};

const secretK = 42;
const Q = scalarMult(secretK, G, a, p);
const recovered = bruteForceDLP(G, Q, a, p, order);
console.log(`ECDLP: 已知 Q = ${secretK}G, 暴力求解 k = ${recovered}`);

ECDH 密钥交换
ECDH（Elliptic Curve Diffie-Hellman）是 DH 协议在椭圆曲线群上的实例化。协议的安全性基于椭圆曲线上的 CDH 假设：给定 aG 和 bG，计算 abG 是困难的。


协议流程：公开参数为曲线 E 和基点 G。Alice 选秘密 a，发送 A = aG。Bob 选秘密 b，发送 B = bG。Alice 计算 K = aB = abG，Bob 计算 K = bA = abG。共享密钥 K 相同。


const ecdh = (a_param: number, p_param: number, G_param: Point) => {
  const aliceSecret = 15;
  const bobSecret = 27;

  const alicePublic = scalarMult(aliceSecret, G_param, a_param, p_param);
  const bobPublic = scalarMult(bobSecret, G_param, a_param, p_param);

  const aliceShared = scalarMult(aliceSecret, bobPublic, a_param, p_param);
  const bobShared = scalarMult(bobSecret, alicePublic, a_param, p_param);

  return {
    alice: { secret: aliceSecret, public: alicePublic, shared: aliceShared },
    bob: { secret: bobSecret, public: bobPublic, shared: bobShared },
    match:
      aliceShared !== 'O' &&
      bobShared !== 'O' &&
      (aliceShared as { x: number }).x === (bobShared as { x: number }).x &&
      (aliceShared as { y: number }).y === (bobShared as { y: number }).y,
  };
};

const result = ecdh(a, p, G);
const fmt = (pt: Point) => (pt === 'O' ? 'O' : `(${(pt as any).x}, ${(pt as any).y})`);
console.log(`Alice 公钥: ${fmt(result.alice.public)}`);
console.log(`Bob 公钥: ${fmt(result.bob.public)}`);
console.log(`Alice 共享密钥: ${fmt(result.alice.shared)}`);
console.log(`Bob 共享密钥: ${fmt(result.bob.shared)}`);
console.log(`密钥匹配: ${result.match ? '✓' : '✗'}`);
实际部署中最流行的 ECDH 曲线是 X25519（基于 Curve25519）和 P-256（NIST 标准）。X25519 由 Daniel Bernstein 设计，具有恒定时间实现（抗时序攻击）、无需验证输入点（抗无效曲线攻击）等优良工程特性。


ECDSA 数字签名
ECDSA（Elliptic Curve Digital Signature Algorithm）是椭圆曲线上的数字签名方案，广泛用于 TLS 证书、比特币交易、代码签名等场景。


签名生成：对消息哈希 e = H(m)，选随机数 k，计算 R = kG，取 r = R.x mod n（n 是基点阶）。计算 s = k⁻¹(e + r·d) mod n，其中 d 是私钥。签名为 (r, s)。


签名验证：计算 w = s⁻¹ mod n, u₁ = ew mod n, u₂ = rw mod n。计算 R' = u₁G + u₂Q（Q 是公钥）。验证 R'.x ≡ r (mod n)。


ECDSA 的关键安全要求是随机数 k 必须真正随机且不能重复。PlayStation 3 的 ECDSA 实现因为使用了固定的 k 而被完全破解——如果两次签名使用相同的 k，攻击者可以从两个签名中直接解出私钥 d。RFC 6979 定义了确定性 k 生成方案来避免这个风险。


const ecdsaSign = (
  e: number,
  d: number,
  G_p: Point,
  a_p: number,
  p_p: number,
  n: number,
): { r: number; s: number } | null => {
  const k = 7 + Math.floor(Math.random() * (n - 8));
  const R = scalarMult(k, G_p, a_p, p_p);
  if (R === 'O') return null;
  const r = (R as { x: number }).x % n;
  if (r === 0) return null;
  const kInv = modPow(k, n - 2, n);
  const s = (kInv * ((e + r * d) % n)) % n;
  if (s === 0) return null;
  return { r, s };
};

const ecdsaVerify = (
  e: number,
  sig: { r: number; s: number },
  Q: Point,
  G_p: Point,
  a_p: number,
  p_p: number,
  n: number,
): boolean => {
  const w = modPow(sig.s, n - 2, n);
  const u1 = (e * w) % n;
  const u2 = (sig.r * w) % n;
  const R = pointAdd(scalarMult(u1, G_p, a_p, p_p), scalarMult(u2, Q, a_p, p_p), a_p, p_p);
  if (R === 'O') return false;
  return (R as { x: number }).x % n === sig.r;
};

const privateKey = 42;
const publicKey = scalarMult(privateKey, G, a, p);
const msgHash = 12345 % order;

const sig = ecdsaSign(msgHash, privateKey, G, a, p, order);
if (sig) {
  const valid = ecdsaVerify(msgHash, sig, publicKey, G, a, p, order);
  console.log(`签名: (r=${sig.r}, s=${sig.s})`);
  console.log(`验证: ${valid ? '有效' : '无效'}`);
}

小结
    

  • 椭圆曲线 y²=x³+ax+b 上的点在有限域 F_p 下构成加法群，群运算由弦切法定义
    • 

  • ECDLP 的最优经典攻击为 O(√n)（无亚指数算法），因此 256 位 ECC ≈ 3072 位 RSA
    • 

  • ECDH 将 Diffie-Hellman 密钥交换搬到椭圆曲线上，X25519 是现代 TLS 的默认方案
    • 

  • ECDSA 是椭圆曲线数字签名，随机数 k 的安全性至关重要（重复则私钥泄露）
    • 

  • 标量乘法 kG 通过倍加法在 O(log k) 步完成，是 ECC 所有协议的核心运算
    • 

  • ECC 的密钥更短、签名更小、计算更快，在移动设备和物联网等资源受限场景优势显著
    •
