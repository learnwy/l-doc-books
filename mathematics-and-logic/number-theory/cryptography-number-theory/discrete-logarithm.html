离散对数问题

核心概念

离散对数问题（Discrete Logarithm Problem, DLP）是现代密码学的另一大基石，与大整数分解问题并列为两个核心困难假设。给定素数 p、生成元 g 和群元素 h，求整数 x 使得 g^x ≡ h (mod p)，记作 x = log_g(h)。在连续域中对数可以高效计算，但在有限群（离散结构）中，目前没有已知的经典多项式时间算法能解决一般情况的离散对数。

离散对数的困难性支撑了 Diffie-Hellman 密钥交换、ElGamal 加密、DSA 数字签名等广泛使用的密码协议。与 RSA 基于分解困难不同，DLP 基于群上的指数运算的单向性——计算 g^x mod p 很容易（快速幂 O(log x) 次乘法），但从结果反推 x 极其困难。

Diffie-Hellman 密钥交换
Diffie-Hellman（DH）协议是 1976 年提出的第一个公钥密钥协商方案，允许两方在公开信道上协商出共享密钥。协议的安全性基于计算 Diffie-Hellman 假设（CDH）：给定 g^a 和 g^b，计算 g^{ab} 是困难的。


协议流程：Alice 和 Bob 公开约定素数 p 和生成元 g。Alice 选择秘密指数 a，发送 A = g^a mod p。Bob 选择秘密指数 b，发送 B = g^b mod p。Alice 计算 K = B^a = g^{ab} mod p，Bob 计算 K = A^b = g^{ab} mod p。双方得到相同的共享密钥 K，而窃听者只能看到 g^a 和 g^b，无法计算 g^{ab}（CDH 假设）。


const modPow = (base: number, exp: number, mod: number): number => {
  let result = 1;
  base = ((base % mod) + mod) % mod;
  while (exp > 0) {
    if (exp & 1) result = (result * base) % mod;
    exp >>= 1;
    base = (base * base) % mod;
  }
  return result;
};

const diffieHellman = (p: number, g: number) => {
  const a = 7 + Math.floor(Math.random() * (p - 8));
  const b = 7 + Math.floor(Math.random() * (p - 8));

  const A = modPow(g, a, p);
  const B = modPow(g, b, p);

  const keyAlice = modPow(B, a, p);
  const keyBob = modPow(A, b, p);

  return {
    public: { p, g, A, B },
    secrets: { a, b },
    sharedKey: { alice: keyAlice, bob: keyBob },
    match: keyAlice === keyBob,
  };
};

const p = 23;
const g = 5;
for (let i = 0; i < 5; i++) {
  const result = diffieHellman(p, g);
  console.log(
    `DH: A=${result.public.A}, B=${result.public.B}, ` +
      `K_a=${result.sharedKey.alice}, K_b=${result.sharedKey.bob}, ` +
      `匹配=${result.match ? '✓' : '✗'}`,
  );
}
DH 协议的弱点是不提供身份认证——攻击者可以实施中间人攻击（MITM）。解决方案包括：用数字证书认证公钥（TLS 中的做法）、使用 Station-to-Station 协议（STS）增加签名认证。

ElGamal 加密方案
ElGamal 加密（1985 年）是基于 DLP 的概率公钥加密方案。与 RSA 的确定性加密不同，ElGamal 每次加密使用随机数，同一明文的密文每次不同，天然具有语义安全性（在 DDH 假设下）。


密钥生成：选择素数 p 和生成元 g，随机选私钥 x ∈ {1,...,p-2}，计算公钥 h = g^x mod p。加密：选随机数 k，计算 c₁ = g^k mod p, c₂ = m · h^k mod p，密文为 (c₁, c₂)。解密：计算 m = c₂ · (c₁^x)⁻¹ mod p。


正确性：c₂ · (c₁^x)⁻¹ = m · h^k · (g^{kx})⁻¹ = m · g^{xk} · g^{-xk} = m。


const modInverse = (a: number, m: number): number => {
  const extGcd = (a: number, b: number): { g: number; x: number } => {
    if (b === 0) return { g: a, x: 1 };
    const { g, x: x1 } = extGcd(b, a % b);
    return { g, x: x1 - Math.floor(a / b) * (a - Math.floor(a / b) * b === 0 ? 0 : x1) };
  };
  let { g, x } = extGcd(a % m, m);
  if (g !== 1) throw new Error('逆元不存在');
  return (((a > 0 ? x : -x) % m) + m) % m;
};

const elgamalKeyGen = (p: number, g: number) => {
  const x = 3 + Math.floor(Math.random() * (p - 4));
  const h = modPow(g, x, p);
  return { publicKey: { p, g, h }, privateKey: x };
};

const elgamalEncrypt = (m: number, pk: { p: number; g: number; h: number }) => {
  const k = 2 + Math.floor(Math.random() * (pk.p - 3));
  const c1 = modPow(pk.g, k, pk.p);
  const c2 = (m * modPow(pk.h, k, pk.p)) % pk.p;
  return { c1, c2 };
};

const elgamalDecrypt = (c1: number, c2: number, x: number, p: number): number => {
  const s = modPow(c1, x, p);
  const sInv = modPow(s, p - 2, p);
  return (c2 * sInv) % p;
};

const { publicKey: pk, privateKey: sk } = elgamalKeyGen(23, 5);
console.log('公钥:', pk, '私钥:', sk);

for (let m = 1; m <= 5; m++) {
  const { c1, c2 } = elgamalEncrypt(m, pk);
  const decrypted = elgamalDecrypt(c1, c2, sk, pk.p);
  console.log(`m=${m} → (c1=${c1}, c2=${c2}) → m'=${decrypted} ${m === decrypted ? '✓' : '✗'}`);
}
ElGamal 的密文是明文的两倍大小（密文扩展率 2:1），这是概率加密的代价。在实际中，ElGamal 常用于混合加密：用 ElGamal 加密对称密钥，再用对称密钥加密实际数据。


Baby-step Giant-step 算法
Baby-step Giant-step（BSGS）是求解离散对数的经典确定性算法，由 Daniel Shanks 于 1971 年提出。它的核心思想是空间换时间：将 x = log_g(h) 分解为 x = i·m + j（m = ⌈√n⌉, 0 ≤ j < m, 0 ≤ i < m），预计算一半的信息存入哈希表，然后匹配另一半。


算法步骤：设群阶为 n，m = ⌈√n⌉。Baby step：计算 g^j (j = 0, 1, ..., m-1)，存入哈希表 {g^j → j}。Giant step：计算 h · (g^{-m})^i (i = 0, 1, 2, ...)，检查是否在哈希表中。若 h · g^{-mi} = g^j，则 x = i·m + j。


时间复杂度 O(√n)，空间复杂度 O(√n)。这是离散对数的一般下界——对于黑盒群（不利用群的结构），Shoup 证明了 Ω(√n) 的下界。


const babyStepGiantStep = (g: number, h: number, p: number): number | null => {
  const n = p - 1;
  const m = Math.ceil(Math.sqrt(n));

  const table = new Map<number, number>();
  let power = 1;
  for (let j = 0; j < m; j++) {
    table.set(power, j);
    power = (power * g) % p;
  }

  const gInvM = modPow(g, p - 1 - m, p);
  let gamma = h;
  for (let i = 0; i < m; i++) {
    if (table.has(gamma)) {
      const j = table.get(gamma)!;
      const x = i * m + j;
      if (modPow(g, x, p) === h) return x;
    }
    gamma = (gamma * gInvM) % p;
  }
  return null;
};

const testCases = [
  { g: 2, h: 8, p: 23 },
  { g: 5, h: 3, p: 23 },
  { g: 2, h: 11, p: 29 },
  { g: 3, h: 13, p: 17 },
];

for (const { g, h, p } of testCases) {
  const x = babyStepGiantStep(g, h, p);
  const verify = x !== null ? modPow(g, x, p) === h : false;
  console.log(`${g}^x ≡ ${h} (mod ${p}): x=${x} ${verify ? '✓' : '✗'}`);
}
离散对数与大数分解的关系
离散对数和大数分解是密码学的两大困难问题，它们之间存在深刻但微妙的关系。


从计算复杂度看：两者都没有已知的经典多项式时间算法。对 Z_p* 上的 DLP，最优算法是指数计算法（Index Calculus），复杂度为 exp(O(∛(log p · (log log p)²)))，与分解 p 位整数的通用数域筛法（GNFS）渐近相同。这不是巧合——两者背后的数学结构（光滑数、因子基、格约化）有深层联系。


从归约关系看：如果能高效分解 n = pq，就能求解 Z_n* 上的 DLP（通过 CRT 转化为 Z_p* 和 Z_q* 上的子问题）。反向不完全成立——DLP 的求解不直接意味着分解能力。


从量子计算看：Shor 算法可以在多项式时间内同时解决两个问题，因为它的核心是量子周期查找——DLP 和分解都可以归约到隐藏子群问题（HSP）。


const compareDLPAndFactoring = () => {
  const indexCalculusComplexity = (bits: number): number => {
    const logN = bits * Math.LN2;
    const logLogN = Math.log(logN);
    return Math.exp(1.923 * Math.cbrt(logN * logLogN * logLogN));
  };

  const gnfsComplexity = (bits: number): number => {
    const logN = bits * Math.LN2;
    const logLogN = Math.log(logN);
    return Math.exp(1.902 * Math.cbrt(logN * logLogN * logLogN));
  };

  const bitSizes = [512, 1024, 2048, 3072, 4096];
  console.log('密钥长度 | DLP (Index Calculus) | 分解 (GNFS) | 比值');
  for (const bits of bitSizes) {
    const dlp = Math.log2(indexCalculusComplexity(bits));
    const factor = Math.log2(gnfsComplexity(bits));
    console.log(`${bits} bit | 2^${dlp.toFixed(1)} | 2^${factor.toFixed(1)} | ${(dlp / factor).toFixed(2)}`);
  }
};

compareDLPAndFactoring();

小结
    

  • 离散对数问题 g^x ≡ h (mod p) 的困难性是 DH、ElGamal、DSA 等协议的安全基础
    • 

  • Diffie-Hellman 协议实现了公开信道上的密钥协商，安全性基于 CDH 假设
    • 

  • ElGamal 是概率公钥加密方案，天然具有语义安全性，但密文扩展率为 2:1
    • 

  • BSGS 算法以 O(√n) 时间和空间求解 DLP，是一般群上的最优黑盒算法
    • 

  • DLP 和大数分解在经典计算下复杂度渐近相同，都可被 Shor 量子算法多项式时间攻破
    • 

  • 椭圆曲线群上的 DLP 没有亚指数时间的经典算法，因此 ECC 能用更短的密钥达到同等安全性
    •
