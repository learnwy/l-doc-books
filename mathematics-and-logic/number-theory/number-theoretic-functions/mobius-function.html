莫比乌斯函数与反演

核心概念

莫比乌斯函数 μ(n) 是数论中最精妙的算术函数之一，它的取值仅有三种：0、1、-1。μ(n) 的定义基于 n 的素因子分解结构：若 n 包含平方因子则 μ(n) = 0，若 n 是 k 个不同素数的乘积则 μ(n) = (-1)^k，特别地 μ(1) = 1。莫比乌斯函数的威力在于莫比乌斯反演公式——它提供了一种从"累积信息"中提取"局部信息"的通用方法，本质上是数论版的容斥原理。

在算法竞赛中，莫比乌斯反演是处理"互素对计数"、"gcd 求和"等问题的核心工具。在解析数论中，μ(n) 与黎曼 ζ 函数的关系 1/ζ(s) = Σ μ(n)/n^s 揭示了素数分布的深层结构。

莫比乌斯函数的定义与取值
μ(n) 的定义看似简单，却蕴含了深刻的组合意义。设 n 的标准分解为 n = p₁^a₁ · p₂^a₂ · ... · pₖ^aₖ：


若存在某个 aᵢ ≥ 2（即 n 有平方因子），则 μ(n) = 0。这对应着"过度重复"——在容斥展开中，包含平方因子的项不贡献新信息。若所有 aᵢ = 1（即 n = p₁ · p₂ · ... · pₖ 是 k 个不同素数的乘积），则 μ(n) = (-1)^k。符号交替反映了容斥原理中奇数层减、偶数层加的模式。


μ(n) 最重要的性质是：对任意正整数 n，∑_{d|n} μ(d) = [n = 1]（艾弗森括号）。当 n = 1 时和为 1，当 n > 1 时和为 0。这个性质使 μ 成为"检测 n 是否为 1"的筛子，是反演公式的数学基础。


证明思路：设 n = p₁^a₁ · ... · pₖ^aₖ，n 的无平方因子的因子 d 形如 p*{i₁} · p*{i₂} · ... · p*{iⱼ}（从 k 个素因子中选 j 个）。因此 ∑*{d|n} μ(d) = ∑_{j=0}^{k} C(k,j)·(-1)^j = (1-1)^k = 0（当 k ≥ 1）。


const mobiusValue = (n: number): number => {
  if (n === 1) return 1;
  let factorCount = 0;
  let temp = n;
  for (let p = 2; p * p <= temp; p++) {
    if (temp % p === 0) {
      temp = Math.floor(temp / p);
      if (temp % p === 0) return 0;
      factorCount++;
    }
  }
  if (temp > 1) factorCount++;
  return factorCount % 2 === 0 ? 1 : -1;
};

const results: Array<{ n: number; mu: number; factorization: string }> = [];
const factorize = (n: number): string => {
  if (n === 1) return '1';
  const factors: string[] = [];
  let temp = n;
  for (let p = 2; p * p <= temp; p++) {
    let count = 0;
    while (temp % p === 0) {
      temp = Math.floor(temp / p);
      count++;
    }
    if (count > 0) factors.push(count > 1 ? `${p}^${count}` : `${p}`);
  }
  if (temp > 1) factors.push(`${temp}`);
  return factors.join('·');
};

for (let n = 1; n <= 30; n++) {
  results.push({ n, mu: mobiusValue(n), factorization: factorize(n) });
}
console.table(results);

莫比乌斯反演公式
莫比乌斯反演是数论的核心工具，有两种等价形式。


第一形式（因子和反演）：若 f(n) = ∑{d|n} g(d)，则 g(n) = ∑{d|n} μ(d) · f(n/d) = ∑_{d|n} μ(n/d) · f(d)。


直觉理解：f(n) 是 g 的"累积"——把 n 的所有因子处的 g 值加起来。反演公式告诉我们如何从累积值 f 还原出 g。μ 的符号交替实现了精确的容斥：先加回所有 f 值，再减去多算的，再加回多减的……


第二形式（倍数和反演）：若 F(n) = ∑{n|d, d≤N} g(d)，则 g(n) = ∑{n|d, d≤N} μ(d/n) · F(d)。


第二形式在算法竞赛中更常用，因为很多问题的"累积方向"是对倍数求和而非因子求和。


const getDivisors = (n: number): number[] => {
  const divs: number[] = [];
  for (let i = 1; i * i <= n; i++) {
    if (n % i === 0) {
      divs.push(i);
      if (i !== Math.floor(n / i)) divs.push(Math.floor(n / i));
    }
  }
  return divs.sort((a, b) => a - b);
};

const eulerTotient = (n: number): number => {
  let result = n;
  let temp = n;
  for (let p = 2; p * p <= temp; p++) {
    if (temp % p === 0) {
      while (temp % p === 0) temp = Math.floor(temp / p);
      result -= Math.floor(result / p);
    }
  }
  if (temp > 1) result -= Math.floor(result / temp);
  return result;
};

const verifyInversion = (n: number): boolean => {
  const divs = getDivisors(n);
  const f = (k: number): number => k;
  const gRecovered = divs.reduce((sum, d) => sum + mobiusValue(Math.floor(n / d)) * f(d), 0);
  return gRecovered === eulerTotient(n);
};

for (let n = 1; n <= 20; n++) {
  console.log(`n=${n}: φ(${n})=${eulerTotient(n)}, 反演恢复=${verifyInversion(n) ? '✓' : '✗'}`);
}
经典的反演实例：已知 ∑{d|n} φ(d) = n（即 f(n) = n, g(d) = φ(d)），由莫比乌斯反演得 φ(n) = ∑{d|n} μ(n/d) · d = ∑_{d|n} μ(d) · (n/d)。这提供了不依赖素因子分解的 φ(n) 计算方式。


算法竞赛中的经典应用
莫比乌斯反演在竞赛中最经典的应用是互素对计数：给定 N，求 1 ≤ a, b ≤ N 中 gcd(a, b) = 1 的有序对数。


核心推导：利用 [gcd(a,b)=1] = ∑{d|gcd(a,b)} μ(d)，交换求和顺序得到 ∑{a=1}^{N} ∑{b=1}^{N} [gcd(a,b)=1] = ∑{d=1}^{N} μ(d) · ⌊N/d⌋²。


进一步，求 ∑{a=1}^{N} ∑{b=1}^{N} gcd(a,b) 也可以用类似技巧：先枚举 gcd 的值 g，将问题转化为互素对计数，最终得到 ∑{g=1}^{N} ∑{d=1}^{⌊N/g⌋} μ(d) · ⌊N/(gd)⌋²。结合整除分块（数论分块），可以在 O(N^{2/3}) 或 O(√N) 时间内解决。


const linearSieveMu = (limit: number): { mu: number[]; primes: number[] } => {
  const mu = new Array(limit + 1).fill(0);
  const primes: number[] = [];
  const isComposite = new Array(limit + 1).fill(false);

  mu[1] = 1;
  for (let i = 2; i <= limit; i++) {
    if (!isComposite[i]) {
      primes.push(i);
      mu[i] = -1;
    }
    for (const p of primes) {
      if (i * p > limit) break;
      isComposite[i * p] = true;
      if (i % p === 0) {
        mu[i * p] = 0;
        break;
      }
      mu[i * p] = -mu[i];
    }
  }
  return { mu, primes };
};

const countCoprimePairs = (n: number): number => {
  const { mu } = linearSieveMu(n);
  let count = 0;
  for (let d = 1; d <= n; d++) {
    const q = Math.floor(n / d);
    count += mu[d] * q * q;
  }
  return count;
};

const countCoprimePairsBruteForce = (n: number): number => {
  const gcd = (a: number, b: number): number => (b === 0 ? a : gcd(b, a % b));
  let count = 0;
  for (let a = 1; a <= n; a++) {
    for (let b = 1; b <= n; b++) {
      if (gcd(a, b) === 1) count++;
    }
  }
  return count;
};

for (const n of [10, 50, 100, 200]) {
  const fast = countCoprimePairs(n);
  console.log(`N=${n}: 互素对数 = ${fast}`);
}
console.log(`N=10 暴力验证: ${countCoprimePairsBruteForce(10)}`);
整除分块的核心观察是：⌊N/d⌋ 最多只有 O(√N) 种不同取值。对于每个取值，找到对应的 d 的范围 [l, r]，在该范围内 ⌊N/d⌋ 是常数，因此只需预处理 μ 的前缀和即可批量计算。


筛法计算莫比乌斯函数
线性筛计算 μ 的原理与欧拉函数类似，关键是利用积性和最小素因子的信息。当筛到 n = i·p 时：若 p | i（即 i 已包含因子 p），则 i·p 必包含 p² 这个平方因子，所以 μ(i·p) = 0；若 p ∤ i，则 gcd(p, i) = 1，由积性 μ(i·p) = μ(i) · μ(p) = -μ(i)。

μ 的前缀和 M(x) = ∑_{n=1}^{x} μ(n) 称为梅滕斯函数（Mertens Function）。梅滕斯猜想（|M(x)| < √x）已被推翻，但 M(x) = O(x^{1/2+ε}) 仍与黎曼假设等价。在算法竞赛中，M(x) 的前缀和可以通过杜教筛在 O(x^{2/3}) 时间内计算。


const { mu, primes } = linearSieveMu(1000);

const mertensFn = (limit: number): number[] => {
  const M = new Array(limit + 1).fill(0);
  for (let i = 1; i <= limit; i++) {
    M[i] = M[i - 1] + mu[i];
  }
  return M;
};

const M = mertensFn(1000);
const samples = [10, 50, 100, 200, 500, 1000];
for (const x of samples) {
  console.log(`M(${x}) = ${M[x]}, |M(${x})|/√${x} = ${(Math.abs(M[x]) / Math.sqrt(x)).toFixed(4)}`);
}

const muDistribution = { pos: 0, neg: 0, zero: 0 };
for (let i = 1; i <= 1000; i++) {
  if (mu[i] > 0) muDistribution.pos++;
  else if (mu[i] < 0) muDistribution.neg++;
  else muDistribution.zero++;
}
console.log('μ 值分布 (n=1..1000):', muDistribution);
在 1 到 N 范围内，μ(n) = 0 的比例趋近于 1 - 6/π² ≈ 39.2%（即有平方因子的数的比例），μ(n) = 1 和 μ(n) = -1 各约 30.4%。这个分布与无平方因子数（squarefree numbers）的密度 6/π² 直接相关。


小结
    

  • 莫比乌斯函数 μ(n) 取值为 0、1、-1，由 n 的素因子分解结构决定，有平方因子时为 0
    • 

  • 核心性质 ∑_{d|n} μ(d) = [n=1] 使 μ 成为"检测 1"的筛子，是反演公式的基础
    • 

  • 莫比乌斯反演有两种形式：因子和反演与倍数和反演，本质都是数论版的容斥原理
    • 

  • 经典应用：互素对计数 ∑_{d=1}^{N} μ(d)·⌊N/d⌋²，结合整除分块可达 O(√N) 复杂度
    • 

  • 线性筛在 O(N) 时间内批量计算 μ 值，核心递推利用积性和平方因子判定
    • 

  • 梅滕斯函数 M(x) = Σμ(n) 的增长阶与黎曼假设深度关联，是解析数论的重要研究对象
