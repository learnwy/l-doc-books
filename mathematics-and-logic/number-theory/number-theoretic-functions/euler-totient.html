欧拉函数

核心概念

欧拉函数 φ(n) 是数论中最重要的算术函数之一，定义为小于等于 n 的正整数中与 n 互素的个数。例如 φ(12) = 4，因为 1, 5, 7, 11 这四个数与 12 互素。欧拉函数连接了素数分解、模运算与群论，是理解 RSA 加密、原根存在性、循环群结构的基础工具。

φ(n) 的计算依赖于 n 的素因子分解。若 n = p₁^a₁ · p₂^a₂ · ... · pₖ^aₖ，则 φ(n) = n · ∏(1 - 1/pᵢ)。这个公式的本质是容斥原理：从 n 个数中减去能被 p₁ 整除的、能被 p₂ 整除的……再加回被重复减去的部分。

计算公式与素因子分解
φ(n) 的核心计算公式来源于容斥原理。设 n 的不同素因子为 p₁, p₂, ..., pₖ，在 1 到 n 中能被 pᵢ 整除的数有 n/pᵢ 个。直接减去所有这些集合会重复减去能被两个素因子同时整除的数，因此需要加回 n/(pᵢpⱼ)，再减去三个素因子的情况……这就是容斥原理的展开，最终化简为乘积形式 φ(n) = n · ∏(1 - 1/pᵢ)。


对于素数幂 p^k，与 p^k 不互素的数恰好是 p 的倍数：p, 2p, 3p, ..., p^(k-1)·p，共 p^(k-1) 个，因此 φ(p^k) = p^k - p^(k-1) = p^(k-1)(p - 1)。


const eulerTotient = (n: number): number => {
  let result = n;
  let temp = n;
  for (let p = 2; p * p <= temp; p++) {
    if (temp % p === 0) {
      while (temp % p === 0) {
        temp = Math.floor(temp / p);
      }
      result -= Math.floor(result / p);
    }
  }
  if (temp > 1) {
    result -= Math.floor(result / temp);
  }
  return result;
};

console.log(eulerTotient(12));
console.log(eulerTotient(36));
console.log(eulerTotient(97));
上述算法的时间复杂度为 O(√n)，对单个值的计算非常高效。算法核心思路是：遍历 n 的每个素因子 p，将 result 乘以 (1 - 1/p)，等价于 result -= result / p。注意整数运算中要先做除法再做减法以避免溢出。


手动验证 φ(12) 的过程：12 = 2² × 3，素因子为 2 和 3。φ(12) = 12 × (1 - 1/2) × (1 - 1/3) = 12 × 1/2 × 2/3 = 4。与 12 互素的数为 {1, 5, 7, 11}，确实是 4 个。


积性与求和性质
欧拉函数是积性函数（Multiplicative Function）：当 gcd(m, n) = 1 时，φ(mn) = φ(m) · φ(n)。积性是欧拉函数最重要的代数性质，它使得 φ(n) 的计算可以分解为各素数幂的独立计算。


证明思路基于中国剩余定理（CRT）：当 gcd(m, n) = 1 时，Z/mnZ ≅ Z/mZ × Z/nZ 作为环同构。在这个同构下，(Z/mnZ)_ 对应 (Z/mZ)_ × (Z/nZ)，因此 φ(mn) = |(Z/mnZ)| = |(Z/mZ)| · |(Z/nZ)| = φ(m) · φ(n)。


另一个深刻的性质是求和恒等式：对任意正整数 n，∑{d|n} φ(d) = n。直觉解释是：将 1 到 n 的每个整数 k 按照 gcd(k, n) 分类。设 gcd(k, n) = d，则 gcd(k/d, n/d) = 1，而满足 gcd(k/d, n/d) = 1 的 k/d 恰好有 φ(n/d) 个。当 d 遍历 n 的所有因子时，k 恰好遍历 1 到 n，因此 n = ∑{d|n} φ(n/d) = ∑_{d|n} φ(d)。


const getDivisors = (n: number): number[] => {
  const divs: number[] = [];
  for (let i = 1; i * i <= n; i++) {
    if (n % i === 0) {
      divs.push(i);
      if (i !== Math.floor(n / i)) divs.push(Math.floor(n / i));
    }
  }
  return divs.sort((a, b) => a - b);
};

const verifySumProperty = (n: number): boolean => {
  const divs = getDivisors(n);
  const sum = divs.reduce((acc, d) => acc + eulerTotient(d), 0);
  return sum === n;
};

for (let n = 1; n <= 20; n++) {
  const divs = getDivisors(n);
  const phiValues = divs.map((d) => `φ(${d})=${eulerTotient(d)}`);
  const sum = divs.reduce((acc, d) => acc + eulerTotient(d), 0);
  console.log(`n=${n}: ${phiValues.join(' + ')} = ${sum} ${verifySumProperty(n) ? '✓' : '✗'}`);
}

线性筛法批量计算
当需要计算 1 到 N 所有数的 φ 值时，逐个计算的复杂度为 O(N√N)，而线性筛法可以在 O(N) 时间内完成。线性筛的核心思想是：每个合数只被其最小素因子筛到一次，同时利用积性在筛的过程中递推计算 φ。


线性筛需要区分三种情况：(1) n 是素数，φ(n) = n - 1；(2) n = p · m 且 p | m（p 是 n 的最小素因子且 m 也包含 p），此时 φ(n) = φ(m) · p，因为 p 已经在 m 的素因子分解中；(3) n = p · m 且 p ∤ m，此时 gcd(p, m) = 1，由积性 φ(n) = φ(p) · φ(m) = (p-1) · φ(m)。


const linearSievePhi = (limit: number): { phi: number[]; primes: number[] } => {
  const phi = new Array(limit + 1).fill(0);
  const primes: number[] = [];
  const isComposite = new Array(limit + 1).fill(false);

  phi[1] = 1;
  for (let i = 2; i <= limit; i++) {
    if (!isComposite[i]) {
      primes.push(i);
      phi[i] = i - 1;
    }
    for (const p of primes) {
      if (i * p > limit) break;
      isComposite[i * p] = true;
      if (i % p === 0) {
        phi[i * p] = phi[i] * p;
        break;
      }
      phi[i * p] = phi[i] * (p - 1);
    }
  }
  return { phi, primes };
};

const { phi, primes } = linearSievePhi(100);
console.log('前20个φ值:', phi.slice(1, 21));
console.log('前15个素数:', primes.slice(0, 15));

const prefixSum = phi.reduce((sums: number[], val, i) => {
  sums.push(i === 0 ? 0 : sums[sums.length - 1] + val);
  return sums;
}, []);
console.log('Σφ(i) for i=1..100:', prefixSum[100]);
线性筛的空间复杂度为 O(N)，时间复杂度为 O(N)，是算法竞赛中处理大范围欧拉函数的标准工具。前缀和 ∑{i=1}^{N} φ(i) 在计算互素对数量时非常有用：1 到 N 中互素的有序对 (a, b) 的数量为 2·∑{i=1}^{N} φ(i) - 1。


RSA 密钥生成中的角色
欧拉函数在 RSA 密码体制中扮演核心角色。RSA 的安全性建立在大整数分解的困难性上，而密钥生成过程直接使用 φ(n) 来构造加密指数和解密指数的关系。


RSA 密钥生成步骤：选择两个大素数 p 和 q，计算 n = p·q 和 φ(n) = (p-1)(q-1)。选择公钥指数 e 满足 gcd(e, φ(n)) = 1（通常取 e = 65537），计算私钥指数 d 使得 e·d ≡ 1 (mod φ(n))。加密为 c = m^e mod n，解密为 m = c^d mod n。正确性依赖欧拉定理：m^(e·d) = m^(1 + k·φ(n)) = m · (m^φ(n))^k ≡ m · 1^k ≡ m (mod n)。


const gcd = (a: number, b: number): number => (b === 0 ? a : gcd(b, a % b));

const extendedGcd = (a: number, b: number): { g: number; x: number; y: number } => {
  if (b === 0) return { g: a, x: 1, y: 0 };
  const { g, x, y } = extendedGcd(b, a % b);
  return { g, x: y, y: x - Math.floor(a / b) * y };
};

const modInverse = (e: number, phiN: number): number => {
  const { g, x } = extendedGcd(e, phiN);
  if (g !== 1) throw new Error('逆元不存在');
  return ((x % phiN) + phiN) % phiN;
};

const modPow = (base: number, exp: number, mod: number): number => {
  let result = 1;
  base = base % mod;
  while (exp > 0) {
    if (exp % 2 === 1) result = (result * base) % mod;
    exp = Math.floor(exp / 2);
    base = (base * base) % mod;
  }
  return result;
};

const p = 61,
  q = 53;
const n = p * q;
const phiN = (p - 1) * (q - 1);
const e = 17;
const d = modInverse(e, phiN);

console.log(`n = ${n}, φ(n) = ${phiN}`);
console.log(`公钥: (e=${e}, n=${n})`);
console.log(`私钥: (d=${d}, n=${n})`);
console.log(`验证: e·d mod φ(n) = ${(e * d) % phiN}`);

const message = 42;
const encrypted = modPow(message, e, n);
const decrypted = modPow(encrypted, d, n);
console.log(`明文: ${message} → 密文: ${encrypted} → 解密: ${decrypted}`);
实际 RSA 实现中使用的是 λ(n) = lcm(p-1, q-1)（卡迈克尔函数）而非 φ(n)，因为 λ(n) | φ(n)，使用更小的 λ(n) 能得到更小的 d，提高解密效率。但两者的数学本质相同——都是寻找使 a^k ≡ 1 (mod n) 成立的指数。

小结
    

  • 欧拉函数 φ(n) 统计 1 到 n 中与 n 互素的正整数个数，通过素因子分解公式 φ(n) = n·∏(1-1/pᵢ) 高效计算
    • 

  • 积性是 φ 最重要的代数性质：gcd(m,n)=1 时 φ(mn)=φ(m)·φ(n)，使计算可分解到素数幂
    • 

  • 求和恒等式 ∑_{d|n} φ(d) = n 将 φ 与因子结构联系，是莫比乌斯反演的基础
    • 

  • 单值计算复杂度 O(√n)，线性筛可在 O(N) 内批量求出 1 到 N 所有 φ 值
    • 

  • 欧拉定理 a^φ(n) ≡ 1 (mod n) 是 RSA 加密正确性的数学基础
    • 

  • RSA 密钥生成直接依赖 φ(n) = (p-1)(q-1) 来建立公钥与私钥的数学关系
