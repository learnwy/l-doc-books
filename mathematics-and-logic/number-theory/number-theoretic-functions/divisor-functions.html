除数函数与积性函数

核心概念

除数函数（Divisor Function）是一类以因子结构为核心的数论函数。最常见的两个是除数个数函数 τ(n)（也记作 d(n) 或 σ₀(n)）和除数和函数 σ(n)（即 σ₁(n)）。更一般地，σₖ(n) = ∑_{d|n} d^k 定义了 k 阶除数函数。这些函数都是积性函数（Multiplicative Function），这意味着它们的计算可以通过素因子分解来分解处理。

积性函数是数论的基石之一。一个函数 f 是积性的，当且仅当 f(1) = 1 且对所有 gcd(m,n) = 1 有 f(mn) = f(m)·f(n)。如果对所有 m, n（不要求互素）都有 f(mn) = f(m)·f(n)，则称 f 为完全积性函数。积性函数的理论框架统一了 φ、μ、τ、σ 等看似不同的数论函数，而狄利克雷卷积为它们的关系提供了优雅的代数语言。

除数个数函数 τ(n)
τ(n) 统计 n 的正因子个数。若 n = p₁^a₁ · p₂^a₂ · ... · pₖ^aₖ，则 τ(n) = (a₁+1)(a₂+1)...(aₖ+1)。这个公式的推导基于乘法原理：n 的每个因子 d 形如 p₁^b₁ · p₂^b₂ · ... · pₖ^bₖ，其中 0 ≤ bᵢ ≤ aᵢ，每个 bᵢ 有 aᵢ+1 种选择，各选择独立。


τ(n) 的增长非常不规则。对于素数 p，τ(p) = 2（只有 1 和 p）。高度合成数（Highly Composite Number）是 τ 的局部极大值点，例如 τ(120) = 16, τ(360) = 24, τ(720) = 30。τ(n) 的平均阶是 ln n：∑_{k=1}^{N} τ(k) ≈ N ln N + (2γ-1)N，其中 γ ≈ 0.5772 是欧拉-马斯凯罗尼常数。


const divisorCount = (n: number): number => {
  let count = 1;
  let temp = n;
  for (let p = 2; p * p <= temp; p++) {
    if (temp % p === 0) {
      let exp = 0;
      while (temp % p === 0) {
        temp = Math.floor(temp / p);
        exp++;
      }
      count *= exp + 1;
    }
  }
  if (temp > 1) count *= 2;
  return count;
};

const divisorSum = (n: number): number => {
  let sum = 1;
  let temp = n;
  for (let p = 2; p * p <= temp; p++) {
    if (temp % p === 0) {
      let powerSum = 1;
      let pk = 1;
      while (temp % p === 0) {
        temp = Math.floor(temp / p);
        pk *= p;
        powerSum += pk;
      }
      sum *= powerSum;
    }
  }
  if (temp > 1) sum *= 1 + temp;
  return sum;
};

const examples = [1, 6, 12, 28, 60, 120, 360];
for (const n of examples) {
  console.log(`n=${n}: τ(${n})=${divisorCount(n)}, σ(${n})=${divisorSum(n)}`);
}
τ 的积性验证：τ(6) = τ(2·3) = τ(2)·τ(3) = 2·2 = 4（因子为 1,2,3,6）。τ(12) = τ(4·3) = τ(4)·τ(3) = 3·2 = 6（因子为 1,2,3,4,6,12）。注意 τ(4) = 3 而非 τ(2)·τ(2) = 4，因为 gcd(2,2) ≠ 1，积性要求互素条件。


除数和函数 σ(n) 与完美数
σ(n) 是 n 所有正因子之和。σ(n) 在数论中的重要地位来自于它与完美数（Perfect Number）的关系：n 是完美数当且仅当 σ(n) = 2n。前几个完美数是 6、28、496、8128。


欧拉-欧几里得定理完全刻画了偶完美数：n 是偶完美数当且仅当 n = 2^(p-1) · (2^p - 1)，其中 2^p - 1 是梅森素数。是否存在奇完美数至今是未解决的数论难题。


σ(n) 对素数幂的公式为 σ(p^a) = 1 + p + p² + ... + p^a = (p^{a+1} - 1)/(p - 1)。由积性，σ(n) = ∏ σ(pᵢ^aᵢ)。


const isPerfect = (n: number): boolean => divisorSum(n) === 2 * n;

const classifyAbundance = (n: number): string => {
  const s = divisorSum(n);
  if (s < 2 * n) return '亏数';
  if (s === 2 * n) return '完美数';
  return '盈数';
};

console.log('完美数搜索 (1-10000):');
for (let n = 1; n <= 10000; n++) {
  if (isPerfect(n)) {
    const getDivisors = (k: number): number[] => {
      const divs: number[] = [];
      for (let i = 1; i * i <= k; i++) {
        if (k % i === 0) {
          divs.push(i);
          if (i !== Math.floor(k / i)) divs.push(Math.floor(k / i));
        }
      }
      return divs.sort((a, b) => a - b);
    };
    console.log(`${n} = ${getDivisors(n).join(' + ')} (除自身) σ(${n})=${divisorSum(n)}`);
  }
}

const abundanceStats = { deficient: 0, perfect: 0, abundant: 0 };
for (let n = 1; n <= 1000; n++) {
  const cls = classifyAbundance(n);
  if (cls === '亏数') abundanceStats.deficient++;
  else if (cls === '完美数') abundanceStats.perfect++;
  else abundanceStats.abundant++;
}

积性函数的代数结构
积性函数构成一个丰富的代数结构。设 f 和 g 都是积性函数，定义狄利克雷卷积 (f _ g)(n) = ∑_{d|n} f(d)·g(n/d)，则 f _ g 也是积性函数。这使得积性函数在狄利克雷卷积下构成一个阿贝尔群（单位元为 ε 函数）。


常见数论函数间的卷积关系是理解它们的关键：


τ = 1 _ 1（两个常数函数的卷积：τ(n) = ∑_{d|n} 1·1 = 因子个数）。σ = id _ 1（恒等函数与常数函数的卷积：σ(n) = ∑{d|n} d）。φ = μ * id（莫比乌斯函数与恒等函数的卷积：φ(n) = ∑{d|n} μ(d)·(n/d)）。ε = μ * 1（单位函数是莫比乌斯函数与常数函数的卷积：∑_{d|n} μ(d) = [n=1]）。


type ArithFunc = (n: number) => number;

const dirichletConvolution = (f: ArithFunc, g: ArithFunc, n: number): number => {
  let sum = 0;
  for (let d = 1; d * d <= n; d++) {
    if (n % d === 0) {
      sum += f(d) * g(Math.floor(n / d));
      if (d !== Math.floor(n / d)) {
        sum += f(Math.floor(n / d)) * g(d);
      }
    }
  }
  return sum;
};

const one: ArithFunc = () => 1;
const id: ArithFunc = (n) => n;
const mobiusValue = (n: number): number => {
  if (n === 1) return 1;
  let factors = 0;
  let temp = n;
  for (let p = 2; p * p <= temp; p++) {
    if (temp % p === 0) {
      temp = Math.floor(temp / p);
      if (temp % p === 0) return 0;
      factors++;
    }
  }
  if (temp > 1) factors++;
  return factors % 2 === 0 ? 1 : -1;
};

for (const n of [6, 12, 20, 30]) {

积性函数的筛法统一框架
所有积性函数都可以通过线性筛在 O(N) 时间内批量计算，关键在于分三种情况处理 n = i·p（p 是 n 的最小素因子）：(1) n = p 即素数，直接赋值；(2) p | i 且需要知道 p 在 n 中的完整幂次；(3) gcd(p, i) = 1，直接用积性。


对于 τ 的线性筛，需要额外维护每个数的最小素因子幂次 e(n)：当 p | i 时，τ(ip) = τ(i) / (e(i)+1) · (e(i)+2) 且 e(ip) = e(i)+1；当 p ∤ i 时，τ(ip) = τ(i) · 2 且 e(ip) = 1。


const linearSieveTauSigma = (limit: number) => {
  const tau = new Array(limit + 1).fill(0);
  const sigma = new Array(limit + 1).fill(0);
  const minPrimeExp = new Array(limit + 1).fill(0);
  const minPrimePow = new Array(limit + 1).fill(0);
  const primes: number[] = [];
  const isComposite = new Array(limit + 1).fill(false);

  tau[1] = 1;
  sigma[1] = 1;
  for (let i = 2; i <= limit; i++) {
    if (!isComposite[i]) {
      primes.push(i);
      tau[i] = 2;
      sigma[i] = 1 + i;
      minPrimeExp[i] = 1;
      minPrimePow[i] = i;
    }
    for (const p of primes) {
      if (i * p > limit) break;
      isComposite[i * p] = true;
      if (i % p === 0) {
        const newExp = minPrimeExp[i] + 1;
        const newPow = minPrimePow[i] * p;
        minPrimeExp[i * p] = newExp;
        minPrimePow[i * p] = newPow;
        tau[i * p] = Math.floor(tau[i] / (minPrimeExp[i] + 1)) * (newExp + 1);
        const base = Math.floor(i / minPrimePow[i]) || 1;
        sigma[i * p] = (sigma[base] * (newPow * p - 1)) / (p - 1);
        break;
      }
      minPrimeExp[i * p] = 1;
      minPrimePow[i * p] = p;
      tau[i * p] = tau[i] * 2;
      sigma[i * p] = sigma[i] * (1 + p);
    }
  }
  return { tau, sigma, primes };
};

const { tau, sigma } = linearSieveTauSigma(100);
console.log('τ(1..20):', tau.slice(1, 21));
console.log('σ(1..20):', sigma.slice(1, 21));

let tauSum = 0;
for (let i = 1; i <= 100; i++) tauSum += tau[i];
console.log(`Στ(i) for i=1..100 = ${tauSum}, 估计值 ≈ ${Math.round(100 * Math.log(100) + (2 * 0.5772 - 1) * 100)}`);
线性筛的统一框架使得在一次遍历中同时计算多个积性函数成为可能。在算法竞赛中，这种技巧可以节省大量时间和内存。


小结
    

  • 除数函数 σₖ(n) = ∑_{d|n} d^k 统一定义了除数个数 τ = σ₀ 和除数和 σ = σ₁
    • 

  • τ(n) 通过素因子分解公式 τ(n) = ∏(aᵢ+1) 计算，平均阶为 ln n
    • 

  • σ(n) 与完美数密切相关：σ(n) = 2n 定义了完美数，偶完美数由梅森素数完全刻画
    • 

  • 积性函数在狄利克雷卷积下构成阿贝尔群，核心关系有 τ=11, σ=id1, φ=μ*id
    • 

  • 完全积性函数是更强的条件，由素数处的值完全决定，常见的有 1、id、id^k
    • 

  • 线性筛提供了 O(N) 批量计算任意积性函数的统一框架，关键在于最小素因子幂次的维护
