最大公因数与最小公倍数

核心概念

最大公因数（Greatest Common Divisor, GCD）和最小公倍数（Least Common Multiple, LCM）是数论中最基本也最实用的概念。GCD 描述了两个整数共享的最大因子，LCM 描述了能同时被两个整数整除的最小正整数。欧几里得算法是计算 GCD 的经典方法，而扩展欧几里得算法则进一步求解了裴蜀等式，是密码学和模运算中不可或缺的工具。

GCD 的形式定义：设 a,ba, ba,b 为不全为零的整数，d=gcd⁡(a,b)d = \gcd(a, b)d=gcd(a,b) 当且仅当（1）d∣ad \mid ad∣a 且 d∣bd \mid bd∣b；（2）若 c∣ac \mid ac∣a 且 c∣bc \mid bc∣b，则 c∣dc \mid dc∣d。条件（2）说明 GCD 是所有公因数中"最大"的，不仅在数值上最大，而且能被所有其他公因数整除。


辗转相除法原理与证明
欧几里得算法（辗转相除法）基于一个简洁的递推关系：


gcd⁡(a,b)=gcd⁡(b,a mod b)\gcd(a, b) = \gcd(b, a \bmod b)gcd(a,b)=gcd(b,amodb)
这个等式的正确性源于：设 a=qb+ra = qb + ra=qb+r（0≤r<b0 \leq r < b0≤r<b），则 aaa 和 bbb 的任何公因数也是 bbb 和 rrr 的公因数，反之亦然。具体来说，若 d∣ad \mid ad∣a 且 d∣bd \mid bd∣b，则 d∣(a−qb)=rd \mid (a - qb) = rd∣(a−qb)=r；若 d∣bd \mid bd∣b 且 d∣rd \mid rd∣r，则 d∣(qb+r)=ad \mid (qb + r) = ad∣(qb+r)=a。因此 {a,b}\{a, b\}{a,b} 和 {b,r}\{b, r\}{b,r} 的公因数集合完全相同，其最大元素自然也相同。


反复应用此递推：


gcd⁡(a,b)→gcd⁡(b,a mod b)→gcd⁡(a mod b,b mod (a mod b))→⋯→gcd⁡(d,0)=d\gcd(a, b) \to \gcd(b, a \bmod b) \to \gcd(a \bmod b, b \bmod (a \bmod b)) \to \cdots \to \gcd(d, 0) = dgcd(a,b)→gcd(b,amodb)→gcd(amodb,bmod(amodb))→⋯→gcd(d,0)=d
终止性：每一步中余数严格递减（0≤r<b0 \leq r < b0≤r<b），因此算法必然在有限步内终止，最终余数为 0 时，另一个数即为 GCD。


时间复杂度：拉梅定理指出，欧几里得算法的步数不超过较小数的十进制位数的 5 倍。更精确地说，最坏情况发生在连续斐波那契数上（如 gcd⁡(Fn+1,Fn)\gcd(F_{n+1}, F_n)gcd(Fn+1​,Fn​)），此时需要 nnn 步。总体复杂度为 O(log⁡min⁡(a,b))O(\log \min(a, b))O(logmin(a,b))。


function gcd(a: number, b: number): number {
  a = Math.abs(a);
  b = Math.abs(b);
  while (b !== 0) {
    [a, b] = [b, a % b];
  }
  return a;
}

function gcdRecursive(a: number, b: number): number {
  if (b === 0) return Math.abs(a);
  return gcdRecursive(b, a % b);
}

function gcdBigInt(a: bigint, b: bigint): bigint {
  a = a < 0n ? -a : a;
  b = b < 0n ? -b : b;
  while (b !== 0n) {
    [a, b] = [b, a % b];
  }
  return a;
}

扩展欧几里得算法与裴蜀定理
裴蜀定理（Bézout's Identity）：对任意整数 a,ba, ba,b（不全为零），存在整数 x,yx, yx,y 使得：


ax+by=gcd⁡(a,b)ax + by = \gcd(a, b)ax+by=gcd(a,b)
这个定理不仅断言了解的存在性，还给出了一个重要推论：gcd⁡(a,b)=1\gcd(a, b) = 1gcd(a,b)=1（即 a,ba, ba,b 互素）当且仅当存在整数 x,yx, yx,y 使得 ax+by=1ax + by = 1ax+by=1。


扩展欧几里得算法在计算 GCD 的同时求出满足裴蜀等式的系数 x,yx, yx,y。核心思想是在欧几里得算法的递归过程中"回代"。


设 gcd⁡(b,a mod b)=bx1+(a mod b)y1=bx1+(a−⌊a/b⌋⋅b)y1=ay1+b(x1−⌊a/b⌋y1)\gcd(b, a \bmod b) = bx_1 + (a \bmod b)y_1 = bx_1 + (a - \lfloor a/b \rfloor \cdot b)y_1 = ay_1 + b(x_1 - \lfloor a/b \rfloor y_1)gcd(b,amodb)=bx1​+(amodb)y1​=bx1​+(a−⌊a/b⌋⋅b)y1​=ay1​+b(x1​−⌊a/b⌋y1​)。


因此 x=y1x = y_1x=y1​，y=x1−⌊a/b⌋y1y = x_1 - \lfloor a/b \rfloor y_1y=x1​−⌊a/b⌋y1​。


function extendedGcd(a: number, b: number): { gcd: number; x: number; y: number } {
  if (b === 0) {
    return { gcd: a, x: 1, y: 0 };
  }
  const result = extendedGcd(b, a % b);
  return {
    gcd: result.gcd,
    x: result.y,
    y: result.x - Math.floor(a / b) * result.y,
  };
}

function extendedGcdIterative(a: number, b: number): { gcd: number; x: number; y: number } {
  let [oldR, r] = [a, b];
  let [oldS, s] = [1, 0];
  let [oldT, t] = [0, 1];
  while (r !== 0) {
    const q = Math.floor(oldR / r);
    [oldR, r] = [r, oldR - q * r];
    [oldS, s] = [s, oldS - q * s];
    [oldT, t] = [t, oldT - q * t];
  }
  return { gcd: oldR, x: oldS, y: oldT };
}
扩展欧几里得算法的一个关键应用是求模逆元。若 gcd⁡(a,m)=1\gcd(a, m) = 1gcd(a,m)=1，则存在 xxx 使得 ax≡1(modm)ax \equiv 1 \pmod{m}ax≡1(modm)。通过扩展欧几里得算法求出 ax+my=1ax + my = 1ax+my=1 中的 xxx，对 mmm 取模即得逆元。


function modInverse(a: number, m: number): number | null {
  const result = extendedGcd(a, m);
  if (result.gcd !== 1) return null;
  return ((result.x % m) + m) % m;
}
LCM 的计算与性质
最小公倍数通过 GCD 来高效计算：


lcm(a,b)=∣a⋅b∣gcd⁡(a,b)\text{lcm}(a, b) = \frac{|a \cdot b|}{\gcd(a, b)}lcm(a,b)=gcd(a,b)∣a⋅b∣​
这个公式的正确性可以通过素因数分解理解：GCD 取各素因数幂次的最小值，LCM 取最大值，而 min⁡+max⁡=\min + \max =min+max= 两个原始幂次之和。


在编程实现中需要注意溢出问题：先除后乘可以减少溢出风险。


function lcm(a: number, b: number): number {
  if (a === 0 || b === 0) return 0;
  return Math.abs(Math.floor(a / gcd(a, b)) * b);
}

function lcmBigInt(a: bigint, b: bigint): bigint {
  if (a === 0n || b === 0n) return 0n;
  const absA = a < 0n ? -a : a;
  const absB = b < 0n ? -b : b;
  return (absA / gcdBigInt(absA, absB)) * absB;
}

function lcmArray(nums: number[]): number {
  return nums.reduce((acc, n) => lcm(acc, n), 1);
}

function gcdArray(nums: number[]): number {
  return nums.reduce((acc, n) => gcd(acc, n), 0);
}

实际应用场景
分数化简：将分数 a/ba/ba/b 化为最简形式，只需计算 gcd⁡(a,b)\gcd(a, b)gcd(a,b) 并除之：


function simplifyFraction(num: number, den: number): [number, number] {
  const d = gcd(Math.abs(num), Math.abs(den));
  const sign = den < 0 ? -1 : 1;
  return [(sign * num) / d, (sign * den) / d];
}
同步周期计算：两个周期性事件的同步周期是其周期的 LCM。例如，两个信号灯的闪烁周期分别为 aaa 和 bbb 秒，它们同时闪烁的周期为 lcm(a,b)\text{lcm}(a, b)lcm(a,b) 秒。


function synchronizationPeriod(periods: number[]): number {
  return lcmArray(periods);
}

function fractionAddition(n1: number, d1: number, n2: number, d2: number): [number, number] {
  const commonDen = lcm(d1, d2);
  const newNum = n1 * (commonDen / d1) + n2 * (commonDen / d2);
  return simplifyFraction(newNum, commonDen);
}
密码学中的应用：RSA 加密算法中，欧拉函数 λ(n)=lcm(p−1,q−1)\lambda(n) = \text{lcm}(p-1, q-1)λ(n)=lcm(p−1,q−1)（卡迈克尔函数）用于计算私钥。扩展欧几里得算法用于求解 ed≡1(modλ(n))ed \equiv 1 \pmod{\lambda(n)}ed≡1(modλ(n)) 中的私钥 ddd。
