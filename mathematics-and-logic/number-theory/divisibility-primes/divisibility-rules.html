整除规则与带余除法

核心概念

整除性是数论中最基础的概念之一。给定两个整数 aaa 和 bbb（b≠0b \neq 0b=0），如果存在整数 kkk 使得 a=kba = kba=kb，则称 bbb 整除 aaa，记作 b∣ab \mid ab∣a。整除关系构成了因数分解、素数理论和同余运算的基础。

整除关系的基本性质包括：若 a∣ba \mid ba∣b 且 b∣cb \mid cb∣c，则 a∣ca \mid ca∣c（传递性）；若 a∣ba \mid ba∣b 且 a∣ca \mid ca∣c，则对任意整数 m,nm, nm,n 有 a∣(mb+nc)a \mid (mb + nc)a∣(mb+nc)（线性组合性）。这些性质在证明和算法设计中频繁出现。


带余除法与除法算法
带余除法（Division Algorithm）是数论的基石定理。对于任意整数 aaa 和正整数 bbb，存在唯一的整数 qqq（商）和 rrr（余数），满足：


a=qb+r,0≤r<ba = qb + r, \quad 0 \leq r < ba=qb+r,0≤r<b
这个定理的关键在于存在性和唯一性两个方面。存在性可以通过良序原理（Well-Ordering Principle）证明：考虑集合 S={a−nb:n∈Z,a−nb≥0}S = \{a - nb : n \in \mathbb{Z}, a - nb \geq 0\}S={a−nb:n∈Z,a−nb≥0}，由良序原理 SSS 有最小元素 rrr，令 qqq 为对应的 nnn，可以证明 0≤r<b0 \leq r < b0≤r<b。唯一性通过反证法：若存在两组 (q1,r1)(q_1, r_1)(q1​,r1​) 和 (q2,r2)(q_2, r_2)(q2​,r2​)，则 b(q1−q2)=r2−r1b(q_1 - q_2) = r_2 - r_1b(q1​−q2​)=r2​−r1​，由 ∣r2−r1∣<b|r_2 - r_1| < b∣r2​−r1​∣<b 得 q1=q2q_1 = q_2q1​=q2​，进而 r1=r2r_1 = r_2r1​=r2​。


function divmod(a: number, b: number): [number, number] {
  const q = Math.floor(a / b);
  const r = a - q * b;
  return [q, r];
}

function divmodBigInt(a: bigint, b: bigint): [bigint, bigint] {
  const q = a / b;
  const r = a % b;
  return [q >= 0n ? q : q - (r !== 0n ? 1n : 0n), r >= 0n ? r : r + b];
}

常见整除判定方法
整除判定规则是无需实际做除法就能判断整除性的快捷方法。这些规则基于十进制数的位值表示 N=an⋅10n+an−1⋅10n−1+⋯+a1⋅10+a0N = a_n \cdot 10^n + a_{n-1} \cdot 10^{n-1} + \cdots + a_1 \cdot 10 + a_0N=an​⋅10n+an−1​⋅10n−1+⋯+a1​⋅10+a0​ 以及 101010 的幂对各个除数取模的规律。


末位判定法（基于 10k≡0(modd)10^k \equiv 0 \pmod{d}10k≡0(modd)）：


    

  • 2 的整除：末一位能被 2 整除。因为 10≡0(mod2)10 \equiv 0 \pmod{2}10≡0(mod2)，所以 N≡a0(mod2)N \equiv a_0 \pmod{2}N≡a0​(mod2)。
    • 

  • 4 的整除：末两位组成的数能被 4 整除。因为 100≡0(mod4)100 \equiv 0 \pmod{4}100≡0(mod4)。
    • 

  • 8 的整除：末三位组成的数能被 8 整除。因为 1000≡0(mod8)1000 \equiv 0 \pmod{8}1000≡0(mod8)。
    • 

  • 5 的整除：末一位为 0 或 5。因为 10≡0(mod5)10 \equiv 0 \pmod{5}10≡0(mod5)。

function digitSum(n: number): number {
  let sum = 0;
  let num = Math.abs(n);
  while (num > 0) {
    sum += num % 10;
    num = Math.floor(num / 10);
  }
  return sum;
}

function isDivisibleBy3(n: number): boolean {
  return digitSum(n) % 3 === 0;
}

function isDivisibleBy11(n: number): boolean {
  let num = Math.abs(n);
  let alternatingSum = 0;
  let sign = 1;
  while (num > 0) {
    alternatingSum += sign * (num % 10);
    num = Math.floor(num / 10);
    sign *= -1;
  }
  return alternatingSum % 11 === 0;
}

function isDivisibleBy7(n: number): boolean {
  let num = Math.abs(n);
  while (num >= 70) {
    const lastDigit = num % 10;
    num = Math.floor(num / 10) - 2 * lastDigit;
    num = Math.abs(num);
  }
  return num % 7 === 0;
}

整除关系在整数上建立了一个偏序关系（在正整数上）。以下性质在算法设计和数学证明中极为重要：

整除关系对差封闭





线性组合性质是理解最大公因数的关键。裴蜀定理（Bézout's Identity）指出，对任意整数 a,ba, ba,b，存在整数 x,yx, yx,y 使得 ax+by=gcd⁡(a,b)ax + by = \gcd(a, b)ax+by=gcd(a,b)。这意味着最大公因数可以表示为 aaa 和 bbb 的线性组合，这一结论是扩展欧几里得算法的理论基础。


整除性还与素因数分解紧密相连。如果 ppp 是素数且 p∣abp \mid abp∣ab，则 p∣ap \mid ap∣a 或 p∣bp \mid bp∣b（欧几里得引理）。这个看似简单的性质实际上是算术基本定理（唯一分解定理）的核心工具。


整除性在编程中的应用
整除性判断是编程中极为常见的操作。以下是几个典型应用场景：


校验位算法：许多编码系统使用整除性来检测错误。例如，ISBN-13 的校验算法基于模 10 运算：


function validateISBN13(isbn: string): boolean {
  const digits = isbn.replace(/-/g, '').split('').map(Number);
  if (digits.length !== 13) return false;
  const sum = digits.reduce((acc, d, i) => acc + d * (i % 2 === 0 ? 1 : 3), 0);
  return sum % 10 === 0;
}

function validateLuhn(cardNumber: string): boolean {
  const digits = cardNumber.replace(/\s/g, '').split('').map(Number).reverse();
  const sum = digits.reduce((acc, d, i) => {
    if (i % 2 === 1) {
      d *= 2;
      if (d > 9) d -= 9;
    }
    return acc + d;
  }, 0);
  return sum % 10 === 0;
}
FizzBuzz 的整除性本质：经典面试题 FizzBuzz 本质上是整除判定的组合应用。更有趣的推广是处理任意整除条件：


type FizzRule = { divisor: number; word: string };

function generalFizzBuzz(n: number, rules: FizzRule[]): string[] {
  return Array.from({ length: n }, (_, i) => {
    const num = i + 1;
    const result = rules
      .filter((r) => num % r.divisor === 0)
      .map((r) => r.word)
      .join('');
    return result || String(num);
  });
}
周期性与循环缓冲区：取模运算天然适合处理周期性问题，如循环缓冲区、轮转调度：


class CircularBuffer<T> {
  private buffer: (T | undefined)[];
  private head = 0;
  private tail = 0;
  private size = 0;

  constructor(private capacity: number) {
    this.buffer = new Array(capacity);
  }

  enqueue(item: T): boolean {
    if (this.size === this.capacity) return false;
    this.buffer[this.tail] = item;
    this.tail = (this.tail + 1) % this.capacity;
    this.size++;
    return true;
  }

  dequeue(): T | undefined {
    if (this.size === 0) return undefined;
    const item = this.buffer[this.head];
    this.head = (this.head + 1) % this.capacity;
    this.size--;
    return item;
  }
}
小结
    

  • 整除关系 b∣ab \mid ab∣a 是数论的基础概念，具有自反性、传递性和线性组合性
    • 

  • 带余除法保证了商和余数的唯一存在性，是欧几里得算法的理论基础
    • 

  • 整除判定规则利用十进制数的位值特征，分为末位法（2, 4, 8, 5）、数字和法（3, 9）和交替和法（11）
    • 

  • 编程中的取模运算与数学定义存在差异，负数取模需要特别处理
    • 

  • 实际应用涵盖校验位算法（ISBN、Luhn）、循环缓冲区、周期性调度等场景
    • 

  • 整除性与素因数分解紧密相连，欧几里得引理是算术基本定理的核心工具
