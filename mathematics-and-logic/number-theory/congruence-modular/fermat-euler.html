费马小定理与欧拉定理

核心概念

费马小定理和欧拉定理是数论中两个密切相关的深刻结果，它们揭示了模幂运算的周期性。费马小定理指出，对于素数 ppp 和不被 ppp 整除的整数 aaa，ap−1≡1(modp)a^{p-1} \equiv 1 \pmod{p}ap−1≡1(modp)。欧拉定理将其推广到任意模数：对于 gcd⁡(a,n)=1\gcd(a, n) = 1gcd(a,n)=1，aφ(n)≡1(modn)a^{\varphi(n)} \equiv 1 \pmod{n}aφ(n)≡1(modn)。这两个定理是 RSA 加密算法的数学基石，也是快速幂取模、模逆元计算和素性测试的理论依据。

费马小定理及其证明
费马小定理：若 ppp 是素数且 gcd⁡(a,p)=1\gcd(a, p) = 1gcd(a,p)=1，则 ap−1≡1(modp)a^{p-1} \equiv 1 \pmod{p}ap−1≡1(modp)。


等价形式：对任意整数 aaa，ap≡a(modp)a^p \equiv a \pmod{p}ap≡a(modp)（这个形式对 p∣ap \mid ap∣a 也成立）。


证明（利用简化剩余系）：考虑模 ppp 的简化剩余系 {1,2,3,…,p−1}\{1, 2, 3, \ldots, p-1\}{1,2,3,…,p−1}。将每个元素乘以 aaa，得到 {a,2a,3a,…,(p−1)a}\{a, 2a, 3a, \ldots, (p-1)a\}{a,2a,3a,…,(p−1)a}。


关键观察：这 p−1p-1p−1 个数模 ppp 后仍然构成 {1,2,…,p−1}\{1, 2, \ldots, p-1\}{1,2,…,p−1} 的一个排列。原因：（1）它们都不是 ppp 的倍数（因为 gcd⁡(a,p)=1\gcd(a, p) = 1gcd(a,p)=1）；（2）它们两两不同余（若 ia≡ja(modp)ia \equiv ja \pmod{p}ia≡ja(modp)，由 gcd⁡(a,p)=1\gcd(a, p) = 1gcd(a,p)=1 消去 aaa 得 i≡ji \equiv ji≡j）。


因此，两边的乘积模 ppp 相等：


a⋅2a⋅3a⋯(p−1)a≡1⋅2⋅3⋯(p−1)(modp)a \cdot 2a \cdot 3a \cdots (p-1)a \equiv 1 \cdot 2 \cdot 3 \cdots (p-1) \pmod{p}a⋅2a⋅3a⋯(p−1)a≡1⋅2⋅3⋯(p−1)(modp)
即 ap−1⋅(p−1)!≡(p−1)!(modp)a^{p-1} \cdot (p-1)! \equiv (p-1)! \pmod{p}ap−1⋅(p−1)!≡(p−1)!(modp)。由于 gcd⁡((p−1)!,p)=1\gcd((p-1)!, p) = 1gcd((p−1)!,p)=1，消去 (p−1)!(p-1)!(p−1)! 得 ap−1≡1(modp)a^{p-1} \equiv 1 \pmod{p}ap−1≡1(modp)。


function verifyFermatLittle(a: number, p: number): boolean {
  if (a % p === 0) return true;
  return modPow(a, p - 1, p) === 1;

function modPow(base: number, exp: number, mod: number): number {
  let result = 1;
  base = ((base % mod) + mod) % mod;
  while (exp > 0) {
    if (exp & 1) result = (result * base) % mod;
    exp >>= 1;
    base = (base * base) % mod;
  }
  return result;
}
欧拉定理与欧拉函数
欧拉定理是费马小定理对合数模数的推广：若 gcd⁡(a,n)=1\gcd(a, n) = 1gcd(a,n)=1，则 aφ(n)≡1(modn)a^{\varphi(n)} \equiv 1 \pmod{n}aφ(n)≡1(modn)。

function eulerTotient(n: number): number {
  let result = n;
  let num = n;
  for (let p = 2; p * p <= num; p++) {
    if (num % p === 0) {
      while (num % p === 0) num = Math.floor(num / p);
      result -= Math.floor(result / p);
    }
  }
  if (num > 1) result -= Math.floor(result / num);
  return result;
}

function eulerTotientSieve(limit: number): Int32Array {
  const phi = new Int32Array(limit + 1);
  for (let i = 0; i <= limit; i++) phi[i] = i;
  for (let i = 2; i <= limit; i++) {
    if (phi[i] === i) {
      for (let j = i; j <= limit; j += i) {
        phi[j] -= Math.floor(phi[j] / i);
      }
    }
  }
  return phi;
}
快速幂取模算法
快速幂（Binary Exponentiation）是计算 an mod ma^n \bmod manmodm 的高效算法，时间复杂度 O(log⁡n)O(\log n)O(logn)。核心思想是将指数 nnn 进行二进制分解：n=bk2k+bk−12k−1+⋯+b12+b0n = b_k 2^k + b_{k-1} 2^{k-1} + \cdots + b_1 2 + b_0n=bk​2k+bk−1​2k−1+⋯+b1​2+b0​，其中 bi∈{0,1}b_i \in \{0, 1\}bi​∈{0,1}。


因此 an=abk2k⋅abk−12k−1⋯ab0a^n = a^{b_k 2^k} \cdot a^{b_{k-1} 2^{k-1}} \cdots a^{b_0}an=abk​2k⋅abk−1​2k−1⋯ab0​。每一项 a2ia^{2^i}a2i 可以通过反复平方得到：a2i+1=(a2i)2a^{2^{i+1}} = (a^{2^i})^2a2i+1=(a2i)2。


function modPowIterative(base: number, exp: number, mod: number): number {
  let result = 1;
  base = ((base % mod) + mod) % mod;
  while (exp > 0) {
    if (exp & 1) result = (result * base) % mod;
    exp >>= 1;
    base = (base * base) % mod;
  }
  return result;
}

function modPowRecursive(base: number, exp: number, mod: number): number {
  if (exp === 0) return 1;
  if (exp & 1) return (base * modPowRecursive(base, exp - 1, mod)) % mod;
  const half = modPowRecursive(base, exp >> 1, mod);
  return (half * half) % mod;
}

function modPowBigInt(base: bigint, exp: bigint, mod: bigint): bigint {
  let result = 1n;
  base = ((base % mod) + mod) % mod;
  while (exp > 0n) {
    if (exp & 1n) result = (result * base) % mod;
    exp >>= 1n;
    base = (base * base) % mod;
  }
  return result;
}
快速幂的正确性依赖于模运算的乘法保持性：每一步平方和相乘后取模不影响最终结果，同时防止了中间值溢出。

模逆元的费马小定理求法
当模数 ppp 是素数时，费马小定理提供了一种优雅的模逆元计算方法：


由 ap−1≡1(modp)a^{p-1} \equiv 1 \pmod{p}ap−1≡1(modp)，两边除以 aaa 得 ap−2≡a−1(modp)a^{p-2} \equiv a^{-1} \pmod{p}ap−2≡a−1(modp)。


因此 a−1≡ap−2(modp)a^{-1} \equiv a^{p-2} \pmod{p}a−1≡ap−2(modp)，用快速幂在 O(log⁡p)O(\log p)O(logp) 时间内计算。


function modInverseFermat(a: number, p: number): number {
  return modPowIterative(a, p - 2, p);
}

function modDivide(a: number, b: number, p: number): number {
  return (a * modInverseFermat(b, p)) % p;
}

function nCrModP(n: number, r: number, p: number): number {
  if (r > n) return 0;
  if (r === 0 || r === n) return 1;
  const fact = [1];
  for (let i = 1; i <= n; i++) fact[i] = (fact[i - 1] * i) % p;
  const invFact = new Array(n + 1);
  invFact[n] = modInverseFermat(fact[n], p);
  for (let i = n - 1; i >= 0; i--) {
    invFact[i] = (invFact[i + 1] * (i + 1)) % p;
  }
  return (((fact[n] * invFact[r]) % p) * invFact[n - r]) % p;
}
Miller-Rabin 素性测试
费马小定理的逆命题不成立（存在卡迈克尔数，即对所有 gcd⁡(a,n)=1\gcd(a, n) = 1gcd(a,n)=1 都有 an−1≡1(modn)a^{n-1} \equiv 1 \pmod{n}an−1≡1(modn) 但 nnn 是合数）。Miller-Rabin 测试通过利用二次探测定理加强了费马测试。


二次探测定理：若 ppp 是素数，则 x2≡1(modp)x^2 \equiv 1 \pmod{p}x2≡1(modp) 的解只有 x≡±1(modp)x \equiv \pm 1 \pmod{p}x≡±1(modp)。


Miller-Rabin 的做法：将 n−1n - 1n−1 写成 2s⋅d2^s \cdot d2s⋅d（ddd 为奇数），然后检验 ad,a2d,a4d,…,a2s−1da^d, a^{2d}, a^{4d}, \ldots, a^{2^{s-1}d}ad,a2d,a4d,…,a2s−1d 的值。若 ad≢1(modn)a^d \not\equiv 1 \pmod{n}ad≡1(modn) 且所有 a2rd≢−1(modn)a^{2^r d} \not\equiv -1 \pmod{n}a2rd≡−1(modn)（0≤r<s0 \leq r < s0≤r<s），则 nnn 一定是合数。


function millerRabin(n: number, witnesses: number[] = [2, 3, 5, 7, 11, 13]): boolean {
  if (n < 2) return false;
  if (n === 2 || n === 3) return true;
  if (n % 2 === 0) return false;

  let d = n - 1;
  let s = 0;
  while (d % 2 === 0) {
    d = Math.floor(d / 2);
    s++;
  }

  for (const a of witnesses) {
    if (a >= n) continue;
    let x = modPowIterative(a, d, n);
    if (x === 1 || x === n - 1) continue;
    let composite = true;
    for (let r = 1; r < s; r++) {
      x = (x * x) % n;
      if (x === n - 1) {
        composite = false;
        break;
      }
    }
    if (composite) return false;
  }
  return true;
}
