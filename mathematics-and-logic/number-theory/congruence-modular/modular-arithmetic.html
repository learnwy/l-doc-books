模运算与线性同余方程

核心概念

模运算不仅是简单的取余操作，它在模 mmm 的整数环 Z/mZ\mathbb{Z}/m\mathbb{Z}Z/mZ 上定义了完整的算术体系。在这个体系中，加法和乘法都有良好定义，但"除法"需要通过模逆元来实现。线性同余方程 ax≡b(modm)ax \equiv b \pmod{m}ax≡b(modm) 是模算术中最基本的方程形式，其可解性和解的结构与 gcd⁡(a,m)\gcd(a, m)gcd(a,m) 密切相关。理解这些概念对于密码学实现、竞赛编程和系统设计至关重要。

模逆元的定义与计算
模 mmm 下 aaa 的逆元是满足 ax≡1(modm)ax \equiv 1 \pmod{m}ax≡1(modm) 的整数 xxx，记作 a−1(modm)a^{-1} \pmod{m}a−1(modm)。逆元存在的充要条件是 gcd⁡(a,m)=1\gcd(a, m) = 1gcd(a,m)=1。


直觉上，逆元就是模运算中的"倒数"。在实数中 a×(1/a)=1a \times (1/a) = 1a×(1/a)=1，在模 mmm 中 a×a−1≡1(modm)a \times a^{-1} \equiv 1 \pmod{m}a×a−1≡1(modm)。


方法一：扩展欧几里得算法。由裴蜀定理，gcd⁡(a,m)=1\gcd(a, m) = 1gcd(a,m)=1 时存在 x,yx, yx,y 使得 ax+my=1ax + my = 1ax+my=1，对 mmm 取模得 ax≡1(modm)ax \equiv 1 \pmod{m}ax≡1(modm)。


方法二：费马小定理。当 mmm 是素数时，am−1≡1(modm)a^{m-1} \equiv 1 \pmod{m}am−1≡1(modm)，因此 a−1≡am−2(modm)a^{-1} \equiv a^{m-2} \pmod{m}a−1≡am−2(modm)。这种方法实现简洁，配合快速幂使用。


方法三：线性递推。用于批量计算 111 到 nnn 的逆元，递推公式 i−1≡−⌊m/i⌋⋅(m mod i)−1(modm)i^{-1} \equiv -\lfloor m/i \rfloor \cdot (m \bmod i)^{-1} \pmod{m}i−1≡−⌊m/i⌋⋅(mmodi)−1(modm)。


function gcd(a: number, b: number): number {
  a = Math.abs(a);
  b = Math.abs(b);
  while (b !== 0) [a, b] = [b, a % b];
  return a;
}

function extGcd(a: number, b: number): { g: number; x: number; y: number } {
  if (b === 0) return { g: a, x: 1, y: 0 };
  const r = extGcd(b, a % b);
  return { g: r.g, x: r.y, y: r.x - Math.floor(a / b) * r.y };
}

function modInverseExtGcd(a: number, m: number): number | null {
  const { g, x } = extGcd(a, m);
  if (g !== 1) return null;
  return ((x % m) + m) % m;
}

function modPow(base: number, exp: number, mod: number): number {
  let result = 1;
  base = ((base % mod) + mod) % mod;
  while (exp > 0) {
    if (exp & 1) result = (result * base) % mod;
    exp >>= 1;
    base = (base * base) % mod;
  }
  return result;
}

function modInverseFermat(a: number, p: number): number {
  return modPow(a, p - 2, p);
}

function batchModInverse(n: number, p: number): number[] {
  const inv = new Array(n + 1).fill(0);
  inv[1] = 1;
  for (let i = 2; i <= n; i++) {
    inv[i] = (((-Math.floor(p / i) * inv[p % i]) % p) + p) % p;
  }
  return inv;
}

线性同余方程求解
线性同余方程 ax≡b(modm)ax \equiv b \pmod{m}ax≡b(modm) 的求解遵循以下规则：


设 d=gcd⁡(a,m)d = \gcd(a, m)d=gcd(a,m)。


情形 1：d∤bd \nmid bd∤b 时方程无解。直觉上，ax mod max \bmod maxmodm 只能取到 ddd 的倍数，若 bbb 不是 ddd 的倍数，则不可能被取到。


情形 2：d∣bd \mid bd∣b 时方程有恰好 ddd 个不同余的解（在模 mmm 意义下）。先将方程化简为 (a/d)x≡(b/d)(modm/d)(a/d)x \equiv (b/d) \pmod{m/d}(a/d)x≡(b/d)(modm/d)，此时 gcd⁡(a/d,m/d)=1\gcd(a/d, m/d) = 1gcd(a/d,m/d)=1，可以用模逆元直接求解，得到一个特解 x0x_0x0​。全部 ddd 个解为：


x≡x0+k⋅md(modm),k=0,1,…,d−1x \equiv x_0 + k \cdot \frac{m}{d} \pmod{m}, \quad k = 0, 1, \ldots, d-1x≡x0​+k⋅dm​(modm),k=0,1,…,d−1
function solveLinearCongruence(a: number, b: number, m: number): number[] | null {
  const d = gcd(a, m);
  if (b % d !== 0) return null;

  const a1 = Math.floor(a / d);
  const b1 = Math.floor(b / d);
  const m1 = Math.floor(m / d);

  const inv = modInverseExtGcd(a1, m1);
  if (inv === null) return null;

  const x0 = (((inv * b1) % m1) + m1) % m1;
  const solutions: number[] = [];
  for (let k = 0; k < d; k++) {
    solutions.push((x0 + k * m1) % m);
  }
  return solutions;
}

模运算在编程中的陷阱
模运算看似简单，但在实际编程中有多个容易出错的地方。


陷阱一：负数取模。在 JavaScript/TypeScript、C/C++、Java 中，% 运算符的结果符号与被除数相同（截断除法），而数学定义的余数总是非负的。


function mod(a: number, m: number): number {
  return ((a % m) + m) % m;
}
陷阱二：整数溢出。两个大数相乘后取模，中间结果可能溢出。在 JavaScript 中，超过 2532^{53}253 的整数会丢失精度。


function modMulSafe(a: bigint, b: bigint, m: bigint): bigint {
  return ((((a % m) * (b % m)) % m) + m) % m;
}

function modPowBigInt(base: bigint, exp: bigint, mod: bigint): bigint {
  let result = 1n;
  base = ((base % mod) + mod) % mod;
  while (exp > 0n) {
    if (exp & 1n) result = (result * base) % mod;
    exp >>= 1n;
    base = (base * base) % mod;
  }
  return result;
}
陷阱三：除法取模。不能直接做 (a / b) % m，必须用 a * modInverse(b, m) % m。这在计算组合数 (nk) mod p\binom{n}{k} \bmod p(kn​)modp 时尤为重要。


陷阱四：模数为 1。任何数模 1 都等于 0，某些算法未处理这个边界情况。


function modCombination(n: number, k: number, p: number): number {
  if (k > n) return 0;
  const factorials = [1];
  for (let i = 1; i <= n; i++) {
    factorials[i] = (factorials[i - 1] * i) % p;
  }
  const invFact = new Array(n + 1);
  invFact[n] = modPow(factorials[n], p - 2, p);
  for (let i = n - 1; i >= 0; i--) {
    invFact[i] = (invFact[i + 1] * (i + 1)) % p;
  }
  return (((factorials[n] * invFact[k]) % p) * invFact[n - k]) % p;
}

同余方程组的联立求解
当需要同时满足多个同余条件时，形成同余方程组：


{x≡a1(modm1)x≡a2(modm2)\begin{cases} x \equiv a_1 \pmod{m_1} \\ x \equiv a_2 \pmod{m_2} \end{cases}{x≡a1​(modm1​)x≡a2​(modm2​)​
对于两个方程的情形，可以直接用代入法。设 x=a1+m1tx = a_1 + m_1 tx=a1​+m1​t，代入第二个方程得 m1t≡a2−a1(modm2)m_1 t \equiv a_2 - a_1 \pmod{m_2}m1​t≡a2​−a1​(modm2​)。这是一个线性同余方程，可以用上述方法求解。当模数两两互素时，中国剩余定理提供了系统化的解法，将在下一节详细讨论。


function solveTwoCongruences(
  a1: number,
  m1: number,
  a2: number,
  m2: number,
): { remainder: number; modulus: number } | null {
  const d = gcd(m1, m2);
  if ((a2 - a1) % d !== 0) return null;

  const m1d = Math.floor(m1 / d);
  const m2d = Math.floor(m2 / d);
  const diff = Math.floor((a2 - a1) / d);
  const inv = modInverseExtGcd(m1d, m2d);
  if (inv === null) return null;

  const lcmVal = m1 * m2d;
  const t = (((inv * diff) % m2d) + m2d) % m2d;
  const x = (((a1 + m1 * t) % lcmVal) + lcmVal) % lcmVal;
  return { remainder: x, modulus: lcmVal };
}
