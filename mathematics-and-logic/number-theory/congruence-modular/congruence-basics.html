同余的定义与基本性质

核心概念

同余（Congruence）是模运算的数学基础，由高斯在《算术研究》中系统化。给定正整数 mmm，若两个整数 aaa 和 bbb 的差 a−ba - ba−b 能被 mmm 整除，则称 aaa 与 bbb 模 mmm 同余，记作 a≡b(modm)a \equiv b \pmod{m}a≡b(modm)。同余关系是一种等价关系，将全体整数按照模 mmm 的余数划分为 mmm 个等价类（同余类），在这些等价类上可以自然地定义加法和乘法，形成模 mmm 的整数环 Z/mZ\mathbb{Z}/m\mathbb{Z}Z/mZ。

同余作为等价关系
同余关系 ≡(modm)\equiv \pmod{m}≡(modm) 满足等价关系的三个公理：


自反性：a≡a(modm)a \equiv a \pmod{m}a≡a(modm)，因为 m∣(a−a)=0m \mid (a - a) = 0m∣(a−a)=0。


对称性：若 a≡b(modm)a \equiv b \pmod{m}a≡b(modm)，则 b≡a(modm)b \equiv a \pmod{m}b≡a(modm)，因为 m∣(a−b)m \mid (a - b)m∣(a−b) 蕴含 m∣(b−a)m \mid (b - a)m∣(b−a)。


传递性：若 a≡b(modm)a \equiv b \pmod{m}a≡b(modm) 且 b≡c(modm)b \equiv c \pmod{m}b≡c(modm)，则 a≡c(modm)a \equiv c \pmod{m}a≡c(modm)，因为 m∣(a−b)m \mid (a - b)m∣(a−b) 且 m∣(b−c)m \mid (b - c)m∣(b−c) 蕴含 m∣(a−b)+(b−c)=(a−c)m \mid (a - b) + (b - c) = (a - c)m∣(a−b)+(b−c)=(a−c)。


作为等价关系，同余将 Z\mathbb{Z}Z 划分为 mmm 个同余类（也称剩余类）：


[0]m,[1]m,[2]m,…,[m−1]m[0]_m, [1]_m, [2]_m, \ldots, [m-1]_m[0]m​,[1]m​,[2]m​,…,[m−1]m​
其中 [r]m={…,r−2m,r−m,r,r+m,r+2m,…}[r]_m = \{\ldots, r - 2m, r - m, r, r + m, r + 2m, \ldots\}[r]m​={…,r−2m,r−m,r,r+m,r+2m,…}。每个整数恰好属于其中一个类。


function congruent(a: number, b: number, m: number): boolean {
  return (((a - b) % m) + m) % m === 0;
}

function residueClass(a: number, m: number): number {
  return ((a % m) + m) % m;
}

function completeResidueSystem(m: number): number[] {
  return Array.from({ length: m }, (_, i) => i);
}

function reducedResidueSystem(m: number): number[] {
  const result: number[] = [];
  for (let a = 1; a <= m; a++) {
    if (gcd(a, m) === 1) result.push(a);
  }
  return result;
}

function gcd(a: number, b: number): number {
  a = Math.abs(a);
  b = Math.abs(b);
  while (b !== 0) {
    [a, b] = [b, a % b];
  }
  return a;
}
模运算的代数规则
同余关系与加法、乘法具有良好的兼容性，这使得模运算形成一个代数结构（环）。


加法保持：若 a≡b(modm)a \equiv b \pmod{m}a≡b(modm) 且 c≡d(modm)c \equiv d \pmod{m}c≡d(modm)，则 a+c≡b+d(modm)a + c \equiv b + d \pmod{m}a+c≡b+d(modm)。


减法保持：若 a≡b(modm)a \equiv b \pmod{m}a≡b(modm) 且 c≡d(modm)c \equiv d \pmod{m}c≡d(modm)，则 a−c≡b−d(modm)a - c \equiv b - d \pmod{m}a−c≡b−d(modm)。


乘法保持：若 a≡b(modm)a \equiv b \pmod{m}a≡b(modm) 且 c≡d(modm)c \equiv d \pmod{m}c≡d(modm)，则 ac≡bd(modm)ac \equiv bd \pmod{m}ac≡bd(modm)。


幂运算保持：若 a≡b(modm)a \equiv b \pmod{m}a≡b(modm)，则 an≡bn(modm)a^n \equiv b^n \pmod{m}an≡bn(modm)（对任意正整数 nnn）。


这些规则意味着在计算过程中可以随时取模，而不影响最终结果。这是模运算在编程中高效处理大数的核心原理。

完全剩余系与简化剩余系
完全剩余系（Complete Residue System）是从每个同余类中各取一个代表元组成的集合。最常用的是最小非负完全剩余系 {0,1,2,…,m−1}\{0, 1, 2, \ldots, m-1\}{0,1,2,…,m−1}。


完全剩余系的判定条件：mmm 个整数 a1,a2,…,ama_1, a_2, \ldots, a_ma1​,a2​,…,am​ 构成模 mmm 的完全剩余系，当且仅当它们两两模 mmm 不同余。


简化剩余系（Reduced Residue System）由完全剩余系中与 mmm 互素的元素组成。其大小等于欧拉函数 φ(m)\varphi(m)φ(m)。


φ(m)=m∏p∣m(1−1p)\varphi(m) = m \prod_{p \mid m} \left(1 - \frac{1}{p}\right)φ(m)=mp∣m∏​(1−p1​)

function eulerTotient(n: number): number {
  let result = n;
  let num = n;
  for (let p = 2; p * p <= num; p++) {
    if (num % p === 0) {
      while (num % p === 0) {
        num = Math.floor(num / p);
      }
      result -= Math.floor(result / p);
    }
  }
  if (num > 1) {
    result -= Math.floor(result / num);
  }
  return result;
}

function multiplicativeOrder(a: number, m: number): number {
  if (gcd(a, m) !== 1) return -1;
  let order = 1;
  let current = a % m;
  while (current !== 1) {
    current = (current * a) % m;
    order++;
  }
  return order;
}
同余在哈希函数中的应用
模运算是哈希函数设计的核心。一个好的哈希函数将键均匀映射到 [0,m−1][0, m-1][0,m−1] 的范围内，其中 mmm 是哈希表的大小。


除法哈希：h(k)=k mod mh(k) = k \bmod mh(k)=kmodm。选择 mmm 为素数可以减少碰撞，因为素数的倍数在整数中分布最均匀。


乘法哈希：h(k)=⌊m⋅(kA mod 1)⌋h(k) = \lfloor m \cdot (kA \bmod 1) \rfloorh(k)=⌊m⋅(kAmod1)⌋，其中 A≈(5−1)/2A \approx (\sqrt{5} - 1) / 2A≈(5​−1)/2（黄金分割比）。


多项式哈希（字符串哈希）：h(s)=∑i=0n−1s[i]⋅pi mod mh(s) = \sum_{i=0}^{n-1} s[i] \cdot p^i \bmod mh(s)=∑i=0n−1​s[i]⋅pimodm，基于同余的乘法保持性，可以在 O(n)O(n)O(n) 时间内计算，并支持 O(1)O(1)O(1) 的子串哈希查询（Rabin-Karp 算法）。


function polynomialHash(s: string, p: number, m: number): number {
  let hash = 0;
  let power = 1;
  for (let i = 0; i < s.length; i++) {
    hash = (hash + s.charCodeAt(i) * power) % m;
    power = (power * p) % m;
  }
  return hash;
}

function buildPrefixHash(s: string, p: number, m: number): { hash: number[]; power: number[] } {
  const n = s.length;
  const hash = new Array(n + 1).fill(0);
  const power = new Array(n + 1).fill(1);
  for (let i = 0; i < n; i++) {
    hash[i + 1] = (hash[i] + s.charCodeAt(i) * power[i]) % m;
    power[i + 1] = (power[i] * p) % m;
  }
  return { hash, power };
}

function substringHash(prefixHash: { hash: number[]; power: number[] }, l: number, r: number, m: number): number {
  const { hash, power } = prefixHash;
  return (((hash[r + 1] - hash[l]) % m) + m) % m;
}
哈希表选择素数大小的原因与同余理论直接相关：若 mmm 和键的分布模式有公因数 d>1d > 1d>1，则哈希值只会落在 m/dm/dm/d 个桶中，浪费了 (1−1/d)(1 - 1/d)(1−1/d) 的空间。素数 mmm 与几乎所有分布模式互素，从而保证均匀分布。


小结
    

  • 同余 a≡b(modm)a \equiv b \pmod{m}a≡b(modm) 是等价关系，将整数划分为 mmm 个同余类

  • 模运算保持加法、减法和乘法，但不保持除法（需要模逆元）

  • 完全剩余系从每个同余类取一个代表元，简化剩余系只取与 mmm 互素的元素
    • 

  • 简化剩余系的大小为欧拉函数 φ(m)\varphi(m)φ(m)，其元素构成模 mmm 的乘法群
    • 

  • 同余是哈希函数设计的数学基础，素数模数保证了哈希值的均匀分布
