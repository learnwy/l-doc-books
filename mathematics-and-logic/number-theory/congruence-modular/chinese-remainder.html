中国剩余定理

核心概念

中国剩余定理（Chinese Remainder Theorem, CRT）是数论中最优美、最实用的定理之一，其历史可追溯到南北朝数学家孙子的《孙子算经》："今有物不知其数，三三数之剩二，五五数之剩三，七七数之剩二，问物几何？"答曰二十三。CRT 的核心思想是：当模数两两互素时，一组同余方程总有唯一解（在模数乘积的范围内），而且这个解可以通过构造性方法计算。CRT 在密码学、大数运算和并行计算中有广泛应用。

function gcd(a: number, b: number): number {
  a = Math.abs(a);
  b = Math.abs(b);
  while (b !== 0) [a, b] = [b, a % b];
  return a;
}

function extGcd(a: number, b: number): { g: number; x: number; y: number } {
  if (b === 0) return { g: a, x: 1, y: 0 };
  const r = extGcd(b, a % b);
  return { g: r.g, x: r.y, y: r.x - Math.floor(a / b) * r.y };
}

function modInverse(a: number, m: number): number {
  const { g, x } = extGcd(a, m);
  if (g !== 1) throw new Error('No inverse');
  return ((x % m) + m) % m;
}

function crt(remainders: number[], moduli: number[]): { solution: number; modulus: number } {
  const n = remainders.length;
  const M = moduli.reduce((acc, m) => acc * m, 1);
  let x = 0;
  for (let i = 0; i < n; i++) {
    const Mi = Math.floor(M / moduli[i]);
    const ti = modInverse(Mi, moduli[i]);
    x = (x + remainders[i] * Mi * ti) % M;
  }
  return { solution: ((x % M) + M) % M, modulus: M };
}

推广形式：模数不互素
当模数不两两互素时，方程组可能无解或需要使用逐步合并法。


对于两个方程 x≡a1(modm1)x \equiv a_1 \pmod{m_1}x≡a1​(modm1​) 和 x≡a2(modm2)x \equiv a_2 \pmod{m_2}x≡a2​(modm2​)，设 d=gcd⁡(m1,m2)d = \gcd(m_1, m_2)d=gcd(m1​,m2​)。有解的充要条件是 d∣(a2−a1)d \mid (a_2 - a_1)d∣(a2​−a1​)。若有解，可以合并为：


x≡a1+m1t0(modlcm(m1,m2))x \equiv a_1 + m_1 t_0 \pmod{\text{lcm}(m_1, m_2)}x≡a1​+m1​t0​(modlcm(m1​,m2​))
其中 t0t_0t0​ 是 m1t≡a2−a1(modm2)m_1 t \equiv a_2 - a_1 \pmod{m_2}m1​t≡a2​−a1​(modm2​) 的一个特解。


function crtGeneral(remainders: number[], moduli: number[]): { solution: number; modulus: number } | null {
  let curR = remainders[0];
  let curM = moduli[0];

  for (let i = 1; i < remainders.length; i++) {
    const a1 = curR;
    const m1 = curM;
    const a2 = remainders[i];
    const m2 = moduli[i];
    const d = gcd(m1, m2);

    if ((a2 - a1) % d !== 0) return null;

    const m1d = Math.floor(m1 / d);
    const m2d = Math.floor(m2 / d);
    const diff = Math.floor((a2 - a1) / d);
    const inv = modInverse(m1d % m2d === 0 ? 1 : m1d, m2d);
    const t = (((inv * diff) % m2d) + m2d) % m2d;

    curM = m1 * m2d;
    curR = (((a1 + m1 * t) % curM) + curM) % curM;
  }

  return { solution: curR, modulus: curM };
}

CRT 的实际应用
大数运算分解：对于需要处理超大整数的运算，可以将其分解到多个较小的互素模数上分别计算，再用 CRT 合并。例如，计算 a+ba + ba+b 其中 a,ba, ba,b 是千位大数，选择模数 m1=10007,m2=10009,m3=10037m_1 = 10007, m_2 = 10009, m_3 = 10037m1​=10007,m2​=10009,m3​=10037，分别计算 (a+b) mod mi(a + b) \bmod m_i(a+b)modmi​，再用 CRT 还原。


function bigAddViaCRT(a: bigint, b: bigint): bigint {
  const moduli = [10007n, 10009n, 10037n];
  const remainders = moduli.map((m) => (((a + b) % m) + m) % m);
  return crtBigInt(remainders.map(Number), moduli.map(Number));
}

function crtBigInt(remainders: number[], moduli: number[]): bigint {
  const result = crt(remainders, moduli);
  return BigInt(result.solution);
}
并行计算：在分布式系统中，将计算任务按不同模数分配到多个节点，各节点独立计算后用 CRT 合并结果。这种策略在全同态加密（FHE）中尤为重要。


周期性问题：多个周期性事件的公共周期可以用 CRT 分析。例如，三个齿轮分别有 12、15、20 个齿，它们同时回到初始位置需要 lcm(12,15,20)=60\text{lcm}(12, 15, 20) = 60lcm(12,15,20)=60 次旋转。CRT 还可以确定在特定位置组合下的最早时刻。


密码学中的 RSA 加速：RSA 解密中，对 n=pqn = pqn=pq 的模幂运算可以分解为对 ppp 和 qqq 分别计算，再用 CRT 合并，速度提升约 4 倍：


function rsaDecryptCRT(c: bigint, d: bigint, p: bigint, q: bigint): bigint {
  const dp = d % (p - 1n);
  const dq = d % (q - 1n);
  const mp = modPowBigInt(c % p, dp, p);
  const mq = modPowBigInt(c % q, dq, q);
  const qInv = modInverseBigInt(q, p);
  const h = ((((mp - mq) * qInv) % p) + p) % p;
  return mq + q * h;
}

function modPowBigInt(base: bigint, exp: bigint, mod: bigint): bigint {
  let result = 1n;
  base = ((base % mod) + mod) % mod;
  while (exp > 0n) {
    if (exp & 1n) result = (result * base) % mod;
    exp >>= 1n;
    base = (base * base) % mod;
  }
  return result;
}

function modInverseBigInt(a: bigint, m: bigint): bigint {
  let [oldR, r] = [a, m];
  let [oldS, s] = [1n, 0n];
  while (r !== 0n) {
    const q = oldR / r;
    [oldR, r] = [r, oldR - q * r];
    [oldS, s] = [s, oldS - q * s];
  }
  return ((oldS % m) + m) % m;
}
