语法与语义

核心概念

命题逻辑的语法（Syntax）和语义（Semantics）是数理逻辑的双翼。语法定义了合式公式（Well-Formed Formula, WFF）的构造规则——哪些符号串是"合法的"命题公式；语义定义了公式在给定赋值下的真值——公式"意味着什么"。这种语法与语义的严格分离是形式化方法的基石，也是编译器、类型系统和自动验证工具的理论源头。

语法关注的是符号的排列规则，不涉及意义；语义则赋予符号以真值解释。只有当两者结合，命题逻辑才成为一个完整的形式系统。理解这种分离有助于程序员区分"语法正确"（程序能通过解析）和"语义正确"（程序行为符合预期）之间的本质差异。

命题逻辑的语法系统
命题逻辑的语法通过递归定义构建合式公式。字母表包含：命题变元集 P = {p₁, p₂, ...}、逻辑联结词 {¬, ∧, ∨, →, ↔}、辅助符号 {(, )}。


合式公式的递归定义：


    

  1. 每个命题变元 pᵢ 是合式公式（原子公式）
    2. 

  2. 若 φ 是合式公式，则 ¬φ 是合式公式
    3. 

  3. 若 φ, ψ 是合式公式，则 (φ ∧ ψ), (φ ∨ ψ), (φ → ψ), (φ ↔ ψ) 是合式公式
    4. 

  4. 只有通过上述规则有限次应用得到的才是合式公式
    5. 



type PropFormula =
  | { type: 'var'; name: string }
  | { type: 'not'; child: PropFormula }
  | { type: 'and'; left: PropFormula; right: PropFormula }
  | { type: 'or'; left: PropFormula; right: PropFormula }
  | { type: 'implies'; left: PropFormula; right: PropFormula }
  | { type: 'iff'; left: PropFormula; right: PropFormula };

function parseFormula(tokens: string[]): { formula: PropFormula; rest: string[] } {
  return parseIff(tokens);
}

function parseIff(tokens: string[]): { formula: PropFormula; rest: string[] } {
  let { formula, rest } = parseImplies(tokens);
  while (rest[0] === '↔') {
    const right = parseImplies(rest.slice(1));
    formula = { type: 'iff', left: formula, right: right.formula };
    rest = right.rest;
  }
  return { formula, rest };
}

function parseImplies(tokens: string[]): { formula: PropFormula; rest: string[] } {
  let { formula, rest } = parseOr(tokens);
  if (rest[0] === '→') {
    const right = parseImplies(rest.slice(1));
    formula = { type: 'implies', left: formula, right: right.formula };
    rest = right.rest;
  }
  return { formula, rest };
}

function parseOr(tokens: string[]): { formula: PropFormula; rest: string[] } {
  let { formula, rest } = parseAnd(tokens);
  while (rest[0] === '∨') {
    const right = parseAnd(rest.slice(1));
    formula = { type: 'or', left: formula, right: right.formula };
    rest = right.rest;
  }
  return { formula, rest };
}

function parseAnd(tokens: string[]): { formula: PropFormula; rest: string[] } {
  let { formula, rest } = parseNot(tokens);
  while (rest[0] === '∧') {
    const right = parseNot(rest.slice(1));
    formula = { type: 'and', left: formula, right: right.formula };
    rest = right.rest;
  }
  return { formula, rest };
}

function parseNot(tokens: string[]): { formula: PropFormula; rest: string[] } {
  if (tokens[0] === '¬') {
    const { formula, rest } = parseNot(tokens.slice(1));
    return { formula: { type: 'not', child: formula }, rest };
  }
  return parseAtom(tokens);
}

function parseAtom(tokens: string[]): { formula: PropFormula; rest: string[] } {
  if (tokens[0] === '(') {
    const { formula, rest } = parseFormula(tokens.slice(1));
    return { formula, rest: rest.slice(1) };
  }
  return { formula: { type: 'var', name: tokens[0] }, rest: tokens.slice(1) };
}
联结词的优先级（从高到低）：¬ > ∧ > ∨ > → > ↔。蕴涵 → 右结合，其余左结合。


真值赋值与语义求值
真值赋值是从命题变元集到 {T, F} 的映射 v: P → {T, F}。给定赋值 v，每个合式公式的真值由递归的解释函数 ⊨ 确定。


type Valuation = Map<string, boolean>;

function evaluate(formula: PropFormula, v: Valuation): boolean {
  switch (formula.type) {
    case 'var':
      return v.get(formula.name) ?? false;
    case 'not':
      return !evaluate(formula.child, v);
    case 'and':
      return evaluate(formula.left, v) && evaluate(formula.right, v);
    case 'or':
      return evaluate(formula.left, v) || evaluate(formula.right, v);
    case 'implies':
      return !evaluate(formula.left, v) || evaluate(formula.right, v);
    case 'iff':
      return evaluate(formula.left, v) === evaluate(formula.right, v);
  }
}

function getVariables(formula: PropFormula): Set<string> {
  switch (formula.type) {
    case 'var':
      return new Set([formula.name]);
    case 'not':
      return getVariables(formula.child);
    default: {
      const left = 'left' in formula ? getVariables(formula.left) : new Set<string>();
      const right = 'right' in formula ? getVariables(formula.right) : new Set<string>();
      return new Set([...left, ...right]);
    }
  }
}

function allValuations(vars: string[]): Valuation[] {
  const n = vars.length;
  const result: Valuation[] = [];
  for (let mask = 0; mask < 1 << n; mask++) {
    const v = new Map<string, boolean>();
    for (let i = 0; i < n; i++) {
      v.set(vars[i], Boolean(mask & (1 << (n - 1 - i))));
    }
    result.push(v);
  }
  return result;
}
永真式、可满足性与逻辑等价
三种语义分类：


    

  • 永真式（Tautology）：在所有赋值下为真，如 p ∨ ¬p
    • 

  • 矛盾式（Contradiction）：在所有赋值下为假，如 p ∧ ¬p
    • 

  • 可满足式（Satisfiable）：存在某个赋值使其为真
    • 



逻辑等价 φ ≡ ψ：φ 和 ψ 在所有赋值下真值相同。等价于 φ ↔ ψ 是永真式。

function classify(formula: PropFormula): 'tautology' | 'contradiction' | 'satisfiable' {
  const vars = [...getVariables(formula)];
  const valuations = allValuations(vars);

  let allTrue = true;
  let allFalse = true;

  for (const v of valuations) {
    const result = evaluate(formula, v);
    if (!result) allTrue = false;
    if (result) allFalse = false;
  }

  if (allTrue) return 'tautology';
  if (allFalse) return 'contradiction';
  return 'satisfiable';
}

function areEquivalent(f1: PropFormula, f2: PropFormula): boolean {
  const vars = [...new Set([...getVariables(f1), ...getVariables(f2)])];
  const valuations = allValuations(vars);
  return valuations.every((v) => evaluate(f1, v) === evaluate(f2, v));
}

function logicalConsequence(premises: PropFormula[], conclusion: PropFormula): boolean {
  const allVars = new Set<string>();
  for (const p of premises) for (const v of getVariables(p)) allVars.add(v);
  for (const v of getVariables(conclusion)) allVars.add(v);

  const valuations = allValuations([...allVars]);
  return valuations.every((v) => {
    const premisesTrue = premises.every((p) => evaluate(p, v));
    return !premisesTrue || evaluate(conclusion, v);
  });
}
联结词的完备集与函数完全性
一个联结词集合是功能完备的（Functionally Complete），当且仅当任何布尔函数都可以仅用该集合中的联结词表达。


经典的完备集：{¬, ∧}、{¬, ∨}、{¬, →}。单个联结词的完备集：{↓}（NOR）、{↑}（NAND）。这在电路设计中具有重要意义——NAND 门可以实现任何逻辑电路。


type BooleanFunction = (inputs: boolean[]) => boolean;

function expressWithNand(f: BooleanFunction, n: number): string {
  const nand = (a: string, b: string) => `(${a} ↑ ${b})`;
  const not = (a: string) => nand(a, a);
  const and = (a: string, b: string) => not(nand(a, b));
  const or = (a: string, b: string) => nand(not(a), not(b));

  const vars = Array.from({ length: n }, (_, i) => `p${i + 1}`);

  const minterms: string[] = [];
  for (let mask = 0; mask < 1 << n; mask++) {
    const inputs = Array.from({ length: n }, (_, i) => Boolean(mask & (1 << (n - 1 - i))));
    if (f(inputs)) {
      const terms = vars.map((v, i) => (inputs[i] ? v : not(v)));
      minterms.push(terms.reduce((acc, t) => and(acc, t)));
    }
  }

  if (minterms.length === 0) return not(or(vars[0], not(vars[0])));
  return minterms.reduce((acc, t) => or(acc, t));
}
小结
    

  • 命题逻辑的语法通过递归定义构建合式公式，语义通过真值赋值赋予公式以真值解释
    • 

  • 永真式在所有赋值下为真，可满足式存在使其为真的赋值，矛盾式在所有赋值下为假
    • 

  • 逻辑等价律（德摩根律、分配律、蕴涵消除等）是公式化简和自动推理的基础工具
    • 

  • NAND 和 NOR 各自构成功能完备集，这是数字电路设计的理论基础
    • 

  • 语法与语义的严格分离是形式化方法的基石，对应程序设计中"语法正确"与"语义正确"的区别
