SAT 问题

核心概念

SAT（Boolean Satisfiability Problem，布尔可满足性问题）是命题逻辑中最基本的计算问题：给定一个命题逻辑公式 φ，是否存在一组变量赋值使得 φ 为真？这个看似简单的问题是计算复杂性理论的核心——它是第一个被证明为 NP 完全的问题（Cook-Levin 定理，1971），也是现代工业级验证工具、人工智能规划和密码学分析的核心求解引擎。

SAT 的理论意义在于它连接了逻辑学与计算复杂性。任何 NP 问题都可以多项式时间归约为 SAT，这意味着如果 SAT 有多项式时间算法，则 P = NP。尽管最坏情况下 SAT 是困难的，现代 SAT 求解器通过精巧的算法和启发式策略，能够高效处理数百万变量的工业实例。

NP 完全性与 Cook-Levin 定理
NP 完全性是理解 SAT 理论地位的关键。一个问题 L 是 NP 完全的，需满足两个条件：L ∈ NP（解可以在多项式时间验证），且所有 NP 问题都可多项式时间归约到 L。


Cook（1971）和 Levin（独立发现）证明了 SAT 是 NP 完全的。证明的核心思路是：任何 NP 问题都有一个非确定性图灵机 M 在多项式时间内判定。将 M 的计算过程编码为命题逻辑公式——每个时间步的磁带内容、读写头位置、状态转移都用命题变量表示，转移规则编码为子句。最终得到的 CNF 公式可满足当且仅当 M 接受输入。


这个归约的深远意义在于建立了 SAT 作为"万能 NP 问题"的地位。后续的 NP 完全性证明（图着色、哈密顿回路、背包问题等）几乎都从 SAT 或 3-SAT 归约而来。


3-SAT 的 NP 完全性通过从 SAT 到 3-SAT 的归约证明。任意长度的子句可以通过引入辅助变量拆分为等价的 3-文字子句。例如，子句 (x₁ ∨ x₂ ∨ x₃ ∨ x₄) 可拆分为 (x₁ ∨ x₂ ∨ y) ∧ (¬y ∨ x₃ ∨ x₄)，其中 y 是新引入的变量。


相比之下，2-SAT 在 P 中——可以构造蕴含图（每个 2-子句 (a ∨ b) 编码为 ¬a → b 和 ¬b → a），通过强连通分量算法在线性时间判定可满足性。这说明从 2-SAT 到 3-SAT 存在复杂度的质变。


DPLL 算法
DPLL（Davis-Putnam-Logemann-Loveland，1962）是现代 SAT 求解的奠基算法，采用系统化的回溯搜索策略。


算法的三个核心操作：


单位传播（Unit Propagation）：如果某个子句只剩一个未赋值的文字（单位子句），则该文字必须为真。连锁反应可能产生新的单位子句，形成传播链。


纯文字消除（Pure Literal Elimination）：如果某个变量在所有子句中只以正（或只以负）形式出现，直接赋值满足所有包含它的子句。


分支决策（Branching）：选择一个未赋值变量，尝试赋值为真，若失败则回溯尝试假。


type Literal = number;
type Clause = Literal[];
type Assignment = Map<number, boolean>;

function dpll(clauses: Clause[], assign: Assignment): boolean {
  clauses = unitPropagate(clauses, assign);
  if (clauses.length === 0) return true;
  if (clauses.some((c) => c.length === 0)) return false;

  clauses = pureLiteralElim(clauses, assign);
  if (clauses.length === 0) return true;

  const variable = chooseBranchVariable(clauses);

  assign.set(variable, true);
  if (dpll(simplify(clauses, variable), new Map(assign))) return true;

  assign.set(variable, false);
  if (dpll(simplify(clauses, -variable), new Map(assign))) return true;

  return false;
}

function unitPropagate(clauses: Clause[], assign: Assignment): Clause[] {
  let changed = true;
  while (changed) {
    changed = false;
    for (const clause of clauses) {
      if (clause.length === 1) {
        const lit = clause[0];
        assign.set(Math.abs(lit), lit > 0);
        clauses = simplify(clauses, lit);
        changed = true;
        break;
      }
    }
  }
  return clauses;
}

function simplify(clauses: Clause[], lit: Literal): Clause[] {
  return clauses.filter((c) => !c.includes(lit)).map((c) => c.filter((l) => l !== -lit));
}

function pureLiteralElim(clauses: Clause[], assign: Assignment): Clause[] {
  const literals = new Set(clauses.flat());
  for (const lit of literals) {
    if (!literals.has(-lit)) {
      assign.set(Math.abs(lit), lit > 0);
      clauses = simplify(clauses, lit);
    }
  }
  return clauses;
}

function chooseBranchVariable(clauses: Clause[]): number {
  return Math.abs(clauses[0][0]);
}
DPLL 的搜索空间是一棵二叉决策树，每个内部节点对应一次分支决策。单位传播极大地修剪了搜索空间——在实际问题中，大量推导通过传播完成，分支决策相对较少。


CDCL 与现代求解技术
CDCL（Conflict-Driven Clause Learning）是 DPLL 的革命性改进，由 GRASP（1996）和 Chaff（2001）等求解器发展而来。CDCL 引入了两个关键创新：冲突分析和子句学习。


当搜索过程中发现矛盾（某个子句所有文字都为假），CDCL 不是简单回溯到上一个决策点，而是分析冲突的原因——通过蕴含图追溯冲突根源，学习一个新的子句（学习子句），然后进行非时序回溯（backjumping）跳过无关的决策层级。


现代 CDCL 求解器还集成了多项关键技术：


两观察文字（Two Watched Literals）：每个子句只监视两个未赋值文字，大幅减少单位传播的检查开销。只有当被监视的文字被赋假时才需要更新。


重启策略（Restart）：周期性丢弃当前搜索进度、保留学习子句重新开始。Luby 序列和几何重启是常用策略。重启看似浪费，但配合学习子句能快速逃离困难的搜索区域。


变量活动度（VSIDS）：优先选择最近参与冲突的变量进行分支决策。通过指数衰减的活动度评分，动态聚焦于问题的"热点"区域。

SAT 在计算机科学中的应用
SAT 求解器已成为计算机科学中的"通用推理引擎"，广泛应用于多个关键领域。


硬件验证：芯片设计中的等价性检查（两个电路是否在所有输入下行为一致）可直接编码为 SAT 问题。Intel 和 AMD 使用 SAT 求解器验证处理器微架构，避免了类似 Pentium FDIV bug 的灾难。有界模型检测（BMC）将系统的 k 步行为展开为命题公式，检查安全性违规。


软件验证与测试：符号执行工具（KLEE、SAGE）将程序路径条件编码为 SAT/SMT 问题，自动生成覆盖特定路径的测试输入。微软的 SAGE 工具通过这种方式发现了 Windows 和 Office 中数百个安全漏洞。


人工智能规划：经典 AI 规划问题（如 STRIPS）可编码为 SAT：在 k 个时间步内，是否存在动作序列将初始状态转变为目标状态？SATplan 系统曾在 AI 规划竞赛中取得优异成绩。


密码分析：密码协议的安全性分析可归约为 SAT 问题。例如，找到 hash 函数的碰撞等价于求解一个大规模 SAT 实例。


function encodePigeonhole(n: number): Clause[] {
  const clauses: Clause[] = [];
  const v = (pigeon: number, hole: number) => pigeon * n + hole + 1;

  for (let p = 0; p <= n; p++) {
    const clause: Literal[] = [];
    for (let h = 0; h < n; h++) {
      clause.push(v(p, h));
    }
    clauses.push(clause);
  }

  for (let h = 0; h < n; h++) {
    for (let p1 = 0; p1 <= n; p1++) {
      for (let p2 = p1 + 1; p2 <= n; p2++) {
        clauses.push([-v(p1, h), -v(p2, h)]);
      }
    }
  }

  return clauses;
}
鸽巢原理（n+1 只鸽子放入 n 个洞，必有一个洞放两只）的 SAT 编码是研究求解器难度的经典基准。虽然人类可以秒懂其不可满足性，但基于消解的 SAT 求解器需要指数级时间才能证明——这揭示了 SAT 求解的本质困难性。


小结
    

  • SAT 是第一个 NP 完全问题，连接了逻辑学与计算复杂性理论，是理解 P vs NP 问题的核心
    • 

  • DPLL 算法通过单位传播和回溯搜索奠定了系统化求解的基础
    • 

  • CDCL 通过冲突驱动的子句学习和非时序回溯，将 SAT 求解提升了数个数量级
    • 

  • 现代 SAT 求解器能处理数百万变量的工业实例，是硬件验证、软件测试和 AI 规划的核心引擎
    • 

  • SAT 的理论困难性（最坏指数级）与实际高效性（启发式策略）之间的张力，是计算复杂性研究的永恒主题
