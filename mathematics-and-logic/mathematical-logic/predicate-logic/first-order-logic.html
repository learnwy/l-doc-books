一阶逻辑

核心概念

一阶逻辑（First-Order Logic，FOL）是命题逻辑的本质性扩展，它引入了个体变量、量词和谓词，使我们能够表达"对所有对象"和"存在某个对象"这类关于对象结构的陈述。命题逻辑只能处理命题之间的逻辑关系，而一阶逻辑能深入到命题内部，刻画对象的属性和对象之间的关系。

一阶逻辑是数学基础的标准形式化语言——集合论（ZFC）、算术（Peano 公理）、群论公理都用一阶逻辑表述。它也是数据库查询语言（SQL 的理论基础是关系演算）、程序规约（Hoare 逻辑）和知识表示（描述逻辑）的核心工具。

一阶语言的语法构成
一阶语言 L 由一个签名（signature）确定，签名规定了可用的非逻辑符号：


常量符号：表示论域中的特定对象，如 0、1、e（群的单位元）。


函数符号：从对象到对象的映射，每个函数符号有固定的元数（arity），如一元函数 S（后继）、二元函数 +（加法）。


谓词符号：表示对象的属性或关系，每个谓词符号有固定的元数，如一元谓词 Prime(x)、二元谓词 <(x, y)。


项（Term） 是指代对象的表达式：变量是项，常量是项，如果 f 是 n 元函数符号且 t₁,...,tₙ 是项，则 f(t₁,...,tₙ) 是项。


原子公式：如果 P 是 n 元谓词符号且 t₁,...,tₙ 是项，则 P(t₁,...,tₙ) 是原子公式。等式 t₁ = t₂ 也是原子公式（在带等式的一阶逻辑中）。


公式的递归定义：原子公式是公式；如果 φ、ψ 是公式，则 ¬φ、φ ∧ ψ、φ ∨ ψ、φ → ψ 是公式；如果 φ 是公式且 x 是变量，则 ∀x φ 和 ∃x φ 是公式。


type Term = { kind: 'var'; name: string } | { kind: 'const'; name: string } | { kind: 'app'; fn: string; args: Term[] };

type Formula =
  | { kind: 'pred'; name: string; args: Term[] }
  | { kind: 'eq'; left: Term; right: Term }
  | { kind: 'not'; sub: Formula }
  | { kind: 'and'; left: Formula; right: Formula }
  | { kind: 'or'; left: Formula; right: Formula }
  | { kind: 'implies'; left: Formula; right: Formula }
  | { kind: 'forall'; variable: string; body: Formula }
  | { kind: 'exists'; variable: string; body: Formula };
变量的自由与约束是一阶逻辑语法的关键概念。在 ∀x P(x, y) 中，x 被 ∀x 约束，y 是自由的。一个公式是句子（sentence）当且仅当它没有自由变量。句子的真值只依赖于结构，与变量赋值无关。


一阶结构与语义解释
一阶逻辑的语义由结构（structure，也称模型或解释）给出。一个签名 σ 上的结构 M = (D, I) 包含：


论域（Domain） D：一个非空集合，是量词"所有"和"存在"的范围。


解释函数（Interpretation） I：将每个常量符号映射到 D 中的元素，每个 n 元函数符号映射到 D^n → D 的函数，每个 n 元谓词符号映射到 D^n 的子集（即 n 元关系）。


给定结构 M 和变量赋值 σ: Var → D，公式的满足关系 M, σ ⊨ φ 递归定义：


    

  • M, σ ⊨ P(t₁,...,tₙ) 当且仅当 (⟦t₁⟧, ..., ⟦tₙ⟧) ∈ I(P)
    • 

  • M, σ ⊨ ∀x φ 当且仅当对所有 d ∈ D，M, σ[x↦d] ⊨ φ
    • 

  • M, σ ⊨ ∃x φ 当且仅当存在 d ∈ D，M, σ[x↦d] ⊨ φ
    •

一阶逻辑的语义赋予了它极强的建模能力。例如，群论公理可以形式化为：∀x∀y∀z ((x·y)·z = x·(y·z))（结合律），∀x (e·x = x ∧ x·e = x)（单位元），∀x∃y (x·y = e ∧ y·x = e)（逆元）。任何满足这些句子的结构都是一个群。


一阶逻辑的表达能力与局限
一阶逻辑的表达能力极为强大，但也有明确的边界。


能表达的：有限性描述（"恰好有 n 个元素满足 P"）、传递闭包的有限近似、算术的基本性质（Peano 公理）、集合论的全部公理（ZFC）。


不能表达的：Lindström 定理表明，一阶逻辑是满足紧致性和 Löwenheim-Skolem 定理的最强逻辑。以下性质无法用一阶语句表达：


    

  • "论域是有限的"——由紧致性可知，任何一阶理论如果有任意大的有限模型，就有无限模型
    • 

  • "论域恰好是可数的"——由向下 Löwenheim-Skolem 定理，如果有不可数模型就有可数模型；由向上定理，如果有无限模型就有任意大基数的模型
    • 

  • 图的连通性——连通性本质上需要传递闭包，而一阶逻辑无法表达传递闭包
    • 

  • 良序性——"每个非空子集有最小元"量化了所有子集，超出一阶逻辑的范围
    • 



function encodeExactlyN(predicate: string, n: number): Formula {
  const vars = Array.from({ length: n }, (_, i) => `x${i}`);

  const existPart: Formula = vars.reduceRight<Formula>((body, v) => ({ kind: 'exists', variable: v, body }), {
    kind: 'and',
    left: vars.reduce<Formula>(
      (acc, v) => ({
        kind: 'and',
        left: acc,
        right: { kind: 'pred', name: predicate, args: [{ kind: 'var', name: v }] },
      }),
      { kind: 'pred', name: predicate, args: [{ kind: 'var', name: vars[0] }] },
    ),
    right: distinctPairs(vars),
  });

  const atMostPart: Formula = {
    kind: 'forall',
    variable: 'y',
    body: {
      kind: 'implies',
      left: { kind: 'pred', name: predicate, args: [{ kind: 'var', name: 'y' }] },
      right: vars.reduce<Formula>(
        (acc, v) => ({
          kind: 'or',
          left: acc,
          right: { kind: 'eq', left: { kind: 'var', name: 'y' }, right: { kind: 'var', name: v } },
        }),
        { kind: 'eq', left: { kind: 'var', name: 'y' }, right: { kind: 'var', name: vars[0] } },
      ),
    },
  };

  return { kind: 'and', left: existPart, right: atMostPart };
}

function distinctPairs(vars: string[]): Formula {
  const pairs: Formula[] = [];
  for (let i = 0; i < vars.length; i++) {
    for (let j = i + 1; j < vars.length; j++) {
      pairs.push({
        kind: 'not',
        sub: {
          kind: 'eq',
          left: { kind: 'var', name: vars[i] },
          right: { kind: 'var', name: vars[j] },
        },
      });
    }
  }
  return pairs.reduce((a, b) => ({ kind: 'and', left: a, right: b }));
}
这些局限性不是缺陷，而是一阶逻辑的"黄金比例"——正是紧致性和 Löwenheim-Skolem 性质使得一阶逻辑拥有完备的推理系统和丰富的模型论。


一阶逻辑在计算机科学中的应用
一阶逻辑在计算机科学中的应用极为广泛，是多个核心领域的形式基础。


数据库理论：关系代数和关系演算（SQL 的理论基础）本质上是一阶逻辑的变体。SQL 的 SELECT-FROM-WHERE 对应存在量词，NOT EXISTS 对应全称量词的否定，JOIN 对应合取。数据库查询优化中的等价变换直接对应一阶逻辑的等价变换。


程序验证：Hoare 逻辑使用一阶公式作为前置条件和后置条件。{P}S{Q} 表示：如果在满足 P 的状态下执行 S，若 S 终止则终止状态满足 Q。循环不变式的发现和验证是一阶推理的核心应用。


知识表示与推理：描述逻辑（OWL 本体语言的基础）是一阶逻辑的可判定子片段。Prolog 逻辑编程基于 Horn 子句——一阶逻辑的特殊形式。


类型系统：依赖类型理论中的类型可以依赖于值，其类型检查本质上是一阶推理。Coq、Agda 等证明助手的核心都建立在一阶逻辑（及其扩展）之上。

小结
    

  • 一阶逻辑通过引入个体变量、量词和谓词，将命题逻辑的表达能力从命题间关系扩展到对象的属性和关系
    • 

  • 语法由签名确定（常量、函数、谓词），语义由结构给出（论域 + 解释函数 + 赋值）
    • 

  • 一阶逻辑是满足紧致性和 Löwenheim-Skolem 性质的最强逻辑（Lindström 定理），这些性质既是力量也是边界
    • 

  • 数据库查询、程序验证、知识表示、类型系统等计算机科学核心领域都以一阶逻辑为形式基础
    • 

  • 一阶逻辑的半可判定性（有效公式可枚举但不可判定）是其在自动推理中需要面对的根本挑战
    •
