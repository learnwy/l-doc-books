量词与推理

核心概念

量词是一阶逻辑区别于命题逻辑的核心机制，它使我们能够精确表达"对论域中所有对象"（全称量词 ∀）和"论域中存在某个对象"（存在量词 ∃）这两类基本陈述。量词推理是一阶逻辑推理系统的核心组成部分，包括量词的引入规则、消去规则以及量词之间的交互规律。

量词推理的复杂性远超命题逻辑。量词的嵌套顺序（∀x∃y vs ∃y∀x）、量词与联结词的交互（∀ 与 ∧ 的分配，∃ 与 ∨ 的分配）、约束变量的重命名（α 变换）等问题构成了一阶推理的核心挑战。掌握这些规律是理解数据库查询优化、程序验证和自动定理证明的基础。

量词的自然演绎规则
在自然演绎系统中，每个量词配备引入规则和消去规则，它们的设计需要精细的变量条件来保证可靠性。


全称消去（∀E，Universal Instantiation）：


  ∀x φ(x)
  ──────── ∀E
   φ(t)
其中 t 是任意项，且 t 对 φ 中的 x 是自由的（即将 x 替换为 t 不会导致 t 中的自由变量被 φ 中的量词捕获）。这是最简单的量词规则——"对所有对象成立"意味着对任何特定对象也成立。


全称引入（∀I，Universal Generalization）：


  φ(a)       a 不在任何未释放假设中出现
  ──────── ∀I
  ∀x φ(x)
条件至关重要：a 必须是"任意的"——不能出现在任何活跃假设中。否则我们可能从特殊情况推出一般结论。例如，从假设 P(a) 不能推出 ∀xP(x)，因为 a 不是任意的。


存在引入（∃I，Existential Generalization）：


   φ(t)
  ──────── ∃I
  ∃x φ(x)
如果某个特定对象 t 满足 φ，则存在对象满足 φ。


存在消去（∃E，Existential Elimination）：


  ∃x φ(x)    [φ(a)]...ψ     a 不在 ψ、∃xφ(x) 或其他假设中出现
  ────────────────────────── ∃E
             ψ
存在消去是最精妙的规则：我们知道存在满足 φ 的对象，引入一个"见证"名 a 代表它，在此假设下推导出 ψ。关键条件是 a 不能出现在结论 ψ 中——我们不能把"某个特定见证"带出推导范围。

量词的前束范式转换
前束范式（Prenex Normal Form，PNF）是将所有量词移到公式最前端的标准形式：Q₁x₁ Q₂x₂ ... Qₙxₙ φ，其中 Qᵢ ∈ {∀, ∃}，φ 是无量词公式（称为矩阵）。


任何一阶公式都可以等价转换为前束范式，转换步骤包括：


步骤 1 — 消除多余联结词：用 ¬、∧、∨、→ 表示所有联结词。


步骤 2 — 否定内推（量词对偶）：


    

  • ¬∀xφ ↔ ∃x¬φ
    • 

  • ¬∃xφ ↔ ∀x¬φ
    • 



步骤 3 — 变量重命名（避免捕获）：确保不同量词绑定不同变量。


步骤 4 — 量词外提：


    

  • (∀xφ) ∧ ψ ↔ ∀x(φ ∧ ψ)（x 不在 ψ 中自由出现）
    • 

  • (∃xφ) ∧ ψ ↔ ∃x(φ ∧ ψ)（x 不在 ψ 中自由出现）
    • 

  • (∀xφ) → ψ ↔ ∃x(φ → ψ)（注意量词翻转！）
    • 

  • φ → (∀xψ) ↔ ∀x(φ → ψ)（x 不在 φ 中自由出现）
    •

前束范式在自动定理证明中至关重要，因为它是进一步转换为 Skolem 范式和子句形式的前提——消解算法要求输入为子句集。


Skolem 化与消解推理
Skolem 化是将存在量词消除的过程，它将前束范式公式转换为只含全称量词的Skolem 范式，同时保持可满足性等价（但不保持逻辑等价）。


Skolem 化规则：对于前束范式 ∀x₁...∀xₖ∃y φ(x₁,...,xₖ,y)，引入新的 k 元函数符号 f（Skolem 函数），替换为 ∀x₁...∀xₖ φ(x₁,...,xₖ, f(x₁,...,xₖ))。


直觉：∃y 声称"存在某个 y"，Skolem 函数 f 将这个"某个 y"具体化为依赖于前面全称量词变量的函数。如果 ∃y 不在任何全称量词范围内，则引入 Skolem 常量。


Skolem 化后的公式去掉全称量词（隐含全称闭包），转换为 CNF，得到子句集。一阶消解（Resolution）就在子句集上操作。


一阶消解规则需要合一（Unification） 来匹配互补文字中的项。合一算法找到最一般合一子（MGU）σ，使得两个项在 σ 下相等。


type Substitution = Map<string, Term>;

function unify(t1: Term, t2: Term): Substitution | null {
  if (t1.kind === 'var') {
    if (occursIn(t1.name, t2)) return null;
    return new Map([[t1.name, t2]]);
  }
  if (t2.kind === 'var') {
    if (occursIn(t2.name, t1)) return null;
    return new Map([[t2.name, t1]]);
  }
  if (t1.kind === 'const' && t2.kind === 'const') {
    return t1.name === t2.name ? new Map() : null;
  }
  if (t1.kind === 'app' && t2.kind === 'app') {
    if (t1.fn !== t2.fn || t1.args.length !== t2.args.length) return null;
    let sigma: Substitution = new Map();
    for (let i = 0; i < t1.args.length; i++) {
      const s = unify(applySubst(t1.args[i], sigma), applySubst(t2.args[i], sigma));
      if (s === null) return null;
      sigma = compose(sigma, s);
    }
    return sigma;
  }
  return null;
}

function occursIn(varName: string, t: Term): boolean {
  if (t.kind === 'var') return t.name === varName;
  if (t.kind === 'const') return false;
  return t.args.some((arg) => occursIn(varName, arg));
}

function applySubst(t: Term, sigma: Substitution): Term {
  if (t.kind === 'var') return sigma.get(t.name) ?? t;
  if (t.kind === 'const') return t;
  return { kind: 'app', fn: t.fn, args: t.args.map((a) => applySubst(a, sigma)) };
}

function compose(s1: Substitution, s2: Substitution): Substitution {
  const result = new Map<string, Term>();
  for (const [k, v] of s1) result.set(k, applySubst(v, s2));
  for (const [k, v] of s2) if (!s1.has(k)) result.set(k, v);
  return result;
}
一阶消解：给定子句 C₁ = {P(s)} ∪ R₁ 和 C₂ = {¬P(t)} ∪ R₂，如果 σ = MGU(s, t) 存在，则消解式为 σ(R₁ ∪ R₂)。一阶消解是反驳完备的——如果子句集不可满足，消解总能推出空子句 □。


量词消除与可判定片段
虽然一般的一阶逻辑是半可判定的（有效公式可枚举但不可判定），但某些特殊理论允许量词消除（Quantifier Elimination），从而变得可判定。


量词消除：理论 T 允许量词消除，如果对每个公式 φ(x₁,...,xₙ)，存在无量词公式 ψ(x₁,...,xₙ) 使得 T ⊢ φ ↔ ψ。

Presburger 算术（只有加法的整数理论）的量词消除在 SMT 求解器中广泛应用。例如，判断线性整数不等式系统是否有解——这在编译器的数组越界检查和循环优化中至关重要。


实闭域（Tarski 的量词消除）表明：所有关于实数的加法和乘法不等式的一阶句子都是可判定的。这个深刻结果在计算机辅助几何定理证明中有重要应用。


小结
    

  • 量词推理的核心是四条规则（∀I、∀E、∃I、∃E），每条规则都有精确的变量条件保证可靠性
    • 

  • 量词的分配律、对偶律和顺序敏感性是理解一阶推理复杂性的关键
    • 

  • 前束范式和 Skolem 化是自动定理证明的预处理步骤，将公式转换为适合消解算法的子句形式
    • 

  • 合一算法是一阶消解的核心，它通过找到最一般合一子匹配互补文字
    • 

  • 量词消除使特定理论变得可判定，在 SMT 求解器和程序验证中有核心应用
    •
