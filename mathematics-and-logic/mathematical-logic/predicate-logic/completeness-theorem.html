完备性定理

核心概念

哥德尔完备性定理（Gödel's Completeness Theorem，1929）是数理逻辑最深刻的成果之一，它证明了一阶逻辑的语法推导（⊢）与语义蕴含（⊨）完全一致。具体而言：一个一阶句子是逻辑有效的（在所有模型中为真），当且仅当它在形式系统中可证。这意味着一阶逻辑的推理规则"恰好捕获了"语义上的有效推理——既不遗漏（完备），也不出错（可靠）。

完备性定理的意义远超技术层面。它为一阶逻辑赋予了独特的认识论地位：语义真理（模型论）和语法可证性（证明论）在一阶逻辑中达到了完美统一。这种统一在更强的逻辑系统（二阶逻辑、标准语义）中不再成立，使一阶逻辑成为数学基础和自动推理的"甜蜜点"。

Henkin 构造法
完备性定理的现代标准证明采用 Henkin 构造（Leon Henkin，1949），其策略是：如果 Γ ⊬ φ，则构造一个模型使 Γ 为真而 φ 为假。等价地，如果 Γ ∪ {¬φ} 是一致的，则它有模型。


证明分三个关键步骤：


步骤 1 — Henkin 扩展：向语言中添加可数多个新常量符号 c₁, c₂, ...（Henkin 见证常量）。对每个形如 ∃xψ(x) 的公式，添加公理 ∃xψ(x) → ψ(cᵢ)。这确保了每个存在陈述都有具体的"见证者"。


步骤 2 — 极大一致扩展：利用 Zorn 引理（或在可数语言中用枚举+逐步添加），将 Γ ∪ {¬φ} 扩展为极大一致集 Γ*。极大一致集的关键性质：对每个句子 σ，要么 σ ∈ Γ* 要么 ¬σ ∈ Γ*；如果 σ ∧ τ ∈ Γ* 当且仅当 σ ∈ Γ* 且 τ ∈ Γ*。


步骤 3 — 项模型构造：以闭合项的等价类作为论域（t₁ ∼ t₂ 当且仅当 t₁ = t₂ ∈ Γ*），常量解释为自身的等价类，谓词 P 的解释为 {([t₁],...,[tₙ]) | P(t₁,...,tₙ) ∈ Γ*}。


真值引理（Truth Lemma）是证明的核心，它通过对公式复杂度的归纳证明：在项模型 M 中，M ⊨ σ 当且仅当 σ ∈ Γ*。这就完成了从语法一致性到语义可满足性的桥梁。


Henkin 构造的深层意义在于它展示了语法对象（公式、证明）如何生成语义对象（模型）。这种"语法即语义"的思想贯穿整个模型论。


完备性定理的等价形式
完备性定理有多个等价陈述，每个形式揭示了不同的数学层面：


形式 1（有效性完备性）：如果 ⊨ φ，则 ⊢ φ。所有逻辑有效的句子都是可证的。


形式 2（强完备性）：如果 Γ ⊨ φ，则 Γ ⊢ φ。语义蕴含蕴含语法推导。


形式 3（模型存在性）：每个一致的理论都有模型。


形式 4（反驳完备性）：如果 Γ 不可满足，则 Γ ⊢ ⊥。不可满足的理论必然能推出矛盾。


形式 3 是最直接的：一致性（纯语法的不矛盾性）保证了模型的存在（语义可满足性）。这在模型论中极为有用——要证明某个结构存在，只需证明相应的一阶理论是一致的。


interface Theory {
  language: string[];
  axioms: string[];
}

interface Model {
  domain: Set<string>;
  interpretation: Map<string, unknown>;
}

function isConsistent(theory: Theory): boolean {
  return !canDerive(theory, '⊥');
}

function canDerive(theory: Theory, formula: string): boolean {
  const clauses = theory.axioms.map(toClauses).flat();
  return resolution(clauses, formula);
}

function resolution(clauses: string[][], target: string): boolean {
  const negTarget = negate(target);
  const allClauses = [...clauses, ...toClauses(negTarget)];
  const seen = new Set<string>();
  const queue = [...allClauses];

  while (queue.length > 0) {
    const c1 = queue.shift()!;
    for (const c2 of allClauses) {
      const resolvent = resolve(c1, c2);
      if (resolvent !== null) {
        if (resolvent.length === 0) return true;
        const key = resolvent.sort().join(',');
        if (!seen.has(key)) {
          seen.add(key);
          queue.push(resolvent);
        }
      }
    }
  }
  return false;
}

function resolve(c1: string[], c2: string[]): string[] | null {
  for (const lit of c1) {
    const comp = lit.startsWith('¬') ? lit.slice(1) : `¬${lit}`;
    if (c2.includes(comp)) {
      return [...c1.filter((l) => l !== lit), ...c2.filter((l) => l !== comp)];
    }
  }
  return null;
}

function negate(f: string): string {
  return f.startsWith('¬') ? f.slice(1) : `¬${f}`;
}

function toClauses(f: string): string[][] {
  return [[f]];
}

紧致性定理及其应用
紧致性定理是完备性定理最重要的推论，它将"有限"与"无限"联系起来。


紧致性定理：一阶理论 Γ 可满足，当且仅当 Γ 的每个有限子集都可满足。


证明：如果 Γ 不可满足，由完备性定理 Γ ⊢ ⊥。证明是有限对象，只使用 Γ 的有限子集 Γ₀，故 Γ₀ ⊢ ⊥，由可靠性 Γ₀ 不可满足。


紧致性定理有强大的应用能力：


非标准模型的存在：考虑 Peano 算术 PA 加上公理集 {c > 0, c > 1, c > 2, ...}（c 是新常量）。每个有限子集都可满足（取 c 为足够大的自然数），由紧致性，整个集合可满足。其模型包含一个"无穷大"元素 c，这就是非标准自然数模型。


图着色：如果一个无限图的每个有限子图都是 k 可着色的，则整个无限图也是 k 可着色的。


一阶逻辑无法表达有限性：如果一阶句子集 Σ 的所有模型都是有限的，则 Σ 的模型大小有一个上界。因为如果 Σ 有任意大的有限模型，加上"至少有 n 个元素"的句子（对每个 n），每个有限子集可满足，由紧致性整个集合可满足——但其模型是无限的，矛盾。


Löwenheim-Skolem 定理
Löwenheim-Skolem 定理是完备性定理的另一个核心推论，它揭示了一阶逻辑对模型基数的"无法控制"。


向下 Löwenheim-Skolem 定理：如果可数语言的一阶理论有模型，则它有可数模型。这直接从 Henkin 构造得出——项模型是可数的。


向上 Löwenheim-Skolem 定理：如果一阶理论有无限模型，则对任何基数 κ ≥ |L|，它有基数为 κ 的模型。


这两个定理合在一起产生了著名的Skolem 悖论：ZFC 集合论的可数模型中"存在不可数集合"——模型内部的"不可数"和外部的"不可数"是不同的。这不是真正的矛盾，而是揭示了一阶逻辑的语义相对性。

Löwenheim-Skolem 定理在计算机科学中的一个重要应用是：如果一个规约（specification）用一阶逻辑表达，它不能精确锁定一个特定大小的模型（除非有限且给出上界）。这意味着一阶规约总是会有"意料之外"的模型——这既是表达力的局限，也是抽象的力量。


小结
    

  • 哥德尔完备性定理证明了一阶逻辑的语法推导与语义蕴含完全一致，是数理逻辑的基石
    • 

  • Henkin 构造通过见证常量、极大一致扩展和项模型，从语法一致性构造出语义模型
    • 

  • 紧致性定理是完备性定理的核心推论，将有限可满足性提升为无限可满足性，应用极为广泛
    • 

  • Löwenheim-Skolem 定理揭示了一阶逻辑对模型基数的"不可控制性"，产生了深刻的哲学问题
    • 

  • 完备性定理使一阶逻辑成为自动推理和数学基础的"甜蜜点"——足够强大又保持可控
