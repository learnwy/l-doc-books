模型论基础

核心概念

模型论（Model Theory）是数理逻辑的核心分支，研究形式语言与其数学解释（模型）之间的关系。如果说证明论关注的是"什么可以推导"，模型论关注的是"在什么结构中为真"。模型论的核心问题是：给定一组一阶句子（理论），它们有哪些模型？这些模型之间有什么关系？理论的语法性质如何决定模型的结构性质？

模型论不仅是纯数学的工具——它在数据库理论（查询等价性）、程序语义（指称语义）和人工智能（知识表示）中有重要应用。模型论的方法论核心是分类思想：通过理论的模型谱（模型的数量和类型）来理解理论的结构复杂度。

结构、同态与初等等价
结构是一阶语言的语义解释。签名 σ 上的结构 M = (|M|, I) 包含论域 |M|（非空集合）和解释函数 I（将签名中的符号映射到论域上的对象、函数和关系）。


同态（Homomorphism）：结构间保持函数和关系的映射 h: |M| → |N|。即 h(f^M(a₁,...,aₙ)) = f^N(h(a₁),...,h(aₙ))，且 (a₁,...,aₙ) ∈ R^M 蕴含 (h(a₁),...,h(aₙ)) ∈ R^N。


嵌入（Embedding）：双向保持关系的单射同态。


同构（Isomorphism）：满射嵌入。同构的结构在一阶逻辑中完全不可区分。


初等等价：M ≡ N 当且仅当对所有一阶句子 φ，M ⊨ φ ↔ N ⊨ φ。同构蕴含初等等价，但反之不成立。


初等子结构：M ≼ N 当且仅当 M ⊆ N 且对所有一阶公式 φ(x₁,...,xₙ) 和 a₁,...,aₙ ∈ |M|，M ⊨ φ(a₁,...,aₙ) ↔ N ⊨ φ(a₁,...,aₙ)。


interface Structure {
  domain: Set<string>;
  constants: Map<string, string>;
  functions: Map<string, (...args: string[]) => string>;
  relations: Map<string, (...args: string[]) => boolean>;
}

function isHomomorphism(h: Map<string, string>, source: Structure, target: Structure): boolean {
  for (const [name, f] of source.functions) {
    const targetF = target.functions.get(name);
    if (!targetF) return false;
    for (const args of allTuples(source.domain, arityOf(name))) {
      const sourceResult = f(...args);
      const mappedArgs = args.map((a) => h.get(a)!);
      const targetResult = targetF(...mappedArgs);
      if (h.get(sourceResult) !== targetResult) return false;
    }
  }

  for (const [name, r] of source.relations) {
    const targetR = target.relations.get(name);
    if (!targetR) return false;
    for (const args of allTuples(source.domain, arityOf(name))) {
      if (r(...args)) {
        const mappedArgs = args.map((a) => h.get(a)!);
        if (!targetR(...mappedArgs)) return false;
      }
    }
  }
  return true;
}

function allTuples(domain: Set<string>, arity: number): string[][] {
  if (arity === 0) return [[]];
  const elements = [...domain];
  const shorter = allTuples(domain, arity - 1);
  return shorter.flatMap((t) => elements.map((e) => [...t, e]));
}

function arityOf(_name: string): number {
  return 1;
}
Tarski-Vaught 判定法为识别初等子结构提供了实用工具：M ≼ N 当且仅当 M ⊆ N 且对每个公式 ∃yφ(ā, y)，如果 N ⊨ ∃yφ(ā, y)，则存在 b ∈ |M| 使得 N ⊨ φ(ā, b)。直觉上，M 中的"见证者足够多"。


类型与饱和模型
类型是模型论的核心工具，它描述了论域中元素（或元组）的所有一阶可表达性质。


n 元类型：给定理论 T 和参数集 A ⊆ |M|，一个 n 元类型 p(x₁,...,xₙ) ∈ Sₙ(A) 是一个最大一致的公式集——包含所有关于 x₁,...,xₙ 的一阶公式中与 T 和 A 一致的极大子集。


实现与省略：元组 ā 实现类型 p 如果 M ⊨ φ(ā) 对所有 φ ∈ p。类型 p 在 M 中被省略如果 M 中没有元组实现 p。


孤立类型：类型 p 是孤立的如果存在公式 φ ∈ p 使得 φ 蕴含 p 中所有公式。孤立类型总是在模型中被实现。


饱和模型：模型 M 是 κ-饱和的如果对任何 |A| < κ 的参数集 A ⊆ |M|，所有 A 上的 1 元类型都在 M 中被实现。饱和模型是"最大"的模型——它包含了所有可能的元素类型。


原子模型：模型 M 是原子的如果 M 中每个元组都实现一个孤立类型。原子模型是"最小"的模型——它只包含"必须存在"的元素。

超积与非标准分析
超积（Ultraproduct） 是模型论最强大的构造方法之一。给定一族结构 {Mᵢ}ᵢ∈I 和 I 上的超滤子 U，超积 ∏ᵢMᵢ/U 的论域是函数 f: I → ∪ᵢ|Mᵢ|（其中 f(i) ∈ |Mᵢ|）的等价类，等价关系为 f ∼ g 当且仅当 {i | f(i) = g(i)} ∈ U。


Łoś 定理：∏ᵢMᵢ/U ⊨ φ([f₁],...,[fₙ]) 当且仅当 {i | Mᵢ ⊨ φ(f₁(i),...,fₙ(i))} ∈ U。


当所有 Mᵢ = M 时，超积退化为超幂 M^I/U。Łoś 定理直接给出 M ≡ M^I/U（初等等价），但当 U 是非主超滤子时，M^I/U 通常与 M 不同构——它包含"非标准元素"。


非标准分析（Robinson，1966）正是基于超幂构造：取自然数 ℕ 的超幂 ℕ = ℕ^ω/U（ω 是自然数集，U 是非主超滤子），得到的ℕ 包含"无穷大自然数"。进一步构造 *ℝ 得到包含无穷小量的超实数域，使得微积分的 ε-δ 定义可以用无穷小量直接表述。


interface Ultrafilter<I> {
  contains: (set: Set<I>) => boolean;
}

function ultraproductSatisfies<I>(
  structures: Map<I, Structure>,
  ultrafilter: Ultrafilter<I>,
  formula: string,

    if (evaluateFormula(structure, formula, localElements)) {
      satisfyingIndices.add(i);
    }
  }

  return ultrafilter.contains(satisfyingIndices);
}

范畴性与 Morley 定理
范畴性是模型论分类理论的核心概念。理论 T 在基数 κ 上是范畴的（κ-categorical），如果 T 的所有基数为 κ 的模型都是同构的。


Morley 定理（1965）：如果可数一阶理论 T 在某个不可数基数 κ 上是范畴的，则 T 在所有不可数基数上都是范畴的。


这个定理极为深刻——它说明一阶理论的"确定性"要么在所有不可数基数上同时成立，要么都不成立。Morley 的证明引入了超越度和 Morley 秩等工具，开创了稳定性理论。

小结
    

  • 模型论研究形式语言与数学结构之间的关系，核心问题是理论的模型有哪些、它们的结构性质如何
    • 

  • 类型刻画了论域元素的所有可表达性质，饱和模型实现所有类型，原子模型只实现必要类型
    • 

  • 超积是模型论最强大的构造工具，Łoś 定理将语义从分量转移到超积，非标准分析是其标志性应用
    • 

  • Morley 定理表明不可数范畴性在所有不可数基数上同时成立，开创了现代分类理论
    • 

  • 模型论方法在数据库查询优化、程序语义和知识表示中有广泛的计算机科学应用
    •
