相继式演算

核心概念

相继式演算（Sequent Calculus）是 Gentzen 于 1934 年与自然演绎同时创立的另一种形式证明系统。与自然演绎的"假设→结论"单向推理不同，相继式演算以相继式（sequent）Γ ⊢ Δ 为基本推理单元，其中 Γ 是前提集（假设），Δ 是结论集（目标）。这种对称结构使得证明搜索更加系统化，是自动定理证明的理论基础。

相继式演算最深刻的成果是 Gentzen 的切消除定理（Hauptsatz，主定理）：任何使用切规则的证明都可以转换为不使用切规则的证明。切消除定理的推论——子公式性质——极大地约束了证明的结构，使得自底向上的证明搜索成为可能。这一结果奠定了结构证明论的基础，对自动推理、编程语言理论和逻辑程序设计产生了深远影响。

相继式与推理规则
一个相继式 Γ ⊢ Δ 的语义是：如果 Γ 中所有公式都为真，则 Δ 中至少有一个公式为真。经典相继式演算 LK 允许多结论（Δ 可包含多个公式），直觉主义相继式演算 LJ 限制结论最多一个公式。


公理和结构规则：


  ─────── Ax
  φ ⊢ φ

  Γ ⊢ Δ             Γ, φ, φ ⊢ Δ        Γ, φ, ψ ⊢ Δ
  ──────── WL        ──────────── CL      ──────────── XL
  Γ, φ ⊢ Δ          Γ, φ ⊢ Δ            Γ, ψ, φ ⊢ Δ
弱化（Weakening）允许添加不使用的假设，收缩（Contraction）允许合并重复假设，交换（Exchange）允许调整假设顺序。右侧也有对应的结构规则。


蕴含规则：


  Γ ⊢ φ, Δ    Γ, ψ ⊢ Δ           Γ, φ ⊢ ψ, Δ
  ────────────────────── →L        ──────────── →R
       Γ, φ → ψ ⊢ Δ              Γ ⊢ φ → ψ, Δ
→L 规则体现了蕴含在假设位置的使用方式：要使用 φ → ψ，需要提供 φ 的证明（左前提），然后 ψ 可用于推理（右前提）。→R 规则将假设 φ 移到左侧，在此假设下证明 ψ。


合取规则：


  Γ, φ ⊢ Δ          Γ, ψ ⊢ Δ          Γ ⊢ φ, Δ    Γ ⊢ ψ, Δ
  ──────── ∧L₁      ──────── ∧L₂       ──────────────────── ∧R
  Γ, φ∧ψ ⊢ Δ       Γ, φ∧ψ ⊢ Δ        Γ ⊢ φ ∧ ψ, Δ
析取规则：


  Γ, φ ⊢ Δ    Γ, ψ ⊢ Δ         Γ ⊢ φ, Δ          Γ ⊢ ψ, Δ
  ────────────────────── ∨L      ──────── ∨R₁       ──────── ∨R₂
       Γ, φ∨ψ ⊢ Δ              Γ ⊢ φ∨ψ, Δ        Γ ⊢ φ∨ψ, Δ
否定规则：


  Γ ⊢ φ, Δ          Γ, φ ⊢ Δ
  ──────── ¬L        ──────── ¬R
  Γ, ¬φ ⊢ Δ         Γ ⊢ ¬φ, Δ
否定规则展示了相继式演算的优雅之处：否定就是将公式从一侧移到另一侧。


type Sequent = {
  antecedent: string[];
  succedent: string[];
};

type ProofTree = { rule: 'axiom'; sequent: Sequent } | { rule: string; sequent: Sequent; premises: ProofTree[] };

function isAxiom(seq: Sequent): boolean {
  return seq.antecedent.some((a) => seq.succedent.includes(a));
}

function applyAndRight(seq: Sequent, formula: string): [Sequent, Sequent] | null {
  const match = formula.match(/^(.+) ∧ (.+)$/);
  if (!match) return null;
  const [, phi, psi] = match;
  const rest = seq.succedent.filter((f) => f !== formula);
  return [
    { antecedent: seq.antecedent, succedent: [phi, ...rest] },
    { antecedent: seq.antecedent, succedent: [psi, ...rest] },
  ];
}

function applyImpliesLeft(seq: Sequent, formula: string): [Sequent, Sequent] | null {
  const match = formula.match(/^(.+) → (.+)$/);
  if (!match) return null;
  const [, phi, psi] = match;
  const rest = seq.antecedent.filter((f) => f !== formula);
  return [
    { antecedent: rest, succedent: [phi, ...seq.succedent] },
    { antecedent: [psi, ...rest], succedent: seq.succedent },
  ];
}
切规则与切消除定理
切规则（Cut Rule）是相继式演算中最重要也最特殊的规则：


  Γ ⊢ φ, Δ    Γ', φ ⊢ Δ'
  ──────────────────────── Cut
       Γ, Γ' ⊢ Δ, Δ'
切规则允许引入一个"引理" φ：先证明 φ，然后使用 φ 证明目标。切规则对应于"使用引理"的推理模式——这在实际数学证明中无处不在。


切消除定理（Gentzen 的 Hauptsatz）：LK（和 LJ）中任何包含切规则的证明都可以转换为不使用切规则的证明。


切消除定理的证明采用双重归纳：对切公式的复杂度和切规则的应用高度进行归纳。核心思想是将切规则的使用逐步"推向上方"直到消失。


切消除定理的核心推论是子公式性质：在无切证明中，出现的每个公式都是结论或前提的子公式。这意味着：


    

  • 证明中不会出现"意外"的复杂公式
    • 

  • 自底向上的证明搜索只需考虑有限的公式集合
    • 

  • 一致性的语法证明：如果理论一致，则 ⊢ ⊥ 没有无切证明（因为 ⊥ 不是任何公式的子公式）
    •

证明搜索与自动推理
相继式演算的一个关键优势是其规则天然支持自底向上的证明搜索。给定目标相继式，逆向应用规则分解公式，直到所有分支都达到公理。


证明搜索的策略涉及几个关键决策：


规则选择：选择分解哪个公式、用哪条规则。对于无切的 LJ（直觉主义），结论最多一个公式，搜索更受控。


收缩处理：收缩规则可以重复使用假设，导致搜索空间无限。策略包括延迟收缩、循环检测、以及限制收缩深度。


聚焦（Focusing）：Andreoli（1992）提出的聚焦证明系统将规则分为异步（可自由交换）和同步（必须连续应用），大幅减少搜索空间中的冗余排列。


type SearchResult = { status: 'proved'; proof: ProofTree } | { status: 'failed' } | { status: 'unknown' };

function searchProof(seq: Sequent, depth: number): SearchResult {
  if (depth <= 0) return { status: 'unknown' };
  if (isAxiom(seq)) {
    return { status: 'proved', proof: { rule: 'axiom', sequent: seq, premises: [] } };
  }

  for (const formula of seq.succedent) {
    const rightRules = getRightRules(formula);
    for (const rule of rightRules) {
      const premises = rule.apply(seq, formula);
      if (premises) {
        const subproofs = premises.map((p: Sequent) => searchProof(p, depth - 1));
        if (subproofs.every((r: SearchResult) => r.status === 'proved')) {
          return {
            status: 'proved',
            proof: {
              rule: rule.name,
              sequent: seq,
              premises: subproofs.map((r: SearchResult) =>
                r.status === 'proved' ? r.proof : ({ rule: '?', sequent: seq, premises: [] } as ProofTree),
              ),
            },
          };
        }
      }
    }
  }

  for (const formula of seq.antecedent) {
    const leftRules = getLeftRules(formula);
    for (const rule of leftRules) {
      const premises = rule.apply(seq, formula);
      if (premises) {
        const subproofs = premises.map((p: Sequent) => searchProof(p, depth - 1));
        if (subproofs.every((r: SearchResult) => r.status === 'proved')) {
          return {
            status: 'proved',
            proof: {
              rule: rule.name,
              sequent: seq,
              premises: subproofs.map((r: SearchResult) =>
                r.status === 'proved' ? r.proof : ({ rule: '?', sequent: seq, premises: [] } as ProofTree),
              ),
            },
          };
        }
      }
    }
  }

  return { status: 'failed' };
}

interface Rule {
  name: string;
  apply: (seq: Sequent, formula: string) => Sequent[] | null;
}

function getRightRules(_formula: string): Rule[] {
  return [];
}

  return [];

逻辑程序设计（Prolog）的理论基础正是相继式演算的证明搜索。Horn 子句对应于特殊形式的相继式，SLD 消解对应于自底向上的规则应用，Prolog 的执行就是相继式演算中的证明搜索。


LK 与 LJ 的对比：经典与直觉主义
LK（经典相继式演算）与 LJ（直觉主义相继式演算）的核心差异在于结论的数量限制。


LK：相继式 Γ ⊢ Δ 允许 Δ 包含多个公式，语义为"如果所有 Γ 成立，则 Δ 中至少一个成立"。


LJ：相继式 Γ ⊢ φ 限制结论最多一个公式。这个限制精确地排除了排中律和双重否定消去。

LJ 的限制看似弱化了逻辑，实际上它赋予了证明更强的计算内容。在 LJ 中，∃xφ(x) 的证明必须提供具体的见证者 t 和 φ(t) 的证明——不存在"非构造性的存在证明"。这使得 LJ 成为程序提取和构造性数学的理论基础。


Glivenko 定理提供了 LK 和 LJ 的精确联系：经典命题逻辑 ⊢_LK φ 当且仅当直觉主义命题逻辑 ⊢_LJ ¬¬φ。这意味着经典逻辑可以通过双重否定翻译嵌入直觉主义逻辑。


小结
    

  • 相继式演算以 Γ ⊢ Δ 为基本推理单元，左右规则的对称结构使证明搜索更加系统化
    • 

  • 切消除定理（Hauptsatz）是证明论最重要的成果，其子公式性质为证明搜索提供了有界空间
    • 

  • 自底向上的证明搜索是自动定理证明和逻辑编程的理论基础
    • 

  • LK（经典）与 LJ（直觉主义）的核心差异在于结论数量——单结论限制排除了非构造性推理
    • 

  • 聚焦系统通过区分异步和同步规则大幅减少搜索冗余，是现代证明搜索的核心技术
    •
