绝对值与距离

核心概念

绝对值 ∣x∣|x|∣x∣ 表示实数 xxx 到原点的距离，是一个看似简单却内涵丰富的概念。它将"方向"信息去除，只保留"大小"。在编程中，绝对值的推广——距离度量——是搜索算法、聚类算法、误差分析和近似比较的基础。

绝对值的形式化定义：

∣x∣={xif x≥0−xif x<0|x| = \begin{cases} x & \text{if } x \geq 0 \\ -x & \text{if } x < 0 \end{cases}∣x∣={x−x​if x≥0if x<0​

等价定义：∣x∣=x2|x| = \sqrt{x^2}∣x∣=x2​，或 ∣x∣=max⁡(x,−x)|x| = \max(x, -x)∣x∣=max(x,−x)。

function solveAbsoluteEquation(f: (x: number) => number, a: number, solver: (target: number) => number[]): number[] {
  if (a < 0) return [];

function solveLinearAbsEquation(coeff: number, constant: number, rhs: number): number[] {
  if (rhs < 0) return [];
  if (coeff === 0) {
    return Math.abs(constant) === rhs ? [-Infinity] : [];
  }

  const results: number[] = [];
  const x1 = (rhs - constant) / coeff;
  const x2 = (-rhs - constant) / coeff;
  results.push(x1);
  if (rhs !== 0) results.push(x2);
  return results.sort((a, b) => a - b);
}

function solveMultiAbsEquation(
  breakpoints: number[],
  expressionInRegion: (region: number) => {
    coeffX: number;
    constant: number;
  },
  rhs: number,
): number[] {
  const sorted = [...breakpoints].sort((a, b) => a - b);
  const results: number[] = [];

  const regions = sorted.length + 1;
  for (let i = 0; i < regions; i++) {
    const { coeffX, constant } = expressionInRegion(i);
    if (coeffX === 0) {
      if (Math.abs(constant - rhs) < 1e-10) {
        continue;
      }
      continue;
    }

    const x = (rhs - constant) / coeffX;

    const lo = i === 0 ? -Infinity : sorted[i - 1];
    const hi = i === regions - 1 ? Infinity : sorted[i];

    if (x >= lo - 1e-10 && x <= hi + 1e-10) {
      results.push(x);
    }
  }

  return results;
}
绝对值不等式
绝对值不等式有两种基本形式：


∣f(x)∣<a|f(x)| < a∣f(x)∣<a（a>0a > 0a>0）：等价于 −a<f(x)<a-a < f(x) < a−a<f(x)<a（"夹逼"形式）


∣f(x)∣>a|f(x)| > a∣f(x)∣>a（a≥0a \geq 0a≥0）：等价于 f(x)>af(x) > af(x)>a 或 f(x)<−af(x) < -af(x)<−a（"外扩"形式）


记忆口诀："小于取中间，大于取两边"。


function solveAbsInequality(
  innerCoeff: number,
  innerConst: number,
  bound: number,
  type: '<' | '<=' | '>' | '>=',
): Interval[] {
  if (type === '<' || type === '<=') {
    if (bound < 0) return [];
    if (bound === 0 && type === '<') return [];

    const inclusive = type === '<=';
    const lower = (-bound - innerConst) / innerCoeff;
    const upper = (bound - innerConst) / innerCoeff;

    if (innerCoeff > 0) {
      return [
        {
          lower: Math.min(lower, upper),
          upper: Math.max(lower, upper),
          lowerInclusive: inclusive,
          upperInclusive: inclusive,
        },
      ];
    }
    return [
      {
        lower: Math.min(lower, upper),
        upper: Math.max(lower, upper),
        lowerInclusive: inclusive,
        upperInclusive: inclusive,
      },
    ];
  }

  if (bound < 0) {
    return [
      {
        lower: -Infinity,
        upper: Infinity,
        lowerInclusive: false,
        upperInclusive: false,
      },
    ];
  }

  const inclusive = type === '>=';
  const x1 = (-bound - innerConst) / innerCoeff;
  const x2 = (bound - innerConst) / innerCoeff;
  const lo = Math.min(x1, x2);
  const hi = Math.max(x1, x2);

  return [
    { lower: -Infinity, upper: lo, lowerInclusive: false, upperInclusive: inclusive },
    { lower: hi, upper: Infinity, lowerInclusive: inclusive, upperInclusive: false },
  ];
}
三角不等式的推论——反三角不等式：


∣∣x∣−∣y∣∣≤∣x−y∣\big||x| - |y|\big| \leq |x - y|​∣x∣−∣y∣​≤∣x−y∣
这告诉我们：两个数绝对值之差不超过它们差的绝对值。在误差分析中经常使用。


距离度量与范数
绝对值的推广是范数（norm），它将"距离"的概念从一维扩展到多维空间。


LpL^pLp 范数：∥x∥p=(∑i=1n∣xi∣p)1/p\|\mathbf{x}\|_p = \left(\sum_{i=1}^n |x_i|^p\right)^{1/p}∥x∥p​=(∑i=1n​∣xi​∣p)1/p


function lpNorm(x: number[], p: number): number {
  if (p === Infinity) {
    return Math.max(...x.map(Math.abs));
  }
  return Math.pow(
    x.reduce((sum, xi) => sum + Math.pow(Math.abs(xi), p), 0),
    1 / p,
  );
}

function lpDistance(a: number[], b: number[], p: number): number {
  const diff = a.map((ai, i) => ai - b[i]);
  return lpNorm(diff, p);
}

function manhattanDistance(a: number[], b: number[]): number {
  return a.reduce((sum, ai, i) => sum + Math.abs(ai - b[i]), 0);
}

function euclideanDistance(a: number[], b: number[]): number {
  return Math.sqrt(a.reduce((sum, ai, i) => sum + (ai - b[i]) ** 2, 0));
}

function chebyshevDistance(a: number[], b: number[]): number {
  return Math.max(...a.map((ai, i) => Math.abs(ai - b[i])));
}

绝对值在误差分析中的应用
浮点数比较是编程中的经典问题。由于浮点运算的舍入误差，直接用 === 比较两个浮点数是不可靠的。


绝对误差：∣xcomputed−xexact∣|x_{\text{computed}} - x_{\text{exact}}|∣xcomputed​−xexact​∣


相对误差：∣xcomputed−xexact∣∣xexact∣\frac{|x_{\text{computed}} - x_{\text{exact}}|}{|x_{\text{exact}}|}∣xexact​∣∣xcomputed​−xexact​∣​


function absoluteError(computed: number, exact: number): number {
  return Math.abs(computed - exact);
}

function relativeError(computed: number, exact: number): number {
  if (exact === 0) return computed === 0 ? 0 : Infinity;
  return Math.abs(computed - exact) / Math.abs(exact);
}

function nearlyEqual(
  a: number,
  b: number,
  absoluteTolerance: number = 1e-12,
  relativeTolerance: number = 1e-9,
): boolean {
  if (a === b) return true;
  const diff = Math.abs(a - b);
  if (diff <= absoluteTolerance) return true;
  const maxAbs = Math.max(Math.abs(a), Math.abs(b));
  return diff <= relativeTolerance * maxAbs;
}

function withinUlps(a: number, b: number, maxUlps: number): boolean {
  const buffer = new ArrayBuffer(8);
  const floatView = new Float64Array(buffer);
  const intView = new BigInt64Array(buffer);

  floatView[0] = a;
  const aBits = intView[0];
  floatView[0] = b;
  const bBits = intView[0];

  if (aBits < 0n !== bBits < 0n) return a === b;

  const ulpDiff = aBits > bBits ? aBits - bBits : bBits - aBits;
  return ulpDiff <= BigInt(maxUlps);
}
ULP（Unit in the Last Place）比较是最精确的浮点比较方法。它直接比较两个浮点数在二进制表示中的"距离"——相差几个最小可表示单位。

小结
    

  • 绝对值 ∣x∣|x|∣x∣ 表示到原点的距离，满足非负性、正定性、对称性和三角不等式
    • 

  • 绝对值方程通过去绝对值分类讨论求解，含多个绝对值时需根据临界点分段
    • 

  • 绝对值不等式的核心规则："小于取中间 −a<f(x)<a-a < f(x) < a−a<f(x)<a"，"大于取两边"
    • 

  • 绝对值的推广——LpL^pLp 范数——是多维空间中距离度量的基础
    • 

  • 曼哈顿距离（L1L^1L1）、欧几里得距离（L2L^2L2）、切比雪夫距离（L∞L^\inftyL∞）各有适用场景
    • 

  • 浮点比较应使用绝对/相对混合容差或 ULP 比较，避免直接 ===
    • 

  • 三角不等式是距离度量的核心性质，保证了空间搜索算法的正确性
