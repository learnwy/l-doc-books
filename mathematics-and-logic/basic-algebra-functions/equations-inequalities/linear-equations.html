一次方程与方程组

核心概念

一次方程（线性方程）是代数中最基本的方程类型，其核心形式为 ax+b=0ax + b = 0ax+b=0（单变量）或 a1x1+a2x2+⋯+anxn=ba_1x_1 + a_2x_2 + \cdots + a_nx_n = ba1​x1​+a2​x2​+⋯+an​xn​=b（多变量）。线性方程组则是多个线性方程的联立，其求解是线性代数的核心问题，也是几乎所有科学计算的基石。

对程序员而言，线性方程组无处不在：网络流量分析、电路模拟、3D 图形变换、最小二乘拟合、PageRank 算法——底层都是在解线性方程组。

单变量线性方程
单变量线性方程 ax+b=0ax + b = 0ax+b=0 的解为 x=−b/ax = -b/ax=−b/a（a≠0a \neq 0a=0）。虽然看似简单，但它包含了方程求解的核心思想——通过等价变换将未知数隔离。


function solveLinear(a: number, b: number): number | null | 'infinite' {
  if (a === 0) {
    return b === 0 ? 'infinite' : null;
  }
  return -b / a;
}

function solveLinearEquation(
  leftCoeffs: Map<string, number>,
  leftConst: number,
  rightCoeffs: Map<string, number>,
  rightConst: number,
): number | null {
  let netCoeff = 0;
  let netConst = rightConst - leftConst;

  for (const [variable, coeff] of leftCoeffs) {
    netCoeff += coeff;
  }
  for (const [variable, coeff] of rightCoeffs) {
    netCoeff -= coeff;
  }

  if (netCoeff === 0) return null;
  return netConst / netCoeff;
}
应用：线性插值逆问题——已知 yyy，反求 xxx：


给定 y=ax+by = ax + by=ax+b，则 x=(y−b)/ax = (y - b)/ax=(y−b)/a。这在动画系统中用于"给定目标值，反算所需的参数"。


二元一次方程组与矩阵表示
二元一次方程组： 


{a1x+b1y=c1a2x+b2y=c2\begin{cases} a_1x + b_1y = c_1 \\ a_2x + b_2y = c_2 \end{cases}{a1​x+b1​y=c1​a2​x+b2​y=c2​​
可以用矩阵形式表示为 Ax=bA\mathbf{x} = \mathbf{b}Ax=b：


(a1b1a2b2)(xy)=(c1c2)\begin{pmatrix} a_1 & b_1 \\ a_2 & b_2 \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} c_1 \\ c_2 \end{pmatrix}(a1​a2​​b1​b2​​)(xy​)=(c1​c2​​)
方程组的解取决于系数矩阵的行列式 det⁡(A)=a1b2−a2b1\det(A) = a_1b_2 - a_2b_1det(A)=a1​b2​−a2​b1​：


    

  • det⁡(A)≠0\det(A) \neq 0det(A)=0：唯一解
    • 

  • det⁡(A)=0\det(A) = 0det(A)=0 且方程相容：无穷多解
    • 

  • det⁡(A)=0\det(A) = 0det(A)=0 且方程不相容：无解
    • 



type Matrix2x2 = [[number, number], [number, number]];
type Vector2 = [number, number];

function determinant2x2(m: Matrix2x2): number {
  return m[0][0] * m[1][1] - m[0][1] * m[1][0];
}

function solve2x2(
  a: Matrix2x2,
  b: Vector2,
): { type: 'unique'; x: number; y: number } | { type: 'infinite' } | { type: 'none' } {
  const det = determinant2x2(a);

  if (Math.abs(det) < 1e-12) {
    const ratio1 = a[0][1] !== 0 ? b[0] / a[0][1] : Infinity;
    const ratio2 = a[1][1] !== 0 ? b[1] / a[1][1] : Infinity;
    if (Math.abs(ratio1 - ratio2) < 1e-12) return { type: 'infinite' };
    return { type: 'none' };
  }

  const x = (b[0] * a[1][1] - b[1] * a[0][1]) / det;
  const y = (a[0][0] * b[1] - a[1][0] * b[0]) / det;
  return { type: 'unique', x, y };
}
高斯消元法
高斯消元法是求解一般线性方程组的标准算法。其核心思想是通过行变换将增广矩阵化为行阶梯形（上三角），然后回代求解。


算法步骤：


    

  1. 构建增广矩阵 [A∣b][A | b][A∣b]
    2. 

  2. 前向消元：逐列消去主对角线以下的元素
    3. 

  3. 回代：从最后一行开始，逐行求解
    4. 



function gaussianElimination(matrix: number[][], rhs: number[]): number[] | null {
  const n = matrix.length;
  const aug: number[][] = matrix.map((row, i) => [...row, rhs[i]]);

  for (let col = 0; col < n; col++) {
    let maxRow = col;
    for (let row = col + 1; row < n; row++) {
      if (Math.abs(aug[row][col]) > Math.abs(aug[maxRow][col])) {
        maxRow = row;
      }
    }
    [aug[col], aug[maxRow]] = [aug[maxRow], aug[col]];

    if (Math.abs(aug[col][col]) < 1e-12) return null;

    for (let row = col + 1; row < n; row++) {
      const factor = aug[row][col] / aug[col][col];
      for (let j = col; j <= n; j++) {
        aug[row][j] -= factor * aug[col][j];
      }
    }
  }

  const solution = new Array(n).fill(0);
  for (let row = n - 1; row >= 0; row--) {
    let sum = aug[row][n];
    for (let j = row + 1; j < n; j++) {
      sum -= aug[row][j] * solution[j];
    }
    solution[row] = sum / aug[row][row];
  }

  return solution;
}
列主元选取（Partial Pivoting）——上面代码中的 maxRow 搜索就是列主元选取。这一步至关重要：如果主元（pivot）很小，除法会放大舍入误差，导致数值不稳定。选择绝对值最大的元素作为主元，可以大大改善稳定性。

矩阵的秩与解的结构
线性方程组 Ax=bA\mathbf{x} = \mathbf{b}Ax=b 的解的结构由矩阵的秩（rank）决定。秩是矩阵中线性无关的行（或列）的最大数目。


设 AAA 为 m×nm \times nm×n 矩阵，增广矩阵为 [A∣b][A|b][A∣b]：


    

  • rank(A)=rank([A∣b])=n\text{rank}(A) = \text{rank}([A|b]) = nrank(A)=rank([A∣b])=n：唯一解
    • 

  • rank(A)=rank([A∣b])<n\text{rank}(A) = \text{rank}([A|b]) < nrank(A)=rank([A∣b])<n：无穷多解（自由变量个数 = n−rank(A)n - \text{rank}(A)n−rank(A)）
    • 

  • rank(A)<rank([A∣b])\text{rank}(A) < \text{rank}([A|b])rank(A)<rank([A∣b])：无解
    • 



function matrixRank(matrix: number[][], epsilon = 1e-10): number {
  const m = matrix.length;
  if (m === 0) return 0;
  const n = matrix[0].length;
  const aug = matrix.map((row) => [...row]);

  let rank = 0;
  for (let col = 0; col < n && rank < m; col++) {
    let maxRow = rank;
    for (let row = rank + 1; row < m; row++) {
      if (Math.abs(aug[row][col]) > Math.abs(aug[maxRow][col])) {
        maxRow = row;
      }
    }

    if (Math.abs(aug[maxRow][col]) < epsilon) continue;

    [aug[rank], aug[maxRow]] = [aug[maxRow], aug[rank]];

    for (let row = rank + 1; row < m; row++) {
      const factor = aug[row][col] / aug[rank][col];
      for (let j = col; j < n; j++) {
        aug[row][j] -= factor * aug[rank][j];
      }
    }
    rank++;
  }

  return rank;
}

function analyzeSolution(A: number[][], b: number[]): 'unique' | 'infinite' | 'none' {
  const m = A.length;
  const n = A[0].length;
  const augmented = A.map((row, i) => [...row, b[i]]);

  const rankA = matrixRank(A);
  const rankAug = matrixRank(augmented);

  if (rankA < rankAug) return 'none';
  if (rankA === n) return 'unique';
  return 'infinite';
}
线性方程组的编程应用
应用一：网页布局约束求解——CSS Flexbox 和 Constraint Layout 底层都在解线性约束系统。


应用二：线性回归——最小二乘法的正规方程 ATAx=ATbA^T A \mathbf{x} = A^T \mathbf{b}ATAx=ATb 就是一个线性方程组。


function linearRegression(points: Array<{ x: number; y: number }>): { slope: number; intercept: number } {
  const n = points.length;
  let sumX = 0,
    sumY = 0,
    sumXY = 0,
    sumX2 = 0;

  for (const { x, y } of points) {
    sumX += x;
    sumY += y;
    sumXY += x * y;
    sumX2 += x * x;
  }

  const det = n * sumX2 - sumX * sumX;
  if (Math.abs(det) < 1e-12) {
    throw new Error('Singular system: points are collinear in x');
  }

  const slope = (n * sumXY - sumX * sumY) / det;
  const intercept = (sumY * sumX2 - sumX * sumXY) / det;
  return { slope, intercept };
}
应用三：Markov 链稳态分布——πA=π\pi A = \piπA=π 加上 ∑πi=1\sum \pi_i = 1∑πi​=1 构成线性方程组。


function stationaryDistribution(transitionMatrix: number[][]): number[] {
  const n = transitionMatrix.length;
  const A: number[][] = [];
  const b: number[] = [];

  for (let j = 0; j < n - 1; j++) {
    const row: number[] = [];
    for (let i = 0; i < n; i++) {
      row.push(transitionMatrix[i][j] - (i === j ? 1 : 0));
    }
    A.push(row);
    b.push(0);
  }

  A.push(new Array(n).fill(1));
  b.push(1);

  return gaussianElimination(A, b) ?? [];
}
小结
    

  • 线性方程 ax+b=0ax + b = 0ax+b=0 是方程求解的基本形式，其解法（隔离未知数）是所有方程求解的思想基础
    • 

  • 线性方程组 Ax=bA\mathbf{x} = \mathbf{b}Ax=b 的矩阵表示是线性代数与编程的桥梁
    • 

  • 高斯消元法时间复杂度为 O(n3)O(n^3)O(n3)，列主元选取对数值稳定性至关重要
    • 

  • 矩阵的秩决定解的结构：唯一解、无穷多解或无解
    • 

  • 线性方程组在线性回归、约束求解、Markov 链分析等编程场景中有广泛应用
    • 

  • 对于大规模稀疏系统，迭代法（Jacobi、Gauss-Seidel）比直接法更高效
    • 

  • 实际编程中应使用成熟的线性代数库（如 LAPACK），避免自行实现数值敏感算法
    •
