不等式求解

核心概念

不等式描述的是量之间的大小关系，而非精确相等。在编程中，不等式无处不在：边界检查（if (index >= 0 && index < array.length)）、约束优化（线性规划）、算法复杂度分析（T(n)≤cnlog⁡nT(n) \leq cn\log nT(n)≤cnlogn）。

与方程的"点解"不同，不等式的解通常是区间或区间的并集。求解不等式的核心技巧是符号分析法——确定表达式在各个区间上的正负号。

| 一次不等式   | ax+b>0ax + b > 0ax+b>0            | 单个区间   | 注意 a<0a < 0a<0 时变号 |
| 二次不等式   | ax2+bx+c>0ax^2+bx+c > 0ax2+bx+c>0         | 0-2 个区间 | 判别式 + 抛物线开口 |
| 分式不等式   | P(x)Q(x)>0\frac{P(x)}{Q(x)} > 0Q(x)P(x)​>0 | 多个区间   | 零点 + 不连续点分区 |
| 绝对值不等式 | ∣f(x)∣<a| f(x)       | < a∣f(x)∣<a                | 等价转化 | 分 a>0a > 0a>0 和 a≤0a \leq 0a≤0 |


一次不等式与变号规则
一次不等式 ax+b>0ax + b > 0ax+b>0 的解法看似简单，但其中隐含一个关键规则：乘以或除以负数时，不等号方向反转。


type Interval = {
  lower: number;
  upper: number;
  lowerInclusive: boolean;
  upperInclusive: boolean;
};

function solveLinearInequality(a: number, b: number, type: '>' | '>=' | '<' | '<='): Interval | null | 'all' {
  if (a === 0) {
    const holds = type === '>' ? b > 0 : type === '>=' ? b >= 0 : type === '<' ? b < 0 : b <= 0;
    return holds ? 'all' : null;
  }

  const boundary = -b / a;
  const strict = type === '>' || type === '<';
  const flipped = a < 0;

  const isGreater = (type === '>' || type === '>=') !== flipped;

  if (isGreater) {
    return {
      lower: boundary,
      upper: Infinity,
      lowerInclusive: !strict,
      upperInclusive: false,
    };
  }
  return {
    lower: -Infinity,
    upper: boundary,
    lowerInclusive: false,
    upperInclusive: !strict,
  };
}

{2x+3>7x−1≤5\begin{cases} 2x + 3 > 7 \\ x - 1 \leq 5 \end{cases}{2x+3>7x−1≤5​
解法：分别求解后取交集。第一个不等式解为 x>2x > 2x>2，第二个解为 x≤6x \leq 6x≤6，交集为 (2,6](2, 6](2,6]。


function intersectIntervals(a: Interval, b: Interval): Interval | null {
  const lower = Math.max(a.lower, b.lower);
  const upper = Math.min(a.upper, b.upper);

  if (lower > upper) return null;

  const lowerInclusive =
    lower === a.lower && lower === b.lower
      ? a.lowerInclusive && b.lowerInclusive
      : lower === a.lower
        ? a.lowerInclusive
        : b.lowerInclusive;

  const upperInclusive =
    upper === a.upper && upper === b.upper
      ? a.upperInclusive && b.upperInclusive
      : upper === a.upper
        ? a.upperInclusive
        : b.upperInclusive;

  if (lower === upper && !lowerInclusive && !upperInclusive) return null;

  return { lower, upper, lowerInclusive, upperInclusive };
}

function solveQuadraticInequality(a: number, b: number, c: number, type: '>' | '>=' | '<' | '<='): Interval[] {
  if (a === 0) {
    const result = solveLinearInequality(b, c, type);
    if (result === 'all') return [{ lower: -Infinity, upper: Infinity, lowerInclusive: false, upperInclusive: false }];
    if (result === null) return [];
    return [result];
  }

  const discriminant = b * b - 4 * a * c;
  const strict = type === '>' || type === '<';
  const wantPositive = type === '>' || type === '>=';

  if (discriminant < 0) {
    const alwaysPositive = a > 0;
    if (wantPositive === alwaysPositive) {
      return [{ lower: -Infinity, upper: Infinity, lowerInclusive: false, upperInclusive: false }];
    }
    if (!strict && wantPositive !== alwaysPositive) return [];
    return [];
  }

  const sqrtD = Math.sqrt(Math.max(0, discriminant));
  const r1 = (-b - sqrtD) / (2 * a);
  const r2 = (-b + sqrtD) / (2 * a);
  const [lo, hi] = r1 <= r2 ? [r1, r2] : [r2, r1];

  const include = !strict;

  if (a > 0 && wantPositive) {
    if (discriminant === 0) {
      return [
        { lower: -Infinity, upper: lo, lowerInclusive: false, upperInclusive: include },
        { lower: hi, upper: Infinity, lowerInclusive: include, upperInclusive: false },
      ];
    }
    return [
      { lower: -Infinity, upper: lo, lowerInclusive: false, upperInclusive: include },
      { lower: hi, upper: Infinity, lowerInclusive: include, upperInclusive: false },
    ];
  }

  if (a > 0 && !wantPositive) {
    return [{ lower: lo, upper: hi, lowerInclusive: include, upperInclusive: include }];
  }

  if (a < 0 && wantPositive) {
    return [{ lower: lo, upper: hi, lowerInclusive: include, upperInclusive: include }];
  }

  return [
    { lower: -Infinity, upper: lo, lowerInclusive: false, upperInclusive: include },
    { lower: hi, upper: Infinity, lowerInclusive: include, upperInclusive: false },
  ];
}
符号分析法（Sign Chart Method）
符号分析法是求解高次不等式和分式不等式的通用方法。核心步骤：


    

  1. 将不等式变为 f(x)>0f(x) > 0f(x)>0（或 ≥,<,≤\geq, <, \leq≥,<,≤）的形式
    2. 

  2. 找出 f(x)f(x)f(x) 的所有零点和不连续点（临界点）
    3. 

  3. 将数轴分成若干区间
    4. 

  4. 在每个区间中取测试点，确定 f(x)f(x)f(x) 的符号
    5. 

  5. 根据不等式方向选择满足条件的区间
    6. 



function signChart(
  zeros: number[],
  discontinuities: number[],
  evaluate: (x: number) => number,
): Array<{
  interval: Interval;
  sign: 'positive' | 'negative' | 'zero';
}> {
  const criticalPoints = [...new Set([...zeros, ...discontinuities])].sort((a, b) => a - b);

  const result: Array<{
    interval: Interval;
    sign: 'positive' | 'negative' | 'zero';
  }> = [];

  const testPoints: number[] = [];
  if (criticalPoints.length === 0) {
    testPoints.push(0);
  } else {
    testPoints.push(criticalPoints[0] - 1);
    for (let i = 0; i < criticalPoints.length - 1; i++) {
      testPoints.push((criticalPoints[i] + criticalPoints[i + 1]) / 2);
    }
    testPoints.push(criticalPoints[criticalPoints.length - 1] + 1);
  }

  const boundaries = [-Infinity, ...criticalPoints, Infinity];

  for (let i = 0; i < testPoints.length; i++) {
    const val = evaluate(testPoints[i]);
    const sign = val > 0 ? 'positive' : val < 0 ? 'negative' : 'zero';

    const isDiscLower = discontinuities.includes(boundaries[i]);
    const isDiscUpper = discontinuities.includes(boundaries[i + 1]);

    result.push({
      interval: {
        lower: boundaries[i],
        upper: boundaries[i + 1],
        lowerInclusive: !isDiscLower && boundaries[i] !== -Infinity,
        upperInclusive: !isDiscUpper && boundaries[i + 1] !== Infinity,
      },
      sign,
    });
  }

  return result;
}
分式不等式
分式不等式 P(x)Q(x)>0\frac{P(x)}{Q(x)} > 0Q(x)P(x)​>0 的求解关键是：分子分母同时为正或同时为负。


注意：不能直接乘以分母消去（因为分母的符号未知），必须使用符号分析法。


function solveRationalInequality(
  numeratorRoots: number[],
  denominatorRoots: number[],
  type: '>' | '>=' | '<' | '<=',
  evaluateNumerator: (x: number) => number,
  evaluateDenominator: (x: number) => number,
): Interval[] {
  const evaluate = (x: number) => {
    const d = evaluateDenominator(x);
    if (Math.abs(d) < 1e-15) return NaN;
    return evaluateNumerator(x) / d;
  };

  const chart = signChart(numeratorRoots, denominatorRoots, evaluate);

  const wantPositive = type === '>' || type === '>=';
  const includeZero = type === '>=' || type === '<=';

  const intervals: Interval[] = [];
  for (const entry of chart) {
    const match = wantPositive ? entry.sign === 'positive' : entry.sign === 'negative';

    if (match) {
      intervals.push(entry.interval);
    }
  }

  if (includeZero) {
    for (const root of numeratorRoots) {
      if (!denominatorRoots.includes(root)) {
        intervals.push({
          lower: root,
          upper: root,
          lowerInclusive: true,
          upperInclusive: true,
        });
      }
    }
  }

  return mergeIntervals(intervals);
}

function mergeIntervals(intervals: Interval[]): Interval[] {
  if (intervals.length <= 1) return intervals;
  const sorted = [...intervals].sort((a, b) => a.lower - b.lower);
  const result: Interval[] = [sorted[0]];

  for (let i = 1; i < sorted.length; i++) {
    const last = result[result.length - 1];
    const curr = sorted[i];
    if (curr.lower <= last.upper) {
      last.upper = Math.max(last.upper, curr.upper);
      last.upperInclusive = curr.upper > last.upper ? curr.upperInclusive : last.upperInclusive || curr.upperInclusive;
    } else {
      result.push(curr);
    }
  }
  return result;
}

不等式在算法分析中的应用
不等式是算法复杂度分析的核心工具。几个关键不等式：


AM-GM 不等式（算术平均 ≥ 几何平均）：


a+b2≥ab(a,b≥0)\frac{a + b}{2} \geq \sqrt{ab} \quad (a, b \geq 0)2a+b​≥ab​(a,b≥0)
Cauchy-Schwarz 不等式：


(∑aibi)2≤(∑ai2)(∑bi2)\left(\sum a_i b_i\right)^2 \leq \left(\sum a_i^2\right)\left(\sum b_i^2\right)(∑ai​bi​)2≤(∑ai2​)(∑bi2​)
function amGmVerify(values: number[]): {
  am: number;
  gm: number;
  holds: boolean;
} {
  const n = values.length;
  const am = values.reduce((s, v) => s + v, 0) / n;
  const gm = Math.pow(
    values.reduce((p, v) => p * v, 1),
    1 / n,
  );
  return { am, gm, holds: am >= gm - 1e-10 };
}

function cauchySchwarz(a: number[], b: number[]): { lhs: number; rhs: number; holds: boolean } {
  const dot = a.reduce((s, ai, i) => s + ai * b[i], 0);
  const normA = Math.sqrt(a.reduce((s, ai) => s + ai * ai, 0));
  const normB = Math.sqrt(b.reduce((s, bi) => s + bi * bi, 0));
  const lhs = dot * dot;
  const rhs = normA * normA * normB * normB;
  return { lhs, rhs, holds: lhs <= rhs + 1e-10 };
}
这些不等式在证明算法下界、优化数据结构性能时经常使用。


小结
    

  • 不等式的解是区间或区间的并集，而非离散的点
    • 

  • 一次不等式求解的核心规则：乘/除负数时不等号反向
    • 

  • 二次不等式的解取决于开口方向和判别式的组合
    • 

  • 符号分析法是高次和分式不等式的通用求解框架：找临界点 → 分区间 → 检验符号
    • 

  • 分式不等式不能直接乘分母，必须使用符号分析法，且分母零点必须排除
    • 

  • AM-GM、Cauchy-Schwarz 等经典不等式是算法分析和优化的核心工具
    • 

  • 编程中的边界检查、约束满足、区间运算都直接依赖不等式理论
