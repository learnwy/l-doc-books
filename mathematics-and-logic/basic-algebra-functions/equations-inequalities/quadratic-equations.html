二次方程

核心概念

二次方程 ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0（a≠0a \neq 0a=0）是代数中研究最深入的方程类型。它的求根公式 x=−b±b2−4ac2ax = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}x=2a−b±b2−4ac​​ 可能是数学史上最著名的公式之一。对程序员来说，二次方程出现在物理模拟（抛体运动、碰撞检测）、优化问题（二次规划）和图形学（光线与曲面求交）中。

理解二次方程不只是套公式——关键在于掌握判别式分析、配方法的推导思想，以及数值计算中的稳定性问题。

配方法与求根公式的推导
配方法（Completing the Square）是二次方程理论的核心。求根公式正是通过配方法推导出来的。

interface QuadraticResult {
  discriminant: number;
  roots: number[];
  vertex: { x: number; y: number };
}

function solveQuadratic(a: number, b: number, c: number): QuadraticResult {
  if (a === 0) throw new Error('Not a quadratic equation (a = 0)');

  const discriminant = b * b - 4 * a * c;
  const vertexX = -b / (2 * a);
  const vertexY = c - (b * b) / (4 * a);

  let roots: number[];
  if (discriminant > 0) {
    const sqrtD = Math.sqrt(discriminant);
    roots = [(-b + sqrtD) / (2 * a), (-b - sqrtD) / (2 * a)];
  } else if (discriminant === 0) {
    roots = [vertexX];
  } else {
    roots = [];
  }

  return {
    discriminant,
    roots,
    vertex: { x: vertexX, y: vertexY },
  };
}
判别式的深层含义
判别式 Δ=b2−4ac\Delta = b^2 - 4acΔ=b2−4ac 不仅决定根的个数，还蕴含着丰富的几何和代数信息。


几何意义：Δ\DeltaΔ 正比于抛物线顶点到 xxx 轴的"距离"。


代数意义：Δ=a2(r1−r2)2\Delta = a^2(r_1 - r_2)^2Δ=a2(r1​−r2​)2，即 Δ\DeltaΔ 是两根之差的平方乘以 a2a^2a2。当 Δ=0\Delta = 0Δ=0 时两根重合。


function classifyQuadratic(
  a: number,
  b: number,
  c: number,
): {
  rootType: 'real_distinct' | 'real_repeated' | 'complex';
  signBehavior: 'always_positive' | 'always_negative' | 'changes_sign' | 'touches_zero';
} {
  const discriminant = b * b - 4 * a * c;

  let rootType: 'real_distinct' | 'real_repeated' | 'complex';
  if (discriminant > 1e-10) rootType = 'real_distinct';
  else if (discriminant < -1e-10) rootType = 'complex';
  else rootType = 'real_repeated';

  let signBehavior: 'always_positive' | 'always_negative' | 'changes_sign' | 'touches_zero';
  if (rootType === 'complex') {
    signBehavior = a > 0 ? 'always_positive' : 'always_negative';
  } else if (rootType === 'real_repeated') {
    signBehavior = 'touches_zero';
  } else {
    signBehavior = 'changes_sign';
  }

  return { rootType, signBehavior };
}

interface Vector3 {
  x: number;
  y: number;
  z: number;
}

function dot(a: Vector3, b: Vector3): number {
  return a.x * b.x + a.y * b.y + a.z * b.z;
}

function subtract(a: Vector3, b: Vector3): Vector3 {
  return { x: a.x - b.x, y: a.y - b.y, z: a.z - b.z };
}

function raySphereIntersection(origin: Vector3, direction: Vector3, center: Vector3, radius: number): number[] {
  const oc = subtract(origin, center);
  const a = dot(direction, direction);
  const b = 2 * dot(oc, direction);
  const c = dot(oc, oc) - radius * radius;
  const discriminant = b * b - 4 * a * c;

  if (discriminant < 0) return [];
  if (discriminant === 0) return [-b / (2 * a)];

  const sqrtD = Math.sqrt(discriminant);
  return [(-b - sqrtD) / (2 * a), (-b + sqrtD) / (2 * a)];
}
韦达定理与根的关系
韦达定理（Vieta's Formulas）建立了根与系数之间的直接关系：


r1+r2=−ba,r1⋅r2=car_1 + r_2 = -\frac{b}{a}, \quad r_1 \cdot r_2 = \frac{c}{a}r1​+r2​=−ab​,r1​⋅r2​=ac​
这些关系的价值在于：不需要实际求根，就能获取根的某些属性。


function constructFromRoots(r1: number, r2: number, leadCoeff: number = 1): { a: number; b: number; c: number } {
  return {
    a: leadCoeff,
    b: -leadCoeff * (r1 + r2),
    c: leadCoeff * r1 * r2,
  };
}

function rootProperties(
  a: number,
  b: number,
  c: number,
): {
  sum: number;
  product: number;
  sumOfSquares: number;
  differenceSquared: number;
} {
  const sum = -b / a;
  const product = c / a;
  return {
    sum,
    product,
    sumOfSquares: sum * sum - 2 * product,
    differenceSquared: sum * sum - 4 * product,
  };
}

数值稳定的求根算法
标准求根公式在某些情况下会产生严重的灾难性消去（catastrophic cancellation）。当 b2≫4acb^2 \gg 4acb2≫4ac 时，b2−4ac≈∣b∣\sqrt{b^2 - 4ac} \approx |b|b2−4ac​≈∣b∣，使得 −b+Δ-b + \sqrt{\Delta}−b+Δ​ 或 −b−Δ-b - \sqrt{\Delta}−b−Δ​ 中有一个接近于零（两个大数相减），精度大幅下降。


function stableQuadraticSolver(a: number, b: number, c: number): number[] {
  if (Math.abs(a) < 1e-15) {
    if (Math.abs(b) < 1e-15) return [];
    return [-c / b];
  }

  const discriminant = b * b - 4 * a * c;
  if (discriminant < 0) return [];

  const sqrtD = Math.sqrt(discriminant);
  const q = -0.5 * (b + Math.sign(b) * sqrtD);

  const r1 = q / a;
  const r2 = c / q;

  if (discriminant === 0) return [r1];
  return r1 < r2 ? [r1, r2] : [r2, r1];
}

function compareStability(): void {
  const a = 1;
  const b = -1e8;
  const c = 1;

  const naive1 = (-b + Math.sqrt(b * b - 4 * a * c)) / (2 * a);
  const naive2 = (-b - Math.sqrt(b * b - 4 * a * c)) / (2 * a);

  const stable = stableQuadraticSolver(a, b, c);

  const exact1 = (b * b) / (4 * a * a) > 0 ? 1e8 : 0;
  const exact2 = c / (a * exact1);

  console.log(`Naive: [${naive1}, ${naive2}]`);
  console.log(`Stable: [${stable[0]}, ${stable[1]}]`);
}
稳定算法的关键：先计算绝对值较大的根（−b-b−b 和 Δ\sqrt{\Delta}Δ​ 符号相同的那个），再用韦达定理 r2=c/(a⋅r1)r_2 = c/(a \cdot r_1)r2​=c/(a⋅r1​) 计算另一个根。这避免了两个大数相减。


二次方程在物理模拟中的应用
抛体运动的位置方程 h(t)=h0+v0t−12gt2h(t) = h_0 + v_0 t - \frac{1}{2}gt^2h(t)=h0​+v0​t−21​gt2 是关于时间 ttt 的二次方程。求解"何时落地"（h(t)=0h(t) = 0h(t)=0）就是解二次方程。


interface ProjectileResult {
  timeOfFlight: number;
  maxHeight: number;
  timeToMaxHeight: number;
  landingPosition: number;
}

function analyzeProjectile(
  initialHeight: number,
  initialVelocityY: number,
  initialVelocityX: number,
  gravity: number = 9.8,
): ProjectileResult {
  const a = -0.5 * gravity;
  const b = initialVelocityY;
  const c = initialHeight;

  const roots = stableQuadraticSolver(a, b, c);
  const timeOfFlight = Math.max(...roots.filter((t) => t > 0));

  const timeToMaxHeight = -b / (2 * a);
  const maxHeight = a * timeToMaxHeight * timeToMaxHeight + b * timeToMaxHeight + c;

  return {
    timeOfFlight,
    maxHeight,
    timeToMaxHeight,
    landingPosition: initialVelocityX * timeOfFlight,
  };
}

function quadraticBezierPoint(p0: number, p1: number, p2: number, t: number): number {
  return (1 - t) * (1 - t) * p0 + 2 * (1 - t) * t * p1 + t * t * p2;
}

function solveBezierForT(p0: number, p1: number, p2: number, target: number): number[] {
  const a = p0 - 2 * p1 + p2;
  const b = 2 * (p1 - p0);
  const c = p0 - target;
  return stableQuadraticSolver(a, b, c).filter((t) => t >= 0 && t <= 1);
}

小结
    

  • 二次方程 ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0 的求根公式通过配方法推导，是代数的里程碑
    • 

  • 判别式 Δ=b2−4ac\Delta = b^2 - 4acΔ=b2−4ac 决定根的性质：正为两不同实根，零为重根，负为复根
    • 

  • 判别式在碰撞检测（光线-球面求交）中有直接的几何意义
    • 

  • 韦达定理连接根与系数，无需求根即可获取根的和与积
    • 

  • 标准求根公式存在灾难性消去问题，数值稳定版本应先算较大根再用韦达定理
    • 

  • 二次方程在物理模拟（抛体运动）、图形学（Bezier 曲线）、碰撞检测中有核心应用
    • 

  • 配方法不仅是求根工具，更是"通过等价变换揭示结构"的思想范式
