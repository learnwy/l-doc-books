因式分解技巧

核心概念

因式分解是将多项式表达为若干不可约因子乘积的过程，它是代数化简、方程求解和表达式优化的核心技术。因式分解与展开是互逆操作——展开是把乘积变成和，分解是把和变成乘积。

在编程中，因式分解的思想无处不在：提取公共子表达式、化简布尔表达式、优化查询条件，本质上都是"提取公因子"的代数操作。

公因子提取与 GCD 分解
最基本的因式分解技巧是提取所有项的最大公因子（GCF）。这一步应该始终最先执行，因为它能降低后续分解的复杂度。


对于多项式 6x3+9x2−3x6x^3 + 9x^2 - 3x6x3+9x2−3x，先提取 GCF = 3x3x3x，得 3x(2x2+3x−1)3x(2x^2 + 3x - 1)3x(2x2+3x−1)。


function gcd(a: number, b: number): number {
  a = Math.abs(a);
  b = Math.abs(b);
  while (b !== 0) {
    [a, b] = [b, a % b];
  }
  return a;
}

function polynomialGCF(coefficients: number[]): number {
  const nonZero = coefficients.filter((c) => c !== 0);
  if (nonZero.length === 0) return 0;
  return nonZero.reduce((acc, val) => gcd(acc, Math.abs(val)));
}

function extractGCF(coefficients: number[]): {
  factor: number;
  reduced: number[];
} {
  const factor = polynomialGCF(coefficients);
  if (factor === 0) return { factor: 0, reduced: [0] };
  return {
    factor,
    reduced: coefficients.map((c) => c / factor),
  };
}

function extractVariableGCF(terms: Array<{ coeff: number; powers: Map<string, number> }>): {
  commonPowers: Map<string, number>;
  reduced: typeof terms;
} {
  const allVars = new Set<string>();
  terms.forEach((t) => t.powers.forEach((_, v) => allVars.add(v)));

  const commonPowers = new Map<string, number>();
  for (const v of allVars) {
    const minPower = Math.min(...terms.map((t) => t.powers.get(v) ?? 0));
    if (minPower > 0) commonPowers.set(v, minPower);
  }

  const reduced = terms.map((t) => {
    const newPowers = new Map(t.powers);
    for (const [v, p] of commonPowers) {
      const current = newPowers.get(v) ?? 0;
      if (current - p === 0) newPowers.delete(v);
      else newPowers.set(v, current - p);
    }
    return { coeff: t.coeff, powers: newPowers };
  });

  return { commonPowers, reduced };
}
公因子提取在编程中的对应就是重构中的提取方法（Extract Method）——将重复逻辑抽离为独立函数，减少代码冗余。


特殊公式分解
掌握几个核心公式可以快速分解大量多项式。这些公式是展开公式的逆运算。


平方差公式 a2−b2=(a+b)(a−b)a^2 - b^2 = (a + b)(a - b)a2−b2=(a+b)(a−b)：


识别要点——表达式是两个完全平方项的差。注意 aaa 和 bbb 本身可以是复合表达式。


例如 x4−16=(x2)2−42=(x2+4)(x2−4)=(x2+4)(x+2)(x−2)x^4 - 16 = (x^2)^2 - 4^2 = (x^2 + 4)(x^2 - 4) = (x^2 + 4)(x + 2)(x - 2)x4−16=(x2)2−42=(x2+4)(x2−4)=(x2+4)(x+2)(x−2)。


function isDifferenceOfSquares(a: number, b: number, c: number): boolean {
  return b === 0 && a > 0 && c < 0;
}

function factorDifferenceOfSquares(a: number, c: number): [number[], number[]] | null {
  if (a <= 0 || c >= 0) return null;
  const sqrtA = Math.sqrt(a);
  const sqrtC = Math.sqrt(-c);
  if (!Number.isInteger(sqrtA) || !Number.isInteger(sqrtC)) return null;
  return [
    [-sqrtC, sqrtA],
    [sqrtC, sqrtA],
  ];
}
完全平方公式：


(a+b)2=a2+2ab+b2(a + b)^2 = a^2 + 2ab + b^2(a+b)2=a2+2ab+b2 和 (a−b)2=a2−2ab+b2(a - b)^2 = a^2 - 2ab + b^2(a−b)2=a2−2ab+b2


识别要点——三项式的首尾项为完全平方，中间项为它们平方根乘积的两倍。


function isPerfectSquareTrinomial(
  a: number,
  b: number,
  c: number,
): { root1: number; root2: number; sign: '+' | '-' } | null {
  if (a <= 0 || c <= 0) return null;
  const sqrtA = Math.sqrt(a);
  const sqrtC = Math.sqrt(c);
  if (!Number.isInteger(sqrtA) || !Number.isInteger(sqrtC)) return null;
  if (b === 2 * sqrtA * sqrtC) {
    return { root1: sqrtA, root2: sqrtC, sign: '+' };
  }
  if (b === -2 * sqrtA * sqrtC) {
    return { root1: sqrtA, root2: sqrtC, sign: '-' };
  }
  return null;
}

二次三项式的分解
二次三项式 ax2+bx+cax^2 + bx + cax2+bx+c 的分解是最常见的因式分解类型。核心方法有两种：十字相乘法和公式法。


十字相乘法（适用于 a,b,ca, b, ca,b,c 为整数且因式有整系数的情况）：寻找整数 p,q,r,sp, q, r, sp,q,r,s 使得 ax2+bx+c=(px+q)(rx+s)ax^2 + bx + c = (px + q)(rx + s)ax2+bx+c=(px+q)(rx+s)，要求 pr=apr = apr=a, qs=cqs = cqs=c, ps+qr=bps + qr = bps+qr=b。


function factorQuadratic(a: number, b: number, c: number): [number, number, number, number] | null {
  const aFactors = getFactorPairs(Math.abs(a));
  const cFactors = getFactorPairs(Math.abs(c));

  for (const [p, r] of aFactors) {
    for (const [q, s] of cFactors) {
      const signs = [
        [q, s],
        [-q, -s],
        [-q, s],
        [q, -s],
      ];
      for (const [sq, ss] of signs) {
        if (p * ss + r * sq === b && p * r === a && sq * ss === c) {
          return [p, sq, r, ss];
        }
      }
    }
  }
  return null;
}

function getFactorPairs(n: number): [number, number][] {
  const pairs: [number, number][] = [];
  for (let i = 1; i <= Math.sqrt(n); i++) {
    if (n % i === 0) pairs.push([i, n / i]);
  }
  return pairs;
}
判别式法——当十字相乘无法快速找到整数因式时，使用判别式 Δ=b2−4ac\Delta = b^2 - 4acΔ=b2−4ac：


    

  • Δ>0\Delta > 0Δ>0：两个不同实根，ax2+bx+c=a(x−r1)(x−r2)ax^2 + bx + c = a(x - r_1)(x - r_2)ax2+bx+c=a(x−r1​)(x−r2​)
    • 

  • Δ=0\Delta = 0Δ=0：重根，ax2+bx+c=a(x−r)2ax^2 + bx + c = a(x - r)^2ax2+bx+c=a(x−r)2
    • 

  • Δ<0\Delta < 0Δ<0：无实数因式（在实数域内不可分解）
    • 



function factorByDiscriminant(
  a: number,
  b: number,
  c: number,
): { type: 'two_roots'; r1: number; r2: number } | { type: 'repeated'; r: number } | { type: 'irreducible' } {
  const discriminant = b * b - 4 * a * c;
  if (discriminant > 0) {
    const sqrtD = Math.sqrt(discriminant);
    return {
      type: 'two_roots',
      r1: (-b + sqrtD) / (2 * a),
      r2: (-b - sqrtD) / (2 * a),
    };
  }
  if (discriminant === 0) {
    return { type: 'repeated', r: -b / (2 * a) };
  }
  return { type: 'irreducible' };
}
分组分解法
当多项式有四项或更多项，且无法直接套用公式时，分组分解法是有效策略。其核心思想是将项分成几组，每组分别提取公因子，然后再提取组间的公因子。


例如 x3+x2−4x−4x^3 + x^2 - 4x - 4x3+x2−4x−4：


    

  1. 分组：(x3+x2)+(−4x−4)(x^3 + x^2) + (-4x - 4)(x3+x2)+(−4x−4)
    2. 

  2. 各组提取：x2(x+1)−4(x+1)x^2(x + 1) - 4(x + 1)x2(x+1)−4(x+1)
    3. 

  3. 提取公因式：(x+1)(x2−4)(x + 1)(x^2 - 4)(x+1)(x2−4)
    4. 

  4. 继续分解：(x+1)(x+2)(x−2)(x + 1)(x + 2)(x - 2)(x+1)(x+2)(x−2)
    5. 



function factorByGrouping(coefficients: number[]): { success: boolean; factors: number[][] } {
  if (coefficients.length !== 4) {
    return { success: false, factors: [] };
  }

  const [a, b, c, d] = coefficients;

  const g1 = gcd(Math.abs(c), Math.abs(d));
  const g2 = gcd(Math.abs(a), Math.abs(b));

  const c1 = d > 0 ? g1 : -g1;
  const c2 = b > 0 ? g2 : -g2;

  const f1a = a / c2;
  const f1b = c / c1;
  const f2a = b / c2;
  const f2b = d / c1;

  if (f1a === f1b && f2a === f2b) {
    return {
      success: true,
      factors: [
        [f2a, f1a],
        [c1, c2],
      ],
    };
  }

  return { success: false, factors: [] };
}
分组分解需要一定的经验和尝试，有时需要重新排列项的顺序才能找到合适的分组。


综合因式分解策略
面对一个任意多项式，推荐按以下流程进行系统性分解：


type Factor = { polynomial: number[]; multiplicity: number };

function fullyFactor(coefficients: number[]): Factor[] {
  const { factor: gcf, reduced } = extractGCF(coefficients);
  const factors: Factor[] = [];

  if (gcf !== 1 && gcf !== 0) {
    factors.push({ polynomial: [gcf], multiplicity: 1 });
  }

  const work = [reduced];
  while (work.length > 0) {
    const current = work.pop()!;

    if (current.length <= 1) {
      if (current[0] !== 1) {
        factors.push({ polynomial: current, multiplicity: 1 });
      }
      continue;
    }

    if (current.length === 2) {
      factors.push({ polynomial: current, multiplicity: 1 });
      continue;
    }

    if (current.length === 3) {
      const [c, b, a] = current;
      const result = factorByDiscriminant(a, b, c);
      if (result.type === 'two_roots') {
        work.push([-result.r1, 1]);
        work.push([-result.r2, 1]);
        if (a !== 1) factors.push({ polynomial: [a], multiplicity: 1 });
      } else if (result.type === 'repeated') {
        factors.push({ polynomial: [-result.r, 1], multiplicity: 2 });
        if (a !== 1) factors.push({ polynomial: [a], multiplicity: 1 });
      } else {
        factors.push({ polynomial: current, multiplicity: 1 });
      }
      continue;
    }

    let found = false;
    const roots = findRationalRoots(current);
    if (roots.length > 0) {
      const root = roots[0];
      const { quotient } = syntheticDivide(current, root);
      work.push([-root, 1]);
      work.push(quotient);
      found = true;
    }

    if (!found) {
      factors.push({ polynomial: current, multiplicity: 1 });
    }
  }

  return mergeDuplicateFactors(factors);
}

function mergeDuplicateFactors(factors: Factor[]): Factor[] {
  const map = new Map<string, Factor>();
  for (const f of factors) {
    const key = f.polynomial.join(',');
    const existing = map.get(key);
    if (existing) {
      existing.multiplicity += f.multiplicity;
    } else {
      map.set(key, { ...f });
    }
  }
  return [...map.values()];
}

小结
    

  • 因式分解是展开的逆运算，将多项式表示为不可约因子的乘积
    • 

  • 提取公因子（GCF）是第一步，对应编程中的"提取方法"重构
    • 

  • 平方差、完全平方、立方和/差是最常用的特殊公式，需要熟练识别
    • 

  • 二次三项式用十字相乘法或判别式法分解，判别式决定了根的存在性
    • 

  • 分组分解法适用于四项及以上的多项式，需要尝试不同的分组策略
    • 

  • 系统化的分解流程：GCF → 特殊公式 → 三项式分解 → 分组 → 试根法
    • 

  • 因式分解在密码学（大整数分解）、编译优化（公共子表达式消除）和数据库（查询条件化简）中有广泛应用
    •
