实数系统与数的分类

核心概念

实数系统是整个代数学的基石，也是计算机科学中数值计算的理论根基。理解实数的结构与分类，不仅帮助程序员写出更精确的数值代码，还能深刻理解浮点运算中的各种"怪异"行为。

实数集 R\mathbb{R}R 包含有理数 Q\mathbb{Q}Q 和无理数两大子集，它们共同构成一条完备的数轴——没有"空隙"的连续统。

有理数与无理数的本质区别
有理数的核心特征是其小数展开必然终止或循环。例如 1/3=0.333…1/3 = 0.333\ldots1/3=0.333…（循环），1/4=0.251/4 = 0.251/4=0.25（终止）。相反，无理数的小数展开永不循环、永不终止。


这一区别对程序员有直接意义：任何有理数都可以用分数精确表示，而无理数只能被逼近。


function isTerminatingDecimal(numerator: number, denominator: number): boolean {
  let d = Math.abs(denominator);
  while (d % 2 === 0) d /= 2;
  while (d % 5 === 0) d /= 5;
  return d === 1;
}

class Rational {
  constructor(
    readonly numerator: bigint,
    readonly denominator: bigint,
  ) {
    if (denominator === 0n) throw new Error('Denominator cannot be zero');
    const g = this.gcd(numerator < 0n ? -numerator : numerator, denominator < 0n ? -denominator : denominator);
    this.numerator = (denominator < 0n ? -numerator : numerator) / g;
    this.denominator = (denominator < 0n ? -denominator : denominator) / g;
  }

  private gcd(a: bigint, b: bigint): bigint {
    while (b !== 0n) {
      [a, b] = [b, a % b];
    }
    return a;
  }

  add(other: Rational): Rational {
    return new Rational(
      this.numerator * other.denominator + other.numerator * this.denominator,
      this.denominator * other.denominator,
    );
  }

  toNumber(): number {
    return Number(this.numerator) / Number(this.denominator);
  }
}
用 Rational 类进行分数运算可以完全避免浮点精度问题。金融计算、精确比较等场景中，这种思路比直接使用 number 可靠得多。


证明 2\sqrt{2}2​ 是无理数——经典的反证法：假设 2=p/q\sqrt{2} = p/q2​=p/q（最简分数），则 2q2=p22q^2 = p^22q2=p2，所以 p2p^2p2 为偶数，进而 ppp 为偶数，设 p=2kp = 2kp=2k，代入得 q2=2k2q^2 = 2k^2q2=2k2，同理 qqq 也为偶数，矛盾。


实数的完备性与稠密性
完备性（Completeness）是实数区别于有理数的关键性质：实数集中的每个有上界的非空子集都有最小上界（上确界）。直观理解——实数轴上"没有空洞"。


有理数不具备完备性。例如集合 {x∈Q∣x2<2}\{x \in \mathbb{Q} \mid x^2 < 2\}{x∈Q∣x2<2} 的上确界是 2\sqrt{2}2​，但 2∉Q\sqrt{2} \notin \mathbb{Q}2​∈/Q。


稠密性（Density）则说明：任意两个不同的实数之间，必然存在无穷多个有理数和无穷多个无理数。


function rationalBetween(a: number, b: number): [number, number] {
  const mid = (a + b) / 2;
  const precision = 1000000;
  const numerator = Math.round(mid * precision);
  return [numerator, precision];
}

function generateRationalsBetween(a: number, b: number, count: number): number[] {
  const result: number[] = [];
  const step = (b - a) / (count + 1);
  for (let i = 1; i <= count; i++) {
    result.push(a + step * i);
  }
  return result;
}
完备性在算法中的体现十分广泛。二分查找之所以能逼近精确解，正因为实数的完备性保证了极限的存在：


function sqrtByBisection(n: number, epsilon: number = 1e-10): number {
  if (n < 0) throw new Error('Cannot compute sqrt of negative number');
  if (n === 0) return 0;
  let low = 0;
  let high = Math.max(1, n);
  while (high - low > epsilon) {
    const mid = (low + high) / 2;
    if (mid * mid < n) {
      low = mid;
    } else {
      high = mid;
    }
  }
  return (low + high) / 2;
}
这个二分法求平方根的过程，本质上就是构造一个单调有界序列，由完备性保证收敛到 n\sqrt{n}n​。


IEEE 754 与浮点数陷阱
JavaScript 和 TypeScript 中的 number 类型基于 IEEE 754 双精度浮点标准，使用 64 位存储：1 位符号位、11 位指数位、52 位尾数位。


这意味着 number 能精确表示的整数范围是 [−253,253][-2^{53}, 2^{53}][−253,253]（即 Number.MIN_SAFE_INTEGER 到 Number.MAX_SAFE_INTEGER）。超出此范围，整数运算也会丢失精度。

function floatEqual(a: number, b: number, epsilon = Number.EPSILON): boolean {
  return Math.abs(a - b) < Math.max(epsilon, epsilon * Math.max(Math.abs(a), Math.abs(b)));
}

0.1 在二进制中是无限循环小数 0.00011‾20.0\overline{0011}_20.000112​，存储时发生截断。这与有理数 1/31/31/3 在十进制中无法精确表示是同一个道理。


数集的可数性与对角线论证
Cantor 的对角线论证证明了实数是不可数的——这是集合论中最优美的证明之一，也对计算理论有深刻影响。


Cantor 对角线论证：假设 [0,1)[0, 1)[0,1) 中的实数可以列成序列 r1,r2,r3,…r_1, r_2, r_3, \ldotsr1​,r2​,r3​,…，每个 rir_iri​ 写成十进制小数 0.di1di2di3…0.d_{i1}d_{i2}d_{i3}\ldots0.di1​di2​di3​…。构造新数 s=0.s1s2s3…s = 0.s_1s_2s_3\ldotss=0.s1​s2​s3​…，其中 si≠diis_i \neq d_{ii}si​=dii​（且 si≠0,9s_i \neq 0, 9si​=0,9 以避免重复表示问题）。则 sss 与每个 rir_iri​ 至少在第 iii 位不同，故 sss 不在列表中——矛盾。


function cantorDiagonal(sequences: string[]): string {
  return sequences
    .map((seq, i) => {
      const digit = parseInt(seq[i], 10);
      return digit === 5 ? '6' : '5';
    })
    .join('');
}

const listed = ['14159265', '71828182', '41421356', '30258509'];
const newNumber = cantorDiagonal(listed);
这个论证的编程意义在于：它证明了存在不可计算的函数。可计算函数（Turing 机能计算的函数）是可数的，而从 N\mathbb{N}N 到 {0,1}\{0,1\}{0,1} 的所有函数是不可数的，因此必然存在不可计算的函数。停机问题的不可判定性正是这一思想的直接应用。

小结
    

  • 实数系统由有理数和无理数构成，形成完备的连续统，是所有数值计算的理论基础
    • 

  • 有理数小数展开终止或循环，无理数永不循环——这决定了计算机只能近似表示无理数
    • 

  • 完备性保证了二分法、牛顿法等迭代算法的收敛性
    • 

  • 稠密性意味着任意两个实数之间有无穷多有理数和无理数
    • 

  • IEEE 754 浮点数是实数的有限近似，理解其局限性是写出正确数值代码的前提
    • 

  • 0.1 + 0.2 !== 0.3 不是 bug，而是二进制浮点的固有特性
    • 

  • Cantor 对角线论证揭示了实数的不可数性，这与停机问题、不可计算函数直接相关
    • 

  • 需要精确有理数运算时，应使用分数类或 bigint，而非直接依赖 number
