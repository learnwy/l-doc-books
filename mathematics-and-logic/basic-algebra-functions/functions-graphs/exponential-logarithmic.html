指数与对数函数

核心概念

指数函数和对数函数是一对互逆函数，它们描述的是"乘法式增长/衰减"与"求幂次"的关系。对程序员而言，这对函数无处不在：算法复杂度分析（O(log⁡n)O(\log n)O(logn)、O(2n)O(2^n)O(2n)）、信息论（信息熵）、数据库索引（B 树高度）、机器学习（sigmoid、softmax）都依赖它们。

指数函数 f(x)=axf(x) = a^xf(x)=ax（a>0,a≠1a > 0, a \neq 1a>0,a=1）将加法运算映射为乘法运算：am+n=am⋅ana^{m+n} = a^m \cdot a^nam+n=am⋅an。对数函数 g(x)=log⁡axg(x) = \log_a xg(x)=loga​x 则将乘法映射回加法：log⁡a(mn)=log⁡am+log⁡an\log_a(mn) = \log_a m + \log_a nloga​(mn)=loga​m+loga​n。

指数函数的性质与增长
指数函数 f(x)=axf(x) = a^xf(x)=ax 的核心特征是乘法式增长——每经过相同的时间间隔，函数值乘以相同的倍数。这与线性增长（每次加相同的量）形成鲜明对比。


当 a>1a > 1a>1 时为指数增长，0<a<10 < a < 10<a<1 时为指数衰减。


function exponentialGrowth(initial: number, rate: number, time: number): number {
  return initial * Math.pow(1 + rate, time);
}

function exponentialDecay(initial: number, halfLife: number, time: number): number {
  return initial * Math.pow(0.5, time / halfLife);
}

function doublingTime(rate: number): number {
  return Math.log(2) / Math.log(1 + rate);
}
72 法则：如果年增长率为 r%r\%r%，翻倍时间约为 72/r72/r72/r 年。这是 ln⁡2≈0.693\ln 2 \approx 0.693ln2≈0.693 的近似。


指数增长在计算机科学中最显著的体现是暴力搜索的爆炸性增长。nnn 个布尔变量的所有组合有 2n2^n2n 种——这就是 NP 问题困难的根源。


function powerSet<T>(items: T[]): T[][] {
  const result: T[][] = [[]];
  for (const item of items) {
    const newSubsets = result.map((subset) => [...subset, item]);
    result.push(...newSubsets);
  }
  return result;
}

function demonstrateExponentialGrowth(maxN: number): void {

    const timeEstimate = combinations / 1e9;

  }
}

对数函数与复杂度分析
对数函数 log⁡ax\log_a xloga​x 是指数函数的逆：y=log⁡ax⇔ay=xy = \log_a x \Leftrightarrow a^y = xy=loga​x⇔ay=x。


对数的核心性质：


    

  • log⁡a(mn)=log⁡am+log⁡an\log_a(mn) = \log_a m + \log_a nloga​(mn)=loga​m+loga​n（积的对数 = 对数的和）
    • 

  • log⁡a(m/n)=log⁡am−log⁡an\log_a(m/n) = \log_a m - \log_a nloga​(m/n)=loga​m−loga​n（商的对数 = 对数的差）
    • 

  • log⁡a(mk)=klog⁡am\log_a(m^k) = k \log_a mloga​(mk)=kloga​m（幂的对数 = 指数乘以对数）
    • 

  • log⁡ab=log⁡cblog⁡ca\log_a b = \frac{\log_c b}{\log_c a}loga​b=logc​alogc​b​（换底公式）
    • 



在算法分析中，对数底数的选择通常不重要，因为换底公式意味着不同底的对数只差一个常数因子：log⁡2n=log⁡10nlog⁡102≈3.32log⁡10n\log_2 n = \frac{\log_{10} n}{\log_{10} 2} \approx 3.32 \log_{10} nlog2​n=log10​2log10​n​≈3.32log10​n。所以 O(log⁡2n)=O(log⁡10n)=O(ln⁡n)O(\log_2 n) = O(\log_{10} n) = O(\ln n)O(log2​n)=O(log10​n)=O(lnn)。


function log(base: number, x: number): number {

function binarySearchDepth(n: number): number {
  return Math.ceil(Math.log2(n));

function bTreeHeight(n: number, order: number): number {
  return Math.ceil(log(Math.ceil(order / 2), (n + 1) / 2));

function mergesortComparisons(n: number): number {

为什么二分查找是 O(log⁡n)O(\log n)O(logn)：每次比较排除一半候选项。nnn 个元素最多需要 ⌈log⁡2n⌉\lceil\log_2 n\rceil⌈log2​n⌉ 次比较。这正是对数的定义——"需要几次除以 2 才能到 1"。


类似地，平衡二叉搜索树的高度为 O(log⁡n)O(\log n)O(logn)，B 树（阶为 mmm）的高度为 O(log⁡mn)O(\log_m n)O(logm​n)。

function taylorExp(x: number, terms: number = 20): number {
  let result = 0;
  let term = 1;
  for (let n = 0; n < terms; n++) {
    result += term;
    term *= x / (n + 1);
  }
  return result;
}

function taylorLn(x: number, terms: number = 100): number {
  if (x <= 0) throw new Error('ln(x) undefined for x <= 0');
  const u = (x - 1) / (x + 1);
  let result = 0;
  let power = u;
  for (let n = 0; n < terms; n++) {
    result += power / (2 * n + 1);
    power *= u * u;
  }
  return 2 * result;
}

function sigmoid(x: number): number {
  if (x >= 0) {
    return 1 / (1 + Math.exp(-x));
  }
  const expX = Math.exp(x);
  return expX / (1 + expX);
}

function softmax(logits: number[]): number[] {
  const maxLogit = Math.max(...logits);
  const exps = logits.map((x) => Math.exp(x - maxLogit));
  const sum = exps.reduce((a, b) => a + b, 0);
  return exps.map((e) => e / sum);
}

function entropy(probabilities: number[]): number {
  return -probabilities.reduce((sum, p) => {
    if (p <= 0) return sum;
    return sum + p * Math.log2(p);
  }, 0);
}
注意 sigmoid 和 softmax 的实现都用了数值稳定性技巧——减去最大值防止溢出。


对数标度与数据可视化
当数据范围跨越多个数量级时，线性刻度无法有效展示。对数标度将每个数量级映射为等距间隔，使得数据可视化更清晰。


常见的对数标度应用：


    

  • 分贝（dB）：L=20log⁡10(A/A0)L = 20\log_{10}(A/A_0)L=20log10​(A/A0​)
    • 

  • 里氏震级：每增加 1 级，能量增大约 31.6 倍
    • 

  • pH 值：pH=−log⁡10[H+]\text{pH} = -\log_{10}[\text{H}^+]pH=−log10​[H+]
    • 

  • 对数坐标图：在对数坐标下，指数函数变成直线
    • 



function toDecibels(amplitude: number, reference: number): number {
  return 20 * Math.log10(amplitude / reference);
}

function fromDecibels(db: number, reference: number): number {
  return reference * Math.pow(10, db / 20);
}

function logScale(value: number, min: number, max: number, outputMin: number, outputMax: number): number {
  const logMin = Math.log(min);
  const logMax = Math.log(max);
  const logValue = Math.log(value);
  const t = (logValue - logMin) / (logMax - logMin);
  return outputMin + t * (outputMax - outputMin);
}
在数据可视化和音频处理中，对数标度是不可或缺的工具。人类的听觉和视觉感知本身就近似对数响应——Weber-Fechner 定律指出，感知强度与刺激强度的对数成正比。


小结
    

  • 指数函数和对数函数互为逆函数，分别描述乘法式增长和"求幂次"操作
    • 

  • 指数增长是 NP 问题困难的根源，2n2^n2n 的增长速度远超任何多项式
    • 

  • 对数是算法复杂度分析的核心工具，O(log⁡n)O(\log n)O(logn) 意味着"每次排除一半"
    • 

  • 不同底数的对数只差常数因子，所以大 O 记号中底数无关紧要
    • 

  • 自然常数 eee 的特殊性在于 exe^xex 的导数等于自身，是微积分和概率论的基石
    • 

  • sigmoid、softmax、信息熵等核心函数都基于 exe^xex 和 ln⁡x\ln xlnx
    • 

  • 对数标度将跨越多个数量级的数据映射为等距间隔，是数据可视化的关键技术
    • 

  • 数值计算中应注意指数溢出问题，使用减去最大值等稳定性技巧
    •
