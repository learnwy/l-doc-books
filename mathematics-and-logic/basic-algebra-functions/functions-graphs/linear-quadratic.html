一次与二次函数

核心概念

一次函数和二次函数是最基础也是应用最广的两类函数。一次函数描述线性关系，二次函数描述抛物线形态。掌握它们的性质，是理解更复杂函数（指数、对数、三角函数等）的前提。

在编程中，一次函数对应线性插值、线性回归；二次函数对应抛物线运动、优化问题中的二次损失函数。

一次函数的斜率与截距
一次函数 f(x)=ax+bf(x) = ax + bf(x)=ax+b 的图像是一条直线。aaa 是斜率（slope），表示 xxx 每增加 1 时 yyy 的变化量；bbb 是 yyy 截距（y-intercept），即直线与 yyy 轴的交点。


两点确定一条直线——给定两点 (x1,y1)(x_1, y_1)(x1​,y1​) 和 (x2,y2)(x_2, y_2)(x2​,y2​)：


a=y2−y1x2−x1,b=y1−a⋅x1a = \frac{y_2 - y_1}{x_2 - x_1}, \quad b = y_1 - a \cdot x_1a=x2​−x1​y2​−y1​​,b=y1​−a⋅x1​
interface LinearFunction {
  slope: number;
  intercept: number;
}

function fromTwoPoints(x1: number, y1: number, x2: number, y2: number): LinearFunction {
  if (x1 === x2) throw new Error('Vertical line: slope is undefined');
  const slope = (y2 - y1) / (x2 - x1);
  const intercept = y1 - slope * x1;
  return { slope, intercept };
}

function evaluateLinear(f: LinearFunction, x: number): number {
  return f.slope * x + f.intercept;
}

function linearInverse(f: LinearFunction): LinearFunction {
  if (f.slope === 0) throw new Error('Constant function has no inverse');
  return {
    slope: 1 / f.slope,
    intercept: -f.intercept / f.slope,
  };
}

function linearIntersection(f: LinearFunction, g: LinearFunction): { x: number; y: number } | null {
  if (f.slope === g.slope) return null;
  const x = (g.intercept - f.intercept) / (f.slope - g.slope);
  const y = evaluateLinear(f, x);
  return { x, y };
}
线性插值——给定两个已知点，估算中间值：


f(x)=y1+y2−y1x2−x1(x−x1)f(x) = y_1 + \frac{y_2 - y_1}{x_2 - x_1}(x - x_1)f(x)=y1​+x2​−x1​y2​−y1​​(x−x1​)
这就是游戏开发和动画中最常用的 lerp（linear interpolation）函数。


function lerp(a: number, b: number, t: number): number {
  return a + (b - a) * t;
}

function inverseLerp(a: number, b: number, value: number): number {
  if (a === b) return 0;
  return (value - a) / (b - a);
}

function remap(value: number, fromMin: number, fromMax: number, toMin: number, toMax: number): number {
  const t = inverseLerp(fromMin, fromMax, value);
  return lerp(toMin, toMax, t);
}
二次函数的三种表示形式
二次函数有三种等价的表示形式，每种突出不同的信息：


标准式 f(x)=ax2+bx+cf(x) = ax^2 + bx + cf(x)=ax2+bx+c：直接给出系数，方便计算函数值。


顶点式 f(x)=a(x−h)2+kf(x) = a(x - h)^2 + kf(x)=a(x−h)2+k：(h,k)(h, k)(h,k) 为顶点坐标，直接读出极值信息。


因式分解式 f(x)=a(x−r1)(x−r2)f(x) = a(x - r_1)(x - r_2)f(x)=a(x−r1​)(x−r2​)：r1,r2r_1, r_2r1​,r2​ 为零点，直接读出与 xxx 轴的交点。


三种形式之间的转换关系：


h=−b2a,k=c−b24a,r1,2=−b±b2−4ac2ah = -\frac{b}{2a}, \quad k = c - \frac{b^2}{4a}, \quad r_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}h=−2ab​,k=c−4ab2​,r1,2​=2a−b±b2−4ac​​
interface QuadraticStandard {
  a: number;
  b: number;
  c: number;
}
interface QuadraticVertex {
  a: number;
  h: number;
  k: number;
}
interface QuadraticFactored {
  a: number;
  r1: number;
  r2: number;
}

function standardToVertex(q: QuadraticStandard): QuadraticVertex {
  const h = -q.b / (2 * q.a);
  const k = q.c - (q.b * q.b) / (4 * q.a);
  return { a: q.a, h, k };
}

function vertexToStandard(q: QuadraticVertex): QuadraticStandard {
  return {
    a: q.a,
    b: -2 * q.a * q.h,
    c: q.a * q.h * q.h + q.k,
  };
}

function standardToFactored(q: QuadraticStandard): QuadraticFactored | null {
  const discriminant = q.b * q.b - 4 * q.a * q.c;
  if (discriminant < 0) return null;
  const sqrtD = Math.sqrt(discriminant);
  return {
    a: q.a,
    r1: (-q.b + sqrtD) / (2 * q.a),
    r2: (-q.b - sqrtD) / (2 * q.a),
  };
}

function evaluateQuadratic(q: QuadraticStandard, x: number): number {
  return q.a * x * x + q.b * x + q.c;
}

判别式与根的分析
判别式 Δ=b2−4ac\Delta = b^2 - 4acΔ=b2−4ac 完全决定了二次方程 ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0 的根的情况：


    

  • Δ>0\Delta > 0Δ>0：两个不同实根 r1≠r2r_1 \neq r_2r1​=r2​
    • 

  • Δ=0\Delta = 0Δ=0：一个重根 r=−b/(2a)r = -b/(2a)r=−b/(2a)
    • 

  • Δ<0\Delta < 0Δ<0：无实根（有两个共轭复根）
    • 



韦达定理（Vieta's formulas）给出根与系数的直接关系：


r1+r2=−ba,r1⋅r2=car_1 + r_2 = -\frac{b}{a}, \quad r_1 \cdot r_2 = \frac{c}{a}r1​+r2​=−ab​,r1​⋅r2​=ac​
韦达定理无需实际求根就能得到根的和与积，在验证答案和构造方程时非常有用。


interface RootAnalysis {
  discriminant: number;
  rootType: 'two_real' | 'repeated' | 'complex';
  roots?: [number, number];
  rootSum: number;
  rootProduct: number;
}

function analyzeQuadratic(a: number, b: number, c: number): RootAnalysis {
  const discriminant = b * b - 4 * a * c;
  const rootSum = -b / a;
  const rootProduct = c / a;

  if (discriminant > 0) {
    const sqrtD = Math.sqrt(discriminant);
    return {
      discriminant,
      rootType: 'two_real',
      roots: [(-b + sqrtD) / (2 * a), (-b - sqrtD) / (2 * a)],
      rootSum,
      rootProduct,
    };
  }

  if (discriminant === 0) {
    const root = -b / (2 * a);
    return {
      discriminant,
      rootType: 'repeated',
      roots: [root, root],
      rootSum,
      rootProduct,
    };
  }

  return { discriminant, rootType: 'complex', rootSum, rootProduct };
}
数值稳定性注意：当 Δ\DeltaΔ 接近零时，直接使用求根公式会导致精度损失。更稳定的做法是先计算较大的根，再用韦达定理求另一个：


function stableQuadraticRoots(a: number, b: number, c: number): [number, number] | null {
  const discriminant = b * b - 4 * a * c;
  if (discriminant < 0) return null;

  const sqrtD = Math.sqrt(discriminant);
  const r1 = (-b - Math.sign(b) * sqrtD) / (2 * a);
  const r2 = c / (a * r1);
  return [r1, r2];
}
二次函数在优化中的应用
二次函数的顶点就是其极值点。当 a>0a > 0a>0 时，顶点是最小值点；当 a<0a < 0a<0 时，顶点是最大值点。


这一性质使二次函数成为优化问题的基础模型。最小二乘法、岭回归中的损失函数都是高维空间中的"二次函数"（二次型）。


function findOptimum(a: number, b: number, c: number): { x: number; y: number; type: 'minimum' | 'maximum' } {
  const x = -b / (2 * a);
  const y = c - (b * b) / (4 * a);
  return { x, y, type: a > 0 ? 'minimum' : 'maximum' };
}

function fitQuadratic(points: Array<{ x: number; y: number }>): QuadraticStandard {
  const n = points.length;
  let sx = 0,
    sx2 = 0,
    sx3 = 0,
    sx4 = 0;
  let sy = 0,
    sxy = 0,
    sx2y = 0;

  for (const { x, y } of points) {
    sx += x;
    sx2 += x * x;
    sx3 += x * x * x;
    sx4 += x * x * x * x;
    sy += y;
    sxy += x * y;
    sx2y += x * x * y;
  }

  const matrix = [
    [sx4, sx3, sx2, sx2y],
    [sx3, sx2, sx, sxy],
    [sx2, sx, n, sy],
  ];

  for (let i = 0; i < 3; i++) {
    const pivot = matrix[i][i];
    for (let j = i; j < 4; j++) matrix[i][j] /= pivot;
    for (let k = 0; k < 3; k++) {
      if (k === i) continue;
      const factor = matrix[k][i];
      for (let j = i; j < 4; j++) matrix[k][j] -= factor * matrix[i][j];
    }
  }

  return { a: matrix[0][3], b: matrix[1][3], c: matrix[2][3] };
}
配方法（Completing the Square）是将标准式转化为顶点式的核心技巧：


ax2+bx+c=a(x+b2a)2+c−b24aax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + c - \frac{b^2}{4a}ax2+bx+c=a(x+2ab​)2+c−4ab2​
配方法不仅用于求极值，还是推导二次公式的基础，在积分、概率分布等领域也频繁使用。
