函数的概念与性质

核心概念

函数是数学中最核心的概念之一，它描述了输入与输出之间的确定性对应关系。形式化定义：函数 f:A→Bf: A \to Bf:A→B 是从集合 AAA（定义域）到集合 BBB（值域的父集，称为陪域）的一个映射，满足 AAA 中的每个元素恰好对应 BBB 中的一个元素。

对程序员而言，函数的数学定义与编程中的纯函数（pure function）完全一致：相同输入必产生相同输出，无副作用。

函数的分类：单射、满射与双射
函数的三种重要分类决定了它的核心性质，也直接影响着数据结构设计和算法选择。


单射（Injective）：不同输入必映射到不同输出。即 f(a)=f(b)⇒a=bf(a) = f(b) \Rightarrow a = bf(a)=f(b)⇒a=b。编程中对应"无哈希冲突"的理想哈希函数。


满射（Surjective）：陪域中的每个元素都至少有一个原像。即 ∀b∈B,∃a∈A,f(a)=b\forall b \in B, \exists a \in A, f(a) = b∀b∈B,∃a∈A,f(a)=b。编程中对应"完全覆盖所有返回值"的函数。


双射（Bijective）：既单又满，建立一一对应。双射函数必有逆函数。编程中对应"可逆的编码/解码"。


function isInjective<T, U>(domain: T[], f: (x: T) => U): boolean {
  const seen = new Set<U>();
  for (const x of domain) {
    const y = f(x);
    if (seen.has(y)) return false;
    seen.add(y);
  }
  return true;
}

function isSurjective<T, U>(domain: T[], codomain: U[], f: (x: T) => U): boolean {
  const range = new Set(domain.map(f));
  return codomain.every((y) => range.has(y));
}

function isBijective<T, U>(domain: T[], codomain: U[], f: (x: T) => U): boolean {
  return isInjective(domain, f) && isSurjective(domain, codomain, f);
}

函数复合与链式调用
函数复合 (g∘f)(x)=g(f(x))(g \circ f)(x) = g(f(x))(g∘f)(x)=g(f(x)) 是用一个函数的输出作为另一个函数的输入。这是函数式编程中最基本的操作。


复合的关键约束：fff 的值域必须是 ggg 的定义域的子集。


function compose<A, B, C>(g: (b: B) => C, f: (a: A) => B): (a: A) => C {
  return (a: A) => g(f(a));
}

function pipe<T>(...fns: Array<(arg: T) => T>): (arg: T) => T {
  return (arg: T) => fns.reduce((val, fn) => fn(val), arg);
}

const double = (x: number) => x * 2;
const addOne = (x: number) => x + 1;
const square = (x: number) => x * x;

const transform = pipe(double, addOne, square);
console.log(transform(3));

  • 结合律：(h∘g)∘f=h∘(g∘f)(h \circ g) \circ f = h \circ (g \circ f)(h∘g)∘f=h∘(g∘f)

  • 不满足交换律：一般情况下 g∘f≠f∘gg \circ f \neq f \circ gg∘f=f∘g
    • 

  • 恒等函数是单位元：f∘id=id∘f=ff \circ \text{id} = \text{id} \circ f = ff∘id=id∘f=f

这些性质使得函数集合在复合运算下构成一个幺半群（monoid），这也是函数式编程中 monad 的数学基础。


逆函数与可逆性
如果函数 fff 是双射，则存在唯一的逆函数 f−1f^{-1}f−1，满足 f−1(f(x))=xf^{-1}(f(x)) = xf−1(f(x))=x 且 f(f−1(y))=yf(f^{-1}(y)) = yf(f−1(y))=y。


逆函数的图像是原函数图像关于直线 y=xy = xy=x 的对称。


type InvertiblePair<T, U> = {
  forward: (x: T) => U;
  backward: (y: U) => T;
};

function createLinearBijection(a: number, b: number): InvertiblePair<number, number> {
  if (a === 0) throw new Error("Coefficient 'a' cannot be zero for bijection");
  return {
    forward: (x: number) => a * x + b,
    backward: (y: number) => (y - b) / a,
  };
}

function verifyInverse(pair: InvertiblePair<number, number>, testValues: number[], epsilon = 1e-10): boolean {
  return testValues.every((x) => {
    const roundTrip = pair.backward(pair.forward(x));
    return Math.abs(roundTrip - x) < epsilon;
  });
}

const linear = createLinearBijection(3, -2);
console.log(linear.forward(5));
console.log(linear.backward(13));
console.log(verifyInverse(linear, [0, 1, -1, 100, -50]));

单调性描述函数值随输入变化的方向：


    

  • 单调递增：x1<x2⇒f(x1)<f(x2)x_1 < x_2 \Rightarrow f(x_1) < f(x_2)x1​<x2​⇒f(x1​)<f(x2​)
    • 

  • 单调递减：x1<x2⇒f(x1)>f(x2)x_1 < x_2 \Rightarrow f(x_1) > f(x_2)x1​<x2​⇒f(x1​)>f(x2​)
    • 

  • 非递减/非递增：允许等号

单调函数必然是单射（在其单调区间上），因此可以在该区间上定义逆函数。


function isMonotonicallyIncreasing(f: (x: number) => number, samples: number[]): boolean {
  const sorted = [...samples].sort((a, b) => a - b);
  for (let i = 1; i < sorted.length; i++) {
    if (f(sorted[i]) <= f(sorted[i - 1])) return false;
  }
  return true;
}

function findMonotonicIntervals(
  f: (x: number) => number,
  start: number,
  end: number,
  steps: number,
): Array<{ from: number; to: number; type: 'increasing' | 'decreasing' }> {
  const intervals: Array<{
    from: number;
    to: number;
    type: 'increasing' | 'decreasing';
  }> = [];
  const dx = (end - start) / steps;

  let currentType: 'increasing' | 'decreasing' | null = null;
  let intervalStart = start;

  for (let i = 1; i <= steps; i++) {
    const x = start + i * dx;
    const prevX = start + (i - 1) * dx;
    const diff = f(x) - f(prevX);
    const type = diff > 0 ? 'increasing' : 'decreasing';

    if (currentType === null) {
      currentType = type;
    } else if (type !== currentType) {
      intervals.push({ from: intervalStart, to: prevX, type: currentType });
      intervalStart = prevX;
      currentType = type;
    }
  }

  if (currentType !== null) {
    intervals.push({ from: intervalStart, to: end, type: currentType });
  }

  return intervals;
}

奇偶性与周期性
奇函数：f(−x)=−f(x)f(-x) = -f(x)f(−x)=−f(x)，图像关于原点对称。如 sin⁡x\sin xsinx, x3x^3x3。


偶函数：f(−x)=f(x)f(-x) = f(x)f(−x)=f(x)，图像关于 yyy 轴对称。如 cos⁡x\cos xcosx, x2x^2x2。


利用奇偶性可以将计算量减半——只需计算非负区间的值。


周期函数：存在最小正数 TTT 使得 f(x+T)=f(x)f(x + T) = f(x)f(x+T)=f(x) 对所有 xxx 成立。如 sin⁡x\sin xsinx 的周期为 2π2\pi2π。


function detectSymmetry(f: (x: number) => number, testPoints: number[], epsilon = 1e-10): 'even' | 'odd' | 'neither' {
  let isEven = true;
  let isOdd = true;

  for (const x of testPoints) {
    if (x === 0) continue;
    const fx = f(x);
    const fNegX = f(-x);
    if (Math.abs(fx - fNegX) > epsilon) isEven = false;
    if (Math.abs(fx + fNegX) > epsilon) isOdd = false;
    if (!isEven && !isOdd) return 'neither';
  }

  if (isEven) return 'even';
  if (isOdd) return 'odd';
  return 'neither';
}

function detectPeriod(
  f: (x: number) => number,
  searchRange: number,
  resolution: number,
  epsilon = 1e-8,
): number | null {
  for (let t = resolution; t <= searchRange; t += resolution) {
    let isPeriodic = true;
    for (let x = -10; x <= 10; x += 0.5) {
      if (Math.abs(f(x + t) - f(x)) > epsilon) {
        isPeriodic = false;
        break;
      }
    }
    if (isPeriodic) return t;
  }
  return null;
}

小结
    

  • 函数是从定义域到陪域的确定性映射，与编程中的纯函数概念一致
    • 

  • 单射、满射、双射分类决定了函数的可逆性和映射性质
    • 

  • 函数复合是函数式编程的基石，满足结合律但不满足交换律
    • 

  • 双射函数有唯一逆函数，对应编码/解码、加密/解密等可逆操作
    • 

  • 单调性保证了区间上的单射性，是二分查找等算法的前提条件
    • 

  • 奇偶性和周期性可将计算量减半或限制在一个周期内，是性能优化的数学基础
    • 

  • 理解函数的数学性质，能帮助程序员设计更可靠、更高效的代码
