函数变换

核心概念

函数变换是通过对函数进行平移、缩放、反射等操作来改变其图像形态的技术。理解函数变换意味着你可以从一个"基础函数"出发，通过一系列变换得到任意复杂的函数图像——这就像 CSS transform 通过 translate、scale、rotate 变换基础元素一样。

函数变换在编程中的应用包括：图形渲染中的坐标变换、信号处理中的频谱变换、动画系统中的缓动函数（easing functions）、数据标准化和归一化。

平移变换
平移是最直观的变换：将图像沿某个方向移动固定距离，不改变形状和大小。


水平平移：f(x)→f(x−h)f(x) \to f(x - h)f(x)→f(x−h)


注意反直觉的地方——f(x−3)f(x - 3)f(x−3) 是将图像向右移 3 个单位（减去正数反而右移）。原因：要让新函数在 x=3x = 3x=3 处的值等于原函数在 x=0x = 0x=0 处的值，就需要 f(3−3)=f(0)f(3 - 3) = f(0)f(3−3)=f(0)。


垂直平移：f(x)→f(x)+kf(x) \to f(x) + kf(x)→f(x)+k


这个比较符合直觉——+k+k+k 就是上移 kkk 个单位。


type MathFn = (x: number) => number;

function horizontalShift(f: MathFn, h: number): MathFn {
  return (x: number) => f(x - h);
}

function verticalShift(f: MathFn, k: number): MathFn {
  return (x: number) => f(x) + k;
}

function translate(f: MathFn, h: number, k: number): MathFn {
  return (x: number) => f(x - h) + k;
}

const baseParabola: MathFn = (x) => x * x;
const shifted = translate(baseParabola, 3, -2);
console.log(shifted(3));
console.log(shifted(0));
平移变换在图形编程中的经典应用——将局部坐标系变换为世界坐标系：


interface Point {
  x: number;
  y: number;
}

function translatePoint(p: Point, dx: number, dy: number): Point {
  return { x: p.x + dx, y: p.y + dy };
}

function translatePath(path: Point[], dx: number, dy: number): Point[] {
  return path.map((p) => translatePoint(p, dx, dy));
}

function centerOnOrigin(points: Point[]): {
  centered: Point[];
  offset: Point;
} {
  const cx = points.reduce((s, p) => s + p.x, 0) / points.length;
  const cy = points.reduce((s, p) => s + p.y, 0) / points.length;
  return {
    centered: translatePath(points, -cx, -cy),
    offset: { x: cx, y: cy },
  };
}
缩放变换
缩放改变函数图像的"拉伸"程度。


垂直缩放：f(x)→a⋅f(x)f(x) \to a \cdot f(x)f(x)→a⋅f(x)


    

  • ∣a∣>1|a| > 1∣a∣>1：纵向拉伸
    • 

  • 0<∣a∣<10 < |a| < 10<∣a∣<1：纵向压缩
    • 

  • a<0a < 0a<0：同时关于 xxx 轴反射
    • 



水平缩放：f(x)→f(bx)f(x) \to f(bx)f(x)→f(bx)


    

  • ∣b∣>1|b| > 1∣b∣>1：水平压缩（图像变窄）
    • 

  • 0<∣b∣<10 < |b| < 10<∣b∣<1：水平拉伸（图像变宽）
    • 



同样反直觉——f(2x)f(2x)f(2x) 是将图像水平压缩到一半宽度，而不是拉伸。


function verticalScale(f: MathFn, a: number): MathFn {
  return (x: number) => a * f(x);
}

function horizontalScale(f: MathFn, b: number): MathFn {
  return (x: number) => f(b * x);
}

function normalize(f: MathFn, domain: [number, number], samples: number = 1000): MathFn {
  const dx = (domain[1] - domain[0]) / samples;
  let maxVal = -Infinity;
  let minVal = Infinity;

  for (let i = 0; i <= samples; i++) {
    const x = domain[0] + i * dx;
    const y = f(x);
    if (y > maxVal) maxVal = y;
    if (y < minVal) minVal = y;
  }

  const range = maxVal - minVal;
  if (range === 0) return () => 0;

  return (x: number) => (f(x) - minVal) / range;
}
数据标准化——将任意范围的数据缩放到 [0,1][0, 1][0,1] 区间：


xnorm=x−xmin⁡xmax⁡−xmin⁡x_{\text{norm}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}xnorm​=xmax​−xmin​x−xmin​​
这就是垂直缩放 + 垂直平移的组合。机器学习中的特征标准化、图像处理中的像素归一化都是这一操作的应用。


反射变换
反射是缩放因子为 −1-1−1 的特殊情况。


关于 xxx 轴反射：f(x)→−f(x)f(x) \to -f(x)f(x)→−f(x)（所有 yyy 值取反）


关于 yyy 轴反射：f(x)→f(−x)f(x) \to f(-x)f(x)→f(−x)（所有 xxx 值取反）


关于原点反射：f(x)→−f(−x)f(x) \to -f(-x)f(x)→−f(−x)（同时反射两个轴）


function reflectX(f: MathFn): MathFn {
  return (x: number) => -f(x);
}

function reflectY(f: MathFn): MathFn {
  return (x: number) => f(-x);
}

function reflectOrigin(f: MathFn): MathFn {
  return (x: number) => -f(-x);
}
反射与函数的奇偶性直接相关：


    

  • 偶函数 f(−x)=f(x)f(-x) = f(x)f(−x)=f(x)：关于 yyy 轴反射后不变
    • 

  • 奇函数 f(−x)=−f(x)f(-x) = -f(x)f(−x)=−f(x)：关于原点反射后不变
    • 



在图形编程中，反射变换常用于创建对称图案、镜像效果和物理模拟中的弹性碰撞。


function createMirrorPattern(f: MathFn, axis: 'x' | 'y' | 'origin'): MathFn {
  switch (axis) {
    case 'x':
      return (x: number) => (x >= 0 ? f(x) : -f(-x));
    case 'y':
      return (x: number) => f(Math.abs(x));
    case 'origin':
      return (x: number) => (x >= 0 ? f(x) : -f(-x));
  }
}
复合变换与变换顺序
实际应用中通常需要多个变换的组合。一般形式为：


g(x)=a⋅f(b(x−h))+kg(x) = a \cdot f(b(x - h)) + kg(x)=a⋅f(b(x−h))+k
变换的执行顺序至关重要——不同顺序会产生不同结果。推荐的思考顺序（从内到外）：


    

  1. 水平平移：x→x−hx \to x - hx→x−h
    2. 

  2. 水平缩放：x→bxx \to bxx→bx
    3. 

  3. 应用原函数：f(⋅)f(\cdot)f(⋅)
    4. 

  4. 垂直缩放：⋅→a⋅\cdot \to a \cdot⋅→a⋅
    5. 

  5. 垂直平移：⋅→⋅+k\cdot \to \cdot + k⋅→⋅+k
    6. 



interface TransformParams {
  horizontalShift: number;
  horizontalScale: number;
  verticalScale: number;
  verticalShift: number;
}

function applyTransform(f: MathFn, params: TransformParams): MathFn {
  return (x: number) => {
    const shifted = x - params.horizontalShift;
    const scaled = shifted * params.horizontalScale;
    const base = f(scaled);
    return params.verticalScale * base + params.verticalShift;
  };
}

function composeTransforms(...transforms: Array<(f: MathFn) => MathFn>): (f: MathFn) => MathFn {
  return (f: MathFn) => transforms.reduce((current, transform) => transform(current), f);
}

const transformSin = applyTransform(Math.sin, {
  horizontalShift: Math.PI / 4,
  horizontalScale: 2,
  verticalScale: 3,
  verticalShift: 1,
});
变换矩阵表示——在图形学中，仿射变换可以用矩阵统一表示：


type Matrix3 = [[number, number, number], [number, number, number], [number, number, number]];

function identityMatrix(): Matrix3 {
  return [
    [1, 0, 0],
    [0, 1, 0],
    [0, 0, 1],
  ];
}

function translationMatrix(tx: number, ty: number): Matrix3 {
  return [
    [1, 0, tx],
    [0, 1, ty],
    [0, 0, 1],
  ];
}

function scalingMatrix(sx: number, sy: number): Matrix3 {
  return [
    [sx, 0, 0],
    [0, sy, 0],
    [0, 0, 1],
  ];
}

function multiplyMatrices(a: Matrix3, b: Matrix3): Matrix3 {
  const result: Matrix3 = [
    [0, 0, 0],
    [0, 0, 0],
    [0, 0, 1],
  ];
  for (let i = 0; i < 3; i++) {
    for (let j = 0; j < 3; j++) {
      result[i][j] = 0;
      for (let k = 0; k < 3; k++) {
        result[i][j] += a[i][k] * b[k][j];
      }
    }
  }
  return result;
}

function transformPoint(m: Matrix3, p: Point): Point {
  return {
    x: m[0][0] * p.x + m[0][1] * p.y + m[0][2],
    y: m[1][0] * p.x + m[1][1] * p.y + m[1][2],
  };
}
使用矩阵的优势：多个变换可以预先相乘为一个矩阵，然后对大量点批量应用——这正是 GPU 渲染管线的核心思想。


缓动函数与动画变换
缓动函数（Easing Functions）是函数变换在 UI 动画中的直接应用。它们将线性的时间进度 t∈[0,1]t \in [0, 1]t∈[0,1] 映射为非线性的动画进度，使运动更自然。


const easing = {
  linear: (t: number) => t,

  easeInQuad: (t: number) => t * t,
  easeOutQuad: (t: number) => t * (2 - t),
  easeInOutQuad: (t: number) => (t < 0.5 ? 2 * t * t : -1 + (4 - 2 * t) * t),

  easeInCubic: (t: number) => t * t * t,
  easeOutCubic: (t: number) => --t * t * t + 1,

  easeInExpo: (t: number) => (t === 0 ? 0 : Math.pow(2, 10 * (t - 1))),
  easeOutExpo: (t: number) => (t === 1 ? 1 : 1 - Math.pow(2, -10 * t)),

  easeOutBounce: (t: number) => {
    if (t < 1 / 2.75) return 7.5625 * t * t;
    if (t < 2 / 2.75) return 7.5625 * (t -= 1.5 / 2.75) * t + 0.75;
    if (t < 2.5 / 2.75) return 7.5625 * (t -= 2.25 / 2.75) * t + 0.9375;
    return 7.5625 * (t -= 2.625 / 2.75) * t + 0.984375;
  },
};

function animate(
  from: number,
  to: number,
  duration: number,
  easingFn: MathFn,
  onUpdate: (value: number) => void,
): void {
  const startTime = performance.now();

  function frame(currentTime: number) {
    const elapsed = currentTime - startTime;
    const t = Math.min(elapsed / duration, 1);
    const easedT = easingFn(t);
    const value = from + (to - from) * easedT;
    onUpdate(value);
    if (t < 1) requestAnimationFrame(frame);
  }

  requestAnimationFrame(frame);
}
缓动函数之间的关系就是函数变换：


    

  • easeOut 是 easeIn 关于 (0.5,0.5)(0.5, 0.5)(0.5,0.5) 点的中心反射：easeOut(t) = 1 - easeIn(1 - t)
    • 

  • easeInOut 是前半段用 easeIn 的压缩版，后半段用 easeOut 的压缩版
    •

小结
    

  • 函数变换包括平移、缩放、反射三类基本操作，任意组合可生成复杂变换
    • 

  • 水平变换的方向与直觉相反：f(x−h)f(x-h)f(x−h) 是右移，f(2x)f(2x)f(2x) 是压缩
    • 

  • 复合变换的顺序影响结果，推荐从内到外（水平平移→水平缩放→原函数→垂直缩放→垂直平移）
    • 

  • 仿射变换可用矩阵统一表示，多个变换预乘为一个矩阵后批量应用——GPU 渲染的核心思想
    • 

  • 数据标准化（归一化到 [0,1][0,1][0,1]）本质上是缩放 + 平移变换的组合
    • 

  • 缓动函数是函数变换在 UI 动画中的直接应用，easeOut 是 easeIn 的反射变换
    • 

  • 掌握函数变换后，任何新函数都可以视为基函数 + 变换的组合，极大简化理解和分析
    •
