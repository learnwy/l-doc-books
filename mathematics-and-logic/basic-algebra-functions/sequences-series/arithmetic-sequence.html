等差数列

核心概念

等差数列（Arithmetic Sequence）是最基本的数列类型：每相邻两项的差为常数 ddd（公差）。形式化定义：数列 {an}\{a_n\}{an​} 满足 an+1−an=da_{n+1} - a_n = dan+1​−an​=d（ddd 为常数）。

等差数列描述的是均匀增长/衰减的模式——每步增加（或减少）相同的量。在编程中，for (let i = 0; i < n; i++) 产生的索引序列 0,1,2,…,n−10, 1, 2, \ldots, n-10,1,2,…,n−1 就是最简单的等差数列（公差为 1）。

等差数列在算法分析中的核心应用：循环的迭代次数、嵌套循环的总操作数、内存分页的地址偏移。

通项公式与高斯求和
通项公式 an=a1+(n−1)da_n = a_1 + (n-1)dan​=a1​+(n−1)d 本质上是一次函数 f(n)=dn+(a1−d)f(n) = dn + (a_1 - d)f(n)=dn+(a1​−d)，其图像是一条直线。这意味着等差数列的增长是线性的。


前 nnn 项和 Sn=n(a1+an)2S_n = \frac{n(a_1 + a_n)}{2}Sn​=2n(a1​+an​)​ 的推导有一个著名的故事：年幼的高斯将 1+2+⋯+1001 + 2 + \cdots + 1001+2+⋯+100 的求和转化为 50×101=505050 \times 101 = 505050×101=5050——首尾配对，每对之和相等。


interface ArithmeticSequence {
  first: number;
  diff: number;
}

function nthTerm(seq: ArithmeticSequence, n: number): number {
  return seq.first + (n - 1) * seq.diff;
}

function sumOfTerms(seq: ArithmeticSequence, n: number): number {
  const last = nthTerm(seq, n);
  return (n * (seq.first + last)) / 2;
}

function gaussSum(n: number): number {
  return (n * (n + 1)) / 2;
}

function fromTwoTerms(n1: number, a1: number, n2: number, a2: number): ArithmeticSequence {
  const diff = (a2 - a1) / (n2 - n1);
  const first = a1 - (n1 - 1) * diff;
  return { first, diff };
}

function findTermIndex(seq: ArithmeticSequence, value: number): number | null {
  if (seq.diff === 0) {
    return value === seq.first ? 1 : null;
  }
  const n = (value - seq.first) / seq.diff + 1;
  if (n < 1 || !Number.isInteger(n)) return null;
  return n;
}

等差数列在循环分析中的应用
嵌套循环中的总操作数常常可以表示为等差数列求和。


选择排序的比较次数：


function selectionSortComparisons(n: number): number {
  return n - 1 + (n - 2) + (n - 3) + 1;
}
这是公差为 −1-1−1 的等差数列 n−1,n−2,…,1n-1, n-2, \ldots, 1n−1,n−2,…,1 的求和：


S=(n−1)⋅n2=n2−n2S = \frac{(n-1) \cdot n}{2} = \frac{n^2 - n}{2}S=2(n−1)⋅n​=2n2−n​
因此选择排序的比较次数为 O(n2)O(n^2)O(n2)。


function analyzeNestedLoop(n: number): {
  innerCounts: number[];
  total: number;
  isArithmetic: boolean;
} {
  const innerCounts: number[] = [];
  let total = 0;

  for (let i = 0; i < n; i++) {
    let count = 0;
    for (let j = i; j < n; j++) {
      count++;
    }
    innerCounts.push(count);
    total += count;
  }

  let isArithmetic = true;
  if (innerCounts.length >= 3) {
    const d = innerCounts[1] - innerCounts[0];
    for (let i = 2; i < innerCounts.length; i++) {
      if (innerCounts[i] - innerCounts[i - 1] !== d) {
        isArithmetic = false;
        break;
      }
    }
  }

  return { innerCounts, total, isArithmetic };
}

function sumArithmeticRange(start: number, end: number, step: number): number {
  if (step === 0) throw new Error('Step cannot be zero');
  const n = Math.floor((end - start) / step) + 1;
  if (n <= 0) return 0;
  const last = start + (n - 1) * step;
  return (n * (start + last)) / 2;
}

等差数列的判定与生成
判定一个数列是否为等差数列，只需检查相邻项之差是否恒定：


function isArithmeticSequence(values: number[], epsilon = 1e-10): { isAP: boolean; diff?: number } {
  if (values.length < 2) return { isAP: true };
  const diff = values[1] - values[0];
  for (let i = 2; i < values.length; i++) {
    if (Math.abs(values[i] - values[i - 1] - diff) > epsilon) {
      return { isAP: false };
    }
  }
  return { isAP: true, diff };
}

function* arithmeticGenerator(first: number, diff: number): Generator<number> {
  let current = first;
  while (true) {
    yield current;
    current += diff;
  }
}

function arithmeticRange(start: number, end: number, step: number): number[] {
  const result: number[] = [];
  if (step > 0) {
    for (let x = start; x <= end + 1e-10; x += step) {
      result.push(x);
    }
  } else if (step < 0) {
    for (let x = start; x >= end - 1e-10; x += step) {
      result.push(x);
    }
  }
  return result;
}
等差数列的实际应用
应用一：分页与偏移量计算


function paginationOffsets(pageSize: number, totalPages: number): number[] {
  const offsets: number[] = [];
  for (let page = 0; page < totalPages; page++) {
    offsets.push(page * pageSize);
  }
  return offsets;
}

function addressSequence(base: number, stride: number, count: number): number[] {
  return Array.from({ length: count }, (_, i) => base + i * stride);
}
应用二：等距采样与插值


function linspace(start: number, end: number, count: number): number[] {
  if (count <= 1) return [start];
  const step = (end - start) / (count - 1);
  return Array.from({ length: count }, (_, i) => start + i * step);
}

function resample(data: number[], targetCount: number): number[] {
  const result: number[] = [];
  const step = (data.length - 1) / (targetCount - 1);
  for (let i = 0; i < targetCount; i++) {
    const pos = i * step;
    const lo = Math.floor(pos);
    const hi = Math.min(lo + 1, data.length - 1);
    const t = pos - lo;
    result.push(data[lo] * (1 - t) + data[hi] * t);
  }
  return result;
}

function trapezoidalRule(f: (x: number) => number, a: number, b: number, n: number): number {
  const h = (b - a) / n;
  let sum = (f(a) + f(b)) / 2;
  for (let i = 1; i < n; i++) {
    sum += f(a + i * h);
  }
  return sum * h;
}
小结
    

  • 等差数列以恒定公差 ddd 增长，通项 an=a1+(n−1)da_n = a_1 + (n-1)dan​=a1​+(n−1)d 是 nnn 的一次函数
    • 

  • 前 nnn 项和 Sn=n(a1+an)/2S_n = n(a_1 + a_n)/2Sn​=n(a1​+an​)/2 是 nnn 的二次函数，即高斯求和公式
    • 

  • 嵌套循环的总操作数常为等差数列求和，这解释了为什么许多双重循环是 O(n2)O(n^2)O(n2)
    • 

  • for 循环索引、分页偏移、等距采样点都是等差数列的直接应用
    • 

  • linspace 函数（等距生成）是数值计算和数据可视化的基础工具
