数学归纳法

核心概念

数学归纳法（Mathematical Induction）是证明与自然数有关命题的标准方法。它的逻辑结构类似于多米诺骨牌：证明第一个命题成立（基础步），然后证明"如果第 kkk 个成立，则第 k+1k+1k+1 个也成立"（归纳步）。

对程序员而言，数学归纳法不仅是证明工具——它与递归算法的正确性证明完全对应。每个递归函数的正确性证明本质上都是一个归纳证明：基础情形对应递归的 base case，归纳步对应递归调用。

弱归纳法
弱归纳法（也称普通数学归纳法）的证明框架：


    

  1. 基础步（Base Case）：证明 P(n0)P(n_0)P(n0​) 成立（通常 n0=0n_0 = 0n0​=0 或 111）
    2. 

  2. 归纳假设（Inductive Hypothesis）：假设 P(k)P(k)P(k) 对某个 k≥n0k \geq n_0k≥n0​ 成立
    3. 

  3. 归纳步（Inductive Step）：在假设 P(k)P(k)P(k) 的前提下，证明 P(k+1)P(k+1)P(k+1) 成立
    4.

function gaussSumRecursive(n: number): number {
  if (n <= 0) return 0;
  return n + gaussSumRecursive(n - 1);
}

function gaussSumFormula(n: number): number {
  return (n * (n + 1)) / 2;
}

function verifyInduction(
  property: (n: number) => boolean,
  base: number,
  maxN: number,
): { allValid: boolean; failedAt?: number } {
  for (let n = base; n <= maxN; n++) {
    if (!property(n)) {
      return { allValid: false, failedAt: n };
    }
  }
  return { allValid: true };
}

const gaussProperty = (n: number) => {
  const sum = Array.from({ length: n }, (_, i) => i + 1).reduce((s, v) => s + v, 0);
  return sum === (n * (n + 1)) / 2;
};

console.log(verifyInduction(gaussProperty, 1, 1000));

强归纳法
强归纳法（Complete Induction）的区别在于：归纳假设不仅假设 P(k)P(k)P(k) 成立，而是假设 P(n0),P(n0+1),…,P(k)P(n_0), P(n_0+1), \ldots, P(k)P(n0​),P(n0​+1),…,P(k) 全部成立。


这在需要"回溯多步"的证明中特别有用。


经典例子：证明每个大于 1 的整数都能分解为质因数的乘积（算术基本定理的存在性部分）。


    

  • 基础步：n=2n = 2n=2 是质数，本身即为质因数分解。
    • 

  • 归纳步：假设所有 2≤m≤k2 \leq m \leq k2≤m≤k 都有质因数分解。对于 k+1k + 1k+1：
      

    • 若 k+1k + 1k+1 是质数，本身即为分解。
      • 

    • 若 k+1k + 1k+1 是合数，则 k+1=a⋅bk + 1 = a \cdot bk+1=a⋅b（2≤a,b≤k2 \leq a, b \leq k2≤a,b≤k），由归纳假设 aaa 和 bbb 各有分解，乘起来即可。
      • 

    

    • 



function primeFactorization(n: number): number[] {
  if (n <= 1) return [];

  const factors: number[] = [];
  let remaining = n;

  for (let p = 2; p * p <= remaining; p++) {
    while (remaining % p === 0) {
      factors.push(p);
      remaining /= p;
    }
  }

  if (remaining > 1) {
    factors.push(remaining);
  }

  return factors;
}

function verifyFundamentalTheorem(maxN: number): boolean {
  for (let n = 2; n <= maxN; n++) {
    const factors = primeFactorization(n);
    const product = factors.reduce((p, f) => p * f, 1);
    if (product !== n) return false;
    if (!factors.every(isPrime)) return false;
  }
  return true;
}

function isPrime(n: number): boolean {
  if (n < 2) return false;
  for (let i = 2; i * i <= n; i++) {
    if (n % i === 0) return false;
  }
  return true;
}
强归纳法在分治算法中的应用——归并排序的正确性证明：


    

  • 基础步：长度为 1 的数组已排序。
    • 

  • 归纳步：假设对所有长度 <k< k<k 的数组，归并排序正确。对长度为 kkk 的数组，分成两个长度 <k< k<k 的子数组（由归纳假设，它们被正确排序），合并两个有序数组的正确性由合并过程保证。
    • 



function mergeSort(arr: number[]): number[] {
  if (arr.length <= 1) return arr;

  const mid = Math.floor(arr.length / 2);
  const left = mergeSort(arr.slice(0, mid));
  const right = mergeSort(arr.slice(mid));

  return merge(left, right);
}

function merge(left: number[], right: number[]): number[] {
  const result: number[] = [];
  let i = 0;
  let j = 0;

  while (i < left.length && j < right.length) {
    if (left[i] <= right[j]) {
      result.push(left[i++]);
    } else {
      result.push(right[j++]);
    }
  }

  while (i < left.length) result.push(left[i++]);
  while (j < right.length) result.push(right[j++]);

  return result;
}
结构归纳法
结构归纳法（Structural Induction）将归纳推广到递归定义的数据结构上：树、链表、表达式等。


    

  • 基础步：证明性质对最小的结构（叶节点、空列表）成立。
    • 

  • 归纳步：假设性质对所有子结构成立，证明对由子结构构建的更大结构也成立。
    • 



例子：证明满二叉树的叶节点数 = 内部节点数 + 1。


type BinaryTree<T> = { type: 'leaf'; value: T } | { type: 'node'; value: T; left: BinaryTree<T>; right: BinaryTree<T> };

function countLeaves<T>(tree: BinaryTree<T>): number {
  if (tree.type === 'leaf') return 1;
  return countLeaves(tree.left) + countLeaves(tree.right);
}

function countInternal<T>(tree: BinaryTree<T>): number {
  if (tree.type === 'leaf') return 0;
  return 1 + countInternal(tree.left) + countInternal(tree.right);
}

function verifyLeafProperty<T>(tree: BinaryTree<T>): boolean {
  return countLeaves(tree) === countInternal(tree) + 1;
}

function treeHeight<T>(tree: BinaryTree<T>): number {
  if (tree.type === 'leaf') return 0;
  return 1 + Math.max(treeHeight(tree.left), treeHeight(tree.right));
}

function maxNodesAtHeight(h: number): number {
  return Math.pow(2, h + 1) - 1;
}
证明过程：


    

  • 基础步：单个叶节点。叶节点数 = 1，内部节点数 = 0。1=0+11 = 0 + 11=0+1，成立。
    • 

  • 归纳步：假设左子树有 lll 个叶和 l−1l - 1l−1 个内部节点，右子树有 rrr 个叶和 r−1r - 1r−1 个内部节点。整棵树有 l+rl + rl+r 个叶和 (l−1)+(r−1)+1=l+r−1(l - 1) + (r - 1) + 1 = l + r - 1(l−1)+(r−1)+1=l+r−1 个内部节点。l+r=(l+r−1)+1l + r = (l + r - 1) + 1l+r=(l+r−1)+1，成立。
    • 



循环不变量与归纳
循环不变量（Loop Invariant）是程序正确性证明的核心工具，其结构完全对应数学归纳法：


    

  • 初始化（= 基础步）：循环开始前，不变量成立
    • 

  • 保持（= 归纳步）：如果某次迭代前不变量成立，则该次迭代后仍成立
    • 

  • 终止：循环结束时，不变量 + 终止条件 → 程序正确性
    • 



function binarySearchWithInvariant(arr: number[], target: number): number {
  let lo = 0;
  let hi = arr.length - 1;

  while (lo <= hi) {
    const mid = lo + Math.floor((hi - lo) / 2);
    if (arr[mid] === target) return mid;
    if (arr[mid] < target) {
      lo = mid + 1;
    } else {
      hi = mid - 1;
    }
  }

  return -1;
}

function insertionSortWithInvariant(arr: number[]): number[] {
  const result = [...arr];

  for (let i = 1; i < result.length; i++) {
    const key = result[i];
    let j = i - 1;

    while (j >= 0 && result[j] > key) {
      result[j + 1] = result[j];
      j--;
    }
    result[j + 1] = key;
  }

  return result;
}
二分查找的循环不变量：如果 target 存在于原数组中，则它位于 arr[lo..hi] 范围内。

归纳法的常见陷阱
陷阱一：基础步缺失或错误


"证明"所有马都是同一颜色的错误归纳：归纳步中假设 nnn 匹马同色，取走一匹加一匹，但基础步从 n=1n = 1n=1 到 n=2n = 2n=2 时逻辑断裂——两匹马未必有公共马来"传递"颜色。


陷阱二：归纳步中的隐含假设


归纳步必须对所有 k≥n0k \geq n_0k≥n0​ 成立，不能只对部分 kkk 成立。


function validateInductionProof(
  baseValue: number,
  baseCheck: (n: number) => boolean,
  stepCheck: (k: number) => boolean,
  testRange: number,
): {
  baseValid: boolean;
  stepValid: boolean;
  counterExample?: number;
} {
  const baseValid = baseCheck(baseValue);
  let stepValid = true;
  let counterExample: number | undefined;

  for (let k = baseValue; k < baseValue + testRange; k++) {
    if (!stepCheck(k)) {
      stepValid = false;
      counterExample = k;
      break;
    }
  }

  return { baseValid, stepValid, counterExample };
}
陷阱三：归纳与递归的终止性


归纳证明假设自然数的良序性（任何非空子集有最小元），但递归程序必须确保参数严格减小才能终止。无限递归 = 归纳链断裂。

小结
    

  • 数学归纳法通过"基础步 + 归纳步"证明对所有自然数成立的命题
    • 

  • 弱归纳假设 P(k)P(k)P(k)，适用于线性递推；强归纳假设 P(1)P(1)P(1) 到 P(k)P(k)P(k) 全部成立，适用于分治问题
    • 

  • 结构归纳法将归纳推广到递归定义的数据结构（树、列表等）
    • 

  • 归纳法与递归算法完全对应：基础步 = base case，归纳步 = 递归调用
    • 

  • 循环不变量是归纳法在迭代算法中的应用：初始化 = 基础步，保持 = 归纳步
    • 

  • 常见陷阱包括基础步缺失、隐含假设和终止性问题——程序中的 off-by-one 错误和无限递归都源于此
    • 

  • 掌握归纳法思维，是理解和证明算法正确性的核心能力
    •
