等比数列

核心概念

等比数列（Geometric Sequence）是另一种基本数列类型：每相邻两项的比为常数 rrr（公比）。形式化定义：数列 {an}\{a_n\}{an​} 满足 an+1/an=ra_{n+1}/a_n = ran+1​/an​=r（r≠0r \neq 0r=0 为常数）。

如果说等差数列描述"均匀加减"，等比数列则描述"均匀乘除"——指数式增长/衰减。在计算机科学中，等比数列无处不在：二分法的搜索空间每步减半（r=1/2r = 1/2r=1/2）、动态数组的扩容策略（r=2r = 2r=2）、指数退避算法、利率计算。

通项公式与指数增长
通项公式 an=a1⋅rn−1a_n = a_1 \cdot r^{n-1}an​=a1​⋅rn−1 是指数函数 f(n)=a1⋅rn−1f(n) = a_1 \cdot r^{n-1}f(n)=a1​⋅rn−1 的离散版本。当 ∣r∣>1|r| > 1∣r∣>1 时呈指数增长，当 ∣r∣<1|r| < 1∣r∣<1 时呈指数衰减。


interface GeometricSequence {
  first: number;
  ratio: number;
}

function nthTermGP(seq: GeometricSequence, n: number): number {
  return seq.first * Math.pow(seq.ratio, n - 1);
}

function sumGP(seq: GeometricSequence, n: number): number {
  if (Math.abs(seq.ratio - 1) < 1e-15) {
    return seq.first * n;
  }
  return (seq.first * (1 - Math.pow(seq.ratio, n))) / (1 - seq.ratio);
}

function infiniteSumGP(seq: GeometricSequence): number | null {
  if (Math.abs(seq.ratio) >= 1) return null;
  return seq.first / (1 - seq.ratio);
}

function isGeometricSequence(values: number[], epsilon = 1e-10): { isGP: boolean; ratio?: number } {
  if (values.length < 2) return { isGP: true };
  if (values.some((v) => v === 0)) return { isGP: false };
  const ratio = values[1] / values[0];
  for (let i = 2; i < values.length; i++) {
    if (Math.abs(values[i] / values[i - 1] - ratio) > epsilon) {
      return { isGP: false };
    }
  }
  return { isGP: true, ratio };
}

动态数组的扩容分析
动态数组（如 JavaScript 的 Array、Java 的 ArrayList）使用等比数列策略扩容：容量不足时，将底层数组大小乘以一个因子（通常为 2）。


为什么扩容因子选 2？这保证了 nnn 次插入的摊还复杂度为 O(1)O(1)O(1)。


class DynamicArray<T> {
  private data: (T | undefined)[];
  private length: number;
  private capacity: number;
  private readonly growthFactor: number;
  private totalCopies: number;

  constructor(initialCapacity = 1, growthFactor = 2) {
    this.data = new Array(initialCapacity);
    this.length = 0;
    this.capacity = initialCapacity;
    this.growthFactor = growthFactor;
    this.totalCopies = 0;
  }

  push(value: T): void {
    if (this.length === this.capacity) {
      this.resize();
    }
    this.data[this.length++] = value;
  }

  private resize(): void {
    const newCapacity = Math.ceil(this.capacity * this.growthFactor);
    const newData = new Array(newCapacity);
    for (let i = 0; i < this.length; i++) {
      newData[i] = this.data[i];
      this.totalCopies++;
    }
    this.data = newData;
    this.capacity = newCapacity;
  }

  getStats(): { length: number; capacity: number; totalCopies: number } {
    return {
      length: this.length,
      capacity: this.capacity,
      totalCopies: this.totalCopies,
    };
  }
}
摊还分析：插入 nnn 个元素，扩容发生在容量为 1,2,4,8,…,2k1, 2, 4, 8, \ldots, 2^k1,2,4,8,…,2k（2k≤n2^k \leq n2k≤n）时。总复制次数为：


1+2+4+8+⋯+2k=2k+1−1<2n1 + 2 + 4 + 8 + \cdots + 2^k = 2^{k+1} - 1 < 2n1+2+4+8+⋯+2k=2k+1−1<2n
因此 nnn 次插入的总复制成本 <2n< 2n<2n，每次插入的摊还复制成本 <2< 2<2，即 O(1)O(1)O(1)。


这正是等比数列求和公式的直接应用：Sk=2k+1−12−1=2k+1−1S_k = \frac{2^{k+1} - 1}{2 - 1} = 2^{k+1} - 1Sk​=2−12k+1−1​=2k+1−1。


指数退避算法
网络编程中的指数退避（Exponential Backoff）让重试间隔按等比数列增长，避免在高负载时大量客户端同时重试造成"惊群效应"。


interface BackoffConfig {
  baseDelay: number;
  maxDelay: number;
  factor: number;
  maxRetries: number;
  jitter: boolean;
}

function calculateBackoffDelay(attempt: number, config: BackoffConfig): number {
  const delay = config.baseDelay * Math.pow(config.factor, attempt);
  const capped = Math.min(delay, config.maxDelay);
  if (config.jitter) {
    return capped * (0.5 + Math.random() * 0.5);
  }
  return capped;
}

async function retryWithBackoff<T>(fn: () => Promise<T>, config: BackoffConfig): Promise<T> {
  let lastError: unknown;

  for (let attempt = 0; attempt <= config.maxRetries; attempt++) {
    try {
      return await fn();
    } catch (error) {
      lastError = error;
      if (attempt < config.maxRetries) {
        const delay = calculateBackoffDelay(attempt, config);
        await new Promise((resolve) => setTimeout(resolve, delay));
      }
    }
  }

  throw lastError;
}

const defaultConfig: BackoffConfig = {
  baseDelay: 100,
  maxDelay: 30000,
  factor: 2,
  maxRetries: 5,
  jitter: true,
};

等比数列在金融计算中的应用
复利计算——最经典的等比数列应用：


本金 PPP，年利率 rrr，nnn 年后的金额：A=P(1+r)nA = P(1 + r)^nA=P(1+r)n


每年的余额 P,P(1+r),P(1+r)2,…P, P(1+r), P(1+r)^2, \ldotsP,P(1+r),P(1+r)2,… 构成公比为 (1+r)(1+r)(1+r) 的等比数列。


function compoundInterest(principal: number, annualRate: number, years: number, compoundsPerYear: number = 1): number {
  const r = annualRate / compoundsPerYear;
  const n = years * compoundsPerYear;
  return principal * Math.pow(1 + r, n);
}

function presentValue(futureValue: number, annualRate: number, years: number): number {
  return futureValue / Math.pow(1 + annualRate, years);
}

function annuityPayment(principal: number, annualRate: number, months: number): number {
  const r = annualRate / 12;
  if (r === 0) return principal / months;
  return (principal * r * Math.pow(1 + r, months)) / (Math.pow(1 + r, months) - 1);
}

function loanAmortization(
  principal: number,
  annualRate: number,
  months: number,
): Array<{ month: number; payment: number; interest: number; principal: number; balance: number }> {
  const monthlyPayment = annuityPayment(principal, annualRate, months);
  const r = annualRate / 12;
  let balance = principal;
  const schedule: Array<{
    month: number;
    payment: number;
    interest: number;
    principal: number;
    balance: number;
  }> = [];

  for (let m = 1; m <= months; m++) {
    const interest = balance * r;
    const principalPaid = monthlyPayment - interest;
    balance -= principalPaid;
    schedule.push({
      month: m,
      payment: monthlyPayment,
      interest,
      principal: principalPaid,
      balance: Math.max(0, balance),
    });
  }
  return schedule;
}

function geometricSeriesPartial(first: number, ratio: number, terms: number): number {
  if (Math.abs(ratio - 1) < 1e-15) return first * terms;
  return (first * (1 - Math.pow(ratio, terms))) / (1 - ratio);
}

function geometricSeriesInfinite(first: number, ratio: number): number {
  if (Math.abs(ratio) >= 1) throw new Error('Series diverges: |r| >= 1');
  return first / (1 - ratio);
}

function repeatingDecimalToFraction(
  nonRepeating: string,
  repeating: string,
): { numerator: number; denominator: number } {
  const nr = nonRepeating || '0';
  const nrLen = nr.length - (nr.indexOf('.') >= 0 ? nr.indexOf('.') + 1 : 0);
  const rLen = repeating.length;

  const base = parseFloat(nr + repeating) * Math.pow(10, nrLen);
  const shifted = parseFloat(nr + repeating) * Math.pow(10, nrLen + rLen);

  const numerator = Math.round(shifted - base);
  const denominator = Math.pow(10, rLen) - 1;

  const g = gcd(Math.abs(numerator), denominator);
  return {
    numerator: numerator / g,
    denominator: denominator / g,
  };
}

function gcd(a: number, b: number): number {
  while (b !== 0) [a, b] = [b, a % b];
  return a;
}
