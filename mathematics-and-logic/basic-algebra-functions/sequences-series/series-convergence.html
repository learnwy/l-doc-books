级数与收敛性

核心概念

级数（Series）是将数列的所有项求和的结果：∑n=1∞an=a1+a2+a3+⋯\sum_{n=1}^{\infty} a_n = a_1 + a_2 + a_3 + \cdots∑n=1∞​an​=a1​+a2​+a3​+⋯。级数理论的核心问题是收敛性——这个无穷和是否有有限值。

对程序员而言，级数收敛性直接关联到：算法复杂度的精确分析（如调和级数）、数值算法的近似精度（如 Taylor 展开）、概率论中的期望计算，以及数据结构的性能分析。

function partialSums(term: (n: number) => number, maxTerms: number): number[] {
  const sums: number[] = [];
  let total = 0;
  for (let n = 1; n <= maxTerms; n++) {
    total += term(n);
    sums.push(total);
  }
  return sums;
}

function estimateSeriesSum(
  term: (n: number) => number,
  epsilon: number = 1e-12,
  maxTerms: number = 1000000,
): { sum: number; terms: number; converged: boolean } {
  let sum = 0;
  for (let n = 1; n <= maxTerms; n++) {
    const t = term(n);
    sum += t;
    if (Math.abs(t) < epsilon) {
      return { sum, terms: n, converged: true };
    }
  }
  return { sum, terms: maxTerms, converged: false };
}

function harmonicNumber(n: number): number {
  let sum = 0;
  for (let k = 1; k <= n; k++) {
    sum += 1 / k;
  }
  return sum;
}

function harmonicApprox(n: number): number {
  const EULER_MASCHERONI = 0.5772156649015329;
  return Math.log(n) + EULER_MASCHERONI + 1 / (2 * n);
}

function couponCollectorSimulation(n: number, trials: number = 10000): { average: number; expected: number } {
  let totalSteps = 0;
  for (let t = 0; t < trials; t++) {
    const collected = new Set<number>();
    let steps = 0;
    while (collected.size < n) {
      collected.add(Math.floor(Math.random() * n));
      steps++;
    }
    totalSteps += steps;
  }
  return {
    average: totalSteps / trials,
    expected: couponCollectorExpected(n),
  };
}

function ratioTest(
  term: (n: number) => number,
  startN: number = 100,
  samples: number = 50,
): { ratio: number; verdict: 'converges' | 'diverges' | 'inconclusive' } {
  let ratioSum = 0;
  for (let n = startN; n < startN + samples; n++) {
    const current = Math.abs(term(n));
    const next = Math.abs(term(n + 1));
    if (current === 0) continue;
    ratioSum += next / current;
  }
  const avgRatio = ratioSum / samples;

  if (avgRatio < 0.999) return { ratio: avgRatio, verdict: 'converges' };
  if (avgRatio > 1.001) return { ratio: avgRatio, verdict: 'diverges' };
  return { ratio: avgRatio, verdict: 'inconclusive' };
}

Taylor 级数是将函数展开为幂级数的工具：

function taylorSin(x: number, terms: number = 10): number {
  let result = 0;
  let power = x;
  let factorial = 1;
  for (let n = 0; n < terms; n++) {
    result += ((n % 2 === 0 ? 1 : -1) * power) / factorial;
    power *= x * x;
    factorial *= (2 * n + 2) * (2 * n + 3);
  }
  return result;
}

function taylorCos(x: number, terms: number = 10): number {
  let result = 0;
  let power = 1;
  let factorial = 1;
  for (let n = 0; n < terms; n++) {
    result += ((n % 2 === 0 ? 1 : -1) * power) / factorial;
    power *= x * x;
    factorial *= (2 * n + 1) * (2 * n + 2);
  }
  return result;
}

function taylorExp(x: number, terms: number = 20): number {
  let result = 0;
  let term = 1;
  for (let n = 0; n < terms; n++) {
    result += term;
    term *= x / (n + 1);
  }
  return result;
}

function taylorLn1PlusX(x: number, terms: number = 100): number {
  if (x <= -1 || x > 1) throw new Error('Convergence requires -1 < x <= 1');
  let result = 0;
  let power = x;
  for (let n = 1; n <= terms; n++) {
    result += ((n % 2 === 1 ? 1 : -1) * power) / n;
    power *= x;
  }
  return result;
}

数值求和的精度问题
直接累加大量浮点数会导致严重的精度损失——小数加到大数时，小数的低位会被"吞掉"。


Kahan 求和算法通过维护一个"补偿变量"来追踪被吞掉的部分：


function naiveSum(values: number[]): number {
  return values.reduce((sum, val) => sum + val, 0);
}

function kahanSum(values: number[]): number {
  let sum = 0;
  let compensation = 0;
  for (const value of values) {
    const y = value - compensation;
    const t = sum + y;
    compensation = t - sum - y;
    sum = t;
  }
  return sum;
}

function compareSummation(n: number): {
  naive: number;
  kahan: number;
  exact: string;
} {
  const values = Array.from({ length: n }, (_, i) => 1 / (i + 1));
  return {
    naive: naiveSum(values),
    kahan: kahanSum(values),
    exact: `H(${n}) ≈ ln(${n}) + γ`,
  };
}
Kahan 求和的误差为 O(ϵ)O(\epsilon)O(ϵ)（ϵ\epsilonϵ 为机器精度），而朴素求和的误差可达 O(nϵ)O(n\epsilon)O(nϵ)。当 nnn 很大时，差异显著。

小结
    

  • 级数是数列的无穷和，收敛性由部分和的极限决定
    • 

  • an→0a_n \to 0an​→0 是收敛的必要但非充分条件（调和级数反例）
    • 

  • 调和级数 Hn≈ln⁡nH_n \approx \ln nHn​≈lnn 虽然发散，但在算法分析中频繁出现（快排、赠券收集、哈希表）
    • 

  • 比值判别法、比较判别法、积分判别法是判定收敛的核心工具
    • 

  • Taylor 级数将函数展开为幂级数，是数学库实现三角函数和指数函数的基础
    • 

  • 数值求和存在精度问题，Kahan 求和算法通过补偿变量将误差从 O(nϵ)O(n\epsilon)O(nϵ) 降到 O(ϵ)O(\epsilon)O(ϵ)
    • 

  • ppp-级数在 p>1p > 1p>1 时收敛，在 p≤1p \leq 1p≤1 时发散——这一边界对算法分析至关重要
    •
