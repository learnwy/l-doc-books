基础代数与函数 简介

本知识库是 13 号「数学与统计」分区的入门基石，覆盖中学到大一过渡阶段的代数运算、函数、方程不等式与数列级数。它的定位很明确：为后续所有数学 hub 提供运算基本功与符号直觉——当你在线性代数里做矩阵消元、在微积分里展开泰勒级数、在最优化里写损失函数时，所依赖的代数操作与函数观念都在这里打底。

本 hub 与兄弟 hub 的分工边界

13 号分区里多个 hub 主题相邻，容易混淆。下表说明「同一个词，谁讲到什么程度」，帮你选对入口：

主题 本 hub（基础代数与函数） 应去的兄弟 hub
实数与完备性 直觉 + 浮点工程含义（实数系统） 公理化构造、确界、柯西列 → 19 实分析
函数 作为映射的基本概念与图像 集合论严格定义（单/满/双射）→ 07 离散数学；连续/可导 → 03 微积分
方程组 二元、手工消元 多元、矩阵化、解的结构 → 01 线性代数
不等式 一元解法与绝对值 凸集、KKT、约束优化 → 05 最优化
数列与级数 等差/等比、收敛初步、归纳法 递推通解 → 07 离散数学；ε-N 严格收敛 → 19 实分析
整数分解 多项式因式分解 素因子分解、模运算、密码学 → 10 数论

一句话边界：本 hub 讲「怎么算、为什么这样算」的运算直觉；兄弟 hub 讲「严格证明、高维推广、工程算法」。 遇到需要公理化或多维化的内容，请跳转。

内容地图

  • 第 1 章 代数基础——实数系统、代数表达式、多项式运算、因式分解技巧。运算基本功，后续一切的前置。
  • 第 2 章 函数与图像——函数概念、一次与二次函数、指数与对数函数、函数变换。贯穿全书的核心抽象。
  • 第 3 章 方程与不等式——一次方程、二次方程、不等式求解、绝对值与距离。约束与求解的工具箱。
  • 第 4 章 数列与级数——等差数列、等比数列、级数与收敛性、数学归纳法。递推、求和与证明思维。

前置知识

本 hub 是数学分区的最底层，几乎零数学前置——只需初中代数符号与基本运算习惯。代码示例用 TypeScript 表达，能读懂变量、循环、函数即可；不熟悉也不影响理解数学主线。本 hub 不要求微积分或线性代数基础（恰恰相反，它们以本 hub 为前置）。

推荐学习路径（分人群）

  • 数学基础生疏的程序员（主力读者）：按 1 → 2 → 3 → 4 顺序通读。第 1 章运算能力是一切的地基，第 2 章函数观念贯穿全书，务必扎实；第 3、4 章可按工作需求挑读。每篇结尾的「延伸阅读」给出跨 hub 跳板，看到感兴趣的高阶主题即可顺链深入。
  • 只想补特定缺口（查漏型）：直接用上面的分工表定位入口。常见缺口：浮点为什么不精确 → 实数系统；对数/指数在 ML 里的角色 → 指数与对数函数；复杂度求和 → 等差/等比数列。
  • 准备进阶到高等数学（承上启下型）：重点打牢第 2 章函数与第 4 章级数/归纳法，再分别承接 03 微积分（函数→极限）、01 线性代数（方程组→矩阵）、19 实分析（实数→严格分析）。

每篇都遵循「直觉理解 → 严格推导 → 编程印证」三段式，建议边读边动手敲代码，把抽象的代数性质落到可运行的实例上。
