Prolog 基础

核心概念

Prolog（Programming in Logic）是最具代表性的逻辑编程语言，它将一阶逻辑的子集直接作为编程语言。在 Prolog 中，程序员不描述"如何计算"，而是描述"什么是真的"——通过声明事实和规则，让 Prolog 的推理引擎自动搜索答案。这种声明式范式与命令式编程形成鲜明对比。

对程序员而言，理解 Prolog 不仅是学习一种语言，更是理解声明式思维的入口。Prolog 的核心机制——统一、回溯和归结——在现代编程中以各种形式出现：TypeScript 的类型推断基于统一算法，正则表达式引擎使用回溯，数据库查询优化器使用类似归结的推理。

统一：逻辑编程的核心算法
统一（Unification）是 Prolog 最核心的计算机制，也是类型推断和模式匹配的理论基础。统一算法试图找到使两个项（Term）相同的最一般替换（Most General Unifier, MGU）。


统一的规则：


    

  1. 常量只能与自身统一
    2. 

  2. 变量可以与任何项统一（绑定为该项）
    3. 

  3. 复合项 f(t₁,...,tₙ) 与 f(s₁,...,sₙ) 统一当且仅当函子相同且对应参数分别统一
    4. 

  4. 出现检查（Occurs Check）：变量 X 不能与包含 X 的项统一（防止无限循环）
    5. 



在 TypeScript 中，当编译器推断泛型类型参数时，本质上在做统一。identity<T>(x: T): T 调用 identity(42) 时，编译器统一 T 与 number 类型，得到 T = number。


统一算法的时间复杂度在最坏情况下是指数的（由于变量替换的传播），但 Robinson 的线性统一算法和后续的近线性算法使其在实践中非常高效。


回溯搜索与搜索策略
Prolog 的执行模型是深度优先搜索（DFS）加回溯（Backtracking）。当一条推理路径失败时，Prolog 自动回退到最近的选择点，尝试下一个可能的匹配。

Prolog 的 DFS 策略意味着子句的顺序很重要——不同的排列可能导致不同的行为（找到解、找不到解、或无限循环）。这是 Prolog 中声明式语义和操作语义之间的差距：逻辑上等价的程序在执行效率上可能天差地别。


切割（Cut, !）是 Prolog 中控制回溯的机制。它相当于告诉搜索引擎"不要再回溯到这个选择点之前"。切割可以提高效率但牺牲了声明式的纯粹性，被称为 Prolog 中最具争议的特性。在现代编程中，提前返回（Early Return）和短路求值与切割有类似的作用。


Horn 子句与逻辑编程的局限
Prolog 基于 Horn 子句（Horn Clauses）——一种特殊形式的一阶逻辑公式。Horn 子句形如 B₁ ∧ B₂ ∧ ... ∧ Bₙ → H，意为"如果 B₁ 到 Bₙ 都成立，则 H 成立"。


Horn 子句的限制意味着 Prolog 不能直接表达所有一阶逻辑公式。特别是：


    

  • 不能直接表达析取结论（A 或 B 成立）
    • 

  • 不能直接表达否定事实（关于什么不是真的）
    • 

  • 不能表达全称否定（没有任何 X 满足 P）
    • 



Prolog 用"否定即失败"（Negation as Failure, NAF）来处理否定：\+ P 成立当且仅当 P 不能被证明。这与逻辑否定不同——无法证明 P 不等于 P 为假。这种封闭世界假设（Closed World Assumption）在数据库理论中也很常见。

Prolog 的现代影响与应用
虽然 Prolog 不是主流编程语言，但它的核心思想深刻影响了现代编程：


类型推断：Hindley-Milner 类型推断（用于 Haskell、OCaml、TypeScript）基于统一算法。编译器在推断类型时，本质上在运行一个类似 Prolog 的推理引擎。


模式匹配：Elixir、Rust、Haskell 等语言的模式匹配直接受 Prolog 启发。Elixir 的模式匹配甚至支持类似 Prolog 的变量绑定语义。


数据库查询：Datalog（Prolog 的子集）在现代数据库和程序分析中复兴。Datomic（Clojure 生态的数据库）和 Souffle（用于静态分析的 Datalog 引擎）都基于 Datalog。


AI 与知识表示：早期 AI 系统大量使用 Prolog。现代知识图谱查询（如 SPARQL）的推理引擎与 Prolog 有相同的逻辑基础。

小结
    

  • Prolog 将一阶逻辑（Horn 子句）直接作为编程语言，实现了"说什么"而非"怎么做"的声明式范式
    • 

  • 统一算法是 Prolog 的核心机制，也是类型推断和模式匹配的理论基础
    • 

  • 回溯搜索赋予 Prolog 自动探索解空间的能力，但受限于 DFS 策略的不完备性
    • 

  • Prolog 的思想在现代编程中无处不在：TypeScript 的类型推断、Rust 的模式匹配、Datalog 的程序分析
    • 

  • 理解逻辑编程帮助程序员建立从"过程思维"到"关系思维"的认知跃迁
    •
