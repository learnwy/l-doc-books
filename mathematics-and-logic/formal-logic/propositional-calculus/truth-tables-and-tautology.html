真值表与重言式

核心概念

真值表（Truth Table）是命题逻辑中最基本的语义工具，通过穷举所有可能的真值组合来确定复合命题的真值。重言式（Tautology）则是在所有真值赋值下都为真的命题公式，它代表了逻辑上的"永真"——不依赖于任何具体情况的必然真理。

对程序员而言，真值表对应着穷举测试（Exhaustive Testing）的思想，而重言式对应着不变量（Invariant）的概念。理解真值表帮助我们系统地分析条件分支的完备性，理解重言式帮助我们识别代码中的逻辑恒等式和冗余判断。

真值表的构造方法与复杂度分析
真值表的构造遵循系统的枚举策略。对于包含 n 个原子命题的公式，真值表有 2^n 行。这意味着真值表方法的时间复杂度是指数级的——与 SAT 问题（布尔可满足性问题）的 NP 完全性直接相关。

最终列全部为 T，因此该公式是重言式。这证明了"如果 p 则 q"等价于"如果非 q 则非 p"。在代码审查中，这个等价关系经常用于简化条件判断：if (!result) { throw Error(); } 等价于在函数入口检查前提条件。


真值表方法的指数增长意味着对于大规模命题公式，我们需要更高效的方法。这启发了 BDD（Binary Decision Diagram，二叉决策图）等数据结构的发明，它在硬件验证和模型检测中有广泛应用。


重言式与逻辑等价的判定
重言式在逻辑推理中扮演着核心角色。如果 φ 是重言式，记作 ⊨ φ，表示 φ 在所有解释下都为真。两个公式 φ 和 ψ 逻辑等价（记作 φ ≡ ψ）当且仅当 φ ↔ ψ 是重言式。


重要的重言式模式包括：


排中律（Law of Excluded Middle）：p ∨ ¬p。在编程中，这意味着一个布尔表达式及其否定覆盖了所有可能。这是 if-else 完备性的逻辑基础。但在直觉主义逻辑（Intuitionistic Logic）中，排中律不被接受——这与类型论和构造性证明有深刻联系。


蕴含传递律：(p → q) ∧ (q → r) → (p → r)。这是推理链的基础。在微服务架构中，如果服务 A 依赖服务 B，服务 B 依赖服务 C，那么服务 A 间接依赖服务 C。


假言三段论（Hypothetical Syllogism）与编程中的函数组合直接对应：如果 f: A → B 且 g: B → C，那么 g ∘ f: A → C。


逆否命题：(p → q) ↔ (¬q → ¬p)。在调试中极其实用——如果我们知道"输入正确则输出正确"，那么"输出不正确"就意味着"输入不正确"。这是错误溯源（Root Cause Analysis）的逻辑基础。


可满足性与 SAT 问题
可满足性（Satisfiability）是逻辑学与计算机科学交叉的核心概念。一个命题公式是可满足的（Satisfiable），当且仅当存在至少一个使其为真的真值赋值。判定可满足性的问题称为 SAT 问题。


SAT 是第一个被证明为 NP 完全的问题（Cook-Levin 定理，1971年），它在计算复杂性理论中具有里程碑意义。从实用角度看，现代 SAT 求解器（如 MiniSat、Z3）已经能高效处理包含数百万变量的实际问题。

npm 的依赖解析本质上是一个 SAT 问题：每个包的版本约束是一个布尔子句，找到满足所有约束的版本组合就是找到一个满足赋值。当依赖冲突无法解决时，就是 SAT 公式不可满足。


范式：合取范式与析取范式
每个命题公式都可以转化为两种标准形式：合取范式（CNF，Conjunctive Normal Form）和析取范式（DNF，Disjunctive Normal Form）。


合取范式（CNF） 是子句的合取：(l₁ ∨ l₂ ∨ ...) ∧ (l₃ ∨ l₄ ∨ ...) ∧ ...，其中每个子句是文字的析取。SAT 求解器通常要求输入为 CNF 形式。


析取范式（DNF） 是合取项的析取：(l₁ ∧ l₂ ∧ ...) ∨ (l₃ ∧ l₄ ∧ ...) ∨ ...。DNF 更直观——每个合取项描述一种使公式为真的条件组合。

在编程中，条件表达式的结构往往自然呈现 CNF 或 DNF 形式。例如，权限检查"（是管理员或是拥有者）且（账户未过期）且（未被封禁）"是典型的 CNF 结构。而功能开关"（国内用户且 VIP）或（海外用户且已付费）或（内部测试账号）"是 DNF 结构。

真值表可以处理任意规模的命题
真值表是指数增长的，只适合小规模公式
复杂条件逻辑需要 SAT 求解器等高效工具




重言式没有实际用处
重言式是推理规则的基础，是程序不变量的逻辑保证
循环不变量、类型约束、接口契约都依赖重言式




CNF 和 DNF 转换总是高效的
CNF↔DNF 转换可能导致指数级膨胀
选择合适的表示形式比转换更重要




SAT 问题不可能高效求解
虽然最坏情况是 NP 完全，但现代求解器对实际问题高效
不要因理论复杂度就放弃使用 SAT 工具





小结
    

  • 真值表通过穷举所有真值组合来判定公式的语义性质，是命题逻辑最基础的分析工具
    • 

  • 重言式代表逻辑上的必然真理，对应编程中的不变量和恒等变换
    • 

  • SAT 问题是逻辑学与计算机科学的关键交叉点，在依赖解析、硬件验证、测试生成中广泛应用
    • 

  • CNF 和 DNF 两种范式各有优势，理解它们帮助程序员选择合适的条件表达式结构
    • 

  • 从真值表的指数复杂度出发，可以深刻理解 P vs NP 问题的本质——验证容易但搜索困难
    •
