一阶逻辑证明论

核心概念

一阶逻辑证明论研究如何通过形式化的推理规则从公理和前提推导出结论。与语义学关注"什么是真的"不同，证明论关注"什么是可证的"。证明论的核心问题是：给定一组公理和推理规则，哪些定理可以被形式化地推导出来？

对程序员而言，证明论直接关联到自动化定理证明、程序验证和类型检查的理论基础。编译器的类型检查算法本质上是一个证明搜索过程——它试图为程序构造一个类型正确性的证明。如果找到了证明，程序通过类型检查；如果找不到，报告类型错误。

相继式演算：结构化的推理框架
相继式演算（Sequent Calculus）由根岑提出，是一阶证明论中最优雅的形式化框架。一个相继式的形式为 Γ ⊢ Δ，其中 Γ 是前提集合（左侧），Δ 是结论集合（右侧），含义为"从 Γ 中的全部假设可以推出 Δ 中的某个结论"。


相继式演算的规则分为三类：


结构规则：弱化（Weakening）、收缩（Contraction）、交换（Exchange）。这些规则不涉及逻辑联结词，只处理相继式的结构。在编程中，弱化对应"引入未使用的变量"，收缩对应"多次使用同一变量"，交换对应"参数重排"。


逻辑规则：每个联结词在左侧和右侧各有规则。左规则描述如何使用（消去）该联结词的公式，右规则描述如何构造（引入）该联结词的公式。


切割规则（Cut Rule）：Γ ⊢ A, Δ 和 A, Σ ⊢ Π 推出 Γ, Σ ⊢ Δ, Π。切割规则允许使用"引理"——先证明中间结论，再用中间结论推导最终结论。这对应编程中的函数组合——先计算中间结果，再用中间结果计算最终结果。


根岑的切割消去定理（Cut Elimination Theorem）证明了：任何使用切割规则的证明都可以转化为不使用切割规则的证明。这个深刻的结果意味着"引理"不是必需的——虽然它们使证明更简洁，但原则上可以消去。在计算机科学中，切割消去对应着内联展开（Inlining）——将函数调用替换为函数体。


归结法与自动定理证明
归结法（Resolution）是 Robinson 在 1965 年提出的自动定理证明方法，它是 Prolog 语言和大多数自动推理系统的理论基础。归结法的核心思想是反证法：要证明 φ，先假设 ¬φ，然后试图推导出矛盾（空子句 □）。

  2. 合取范式：将公式转化为子句集
    3. 

  3. 统一：找到使两个文字互补的替换（Unification）
    4. 

  4. 归结：对含有互补文字的子句对进行归结

统一（Unification）是归结法的核心算法，也是类型推断的基础。Robinson 统一算法寻找使两个项相同的最一般替换（Most General Unifier, MGU）。在 TypeScript 的类型推断中，编译器就是在做统一——找到使类型约束一致的类型变量赋值。

Herbrand 定理与可半判定性
Herbrand 定理是连接语义和证明论的桥梁，它将一阶逻辑的可满足性问题归结为命题逻辑层面的问题。定理表述为：一阶公式（的 Skolem 标准形式）不可满足，当且仅当其 Herbrand 域上存在有限多个基实例的合取不可满足。


这个定理的工程意义在于：它将无穷论域上的推理问题转化为有限（但可能很大）的命题逻辑问题。这是自动定理证明的理论基础——虽然一阶逻辑不可判定，但通过系统枚举 Herbrand 域的基实例，可以半判定（Semi-Decidable）不可满足性。


一阶逻辑的不可判定性（Church-Turing 定理）意味着不存在通用算法能在有限时间内判定任意一阶公式的有效性。但半判定性保证：如果公式确实是有效的，证明搜索过程最终会终止并找到证明；如果不是有效的，过程可能永远不终止。


这对程序员有重要的实践启示：类型检查对于某些类型系统是不可判定的（如依赖类型系统），这就是为什么 TypeScript 编译器设置了递归深度限制——防止类型检查过程不终止。


Hoare 逻辑与程序验证
Hoare 逻辑是证明论在软件工程中最直接的应用，它为程序正确性提供了形式化的证明框架。Hoare 三元组 {P} S {Q} 表示：如果程序 S 在满足前置条件 P 的状态下执行，且执行终止，则终止后状态满足后置条件 Q。

{P∧B}S{P} ⊢ {P}while B do S{P∧¬B}

加强前置
P'→P, {P}S{Q} ⊢ {P'}S{Q}
更强的前置条件也行




弱化后置
{P}S{Q}, Q→Q' ⊢ {P}S{Q'}
可以放宽后置条件





循环不变量（Loop Invariant）是 Hoare 逻辑中最关键的概念。在实际编程中，理解和维护循环不变量是写出正确循环代码的关键。每次迭代开始时，不变量都必须成立；循环终止时，不变量加上循环条件的否定给出最终结论。

小结
    

  • 相继式演算提供了结构化的证明框架，切割消去定理揭示了"引理=函数抽象"的本质
    • 

  • 归结法和统一算法是自动定理证明的核心，也是类型推断和逻辑编程的理论基础
    • 

  • 一阶逻辑的不可判定性解释了为什么类型检查有时需要人工提供类型注解
    • 

  • Hoare 逻辑将证明论直接应用于程序验证，循环不变量是其中最关键的实践概念
    • 

  • 理解证明论帮助程序员从"试错"走向"推理"，从"调试"走向"验证"
