行列式与克拉默法则

核心概念

行列式是方阵到标量的一个映射函数，它将 n×n 矩阵映射为一个实数（或复数）。行列式的值编码了矩阵的关键信息：可逆性、体积变化因子、特征值的乘积。几何上，行列式的绝对值等于矩阵列向量所构成的平行多面体的体积。

行列式记作 det(A) 或 |A|。二阶行列式 det([[a,b],[c,d]]) = ad - bc，三阶及以上通过余子式展开或初等行变换计算。行列式为零意味着矩阵奇异（不可逆），列向量线性相关。

行列式的递归计算与余子式展开
行列式可以沿任意行或列做余子式展开。沿第 i 行展开：det(A) = Σ(j=1到n) (-1)^(i+j) · a[i][j] · M[i][j]，其中 M[i][j] 是去掉第 i 行第 j 列后的 (n-1)×(n-1) 子矩阵的行列式（称为余子式）。


type Matrix = number[][];

const determinant = (A: Matrix): number => {
  const n = A.length;
  if (n === 1) return A[0][0];
  if (n === 2) return A[0][0] * A[1][1] - A[0][1] * A[1][0];

  let det = 0;
  for (let j = 0; j < n; j++) {
    const minor = A.slice(1).map((row) => [...row.slice(0, j), ...row.slice(j + 1)]);
    det += Math.pow(-1, j) * A[0][j] * determinant(minor);
  }
  return det;
};

const cofactorMatrix = (A: Matrix): Matrix => {
  const n = A.length;
  return Array.from({ length: n }, (_, i) =>
    Array.from({ length: n }, (_, j) => {
      const minor = A.filter((_, ri) => ri !== i).map((row) => row.filter((_, ci) => ci !== j));
      return Math.pow(-1, i + j) * determinant(minor);
    }),
  );
};
递归余子式展开的时间复杂度为 O(n!)，这在 n > 10 时完全不实用。实际计算中，行列式通过高斯消元转化为上三角矩阵后，取对角线元素乘积，复杂度降至 O(n³)。


const detByElimination = (A: Matrix): number => {
  const n = A.length;
  const U = A.map((row) => [...row]);
  let sign = 1;

  for (let col = 0; col < n; col++) {
    let pivotRow = -1;
    for (let row = col; row < n; row++) {
      if (Math.abs(U[row][col]) > 1e-10) {
        pivotRow = row;
        break;
      }
    }
    if (pivotRow === -1) return 0;

    if (pivotRow !== col) {
      [U[col], U[pivotRow]] = [U[pivotRow], U[col]];
      sign *= -1;
    }

    for (let row = col + 1; row < n; row++) {
      const factor = U[row][col] / U[col][col];
      for (let j = col; j < n; j++) {
        U[row][j] -= factor * U[col][j];
      }
    }
  }

  let det = sign;
  for (let i = 0; i < n; i++) {
    det *= U[i][i];
  }
  return det;
};
行列式的代数性质
行列式满足一系列重要的代数性质，这些性质是简化计算和理论推导的基础。


乘法性 det(AB) = det(A)·det(B) 是最重要的性质之一。它意味着两个线性变换的组合对体积的影响等于各自影响的乘积。由此可推出 det(A⁻¹) = 1/det(A)，det(Aⁿ) = (det(A))ⁿ。


行列式对行（或列）是多线性的：如果第 i 行是两个向量之和 rᵢ = u + v，则 det(A) 等于将 rᵢ 分别替换为 u 和 v 后两个行列式之和。这种多线性性是行列式的定义性质之一。


行列式是交替的：交换两行，行列式变号。如果有两行相同，行列式为零。这反映了行列式与排列符号（置换奇偶性）的深层联系。


克拉默法则与伴随矩阵
克拉默法则给出了线性方程组 Ax = b 在 det(A) ≠ 0 时的显式解：x[i] = det(Aᵢ) / det(A)，其中 Aᵢ 是将 A 的第 i 列替换为 b 后得到的矩阵。


const cramerSolve = (A: Matrix, b: number[]): number[] | null => {
  const n = A.length;
  const detA = detByElimination(A);
  if (Math.abs(detA) < 1e-10) return null;

  const x: number[] = [];
  for (let i = 0; i < n; i++) {
    const Ai = A.map((row, r) => {
      const newRow = [...row];
      newRow[i] = b[r];
      return newRow;
    });
    x.push(detByElimination(Ai) / detA);
  }
  return x;
};

const A: Matrix = [
  [2, 1, -1],
  [-3, -1, 2],
  [-2, 1, 2],
];
const b = [8, -11, -3];
console.log(cramerSolve(A, b));
克拉默法则需要计算 n+1 个 n×n 行列式，总复杂度 O(n⁴)，远不如高斯消元的 O(n³)。因此克拉默法则主要用于理论分析和符号计算，不适合大规模数值计算。


伴随矩阵（adjugate matrix）adj(A) 是余子式矩阵的转置，满足 A·adj(A) = det(A)·I。由此可得逆矩阵公式 A⁻¹ = adj(A) / det(A)。这个公式同样主要用于理论推导。


const adjugate = (A: Matrix): Matrix => {
  const cof = cofactorMatrix(A);
  const n = cof.length;
  return Array.from({ length: n }, (_, i) => Array.from({ length: n }, (_, j) => cof[j][i]));
};

const inverseViaDet = (A: Matrix): Matrix | null => {
  const det = detByElimination(A);
  if (Math.abs(det) < 1e-10) return null;
  const adj = adjugate(A);
  return adj.map((row) => row.map((val) => val / det));
};
行列式的几何意义
行列式的几何意义是理解其本质的关键。在二维空间中，2×2 矩阵的行列式等于其两个列向量所构成的平行四边形的有向面积。在三维空间中，3×3 矩阵的行列式等于三个列向量构成的平行六面体的有向体积。


"有向"意味着行列式可以为负。正值表示变换保持空间方向（右手系→右手系），负值表示方向翻转（右手系→左手系）。det = 0 表示空间被"压扁"到低维——体积塌缩为零。


const parallelogramArea = (v1: number[], v2: number[]): number => Math.abs(v1[0] * v2[1] - v1[1] * v2[0]);

const parallelepipedVolume = (v1: number[], v2: number[], v3: number[]): number => {
  const A: Matrix = [v1, v2, v3];
  return Math.abs(detByElimination(A[0].map((_, j) => A.map((row) => row[j]))));
};

const det2D = determinant([
  [3, 0],
  [0, 2],
]);
console.log(`面积缩放因子: ${det2D}`);

const det3D = determinant([
  [1, 0, 0],
  [0, 2, 0],
  [0, 0, 3],
]);
console.log(`体积缩放因子: ${det3D}`);
在机器学习中，协方差矩阵的行列式衡量数据的"散布程度"。多元正态分布的概率密度函数中包含 1/√det(Σ) 项，行列式越大表示数据越分散，概率密度越低。


小结
    

  • 行列式将方阵映射为标量，编码了可逆性、体积变化和特征值乘积信息
    • 

  • 余子式展开 O(n!) 仅适合小矩阵，实际使用高斯消元 O(n³) 计算
    • 

  • 行列式满足乘法性 det(AB) = det(A)det(B)，是理论推导的核心工具
    • 

  • 克拉默法则给出显式解但计算复杂度高，主要用于理论分析
    • 

  • 行列式的绝对值等于列向量构成的平行多面体体积，符号表示方向
    • 

  • 行列式为零意味着矩阵奇异，空间被"压扁"到低维
