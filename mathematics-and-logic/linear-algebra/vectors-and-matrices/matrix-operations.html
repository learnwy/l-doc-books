矩阵运算与性质

核心概念

矩阵是线性代数中最重要的计算工具，它将线性变换、线性方程组和数据组织统一在一个紧凑的数学对象中。一个 m×n 矩阵是由 m 行 n 列实数（或复数）排列成的矩形数组，矩阵运算的规则直接反映了线性映射的组合方式。

在编程中，矩阵无处不在：神经网络的权重矩阵、图像处理的卷积核、推荐系统的用户-物品矩阵、图算法的邻接矩阵。掌握矩阵运算不仅是理论需要，更是高效编程的基础。

矩阵乘法的本质
矩阵乘法是线性代数中最核心的运算。给定 m×n 矩阵 A 和 n×p 矩阵 B，乘积 C = AB 是 m×p 矩阵，其中 C[i][j] = Σ(k=0 到 n-1) A[i][k] * B[k][j]。


矩阵乘法有四种等价视角：行列内积视角、列向量线性组合视角、行向量线性组合视角、外积求和视角。每种视角适用于不同场景。


type Matrix = number[][];

const matMul = (A: Matrix, B: Matrix): Matrix => {
  const m = A.length;
  const n = A[0].length;
  const p = B[0].length;
  const C: Matrix = Array.from({ length: m }, () => Array.from({ length: p }, () => 0));
  for (let i = 0; i < m; i++) {
    for (let k = 0; k < n; k++) {
      for (let j = 0; j < p; j++) {
        C[i][j] += A[i][k] * B[k][j];
      }
    }
  }
  return C;
};

const matAdd = (A: Matrix, B: Matrix): Matrix => A.map((row, i) => row.map((val, j) => val + B[i][j]));

const scalarMul = (c: number, A: Matrix): Matrix => A.map((row) => row.map((val) => c * val));

const transpose = (A: Matrix): Matrix => {
  const m = A.length;
  const n = A[0].length;
  return Array.from({ length: n }, (_, j) => Array.from({ length: m }, (_, i) => A[i][j]));
};
注意循环顺序 i-k-j 而非 i-j-k。这是因为内层循环访问 B[k][j] 时 j 是连续的，利于 CPU 缓存行预取。在大规模矩阵乘法中，这个优化可以带来 2-5 倍的性能提升。


矩阵乘法不满足交换律（AB ≠ BA），但满足结合律 (AB)C = A(BC) 和分配律 A(B+C) = AB + AC。结合律意味着我们可以选择乘法顺序来优化计算量——这就是矩阵链乘法问题，一个经典的动态规划问题。


特殊矩阵与结构化运算
线性代数中存在许多特殊结构的矩阵，利用这些结构可以大幅简化运算。


单位矩阵 I 是方阵中对角线全为 1、其余为 0 的矩阵，AI = IA = A。对角矩阵只有对角线上有非零元素，其乘法和求逆都只需 O(n) 时间。对称矩阵满足 A = Aᵀ，在存储上只需保存上三角（或下三角）。


const identity = (n: number): Matrix =>
  Array.from({ length: n }, (_, i) => Array.from({ length: n }, (_, j) => (i === j ? 1 : 0)));

const isDiagonal = (A: Matrix): boolean => {
  const n = A.length;
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) {
      if (i !== j && Math.abs(A[i][j]) > 1e-10) return false;
    }
  }
  return true;
};

const isSymmetric = (A: Matrix): boolean => {
  const n = A.length;
  for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {
      if (Math.abs(A[i][j] - A[j][i]) > 1e-10) return false;
    }
  }
  return true;
};

const diagonalInverse = (D: Matrix): Matrix => {
  const n = D.length;
  return Array.from({ length: n }, (_, i) => Array.from({ length: n }, (_, j) => (i === j ? 1 / D[i][i] : 0)));
};
上三角矩阵和下三角矩阵在求解线性方程组时特别重要。三角矩阵的行列式等于对角线元素的乘积，求解 Ax = b 只需 O(n²) 的回代操作，远快于一般方阵的 O(n³)。


正交矩阵满足 QᵀQ = QQᵀ = I，即转置等于逆。正交矩阵保持向量长度和角度不变，对应几何上的旋转和反射。在数值计算中，正交变换具有最佳的数值稳定性。


逆矩阵与可逆性判定
方阵 A 的逆矩阵 A⁻¹ 满足 AA⁻¹ = A⁻¹A = I。不是所有方阵都可逆——A 可逆当且仅当 det(A) ≠ 0，等价于 A 的列向量线性无关，等价于 Ax = 0 只有零解。


const invertMatrix = (A: Matrix): Matrix | null => {
  const n = A.length;
  const augmented = A.map((row, i) => [...row, ...Array.from({ length: n }, (_, j) => (i === j ? 1 : 0))]);

  for (let col = 0; col < n; col++) {
    let maxRow = col;
    for (let row = col + 1; row < n; row++) {
      if (Math.abs(augmented[row][col]) > Math.abs(augmented[maxRow][col])) {
        maxRow = row;
      }
    }
    [augmented[col], augmented[maxRow]] = [augmented[maxRow], augmented[col]];

    if (Math.abs(augmented[col][col]) < 1e-10) return null;

    const pivot = augmented[col][col];
    for (let j = col; j < 2 * n; j++) {
      augmented[col][j] /= pivot;
    }
    for (let row = 0; row < n; row++) {
      if (row !== col) {
        const factor = augmented[row][col];
        for (let j = col; j < 2 * n; j++) {
          augmented[row][j] -= factor * augmented[col][j];
        }
      }
    }
  }
  return augmented.map((row) => row.slice(n));
};
逆矩阵的性质包括：(AB)⁻¹ = B⁻¹A⁻¹（注意顺序反转），(Aᵀ)⁻¹ = (A⁻¹)ᵀ，(cA)⁻¹ = (1/c)A⁻¹。在实际计算中，很少直接求逆矩阵——解方程 Ax = b 时，使用 LU 分解再回代远比计算 A⁻¹b 更高效、更稳定。


分块矩阵运算
分块矩阵将大矩阵划分为若干子矩阵块，运算规则与普通矩阵相同，只是元素换成了矩阵块。分块技术在并行计算、稀疏矩阵处理和理论推导中极为重要。


常见的分块方式包括：按行分块 A = [A₁; A₂; ...]、按列分块 A = [A₁ A₂ ...]、以及一般的网格分块。分块矩阵乘法的公式是 C[i][j] = Σ A[i][k] * B[k][j]，其中乘法和加法是矩阵运算。


const blockMatMul = (A: Matrix, B: Matrix, blockSize: number): Matrix => {
  const n = A.length;
  const C: Matrix = Array.from({ length: n }, () => Array.from({ length: n }, () => 0));

  for (let i = 0; i < n; i += blockSize) {
    for (let j = 0; j < n; j += blockSize) {
      for (let k = 0; k < n; k += blockSize) {
        const iEnd = Math.min(i + blockSize, n);
        const jEnd = Math.min(j + blockSize, n);
        const kEnd = Math.min(k + blockSize, n);
        for (let ii = i; ii < iEnd; ii++) {
          for (let kk = k; kk < kEnd; kk++) {
            for (let jj = j; jj < jEnd; jj++) {
              C[ii][jj] += A[ii][kk] * B[kk][jj];
            }
          }
        }
      }
    }
  }
  return C;
};
分块乘法的核心优势是提高缓存利用率。当 blockSize 匹配 CPU 的 L1 缓存大小时，每个子块可以完全装入缓存，避免频繁的缓存未命中。这是 BLAS 库（如 OpenBLAS、MKL）实现高性能矩阵乘法的核心技术。


小结
    

  • 矩阵乘法是核心运算，满足结合律和分配律但不满足交换律
    • 

  • i-k-j 循环顺序利于缓存行预取，可带来数倍性能提升
    • 

  • 特殊矩阵（对角、三角、正交）的结构化性质可大幅简化计算
    • 

  • 可逆性等价于行列式非零、列线性无关、零空间仅含零向量
    • 

  • 实践中应避免直接求逆矩阵，优先使用分解法求解方程
    • 

  • 分块矩阵技术是高性能数值计算库的核心优化策略
