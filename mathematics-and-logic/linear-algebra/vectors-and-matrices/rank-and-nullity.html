秩与零空间

核心概念

矩阵的秩（rank）是矩阵中线性无关的行（或列）的最大数目，它是衡量矩阵"信息含量"的核心指标。秩揭示了线性方程组的解结构、线性变换的维度变化、以及数据矩阵的有效维度。

零空间（null space）又称核空间（kernel），是齐次方程组 Ax = 0 的解集。零空间的维度称为零度（nullity）。秩-零度定理 rank(A) + nullity(A) = n（列数）建立了秩与零空间之间的精确联系。

秩的计算方法
秩的标准计算方法是通过行化简（高斯消元）将矩阵转化为行阶梯形，然后数非零行的个数。行化简不改变行空间和秩，但会改变列空间（不过列空间的维度不变）。


type Matrix = number[][];

const computeRank = (A: Matrix): number => {
  const m = A.length;
  const n = A[0].length;
  const R = A.map((row) => [...row]);
  let rank = 0;

  for (let col = 0; col < n && rank < m; col++) {
    let pivotRow = -1;
    let maxVal = 1e-10;
    for (let row = rank; row < m; row++) {
      if (Math.abs(R[row][col]) > maxVal) {
        maxVal = Math.abs(R[row][col]);
        pivotRow = row;
      }
    }
    if (pivotRow === -1) continue;

    [R[rank], R[pivotRow]] = [R[pivotRow], R[rank]];

    const pivot = R[rank][col];
    for (let j = col; j < n; j++) {
      R[rank][j] /= pivot;
    }
    for (let row = 0; row < m; row++) {
      if (row !== rank && Math.abs(R[row][col]) > 1e-10) {
        const factor = R[row][col];
        for (let j = col; j < n; j++) {
          R[row][j] -= factor * R[rank][j];
        }
      }
    }
    rank++;
  }
  return rank;
};

const A: Matrix = [
  [1, 2, 3, 4],
  [2, 4, 6, 8],
  [1, 3, 5, 7],
];
console.log(`rank = ${computeRank(A)}`);
秩还可以通过奇异值分解（SVD）计算：rank(A) 等于 A 的非零奇异值的个数。SVD 方法在数值上更稳定，特别是当矩阵接近秩亏（near-rank-deficient）时。在实际应用中，常用数值秩——将小于某个阈值 ε 的奇异值视为零。


秩的等价定义包括：A 的最大非零子式的阶数、列空间的维度、行空间的维度、非零奇异值的个数。这些等价性确保了秩是矩阵的内在属性。


零空间的求解
零空间的求解本质上是求齐次线性方程组 Ax = 0 的通解。通过将 A 化为行最简阶梯形（RREF），可以直接读出零空间的基向量。


const rref = (A: Matrix): { reduced: Matrix; pivotCols: number[] } => {
  const m = A.length;
  const n = A[0].length;
  const R = A.map((row) => [...row]);
  const pivotCols: number[] = [];
  let rank = 0;

  for (let col = 0; col < n && rank < m; col++) {
    let pivotRow = -1;
    let maxVal = 1e-10;
    for (let row = rank; row < m; row++) {
      if (Math.abs(R[row][col]) > maxVal) {
        maxVal = Math.abs(R[row][col]);
        pivotRow = row;
      }
    }
    if (pivotRow === -1) continue;

    [R[rank], R[pivotRow]] = [R[pivotRow], R[rank]];
    const pivot = R[rank][col];
    for (let j = col; j < n; j++) R[rank][j] /= pivot;
    for (let row = 0; row < m; row++) {
      if (row !== rank) {
        const factor = R[row][col];
        for (let j = col; j < n; j++) R[row][j] -= factor * R[rank][j];
      }
    }
    pivotCols.push(col);
    rank++;
  }
  return { reduced: R, pivotCols };
};

const nullSpace = (A: Matrix): Matrix => {
  const n = A[0].length;
  const { reduced, pivotCols } = rref(A);
  const rank = pivotCols.length;
  const freeCols = Array.from({ length: n }, (_, i) => i).filter((i) => !pivotCols.includes(i));

  return freeCols.map((freeCol) => {
    const x = Array(n).fill(0);
    x[freeCol] = 1;
    for (let i = 0; i < rank; i++) {
      x[pivotCols[i]] = -reduced[i][freeCol];
    }
    return x;
  });
};

const B: Matrix = [
  [1, 2, 3, 4],
  [2, 4, 6, 8],
  [1, 3, 5, 7],
];
const nullBasis = nullSpace(B);
console.log('零空间基:', nullBasis);
每个自由变量对应一个零空间基向量，零空间维度等于自由变量个数 = n - rank(A)。零空间基向量的线性组合构成 Ax = 0 的通解。


秩-零度定理
秩-零度定理（也称维度公式）是线性代数中最优美的结果之一：对于 m×n 矩阵 A，rank(A) + nullity(A) = n。


直觉理解：n 维输入空间被线性映射 A 分成两部分——rank(A) 维的"有效输入"映射到列空间，剩余 nullity(A) 维的"死区"映射到零向量。两部分加起来恰好覆盖整个输入空间。


const verifyRankNullity = (A: Matrix): void => {
  const n = A[0].length;
  const rank = computeRank(A);
  const nullBasis = nullSpace(A);
  const nullity = nullBasis.length;

  console.log(`列数 n = ${n}`);
  console.log(`秩 rank = ${rank}`);
  console.log(`零度 nullity = ${nullity}`);
  console.log(`rank + nullity = ${rank + nullity}`);
  console.log(`定理成立: ${rank + nullity === n}`);
};

verifyRankNullity([
  [1, 2, 3, 4],
  [2, 4, 6, 8],
  [1, 3, 5, 7],
]);
秩-零度定理的推论：如果 A 是 n×n 方阵且 rank(A) = n，则 nullity = 0，即 Ax = 0 只有零解，A 可逆。反之，rank(A) < n 时，存在非零解，A 奇异。


四个基本子空间
一个 m×n 矩阵 A 关联四个基本子空间，它们构成了线性代数的几何骨架。这四个空间两两正交，维度关系完全由秩决定。


列空间 Col(A) 是 R^m 中的 r 维子空间，由 A 的列向量张成，决定了 Ax = b 何时有解。行空间 Row(A) 是 R^n 中的 r 维子空间。零空间 Null(A) 是 R^n 中的 (n-r) 维子空间，与行空间正交互补。左零空间 Null(Aᵀ) 是 R^m 中的 (m-r) 维子空间，与列空间正交互补。


const fourSubspaces = (A: Matrix) => {
  const m = A.length;
  const n = A[0].length;

  const rank = computeRank(A);
  const nullBasis = nullSpace(A);

  const AT = A[0].map((_, j) => A.map((row) => row[j]));
  const leftNullBasis = nullSpace(AT);

  const { reduced, pivotCols } = rref(A);
  const colBasis = pivotCols.map((col) => A.map((row) => row[col]));

  const { reduced: rrefAT, pivotCols: rowPivots } = rref(AT);
  const rowBasis = rowPivots.map((i) => rrefAT[rowPivots.indexOf(i)]);

  return {
    columnSpace: { dim: rank, basis: colBasis },
    rowSpace: { dim: rank, basis: rowBasis },
    nullSpace: { dim: n - rank, basis: nullBasis },
    leftNullSpace: { dim: m - rank, basis: leftNullBasis },
  };
};
在数据科学中，四个基本子空间有清晰的实际意义：列空间是模型能表达的输出范围，行空间是数据的有效特征维度，零空间包含对输出无影响的输入方向，左零空间包含无法被数据解释的输出方向。


小结
    

  • 秩是矩阵中线性无关行/列的最大数目，反映矩阵的"信息含量"
    • 

  • 零空间是 Ax=0 的解集，其维度 = 列数 - 秩
    • 

  • 秩-零度定理 rank + nullity = n 将输入空间精确分为有效维度和零空间
    • 

  • 四个基本子空间构成线性代数的几何骨架，维度关系完全由秩决定
    • 

  • 秩在数据科学中对应数据的有效维度，是降维和特征选择的理论基础
    • 

  • 数值计算中，SVD 比行化简更稳定，适合处理近秩亏矩阵
