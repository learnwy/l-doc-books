矩阵对角化

核心概念

矩阵对角化是将方阵 A 分解为 A = PDP⁻¹ 的过程，其中 D 是对角矩阵（对角线上是特征值），P 是由对应特征向量组成的可逆矩阵。对角化使得矩阵幂运算、指数运算和微分方程求解变得极为简单：Aⁿ = PDⁿP⁻¹。

n×n 矩阵 A 可对角化当且仅当 A 有 n 个线性无关的特征向量，等价于每个特征值的几何重数等于代数重数。实对称矩阵一定可以正交对角化（A = QDQᵀ），这是最理想的情况。

对角化的判定与计算
对角化的核心步骤：(1) 求所有特征值；(2) 对每个特征值求特征空间；(3) 检查特征向量总数是否为 n；(4) 构造 P 和 D。


type Matrix = number[][];

const diagonalize = (
  A: Matrix,
): {
  P: Matrix;
  D: Matrix;
  Pinv: Matrix;
} | null => {
  const n = A.length;
  const eigenvalues = computeEigenvalues(A);
  const eigenvectors: number[][] = [];

  for (const lambda of eigenvalues) {
    const shifted = A.map((row, i) => row.map((val, j) => (i === j ? val - lambda : val)));
    const basis = nullSpace(shifted);
    eigenvectors.push(...basis);
  }

  if (eigenvectors.length !== n) return null;

  const P = eigenvectors[0].map((_, i) => eigenvectors.map((v) => v[i]));

  const uniqueEigen = [...new Set(eigenvalues)];
  const D: Matrix = Array.from({ length: n }, (_, i) =>
    Array.from({ length: n }, (_, j) => {
      if (i === j) {
        let idx = 0;
        for (const lambda of uniqueEigen) {
          const shifted = A.map((row, ri) => row.map((val, ci) => (ri === ci ? val - lambda : val)));
          const dim = nullSpace(shifted).length;
          if (i < idx + dim) return lambda;
          idx += dim;
        }
      }
      return 0;
    }),
  );

  const Pinv = invertMatrix(P);
  if (!Pinv) return null;
  return { P, D, Pinv };
};

const matrixPower = (A: Matrix, n: number): Matrix => {
  const result = diagonalize(A);
  if (!result) throw new Error('矩阵不可对角化');

  const { P, D, Pinv } = result;
  const size = D.length;
  const Dn: Matrix = Array.from({ length: size }, (_, i) =>
    Array.from({ length: size }, (_, j) => (i === j ? Math.pow(D[i][i], n) : 0)),
  );
  return matMul(matMul(P, Dn), Pinv);
};
对角化的一个重要应用是快速计算矩阵幂。例如 Fibonacci 数列可以用矩阵幂表示：F(n) 是矩阵 [[1,1],[1,0]] 的 n 次幂的 [0][1] 元素。对角化后，矩阵幂从 O(n) 次矩阵乘法降为 O(1)（仅需对角线元素取幂）。


矩阵指数与微分方程
矩阵指数 e^(At) 定义为幂级数 I + At + (At)²/2! + ...，它是线性常系数微分方程组 dx/dt = Ax 的解算子。当 A 可对角化时，e^(At) = P·diag(e^(λ₁t), ..., e^(λₙt))·P⁻¹。


const matrixExponential = (A: Matrix, t: number): Matrix => {
  const result = diagonalize(A);
  if (!result) {
    return matExpTaylor(A, t, 20);
  }

  const { P, D, Pinv } = result;
  const n = D.length;
  const expD: Matrix = Array.from({ length: n }, (_, i) =>
    Array.from({ length: n }, (_, j) => (i === j ? Math.exp(D[i][i] * t) : 0)),
  );
  return matMul(matMul(P, expD), Pinv);
};

const matExpTaylor = (A: Matrix, t: number, terms: number): Matrix => {
  const n = A.length;
  let result: Matrix = Array.from({ length: n }, (_, i) => Array.from({ length: n }, (_, j) => (i === j ? 1 : 0)));
  let power: Matrix = Array.from({ length: n }, (_, i) => Array.from({ length: n }, (_, j) => (i === j ? 1 : 0)));
  let factorial = 1;

  const tA = A.map((row) => row.map((v) => v * t));

  for (let k = 1; k <= terms; k++) {
    power = matMul(power, tA);
    factorial *= k;
    result = result.map((row, i) => row.map((val, j) => val + power[i][j] / factorial));
  }
  return result;
};
微分方程 dx/dt = Ax, x(0) = x₀ 的解是 x(t) = e^(At)·x₀。对角化后，解分解为 n 个独立的标量微分方程 yᵢ'(t) = λᵢyᵢ(t)，解为 yᵢ(t) = yᵢ(0)·e^(λᵢt)。特征值的实部决定稳定性：所有特征值实部为负则系统稳定。


相似矩阵与不变量
两个矩阵 A 和 B 相似，如果存在可逆矩阵 P 使得 B = P⁻¹AP。相似矩阵本质上表示同一个线性变换在不同基下的矩阵表示。对角化就是找到一个使矩阵表示最简的基。


相似矩阵共享一系列不变量：特征多项式相同（因此特征值相同）、迹相同、行列式相同、秩相同。但特征向量不同——它们在新基下有不同的坐标表示。


const areSimilar = (A: Matrix, B: Matrix): boolean => {
  const n = A.length;
  if (B.length !== n) return false;

  const traceA = A.reduce((s, row, i) => s + row[i], 0);
  const traceB = B.reduce((s, row, i) => s + row[i], 0);
  if (Math.abs(traceA - traceB) > 1e-10) return false;

  const detA = determinant(A);
  const detB = determinant(B);
  if (Math.abs(detA - detB) > 1e-10) return false;

  const polyA = characteristicPoly(A);
  const polyB = characteristicPoly(B);
  return polyA.every((c, i) => Math.abs(c - polyB[i]) < 1e-10);
};
在编程中，相似变换常用于将矩阵化为更容易处理的形式：上 Hessenberg 形（QR 算法的预处理步骤）、三对角形（对称矩阵）、Schur 形（上三角，所有矩阵都可以）。


小结
    

  • 对角化 A = PDP⁻¹ 要求有 n 个线性无关特征向量
    • 

  • 实对称矩阵一定可以正交对角化 A = QDQᵀ
    • 

  • 矩阵幂通过对角化降为 O(1) 计算：Aⁿ = PDⁿP⁻¹
    • 

  • 矩阵指数 e^(At) 是线性微分方程组的解算子
    • 

  • 特征值实部决定系统稳定性：全负实部→稳定
    • 

  • 相似矩阵共享特征多项式、迹、行列式等不变量
