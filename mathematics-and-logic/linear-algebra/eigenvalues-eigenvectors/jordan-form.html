若尔当标准形

核心概念

若尔当标准形（Jordan Normal Form）是不可对角化矩阵的"最简形式"。当矩阵的某些特征值的几何重数小于代数重数时，矩阵无法对角化，但总可以化为若尔当标准形——一种由若尔当块组成的准对角矩阵。

若尔当标准形 J = P⁻¹AP 由若干若尔当块 J(λ,k) 沿对角线排列构成。每个若尔当块是 k×k 矩阵，对角线为特征值 λ，超对角线为 1，其余为 0。对角化是若尔当形的特殊情况——所有若尔当块都是 1×1 的。

广义特征向量与若尔当链
当特征值 λ 的几何重数小于代数重数时，普通特征向量不够用，需要引入广义特征向量。k 阶广义特征向量满足 (A-λI)ᵏv = 0 但 (A-λI)ᵏ⁻¹v ≠ 0。


type Matrix = number[][];
type Vector = number[];

const generalizedEigenvectors = (A: Matrix, lambda: number, algebraicMult: number): Matrix => {
  const n = A.length;
  const shifted = A.map((row, i) => row.map((val, j) => (i === j ? val - lambda : val)));

  let power = shifted.map((row) => [...row]);
  const chains: Vector[][] = [];
  let prevNullDim = 0;

  for (let k = 1; k <= algebraicMult; k++) {
    const nullBasis = computeNullSpace(power);
    const currentDim = nullBasis.length;

    if (currentDim === algebraicMult) {
      const newVectors = currentDim - prevNullDim;
      for (let i = 0; i < newVectors; i++) {
        chains.push(buildChain(shifted, nullBasis[prevNullDim + i], k));
      }
      break;
    }

    prevNullDim = currentDim;
    power = matMul(power, shifted);
  }

  return chains.flat().map((v) => v);
};

const buildChain = (shifted: Matrix, topVector: Vector, length: number): Vector[] => {
  const chain: Vector[] = [topVector];
  let current = topVector;

  for (let i = 1; i < length; i++) {
    current = matVecMul(shifted, current);
    chain.unshift(current);
  }
  return chain;
};

const matVecMul = (A: Matrix, v: Vector): Vector => A.map((row) => row.reduce((s, a, j) => s + a * v[j], 0));
若尔当链从最高阶广义特征向量开始：vₖ 满足 (A-λI)ᵏvₖ = 0，然后 vₖ₋₁ = (A-λI)vₖ, ..., v₁ = (A-λI)v₂。v₁ 是普通特征向量。在若尔当块对应的基下，A 的作用是：Avₖ = λvₖ + vₖ₋₁（链内传递），Av₁ = λv₁（链头不变）。


若尔当形的计算
若尔当标准形的计算需要：确定每个特征值的若尔当块结构（块的大小和数量），然后求出对应的广义特征向量链。块结构由 Null((A-λI)ᵏ) 的维度递推确定。


const jordanStructure = (A: Matrix, lambda: number, algebraicMult: number): number[] => {
  const n = A.length;
  const shifted = A.map((row, i) => row.map((val, j) => (i === j ? val - lambda : val)));

  const dims: number[] = [];
  let power = shifted.map((row) => [...row]);

  for (let k = 1; k <= algebraicMult; k++) {
    const nullDim = computeNullSpace(power).length;
    dims.push(nullDim);
    if (nullDim === algebraicMult) break;
    power = matMul(power, shifted);
  }

  const blocks: number[] = [];
  for (let k = dims.length; k >= 1; k--) {
    const currentDim = dims[k - 1];
    const prevDim = k >= 2 ? dims[k - 2] : 0;
    const numBlocks = currentDim - prevDim;
    const prevBlocks = blocks.reduce((s, b) => s + (b >= k ? 1 : 0), 0);
    for (let i = 0; i < numBlocks - prevBlocks; i++) {
      blocks.push(k);
    }
  }
  return blocks.sort((a, b) => b - a);
};

const jordanBlock = (lambda: number, size: number): Matrix =>
  Array.from({ length: size }, (_, i) =>
    Array.from({ length: size }, (_, j) => {
      if (i === j) return lambda;
      if (j === i + 1) return 1;
      return 0;
    }),
  );
若尔当块大小的判定规则：设 rₖ = dim Null((A-λI)ᵏ)，则大小 ≥ k 的块数等于 rₖ - rₖ₋₁（其中 r₀ = 0）。例如，若 r₁ = 2, r₂ = 3, r₃ = 4 = 代数重数，则有 2 个大小≥1 的块，1 个大小≥2 的块，1 个大小≥3 的块，结构为 [3, 1]。


若尔当形的应用
若尔当标准形虽然数值上不稳定（微小扰动可能改变块结构），但在理论分析中极为重要。矩阵幂 Aⁿ 和矩阵指数 e^(At) 通过若尔当形得到精确公式。


const jordanBlockPower = (lambda: number, size: number, n: number): Matrix => {
  const result: Matrix = Array.from({ length: size }, () => new Array(size).fill(0));
  for (let i = 0; i < size; i++) {
    for (let j = i; j < size; j++) {
      const k = j - i;
      result[i][j] = binomial(n, k) * Math.pow(lambda, n - k);
    }
  }
  return result;
};

const jordanBlockExp = (lambda: number, size: number, t: number): Matrix => {
  const result: Matrix = Array.from({ length: size }, () => new Array(size).fill(0));
  const expLt = Math.exp(lambda * t);
  for (let i = 0; i < size; i++) {
    for (let j = i; j < size; j++) {
      const k = j - i;
      let factorial = 1;
      for (let f = 1; f <= k; f++) factorial *= f;
      result[i][j] = (expLt * Math.pow(t, k)) / factorial;
    }
  }
  return result;
};

const binomial = (n: number, k: number): number => {
  if (k < 0 || k > n) return 0;
  let result = 1;
  for (let i = 0; i < k; i++) {
    result *= (n - i) / (i + 1);
  }
  return result;
};
若尔当形还揭示了线性微分方程组的定性行为。k×k 若尔当块 J(λ,k) 对应的微分方程解包含 t^j·e^(λt) 项（j = 0, ..., k-1），块越大多项式次数越高。这解释了为什么不可对角化系统的动力学行为与可对角化系统有本质区别。


在数值计算中，由于若尔当形的数值不稳定性，实际更常使用 Schur 分解 A = QTQᵀ（T 为上三角），它总是存在且数值稳定。


小结
    

  • 若尔当标准形是不可对角化矩阵的最简形式，由若尔当块准对角排列
    • 

  • 广义特征向量满足 (A-λI)ᵏv = 0，通过若尔当链组织
    • 

  • 块结构由零空间维度序列的差分唯一确定
    • 

  • 若尔当块幂和指数有显式公式，包含多项式×指数项
    • 

  • 数值上若尔当形不稳定，实际计算更常用 Schur 分解
    • 

  • 若尔当形的理论价值在于提供了矩阵结构的完整分类
