特征值与特征多项式

核心概念

特征值和特征向量是线性代数中最深刻的概念之一。对于方阵 A，如果存在非零向量 v 和标量 λ，使得 Av = λv，则 λ 是 A 的特征值，v 是对应的特征向量。直觉上，特征向量是线性变换中方向不变（只被缩放）的向量，特征值是缩放因子。

特征值问题贯穿科学计算的方方面面：Google 的 PageRank 算法求邻接矩阵的主特征向量，量子力学中可观测量的测量值是算子的特征值，PCA 降维求协方差矩阵的特征值，振动分析求刚度矩阵的特征频率。

特征多项式与特征值求解
特征方程 det(A - λI) = 0 定义了特征多项式。展开后是 λ 的 n 次多项式 p(λ) = (-1)ⁿλⁿ + ... + det(A)。根据代数基本定理，n×n 矩阵在复数域上恰好有 n 个特征值（计重数）。


type Matrix = number[][];

const characteristicPoly = (A: Matrix): number[] => {
  const n = A.length;
  if (n === 1) return [-A[0][0], 1];
  if (n === 2) {
    const a = A[0][0],
      b = A[0][1],
      c = A[1][0],
      d = A[1][1];
    return [a * d - b * c, -(a + d), 1];
  }
  const trace = A.reduce((s, row, i) => s + row[i], 0);
  const det2 = A[0][0] * A[1][1] - A[0][1] * A[1][0];
  if (n === 3) {
    const det = determinant3x3(A);
    const cofSum = det2 + A[0][0] * A[2][2] - A[0][2] * A[2][0] + A[1][1] * A[2][2] - A[1][2] * A[2][1];
    return [-det, cofSum, -trace, 1];
  }
  return [];
};

const determinant3x3 = (A: Matrix): number =>
  A[0][0] * (A[1][1] * A[2][2] - A[1][2] * A[2][1]) -
  A[0][1] * (A[1][0] * A[2][2] - A[1][2] * A[2][0]) +
  A[0][2] * (A[1][0] * A[2][1] - A[1][1] * A[2][0]);

const eigenvalues2x2 = (A: Matrix): number[] => {
  const trace = A[0][0] + A[1][1];
  const det = A[0][0] * A[1][1] - A[0][1] * A[1][0];
  const discriminant = trace * trace - 4 * det;
  if (discriminant >= 0) {
    const sqrtD = Math.sqrt(discriminant);
    return [(trace + sqrtD) / 2, (trace - sqrtD) / 2];
  }
  return [];
};
对于大矩阵，直接展开特征多项式并求根既不实用也不稳定。实际算法使用迭代方法：幂法求最大特征值，QR 算法同时求所有特征值。Wilkinson 移位的隐式 QR 算法是工业级数值库的标准。


特征值的基本性质：所有特征值之和等于迹 tr(A) = Σλᵢ，所有特征值之积等于行列式 det(A) = Πλᵢ。这两个关系连接了矩阵的代数性质和几何性质。


幂法求主特征值
幂法（Power Iteration）是求矩阵绝对值最大的特征值（称为主特征值）的简单而有效的方法。基本思想：从任意非零初始向量 x₀ 出发，反复计算 xₖ₊₁ = Axₖ / ‖Axₖ‖，序列收敛到主特征向量。


const powerIteration = (
  A: Matrix,
  maxIter: number = 100,
  tol: number = 1e-10,
): { eigenvalue: number; eigenvector: number[] } => {
  const n = A.length;
  let x = Array.from({ length: n }, () => Math.random());
  let norm = Math.sqrt(x.reduce((s, v) => s + v * v, 0));
  x = x.map((v) => v / norm);

  let eigenvalue = 0;
  for (let iter = 0; iter < maxIter; iter++) {
    const Ax = A.map((row) => row.reduce((s, a, j) => s + a * x[j], 0));

    const newEigenvalue = x.reduce((s, v, i) => s + v * Ax[i], 0);
    norm = Math.sqrt(Ax.reduce((s, v) => s + v * v, 0));
    const newX = Ax.map((v) => v / norm);

    if (Math.abs(newEigenvalue - eigenvalue) < tol) {
      return { eigenvalue: newEigenvalue, eigenvector: newX };
    }
    eigenvalue = newEigenvalue;
    x = newX;
  }
  return { eigenvalue, eigenvector: x };
};
幂法的收敛速度取决于主特征值与第二大特征值的比值 |λ₂/λ₁|。比值越小，收敛越快。当两个最大特征值接近时，收敛很慢，需要加速技巧（如 Rayleigh 商迭代或移位）。


逆幂法（Inverse Power Iteration）通过求 A⁻¹ 的最大特征值来找 A 的最小特征值。带移位的逆幂法 (A - σI)⁻¹ 可以求最接近 σ 的特征值，是精化特征值估计的标准工具。


特征空间与特征向量计算
特征值 λ 对应的特征空间是 Null(A - λI)，即齐次方程组 (A - λI)x = 0 的解空间。特征空间的维度（几何重数）小于等于特征值的代数重数。


const findEigenvectors = (A: Matrix, eigenvalue: number): Matrix => {
  const n = A.length;
  const shifted = A.map((row, i) => row.map((val, j) => (i === j ? val - eigenvalue : val)));
  return nullSpace(shifted);
};

const nullSpace = (A: Matrix): Matrix => {
  const m = A.length,
    n = A[0].length;
  const R = A.map((row) => [...row]);
  const pivotCols: number[] = [];
  let rank = 0;

  for (let col = 0; col < n && rank < m; col++) {
    let maxRow = rank;
    for (let row = rank + 1; row < m; row++) {
      if (Math.abs(R[row][col]) > Math.abs(R[maxRow][col])) maxRow = row;
    }
    if (Math.abs(R[maxRow][col]) < 1e-10) continue;
    [R[rank], R[maxRow]] = [R[maxRow], R[rank]];
    const p = R[rank][col];
    for (let j = col; j < n; j++) R[rank][j] /= p;
    for (let row = 0; row < m; row++) {
      if (row !== rank) {
        const f = R[row][col];
        for (let j = col; j < n; j++) R[row][j] -= f * R[rank][j];
      }
    }
    pivotCols.push(col);
    rank++;
  }

  const freeCols = Array.from({ length: n }, (_, i) => i).filter((c) => !pivotCols.includes(c));
  return freeCols.map((fc) => {
    const v = new Array(n).fill(0);
    v[fc] = 1;
    for (let i = 0; i < rank; i++) v[pivotCols[i]] = -R[i][fc];
    return v;
  });
};

const A: Matrix = [
  [4, 1],
  [2, 3],
];
const lambdas = eigenvalues2x2(A);
lambdas.forEach((lambda) => {
  console.log(`λ = ${lambda}, 特征向量:`, findEigenvectors(A, lambda));
});
当代数重数大于几何重数时，矩阵不可对角化，需要使用若尔当标准形。这种情况在数值计算中很棘手——微小的扰动就可能使缺陷特征值分裂。


小结
    

  • 特征值 λ 和特征向量 v 满足 Av = λv，描述线性变换中的不变方向和缩放因子
    • 

  • 特征多项式 det(A-λI) = 0 理论上确定所有特征值，但直接求根数值不稳定
    • 

  • 幂法求主特征值简单有效，逆幂法和移位可求特定特征值
    • 

  • 迹 = 特征值之和，行列式 = 特征值之积，连接代数与几何性质
    • 

  • 几何重数 ≤ 代数重数，相等时可对角化，不等时需若尔当形
    • 

  • QR 算法是工业级特征值计算的标准方法
