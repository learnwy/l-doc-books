谱定理与对称矩阵

核心概念

谱定理是线性代数中最重要的定理之一，它断言：实对称矩阵一定可以正交对角化，即存在正交矩阵 Q 使得 A = QDQᵀ，其中 D 是对角矩阵。更深入地说，实对称矩阵的特征值全为实数，且不同特征值对应的特征向量彼此正交。

谱定理的"谱"（spectrum）指矩阵所有特征值的集合。这个定理在数学物理、量子力学、统计学和机器学习中具有深远影响。PCA、核方法、谱聚类、图拉普拉斯算子等核心算法都建立在谱定理的基础之上。

谱分解与投影
谱定理给出的分解 A = QDQᵀ 可以改写为谱分解形式：A = λ₁q₁q₁ᵀ + λ₂q₂q₂ᵀ + ... + λₙqₙqₙᵀ，其中 qᵢ 是单位正交特征向量，qᵢqᵢᵀ 是到 qᵢ 方向的投影矩阵。


type Matrix = number[][];
type Vector = number[];

const spectralDecomposition = (eigenvalues: number[], eigenvectors: Matrix): Matrix => {
  const n = eigenvalues.length;
  const result: Matrix = Array.from({ length: n }, () => new Array(n).fill(0));

  for (let k = 0; k < n; k++) {
    const q = eigenvectors.map((row) => row[k]);
    for (let i = 0; i < n; i++) {
      for (let j = 0; j < n; j++) {
        result[i][j] += eigenvalues[k] * q[i] * q[j];
      }
    }
  }
  return result;
};

const projectionMatrix = (q: Vector): Matrix => {
  const n = q.length;
  return Array.from({ length: n }, (_, i) => Array.from({ length: n }, (_, j) => q[i] * q[j]));
};

const orthogonalDiagonalize = (
  A: Matrix,
): {
  Q: Matrix;
  D: number[];
} => {
  const n = A.length;
  const { eigenvalues, eigenvectors } = symmetricEigen(A);
  const Q = gramSchmidt(eigenvectors);
  return { Q, D: eigenvalues };
};
谱分解的直觉：对称矩阵的作用等于先将向量投影到各特征方向，分别缩放（乘以特征值），再叠加。这是理解 PCA 的关键——PCA 就是将数据投影到协方差矩阵最大特征值对应的方向上。


每个投影矩阵 Pₖ = qₖqₖᵀ 满足 Pₖ² = Pₖ（幂等性），Pₖᵀ = Pₖ（对称性），且不同特征值的投影互不相交：PᵢPⱼ = 0（i ≠ j）。所有投影的和等于单位矩阵：P₁ + P₂ + ... + Pₙ = I。


Rayleigh 商与特征值极值
Rayleigh 商 R(x) = xᵀAx / xᵀx 是连接对称矩阵特征值与二次型的桥梁。对于实对称矩阵 A，Rayleigh 商的最大值等于最大特征值 λₘₐₓ，最小值等于最小特征值 λₘᵢₙ，极值在对应特征向量处取到。


const rayleighQuotient = (A: Matrix, x: Vector): number => {
  const Ax = A.map((row) => row.reduce((s, a, j) => s + a * x[j], 0));
  const xAx = x.reduce((s, v, i) => s + v * Ax[i], 0);
  const xx = x.reduce((s, v) => s + v * v, 0);
  return xAx / xx;
};

const rayleighIteration = (A: Matrix, maxIter: number = 50): { eigenvalue: number; eigenvector: Vector } => {
  const n = A.length;
  let x = Array.from({ length: n }, () => Math.random());
  let norm = Math.sqrt(x.reduce((s, v) => s + v * v, 0));
  x = x.map((v) => v / norm);
  let sigma = rayleighQuotient(A, x);

  for (let iter = 0; iter < maxIter; iter++) {
    const shifted = A.map((row, i) => row.map((val, j) => (i === j ? val - sigma : val)));
    const y = solveLinearSystem(shifted, x);
    if (!y) break;

    norm = Math.sqrt(y.reduce((s, v) => s + v * v, 0));
    x = y.map((v) => v / norm);
    const newSigma = rayleighQuotient(A, x);

    if (Math.abs(newSigma - sigma) < 1e-14) {
      return { eigenvalue: newSigma, eigenvector: x };
    }
    sigma = newSigma;
  }
  return { eigenvalue: sigma, eigenvector: x };
};
Rayleigh 商迭代具有三次收敛速度，是已知最快的特征值精化方法。Courant-Fischer 极小极大定理将 Rayleigh 商推广到子空间：第 k 个特征值等于 min(dim V=k) max(x∈V) R(x)。


正定矩阵与二次型
对称矩阵的正定性完全由特征值决定。正定矩阵（所有特征值为正）定义正定二次型 xᵀAx > 0（对所有非零 x）。正定矩阵在优化、统计和数值计算中扮演核心角色。


const isPositiveDefinite = (A: Matrix): boolean => {
  const n = A.length;
  for (let k = 1; k <= n; k++) {
    const submatrix = A.slice(0, k).map((row) => row.slice(0, k));
    if (determinant(submatrix) <= 0) return false;
  }
  return true;
};

const quadraticForm = (A: Matrix, x: Vector): number =>
  x.reduce((s, xi, i) => s + xi * A[i].reduce((ss, aij, j) => ss + aij * x[j], 0), 0);

const choleskyTest = (A: Matrix): boolean => {
  const n = A.length;
  const L: Matrix = Array.from({ length: n }, () => new Array(n).fill(0));
  for (let i = 0; i < n; i++) {
    for (let j = 0; j <= i; j++) {
      let sum = 0;
      for (let k = 0; k < j; k++) sum += L[i][k] * L[j][k];
      if (i === j) {
        const val = A[i][i] - sum;
        if (val <= 0) return false;
        L[i][j] = Math.sqrt(val);
      } else {
        L[i][j] = (A[i][j] - sum) / L[j][j];
      }
    }
  }
  return true;
};
正定性的等价条件：所有特征值为正、所有主子式（leading principal minors）为正、Cholesky 分解存在、存在可逆矩阵 B 使得 A = BᵀB。在优化中，Hessian 矩阵正定意味着驻点是严格局部最小值。


小结
    

  • 谱定理保证实对称矩阵可正交对角化，特征值全实，特征向量正交
    • 

  • 谱分解 A = Σλₖqₖqₖᵀ 揭示矩阵作用的本质：投影+缩放+叠加
    • 

  • Rayleigh 商连接特征值与二次型极值，迭代法具有三次收敛速度
    • 

  • 正定矩阵是优化和统计的核心：Hessian 正定 = 局部最小值
    • 

  • PCA、谱聚类等算法的数学基础都是谱定理及其推论
    • 

  • Cholesky 分解既是正定性检验工具，也是高效的求解方法
    •
