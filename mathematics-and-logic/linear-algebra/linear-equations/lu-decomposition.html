LU 分解

核心概念

LU 分解将方阵 A 分解为下三角矩阵 L（Lower）和上三角矩阵 U（Upper）的乘积：A = LU。这个分解本质上是高斯消元过程的矩阵形式记录——U 是消元后的上三角矩阵，L 记录了消元过程中使用的乘数。

LU 分解的价值在于"一次分解，多次求解"：分解一次 A = LU 需要 O(n³/3) 的计算量，之后每次求解 Ax = b 只需两次三角回代，各 O(n²/2)。当需要对同一个 A 求解多个不同右端向量时，LU 分解比反复做高斯消元高效得多。

LU 分解的算法实现
LU 分解的过程就是高斯消元，但同时记录消元乘数。在消元第 k 步，用第 k 行消去下方第 i 行时的乘数 l[i][k] = A[i][k] / A[k][k]，这些乘数恰好构成 L 的下三角部分。


type Matrix = number[][];

const luDecomposition = (
  A: Matrix,
): {
  L: Matrix;
  U: Matrix;
  success: boolean;
} => {
  const n = A.length;
  const L: Matrix = Array.from({ length: n }, (_, i) => Array.from({ length: n }, (_, j) => (i === j ? 1 : 0)));
  const U: Matrix = A.map((row) => [...row]);

  for (let k = 0; k < n; k++) {
    if (Math.abs(U[k][k]) < 1e-12) {
      return { L, U, success: false };
    }
    for (let i = k + 1; i < n; i++) {
      const factor = U[i][k] / U[k][k];
      L[i][k] = factor;
      for (let j = k; j < n; j++) {
        U[i][j] -= factor * U[k][j];
      }
    }
  }
  return { L, U, success: true };
};

const solveLU = (L: Matrix, U: Matrix, b: number[]): number[] => {
  const n = L.length;
  const y = new Array(n).fill(0);
  for (let i = 0; i < n; i++) {
    let sum = b[i];
    for (let j = 0; j < i; j++) sum -= L[i][j] * y[j];
    y[i] = sum;
  }

  const x = new Array(n).fill(0);
  for (let i = n - 1; i >= 0; i--) {
    let sum = y[i];
    for (let j = i + 1; j < n; j++) sum -= U[i][j] * x[j];
    x[i] = sum / U[i][i];
  }
  return x;
};
注意基本 LU 分解要求所有主子式（leading principal minors）非零，即消元过程中不会遇到零主元。当主元为零（或接近零）时，需要引入行交换——这就是 PLU 分解。


PLU 分解与行交换
PLU 分解 PA = LU 通过置换矩阵 P 记录行交换操作。置换矩阵是每行每列恰好有一个 1 的方阵，满足 PᵀP = I（正交矩阵）。P 记录了消元过程中所有行交换的累积效果。


const pluDecomposition = (
  A: Matrix,
): {
  P: number[];
  L: Matrix;
  U: Matrix;
} => {
  const n = A.length;
  const P = Array.from({ length: n }, (_, i) => i);
  const L: Matrix = Array.from({ length: n }, () => new Array(n).fill(0));
  const U: Matrix = A.map((row) => [...row]);

  for (let k = 0; k < n; k++) {
    let maxRow = k;
    for (let i = k + 1; i < n; i++) {
      if (Math.abs(U[i][k]) > Math.abs(U[maxRow][k])) maxRow = i;
    }

    if (maxRow !== k) {
      [U[k], U[maxRow]] = [U[maxRow], U[k]];
      [P[k], P[maxRow]] = [P[maxRow], P[k]];
      for (let j = 0; j < k; j++) {
        [L[k][j], L[maxRow][j]] = [L[maxRow][j], L[k][j]];
      }
    }

    L[k][k] = 1;
    for (let i = k + 1; i < n; i++) {
      if (Math.abs(U[k][k]) < 1e-12) continue;
      L[i][k] = U[i][k] / U[k][k];
      for (let j = k; j < n; j++) {
        U[i][j] -= L[i][k] * U[k][j];
      }
    }
  }
  return { P, L, U };
};

const solvePLU = (P: number[], L: Matrix, U: Matrix, b: number[]): number[] => {
  const n = b.length;
  const pb = P.map((i) => b[i]);
  return solveLU(L, U, pb);
};
PLU 分解对任意可逆矩阵都存在，是实际数值计算库（如 LAPACK）中求解线性方程组的标准方法。分解一次后，可以高效求解多个右端向量、计算行列式 det(A) = ±Π U[i][i]、以及判断可逆性。


Cholesky 分解
当矩阵 A 是对称正定矩阵时（Aᵀ = A 且所有特征值为正），LU 分解可以特化为 Cholesky 分解 A = LLᵀ，其中 L 是对角线元素为正的下三角矩阵。Cholesky 分解的计算量约为 n³/6，是一般 LU 分解的一半。


const choleskyDecomposition = (A: Matrix): Matrix | null => {
  const n = A.length;
  const L: Matrix = Array.from({ length: n }, () => new Array(n).fill(0));

  for (let i = 0; i < n; i++) {
    for (let j = 0; j <= i; j++) {
      let sum = 0;
      for (let k = 0; k < j; k++) {
        sum += L[i][k] * L[j][k];
      }
      if (i === j) {
        const diag = A[i][i] - sum;
        if (diag <= 0) return null;
        L[i][j] = Math.sqrt(diag);
      } else {
        L[i][j] = (A[i][j] - sum) / L[j][j];
      }
    }
  }
  return L;
};

const solveCholesky = (L: Matrix, b: number[]): number[] => {
  const n = L.length;
  const y = new Array(n).fill(0);
  for (let i = 0; i < n; i++) {
    let sum = b[i];
    for (let j = 0; j < i; j++) sum -= L[i][j] * y[j];
    y[i] = sum / L[i][i];
  }

  const x = new Array(n).fill(0);
  for (let i = n - 1; i >= 0; i--) {
    let sum = y[i];
    for (let j = i + 1; j < n; j++) sum -= L[j][i] * x[j];
    x[i] = sum / L[i][i];
  }
  return x;
};
Cholesky 分解在机器学习中应用广泛：高斯过程回归中的协方差矩阵求逆、多元正态分布的采样、最小二乘问题的正规方程求解。由于协方差矩阵天然是对称半正定的，Cholesky 分解是最自然的选择。


如果 Cholesky 分解过程中出现对角线元素为零或负数，说明矩阵不是正定的。这个性质使得 Cholesky 分解同时可以作为正定性检验工具。


小结
    

  • LU 分解将矩阵 A 分解为下三角 L 和上三角 U 的乘积，本质是高斯消元的矩阵记录
    • 

  • 分解一次 O(n³/3)，之后每次求解仅需 O(n²)，适合多右端向量问题
    • 

  • PLU 分解通过置换矩阵 P 引入行交换，对任意可逆矩阵都适用
    • 

  • Cholesky 分解利用对称正定性，计算量减半，数值稳定性更好
    • 

  • LU 分解是数值计算库的核心算法，LAPACK 中所有方程求解都基于此
    • 

  • Cholesky 分解在协方差矩阵处理、高斯过程等机器学习场景中广泛应用
    •
