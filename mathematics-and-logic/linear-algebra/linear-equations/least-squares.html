最小二乘法

核心概念

最小二乘法是处理超定线性方程组（方程数多于未知数）的标准方法。当 Ax = b 无精确解时，最小二乘法寻找使残差向量 r = b - Ax 的欧几里得范数 ‖r‖₂ 最小的向量 x。几何上，最小二乘解对应的 Ax̂ 是 b 在 A 的列空间上的正交投影。

最小二乘法是统计回归、信号处理、计算机视觉等领域的基础工具。线性回归、多项式拟合、曲线拟合等问题都可以转化为最小二乘问题。

正规方程推导与实现
最小二乘问题 min ‖Ax - b‖² 的解满足正规方程 AᵀAx = Aᵀb。推导过程：令 f(x) = ‖Ax-b‖² = (Ax-b)ᵀ(Ax-b) = xᵀAᵀAx - 2bᵀAx + bᵀb，对 x 求导并令其为零，得 2AᵀAx - 2Aᵀb = 0，即 AᵀAx = Aᵀb。


当 A 列满秩时，AᵀA 是对称正定矩阵，正规方程有唯一解 x = (AᵀA)⁻¹Aᵀb。


type Matrix = number[][];
type Vector = number[];

const transpose = (A: Matrix): Matrix => A[0].map((_, j) => A.map((row) => row[j]));

const matMul = (A: Matrix, B: Matrix): Matrix => {
  const m = A.length,
    p = B[0].length,
    n = A[0].length;
  return Array.from({ length: m }, (_, i) =>
    Array.from({ length: p }, (_, j) => {
      let s = 0;
      for (let k = 0; k < n; k++) s += A[i][k] * B[k][j];
      return s;
    }),
  );
};

const matVecMul = (A: Matrix, v: Vector): Vector => A.map((row) => row.reduce((s, a, i) => s + a * v[i], 0));

const normalEquationSolve = (A: Matrix, b: Vector): Vector => {
  const AT = transpose(A);
  const ATA = matMul(AT, A);
  const ATb = matVecMul(AT, b);
  const n = ATA.length;
  const aug = ATA.map((row, i) => [...row, ATb[i]]);

  for (let col = 0; col < n; col++) {
    let maxRow = col;
    for (let row = col + 1; row < n; row++) {
      if (Math.abs(aug[row][col]) > Math.abs(aug[maxRow][col])) maxRow = row;
    }
    [aug[col], aug[maxRow]] = [aug[maxRow], aug[col]];
    const pivot = aug[col][col];
    for (let j = col; j <= n; j++) aug[col][j] /= pivot;
    for (let row = 0; row < n; row++) {
      if (row !== col) {
        const f = aug[row][col];
        for (let j = col; j <= n; j++) aug[row][j] -= f * aug[col][j];
      }
    }
  }
  return aug.map((row) => row[n]);
};
正规方程的数值问题：AᵀA 的条件数是 A 的条件数的平方，κ(AᵀA) = κ(A)²。这意味着如果 A 已经是病态的（条件数大），形成 AᵀA 会使数值问题急剧恶化。因此对于病态问题，应使用 QR 分解或 SVD。


QR 分解求解最小二乘
QR 分解将 m×n 矩阵 A（m ≥ n）分解为正交矩阵 Q 和上三角矩阵 R 的乘积。由于正交变换不改变向量范数，‖Ax - b‖ = ‖QRx - b‖ = ‖Rx - Qᵀb‖，问题简化为求解上三角方程组 Rx = Qᵀb。


const qrDecomposition = (A: Matrix): { Q: Matrix; R: Matrix } => {
  const m = A.length;
  const n = A[0].length;
  const Q: Matrix = A.map((row) => [...row]);
  const R: Matrix = Array.from({ length: n }, () => new Array(n).fill(0));

  for (let j = 0; j < n; j++) {
    for (let i = 0; i < j; i++) {
      let dot = 0;
      for (let k = 0; k < m; k++) dot += Q[k][i] * A[k][j];
      R[i][j] = dot;
      for (let k = 0; k < m; k++) Q[k][j] -= dot * Q[k][i];
    }
    let norm = 0;
    for (let k = 0; k < m; k++) norm += Q[k][j] * Q[k][j];
    norm = Math.sqrt(norm);
    R[j][j] = norm;
    if (norm > 1e-12) {
      for (let k = 0; k < m; k++) Q[k][j] /= norm;
    }
  }
  return { Q, R };
};

const leastSquaresQR = (A: Matrix, b: Vector): Vector => {
  const { Q, R } = qrDecomposition(A);
  const n = R.length;
  const Qtb = Q[0].map((_, j) => Q.reduce((s, row, i) => s + row[j] * b[i], 0));

  const x = new Array(n).fill(0);
  for (let i = n - 1; i >= 0; i--) {
    let sum = Qtb[i];
    for (let j = i + 1; j < n; j++) sum -= R[i][j] * x[j];
    x[i] = sum / R[i][i];
  }
  return x;
};
QR 分解避免了形成 AᵀA，数值稳定性远优于正规方程法。Gram-Schmidt 正交化是最直观的 QR 算法，但经典版本数值不稳定，实际使用改进的 Gram-Schmidt 或 Householder 反射。


线性回归与多项式拟合
最小二乘法最直接的应用是线性回归：给定数据点 (x₁,y₁), ..., (xₘ,yₘ)，找到最佳拟合直线 y = a + bx。构造设计矩阵 A（第一列全1，第二列为 x 值），目标向量 b 为 y 值，最小二乘解 [a, b] 给出回归系数。


const linearRegression = (xs: number[], ys: number[]): { intercept: number; slope: number; rSquared: number } => {
  const m = xs.length;
  const A: Matrix = xs.map((x) => [1, x]);
  const coeffs = leastSquaresQR(A, ys);

  const yMean = ys.reduce((s, y) => s + y, 0) / m;
  let ssRes = 0,
    ssTot = 0;
  for (let i = 0; i < m; i++) {
    const yPred = coeffs[0] + coeffs[1] * xs[i];
    ssRes += (ys[i] - yPred) ** 2;
    ssTot += (ys[i] - yMean) ** 2;
  }

  return {
    intercept: coeffs[0],
    slope: coeffs[1],
    rSquared: 1 - ssRes / ssTot,
  };
};

const polyFit = (xs: number[], ys: number[], degree: number): number[] => {
  const A: Matrix = xs.map((x) => Array.from({ length: degree + 1 }, (_, d) => x ** d));
  return leastSquaresQR(A, ys);
};

const xs = [1, 2, 3, 4, 5];
const ys = [2.1, 3.9, 6.2, 7.8, 10.1];
console.log(linearRegression(xs, ys));
console.log(polyFit(xs, ys, 2));
R² 值（决定系数）衡量拟合优度，范围 [0,1]。R² = 1 表示完美拟合，R² = 0 表示模型与取均值无异。多项式拟合通过增大设计矩阵的列数来提高灵活性，但高次多项式容易过拟合——这引出了正则化的需求。


正则化最小二乘
当矩阵 A 病态或需要控制过拟合时，在目标函数中添加正则项。岭回归（Tikhonov 正则化）最小化 ‖Ax - b‖² + λ‖x‖²，正规方程变为 (AᵀA + λI)x = Aᵀb。


const ridgeRegression = (A: Matrix, b: Vector, lambda: number): Vector => {
  const AT = transpose(A);
  const ATA = matMul(AT, A);
  const n = ATA.length;
  for (let i = 0; i < n; i++) ATA[i][i] += lambda;
  const ATb = matVecMul(AT, b);

  const aug = ATA.map((row, i) => [...row, ATb[i]]);
  for (let col = 0; col < n; col++) {
    const pivot = aug[col][col];
    for (let j = col; j <= n; j++) aug[col][j] /= pivot;
    for (let row = 0; row < n; row++) {
      if (row !== col) {
        const f = aug[row][col];
        for (let j = col; j <= n; j++) aug[row][j] -= f * aug[col][j];
      }
    }
  }
  return aug.map((row) => row[n]);
};
正则化参数 λ 控制偏差-方差权衡：λ 过小接近普通最小二乘，可能过拟合；λ 过大使解趋于零，导致欠拟合。选择 λ 的常用方法包括交叉验证、L-曲线法和广义交叉验证（GCV）。


小结
    

  • 最小二乘法最小化超定系统的残差范数，解满足正规方程 AᵀAx = Aᵀb
    • 

  • QR 分解法避免形成 AᵀA，数值稳定性远优于正规方程直接求解
    • 

  • 线性回归和多项式拟合是最小二乘的经典应用，R² 衡量拟合优度
    • 

  • 正则化（岭回归）通过添加 λ‖x‖² 项控制过拟合和处理病态问题
    • 

  • 几何上，最小二乘解对应 b 在列空间的正交投影，残差正交于列空间
    • 

  • SVD 方法是处理秩亏和病态情况的最通用工具
