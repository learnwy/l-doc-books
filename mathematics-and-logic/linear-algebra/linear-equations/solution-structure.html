解的结构与存在性

核心概念

线性方程组 Ax = b 的解的结构是线性代数理论的核心问题之一。解的存在性、唯一性以及解集的几何形态，完全由系数矩阵 A 和增广矩阵 [A|b] 的秩关系决定。弗雷德霍姆替代定理（Fredholm Alternative）给出了关于解存在性的完整刻画。

理解解的结构不仅对理论推导重要，在实际编程中也至关重要：当线性系统无解时，我们需要最小二乘近似解；当有无穷多解时，我们需要选择特定解（如最小范数解）。

齐次与非齐次方程组
齐次方程组 Ax = 0 总有解（至少有零解），其解集构成一个子空间——零空间 Null(A)。零空间的维度等于 n - rank(A)，即自由变量的个数。


非齐次方程组 Ax = b 的解集（如果有解）是一个仿射子空间：通解 = 特解 x₀ + 齐次通解。几何上，解集是零空间经过平移的结果。


type Matrix = number[][];
type Vector = number[];

const solveSystem = (
  A: Matrix,
  b: Vector,
): {
  type: 'unique' | 'infinite' | 'none';
  particular?: Vector;
  nullBasis?: Matrix;
} => {
  const m = A.length;
  const n = A[0].length;
  const aug = A.map((row, i) => [...row, b[i]]);

  const { reduced, pivotCols } = toRREF(aug);
  const rankA = pivotCols.filter((c) => c < n).length;
  const rankAug = pivotCols.length;

  if (rankA < rankAug) {
    return { type: 'none' };
  }

  const particular = new Array(n).fill(0);
  for (let i = 0; i < rankA; i++) {
    particular[pivotCols[i]] = reduced[i][n];
  }

  if (rankA === n) {
    return { type: 'unique', particular };
  }

  const freeCols = Array.from({ length: n }, (_, i) => i).filter((c) => !pivotCols.includes(c));
  const nullBasis = freeCols.map((fc) => {
    const v = new Array(n).fill(0);
    v[fc] = 1;
    for (let i = 0; i < rankA; i++) {
      v[pivotCols[i]] = -reduced[i][fc];
    }
    return v;
  });

  return { type: 'infinite', particular, nullBasis };
};

const toRREF = (A: Matrix): { reduced: Matrix; pivotCols: number[] } => {
  const m = A.length;
  const n = A[0].length;
  const R = A.map((row) => [...row]);
  const pivotCols: number[] = [];
  let rank = 0;

  for (let col = 0; col < n && rank < m; col++) {
    let maxRow = rank;
    for (let row = rank + 1; row < m; row++) {
      if (Math.abs(R[row][col]) > Math.abs(R[maxRow][col])) maxRow = row;
    }
    if (Math.abs(R[maxRow][col]) < 1e-12) continue;
    [R[rank], R[maxRow]] = [R[maxRow], R[rank]];
    const p = R[rank][col];
    for (let j = col; j < n; j++) R[rank][j] /= p;
    for (let row = 0; row < m; row++) {
      if (row !== rank) {
        const f = R[row][col];
        for (let j = col; j < n; j++) R[row][j] -= f * R[rank][j];
      }
    }
    pivotCols.push(col);
    rank++;
  }
  return { reduced: R, pivotCols };
};
解的叠加原理是线性系统最重要的性质：如果 x₁ 是 Ax = b₁ 的解，x₂ 是 Ax = b₂ 的解，则 c₁x₁ + c₂x₂ 是 Ax = c₁b₁ + c₂b₂ 的解。这个性质在信号处理中广泛应用——系统对复合输入的响应等于各分量响应的叠加。


弗雷德霍姆替代定理
弗雷德霍姆替代定理给出了方程 Ax = b 可解性的完整刻画：Ax = b 有解当且仅当 b 正交于 A 的左零空间 Null(Aᵀ)，即对所有满足 Aᵀy = 0 的 y，都有 yᵀb = 0。


等价地说：Ax = b 有解当且仅当 b 在 A 的列空间中。这两个条件是同一回事，因为列空间和左零空间是正交互补的。


const isConsistent = (A: Matrix, b: Vector): boolean => {
  const m = A.length;
  const n = A[0].length;

  const AT = A[0].map((_, j) => A.map((row) => row[j]));
  const augAT = AT.map((row) => [...row]);
  const { pivotCols } = toRREF(augAT);
  const rankA = pivotCols.length;

  const augFull = A.map((row, i) => [...row, b[i]]);
  const { pivotCols: pivotsFull } = toRREF(augFull);
  const rankAug = pivotsFull.filter((c) => c <= n).length;

  return rankA === rankAug;
};

const leftNullSpace = (A: Matrix): Matrix => {
  const AT = A[0].map((_, j) => A.map((row) => row[j]));
  const m = AT.length;
  const n = AT[0].length;
  const { reduced, pivotCols } = toRREF(AT);
  const freeCols = Array.from({ length: n }, (_, i) => i).filter((c) => !pivotCols.includes(c));

  return freeCols.map((fc) => {
    const v = new Array(n).fill(0);
    v[fc] = 1;
    for (let i = 0; i < pivotCols.length; i++) {
      v[pivotCols[i]] = -reduced[i][fc];
    }
    return v;
  });
};
弗雷德霍姆替代定理有一个"替代"形式：要么 Ax = b 有解，要么存在 y 使得 Aᵀy = 0 且 yᵀb ≠ 0。两种情况恰好有一种成立——这就是"替代"的含义。


超定与欠定系统
超定系统（方程多于未知数，m > n）通常无精确解，需要最小二乘近似。欠定系统（方程少于未知数，m < n）通常有无穷多解，需要额外约束选择特定解。


超定系统的最小二乘解满足正规方程 AᵀAx = Aᵀb。当 A 列满秩时，AᵀA 可逆，唯一最小二乘解 x = (AᵀA)⁻¹Aᵀb。矩阵 A⁺ = (AᵀA)⁻¹Aᵀ 称为 A 的左伪逆。


欠定系统中，最小范数解 x = Aᵀ(AAᵀ)⁻¹b 是所有解中范数最小的。矩阵 A⁺ = Aᵀ(AAᵀ)⁻¹ 称为 A 的右伪逆。一般情况下，Moore-Penrose 伪逆 A⁺ 通过 SVD 定义，统一处理所有情况。


const transpose = (A: Matrix): Matrix => A[0].map((_, j) => A.map((row) => row[j]));

const matMul = (A: Matrix, B: Matrix): Matrix => {
  const m = A.length,
    p = B[0].length,
    n = A[0].length;
  return Array.from({ length: m }, (_, i) =>
    Array.from({ length: p }, (_, j) => {
      let sum = 0;
      for (let k = 0; k < n; k++) sum += A[i][k] * B[k][j];
      return sum;
    }),
  );
};

const leastSquares = (A: Matrix, b: Vector): Vector => {
  const AT = transpose(A);
  const ATA = matMul(AT, A);
  const ATb = AT.map((row) => row.reduce((sum, val, i) => sum + val * b[i], 0));

  const n = ATA.length;
  const aug = ATA.map((row, i) => [...row, ATb[i]]);
  const { reduced } = toRREF(aug);
  return reduced.map((row) => row[n]);
};
参数化解的表示
当方程组有无穷多解时，解集可以用参数化形式表示：x = x₀ + t₁v₁ + t₂v₂ + ... + tₖvₖ，其中 x₀ 是特解，v₁...vₖ 是零空间的基向量，t₁...tₖ 是任意参数。


const parametricSolution = (A: Matrix, b: Vector): string => {
  const result = solveSystem(A, b);

  if (result.type === 'none') return '方程组无解';
  if (result.type === 'unique') {
    return `唯一解: x = [${result.particular!.map((v) => v.toFixed(4)).join(', ')}]`;
  }

  const parts = [`x = [${result.particular!.map((v) => v.toFixed(4)).join(', ')}]`];
  result.nullBasis!.forEach((v, i) => {
    parts.push(`+ t${i + 1} * [${v.map((val) => val.toFixed(4)).join(', ')}]`);
  });
  return `无穷多解:\n${parts.join('\n')}`;
};

console.log(
  parametricSolution(
    [
      [1, 2, 3],
      [4, 5, 6],
      [7, 8, 9],
    ],
    [1, 2, 3],
  ),
);
参数化表示在优化问题中特别有用：当约束方程有无穷多可行解时，可以在解空间中搜索目标函数的最优值。支持向量机的对偶问题、神经网络的权重初始化都涉及在解空间中的选择。


小结
    

  • 线性方程组的解由系数矩阵和增广矩阵的秩关系完全确定
    • 

  • 通解 = 特解 + 零空间，解集是仿射子空间
    • 

  • 弗雷德霍姆替代定理：Ax=b 有解当且仅当 b 正交于左零空间
    • 

  • 超定系统用最小二乘近似，欠定系统选最小范数解
    • 

  • 叠加原理是线性系统的核心性质，使得复杂问题可分解处理
    • 

  • Moore-Penrose 伪逆通过 SVD 统一处理所有情况
