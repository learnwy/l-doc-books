高斯消元法

核心概念

高斯消元法是求解线性方程组的基石算法，它通过一系列初等行变换将增广矩阵化为行阶梯形（Row Echelon Form），再通过回代求解未知数。这个算法的时间复杂度为 O(n³)，是实际计算中求解线性方程组最常用的方法。

高斯消元法不仅用于求解方程，还用于计算行列式、求逆矩阵、判定秩和线性无关性。它是数值线性代数的基础，理解其原理和数值陷阱对于编写可靠的数学计算代码至关重要。

前向消元与行阶梯形
前向消元的核心思想是：从左到右逐列处理，对每列找到主元（pivot），然后用主元所在行消去该列下方所有元素。处理完所有列后，矩阵变为上三角形式（行阶梯形）。


type Matrix = number[][];

const forwardElimination = (augmented: Matrix): { ref: Matrix; swaps: number } => {
  const m = augmented.length;
  const n = augmented[0].length;
  const A = augmented.map((row) => [...row]);
  let swaps = 0;
  let pivotRow = 0;

  for (let col = 0; col < n - 1 && pivotRow < m; col++) {
    let maxRow = pivotRow;
    for (let row = pivotRow + 1; row < m; row++) {
      if (Math.abs(A[row][col]) > Math.abs(A[maxRow][col])) {
        maxRow = row;
      }
    }

    if (Math.abs(A[maxRow][col]) < 1e-12) continue;

    if (maxRow !== pivotRow) {
      [A[pivotRow], A[maxRow]] = [A[maxRow], A[pivotRow]];
      swaps++;
    }

    for (let row = pivotRow + 1; row < m; row++) {
      const factor = A[row][col] / A[pivotRow][col];
      for (let j = col; j < n; j++) {
        A[row][j] -= factor * A[pivotRow][j];
      }
    }
    pivotRow++;
  }
  return { ref: A, swaps };
};
初等行变换有三种：行交换（交换两行）、行倍乘（某行乘以非零常数）、行倍加（一行的倍数加到另一行）。这三种变换不改变方程组的解集，因为它们对应的是等价方程的变换。


行阶梯形的特征是：每一行的首个非零元素（主元）在上一行主元的右边；全零行在最下方。行最简阶梯形（RREF）还要求每个主元为 1，且主元所在列的其他元素全为 0。


回代与解的读取
得到行阶梯形后，通过回代（back substitution）从最后一个方程开始向上逐步求解。如果系统有唯一解，回代过程是确定性的；如果有自由变量，需要参数化表示解。


const backSubstitution = (ref: Matrix): number[] | null => {
  const m = ref.length;
  const n = ref[0].length - 1;
  const x = new Array(n).fill(0);

  for (let i = m - 1; i >= 0; i--) {
    let pivotCol = -1;
    for (let j = 0; j < n; j++) {
      if (Math.abs(ref[i][j]) > 1e-12) {
        pivotCol = j;
        break;
      }
    }
    if (pivotCol === -1) {
      if (Math.abs(ref[i][n]) > 1e-12) return null;
      continue;
    }

    let sum = ref[i][n];
    for (let j = pivotCol + 1; j < n; j++) {
      sum -= ref[i][j] * x[j];
    }
    x[pivotCol] = sum / ref[i][pivotCol];
  }
  return x;
};

const gaussianSolve = (A: Matrix, b: number[]): number[] | null => {
  const m = A.length;
  const n = A[0].length;
  const augmented = A.map((row, i) => [...row, b[i]]);
  const { ref } = forwardElimination(augmented);
  return backSubstitution(ref);
};

const A: Matrix = [
  [2, 1, -1],
  [-3, -1, 2],
  [-2, 1, 2],
];
const b = [8, -11, -3];
console.log(gaussianSolve(A, b));
解的分类取决于行阶梯形的结构：如果每列恰好有一个主元且无矛盾行，则唯一解；如果存在自由列，则无穷多解（解空间是一个仿射子空间）；如果出现形如 [0 0 ... 0 | c]（c≠0）的行，则无解。


部分选主元策略
不加选主元的高斯消元在遇到小主元时会产生严重的数值误差。部分选主元（partial pivoting）在每步选择当前列中绝对值最大的元素作为主元，通过行交换将其移到主元位置。


const gaussWithPartialPivot = (A: Matrix, b: number[]): number[] | null => {
  const n = A.length;
  const aug = A.map((row, i) => [...row, b[i]]);

  for (let col = 0; col < n; col++) {
    let maxRow = col;
    let maxVal = Math.abs(aug[col][col]);
    for (let row = col + 1; row < n; row++) {
      if (Math.abs(aug[row][col]) > maxVal) {
        maxVal = Math.abs(aug[row][col]);
        maxRow = row;
      }
    }

    if (maxVal < 1e-12) return null;
    [aug[col], aug[maxRow]] = [aug[maxRow], aug[col]];

    for (let row = col + 1; row < n; row++) {
      const factor = aug[row][col] / aug[col][col];
      for (let j = col; j <= n; j++) {
        aug[row][j] -= factor * aug[col][j];
      }
    }
  }

  const x = new Array(n).fill(0);
  for (let i = n - 1; i >= 0; i--) {
    let sum = aug[i][n];
    for (let j = i + 1; j < n; j++) {
      sum -= aug[i][j] * x[j];
    }
    x[i] = sum / aug[i][i];
  }
  return x;
};
考虑方程组 0.0001x₁ + x₂ = 1 和 x₁ + x₂ = 2。不选主元时，用 0.0001 作主元消元会导致 x₂ ≈ 1/0.0001 = 10000 的中间结果，浮点精度损失严重。选主元后交换两行，用 1 作主元，结果稳定得多。


高斯-约当消元
高斯-约当消元（Gauss-Jordan elimination）在前向消元的基础上，进一步消去主元上方的元素，将矩阵化为行最简阶梯形（RREF）。RREF 中每个主元为 1，且主元所在列其他元素全为 0。


const gaussJordan = (A: Matrix, b: number[]): number[] | null => {
  const n = A.length;
  const aug = A.map((row, i) => [...row, b[i]]);

  for (let col = 0; col < n; col++) {
    let maxRow = col;
    for (let row = col + 1; row < n; row++) {
      if (Math.abs(aug[row][col]) > Math.abs(aug[maxRow][col])) {
        maxRow = row;
      }
    }
    if (Math.abs(aug[maxRow][col]) < 1e-12) return null;
    [aug[col], aug[maxRow]] = [aug[maxRow], aug[col]];

    const pivot = aug[col][col];
    for (let j = col; j <= n; j++) aug[col][j] /= pivot;

    for (let row = 0; row < n; row++) {
      if (row !== col) {
        const factor = aug[row][col];
        for (let j = col; j <= n; j++) {
          aug[row][j] -= factor * aug[col][j];
        }
      }
    }
  }
  return aug.map((row) => row[n]);
};
高斯-约当法的运算量约为 n³/2，高于标准高斯消元的 n³/3 + n²/2。但它在求逆矩阵时特别方便：将 [A | I] 化为 [I | A⁻¹]，一步完成。在求解多个右端向量 Ax₁=b₁, Ax₂=b₂, ... 时，可以同时增广 [A | b₁ b₂ ...]，一次消元同时得到所有解。


小结
    

  • 高斯消元法通过初等行变换将增广矩阵化为行阶梯形，再回代求解
    • 

  • 前向消元 O(n³/3) + 回代 O(n²/2)，总计 O(n³)
    • 

  • 部分选主元通过选择最大绝对值主元避免数值不稳定
    • 

  • 解的存在唯一性由行阶梯形的结构决定：矛盾行→无解，自由列→无穷解
    • 

  • 高斯-约当法进一步化为 RREF，运算量稍大但可直接读取解
    • 

  • 高斯消元是 LU 分解、行列式计算、秩判定等算法的基础
