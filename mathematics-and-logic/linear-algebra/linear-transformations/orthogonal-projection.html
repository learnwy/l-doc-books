正交投影

核心概念

正交投影是线性代数中连接几何直觉和计算方法的桥梁。将向量 b 正交投影到子空间 W 上，就是在 W 中找到距 b 最近的点 p̂，使得误差向量 b - p̂ 正交于 W。正交投影矩阵 P 满足 P² = P（幂等性）和 Pᵀ = P（对称性）。

正交投影的应用无处不在：最小二乘法的几何解释就是将 b 投影到 A 的列空间；Gram-Schmidt 正交化的每一步都用到正交投影；信号处理中的滤波本质上是在频率子空间上的投影。

到直线的投影与向量分解
向量 b 到直线 span(a) 的正交投影是最简单的情况。投影向量 p = (aᵀb/aᵀa)·a，投影矩阵 P = aaᵀ/(aᵀa)。残差 e = b - p 正交于 a。


type Vector = number[];
type Matrix = number[][];

const dot = (u: Vector, v: Vector): number => u.reduce((s, ui, i) => s + ui * v[i], 0);

const projectOntoLine = (
  b: Vector,
  a: Vector,
): {
  projection: Vector;
  residual: Vector;
  coefficient: number;
} => {
  const coeff = dot(a, b) / dot(a, a);
  const projection = a.map((ai) => coeff * ai);
  const residual = b.map((bi, i) => bi - projection[i]);
  return { projection, residual, coefficient: coeff };
};

const projectionMatrixLine = (a: Vector): Matrix => {
  const n = a.length;
  const ata = dot(a, a);
  return Array.from({ length: n }, (_, i) => Array.from({ length: n }, (_, j) => (a[i] * a[j]) / ata));
};

const b = [3, 4];
const a = [1, 0];
const result = projectOntoLine(b, a);
console.log('投影:', result.projection);
console.log('残差:', result.residual);
console.log('验证正交:', dot(result.projection, result.residual));
向量分解 b = p + e 将 b 分为平行于 a 的分量 p 和垂直于 a 的分量 e。这在物理学中对应力的分解、速度的分解等，在数据分析中对应方差的分解。


到一般子空间的投影
将向量 b 投影到矩阵 A 的列空间 Col(A) 上，投影矩阵为 P = A(AᵀA)⁻¹Aᵀ。投影向量 p̂ = Pb，残差 e = b - p̂ 正交于 Col(A)，即 Aᵀ(b - Ax̂) = 0，这就是正规方程。


const transpose = (A: Matrix): Matrix => A[0].map((_, j) => A.map((row) => row[j]));

const matMul = (A: Matrix, B: Matrix): Matrix => {
  const m = A.length,
    p = B[0].length,
    n = A[0].length;
  return Array.from({ length: m }, (_, i) =>
    Array.from({ length: p }, (_, j) => {
      let s = 0;
      for (let k = 0; k < n; k++) s += A[i][k] * B[k][j];
      return s;
    }),
  );
};

const projectionMatrixSubspace = (A: Matrix): Matrix => {
  const AT = transpose(A);
  const ATA = matMul(AT, A);
  const ATAinv = invertMatrix(ATA);
  if (!ATAinv) throw new Error('列不满秩');
  return matMul(matMul(A, ATAinv), AT);
};

const projectOntoSubspace = (
  A: Matrix,
  b: Vector,
): {
  projection: Vector;
  residual: Vector;
} => {
  const P = projectionMatrixSubspace(A);
  const projection = P.map((row) => row.reduce((s, a, j) => s + a * b[j], 0));
  const residual = b.map((bi, i) => bi - projection[i]);
  return { projection, residual };
};
投影矩阵 P 的关键性质：P² = P（投影再投影不变）、Pᵀ = P（对称性保证正交）、rank(P) = rank(A)（投影到的子空间维度）、特征值只有 0 和 1（对应子空间内和子空间外）。


Gram-Schmidt 正交化
Gram-Schmidt 正交化过程将一组线性无关的向量转化为正交（或正交归一）的向量组，本质是反复做正交投影：从当前向量中减去它在已正交化向量上的投影分量。


const gramSchmidt = (vectors: Matrix): Matrix => {
  const m = vectors.length;
  const n = vectors[0].length;
  const Q: Matrix = [];

  for (let i = 0; i < n; i++) {
    const v = vectors.map((row) => row[i]);
    const u = [...v];

    for (let j = 0; j < Q.length; j++) {
      const qj = Q[j];
      const proj = dot(qj, v) / dot(qj, qj);
      for (let k = 0; k < m; k++) u[k] -= proj * qj[k];
    }

    const norm = Math.sqrt(dot(u, u));
    if (norm > 1e-10) {
      Q.push(u.map((x) => x / norm));
    }
  }
  return Q;
};

const qrViaGramSchmidt = (A: Matrix): { Q: Matrix; R: Matrix } => {
  const m = A.length,
    n = A[0].length;
  const cols = A[0].map((_, j) => A.map((row) => row[j]));
  const orthonormal = gramSchmidt(cols[0].map((_, i) => cols.map((c) => c[i])));

  const Q = orthonormal[0].map((_, i) => orthonormal.map((q) => q[i]));
  const QT = transpose(Q);
  const R = matMul(QT, A);
  return { Q, R };
};
经典 Gram-Schmidt 在数值上容易丢失正交性，改进的 Gram-Schmidt（Modified Gram-Schmidt）在每步使用最新的正交向量而非原始向量进行投影，数值稳定性显著提高。Householder 反射进一步提供了最佳的数值稳定性。


正交投影在 PCA 中的应用
PCA（主成分分析）的核心就是找到数据方差最大的投影方向。将数据投影到协方差矩阵最大特征值对应的特征向量方向上，可以在保留最多信息的同时降低维度。


const pca = (
  data: Matrix,
  k: number,
): {
  projectedData: Matrix;
  components: Matrix;
  explainedVariance: number[];
} => {
  const m = data.length,
    n = data[0].length;
  const mean = Array.from({ length: n }, (_, j) => data.reduce((s, row) => s + row[j], 0) / m);

  const centered = data.map((row) => row.map((val, j) => val - mean[j]));

  const cov = matMul(transpose(centered), centered).map((row) => row.map((v) => v / (m - 1)));

  const { eigenvalues, eigenvectors } = symmetricEigen(cov);
  const sortedIndices = eigenvalues
    .map((v, i) => ({ v, i }))
    .sort((a, b) => b.v - a.v)
    .map((x) => x.i);

  const components = sortedIndices.slice(0, k).map((i) => eigenvectors.map((row) => row[i]));

  const W = components[0].map((_, i) => components.map((c) => c[i]));
  const projectedData = matMul(centered, W);

  const totalVar = eigenvalues.reduce((s, v) => s + v, 0);
  const explainedVariance = sortedIndices.slice(0, k).map((i) => eigenvalues[i] / totalVar);

  return { projectedData, components, explainedVariance };
};
PCA 的投影矩阵 P = WᵀW，其中 W 的列是前 k 个主成分（最大特征值对应的特征向量）。重构误差等于被丢弃特征值之和，这就是选择 k 的依据——保留足够的主成分使得累计方差解释比超过阈值（如 95%）。


小结
    

  • 正交投影将向量分解为子空间内分量和正交残差，残差正交于子空间
    • 

  • 投影矩阵满足 P² = P 和 Pᵀ = P，特征值只有 0 和 1
    • 

  • Gram-Schmidt 正交化通过反复投影将向量组正交化，是 QR 分解的基础
    • 

  • PCA 通过将数据投影到协方差矩阵最大特征向量方向实现降维
    • 

  • 最小二乘法的几何解释就是将 b 正交投影到 A 的列空间
    • 

  • 正交投影在信号处理、统计和机器学习中无处不在
