内积空间与正交性

核心概念

内积空间是在向量空间的基础上增加了内积运算的结构，内积将两个向量映射为一个标量，定义了长度、角度和正交性的概念。在实向量空间中，标准内积 ⟨u,v⟩ = Σuᵢvᵢ 就是我们熟悉的点积。内积空间是距离度量、正交分解、最佳逼近等概念的数学基础。

内积必须满足四个公理：正定性 ⟨v,v⟩ ≥ 0（等号当且仅当 v=0）、对称性 ⟨u,v⟩ = ⟨v,u⟩、线性性 ⟨au+bw,v⟩ = a⟨u,v⟩ + b⟨w,v⟩。不同的内积定义了不同的几何结构——改变内积就是改变空间的"尺子"。

Cauchy-Schwarz 不等式与三角不等式
Cauchy-Schwarz 不等式是内积空间最基本的不等式：|⟨u,v⟩| ≤ ‖u‖·‖v‖，等号成立当且仅当 u 和 v 线性相关。这个不等式保证了余弦相似度的值在 [-1, 1] 范围内。


type Vector = number[];

const innerProduct = (u: Vector, v: Vector): number => u.reduce((s, ui, i) => s + ui * v[i], 0);

const norm = (v: Vector): number => Math.sqrt(innerProduct(v, v));

const distance = (u: Vector, v: Vector): number => norm(u.map((ui, i) => ui - v[i]));

const cosineSimilarity = (u: Vector, v: Vector): number => {
  const dotUV = innerProduct(u, v);
  const normU = norm(u);
  const normV = norm(v);
  if (normU < 1e-10 || normV < 1e-10) return 0;
  return dotUV / (normU * normV);
};

const verifyCauchySchwarz = (u: Vector, v: Vector): boolean => {
  const lhs = Math.abs(innerProduct(u, v));
  const rhs = norm(u) * norm(v);
  return lhs <= rhs + 1e-10;
};

const verifyTriangleInequality = (u: Vector, v: Vector): boolean => {
  const sum = u.map((ui, i) => ui + v[i]);
  return norm(sum) <= norm(u) + norm(v) + 1e-10;
};
三角不等式 ‖u+v‖ ≤ ‖u‖ + ‖v‖ 是 Cauchy-Schwarz 的直接推论。它保证了范数诱导的距离满足距离的三角不等式，即距离函数的合法性。


在机器学习中，余弦相似度 cos(θ) = ⟨u,v⟩/(‖u‖‖v‖) 被广泛用于文本相似度（TF-IDF 向量的余弦）、词嵌入相似度（Word2Vec）和推荐系统中。


加权内积与马氏距离
标准内积赋予所有坐标同等权重，但实际数据的各维度可能有不同的尺度和相关性。加权内积 ⟨u,v⟩_W = uᵀWv（W 是正定矩阵）定义了考虑特征相关性的度量。


type Matrix = number[][];

const weightedInnerProduct = (u: Vector, v: Vector, W: Matrix): number => {
  const Wv = W.map((row) => row.reduce((s, w, j) => s + w * v[j], 0));
  return u.reduce((s, ui, i) => s + ui * Wv[i], 0);
};

const mahalanobisDistance = (u: Vector, v: Vector, covInv: Matrix): number => {
  const diff = u.map((ui, i) => ui - v[i]);
  return Math.sqrt(weightedInnerProduct(diff, diff, covInv));
};

const euclideanDistance = (u: Vector, v: Vector): number => {
  const diff = u.map((ui, i) => ui - v[i]);
  return Math.sqrt(innerProduct(diff, diff));
};

const u = [2, 3];
const v = [5, 7];
console.log('欧氏距离:', euclideanDistance(u, v));

const covInv: Matrix = [
  [2, -1],
  [-1, 3],
];
console.log('马氏距离:', mahalanobisDistance(u, v, covInv));
马氏距离（Mahalanobis distance）使用协方差矩阵的逆作为权重：d²(u,v) = (u-v)ᵀΣ⁻¹(u-v)。马氏距离消除了各维度的尺度差异和相关性影响，是多元统计中"标准化"距离。高斯判别分析中，类别判定就是比较到各类均值的马氏距离。


正交基与坐标计算
在正交基（或正交归一基）下，坐标计算极为简便：向量 v 在正交归一基 {q₁, ..., qₙ} 下的坐标 cᵢ = ⟨v, qᵢ⟩。不需要解方程组，只需计算 n 次内积。


const orthonormalCoordinates = (v: Vector, basis: Matrix): Vector => basis.map((q) => innerProduct(v, q));

const reconstructFromBasis = (coords: Vector, basis: Matrix): Vector => {
  const n = basis[0].length;
  const result = new Array(n).fill(0);
  for (let i = 0; i < coords.length; i++) {
    for (let j = 0; j < n; j++) {
      result[j] += coords[i] * basis[i][j];
    }
  }
  return result;
};

const parseval = (v: Vector, orthoBasis: Matrix): boolean => {
  const normV2 = innerProduct(v, v);
  const sumCoords2 = orthoBasis.reduce((s, q) => s + innerProduct(v, q) ** 2, 0);
  return Math.abs(normV2 - sumCoords2) < 1e-10;
};
Parseval 等式 ‖v‖² = Σ|⟨v, qᵢ⟩|² 在正交归一基下成立，它说明向量的能量（范数的平方）等于各坐标分量能量之和。在信号处理中，Parseval 定理保证时域和频域的总能量相等（能量守恒）。


正交基的计算优势是巨大的：在一般基下，求坐标需要解 n×n 线性方程组（O(n³)），而在正交基下只需 n 次内积（O(n²)）。这就是为什么 QR 分解和正交化如此重要。


小结
    

  • 内积定义了长度、角度和正交性，是距离度量和相似度的数学基础
    • 

  • Cauchy-Schwarz 不等式保证余弦相似度合法，三角不等式保证距离合法
    • 

  • 加权内积和马氏距离考虑维度间的尺度差异和相关性
    • 

  • 正交基使坐标计算从 O(n³) 降为 O(n²)，是高效计算的关键
    • 

  • Parseval 等式保证正交分解的能量守恒
    • 

  • 余弦相似度在 NLP、推荐系统等领域被广泛使用
    •
