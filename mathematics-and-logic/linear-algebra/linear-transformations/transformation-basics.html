线性变换基础

核心概念

线性变换是向量空间之间保持线性结构的映射 T: V → W，满足两个条件：T(u + v) = T(u) + T(v) 和 T(cv) = cT(v)。矩阵乘法 Ax 就是从 R^n 到 R^m 的线性变换，而每个有限维线性变换都可以用矩阵表示。

线性变换的概念将矩阵从"数字表格"提升为"空间之间的映射"。旋转、反射、投影、缩放、剪切等几何操作都是线性变换，理解它们的矩阵表示是计算机图形学和机器学习的基础。

几何变换的矩阵表示
二维平面上的常见几何变换都有简洁的矩阵形式。理解这些变换是计算机图形学的基础。


type Matrix = number[][];
type Vector = number[];

const rotation2D = (theta: number): Matrix => [
  [Math.cos(theta), -Math.sin(theta)],
  [Math.sin(theta), Math.cos(theta)],
];

const reflection2D = (axis: 'x' | 'y' | 'origin' | number): Matrix => {
  if (axis === 'x')
    return [
      [1, 0],
      [0, -1],
    ];
  if (axis === 'y')
    return [
      [-1, 0],
      [0, 1],
    ];
  if (axis === 'origin')
    return [
      [-1, 0],
      [0, -1],
    ];
  const theta = axis;
  return [
    [Math.cos(2 * theta), Math.sin(2 * theta)],
    [Math.sin(2 * theta), -Math.cos(2 * theta)],
  ];
};

const projection2D = (direction: Vector): Matrix => {
  const [a, b] = direction;
  const norm2 = a * a + b * b;
  return [
    [(a * a) / norm2, (a * b) / norm2],
    [(a * b) / norm2, (b * b) / norm2],
  ];
};

const scaling2D = (sx: number, sy: number): Matrix => [
  [sx, 0],
  [0, sy],
];

const shear2D = (kx: number, ky: number): Matrix => [
  [1, kx],
  [ky, 1],
];

const applyTransform = (M: Matrix, v: Vector): Vector => M.map((row) => row.reduce((s, a, j) => s + a * v[j], 0));
三维旋转可以用绕三个坐标轴的旋转矩阵 Rx(α)、Ry(β)、Rz(γ) 的组合表示。欧拉角 (α, β, γ) 给出了任意三维旋转的参数化。但欧拉角存在万向锁（gimbal lock）问题，实际中常用四元数替代。


const rotationX = (a: number): Matrix => [
  [1, 0, 0],
  [0, Math.cos(a), -Math.sin(a)],
  [0, Math.sin(a), Math.cos(a)],
];

const rotationY = (b: number): Matrix => [
  [Math.cos(b), 0, Math.sin(b)],
  [0, 1, 0],
  [-Math.sin(b), 0, Math.cos(b)],
];

const rotationZ = (g: number): Matrix => [
  [Math.cos(g), -Math.sin(g), 0],
  [Math.sin(g), Math.cos(g), 0],
  [0, 0, 1],
];
线性变换的合成与逆
两个线性变换的合成 S∘T（先 T 后 S）对应矩阵乘法 BA（注意顺序反转）。这解释了为什么矩阵乘法不满足交换律——先旋转后缩放与先缩放后旋转通常不同。


const compose = (...matrices: Matrix[]): Matrix => matrices.reduce((acc, M) => matMul(M, acc));

const matMul = (A: Matrix, B: Matrix): Matrix => {
  const m = A.length,
    p = B[0].length,
    n = A[0].length;
  return Array.from({ length: m }, (_, i) =>
    Array.from({ length: p }, (_, j) => {
      let s = 0;
      for (let k = 0; k < n; k++) s += A[i][k] * B[k][j];
      return s;
    }),
  );
};

const rotThenScale = compose(scaling2D(2, 3), rotation2D(Math.PI / 4));
const scaleThenRot = compose(rotation2D(Math.PI / 4), scaling2D(2, 3));
如果线性变换 T 是可逆的（对应可逆矩阵），则存在逆变换 T⁻¹ 使得 T⁻¹∘T = T∘T⁻¹ = I（恒等变换）。旋转的逆是反向旋转，缩放的逆是倒数缩放，但投影没有逆（信息丢失不可恢复）。


仿射变换与齐次坐标
纯线性变换无法表示平移（平移不保持零向量），但通过齐次坐标可以将平移统一为矩阵乘法。在 n 维空间中使用 (n+1) 维齐次坐标，点 (x,y) 表示为 (x,y,1)，仿射变换用 (n+1)×(n+1) 矩阵表示。


const translate2D = (tx: number, ty: number): Matrix => [
  [1, 0, tx],
  [0, 1, ty],
  [0, 0, 1],
];

const affineRotation2D = (theta: number): Matrix => [
  [Math.cos(theta), -Math.sin(theta), 0],
  [Math.sin(theta), Math.cos(theta), 0],
  [0, 0, 1],
];

const affineScaling2D = (sx: number, sy: number): Matrix => [
  [sx, 0, 0],
  [0, sy, 0],
  [0, 0, 1],
];

const affineTransform = (M: Matrix, point: Vector): Vector => {
  const homo = [...point, 1];
  const result = M.map((row) => row.reduce((s, a, j) => s + a * homo[j], 0));
  return result.slice(0, point.length);
};

const combined = compose(translate2D(5, 3), affineRotation2D(Math.PI / 6), affineScaling2D(2, 2));
齐次坐标在计算机图形学中是标准技术。三维场景渲染的模型-视图-投影（MVP）矩阵就是一系列仿射变换的组合，全部通过 4×4 矩阵的乘法实现。


小结
    

  • 线性变换保持加法和标量乘法，有限维线性变换等价于矩阵乘法
    • 

  • 旋转、反射、投影、缩放、剪切是基本几何线性变换
    • 

  • 变换合成对应矩阵乘法（顺序反转），逆变换对应逆矩阵
    • 

  • 仿射变换通过齐次坐标统一为矩阵乘法，包含了平移
    • 

  • 计算机图形学的 MVP 矩阵是仿射变换合成的核心应用
    • 

  • 理解线性变换的几何意义是连接抽象代数和实际应用的桥梁
    •
