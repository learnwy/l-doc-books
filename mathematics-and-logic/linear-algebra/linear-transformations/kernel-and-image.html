核与像

核心概念

线性变换 T: V → W 的核（kernel）和像（image）是理解变换结构的两个基本子空间。核 ker(T) = {v ∈ V : T(v) = 0} 是输入空间中被映射到零的所有向量的集合，像 im(T) = {T(v) : v ∈ V} 是输出空间中所有可达向量的集合。核和像分别对应矩阵的零空间和列空间。

维度公式（秩-零度定理的变换版本）给出了核与像之间的精确关系：dim(ker T) + dim(im T) = dim V。这个等式说明输入空间的维度被精确地分配给了"被压扁"的部分（核）和"有效输出"的部分（像）。

核的计算与单射判定
核的计算等价于求解齐次方程组 Ax = 0。核为零空间 {0} 意味着 T 是单射（一一映射）——不同输入必有不同输出。


type Matrix = number[][];
type Vector = number[];

const computeKernel = (A: Matrix): { basis: Matrix; dimension: number } => {
  const m = A.length,
    n = A[0].length;
  const R = A.map((row) => [...row]);
  const pivotCols: number[] = [];
  let rank = 0;

  for (let col = 0; col < n && rank < m; col++) {
    let maxRow = rank;
    for (let row = rank + 1; row < m; row++) {
      if (Math.abs(R[row][col]) > Math.abs(R[maxRow][col])) maxRow = row;
    }
    if (Math.abs(R[maxRow][col]) < 1e-10) continue;
    [R[rank], R[maxRow]] = [R[maxRow], R[rank]];
    const p = R[rank][col];
    for (let j = col; j < n; j++) R[rank][j] /= p;
    for (let row = 0; row < m; row++) {
      if (row !== rank) {
        const f = R[row][col];
        for (let j = col; j < n; j++) R[row][j] -= f * R[rank][j];
      }
    }
    pivotCols.push(col);
    rank++;
  }

  const freeCols = Array.from({ length: n }, (_, i) => i).filter((c) => !pivotCols.includes(c));

  const basis = freeCols.map((fc) => {
    const v = new Array(n).fill(0);
    v[fc] = 1;
    for (let i = 0; i < rank; i++) v[pivotCols[i]] = -R[i][fc];
    return v;
  });

  return { basis, dimension: freeCols.length };
};

const isInjective = (A: Matrix): boolean => computeKernel(A).dimension === 0;
单射性在编码理论中意味着信息可以完美恢复——如果编码映射是单射的，那么每个码字对应唯一的消息。在机器学习中，如果特征提取函数是单射的，则不同数据点的特征表示必然不同。


像的计算与满射判定
像等于矩阵 A 的列空间 Col(A)，由 A 的列向量张成。像的维度等于矩阵的秩。T 是满射（onto）当且仅当 im(T) = W，即 rank(A) = dim W = m。


const computeImage = (A: Matrix): { basis: Matrix; dimension: number } => {
  const m = A.length,
    n = A[0].length;
  const R = A.map((row) => [...row]);
  const pivotCols: number[] = [];
  let rank = 0;

  for (let col = 0; col < n && rank < m; col++) {
    let maxRow = rank;
    for (let row = rank + 1; row < m; row++) {
      if (Math.abs(R[row][col]) > Math.abs(R[maxRow][col])) maxRow = row;
    }
    if (Math.abs(R[maxRow][col]) < 1e-10) continue;
    [R[rank], R[maxRow]] = [R[maxRow], R[rank]];
    const p = R[rank][col];
    for (let j = col; j < n; j++) R[rank][j] /= p;
    for (let row = 0; row < m; row++) {
      if (row !== rank) {
        const f = R[row][col];
        for (let j = col; j < n; j++) R[row][j] -= f * R[rank][j];
      }
    }
    pivotCols.push(col);
    rank++;
  }

  const basis = pivotCols.map((col) => A.map((row) => row[col]));
  return { basis, dimension: rank };
};

const isSurjective = (A: Matrix): boolean => computeImage(A).dimension === A.length;

const isIsomorphism = (A: Matrix): boolean => isInjective(A) && isSurjective(A);
维度公式 dim(ker T) + dim(im T) = dim V 有直接的编程意义：如果输入有 n 个特征，核的维度为 k，那么变换只保留了 n-k 个有效维度。在神经网络中，如果某一层的权重矩阵的秩远小于输入维度，说明该层存在严重的信息瓶颈。


同构与维度等价
两个向量空间 V 和 W 同构（V ≅ W）当且仅当存在可逆线性变换 T: V → W。同构保持所有线性结构——维度、线性无关性、子空间关系。一个关键结论：两个有限维向量空间同构当且仅当它们的维度相同。


const checkIsomorphism = (
  A: Matrix,
): {
  isIso: boolean;
  kernel: { basis: Matrix; dimension: number };
  image: { basis: Matrix; dimension: number };
} => {
  const kernel = computeKernel(A);
  const image = computeImage(A);
  const m = A.length,
    n = A[0].length;

  return {
    isIso: kernel.dimension === 0 && image.dimension === m && m === n,
    kernel,
    image,
  };
};

const findInverse = (A: Matrix): Matrix | null => {
  const n = A.length;
  if (A[0].length !== n) return null;
  const aug = A.map((row, i) => [...row, ...Array.from({ length: n }, (_, j) => (i === j ? 1 : 0))]);

  for (let col = 0; col < n; col++) {
    let maxRow = col;
    for (let row = col + 1; row < n; row++) {
      if (Math.abs(aug[row][col]) > Math.abs(aug[maxRow][col])) maxRow = row;
    }
    if (Math.abs(aug[maxRow][col]) < 1e-10) return null;
    [aug[col], aug[maxRow]] = [aug[maxRow], aug[col]];
    const pivot = aug[col][col];
    for (let j = 0; j < 2 * n; j++) aug[col][j] /= pivot;
    for (let row = 0; row < n; row++) {
      if (row !== col) {
        const f = aug[row][col];
        for (let j = 0; j < 2 * n; j++) aug[row][j] -= f * aug[col][j];
      }
    }
  }
  return aug.map((row) => row.slice(n));
};
同构在编程中意味着可以自由地在两个空间之间转换而不丢失信息。坐标变换就是典型的同构——同一个向量在不同基下有不同的坐标表示，但信息完全保持。


小结
    

  • 核是被映射到零的向量集合，等价于零空间；像是变换的值域，等价于列空间
    • 

  • 维度公式 dim(ker T) + dim(im T) = dim V 精确分配输入空间的维度
    • 

  • 单射 ⟺ ker = {0}，满射 ⟺ im = W，同构 ⟺ 双射
    • 

  • 核的维度衡量信息丢失程度，像的维度衡量有效输出维度
    • 

  • 同构在有限维空间中等价于维度相同，保持所有线性结构
    • 

  • 在神经网络中，权重矩阵的秩反映了信息通道的有效宽度
    •
