基变换

核心概念

基变换是同一个向量在不同基下坐标表示之间的转换。当向量空间 V 有两组基 B = {b₁,...,bₙ} 和 B' = {b₁',...,bₙ'}，向量 v 在基 B 下的坐标 [v]_B 和在基 B' 下的坐标 [v]_B' 通过过渡矩阵（change-of-basis matrix）P 关联：[v]_B' = P⁻¹[v]_B。

基变换的核心意义在于：线性变换的矩阵表示依赖于基的选择。通过选择"好的"基（如特征向量基），可以使变换矩阵变为最简形式（如对角矩阵），从而简化计算和分析。对角化就是一种基变换。

过渡矩阵的构造
过渡矩阵 P 从基 B' 到基 B 的转换：P 的列向量是 B' 的基向量在标准基下的坐标。如果两组基都不是标准基，可以通过标准基作为中介：P*{B→B'} = (P*{std→B'})⁻¹ · P_{std→B}。


type Matrix = number[][];
type Vector = number[];

const changeOfBasisMatrix = (fromBasis: Matrix, toBasis: Matrix): Matrix => {
  const n = fromBasis.length;
  const toBasisInv = invertMatrix(toBasis);
  if (!toBasisInv) throw new Error('目标基不可逆');
  return matMul(toBasisInv, fromBasis);
};

const transformCoordinates = (coords: Vector, transitionMatrix: Matrix): Vector =>
  transitionMatrix.map((row) => row.reduce((s, p, j) => s + p * coords[j], 0));

const matMul = (A: Matrix, B: Matrix): Matrix => {
  const m = A.length,
    p = B[0].length,
    n = A[0].length;
  return Array.from({ length: m }, (_, i) =>
    Array.from({ length: p }, (_, j) => {
      let s = 0;
      for (let k = 0; k < n; k++) s += A[i][k] * B[k][j];
      return s;
    }),
  );
};

const standardBasis = (n: number): Matrix =>
  Array.from({ length: n }, (_, i) => Array.from({ length: n }, (_, j) => (i === j ? 1 : 0)));

const invertMatrix = (A: Matrix): Matrix | null => {
  const n = A.length;
  const aug = A.map((row, i) => [...row, ...Array.from({ length: n }, (_, j) => (i === j ? 1 : 0))]);
  for (let col = 0; col < n; col++) {
    let maxRow = col;
    for (let row = col + 1; row < n; row++) {
      if (Math.abs(aug[row][col]) > Math.abs(aug[maxRow][col])) maxRow = row;
    }
    if (Math.abs(aug[maxRow][col]) < 1e-10) return null;
    [aug[col], aug[maxRow]] = [aug[maxRow], aug[col]];
    const pivot = aug[col][col];
    for (let j = 0; j < 2 * n; j++) aug[col][j] /= pivot;
    for (let row = 0; row < n; row++) {
      if (row !== col) {
        const f = aug[row][col];
        for (let j = 0; j < 2 * n; j++) aug[row][j] -= f * aug[col][j];
      }
    }
  }
  return aug.map((row) => row.slice(n));
};
在实际计算中，过渡矩阵最常见的用途是将标准基下的矩阵转换为特征向量基下的对角矩阵：D = P⁻¹AP，其中 P 的列是 A 的特征向量。


相似变换与矩阵表示
同一个线性变换 T 在不同基下有不同的矩阵表示，它们通过相似变换联系：[T]_B' = P⁻¹[T]_B P。相似矩阵共享特征多项式、特征值、迹、行列式、秩等不变量。


const similarTransform = (A: Matrix, P: Matrix): Matrix => {
  const Pinv = invertMatrix(P);
  if (!Pinv) throw new Error('变换矩阵不可逆');
  return matMul(matMul(Pinv, A), P);
};

const verifyInvariants = (A: Matrix, B: Matrix): boolean => {
  const n = A.length;
  const traceA = A.reduce((s, row, i) => s + row[i], 0);
  const traceB = B.reduce((s, row, i) => s + row[i], 0);
  if (Math.abs(traceA - traceB) > 1e-8) return false;

  const detA = computeDeterminant(A);
  const detB = computeDeterminant(B);
  if (Math.abs(detA - detB) > 1e-8) return false;

  const rankA = computeRank(A);
  const rankB = computeRank(B);
  return rankA === rankB;
};

const diagonalizeViaChange = (
  A: Matrix,
): {
  D: Matrix;
  P: Matrix;
} | null => {
  const eigenPairs = computeEigenPairs(A);
  if (eigenPairs.length !== A.length) return null;

  const P = eigenPairs[0].vector.map((_, i) => eigenPairs.map((ep) => ep.vector[i]));
  const D = similarTransform(A, P);
  return { D, P };
};
选择特征向量作为基是最重要的基变换——它使矩阵对角化。对称矩阵的正交对角化 A = QDQᵀ 更优美：过渡矩阵 Q 是正交的，变换后 Q⁻¹ = Qᵀ，计算高效且数值稳定。


坐标系在工程中的应用
基变换在工程中对应坐标系转换：机器人学中世界坐标系与关节坐标系之间的转换、计算机图形学中模型空间到视图空间的变换、信号处理中时域到频域的变换。


const worldToCamera = (worldPoint: Vector, cameraPosition: Vector, cameraOrientation: Matrix): Vector => {
  const translated = worldPoint.map((w, i) => w - cameraPosition[i]);
  return cameraOrientation.map((row) => row.reduce((s, r, i) => s + r * translated[i], 0));
};

const robotForwardKinematics = (jointAngles: number[], linkLengths: number[]): Vector => {
  let x = 0,
    y = 0,
    totalAngle = 0;
  for (let i = 0; i < jointAngles.length; i++) {
    totalAngle += jointAngles[i];
    x += linkLengths[i] * Math.cos(totalAngle);
    y += linkLengths[i] * Math.sin(totalAngle);
  }
  return [x, y];
};

const fourierBasisChange = (signal: Vector): Vector => {
  const N = signal.length;
  const result: Vector = new Array(N).fill(0);
  for (let k = 0; k < N; k++) {
    for (let n = 0; n < N; n++) {
      result[k] += signal[n] * Math.cos((2 * Math.PI * k * n) / N);
    }
  }
  return result;
};
傅里叶变换可以看作基变换：从标准基（时域采样点）变换到频率基（正弦/余弦函数）。信号在频率基下的坐标就是其频谱，往往比时域表示更紧凑，这就是频域压缩的原理。
