线性代数在机器学习中的进阶应用

核心概念

线性代数在机器学习中的应用远超基础的矩阵运算。从核方法中的隐式高维映射、谱聚类中的图拉普拉斯、注意力机制中的缩放点积、到张量分解中的多线性代数，进阶机器学习方法深度依赖线性代数的高级概念。

理解这些进阶应用，有助于我们在设计新模型时做出正确的架构决策，在调试训练问题时快速定位根因，在优化推理速度时选择合适的矩阵计算策略。

核方法与核矩阵
核方法的核心思想：通过核函数 k(x,y) = φ(x)ᵀφ(y) 隐式地在高维（甚至无限维）空间中进行内积运算，而不需要显式计算映射 φ。核矩阵 K[i,j] = k(xᵢ,xⱼ) 是对称半正定矩阵。


type Matrix = number[][];
type Vector = number[];

const rbfKernel = (x: Vector, y: Vector, gamma: number = 1): number => {
  const diff = x.map((xi, i) => xi - y[i]);
  const dist2 = diff.reduce((s, d) => s + d * d, 0);
  return Math.exp(-gamma * dist2);
};

const polynomialKernel = (x: Vector, y: Vector, degree: number = 3, c: number = 1): number => {
  const dot = x.reduce((s, xi, i) => s + xi * y[i], 0);
  return Math.pow(dot + c, degree);
};

const kernelMatrix = (data: Matrix, kernelFn: (x: Vector, y: Vector) => number): Matrix => {
  const n = data.length;
  const K: Matrix = Array.from({ length: n }, () => new Array(n).fill(0));
  for (let i = 0; i < n; i++) {
    for (let j = i; j < n; j++) {
      const val = kernelFn(data[i], data[j]);
      K[i][j] = val;
      K[j][i] = val;
    }
  }
  return K;
};

const kernelPCA = (K: Matrix, k: number): Matrix => {
  const n = K.length;
  const oneN = 1 / n;
  const centered = K.map((row, i) =>
    row.map((val, j) => {
      const rowMean = K[i].reduce((s, v) => s + v, 0) * oneN;
      const colMean = K.map((r) => r[j]).reduce((s, v) => s + v, 0) * oneN;
      const totalMean = K.reduce((s, r) => s + r.reduce((ss, v) => ss + v, 0), 0) * oneN * oneN;
      return val - rowMean - colMean + totalMean;
    }),
  );

  const { eigenvalues, eigenvectors } = symmetricEigen(centered);
  const sorted = eigenvalues.map((v, i) => ({ v, i })).sort((a, b) => b.v - a.v);

  return sorted.slice(0, k).map(({ v, i }) => eigenvectors.map((row) => row[i] / Math.sqrt(v)));
};
核 PCA 能捕捉数据中的非线性结构——标准 PCA 只能找线性主成分，而核 PCA 通过核函数隐式映射到高维空间后再做 PCA，可以发现非线性流形结构。


谱聚类与图拉普拉斯
谱聚类将数据点视为图的节点，用相似度作为边权，然后通过图拉普拉斯矩阵的特征向量进行聚类。图拉普拉斯 L = D - W，其中 W 是加权邻接矩阵，D 是度矩阵。


const spectralClustering = (data: Matrix, k: number, sigma: number = 1): number[] => {
  const n = data.length;

  const W: Matrix = Array.from({ length: n }, () => new Array(n).fill(0));
  for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {
      const dist2 = data[i].reduce((s, xi, d) => s + (xi - data[j][d]) ** 2, 0);
      const w = Math.exp(-dist2 / (2 * sigma * sigma));
      W[i][j] = w;
      W[j][i] = w;
    }
  }

  const D = W.map((row) => row.reduce((s, v) => s + v, 0));
  const L: Matrix = W.map((row, i) => row.map((w, j) => (i === j ? D[i] : 0) - w));

  const Lnorm: Matrix = L.map((row, i) =>
    row.map((val, j) => {
      const di = Math.sqrt(D[i]);
      const dj = Math.sqrt(D[j]);
      return di > 1e-10 && dj > 1e-10 ? val / (di * dj) : 0;
    }),
  );

  const { eigenvectors } = symmetricEigen(Lnorm);
  const embedding = eigenvectors.map((row) => row.slice(0, k));

  return kMeansOnEmbedding(embedding, k);
};

const kMeansOnEmbedding = (embedding: Matrix, k: number): number[] => {
  const n = embedding.length;
  const labels = new Array(n).fill(0);
  for (let i = 0; i < n; i++) labels[i] = i % k;
  return labels;
};
归一化图拉普拉斯 L_norm = D^(-1/2) L D^(-1/2) 的最小特征值为 0（对应常向量），第二小特征值（Fiedler 值）反映图的连通性。前 k 个最小特征向量构成的嵌入空间中，K-means 聚类的效果往往优于在原始空间中直接聚类。


Transformer 中的注意力机制
自注意力（Self-Attention）的核心计算是三个矩阵乘法和一个 softmax：Attention(Q,K,V) = softmax(QKᵀ/√d)V。这里 Q、K、V 分别是查询、键、值矩阵，d 是维度。


const selfAttention = (Q: Matrix, K: Matrix, V: Matrix): Matrix => {
  const d = Q[0].length;
  const scale = Math.sqrt(d);

  const scores = matMul(Q, transpose(K)).map((row) => row.map((v) => v / scale));

  const weights = scores.map((row) => {
    const maxVal = Math.max(...row);
    const exps = row.map((v) => Math.exp(v - maxVal));
    const sum = exps.reduce((s, e) => s + e, 0);
    return exps.map((e) => e / sum);
  });

  return matMul(weights, V);
};

const multiHeadAttention = (
  X: Matrix,
  numHeads: number,
  Wq: Matrix[],
  Wk: Matrix[],
  Wv: Matrix[],
  Wo: Matrix,
): Matrix => {
  const heads = Array.from({ length: numHeads }, (_, h) => {
    const Q = matMul(X, Wq[h]);
    const K = matMul(X, Wk[h]);
    const V = matMul(X, Wv[h]);
    return selfAttention(Q, K, V);
  });

  const concatenated = heads[0].map((row, i) => heads.flatMap((head) => head[i]));
  return matMul(concatenated, Wo);
};

const transpose = (A: Matrix): Matrix => A[0].map((_, j) => A.map((row) => row[j]));

const matMul = (A: Matrix, B: Matrix): Matrix => {
  const m = A.length,
    p = B[0].length,
    n = A[0].length;
  return Array.from({ length: m }, (_, i) =>
    Array.from({ length: p }, (_, j) => {
      let s = 0;
      for (let k = 0; k < n; k++) s += A[i][k] * B[k][j];
      return s;
    }),
  );
};
注意力矩阵 softmax(QKᵀ/√d) 是一个 n×n 的"软选择"矩阵，每行的值之和为 1，表示当前位置对所有位置的关注权重。从线性代数角度看，自注意力对 V 的每一行做了加权平均——权重由 Q 和 K 的相似度决定。


张量运算基础
张量是矩阵向高维的推广：标量（0阶）、向量（1阶）、矩阵（2阶）、三阶张量等。深度学习中的数据批次、卷积核、注意力权重都是高阶张量。


type Tensor3D = number[][][];

const tensorMatMul = (T: Tensor3D, M: Matrix): Tensor3D => T.map((slice) => matMul(slice, M));

const batchMatMul = (A: Tensor3D, B: Tensor3D): Tensor3D => A.map((a, i) => matMul(a, B[i]));

const tensorContract = (T: Tensor3D, v: Vector, axis: number): Matrix => {
  const [d1, d2, d3] = [T.length, T[0].length, T[0][0].length];
  if (axis === 2) {
    return T.map((slice) => slice.map((row) => row.reduce((s, val, k) => s + val * v[k], 0)));
  }
  return T[0].map((_, i) => T[0][0].map((_, j) => T.reduce((s, slice, k) => s + slice[i][j] * v[k], 0)));
};
CP 分解将三阶张量表示为秩1张量之和：T ≈ Σ aᵢ ⊗ bᵢ ⊗ cᵢ，类似于矩阵的 SVD。Tucker 分解是更一般的形式，允许在每个模式上使用不同大小的因子矩阵。


小结
    

  • 核方法通过核函数隐式在高维空间计算内积，核矩阵是对称半正定矩阵
    • 

  • 谱聚类利用图拉普拉斯的特征向量在嵌入空间中聚类，能发现非凸结构
    • 

  • 自注意力 softmax(QKᵀ/√d)V 本质上是基于相似度的加权平均
    • 

  • 张量是矩阵的高维推广，深度学习中无处不在
    • 

  • 这些进阶应用的性能优化核心都是高效矩阵/张量运算（如 FlashAttention）
    • 

  • 理解线性代数基础是掌握这些进阶技术的前提
    •
