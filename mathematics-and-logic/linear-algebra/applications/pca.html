主成分分析

核心概念

主成分分析（PCA）是最经典的线性降维方法，它通过将高维数据投影到方差最大的正交方向上实现维度压缩。PCA 的数学基础完全建立在线性代数之上：协方差矩阵的特征值分解或数据矩阵的奇异值分解。

PCA 的核心思想是：高维数据的大部分信息（方差）往往集中在少数几个方向上。找到这些方向（主成分），将数据投影上去，就能在大幅降低维度的同时保留最多信息。这在数据可视化、特征提取、去噪和预处理中极为有用。

PCA 的完整实现
PCA 的标准流程包括中心化、协方差矩阵计算、特征分解、维度选择和投影。对于大规模数据，可以用 SVD 替代特征分解，避免显式构造协方差矩阵。


type Matrix = number[][];
type Vector = number[];

const pcaFull = (
  X: Matrix,
  k: number,
): {
  transformed: Matrix;
  components: Matrix;
  explainedVarianceRatio: number[];
  mean: Vector;
} => {
  const m = X.length;
  const n = X[0].length;

  const mean = Array.from({ length: n }, (_, j) => X.reduce((s, row) => s + row[j], 0) / m);

  const centered = X.map((row) => row.map((val, j) => val - mean[j]));

  const cov = computeCovariance(centered);

  const { eigenvalues, eigenvectors } = symmetricEigen(cov);
  const sorted = eigenvalues.map((v, i) => ({ v, i })).sort((a, b) => b.v - a.v);

  const totalVar = sorted.reduce((s, x) => s + x.v, 0);
  const explainedVarianceRatio = sorted.slice(0, k).map((x) => x.v / totalVar);

  const W = sorted.slice(0, k).map(({ i }) => eigenvectors.map((row) => row[i]));

  const WMatrix = W[0].map((_, i) => W.map((w) => w[i]));
  const transformed = matMul(centered, WMatrix);

  return {
    transformed,
    components: WMatrix,
    explainedVarianceRatio,
    mean,
  };
};

const computeCovariance = (X: Matrix): Matrix => {
  const m = X.length,
    n = X[0].length;
  const XT = transpose(X);
  const cov = matMul(XT, X);
  return cov.map((row) => row.map((v) => v / (m - 1)));
};
通过 SVD 实现的 PCA 更高效（特别是 m >> n 时不需要形成 n×n 协方差矩阵），也更数值稳定：


const pcaViaSVD = (
  X: Matrix,
  k: number,
): {
  transformed: Matrix;
  components: Matrix;
  singularValues: number[];
} => {
  const m = X.length,
    n = X[0].length;
  const mean = Array.from({ length: n }, (_, j) => X.reduce((s, row) => s + row[j], 0) / m);
  const centered = X.map((row) => row.map((val, j) => val - mean[j]));

  const { U, S, V } = svdFull(centered);

  const components = V.map((row) => row.slice(0, k));
  const transformed = U.map((row, i) => Array.from({ length: k }, (_, j) => row[j] * S[j]));

  return { transformed, components, singularValues: S };
};
维度选择策略
选择保留多少个主成分是 PCA 的关键决策。常用策略包括：累计方差解释比（如保留 95%）、碎石图（scree plot）的"肘部"、Kaiser 准则（保留特征值>1的成分）。


const selectDimensions = (eigenvalues: number[], threshold: number = 0.95): number => {
  const total = eigenvalues.reduce((s, v) => s + v, 0);
  let cumulative = 0;
  for (let k = 0; k < eigenvalues.length; k++) {
    cumulative += eigenvalues[k];
    if (cumulative / total >= threshold) return k + 1;
  }
  return eigenvalues.length;
};

const kaiserRule = (eigenvalues: number[]): number => eigenvalues.filter((v) => v > 1).length;

const screePlot = (
  eigenvalues: number[],
): {
  component: number;
  variance: number;
  cumulative: number;
}[] => {
  const total = eigenvalues.reduce((s, v) => s + v, 0);
  let cum = 0;
  return eigenvalues.map((v, i) => {
    cum += v;
    return {
      component: i + 1,
      variance: v / total,
      cumulative: cum / total,
    };
  });
};
在实践中，95% 累计方差是最常用的阈值。但在某些场景（如可视化）固定 k=2 或 k=3；在预处理场景，可能保留 99% 以确保信息不丢失。


数据重构与降噪
PCA 的逆过程可以重构数据：X̂ = ZWᵀ + μ。当 k < n 时，重构是有损的——丢失了小特征值方向的信息。但这种"有损"恰好可以用于降噪：噪声通常在小方差方向上，丢弃它们等于去除噪声。


const reconstruct = (transformed: Matrix, components: Matrix, mean: Vector): Matrix =>
  transformed.map((row) => {
    const n = mean.length;
    const result = [...mean];
    for (let j = 0; j < row.length; j++) {
      for (let i = 0; i < n; i++) {
        result[i] += row[j] * components[i][j];
      }
    }
    return result;
  });

const reconstructionError = (original: Matrix, reconstructed: Matrix): number => {
  let error = 0;
  for (let i = 0; i < original.length; i++) {
    for (let j = 0; j < original[0].length; j++) {
      error += (original[i][j] - reconstructed[i][j]) ** 2;
    }
  }
  return Math.sqrt(error / (original.length * original[0].length));
};

const denoise = (X: Matrix, k: number): Matrix => {
  const { transformed, components, mean } = pcaFull(X, k);
  return reconstruct(transformed, components, mean);
};
在图像降噪中，对带噪图像做 PCA 并只保留前 k 个主成分，可以有效去除高斯白噪声。在基因表达数据分析中，PCA 降噪是标准的预处理步骤。


小结
    

  • PCA 将数据投影到协方差矩阵最大特征值方向，实现最优线性降维
    • 

  • SVD 实现比特征分解更高效、更稳定，避免显式构造协方差矩阵
    • 

  • 维度选择常用 95% 累计方差阈值，Kaiser 准则或碎石图辅助决策
    • 

  • PCA 重构可用于降噪——丢弃小方差方向等价于去除噪声
    • 

  • PCA 是线性方法，对非线性结构的数据效果有限，需考虑 kernel PCA
    • 

  • 数据需先中心化，标准化则取决于各特征量纲是否一致
