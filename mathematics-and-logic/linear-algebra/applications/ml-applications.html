线性代数在机器学习中的应用

核心概念

线性代数是机器学习的数学语言。从数据表示（矩阵）、模型参数（向量/矩阵）、损失函数（二次型）、优化算法（梯度=矩阵向量乘法）到模型解释（特征分解），每一步都依赖线性代数的概念和运算。

理解线性代数在机器学习中的应用，不仅帮助我们正确实现算法，更重要的是理解算法"为什么这样工作"。神经网络为什么需要非线性激活？正则化为什么能防止过拟合？梯度下降为什么有时收敛很慢？这些问题的答案都根植于线性代数。

神经网络的矩阵视角
神经网络的前向传播本质上是一系列矩阵乘法加非线性激活的链。单层的计算 h = σ(Wx + b) 中，W 是权重矩阵（线性变换），b 是偏置向量（平移），σ 是激活函数（非线性）。


type Matrix = number[][];
type Vector = number[];

const relu = (x: number): number => Math.max(0, x);
const sigmoid = (x: number): number => 1 / (1 + Math.exp(-x));

const denseLayer = (W: Matrix, b: Vector, x: Vector, activation: (x: number) => number): Vector => {
  const z = W.map((row, i) => row.reduce((s, w, j) => s + w * x[j], 0) + b[i]);
  return z.map(activation);
};

const forwardPass = (
  weights: Matrix[],
  biases: Vector[],
  input: Vector,
  activations: ((x: number) => number)[],
): { outputs: Vector[]; preActivations: Vector[] } => {
  const outputs: Vector[] = [input];
  const preActivations: Vector[] = [];
  let current = input;

  for (let i = 0; i < weights.length; i++) {
    const z = weights[i].map((row, r) => row.reduce((s, w, j) => s + w * current[j], 0) + biases[i][r]);
    preActivations.push(z);
    current = z.map(activations[i]);
    outputs.push(current);
  }
  return { outputs, preActivations };
};
没有激活函数的神经网络等价于一个线性变换：W₃(W₂(W₁x)) = (W₃W₂W₁)x，多层退化为单层。激活函数引入非线性，使网络能逼近任意连续函数（万能逼近定理）。但线性代数仍然是分析网络行为的核心工具——权重矩阵的秩、条件数、奇异值衰减都影响网络的表达能力和训练难度。


梯度计算的矩阵形式
反向传播算法的核心是链式法则的矩阵形式。对于损失函数 L 关于权重矩阵 W 的梯度，可以用矩阵微分简洁表达：∂L/∂W = δ·hᵀ，其中 δ 是当前层的误差信号，h 是上一层的输出。


const backpropLayer = (
  delta: Vector,
  prevOutput: Vector,
  W: Matrix,
  preActivation: Vector,
  activationDerivative: (z: number) => number,
): { gradW: Matrix; gradB: Vector; deltaPrev: Vector } => {
  const gradW = delta.map((d) => prevOutput.map((h) => d * h));
  const gradB = [...delta];

  const WT = W[0].map((_, j) => W.map((row) => row[j]));
  const deltaPrev = WT.map((row) => row.reduce((s, w, i) => s + w * delta[i], 0));

  return {
    gradW,
    gradB,
    deltaPrev: deltaPrev.map((d, i) => d * activationDerivative(preActivation[i])),
  };
};

const sgdUpdate = (W: Matrix, gradW: Matrix, learningRate: number): Matrix =>
  W.map((row, i) => row.map((w, j) => w - learningRate * gradW[i][j]));
梯度消失和梯度爆炸问题可以从矩阵角度理解：反向传播中梯度要乘以多层的权重矩阵转置 Wᵀ，如果 W 的奇异值都小于 1，连乘后梯度指数衰减；如果奇异值都大于 1，梯度指数增长。BatchNorm、残差连接和精心的初始化都是为了控制这个问题。


矩阵分解在推荐系统中的应用
推荐系统的核心问题是填补用户-物品评分矩阵 R 中的缺失值。矩阵分解方法将 R 近似为两个低秩矩阵的乘积 R ≈ UVᵀ，其中 U 是用户特征矩阵，V 是物品特征矩阵。


const matrixFactorization = (
  R: (number | null)[][],
  k: number,
  learningRate: number = 0.01,
  regularization: number = 0.02,
  iterations: number = 100,
): { U: Matrix; V: Matrix } => {
  const m = R.length;
  const n = R[0].length;

  let U: Matrix = Array.from({ length: m }, () => Array.from({ length: k }, () => Math.random() * 0.1));
  let V: Matrix = Array.from({ length: n }, () => Array.from({ length: k }, () => Math.random() * 0.1));

  for (let iter = 0; iter < iterations; iter++) {
    for (let i = 0; i < m; i++) {
      for (let j = 0; j < n; j++) {
        if (R[i][j] === null) continue;
        const pred = U[i].reduce((s, u, f) => s + u * V[j][f], 0);
        const err = R[i][j]! - pred;

        for (let f = 0; f < k; f++) {
          const uOld = U[i][f];
          U[i][f] += learningRate * (err * V[j][f] - regularization * U[i][f]);
          V[j][f] += learningRate * (err * uOld - regularization * V[j][f]);
        }
      }
    }
  }
  return { U, V };
};

const predict = (U: Matrix, V: Matrix, i: number, j: number): number => U[i].reduce((s, u, f) => s + u * V[j][f], 0);
低秩假设的直觉：用户的偏好和物品的属性都可以用少数几个隐因子（latent factors）描述——如电影的类型、节奏、深度等。k 通常取 20-200，远小于用户数和物品数。


正则化的线代视角
正则化从线性代数角度有清晰的几何解释。L2 正则化 min ‖Xw-y‖² + λ‖w‖² 的解为 w = (XᵀX + λI)⁻¹Xᵀy。加上 λI 使得 XᵀX + λI 的特征值都大于 λ，改善条件数，防止过拟合。


const ridgeRegression = (X: Matrix, y: Vector, lambda: number): Vector => {
  const XT = transpose(X);
  const XTX = matMul(XT, X);
  const n = XTX.length;
  for (let i = 0; i < n; i++) XTX[i][i] += lambda;
  const XTy = XT.map((row) => row.reduce((s, x, i) => s + x * y[i], 0));
  return solveSystem(XTX, XTy);
};

const conditionImprovement = (
  X: Matrix,
  lambda: number,
): {
  original: number;
  regularized: number;
} => {
  const XT = transpose(X);
  const XTX = matMul(XT, X);
  const origCond = conditionNumber(eigenvalues(XTX));

  const n = XTX.length;
  for (let i = 0; i < n; i++) XTX[i][i] += lambda;
  const regCond = conditionNumber(eigenvalues(XTX));

  return { original: origCond, regularized: regCond };
};
从 SVD 角度理解：X 的奇异值分解 X = UΣVᵀ 下，岭回归解 w = V·diag(σᵢ/(σᵢ²+λ))·Uᵀy。小奇异值对应的方向被 λ 压制——λ 越大，小奇异值方向的贡献越小，解越平滑（偏差增大但方差减小）。


小结
    

  • 神经网络的前向传播是矩阵乘法+激活函数的链，权重矩阵的奇异值影响训练稳定性
    • 

  • 反向传播的梯度计算是矩阵微分的链式法则，∂L/∂W = δ·hᵀ
    • 

  • 推荐系统用矩阵分解将评分矩阵近似为低秩形式 R ≈ UVᵀ
    • 

  • L2 正则化等价于加 λI 改善条件数，从 SVD 角度压制小奇异值方向
    • 

  • 梯度消失/爆炸本质上是多个矩阵连乘导致的奇异值指数增长/衰减
    • 

  • 理解线性代数是深入理解机器学习算法原理的必经之路
    •
