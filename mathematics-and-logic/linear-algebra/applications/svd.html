奇异值分解

核心概念

奇异值分解（SVD）是线性代数中最强大、最通用的矩阵分解。任何 m×n 矩阵 A 都可以分解为 A = UΣVᵀ，其中 U 是 m×m 正交矩阵（左奇异向量），Σ 是 m×n 对角矩阵（奇异值），V 是 n×n 正交矩阵（右奇异向量）。SVD 不要求矩阵是方阵或可逆，这使它成为处理任意矩阵的"瑞士军刀"。

SVD 的应用范围极其广泛：图像压缩、推荐系统、文本分析（LSA）、数据降维、伪逆计算、数值秩判定、条件数估计、最小二乘的稳定求解。几乎所有涉及矩阵的实际计算，SVD 都能提供最稳定的方案。

SVD 的计算原理
SVD 的理论推导：AᵀA 是 n×n 对称半正定矩阵，其特征值 λᵢ ≥ 0，奇异值 σᵢ = √λᵢ。AᵀA 的特征向量构成 V，AAᵀ 的特征向量构成 U。关系：Avᵢ = σᵢuᵢ。


type Matrix = number[][];
type Vector = number[];

const transpose = (A: Matrix): Matrix => A[0].map((_, j) => A.map((row) => row[j]));

const matMul = (A: Matrix, B: Matrix): Matrix => {
  const m = A.length,
    p = B[0].length,
    n = A[0].length;
  return Array.from({ length: m }, (_, i) =>
    Array.from({ length: p }, (_, j) => {
      let s = 0;
      for (let k = 0; k < n; k++) s += A[i][k] * B[k][j];
      return s;
    }),
  );
};

const svdSimple = (
  A: Matrix,
): {
  U: Matrix;
  S: number[];
  V: Matrix;
} => {
  const AT = transpose(A);
  const ATA = matMul(AT, A);

  const { eigenvalues, eigenvectors } = symmetricEigen(ATA);

  const sorted = eigenvalues.map((val, idx) => ({ val: Math.max(val, 0), idx })).sort((a, b) => b.val - a.val);

  const S = sorted.map((s) => Math.sqrt(s.val));
  const V = sorted.map((s) => eigenvectors.map((row) => row[s.idx]));

  const rank = S.filter((s) => s > 1e-10).length;
  const U: Matrix = [];
  for (let i = 0; i < rank; i++) {
    const vi = V[i];
    const Avi = A.map((row) => row.reduce((s, a, j) => s + a * vi[j], 0));
    U.push(Avi.map((x) => x / S[i]));
  }

  return {
    U: U[0].map((_, i) => U.map((u) => u[i])),
    S,
    V: V[0].map((_, i) => V.map((v) => v[i])),
  };
};
实际的 SVD 算法不会直接形成 AᵀA（条件数平方化），而是使用 Golub-Kahan 双对角化：先将 A 化为双对角矩阵 B，然后用隐式 QR 迭代求 B 的 SVD。这是 LAPACK 中 DGESVD 的标准实现。


低秩近似与 Eckart-Young 定理
Eckart-Young 定理是 SVD 最深刻的应用：在所有秩为 k 的矩阵中，截断 SVD 给出的 Aₖ = Σ(i=1到k) σᵢuᵢvᵢᵀ 是对 A 的最佳近似（在 Frobenius 范数和算子范数意义下）。近似误差 = σₖ₊₁（算子范数）或 √(σₖ₊₁² + ... + σᵣ²)（Frobenius 范数）。


const lowRankApprox = (U: Matrix, S: number[], V: Matrix, k: number): Matrix => {
  const m = U.length,
    n = V.length;
  const result: Matrix = Array.from({ length: m }, () => new Array(n).fill(0));

  for (let i = 0; i < k; i++) {
    for (let r = 0; r < m; r++) {
      for (let c = 0; c < n; c++) {
        result[r][c] += S[i] * U[r][i] * V[c][i];
      }
    }
  }
  return result;
};

const approximationError = (S: number[], k: number, normType: 'frobenius' | 'operator'): number => {
  if (normType === 'operator') {
    return k < S.length ? S[k] : 0;
  }
  let sum = 0;
  for (let i = k; i < S.length; i++) sum += S[i] * S[i];
  return Math.sqrt(sum);
};

const compressionRatio = (m: number, n: number, k: number): number => {
  const original = m * n;
  const compressed = k * (m + n + 1);
  return original / compressed;
};
图像压缩是低秩近似的经典应用。一张 1000×1000 的灰度图像存储需要 10⁶ 个值。如果保留前 50 个奇异值，只需要 50 × (1000 + 1000 + 1) = 100050 个值，压缩比约 10:1，而视觉质量几乎无损。


Moore-Penrose 伪逆
Moore-Penrose 伪逆 A⁺ 通过 SVD 定义：A = UΣVᵀ 则 A⁺ = VΣ⁺Uᵀ，其中 Σ⁺ 将 Σ 的非零对角元素取倒数。伪逆统一了超定和欠定系统：超定给最小二乘解，欠定给最小范数解。


const pseudoInverse = (U: Matrix, S: number[], V: Matrix, tol: number = 1e-10): Matrix => {
  const m = U.length,
    n = V.length;
  const Sinv = S.map((s) => (s > tol ? 1 / s : 0));
  const result: Matrix = Array.from({ length: n }, () => new Array(m).fill(0));

  for (let i = 0; i < Sinv.length; i++) {
    if (Sinv[i] === 0) continue;
    for (let r = 0; r < n; r++) {
      for (let c = 0; c < m; c++) {
        result[r][c] += Sinv[i] * V[r][i] * U[c][i];
      }
    }
  }
  return result;
};

const solveSVD = (A: Matrix, b: Vector): Vector => {
  const { U, S, V } = svdSimple(A);
  const Apinv = pseudoInverse(U, S, V);
  return Apinv.map((row) => row.reduce((s, a, j) => s + a * b[j], 0));
};
伪逆满足四个 Moore-Penrose 条件：AA⁺A = A、A⁺AA⁺ = A⁺、(AA⁺)ᵀ = AA⁺、(A⁺A)ᵀ = A⁺A。它是唯一满足这四个条件的矩阵，对任何矩阵（方阵或非方阵、满秩或秩亏）都存在且唯一。


数值秩与条件数
数值秩是矩阵在给定精度下的"有效秩"——大于阈值 ε 的奇异值个数。条件数 κ(A) = σ₁/σᵣ 衡量矩阵的数值敏感度。条件数越大，矩阵越"病态"，计算结果越不可靠。


const numericalRank = (S: number[], tol?: number): number => {
  const threshold = tol ?? S[0] * Math.max(S.length, 1) * 2.2e-16;
  return S.filter((s) => s > threshold).length;
};

const conditionNumber = (S: number[]): number => {
  const maxS = S[0];
  const minS = S.filter((s) => s > 1e-15).pop() ?? 0;
  return minS > 0 ? maxS / minS : Infinity;
};

const analyzeMatrix = (
  A: Matrix,
): {
  rank: number;
  numericalRank: number;
  conditionNumber: number;
  singularValues: number[];
} => {
  const { S } = svdSimple(A);
  return {
    rank: S.filter((s) => s > 1e-10).length,
    numericalRank: numericalRank(S),
    conditionNumber: conditionNumber(S),
    singularValues: S,
  };
};
经验法则：条件数 < 10³ 认为良态，10³-10⁶ 需要注意，> 10⁶ 为病态。在浮点运算中，结果的有效位数大约会损失 log₁₀(κ) 位。


小结
    

  • SVD 将任意矩阵分解为 A = UΣVᵀ，是最通用的矩阵分解
    • 

  • Eckart-Young 定理保证截断 SVD 是最佳低秩近似
    • 

  • Moore-Penrose 伪逆通过 SVD 定义，统一处理所有线性系统
    • 

  • 条件数 σ₁/σᵣ 衡量数值稳定性，条件数大的矩阵计算不可靠
    • 

  • 数值秩考虑浮点精度，比精确秩更适合实际计算
    • 

  • SVD 在图像压缩、推荐系统、文本分析等场景中被广泛应用
