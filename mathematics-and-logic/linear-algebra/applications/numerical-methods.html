数值线性代数

核心概念

数值线性代数是连接线性代数理论和实际计算的桥梁。在理论上精确的算法，在浮点运算环境中可能产生灾难性的误差。数值线性代数研究如何在有限精度下高效、稳定地实现矩阵运算。

浮点数只能表示实数的有限子集，每次运算都会引入舍入误差。数值线性代数的核心问题是：如何设计算法使误差不被放大？答案涉及条件数分析、稳定算法设计、迭代方法和稀疏矩阵技术。

浮点误差与条件数
IEEE 754 双精度浮点数有约 16 位有效十进制数字，机器精度 ε ≈ 2.2×10⁻¹⁶。每次浮点运算的相对误差不超过 ε，但误差在连续运算中可能累积和放大。


条件数 κ(A) = ‖A‖·‖A⁻¹‖ 衡量矩阵对输入扰动的敏感度。对于线性方程组 Ax = b，当 b 有相对扰动 δb/‖b‖ 时，解的相对扰动最多为 κ(A)·δb/‖b‖。


type Matrix = number[][];
type Vector = number[];

const MACHINE_EPSILON = 2.220446049250313e-16;

const frobeniusNorm = (A: Matrix): number => {
  let sum = 0;
  for (const row of A) {
    for (const val of row) sum += val * val;
  }
  return Math.sqrt(sum);
};

const estimateCondition = (A: Matrix): number => {
  const { S } = computeSVD(A);
  const maxS = S[0];
  const minS = S[S.length - 1];
  return minS > MACHINE_EPSILON ? maxS / minS : Infinity;
};

const effectiveDigits = (condNumber: number): number => Math.max(0, 16 - Math.log10(condNumber));

const isWellConditioned = (
  A: Matrix,
): {
  condition: number;
  digits: number;
  assessment: string;
} => {
  const cond = estimateCondition(A);
  const digits = effectiveDigits(cond);
  let assessment: string;
  if (cond < 1e3) assessment = '良态';
  else if (cond < 1e6) assessment = '需注意';
  else if (cond < 1e12) assessment = '病态';
  else assessment = '严重病态';
  return { condition: cond, digits, assessment };
};
Hilbert 矩阵 H[i][j] = 1/(i+j-1) 是经典的病态矩阵，n=10 时条件数已达 10¹³，意味着结果几乎没有有效数字。在实际编程中，遇到大条件数时应考虑正则化或重新建模。


迭代法：共轭梯度
对于大规模稀疏对称正定系统 Ax = b，直接法（LU 分解）的 O(n³) 复杂度不可接受。共轭梯度法（CG）是最优的 Krylov 子空间方法，k 步迭代后的误差最多为 2(√κ-1)/(√κ+1))ᵏ·‖x₀-x*‖，收敛速度由条件数的平方根决定。


const conjugateGradient = (
  A: Matrix,
  b: Vector,
  maxIter: number = 1000,
  tol: number = 1e-10,
): { x: Vector; iterations: number; residualNorm: number } => {
  const n = b.length;
  const x = new Array(n).fill(0);
  let r = [...b];
  let p = [...r];
  let rsOld = r.reduce((s, v) => s + v * v, 0);

  for (let iter = 0; iter < maxIter; iter++) {
    const Ap = A.map((row) => row.reduce((s, a, j) => s + a * p[j], 0));
    const pAp = p.reduce((s, v, i) => s + v * Ap[i], 0);
    const alpha = rsOld / pAp;

    for (let i = 0; i < n; i++) {
      x[i] += alpha * p[i];
      r[i] -= alpha * Ap[i];
    }

    const rsNew = r.reduce((s, v) => s + v * v, 0);
    if (Math.sqrt(rsNew) < tol) {
      return { x, iterations: iter + 1, residualNorm: Math.sqrt(rsNew) };
    }

    const beta = rsNew / rsOld;
    for (let i = 0; i < n; i++) {
      p[i] = r[i] + beta * p[i];
    }
    rsOld = rsNew;
  }
  return { x, iterations: maxIter, residualNorm: Math.sqrt(rsOld) };
};
预处理（preconditioning）是加速 CG 收敛的关键技术。不求解 Ax = b，而是求解 M⁻¹Ax = M⁻¹b，其中 M ≈ A 但 M⁻¹ 容易计算（如不完全 Cholesky 分解）。好的预处理器可以将条件数从 10⁶ 降到 10¹，迭代次数从数千次降到数十次。


稀疏矩阵与压缩存储
实际应用中的大规模矩阵通常是稀疏的——大部分元素为零。n×n 稀疏矩阵如果只有 O(n) 个非零元素，用稠密格式存储需要 O(n²) 空间，是巨大的浪费。压缩存储格式（CSR、CSC、COO）只存储非零元素。


interface CSRMatrix {
  values: number[];
  colIndices: number[];
  rowPointers: number[];
  rows: number;
  cols: number;
}

const denseToCSR = (A: Matrix): CSRMatrix => {
  const values: number[] = [];
  const colIndices: number[] = [];
  const rowPointers: number[] = [0];

  for (const row of A) {
    for (let j = 0; j < row.length; j++) {
      if (Math.abs(row[j]) > 1e-15) {
        values.push(row[j]);
        colIndices.push(j);
      }
    }
    rowPointers.push(values.length);
  }

  return {
    values,
    colIndices,
    rowPointers,
    rows: A.length,
    cols: A[0].length,
  };
};

const csrMatVec = (A: CSRMatrix, x: Vector): Vector => {
  const result = new Array(A.rows).fill(0);
  for (let i = 0; i < A.rows; i++) {
    for (let j = A.rowPointers[i]; j < A.rowPointers[i + 1]; j++) {
      result[i] += A.values[j] * x[A.colIndices[j]];
    }
  }
  return result;
};

const sparsity = (A: CSRMatrix): number => {
  const total = A.rows * A.cols;
  const nonzero = A.values.length;
  return 1 - nonzero / total;
};
CSR（Compressed Sparse Row）格式用三个数组表示稀疏矩阵：values 存储非零元素值，colIndices 存储对应列索引，rowPointers 存储每行非零元素在 values 中的起始位置。稀疏矩阵-向量乘法（SpMV）是迭代法的核心操作。


随机化算法
对于超大规模矩阵（如网页邻接矩阵、社交网络图），传统算法的 O(mn²) 或 O(n³) 复杂度不可接受。随机化算法通过随机采样降低计算量，以高概率给出近似结果。


const randomizedSVD = (A: Matrix, k: number, oversampling: number = 10): { U: Matrix; S: number[]; V: Matrix } => {
  const m = A.length,
    n = A[0].length;
  const l = k + oversampling;

  const Omega: Matrix = Array.from({ length: n }, () => Array.from({ length: l }, () => gaussianRandom()));

  const Y = matMul(A, Omega);
  const { Q } = qrDecomposition(Y);
  const B = matMul(transpose(Q), A);
  const { U: Ub, S, V } = svdFull(B);
  const U = matMul(Q, Ub);

  return {
    U: U.map((row) => row.slice(0, k)),
    S: S.slice(0, k),
    V: V.map((row) => row.slice(0, k)),
  };
};

const gaussianRandom = (): number => {
  const u1 = Math.random();
  const u2 = Math.random();
  return Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
};
随机化 SVD 的复杂度为 O(mnk)，远低于完整 SVD 的 O(mn²)。当只需要前 k 个奇异值/向量时（如推荐系统中 k = 50-200），随机化方法是最优选择。


小结
    

  • 浮点运算有限精度导致舍入误差，条件数衡量误差放大程度
    • 

  • 大条件数意味着结果不可靠，应考虑正则化或算法改进
    • 

  • 共轭梯度是稀疏对称正定系统的最优迭代法，预处理可大幅加速
    • 

  • CSR 格式高效存储稀疏矩阵，稀疏矩阵-向量乘法是迭代法核心
    • 

  • 随机化 SVD 将复杂度从 O(mn²) 降到 O(mnk)，适合超大规模数据
    • 

  • 选择算法的关键考量：矩阵规模、稀疏度、对称性、精度需求
