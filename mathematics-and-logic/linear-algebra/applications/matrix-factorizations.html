矩阵分解方法

核心概念

矩阵分解是将一个矩阵表示为若干结构更简单的矩阵的乘积。不同的分解方法适用于不同类型的问题：LU 分解用于求解线性方程组，QR 分解用于最小二乘和特征值计算，SVD 是最通用的分解，特征分解揭示矩阵的内在结构。

矩阵分解的价值在于"化繁为简"：将复杂矩阵转化为容易处理的形式（三角、对角、正交），使得后续运算（求解、求逆、求幂）变得高效。现代数值线性代数几乎所有算法都建立在某种矩阵分解之上。

QR 分解算法
QR 分解将 m×n 矩阵 A（m ≥ n）分解为正交矩阵 Q 和上三角矩阵 R 的乘积。主要有三种算法：Gram-Schmidt 正交化、Householder 反射和 Givens 旋转。


type Matrix = number[][];
type Vector = number[];

const householderQR = (A: Matrix): { Q: Matrix; R: Matrix } => {
  const m = A.length;
  const n = A[0].length;
  let R = A.map((row) => [...row]);
  let Q = identity(m);

  for (let j = 0; j < Math.min(m - 1, n); j++) {
    const x: Vector = [];
    for (let i = j; i < m; i++) x.push(R[i][j]);

    const normX = Math.sqrt(x.reduce((s, v) => s + v * v, 0));
    const sign = x[0] >= 0 ? 1 : -1;
    x[0] += sign * normX;
    const normV = Math.sqrt(x.reduce((s, v) => s + v * v, 0));
    if (normV < 1e-12) continue;
    const v = x.map((xi) => xi / normV);

    for (let k = j; k < n; k++) {
      let dot = 0;
      for (let i = 0; i < v.length; i++) dot += v[i] * R[i + j][k];
      for (let i = 0; i < v.length; i++) R[i + j][k] -= 2 * dot * v[i];
    }

    for (let k = 0; k < m; k++) {
      let dot = 0;
      for (let i = 0; i < v.length; i++) dot += v[i] * Q[k][i + j];
      for (let i = 0; i < v.length; i++) Q[k][i + j] -= 2 * dot * v[i];
    }
  }
  return { Q, R };
};

const identity = (n: number): Matrix =>
  Array.from({ length: n }, (_, i) => Array.from({ length: n }, (_, j) => (i === j ? 1 : 0)));
Householder 反射的几何意义：每步选择一个超平面，将列向量反射到坐标轴方向，逐步将矩阵变为上三角形。相比 Gram-Schmidt，Householder 方法数值更稳定，是 LAPACK 中 QR 分解的标准实现。


Givens 旋转每次只处理两个元素，适合稀疏矩阵和并行计算。它将矩阵中的一个指定元素旋转为零，通过逐个消去下三角元素得到 QR 分解。


Schur 分解
Schur 分解定理保证：任何方阵 A 都可以分解为 A = QTQ*（实矩阵版本：A = QTQᵀ），其中 Q 是酉矩阵（正交矩阵），T 是上三角矩阵，T 的对角线元素是 A 的特征值。


const qrAlgorithm = (A: Matrix, maxIter: number = 100): { eigenvalues: number[]; schurForm: Matrix } => {
  const n = A.length;
  let T = A.map((row) => [...row]);

  for (let iter = 0; iter < maxIter; iter++) {
    const shift = T[n - 1][n - 1];
    for (let i = 0; i < n; i++) T[i][i] -= shift;

    const { Q, R } = householderQR(T);
    T = matMul(R, Q);
    for (let i = 0; i < n; i++) T[i][i] += shift;

    let offDiag = 0;
    for (let i = 1; i < n; i++) {
      offDiag += T[i][i - 1] * T[i][i - 1];
    }
    if (Math.sqrt(offDiag) < 1e-12) break;
  }

  const eigenvalues = Array.from({ length: n }, (_, i) => T[i][i]);
  return { eigenvalues, schurForm: T };
};

const matMul = (A: Matrix, B: Matrix): Matrix => {
  const m = A.length,
    p = B[0].length,
    n = A[0].length;
  return Array.from({ length: m }, (_, i) =>
    Array.from({ length: p }, (_, j) => {
      let s = 0;
      for (let k = 0; k < n; k++) s += A[i][k] * B[k][j];
      return s;
    }),
  );
};
Schur 分解的优势：(1) 对所有方阵都存在，不要求可对角化；(2) 数值稳定，不像若尔当形那样对扰动敏感；(3) T 的对角线直接给出特征值。QR 算法加 Wilkinson 移位是计算 Schur 形的标准方法，也是所有特征值算法的基础。


分解的选择策略
面对不同问题应选择最合适的分解方法。选择依据包括矩阵类型（方阵/非方阵、对称/非对称、稠密/稀疏）、问题需求（求解/特征值/分析）和精度要求。


const selectDecomposition = (
  problem: 'solve' | 'eigenvalue' | 'leastSquares' | 'lowRank',
  matrixType: 'general' | 'symmetric' | 'spd' | 'sparse',
): string => {
  if (problem === 'solve') {
    if (matrixType === 'spd') return 'Cholesky';
    if (matrixType === 'sparse') return 'Iterative (CG/GMRES)';
    return 'PLU';
  }
  if (problem === 'eigenvalue') {
    if (matrixType === 'symmetric') return 'Symmetric QR → Eigendecomposition';
    return 'QR Algorithm → Schur';
  }
  if (problem === 'leastSquares') {
    return matrixType === 'sparse' ? 'LSQR' : 'QR Decomposition';
  }
  if (problem === 'lowRank') {
    return 'SVD (or Randomized SVD for large scale)';
  }
  return 'SVD (most general)';
};

const benchmarkDecompositions = (A: Matrix): Record<string, number> => {
  const results: Record<string, number> = {};
  const n = A.length;

  let start = performance.now();
  householderQR(A);
  results['QR'] = performance.now() - start;

  start = performance.now();
  luDecomposition(A);
  results['LU'] = performance.now() - start;

  return results;
};
经验法则：能用 Cholesky 就不用 LU，能用 QR 就不用 SVD——越特殊的分解利用了越多的结构信息，效率越高。但当不确定矩阵性质时，SVD 是最安全的选择。


小结
    

  • QR 分解通过 Householder 反射实现，是最小二乘和特征值计算的基础
    • 

  • Schur 分解对任意方阵存在，数值稳定性优于若尔当形
    • 

  • QR 算法通过反复 QR 分解迭代收敛到 Schur 形，是特征值计算的标准
    • 

  • 选择分解方法依据：矩阵类型（对称/正定/稀疏）和问题需求
    • 

  • Cholesky 最快但要求正定，LU 通用但不够稳定，QR 平衡，SVD 最安全
    • 

  • 现代数值线性代数的几乎所有算法都建立在某种矩阵分解之上
