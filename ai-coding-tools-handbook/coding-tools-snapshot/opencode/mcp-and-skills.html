MCP servers · Skills 三路径互通 · 自定义 slash

核心概念

跑通 provider 与 rules 之后（前置见 1_providers-and-rules.md），OpenCode 配置面剩下的三块都是"给 agent 加能力"——MCP servers 暴露外部协议化工具、Skills 注入可复用的领域知识 + 工具组合、自定义 slash commands 把团队工作流固化成一行命令。三块共同点是都走"声明式文件 + 自动发现"，开发者只需写 JSON / SKILL.md / Markdown，不必接 SDK。

MCP servers：stdio / Streamable HTTP + OAuth + DCR
Model Context Protocol 是 2026 年所有主流工具的共识扩展层。OpenCode 在 opencode.json 的 "mcp" 块里声明 server，支持两种传输：


    

  • stdio：spawn 一个本地子进程，stdin/stdout JSON-RPC 通信。适合本地工具（filesystem、git、shell）。
    • 

  • Streamable HTTP：远程 HTTP + SSE 双向流。适合 SaaS（GitHub MCP、Linear、Slack）与企业内网服务。
    • 



外加 OAuth + RFC 7591 Dynamic Client Registration：读者接公司内部 MCP server 时不需要预先申请 client credential，OpenCode 自动注册并存 client_id / secret。这是同类工具里 DCR 支持最完整的一家。


{
  "mcp": {
    "filesystem": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/me/code"],
    },
    "company-jira": {
      "type": "http",
      "url": "https://mcp.company.internal/jira",
      "auth": "oauth",
    },
    "github": {
      "type": "stdio",
      "command": "docker",
      "args": ["run", "-i", "--rm", "ghcr.io/github/github-mcp-server"],
      "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "${env:GH_TOKEN}" },
    },
  },
}

Skills：三路径互通 + 跨工具共识
OpenCode 把 agentskills.io 开放标准的 SKILL.md 设计推到了"跨工具最友好"的程度：除了自家 .opencode/skills/ 与全局 ~/.config/opencode/skills/，还默认读取 .claude/skills/ 与 .agents/skills/，意味着 Claude Code 用户的 skill 资产、跨工具共识路径 .agents/skills/ 都能直接被 OpenCode 加载。


my-app/
├── opencode.json
├── AGENTS.md
├── .opencode/
│   ├── commands/
│   │   └── tests.md             ← /tests 自定义 slash
│   └── skills/

└── .agents/
    └── skills/                   ← Codex / OpenClaw 也读，跨工具共识
        └── refactor-helper/

一份 SKILL.md 最小模板
---
name: rust-review
description: Rust code review with clippy + rustfmt + idiom 检查
triggers:
  - "review.*\\.rs"
  - 'lint rust'
allowed-tools: [Read, Bash]
---
## 使用方式
读者在对话中提到"review rust"或"lint rust"时，触发本 skill。
1. 跑 `cargo clippy --workspace`
2. 跑 `cargo fmt --check`
3. 找出 unsafe / unwrap / panic! 的高风险用法
4. 输出 markdown 报告，含 file:line 引用
注意：路径互通 ≠ frontmatter 字段全兼容。Claude Code 独有的 context: fork / disable-model-invocation 在 OpenCode 里会被忽略；想跨工具复用就用最小 frontmatter（name / description / triggers / allowed-tools）。


自定义 slash commands
OpenCode 内置 /init / /undo / /redo / /share / /help / /model / /mcp，自定义 slash 放 .opencode/commands/<name>.md，frontmatter 支持三类占位 / 嵌入：


    

  • $ARGUMENTS —— 调用时附带的参数
    • 

  • !`shell-cmd` —— 把 shell 命令的 stdout 嵌入提示
    • 

  • @file / @dir —— 把文件 / 目录内容嵌入提示
    • 



下面是一个"跑测试 + 把失败 diff 喂给 agent"的示例。


---
description: 跑测试并把失败 diff 喂给 agent
arguments: '[scope]'
---

请帮我跑一下 `bun test $ARGUMENTS`，下面是当前的失败输出与 git diff：

!`bun test $ARGUMENTS 2>&1 | tail -50`

当前 diff:
!`git diff --stat`

@package.json
进入 TUI 后输入 /tests packages/core 就会替换占位、嵌入 shell 输出、贴上 package.json 内容，agent 拿到完整上下文。

Skill 与 slash 的区别：slash 必须用户显式输入 /name、skill 可由 trigger 自动激活。同一工作流既可写成 slash 也可写成 skill，看是否希望 agent 自主调用。

MCP server OAuth 反复弹窗
mcp-auth.json 写入失败
ls -la ~/.local/share/opencode/ 确认目录可写




/mcp connect 报 unknown_client

.claude/skills/ 加载失败
SKILL.md frontmatter 用了 OpenCode 不识别的字段

Slash command $ARGUMENTS 没替换
frontmatter 没声明 arguments 字段

!`cmd` 嵌入了空字符串
shell 命令在 cwd 下执行失败、stderr 没被捕获
命令后加 2>&1，或换绝对路径




@file 内容超大撑爆 context
整目录 @docs/ 一次性嵌入
改成 @docs/specific-file.md 或精确文件路径




GitHub MCP server 跑不起来
Docker 缺 GH_TOKEN 环境
用 ${env:GH_TOKEN} 时确认 shell 已 export





小结
    

  • MCP servers 在 opencode.json mcp 块声明；stdio + Streamable HTTP + OAuth + RFC 7591 DCR；token 落 mcp-auth.json，CLI 走 opencode mcp auth/list/logout。
    • 

  • Skills 三路径互通：.opencode/skills/ + ~/.config/opencode/skills/ + .claude/skills/ + .agents/skills/；路径兼容 ≠ frontmatter 全兼容，跨工具用最小 frontmatter。
    • 

  • 自定义 slash 放 .opencode/commands/<name>.md，$ARGUMENTS + !`cmd` + @file 三件套覆盖大多数定制需求。
    • 

  • Slash vs Skill：前者需用户显式输入，后者可 trigger 自动激活——同一工作流二选一即可。
    • 

  • 三块配置加上 1_providers-and-rules.md 的 provider + rules，本 hub 配置面收敛完毕；深入到 MCP / Skills / Hooks 跨工具横向比较请转 01_coding-tools/。
    •
