Tier 1 · Coding Tools 工具栈三款 Coding Tools 速览 简介OpenCode 速览 简介首次会话：TUI 导航 · /init · /share

首次会话：TUI 导航 · /init · /share

核心概念

凭据就绪之后（前置见 1_install-and-login.md），从空白 TUI 到把一次完整对话分享给同事，主路径是三步：进 TUI 熟悉键位 → /init 生成 AGENTS.md → /share 推 session。整个流程对网络通畅的机器一般 3-5 分钟跑完。本文按这条路径展开，最后单列一节"首次跑不通的三类常见原因"——99% 卡住的新人都落在这三类里。

plan 与 build 的语义：build agent 默认拥有 edit / bash / task 等改写权限，可直接修改文件；plan agent 只读，让 AI 推演方案、列 patch 建议但不实际下手——读者复杂改动时建议先 plan 后 build，类似"先 dry-run 再 apply"。


用 /init 生成首份 AGENTS.md
/init 是 OpenCode 把"我项目长什么样"自动化的入口。它让 agent 自己扫描仓库根目录的几类文件——README.md、package.json / Cargo.toml / pyproject.toml 等构建描述、CI 配置、docs/ 子目录——然后输出一份 AGENTS.md 草稿放在项目根。这份草稿会被后续每条提示自动加载，相当于"持久化的项目自我介绍"。


# 在项目根目录启动 opencode 后，进入 TUI:
/init
# Agent 会读取仓库结构、构建配置、README，输出建议的 AGENTS.md 内容
# 你可以编辑确认后保存，也可以拒绝重生成
建议工作流：


    

  1. 第一次跑 /init，不要直接 accept —— 让 agent 输出草稿后人工 review。
    2. 

  2. 删掉 agent 抄 README 的复述段，留下"业务目标 / 团队约定 / 不希望 agent 触碰的目录"三段。
    3. 

  3. 项目结构变化（新增子模块、迁移构建系统）后再跑一次 /init，对照 diff 增补。
    4. 

  4. 已有 Claude Code 的 CLAUDE.md 时，OpenCode 自动 fallback 读取，不必专门生 AGENTS.md；两份同存时 AGENTS.md 优先。
    5. 



用 /share 导出 session
/share 把当前会话推到 OpenCode share gateway，返回一个 URL，对外只暴露提示 + 工具调用记录 + agent 输出，不上传源代码（除非提示里贴了大段代码）。典型场景：code review 时附 AI 推理过程、bug 复盘让同事看完整步骤、招聘面试或团队培训演示工作流。


# 在 TUI 中:
/share
# 返回类似: https://share.opencode.ai/abc123def

首次跑不通的三类常见原因
经验显示新人第一次跑 OpenCode，卡住的几乎都落在以下三类。


类 1 · 终端不支持 Kitty keyboard protocol。一些老 SSH 客户端、Windows Terminal 旧版、tmux 嵌套层会出现 Shift+Enter 失效、Ctrl+P 被外层 shell 截获等问题。升级终端（kitty / wezterm / iTerm2 / Ghostty）或显式声明 TERM=xterm-256color opencode 启动可绕开大部分情况；逃生方案是用 Alt+Enter 替代 Shift+Enter、Esc 后接命令名替代 Ctrl+P。


类 2 · OAuth 回调端口被防火墙拦。公司网络常拦截 localhost 短端口反向回调。症状是浏览器弹出授权页、点完同意之后浏览器进度条永远转圈，CLI 端则停在 "Waiting for callback..."。解决方法是退回 API key 模式：opencode auth login <provider> 再选 "API key"，从 provider 控制台直接复制。


类 3 · Bun 版本过旧 / 不存在。TUI 启动闪退、stderr 报 bun: undefined behaviour 或 Bun is required。这是 OpenCode 2026 切到 Bun runtime 后的硬依赖。处理：bun --version 验证（缺则装），或者升级到 ≥1.x。


其它常见小坑
    

  • /init 生成的 AGENTS.md 太长且空话多：agent 把整个 README 抄了一遍。删掉复述段、留"业务 / 约定 / 禁区"三段即可。
    • 

  • Build agent 改写文件被 ask 卡住：默认权限三态（allow / ask / deny）会拦改写。临时方案：切到 plan agent 推演 + 手动 apply；长期方案：在 opencode.json 把可信目录改为 allow。
    • 

  • /share 返回 403：share gateway 域名被防火墙拦。在 opencode.json 关 share 或自部署 gateway。
    • 

  • TUI 起来后看不到响应、但 CPU 正在跑：default model 选错（如指向本地 Ollama 但 Ollama 未启）。/model 切到云端 model 测一下。
    • 



小结
    

  • TUI 键位四件套记牢：Tab（切 agent）/ Ctrl+P（命令面板）/ /（slash）/ @（嵌文件），其它键位用 /help 现查。
    • 

  • /init 是"项目自我介绍"自动化入口，人工 review 后保存，留"业务 / 约定 / 禁区"三段而非 README 复述。
    • 

  • /share 只导出对话 + 工具记录，不上传源代码；不希望出公网就在 opencode.json 关或自部署 gateway。
    • 

  • 首次跑不通三大类：终端键位（升级终端 / Alt+Enter 逃生）、OAuth 端口（退回 API key）、Bun 版本（升级到 1.x）。
    • 

  • 跑完一次 /share 拿到 URL，本章入门基本毕业；下一步走 ./5_providers-and-rules.md 把配置写到 opencode.json 里。
    •
