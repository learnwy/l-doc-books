MCP 接外部工具 · Hooks 29 事件 × 5 handler

核心概念

CLAUDE.md 与 Skills 解决"agent 该做什么 / 怎么做"，本节解决"agent 怎么接外部工具 / 怎么自动化"。MCP 把外部服务（GitHub / Playwright / 内部 search 等）以标准协议暴露成 agent 可调用的工具；Hooks 把"在 X 事件发生时跑 Y 动作"固化成配置——29 个事件 × 5 种 handler 是 5 家工具里最细的事件粒度。

两层各管一摊：.mcp.json + ~/.claude.json 管外部工具接入；.claude/settings.json + 各 skill/subagent frontmatter hooks: 管事件自动化。把"transport / 鉴权 / 帧上限"与"事件分组 / handler 类型"两侧分别看清，配置上几乎不会再卡壳。

MCP servers · 三 transport 与配置两份叠加
MCP 是接外部工具的标准协议；Claude Code 在 client 侧是一等支持，transport 三选一：http / sse（deprecated 但仍可用）/ stdio。


// .mcp.json（项目根，commit 进版本控制让团队共用）
{
  "mcpServers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/",
      "headers": {
        "Authorization": "Bearer ${GITHUB_MCP_TOKEN}"
      }
    },
    "playwright": {
      "type": "stdio",
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    },
    "internal-search": {
      "type": "http",
      "url": "https://mcp.internal/search",
      "oauth": {
        "authorizationUrl": "https://sso.internal/oauth/authorize",
        "tokenUrl": "https://sso.internal/oauth/token"
      }
    }
  }
}
两份配置叠加：.mcp.json 项目共享、~/.claude.json 用户全局；.claude/settings.json 里 enableAllProjectMcpServers: true 一键启用项目所有 MCP server，避免每个 server 都被 /permissions 单独问一次。

HTTP/SSE 帧上限 16MB：2026-04 修复——之前 server 推大量截图 / 长 markdown 会被截断；现超出会自动拆帧重发。list_changed 让 server 端动态更新工具集（agent 不必重启）；连接断开走指数退避重连；push channels 支持 server 主动通知。


OAuth 与 plugin bundled
OAuth 流程通过 /mcp slash command 触发：选 server → 跳浏览器 → 回调 → token 落 ~/.claude/auth/mcp/<server>.json。同一 MCP server 在 OpenCode / Codex CLI / Hermes / OpenClaw 上都能配，跨工具协同时 server 端只写一份即可。


Plugin bundled MCP 用 ${CLAUDE_PLUGIN_ROOT} placeholder 引相对路径：


// <plugin>/.mcp.json
{
  "mcpServers": {
    "my-plugin-tool": {
      "type": "stdio",
      "command": "node",
      "args": ["${CLAUDE_PLUGIN_ROOT}/server/index.js"]
    }
  }
}
这样 plugin 移到任何路径都能找到 server 入口。


Hooks · 29 事件分四组
Hooks 是 Claude Code 在 5 家工具里事件最多的一项——29 个事件覆盖 session 生命周期、prompt/tool 调用、agent 状态、环境变化。2026 年还修了一个老问题：hook 异常不再能破坏 TUI（"hook 不能 corrupt UI"修复），hook 失败现在只会被记进日志、agent 收到带 stderr 的失败信号，不再让 TUI 卡住。

// .claude/settings.json 片段
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit",
        "handler": {
          "type": "command",
          "command": "bun run lint --fix ${CLAUDE_FILE_PATH}"
        }
      }
    ],
    "PreToolUse": [
      {
        "matcher": "Bash(rm:*)",
        "handler": {
          "type": "prompt",
          "prompt": "Confirm rm intent: ${CLAUDE_TOOL_ARGS}"
        }
      }
    ],
    "PostToolUseFailure": [
      {
        "matcher": "Bash(npm test:*)",
        "handler": {
          "type": "agent",
          "agent": "explore"
        }
      }
    ]
  },
  "enableAllProjectMcpServers": true
}
也可以把 hooks 嵌进 skill / subagent frontmatter，让 hook 只在该 skill 触发时生效——这是 Claude Code 在抽象层级上比 Codex CLI（6 个事件、仅全局）灵活很多的地方。

误解
实际情况





"MCP server 装在哪台机器都得各装一遍"
.mcp.json commit 进项目，团队成员 clone 仓库自动共享；OAuth token 各自登。




"SSE 是首选 MCP 传输"
SSE 已 deprecated（仍可用）；新建议用 http 或 stdio。HTTP/SSE 帧上限 16MB（2026-04 修复）。




"Hooks 是 25 个"
v2.1.x 截至 2026-05-14 是 29 个事件；handler 5 种（command/http/mcp_tool/prompt/agent）。




"Hook 只能写在 settings.json"
可以内嵌进 skill / subagent frontmatter hooks: 字段，让 hook 仅在该 skill 触发时生效。




"Hook 异常会把 TUI 卡死"
2026-04 修复：hook 失败现在只记日志、agent 收到 stderr 的失败信号，不会破坏 TUI。




"MCP server 改了我得重启 Claude"
list_changed 让 server 端动态更新工具集，agent 不必重启；连接断开走指数退避重连。




"PostToolUseFailure 没有"
有——这是 2026 加入的细化事件，让"失败时自动 spawn explore agent 诊断"成为一行配置。





小结
    

  • 两层各管一摊：.mcp.json + ~/.claude.json 管外部工具接入、settings.json + frontmatter hooks: 管事件自动化。
    • 

  • MCP 三 transport：http（首选）/ sse-deprecated / stdio；.mcp.json 项目共享 + ~/.claude.json 用户全局；enableAllProjectMcpServers: true 一键启用；HTTP/SSE 帧上限 16MB（2026-04 修复）；OAuth 走 /mcp slash；plugin bundled 用 ${CLAUDE_PLUGIN_ROOT}。
    • 

  • Hooks 29 个事件 × 5 种 handler：事件分四组（session 生命周期 / prompt-tool / agent 状态 / 环境变化）；handler 五种（command / http / mcp_tool / prompt / agent）；可嵌进 settings.json 或 skill / subagent frontmatter。
    • 

  • 2026 修复：hook 异常不再能破坏 TUI——失败只记日志，agent 收到 stderr 失败信号。
    • 

  • placeholder 四件套：${CLAUDE_PROJECT_DIR} / ${CLAUDE_PLUGIN_ROOT} / ${CLAUDE_FILE_PATH} / ${CLAUDE_TOOL_ARGS}，让 hook 命令自适应路径与参数。
    •
