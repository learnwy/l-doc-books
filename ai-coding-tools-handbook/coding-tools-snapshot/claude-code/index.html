Claude Code 速览 简介

Claude Code 是 Anthropic 官方的终端原生 AI 编程代理，2026 年的现状已经从"早期 CLI"演进为多 surface 同引擎的成熟产品族：终端 CLI + VS Code / JetBrains 扩展 + 桌面（macOS / Win / Linux ARM64）+ Web（claude.ai/code）+ iOS。它在 5 款工具里最显著的差异点在三处：三层扩展架构 Skills + Subagents + Hooks、唯一以 CLAUDE.md 而非 AGENTS.md 为主提示文件（但兼容读 AGENTS.md fallback）、以及唯一 source-available 但非 OSI 开源的许可证模式（走 Anthropic Commercial ToS）。

适合读者主要有三类：已经在用 Claude 模型（Pro / Max / Team / Enterprise）希望把订阅最大化的开发者；想用 1M token 长上下文（Opus 4.7 / Sonnet 4.6）做大型 refactor 的工程师；以及对 Anthropic 在 agentic coding 上的最新设计（Agent Teams、Background Agents、Plan Mode、Skills 自治调用）感兴趣的工具开发者。本章假设读者熟悉 shell、Git，并理解"Claude Code 不能用 OpenAI / Gemini 等其他厂商模型"。

本章六篇 L4 按"先理解、再上手、最后配置"三对递进。

定位对（1-2）：1_identity-and-history.md 讲 anthropics/claude-code 的 source-available 身份与 Opus 4.7 / Sonnet 4.6 (1M ctx) / Haiku 4.5 (200K ctx) 模型阵列；2_competitive-positioning.md 讲与 Codex / OpenCode / Cursor 的对比定位与目标读者。重点澄清：模型阵列已升级为 Opus 4.7 / Sonnet 4.6 (1M ctx) / Haiku 4.5 (200K ctx)，Pro / Team 默认 Sonnet 4.6（Enterprise + API 自 2026-04-23 切到 Opus 4.7）；2026-05-06 起 5 小时窗速率全面翻倍；commands 已并入 Skills。

上手对（3-4）：3_install-and-login.md 讲 npm / Homebrew / DMG / VS Code+JetBrains 安装与 claude login OAuth / ANTHROPIC_API_KEY 登录；4_first-session-and-headless.md 讲 TUI 内 /permissions /model /agents /skills /plan + /memory 生成 CLAUDE.md + claude -p / --continue / --resume headless 模式。

配置对（5-6）：5_claude-md-and-skills.md 讲 CLAUDE.md 多层加载与 path-scoped rules + Skills frontmatter 14+ 字段；6_mcp-and-hooks.md 讲 .mcp.json + ~/.claude.json 与 29 hooks 事件 + 5 handler 类。

推荐学习路径是按 1→2→3→4→5→6 顺序走一遍；如果已经在用 OpenCode 或 Codex CLI，可直接跳到第 5-6 篇对比 CLAUDE.md vs AGENTS.md 的差异；对 Subagents 与 Agent Teams（v2.1.32+，Opus 协调并行 10 个 sub）感兴趣，请转 01_coding-tools/7_agents/。

版本冻结：本章内容基于 Claude Code 截至 2026-05-14 的官方文档 code.claude.com/docs/en/、Anthropic Changelog 与 v2.1.x 版本族；事实主张全部可在 _research/doc-sources.md §3 中追溯。
