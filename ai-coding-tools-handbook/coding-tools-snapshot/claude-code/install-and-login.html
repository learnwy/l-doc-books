安装客户端 · 登录身份 · plan-默认模型对齐

核心概念

把 Claude Code 从零跑通的"幸福路径"在 2026-05 已经稳定为三步：装客户端 → claude login 或注入 API key → 用 claude status 核对默认模型。三步走通后你就能进 TUI；第一节专注"装 + 登 + 核对"，把"plan 与默认模型不匹配"这种最高频首次失败先拦在源头。

每一步都有 fallback：npm 装失败可改 Homebrew / DMG / VS Code Marketplace；OAuth 端口被拦改 ANTHROPIC_API_KEY；TUI 默认模型不对就 /model opus 或 ANTHROPIC_DEFAULT_OPUS_MODEL 显式 pin。整套流程在网络通畅、有 Claude 订阅或 API key 的前提下，10 分钟以内能完成。

Step 1 · 安装 Claude Code 客户端
官方在 2026 年同时维护四条平行安装路径，按"装在哪台机器 + 谁来管更新"挑就好。

Step 2 · 登录或注入 API key
Claude Code 必须先有一个能用的身份，否则进 TUI 会立刻被引导走登录流程。OAuth 与 API key 互斥但等价，按场景选。


# 推荐：交互式 OAuth，绑定 Claude 订阅
claude login
# 浏览器打开 Anthropic OAuth → 回调本地端口 → token 落 ~/.claude/auth/

# 受限网络 / CI / 仅用 API 计费：直接注入 API key
export ANTHROPIC_API_KEY=sk-ant-xxxxxxxx
claude         # 启动时自动检测环境变量
OAuth 流程临时开本地回调端口（默认 localhost:54545 附近）。公司网络拦回调时退到 API key 模式即可——claude status 会显示 "API key (no plan)"，此时计费走 Anthropic API，与 Pro / Team 订阅额度互不相通。

这是新手最容易踩的一个坑：默认模型与 plan 强绑定，跑起来感觉"很慢且回答短"时，十有八九是 plan 默认 Sonnet 4.6 但任务实际需要 Opus 4.7。下表是 2026-05-14 的状态。

三种修正路径：


# 路径 A：TUI 内当场切（仅本次 session）
# 进 TUI 后输入：
/model opus

# 路径 B：用户级默认（落 ~/.claude/settings.json）
cat >> ~/.claude/settings.json <<'EOF'
{
  "defaultModel": "opus"
}
EOF

# 路径 C：环境变量（三方分发场景必需）
export ANTHROPIC_DEFAULT_OPUS_MODEL=claude-opus-4-7
claude status   # 重新核对，应显示 Opus 4.7
claude status 是排查的第一站，输出大致如下：


$ claude status
Claude Code v2.1.32
Identity     : OAuth (Pro plan)
Account      : alice@example.com
Default model: claude-sonnet-4-6 (1M ctx)
API key      : (not set)
Telemetry    : opt-in (off)
Active project: ~/code/my-monorepo (CLAUDE.md found)
如果 Default model 与你期望不符——例如你是 Pro 用户但想跑 Opus 4.7——就在 ~/.claude/settings.json 里加 defaultModel: opus；或在 TUI 内 /model opus 只切本次 session。三方分发上"找不到 Opus 4.7"的现象专门在路径 C 解决。

小结
    

  • 三步打通：装客户端 → claude login 或 API key → claude status 核对默认模型，10 分钟内完成。
    • 

  • 安装路径六选一：npm 最适合 CI、Homebrew Tap 适合 macOS、DMG/MSI 适合 GUI-first、VS Code & JetBrains 扩展与 CLI 共享 ~/.claude/ 配置、Windows .msi 自动加 PATH。
    • 

  • 登录两种身份：claude login OAuth 绑订阅、ANTHROPIC_API_KEY 按量计费；二者互斥但等价；不能跨用。
    • 

  • plan-默认模型矩阵：Pro/Team = Sonnet 4.6 / Enterprise+API = Opus 4.7（2026-04-23 起）/ Bedrock-Vertex-Foundry = Sonnet 4.5 需 pin；三种修正路径（TUI /model、settings.json、env var）。
    • 

  • 诊断从 claude status 起：Identity / Default model / Active project 三行决定下一步。
