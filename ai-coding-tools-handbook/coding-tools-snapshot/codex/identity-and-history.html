身份与 2026 时间线 · openai/codex 是谁、走到了哪一步

核心概念

OpenAI Codex CLI 是 OpenAI 官方维护的终端编程代理，仓库 openai/codex、许可证 Apache-2.0、用 Rust 编写（核心代码在 codex-rs/）。它在 2026 年的位置可以用一句话定性：唯一一个"由模型方亲自做客户端"的开源终端 CLI —— 其它工具（Claude Code 闭源、OpenCode 第三方、Copilot CLI 闭源加壳）都不同时满足这三点。

身份带来的最大差异是 release train 一体：模型升级（GPT-5.4 → 5.5）、协议演进（MCP outputSchema、AGENTS.md）、商业策略（Fast 推理档、ChatGPT plan 包消化）这三条线都在同一个仓库滚动，CLI 通常领先 chat.openai.com 与第三方 CLI 1–2 周。

只有 openai/codex 同时满足"OpenAI 官方维护、Apache-2.0 开源、跑在本地"三条；ChatGPT 沙箱不开源、Copilot CLI 是 GitHub 的第三方包装。

2026-05 起，CLI 默认模型是 GPT-5.5；向下兼容三个 alias，覆盖"质量 / 速度 / 成本"三档需求。

Fast 推理档 · 2026-05 的关键商业变化
合格 ChatGPT plan（Plus / Pro / Business / Enterprise）在 CLI 内默认启用 Fast 推理档（仓库 PR #19053），等价于"网页和 CLI 拼一份订阅额度"。Free / Go 档无 Fast，响应慢但保留基本能力。


差异化体感是：同一句 prompt，Plus 档 Fast 通常 5–8s 出第一 token，Free 档可能要 15–30s。判断当前档位用 codex status，输出会标 Fast tier: enabled / not eligible。

# ~/.codex/config.toml 看当前的默认模型与 Fast 档
[models]
default = "openai"

[models.openai]
model = "gpt-5.5"           # 默认；可手动锁回 gpt-5.4-mini 省钱
# 不需要 api_key 字段；OAuth 时由 ~/.codex/auth.json 提供

# 若装了多个 provider，fallback 在 default 失败时切
fallback = "ollama"
/etc/codex/requirements.toml 一旦由 admin 部署，用户的 config.toml 与 admin 值冲突时静默失效；启动会打 warning。这是企业管控的 anchor，配置细节见 ./6_hooks-and-mcp.md 收尾段。


陷阱与常见误解




误解
实际情况





"Codex CLI 是 Python 写的"
是 Rust；openai/codex 仓库根下 codex-rs/ 是核心实现，npm 包发的是预编译 Rust 二进制




"Codex CLI = 2021 年 codex 模型"
2021 年 codex 模型已下线；2026 年 CLI 默认 GPT-5.5，仅保留 gpt-5.3-codex 这个 alias 名做命名延续




"Codex CLI = GitHub Copilot CLI"
不同项目：Copilot CLI 由 GitHub 维护、不开源、不读 AGENTS.md、不支持 MCP




"Codex CLI = ChatGPT 网页编程"
网页是 Code Interpreter sandbox Python；CLI 跑在本地终端、读你的真实文件、能改你的真实代码




"Fast tier 是付费功能"
Fast 档不是单独收费项；它是合格 plan（Plus 起）的默认包内能力，没有 Plus 就不能买 Fast




"CLI 升级要重新 codex login"
OAuth refresh token 写在 ~/.codex/auth.json，升级二进制不影响登录态；除非 token 30 天未活跃过期





小结
    

  • OpenAI Codex CLI = OpenAI 官方维护的 Rust 实现 + Apache-2.0 开源终端编程代理，仓库 openai/codex。
    • 

  • 模型阵容：默认 GPT-5.5，向下三档 5.4 / 5.4-mini / 5.3-Codex，覆盖质量、速度、成本。
    • 

  • Fast 推理档（PR #19053）2026-05 起对 Plus / Pro / Business / Enterprise 默认开启，是与第三方 CLI 最直接的商业差异。
    • 

  • 2026 时间线四件大事：Skills 替代 custom prompts（01-22）、MCP outputSchema 推断（04）、Bedrock 一等 + inference_profile_arn（04）、Fast 默认开（05）。
    • 

  • requirements.toml 给企业 admin 一个强约束面，2026 上半年走向稳定，是 Codex CLI 在企业市场的关键 anchor。
    •
