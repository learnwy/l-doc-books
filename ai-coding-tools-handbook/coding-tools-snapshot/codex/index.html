OpenAI Codex CLI 速览 简介

OpenAI Codex CLI 是 OpenAI 官方推出的开源（Apache-2.0）终端编程代理，2026 年的现状已经从"早期 alpha"演进为多前端共享同一 app-server 的完整生态：CLI + TUI + codex exec headless + 桌面应用 + iOS + VS Code / Cursor / Windsurf 扩展 + Cloud。它的核心定位是把 OpenAI 自家最强模型（默认 GPT-5.5，也可用 5.4 / 5.4-mini / 5.3-Codex）以 OpenAI 推荐的安全策略落到你本地终端，同时第一次把 Hooks、MCP、Skills、AGENTS.md 都做成"一等公民"的官方协议面。

适合读者主要有三类：以 ChatGPT 订阅（Plus / Pro / Business）覆盖编程额度、想要把订阅消化到 CLI 的开发者；正在用 Claude Code 但希望加入 OpenAI 模型 / Bedrock 接入面的工程师；以及对"AGENTS.md 跨工具共识"感兴趣、想理解 OpenAI 一手制定的提示约定的团队。本章假设读者熟悉 shell、Git，并接受"CLI 默认会执行真实命令"的事实——如果对此不放心，请先阅读第 5-6 篇的 sandbox_mode 与 approval_policy 章节再上手。

本章六篇 L4 按"先理解、再上手、最后配置"三对递进。

定位对（1-2）：1_identity-and-history.md 讲 openai/codex 的 Rust + Apache-2.0 身份、默认 GPT-5.5、2026 上半年时间线；2_competitive-positioning.md 讲与 Claude Code / OpenCode 的对比定位与目标读者。重点澄清：Codex CLI 是 OpenAI 官方仓库 openai/codex，用 Rust 编写；2026 年 5 月起对合格 ChatGPT plan 默认开启 Fast 推理档；MCP outputSchema、远程插件市场、Amazon Bedrock 一等支持都是 2026 上半年新增能力。

上手对（3-4）：3_install-and-login.md 讲 brew / npm / Releases / Docker 安装与 codex login OAuth / OPENAI_API_KEY 登录；4_first-session-and-headless.md 讲 TUI 内 /permissions /model approval_policy 切换 + /init 生成 AGENTS.md + codex exec --json headless 调用。

配置对（5-6）：5_providers-and-agents-md.md 讲 providers / model（OpenAI / Bedrock / Ollama / LM Studio）与 AGENTS.md 多层加载（project_root_markers、AGENTS.override.md、untrusted-projects 跳过 .codex/ 的安全模型）；6_hooks-and-mcp.md 讲 Hooks 6 个 stable event 与 MCP [mcp_servers.<id>]（stdio + Streamable HTTP + OAuth + allowlist）。

推荐学习路径是按 1→2→3→4→5→6 顺序走一遍；如果已经在用 Claude Code 或 OpenCode，可直接跳到第 5-6 篇看配置差异；如果只是想接 Codex 跑一次 CI 自动化，看完第 1-2 篇后跳到 01_coding-tools/9_industry-scenarios/。模块深度（MCP 协议、AGENTS.md 标准、Skills、Hooks 触发模型、Subagents）请转 01_coding-tools/。

版本冻结：本章内容基于 openai/codex 截至 2026-05-14 的官方文档 developers.openai.com/codex/ 与 Changelog；事实主张全部可在 _research/doc-sources.md §2 中追溯。
