MCP 双向调用 简介

Tier 1 工具栈把 MCP 当 client 用——claude mcp add 接入外部 server 调外部 tool。Tier 2 personal-agent 工具栈把同一个进程既作 client 又作 server：hermes mcp serve / openclaw mcp serve 暴露 memory / persona / skill 这些"软上下文"给 Tier 1 反向调用，同时这些进程内部还作 client 调 Claude Code / Codex 协同工作。本章四篇 L4 讲清这种"双向"协议的实现细节。

本章包含四篇 L4 文档。

1_server-side-impl-hermes.md —— hermes mcp serve 暴露 tool 集（memory_query / memory_write / curator_schedule_list / persona_active / skill_dispatch）与 stdio-first 设计。

2_server-side-impl-openclaw.md —— openclaw mcp serve 暴露 multi-tenant tool 集（persona_switch / message_route / tenant_list / channel_send）与 per-tenant key 隔离。

3_dual-role-process-architecture.md —— 同进程双角色：server thread 监 stdio JSON-RPC、client thread 调 Claude Code/Codex；reentry-guard 防递归、resource isolation 避免 client/server 互相阻塞。

4_anti-recursion-and-orchestration.md —— 防递归与跨 tier 编排：call chain depth limit、超时熔断、典型工作流（Claude Code 拉 hermes memory → 写代码 → memory_write 落回）。

学习建议按章节顺序读；只关心 client 端反向调用配置请回 ../../../01_coding-tools/3_mcp/3_reverse-mcp-and-pitfalls/。深入选型在 ../../../03_bridges/。
