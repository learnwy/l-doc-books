Claude Code：CLAUDE.md 5 层加载与 path-scoped rules

Claude Code 把"提示文件"做成了 5 层金字塔——global / project / personal / subdir lazy-load / path-scoped——但 AGENTS.md fallback 仍是公开 issue #6235 未解决，事实标准是 ln -s AGENTS.md CLAUDE.md。

Claude Code 的提示文件系统是三款工具里最复杂、也最强大的：5 层加载顺序、subdir lazy-load 语义、@path imports 5 跳上限、path-scoped rules 通过 frontmatter globs: 限定。理解它需要先放下"AGENTS.md 应该到处通用"的预期——Anthropic 在 2026-04 docs 已建议 symlink 方案，但 Claude Code 本身并未把 AGENTS.md 当作 first-class 输入。

5 层加载的执行细节
每一层都有独特语义，混淆会导致"明明写了规则却不生效"。


Layer 1 全局 ~/.claude/CLAUDE.md：跨项目共享的个人偏好——"我用 zsh、偏好 pnpm、commit 用 conventional commits"。所有项目启动都会读取，写得过长会消耗每个会话的 context 预算。


Layer 2 项目根 ./CLAUDE.md：团队共享，典型内容是项目命令、代码规范、架构约束。这是大部分内容应该放的地方。


Layer 3 personal override ./CLAUDE.local.md：与 project 同级、但 gitignored，用于个人对项目级规则的临时偏离。优先级高于 Layer 2、低于 chat prompt。


Layer 4 .claude/rules/*.md：path-scoped，通过 frontmatter globs: 字段决定哪些文件访问时激活。详见下文专节。


Layer 5 subdir CLAUDE.md：lazy-load——只有 Claude 真的访问该子目录下的文件时，才会把对应 CLAUDE.md 注入当前 context。这条语义对 monorepo 极重要，但也是最常见的陷阱（见 chapter 3）。


@path Imports 与 5 跳上限
Claude Code 支持在任何 CLAUDE.md 里通过 @path 语法引入其它文件：


# 项目级 CLAUDE.md

## 常用命令

@docs/commands.md

## TypeScript 偏好

@~/.claude/typescript-prefs.md

## API key 处理（敏感，仅本地）

@CLAUDE.local.md
行为细节：


    

  • @path 路径可以是相对（基于当前文件所在目录）或绝对（含 ~/）
    • 

  • import 是编译时展开——加载 CLAUDE.md 时就把 @docs/commands.md 内容塞进去，不在运行时拉取
    • 

  • 5 跳上限：A 引入 B、B 引入 C、C 引入 D、D 引入 E、E 引入 F，第 6 跳静默截断；环依赖（A → B → A）也由这个上限保护
    • 

  • 引入的文件本身没有 @ 限制——可以是任意 Markdown
    • 



实战用法：


    

  • 把长 CLAUDE.md 拆成话题文件、主文件用 @imports 聚合，便于维护
    • 

  • 在 CLAUDE.local.md 用 @~/.claude/private.md 引入敏感偏好（避免每个项目重复抄写）
    • 

  • 团队级"规范库"独立仓库 + git submodule，CLAUDE.md @vendor/style-guide/main.md
    • 



AGENTS.md fallback 之争
Claude Code 是否会把 AGENTS.md 当作 CLAUDE.md 缺失时的 fallback？这是个仍未盖棺定论的问题，截至 2026-05-14：


    

  • 官方 docs 在 2026-02 与 2026-04 两次更新存在矛盾说法：早期写"在 CLAUDE.md 不存在时尝试 AGENTS.md"，最新版改为"建议使用 symlink"
    • 

  • GitHub anthropics/claude-code issue #6235 仍 open，社区诉求是"原生 walk-up AGENTS.md，不要 symlink hack"
    • 

  • 第三方评测站 HiveTrail 在 2026-04 实测 Claude Code 1.x 各版本——AGENTS.md fallback 不可靠，部分版本读取、部分版本忽略，没有公开 changelog 解释行为
    • 



行业事实标准：


ln -s AGENTS.md CLAUDE.md
# 或在 Windows / 某些 CI 环境用 cp 镜像 + pre-commit 同步
这样一份内容同时被 Codex / OpenCode / Cursor / Aider 等读取为 AGENTS.md，被 Claude Code 读取为 CLAUDE.md。Anthropic 在 2026-04 docs 已明确推荐此做法。


注意：


    

  • symlink 只在类 Unix 系统可靠，Windows 需要管理员权限或 WSL
    • 

  • 部分 IDE（VS Code Git 集成）对 symlink 的提交有 bug，建议提交时检查 git diff 确认指向正确
    • 

  • CLAUDE.md 是 symlink 时，Claude Code 仍能正常读取——它是基于 fs.readFile 而非 fs.readlink
    • 



Path-scoped Rules 实战
Layer 4 是 Claude Code 最独特的扩展，落到一个具体例子：


---
description: TypeScript / TSX 编辑时激活的规则
globs:
  - '**/*.ts'
  - '**/*.tsx'
paths:
  - 'src/'
  - 'packages/web/'
---

# TypeScript 偏好

- 优先 `const` over `let`，永远不用 `var`
- React 函数组件用 `function Foo() {}` 不用 `const Foo = () => {}`
- 错误处理用 Result 类型而非 try/catch
- 文件长度建议 < 300 行，超长拆分
文件名 .claude/rules/typescript.md。语义：


    

  • globs: 控制"编辑哪些文件时激活"——这里编辑任意 .ts 或 .tsx 时这条规则进 context
    • 

  • paths: 是更粗的过滤——src/ 或 packages/web/ 路径下才激活
    • 

  • 两者与运算：必须同时命中才激活
    • 

  • description: 用于 model 元数据展示，不影响激活
    • 



落地建议：


    

  • 把"常驻 context 会浪费 token"的规则放到 .claude/rules/ 切片
    • 

  • 命名按语言或子领域分：typescript.md / python.md / database.md / security.md
    • 

  • frontmatter globs: 优先精确（**/*.ts 比 **/* 好），减少误激活
    • 



陷阱与常见问题
    

  • AGENTS.md 不被读取：Claude Code 默认主读 CLAUDE.md，AGENTS.md fallback 不可靠。规避：用 symlink 或 pre-commit 镜像。
    • 

  • subdir CLAUDE.md 不进 context：用户说"看下 frontend/ 然后改 backend/"，但 Claude 没真访问 frontend/，frontend/CLAUDE.md 就不加载。下一章会详谈这条 lazy-load 陷阱。
    • 

  • globs 字段拼写错误：写成 glob: 或 patterns:，frontmatter parser 解析成功但语义不识别，规则永远不激活——没有运行时报错。claude --check-rules 命令可校验。
    • 

  • @imports 跳数错算：在多层引入链里写循环，第 6 跳被截断后部分内容缺失，但 Claude Code 不报错，导致 system prompt 不完整。控制嵌套层级 ≤ 3 是安全做法。
    • 

  • CLAUDE.local.md 误提交：项目 .gitignore 没显式列出 CLAUDE.local.md 时，新仓库可能误推。claude /init 默认会加，但手动新建需要确认。
    • 

  • path-scoped paths 与 globs 关系误解：以为是"或"，实际是"与"——配置 paths: ["src/"] + globs: ["**/*.md"] 时只有 src/ 下的 .md 才激活，不是"src/ 下所有 文件 + 任何 .md"。
    • 



小结
    

  • Claude Code 的提示文件系统是 5 层金字塔：global → project → personal → path-scoped rules → subdir lazy-load
    • 

  • @path imports 编译时展开，最多 5 跳，环依赖由跳数上限保护
    • 

  • AGENTS.md fallback 仍是开放 issue #6235，官方 docs 在 2026-04 推荐 symlink 模式（ln -s AGENTS.md CLAUDE.md）作为行业事实标准
    • 

  • Path-scoped rules 通过 frontmatter globs: + paths: 限定激活范围，把"非常驻"规则切出去节省 context
    • 

  • Layer 5 subdir CLAUDE.md 是 lazy-load——访问该目录文件才注入，是 monorepo 利器也是常见陷阱
    • 

  • 实战注意：AGENTS.md 不可靠、globs 字段拼写、imports 跳数、.local.md 误提交、paths 与 globs 是"与"关系
    •
