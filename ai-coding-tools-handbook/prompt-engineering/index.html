提示工程与 AGENTS.md 统一标准 简介

AI 编程代理在 2026 年终于围绕"提示文件 / agent 配置文件"形成了行业级共识：AGENTS.md 由 OpenAI、Google、Sourcegraph、Cursor、Factory、Anthropic 等八家厂商共同推动，2025 年 12 月归入 Agentic AI Foundation (AAIF / Linux Foundation) 治理；截至 2026 上半年已有 16+ 工具原生读取。这是工具栈里第一份不被任何单家厂商绑定、跨工具直接可移植的提示标准。但表面共识之下，每家工具对同一份 AGENTS.md 的解析路径、扩展能力、加载范围都有可观差异——本 hub 把"标准本身 / 三款工具的差异 / 跨工具协作的陷阱"分三章讲清。

适合读者主要有三类：在 OpenCode / Codex / Claude Code 之间切换或同时使用、希望写一份提示文件喂所有工具的开发者；带团队规范 AI 编程协议的技术负责人，需要决定 AGENTS.md 主写 / CLAUDE.md 主写 / 双写并 symlink 哪种模式；以及对开放标准生态本身感兴趣、想理解 AAIF + agentskills.io 双轨治理的开源贡献者。读者只需会用任一款编程代理跑通过一次会话，无需先读完三款工具的 tool-overview——本 hub 把跨工具差异作为主轴，每条事实都标出最早 source。

本 hub 三章按"先理解标准、再看实现、最后吸取教训"递进。

第 1 章 1_agents-md-and-skills-standards/ 讲两条 2026 年才稳定下来的开放规范：AGENTS.md（agents.md 站点 + AAIF 治理 + 16+ 厂商签署）与 SKILL.md（agentskills.io 标准 + Apache-2.0 + progressive disclosure 设计原则）。两章 L4 分别覆盖规范本体与治理、Skills 渐进披露机制与 token 预算——读完即可独立判断"这个工具是否真正实现了标准 / 实现到哪一层"。

第 2 章 2_per-tool-deep-dive/ 把三款工具的提示文件实现拉平比较：OpenCode 的 opencode.json instructions 字段（支持 paths / globs / URLs 三源）+ AGENTS.md 早期采纳者身份；Codex CLI 的 walk-up 算法 + project_root_markers + AGENTS.override.md + untrusted-projects + requirements.toml admin override；Claude Code 的 CLAUDE.md 5 层加载（~/.claude/CLAUDE.md → 项目根 → subdir lazy-load → .claude/rules/*.md path-scoped → 用户 @imports）+ AGENTS.md fallback 之争（GitHub issue #6235 + 行业 symlink 模式）。

第 3 章 3_pitfalls-and-team-patterns/ 把跨工具协作的陷阱与团队规范沉淀成两篇——大小纪律与 lazy-load 陷阱（150-200 instruction empirical limit、subdir CLAUDE.md 不跨目录加载导致的"我明明写了"误解、.claude/rules/ path-scoped 与 globs 触发条件）、团队协议与迁移路径（mono-repo 多文件 vs flat AGENTS.md、symlink 模式落地、Codex AGENTS.override.md 临时覆盖与 admin requirements.toml 配合、跨工具迁移工具链）。

推荐学习路径是按章节顺序走一遍；如果只用 Claude Code，可在第 1 章后跳到 ./2_per-tool-deep-dive/3_claude-md-imports-and-path-scoped-rules.md；如果在选型阶段、还未决定主用哪款，先把第 3 章扫一遍能避开大部分迁移坑。对 Skills 模块的深入（SKILL.md frontmatter 全集 / per-tool 路径互通）请转 ../3_skills/，对 MCP / Hooks / Subagents 等其它模块请回 ../../01_coding-tools/_INTRODUCTION.md。

版本冻结：本 hub 内容基于 agents.md / agentskills.io / 三款工具截至 2026-05-14 的官方文档与 GitHub 公开 Issue；事实主张全部可在 _research/doc-sources.md §1（OpenCode）/ §2（Codex CLI）/ §3（Claude Code）+ AAIF / Linux Foundation 公告中追溯。
