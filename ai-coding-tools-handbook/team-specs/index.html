团队规范与 AGENTS.md 模板 简介

AI 编程代理进入团队规模化使用阶段后，三类问题立刻浮现：每个开发者各写一份 CLAUDE.md / AGENTS.md，规范不一致；个人 settings 容易把企业策略覆盖掉；新人入职第一天就能把 production database 误删——后两类 2026 已经在多家公司发生事故。Anthropic 2026-04 推出的 admin controls（user groups + 自定义 roles + per-user spend cap + managed Claude Code policies + Compliance API）+ Codex requirements.toml + OpenCode managed settings 共同构成了"团队级强制策略 + 个人级合理灵活"的双层模型。本 hub 把团队 AGENTS.md 模板、admin override 机制、RBAC 权限与分阶段 rollout 讲清，目标读者拿到 hub 直接能起草内部规范文档。

适合读者主要有三类：在中小团队（5-50 人）首次推 AI coding 代理需要标准 baseline 的技术负责人；在大型企业（50+）需要 RBAC + Compliance + MDM 管控的 platform/security 工程师；以及单个开发者想理解为什么自己 settings 某些字段被 silent 覆盖的好奇者。读者只需用过任一款编程代理；如果还不熟 AGENTS.md / CLAUDE.md 的多层加载机制，请先回 ../../01_coding-tools/2_prompt-engineering/。

本 hub 两章按"先看模板与覆盖、再看权限与上线"递进。

第 1 章 1_team-conventions-and-templates/ 讲规范层：第一篇 1_team-agents-md-template-and-monorepo.md 给出一份可直接复用的团队 AGENTS.md baseline（项目背景 / 构建命令 / 测试规约 / 编码风格 / 禁区目录 / 安全约束六段式）+ monorepo 模式（根 + 每 package subdir + .agents/skills/ 中性路径共享）；第二篇 2_managed-settings-and-admin-override.md 讲 admin override 三家实现——Claude Code managed-settings.json 通过 MDM 推到 OS 级路径（macOS /Library/Application Support/ClaudeCode/、Linux /etc/claude-code/）、Codex requirements.toml 在 ~/.codex/ 或 /etc/codex/、OpenCode 远程 .well-known/opencode + managed settings 配置；admin 字段无法被 user 或 project settings 覆盖。

第 2 章 2_permissions-and-rollout/ 讲权限与上线：第一篇 1_permission-tiers-and-rbac.md 讲 Claude Code 的 deny → ask → allow 优先级（first-match wins、hook decisions 不能绕过 deny）+ RBAC on Enterprise（org setting + role setting 双 ON 才生效、custom roles 不能 override seat-level、dual-seat plan 限制）+ MCP server allowlist（allowManagedMcpServersOnly: true 锁定）；第二篇 2_phased-rollout-and-compliance.md 讲分三阶段 rollout（pilot 5 人 → 团队 20 人 → 全公司）、Anthropic 2026-04 Compliance API 抓 audit log、与 SOC2 / ISO 27001 的接入点、回滚预案（若 managed settings 推下去后影响开发效率怎么快速 rollback）。

推荐学习路径是按章节顺序读；首次部署的团队建议把第 1 章 1 节模板直接搬到 agents/AGENTS.md.template、再读第 2 章 2 节做 phased rollout。Observability 的 metrics export 与本 hub 是 admin 视角的两条线，请同时读 ../3_observability/。

版本冻结：本 hub 内容基于 Anthropic 2026-04 admin controls release + Claude Code v2.1.x + Codex requirements.toml + OpenCode anomalyco/opencode 仓库截至 2026-05-14；事实主张全部可在 _research/doc-sources.md 与 Anthropic 官方 changelog 中追溯。
