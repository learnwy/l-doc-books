Skills 实现与 SKILL.md 深度参考 简介

Skills 在 2026 年是 AI 编程工具栈里"可复用过程性知识"的事实标准。agentskills.io 把核心规范以 Apache-2.0 协议发布、Anthropic 在 Claude Code 里把它扩展成 14+ frontmatter 字段、Codex 通过 openai.yaml 元数据补充、OpenCode 走多路径互通 + plugin-bundled——同一份 base SKILL.md 在 16+ 工具里直读，是这套标准跨工具协作的核心成果。前置 hub ../1_prompt-engineering/1_agents-md-and-skills-standards/ 已经讲清"Skills 是什么、为什么 progressive disclosure 设计、token 经济学"。本 hub 接着深入实现细节：完整的 frontmatter 字段参考、每款工具的 Skills 实现差异、跨工具路径互通与生命周期管理。

适合读者主要有三类：第一次写 SKILL.md、不知道哪些字段是 spec 哪些是 vendor extension 的开发者；正在迁移 skill 从 Claude Code 到 Codex / OpenCode、需要知道哪些字段会被静默忽略的工程师；以及在团队规模化 Skills 实践（多人 review、共享插件、版本管理）阶段需要 lifecycle 模板的技术负责人。本 hub 假设读者已经熟悉 SKILL.md 与 AGENTS.md 的角色分工——如果还不熟，请先回 ../1_prompt-engineering/。

本 hub 三章按"先读规范、再看实现、最后看跨工具协作"递进。

第 1 章 1_skill-md-reference/ 是 SKILL.md 规范的深度参考：第一篇讲文件布局与发现机制——skill-name/SKILL.md 目录结构、scripts/ 子目录、命名规则、四类 discovery 来源（user ~/.config/claude/skills/ + project .claude/skills/ + plugin-bundled + built-in）的扫描顺序与冲突处理；第二篇是 14+ frontmatter 字段的完整 reference 表，含每字段的 spec/Claude/Codex/OpenCode 支持矩阵（哪些字段被哪些工具识别 / 哪些被静默忽略），覆盖 name / description / argument-hint / disable-model-invocation / user-invocable / allowed-tools / model / context: fork / agent / effort / version / mode / !command 动态注入 / $ARGUMENTS 替换。

第 2 章 2_per-tool-skills/ 把三款工具的 Skills 实现拉平展开：Claude Code 是 spec 创始者与 reference implementation——讲完整的 14+ 字段语义、commands 已合并到 Skills 后的兼容路径、运行时 /skills 命令、context: fork 与 agent: 字段的已知 bug（issue #17283）；Codex 用 openai.yaml 做 vendor extension、tools allowlist 与 Skills 协作；OpenCode 的关键差异是多路径互通——.opencode/skills/ + .claude/skills/ + .agents/skills/ 三路径并存扫描、plugin-bundled skills、commands 仍兼容旧路径。

第 3 章 3_cross-tool-interop/ 收尾跨工具协作与生命周期：第一篇讲路径互通的实战——同一份 skill 在多个工具里共用、plugin 与 user-skill 的优先级、team 共享时 commit 哪些路径；第二篇讲生命周期与陷阱——版本管理、命名冲突、prompt-injection 安全审计 checklist、retire 已弃用 skill 的迁移路径。

推荐学习路径是按章节顺序走一遍。如果只想快速查某个 frontmatter 字段，直接看第 1 章 2 篇的字段表；如果是新手写第一个 skill，建议第 1 章 + 第 2 章对应工具的一节即可。对 MCP / Hooks 等其它模块请回 ../；对 Skills 跨 tier 应用（Tier 2 工具自动维护 Skills 的方案）请转 ../../02_personal-agents/3_skills-self-creation/。

版本冻结：本 hub 内容基于 agentskills.io Apache-2.0 标准、code.claude.com/docs/en/skills 与三款工具截至 2026-05-14 的官方文档；事实主张全部可在 _research/doc-sources.md 与 Anthropic / OpenAI / Anomalyco 官方仓库公开 issue 中追溯。
