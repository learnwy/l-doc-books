三款工具的命令实现 简介

读完架构脉络之后，本章把三款工具具体怎么写命令、怎么调用、有哪些独有能力拉平比较。Claude Code 是 commands→Skills 合并的发起者、reference implementation；Codex 用 implicit description 匹配 + sidecar openai.yaml 提供 vendor extension；OpenCode 走多路径兼容 + plugin-bundled + 触发器机制。三家底层都接受 SKILL.md 格式，但 frontmatter 字段支持度、参数捕获机制、运行时列表 UI 都不相同。

本章包含三篇 L4 文档。

1_claude-code-commands.md —— Claude Code 的 commands→Skills 合并。第一块讲两个共存路径——.claude/commands/<name>.md legacy（仍工作）+ .claude/skills/<name>/SKILL.md 新形式；同名时 skill 优先、/help 显示双源命令。第二块讲 legacy 命令的 $ARGUMENTS 参数捕获——/review feature/auth 会把 feature/auth 注入到命令 body 的 $ARGUMENTS 占位符；新 Skill 形式用 $1 $2 多参数 + frontmatter argument-hint 提示自动补全。第三块讲 frontmatter 在 legacy 与 Skill 之间的字段对应——description / model / tools 三者两边都支持；Skill 独有 disable-model-invocation / user-invocable / context: fork。第四块讲运行时——/help 列命令、/skills 列 Skills、两者可同时出现；session 中可用 /clear 重置 context。

2_codex-commands.md —— Codex 的 implicit + explicit 双轨调用。第一块讲发现路径——.codex/commands/<name>.md（legacy） + .agents/skills/<name>/SKILL.md（中性路径，walk-up 扫描），Codex 不读 project 级 .codex/ 因 untrusted-projects 默认策略。第二块讲两种调用——implicit（模型读 description 匹配 user prompt，"帮我审 PR" 自动激活 pr-review skill）vs explicit（$pr-review 强制激活）。第三块讲 agents/openai.yaml sidecar 元数据——声明 UI display name、invocation policy（manual / auto / hybrid）、依赖的 MCP server 列表；这些 OpenAI-only 字段不进 base SKILL.md frontmatter，避免污染跨工具 spec。第四块讲 Codex 命令的安全模型——approval_policy 与 sandbox_mode 字段在 openai.yaml 可设置，触发命令时强制走相应级别 user approval。

3_opencode-commands.md —— OpenCode 的多路径互通 + plugin-bundled。第一块讲三路径并存——.opencode/commands/ legacy + .opencode/skills/ 新格式 + 共享 .agents/skills/（agentskills.io 中性路径）；扫描合并去重、同名按 plugin > project > user 优先。第二块讲 plugin-bundled commands——通过 plugin.json 声明 skill 列表，plugin 安装时一并注册；touch plugin 文件不需要重启 OpenCode session。第三块讲 OpenCode 独有的 instructions provider plugin——同一 plugin 可在 build/plan agent 切换时动态变更 skill 列表，是"plugin = hook 实现方式"哲学在 commands 上的具体落地。第四块讲与 Claude Code skill 的 binary compatibility——.claude/skills/<name>/SKILL.md 直接放进 OpenCode 项目可工作，无需任何转换。

学习建议是只用一款工具的读者只看对应一节；同时用多款的建议三节都读——重点对比"frontmatter 字段支持度差异"与"参数捕获语法差异"两条线，迁移 80% 的坑都在这两处。
