Subagents 隔离与 Agent Teams 协同 简介

2026 年 AI 编程代理生态完成了从"单 agent + tool 调用"到"多 agent 协同"的关键演进。Anthropic 在 Opus 4.6（2026-02 早期）随 Claude Code 推出 Agent Teams——lead agent 派出 teammate 各自独立 context，通过 shared task list 与 peer-to-peer 消息协调；OpenAI Codex App 走桌面 supervisor 路线、内置 worktree per agent；OpenCode 在 2026 上半年 port 出自己的 Agent Teams 实现、独有 cross-provider model mix 能力。这一波"多 agent"是建立在更早的 subagent 隔离机制（isolation: worktree、own context window、独立 hooks / permissions）之上的——理解 subagent 隔离是看懂多 agent 协同的前提。本 hub 把 subagent 基础、三家 agent 实现、多 agent 模式选型与防递归讲清。

适合读者主要有三类：第一次用 subagent 委派任务、被"为什么 fork 比 spawn fresh 便宜"困惑的开发者；规划团队大型重构、想用 Agent Teams 把工作并行化的工程师；以及在 Tier 1 + Tier 2 反向 MCP 编排场景下担心 agent 递归调用的架构师。读者只需会用一款编程代理跑通一次 session 即可上手；如果对 hooks / permissions 还不熟，请先回 ../5_hooks/。

本 hub 三章按"先理解 subagent 隔离、再看每家 agent 实现、最后看多 agent 模式与防递归"递进。

第 1 章 1_subagent-fundamentals/ 讲 subagent 基础机制：第一篇 subagent 隔离与 context——每个 subagent 自己的 context window、system prompt、tool access、permission 集；isolation: worktree 在 fresh git worktree 跑 subagent、per-worktree state（plan mode / memory / hooks / permissions / transcript）随 worktree 走、收尾自动 cleanup；第二篇 fork mode 与 prompt cache——fork 复用 parent 的 system prompt 与 tool definitions、首次 request reuse parent prompt cache（比 spawn fresh 便宜）、CLAUDE_CODE_FORK_SUBAGENT=1 启用、fork 不能再 fork（防递归）、何时 fork 何时 spawn。

第 2 章 2_per-tool-agents/ 把三款工具拉平：Claude Code 的 subagent + Agent Teams（Opus 4.6 release 2026-02，CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS flag，shared task list 三态 pending/in-progress/completed + 依赖、teammate 间 message passing 而非 main agent 中转）；Codex App 的 desktop supervisor 模型（视觉 operations console、built-in worktree per agent、cloud execution、跨 surface 状态统一）；OpenCode 的 Agent Teams port（cross-provider model mix 独有能力、event-driven messaging + JSONL append-only、single-process 折衷）。

第 3 章 3_multi-agent-patterns-and-recursion-guards/ 讲多 agent 实战：第一篇 模式选型决策框架——single session vs subagent vs Agent Teams vs /batch，按"并行需求 / 共享 context / 任务依赖度"三轴决定；worktree + subagent 组合最被低估；第二篇 防递归与协调——fork-can't-fork 规则的底层逻辑、message-passing 协调、task list state machine 的 dependency 解锁、Tier 2 工具反向 MCP 场景下的 reentry-guard、infinite-loop 防护套件。

推荐学习路径是按章节顺序走一遍；如果只用 Claude Code，第 1 章 + 第 2 章 1 节 + 第 3 章即可；选型阶段必读第 3 章 1 节。反向 MCP 场景请同时参考 ../2_mcp/3_reverse-mcp-and-pitfalls/。

版本冻结：本 hub 内容基于 Claude Code v2.1.32+（Agent Teams 引入）+ Anthropic Opus 4.6 release 2026-02 + Codex App 桌面端官方 docs + anomalyco/opencode 仓库截至 2026-05-14；事实主张全部可在 _research/doc-sources.md 中追溯。
