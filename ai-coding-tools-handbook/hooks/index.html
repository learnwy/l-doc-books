Hooks 触发模型与跨工具实现 简介

Hooks 是 AI 编程代理生态里"事件驱动自动化"的统一抽象——在 agent 生命周期的特定事件点（工具调用前后、会话启动、用户提交 prompt、stop、文件变更、worktree 创建等）执行外部脚本以注入额外检查、状态收集或硬拦截。三款主流工具的 hook 触发模型在 2026 收敛到一套相似的"JSON via stdin / exit code + stdout + stderr"协议，但事件覆盖度、JSON output 控制语义、bridge 机制各不相同：Claude Code 有 20+ 事件、最丰富的结构化 JSON 控制 schema、5 类 handler；Codex 有 6 个 stable 事件、走 OpenAI 内部安全策略；OpenCode 不原生支持 Claude 兼容 hooks、走 plugin 系统（tool.execute.before/after + session.idle），是"plugin = hook 实现方式"哲学的具体落地。本 hub 把触发模型、三家实现、陷阱与 bridge 模式讲清。

适合读者主要有三类：第一次写 hook 需要理解 exit code 0/2 阻塞语义的开发者；维护跨 Claude / Codex / OpenCode 多工具 setup 但希望 hook 逻辑可复用的工程师；以及需要把"团队规范"硬编码到 agent 工作流里（如 pre-commit 强制检查、stop hook 验证 SOP 完成）的技术负责人。读者只需会写一个 bash/python 脚本即可上手；如果对 agent session 生命周期还不熟，请先读 ../../01_coding-tools/ 任一款工具的 getting-started 章。

本 hub 三章按"先理解触发模型、再看实现、最后看陷阱与跨工具桥接"递进。

第 1 章 1_hook-trigger-model/ 讲触发模型本体：第一篇讲 exit code + stderr semantics——exit 0 success / exit 2 blocking + stderr 反馈 / 其它 non-zero 非阻塞（WorktreeCreate 除外，任何 non-zero abort）；第二篇讲 JSON stdout 结构化控制——PreToolUse {decision: "allow"|"deny"|"ask"}、PostToolUse/Stop {block: true}、{additionalContext: "..."} 上下文注入、UserPromptSubmit/UserPromptExpansion/SessionStart stdout 作 context 三个特殊事件。

第 2 章 2_per-tool-hooks/ 把三款工具实现拉平：Claude Code 的 20+ 事件 + 5 类 handler（command / http / mcp_tool / prompt / agent）+ settings.json 配置；Codex 6 stable 事件 + [hooks] config.toml 配置 + admin override；OpenCode 的 plugin-based 触发器架构——tool.execute.before / tool.execute.after / session.idle 三类事件 + plugin 生命周期。

第 3 章 3_hooks-pitfalls-and-bridges/ 收尾两类话题：第一篇讲 stdout 纪律与无限循环防护——echo/printf 必须走 stderr 否则破坏 JSON 解析、FileChanged hook 写文件触发自己造成 loop、debug log 与生产 hook 分离；第二篇讲 跨工具 bridge 模式——OpenCode 用 plugin 把 Claude Code hook 逻辑桥接（PreToolUse → tool.execute.before + tool 名转换 bash→Bash + exit 2 re-injection 模拟 Stop hook SOP-enforcement），让一套 hook 脚本喂多个工具。

推荐学习路径是按章节顺序读；如果只用 Claude Code，第 1 章 + 第 2 章 1 节 + 第 3 章 1 节即可；多工具用户必读第 3 章 2 节理解 bridge 范式。MCP / Skills / Subagents 等其它模块请回 ../。

版本冻结：本 hub 内容基于 Claude Code code.claude.com/docs/en/hooks + Codex developers.openai.com/codex/ + anomalyco/opencode issue #12472（Claude Code hook 原生兼容讨论）+ Anthropic Changelog v2.1.x；事实主张全部可在 _research/doc-sources.md 中追溯。
