Hermes 安装与 memory 初始化

核心概念

Hermes 的上手路径分三步：先把 CLI binary 装好（直接下载 / Homebrew 二选一）、再用 hermes init 初始化 memory 存储与配置目录、最后等第一次 curator cron 跑一遍把"骨架库"长出来。本节按这条线性流程走，目标是让读者在 20 分钟内拿到一个能被 coding agent 通过反向 MCP 调用的 Hermes 实例。

整套流程的核心是"先把骨架长出来"——init 完毕只是壳，真正能用的 memory 库需要至少一次 curator 周期把 importance / dedupe / retire 三件事跑完。

Homebrew 安装步骤
brew tap hermes-agent/tap
brew install hermes-agent
hermes --version
后续升级：


brew upgrade hermes-agent
直接下载 binary 步骤
# 假设是 macOS arm64
curl -L -o hermes \
  https://example.invalid/hermes/releases/latest/hermes-darwin-arm64
chmod +x hermes
sudo mv hermes /usr/local/bin/hermes
hermes --version
下载源 / 校验签名 / 版本号在实际官方发布时按官方说明执行；上面是结构示例。


hermes init：初始化存储与配置
hermes init
init 会依次问几件事：


    

  1. storage path：默认 ~/.learnwy/hermes/，可改；这是 memory SQLite + skill 目录 + audit log 的家。
    2. 

  2. default editor：用于后续 hermes skill new / hermes memory edit 时调起的编辑器（默认读 $EDITOR）。
    3. 

  3. enable curator cron：默认 yes，会在系统 cron / launchd 里登记一个每日 03:00 跑的 job。
    4. 

  4. import existing context：可选，把已有的笔记 / chat history 导入为初始 memory（详见下节）。
    5. 



完成后会生成的目录结构：


~/.learnwy/hermes/
  config.toml              # 顶层配置
  memory.sqlite            # 主存储（FTS5 索引）
  skills/                  # 自创 skill 根目录
    claude-code/           # 官方 bundled skill
      SKILL.md
  audit/                   # NDJSON 审计日志按天分片
    2026-05-14.ndjson
config.toml 大致这样：


[storage]
path = "/Users/<you>/.learnwy/hermes"

[curator]
schedule = "0 3 * * *"
importance_threshold = 0.3
stale_days = 90

[mcp]
listen_address = "127.0.0.1:7654"
require_token = true
可选：import existing context
如果你之前用过别的笔记 / chat 工具，可以一次性导入作为 Hermes 的初始 memory：


# 从纯文本笔记导入
hermes import notes --path ~/notes/ --recurse --tag personal

# 从 chat platform 导出文件导入（飞书 / Slack 的导出 JSON）
hermes import chat --format slack --file ./team-export.json --tag team

# 从 Claude Code transcript 导入
hermes import transcript --path ~/.claude/projects/ --since 2026-01-01
import 完成后每条变成一个 memory entry，自动打上初始 importance score（按字数、重复度、显式标记的优先级）；具体 score 算法在 6_curator-and-skill-self-improvement.md 详述。

第一次 curator 周期
curator 是 Hermes 的"看门人"。init 后第一次 cron 触发可能要等到次日 03:00；如果你想立刻跑一遍，手动触发：


hermes curator run --dry-run        # 看会做什么
hermes curator run                  # 实际跑
第一次 curator 周期会做四件事：


    

  1. importance re-rank：把当前所有 memory entry 重排，按 (importance × recency-decay) 算综合分。
    2. 

  2. dedupe：检测内容近似的条目（FTS5 hash + 编辑距离），保留最高分，其它标为 superseded。
    3. 

  3. retire stale：超过 stale_days（默认 90 天）且 access count = 0 的条目标为 retired，不再返回给查询。
    4. 

  4. emit metrics：把本次 curator 处理量 / 改变数写入 audit/curator-<date>.ndjson，便于事后追溯。
    5. 



dry-run 输出大致：


curator-dry-run:
  total-entries: 1247
  to-rerank: 89  (importance score moved by >0.1)
  to-dedupe: 12  (would mark 7 as superseded)
  to-retire: 34  (90+ days no access)
  estimated-time: 4.2s
hermes status：健康检查
curator 跑完后跑一次 status：


hermes status
输出大致：


hermes:
  storage: ~/.learnwy/hermes (free=120GB)
  memory-entries: 1247 (active=1206, retired=34, superseded=7)
  skills: 1 (claude-code bundled)
  curator:
    last-run: 2026-05-14 03:00:00 UTC
    next-run: 2026-05-15 03:00:00 UTC
    metrics: 89/12/34 (rerank/dedupe/retire)
  mcp-serve: not-listening (run `hermes mcp-serve` to start)
最后一行提醒：要让 coding agent 调用 Hermes 必须先 hermes mcp-serve：


hermes mcp-serve &
启动后在 Claude Code 的 MCP 配置里加：


{
  "mcpServers": {
    "hermes": {
      "command": "hermes",
      "args": ["mcp-stdio"]
    }
  }
}
下次 coding agent 起 session 就能看到 memory.query / memory.write / skill.list / skill.dispatch 等 tool 可用。


陷阱与常见问题
    

  • storage path 选了云盘同步目录：iCloud / Dropbox 会同步 SQLite 中间状态，导致 corruption；务必放本地非同步目录。
    • 

  • 跳过首次 curator：未 curator 过的 memory 全是 raw 状态，查询返回 noise 多；至少 dry-run + 实际跑一次。
    • 

  • 直接编辑 memory.sqlite：FTS5 索引必须用 hermes memory edit 维护，手改 SQLite 会破坏倒排索引。
    • 

  • 多机器共用同一 storage：SQLite WAL 模式不支持多 host 并发；多设备同步要用专门的 sync 协议（见 5_seven-terminal-backends.md 末尾的 mesh 模式）。
    • 

  • 忘记 hermes mcp-serve：coding agent 没看到 Hermes tool 时第一件事就是 status 看 mcp-serve 行。
    • 



小结
    

  • 两种安装：直接下载 binary（Linux 友好）/ Homebrew（macOS 友好）。
    • 

  • 首次 init 配置 storage path + curator cron + 可选 import 旧 context。
    • 

  • 第一次 curator 周期做四件事：importance re-rank / dedupe / retire stale / emit metrics。
    • 

  • hermes status 是健康检查入口，逐行确认 storage / memory / skill / curator / mcp。
    • 

  • 最后 hermes mcp-serve 启动反向 MCP server，coding agent 才能调用。
    • 

  • 下一篇 4_first-skill-and-claude-code-bundle.md 自创第一个 skill 并启用 bundled claude-code。
    •
