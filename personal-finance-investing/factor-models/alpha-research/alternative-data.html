另类数据与非传统因子

概述

另类数据（Alternative Data）是指传统金融数据（价格、成交量、财务报表）之外的一切可用于投资决策的数据源。截至 2026 年，全球另类数据市场规模已超过 80 亿美元，超过 90% 的系统化对冲基金至少使用一种另类数据。从卫星图像到社交媒体情绪，从信用卡交易到专利申请，另类数据正在重塑量化投资的竞争格局。本文系统介绍主要另类数据类型、处理方法和因子化路径。

文本数据与情绪因子
新闻情绪分析
新闻情绪因子是另类数据中最成熟的应用。构建流程：


    

  1. 数据采集：从新闻源（Reuters, Dow Jones, Bloomberg）获取实时新闻
    2. 

  2. 实体识别：将新闻映射到具体公司/股票
    3. 

  3. 情绪打分：使用 NLP 模型对新闻文本进行情绪分类
    4. 

  4. 信号聚合：将多条新闻的情绪汇总为单一信号
    5. 



import numpy as np
import pandas as pd

class NewsSentimentFactor:
    """新闻情绪因子构建"""

    def __init__(self, decay_half_life=5, min_articles=3):
        self.decay_half_life = decay_half_life
        self.min_articles = min_articles

    def compute_sentiment_signal(self, news_data, as_of_date):
        """
        计算截至 as_of_date 的情绪信号

        参数:
            news_data: 新闻数据，含 stock_id, date, sentiment_score, relevance
        返回:
            signals: 各股票的情绪信号
        """
        lookback_days = self.decay_half_life * 5
        start_date = as_of_date - pd.Timedelta(days=lookback_days)

        recent_news = news_data[
            (news_data['date'] >= start_date) &
            (news_data['date'] <= as_of_date)
        ].copy()

        recent_news['days_ago'] = (as_of_date - recent_news['date']).dt.days
        decay = np.log(2) / self.decay_half_life
        recent_news['weight'] = (
            np.exp(-decay * recent_news['days_ago']) * recent_news['relevance']
        )

        def weighted_sentiment(group):
            if len(group) < self.min_articles:
                return np.nan
            weights = group['weight']
            sentiments = group['sentiment_score']
            return np.average(sentiments, weights=weights)

        signals = recent_news.groupby('stock_id').apply(weighted_sentiment)
        return signals

地理位置数据
手机地理位置数据提供了消费者行为的实时画像：


def foot_traffic_signal(location_data, store_mapping, stock_id):
    """
    基于人流量数据构建消费类公司的收入预测信号

    参数:
        location_data: 包含 POI 日均访问量的时间序列
        store_mapping: POI 到上市公司的映射
        stock_id: 目标股票
    返回:
        signal: 人流量变化信号
    """
    stores = store_mapping[store_mapping['stock_id'] == stock_id]
    store_visits = location_data[location_data['poi_id'].isin(stores['poi_id'])]

    daily_total = store_visits.groupby('date')['visits'].sum()

    current_4w = daily_total.iloc[-28:].mean()
    previous_4w = daily_total.iloc[-56:-28].mean()
    yoy_same_period = daily_total.iloc[-365-14:-365+14].mean()

    mom_signal = (current_4w / previous_4w - 1) if previous_4w > 0 else 0
    yoy_signal = (current_4w / yoy_same_period - 1) if yoy_same_period > 0 else 0

    return 0.5 * mom_signal + 0.5 * yoy_signal
消费与交易数据
信用卡数据
信用卡交易数据被认为是"最接近营收的另类数据"——直接衡量消费者在特定商户的支出。


关键挑战：


    

  1. 面板偏差：信用卡数据通常来自特定发卡行，面板可能不代表全部消费者
    2. 

  2. 支付方式变化：现金、借记卡、移动支付的占比变化影响信号稳定性
    3. 

  3. 季节性：消费数据有强季节性，需要年同比处理
    4. 

  4. 数据延迟：通常 3-7 天可用
    5.

ESG 因子的特殊性
ESG 因子与传统因子的显著区别：


    

  1. 评分分歧：不同 ESG 评级机构对同一公司的评分相关性仅 ~0.6（远低于信用评级的 0.99）
    2. 

  2. 动量效应：ESG 评分的变化（而非水平）可能是更好的预测因子
    3. 

  3. 行业偏差：某些行业天然 ESG 评分低（如能源），行业中性化是必要的
    4. 

  4. 数据可用性：中小盘公司的 ESG 数据覆盖不足
    5. 



def esg_momentum_factor(esg_scores, lookback_months=12):
    """
    ESG 动量因子：ESG 评分的变化而非水平

    参数:
        esg_scores: 包含 stock_id, date, esg_score 的面板数据
        lookback_months: 变化计算的回溯期
    返回:
        factor: ESG 动量因子值
    """
    esg_current = esg_scores.groupby('stock_id')['esg_score'].last()

    lookback_date = esg_scores['date'].max() - pd.DateOffset(months=lookback_months)
    esg_prior = esg_scores[esg_scores['date'] <= lookback_date].groupby(
        'stock_id')['esg_score'].last()

    esg_change = esg_current - esg_prior

    esg_change_ranked = esg_change.rank(pct=True)
    return esg_change_ranked

总结
核心要点
    

  1. 另类数据的价值在于信息时效性优势——比传统财务数据更早反映公司基本面变化
    2. 

  2. NLP 和 LLM 已成为文本因子的标准工具——但模型选择和提示工程仍是核心差异化来源
    3. 

  3. 卫星和地理空间数据提供了"物理世界"的实时观测——特别适合消费、能源和农业领域
    4. 

  4. 数据质量评估先于信号开发——历史深度、覆盖度和偏差是首要考量
    5. 

  5. 另类数据因子的独特贡献才有价值——如果只是已知因子的高相关替代，则不值得付费
    6. 

  6. 信息优势会随数据普及而衰减——持续寻找和整合新数据源是保持竞争力的关键
    7. 

  7. 合规风险不可忽视——个人数据保护法规（GDPR、CCPA、中国个人信息保护法）对数据使用有严格限制
    8.
