机器学习因子模型

概述

机器学习（Machine Learning, ML）方法正在深刻地改变量化因子研究的范式。传统因子模型假设线性定价关系（E[Ri]=βTλE[R_i] = \beta^T \lambdaE[Ri​]=βTλ），而 ML 方法允许高度非线性的特征-收益映射、自动化特征交互和高维数据的降维。从 Gu, Kelly & Xiu（2020）的里程碑式研究到 2025-2026 年 Transformer 和大语言模型在金融中的应用，ML 因子模型已从学术探索走向产业标准。本文系统介绍 ML 在因子模型中的核心方法、最佳实践和前沿进展。

ML 因子模型的理论框架

从线性到非线性

传统因子模型的定价方程为线性形式：

E[Ri,t+1]=g(xi,t)=xi,tTβE[R_{i,t+1}] = g(x_{i,t}) = x_{i,t}^T \betaE[Ri,t+1​]=g(xi,t​)=xi,tT​β

ML 因子模型将其推广为：

E[Ri,t+1]=g(xi,t)E[R_{i,t+1}] = g(x_{i,t})E[Ri,t+1​]=g(xi,t​)

其中 g(⋅)g(\cdot)g(⋅) 是通过数据学习的非线性函数，xi,tx_{i,t}xi,t​ 是高维特征向量。

核心 ML 方法
线性模型：LASSO / Ridge / Elastic Net
正则化线性模型是 ML 因子模型的起点：


LASSO（L1 正则化）：


min⁡β1T∑t,i(ri,t+1−xi,tTβ)2+λ∥β∥1\min_\beta \frac{1}{T}\sum_{t,i} (r_{i,t+1} - x_{i,t}^T\beta)^2 + \lambda \|\beta\|_1βmin​T1​t,i∑​(ri,t+1​−xi,tT​β)2+λ∥β∥1​
LASSO 自动进行特征选择——不重要的特征系数被缩减为零。


Ridge（L2 正则化）：


min⁡β1T∑t,i(ri,t+1−xi,tTβ)2+λ∥β∥22\min_\beta \frac{1}{T}\sum_{t,i} (r_{i,t+1} - x_{i,t}^T\beta)^2 + \lambda \|\beta\|_2^2βmin​T1​t,i∑​(ri,t+1​−xi,tT​β)2+λ∥β∥22​
Ridge 将所有系数收缩但不置零，适合高度共线的特征集。


Elastic Net：


min⁡β1T∑t,i(ri,t+1−xi,tTβ)2+λ1∥β∥1+λ2∥β∥22\min_\beta \frac{1}{T}\sum_{t,i} (r_{i,t+1} - x_{i,t}^T\beta)^2 + \lambda_1 \|\beta\|_1 + \lambda_2 \|\beta\|_2^2βmin​T1​t,i∑​(ri,t+1​−xi,tT​β)2+λ1​∥β∥1​+λ2​∥β∥22​
结合 L1 和 L2 的优势。

y^(m)=y^(m−1)+η⋅hm(x)\hat{y}^{(m)} = \hat{y}^{(m-1)} + \eta \cdot h_m(x)y^​(m)=y^​(m−1)+η⋅hm​(x)

import lightgbm as lgb
import numpy as np
import pandas as pd

def train_lgbm_factor_model(train_features, train_returns,
                             valid_features, valid_returns,
                             params=None):
    """
    LightGBM 因子预测模型

    参数:
        train_features: 训练集特征 (T_train × N, K)
        train_returns: 训练集收益 (T_train × N,)
        valid_features: 验证集特征
        valid_returns: 验证集收益
    返回:
        model: 训练好的模型
        feature_importance: 特征重要性
    """
    if params is None:
        params = {
            'objective': 'regression',
            'metric': 'mse',
            'learning_rate': 0.05,
            'num_leaves': 31,
            'max_depth': 6,
            'min_child_samples': 100,
            'subsample': 0.8,
            'colsample_bytree': 0.8,
            'reg_alpha': 0.1,
            'reg_lambda': 1.0,
            'verbose': -1
        }

    train_data = lgb.Dataset(train_features, label=train_returns)
    valid_data = lgb.Dataset(valid_features, label=valid_returns, reference=train_data)

    callbacks = [
        lgb.early_stopping(stopping_rounds=50),
        lgb.log_evaluation(period=100)
    ]

    model = lgb.train(
        params, train_data,
        num_boost_round=1000,
        valid_sets=[valid_data],
        callbacks=callbacks
    )

    importance = pd.Series(
        model.feature_importance(importance_type='gain'),
        index=train_features.columns
    ).sort_values(ascending=False)

    return model, importance

import torch
import torch.nn as nn

class FactorNN(nn.Module):
    """用于截面收益预测的前馈网络"""

    def __init__(self, input_dim, hidden_dims=[64, 32, 16], dropout=0.3):
        super().__init__()

        layers = []
        prev_dim = input_dim
        for hidden_dim in hidden_dims:
            layers.extend([
                nn.Linear(prev_dim, hidden_dim),
                nn.BatchNorm1d(hidden_dim),
                nn.ReLU(),
                nn.Dropout(dropout)
            ])
            prev_dim = hidden_dim

        layers.append(nn.Linear(prev_dim, 1))
        self.network = nn.Sequential(*layers)

    def forward(self, x):
        return self.network(x).squeeze(-1)

条件因子模型与注意力机制
时变因子载荷：允许因子暴露随宏观状态变化：


ri,t+1=g(xi,t,zt)Tft+1+ϵi,t+1r_{i,t+1} = g(x_{i,t}, z_t)^T f_{t+1} + \epsilon_{i,t+1}ri,t+1​=g(xi,t​,zt​)Tft+1​+ϵi,t+1​
其中 ztz_tzt​ 为宏观状态变量（如 VIX、信用利差、期限结构斜率），g(⋅)g(\cdot)g(⋅) 由网络学习。


Transformer 与自注意力：


Transformer 架构（Vaswani et al., 2017）被应用于股票截面建模——每只股票视为一个 token，通过自注意力机制捕获股票间的相互关系：


Attention(Q,K,V)=softmax(QKTdk)V\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)VAttention(Q,K,V)=softmax(dk​​QKT​)V
这种方法的优势在于能建模股票间的非线性依赖（如行业链传导、竞争关系），而传统因子模型假设股票间的关系仅通过因子暴露体现。

Autoencoder 因子
Chen, Pelger & Zhu（2024）提出的 Conditional Autoencoder 模型直接从数据中学习因子：


编码器（从特征到因子载荷）：


βi,t=Encoder(xi,t)\beta_{i,t} = \text{Encoder}(x_{i,t})βi,t​=Encoder(xi,t​)
因子收益（从截面收益中提取）：


ft=(βtTβt)−1βtTrtf_t = (\beta_t^T \beta_t)^{-1} \beta_t^T r_tft​=(βtT​βt​)−1βtT​rt​
解码器（重构收益）：


r^i,t=βi,tTft\hat{r}_{i,t} = \beta_{i,t}^T f_tr^i,t​=βi,tT​ft​
这种方法同时学习因子结构和因子收益，无需预先指定因子是什么。

过拟合防护
ML 模型的过拟合风险远高于线性模型。关键防护措施：


    

  1. 正则化：L1/L2 惩罚、Dropout、早停
    2. 

  2. 数据增强：向特征添加噪声、时间序列采样
    3. 

  3. 特征筛选：先用 LASSO 筛选再输入复杂模型
    4. 

  4. 交叉验证：Purged K-Fold 或 Walk-Forward
    5. 

  5. 集成：Bagging 降低方差，多模型平均
    6. 

  6. 模型容量控制：限制网络大小、树的深度
    7.

import shap

def explain_model_predictions(model, features, feature_names):
    """
    使用 SHAP 解释模型预测

    参数:
        model: 训练好的模型
        features: 待解释的特征矩阵
        feature_names: 特征名称
    返回:
        shap_values: SHAP 值矩阵
    """
    explainer = shap.TreeExplainer(model)
    shap_values = explainer.shap_values(features)

    importance = pd.Series(
        np.abs(shap_values).mean(axis=0),
        index=feature_names
    ).sort_values(ascending=False)

    return shap_values, importance

总结
ML 因子模型的层次选择
核心要点
    

  1. ML 因子模型的核心优势在于捕获非线性特征交互——而非简单地用复杂模型替代线性回归
    2. 

  2. GBM（LightGBM/XGBoost）是当前最佳性价比的方法——在大多数场景下接近神经网络的效果，且训练更快、更稳定
    3. 

  3. 过拟合控制是 ML 因子建模的第一要务——时间序列交叉验证、正则化、早停和集成缺一不可
    4. 

  4. 集成方法几乎总是优于单一模型——多模型平均是提升稳健性的最简单方法
    5. 

  5. 可解释性不是可选的——在投资决策中，理解模型预测的驱动因素与预测精度同等重要
    6. 

  6. ML 不替代金融知识——金融知识指导特征工程、模型选择和结果解读，ML 处理的是从特征到预测的映射优化
    7.
