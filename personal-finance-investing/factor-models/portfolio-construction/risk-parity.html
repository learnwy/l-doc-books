风险平价与层次风险平价

概述

风险平价（Risk Parity）是一种不依赖期望收益估计的组合构建方法，其核心理念是让每种资产（或每个因子）对组合总风险的贡献相等。这一方法由 Qian（2005, 2006）系统阐述，Bridgewater 的全天候策略（All Weather）是其最著名的实践案例。2016 年 López de Prado 提出的层次风险平价（Hierarchical Risk Parity, HRP）则进一步引入聚类和层次结构，解决了传统风险平价对协方差矩阵求逆的依赖。本文详解这两种方法的数学原理、实现细节和实践考量。

风险平价的数学基础

风险贡献（Risk Contribution）

给定 NNN 种资产，权重 www，协方差矩阵 Σ\SigmaΣ，组合风险为：

σp=wTΣw\sigma_p = \sqrt{w^T \Sigma w}σp​=wTΣw​

资产 iii 的边际风险贡献（Marginal Risk Contribution, MRC）：

MRCi=∂σp∂wi=(Σw)iσpMRC_i = \frac{\partial \sigma_p}{\partial w_i} = \frac{(\Sigma w)_i}{\sigma_p}MRCi​=∂wi​∂σp​​=σp​(Σw)i​​

资产 iii 的总风险贡献（Total Risk Contribution, TRC）：

TRCi=wi×MRCi=wi(Σw)iσpTRC_i = w_i \times MRC_i = \frac{w_i (\Sigma w)_i}{\sigma_p}TRCi​=wi​×MRCi​=σp​wi​(Σw)i​​

关键性质——Euler 分解定理：

σp=∑i=1NTRCi\sigma_p = \sum_{i=1}^{N} TRC_iσp​=i=1∑N​TRCi​

即组合风险可以精确分解为各资产的风险贡献之和。

风险平价条件

等风险贡献（Equal Risk Contribution, ERC）要求：

TRCi=TRCj,∀i,jTRC_i = TRC_j, \quad \forall i, jTRCi​=TRCj​,∀i,j

即：

wi(Σw)i=wj(Σw)j,∀i,jw_i (\Sigma w)_i = w_j (\Sigma w)_j, \quad \forall i, jwi​(Σw)i​=wj​(Σw)j​,∀i,j

等价于每种资产的风险贡献占比相等：

TRCiσp=1N,∀i\frac{TRC_i}{\sigma_p} = \frac{1}{N}, \quad \forall iσp​TRCi​​=N1​,∀i

特殊情况下的解析解

当资产不相关（Σ\SigmaΣ 为对角矩阵）时：

wiERC=1/σi∑j=1N1/σjw_i^{ERC} = \frac{1/\sigma_i}{\sum_{j=1}^{N} 1/\sigma_j}wiERC​=∑j=1N​1/σj​1/σi​​

即波动率倒数加权——高波动资产获得低权重，低波动资产获得高权重。

当所有资产等相关（ρij=ρ,∀i≠j\rho_{ij} = \rho, \forall i \neq jρij​=ρ,∀i=j）时：

ERC 解仍为波动率倒数加权，因为等相关性不改变相对风险贡献的排序。

风险平价的数值求解

优化方法

一般情况下，ERC 没有解析解，需要数值优化。常用的目标函数：

min⁡w∑i=1N∑j=1N(wi(Σw)i−wj(Σw)j)2\min_w \sum_{i=1}^{N} \sum_{j=1}^{N} \left(w_i (\Sigma w)_i - w_j (\Sigma w)_j\right)^2wmin​i=1∑N​j=1∑N​(wi​(Σw)i​−wj​(Σw)j​)2
s.t.wi≥0,∑iwi=1\text{s.t.} \quad w_i \geq 0, \quad \sum_i w_i = 1s.t.wi​≥0,i∑​wi​=1

等价的简化形式（Maillard, Roncalli & Teïlétche, 2010）：

min⁡w∑i=1N(wi(Σw)i−wTΣwN)2\min_w \sum_{i=1}^{N} \left(w_i (\Sigma w)_i - \frac{w^T\Sigma w}{N}\right)^2wmin​i=1∑N​(wi​(Σw)i​−NwTΣw​)2
import numpy as np
from scipy.optimize import minimize

def risk_parity(sigma, budget=None):
    """
    风险平价（等风险贡献）组合优化

    参数:
        sigma: N×N 协方差矩阵
        budget: N 维目标风险预算（None 为等预算）
    返回:
        weights: 最优权重
        risk_contributions: 各资产的风险贡献占比
    """
    N = sigma.shape[0]
    if budget is None:
        budget = np.ones(N) / N

    def objective(w):
        portfolio_vol = np.sqrt(w @ sigma @ w)
        marginal_risk = sigma @ w / portfolio_vol
        risk_contrib = w * marginal_risk
        risk_contrib_pct = risk_contrib / portfolio_vol

        target = budget * portfolio_vol
        return np.sum((risk_contrib - target) ** 2)

    constraints = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1}]
    bounds = [(0.001, 1)] * N
    w0 = np.ones(N) / N

    result = minimize(objective, w0, method='SLSQP',
                     bounds=bounds, constraints=constraints)

    w_opt = result.x
    portfolio_vol = np.sqrt(w_opt @ sigma @ w_opt)
    risk_contrib = w_opt * (sigma @ w_opt) / portfolio_vol
    risk_contrib_pct = risk_contrib / portfolio_vol

    return w_opt, risk_contrib_pct

Roncalli 的 CCD 算法

Roncalli（2013）提出了循环坐标下降（Cyclical Coordinate Descent, CCD）算法，比通用优化器更高效：

对每个资产 iii，固定其他权重，求解单变量方程：

wi(Σw)i=bi⋅wTΣw/∑jbjw_i (\Sigma w)_i = b_i \cdot w^T\Sigma w / \sum_j b_jwi​(Σw)i​=bi​⋅wTΣw/j∑​bj​

迭代至收敛。CCD 算法的优势在于每步有解析更新公式，收敛快且不需要梯度计算。

风险预算组合

从等预算到自定义预算

风险平价是风险预算（Risk Budgeting）的特例。一般的风险预算问题允许自定义风险贡献：

TRCiσp=bi,∑ibi=1\frac{TRC_i}{\sigma_p} = b_i, \quad \sum_i b_i = 1σp​TRCi​​=bi​,i∑​bi​=1

其中 bib_ibi​ 为目标风险预算。例如：

策略 风险预算设置 动机
等风险贡献 bi=1/Nb_i = 1/Nbi​=1/N 最大分散化
Alpha 加权 bi∝Alphaib_i \propto \text{Alpha}_ibi​∝Alphai​ 给高 Alpha 资产更多风险预算
Sharpe 加权 bi∝SRib_i \propto \text{SR}_ibi​∝SRi​ 给高效率资产更多风险预算
逆波动率 等价于波动率倒数权重 简单近似

因子风险平价

在因子投资框架下，风险平价可以在因子层面实施：

wTXk×(ΣFXkTw)σp=bk,∀k\frac{w^T X_k \times (\Sigma_F X_k^T w)}{\sigma_p} = b_k, \quad \forall kσp​wTXk​×(ΣF​XkT​w)​=bk​,∀k

其中 XkX_kXk​ 是第 kkk 个因子的暴露向量。这确保了每个因子对组合风险的贡献相等，避免了组合被单一因子主导。

层次风险平价（HRP）

动机

传统风险平价需要对协方差矩阵求逆（或至少需要其特征结构），在以下场景中效果不佳：

  1. 资产数 NNN 大、样本期 TTT 短（N/TN/TN/T 高）
  2. 协方差矩阵接近奇异
  3. 存在共线性强的资产组（如同行业股票）

López de Prado（2016）提出的 HRP 通过层次聚类来替代矩阵求逆，理论上对上述问题更稳健。

HRP 三步流程

Step 1: 层次聚类


将相关系数矩阵转化为距离矩阵：


dij=12(1−ρij)d_{ij} = \sqrt{\frac{1}{2}(1 - \rho_{ij})}dij​=21​(1−ρij​)​
使用层次聚类（如 Ward 方法）构建树状图（Dendrogram）。


Step 2: 准对角化（Quasi-Diagonalization）


按聚类结果重排协方差矩阵，使相似资产相邻——协方差矩阵呈"块状对角"结构。


Step 3: 递归二分


自上而下沿聚类树递归分配权重：


w1=1−V1V1+V2,w2=1−w1w_1 = 1 - \frac{V_1}{V_1 + V_2}, \quad w_2 = 1 - w_1w1​=1−V1​+V2​V1​​,w2​=1−w1​
其中 V1,V2V_1, V_2V1​,V2​ 分别为左右子树的逆方差。


import numpy as np
import pandas as pd
from scipy.cluster.hierarchy import linkage, leaves_list
from scipy.spatial.distance import squareform

def hierarchical_risk_parity(returns):
    """
    层次风险平价（HRP）

    参数:
        returns: T×N 收益矩阵（DataFrame）
    返回:
        weights: 资产权重（Series）
    """
    cov = returns.cov()
    corr = returns.corr()

    dist = np.sqrt(0.5 * (1 - corr))
    dist_condensed = squareform(dist.values, checks=False)
    link = linkage(dist_condensed, method='ward')

    sort_ix = leaves_list(link)
    sorted_assets = corr.index[sort_ix].tolist()

    weights = pd.Series(1.0, index=sorted_assets)
    cluster_items = [sorted_assets]

    while cluster_items:
        new_clusters = []
        for cluster in cluster_items:
            if len(cluster) <= 1:
                continue
            mid = len(cluster) // 2
            left = cluster[:mid]
            right = cluster[mid:]

            var_left = _cluster_variance(cov, left)
            var_right = _cluster_variance(cov, right)

            alpha = 1 - var_left / (var_left + var_right)

            weights[left] *= alpha
            weights[right] *= (1 - alpha)

            new_clusters.extend([left, right])

        cluster_items = [c for c in new_clusters if len(c) > 1]

    weights /= weights.sum()
    return weights


def _cluster_variance(cov, assets):
    """计算子簇的逆方差加权组合的方差"""
    sub_cov = cov.loc[assets, assets]
    ivp = 1 / np.diag(sub_cov)
    ivp /= ivp.sum()
    return ivp @ sub_cov.values @ ivp

HRP 的改进变体
HERC（Hierarchical Equal Risk Contribution）


Raffinot（2017）提出的 HERC 在 HRP 基础上增加了聚类内部的风险平价约束——先用层次聚类确定组结构，然后在组间和组内分别应用风险平价。


嵌套聚类优化（NCO）


López de Prado（2020）提出的 NCO 将 HRP 的聚类结构与 MVO 结合：


    

  1. 层次聚类确定资产组
    2. 

  2. 组内运行 MVO（小规模，估计稳定）
    3. 

  3. 组间运行 MVO（以组收益/风险为输入）
    4. 



这种"分治"策略有效降低了 MVO 的维度，同时保留了优化框架的灵活性。


风险平价在因子投资中的应用
因子风险平价策略
在多因子组合中，风险平价确保没有单一因子主导组合风险：


def factor_risk_parity(factor_returns, factor_cov=None):
    """
    因子层面的风险平价

    参数:
        factor_returns: T×K 因子收益矩阵
        factor_cov: K×K 因子协方差矩阵（None 则从数据估计）
    返回:
        factor_weights: K 维因子权重
    """
    if factor_cov is None:
        factor_cov = factor_returns.cov().values

    weights, risk_contrib = risk_parity(factor_cov)
    return weights, risk_contrib
与因子择时的结合
风险平价可以与因子择时信号结合——将风险预算与因子动量或因子估值信号挂钩：


bk(t)=f(sk,t)∑jf(sj,t)b_k(t) = \frac{f(s_{k,t})}{\sum_j f(s_{j,t})}bk​(t)=∑j​f(sj,t​)f(sk,t​)​
其中 sk,ts_{k,t}sk,t​ 为因子 kkk 在 ttt 期的择时信号。这样既保持了风险分散的底线，又允许根据因子状态动态调整暴露。

总结
核心要点
    

  1. 风险平价的核心理念是风险分散而非收益最大化——在不确定期望收益时，这是一种理性的保守策略
    2. 

  2. ERC 组合在等相关假设下等价于波动率倒数加权——但一般情况下需要数值求解
    3. 

  3. HRP 通过层次聚类避免了矩阵求逆——在高维场景下比传统方法更稳健
    4. 

  4. 风险预算是风险平价的推广——允许根据 Alpha 信号或因子择时动态调整风险分配
    5. 

  5. 因子层面的风险平价防止单因子主导——是多因子组合管理的重要工具
    6. 

  6. 实际应用需要考虑杠杆、交易成本和再平衡频率——纯理论的风险平价在实践中需要大量工程化调整
