组合约束与交易成本

概述

真实世界的投资组合管理远不止求解一个优化问题——来自监管、投资者、流动性和操作层面的各种约束条件，以及不可忽视的交易成本，共同塑造了最终可实施的组合。忽略这些约束和成本的回测往往严重高估策略收益，导致实盘表现远低于预期。本文系统介绍量化组合管理中的常见约束类型、交易成本建模方法，以及将约束和成本纳入优化框架的技术方案。

import numpy as np
from scipy.optimize import minimize

def constrained_portfolio_optimization(mu, sigma, factor_exposures,
                                        factor_bounds, weight_bounds,
                                        max_turnover=None, w_prev=None):
    """
    带约束的组合优化

    参数:
        mu: N 维期望收益
        sigma: N×N 协方差矩阵
        factor_exposures: N×K 因子暴露矩阵
        factor_bounds: K×2 因子暴露上下限
        weight_bounds: N×2 权重上下限
        max_turnover: 最大换手率
        w_prev: 上期权重（用于换手率约束）
    """
    N = len(mu)
    delta = 2.5

    def neg_utility(w):
        return -(w @ mu - delta / 2 * w @ sigma @ w)

    constraints = [
        {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
    ]

    K = factor_exposures.shape[1]
    for k in range(K):
        lb, ub = factor_bounds[k]
        constraints.append(
            {'type': 'ineq', 'fun': lambda w, k=k, lb=lb: w @ factor_exposures[:, k] - lb}
        )
        constraints.append(
            {'type': 'ineq', 'fun': lambda w, k=k, ub=ub: ub - w @ factor_exposures[:, k]}
        )

    if max_turnover is not None and w_prev is not None:
        constraints.append(
            {'type': 'ineq',
             'fun': lambda w: max_turnover - np.sum(np.abs(w - w_prev))}
        )

    bounds = [(weight_bounds[i, 0], weight_bounds[i, 1]) for i in range(N)]

    w0 = np.ones(N) / N
    result = minimize(neg_utility, w0, method='SLSQP',
                     bounds=bounds, constraints=constraints)

    return result.x

def estimate_transaction_cost(delta_weights, market_caps, adv, volatility,
                               model='sqrt', commission_bps=5):
    """
    估计交易成本

    参数:
        delta_weights: N 维权重变化（新 - 旧）
        market_caps: 组合在各股票上的名义金额
        adv: N 维日均成交额
        volatility: N 维日波动率
        model: 冲击模型 ('linear', 'sqrt')
        commission_bps: 佣金（基点）
    返回:
        total_cost: 总成本
        cost_breakdown: 各项成本明细
    """
    trade_values = np.abs(delta_weights) * market_caps.sum()

    commission = trade_values * commission_bps / 10000

    participation_rate = trade_values / adv

    if model == 'linear':
        impact = 0.1 * volatility * participation_rate
    elif model == 'sqrt':
        impact = 0.1 * volatility * np.sqrt(np.clip(participation_rate, 0, 1))

    impact_cost = trade_values * impact

    spread_cost = trade_values * 0.0005

    total_cost = commission.sum() + impact_cost.sum() + spread_cost.sum()

    return total_cost, {
        'commission': commission.sum(),
        'impact': impact_cost.sum(),
        'spread': spread_cost.sum()
    }

多期优化（Multi-Period Optimization）
单期优化忽略了未来再平衡的成本。多期优化考虑 HHH 期的总效用：


max⁡w1,…,wH∑t=1H[wtTμt−δ2wtTΣtwt−λTC(wt,wt−1)]\max_{w_1, \ldots, w_H} \sum_{t=1}^{H} \left[w_t^T\mu_t - \frac{\delta}{2}w_t^T\Sigma_t w_t - \lambda TC(w_t, w_{t-1})\right]w1​,…,wH​max​t=1∑H​[wtT​μt​−2δ​wtT​Σt​wt​−λTC(wt​,wt−1​)]
这是一个动态规划问题，精确求解计算量大，通常使用以下近似：


    

  1. 贪心法：每期做单期优化，但带换手率约束

  2. 滚动窗口：每期优化未来 3-5 期，但只执行第一期

实际组合不可能始终满仓——申赎、分红、保证金要求都会产生现金头寸。现金拖累（Cash Drag）对长期收益的影响：

CVXPY 示例
import cvxpy as cp
import numpy as np

def portfolio_optimize_cvxpy(mu, sigma, w_prev, tc_coef=0.003,
                              max_weight=0.05, max_turnover=0.3):
    """
    使用 CVXPY 求解带约束的组合优化（二次规划）

    参数:
        mu: N 维 Alpha 信号
        sigma: N×N 协方差矩阵
        w_prev: 上期权重
        tc_coef: 交易成本系数
        max_weight: 单股最大权重
        max_turnover: 最大单边换手率
    """
    N = len(mu)
    w = cp.Variable(N)
    delta = 2.5

    utility = w @ mu - (delta / 2) * cp.quad_form(w, sigma)
    tc = tc_coef * cp.norm(w - w_prev, 1)

    objective = cp.Maximize(utility - tc)

    constraints = [
        cp.sum(w) == 1,
        w >= 0,
        w <= max_weight,
        cp.norm(w - w_prev, 1) <= max_turnover * 2,
    ]

    prob = cp.Problem(objective, constraints)
    prob.solve(solver=cp.ECOS)

    return w.value

总结
核心要点
    

  1. 约束不是优化的障碍，而是风险管理的手段——合理的约束防止极端持仓和意外风险暴露
    2. 

  2. 交易成本是量化策略的"无形税"——忽略成本的回测毫无参考价值
    3. 

  3. 非线性冲击成本意味着大额交易应分散执行——平方根法则是最小化冲击的基本原则
    4. 

  4. 成本感知优化将交易成本纳入目标函数——比事后扣除更优，因为优化器会自动权衡信号强度与交易成本
    5. 

  5. 多期优化考虑了再平衡的动态效应——但复杂度高，实践中常用滚动窗口近似
    6. 

  6. CVXPY 等凸优化工具是量化组合管理的工业标准——将约束自然地嵌入优化问题
    7.
