均值方差优化与改进

概述

均值方差优化（Mean-Variance Optimization, MVO）是 Markowitz（1952）提出的现代投资组合理论的核心工具，也是将因子信号转化为投资组合的标准方法。MVO 通过最大化预期收益与风险的权衡来确定最优资产权重。然而，经典 MVO 在实际应用中面临严重的"估计误差放大"问题——对输入参数（期望收益、协方差矩阵）的微小估计误差会导致极端且不稳定的权重。本文系统介绍 MVO 的数学框架及其各种改进方案，涵盖收缩估计、正则化、贝叶斯方法和 Black-Litterman 模型。

import numpy as np
from scipy.optimize import minimize

def mean_variance_optimize(mu, sigma, delta=2.5, long_only=False):
    """
    经典均值方差优化

    参数:
        mu: N 维期望收益向量
        sigma: N×N 协方差矩阵
        delta: 风险厌恶系数
        long_only: 是否限制做多
    返回:
        weights: 最优权重向量
    """
    N = len(mu)

    def neg_utility(w):
        return -(w @ mu - delta / 2 * w @ sigma @ w)

    constraints = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1}]

    if long_only:
        bounds = [(0, 1)] * N
    else:
        bounds = [(-1, 1)] * N

    w0 = np.ones(N) / N
    result = minimize(neg_utility, w0, method='SLSQP',
                     bounds=bounds, constraints=constraints)

    return result.x

MVO 的问题：估计误差放大

Michaud 的 "Error Maximization" 论点

Michaud（1989）将 MVO 称为"误差最大化器"（Error Maximizer），因为：

  1. MVO 将最大权重分配给期望收益被高估、方差被低估的资产
  2. 将最小（负）权重分配给期望收益被低估、方差被高估的资产
  3. 优化过程系统性地放大输入参数的估计误差

敏感性分析

MVO 对期望收益估计的敏感度远高于对协方差矩阵的敏感度。Chopra & Ziemba（1993）发现：

参数 误差对组合效用的影响
期望收益 μ\muμ 影响最大（~11×方差误差的影响）
方差 σ2\sigma^2σ2 中等影响（~2×协方差误差的影响）
协方差 影响最小

这一发现有深刻的实践含义——投资于改善期望收益估计的回报远高于改善协方差估计。

高维场景下的退化

当 N>TN > TN>T（资产数超过时间期数）时，样本协方差矩阵 Σ^\hat{\Sigma}Σ^ 奇异，Σ−1\Sigma^{-1}Σ−1 不存在。即使 N<TN < TN<T，当 N/TN/TN/T 较大时，Σ^\hat{\Sigma}Σ^ 的最大特征值被高估、最小特征值被低估，导致 Σ^−1\hat{\Sigma}^{-1}Σ^−1 严重不稳定。

协方差矩阵估计的改进
Ledoit-Wolf 收缩（2004）
Ledoit & Wolf 提出将样本协方差矩阵向结构化目标（如对角矩阵或单因子模型）收缩：


Σ^shrink=(1−α)Σ^sample+αΣ^target\hat{\Sigma}_{shrink} = (1 - \alpha) \hat{\Sigma}_{sample} + \alpha \hat{\Sigma}_{target}Σ^shrink​=(1−α)Σ^sample​+αΣ^target​
其中 α∈[0,1]\alpha \in [0, 1]α∈[0,1] 为最优收缩强度，可通过分析公式计算（无需交叉验证）。

from sklearn.covariance import LedoitWolf

def shrinkage_covariance(returns):
    """
    Ledoit-Wolf 收缩协方差矩阵估计

    参数:
        returns: T×N 收益矩阵
    返回:
        sigma_shrunk: 收缩后的协方差矩阵
        shrinkage: 最优收缩系数
    """
    lw = LedoitWolf().fit(returns)
    return lw.covariance_, lw.shrinkage_
因子模型协方差
使用因子模型估计协方差矩阵可以大幅降低参数估计量：


Σ=BΣFBT+D\Sigma = B \Sigma_F B^T + DΣ=BΣF​BT+D
其中 BBB 是 N×KN \times KN×K 的因子载荷矩阵，ΣF\Sigma_FΣF​ 是 K×KK \times KK×K 的因子协方差矩阵，DDD 是 N×NN \times NN×N 的对角特异风险矩阵。


参数量从 N(N+1)/2N(N+1)/2N(N+1)/2（样本协方差）降至 NK+K(K+1)/2+NNK + K(K+1)/2 + NNK+K(K+1)/2+N（因子模型），当 K≪NK \ll NK≪N 时效果显著。


期望收益估计的改进
Black-Litterman 模型（1992）
Black & Litterman 模型巧妙地解决了期望收益估计问题，其核心思想是：


    

  1. 先验：从市场均衡出发，推导隐含期望收益（市场组合 = 最优组合）
    2. 

  2. 观点：投资者的主动观点（如"A 股将跑赢 B 股 2%"）
    3. 

  3. 后验：贝叶斯更新，将先验与观点融合
    4. 



隐含均衡收益：


Π=δΣwmkt\Pi = \delta \Sigma w_{mkt}Π=δΣwmkt​
后验期望收益：


μBL=[(τΣ)−1+PTΩ−1P]−1[(τΣ)−1Π+PTΩ−1Q]\mu_{BL} = [(\tau\Sigma)^{-1} + P^T\Omega^{-1}P]^{-1}[(\tau\Sigma)^{-1}\Pi + P^T\Omega^{-1}Q]μBL​=[(τΣ)−1+PTΩ−1P]−1[(τΣ)−1Π+PTΩ−1Q]
其中：


    

  • τ\tauτ 为不确定性标度参数（通常 0.01-0.05）
    • 

  • PPP 为观点矩阵，QQQ 为观点收益向量
    • 

  • Ω\OmegaΩ 为观点不确定性矩阵
    • 



def black_litterman(sigma, w_mkt, P, Q, omega=None, delta=2.5, tau=0.025):
    """
    Black-Litterman 模型

    参数:
        sigma: N×N 协方差矩阵
        w_mkt: N 维市场权重（如市值权重）
        P: K×N 观点矩阵
        Q: K 维观点收益向量
        omega: K×K 观点不确定性矩阵
        delta: 风险厌恶系数
        tau: 不确定性参数
    返回:
        mu_bl: 后验期望收益
        sigma_bl: 后验协方差矩阵
    """
    pi = delta * sigma @ w_mkt

    if omega is None:
        omega = np.diag(np.diag(P @ (tau * sigma) @ P.T))

    tau_sigma_inv = np.linalg.inv(tau * sigma)
    pt_omega_inv = P.T @ np.linalg.inv(omega)

    sigma_bl_inv = tau_sigma_inv + pt_omega_inv @ P
    sigma_bl = np.linalg.inv(sigma_bl_inv)

    mu_bl = sigma_bl @ (tau_sigma_inv @ pi + pt_omega_inv @ Q)

    return mu_bl, sigma_bl + sigma
因子信号作为 Black-Litterman 观点
在量化投资中，因子信号可以自然地转化为 BL 观点：


    

  • 因子 Alpha 模型预测各股票的超额收益 → 作为观点向量 QQQ
    • 

  • Alpha 模型的置信度（如 IC） → 决定 Ω\OmegaΩ 的对角元素
    • 

  • 相对观点（如"高 B/M 股票将跑赢低 B/M 股票 3%/年"）→ 构建 PPP 矩阵
    • 



这样 BL 框架自然地将因子信号与市场均衡融合，避免了直接使用因子 Alpha 作为期望收益的极端权重问题。

Michaud 重采样（Resampled Efficiency）
Michaud（1998）提出通过 Bootstrap 重采样来量化 MVO 的不确定性：


    

  1. 从原始数据中 Bootstrap 采样得到 BBB 组 (μ^b,Σ^b)(\hat{\mu}_b, \hat{\Sigma}_b)(μ^​b​,Σ^b​)
    2. 

  2. 对每组参数运行 MVO 得到 wb∗w_b^*wb∗​
    3. 

  3. 最终权重为所有 Bootstrap 权重的平均值
    4. 



wresample∗=1B∑b=1Bwb∗w_{resample}^* = \frac{1}{B}\sum_{b=1}^{B} w_b^*wresample∗​=B1​b=1∑B​wb∗​
这种方法有效地平滑了极端权重，但被批评为理论基础薄弱（平均的有效前沿本身未必有效）。


最大多样化组合
Choueifaty 的 Most Diversified Portfolio
Choueifaty & Coignard（2008）提出最大化多样化比率（Diversification Ratio）：


DR(w)=wTσwTΣw=∑iwiσiσpDR(w) = \frac{w^T \sigma}{\sqrt{w^T\Sigma w}} = \frac{\sum_i w_i \sigma_i}{\sigma_p}DR(w)=wTΣw​wTσ​=σp​∑i​wi​σi​​
分子是加权平均个股波动率，分母是组合波动率。当相关性 < 1 时，分散化使分母 < 分子，DR > 1。最大化 DR 意味着最大程度利用分散化效应。


最小方差组合
Global Minimum Variance（GMV）组合完全不使用期望收益估计：


wGMV=Σ−111TΣ−11w_{GMV} = \frac{\Sigma^{-1}\mathbf{1}}{\mathbf{1}^T\Sigma^{-1}\mathbf{1}}wGMV​=1TΣ−11Σ−11​
实证研究发现 GMV 组合的样本外表现往往优于需要估计 μ\muμ 的 MVO，因为避免了期望收益估计误差的放大效应。DeMiguel, Garlappi & Uppal（2009）发现等权组合 1/N1/N1/N 在样本外 Sharpe 上也能与复杂优化方法持平。

总结
方法选择指南
核心要点
    

  1. 经典 MVO 是理论最优但实践脆弱的方法——估计误差放大使得极端权重频繁出现
    2. 

  2. 协方差矩阵改进（收缩、因子模型）是最有效的技术手段——降低 N/TN/TN/T 问题的影响
    3. 

  3. Black-Litterman 模型优雅地融合了市场均衡与主动观点——因子 Alpha 信号可以自然地嵌入 BL 框架
    4. 

  4. 不使用期望收益的方法（GMV, 1/N, 风险平价）在样本外表现出人意料地好——这反映了期望收益估计的困难程度
    5. 

  5. 正则化和约束是防止过拟合的必要手段——L1L_1L1​/L2L_2L2​ 惩罚、权重上下限、换手率约束各有所长
    6. 

  6. 因子投资场景下的优化应以因子暴露为目标——而非直接优化个股权重
    7.
