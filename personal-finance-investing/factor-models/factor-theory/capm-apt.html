CAPM 与套利定价理论

概述

资本资产定价模型（Capital Asset Pricing Model, CAPM）和套利定价理论（Arbitrage Pricing Theory, APT）是现代金融学的两大定价基石。CAPM 由 Sharpe（1964）、Lintner（1965）和 Mossin（1966）在 Markowitz 均值方差框架之上独立推导而来，以单一市场因子解释资产预期收益；APT 由 Ross（1976）提出，放松了 CAPM 的诸多假设，允许多个系统性因子共同驱动资产收益。这两套理论为后续所有多因子模型奠定了逻辑起点。

从 Markowitz 到 CAPM

均值方差框架回顾

Markowitz（1952）的核心洞见在于：投资者关心的不仅是期望收益 E[R]E[R]E[R]，还有收益的波动性 σ(R)\sigma(R)σ(R)。给定 NNN 种资产，组合的期望收益和方差为：

E[Rp]=∑i=1NwiE[Ri]E[R_p] = \sum_{i=1}^{N} w_i E[R_i]E[Rp​]=i=1∑N​wi​E[Ri​]
σ2(Rp)=∑i=1N∑j=1NwiwjCov(Ri,Rj)\sigma^2(R_p) = \sum_{i=1}^{N}\sum_{j=1}^{N} w_i w_j \text{Cov}(R_i, R_j)σ2(Rp​)=i=1∑N​j=1∑N​wi​wj​Cov(Ri​,Rj​)

通过求解约束优化问题，可以得到有效前沿（Efficient Frontier）——在给定风险水平下期望收益最大的组合集合。

CAPM 的推导逻辑

CAPM 在均值方差框架之上增加了关键假设：

假设编号 内容 现实约束
A1 投资者是均值方差优化者 忽略高阶矩（偏度、峰度）
A2 存在无风险资产，可自由借贷 借贷利率不等
A3 同质预期（Homogeneous Expectations） 投资者信息不对称
A4 无交易成本、无税 现实中摩擦显著
A5 所有资产可分割、可交易 非上市资产、人力资本

在这些假设下，所有投资者持有相同的切线组合（Tangency Portfolio），该组合就是市场组合（Market Portfolio）。由此推导出 CAPM 核心方程：

E[Ri]−Rf=βi(E[Rm]−Rf)E[R_i] - R_f = \beta_i (E[R_m] - R_f)E[Ri​]−Rf​=βi​(E[Rm​]−Rf​)

其中：

  • RfR_fRf​ 为无风险利率
  • E[Rm]−RfE[R_m] - R_fE[Rm​]−Rf​ 为市场风险溢价（Equity Risk Premium）
  • βi=Cov(Ri,Rm)Var(Rm)\beta_i = \frac{\text{Cov}(R_i, R_m)}{\text{Var}(R_m)}βi​=Var(Rm​)Cov(Ri​,Rm​)​ 衡量资产 iii 对市场风险的敏感度

Beta 的经济含义

Beta 捕获的是系统性风险——不可通过分散化消除的那部分风险。CAPM 的核心预言是：

  1. 只有系统性风险被定价：特异性风险（Idiosyncratic Risk）不获得补偿
  2. 证券市场线（SML）为线性：E[Ri]E[R_i]E[Ri​] 与 βi\beta_iβi​ 呈线性关系
  3. 市场组合有效：市场组合位于有效前沿之上
CAPM 的实证检验与困境
早期实证支持
Black, Jensen & Scholes（1972）通过时间序列回归验证了 Beta 与收益的正相关关系，但斜率低于理论预测——低 Beta 股票的收益高于 CAPM 预测，高 Beta 股票则低于预测，形成所谓的"Beta 异常"（Beta Anomaly）。


Roll 批判
Roll（1977）指出 CAPM 本质上不可检验，因为：


    

  1. 真实市场组合不可观测（应包含所有资产：股票、债券、房地产、人力资本等）
    2. 

  2. 任何对市场组合的代理（如 S&P 500）若本身是均值方差有效的，则 CAPM 必然成立
    3. 

  3. 若代理不是有效的，检验结果与 CAPM 真实有效性无关
    4. 



这意味着 CAPM 的实证"失败"可能仅仅是市场代理选择不当的结果。


Fama-MacBeth 回归
Fama & MacBeth（1973）提出了资产定价的标准截面检验框架，至今仍是因子检验的黄金标准：


第一步：时间序列回归（估计 Beta）


Ri,t−Rf,t=αi+βi(Rm,t−Rf,t)+ϵi,tR_{i,t} - R_{f,t} = \alpha_i + \beta_i (R_{m,t} - R_{f,t}) + \epsilon_{i,t}Ri,t​−Rf,t​=αi​+βi​(Rm,t​−Rf,t​)+ϵi,t​
第二步：截面回归（检验定价关系）


Ri,t−Rf,t=γ0,t+γ1,tβ^i+ηi,tR_{i,t} - R_{f,t} = \gamma_{0,t} + \gamma_{1,t} \hat{\beta}_i + \eta_{i,t}Ri,t​−Rf,t​=γ0,t​+γ1,t​β^​i​+ηi,t​
第三步：对 γ\gammaγ 序列做时间序列检验


γˉ1=1T∑t=1Tγ1,t,t-stat=γˉ1SE(γ1,t)\bar{\gamma}_1 = \frac{1}{T}\sum_{t=1}^{T}\gamma_{1,t}, \quad t\text{-stat} = \frac{\bar{\gamma}_1}{\text{SE}(\gamma_{1,t})}γˉ​1​=T1​t=1∑T​γ1,t​,t-stat=SE(γ1,t​)γˉ​1​​
import numpy as np
import pandas as pd
from scipy import stats

def fama_macbeth_regression(returns, factor_betas):
    """
    Fama-MacBeth 两步截面回归

    参数:
        returns: T×N 收益矩阵
        factor_betas: N×K 因子载荷矩阵
    返回:
        gamma_mean: K 维因子风险溢价估计
        t_stats: K 维 t 统计量
    """
    T, N = returns.shape
    K = factor_betas.shape[1]
    gammas = np.zeros((T, K + 1))

    for t in range(T):
        X = np.column_stack([np.ones(N), factor_betas])
        y = returns[t, :]
        beta_hat = np.linalg.lstsq(X, y, rcond=None)[0]
        gammas[t, :] = beta_hat

    gamma_mean = gammas.mean(axis=0)
    gamma_se = gammas.std(axis=0, ddof=1) / np.sqrt(T)
    t_stats = gamma_mean / gamma_se

    return gamma_mean[1:], t_stats[1:]
套利定价理论（APT）
理论动机
Ross（1976）提出 APT 的动机是为了放松 CAPM 过于严格的假设。APT 不要求投资者是均值方差优化者，不要求市场组合可观测，仅依赖两个核心假设：


    

  1. 因子模型假设：资产收益由有限个共同因子线性驱动
    2. 

  2. 无套利假设：不存在无风险的套利机会
    3. 



因子模型结构
APT 假设资产收益满足以下线性因子模型：


Ri=E[Ri]+bi1F1+bi2F2+⋯+biKFK+ϵiR_i = E[R_i] + b_{i1}F_1 + b_{i2}F_2 + \cdots + b_{iK}F_K + \epsilon_iRi​=E[Ri​]+bi1​F1​+bi2​F2​+⋯+biK​FK​+ϵi​
其中：


    

  • FkF_kFk​ 是第 kkk 个共同因子的实现值（零均值）
    • 

  • bikb_{ik}bik​ 是资产 iii 对因子 kkk 的敏感度（Factor Loading）
    • 

  • ϵi\epsilon_iϵi​ 是特异性收益，满足 E[ϵi]=0E[\epsilon_i] = 0E[ϵi​]=0 且与所有因子及其他资产的特异性收益不相关
    • 



APT 定价方程推导
在无套利条件下，对于充分分散化的组合（特异性风险趋近于零），有：


E[Ri]=Rf+bi1λ1+bi2λ2+⋯+biKλKE[R_i] = R_f + b_{i1}\lambda_1 + b_{i2}\lambda_2 + \cdots + b_{iK}\lambda_KE[Ri​]=Rf​+bi1​λ1​+bi2​λ2​+⋯+biK​λK​
其中 λk\lambda_kλk​ 是因子 kkk 的风险溢价——持有单位因子暴露所获得的超额收益。

APT 的局限
APT 的最大缺陷是不指定因子是什么。理论只说"存在 K 个因子"，但不告诉我们 K 是多少，也不告诉我们因子的经济含义。这一缺陷催生了两个实证研究方向：


    

  1. 统计因子提取：使用主成分分析（PCA）或因子分析从收益协方差矩阵中提取潜在因子
    2. 

  2. 经济因子指定：基于经济理论预先指定因子，如 Chen, Roll & Ross（1986）提出的宏观经济因子
    3. 



从 APT 到现代多因子模型
宏观因子模型
Chen, Roll & Ross（1986）将以下宏观经济变量作为 APT 因子：


    

  • 工业产出增长率变动
    • 

  • 预期通胀变动
    • 

  • 非预期通胀
    • 

  • 信用利差变动（Baa-Aaa）
    • 

  • 期限利差变动（长期国债-短期国债）
    • 



这一工作开启了从"统计因子"到"经济因子"的转向，但宏观因子的解释力有限（R2R^2R2 通常 < 30%），且数据频率低（月度/季度），难以捕捉股票截面收益的精细差异。


特征因子模型的崛起
Fama & French（1993）的三因子模型开启了特征因子的时代——不再从宏观经济变量出发，而是直接从股票特征（Size、Book-to-Market）构建因子组合。这一范式转变有两个深刻含义：


    

  1. 因子不再是"发现的"（通过统计方法从协方差矩阵中提取），而是"构建的"（基于可观测股票特征排序分组）
    2. 

  2. 因子的经济解释从"风险补偿"扩展到"行为偏差"和"制度摩擦"
    3. 



ICAPM 与条件资产定价
跨期 CAPM
Merton（1973）提出的跨期资本资产定价模型（ICAPM）在连续时间框架下推导出多因子定价方程。与 APT 不同，ICAPM 为额外因子提供了经济学解释——这些因子代表投资机会集变动的对冲需求：


E[Ri]−Rf=βi,mλm+∑k=1Kβi,kλkE[R_i] - R_f = \beta_{i,m}\lambda_m + \sum_{k=1}^{K}\beta_{i,k}\lambda_kE[Ri​]−Rf​=βi,m​λm​+k=1∑K​βi,k​λk​
其中 βi,k\beta_{i,k}βi,k​ 衡量资产 iii 与第 kkk 个状态变量的协方差，λk\lambda_kλk​ 是该状态变量的风险溢价。投资者不仅关心当期财富，还关心未来投资机会的变化，因此愿意为能够对冲这种变化的资产支付溢价。


条件 CAPM
条件 CAPM 允许 Beta 和市场风险溢价随时间变化：


Et[Ri,t+1]−Rf,t=βi,t⋅Et[Rm,t+1−Rf,t]E_t[R_{i,t+1}] - R_{f,t} = \beta_{i,t} \cdot E_t[R_{m,t+1} - R_{f,t}]Et​[Ri,t+1​]−Rf,t​=βi,t​⋅Et​[Rm,t+1​−Rf,t​]
Jagannathan & Wang（1996）发现条件 CAPM 使用人力资本代理和时变 Beta 后，能解释约 50% 的截面收益差异——远高于无条件 CAPM 的解释力。但这也引发了争论：条件模型的灵活性是否过高，以至于失去了可证伪性？

核心要点
    

  1. CAPM 是起点而非终点：其简洁性使其至今仍是教学和沟通的标准语言，但单因子框架无法解释丰富的截面收益差异
    2. 

  2. APT 提供了理论容器：多因子定价的合理性无需依赖 CAPM 的严格假设，但因子选择问题转移给了实证研究
    3. 

  3. 从理论到实践的桥梁是因子构建：无论理论基础是风险补偿、行为偏差还是制度摩擦，关键在于因子能否在样本外持续产生超额收益
    4. 

  4. Fama-MacBeth 回归是因子检验的标准方法，贯穿整个量化因子研究的流程
    5.
