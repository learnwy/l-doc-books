Fama-French 多因子模型演进

概述

Fama-French 系列模型是实证资产定价的里程碑，将因子投资从理论概念推向可操作的量化框架。Eugene Fama 和 Kenneth French 从 1992 年的截面研究起步，先后提出三因子模型（1993）、四因子扩展（Carhart, 1997）和五因子模型（2015），每一步都回应了前一版本遗留的定价异象。这些模型不仅定义了学术界的研究范式，也直接塑造了全球量化基金的因子投资实践。

前奏：1992 截面研究

Fama-French（1992）的关键发现

Fama & French（1992）对 NYSE、AMEX 和 NASDAQ 全部非金融股票进行了系统的截面分析，核心发现如下：

  1. Beta 不定价：控制市值后，Beta 与预期收益之间没有显著关系
  2. 市值效应显著：小市值股票的平均收益系统性高于大市值股票
  3. 价值效应显著：高账面市值比（Book-to-Market, B/M）股票的收益高于低 B/M 股票

这些发现直接挑战了 CAPM 的核心预言——仅 Beta 就足以解释截面收益差异。

Banz（1981）与 Size Effect

市值效应的学术发现可追溯至 Banz（1981），他发现 NYSE 最小十分位股票的年化超额收益比最大十分位高约 19.8%。这一效应的经济解释一直存在争议：

解释类别 具体机制 支持证据
风险补偿 小公司面临更高的财务困境风险 Berk（1995）: 市值反映折现率
流动性溢价 小公司交易成本更高 Amihud（2002）: 流动性因子
信息不对称 小公司信息披露不足 分析师覆盖度与收益负相关
统计幻觉 数据窥探 + 微型股偏差 1980 年代后效应减弱

三因子模型（1993）

模型结构

Fama & French（1993）提出的三因子模型：

Ri−Rf=αi+βiMKT(Rm−Rf)+βiSMB⋅SMB+βiHML⋅HML+ϵiR_i - R_f = \alpha_i + \beta_i^{MKT}(R_m - R_f) + \beta_i^{SMB} \cdot SMB + \beta_i^{HML} \cdot HML + \epsilon_iRi​−Rf​=αi​+βiMKT​(Rm​−Rf​)+βiSMB​⋅SMB+βiHML​⋅HML+ϵi​

因子构建方法（2×3 排序法）：

每年 6 月末，按市值中位数将股票分为 Small（S）和 Big（B）两组，同时按 B/M 的 30%/70% 分位数分为 Value（H）、Neutral（N）和 Growth（L）三组，交叉得到 6 个组合：

SMB=13(SH+SN+SL)−13(BH+BN+BL)SMB = \frac{1}{3}(SH + SN + SL) - \frac{1}{3}(BH + BN + BL)SMB=31​(SH+SN+SL)−31​(BH+BN+BL)
HML=12(SH+BH)−12(SL+BL)HML = \frac{1}{2}(SH + BH) - \frac{1}{2}(SL + BL)HML=21​(SH+BH)−21​(SL+BL)
Python 实现因子构建
import pandas as pd
import numpy as np

def construct_ff3_factors(stock_data, date_col='date', ret_col='ret',
                          mktcap_col='mktcap', bm_col='bm'):
    """
    构建 Fama-French 三因子（SMB, HML）

    参数:
        stock_data: 包含日期、收益、市值、B/M 的股票面板数据
    返回:
        factors: 日期索引的因子收益 DataFrame
    """
    factors_list = []

    for date, group in stock_data.groupby(date_col):
        n = len(group)
        if n < 20:
            continue

        size_median = group[mktcap_col].median()
        bm_30 = group[bm_col].quantile(0.3)
        bm_70 = group[bm_col].quantile(0.7)

        group['size_group'] = np.where(group[mktcap_col] <= size_median, 'S', 'B')
        group['bm_group'] = np.where(group[bm_col] <= bm_30, 'L',
                            np.where(group[bm_col] >= bm_70, 'H', 'N'))

        portfolios = group.groupby(['size_group', 'bm_group'])[ret_col].mean()

        smb = (portfolios.get(('S','H'), 0) + portfolios.get(('S','N'), 0) +
               portfolios.get(('S','L'), 0)) / 3 - \
              (portfolios.get(('B','H'), 0) + portfolios.get(('B','N'), 0) +
               portfolios.get(('B','L'), 0)) / 3

        hml = (portfolios.get(('S','H'), 0) + portfolios.get(('B','H'), 0)) / 2 - \
              (portfolios.get(('S','L'), 0) + portfolios.get(('B','L'), 0)) / 2

        factors_list.append({date_col: date, 'SMB': smb, 'HML': hml})

    return pd.DataFrame(factors_list).set_index(date_col)
三因子模型的实证表现
Fama & French（1993）原始论文中，三因子模型能解释 25 个 Size-B/M 组合约 90% 的截面收益差异（R2R^2R2 显著高于 CAPM），且大多数组合的截距项 α\alphaα 在统计上不显著。


但仍有两类异象无法解释：


    

  1. 动量效应（Jegadeesh & Titman, 1993）：过去 3-12 个月表现好的股票在未来 3-12 个月继续表现好
    2. 

  2. 短期反转效应：过去 1 个月表现最差的股票在下一个月反弹
    3. 



Carhart 四因子模型（1997）
动量因子的加入
Carhart（1997）在三因子基础上加入了动量因子 UMD（Up Minus Down）：


Ri−Rf=αi+βiMKTMKT+βiSMBSMB+βiHMLHML+βiUMDUMD+ϵiR_i - R_f = \alpha_i + \beta_i^{MKT} MKT + \beta_i^{SMB} SMB + \beta_i^{HML} HML + \beta_i^{UMD} UMD + \epsilon_iRi​−Rf​=αi​+βiMKT​MKT+βiSMB​SMB+βiHML​HML+βiUMD​UMD+ϵi​
UMD 构建方法：


每月末按过去 2-12 个月累计收益（跳过最近 1 个月）排序，做多前 30% 赢家组合，做空后 30% 输家组合：


UMD=RWinners−RLosersUMD = R_{Winners} - R_{Losers}UMD=RWinners​−RLosers​
跳过最近 1 个月是为了排除短期反转效应的干扰。

Daniel & Moskowitz（2016）记录了动量策略的"崩溃"现象：在市场急剧反转时，过去的输家股票猛涨而赢家股票暴跌，导致动量策略遭受巨额亏损。2009 年 3-5 月的动量崩溃损失超过前 10 年的累计收益。


五因子模型（2015）
新增因子的动机
Fama & French（2015）观察到三因子模型无法解释两类新异象：


    

  1. 盈利能力效应：高利润率公司的股票收益更高（Novy-Marx, 2013）
    2. 

  2. 投资效应：保守投资（低资产增长率）公司的收益更高（Titman, Wei & Xie, 2004）
    3. 



这两个效应可以从 Gordon 增长模型的变形中获得理论支持：


MtBt=∑τ=1∞Et[Yt+τ−ΔBt+τ](1+r)τ⋅Bt\frac{M_t}{B_t} = \frac{\sum_{\tau=1}^{\infty} E_t[Y_{t+\tau} - \Delta B_{t+\tau}]}{(1+r)^\tau \cdot B_t}Bt​Mt​​=(1+r)τ⋅Bt​∑τ=1∞​Et​[Yt+τ​−ΔBt+τ​]​
在 B/M 相同的情况下，预期盈利能力更高意味着更高的预期收益（rrr），而预期投资更激进则意味着更低的预期收益。


五因子模型结构
Ri−Rf=αi+biMKT+siSMB+hiHML+riRMW+ciCMA+ϵiR_i - R_f = \alpha_i + b_i MKT + s_i SMB + h_i HML + r_i RMW + c_i CMA + \epsilon_iRi​−Rf​=αi​+bi​MKT+si​SMB+hi​HML+ri​RMW+ci​CMA+ϵi​
新增因子：


    

  • RMW（Robust Minus Weak）：高盈利能力 - 低盈利能力，盈利能力用经营利润率（Operating Profitability = Revenue - COGS - SGA - Interest / Book Equity）衡量
    • 

  • CMA（Conservative Minus Aggressive）：低投资率 - 高投资率，投资率用总资产增长率衡量
    • 



2×3×3 排序法
五因子模型使用更复杂的排序方法。以 RMW 为例：


    

  1. 按市值中位数分为 Small/Big
    2. 

  2. 按盈利能力 30%/70% 分为 Robust/Neutral/Weak
    3. 

  3. 类似地按投资率分组构建 CMA
    4. 



RMW=12(SR+BR)−12(SW+BW)RMW = \frac{1}{2}(S_R + B_R) - \frac{1}{2}(S_W + B_W)RMW=21​(SR​+BR​)−21​(SW​+BW​)
CMA=12(SC+BC)−12(SA+BA)CMA = \frac{1}{2}(S_C + B_C) - \frac{1}{2}(S_A + B_A)CMA=21​(SC​+BC​)−21​(SA​+BA​)
HML 的冗余性争议
五因子模型的一个争议性发现是：加入 RMW 和 CMA 后，HML 的截距项变得不显著——即 HML 可以被其他四个因子解释。Fama & French 自己也承认"HML 在五因子模型中可能是冗余的"。但他们选择保留 HML，理由是：


    

  1. 历史延续性——大量实务和学术工作基于 HML
    2. 

  2. 国际市场中 HML 的冗余性并不一致
    3. 

  3. HML 在某些子样本和某些测试资产中仍有独立解释力
    4. 



六因子模型与后续扩展
Fama-French 六因子（2018）
Fama & French（2018）最终将动量因子纳入，形成六因子模型：


Ri−Rf=αi+biMKT+siSMB+hiHML+riRMW+ciCMA+miUMD+ϵiR_i - R_f = \alpha_i + b_i MKT + s_i SMB + h_i HML + r_i RMW + c_i CMA + m_i UMD + \epsilon_iRi​−Rf​=αi​+bi​MKT+si​SMB+hi​HML+ri​RMW+ci​CMA+mi​UMD+ϵi​
这实质上是对"五因子 + 动量"的官方认可。

因子在不同资产类别中的表现
Asness, Moskowitz & Pedersen（2013）发现 Value 和 Momentum 因子不仅存在于股票市场，还存在于债券、外汇、商品等多个资产类别，且跨资产的因子收益之间存在显著正相关。这一"无处不在"（Everywhere）的证据被视为因子定价的有力支持——不太可能所有市场同时存在相同方向的数据挖掘偏差。

核心要点
    

  1. Fama-French 模型是实证驱动的——每个因子的加入都回应了前一版本无法解释的异象，而非理论先验
    2. 

  2. 因子构建方法（2×3 排序）本身就是方法论创新——它将股票特征映射为可交易的因子模拟组合
    3. 

  3. 从三因子到六因子的演进，本质上是在"解释力"和"简洁性"之间不断权衡——每加一个因子都要证明其独立贡献
    4. 

  4. A 股市场的因子结构与美股显著不同，直接照搬 Fama-French 因子体系可能失效，需要结合本土市场特征调整
    5.
