订单簿动态与价格发现

概述

订单簿（Order Book）是现代电子市场的核心数据结构，记录了所有未成交的限价订单。订单簿的动态变化——订单的到达、取消、修改和成交——构成了价格发现过程的微观基础。理解订单簿动态不仅是市场微观结构理论的核心问题，也是量化交易策略（特别是做市和高频交易）的关键输入。

价格发现（Price Discovery）是指市场价格如何从分散的、异质的交易者信息中涌现的过程。在限价订单簿市场中，价格发现同时通过两个渠道进行：市价订单携带信息主动推动价格变化，限价订单通过报价更新被动反映交易者的估值。

订单簿模型
经验性模型
订单簿的统计特征


大量实证研究揭示了订单簿的以下普遍统计规律：


    

  1. 订单到达过程：限价订单和市价订单的到达间隔近似服从指数分布（修正后为 Hawkes 过程或自激点过程）
    

    2. 

  2. 订单大小分布：服从幂律分布 $P(V>v)∝v−α,α≈1.5P(V > v) \propto v^{-\alpha}, \quad \alpha \approx 1.5P(V>v)∝v−α,α≈1.5$
    

    3. 

  3. 订单簿深度分布：在最优价位附近深度较薄，距离最优价越远深度越大，呈现"V 形"或"勺形"分布
    

    4. 

  4. 限价订单存活时间：服从幂律分布，大部分订单在提交后很短时间内被取消
    

    5. 



import numpy as np
from scipy import stats

def analyze_order_book_shape(snapshots, n_levels=20):
    avg_bid_depth = np.zeros(n_levels)
    avg_ask_depth = np.zeros(n_levels)
    for snap in snapshots:
        for i in range(n_levels):
            avg_bid_depth[i] += snap['bid_qty'][i]
            avg_ask_depth[i] += snap['ask_qty'][i]
    avg_bid_depth /= len(snapshots)
    avg_ask_depth /= len(snapshots)
    return avg_bid_depth, avg_ask_depth
Zero-Intelligence 模型
Daniels, Farmer, Gillemot 和 Iori（2003）提出的零智能模型假设订单以恒定速率随机到达和取消：


    

  • 限价买单以速率 λ\lambdaλ 在价格 p<ap < ap<a 处到达（aaa 为当前最优卖价）
    • 

  • 限价卖单以速率 λ\lambdaλ 在价格 p>bp > bp>b 处到达（bbb 为当前最优买价）
    • 

  • 市价订单以速率 μ\muμ 到达
    • 

  • 限价订单以速率 δ\deltaδ 被取消
    • 



尽管不包含任何"智能"成分，这个模型能够复现订单簿的许多统计特征，包括价差的分布和深度的形状。均衡价差的近似公式为：


⟨S⟩∝μλ\langle S \rangle \propto \sqrt{\frac{\mu}{\lambda}}⟨S⟩∝λμ​​
Hawkes 过程模型
订单流的自激（Self-Exciting）特性可以用 Hawkes 过程建模。市场事件（如大额成交）会触发后续事件的密集到达（如限价订单补充深度），体现为正反馈效应。


单变量 Hawkes 过程的条件强度函数：


λ(t)=μ+∑ti<tαe−β(t−ti)\lambda(t) = \mu + \sum_{t_i < t} \alpha e^{-\beta(t - t_i)}λ(t)=μ+ti​<t∑​αe−β(t−ti​)
其中 μ\muμ 是基础到达率，α\alphaα 是激励强度，β\betaβ 是衰减速率。多变量 Hawkes 过程可以捕捉不同事件类型之间的交叉激励效应（如一笔大额买入触发卖方限价订单的补充）。


Bacry, Mastromatteo 和 Muzy（2015）使用多维 Hawkes 过程对订单簿事件建模，发现内核结构能够反映做市商的报价更新策略和信息扩散过程。

信息与价格
价格发现的核心问题：私有信息如何通过交易活动融入公共价格？


Kyle 模型
Kyle（1985）的经典模型是理解价格发现的基石。模型设定：


    

  • 一个知情交易者知道资产真实价值 vvv
    • 

  • 噪声交易者提交随机订单 u∼N(0,σu2)u \sim N(0, \sigma_u^2)u∼N(0,σu2​)
    • 

  • 做市商观察总订单流 y=x+uy = x + uy=x+u（xxx 为知情交易者的订单），设定价格
    • 



均衡解中，知情交易者的最优策略是线性的：


x=σuσv(v−p0)x = \frac{\sigma_u}{\sigma_v} (v - p_0)x=σv​σu​​(v−p0​)
做市商的定价规则：


p=p0+λ⋅yp = p_0 + \lambda \cdot yp=p0​+λ⋅y
其中 λ=σv2σu\lambda = \frac{\sigma_v}{2\sigma_u}λ=2σu​σv​​ 是Kyle's Lambda，衡量订单流对价格的永久性影响。λ\lambdaλ 越大，市场的信息不对称程度越高，流动性越低。


订单流毒性与 VPIN
Easley, López de Prado 和 O'Hara（2012）提出了 VPIN（Volume-Synchronized Probability of Informed Trading）指标，用于实时度量订单流的信息毒性：


VPIN=∑n=1N∣VnBuy−VnSell∣N×VbucketVPIN = \frac{\sum_{n=1}^{N} |V_n^{Buy} - V_n^{Sell}|}{N \times V_{bucket}}VPIN=N×Vbucket​∑n=1N​∣VnBuy​−VnSell​∣​
其中订单流被分割为等成交量的"桶"（Volume Bucket），VnBuyV_n^{Buy}VnBuy​ 和 VnSellV_n^{Sell}VnSell​ 分别为第 nnn 个桶中的买入和卖出量。


VPIN 在 2010 年"闪崩"事件前数小时显著上升，表明知情交易者提前在市场中积极交易，为闪崩提供了预警信号。

订单簿不平衡（Order Book Imbalance, OBI）是短期价格预测的强力信号：


OBI=QbidL1−QaskL1QbidL1+QaskL1OBI = \frac{Q_{bid}^{L1} - Q_{ask}^{L1}}{Q_{bid}^{L1} + Q_{ask}^{L1}}OBI=QbidL1​+QaskL1​QbidL1​−QaskL1​​

多层次不平衡指标将深度信息扩展到多个价位：


OBIk=∑i=1kQbidLi−∑i=1kQaskLi∑i=1kQbidLi+∑i=1kQaskLiOBI_k = \frac{\sum_{i=1}^{k} Q_{bid}^{Li} - \sum_{i=1}^{k} Q_{ask}^{Li}}{\sum_{i=1}^{k} Q_{bid}^{Li} + \sum_{i=1}^{k} Q_{ask}^{Li}}OBIk​=∑i=1k​QbidLi​+∑i=1k​QaskLi​∑i=1k​QbidLi​−∑i=1k​QaskLi​​
def compute_obi(bid_quantities, ask_quantities, levels=5):
    bid_sum = sum(bid_quantities[:levels])
    ask_sum = sum(ask_quantities[:levels])
    if bid_sum + ask_sum == 0:
        return 0.0
    return (bid_sum - ask_sum) / (bid_sum + ask_sum)
价格发现的经验度量
永久性价格影响与暂时性价格影响
交易对价格的影响可以分解为：


    

  • 永久性影响（Permanent Impact）：反映信息融入价格的部分，不会随时间消散
    • 

  • 暂时性影响（Temporary Impact）：反映流动性压力，随新订单到达而消散
    • 



Hasbrouck（1991）的向量自回归（VAR）模型将价格变化分解为：


Δpt=α+∑k=1Kakxt−k+∑k=1KbkΔpt−k+ϵt\Delta p_t = \alpha + \sum_{k=1}^{K} a_k x_{t-k} + \sum_{k=1}^{K} b_k \Delta p_{t-k} + \epsilon_tΔpt​=α+k=1∑K​ak​xt−k​+k=1∑K​bk​Δpt−k​+ϵt​
xt=γ+∑k=1Kckxt−k+∑k=1KdkΔpt−k+ηtx_t = \gamma + \sum_{k=1}^{K} c_k x_{t-k} + \sum_{k=1}^{K} d_k \Delta p_{t-k} + \eta_txt​=γ+k=1∑K​ck​xt−k​+k=1∑K​dk​Δpt−k​+ηt​
通过方差分解可以量化交易对价格永久性变化的贡献。


价格发现的速度
价格发现的效率可以通过信息融入速度来衡量。Chordia, Roll 和 Subrahmanyam（2005）发现：


    

  • 在美国市场，新信息在 5-30 分钟内基本完全融入价格
    • 

  • 大盘股的价格发现速度快于小盘股
    • 

  • 电子化和竞争加剧了价格发现的速度
    • 



逐笔交易的信息含量
每笔交易携带的信息量可以用以下指标衡量：


交易方向指标（Trade Sign）：Lee 和 Ready（1991）的算法通过比较成交价与最近的报价来判断交易是买方发起还是卖方发起：


    

  • 成交价 > 中间价 → 买方发起（Buy）
    • 

  • 成交价 < 中间价 → 卖方发起（Sell）
    • 

  • 成交价 = 中间价 → 使用 Tick Rule（与前一笔成交价比较）
    • 



高频价格发现
微观价格
传统的中间价在最小报价单位（Tick Size）较大时可能不够精确。微观价格（Microprice）利用订单簿不平衡信息进行加权：


Pmicro=Pask×QbidQbid+Qask+Pbid×QaskQbid+QaskP_{micro} = P_{ask} \times \frac{Q_{bid}}{Q_{bid} + Q_{ask}} + P_{bid} \times \frac{Q_{ask}}{Q_{bid} + Q_{ask}}Pmicro​=Pask​×Qbid​+Qask​Qbid​​+Pbid​×Qbid​+Qask​Qask​​
微观价格比中间价更接近真实的有效价格，在高频交易和做市策略中被广泛使用。

DeepLOB 模型结合了 CNN（提取订单簿横截面特征）和 LSTM（建模时间依赖），在多个市场的价格方向预测中表现出色，预测准确率在短期内（数秒）可达 60-70%。


import torch
import torch.nn as nn

class DeepLOBBlock(nn.Module):
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, (1, 2), stride=(1, 2))
        self.conv2 = nn.Conv2d(out_channels, out_channels, (4, 1), padding=(1, 0))
        self.conv3 = nn.Conv2d(out_channels, out_channels, (4, 1), padding=(1, 0))
        self.leaky_relu = nn.LeakyReLU(0.01)

    def forward(self, x):
        x = self.leaky_relu(self.conv1(x))
        x = self.leaky_relu(self.conv2(x))
        x = self.leaky_relu(self.conv3(x))
        return x

总结
订单簿动态是价格发现过程的微观基础。从零智能模型到 Hawkes 过程，从 Kyle Lambda 到深度学习预测，学术界和业界持续探索订单簿中蕴含的丰富信息。关键洞察包括：订单簿不平衡是短期价格预测的有力信号；订单流的自激特性反映了市场参与者之间的交互反馈；深度学习方法正在突破传统线性模型的预测边界。对量化交易者而言，深入理解订单簿动态是构建做市策略、执行算法和风险管理系统的基础。
