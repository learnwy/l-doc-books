买卖价差模型与信息不对称

概述

买卖价差（Bid-Ask Spread）是市场微观结构中最基本也最重要的概念之一。价差是流动性的直接度量，反映了交易的隐性成本。理解价差的成因和决定因素，是理解市场如何定价信息、如何补偿流动性供给者的关键。

学术界发展了三类主要的价差理论模型：存货模型关注做市商的风险管理，信息模型强调知情交易者与非知情交易者之间的信息博弈，订单处理成本模型考虑运营和合规成本。这些模型从不同角度解释了价差的来源，也为实证研究提供了可检验的预测。

价差的经济学含义

为什么存在价差？

在无摩擦的理想市场中，资产以单一的均衡价格交易，不存在价差。现实中价差存在的根本原因是流动性不是免费的：

价差与社会福利
价差并非纯粹的损耗。做市商通过价差获得补偿后，提供了宝贵的即时性（Immediacy）服务——允许交易者在任何时刻以已知价格执行交易。没有这种服务，交易者需要等待对手方自然到达，交易效率大幅降低。


存货模型
Garman 模型（1976）
Garman 的开创性工作首次形式化了做市商的存货管理问题。模型假设买卖订单以泊松过程到达：


    

  • 买入订单到达率 λb(Pa)\lambda_b(P_a)λb​(Pa​)：卖价越低，买入需求越高
    • 

  • 卖出订单到达率 λs(Pb)\lambda_s(P_b)λs​(Pb​)：买价越高，卖出供给越多
    • 



做市商面临破产约束：如果现金耗尽（持有过多库存）或库存耗尽（卖空过多），就无法继续做市。最优价差需要在吸引订单流和控制破产风险之间取得平衡。


Stoll 模型（1978）
Stoll 将做市商建模为一个风险厌恶的投资者，其最优价差取决于：


S∗=α⋅σ2⋅Q+β⋅CS^* = \alpha \cdot \sigma^2 \cdot Q + \beta \cdot CS∗=α⋅σ2⋅Q+β⋅C
其中 σ2\sigma^2σ2 是资产收益方差，QQQ 是交易规模，CCC 是处理成本，α\alphaα 和 β\betaβ 是取决于做市商风险厌恶程度的参数。


核心洞察：价差随波动率和交易规模增加而扩大，因为做市商承担的存货风险更大。


Amihud-Mendelson 模型（1980）
该模型引入了首选存货水平的概念。做市商有一个最优库存目标（通常为零或接近零），偏离这一目标时调整报价：


    

  • 库存过多（多头偏大）→ 降低买价和卖价，鼓励卖出
    • 

  • 库存过少（空头偏大）→ 提高买价和卖价，鼓励买入
    • 



这导致了均值回归的报价行为：


Pbid(I)=P∗−γ(I−I∗)−S2P_{bid}(I) = P^* - \gamma(I - I^*) - \frac{S}{2}Pbid​(I)=P∗−γ(I−I∗)−2S​
 


Pask(I)=P∗−γ(I−I∗)+S2P_{ask}(I) = P^* - \gamma(I - I^*) + \frac{S}{2}Pask​(I)=P∗−γ(I−I∗)+2S​
其中 III 是当前库存，I∗I^*I∗ 是目标库存，γ\gammaγ 是调整速度。

max⁡Pbid,PaskE[∑t=0TU(Wt)]\max_{P_{bid}, P_{ask}} E\left[\sum_{t=0}^{T} U(W_t)\right]Pbid​,Pask​max​E[t=0∑T​U(Wt​)]

Avellaneda-Stoikov 模型（2008）
这是现代量化做市最广泛引用的模型之一。做市商在随机环境下最优控制报价偏移（Offset）：


最优报价：


δbid=δask=1γln⁡(1+γκ)+γσ2(T−t)2\delta^{bid} = \delta^{ask} = \frac{1}{\gamma} \ln\left(1 + \frac{\gamma}{\kappa}\right) + \frac{\gamma \sigma^2 (T-t)}{2}δbid=δask=γ1​ln(1+κγ​)+2γσ2(T−t)​
存货调整项：


Pbid=S−δbid−q⋅γσ2(T−t)P_{bid} = S - \delta^{bid} - q \cdot \gamma \sigma^2 (T-t)Pbid​=S−δbid−q⋅γσ2(T−t)
 


Pask=S+δask−q⋅γσ2(T−t)P_{ask} = S + \delta^{ask} - q \cdot \gamma \sigma^2 (T-t)Pask​=S+δask−q⋅γσ2(T−t)
其中 qqq 是当前库存，γ\gammaγ 是风险厌恶系数，σ\sigmaσ 是价格波动率，κ\kappaκ 是订单到达强度参数。


import numpy as np

def avellaneda_stoikov_quotes(mid_price, inventory, gamma, sigma, kappa, T_remaining):
    reservation_price = mid_price - inventory * gamma * sigma**2 * T_remaining
    optimal_spread = (2 / gamma) * np.log(1 + gamma / kappa)
    spread_adjustment = gamma * sigma**2 * T_remaining
    total_half_spread = optimal_spread / 2 + spread_adjustment / 2
    bid = reservation_price - total_half_spread
    ask = reservation_price + total_half_spread
    return bid, ask
信息模型
Bagehot/Copeland-Galai 模型（1971/1983）
这是信息不对称模型的先驱。做市商面对两类交易者：


    

  • 知情交易者（比例 π\piπ）：知道资产真值，与做市商交易必赢
    • 

  • 非知情交易者（比例 1−π1-\pi1−π）：随机交易
    • 



做市商的零期望利润条件要求：


π⋅E[对知情亏损]=(1−π)⋅E[对非知情盈利]\pi \cdot E[\text{对知情亏损}] = (1-\pi) \cdot E[\text{对非知情盈利}]π⋅E[对知情亏损]=(1−π)⋅E[对非知情盈利]
这导致均衡价差为：


S=2π(vˉ−v‾)1+(1−π)S = \frac{2\pi(\bar{v} - \underline{v})}{1 + (1-\pi)}S=1+(1−π)2π(vˉ−v​)​
核心洞察：知情交易者比例越高，价差越大。


Glosten-Milgrom 模型（1985）
Glosten 和 Milgrom 建立了序贯交易（Sequential Trade）模型，做市商通过贝叶斯更新从订单流中学习：


初始时做市商对资产价值的先验信念为 μ0\mu_0μ0​。收到买入订单后：


μ1buy=E[v∣Buy]=π⋅vˉ⋅P(Buy∣Informed)+(1−π)⋅μ0⋅P(Buy∣Uninformed)π⋅P(Buy∣Informed)+(1−π)⋅P(Buy∣Uninformed)\mu_1^{buy} = E[v | \text{Buy}] = \frac{\pi \cdot \bar{v} \cdot P(\text{Buy}|\text{Informed}) + (1-\pi) \cdot \mu_0 \cdot P(\text{Buy}|\text{Uninformed})}{\pi \cdot P(\text{Buy}|\text{Informed}) + (1-\pi) \cdot P(\text{Buy}|\text{Uninformed})}μ1buy​=E[v∣Buy]=π⋅P(Buy∣Informed)+(1−π)⋅P(Buy∣Uninformed)π⋅vˉ⋅P(Buy∣Informed)+(1−π)⋅μ0​⋅P(Buy∣Uninformed)​
关键结论：


    

  1. 价差反映了逆向选择成本——做市商在订单流中无法区分知情和非知情交易者
    2. 

  2. 价格序列是鞅（Martingale）——做市商的报价是无偏的估计
    3. 

  3. 买卖价差会随着信息逐渐融入价格而收窄
    4.

PIN=αμαμ+2ϵPIN = \frac{\alpha \mu}{\alpha \mu + 2\epsilon}PIN=αμ+2ϵαμ​

    •

Glosten 和 Harris 提出了将价格影响分解为永久性和暂时性成分的回归框架：

现代价差理论发展
高频环境下的价差
在微秒级交易环境中，传统价差理论面临新挑战：


    

  1. Tick Size 约束：最小报价单位（$0.01）可能大于均衡价差，导致"约束型价差"（Constrained Spread）
    

    2. 

  2. 队列优先权的价值：当 Tick Size 具有约束性时，时间优先权（队列位置）成为宝贵资源。做市商愿意以零利润甚至负利润维持队列位置
    

    3. 

  3. 速度军备竞赛：更快的速度意味着更少的逆向选择损失（来得及在不利信息后撤单），这改变了价差的信息含量
    

    4. 



机器学习与价差预测
现代方法使用机器学习预测价差的变化，输入特征包括：


    

  • 订单簿状态（多层深度、不平衡）
    • 

  • 交易流特征（成交量、方向、速度）
    • 

  • 跨资产信号（相关资产的价格变动）
    • 

  • 宏观日历效应（时间、日期、事件）
    • 



随机森林和 XGBoost 在价差预测中表现良好，对于做市策略的报价宽度决策提供了数据驱动的支持。


总结
买卖价差理论从两个互补的视角解释了流动性的成本。存货模型强调做市商的风险管理需求——持有非期望头寸的风险需要通过价差补偿；信息模型揭示了逆向选择的核心角色——做市商需要从非知情交易者的利润中弥补与知情交易者交易的损失。这两类理论并不矛盾，它们分别抓住了价差的不同组成部分。从 Garman 的破产约束到 Avellaneda-Stoikov 的最优控制，从 Glosten-Milgrom 的贝叶斯更新到 VPIN 的实时监控，价差理论持续为量化做市和市场监管提供理论基础。
