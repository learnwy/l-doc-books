监督学习在金融中的应用

概述

监督学习（Supervised Learning）是金融机器学习的基石。从信用评分到股票收益预测，从欺诈检测到客户流失预警，几乎所有需要"给定输入预测输出"的金融问题都可以建模为监督学习任务。然而，金融数据具有信噪比极低、非平稳性强、样本分布漂移（concept drift）频繁等特征，使得直接套用标准 ML 方法往往导致灾难性过拟合。

本文系统梳理监督学习算法在金融场景中的适配策略，涵盖线性模型、树模型、集成方法三大族系，重点阐述金融特有的交叉验证方案、评估指标设计和模型选择框架。

金融监督学习问题分类

金融监督学习的三类核心问题如上所示。分类问题关注离散事件的概率（违约/不违约）；回归问题估计连续目标变量（收益率、波动率）；排序问题对资产进行相对排名，这在投资组合构建中尤为重要——我们不需要精确预测收益率，只需正确排序即可。


线性模型族
Lasso 与 Ridge 在因子选择中的作用
金融因子研究中，线性模型仍占据核心地位，原因在于其可解释性和稳定性。


Ridge 回归（L2 正则化）通过收缩系数降低过拟合风险：


β^Ridge=arg⁡min⁡β∥y−Xβ∥22+λ∥β∥22\hat{\beta}^{\text{Ridge}} = \arg\min_\beta \left\| y - X\beta \right\|_2^2 + \lambda \|\beta\|_2^2β^​Ridge=argβmin​∥y−Xβ∥22​+λ∥β∥22​
Lasso 回归（L1 正则化）自动执行变量选择，将不相关因子的系数压缩为零：


β^Lasso=arg⁡min⁡β∥y−Xβ∥22+λ∥β∥1\hat{\beta}^{\text{Lasso}} = \arg\min_\beta \left\| y - X\beta \right\|_2^2 + \lambda \|\beta\|_1β^​Lasso=argβmin​∥y−Xβ∥22​+λ∥β∥1​
ElasticNet 结合两者优势，在高度共线性的因子矩阵中表现更稳定：


β^EN=arg⁡min⁡β∥y−Xβ∥22+λ1∥β∥1+λ2∥β∥22\hat{\beta}^{\text{EN}} = \arg\min_\beta \left\| y - X\beta \right\|_2^2 + \lambda_1 \|\beta\|_1 + \lambda_2 \|\beta\|_2^2β^​EN=argβmin​∥y−Xβ∥22​+λ1​∥β∥1​+λ2​∥β∥22​
import numpy as np
from sklearn.linear_model import ElasticNetCV
from sklearn.preprocessing import StandardScaler

def build_factor_model(X_train, y_train, X_test):
    scaler = StandardScaler()
    X_train_scaled = scaler.fit_transform(X_train)
    X_test_scaled = scaler.transform(X_test)

    model = ElasticNetCV(
        l1_ratio=[0.1, 0.5, 0.7, 0.9, 0.95, 0.99],
        alphas=np.logspace(-4, 1, 50),
        cv=5,
        max_iter=10000,
        random_state=42
    )
    model.fit(X_train_scaled, y_train)

    selected_factors = np.where(np.abs(model.coef_) > 1e-6)[0]
    predictions = model.predict(X_test_scaled)

    return predictions, selected_factors, model.coef_

树模型与集成方法
随机森林在信用风险中的应用
随机森林（Random Forest）通过 Bagging + 特征随机化构建多棵决策树，有效降低方差。在信用风险评估中，其优势在于：


    

  1. 自动处理缺失值：金融数据中缺失率通常 10%-30%
    2. 

  2. 非线性建模：捕捉收入与违约率之间的阈值效应
    3. 

  3. 特征重要性排序：为因子筛选提供定量依据

import lightgbm as lgb

def train_lgb_ranker(X_train, y_train, groups, X_val, y_val, val_groups):
    train_data = lgb.Dataset(
        X_train, label=y_train, group=groups
    )
    val_data = lgb.Dataset(
        X_val, label=y_val, group=val_groups, reference=train_data
    )

    params = {
        "objective": "lambdarank",
        "metric": "ndcg",
        "ndcg_eval_at": [5, 10, 20],
        "num_leaves": 63,
        "learning_rate": 0.05,
        "feature_fraction": 0.8,
        "bagging_fraction": 0.8,
        "bagging_freq": 5,
        "min_child_samples": 50,
        "lambda_l1": 0.1,
        "lambda_l2": 1.0,
        "verbose": -1
    }

    model = lgb.train(
        params, train_data,
        num_boost_round=1000,
        valid_sets=[val_data],
        callbacks=[lgb.early_stopping(50)]
    )

    return model
上述代码展示了 LightGBM 的 LambdaRank 模式——将股票收益率预测转化为排序问题，直接优化 NDCG 指标，这比预测绝对收益更适合量化选股。


金融交叉验证
标准 K-Fold 交叉验证在金融时间序列上会导致严重的前视偏差（look-ahead bias），因为它允许用未来数据训练去预测过去。金融场景必须使用时序感知的验证方案。


Walk-Forward 验证
Walk-Forward（滚动窗口）是最基本的金融交叉验证方法：


from sklearn.model_selection import TimeSeriesSplit

def walk_forward_cv(X, y, model_fn, n_splits=5):
    tscv = TimeSeriesSplit(n_splits=n_splits)
    scores = []

    for fold, (train_idx, test_idx) in enumerate(tscv.split(X)):
        X_train, X_test = X[train_idx], X[test_idx]
        y_train, y_test = y[train_idx], y[test_idx]

        model = model_fn()
        model.fit(X_train, y_train)
        score = model.score(X_test, y_test)
        scores.append(score)

    return np.array(scores)
Purged K-Fold 与 Embargo
Marcos López de Prado 在 Advances in Financial Machine Learning 中提出 Purged K-Fold 方法：在训练集和测试集之间插入一段"禁区"（embargo period），避免因标签重叠（如 20 日收益率横跨多个折叠）导致的信息泄露。


关键参数设计：


    

  • Purge 范围：等于标签计算窗口长度（如 20 日收益率对应 purge 20 个交易日）
    • 

  • Embargo 长度：通常设为 purge 的 1%-5%，作为额外安全边际
    • 

  • 折叠数量：5-10 折，过多折叠导致训练集缺口比例过大
    •

from scipy.stats import spearmanr

def calculate_ic_series(predictions_df, returns_df):
    ic_list = []
    for date in predictions_df.index:
        pred = predictions_df.loc[date]
        ret = returns_df.loc[date]
        valid = pred.notna() & ret.notna()
        if valid.sum() < 30:
            continue
        ic, _ = spearmanr(pred[valid], ret[valid])
        ic_list.append({"date": date, "ic": ic})

    ic_series = pd.DataFrame(ic_list).set_index("date")
    mean_ic = ic_series["ic"].mean()
    ic_ir = mean_ic / ic_series["ic"].std()

    return ic_series, mean_ic, ic_ir
模型选择框架
金融场景的模型选择不是单纯的性能比较，还需综合考虑可解释性需求、计算预算、监管约束和策略容量。


实践建议
金融监督学习的常见陷阱
    

  1. 过度优化回测：对历史数据的 IC 优化不等于未来可盈利，需 out-of-sample 验证
    2. 

  2. 忽视交易成本：模型预测的微小 alpha 可能无法覆盖交易摩擦
    3. 

  3. 标签定义模糊：20 日收益率 vs 5 日收益率，超额收益 vs 绝对收益，标签选择直接影响模型行为
    4. 

  4. 特征泄露：使用了包含未来信息的特征（如报告公布前的财务数据点）
    5. 

  5. 幸存者偏差：仅使用当前上市股票回测，忽略退市股票
    6.

总结
监督学习在金融中的应用远非"选个算法跑一遍"那么简单。金融数据的低信噪比、非平稳性、标签模糊性要求从业者在交叉验证方案设计、评估指标选择、模型更新策略等环节进行专门适配。线性模型在可解释性要求强的场景（信用、合规）中仍是首选；GBDT 家族在中等规模因子建模中表现最稳定；排序学习框架（LambdaRank）则为量化选股提供了更自然的优化目标。理解"什么时候不该用 ML"与"什么时候该用 ML"同样重要——当因果关系清晰且线性假设成立时，简单模型往往比复杂模型更可靠。
