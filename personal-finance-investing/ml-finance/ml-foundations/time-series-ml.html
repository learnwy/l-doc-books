时间序列机器学习方法

概述

金融市场的核心数据形态是时间序列——股价、利率、波动率、交易量无一不是随时间演化的序列数据。时间序列机器学习（Time Series ML）将经典统计时序方法与现代 ML 技术融合，旨在解决金融序列中的非平稳性、体制转换（regime switching）、长程依赖和低信噪比等挑战。

本文从传统统计方法出发，经由机器学习增强的混合模型，直至端到端的深度时序预测方法，构建完整的金融时间序列建模知识体系。重点不在算法本身的数学推导，而在于每种方法在金融时序场景中的适配性分析。

金融时间序列的特殊性质

金融时间序列区别于一般时间序列的关键特征：

特征 描述 对建模的影响
非平稳性 均值、方差随时间变化 需要差分/去趋势预处理
波动率聚集 大波动倾向于跟随大波动 GARCH 族模型的动机
尖峰厚尾 收益率分布非正态，极端值频繁 损失函数需稳健设计
低信噪比 价格变动中噪声占主导 模型容量需严格控制
体制转换 牛市/熊市/震荡市行为迥异 需要动态参数或混合模型
日历效应 月末、季末、年末异常模式 时间编码特征的重要性
微观结构噪声 高频数据中买卖价差造成假信号 数据采样频率需权衡 
经典统计方法
ARIMA 族模型
ARIMA(p,d,q) 仍是金融时间序列建模的基准方法。其核心假设是：当前值可由自身滞后项（AR）和过去预测误差（MA）的线性组合表达。


import pandas as pd
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.tsa.stattools import adfuller

def fit_arima_with_diagnostics(returns, order=(5, 0, 2)):
    adf_stat, p_value, *_ = adfuller(returns.dropna())
    print(f"ADF Statistic: {adf_stat:.4f}, p-value: {p_value:.4f}")

    if p_value > 0.05:
        returns = returns.diff().dropna()
        order = (order[0], 1, order[2])

    model = ARIMA(returns, order=order)
    result = model.fit()

    return result

def rolling_arima_forecast(series, window=252, horizon=1, order=(5, 0, 2)):
    forecasts = []
    for i in range(window, len(series) - horizon):
        train = series[i - window:i]
        try:
            model = ARIMA(train, order=order)
            fit = model.fit()
            pred = fit.forecast(steps=horizon)
            forecasts.append({
                "date": series.index[i + horizon],
                "forecast": pred.iloc[-1],
                "actual": series.iloc[i + horizon]
            })
        except Exception:
            continue

    return pd.DataFrame(forecasts)
GARCH 族：波动率建模
金融中更有价值的往往不是收益率预测（极难），而是波动率预测（相对可预测）。GARCH(1,1) 是最广泛使用的波动率模型：


σt2=ω+αϵt−12+βσt−12\sigma_t^2 = \omega + \alpha \epsilon_{t-1}^2 + \beta \sigma_{t-1}^2σt2​=ω+αϵt−12​+βσt−12​
其中 α+β<1\alpha + \beta < 1α+β<1 保证平稳性，α+β\alpha + \betaα+β 越接近 1 表示波动率记忆越持久。

from arch import arch_model

def fit_garch_model(returns, p=1, q=1, dist="skewt"):
    model = arch_model(
        returns,
        vol="Garch",
        p=p, q=q,
        dist=dist,
        mean="AR",
        lags=1
    )
    result = model.fit(disp="off")

    forecasts = result.forecast(horizon=5)
    vol_forecast = np.sqrt(forecasts.variance.iloc[-1])

    return result, vol_forecast
向量自回归（VAR）与协整
多个金融时间序列之间的联合建模使用 VAR：


    

  • VAR(p)：多变量 AR 模型，捕捉变量间的领先-滞后关系
    • 

  • VECM：误差修正模型，利用协整关系建模长期均衡
    • 

  • Granger 因果检验：判断一个序列是否包含另一个序列的预测信息
    • 



在配对交易（pairs trading）中，协整检验（Johansen 检验）是核心工具——找到长期价格比例稳定的资产对，在偏离时交易均值回复。


机器学习增强的时序方法
特征化时序建模
将时间序列问题转化为表格化的监督学习问题，是金融 ML 实践中最常见的范式：


滑动窗口特征构造示例：


def create_ts_features(df, lookback_windows=[5, 10, 20, 60]):
    features = pd.DataFrame(index=df.index)

    for w in lookback_windows:
        features[f"ret_{w}d"] = df["close"].pct_change(w)
        features[f"vol_{w}d"] = df["close"].pct_change().rolling(w).std()
        features[f"skew_{w}d"] = df["close"].pct_change().rolling(w).skew()
        features[f"kurt_{w}d"] = df["close"].pct_change().rolling(w).kurt()
        features[f"max_dd_{w}d"] = (
            df["close"].rolling(w).apply(
                lambda x: (x / x.cummax() - 1).min()
            )
        )
        features[f"rsi_{w}d"] = compute_rsi(df["close"], w)
        features[f"volume_ratio_{w}d"] = (
            df["volume"] / df["volume"].rolling(w).mean()
        )

    features["day_of_week"] = df.index.dayofweek
    features["month"] = df.index.month
    features["is_month_end"] = df.index.is_month_end.astype(int)

    return features

def compute_rsi(prices, window):
    delta = prices.diff()
    gain = (delta.where(delta > 0, 0)).rolling(window).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(window).mean()
    rs = gain / loss
    return 100 - (100 / (1 + rs))

Hidden Markov Model（HMM）与体制识别
金融市场存在明显的体制转换——牛市、熊市、震荡市的统计特征截然不同。HMM 假设观测序列由隐状态控制，通过 Baum-Welch 算法估计状态转移概率。


from hmmlearn.hmm import GaussianHMM

def fit_regime_model(returns, n_regimes=3):
    model = GaussianHMM(
        n_components=n_regimes,
        covariance_type="full",
        n_iter=1000,
        random_state=42
    )
    X = returns.values.reshape(-1, 1)
    model.fit(X)

    hidden_states = model.predict(X)

    regime_stats = {}
    for i in range(n_regimes):
        mask = hidden_states == i
        regime_stats[f"regime_{i}"] = {
            "mean": returns[mask].mean(),
            "std": returns[mask].std(),
            "count": mask.sum(),
            "fraction": mask.mean()
        }

    return model, hidden_states, regime_stats
实际应用中，HMM 识别出的体制可以作为下游 ML 模型的条件特征——在不同体制下使用不同的交易策略或调整仓位。


现代深度时序方法
Temporal Fusion Transformer（TFT）
Google 提出的 TFT 模型专为多步时间序列预测设计，其核心创新：


    

  • Variable Selection Network：自动选择相关输入变量
    • 

  • Gated Residual Network（GRN）：灵活的非线性处理
    • 

  • Multi-head Attention：捕捉不同时间尺度的依赖
    • 

  • Quantile 输出：直接输出预测区间
    • 



在金融中，TFT 的变量选择能力特别有价值——当输入因子数量庞大时，模型自动识别当前体制下最相关的因子。


N-BEATS 与 N-HiTS
N-BEATS（Neural Basis Expansion Analysis）是纯深度学习的时序预测模型，不依赖任何传统时序假设：


    

  • 基函数分解：将预测分解为趋势和季节性分量
    • 

  • 可解释版本：强制使用多项式（趋势）和傅里叶级数（季节性）作为基函数
    • 

  • Ensemble 机制：多个 Block 的层级叠加
    • 



N-HiTS 进一步引入多尺度采样，对长短期模式同时建模，在金融长窗口预测中表现良好。


时序模型评估框架
方向准确率（Directional Accuracy） 在金融中比绝对误差更重要——我们不需要精确知道明天涨多少，只需知道涨还是跌：


def directional_accuracy(y_true, y_pred):
    correct = np.sign(y_true) == np.sign(y_pred)
    return correct.mean()

def diebold_mariano_test(e1, e2, h=1):
    d = e1**2 - e2**2
    mean_d = d.mean()
    var_d = d.var() / len(d)
    dm_stat = mean_d / np.sqrt(var_d)
    return dm_stat

总结
金融时间序列建模是统计学、机器学习和金融理论的交汇点。经典方法（ARIMA、GARCH）提供了坚实的理论基础和可解释框架；机器学习增强方法（特征化 GBDT、HMM）在中频金融预测中表现最稳定；深度学习方法（TFT、N-BEATS）在数据充足、多变量联合预测场景中展现潜力。选择方法时，"金融问题的特殊性"应始终优先于"算法的先进性"——低信噪比意味着简单模型往往比复杂模型更稳健，而严格的时序验证框架是避免回测幻觉的唯一保障。
