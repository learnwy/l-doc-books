金融中的过拟合与正则化

概述

过拟合（Overfitting）是金融机器学习的头号公敌。在信噪比（Signal-to-Noise Ratio）极低的金融数据中，模型极易将随机噪声误认为可预测的规律——回测中表现惊艳的策略在实盘中亏损，IC 从样本内的 0.08 骤降至样本外的 0.01，这些都是过拟合的典型症状。更危险的是，金融中的过拟合往往难以被传统统计检验发现，因为研究者在反复尝试模型配置的过程中不自觉地进行了"多重检验"。

本文系统梳理金融过拟合的来源、诊断方法和应对策略，涵盖统计正则化、回测过拟合修正和组织级别的防过拟合规范。

非平稳性与体制转换
金融数据的统计特性随时间变化——一个在 2015-2020 年有效的因子可能在 2021-2025 年完全失效：


import numpy as np
import pandas as pd
from scipy.stats import spearmanr

def rolling_ic_analysis(factor, returns, window=60, step=20):
    results = []
    dates = factor.index

    for i in range(window, len(dates), step):
        start = dates[i - window]
        end = dates[i]

        f = factor.loc[start:end]
        r = returns.loc[start:end]

        ic_list = []
        for date in f.index:
            if date not in r.index:
                continue
            valid = f.loc[date].notna() & r.loc[date].notna()
            if valid.sum() < 30:
                continue
            ic, _ = spearmanr(f.loc[date][valid], r.loc[date][valid])
            ic_list.append(ic)

        if ic_list:
            results.append({
                "end_date": end,
                "mean_ic": np.mean(ic_list),
                "ic_std": np.std(ic_list),
                "ic_ir": np.mean(ic_list) / max(np.std(ic_list), 1e-8),
                "n_periods": len(ic_list)
            })

    return pd.DataFrame(results).set_index("end_date")

Dropout 与深度学习正则化
import torch.nn as nn

class RegularizedFinanceNet(nn.Module):
    def __init__(self, input_dim, hidden_dim=64, dropout_rate=0.5):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.BatchNorm1d(hidden_dim),
            nn.ReLU(),
            nn.Dropout(dropout_rate),
            nn.Linear(hidden_dim, hidden_dim // 2),
            nn.BatchNorm1d(hidden_dim // 2),
            nn.ReLU(),
            nn.Dropout(dropout_rate),
            nn.Linear(hidden_dim // 2, 1)
        )

    def forward(self, x):
        return self.net(x)

import lightgbm as lgb

def train_conservative_lgb(X_train, y_train, X_val, y_val):
    train_data = lgb.Dataset(X_train, label=y_train)
    val_data = lgb.Dataset(X_val, label=y_val, reference=train_data)

    params = {
        "objective": "regression",
        "metric": "mae",
        "num_leaves": 31,
        "max_depth": 5,
        "learning_rate": 0.02,
        "feature_fraction": 0.6,
        "bagging_fraction": 0.7,
        "bagging_freq": 5,
        "min_child_samples": 100,
        "lambda_l1": 1.0,
        "lambda_l2": 5.0,
        "min_gain_to_split": 0.01,
        "verbose": -1
    }

    model = lgb.train(
        params, train_data,
        num_boost_round=2000,
        valid_sets=[val_data],
        callbacks=[
            lgb.early_stopping(100),
            lgb.log_evaluation(200)
        ]
    )

    return model
回测过拟合
多重检验问题
当研究者尝试 NNN 种策略配置并选择最优者时，最优策略的回测表现被系统性高估。这就是 Harvey, Liu & Zhu（2016）在 "…and the Cross-Section of Expected Returns" 中指出的 p-hacking 问题。


Bonferroni 修正：如果独立测试了 NNN 种策略，显著性阈值应从 α\alphaα 调整为 α/N\alpha / Nα/N。


Deflated Sharpe Ratio
López de Prado 提出的 Deflated Sharpe Ratio（DSR）考虑了多重检验、收益率非正态分布等因素：


from scipy.stats import norm

def deflated_sharpe_ratio(observed_sr, sr_benchmark, n_trials,
                           skewness, kurtosis, n_observations):
    sr_std = np.sqrt(
        (1 - skewness * observed_sr + (kurtosis - 1) / 4 * observed_sr**2)
        / (n_observations - 1)
    )

    expected_max_sr = sr_benchmark * (
        (1 - np.euler_gamma) * norm.ppf(1 - 1 / n_trials)
        + np.euler_gamma * norm.ppf(1 - 1 / (n_trials * np.e))
    )

    dsr = norm.cdf((observed_sr - expected_max_sr) / sr_std)

    return dsr
Combinatorially Symmetric Cross-Validation（CSCV）
CSCV 通过排列组合所有可能的训练/测试划分来检测回测过拟合：


    

  1. 将样本按时间分为 2S2S2S 个子样本
    2. 

  2. 枚举所有 (2SS)\binom{2S}{S}(S2S​) 种训练/测试划分
    3. 

  3. 在每种划分上计算策略的样本外表现
    4. 

  4. 计算"样本外表现中位数 > 0"的比例
    5. 

  5. 如果比例接近 50%，说明策略可能是过拟合的随机产物
    6. 



from itertools import combinations

def cscv_test(returns_matrix, n_splits=8):
    n_periods = returns_matrix.shape[0]
    period_size = n_periods // (2 * n_splits)

    sub_samples = []
    for i in range(2 * n_splits):
        start = i * period_size
        end = (i + 1) * period_size
        sub_samples.append(returns_matrix[start:end])

    oos_performances = []
    half = n_splits

    for train_indices in combinations(range(2 * n_splits), half):
        test_indices = [i for i in range(2 * n_splits) if i not in train_indices]

        train_data = np.concatenate([sub_samples[i] for i in train_indices])
        test_data = np.concatenate([sub_samples[i] for i in test_indices])

        is_sharpe = np.mean(train_data) / max(np.std(train_data), 1e-8)
        oos_sharpe = np.mean(test_data) / max(np.std(test_data), 1e-8)

        oos_performances.append(oos_sharpe)

    oos_performances = np.array(oos_performances)
    pbo = (oos_performances < 0).mean()

    return {
        "probability_of_backtest_overfitting": pbo,
        "median_oos_sharpe": np.median(oos_performances),
        "mean_oos_sharpe": np.mean(oos_performances)
    }
特征选择防过拟合
前向特征选择
逐步添加特征，每步验证增量贡献：


def forward_feature_selection(X, y, model_fn, cv_fn, max_features=20):
    available = list(X.columns)
    selected = []
    best_scores = []

    for _ in range(min(max_features, len(available))):
        best_score = -np.inf
        best_feature = None

        for feat in available:
            candidate = selected + [feat]
            score = cv_fn(X[candidate], y, model_fn)

            if score > best_score:
                best_score = score
                best_feature = feat

        if best_feature is None:
            break

        improvement = best_score - (best_scores[-1] if best_scores else -np.inf)
        if improvement < 0.001 and len(selected) > 3:
            break

        selected.append(best_feature)
        available.remove(best_feature)
        best_scores.append(best_score)

    return selected, best_scores
基于重要性的特征筛选
结合多种重要性指标综合判断：


def robust_feature_importance(model, X_val, y_val, n_repeats=10):
    from sklearn.inspection import permutation_importance

    perm_importance = permutation_importance(
        model, X_val, y_val,
        n_repeats=n_repeats,
        scoring="neg_mean_absolute_error",
        random_state=42
    )

    if hasattr(model, "feature_importances_"):
        split_importance = model.feature_importances_
    else:
        split_importance = np.zeros(X_val.shape[1])

    importance_df = pd.DataFrame({
        "feature": X_val.columns if hasattr(X_val, "columns") else range(X_val.shape[1]),
        "permutation_mean": perm_importance.importances_mean,
        "permutation_std": perm_importance.importances_std,
        "split_importance": split_importance
    })

    importance_df["perm_rank"] = importance_df["permutation_mean"].rank(ascending=False)
    importance_df["split_rank"] = importance_df["split_importance"].rank(ascending=False)
    importance_df["avg_rank"] = (importance_df["perm_rank"] + importance_df["split_rank"]) / 2

    return importance_df.sort_values("avg_rank")

总结
金融中的过拟合不仅是一个统计问题，更是一个系统性的方法论挑战。它渗透在数据准备（幸存者偏差）、特征工程（前视偏差）、模型选择（多重检验）和回测评估（回测过拟合）的每一个环节。有效的防过拟合策略需要在三个层面同时作用：算法层面的正则化技术（L1/L2、Dropout、早停、浅树）；评估层面的严格验证框架（Purged K-Fold、Walk-Forward、Deflated Sharpe Ratio）；组织层面的研究管理规范（预注册、样本隔离、独立复现）。最终，对过拟合最好的防御是保持对"异常好的结果"的怀疑——在金融中，如果回测表现好得令人难以置信，那它通常确实不可信。
