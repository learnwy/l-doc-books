图神经网络与金融关系建模

概述

金融市场不是一个个孤立资产的集合，而是一张由供应链、股权关系、行业关联、交易对手等多种关系编织的复杂网络。图神经网络（Graph Neural Network, GNN）将这些关系结构显式编码为图拓扑，通过消息传递机制在图上进行推理，实现传统表格化模型无法捕捉的关系驱动预测。

本文系统梳理 GNN 在金融中的理论基础与应用实践，涵盖图构建方法、主流 GNN 架构、动态图演化，以及在股票预测、风险传导、欺诈检测等场景中的落地案例。

图构建方法
import numpy as np
import torch
from torch_geometric.data import Data

def build_correlation_graph(returns_df, threshold=0.3, top_k=10):
    corr_matrix = returns_df.corr().values
    n = corr_matrix.shape[0]

    edge_index = []
    edge_attr = []

    for i in range(n):
        corr_row = np.abs(corr_matrix[i])
        corr_row[i] = 0

        if top_k:
            top_indices = np.argsort(corr_row)[-top_k:]
            for j in top_indices:
                if corr_row[j] > threshold:
                    edge_index.append([i, j])
                    edge_attr.append(corr_matrix[i, j])
        else:
            for j in range(n):
                if i != j and corr_row[j] > threshold:
                    edge_index.append([i, j])
                    edge_attr.append(corr_matrix[i, j])

    edge_index = torch.tensor(edge_index, dtype=torch.long).t()
    edge_attr = torch.tensor(edge_attr, dtype=torch.float)

    return edge_index, edge_attr

def build_industry_graph(industry_labels):
    n = len(industry_labels)
    edge_index = []

    for i in range(n):
        for j in range(i + 1, n):
            if industry_labels[i] == industry_labels[j]:
                edge_index.append([i, j])
                edge_index.append([j, i])

    return torch.tensor(edge_index, dtype=torch.long).t()

def build_multi_relation_graph(returns_df, industry_labels, supply_chain_edges):
    corr_edges, corr_attr = build_correlation_graph(returns_df)
    industry_edges = build_industry_graph(industry_labels)
    supply_edges = torch.tensor(supply_chain_edges, dtype=torch.long).t()

    return {
        "correlation": (corr_edges, corr_attr),
        "industry": (industry_edges, None),
        "supply_chain": (supply_edges, None)
    }
主流 GNN 架构
GCN（图卷积网络）
GCN 通过谱域卷积在图上聚合邻居信息：


H(l+1)=σ(D~−1/2A~D~−1/2H(l)W(l))H^{(l+1)} = \sigma(\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}H^{(l)}W^{(l)})H(l+1)=σ(D~−1/2A~D~−1/2H(l)W(l))
其中 A~=A+I\tilde{A} = A + IA~=A+I 是加入自环的邻接矩阵，D~\tilde{D}D~ 是度矩阵。


GAT（图注意力网络）
GAT 用注意力机制动态计算邻居权重，允许模型自动学习不同关系的重要性：

import torch.nn.functional as F
from torch_geometric.nn import GATConv, GCNConv, global_mean_pool

class StockGAT(torch.nn.Module):
    def __init__(self, input_dim, hidden_dim=64, heads=4, num_layers=3,
                 dropout=0.3):
        super().__init__()
        self.convs = torch.nn.ModuleList()
        self.norms = torch.nn.ModuleList()

        self.convs.append(
            GATConv(input_dim, hidden_dim, heads=heads, dropout=dropout)
        )
        self.norms.append(torch.nn.LayerNorm(hidden_dim * heads))

        for _ in range(num_layers - 2):
            self.convs.append(
                GATConv(hidden_dim * heads, hidden_dim, heads=heads,
                        dropout=dropout)
            )
            self.norms.append(torch.nn.LayerNorm(hidden_dim * heads))

        self.convs.append(
            GATConv(hidden_dim * heads, hidden_dim, heads=1,
                    concat=False, dropout=dropout)
        )

        self.predictor = torch.nn.Sequential(
            torch.nn.Linear(hidden_dim, hidden_dim // 2),
            torch.nn.ReLU(),
            torch.nn.Dropout(dropout),
            torch.nn.Linear(hidden_dim // 2, 1)
        )

    def forward(self, x, edge_index):
        for i, conv in enumerate(self.convs[:-1]):
            x = conv(x, edge_index)
            x = self.norms[i](x)
            x = F.elu(x)

        x = self.convs[-1](x, edge_index)
        return self.predictor(x).squeeze(-1)
异构图神经网络
金融场景中存在多种节点类型（股票、基金、行业、分析师）和多种边类型，需要异构图模型：


from torch_geometric.nn import HeteroConv, SAGEConv

class HeteroStockGNN(torch.nn.Module):
    def __init__(self, metadata, hidden_dim=64, num_layers=2):
        super().__init__()
        self.convs = torch.nn.ModuleList()

        for _ in range(num_layers):
            conv_dict = {}
            for edge_type in metadata[1]:
                conv_dict[edge_type] = SAGEConv((-1, -1), hidden_dim)
            self.convs.append(HeteroConv(conv_dict, aggr="mean"))

        self.predictor = torch.nn.Linear(hidden_dim, 1)

    def forward(self, x_dict, edge_index_dict):
        for conv in self.convs:
            x_dict = conv(x_dict, edge_index_dict)
            x_dict = {key: F.relu(x) for key, x in x_dict.items()}

        stock_embeddings = x_dict["stock"]
        return self.predictor(stock_embeddings).squeeze(-1)
动态图与时序图
时序图神经网络
金融图的结构随时间演化——相关性矩阵随市场体制变化，供应链关系因商业活动调整。时序图网络需要同时建模图结构演化和节点特征演化。


EvolveGCN 是一种典型的动态图方法：用 RNN 演化 GCN 的权重矩阵，使图卷积参数随时间自适应。在金融中，这种方法可以捕捉市场体制转换引起的关系结构变化。


class TemporalGNN(torch.nn.Module):
    def __init__(self, input_dim, hidden_dim=64, num_gnn_layers=2):
        super().__init__()
        self.gnn = StockGAT(input_dim, hidden_dim)
        self.temporal = torch.nn.GRU(
            hidden_dim, hidden_dim, batch_first=True
        )
        self.predictor = torch.nn.Linear(hidden_dim, 1)

    def forward(self, x_sequence, edge_index_sequence):
        embeddings = []
        for x, edge_index in zip(x_sequence, edge_index_sequence):
            h = self.gnn.encode(x, edge_index)
            embeddings.append(h)

        temporal_input = torch.stack(embeddings, dim=1)
        temporal_out, _ = self.temporal(temporal_input)

        return self.predictor(temporal_out[:, -1, :]).squeeze(-1)
应用场景
股票收益预测
将每只股票作为节点，因子值作为节点特征，多种关系作为边，构建股票关系图。GNN 通过消息传递让每只股票"看到"其关联股票的信息，实现关系增强的收益预测。


研究表明，加入图结构后的收益预测 IC 通常提升 10%-20%（相比仅用节点特征的 MLP 基准）。


信用风险传导
企业信用风险可以通过供应链和担保链传导。GNN 可以建模这种风险溢出效应：


    

  • 节点特征：企业财务指标、信用评级
    • 

  • 边关系：供应链依赖、互保关系、股权关联
    • 

  • 目标：预测企业违约概率
    • 



欺诈检测
金融欺诈往往涉及多个账户的协同行为。图结构天然适合检测此类模式：






图元素
含义





节点

边

目标

GNN 在欺诈检测中的优势在于能发现社区级别的异常模式——单个账户看起来正常，但一群相互关联的账户共同表现出异常行为。

  • 图分区：将大图分割为子图并行训练

总结
图神经网络为金融建模提供了一种全新的范式——将资产间的关系结构作为模型的一等公民，而非仅依赖各资产自身的特征。在股票预测中，GNN 通过关系增强提升了因子模型的 IC；在信用风险中，GNN 实现了风险传导的端到端建模；在欺诈检测中，GNN 发现了传统方法难以捕捉的社区级异常。关键挑战在于图构建的质量和稳健性——"garbage in, garbage out"在图模型中比表格模型更为显著，因为错误的边会通过消息传递传播到整个图。
