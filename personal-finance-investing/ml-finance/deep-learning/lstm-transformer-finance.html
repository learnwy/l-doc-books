LSTM 与 Transformer 金融预测

概述

循环神经网络（RNN）及其改进变体 LSTM/GRU 长期以来是金融时序预测的深度学习标配，而 Transformer 架构自 2017 年在 NLP 领域取得突破后，迅速渗透至时间序列预测领域。两类架构在金融预测中各有所长：LSTM 通过门控机制维护有序的时间状态，天然适合金融序列中的因果依赖；Transformer 通过自注意力机制并行处理全序列，在长程依赖建模和多变量融合上具有结构性优势。

本文系统对比两类架构的原理、金融适配策略和工程实践，涵盖从单步预测到概率预测的完整技术栈。

LSTM 金融预测
核心架构
金融预测中的 LSTM 通常采用 Encoder-Decoder 结构：Encoder 压缩历史窗口为上下文向量，Decoder 递归生成多步预测。


import torch
import torch.nn as nn

class FinanceLSTM(nn.Module):
    def __init__(self, input_dim, hidden_dim=128, num_layers=2,
                 dropout=0.3, output_dim=1, seq_len=60):
        super().__init__()
        self.hidden_dim = hidden_dim
        self.num_layers = num_layers

        self.feature_bn = nn.BatchNorm1d(seq_len)

        self.lstm = nn.LSTM(
            input_size=input_dim,
            hidden_size=hidden_dim,
            num_layers=num_layers,
            batch_first=True,
            dropout=dropout if num_layers > 1 else 0
        )

        self.attention = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim // 2),
            nn.Tanh(),
            nn.Linear(hidden_dim // 2, 1)
        )

        self.fc = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim // 2),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(hidden_dim // 2, output_dim)
        )

    def forward(self, x):
        x = self.feature_bn(x)
        lstm_out, _ = self.lstm(x)

        attn_weights = torch.softmax(
            self.attention(lstm_out).squeeze(-1), dim=1
        )
        context = torch.bmm(
            attn_weights.unsqueeze(1), lstm_out
        ).squeeze(1)

        output = self.fc(context)
        return output, attn_weights

Transformer 金融预测
位置编码的金融适配
标准 Transformer 使用正弦/余弦位置编码，但金融时间序列有更丰富的时间语义：


class FinancialPositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=512):
        super().__init__()

        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        div_term = torch.exp(
            torch.arange(0, d_model, 2).float() * (-np.log(10000.0) / d_model)
        )
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        self.register_buffer("pe", pe.unsqueeze(0))

        self.temporal_embed = nn.Embedding(5, d_model // 4)
        self.month_embed = nn.Embedding(12, d_model // 4)
        self.quarter_embed = nn.Embedding(4, d_model // 4)
        self.fusion = nn.Linear(d_model + 3 * (d_model // 4), d_model)

    def forward(self, x, day_of_week, month, quarter):
        seq_len = x.size(1)
        pos = self.pe[:, :seq_len]
        dow = self.temporal_embed(day_of_week)
        mon = self.month_embed(month)
        qtr = self.quarter_embed(quarter)

        temporal = torch.cat([pos.expand_as(x), dow, mon, qtr], dim=-1)
        return self.fusion(temporal)
金融 Transformer 架构
class FinanceTransformer(nn.Module):
    def __init__(self, input_dim, d_model=256, nhead=8,
                 num_layers=4, dropout=0.2, quantiles=[0.1, 0.5, 0.9]):
        super().__init__()
        self.quantiles = quantiles
        self.input_projection = nn.Linear(input_dim, d_model)
        self.pos_encoding = FinancialPositionalEncoding(d_model)

        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model,
            nhead=nhead,
            dim_feedforward=d_model * 4,
            dropout=dropout,
            batch_first=True,
            activation="gelu"
        )
        self.encoder = nn.TransformerEncoder(
            encoder_layer, num_layers=num_layers
        )

        self.quantile_heads = nn.ModuleList([
            nn.Linear(d_model, 1) for _ in quantiles
        ])

    def forward(self, x, temporal_info, mask=None):
        h = self.input_projection(x)
        h = h + self.pos_encoding(h, **temporal_info)

        if mask is None:
            mask = nn.Transformer.generate_square_subsequent_mask(
                x.size(1)
            ).to(x.device)

        h = self.encoder(h, mask=mask)
        last_hidden = h[:, -1, :]

        quantile_preds = [head(last_hidden) for head in self.quantile_heads]
        return torch.cat(quantile_preds, dim=-1)

    def quantile_loss(self, y_pred, y_true):
        losses = []
        for i, q in enumerate(self.quantiles):
            error = y_true - y_pred[:, i]
            loss = torch.max(q * error, (q - 1) * error)
            losses.append(loss.mean())
        return sum(losses) / len(losses)

iTransformer 的思路特别值得关注：传统 Transformer 将每个时间步作为 token，而 iTransformer 将每个变量（因子）作为 token，让注意力机制学习因子间的关系而非时间步间的关系——这在因子投资中非常自然。

金融深度学习的训练陷阱
多种子集成是降低深度学习不确定性的关键手段：


def ensemble_predictions(model_class, config, X, y, n_seeds=5):
    predictions = []
    for seed in range(n_seeds):
        torch.manual_seed(seed)
        np.random.seed(seed)
        model = model_class(**config)
        train_model(model, X, y)
        pred = model.predict(X)
        predictions.append(pred)

    ensemble_pred = np.mean(predictions, axis=0)
    pred_std = np.std(predictions, axis=0)

    return ensemble_pred, pred_std

混合架构
CNN-LSTM 组合
CNN 提取局部模式（如 K 线形态），LSTM 捕捉序列依赖：


class CNN_LSTM(nn.Module):
    def __init__(self, input_dim, cnn_filters=64, lstm_hidden=128):
        super().__init__()
        self.cnn = nn.Sequential(
            nn.Conv1d(input_dim, cnn_filters, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.Conv1d(cnn_filters, cnn_filters, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool1d(2)
        )
        self.lstm = nn.LSTM(
            cnn_filters, lstm_hidden, batch_first=True, num_layers=2
        )
        self.fc = nn.Linear(lstm_hidden, 1)

    def forward(self, x):
        x = x.permute(0, 2, 1)
        cnn_out = self.cnn(x)
        cnn_out = cnn_out.permute(0, 2, 1)
        lstm_out, _ = self.lstm(cnn_out)
        return self.fc(lstm_out[:, -1, :])

关键观察：深度学习在日频数据上相对 GBDT 的优势不大，但在多变量融合和概率预测上更具优势。当数据量足够（>3 年日频全市场）且特征维度高（>100 因子）时，Transformer 系列的优势逐渐显现。


总结
LSTM 和 Transformer 在金融预测中各有适用场景。LSTM 适合数据量有限、序列较短、计算资源受限的场景，其递归结构天然尊重时间因果性；Transformer 在长序列、多变量、概率预测场景中更具优势，但需要更多数据和更强正则化来避免过拟合。混合架构（CNN-LSTM、Transformer+GARCH）往往比单一架构更稳健。在实践中，深度学习模型应与 GBDT 基准进行严格对比——如果深度模型的 IC 提升不显著且增加了大量工程复杂度，GBDT 仍是更实用的选择。
