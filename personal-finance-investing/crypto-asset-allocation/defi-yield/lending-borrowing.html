借贷协议

DeFi 借贷的基本机制

去中心化借贷协议允许用户在无需信任中介的情况下进行加密资产的存款和借款。与传统银行不同，DeFi 借贷完全由智能合约驱动，利率由算法根据供需动态决定。

核心参与者

角色 行为 动机
存款人（Lender） 存入资产至流动池 获取存款利息
借款人（Borrower） 超额抵押后借出资产 做多/做空、杠杆、流动性需求
清算人（Liquidator） 清算健康因子不足的仓位 获取清算折扣（通常 5-10%）
协议（Protocol） 设定参数、收取费用 协议收入（存借利差 + 清算费）

超额抵押模型

DeFi 借贷的核心约束：所有借款必须超额抵押。这意味着借款人存入的抵押品价值必须始终高于借款价值。

\text{抵押率} = \frac{\text{抵押品价值}}{\text{借款价值}} > \text{最低抵押率（通常 110-150%）}

示例：

  • 存入 1 ETH（价值 $2,000）作为抵押
  • 最大借款额度（LTV 75%）= $1,500 等值的 USDC
  • 清算阈值（Liquidation Threshold）= 82.5%
  • 当 ETH 跌至使抵押率降至 82.5% 时触发清算

主要借贷协议对比

Aave

Aave 是最大的多链借贷协议，支持以太坊、Polygon、Arbitrum、Optimism 等多链部署：

特性 详情
TVL ~150 亿美元（2026年初）
支持资产 100+ 种
利率模型 分段线性利率（Kinked Rate）
治理 AAVE 代币，通过 Aave DAO
闪电贷 支持（单交易内无抵押借款）
创新 GHO 稳定币、信用委托

Compound

Compound 是 DeFi 借贷的先驱，设计简洁：

特性 详情
TVL ~50 亿美元
版本 Compound V3（Comet）单资产市场
利率模型 分段利率曲线
特点 V3 采用「Base Asset」模型——每个市场只借一种资产

Morpho

Morpho 代表了新一代借贷协议的设计思路——点对点匹配优化：

特性 详情
TVL ~30 亿美元
创新 在 Aave/Compound 之上做点对点利率优化
逻辑 将存款人和借款人直接匹配，消除利差
效果 存款人获得更高利率，借款人支付更低利率 
利率模型详解
分段线性利率（Kinked Rate Model）
Aave 和 Compound 使用的核心利率模型——以「最优利用率」为拐点的分段函数：


利用率 < 最优利用率（通常 80%）： 


Rborrow=Rbase+UUoptimal×Rslope1R_{borrow} = R_{base} + \frac{U}{U_{optimal}} \times R_{slope1}Rborrow​=Rbase​+Uoptimal​U​×Rslope1​
利用率 > 最优利用率： 


Rborrow=Rbase+Rslope1+U−Uoptimal1−Uoptimal×Rslope2R_{borrow} = R_{base} + R_{slope1} + \frac{U - U_{optimal}}{1 - U_{optimal}} \times R_{slope2}Rborrow​=Rbase​+Rslope1​+1−Uoptimal​U−Uoptimal​​×Rslope2​
其中：


    

  • UUU = 利用率 = 总借款 / 总存款
    • 

  • RbaseR_{base}Rbase​ = 基础利率（通常 0-2%）
    • 

  • Rslope1R_{slope1}Rslope1​ = 低利用率斜率（温和上升）
    • 

  • Rslope2R_{slope2}Rslope2​ = 高利用率斜率（急剧上升，惩罚性）
    •

这意味着：


    

  • 利用率 50% → 借款利率 ≈ 2.5%
    • 

  • 利用率 80% → 借款利率 ≈ 4%
    • 

  • 利用率 90% → 借款利率 ≈ 34%（急剧惩罚）
    • 

  • 利用率 95% → 借款利率 ≈ 49%
    • 



设计意图：通过惩罚性高利率激励借款人还款，确保存款人始终能提取资金。


清算机制与风险
清算触发条件
Health Factor=抵押品价值×清算阈值借款价值<1\text{Health Factor} = \frac{\text{抵押品价值} \times \text{清算阈值}}{\text{借款价值}} < 1Health Factor=借款价值抵押品价值×清算阈值​<1
Health Factor 降至 1 以下时，任何人都可以代偿部分债务并获取折价抵押品。


清算的连锁效应
极端市场下的清算级联是 DeFi 最大的系统性风险：


    

  1. 价格大幅下跌
    2. 

  2. 大量仓位 Health Factor < 1
    3. 

  3. 清算人抛售获得的抵押品
    4. 

  4. 进一步打压价格
    5. 

  5. 更多仓位被清算
    6. 

  6. 形成正反馈死亡螺旋
    7. 



历史案例：


    

  • 2022 年 LUNA 崩盘：引发超过 20 亿美元的连锁清算
    • 

  • 2022 年 stETH 脱锚：三箭资本 (3AC) 的杠杆仓位被清算
    • 



清算保护策略
    

  1. 保持低 LTV：借款不超过最大额度的 50%（即使协议允许 75%）
    2. 

  2. 使用稳定资产借贷：抵押 ETH 借 USDC，而非抵押波动资产借波动资产
    3. 

  3. 设置价格警报：当 Health Factor 降至 1.5 时收到通知
    4. 

  4. 准备追加抵押品：保持流动性资金用于紧急追加
    5. 

  5. 分散协议风险：不在单一协议中集中所有借贷仓位
    6. 



循环借贷放大收益
策略原理
循环借贷（Recursive Borrowing / Looping）是通过反复存入-借出-再存入来放大敞口和收益的策略：


收益数学
假设：


    

  • 存款 APY = 5%
    • 

  • 借款 APY = 3%
    • 

  • LTV = 75%
    • 

  • 循环 n 次
    • 



有效存款量：Deff=D×11−LTV=D×4D_{eff} = D \times \frac{1}{1 - LTV} = D \times 4Deff​=D×1−LTV1​=D×4（极限值）


净收益率：(存款利率−借款利率×LTV)×杠杆倍数(存款利率 - 借款利率 \times LTV) \times 杠杆倍数(存款利率−借款利率×LTV)×杠杆倍数


= (5%−3%×75%)×4=(5%−2.25%)×4=11%(5\% - 3\% \times 75\%) \times 4 = (5\% - 2.25\%) \times 4 = 11\%(5%−3%×75%)×4=(5%−2.25%)×4=11%


看起来诱人，但风险极高：


循环借贷的风险
    

  1. 利率风险：借款利率可能突然飙升（利用率达到拐点），净收益变负
    2. 

  2. 清算风险：高杠杆意味着极小的价格波动就可能触发清算
    3. 

  3. 协议风险：智能合约漏洞在高杠杆下损失被放大
    4. 

  4. Gas 费吞噬：维护多层循环需要频繁的链上操作
    5. 

  5. 退出流动性：极端情况下利用率达 100%，无法提取存款
    6. 



适用场景：仅适合使用稳定币对（如存 USDC 借 USDT，无价格风险）且利差稳定的情况。不建议对波动资产使用循环借贷。

评估借贷协议安全性的清单
    

  •  协议是否经过多家审计公司审计？
    • 

  •  TVL 规模和运行时间（越大越久 = 经受更多考验）
    • 

  •  是否有漏洞赏金计划（Bug Bounty）？额度多大？
    • 

  •  治理权力是否过度集中（多签、时间锁）？
    • 

  •  预言机来源（Chainlink 为首选，自建预言机风险高）？
    • 

  •  是否有坏账保险基金？规模是否足够？
    • 

  •  代码是否开源？是否可验证？
    • 



实操建议
存款端（赚取利息）
    

  1. 首选蓝筹协议：Aave V3、Compound V3 在安全性和流动性上最优
    2. 

  2. 分散存款：不要将所有资金存入单一协议
    3. 

  3. 关注真实利率：稳定币存款利率在 2-8% 区间波动，牛市更高
    4. 

  4. 注意利用率：如果利用率长期 >90%，存款人可能面临取款延迟
    5. 



借款端（使用杠杆）
    

  1. 保守 LTV：不超过最大 LTV 的 50-60%
    2. 

  2. 同类资产借贷：抵押 stETH 借 ETH（价格高度相关，清算风险极低）
    3. 

  3. 监控 Health Factor：设置 1.5 以下的自动提醒
    4. 

  4. 有明确还款计划：不要「借了就忘」，利息会持续累积
    5. 

  5. 考虑 Morpho 优化：可获得比直接使用 Aave 更优的利率
    6.
