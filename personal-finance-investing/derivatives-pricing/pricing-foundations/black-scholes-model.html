Black-Scholes 模型与解析解

概述

Black-Scholes 模型是现代金融学最具影响力的理论成果之一。1973 年，Fischer Black 和 Myron Scholes 发表了欧式期权定价公式，Robert Merton 同期独立给出了严格的数学推导。这一成果不仅为期权市场的爆发式增长提供了理论基石，也开创了量化金融的时代。Scholes 和 Merton 因此获得 1997 年诺贝尔经济学奖（Black 已于 1995 年去世）。

本文从模型假设出发，通过两条路径——PDE 方法和风险中性定价方法——推导 Black-Scholes 公式，分析 Greeks 参数，讨论模型的局限性与实际应用。

模型假设

Black-Scholes 模型建立在以下关键假设之上：

假设 描述 现实偏差
几何布朗运动 dSt=μSt dt+σSt dWtdS_t = \mu S_t \, dt + \sigma S_t \, dW_tdSt​=μSt​dt+σSt​dWt​ 收益率存在尖峰厚尾
常数波动率 σ\sigmaσ 不随时间或价格变化 隐含波动率存在微笑
无风险利率恒定 rrr 为常数 利率期限结构非平坦
无交易成本 没有佣金、滑点 实际存在买卖价差
无股息 标的资产不支付股息 多数股票支付股息
连续交易 可在任意时刻交易 市场存在停牌、休市
无卖空限制 可自由卖空 卖空需要保证金
市场无摩擦 无税收、无保证金要求 实际存在多种摩擦

尽管假设高度理想化，Black-Scholes 模型仍然是所有更复杂模型的出发点和基准。

Python 实现

import numpy as np
from scipy.stats import norm

def black_scholes(S, K, T, r, sigma, option_type='call'):
    """
    Black-Scholes 欧式期权定价
    S: 当前股价, K: 行权价, T: 到期时间（年）
    r: 无风险利率, sigma: 波动率
    """
    d1 = (np.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)

    if option_type == 'call':
        price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
    else:
        price = K * np.exp(-r * T) * norm.cdf(-d2) - S * norm.cdf(-d1)

    return price

S, K, T, r, sigma = 100, 100, 1.0, 0.05, 0.2
call_price = black_scholes(S, K, T, r, sigma, 'call')
put_price = black_scholes(S, K, T, r, sigma, 'put')

print(f"Call: {call_price:.4f}")
print(f"Put:  {put_price:.4f}")
print(f"Put-Call Parity 验证: C - P = {call_price - put_price:.4f}")
print(f"S - K*exp(-rT) = {S - K * np.exp(-r * T):.4f}")

Greeks 计算实现
import numpy as np
from scipy.stats import norm

def bs_greeks(S, K, T, r, sigma, option_type='call'):
    """计算 Black-Scholes Greeks"""
    d1 = (np.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    n_d1 = norm.pdf(d1)

    gamma = n_d1 / (S * sigma * np.sqrt(T))
    vega = S * np.sqrt(T) * n_d1

    if option_type == 'call':
        delta = norm.cdf(d1)
        theta = (-S * n_d1 * sigma / (2 * np.sqrt(T))
                 - r * K * np.exp(-r * T) * norm.cdf(d2))
        rho = K * T * np.exp(-r * T) * norm.cdf(d2)
    else:
        delta = norm.cdf(d1) - 1
        theta = (-S * n_d1 * sigma / (2 * np.sqrt(T))
                 + r * K * np.exp(-r * T) * norm.cdf(-d2))
        rho = -K * T * np.exp(-r * T) * norm.cdf(-d2)

    return {
        'delta': delta, 'gamma': gamma,
        'theta': theta, 'vega': vega, 'rho': rho
    }

greeks = bs_greeks(100, 100, 1.0, 0.05, 0.2, 'call')
for name, value in greeks.items():
    print(f"{name:>6s}: {value:+.6f}")
含股息的扩展
连续股息率模型
若标的资产支付连续股息率 qqq，则 Black-Scholes 公式修改为（Merton, 1973）：


C=Se−qTN(d1)−Ke−rTN(d2)C = Se^{-qT} N(d_1) - Ke^{-rT} N(d_2)C=Se−qTN(d1​)−Ke−rTN(d2​)
d1=ln⁡(S/K)+(r−q+σ2/2)TσT,d2=d1−σTd_1 = \frac{\ln(S/K) + (r - q + \sigma^2/2)T}{\sigma\sqrt{T}}, \quad d_2 = d_1 - \sigma\sqrt{T}d1​=σT​ln(S/K)+(r−q+σ2/2)T​,d2​=d1​−σT​
股息的效果是将股价折现为 Se−qTSe^{-qT}Se−qT，反映了持有标的资产的收益。


离散股息处理
对于支付已知离散股息 DiD_iDi​（在时刻 tit_iti​ 支付）的标的资产，常用方法是将股价调整为：


S∗=S−∑i:ti≤TDie−rtiS^* = S - \sum_{i: t_i \leq T} D_i e^{-r t_i}S∗=S−i:ti​≤T∑​Di​e−rti​
然后对 S∗S^*S∗ 应用标准 Black-Scholes 公式。

波动率微笑
Black-Scholes 模型假设常数波动率，但市场隐含波动率呈现"微笑"或"偏斜"形态：

其他局限性
    

  • 尖峰厚尾：实际收益率分布相比正态分布具有更高的峰度和更厚的尾部
    • 

  • 跳跃风险：资产价格可能出现不连续的跳跃（如 Merton 跳跃扩散模型）
    • 

  • 交易成本：频繁的 Delta 对冲在实际中成本高昂
    • 

  • 流动性风险：深度虚值期权流动性不足，买卖价差大
    • 



尽管存在这些局限，Black-Scholes 模型仍然是实务中的标准基准：交易员通常使用 Black-Scholes 框架，但将波动率作为输入参数从市场价格中反推（隐含波动率），而非使用历史波动率。


隐含波动率
定义
隐含波动率（Implied Volatility, IV）是使 Black-Scholes 公式的理论价格等于市场观察价格的波动率参数：


VBS(S,K,T,r,σIV)=VmarketV_{BS}(S, K, T, r, \sigma_{IV}) = V_{market}VBS​(S,K,T,r,σIV​)=Vmarket​
由于 Black-Scholes 价格关于 σ\sigmaσ 严格单调递增，IV 唯一存在。


Newton-Raphson 求解
import numpy as np
from scipy.stats import norm

def implied_volatility(market_price, S, K, T, r, option_type='call',
                       tol=1e-8, max_iter=100):
    """Newton-Raphson 求解隐含波动率"""
    sigma = 0.2

    for _ in range(max_iter):
        d1 = (np.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
        d2 = d1 - sigma * np.sqrt(T)

        if option_type == 'call':
            price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
        else:
            price = K * np.exp(-r * T) * norm.cdf(-d2) - S * norm.cdf(-d1)

        vega = S * np.sqrt(T) * norm.pdf(d1)

        if vega < 1e-12:
            break

        sigma = sigma - (price - market_price) / vega

        if abs(price - market_price) < tol:
            return sigma

    return sigma

iv = implied_volatility(10.45, 100, 100, 1.0, 0.05, 'call')
print(f"隐含波动率: {iv:.4f} ({iv*100:.2f}%)")
总结
Black-Scholes 模型通过几何布朗运动假设、Delta 对冲论证和无套利条件，推导出欧式期权的封闭解析解。公式的优雅之处在于：期权价格仅依赖五个可观测参数（SSS, KKK, TTT, rrr, σ\sigmaσ），且不包含投资者的风险偏好。Greeks 参数体系为风险管理提供了精确的量化工具。虽然常数波动率假设在实际市场中不成立（波动率微笑的普遍存在），但 Black-Scholes 框架作为定价基准和隐含波动率的"语言"，至今仍是衍生品市场最重要的定价工具。
