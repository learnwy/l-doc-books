随机微积分基础：布朗运动与伊藤引理

概述

随机微积分（Stochastic Calculus）是衍生品定价的数学语言。与确定性微积分不同，随机微积分处理的是具有随机性的连续时间过程。其核心工具包括：布朗运动（Brownian Motion）作为随机性的基本驱动源，伊藤积分（Itô Integral）作为随机过程的积分理论，以及伊藤引理（Itô's Lemma）作为随机微积分的链式法则。本文从布朗运动的定义与性质出发，逐步建立伊藤积分和伊藤引理的完整框架，为后续 Black-Scholes 模型的推导奠定数学基础。

布朗运动

定义与基本性质

布朗运动（也称 Wiener 过程）W={Wt,t≥0}W = \{W_t, t \geq 0\}W={Wt​,t≥0} 是满足以下四个条件的随机过程：

  1. W0=0W_0 = 0W0​=0（从原点出发）
  2. 独立增量：对 0≤s<t0 \leq s < t0≤s<t，Wt−WsW_t - W_sWt​−Ws​ 独立于 {Wu,0≤u≤s}\{W_u, 0 \leq u \leq s\}{Wu​,0≤u≤s}
  3. 正态增量：Wt−Ws∼N(0,t−s)W_t - W_s \sim N(0, t-s)Wt​−Ws​∼N(0,t−s)
  4. 路径连续：t↦Wtt \mapsto W_tt↦Wt​ 几乎处处连续

关键性质

布朗运动具有若干深刻的数学性质：

| 性质 | 描述 | 数学表达 | | ----------- | ------------------ | ------------------------------------------ | --- | ---------------- | | 鞅性 | 布朗运动是鞅 | E[Wt∣Fs]=Ws\mathbb{E}[W_t \mid \mathcal{F}_s] = W_sE[Wt​∣Fs​]=Ws​ | | 二次变差 | 二次变差等于时间 | ⟨W⟩t=t\langle W \rangle_t = t⟨W⟩t​=t | | 自相似性 | 时间缩放不变 | {cWt/c2}=d{Wt}\{cW_{t/c^2}\} \overset{d}{=} \{W_t\}{cWt/c2​}=d{Wt​} | | 处处不可微 | 路径几乎处处不可微 | P(W 在任意点可微)=0P(\text{W 在任意点可微}) = 0P(W 在任意点可微)=0 | | Hölder 连续 | 指数至多 1/2 | ∥Wt−Ws∥≤C∣t−s∣1/2−ϵ\|W_t - W_s\| \leq C | t-s | ^{1/2-\epsilon}∥Wt​−Ws​∥≤C∣t−s∣1/2−ϵ |

处处不可微这一性质是随机微积分不同于经典微积分的根本原因——我们不能对布朗运动做逐点求导，必须发展新的积分理论。

二次变差

布朗运动最特殊的性质之一是其二次变差（Quadratic Variation）。对于区间 [0,T][0, T][0,T] 的分割 0=t0<t1<⋯<tn=T0 = t_0 < t_1 < \cdots < t_n = T0=t0​<t1​<⋯<tn​=T：

⟨W⟩T=lim⁡n→∞∑i=0n−1(Wti+1−Wti)2=T\langle W \rangle_T = \lim_{n \to \infty} \sum_{i=0}^{n-1} (W_{t_{i+1}} - W_{t_i})^2 = T⟨W⟩T​=n→∞lim​i=0∑n−1​(Wti+1​​−Wti​​)2=T

这个极限在 L2L^2L2 和几乎处处的意义下成立。直觉上，布朗运动的"波动幅度"以 dt\sqrt{dt}dt​ 的速率积累，因此二次变差为有限值。这导致了伊藤微积分与经典微积分的关键差异。

形式记号：

dWt⋅dWt=dt,dWt⋅dt=0,dt⋅dt=0dW_t \cdot dW_t = dt, \quad dW_t \cdot dt = 0, \quad dt \cdot dt = 0dWt​⋅dWt​=dt,dWt​⋅dt=0,dt⋅dt=0

Python 模拟布朗运动

import numpy as np
import matplotlib.pyplot as plt

def simulate_brownian_motion(T=1.0, n_steps=1000, n_paths=5, seed=42):
    """模拟多条布朗运动路径"""
    np.random.seed(seed)
    dt = T / n_steps
    t = np.linspace(0, T, n_steps + 1)

    paths = np.zeros((n_paths, n_steps + 1))
    for i in range(n_paths):
        dW = np.random.normal(0, np.sqrt(dt), n_steps)
        paths[i, 1:] = np.cumsum(dW)

    return t, paths

def verify_quadratic_variation(T=1.0, n_steps=10000, seed=42):
    """验证二次变差收敛到 T"""
    np.random.seed(seed)
    dt = T / n_steps
    dW = np.random.normal(0, np.sqrt(dt), n_steps)
    W = np.concatenate([[0], np.cumsum(dW)])

    qv = np.sum(dW**2)
    print(f"期望二次变差: {T:.4f}")
    print(f"实际二次变差: {qv:.4f}")
    print(f"相对误差: {abs(qv - T) / T * 100:.2f}%")

t, paths = simulate_brownian_motion()
verify_quadratic_variation()

几何布朗运动

定义

金融模型中，资产价格通常建模为几何布朗运动（Geometric Brownian Motion, GBM）：

dSt=μSt dt+σSt dWtdS_t = \mu S_t \, dt + \sigma S_t \, dW_tdSt​=μSt​dt+σSt​dWt​

其中 μ\muμ 为漂移率（期望收益率），σ\sigmaσ 为波动率。GBM 保证价格 St>0S_t > 0St​>0，符合金融直觉。

对数价格过程

设 Xt=ln⁡StX_t = \ln S_tXt​=lnSt​，利用伊藤引理（下文推导），可得：

dXt=(μ−σ22)dt+σ dWtdX_t = \left(\mu - \frac{\sigma^2}{2}\right) dt + \sigma \, dW_tdXt​=(μ−2σ2​)dt+σdWt​

这是一个带漂移的布朗运动，解为：

Xt=X0+(μ−σ22)t+σWtX_t = X_0 + \left(\mu - \frac{\sigma^2}{2}\right)t + \sigma W_tXt​=X0​+(μ−2σ2​)t+σWt​

因此 GBM 的解为：

St=S0exp⁡[(μ−σ22)t+σWt]S_t = S_0 \exp\left[\left(\mu - \frac{\sigma^2}{2}\right)t + \sigma W_t\right]St​=S0​exp[(μ−2σ2​)t+σWt​]

STS_TST​ 服从对数正态分布：ln⁡ST∼N(ln⁡S0+(μ−σ2/2)T, σ2T)\ln S_T \sim N\left(\ln S_0 + (\mu - \sigma^2/2)T, \, \sigma^2 T\right)lnST​∼N(lnS0​+(μ−σ2/2)T,σ2T)。

注意 μ−σ2/2\mu - \sigma^2/2μ−σ2/2 而非 μ\muμ 出现在指数中——这个修正项正是伊藤引理带来的，反映了 Jensen 不等式在凸函数和随机变量之间的关系。

伊藤积分

构造动机

对于光滑函数 fff，经典 Riemann-Stieltjes 积分 ∫0Tf(t) dg(t)\int_0^T f(t) \, dg(t)∫0T​f(t)dg(t) 对光滑被积函数 ggg 是良定义的。但布朗运动路径处处不可微，具有无穷变差，经典积分理论失效。

伊藤积分通过以下步骤构造：

  1. 对简单过程（分段常值）定义积分
  2. 利用 L2L^2L2 逼近推广到一般适应过程

定义

设 HtH_tHt​ 是关于布朗运动信息流 {Ft}\{\mathcal{F}_t\}{Ft​} 适应的随机过程，满足 E[∫0THt2 dt]<∞\mathbb{E}\left[\int_0^T H_t^2 \, dt\right] < \inftyE[∫0T​Ht2​dt]<∞。伊藤积分定义为：

I(H)=∫0THt dWt=lim⁡n→∞∑i=0n−1Hti(Wti+1−Wti)I(H) = \int_0^T H_t \, dW_t = \lim_{n \to \infty} \sum_{i=0}^{n-1} H_{t_i}(W_{t_{i+1}} - W_{t_i})I(H)=∫0T​Ht​dWt​=n→∞lim​i=0∑n−1​Hti​​(Wti+1​​−Wti​​)

关键特征：被积函数取左端点 HtiH_{t_i}Hti​​ 的值，这保证了积分的非预见性（non-anticipating）。

伊藤积分的核心性质

伊藤等距（Itô Isometry）：

E[(∫0THt dWt)2]=E[∫0THt2 dt]\mathbb{E}\left[\left(\int_0^T H_t \, dW_t\right)^2\right] = \mathbb{E}\left[\int_0^T H_t^2 \, dt\right]E​(∫0T​Ht​dWt​)2​=E[∫0T​Ht2​dt]

鞅性：

Mt=∫0tHs dWs 是鞅M_t = \int_0^t H_s \, dW_s \text{ 是鞅}Mt​=∫0t​Hs​dWs​ 是鞅

即 E[Mt∣Fs]=Ms\mathbb{E}[M_t \mid \mathcal{F}_s] = M_sE[Mt​∣Fs​]=Ms​，特别地 E[Mt]=0\mathbb{E}[M_t] = 0E[Mt​]=0。

与 Stratonovich 积分的区别：

Stratonovich 积分取中点值 H(ti+ti+1)/2H_{(t_i+t_{i+1})/2}H(ti​+ti+1​)/2​，满足经典链式法则，但不是鞅。两者的关系：

∫0THt∘dWt=∫0THt dWt+12∫0THt′ dt\int_0^T H_t \circ dW_t = \int_0^T H_t \, dW_t + \frac{1}{2}\int_0^T H_t' \, dt∫0T​Ht​∘dWt​=∫0T​Ht​dWt​+21​∫0T​Ht′​dt

金融中几乎总是使用伊藤积分，因为其鞅性与无套利定价的联系更为自然。

伊藤引理

一维伊藤引理

伊藤引理是随机微积分的链式法则，也是推导衍生品定价方程的核心工具。

设 XtX_tXt​ 满足随机微分方程：

Euler-Maruyama 数值求解

import numpy as np

def euler_maruyama(mu_func, sigma_func, x0, T, n_steps, n_paths=1000, seed=42):
    """
    Euler-Maruyama 方法求解 SDE
    dX_t = mu(t, X_t) dt + sigma(t, X_t) dW_t
    """
    np.random.seed(seed)
    dt = T / n_steps
    sqrt_dt = np.sqrt(dt)
    t = np.linspace(0, T, n_steps + 1)

    X = np.zeros((n_paths, n_steps + 1))
    X[:, 0] = x0

    for i in range(n_steps):
        dW = np.random.normal(0, sqrt_dt, n_paths)
        X[:, i+1] = (X[:, i]
                      + mu_func(t[i], X[:, i]) * dt
                      + sigma_func(t[i], X[:, i]) * dW)

    return t, X

mu_gbm = lambda t, S: 0.05 * S
sigma_gbm = lambda t, S: 0.2 * S
t, S = euler_maruyama(mu_gbm, sigma_gbm, x0=100, T=1, n_steps=252)

print(f"S_T 均值: {S[:, -1].mean():.2f}")
print(f"S_T 标准差: {S[:, -1].std():.2f}")
print(f"理论均值: {100 * np.exp(0.05):.2f}")

鞅表示定理与 Feynman-Kac 公式
