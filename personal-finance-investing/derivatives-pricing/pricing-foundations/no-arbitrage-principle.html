无套利原理与风险中性定价

概述

无套利原理（No-Arbitrage Principle）是现代衍生品定价理论的基石。它断言在一个有效市场中，不存在无风险获利的机会——如果两个投资组合在未来产生完全相同的现金流，那么它们今天的价格必须相同。这个看似简单的原则，结合风险中性定价（Risk-Neutral Pricing）的数学框架，构成了从 Black-Scholes 公式到最复杂的奇异衍生品定价的统一逻辑基础。

本文从经济直觉出发，逐步建立无套利条件的数学形式化表述，推导风险中性测度的存在性与唯一性，并展示如何利用风险中性期望对衍生品进行定价。

套利与无套利条件

套利的定义

在金融学中，套利（Arbitrage）指的是满足以下三个条件的交易策略：

  1. 零初始投资：不需要任何净资本投入
  2. 无下行风险：未来的收益在任何状态下都不为负
  3. 正收益可能：至少在某些状态下获得正收益

用数学语言表述，设 V0V_0V0​ 为策略的初始成本，VTV_TVT​ 为到期收益，套利策略满足：

V0=0,P(VT≥0)=1,P(VT>0)>0V_0 = 0, \quad P(V_T \geq 0) = 1, \quad P(V_T > 0) > 0V0​=0,P(VT​≥0)=1,P(VT​>0)>0

一价定律

无套利条件的直接推论是一价定律（Law of One Price）：

如果两个资产（或组合）在未来所有状态下产生完全相同的现金流，则它们当前的价格必须相同。

假设资产 AAA 和 BBB 满足 VTA=VTBV_T^A = V_T^BVTA​=VTB​（几乎处处），但 V0A<V0BV_0^A < V_0^BV0A​<V0B​，则可以构造套利：买入 AAA、卖空 BBB，净收入 V0B−V0A>0V_0^B - V_0^A > 0V0B​−V0A​>0，到期时净头寸为零。

无套利条件的等价形式

在离散模型中，无套利条件可以等价表述为以下几种形式：

表述 数学形式 含义
直接定义 不存在满足套利三条件的策略 市场没有"免费午餐"
一价定律 相同收益 → 相同价格 定价的一致性
正线性定价 存在正的线性定价算子 任何正收益的价格为正
等价鞅测度 存在等价概率测度使折现价格为鞅 资产定价基本定理

资产定价基本定理

第一基本定理

资产定价第一基本定理（First Fundamental Theorem of Asset Pricing）建立了无套利与等价鞅测度之间的深刻联系：

市场无套利   ⟺  \iff⟺ 存在等价鞅测度 Q\mathbb{Q}Q，使得所有折现资产价格在 Q\mathbb{Q}Q 下为鞅。

设 Bt=ertB_t = e^{rt}Bt​=ert 为无风险资产（以连续复利率 rrr 增长），StS_tSt​ 为风险资产价格。折现价格定义为：

S~t=StBt=Ste−rt\tilde{S}_t = \frac{S_t}{B_t} = S_t e^{-rt}S~t​=Bt​St​​=St​e−rt

等价鞅测度 Q\mathbb{Q}Q 满足：

S~t=EQ[S~T∣Ft],∀t≤T\tilde{S}_t = \mathbb{E}^{\mathbb{Q}}[\tilde{S}_T \mid \mathcal{F}_t], \quad \forall t \leq TS~t​=EQ[S~T​∣Ft​],∀t≤T

即折现价格在 Q\mathbb{Q}Q 下是鞅（Martingale）。

第二基本定理

资产定价第二基本定理处理市场完备性：

市场完备（任何衍生品都可以通过基础资产复制）   ⟺  \iff⟺ 等价鞅测度 Q\mathbb{Q}Q 唯一。

市场完备意味着每个或有索取权（Contingent Claim）都有唯一的无套利价格。

风险中性定价
核心思想
风险中性定价的核心思想是：在等价鞅测度 Q\mathbb{Q}Q 下，所有资产的期望收益率都等于无风险利率 rrr。这并不意味着投资者真的是风险中性的，而是通过测度变换，将风险溢价"吸收"到概率测度中。


衍生品在时刻 ttt 的价格为：


Vt=e−r(T−t)EQ[VT∣Ft]V_t = e^{-r(T-t)} \mathbb{E}^{\mathbb{Q}}[V_T \mid \mathcal{F}_t]Vt​=e−r(T−t)EQ[VT​∣Ft​]
即到期收益在风险中性测度下的折现期望。


离散模型示例：二叉树
考虑单期二叉树模型，股票当前价格 S0S_0S0​，一期后上涨至 Su=uS0S_u = uS_0Su​=uS0​ 或下跌至 Sd=dS0S_d = dS_0Sd​=dS0​，无风险利率为 rrr。


风险中性概率 qqq 由下式确定：


S0=11+r[q⋅Su+(1−q)⋅Sd]S_0 = \frac{1}{1+r}[q \cdot S_u + (1-q) \cdot S_d]S0​=1+r1​[q⋅Su​+(1−q)⋅Sd​]
解得：


q=(1+r)−du−dq = \frac{(1+r) - d}{u - d}q=u−d(1+r)−d​
无套利条件要求 d<1+r<ud < 1+r < ud<1+r<u，确保 0<q<10 < q < 10<q<1。


期权价格为：


C0=11+r[q⋅Cu+(1−q)⋅Cd]C_0 = \frac{1}{1+r}[q \cdot C_u + (1-q) \cdot C_d]C0​=1+r1​[q⋅Cu​+(1−q)⋅Cd​]
其中 CuC_uCu​、CdC_dCd​ 为期权在上涨和下跌状态的收益。


Python 实现：二叉树风险中性定价
import numpy as np

def binomial_risk_neutral_price(S0, K, r, u, d, n, option_type='call'):
    """
    多期二叉树风险中性定价
    S0: 初始股价, K: 行权价, r: 无风险利率
    u: 上涨因子, d: 下跌因子, n: 期数
    """
    dt = 1.0 / n
    q = (np.exp(r * dt) - d) / (u - d)

    stock_prices = np.zeros(n + 1)
    for j in range(n + 1):
        stock_prices[j] = S0 * (u ** (n - j)) * (d ** j)

    if option_type == 'call':
        option_values = np.maximum(stock_prices - K, 0)
    else:
        option_values = np.maximum(K - stock_prices, 0)

    for i in range(n - 1, -1, -1):
        for j in range(i + 1):
            option_values[j] = np.exp(-r * dt) * (
                q * option_values[j] + (1 - q) * option_values[j + 1]
            )

    return option_values[0]

S0, K, r = 100, 100, 0.05
u, d, n = 1.1, 0.9, 50
call_price = binomial_risk_neutral_price(S0, K, r, u, d, n, 'call')
put_price = binomial_risk_neutral_price(S0, K, r, u, d, n, 'put')
print(f"Call: {call_price:.4f}, Put: {put_price:.4f}")
测度变换与 Girsanov 定理
Radon-Nikodym 导数
两个等价概率测度之间的变换通过 Radon-Nikodym 导数 实现。设 P\mathbb{P}P 为真实概率测度，Q\mathbb{Q}Q 为风险中性测度，则存在随机变量 Z=dQdPZ = \frac{d\mathbb{Q}}{d\mathbb{P}}Z=dPdQ​，满足：


EQ[X]=EP[ZX]\mathbb{E}^{\mathbb{Q}}[X] = \mathbb{E}^{\mathbb{P}}[ZX]EQ[X]=EP[ZX]
其中 Z>0Z > 0Z>0 几乎处处，且 EP[Z]=1\mathbb{E}^{\mathbb{P}}[Z] = 1EP[Z]=1。


Girsanov 定理
在连续时间框架中，Girsanov 定理给出了测度变换的具体机制。设在 P\mathbb{P}P 下 WtW_tWt​ 是标准布朗运动，定义：


Zt=exp⁡(−∫0tθs dWs−12∫0tθs2 ds)Z_t = \exp\left(-\int_0^t \theta_s \, dW_s - \frac{1}{2}\int_0^t \theta_s^2 \, ds\right)Zt​=exp(−∫0t​θs​dWs​−21​∫0t​θs2​ds)
其中 θt\theta_tθt​ 为市场风险价格（Market Price of Risk）。则在新测度 Q\mathbb{Q}Q（由 ZTZ_TZT​ 定义）下：


W~t=Wt+∫0tθs ds\tilde{W}_t = W_t + \int_0^t \theta_s \, dsW~t​=Wt​+∫0t​θs​ds
是标准布朗运动。


对于 Black-Scholes 模型，股票价格满足：


dSt=μSt dt+σSt dWt(在 P 下)dS_t = \mu S_t \, dt + \sigma S_t \, dW_t \quad (\text{在 } \mathbb{P} \text{ 下})dSt​=μSt​dt+σSt​dWt​(在 P 下)
市场风险价格为 θ=μ−rσ\theta = \frac{\mu - r}{\sigma}θ=σμ−r​，测度变换后：


dSt=rSt dt+σSt dW~t(在 Q 下)dS_t = r S_t \, dt + \sigma S_t \, d\tilde{W}_t \quad (\text{在 } \mathbb{Q} \text{ 下})dSt​=rSt​dt+σSt​dW~t​(在 Q 下)
漂移项由真实收益率 μ\muμ 变为无风险利率 rrr。


复制与对冲
动态复制策略
在完备市场中，任何衍生品都可以通过基础资产和无风险资产的动态交易策略完美复制。设衍生品价格为 V(t,St)V(t, S_t)V(t,St​)，复制组合持有 Δt\Delta_tΔt​ 份股票和 Φt\Phi_tΦt​ 份债券：


V(t,St)=ΔtSt+ΦtBtV(t, S_t) = \Delta_t S_t + \Phi_t B_tV(t,St​)=Δt​St​+Φt​Bt​
其中 Δt=∂V∂S\Delta_t = \frac{\partial V}{\partial S}Δt​=∂S∂V​ 就是 Delta 对冲比率。


自融资策略
复制策略必须是自融资（Self-Financing）的，即组合价值的变化完全来自资产价格变动，不需要额外注入或撤出资金：


dVt=Δt dSt+Φt dBtdV_t = \Delta_t \, dS_t + \Phi_t \, dB_tdVt​=Δt​dSt​+Φt​dBt​
自融资条件是推导 Black-Scholes 偏微分方程的关键约束。

无套利在实践中的应用
期货平价关系
无套利原理的经典应用之一是期货的持有成本模型：


F0=S0e(r−q)TF_0 = S_0 e^{(r-q)T}F0​=S0​e(r−q)T
其中 qqq 为连续股息率。如果期货价格偏离此公式，则存在套利机会。


Put-Call Parity
欧式看涨期权 CCC 与看跌期权 PPP 之间满足：


C−P=S0e−qT−Ke−rTC - P = S_0 e^{-qT} - K e^{-rT}C−P=S0​e−qT−Ke−rT
这个平价关系可以直接由无套利条件推导。如果市场上观察到违反 Put-Call Parity 的价格，可以构造无风险套利。

这些摩擦意味着：无套利定价给出的是一个价格区间而非精确点，衍生品的市场价格通常在理论价格附近波动。


总结
无套利原理与风险中性定价构成了衍生品定价理论的两大支柱。无套利条件通过资产定价基本定理与等价鞅测度的存在性联系起来，风险中性定价公式 Vt=e−r(T−t)EQ[VT]V_t = e^{-r(T-t)} \mathbb{E}^{\mathbb{Q}}[V_T]Vt​=e−r(T−t)EQ[VT​] 提供了计算任意衍生品价格的统一框架。Girsanov 定理给出了从真实概率到风险中性概率的具体转换机制，而复制与对冲策略则从交易层面验证了定价的合理性。理解这些基础概念，是掌握后续所有定价模型与数值方法的前提。
