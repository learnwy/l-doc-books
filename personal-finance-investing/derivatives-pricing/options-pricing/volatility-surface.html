波动率曲面与微笑

概述

在 Black-Scholes 框架中，波动率 σ\sigmaσ 被假设为常数。然而，市场实践揭示了一个系统性偏差：从不同行权价和到期日的期权价格中反推出的隐含波动率并不相同，而是呈现出依赖于行权价（波动率微笑/偏斜）和到期日（期限结构）的二维曲面。这个波动率曲面（Volatility Surface）是衍生品定价与风险管理的核心市场数据，也是驱动更复杂模型（局部波动率、随机波动率）发展的直接动因。

本文系统阐述波动率曲面的经验特征、参数化方法、校准技术和实际应用。

隐含波动率基础

定义与计算

隐含波动率（Implied Volatility, IV）是使 Black-Scholes 理论价格等于市场价格的波动率参数：

CBS(S,K,T,r,q,σIV)=CmarketC_{BS}(S, K, T, r, q, \sigma_{IV}) = C_{market}CBS​(S,K,T,r,q,σIV​)=Cmarket​

由于 CBSC_{BS}CBS​ 关于 σ\sigmaσ 严格单调递增且连续，IV 对每个市场价格唯一存在。实际计算通常使用 Newton-Raphson 迭代或 Brent 方法。

单一性假设的破坏

如果 Black-Scholes 假设完全正确，所有期权（不同 KKK、TTT）的 IV 应该相同。但市场数据显示：

σIV(K1,T)≠σIV(K2,T)(不同行权价)\sigma_{IV}(K_1, T) \neq \sigma_{IV}(K_2, T) \quad \text{(不同行权价)}σIV​(K1​,T)=σIV​(K2​,T)(不同行权价)

σIV(K,T1)≠σIV(K,T2)(不同到期日)\sigma_{IV}(K, T_1) \neq \sigma_{IV}(K, T_2) \quad \text{(不同到期日)}σIV​(K,T1​)=σIV​(K,T2​)(不同到期日)

这就是波动率曲面的来源。

经验特征

波动率微笑与偏斜

波动率微笑（Volatility Smile）指的是 IV 关于行权价的 U 形曲线——深度实值和深度虚值期权的 IV 高于平值期权。

波动率偏斜（Volatility Skew）指的是 IV 随行权价单调递减的模式——低行权价（虚值看跌）的 IV 显著高于高行权价（虚值看涨）。

市场 典型形态 主要原因
股票/指数期权 偏斜（左高右低） 崩盘保险需求、杠杆效应
外汇期权 微笑（U 形） 双向尾部风险
商品期权 因品种而异 供给冲击方向不同
利率期权 偏斜或微笑 利率方向性预期

1987 年之前与之后

1987 年 10 月"黑色星期一"之前，股指期权市场几乎不存在显著偏斜。崩盘之后，市场对下跌风险的认知永久改变——虚值看跌期权的需求激增，波动率偏斜成为持续存在的市场特征。

期限结构

波动率的期限结构描述 IV 随到期时间 TTT 的变化：

  • 正期限结构：长期 IV > 短期 IV（正常市场，均值回复预期）
  • 反转期限结构：短期 IV > 长期 IV（危机期间，近期不确定性高）
  • 驼峰形态：中期 IV 最高（重要事件窗口）

为了跨不同标的和到期日比较波动率，通常用 Moneyness 标准化行权价：

参数化模型

SVI 参数化

Gatheral（2004）提出的 SVI（Stochastic Volatility Inspired）模型是最流行的波动率微笑参数化：

SVI 的优势在于：

  1. 仅 5 个参数即可拟合一条微笑曲线
  2. 渐近行为与随机波动率模型一致
  3. 可以施加无蝴蝶套利约束

波动率曲面的校准

校准流程

校准目标函数
典型的校准目标是最小化 IV 残差或价格残差的加权平方和：


min⁡θ∑iwi(σIVmodel(Ki,Ti;θ)−σIVmarket(Ki,Ti))2\min_{\theta} \sum_i w_i \left(\sigma_{IV}^{model}(K_i, T_i; \theta) - \sigma_{IV}^{market}(K_i, T_i)\right)^2θmin​i∑​wi​(σIVmodel​(Ki​,Ti​;θ)−σIVmarket​(Ki​,Ti​))2
权重 wiw_iwi​ 通常设为 Vega 的倒数，使得对期权价格的影响均匀。


Python 校准示例
import numpy as np
from scipy.optimize import minimize

def svi(k, params):
    """SVI 参数化"""
    a, b, rho, m, sigma = params
    return a + b * (rho * (k - m) + np.sqrt((k - m)**2 + sigma**2))

def calibrate_svi(k_market, iv_market, T):
    """SVI 校准"""
    w_market = iv_market**2 * T

    def objective(params):
        a, b, rho, m, sigma = params
        w_model = svi(k_market, params)
        return np.sum((w_model - w_market)**2)

    bounds = [(0.001, 1), (0.001, 2), (-0.99, 0.99), (-0.5, 0.5), (0.01, 1)]
    x0 = [0.04, 0.1, -0.3, 0.0, 0.1]

    result = minimize(objective, x0, bounds=bounds, method='L-BFGS-B')

    return result.x

k_data = np.array([-0.3, -0.2, -0.1, 0.0, 0.1, 0.2, 0.3])
iv_data = np.array([0.28, 0.24, 0.21, 0.20, 0.21, 0.23, 0.27])
T = 0.5

params = calibrate_svi(k_data, iv_data, T)
print(f"SVI 参数: a={params[0]:.4f}, b={params[1]:.4f}, "
      f"rho={params[2]:.4f}, m={params[3]:.4f}, sigma={params[4]:.4f}")

k_fine = np.linspace(-0.4, 0.4, 100)
w_fit = svi(k_fine, params)
iv_fit = np.sqrt(w_fit / T)
print(f"平值 IV: {iv_fit[50]:.4f}")
无套利约束
蝴蝶套利

局部波动率
Dupire 公式
局部波动率（Local Volatility）模型假设波动率为标的价格和时间的确定性函数 σloc(S,t)\sigma_{loc}(S, t)σloc​(S,t)。Dupire（1994）给出了从波动率曲面推导局部波动率的公式：

局部波动率的局限
局部波动率模型可以完美拟合当前的波动率曲面，但对曲面的未来动态预测很差——它预测远期微笑趋于平坦，与市场观察不符（"微笑动态问题"）。

总结
波动率曲面是衍生品市场最重要的"数据产品"之一，它将 Black-Scholes 模型的单一波动率假设推广为一个二维函数。微笑/偏斜反映了市场对尾部风险的定价，期限结构反映了对未来波动率路径的预期。SVI 和 SABR 等参数化方法提供了紧凑的数学描述，校准过程需要同时满足数据拟合和无套利约束。从波动率曲面出发，可以推导局部波动率（Dupire）或校准随机波动率模型（Heston、SABR），进而对奇异期权进行一致性定价。掌握波动率曲面的构建与应用，是量化定价工作的核心技能。
