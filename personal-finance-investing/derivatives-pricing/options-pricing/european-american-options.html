欧式与美式期权定价

概述

欧式期权（European Option）和美式期权（American Option）是金融市场中最基本的两类期权合约。欧式期权只能在到期日行权，而美式期权允许持有人在到期日之前的任何时刻行权。这个"提前行权权利"看似简单，却从根本上改变了定价的数学结构——欧式期权有 Black-Scholes 解析解，而美式期权的定价本质上是一个最优停时问题（Optimal Stopping Problem），通常需要数值方法求解。

本文系统比较两类期权的定价方法，深入分析提前行权的经济逻辑与数学条件，并给出二叉树和最小二乘蒙特卡洛（LSM）等实用算法。

美式期权的提前行权分析

核心问题

美式期权的持有人面临持续的最优决策问题：在每个时刻 ttt，是立即行权获得内在价值 max⁡(St−K,0)\max(S_t - K, 0)max(St​−K,0)（Call）或 max⁡(K−St,0)\max(K - S_t, 0)max(K−St​,0)（Put），还是继续持有期权等待更好的时机？

美式期权价格满足：

VAm(t,S)=sup⁡τ∈[t,T]EQ[e−r(τ−t)Φ(Sτ)∣St=S]V^{Am}(t, S) = \sup_{\tau \in [t, T]} \mathbb{E}^{\mathbb{Q}}\left[e^{-r(\tau - t)} \Phi(S_\tau) \mid S_t = S\right]VAm(t,S)=τ∈[t,T]sup​EQ[e−r(τ−t)Φ(Sτ​)∣St​=S]

其中 τ\tauτ 为停时，Φ\PhiΦ 为收益函数。

美式看涨期权（无股息）

关键结论：当标的资产不支付股息时，美式看涨期权永远不应提前行权。

证明思路：

CAm≥CEu≥Se−qT−Ke−rTC_{Am} \geq C_{Eu} \geq Se^{-qT} - Ke^{-rT}CAm​≥CEu​≥Se−qT−Ke−rT

当 q=0q = 0q=0 时，CEu≥S−Ke−rT>S−KC_{Eu} \geq S - Ke^{-rT} > S - KCEu​≥S−Ke−rT>S−K（内在价值），因此继续持有期权的价值总是大于立即行权。

经济直觉：

  1. 时间价值：期权的时间价值（外在价值）始终为正
  2. 利息收入：延迟支付行权价 KKK 可以获得利息
  3. 下行保护：继续持有保留了价格下跌时不行权的权利

美式看涨期权（有股息）

当标的支付离散股息时，在除息日前可能提前行权——放弃剩余时间价值以捕获股息收入。

提前行权条件（近似）：在除息日 tdt_dtd​ 前，当 SSS 足够高（深度实值）且股息 DDD 足够大时，行权价值超过继续持有价值。

美式看跌期权

美式看跌期权即使无股息也可能提前行权。

当股价 SSS 足够低时，看跌期权深度实值，其内在价值 K−SK - SK−S 接近最大值 KKK。继续持有的机会成本（无法投资行权所得）超过了时间价值，此时应提前行权。

最优行权边界
自由边界问题
美式看跌期权的定价可以表述为自由边界问题：存在一条时间依赖的最优行权边界 S∗(t)S^*(t)S∗(t)，满足：


    

  • 当 St≤S∗(t)S_t \leq S^*(t)St​≤S∗(t) 时，立即行权（停止区域）
    • 

  • 当 St>S∗(t)S_t > S^*(t)St​>S∗(t) 时，继续持有（持有区域）
    • 



在持有区域，期权价格满足 Black-Scholes PDE：


∂V∂t+rS∂V∂S+12σ2S2∂2V∂S2−rV=0\frac{\partial V}{\partial t} + rS\frac{\partial V}{\partial S} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} - rV = 0∂t∂V​+rS∂S∂V​+21​σ2S2∂S2∂2V​−rV=0
在行权边界上满足光滑粘合条件（Smooth Pasting）：


V(t,S∗(t))=K−S∗(t),∂V∂S(t,S∗(t))=−1V(t, S^*(t)) = K - S^*(t), \quad \frac{\partial V}{\partial S}(t, S^*(t)) = -1V(t,S∗(t))=K−S∗(t),∂S∂V​(t,S∗(t))=−1
提前行权溢价
美式期权价格 = 欧式期权价格 + 提前行权溢价：


VAm=VEu+ϵV^{Am} = V^{Eu} + \epsilonVAm=VEu+ϵ
提前行权溢价 ϵ≥0\epsilon \geq 0ϵ≥0 代表了提前行权权利的价值。


二叉树定价
CRR 模型
Cox-Ross-Rubinstein（CRR，1979）二叉树是美式期权定价最直观的数值方法。


参数设定（Δt=T/n\Delta t = T/nΔt=T/n）：


u=eσΔt,d=e−σΔt=1uu = e^{\sigma\sqrt{\Delta t}}, \quad d = e^{-\sigma\sqrt{\Delta t}} = \frac{1}{u}u=eσΔt​,d=e−σΔt​=u1​
p=e(r−q)Δt−du−dp = \frac{e^{(r-q)\Delta t} - d}{u - d}p=u−de(r−q)Δt−d​
回溯定价算法
从到期日 TTT 向前回溯：


    

  1. 终端节点：Vn,j=Φ(Sn,j)V_{n,j} = \Phi(S_{n,j})Vn,j​=Φ(Sn,j​)
    2. 

  2. 中间节点（欧式）：Vi,j=e−rΔt[pVi+1,j+(1−p)Vi+1,j+1]V_{i,j} = e^{-r\Delta t}[p V_{i+1,j} + (1-p)V_{i+1,j+1}]Vi,j​=e−rΔt[pVi+1,j​+(1−p)Vi+1,j+1​]
    3. 

  3. 中间节点（美式）：Vi,j=max⁡(Φ(Si,j), e−rΔt[pVi+1,j+(1−p)Vi+1,j+1])V_{i,j} = \max\left(\Phi(S_{i,j}), \, e^{-r\Delta t}[p V_{i+1,j} + (1-p)V_{i+1,j+1}]\right)Vi,j​=max(Φ(Si,j​),e−rΔt[pVi+1,j​+(1−p)Vi+1,j+1​])
    4. 



美式期权在每个节点比较行权价值与持有价值，取较大者。


Python 实现
import numpy as np

def crr_option_price(S0, K, T, r, q, sigma, n, option_type='put', exercise='american'):
    """
    CRR 二叉树期权定价
    支持欧式/美式、看涨/看跌
    """
    dt = T / n
    u = np.exp(sigma * np.sqrt(dt))
    d = 1 / u
    p = (np.exp((r - q) * dt) - d) / (u - d)
    disc = np.exp(-r * dt)

    stock = np.zeros(n + 1)
    for j in range(n + 1):
        stock[j] = S0 * (u ** (n - j)) * (d ** j)

    if option_type == 'call':
        option = np.maximum(stock - K, 0)
    else:
        option = np.maximum(K - stock, 0)

    for i in range(n - 1, -1, -1):
        for j in range(i + 1):
            stock_ij = S0 * (u ** (i - j)) * (d ** j)
            hold_value = disc * (p * option[j] + (1 - p) * option[j + 1])

            if exercise == 'american':
                if option_type == 'call':
                    exercise_value = max(stock_ij - K, 0)
                else:
                    exercise_value = max(K - stock_ij, 0)
                option[j] = max(hold_value, exercise_value)
            else:
                option[j] = hold_value

    return option[0]

S0, K, T, r, q, sigma = 100, 100, 1.0, 0.05, 0.02, 0.2
n_steps = 500

eu_put = crr_option_price(S0, K, T, r, q, sigma, n_steps, 'put', 'european')
am_put = crr_option_price(S0, K, T, r, q, sigma, n_steps, 'put', 'american')
eu_call = crr_option_price(S0, K, T, r, q, sigma, n_steps, 'call', 'european')
am_call = crr_option_price(S0, K, T, r, q, sigma, n_steps, 'call', 'american')

print(f"欧式看跌: {eu_put:.4f}")
print(f"美式看跌: {am_put:.4f} (溢价: {am_put - eu_put:.4f})")
print(f"欧式看涨: {eu_call:.4f}")
print(f"美式看涨: {am_call:.4f} (溢价: {am_call - eu_call:.4f})")
Longstaff-Schwartz 最小二乘蒙特卡洛
算法原理
Longstaff-Schwartz（2001）提出的最小二乘蒙特卡洛（Least Squares Monte Carlo, LSM）是美式期权定价的另一重要方法，特别适合高维问题。


核心思想：在每个行权时点，用回归估计继续持有的条件期望价值，与即时行权价值比较决定是否行权。


算法步骤
    

  1. 模拟 MMM 条资产价格路径 St(m)S_t^{(m)}St(m)​，m=1,…,Mm = 1, \ldots, Mm=1,…,M
    2. 

  2. 在到期日 TTT：VT(m)=Φ(ST(m))V_T^{(m)} = \Phi(S_T^{(m)})VT(m)​=Φ(ST(m)​)
    3. 

  3. 从 T−ΔtT - \Delta tT−Δt 向前回溯，在每个时点 tkt_ktk​：a. 计算即时行权价值 hk(m)=Φ(Stk(m))h_k^{(m)} = \Phi(S_{t_k}^{(m)})hk(m)​=Φ(Stk​(m)​) b. 筛选实值路径（hk(m)>0h_k^{(m)} > 0hk(m)​>0）c. 对实值路径，回归 C^k=∑jβjψj(Stk)\hat{C}_k = \sum_{j} \beta_j \psi_j(S_{t_k})C^k​=∑j​βj​ψj​(Stk​​) 估计继续价值 d. 若 hk(m)>C^k(m)h_k^{(m)} > \hat{C}_k^{(m)}hk(m)​>C^k(m)​，则在 tkt_ktk​ 行权
    4. 

  4. 折现所有路径的行权收益并取平均
    5. 



Python 实现
import numpy as np

def lsm_american_put(S0, K, T, r, q, sigma, n_steps, n_paths, seed=42):
    """Longstaff-Schwartz 最小二乘蒙特卡洛定价美式看跌"""
    np.random.seed(seed)
    dt = T / n_steps
    discount = np.exp(-r * dt)

    Z = np.random.normal(0, 1, (n_paths, n_steps))
    S = np.zeros((n_paths, n_steps + 1))
    S[:, 0] = S0
    for t in range(n_steps):
        S[:, t + 1] = S[:, t] * np.exp(
            (r - q - 0.5 * sigma**2) * dt + sigma * np.sqrt(dt) * Z[:, t]
        )

    payoff = np.maximum(K - S[:, -1], 0)
    cashflow = payoff.copy()

    for t in range(n_steps - 1, 0, -1):
        exercise = np.maximum(K - S[:, t], 0)
        itm = exercise > 0

        if np.sum(itm) == 0:
            cashflow = cashflow * discount
            continue

        X = S[itm, t]
        Y = cashflow[itm] * discount

        basis = np.column_stack([np.ones_like(X), X, X**2])
        coeffs = np.linalg.lstsq(basis, Y, rcond=None)[0]
        continuation = basis @ coeffs

        exercise_now = exercise[itm] > continuation
        idx_itm = np.where(itm)[0]
        cashflow[idx_itm[exercise_now]] = exercise[itm][exercise_now]
        cashflow[idx_itm[~exercise_now]] = cashflow[idx_itm[~exercise_now]] * discount
        cashflow[~itm] = cashflow[~itm] * discount

    price = np.mean(cashflow * discount)
    se = np.std(cashflow * discount) / np.sqrt(n_paths)
    return price, se

price, se = lsm_american_put(100, 100, 1.0, 0.05, 0.02, 0.2, 50, 100000)
print(f"LSM 美式看跌: {price:.4f} ± {1.96*se:.4f} (95% CI)")

百慕大期权
百慕大期权（Bermudan Option）允许在若干预定日期行权，介于欧式和美式之间。定价方法通常基于：


    

  • 在离散行权日做回溯定价（类似二叉树的中间节点检查）
    • 

  • LSM 方法中仅在允许的行权日做回归比较
    • 



百慕大期权在利率衍生品市场中非常常见，如百慕大互换期权（Bermudan Swaption）。


总结
欧式期权有优雅的 Black-Scholes 解析解，而美式期权的提前行权特征将定价问题转化为最优停时问题。理解提前行权的经济逻辑（无股息看涨不行权、看跌可能行权、有股息看涨除息日前可能行权）是正确定价的基础。CRR 二叉树提供了直观的数值框架，LSM 蒙特卡洛则将美式期权定价推广到高维场景。这些方法共同构成了期权定价实务的工具箱。
