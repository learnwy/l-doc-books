信用衍生品与违约模型

概述

信用衍生品（Credit Derivatives）是用于转移和管理信用风险的金融工具。信用违约互换（Credit Default Swap, CDS）是最基础也是最重要的信用衍生品——它本质上是一份针对债务人违约的保险合约。担保债务凭证（Collateralized Debt Obligation, CDO）则通过资产池的分层（Tranching）结构化地分配信用风险。2008 年金融危机深刻暴露了信用衍生品定价模型的局限性，也推动了这一领域的理论与实务革新。

本文系统介绍信用风险建模的两大框架——结构化模型和简约化模型，CDS 的定价机制，以及 CDO 的相关性建模。

信用风险基础

违约概率与信用价差

违约概率（Probability of Default, PD）是信用风险量化的核心指标。定义：

  • 边际违约概率：qt=P(在[t,t+dt]内违约∣到t未违约)q_t = P(\text{在} [t, t+dt] \text{内违约} \mid \text{到} t \text{未违约})qt​=P(在[t,t+dt]内违约∣到t未违约)
  • 累积违约概率：Q(t)=P(τ≤t)Q(t) = P(\tau \leq t)Q(t)=P(τ≤t)，其中 τ\tauτ 为违约时刻
  • 存活概率：S(t)=1−Q(t)=P(τ>t)S(t) = 1 - Q(t) = P(\tau > t)S(t)=1−Q(t)=P(τ>t)

信用价差（Credit Spread）是含信用风险债券的收益率与同期限无风险利率之差，反映了市场对违约风险的补偿要求。

回收率

回收率（Recovery Rate, RRR）是违约发生后债权人可以收回的比例。典型假设：

债券类型 典型回收率
高级担保 50-70%
高级无担保 40-50%
次级 20-35%
主权债务 30-60%

实务中常假设 R=40%R = 40\%R=40%（投资级）或 R=25%R = 25\%R=25%（高收益级）。

违约强度

违约强度（Default Intensity / Hazard Rate）λ(t)\lambda(t)λ(t) 定义为条件违约率：

λ(t)=lim⁡Δt→0P(τ≤t+Δt∣τ>t)Δt\lambda(t) = \lim_{\Delta t \to 0} \frac{P(\tau \leq t + \Delta t \mid \tau > t)}{\Delta t}λ(t)=Δt→0lim​ΔtP(τ≤t+Δt∣τ>t)​

存活概率与违约强度的关系：

S(t)=exp⁡(−∫0tλ(s) ds)S(t) = \exp\left(-\int_0^t \lambda(s) \, ds\right)S(t)=exp(−∫0t​λ(s)ds)

常数违约强度 λ\lambdaλ 意味着违约时刻服从指数分布：τ∼Exp(λ)\tau \sim \text{Exp}(\lambda)τ∼Exp(λ)。

结构化模型

Merton 模型

Merton（1974）将企业违约视为一个期权定价问题。核心思想：企业资产 VtV_tVt​ 遵循 GBM，债务面值为 DDD（到期日 TTT），违约当且仅当 VT<DV_T < DVT​<D。

dVt=μVt dt+σVVt dWtdV_t = \mu V_t \, dt + \sigma_V V_t \, dW_tdVt​=μVt​dt+σV​Vt​dWt​

股权 = 资产的看涨期权：E=VN(d1)−De−rTN(d2)E = V N(d_1) - De^{-rT} N(d_2)E=VN(d1​)−De−rTN(d2​)

债务 = 无风险债务 - 看跌期权：B=De−rT−PB = De^{-rT} - PB=De−rT−P

d1=ln⁡(V/D)+(r+σV2/2)TσVT,d2=d1−σVTd_1 = \frac{\ln(V/D) + (r + \sigma_V^2/2)T}{\sigma_V\sqrt{T}}, \quad d_2 = d_1 - \sigma_V\sqrt{T}d1​=σV​T​ln(V/D)+(r+σV2​/2)T​,d2​=d1​−σV​T​

违约概率（风险中性）：PD=N(−d2)PD = N(-d_2)PD=N(−d2​)

首达时模型
Black 和 Cox（1976）将违约定义为资产价值首次触及违约边界 H(t)H(t)H(t) 的时刻：


τ=inf⁡{t>0:Vt≤H(t)}\tau = \inf\{t > 0 : V_t \leq H(t)\}τ=inf{t>0:Vt​≤H(t)}
这允许在到期前违约，更符合实际情况。


Python 实现：Merton 模型
import numpy as np
from scipy.stats import norm

def merton_credit_model(V0, D, T, r, sigma_V):
    """
    Merton 信用模型
    V0: 资产价值, D: 债务面值, T: 到期时间
    r: 无风险利率, sigma_V: 资产波动率
    """
    d1 = (np.log(V0 / D) + (r + 0.5 * sigma_V**2) * T) / (sigma_V * np.sqrt(T))
    d2 = d1 - sigma_V * np.sqrt(T)

    equity = V0 * norm.cdf(d1) - D * np.exp(-r * T) * norm.cdf(d2)
    debt = V0 - equity
    pd_risk_neutral = norm.cdf(-d2)

    credit_spread = -np.log(debt / (D * np.exp(-r * T))) / T

    dd = d2

    return {
        'equity': equity,
        'debt': debt,
        'pd': pd_risk_neutral,
        'credit_spread': credit_spread,
        'distance_to_default': dd
    }

result = merton_credit_model(V0=100, D=80, T=1.0, r=0.05, sigma_V=0.2)
for key, value in result.items():
    print(f"{key:>20s}: {value:.6f}")
简约化模型
核心思想
简约化模型（Reduced-Form / Intensity Models）不显式建模资产价值，而是直接将违约视为一个外生的随机事件，由违约强度（Poisson 过程的强度）驱动。


在简约化模型中，违约时刻 τ\tauτ 的条件分布由违约强度 λ(t)\lambda(t)λ(t) 决定。


含违约风险的债券定价
风险债券价格：


Pˉ(t,T)=EQ[exp⁡(−∫tTrs ds)⋅(1τ>T+R⋅1τ≤T)∣Ft]\bar{P}(t, T) = \mathbb{E}^{\mathbb{Q}}\left[\exp\left(-\int_t^T r_s \, ds\right) \cdot \left(\mathbf{1}_{\tau > T} + R \cdot \mathbf{1}_{\tau \leq T}\right) \mid \mathcal{F}_t\right]Pˉ(t,T)=EQ[exp(−∫tT​rs​ds)⋅(1τ>T​+R⋅1τ≤T​)∣Ft​]
当利率和违约独立时：


Pˉ(t,T)=P(t,T)[S(t,T)+R⋅Q(t,T)]\bar{P}(t, T) = P(t, T) \left[S(t, T) + R \cdot Q(t, T)\right]Pˉ(t,T)=P(t,T)[S(t,T)+R⋅Q(t,T)]
其中 S(t,T)S(t,T)S(t,T) 为存活概率，Q(t,T)=1−S(t,T)Q(t,T) = 1 - S(t,T)Q(t,T)=1−S(t,T) 为违约概率。

dλt=κ(θ−λt) dt+σλt dWtd\lambda_t = \kappa(\theta - \lambda_t) \, dt + \sigma\sqrt{\lambda_t} \, dW_tdλt​=κ(θ−λt​)dt+σλt​​dWt​

从市场 CDS 价差推导存活概率
Bootstrap 方法：从短期到长期 CDS 逐步推导存活概率曲线。


import numpy as np

def bootstrap_survival_curve(cds_spreads, tenors, recovery=0.4, r=0.03):
    """
    从 CDS 价差 Bootstrap 存活概率曲线
    cds_spreads: 各期限 CDS 价差（年化，如 0.01 = 100bp）
    tenors: 对应期限（年）
    """
    delta = 0.25
    survival = np.ones(len(tenors))
    discount = np.exp(-r * np.array(tenors))

    for i, (s, T) in enumerate(zip(cds_spreads, tenors)):
        n_payments = int(T / delta)
        payment_times = np.arange(1, n_payments + 1) * delta

        if i == 0:
            pv_prot = (1 - recovery) * discount[i]
            pv_prem = s * delta * sum(
                np.exp(-r * t) for t in payment_times
            )
            survival[i] = pv_prem / (pv_prem + pv_prot)
        else:
            known_prem = 0
            known_prot = 0
            for j in range(i):
                t_start = tenors[j-1] if j > 0 else 0
                t_end = tenors[j]
                n_sub = int((t_end - t_start) / delta)
                for k in range(n_sub):
                    t = t_start + (k + 1) * delta
                    known_prem += s * delta * np.exp(-r * t) * survival[j]
                s_prev = survival[j-1] if j > 0 else 1.0
                known_prot += (1 - recovery) * np.exp(-r * t_end) * (s_prev - survival[j])

            pv_new_prot = (1 - recovery) * discount[i] * survival[i-1]
            n_remaining = int((tenors[i] - tenors[i-1]) / delta)
            pv_new_prem = s * delta * sum(
                np.exp(-r * (tenors[i-1] + (k+1) * delta))
                for k in range(n_remaining)
            )

            survival[i] = (known_prem + pv_new_prem * survival[i-1]) / (
                known_prem + pv_new_prem * survival[i-1]
                + pv_new_prot - known_prot
            )

    hazard = np.zeros(len(tenors))
    for i in range(len(tenors)):
        s_prev = survival[i-1] if i > 0 else 1.0
        t_prev = tenors[i-1] if i > 0 else 0
        dt = tenors[i] - t_prev
        if survival[i] > 0 and s_prev > 0:
            hazard[i] = -np.log(survival[i] / s_prev) / dt

    return survival, hazard

tenors = [1, 2, 3, 5, 7, 10]
spreads = [0.005, 0.008, 0.010, 0.012, 0.013, 0.014]

survival, hazard = bootstrap_survival_curve(spreads, tenors)
for T, S, h in zip(tenors, survival, hazard):
    print(f"T={T}y: S={S:.4f}, λ={h*10000:.1f}bp")

Gaussian Copula 模型

隐含相关性
类似于 Black-Scholes 的隐含波动率，从 CDO 分层的市场价格可以反推隐含相关性（Implied Correlation）。但隐含相关性存在"微笑"现象，表明 Gaussian Copula 模型的不足。


基础相关性（Base Correlation）是更稳定的市场报价方式——每个 [0,K][0, K][0,K] 层级对应一个相关系数，避免了标准相关性的非单调问题。

总结
信用衍生品定价建立在违约建模的两大框架之上：结构化模型（Merton）从资产价值出发，提供了违约的经济直觉；简约化模型直接对违约强度建模，更适合市场校准。CDS 定价的核心是将保护腿和费用腿的现值相等，通过 Bootstrap 方法从市场价差推导存活概率曲线。CDO 定价引入了违约相关性建模的挑战，Gaussian Copula 虽然简单但在 2008 年危机中暴露了严重局限。后危机时代，XVA 框架、压力测试和中央清算成为信用风险管理的新标准，动态相关性模型和机器学习方法也在不断推进这一领域的发展。
