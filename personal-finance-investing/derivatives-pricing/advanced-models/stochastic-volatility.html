随机波动率模型：Heston 与 SABR

概述

Black-Scholes 模型假设波动率为常数，但市场隐含波动率的微笑/偏斜形态表明这个假设过于简化。随机波动率模型（Stochastic Volatility Models）通过让波动率本身成为一个随机过程来解决这个问题。在这类模型中，资产价格和波动率共同演化，波动率过程通常具有均值回复特性，且与资产价格过程存在相关性（杠杆效应）。

Heston 模型（1993）和 SABR 模型（2002）是实务中最重要的两个随机波动率模型——Heston 因其半解析特征函数方法而在股票期权定价中广泛使用，SABR 则因其隐含波动率近似公式而成为利率期权市场的标准。本文详细介绍这两个模型的数学结构、定价方法和校准技术。

Feller 条件

为保证方差过程 vtv_tvt​ 严格为正，需要满足 Feller 条件：

2κθ>ξ22\kappa\theta > \xi^22κθ>ξ2

当 Feller 条件不满足时，vtv_tvt​ 可能触及零边界（但会被"反弹"回来），数值模拟需要特殊处理。

波动率微笑的来源

Heston 模型生成波动率微笑的两个关键机制：

  1. 相关性 ρ<0\rho < 0ρ<0：股价下跌时波动率上升（杠杆效应），产生左偏斜
  2. vol-of-vol ξ>0\xi > 0ξ>0：波动率自身的随机性产生尾部肥厚，形成微笑

Python 实现
import numpy as np
from scipy.integrate import quad

def heston_call_price(S0, K, T, r, q, v0, kappa, theta, xi, rho):
    """Heston 模型看涨期权定价（特征函数方法）"""
    x = np.log(S0)
    k = np.log(K)

    def char_func(omega, j):
        if j == 1:
            u, b = 0.5, kappa - rho * xi
        else:
            u, b = -0.5, kappa

        d = np.sqrt((rho * xi * 1j * omega - b)**2
                     - xi**2 * (2 * u * 1j * omega - omega**2))
        g = (b - rho * xi * 1j * omega + d) / (b - rho * xi * 1j * omega - d)

        C = ((r - q) * 1j * omega * T
             + kappa * theta / xi**2 * (
                 (b - rho * xi * 1j * omega + d) * T
                 - 2 * np.log((1 - g * np.exp(d * T)) / (1 - g))
             ))
        D = ((b - rho * xi * 1j * omega + d) / xi**2
             * (1 - np.exp(d * T)) / (1 - g * np.exp(d * T)))

        return np.exp(C + D * v0 + 1j * omega * x)

    def integrand(omega, j):
        return np.real(np.exp(-1j * omega * k) * char_func(omega, j)) / omega

    P1 = 0.5 + 1 / np.pi * quad(integrand, 0, 200, args=(1,), limit=200)[0]
    P2 = 0.5 + 1 / np.pi * quad(integrand, 0, 200, args=(2,), limit=200)[0]

    call = S0 * np.exp(-q * T) * P1 - K * np.exp(-r * T) * P2
    return call

price = heston_call_price(
    S0=100, K=100, T=1.0, r=0.05, q=0.02,
    v0=0.04, kappa=2.0, theta=0.04, xi=0.3, rho=-0.7
)
print(f"Heston Call: {price:.4f}")

其中 Θ=(v0,κ,θ,ξ,ρ)\Theta = (v_0, \kappa, \theta, \xi, \rho)Θ=(v0​,κ,θ,ξ,ρ)。

Hagan 隐含波动率近似
SABR 模型的核心实用价值在于 Hagan 等人给出的隐含波动率近似公式，使得无需数值求解即可快速得到隐含波动率：

Python 实现
import numpy as np

def sabr_implied_vol(F, K, T, alpha, beta, rho, nu):
    """SABR Hagan 近似隐含波动率"""
    if abs(F - K) < 1e-12:
        vol = (alpha / F**(1 - beta)) * (
            1 + ((1 - beta)**2 / 24 * alpha**2 / F**(2 * (1 - beta))
                 + rho * beta * nu * alpha / (4 * F**(1 - beta))
                 + (2 - 3 * rho**2) / 24 * nu**2) * T
        )
        return vol

    fk = F * K
    fk_beta = fk**((1 - beta) / 2)
    log_fk = np.log(F / K)

    z = nu / alpha * fk_beta * log_fk
    x_z = np.log((np.sqrt(1 - 2 * rho * z + z**2) + z - rho) / (1 - rho))

    if abs(z) < 1e-12:
        z_over_xz = 1.0
    else:
        z_over_xz = z / x_z

    denom = fk_beta * (1 + (1 - beta)**2 / 24 * log_fk**2
                        + (1 - beta)**4 / 1920 * log_fk**4)

    correction = 1 + ((1 - beta)**2 / 24 * alpha**2 / fk**(1 - beta)
                       + rho * beta * nu * alpha / (4 * fk_beta)
                       + (2 - 3 * rho**2) / 24 * nu**2) * T

    vol = alpha / denom * z_over_xz * correction
    return vol

F, T = 0.03, 5.0
alpha, beta, rho, nu = 0.02, 0.5, -0.3, 0.4

strikes = np.linspace(0.01, 0.06, 11)
vols = [sabr_implied_vol(F, K, T, alpha, beta, rho, nu) for K in strikes]

for K, vol in zip(strikes, vols):
    print(f"K={K:.3f}: σ={vol:.4f} ({vol*100:.2f}%)")

其他随机波动率模型
3/2 模型
dvt=κvt(θ−vt) dt+ξvt3/2 dWtvdv_t = \kappa v_t(\theta - v_t) \, dt + \xi v_t^{3/2} \, dW_t^vdvt​=κvt​(θ−vt​)dt+ξvt3/2​dWtv​
波动率的扩散系数为 v3/2v^{3/2}v3/2 而非 v\sqrt{v}v​，能更好地拟合极端波动率情景。


Bergomi 模型
Bergomi（2005）提出了一类基于远期方差曲线的模型，直接对方差互换曲线建模。其二因子版本已在实务中获得广泛应用。


粗糙波动率
Gatheral, Jaisson 和 Rosenbaum（2018）发现历史波动率的时间序列表现出粗糙特征——波动率增量的方差以 ∣t−s∣2H|t-s|^{2H}∣t−s∣2H（H≈0.1H \approx 0.1H≈0.1，远小于标准布朗运动的 H=0.5H = 0.5H=0.5）的速率增长。粗糙 Bergomi 模型将这一发现推广到定价框架，但数值实现更为复杂。


总结
随机波动率模型通过赋予波动率自身的随机动态，系统性地解释了市场中波动率微笑/偏斜的存在。Heston 模型以其特征函数方法在股票期权定价中占据核心地位，SABR 模型以其简洁的隐含波动率近似公式主导了利率期权市场。两个模型各有优势——Heston 的期限一致性与 SABR 的校准简便性分别满足了不同的实务需求。理解参数的经济含义（ρ\rhoρ 控制偏斜、ξ/ν\xi/\nuξ/ν 控制微笑、κ\kappaκ 控制期限结构）是正确使用和校准这些模型的基础。
