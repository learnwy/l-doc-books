利率模型与固定收益定价

概述

利率衍生品——利率互换（Interest Rate Swap）、利率上/下限（Cap/Floor）、互换期权（Swaption）等——是全球交易量最大的衍生品类别。与股票衍生品不同，利率衍生品的标的是收益率曲线（Yield Curve）本身，而非单一资产价格。这意味着利率模型必须描述整条收益率曲线的动态演化，同时保证模型内部的一致性（任何时刻的收益率曲线对应的贴现函数都无套利）。

本文从短期利率模型出发，经过 Heath-Jarrow-Morton（HJM）框架，到实务中广泛使用的 LIBOR 市场模型（LMM/BGM），系统介绍利率建模与固定收益衍生品定价的理论体系。

Python 实现：Vasicek 债券定价
import numpy as np

def vasicek_bond_price(r0, kappa, theta, sigma, T):
    """Vasicek 模型零息债券价格"""
    B = (1 - np.exp(-kappa * T)) / kappa
    A = np.exp(
        (theta - sigma**2 / (2 * kappa**2)) * (B - T)
        - sigma**2 / (4 * kappa) * B**2
    )
    return A * np.exp(-B * r0)

def vasicek_yield_curve(r0, kappa, theta, sigma, maturities):
    """计算 Vasicek 收益率曲线"""
    yields = []
    for T in maturities:
        P = vasicek_bond_price(r0, kappa, theta, sigma, T)
        y = -np.log(P) / T
        yields.append(y)
    return np.array(yields)

r0, kappa, theta, sigma = 0.03, 0.5, 0.05, 0.01
maturities = np.array([0.25, 0.5, 1, 2, 3, 5, 7, 10, 20, 30])
yields = vasicek_yield_curve(r0, kappa, theta, sigma, maturities)

for T, y in zip(maturities, yields):
    print(f"T={T:5.2f}y: yield={y*100:.3f}%")
HJM 框架
远期利率动态
Heath, Jarrow 和 Morton（1992）提出了一个统一框架，直接对整条远期利率曲线建模：


df(t,T)=μf(t,T) dt+σf(t,T) dWtdf(t, T) = \mu_f(t, T) \, dt + \sigma_f(t, T) \, dW_tdf(t,T)=μf​(t,T)dt+σf​(t,T)dWt​
HJM 漂移条件
在风险中性测度下，无套利条件对漂移施加了严格约束：


μf(t,T)=σf(t,T)∫tTσf(t,s) ds\mu_f(t, T) = \sigma_f(t, T) \int_t^T \sigma_f(t, s) \, dsμf​(t,T)=σf​(t,T)∫tT​σf​(t,s)ds
这就是著名的 HJM 漂移条件——波动率结构 σf(t,T)\sigma_f(t, T)σf​(t,T) 完全决定了远期利率的演化。

LIBOR 市场模型
背景与动机
LIBOR 市场模型（LMM，也称 BGM 模型，Brace-Gatarek-Musiela, 1997）直接对市场可观测的远期 LIBOR 利率建模，避免了短期利率模型的抽象性。

蒙特卡洛模拟
LMM 没有解析解（Swaption 定价无封闭公式），主要依赖蒙特卡洛模拟：


import numpy as np

def lmm_simulate(L0, sigma, rho, delta, T_end, n_paths, n_steps_per_period, seed=42):
    """
    LIBOR 市场模型蒙特卡洛模拟
    L0: 初始远期利率向量, sigma: 波动率向量
    rho: 相关矩阵, delta: 期限间隔
    """
    np.random.seed(seed)
    n_rates = len(L0)
    dt = delta / n_steps_per_period

    L = np.tile(L0, (n_paths, 1))
    chol = np.linalg.cholesky(rho)

    total_steps = n_rates * n_steps_per_period

    for step in range(total_steps):
        Z = np.random.standard_normal((n_paths, n_rates))
        corr_Z = Z @ chol.T

        current_time = step * dt
        k_current = int(current_time / delta)

        for k in range(k_current, n_rates):
            drift = 0.0
            for j in range(k + 1, n_rates):
                drift -= (delta * rho[k, j] * sigma[k] * sigma[j] * L[:, j]
                          / (1 + delta * L[:, j]))

            L[:, k] = L[:, k] * np.exp(
                (drift - 0.5 * sigma[k]**2) * dt
                + sigma[k] * np.sqrt(dt) * corr_Z[:, k]
            )

    return L

n_rates = 10
L0 = np.full(n_rates, 0.03)
sigma = np.full(n_rates, 0.15)
rho = 0.5 * np.ones((n_rates, n_rates)) + 0.5 * np.eye(n_rates)
delta = 0.5

L_terminal = lmm_simulate(L0, sigma, rho, delta, 5.0, 10000, 10)
print(f"终端 LIBOR 均值: {L_terminal.mean(axis=0)}")

互换期权
互换期权（Swaption）赋予持有人在未来某时刻进入利率互换的权利。在 LMM 中，Swaption 定价需要蒙特卡洛或近似方法（如 Rebonato 的冻结漂移近似）。

SOFR 等 RFR 基于实际交易数据（回购市场），相比 LIBOR（基于银行报价）更具透明度。


对建模的影响
RFR 是隔夜利率，衍生品通常基于其回溯复合（Backward-looking Compounding）：


Rcomp(Tk−1,Tk)=1δ[∏i(1+riδi)−1]R_{comp}(T_{k-1}, T_k) = \frac{1}{\delta}\left[\prod_{i} (1 + r_i \delta_i) - 1\right]Rcomp​(Tk−1​,Tk​)=δ1​[i∏​(1+ri​δi​)−1]
这改变了 LMM 的建模结构——从前瞻性 LIBOR 到回溯性 SOFR 复合利率，需要新的模型框架。


总结
利率模型从简单的短期利率模型（Vasicek、CIR、Hull-White）发展到 HJM 框架，再到市场标准的 LIBOR 市场模型（LMM/BGM），反映了从数学优雅到实务需求的演进。短期利率模型提供解析债券价格但难以同时拟合市场数据；HJM 框架在理论上统一但维度过高；LMM 通过直接对市场利率建模实现了理论与实务的平衡。随着 LIBOR 退出历史舞台，利率建模正在向 SOFR 等无风险利率框架迁移，这对定价和风险管理提出了新的技术要求。
