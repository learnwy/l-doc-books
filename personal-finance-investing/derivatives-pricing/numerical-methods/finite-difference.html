有限差分方法

概述

有限差分方法（Finite Difference Methods, FDM）是求解衍生品定价偏微分方程（PDE）的核心数值技术。Black-Scholes PDE 是一个抛物型方程，有限差分方法将连续的时间-空间域离散化为网格，用差分近似代替微分算子，将 PDE 转化为可以逐步求解的代数方程组。与蒙特卡洛方法相比，有限差分在低维问题（1-2 个标的资产）中通常更高效、更精确，且天然支持美式期权的自由边界处理。

本文覆盖显式、隐式和 Crank-Nicolson 三种主要有限差分格式，讨论稳定性与收敛性，以及在美式期权和障碍期权中的应用。

Black-Scholes PDE 回顾

标准 Black-Scholes PDE：

∂V∂t+(r−q)S∂V∂S+12σ2S2∂2V∂S2−rV=0\frac{\partial V}{\partial t} + (r-q)S\frac{\partial V}{\partial S} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} - rV = 0∂t∂V​+(r−q)S∂S∂V​+21​σ2S2∂S2∂2V​−rV=0

通过变量替换 x=ln⁡Sx = \ln Sx=lnS，可将变系数 PDE 转化为常系数形式：

∂V∂t+(r−q−σ22)∂V∂x+12σ2∂2V∂x2−rV=0\frac{\partial V}{\partial t} + \left(r - q - \frac{\sigma^2}{2}\right)\frac{\partial V}{\partial x} + \frac{1}{2}\sigma^2\frac{\partial^2 V}{\partial x^2} - rV = 0∂t∂V​+(r−q−2σ2​)∂x∂V​+21​σ2∂x2∂2V​−rV=0

令 τ=T−t\tau = T - tτ=T−t（从终端向前），PDE 变为正向扩散方程：

∂V∂τ=12σ2∂2V∂x2+(r−q−σ22)∂V∂x−rV\frac{\partial V}{\partial \tau} = \frac{1}{2}\sigma^2\frac{\partial^2 V}{\partial x^2} + \left(r - q - \frac{\sigma^2}{2}\right)\frac{\partial V}{\partial x} - rV∂τ∂V​=21​σ2∂x2∂2V​+(r−q−2σ2​)∂x∂V​−rV

在矩形域 [xmin⁡,xmax⁡]×[0,T][x_{\min}, x_{\max}] \times [0, T][xmin​,xmax​]×[0,T] 上构造均匀网格：

Python 实现
Crank-Nicolson 欧式期权
import numpy as np

def crank_nicolson_european(S0, K, T, r, q, sigma, Nx, Nt, option_type='call'):
    """Crank-Nicolson 有限差分定价欧式期权"""
    x_min = np.log(S0) - 5 * sigma * np.sqrt(T)
    x_max = np.log(S0) + 5 * sigma * np.sqrt(T)
    dx = (x_max - x_min) / Nx
    dt = T / Nt
    alpha = r - q - 0.5 * sigma**2

    x = np.linspace(x_min, x_max, Nx + 1)
    S = np.exp(x)

    if option_type == 'call':
        V = np.maximum(S - K, 0.0)
    else:
        V = np.maximum(K - S, 0.0)

    a = 0.5 * dt * (sigma**2 / dx**2 - alpha / dx)
    b = -dt * (sigma**2 / dx**2 + r)
    c = 0.5 * dt * (sigma**2 / dx**2 + alpha / dx)

    A_lower = np.full(Nx - 2, -0.5 * a)
    A_diag = np.full(Nx - 1, 1 - 0.5 * b)
    A_upper = np.full(Nx - 2, -0.5 * c)

    B_lower = np.full(Nx - 2, 0.5 * a)
    B_diag = np.full(Nx - 1, 1 + 0.5 * b)
    B_upper = np.full(Nx - 2, 0.5 * c)

    def solve_tridiag(lower, diag, upper, rhs):
        n = len(diag)
        c_prime = np.zeros(n)
        d_prime = np.zeros(n)
        c_prime[0] = upper[0] / diag[0]
        d_prime[0] = rhs[0] / diag[0]
        for i in range(1, n):
            m = diag[i] - lower[i-1] * c_prime[i-1]
            c_prime[i] = upper[i-1] / m if i < n - 1 else 0
            d_prime[i] = (rhs[i] - lower[i-1] * d_prime[i-1]) / m
        x_sol = np.zeros(n)
        x_sol[-1] = d_prime[-1]
        for i in range(n - 2, -1, -1):
            x_sol[i] = d_prime[i] - c_prime[i] * x_sol[i + 1]
        return x_sol

    for n in range(Nt):
        rhs = np.zeros(Nx - 1)
        for j in range(Nx - 1):
            rhs[j] = B_diag[j] * V[j+1]
            if j > 0:
                rhs[j] += B_lower[j-1] * V[j]
            if j < Nx - 2:
                rhs[j] += B_upper[j] * V[j+2]

        rhs[0] += 0.5 * a * V[0]
        rhs[-1] += 0.5 * c * V[-1]

        if option_type == 'call':
            V[0] = 0
            V[-1] = S[-1] - K * np.exp(-r * (T - (n+1) * dt))
        else:
            V[0] = K * np.exp(-r * (T - (n+1) * dt)) - S[0]
            V[-1] = 0

        rhs[0] += 0.5 * a * V[0]
        rhs[-1] += 0.5 * c * V[-1]

        V[1:-1] = solve_tridiag(A_lower, A_diag, A_upper, rhs)

    idx = np.argmin(np.abs(x - np.log(S0)))
    return V[idx]

price = crank_nicolson_european(100, 100, 1.0, 0.05, 0.02, 0.2, 200, 200, 'call')
print(f"Crank-Nicolson Call: {price:.4f}")
美式期权的有限差分处理
惩罚方法
在美式期权定价中，期权价值在每个时间步不能低于内在价值。最简单的方法是在每个时间步后强制：


Vjn+1=max⁡(Vjn+1,Φ(Sj))V_j^{n+1} = \max\left(V_j^{n+1}, \Phi(S_j)\right)Vjn+1​=max(Vjn+1​,Φ(Sj​))
PSOR 方法
投影逐次超松弛法（Projected Successive Over-Relaxation, PSOR）直接求解线性互补问题：


AV≥b,V≥g,(AV−b)T(V−g)=0AV \geq b, \quad V \geq g, \quad (AV - b)^T(V - g) = 0AV≥b,V≥g,(AV−b)T(V−g)=0
其中 ggg 为内在价值向量。PSOR 在每次迭代中投影到可行域，直到收敛。


Brennan-Schwartz 算法
对于三对角系统，Brennan 和 Schwartz（1977）给出了一种修改的 Thomas 算法，在前代和回代过程中直接施加提前行权约束，效率与欧式情况相同（O(Nx)O(N_x)O(Nx​)）。

非均匀网格与自适应方法
对数价格网格
使用 x=ln⁡Sx = \ln Sx=lnS 可以将 GBM 的变系数 PDE 转化为常系数，但更重要的是实现了对价格空间的非均匀覆盖——低价格区域节点更密，高价格区域节点更稀。


集中网格
在行权价附近加密网格可以提高精度：


xj=xmin⁡+(xmax⁡−xmin⁡)⋅g(j/Nx)x_j = x_{\min} + (x_{\max} - x_{\min}) \cdot g(j/N_x)xj​=xmin​+(xmax​−xmin​)⋅g(j/Nx​)
其中 ggg 为将点集中到 ln⁡K\ln KlnK 附近的映射函数。


高维扩展
ADI 方法
对于两个标的资产的 PDE（如彩虹期权），使用交替方向隐式法（Alternating Direction Implicit, ADI）：每个时间步分解为两个半步，每个半步只在一个空间方向上隐式处理。


Vn+1/2=Vn+Δτ2(LxVn+1/2+LyVn)V^{n+1/2} = V^n + \frac{\Delta\tau}{2}\left(\mathcal{L}_x V^{n+1/2} + \mathcal{L}_y V^n\right)Vn+1/2=Vn+2Δτ​(Lx​Vn+1/2+Ly​Vn)
 


Vn+1=Vn+1/2+Δτ2(LxVn+1/2+LyVn+1)V^{n+1} = V^{n+1/2} + \frac{\Delta\tau}{2}\left(\mathcal{L}_x V^{n+1/2} + \mathcal{L}_y V^{n+1}\right)Vn+1=Vn+1/2+2Δτ​(Lx​Vn+1/2+Ly​Vn+1)
ADI 将二维问题分解为一系列一维三对角系统，效率大幅提升。

总结
有限差分方法通过将 Black-Scholes PDE 离散化，提供了低维衍生品定价的高效数值框架。Crank-Nicolson 格式以其二阶精度和无条件稳定性成为标准选择。美式期权通过 PSOR 或 Brennan-Schwartz 算法处理提前行权约束，障碍期权需要仔细的网格对齐。对于二维问题，ADI 方法有效控制计算量；三维以上则达到有限差分的实用边界。理解网格设计、稳定性条件和边界处理，是有效使用有限差分定价的关键。
