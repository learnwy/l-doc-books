树模型与格子方法

概述

树模型（Tree Models）和格子方法（Lattice Methods）是衍生品定价中最直观的数值方法。通过将连续的资产价格过程离散化为有限步的上涨/下跌路径，树模型将定价问题转化为从终端节点向根节点回溯的简单递推过程。二叉树（Binomial Tree）和三叉树（Trinomial Tree）是最常用的格子结构，它们在 GBM 的极限下收敛于 Black-Scholes 价格，同时天然支持美式期权的提前行权判断。

本文系统介绍 CRR 二叉树、JR 二叉树、三叉树模型的构造原理与收敛特性，以及格子方法在各类衍生品中的应用。

import numpy as np

def binomial_tree(S0, K, T, r, q, sigma, n, option_type='call',
                  exercise='european', model='crr'):
    """
    通用二叉树期权定价
    model: 'crr' 或 'jr'
    exercise: 'european' 或 'american'
    """
    dt = T / n

    if model == 'crr':
        u = np.exp(sigma * np.sqrt(dt))
        d = 1 / u
        p = (np.exp((r - q) * dt) - d) / (u - d)
    else:
        nu = (r - q - 0.5 * sigma**2) * dt
        u = np.exp(nu + sigma * np.sqrt(dt))
        d = np.exp(nu - sigma * np.sqrt(dt))
        p = 0.5

    disc = np.exp(-r * dt)

    stock = np.array([S0 * u**(n - 2*j) for j in range(n + 1)])

    if option_type == 'call':
        V = np.maximum(stock - K, 0.0)
    else:
        V = np.maximum(K - stock, 0.0)

    for i in range(n - 1, -1, -1):
        for j in range(i + 1):
            V[j] = disc * (p * V[j] + (1 - p) * V[j + 1])

            if exercise == 'american':
                S_ij = S0 * u**(i - 2*j)
                if option_type == 'call':
                    V[j] = max(V[j], S_ij - K)
                else:
                    V[j] = max(V[j], K - S_ij)

    return V[0]

params = (100, 100, 1.0, 0.05, 0.02, 0.2, 1000)
eu_call = binomial_tree(*params, 'call', 'european')
am_put = binomial_tree(*params, 'put', 'american')
print(f"欧式 Call: {eu_call:.4f}")
print(f"美式 Put:  {am_put:.4f}")

三叉树与有限差分的等价性
一个重要的数学事实是：三叉树模型等价于显式有限差分格式。三叉树的三个概率正好对应显式差分方程中的三个系数。这个等价关系意味着：

import numpy as np

def trinomial_tree(S0, K, T, r, q, sigma, n, option_type='put', exercise='american'):
    """三叉树期权定价"""
    dt = T / n
    u = np.exp(sigma * np.sqrt(2 * dt))
    d = 1 / u

    exp_half = np.exp((r - q) * dt / 2)
    exp_sig = np.exp(sigma * np.sqrt(dt / 2))

    pu = ((exp_half - 1 / exp_sig) / (exp_sig - 1 / exp_sig))**2
    pd = ((exp_sig - exp_half) / (exp_sig - 1 / exp_sig))**2
    pm = 1 - pu - pd

    disc = np.exp(-r * dt)
    n_nodes = 2 * n + 1

    stock = np.array([S0 * u**(n - j) for j in range(n_nodes)])

    if option_type == 'call':
        V = np.maximum(stock - K, 0.0)
    else:
        V = np.maximum(K - stock, 0.0)

    for i in range(n - 1, -1, -1):
        n_j = 2 * i + 1
        V_new = np.zeros(n_j)
        for j in range(n_j):
            V_new[j] = disc * (pu * V[j] + pm * V[j + 1] + pd * V[j + 2])

            if exercise == 'american':
                S_ij = S0 * u**(i - j)
                if option_type == 'call':
                    V_new[j] = max(V_new[j], S_ij - K)
                else:
                    V_new[j] = max(V_new[j], K - S_ij)

        V = V_new

    return V[0]

price = trinomial_tree(100, 100, 1.0, 0.05, 0.02, 0.2, 200, 'put', 'american')
print(f"三叉树美式 Put: {price:.4f}")

振荡收敛问题
CRR 二叉树价格随步数 nnn 的增加呈现振荡收敛——偶数步和奇数步的价格序列分别单调收敛到不同的值，总体以 O(1/n)O(1/n)O(1/n) 的速率趋近真值。


这种振荡源于行权价 KKK 在树的最后一层上的位置：当 KKK 恰好在两个节点之间时，离散化误差最大。

def binomial_richardson(S0, K, T, r, q, sigma, n, option_type, exercise):
    """Richardson 外推加速"""
    V_n = binomial_tree(S0, K, T, r, q, sigma, n, option_type, exercise)
    V_2n = binomial_tree(S0, K, T, r, q, sigma, 2*n, option_type, exercise)
    return 2 * V_2n - V_n

price = binomial_richardson(100, 100, 1.0, 0.05, 0.02, 0.2, 100, 'call', 'european')
print(f"Richardson 外推: {price:.4f}")

连续股息

离散股息
离散股息处理更为复杂。两种常见方法：


方法一：已知股息金额


在除息日，树的所有节点减去股息 DDD：S→S−DS \to S - DS→S−D。但这会破坏重合性——除息后树不再重合。


方法二：已知股息率


除息日按比例调整：S→S(1−δ)S \to S(1 - \delta)S→S(1−δ)。保持重合性但可能不准确。


方法三：分离法


将股价分为确定性部分（已知股息的现值）和随机部分，只对随机部分建树，保持重合性。

总结
树模型和格子方法通过离散化资产价格动态，将衍生品定价转化为简洁的回溯递推过程。CRR 二叉树以其对称性和重合性成为最广泛使用的格子模型；三叉树在障碍处理和均值回复过程中具有优势；加速技术（Richardson 外推、网格对齐）可将收敛速率提高一个量级。树模型与有限差分方法的等价关系揭示了两类方法的统一本质。虽然在高维问题中让位于蒙特卡洛方法，但树模型在低维定价、美式期权处理和利率建模中仍然是不可或缺的工具。
