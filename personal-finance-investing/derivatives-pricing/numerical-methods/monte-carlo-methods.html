蒙特卡洛模拟定价

概述

蒙特卡洛模拟（Monte Carlo Simulation）是衍生品定价中最通用、最灵活的数值方法。其核心思想源于风险中性定价公式：衍生品价格等于到期收益在风险中性测度下的折现期望。通过随机生成大量资产价格路径，计算收益的样本平均来估计这个期望值。蒙特卡洛方法的最大优势在于维度不敏感——无论标的资产是 1 维还是 100 维，算法的结构不变，收敛速率 O(1/M)O(1/\sqrt{M})O(1/M​) 与维度无关。

本文系统介绍蒙特卡洛定价的基本框架、路径生成技术、方差缩减方法和 Greeks 计算。

基本框架

风险中性模拟

在风险中性测度 Q\mathbb{Q}Q 下，衍生品价格为：

V0=e−rTEQ[Φ(ST)]V_0 = e^{-rT} \mathbb{E}^{\mathbb{Q}}[\Phi(S_T)]V0​=e−rTEQ[Φ(ST​)]

蒙特卡洛估计量：

V^0=e−rT1M∑m=1MΦ(ST(m))\hat{V}_0 = e^{-rT} \frac{1}{M} \sum_{m=1}^{M} \Phi(S_T^{(m)})V^0​=e−rTM1​m=1∑M​Φ(ST(m)​)

其中 ST(m)S_T^{(m)}ST(m)​ 为第 mmm 条模拟路径的终端价格。

收敛性与误差

由中心极限定理，V^0\hat{V}_0V^0​ 的标准误为：

SE=σ^ΦMSE = \frac{\hat{\sigma}_{\Phi}}{\sqrt{M}}SE=M​σ^Φ​​

其中 σ^Φ\hat{\sigma}_{\Phi}σ^Φ​ 为收益的样本标准差。95% 置信区间为 V^0±1.96⋅SE\hat{V}_0 \pm 1.96 \cdot SEV^0​±1.96⋅SE。

关键特征：

属性 值 意义
收敛速率 O(M−1/2)O(M^{-1/2})O(M−1/2) 精度提高一倍需 4 倍路径
维度依赖 无 对高维问题有天然优势
路径灵活性 可处理任意路径依赖型收益 亚式、障碍、回望均适用
精度控制 标准误可计算 可给出置信区间

算法流程

路径生成
GBM 精确模拟
对于几何布朗运动，可以直接利用解析解精确模拟：


ST=S0exp⁡[(r−q−σ22)T+σT Z],Z∼N(0,1)S_T = S_0 \exp\left[\left(r - q - \frac{\sigma^2}{2}\right)T + \sigma\sqrt{T} \, Z\right], \quad Z \sim N(0,1)ST​=S0​exp[(r−q−2σ2​)T+σT​Z],Z∼N(0,1)
若需要路径（亚式/障碍期权），则逐步模拟：


St+Δt=Stexp⁡[(r−q−σ22)Δt+σΔt Zt]S_{t+\Delta t} = S_t \exp\left[\left(r - q - \frac{\sigma^2}{2}\right)\Delta t + \sigma\sqrt{\Delta t} \, Z_t\right]St+Δt​=St​exp[(r−q−2σ2​)Δt+σΔt​Zt​]
多资产相关模拟
对于 nnn 个相关资产（相关矩阵 Σ\SigmaΣ），使用 Cholesky 分解：


Σ=LLT\Sigma = LL^TΣ=LLT
独立标准正态向量 Z\mathbf{Z}Z 变换为相关向量 X=LZ\mathbf{X} = L\mathbf{Z}X=LZ。


Python 基础实现
import numpy as np

def monte_carlo_european(S0, K, T, r, q, sigma, n_paths, option_type='call', seed=42):
    """蒙特卡洛定价欧式期权"""
    np.random.seed(seed)
    Z = np.random.standard_normal(n_paths)

    ST = S0 * np.exp((r - q - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * Z)

    if option_type == 'call':
        payoff = np.maximum(ST - K, 0)
    else:
        payoff = np.maximum(K - ST, 0)

    discounted = np.exp(-r * T) * payoff
    price = np.mean(discounted)
    se = np.std(discounted) / np.sqrt(n_paths)

    return price, se

price, se = monte_carlo_european(100, 100, 1.0, 0.05, 0.02, 0.2, 1000000)
print(f"蒙特卡洛价格: {price:.4f} ± {1.96*se:.4f}")
路径依赖定价示例
import numpy as np

def mc_asian_call(S0, K, T, r, q, sigma, n_obs, n_paths, seed=42):
    """蒙特卡洛定价算术亚式看涨期权"""
    np.random.seed(seed)
    dt = T / n_obs

    S = np.zeros((n_paths, n_obs + 1))
    S[:, 0] = S0

    for t in range(n_obs):
        Z = np.random.standard_normal(n_paths)
        S[:, t+1] = S[:, t] * np.exp(
            (r - q - 0.5 * sigma**2) * dt + sigma * np.sqrt(dt) * Z
        )

    avg_price = np.mean(S[:, 1:], axis=1)
    payoff = np.maximum(avg_price - K, 0)
    discounted = np.exp(-r * T) * payoff

    price = np.mean(discounted)
    se = np.std(discounted) / np.sqrt(n_paths)
    return price, se

price, se = mc_asian_call(100, 100, 1.0, 0.05, 0.02, 0.2, 252, 500000)
print(f"亚式看涨: {price:.4f} ± {1.96*se:.4f}")
方差缩减技术
方差缩减是蒙特卡洛定价的核心优化策略——在不增加路径数的情况下减小标准误。


对偶变量法
对偶变量法（Antithetic Variates）利用 ZZZ 和 −Z-Z−Z 生成两条对称路径：


V^=12M∑m=1M[Φ(S(Zm))+Φ(S(−Zm))]⋅e−rT\hat{V} = \frac{1}{2M}\sum_{m=1}^{M}\left[\Phi(S^{(Z_m)}) + \Phi(S^{(-Z_m)})\right] \cdot e^{-rT}V^=2M1​m=1∑M​[Φ(S(Zm​))+Φ(S(−Zm​))]⋅e−rT
对于单调函数型收益（如 Call/Put），Cov(Φ(S(Z)),Φ(S(−Z)))<0\text{Cov}(\Phi(S^{(Z)}), \Phi(S^{(-Z)})) < 0Cov(Φ(S(Z)),Φ(S(−Z)))<0，方差显著降低。


控制变量法
控制变量法（Control Variates）利用一个期望已知的随机变量来减小方差：


V^CV=V^−β(C^−E[C])\hat{V}_{CV} = \hat{V} - \beta(\hat{C} - \mathbb{E}[C])V^CV​=V^−β(C^−E[C])
最优系数 β∗=Cov(V,C)/Var(C)\beta^* = \text{Cov}(V, C) / \text{Var}(C)β∗=Cov(V,C)/Var(C)。

重要性采样
重要性采样（Importance Sampling）通过改变模拟测度来增加"有效"路径的比例：


V=EP[Φ(X)]=EQ[Φ(X)dPdQ(X)]V = \mathbb{E}^{\mathbb{P}}[\Phi(X)] = \mathbb{E}^{\mathbb{Q}}\left[\Phi(X)\frac{d\mathbb{P}}{d\mathbb{Q}}(X)\right]V=EP[Φ(X)]=EQ[Φ(X)dQdP​(X)]
对于深度虚值期权（到期收益概率很小），将漂移向行权价方向偏移可以大幅减少方差。


分层抽样
分层抽样（Stratified Sampling）将概率空间分为若干子区间，在每个子区间内均匀抽样：


import numpy as np
from scipy.stats import norm

def stratified_normal(n_paths, n_strata=None):
    """分层正态随机数生成"""
    if n_strata is None:
        n_strata = n_paths

    paths_per_stratum = n_paths // n_strata
    U = np.zeros(n_paths)

    for i in range(n_strata):
        lower = i / n_strata
        upper = (i + 1) / n_strata
        U[i*paths_per_stratum:(i+1)*paths_per_stratum] = (
            np.random.uniform(lower, upper, paths_per_stratum)
        )

    np.random.shuffle(U)
    return norm.ppf(U)
方差缩减效果对比
import numpy as np
from scipy.stats import norm as normal_dist

def compare_variance_reduction(S0, K, T, r, q, sigma, n_paths):
    """比较各方差缩减方法"""
    np.random.seed(42)

    Z = np.random.standard_normal(n_paths)
    ST = S0 * np.exp((r - q - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * Z)
    payoff_plain = np.exp(-r * T) * np.maximum(ST - K, 0)

    Z_half = np.random.standard_normal(n_paths // 2)
    ST_pos = S0 * np.exp((r - q - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * Z_half)
    ST_neg = S0 * np.exp((r - q - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * (-Z_half))
    payoff_anti = 0.5 * np.exp(-r * T) * (
        np.maximum(ST_pos - K, 0) + np.maximum(ST_neg - K, 0)
    )

    results = {
        '朴素蒙特卡洛': (np.mean(payoff_plain), np.std(payoff_plain) / np.sqrt(n_paths)),
        '对偶变量法': (np.mean(payoff_anti), np.std(payoff_anti) / np.sqrt(n_paths // 2)),
    }

    for name, (price, se) in results.items():
        print(f"{name:12s}: {price:.4f} ± {1.96*se:.4f}")

compare_variance_reduction(100, 100, 1.0, 0.05, 0.02, 0.2, 100000)
准蒙特卡洛
低差异序列
准蒙特卡洛（Quasi-Monte Carlo, QMC）用确定性的低差异序列代替伪随机数，实现更均匀的空间覆盖，收敛速率可达 O(M−1(log⁡M)d)O(M^{-1}(\log M)^d)O(M−1(logM)d)，对中等维度问题比标准蒙特卡洛快得多。

Sobol 序列示例
import numpy as np
from scipy.stats import qmc, norm

def qmc_european_call(S0, K, T, r, q, sigma, n_paths):
    """准蒙特卡洛定价（Sobol 序列）"""
    sampler = qmc.Sobol(d=1, scramble=True, seed=42)
    U = sampler.random(n_paths)
    Z = norm.ppf(U).flatten()

    ST = S0 * np.exp((r - q - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * Z)
    payoff = np.exp(-r * T) * np.maximum(ST - K, 0)

    price = np.mean(payoff)
    se = np.std(payoff) / np.sqrt(n_paths)
    return price, se

price, se = qmc_european_call(100, 100, 1.0, 0.05, 0.02, 0.2, 65536)
print(f"QMC 价格: {price:.4f} ± {1.96*se:.4f}")
Greeks 的蒙特卡洛估计
有限差分法
最简单的方法是对参数做微小扰动：


Δ≈V(S+h)−V(S−h)2h\Delta \approx \frac{V(S+h) - V(S-h)}{2h}Δ≈2hV(S+h)−V(S−h)​
Γ≈V(S+h)−2V(S)+V(S−h)h2\Gamma \approx \frac{V(S+h) - 2V(S) + V(S-h)}{h^2}Γ≈h2V(S+h)−2V(S)+V(S−h)​
似然比方法
似然比方法（Likelihood Ratio Method / Pathwise Method）通过微分概率密度来计算 Greeks，无需重新模拟：


Δ=e−rTE[Φ(ST)∂ln⁡f(ST)∂S0]\Delta = e^{-rT} \mathbb{E}\left[\Phi(S_T) \frac{\partial \ln f(S_T)}{\partial S_0}\right]Δ=e−rTE[Φ(ST​)∂S0​∂lnf(ST​)​]
对于 GBM：


Δ=e−rTE[Φ(ST)ZσS0T]\Delta = e^{-rT} \mathbb{E}\left[\Phi(S_T) \frac{Z}{\sigma S_0 \sqrt{T}}\right]Δ=e−rTE[Φ(ST​)σS0​T​Z​]
Pathwise 方法
对于收益函数 Φ\PhiΦ 关于 STS_TST​ 可微的情况，Pathwise 方法直接微分：


Δ=e−rTE[Φ′(ST)∂ST∂S0]=e−rTE[Φ′(ST)STS0]\Delta = e^{-rT} \mathbb{E}\left[\Phi'(S_T) \frac{\partial S_T}{\partial S_0}\right] = e^{-rT} \mathbb{E}\left[\Phi'(S_T) \frac{S_T}{S_0}\right]Δ=e−rTE[Φ′(ST​)∂S0​∂ST​​]=e−rTE[Φ′(ST​)S0​ST​​]
对于看涨期权 Φ′(ST)=1ST>K\Phi'(S_T) = \mathbf{1}_{S_T > K}Φ′(ST​)=1ST​>K​，因此：


Δcall=e−rTE[STS01ST>K]\Delta_{call} = e^{-rT} \mathbb{E}\left[\frac{S_T}{S_0} \mathbf{1}_{S_T > K}\right]Δcall​=e−rTE[S0​ST​​1ST​>K​]

总结
蒙特卡洛模拟是衍生品定价数值方法中最为通用的工具。其 O(1/M)O(1/\sqrt{M})O(1/M​) 的收敛速率虽然不如确定性方法（有限差分 O(h2)O(h^2)O(h2)、树 O(1/n)O(1/n)O(1/n)），但维度无关的特性使其成为高维和复杂路径依赖型衍生品定价的首选。方差缩减技术（对偶变量、控制变量、重要性采样、分层抽样）和准蒙特卡洛方法可以将效率提升一到两个数量级。Greeks 的蒙特卡洛计算通过有限差分、似然比和 Pathwise 方法实现。在实务中，蒙特卡洛定价系统是量化交易台的基础设施，处理从简单欧式到多资产奇异期权的全品种定价需求。
