Part II · 衍生品与加密期权基础期权策略高级组合

高级组合

概述

高级组合策略使用三个或更多期权腿（legs），构建出特定的收益形态。这些策略的共同特点是对标的方向性依赖减少，转而表达对波动率或区间的判断。

Straddle（跨式组合）

构建方式

Long Straddle：买入 1 张 ATM Call + 买入 1 张 ATM Put（同行权价、同到期日）

Short Straddle：卖出 1 张 ATM Call + 卖出 1 张 ATM Put

Long Straddle 收益分析

利润
 ↑\        /
 | \      /
 |  \    /
 |   \  /
-|----\/------→ 标的价格
 |    K
 ↓ (-C-P)
指标 公式
最大利润 无限（任一方向大幅波动）
最大亏损 C + P（两个权利金之和）
上方盈亏平衡 K + C + P
下方盈亏平衡 K - C - P

市场观点

  • Long Straddle：预期标的将大幅波动，但不确定方向（做多波动率）
  • Short Straddle：预期标的将在窄幅震荡（做空波动率）

Greeks 特征（Long Straddle）

Greek 值 含义
Delta ≈ 0 方向中性
Gamma 大正值 标的波动越大越有利
Theta 大负值 时间流逝极为不利
Vega 大正值 IV 上升有利

适用场景

  • 财报公布前（预期大幅波动，方向不确定）
  • 重大政策事件前（如央行利率决议、监管政策）
  • IV 处于历史低位（买入波动率"便宜"）

关键风险

Long Straddle 的最大敌人是时间衰减。如果事件未能带来足够大的波动，两个期权的时间价值每天都在消耗。

实战经验：财报前买入 Straddle 通常不划算——因为市场已经通过抬高 IV 定价了事件风险（"事件前 IV 膨胀"）。真正的机会是在事件后 IV 骤降（"Vol Crush"）时做空 Straddle。

Strangle（宽跨式组合）

构建方式

Long Strangle：买入 1 张 OTM Call + 买入 1 张 OTM Put（不同行权价、同到期日）

Short Strangle：卖出 1 张 OTM Call + 卖出 1 张 OTM Put

与 Straddle 的区别

维度 Straddle Strangle
行权价 同一 ATM 行权价 两个不同 OTM 行权价
成本 较高 较低
盈亏平衡区间 较窄 较宽
最大亏损 C + P（较大） C + P（较小）
需要的波动幅度 较小 较大
Gamma 较大 较小

Short Strangle 实战

Short Strangle 是卖出波动率的最流行策略之一（在中国市场也是做市商常用策略）：

典型构建：卖出 25-Delta Put + 卖出 25-Delta Call

  • 盈利区间较宽（两个行权价之间）
  • 只要标的不超出范围就全额获利
  • 时间衰减有利

风险管理：

  • 标的接近任一行权价时考虑调整
  • 设定止损：亏损达到权利金收入的 2-3 倍时平仓
  • 避免在高 IV 但即将有大事件时进场

Iron Condor（铁鹰式）

构建方式

Iron Condor = Bull Put Spread + Bear Call Spread：

  1. 卖出 OTM Put（较高行权价）
  2. 买入更深 OTM Put（较低行权价）
  3. 卖出 OTM Call（较低行权价）
  4. 买入更深 OTM Call（较高行权价）

等价于 Short Strangle + 两个保护腿（限定最大亏损）。

收益分析

利润
         ____________________
        /                    \
Net   _/                      \_
Credit |  K1    K2     K3    K4  |→ 标的价格
       |                        |
Max   _|________________________|_
Loss
指标 公式
最大利润 Net Credit（四腿净收入）
最大亏损 (K2 - K1) - Net Credit 或 (K4 - K3) - Net Credit
盈利区间 K2 - Net Credit 到 K3 + Net Credit

优势

  • 风险有限：最大亏损确定，不会无限
  • 高胜率：只要标的不出大范围就获利
  • 保证金友好：中国组合保证金制度下效率高

适用场景

  • 预期标的在一定区间内震荡
  • IV 偏高（权利金丰厚）
  • 想做空波动率但不愿承受无限风险

调整技巧

当标的接近一侧边界时：

  • Rolling：将受威胁的一侧向外展（更远的行权价或更远的到期日）
  • 减仓：平掉受威胁的一侧
  • 对称化：将另一侧也调整至更有利位置
Butterfly（蝶式组合）
构建方式（Long Call Butterfly）
    

  1. 买入 1 张低行权价 Call（K1）
    2. 

  2. 卖出 2 张中间行权价 Call（K2）
    3. 

  3. 买入 1 张高行权价 Call（K3）
    4. 



其中 K2 = (K1 + K3) / 2（等间距）

S_T = K2（标的恰好等于中间行权价）

K1 + Net Debit 和 K3 - Net Debit





特点
    

  • 成本极低：四腿组合的净支出通常很小

  • 最大利润集中：需要标的精确落在 K2 附近
    • 

  • 低成本高回报：风险回报比可能非常高（但概率低）
    • 



Iron Butterfly
将 Butterfly 用 Put + Call 构建：


    

  • 卖出 1 张 ATM Call + 卖出 1 张 ATM Put
    • 

  • 买入 1 张 OTM Call + 买入 1 张 OTM Put
    • 



相当于 Short Straddle + 两个保护腿。收入型策略（Credit），盈利区间比 Iron Condor 窄但最大利润更大。


Ratio Spread（比率价差）
构建方式
Call Ratio Spread：买入 1 张 ATM Call + 卖出 2 张 OTM Call


收益特征
    

  • 低行权价以上开始盈利
    • 

  • 在高行权价处利润最大
    • 

  • 超过高行权价后利润下降（因为多卖了 1 张 Call）
    • 

  • 如果标的大幅上涨，可能产生亏损
    • 



适用场景
    

  • 温和看涨但不认为会暴涨
    • 

  • 通过多卖 1 张 Call 降低成本（甚至零成本）
    • 

  • 隐含波动率偏高时效果更好（卖出的期权更值钱）
    • 



风险提示
Ratio Spread 有一个方向的无限风险（多卖的那张期权如果被深度行权）。必须设定严格的止损或使用 Broken Wing（加一个保护腿）。

组合策略的管理原则
入场前
    

  1. 明确市场观点：方向性 + 波动率 + 时间框架
    2. 

  2. 选择匹配策略：使用决策树筛选
    3. 

  3. 计算风险回报比：最大亏损 / 最大利润 ≥ 1:2
    4. 

  4. 设定退出规则：止损点、止盈点、时间止损
    5. 



持有期间
    

  1. 监控 Greeks：尤其是 Delta 和 Gamma 的变化
    2. 

  2. 观察 IV 变化：IV 变化可能比标的移动影响更大
    3. 

  3. 考虑 Rolling：将接近到期的腿展期到下月
    4. 

  4. 纪律执行：到达止损点必须执行，不幻想反转
    5. 



平仓原则
    

  • 盈利达到最大利润的 50-70% → 考虑平仓（避免最后的 Gamma 风险）
    • 

  • 亏损达到最大可接受值 → 止损平仓
    • 

  • 剩余时间不足 7 天 → 除非深度实值，否则平仓避免 Gamma 爆炸
    • 

  • IV 出现大幅变化 → 重新评估策略逻辑是否仍然成立
    • 



本节小结
    

  • Straddle/Strangle 是做多/做空波动率的经典工具，区别在于成本和盈亏平衡区间
    • 

  • Iron Condor 是 Short Strangle 的"安全版"，限定了最大亏损
    • 

  • Butterfly 是低成本精确预测策略，适合对标的位置有精确判断时使用
    • 

  • Ratio Spread 通过不等数量的多空腿降低成本，但引入了单侧无限风险
    • 

  • 策略选择的核心框架：方向性判断 × 波动率判断 × 风险容忍度
    • 

  • 盈利达到 50-70% 最大利润时考虑获利了结，避免在临近到期时承受 Gamma 风险
    •
