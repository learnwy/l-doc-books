Part II · 衍生品与加密期权基础期权策略基础策略

基础策略

策略总览

基础策略是将期权与标的资产（或现金）结合使用的入门级策略。它们不需要复杂的多腿组合，风险相对可控，是个人投资者最先应该掌握的实战工具。

策略 构成 市场观点 目的
Covered Call 持有标的 + 卖出 Call 温和看涨/中性 增强收益
Protective Put 持有标的 + 买入 Put 看涨但防范下跌 保险对冲
Cash-Secured Put 持有现金 + 卖出 Put 温和看涨/愿意接盘 降低买入成本
Collar 持有标的 + 买 Put + 卖 Call 中性/锁定区间 锁定利润区间

Covered Call（备兑开仓）

构建方式

  • 持有标的资产（如 10,000 份 50ETF）
  • 卖出 1 张相同标的的 OTM Call

收益分析

利润

 |    /
 |   /

 | /
-|/------------------→ 标的价格
 |

指标 公式
最大利润 (K - S₀) + C（行权价 - 买入成本 + 权利金）
最大亏损 S₀ - C（标的跌到零，但权利金缓冲部分损失）
盈亏平衡 S₀ - C（低于买入成本一个权利金的位置）

适用场景

  • 持有标的且认为短期不会大涨
  • 愿意在特定价格卖出标的
  • 希望在持有期间获取额外收入（类似"房东收租"）

实战案例

假设持有 10,000 份 300ETF（买入成本 4.00 元/份），当前价格 4.10 元。卖出 1 张行权价 4.30 元、30 天到期的认购期权，收取权利金 0.05 元/份。

到期情景 结果
300ETF = 4.50 被行权，以 4.30 卖出，总利润 = (4.30 - 4.00 + 0.05) × 10,000 = 3,500 元
300ETF = 4.20 不被行权，保留持仓，权利金收入 = 0.05 × 10,000 = 500 元
300ETF = 3.90 不被行权，浮亏 = (4.00 - 3.90 - 0.05) × 10,000 = -500 元（无备兑则亏 1,000）

关键要点

  • 上涨封顶：放弃了超过行权价的上涨收益
  • 下跌缓冲有限：权利金仅提供微小的下跌保护
  • 月频操作：每月到期后可重新卖出新的 Call（"Wheel Strategy"的一部分）
  • 中国市场数据：2025 年上交所统计，备兑开仓策略占个人投资者交易目的的 58.42%，是最主流的收益增强策略

Cash-Secured Put（现金担保卖出看跌）
构建方式
    

  • 账户持有足够现金（= K × 合约单位）
    • 

  • 卖出 1 张 Put
    • 



收益分析




指标
公式





最大利润
P（权利金）




最大亏损
(K - P) × 合约单位（标的跌至零时）




盈亏平衡
K - P（有效买入价 = 行权价 - 权利金）





适用场景
    

  • 看好某标的但认为当前价格偏高，愿意在更低价格买入
    • 

  • "不买也赚钱"：如果到期时标的未跌至行权价以下，白赚权利金
    • 

  • "被指派也开心"：如果被行权，相当于以 K - P 的价格买入标的（低于市价）
    • 



实战思维
Cash-Secured Put 的本质是表达："我愿意在 X 价格买入这个标的"。


    

  • 如果标的不跌到 X → 收取权利金作为"等待费"
    • 

  • 如果标的跌到 X → 以有效价格 X - P 买入（比市场上直接买更便宜）
    • 



风险警示：不要仅因为权利金诱人而卖 Put——只在你真正愿意持有该标的时才使用这个策略。


Wheel Strategy（轮转策略）
将 Cash-Secured Put 和 Covered Call 组合成循环操作：


    

  1. 阶段一：卖出 Put，收取权利金
    2. 

  2. 如果被指派：获得标的 → 进入阶段二
    3. 

  3. 阶段二：对持有的标的做 Covered Call
    4. 

  4. 如果被行权：标的被卖出 → 回到阶段一
    5. 

  5. 循环往复：持续收取权利金
    6.

构建方式
    

  • 持有标的资产
    •

    • 

  • 卖出 1 张 OTM Call（上行封顶，用于支付 Put 成本）
    •

S₀ - K_put + P - C（下跌到Put行权价 + 净权利金成本）




盈亏区间
[K_put, K_call]（利润/亏损在此区间内线性变化）





零成本 Collar
当 OTM Call 权利金恰好等于 OTM Put 权利金时，Collar 的净成本为零。这种"零成本保险"在机构投资者中极为流行。


如何实现：选择 Call 和 Put 使两者权利金相等（通常意味着 Call 的行权价比 Put 的行权价离标的更近）。


适用场景
    

  • 持有大额头寸，已有浮盈想锁定利润区间
    • 

  • 对标的长期看好但短期不确定
    • 

  • 上市公司大股东减持受限时的对冲工具
    • 

  • 即将退休的投资者保护退休金组合
    •

策略选择框架
本节小结
    

  • Covered Call 是最基础的收益增强策略，适合温和看涨的持仓者
    • 

  • Protective Put 是"保险"，成本确定但拖累长期收益
    • 

  • Cash-Secured Put 是"收费等买入"，只在真正想持有标的时使用
    • 

  • Collar 是零成本区间锁定，适合保护已有浮盈
    • 

  • Wheel Strategy 将 Put 和 Call 串联成循环收入来源
    • 

  • 策略选择取决于：是否持有标的 × 市场观点 × 波动率水平
    •
