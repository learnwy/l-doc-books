看涨与看跌期权

期权的本质定义

期权（Option）是一种金融合约，赋予买方（holder）在约定时间内以约定价格买入或卖出标的资产的权利。与期货合约不同，期权买方拥有的是权利而非义务——这种权利与义务的不对称性是理解所有期权概念的基石。

为了获得这项权利，买方需要向卖方（writer）支付一笔费用，称为权利金（Premium）。权利金是买方的最大损失，也是卖方的最大收益。

看涨期权（Call Option）

看涨期权赋予买方在到期日（或到期日之前）以行权价格（Strike Price）买入标的资产的权利。

  • 买方视角：预期标的资产价格上涨，希望锁定一个较低的买入价格
  • 卖方视角：预期标的资产价格不会大幅上涨，愿意承担义务以收取权利金
实例说明：假设某投资者以 0.5 元/份的权利金买入一张行权价为 3.00 元的 50ETF 认购期权（合约单位 10,000 份），总成本为 5,000 元。若到期时 50ETF 价格为 3.80 元：


    

  • 行权收益 = (3.80 - 3.00) × 10,000 = 8,000 元
    • 

  • 净利润 = 8,000 - 5,000 = 3,000 元
    • 

  • 收益率 = 3,000 / 5,000 = 60%
    • 



而同期 50ETF 本身的涨幅仅为 (3.80 - 3.00) / 3.00 ≈ 26.7%，这体现了期权的杠杆效应。


看跌期权（Put Option）
看跌期权赋予买方在到期日（或到期日之前）以行权价格卖出标的资产的权利。


    

  • 买方视角：预期标的资产价格下跌，希望锁定一个较高的卖出价格
    • 

  • 卖方视角：预期标的资产价格不会大幅下跌，愿意承担义务以收取权利金
    • 



实例说明：假设投资者持有 10,000 份 50ETF（当前价格 3.50 元），担心短期下跌，以 0.3 元/份的权利金买入一张行权价为 3.40 元的认沽期权。若 50ETF 跌至 2.90 元：


    

  • 未对冲的亏损 = (3.50 - 2.90) × 10,000 = 6,000 元
    • 

  • 行权收益 = (3.40 - 2.90) × 10,000 = 5,000 元
    • 

  • 权利金成本 = 3,000 元
    • 

  • 实际净亏损 = 6,000 - 5,000 + 3,000 = 4,000 元（相比无保护的 6,000 元大幅降低）
    •

这种不对称性的经济含义是：期权买方付出确定的成本（权利金）来购买一个"保险"，而期权卖方则像保险公司一样，收取保费并承担潜在的大额赔付风险。


内在价值与时间价值
期权的价格（权利金）由两部分组成：


Premium=Intrinsic Value+Time ValuePremium = Intrinsic\ Value + Time\ ValuePremium=Intrinsic Value+Time Value
内在价值（Intrinsic Value）
内在价值是期权立即行权所能获得的收益，反映的是期权的"即时价值"：


    

  • Call 的内在价值 = max(S - K, 0)，其中 S 为标的价格，K 为行权价
    • 

  • Put 的内在价值 = max(K - S, 0)
    • 



内在价值永远不会为负——如果行权无利可图，持有人可以选择不行权。


时间价值（Time Value）
时间价值 = 权利金 - 内在价值，反映的是期权在到期前可能变得更有价值的概率溢价。


时间价值的驱动因素：


    

  • 到期时间：时间越长，标的资产波动的可能性越大，时间价值越高
    • 

  • 波动率：波动率越高，标的资产大幅变动的可能性越大，时间价值越高
    • 

  • 距离平值的程度：平值期权的时间价值最高（不确定性最大）
    • 



时间价值衰减
时间价值并非线性衰减，而是呈加速递减的特征——在最后 30 天内衰减速度显著加快。这一特征对策略选择至关重要：


    

  • 买方不利：持有期权时每天都在损失时间价值
    • 

  • 卖方有利：时间的流逝自动为卖方创造利润
    •

杠杆效应
期权的杠杆效应来源于用少量资金（权利金）控制大额标的资产的能力。杠杆倍数可以近似为：


Leverage≈SPremium×DeltaLeverage ≈ \frac{S}{Premium} × DeltaLeverage≈PremiumS​×Delta
其中 Delta 表示期权价格对标的价格变动的敏感度（详见第二章）。


杠杆的双面性
杠杆放大了收益，也放大了损失的速度：

关键认知：期权杠杆与融资杠杆的本质区别在于——期权亏损有限（最多亏权利金），而融资可能亏损超过本金。但期权亏损的概率更高（时间价值衰减是确定的），这是"以概率换幅度"的博弈。

本节小结
    

  • 期权是一种非线性金融工具，买方拥有权利、卖方承担义务
    • 

  • Call 期权看涨、Put 期权看跌；买方亏损有限，卖方风险敞口大
    • 

  • 权利金 = 内在价值 + 时间价值，时间价值随到期临近加速衰减
    • 

  • 到期收益图（hockey stick）是分析期权策略的基本工具
    • 

  • 期权杠杆源于"用少量权利金控制大额标的"，但时间是买方的敌人
    •
