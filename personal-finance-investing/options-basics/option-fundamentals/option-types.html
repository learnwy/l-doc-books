期权类型与合约要素

按行权方式分类

期权按照买方何时可以行使权利，分为三大类型。行权方式的不同直接影响期权的定价模型和交易策略。

美式期权（American Options）

美式期权允许买方在到期日及之前的任何交易日行使权利。

  • 灵活性最高：买方可以在最有利的时机行权
  • 价格 ≥ 欧式期权：额外的灵活性意味着更高的价值
  • 典型市场：美国股票期权（如 CBOE 上市的个股期权）

提前行权的合理时机：

  • 深度实值的美式 Call：标的资产即将除息，且内在价值远超时间价值
  • 深度实值的美式 Put：将行权收益存入银行获取利息的收益超过继续持有的时间价值

欧式期权（European Options）

欧式期权仅允许买方在到期日当天行使权利。

  • 灵活性较低：只有一次行权机会
  • 定价更简单：BSM 模型直接适用
  • 典型市场：中国 ETF 期权（上交所/深交所）、中金所股指期权、欧洲大部分指数期权

中国实践：中国所有场内期权（ETF 期权、股指期权）均采用欧式，这简化了定价但限制了策略灵活性。投资者无法通过提前行权来锁定利润，必须在到期前通过平仓实现收益。

百慕大期权（Bermudan Options）

百慕大期权允许买方在到期日之前的若干特定日期行权，是美式和欧式的折中。

  • 行权窗口：通常是每月、每季度或特定日期
  • 典型应用：利率衍生品、可转债内嵌期权
  • 定价复杂度：介于美式和欧式之间

期权状态：实值、平值、虚值
根据标的价格与行权价的关系，期权在任何时刻处于三种状态之一：


实值（In-the-Money, ITM）
期权具有正的内在价值，立即行权可获利：


    

  • Call ITM：S > K（标的价格高于行权价）
    • 

  • Put ITM：S < K（标的价格低于行权价）
    • 



平值（At-the-Money, ATM）
标的价格约等于行权价，内在价值接近零：


    

  • Call ATM：S ≈ K
    • 

  • Put ATM：S ≈ K
    • 



平值期权的时间价值最高，Delta 约为 0.5（Call）或 -0.5（Put），对标的价格变动最敏感。


虚值（Out-of-the-Money, OTM）
期权没有内在价值，行权无利可图：


    

  • Call OTM：S < K（标的价格低于行权价）
    • 

  • Put OTM：S > K（标的价格高于行权价）
    • 



虚值期权的全部价值都是时间价值，到期时价值归零的概率最高。

期权链解读要点
    

  1. 隐含波动率分布：不同行权价的隐含波动率差异揭示市场对方向性风险的定价
    2. 

  2. 成交量与持仓量：反映市场参与者的兴趣和仓位集中度
    3. 

  3. PCR（Put-Call Ratio）：认沽/认购比率是重要的情绪指标
    4. 

  4. 价差宽度：买卖价差反映流动性，平值附近通常最窄
    5.

按其他维度分类
按标的资产分类
    

  • 股票期权（Equity Options）：标的为个股（中国暂无场内个股期权）
    • 

  • ETF 期权：标的为交易所交易基金（中国主流品种）
    • 

  • 指数期权（Index Options）：标的为股票指数
    • 

  • 商品期权（Commodity Options）：标的为商品期货合约
    • 

  • 外汇期权（FX Options）：标的为货币对
    • 

  • 利率期权（Interest Rate Options）：标的为利率或债券
    • 



按交易场所分类
    

  • 场内期权（Exchange-traded）：标准化合约，在交易所集中交易，有中央对手方清算
    • 

  • 场外期权（OTC）：定制化合约，双方协商条款，对手方风险较高
    • 



按期权结构分类
    

  • 普通期权（Vanilla Options）：标准的 Call 和 Put
    • 

  • 奇异期权（Exotic Options）：障碍期权、亚式期权、回望期权、二元期权等
    • 



本节小结
    

  • 行权方式分为美式（随时行权）、欧式（仅到期行权）、百慕大（特定日期行权）
    • 

  • 中国场内期权均为欧式，理解这一点对策略选择至关重要
    • 

  • 合约五要素：标的资产、行权价、到期日、合约单位、交割方式
    • 

  • 期权状态（ITM/ATM/OTM）动态变化，决定了期权的内在价值和行为特征
    • 

  • 期权链是实盘交易的核心界面，需关注流动性、隐含波动率和 PCR
    •
