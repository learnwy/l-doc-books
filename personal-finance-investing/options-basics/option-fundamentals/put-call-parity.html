看跌-看涨平价关系

平价关系的直觉

看跌-看涨平价关系（Put-Call Parity）是期权定价理论中最基础、最优雅的关系式。它揭示了一个深刻的事实：在无套利条件下，同一标的、同一行权价、同一到期日的 Call 和 Put 之间存在确定的数学关系。

这意味着你不需要独立地为 Call 和 Put 分别定价——知道一个的价格，就能推导出另一个。这种关系不依赖于任何特定的定价模型（如 BSM），而是由无套利原理直接决定的。

数学推导

欧式期权的平价公式

对于欧式期权，平价关系为：

C−P=S−K⋅e−rTC - P = S - K \cdot e^{-rT}C−P=S−K⋅e−rT

或等价地写为：

C+K⋅e−rT=P+SC + K \cdot e^{-rT} = P + SC+K⋅e−rT=P+S

其中：

  • C = 欧式看涨期权价格
  • P = 欧式看跌期权价格
  • S = 标的资产当前价格
  • K = 行权价格
  • r = 无风险利率
  • T = 到期时间（年化）
  • e−rTe^{-rT}e−rT = 折现因子

直觉理解

公式两边在到期时的收益完全相同：

左边组合：持有 1 份 Call + 持有面值为 K 的零息债券（到期值为 K）

右边组合：持有 1 份 Put + 持有 1 份标的资产

到期时场景 左边组合到期价值 右边组合到期价值
S_T > K (S_T - K) + K = S_T 0 + S_T = S_T
S_T < K 0 + K = K (K - S_T) + S_T = K
S_T = K 0 + K = K 0 + K = K

无论到期时标的价格如何，两个组合的到期价值恒等。因此，在无套利条件下，它们今天的价值也必须相等。

无套利证明

正向套利（C - P > S - Ke^{-rT}）

如果平价关系被打破，例如 Call 相对于 Put 过贵：

C−P>S−K⋅e−rTC - P > S - K \cdot e^{-rT}C−P>S−K⋅e−rT

套利者可以执行以下操作：

  1. 卖出 Call（收取 C）
  2. 买入 Put（支付 P）
  3. 买入标的资产（支付 S）
  4. 借入资金 K⋅e−rTK \cdot e^{-rT}K⋅e−rT（到期偿还 K）

初始现金流 = C - P - S + Ke^{-rT} > 0（净收入）

到期时：

  • 若 S_T > K：Call 被行权，以 K 卖出标的，偿还贷款 K → 净零
  • 若 S_T < K：行使 Put，以 K 卖出标的，偿还贷款 K → 净零
  • 若 S_T = K：Put 和 Call 都不行权，卖出标的得 K，偿还 K → 净零

结论：初始净收入 > 0，到期无风险 → 无风险套利。市场力量将推动价格回归平价。

反向套利（C - P < S - Ke^{-rT}）

类似地，如果 Put 相对过贵，套利者执行相反操作：

  1. 买入 Call
  2. 卖出 Put
  3. 卖空标的资产
  4. 将 S−C+PS - C + PS−C+P 的资金以无风险利率投资
合成头寸（Synthetic Positions）
平价关系的一个重要应用是通过组合不同工具来合成等价的头寸。当某个工具交易不便或成本过高时，合成头寸提供了替代方案。


六种基本合成关系
由 C−P=S−Ke−rTC - P = S - Ke^{-rT}C−P=S−Ke−rT 推导：

合成方式
等式来源





合成 Long Call
Long Put + Long Stock - Short Bond
C = P + S - Ke^{-rT}




合成 Long Put
Long Call - Long Stock + Long Bond
P = C - S + Ke^{-rT}




合成 Long Stock
Long Call - Long Put + Long Bond
S = C - P + Ke^{-rT}




合成 Short Stock
Long Put - Long Call - Long Bond
-S = P - C - Ke^{-rT}




合成 Long Bond
Long Put - Long Call + Long Stock
Ke^{-rT} = P - C + S




合成 Short Bond
Long Call - Long Put - Long Stock
-Ke^{-rT} = C - P - S





合成多头（Synthetic Long Stock）
最常用的合成头寸是合成多头：买入 Call + 卖出 Put（同行权价、同到期日）。


Synthetic Long=Long Call+Short PutSynthetic\ Long = Long\ Call + Short\ PutSynthetic Long=Long Call+Short Put
收益特征：


    

  • 标的上涨 → Call 获利，Put 不被行权 → 盈利
    • 

  • 标的下跌 → Call 归零，Put 被行权（必须买入标的）→ 亏损
    • 

  • 收益曲线与直接持有标的几乎完全相同
    • 



优势：


    

  • 资金效率高：不需要全额购买标的
    • 

  • 在标的难以买入时（如做空限制）提供替代方案
    • 

  • 配合现有头寸实现复杂策略
    • 



合成空头（Synthetic Short Stock）
Synthetic Short=Long Put+Short CallSynthetic\ Short = Long\ Put + Short\ CallSynthetic Short=Long Put+Short Call
在中国市场，融券做空成本高且券源有限，合成空头是实现看跌观点的重要替代：


    

  • 买入平值 Put + 卖出平值 Call
    • 

  • 收益曲线近似于融券卖空
    • 

  • 无需借券，执行更便捷
    • 



平价关系的实际应用
应用一：检验期权定价合理性
交易者可以利用平价关系检验市场报价是否合理：


Implied S=C−P+K⋅e−rTImplied\ S = C - P + K \cdot e^{-rT}Implied S=C−P+K⋅e−rT
如果由期权价格推算出的"隐含标的价格"与实际标的价格存在显著差异，可能存在套利机会或市场微观结构原因（如分红预期、借贷成本）。


应用二：估算股息（Dividends）
对于付息标的，平价关系修正为：


C−P=S−PV(D)−K⋅e−rTC - P = S - PV(D) - K \cdot e^{-rT}C−P=S−PV(D)−K⋅e−rT
其中 PV(D) 为到期前预期股息的现值。通过观察 C - P 的偏差，可以反推市场隐含的股息预期。


应用三：转换套利与反转套利
转换套利（Conversion）：


    

  • Long Stock + Long Put + Short Call（同行权价）
    • 

  • 理论上锁定无风险收益 = Ke^{-rT} - S + C - P
    • 

  • 当 C - P > S - Ke^{-rT} 时有利可图
    • 



反转套利（Reversal）：


    

  • Short Stock + Long Call + Short Put
    • 

  • 当 C - P < S - Ke^{-rT} 时有利可图
    • 



实际交易中的摩擦：


    

  • 买卖价差（Bid-Ask Spread）
    • 

  • 交易手续费
    • 

  • 保证金成本
    • 

  • 做空标的的借券费用
    • 

  • 执行时间差导致的滑点
    • 



这些摩擦成本形成了一个"无套利区间"——只有当偏差超过总摩擦成本时，套利才有利可图。


应用四：波动率套利的基础
平价关系保证了同行权价、同到期日的 Call 和 Put 具有相同的隐含波动率（在无分红的欧式期权中严格成立）。如果观察到 Call 和 Put 的隐含波动率不同，通常是以下原因：


    

  • 标的分红预期差异
    • 

  • 借贷利率不对称
    • 

  • 交易摩擦
    • 

  • 市场微观结构效应
    • 



平价关系的局限与拓展
美式期权的平价关系
美式期权由于提前行权的可能性，平价关系变为不等式：


S−K≤C−P≤S−K⋅e−rTS - K ≤ C - P ≤ S - K \cdot e^{-rT}S−K≤C−P≤S−K⋅e−rT
这意味着美式期权的 C - P 关系只有范围约束，不像欧式那样精确。


考虑分红的修正
对于到期前有确定分红 D（现值 PV(D)）的标的：


C−P=S−PV(D)−K⋅e−rTC - P = S - PV(D) - K \cdot e^{-rT}C−P=S−PV(D)−K⋅e−rT
在中国 ETF 期权市场中，ETF 分红较少且金额较小，通常可以忽略或通过合约调整处理。


考虑借贷利差的修正
当借入利率 rbr_brb​ 和贷出利率 rlr_lrl​ 不同时（rb>rlr_b > r_lrb​>rl​），平价关系变为区间：


S−K⋅e−rbT≤C−P≤S−K⋅e−rlTS - K \cdot e^{-r_b T} ≤ C - P ≤ S - K \cdot e^{-r_l T}S−K⋅e−rb​T≤C−P≤S−K⋅e−rl​T
数值示例
假设以下市场数据：


    

  • 标的资产价格 S = 3.50 元
    • 

  • 行权价 K = 3.50 元（平值）
    • 

  • 到期时间 T = 30 天 = 30/365 年
    • 

  • 无风险利率 r = 2%
    • 

  • Call 价格 C = 0.1200 元
    • 

  • Put 价格 P = 0.1185 元
    • 



验证平价关系：


C−P=0.1200−0.1185=0.0015C - P = 0.1200 - 0.1185 = 0.0015C−P=0.1200−0.1185=0.0015
S−K⋅e−rT=3.50−3.50×e−0.02×30/365=3.50−3.4994=0.0006S - K \cdot e^{-rT} = 3.50 - 3.50 \times e^{-0.02 \times 30/365} = 3.50 - 3.4994 = 0.0006S−K⋅e−rT=3.50−3.50×e−0.02×30/365=3.50−3.4994=0.0006
差异 = 0.0015 - 0.0006 = 0.0009 元


这 0.0009 元的差异在买卖价差（通常 0.001-0.003 元）范围内，说明市场定价合理，无可行套利空间。


本节小结
    

  • Put-Call Parity 是期权定价的基石公式：C−P=S−Ke−rTC - P = S - Ke^{-rT}C−P=S−Ke−rT
    • 

  • 该关系由无套利原理推导，不依赖于任何特定定价模型
    • 

  • 通过合成头寸，可以用 Call+Put+标的+债券四种工具互相复制
    • 

  • 实际应用包括：定价验证、股息估算、转换套利、合成头寸构建
    • 

  • 美式期权的平价关系为不等式，欧式为严格等式
    • 

  • 交易摩擦形成"无套利区间"，只有超过该区间的偏差才有套利价值
    •
