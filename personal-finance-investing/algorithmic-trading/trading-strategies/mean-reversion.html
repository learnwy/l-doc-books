均值回归策略

概述

均值回归（Mean Reversion）是与动量策略相对的另一大经典策略范式。其核心假设是：资产价格围绕某个"均衡水平"上下波动，当价格偏离均衡过远时，会产生回归的力量将价格拉回。这一思想最早可以追溯到 18 世纪的天文学家 Francis Galton 提出的"回归均值"现象，后被广泛应用于金融市场。

在实际交易中，均值回归策略的核心挑战在于：如何定义"均衡水平"？如何判断偏离是否"过远"？偏离是暂时的还是结构性的？这些问题的回答决定了策略的具体实现方式。

理论基础
有效市场与均值回归
在弱式有效市场假说下，价格已经反映了所有历史信息，不应存在可预测的均值回归模式。然而，大量实证研究表明均值回归现象确实存在：

Ornstein-Uhlenbeck（OU）过程
均值回归在数学上可以用 OU 过程建模。这是一个连续时间的均值回归随机过程：


dXt=θ(μ−Xt)dt+σdWtdX_t = \theta(\mu - X_t)dt + \sigma dW_tdXt​=θ(μ−Xt​)dt+σdWt​
其中：


    

  • θ>0\theta > 0θ>0：均值回归速度，值越大回归越快
    • 

  • μ\muμ：长期均衡水平
    • 

  • σ\sigmaσ：波动率
    • 

  • WtW_tWt​：标准布朗运动
    • 



OU 过程的半衰期（价格偏离回归一半所需的时间）为：


t1/2=ln⁡2θt_{1/2} = \frac{\ln 2}{\theta}t1/2​=θln2​
这个半衰期是策略设计的关键参数——如果半衰期太长（如 > 30 天），策略的资金占用效率会很低。


均值回归的统计检验
在实施均值回归策略之前，需要统计检验资产价格是否真的具有均值回归特性。


ADF 检验（Augmented Dickey-Fuller）
ADF 检验是最常用的平稳性检验方法：


import numpy as np
import pandas as pd
from statsmodels.tsa.stattools import adfuller
from statsmodels.regression.linear_model import OLS

class MeanReversionTester:
    """均值回归检验工具"""

    def adf_test(self, series: pd.Series, max_lag: int = None) -> dict:
        result = adfuller(series.dropna(), maxlag=max_lag, regression="c")
        return {
            "adf_statistic": result[0],
            "p_value": result[1],
            "lags_used": result[2],
            "critical_values": result[4],
            "is_stationary": result[1] < 0.05,
        }

    def hurst_exponent(self, series: pd.Series, max_lag: int = 100) -> float:
        lags = range(2, max_lag)
        tau = [
            np.sqrt(np.std(np.subtract(series[lag:].values, series[:-lag].values)))
            for lag in lags
        ]
        poly = np.polyfit(np.log(list(lags)), np.log(tau), 1)
        return poly[0] * 2.0

    def half_life(self, series: pd.Series) -> float:
        lagged = series.shift(1)
        delta = series - lagged
        lagged = lagged.iloc[1:]
        delta = delta.iloc[1:]
        model = OLS(delta, lagged - lagged.mean())
        result = model.fit()
        theta = -result.params[0]
        if theta <= 0:
            return float("inf")
        return np.log(2) / theta

经典均值回归策略实现
布林带策略
布林带（Bollinger Bands）是最直观的均值回归交易工具：


class BollingerBandStrategy:
    """布林带均值回归策略"""

    def __init__(self, window: int = 20, num_std: float = 2.0, exit_std: float = 0.5):
        self.window = window
        self.num_std = num_std
        self.exit_std = exit_std

    def compute_bands(self, prices: pd.Series) -> pd.DataFrame:
        mid = prices.rolling(self.window).mean()
        std = prices.rolling(self.window).std()
        return pd.DataFrame({
            "upper": mid + self.num_std * std,
            "lower": mid - self.num_std * std,
            "mid": mid,
            "exit_upper": mid + self.exit_std * std,
            "exit_lower": mid - self.exit_std * std,
        })

    def generate_signals(self, prices: pd.Series) -> pd.Series:
        bands = self.compute_bands(prices)
        position = pd.Series(0.0, index=prices.index)
        current_pos = 0.0

        for i in range(self.window, len(prices)):
            price = prices.iloc[i]
            if current_pos == 0:
                if price < bands["lower"].iloc[i]:
                    current_pos = 1.0
                elif price > bands["upper"].iloc[i]:
                    current_pos = -1.0
            elif current_pos > 0:
                if price > bands["exit_upper"].iloc[i]:
                    current_pos = 0.0
            elif current_pos < 0:
                if price < bands["exit_lower"].iloc[i]:
                    current_pos = 0.0
            position.iloc[i] = current_pos

        return position
Z-Score 策略
Z-Score 策略将价格标准化后进行交易：


class ZScoreStrategy:
    """Z-Score 均值回归"""

    def __init__(self, lookback: int = 60, entry_z: float = 2.0, exit_z: float = 0.5):
        self.lookback = lookback
        self.entry_z = entry_z
        self.exit_z = exit_z

    def compute_zscore(self, series: pd.Series) -> pd.Series:
        mean = series.rolling(self.lookback).mean()
        std = series.rolling(self.lookback).std()
        return (series - mean) / std

    def generate_signals(self, prices: pd.Series) -> pd.Series:
        zscore = self.compute_zscore(prices)
        signal = pd.Series(0.0, index=prices.index)
        signal[zscore < -self.entry_z] = 1.0
        signal[zscore > self.entry_z] = -1.0
        signal[(zscore > -self.exit_z) & (zscore < self.exit_z)] = 0.0
        return signal.ffill().fillna(0.0)
OU 过程参数估计与交易
将均值回归建模为 OU 过程后，可以用最大似然估计参数：


class OUStrategy:
    """基于 OU 过程的均值回归策略"""

    def __init__(self, calibration_window: int = 252):
        self.calibration_window = calibration_window

    def estimate_ou_params(self, series: pd.Series) -> dict:
        n = len(series)
        dt = 1.0 / 252
        x = series.values
        x_lag = x[:-1]
        x_curr = x[1:]

        sx = np.sum(x_lag)
        sy = np.sum(x_curr)
        sxx = np.sum(x_lag ** 2)
        sxy = np.sum(x_lag * x_curr)
        syy = np.sum(x_curr ** 2)
        n_obs = len(x_lag)

        mu = (sy * sxx - sx * sxy) / (n_obs * (sxx - sxy) - (sx ** 2 - sx * sy))
        theta = -np.log((sxy - mu * sx - mu * sy + n_obs * mu ** 2) /
                        (sxx - 2 * mu * sx + n_obs * mu ** 2)) / dt
        sigma_eq = np.sqrt(
            np.mean((x_curr - x_lag * np.exp(-theta * dt) -
                     mu * (1 - np.exp(-theta * dt))) ** 2) /
            ((1 - np.exp(-2 * theta * dt)) / (2 * theta))
        )

        half_life = np.log(2) / theta if theta > 0 else float("inf")

        return {
            "mu": mu,
            "theta": theta,
            "sigma": sigma_eq,
            "half_life": half_life,
        }

    def optimal_entry_exit(self, params: dict, risk_aversion: float = 1.0) -> dict:
        mu = params["mu"]
        theta = params["theta"]
        sigma = params["sigma"]
        s_bar = sigma / np.sqrt(2 * theta)
        entry_distance = s_bar * np.sqrt(2 * np.log(risk_aversion + 1))
        return {
            "long_entry": mu - entry_distance,
            "short_entry": mu + entry_distance,
            "exit": mu,
        }

均值回归与机器学习
近年来，机器学习方法被引入均值回归策略的多个环节：


    

  1. 均值回归检测：使用分类模型（如 XGBoost）判断当前是否处于均值回归区间
    2. 

  2. 入场时机优化：用强化学习优化入场和出场阈值
    3. 

  3. 体制识别：用隐马尔可夫模型（HMM）识别市场在趋势和均值回归状态之间的切换
    4. 

  4. 特征工程：结合订单簿数据、微观结构特征提升均值回归信号的预测能力
    5. 



class RegimeAwareMeanReversion:
    """体制感知的均值回归策略"""

    def __init__(self, n_regimes: int = 2, lookback: int = 60):
        self.n_regimes = n_regimes
        self.lookback = lookback

    def detect_regime(self, returns: pd.Series) -> np.ndarray:
        from hmmlearn.hmm import GaussianHMM
        model = GaussianHMM(n_components=self.n_regimes, covariance_type="full", n_iter=100)
        X = returns.values.reshape(-1, 1)
        model.fit(X)
        regimes = model.predict(X)

        mean_0 = model.means_[0][0]
        mean_1 = model.means_[1][0]
        var_0 = model.covars_[0][0][0]
        var_1 = model.covars_[1][0][0]

        mr_regime = 0 if var_0 < var_1 else 1
        return regimes, mr_regime

    def apply_strategy(self, prices: pd.Series) -> pd.Series:
        returns = prices.pct_change().dropna()
        regimes, mr_regime = self.detect_regime(returns)
        zscore = (prices - prices.rolling(self.lookback).mean()) / prices.rolling(self.lookback).std()

        signal = pd.Series(0.0, index=prices.index)
        for i in range(len(regimes)):
            if regimes[i] == mr_regime:
                z = zscore.iloc[i + 1]
                if z < -2:
                    signal.iloc[i + 1] = 1.0
                elif z > 2:
                    signal.iloc[i + 1] = -1.0
        return signal
总结
均值回归策略基于价格围绕均衡水平波动的统计特性进行交易。从布林带、Z-Score 等技术指标方法，到 OU 过程建模和参数估计，再到结合体制识别的机器学习方法，均值回归策略的实现方式不断丰富。关键成功要素包括：在交易前进行严格的平稳性检验（ADF 检验、Hurst 指数）、合理估计半衰期以确定持仓周期、设定与偏离程度相匹配的仓位管理规则、以及建立应对结构性偏离的止损机制。在策略组合中，均值回归与动量策略天然互补——前者在震荡市中表现优异，后者在趋势市中获利，二者组合可以显著平滑收益曲线。
