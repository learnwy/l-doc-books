动量与趋势跟踪策略

概述

动量策略（Momentum Strategy）是量化交易中历史最悠久、研究最充分的策略类型之一。其核心假设是：过去表现良好的资产在未来一段时间内倾向于继续表现良好，反之亦然。这一现象最早由 Jegadeesh 和 Titman（1993）在学术上系统性地记录，被称为"动量效应"（Momentum Effect），至今仍是资产定价领域中最具挑战性的异象之一。

趋势跟踪（Trend Following）是动量策略的一个重要子类，专注于识别和跟随中长期价格趋势。从管理期货基金（CTA）到全球宏观对冲基金，趋势跟踪策略管理着数千亿美元的资产规模。

风险因子解释
从风险定价的角度，动量收益可能是对特定风险的补偿：


    

  • 崩盘风险：动量策略在市场剧烈反转时会经历巨大回撤（如 2009 年 3 月的动量崩溃），因此动量溢价可能补偿了这种尾部风险
    • 

  • 流动性风险：高动量股票往往集中在流动性较差的小盘股中
    • 

  • 宏观经济风险：动量收益与经济周期存在一定的相关性
    • 



横截面动量策略
横截面动量（Cross-Sectional Momentum）在同一时间点比较不同资产的历史表现，做多相对强势资产、做空相对弱势资产。


经典实现：排名动量
import numpy as np
import pandas as pd

class CrossSectionalMomentum:
    """横截面动量策略"""

    def __init__(self, lookback: int = 252, holding: int = 21, skip: int = 21):
        self.lookback = lookback
        self.holding = holding
        self.skip = skip

    def compute_signals(self, prices: pd.DataFrame) -> pd.DataFrame:
        returns = prices.pct_change(self.lookback).shift(self.skip)
        ranked = returns.rank(axis=1, pct=True)
        long_threshold = 0.8
        short_threshold = 0.2
        signals = pd.DataFrame(0.0, index=prices.index, columns=prices.columns)
        signals[ranked >= long_threshold] = 1.0
        signals[ranked <= short_threshold] = -1.0
        signals = signals.div(signals.abs().sum(axis=1), axis=0)
        return signals

    def backtest(self, prices: pd.DataFrame) -> pd.Series:
        signals = self.compute_signals(prices)
        daily_returns = prices.pct_change()
        strategy_returns = (signals.shift(1) * daily_returns).sum(axis=1)
        return strategy_returns

时间序列动量策略
时间序列动量（Time-Series Momentum）只关注资产自身的历史表现，不与其他资产比较。Moskowitz、Ooi 和 Pedersen（2012）在 58 个市场上验证了时间序列动量的普遍性。


移动平均交叉系统
移动平均是最经典的趋势跟踪信号：


class MovingAverageCrossover:
    """双均线交叉系统"""

    def __init__(self, fast: int = 50, slow: int = 200):
        self.fast = fast
        self.slow = slow

    def generate_signals(self, prices: pd.Series) -> pd.Series:
        ma_fast = prices.rolling(self.fast).mean()
        ma_slow = prices.rolling(self.slow).mean()
        signal = pd.Series(0.0, index=prices.index)
        signal[ma_fast > ma_slow] = 1.0
        signal[ma_fast < ma_slow] = -1.0
        return signal

    def position_sizing(self, prices: pd.Series, target_vol: float = 0.15) -> pd.Series:
        signal = self.generate_signals(prices)
        realized_vol = prices.pct_change().rolling(63).std() * np.sqrt(252)
        vol_scalar = target_vol / realized_vol
        position = signal * vol_scalar.clip(upper=2.0)
        return position
通道突破系统
通道突破（Channel Breakout）源自 Richard Dennis 的海龟交易系统，在期货市场中有着广泛应用：


class DonchianBreakout:
    """唐奇安通道突破"""

    def __init__(self, entry_period: int = 55, exit_period: int = 20):
        self.entry_period = entry_period
        self.exit_period = exit_period

    def generate_signals(self, high: pd.Series, low: pd.Series, close: pd.Series) -> pd.Series:
        upper_entry = high.rolling(self.entry_period).max()
        lower_entry = low.rolling(self.entry_period).min()
        upper_exit = high.rolling(self.exit_period).max()
        lower_exit = low.rolling(self.exit_period).min()

        position = pd.Series(0.0, index=close.index)
        current_pos = 0.0

        for i in range(self.entry_period, len(close)):
            if current_pos == 0:
                if close.iloc[i] > upper_entry.iloc[i - 1]:
                    current_pos = 1.0
                elif close.iloc[i] < lower_entry.iloc[i - 1]:
                    current_pos = -1.0
            elif current_pos > 0:
                if close.iloc[i] < lower_exit.iloc[i - 1]:
                    current_pos = 0.0
            elif current_pos < 0:
                if close.iloc[i] > upper_exit.iloc[i - 1]:
                    current_pos = 0.0
            position.iloc[i] = current_pos

        return position
自适应动量系统
传统动量系统使用固定参数，无法适应变化的市场环境。自适应系统尝试根据市场状态动态调整策略参数。


波动率自适应
class AdaptiveMomentum:
    """波动率自适应动量"""

    def __init__(self, base_lookback: int = 200, vol_window: int = 63):
        self.base_lookback = base_lookback
        self.vol_window = vol_window

    def adaptive_lookback(self, prices: pd.Series) -> pd.Series:
        vol = prices.pct_change().rolling(self.vol_window).std()
        median_vol = vol.rolling(252).median()
        vol_ratio = vol / median_vol
        adaptive_lb = (self.base_lookback / vol_ratio).clip(lower=20, upper=500).astype(int)
        return adaptive_lb

    def generate_signals(self, prices: pd.Series) -> pd.Series:
        adaptive_lb = self.adaptive_lookback(prices)
        signal = pd.Series(0.0, index=prices.index)

        for i in range(500, len(prices)):
            lb = adaptive_lb.iloc[i]
            ma = prices.iloc[i - lb:i].mean()
            signal.iloc[i] = 1.0 if prices.iloc[i] > ma else -1.0

        return signal

class MultiTimeframeMomentum:
    """多时间框架动量"""

    def __init__(self):
        self.timeframes = [
            {"lookback": 21, "weight": 0.2},
            {"lookback": 126, "weight": 0.5},
            {"lookback": 252, "weight": 0.3},
        ]

    def composite_signal(self, prices: pd.Series) -> pd.Series:
        composite = pd.Series(0.0, index=prices.index)
        for tf in self.timeframes:
            ret = prices.pct_change(tf["lookback"])
            zscore = (ret - ret.rolling(252).mean()) / ret.rolling(252).std()
            normalized = zscore.clip(-3, 3) / 3
            composite += normalized * tf["weight"]
        return composite
动量策略的风险管理
动量崩溃
动量策略最大的风险是"动量崩溃"（Momentum Crash），即市场急剧反转时动量组合遭受巨大亏损。典型案例包括：


    

  • 2009 年 3 月：全球金融危机后的剧烈反弹，做空的弱势股暴涨导致严重亏损
    • 

  • 2020 年 11 月：新冠疫苗消息引发价值股剧烈反弹，动量策略大幅回撤
    • 

  • 2023 年 3 月：硅谷银行危机后的银行股反弹
    • 



风险缓解措施
class MomentumRiskManager:
    """动量策略风险管理"""

    def __init__(self, max_drawdown: float = 0.15, vol_target: float = 0.12):
        self.max_drawdown = max_drawdown
        self.vol_target = vol_target

    def dynamic_hedge(self, momentum_signal: pd.Series, market_return: pd.Series) -> pd.Series:
        rolling_beta = (
            momentum_signal.rolling(63).cov(market_return)
            / market_return.rolling(63).var()
        )
        hedged_signal = momentum_signal - rolling_beta * market_return
        return hedged_signal

    def crash_protection(self, returns: pd.Series, lookback: int = 21) -> float:
        recent_vol = returns.iloc[-lookback:].std() * np.sqrt(252)
        long_vol = returns.iloc[-252:].std() * np.sqrt(252)
        vol_expansion = recent_vol / long_vol

        recent_skew = returns.iloc[-lookback:].skew()
        crash_score = vol_expansion * max(0, -recent_skew)

        if crash_score > 2.0:
            return 0.25
        elif crash_score > 1.5:
            return 0.5
        else:
            return 1.0
动量策略的衰减与演变
近年来（2020-2025），传统动量策略面临若干挑战：


    

  1. 交易拥挤：量化基金的普及使得动量因子的超额收益逐步衰减
    2. 

  2. 因子时序变化：动量效应在不同市场周期中表现差异显著
    3. 

  3. 交易成本压力：高换手率策略在流动性降低时表现恶化
    4. 



应对方向包括：


    

  • 增强型动量：结合基本面信号（如 SUE、分析师修正）过滤纯价格动量
    • 

  • 另类数据动量：利用新闻情绪、社交媒体、卫星图像等非传统数据源
    • 

  • 机器学习动量：使用 LSTM、Transformer 等模型捕捉非线性动量模式
    • 

  • 低频动量：降低交易频率，从日频/周频转向月频信号以降低交易成本
    • 



总结
动量与趋势跟踪策略是量化交易的基石之一。从横截面排名动量到时间序列趋势跟踪，从固定参数系统到自适应框架，这一策略族群不断演进。关键要点包括：理解动量效应的行为金融学基础、合理选择回望期和持仓期参数、通过波动率调整和多时间框架组合提升稳健性、以及建立针对动量崩溃的风险管理机制。在策略日益拥挤的当下，将传统动量与另类数据和机器学习方法相结合，是保持策略竞争力的重要方向。
