压力测试与情景分析

概述

压力测试（Stress Testing）和情景分析（Scenario Analysis）是风险管理中超越统计模型的关键补充工具。当统计模型基于历史数据和分布假设估计风险时，压力测试则通过构造极端但合理的假设情景，评估投资组合在危机条件下的潜在损失。2008 年金融危机深刻揭示了统计模型在尾部风险估计上的不足，此后压力测试从辅助工具跃升为监管核心要求。

Basel III 将压力测试纳入资本充足性评估流程（ICAAP），美联储的综合资本分析与审查（CCAR）和欧洲银行管理局（EBA）的年度压力测试已成为全球系统重要性银行的必修科目。压力测试不仅是合规义务，更是风险管理者理解组合脆弱性、发现模型盲区、制定应急预案的核心手段。

import numpy as np
import pandas as pd

def historical_scenario_pnl(portfolio_sensitivities, scenario_shocks):
    pnl = 0
    details = {}
    for factor, shock in scenario_shocks.items():
        if factor in portfolio_sensitivities:
            factor_pnl = portfolio_sensitivities[factor] * shock
            pnl += factor_pnl
            details[factor] = factor_pnl
    return pnl, details

portfolio = {
    'equity_delta': -5_000_000,
    'equity_vega': 2_000_000,
    'rate_dv01': -150_000,
    'credit_cs01': -80_000,
    'fx_delta_usd': 3_000_000,
}

gfc_scenario = {
    'equity_delta': -0.40,
    'equity_vega': 0.50,
    'rate_dv01': -150,
    'credit_cs01': 300,
    'fx_delta_usd': 0.15,
}

total_pnl, breakdown = historical_scenario_pnl(portfolio, gfc_scenario)
print(f"全球金融危机情景总损益: ${total_pnl:,.0f}")
for factor, pnl in sorted(breakdown.items(), key=lambda x: x[1]):
    print(f"  {factor}: ${pnl:,.0f}")

情景构造的关键原则
    

  1. 内在一致性：情景中的各风险因子变动应符合经济逻辑（如央行加息→债券下跌→信用利差扩大）
    2. 

  2. 极端但合理：冲击幅度应超出正常波动但有历史先例支撑
    3. 

  3. 全面覆盖：不仅包括直接冲击，还应涵盖二阶效应（流动性枯竭、保证金追缴等）
    4. 

  4. 可操作性：情景结果应能转化为风险限额调整或对冲行动
    5. 



宏观情景模型
结构化的宏观情景通常通过宏观经济模型（如 VAR 模型）将宏观变量映射到金融风险因子：


Yt=A1Yt−1+…+ApYt−p+ut\mathbf{Y}_t = \mathbf{A}_1 \mathbf{Y}_{t-1} + \ldots + \mathbf{A}_p \mathbf{Y}_{t-p} + \mathbf{u}_tYt​=A1​Yt−1​+…+Ap​Yt−p​+ut​
其中 Yt\mathbf{Y}_tYt​ 包含 GDP 增长率、通胀率、失业率等宏观变量。通过脉冲响应函数，可以从宏观冲击推导出利率、信用利差、股票指数等金融因子的变动路径。


反向压力测试
反向压力测试从预设的损失阈值或机构存续性条件出发，反推可能导致该结果的情景组合。


方法框架
寻找 Δf∗=arg⁡min⁡∣∣Δf∣∣s.t. L(Δf)≥Lthreshold\text{寻找 } \boldsymbol{\Delta f}^* = \arg\min ||\boldsymbol{\Delta f}|| \quad \text{s.t. } L(\boldsymbol{\Delta f}) \geq L_{threshold}寻找 Δf∗=argmin∣∣Δf∣∣s.t. L(Δf)≥Lthreshold​
即在满足损失阈值的约束下，找到最小幅度（因此最可能发生）的风险因子变动组合。


from scipy.optimize import minimize

def reverse_stress_test(sensitivities, loss_threshold, cov_matrix, factor_names):
    n_factors = len(factor_names)

    def objective(delta_f):
        return delta_f @ np.linalg.inv(cov_matrix) @ delta_f

    def loss_constraint(delta_f):
        loss = sum(sensitivities[f] * delta_f[i]
                   for i, f in enumerate(factor_names)
                   if f in sensitivities)
        return loss - loss_threshold

    x0 = np.zeros(n_factors)
    constraints = {'type': 'ineq', 'fun': loss_constraint}

    result = minimize(objective, x0, constraints=constraints, method='SLSQP')

    scenario = {f: result.x[i] for i, f in enumerate(factor_names)}
    mahalanobis_dist = np.sqrt(result.fun)

    return scenario, mahalanobis_dist
反向压力测试的核心价值在于揭示机构可能未意识到的脆弱性——那些看似不相关的风险因子在特定组合下可能产生灾难性后果。

欧洲压力测试采用"静态资产负债表"假设，即假设银行在压力期间不调整业务规模和结构，重点考察银行在冻结状态下承受冲击的能力。


中国银行业压力测试
中国银保监会要求商业银行开展信用风险、市场风险、流动性风险等维度的压力测试，重点关注房地产贷款、地方政府融资平台和产能过剩行业的风险敞口。


压力测试的技术挑战
情景一致性校验
多因子情景的内部一致性是最大挑战。检验方法包括：


    

  1. 历史校准：检查因子联合变动是否在历史极端事件范围内
    2. 

  2. 模型校准：使用宏观经济模型检验因子变动的因果一致性
    3. 

  3. Mahalanobis 距离：d=(Δf)⊤Σ−1(Δf)d = \sqrt{(\Delta\mathbf{f})^\top \Sigma^{-1} (\Delta\mathbf{f})}d=(Δf)⊤Σ−1(Δf)​，过大的距离意味着情景过度极端
    4. 



非线性效应
线性灵敏度分析在大幅冲击下失效。含期权的组合需要完全重估（full revaluation）：


ΔP=P(f+Δf)−P(f)\Delta P = P(\mathbf{f} + \Delta\mathbf{f}) - P(\mathbf{f})ΔP=P(f+Δf)−P(f)
而非近似为：


ΔP≈∑iδiΔfi+12∑iγi(Δfi)2\Delta P \approx \sum_i \delta_i \Delta f_i + \frac{1}{2}\sum_i \gamma_i (\Delta f_i)^2ΔP≈i∑​δi​Δfi​+21​i∑​γi​(Δfi​)2
流动性维度
压力测试应纳入流动性恶化效应：


    

  • 买卖价差扩大导致的额外损失

    • 

  • 保证金追缴引发的强制平仓
    •

总结
压力测试和情景分析是统计风险模型的必要补充，弥补了 VaR/CVaR 等度量在极端事件建模上的不足。有效的压力测试程序需要：多类型情景覆盖（历史、假设、反向）、情景构造的经济一致性、完全重估的估值方法、流动性维度的纳入，以及将结果转化为可操作的风险管理行动。随着监管要求日趋严格，压力测试已从辅助工具演变为风险管理的核心支柱。
