风险归因与分解

概述

风险归因（Risk Attribution）将投资组合的整体风险分解到各个组成维度——资产类别、风险因子、交易策略或个体头寸。风险归因回答的核心问题是"我的风险来自哪里"，这是风险预算（risk budgeting）、限额管理和组合优化的基础。

与绩效归因（Performance Attribution）关注已实现收益的分解不同，风险归因聚焦于前瞻性的风险暴露结构。理解组合风险的来源分布，使得投资经理和风险管理者能够：识别非预期的风险集中、验证投资组合是否符合风险预算、优化风险-收益权衡，以及在风险限额框架下进行有效的头寸管理。

风险分解的数学框架

欧拉分解（Euler Decomposition）

对于正齐次风险度量 ρ\rhoρ（满足 ρ(λX)=λρ(X)\rho(\lambda X) = \lambda \rho(X)ρ(λX)=λρ(X)），欧拉定理保证了完全分解：

ρ(X)=∑i=1nwi∂ρ(X)∂wi\rho(X) = \sum_{i=1}^{n} w_i \frac{\partial \rho(X)}{\partial w_i}ρ(X)=i=1∑n​wi​∂wi​∂ρ(X)​

其中 wiw_iwi​ 为第 iii 个头寸的权重，wi∂ρ∂wiw_i \frac{\partial \rho}{\partial w_i}wi​∂wi​∂ρ​ 即为第 iii 个头寸的风险贡献。

VaR 的风险贡献

对于组合 VaR，第 iii 个资产的边际风险贡献和风险贡献为：

边际 VaR（Marginal VaR）：

MVaRi=∂VaR∂wi\text{MVaR}_i = \frac{\partial \text{VaR}}{\partial w_i}MVaRi​=∂wi​∂VaR​

分量 VaR（Component VaR）：

CVaRi=wi⋅MVaRi\text{CVaR}_i = w_i \cdot \text{MVaR}_iCVaRi​=wi​⋅MVaRi​

在正态分布假设下：

MVaRi=(Σw)iσpzα\text{MVaR}_i = \frac{(\Sigma \mathbf{w})_i}{\sigma_p} z_\alphaMVaRi​=σp​(Σw)i​​zα​

因此：

CVaRi=wi(Σw)iσpzα=wi∑jwjσijσpzα\text{CVaR}_i = w_i \frac{(\Sigma \mathbf{w})_i}{\sigma_p} z_\alpha = \frac{w_i \sum_j w_j \sigma_{ij}}{\sigma_p} z_\alphaCVaRi​=wi​σp​(Σw)i​​zα​=σp​wi​∑j​wj​σij​​zα​

CVaR（ES）的风险贡献

CVaR 作为一致性风险度量，其分量分解更为自然：

ESα(X)=∑i=1nwi⋅E[ri∣rp≤−VaRα]\text{ES}_\alpha(X) = \sum_{i=1}^{n} w_i \cdot E[r_i \mid r_p \leq -\text{VaR}_\alpha]ESα​(X)=i=1∑n​wi​⋅E[ri​∣rp​≤−VaRα​]

即第 iii 个资产的 CVaR 贡献等于其在组合损失超过 VaR 条件下的条件期望损失。

Python 实现
import numpy as np

def portfolio_risk_decomposition(weights, cov_matrix, asset_names=None):
    n = len(weights)
    if asset_names is None:
        asset_names = [f"资产{i+1}" for i in range(n)]

    port_var = weights @ cov_matrix @ weights
    port_vol = np.sqrt(port_var)

    marginal_risk = (cov_matrix @ weights) / port_vol
    component_risk = weights * marginal_risk
    pct_contribution = component_risk / port_vol * 100

    results = {
        'portfolio_vol': port_vol,
        'decomposition': []
    }

    for i in range(n):
        results['decomposition'].append({
            'asset': asset_names[i],
            'weight': weights[i],
            'marginal_risk': marginal_risk[i],
            'component_risk': component_risk[i],
            'pct_contribution': pct_contribution[i]
        })

    return results

def factor_risk_attribution(weights, factor_loadings, factor_cov,
                           specific_var, factor_names=None):
    n_assets, n_factors = factor_loadings.shape
    if factor_names is None:
        factor_names = [f"因子{k+1}" for k in range(n_factors)]

    port_factor_exposure = factor_loadings.T @ weights
    factor_risk_var = port_factor_exposure @ factor_cov @ port_factor_exposure
    specific_risk_var = weights @ np.diag(specific_var) @ weights
    total_var = factor_risk_var + specific_risk_var
    total_vol = np.sqrt(total_var)

    factor_marginal = (factor_cov @ port_factor_exposure) / total_vol
    factor_component = port_factor_exposure * factor_marginal

    results = {
        'total_vol': total_vol,
        'factor_risk_pct': factor_risk_var / total_var * 100,
        'specific_risk_pct': specific_risk_var / total_var * 100,
        'factor_attribution': []
    }

    for k in range(n_factors):
        results['factor_attribution'].append({
            'factor': factor_names[k],
            'exposure': port_factor_exposure[k],
            'risk_contribution': factor_component[k],
            'pct_of_total': factor_component[k] / total_vol * 100
        })

    return results

weights = np.array([0.3, 0.25, 0.2, 0.15, 0.1])
cov = np.array([
    [0.04, 0.012, 0.008, 0.006, 0.004],
    [0.012, 0.06, 0.015, 0.009, 0.006],
    [0.008, 0.015, 0.03, 0.012, 0.008],
    [0.006, 0.009, 0.012, 0.05, 0.010],
    [0.004, 0.006, 0.008, 0.010, 0.02]
])
names = ["大盘股", "小盘股", "债券", "商品", "REIT"]

result = portfolio_risk_decomposition(weights, cov, names)
print(f"组合年化波动率: {result['portfolio_vol']:.2%}\n")
print(f"{'资产':<8} {'权重':>6} {'边际风险':>8} {'风险贡献':>8} {'占比':>6}")
print("-" * 42)
for d in result['decomposition']:
    print(f"{d['asset']:<8} {d['weight']:>6.1%} {d['marginal_risk']:>8.4f} "
          f"{d['component_risk']:>8.4f} {d['pct_contribution']:>5.1f}%")
风险预算
风险预算的定义
风险预算将组合的总风险容量按预设比例分配给各资产类别或策略：


RBi=θi⋅σp,∑i=1nθi=1\text{RB}_i = \theta_i \cdot \sigma_p, \quad \sum_{i=1}^{n}\theta_i = 1RBi​=θi​⋅σp​,i=1∑n​θi​=1
其中 θi\theta_iθi​ 为第 iii 个资产的目标风险贡献比例。


等风险贡献组合（Risk Parity）
Risk Parity 策略要求每个资产的风险贡献相等：


wi⋅(Σw)iσp=σpn,∀iw_i \cdot \frac{(\Sigma \mathbf{w})_i}{\sigma_p} = \frac{\sigma_p}{n}, \quad \forall iwi​⋅σp​(Σw)i​​=nσp​​,∀i
等价于求解优化问题：


min⁡w∑i=1n∑j=1n(wi(Σw)i−wj(Σw)j)2\min_{\mathbf{w}} \sum_{i=1}^{n}\sum_{j=1}^{n}\left(w_i(\Sigma\mathbf{w})_i - w_j(\Sigma\mathbf{w})_j\right)^2wmin​i=1∑n​j=1∑n​(wi​(Σw)i​−wj​(Σw)j​)2
def risk_parity_weights(cov_matrix, tol=1e-8, max_iter=1000):
    n = cov_matrix.shape[0]
    w = np.ones(n) / n

    for iteration in range(max_iter):
        port_var = w @ cov_matrix @ w
        port_vol = np.sqrt(port_var)
        marginal_risk = (cov_matrix @ w) / port_vol
        risk_contrib = w * marginal_risk
        target_rc = port_vol / n

        w_new = w * (target_rc / risk_contrib)
        w_new = w_new / np.sum(w_new)

        if np.max(np.abs(w_new - w)) < tol:
            break
        w = w_new

    return w

rp_weights = risk_parity_weights(cov)
print("\nRisk Parity 权重:")
for name, w in zip(names, rp_weights):
    print(f"  {name}: {w:.2%}")

IVaRi=VaR(w)−VaR(w−i)\text{IVaR}_i = \text{VaR}(\mathbf{w}) - \text{VaR}(\mathbf{w}_{-i})IVaRi​=VaR(w)−VaR(w−i​)

总结
风险归因是连接风险度量与风险管理决策的桥梁。欧拉分解为正齐次风险度量提供了数学上严格的分解框架。因子风险模型将归因从资产层面提升到因子层面，揭示系统性风险来源。风险预算和 Risk Parity 将风险归因转化为主动的组合构建工具。增量风险分析指导头寸调整决策。在实践中，多层次风险归因框架结合蒙特卡洛方法，为包含复杂衍生品的组合提供全面的风险透视。
