气候金融风险

概述

气候金融风险（Climate Financial Risk）是量化风险管理领域中发展最迅速的前沿方向。气候变化通过物理风险（极端天气事件、海平面上升）和转型风险（低碳政策、技术变革、市场偏好转变）两条路径，对金融资产估值、信贷质量和投资组合收益产生深远影响。

2015 年巴黎协定后，金融稳定委员会（FSB）成立了气候相关金融信息披露工作组（TCFD），2017 年发布的 TCFD 框架成为全球气候金融风险管理的基准标准。2021 年起，ISSB（国际可持续准则理事会）在 TCFD 基础上制定了强制性气候信息披露标准 IFRS S2。各国央行通过 NGFS（绿色金融网络）发布气候情景，将气候压力测试纳入金融监管框架。截至 2025 年，欧盟、英国、日本、新加坡等主要市场已将气候压力测试制度化。

框架流程
信用风险传导
气候因素影响企业信用质量的路径：


PDclimate=PDbaseline×exp⁡(βphysical⋅Xphysical+βtransition⋅Xtransition)PD_{climate} = PD_{baseline} \times \exp(\beta_{physical} \cdot X_{physical} + \beta_{transition} \cdot X_{transition})PDclimate​=PDbaseline​×exp(βphysical​⋅Xphysical​+βtransition​⋅Xtransition​)
其中 XphysicalX_{physical}Xphysical​ 和 XtransitionX_{transition}Xtransition​ 分别为物理风险和转型风险暴露指标。


Python 实现示例
import numpy as np

def climate_credit_risk_adjustment(baseline_pd, carbon_intensity,
                                    carbon_price_shock, revenue_elasticity,
                                    physical_damage_pct=0):
    carbon_cost_impact = carbon_intensity * carbon_price_shock
    revenue_shock = -carbon_cost_impact * revenue_elasticity
    total_shock = revenue_shock - physical_damage_pct

    pd_multiplier = np.exp(-2.0 * total_shock)
    adjusted_pd = np.minimum(baseline_pd * pd_multiplier, 1.0)

    return {
        'baseline_pd': baseline_pd,
        'adjusted_pd': adjusted_pd,
        'pd_multiplier': pd_multiplier,
        'carbon_cost_impact': carbon_cost_impact,
        'revenue_shock': revenue_shock
    }

sectors = [
    {'name': '石油开采', 'pd': 0.02, 'carbon_intensity': 0.5,
     'revenue_elasticity': 0.3, 'physical_damage': 0.01},
    {'name': '电力(煤电)', 'pd': 0.03, 'carbon_intensity': 0.8,
     'revenue_elasticity': 0.4, 'physical_damage': 0.02},
    {'name': '汽车制造', 'pd': 0.015, 'carbon_intensity': 0.2,
     'revenue_elasticity': 0.5, 'physical_damage': 0.005},
    {'name': '可再生能源', 'pd': 0.025, 'carbon_intensity': 0.02,
     'revenue_elasticity': -0.3, 'physical_damage': 0.01},
    {'name': '科技服务', 'pd': 0.01, 'carbon_intensity': 0.05,
     'revenue_elasticity': 0.1, 'physical_damage': 0.003},
]

carbon_price = 200
print(f"碳价冲击: ${carbon_price}/tCO₂")
print(f"\n{'行业':<12} {'基准PD':>7} {'调整PD':>7} {'倍数':>6} {'碳成本':>7}")
print("-" * 45)
for s in sectors:

        s['pd'], s['carbon_intensity'],

    )

搁浅资产
概念
搁浅资产（Stranded Assets）是指因气候政策、技术变革或市场变化而提前丧失价值的资产。最典型的搁浅资产是未开采的化石燃料储量——若要实现 2°C 目标，全球已探明化石燃料储量的约 60-80% 必须留在地下。

气候 VaR
气候 VaR（Climate VaR）将气候情景下的资产价格变动转化为组合风险度量：


Climate VaR=∑iwi⋅ΔViclimate\text{Climate VaR} = \sum_i w_i \cdot \Delta V_i^{climate}Climate VaR=i∑​wi​⋅ΔViclimate​

总结
气候金融风险正从边缘议题演变为金融风险管理的核心维度。TCFD/ISSB 框架提供了披露标准，NGFS 情景提供了压力测试基准，欧盟 Taxonomy 提供了绿色分类体系。对于量化风险管理者，关键挑战在于：将长周期气候情景转化为可操作的风险指标，处理数据缺口和建模不确定性，以及将气候风险整合到现有的信用风险、市场风险和组合管理框架中。随着监管要求的持续收紧和数据基础设施的不断完善，气候风险量化将成为未来十年风险管理领域最重要的增长方向。
