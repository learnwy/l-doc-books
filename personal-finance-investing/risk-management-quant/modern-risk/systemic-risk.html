系统性风险与宏观审慎

概述

系统性风险（Systemic Risk）是指金融体系中单个或少数机构的失败或困境通过传染、关联和共同暴露等机制，引发整个金融系统功能紊乱，进而对实体经济造成严重负面影响的风险。系统性风险与个体机构风险的根本区别在于：它不能通过分散化消除，且具有强烈的外部性——单个机构的风险决策不会内化其对系统稳定性的影响。

2008 年全球金融危机是系统性风险爆发的典型案例：雷曼兄弟的破产通过衍生品网络、货币市场基金和银行间拆借市场，迅速传导至全球金融体系，导致信贷冻结、资产价格暴跌和大规模经济衰退。此后，宏观审慎（Macroprudential）政策框架应运而生，旨在从系统层面而非个体机构层面管理金融风险。

系统性风险度量
CoVaR
Adrian 和 Brunnermeier（2016）提出的 CoVaR 衡量当某机构 jjj 处于困境时，金融系统的条件风险：


CoVaRαsystem∣j=VaRαsystem∣rj=VaRαj\text{CoVaR}_\alpha^{system|j} = \text{VaR}_\alpha^{system}\left| r_j = \text{VaR}_\alpha^j\right.CoVaRαsystem∣j​=VaRαsystem​​rj​=VaRαj​
机构 jjj 对系统性风险的贡献（ΔCoVaR\Delta\text{CoVaR}ΔCoVaR）：


ΔCoVaRαj=CoVaRαsystem∣j−CoVaRαsystem∣j=median\Delta\text{CoVaR}_\alpha^j = \text{CoVaR}_\alpha^{system|j} - \text{CoVaR}_\alpha^{system|j=\text{median}}ΔCoVaRαj​=CoVaRαsystem∣j​−CoVaRαsystem∣j=median​
SRISK
Brownlees 和 Engle（2017）提出的 SRISK 衡量在市场大幅下跌时，机构的资本缺口：


SRISKi=max⁡(0, k⋅Di−(1−k)⋅Wi⋅(1−LRMESi))\text{SRISK}_i = \max\left(0, \, k \cdot D_i - (1-k) \cdot W_i \cdot (1 - \text{LRMES}_i)\right)SRISKi​=max(0,k⋅Di​−(1−k)⋅Wi​⋅(1−LRMESi​))

import numpy as np
from scipy import stats

def calculate_covar(returns_system, returns_institution, alpha=0.05):
    var_inst = np.percentile(returns_institution, alpha * 100)

    mask = np.abs(returns_institution - var_inst) < np.std(returns_institution) * 0.1
    if np.sum(mask) < 10:
        sorted_inst = np.sort(returns_institution)
        n_tail = max(10, int(alpha * len(returns_institution)))
        tail_indices = np.argsort(returns_institution)[:n_tail]
        conditional_system = returns_system[tail_indices]
    else:
        conditional_system = returns_system[mask]

    covar = np.percentile(conditional_system, alpha * 100)

    median_mask = (np.abs(returns_institution - np.median(returns_institution))
                   < np.std(returns_institution) * 0.1)
    if np.sum(median_mask) < 10:
        median_indices = np.argsort(np.abs(returns_institution - np.median(returns_institution)))[:20]
        median_system = returns_system[median_indices]
    else:
        median_system = returns_system[median_mask]

    covar_median = np.percentile(median_system, alpha * 100)
    delta_covar = covar - covar_median

    return {
        'VaR_institution': var_inst,
        'CoVaR': covar,
        'CoVaR_median': covar_median,
        'DeltaCoVaR': delta_covar
    }

def calculate_srisk(equity, debt, lrmes, k=0.08):
    srisk = max(0, k * debt - (1 - k) * equity * (1 - lrmes))
    return srisk

def simulate_contagion(adjacency_matrix, capital_ratios, initial_default=0,
                      loss_given_default=0.6, threshold=0.0):
    n = len(capital_ratios)
    capital = capital_ratios.copy()
    defaulted = np.zeros(n, dtype=bool)
    defaulted[initial_default] = True
    capital[initial_default] = 0

    round_num = 0
    cascade_history = [{
        'round': 0,
        'new_defaults': [initial_default],
        'total_defaults': 1
    }]

    while True:
        round_num += 1
        new_defaults = []

        for i in range(n):
            if defaulted[i]:
                continue
            loss = 0
            for j in range(n):
                if defaulted[j]:
                    loss += adjacency_matrix[i, j] * loss_given_default
            capital[i] -= loss

            if capital[i] <= threshold:
                new_defaults.append(i)

        if not new_defaults:
            break

        for i in new_defaults:
            defaulted[i] = True
            capital[i] = 0

        cascade_history.append({
            'round': round_num,
            'new_defaults': new_defaults,
            'total_defaults': int(np.sum(defaulted))
        })

    return {
        'total_defaults': int(np.sum(defaulted)),
        'cascade_rounds': round_num,
        'history': cascade_history,
        'remaining_capital': capital
    }

总结
系统性风险管理是后危机时代金融监管的核心创新。从度量层面，CoVaR 和 SRISK 等指标量化了单个机构对系统稳定性的贡献；从方法论层面，网络分析和传染模型揭示了金融系统的脆弱性结构；从政策层面，CCyB、G-SIB 附加资本和恢复处置计划构成了宏观审慎政策的完整工具箱。未来的挑战在于：完善非银行金融中介的系统性风险监控、应对气候变化带来的系统性转型风险，以及在数字金融和 DeFi 快速发展中维护金融稳定。
