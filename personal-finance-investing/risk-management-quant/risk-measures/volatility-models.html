波动率模型与 GARCH 族

概述

波动率是金融风险度量的基础参数，直接影响 VaR 计算、期权定价和资产配置决策。金融市场收益率的波动率呈现出显著的时变特征——波动率聚集（volatility clustering）、均值回归（mean reversion）和杠杆效应（leverage effect）——这些特征使得常数波动率假设严重失真。

GARCH（Generalized Autoregressive Conditional Heteroskedasticity）族模型由 Engle（1982）和 Bollerslev（1986）奠基，通过将条件方差建模为过去收益率平方和过去方差的函数，成功捕捉了波动率的动态演化。经过四十余年的发展，GARCH 族已衍生出数十种变体，分别针对非对称性、长记忆性、多变量依赖等不同特征。

波动率的经验特征

金融资产收益率的波动率呈现以下典型特征：

特征 描述 对建模的意义
波动率聚集 大波动后跟大波动，小波动后跟小波动 需要自回归结构
均值回归 波动率偏离长期均值后会逐渐回归 需要长期均值参数
杠杆效应 负收益对波动率的冲击大于同等正收益 需要非对称项
厚尾分布 标准化残差仍呈厚尾 需要非正态创新分布
长记忆性 波动率自相关函数缓慢衰减 需要分整阶参数

ARCH 模型

基本结构

Engle（1982）提出的 ARCH(q) 模型：

σt2=ω+∑i=1qαiϵt−i2\sigma_t^2 = \omega + \sum_{i=1}^{q} \alpha_i \epsilon_{t-i}^2σt2​=ω+i=1∑q​αi​ϵt−i2​

参数约束：ω>0\omega > 0ω>0，αi≥0\alpha_i \geq 0αi​≥0，∑i=1qαi<1\sum_{i=1}^{q} \alpha_i < 1∑i=1q​αi​<1（保证平稳性）。

无条件方差为：

GARCH 模型

GARCH(p,q) 定义

Bollerslev（1986）通过引入条件方差的滞后项解决了 ARCH 的高阶问题：

σt2=ω+∑i=1qαiϵt−i2+∑j=1pβjσt−j2\sigma_t^2 = \omega + \sum_{i=1}^{q} \alpha_i \epsilon_{t-i}^2 + \sum_{j=1}^{p} \beta_j \sigma_{t-j}^2σt2​=ω+i=1∑q​αi​ϵt−i2​+j=1∑p​βj​σt−j2​

最常用的 GARCH(1,1) 模型：

σt2=ω+αϵt−12+βσt−12\sigma_t^2 = \omega + \alpha \epsilon_{t-1}^2 + \beta \sigma_{t-1}^2σt2​=ω+αϵt−12​+βσt−12​

其中 α+β<1\alpha + \beta < 1α+β<1 保证协方差平稳性，无条件方差为 σˉ2=ω/(1−α−β)\bar{\sigma}^2 = \omega / (1 - \alpha - \beta)σˉ2=ω/(1−α−β)。

波动率半衰期

波动率冲击的半衰期衡量波动率回归均值的速度：

h=ln⁡(0.5)ln⁡(α+β)h = \frac{\ln(0.5)}{\ln(\alpha + \beta)}h=ln(α+β)ln(0.5)​

典型金融序列中 α+β≈0.98\alpha + \beta \approx 0.98α+β≈0.98，对应半衰期约 34 天。

非对称 GARCH 模型
EGARCH 模型
Nelson（1991）提出的指数 GARCH 模型，直接对对数方差建模，自然保证方差为正：

IGARCH 模型
当 α+β=1\alpha + \beta = 1α+β=1 时，GARCH(1,1) 退化为 IGARCH（Integrated GARCH），波动率冲击对未来方差的影响不衰减：

Python 实现
import numpy as np
from scipy.optimize import minimize
from scipy.stats import norm

def garch11_loglik(params, returns):
    omega, alpha, beta = params
    T = len(returns)
    sigma2 = np.zeros(T)
    sigma2[0] = np.var(returns)

    for t in range(1, T):
        sigma2[t] = omega + alpha * returns[t-1]**2 + beta * sigma2[t-1]

    if np.any(sigma2 <= 0):
        return 1e10

    loglik = -0.5 * np.sum(np.log(2 * np.pi) + np.log(sigma2) + returns**2 / sigma2)
    return -loglik

def fit_garch11(returns):
    initial_var = np.var(returns)
    x0 = [initial_var * 0.05, 0.05, 0.90]

    bounds = [(1e-8, None), (1e-8, 0.999), (1e-8, 0.999)]
    constraints = {'type': 'ineq', 'fun': lambda p: 0.999 - p[1] - p[2]}

    result = minimize(
        garch11_loglik, x0, args=(returns,),
        method='SLSQP', bounds=bounds, constraints=constraints
    )

    omega, alpha, beta = result.x
    persistence = alpha + beta
    unconditional_var = omega / (1 - persistence)
    half_life = np.log(0.5) / np.log(persistence)

    return {
        'omega': omega, 'alpha': alpha, 'beta': beta,
        'persistence': persistence,
        'unconditional_vol': np.sqrt(unconditional_var * 252),
        'half_life_days': half_life,
        'log_likelihood': -result.fun
    }

def gjr_garch_loglik(params, returns):
    omega, alpha, gamma, beta = params
    T = len(returns)
    sigma2 = np.zeros(T)
    sigma2[0] = np.var(returns)

    for t in range(1, T):
        indicator = 1.0 if returns[t-1] < 0 else 0.0
        sigma2[t] = (omega + alpha * returns[t-1]**2
                     + gamma * indicator * returns[t-1]**2
                     + beta * sigma2[t-1])

    if np.any(sigma2 <= 0):
        return 1e10

    loglik = -0.5 * np.sum(np.log(2 * np.pi) + np.log(sigma2) + returns**2 / sigma2)
    return -loglik

np.random.seed(42)
T = 2000
omega_true, alpha_true, beta_true = 0.00001, 0.08, 0.90
returns = np.zeros(T)
sigma2 = np.zeros(T)
sigma2[0] = omega_true / (1 - alpha_true - beta_true)

for t in range(1, T):
    sigma2[t] = omega_true + alpha_true * returns[t-1]**2 + beta_true * sigma2[t-1]
    returns[t] = np.sqrt(sigma2[t]) * np.random.standard_normal()

result = fit_garch11(returns)
print(f"GARCH(1,1) 估计结果:")
print(f"  omega = {result['omega']:.6f}")
print(f"  alpha = {result['alpha']:.4f}")
print(f"  beta  = {result['beta']:.4f}")
print(f"  持续性 = {result['persistence']:.4f}")
print(f"  年化波动率 = {result['unconditional_vol']:.2%}")
print(f"  半衰期 = {result['half_life_days']:.1f} 天")

总结
波动率建模是风险管理的技术核心。GARCH 族模型为条件波动率提供了灵活且经过广泛验证的框架。实践中的关键选择包括：是否需要捕捉非对称效应（选择 EGARCH 或 GJR-GARCH）、是否存在长记忆特征（选择 FIGARCH）、创新分布的尾部假设（Student-t 还是 GED），以及多变量情况下的维度与灵活性权衡（DCC 还是 BEKK）。随着高频数据和已实现波动率方法的发展，波动率建模正向参数模型与非参数估计的融合方向演进。
