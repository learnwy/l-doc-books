VaR 与 CVaR 风险度量

概述

Value at Risk（VaR）和 Conditional Value at Risk（CVaR，又称 Expected Shortfall, ES）是现代金融风险管理中最核心的两个度量指标。VaR 回答"在给定置信水平下，投资组合在特定时间窗口内的最大预期损失是多少"，而 CVaR 则进一步回答"当损失超过 VaR 阈值时，平均损失是多少"。

自 1990 年代 J.P. Morgan 推出 RiskMetrics 以来，VaR 成为全球金融机构的标准风险度量工具，并被 Basel II 框架纳入市场风险资本计量。然而，VaR 的理论缺陷——不满足次可加性（subadditivity）、忽视尾部风险分布形态——在 2008 年金融危机中暴露无遗。Basel III/IV 和 FRTB 框架因此转向以 ES（即 CVaR）作为首选风险度量，标志着监管层面对尾部风险认知的根本转变。

VaR 的数学定义

基本定义

设投资组合损失随机变量为 LLL，置信水平为 α∈(0,1)\alpha \in (0,1)α∈(0,1)，VaR 定义为损失分布的 α\alphaα 分位数：

VaRα(L)=inf⁡{l∈R:P(L>l)≤1−α}=FL−1(α)\text{VaR}_\alpha(L) = \inf\{l \in \mathbb{R} : P(L > l) \leq 1 - \alpha\} = F_L^{-1}(\alpha)VaRα​(L)=inf{l∈R:P(L>l)≤1−α}=FL−1​(α)

其中 FL−1F_L^{-1}FL−1​ 为损失分布的广义逆函数。常用置信水平包括 95%、99% 和 99.5%。

蒙特卡洛模拟法
import numpy as np

def monte_carlo_var(mu, cov, weights, horizon=1, n_sims=100000, alpha=0.99):
    n_assets = len(weights)
    cholesky = np.linalg.cholesky(cov)

    z = np.random.standard_normal((n_sims, n_assets))
    correlated_returns = z @ cholesky.T

    portfolio_returns = correlated_returns @ weights * np.sqrt(horizon)
    portfolio_returns += np.dot(weights, mu) * horizon

    losses = -portfolio_returns
    var = np.percentile(losses, alpha * 100)
    return var

mu = np.array([0.08, 0.12, 0.06])
cov = np.array([
    [0.04, 0.006, 0.002],
    [0.006, 0.09, 0.009],
    [0.002, 0.009, 0.01]
])
weights = np.array([0.4, 0.3, 0.3])

var_99 = monte_carlo_var(mu, cov, weights, horizon=10/252, alpha=0.99)
print(f"10 日 99% VaR: {var_99:.4f}")
VaR 的理论缺陷
次可加性违反
VaR 不是一致性风险度量（coherent risk measure），因为它不满足次可加性：


VaRα(LA+LB)≤VaRα(LA)+VaRα(LB)\text{VaR}_\alpha(L_A + L_B) \leq \text{VaR}_\alpha(L_A) + \text{VaR}_\alpha(L_B)VaRα​(LA​+LB​)≤VaRα​(LA​)+VaRα​(LB​)
上述不等式对 VaR 不一定成立。这意味着分散化投资可能导致 VaR 反而增大——违反了"分散化降低风险"的基本原则。


尾部盲区
VaR 仅告知阈值位置，不提供超过阈值后损失的任何信息。两个具有相同 VaR 的投资组合，其尾部风险可能差异巨大：


CVaR（Expected Shortfall）
数学定义
CVaR 定义为损失超过 VaR 条件下的期望值：


CVaRα(L)=E[L∣L≥VaRα(L)]=11−α∫α1VaRu(L) du\text{CVaR}_\alpha(L) = E[L \mid L \geq \text{VaR}_\alpha(L)] = \frac{1}{1-\alpha}\int_\alpha^1 \text{VaR}_u(L) \, duCVaRα​(L)=E[L∣L≥VaRα​(L)]=1−α1​∫α1​VaRu​(L)du

CVaR 的优化表示
Rockafellar 和 Uryasev（2000）给出了 CVaR 的重要优化表示：


CVaRα(L)=min⁡ζ∈R{ζ+11−αE[max⁡(L−ζ,0)]}\text{CVaR}_\alpha(L) = \min_{\zeta \in \mathbb{R}} \left\{ \zeta + \frac{1}{1-\alpha} E\left[\max(L - \zeta, 0)\right] \right\}CVaRα​(L)=ζ∈Rmin​{ζ+1−α1​E[max(L−ζ,0)]}
这个表示使得 CVaR 优化问题可以转化为线性规划，极大地促进了其在组合优化中的应用。


CVaR 计算实现
import numpy as np
from scipy import stats

def parametric_var_cvar(mu, sigma, alpha=0.99):
    z = stats.norm.ppf(alpha)
    var = mu + sigma * z
    cvar = mu + sigma * stats.norm.pdf(z) / (1 - alpha)
    return var, cvar

def historical_var_cvar(losses, alpha=0.99):
    sorted_losses = np.sort(losses)
    n = len(sorted_losses)
    var_index = int(np.ceil(alpha * n)) - 1
    var = sorted_losses[var_index]
    cvar = sorted_losses[var_index:].mean()
    return var, cvar

def mc_var_cvar(returns, weights, n_sims=100000, alpha=0.99):
    mu = returns.mean(axis=0)
    cov = np.cov(returns.T)
    chol = np.linalg.cholesky(cov)

    z = np.random.standard_normal((n_sims, len(weights)))
    sim_returns = z @ chol.T + mu
    portfolio_losses = -(sim_returns @ weights)

    var = np.percentile(portfolio_losses, alpha * 100)
    cvar = portfolio_losses[portfolio_losses >= var].mean()
    return var, cvar

np.random.seed(42)
returns = np.random.multivariate_normal(
    mean=[0.0003, 0.0005],
    cov=[[0.0004, 0.0001], [0.0001, 0.0009]],
    size=1000
)
weights = np.array([0.6, 0.4])
portfolio_losses = -(returns @ weights)

h_var, h_cvar = historical_var_cvar(portfolio_losses)
print(f"历史模拟 VaR(99%): {h_var:.4f}, CVaR(99%): {h_cvar:.4f}")

mc_var, mc_cvar = mc_var_cvar(returns, weights)
print(f"蒙特卡洛 VaR(99%): {mc_var:.4f}, CVaR(99%): {mc_cvar:.4f}")
VaR 回测（Backtesting）
VaR 模型的有效性需要通过回测验证。主要回测方法包括：

LRUC=−2ln⁡px(1−p)T−xp^x(1−p^)T−x∼χ2(1)LR_{UC} = -2\ln\frac{p^x(1-p)^{T-x}}{\hat{p}^x(1-\hat{p})^{T-x}} \sim \chi^2(1)LRUC​=−2lnp^​x(1−p^​)T−xpx(1−p)T−x​∼χ2(1)

实践中的关键考量
时间窗口选择：VaR 和 CVaR 的计算结果高度依赖历史数据窗口。短窗口（如 250 天）响应快但噪声大，长窗口（如 1000 天）稳定但可能包含已不相关的制度。实践中常用 500-750 天窗口配合指数加权。


置信水平与持有期：监管用途通常要求 99% 置信度和 10 日持有期（通过 T\sqrt{T}T​ 缩放或直接模拟）；内部风险管理可能使用 95% 单日 VaR 以提高回测可靠性。


分布假设：正态分布假设严重低估尾部风险。实践中更常采用 Student-t 分布、混合正态分布或非参数方法。对于含期权等非线性头寸的组合，蒙特卡洛方法几乎是唯一可靠的选择。


模型风险：任何 VaR/CVaR 估计都包含模型风险。良好的风险管理实践要求同时运行多个模型（模型委员会方法），并定期进行压力测试作为模型驱动度量的补充。
