交对手信用风险与 XVA

概述

交对手信用风险（Counterparty Credit Risk, CCR）是指场外衍生品交易中，交易对手在合约到期前违约导致的潜在损失。与传统信贷风险不同，CCR 的敞口是双向的且随市场波动而变化——衍生品合约在不同时点可能对任一方具有正或负的市场价值。

XVA（X-Value Adjustment）是对传统无风险衍生品价格的一组估值调整项的统称，将信用风险、资金成本和资本成本纳入衍生品的真实经济价值。2008 年金融危机前，银行间衍生品交易通常忽略交对手信用风险，以 LIBOR 曲线作为无风险利率进行折现。危机后，CVA（信用估值调整）成为最大的单一利润波动来源之一，催生了专业的 XVA 交易台和数十亿美元级别的技术投资。

交对手信用风险度量

基本概念

度量 定义 用途
MtM（盯市价值） 当前合约价值 即时敞口
PFE（潜在未来敞口） 未来敞口的高分位数（通常 97.5%） 信用限额管理
EPE（预期正敞口） 未来正敞口的时间加权平均 监管资本计量
EE（预期敞口） 特定时点的正敞口期望 CVA 计算基础
EEPE（有效预期正敞口） EPE 的非递减调整版本 Basel 资本计量

敞口演化

衍生品敞口的时间演化呈现特征性的"驼峰"形态：

敞口先随时间增长（因为更远期的市场波动累积），然后因剩余现金流减少而回落。这种"先升后降"的形态对 CVA 计算至关重要。


敞口模拟
蒙特卡洛模拟是计算敞口分布的标准方法：


import numpy as np
from scipy.stats import norm

def simulate_irs_exposure(notional, fixed_rate, tenor, n_paths=10000,
                         n_steps=40, r0=0.03, sigma_r=0.01, kappa=0.1, theta=0.03):
    dt = tenor / n_steps
    times = np.linspace(0, tenor, n_steps + 1)
    rates = np.zeros((n_paths, n_steps + 1))
    rates[:, 0] = r0

    for t in range(n_steps):
        dw = np.random.standard_normal(n_paths) * np.sqrt(dt)
        rates[:, t+1] = (rates[:, t]
                         + kappa * (theta - rates[:, t]) * dt
                         + sigma_r * dw)

    exposures = np.zeros((n_paths, n_steps + 1))
    for t in range(n_steps + 1):
        remaining_tenor = tenor - times[t]
        if remaining_tenor <= 0:
            continue
        n_remaining = max(1, int(remaining_tenor / dt))
        discount_factors = np.exp(-rates[:, t, np.newaxis]
                                   * np.arange(1, n_remaining + 1) * dt)
        fixed_leg = notional * fixed_rate * dt * np.sum(discount_factors, axis=1)
        float_leg = notional * (1 - discount_factors[:, -1])
        mtm = float_leg - fixed_leg
        exposures[:, t] = np.maximum(mtm, 0)

    ee = np.mean(exposures, axis=0)
    pfe_97_5 = np.percentile(exposures, 97.5, axis=0)

    return {
        'times': times,
        'ee': ee,
        'pfe': pfe_97_5,
        'epe': np.trapz(ee, times) / tenor
    }

result = simulate_irs_exposure(
    notional=100_000_000,
    fixed_rate=0.035,
    tenor=10,
    n_paths=10000
)

print(f"EPE: ${result['epe']:,.0f}")
print(f"峰值 EE: ${np.max(result['ee']):,.0f}")
print(f"峰值 PFE(97.5%): ${np.max(result['pfe']):,.0f}")
SA-CCR 标准法
SA-CCR（Standardised Approach for Counterparty Credit Risk）是 Basel III 下交对手信用风险敞口计算的标准方法，于 2014 年发布，替代旧的 CEM（Current Exposure Method）。

CVA（信用估值调整）
定义
CVA 是无风险衍生品价格与考虑交对手违约风险后的真实价格之差：


CVA=−∫0TLGD⋅EE(t)⋅dPD(t)\text{CVA} = -\int_0^T \text{LGD} \cdot EE(t) \cdot dPD(t)CVA=−∫0T​LGD⋅EE(t)⋅dPD(t)
离散化近似：


CVA≈LGD∑i=1nEE(ti)⋅[S(ti−1)−S(ti)]\text{CVA} \approx \text{LGD} \sum_{i=1}^{n} EE(t_i) \cdot [S(t_{i-1}) - S(t_i)]CVA≈LGDi=1∑n​EE(ti​)⋅[S(ti−1​)−S(ti​)]
其中 S(t)S(t)S(t) 为交对手的生存概率函数，EE(ti)EE(t_i)EE(ti​) 为 tit_iti​ 时刻的预期敞口。


错向风险
一般错向风险（General Wrong-Way Risk, GWWR）：交对手违约概率与敞口之间存在正相关——典型例子是主权 CDS：当主权信用恶化时，CDS 的敞口增加，而此时主权违约的概率也在上升。


特定错向风险（Specific Wrong-Way Risk, SWWR）：敞口与交对手之间存在直接法律或经济联系——例如持有某公司发行的看跌期权作为对冲，当该公司信用恶化时期权价值上升但交对手（该公司本身）更可能违约。

风险缓释机制
净额结算
ISDA 主协议下的净额结算权（Close-out Netting）允许在交对手违约时将所有衍生品合约进行净额计算：


Net Exposure=max⁡(∑iVi,0)≤∑imax⁡(Vi,0)\text{Net Exposure} = \max\left(\sum_{i} V_i, 0\right) \leq \sum_i \max(V_i, 0)Net Exposure=max(i∑​Vi​,0)≤i∑​max(Vi​,0)
净额结算可将敞口降低 50-80%。


担保品管理
信用支持附件（CSA）约定的变动保证金（Variation Margin）要求：


Margin Call=max⁡(Vnet−Threshold−MTA,0)\text{Margin Call} = \max(V_{net} - \text{Threshold} - \text{MTA}, 0)Margin Call=max(Vnet​−Threshold−MTA,0)
后危机时代的监管要求对大多数场外衍生品强制收取变动保证金和初始保证金（BCBS-IOSCO 框架）。

总结
交对手信用风险和 XVA 体系代表了后危机时代衍生品风险管理的核心演进。CVA 将信用风险纳入衍生品定价的全生命周期；FVA 和 KVA 反映了资金和资本的真实成本；SA-CCR 提供了标准化的敞口计量框架。对于量化从业者，XVA 计算涉及跨资产的蒙特卡洛模拟、敞口聚合、信用曲线校准和多维度风险管理——这是当前金融工程中技术密度最高的领域之一。随着 FRTB-CVA 框架的实施和初始保证金规则的全面推行，XVA 管理将继续是银行衍生品业务的核心竞争力。
