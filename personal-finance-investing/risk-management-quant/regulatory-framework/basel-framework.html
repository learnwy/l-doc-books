Basel III/IV 资本框架

概述

Basel 资本框架是全球银行业最重要的风险监管体系，由巴塞尔银行监管委员会（BCBS）制定。Basel III 于 2010 年金融危机后发布，Basel IV（BCBS 官方称"Basel III 最终化"）于 2017 年定稿并于 2023-2028 年分阶段实施。这一框架通过资本充足率要求、杠杆率限制和流动性标准三大支柱，确保银行体系的稳健运行。

对于量化金融从业者而言，理解 Basel 框架不仅是合规需要——资本计量方法直接决定了银行的业务经济性：高资本消耗的业务需要更高的风险调整收益才能创造价值。风险加权资产（RWA）的计算方法从标准法到内部模型法，构成了一个复杂的量化建模生态系统。

内部评级法（IRB）
IRB 法允许银行使用自有模型估计关键风险参数：


初级 IRB（F-IRB）：银行自行估计违约概率（PD），其他参数（LGD、EAD）由监管给定。


高级 IRB（A-IRB）：银行自行估计 PD、LGD、EAD 和 M（到期期限）。


资本要求公式（单因子 Vasicek 模型推导）：


K=LGD⋅[Φ(Φ−1(PD)+ρΦ−1(0.999)1−ρ)−PD]⋅1+(M−2.5)b1−1.5bK = LGD \cdot \left[\Phi\left(\frac{\Phi^{-1}(PD) + \sqrt{\rho}\Phi^{-1}(0.999)}{\sqrt{1-\rho}}\right) - PD\right] \cdot \frac{1 + (M-2.5)b}{1-1.5b}K=LGD⋅[Φ(1−ρ​Φ−1(PD)+ρ​Φ−1(0.999)​)−PD]⋅1−1.5b1+(M−2.5)b​
其中：


    

  • ρ\rhoρ 为资产相关系数（由 PD 决定）
    • 

  • b=[0.11852−0.05478ln⁡(PD)]2b = [0.11852 - 0.05478 \ln(PD)]^2b=[0.11852−0.05478ln(PD)]2 为到期调整因子

  • MMM 为有效到期期限

import numpy as np
from scipy.stats import norm

def irb_capital_requirement(pd, lgd, ead, maturity=2.5, exposure_type='corporate'):
    if exposure_type == 'corporate':
        rho = 0.12 * (1 - np.exp(-50 * pd)) / (1 - np.exp(-50))
        rho += 0.24 * (1 - (1 - np.exp(-50 * pd)) / (1 - np.exp(-50)))
    elif exposure_type == 'retail_mortgage':
        rho = 0.15
    elif exposure_type == 'retail_revolving':
        rho = 0.04
    else:
        rho = 0.03 * (1 - np.exp(-35 * pd)) / (1 - np.exp(-35))
        rho += 0.16 * (1 - (1 - np.exp(-35 * pd)) / (1 - np.exp(-35)))

    conditional_pd = norm.cdf(
        (norm.ppf(pd) + np.sqrt(rho) * norm.ppf(0.999)) / np.sqrt(1 - rho)
    )

    b = (0.11852 - 0.05478 * np.log(pd)) ** 2
    maturity_adj = (1 + (maturity - 2.5) * b) / (1 - 1.5 * b)

    k = lgd * (conditional_pd - pd) * maturity_adj
    rwa = k * 12.5 * ead

    return {
        'capital_requirement': k,
        'rwa': rwa,
        'asset_correlation': rho,
        'conditional_pd': conditional_pd,
        'maturity_adjustment': maturity_adj
    }

Basel IV 产出底线（Output Floor）
Basel IV 最重大的变革是引入了产出底线（output floor），限制内部模型法相对于标准法的资本节省：


RWAfinal=max⁡(RWAinternal,72.5%×RWAstandardised)\text{RWA}_{final} = \max\left(\text{RWA}_{internal}, 72.5\% \times \text{RWA}_{standardised}\right)RWAfinal​=max(RWAinternal​,72.5%×RWAstandardised​)
产出底线从 50%（2023 年）逐步过渡到 72.5%（2028 年），对依赖内部模型的大型银行影响深远。

杠杆率
杠杆率作为风险加权资本比率的非模型补充：


杠杆率=一级资本杠杆率敞口≥3%\text{杠杆率} = \frac{\text{一级资本}}{\text{杠杆率敞口}} \geq 3\%杠杆率=杠杆率敞口一级资本​≥3%
杠杆率敞口包括表内资产、衍生品敞口（SA-CCR 方法）、证券融资交易和表外项目。G-SIB 面临额外的杠杆率缓冲要求（其 G-SIB 缓冲的 50%）。

NSFR=可用稳定资金（ASF）所需稳定资金（RSF）≥100%\text{NSFR} = \frac{\text{可用稳定资金（ASF）}}{\text{所需稳定资金（RSF）}} \geq 100\%NSFR=所需稳定资金（RSF）可用稳定资金（ASF）​≥100%
NSFR 关注银行中长期（一年以上）的资产负债结构匹配，补充 LCR 的短期视角。


资本计量的量化挑战
PD 模型校准
PD 模型需要满足"穿越周期"（Through-the-Cycle, TTC）的要求，即反映长期平均违约率而非当前周期位置。这要求：


    

  1. 足够长的数据历史（至少一个完整经济周期）
    2. 

  2. 周期调整技术（如 Merton 模型框架下的长期均值映射）
    3. 

  3. 低违约组合（LDP）的特殊处理（缺少足够违约样本的投资级组合）
    4. 



LGD 模型
LGD 建模需要区分经济下行期的 LGD（downturn LGD），要求：


LGDdownturn≥LGDaverage\text{LGD}_{downturn} \geq \text{LGD}_{average}LGDdownturn​≥LGDaverage​
实践中通过混合模型处理 LGD 的双峰分布特征（高回收 vs 低回收集群）。


模型验证
监管要求对 IRB 模型进行严格的独立验证：


    

  • 区分度检验：ROC 曲线、AR/Gini 系数（最低 0.4-0.5）
    • 

  • 校准检验：Hosmer-Lemeshow 检验、二项式检验
    • 

  • 稳定性检验：PSI（群体稳定性指数）、CSI（特征稳定性指数）
    • 

  • 回测：实际违约率 vs 预测违约率的偏差分析
    • 



总结
Basel III/IV 资本框架构建了全球银行风险管理的底层约束。对于量化从业者，关键在于理解：资本计量方法（SA vs IRB）直接影响业务经济性；产出底线压缩了内部模型的资本优势；流动性要求改变了资产负债管理策略；资本缓冲体系引入了宏观审慎维度。随着 Basel IV 的全面实施，银行业正经历资本效率的深度再优化，这将重塑交易策略、产品设计和客户定价。
