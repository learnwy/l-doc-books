市场风险监管与 FRTB

概述

FRTB（Fundamental Review of the Trading Book）是 Basel 委员会对交易账簿市场风险资本框架的根本性改革，于 2016 年首次发布、2019 年修订定稿，目标实施日期为 2025-2028 年。FRTB 从多个维度重构了市场风险资本计量体系：从 VaR 转向 Expected Shortfall（ES）、引入流动性期限层级、重新定义交易账簿与银行账簿的边界、对内部模型法（IMA）施加更严格的资质要求。

FRTB 的推出源于 2008 年金融危机的深刻教训：Basel II.5 的增量风险资本要求（IRC）和综合风险度量（CRM）虽然弥补了部分缺陷，但框架性问题依然存在——VaR 对尾部风险的低估、10 天流动性假设的不切实际、交易账簿与银行账簿之间的监管套利。FRTB 试图从根本上解决这些问题。

FRTB 核心变革

从 VaR 到 Expected Shortfall
理论动机
VaR 的两大缺陷驱动了向 ES 的转变：


    

  1. 次可加性违反：VaR 不满足一致性风险度量要求

  2. 尾部盲区：两个 VaR 相同的组合可能有截然不同的尾部风险

import numpy as np

def frtb_sa_delta_capital(sensitivities, risk_weights, intra_bucket_corr, inter_bucket_corr):
    n_buckets = len(sensitivities)
    weighted_sens = {}
    bucket_capital = {}

    for bucket, sens_list in sensitivities.items():
        rw_list = risk_weights[bucket]
        ws = np.array([s * rw for s, rw in zip(sens_list, rw_list)])
        weighted_sens[bucket] = ws

        n = len(ws)
        rho = intra_bucket_corr[bucket]
        kb_sq = np.sum(ws**2)
        for i in range(n):
            for j in range(i+1, n):
                kb_sq += 2 * rho * ws[i] * ws[j]
        bucket_capital[bucket] = np.sqrt(max(kb_sq, 0))

    buckets = list(bucket_capital.keys())
    n_b = len(buckets)
    total_sq = sum(bc**2 for bc in bucket_capital.values())

    for i in range(n_b):
        for j in range(i+1, n_b):
            bi, bj = buckets[i], buckets[j]
            sb_i = max(min(sum(weighted_sens[bi]), bucket_capital[bi]), -bucket_capital[bi])
            sb_j = max(min(sum(weighted_sens[bj]), bucket_capital[bj]), -bucket_capital[bj])
            gamma = inter_bucket_corr.get((bi, bj), inter_bucket_corr.get((bj, bi), 0))
            total_sq += 2 * gamma * sb_i * sb_j

    return np.sqrt(max(total_sq, 0)), bucket_capital

sensitivities = {
    'bucket_1': [100_000, -50_000, 30_000],
    'bucket_2': [-80_000, 60_000],
}
risk_weights = {
    'bucket_1': [0.017, 0.016, 0.013],
    'bucket_2': [0.011, 0.011],
}
intra_corr = {'bucket_1': 0.95, 'bucket_2': 0.90}
inter_corr = {('bucket_1', 'bucket_2'): 0.5}

total, by_bucket = frtb_sa_delta_capital(sensitivities, risk_weights, intra_corr, inter_corr)
print(f"Delta 资本要求: ${total:,.0f}")
for b, k in by_bucket.items():
    print(f"  {b}: ${k:,.0f}")

内部模型法（IMA）
逐交易台审批
FRTB 最深刻的改变之一是将 IMA 审批从全行级别下沉到交易台级别。每个交易台必须独立通过：


    

  1. 回测检验（Backtesting）：过去 250 天的 VaR 突破次数
    2. 

  2. 损益归因检验（P&L Attribution Test, PLAT）：风险理论 P&L 与实际 P&L 的一致性
    3. 



损益归因检验

总结
FRTB 从根本上重塑了交易账簿市场风险的资本计量体系。ES 替代 VaR 改善了尾部风险敏感性；差异化流动性期限更真实地反映了市场流动性；逐交易台审批机制提高了模型治理标准；灵敏度方法重设计的标准法为中小银行提供了更风险敏感的选择。对于量化从业者，FRTB 创造了大量的建模需求——从 ES 计算引擎、PLAT 框架到 NMRF 识别系统——这些都是风险技术领域的核心挑战。
