存量-流量图

核心概念

存量-流量图（Stock and Flow Diagram, SFD）是系统动力学中用于精确建模系统结构和行为的核心工具。与因果环路图（CLD）侧重于定性地描述反馈结构不同，SFD 是定量建模的基础——它明确标注了哪些变量是存量、哪些是流量、哪些是辅助变量，以及它们之间的数学关系。掌握 SFD 的绘制方法，是从系统思维的"定性分析"进阶到"定量模拟"的关键一步。

SFD 使用一套标准化的图形符号，这套符号由杰伊·福雷斯特在创立系统动力学时确定，至今仍是该领域的标准语言。

从 CLD 到 SFD 的转换
因果环路图（CLD）和存量-流量图（SFD）是互补的工具。CLD 适合快速探索系统结构、识别反馈环路；SFD 适合精确建模、进行定量模拟。在实践中，通常先画 CLD 理清系统结构，然后将 CLD 转换为 SFD 进行深入分析。


转换步骤：


    

  1. 识别存量：在 CLD 的变量中找出哪些是累积量（可以在某一时刻测量）。经验法则：如果你能说"现在有 X 个/行/元"，它就是存量。
    

    2. 

  2. 识别流量：找出直接改变存量的变量。流量总是以速率形式存在——"每天/周/月的变化量"。
    

    3. 

  3. 识别辅助变量：CLD 中剩余的变量大多是辅助变量——它们影响流量，但本身不直接累积。
    

    4. 

  4. 画出物质流：用实线箭头连接存量和流量。物质流必须守恒——一个流量的流出等于另一个流量的流入。
    

    5. 

  5. 画出信息流：用虚线箭头表示信息如何从存量或辅助变量流向流量（影响流量的速率）。
    

    6.

SFD 绘制的关键规则
绘制 SFD 时需要遵循几条严格的规则，这些规则确保模型的物理合理性：


规则一：存量只能通过流量改变。不能画一条箭头直接从辅助变量指向存量——信息不能直接改变存量，只有物质流（流量）才能。这条规则反映了物理世界的守恒定律。


规则二：信息可以瞬时传递，物质不能。虚线（信息流）可以"跨越"系统结构，但实线（物质流/流量）必须遵循存量-流量的链式连接。


规则三：每个流量至少有一端连接存量。流量不能凭空产生或消失——它要么从一个存量流出，要么流入一个存量（或者两者都有）。当流量的来源在系统边界之外时，用"云形"符号表示无限源或汇。


规则四：避免"无物质流的信息回路"。所有反馈回路中至少应该包含一个存量。没有存量的反馈回路意味着信号以无限速度传播，在真实系统中不存在。

SFD 在容量规划中的应用
SFD 的一个高价值应用场景是容量规划——通过建模系统的存量-流量结构，预测未来的资源需求。


数据库容量规划：数据量是存量，数据写入速率是流入量，数据清理/归档速率是流出量。通过 SFD 建模，可以根据业务增长预测（流入量变化趋势）和清理策略（流出量），计算存量在未来 6/12/24 个月的变化，从而确定扩容时间点。


团队产能规划同样适合 SFD 建模。团队有效产能是存量（总人力减去非生产性消耗后的有效产出能力），招聘是流入量，离职是流出量，培训和团队建设影响流入效率。通过 SFD 模型可以回答："如果每月离职率从 3% 上升到 5%，且招聘周期从 2 个月延长到 4 个月，团队产能会在几个月后降至危险水平？"

SFD 工具与建模实践
在实际工作中，SFD 的绘制和模拟可以使用专业工具或通用工具：


专业系统动力学工具：


    

  • Vensim：最经典的系统动力学建模工具，学术界广泛使用
    • 

  • Stella Architect：isee systems 出品，界面友好，适合教学
    • 

  • AnyLogic：支持系统动力学、离散事件和 Agent-Based 三种建模范式
    • 



轻量级替代：


    

  • 电子表格：用 Excel/Google Sheets 实现简单的存量-流量模拟。每行代表一个时间步长，存量列的公式是"上一行存量 + 流入 - 流出"
    • 

  • 代码模拟：用 TypeScript/Python 编写简单的模拟循环，更灵活且可集成到自动化流程中
    • 



建模实践建议：


    

  1. 从最简模型开始：先建立只包含 1-2 个存量的最简模型，验证其行为是否合理
    2. 

  2. 逐步增加复杂度：确认简单模型正确后，再添加反馈回路和辅助变量
    3. 

  3. 对参数做敏感性分析：改变关键参数的值，观察系统行为是否会发生质变
    4. 

  4. 用真实数据校准：用历史数据验证模型的输出是否与真实观察一致
    5. 



小结
    

  • 存量-流量图（SFD）是系统动力学的定量建模基础，使用标准化的符号系统
    • 

  • 从 CLD 到 SFD 的转换需要明确区分存量、流量和辅助变量
    • 

  • SFD 的四条核心规则确保模型的物理合理性：存量只能通过流量改变、物质流守恒、信息可瞬时传递、反馈回路必含存量
    • 

  • 容量规划是 SFD 在软件工程中的高价值应用——通过建模预测资源需求和扩容时间
    • 

  • 建模应从最简模型开始，逐步增加复杂度，并用真实数据校准
    • 

  • SFD 的价值不在于精确预测未来，而在于帮助理解系统结构如何驱动行为模式
    •
