语素类型与词的构成

核心概念

语素（morpheme）是语言中最小的音义结合体——即最小的携带意义或语法功能的语言单位。一个词可以由一个或多个语素构成。形态学（Morphology）的核心任务就是分析词的内部结构，揭示语素如何组合形成复杂的词汇。理解语素类型及其组合规则是深入学习句法学、历史语言学和计算语言学的重要基础。

自由语素与粘着语素
自由语素（free morpheme）可以独立作为一个词存在。"book""happy""run"都是自由语素——它们本身就是完整的词。自由语素进一步分为词汇语素（lexical morpheme，承载实在意义，如名词、动词、形容词）和功能语素（functional morpheme，主要承载语法功能，如冠词"the"、连词"and"、介词"to"）。


词汇语素构成一个开放类（open class）——新的词汇语素可以随时被创造（如"google""emoji""selfie"）。功能语素构成一个封闭类（closed class）——极少有新的功能词被创造出来，它们的数量在任何语言中都是有限的。这一开放/封闭的区分对句法学、语言习得和失语症研究都具有重要意义：布洛卡失语症患者典型地丧失了功能词的使用能力，但保留了大部分词汇词。


粘着语素（bound morpheme）不能独立成词，必须附着于其他语素。英语的"-s"（复数）、"-ed"（过去时）、"un-"（否定）、"-ness"（名词化）都是粘着语素。粘着语素中还有一个特殊类别——粘着词根（bound root）：它承载核心词义但不能独立成词。英语的"-ceive"出现在receive、perceive、conceive、deceive中，"-mit"出现在submit、permit、commit、transmit中——它们不能单独使用，但在一系列相关词中反复出现，承载着可辨识的核心意义。


独特语素（cranberry morpheme/unique morpheme）是一种特殊的粘着语素——它仅出现在一个词中，如"cranberry"中的"cran-"。虽然说话者能感知到"cranberry"与"strawberry""blueberry"具有相似的构造，但"cran-"本身没有独立的意义，也不出现在其他词中。


词缀类型与位置
词缀（affix）按照其相对于词根的位置分为多种类型。


前缀（prefix）出现在词根之前：un-happy, re-write, pre-view, dis-agree。英语的前缀以派生型为主（改变词义），几乎没有屈折型前缀。但许多其他语言大量使用屈折型前缀——斯瓦希里语动词的时态、主语一致性和宾语一致性都通过前缀标记。


后缀（suffix）出现在词根之后：happi-ness, teach-er, walk-ed, kind-ly。英语的后缀既有派生型（-ness, -er, -able, -ment）也有屈折型（-s, -ed, -ing, -est）。后缀是跨语言最常见的词缀类型——几乎所有使用词缀的语言都有后缀，但不一定有前缀。


中缀（infix）插入词根内部。英语中没有生产性的中缀（不过非正式表达如"abso-freakin-lutely"展示了类中缀行为）。他加禄语（Tagalog）有系统性的中缀：sulat"写"→ sumulat"在写"，其中-um-插入在第一个辅音之后。


环缀（circumfix）同时出现在词根的两端。德语的过去分词ge-...-t就是环缀：machen"做"→ ge-mach-t"做了"。这不能简单地分析为一个前缀加一个后缀，因为ge-和-t在功能上不可分割——它们共同标记过去分词。

词的分析方法
形态学分析的目标是将复杂词分解为其组成语素，并揭示它们的组合结构。


即时成分分析（Immediate Constituent Analysis, IC分析）将词逐层分解为两个直接成分，揭示词的层级结构。以"unhappiness"为例：第一层切分为[un-[happi-ness]]而非[[un-happi]-ness]——因为"unhappiness"是"happiness的否定"（un-happiness）而非"unhappy的名词化"（虽然表面上两种分析都能得到相同的表层形式）。判断正确切分的证据是：un-可以附加在名词上（如un-happiness），也可以附加在形容词上（如un-happy），但-ness只能附加在形容词上（happy → happiness），不能附加在其他名词上。


语素识别测试包括：替换测试（如果一个片段可以在相同位置被其他片段替换且结果仍有意义，则该片段可能是一个语素：un-happy, un-kind, un-fair → un-是语素）；反复出现测试（一个片段在不同词中反复出现且携带一致的意义：teacher, singer, writer → -er是语素）；最小对测试（两个词仅在一个语素上不同：kind/un-kind, happy/un-happy）。


零语素（zero morpheme）是形态学中一个重要的抽象概念。英语名词复数由-s标记（dog → dog-s），但"sheep"的复数形式与单数相同——这可以分析为sheep + ∅（零复数语素）。这种分析的合理性在于维护了"复数=词根+复数标记"的统一规则。


复合词与其他构词法
复合（compounding）是将两个或多个自由语素（通常是词根）组合成新词的过程。英语的复合词极为丰富：blackbird（黑鸟→乌鸫）、fire-engine（消防车）、greenhouse（温室）、output（输出）。


复合词的中心语（head）决定了整个复合词的词类和核心语义。英语的复合词通常是右中心的（right-headed）：[black][bird]中"bird"是中心语——blackbird是一种鸟，不是一种黑色。但也存在外心复合（exocentric compound/bahuvrihi）：deadbeat不是一种beat，pickpocket不是一种pocket——这类复合词的意义不由任何一个成分的意义来预测。


其他重要的构词法包括：混成（blending: breakfast + lunch → brunch, smoke + fog → smog）、截短（clipping: advertisement → ad, laboratory → lab）、首字母缩略（acronym: NASA, AIDS, laser）、逆构词（back-formation: editor → edit, babysitter → babysit）、词类转换（conversion/zero derivation: 动词google来自名词Google，动词text来自名词text）。


小结
    

  • 语素是语言中最小的音义结合体，分为自由语素和粘着语素两大类
    • 

  • 粘着语素包括派生词缀（改变词义/词类）和屈折词缀（添加语法信息）
    • 

  • 词缀按位置分为前缀、后缀、中缀和环缀，后缀是跨语言最普遍的类型
    • 

  • 即时成分分析揭示词的层级结构，替换测试和反复出现测试帮助识别语素边界
    • 

  • 复合词的中心语决定整个词的词类和语义，英语复合通常是右中心的
    • 

  • 构词法包括词缀法、复合、混成、截短、首字母缩略、逆构词和词类转换
    • 

  • 形态分析是理解语言词汇系统和语法结构的基础
    •
