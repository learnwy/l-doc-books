派生与屈折

核心概念

派生（derivation）和屈折（inflection）是形态学中两种最基本的词缀化过程，它们在功能、行为和理论地位上存在系统性的差异。派生创造新的词项（新词汇），改变词根的意义或词类；屈折则为已有的词项添加语法信息（如时态、数、格），不改变其核心意义或词类。这一区分看似简单，实际上涉及形态学最深层的理论问题之一。

派生形态学
派生（derivation）通过添加词缀来创造新的词项。派生词缀可以是改变词类的（class-changing）或不改变词类的（class-maintaining）。


改变词类的派生是最典型的类型：名词→形容词（danger → danger-ous）、动词→名词（arrive → arriv-al）、形容词→名词（happy → happi-ness）、形容词→动词（simple → simpl-ify）、名词→动词（hospital → hospital-ize）、动词→形容词（accept → accept-able）。这些词类变化对句法有直接的影响——派生产出的新词可以出现在原词不能出现的句法位置上。


不改变词类的派生改变词义但保持词类：happy → un-happy（形容词→形容词，添加否定义）、write → re-write（动词→动词，添加重复义）、king → king-dom（名词→名词，但语义域不同）。


派生的生产性（productivity）是一个连续的梯度而非二元的有/无。英语的-ness（形容词→名词）和-able（动词→形容词）是高度生产的——几乎可以附加到任何合适词类的新词上。-ment（动词→名词）的生产性中等——有些新词可以用（如"deployment"），但不是所有动词都能加-ment。-th（形容词→名词，如warm→warmth）几乎完全不生产——不能说*"coolth"或*"tallth"。


词汇化（lexicalization）发生在派生词的意义不再可以从其组成部分透明地组合推导时。"understand"（理解）的意义不能从"under"+"stand"组合得到。"breakfast"（早餐）的意义虽然历史上来自"break"+"fast"（打破禁食），但现代说话者不再感知这种语素分析。


屈折形态学
屈折（inflection）为词添加句法所要求的语法信息，而不创造新词。英语动词的屈折范式包括：walk、walks、walking、walked——这四个形式不是四个不同的词，而是同一个词"walk"的四个屈折变体（inflectional forms）。


主要的屈折范畴包括：数（number: 单数/复数/双数）、格（case: 主格/宾格/属格/与格...）、性（gender: 阳性/阴性/中性）、时（tense: 过去/现在/将来）、体（aspect: 完成/进行/习惯）、语气（mood: 陈述/虚拟/命令）、人称（person: 第一/第二/第三）、语态（voice: 主动/被动）。


英语的屈折系统极其贫乏——整个语言只有约8个屈折后缀：名词复数-s、名词所有格-'s、动词第三人称单数-s、过去时-ed、过去分词-ed/-en、现在分词-ing、比较级-er、最高级-est。相比之下，拉丁语动词有超过120个屈折形式（6个人称-数组合×6个时态×3个语气×2个语态），土耳其语动词通过黏着后缀可以产出数百个形式。


屈折范式（paradigm）是一个词项的全部屈折形式的系统性排列。拉丁语名词"rosa"（玫瑰）的屈折范式：

派生-屈折的界面问题
派生与屈折的区分在原型情况下是清晰的，但存在一些挑战性的边界案例。


比较级和最高级：英语的-er（taller）和-est（tallest）通常被分析为屈折——它们不改变词类（仍然是形容词），且是高度规则的。但它们也创造了语义上可以被视为新词项的形式，且并非所有形容词都可以加-er/-est（*beautifuller）——这是典型的派生特征。


分词：英语的现在分词-ing和过去分词-ed/-en既有屈折用法（"She is walking"中的walking是动词的屈折形式）也有派生用法（"the walking dead"中的walking是形容词）。这种双重身份使得分词成为派生-屈折区分中最棘手的案例之一。


"分裂形态学假说"（Split Morphology Hypothesis, Anderson 1982）主张派生和屈折是两个根本不同的系统：派生在词库（lexicon）中完成，屈折在句法中完成。这一假说的极端版本认为屈折根本不是"形态学"——它是句法的词内反映。

小结
    

  • 派生创造新词项（改变词义或词类），屈折为现有词添加语法信息（不改变核心意义）
    • 

  • 派生词缀的生产性从极高（-ness）到完全死亡（-ric）形成一个连续梯度
    • 

  • 屈折范畴包括数、格、性、时、体、语气、人称和语态等
    • 

  • 英语的屈折系统极其贫乏（约8个后缀），而拉丁语、土耳其语等有极其丰富的屈折
    • 

  • 派生通常比屈折更靠近词根——"un-happi-ness"中派生在内，屈折在外
    • 

  • 比较级、分词等边界案例挑战了派生-屈折的简单二分
    • 

  • 分裂形态学假说主张派生在词库中完成而屈折在句法中完成
    •
