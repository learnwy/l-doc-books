剧本格式与规范 Script Formatting Standards

编剧行业有一句流传甚广的忠告：如果你的剧本格式不对，它连被翻开第二页的机会都不会有。这并非夸张——好莱坞的读稿人（Script Reader）每天面对数十份剧本，格式不规范是最快的淘汰信号。格式不仅是礼仪，更是一种功能性工具：标准化的排版确保「一页约等于一分钟银幕时间」的换算成立，让制片人从页数即可估算时长、预算和拍摄日程。

本文系统梳理好莱坞工业标准的剧本格式体系，从页面设置到每个剧本元素的具体排版规则，帮助自学者建立扎实的格式基础。

页面基础设置

好莱坞剧本的页面设置有着非常具体的行业标准，这套标准从打字机时代沿用至今，核心目的是保证一页剧本对应约一分钟的银幕时间。

字体与字号：Courier 或 Courier New，12号字。这是最不可动摇的规则之一。Courier 是等宽字体（Monospaced Font），每个字符占据相同的水平空间，这使得页面上的文字量保持稳定，从而支撑「一页一分钟」的时间换算。任何非 Courier 字体的剧本都会被视为业余标志。部分编剧软件使用 Courier Prime——这是一种专为剧本设计的 Courier 变体，保持等宽特性的同时提升了屏幕可读性。

页面边距：左边距 1.5 英寸（约 3.81 厘米），右边距 1 英寸（约 2.54 厘米），上下边距各 1 英寸。左边距偏宽是为了给装订留出空间——好莱坞剧本的标准装订方式是使用两枚铜钉（Brads）固定在左侧。右边距相对宽松，对白如果略微超出不算违规，但动作描写应当严格控制在边距内。

页码：从第二页开始，在页面右上角标注，后跟一个句点（如 2.）。封面页和第一页不标注页码。页码使用与正文相同的 Courier 12 号字体。

行距：正文使用单倍行距。不同元素之间的空行有明确规定——场景标题前空两行，动作描写段落之间空一行，角色名与对白之间不空行。这些间距规则是「一页一分钟」换算的重要组成部分。

纸张：美国标准 Letter 尺寸（8.5 × 11 英寸）。即使在数字化时代，剧本的排版仍以这个纸张尺寸为基准进行设计。

剧本核心元素

一个标准的好莱坞剧本由以下核心元素组成，每个元素都有严格的格式规则。理解这些元素是编剧的必修课。

场景标题（Slugline / Scene Heading）：每个新场景的起始标记，全部大写。格式为：内/外景 — 地点 — 时间。英文标准写法：INT. COFFEE SHOP - DAY 或 EXT. ROOFTOP - NIGHT。场景标题告诉拍摄团队三个关键信息：这场戏在室内还是室外（决定灯光方案）、具体地点（决定场景搭建或选景）、时间段（决定拍摄计划）。INT. 代表内景（Interior），EXT. 代表外景（Exterior），INT./EXT. 用于跨越室内外的场景（如车内戏）。

动作描写（Action / Scene Description）：描述场景中发生的视觉事件。顶格书写，使用现在时态（Present Tense）。动作描写是编剧最直接的叙事工具——它不是小说式的环境描写，而是摄影机「看到」的内容。好的动作描写简洁、具体、有画面感。每个段落控制在三到四行以内；超过四行的长段落会在视觉上显得沉重，容易让读者失去节奏感。角色首次出场时，名字全部大写（如 SARAH, 35, 穿着不合身的西装，目光锐利），之后正常书写即可。

角色名（Character Name）：出现在对白上方，大写，居中偏左（距左边距约 3.7 英寸）。如果角色在画外说话，名字后加 (V.O.)（Voice Over，画外音）或 (O.S.)（Off Screen，画面外但在场景中）。如果对白需要延续到下一页，在断点处标注 (MORE)，在下一页的角色名后加 (CONT'D)。

对白（Dialogue）：角色名下方，居中偏左，宽度约 3.5 英寸（比动作描写窄得多）。对白的窄幅排版是一个巧妙的设计——它使得对白在页面上形成一个视觉上的「窄柱」，让读者能够快速区分叙事文字（宽幅的动作描写）和角色语言（窄幅的对白），从而加快阅读节奏。

括号说明（Parenthetical）：对白中的表演指示，放在角色名和对白之间或对白中间，用括号包裹，如 (低声) 或 (转向窗户)。括号说明应当极度节制——它是编剧「建议」演员如何表演，而非「指挥」。过多的括号说明会被导演和演员视为越权。Robert McKee 在《故事》中的建议是：如果对白本身写得足够好，括号说明根本不需要。

过渡标记（Transition）：标记场景之间的切换方式，右对齐，大写。常见的包括 CUT TO:、DISSOLVE TO:、SMASH CUT TO:。在当代剧本写作中，过渡标记的使用已经大幅减少——默认每个场景之间就是直切（Cut），只有当过渡方式本身具有叙事意义时才需要标注。例如，SMASH CUT TO: 暗示一个突然的、有冲击力的场景切换。

封面页与标题页

剧本的封面页（Title Page）是读者看到的第一个页面，它的格式同样有严格的行业标准。

标题居中，使用大写或首字母大写，位于页面上半部分。标题下方空一行写 Written by（或 Screenplay by），再下一行写编剧姓名。如果是改编剧本，标题下方写 Screenplay by [编剧名]，再下一行写 Based on [原作名] by [原作者名]。

页面右下角写联系方式——经纪人或经理人的联系信息，或者独立编剧的个人联系方式。左下角可选择性地写日期和草稿编号（如 Third Draft - March 2025）。

一个常见的业余错误是在封面页上添加过多的装饰——版权声明（©）、WGA 注册编号、引用名言、装饰图案等。专业的封面页应当极度简洁：标题、作者、联系方式，仅此而已。Syd Field 在《电影剧本写作基础》中特别强调：封面页的简洁程度本身就是专业性的信号。

编剧软件工具

现代编剧几乎不需要手动处理格式问题——专业的编剧软件会自动应用正确的格式。以下是行业中最常用的几类工具。

Final Draft：好莱坞的行业标准软件，几乎所有制片公司和经纪公司都接受 .fdx 格式。Final Draft 内置了完整的格式模板，支持实时协作、修改追踪和标准化的排版输出。它的定价较高（约 250 美元），但对于认真从事编剧的人来说是值得的投资。其「Beat Board」功能允许编剧在写剧本之前先进行结构性的卡片规划。

WriterSolo / WriterDuet：基于云端的编剧工具，WriterDuet 以实时协作功能著称。免费版本已经包含完整的格式功能，付费版增加了离线编辑、修改追踪等高级功能。对于预算有限的学习者来说，这是一个优秀的入门选择。

Highland：由编剧 John August（《大鱼》《查理和巧克力工厂》的编剧）开发，采用「Fountain 语法」——一种纯文本的剧本标记语言。Highland 的理念是让编剧专注于写作本身而非格式操作：你只需在纯文本中用简单的标记（如行首全大写自动识别为场景标题），软件就会在预览和输出时自动应用正确的格式。

Fountain 语法：严格来说 Fountain 不是软件而是一种开放标准。它定义了一套纯文本标记规则，任何支持 Fountain 的编辑器（Highland、VS Code 插件、甚至普通文本编辑器）都能将其渲染为标准剧本格式。Fountain 的优势在于文件的可移植性和版本控制友好性——剧本文件本质上就是纯文本，可以用 Git 进行版本管理。

Scrivener：更偏向「写作工坊」的工具，适合需要大量前期研究和资料整理的编剧。Scrivener 内置了剧本格式模板，但它的核心优势在于组织能力——角色卡片、场景备注、研究资料都可以在同一个项目中管理。不过，Scrivener 的剧本格式支持不如 Final Draft 或 WriterDuet 专业。

中文剧本的格式差异

中国影视行业的剧本格式与好莱坞有显著差异。中文剧本通常没有好莱坞那样严格的「一页一分钟」换算标准，格式也没有达到高度统一的程度。

中文剧本的常见格式特点包括：场景标题使用「第 X 场」编号方式；对白前写角色名后加冒号而非美式的居中格式；动作描写通常使用宋体而非等宽字体；对白通常不像美式剧本那样缩窄排列，而是与正文等宽。部分中国编剧（特别是有国际合作经验的）会同时准备两种格式的剧本——中式格式用于国内沟通，美式格式用于国际合拍项目。

随着中国影视工业化程度的提升和国际合作的增多，越来越多的中国编剧开始学习和采用好莱坞格式，或至少在关键元素（如场景标题的信息完整性、动作描写的视觉化）上向好莱坞标准靠拢。学习好莱坞格式的意义不仅在于参与国际项目，更在于理解这套格式背后的工业逻辑——每一条规则都对应着拍摄流程中的实际需求。

关键要点

  • Courier 12pt + 标准边距是不可动摇的基础规则，支撑「一页一分钟」的核心换算
  • 剧本的六大核心元素各有严格的位置和格式规则，掌握它们是编剧入门的第一步
  • 封面页越简洁越专业——标题、作者、联系方式即可
  • 使用专业编剧软件可以解放格式负担，让编剧专注于内容创作
  • 了解中文剧本与好莱坞格式的差异，有助于在不同制作体系中灵活切换
