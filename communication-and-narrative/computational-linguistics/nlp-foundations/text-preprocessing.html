文本预处理

核心概念

文本预处理（text preprocessing）是自然语言处理（NLP）流水线中的第一个关键阶段，负责将原始文本转换为计算机可处理的结构化表示。原始文本——无论来自网页、社交媒体、学术论文还是对话记录——充满了噪声、不一致性和歧义，直接输入到下游模型中会严重影响性能。预处理的目标是在保留语言学信息的前提下，消除噪声、规范化表示、降低数据稀疏性。从传统 NLP 的规则管线到深度学习时代的端到端模型，预处理的策略和重要性经历了深刻变化，但理解其核心原理对于设计高效的语言处理系统仍然至关重要。

分词与子词切分
分词（tokenization）是将连续文本切分为离散单元（token）的过程，是几乎所有 NLP 系统的入口点。不同语言的分词面临截然不同的挑战。


空格分隔语言（如英语）的分词看似简单——按空格切分即可——但实际复杂性远超预期。缩略词（"don't" → "do" + "n't" 还是 "don" + "'t"？）、连字符复合词（"well-known"）、多词表达（"New York"）、URL、电子邮件地址和 emoji 序列都需要特殊处理。Penn Treebank 分词标准将 "don't" 切分为 "do" + "n't"，"cannot" 切分为 "can" + "not"，但不同的分词标准之间存在显著差异。

中文分词方法经历了从词典匹配（最大匹配法 FMM/BMM）→ 统计模型（HMM、CRF）→ 神经网络（BiLSTM-CRF）→ 预训练模型（BERT 序列标注）的演进。当代最优系统在 CTB 和 PKU 语料上的 F1 超过 98%，但跨领域和新词识别仍有挑战。


子词切分（subword tokenization）在深度学习时代成为主流方案，根本性地改变了分词的范式。其核心动机是解决开放词汇问题（open vocabulary problem）——传统词级分词面临的 OOV（out-of-vocabulary）问题。

BPE 的训练过程：初始化词表为所有单字符；统计相邻字符对的频率；合并最频繁的字符对为新 token；重复直到达到目标词表大小。例如，从语料 ["low", "lower", "newest", "widest"] 出发，BPE 可能依次合并 "e"+"s"→"es"、"es"+"t"→"est"、"l"+"o"→"lo"、"lo"+"w"→"low"，使 "lowest" 被切分为 "low"+"est"。


规范化与词形还原
文本规范化（normalization）将文本中的变体统一为标准形式，降低数据稀疏性。


Unicode 规范化是最基础的步骤。同一个字符可能有多种 Unicode 编码方式：é 可以是单一码点 U+00E9（预组合形式，NFC），也可以是 e + ´（分解形式，NFD）。NFC 规范化将分解形式统一为预组合形式，NFKC 进一步将兼容等价字符统一（如将全角字母 "Ａ" 转为半角 "A"）。


大小写折叠（case folding）将所有字母统一为小写。这在信息检索中几乎是标准操作，但在命名实体识别等任务中可能损失信息（"Apple"（公司）vs. "apple"（水果））。Truecasing 技术在保留大小写信息的有用性和降低稀疏性之间寻求平衡。

Porter Stemmer（1980）是最经典的英语词干提取器，使用约 60 条规则分五步去除后缀（如 -ATION → -ATE → 词干）。Snowball 框架将 Porter 的方法扩展到 20+ 语言。WordNet Lemmatizer 和 spaCy 的词形还原器则依赖词法词典和上下文 POS 标签，输出总是真实的词典形式。


句子分割与文档结构
句子分割（sentence segmentation / sentence boundary detection, SBD）将文本切分为句子单元。看似简单的任务实则充满歧义——句号 "." 在英语中既是句末标记，也出现在缩写词（"Dr."、"U.S.A."）、小数（"3.14"）、URL（"example.com"）和省略号（"..."）中。


规则基础的方法使用缩写词词典和正则表达式处理常见模式，如 Punkt 分句器（NLTK 内置）结合缩写词自动发现和搭配统计来判定句号功能。统计方法和神经网络方法将 SBD 建模为序列标注任务——为每个标点（或每个字符位置）分配"句界"或"非句界"标签。

多语言 SBD 面临额外挑战。中文使用"。"作为句号但也使用"！""？""……"；日文混合使用"。"和"."；泰文几乎不使用句号。社交媒体文本中标点的省略和非标准使用进一步增加了难度。


文档结构解析是更高层次的预处理，涉及识别标题、段落、列表、表格等结构元素。PDF 和图像文档需要 OCR（光学字符识别）+ 版面分析（layout analysis）。HTML 文档需要去标签、提取正文（如 Readability 算法）、处理样板文本（导航栏、广告）。


预处理在深度学习时代的演变
深度学习——特别是预训练语言模型——深刻改变了预处理的角色和策略。


端到端学习将部分预处理步骤内化到模型中。BERT 使用 WordPiece 子词切分，直接在原始文本上操作，无需词干提取或词形还原。GPT 系列使用 BPE，将分词和特征提取合为一步。但这并不意味着预处理变得不重要——分词器的选择和配置直接影响模型性能，且数据清洗和规范化仍需在分词前完成。

数据质量在大模型时代变得更加关键。训练数据中的噪声会被模型放大：拼写错误导致稀有 token 的不合理权重，编码错误（如 Latin-1 被误当 UTF-8 解码）产生乱码 token，HTML 残留标签干扰语义理解。C4（Colossal Clean Crawled Corpus）和 The Pile 等大规模语料的构建都投入了大量工程资源在清洗和过滤上——包括语言识别、重复文档去除（MinHash）、有毒内容过滤和质量评分。


多语言预处理面临独特挑战。SentencePiece 的语言无关性使其成为多语言模型的首选分词器——它直接在 Unicode 码点序列上训练，不假设空格是词边界。但词表分配不均（高资源语言占据更多子词）和脚本差异（拉丁、汉字、阿拉伯文、天城文等）仍需通过均衡采样和脚本感知策略来应对。


小结
    

  • 文本预处理将原始文本转换为结构化表示，包含清洗、分句、分词、规范化、词形还原等步骤
    • 

  • 子词切分（BPE、WordPiece、Unigram）取代传统词级分词，解决开放词汇和 OOV 问题
    • 

  • 中文分词面临组合歧义、交叉歧义和未登录词挑战，从词典匹配演进到预训练模型
    • 

  • 规范化（Unicode、大小写、词形还原）降低数据稀疏性，但深度学习时代部分步骤被模型内化
    • 

  • 句子分割在标点歧义和多语言场景中仍需专门处理
    • 

  • 大模型时代预处理的重心转向数据质量控制和分词器设计，端到端学习隐式替代了部分传统步骤
