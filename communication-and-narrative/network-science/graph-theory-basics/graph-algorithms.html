图算法

核心概念

图算法是处理和分析图结构数据的计算方法。从最基本的遍历（BFS/DFS）到复杂的网络流和子图匹配，图算法构成了一个层级分明的工具箱。选择正确的算法取决于问题的性质、图的规模和性能要求。

BFS 与 DFS
广度优先搜索（BFS）和深度优先搜索（DFS）是所有图算法的基础。BFS 从起点开始，按层次逐步扩展到更远的顶点，适合找最短路径和层级结构。DFS 沿一条路径尽可能深入，适合检测环、拓扑排序和路径枚举。


const bfs = <V, E>(
  graph: Graph<V, E>,
  start: string,
  visit: (id: string, depth: number) => void,
): Map<string, number> => {
  const distances = new Map<string, number>();
  const queue: Array<[string, number]> = [[start, 0]];
  distances.set(start, 0);

  while (queue.length > 0) {
    const [current, depth] = queue.shift()!;
    visit(current, depth);

    for (const { id } of graph.getNeighbors(current)) {
      if (!distances.has(id)) {
        distances.set(id, depth + 1);
        queue.push([id, depth + 1]);
      }
    }
  }
  return distances;
};

const dfs = <V, E>(
  graph: Graph<V, E>,
  start: string,
  visit: (id: string) => void,
  visited = new Set<string>(),
): void => {
  if (visited.has(start)) return;
  visited.add(start);
  visit(start);

  for (const { id } of graph.getNeighbors(start)) {
    dfs(graph, id, visit, visited);
  }
};

在微服务系统中，BFS 用于分析故障传播的"爆炸半径"——从一个故障服务出发，BFS 的每一层代表故障可能传播的下一圈受影响服务。DFS 用于检测循环依赖——如果 DFS 过程中遇到灰色节点（正在当前路径上的节点），就发现了一个环。


A* 搜索算法
A* 算法是 Dijkstra 算法的启发式增强版本，通过估价函数 f(n) = g(n) + h(n) 来引导搜索方向。g(n) 是从起点到当前节点的实际代价，h(n) 是从当前节点到目标节点的估计代价（启发函数）。当 h(n) 是可接受的（不高估实际代价），A* 保证找到最优路径。


interface AStarNode {
  id: string;
  g: number;
  h: number;
  f: number;
  parent: string | null;
}

const aStar = <V>(
  graph: Graph<V, number>,
  start: string,
  goal: string,
  heuristic: (id: string, goal: string) => number,
): string[] | null => {
  const openSet = new Map<string, AStarNode>();
  const closedSet = new Set<string>();

  openSet.set(start, {
    id: start,
    g: 0,
    h: heuristic(start, goal),
    f: heuristic(start, goal),
    parent: null,
  });

  while (openSet.size > 0) {
    let current: AStarNode | null = null;
    for (const node of openSet.values()) {
      if (!current || node.f < current.f) current = node;
    }

    if (!current) return null;
    if (current.id === goal) {
      const path: string[] = [];
      let node: AStarNode | null = current;
      while (node) {
        path.unshift(node.id);
        node = node.parent ? (openSet.get(node.parent) ?? null) : null;
      }
      return path;
    }

    openSet.delete(current.id);
    closedSet.add(current.id);

    for (const { id, edge: weight } of graph.getNeighbors(current.id)) {
      if (closedSet.has(id)) continue;
      const tentativeG = current.g + weight;
      const existing = openSet.get(id);

      if (!existing || tentativeG < existing.g) {
        openSet.set(id, {
          id,
          g: tentativeG,
          h: heuristic(id, goal),
          f: tentativeG + heuristic(id, goal),
          parent: current.id,
        });
      }
    }
  }
  return null;
};

PageRank 与节点重要性
PageRank 由 Larry Page 和 Sergey Brin 提出，是 Google 搜索引擎的核心算法之一。其基本思想是：一个网页的重要性取决于指向它的其他网页的数量和质量。形式化为迭代公式：PR(v) = (1-d)/N + d × Σ(PR(u)/L(u))，其中 d 是阻尼因子（通常 0.85），L(u) 是 u 的出度。


PageRank 不仅用于网页排名，在软件系统中也有广泛应用。对微服务依赖图运行 PageRank，可以识别系统中最"重要"的服务——被更多重要服务依赖的服务 PageRank 值更高。这有助于资源分配（给高 PageRank 服务分配更多资源）和故障优先级（高 PageRank 服务的故障需要最优先处理）。


const pageRank = <V, E>(
  graph: Graph<V, E>,
  damping: number = 0.85,
  iterations: number = 100,
  tolerance: number = 1e-6,
): Map<string, number> => {
  const vertices = graph.getVertices();
  const n = vertices.length;
  const rank = new Map<string, number>();

  for (const v of vertices) rank.set(v, 1 / n);

  for (let i = 0; i < iterations; i++) {
    const newRank = new Map<string, number>();
    let maxDiff = 0;

    for (const v of vertices) {
      let sum = 0;
      for (const u of vertices) {
        if (graph.hasEdge(u, v)) {
          const outDegree = graph.getNeighbors(u).length;
          sum += (rank.get(u) ?? 0) / outDegree;
        }
      }
      const newVal = (1 - damping) / n + damping * sum;
      newRank.set(v, newVal);
      maxDiff = Math.max(maxDiff, Math.abs(newVal - (rank.get(v) ?? 0)));
    }

    for (const [k, v] of newRank) rank.set(k, v);
    if (maxDiff < tolerance) break;
  }
  return rank;
};
小结
    

  • BFS 和 DFS 是所有图算法的基础，分别适合层级分析和环检测
    • 

  • A* 通过启发函数引导搜索，在保证最优性的同时显著减少搜索空间
    • 

  • PageRank 通过迭代传播计算节点重要性，在服务依赖分析中识别关键服务
    • 

  • 图算法的选择取决于问题性质（遍历、路径、连通性、中心性）和图的规模
    • 

  • 微服务架构中的循环依赖检测、故障传播分析和关键服务识别都依赖图算法
    • 

  • 理解图算法的时间复杂度对处理大规模网络数据至关重要
