图论基础

核心概念

图（Graph）是描述对象之间关系的数学结构，由顶点（Vertex/Node）集合和边（Edge）集合组成。图论是网络科学的数学基础，为分析任何由"实体+关系"构成的系统提供了精确的语言和工具。从社交网络到微服务依赖、从路由拓扑到知识图谱，图无处不在。

形式化地，图 G = (V, E) 由顶点集 V 和边集 E ⊆ V × V 组成。边 (u, v) 表示顶点 u 和 v 之间存在关系。这个简单的定义支撑了一个丰富的数学理论体系。

图的表示方式有两种主要选择：邻接矩阵和邻接表。邻接矩阵用 V×V 的矩阵存储边的信息，适合稠密图和需要快速查询两点间是否有边的场景。邻接表用链表/数组存储每个顶点的邻居，适合稀疏图且更省内存。大多数真实世界的网络是稀疏的（边数远小于 V²），因此邻接表是更常用的选择。


图的数据结构实现
在软件工程中，图的实现需要在空间效率、查询效率和实现复杂度之间做权衡。


interface Graph<V, E> {
  addVertex(id: string, data: V): void;
  addEdge(from: string, to: string, data: E): void;
  getNeighbors(id: string): Array<{ id: string; edge: E }>;
  hasEdge(from: string, to: string): boolean;
  getVertices(): string[];
  getEdgeCount(): number;
}

class AdjacencyListGraph<V, E> implements Graph<V, E> {
  private vertices = new Map<string, V>();
  private edges = new Map<string, Map<string, E>>();

  addVertex(id: string, data: V): void {
    this.vertices.set(id, data);
    if (!this.edges.has(id)) this.edges.set(id, new Map());
  }

  addEdge(from: string, to: string, data: E): void {
    this.edges.get(from)?.set(to, data);
  }

  getNeighbors(id: string): Array<{ id: string; edge: E }> {
    const neighbors = this.edges.get(id);
    if (!neighbors) return [];
    return [...neighbors].map(([id, edge]) => ({ id, edge }));
  }

  hasEdge(from: string, to: string): boolean {
    return this.edges.get(from)?.has(to) ?? false;
  }

  getVertices(): string[] {
    return [...this.vertices.keys()];
  }

  getEdgeCount(): number {
    let count = 0;
    for (const neighbors of this.edges.values()) count += neighbors.size;
    return count;
  }
}

度与度分布
度（Degree）是图论中最基本的顶点属性。无向图中，顶点的度等于与其相连的边数。有向图中，区分入度（In-Degree，指向该顶点的边数）和出度（Out-Degree，从该顶点出发的边数）。


度分布 P(k) 描述了网络中度为 k 的顶点所占比例。度分布是区分不同类型网络的关键特征。随机网络（Erdős–Rényi 模型）的度分布近似正态分布，大多数顶点的度接近平均值。真实世界的网络（如互联网、社交网络）通常遵循幂律分布 P(k) ~ k^(-γ)，少数顶点有极高的度（Hub 节点），大多数顶点度很低。


在软件系统中，度分析有直接的工程价值。分析微服务依赖图的入度和出度可以识别系统中的关键节点：高入度的服务是被大量依赖的基础服务（如认证服务、用户服务），其故障影响面广；高出度的服务依赖大量其他服务（如聚合网关），其可靠性受制于所有上游服务。

路径与连通性
路径是图中从一个顶点到另一个顶点的边序列。最短路径的长度定义了两个顶点之间的"距离"。图的直径（Diameter）是所有顶点对之间最短路径的最大值，描述了图中信息传播需要的最大步数。


连通性描述了图中顶点之间的可达关系。在无向图中，如果任意两个顶点之间存在路径，图是连通的。强连通分量（Strongly Connected Component, SCC）是有向图中任意两点可以互相到达的最大子图。


在微服务架构中，连通性分析揭示了系统的结构特征。如果服务依赖图不是连通的，说明系统可以被分解为完全独立的子系统。强连通分量的存在通常意味着循环依赖——这是架构设计中需要特别关注的问题。


const findConnectedComponents = (graph: Graph<unknown, unknown>): string[][] => {
  const visited = new Set<string>();
  const components: string[][] = [];

  const bfs = (start: string): string[] => {
    const component: string[] = [];
    const queue = [start];
    visited.add(start);

    while (queue.length > 0) {
      const current = queue.shift()!;
      component.push(current);
      for (const { id } of graph.getNeighbors(current)) {
        if (!visited.has(id)) {
          visited.add(id);
          queue.push(id);
        }
      }
    }
    return component;
  };

  for (const vertex of graph.getVertices()) {
    if (!visited.has(vertex)) {
      components.push(bfs(vertex));
    }
  }
  return components;
};
小结
    

  • 图由顶点和边组成，是描述实体关系的通用数学结构
    • 

  • 邻接矩阵适合稠密图和快速边查询，邻接表适合稀疏图和遍历操作
    • 

  • 度是顶点最基本的属性，度分布区分了随机网络和无标度网络
    • 

  • 微服务依赖图的入度/出度分析可以识别单点故障和级联故障风险
    • 

  • 连通性分析揭示系统的独立子系统和循环依赖
    • 

  • 图论为网络科学提供了精确的数学语言和算法工具
