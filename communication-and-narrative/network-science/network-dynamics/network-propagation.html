网络传播

核心概念

网络传播（Network Propagation）研究信息、疾病、谣言、故障等实体在网络中扩散的动力学过程。传播动力学揭示了网络拓扑结构如何决定传播速度、范围和模式。对软件工程师而言，理解传播模型有助于分析故障扩散、信息分发和产品采用过程。

传播模型的基本框架来自流行病学。SIR（易感-感染-恢复）模型和 SIS（易感-感染-易感）模型是两个基础模型。在 SIR 模型中，个体从易感状态（S）转变为感染状态（I），然后恢复（R）并获得免疫。在 SIS 模型中，恢复后的个体回到易感状态，可以被再次感染。

基本再生数 R₀ = β/γ 是传播动力学中最关键的参数。当 R₀ > 1 时，传播呈指数增长；当 R₀ < 1 时，传播自然消退。在软件系统中，故障的"R₀"取决于每个故障服务平均影响多少个健康服务。熔断器的作用就是将 R₀ 降低到 1 以下，阻断故障的级联传播。


网络结构对传播的影响
传播动力学与网络拓扑深度耦合。在无标度网络中，Hub 节点既是超级传播者（如果被感染，可以迅速感染大量邻居），也是超级免疫目标（优先免疫 Hub 节点的效果远优于随机免疫）。


interface PropagationSimulation {
  graph: Map<string, Set<string>>;
  state: Map<string, 'S' | 'I' | 'R'>;
  beta: number;
  gamma: number;
}

const simulateSIR = (
  graph: Map<string, Set<string>>,
  initialInfected: string[],
  beta: number,
  gamma: number,
  maxSteps: number,
): Array<{ step: number; s: number; i: number; r: number }> => {
  const state = new Map<string, 'S' | 'I' | 'R'>();
  for (const node of graph.keys()) state.set(node, 'S');
  for (const node of initialInfected) state.set(node, 'I');

  const history: Array<{ step: number; s: number; i: number; r: number }> = [];

  for (let step = 0; step < maxSteps; step++) {
    let s = 0,
      i = 0,
      r = 0;
    for (const st of state.values()) {
      if (st === 'S') s++;
      else if (st === 'I') i++;
      else r++;
    }
    history.push({ step, s, i, r });

    if (i === 0) break;

    const newStates = new Map(state);

    for (const [node, st] of state) {
      if (st === 'I') {
        for (const neighbor of graph.get(node) ?? []) {
          if (state.get(neighbor) === 'S' && Math.random() < beta) {
            newStates.set(neighbor, 'I');
          }
        }
        if (Math.random() < gamma) {
          newStates.set(node, 'R');
        }
      }
    }

    for (const [k, v] of newStates) state.set(k, v);
  }

  return history;
};

在无标度网络中一个关键发现是：传播阈值接近零。这意味着即使传播力很弱的"疾病"（或故障）也能在无标度网络中持续存在。在软件系统中，这暗示着低概率的间歇性故障在高度连接的系统中永远不会自行消退——需要主动干预。


影响力最大化
影响力最大化问题（Influence Maximization）是传播动力学的逆问题：给定网络结构和传播模型，找到 k 个"种子节点"使得最终传播范围最大。这个问题在病毒营销、信息分发和安全加固中都有直接应用。


Kempe 等人在 2003 年证明影响力最大化是 NP-hard 问题，但贪心算法可以获得 (1-1/e) ≈ 63% 的近似最优解。贪心策略每次选择能带来最大边际传播增量的节点。


在软件系统中，影响力最大化的对偶问题——关键节点免疫——更有实际意义。给定有限的容灾预算（只能为 k 个服务部署高可用方案），哪些服务应该优先保护？

信息传播与谣言模型
信息在社交网络中的传播遵循不同于疾病的规则。DK（Daley-Kendall）谣言模型将个体分为三类：Ignorant（不知情者）、Spreader（传播者）和 Stifler（沉默者）。传播者遇到不知情者时传递信息，但传播者遇到另一个传播者或沉默者时会变成沉默者（因为信息已不再"新鲜"）。


在软件系统中，配置变更的传播类似谣言模型。配置中心推送新配置时，服务实例从"旧配置"变为"新配置"。已经获得新配置的实例不会再次被同一变更"感染"。传播速度取决于配置推送的网络拓扑和推送策略。


interface RumorSpread {
  graph: Map<string, Set<string>>;
  ignorants: Set<string>;
  spreaders: Set<string>;
  stiflers: Set<string>;
}

const simulateRumor = (
  graph: Map<string, Set<string>>,
  initialSpreader: string,
  spreadRate: number,
  stifleRate: number,
  maxSteps: number,
): { finalReached: number; peakSpreaders: number } => {
  const ignorants = new Set(graph.keys());
  const spreaders = new Set<string>();
  const stiflers = new Set<string>();

  ignorants.delete(initialSpreader);
  spreaders.add(initialSpreader);

  let peakSpreaders = 1;

  for (let step = 0; step < maxSteps; step++) {
    if (spreaders.size === 0) break;

    const newSpreaders = new Set<string>();
    const newStiflers = new Set<string>();

    for (const spreader of spreaders) {
      for (const neighbor of graph.get(spreader) ?? []) {
        if (ignorants.has(neighbor) && Math.random() < spreadRate) {
          ignorants.delete(neighbor);
          newSpreaders.add(neighbor);
        } else if ((spreaders.has(neighbor) || stiflers.has(neighbor)) && Math.random() < stifleRate) {
          newStiflers.add(spreader);
        }
      }
    }

    for (const s of newSpreaders) spreaders.add(s);
    for (const s of newStiflers) {
      spreaders.delete(s);
      stiflers.add(s);
    }

    peakSpreaders = Math.max(peakSpreaders, spreaders.size);
  }

  return {
    finalReached: stiflers.size + spreaders.size,
    peakSpreaders,
  };
};
小结
    

  • SIR/SIS 等流行病学模型为网络传播提供了数学框架
    • 

  • 基本再生数 R₀ 决定了传播是扩散还是消退，熔断器的本质是将故障 R₀ 降到 1 以下
    • 

  • 无标度网络中传播阈值接近零，低概率故障也能持续存在
    • 

  • 影响力最大化和关键节点免疫是传播动力学的正问题和逆问题
    • 

  • 度中心性是最简单有效的种子/免疫节点选择策略
    • 

  • 信息传播遵循谣言模型而非疾病模型，传播速度随时间自然衰减
