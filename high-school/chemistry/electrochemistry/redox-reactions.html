高二化学 — 氧化还原

知识要点

氧化还原反应是化学反应中最重要的一大类，几乎贯穿了无机化学和电化学的全部内容。其本质是电子的转移（或共用电子对的偏移），而不仅仅是得失氧。通过化合价的升降来判断氧化还原关系，是分析复杂反应的基本功。

概念 定义 化合价变化 电子转移
氧化反应 物质失去电子的过程 升高 失去 e−e^-e−
还原反应 物质得到电子的过程 降低 得到 e−e^-e−
氧化剂 反应中得电子的物质 化合价降低 被还原
还原剂 反应中失电子的物质 化合价升高 被氧化
氧化产物 还原剂被氧化后的产物 — —
还原产物 氧化剂被还原后的产物 — —

详细讲解

一、氧化还原反应的判断

判断一个反应是否属于氧化还原反应，关键在于是否有元素化合价的变化。

Fe+CuSO4→FeSO4+Cu\text{Fe} + \text{CuSO}_4 \to \text{FeSO}_4 + \text{Cu}Fe+CuSO4​→FeSO4​+Cu

在这个反应中：Fe\text{Fe}Fe 从 000 价升高到 +2+2+2 价（失去 222 个电子，被氧化，是还原剂）；Cu2+\text{Cu}^{2+}Cu2+ 从 +2+2+2 价降低到 000 价（得到 222 个电子，被还原，是氧化剂）。

关系链条：

  • 还原剂 → 失电子 → 化合价升高 → 被氧化 → 发生氧化反应 → 生成氧化产物
  • 氧化剂 → 得电子 → 化合价降低 → 被还原 → 发生还原反应 → 生成还原产物

记忆口诀：升失氧还原剂，降得还氧化剂。

三、氧化还原反应方程式的配平

配平原则：电子守恒（转移电子总数相等）+ 电荷守恒 + 质量守恒。

配平步骤（化合价升降法）：

  1. 标出变价元素的化合价
  2. 列出升降变化值
  3. 用最小公倍数使升降总量相等
  4. 确定系数后配平其余原子

例：配平 Cu+HNO3(稀)→Cu(NO3)2+NO↑+H2O\text{Cu} + \text{HNO}_3(\text{稀}) \to \text{Cu(NO}_3)_2 + \text{NO}\uparrow + \text{H}_2\text{O}Cu+HNO3​(稀)→Cu(NO3​)2​+NO↑+H2​O

  • Cu\text{Cu}Cu：0→+20 \to +20→+2，升高 222
  • N\text{N}N：+5→+2+5 \to +2+5→+2，降低 333

最小公倍数为 666：333 个 Cu\text{Cu}Cu 失 666 个电子，222 个 N\text{N}N 得 666 个电子。

3Cu+8HNO3(稀)=3Cu(NO3)2+2NO↑+4H2O3\text{Cu} + 8\text{HNO}_3(\text{稀}) = 3\text{Cu(NO}_3)_2 + 2\text{NO}\uparrow + 4\text{H}_2\text{O}3Cu+8HNO3​(稀)=3Cu(NO3​)2​+2NO↑+4H2​O

其中 888 个 HNO3\text{HNO}_3HNO3​ 中只有 222 个被还原（表现氧化性），另外 666 个提供 NO3−\text{NO}_3^-NO3−​ 与 Cu2+\text{Cu}^{2+}Cu2+ 结合。

四、氧化还原反应中的特殊情况

（1）歧化反应

同一种元素既被氧化又被还原：

Cl2+2NaOH=NaCl+NaClO+H2O\text{Cl}_2 + 2\text{NaOH} = \text{NaCl} + \text{NaClO} + \text{H}_2\text{O}Cl2​+2NaOH=NaCl+NaClO+H2​O

Cl2\text{Cl}_2Cl2​ 中 Cl\text{Cl}Cl 为 000 价，产物中 NaCl\text{NaCl}NaCl 的 Cl\text{Cl}Cl 为 −1-1−1 价（被还原），NaClO\text{NaClO}NaClO 的 Cl\text{Cl}Cl 为 +1+1+1 价（被氧化）。

（2）归中反应

不同价态的同种元素生成中间价态：

H2S+SO2→S+H2O\text{H}_2\text{S} + \text{SO}_2 \to \text{S} + \text{H}_2\text{O}H2​S+SO2​→S+H2​O

S−2\text{S}^{-2}S−2 和 S+4\text{S}^{+4}S+4 归中到 S0\text{S}^{0}S0。

（3）自身氧化还原

2Na2O2+2H2O=4NaOH+O2↑2\text{Na}_2\text{O}_2 + 2\text{H}_2\text{O} = 4\text{NaOH} + \text{O}_2\uparrow2Na2​O2​+2H2​O=4NaOH+O2​↑

Na2O2\text{Na}_2\text{O}_2Na2​O2​ 中 O\text{O}O 为 −1-1−1 价，产物中 NaOH\text{NaOH}NaOH 的 O\text{O}O 为 −2-2−2 价（被还原），O2\text{O}_2O2​ 的 O\text{O}O 为 000 价（被氧化）。

五、氧化性与还原性强弱的比较

规律一： 氧化剂的氧化性 >>> 氧化产物的氧化性；还原剂的还原性 >>> 还原产物的还原性。

由反应 Fe+CuSO4=FeSO4+Cu\text{Fe} + \text{CuSO}_4 = \text{FeSO}_4 + \text{Cu}Fe+CuSO4​=FeSO4​+Cu 可得：

  • 还原性：Fe>Cu\text{Fe} > \text{Cu}Fe>Cu
  • 氧化性：Cu2+>Fe2+\text{Cu}^{2+} > \text{Fe}^{2+}Cu2+>Fe2+

规律二： 金属活动性顺序表反映了还原性的强弱。

K>Na>Mg>Al>Zn>Fe>Cu>Ag>Au\text{K} > \text{Na} > \text{Mg} > \text{Al} > \text{Zn} > \text{Fe} > \text{Cu} > \text{Ag} > \text{Au}K>Na>Mg>Al>Zn>Fe>Cu>Ag>Au

对应阳离子的氧化性顺序相反。

六、氧化还原反应与电子转移的表示

双线桥法：在反应方程式上方标出氧化剂到还原产物的电子转移，下方标出还原剂到氧化产物的电子转移。箭头起止为同一元素的不同价态。

单线桥法：只画一条从还原剂到氧化剂的箭头，标注转移的电子数。

拓展阅读

氧化还原反应在日常生活中无处不在：铁的锈蚀是缓慢氧化的典型例子，食物腐败的本质也是有机物被氧化的过程。人体的呼吸作用本质上是葡萄糖在酶催化下被缓慢氧化为 CO2\text{CO}_2CO2​ 和 H2O\text{H}_2\text{O}H2​O，释放的能量以 ATP 形式储存。

金属冶炼的历史就是人类掌握还原反应的历史。从青铜时代的碳还原铜矿，到现代电解法冶炼铝，每一次冶金技术的进步都改变了人类文明的面貌。

法医科学中的血迹检测（鲁米诺反应）也是氧化还原反应的应用：血红素中的铁离子催化过氧化氢氧化鲁米诺，产生蓝色荧光——这是氧化还原反应在犯罪侦查中的精妙应用。

小结

  • 氧化还原反应的本质是电子的转移，外在表现为化合价的升降
  • "升失氧还原剂，降得还氧化剂"是判断各角色的核心口诀
  • 配平氧化还原方程式的关键是电子守恒（升降总量相等）
  • 歧化反应和归中反应是氧化还原的两种特殊形式
  • 氧化性和还原性的强弱可通过金属活动性顺序和反应事实来判断
