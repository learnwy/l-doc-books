高一化学 — 化学方程式

知识要点

铁在潮湿空气中会慢慢生锈，氢气在氧气中燃烧生成水——这些化学变化该如何用精确的语言描述？化学方程式就是化学反应的"数学表达式"，它不仅告诉我们反应物和生成物是什么，还揭示了它们之间精确的物质的量关系。化学方程式的配平是将"定性描述"升级为"定量计算"的关键一步，而基于化学方程式的计算则是化学工业中确定原料用量和产品产量的基本工具。

详细讲解

一、化学方程式的书写规则

化学方程式：用化学式表示化学反应的式子。

书写步骤：

  1. 写出反应物和生成物的正确化学式
  2. 配平方程式（使等号两边各元素原子数相等）
  3. 标注反应条件（加热 △\triangle△、催化剂、点燃、光照等）
  4. 标注气体符号 ↑\uparrow↑ 和沉淀符号 ↓\downarrow↓（在溶液中反应时）

示例：

铁在氧气中燃烧：

3Fe+2O2→点燃Fe3O43\text{Fe} + 2\text{O}_2 \xrightarrow{\text{点燃}} \text{Fe}_3\text{O}_43Fe+2O2​点燃​Fe3​O4​

氢气还原氧化铜：

H2+CuO→△Cu+H2O\text{H}_2 + \text{CuO} \xrightarrow{\triangle} \text{Cu} + \text{H}_2\text{O}H2​+CuO△​Cu+H2​O

二、化学方程式的配平方法

配平的目标是使方程式两边每种元素的原子数相等（质量守恒定律的要求）。

（一）观察法

从最复杂的化学式入手，逐步调整系数。

例如配平：Al+O2→Al2O3\text{Al} + \text{O}_2 \to \text{Al}_2\text{O}_3Al+O2​→Al2​O3​

  • Al2O3\text{Al}_2\text{O}_3Al2​O3​ 中有 333 个 O，而 O2\text{O}_2O2​ 中有 222 个 O
  • O 的最小公倍数为 666，所以 Al2O3\text{Al}_2\text{O}_3Al2​O3​ 前系数为 222，O2\text{O}_2O2​ 前系数为 333
  • 右边有 444 个 Al，所以 Al 前系数为 444
4Al+3O2→点燃2Al2O34\text{Al} + 3\text{O}_2 \xrightarrow{\text{点燃}} 2\text{Al}_2\text{O}_34Al+3O2​点燃​2Al2​O3​

（二）奇偶法

当某元素在方程式一边为奇数个、另一边为偶数个时，先在奇数个的化学式前加系数 222。

（三）化合价升降法（氧化还原反应）

原则：化合价升高的总数 = 化合价降低的总数

例如配平：Fe2O3+CO→Fe+CO2\text{Fe}_2\text{O}_3 + \text{CO} \to \text{Fe} + \text{CO}_2Fe2​O3​+CO→Fe+CO2​

  • Fe 化合价从 +3+3+3 降到 000，每个 Fe 降 333，222 个 Fe 共降 666
  • C 化合价从 +2+2+2 升到 +4+4+4，每个 C 升 222
  • 升降相等：需要 333 个 CO
Fe2O3+3CO→高温2Fe+3CO2\text{Fe}_2\text{O}_3 + 3\text{CO} \xrightarrow{\text{高温}} 2\text{Fe} + 3\text{CO}_2Fe2​O3​+3CO高温​2Fe+3CO2​

三、化学方程式的含义

一个配平的化学方程式包含多层含义：

以 2H2+O2→点燃2H2O2\text{H}_2 + \text{O}_2 \xrightarrow{\text{点燃}} 2\text{H}_2\text{O}2H2​+O2​点燃​2H2​O 为例：

层次 含义
定性 氢气和氧气在点燃条件下反应生成水
微观（粒子数比） 每 222 个 H2\text{H}_2H2​ 分子与 111 个 O2\text{O}_2O2​ 分子反应生成 222 个 H2O\text{H}_2\text{O}H2​O 分子
物质的量比 2 mol2\text{ mol}2 mol H2\text{H}_2H2​ 与 1 mol1\text{ mol}1 mol O2\text{O}_2O2​ 反应生成 2 mol2\text{ mol}2 mol H2O\text{H}_2\text{O}H2​O
质量比 4 g4\text{ g}4 g H2\text{H}_2H2​ 与 32 g32\text{ g}32 g O2\text{O}_2O2​ 反应生成 36 g36\text{ g}36 g H2O\text{H}_2\text{O}H2​O
气体体积比（同温同压） 222 体积 H2\text{H}_2H2​ 与 111 体积 O2\text{O}_2O2​ 反应生成 222 体积 H2O\text{H}_2\text{O}H2​O（气态）

四、根据化学方程式的计算

基本思路：利用化学方程式中各物质的物质的量之比进行计算。

计算步骤：

  1. 写出配平的化学方程式
  2. 在相关物质下方标注物质的量之比
  3. 将已知量转化为物质的量
  4. 利用物质的量之比求未知量的物质的量
  5. 将结果转化为所求的物理量（质量、体积等）

典型例题：

实验室用 11.2 g11.2\text{ g}11.2 g 铁与足量稀盐酸反应，求生成氢气在标准状况下的体积。

Fe+2HCl=FeCl2+H2↑\text{Fe} + 2\text{HCl} = \text{FeCl}_2 + \text{H}_2\uparrowFe+2HCl=FeCl2​+H2​↑
  • Fe 的物质的量：n(Fe)=11.256=0.2 moln(\text{Fe}) = \frac{11.2}{56} = 0.2\text{ mol}n(Fe)=5611.2​=0.2 mol
  • 由方程式：n(H2)=n(Fe)=0.2 moln(\text{H}_2) = n(\text{Fe}) = 0.2\text{ mol}n(H2​)=n(Fe)=0.2 mol
  • 氢气在 STP 下的体积：V=nVm=0.2×22.4=4.48 LV = nV_m = 0.2 \times 22.4 = 4.48\text{ L}V=nVm​=0.2×22.4=4.48 L

五、离子方程式

定义：用实际参加反应的离子来表示反应的式子。

书写步骤：

  1. 写出完整的化学方程式
  2. 将强电解质（易溶的强酸、强碱和可溶性盐）改写为离子形式
  3. 删去等号两边相同的离子（旁观离子）
  4. 检查：原子守恒、电荷守恒

示例：

NaOH+HCl=NaCl+H2O\text{NaOH} + \text{HCl} = \text{NaCl} + \text{H}_2\text{O}NaOH+HCl=NaCl+H2​O

离子方程式：

OH−+H+=H2O\text{OH}^- + \text{H}^+ = \text{H}_2\text{O}OH−+H+=H2​O

注意事项：

  • 难溶物、弱电解质、气体和单质不能拆写为离子形式
  • H2O\text{H}_2\text{O}H2​O、BaSO4\text{BaSO}_4BaSO4​、CaCO3\text{CaCO}_3CaCO3​ 等保留化学式形式
  • 弱酸（CH3COOH\text{CH}_3\text{COOH}CH3​COOH、H2CO3\text{H}_2\text{CO}_3H2​CO3​）、弱碱（NH3⋅H2O\text{NH}_3\cdot\text{H}_2\text{O}NH3​⋅H2​O）保留分子形式

六、氧化还原反应方程式

核心概念：

概念 定义 关键词
氧化反应 物质失去电子（化合价升高）的反应 失电子、升价
还原反应 物质得到电子（化合价降低）的反应 得电子、降价
氧化剂 得到电子的物质 化合价降低，被还原
还原剂 失去电子的物质 化合价升高，被氧化

记忆口诀：升（化合价升高）→ 失（失去电子）→ 氧化（被氧化）→ 还原剂

以 Zn+CuSO4=ZnSO4+Cu\text{Zn} + \text{CuSO}_4 = \text{ZnSO}_4 + \text{Cu}Zn+CuSO4​=ZnSO4​+Cu 为例：

  • Zn：化合价从 000 升到 +2+2+2，失去 222 个电子，被氧化，Zn 是还原剂
  • Cu：化合价从 +2+2+2 降到 000，得到 222 个电子，被还原，CuSO4\text{CuSO}_4CuSO4​ 是氧化剂

七、化学计量数与限量计算

当两种反应物都给出用量时，需要判断哪种过量、哪种不足。

方法：将两种反应物的物质的量分别除以各自的化学计量数，商较小的为限量（不足量），计算应以限量为基准。

例如：2 mol2\text{ mol}2 mol H2\text{H}_2H2​ 与 2 mol2\text{ mol}2 mol O2\text{O}_2O2​ 反应。

2H2+O2→2H2O2\text{H}_2 + \text{O}_2 \to 2\text{H}_2\text{O}2H2​+O2​→2H2​O
  • H2\text{H}_2H2​：2/2=12/2 = 12/2=1
  • O2\text{O}_2O2​：2/1=22/1 = 22/1=2

H2\text{H}_2H2​ 的商更小，为限量。生成 H2O\text{H}_2\text{O}H2​O 的量以 H2\text{H}_2H2​ 计算：n(H2O)=2 moln(\text{H}_2\text{O}) = 2\text{ mol}n(H2​O)=2 mol。

练习与思考

  1. 配平下列化学方程式：(1) KClO3→KCl+O2\text{KClO}_3 \to \text{KCl} + \text{O}_2KClO3​→KCl+O2​；(2) C2H6+O2→CO2+H2O\text{C}_2\text{H}_6 + \text{O}_2 \to \text{CO}_2 + \text{H}_2\text{O}C2​H6​+O2​→CO2​+H2​O；(3) MnO2+HCl→MnCl2+Cl2+H2O\text{MnO}_2 + \text{HCl} \to \text{MnCl}_2 + \text{Cl}_2 + \text{H}_2\text{O}MnO2​+HCl→MnCl2​+Cl2​+H2​O。

  2. 6.5 g6.5\text{ g}6.5 g 锌与足量稀硫酸反应，求生成 H2\text{H}_2H2​ 在标准状况下的体积和消耗 H2SO4\text{H}_2\text{SO}_4H2​SO4​ 的物质的量。

  3. 写出下列反应的离子方程式：(1) Ba(OH)2+H2SO4\text{Ba(OH)}_2 + \text{H}_2\text{SO}_4Ba(OH)2​+H2​SO4​；(2) Na2CO3+HCl\text{Na}_2\text{CO}_3 + \text{HCl}Na2​CO3​+HCl。

  4. Na\text{Na}Na 在 O2\text{O}_2O2​ 中充分燃烧生成 Na2O2\text{Na}_2\text{O}_2Na2​O2​。若有 4.6 g4.6\text{ g}4.6 g Na 参加反应，求需要 O2\text{O}_2O2​ 的质量和生成 Na2O2\text{Na}_2\text{O}_2Na2​O2​ 的质量。

  5. 思考：化学方程式的系数代表分子数之比，也代表物质的量之比。但能否代表质量之比？为什么？

拓展阅读

化学方程式的配平看似简单，但对于复杂的有机反应或氧化还原反应，配平可能相当具有挑战性。数学上，化学方程式的配平本质上是求解一个线性齐次方程组。例如 aC2H6+bO2→cCO2+dH2Oa\text{C}_2\text{H}_6 + b\text{O}_2 \to c\text{CO}_2 + d\text{H}_2\text{O}aC2​H6​+bO2​→cCO2​+dH2​O 的配平等价于求解：C: 2a=c2a = c2a=c；H: 6a=2d6a = 2d6a=2d；O: 2b=2c+d2b = 2c + d2b=2c+d。这三个方程有四个未知数，取 a=1a = 1a=1 后即可解出 c=2c = 2c=2，d=3d = 3d=3，b=7/2b = 7/2b=7/2，两边乘 222 得到整数系数。计算机化学中，矩阵方法可以自动配平任意复杂的化学方程式，这也是化学信息学的基础应用之一。

小结

化学方程式是用化学式和系数精确描述化学反应的工具。配平方程式使等号两边各元素原子数相等，常用方法包括观察法、奇偶法和化合价升降法。方程式的系数既代表粒子数比，也代表物质的量之比。基于方程式的计算以物质的量为核心，通过化学计量数建立已知量和未知量之间的比例关系。离子方程式只保留实际参加反应的离子，更能反映反应的本质。当多种反应物给定用量时，需要通过限量判断来确定计算基准。
