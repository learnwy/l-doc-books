高二化学 — 官能团

知识要点

官能团是决定有机化合物化学性质的特定原子或原子团。有机化学中成千上万种化合物之所以表现出各自独特的性质，根源在于它们含有不同的官能团。学会识别官能团、理解其反应规律，就相当于掌握了有机化学的核心密码。

官能团 名称 结构简式 代表物 所属类别
-OH\text{-OH}-OH 羟基 — 乙醇 C2H5OH\text{C}_2\text{H}_5\text{OH}C2​H5​OH 醇
-CHO\text{-CHO}-CHO 醛基 — 乙醛 CH3CHO\text{CH}_3\text{CHO}CH3​CHO 醛
-COOH\text{-COOH}-COOH 羧基 — 乙酸 CH3COOH\text{CH}_3\text{COOH}CH3​COOH 羧酸
-COO-\text{-COO-}-COO- 酯基 — 乙酸乙酯 酯
-NH2\text{-NH}_2-NH2​ 氨基 — 甲胺 CH3NH2\text{CH}_3\text{NH}_2CH3​NH2​ 胺
C=C\text{C=C}C=C 碳碳双键 — 乙烯 烯烃
-X\text{-X}-X（F,Cl,Br,I\text{F,Cl,Br,I}F,Cl,Br,I） 卤素原子 — 氯乙烷 C2H5Cl\text{C}_2\text{H}_5\text{Cl}C2​H5​Cl 卤代烃

详细讲解

一、醇与羟基

醇是含有羟基（-OH\text{-OH}-OH）与烃基直接相连的有机化合物。乙醇（CH3CH2OH\text{CH}_3\text{CH}_2\text{OH}CH3​CH2​OH）是最重要的醇类。

乙醇的化学性质：

（1）与活泼金属反应（体现 O-H\text{O-H}O-H 键断裂）：

2CH3CH2OH+2Na→2CH3CH2ONa+H2↑2\text{CH}_3\text{CH}_2\text{OH} + 2\text{Na} \to 2\text{CH}_3\text{CH}_2\text{ONa} + \text{H}_2\uparrow2CH3​CH2​OH+2Na→2CH3​CH2​ONa+H2​↑

反应速率远慢于钠与水的反应，说明醇的 O-H\text{O-H}O-H 键比水中的更难断裂。

（2）催化氧化（体现 C-H\text{C-H}C-H 键和 O-H\text{O-H}O-H 键同时断裂）：

2CH3CH2OH+O2→Cu/Δ2CH3CHO+2H2O2\text{CH}_3\text{CH}_2\text{OH} + \text{O}_2 \xrightarrow{\text{Cu}/\Delta} 2\text{CH}_3\text{CHO} + 2\text{H}_2\text{O}2CH3​CH2​OH+O2​Cu/Δ​2CH3​CHO+2H2​O

铜或银作催化剂，醇脱去两个氢原子变为醛。注意：只有含有 -CH2OH\text{-CH}_2\text{OH}-CH2​OH 或 -CHOH-\text{-CHOH-}-CHOH- 结构的醇才能发生催化氧化。

（3）消去反应（分子内脱水）：

CH3CH2OH→170°C,浓H2SO4CH2=CH2↑+H2O\text{CH}_3\text{CH}_2\text{OH} \xrightarrow{170°\text{C}, \text{浓H}_2\text{SO}_4} \text{CH}_2\text{=CH}_2\uparrow + \text{H}_2\text{O}CH3​CH2​OH170°C,浓H2​SO4​​CH2​=CH2​↑+H2​O

（4）酯化反应（分子间脱水）：

CH3COOH+C2H5OH⇌浓H2SO4ΔCH3COOC2H5+H2O\text{CH}_3\text{COOH} + \text{C}_2\text{H}_5\text{OH} \underset{\Delta}{\overset{\text{浓H}_2\text{SO}_4}{\rightleftharpoons}} \text{CH}_3\text{COOC}_2\text{H}_5 + \text{H}_2\text{O}CH3​COOH+C2​H5​OHΔ⇌浓H2​SO4​​​CH3​COOC2​H5​+H2​O

酯化反应是可逆反应，浓硫酸起催化剂和吸水剂的双重作用。

醇的分类：

类型 定义 示例 催化氧化产物
伯醇 -OH\text{-OH}-OH 连在端碳上 CH3CH2OH\text{CH}_3\text{CH}_2\text{OH}CH3​CH2​OH 醛
仲醇 -OH\text{-OH}-OH 连在含两个碳基的碳上 (CH3)2CHOH\text{(CH}_3\text{)}_2\text{CHOH}(CH3​)2​CHOH 酮
叔醇 -OH\text{-OH}-OH 连在含三个碳基的碳上 (CH3)3COH\text{(CH}_3\text{)}_3\text{COH}(CH3​)3​COH 不能催化氧化

二、醛与醛基

醛含有醛基（-CHO\text{-CHO}-CHO），是醇与羧酸之间的中间氧化态。

乙醛的化学性质：

（1）银镜反应——醛基被弱氧化剂氧化：

CH3CHO+2[Ag(NH3)2]++2OH−→CH3COO−+NH4++2Ag↓+3NH3+H2O\text{CH}_3\text{CHO} + 2[\text{Ag(NH}_3\text{)}_2]^+ + 2\text{OH}^- \to \text{CH}_3\text{COO}^- + \text{NH}_4^+ + 2\text{Ag}\downarrow + 3\text{NH}_3 + \text{H}_2\text{O}CH3​CHO+2[Ag(NH3​)2​]++2OH−→CH3​COO−+NH4+​+2Ag↓+3NH3​+H2​O

银镜反应需要在水浴加热条件下进行，试管内壁会产生光亮的银镜。这是检验醛基的经典方法。

（2）与新制氢氧化铜悬浊液反应：

CH3CHO+2Cu(OH)2→ΔCH3COOH+Cu2O↓+2H2O\text{CH}_3\text{CHO} + 2\text{Cu(OH)}_2 \xrightarrow{\Delta} \text{CH}_3\text{COOH} + \text{Cu}_2\text{O}\downarrow + 2\text{H}_2\text{O}CH3​CHO+2Cu(OH)2​Δ​CH3​COOH+Cu2​O↓+2H2​O

产生砖红色沉淀，可用于检验醛基（如医学上检验尿糖）。

（3）加成反应——与 H2\text{H}_2H2​ 加成被还原为醇：

CH3CHO+H2→催化剂CH3CH2OH\text{CH}_3\text{CHO} + \text{H}_2 \xrightarrow{\text{催化剂}} \text{CH}_3\text{CH}_2\text{OH}CH3​CHO+H2​催化剂​CH3​CH2​OH

（4）被酸性 KMnO4\text{KMnO}_4KMnO4​ 氧化为羧酸。

三、羧酸与羧基

羧酸含有羧基（-COOH\text{-COOH}-COOH），具有酸性。乙酸（CH3COOH\text{CH}_3\text{COOH}CH3​COOH）是最常见的有机酸。

乙酸的化学性质：

（1）酸性：乙酸是弱酸，但酸性强于碳酸。

CH3COOH+NaOH→CH3COONa+H2O\text{CH}_3\text{COOH} + \text{NaOH} \to \text{CH}_3\text{COONa} + \text{H}_2\text{O}CH3​COOH+NaOH→CH3​COONa+H2​O
2CH3COOH+Na2CO3→2CH3COONa+H2O+CO2↑2\text{CH}_3\text{COOH} + \text{Na}_2\text{CO}_3 \to 2\text{CH}_3\text{COONa} + \text{H}_2\text{O} + \text{CO}_2\uparrow2CH3​COOH+Na2​CO3​→2CH3​COONa+H2​O+CO2​↑

利用乙酸能与碳酸钠反应产生气泡，可以区分乙酸和乙醇。

（2）酯化反应：与醇脱水生成酯（见前述）。

酸性强弱比较：HCl>CH3COOH>H2CO3>C6H5OH\text{HCl} > \text{CH}_3\text{COOH} > \text{H}_2\text{CO}_3 > \text{C}_6\text{H}_5\text{OH}HCl>CH3​COOH>H2​CO3​>C6​H5​OH（苯酚）

四、酯与油脂

酯是由酸和醇脱水缩合而成的化合物，含酯基 -COO-\text{-COO-}-COO-。

酯的水解（皂化反应）：

酸性条件（可逆）：

CH3COOC2H5+H2O⇌稀H2SO4ΔCH3COOH+C2H5OH\text{CH}_3\text{COOC}_2\text{H}_5 + \text{H}_2\text{O} \underset{\Delta}{\overset{\text{稀H}_2\text{SO}_4}{\rightleftharpoons}} \text{CH}_3\text{COOH} + \text{C}_2\text{H}_5\text{OH}CH3​COOC2​H5​+H2​OΔ⇌稀H2​SO4​​​CH3​COOH+C2​H5​OH

碱性条件（不可逆，更彻底）：

CH3COOC2H5+NaOH→ΔCH3COONa+C2H5OH\text{CH}_3\text{COOC}_2\text{H}_5 + \text{NaOH} \xrightarrow{\Delta} \text{CH}_3\text{COONa} + \text{C}_2\text{H}_5\text{OH}CH3​COOC2​H5​+NaOHΔ​CH3​COONa+C2​H5​OH

油脂是高级脂肪酸甘油酯。油脂在碱性条件下水解称为皂化反应，产物是甘油和高级脂肪酸钠（即肥皂）。

五、官能团间的相互转化

有机化学中各类化合物之间存在清晰的转化关系：

这条转化链的氧化态逐渐升高：烯烃 → 醇 → 醛 → 羧酸，每一步都有对应的官能团变化。

拓展阅读
官能团的概念让有机化学从"一种物质一种性质"的混乱状态进入了系统化时代。19 世纪化学家发现，含有相同官能团的化合物表现出相似的化学性质，这一认识让有机物的分类和性质预测成为可能。


药物设计中，官能团的微小改变可以极大地影响药效。阿司匹林（乙酰水杨酸）是水杨酸酚羟基被乙酰化后的产物——这一个酯基的引入，大大降低了水杨酸对胃的刺激性，同时保留了消炎止痛的功效。


高分子材料的合成也离不开官能团的反应。聚酯纤维（涤纶）由二元酸和二元醇通过酯化缩聚反应合成，尼龙则利用了氨基和羧基的缩合——官能团反应是连接单体为高分子的桥梁。


小结
    

  • 官能团决定有机物的化学性质，同类官能团具有相似的反应规律
    • 

  • 醇的核心反应包括与活泼金属反应、催化氧化、消去和酯化
    • 

  • 醛基可通过银镜反应和新制 Cu(OH)2\text{Cu(OH)}_2Cu(OH)2​ 反应来检验
    • 

  • 羧酸具有酸性，能与碳酸盐反应产生 CO2\text{CO}_2CO2​
    • 

  • 酯在酸性条件下可逆水解，在碱性条件下不可逆水解
    • 

  • 有机转化链：烯烃 → 醇 → 醛 → 羧酸 → 酯，氧化态逐步升高
    •
