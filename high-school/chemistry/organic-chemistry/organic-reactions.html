高二化学 — 有机反应

知识要点

有机反应的种类繁多，但归纳起来主要有取代、加成、消去、氧化还原和聚合等几大类型。掌握每种反应类型的特征——旧键在哪里断裂、新键在哪里生成——是有机合成推断题的核心能力。不同反应类型之间并非孤立存在，同一分子在不同条件下可以走不同的反应路径。

反应类型 核心特征 键的变化 典型官能团
取代反应 一个原子/基团被另一个替换 断一旧键，成一新键 C-H\text{C-H}C-H、C-X\text{C-X}C-X、O-H\text{O-H}O-H
加成反应 双键/三键打开，两端各接新原子 π\piπ 键断裂，成两个 σ\sigmaσ 键 C=C\text{C=C}C=C、C≡C\text{C≡C}C≡C、C=O\text{C=O}C=O
消去反应 分子脱去小分子，生成不饱和键 两个 σ\sigmaσ 键断裂，成一个 π\piπ 键 -OH\text{-OH}-OH、-X\text{-X}-X
氧化反应 有机物失去氢或得到氧 C-H\text{C-H}C-H 或 C=C\text{C=C}C=C 被打破 -OH\text{-OH}-OH、-CHO\text{-CHO}-CHO、C=C\text{C=C}C=C
还原反应 有机物得到氢或失去氧 C=O\text{C=O}C=O 等接上 H\text{H}H -CHO\text{-CHO}-CHO、C=C\text{C=C}C=C、-NO2\text{-NO}_2-NO2​

详细讲解

一、取代反应

取代反应是有机物分子中的某个原子或原子团被其他原子或原子团替代的反应。产物中既有有机物也有小分子副产物。

（1）烃的卤代

甲烷与氯气在光照下发生自由基取代：

CH4+Cl2→光照CH3Cl+HCl\text{CH}_4 + \text{Cl}_2 \xrightarrow{\text{光照}} \text{CH}_3\text{Cl} + \text{HCl}CH4​+Cl2​光照​CH3​Cl+HCl

苯与液溴在催化剂下发生亲电取代：

C6H6+Br2→FeBr3C6H5Br+HBr\text{C}_6\text{H}_6 + \text{Br}_2 \xrightarrow{\text{FeBr}_3} \text{C}_6\text{H}_5\text{Br} + \text{HBr}C6​H6​+Br2​FeBr3​​C6​H5​Br+HBr

两者的区别：甲烷卤代需要光照引发自由基，产物为混合物；苯的卤代需要催化剂（路易斯酸），产物较单一。

（2）酯化反应（取代的一种）

CH3COOH+C2H5OH⇌浓H2SO4ΔCH3COOC2H5+H2O\text{CH}_3\text{COOH} + \text{C}_2\text{H}_5\text{OH} \underset{\Delta}{\overset{\text{浓H}_2\text{SO}_4}{\rightleftharpoons}} \text{CH}_3\text{COOC}_2\text{H}_5 + \text{H}_2\text{O}CH3​COOH+C2​H5​OHΔ⇌浓H2​SO4​​​CH3​COOC2​H5​+H2​O

酯化反应的脱水方式：羧酸脱去 -OH\text{-OH}-OH，醇脱去 -H\text{-H}-H（"酸脱羟基醇脱氢"）。这一机理通过同位素示踪实验（用 18O^{18}\text{O}18O 标记醇中的氧原子）得到证实。

（3）水解反应（取代的逆过程）

卤代烃的水解：

CH3CH2Br+NaOH→水溶液,ΔCH3CH2OH+NaBr\text{CH}_3\text{CH}_2\text{Br} + \text{NaOH} \xrightarrow{\text{水溶液}, \Delta} \text{CH}_3\text{CH}_2\text{OH} + \text{NaBr}CH3​CH2​Br+NaOH水溶液,Δ​CH3​CH2​OH+NaBr

酯的水解：

CH3COOC2H5+NaOH→ΔCH3COONa+C2H5OH\text{CH}_3\text{COOC}_2\text{H}_5 + \text{NaOH} \xrightarrow{\Delta} \text{CH}_3\text{COONa} + \text{C}_2\text{H}_5\text{OH}CH3​COOC2​H5​+NaOHΔ​CH3​COONa+C2​H5​OH

二、加成反应

加成反应是不饱和键（C=C\text{C=C}C=C、C≡C\text{C≡C}C≡C、C=O\text{C=O}C=O）的 π\piπ 键断裂，两端各与一个新原子或原子团结合的反应。

（1）烯烃的加成

乙烯与溴水：CH2=CH2+Br2→BrCH2CH2Br\text{CH}_2\text{=CH}_2 + \text{Br}_2 \to \text{BrCH}_2\text{CH}_2\text{Br}CH2​=CH2​+Br2​→BrCH2​CH2​Br

乙烯与水：CH2=CH2+H2O→催化剂CH3CH2OH\text{CH}_2\text{=CH}_2 + \text{H}_2\text{O} \xrightarrow{\text{催化剂}} \text{CH}_3\text{CH}_2\text{OH}CH2​=CH2​+H2​O催化剂​CH3​CH2​OH

乙烯与氢气：CH2=CH2+H2→NiCH3CH3\text{CH}_2\text{=CH}_2 + \text{H}_2 \xrightarrow{\text{Ni}} \text{CH}_3\text{CH}_3CH2​=CH2​+H2​Ni​CH3​CH3​

（2）醛的加成（亲核加成）

CH3CHO+H2→NiCH3CH2OH\text{CH}_3\text{CHO} + \text{H}_2 \xrightarrow{\text{Ni}} \text{CH}_3\text{CH}_2\text{OH}CH3​CHO+H2​Ni​CH3​CH2​OH

醛基中的 C=O\text{C=O}C=O 双键也能发生加成。碳原子带部分正电荷，容易接受亲核试剂的进攻。

（3）加成与取代的判断

判断一个反应是加成还是取代的关键：

  • 加成反应只有一种产物（原子全部进入同一分子）
  • 取代反应有两种产物（被替换的原子/基团形成副产物）

三、消去反应

消去反应是从一个分子中脱去一个小分子（H2O\text{H}_2\text{O}H2​O 或 HX\text{HX}HX），生成含不饱和键的化合物。

醇的消去（脱水）：

CH3CH2OH→170°C,浓H2SO4CH2=CH2+H2O\text{CH}_3\text{CH}_2\text{OH} \xrightarrow{170°\text{C}, \text{浓H}_2\text{SO}_4} \text{CH}_2\text{=CH}_2 + \text{H}_2\text{O}CH3​CH2​OH170°C,浓H2​SO4​​CH2​=CH2​+H2​O

卤代烃的消去（脱卤化氢）：

CH3CH2Br+NaOH→醇溶液,ΔCH2=CH2+NaBr+H2O\text{CH}_3\text{CH}_2\text{Br} + \text{NaOH} \xrightarrow{\text{醇溶液}, \Delta} \text{CH}_2\text{=CH}_2 + \text{NaBr} + \text{H}_2\text{O}CH3​CH2​Br+NaOH醇溶液,Δ​CH2​=CH2​+NaBr+H2​O

注意同一个卤代烃在不同条件下走不同路径：

条件 反应类型 产物
NaOH\text{NaOH}NaOH 水溶液加热 取代（水解） 醇
NaOH\text{NaOH}NaOH 醇溶液加热 消去 烯烃

消去反应的条件：与 -OH\text{-OH}-OH 或 -X\text{-X}-X 相邻的碳上必须有氢原子可供脱去。叔丁醇（(CH3)3COH\text{(CH}_3\text{)}_3\text{COH}(CH3​)3​COH）和氯甲烷（CH3Cl\text{CH}_3\text{Cl}CH3​Cl）的邻碳结构不同，消去行为也不同。

四、氧化反应与还原反应

有机物的氧化：

底物 氧化条件 产物 类型
醇（伯醇） Cu/O2\text{Cu}/\text{O}_2Cu/O2​，加热 醛 催化氧化
醛 银氨溶液 / Cu(OH)2\text{Cu(OH)}_2Cu(OH)2​ 羧酸（盐） 弱氧化
烯烃 酸性 KMnO4\text{KMnO}_4KMnO4​ 断裂产物 强氧化
甲苯侧链 酸性 KMnO4\text{KMnO}_4KMnO4​ 苯甲酸 侧链氧化
有机物燃烧 O2\text{O}_2O2​，点燃 CO2+H2O\text{CO}_2 + \text{H}_2\text{O}CO2​+H2​O 完全氧化

有机物的还原：

CH3CHO+H2→NiCH3CH2OH\text{CH}_3\text{CHO} + \text{H}_2 \xrightarrow{\text{Ni}} \text{CH}_3\text{CH}_2\text{OH}CH3​CHO+H2​Ni​CH3​CH2​OH
CH2=CH2+H2→NiCH3CH3\text{CH}_2\text{=CH}_2 + \text{H}_2 \xrightarrow{\text{Ni}} \text{CH}_3\text{CH}_3CH2​=CH2​+H2​Ni​CH3​CH3​
C6H5NO2+3H2→Fe/HClC6H5NH2+2H2O\text{C}_6\text{H}_5\text{NO}_2 + 3\text{H}_2 \xrightarrow{\text{Fe/HCl}} \text{C}_6\text{H}_5\text{NH}_2 + 2\text{H}_2\text{O}C6​H5​NO2​+3H2​Fe/HCl​C6​H5​NH2​+2H2​O

五、聚合反应

加聚反应：含不饱和键的单体通过加成方式连接成高分子。

nCH2=CH2→[−CH2-CH2−]n(聚乙烯)n\text{CH}_2\text{=CH}_2 \to [-\text{CH}_2\text{-CH}_2-]_n \quad (\text{聚乙烯})nCH2​=CH2​→[−CH2​-CH2​−]n​(聚乙烯)
nCH2=CHCl→[−CH2-CHCl−]n(聚氯乙烯)n\text{CH}_2\text{=CHCl} \to [-\text{CH}_2\text{-CHCl}-]_n \quad (\text{聚氯乙烯})nCH2​=CHCl→[−CH2​-CHCl−]n​(聚氯乙烯)

缩聚反应：含两个或以上官能团的单体之间脱去小分子（如 H2O\text{H}_2\text{O}H2​O）而聚合。

nHOOC-R-COOH+nHO-R’-OH→[−OC-R-COO-R’-O−]n+2nH2On\text{HOOC-R-COOH} + n\text{HO-R'-OH} \to [-\text{OC-R-COO-R'-O}-]_n + 2n\text{H}_2\text{O}nHOOC-R-COOH+nHO-R’-OH→[−OC-R-COO-R’-O−]n​+2nH2​O

加聚与缩聚的区别：加聚无副产物，高分子与单体元素组成相同；缩聚有小分子副产物脱出，高分子与单体组成不同。

六、有机合成路线设计

有机合成的关键是选择合适的反应路径，将简单原料转化为目标产物。设计合成路线的一般思路：

  1. 逆合成分析：从目标产物出发，分析需要哪些官能团转化
  2. 确定每步的反应类型和条件
  3. 选择合适的起始原料

拓展阅读
有机合成是化学中最具创造性的领域之一。2010 年诺贝尔化学奖授予赫克、根岸和铃木，表彰他们在钯催化交叉偶联反应方面的贡献——这类反应可以在温和条件下形成碳碳键，极大地拓展了有机合成的能力。


在制药工业中，一个药物分子的合成往往需要 10∼2010 \sim 2010∼20 步反应，每一步的反应类型、选择性和产率都经过精心设计。全合成（从最简单的原料出发合成复杂天然产物）被视为有机化学的最高艺术。


绿色化学强调反应的原子经济性——即反应物的原子尽可能多地转化为目标产物，减少副产物和废弃物。加成反应的原子经济性为 100%100\%100%（所有原子都进入产物），而取代和消去反应必然产生副产物，原子利用率较低。


小结
    

  • 取代反应特征：原子/基团被替换，产物为有机物 + 小分子
    • 

  • 加成反应特征：π\piπ 键断裂，只生成一种产物，原子经济性高
    • 

  • 消去反应特征：脱去小分子生成不饱和键，与加成互为逆过程
    • 

  • 卤代烃的反应条件决定反应类型：NaOH\text{NaOH}NaOH 水溶液 → 水解，NaOH\text{NaOH}NaOH 醇溶液 → 消去
    • 

  • 有机合成设计采用逆合成分析法，从目标产物逆推反应路线
