高三化学 — 元素化学

知识要点

元素化学是高考化学的基础板块，覆盖金属元素（Na、Al、Fe、Cu）和非金属元素（C、N、S、Cl、Si）的单质及其化合物的性质、制备和用途。高三复习阶段需要建立"物质→结构→性质→用途"的思维链条，将零散的知识点整合为系统的元素知识网络。

详细讲解

一、钠及其化合物

金属钠的性质：银白色、质软、密度比水小、熔点低。保存在煤油中（隔绝空气和水）。

钠与水反应：2Na+2H2O→2NaOH+H2↑2\text{Na} + 2\text{H}_2\text{O} \to 2\text{NaOH} + \text{H}_2\uparrow2Na+2H2​O→2NaOH+H2​↑

现象：浮在水面（密度小）、熔成小球（放热）、四处游动（生成气体）、发出嘶嘶声、溶液变红（加酚酞）。

过氧化钠 Na2O2\text{Na}_2\text{O}_2Na2​O2​——高考明星物质：

  • 淡黄色粉末，强氧化剂
  • 与水反应：2Na2O2+2H2O→4NaOH+O2↑2\text{Na}_2\text{O}_2 + 2\text{H}_2\text{O} \to 4\text{NaOH} + \text{O}_2\uparrow2Na2​O2​+2H2​O→4NaOH+O2​↑
  • 与 CO2\text{CO}_2CO2​ 反应：2Na2O2+2CO2→2Na2CO3+O22\text{Na}_2\text{O}_2 + 2\text{CO}_2 \to 2\text{Na}_2\text{CO}_3 + \text{O}_22Na2​O2​+2CO2​→2Na2​CO3​+O2​
  • 用于呼吸面具和潜水艇（吸收 CO2\text{CO}_2CO2​ 并释放 O2\text{O}_2O2​）

碳酸钠与碳酸氢钠的对比：

性质 Na2CO3\text{Na}_2\text{CO}_3Na2​CO3​（纯碱） NaHCO3\text{NaHCO}_3NaHCO3​（小苏打）
热稳定性 稳定，加热不分解 不稳定，2NaHCO3→ΔNa2CO3+H2O+CO2↑2\text{NaHCO}_3 \xrightarrow{\Delta} \text{Na}_2\text{CO}_3 + \text{H}_2\text{O} + \text{CO}_2\uparrow2NaHCO3​Δ​Na2​CO3​+H2​O+CO2​↑
与酸反应速率 较慢 较快（用于灭火器）
与 Ca(OH)2\text{Ca(OH)}_2Ca(OH)2​ 反应 生成 CaCO3\text{CaCO}_3CaCO3​ 沉淀 也生成 CaCO3\text{CaCO}_3CaCO3​ 沉淀
鉴别方法 加热后通入澄清石灰水（不变浑浊） 加热后通入澄清石灰水（变浑浊）

二、铝及其化合物——两性的典范

铝是典型的两性金属：既能与酸反应，又能与强碱反应。

Al+3HCl→AlCl3+32H2↑\text{Al} + 3\text{HCl} \to \text{AlCl}_3 + \frac{3}{2}\text{H}_2\uparrowAl+3HCl→AlCl3​+23​H2​↑
Al+NaOH+H2O→NaAlO2+32H2↑\text{Al} + \text{NaOH} + \text{H}_2\text{O} \to \text{NaAlO}_2 + \frac{3}{2}\text{H}_2\uparrowAl+NaOH+H2​O→NaAlO2​+23​H2​↑

氢氧化铝 Al(OH)3\text{Al(OH)}_3Al(OH)3​ 的制备：

最佳方案：Al3+\text{Al}^{3+}Al3+ 溶液中逐滴加入氨水（弱碱，不会溶解沉淀）。

AlCl3+3NH3⋅H2O→Al(OH)3↓+3NH4Cl\text{AlCl}_3 + 3\text{NH}_3·\text{H}_2\text{O} \to \text{Al(OH)}_3\downarrow + 3\text{NH}_4\text{Cl}AlCl3​+3NH3​⋅H2​O→Al(OH)3​↓+3NH4​Cl

不能用 NaOH\text{NaOH}NaOH，因为过量 NaOH\text{NaOH}NaOH 会溶解 Al(OH)3\text{Al(OH)}_3Al(OH)3​：

Al(OH)3+NaOH→NaAlO2+2H2O\text{Al(OH)}_3 + \text{NaOH} \to \text{NaAlO}_2 + 2\text{H}_2\text{O}Al(OH)3​+NaOH→NaAlO2​+2H2​O

三、铁及其化合物——氧化还原的桥梁

铁有两种常见价态：Fe2+\text{Fe}^{2+}Fe2+（亚铁离子，浅绿色）和 Fe3+\text{Fe}^{3+}Fe3+（铁离子，棕黄色）。

Fe2+\text{Fe}^{2+}Fe2+ 和 Fe3+\text{Fe}^{3+}Fe3+ 的相互转化：

Fe2+→氧化剂（如 Cl2、H2O2）Fe3+\text{Fe}^{2+} \xrightarrow{\text{氧化剂（如 Cl}_2\text{、H}_2\text{O}_2\text{）}} \text{Fe}^{3+}Fe2+氧化剂（如 Cl2​、H2​O2​）​Fe3+
Fe3+→还原剂（如 Fe、Cu）Fe2+\text{Fe}^{3+} \xrightarrow{\text{还原剂（如 Fe、Cu）}} \text{Fe}^{2+}Fe3+还原剂（如 Fe、Cu）​Fe2+

检验方法：

离子 检验试剂 现象
Fe3+\text{Fe}^{3+}Fe3+ KSCN\text{KSCN}KSCN 溶液 溶液变血红色
Fe2+\text{Fe}^{2+}Fe2+ 先加 KSCN\text{KSCN}KSCN（不变色），再加氯水（变红） 证明原有 Fe2+\text{Fe}^{2+}Fe2+
Fe2+\text{Fe}^{2+}Fe2+ NaOH\text{NaOH}NaOH 溶液 白色沉淀→灰绿色→红褐色

四、氮及其化合物

氮的氧化物：

NO\text{NO}NO 无色有毒气体，遇空气立即变为红棕色 NO2\text{NO}_2NO2​：2NO+O2→2NO22\text{NO} + \text{O}_2 \to 2\text{NO}_22NO+O2​→2NO2​

NO2\text{NO}_2NO2​ 红棕色有毒气体，溶于水生成硝酸：3NO2+H2O→2HNO3+NO3\text{NO}_2 + \text{H}_2\text{O} \to 2\text{HNO}_3 + \text{NO}3NO2​+H2​O→2HNO3​+NO

硝酸的氧化性：浓硝酸和稀硝酸都具有强氧化性，区别在于还原产物不同。

  • 浓 HNO3\text{HNO}_3HNO3​：还原产物为 NO2\text{NO}_2NO2​（红棕色气体）
  • 稀 HNO3\text{HNO}_3HNO3​：还原产物为 NO\text{NO}NO（无色气体，遇空气变红棕色）

铁与硝酸：铁遇浓硝酸常温下钝化（形成致密氧化膜），加热溶解。铁遇稀硝酸，少量铁生成 Fe3+\text{Fe}^{3+}Fe3+，过量铁生成 Fe2+\text{Fe}^{2+}Fe2+。

五、硫及其化合物

SO2\text{SO}_2SO2​ 的多重身份：

身份 反应实例
酸性氧化物 SO2+2NaOH→Na2SO3+H2O\text{SO}_2 + 2\text{NaOH} \to \text{Na}_2\text{SO}_3 + \text{H}_2\text{O}SO2​+2NaOH→Na2​SO3​+H2​O
还原剂 2SO2+O2→催化剂2SO32\text{SO}_2 + \text{O}_2 \xrightarrow{\text{催化剂}} 2\text{SO}_32SO2​+O2​催化剂​2SO3​
氧化剂 SO2+2H2S→3S↓+2H2O\text{SO}_2 + 2\text{H}_2\text{S} \to 3\text{S}\downarrow + 2\text{H}_2\text{O}SO2​+2H2​S→3S↓+2H2​O
漂白剂 使品红溶液褪色（加热后恢复红色）——与 Cl2\text{Cl}_2Cl2​ 漂白机理不同

浓硫酸的三大特性：吸水性（干燥剂）、脱水性（使蔗糖炭化变黑）、强氧化性（热的浓硫酸能氧化大多数金属和非金属）。

练习与思考

  1. 向含有 FeCl2\text{FeCl}_2FeCl2​ 和 FeCl3\text{FeCl}_3FeCl3​ 的混合溶液中，加入足量铁粉后过滤。滤液中含有的溶质是什么？滤渣中含有什么物质？

  2. 将 Na2O2\text{Na}_2\text{O}_2Na2​O2​ 粉末加入含酚酞的水中，观察到的现象是什么？先变红后褪色，请解释原因。

  3. 鉴别 Na2CO3\text{Na}_2\text{CO}_3Na2​CO3​ 溶液和 NaHCO3\text{NaHCO}_3NaHCO3​ 溶液，至少写出三种方法。

  4. SO2\text{SO}_2SO2​ 和 Cl2\text{Cl}_2Cl2​ 都能使品红溶液褪色。若将二者按体积比 1:11:11:1 混合后通入品红溶液中，品红是否褪色？为什么？

拓展阅读

元素化学的知识体系与元素周期律密切相关。门捷列夫在编制元素周期表时，正是根据元素性质的周期性变化规律来预测未知元素的存在和性质。如今，周期表中已有 118 种元素，其中最重的几种是在粒子加速器中人工合成的，存在时间仅以毫秒计。

工业生产中的元素化学应用无处不在：铝的冶炼（霍尔-埃鲁法电解 Al2O3\text{Al}_2\text{O}_3Al2​O3​）、钢铁的冶炼（高炉还原 Fe2O3\text{Fe}_2\text{O}_3Fe2​O3​）、合成氨（N2+3H2⇌2NH3\text{N}_2 + 3\text{H}_2 \rightleftharpoons 2\text{NH}_3N2​+3H2​⇌2NH3​）、硫酸的工业制法（接触法）——这些都是高考常考的工业流程题背景。

小结

元素化学复习的核心策略是"以元素为线索，以氧化还原为纽带"。钠的化合物重点掌握 Na2O2\text{Na}_2\text{O}_2Na2​O2​ 的强氧化性和 Na2CO3/NaHCO3\text{Na}_2\text{CO}_3/\text{NaHCO}_3Na2​CO3​/NaHCO3​ 的对比；铝的化合物突出两性特征；铁的化合物围绕 Fe2+/Fe3+\text{Fe}^{2+}/\text{Fe}^{3+}Fe2+/Fe3+ 转化展开；非金属部分重点是氮的氧化物和硫的化合物的多重性质。建立每种物质的"性质卡片"，反复对比和联想，是高效记忆的关键。
