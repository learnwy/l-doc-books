高三化学 — 溶液平衡

知识要点

溶液平衡是高考化学的核心难点，涵盖电离平衡、水的电离、盐类水解和沉淀溶解平衡四大板块。这些知识在高考中以选择题和综合题的形式高频出现，尤其是图像分析和定量计算。高三复习需要将四种平衡统一到"动态平衡"的框架下理解。

四大平衡对比：

平衡类型 实质 平衡常数 影响因素
弱电解质电离 弱酸/弱碱的部分电离 KaK_aKa​（酸）、KbK_bKb​（碱） 温度、浓度
水的电离 H2O⇌H++OH−\text{H}_2\text{O} \rightleftharpoons \text{H}^+ + \text{OH}^-H2​O⇌H++OH− Kw=10−14K_w = 10^{-14}Kw​=10−14（25°C25°\text{C}25°C） 温度
盐类水解 弱酸阴离子/弱碱阳离子与水反应 Kh=KwKaK_h = \frac{K_w}{K_a}Kh​=Ka​Kw​​ 或 KwKb\frac{K_w}{K_b}Kb​Kw​​ 温度、浓度
沉淀溶解 难溶盐的溶解与沉淀动态平衡 KspK_{sp}Ksp​ 温度

详细讲解

一、弱电解质的电离平衡

弱酸 HA\text{HA}HA 在水溶液中的电离：

HA⇌H++A−\text{HA} \rightleftharpoons \text{H}^+ + \text{A}^-HA⇌H++A−

电离常数：Ka=c(H+)⋅c(A−)c(HA)K_a = \frac{c(\text{H}^+) \cdot c(\text{A}^-)}{c(\text{HA})}Ka​=c(HA)c(H+)⋅c(A−)​

KaK_aKa​ 只与温度有关，与浓度无关。KaK_aKa​ 越大，酸性越强。

多元弱酸的分步电离：以 H2CO3\text{H}_2\text{CO}_3H2​CO3​ 为例

H2CO3⇌H++HCO3−Ka1=4.3×10−7\text{H}_2\text{CO}_3 \rightleftharpoons \text{H}^+ + \text{HCO}_3^- \quad K_{a1} = 4.3 \times 10^{-7}H2​CO3​⇌H++HCO3−​Ka1​=4.3×10−7
HCO3−⇌H++CO32−Ka2=5.6×10−11\text{HCO}_3^- \rightleftharpoons \text{H}^+ + \text{CO}_3^{2-} \quad K_{a2} = 5.6 \times 10^{-11}HCO3−​⇌H++CO32−​Ka2​=5.6×10−11

第一步电离远大于第二步（Ka1≫Ka2K_{a1} \gg K_{a2}Ka1​≫Ka2​），溶液 pH\text{pH}pH 主要由第一步决定。

电离度：α=已电离的弱电解质浓度初始浓度×100%\alpha = \frac{\text{已电离的弱电解质浓度}}{\text{初始浓度}} \times 100\%α=初始浓度已电离的弱电解质浓度​×100%

稀释弱电解质溶液：KaK_aKa​ 不变，α\alphaα 增大，c(H+)c(\text{H}^+)c(H+) 减小。

二、水的电离与 pH

水的离子积：Kw=c(H+)⋅c(OH−)=10−14K_w = c(\text{H}^+) \cdot c(\text{OH}^-) = 10^{-14}Kw​=c(H+)⋅c(OH−)=10−14（25°C25°\text{C}25°C）

KwK_wKw​ 只与温度有关。温度升高，KwK_wKw​ 增大（水的电离是吸热过程）。

pH 的定义：pH=−lg⁡c(H+)\text{pH} = -\lg c(\text{H}^+)pH=−lgc(H+)

溶液类型 c(H+)c(\text{H}^+)c(H+) 与 c(OH−)c(\text{OH}^-)c(OH−) 的关系 pH 范围
酸性 c(H+)>c(OH−)c(\text{H}^+) > c(\text{OH}^-)c(H+)>c(OH−) pH<7\text{pH} < 7pH<7
中性 c(H+)=c(OH−)c(\text{H}^+) = c(\text{OH}^-)c(H+)=c(OH−) pH=7\text{pH} = 7pH=7
碱性 c(H+)<c(OH−)c(\text{H}^+) < c(\text{OH}^-)c(H+)<c(OH−) pH>7\text{pH} > 7pH>7

酸碱混合后 pH 的计算：

强酸 + 强碱：先计算 H+\text{H}^+H+ 和 OH−\text{OH}^-OH− 的物质的量，多余的决定溶液酸碱性。

强酸 + 弱碱（或弱酸 + 强碱）：需要考虑盐类水解的影响。

三、盐类水解

水解的本质：盐中的弱酸阴离子或弱碱阳离子与水电离产生的 H+\text{H}^+H+ 或 OH−\text{OH}^-OH− 结合，破坏水的电离平衡，促进水的电离。

CH3COO−+H2O⇌CH3COOH+OH−(碱性)\text{CH}_3\text{COO}^- + \text{H}_2\text{O} \rightleftharpoons \text{CH}_3\text{COOH} + \text{OH}^- \quad (\text{碱性})CH3​COO−+H2​O⇌CH3​COOH+OH−(碱性)
NH4++H2O⇌NH3⋅H2O+H+(酸性)\text{NH}_4^+ + \text{H}_2\text{O} \rightleftharpoons \text{NH}_3·\text{H}_2\text{O} + \text{H}^+ \quad (\text{酸性})NH4+​+H2​O⇌NH3​⋅H2​O+H+(酸性)

水解规律口诀："有弱才水解，无弱不水解；谁弱谁水解，谁强显谁性。"

盐的类型 水解情况 溶液酸碱性 实例
强酸强碱盐 不水解 中性 NaCl\text{NaCl}NaCl
强酸弱碱盐 阳离子水解 酸性 NH4Cl\text{NH}_4\text{Cl}NH4​Cl
弱酸强碱盐 阴离子水解 碱性 CH3COONa\text{CH}_3\text{COONa}CH3​COONa
弱酸弱碱盐 双水解 取决于 KaK_aKa​ 和 KbK_bKb​ CH3COONH4\text{CH}_3\text{COONH}_4CH3​COONH4​

影响水解程度的因素：

  • 温度升高→水解程度增大（水解是吸热过程）
  • 稀释→水解程度增大
  • 加酸/碱→抑制/促进水解

四、沉淀溶解平衡

难溶电解质在水中存在溶解平衡：

AgCl(s)⇌Ag+(aq)+Cl−(aq)\text{AgCl}(\text{s}) \rightleftharpoons \text{Ag}^+(\text{aq}) + \text{Cl}^-(\text{aq})AgCl(s)⇌Ag+(aq)+Cl−(aq)
Ksp=c(Ag+)⋅c(Cl−)K_{sp} = c(\text{Ag}^+) \cdot c(\text{Cl}^-)Ksp​=c(Ag+)⋅c(Cl−)

KspK_{sp}Ksp​ 的应用：

应用 原理
判断是否有沉淀生成 计算离子积 QQQ：Q>KspQ > K_{sp}Q>Ksp​ 生成沉淀；Q<KspQ < K_{sp}Q<Ksp​ 不生成
沉淀的溶解 减小某离子浓度（加酸溶解、配位溶解）→ Q<KspQ < K_{sp}Q<Ksp​ → 沉淀溶解
沉淀的转化 将 KspK_{sp}Ksp​ 大的沉淀转化为 KspK_{sp}Ksp​ 小的沉淀

沉淀转化的条件：KspK_{sp}Ksp​ 小的沉淀更稳定，可以通过加入含目标离子的溶液实现转化。

例：AgCl+I−→AgI+Cl−\text{AgCl} + \text{I}^- \to \text{AgI} + \text{Cl}^-AgCl+I−→AgI+Cl−（Ksp(AgI)≪Ksp(AgCl)K_{sp}(\text{AgI}) \ll K_{sp}(\text{AgCl})Ksp​(AgI)≪Ksp​(AgCl)）

五、溶液中的守恒关系

电荷守恒：溶液中所有阳离子的正电荷总量等于所有阴离子的负电荷总量。

以 Na2CO3\text{Na}_2\text{CO}_3Na2​CO3​ 溶液为例：

c(Na+)+c(H+)=2c(CO32−)+c(HCO3−)+c(OH−)c(\text{Na}^+) + c(\text{H}^+) = 2c(\text{CO}_3^{2-}) + c(\text{HCO}_3^-) + c(\text{OH}^-)c(Na+)+c(H+)=2c(CO32−​)+c(HCO3−​)+c(OH−)

物料守恒：溶液中某元素的总浓度不变（无论以何种形态存在）。

c(Na+)=2[c(CO32−)+c(HCO3−)+c(H2CO3)]c(\text{Na}^+) = 2[c(\text{CO}_3^{2-}) + c(\text{HCO}_3^-) + c(\text{H}_2\text{CO}_3)]c(Na+)=2[c(CO32−​)+c(HCO3−​)+c(H2​CO3​)]

质子守恒：水电离出的 H+\text{H}^+H+ 总量等于 OH−\text{OH}^-OH− 总量（由电荷守恒和物料守恒推导）。

c(OH−)+c(HCO3−)+2c(H2CO3)=c(H+)c(\text{OH}^-) + c(\text{HCO}_3^-) + 2c(\text{H}_2\text{CO}_3) = c(\text{H}^+)c(OH−)+c(HCO3−​)+2c(H2​CO3​)=c(H+)

（注意：这里需要考虑 Na2CO3\text{Na}_2\text{CO}_3Na2​CO3​ 溶液呈碱性，c(OH−)>c(H+)c(\text{OH}^-) > c(\text{H}^+)c(OH−)>c(H+)）

六、图像分析

高考常以滴定曲线、分布系数图等形式考查溶液平衡。

酸碱滴定曲线的关键点：

  • 起始点：看初始溶液的 pH\text{pH}pH
  • 半中和点（弱酸被中和一半）：pH=pKa\text{pH} = \text{p}K_apH=pKa​
  • 恰好完全中和点：根据盐的水解判断 pH\text{pH}pH
  • 突跃区：pH\text{pH}pH 急剧变化的区域，用于选择指示剂

练习与思考

  1. 在 25°C25°\text{C}25°C 下，0.1  mol/L0.1\;\text{mol/L}0.1mol/L 的 CH3COOH\text{CH}_3\text{COOH}CH3​COOH 溶液的 pH=2.88\text{pH} = 2.88pH=2.88。计算醋酸的电离常数 KaK_aKa​ 和电离度 α\alphaα。

  2. 比较等浓度的 Na2CO3\text{Na}_2\text{CO}_3Na2​CO3​、NaHCO3\text{NaHCO}_3NaHCO3​、NaCl\text{NaCl}NaCl、NH4Cl\text{NH}_4\text{Cl}NH4​Cl 四种溶液的 pH\text{pH}pH 大小，并说明理由。

  3. 向 AgNO3\text{AgNO}_3AgNO3​ 溶液中逐滴加入 NaCl\text{NaCl}NaCl 溶液直至过量。画出 c(Ag+)c(\text{Ag}^+)c(Ag+) 随加入 NaCl\text{NaCl}NaCl 体积变化的曲线，并标注关键点。

  4. 写出 0.1  mol/L0.1\;\text{mol/L}0.1mol/L Na2CO3\text{Na}_2\text{CO}_3Na2​CO3​ 溶液中所有离子浓度的大小排序，并利用三大守恒关系验证。

拓展阅读

溶液化学在环境科学和生命科学中有广泛应用。酸雨的形成涉及 SO2\text{SO}_2SO2​ 和 NO2\text{NO}_2NO2​ 溶于水后的电离平衡；血液的 pH\text{pH}pH 维持在 7.357.357.35-7.457.457.45 的狭窄范围内，依赖碳酸-碳酸氢根缓冲体系；水处理厂利用沉淀溶解平衡去除重金属离子。

缓冲溶液是溶液平衡的精彩应用。由弱酸及其共轭碱（或弱碱及其共轭酸）组成的溶液，在加入少量强酸或强碱后 pH\text{pH}pH 变化极小。这一原理在医学（输液配制）、生物实验（酶活性测定）和工业生产（电镀液维护）中不可或缺。

小结

溶液平衡的复习以四大平衡为框架，以三大守恒（电荷守恒、物料守恒、质子守恒）为计算工具，以图像分析为高考载体。弱电解质的电离常数 KaK_aKa​ 和水的离子积 KwK_wKw​ 是两个核心常数。盐类水解的本质是"弱离子与水反应"，水解程度受温度和浓度影响。沉淀溶解平衡用 KspK_{sp}Ksp​ 定量描述，应用于沉淀的生成、溶解和转化。
