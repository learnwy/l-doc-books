高三化学 — 有机合成路线

知识要点

有机合成路线设计是高考化学选考模块（有机化学基础）的压轴考点，要求考生根据目标产物逆向推导原料和反应路径。掌握官能团的引入、转化和保护方法，是解决合成题的核心能力。高三复习阶段需要系统梳理各类有机反应的条件和产物，建立"官能团转化网络"。

高考常考有机反应类型：

反应类型 典型条件 功能
取代反应 光照/催化剂/浓 H2SO4\text{H}_2\text{SO}_4H2​SO4​ 用一个原子或基团替换另一个
加成反应 催化剂/高温高压 双键或三键打开，加上新的原子或基团
消去反应 醇 + 浓 H2SO4\text{H}_2\text{SO}_4H2​SO4​，170°C170°\text{C}170°C 脱去小分子（H2O\text{H}_2\text{O}H2​O、HX\text{HX}HX），形成双键
氧化反应 酸性 KMnO4\text{KMnO}_4KMnO4​/催化氧化 引入含氧官能团或增加氧的含量
还原反应 H2\text{H}_2H2​/催化剂 双键加氢、醛基还原为羟基
酯化反应 浓 H2SO4\text{H}_2\text{SO}_4H2​SO4​，加热 醇 + 酸→酯 + 水
水解反应 酸/碱催化 酯→醇 + 酸/盐

详细讲解

一、官能团转化网络

有机合成的本质是官能团的相互转化。以下是高考范围内最重要的转化路径：

碳碳双键（C=C\text{C=C}C=C）的引入与去除：

  • 引入双键：醇的消去反应（浓 H2SO4\text{H}_2\text{SO}_4H2​SO4​，170°C170°\text{C}170°C）
  • 去除双键：加氢（H2\text{H}_2H2​/催化剂）、加卤素（Br2\text{Br}_2Br2​）、加水（稀 H2SO4\text{H}_2\text{SO}_4H2​SO4​）

卤素原子（-X\text{-X}-X）的引入：

  • 烷烃 + Cl2\text{Cl}_2Cl2​（光照）→ 一氯代物
  • 烯烃 + HBr\text{HBr}HBr → 溴代烃（马氏规则）
  • 烯烃 + Br2\text{Br}_2Br2​ → 二溴代物
  • 醇 + HBr\text{HBr}HBr → 溴代烃 + H2O\text{H}_2\text{O}H2​O

羟基（-OH\text{-OH}-OH）的引入：

  • 卤代烃 + NaOH\text{NaOH}NaOH（水溶液，加热）→ 醇
  • 烯烃 + H2O\text{H}_2\text{O}H2​O（稀 H2SO4\text{H}_2\text{SO}_4H2​SO4​）→ 醇
  • 醛 + H2\text{H}_2H2​（催化剂）→ 醇
  • 酯 + NaOH\text{NaOH}NaOH（水溶液）→ 醇 + 羧酸钠

醛基（-CHO\text{-CHO}-CHO）的引入：

  • 伯醇的催化氧化：R-CH2OH→Cu/ΔR-CHO\text{R-CH}_2\text{OH} \xrightarrow{\text{Cu}/\Delta} \text{R-CHO}R-CH2​OHCu/Δ​R-CHO
  • 烯烃的臭氧化裂解（了解即可）

羧基（-COOH\text{-COOH}-COOH）的引入：

  • 醛的氧化：R-CHO→O2/催化剂R-COOH\text{R-CHO} \xrightarrow{\text{O}_2/\text{催化剂}} \text{R-COOH}R-CHOO2​/催化剂​R-COOH
  • 酯的水解：酸性或碱性条件

二、常见合成路线模板

模板一：烯烃→醇→醛→羧酸

CH2=CH2→H2O/H+CH3CH2OH→Cu/ΔCH3CHO→O2/催化剂CH3COOH\text{CH}_2\text{=CH}_2 \xrightarrow{\text{H}_2\text{O}/\text{H}^+} \text{CH}_3\text{CH}_2\text{OH} \xrightarrow{\text{Cu}/\Delta} \text{CH}_3\text{CHO} \xrightarrow{\text{O}_2/\text{催化剂}} \text{CH}_3\text{COOH}CH2​=CH2​H2​O/H+​CH3​CH2​OHCu/Δ​CH3​CHOO2​/催化剂​CH3​COOH

模板二：卤代烃→醇→烯烃

CH3CH2Br→NaOH(aq)/ΔCH3CH2OH→浓H2SO4,170°CCH2=CH2\text{CH}_3\text{CH}_2\text{Br} \xrightarrow{\text{NaOH(aq)}/\Delta} \text{CH}_3\text{CH}_2\text{OH} \xrightarrow{\text{浓H}_2\text{SO}_4, 170°\text{C}} \text{CH}_2\text{=CH}_2CH3​CH2​BrNaOH(aq)/Δ​CH3​CH2​OH浓H2​SO4​,170°C​CH2​=CH2​

模板三：增长碳链

利用格氏试剂或羟醛缩合反应增长碳链（高考通常给出提示信息）。

模板四：成环反应

二元醇和二元酸的缩聚反应可以形成环酯，分子内脱水也可成环。

三、逆合成分析法

逆合成分析（逆向推导）是设计合成路线的标准方法：

  1. 写出目标分子的结构
  2. 找出目标分子中的关键官能团
  3. 问自己："这个官能团是从什么前体通过什么反应得来的？"
  4. 将前体作为新的目标，重复步骤 2-3
  5. 直到回溯到简单的原料（烯烃、醇、苯等）

四、合成路线中的条件辨析

高考特别考查反应条件的细节差异：

反应 条件 产物
乙醇脱水 浓 H2SO4\text{H}_2\text{SO}_4H2​SO4​，170°C170°\text{C}170°C 乙烯（消去）
乙醇脱水 浓 H2SO4\text{H}_2\text{SO}_4H2​SO4​，140°C140°\text{C}140°C 乙醚（分子间脱水）
卤代烃 + NaOH\text{NaOH}NaOH 水溶液，加热 醇（水解）
卤代烃 + NaOH\text{NaOH}NaOH 醇溶液，加热 烯烃（消去）
苯 + Br2\text{Br}_2Br2​ FeBr3\text{FeBr}_3FeBr3​ 催化 溴苯（取代）
烯烃 + Br2\text{Br}_2Br2​ 直接反应（Br2\text{Br}_2Br2​ 的 CCl4\text{CCl}_4CCl4​ 溶液） 二溴代物（加成）

五、高考有机合成题的解题策略

  1. 读信息：题目通常提供 1-2 个新反应（信息迁移），先理解新反应的实质
  2. 找官能团变化：比较每步反应前后的分子结构，标注变化的官能团
  3. 补充条件和试剂：根据官能团变化确定反应类型，填写条件和试剂
  4. 写反应方程式：注意有机物的结构简式书写规范
  5. 设计路线题：用逆合成分析法，从目标出发倒推

练习与思考

  1. 由乙烯为原料合成乙酸乙酯，写出合成路线（用反应流程图表示，标注每步的条件和试剂）。

  2. 以下转化中，判断每步反应的类型： CH3CH2Cl→①CH3CH2OH→②CH2=CH2→③CH2BrCHBr\text{CH}_3\text{CH}_2\text{Cl} \xrightarrow{①} \text{CH}_3\text{CH}_2\text{OH} \xrightarrow{②} \text{CH}_2\text{=CH}_2 \xrightarrow{③} \text{CH}_2\text{BrCHBr}CH3​CH2​Cl①​CH3​CH2​OH②​CH2​=CH2​③​CH2​BrCHBr

  3. 已知信息：R-CHO+CH3CHO→NaOHR-CH=CH-CHO+H2O\text{R-CHO} + \text{CH}_3\text{CHO} \xrightarrow{\text{NaOH}} \text{R-CH=CH-CHO} + \text{H}_2\text{O}R-CHO+CH3​CHONaOH​R-CH=CH-CHO+H2​O（羟醛缩合）。利用该反应，从乙醛出发合成 CH3CH=CHCHO\text{CH}_3\text{CH=CHCHO}CH3​CH=CHCHO。

  4. 某有机物 A 的分子式为 C4H8O2\text{C}_4\text{H}_8\text{O}_2C4​H8​O2​，A 能与 NaOH\text{NaOH}NaOH 溶液反应，水解后生成的一种产物能发生银镜反应。推断 A 的结构简式。

拓展阅读

有机合成是制药、材料和精细化工的核心技术。2010 年诺贝尔化学奖授予赫克、根岸和铃木三位化学家，表彰他们在钯催化交叉偶联反应方面的贡献——这种反应能高效地形成碳碳键，极大拓展了有机合成的可能性。

高考有机合成题的难度逐年提升，信息迁移能力成为区分高低分的关键。建议复习时不仅要背熟官能团转化网络，还要多练习"读懂新反应→应用到合成路线"的能力。

小结

有机合成路线的复习核心是"官能团转化网络"——掌握每种官能团的引入、转化和去除方法，以及对应的反应条件。解题时使用逆合成分析法，从目标产物倒推到简单原料。注意区分相似反应的不同条件（如卤代烃在水溶液和醇溶液中与 NaOH\text{NaOH}NaOH 反应的区别）。高考题通常提供新反应信息，关键是理解反应实质后灵活应用。
