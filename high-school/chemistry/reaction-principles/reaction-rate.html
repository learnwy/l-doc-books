高二化学 — 反应速率

知识要点

化学反应的快慢直接决定了工业生产的效率和日常生活中的化学现象。反应速率研究的核心问题是：反应有多快？哪些因素能改变这个速率？如何从微观碰撞的角度理解宏观的速率变化？

概念 定义 表达式
化学反应速率 单位时间内反应物或生成物浓度的变化量 v=ΔcΔtv = \dfrac{\Delta c}{\Delta t}v=ΔtΔc​
瞬时速率 某一时刻的反应速率 v=dcdtv = \dfrac{dc}{dt}v=dtdc​
平均速率 一段时间内的平均反应快慢 v=c2−c1t2−t1v = \dfrac{c_2 - c_1}{t_2 - t_1}v=t2​−t1​c2​−c1​​
速率常数 反映反应固有快慢的常数 kkk（与温度有关）
活化能 反应发生所需的最低能量 EaE_aEa​（kJ/mol\text{kJ/mol}kJ/mol）

详细讲解

一、反应速率的表示方法

对于反应 aA+bB→cC+dDa\text{A} + b\text{B} \to c\text{C} + d\text{D}aA+bB→cC+dD，各物质的反应速率之间存在固定比例关系：

v(A)a=v(B)b=v(C)c=v(D)d\frac{v(\text{A})}{a} = \frac{v(\text{B})}{b} = \frac{v(\text{C})}{c} = \frac{v(\text{D})}{d}av(A)​=bv(B)​=cv(C)​=dv(D)​

例如反应 2SO2(g)+O2(g)→2SO3(g)2\text{SO}_2(g) + \text{O}_2(g) \to 2\text{SO}_3(g)2SO2​(g)+O2​(g)→2SO3​(g)，若 v(O2)=0.1 mol/(L⋅s)v(\text{O}_2) = 0.1\,\text{mol/(L·s)}v(O2​)=0.1mol/(L⋅s)，则：

v(SO2)=2×0.1=0.2 mol/(L⋅s)v(\text{SO}_2) = 2 \times 0.1 = 0.2\,\text{mol/(L·s)}v(SO2​)=2×0.1=0.2mol/(L⋅s)
v(SO3)=2×0.1=0.2 mol/(L⋅s)v(\text{SO}_3) = 2 \times 0.1 = 0.2\,\text{mol/(L·s)}v(SO3​)=2×0.1=0.2mol/(L⋅s)

注意：反应速率通常取正值，无论是反应物（浓度减小）还是生成物（浓度增大）。

二、碰撞理论与活化能

反应的发生需要满足两个条件：

  1. 有效碰撞：分子必须以足够的能量碰撞
  2. 正确取向：碰撞时分子的空间方向必须合适

只有能量超过活化能 EaE_aEa​ 的分子（称为活化分子）发生的取向正确的碰撞才能引发反应。在一定温度下，分子的能量分布服从麦克斯韦-玻尔兹曼分布。

活化分子占总分子的比例与温度关系：

活化分子比例∝e−Ea/(RT)\text{活化分子比例} \propto e^{-E_a/(RT)}活化分子比例∝e−Ea​/(RT)

其中 R=8.314 J/(mol⋅K)R = 8.314\,\text{J/(mol·K)}R=8.314J/(mol⋅K) 为气体常数，TTT 为热力学温度。温度越高或 EaE_aEa​ 越低，活化分子比例越大，反应速率越快。

三、影响反应速率的因素

（1）浓度的影响

增大反应物浓度 → 单位体积内分子数增多 → 有效碰撞频率增大 → 反应速率加快。

对于气相反应，增大压强等效于增大浓度（体积缩小）。但需注意：加入惰性气体若保持体积不变，各物质浓度不变，速率不变。

（2）温度的影响

温度升高 → 分子平均动能增大 → 活化分子比例显著增加 → 速率加快。

经验规律：温度每升高 10 K10\,\text{K}10K，反应速率大约增大 2∼42 \sim 42∼4 倍。阿伦尼乌斯方程给出更精确的描述：

k=A⋅e−Ea/(RT)k = A \cdot e^{-E_a/(RT)}k=A⋅e−Ea​/(RT)

其中 AAA 为指前因子（频率因子），kkk 为速率常数。

两个温度下速率常数的关系：

ln⁡k2k1=EaR(1T1−1T2)\ln\frac{k_2}{k_1} = \frac{E_a}{R}\left(\frac{1}{T_1} - \frac{1}{T_2}\right)lnk1​k2​​=REa​​(T1​1​−T2​1​)

（3）催化剂的影响

催化剂通过提供一条新的反应路径来降低活化能 EaE_aEa​，使更多分子成为活化分子，从而加快反应速率。催化剂在反应前后质量和化学性质不变。

类型 特点 举例
均相催化 催化剂与反应物处于同一相 NO\text{NO}NO 催化 SO2\text{SO}_2SO2​ 氧化
多相催化 催化剂与反应物不同相 Fe\text{Fe}Fe 催化合成氨
酶催化 生物催化剂，高效且专一 淀粉酶催化淀粉水解

（4）其他因素

  • 固体反应物的颗粒大小：研磨成粉末增大接触面积
  • 光照：引发某些光化学反应（如 H2+Cl2\text{H}_2 + \text{Cl}_2H2​+Cl2​ 混合气爆炸）
  • 溶剂：影响溶液中离子或分子的活性

四、速率方程与反应级数

对于基元反应 aA+bB→Productsa\text{A} + b\text{B} \to \text{Products}aA+bB→Products，速率方程为：

v=k[A]a[B]bv = k[\text{A}]^a[\text{B}]^bv=k[A]a[B]b

反应级数 n=a+bn = a + bn=a+b，它决定了浓度对速率的影响程度。

  • 零级反应：v=kv = kv=k，速率与浓度无关
  • 一级反应：v=k[A]v = k[\text{A}]v=k[A]，浓度减半时间固定（半衰期 t1/2=ln⁡2kt_{1/2} = \dfrac{\ln 2}{k}t1/2​=kln2​）
  • 二级反应：v=k[A]2v = k[\text{A}]^2v=k[A]2，速率随浓度平方变化

非基元反应的速率方程由实验确定，指数不一定等于化学计量数。

五、实验测定方法

方法 适用场景 原理
量气法 产生气体的反应 收集气体体积随时间变化
比色法 有颜色变化的反应 溶液颜色深浅与浓度成正比
电导率法 离子浓度变化的反应 溶液导电性随离子浓度变化
滴定法 取样后用标准液滴定 定量分析反应物剩余量

拓展阅读

反应速率的研究在工业上意义重大。合成氨工艺中，哈伯选择铁基催化剂、400∼500 °C400 \sim 500\,°\text{C}400∼500°C 的反应温度和 200∼300 atm200 \sim 300\,\text{atm}200∼300atm 的高压，正是在反应速率与平衡转化率之间寻找最优平衡点的结果。

现代化学动力学还发展出过渡态理论和分子反应动力学。1986年诺贝尔化学奖授予了李远哲等人，表彰他们用交叉分子束方法直接观察化学反应中分子碰撞的微观过程，这是人类第一次"看到"化学反应是如何发生的。

生物体内的酶是自然界最高效的催化剂，碳酸酐酶每秒可催化约 10610^6106 个 CO2\text{CO}_2CO2​ 分子的水合反应，这一效率远超任何人工催化剂。

小结

  • 反应速率用单位时间内浓度变化量表示，各物质速率之比等于化学计量数之比
  • 碰撞理论解释了反应发生需要有效碰撞和正确取向两个条件
  • 浓度、温度、催化剂、接触面积是影响反应速率的四大因素
  • 催化剂通过降低活化能加快反应速率，但不改变反应焓变和平衡位置
  • 速率方程 v=k[A]m[B]nv = k[\text{A}]^m[\text{B}]^nv=k[A]m[B]n 中的指数由实验确定，反应级数 =m+n= m + n=m+n
