高二化学 — 化学平衡

知识要点

许多化学反应并不会进行到底，而是在正反应速率等于逆反应速率时达到一种动态的平衡状态。化学平衡是可逆反应的核心概念，理解平衡常数、平衡移动规律以及转化率的计算，对于分析工业生产条件和解决实际化学问题至关重要。

概念 定义 关键特征
可逆反应 在相同条件下正反两个方向都能进行的反应 双箭头 ⇌\rightleftharpoons⇌
化学平衡状态 正反应速率等于逆反应速率时的状态 v正=v逆v_{\text{正}} = v_{\text{逆}}v正​=v逆​
平衡常数 KKK 平衡时产物浓度幂之积与反应物浓度幂之积的比值 只与温度有关
转化率 已转化的反应物占初始量的百分比 α=n转化n初始×100%\alpha = \dfrac{n_{\text{转化}}}{n_{\text{初始}}} \times 100\%α=n初始​n转化​​×100%

详细讲解

一、化学平衡状态的建立

以合成氨反应 N2(g)+3H2(g)⇌2NH3(g)\text{N}_2(g) + 3\text{H}_2(g) \rightleftharpoons 2\text{NH}_3(g)N2​(g)+3H2​(g)⇌2NH3​(g) 为例。反应开始时只有 N2\text{N}_2N2​ 和 H2\text{H}_2H2​，正反应速率最大，逆反应速率为零。随着反应进行，反应物浓度降低、生成物浓度增大，正反应速率逐渐减小、逆反应速率逐渐增大，直到两者相等时达到平衡。

化学平衡的五个特征（可概括为"逆、等、动、定、变"）：

  • 逆：研究对象必须是可逆反应
  • 等：v正=v逆≠0v_{\text{正}} = v_{\text{逆}} \neq 0v正​=v逆​=0
  • 动：平衡是动态的，正逆反应仍在进行
  • 定：各组分浓度、百分含量保持不变
  • 变：条件改变时平衡会移动

判断是否达到平衡状态的常用标志：

标志类型 说明 能否判断平衡
各物质浓度不变 直接标志 ✓
各物质百分含量不变 直接标志 ✓
总压不变（气体分子数变化的反应） 间接标志 ✓
混合气体密度不变（特定条件） 需具体分析 视情况而定
混合气体平均摩尔质量不变 气体分子数变化时有效 视情况而定
v正=v逆v_{\text{正}} = v_{\text{逆}}v正​=v逆​（同种物质） 直接标志 ✓

二、平衡常数

对于一般反应 aA(g)+bB(g)⇌cC(g)+dD(g)a\text{A}(g) + b\text{B}(g) \rightleftharpoons c\text{C}(g) + d\text{D}(g)aA(g)+bB(g)⇌cC(g)+dD(g)，浓度平衡常数为：

Kc=[C]c⋅[D]d[A]a⋅[B]bK_c = \frac{[\text{C}]^c \cdot [\text{D}]^d}{[\text{A}]^a \cdot [\text{B}]^b}Kc​=[A]a⋅[B]b[C]c⋅[D]d​

平衡常数的重要性质：

  1. KKK 只与温度有关，与初始浓度、催化剂无关
  2. KKK 越大，正反应进行的程度越大（产物越多）
  3. 逆反应的平衡常数 K′=1KK' = \dfrac{1}{K}K′=K1​
  4. 方程式系数翻倍时，KKK 变为原来的平方
  5. 纯固体和纯液体不写入 KKK 的表达式

例如 CaCO3(s)⇌CaO(s)+CO2(g)\text{CaCO}_3(s) \rightleftharpoons \text{CaO}(s) + \text{CO}_2(g)CaCO3​(s)⇌CaO(s)+CO2​(g) 的平衡常数为 K=[CO2]K = [\text{CO}_2]K=[CO2​]。

反应商 QQQ 与 KKK 的比较可判断反应进行方向：

比较 反应方向
Q<KQ < KQ<K 正向移动
Q=KQ = KQ=K 已达平衡
Q>KQ > KQ>K 逆向移动

三、勒夏特列原理（平衡移动）

当改变影响平衡的条件之一时，平衡会向着减弱该改变的方向移动。

（1）浓度变化

  • 增大反应物浓度 → 平衡正向移动
  • 增大生成物浓度 → 平衡逆向移动
  • 减小反应物浓度 → 平衡逆向移动

（2）压强变化（气体反应）

  • 增大压强（缩小体积） → 平衡向气体分子数减小的方向移动
  • 减小压强（增大体积） → 平衡向气体分子数增大的方向移动
  • 若反应前后气体分子数不变（如 H2+I2⇌2HI\text{H}_2 + \text{I}_2 \rightleftharpoons 2\text{HI}H2​+I2​⇌2HI），压强变化不影响平衡

（3）温度变化

  • 升高温度 → 平衡向吸热方向移动
  • 降低温度 → 平衡向放热方向移动

温度是唯一能改变 KKK 值的因素。

（4）催化剂

催化剂同等程度加快正逆反应速率，不改变平衡位置，不改变 KKK 值，但能缩短达到平衡的时间。

四、等效平衡

在相同条件（恒温恒容或恒温恒压）下，无论从正反应方向还是逆反应方向出发，只要换算后的初始组成相同，就能达到相同的平衡状态。

恒温恒容条件下的等效平衡：将各物质按化学计量关系换算到方程式同一侧，若对应物质的物质的量完全相同，则为等效平衡。

恒温恒压条件下：只要换算后各物质的物质的量之比相同即可（不要求绝对量相同）。

拓展阅读

化学平衡理论是工业化学的理论支柱。合成氨工业选择 400∼500 °C400 \sim 500\,°\text{C}400∼500°C 而非更低的温度，并非因为低温不利于正向平衡（事实上低温 KKK 更大），而是因为低温下反应速率太慢，催化剂活性不够，无法在经济可行的时间内达到平衡。这体现了速率与平衡的矛盾统一。

接触法制硫酸中 SO2\text{SO}_2SO2​ 氧化为 SO3\text{SO}_3SO3​ 的过程同样需要在速率和平衡之间折中。选择 450 °C450\,°\text{C}450°C 和 V2O5\text{V}_2\text{O}_5V2​O5​ 催化剂，并采用常压（而非高压，因为该反应转化率已经很高，增压成本不划算），是化工设计中综合考量的典范。

化学平衡的概念后来被推广到溶解平衡、电离平衡、水解平衡等更广泛的体系，形成了统一的平衡理论框架。

小结

  • 化学平衡是可逆反应在 v正=v逆v_{\text{正}} = v_{\text{逆}}v正​=v逆​ 时的动态平衡状态
  • 平衡常数 KKK 只与温度有关，是衡量反应进行程度的定量标准
  • 勒夏特列原理：改变条件时，平衡向减弱该改变的方向移动
  • 催化剂不改变平衡位置和 KKK 值，只缩短达到平衡的时间
  • 转化率计算常用 ICE 表（初始-变化-平衡三段式）
