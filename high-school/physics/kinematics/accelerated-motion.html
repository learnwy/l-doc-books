高一物理 — 匀变速运动

知识要点

匀变速直线运动是加速度恒定不变的直线运动，是高中物理运动学的核心内容。在匀变速运动中，速度随时间均匀变化，加速度a保持恒定。核心公式包括速度公式v = v0v_0v0​ + at、位移公式x = v0v_0v0​t + ½at2at^2at2、速度位移关系v2v^2v2 - v02v_0^2v02​ = 2ax，以及平均速度公式v̄ = (v0v_0v0​ + v)/2。

加速度的物理意义：速度变化的快慢，a = Δv/Δt，单位m/s2s^2s2。加速度的方向与速度变化量Δv的方向一致，不一定与速度方向一致。

详细讲解

一、加速度的概念

定义：加速度是速度变化量与时间的比值，表示速度变化的快慢。

a = (v - v0v_0v0​)/t = Δv/Δt

理解要点：加速度大不代表速度大（火箭发射瞬间加速度大但速度为零）；加速度方向与速度方向相同时物体加速，相反时物体减速。

运动状态 v与a的方向关系 速度变化
匀加速 v与a同向 速度增大
匀减速 v与a反向 速度减小
匀速 a = 0 速度不变

二、匀变速运动的三个基本公式

公式一（速度-时间关系）：v = v0v_0v0​ + at

由加速度定义直接得出。v-t图上表示为一条斜率为a的直线。

公式二（位移-时间关系）：x = v0v_0v0​t + ½at2at^2at2

推导：利用v-t图下的面积等于位移。梯形面积 = ½(v0v_0v0​ + v)·t = ½(v0v_0v0​ + v0v_0v0​ + at)·t = v0v_0v0​t + ½at2at^2at2。

公式三（速度-位移关系）：v2v^2v2 - v02v_0^2v02​ = 2ax

推导：由公式一t = (v-v0v_0v0​)/a代入公式二得到。当题目不涉及时间t时，此公式最为方便。

补充公式：平均速度v̄ = (v0v_0v0​ + v)/2 = x/t。中间时刻速度等于全程的平均速度v_(t/2) = (v0v_0v0​+v)/2。

三、v-t图像分析

匀变速运动的v-t图是一条直线。从v-t图可以读出以下信息：

斜率 = 加速度a（斜率为正表示加速度向正方向，为负表示向负方向）

面积 = 位移（时间轴以上的面积为正位移，以下为负位移）

截距 = 初速度v0v_0v0​

与横轴交点 = 速度为零的时刻

四、匀减速到零的问题

当物体做匀减速运动时，速度最终减为零后物体停止。常见错误：代入公式后得到"负速度"——物理上没有意义，说明物体已经停止。

处理方法：先求减速到零所需的时间t0t_0t0​ = v0v_0v0​/|a|。如果题目要求的时间t > t0t_0t0​，则物体在t0t_0t0​时已停止，此后位移不再变化。

例：v0v_0v0​ = 10m/s, a = -2m/s2s^2s2。求5秒内和8秒内的位移。

t0t_0t0​ = 10/2 = 5s。5秒内：x = 10×5 + ½(-2)×25 = 25m。8秒内：物体在5s时已停止，x仍为25m。

五、典型例题

追及问题：A以v1v_1v1​匀速运动，B从静止开始以加速度a匀加速追赶A。当B的速度等于A的速度时，两者距离最大（此后B更快，距离开始缩小）。

设经过时间t两者速度相同：at = v1v_1v1​，t = v1v_1v1​/a。

此时A走的距离：x1x_1x1​ = v1v_1v1​t = v12v_1^2v12​/a

B走的距离：x2x_2x2​ = ½at2at^2at2 = ½a(v1v_1v1​/a)2^22 = v12v_1^2v12​/(2a)

最大距离差：Δx = x1x_1x1​ - x2x_2x2​ = v12v_1^2v12​/(2a)

刹车问题：某汽车以20m/s行驶，紧急刹车后加速度为-5m/s2s^2s2，求3s内和6s内的位移。

停止时间：t0t_0t0​ = 20/5 = 4s。3s < 4s，x3x_3x3​ = 20×3 + ½(-5)×9 = 37.5m。6s > 4s，x6x_6x6​ = x4x_4x4​ = 20×4 + ½(-5)×16 = 40m。

练习与思考

  1. 一辆汽车从静止出发以2m/s2s^2s2的加速度做匀加速运动，求：(1) 第3秒末的速度；(2) 前3秒内的位移；(3) 第3秒内的位移。

  2. 一个物体以10m/s的初速度做匀减速运动，加速度大小为2m/s2s^2s2，求物体在前8秒内的总路程。

  3. 从v-t图中读出初速度、加速度和前4秒的位移（需自行绘制一个匀变速运动的v-t图进行练习）。

  4. 飞机着陆后以-6m/s2s^2s2的加速度减速滑行，着陆速度为60m/s，求飞机滑行的距离。

拓展阅读

伽利略是系统研究匀变速运动的第一人。他通过斜面实验巧妙地"稀释"了重力加速度，验证了物体下落距离与时间平方成正比的关系。这项实验被视为近代实验物理学的开端。匀变速运动的公式在工程中有广泛应用，如汽车制动距离计算、电梯加减速设计等。

小结

匀变速运动的三个基本公式——v = v0v_0v0​ + at、x = v0v_0v0​t + ½at2at^2at2、v2v^2v2 - v02v_0^2v02​ = 2ax——是解决运动学问题的核心工具。理解加速度的方向性（与速度同向则加速、反向则减速）和v-t图的物理含义（斜率=加速度，面积=位移）是正确解题的关键。注意匀减速到零后物体停止的特殊情况。
