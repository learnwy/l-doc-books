高一物理 — 摩擦力与受力分析

知识要点

摩擦力存在于生活的方方面面：走路时脚与地面的摩擦使我们前进，刹车时轮胎与路面的摩擦使汽车减速，甚至拧螺丝、握笔写字都离不开摩擦力。摩擦力分为静摩擦力和滑动摩擦力两类，它们的产生条件、大小规律和方向判断各有不同。受力分析则是力学解题的第一步也是最关键的一步——找全力、画对图、分好类，才能正确列方程求解。

详细讲解

一、摩擦力的产生条件

摩擦力产生需要同时满足三个条件：

  1. 两物体直接接触且接触面粗糙
  2. 接触面之间有正压力（弹力）
  3. 两物体之间有相对运动或相对运动趋势

这三个条件缺一不可。光滑接触面（理想化模型）不产生摩擦力；两个物体虽然接触但没有正压力（如恰好悬浮）也不产生摩擦力；正压力存在但没有相对运动趋势（如水平面上静止物体没有水平推力时）也没有水平方向的摩擦力。

二、静摩擦力

定义：两个相互接触的物体之间没有发生相对滑动时，沿接触面切线方向阻碍物体相对运动趋势的力。

大小：静摩擦力的大小没有固定的计算公式，它随外力变化而变化（被动力），范围为 0 < f_静 ≤ f_max。

最大静摩擦力：f_max 是静摩擦力的上限，当外力超过 f_max 时物体开始滑动。实验表明 f_max 略大于滑动摩擦力，高中阶段通常近似认为 f_max ≈ μN。

方向判断：与物体相对运动趋势方向相反。判断相对运动趋势的方法：假设接触面光滑，看物体会怎样运动，这个运动方向就是相对运动趋势的方向。

情境 相对运动趋势 静摩擦力方向
水平推力推静止物体（未推动） 推力方向 与推力方向相反
斜面上静止物体 沿斜面向下 沿斜面向上
随传送带一起加速的物体 相对传送带向后 与传送带运动方向相同
圆盘上随盘转动的物体 沿切线方向飞出 指向圆心

三、滑动摩擦力

定义：两个相互接触的物体之间发生相对滑动时，接触面上产生的阻碍相对滑动的力。

大小：f = μN

其中 μ 为动摩擦因数（无量纲，取决于接触面材料和粗糙程度），N 为正压力（不一定等于重力）。

方向：与物体相对运动方向相反（注意是相对运动方向，不是运动方向）。

重要辨析：

  • 摩擦力方向与运动方向不一定相反。例如：人走路时，脚向后蹬地，地面给脚的摩擦力向前——这个摩擦力是人前进的动力
  • 正压力 N 不一定等于重力 mg。在斜面上 N = mgcos θ；有额外的竖直方向力时需要先求 N

四、受力分析的方法与步骤

受力分析是解力学问题的基础。标准步骤如下：

第一步：明确研究对象。确定对哪个物体进行受力分析。只画这个物体受到的力，不画它施加给别人的力。

第二步：按顺序找力。推荐的顺序是"先场力、后接触力"：

  1. 重力（场力）：任何物体都受重力，方向竖直向下，作用点在重心
  2. 弹力：逐个检查每个接触面或连接处是否有弹力（支持力、拉力、推力）
  3. 摩擦力：在有弹力的接触面上判断是否有摩擦力

第三步：画受力图。将所有力画在研究对象上，用带箭头的线段表示力的大小和方向。

第四步：检验。检查每个力的施力物体是否明确（每个力都必须有施力物体）；检查是否多画了力（如"向心力""合力"不应单独画出）；检查力的方向是否正确。

五、受力分析的典型场景

斜面上的物体：

  • 重力 mg：竖直向下
  • 支持力 N：垂直斜面向上
  • 摩擦力 f：沿斜面（方向取决于运动状态）

将重力沿斜面和垂直斜面分解：

  • 沿斜面方向：mgsin θ
  • 垂直斜面方向：mgcos θ
  • 因此 N = mgcos θ（垂直斜面方向平衡）

悬挂物体：

  • 重力 mg：竖直向下
  • 两根绳的拉力 T1T_1T1​、T2T_2T2​：沿绳的方向
  • 平衡条件：三个力的矢量和为零

连接体：

  • 先用整体法确定系统加速度
  • 再用隔离法分析个别物体的受力（特别是内力）

六、正交分解法

当受力较多且不在同一方向时，采用正交分解法：

  1. 建立互相垂直的 x-y 坐标系（通常取加速度方向为 x 轴正方向）
  2. 将每个力分解到 x 和 y 两个方向
  3. 分别在 x 和 y 方向上列方程：ΣFxF_xFx​ = maxa_xax​，ΣFyF_yFy​ = maya_yay​

坐标系的选取原则：尽量让更多的力落在坐标轴上，减少需要分解的力的个数。

练习与思考

  1. 一个质量为 5 kg 的物体放在水平面上，动摩擦因数 μ = 0.3。用水平力 F 推物体：(1) 当 F = 10 N 时物体未动，此时摩擦力多大？(2) 当 F = 20 N 时物体恰好开始滑动，最大静摩擦力多大？(3) 物体滑动后（F = 20 N 仍作用），加速度多大？（g 取 10 m/s2s^2s2）

  2. 一个物体放在倾角 θ = 30° 的粗糙斜面上，恰好不滑动。求物体与斜面之间的动摩擦因数。（设 f_max ≈ μN）

  3. 一个质量为 m 的物体放在传送带上，传送带以速度 v0v_0v0​ 匀速运动。物体初始静止，与传送带之间的动摩擦因数为 μ。描述物体的运动过程并求物体达到传送带速度所需的时间。

  4. 对下列情境进行完整的受力分析（画出受力图）：(1) 斜面上用绳平行于斜面向上拉住的物体；(2) 水平面上同时受到水平推力和斜向上拉力的物体。

  5. 思考：为什么冰面上走路容易摔倒？从摩擦力的角度解释为什么撒盐或撒沙子能防滑。

拓展阅读

摩擦力的微观本质至今仍是物理学研究的前沿课题。宏观上我们用 f = μN 来描述滑动摩擦力，但微观层面上，摩擦力来源于接触面微观凸起之间的分子间作用力和机械咬合。真正的接触面积远小于表观接触面积，正压力越大，真实接触面积越大，摩擦力也越大。纳米尺度上的摩擦行为与宏观完全不同，这催生了"纳米摩擦学"这一新兴学科。在工程中，减小摩擦（润滑、轴承、气垫）和增大摩擦（轮胎花纹、刹车片、砂纸）都是重要的应用方向。

小结

摩擦力分为静摩擦力（被动力，大小可变，范围 0 到 f_max）和滑动摩擦力（f = μN），方向均与相对运动（趋势）方向相反。受力分析的关键是按"重力→弹力→摩擦力"的顺序逐一排查，每个力都必须有明确的施力物体，不能多画也不能少画。正交分解法是处理多力问题的标准工具，坐标轴的选取直接影响解题的简洁程度。养成规范画受力图的习惯，是学好力学的第一步。
