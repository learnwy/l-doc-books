高三物理 — 电路综合

知识要点

电路分析是高考物理的必考模块，涵盖直流电路的基本定律、电学实验和动态电路分析。高三复习需要从欧姆定律和基尔霍夫定律出发，熟练掌握含内阻电路的计算，并结合实验题型训练电表读数、电路设计和误差分析能力。

直流电路核心公式：

公式 表达式 适用范围
欧姆定律（部分电路） U=IRU = IRU=IR 纯电阻或外电路
闭合电路欧姆定律 ε=I(R+r)\varepsilon = I(R + r)ε=I(R+r) 含内阻的完整电路
电功率 P=UI=I2R=U2RP = UI = I^2R = \frac{U^2}{R}P=UI=I2R=RU2​ 任何用电器
热功率 P热=I2RP_{\text{热}} = I^2RP热​=I2R 纯电阻时等于总功率
电源效率 η=P外P总=RR+r\eta = \frac{P_{\text{外}}}{P_{\text{总}}} = \frac{R}{R + r}η=P总​P外​​=R+rR​ 含内阻电路

详细讲解

一、闭合电路欧姆定律

一个电动势为 ε\varepsilonε、内阻为 rrr 的电源，连接外电阻 RRR：

ε=IR+Ir=U外+U内\varepsilon = IR + Ir = U_{\text{外}} + U_{\text{内}}ε=IR+Ir=U外​+U内​

路端电压：U=ε−IrU = \varepsilon - IrU=ε−Ir

这个方程揭示了一个重要关系：电源的路端电压随电流增大而线性下降。在 UUU-III 图上，这是一条斜率为 −r-r−r 的直线，纵截距为 ε\varepsilonε。

短路与断路的极端情况：

情形 电流 路端电压 说明
断路（R→∞R \to \inftyR→∞） I=0I = 0I=0 U=εU = \varepsilonU=ε 路端电压等于电动势
短路（R=0R = 0R=0） I=εrI = \frac{\varepsilon}{r}I=rε​ U=0U = 0U=0 电源全部消耗在内阻上，非常危险

二、串并联电路计算

串联电路：电流处处相等，电压按电阻分配。

I总=I1=I2,U总=U1+U2,R总=R1+R2I_{\text{总}} = I_1 = I_2, \quad U_{\text{总}} = U_1 + U_2, \quad R_{\text{总}} = R_1 + R_2I总​=I1​=I2​,U总​=U1​+U2​,R总​=R1​+R2​

并联电路：电压处处相等，电流按电导分配。

U总=U1=U2,I总=I1+I2,1R总=1R1+1R2U_{\text{总}} = U_1 = U_2, \quad I_{\text{总}} = I_1 + I_2, \quad \frac{1}{R_{\text{总}}} = \frac{1}{R_1} + \frac{1}{R_2}U总​=U1​=U2​,I总​=I1​+I2​,R总​1​=R1​1​+R2​1​

两个电阻并联的简化公式：R总=R1R2R1+R2R_{\text{总}} = \frac{R_1 R_2}{R_1 + R_2}R总​=R1​+R2​R1​R2​​

三、动态电路分析

动态电路分析是高考选择题的常客。当电路中某个电阻发生变化时，需要分析各处电流、电压的变化趋势。

分析步骤（程序法）：

  1. 判断变化的电阻（RRR 增大还是减小）
  2. 判断总电阻（R总R_{\text{总}}R总​）的变化方向
  3. 由闭合电路欧姆定律判断总电流 III 的变化
  4. 由 U内=IrU_{\text{内}} = IrU内​=Ir 判断内电压变化
  5. 由 U外=ε−U内U_{\text{外}} = \varepsilon - U_{\text{内}}U外​=ε−U内​ 判断路端电压变化
  6. 逐个分析各支路的电流和电压

关键技巧：并联支路中一条电阻增大→并联等效电阻增大→总电阻增大→总电流减小→路端电压增大→并联两端电压增大→另一支路电流增大。这个"此消彼长"的规律是动态分析的高频考点。

四、电功率最大值问题

外电路功率：

P外=I2R=ε2R(R+r)2P_{\text{外}} = I^2 R = \frac{\varepsilon^2 R}{(R + r)^2}P外​=I2R=(R+r)2ε2R​

对 RRR 求导令其为零，或用均值不等式：

当 R=rR = rR=r 时，P外P_{\text{外}}P外​ 取最大值 Pmax⁡=ε24rP_{\max} = \frac{\varepsilon^2}{4r}Pmax​=4rε2​

此时电源效率为 50%50\%50%，路端电压为 ε2\frac{\varepsilon}{2}2ε​。

五、电学实验核心方法

测电阻——伏安法：

接法 电路特征 测量值 适用条件
安培表外接 电压表并联在电阻和电流表外 R测=UI>R真R_{\text{测}} = \frac{U}{I} > R_{\text{真}}R测​=IU​>R真​ 被测电阻较小（R≪RVR \ll R_VR≪RV​）
安培表内接 电压表并联在电阻两端（含电流表） R测=UI<R真R_{\text{测}} = \frac{U}{I} < R_{\text{真}}R测​=IU​<R真​（注：此处 UUU 含 UAU_AUA​，所以偏大） 被测电阻较大（R≫RAR \gg R_AR≫RA​）

判断依据：RxR_xRx​ 与 RARV\sqrt{R_A R_V}RA​RV​​ 比较，小于用外接，大于用内接。

测电动势和内阻：

用伏安法，U=ε−IrU = \varepsilon - IrU=ε−Ir。测量多组 (I,U)(I, U)(I,U) 数据，以 UUU 为纵轴、III 为横轴作图，直线的纵截距为 ε\varepsilonε，斜率绝对值为 rrr。

滑动变阻器的两种接法：

接法 特点 适用情形
限流接法 电阻串联在电路中 电压调节范围不需要从零开始
分压接法 电阻并联分压 需要电压从零连续可调，或滑动变阻器电阻远小于被测电阻

电流表改装为电压表：串联大电阻 R=UIg−RgR = \frac{U}{I_g} - R_gR=Ig​U​−Rg​

电流表改装为大量程电流表：并联小电阻 R=IgRgI−IgR = \frac{I_g R_g}{I - I_g}R=I−Ig​Ig​Rg​​

拓展阅读

欧姆在 1827 年发表的电路定律最初并未被学术界接受——德国的物理学家们认为他的实验过于粗糙，数学推导缺乏严谨性。直到英国皇家学会授予他科普利奖章，欧姆定律才获得广泛认可。

现代电路设计已经远超直流电路的范畴。集成电路芯片上包含数十亿个晶体管，每个晶体管都是一个微型开关。但其工作原理的底层逻辑——电压驱动电流、电阻限制电流——与高考电路题的分析思路是一脉相承的。

高考电学实验题的评分特别关注"实验设计的合理性"和"误差分析的准确性"。平时练习时，不要只追求最终答案，要养成分析每种接法优缺点的习惯。

小结

电路综合复习以闭合电路欧姆定律 ε=I(R+r)\varepsilon = I(R + r)ε=I(R+r) 为核心，串并联计算为基本工具，动态分析为思维训练。实验部分重点掌握伏安法测电阻的内外接选择、测电动势和内阻的图像法处理、滑动变阻器的分压与限流接法。电功率最大值条件 R=rR = rR=r 是计算题的常见考点。
