高二物理 — 电路

知识要点

电路是电荷定向流动的闭合路径。从简单的手电筒到复杂的集成电路，电路原理贯穿了现代技术的方方面面。高二阶段在初中电路知识的基础上引入电动势、内阻和闭合电路欧姆定律等概念，构建更加完整的电路分析体系。

本节核心内容：

  • 电流与电阻：电流的微观本质与欧姆定律
  • 电动势与内阻：电源的完整模型
  • 闭合电路欧姆定律：考虑内阻的电路分析
  • 串并联电路的综合分析
  • 电功与电功率：电路中的能量转化

详细讲解

一、电流的本质与欧姆定律

电流强度的定义：单位时间内通过导体横截面的电荷量。

I=qtI = \frac{q}{t}I=tq​

单位：安培（A\text{A}A），1A=1C/s1\text{A} = 1\text{C/s}1A=1C/s。

电流的方向规定为正电荷的流动方向（实际上在金属导体中是自由电子的定向移动，方向与电流方向相反）。

欧姆定律：导体两端的电压 UUU 与通过的电流 III 成正比：

U=IRU = IRU=IR

RRR 为电阻，单位为欧姆（Ω\OmegaΩ）。

电阻的决定因素：

R=ρLSR = \rho \frac{L}{S}R=ρSL​

其中 ρ\rhoρ 为电阻率（取决于材料和温度），LLL 为导体长度，SSS 为横截面积。

二、电动势与内阻

电源的作用是将其他形式的能量转化为电能，维持电路中的电流。

电动势 ε\varepsilonε 描述了电源将其他能量转化为电能的能力：

ε=Wq\varepsilon = \frac{W}{q}ε=qW​

其中 WWW 是电源将非电能转化为电能的总功，qqq 为转移的电荷量。

电动势的单位是伏特（V\text{V}V），一节干电池的电动势约为 1.5V1.5\text{V}1.5V。

内阻 rrr：电源内部也有电阻，电流通过内部时会消耗一部分电能转化为热能。

电源的端电压（外部电路两端的电压）：

U=ε−IrU = \varepsilon - IrU=ε−Ir

当外电路断开（I=0I = 0I=0）时，端电压等于电动势：U=εU = \varepsilonU=ε。

三、闭合电路欧姆定律

对于一个由电源和外电路组成的闭合回路：

ε=I(R+r)\varepsilon = I(R + r)ε=I(R+r)

即电动势等于内、外电路电压降之和。由此可得：

I=εR+rI = \frac{\varepsilon}{R + r}I=R+rε​

路端电压与外电阻的关系：

U=ε−Ir=ε⋅RR+rU = \varepsilon - Ir = \varepsilon \cdot \frac{R}{R + r}U=ε−Ir=ε⋅R+rR​

串联电路：

1R总=1R1+1R2+⋯+1Rn\frac{1}{R_{\text{总}}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n}R总​1​=R1​1​+R2​1​+⋯+Rn​1​

综合分析步骤：

  1. 识别电路结构（哪些元件串联，哪些并联）
  2. 化简等效电阻
  3. 利用闭合电路欧姆定律求总电流
  4. 逐步分配电压和电流

五、电功与电功率

电功：电场力对电荷做的功。

W=UIt=I2Rt=U2RtW = UIt = I^2Rt = \frac{U^2}{R}tW=UIt=I2Rt=RU2​t

电功率：单位时间内电流做的功。

P=UI=I2R=U2RP = UI = I^2R = \frac{U^2}{R}P=UI=I2R=RU2​

电源的功率分析：

拓展阅读

欧姆在 1827 年发表了他的电路定律，但当时并没有得到科学界的认可。直到数年后，其他科学家的实验验证了他的发现，欧姆定律才被广泛接受。电阻的单位"欧姆"就是以他的名字命名的。

电路理论的应用极为广泛：

  • 集成电路中一个指甲大小的芯片上包含数十亿个晶体管，每一个都遵循基本的电路原理
  • 家用电路采用并联设计，使各个电器可以独立工作
  • 电动汽车的电池管理系统需要精确控制串并联电池组的充放电
  • 心脏起搏器是一个精密的电路系统，通过微小电流刺激心肌规律收缩

基尔霍夫定律（电流定律和电压定律）是分析复杂电路的更强大工具，将在大学物理中系统学习。

小结

  • 欧姆定律 U=IRU = IRU=IR 是电路分析的基础公式
  • 电源有电动势 ε\varepsilonε 和内阻 rrr，路端电压 U=ε−IrU = \varepsilon - IrU=ε−Ir 随电流增大而减小
  • 闭合电路欧姆定律 I=εR+rI = \frac{\varepsilon}{R + r}I=R+rε​ 将内外电路统一分析
  • 串联分压、并联分流是电路综合分析的核心思路
  • 当外电阻等于内阻时，电源输出功率最大
