高一物理 — 守恒定律

知识要点

台球桌上白球撞击彩球后，白球减速、彩球加速——速度在两球之间"转移"了。如果把两球视为一个整体，会发现它们的总动量在碰撞前后保持不变。这就是动量守恒定律。与机械能守恒定律一起，动量守恒定律构成了力学中最重要的两条守恒定律。守恒定律之所以强大，在于它们让我们可以绕过复杂的受力分析和运动细节，直接从初状态跳到末状态来求解问题。

详细讲解

一、动量守恒定律

内容：如果一个系统不受外力或所受外力的合力为零，则该系统的总动量保持不变。

m1v⃗1+m2v⃗2=m1v⃗1′+m2v⃗2′m_1\vec{v}_1 + m_2\vec{v}_2 = m_1\vec{v}_1' + m_2\vec{v}_2'm1​v1​+m2​v2​=m1​v1′​+m2​v2′​

守恒条件：

  1. 系统不受外力，或外力的矢量和为零
  2. 外力远小于内力（近似守恒），如碰撞、爆炸等瞬间过程
  3. 某一方向上的外力为零或可忽略时，该方向上动量守恒

动量守恒与牛顿第三定律的关系：

考虑两个物体组成的系统。由牛顿第三定律，F⃗12=−F⃗21\vec{F}_{12} = -\vec{F}_{21}F12​=−F21​。在相同时间 Δt\Delta tΔt 内：

F⃗12Δt=−F⃗21Δt\vec{F}_{12}\Delta t = -\vec{F}_{21}\Delta tF12​Δt=−F21​Δt
Δp⃗1=−Δp⃗2\Delta\vec{p}_1 = -\Delta\vec{p}_2Δp​1​=−Δp​2​
Δp⃗1+Δp⃗2=0\Delta\vec{p}_1 + \Delta\vec{p}_2 = 0Δp​1​+Δp​2​=0

这表明系统总动量的变化为零，即总动量守恒。

二、动量守恒定律的应用

使用步骤：

  1. 选取系统——确定研究的对象包含哪些物体
  2. 判断守恒条件——检验系统是否满足动量守恒
  3. 规定正方向——动量是矢量，必须选定正方向
  4. 列方程——写出初末状态的总动量相等
  5. 求解——代入数值计算

典型场景一：碰撞问题

碰撞分为三类：

类型 动量守恒 动能变化 特点
完全弹性碰撞 守恒 守恒 碰后两物体分开，动能无损失
非弹性碰撞 守恒 减少 碰后两物体分开，部分动能转化为内能
完全非弹性碰撞 守恒 最大损失 碰后两物体粘在一起，动能损失最大

完全弹性碰撞的公式（一维正碰，目标静止）：

v1′=m1−m2m1+m2v1v_1' = \frac{m_1 - m_2}{m_1 + m_2}v_1v1′​=m1​+m2​m1​−m2​​v1​
v2′=2m1m1+m2v1v_2' = \frac{2m_1}{m_1 + m_2}v_1v2′​=m1​+m2​2m1​​v1​

特殊情况分析：

  • m1=m2m_1 = m_2m1​=m2​：v1′=0v_1' = 0v1′​=0，v2′=v1v_2' = v_1v2′​=v1​（速度完全交换，如台球）
  • m1≫m2m_1 \gg m_2m1​≫m2​：v1′≈v1v_1' \approx v_1v1′​≈v1​，v2′≈2v1v_2' \approx 2v_1v2′​≈2v1​（重物几乎不减速，轻物以约两倍速度弹出）
  • m1≪m2m_1 \ll m_2m1​≪m2​：v1′≈−v1v_1' \approx -v_1v1′​≈−v1​，v2′≈0v_2' \approx 0v2′​≈0（轻物几乎原速弹回，重物几乎不动）

典型场景二：爆炸问题

系统内部有能量释放（如炸药、弹簧），但过程极短，外力冲量可忽略。

一颗静止的炮弹爆炸成两块，质量分别为 m1m_1m1​ 和 m2m_2m2​。由动量守恒：

0=m1v1+m2v20 = m_1v_1 + m_2v_20=m1​v1​+m2​v2​
v1=−m2m1v2v_1 = -\frac{m_2}{m_1}v_2v1​=−m1​m2​​v2​

两块碎片速度方向相反，速度大小之比等于质量的反比。

典型场景三：反冲运动

人站在光滑冰面上扔球。设人的质量为 MMM，球的质量为 mmm，扔出的速度为 vvv。由动量守恒：

0=mv+MV0 = mv + MV0=mv+MV
V=−mMvV = -\frac{m}{M}vV=−Mm​v

人向反方向运动，这就是反冲原理。火箭推进正是利用了这一原理——向后高速喷出气体，火箭获得向前的速度。

三、机械能守恒定律的深化

回顾机械能守恒定律：在只有重力和弹力做功的系统中，动能和势能可以相互转化，但机械能总量不变。

12mv12+mgh1=12mv22+mgh2\frac{1}{2}mv_1^2 + mgh_1 = \frac{1}{2}mv_2^2 + mgh_221​mv12​+mgh1​=21​mv22​+mgh2​

与动量守恒的对比：

比较项 动量守恒 机械能守恒
守恒条件 合外力为零或内力远大于外力 只有重力和弹力做功
矢量/标量 矢量守恒 标量守恒
碰撞中 总成立（若外力可忽略） 仅弹性碰撞成立
爆炸中 总成立 不成立（内能转化为机械能）

四、两个守恒定律的联合应用

许多问题需要同时使用动量守恒和能量守恒来求解。

经典问题：子弹打木块

质量为 mmm 的子弹以速度 v0v_0v0​ 射入质量为 MMM 的静止木块并嵌入其中（完全非弹性碰撞）。

第一阶段（碰撞过程）：动量守恒（碰撞时间极短，外力冲量可忽略）

mv0=(m+M)vmv_0 = (m + M)vmv0​=(m+M)v
v=mv0m+Mv = \frac{mv_0}{m + M}v=m+Mmv0​​

第二阶段（嵌入后的运动）：根据后续条件（如木块在光滑面上滑行、悬挂摆动等）应用能量守恒或动能定理。

碰撞过程中损失的动能：

ΔEk=12mv02−12(m+M)v2=mM2(m+M)v02\Delta E_k = \frac{1}{2}mv_0^2 - \frac{1}{2}(m + M)v^2 = \frac{mM}{2(m + M)}v_0^2ΔEk​=21​mv02​−21​(m+M)v2=2(m+M)mM​v02​

这部分能量转化为木块的内能（热能）和木块的形变能。

五、守恒定律的普适性

动量守恒和能量守恒是自然界中最基本的守恒定律。它们的成立不依赖于相互作用力的具体形式，无论是引力、电磁力还是核力，这些守恒定律都成立。

从更深层次看，诺特定理揭示了守恒定律与对称性之间的对应关系：

对称性 守恒量
时间平移对称性 能量守恒
空间平移对称性 动量守恒
空间旋转对称性 角动量守恒

拓展阅读

守恒定律在粒子物理学中发挥着关键作用。科学家在实验中发现，β\betaβ 衰变过程中能量似乎不守恒——衰变前后的动能和质量能之和对不上。泡利在1930年大胆假设存在一种未被探测到的粒子带走了"消失"的能量和动量，后来费米将它命名为"中微子"。25年后（1956年），科学家终于在实验中直接探测到了中微子，证实了泡利的预言。这个故事深刻地说明了一个道理：物理学家宁愿假设存在新粒子，也不愿意放弃守恒定律——因为守恒定律的基础是自然界的基本对称性。

小结

动量守恒定律指出，在合外力为零（或可忽略）的系统中，总动量保持不变，这一定律源自牛顿第三定律。碰撞分为弹性碰撞（动能也守恒）、非弹性碰撞和完全非弹性碰撞三类。动量守恒与机械能守恒是力学中最重要的两条守恒定律，前者是矢量守恒，后者是标量守恒，二者的守恒条件不同但可以联合使用。在子弹打木块、爆炸、反冲等经典问题中，往往需要根据不同阶段分别应用不同的守恒定律。守恒定律不仅是解题工具，更是自然界对称性的深刻体现。
