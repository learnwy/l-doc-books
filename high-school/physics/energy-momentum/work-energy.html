高一物理 — 功与能

知识要点

当你用力推动一个箱子沿地面滑动时，你的肌肉在"做功"——力沿位移方向产生了实际效果。功是力学中连接力与能量的桥梁概念：力对物体做功的过程，就是能量从一种形式转化为另一种形式的过程。功的定义看似简单（W=Fscos⁡θW = Fs\cos\thetaW=Fscosθ），但它背后蕴含着深刻的物理思想——用标量来度量矢量（力）沿某一方向的累积效果。动能定理则把功与物体运动状态的改变直接联系起来，是解决力学问题的强大工具。

详细讲解

一、功的定义与计算

定义：力对物体做的功等于力的大小、位移的大小以及力与位移方向夹角的余弦的乘积。

W=Fscos⁡θW = Fs\cos\thetaW=Fscosθ

其中 FFF 为力的大小（单位 N），sss 为位移的大小（单位 m），θ\thetaθ 为力与位移方向的夹角，WWW 的单位为焦耳（J），1 J=1 N⋅m1\text{ J} = 1\text{ N}\cdot\text{m}1 J=1 N⋅m。

对公式的理解：

夹角范围 cos⁡θ\cos\thetacosθ 符号 功的正负 物理意义
0≤θ<90°0 \leq \theta < 90°0≤θ<90° 正 正功 力促进物体运动，力向物体传递能量
θ=90°\theta = 90°θ=90° 零 不做功 力与运动方向垂直，如圆周运动中的向心力
90°<θ≤180°90° < \theta \leq 180°90°<θ≤180° 负 负功 力阻碍物体运动，物体向外界传递能量

重要说明：

  • 功是标量，没有方向，但有正负之分。正负代表能量传递的方向，不代表方向。
  • 公式中的 sss 是位移而非路程。
  • 力和位移必须是同一个物体上的力和该物体的位移。

几种常见力做功的特点：

  1. 重力做功：WG=mghW_G = mghWG​=mgh，其中 hhh 为物体重心下降的高度。重力做功只与起点和终点的高度差有关，与运动路径无关。
  2. 弹力做功：弹簧弹力做功需要用 W=12kx12−12kx22W = \frac{1}{2}kx_1^2 - \frac{1}{2}kx_2^2W=21​kx12​−21​kx22​ 来计算（x1x_1x1​、x2x_2x2​ 分别为初末形变量）。
  3. 摩擦力做功：滑动摩擦力做的功等于 Wf=−f⋅dW_f = -f \cdot dWf​=−f⋅d（ddd 为相对滑动的路程），摩擦力做功与路径有关。

二、功率

功率描述做功的快慢，定义为单位时间内所做的功：

P=WtP = \frac{W}{t}P=tW​

单位为瓦特（W），1 W=1 J/s1\text{ W} = 1\text{ J/s}1 W=1 J/s。

瞬时功率：当力 FFF 与速度 vvv 方向一致时，瞬时功率为：

P=FvP = FvP=Fv

这个公式在分析汽车启动问题时特别有用。

汽车启动的两种方式：

  1. 恒功率启动：发动机从启动开始就以额定功率运转。随着速度增大，由 F=P/vF = P/vF=P/v 可知牵引力减小；当牵引力等于阻力时，加速度为零，达到最大速度 vmax=P额/fv_{max} = P_{额}/fvmax​=P额​/f。
  2. 恒加速度启动：先以恒定加速度增速，此阶段功率逐渐增大；当功率达到额定功率后，转入恒功率运行，继续加速直到达到最大速度。

三、动能与动能定理

动能：物体由于运动而具有的能量，定义为：

Ek=12mv2E_k = \frac{1}{2}mv^2Ek​=21​mv2

动能是标量，始终为非负值。

动能定理：合外力对物体所做的总功等于物体动能的变化量。

W合=ΔEk=12mv22−12mv12W_{合} = \Delta E_k = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2W合​=ΔEk​=21​mv22​−21​mv12​

动能定理的优势：

  • 动能定理是标量方程，不涉及矢量分解，计算更简便
  • 可以处理变力做功的问题（牛顿定律直接处理变力较困难）
  • 适用于任意运动过程，不要求是直线运动或匀变速运动

四、重力势能

物体由于被举高而具有的能量叫做重力势能：

Ep=mghE_p = mghEp​=mgh

其中 hhh 是物体重心相对于参考平面的高度。参考平面的选取是任意的（通常选地面），不影响势能的变化量。

重力势能变化与重力做功的关系：

WG=−ΔEp=−(Ep2−Ep1)=Ep1−Ep2W_G = -\Delta E_p = -(E_{p2} - E_{p1}) = E_{p1} - E_{p2}WG​=−ΔEp​=−(Ep2​−Ep1​)=Ep1​−Ep2​

重力做正功时，重力势能减小；重力做负功时，重力势能增大。重力势能的变化只与始末位置有关，与运动路径无关——这正是重力做功的路径无关性在能量语言中的表达。

五、弹性势能

物体由于发生弹性形变而具有的能量叫做弹性势能。对于弹簧：

E弹=12kx2E_{弹} = \frac{1}{2}kx^2E弹​=21​kx2

其中 kkk 为弹簧劲度系数，xxx 为弹簧的形变量（伸长或压缩的长度）。弹性势能总是非负的，自然长度时弹性势能为零。

六、机械能守恒定律

机械能：动能与势能（重力势能和弹性势能）的总和。

E=Ek+Ep+E弹E = E_k + E_p + E_{弹}E=Ek​+Ep​+E弹​

机械能守恒定律：在只有重力和弹簧弹力做功的系统内，物体的动能和势能可以相互转化，但机械能的总量保持不变。

Ek1+Ep1=Ek2+Ep2E_{k1} + E_{p1} = E_{k2} + E_{p2}Ek1​+Ep1​=Ek2​+Ep2​

守恒条件：只有重力或弹力做功（即除重力和弹力外的其他力不做功，或其他力做功之和为零）。

判断机械能是否守恒的方法：

  1. 分析除重力和弹力外是否还有其他力
  2. 如果有其他力，这些力是否做功
  3. 如果做功，这些功之和是否为零

  1. 一个质量为 m=5 kgm = 5\text{ kg}m=5 kg 的物体，在 F=20 NF = 20\text{ N}F=20 N 的水平拉力作用下沿粗糙水平面移动了 s=10 ms = 10\text{ m}s=10 m，动摩擦因数 μ=0.2\mu = 0.2μ=0.2。求：(1) 拉力做的功；(2) 摩擦力做的功；(3) 合力做的功；(4) 物体获得的动能。（ggg 取 10 m/s210\text{ m/s}^210 m/s2）

  2. 一辆汽车质量为 m=1000 kgm = 1000\text{ kg}m=1000 kg，发动机额定功率 P=60 kWP = 60\text{ kW}P=60 kW，行驶阻力恒为 f=1500 Nf = 1500\text{ N}f=1500 N。求：(1) 汽车在水平路面上的最大速度；(2) 当汽车速度为 v=20 m/sv = 20\text{ m/s}v=20 m/s 时的加速度。

  3. 一个质量为 mmm 的小球从高 hhh 处自由落下，落到地面时速度为 vvv。试用动能定理证明 v=2ghv = \sqrt{2gh}v=2gh​。

  4. 从光滑斜面顶端释放一个小球，斜面高 h=5 mh = 5\text{ m}h=5 m。求小球到达斜面底端时的速度。如果换成粗糙斜面，小球到达底端的速度会变大还是变小？为什么？

拓展阅读

功和能的概念在物理学史上经历了漫长的发展过程。17世纪，莱布尼茨提出了"活力"（mv2mv^2mv2）的概念，与牛顿学派支持的"动量"（mvmvmv）展开了长达一个世纪的"活力之争"。直到19世纪中叶，焦耳通过精密实验确定了热功当量，证明了热量与功之间可以相互转化且有确定的比值，能量守恒定律才最终确立。今天我们知道，能量守恒是自然界最普遍、最深刻的规律之一——它不仅适用于力学，也适用于热学、电磁学、原子物理等一切物理过程。诺特定理更从数学上证明了能量守恒与时间平移对称性之间的深刻联系。

小结

功是力沿位移方向的累积效果，公式 W=Fscos⁡θW = Fs\cos\thetaW=Fscosθ 中夹角 θ\thetaθ 决定功的正负。功率 P=W/tP = W/tP=W/t（平均）或 P=FvP = FvP=Fv（瞬时）描述做功的快慢。动能定理 W合=ΔEkW_{合} = \Delta E_kW合​=ΔEk​ 建立了功与动能变化之间的桥梁，特别适合处理变力和曲线运动问题。重力势能 Ep=mghE_p = mghEp​=mgh 与重力做功路径无关，弹性势能 E弹=12kx2E_{弹} = \frac{1}{2}kx^2E弹​=21​kx2 储存在形变中。当只有重力和弹力做功时，机械能守恒——动能与势能此消彼长，总量恒定。
