高一 (Year 1)高一信息科技 简介AI 使用 简介Untitled

知识要点

把同一个 AI 模型当成黑盒，输入一句话能得到答案，但答案质量会因为问法不同相差十倍——这种"通过精心设计提问把模型潜力榨出来"的技能，就叫 prompt 工程（prompt engineering，又译"提示词工程"）。它不是程序员的专利，而是任何一个想把 AI 当作助手的人都需要掌握的基本功。

  • Prompt（提示词）：你输入给 AI 的那段文字。一个 prompt 可以只有一句话，也可以是几百字的复杂说明。
  • Prompt 工程：有意识地设计 prompt 的过程——思考给 AI 什么背景、什么要求、什么格式，让它输出更接近你的真实需求。
  • 关键认知：AI 不是搜索引擎。搜索引擎按关键词匹配；AI 按你给的全部上下文"推理"。所以你说得越具体、越像在跟一个聪明但毫无背景知识的实习生交代任务，输出就越好。

学完本节，你需要能回答三个问题：为什么"问得好"是一项可以训练的技能；普通用法和工程化用法的差别在哪；高中生在哪些日常学习场景里值得花时间设计 prompt。

详细讲解

为什么需要专门学提问

直觉上，AI 模型像 ChatGPT、文心一言、Kimi、豆包之类，输入问题就有答案，似乎不需要"学"。但实际试过的同学很快会发现：

场景 随手提问的结果 工程化提问的结果
让 AI 帮你写议论文素材 给一段网上常见的、谁都能想到的例子 给三段从不同角度切入、有数据有反差的高质量素材
让 AI 解释一道数学题 直接给答案，过程跳跃 一步一步推导，标出常见错误点
让 AI 翻译英语段落 字面直译，中式英语 符合英语母语者表达习惯，附带语法和词汇解释

差距来自哪里？AI 内部其实"知道"很多东西，但它每次回答都只看你这一轮输入。如果你只说"帮我写素材"，它默认走最普通、最保险的输出路径——因为它不知道你要议论文还是记叙文、要正面还是反面、要近现代还是古代。

Prompt 工程的本质就是：主动给 AI 那些它本来需要猜的信息。猜得越少，答得越准。

提问质量公式

可以用一个简化的公式来理解：

输出质量≈f(模型能力,提问清晰度,上下文充分性)\text{输出质量} \approx f(\text{模型能力}, \text{提问清晰度}, \text{上下文充分性})输出质量≈f(模型能力,提问清晰度,上下文充分性)

模型能力是固定的（你换不了模型），所以输出质量的可控变量主要是后两项。这两项加起来，就是 prompt 工程要训练的全部内容。

高一最值得用 prompt 工程的五个场景
高中阶段时间紧，不可能事事都精雕细琢一个 prompt。建议把训练精力集中在以下五类场景：


    

  1. 议论文素材积累——让 AI 围绕同一个主题（比如"逆境与成长"）从历史、科学、文学、当代、个人五个角度各给一个素材，远比搜索引擎查"逆境素材"高效。
    2. 

  2. 英语阅读理解——把一段英文 reading 喂给 AI，要求标出生词、长难句结构、作者态度，比单纯查字典快十倍。
    3. 

  3. 数学错题分析——把你做错的题目和错误过程给 AI，要求它指出错在哪一步、为什么会这样想、正确思路如何展开。
    4. 

  4. 研究性学习开题——一个好的研究课题需要文献调研、背景梳理、研究问题聚焦，AI 可以快速帮你做出第一版骨架。
    5. 

  5. 自主招生 / 综评材料——个人陈述、活动经历描述需要反复打磨，AI 是很好的"陪练对手"。
    6. 



普通用法 vs 工程化用法对照
举一个具体例子，主题是"帮我写一段议论文素材，主题是逆境"：


普通问法（差）：


帮我写一段议论文素材，主题是逆境。
AI 大概率回给你一段司马迁忍辱负重写《史记》的文字——人人都用过，老师看烦了。


工程化问法（好）：


我是一名高一学生，正在写一篇议论文，主题是"逆境塑造成长"。
请给我三段素材：
1. 一段近现代科学家的事例（不要爱因斯坦、牛顿等过于常见的）
2. 一段当代体育或商业人物的事例（带具体数据）
3. 一段我自己可以代入的"普通学生"视角小故事

每段控制在 150 字以内，结尾要点出与"逆境"主题的关联。
第二种问法把 AI 的输出空间从"逆境素材"这种笼统范围，收窄到了具体的、可用的三段内容。这就是 prompt 工程要做的事。


练习与思考
    

  1. 你平时使用 AI 最多的三个场景是什么？尝试用"普通问法 → 工程化问法"对照，把每个场景的问法升级一次。
    2. 

  2. 思考：搜索引擎和 AI 在你需要查找信息时各自的优势是什么？什么时候用哪个更合适？
    3. 

  3. 找一道你最近做错的数学题，分别用"老师我这题做错了"（普通问法）和包含错误过程、错误原因猜测、希望讲解角度的工程化问法各问 AI 一次，对比两次回答的差距。
    4. 

  4. 反思：当 AI 给你一个不满意的答案时，你过去通常是放弃换搜索引擎，还是会继续调整问法？
    5. 



拓展阅读
    

  • 本系列下一节《结构化提问》会给出一个稳定的提问骨架——角色、任务、背景、要求、格式，让你能批量产出高质量 prompt。
    • 

  • 推荐主题：搜索"提示词工程指南 中文版"或 "Prompt Engineering Guide"，能找到许多开源教程，挑你能看懂的部分阅读即可。
    • 

  • 关联学科：本节的核心其实是"清晰表达需求"的能力——这在语文议论文写作、英语作文、数学应用题表述里都是同一种底层能力。
    • 

  • 升学衔接：进入大学和职场后，AI 将成为日常工作的常规工具，本章的训练就是为那个阶段提前做准备。
    • 



小结
    

  • Prompt 工程 = 有意识地设计提问，把 AI 的输出潜力榨出来。
    • 

  • AI 不是搜索引擎，它依赖你给的上下文做推理；猜得越少，答得越准。
    • 

  • 输出质量 ≈ f(模型能力, 提问清晰度, 上下文充分性)——可控的是后两项。
    • 

  • 高一最值得用 prompt 工程的场景：议论文素材、英语阅读、数学错题、研究性学习、综评材料。
    • 

  • 普通问法和工程化问法的输出质量差距可能十倍以上，这种差距完全来自提问者，而不是模型。
    •
