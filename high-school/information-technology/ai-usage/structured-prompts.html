高一 (Year 1)高一信息科技 简介AI 使用 简介Untitled

知识要点

结构化提问的核心想法是：把每次提问拆解成五个固定字段——角色（Role）、任务（Task）、背景（Background）、要求（Requirement）、格式（Format）——按这个骨架填空，问题质量会立刻上一个台阶。这不是教条，而是经过大量实践验证的"懒人公式"：当你不知道怎么开口时，按这五个字段填一遍，往往就够用了。

  • 角色：让 AI 扮演什么人（特级语文教师 / 雅思考官 / 高中数学竞赛教练）
  • 任务：你要它具体干什么（润色一段文字 / 解释一道题 / 给三个素材）
  • 背景：你是谁、为什么需要（高一学生 / 准备综评材料 / 时间紧）
  • 要求：质量标准（不要俗套 / 避免某种风格 / 限定字数）
  • 格式：输出形式（表格 / 列表 / 三段对照 / Markdown）

学完本节，你需要能闭着眼睛在 30 秒内把任何一个学习需求填进这五个字段——这就是"prompt 工程肌肉记忆"的起点。

详细讲解

为什么是这五个字段

你可以把每次提问想象成给一个新入职的实习生交代工作。如果只丢一句"帮我写点东西"，实习生只能蒙；但如果按下面这张表填好，他立刻就能开工：

字段 实习生场景的对应物 缺失时 AI 的表现
角色 这个工作需要什么专业身份 用最普通的常识性回答
任务 具体要交付什么 答非所问或太宽泛
背景 这件事的来龙去脉 给出不符合场景的建议
要求 老板对质量的额外标准 写出能用但不出彩的版本
格式 交付物长什么样 给一大段连贯文字，难以使用

这五个字段并不需要每次都全部填——简单任务填三个就够，复杂任务全填上。但起步阶段建议每个都尝试写一遍，形成肌肉记忆。

模板与对照示例

下面给出一个可以直接复制的模板：

【角色】请你扮演 ________。
【任务】我需要你帮我 ________。
【背景】我是 ________，目的是 ________。
【要求】请注意 ________。
【格式】请按 ________ 的形式输出。

来看一个完整对照——主题："英语作文怎么开头能拿高分"。

普通问法：

英语作文怎么开头能写好？

AI 会给你一段泛泛的写作建议，看起来都对，但没法直接用。

结构化问法：

【角色】请你扮演一位高考英语阅卷老师，有十年评分经验。
【任务】帮我点评并改写一篇英语作文的开头段。
【背景】我是高一学生，下周英语月考，开头段经常被扣分。
【要求】
  - 指出原段落的三个问题（不要笼统说"不够生动"，要具体到句子）
  - 给出两个改写版本：一个偏稳健、一个偏出彩
  - 用语难度控制在高一水平，不要出现 GRE 词汇
【格式】先列三个问题（编号），再分两栏展示改写版本。

我的原段落：
"With the development of society, more and more people use smartphones. Smartphones bring us convenience but also bring us problems."

第二种问法 AI 几乎不可能糊弄过去——它必须分析具体句子、给两版改写、用高一难度。

字段填写的实操技巧

实操中常见的坑：


    

  1. "角色"字段不要太抽象——"语文老师"不如"特级语文教师，擅长议论文教学"。
    2. 

  2. "要求"字段优先写"不要什么"——AI 默认会给最保险的输出，所以"不要俗套素材"比"要好素材"更管用。
    3. 

  3. "格式"字段要落到可见结构——"分点列出" / "用表格" / "先 A 再 B" 都比"清晰一点"具体。
    4. 

  4. "背景"不必长——一两句话点明身份和场景即可，不要写成自我介绍。
    5.

真实案例：研究性学习开题
【角色】请你扮演一位高中研究性学习指导老师，熟悉课题立项流程。
【任务】帮我把一个粗略的研究兴趣转化为可立项的研究课题。
【背景】我是高一学生，对短视频对同学注意力的影响感兴趣，想做研究性学习课题，时间是一学期。
【要求】
  - 课题名字要具体，避免"短视频对青少年的影响"这种宽泛标题
  - 研究方法要可在校园内执行，不要需要专业实验设备的方案
  - 给出三个备选方向，每个标注难度（容易 / 中等 / 难）
【格式】用表格，列：课题名、研究问题、方法、难度、可能的困难
这种 prompt 几乎能直接拿去和指导老师讨论——AI 不再是答非所问的对话伙伴，而是一个可控的脚手架生成器。


练习与思考
    

  1. 把你最近问过 AI 的三个问题改写成结构化版本，用同一个 AI 重新问一次，对比前后差距。
    2. 

  2. 设计一个"英语作文开头改写"的结构化 prompt，要求 AI 必须给出两版（稳健 + 出彩），自己用学过的英语作文测试一遍。
    3. 

  3. 思考：哪些场景下"角色"字段可以省略？哪些场景下不能省略？
    4. 

  4. 找一道你做错的数学题，用本节的五字段模板写一个 prompt，让 AI 帮你分析错因。
    5. 



拓展阅读
    

  • 下一节《示例驱动提问》会教你怎样用一两个范例进一步提升输出质量——结构化骨架 + 示例 = 当前最强组合拳。
    • 

  • 关联：本节五字段法其实和议论文写作的"是什么—为什么—怎么办"框架是同源的——清晰表达需求是一种跨场景的能力。
    • 

  • 推荐查阅：网络上常被提及的"CRISPE 框架"（Capacity, Role, Insight, Statement, Personality, Experiment）和本节五字段法本质相同，只是分类略有差异。
    • 

  • 进阶视角：当 prompt 长到一定程度（比如超过 200 字），可以考虑在最开头加一行"我接下来会按角色/任务/背景/要求/格式说明这个任务，请你按整体理解后再回答"，让 AI 不要边读边答。
    • 



小结
    

  • 结构化提问把任意需求拆成五个字段：角色、任务、背景、要求、格式。
    • 

  • 简单任务可省略，但每个字段都值得在脑中过一遍，看看是否会改变输出。
    • 

  • "要求"字段优先写"不要什么"——堵死偷懒空间比鼓励发挥更有效。
    • 

  • "格式"字段要落到可见的可视结构（表格 / 编号 / 多栏）。
    • 

  • 越可量化的要求，输出可控度越高。
    • 

  • 这一节是 prompt 工程的"硬骨架"；下一节会教你给骨架配示例，进一步逼近你想要的风格。
