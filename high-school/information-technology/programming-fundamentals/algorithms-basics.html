高一信息技术 — 算法基础与流程图

知识要点

算法是解决问题的有限步骤序列，是计算机科学的核心概念之一。在日常生活中，我们其实时刻都在运用算法思维——从规划上学路线到制定考试复习计划，这些都可以抽象为算法问题。理解算法的基本概念，是学习编程和计算思维的第一步。

算法具有五个基本特征：有穷性（在有限步骤内完成）、确定性（每一步操作明确无歧义）、可行性（每一步都可以实际执行）、输入（有零个或多个输入）和输出（有一个或多个输出）。掌握这五个特征，可以帮助我们判断一个解决方案是否构成合格的算法。

流程图是算法的图形化表示方式，它用标准化的图形符号直观地展示算法的执行过程。与自然语言描述相比，流程图更加精确、清晰，能够避免语言的模糊性。流程图与伪代码、程序代码一起，构成了算法表示的三种主要方式。

详细讲解

算法的概念与日常实例

算法这个词源于九世纪波斯数学家花拉子密（al-Khwarizmi）的名字。简单来说，算法就是为解决特定问题而设计的一系列有序操作步骤。

以"泡一杯茶"为例，其算法可以描述为：（1）准备茶杯和茶叶；（2）烧开水；（3）将茶叶放入杯中；（4）倒入开水；（5）等待3-5分钟；（6）取出茶叶，完成。这个过程满足有穷性（6步完成）、确定性（每步操作明确）、可行性（每步都可执行）等算法特征。

再看一个数学实例：求1到100的整数之和。

方法一（逐一累加法）：从1开始，依次加2、加3……直到加100。这需要99次加法运算。

方法二（高斯求和法）：利用等差数列求和公式 S = n(n+1)/2 = 100×101/2 = 5050。只需一次乘法和一次除法。

两种方法都能得到正确结果，但效率差异巨大。这引出了一个重要概念——算法效率，即用尽可能少的步骤完成任务。

算法的三种基本结构

所有算法都可以由三种基本结构组合而成，这是结构化程序设计的基础：

顺序结构：按照语句的书写顺序依次执行，是最简单的结构。例如计算长方形面积：输入长a和宽b，计算S=a×b，输出S。三个步骤按顺序逐一执行。

选择结构（分支结构）：根据条件判断的结果选择不同的执行路径。例如判断一个数的奇偶性：输入整数n，若n除以2余数为0则输出"偶数"，否则输出"奇数"。选择结构有单分支（if）、双分支（if-else）和多分支（if-elif-else）三种形式。

循环结构：在满足某个条件时重复执行一段操作。例如计算1到100的累加和：设置初始值sum=0和i=1，当i≤100时执行sum=sum+i和i=i+1，循环结束后输出sum。循环结构有"当型循环"（先判断后执行）和"直到型循环"（先执行后判断）两种。

流程图的标准符号

流程图使用国际标准化组织（ISO）规定的图形符号：

符号名称 图形形状 用途说明
起止框 圆角矩形 表示算法的开始或结束
处理框 矩形 表示计算、赋值等处理操作
判断框 菱形 表示条件判断，有"是"和"否"两个出口
输入输出框 平行四边形 表示数据的输入或输出
流程线 带箭头的线 表示算法的执行方向
连接点 小圆圈 用于连接流程图的不同部分

绘制流程图时需要遵循以下规范：（1）流程线的方向一般从上到下、从左到右；（2）判断框必须有两个出口，分别标注"是/否"或"Y/N"；（3）起止框在流程图的开头和结尾各出现一次；（4）每个处理框只有一个入口和一个出口。

流程图实例分析

实例一：判断闰年

判断某年份year是否为闰年的规则是：能被4整除但不能被100整除，或者能被400整除。

流程图的设计思路：

  1. 开始 → 输入年份year
  2. 判断 year%400==0？若是 → 输出"闰年" → 结束
  3. 若否 → 判断 year%4==0 且 year%100≠0？若是 → 输出"闰年" → 结束
  4. 若否 → 输出"平年" → 结束

实例二：求三个数中的最大值

输入三个数a、b、c，找出其中的最大值：

  1. 开始 → 输入a, b, c
  2. 令max=a
  3. 判断b>max？若是，令max=b
  4. 判断c>max？若是，令max=c
  5. 输出max → 结束

这个算法使用了"打擂台"思想：先假设第一个数最大，然后逐一与其他数比较，如果发现更大的就替换。

从流程图到伪代码

伪代码是介于自然语言和程序语言之间的一种算法描述方式，它使用类似程序语言的结构但不受严格语法约束。

以求1到n的累加和为例：

输入: n
设置 sum = 0
设置 i = 1
当 i <= n 时:
    sum = sum + i
    i = i + 1
输出 sum

伪代码的优势在于：比自然语言更精确，比流程图更简洁，比程序代码更易读。在实际开发中，程序员经常先用伪代码理清思路，再翻译成具体的编程语言。

算法效率的初步认识

衡量算法效率主要看两个指标：时间复杂度（执行步骤的数量级）和空间复杂度（占用存储空间的数量级）。

以查找为例，在一个有1000个元素的有序列表中查找某个数：

  • 顺序查找：从头到尾逐一比较，最坏情况需要比较1000次
  • 二分查找：每次将范围缩小一半，最多只需要比较约10次（log⁡2\log_2log2​1000≈10）

二分查找的效率远高于顺序查找，这就是算法优化的价值。选择合适的算法，可以将原本需要数小时的计算缩短到几秒钟。

练习与思考

  1. 请用自然语言描述"在一组数中找出最小值"的算法，并指出该算法的五个特征分别如何体现。

  2. 画出如下算法的流程图：输入一个正整数n，判断它是否为质数（素数）。提示：质数是只能被1和自身整除的大于1的正整数。

  3. 有一个经典问题"鸡兔同笼"：笼中有鸡和兔共35只，脚共94只，问鸡和兔各有多少只？请用流程图表示求解算法。

  4. 比较以下两种求最大公约数的算法，哪种效率更高？

    • 方法A：从较小数开始逐一递减尝试，找到第一个能同时整除两数的数
    • 方法B：辗转相除法（欧几里得算法），用较大数除以较小数取余数，再用较小数除以余数，直到余数为0

  5. 思考题：生活中哪些场景可以用选择结构来描述？哪些场景可以用循环结构来描述？各举两个例子并尝试画出流程图。

拓展阅读

算法思维不仅仅是计算机科学的专属工具。在数学中，辗转相除法（求最大公约数）已有两千多年历史；在生物学中，DNA的复制过程可以看作一种精确的"生物算法"；在经济学中，博弈论中的策略选择本质上也是算法问题。

如果你对算法感兴趣，可以了解一下"排序算法"的世界——冒泡排序、选择排序、插入排序等经典算法各有特色。网上有许多算法可视化网站（如VisuAlgo），能够动态展示算法的执行过程，非常适合初学者理解算法的工作原理。

此外，国际信息学奥林匹克竞赛（IOI）和全国青少年信息学奥林匹克竞赛（NOIP）都是以算法为核心的竞赛，有兴趣的同学可以通过这些竞赛深入学习算法知识。

小结

本节课我们学习了算法的基本概念和五个特征，掌握了顺序、选择、循环三种基本结构，熟悉了流程图的标准符号和绘制规范。算法是程序设计的灵魂，理解算法思维不仅有助于后续的编程学习，更能培养我们系统化、结构化地解决问题的能力。下一节课我们将进入Python编程语言的学习，将算法转化为可执行的程序代码。
