高一信息技术 — 数据结构入门

知识要点

想象你要管理全班50位同学的考试成绩——如果每个人的成绩都用一个独立变量存储，你需要写50个变量名，查找和排序都极其困难。数据结构就是解决这类问题的工具——它研究如何在计算机中高效地组织、存储和操作数据。选择合适的数据结构，往往比优化算法本身更能提升程序的性能。

常见数据结构概览：

数据结构 特点 适用场景 Python实现
数组/列表 连续存储，按索引访问 需要快速按位置访问的数据 list
栈 后进先出（LIFO） 撤销操作、表达式求值、递归 list（用append/pop）
队列 先进先出（FIFO） 排队系统、广度优先搜索 collections.deque
字典 键值对存储，按键快速查找 通讯录、词频统计、配置信息 dict
集合 无序、不重复的元素集 去重、集合运算 set

数据结构与算法密不可分——好的算法往往建立在合适的数据结构之上。正如著名计算机科学家尼古拉斯·沃斯所说："程序 = 数据结构 + 算法"。

详细讲解

一、列表——最基本的线性结构

列表（在其他语言中常称为数组）是最基本也是最常用的数据结构。Python的列表功能强大，可以存储不同类型的元素。

列表的基本操作：

fruits = ["苹果", "香蕉", "橙子", "葡萄"]
print(fruits[0])
print(fruits[-1])
fruits.append("西瓜")
fruits.insert(1, "草莓")
fruits.remove("香蕉")
sliced = fruits[1:3]

列表的遍历：

scores = [92, 85, 78, 96, 63, 88, 71]

for score in scores:
    print(score)

for i, score in enumerate(scores):
    print(f"第{i+1}位同学：{score}分")

列表推导式——Pythonic的创建方式：

squares = [x ** 2 for x in range(1, 11)]

even_numbers = [x for x in range(1, 101) if x % 2 == 0]

matrix = [[0] * 3 for _ in range(3)]

列表的时间复杂度：

操作 时间复杂度 说明
按索引访问 list[i] O(1)O(1)O(1) 直接计算内存地址
末尾添加 append() O(1)O(1)O(1) 直接在末尾追加
插入 insert(i, x) O(n)O(n)O(n) 需要移动后续元素
删除 remove(x) O(n)O(n)O(n) 需要查找元素并移动
查找 x in list O(n)O(n)O(n) 需要逐一比较

二、栈——后进先出的容器

栈（Stack）是一种特殊的线性结构，只允许在一端（栈顶）进行插入和删除操作。

栈的核心特征：后进先出（LIFO, Last In First Out）

想象一摞盘子：你只能从最上面放盘子，也只能从最上面取盘子——最后放上去的盘子总是最先被取下来。

用Python列表模拟栈：

stack = []
stack.append("A")
stack.append("B")
stack.append("C")
print(stack)

top = stack.pop()
print(f"弹出：{top}")
print(f"栈顶：{stack[-1]}")
print(f"栈是否为空：{len(stack) == 0}")

栈的经典应用——括号匹配：

检查一个表达式中的括号是否正确匹配：

def check_brackets(expression):
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}
    for char in expression:
        if char in '([{':
            stack.append(char)
        elif char in ')]}':
            if not stack or stack[-1] != pairs[char]:
                return False
            stack.pop()
    return len(stack) == 0

print(check_brackets("(a + b) * [c - d]"))
print(check_brackets("(a + b] * c"))

栈的其他应用：

  • 浏览器的"后退"功能——每访问一个页面就压入栈中，点击后退就弹出栈顶
  • 文本编辑器的"撤销"功能——每次操作压栈，撤销时弹出
  • 函数调用——程序执行时的调用栈记录函数调用层次

三、队列——先进先出的容器

队列（Queue）与栈相反，遵循先进先出（FIFO, First In First Out）原则。

队列的核心特征：先进先出（FIFO）

就像食堂排队打饭：先来的人先打饭离开，后来的人排在队尾等待。

用Python实现队列：

from collections import deque

queue = deque()
queue.append("张三")
queue.append("李四")
queue.append("王五")
print(f"排队中：{list(queue)}")

served = queue.popleft()
print(f"叫号：{served}")
print(f"剩余：{list(queue)}")

队列的应用场景：

  • 打印任务排队——多个打印请求按先后顺序处理
  • 消息队列——网络通信中消息按发送顺序传递
  • 广度优先搜索——逐层探索图或树的节点

四、字典——键值对的快速查找

字典（Dictionary）使用键值对（key-value pair）存储数据，通过键快速查找对应的值。

字典的基本操作：

student = {
    "name": "李华",
    "age": 16,
    "grade": "高一",
    "scores": {"语文": 92, "数学": 88, "英语": 95}
}

print(student["name"])
print(student.get("phone", "未登记"))
student["phone"] = "13800138000"

for key, value in student.items():
    print(f"{key}: {value}")

字典的经典应用——词频统计：

text = "to be or not to be that is the question"
words = text.split()
freq = {}
for word in words:
    freq[word] = freq.get(word, 0) + 1

for word, count in sorted(freq.items(), key=lambda x: x[1], reverse=True):
    print(f"{word}: {count}次")

字典的时间复杂度：

操作 时间复杂度 说明
按键查找 dict[key] O(1)O(1)O(1) 哈希表实现，直接定位
插入/修改 dict[key] = value O(1)O(1)O(1) 哈希计算后直接写入
删除 del dict[key] O(1)O(1)O(1) 标记删除
遍历 O(n)O(n)O(n) 需要遍历所有键值对

字典的高效查找是其最大优势——无论字典中有100个还是100万个元素，按键查找的速度几乎相同。

五、集合——去重与集合运算

集合（Set）是无序的、不重复的元素集合。

numbers = [1, 2, 2, 3, 3, 3, 4, 5]
unique = set(numbers)
print(unique)

set_a = {1, 2, 3, 4, 5}
set_b = {4, 5, 6, 7, 8}
print(f"交集：{set_a & set_b}")
print(f"并集：{set_a | set_b}")
print(f"差集：{set_a - set_b}")

六、如何选择数据结构

面对一个具体问题，选择合适的数据结构是程序设计的关键决策：

需求 推荐数据结构 理由
有序存储，按位置访问 列表 支持索引，顺序明确
后进先出的操作 栈 只在一端操作
先进先出的排队 队列 两端操作：入队在尾，出队在头
按名称快速查找 字典 键值对映射，查找 O(1)O(1)O(1)
去重或集合运算 集合 自动去重，支持交并差
存储层级关系 树（进阶） 如文件目录、组织架构

练习与思考

  1. 列表应用：编写程序，输入一组整数（以-1结束），存入列表后输出：（a）所有元素（b）最大值和最小值（c）逆序排列的结果。

  2. 栈应用：利用栈实现十进制转二进制的功能。提示：将十进制数不断除以2，把余数压入栈中，最后依次弹出即为二进制。

  3. 字典应用：编写一个简单的英汉词典程序——预先存入10个单词和中文释义，用户输入单词后查找并显示释义，如果查不到则提示"未收录"。

  4. 综合设计：某超市收银台模拟：顾客按到达顺序排队（队列），VIP顾客优先服务。请设计数据结构和算法来模拟这个场景。

  5. 思考题：为什么字典的查找速度比列表快得多？列表按值查找需要逐一比较（O(n)O(n)O(n)），而字典按键查找只需 O(1)O(1)O(1)，这背后的原理（哈希）是什么？

拓展阅读

数据结构是计算机科学的核心课程之一。高中阶段我们学习的列表、栈、队列、字典只是冰山一角——在大学的数据结构课程中，你还会接触到链表、树（二叉树、红黑树、B树）、图、堆、哈希表等更高级的数据结构，以及它们对应的各种算法。

在实际软件开发中，数据结构的选择直接影响程序的性能。例如，搜索引擎的核心就是高效的数据结构——Google用倒排索引（一种特殊的字典结构）在零点几秒内从数十亿网页中找到你需要的信息。社交网络中的好友推荐使用图数据结构来分析人际关系。

推荐进一步学习：

  • 可视化数据结构网站（如VisuAlgo）
  • Python标准库中的collections模块
  • 信息学竞赛中的经典数据结构题目

小结

数据结构是组织和管理数据的方式，直接决定了程序的效率和可维护性。本节课我们学习了列表（按位置访问）、栈（后进先出）、队列（先进先出）、字典（键值对快速查找）和集合（去重与集合运算）五种基本数据结构。掌握这些数据结构及其适用场景，是编写高质量程序的基础。下一章我们将学习网络基础知识，了解计算机是如何通过网络实现互联互通的。
