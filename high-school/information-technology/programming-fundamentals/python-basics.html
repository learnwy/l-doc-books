高一信息技术 — Python基础

知识要点

上节课我们学习了算法和流程图，掌握了用图形化方式描述解决问题的步骤。现在，是时候将这些算法思想转化为计算机能够执行的代码了。Python是当今世界上最流行的编程语言之一，以语法简洁、易于上手著称——它的设计哲学就是"优美胜于丑陋，简洁胜于复杂"。

Python语言的核心要素：

要素 说明 示例
变量 存储数据的"容器"，可以随时改变内容 name = "张三"
数据类型 数据的种类，决定了数据的存储方式和运算规则 整数int、浮点数float、字符串str、布尔值bool
运算符 对数据进行操作的符号 +、-、*、/、//、%、**
输入输出 与用户交互的基本方式 input()获取输入、print()输出结果
控制结构 控制程序执行流程 if-elif-else选择、for/while循环

为什么选择Python作为入门语言？

  • 语法接近自然语言，降低学习门槛
  • 不需要声明变量类型（动态类型语言）
  • 用缩进表示代码块，代码结构清晰
  • 拥有丰富的标准库和第三方库
  • 广泛应用于数据科学、人工智能、Web开发等领域

详细讲解

一、Python基本语法

变量与赋值：

在Python中，创建变量不需要提前声明类型，直接用等号赋值即可：

age = 16
height = 1.72
name = "李华"
is_student = True

变量命名规则：

  • 只能包含字母、数字和下划线，且不能以数字开头
  • 区分大小写（Age和age是不同的变量）
  • 不能使用Python关键字（如if、for、while等）
  • 建议使用有意义的名称（如student_name而非a）

数据类型：

类型 英文名 说明 示例
整数 int 没有小数部分的数 42、-7、0
浮点数 float 带小数部分的数 3.14、-0.5、1.0
字符串 str 用引号括起来的文本 "Hello"、'Python'
布尔值 bool 逻辑值，只有两个取值 True、False
列表 list 有序的可变集合 [1, 2, 3]、["a", "b"]

类型转换：

num_str = "123"
num_int = int(num_str)
num_float = float(num_str)
back_to_str = str(num_int)

二、输入与输出

输出——print()函数：

print("你好，世界！")
print("我今年", 16, "岁")
print(f"圆周率约等于{3.14159:.2f}")

f-string（格式化字符串）是Python 3.6引入的特性，用花括号{}嵌入变量或表达式，非常实用。

输入——input()函数：

name = input("请输入你的名字：")
age = int(input("请输入你的年龄："))
print(f"{name}，你好！你明年{age + 1}岁。")

input()返回的始终是字符串类型，如果需要数值运算必须用int()或float()转换。

三、运算符

算术运算符：

运算符 含义 示例 结果
+ 加法 7 + 3 10
- 减法 7 - 3 4
* 乘法 7 * 3 21
/ 除法（结果为浮点数） 7 / 3 2.333...
// 整除（取商的整数部分） 7 // 3 2
% 取余（取余数） 7 % 3 1
** 幂运算 2 ** 10 1024

比较运算符：

==（等于）、!=（不等于）、>、<、>=、<=

比较运算的结果是布尔值True或False。

逻辑运算符：

and（与）、or（或）、not（非）

age = 16
is_student = True
print(age >= 18 and is_student)
print(age >= 18 or is_student)
print(not is_student)

四、选择结构

Python用if-elif-else实现分支选择，注意缩进是Python的语法要求：

score = int(input("请输入成绩："))
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")

嵌套选择：

year = int(input("请输入年份："))
if year % 400 == 0:
    print(f"{year}年是闰年")
elif year % 4 == 0 and year % 100 != 0:
    print(f"{year}年是闰年")
else:
    print(f"{year}年是平年")

五、循环结构

for循环：

for循环用于遍历序列（如列表、字符串、range对象）：

for i in range(1, 11):
    print(i, end=" ")

total = 0
for i in range(1, 101):
    total += i
print(f"1到100的和是{total}")

range(start, stop, step)生成从start到stop-1的整数序列，step是步长（默认为1）。

while循环：

while循环在条件为True时反复执行：

count = 1
total = 0
while count <= 100:
    total += count
    count += 1
print(f"1到100的和是{total}")

循环控制：

  • break：立即退出整个循环
  • continue：跳过本次循环的剩余部分，进入下一次循环
for i in range(1, 101):
    if i % 7 == 0:
        continue
    print(i, end=" ")

六、列表基础

列表是Python中最常用的数据结构，用方括号[]表示：

scores = [92, 85, 78, 96, 63]
print(scores[0])
print(len(scores))
scores.append(88)
scores.sort()
print(scores)
操作 语法 说明
访问元素 list[index] 索引从0开始
添加元素 list.append(item) 在末尾添加
删除元素 list.remove(item) 删除第一个匹配项
排序 list.sort() 升序排列
长度 len(list) 返回元素个数
切片 list[start:end] 获取子列表

七、函数初步

函数是组织好的、可重复使用的代码块。用def关键字定义：

def greet(name):
    return f"你好，{name}！"

def calculate_bmi(weight, height):
    bmi = weight / (height ** 2)
    return round(bmi, 1)

print(greet("李华"))
print(f"BMI = {calculate_bmi(65, 1.72)}")

函数的好处：

  • 代码复用——相同逻辑只需写一次
  • 结构清晰——将复杂问题分解为多个函数
  • 便于调试——可以单独测试每个函数

练习与思考

  1. 基础练习：编写一个程序，输入三角形的三条边长，判断是否能构成三角形（任意两边之和大于第三边），如果能则计算面积（海伦公式：S=s(s−a)(s−b)(s−c)S = \sqrt{s(s-a)(s-b)(s-c)}S=s(s−a)(s−b)(s−c)​，其中 s=a+b+c2s = \frac{a+b+c}{2}s=2a+b+c​）。

  2. 循环应用：编写程序求1000以内所有"水仙花数"。水仙花数是指一个三位数，其各位数字的立方和等于该数本身（如 153=13+53+33153 = 1^3 + 5^3 + 3^3153=13+53+33）。

  3. 列表操作：输入10个学生的成绩存入列表，计算平均分、最高分、最低分，并统计不及格（<60）的人数。

  4. 函数设计：编写一个函数is_prime(n)，判断正整数n是否为质数，然后调用该函数输出100以内的所有质数。

  5. 综合题：编写一个简单的"猜数字"游戏：程序随机生成1-100之间的整数，用户反复猜测，程序提示"猜大了"或"猜小了"，直到猜对为止，并显示猜了多少次。

拓展阅读

Python由荷兰程序员吉多·范罗苏姆（Guido van Rossum）在1989年圣诞节假期开始开发，名字来源于他喜爱的英国喜剧团体"蒙提·派森"（Monty Python）。如今Python已成为全球使用最广泛的编程语言之一——从NASA的火星探测器数据分析到Instagram的后端服务，从AlphaGo的深度学习训练到学术论文的数据可视化。

Python的哲学理念可以通过在Python解释器中输入import this来查看——"The Zen of Python"包含了19条编程格言，其中最核心的是"Simple is better than complex"（简洁胜于复杂）。

推荐练习平台：

  • Luogu（洛谷）：适合算法入门和竞赛练习
  • LeetCode：全球最大的编程题库
  • Python官方教程（docs.python.org）

小结

Python以简洁易读的语法降低了编程的入门门槛。本节课我们学习了变量与数据类型、输入输出、运算符、选择结构（if-elif-else）、循环结构（for和while）、列表基础和函数定义。这些知识构成了Python编程的基本工具箱，掌握它们就能编写出解决实际问题的程序。下一节我们将学习数据结构的入门知识，了解如何更高效地组织和管理数据。
