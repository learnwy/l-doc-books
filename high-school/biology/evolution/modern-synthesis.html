高二生物 — 现代综合进化论

知识要点

现代综合进化论（也称现代达尔文主义）是在达尔文自然选择学说基础上，融合遗传学、群体遗传学和古生物学等学科发展而来的进化理论。它将进化的研究单位从个体转向种群，将进化的实质定义为种群基因频率的改变，弥补了达尔文无法解释遗传和变异机制的重大缺陷。

概念 定义
种群 生活在一定区域内、同种个体的集合，是进化的基本单位
基因库 一个种群中全部个体所含有的全部基因的总和
基因频率 某个基因在种群中出现的比例
基因型频率 某种基因型在种群中出现的比例
遗传漂变 小种群中基因频率的随机波动
基因流 种群之间因个体迁移导致的基因交流

详细讲解

一、种群是进化的基本单位

达尔文将进化的讨论集中在个体层面，但现代进化论指出：个体不能进化，进化是种群的属性。一个个体的基因型在出生时就已确定，不会改变；而种群的基因组成可以在世代间发生变化。

种群的特征：

  • 同一物种的个体组成
  • 占据一定的地理空间
  • 个体之间能够相互交配并产生可育后代
  • 具有共同的基因库

二、基因频率与基因型频率

设一个种群中，某基因座上有两个等位基因 AAA 和 aaa，基因频率分别为 ppp 和 qqq（p+q=1p + q = 1p+q=1）。

基因频率的计算方法：

p(A)=2×AA个体数+Aa个体数2×种群总个体数p(A) = \frac{2 \times AA\text{个体数} + Aa\text{个体数}}{2 \times \text{种群总个体数}}p(A)=2×种群总个体数2×AA个体数+Aa个体数​

例题：某种群有 100100100 个个体，其中 AAAAAA 型 303030 个，AaAaAa 型 606060 个，aaaaaa 型 101010 个。

p(A)=2×30+602×100=120200=0.6p(A) = \frac{2 \times 30 + 60}{2 \times 100} = \frac{120}{200} = 0.6p(A)=2×1002×30+60​=200120​=0.6
q(a)=2×10+602×100=80200=0.4q(a) = \frac{2 \times 10 + 60}{2 \times 100} = \frac{80}{200} = 0.4q(a)=2×1002×10+60​=20080​=0.4

验证：p+q=0.6+0.4=1p + q = 0.6 + 0.4 = 1p+q=0.6+0.4=1 ✓

三、哈迪-温伯格定律

在满足以下五个条件的理想种群中，基因频率和基因型频率世代不变：

  1. 种群足够大
  2. 随机交配
  3. 没有自然选择
  4. 没有突变
  5. 没有迁移（基因流）

此时基因型频率分布为：

p2(AA)+2pq(Aa)+q2(aa)=1p^2(AA) + 2pq(Aa) + q^2(aa) = 1p2(AA)+2pq(Aa)+q2(aa)=1

其中 ppp 为 AAA 的频率，qqq 为 aaa 的频率。

哈迪-温伯格定律的意义：它提供了一个理论基准——如果实际种群偏离了这个比例，就说明有某种进化力量在起作用。

例题应用：某种群中隐性性状（aaaaaa）的比例为 16%16\%16%。

q2=0.16  ⟹  q=0.4  ⟹  p=0.6q^2 = 0.16 \implies q = 0.4 \implies p = 0.6q2=0.16⟹q=0.4⟹p=0.6
AA的频率=p2=0.36=36%AA\text{的频率} = p^2 = 0.36 = 36\%AA的频率=p2=0.36=36%
Aa的频率=2pq=0.48=48%Aa\text{的频率} = 2pq = 0.48 = 48\%Aa的频率=2pq=0.48=48%

四、进化的驱动力

现代综合进化论认为，五种力量可以改变种群的基因频率：

（1）突变

基因突变和染色体变异为进化提供原始材料。突变是随机的、不定向的，大多数突变是中性或有害的，但极少数有利突变可被自然选择保留。

突变率虽低（通常每代每基因位点 10−5∼10−610^{-5} \sim 10^{-6}10−5∼10−6），但由于基因位点数量巨大，种群中每一代都会产生相当数量的新突变。

（2）自然选择

自然选择是唯一的定向进化因素，能系统地改变基因频率。

选择类型 效果 举例
稳定化选择 淘汰极端表现型，维持中间类型 人类新生儿体重约 3∼4 kg3 \sim 4\,\text{kg}3∼4kg 存活率最高
定向选择 偏向某一极端方向 工业黑化的桦尺蛾
分裂性选择 两个极端方向都被保留 非洲维多利亚湖的慈鲷鱼体色分化

（3）遗传漂变

在小种群中，基因频率可能因随机抽样效应而发生显著波动，与自然选择无关。这称为遗传漂变（genetic drift）。

瓶颈效应：种群经历急剧缩小后，幸存个体的基因频率可能与原种群差异很大。

建立者效应：少数个体迁入新地区建立新种群，其基因频率可能与源种群不同。

（4）基因流

种群之间的个体迁移导致基因在种群间传递。基因流使不同种群的基因频率趋于一致，对抗种群分化。

（5）非随机交配

近亲交配增加纯合体比例，降低杂合体比例。性选择也是非随机交配的一种形式——特定性状的个体更受异性青睐。

五、突变和基因重组提供进化的原材料

突变（基因突变和染色体变异）是产生新基因和新基因型的源泉。但突变本身频率低、方向随机，不能决定进化方向。

基因重组（自由组合和交叉互换）极大地增加了基因型的多样性。假设有 nnn 对独立的等位基因，仅自由组合就可产生 2n2^n2n 种配子类型和 3n3^n3n 种基因型。

进化的原材料 = 突变 + 基因重组

来源 产生方式 效果
基因突变 DNA 复制错误 产生新基因（新等位基因）
染色体变异 结构或数目改变 改变基因的排列或剂量
基因重组 减数分裂中的自由组合和交叉互换 产生新的基因型组合

六、自然选择决定进化方向

虽然突变是随机的，但自然选择的筛选作用使得有利突变的频率不断升高，有害突变的频率不断降低。因此，自然选择决定了进化的方向。

以一个具体案例说明：假设某昆虫种群中，抗药性基因 RRR 的初始频率为 0.010.010.01。使用杀虫剂后，不含 RRR 基因的个体大量死亡，RRR 基因的频率迅速升高。若干代后 RRR 基因频率可能达到 0.90.90.9 以上——这就是自然选择定向改变基因频率的过程。

拓展阅读

现代综合进化论的形成经历了数十年。20 世纪初，孟德尔遗传学的重新发现与达尔文进化论之间一度被认为是矛盾的（早期遗传学家认为突变才是进化的主要动力，否定自然选择的渐变论）。直到费希尔、霍尔丹和赖特等群体遗传学家证明：小的基因频率变化在自然选择下可以累积为显著的表型变化，两大理论才被成功融合。

1942 年赫胥黎出版的《进化：现代综合》标志着这一理论框架的正式确立。迈尔强调了地理隔离在物种形成中的关键作用，杜布赞斯基从群体遗传学角度阐释了种群层面的进化机制，辛普森从古生物学角度补充了宏观进化模式——三者合力构成了现代综合进化论的完整体系。

近年来，"扩展进化综合"（EES）理论认为表观遗传、发育可塑性和生态位构建等因素也应纳入进化框架，但这些拓展并未否定现代综合进化论的核心，而是在其基础上进一步丰富了我们对进化过程的理解。

小结

  • 种群是进化的基本单位，进化的实质是种群基因频率的改变
  • 哈迪-温伯格定律描述理想种群中基因频率的平衡条件，p2+2pq+q2=1p^2 + 2pq + q^2 = 1p2+2pq+q2=1
  • 突变和基因重组提供进化的原材料，自然选择决定进化方向
  • 遗传漂变在小种群中影响显著，基因流对抗种群分化
  • 自然选择包括稳定化选择、定向选择和分裂性选择三种模式
