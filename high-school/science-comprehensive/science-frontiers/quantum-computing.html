理科方向 理科综合 — 量子计算

知识要点

量子计算是利用量子力学原理（叠加态、纠缠态、量子干涉）进行信息处理的计算范式。与经典计算机使用二进制比特（0 或 1）不同，量子计算机使用量子比特（qubit），能同时处于 0 和 1 的叠加态，在特定问题上具有远超经典计算机的计算能力。

  • 量子比特（Qubit）：量子计算的基本信息单位。单个 qubit 的状态用 |ψ⟩ = α|0⟩ + β|1⟩ 表示，其中 α 和 β 是复数振幅，满足 |α|2{}^{2}2 + |β|2{}^{2}2 = 1。测量时以概率 |α|2{}^{2}2 得到 0，概率 |β|2{}^{2}2 得到 1。
  • 量子叠加：qubit 可以同时处于多个状态的叠加。n 个 qubit 可以同时表示 2n2^{n}2n 个状态，这是量子并行性的来源。
  • 量子纠缠：两个或多个 qubit 之间存在非经典关联。纠缠态不能分解为单个 qubit 状态的乘积，测量其中一个 qubit 会立即影响另一个的状态，无论它们相距多远。
  • 量子门与量子电路：量子计算通过量子门（酉变换）操作 qubit。常见的单量子门包括 Hadamard 门（创建叠加态）、Pauli-X 门（量子非门）、相位门等；双量子门包括 CNOT 门（受控非门）。

详细讲解

从经典比特到量子比特

经典计算机的比特是确定性的：一个比特要么是 0，要么是 1。n 个经典比特在任一时刻只能处于 2n2^{n}2n 种可能状态中的一种。

量子比特则处于叠加态。以最简单的单 qubit 为例，它的状态可以用布洛赫球（Bloch sphere）上的一个点表示。北极 |0⟩ 和南极 |1⟩ 是两个基态，球面上的任何点都是合法的量子态。这意味着一个 qubit 承载的信息量远超一个经典比特——但请注意，测量会使叠加态"坍缩"为某个确定态，我们只能获得概率性的结果。

2 个 qubit 的状态空间是四维的：|ψ⟩ = α00α_{00}α00​|00⟩ + α01α_{01}α01​|01⟩ + α10α_{10}α10​|10⟩ + α11α_{11}α11​|11⟩。一般地，n 个 qubit 的状态需要 2n2^{n}2n 个复数来描述。50 个 qubit 的完整状态向量需要存储 250≈10152^{50} ≈ 10^{15}250≈1015 个复数，这已经超出了现有经典计算机的内存容量——这正是量子优势的物理基础。

量子纠缠与贝尔态

量子纠缠是量子计算最神奇也最关键的资源。最简单的纠缠态是贝尔态：

|Φ+Φ^{+}Φ+⟩ = (1/√2)(|00⟩ + |11⟩)

在这个状态中，两个 qubit 都没有确定的值（各自测量到 0 和 1 的概率均为 50%），但它们之间存在完美的关联：如果第一个 qubit 测量到 0，第二个 qubit 必定也是 0；如果第一个是 1，第二个也必定是 1。

爱因斯坦、波多尔斯基和罗森（EPR）在 1935 年提出这种关联违反了"定域实在论"，认为量子力学不完备。但 1964 年贝尔不等式的提出，以及 1982 年阿斯佩等人的实验验证（2022 年获诺贝尔物理学奖），证实了量子纠缠是真实的物理现象，不能用经典的"隐变量"理论解释。

量子算法

Shor 算法（1994 年）：能在多项式时间内完成大整数因数分解，而目前最好的经典算法需要亚指数时间。RSA 密码系统的安全性建立在大整数因数分解的困难性之上，因此一旦大规模量子计算机实现，现有的公钥密码体系将面临威胁。

Grover 算法（1996 年）：在无序数据库中搜索目标元素。经典算法平均需要检查 N/2 个元素，Grover 算法只需约 √N 次查询——对于包含 100 万条记录的数据库，从约 50 万次减少到约 1000 次。

量子模拟：费曼在 1982 年首先提出用量子系统模拟量子系统的想法。模拟分子的量子行为（如药物分子与蛋白质的相互作用）对经典计算机极为困难，但在量子计算机上可以自然实现。这被认为是量子计算最早的实际应用方向。

量子计算的物理实现

练习与思考

  1. 一个 qubit 处于状态 |ψ⟩ = (√3/2)|0⟩ + (1/2)|1⟩。计算测量到 |0⟩ 和 |1⟩ 的概率。验证概率归一化条件。

  2. 解释为什么 n 个经典比特最多只能存储 n 比特信息，而 n 个量子比特的状态空间维度为 2n2^{n}2n。这是否意味着量子计算机可以指数级加速所有计算任务？为什么？

  3. 如果量子计算机能高效分解大整数，对现代密码学意味着什么？后量子密码学（post-quantum cryptography）提出了哪些应对方案？

  4. 量子退相干（decoherence）是量子计算面临的最大挑战之一。查阅资料解释什么是退相干，以及为什么超导量子计算机需要在接近绝对零度的环境中运行。

拓展阅读

量子信息科学已成为国际科技竞争的战略高地。中国在量子通信领域处于世界领先地位：2016 年发射的"墨子号"量子科学实验卫星实现了千公里级的量子密钥分发，京沪量子通信干线已投入运行。在量子计算方面，中国科大团队在光量子计算和超导量子计算两个方向都取得了重要突破。

量子纠错是实现实用量子计算的关键技术。由于量子比特极易受环境噪声影响，需要将多个物理 qubit 编码为一个逻辑 qubit，用冗余信息检测和纠正错误。目前估计实现有实用价值的量子计算需要数百万个物理 qubit，离实际应用还有相当距离。

对于对量子计算感兴趣的同学，推荐从 IBM Quantum Experience 平台入手，它提供免费的在线量子计算机访问和可视化量子电路编辑器，可以动手构建和运行简单的量子算法。

小结

量子计算是量子力学原理在信息技术领域的革命性应用。量子比特的叠加态和纠缠态赋予了量子计算机在特定问题上超越经典计算机的潜力。虽然大规模通用量子计算机的实现仍面临重大技术挑战，但量子计算已经在密码学、药物设计、材料科学等领域展现出巨大的应用前景。理解量子计算的基本原理，是面向未来的理科素养的重要组成部分。
