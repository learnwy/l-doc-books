高一数学 — 指数与对数函数

知识要点

指数函数与对数函数是高中数学的重要内容，两者互为反函数，在科学、工程和日常生活中有广泛应用。学习这部分内容需要掌握：指数运算的法则（包括有理数指数幂和无理数指数幂）、指数函数y = axa^xax的图像与性质、对数的概念与运算法则、对数函数y = log_a(x)的图像与性质，以及指数方程和对数方程的基本解法。

前置知识：整数指数幂的运算、幂的基本运算律。

详细讲解

一、指数运算

有理数指数幂的定义：

正整数指数：ana^nan = a × a × ... × a（n个a相乘）

零指数：a0a^0a0 = 1（a ≠ 0）

负整数指数：a−na^{-n}a−n = 1/ana^nan（a ≠ 0）

分数指数：a^(m/n) = n^nn√(ama^mam)（a > 0, m∈ℤ, n∈ℕ*, n > 1）

指数运算法则（a > 0, b > 0）：

法则 公式 示例
同底数幂相乘 ama^mam · ana^nan = am+na^{m+n}am+n 232^323 · 252^525 = 282^828
幂的幂 (ama^mam)n^nn = amna^{mn}amn (232^323)2^22 = 262^626
积的幂 (ab)n^nn = ana^nan · bnb^nbn (2·3)2^22 = 222^222 · 323^232
同底数幂相除 ama^mam / ana^nan = am−na^{m-n}am−n 252^525 / 232^323 = 222^222

二、指数函数

定义：y = axa^xax（a > 0且a ≠ 1）。

图像特征：

所有指数函数都过点(0, 1)，因为a0a^0a0 = 1。

当a > 1时：函数在ℝ上单调递增，图像从左向右上升。x→-∞时y→0（x轴是渐近线），x→+∞时y→+∞。

当0 < a < 1时：函数在ℝ上单调递减，图像从左向右下降。x→-∞时y→+∞，x→+∞时y→0。

性质总结：

定义域：ℝ；值域：(0, +∞)

过定点：(0, 1)

单调性：a > 1时递增，0 < a < 1时递减

y > 0恒成立（指数函数值永远为正）

底数a越大，图像在x > 0部分增长越快

三、对数的概念与运算

对数的定义：如果aba^bab = N（a > 0, a ≠ 1, N > 0），则b叫做以a为底N的对数，记作b = log_a(N)。

指数式与对数式是同一关系的两种表示：aba^bab = N ⟺ b = log_a(N)。

特殊对数：常用对数lg(N) = log⁡10\log_{10}log10​(N)，自然对数ln(N) = log⁡e\log_eloge​(N)（e ≈ 2.71828）。

对数运算法则（a > 0, a ≠ 1, M > 0, N > 0）：

log_a(MN) = log_a(M) + log_a(N) —— 积的对数等于对数的和

log_a(M/N) = log_a(M) - log_a(N) —— 商的对数等于对数的差

log_a(MnM^nMn) = n · log_a(M) —— 幂的对数等于指数乘以对数

换底公式：log_a(b) = log_c(b) / log_c(a)

重要恒等式：a^(log_a(N)) = N，log_a(ana^nan) = n

四、对数函数

定义：y = log_a(x)（a > 0且a ≠ 1）。

图像特征：

所有对数函数都过点(1, 0)，因为log_a(1) = 0。

当a > 1时：函数在(0, +∞)上单调递增。

当0 < a < 1时：函数在(0, +∞)上单调递减。

性质总结：

定义域：(0, +∞)；值域：ℝ

过定点：(1, 0)

x→0+0^+0+时，a > 1则y→-∞，0 < a < 1则y→+∞

五、指数函数与对数函数的关系

y = axa^xax与y = log_a(x)互为反函数，它们的图像关于直线y = x对称。

比较项目 指数函数y = axa^xax 对数函数y = log_a(x)
定义域 ℝ (0, +∞)
值域 (0, +∞) ℝ
过定点 (0, 1) (1, 0)
单调性(a>1) 递增 递增
单调性(0<a<1) 递减 递减
渐近线 y = 0 x = 0

六、典型例题

例1：化简 log⁡2\log_2log2​8 + log⁡3\log_3log3​(1/9) - log⁡5\log_5log5​1。

解：log⁡2\log_2log2​8 = log⁡223\log_22^3log2​23 = 3，log⁡3\log_3log3​(1/9) = log⁡33−2\log_33^{-2}log3​3−2 = -2，log⁡5\log_5log5​1 = 0。原式 = 3 + (-2) - 0 = 1。

例2：比较2^0.3, 0.320.3^20.32, log⁡2\log_2log2​0.3的大小。

解：2^0.3 > 202^020 = 1（指数函数a>1，递增），0.320.3^20.32 = 0.09 < 1 且 > 0，log⁡2\log_2log2​0.3 < log⁡2\log_2log2​1 = 0。故 log⁡2\log_2log2​0.3 < 0.320.3^20.32 < 2^0.3。

练习与思考

  1. 计算：(1) log⁡2\log_2log2​32; (2) lg0.01; (3) ln(e3e^3e3); (4) log⁡9\log_9log9​27。

  2. 化简：log⁡3\log_3log3​6 - log⁡3\log_3log3​2 + log⁡3\log_3log3​(1/3)。

  3. 画出y = 2x2^x2x, y = (1/2)x^xx, y = log⁡2\log_2log2​x, y = log_(1/2)(x)在同一坐标系中的图像，观察它们之间的对称关系。

  4. 已知f(x) = log_a(x-1) + 1（a > 0, a ≠ 1），若f(x)的图像过点(3, 2)，求a的值和f(x)的定义域。

拓展阅读

对数的发明被称为"将数学家的寿命延长了一倍"，因为它将乘除运算转化为加减运算，极大地简化了天文学和航海学中的大量计算。纳皮尔在17世纪初发明对数时，其计算工具——对数表和对数尺——是计算器发明前最重要的计算辅助工具。自然对数的底e是一个与π齐名的数学常数，在微积分、概率论和物理学中都有深刻的应用。

小结

指数函数和对数函数互为反函数，是高中数学中最重要的基本初等函数。指数运算法则是掌握指数函数的基础，对数运算法则是处理对数函数的工具。理解两种函数的图像和性质，关键是把握底数a与1的大小关系对函数行为的决定性影响。比较数的大小、解方程和不等式等问题中，经常需要灵活运用指数函数和对数函数的性质。
