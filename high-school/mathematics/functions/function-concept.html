高一数学 — 函数概念与性质

知识要点

函数是高中数学最核心的概念之一，是描述变量之间依赖关系的数学模型。高一阶段需要深入理解函数的现代定义（从集合与对应的角度），掌握函数的三要素（定义域、值域、对应法则），以及函数的基本性质（单调性、奇偶性、周期性）。

函数的现代定义：设A、B是两个非空数集，如果按照某种确定的对应关系f，使得对于集合A中的任意一个数x，在集合B中都有唯一确定的数f(x)和它对应，那么就称f: A→B为从集合A到集合B的一个函数，记作y = f(x), x∈A。

详细讲解

一、函数的三要素

定义域：自变量x的取值范围，即集合A。确定定义域需要考虑：分母不为零、偶次根号下非负、对数的真数大于零、实际问题中的约束条件。

值域：因变量y的取值范围。值域由定义域和对应法则共同决定。

对应法则：从x到y的对应规则f。可以用解析式、图表、图像等方式表示。

两个函数相同的条件：定义域相同且对应法则相同（值域会自动相同）。

例如：f(x) = x2x^2x2（x∈ℝ）与g(x) = x2x^2x2（x > 0）是不同的函数，因为定义域不同。

f(x) = |x|/x 与 g(x) = 符号函数 是相同的函数（对应法则实质相同）。

二、函数的单调性

定义：设函数f(x)的定义域为D，区间I⊆D。如果对于I中任意两个值x1x_1x1​、x2x_2x2​，当x1x_1x1​ < x2x_2x2​时，都有f(x1x_1x1​) < f(x2x_2x2​)，则称f(x)在区间I上是增函数。若都有f(x1x_1x1​) > f(x2x_2x2​)，则称f(x)在I上是减函数。

判断单调性的方法：

定义法（作差法）：设x1x_1x1​ < x2x_2x2​，计算f(x1x_1x1​) - f(x2x_2x2​)的符号。若f(x1x_1x1​) - f(x2x_2x2​) < 0，则f递增。

导数法（高一后期或高二学习）：f'(x) > 0则递增，f'(x) < 0则递减。

图像法：图像从左到右上升为增函数，下降为减函数。

常见函数 单调递增区间 单调递减区间
y = x2x^2x2 [0, +∞) (-∞, 0]
y = 1/x 无 (-∞, 0)和(0, +∞)各自上递减
y = √x [0, +∞) 无
y = x

注意：单调性是在某个区间上的性质，不能说"函数在x = 1处单调递增"。y = 1/x在(-∞, 0)和(0, +∞)上分别递减，但不能合并说在(-∞, 0)∪(0, +∞)上递减。

三、函数的奇偶性

偶函数：对于定义域内的任意x，都有f(-x) = f(x)。图像关于y轴对称。

奇函数：对于定义域内的任意x，都有f(-x) = -f(x)。图像关于原点对称。

判断奇偶性的前提：定义域必须关于原点对称。如果定义域不关于原点对称，函数既不是奇函数也不是偶函数。

判断步骤：

第一步：检查定义域是否关于原点对称。

第二步：计算f(-x)，与f(x)和-f(x)比较。

第三步：得出结论。

常见奇偶函数：

偶函数：y = x2x^2x2, y = |x|, y = cos x

奇函数：y = x3x^3x3, y = x, y = sin x, y = 1/x

奇偶函数的运算性质：奇 + 奇 = 奇，偶 + 偶 = 偶，奇 × 奇 = 偶，偶 × 偶 = 偶，奇 × 偶 = 奇。

四、函数的表示方法

解析法：用数学公式表示对应法则。如y = 2x + 1, y = x2x^2x2 - 3x + 2。优点是精确，便于计算和推理。

列表法：用表格列出自变量与函数值的对应关系。如气温记录表、成绩表。优点是直观、便于查阅。

图像法：用坐标系中的图形表示函数。优点是形象直观，能反映函数的整体变化趋势。

分段函数：在定义域的不同部分用不同的解析式表示。如绝对值函数 |x| = x（x≥0）或 -x（x<0）。分段函数是一个函数，不是多个函数的拼接。

五、函数的值域求法

观察法：对于简单函数直接观察。如y = x2x^2x2 + 1（x∈ℝ），值域为[1, +∞)。

配方法：对二次函数配方求最值。如y = x2x^2x2 - 4x + 5 = (x-2)2^22 + 1，最小值为1，值域为[1, +∞)。

判别式法：将y = f(x)视为关于x的方程，利用判别式Δ ≥ 0求y的范围。

单调性法：利用函数在定义域上的单调性确定值域。

换元法：通过变量替换简化求值域的过程。如y = x + √(1-x)，令t = √(1-x) ≥ 0，则x = 1 - t2t^2t2，y = 1 - t2t^2t2 + t = -(t - 1/2)2^22 + 5/4，值域为(-∞, 5/4]。

练习与思考

  1. 求下列函数的定义域：(1) f(x) = √(x-1) + 1/(x-2); (2) f(x) = lg(3-x); (3) f(x) = √(x2x^2x2-4)/(x-3)。

  2. 用定义法证明f(x) = x3x^3x3在ℝ上是增函数。

  3. 判断下列函数的奇偶性：(1) f(x) = x2x^2x2 + |x|; (2) f(x) = x3x^3x3 + x; (3) f(x) = x2x^2x2（x∈[0, 2]）。

  4. 求函数y = -x2x^2x2 + 4x - 1在区间[0, 3]上的值域。

拓展阅读

函数概念的演变经历了从"变量之间的依赖关系"（欧拉）到"集合之间的对应"（狄利克雷-布尔巴基）的发展过程。理解函数的现代定义有助于后续学习映射、变换等更一般的数学概念。推荐阅读《数学分析》的函数部分了解函数概念在大学数学中的深化。

小结

函数是高中数学的主线。定义域、值域、对应法则三要素确定一个函数，单调性和奇偶性是分析函数行为的基本工具。判断单调性用"作差法"，判断奇偶性先查定义域对称性再比较f(-x)与f(x)。这些基础概念和方法将在后续的指数函数、对数函数、三角函数等内容中反复运用。
