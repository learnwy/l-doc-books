高一数学 — 三角函数

知识要点

三角函数是以角度为自变量、以比值为函数值的一类函数，是高中数学的核心内容之一。三角函数将几何中的角度关系转化为代数运算，在物理学、工程学和信号处理中有广泛应用。高一阶段需要掌握：任意角与弧度制、三角函数的定义、基本三角函数（正弦、余弦、正切）的图像与性质、三角恒等变换的基本公式。

前置知识：初中阶段的锐角三角函数（直角三角形中的正弦、余弦、正切定义）、角的度量。

详细讲解

一、任意角与弧度制

任意角的概念：将角的概念从锐角推广到任意角。按旋转方向规定：逆时针旋转为正角，顺时针旋转为负角，不旋转为零角。角可以大于360°（旋转超过一周），也可以为负值。

终边相同的角：与角α终边相同的所有角可以表示为α + k·360°（k∈ℤ），或用弧度制表示为α + 2kπ（k∈ℤ）。

弧度制：用弧长与半径的比值来度量角的大小。1弧度 = 180°/π ≈ 57.3°。

角度与弧度的换算：

度数 0° 30° 45° 60° 90° 180° 270° 360°
弧度 0 π/6 π/4 π/3 π/2 π 3π/2 2π

换算公式：弧度数 = 度数 × π/180，度数 = 弧度数 × 180/π。

弧长公式：l = |α| · r，扇形面积：S = (1/2)|α|r2r^2r2 = (1/2)lr。

二、三角函数的定义

设角α的终边与单位圆（圆心在原点、半径为1的圆）的交点为P(x, y)，则：

sin α = y（P点的纵坐标）

cos α = x（P点的横坐标）

tan α = y/x（x ≠ 0）

这一定义将三角函数从直角三角形推广到了任意角。

各象限三角函数的符号（口诀："一全正，二正弦，三正切，四余弦"）：

象限 sin α cos α tan α
第一象限 + + +
第二象限 + - -
第三象限 - - +
第四象限 - + -

三、正弦函数y = sin x

图像特征：正弦曲线是一条连续的波浪形曲线，在y = -1和y = 1之间振荡。

基本性质：

定义域：ℝ

值域：[-1, 1]

周期：2π（最小正周期）

奇偶性：奇函数，sin(-x) = -sin x

单调性：在[-π/2 + 2kπ, π/2 + 2kπ]上递增，在[π/2 + 2kπ, 3π/2 + 2kπ]上递减

最大值：sin x = 1 当x = π/2 + 2kπ

最小值：sin x = -1 当x = -π/2 + 2kπ

四、余弦函数y = cos x

基本性质：

定义域：ℝ

值域：[-1, 1]

周期：2π

奇偶性：偶函数，cos(-x) = cos x

单调性：在[2kπ - π, 2kπ]上递增，在[2kπ, 2kπ + π]上递减

关键关系：cos x = sin(x + π/2)，即余弦函数可以看作正弦函数向左平移π/2个单位。

五、基本三角恒等式

同角三角函数的基本关系：

sin2sin^2sin2α + cos2cos^2cos2α = 1（勾股关系）

tan α = sin α / cos α（商数关系）

诱导公式（核心规律："奇变偶不变，符号看象限"）：

π/2相关的公式（奇变）：

sin(π/2 - α) = cos α，cos(π/2 - α) = sin α

sin(π/2 + α) = cos α，cos(π/2 + α) = -sin α

π相关的公式（偶不变）：

sin(π - α) = sin α，cos(π - α) = -cos α

sin(π + α) = -sin α，cos(π + α) = -cos α

和差角公式：

sin(α ± β) = sin α cos β ± cos α sin β

cos(α ± β) = cos α cos β ∓ sin α sin β

二倍角公式：

sin 2α = 2 sin α cos α

cos 2α = cos2cos^2cos2α - sin2sin^2sin2α = 2cos2cos^2cos2α - 1 = 1 - 2sin2sin^2sin2α

六、函数y = A sin(ωx + φ)

参数含义：

A——振幅，|A|决定函数值的最大变化范围

ω——角频率，周期T = 2π/|ω|

φ——初相，决定图像的水平平移

图像变换：从y = sin x到y = A sin(ωx + φ)可分三步：先平移（φ的作用），再伸缩x轴（ω的作用），最后伸缩y轴（A的作用）。

练习与思考

  1. 将下列角度转化为弧度：(1) 150°; (2) -225°; (3) 330°。将下列弧度转化为角度：(1) 5π/6; (2) -3π/4。

  2. 已知sin α = 3/5，α在第二象限，求cos α和tan α的值。

  3. 化简：sin(π + α) · cos(2π - α) · tan(-α) / [sin(-α) · cos(π + α)]。

  4. 求函数y = 2sin(2x + π/3)的振幅、周期和初相，并画出其在一个周期内的图像。

拓展阅读

三角函数起源于古代天文学对天体运行的描述，古希腊天文学家希帕克斯编制了最早的三角函数表。傅里叶发现任何周期函数都可以分解为正弦和余弦函数的叠加（傅里叶级数），这一发现是信号处理和通信技术的数学基础。推荐阅读《三角之美》了解三角函数在自然界和工程中的奇妙应用。

小结

三角函数通过弧度制和单位圆定义将角度关系代数化，使得几何问题可以用代数方法处理。正弦函数和余弦函数是最基本的周期函数，它们的图像、性质和变换规律是三角函数学习的核心。三角恒等变换（诱导公式、和差角公式、二倍角公式）则为三角函数的化简、求值和证明提供了强大的工具。
