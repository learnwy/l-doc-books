高二数学 — 概率论基础

知识要点

概率论研究随机现象的数学规律。与确定性事件不同，随机事件的单次结果无法预知，但大量重复试验后，其发生的频率会趋于稳定——这个稳定值就是概率。高二阶段的概率内容建立在计数原理之上，着重掌握古典概型、条件概率与事件独立性。

核心知识点：

  • 随机事件与样本空间：试验的所有可能结果构成样本空间 Ω\OmegaΩ
  • 古典概型：有限等可能样本空间中的概率计算
  • 概率的基本性质：非负性、规范性、可加性
  • 条件概率：在已知某事件发生的条件下另一事件的概率
  • 事件的独立性：两事件互不影响的严格定义
  • 独立重复试验与二项分布

详细讲解

一、随机事件与概率的定义

随机试验的三个特征：可以在相同条件下重复进行；每次结果不止一个；事先无法确定结果。

样本空间 Ω\OmegaΩ：所有可能结果的集合。例如掷一枚骰子，Ω={1,2,3,4,5,6}\Omega = \{1, 2, 3, 4, 5, 6\}Ω={1,2,3,4,5,6}。

事件：样本空间的子集。例如"掷出偶数"对应事件 A={2,4,6}A = \{2, 4, 6\}A={2,4,6}。

概率的统计定义：在 nnn 次重复试验中，事件 AAA 发生了 mmm 次，则当 nnn 充分大时，频率 mn\frac{m}{n}nm​ 趋于一个稳定常数，这个常数就是 P(A)P(A)P(A)。

概率的公理化定义（柯尔莫哥洛夫）：

  1. 非负性：P(A)≥0P(A) \geq 0P(A)≥0
  2. 规范性：P(Ω)=1P(\Omega) = 1P(Ω)=1
  3. 可加性：若 A∩B=∅A \cap B = \emptysetA∩B=∅，则 P(A∪B)=P(A)+P(B)P(A \cup B) = P(A) + P(B)P(A∪B)=P(A)+P(B)

二、古典概型

条件：样本空间有限（共 NNN 个样本点），且每个样本点等可能出现。

计算公式：

P(A)=事件 A 包含的样本点数样本空间的样本点总数=∣A∣∣Ω∣P(A) = \frac{\text{事件 } A \text{ 包含的样本点数}}{\text{样本空间的样本点总数}} = \frac{|A|}{|\Omega|}P(A)=样本空间的样本点总数事件 A 包含的样本点数​=∣Ω∣∣A∣​

示例一：从标准扑克牌（525252 张）中随机抽取一张，抽到红心的概率是多少？

P(红心)=1352=14P(\text{红心}) = \frac{13}{52} = \frac{1}{4}P(红心)=5213​=41​

示例二：同时掷两颗骰子，点数之和为 777 的概率。

样本空间大小 ∣Ω∣=6×6=36|\Omega| = 6 \times 6 = 36∣Ω∣=6×6=36。

和为 777 的组合：(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)(1,6), (2,5), (3,4), (4,3), (5,2), (6,1)(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)，共 666 种。

P(和为7)=636=16P(\text{和为} 7) = \frac{6}{36} = \frac{1}{6}P(和为7)=366​=61​

示例三：袋中有 555 个红球和 333 个白球，随机取 333 个球，恰好取到 222 个红球和 111 个白球的概率。

P=C52×C31C83=10×356=3056=1528P = \frac{C_5^2 \times C_3^1}{C_8^3} = \frac{10 \times 3}{56} = \frac{30}{56} = \frac{15}{28}P=C83​C52​×C31​​=5610×3​=5630​=2815​

三、概率的加法公式

对于任意两个事件 AAA 和 BBB：

P(A∪B)=P(A)+P(B)−P(A∩B)P(A \cup B) = P(A) + P(B) - P(A \cap B)P(A∪B)=P(A)+P(B)−P(A∩B)

若 AAA 和 BBB 互斥（A∩B=∅A \cap B = \emptysetA∩B=∅），则简化为：

P(A∪B)=P(A)+P(B)P(A \cup B) = P(A) + P(B)P(A∪B)=P(A)+P(B)

对立事件：P(Aˉ)=1−P(A)P(\bar{A}) = 1 - P(A)P(Aˉ)=1−P(A)

这在"至少"型问题中非常有用。例如：求"至少发生一次"的概率，往往用 111 减去"一次都不发生"的概率更方便。

四、条件概率

在事件 BBB 已经发生的条件下，事件 AAA 发生的概率：

P(A∣B)=P(A∩B)P(B)(P(B)>0)P(A|B) = \frac{P(A \cap B)}{P(B)} \quad (P(B) > 0)P(A∣B)=P(B)P(A∩B)​(P(B)>0)

示例：掷两颗骰子，已知点数之和大于 888，求两颗都大于 333 的概率。

BBB：和大于 888，包括和为 9,10,11,129, 10, 11, 129,10,11,12，共有 101010 种情况。

A∩BA \cap BA∩B：两颗都大于 333 且和大于 888，即两颗取值均在 {4,5,6}\{4,5,6\}{4,5,6} 中且和大于 888。

可能的组合：(3,6),(4,5),(4,6),(5,4),(5,5),(5,6),(6,3),(6,4),(6,5),(6,6)(3,6),(4,5),(4,6),(5,4),(5,5),(5,6),(6,3),(6,4),(6,5),(6,6)(3,6),(4,5),(4,6),(5,4),(5,5),(5,6),(6,3),(6,4),(6,5),(6,6) 中，两颗都大于 333 的有 (4,5),(4,6),(5,4),(5,5),(5,6),(6,4),(6,5),(6,6)(4,5),(4,6),(5,4),(5,5),(5,6),(6,4),(6,5),(6,6)(4,5),(4,6),(5,4),(5,5),(5,6),(6,4),(6,5),(6,6)，共 888 种。

P(A∣B)=810=45P(A|B) = \frac{8}{10} = \frac{4}{5}P(A∣B)=108​=54​

乘法公式：P(A∩B)=P(B)⋅P(A∣B)P(A \cap B) = P(B) \cdot P(A|B)P(A∩B)=P(B)⋅P(A∣B)

五、事件的独立性

若事件 AAA 的发生不影响事件 BBB 的概率，即：

P(A∩B)=P(A)⋅P(B)P(A \cap B) = P(A) \cdot P(B)P(A∩B)=P(A)⋅P(B)

则称 AAA 和 BBB 相互独立。

注意区分：互斥指不能同时发生（A∩B=∅A \cap B = \emptysetA∩B=∅），独立指互不影响。两个概率都不为零的事件如果互斥则一定不独立。

六、独立重复试验与二项分布

在 nnn 次独立重复试验中，每次试验成功的概率为 ppp，恰好成功 kkk 次的概率为：

P(X=k)=Cnkpk(1−p)n−k(k=0,1,2,…,n)P(X = k) = C_n^k p^k (1-p)^{n-k} \quad (k = 0, 1, 2, \ldots, n)P(X=k)=Cnk​pk(1−p)n−k(k=0,1,2,…,n)

记作 X∼B(n,p)X \sim B(n, p)X∼B(n,p)（二项分布）。

示例：某产品的合格率为 0.90.90.9，随机检验 555 件产品，恰好有 444 件合格的概率。

P(X=4)=C54×0.94×0.11=5×0.6561×0.1=0.32805P(X = 4) = C_5^4 \times 0.9^4 \times 0.1^1 = 5 \times 0.6561 \times 0.1 = 0.32805P(X=4)=C54​×0.94×0.11=5×0.6561×0.1=0.32805

二项分布的期望与方差：E(X)=npE(X) = npE(X)=np，D(X)=np(1−p)D(X) = np(1-p)D(X)=np(1−p)。

练习与思考

  1. 某班有 303030 名男生和 202020 名女生，随机选 555 人组成学习小组，求恰好有 222 名女生的概率。
  2. 甲、乙两人独立地射击同一目标，甲命中的概率为 0.60.60.6，乙命中的概率为 0.70.70.7。求目标被击中的概率。
  3. 掷一枚硬币 666 次，求恰好出现 333 次正面的概率。
  4. 一个家庭有 333 个孩子，假设每个孩子是男孩或女孩的概率各为 12\frac{1}{2}21​。已知至少有一个女孩，求三个孩子全是女孩的概率。
  5. 思考：为什么"生日悖论"中 232323 人里有两人同一天生日的概率就超过 50%50\%50%？

拓展阅读

概率论的起源与赌博问题密不可分。1654 年帕斯卡和费马通过通信讨论了"赌金分配问题"，被认为是概率论的诞生。此后，伯努利、拉普拉斯、高斯等数学家逐步将概率论发展为严格的数学学科。

现代生活中概率无处不在：

  • 医学中的检测准确率和假阳性问题（贝叶斯定理的典型应用）
  • 保险业用精算模型预测理赔概率来设定保费
  • 天气预报中"降水概率 60%60\%60%"意味着在类似气象条件下约 60%60\%60% 的时间会降水
  • 互联网推荐系统基于条件概率预测用户的点击行为

推荐进一步了解全概率公式和贝叶斯公式——它们是条件概率最强大的应用工具。

小结

  • 概率量化了随机事件发生的可能性，取值范围为 [0,1][0, 1][0,1]
  • 古典概型要求有限等可能，概率等于"有利样本数除以总样本数"
  • 条件概率改变了样本空间，P(A∣B)=P(A∩B)P(B)P(A|B) = \frac{P(A \cap B)}{P(B)}P(A∣B)=P(B)P(A∩B)​
  • 独立性的判定标准是 P(A∩B)=P(A)⋅P(B)P(A \cap B) = P(A) \cdot P(B)P(A∩B)=P(A)⋅P(B)
  • 二项分布刻画了 nnn 次独立重复试验中成功次数的分布规律
