高三数学 — 基本初等函数

知识要点

基本初等函数是高中数学的核心框架，贯穿选择题、填空题和解答题各种题型。高考对函数的考查从未缺席，且经常与导数、不等式结合形成压轴题的子问题。高三总复习阶段需要将分散在高一高二学习的函数知识整合为一个系统——从函数的一般性质（定义域、值域、单调性、奇偶性、周期性）到具体函数模型（指数函数、对数函数、幂函数、三角函数）的图像与性质，再到函数之间的复合与变换。

详细讲解

一、函数的一般性质

定义域是函数的"生命线"。求定义域的核心规则：

结构 条件 示例
分式 分母 ≠0\neq 0=0 y=1x−2y = \frac{1}{x-2}y=x−21​，x≠2x \neq 2x=2
偶次根式 被开方数 ≥0\geq 0≥0 y=x−1y = \sqrt{x-1}y=x−1​，x≥1x \geq 1x≥1
对数 真数 >0> 0>0 y=ln⁡(x+3)y = \ln(x+3)y=ln(x+3)，x>−3x > -3x>−3
复合结构 各条件取交集 y=x−1ln⁡(3−x)y = \frac{\sqrt{x-1}}{\ln(3-x)}y=ln(3−x)x−1​​，需 x≥1x \geq 1x≥1 且 3−x>03-x > 03−x>0 且 3−x≠13-x \neq 13−x=1

单调性判断方法：

  1. 定义法：取 x1<x2x_1 < x_2x1​<x2​，比较 f(x1)f(x_1)f(x1​) 与 f(x2)f(x_2)f(x2​) 的大小
  2. 导数法：f′(x)>0f'(x) > 0f′(x)>0 时递增，f′(x)<0f'(x) < 0f′(x)<0 时递减
  3. 复合函数单调性："同增异减"——外层函数与内层函数同增则复合后递增，一增一减则复合后递减

奇偶性判断步骤：

  1. 检查定义域是否关于原点对称（必要条件）
  2. 计算 f(−x)f(-x)f(−x)，与 f(x)f(x)f(x) 比较
  3. f(−x)=f(x)f(-x) = f(x)f(−x)=f(x)：偶函数；f(−x)=−f(x)f(-x) = -f(x)f(−x)=−f(x)：奇函数

四、函数的零点与方程

函数零点问题本质上是方程 f(x)=0f(x) = 0f(x)=0 的求解问题。高考常考的形式是"判断零点个数"或"求零点所在的区间"。

零点存在定理：若 f(x)f(x)f(x) 在区间 [a,b][a, b][a,b] 上连续，且 f(a)⋅f(b)<0f(a) \cdot f(b) < 0f(a)⋅f(b)<0，则 f(x)f(x)f(x) 在 (a,b)(a, b)(a,b) 内至少存在一个零点。

数形结合求零点个数：将 f(x)=0f(x) = 0f(x)=0 转化为两个函数图像的交点问题。

例：求 ex=2xe^x = 2xex=2x 的解的个数 → 画出 y=exy = e^xy=ex 和 y=2xy = 2xy=2x 的图像 → 观察交点个数。

分段函数的零点：分段函数在每段上分别讨论零点，最后合并结果。注意分界点处的取值。

五、函数模型的比较

高考常考"函数增长速度比较"：

当 x→+∞ 时：xn≪ax≪x!(a>1,n>0)\text{当 } x \to +\infty \text{ 时：} \quad x^n \ll a^x \ll x! \quad (a > 1, n > 0)当 x→+∞ 时：xn≪ax≪x!(a>1,n>0)

即：幂函数增长 <<< 指数函数增长。这一结论经常以选择题或填空题的形式出现。

对数增长则是最慢的：当 x→+∞x \to +\inftyx→+∞ 时，log⁡ax\log_a xloga​x 的增长速度慢于任何正幂次函数 xαx^\alphaxα（α>0\alpha > 0α>0）。

六、复合函数与函数变换

高考中大量题目涉及复合函数，如 y=esin⁡xy = e^{\sin x}y=esinx、y=ln⁡(x2−1)y = \ln(x^2 - 1)y=ln(x2−1)。

复合函数定义域：先确定内层函数的值域，再确保其满足外层函数的定义域要求。

复合函数单调性：设 y=f(g(x))y = f(g(x))y=f(g(x))，在某区间上：

  • 若 fff 增且 ggg 增 → yyy 增
  • 若 fff 减且 ggg 减 → yyy 增
  • 若 fff 增且 ggg 减 → yyy 减
  • 若 fff 减且 ggg 增 → yyy 减

拓展阅读

  • 函数概念是数学中最核心的概念之一，从狄利克雷的"对应关系"定义到集合论框架下的现代定义，函数概念经历了三百多年的演化。
  • 指数增长模型在生物学（种群增长）、经济学（复利计算）、传染病学（传播模型）中有广泛应用，理解指数函数的实际意义有助于跨学科思维。
  • 三角函数起源于古希腊天文学，弦表和正弦表是人类最早的函数表之一。
  • 对数由纳皮尔在 171717 世纪发明，最初目的是简化天文计算中的乘除运算。

小结

基本初等函数复习的核心线索是"性质—图像—应用"三位一体。性质方面，定义域、单调性、奇偶性、周期性是所有函数的通用分析框架；图像方面，指数、对数、三角函数的图像特征及其参数变换规律必须烂熟于心；应用方面，零点问题、增长速度比较和复合函数是高考的高频考查方向。总复习阶段不要孤立地复习每种函数，而要在它们之间建立联系——指数与对数互为反函数、三角函数的辅助角公式将多种三角关系统一为单一正弦模型——这种系统性的理解才是高考数学拿高分的基础。
