高三数学 — 不等式与证明

知识要点

不等式是高中数学的基础工具，渗透在函数、导数、数列、解析几何等几乎所有板块中。高考对不等式的考查分为两个层面：一是不等式的基本求解（线性不等式、二次不等式、分式不等式），属于选择题和填空题的基础考查；二是不等式的证明与应用，常与导数结合构成压轴题的核心问题。高三总复习需要将"解不等式"和"证不等式"两种能力同步提升，尤其是均值不等式、放缩法和参数范围问题的综合运用。

二次不等式 ax2+bx+c>0ax^2 + bx + c > 0ax2+bx+c>0 的解法 基础必备
绝对值不等式 $ a

详细讲解

一、均值不等式及其应用

均值不等式（又称AM-GM不等式）是高考最高频的不等式工具：

若 a>0,b>0，则 a+b2≥ab\text{若 } a > 0, b > 0 \text{，则 } \frac{a+b}{2} \geq \sqrt{ab}若 a>0,b>0，则 2a+b​≥ab​

等号成立条件：a=ba = ba=b。

使用均值不等式求最值的三个条件（简称"一正二定三相等"）：

  1. 正：a,b>0a, b > 0a,b>0
  2. 定：a+ba + ba+b 或 ababab 之一为定值
  3. 等：a=ba = ba=b 的条件可以取到

常见变形：

条件 结论 应用场景
a+b=Sa + b = Sa+b=S（常数） ab≤S24ab \leq \frac{S^2}{4}ab≤4S2​，当 a=ba = ba=b 时取等 求积的最大值
ab=Pab = Pab=P（常数） a+b≥2Pa + b \geq 2\sqrt{P}a+b≥2P​，当 a=ba = ba=b 时取等 求和的最小值
a+b=Sa + b = Sa+b=S 1a+1b≥4S\frac{1}{a} + \frac{1}{b} \geq \frac{4}{S}a1​+b1​≥S4​ 调和均值问题

典型例题：已知 x>0x > 0x>0，求 f(x)=x+4xf(x) = x + \frac{4}{x}f(x)=x+x4​ 的最小值。

f(x)=x+4x≥2x⋅4x=24=4f(x) = x + \frac{4}{x} \geq 2\sqrt{x \cdot \frac{4}{x}} = 2\sqrt{4} = 4f(x)=x+x4​≥2x⋅x4​​=24​=4

当 x=4xx = \frac{4}{x}x=x4​ 即 x=2x = 2x=2 时取等号。所以最小值为 444。

进阶技巧——"凑定值"：

求 y=x2+5x−1y = \frac{x^2 + 5}{x - 1}y=x−1x2+5​（x>1x > 1x>1）的最小值。

令 t=x−1>0t = x - 1 > 0t=x−1>0，则 x=t+1x = t + 1x=t+1：

y=(t+1)2+5t=t2+2t+6t=t+2+6ty = \frac{(t+1)^2 + 5}{t} = \frac{t^2 + 2t + 6}{t} = t + 2 + \frac{6}{t}y=t(t+1)2+5​=tt2+2t+6​=t+2+t6​

对 t+6tt + \frac{6}{t}t+t6​ 使用均值不等式：t+6t≥26t + \frac{6}{t} \geq 2\sqrt{6}t+t6​≥26​

所以 y≥26+2y \geq 2\sqrt{6} + 2y≥26​+2，当 t=6t = \sqrt{6}t=6​ 时取等。

三、放缩法证明不等式

放缩法是高考不等式证明的核心技巧，尤其在数列与不等式结合的题目中。

拓展阅读

  • 均值不等式可以推广为 nnn 元形式：a1+a2+⋯+ann≥a1a2⋯ann\frac{a_1 + a_2 + \cdots + a_n}{n} \geq \sqrt[n]{a_1 a_2 \cdots a_n}na1​+a2​+⋯+an​​≥na1​a2​⋯an​​，这在竞赛数学中有广泛应用。
  • 柯西-施瓦茨不等式是数学中最优美的不等式之一，其向量形式为 ∣a⃗⋅b⃗∣≤∣a⃗∣∣b⃗∣|\vec{a} \cdot \vec{b}| \leq |\vec{a}||\vec{b}|∣a⋅b∣≤∣a∣∣b∣。
  • 杨辉-牛顿不等式和琴生不等式是凸函数理论的核心结论，与高中的均值不等式有深刻联系。
  • 放缩法的精妙之处在于"恰到好处"——放得太松结论不够强，放得太紧无法成立。

小结

不等式与证明的复习需要兼顾"解题"和"证明"两种能力。解不等式方面，二次不等式靠图像法，分式不等式靠移项通分后画数轴标根，绝对值不等式靠去绝对值转化。证明不等式方面，比较法和构造函数法是最通用的工具，放缩法是数列不等式的核心技巧，均值不等式的应用要牢记"一正二定三相等"。参数范围问题是将不等式与函数最值问题联系起来的桥梁，掌握恒成立和存在性问题的转化方式是解决此类题目的关键。每种证明方法都有其最佳适用场景，灵活选择方法比生搬硬套公式更重要。
