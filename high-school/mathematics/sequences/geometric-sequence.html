高一数学 — 等比数列

知识要点

等比数列是相邻两项之比恒为常数的数列，与等差数列并称为两大基本数列。等比数列在复利计算、几何级数、人口增长模型等领域有重要应用。高一阶段需要掌握：等比数列的定义与通项公式、等比中项的概念、等比数列前n项和公式及其推导方法（错位相减法）、等比数列的性质。

等比数列的核心参数：首项a1a_1a1​、公比q（q ≠ 0）。

详细讲解

一、等比数列的定义

如果一个数列从第二项起，每一项与前一项的比等于同一个不为零的常数，则这个数列称为等比数列。这个常数称为公比，用q表示。

数学表达：an+1a_{n+1}an+1​/ana_nan​ = q（n∈ℕ*, q ≠ 0, q为常数）。

注意：等比数列中每一项都不为零（否则比值无意义）。

通项公式：ana_nan​ = a1a_1a1​ · qn−1q^{n-1}qn−1。

推导：a2a_2a2​ = a1a_1a1​q, a3a_3a3​ = a1q2a_1q^2a1​q2, ..., ana_nan​ = a1qn−1a_1q^{n-1}a1​qn−1。

更一般地：ana_nan​ = ama_mam​ · qn−mq^{n-m}qn−m。

二、等比中项

如果a, b, c成等比数列（且均不为零），则b称为a和c的等比中项，且b2b^2b2 = ac，即b = ±√(ac)。

注意与等差中项的区别：等差中项b = (a+c)/2是唯一的，等比中项b = ±√(ac)可能有两个值。

三、等比数列的前n项和

当q = 1时：SnS_nSn​ = na1a_1a1​。

当q ≠ 1时：

SnS_nSn​ = a1a_1a1​(1 - qnq^nqn)/(1 - q) = a1a_1a1​(qnq^nqn - 1)/(q - 1)

推导方法——错位相减法：

SnS_nSn​ = a1a_1a1​ + a1a_1a1​q + a1q2a_1q^2a1​q2 + ... + a1qn−1a_1q^{n-1}a1​qn−1 ……①

qSnS_nSn​ = a1a_1a1​q + a1q2a_1q^2a1​q2 + a1q3a_1q^3a1​q3 + ... + a1qna_1q^na1​qn ……②

①-②得：(1-q)SnS_nSn​ = a1a_1a1​ - a1qna_1q^na1​qn = a1a_1a1​(1 - qnq^nqn)

故 SnS_nSn​ = a1a_1a1​(1 - qnq^nqn)/(1 - q)（q ≠ 1）。

条件 公式
q = 1 SnS_nSn​ = na1a_1a1​
q ≠ 1, 已知a1a_1a1​, q, n SnS_nSn​ = a1a_1a1​(1-qnq^nqn)/(1-q)
q ≠ 1, 已知a1a_1a1​, q, ana_nan​ SnS_nSn​ = (a1a_1a1​ - ana_nan​q)/(1-q)

四、等比数列的性质

性质一：ama_mam​ · ana_nan​ = apa_pap​ · aya_yay​（当m + n = p + q时）。

对比等差数列的加法性质，等比数列的对应性质是乘法。

性质二：若{ana_nan​}是公比为q的等比数列，则{an2a_n^2an2​}是公比为q2q^2q2的等比数列，{c · ana_nan​}（c ≠ 0）是公比为q的等比数列。

性质三：SnS_nSn​, S2nS_{2n}S2n​ - SnS_nSn​, S3nS_{3n}S3n​ - S2nS_{2n}S2n​也构成等比数列（当每一段和都不为零时）。

性质四：在等比数列中，奇数项之积与偶数项之积的比有特殊规律。

收敛性：当|q| < 1时，随着n→∞，SnS_nSn​趋近于S = a1a_1a1​/(1-q)。这就是无穷等比级数的和。

五、等差数列与等比数列的对比

比较项 等差数列 等比数列
定义 an+1a_{n+1}an+1​ - ana_nan​ = d an+1a_{n+1}an+1​/ana_nan​ = q
通项公式 ana_nan​ = a1a_1a1​ + (n-1)d ana_nan​ = a1a_1a1​ · qn−1q^{n-1}qn−1
中项 b = (a+c)/2 b2b^2b2 = ac
求和 SnS_nSn​ = n(a1a_1a1​+ana_nan​)/2 SnS_nSn​ = a1a_1a1​(1-qnq^nqn)/(1-q)
性质对比 ama_mam​ + ana_nan​ = apa_pap​ + aya_yay​ ama_mam​ · ana_nan​ = apa_pap​ · aya_yay​
递推运算 加法 乘法

本质关系：如果{ana_nan​}是等差数列，则{c^ana_nan​}（c > 0, c ≠ 1）是等比数列；如果{bnb_nbn​}是正项等比数列，则{log bnb_nbn​}是等差数列。

六、典型题型

例1：在等比数列中，a2a_2a2​ = 6, a5a_5a5​ = 162，求a1a_1a1​和q。

解：a5a_5a5​/a2a_2a2​ = a1q4a_1q^4a1​q4/a1a_1a1​q = q3q^3q3 = 162/6 = 27，q = 3。a1a_1a1​ = a2a_2a2​/q = 6/3 = 2。

例2：等比数列1, 2, 4, 8, ...的前10项和。

解：a1a_1a1​ = 1, q = 2, S10S_{10}S10​ = 1×(2102^{10}210 - 1)/(2-1) = 1024 - 1 = 1023。

例3：已知等比数列的前3项和S3S_3S3​ = 7，前6项和S6S_6S6​ = 63，求公比q。

解：S3S_3S3​ = a1a_1a1​(1-q3q^3q3)/(1-q) = 7, S6S_6S6​ = a1a_1a1​(1-q6q^6q6)/(1-q) = 63。S6S_6S6​/S3S_3S3​ = (1-q6q^6q6)/(1-q3q^3q3) = (1+q3q^3q3) = 63/7 = 9, q3q^3q3 = 8, q = 2。

练习与思考

  1. 在等比数列{ana_nan​}中，a3a_3a3​ = 4, a6a_6a6​ = 32，求a1a_1a1​, q和通项公式。

  2. 求等比数列3, -6, 12, -24, ...的前8项和。

  3. 已知等比数列{ana_nan​}中，a1a_1a1​ + a3a_3a3​ = 10, a2a_2a2​ + a4a_4a4​ = 20，求a5a_5a5​ + a7a_7a7​。

  4. 某银行年利率为3%，某人每年初存入10000元，10年后本利合计多少？（用等比数列求和公式计算）

拓展阅读

等比级数（无穷等比数列求和）是微积分中级数理论的起点。阿基米德用等比级数求出了抛物线弓形的面积。芝诺悖论"阿喀琉斯与乌龟赛跑"的数学解答也依赖于无穷等比级数的收敛性。在金融数学中，复利计算、年金现值和终值的计算都直接使用等比数列的求和公式。

小结

等比数列是乘法结构的数列，与等差数列（加法结构）形成完美的对照。通项公式ana_nan​ = a1qn−1a_1q^{n-1}a1​qn−1体现了指数增长（或衰减）的特征，前n项和的推导使用错位相减法——这是一种重要的数学技巧。理解等差与等比数列之间的内在联系（通过指数和对数的互逆关系），有助于建立更完整的数列知识体系。
