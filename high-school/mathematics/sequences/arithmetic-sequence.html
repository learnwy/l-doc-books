高一数学 — 等差数列

知识要点

数列是按照一定顺序排列的一列数，是函数概念在整数集上的特殊应用。等差数列是最基本的数列类型，其特征是相邻两项之差恒为常数。高一阶段需要掌握：等差数列的定义与通项公式、等差中项的概念、等差数列前n项和公式及其推导、等差数列的性质与应用。

等差数列的核心参数：首项a1a_1a1​、公差d。这两个参数完全确定一个等差数列。

详细讲解

一、等差数列的定义

如果一个数列从第二项起，每一项与前一项的差等于同一个常数，则这个数列称为等差数列。这个常数称为公差，用d表示。

数学表达：an+1a_{n+1}an+1​ - ana_nan​ = d（n∈ℕ*, d为常数）。

当d > 0时，数列递增；当d < 0时，数列递减；当d = 0时，数列为常数列。

通项公式：ana_nan​ = a1a_1a1​ + (n-1)d。

推导：a2a_2a2​ = a1a_1a1​ + d, a3a_3a3​ = a1a_1a1​ + 2d, ..., ana_nan​ = a1a_1a1​ + (n-1)d。

更一般地：ana_nan​ = ama_mam​ + (n-m)d（已知第m项和公差，求第n项）。

二、等差中项

如果a, b, c成等差数列，则b称为a和c的等差中项，且b = (a + c)/2。

反过来，如果b = (a + c)/2，则a, b, c成等差数列。

这个性质可以推广：在等差数列中，ama_mam​ + ana_nan​ = apa_pap​ + aya_yay​（当m + n = p + q时）。

例如：在等差数列中，a3a_3a3​ + a7a_7a7​ = a5a_5a5​ + a5a_5a5​ = 2a5a_5a5​，a1a_1a1​ + a9a_9a9​ = a3a_3a3​ + a7a_7a7​ = a5a_5a5​ × 2。

三、等差数列的前n项和

前n项和公式（两种形式）：

SnS_nSn​ = n(a1a_1a1​ + ana_nan​)/2 = na1a_1a1​ + n(n-1)d/2

推导方法——倒序相加法：

SnS_nSn​ = a1a_1a1​ + a2a_2a2​ + a3a_3a3​ + ... + ana_nan​

SnS_nSn​ = ana_nan​ + an−1a_{n-1}an−1​ + an−2a_{n-2}an−2​ + ... + a1a_1a1​

两式相加：2SnS_nSn​ = (a1a_1a1​ + ana_nan​) + (a2a_2a2​ + an−1a_{n-1}an−1​) + ... + (ana_nan​ + a1a_1a1​)

由等差数列性质，a1a_1a1​ + ana_nan​ = a2a_2a2​ + an−1a_{n-1}an−1​ = ... = 常数

所以 2SnS_nSn​ = n(a1a_1a1​ + ana_nan​)，即 SnS_nSn​ = n(a1a_1a1​ + ana_nan​)/2。

已知条件 适用公式
a1a_1a1​, ana_nan​, n SnS_nSn​ = n(a1a_1a1​ + ana_nan​)/2
a1a_1a1​, d, n SnS_nSn​ = na1a_1a1​ + n(n-1)d/2
a1a_1a1​, d ana_nan​ = a1a_1a1​ + (n-1)d 后代入

SnS_nSn​与二次函数的关系：将公式SnS_nSn​ = na1a_1a1​ + n(n-1)d/2展开得SnS_nSn​ = (d/2)n2n^2n2 + (a1a_1a1​ - d/2)n。当d ≠ 0时，SnS_nSn​是关于n的二次函数（无常数项）。

四、等差数列的性质

性质一：ama_mam​ + ana_nan​ = apa_pap​ + aya_yay​（当m + n = p + q时）。

性质二：若数列{ana_nan​}是等差数列，则数列{ana_nan​ + c}、{kana_nan​}也是等差数列。

性质三：若{ana_nan​}和{bnb_nbn​}都是等差数列，则{ana_nan​ + bnb_nbn​}和{ana_nan​ - bnb_nbn​}也是等差数列。

性质四：SnS_nSn​, S2nS_{2n}S2n​ - SnS_nSn​, S3nS_{3n}S3n​ - S2nS_{2n}S2n​也构成等差数列（即相邻n项和构成等差数列）。

性质五：ana_nan​ = SnS_nSn​ - Sn−1S_{n-1}Sn−1​（n ≥ 2），a1a_1a1​ = S1S_1S1​。

五、典型题型

基本量计算：等差数列有五个基本量——a1a_1a1​, d, n, ana_nan​, SnS_nSn​，知三求二。

例：已知等差数列中a3a_3a3​ = 7, a7a_7a7​ = 19，求a1a_1a1​和d。

解：a3a_3a3​ = a1a_1a1​ + 2d = 7, a7a_7a7​ = a1a_1a1​ + 6d = 19。两式相减得4d = 12, d = 3, a1a_1a1​ = 1。

前n项和最值问题：当公差d < 0时，SnS_nSn​先增后减，存在最大值。

方法一：令ana_nan​ ≥ 0且an+1a_{n+1}an+1​ ≤ 0，求n的范围。

方法二：利用SnS_nSn​ = (d/2)n2n^2n2 + (a1a_1a1​ - d/2)n，求二次函数的顶点。

例：等差数列中a1a_1a1​ = 20, d = -3，求SnS_nSn​的最大值。

解：ana_nan​ = 20 - 3(n-1) = 23 - 3n。令ana_nan​ ≥ 0得n ≤ 23/3 ≈ 7.67，故n = 7时ana_nan​ = 2 > 0，n = 8时ana_nan​ = -1 < 0。S7S_7S7​ = 7 × (20 + 2)/2 = 77。

练习与思考

  1. 在等差数列{ana_nan​}中，已知a5a_5a5​ = 10, a12a_{12}a12​ = 31，求a1a_1a1​, d和通项公式。

  2. 求等差数列2, 5, 8, 11, ...的前20项和。

  3. 已知等差数列{ana_nan​}的前n项和为SnS_nSn​，若S10S_{10}S10​ = 100, S20S_{20}S20​ = 400，求S30S_{30}S30​。

  4. 在等差数列中，a1a_1a1​ = 25, d = -2，SnS_nSn​取最大值时n等于多少？最大值是多少？

拓展阅读

等差数列的求和方法——倒序相加法据说起源于高斯童年时代的故事：老师要求计算1+2+3+...+100，年仅10岁的高斯迅速得出答案5050。这个方法体现了数学中对称性思想的运用。等差数列在实际生活中有广泛应用，如等额本金还款、均匀变速运动中的位移计算等。

小结

等差数列是最基础的数列类型，由首项a1a_1a1​和公差d完全确定。通项公式ana_nan​ = a1a_1a1​ + (n-1)d和前n项和公式SnS_nSn​ = n(a1a_1a1​ + ana_nan​)/2是解题的两大基本工具。等差数列的性质（如等距项和相等、连续n项和构成等差数列）为解决复杂问题提供了简便方法。掌握"知三求二"的基本量运算是处理等差数列问题的核心能力。
