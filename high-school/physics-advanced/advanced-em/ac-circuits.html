高中物理进阶 — 交流电路分析

知识要点

交流电（AC）是幅值和方向随时间周期性变化的电流，与恒定不变的直流电（DC）形成对比。交流电路分析是电磁学的重要应用领域，也是电气工程的基础。

核心概念包括：

  • 正弦交流电：i(t) = I_m sin(ωt + φ)，其中 I_m 为峰值电流，ω 为角频率，φ 为初相位
  • 有效值（均方根值）：I_rms = I_m/√2，对应产生相同热效应的直流值
  • 阻抗：交流电路中对电流的综合阻碍，Z = R + jX，包含电阻和电抗
  • 容抗与感抗：X_C = 1/(ωC) 随频率增大而减小，X_L = ωL 随频率增大而增大
  • 相位关系：电阻上电压与电流同相，电感上电压超前电流 90°，电容上电压滞后电流 90°
  • RLC 串联谐振：当 X_L = X_C 时电路达到谐振，阻抗最小，电流最大

详细讲解

正弦交流电的描述

交流发电机的基本原理是法拉第电磁感应定律。矩形线圈在匀强磁场中匀速转动时，产生的感应电动势为：

e(t)=NBAωsin⁡(ωt)=Emsin⁡(ωt)e(t) = NBA\omega\sin(\omega t) = E_m\sin(\omega t)e(t)=NBAωsin(ωt)=Em​sin(ωt)

其中 N 为线圈匝数，B 为磁感应强度，A 为线圈面积，ω = 2πf 为角频率。

描述交流电需要三个参数：

  • 峰值 E_m：最大瞬时值
  • 频率 f：每秒完成的完整周期数，中国电网标准为 50 Hz
  • 初相位 φ：t = 0 时刻的相位角

有效值的物理意义至关重要。交流电的有效值定义为：在相同时间内，通过相同电阻产生相同热量的直流电的大小。对于正弦交流电：

Irms=Im2≈0.707ImI_{rms} = \frac{I_m}{\sqrt{2}} \approx 0.707I_mIrms​=2​Im​​≈0.707Im​

家用电源标称 220V 就是有效值，对应峰值约 311V。

纯电阻、纯电感与纯电容电路

纯电阻电路中，电压与电流满足欧姆定律 u = iR，二者同相位。功率完全消耗在电阻上，P = I2I^{2}I2_rms R = U2U^{2}U2_rms/R。

纯电感电路中，电感对交流电产生感抗 X_L = ωL = 2πfL。关键特性：

  • 电压超前电流 90°（电感上"电压领先"）
  • 感抗与频率成正比，频率越高阻碍越大
  • 电感不消耗能量，只在磁场中储存和释放能量
  • 功率在正负之间交替，平均功率为零

纯电容电路中，电容对交流电产生容抗 X_C = 1/(ωC) = 1/(2πfC)。关键特性：

  • 电压滞后电流 90°（电容上"电流领先"）
  • 容抗与频率成反比，频率越高阻碍越小
  • 电容不消耗能量，只在电场中储存和释放能量

RLC 串联电路

当电阻、电感和电容串联时，总阻抗不是简单的代数相加，因为各元件上的电压相位不同。利用相量法：

Z=R2+(XL−XC)2Z = \sqrt{R^2 + (X_L - X_C)^2}Z=R2+(XL​−XC​)2​
tan⁡φ=XL−XCR\tan\varphi = \frac{X_L - X_C}{R}tanφ=RXL​−XC​​

其中 φ 是电路总电压与总电流之间的相位差。

三种情况：

  • X_L > X_C：电路呈感性，电压超前电流
  • X_L < X_C：电路呈容性，电流超前电压
  • X_L = X_C：电路谐振，阻抗最小等于 R

串联谐振

当 X_L = X_C 时，即 ωL = 1/(ωC)，解出谐振角频率：

ω0=1LC,f0=12πLC\omega_0 = \frac{1}{\sqrt{LC}}, \quad f_0 = \frac{1}{2\pi\sqrt{LC}}ω0​=LC​1​,f0​=2πLC​1​

谐振时的重要特征：

  • 阻抗最小，Z = R，电路中电流最大
  • 电压与电流同相，功率因数 cos φ = 1
  • 电感和电容上的电压可能远大于总电压（品质因数 Q = ωL/R = 1/(ωCR)）
  • 品质因数 Q 越大，谐振峰越尖锐，选频能力越强

收音机的调谐原理就是利用 LC 谐振：改变电容值使谐振频率与目标电台频率一致，从而在该频率上获得最大响应。

功率与功率因数

交流电路中的功率分为三类：

  • 有功功率 P = UIcos φ（单位：W），实际消耗的功率
  • 无功功率 Q = UIsin φ（单位：var），电感/电容储能交换的功率
  • 视在功率 S = UI（单位：VA），电压有效值与电流有效值的乘积

三者满足关系：S2=P2+Q2三者满足关系：S^{2} = P^{2} + Q^{2}三者满足关系：S2=P2+Q2。

功率因数 cos φ 衡量电路从电源获取有功功率的效率。工业中常通过并联电容来提高感性负载的功率因数，减少电流从而降低输电线路的损耗。

变压器原理

理想变压器基于电磁感应，原线圈和副线圈绕在同一铁芯上：

U1U2=N1N2,I1I2=N2N1\frac{U_1}{U_2} = \frac{N_1}{N_2}, \quad \frac{I_1}{I_2} = \frac{N_2}{N_1}U2​U1​​=N2​N1​​,I2​I1​​=N1​N2​​

变压器不改变功率（理想情况下 P1=P2P_1 = P_2P1​=P2​），只改变电压和电流的比值。远距离输电采用高压输送的原因是：在输送功率不变的条件下，提高电压可以降低电流，从而减少输电线上 I2RI^2 RI2R 的热损耗。

练习与思考

  1. 有效值计算：家用 220V 交流电的峰值电压是多少？一个峰值为 5A 的正弦交流电，其有效值是多少？

  2. 相量分析：在 RLC 串联电路中，R = 100Ω，L = 0.2H，C = 10μF，外加电压 u = 220√2 sin(100πt) V。求电路的阻抗、电流有效值和相位差。

  3. 谐振频率：一个串联谐振电路中 L = 1mH，C = 1μF。求谐振频率。若要将谐振频率提高一倍，电容应改为多大？

  4. 功率因数：某工厂电动机的功率因数为 0.6，额定功率 10kW，接在 380V 电源上。计算电流有效值和需要并联多大的电容才能将功率因数提高到 0.9。

  5. 变压器设计：某发电厂发电功率为 100MW，发电机输出电压 10kV。若输电线总电阻为 10Ω，分别计算以 10kV 和 500kV 输电时输电线上的功率损耗百分比。

拓展阅读

交流电的发展史是一段激动人心的技术竞争史。19世纪末的"电流战争"中，特斯拉和威斯汀豪斯支持交流电系统，爱迪生则力推直流电系统。最终交流电凭借变压器可以方便地改变电压这一关键优势获胜，奠定了现代电力系统的基础。

现代电力电子技术的发展使得交直流转换变得高效便捷。高压直流输电（HVDC）在超长距离输电和海底电缆中重新获得优势。中国的±1100kV 昌吉—古泉特高压直流输电工程是世界上电压等级最高、输送距离最远的直流输电工程。

竞赛拓展：复阻抗方法使用复数表示交流电路，Z = R + jX_L - jX_C，可以将微分方程化为代数方程。这种方法是信号与系统、电路分析等大学课程的核心工具，在自主招生考试中偶有涉及。

小结

  • 正弦交流电用峰值、频率和初相位三个参数完整描述
  • 有效值 I_rms = I_m/√2 等价于产生相同热效应的直流值
  • 电阻消耗能量，电感和电容只储存/释放能量
  • RLC 串联谐振时阻抗最小、电流最大，是选频电路的基础
  • 功率因数 cos φ 衡量有功功率利用效率，工业上通过并联电容提高
  • 变压器利用电磁感应改变电压，是远距离高压输电的关键设备
