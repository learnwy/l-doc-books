理科方向 物理进阶 — 振动与波

知识要点

振动与波是物理学中描述周期性运动和能量传播的基本框架。从弹簧振子到电磁波，从声音到光，振动与波的概念贯穿了力学、电磁学和量子力学。

  • 简谐运动：位移 x=Acos⁡(ωt+φ)x = A\cos(\omega t + \varphi)x=Acos(ωt+φ)，回复力 F = −kx。周期 T=2π/ω=2πm/kT = 2\pi/\omega = 2\pi\sqrt{m/k}T=2π/ω=2πm/k​（弹簧振子）或 T=2πL/gT = 2\pi\sqrt{L/g}T=2πL/g​（单摆，小角度近似）。
  • 阻尼振动与受迫振动：阻尼使振幅随时间衰减。受迫振动在驱动频率等于固有频率时发生共振，振幅达到最大。
  • 机械波：振动在介质中的传播。横波（振动方向垂直于传播方向）和纵波（振动方向平行于传播方向）。波速 v = fλ = λ/T。
  • 波的叠加与干涉：两列频率相同的波叠加产生稳定的干涉图样。相长干涉（波程差为波长整数倍）和相消干涉（波程差为半波长奇数倍）。
  • 驻波：两列振幅、频率、传播方向相反的波叠加形成的空间上稳定的振动模式。波节（始终不振动）和波腹（振幅最大）。

详细讲解

简谐运动的动力学分析

简谐运动的微分方程为 d2x/dt2+ω2x=0d^2x/dt^2 + \omega^2 x = 0d2x/dt2+ω2x=0，通解为 x(t)=Acos⁡(ωt+φ)x(t) = A\cos(\omega t + \varphi)x(t)=Acos(ωt+φ)。其中 A 是振幅（由初始条件决定），ω 是角频率（由系统参数决定），φ 是初相位。

能量分析：简谐运动中动能 Ek=(1/2)mv2=(1/2)mA2ω2sin⁡2(ωt+φ)E_k = (1/2)mv^2 = (1/2)mA^2\omega^2\sin^2(\omega t+\varphi)Ek​=(1/2)mv2=(1/2)mA2ω2sin2(ωt+φ) 和势能 Ep=(1/2)kx2=(1/2)kA2cos⁡2(ωt+φ)E_p = (1/2)kx^2 = (1/2)kA^2\cos^2(\omega t+\varphi)Ep​=(1/2)kx2=(1/2)kA2cos2(ωt+φ) 之间不断转化，总能量 E=(1/2)kA2E = (1/2)kA^2E=(1/2)kA2 保持恒定。

弹簧并联和串联：并联等效劲度系数 keff=k1+k2k_{eff} = k_1 + k_2keff​=k1​+k2​（弹簧更硬，周期减小），串联等效 1/keff=1/k1+1/k21/k_{eff} = 1/k_1 + 1/k_21/keff​=1/k1​+1/k2​（弹簧更软，周期增大）。

耦合振动：两个通过弹簧连接的振子构成耦合系统，有两个固有频率（简正模式）。一般运动是两个简正模式的叠加，可以出现能量在两个振子之间来回转移的"拍"现象。

阻尼振动与共振

在粘滞阻力 f = −bv 的作用下，振动方程变为 d2x/dt2+γ dx/dt+ω02x=0d^2x/dt^2 + \gamma \, dx/dt + \omega_0^2 x = 0d2x/dt2+γdx/dt+ω02​x=0（γ = b/m 为阻尼系数）。

  • 欠阻尼（γ<2ω0\gamma < 2\omega_0γ<2ω0​）：振幅按指数衰减 A(t)=A0e−γt/2A(t) = A_0 e^{-\gamma t/2}A(t)=A0​e−γt/2，振动频率略低于固有频率。
  • 临界阻尼（γ=2ω0\gamma = 2\omega_0γ=2ω0​）：最快回到平衡位置，不发生振荡。汽车悬挂系统设计在临界阻尼附近。
  • 过阻尼（γ>2ω0\gamma > 2\omega_0γ>2ω0​）：缓慢回到平衡位置，不发生振荡。

受迫振动在驱动频率 ωd\omega_dωd​ 接近固有频率 ω0\omega_0ω0​ 时发生共振。共振时振幅达到极大值 Amax=F0/(mγω0)A_{max} = F_0/(m\gamma\omega_0)Amax​=F0​/(mγω0​)（正比于驱动力，反比于阻尼）。共振现象在工程中既有利用（如微波加热、MRI 核磁共振）也需避免（如桥梁共振坍塌的 Tacoma Narrows Bridge 事件）。

波的数学描述

沿 x 轴正方向传播的简谐波：y(x,t)=Acos⁡(kx−ωt+φ0)y(x,t) = A\cos(kx - \omega t + \varphi_0)y(x,t)=Acos(kx−ωt+φ0​)，其中 k = 2π/λ 是波数，ω = 2πf 是角频率，波速 v = ω/k = fλ。

波动方程：∂2y/∂t2=v2 ∂2y/∂x2\partial^2 y/\partial t^2 = v^2 \, \partial^2 y/\partial x^2∂2y/∂t2=v2∂2y/∂x2。这是所有经典波动的基本方程。声波、电磁波、水波在小振幅近似下都满足这个方程。

波的能量：波在介质中传播时携带能量。对于一维绳波，单位长度的平均能量密度 eˉ=(1/2)ρA2ω2\bar{e} = (1/2)\rho A^2\omega^2eˉ=(1/2)ρA2ω2（ρ 为线密度）。能量传播速度等于波速（群速度等于相速度的情况）。

干涉与衍射

双缝干涉（杨氏实验）：两个相干波源产生的波在屏上叠加，明纹条件 dsin⁡θ=nλd\sin\theta = n\lambdadsinθ=nλ（n = 0, ±1, ±2,...），暗纹条件 dsin⁡θ=(n+1/2)λd\sin\theta = (n+1/2)\lambdadsinθ=(n+1/2)λ。相邻明纹间距 Δy=λL/d\Delta y = \lambda L/dΔy=λL/d（L 为双缝到屏的距离，d 为缝间距）。

薄膜干涉：光在薄膜上下表面反射的两束光发生干涉。等厚干涉产生明暗相间的条纹（如牛顿环、肥皂膜彩色条纹）。注意半波损失：光从光疏介质射向光密介质反射时有 π 的相位突变。

单缝衍射：当缝宽 a 与波长 λ 可比拟时，光通过窄缝后不再沿直线传播。中央明纹角宽度 2θ1=2λ/a2\theta_1 = 2\lambda/a2θ1​=2λ/a，远大于缝宽对应的几何影。衍射是波动性的直接证据。

多普勒效应

观察者接收到的频率 f' 与波源频率 f 的关系：f′=f(v±vobserver)/(v∓vsource)f' = f(v \pm v_{observer}) / (v \mp v_{source})f′=f(v±vobserver​)/(v∓vsource​)，其中 v 是波速。接近时频率增大（蓝移），远离时频率减小（红移）。

天文学中的红移是宇宙膨胀的直接证据。哈勃定律 v=H0dv = H_0 dv=H0​d 表明星系的退行速度与距离成正比。

练习与思考

  1. 质量为 m 的物体连接劲度系数为 k 的弹簧在光滑水平面上振动。已知初始位移 x0x_0x0​ 和初始速度 v0v_0v0​，求振幅 A 和初相位 φ 的表达式。

  2. 两列振幅均为 A、频率均为 f 的简谐波在绳上相向传播形成驻波。写出驻波的数学表达式，并求相邻波节间的距离。

  3. 在杨氏双缝实验中，双缝间距 d = 0.5 mm，双缝到屏距离 L = 1 m，使用波长 λ = 600 nm 的光。求屏上相邻明纹的间距。若将整个装置浸入折射率为 1.5 的液体中，间距如何变化？

  4. 救护车以 30 m/s 的速度驶向静止的观察者，鸣笛频率为 800 Hz。计算观察者听到的频率。（声速取 340 m/s）

拓展阅读

振动与波的理论在 20 世纪催生了量子力学。德布罗意提出物质波假说（λ = h/p），将波粒二象性从光推广到所有物质粒子。薛定谔方程本质上是量子力学的波动方程，电子的驻波模式解释了原子中电子轨道的量子化。

声学是振动与波应用最直接的领域。超声波检测利用声波在不同介质界面的反射来检测材料内部缺陷。主动降噪耳机利用相消干涉原理：麦克风采集环境噪声，产生反相声波叠加消除噪声。

对于竞赛选手，波动光学（干涉、衍射、偏振）是物理竞赛的重要考点。推荐《光学》（赵凯华）和 Hecht《Optics》的波动光学章节。

小结

振动与波将周期性运动和能量传播统一在一个数学框架下。简谐运动是最基本的振动形式，波动方程描述了振动在介质中的传播规律，干涉和衍射是波动性的标志性现象。从声学到光学，从地震波到电磁波，振动与波的理论在自然科学和工程技术中有着最广泛的应用。
