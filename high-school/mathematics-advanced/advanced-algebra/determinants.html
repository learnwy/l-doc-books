理科方向 数学进阶 — 行列式

知识要点

行列式是方阵的一个标量值函数，将 n×n 矩阵映射为一个数。行列式的值反映了线性变换对体积的缩放因子，在线性方程组求解、矩阵可逆性判断和几何计算中具有核心地位。

  • 二阶行列式：|a b; c d| = ad − bc。几何意义是由两个列向量张成的平行四边形的有向面积。
  • n 阶行列式：按行展开 det A = ΣjΣ_{j}Σj​ a_{ij}AijA_{ij}Aij​，其中 AijA_{ij}Aij​ = (−1)^(i+j) MijM_{ij}Mij​ 是代数余子式。
  • 行列式性质：交换两行改变符号、某行乘以常数则行列式乘以该常数、某行加上另一行的倍数不改变行列式值、det(AB) = det A · det B。
  • 克拉默法则：线性方程组 Ax = b 在 det A ≠ 0 时的解为 xjx_{j}xj​ = det AjA_{j}Aj​ / det A。

详细讲解

行列式的定义与计算

n 阶行列式的严格定义基于排列：det A = Σ (−1)^τ(σ) · a_{1,σ(1)} · a_{2,σ(2)} · ... · a_{n,σ(n)}，求和遍历 {1,...,n} 的所有 n! 个排列 σ，τ(σ) 是逆序数。实际计算采用以下方法：

按行展开：选择零元素最多的行或列展开以减少计算量。det A = ΣjaijAijΣ_{j} a_{ij} A_{ij}Σj​aij​Aij​，其中 AijA_{ij}Aij​ = (−1)^(i+j) MijM_{ij}Mij​。

化上三角：利用初等行变换将矩阵化为上三角形，行列式等于主对角线元素之积。这是最高效的手工计算方法，时间复杂度 O(n3n^{3}n3)。

例如计算三阶行列式：先用第一行消去第二、三行的首列元素，再用第二行消去第三行的第二列元素，最终化为上三角形式。

行列式与几何

二阶行列式的绝对值等于两个列向量构成的平行四边形面积。三阶行列式的绝对值等于三个列向量构成的平行六面体体积。符号表示方向（右手定则）。

叉积与行列式：三维空间中向量 a = (a1,a2,a3a_{1},a_{2},a_{3}a1​,a2​,a3​) 和 b = (b1,b2,b3b_{1},b_{2},b_{3}b1​,b2​,b3​) 的叉积可用行列式表示：a × b = |i j k; a1a2a3;b1b2b3a_{1} a_{2} a_{3}; b_{1} b_{2} b_{3}a1​a2​a3​;b1​b2​b3​|。叉积的模等于平行四边形面积。

三角形面积：顶点为 (x1,y1x_{1},y_{1}x1​,y1​)、(x2,y2x_{2},y_{2}x2​,y2​)、(x3,y3x_{3},y_{3}x3​,y3​) 的三角形面积 S = (1/2)|x1x_{1}x1​(y_{2}−y3−y_{3}−y3​) + x2x_{2}x2​(y_{3}−y1−y_{1}−y1​) + x3x_{3}x3​(y_{1}−y2−y_{2}−y2​)|。

克拉默法则及其局限

对于 n 元线性方程组 Ax = b，若 det A ≠ 0，则 xjx_{j}xj​ = det AjA_{j}Aj​ / det A，其中 AjA_{j}Aj​ 是将 A 的第 j 列替换为 b 得到的矩阵。

克拉默法则的理论价值在于证明了方程组解的存在唯一性，并给出了解的显式表达。但其计算复杂度为 O(n · n!)（需计算 n+1 个 n 阶行列式），远不如高斯消元法 O(n3n^{3}n3) 高效。因此克拉默法则主要用于理论分析和小规模方程组（2-3 阶）的求解。

拓展阅读

行列式的概念可追溯到 17 世纪的莱布尼茨和日本数学家关孝和。在现代数学中，行列式被推广为外代数的概念。微分形式和外积运算将行列式的面积/体积解释推广到流形上，是微分几何和广义相对论的数学基础。

在数值计算中，LU 分解将行列式计算的复杂度降到 O(n3n^{3}n3)。对于稀疏矩阵，还有更高效的专用算法。在量子力学中，费米子系统的波函数用 Slater 行列式表示，体现了泡利不相容原理。

对于竞赛选手，行列式的递推计算、利用行列式证明组合恒等式是常见题型。推荐练习《高等代数》（丘维声）习题集中的行列式专题。

小结

行列式是方阵的核心标量函数，编码了线性变换的体积缩放和方向信息。掌握行列式的计算方法（展开、化上三角）、基本性质（转置不变、乘积公式）和应用（可逆判据、克拉默法则、几何面积体积），是理解高等代数理论的关键基础。
