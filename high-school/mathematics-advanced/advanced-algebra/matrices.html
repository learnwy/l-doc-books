理科方向 数学进阶 — 矩阵

知识要点

矩阵是高等代数的基本对象，是将线性方程组、线性变换和向量空间统一描述的数学工具。一个 m×n 矩阵是由 m 行 n 列数排成的矩形阵列，记作 A = (aij)mxna_{ij}){}_{mxn}aij​)mxn​。

  • 矩阵运算：加法（对应元素相加，要求同型）、数乘（每个元素乘以常数）、乘法（A_{m×n} · B_{n×p} = C_{m×p}，其中 cij=Σkaikbkjc_{ij} = Σ_{k} a_{ik} b_{kj}cij​=Σk​aik​bkj​）。矩阵乘法不满足交换律。
  • 特殊矩阵：单位矩阵 E（对角线为 1，其余为 0）、零矩阵 O、对角矩阵、对称矩阵（A = ATA^{T}AT）、正交矩阵（AATAA^{T}AAT = E）。
  • 逆矩阵：若 AB = BA = E，则 B 是 A 的逆矩阵，记作 A−1A^{-1}A−1。可逆的充要条件是 det(A) ≠ 0。
  • 矩阵的秩：矩阵中非零子式的最高阶数。秩反映了矩阵所携带的"独立信息量"，与线性方程组解的结构密切相关。
  • 特征值与特征向量：Av = λv（v ≠ 0）中的 λ 为特征值，v 为特征向量。特征值满足特征方程 det(A − λE) = 0。

详细讲解

矩阵乘法的本质

矩阵乘法看似复杂，但有三种直观理解方式：

行乘列：最基本的定义。结果矩阵的第 i 行第 j 列元素是 A 的第 i 行与 B 的第 j 列的内积。

列的线性组合：AB 的每一列是 A 的列向量的线性组合，组合系数由 B 的对应列提供。如果 A = [a1,a2a_{1}, a_{2}a1​,a2​, ..., ana_{n}an​]（列分块），B 的第 j 列为 bjb_{j}bj​ = (b1j,b2jb_{1j}, b_{2j}b1j​,b2j​, ..., bnj)Tb_{nj}){}^{T}bnj​)T，则 AB 的第 j 列 = b_{1j}a1a_{1}a1​ + b_{2j}a2a_{2}a2​ + ... + b_{nj}ana_{n}an​。

线性变换的复合：矩阵可以看作线性变换。如果 A 代表变换 T1T_{1}T1​，B 代表变换 T2T_{2}T2​，则 AB 代表先做 T2T_{2}T2​ 再做 T1T_{1}T1​。这解释了矩阵乘法不可交换：先旋转再缩放与先缩放再旋转的结果不同。

矩阵乘法满足结合律 (AB)C = A(BC)、分配律 A(B+C) = AB+AC，但不满足交换律、不满足消去律（AB = 0 不能推出 A = 0 或 B = 0）。

逆矩阵的求法

∗∗伴随矩阵法∗∗：A−1**伴随矩阵法**：A^{-1}∗∗伴随矩阵法∗∗：A−1 = (1/det A) · A*，其中 A* 是伴随矩阵（每个元素的代数余子式构成的矩阵的转置）。对于 2×2 矩阵 A = [[a,b],[c,d]]，A−1A^{-1}A−1 = (1/(ad−bc)) · [[d,−b],[−c,a]]。

初等行变换法：将增广矩阵 [A|E] 通过初等行变换化为 [E|A−1A^{-1}A−1]。这种方法在数值计算中更常用，因为避免了计算行列式。

逆矩阵的性质：(A−1)−1A^{-1}){}^{-1}A−1)−1 = A，(AB)−1{}^{-1}−1 = B^{-1}A−1A^{-1}A−1（注意顺序反转），(AT)−1A^{T}){}^{-1}AT)−1 = (A−1)TA^{-1}){}^{T}A−1)T，(kA)−1{}^{-1}−1 = (1/k)A−1A^{-1}A−1。

矩阵与线性方程组

齐次方程组 Ax = 0 有非零解的充要条件是 r(A) < n（变量个数）。解空间的维数为 n − r(A)，称为零度（nullity）。

非齐次方程组 Ax = b 有解的充要条件是 r(A) = r(A|b)（系数矩阵与增广矩阵的秩相等）。若 r(A) = r(A|b) = n，方程有唯一解；若 r(A) = r(A|b) < n，方程有无穷多解。

这些结论统一了初等数学中关于方程组解的讨论，并通过秩给出了定量的判断标准。

特征值与矩阵对角化

特征方程 det(A − λE) = 0 是关于 λ 的 n 次多项式方程。n 阶矩阵有 n 个特征值（计重数，可能有复数特征值）。

矩阵对角化：如果 n 阶矩阵 A 有 n 个线性无关的特征向量 v1,v2v_{1}, v_{2}v1​,v2​, ..., vnv_{n}vn​，对应特征值 λ1,λ2λ_{1}, λ_{2}λ1​,λ2​, ..., λnλ_{n}λn​，则 P−1P^{-1}P−1AP = Λ = diag(λ1,λ2λ_{1}, λ_{2}λ1​,λ2​, ..., λnλ_{n}λn​)，其中 P = [v1,v2v_{1}, v_{2}v1​,v2​, ..., vnv_{n}vn​]。

对角化的威力在于简化矩阵幂的计算：An对角化的威力在于简化矩阵幂的计算：A^{n}对角化的威力在于简化矩阵幂的计算：An = PΛ^{n}P−1P^{-1}P−1 = P · diag(λ_{1}n^{n}n, λ_{2}n^{n}n, ..., λ_{n}n^{n}n) · P−1P^{-1}P−1。

实对称矩阵一定可以正交对角化：存在正交矩阵 Q 使 QTQ^{T}QTAQ = Λ。实对称矩阵的特征值全为实数，不同特征值对应的特征向量正交。

练习与思考

  1. 设 A = [[1,2],[3,4]]，B = [[0,1],[1,0]]。计算 AB 和 BA，验证 AB ≠ BA。求 A 的逆矩阵。

  2. 用初等行变换法求矩阵 A = [[1,2,3],[2,5,7],[3,7,11]] 的逆矩阵（如果存在）。如果不可逆，求其秩。

  3. 求矩阵 A = [[3,1],[0,2]] 的特征值和特征向量。写出对角化分解 A = PΛP−1PΛP^{-1}PΛP−1，并利用此分解计算 A10A^{10}A10。

  4. 证明：如果 A 是实对称矩阵，则 A 的所有特征值都是实数。（提示：设 Av = λv，考虑 vˉTv̄^{T}vˉTAv 和 vˉTv̄^{T}vˉT(Av) 的共轭关系。）

拓展阅读

矩阵理论在现代科学和工程中无处不在。Google 的 PageRank 算法本质上是求一个巨大矩阵（网页链接矩阵）的主特征向量。主成分分析（PCA）通过计算数据协方差矩阵的特征值和特征向量来降维。量子力学中的可观测量用厄米矩阵（自伴算子）表示，测量结果恰好是特征值。

奇异值分解（SVD）将任意矩阵分解为 A = UΣVTUΣV^{T}UΣVT，是数据科学中最重要的矩阵分解。SVD 在图像压缩、推荐系统和自然语言处理中有广泛应用。

对于竞赛选手，Cayley-Hamilton 定理（矩阵满足自身的特征方程）、矩阵的若尔当标准形和矩阵指数 eAe^{A}eA 是进阶内容。推荐阅读丘维声《高等代数》或 Gilbert Strang《Introduction to Linear Algebra》。

小结

矩阵是线性代数的核心语言。矩阵乘法表示线性变换的复合，逆矩阵对应可逆变换，秩刻画了变换的信息保留能力，特征值和特征向量揭示了变换的本征方向和伸缩因子。掌握矩阵理论不仅是数学竞赛的重要考点，更是理解量子力学、数据科学和工程计算的数学基础。
