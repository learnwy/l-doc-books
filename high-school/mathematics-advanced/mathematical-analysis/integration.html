理科方向 数学进阶 — 积分学

知识要点

积分学是微积分的第二大支柱，与微分学互为逆运算。不定积分求原函数，定积分计算"累积量"——面积、体积、做功、概率等。牛顿-莱布尼茨公式将微分与积分统一起来，是数学史上最深刻的发现之一。

  • 不定积分：F'(x) = f(x) 时称 F(x) 为 f(x) 的原函数。∫f(x)dx = F(x) + C（C 为任意常数）。不定积分的结果是一族函数。
  • ∗∗定积分∗∗：∫a**定积分**：∫_{a}∗∗定积分∗∗：∫a​^{b}f(x)dx=lim(n→∞)Σf(f(x)dx = lim(n→∞) Σ f(f(x)dx=lim(n→∞)Σf(x_{i})Δx_{i}$（黎曼和的极限）。几何意义是曲线 y = f(x) 与 x 轴之间的有向面积。
  • ∗∗牛顿−莱布尼茨公式∗∗：∫a**牛顿-莱布尼茨公式**：∫_{a}∗∗牛顿−莱布尼茨公式∗∗：∫a​^{b}$ f(x)dx = F(b) − F(a)，将定积分的计算转化为求原函数。
  • 积分方法：换元法（第一类和第二类）、分部积分法、有理函数积分、三角函数积分等。
  • 积分应用：平面图形面积、旋转体体积、曲线弧长、物理量（功、质心、转动惯量）的计算。

换元积分法

第一类换元法（凑微分法）：利用 ∫f(g(x))g'(x)dx = ∫f(u)du（令 u = g(x)）。关键是识别被积函数中可以凑成某个函数微分的部分。

第二类换元法：通过变量替换简化被积函数的结构。常用的替换包括：

分部积分法

公式：∫ u dv = uv − ∫ v du。选择 u 和 dv 的原则是使 ∫ v du 比原积分更简单。

经验法则（LIATE 规则）：优先选择以下类型的函数作为 u（从左到右优先级递减）：对数函数(L)、反三角函数(I)、代数函数(A)、三角函数(T)、指数函数(E)。

例：∫ x exe^{x}ex dx。选 u = x, dv = exe^{x}ex dx，则 du = dx, v = exe^{x}ex。 ∫ x exe^{x}ex dx = x exe^{x}ex − ∫ exe^{x}ex dx = x exe^{x}ex − exe^{x}ex + C = exe^{x}ex(x−1) + C

表格法（快速分部积分）：对于 ∫ P(x) exe^{x}ex dx 或 ∫ P(x) sin x dx 类型（P(x) 为多项式），反复分部积分可用表格快速完成：第一列写 P(x) 及其各阶导数，第二列写 exe^{x}ex（或 sin x）及其各阶积分，交叉相乘并交替加减。

拓展阅读

积分理论在高等数学中有更深层的发展。勒贝格积分（20 世纪初）将黎曼积分推广到更广泛的函数类，解决了"可积性"的根本问题。多重积分将一元积分推广到多维空间，格林公式、高斯公式和斯托克斯公式建立了不同维度积分之间的深刻联系。

在概率论中，连续型随机变量的概率就是概率密度函数的积分：P(a ≤ X ≤ b) = ∫a∫_{a}∫a​^{b}f(x)dx。正态分布的概率密度函数f(x)=(1/√2π)e(f(x) dx。正态分布的概率密度函数 f(x) = (1/√2π) e^(f(x)dx。正态分布的概率密度函数f(x)=(1/√2π)e(−x^{2}$/2) 的全实数轴积分等于 1，这个结果的证明需要用到极坐标下的二重积分技巧。

对于数学竞赛选手，定积分与不等式的结合、积分不等式（如 Cauchy-Schwarz 积分不等式）是重要的考点。推荐练习《数学分析习题集》（吉米多维奇）中的积分章节。

小结

积分学通过累积的思想将微小量合成整体量。不定积分是求导的逆运算，定积分是黎曼和的极限，牛顿-莱布尼茨公式将两者统一。换元法和分部积分法是计算积分的核心技巧，定积分的应用则将数学工具与物理、几何问题紧密相连。掌握积分学是通向高等数学和科学计算的必经之路。
