理科方向 数学进阶 — 微分学

知识要点

微分学研究函数的局部变化率，是数学分析的第一大支柱。导数概念将"瞬时变化速度"从物理直觉提升为严格的数学定义，而微分则提供了用线性函数近似非线性函数的强大工具。

  • 导数定义：f'(x0x_{0}x0​) = lim(Δx→0) [f(x0x_{0}x0​+Δx) − f(x0x_{0}x0​)] / Δx。几何意义是曲线在该点切线的斜率，物理意义是瞬时变化率（速度、加速度等）。
  • 求导法则：基本初等函数的导数公式、四则运算法则（和差积商）、复合函数求导（链式法则）、隐函数求导、参数方程求导、对数求导法。
  • 中值定理：罗尔定理、拉格朗日中值定理、柯西中值定理是微分学的核心理论，连接了函数值的变化与导数的关系。
  • 导数应用：单调性判断、极值与最值、凹凸性与拐点、渐近线、函数作图、不等式证明、方程根的讨论。
  • 泰勒展开：用多项式逼近函数，提供了比线性近似更精确的局部描述。

详细讲解

导数的严格定义与计算

导数的定义本质上是一个极限过程。以 f(x) = xnx^{n}xn 为例，用二项式定理展开：

f'(x) = lim(h→0) [(x+h)n{}^{n}n − xnx^{n}xn] / h = lim(h→0) [nxn−1nx^{n-1}nxn−1h + C(n,2)x^{n-2}h2h^{2}h2 + ...] / h = nxn−1nx^{n-1}nxn−1

这就是幂函数的求导公式 (xnx^{n}xn)' = nxn−1nx^{n-1}nxn−1。将此推广到任意实数指数 α：(xαx^{\alpha}xα)' = αxα−1αx^{\alpha-1}αxα−1。

链式法则是求导的核心工具。对于复合函数 y = f(g(x))，有 dy/dx = f'(g(x)) · g'(x)。直觉理解：外层对内层求导，再乘以内层对 x 的导数。多层复合时逐层展开。

对数求导法适用于幂指函数 y = u(x)^v(x)。两边取对数：ln y = v(x) · ln u(x)，两边对 x 求导：y'/y = v'·ln u + v·u'/u，故 y' = y·[v'·ln u + v·u'/u]。

隐函数求导：对方程两边同时对 x 求导，注意 y 是 x 的函数。例如对 x2+y2x^{2} + y^{2}x2+y2 = 1 两边求导：2x + 2y·y' = 0，解得 y' = −x/y。

中值定理体系

罗尔定理：若 f(x) 在 [a,b] 连续，在 (a,b) 可导，且 f(a) = f(b)，则存在 ξ ∈ (a,b) 使 f'(ξ) = 0。几何含义：连接曲线两端点的弦是水平的，则曲线上至少存在一点切线是水平的。

拉格朗日中值定理：若 f(x) 在 [a,b] 连续，在 (a,b) 可导，则存在 ξ ∈ (a,b) 使 f'(ξ) = [f(b) − f(a)] / (b − a)。这是罗尔定理的推广：曲线上至少存在一点切线平行于连接两端点的弦。

柯西中值定理：若 f(x)、g(x) 在 [a,b] 连续，在 (a,b) 可导，且 g'(x) ≠ 0，则存在 ξ 使 f'(ξ)/g'(ξ) = [f(b)−f(a)] / [g(b)−g(a)]。这是洛必达法则的理论基础。

中值定理在竞赛中的典型应用包括：证明不等式（构造辅助函数使其满足罗尔定理条件）、证明方程根的存在性、估计函数值的范围。

泰勒展开

泰勒公式将函数在某点附近展开为多项式加余项：

f(x) = f(a) + f'(a)(x−a) + f''(a)(x−a)2{}^{2}2/2! + ... + f(n)f^{(n)}f(n)(a)(x−a)n{}^{n}n/n! + RnR_{n}Rn​(x)

泰勒展开的应用：求极限（展开到能消去不定型的阶数）、近似计算（如 √1.01 ≈ 1 + 0.01/2 = 1.005）、证明不等式（如 exe^{x}ex ≥ 1 + x）。

导数在不等式证明中的应用

利用导数证明不等式是竞赛数学的重要技巧。基本思路：将不等式转化为函数的单调性或极值问题。

例如证明 exe^{x}ex ≥ 1 + x（对所有实数 x 成立）：

设 f(x) = exe^{x}ex − 1 − x，则 f'(x) = exe^{x}ex − 1。当 x > 0 时 f'(x) > 0，当 x < 0 时 f'(x) < 0，所以 x = 0 是 f(x) 的最小值点。f(0) = 0，故 f(x) ≥ f(0) = 0，即 exe^{x}ex ≥ 1 + x。

拓展阅读

微分学的思想贯穿了现代科学与工程。在物理学中，牛顿运动定律 F = ma 本质上是位置关于时间的二阶微分方程。在经济学中，边际成本、边际效用等概念就是导数。在机器学习中，梯度下降法利用损失函数的梯度（多元导数）来优化模型参数。

多元函数的微分学将一元的导数推广为偏导数、方向导数和梯度。拉格朗日乘数法利用梯度来求解带约束的最优化问题，是工程设计和经济学中最常用的数学工具之一。

对于数学竞赛选手，建议系统学习分析学中的介值定理、不动点定理和构造辅助函数的技巧。裴礼文《数学分析中的典型问题与方法》是中文经典参考书。

小结

微分学的核心是用局部线性近似理解函数的行为。导数给出了函数的瞬时变化率，中值定理建立了函数值变化与导数之间的桥梁，泰勒展开则提供了任意精度的多项式近似。掌握微分学不仅是数学分析的基础，也是物理建模、工程优化和数据科学的核心数学工具。
