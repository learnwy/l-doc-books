理科方向 数学进阶 — 极限与连续

知识要点

极限是微积分的基础概念，描述函数或数列在某一趋近过程中的变化趋势。连续性则是函数在某点处"不跳跃、不断裂"的精确数学描述。极限与连续的理论是从高中数学向大学数学过渡的桥梁。

  • 数列极限：如果数列 {ana_{n}an​} 当 n 趋向无穷大时无限接近某个确定值 A，则称 A 为该数列的极限，记作 lim(n→∞) ana_{n}an​ = A。ε-N 语言的精确定义：对任意 ε > 0，存在正整数 N，当 n > N 时有 |ana_{n}an​ − A| < ε。
  • 函数极限：lim(x→x0x→x_{0}x→x0​) f(x) = L 意味着当 x 从任何方向趋近 x0x_{0}x0​ 时，f(x) 都无限接近 L。左极限和右极限必须相等，极限才存在。
  • 无穷小与无穷大：极限为零的变量称为无穷小量，无穷小的阶反映了趋近零的速度。等价无穷小替换是求极限的重要技巧。
  • 连续性：函数 f(x) 在 x0x_{0}x0​ 处连续的三个条件：f(x0x_{0}x0​) 有定义、lim(x→x0x→x_{0}x→x0​) f(x) 存在、极限值等于函数值。不满足这些条件分别对应不同类型的间断点。

详细讲解

数列极限的计算方法

基本极限：lim(n→∞) 1/n = 0，lim(n→∞) qnq^{n}qn = 0（|q| < 1），lim(n→∞) (1 + 1/n)n{}^{n}n = e ≈ 2.71828。最后一个极限是自然对数底 e 的定义，它在微积分、概率论和复分析中无处不在。

极限运算法则：如果 lim ana_{n}an​ = A，lim bnb_{n}bn​ = B，则 lim(an±bna_{n} ± b_{n}an​±bn​) = A ± B，lim(an⋅bna_{n} · b_{n}an​⋅bn​) = A · B，lim(a_{n}/bn/b_{n}/bn​) = A/B（B ≠ 0）。这些法则允许将复杂的极限分解为简单极限的组合。

夹逼定理（三明治定理）：如果对充分大的 n 有 an≤bn≤cna_{n} ≤ b_{n} ≤ c_{n}an​≤bn​≤cn​，且 lim ana_{n}an​ = lim cnc_{n}cn​ = L，则 lim bnb_{n}bn​ = L。例如求 lim(n→∞) (n!)^(1/n)/n 需要用斯特林公式或夹逼法。

单调有界定理：单调递增有上界的数列必有极限，单调递减有下界的数列必有极限。这是证明极限存在的重要工具。例如递推数列 a1a_{1}a1​ = √2，an+1a_{n+1}an+1​ = √(2 + ana_{n}an​)，可以用数学归纳法证明递增有界（上界为 2），从而极限存在，设极限为 L，由 L = √(2 + L) 解得 L = 2。

函数极限与重要极限

两个重要极限：

  1. lim(x→0) sin x / x = 1（可用夹逼定理和扇形面积比较证明）
  2. lim(x→∞) (1 + 1/x)x{}^{x}x = e（与数列极限 (1+1/n)n{}^{n}n 等价）

等价无穷小替换：当 x → 0 时，以下等价关系成立：

等价无穷小替换只能在乘除法中使用，在加减法中一般不能使用（除非两项不等价）。

洛必达法则：当极限呈现 0/0 或 ∞/∞ 的不定型时，可以对分子分母分别求导后再取极限。其他不定型（0·∞、∞−∞、000^{0}00、1^∞、∞0∞^{0}∞0）需要先转化为 0/0 或 ∞/∞。

连续性与间断点分类

函数在某点不连续时，该点称为间断点。间断点分为两类：

第一类间断点：左右极限都存在（有限）。如果左右极限相等但不等于函数值（或函数无定义），称为可去间断点；如果左右极限不相等，称为跳跃间断点。

第二类间断点：左右极限至少有一个不存在或为无穷。例如 f(x) = sin(1/x) 在 x = 0 处的极限不存在（振荡间断点），f(x) = 1/x 在 x = 0 处的极限为无穷（无穷间断点）。

连续函数的性质：

  • 介值定理：如果 f(x) 在 [a,b] 上连续，且 f(a) · f(b) < 0，则存在 c ∈ (a,b) 使 f(c) = 0。这是二分法求方程近似根的理论基础。
  • 最值定理：连续函数在闭区间上必有最大值和最小值。
  • 一致连续性：如果 f(x) 在 [a,b] 上连续，则它在 [a,b] 上一致连续（收敛速度与位置无关）。

竞赛级极限问题

数学竞赛和自主招生中，极限问题常与级数求和结合。例如：

求极限 lim(n→∞) (1/n) × [sin(π/n) + sin(2π/n) + ... + sin(nπ/n)]

这实际上是定积分 ∫0∫_{0}∫0​^π sin x dx = 2 的黎曼和形式。将区间 [0,π] 等分为 n 份，每份宽度 Δx = π/n，取右端点 xkx_{k}xk​ = kπ/n，则上式 = (π/n) × Σ sin(kπ/n) × (1/π) → (1/π) ∫0∫_{0}∫0​^π sin x dx = 2/π。这种将离散求和转化为定积分的方法在竞赛中极为常用。

练习与思考

  1. 用 ε-N 语言证明 lim(n→∞) (2n+1)/(3n−1) = 2/3。

  2. 计算以下极限：

    • lim(x→0) (tan x − sin x) / x3x^{3}x3
    • lim(x→0) (exe^{x}ex − e^(−x)) / (2 sin x)
    • lim(x→∞) (1 + 3/x)^(2x)

  3. 判断函数 f(x) = (x2x^{2}x2 − 1)/(x − 1)（x ≠ 1），f(1) = 3 在 x = 1 处的连续性。如果不连续，判断间断点类型并说明如何修改使其连续。

  4. 利用夹逼定理证明 lim(n→∞) (1/√(n2n^{2}n2+1) + 1/√(n2n^{2}n2+2) + ... + 1/√(n2n^{2}n2+n)) = 1。

拓展阅读

极限概念的严格化经历了漫长的历史过程。牛顿和莱布尼茨在 17 世纪发明微积分时使用的是直觉性的"无穷小量"概念。19 世纪柯西用 ε-δ 语言给出了极限的严格定义，魏尔斯特拉斯进一步完善了分析学的基础。20 世纪 60 年代，鲁滨逊发展了非标准分析，重新为"无穷小量"赋予了严格的数学含义。

实分析课程中，极限理论会进一步发展为点集拓扑的框架：开集、闭集、紧致性、连通性等概念将连续性推广到一般的度量空间和拓扑空间。对于有志于纯数学的同学，这些抽象化是必经之路。

建议阅读陈纪修《数学分析》第一、二章或 Ruerta《Principles of Mathematical Analysis》的前几章，系统学习极限与连续的完整理论。

小结

极限与连续是数学分析的基石。数列极限描述了离散过程的趋近行为，函数极限描述了连续变化的趋近行为，连续性则将极限与函数值统一起来。掌握极限的计算技巧（等价无穷小、洛必达法则、夹逼定理）和连续性的理论（间断点分类、介值定理），不仅是数学竞赛和自主招生的核心考点，更是理解微分学和积分学的必要前提。
