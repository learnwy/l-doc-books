理科方向 数学进阶 — 组合数学

知识要点

组合数学研究离散结构的计数、存在性和构造问题。在数学竞赛中，组合问题以其灵活多变、不依赖高深理论但需要巧妙构思而著称，是区分选手水平的关键题型。

  • 基本计数原理：加法原理（分类计数）和乘法原理（分步计数）是所有组合计数的基础。
  • 排列与组合：P(n,k) = n!/(n−k)! 为排列数，C(n,k) = n!/[k!(n−k)!] 为组合数。C(n,k) 满足递推关系 C(n,k) = C(n−1,k−1) + C(n−1,k)（帕斯卡恒等式）。
  • 二项式定理：(a+b)n=Σk{}^{n} = Σ_{k}n=Σk​ C(n,k) a^{n-k}bkb^{k}bk。推论：Σ C(n,k) = 2n2^{n}2n，Σ(−1)k{}^{k}k C(n,k) = 0。
  • 容斥原理：|$$A1A_{1}A1​∪A_{2}∪...∪An∪...∪A_{n}∪...∪An​| = Σ|AiA_{i}Ai​| − Σ|A_{i}∩Aj∩A_{j}∩Aj​| + Σ|$$AiA_{i}Ai​∩A_{j}∩Ak∩A_{k}∩Ak​| − ... + (−1)n+1{}^{n+1}n+1|A_{1}∩...∩An∩...∩A_{n}∩...∩An​|。
  • 鸽巢原理：n+1 个物体放入 n 个盒子，至少有一个盒子包含两个物体。推广：若有 kn+1 个物体放入 n 个盒子，至少有一个盒子包含 k+1 个物体。

详细讲解

高级计数方法

多重集的排列与组合：从含 n1n_{1}n1​ 个 a1a_{1}a1​、n2n_{2}n2​ 个 a2a_{2}a2​、...、nkn_{k}nk​ 个 aka_{k}ak​ 的多重集中取全排列，总数为 n!/( $ $n1n_{1}n1​!n_{2}!...nk!...n_{k}!...nk​!)（多项式系数）。

隔板法：将 n 个相同球放入 k 个不同盒子（每盒至少 1 个）的方案数为 C(n−1, k−1)。允许空盒时为 C(n+k−1, k−1)。

∗∗卡特兰数∗∗：Cn**卡特兰数**：C_{n}∗∗卡特兰数∗∗：Cn​ = C(2n,n)/(n+1) = 1, 1, 2, 5, 14, 42, 132, ...。出现在众多计数问题中：合法括号序列数、n+1 个叶子的满二叉树数、凸多边形的三角剖分数、n×n 格点不越过对角线的路径数等。

斯特林数：第二类 Stirling 数 S(n,k) 是将 n 个不同元素分成 k 个非空子集的方案数。递推关系 S(n,k) = k·S(n−1,k) + S(n−1,k−1)。

容斥原理的应用

错排问题：n 个元素的全错排（没有元素在原位）数目 DnD_{n}Dn​ = n! · Σ_{k=0}n^{n}n (−1)k{}^{k}k/k! ≈ n!/e。

欧拉函数：φ(n) = n ∏p∣n∏_{p}|{}_{n}∏p​∣n​ (1−1/p) 的推导正是容斥原理的经典应用。从 {1,2,...,n} 中去掉 n 的每个素因子的倍数，再加回公共倍数，如此交替。

多面体的面-边-顶点关系：容斥原理还可以推导欧拉公式 V − E + F = 2。

鸽巢原理的高级应用

鸽巢原理看似简单，但巧妙地构造"鸽子"和"鸽巢"是竞赛中的核心技巧。

经典问题：任意选 n+1 个不超过 2n 的正整数，其中必有两个互素。构造：将 {1,...,2n} 分为 n 组 {1,2}, {3,4}, ..., {2n−1,2n}，相邻两数互素。

Erdős–Szekeres 定理：长度为 mn+1 的序列中，必有长度为 m+1 的递增子序列或长度为 n+1 的递减子序列。证明用鸽巢原理：对每个元素标记 (ai,bia_{i},b_{i}ai​,bi​)，其中 aia_{i}ai​ 是以该元素开头的最长递增子序列长度，bib_{i}bi​ 是最长递减子序列长度。若所有 aia_{i}ai​ ≤ m 且 bib_{i}bi​ ≤ n，则标记只有 mn 种，但有 mn+1 个元素，矛盾。

生成函数方法

生成函数将组合计数问题转化为代数运算。序列 {ana_{n}an​} 的普通生成函数为 f(x) = Σ a_{n}xnx^{n}xn。

斐波那契数列的封闭公式：F(x) = x/(1−x−x21−x−x^{2}1−x−x2)。分解部分分数后展开，得到 FnF_{n}Fn​ = (φnφ^{n}φn − ψnψ^{n}ψn)/√5，其中 φ = (1+√5)/2（黄金比），ψ = (1−√5)/2。

卡特兰数的生成函数：C(x) = (1−√(1−4x))/(2x)，满足方程 C(x) = 1 + xC(x)2{}^{2}2，反映了卡特兰数的递推结构。

图论中的组合

握手定理：图的所有顶点度数之和等于边数的两倍。推论：度数为奇数的顶点个数为偶数。

拉姆齐定理：R(3,3) = 6，即 6 人聚会中必有 3 人互相认识或 3 人互不认识。更一般地，R(m,n) 存在但具体值难以计算。

拓展阅读

组合数学与计算机科学的联系极为紧密。算法复杂度分析、数据结构设计、编码理论都大量使用组合数学工具。概率组合方法（Lovász Local Lemma、随机图理论）在理论计算机科学中发挥关键作用。

近年来，代数组合学将代数结构（群论、表示论）引入组合计数，产生了对称函数理论、Young 表等深刻工具。极值组合学研究最大/最小化某种组合结构的问题，如 Turán 定理给出了不含 K_{r+1} 的图的最大边数。

对于竞赛选手，推荐 Miklos Bona《A Walk Through Combinatorics》和《组合数学》（Richard Brualdi 著，冯速译）。IMO 和 CMO 历年真题中的组合题是最好的练习材料。

小结

组合数学的魅力在于用简洁的原理解决看似复杂的计数和存在性问题。从加法乘法原理到容斥原理，从鸽巢原理到生成函数，组合数学提供了一整套从简单到精巧的工具箱。在数学竞赛中，组合问题最能考查选手的创造力和逻辑严密性，是通向高水平数学思维的重要训练场。
