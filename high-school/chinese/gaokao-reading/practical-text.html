高三语文 — 实用类文本阅读

知识要点

高考实用类文本阅读近年经历了从单一非连续性文本向"信息类文本阅读"的转型。新高考卷将实用类文本与论述类文本合并为"现代文阅读Ⅰ"，分值约 171717 至 191919 分，设置 555 道题（333 道选择 +++ 222 道主观）。命题材料涵盖新闻报道、学术论文、调查报告、科普说明等多种文体，通常以多材料组合形式呈现，考查信息筛选、比较分析和逻辑推理能力。

实用类文本的核心考点分布：

考点 题型 分值占比 难度
信息筛选与整合 选择题 约 40%40\%40% 中等
文本内容理解 选择题 约 20%20\%20% 中等
概括与归纳 主观题 约 20%20\%20% 较高
观点比较与评价 主观题 约 20%20\%20% 高

详细讲解

一、信息类文本的阅读方法

实用类文本的阅读策略与文学类文本截然不同。文学类文本需要"沉浸式阅读"以体会情感，而信息类文本需要"检索式阅读"以提取关键信息。

快速阅读三步法：

  1. 扫读标题与出处（303030 秒）：判断材料主题、来源的权威性和时效性。标题往往直接揭示材料的核心观点。
  2. 通读各则材料（333 至 444 分钟）：每则材料读完后用一句话概括其核心信息。不必纠结个别词句。
  3. 标注关键信息（随读随标）：数据、时间节点、因果关系、转折处（"但是""然而""事实上"）、限定词（"部分""大多数""主要"）。

特别注意限定词。高考选项常在限定词上做文章：

原文表述 错误选项改写 错误类型
"大多数研究者认为" "研究者普遍认为" 范围扩大
"在一定条件下可以实现" "已经实现" 或然变必然
"这是原因之一" "这是根本原因" 主次颠倒
"截至 202220222022 年" 未标注时间限制 时间偷换

二、选择题的比对技巧

信息类文本的选择题本质上是"选项与原文的精确比对"。高效比对的方法是"逐句定位、逐词比较"。

常见干扰项类型：

①偷换概念：将原文中的某个概念替换为相近但不同的概念。例如原文说"人工智能技术"，选项改为"计算机技术"。

②因果倒置：将原文中的因果关系颠倒。例如原文说"因为 A 所以 B"，选项改为"因为 B 所以 A"。

③无中生有：选项中的信息在所有材料中都找不到依据。这类干扰项往往表述合理、符合常识，但就是没有文本支撑。

④张冠李戴：将材料一中的内容说成材料二的观点，或将甲研究者的结论归到乙研究者名下。

⑤过度引申：在原文结论的基础上进行了不合理的推论延伸。

比对实操建议：先读选项画出关键词，再回原文定位对应段落，逐个关键词核对。发现一处不符即可排除。

三、多材料组合阅读策略

新高考的信息类文本通常由 222 至 333 则材料组合而成，材料之间存在特定的逻辑关系。识别这些关系是答题的关键。

常见的材料组合模式：

组合模式 材料关系 答题要点
互补型 不同角度阐述同一话题 综合各则材料归纳全貌
对比型 呈现不同观点或立场 区分各方观点，避免混淆
递进型 从现象到原因到对策 理清逻辑链条
佐证型 数据/案例支撑核心论点 区分论点与论据

处理多材料题的步骤：

  1. 每则材料读完标注其核心信息
  2. 识别材料之间的关系（互补/对比/递进）
  3. 做题时先判断题目考查的是单则材料还是跨材料比较
  4. 跨材料比较题需要在各材料中分别定位信息再综合

四、主观题的答题规范

信息类文本的主观题通常有两种：概括归纳题和分析评价题。

概括归纳题的答题规范：

  • 明确概括范围（某一则材料还是所有材料）
  • 分条陈述，每条一个要点
  • 使用原文关键词，不要过度改写
  • 注意字数限制和分值（通常 111 分 111 个要点）

分析评价题的答题模板：

观点 + 依据 + 分析

例：关于人工智能是否会取代人类劳动——
材料一认为……（概括观点），其依据是……（引用文本）；
材料二则指出……（概括不同观点），这是基于……（引用文本）。
两则材料的分歧在于……（分析差异的根源）。

五、图表信息题的处理

高考实用类文本经常包含图表（柱状图、折线图、表格、流程图），考查从图表中提取和解读信息的能力。

图表阅读四要素：

  1. 标题：明确图表反映的主题
  2. 坐标/表头：理解数据维度
  3. 数据趋势：上升/下降/波动/稳定
  4. 峰值与拐点：关注极端值和转折点

图表信息转述的语言规范：

  • "由图可知，201820182018 年至 202320232023 年间，我国新能源汽车销量呈持续增长趋势"
  • "表中数据显示，A 地区人均收入最高，约为 B 地区的 2.32.32.3 倍"
  • 避免使用模糊表述如"差不多""看起来"

六、论述类内容的逻辑分析

当信息类文本涉及学术论文或评论文章时，需要把握其论证逻辑。

核心论证要素识别：

要素 功能 识别方法
中心论点 统领全文的核心主张 通常在文首或文末，是判断性语句
分论点 支撑中心论点的子观点 通常位于段首，与中心论点构成总分关系
论据 支撑论点的事实或道理 事实论据（数据、事例）、道理论据（名言、原理）
论证方法 论点与论据的连接方式 举例论证、对比论证、引用论证、比喻论证、归谬法

答题时要区分"论点"和"论据"——选项把论据当论点是高频陷阱。

练习与思考

  1. 选取一篇近年高考真题的信息类文本阅读，先不做题，用 555 分钟通读所有材料，为每则材料写一句话摘要，然后检查你的摘要是否覆盖了题目考查的信息。
  2. 以下表述中，哪些属于"偷换概念"，哪些属于"过度引申"？
    • 原文："部分城市试点了数字人民币"→ 选项："我国已全面推广数字人民币"
    • 原文："这项技术有望降低成本"→ 选项："这项技术能够降低成本"
    • 原文："新能源汽车产业发展迅速"→ 选项："汽车产业发展迅速"
  3. 从近三年全国卷中找出 222 道跨材料比较题，分析每道题涉及了哪些材料的哪些段落，归纳跨材料题的命题规律。
  4. 画出某篇论述类文本的论证结构图：中心论点 → 分论点 → 论据，检查论证链条是否完整。
  5. 限时训练：在 181818 分钟内完成一套信息类文本阅读真题（555 道题），记录每道题的用时分布。

拓展阅读

  • 高考评价体系提出"信息性阅读"能力框架，强调对真实语境中复杂信息的处理能力。
  • 《人民日报》社论和《光明日报》学术版是高考实用类文本的常见选材来源，日常阅读有助于熟悉其语言风格和论述结构。
  • PISA（国际学生评估项目）的阅读素养框架将信息类文本阅读分为"检索""理解""评价与反思"三个层次，与高考考查方向高度一致。
  • 科普刊物如《科学》《环球科学》的中文文章也是优质练习素材，尤其适合训练科技类文本的信息提取能力。

小结

实用类文本（信息类文本）阅读的核心能力是信息的快速定位与精准比对。选择题的突破在于逐词比对，识别偷换概念、因果倒置、无中生有、张冠李戴和过度引申五种干扰类型。多材料组合阅读要先识别材料之间的逻辑关系（互补、对比、递进、佐证），再有针对性地跨材料整合信息。主观题分点作答、紧扣原文，图表题关注标题、坐标、趋势和拐点。总用时控制在 181818 分钟以内，确保选择题零失误、主观题得分率超过 70%70\%70%。
