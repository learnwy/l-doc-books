日志分析技术

日志的工程价值

日志是系统的"黑匣子"——当一切正常时无人在意，但当故障发生时，日志质量直接决定了问题定位的速度。好的日志体系能让你在 5 分钟内定位问题，差的日志体系可能让你花 5 小时都找不到头绪。



结构化日志
非结构化 vs 结构化
传统的纯文本日志难以被程序解析和检索。结构化日志使用 JSON 格式，让日志成为可查询的数据。






维度
非结构化日志
结构化日志





格式
[2024-03-15 10:30:45] ERROR - Failed to process order 12345
{"timestamp":"2024-03-15T10:30:45Z","level":"error","msg":"Failed to process order","orderId":"12345"}

日志结构设计
interface StructuredLog {
  timestamp: string;
  level: 'debug' | 'info' | 'warn' | 'error' | 'fatal';
  message: string;
  service: string;
  traceId?: string;
  spanId?: string;
  userId?: string;
  requestId?: string;
  duration?: number;
  error?: {
    name: string;
    message: string;
    stack: string;
  };
  context?: Record<string, unknown>;
}
实现示例
import pino from 'pino';

const logger = pino({
  level: process.env.LOG_LEVEL ?? 'info',
  formatters: {
    level: (label) => ({ level: label }),
  },
  timestamp: pino.stdTimeFunctions.isoTime,
  base: {
    service: 'order-service',
    env: process.env.NODE_ENV,
  },
});

const requestLogger = (req: Request) =>
  logger.child({
    requestId: req.headers.get('x-request-id'),
    traceId: req.headers.get('x-trace-id'),
    method: req.method,
    path: new URL(req.url).pathname,
  });

grep/jq 命令行技巧
cat app.log | jq 'select(.level == "error")'

cat app.log | jq 'select(.orderId == "12345")'

cat app.log | jq 'select(.level == "error") | {time: .timestamp, msg: .message, err: .error.message}'

cat app.log | jq -s 'group_by(.level) | map({level: .[0].level, count: length})'

cat app.log | jq 'select(.timestamp >= "2024-03-15T10:00:00" and .timestamp <= "2024-03-15T11:00:00")'

分布式追踪
在微服务架构中，一个用户请求可能经过多个服务。分布式追踪通过 Trace ID 将跨服务的日志串联起来。


OpenTelemetry 集成
import { trace, context, SpanStatusCode } from '@opentelemetry/api';

const tracer = trace.getTracer('order-service');

async function processOrder(order: Order): Promise<OrderResult> {
  return tracer.startActiveSpan('processOrder', async (span) => {
    try {
      span.setAttribute('order.id', order.id);
      span.setAttribute('order.itemCount', order.items.length);

      const validated = await tracer.startActiveSpan('validateOrder', async (childSpan) => {
        const result = await validateOrder(order);
        childSpan.end();
        return result;
      });

      const result = await chargeAndFulfill(validated);
      span.setStatus({ code: SpanStatusCode.OK });
      return result;
    } catch (error) {
      span.setStatus({
        code: SpanStatusCode.ERROR,
        message: error instanceof Error ? error.message : 'Unknown error',
      });
      span.recordException(error as Error);
      throw error;
    } finally {
      span.end();
    }
  });
}

function createRequestMiddleware(logger: Logger) {
  return async (req: Request, next: () => Promise<Response>): Promise<Response> => {
    const requestId = req.headers.get('x-request-id') ?? crypto.randomUUID();
    const start = performance.now();
    const reqLogger = logger.child({ requestId });

    reqLogger.info('请求开始', {
      method: req.method,
      path: new URL(req.url).pathname,
    });

    try {
      const response = await next();
      const duration = Math.round(performance.now() - start);

      reqLogger.info('请求完成', {
        status: response.status,
        duration,
      });

      return response;
    } catch (error) {
      const duration = Math.round(performance.now() - start);

      reqLogger.error('请求失败', {
        error:
          error instanceof Error
            ? {
                name: error.name,
                message: error.message,
                stack: error.stack,
              }
            : String(error),
        duration,
      });

      throw error;
    }
  };
}
日志是工程师最重要的"感知系统"。好的日志实践不是故障发生后的补救措施，而是在编写代码时就内建的可观测性能力。当你养成在关键路径上打出结构化、上下文丰富的日志的习惯时，未来的每一次故障排查都会感谢今天的你。
