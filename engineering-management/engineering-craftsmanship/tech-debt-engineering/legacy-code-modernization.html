遗留代码现代化

什么是遗留代码

Michael Feathers 在《Working Effectively with Legacy Code》中给出了一个精辟的定义：遗留代码就是没有测试的代码。不管它是昨天写的还是十年前写的，只要没有测试保护，修改它就是在走钢丝。



表征测试（Characterization Tests）
面对遗留代码，第一步不是理解它应该做什么，而是记录它实际上在做什么。表征测试就是为这个目的而设计的。

import { describe, it, expect } from 'vitest';
import { calculateShipping } from '../legacy/shipping';

describe('calculateShipping (表征测试)', () => {
  it('小订单使用标准运费', () => {
    const result = calculateShipping({
      items: [{ weight: 0.5, price: 20 }],
      destination: 'domestic',
    });
    expect(result).toBe(8.0);
  });

  it('大订单免运费', () => {
    const result = calculateShipping({
      items: [{ weight: 2, price: 200 }],
      destination: 'domestic',
    });
    expect(result).toBe(0);
  });

  it('国际订单加收费用', () => {
    const result = calculateShipping({
      items: [{ weight: 1, price: 50 }],
      destination: 'international',
    });
    expect(result).toBe(25.0);
  });

  it('空订单返回零', () => {
    const result = calculateShipping({
      items: [],
      destination: 'domestic',
    });
    expect(result).toBe(0);
  });
});
表征测试不关心结果是否"正确"——如果遗留代码中有 Bug 但用户已经适应了这个行为，表征测试应该保护这个行为，直到有意识地决定修复它。




接缝识别（Seam Identification）
接缝（Seam）是代码中可以改变行为而无需修改代码本身的位置。识别接缝是让遗留代码变得可测试的关键。


接缝类型
在 TypeScript/JavaScript 中，最常用的接缝是参数接缝和模块接缝：

防腐层（Anti-Corruption Layer）
interface ModernUser {
  id: string;
  displayName: string;
  email: string;
  createdAt: Date;
}

interface LegacyUserRecord {
  user_id: number;
  first_name: string;
  last_name: string;
  email_address: string;
  created_date: string;
}

class UserAntiCorruptionLayer {
  constructor(private readonly legacyDb: LegacyDatabase) {}

  async findById(id: string): Promise<ModernUser | null> {
    const legacy = await this.legacyDb.query<LegacyUserRecord>('SELECT * FROM users WHERE user_id = $1', [
      parseInt(id, 10),
    ]);
    if (!legacy) return null;
    return this.translate(legacy);
  }

  private translate(legacy: LegacyUserRecord): ModernUser {
    return {
      id: String(legacy.user_id),
      displayName: `${legacy.first_name} ${legacy.last_name}`.trim(),
      email: legacy.email_address,
      createdAt: new Date(legacy.created_date),
    };
  }
}
防腐层确保新代码不受旧数据模型的"污染"，所有翻译逻辑集中在一处。

遗留代码现代化不是一个项目，而是一个持续的过程。它需要耐心、纪律和对细节的关注。最成功的现代化案例都有一个共同特点：它们从来不试图一步到位，而是通过无数个小步骤积累成变革性的结果。每一行被测试覆盖的遗留代码，都是向更健康的系统迈进的一步。
