可逆与不可逆决策

Bezos 的两类决策模型

Jeff Bezos 在 2015 年致股东信中提出了一个深刻的决策分类：

  • Type 1（不可逆决策）：单行道——一旦做出，很难或无法回退。这类决策需要深思熟虑、广泛讨论、审慎行动。
  • Type 2（可逆决策）：双行道——做了之后如果发现不对，可以回退到原来的状态。这类决策应该由小团队快速做出。
大多数组织的问题不是把 Type 1 决策做得太快，而是把 Type 2 决策当作 Type 1 来处理——一个可以轻松回退的技术选型，却走了三个月的审批流程。

将 Type 1 转化为 Type 2
interface FeatureFlagConfig {
  name: string;
  description: string;
  rollout: {
    strategy: 'percentage' | 'user-list' | 'region';
    percentage?: number;
    users?: string[];
    regions?: string[];
  };
  killSwitch: boolean;
  metrics: string[];
}

const newPaymentGateway: FeatureFlagConfig = {
  name: 'new-payment-gateway',
  description: '从 Stripe 迁移到自建支付网关',
  rollout: {
    strategy: 'percentage',
    percentage: 5,
  },
  killSwitch: true,
  metrics: ['payment_success_rate', 'payment_latency_p99'],
};
通过 Feature Flag，一个"选择支付网关"的 Type 1 决策被转化为一系列 Type 2 决策——先给 5% 用户试用，观察指标，逐步放量或立即回退。

决策速度的平衡




原则
说明





Type 1 用 70% 信息决策
等待 100% 信息太慢，70% 足够做出合理判断




Type 2 用 40% 信息决策
快速行动比完美分析更重要




错误的 Type 分类比错误的决策更危险
把 Type 2 当 Type 1 处理浪费时间，反之则承担不必要的风险





区分可逆与不可逆决策，是提升工程决策速度和质量的最大杠杆。当团队学会快速识别决策类型并匹配相应流程时，Type 2 决策不再被过度分析所拖累，Type 1 决策也不会因为仓促而酿成大错。真正的决策智慧不在于做出完美的选择，而在于知道什么时候可以快速尝试、什么时候必须三思而后行。
