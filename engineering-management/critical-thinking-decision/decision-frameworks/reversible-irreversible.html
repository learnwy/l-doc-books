可逆与不可逆决策

Jeff Bezos 的决策分类框架

Jeff Bezos 在 Amazon 的年度股东信中提出了一个影响深远的决策分类方法：将决策分为 Type 1（不可逆决策）和 Type 2（可逆决策）。这个分类的核心洞察是——大多数组织犯的最大错误不是做了错误的决策，而是用对待 Type 1 的方式对待所有 Type 2 决策，从而导致决策速度严重下降。

Type 1（不可逆）
Type 2（可逆）





定义

单向门——走过去就回不来
双向门——走过去还能走回来

决策速度 vs 质量权衡
速度的价值
在快速变化的技术环境中，决策速度本身就是一个竞争优势。一个 80% 正确但今天做出的决策，往往比一个 95% 正确但三个月后才做出的决策更有价值。


Bezos 的 70% 规则
Jeff Bezos 建议：当你有大约 70% 的信息时就做决策。如果等到有 90% 的信息，在大多数情况下你已经太慢了。

小结
决策分类是提升决策效率的第一步。大多数技术决策是 Type 2（可逆）决策，应该快速做出；少数 Type 1（不可逆）决策需要慎重分析。最大的决策效率提升来自两个方面：加快 Type 2 决策的速度，以及用技术手段将 Type 1 决策转化为 Type 2 决策。


记住 Bezos 的警告：对 Type 2 决策使用 Type 1 的决策流程，是组织变慢的最常见原因。如果你的团队每次选一个 npm 包都要开会讨论两小时，那么真正需要改变的不是包的选择，而是决策流程本身。
