权力导航

核心概念

权力导航（Navigating Power）是在组织政治环境中保持原则又获得支持的能力。许多技术专家把"政治"视为肮脏的事——拒绝参与，结果在权力斗争中被边缘化。但组织本质上是政治环境——任何由人组成的群体都有权力关系、利益冲突、联盟博弈。优秀的高管不是"远离政治"，而是"在政治中保持 integrity"——理解权力如何运作、建立合理联盟、不参与肮脏游戏、用 integrity 在政治中胜出。本节给出权力导航的工程化框架——权力来源、组织政治的形态、健康 vs 不健康的政治、保持原则的具体实践。

权力来源 类型 持久度 例子
Position 正式职位 短（任职期间） CEO、VP
Expertise 专业能力 中（可演化） 资深技术专家
Relationship 人际网络 长 信任关系网络
Information 关键信息掌握 短-中 知道某秘密
Reward 给奖励能力 短 决定 bonus、晋升
Coercive 惩罚能力 短 解雇、降级
Reference 被尊敬 长 行业声望
Charisma 个人吸引力 中 让人 follow

理解组织政治

组织政治不是邪恶或可避免的——是任何组织的固有特征。

组织政治的根源：

  • 资源稀缺：预算、人头、机会有限，必然有竞争。
  • 目标不一：不同部门有不同 KPI，可能冲突。
  • 信息不对称：有些人掌握更多信息，权力不对等。
  • 不确定性：决策依赖判断，不同人判断不同。
  • 利益不同：高管个人利益（晋升、bonus、reputation）有时与组织利益不完全对齐。

组织政治的形态：

  • 同盟形成：志同道合的人形成 informal 联盟。
  • 影响力行使：用各种方式影响决策。
  • 资源博弈：争取预算、headcount、project 分配。
  • 认可争夺：让自己 / 自己团队的成就被看见。
  • 保护自己：避免被指责、保护 reputation。

理解政治是中性的——可以用于善（推动好决策）或恶（个人利益最大化）。

7 种权力来源

French & Raven 经典模型把权力分为 7 种：

1. Position Power（职位权力）：来自正式职位。CEO、VP 的权力部分来自此。

  • 优势：清晰、合法、可传承。
  • 劣势：随职位变化而变化、不能积累。

2. Expertise Power（专业权力）：来自专业能力。技术专家的权力来自此。

  • 优势：被尊重、可演化。
  • 劣势：限于专业范围。

3. Relationship Power（关系权力）：来自人际网络。

  • 优势：长期累积、跨场合。
  • 劣势：建设需要时间。

4. Information Power（信息权力）：来自掌握关键信息。

  • 优势：在不对称中获益。
  • 劣势：信息扩散后失效。

5. Reward Power（奖励权力）：来自给奖励的能力。

  • 优势：immediate 影响。
  • 劣势：需要预算 / 资源、短期。

6. Coercive Power（惩罚权力）：来自施加惩罚的能力。

  • 优势：immediate 影响。
  • 劣势：建立恐惧而非忠诚、长期破坏关系。

7. Reference Power（参照权力）：来自被尊敬。

  • 优势：自然产生 follower、可持续。
  • 劣势：建设非常缓慢。
健康 vs 不健康政治
健康政治：


    

  • 推动组织目标。
    • 

  • 透明的影响行为。
    • 

  • 多 stakeholder 共赢。
    • 

  • Integrity 不被 compromise。
    • 

  • 长期 build。
    • 



不健康政治：


    

  • 个人利益至上。
    • 

  • 暗中操作。
    • 

  • 零和博弈。
    • 

  • 牺牲 integrity。
    • 

  • 短期投机。
    • 



健康政治：用合理影响推动好决策
不健康政治：用 manipulation 推动个人利益
许多技术专家拒绝任何政治，结果是放弃了健康政治——让位于不健康的政治玩家。


健康政治的实践
1. 建立联盟：


    

  • 与志同道合的同事建立联盟。
    • 

  • 互相支持议题。
    • 

  • 不是阴谋——是协作。
    • 



2. 影响力：


    

  • 用 logic、data、emotion 影响决策。
    • 

  • 公开的影响行为。
    • 



3. 互惠：


    

  • 帮别人，长期建立 IOU。
    • 

  • "I scratch your back, you scratch mine"——只要透明且不违 integrity。
    • 



4. Visibility：


    

  • 让自己的工作被看见。
    • 

  • 不是吹嘘，是透明 sharing。
    • 



5. Stakeholder 管理：


    

  • 主动管理与各利益相关方的关系。
    • 

  • 不只与上级，还有同级、下属、跨部门。
    • 



6. 适当的让步：


    

  • 在不影响核心的部分让步。
    • 

  • 让别人 win 一些，长期获得支持。
    •

读懂权力地图
每个组织有自己的权力地图。读懂它需要观察：


1. 谁的话被听：


    

  • 同样话不同人说效果不同。
    • 

  • 关注谁说什么被采纳。
    • 



2. 决策真正在哪里发生：


    

  • 名义会议 vs 私下决策。
    • 

  • 重要决策可能在 lunch 中达成，会议只是 confirm。
    • 



3. 信任网络：


    

  • 谁与谁经常 1:1？
    • 

  • 谁是 CEO 的 inner circle？
    • 



4. 历史：


    

  • 过去的权力斗争结果。
    • 

  • 谁支持过谁、谁反对过谁。
    • 



5. 隐含规则：


    

  • 组织的"潜规则"——不写下来但大家遵守。
    • 

  • 例：在某公司"不要在 all-hands 直接挑战 CEO"。
    • 



政治智商（Political Intelligence）
政治智商是读懂权力的能力。培养：


1. 观察：


    

  • 不只听内容，看互动模式。
    • 

  • 谁与谁站在一起？谁在某话题上沉默？
    • 



2. 询问：


    

  • 与资深同事请教"组织政治"。
    • 

  • "X 与 Y 是什么关系？"
    • 



3. 反思：


    

  • 反思自己的政治盲点。
    • 

  • 我是否 underestimate 某人？是否 overestimate？
    • 



4. 阅读：


    

  • 阅读组织政治的经典书——《Power》by Jeffrey Pfeffer、《The 48 Laws of Power》（批判性阅读）。
    • 



5. 教练：


    

  • 与外部 executive coach 讨论组织政治。
    • 

  • 中立视角让你看到盲点。
    • 



权力建设
不只是 "use power"，更要 "build power"：


1. Expertise：


    

  • 持续学习，成为领域专家。
    • 

  • 长期可持续。
    • 



2. Relationship：


    

  • 跨部门、跨级别、跨公司的 network。
    • 

  • 投资关系本身（不只在需要时联系）。
    • 



3. Reference：


    

  • 长期 build reputation。
    • 

  • 让别人为你说好话。
    • 



4. 跨界 visibility：


    

  • 在公司外建立 visibility（演讲、文章）。
    • 

  • 增加 leverage——离职选择多。
    • 



5. Integrity 资本：


    

  • 长期一致的行为。
    • 

  • 在关键时刻被信任。
    • 



避免依赖短期权力（position、reward、coercive）——它们随职位变化消失。


权力的常见反模式
反模式 1：拒绝政治：以为可以"远离政治"。规避：参与健康政治。


反模式 2：只用 Position Power：只靠职位行使权力。规避：建设 reference + expertise + relationship。


反模式 3：政治至上：所有事用政治算计。规避：80% 业务、20% 政治。


反模式 4：联盟过度：所有事都通过联盟。规避：明确联盟边界。


反模式 5：信任过度：相信所有人。规避：基于行为信任。


反模式 6：报复：被反对就报复。规避：长期 reputation 重要。


反模式 7：short-term：为短期赢牺牲 integrity。规避：长期视角。


权力的负面影响
权力本身有腐蚀性——许多研究显示长期掌权改变人格：


1. 共情下降：权力者对他人的感受不敏感。


2. 风险偏好上升：权力者高估自己判断、低估风险。


3. 沟通改变：权力者打断别人、占用更多发言时间。


4. 道德灵活：权力者更容易合理化不当行为。


对抗工具：


    

  • 接收反馈：定期 360 反馈。
    • 

  • 保持谦逊：刻意 reminders（如 CEO 仍坐 economy class）。
    • 

  • mentor：有 mentor 让你 ground。
    • 

  • 不孤立：不只与 yes-men 交流。
    • 



小结
权力导航是在组织政治环境中保持原则又获得支持的能力。组织政治不可避免——资源稀缺、目标不一、信息不对称等都让政治成为组织本质。7 种权力来源（Position、Expertise、Relationship、Information、Reward、Coercive、Reference）有不同特点与持久度——长期建设应靠 expertise + relationship + reference 而非 position + reward + coercive。健康政治（公开影响、双赢联盟、integrity）vs 不健康政治（manipulation、利用、利益至上）有清晰边界。读懂权力地图需要观察互动、识别真决策位置、理解历史与隐含规则。培养政治智商通过观察、询问、反思、阅读、教练。建设可持续权力——expertise、relationship、reference、跨界 visibility、integrity 资本。常见反模式包括拒绝政治（结果让位给不健康玩家）、只用 Position Power、政治至上、联盟过度、报复、short-term。权力本身有腐蚀性——长期需要反馈、谦逊、mentor、不孤立来对抗。一个简单的检验：你能否清楚说出组织内权力的 top 5 持有者，以及他们权力的来源？如果不能，权力地图还需要更深观察。权力导航是高管不可避免的能力——不是道德问题（参与健康政治不违背 integrity），是工程能力（让对的事被组织接受）。
