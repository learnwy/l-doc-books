习惯分析

用数据工程思维分析习惯

程序员擅长分析系统性能、追踪用户行为、优化数据库查询——但很少有人用同样的分析思维来审视自己的习惯数据。习惯分析就是将数据工程的方法论应用于个人行为数据，从中发现模式、相关性和优化机会。

把自己想象成一个复杂的分布式系统。你的每个习惯就是一个微服务，它们之间存在依赖关系、资源竞争和级联效应。习惯分析就是你的 Observability Stack——帮助你理解这个系统的运行状态。

描述性分析：看见你的行为模式
完成率分析
最基础的分析是各习惯的完成率趋势：


function analyzeCompletionRate(data, habit, period = 7) {
  const recentData = data.slice(-period);
  const completed = recentData.filter((d) => d.habits[habit]?.done).length;
  const rate = ((completed / period) * 100).toFixed(1);

  const previousData = data.slice(-period * 2, -period);
  const prevCompleted = previousData.filter((d) => d.habits[habit]?.done).length;
  const prevRate = ((prevCompleted / period) * 100).toFixed(1);

  const trend = rate - prevRate;
  const arrow = trend > 0 ? '📈' : trend < 0 ? '📉' : '➡️';

  return { rate, prevRate, trend, arrow };
}

简易相关性计算
function correlation(xArr, yArr) {
  const n = xArr.length;
  const sumX = xArr.reduce((a, b) => a + b, 0);
  const sumY = yArr.reduce((a, b) => a + b, 0);
  const sumXY = xArr.reduce((total, x, i) => total + x * yArr[i], 0);
  const sumX2 = xArr.reduce((total, x) => total + x * x, 0);
  const sumY2 = yArr.reduce((total, y) => total + y * y, 0);

  const numerator = n * sumXY - sumX * sumY;
  const denominator = Math.sqrt((n * sumX2 - sumX ** 2) * (n * sumY2 - sumY ** 2));

  return denominator === 0 ? 0 : numerator / denominator;
}

## 实验 #007: 晨跑对编码效率的影响

### 假设

晨跑 30 分钟会提升当天的深度编码时间

### 实验设计

- A 周（对照）：不晨跑，正常作息
- B 周（实验）：每天 7:00 晨跑 30 分钟
- 测量指标：深度编码小时数、代码提交质量、下午疲劳度

### 数据收集

| 日期   | 是否晨跑 | 深度编码(h) | 提交数 | 疲劳度(1-10) |
| ------ | -------- | ----------- | ------ | ------------ |
| Mon(A) | ❌       | 2.5         | 3      | 6            |
| Mon(B) | ✅       | 3.5         | 5      | 4            |
| Tue(A) | ❌       | 2.0         | 2      | 7            |
| Tue(B) | ✅       | 3.0         | 4      | 5            |

### 结论

晨跑组平均深度编码时间增加 0.8h/天，疲劳度降低 1.5 分。假设成立，将晨跑纳入核心习惯。

总结与行动清单
习惯分析不是为了让你成为一个数据收集机器，而是为了帮助你用最少的努力获得最大的成长回报。就像性能优化一样——先 profile，再优化，别过早优化。


立即行动：


    

  1. 今天：确定你的 MVDS（最小可行数据集），开始记录 3 个核心指标
    2. 

  2. 2 周后：做第一次描述性分析，找出完成率的时间模式
    3. 

  3. 1 个月后：做第一次相关性分析，发现习惯之间的隐藏联系
    4. 

  4. 2 个月后：设计并执行你的第一个 A/B 实验
    5. 

  5. 每季度：做一次全面的习惯分析回顾，调整整体策略
    6. 





最好的习惯系统不是最完美的系统，而是你能持续分析和改进的系统。数据给你洞察，但最终还是你的判断和行动在驱动改变。
