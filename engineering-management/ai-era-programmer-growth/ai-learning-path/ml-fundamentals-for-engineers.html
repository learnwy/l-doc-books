工程师的 ML 基础

为什么需要了解 ML

作为软件工程师，你不需要成为机器学习研究员。但你需要足够的 ML 知识来：

  • 判断一个问题是否适合用 ML 解决
  • 与数据科学团队有效沟通
  • 理解 AI API 返回结果的含义
  • 设计合理的 AI 功能方案
  • 识别 AI 系统的风险和局限
本章聚焦于金字塔底部——作为软件工程师需要掌握的 ML 核心概念。


监督学习 vs 无监督学习
监督学习
给模型提供"正确答案"（标签），让它学习输入到输出的映射关系。






任务类型
说明
示例





分类
预测离散类别
垃圾邮件检测、图片分类




回归
预测连续数值
房价预测、销量预测





工程师视角： 如果你有大量"输入→输出"的历史数据，监督学习可能适用。


无监督学习
不提供标签，让模型自己发现数据中的模式和结构。






任务类型
说明
示例





聚类
将数据分组
用户分群、文档归类




降维
压缩数据维度
数据可视化、特征压缩




异常检测
发现异常数据
欺诈检测、系统异常





工程师视角： 当你有大量数据但没有标签，或者想发现数据中的隐藏模式时，考虑无监督学习。


强化学习
模型通过与环境交互，根据奖励信号学习最优策略。


工程师视角： 大多数应用开发场景不需要直接使用强化学习，但了解概念有助于理解 AI 代理和推荐系统。


神经网络基础
核心类比
传统编程：y = f(x)  ← 你手动编写函数 f
神经网络：y = f(x)  ← 网络自动学习函数 f 的参数
基本结构
关键概念（工程师语言）：


    

  • 权重（Weight）：连接的强度，类比程序中的参数
    • 

  • 偏置（Bias）：调整阈值，类比程序中的默认值
    • 

  • 激活函数：非线性变换，让网络能学习复杂模式
    • 

  • 损失函数：衡量预测与实际的差距，类比测试中的断言
    • 

  • 反向传播：计算梯度更新权重，类比梯度下降优化
    • 



训练过程类比
传统开发的迭代：
需求 → 编码 → 测试 → 发现 Bug → 修改代码 → 重新测试

神经网络的训练：
数据 → 前向传播 → 计算损失 → 反向传播 → 更新权重 → 重新预测
Transformer 架构
为什么重要
Transformer 是当今 LLM（GPT、Claude、Gemini 等）的基础架构。理解它的核心思想，你就能理解 LLM 的能力和局限。


注意力机制
核心思想： 处理序列数据时，模型能"关注"输入中最相关的部分，而不是按顺序逐个处理。


工程师理解： 类似于数据库查询中的 JOIN — 不是遍历每条记录，而是根据相关性匹配最重要的信息。

嵌入（Embedding）
核心概念
Embedding 是将离散数据（文字、图片、用户行为）转换为连续的数值向量。


文本 → Embedding 模型 → 数值向量

"机器学习" → [0.12, -0.34, 0.78, 0.56, ...]
"深度学习" → [0.15, -0.31, 0.82, 0.49, ...]
"做饭技巧" → [-0.67, 0.23, -0.11, 0.88, ...]
语义相似的内容在向量空间中距离更近。

代码示例
import OpenAI from 'openai';

const openai = new OpenAI();

async function getEmbedding(text: string): Promise<number[]> {
  const response = await openai.embeddings.create({
    model: 'text-embedding-3-small',
    input: text,
  });
  return response.data[0].embedding;
}

function cosineSimilarity(a: number[], b: number[]): number {
  const dotProduct = a.reduce((sum, val, i) => sum + val * b[i], 0);
  const magnitudeA = Math.sqrt(a.reduce((sum, val) => sum + val * val, 0));
  const magnitudeB = Math.sqrt(b.reduce((sum, val) => sum + val * val, 0));
  return dotProduct / (magnitudeA * magnitudeB);
}

学习建议
第一周： 理解监督学习、无监督学习的区别，了解神经网络的基本结构


第二周： 理解 Transformer 和注意力机制的核心思想，动手调用 Embedding API


第三周： 实践 LLM API 调用，理解 Token、温度、上下文窗口等核心参数


第四周： 尝试构建一个端到端的 AI 功能（如语义搜索），巩固理论与实践的连接


记住：你的目标不是成为 ML 专家，而是成为能有效利用 ML 的工程师。就像你不需要理解数据库引擎的 B+ 树实现细节也能设计好的数据库表一样。
