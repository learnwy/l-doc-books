高盛科技工程师成长路线：从代码到金融基础设施的四大方向

知识要点

高盛拥有约 12,000 名工程师，占全公司员工总数的近三分之一，是名副其实的「华尔街最大的科技公司」。工程部门不是业务的附属品，而是高盛竞争力的核心引擎——从低延迟交易系统到 GS Financial Cloud，从风控模型到 AI 辅助投研，工程团队直接影响着数千亿美元级别的业务运作。

工程师在高盛有四大核心发展方向：Securities Division Tech（证券交易技术）、Platform Engineering（平台工程）、GS Financial Cloud（金融云对外输出）、AI/ML（人工智能与机器学习）。每个方向都有独立的技术栈、业务场景和晋升路径，但共享相同的六级职级体系（Analyst → Associate → VP → ED → MD → Partner）。

高盛工程组织的战略地位

从成本中心到利润中心的转型

传统投行中，技术团队是「花钱部门」。高盛的战略转型从根本上改变了这一定位：

阶段 时间 工程定位 关键举措
内部工具期 2000-2012 业务支撑 SecDB 统一定价平台建设
平台化期 2013-2019 效率杠杆 Marquee 平台对外开放、API 化
云化输出期 2020-至今 收入引擎 GS Financial Cloud 与 AWS 合作、Transaction Banking
AI 驱动期 2024-至今 战略核心 OneGS 3.0 以 AI 为核心推进全面数字化

高盛 CEO David Solomon 在 2025 年年报中明确表示：「我们正在将工程投资从成本转化为收入来源。」2025 年融资类业务净收入创下 114 亿美元纪录，其中技术平台的贡献不可忽视。

工程团队的组织架构

高盛工程部门（Engineering Division）由以下核心团队组成：

工程师分为两类角色模式：


    

  • 嵌入式团队（Embedded Engineering）：直接嵌入交易、投行、资管等业务部门，与 Trader、Banker 并肩工作，深度理解业务需求
    • 

  • 核心平台团队（Core Engineering）：构建公司级基础设施，包括 SDLC 工具链、CI/CD 管道、数据平台、安全框架
    • 



四大核心发展方向
方向一：Securities Division Tech（证券交易技术）
这是高盛工程最具「华尔街特色」的方向，工程师直接服务于交易台（Trading Desk），构建驱动全球交易的技术系统。


核心系统：SecDB


SecDB（Securities Database）是高盛最核心的技术资产之一，诞生于 1990 年代，是一个统一的风险分析和定价平台。它使用自研语言 Slang（Securities Language），能够对几乎所有金融产品进行实时定价和风险计算。

低延迟交易系统


电子交易（Electronic Trading）团队构建微秒级延迟的订单路由和执行系统。核心技术挑战包括：


    

  • 网络优化：使用 FPGA 硬件加速、内核旁路（kernel bypass）技术
    • 

  • 内存管理：自研内存分配器，避免 GC 停顿
    • 

  • 协议优化：FIX 协议的超高速解析和生成
    • 

  • 监控告警：实时延迟监控、异常交易检测
    • 



做市系统


高盛是全球最大的做市商之一，其股票业务连续多年蝉联全球第一。做市系统需要：


    

  • 实时计算数千只股票的双边报价
    • 

  • 动态调整库存风险暴露
    • 

  • 整合另类数据源优化定价策略
    • 

  • 满足监管要求的交易后报告
    •

方向二：Platform Engineering（平台工程）
平台工程团队构建高盛全公司共享的技术基础设施，是「工程师的工程师」。


核心平台：Marquee


Marquee 是高盛面向机构客户的数字服务平台，提供分析工具、交易执行和风险管理能力。它本质上是将高盛内部的技术能力产品化，对外输出。


Marquee 平台的核心模块包括：


    

  • GS Quant：开源的 Python 量化分析库，提供衍生品定价、风险分析、回测框架
    • 

  • Marquee Data：金融数据 API 服务，覆盖市场数据、宏观经济、ESG 指标
    • 

  • Marquee Portfolio Analytics：投资组合分析工具
    • 

  • Marquee Risk Manager：实时风险监控仪表板
    • 



Developer Journey Strategy


高盛内部推行「开发者旅程战略」（Developer Journey Strategy），核心目标是：


    

  • 最小化开发摩擦：统一构建工具、标准化 CI/CD 流水线
    • 

  • 促进标准化：代码规范、安全合规检查自动化
    • 

  • 集成 AI 能力：AI 驱动的代码审查、自动化测试生成、智能推荐
    • 



平台工程师的日常工作包括维护 GitLab 实例、构建内部 PaaS 平台、优化容器编排（Kubernetes）、开发内部语言支持工具等。

方向三：GS Financial Cloud（金融云）
GS Financial Cloud 是高盛最具前瞻性的战略方向之一，目标是将高盛的金融服务能力以云服务形式对外输出。


与 AWS 的战略合作


2021 年，高盛与 AWS 联合推出 GS Financial Cloud for Data，提供云端金融数据管理和分析解决方案。David Solomon 表示：「我们正在为金融服务重新定义云的未来，使开发者能够专注于为客户构建金融解决方案。」

商业模式创新


金融云的本质是将高盛 150 年积累的金融能力——交易基础设施、风险模型、合规框架——以 API 和云服务的形式货币化。这意味着：


    

  • 工程投资从纯成本变为可计量的收入来源
    • 

  • 高盛与科技公司形成互补而非竞争关系
    • 

  • 为非金融企业提供嵌入式金融（Embedded Finance）能力
    • 



工程师在金融云方向的挑战


    

  • 多租户架构设计：确保不同客户间的数据隔离和安全
    • 

  • API 设计哲学：为外部开发者提供直观、稳定的接口
    • 

  • 合规即代码：将金融监管要求编码为自动化检查规则
    • 

  • 全球化部署：满足不同地区的数据本地化要求
    • 



方向四：AI/ML（人工智能与机器学习）
AI 是高盛 OneGS 3.0 战略的核心驱动力。2025 年年报显示，高盛正将 AI 技术全面嵌入六大关键流程：客户开户、监管报告、风险管理、销售赋能、贷款管理、供应商协作。


AI 应用场景矩阵


GS AI Assistant


高盛内部部署了基于大语言模型的 AI 助手，覆盖以下场景：


    

  • 代码生成与审查：辅助工程师编写和审查代码，提升开发效率
    • 

  • 文档自动化：自动生成投研报告摘要、合规文档
    • 

  • 知识问答：快速检索内部政策、流程和历史案例
    • 

  • 数据分析：自然语言查询内部数据库
    • 



量化策略师（Quantitative Strategist）


Quant Strat 是高盛 AI/ML 方向中最核心的角色，直接与交易员、投资组合经理、银行家协作。他们的工作包括：


    

  • Alpha 策略研发：利用机器学习发现新的交易信号
    • 

  • 衍生品定价：构建复杂金融产品的定价模型
    • 

  • 投资组合优化：资产配置和风险预算
    • 

  • 交易自动化：端到端的交易策略实现
    •

工程师的「非技术」晋升要素
在高盛，纯技术能力只是入场券。VP 及以上级别的晋升需要：


    

  • Networking：构建跨部门关系网络，确保你的工作被关键决策者看到
    • 

  • Sponsorship：找到一位高级别（MD 或 Partner）的 Sponsor，而不仅仅是 Mentor
    • 

  • Visible Impact：将技术贡献转化为可量化的业务影响（如节省多少成本、提升多少效率）
    • 

  • 360 Feedback：确保多个利益相关方对你有正面评价
    • 

  • Culture Fit：展现高盛的核心文化价值观——团队协作、客户至上、卓越标准
    •

    4. 



VP 之后的分水岭
VP 是高盛工程师职业路径的关键分水岭。此后有三条典型路径：


    

  • 深耕技术：成为 Distinguished Engineer 级别的技术专家（少数人）
    • 

  • 转向管理：走技术管理路线，目标 ED → MD
    • 

  • 外部跳槽：利用高盛品牌和金融科技经验，跳到对冲基金、Fintech 创业公司或科技巨头
    • 



每条路径都有明确的能力要求和机会成本，关键是在 VP 阶段就开始有意识地积累对应方向的资本。
