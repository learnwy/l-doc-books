Visa 绩效考核体系

绩效管理哲学

Visa 的绩效管理体系围绕一个核心信念：绩效管理的目的是发展人才，而非惩罚低绩效者。这一哲学通过三个年度循环环节体现——目标设定（Goal Setting）、年中评审（Mid-Year Review）和年终评审（Year-End Review），再辅以跨团队的校准会议（Calibration）确保公平性。

第一阶段：Goal Setting（目标设定）
时间窗口
通常在每年 1 月底至 2 月完成。


目标设定框架
Visa 使用 SMART + OKR 混合模式：


    

  • Specific：目标必须具体可操作
    • 

  • Measurable：有明确的量化衡量标准
    • 

  • Achievable：具有挑战性但可实现
    • 

  • Relevant：与团队/部门/公司战略对齐
    • 

  • Time-bound：有明确截止日期
    • 



目标类型
每位员工通常设定 4-6 个目标，涵盖：






类型
权重建议
说明





Business Impact
50-60%
直接业务贡献（项目交付、指标提升）




Leadership & Influence
20-30%
团队影响力、跨组织协作




Development
10-20%
个人能力提升、技能学习





与公司战略的连接
Visa 实行战略级联（Strategy Cascade）：


    

  • CEO 设定公司级优先事项
    • 

  • EVP/SVP 将其分解为 BU 目标
    • 

  • VP/Director 进一步分解为团队目标
    • 

  • 个人目标需明确链接到上级组织目标
    • 



第二阶段：Mid-Year Review（年中评审）
时间窗口
通常在 6-7 月进行。


目的
年中评审不产生绩效评级，其核心目的是：


    

  1. 检查目标进展，调整不再相关的目标
    2. 

  2. 提供发展性反馈
    3. 

  3. 识别阻碍因素并提供支持
    4. 

  4. 确认下半年优先事项
    5. 



流程
    

  1. 自我评估：员工撰写半年进展总结
    2. 

  2. 经理反馈：经理提供书面 + 口头反馈
    3. 

  3. 一对一讨论：30-60 分钟面谈
    4. 

  4. 目标调整：如有需要，更新目标（需记录原因）
    5. 



最佳实践
    

  • 不要等到年中才给反馈——持续反馈是文化期望
    • 

  • Mid-Year 不应有"surprise"——如果有，说明日常沟通不足
    • 

  • 记录好你的贡献和影响力数据，不要依赖年底回忆
    • 



第三阶段：Year-End Review（年终评审）
时间窗口
通常在 11-12 月进行自评和经理评审，次年 1 月完成 Calibration。


绩效评级体系
Visa 采用多级评级制度：

含义

未达标

评估维度
年终评估围绕两个核心维度：


What（做了什么）：


    

  • 目标完成度
    • 

  • 业务影响的量化证据
    • 

  • 超出目标的额外贡献
    • 



How（怎么做的）：


    

  • 是否体现 Visa Leadership Principles
    • 

  • 协作方式和团队影响
    • 

  • 是否以正确的方式达成结果
    • 



自评要点
撰写有效的年终自评：


    

  1. 用数据说话——量化你的影响（$、%、人数、效率提升）
    2. 

  2. 链接到战略——说明你的工作如何支持公司优先事项
    3. 

  3. 讲故事——描述挑战、你的行动和结果（STAR 格式）
    4. 

  4. 展示成长——相比去年你有什么新能力
    5. 

  5. 不要谦虚——这是展示你价值的时刻
    6. 



第四阶段：Calibration（校准）
什么是 Calibration
Calibration 是确保跨团队绩效评估公平性的关键机制。多个经理坐在一起，讨论和对齐他们团队成员的评级。


流程
    

  1. 各经理带着初步评级和证据参加 Calibration 会议
    2. 

  2. 按评级分组讨论，确保同一评级的人确实在同一水平
    3. 

  3. 调整偏差——如果某个经理的标准过松/过紧，会被要求调整
    4. 

  4. 特别关注边界case——"Exceeds" 和 "Meets" 边界、晋升候选人
    5. 

  5. 最终评级在 Calibration 后确定
    6. 



Calibration 的意义
    

  • 防止标准漂移：不同经理对"Exceeds"的理解可能不同
    • 

  • 确保公平：避免"会哭的孩子有奶吃"
    • 

  • 晋升质量控制：晋升提名在 Calibration 中讨论和决定
    • 

  • 组织健康检查：发现团队间的人才分布问题
    • 



员工如何应对 Calibration
    

  1. 确保你的经理了解你的所有贡献——他们需要在会上为你"辩护"
    2. 

  2. 跨团队影响力很重要——其他经理如果认识你的工作，会成为你的"证人"
    3. 

  3. 文档化一切——经理在 Calibration 中需要具体证据
    4.

绩效改进计划（PIP）
如果员工获得 "Does Not Meet" 或连续 "Partially Meets"：


    

  • 进入 Performance Improvement Plan（PIP）
    • 

  • 通常为 60-90 天
    • 

  • 设定具体改进目标和检查点
    • 

  • 通过 PIP → 恢复正常；未通过 → 可能面临离职
    • 



Visa 的 PIP 文化：相比某些科技公司将 PIP 作为"体面解雇"的工具，Visa 的 PIP 相对更真诚——公司确实投入资源帮助员工改进。但现实是，PIP 的通过率并不高。


持续反馈文化
除了正式的年度绩效周期，Visa 强调：


1:1 会议
    

  • 经理与直接下属每周或双周一次
    • 

  • 不仅讨论项目进展，也讨论职业发展
    • 

  • 是绩效反馈的主要日常载体
    • 



360 度反馈
    

  • 晋升时通常会收集 Peer Feedback
    • 

  • 部分团队在年终评审中收集跨功能反馈
    • 

  • 反馈被视为发展工具而非评判工具
    • 



Skip-level 会议
    

  • 经理的经理定期与你 1:1
    • 

  • 确保信息不被单一层级过滤
    • 

  • 也是展示影响力和获得高层 visibility 的机会
    • 



对求职者和在职者的建议
    

  1. 入职第一年：重点是学习和建立关系，不要急于"exceed"
    2. 

  2. 向上管理：确保经理了解你的贡献，不要假设"做好了自然会被看到"
    3. 

  3. 文档习惯：每周记录关键贡献，年终自评时会感谢自己
    4. 

  4. 跨团队协作：Calibration 中，被多个团队认可的人更容易获得高评级
    5. 

  5. 长期视角：Visa 奖励持续稳定的高绩效，不鼓励"一年冲刺然后burnout"
    6.
