金融科技合作而非对抗

知识要点

2010 年代中期，全球金融科技浪潮席卷而来。PayPal 的崛起、Square 的移动支付革命、Stripe 的在线支付简化、各国移动钱包的爆发，一度让市场担忧 Visa 的卡网络会被"绕过"（disintermediate）。面对这一挑战，Visa 做出了一个关键战略选择：合作而非对抗。

这一选择背后的逻辑是：金融科技公司的创新大多发生在"最后一英里"（用户体验和交互层），而非"核心管道"（清算和结算基础设施）。Visa 的核心能力——全球化的授权、清算、结算网络——恰恰是金融科技公司需要但无法自建的基础设施。因此，大多数金融科技公司本质上是 Visa 网络的"界面创新者"，而非"管道替代者"。

Visa 的金融科技策略框架：

  • 合作吸纳：将金融科技公司作为新的网络分发渠道
  • 投资布局：通过 Visa Ventures 获取前沿洞察和战略期权
  • 收购整合：将关键能力内化
  • 规则适配：调整网络规则以适应新型业务模式
  • 竞争防御：识别真正可能绕过网络的威胁并针对性应对

详细讲解

金融科技对 Visa 的"威胁"分类

并非所有金融科技创新都对 Visa 构成同等威胁。Visa 将金融科技浪潮分为三类：

第一类：网络增强者（Network Amplifiers）——70% 的金融科技

这些公司实际上是在 Visa 网络之上构建新体验，为网络带来增量交易：

  • 数字银行（Chime、Revolut、N26）：发行 Visa 卡作为核心产品
  • BNPL（先买后付）（Klarna、Afterpay）：底层交易仍通过 Visa 网络处理
  • 电商支付网关（Stripe、Adyen）：为商户接入 Visa 网络
  • 零工平台（Uber、Lyft、DoorDash）：通过 Visa Direct 向工作者支付

对策：拥抱和加速合作。Fast Track 简化接入，确保这些公司选择 Visa 而非 Mastercard。

第二类：部分绕过者（Partial Bypassers）——25% 的金融科技

这些公司可能在某些场景中绕过 Visa 网络：

  • PayPal/Venmo：P2P 转账不经过 Visa（但 PayPal 余额花费到商户时仍需 Visa 网络）
  • Apple Pay：增加了一层中间体验，但底层仍是 Visa 卡交易
  • 各国实时支付系统（UPI、Pix）：在国内小额支付中直接替代卡支付

对策：在被绕过的场景中寻找合作角度（如为 PayPal 提供 Instant Transfer 通道），同时确保 Visa 在更多高价值场景中不可替代。

第三类：根本性替代者（Fundamental Disruptors）——5% 的金融科技

这些模式如果成功，可能从根本上替代卡网络：

  • 去中心化金融（DeFi）：如果稳定币成为主流支付方式
  • 央行数字货币（CBDC）：如果政府直接提供零费率的即时支付
  • 开放银行 A2A 支付：如果账户对账户支付规模化成功

对策：积极参与和连接（成为加密结算层、参与 CBDC 设计），同时确保这些替代方案的发展速度慢于 Visa 自身的进化速度。

"合作而非对抗"的具体战术

战术一：成为金融科技的默认基础设施

Visa 通过以下方式让自己成为金融科技公司创业的"默认选择"：

  • Visa Fintech Fast Track：数周内完成网络接入
  • Visa Ready 认证：为硬件和软件创新提供质量背书
  • Visa Developer Platform：开放 API 让开发者可以免费使用 Visa 能力
  • 创业扶持：为早期金融科技公司提供技术支持和市场推广资源

战术二：策略性定价和激励

对高增长金融科技公司提供优惠的网络费率：

  • 初期免费或低费率接入，随交易量增长逐步调整至标准费率
  • 与全球性金融科技公司（如 Revolut、Wise）签订定制合约
  • 为 BNPL 模式设计专门的交易结构和费率方案

战术三：联合产品开发

与金融科技公司共同开发新产品：

  • 与 Apple 联合设计 Apple Card 体验
  • 与 Coinbase 合作开发加密货币 Visa 卡
  • 与 Klarna 合作优化 BNPL 商户体验
  • 与 Plaid 合作探索开放银行整合

战术四：投资获取视野

通过 Visa Ventures 投资金融科技公司：

  • 不追求财务回报最大化，追求战略信息和关系
  • 投资决策由战略团队而非财务团队主导
  • 被投公司成为合作深化的优先对象
  • 部分投资演变为收购标的（如 Plaid）

Plaid 收购尝试：战略与教训

2020 年 1 月，Visa 宣布以 $5.3B 收购 Plaid——这是 Visa 金融科技合作策略的最大手笔。Plaid 提供连接用户银行账户的 API，被超过 11,000 家金融应用使用。

Visa 的战略意图：

  • 获取银行账户层面的数据连接能力
  • 控制"开放银行"的关键基础设施
  • 将 Plaid 的数据网络与 Visa 的支付网络融合
  • 预防竞争对手（Mastercard）收购 Plaid

美国司法部的反对理由：

  • Visa 收购 Plaid 将消除一个潜在竞争者
  • Plaid 正在开发可能与 Visa 竞争的支付服务
  • 收购将加强 Visa 在在线借记卡交易中的主导地位

Visa 最终放弃收购（2021 年 1 月）

教训与后续策略调整：

  1. 大型并购面临越来越严格的反垄断审查
  2. 转向更小规模、更专注的收购（Tink 2.1B、Pismo2.1B、Pismo2.1B、Pismo1B）
  3. 加速自研开放银行和 A2A 支付能力
  4. 对监管风险进行更全面的前置评估

PayPal：从对手到合作伙伴

PayPal 是最早"威胁"卡网络的金融科技公司之一。2000 年代，PayPal 允许用户在 PayPal 余额之间转账，完全绕过 Visa 网络。但 Visa 与 PayPal 的关系经历了几个阶段：

第一阶段（2000s）：警惕与对立

  • PayPal 试图建立自己的商户网络
  • Visa 担心被"脱媒"

第二阶段（2010s）：合作框架建立

  • 2016 年，Visa 与 PayPal 签订"合作伙伴协议"
  • PayPal 同意在结账页面更prominently展示 Visa 标志
  • Visa 为 PayPal 提供 Visa Token Service 支持
  • PayPal 的 Venmo 开始发行 Visa 借记卡

第三阶段（2020s）：深度整合

  • PayPal 使用 Visa Direct 为 Instant Transfer 提供实时到账
  • Venmo Visa 卡成为年轻用户的重要入口
  • PayPal 的加密货币交易通过 Visa 网络清算

关键洞察：PayPal 最终发现完全绕过卡网络的成本和复杂度远超预期。与其建立自己的全球清算网络，不如利用 Visa 的现有基础设施。这正是 Visa "合作吸纳"策略的成功之处。

对 BNPL（先买后付）的战略定位

先买后付（Klarna、Afterpay、Affirm）的兴起最初被视为对信用卡的直接替代。但 Visa 的分析显示：

BNPL 的底层仍依赖 Visa：

  • Klarna 向商户支付全款时，走的是 Visa 网络
  • Afterpay 向消费者收取分期款时，从消费者的 Visa 借记卡扣款
  • BNPL 公司发行的虚拟卡（用于实体店消费）通常是 Visa 品牌

Visa 的策略：

  • 欢迎 BNPL 公司使用 Visa 网络（增量交易）
  • 为 BNPL 设计专门的"Visa Installments"产品（让传统发卡行也能提供分期功能）
  • 通过 Visa Installments 确保分期付款留在 Visa 生态内

实践案例

案例一：Wise（TransferWise）的共存策略

Wise 是全球最大的在线跨境汇款公司之一，其核心价值主张是"低成本跨境转账"——直接挑战了 Visa 高收费跨境交易的利润池。

表面上的竞争：

  • Wise 的 A2A 跨境转账费率约 0.5-1%，远低于 Visa 跨境交易的费率
  • Wise 用户越多，通过 Visa 网络的跨境交易可能越少

Visa 的应对：

  • 不对抗 Wise 的核心 P2P 汇款业务
  • 与 Wise 合作发行 Visa 借记卡（Wise Card），让 Wise 用户在海外消费时使用 Visa 网络
  • Wise Card 的海外消费仍产生 Visa 跨境交易收入
  • 通过 Visa Direct 为 Wise 提供实时到账能力

结果：Wise 成为 Visa 的合作伙伴而非敌人，Visa 从 Wise 的增长中也获益（Wise Card 的交易量快速增长）。

案例二：Crypto.com Visa 卡的生态整合

加密货币交易所 Crypto.com 发行的 Visa 卡是加密与传统支付融合的标杆案例：

合作模式：

  • 用户在 Crypto.com 持有加密货币
  • 使用 Crypto.com Visa 卡在任何接受 Visa 的商户消费
  • 交易瞬间将加密货币兑换为法币，通过 Visa 网络完成支付
  • 商户收到的是法币，完全无感加密货币的存在

对 Visa 的价值：

  • 增量交易量（加密用户的日常消费通过 Visa 网络完成）
  • 吸引年轻、高科技素养的新用户群体
  • 在加密领域建立品牌影响力
  • 不承担任何加密货币价格风险（风险留给用户和 Crypto.com）

案例三：Block（原 Square）的竞合演变

Block（Jack Dorsey 创立）从最初的小微商户移动 POS 起家，如今已发展为集商户服务（Square）、消费者金融（Cash App）和加密货币（Spiral）于一体的金融科技巨头。

合作维度：

  • Square 的核心商户服务依赖 Visa 网络处理卡支付
  • Cash App Visa 卡让用户在线下消费
  • Block 是 Visa 最大的收单合作伙伴之一

竞争维度：

  • Cash App 的 P2P 转账绕过 Visa 网络
  • Block 正在开发基于比特币的支付网络
  • Square Banking 提供直接存款和借贷，可能减少对卡的依赖

Visa 的平衡术：

  • 通过优惠费率和合作协议确保 Square 核心业务留在 Visa 网络
  • 接受 Cash App P2P 的"绕过"（市场相对较小）
  • 密切关注但不过度反应 Block 的比特币支付计划
  • 保持足够的开放性，使 Block 没有动力完全脱离 Visa 生态

总结与启示

Visa 的金融科技合作策略提供了以下管理启示：

  1. 区分威胁等级：并非所有"颠覆者"都是真正的威胁。70% 的金融科技实际上是网络的增强者而非替代者。精准分类是正确应对的前提
  2. 基础设施不可替代性：当你的能力处于足够底层时，上层的创新反而为你带来增量。Visa 的全球清算网络是金融科技公司无法自建的
  3. 速度是最好的防御：通过 Fast Track 简化接入，确保金融科技公司在做网络选择时首先想到 Visa。12 个月的接入流程会把客户推向竞争对手
  4. 合作不等于放弃竞争：Visa 与 PayPal 合作，但同时开发 Visa Checkout 与 PayPal 竞争。合作是手段不是目的
  5. 反垄断是现实约束：Plaid 案例提醒我们，在监管日益严格的环境中，"用收购消灭威胁"的策略越来越难以执行。需要更多依赖自建和合作
