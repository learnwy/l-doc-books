LVMH 绩效考核体系

双维度评估：创意与商业的并行考核

LVMH 的绩效考核体系最独特之处在于拒绝用单一标准衡量所有人。在一个创意总监的灵感和品牌 CEO 的财务目标同等重要的组织中，绩效考核必须设计为双维度并行体系——创意贡献和商业成果各有独立的评估逻辑。

品牌 CEO/President 是 LVMH 绩效考核体系中最关键的节点——他们承担品牌整体表现的最终责任。

品牌总裁的"隐形考核"
除了上述可量化的 KPI，品牌总裁还面临 Arnault 本人的直觉评估——这些不写在考核表上，但决定着职业命运：


    

  1. 创意敏感度：总裁是否理解并支持创意团队的愿景？
    2. 

  2. 危机应对：面对公关危机或市场下滑时的反应速度和质量
    3. 

  3. 行业关系：与关键 KOL、媒体、零售合作伙伴的关系质量
    4. 

  4. 战略前瞻性：是否在为品牌的下一个十年布局？
    5. 

  5. 文化契合度：是否体现了 LVMH 的核心价值观？
    6.

考核周期与流程
详细流程：


    

  1. 目标设定（January-February）
    

      

    • 品牌级目标由集团→部门→品牌层级分解
      • 

    • 个人目标与上级协商确定（SMART原则）
      • 

    • 创意序列以"方向性目标"替代具体数字目标
      • 

    

    2. 

  2. 年中回顾（June-July）
    

      

    • 非正式，以对话为主
      • 

    • 目标调整窗口（市场变化可能导致原始目标不合理）
      • 

    • 发展需求确认
      • 

    

    3. 

  3. 年末评估（November-December）
    

      

    • 正式绩效面谈
      • 

    • 360度反馈（Manager 级别及以上）
      • 

    • 最终评级确定
      • 

    

    4. 

  4. 结果应用（January-March）
    

      

    • 奖金计算和发放
      • 

    • 晋升决定
      • 

    • 个人发展计划（IDP）制定
      • 

    

    5.

强制分布（Forced Ranking）：LVMH 不强制执行严格的强制分布，但各品牌 HR 会引导评级分布接近上述比例。顶级品牌（LV、Dior）因人才密度高，E 级的竞争尤为激烈。


绩效与薪酬的联动
奖金乘数计算
最终奖金 = 目标奖金 × 品牌绩效系数 × 个人绩效系数

品牌绩效系数：0.5-1.5（品牌年度业绩决定）
个人绩效系数：
  E = 1.5-2.0
  A = 1.1-1.3
  M = 0.9-1.0
  P = 0.5-0.7
  U = 0

LVMH 绩效文化的独特之处
    

  1. 容忍创意失败：在创意序列中，一次大胆但失败的尝试不会被严厉惩罚——前提是它忠于品牌精神并推动了行业对话
    

    2. 

  2. 长期视野：品牌总裁的绩效不仅看当年数字，更看 3-5 年的品牌健康度趋势。短期压榨利润损害品牌长期价值的行为会被识别和制止
    

    3. 

  3. 直觉判断的权重：在正式 KPI 之外，Arnault 和部门负责人的主观评价对高管职业走向有决定性影响。这既是优势（避免唯数字论）也是风险（可能不透明）
    

    4. 

  4. 品牌间比较：集团会进行跨品牌的绩效对标——同类品牌（如同规模时装品牌）之间的业绩差异是评估品牌总裁的重要维度
    

    5. 

  5. 退出文化：LVMH 的"快换人"文化意味着绩效不佳的高管离开速度快于大多数欧洲公司。但这通常以"协商离职"方式完成，附带优厚的离职补偿，维护双方体面
    

    6.
