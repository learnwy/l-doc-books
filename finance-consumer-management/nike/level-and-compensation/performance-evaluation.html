Nike 绩效考核体系

绩效管理框架

Nike 的绩效管理体系在 2024–2025 年经历了重大变革。随着 Elliott Hill 推行"Win Now"战略，绩效系统从强调"增长潜力"转向强调"即时交付能力"。

年度绩效周期

OKR 体系
目标设定原则
Nike 使用 OKR（Objectives and Key Results）作为目标管理框架：






层级
OKR 特征
示例





公司级
3–5 个年度 Objectives
"恢复北美市场增长到 X%"




BU/Function 级
对齐公司目标的分解
"Nike App MAU 提升 Y%"




团队级
具体可衡量的项目目标
"重构推荐系统，提升点击率 Z%"




个人级
与团队目标关联的个人贡献
"交付 ABC 模块，Q2 上线"





Key Results 的衡量标准
    

  • 量化优先：尽可能用数字衡量（营收增长、用户指标、代码质量指标）
    • 

  • 70% 是成功：与 Google 类似，OKR 设定得有野心，达成 70% 即为正轨
    • 

  • 季度刷新：每季度 Check-in 时可调整 KR，但 Objective 通常全年不变
    • 



Calibration 校准流程
Calibration 是 Nike 绩效系统中最关键（也最具争议性）的环节：


流程结构
绩效等级分布
Nike 使用强制分布（Forced Curve）模型，虽然官方不称之为"强制"：






等级
比例目标
含义
薪酬影响





Exceeds（卓越）
~10–15%
远超预期，额外影响力
最高调薪 + 高 RSU 刷新




Strong（强）
~25–30%
稳定高表现
高于平均调薪 + RSU

~10–15%

Calibration 的实际运作
谁参与：


    

  • 直属 Manager 为每位下属准备评估材料
    • 

  • Skip-Level（Manager 的 Manager）参与校准会议
    • 

  • HR Business Partner 作为流程协调人
    • 

  • 同级 Manager 交叉讨论各自团队的人员
    • 



典型讨论：


    

  • "这个人的项目确实完成了，但对比同 Band 其他人，影响力够不够 Strong？"
    • 

  • "虽然数据好看，但他的贡献有多少是团队协作 vs 个人独立驱动？"
    • 

  • "这个评级如果给 Exceeds，对标谁？有具体的对比案例吗？"
    • 



Calibration 的争议
    

  • 信息不对称：员工不参与校准会议，Manager 的代言能力直接影响结果
    • 

  • 政治因素：声量大的 Manager 可能为其团队争取更多 Exceeds 名额
    • 

  • 跨团队不公：同样的表现在不同团队可能因 Manager 的标准差异而获得不同评级
    • 



PIP 机制（Performance Improvement Plan）
触发条件
    

  • 连续两个周期"Partially Achieves"
    • 

  • 单次"Does Not Meet"
    • 

  • Manager 主动提出（需 HR 批准）
    • 



PIP 流程




阶段
时长
内容





PIP 启动
第 0 天
书面通知、明确改善目标




改善期
30–90 天
每周 1:1 跟踪、明确的交付物




中期检查
第 30/45 天
评估进展，决定是否延长或终止




最终评估
第 60/90 天
通过 = 正常续用；未通过 = 终止合同





PIP 的现实
    

  • 通过率较低：业内估计 Nike 的 PIP 通过率约 20–30%
    • 

  • 实质是"有文件记录的分手流程"：很多 PIP 的真实目的是为终止合同建立法律文件
    • 

  • 心理压力巨大：进入 PIP 的员工通常面临团队孤立和持续的焦虑
    • 

  • 策略性退出：部分员工在收到 PIP 通知后主动选择协商离职（negotiated exit）以获得遣散包
    • 



绩效与晋升的关系
晋升的绩效前提




晋升类型
绩效要求
额外条件





Band 内晋级（如 IC I → IC II）
连续 1–2 个"Achieves"以上
展示下一级别能力




Band 间晋升（如 Band IV → V）
至少 1 个"Strong"或"Exceeds"
填补岗位空缺/新增需求




管理转轨（IC → Manager）
持续高绩效 + 领导力证据
团队有管理需求





晋升窗口
    

  • 正式窗口：每年 1–2 次（通常与 Calibration 同步）
    • 

  • 例外晋升：极少数，需 VP 级别特批
    • 

  • 晋升节奏：典型的 IC I → Senior IC 需要 5–8 年
    • 



2025–2026 重组对绩效体系的影响
Win Now 战略对绩效系统带来了实质性变化：


变化趋势
    

  1. 更强的交付导向：OKR 中"影响力"的权重增加，"能力发展"权重降低
    2. 

  2. 更快的不合格淘汰：PIP 周期可能缩短，容忍度降低
    3. 

  3. 资源向高绩效者倾斜：RSU 刷新更集中于 Top 20%
    4. 

  4. 层级压缩后的竞争加剧：裁员后留下的人面临更高的期望和更少的晋升名额
    5. 



对员工的建议
    

  • 确保目标可量化：模糊的 OKR 在 Calibration 中没有说服力
    • 

  • 主动向上管理：确保 Skip-Level 知道你的贡献（因为他参与校准）
    • 

  • 文档化成果：不是口头汇报，而是有可追溯的数据和成果记录
    • 

  • 了解"对标人选"：知道在 Calibration 中你会被拿来和谁比较
    • 



小结
Nike 的绩效系统是"目标管理 + 强制分布 + 校准会议"的经典组合。它的核心逻辑是：公司资源（薪酬、晋升、股票）有限，必须通过相对排名而非绝对标准来分配。这意味着你的绩效不仅取决于你做了什么，还取决于你的 Manager 如何在校准会议中为你代言，以及你所在 Band 的竞争对手表现如何。理解这个系统的"明规则"和"潜规则"，是 Nike 职场生存的基本功。
