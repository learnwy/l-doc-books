艺术与商业的平衡

核心命题：当情感价值遇上商业规模

泡泡玛特面临的核心张力在于：潮玩的价值根基是艺术性和情感共鸣，但企业增长要求规模化生产和商业化运营。如何在不稀释艺术价值的前提下实现商业扩张，是贯穿泡泡玛特发展始终的关键命题。

自由度的三层边界
案例：Kenny Wong 与 MOLLY
MOLLY 的创作者 Kenny Wong 是理解泡泡玛特设计师合作模式的最佳窗口：


    

  • 2016 年签约前：Kenny 是独立艺术家，MOLLY 年销几百个
    • 

  • 签约后的自由：Kenny 保持独立创作，泡泡玛特不干涉设计方向
    • 

  • 平台赋能：泡泡玛特提供工业化生产、全球渠道、品牌推广
    • 

  • 结果：MOLLY 成为中国最知名的潮玩 IP 之一，Kenny 获得丰厚回报
    •

"减法的力量"
王宁每年在内部复盘时都会强调"减法的力量"。在商业化层面，这意味着：

商业化的四个节奏控制点
关键原则：每一步都有"止损阀"。不是所有 IP 都需要走到"规模化"阶段，能在早期识别并接受"这个 IP 不适合大规模商业化"同样重要。


LABUBU 的"反直觉"商业化
2025 年 LABUBU 全球爆火后，泡泡玛特采取了一系列反直觉的操作：


    

  • 主动控制产量：不大规模扩产以维持稀缺感
    • 

  • 拒绝过度授权：不将 LABUBU 大量授权给第三方
    • 

  • 打击黄牛：限制代购、代排，保护真实用户体验
    • 

  • 克制联名频率：不因热度而密集推出联名产品
    • 



王宁对此的解释："品牌现在正在形成势能，这个势能用不好的话，很多企业就会在这个时候犯很多错误。"

避免 IP 衰退的关键策略
    

  1. 品类创新：为成熟 IP 开发新品类（如 LABUBU 从盲盒到搪胶毛绒）
    2. 

  2. 内容赋能：通过动画、短视频等内容让 IP 更立体
    3. 

  3. 场景扩展：主题乐园、快闪店、线下展览增加 IP 触点
    4. 

  4. 限量机制：通过 MEGA 珍藏系列等高端线维持收藏热度
    5. 

  5. 跨界新生：家电、积木等品类让 IP 进入新消费场景
    6.

2025-2026 数据验证
2025 年财报数据表明泡泡玛特的艺术-商业平衡策略取得了成效：


    

  • 毛利率提升：从 2024 年 66.8% 提升至 2025 年 72.1%——说明产品溢价能力增强
    • 

  • 非 LABUBU IP 增长：2026 年非头部 IP 预计贡献 60%+ 营收——多元化成功
    • 

  • 海外毛利率 70%：高于国内——说明品牌力在海外市场获得认可
    • 

  • 设计师生态稳定：500+ 签约设计师，年孵化新 IP 超百个
    • 





对管理者的启示
艺术-商业平衡的五个原则
    

  1. 创作自由是底线：不用 KPI 驱动设计师创作方向
    2. 

  2. 商业化是赋能而非束缚：让好的设计触达更多人
    3. 

  3. 时间是最好的滤网：不急于判断 IP 的商业潜力
    4. 

  4. 克制是竞争力：不做的事比做的事更重要
    5. 

  5. 数据参考但不决策：数据告诉你"是什么"，但艺术直觉告诉你"该怎么做"
    6. 



王宁的平衡哲学总结


"文化产业的魅力在于，它要求较强的软实力，无法理性计算，也就是说，不是花钱就能再造出一个拉布布。"——王宁




这句话揭示了泡泡玛特商业成功的本质：正是因为艺术价值无法被资本复制，坚守艺术底线的企业反而获得了最深厚的商业护城河。
