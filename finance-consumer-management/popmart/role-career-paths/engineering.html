泡泡玛特技术岗位路径

技术在泡泡玛特的战略定位

从"零售公司"到"科技驱动的文化消费平台"

泡泡玛特表面上是一家潮玩零售公司，但其底层已经高度数字化。2025 年全年营收 371.2 亿元，支撑这个体量的是一套复杂的技术系统——从抽盒机小程序到全球电商平台，从会员系统到供应链数字化，从 AR 互动体验到数据驱动决策。

技术不是泡泡玛特的核心壁垒（那是 IP），但技术是放大核心壁垒的关键杠杆。

技术团队规模与定位

维度 现状（2025-2026）
技术团队规模 估计 500-800 人（含海外技术岗）
技术占总员工比 约 5-8%（10000+ 全球员工）
总部位置 北京朝阳区浦项中心
技术方向 电商、小程序、会员、供应链、数据、AR/AI
技术栈 Node.js/TypeScript + React/Next.js + PostgreSQL + Redis + Kafka
开发工具 Cursor、Trae、Claude Code 等 AI IDE

泡泡玛特的特殊考量
在泡泡玛特选择 IC 还是管理，还需考虑：


    

  1. 公司阶段：高速增长期，管理岗位需求大——晋升机会多
    2. 

  2. 技术深度：公司技术复杂度中等——纯技术 P7+ 的空间有限
    3. 

  3. 业务理解：技术岗也需要深度理解潮玩业务——偏业务型的技术人才更受重视
    4. 

  4. 全球化机遇：海外技术团队建设需要技术管理人才
    5. 





逐级晋升行动清单
P2→P3 行动清单

    • 



P3→P4 行动清单
    

  •  主导一个中型项目的技术方案设计
    •

  •  在团队内进行至少 1 次技术分享
    • 



P4→P5 行动清单
    

  •  负责一个系统/子系统的技术演进方向

P5→P6 行动清单
    

  •  负责公司级技术决策（架构升级/技术栈迁移）

    • 

  •  能从行业视角评估公司技术体系的优劣
    • 

  •  参与或主导技术战略规划
    • 

  •  在技术社区有一定知名度（可选但加分）
    • 

  •  能从 0 到 1 设计新系统并推动落地
