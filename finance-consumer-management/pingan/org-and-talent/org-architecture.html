综合金融组织架构

知识要点

平安集团的组织架构是中国综合金融控股集团中最具代表性的范本。作为一家覆盖保险、银行、投资、科技四大板块的超级金融集团，平安采用了"集团控股+子公司独立运营"的组织模式。其核心架构特征是：集团层面实施强战略管控和资源协调，子公司层面保持业务运营独立性和市场化竞争能力。联席CEO制度（Co-CEO）、矩阵式管理、以及"个人综合金融"和"团体综合金融"双条线并行的设计，使得这一架构能够同时实现规模协同和专业深耕。

组织架构的核心设计原则：

  • 控股集团作为战略大脑：集团负责战略方向、资本配置、品牌管理、合规底线、核心科技基础设施
  • 子公司作为业务引擎：各子公司拥有独立法人地位、独立管理层、独立财务核算，直接面对市场竞争
  • 联席CEO制度：自马明哲逐步退居二线后，由两位联席CEO（谢永林、陈心颖）分管不同板块
  • 矩阵式双线管理：每个子公司CEO既向联席CEO汇报，又受集团职能线（人力、财务、合规、科技）的管控
  • 综合金融委员会：跨子公司协调机制的核心组织，推动交叉销售和客户资源共享

详细讲解

集团控股架构总览

平安集团（中国平安保险（集团）股份有限公司）是最顶层的控股实体，通过直接和间接持股控制旗下数十家子公司。核心架构如下：

联席CEO制度
平安的联席CEO（Co-CEO）制度是其组织架构中最具特色的设计之一：


历史演进：


    

  • 2018年前：马明哲担任董事长兼CEO，是集团唯一的最高决策者
    • 

  • 2018-2020年：马明哲逐步引入联席CEO机制，先后任命李源祥、谢永林、陈心颖为联席CEO
    • 

  • 2020年后：李源祥离职后，形成谢永林（负责金融业务）和陈心颖（Jessica Tan，负责科技和医疗业务）的双CEO格局
    • 

  • 2023年后：陈心颖离任，组织架构进一步调整
    •

联席CEO制度的优势：


    

  1. 避免单一CEO认知瓶颈——金融和科技是两种完全不同的管理范式
    2. 

  2. 内部赛马机制——两位CEO分管板块的业绩可对比，形成良性竞争
    3. 

  3. 接班梯队——联席CEO制度本身就是对未来一把手的考察和培养
    4. 



潜在风险：


    

  1. 权责边界模糊可能导致推诿或重复决策
    2. 

  2. 两位CEO管理风格差异可能造成组织文化撕裂
    3. 

  3. 需要董事长作为仲裁者维持平衡，一旦仲裁者缺位可能失稳
    4. 



集团与子公司的管控模式
平安采用"强总部、活子公司"的管控模式，具体体现为：


集团层面管控的事项（不可下放）：


    

  1. 战略方向：五年战略规划、重大业务进入/退出决策、并购交易
    2. 

  2. 资本配置：子公司年度资本预算、重大投资（>10亿元）、分红政策
    3. 

  3. 品牌管理：统一的"平安"品牌使用规范、重大公关事件应对
    4. 

  4. 科技基础设施：云计算平台、AI中台、数据中台由集团统建共用
    5. 

  5. 风控底线：合规管理、内部审计、反洗钱（AML）、信息安全
    6. 

  6. 高管任免：子公司CEO及副总级别的任命和绩效考核
    7. 



子公司层面的自主权：


    

  1. 产品设计：在合规框架内自主设计和定价产品
    2. 

  2. 渠道建设：自主决定销售渠道布局和投入
    3. 

  3. 日常运营：独立的运营管理和人员调配
    4. 

  4. 市场竞争：以独立市场主体身份参与竞争，即使与同集团子公司形成竞争关系
    5. 

  5. 激励机制：在集团薪酬框架内自主设计绩效考核和激励方案
    6. 



矩阵式管理的实施
平安的矩阵管理体现为"业务线+职能线"的双重汇报：


业务线（纵向）：


    

  • 子公司CEO → 联席CEO → 董事长
    • 

  • 各子公司内部按业务条线管理
    • 



职能线（横向）：


    

  • 集团人力资源中心 → 对各子公司HR负责人有指导权和审批权
    • 

  • 集团财务中心 → 对各子公司CFO有财务报告标准和资本使用的管控权
    • 

  • 集团合规中心 → 对各子公司合规官有直接指挥权（合规官向集团虚线汇报）
    • 

  • 集团科技中心 → 对各子公司CTO有技术标准和架构审批权
    • 



实际运作中的张力：


在矩阵管理中，"子公司CEO的业务目标"与"集团职能线的管控要求"经常产生张力。例如：


    

  • 子公司CEO想快速上线新产品以抢占市场→集团合规线要求完成全面的合规审查（耗时3个月）
    • 

  • 子公司想自建技术系统以满足特殊需求→集团科技线要求统一使用中台能力
    • 

  • 子公司想通过高薪挖人→集团HR线担心引发内部薪酬攀比
    • 



平安通过"联席CEO裁决机制"解决这些冲突：当业务线和职能线无法达成一致时，由对应联席CEO做最终裁决。


综合金融委员会
综合金融委员会（Comprehensive Finance Committee）是平安协调跨子公司协同的核心组织机构：


组成：


    

  • 主席：集团联席CEO
    • 

  • 成员：各子公司CEO、集团首席运营官、集团战略发展中心负责人
    • 

  • 执行秘书：综合金融部负责人
    • 



职责：


    

  1. 制定年度交叉销售目标和策略
    2. 

  2. 协调子公司间的客户资源共享规则
    3. 

  3. 裁决子公司间的利益分配争议
    4. 

  4. 评估综合金融项目的投入产出
    5. 

  5. 推动综合金融IT系统建设
    6. 



会议机制：


    

  • 月度例会：审视交叉销售数据、协调当期重点项目
    • 

  • 季度战略会：调整综合金融策略方向
    • 

  • 年度规划会：制定下一年综合金融目标
    • 



个人综合金融 vs 团体综合金融
平安的组织架构中有一个独特设计——将综合金融业务分为"个人"和"团体"两条线：


个人综合金融（Personal Comprehensive Finance）：


    

  • 面对个人客户和家庭客户
    • 

  • 核心载体：平安人寿代理人、平安银行零售、平安口袋银行APP
    • 

  • 核心指标：客均合同数、客均AUM、交叉销售率
    • 

  • 主管：寿险改革办公室+银行零售事业部
    • 



团体综合金融（Corporate Comprehensive Finance）：


    

  • 面对企业客户和机构客户
    • 

  • 核心载体：平安银行对公、平安财险、平安信托
    • 

  • 核心指标：企业客户综合收入贡献、企业客户金融产品渗透率
    • 

  • 主管：团体综合金融委员会
    • 



两条线各有独立的管理团队、KPI体系和激励机制，但共享集团科技中台和数据资源。


实践案例
案例一：寿险改革中的组织架构调整
2019年，平安启动寿险改革（被称为"最难的改革"），组织架构变动是改革的核心内容之一：


改革前的组织问题：


    

  • 保险代理人队伍超过140万人，管理层级过多（7-8级）
    • 

  • 代理人与银行渠道、科技渠道之间存在严重的"抢客户"现象
    • 

  • 分公司—中支—营业区—营业部的层级架构导致信息传递失真
    • 

  • 交叉销售指标分摊到基层后变形为"强制搭售"
    • 



组织架构调整方案：


    

  • 压缩管理层级：从7级压缩为5级
    • 

  • 设立"综合金融服务中心"：在每个营业区设置专职综合金融岗位
    • 

  • 代理人分类管理：区分"保障型代理人"和"综合金融代理人"两种定位
    • 

  • 新设"数字化营业部"：以线上方式管理远程代理人
    • 



结果：代理人数量从140万降至50万+，但人均产能提升3倍以上。组织更加精干，综合金融执行力反而更强。


案例二：平安银行的组织重构
平安银行在2016年前后进行了大刀阔斧的组织重构，从传统银行架构转向"零售+科技"双驱动架构：


重构前：


    

  • 传统的"总行→分行→支行"三级架构
    • 

  • 对公和零售完全割裂
    • 

  • 科技部门是"后台支持"角色
    • 



重构后：


    

  • 设立三大事业群：零售金融、对公金融、资金同业
    • 

  • 科技团队从"IT部"升级为"首席信息官条线"，CTO直接进入核心管理层
    • 

  • 设置"综合金融事业部"专门承接集团客户转介
    • 

  • "新零售"模式：线上APP+线下网点融合
    • 



关键组织创新：


    

  • "AI银行家"概念：科技团队内嵌到每个业务条线，而非集中在一个IT部门
    • 

  • "铁三角"团队：客户经理+产品经理+技术经理三人小组服务大客户
    • 

  • 敏捷组织：部分团队采用SQUAD制（类似Spotify模式），跨职能小团队快速迭代
    • 



案例三：金融壹账通的独立运营与集团协同
金融壹账通（OneConnect）作为平安科技输出的核心平台，其组织定位体现了集团架构的灵活性：


组织定位的三重身份：


    

  1. 集团子公司：受集团战略管控和资本调配
    2. 

  2. 独立上市公司（曾在NYSE上市）：有独立董事会、独立治理结构
    3. 

  3. 集团技术对外窗口：代表平安向外部金融机构提供技术服务
    4. 



协同与独立的平衡：


    

  • 技术底座来自平安科技（集团共享），但产品化和客户服务由壹账通自主完成
    • 

  • 在服务外部银行时，必须确保客户数据不回流给平安银行（竞争隔离）
    • 

  • 定价策略既要市场化竞争，又要考虑集团整体利益
    • 



组织架构中的"防火墙"设计：


    

  • 数据防火墙：外部客户数据与集团内部数据物理隔离
    • 

  • 人员防火墙：核心岗位不能兼任集团其他子公司职务
    • 

  • 商务防火墙：与外部客户的合同条款中明确数据归属和保密义务
    • 



总结与启示
平安综合金融组织架构的核心经验：


    

  1. "控"与"放"的艺术：集团管控战略、资本、品牌、科技底座和合规底线，其余充分下放给子公司。过度集权会扼杀子公司的市场竞争力，过度放权会导致资源浪费和品牌混乱。
    

    2. 

  2. 联席CEO是过渡期方案而非终态：联席CEO制度本质上是权力交接的过渡安排。它需要一个强势的董事长作为仲裁者才能有效运作。一旦董事长缺位或退出，必须回归单一CEO架构。
    

    3. 

  3. 矩阵管理的代价是决策效率：双线汇报增加了协调成本。平安通过"联席CEO快速裁决"机制部分解决了这一问题，但在实际运作中，很多中层管理者仍然面临"两个老板"的困境。
    

    4. 

  4. 组织架构必须跟随战略演化：平安的架构在过去20年经历了数次重大调整——从保险公司到金融集团，从金融集团到"金融+科技"集团。每一次战略转型都伴随着组织架构的重大变革。
    

    5. 

  5. 综合金融的组织难题：跨子公司的客户资源共享和利益分配是所有综合金融集团面临的共同难题。平安通过"综合金融委员会+交叉销售积分制"部分解决了利益分配问题，但子公司间的博弈从未停止。组织设计只能减少摩擦，不能消除摩擦。
    

    6.
