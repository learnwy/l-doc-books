安踏集团技术岗位成长路径

技术团队在安踏的战略定位

安踏集团的技术团队承载着 AI 365 战略落地、全渠道数字化运营、全球化系统支撑的核心使命。2024 年研发投入近 20 亿元（2015 年仅约 3 亿元，十年增长近 7 倍），技术已从"支撑部门"跃升为"战略驱动力"。

技术方向全景

安踏的技术岗位覆盖以下核心方向：

方向 核心系统 团队规模趋势 战略优先级
电商平台 多品牌电商中台、DTC直营 稳定增长 ⭐⭐⭐⭐
会员数字化 超亿会员系统、精准营销 快速增长 ⭐⭐⭐⭐⭐
供应链系统 智能补货、需求预测、WMS 快速增长 ⭐⭐⭐⭐⭐
数据中台 数据湖、BI、算法平台 快速增长 ⭐⭐⭐⭐⭐
智能零售 门店系统、POS、"安诊无忧" 稳定增长 ⭐⭐⭐⭐
AI/算法 灵龙大模型、推荐、预测 新建/快速增长 ⭐⭐⭐⭐⭐
基础架构 云平台、中间件、安全 稳定 ⭐⭐⭐
移动端 APP/小程序/导购工具 稳定 ⭐⭐⭐

各技术方向详细路径

电商平台方向

安踏的电商体系需要支撑 15+ 品牌的多平台运营（天猫、京东、抖音、小程序等）。

技术栈：Java/Spring Cloud + 微服务 + MySQL/Redis + Kafka + K8s

级别 典型工作 关键技能
P3—P4 CRUD开发、接口实现 Java基础、Spring Boot、SQL
P5 复杂业务功能、性能优化 分布式事务、缓存设计、高并发
P6 子系统设计、大促稳定性 微服务治理、限流降级、容量规划
P7 电商中台架构、跨品牌方案 中台设计、DDD、多租户架构
P8 全渠道架构规划 技术战略、AI+电商融合

晋升关键项目：

  • P4→P5：独立负责一个品牌的电商模块，大促零故障
  • P5→P6：主导中台化改造或大促架构升级
  • P6→P7：设计多品牌电商统一架构
  • P7→P8：定义"AI+电商"的技术蓝图

会员数字化方向

安踏超亿会员系统是集团最重要的数字资产之一。

技术栈：Java + 大数据（Spark/Flink） + 画像系统 + CDP + 营销自动化

级别 典型工作 关键技能
P3—P4 会员基础功能开发 Java、数据处理、API开发
P5 画像系统、标签体系 大数据处理、实时计算
P6 CDP平台设计、跨品牌打通 数据架构、隐私合规（PIPL）
P7 会员数据智能化架构 AI推荐、营销自动化、数据策略
P8 集团数据资产战略 数据治理、AI驱动的会员价值最大化

晋升关键项目：

  • P5→P6：实现跨品牌会员身份打通
  • P6→P7：构建AI驱动的精准营销平台
  • P7→P8：定义集团数据资产变现战略

供应链系统方向

每年2亿双鞋+3亿件服装的供应链管理是安踏技术的核心战场。

技术栈：Java + Python（ML模型） + WMS/TMS + IoT + 运筹优化

级别 典型工作 关键技能
P3—P4 WMS/OMS模块开发 Java、仓储物流业务理解
P5 智能补货算法、库存优化 Python、ML基础、运筹学
P6 供应链数字孪生、全链路设计 系统架构、仿真建模
P7 智能供应链平台架构 AI+供应链、全球物流网络
P8 集团供应链技术战略 端到端数字化、行业级创新

晋升关键项目：

  • P5→P6：AI补货模型落地，库存周转提升15%+
  • P6→P7：构建柔性供应链中台
  • P7→P8：全球供应网络架构设计

数据中台/AI方向

AI 365 战略的技术核心，集团重点建设方向。

技术栈：Python + PyTorch/TensorFlow + Spark/Flink + 向量数据库 + LLM + MLOps

级别 典型工作 关键技能
P3—P4 数据ETL、基础模型训练 Python、SQL、ML基础
P5 推荐/预测模型开发 深度学习、特征工程、A/B测试
P6 AI平台建设、大模型应用 MLOps、LLM微调、RAG
P7 AI战略落地、灵龙大模型 大模型架构、AI产品化
P8 集团AI技术战略 技术愿景、行业影响

晋升关键项目：

  • P5→P6：AI模型产生可量化的业务价值（如预测准确率提升20%）
  • P6→P7：构建灵龙大模型或同等级AI平台
  • P7→P8：定义安踏"AI 365"技术路线图

智能零售方向

门店系统、POS、"安诊无忧"智能运营平台。

技术栈：Java/Node.js + React/小程序 + IoT + 边缘计算 + AI视觉

级别 典型工作 关键技能
P3—P4 POS功能开发、小程序页面 前后端基础、移动开发
P5 门店智能系统开发 IoT集成、实时计算、边缘计算
P6 "安诊无忧"平台设计 平台架构、AI集成、多门店管理
P7 新零售技术架构 OMO架构、即时零售系统、AI+零售
P8 零售科技战略 行业级创新、全球零售技术趋势
