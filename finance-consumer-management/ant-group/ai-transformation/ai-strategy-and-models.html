AI 大模型战略：百灵大模型与 AI Agent 平台

概述

2023年大模型竞赛全面爆发后，蚂蚁集团迅速确立了"AI First"战略，将大模型能力作为未来十年的核心竞争力。百灵大模型家族（Ling/Ring/Ming系列）是这一战略的技术基石。2025年3月，蚂蚁宣布百灵大模型万亿参数版本全系开源，成为国内首家将万亿参数大模型完全开源的金融科技公司。这标志着蚂蚁的AI战略从"自用"转向"平台化+生态化"。

百灵大模型家族

模型矩阵

蚂蚁的百灵大模型按应用场景分为三大系列：

系列 定位 参数规模 核心场景
Ling（灵） 通用基座模型 万亿级 通用推理、代码生成、多模态理解
Ring（睿） 金融专用模型 千亿级 风控、投研、合规、信贷决策
Ming（明） 轻量化部署模型 十亿–百亿级 端侧推理、边缘计算、IoT设备

Ling 系列：通用能力基座

Ling 系列是百灵大模型家族的基座，2025年3月开源版本的核心能力：

关键技术指标（2025年）


    

  • 参数规模：万亿级（采用MoE架构，激活参数约千亿级）
    • 

  • 上下文窗口：128K tokens
    • 

  • 训练数据：超过10万亿tokens，覆盖中英文通用语料+金融专用语料
    • 

  • 推理性能：A100集群下首字延迟 < 200ms
    • 

  • 基准测试：在MMLU、C-Eval、FinBench等多个榜单上达到国内第一梯队
    •

AFMF（Ant Financial Model Framework）


2024年9月发布的AFMF是金融大模型的应用框架：


    

  • 预置20+金融场景模板（风控、投顾、客服、合规等）
    • 

  • 内置金融知识图谱和合规规则库
    • 

  • 支持私有化部署，满足金融机构数据安全要求
    • 

  • 提供模型效果评估和监控工具
    • 



Ming 系列：端侧与边缘
Ming 系列面向资源受限场景，是蚂蚁"AI无处不在"战略的关键：


    

  • 参数规模：1B / 3B / 7B / 13B 多种规格
    • 

  • 部署形态：手机端 / IoT设备 / 边缘服务器
    • 

  • 核心场景：
      

    • 支付宝App内的端侧推理（离线场景可用）
      • 

    • 智能POS机上的商户服务
      • 

    • 车载支付场景的实时推理
      • 

    

    • 

  • 技术特点：
      

    • INT4/INT8量化，在移动端流畅运行
      • 

    • 支持NPU加速（适配主流手机芯片）
      • 

    • 本地知识库+云端大模型的混合推理

商业模式
Agent平台的商业化采用多层次定价：


    

  • 基础层（免费）：开发者试用，有调用频次限制
    • 

  • 专业层：按API调用量计费，面向中小企业
    • 

  • 企业层：私有化部署+定制化服务，面向金融机构
    • 

  • 生态分成：第三方Agent在平台获得的收入，平台抽成15–30%
    •

AI人才策略
蚂蚁在AI人才方面的投入力度：


    

  • 人员规模：AI相关岗位超过5000人（占总人力的25%+）
    • 

  • 校招倾斜：2025年校招AI方向占比超过40%
    • 

  • 薪酬竞争：AI方向薪酬较同级别非AI岗位高20–30%
    • 

  • 研究院：蚂蚁研究院下设NLP、CV、图计算、隐私计算四个实验室
    • 

  • 学术合作：与全球20+高校建立联合研究项目
    • 



竞争格局分析
国内大模型竞争
蚂蚁的差异化优势
    

  • 金融场景深度：十年金融数据和场景积累，其他通用大模型难以复制
    • 

  • 合规能力：经历监管整改后建立的合规体系，成为金融AI落地的护城河
    • 

  • 端到端闭环：从模型到应用到场景的完整闭环（百灵→Agent→支付宝/蚂蚁财富）
    • 

  • 隐私计算：摩斯+隐语的隐私计算能力，解决金融数据共享难题
    • 

  • 开源生态：通过开源建立标准和生态，形成网络效应
    • 



战略风险与展望
风险因素
    

  • 投入回报周期长：大模型研发投入巨大（年投入预计超百亿元），商业化回报尚不明确
    • 

  • 技术路线不确定性：MoE vs Dense、开源vs闭源等技术路线选择风险
    • 

  • 监管政策变化：AI监管政策可能对金融AI的自主决策能力形成限制
    • 

  • 人才竞争激烈：与字节、阿里、百度等争夺AI人才
    • 



2026–2028战略展望
蚂蚁AI战略的三年目标：


    

  • 2026年：百灵成为金融AI领域的事实标准，Agent平台MAU突破1亿
    • 

  • 2027年：AI贡献的营收占比超过30%，开源社区形成自循环
    • 

  • 2028年：实现"金融AI基础设施公司"的战略定位转型
    •
