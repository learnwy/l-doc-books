供应商评分与淘汰体系

知识要点

SHEIN 的供应商管理体系是其小单快反模式能够运转的基石。面对 3000+ 家合作工厂，SHEIN 不依赖传统的"关系维护"方式管理供应链，而是建立了一套精密的数据化评分系统。供应商的每一次交货、每一件产品的质量、每一次响应速度，都被系统记录、量化、评分。评分直接决定订单分配量，末位供应商面临降级甚至淘汰。

评分体系的核心维度：

  • 品质维度：退货率、质检合格率、客诉归因率
  • 交期维度：准时交货率、平均交货天数、紧急追单响应时间
  • 产能维度：月均产能、产能弹性（高峰期扩产能力）、品类覆盖广度
  • 配合度：系统使用率、数据更新及时性、新要求落地速度
  • 成本维度：报价竞争力、成本优化建议主动性

数据采集与评分计算
自动化数据采集


供应商的大部分评分数据通过系统自动采集，减少人为干预：


    

  • 质检数据：SHEIN 的QC团队在工厂端和入仓端进行抽检，结果直接进入系统
    • 

  • 交期数据：供应商在SCM系统中更新生产进度，系统自动记录实际交货时间与承诺时间的偏差
    • 

  • 退货归因：售后系统将退货原因（尺码问题、色差、破损等）自动关联到具体供应商
    • 

  • 产能数据：根据历史订单完成量和交期表现推算实际产能
    • 



评分计算周期


    

  • 基础评分：月度更新
    • 

  • 综合评级：季度调整
    • 

  • 淘汰决策：累计两个季度C/D级，触发正式淘汰流程
    • 



淘汰机制的具体运作
渐进式退出


SHEIN 的淘汰不是一刀切，而是有明确的降级路径：


    

  1. 黄牌警告：单月评分跌破70，系统自动发送改善通知
    2. 

  2. 订单缩减：连续两月低于70，自动减少50%新单分配
    3. 

  3. 观察期：进入3个月观察期，期间有专人跟进改善计划
    4. 

  4. 终止合作：观察期结束仍未达标，正式终止合作关系
    5. 



淘汰率与新增率


SHEIN 的供应商池保持动态平衡：


    

  • 年均淘汰率约 5-10%
    • 

  • 年均新增供应商约 15-20%（保持供应链活力）
    • 

  • 淘汰不等于"断绝关系"——改善后可以重新申请入库
    •

系统的局限与争议
局限性：


    

  • 纯数据评分可能忽视供应商的长期投入和战略价值
    • 

  • 对小型供应商不友好——一次失误可能导致评分大幅下滑
    • 

  • 某些维度（如面料创新能力）难以量化
    • 



争议：


    

  • 供应商反映评分压力导致利润极薄
    • 

  • 部分供应商为了交期指标牺牲工人福利
    • 

  • 评分过度聚焦短期指标，不利于长期合作关系建设
    • 



实践案例
案例一：一家A级供应商的日常
某位于广州番禺的核心供应商（年产值约2亿元）的管理日常：


    

  • 每日早会第一件事：查看SHEIN SCM系统中的订单状态和评分变动
    • 

  • 设立专门的"SHEIN项目组"，核心成员24小时响应追单需求
    • 

  • 投资200万元建设了自动裁剪设备，将交货周期从10天缩短到5天
    • 

  • 品控团队从3人扩充到12人，来料检验+在线检验+出厂检验三道关
    • 

  • 每月分析退货归因数据，针对高频问题制定改善计划
    • 



结果：连续12个月保持S级评分，月均订单量增长200%。


案例二：从D级到B级的逆袭
某供应商因连续两月交期不达标（准时率从92%跌到68%）降为D级：


改善行动：


    

  • 根因分析：产能计算模型过于乐观，导致承诺交期不现实
    • 

  • 调整措施：降低接单量至实际产能的80%，建立缓冲库存
    • 

  • 系统优化：安装SHEIN推荐的生产管理系统，实时追踪工序进度
    • 

  • 人员调整：招聘专职计划排产人员
    • 



6个月后评分回升到74分，恢复B级，开始重新获得增量订单。


案例三：评分系统推动的行业升级
SHEIN 的评分体系客观上推动了广州服装供应链的整体升级：


    

  • 数字化水平提升：为了满足SHEIN的系统对接要求，大量小型工厂首次部署了ERP/MES系统
    • 

  • 品质意识增强：退货归因数据让供应商第一次清楚知道"哪些品质问题最致命"
    • 

  • 管理规范化：从"老板拍脑袋"到"看数据做决策"的管理转型
    • 

  • 设备升级：追求速度的压力推动了自动化设备投资
    • 



据估计，SHEIN生态圈内的供应商在2019-2023年间累计投入超过50亿元进行产能和技术升级。


总结与启示
SHEIN 的供应商评分体系代表了一种"数据化生态管理"的范式——不是通过人际关系管理供应商，而是通过透明的数据规则让供应商自我管理和自我淘汰。


核心启示：


    

  1. 规则透明比关系亲疏更重要 —— 当评分标准清晰公开时，供应商知道如何改进，比"揣摩甲方心意"高效得多
    2. 

  2. 淘汰机制保障了生态质量 —— 没有退出机制的生态会被"搭便车者"稀释
    3. 

  3. 数据化管理降低了管理成本 —— 3000+供应商如果用传统方式管理需要庞大的供应商管理团队
    4. 

  4. 评分体系需要持续校准 —— 权重和阈值不是一成不变的，需要根据业务变化定期调整
    5. 

  5. 注意人文关怀 —— 纯数据管理可能忽视供应商作为合作伙伴的尊严和可持续性
    6.
