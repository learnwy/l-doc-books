SHEIN 绩效考核体系

OKR + KPI 混合模式

SHEIN 的绩效考核采用了互联网行业流行的 OKR（目标与关键结果）与传统 KPI（关键绩效指标）的混合模式。这种混合设计体现了 SHEIN 的管理哲学——既追求创新探索的开放性，又坚持结果导向的严格性。

OKR 与 KPI 的分工

OKR 的应用场景
SHEIN 在以下场景主要使用 OKR：


    

  • 技术方向探索：如"探索 AI 在趋势预测中的新应用"
    • 

  • 跨团队协作项目：如"打通供应链与推荐系统的数据链路"
    • 

  • 长期能力建设：如"建立供应链实时监控体系"
    •

强制分布的争议
SHEIN 在绩效考核中采用一定程度的强制分布（Forced Ranking），这意味着：


    

  • 每个团队必须有一定比例的低绩效标识
    • 

  • 即使团队整体表现优秀，也需要区分高低
    • 

  • 这种机制在高增长期激励竞争，但在成熟期可能引发内耗
    • 



快速淘汰文化
PIP（绩效改进计划）
连续获得 C 级绩效的员工会进入 PIP 流程：


    

  • 观察期：通常 1-3 个月
    • 

  • 改进目标：设定明确的可量化改进指标
    • 

  • 结果评估：达标则恢复正常，不达标则面临劝退
    • 



淘汰率
SHEIN 的淘汰强度在互联网行业中属于中上水平：


    

  • 年度淘汰率约 5-10%
    • 

  • 试用期通过率约 80-85%（高于行业平均）
    • 

  • 业务调整期可能出现更大规模的优化
    • 



淘汰文化的组织影响
正面效应：


    

  • 保持团队的竞争活力和危机意识
    • 

  • 快速淘汰不适配的人，提高整体效率
    • 

  • 为高绩效员工创造更多资源和机会
    • 



负面影响：


    

  • 可能导致短期行为，追求可量化的结果而忽视长期建设
    • 

  • 内部竞争过度可能损害协作氛围
    • 

  • 高流动性增加了知识传承和团队稳定性的风险
    • 



数据化评估的深度渗透
数据驱动绩效的具体实践
SHEIN 的"数据驱动一切"文化在绩效考核中体现得淋漓尽致：


工程师的代码指标：


    

  • 代码提交频率和代码审查参与度
    • 

  • 技术债务减少量
    • 

  • 系统性能优化的可量化结果
    • 

  • 线上故障的响应和解决时效
    • 



运营的数据指标：


    

  • 负责品类的 GMV 增长率
    • 

  • 爆款识别准确率
    • 

  • 供应商管理效率（交付时效、质量合格率）
    • 

  • 库存健康度指标
    • 



产品经理的数据指标：


    

  • 功能上线后的核心数据变化
    • 

  • A/B 测试的决策正确率
    • 

  • 需求交付时效和质量
    • 



"数据说话"的文化含义
在 SHEIN 的绩效评估中，有几个核心原则：


    

  1. 可量化优先：能用数据衡量的绩效不用主观评价
    2. 

  2. 结果大于过程：关注产出而非工时投入（虽然实际上两者都很高）
    3. 

  3. 横向对比：绩效不仅纵向看个人进步，更横向比较同级别员工
    4. 

  4. 快速反馈：不等半年一次的正式评估，数据仪表盘提供实时反馈
    5.

对求职者的启示
    

  1. 准备数据化的面试回答：SHEIN 的面试会深入考察候选人用数据驱动决策的能力
    2. 

  2. 设定清晰的可量化目标：入职后应尽快建立可追踪的个人绩效指标
    3. 

  3. 适应快节奏的反馈循环：不要等半年一次的正式评估，主动寻求日常反馈
    4. 

  4. 理解淘汰文化：提前做好心理准备，保持持续学习和输出的节奏
    5. 

  5. 关注业务理解：纯技术能力不够，需要展现对电商和供应链业务的深入理解
    6.
