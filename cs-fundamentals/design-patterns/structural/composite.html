组合模式

核心概念

组合模式（Composite Pattern）将对象组合成树形结构来表示"部分-整体"的层次关系。它让客户端可以用统一的方式处理单个对象（叶子）和组合对象（容器）。

组合模式的核心思想：无论是叶子节点还是组合节点，它们都实现相同的接口。客户端无需区分二者。




基础实现：文件系统
interface FileSystemNode {
  getName(): string;
  getSize(): number;
  print(indent?: string): string;
}

class File implements FileSystemNode {
  constructor(
    private name: string,
    private size: number,
  ) {}

  getName(): string {
    return this.name;
  }

  getSize(): number {
    return this.size;
  }

  print(indent = ''): string {
    return `${indent}📄 ${this.name} (${this.size} bytes)`;
  }
}

class Directory implements FileSystemNode {
  private children: FileSystemNode[] = [];

  constructor(private name: string) {}

  add(node: FileSystemNode): this {
    this.children.push(node);
    return this;
  }

  remove(node: FileSystemNode): void {
    const index = this.children.indexOf(node);
    if (index !== -1) {
      this.children.splice(index, 1);
    }
  }

  getName(): string {
    return this.name;
  }

  getSize(): number {
    return this.children.reduce((total, child) => total + child.getSize(), 0);
  }

  print(indent = ''): string {
    const lines = [`${indent}📁 ${this.name}/`];
    for (const child of this.children) {
      lines.push(child.print(indent + '  '));
    }
    return lines.join('\n');
  }
}

const root = new Directory('project')
  .add(new File('package.json', 1024))
  .add(new File('tsconfig.json', 512))
  .add(
    new Directory('src')
      .add(new File('index.ts', 2048))
      .add(new Directory('components').add(new File('Button.tsx', 1536)).add(new File('Modal.tsx', 2048)))
      .add(new Directory('utils').add(new File('helpers.ts', 768))),
  )
  .add(new Directory('tests').add(new File('index.test.ts', 1024)));

console.log(root.print());
console.log(`Total size: ${root.getSize()} bytes`);
getSize() 对文件返回自身大小，对目录递归计算所有子节点的大小总和。客户端无需区分文件和目录。




实际应用：UI 组件树
interface UIComponent {
  render(): string;
  getWidth(): number;
  getHeight(): number;
}

class TextElement implements UIComponent {
  constructor(
    private text: string,
    private fontSize: number,
  ) {}

  render(): string {
    return `<span style="font-size:${this.fontSize}px">${this.text}</span>`;
  }

  getWidth(): number {
    return this.text.length * this.fontSize * 0.6;
  }

  getHeight(): number {
    return this.fontSize * 1.2;
  }
}

class ImageElement implements UIComponent {
  constructor(
    private src: string,
    private width: number,
    private height: number,
  ) {}

  render(): string {
    return `<img src="${this.src}" width="${this.width}" height="${this.height}" />`;
  }

  getWidth(): number {
    return this.width;
  }

  getHeight(): number {
    return this.height;
  }
}

class Panel implements UIComponent {
  private children: UIComponent[] = [];
  private direction: 'row' | 'column';

  constructor(direction: 'row' | 'column' = 'column') {
    this.direction = direction;
  }

  add(child: UIComponent): this {
    this.children.push(child);
    return this;
  }

  render(): string {
    const childrenHtml = this.children.map((c) => c.render()).join('\n');
    return `<div style="display:flex;flex-direction:${this.direction}">\n${childrenHtml}\n</div>`;
  }

  getWidth(): number {
    if (this.direction === 'row') {
      return this.children.reduce((sum, c) => sum + c.getWidth(), 0);
    }
    return Math.max(...this.children.map((c) => c.getWidth()), 0);
  }

  getHeight(): number {
    if (this.direction === 'column') {
      return this.children.reduce((sum, c) => sum + c.getHeight(), 0);
    }
    return Math.max(...this.children.map((c) => c.getHeight()), 0);
  }
}

const card = new Panel('column')
  .add(new ImageElement('avatar.jpg', 100, 100))
  .add(new TextElement('Alice Wang', 16))
  .add(new TextElement('Software Engineer', 12))
  .add(new Panel('row').add(new TextElement('⭐ 4.9', 14)).add(new TextElement('📍 Shanghai', 14)));

console.log(card.render());
console.log(`Card size: ${card.getWidth()} x ${card.getHeight()}`);


遍历组合树
function findByName(node: FileSystemNode, name: string): FileSystemNode[] {
  const results: FileSystemNode[] = [];

  if (node.getName().includes(name)) {
    results.push(node);
  }

  if (node instanceof Directory) {
    for (const child of (node as Directory & { children: FileSystemNode[] }).children) {
      results.push(...findByName(child, name));
    }
  }

  return results;
}

interface Visitor {
  visitFile(file: File): void;
  visitDirectory(directory: Directory): void;
}

class SizeReportVisitor implements Visitor {
  private report: { name: string; size: number }[] = [];

  visitFile(file: File): void {
    this.report.push({ name: file.getName(), size: file.getSize() });
  }

  visitDirectory(directory: Directory): void {
    this.report.push({ name: directory.getName() + '/', size: directory.getSize() });
  }

  getReport(): { name: string; size: number }[] {
    return [...this.report].sort((a, b) => b.size - a.size);
  }
}


组合模式适用场景
典型场景：


    

  • 文件系统：文件和文件夹
    • 

  • UI 组件树：元素和容器
    • 

  • 组织架构：员工和部门
    • 

  • 表达式树：操作符和操作数
    • 

  • 菜单系统：菜单项和子菜单
    • 





常见误区
误区一：所有树结构都用组合模式
组合模式的前提是叶子和容器需要统一接口。如果叶子和容器的行为差异很大，强行统一接口反而会导致不自然的 API。


误区二：在叶子节点上实现容器方法
有些实现在 Component 接口中定义了 add、remove 方法，叶子节点抛出异常。这违反了里氏替换原则。更好的做法是只在 Composite 类中定义管理子节点的方法。


误区三：忽略树结构的性能问题
递归计算（如 getSize()）在深层树中可能有性能问题。对于频繁查询的属性，可以考虑缓存机制。




小结
    

  • 组合模式让客户端用统一的方式处理单个对象和组合对象。
    • 

  • 核心在于叶子节点和容器节点实现相同的接口。
    • 

  • 适用于文件系统、UI 组件树、组织架构等树形结构场景。
    • 

  • 管理子节点的方法（add/remove）应放在 Composite 中，而非 Component 接口中。
