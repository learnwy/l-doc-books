命令模式

核心概念

命令模式（Command Pattern）将请求封装为对象，从而支持参数化请求、请求排队、日志记录以及可撤销操作。命令模式将"发起请求的对象"与"执行请求的对象"解耦。

命令模式的四个角色：Command（命令接口）、ConcreteCommand（具体命令）、Invoker（调用者）、Receiver（接收者）。




实现 Undo/Redo
interface Command {
  execute(): void;
  undo(): void;
  description: string;
}

class TextEditor {
  private content = '';

  getContent(): string {
    return this.content;
  }

  insert(text: string, position: number): void {
    this.content = this.content.slice(0, position) + text + this.content.slice(position);
  }

  delete(position: number, length: number): string {
    const deleted = this.content.slice(position, position + length);
    this.content = this.content.slice(0, position) + this.content.slice(position + length);
    return deleted;
  }

  replace(position: number, length: number, text: string): string {
    const replaced = this.content.slice(position, position + length);
    this.content = this.content.slice(0, position) + text + this.content.slice(position + length);
    return replaced;
  }
}

class InsertCommand implements Command {
  description: string;

  constructor(
    private editor: TextEditor,
    private text: string,
    private position: number,
  ) {
    this.description = `Insert "${text}" at ${position}`;
  }

  execute(): void {
    this.editor.insert(this.text, this.position);
  }

  undo(): void {
    this.editor.delete(this.position, this.text.length);
  }
}

class DeleteCommand implements Command {
  description: string;
  private deletedText = '';

  constructor(
    private editor: TextEditor,
    private position: number,
    private length: number,
  ) {
    this.description = `Delete ${length} chars at ${position}`;
  }

  execute(): void {
    this.deletedText = this.editor.delete(this.position, this.length);
  }

  undo(): void {
    this.editor.insert(this.deletedText, this.position);
  }
}

class CommandHistory {
  private undoStack: Command[] = [];
  private redoStack: Command[] = [];

  execute(command: Command): void {
    command.execute();
    this.undoStack.push(command);
    this.redoStack = [];
  }

  undo(): Command | undefined {
    const command = this.undoStack.pop();
    if (command) {
      command.undo();
      this.redoStack.push(command);
    }
    return command;
  }

  redo(): Command | undefined {
    const command = this.redoStack.pop();
    if (command) {
      command.execute();
      this.undoStack.push(command);
    }
    return command;
  }

  canUndo(): boolean {
    return this.undoStack.length > 0;
  }

  canRedo(): boolean {
    return this.redoStack.length > 0;
  }
}

const editor = new TextEditor();
const history = new CommandHistory();

history.execute(new InsertCommand(editor, 'Hello', 0));
console.log(editor.getContent());

history.execute(new InsertCommand(editor, ' World', 5));
console.log(editor.getContent());

history.undo();
console.log(editor.getContent());

history.redo();
console.log(editor.getContent());

history.execute(new DeleteCommand(editor, 5, 6));
console.log(editor.getContent());

history.undo();
console.log(editor.getContent());


宏命令
class MacroCommand implements Command {
  description: string;
  private commands: Command[];

  constructor(description: string, commands: Command[]) {
    this.description = description;
    this.commands = commands;
  }

  execute(): void {
    for (const cmd of this.commands) {
      cmd.execute();
    }
  }

  undo(): void {
    for (let i = this.commands.length - 1; i >= 0; i--) {
      this.commands[i].undo();
    }
  }
}

const macro = new MacroCommand('Insert greeting', [
  new InsertCommand(editor, 'Dear ', 0),
  new InsertCommand(editor, 'User', 5),
  new InsertCommand(editor, ',\n', 9),
]);

history.execute(macro);
console.log(editor.getContent());

history.undo();
console.log(editor.getContent());
宏命令将多个命令打包成一个原子操作——执行和撤销时作为一个整体处理。




实际应用：任务队列
interface AsyncCommand {
  execute(): Promise<void>;
  description: string;
}

class TaskQueue {
  private queue: AsyncCommand[] = [];
  private running = false;
  private results: { command: string; success: boolean; error?: string }[] = [];

  enqueue(command: AsyncCommand): void {
    this.queue.push(command);
    if (!this.running) {
      this.process();
    }
  }

  private async process(): Promise<void> {
    this.running = true;
    while (this.queue.length > 0) {
      const command = this.queue.shift()!;
      try {
        console.log(`Executing: ${command.description}`);
        await command.execute();
        this.results.push({ command: command.description, success: true });
      } catch (err) {
        this.results.push({
          command: command.description,
          success: false,
          error: (err as Error).message,
        });
      }
    }
    this.running = false;
  }

  getResults(): typeof this.results {
    return [...this.results];
  }
}

class SendEmailCommand implements AsyncCommand {
  description: string;

  constructor(
    private to: string,
    private subject: string,
  ) {
    this.description = `Send email to ${to}: ${subject}`;
  }

  async execute(): Promise<void> {
    await new Promise((resolve) => setTimeout(resolve, 100));
    console.log(`Email sent to ${this.to}`);
  }
}

const queue = new TaskQueue();
queue.enqueue(new SendEmailCommand('alice@example.com', 'Welcome'));
queue.enqueue(new SendEmailCommand('bob@example.com', 'Update'));


命令模式 vs 策略模式
两者的区别在于意图：命令封装的是"做什么"（操作），策略封装的是"怎么做"（算法）。




常见误区
误区一：每个按钮都用命令模式
简单的 UI 操作直接用回调函数即可。命令模式在需要撤销、排队、日志记录等场景下才有价值。


误区二：Command 中包含过多逻辑
Command 应该是轻量的——它主要负责协调 Receiver 的方法调用，不应该包含大量的业务逻辑。


误区三：忽略 undo 的复杂性
实现可靠的 undo 需要保存足够的状态信息。对于有副作用的操作（如网络请求），undo 可能需要补偿操作而非简单的状态回退。




小结
    

  • 命令模式将请求封装为对象，支持参数化、排队和撤销。
    • 

  • CommandHistory 通过两个栈实现 undo/redo。
    • 

  • 宏命令将多个命令打包为原子操作。
    • 

  • 适用于需要撤销/重做、任务排队、事务管理的场景。
