迭代器与职责链模式

迭代器模式

核心概念

迭代器模式（Iterator Pattern）提供一种方法来顺序访问集合对象中的各个元素，而不暴露该对象的内部表示。在现代 TypeScript 中，迭代器通过 Symbol.iterator 和 for...of 原生支持。

自定义可迭代集合
class Range implements Iterable<number> {
  constructor(
    private start: number,
    private end: number,
    private step: number = 1,
  ) {}

  [Symbol.iterator](): Iterator<number> {
    let current = this.start;
    const end = this.end;
    const step = this.step;

    return {
      next(): IteratorResult<number> {
        if (current <= end) {
          const value = current;
          current += step;
          return { value, done: false };
        }
        return { value: undefined as unknown as number, done: true };
      },
    };
  }
}

for (const n of new Range(1, 10, 2)) {
  console.log(n);
}

const numbers = [...new Range(1, 5)];
console.log(numbers);
Generator 实现
function* fibonacci(): Generator<number> {
  let a = 0;
  let b = 1;
  while (true) {
    yield a;
    [a, b] = [b, a + b];
  }
}

function take<T>(iterator: Iterable<T>, count: number): T[] {
  const result: T[] = [];
  for (const item of iterator) {
    result.push(item);
    if (result.length >= count) break;
  }
  return result;
}

console.log(take(fibonacci(), 10));
树形结构遍历
interface TreeNode<T> {
  value: T;
  children: TreeNode<T>[];
}

function* depthFirst<T>(node: TreeNode<T>): Generator<T> {
  yield node.value;
  for (const child of node.children) {
    yield* depthFirst(child);
  }
}

function* breadthFirst<T>(root: TreeNode<T>): Generator<T> {
  const queue: TreeNode<T>[] = [root];
  while (queue.length > 0) {
    const node = queue.shift()!;
    yield node.value;
    queue.push(...node.children);
  }
}

const tree: TreeNode<string> = {
  value: 'root',
  children: [
    {
      value: 'a',
      children: [
        { value: 'a1', children: [] },
        { value: 'a2', children: [] },
      ],
    },
    {
      value: 'b',
      children: [{ value: 'b1', children: [] }],
    },
  ],
};

console.log('DFS:', [...depthFirst(tree)]);
console.log('BFS:', [...breadthFirst(tree)]);


职责链模式
核心概念
职责链模式（Chain of Responsibility Pattern）让多个对象都有机会处理请求，将这些对象连成一条链，并沿链传递请求，直到有一个对象处理它为止。


实现
interface Request {
  type: string;
  amount?: number;
  priority?: string;
  content?: string;
}

interface Response {
  handled: boolean;
  handler: string;
  message: string;
}

abstract class Handler {
  private next: Handler | null = null;

  setNext(handler: Handler): Handler {
    this.next = handler;
    return handler;
  }

  handle(request: Request): Response {
    if (this.canHandle(request)) {
      return this.process(request);
    }
    if (this.next) {
      return this.next.handle(request);
    }
    return { handled: false, handler: 'none', message: 'No handler found' };
  }

  protected abstract canHandle(request: Request): boolean;
  protected abstract process(request: Request): Response;
}

class SmallExpenseHandler extends Handler {
  protected canHandle(request: Request): boolean {
    return request.type === 'expense' && (request.amount ?? 0) <= 100;
  }

  protected process(request: Request): Response {
    return {
      handled: true,
      handler: 'Team Lead',
      message: `Approved ¥${request.amount} expense`,
    };
  }
}

class MediumExpenseHandler extends Handler {
  protected canHandle(request: Request): boolean {
    return request.type === 'expense' && (request.amount ?? 0) <= 1000;
  }

  protected process(request: Request): Response {
    return {
      handled: true,
      handler: 'Department Manager',
      message: `Approved ¥${request.amount} expense`,
    };
  }
}

class LargeExpenseHandler extends Handler {
  protected canHandle(request: Request): boolean {
    return request.type === 'expense' && (request.amount ?? 0) <= 10000;
  }

  protected process(request: Request): Response {
    return {
      handled: true,
      handler: 'VP',
      message: `Approved ¥${request.amount} expense`,
    };
  }
}

class CEOHandler extends Handler {
  protected canHandle(request: Request): boolean {
    return request.type === 'expense';
  }

  protected process(request: Request): Response {
    return {
      handled: true,
      handler: 'CEO',
      message: `Approved ¥${request.amount} expense (requires board notification)`,
    };
  }
}

const chain = new SmallExpenseHandler();
chain.setNext(new MediumExpenseHandler()).setNext(new LargeExpenseHandler()).setNext(new CEOHandler());

console.log(chain.handle({ type: 'expense', amount: 50 }));
console.log(chain.handle({ type: 'expense', amount: 500 }));
console.log(chain.handle({ type: 'expense', amount: 5000 }));
console.log(chain.handle({ type: 'expense', amount: 50000 }));
函数式职责链
type RequestHandler = (request: Request) => Response | null;

function createChain(...handlers: RequestHandler[]): (request: Request) => Response {
  return (request: Request) => {
    for (const handler of handlers) {
      const result = handler(request);
      if (result) return result;
    }
    return { handled: false, handler: 'none', message: 'No handler found' };
  };
}

const handleSmall: RequestHandler = (req) =>
  req.type === 'expense' && (req.amount ?? 0) <= 100
    ? { handled: true, handler: 'Team Lead', message: `Approved ¥${req.amount}` }
    : null;

const handleMedium: RequestHandler = (req) =>
  req.type === 'expense' && (req.amount ?? 0) <= 1000
    ? { handled: true, handler: 'Manager', message: `Approved ¥${req.amount}` }
    : null;

const processExpense = createChain(handleSmall, handleMedium);
console.log(processExpense({ type: 'expense', amount: 50 }));
console.log(processExpense({ type: 'expense', amount: 500 }));


两种模式的联系
迭代器和职责链看似不同，实际上有共通之处：它们都涉及顺序处理一系列元素。迭代器顺序访问集合元素，职责链顺序传递请求给处理器。在函数式编程中，两者可以统一为对序列的操作。




常见误区
迭代器的误区
无限迭代器没有终止条件：使用无限迭代器（如 fibonacci()）时，必须配合 take 或 break 来限制迭代次数。


职责链的误区
链中没有兜底处理器：如果请求到达链尾仍未被处理，应该有明确的默认行为，而不是静默丢弃。


链过长影响性能：每个请求都可能遍历整条链。如果链很长且大多数请求由前几个处理器处理，考虑优化链的顺序。




小结
    

  • 迭代器模式提供统一的方式遍历集合，TypeScript 原生支持 Symbol.iterator 和 Generator。
    • 

  • 职责链模式让请求沿处理器链传递，适合审批流程、中间件管道等场景。
    • 

  • 两者都可以用函数式方式简洁实现。
    • 

  • 注意迭代器的终止条件和职责链的兜底处理。
