MVC / MVP / MVVM 架构模式对比

核心概念

MVC、MVP、MVVM 是三种经典的 UI 架构模式，它们都旨在分离 UI 展示逻辑与业务逻辑。随着 UI 框架的演进，这三种模式依次出现，每种都是对前一种不足的改进。

MVC（Model-View-Controller）
interface Model {
  data: string[];
  addItem(item: string): void;
  getItems(): string[];
  onChange(callback: () => void): void;
}

class TodoModel implements Model {
  data: string[] = [];
  private listeners: (() => void)[] = [];

  addItem(item: string): void {
    this.data.push(item);
    this.notify();
  }

  removeItem(index: number): void {
    this.data.splice(index, 1);
    this.notify();
  }

  getItems(): string[] {
    return [...this.data];
  }

  onChange(callback: () => void): void {
    this.listeners.push(callback);
  }

  private notify(): void {
    this.listeners.forEach((cb) => cb());
  }
}

class TodoView {
  render(items: string[]): string {
    if (items.length === 0) return '<p>No items</p>';
    const list = items.map((item, i) => `<li>${i + 1}. ${item}</li>`).join('\n');
    return `<ul>\n${list}\n</ul>`;
  }
}

class TodoController {
  constructor(
    private model: TodoModel,
    private view: TodoView,
  ) {
    this.model.onChange(() => this.updateView());
  }

  addItem(item: string): void {
    this.model.addItem(item);
  }

  removeItem(index: number): void {
    this.model.removeItem(index);
  }

  private updateView(): void {
    const html = this.view.render(this.model.getItems());
    console.log(html);
  }
}

const model = new TodoModel();
const view = new TodoView();
const controller = new TodoController(model, view);

controller.addItem('Learn MVC');
controller.addItem('Learn MVP');
controller.addItem('Learn MVVM');
MVC 的特点是 View 可以直接观察 Model 的变化。Controller 处理用户输入并更新 Model，Model 变化后通知 View 重新渲染。




MVP（Model-View-Presenter）
interface TodoViewInterface {
  displayItems(items: string[]): void;
  showError(message: string): void;
  showSuccess(message: string): void;
}

class ConsoleTodoView implements TodoViewInterface {
  displayItems(items: string[]): void {
    console.log('=== Todo List ===');
    items.forEach((item, i) => console.log(`${i + 1}. ${item}`));
  }

  showError(message: string): void {
    console.error(`Error: ${message}`);
  }

  showSuccess(message: string): void {
    console.log(`Success: ${message}`);
  }
}

class TodoPresenter {
  constructor(
    private model: TodoModel,
    private view: TodoViewInterface,
  ) {}

  loadItems(): void {
    const items = this.model.getItems();
    this.view.displayItems(items);
  }

  addItem(item: string): void {
    if (item.trim() === '') {
      this.view.showError('Item cannot be empty');
      return;
    }
    this.model.addItem(item);
    this.view.showSuccess(`Added: ${item}`);
    this.loadItems();
  }

  removeItem(index: number): void {
    const items = this.model.getItems();
    if (index < 0 || index >= items.length) {
      this.view.showError('Invalid index');
      return;
    }
    this.model.removeItem(index);
    this.view.showSuccess('Item removed');
    this.loadItems();
  }
}

const mvpModel = new TodoModel();
const mvpView = new ConsoleTodoView();
const presenter = new TodoPresenter(mvpModel, mvpView);

presenter.addItem('Learn design patterns');
presenter.addItem('Build a project');
presenter.addItem('');
MVP 的关键改进：View 和 Model 完全隔离，所有交互通过 Presenter 中转。View 通过接口定义，可以方便地替换和测试。




MVVM（Model-View-ViewModel）
type Subscriber<T> = (value: T) => void;

class Observable<T> {
  private value: T;
  private subscribers = new Set<Subscriber<T>>();

  constructor(initialValue: T) {
    this.value = initialValue;
  }

  get(): T {
    return this.value;
  }

  set(newValue: T): void {
    if (this.value !== newValue) {
      this.value = newValue;
      this.notify();
    }
  }

  subscribe(subscriber: Subscriber<T>): () => void {
    this.subscribers.add(subscriber);
    subscriber(this.value);
    return () => this.subscribers.delete(subscriber);
  }

  private notify(): void {
    this.subscribers.forEach((sub) => sub(this.value));
  }
}

class Computed<T> {
  private observable: Observable<T>;
  private disposers: (() => void)[] = [];

  constructor(compute: () => T, deps: Observable<unknown>[]) {
    this.observable = new Observable<T>(compute());
    for (const dep of deps) {
      this.disposers.push(
        dep.subscribe(() => {
          this.observable.set(compute());
        }),
      );
    }
  }

  get(): T {
    return this.observable.get();
  }

  subscribe(subscriber: Subscriber<T>): () => void {
    return this.observable.subscribe(subscriber);
  }

  dispose(): void {
    this.disposers.forEach((d) => d());
  }
}

class TodoViewModel {
  readonly items = new Observable<string[]>([]);
  readonly newItemText = new Observable('');
  readonly itemCount: Computed<number>;
  readonly isEmpty: Computed<boolean>;

  constructor() {
    this.itemCount = new Computed(() => this.items.get().length, [this.items]);
    this.isEmpty = new Computed(() => this.items.get().length === 0, [this.items]);
  }

  addItem(): void {
    const text = this.newItemText.get().trim();
    if (!text) return;
    this.items.set([...this.items.get(), text]);
    this.newItemText.set('');
  }

  removeItem(index: number): void {
    const current = this.items.get();
    this.items.set(current.filter((_, i) => i !== index));
  }
}

const vm = new TodoViewModel();

vm.items.subscribe((items) => {
  console.log('View update - Items:', items);
});

vm.itemCount.subscribe((count) => {
  console.log('View update - Count:', count);
});

vm.newItemText.set('Learn MVVM');
vm.addItem();

vm.newItemText.set('Practice patterns');
vm.addItem();
MVVM 的核心是数据绑定——ViewModel 暴露可观察的数据，View 订阅这些数据自动更新。这正是 React、Vue、Angular 等现代框架的底层思想。

常见误区
误区一：三种模式非此即彼
实际项目中经常混用。例如 React 本质上更接近"View = f(State)"而非严格的 MVVM，但 React + 状态管理的组合体现了 MVVM 的思想。


误区二：MVVM 一定优于 MVC
每种模式有其适用场景。简单页面用 MVC 足够，复杂的交互式应用才需要 MVVM 的数据绑定能力。


误区三：Controller/Presenter/ViewModel 应该很薄
中介者的厚薄取决于业务复杂度。关键是不要把视图渲染逻辑放在中介者中。




小结
    

  • MVC 通过 Controller 协调，View 可直接观察 Model。
    • 

  • MVP 通过 Presenter 中转，View 和 Model 完全隔离。
    • 

  • MVVM 通过数据绑定自动同步 ViewModel 和 View。
    • 

  • 现代前端框架的核心思想与 MVVM 最为接近。
