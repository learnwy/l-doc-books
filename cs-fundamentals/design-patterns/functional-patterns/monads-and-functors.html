Monad 与 Functor

核心概念

Functor 和 Monad 是函数式编程中描述"计算容器"的抽象。它们定义了如何在不直接操作内部值的情况下对容器中的值进行转换和组合。虽然这些概念源自范畴论，但在实际 TypeScript 开发中，它们以 map、flatMap、Optional、Result 等形式广泛存在。

Functor
Functor 是任何实现了 map 方法的容器——Array 就是最常见的 Functor：


interface Functor<T> {
  map<R>(fn: (value: T) => R): Functor<R>;
}

class Box<T> implements Functor<T> {
  constructor(private value: T) {}

  map<R>(fn: (value: T) => R): Box<R> {
    return new Box(fn(this.value));
  }

  getValue(): T {
    return this.value;
  }
}

const result = new Box(5)
  .map((n) => n * 2)
  .map((n) => n + 1)
  .map((n) => `Result: ${n}`)
  .getValue();

console.log(result);
Functor 的规则：


    

  1. 恒等律：box.map(x => x) 等价于 box
    2. 

  2. 组合律：box.map(f).map(g) 等价于 box.map(x => g(f(x)))

Maybe Monad
Maybe 处理可能为空的值，消除 null/undefined 检查：


class Maybe<T> {
  private constructor(private value: T | null) {}

  static of<T>(value: T): Maybe<T> {
    return new Maybe(value);
  }

  static none<T>(): Maybe<T> {
    return new Maybe<T>(null);
  }

  static fromNullable<T>(value: T | null | undefined): Maybe<T> {
    return value == null ? Maybe.none<T>() : Maybe.of(value);
  }

  isPresent(): boolean {
    return this.value !== null;
  }

  map<R>(fn: (value: T) => R): Maybe<R> {
    if (this.value === null) return Maybe.none<R>();
    return Maybe.of(fn(this.value));
  }

  flatMap<R>(fn: (value: T) => Maybe<R>): Maybe<R> {
    if (this.value === null) return Maybe.none<R>();
    return fn(this.value);
  }

  getOrElse(defaultValue: T): T {
    return this.value ?? defaultValue;
  }

  match<R>(handlers: { some: (value: T) => R; none: () => R }): R {
    return this.value !== null ? handlers.some(this.value) : handlers.none();
  }
}

interface UserProfile {
  name: string;
  address?: {
    city?: string;
    zip?: string;
  };
}

function getUserCity(profile: UserProfile | null): string {
  return Maybe.fromNullable(profile)
    .flatMap((p) => Maybe.fromNullable(p.address))
    .flatMap((a) => Maybe.fromNullable(a.city))
    .getOrElse('Unknown');
}

console.log(getUserCity({ name: 'Alice', address: { city: 'Shanghai' } }));
console.log(getUserCity({ name: 'Bob' }));
console.log(getUserCity(null));


Result Monad（Either）
Result 处理可能失败的操作，是异常处理的函数式替代：


class Result<T, E = Error> {
  private constructor(
    private readonly value: T | null,
    private readonly error: E | null,
  ) {}

  static ok<T, E = Error>(value: T): Result<T, E> {
    return new Result<T, E>(value, null);
  }

  static err<T, E = Error>(error: E): Result<T, E> {
    return new Result<T, E>(null, error);
  }

  isOk(): boolean {
    return this.error === null;
  }

  isErr(): boolean {
    return this.error !== null;
  }

  map<R>(fn: (value: T) => R): Result<R, E> {
    if (this.error !== null) return Result.err<R, E>(this.error);
    return Result.ok(fn(this.value!));
  }

  flatMap<R>(fn: (value: T) => Result<R, E>): Result<R, E> {
    if (this.error !== null) return Result.err<R, E>(this.error);
    return fn(this.value!);
  }

  mapErr<F>(fn: (error: E) => F): Result<T, F> {
    if (this.error === null) return Result.ok<T, F>(this.value!);
    return Result.err<T, F>(fn(this.error));
  }

  match<R>(handlers: { ok: (value: T) => R; err: (error: E) => R }): R {
    return this.error === null ? handlers.ok(this.value!) : handlers.err(this.error);
  }

  unwrap(): T {
    if (this.error !== null) throw this.error;
    return this.value!;
  }

  unwrapOr(defaultValue: T): T {
    return this.error === null ? this.value! : defaultValue;
  }
}

function parseJSON<T>(json: string): Result<T, Error> {
  try {
    return Result.ok(JSON.parse(json));
  } catch (e) {
    return Result.err(e as Error);
  }
}

function validateAge(data: { age?: number }): Result<number, string> {
  if (data.age === undefined) return Result.err('Age is required');
  if (data.age < 0 || data.age > 150) return Result.err('Invalid age range');
  return Result.ok(data.age);
}

const result2 = parseJSON<{ age: number }>('{"age": 25}')
  .mapErr((e) => e.message)
  .flatMap((data) => validateAge(data))
  .map((age) => `Valid age: ${age}`);

result2.match({
  ok: (msg) => console.log(msg),
  err: (error) => console.error(`Error: ${error}`),
});


链式操作实践
interface ApiResponse<T> {
  data?: T;
  error?: string;
}

function fetchUser(id: string): Result<{ name: string; email: string }, string> {
  if (id === '1') return Result.ok({ name: 'Alice', email: 'alice@example.com' });
  return Result.err(`User ${id} not found`);
}

function fetchOrders(email: string): Result<{ orderId: string; amount: number }[], string> {
  if (email === 'alice@example.com') {
    return Result.ok([
      { orderId: 'ORD-001', amount: 99 },
      { orderId: 'ORD-002', amount: 199 },
    ]);
  }
  return Result.err('No orders found');
}

function calculateTotal(orders: { amount: number }[]): Result<number, string> {
  const total = orders.reduce((sum, o) => sum + o.amount, 0);
  return total > 0 ? Result.ok(total) : Result.err('Empty order list');
}

const summary = fetchUser('1')
  .flatMap((user) => fetchOrders(user.email))
  .flatMap((orders) => calculateTotal(orders))
  .map((total) => `Total spending: ¥${total}`);

summary.match({
  ok: (msg) => console.log(msg),
  err: (error) => console.error(error),
});
链式调用中，任何一步返回 Err，后续步骤都会被跳过——这就像 Railway Oriented Programming（铁路编程）。

JavaScript 的 Promise 本身就是一个 Monad——.then() 既是 map 也是 flatMap。Array 既是 Functor（map）也是 Monad（flatMap）。




常见误区
误区一：Monad 是难以理解的数学概念
在实际编程中，Monad 就是一个带有 map 和 flatMap 的容器。你可能已经在用了——Promise.then 就是 flatMap。


误区二：必须用类来实现 Monad
函数和对象字面量同样可以实现 Monad 的行为。重要的是模式（map/flatMap），而非具体实现形式。


误区三：Result 类型可以完全替代异常
Result 适合预期内的错误（如验证失败、资源不存在）。对于真正的程序错误（如内存不足、bug），异常仍然是合适的机制。




小结
    

  • Functor 通过 map 对容器内的值进行转换。
    • 

  • Monad 通过 flatMap 链式组合可能失败的计算。
    • 

  • Maybe 消除 null/undefined 检查，Result 提供类型安全的错误处理。
    • 

  • JavaScript 的 Promise 和 Array 本身就是 Monad。
