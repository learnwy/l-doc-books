函数式模式 简介

函数式编程不仅是一种范式，更是一套经过数十年数学验证的设计模式。在现代 TypeScript 开发中，函数式模式与传统 OOP 模式互为补充——很多场景下，函数式方案比类层次结构更简洁、更安全、更易组合。本章介绍函数式编程中最核心的三组模式。

第一节"高阶函数与闭包"是函数式编程的基础。高阶函数（接受函数作为参数或返回函数的函数）让你可以用函数来参数化行为，这正是策略模式、装饰器模式的函数式等价物。闭包则让函数能够"记住"创建时的环境，提供了封装状态的轻量替代方案。你将学习柯里化、偏应用、函数组合等核心技巧。

第二节"不可变性与纯函数"探讨数据管理的最佳实践。不可变数据结构消除了状态共享带来的一切副作用问题，纯函数（相同输入总是产生相同输出且无副作用）让代码极易测试和推理。你将学习如何在 TypeScript 中实现深度不可变性、结构共享，以及用纯函数替代有状态的面向对象设计。

第三节"Monad 与 Functor"将抽象提升到一个新的层次。Functor 提供了对容器中值进行映射的统一接口，Monad 则处理计算的链式组合——尤其擅长处理可能失败、可能为空、或有副作用的场景。你将用 TypeScript 实现 Maybe、Result（Either）等实用的 Monad 类型。

三节内容从基础工具到数据哲学再到高级抽象，构成完整的函数式模式知识体系。
