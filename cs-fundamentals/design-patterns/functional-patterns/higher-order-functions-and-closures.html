高阶函数与闭包

核心概念

高阶函数（Higher-Order Function）是接受函数作为参数或返回函数的函数。闭包（Closure）是函数能够访问其创建时作用域中变量的能力。这两个概念是函数式编程的基石，也是理解 TypeScript 中许多高级模式的关键。



高阶函数基础
函数作为参数
function transform<T, R>(items: T[], fn: (item: T, index: number) => R): R[] {
  const result: R[] = [];
  for (let i = 0; i < items.length; i++) {
    result.push(fn(items[i], i));
  }
  return result;
}

const numbers = [1, 2, 3, 4, 5];
const doubled = transform(numbers, (n) => n * 2);
const strings = transform(numbers, (n, i) => `${i}: ${n}`);

console.log(doubled);
console.log(strings);
函数作为返回值
function multiplier(factor: number): (n: number) => number {
  return (n) => n * factor;
}

const double = multiplier(2);
const triple = multiplier(3);

console.log(double(5));
console.log(triple(5));
console.log([1, 2, 3].map(double));
multiplier 返回一个新函数，这个新函数通过闭包"记住"了 factor 的值。




闭包
闭包让函数可以捕获并保持对创建时作用域变量的引用：


function createCounter(initial = 0) {
  let count = initial;

  return {
    increment: () => ++count,
    decrement: () => --count,
    getCount: () => count,
    reset: () => {
      count = initial;
    },
  };
}

const counter = createCounter(10);
console.log(counter.increment());
console.log(counter.increment());
console.log(counter.decrement());
console.log(counter.getCount());
counter.reset();
console.log(counter.getCount());
闭包是实现数据封装的轻量替代方案——无需类也能实现私有状态。


闭包实现记忆化
function memoize<Args extends unknown[], R>(fn: (...args: Args) => R): (...args: Args) => R {
  const cache = new Map<string, R>();

  return (...args: Args): R => {
    const key = JSON.stringify(args);
    if (cache.has(key)) {
      return cache.get(key)!;
    }
    const result = fn(...args);
    cache.set(key, result);
    return result;
  };
}

const expensiveCalculation = memoize((n: number): number => {
  console.log(`Computing fib(${n})...`);
  if (n <= 1) return n;
  return expensiveCalculation(n - 1) + expensiveCalculation(n - 2);
});

console.log(expensiveCalculation(10));
console.log(expensiveCalculation(10));


柯里化
柯里化（Currying）将多参数函数转换为一系列单参数函数：


function curry<A, B, C>(fn: (a: A, b: B) => C): (a: A) => (b: B) => C {
  return (a: A) => (b: B) => fn(a, b);
}

const add = (a: number, b: number): number => a + b;
const curriedAdd = curry(add);

const add5 = curriedAdd(5);
console.log(add5(3));
console.log(add5(10));

const formatDate = curry((locale: string, date: Date): string => date.toLocaleDateString(locale));

const formatCN = formatDate('zh-CN');
const formatUS = formatDate('en-US');

console.log(formatCN(new Date()));
console.log(formatUS(new Date()));
柯里化的价值在于"预填参数"——创建部分应用的专用函数。




函数组合
type Fn<A, B> = (a: A) => B;

function pipe<A, B>(fn1: Fn<A, B>): Fn<A, B>;
function pipe<A, B, C>(fn1: Fn<A, B>, fn2: Fn<B, C>): Fn<A, C>;
function pipe<A, B, C, D>(fn1: Fn<A, B>, fn2: Fn<B, C>, fn3: Fn<C, D>): Fn<A, D>;
function pipe(...fns: Fn<unknown, unknown>[]): Fn<unknown, unknown> {
  return (input: unknown) => fns.reduce((acc, fn) => fn(acc), input);
}

const processString = pipe(
  (s: string) => s.trim(),
  (s: string) => s.toLowerCase(),
  (s: string) => s.replace(/\s+/g, '-'),
);

console.log(processString('  Hello World  '));
console.log(processString('  TypeScript Design Patterns  '));
function compose<A, B, C>(f: Fn<B, C>, g: Fn<A, B>): Fn<A, C> {
  return (a: A) => f(g(a));
}

const toSlug = compose(
  (s: string) => s.replace(/\s+/g, '-'),
  (s: string) => s.toLowerCase(),
);

console.log(toSlug('Design Patterns Guide'));
pipe 从左到右执行，compose 从右到左执行。pipe 更符合阅读直觉。




实际应用：中间件管道
type Middleware<T> = (data: T, next: () => T) => T;

function createPipeline<T>(...middlewares: Middleware<T>[]): (initial: T) => T {
  return (initial: T) => {
    let index = 0;

    function dispatch(): T {
      if (index >= middlewares.length) {
        return initial;
      }
      const middleware = middlewares[index++];
      return middleware(initial, dispatch);
    }

    return dispatch();
  };
}

type RequestContext = {
  path: string;
  method: string;
  headers: Record<string, string>;
  body: string;
};

const addTimestamp: Middleware<RequestContext> = (ctx, next) => {
  ctx.headers['X-Timestamp'] = new Date().toISOString();
  return next();
};

const addRequestId: Middleware<RequestContext> = (ctx, next) => {
  ctx.headers['X-Request-Id'] = Math.random().toString(36).slice(2);
  return next();
};

const pipeline = createPipeline(addTimestamp, addRequestId);

const result = pipeline({
  path: '/api/users',
  method: 'GET',
  headers: {},
  body: '',
});

console.log(result.headers);

常见误区
误区一：闭包必然导致内存泄漏
闭包只是函数引用了外部变量。只要闭包本身被正确释放（如取消订阅），被捕获的变量也会被垃圾回收。


误区二：柯里化在任何场景都优于多参数函数
柯里化在需要部分应用时有价值。如果函数总是被全部参数调用，柯里化反而降低可读性。


误区三：函数组合总比命令式代码好
对于简单的顺序操作，pipe 很优雅。但如果中间需要条件分支或错误处理，命令式代码可能更清晰。




小结
    

  • 高阶函数是函数式编程的基础，让函数可以参数化和组合。
    • 

  • 闭包提供了轻量的状态封装机制。
    • 

  • 柯里化和函数组合是构建复杂逻辑的核心工具。
    • 

  • 很多 OOP 设计模式在函数式中有更简洁的等价实现。
