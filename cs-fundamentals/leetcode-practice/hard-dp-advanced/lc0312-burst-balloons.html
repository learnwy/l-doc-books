LeetCode 312 戳气球

题目描述

有 n 个气球，编号为 0 到 n-1，每个气球上都标有一个数字，存在数组 nums 中。现在要求你戳破所有的气球。戳破第 i 个气球，可以获得 nums[i-1] × nums[i] × nums[i+1] 枚硬币。这里的 i-1 和 i+1 代表和 i 相邻的两个气球的序号。如果 i-1 或 i+1 超出了数组的边界，那么就当它是一个数字为 1 的气球。

求所能获得硬币的最大数量。

约束条件：

  • n == nums.length
  • 1 <= n <= 300
  • 0 <= nums[i] <= 100

示例 1：

输入：nums = [3,1,5,8]
输出：167
解释：
nums = [3,1,5,8] → [3,5,8] → [3,8] → [8] → []
硬币 = 3×1×5 + 3×5×8 + 1×3×8 + 1×8×1 = 15+120+24+8 = 167

示例 2：

输入：nums = [1,5]
输出：10

解题思路

本题是区间 DP 的经典代表题目。关键难点在于：戳破一个气球后，它的邻居会发生变化，导致正向思考非常复杂。

逆向思维： 不要考虑先戳哪个气球，而是考虑最后戳哪个气球。在区间 (i, j) 内，假设最后戳破的是气球 k。此时 k 的左右邻居恰好是 i 和 j（区间内其他气球都已被戳破），因此获得的硬币为 nums[i] × nums[k] × nums[j]。

状态定义： 为了处理边界，在 nums 前后各添加一个值为 1 的虚拟气球。设 dp[i][j] 表示戳破开区间 (i, j) 内所有气球能获得的最大硬币数。

状态转移： 枚举最后戳破的气球 k（i < k < j）：

dp[i][j] = max(dp[i][k] + dp[k][j] + nums[i] × nums[k] × nums[j])  对所有 i < k < j

解读：

  • dp[i][k]：戳破 (i, k) 内的气球获得的最大硬币
  • dp[k][j]：戳破 (k, j) 内的气球获得的最大硬币
  • nums[i] × nums[k] × nums[j]：最后戳破 k 获得的硬币
遍历顺序： 区间长度从小到大（先算短区间，再算长区间）。这保证了计算 dp[i][j] 时，所有更短的区间已经计算完毕。

代码实现
区间 DP（自底向上）：


function maxCoins(nums: number[]): number {
  const n = nums.length;
  const val = [1, ...nums, 1];
  const dp: number[][] = Array.from({ length: n + 2 }, () => new Array(n + 2).fill(0));

  for (let len = 2; len <= n + 1; len++) {
    for (let i = 0; i + len <= n + 1; i++) {
      const j = i + len;
      for (let k = i + 1; k < j; k++) {
        dp[i][j] = Math.max(dp[i][j], dp[i][k] + dp[k][j] + val[i] * val[k] * val[j]);
      }
    }
  }

  return dp[0][n + 1];
}
记忆化递归：


function maxCoinsMemo(nums: number[]): number {
  const n = nums.length;
  const val = [1, ...nums, 1];
  const memo: number[][] = Array.from({ length: n + 2 }, () => new Array(n + 2).fill(-1));

  const solve = (i: number, j: number): number => {
    if (j - i < 2) return 0;
    if (memo[i][j] !== -1) return memo[i][j];

    let best = 0;
    for (let k = i + 1; k < j; k++) {
      best = Math.max(best, solve(i, k) + solve(k, j) + val[i] * val[k] * val[j]);
    }

    memo[i][j] = best;
    return best;
  };

  return solve(0, n + 1);
}
逆向思维的精髓：


为什么要考虑"最后戳破"而非"最先戳破"？因为最先戳破某个气球后，它的邻居会合并，后续的状态非常难以描述。而"最后戳破"的好处是：在开区间 (i, j) 中最后戳破 k 时，k 的邻居确定为 i 和 j（两端未被戳破的边界气球），状态转移变得清晰。


这种"逆向思考"的技巧在区间 DP 中非常常见。类似的思路还出现在矩阵链乘法、石子合并等经典问题中。


示例演算（nums = [3,1,5,8]，扩展为 val = [1,3,1,5,8,1]）：


dp[0][2] = 1×3×1 = 3         (只有气球 3)
dp[1][3] = 3×1×5 = 15        (只有气球 1)
dp[2][4] = 1×5×8 = 40        (只有气球 5)
dp[3][5] = 5×8×1 = 40        (只有气球 8)
dp[0][3] = max(dp[0][1]+dp[1][3]+1×3×5, dp[0][2]+dp[2][3]+1×1×5)
         = max(0+15+15, 3+0+5) = 30
...最终 dp[0][5] = 167

时间复杂度详解： 区间数为 O(n²)，每个区间枚举分割点 O(n)，总计 O(n³)。n ≤ 300 时约 2700 万次操作，需要常数因子够小才能通过。


空间复杂度详解： DP 表格为 (n+2) × (n+2) 的二维数组，O(n²)。


区间 DP 的通用范式： 本题体现了区间 DP 的标准模板——枚举区间长度、枚举区间起点、枚举分割点。这个三重循环结构是区间 DP 的核心骨架，掌握后可以迁移到合并石堆、最优三角剖分、矩阵链乘法等同类问题。
