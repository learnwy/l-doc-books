LeetCode 213 打家劫舍 II

题目描述

你是一个专业的小偷，计划偷窃沿街的房屋，每间房内都藏有一定的现金。这个地方所有的房屋都围成一圈，这意味着第一个房屋和最后一个房屋是紧挨着的。同时，相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。

给定一个代表每个房屋存放金额的非负整数数组，计算你在不触动警报装置的情况下，今晚能够偷窃到的最高金额。

约束条件：

  • 1 ≤ nums.length ≤ 100
  • 0 ≤ nums[i] ≤ 1000

示例 1：

输入：nums = [2,3,2] 输出：3 解释：不能偷窃 1 号和 3 号房屋（它们相邻，因为围成一圈），所以偷窃 2 号房屋（金额 = 3）。

示例 2：

输入：nums = [1,2,3,1] 输出：4 解释：偷窃 1 号房屋（金额 = 1），然后偷窃 3 号房屋（金额 = 3），总金额 = 1 + 3 = 4。

示例 3：

输入：nums = [1,2,3] 输出：3

解题思路

本题是 LC #198（打家劫舍）的环形变体。房屋排成一个环，第一间和最后一间相邻，因此不能同时偷窃。

关键洞察：环形约束意味着第一间和最后一间不能同时选择。因此可以将问题分解为两个线性子问题：

  1. 子问题 A：考虑 nums[0..n-2]（可能偷第一间，不考虑最后一间）
  2. 子问题 B：考虑 nums[1..n-1]（不考虑第一间，可能偷最后一间）

两个子问题都是标准的 LC #198，取两者的较大值即为最终答案。

正确性证明：对于最优解，要么不包含第一间房（对应子问题 B），要么不包含最后一间房（对应子问题 A），不可能两者都包含。因此两个子问题覆盖了所有可能的最优解。

方法 时间复杂度 空间复杂度 思路
暴力枚举 O(2ⁿ) O(n) 枚举所有合法子集
两次线性 DP O(n) O(1) 分解为两个 LC #198

代码实现

function rob(nums: number[]): number {
  if (nums.length === 1) return nums[0];
  if (nums.length === 2) return Math.max(nums[0], nums[1]);

  const robRange = (start: number, end: number): number => {
    let prev2 = 0;
    let prev1 = 0;

    for (let i = start; i <= end; i++) {
      const current = Math.max(prev1, prev2 + nums[i]);
      prev2 = prev1;
      prev1 = current;
    }

    return prev1;
  };

  return Math.max(robRange(0, nums.length - 2), robRange(1, nums.length - 1));
}

代码逻辑详解：

robRange(start, end) 是 LC #198 的标准解法，在指定范围内做线性 DP。主函数调用两次：

  • robRange(0, n-2)：从第 0 间到第 n-2 间（排除最后一间）
  • robRange(1, n-1)：从第 1 间到第 n-1 间（排除第一间）

取两者最大值。每次调用使用滚动变量，空间 O(1)。

边界处理：

  • 只有 1 间房：直接返回该金额
  • 只有 2 间房：返回较大值（由于相邻不能都偷）

模拟执行（nums = [1,2,3,1]）：

子问题 A（nums[0..2] = [1,2,3]）：

  • num=1: current=max(0,0+1)=1, prev2=0, prev1=1
  • num=2: current=max(1,0+2)=2, prev2=1, prev1=2
  • num=3: current=max(2,1+3)=4, prev2=2, prev1=4
  • 结果：4

子问题 B（nums[1..3] = [2,3,1]）：

  • num=2: current=max(0,0+2)=2, prev2=0, prev1=2
  • num=3: current=max(2,0+3)=3, prev2=2, prev1=3
  • num=1: current=max(3,2+1)=3, prev2=3, prev1=3
  • 结果：3

最终答案：max(4, 3) = 4

与 LC #198 的关系：

维度 LC #198 (线性) LC #213 (环形)
结构 线性数组 环形数组
约束 相邻不能同时选 首尾也不能同时选
解法 一次线性 DP 两次线性 DP 取 max
核心思路 dp[i] = max(dp[i-1], dp[i-2]+nums[i]) 拆环为链

复杂度分析

维度 复杂度 说明
时间复杂度 O(n) 两次线性遍历，总共 2n 次操作
空间复杂度 O(1) 滚动变量，无额外数组

"拆环为链"是处理环形 DP 的通用技巧：将长度为 n 的环形问题拆成两个长度为 n-1 的线性问题。这一技巧在 LC #918（环形子数组的最大和）中也有应用。掌握这个模式后，遇到环形约束的问题都可以先考虑"固定首或尾，拆成线性子问题"。
