LeetCode 31 下一个排列

题目描述

整数数组的一个排列就是将其所有成员以序列或线性顺序排列。例如，arr = [1, 2, 3] 的下一个排列是 [1, 3, 2]。

实现获取下一个排列的函数，算法需要将给定数字序列重新排列成字典序中下一个更大的排列（即，组合出下一个更大的整数）。如果不存在下一个更大的排列，则将数字重新排列成最小的排列（即升序排列）。

必须原地修改，只允许使用额外常数空间。

约束条件：

  • 1 <= nums.length <= 100
  • 0 <= nums[i] <= 100

示例 1：

输入：nums = [1, 2, 3]
输出：[1, 3, 2]

示例 2：

输入：nums = [3, 2, 1]
输出：[1, 2, 3]

示例 3：

输入：nums = [1, 1, 5]
输出：[1, 5, 1]

下一个排列是一个经典的组合数学问题，其解法蕴含着深刻的字典序思想。理解这个算法不仅能解决本题，还能帮助你处理全排列生成、字典序第 K 大等相关问题。

解题思路

字典序的直觉

想象把数组看作一个多位数字。「下一个排列」就是找到比当前数字大的最小数字。例如：

  • 123 的下一个是 132
  • 321 已经是最大的，下一个回到 123（最小排列）
  • 115 的下一个是 151

三步法

  1. 从右往左找到第一个下降的位置 i：即 nums[i] < nums[i+1]。位置 i 右边的部分是降序排列的（已经是该子序列的最大排列）

  2. 从右往左找到第一个大于 nums[i] 的位置 j：在降序序列中，从右找到刚好大于 nums[i] 的元素

  3. 交换 nums[i] 和 nums[j]，然后反转 i+1 到末尾的部分：交换后，i+1 到末尾仍然是降序的，反转使其变为升序（最小排列）

步骤 操作 目的
找下降点 从右到左找 nums[i] < nums[i+1] 定位需要改变的最低位
找交换对象 从右到左找第一个 > nums[i] 的元素 找到最小的增量
交换 + 反转 swap(i, j) + reverse(i+1, end) 确保后缀最小

为什么这个算法是正确的

步骤 1 找到的 i 是最右边的「可以增大」的位置。i 右边已经是最大排列，无法再增大。步骤 2 找到的 j 是右边部分中刚好大于 nums[i] 的数，保证增量最小。交换后反转使后缀变为最小排列，从而得到恰好比当前大一步的排列。

特殊情况

如果整个数组是降序的（步骤 1 找不到下降点），说明当前是最大排列，直接反转整个数组即可得到最小排列。

代码实现

function nextPermutation(nums: number[]): void {
  const n = nums.length;
  let i = n - 2;

  while (i >= 0 && nums[i] >= nums[i + 1]) {
    i--;
  }

  if (i >= 0) {
    let j = n - 1;
    while (j > i && nums[j] <= nums[i]) {
      j--;
    }
    [nums[i], nums[j]] = [nums[j], nums[i]];
  }

  let left = i + 1;
  let right = n - 1;
  while (left < right) {
    [nums[left], nums[right]] = [nums[right], nums[left]];
    left++;
    right--;
  }
}

执行过程示例：

以 nums = [1, 5, 8, 4, 7, 6, 5, 3, 1] 为例：

步骤 1： 从右往左找第一个下降点

  • 比较 3 和 1：3 > 1，继续
  • 比较 5 和 3：5 > 3，继续
  • 比较 6 和 5：6 > 5，继续
  • 比较 7 和 6：7 > 6，继续
  • 比较 4 和 7：4 < 7 → 找到 i = 3，nums[3] = 4

步骤 2： 从右往左找第一个大于 4 的数

  • nums[8] = 1：1 ≤ 4，继续
  • nums[7] = 3：3 ≤ 4，继续
  • nums[6] = 5：5 > 4 → 找到 j = 6

步骤 3： 交换 nums[3] 和 nums[6]

  • 交换前：[1, 5, 8, 4, 7, 6, 5, 3, 1]
  • 交换后：[1, 5, 8, 5, 7, 6, 4, 3, 1]

步骤 4： 反转 i+1 到末尾（索引 4 到 8）

  • 反转前：[7, 6, 4, 3, 1]
  • 反转后：[1, 3, 4, 6, 7]
  • 最终结果：[1, 5, 8, 5, 1, 3, 4, 6, 7]
阶段 数组状态
原始 [1, 5, 8, 4, 7, 6, 5, 3, 1]
交换后 [1, 5, 8, 5, 7, 6, 4, 3, 1]
反转后 [1, 5, 8, 5, 1, 3, 4, 6, 7]

复杂度分析

维度 复杂度 说明
时间复杂度 O(n) 最多遍历数组三次
空间复杂度 O(1) 原地修改，只用常数空间

时间复杂度分析： 步骤 1 从右到左扫描一次（最多 n 步），步骤 2 从右到左扫描一次（最多 n 步），步骤 3 反转最多 n/2 次交换。总时间为 O(n)。

空间复杂度分析： 所有操作都在原数组上进行，只使用了 i、j、left、right 等常数个变量，空间为 O(1)。

与全排列的关系： 如果从最小排列开始，反复调用 nextPermutation，可以按字典序生成所有排列。这正是 C++ STL 中 std::next_permutation 的实现原理。理解这个算法还有助于解决 LC #60（排列序列）——给定 n 和 k，找到第 k 个排列。
