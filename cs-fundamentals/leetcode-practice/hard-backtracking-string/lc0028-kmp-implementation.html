LeetCode 28 KMP 字符串匹配

题目描述

给定两个字符串 haystack 和 needle，在 haystack 中找出 needle 第一次出现的位置（下标从 0 开始）。如果 needle 不是 haystack 的一部分，返回 -1。

示例：

输入：haystack = "sadbutsad", needle = "sad"
输出：0
解释："sad" 在下标 0 和 6 处出现，第一个出现的位置是 0

输入：haystack = "leetcode", needle = "leeto"
输出：-1
解释："leeto" 没有出现在 "leetcode" 中

约束条件：

  • 1 <= haystack.length, needle.length <= 10⁴
  • haystack 和 needle 仅由小写英文字母组成

解题思路

字符串匹配是计算机科学中最基础的问题之一。暴力方法在最坏情况下性能极差，而 KMP 算法通过预处理模式串，实现线性时间匹配。

暴力方法： 对于 haystack 中的每个位置 i，尝试将 needle 逐字符匹配。匹配失败时，i 前进一位，needle 从头开始。最坏情况下（如 haystack="aaaa...ab", needle="aaa...ab"），时间复杂度为 O(m×n)。

KMP 的核心洞察： 匹配失败时，已匹配的部分包含有价值的信息——模式串中可能存在前缀和后缀的重叠，利用这个信息可以跳过不必要的比较。

KMP 算法分两个阶段：

  1. 构建失败函数（next 数组）： next[i] 表示模式串 needle[0..i] 中，最长的相等的真前缀和真后缀的长度。
  2. 匹配阶段： 使用 next 数组在失配时跳转，避免回退主串指针。
算法 时间复杂度 空间复杂度 核心思想
暴力匹配 O(m×n) O(1) 逐位尝试，失配后主串回退
KMP O(m+n) O(n) 预处理 next 数组，主串不回退
Rabin-Karp O(m+n) 期望 O(1) 滚动哈希，冲突时逐字符验证
Boyer-Moore O(m/n) 最优 O(σ) 从后向前匹配，坏字符/好后缀跳转

其中 m 为 haystack 长度，n 为 needle 长度，σ 为字符集大小。

next 数组构建的直觉理解： 考虑模式串 "ABCABD"，next 数组为 [0,0,0,1,2,0]。next[4]=2 表示前缀 "ABCAB" 中，最长的相等前后缀是 "AB"（长度 2）。这意味着当匹配到第 5 个字符失配时，可以直接将模式串跳到第 2 个位置继续匹配，因为前 2 个字符 "AB" 已经与主串对齐。

代码实现

function strStr(haystack: string, needle: string): number {
  const m = haystack.length;
  const n = needle.length;

  if (n === 0) return 0;

  const next = buildNext(needle);

  let j = 0;
  for (let i = 0; i < m; i++) {
    while (j > 0 && haystack[i] !== needle[j]) {
      j = next[j - 1];
    }
    if (haystack[i] === needle[j]) {
      j++;
    }
    if (j === n) {
      return i - n + 1;
    }
  }

  return -1;
}

function buildNext(pattern: string): number[] {
  const n = pattern.length;
  const next: number[] = [0];

  let len = 0;
  let i = 1;

  while (i < n) {
    if (pattern[i] === pattern[len]) {
      len++;
      next[i] = len;
      i++;
    } else if (len > 0) {
      len = next[len - 1];
    } else {
      next[i] = 0;
      i++;
    }
  }

  return next;
}

buildNext 函数的逐步解析：

  • len 追踪当前最长相等前后缀的长度，初始为 0。
  • 当 pattern[i] === pattern[len] 时，前后缀可以扩展，len++，记录 next[i] = len。
  • 当不匹配且 len > 0 时，回退到 next[len-1]——这是 KMP 的精髓，利用已有的 next 信息避免从头比较。
  • 当不匹配且 len === 0 时，说明没有任何相等前后缀，next[i] = 0。

匹配阶段的逻辑：

  • i 遍历主串（永不回退），j 指向模式串当前待匹配位置。
  • 失配时，j 跳转到 next[j-1]，相当于将模式串右移，对齐已匹配的前缀。
  • 当 j === n 时，完整匹配成功，返回起始位置 i - n + 1。

复杂度分析

维度 复杂度 说明
时间（预处理） O(n) 构建 next 数组，每个字符最多被处理两次
时间（匹配） O(m) 主串指针 i 只前进不后退
总时间 O(m + n) 两阶段之和
空间 O(n) next 数组大小等于模式串长度

KMP 算法的时间复杂度证明依赖于摊还分析：在匹配阶段，j 每次通过 while 循环减小至少 1，而 j 通过 j++ 增加的总次数不超过 m，因此 while 循环的总执行次数也不超过 m，整体为 O(m)。buildNext 的分析同理。

KMP 算法不仅是字符串匹配的基础工具，其 next 数组（也称为失败函数或部分匹配表）在许多高级算法中都有应用，包括 AC 自动机的构建、最短循环节的计算（n % (n - next[n-1]) === 0 时循环节长度为 n - next[n-1]），以及字符串的周期性分析。
