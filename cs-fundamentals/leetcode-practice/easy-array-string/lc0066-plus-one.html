LeetCode 66 加一

题目描述

给定一个由整数组成的非空数组所表示的非负整数，在该数的基础上加一。

最高位数字存放在数组的首位，数组中每个元素只存储单个数字。

你可以假设除了整数 0 之外，这个整数不会以零开头。

约束条件：

  • 1 <= digits.length <= 100
  • 0 <= digits[i] <= 9
  • 输入的数不含前导零

示例 1：

输入：digits = [1,2,3]
输出：[1,2,4]
解释：输入数组表示数字 123，加一后得到 124

示例 2：

输入：digits = [4,3,2,1]
输出：[4,3,2,2]

示例 3：

输入：digits = [9]
输出：[1,0]
解释：9 + 1 = 10，需要进位

示例 4：

输入：digits = [9,9,9]
输出：[1,0,0,0]
解释：999 + 1 = 1000，多次进位且数组长度增加

解题思路

本题的核心难点在于进位处理。大多数情况下，我们只需将最后一位加 1 即可，但当末尾出现连续的 9 时，进位会一路传播到高位，甚至可能导致数组长度增加（如 999 → 1000）。

逆向遍历法是最直接的方案：

  1. 从数组末尾开始遍历（个位数开始）
  2. 当前位加 1
  3. 如果当前位 < 10，说明没有进位，直接返回
  4. 如果当前位 === 10，将当前位设为 0，继续向高位进位
  5. 如果遍历完所有位仍有进位，说明原数形如 999...9，需要在数组头部插入 1

实际上可以进一步简化——我们不需要显式维护进位变量。因为每次加的都是 1，所以产生进位的唯一条件是当前位为 9。利用这个特性，算法可以写得更简洁：

  1. 从末位开始，如果当前位 < 9，直接加 1 并返回
  2. 如果当前位 === 9，将其设为 0，继续处理上一位
  3. 如果所有位都是 9，最终创建长度加 1 的新数组，首位为 1
情况 示例 进位次数 数组长度变化
末位非 9 [1,2,3] → [1,2,4] 0 不变
末位为 9 但非全 9 [1,2,9] → [1,3,0] 1 不变
连续 9 [1,9,9] → [2,0,0] 2 不变
全 9 [9,9,9] → [1,0,0,0] 3 +1

代码实现

function plusOne(digits: number[]): number[] {
  for (let i = digits.length - 1; i >= 0; i--) {
    if (digits[i] < 9) {
      digits[i]++;
      return digits;
    }
    digits[i] = 0;
  }

  const result = new Array(digits.length + 1).fill(0);
  result[0] = 1;
  return result;
}

这个实现利用了一个巧妙的观察：加 1 后产生进位，当且仅当当前位为 9。所以我们只需检查当前位是否为 9：如果不是，直接加 1 返回；如果是，置为 0 并继续向高位传播。

如果需要处理更通用的"加 k"场景（如面试追问），可以使用显式进位：

function plusK(digits: number[], k: number): number[] {
  let carry = k;

  for (let i = digits.length - 1; i >= 0; i--) {
    const sum = digits[i] + carry;
    digits[i] = sum % 10;
    carry = Math.floor(sum / 10);

    if (carry === 0) return digits;
  }

  const extra: number[] = [];
  while (carry > 0) {
    extra.unshift(carry % 10);
    carry = Math.floor(carry / 10);
  }

  return [...extra, ...digits];
}

复杂度分析

指标 值 说明
时间复杂度 O(n) 最坏情况遍历所有数位（全 9 的场景）
空间复杂度 O(1) 或 O(n) 无进位时原地修改为 O(1)；全 9 时需新建数组为 O(n)
最佳情况 O(1) 末位非 9，直接加 1 返回

平均情况下，末位非 9 的概率为 90%，此时时间复杂度为 O(1)。只有全 9 的情况（概率约为 10⁻ⁿ）才需要 O(n) 时间。本题虽然简单，但"从低位到高位的进位传播"是大数加法、大数乘法等高频面试题的核心基础。
