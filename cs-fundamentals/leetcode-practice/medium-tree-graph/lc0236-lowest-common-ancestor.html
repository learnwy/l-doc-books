LeetCode 236 二叉树的最近公共祖先

题目描述

给定一个二叉树，找到该树中两个指定节点的最近公共祖先（LCA，Lowest Common Ancestor）。

最近公共祖先的定义为：对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。

示例 1：

  • 输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
  • 输出：3
  • 解释：节点 5 和节点 1 的最近公共祖先是节点 3。

示例 2：

  • 输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
  • 输出：5
  • 解释：节点 5 和节点 4 的最近公共祖先是节点 5，因为根据定义最近公共祖先节点可以是节点本身。

示例 3：

  • 输入：root = [1,2], p = 1, q = 2
  • 输出：1

约束条件：

  • 树中节点数目在范围 [2, 10^5] 内
  • -10^9 <= Node.val <= 10^9
  • 所有 Node.val 互不相同
  • p != q
  • p 和 q 均存在于给定的二叉树中

LCA 是树上最经典的问题之一，在实际工程中广泛应用于版本控制（查找分支交点）、文件系统（查找共同父目录）等场景。

解题思路

后序 DFS 递归

本题的核心思路是利用后序遍历（左→右→根）的「汇报」机制：

  1. 递归遍历左子树，看是否找到 p 或 q
  2. 递归遍历右子树，看是否找到 p 或 q
  3. 根据左右子树的返回结果判断：
    • 左右都找到：说明 p 和 q 分别在当前节点的左右子树中，当前节点就是 LCA
    • 只有左边找到：LCA 在左子树中，向上传递左子树的结果
    • 只有右边找到：LCA 在右子树中，向上传递右子树的结果
    • 都没找到：向上传递 null

为什么是后序遍历？ 因为我们需要先知道左右子树的结果，才能判断当前节点是否为 LCA。这正是「先处理子问题，再处理当前问题」的后序特征。

情况 left 返回 right 返回 当前节点返回
p、q 分居两侧 非 null 非 null 当前节点（LCA）
都在左子树 非 null null left 的返回值
都在右子树 null 非 null right 的返回值
当前节点是 p 或 q — — 当前节点

代码实现

class TreeNode {
  val: number;
  left: TreeNode | null;
  right: TreeNode | null;
  constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
    this.val = val ?? 0;
    this.left = left ?? null;
    this.right = right ?? null;
  }
}

function lowestCommonAncestor(root: TreeNode | null, p: TreeNode, q: TreeNode): TreeNode | null {
  if (root === null || root === p || root === q) {
    return root;
  }

  const left = lowestCommonAncestor(root.left, p, q);
  const right = lowestCommonAncestor(root.right, p, q);

  if (left !== null && right !== null) {
    return root;
  }

  return left !== null ? left : right;
}

代码简洁性分析： 这段代码虽然只有不到 10 行核心逻辑，但包含了所有情况的处理：

  • root === null：到达叶子节点以下，返回 null
  • root === p || root === q：找到目标节点，立即返回（不再深入）
  • left && right 都非空：当前节点是 LCA
  • 只有一侧非空：向上传递该侧的结果

执行过程示例

以 root = [3,5,1,6,2,0,8,null,null,7,4]，p = 5，q = 4 为例：

        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4
递归调用 节点 left right 返回
dfs(6) 6 null null null
dfs(7) 7 null null null
dfs(4) 4 — — 4（p=4匹配）
dfs(2) 2 null(7) 4 4
dfs(5) 5 — — 5（q=5匹配）
dfs(0) 0 null null null
dfs(8) 8 null null null
dfs(1) 1 null null null
dfs(3) 3 5 null 5

注意：dfs(5) 直接返回 5（因为 root === q），不再向下递归。节点 4 的信息通过 dfs(2) → dfs(5) 向上传递，但因为 5 本身就是目标，所以在 5 处就截断了。最终 dfs(3) 的 left=5, right=null，返回 5。

为什么结果是 5 而不是 3？ 因为 dfs(5) 匹配到 root === q 后立即返回，不再检查其子树。4 作为 5 的后代，其公共祖先就是 5 本身。

BST 上的 LCA

如果树是二叉搜索树（LC #235），可以利用 BST 性质简化：

function lowestCommonAncestorBST(root: TreeNode | null, p: TreeNode, q: TreeNode): TreeNode | null {
  let current = root;
  while (current !== null) {
    if (p.val < current.val && q.val < current.val) {
      current = current.left;
    } else if (p.val > current.val && q.val > current.val) {
      current = current.right;
    } else {
      return current;
    }
  }
  return null;
}

复杂度分析

维度 复杂度 说明
时间复杂度 O(n) 最坏情况遍历所有节点
空间复杂度 O(h) 递归栈深度，h 为树高

时间复杂度详解： 每个节点最多被访问一次。当 p 和 q 分别位于最深的叶子节点时，需要遍历所有节点，因此最坏 O(n)。

空间复杂度详解： 递归栈深度等于树高 h。平衡二叉树 h = O(log n)，退化为链表时 h = O(n)。

LCA 问题是面试高频考点，也是许多复杂树算法的基础。掌握后序递归的「汇报」思想后，还可以解决树上路径和（LC #124）、树的直径（LC #543）等需要同时考虑左右子树信息的问题。
