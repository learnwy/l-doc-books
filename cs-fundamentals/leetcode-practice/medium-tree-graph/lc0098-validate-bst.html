LeetCode 98 验证二叉搜索树

题目描述

给你一个二叉树的根节点 root，判断其是否是一个有效的二叉搜索树。

有效的二叉搜索树定义如下：

  • 节点的左子树只包含小于当前节点的数
  • 节点的右子树只包含大于当前节点的数
  • 所有左子树和右子树自身必须也是二叉搜索树

示例 1：

  • 输入：root = [2,1,3]
  • 输出：true

示例 2：

  • 输入：root = [5,1,4,null,null,3,6]
  • 输出：false
  • 解释：根节点的值是 5，但右子节点的值是 4。

约束条件：

  • 树中节点数目范围在 [1, 10^4] 内
  • -2^31 <= Node.val <= 2^31 - 1

本题常见的错误是只比较节点与其直接子节点的大小关系。例如 [5,4,6,null,null,3,7] 中，节点 3 虽然是 6 的左子节点（3 < 6），但它在根节点 5 的右子树中，必须大于 5，因此该树不是有效 BST。

解题思路

方法一：递归传递上下界

正确的做法是为每个节点维护一个有效的取值范围 (lower, upper)。根节点的范围是 (-∞, +∞)，左子节点的上界更新为父节点的值，右子节点的下界更新为父节点的值。

递归过程：

  1. 如果节点为空，返回 true
  2. 如果节点值 ≤ lower 或 ≥ upper，返回 false
  3. 递归验证左子树（upper 更新为当前值）和右子树（lower 更新为当前值）

方法二：中序遍历

BST 的中序遍历结果是严格递增序列。因此可以对树进行中序遍历，检查每个元素是否大于前一个元素。

这种方法的优势是思路直观，不需要维护复杂的边界参数。只需记录上一个访问的值 prev，每次比较即可。

方法 思路 时间复杂度 空间复杂度
上下界递归 传递有效范围 O(n) O(h)
中序遍历 验证有序性 O(n) O(h)

其中 h 为树的高度，最坏情况下 h = n（退化为链表）。

代码实现

方法一：递归上下界

class TreeNode {
  val: number;
  left: TreeNode | null;
  right: TreeNode | null;
  constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
    this.val = val ?? 0;
    this.left = left ?? null;
    this.right = right ?? null;
  }
}

function isValidBST(root: TreeNode | null): boolean {
  const validate = (node: TreeNode | null, lower: number, upper: number): boolean => {
    if (node === null) return true;
    if (node.val <= lower || node.val >= upper) return false;
    return validate(node.left, lower, node.val) && validate(node.right, node.val, upper);
  };

  return validate(root, -Infinity, Infinity);
}

方法二：中序遍历（迭代）

function isValidBST(root: TreeNode | null): boolean {
  const stack: TreeNode[] = [];
  let prev = -Infinity;
  let current = root;

  while (current !== null || stack.length > 0) {
    while (current !== null) {
      stack.push(current);
      current = current.left;
    }

    current = stack.pop()!;

    if (current.val <= prev) {
      return false;
    }
    prev = current.val;

    current = current.right;
  }

  return true;
}

执行过程示例

以 root = [5,1,4,null,null,3,6] 为例，展示上下界递归法：

节点 lower upper 判断 结果
5 -∞ +∞ -∞ < 5 < +∞ 有效，继续
1（左） -∞ 5 -∞ < 1 < 5 有效，继续
4（右） 5 +∞ 4 ≤ 5 无效！

节点 4 在根节点 5 的右子树中，但 4 < 5，违反了 BST 性质，返回 false。

以中序遍历法验证同一棵树：中序遍历顺序为 1, 5, 3, 4, 6，当访问到 3 时发现 3 < 5（前一个值），即序列不是严格递增的，返回 false。

常见错误

function isValidBSTWrong(root: TreeNode | null): boolean {
  if (root === null) return true;
  if (root.left !== null && root.left.val >= root.val) return false;
  if (root.right !== null && root.right.val <= root.val) return false;
  return isValidBSTWrong(root.left) && isValidBSTWrong(root.right);
}

上述代码只检查了直接子节点，对于 [5,4,6,null,null,3,7] 会错误返回 true（3 是 6 的左子节点但小于根节点 5）。

复杂度分析

维度 上下界递归 中序遍历
时间复杂度 O(n)，每个节点访问一次 O(n)，每个节点访问一次
空间复杂度 O(h)，递归栈深度 O(h)，显式栈深度

时间复杂度详解： 两种方法都需要在最坏情况下访问每个节点恰好一次。上下界递归在发现无效时可以提前终止，但最坏情况仍是 O(n)。

空间复杂度详解： h 为树高。对于平衡 BST，h = O(log n)；对于退化的链表形状，h = O(n)。两种方法的空间复杂度本质相同，只是递归法使用调用栈，迭代法使用显式栈。

验证 BST 是树类题目的基础。掌握「上下界传递」和「中序遍历验证有序性」两种思路后，可以推广到恢复 BST（LC #99）、BST 中第 K 小的元素（LC #230）等问题。
