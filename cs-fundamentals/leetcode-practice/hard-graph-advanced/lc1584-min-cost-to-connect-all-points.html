LeetCode 1584 连接所有点的最小费用

题目描述

给定一个 points 数组，其中 points[i] = [xi, yi] 表示二维平面上的一个点。连接两个点 [xi, yi] 和 [xj, yj] 的费用为它们之间的曼哈顿距离：|xi - xj| + |yi - yj|。

请返回将所有点连接起来的最小总费用。只有任意两点之间恰好有一条简单路径时，才认为所有点都已连接。

约束条件：

  • 1 <= points.length <= 1000
  • -10^6 <= xi, yi <= 10^6
  • 所有点的坐标互不相同

示例 1：

输入：points = [[0,0],[2,2],[3,10],[5,2],[7,0]]
输出：20
解释：最小生成树连接所有点，总费用为 20。

示例 2：

输入：points = [[3,12],[-2,5],[-4,1]]
输出：18

解题思路

本题要求将 n 个点全部连通且总边权最小，这正是经典的最小生成树（Minimum Spanning Tree, MST）问题。

问题建模： 将每个点视为图的节点，任意两点之间都有一条边，边权为曼哈顿距离。这构成了一个完全图，共有 n(n-1)/2 条边。

Kruskal 算法： 将所有边按权重排序，从小到大依次加入，如果加入的边不形成环（用并查集判断），则选中。选够 n-1 条边后停止。

Prim 算法： 从任意一个点开始，维护一个"已选集合"。每次从未选点中选择到已选集合距离最小的点加入。适合稠密图（边数多），因为可以用邻接矩阵实现 O(V²)。

通用





本题是完全图，E = V(V-1)/2 ≈ V²。Prim 的 O(V²) 实现最优，避免了对 V² 条边排序。但 Kruskal 代码更直观，在 V ≤ 1000 的约束下也完全可行。


代码实现
Prim 算法（O(V²) 实现）：


function minCostConnectPoints(points: number[][]): number {
  const n = points.length;
  const dist = new Array(n).fill(Infinity);
  const inMST = new Array(n).fill(false);
  dist[0] = 0;
  let totalCost = 0;

  for (let i = 0; i < n; i++) {
    let u = -1;
    for (let j = 0; j < n; j++) {
      if (!inMST[j] && (u === -1 || dist[j] < dist[u])) {
        u = j;
      }
    }

    inMST[u] = true;
    totalCost += dist[u];

    for (let v = 0; v < n; v++) {
      if (!inMST[v]) {
        const d = Math.abs(points[u][0] - points[v][0]) + Math.abs(points[u][1] - points[v][1]);
        dist[v] = Math.min(dist[v], d);
      }
    }
  }

  return totalCost;
}
Kruskal 算法（排序 + 并查集）：


function minCostConnectPointsKruskal(points: number[][]): number {
  const n = points.length;
  const edges: [number, number, number][] = [];

  for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {
      const d = Math.abs(points[i][0] - points[j][0]) + Math.abs(points[i][1] - points[j][1]);
      edges.push([d, i, j]);
    }
  }

  edges.sort((a, b) => a[0] - b[0]);

  const parent = new Array(n).fill(0).map((_, i) => i);
  const rank = new Array(n).fill(0);

  const find = (x: number): number => {
    if (parent[x] !== x) parent[x] = find(parent[x]);
    return parent[x];
  };

  const union = (x: number, y: number): boolean => {
    const px = find(x);
    const py = find(y);
    if (px === py) return false;
    if (rank[px] < rank[py]) {
      parent[px] = py;
    } else if (rank[px] > rank[py]) {
      parent[py] = px;
    } else {
      parent[py] = px;
      rank[px]++;
    }
    return true;
  };

  let totalCost = 0;
  let edgeCount = 0;

  for (const [d, u, v] of edges) {
    if (union(u, v)) {
      totalCost += d;
      edgeCount++;
      if (edgeCount === n - 1) break;
    }
  }

  return totalCost;
}

Prim 分析： 外层循环 V 次，每次内部遍历 V 个节点找最小值和更新距离。总计 O(V²)。空间只需 dist 和 inMST 数组，O(V)。


Kruskal 分析： 生成所有边 O(V²)，排序 O(V² log V²) = O(V² log V)，并查集操作总计约 O(V² α(V))。排序主导，总计 O(V² log V)。空间需要存储所有边 O(V²)。


在 V = 1000 时，Prim 约需 10⁶ 次操作，Kruskal 约需 5 × 10⁵ × 20 ≈ 10⁷ 次操作。两者都能轻松通过，但 Prim 更优。


选择建议： 面试中两种算法都要掌握。Kruskal 更适合稀疏图（边数远小于 V²），Prim 更适合稠密图和完全图。本题作为完全图，Prim 是更自然的选择。
