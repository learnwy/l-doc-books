LeetCode 787 K 站中转内最便宜的航班

题目描述

有 n 个城市通过一些航班连接。给定一个数组 flights，其中 flights[i] = [fromi, toi, pricei] 表示从城市 fromi 到城市 toi 的航班价格为 pricei。

给定所有的城市数 n、航班列表 flights、出发城市 src、目的城市 dst 以及经停站的数量限制 k，请找出从 src 到 dst 最多经过 k 站中转的最便宜价格。如果不存在这样的路线，则返回 -1。

约束条件：

  • 1 <= n <= 100
  • 0 <= flights.length <= n * (n - 1) / 2
  • flights[i].length == 3
  • 0 <= fromi, toi < n
  • fromi != toi
  • 1 <= pricei <= 10^4
  • 航班没有重复，且不存在自环
  • 0 <= src, dst, k < n
  • src != dst

示例 1：

输入：n = 4, flights = [[0,1,100],[1,2,100],[2,0,100],[1,3,600],[2,3,200]], src = 0, dst = 3, k = 1
输出：700
解释：从城市 0 到城市 3，经过 1 站中转的最优路径为 0→1→3，价格 100+600=700。

示例 2：

输入：n = 3, flights = [[0,1,100],[1,2,100],[0,2,500]], src = 0, dst = 2, k = 1
输出：200
解释：路径 0→1→2 经过 1 站中转，价格 200，优于直飞的 500。

示例 3：

输入：n = 3, flights = [[0,1,100],[1,2,100],[0,2,500]], src = 0, dst = 2, k = 0
输出：500
解释：k=0 表示不允许中转，只能直飞 0→2，价格 500。

解题思路

本题是带限制条件的最短路径问题。经典 Dijkstra 算法不能直接使用，因为贪心策略可能会选择中转次数过多的路径。

方法一：Bellman-Ford 变体

Bellman-Ford 算法天然支持限制松弛轮数。标准 Bellman-Ford 进行 V-1 轮松弛，本题只需进行 k+1 轮（k 次中转意味着最多走 k+1 条边）。

关键点：每轮松弛时，必须使用上一轮的距离数组副本来更新，而非当前轮的数组。否则同一轮内的多次松弛会导致中转次数超限。

方法二：动态规划


定义 dp[t][v] 为最多经过 t 条边到达节点 v 的最小花费。状态转移方程：


dp[t][v] = min(dp[t-1][v], min(dp[t-1][u] + w(u,v)) for all edges (u,v))
这与 Bellman-Ford 的本质完全一致，只是用 DP 的视角来理解。

Bellman-Ford 变体是本题最优雅的解法，代码简洁且正确。


代码实现
Bellman-Ford 变体：


function findCheapestPrice(n: number, flights: number[][], src: number, dst: number, k: number): number {
  let dist = new Array(n).fill(Infinity);
  dist[src] = 0;

  for (let i = 0; i <= k; i++) {
    const prev = [...dist];
    for (const [u, v, w] of flights) {
      if (prev[u] < Infinity && prev[u] + w < dist[v]) {
        dist[v] = prev[u] + w;
      }
    }
  }

  return dist[dst] === Infinity ? -1 : dist[dst];
}
动态规划解法：


function findCheapestPriceDP(n: number, flights: number[][], src: number, dst: number, k: number): number {
  const INF = Infinity;
  let prev = new Array(n).fill(INF);
  prev[src] = 0;

  for (let t = 1; t <= k + 1; t++) {
    const curr = [...prev];
    for (const [u, v, w] of flights) {
      if (prev[u] < INF && prev[u] + w < curr[v]) {
        curr[v] = prev[u] + w;
      }
    }
    prev = curr;
  }

  return prev[dst] === INF ? -1 : prev[dst];
}
BFS + 队列解法（分层遍历）：


function findCheapestPriceBFS(n: number, flights: number[][], src: number, dst: number, k: number): number {
  const graph: Map<number, [number, number][]> = new Map();
  for (let i = 0; i < n; i++) graph.set(i, []);
  for (const [u, v, w] of flights) {
    graph.get(u)!.push([v, w]);
  }

  const dist = new Array(n).fill(Infinity);
  dist[src] = 0;

  const queue: [number, number][] = [[src, 0]];
  let stops = 0;

  while (queue.length > 0 && stops <= k) {
    const size = queue.length;
    for (let i = 0; i < size; i++) {
      const [u, cost] = queue.shift()!;
      for (const [v, w] of graph.get(u)!) {
        const newCost = cost + w;
        if (newCost < dist[v]) {
          dist[v] = newCost;
          queue.push([v, newCost]);
        }
      }
    }
    stops++;
  }

  return dist[dst] === Infinity ? -1 : dist[dst];
}

时间复杂度详解： Bellman-Ford 变体执行 k+1 轮松弛，每轮遍历所有边。在本题约束下，k < n ≤ 100，E ≤ n(n-1)/2 ≈ 4950，因此最坏情况约 100 × 5000 = 50 万次操作，非常高效。


空间复杂度详解： Bellman-Ford 只需要维护两个长度为 V 的数组（当前距离和上一轮距离），空间复杂度 O(V)。BFS 需要额外的邻接表和队列空间。


关键陷阱： 松弛时必须使用上一轮的快照 prev，否则同一轮内的连锁更新会导致实际中转次数超过 k。这是本题最容易犯的错误。
