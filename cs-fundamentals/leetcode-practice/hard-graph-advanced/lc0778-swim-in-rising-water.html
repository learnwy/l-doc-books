LeetCode 778 水位上升的泳池中游泳

题目描述

在一个 n x n 的整数矩阵 grid 中，每个单元格 grid[i][j] 表示该位置的海拔高度。当时间为 t 时，水位等于 t，你可以在水位大于等于当前位置和目标位置海拔的情况下游动。

你从左上角 (0, 0) 出发，目标是到达右下角 (n-1, n-1)。可以上下左右四个方向移动。求到达终点的最少时间 t。

约束条件：

  • n == grid.length
  • n == grid[i].length
  • 1 <= n <= 50
  • 0 <= grid[i][j] < n²
  • grid[i][j] 中每个值恰好出现一次（即矩阵是 0 到 n²-1 的排列）

示例 1：

输入：grid = [[0,2],[1,3]]
输出：3
解释：时间为 3 时，水位为 3，所有格子都可通行。路径 (0,0)→(0,1)→(1,1) 或 (0,0)→(1,0)→(1,1)。

示例 2：

输入：grid = [[0,1,2,3,4],[24,23,22,21,5],[12,13,14,15,16],[11,17,18,19,20],[10,9,8,7,6]]
输出：16
解释：最优路径经过的最大海拔为 16。

解题思路

本题要找从左上到右下的路径，使得路径上的最大海拔值最小。这是一个最小化最大值问题，有多种经典解法。

核心转化： 时间 t 就是路径上所有节点的最大海拔值。我们要找一条路径，使路径上的最大值尽可能小。

方法一：二分答案 + BFS/DFS

对答案 t 进行二分搜索。对于给定的 t，检查是否存在从 (0,0) 到 (n-1,n-1) 的路径，使得路径上所有节点的海拔 ≤ t。用 BFS 或 DFS 验证。

方法二：优先队列（类 Dijkstra）

使用最小堆，每次扩展当前"代价"最小的格子。从 (0,0) 开始，每到一个新格子，路径代价更新为 max(当前代价, 新格子海拔)。这本质上是 Dijkstra 算法的变体，只是"距离"定义改为路径上的最大值。

方法三：并查集

将所有格子按海拔从小到大排序，依次加入图中。每加入一个格子就和相邻已加入的格子合并。当 (0,0) 和 (n-1,n-1) 连通时，当前格子的海拔就是答案。

代码实现
方法一：二分答案 + BFS


function swimInWater(grid: number[][]): number {
  const n = grid.length;
  const dirs = [
    [-1, 0],
    [1, 0],
    [0, -1],
    [0, 1],
  ];

  const canReach = (t: number): boolean => {
    if (grid[0][0] > t) return false;
    const visited = Array.from({ length: n }, () => new Array(n).fill(false));
    const queue: [number, number][] = [[0, 0]];
    visited[0][0] = true;

    while (queue.length > 0) {
      const [x, y] = queue.shift()!;
      if (x === n - 1 && y === n - 1) return true;
      for (const [dx, dy] of dirs) {
        const nx = x + dx;
        const ny = y + dy;
        if (nx >= 0 && nx < n && ny >= 0 && ny < n && !visited[nx][ny] && grid[nx][ny] <= t) {
          visited[nx][ny] = true;
          queue.push([nx, ny]);
        }
      }
    }
    return false;
  };

  let lo = Math.max(grid[0][0], grid[n - 1][n - 1]);
  let hi = n * n - 1;

  while (lo < hi) {
    const mid = (lo + hi) >> 1;
    if (canReach(mid)) {
      hi = mid;
    } else {
      lo = mid + 1;
    }
  }

  return lo;
}
方法二：优先队列（Dijkstra 变体）


function swimInWaterDijkstra(grid: number[][]): number {
  const n = grid.length;
  const dirs = [
    [-1, 0],
    [1, 0],
    [0, -1],
    [0, 1],
  ];
  const visited = Array.from({ length: n }, () => new Array(n).fill(false));

  const heap: [number, number, number][] = [[grid[0][0], 0, 0]];
  visited[0][0] = true;

  while (heap.length > 0) {
    heap.sort((a, b) => a[0] - b[0]);
    const [cost, x, y] = heap.shift()!;

    if (x === n - 1 && y === n - 1) return cost;

    for (const [dx, dy] of dirs) {
      const nx = x + dx;
      const ny = y + dy;
      if (nx >= 0 && nx < n && ny >= 0 && ny < n && !visited[nx][ny]) {
        visited[nx][ny] = true;
        heap.push([Math.max(cost, grid[nx][ny]), nx, ny]);
      }
    }
  }

  return -1;
}
方法三：并查集


function swimInWaterUnionFind(grid: number[][]): number {
  const n = grid.length;
  const parent = new Array(n * n).fill(0).map((_, i) => i);
  const rank = new Array(n * n).fill(0);

  const find = (x: number): number => {
    if (parent[x] !== x) parent[x] = find(parent[x]);
    return parent[x];
  };

  const union = (x: number, y: number) => {
    const px = find(x);
    const py = find(y);
    if (px === py) return;
    if (rank[px] < rank[py]) {
      parent[px] = py;
    } else if (rank[px] > rank[py]) {
      parent[py] = px;
    } else {
      parent[py] = px;
      rank[px]++;
    }
  };

  const cells: [number, number, number][] = [];
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) {
      cells.push([grid[i][j], i, j]);
    }
  }
  cells.sort((a, b) => a[0] - b[0]);

  const dirs = [
    [-1, 0],
    [1, 0],
    [0, -1],
    [0, 1],
  ];
  const added = Array.from({ length: n }, () => new Array(n).fill(false));

  for (const [val, x, y] of cells) {
    added[x][y] = true;
    for (const [dx, dy] of dirs) {
      const nx = x + dx;
      const ny = y + dy;
      if (nx >= 0 && nx < n && ny >= 0 && ny < n && added[nx][ny]) {
        union(x * n + y, nx * n + ny);
      }
    }
    if (find(0) === find(n * n - 1)) return val;
  }

  return -1;
}

二分 + BFS： 二分范围为 [0, n²-1]，共 O(log(n²)) = O(log n) 轮，每轮 BFS 访问 O(n²) 个格子。


Dijkstra 变体： 每个格子最多入堆一次，堆操作 O(log(n²)) = O(log n)。总计 O(n² log n)。


并查集： 排序 O(n² log(n²))，之后每次 union/find 为 O(α(n²)) ≈ O(1)。总计约 O(n² log n)。


三种方法在 n ≤ 50 的约束下都非常高效。并查集方法在实际运行中最快，因为排序后每步操作接近 O(1)。优先队列方法代码最简洁，面试中推荐使用。
