LeetCode 739 每日温度

题目描述

给定一个整数数组 temperatures，表示每天的温度，返回一个数组 answer，其中 answer[i] 是指对于第 i 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 0 来代替。

约束条件：

  • 1 <= temperatures.length <= 10^5
  • 30 <= temperatures[i] <= 100

示例 1：

输入：temperatures = [73,74,75,71,69,72,76,73]
输出：[1,1,4,2,1,1,0,0]

示例 2：

输入：temperatures = [30,40,50,60]
输出：[1,1,1,0]

示例 3：

输入：temperatures = [30,60,90]
输出：[1,1,0]

本题是单调栈的经典入门题。核心问题是对每个元素找到右侧第一个比它大的元素，这正是单调栈的标准应用场景。

解题思路

暴力方法

对每个位置 i，向右遍历找到第一个比 temperatures[i] 大的位置 j，answer[i] = j - i。时间复杂度 O(n²)，当数组较大时会超时。

单调栈方法

维护一个单调递减栈（栈底到栈顶元素递减），栈中存储的是数组下标。从左到右遍历数组：

  1. 当前温度大于栈顶对应的温度时，说明栈顶元素找到了右侧第一个更大值
  2. 弹出栈顶，计算天数差 i - stack.top()
  3. 重复直到栈为空或栈顶温度不小于当前温度
  4. 将当前下标入栈

单调栈的核心思想：维护一个"等待被解决"的元素集合。当一个更大的元素出现时，它会"解决"栈中所有比它小的元素。

方法 时间复杂度 空间复杂度 特点
暴力双循环 O(n²) O(1) 简单但超时
单调栈 O(n) O(n) 每个元素最多入栈出栈各一次

为什么单调栈是 O(n)？虽然内层有 while 循环，但每个元素最多入栈一次、出栈一次，因此所有元素的总操作次数为 2n，均摊时间复杂度 O(n)。

代码实现

function dailyTemperatures(temperatures: number[]): number[] {
  const n = temperatures.length;
  const answer = new Array(n).fill(0);
  const stack: number[] = [];

  for (let i = 0; i < n; i++) {
    while (stack.length > 0 && temperatures[i] > temperatures[stack[stack.length - 1]]) {
      const prevIdx = stack.pop()!;
      answer[prevIdx] = i - prevIdx;
    }
    stack.push(i);
  }

  return answer;
}

我们来用示例 1 模拟整个过程，直观理解单调栈的工作机制：

temperatures = [73, 74, 75, 71, 69, 72, 76, 73]

i=0: 栈空，入栈 [0]                       → 栈对应温度: [73]
i=1: 74 > 73, 弹出 0, answer[0]=1; 入栈 [1] → 栈对应温度: [74]
i=2: 75 > 74, 弹出 1, answer[1]=1; 入栈 [2] → 栈对应温度: [75]
i=3: 71 < 75, 入栈 [2,3]                   → 栈对应温度: [75,71]
i=4: 69 < 71, 入栈 [2,3,4]                 → 栈对应温度: [75,71,69]
i=5: 72 > 69, 弹出 4, answer[4]=1;
     72 > 71, 弹出 3, answer[3]=2; 入栈 [2,5] → 栈对应温度: [75,72]
i=6: 76 > 72, 弹出 5, answer[5]=1;
     76 > 75, 弹出 2, answer[2]=4; 入栈 [6] → 栈对应温度: [76]
i=7: 73 < 76, 入栈 [6,7]                   → 栈对应温度: [76,73]

遍历结束，栈中剩余 [6,7]，answer[6]=0, answer[7]=0（默认值）
最终结果：[1, 1, 4, 2, 1, 1, 0, 0]

从模拟过程可以看出，栈中始终维护着一个温度递减的序列。每当遇到一个较高温度时，它会"消灭"栈中所有比它低的温度，并为这些温度计算答案。

单调栈的模式可以总结为：寻找下一个更大/更小元素。根据具体问题的不同，可以选择单调递增栈或单调递减栈，以及从左向右或从右向左遍历。本题使用的是单调递减栈 + 从左向右遍历。

复杂度分析

维度 复杂度 说明
时间 O(n) 每个元素最多入栈和出栈各一次
空间 O(n) 栈的最大深度为 n（温度严格递减时）

时间复杂度详解： 虽然代码中有嵌套的 for + while 结构，但这不是 O(n²)。关键观察：每个下标最多入栈一次、出栈一次。所有 push 操作总共 n 次，所有 pop 操作总共最多 n 次，因此总操作次数为 O(2n) = O(n)。这种分析方法称为均摊分析。

空间复杂度详解： 最差情况下，温度序列严格递减，所有元素都会停留在栈中，空间为 O(n)。最好情况下，温度严格递增，栈中始终只有一个元素，空间为 O(1)。

实际应用： 单调栈是处理"下一个更大/更小元素"问题的标准工具，在股票价格分析、直方图最大矩形、接雨水等问题中都有广泛应用。理解本题后，建议继续练习 LC 496、LC 503、LC 84 和 LC 42 巩固单调栈模式。
