LeetCode 215 数组中的第 K 个最大元素

题目描述

给定整数数组 nums 和整数 k，请返回数组中第 k 个最大的元素。

注意，你需要找的是数组排序后的第 k 个最大的元素，而不是第 k 个不同的元素。要求设计并实现时间复杂度为 O(n) 的算法解决此问题。

约束条件：

  • 1 <= k <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4

示例 1：

输入：nums = [3,2,1,5,6,4], k = 2
输出：5

示例 2：

输入：nums = [3,2,3,1,2,4,5,5,6], k = 4
输出：4

本题是经典的 Top-K 问题，有多种解法可以选择，核心在于理解不同方法在时间复杂度和空间复杂度上的权衡。

解题思路

最直观的方法是对数组排序后取第 k 个最大值，时间复杂度为 O(n log n)。但题目要求 O(n) 的算法，因此需要更高效的策略。

方法一：快速选择算法（QuickSelect）

快速选择算法基于快速排序的分区思想。每次选择一个基准元素（pivot），将数组分为三部分：大于 pivot、等于 pivot、小于 pivot。根据 k 与各部分长度的关系，只需要递归处理其中一个部分即可。

核心原理：假设 pivot 将数组分区后，大于 pivot 的元素有 left 个。如果 k <= left，说明第 k 大元素在左半部分；如果 k > left + equal，说明在右半部分；否则 pivot 本身就是答案。

方法二：小顶堆

维护一个大小为 k 的小顶堆。遍历数组时，如果堆的大小小于 k，直接入堆；否则，当当前元素大于堆顶时，替换堆顶元素并调整堆。遍历完成后堆顶即为第 k 大元素。

方法 时间复杂度（平均） 时间复杂度（最差） 空间复杂度 适用场景
排序 O(n log n) O(n log n) O(log n) 简单直接，数据量小
快速选择 O(n) O(n²) O(log n) 数据量大，求单个第K大
小顶堆 O(n log k) O(n log k) O(k) 数据流/需要前K个元素
BFPRT O(n) O(n) O(log n) 理论最优但常数大

快速选择在平均情况下性能最优，但最差情况退化为 O(n²)。通过随机化选择 pivot 可以将最差情况的概率降到极低。

代码实现

方法一：快速选择（推荐）

function findKthLargest(nums: number[], k: number): number {
  const n = nums.length;
  const target = n - k;

  function partition(left: number, right: number): number {
    const randomIdx = left + Math.floor(Math.random() * (right - left + 1));
    [nums[randomIdx], nums[right]] = [nums[right], nums[randomIdx]];

    const pivot = nums[right];
    let storeIdx = left;

    for (let i = left; i < right; i++) {
      if (nums[i] < pivot) {
        [nums[i], nums[storeIdx]] = [nums[storeIdx], nums[i]];
        storeIdx++;
      }
    }

    [nums[storeIdx], nums[right]] = [nums[right], nums[storeIdx]];
    return storeIdx;
  }

  let left = 0;
  let right = n - 1;

  while (left <= right) {
    const pivotIdx = partition(left, right);
    if (pivotIdx === target) {
      return nums[pivotIdx];
    } else if (pivotIdx < target) {
      left = pivotIdx + 1;
    } else {
      right = pivotIdx - 1;
    }
  }

  return -1;
}

方法二：小顶堆

function findKthLargestHeap(nums: number[], k: number): number {
  const heap: number[] = [];

  function siftUp(i: number): void {
    while (i > 0) {
      const parent = (i - 1) >> 1;
      if (heap[parent] > heap[i]) {
        [heap[parent], heap[i]] = [heap[i], heap[parent]];
        i = parent;
      } else {
        break;
      }
    }
  }

  function siftDown(i: number): void {
    const n = heap.length;
    while (2 * i + 1 < n) {
      let smallest = 2 * i + 1;
      if (smallest + 1 < n && heap[smallest + 1] < heap[smallest]) {
        smallest++;
      }
      if (heap[i] > heap[smallest]) {
        [heap[i], heap[smallest]] = [heap[smallest], heap[i]];
        i = smallest;
      } else {
        break;
      }
    }
  }

  for (const num of nums) {
    if (heap.length < k) {
      heap.push(num);
      siftUp(heap.length - 1);
    } else if (num > heap[0]) {
      heap[0] = num;
      siftDown(0);
    }
  }

  return heap[0];
}

快速选择算法的关键在于随机化 pivot 的选择。通过在 [left, right] 区间内随机选取基准元素，可以避免在已排序数组等特殊情况下出现 O(n²) 的退化。每次分区后，我们只需要递归处理包含目标索引的那一侧，丢弃另一侧，因此平均每次将问题规模缩小一半。

小顶堆方法的优势在于它可以处理数据流场景——不需要一次性把所有数据加载到内存中。堆的大小始终为 k，适合 k 远小于 n 的场景。

复杂度分析

方法 时间复杂度 空间复杂度 说明
快速选择 平均 O(n)，最差 O(n²) O(1)（迭代版） 随机化后最差情况概率极低
小顶堆 O(n log k) O(k) 堆大小固定为 k

快速选择时间复杂度推导： 平均情况下，每次分区将问题规模缩减为原来的一半。总工作量为 T(n) = n + n/2 + n/4 + ... = 2n = O(n)。最差情况下每次只排除一个元素，退化为 n + (n-1) + (n-2) + ... = O(n²)。

空间复杂度说明： 迭代版快速选择只使用常数额外空间。小顶堆需要 O(k) 空间存储堆中元素。当 k 较小时，堆方法的空间效率也很高。

实际选择建议： 如果是一次性查询且数据全部在内存中，优先使用快速选择；如果是数据流场景或需要多次查询不同的 k 值，优先使用堆。在面试中，两种方法都要掌握，快速选择展示算法功底，堆方法展示工程思维。
