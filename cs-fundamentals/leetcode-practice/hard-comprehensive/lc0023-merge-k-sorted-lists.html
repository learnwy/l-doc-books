LeetCode 23 合并 K 个升序链表

题目描述

给定一个链表数组 lists，每个链表都已经按升序排列。将所有链表合并到一个升序链表中，返回合并后的链表。

示例：

输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：
  链表 1: 1 → 4 → 5
  链表 2: 1 → 3 → 4
  链表 3: 2 → 6
  合并后: 1 → 1 → 2 → 3 → 4 → 4 → 5 → 6

输入：lists = []
输出：[]

输入：lists = [[]]
输出：[]

约束条件：

  • k == lists.length
  • 0 <= k <= 10⁴
  • 0 <= lists[i].length <= 500
  • -10⁴ <= lists[i][j] <= 10⁴
  • lists[i] 按升序排列
  • lists[i].length 的总和不超过 10⁴

解题思路

这是一道经典的链表与排序综合题，有多种解法，每种解法代表不同的算法范式。

暴力方法： 收集所有节点值到数组，排序后构建新链表。时间 O(N log N)，空间 O(N)。

逐一合并： 将 k 个链表逐一两两合并。每次合并两个有序链表需要 O(n) 时间，总共合并 k-1 次。但问题是每次合并后链表越来越长，总时间为 O(kN)。

分治合并： 类似归并排序，每轮将 k 个链表两两配对合并，经过 log k 轮完成。每轮处理所有 N 个节点，总时间 O(N log k)。

最小堆（优先队列）： 维护一个大小为 k 的最小堆，每次弹出最小节点，将其后继节点加入堆中。每次堆操作 O(log k)，总共 N 次操作。

方法 时间复杂度 空间复杂度 核心思想
暴力排序 O(N log N) O(N) 收集所有值，整体排序
逐一合并 O(kN) O(1) 顺序合并 k-1 次
分治合并 O(N log k) O(log k) 归并排序思路，两两配对
最小堆 O(N log k) O(k) 维护 k 个链表头的堆

其中 N 为所有节点总数，k 为链表数量。分治和最小堆的时间复杂度相同，但实际表现各有优劣：分治的递归开销小但不够灵活，最小堆在 k 很大时常数更优。

代码实现

分治合并

interface ListNode {
  val: number;
  next: ListNode | null;
}

function mergeKLists(lists: Array<ListNode | null>): ListNode | null {
  if (lists.length === 0) return null;
  return divideAndConquer(lists, 0, lists.length - 1);
}

function divideAndConquer(lists: Array<ListNode | null>, lo: number, hi: number): ListNode | null {
  if (lo === hi) return lists[lo];

  const mid = Math.floor((lo + hi) / 2);
  const left = divideAndConquer(lists, lo, mid);
  const right = divideAndConquer(lists, mid + 1, hi);

  return mergeTwoLists(left, right);
}

function mergeTwoLists(l1: ListNode | null, l2: ListNode | null): ListNode | null {
  const dummy: ListNode = { val: 0, next: null };
  let curr = dummy;

  while (l1 !== null && l2 !== null) {
    if (l1.val <= l2.val) {
      curr.next = l1;
      l1 = l1.next;
    } else {
      curr.next = l2;
      l2 = l2.next;
    }
    curr = curr.next;
  }

  curr.next = l1 ?? l2;
  return dummy.next;
}

最小堆方法

function mergeKLists(lists: Array<ListNode | null>): ListNode | null {
  const heap: ListNode[] = [];

  for (const head of lists) {
    if (head !== null) heap.push(head);
  }

  buildMinHeap(heap);

  const dummy: ListNode = { val: 0, next: null };
  let curr = dummy;

  while (heap.length > 0) {
    const min = extractMin(heap);
    curr.next = min;
    curr = curr.next;

    if (min.next !== null) {
      insertHeap(heap, min.next);
    }
  }

  curr.next = null;
  return dummy.next;
}

function buildMinHeap(heap: ListNode[]): void {
  for (let i = Math.floor(heap.length / 2) - 1; i >= 0; i--) {
    siftDown(heap, i);
  }
}

function extractMin(heap: ListNode[]): ListNode {
  const min = heap[0];
  const last = heap.pop()!;
  if (heap.length > 0) {
    heap[0] = last;
    siftDown(heap, 0);
  }
  return min;
}

function insertHeap(heap: ListNode[], node: ListNode): void {
  heap.push(node);
  siftUp(heap, heap.length - 1);
}

function siftDown(heap: ListNode[], i: number): void {
  const n = heap.length;
  while (true) {
    let smallest = i;
    const left = 2 * i + 1;
    const right = 2 * i + 2;
    if (left < n && heap[left].val < heap[smallest].val) smallest = left;
    if (right < n && heap[right].val < heap[smallest].val) smallest = right;
    if (smallest === i) break;
    [heap[i], heap[smallest]] = [heap[smallest], heap[i]];
    i = smallest;
  }
}

function siftUp(heap: ListNode[], i: number): void {
  while (i > 0) {
    const parent = Math.floor((i - 1) / 2);
    if (heap[parent].val <= heap[i].val) break;
    [heap[i], heap[parent]] = [heap[parent], heap[i]];
    i = parent;
  }
}

实现要点：

  • 分治法：递归结构与归并排序完全相同，divideAndConquer 将 k 个链表分为两半，递归合并后再将两个结果合并。mergeTwoLists 是合并两个有序链表的标准实现。
  • 最小堆法：手写最小堆（TypeScript 标准库没有内置优先队列）。堆中始终维护 k 个链表的当前头节点，每次取最小值后将其后继加入堆中。
  • dummy 节点：两种方法都使用哨兵节点简化链表头的处理逻辑。

复杂度分析

维度 分治合并 最小堆 说明
时间 O(N log k) O(N log k) 每个节点被处理一次，每次涉及 O(log k) 操作
空间 O(log k) O(k) 分治用递归栈，堆用数组
实现难度 低 中 需要手写堆结构

分治法是面试中的首选方案：代码简洁、不需要额外数据结构、递归结构清晰。最小堆方法在处理动态添加/删除链表的场景中更灵活，是工程实践中常用的方案。
