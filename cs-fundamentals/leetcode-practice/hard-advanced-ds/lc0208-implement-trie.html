LeetCode 208 实现 Trie（前缀树）

题目描述

Trie（发音类似 "try"）或者说前缀树，是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用场景，例如自动补完和拼写检查。

请你实现 Trie 类：

  • Trie() 初始化前缀树对象
  • void insert(String word) 向前缀树中插入字符串 word
  • boolean search(String word) 如果字符串 word 在前缀树中，返回 true；否则返回 false
  • boolean startsWith(String prefix) 如果之前已经插入的字符串 word 的前缀之一为 prefix，返回 true；否则返回 false

约束条件：

  • 1 <= word.length, prefix.length <= 2000
  • word 和 prefix 仅由小写英文字母组成
  • insert、search 和 startsWith 调用次数总计不超过 3 × 10^4 次

示例：

输入：
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]
输出：[null, null, true, false, true, null, true]

解释：
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // 返回 true
trie.search("app");     // 返回 false
trie.startsWith("app"); // 返回 true
trie.insert("app");
trie.search("app");     // 返回 true

Trie 是一种经典的树形数据结构，在字符串匹配、前缀搜索和自动补全等场景中有着不可替代的作用。

解题思路

Trie 的核心结构

Trie 的每个节点包含：

  • 一个子节点映射（通常是大小为 26 的数组或 Map），存储当前字符到下一个节点的映射
  • 一个布尔标记 isEnd，表示从根节点到该节点的路径是否构成一个完整单词

三个操作的实现：

insert(word): 从根节点开始，逐字符遍历。如果当前字符对应的子节点不存在，创建新节点。移动到子节点，最终将末尾节点标记为 isEnd = true。

search(word): 从根节点开始，逐字符遍历。如果任何字符对应的子节点不存在，返回 false。遍历完所有字符后，检查末尾节点的 isEnd 是否为 true。

startsWith(prefix): 与 search 类似，但不需要检查 isEnd。只要能遍历完所有前缀字符就返回 true。

操作 Trie 哈希表 有序数组 + 二分
插入 O(m) O(m) O(n)
精确查找 O(m) O(m) O(m log n)
前缀查找 O(m) O(n×m) O(m log n)
前缀枚举 O(m + k) O(n×m) O(m log n + k)
空间 O(Σ×N) O(N×m) O(N×m)

其中 m 为字符串长度，n 为已存储字符串数量，Σ 为字符集大小，k 为结果数量。

Trie 的最大优势在于前缀操作——给定前缀后枚举所有匹配单词，这是哈希表无法高效实现的。

代码实现

class TrieNode {
  children: Map<string, TrieNode>;
  isEnd: boolean;

  constructor() {
    this.children = new Map();
    this.isEnd = false;
  }
}

class Trie {
  private root: TrieNode;

  constructor() {
    this.root = new TrieNode();
  }

  insert(word: string): void {
    let node = this.root;
    for (const ch of word) {
      if (!node.children.has(ch)) {
        node.children.set(ch, new TrieNode());
      }
      node = node.children.get(ch)!;
    }
    node.isEnd = true;
  }

  search(word: string): boolean {
    const node = this.traverse(word);
    return node !== null && node.isEnd;
  }

  startsWith(prefix: string): boolean {
    return this.traverse(prefix) !== null;
  }

  private traverse(str: string): TrieNode | null {
    let node = this.root;
    for (const ch of str) {
      if (!node.children.has(ch)) {
        return null;
      }
      node = node.children.get(ch)!;
    }
    return node;
  }
}

代码中提取了 traverse 辅助方法来消除 search 和 startsWith 之间的重复逻辑。traverse 返回遍历到的最终节点，或者在路径中断时返回 null。

使用数组代替 Map 的优化版本：

class TrieNodeArray {
  children: (TrieNodeArray | null)[];
  isEnd: boolean;

  constructor() {
    this.children = new Array(26).fill(null);
    this.isEnd = false;
  }
}

class TrieArray {
  private root: TrieNodeArray;

  constructor() {
    this.root = new TrieNodeArray();
  }

  insert(word: string): void {
    let node = this.root;
    for (const ch of word) {
      const idx = ch.charCodeAt(0) - 97;
      if (node.children[idx] === null) {
        node.children[idx] = new TrieNodeArray();
      }
      node = node.children[idx]!;
    }
    node.isEnd = true;
  }

  search(word: string): boolean {
    const node = this.traverse(word);
    return node !== null && node.isEnd;
  }

  startsWith(prefix: string): boolean {
    return this.traverse(prefix) !== null;
  }

  private traverse(str: string): TrieNodeArray | null {
    let node = this.root;
    for (const ch of str) {
      const idx = ch.charCodeAt(0) - 97;
      if (node.children[idx] === null) return null;
      node = node.children[idx]!;
    }
    return node;
  }
}

数组版本在字符集较小（如 26 个小写字母）时性能更好，因为数组索引比 Map 查找更快。但当字符集很大（如 Unicode）时，Map 版本更节省空间。

复杂度分析

操作 时间复杂度 空间复杂度 说明
insert O(m) O(m) m 为单词长度，最差新建 m 个节点
search O(m) O(1) 沿路径遍历，无额外空间
startsWith O(m) O(1) 同 search
总空间 — O(N × m × Σ) N 个单词，平均长度 m

时间复杂度说明： 所有操作都是沿着 Trie 的路径遍历，路径长度等于字符串长度 m。每一步的子节点查找是 O(1)（数组索引）或 O(1) 均摊（Map 查找）。

空间复杂度说明： 最差情况下，每个字符都需要一个新节点，每个节点有 26 个指针槽位。但如果多个单词共享前缀，空间会大幅减少。例如 "apple" 和 "app" 共享 "app" 三个节点。这种前缀共享正是 Trie 名称（Retrieval）的由来。

Trie 的实际应用： 搜索引擎的自动补全、IDE 的代码提示、IP 路由表（使用二叉 Trie）、拼写检查器等。本题是 Trie 的基础实现，掌握后可以继续挑战 LC 211（通配符搜索）和 LC 212（矩阵单词搜索）。
