LeetCode 24 两两交换链表中的节点

题目描述

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部值的情况下完成本题（即只能进行节点交换）。

示例 1：

  • 输入：head = [1,2,3,4]
  • 输出：[2,1,4,3]

示例 2：

  • 输入：head = []
  • 输出：[]

示例 3：

  • 输入：head = [1]
  • 输出：[1]

约束条件：

  • 链表中节点的数目在范围 [0, 100] 内
  • 0 <= Node.val <= 100

本题要求真正交换节点而非交换值，这意味着必须正确操作指针。需要仔细处理每对节点的指针重连，避免断链。

解题思路

递归思路

递归解法非常优雅。对于每一对节点 (first, second)：

  1. 递归处理 second.next 及之后的链表，得到已交换好的子链表
  2. 将 second.next 指向 first
  3. 将 first.next 指向递归返回的子链表头
  4. 返回 second 作为交换后的头节点

递归终止条件：链表为空或只剩一个节点时，无需交换，直接返回。

迭代思路

迭代解法需要一个前驱指针 prev 来连接已交换部分和当前交换对。每次操作一对节点 (node1, node2)：

  1. 保存 node2.next（下一对的起点）
  2. prev.next = node2（前驱指向交换后的第一个节点）
  3. node2.next = node1（第二个指向第一个）
  4. node1.next = saved（第一个指向下一对的起点）
  5. prev = node1（更新前驱为当前对的尾节点）
方法 思路 时间复杂度 空间复杂度
递归 自底向上交换 O(n) O(n) 栈空间
迭代 逐对交换 + 前驱指针 O(n) O(1)

代码实现

方法一：递归

class ListNode {
  val: number;
  next: ListNode | null;
  constructor(val?: number, next?: ListNode | null) {
    this.val = val ?? 0;
    this.next = next ?? null;
  }
}

function swapPairs(head: ListNode | null): ListNode | null {
  if (head === null || head.next === null) {
    return head;
  }

  const first = head;
  const second = head.next;

  first.next = swapPairs(second.next);
  second.next = first;

  return second;
}

方法二：迭代

function swapPairs(head: ListNode | null): ListNode | null {
  const dummy = new ListNode(0, head);
  let prev: ListNode = dummy;

  while (prev.next !== null && prev.next.next !== null) {
    const node1 = prev.next;
    const node2 = prev.next.next;

    prev.next = node2;
    node1.next = node2.next;
    node2.next = node1;

    prev = node1;
  }

  return dummy.next;
}

指针变化图解

以 [1,2,3,4] 为例，展示迭代法第一轮的指针操作：

交换前： dummy → 1 → 2 → 3 → 4

操作 指针变化 链表状态
prev.next = node2 dummy → 2 dummy → 2, 1 → 2 → 3 → 4
node1.next = node2.next 1 → 3 dummy → 2, 1 → 3 → 4
node2.next = node1 2 → 1 dummy → 2 → 1 → 3 → 4
prev = node1 prev 移至 1 准备下一轮

交换后： dummy → 2 → 1 → 3 → 4

第二轮从 prev = 1 开始，交换 3 和 4，最终得到 dummy → 2 → 1 → 4 → 3。

递归展开过程

以 [1,2,3,4] 为例：

swapPairs([1,2,3,4])
  first=1, second=2
  first.next = swapPairs([3,4])
                first=3, second=4
                first.next = swapPairs(null) → null
                second.next = 3
                return 4  → [4,3]
  first.next = [4,3]  → 1 → 4 → 3
  second.next = 1      → 2 → 1 → 4 → 3
  return 2  → [2,1,4,3]

复杂度分析

维度 递归 迭代
时间复杂度 O(n)，每个节点处理一次 O(n)，每个节点处理一次
空间复杂度 O(n)，递归栈深度 n/2 O(1)，仅需常数指针

时间复杂度详解： 两种方法都精确地遍历链表一次，每对节点执行常数次指针操作。对于 n 个节点，共 n/2 对，总操作 O(n)。

空间复杂度详解： 递归方法的栈深度为 n/2（每次递归处理一对），即 O(n)。迭代方法只使用 dummy、prev、node1、node2 四个指针，空间 O(1)。在面试中，如果面试官关注空间复杂度，应选择迭代解法。

本题是链表指针操作的经典训练题。核心技能是理解「修改指针顺序的正确性」——必须保证在断开某个连接之前，已经保存了需要的引用。这个技能可以推广到 K 个一组翻转链表（LC #25）。
