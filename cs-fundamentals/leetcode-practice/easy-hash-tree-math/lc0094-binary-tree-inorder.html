LeetCode 94 二叉树的中序遍历

题目描述

给定一个二叉树的根节点 root，返回它的中序遍历结果。

约束条件：

  • 树中节点数目在范围 [0, 100] 内
  • -100 <= Node.val <= 100

示例 1：

输入：root = [1, null, 2, 3]
     1
      \
       2
      /
     3
输出：[1, 3, 2]

示例 2：

输入：root = []
输出：[]

示例 3：

输入：root = [1]
输出：[1]

进阶： 递归算法很简单，你可以通过迭代算法完成吗？

二叉树的遍历是树结构的基础操作。中序遍历（左 → 根 → 右）的特殊性在于：对于二叉搜索树（BST），中序遍历的结果是有序的。本题将深入讲解递归和迭代两种实现方式，以及 Morris 遍历这一空间优化方案。

解题思路

三种遍历顺序回顾

二叉树的深度优先遍历有三种顺序：

遍历方式 访问顺序 记忆口诀 BST 特性
前序（Preorder） 根 → 左 → 右 根在前 第一个是根
中序（Inorder） 左 → 根 → 右 根在中 升序排列
后序（Postorder） 左 → 右 → 根 根在后 最后一个是根

递归法

中序遍历的递归实现是最自然的方式：先递归遍历左子树，然后访问当前节点，最后递归遍历右子树。递归的终止条件是节点为空。

递归法的优点是代码简洁、逻辑清晰。缺点是当树的深度很大时，可能导致调用栈溢出。

迭代法（显式栈）

迭代法使用显式栈来模拟递归的调用栈。核心思路是：

  1. 从根节点出发，沿左子树一直往下走，将沿途节点压入栈中
  2. 当左子树走到头（当前节点为空），从栈中弹出一个节点，记录其值
  3. 然后转向该节点的右子树，重复上述过程

这个过程本质上是在手动管理递归的「暂停」和「恢复」。

Morris 遍历

Morris 遍历是一种空间复杂度为 O(1) 的遍历算法。它通过修改树的结构（建立临时线索）来避免使用栈。核心思想是：找到当前节点左子树的最右节点，将其右指针指向当前节点，从而在遍历完左子树后能回到当前节点。

方法 时间复杂度 空间复杂度 特点
递归 O(n) O(h) 代码最简洁
迭代（栈） O(n) O(h) 避免栈溢出风险
Morris O(n) O(1) 不需要额外空间

其中 h 为树的高度，最坏情况 h = n（退化为链表），最好情况 h = log n（完全二叉树）。

代码实现

递归法

interface TreeNode {
  val: number;
  left: TreeNode | null;
  right: TreeNode | null;
}

function inorderTraversal(root: TreeNode | null): number[] {
  const result: number[] = [];

  const dfs = (node: TreeNode | null): void => {
    if (node === null) {
      return;
    }
    dfs(node.left);
    result.push(node.val);
    dfs(node.right);
  };

  dfs(root);
  return result;
}

迭代法（推荐）

function inorderTraversal(root: TreeNode | null): number[] {
  const result: number[] = [];
  const stack: TreeNode[] = [];
  let current = root;

  while (current !== null || stack.length > 0) {
    while (current !== null) {
      stack.push(current);
      current = current.left;
    }

    current = stack.pop()!;
    result.push(current.val);
    current = current.right;
  }

  return result;
}

Morris 遍历

function inorderTraversal(root: TreeNode | null): number[] {
  const result: number[] = [];
  let current = root;

  while (current !== null) {
    if (current.left === null) {
      result.push(current.val);
      current = current.right;
    } else {
      let predecessor = current.left;
      while (predecessor.right !== null && predecessor.right !== current) {
        predecessor = predecessor.right;
      }

      if (predecessor.right === null) {
        predecessor.right = current;
        current = current.left;
      } else {
        predecessor.right = null;
        result.push(current.val);
        current = current.right;
      }
    }
  }

  return result;
}

迭代法执行过程：

以 root = [1, null, 2, 3] 为例：

步骤 current stack result 动作
1 1 [] [] 左子树为空，不进内循环
2 1 [1] [] 压入栈
3 null [1] [] current 为空
4 1 [] [1] 弹出 1，记录值
5 2 [] [1] 转向右子树 2
6 3 [2] [1] 沿左走到 3
7 null [2, 3] [1] 左子树为空
8 3 [2] [1, 3] 弹出 3，记录值
9 null [2] [1, 3] 3 无右子树
10 2 [] [1, 3, 2] 弹出 2，记录值

最终返回 [1, 3, 2]。

复杂度分析

方法 时间复杂度 空间复杂度 说明
递归 O(n) O(n) 最坏情况栈深度为 n
迭代 O(n) O(n) 显式栈最坏存储 n 个节点
Morris O(n) O(1) 每条边最多遍历 2 次

时间复杂度分析： 三种方法都需要访问每个节点恰好一次，因此时间复杂度均为 O(n)。Morris 遍历虽然有内层循环寻找前驱节点，但均摊下来每条边最多被访问两次（建立线索和断开线索各一次），总时间仍为 O(n)。

空间复杂度分析： 递归法和迭代法的空间取决于树的高度。平衡二叉树的高度为 O(log n)，退化为链表时高度为 O(n)。Morris 遍历不使用任何额外数据结构，空间为 O(1)，但代价是临时修改了树的结构。

实际选择建议： 面试中通常要求掌握递归和迭代两种写法。迭代法是必须掌握的，因为它是理解栈与递归关系的关键。Morris 遍历作为进阶内容，在需要严格 O(1) 空间时才使用。
