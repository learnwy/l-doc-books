LeetCode 242 有效的字母异位词

题目描述

给定两个字符串 s 和 t，编写一个函数来判断 t 是否是 s 的字母异位词。

字母异位词是指由相同字母重新排列组合而成的单词或短语，每个字母的使用次数都必须相同。

约束条件：

  • 1 <= s.length, t.length <= 5 * 10^4
  • s 和 t 仅包含小写字母

示例 1：

输入：s = "anagram", t = "nagaram"
输出：true

示例 2：

输入：s = "rat", t = "car"
输出：false

进阶： 如果输入字符串包含 Unicode 字符，你将如何调整你的方案？

字母异位词的判断是频次统计的经典应用。本题将深入探讨如何利用哈希表进行字符频次计数，以及在不同约束条件下选择数组还是 Map 作为计数容器。

解题思路

问题本质

两个字符串互为字母异位词，等价于：

  1. 两个字符串长度相同
  2. 每个字符出现的次数完全一致

因此，问题转化为统计并比较两个字符串的字符频次分布。

方法一：排序比较

将两个字符串的字符分别排序，如果排序后的结果相同，则互为字母异位词。这种方法直觉上很自然，但排序的时间复杂度为 O(n log n)。

方法二：频次统计（哈希表）

更高效的做法是使用频次计数数组或哈希表：

  1. 遍历字符串 s，统计每个字符的出现次数（加 1）
  2. 遍历字符串 t，对每个字符的出现次数减 1
  3. 最后检查所有计数是否都为 0

由于题目限定为小写字母（只有 26 种），可以使用长度为 26 的数组替代 Map，性能更佳。

方法 时间复杂度 空间复杂度 适用范围
排序比较 O(n log n) O(n) 通用
频次数组（26位） O(n) O(1) 仅限小写字母
频次 Map O(n) O(k) 支持 Unicode

优化技巧

提前终止： 如果 s.length !== t.length，可以直接返回 false，避免不必要的遍历。

单数组技巧： 不需要两个数组分别统计再比较。只用一个数组，对 s 中的字符加 1，对 t 中的字符减 1。如果最终所有位置都是 0，说明两个字符串的字符频次完全匹配。

中途检测负数： 在遍历 t 的过程中，如果某个字符的计数变为负数，说明 t 中该字符的出现次数超过了 s，可以提前返回 false。

代码实现

频次数组法（推荐）

function isAnagram(s: string, t: string): boolean {
  if (s.length !== t.length) {
    return false;
  }

  const count = new Array<number>(26).fill(0);
  const base = 'a'.charCodeAt(0);

  for (let i = 0; i < s.length; i++) {
    count[s.charCodeAt(i) - base]++;
    count[t.charCodeAt(i) - base]--;
  }

  return count.every((c) => c === 0);
}

Map 法（支持 Unicode）

function isAnagram(s: string, t: string): boolean {
  if (s.length !== t.length) {
    return false;
  }

  const freq = new Map<string, number>();

  for (const ch of s) {
    freq.set(ch, (freq.get(ch) ?? 0) + 1);
  }

  for (const ch of t) {
    const count = freq.get(ch) ?? 0;
    if (count === 0) {
      return false;
    }
    freq.set(ch, count - 1);
  }

  return true;
}

执行过程示例：

以 s = "anagram"、t = "nagaram" 为例（频次数组法）：

步骤 s[i] t[i] count['a'] count['n'] count['g'] count['r'] count['m']
0 a n +1 -1 0 0 0
1 n a 0 0 0 0 0
2 a g +1 0 -1 0 0
3 g a 0 0 0 0 0
4 r r 0 0 0 0 0
5 a a 0 0 0 0 0
6 m m 0 0 0 0 0

最终所有计数为 0，返回 true。

排序法

function isAnagram(s: string, t: string): boolean {
  if (s.length !== t.length) {
    return false;
  }

  return s.split('').sort().join('') === t.split('').sort().join('');
}

复杂度分析

方法 时间复杂度 空间复杂度 说明
频次数组 O(n) O(1) 26 个固定空间，与 n 无关
Map 法 O(n) O(k) k 为不同字符数，最大为 n
排序法 O(n log n) O(n) 排序需要额外空间

时间复杂度分析： 频次数组法只需遍历两个字符串各一次（合并为一次循环），每次操作为 O(1) 的数组访问，总时间 O(n)。最后 every 检查固定 26 个元素，为 O(1)。

空间复杂度分析： 频次数组固定长度 26，不随输入规模增长，因此空间复杂度为 O(1)。Map 法的空间取决于字符种类数 k，当输入为 Unicode 字符时 k 可能很大。

Unicode 扩展思考： 当输入包含 Unicode 字符（如中文、emoji）时，26 位数组不再适用，必须使用 Map。此时 for...of 循环能正确处理 UTF-16 代理对，而 s[i] 索引可能会错误地拆分多字节字符。这是实际开发中需要注意的细节。
