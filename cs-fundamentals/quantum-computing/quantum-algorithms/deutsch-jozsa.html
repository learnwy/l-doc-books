Deutsch-Jozsa 算法

核心概念

Deutsch-Jozsa 算法（1992）是历史上第一个明确显示量子优势的算法——给定一个 oracle f: {0,1}^N → {0,1} 承诺要么 constant（所有输入相同输出）要么 balanced（一半 0 一半 1），quantum 1 次 oracle query 即可判断（经典最坏 2^(N-1) + 1 次）。这是 quantum 算法的"Hello World"——demonstrate 量子并行 + 干涉的核心思想，是 Shor / Grover 等的概念前驱。虽然 Deutsch-Jozsa 不实用（要求 oracle 严格 promise，现实问题没有这种结构），它的电路仅 H + oracle + H + measurement 就 elegant 展示量子优势。本节给出 Deutsch（单 qubit 简化版）、Deutsch-Jozsa（N qubit 推广）、为什么 work、它教给我们的量子算法 design pattern。

维度 经典算法 Deutsch-Jozsa
Oracle queries 最坏 2^(N-1) + 1 仅 1 次
错误率 0（exact） 0（exact）
Promise f constant 或 balanced 同上
实用 一般 不实用（演示用途）
概念意义 - 第一个 quantum 加速

Deutsch's Problem（单 qubit 版）

Setup：

  • Oracle 实现 f: {0, 1} → {0, 1}。
  • f 承诺要么 constant（f(0) = f(1)）要么 balanced（f(0) ≠ f(1)）。
  • 有 4 种可能 f：
    • f(x) = 0（constant 0）。
    • f(x) = 1（constant 1）。
    • f(x) = x（identity, balanced）。
    • f(x) = 1-x（NOT, balanced）。

经典：必须 query f(0) 与 f(1)，2 次 query。

Quantum：1 次。

Deutsch's Algorithm

电路：

q0: |0⟩ ──H──┐         ┌──H──Measure
              │ Oracle U_f│
q1: |1⟩ ──H──┘         └──

步骤：

1. 初始化：

  • q0 = |0⟩（input）。
  • q1 = |1⟩（aux）。

2. H on both：

q0: |+⟩
q1: |-⟩
联合态：|+⟩|-⟩ = (|0⟩+|1⟩)(|0⟩-|1⟩)/2
     = (|00⟩-|01⟩+|10⟩-|11⟩)/2

3. Oracle U_f：

U_f|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩

应用后：

(|0⟩|0⊕f(0)⟩ - |0⟩|1⊕f(0)⟩ + |1⟩|0⊕f(1)⟩ - |1⟩|1⊕f(1)⟩) / 2

Phase kickback（关键 trick）：

|0⊕f(x)⟩ - |1⊕f(x)⟩ = (-1)^f(x) (|0⟩ - |1⟩)

So：

((-1)^f(0)|0⟩ + (-1)^f(1)|1⟩) ⊗ (|0⟩-|1⟩)/√2 / √2

q1 与 q0 解纠缠，q0 现在是 ((-1)^f(0)|0⟩ + (-1)^f(1)|1⟩) / √2。

4. H on q0：

  • 若 f(0) = f(1)（constant）：q0 = ±|+⟩ → H → ±|0⟩。
  • 若 f(0) ≠ f(1)（balanced）：q0 = ±|−⟩ → H → ±|1⟩。

5. 测 q0：

  • 0 → constant。
  • 1 → balanced。

仅 1 次 oracle query——显示量子优势。

Phase Kickback 详细
Phase kickback 是量子算法核心 trick：


    

  • aux qubit 初始为 |-⟩。
    • 

  • Oracle 应用让 input qubit 拿到 (-1)^f(x) 的相位。
    • 

  • aux qubit 不变。
    • 



为什么 work：


U_f|x⟩|-⟩ = |x⟩(|0⊕f(x)⟩ - |1⊕f(x)⟩)/√2
         = (-1)^f(x) |x⟩|-⟩
因为 |0⊕f(x)⟩ - |1⊕f(x)⟩ = (-1)^f(x) (|0⟩-|1⟩)。


意义：


    

  • 把 f 的输出"编码"到 input 的相位。
    • 

  • 后续干涉可"读出"相位信息。
    • 



Deutsch-Jozsa（N qubit 推广）
Setup：


    

  • f: {0,1}^N → {0,1}。
    • 

  • 承诺 constant 或 balanced（半数 input 输出 0，半数输出 1）。
    • 



经典：


    

  • 最坏需 2^(N-1) + 1 次 query 确定。
    • 

  • 例：前 2^(N-1) 次都得 0，第 2^(N-1)+1 次得 0 → constant；得 1 → balanced。
    • 



Quantum：1 次。


Deutsch-Jozsa Circuit
q_0..N-1: |0⟩^N ──H^⊗N──┐         ┌──H^⊗N──Measure
                          │ Oracle  │
aux: |1⟩ ──H──            │         │
                          └─────────┘
步骤：


1. 初始化：


    

  • N input qubit 全 |0⟩。
    • 

  • aux qubit |1⟩。
    • 



2. H^⊗(N+1)：


input：(1/√(2^N)) Σ_x |x⟩
aux：|-⟩
3. Oracle：


U_f|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩
Phase kickback：


(1/√(2^N)) Σ_x (-1)^f(x) |x⟩ ⊗ |-⟩
4. H^⊗N on input：


H^⊗N |x⟩ = (1/√(2^N)) Σ_z (-1)^(x·z) |z⟩
应用：


(1/2^N) Σ_x (-1)^f(x) Σ_z (-1)^(x·z) |z⟩
       = Σ_z [(1/2^N) Σ_x (-1)^(f(x) ⊕ x·z)] |z⟩
5. Measure |0...0⟩：


Amplitude = (1/2^N) Σ_x (-1)^f(x)
    

  • f constant：所有 (-1)^f(x) 同号 → |amplitude| = 1。
    • 

  • f balanced：一半 +1 一半 -1 → 互相抵消 → amplitude = 0。
    • 



结果：


    

  • 测得 |0...0⟩（all zeros）→ constant。
    • 

  • 测得任何其他 → balanced。
    • 



只用 1 次 oracle query！


干涉是关键
Deutsch-Jozsa 的核心：


    

  • Quantum：1 次 oracle 拿到所有 2^N 输入的"相位编码"。
    • 

  • Final H + measure 用干涉读出 global property（constant vs balanced）。
    • 

  • 经典：必须 query 多次个别值，没法利用 global structure。
    • 



Why DJ doesn't 实用：


    

  • 实际问题很少有 strict constant / balanced promise。
    • 

  • 但概念是 Shor / Grover / 各种 oracle 算法的祖先。
    • 



实战 Qiskit
from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister
from qiskit_aer import AerSimulator

def deutsch_jozsa(oracle, n):
    """Run DJ algorithm with n-bit oracle."""
    qc = QuantumCircuit(n + 1, n)

    # Initialize aux to |1>
    qc.x(n)
    qc.h(range(n + 1))

    # Apply oracle
    qc.append(oracle, range(n + 1))

    # H on inputs
    qc.h(range(n))

    # Measure
    qc.measure(range(n), range(n))
    return qc

# Constant-0 oracle
def constant_zero_oracle(n):
    qc = QuantumCircuit(n + 1)
    return qc.to_gate(label='Constant-0')

# Balanced oracle (e.g., f(x) = x_0 XOR x_1)
def balanced_oracle(n):
    qc = QuantumCircuit(n + 1)
    qc.cx(0, n)  # f(x) depends on x_0
    qc.cx(1, n)  # f(x) XOR x_1
    return qc.to_gate(label='Balanced')

# Run
n = 3
qc = deutsch_jozsa(balanced_oracle(n), n)
backend = AerSimulator()
result = backend.run(qc, shots=1).result()
counts = result.get_counts()
# all-zeros → constant; else → balanced
DJ Pattern 在量子算法中的复用
Pattern：


    

  1. Equal superposition over inputs（H^⊗N |0⟩^N）。
    2. 

  2. Oracle 用 phase kickback 编码 function value。
    3. 

  3. Quantum Fourier Transform（H^⊗N 在 binary case）读取 global pattern。
    4. 

  4. Measure → global property。
    5. 



Bernstein-Vazirani (1992)：


    

  • Promise：f(x) = a · x mod 2 for unknown a。
    • 

  • Quantum 1 次 query 找 a。
    • 

  • 经典 N 次。
    • 



Simon's Algorithm (1994)：


    

  • Promise：f(x) = f(y) iff x ⊕ y = s（unknown）。
    • 

  • Quantum O(N) 次 query。
    • 

  • 经典 Ω(2^(N/2))（指数）。
    • 

  • Shor 算法的直接前驱。
    • 



Shor's Algorithm：


    

  • Period finding via QFT（Simon 推广到非二进制）。
    • 

  • 破 RSA。
    • 



量子算法 design 原则
Deutsch-Jozsa 教给我们：


    

  1. 量子并行：H^⊗N 一次生成 2^N input superposition。
    2. 

  2. Phase kickback：oracle 把 function value 编码到 phase。
    3. 

  3. 干涉 + 测量：把 phase 信息提取为 measurable global property。
    4. 

  4. Promise 限制：量子优势通常需要 input 有 structure。
    5. 



没有 promise 的搜索：


    

  • Grover 给 √N 加速（vs 经典 N），不是指数。
    • 

  • 强 promise（如 hidden subgroup）有指数加速（Shor、Simon）。
    • 



局限
1. 不实用：


    

  • 真实问题没有 constant/balanced 严格 promise。
    • 

  • 仅教学价值。
    • 



2. 1 query 是 ideal：


    

  • Noisy hardware 上 single-shot 可能错。
    • 

  • 实战需重复 + majority vote。
    • 



3. 不 generalize 到 NP：


    

  • DJ 是 promise problem，不是 NP-complete。
    • 

  • 量子计算 BQP 与 NP 关系仍 open。
    • 



历史地位
1985 Deutsch's quantum Turing machine paper：


    

  • 提出 quantum computation。
    • 

  • 给出 Deutsch's algorithm（单 qubit）。
    • 



1992 Deutsch-Jozsa：


    

  • 推广到 N qubit。
    • 

  • 第一个明确量子优势的算法。
    • 



1992 Bernstein-Vazirani：


    

  • 同样思路，新 promise（黑 box function）。
    • 



1994 Simon's algorithm：


    

  • 首次 superpolynomial 加速。
    • 

  • 直接启发 Shor。
    • 



1994 Shor's algorithm：


    

  • 破 RSA / 离散对数。
    • 

  • 量子计算最具威胁的算法。
    • 



总结：DJ 是 quantum algorithmic 思想的开端——所有后续重要算法（Shor、Grover、QPE、HHL）都用了类似的"superposition + oracle + interference"pattern。


小结
Deutsch-Jozsa 算法是历史上第一个明确量子优势的算法（1992）——oracle f 承诺 constant 或 balanced 的判断，quantum 1 次 query 经典 2^(N-1)+1 次。Deutsch（单 qubit）电路 H ⊗ H → oracle → H on input → measure，phase kickback 把 (-1)^f(x) 编码到 input phase，最终 H 测到 0 (constant) 或 1 (balanced)。Deutsch-Jozsa（N qubit）相同思路 H^⊗(N+1) → oracle → H^⊗N → measure，测 |0...0⟩ → constant 否则 balanced。Phase kickback 是核心 trick：U_f|x⟩|-⟩ = (-1)^f(x)|x⟩|-⟩。干涉让 oracle 全局结构在 1 query 后可测。Pattern：equal superposition + oracle phase encoding + QFT (H^⊗N) + measure 是 Bernstein-Vazirani / Simon / Shor 共同 DNA。Bernstein-Vazirani 找 hidden a, Simon 找 hidden period（superpolynomial 加速首次），Shor 把 Simon 推广到 RSA factoring。设计原则——量子并行 + phase kickback + 干涉 + promise 限制。局限——不实用 promise、noisy single-shot、不解 NP。历史地位——1985 Deutsch 量子 Turing machine、1992 DJ + BV、1994 Simon + Shor。一个简单的检验：你能解释为什么"DJ 1 次 query 经典 2^(N-1)+1 次"？如果不能，量子并行与干涉的力量还需巩固。Deutsch-Jozsa 是量子算法的"Hello World"——理解它你就理解了所有后续重要算法的概念基础。
