Shor 算法

核心概念

Shor 算法（Peter Shor 1994）是量子计算最具威胁的算法——给定 N = p × q（两大素数乘积），在 O((log N)³) 时间分解 N，破解 RSA / DH / ECC 等几乎所有公钥密码。经典最佳算法（GNFS）是 sub-exponential O(exp((log N)^(1/3) · (log log N)^(2/3)))，2048 bit RSA 经典需 10^15 年，Shor 量子约几小时。Shor 让 post-quantum 密码学（lattice-based、hash-based）成为必须——NIST 2024 年标准化 ML-KEM / ML-DSA。本节给出 Shor 数学（period finding via QFT）、电路实现、为什么破 RSA、需要的 qubit 数（破 2048 RSA ~ 4000 logical qubit）、当前实现 limit（已分解 21 = 3 × 7，未到实战）、post-quantum 应对。

算法 复杂度（factor N） 实战分解 2048-bit
Trial division O(√N) ~ 10^308 年
Pollard rho O(N^(1/4)) ~ 10^154 年
Quadratic sieve O(exp(√(log N · log log N))) ~ 10^25 年
GNFS（最佳经典） O(exp((log N)^(1/3) · (log log N)^(2/3))) ~ 10^15 年
Shor（量子） O((log N)³) ~ 几小时

RSA 与 Factoring

RSA security 依赖 factoring：

  • N = p × q（公开）。
  • φ(N) = (p-1)(q-1)（保密）。
  • 私钥 d = e⁻¹ mod φ(N)。

若可分解 N：

  • 算 φ(N) → 算 d → 解密任意 ciphertext。
  • 即破 RSA。

Shor 让分解从 indeterministic exponential 变 polynomial——RSA 完全失效。

Period Finding

Shor 把 factoring 转化为 period finding：

经典 reduction：

  1. 选随机 a < N，gcd(a, N) = 1。
  2. 找 f(x) = a^x mod N 的 period r（最小 r 使 a^r ≡ 1 mod N）。
  3. 若 r 偶且 a^(r/2) ≢ -1 mod N：
    • p = gcd(a^(r/2) - 1, N), q = gcd(a^(r/2) + 1, N)。
  4. 否则换 a 重试。

关键步骤：找 period r。

  • 经典找 r：sub-exponential。
  • Quantum 找 r：polynomial（用 QFT）。

Quantum Period Finding

Setup：

  • 第一 register：n qubit，n = 2 · log N（够覆盖 r 的精度）。
  • 第二 register：log N qubit。

电路：

|0⟩^n ── H^⊗n ──────● ── QFT⁻¹ ── Measure
                     │
|0⟩ ──────────── U_f ──── (discard or measure)

步骤：

1. Equal superposition on first register：

(1/√(2^n)) Σ_x |x⟩ |0⟩

2. Apply U_f|x⟩|0⟩ = |x⟩|f(x)⟩ where f(x) = a^x mod N：

(1/√(2^n)) Σ_x |x⟩ |a^x mod N⟩

3. Measure second register（optional, but conceptually）：

  • 得到某 y₀，第一 register 塌缩到所有 x 满足 f(x) = y₀。
  • 即 x = x₀, x₀ + r, x₀ + 2r, ... ：
(1/√M) Σ_k |x₀ + kr⟩

4. Apply QFT⁻¹ on first register：

QFT 把 periodic function 转成 inverse period 的 spectrum。结果集中在 multiples of 2^n / r。

5. Measure first register：

  • 得到 c ≈ k · 2^n / r 某 integer k。
  • 用 continued fraction 算法从 c / 2^n 估 r。

6. Verify r：

  • Test a^r ≡ 1 mod N。
  • 若是 → 用 r 算 factor。
Quantum Fourier Transform（QFT）
QFT 是 Shor 算法的"心脏"：


QFT|x⟩ = (1/√N) Σ_y e^(2πixy/N) |y⟩
其中 N = 2^n。


经典 FFT vs QFT：


    

  • FFT：O(N log N) on N classical points。
    • 

  • QFT：O((log N)²) gate on log N qubit（quantum 自然 superposition）。
    • 



电路：


Hadamard + controlled-phase gates。
N = 2^n qubit → ~ n² gate。
意义：


    

  • QFT 找 periodic function 的 period。
    • 

  • 是 Shor 与 quantum phase estimation 共同核心。
    • 



Inverse QFT
Shor 用 QFT⁻¹（forward QFT 是 prepare state、inverse 是 read out）：


    

  • QFT⁻¹|x⟩ = (1/√N) Σ_y e^(-2πixy/N) |y⟩。
    • 

  • 实现：reverse circuit + conjugate phase。
    • 



资源 estimation
破 RSA-2048：


    

  • N ≈ 2^2048。
    • 

  • 需 ~ 2 · 2048 = 4096 qubit（input register）+ 2048 qubit（output）= ~ 6000 logical qubit。
    • 

  • 加 ancilla 等 ~ 4000-5000 logical。
    • 

  • Each logical qubit ≈ 1000 physical qubit (surface code, distance 21)。
    • 

  • 总 ~ 5-20 million physical qubit。
    • 



Gate count：~ 10^11 gate。


Time：


    

  • 每 gate ~ μs（超导）。
    • 

  • ~ 10^5 秒 ≈ 几天。
    • 

  • 需 高 fidelity（> 99.9%）维持 coherence。
    • 



当前 status：


    

  • IBM Heron 1121 qubit、Google 70 qubit、IonQ Forte 64 qubit。
    • 

  • 仅 NISQ 阶段，无 fault-tolerance。
    • 

  • 小规模 Shor demo（21 = 3×7、35 = 5×7）已演示。
    • 

  • 大规模需 2030-2040+。
    • 



当前实验记录
真正 Shor 因子分解记录：


    

  • 15 = 3 × 5（2001 IBM 7 qubit NMR）。
    • 

  • 21 = 3 × 7（2012 IBM）。
    • 

  • 35 = 5 × 7（2018）。
    • 



Compiled Shor（用 simplified circuit）：


    

  • 多个数到 ~ 10000+。
    • 

  • 但简化了 oracle，不算"真 Shor"。
    • 



Hybrid algorithms：


    

  • 小数（~ 2-3 digit）真 Shor 已演示。
    • 

  • 大数仍需要 fault-tolerant + millions qubit。
    • 



Post-Quantum 应对
NIST 2024 年标准化：


ML-KEM（Module-Lattice-based Key Encapsulation Mechanism）：


    

  • 基于 LWE（Learning With Errors）。
    • 

  • Lattice-based。
    • 

  • 替代 RSA / ECC key exchange。
    • 



ML-DSA（Module-Lattice-based Digital Signature）：


    

  • 替代 RSA / ECDSA 签名。
    • 



其他候选：


    

  • Hash-based signatures（XMSS, SPHINCS+）：基于 hash。
    • 

  • Code-based（Classic McEliece）：基于 error-correcting codes。
    • 

  • Multivariate（HFE）：基于多元方程。
    • 

  • Isogeny-based（SIKE）：2022 被 break，弃用。
    • 



Hybrid 部署：


    

  • TLS 1.3 hybrid X25519 + ML-KEM。
    • 

  • Cloudflare、Google Chrome 2024 起。
    • 

  • 转 transition 5-10 年。
    • 



Why Shor Works（直觉）
经典 period finding 慢：


    

  • 必须 sample f(x) 多次找 period。
    • 

  • f 是 expensive 计算（big modular exponentiation）。
    • 

  • 经典 period finding 不存在 polynomial 算法（除特殊结构 like Shor 的 multiplicative）。
    • 



Quantum 优势：


    

  • 一次 superposition encode 所有 x 的 f(x)。
    • 

  • QFT 提取 period information from periodic structure。
    • 

  • 量子 Fourier 干涉让 period 自然 emerge。
    • 



深层原因：


    

  • Period finding 是 abelian Hidden Subgroup Problem 特例。
    • 

  • Quantum 对 abelian HSP 有 polynomial 算法。
    • 

  • 不仅 factoring，还破 discrete log（DH, ECC）。
    • 



Shor 破 ECC 与 DH
Shor 同样破 ECC：


    

  • 用 ECDLP version of Shor。
    • 

  • 256 bit ECC ≈ 2300 logical qubit（比 RSA 少）。
    • 

  • 实战上 ECC 比 RSA 先破。
    • 



Shor 破 Diffie-Hellman：


    

  • 同样 discrete log 问题。
    • 

  • DH 与 ECDH 同 vulnerable。
    • 



TLS 1.3 完全 vulnerable：


    

  • key exchange（X25519）→ 破。
    • 

  • Cert signature（RSA / ECDSA）→ 破。
    • 

  • 整个 TLS 框架失效。
    • 



对策：


    

  • 切 post-quantum cipher suite。
    • 

  • ML-KEM + ML-DSA 替代。
    • 



"Harvest Now, Decrypt Later"
威胁场景：


    

  • 现在 NSA / 国家 actor 大量记录加密流量。
    • 

  • 等 2030-2040 fault-tolerant quantum 出现。
    • 

  • 解密所有过去通讯。
    • 



应对：


    

  • 立即 transition 到 post-quantum。
    • 

  • 不要等到 quantum 实战时。
    • 

  • 长期保密数据（医疗、金融）特别紧迫。
    • 



实战 Qiskit Shor
from qiskit_algorithms import Shor
from qiskit.primitives import Sampler

# Note: 实战 Shor 在 IBM hardware 受限（仅小数）
shor = Shor()
result = shor.factor(N=15)
print(result.factors)  # [3, 5]
注意：库 implementation 通常 simplified for demo——真 Shor for large N 需要 fault-tolerant hardware。


时间表预测
2025-2030：


    

  • NISQ improve（1000-10000 qubit, fidelity 99.9%）。
    • 

  • Logical qubit demo（~ 10-100 logical）。
    • 

  • Hybrid algorithms 实战（VQE、QAOA）。
    • 



2030-2035：


    

  • 早期 fault-tolerant（100-1000 logical qubit）。
    • 

  • Small-scale Shor real（256-bit ECC?）。
    • 



2035-2045：


    

  • Large-scale FTQC（millions physical, 1000+ logical）。
    • 

  • 破 RSA-2048。
    • 

  • Post-quantum 必须完成 transition。
    • 



不确定性
"Y2Q"（Years to Quantum）：


    

  • 估计 2035-2045 破 RSA。
    • 

  • 但有 hidden quantum advance 可能加速。
    • 

  • 也可能慢（hardware 难度低估）。
    • 



安全 margin：


    

  • NIST 建议 2030 前完成 post-quantum transition。
    • 

  • Critical infrastructure（CA、关键基础设施）更紧迫。
    • 



小结
Shor 算法（1994）是量子计算最具威胁的算法——polynomial 时间分解大整数破 RSA / DH / ECC。把 factoring 转 period finding：随机选 a，找 f(x) = a^x mod N 的 period r，若 r 偶且 a^(r/2) ≢ -1，则 p = gcd(a^(r/2) - 1, N), q = gcd(a^(r/2) + 1, N)。Period finding 用 QFT——superposition 所有 x 的 f(x)，QFT⁻¹ 提取 period 信息，continued fraction 算 r。QFT 是 quantum 版 FFT，O((log N)²) gate。资源——破 RSA-2048 需 ~ 4000 logical qubit、~ 5-20M physical qubit (surface code)、~ 10^11 gate、~ 几天。当前 record：21 = 3×7 真 Shor，大数需 fault-tolerant 2030-2040+。Post-quantum：NIST 2024 标准化 ML-KEM（lattice key exchange）+ ML-DSA（lattice signature），hash-based / code-based / multivariate 候选。Hybrid 部署 X25519 + ML-KEM 已在 TLS 1.3。Shor 破 ECC（~ 2300 logical qubit, 比 RSA 少）+ DH，TLS 1.3 完全 vulnerable。Why Shor works：abelian Hidden Subgroup Problem 量子有 polynomial 算法。"Harvest Now, Decrypt Later"威胁——记录加密流量等量子破——长期保密数据（医疗、金融）紧迫 transition。Timeline——2025-2030 NISQ improve、2030-2035 早期 FTQC、2035-2045 大规模 + RSA broken。NIST 建议 2030 前 post-quantum transition。一个简单的检验：你能解释 Shor 算法把 factoring 转 period finding 的核心 step？如果不能，period finding 数学还需巩固。Shor 是量子计算最大 implication——让密码学历史划分 pre-Shor / post-Shor era，post-quantum migration 是 next decade 的安全工作 priority。
