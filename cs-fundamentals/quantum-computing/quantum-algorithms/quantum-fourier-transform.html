量子傅里叶变换

核心概念

Quantum Fourier Transform（QFT）是 Discrete Fourier Transform（DFT）的量子推广——把 N qubit superposition 状态 (1/√N) Σ_x α_x |x⟩ 变换为 (1/√N) Σ_y β_y |y⟩，其中 β_y 是 α_x 的 DFT。它是 Shor 算法的"心脏"（period finding）、Quantum Phase Estimation（QPE）的核心、HHL 线性方程组求解的关键工具。QFT 极快——经典 FFT 是 O(N log N)，QFT 是 O((log N)²) gate（in qubit space）——quantum 提供 exponential speedup（对 amplitude representation）。但 QFT 不能直接"读出"DFT result——只能在 superposition 上操作。本节介绍 QFT 数学、电路构造、为什么快、应用、limitation。

维度 DFT (Classical FFT) QFT (Quantum)
复杂度 O(N log N) O((log N)²) gate
Input N classical numbers N-qubit superposition
Output N classical numbers N-qubit superposition
直接读取 是 否（必须 measure）
应用 信号处理、压缩 Shor、QPE、HHL

DFT 与 QFT 数学

Classical DFT：

y_k = (1/√N) Σ_(j=0)^(N-1) x_j · e^(2πijk/N)

把 length-N 复数序列变换到 frequency domain。

QFT：把上式作用在 quantum amplitude：

QFT |j⟩ = (1/√N) Σ_(k=0)^(N-1) e^(2πijk/N) |k⟩

线性扩展到 superposition：

QFT (Σ_j α_j |j⟩) = Σ_k β_k |k⟩
where β_k = (1/√N) Σ_j α_j e^(2πijk/N)

关键：

  • QFT 把 amplitude 中 "frequency component" 提取出来。
  • Periodic state 经 QFT 集中到 inverse-period 位置。

QFT 电路

N = 2^n（n qubit）的 QFT 电路：

Step 1：Apply H to qubit 0。

Step 2：Apply controlled-R_2, R_3, ..., R_n where target = qubit 0, control 是 qubit 1, 2, ..., n-1。

R_k = ⎡1 0       ⎤
      ⎣0 e^(2πi/2^k)⎦

Step 3：Apply H to qubit 1, then controlled-R2, ..., R(n-1)。

Step 4：依次到 qubit n-1。

Step 5：Reverse qubit order（用 SWAP 或 relabel）。

Gate count：

  • n H gate。
  • n(n-1)/2 controlled-rotation gates。
  • n/2 SWAP（或 0 if relabel）。
  • 总 O(n²)。
QFT 为什么 O((log N)²)
Recursive structure：


    

  • QFTN 可分解为 QFT(N/2) on first n-1 qubit + Hadamard + controlled-rotations。
    • 

  • 类似 FFT 的 divide-and-conquer。
    • 



Quantum advantage：


    

  • Classical FFT operates on N classical numbers → O(N log N)。
    • 

  • QFT operates on N amplitudes (superposition over n = log N qubit) → O(n²) gate。
    • 

  • Exponential speedup in gate count vs classical（但 quantum amplitude 不能直接读）。
    • 



实战：


    

  • 256 qubit QFT ~ 32768 gate。
    • 

  • 1000 qubit QFT ~ 500k gate。
    • 



QFT 与 Phase Estimation
Phase estimation：给 unitary U 与 eigenstate |u⟩ (U|u⟩ = e^(2πiφ)|u⟩)，估 φ。


QPE 算法：


    

  1. 准备 n qubit |0⟩^n + auxiliary |u⟩。
    2. 

  2. Apply H^⊗n on first register。
    3. 

  3. Apply controlled-U^(2^j) (control = qubit j of first register)。
    4. 

  4. Apply QFT⁻¹ on first register。
    5. 

  5. Measure → get integer ≈ 2^n · φ。
    6. 



精度：n qubit 给 n-bit 精度的 φ。


用途：


    

  • Shor 算法（period finding）。
    • 

  • 量子化学（找 molecular Hamiltonian eigenvalue）。
    • 

  • Linear systems（HHL）。
    • 



QFT 与 Shor
Shor 用 QFT 找 period r of f(x) = a^x mod N：


    

  • Setup: superposition Σ_x |x⟩|f(x)⟩。
    • 

  • Measure second register → first register 塌缩到 periodic Σ_k |x_0 + kr⟩。
    • 

  • QFT⁻¹ → spike at multiples of N/r。
    • 

  • Measure → find r via continued fraction。
    • 



QFT 是 Shor "polynomial time" 的关键 step。


QFT 与 HHL
HHL 算法（Harrow, Hassidim, Lloyd 2009）：


    

  • 解 Ax = b 给 x（A 稀疏）。
    • 

  • 经典 O(N^3)（一般 sparse O(N · κ²)）。
    • 

  • HHL: O(log N · κ² · 1/ε) (quantum)。
    • 

  • 用 phase estimation + QFT。
    • 



Caveat：


    

  • 不能完整读 x（输出 quantum state）。
    • 

  • 只能 query x 的 expectation（如 ⟨x|M|x⟩）。
    • 

  • 实战 limit。
    • 



QFT 与 BV 算法
Bernstein-Vazirani：


    

  • 用 QFT in disguise（H^⊗N is QFT for binary case）。
    • 

  • Promise f(x) = a · x，找 a。
    • 

  • Quantum 1 query。
    • 



Approximate QFT (AQFT)
问题：QFT 用 controlled-R_k where R_k 是 small-angle rotation（~ 2π / 2^k）。


    

  • Small angle gate 实现误差大。
    • 

  • Total error 累积。
    • 



AQFT：


    

  • 截断小 angle gate（drop k > threshold）。
    • 

  • 误差 bounded。
    • 

  • O(n log n) gate（更少）。
    • 



实战：


    

  • Approximate QFT 在 NISQ 上更可行。
    • 

  • 多数应用 AQFT 已 sufficient。
    • 



QFT 与 quantum walks
Quantum walk：quantum 版 random walk，用 QFT 在某些 graph 上提供 exponential 加速。


应用：


    

  • Element distinctness。
    • 

  • Graph search。
    • 

  • Quantum simulation。
    • 



实战 Qiskit
from qiskit import QuantumCircuit
from qiskit.circuit.library import QFT

# 4-qubit QFT
qc = QuantumCircuit(4)
qc.append(QFT(4, do_swaps=True), range(4))

# QFT on input state
qc_full = QuantumCircuit(4, 4)
qc_full.h([0, 1])  # 准备某 input
qc_full.append(QFT(4), range(4))
qc_full.measure_all()
QFT 限制
1. 不能直接读取 DFT result：


    

  • Classical FFT 输出 N 个 number 直接 access。
    • 

  • QFT 输出 superposition——measure 只得 1 个 outcome。
    • 

  • 必须 algorithm 结构利用 QFT amplitude pattern（如 phase estimation 提取 frequency）。
    • 



2. Input 准备：


    

  • DFT input 是 classical data（free）。
    • 

  • QFT input 必须是 quantum superposition——准备 itself 可能 expensive。
    • 

  • 例：把 2^n classical number 加载到 n qubit amplitude → 用 QRAM（仍研究阶段）。
    • 



3. Output 提取：


    

  • Measure 得 sample from |amplitude|²。
    • 

  • 提取 specific frequency 需多 shot。
    • 



因此：


    

  • QFT 的 exponential speedup 仅在 quantum-quantum 流水线（如 Shor）显现。
    • 

  • Classical input + classical output 的 FFT 任务，量子 dominate 只在特殊 promise 下。
    • 



QFT vs DFT 比较
速度：


    

  • QFT：O(n²) gate, n = log N。
    • 

  • DFT (FFT)：O(N log N) operation。
    • 

  • QFT 指数快 in gate count。
    • 



适用：


    

  • DFT：信号处理（音频、图像）、数据压缩。
    • 

  • QFT：量子算法（Shor、QPE、HHL）。
    • 



互通性：


    

  • DFT 输出可分析；QFT 输出仅 quantum state。
    • 

  • QFT 不替代 FFT 在 classical 任务上。
    • 



QFT 在量子化学
Phase estimation 在 chemistry：


    

  • 模拟分子 Hamiltonian e^(-iHt)。
    • 

  • QPE 估 H 的 eigenvalue → ground state energy。
    • 

  • 分子设计、催化剂、药物——量子化学是 quantum 早期 killer app。
    • 



资源需求：


    

  • 大分子（~ 100 atom）需 ~ 1000 qubit + fault-tolerance。
    • 

  • 仍 future。
    • 



QFT 在 quantum machine learning
HHL-based ML：


    

  • Linear regression、PCA、SVM 用 HHL。
    • 

  • 理论 exponential speedup。
    • 

  • 但 input/output 限制让实战 unclear。
    • 



Quantum kernel methods：


    

  • Use QFT for feature mapping。
    • 

  • 仍研究阶段。
    • 



历史 milestones
1985：Coppersmith 给出第一个 quantum FT-like 算法。


1994：Shor 算法 use QFT（first major use）。


1995：Cleve, Ekert, Macchiavello, Mosca 形式化 phase estimation。


1995：Coppersmith 系统化 QFT 算法。


2009：HHL 算法（QFT 间接 via phase estimation）。


2010s- various quantum walks、estimation algorithms 用 QFT。


小结
QFT 是 DFT 的 quantum 推广——QFT|j⟩ = (1/√N) Σ_k e^(2πijk/N)|k⟩，N = 2^n。线性扩展到 superposition 把 amplitude 中 frequency component 提取。电路 O(n²) gate（n H gate + n(n-1)/2 controlled-rotation + qubit reverse SWAP）。Recursive structure 类似 FFT divide-and-conquer，gate count O((log N)²) vs classical O(N log N)，exponential speedup in gate count。Phase Estimation（QPE）：用 QFT⁻¹ 估 unitary eigenvalue φ，n qubit 给 n-bit 精度，是 Shor / chemistry simulation / HHL 核心。Shor 用 QFT 找 period r。HHL 解 Ax = b 用 phase estimation + QFT，O(log N · κ² · 1/ε)，但 input/output limit 实战 unclear。Approximate QFT 截断 small-angle gate，O(n log n) 更适 NISQ。Quantum walks 用 QFT 在 graph 上 exponential 加速。Qiskit QFT library available。限制——不能直接读取 DFT result（output 是 superposition）、input 准备 expensive（QRAM 未成熟）、output 提取 sample-based。QFT vs DFT——QFT 指数 gate 加速但 classical 任务上 FFT 仍 dominant；QFT 在 quantum-quantum pipeline (Shor) 优势显著。Chemistry 中 phase estimation 估 molecular Hamiltonian eigenvalue（ground state energy），分子设计 / 药物 killer app 需 fault-tolerance。Quantum ML（HHL-based）理论加速但实战 unclear。一个简单的检验：你能解释为什么 "QFT exponential 快但实战 doesn't 替代 FFT"？如果不能，input/output 限制还需巩固。QFT 是量子算法的"通用工具"——理解它是后续 Shor / QPE / HHL / 量子化学 / 量子 ML 的钥匙。
