Grover 算法

核心概念

Grover 算法（Lov Grover 1996）是量子计算的"通用搜索加速"——给 N item unstructured database 与 oracle 标记 target，quantum 用 O(√N) 次 oracle query 找 target，经典最差 O(N)。这是 quadratic speedup（vs Shor 的 exponential）——破对称密码（AES-128 → 2^64 attack）但不破公钥密码本身。Grover 是 amplitude amplification 的 specialization——把 amplitude amplification 的 general framework 简化到搜索问题。本节给出 Grover 算法、电路、为什么 √N、应用（密码破解、optimization、SAT solver）、limit（不能做 P = NP）。

维度 经典搜索 Grover
复杂度 O(N) O(√N)
对称密码 brute 2^N 2^(N/2)（攻击）
适用 任何 search 必须 oracle
Promise 无 unstructured
加速 - 平方

Grover 解决的问题

Setup：

  • N 个 item（label 0 到 N-1）。
  • Oracle f(x) = 1 if x 是 target，0 otherwise。
  • 假设 1 个（或 M 个）target。

经典：

  • 平均 N/2 次 query。
  • 最差 N 次。

Grover：

  • O(√N) 次 query。
  • 高概率（→ 1）找到 target。

意义：

  • 破 AES-128 brute force 从 2^128 到 2^64。
  • AES-256 → 2^128（仍强）。
  • 推荐 post-quantum AES-256。

Grover 电路

|0⟩^n ── H^⊗n ──┐──┐──...──┐── Measure
                 │   │       │
              Oracle│       │
                  Diffuser  Diffuser

重复 √N 次

步骤：

1. 初始化 + H^⊗n：

|s⟩ = (1/√N) Σ_x |x⟩ = equal superposition

2. Grover iteration（重复 ~ π/4 · √N 次）：

  • Oracle（mark target）：

    O|x⟩ = (-1)^f(x) |x⟩

    即 target 拿 -1 phase。

  • Diffuser（reflect about average）：

    D = 2|s⟩⟨s| - I

    把 amplitude 翻转 around mean。

3. Measure：高概率 (→ 1) 测得 target。

Geometric 直觉
双 vector 视角：


    

  • |target⟩ = target 的 superposition。
    • 

  • |s⟩ = equal superposition（initial）。
    • 

  • 它们 span 一 2D 平面。
    • 



初始：|s⟩ 与 |target⟩ 角度 ~ π/2 - 1/√N。


每个 Grover iteration：


    

  • Oracle：reflect across hyperplane orthogonal to |target⟩（即 |non-target⟩）。
    • 

  • Diffuser：reflect across |s⟩。
    • 

  • 两次 reflect = rotation by 2θ where sin(θ) = 1/√N。
    • 



经过 k iteration：rotation by 2kθ。


目标 rotation：到 |target⟩，需 (π/2 - θ) / (2θ) ≈ π/(4θ) ≈ π · √N / 4 iteration。


最大 amplitude：sin((2k+1)θ) ≈ 1 when 2k+1 = π/(2θ) → k ≈ π√N/4。


注意：Grover 不能 over-rotate——超过最优 iteration 数 amplitude 减小。必须用近似 √N 次。


Multiple Targets
M targets out of N：


    

  • 最优 iteration 数：~ π/4 · √(N/M)。
    • 

  • 仍是 √N 加速。
    • 



Unknown M：


    

  • Quantum counting algorithm 估 M。
    • 

  • 然后 run optimal Grover。
    • 



为什么不能更快
Lower bound（Bennett, Bernstein, Brassard, Vazirani 1997）：


    

  • 任何 quantum algorithm 找 unstructured target 至少 Ω(√N) query。
    • 

  • 即 Grover 是 optimal。
    • 



意义：


    

  • Quadratic speedup is best possible for unstructured search。
    • 

  • 没有 P = NP via quantum。
    • 

  • 但 structured 问题可能 exponential 加速（Shor）。
    • 



应用
1. 密码破解：


    

  • AES-N：Grover 把暴力 2^N 减到 2^(N/2)。
    • 

  • AES-128 在 quantum 下等价 2^64（弱）。
    • 

  • AES-256 → 2^128（仍强）——post-quantum 推荐。
    • 



2. SAT Solver：


    

  • N 变量 SAT 暴力 2^N。
    • 

  • Grover：2^(N/2)。
    • 

  • 不解 NP，但加速 brute force。
    • 



3. Search Database：


    

  • Unstructured DB 找 record。
    • 

  • 但实战 DB 通常 structured（B-tree、hash）→ 经典 O(log N) 已优。
    • 

  • Grover 实战意义有限。
    • 



4. Collision Finding：


    

  • Find x ≠ y with f(x) = f(y)。
    • 

  • BHT 算法（Brassard, Høyer, Tapp）：O(N^(1/3))。
    • 

  • 比 generic Grover 更优。
    • 



5. Mean / Min Estimation：


    

  • Quantum amplitude estimation 给 √N 加速。
    • 



6. Optimization：


    

  • Grover-based metaheuristic for combinatorial optimization。
    • 

  • 与 QAOA 互补。
    • 



Amplitude Amplification
Generalization of Grover：


    

  • A：preparation algorithm（不一定 H^⊗N）。
    • 

  • f：success criterion。
    • 

  • Goal：amplify success amplitude。
    • 



算法：


    

  • 初始 A|0⟩ = sin(θ)|good⟩ + cos(θ)|bad⟩。
    • 

  • Each iteration rotate 2θ。
    • 

  • O(1/sin(θ)) iteration 收敛到 |good⟩。
    • 



意义：


    

  • 任何"低成功率"算法可被 amplitude amplification 加速。
    • 

  • Grover 是特例 sin(θ) = 1/√N。
    • 



实战 Qiskit Grover
from qiskit_algorithms import Grover, AmplificationProblem
from qiskit.primitives import Sampler
from qiskit.circuit.library import PhaseOracle

# Define 3-bit oracle: target = 101
oracle = PhaseOracle('a & ~b & c')

problem = AmplificationProblem(oracle, is_good_state=['101'])
grover = Grover(sampler=Sampler())
result = grover.amplify(problem)
print(result.top_measurement)  # '101'
Grover 在 NISQ 限制
Noise sensitivity：


    

  • Grover 需要多 iteration（√N）。
    • 

  • 每 iteration noise accumulate。
    • 

  • 大 N 下 noise 吞掉 √N 优势。
    • 



Practical N：


    

  • NISQ 上 N ~ 100-1000 demo。
    • 

  • 真实 cryptography break N = 2^128 需 fault-tolerant。
    • 



与经典 hybrid：


    

  • Quantum 用于 inner loop。
    • 

  • Classical drive outer loop。
    • 



Grover 的 limit
1. 仅 quadratic 加速：


    

  • 不解 NP-complete in P。
    • 

  • 仅"加速"暴力 search。
    • 



2. 必须 oracle：


    

  • 实战 oracle 是 expensive computation（如 AES decryption）。
    • 

  • 总 cost = √N × oracle_cost——可能仍 prohibitive。
    • 



3. 非 reversible 部分难：


    

  • Oracle 必须 unitary。
    • 

  • 经典 algorithm 转 reversible 需 ancilla qubit。
    • 



4. Distinguishing single target from no target：


    

  • 若不知道是否有 target，需 amplitude estimation。
    •

关键：


    

  • 已 structured 的搜索（hash、B-tree）quantum 没优势。
    •

    • 



Grover 在 cryptography
对称密码：


    

  • AES-128 → 2^64（弱，需 AES-256）。
    • 

  • AES-256 → 2^128（仍强）。
    • 

  • ChaCha20-256 → 2^128（仍强）。
    • 

  • SHA-256 抗 collision 2^128 → 2^85（生日 + Grover）→ 仍强。
    • 



Hash function：


    

  • Pre-image：2^N → 2^(N/2)。
    • 

  • Collision：2^(N/2) → 2^(N/3)（BHT）。
    • 



post-quantum 推荐：


    

  • 对称：≥ 256 bit。
    • 

  • Hash：≥ 384 bit。
    • 

  • 公钥：lattice-based / hash-based。
    • 



历史 milestone
1996 Grover paper：Lov Grover 提出。


1997 Optimal lower bound：BBBV 证明 Grover 是 optimal。


1998 Brassard et al amplitude amplification：generalize Grover。


2000- experimental demos NMR、ion trap、photonics。


2024+ NISQ 上 small Grover 普遍。


小结
Grover 算法（1996）是 unstructured search quantum 加速——N item oracle，O(√N) query 找 target，vs 经典 O(N)。Quadratic（不是 exponential）加速。电路：H^⊗N initial → repeat (Oracle phase + Diffuser) ~ π/4 √N 次 → measure。Geometric 视角：|s⟩ 与 |target⟩ 在 2D 平面，每 iteration rotate 2θ where sin(θ) = 1/√N，π/(4θ) iteration 到 target。不能 over-rotate——必须近似 √N 次。Multiple M targets：iteration ~ √(N/M)。BBV 1997 lower bound Ω(√N)——Grover optimal。应用——AES brute（128→64、256→128）、SAT solver brute、collision finding（BHT N^(1/3)）、optimization、amplitude estimation。Amplitude amplification 是 Grover generalization——任何低成功率算法可加速。NISQ 限制——noise accumulate over √N iteration，N~100-1000 demo，真实 cryptography break 需 fault-tolerant。Grover 仅对 unstructured 有效（已 structured 如 hash、B-tree quantum 无优势）。post-quantum 对称密码 ≥ 256 bit、hash ≥ 384 bit。一个简单的检验：你能解释为什么"AES-256 在 Grover 下仍强但 AES-128 弱"？如果不能，quadratic speedup 与 effective key length 还需巩固。Grover 是 quantum 计算第二重要算法（仅次 Shor）——quadratic speedup 让对称密码必须 double key length，post-quantum era 必须考虑。
