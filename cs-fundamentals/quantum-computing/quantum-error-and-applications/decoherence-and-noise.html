Part I · 理论基础 (Theory)量子计算量子纠错与应用退相干与噪声

退相干与噪声

核心概念

退相干（Decoherence）是量子计算面临的最大工程挑战——量子比特与环境（电磁场、声子、宇宙射线、其他量子比特）之间不可避免的相互作用导致叠加态与纠缠态在微秒级时间内丢失。这不是"软件漏洞"，而是基础物理现象——量子态的脆弱性与经典比特的鲁棒性形成鲜明对比。退相干由 T1T_1T1​（振幅阻尼，能量损失）与 T2T_2T2​（退相位，相位损失）表征，且 T2≤2T1T_2 \leq 2T_1T2​≤2T1​。当代超导量子比特的 T1T_1T1​ 约 100 微秒，囚禁离子量子比特的 T1T_1T1​ 达秒级。这些短暂的相干时间限制了电路深度——只有量子纠错（QEC）才使大规模容错计算成为可能。本节介绍噪声类型、克劳斯算符数学、T1T_1T1​ 与 T2T_2T2​ 测量、基准测试协议（随机基准测试、量子体积）以及缓解技术。

噪声类型 物理来源 时间尺度 缓解方法
T₁ 弛豫 能量耗散到热库 50-200μs 硬件改进
T₂ 退相位 1/f 噪声、电荷噪声 < 2T₁ 回波、动力学解耦
门误差 控制不完美 0.1%-1% 校准

量子噪声数学

密度矩阵演化：

  • 封闭系统：ρ→UρU†\rho \to U\rho U^\daggerρ→UρU†（幺正演化）。
  • 开放系统：与环境纠缠 → 等效噪声信道。

克劳斯算符：

  • 噪声信道 ε(ρ)=∑kKkρKk†\varepsilon(\rho) = \sum_k K_k \rho K_k^\daggerε(ρ)=∑k​Kk​ρKk†​。
  • ∑kKk†Kk=I\sum_k K_k^\dagger K_k = I∑k​Kk†​Kk​=I（保迹条件）。
  • 多个 KKK 描述不同的噪声结果。

示例：比特翻转信道：

  • K0=1−p⋅IK_0 = \sqrt{1-p} \cdot IK0​=1−p​⋅I, K1=p⋅XK_1 = \sqrt{p} \cdot XK1​=p​⋅X。
  • 概率 ppp 翻转 ∣0⟩↔∣1⟩|0\rangle \leftrightarrow |1\rangle∣0⟩↔∣1⟩。

示例：退相位信道：

  • K0=1−p⋅IK_0 = \sqrt{1-p} \cdot IK0​=1−p​⋅I, K1=p⋅ZK_1 = \sqrt{p} \cdot ZK1​=p​⋅Z。
  • 概率 ppp 添加 ZZZ 相位。

示例：去极化信道：

  • ρ→(1−p)ρ+p⋅I/d\rho \to (1-p) \rho + p \cdot I/dρ→(1−p)ρ+p⋅I/d。
  • ddd 维希尔伯特空间。

T₁ 弛豫

T₁：能量从 ∣1⟩|1\rangle∣1⟩ 衰减到 ∣0⟩|0\rangle∣0⟩ 的特征时间。

振幅阻尼信道：

  • ∣1⟩→∣0⟩|1\rangle \to |0\rangle∣1⟩→∣0⟩，概率 γ=1−e−t/T1\gamma = 1 - e^{-t/T_1}γ=1−e−t/T1​。

布洛赫球：

  • 矢量在 zzz 方向收缩到 +z+z+z（北极）。

测量方法：

  • 准备 ∣1⟩|1\rangle∣1⟩ 态。
  • 等待时间 ttt。
  • 测量。
  • P(∣1⟩)=e−t/T1P(|1\rangle) = e^{-t/T_1}P(∣1⟩)=e−t/T1​。
  • 拟合指数衰减得到 T1T_1T1​。

当代典型值：

  • 超导：50-200μs。
  • 囚禁离子：> 1s。
  • 拓扑：理论上更长（尚未实现）。

T₂ 退相位

T₂：相位相干性衰减时间。

纯退相位信道：

  • ∣+⟩→|+\rangle \to∣+⟩→ 混合态，非对角元衰减 e−t/T2e^{-t/T_2}e−t/T2​。

布洛赫球：

  • 矢量在 xyxyxy 平面收缩到 zzz 轴。
  • 失去相位信息。

关系：

  • T2≤2T1T_2 \leq 2T_1T2​≤2T1​（数学定理）。
  • 通常 T2<T1T_2 < T_1T2​<T1​。

T₂ 与 T₂*：

  • T2∗T_2^*T2∗​：包含准静态噪声（低频）。
  • T2T_2T2​：用自旋回波消除准静态噪声后。
  • 通常 T2>T2∗T_2 > T_2^*T2​>T2∗​。

测量方法：

  • 哈恩回波：H 门，等待 t/2t/2t/2，X 门，等待 t/2t/2t/2，H 门，测量。
  • 拟合 e−t/T2e^{-t/T_2}e−t/T2​。
门误差
单量子比特门保真度：


    

  • 现代超导：99.9%+。
    • 

  • 囚禁离子：99.99%+。
    • 



双量子比特门保真度：


    

  • IBM CNOT：99.5%。
    • 

  • Google √iSWAP：99.7%。
    • 

  • Quantinuum 囚禁离子：99.96%。
    • 



误差来源：


    

  • 校准漂移。
    • 

  • 相干误差（系统性相位）。
    • 

  • 非相干误差（与噪声耦合）。
    • 

  • 串扰（相邻量子比特）。
    • 



阈值定理：容错计算要求门误差 < ~1%（表面码）。现代硬件已超过此阈值。


读出误差
测量不完美：


    

  • 准备 ∣0⟩|0\rangle∣0⟩，测量 → 报告 ∣1⟩|1\rangle∣1⟩ 的概率约 1-3%。
    • 

  • 反之亦然。
    • 



混淆矩阵：


M = ⎡P(0|0) P(0|1)⎤
    ⎣P(1|0) P(1|1)⎦
缓解方法：


    

  • 用校准矩阵 M−1M^{-1}M−1 校正原始计数。
    • 

  • 更好的硬件（量子非破坏测量）。
    • 



相干误差与非相干误差
相干误差：


    

  • 系统性的、幺正的。
    • 

  • 例：Rx(0.99π)R_x(0.99\pi)Rx​(0.99π) 而非 Rx(π)R_x(\pi)Rx​(π)。
    • 

  • 会累积——可能恶化。
    • 

  • 但可通过反向系统性误差抵消。
    • 



非相干误差：


    

  • 随机的，与环境混合。
    • 

  • 例：T1T_1T1​ 衰减。
    • 

  • 无法用幺正操作消除。
    • 

  • 必须用量子纠错。
    • 



重要区别：


    

  • 总保真度 = 1 - 误差率。
    • 

  • 相干误差可检测与修复。
    • 

  • 非相干误差是根本限制。
    • 



泡利旋转
技巧：把相干误差转化为随机泡利误差。


方法：


    

  • 每个门前后施加随机泡利门。
    • 

  • 在多次电路执行上平均。
    • 

  • 相干误差平均为去极化信道。
    • 



意义：


    

  • 简化误差模型（更易分析）。
    • 

  • 使量子纠错模拟更准确。
    • 

  • 随机编译在实战中使用。
    • 



随机基准测试
目标：估计平均门误差。


协议：


    

  1. 选择长度 mmm 的随机克利福德序列。
    2. 

  2. 末尾施加逆克利福德（使总幺正 = III）。
    3. 

  3. 测量。
    4. 

  4. 对多个序列和长度重复。
    5. 

  5. 拟合衰减曲线 Pm=A⋅pm+BP_m = A \cdot p^m + BPm​=A⋅pm+B。
    6. 

  6. 每门平均误差 r=(1−p)(d−1)/dr = (1 - p)(d-1)/dr=(1−p)(d−1)/d。
    7. 



优势：


    

  • 不依赖状态制备与测量误差（SPAM）。
    • 

  • 给出鲁棒的门误差估计。
    • 



量子体积（QV）
IBM 提出的整体基准测试：


    

  • 运行方形电路（深度 = 宽度 = NNN）。
    • 

  • 随机双量子比特门。
    • 

  • 比较量子输出分布与理论值。
    • 

  • 若硬件通过 NNN，则 QV = 2N2^N2N。
    • 



当代典型值：


    

  • IBM Heron 2024：QV 1024（相当于 10 量子比特）。
    • 

  • 比原始量子比特数更有意义。
    • 



串扰
串扰：在量子比特 A 上施加门影响量子比特 B。


来源：


    

  • 微波耦合。
    • 

  • 频率接近。
    • 



缓解方法：


    

  • 频率分配。
    • 

  • 旁观量子比特解耦。
    • 

  • 更好的硬件设计。
    • 



宇宙射线
问题：高能粒子（宇宙射线、放射性背景）击中芯片：


    

  • 在超导量子比特中产生准粒子。
    • 

  • 多量子比特误差相关（破坏量子纠错假设）。
    • 



缓解方法：


    

  • 地下实验室（减少宇宙射线通量）。
    • 

  • 屏蔽。
    • 

  • 新芯片设计（减少准粒子传播）。
    • 



退相干缓解技术
1. 回波与动力学解耦：


    

  • 周期性施加 X/Y 脉冲抵消低频噪声。
    • 

  • 延长有效 T2T_2T2​。
    • 



2. 无退相干子空间：


    

  • 将逻辑量子比特编码到多量子比特态。
    • 

  • 选择噪声不影响的不量子空间。
    • 



3. 甜点操作：


    

  • 调节量子比特频率到噪声不敏感点。
    • 

  • 例：Transmon 对电荷不敏感。
    • 



4. 主动反馈：


    

  • 电路中间测量 → 条件校正。
    • 



5. 量子纠错：


    

  • 编码逻辑量子比特。
    • 

  • 见下节展开。
    • 



误差缓解（vs 纠错）
误差缓解（适用于 NISQ）：


    

  • 不增加量子比特开销。
    • 

  • 概率性地减少误差。
    • 

  • 零噪声外推：运行不同噪声级别，外推到零。
    • 

  • 概率性误差抵消。
    • 

  • 对称性验证。
    • 



误差纠错（容错计算）：


    

  • 增加量子比特开销（约 1000 倍）。
    • 

  • 基于阈值指数压低误差。
    • 

  • 见下节。
    • 



NISQ 时代的噪声
特征：


    

  • 有噪声（高门误差 0.1-1%）。
    • 

  • 中等规模（50-1000 量子比特）。
    • 

  • 量子性（仍利用量子效应）。
    • 



实战策略：


    

  • 浅电路（< 100 门）。
    • 

  • 变分算法（VQE、QAOA）。
    • 

  • 噪声感知优化。
    • 

  • 误差缓解。
    • 



不适合 NISQ：


    

  • 深电路（如 Shor 算法）。
    • 

  • 大规模 Grover 搜索。
    • 



实战 Qiskit
from qiskit_aer.noise import NoiseModel, depolarizing_error, thermal_relaxation_error

noise_model = NoiseModel()

# T1, T2
T1 = 100e-6  # 100us
T2 = 80e-6
gate_time = 50e-9  # 50ns
error = thermal_relaxation_error(T1, T2, gate_time)
noise_model.add_all_qubit_quantum_error(error, ['rx', 'ry', 'rz'])

# Gate depolarizing
gate_error = 0.01  # 1%
error = depolarizing_error(gate_error, 1)
noise_model.add_all_qubit_quantum_error(error, ['rx', 'ry', 'rz'])

# Run noisy simulation
backend = AerSimulator(noise_model=noise_model)

小结
退相干是量子计算最大的工程挑战——量子比特与环境纠缠导致叠加态与纠缠态在微秒级内丢失。开放系统的密度矩阵演化用克劳斯算符 ε(ρ)=∑kKkρKk†\varepsilon(\rho) = \sum_k K_k \rho K_k^\daggerε(ρ)=∑k​Kk​ρKk†​ 描述。T1T_1T1​（振幅阻尼）：能量从 ∣1⟩|1\rangle∣1⟩ 衰减到 ∣0⟩|0\rangle∣0⟩，超导 50-200μs、囚禁离子 > 1s。T2T_2T2​（退相位）：相位相干衰减，T2≤2T1T_2 \leq 2T_1T2​≤2T1​。布洛赫球中 T1T_1T1​ 收缩到北极、T2T_2T2​ 收缩到 zzz 轴。门误差现代 99.5-99.96%，单量子比特 > 99.9%。读出误差 1-3%，用混淆矩阵反校准。相干误差（系统性幺正）vs 非相干误差（随机）——前者可抵消，后者必须用 QEC。泡利旋转将相干误差转化为随机泡利误差以简化误差模型。随机基准测试估计平均门误差（不依赖 SPAM）。量子体积是 IBM 提出的整体基准测试（方形随机电路）。串扰（相邻量子比特）通过频率分配减少。宇宙射线导致多量子比特误差相关（破坏 QEC 假设），通过地下实验/屏蔽缓解。缓解技术——回波/动力学解耦、无退相干子空间、甜点操作、主动反馈。误差缓解（适用于 NISQ）vs 纠错（容错计算）——前者零噪声外推/概率性误差抵消不增加量子比特、后者编码逻辑量子比特增加 1000 倍量子比特。NISQ 策略——浅电路、变分算法、噪声感知、误差缓解。Qiskit Aer 支持噪声模型模拟。硬件路线图——IBM 2030 年达百万量子比特、Google Willow 逻辑量子比特演示。一个简单的检验：你能解释为什么 "T2≤2T1T_2 \leq 2T_1T2​≤2T1​"？如果不能，退相位与弛豫的关系还需巩固。退相干是 NISQ 与容错量子计算的分界——理解噪声让算法设计具有噪声感知性，是量子工程师的日常。
