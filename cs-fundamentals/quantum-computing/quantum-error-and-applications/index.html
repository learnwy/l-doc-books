量子纠错与应用

量子计算的最大工程挑战是退相干（decoherence）——量子态对环境噪声极敏感，毫秒级丢失叠加 / 纠缠。1995 Shor 给出第一个量子纠错码（QEC），证明"逻辑 qubit 可由多个物理 qubit 编码并 robust"。Surface code 是当前主流 QEC——一个逻辑 qubit 需 ~ 1000 physical qubit。Fault-tolerant quantum computing 需 ~ 百万 physical qubit 才能跑 Shor 破 2048 bit RSA——目前 IBM 1121 qubit、Google Sycamore 70+ qubit 仅是 NISQ（Noisy Intermediate-Scale Quantum）阶段。Quantum supremacy（2019 Google Sycamore 200 秒任务超过经典 10000 年）证明特定任务上的量子优势但不实用。量子计算硬件平台多元——超导（Google / IBM）、trapped ion（IonQ / Quantinuum）、光子（PsiQuantum）、neutral atom（QuEra）、topological（Microsoft 押注）。本章覆盖退相干源（dephasing、relaxation、leakage）、QEC 原理（surface code、threshold theorem）、quantum supremacy 历史与争议、硬件平台对比、未来 10-20 年路线图。学完本章你能解释"为什么 NISQ 不能破 RSA"、"surface code 的 distance 与 logical error 关系"、"超导 vs trapped ion 的 trade-off"。
