量子纠错

核心概念

量子纠错（QEC）是容错量子计算的关键——将 1 个逻辑量子比特编码到多个物理量子比特中，使噪声引起的错误可被检测与纠正。Peter Shor 于 1995 年给出第一个量子纠错码（9 量子比特码），证明量子错误可以被纠正（此前认为不可能）。阈值定理（1996-2000）证明若物理门误差率低于阈值（表面码约 1%），增加码距可指数级压低逻辑误差率。表面码是当前主流方案——一个逻辑量子比特需要约 1000 个物理量子比特才能达到 10−1210^{-12}10−12 的误差率。本节介绍经典与量子纠错差异、3 量子比特重复码、Shor 9 量子比特码、稳定子形式化方法、表面码、阈值定理以及当前实验进展（Google Willow 逻辑量子比特 2024）。

Shor 9 量子比特 9 3 不切实际 教学用

经典与量子纠错的差异

经典纠错：

  • 复制比特（1 → 111）。
  • 多数投票（5 个比特，3 个相同即可）。
  • 简单且有效。

量子纠错的难点：

  • 不可克隆定理：不能复制未知量子态 ∣ψ⟩|\psi\rangle∣ψ⟩。
  • 连续误差：错误不是离散的比特翻转，而是连续幺正变换。
  • 测量扰动：直接测量量子比特会塌缩叠加态。

量子解决方案：

  • 将逻辑量子比特编码到纠缠的多量子比特态中。
  • 测量综合征（不破坏逻辑态）。
  • 根据综合征施加校正幺正操作。

3 量子比特翻转码

教学示例：纠正比特翻转（XXX 误差）。

编码：

|0⟩_L = |000⟩
|1⟩_L = |111⟩
α|0⟩ + β|1⟩ → α|000⟩ + β|111⟩

误差：

  • 假设 1 个量子比特受 XXX 误差。
  • ∣000⟩→∣100⟩|000\rangle \to |100\rangle∣000⟩→∣100⟩ 或 ∣010⟩|010\rangle∣010⟩ 或 ∣001⟩|001\rangle∣001⟩。

综合征测量：

  • 测量 Z1Z2Z_1Z_2Z1​Z2​ 与 Z2Z3Z_2Z_3Z2​Z3​（不破坏逻辑态）。
  • (0, 0) → 无误差。
  • (1, 0) → 第 1 位错。
  • (1, 1) → 第 2 位错。
  • (0, 1) → 第 3 位错。

校正：

  • 对指出的量子比特施加 XXX 门。
  • 逻辑态恢复。

关键：测量 Z1Z2Z_1Z_2Z1​Z2​ 不暴露单个量子比特的值——只暴露奇偶性（差异）。逻辑态不被破坏。

Shor 9 量子比特码
Shor 1995：第一个完整的量子纠错码，能纠正 XXX、YYY、ZZZ 误差。


编码：


|0⟩_L = (|000⟩ + |111⟩)(|000⟩ + |111⟩)(|000⟩ + |111⟩) / 2√2
|1⟩_L = (|000⟩ - |111⟩)(|000⟩ - |111⟩)(|000⟩ - |111⟩) / 2√2
结构：


    

  • 3 个区块，每区块 3 个量子比特。
    • 

  • 内层：3 量子比特翻转码。
    • 

  • 外层：3 区块相位翻转码（每区块视为逻辑量子比特）。
    • 



纠错能力：


    

  • 单量子比特误差（XXX、YYY、ZZZ）均可纠正。
    • 

  • 码距为 3。
    • 



意义：


    

  • 证明量子纠错的可能性。
    • 

  • 启发了后续纠错码的研究。
    • 



稳定子形式化方法
Gottesman 1997：量子纠错的系统化框架。


稳定子群：固定 ∣ψ⟩|\psi\rangle∣ψ⟩ 的一组对易泡利算符。


示例：3 量子比特码的稳定子：


    

  • Z1Z2Z_1Z_2Z1​Z2​
    • 

  • Z2Z3Z_2Z_3Z2​Z3​
    • 



∣000⟩|000\rangle∣000⟩ 与 ∣111⟩|111\rangle∣111⟩ 都被这些算符固定（共同 +1 本征值）。


码的定义：


    

  • NNN 个量子比特系统。
    • 

  • (N−K)(N - K)(N−K) 个稳定子。
    • 

  • 码空间 = 同时 +1 本征空间。
    • 

  • 有 2K2^K2K 个逻辑量子比特。
    • 



误差检测：


    

  • 测量稳定子。
    • 

  • 任何错误改变稳定子本征值 → 综合征。
    • 

  • 不破坏逻辑态（稳定子与逻辑算符对易）。
    • 



著名量子码：


    

  • 5 量子比特码：[[5,1,3]][[5,1,3]][[5,1,3]]，最小可纠任意单量子比特误差。
    • 

  • 7 量子比特 Steane 码：[[7,1,3]][[7,1,3]][[7,1,3]]，CSS 码，与经典汉明码相关。
    • 

  • 9 量子比特 Shor 码。
    • 

  • 表面码：[[d2,1,d]][[d^2,1,d]][[d2,1,d]]。
    • 



表面码
二维格子上的拓扑码：


    

  • 量子比特位于格子边上。
    • 

  • 两种稳定子：
      

    • 面稳定子（ZZZ 型）：面周围 4 个量子比特施加 ZZZ。
      • 

    • 顶点稳定子（XXX 型）：顶点周围 4 个量子比特施加 XXX。
      • 

    

    • 

  • 码距 ddd：最小非平凡环路。
    • 



优势：


    

  • 仅需最近邻双量子比特门。
    • 

  • 高阈值约 1%。
    • 

  • 可扩展。
    • 



资源需求：


    

  • d×dd \times dd×d 格子 → 约 2d22d^22d2 个物理量子比特。
    • 

  • 每个格子块对应 1 个逻辑量子比特。
    • 

  • 逻辑误差率 ∼exp⁡(−d)\sim \exp(-d)∼exp(−d)（指数级压低）。
    • 



成为主流的原因：


    

  • IBM、Google、AWS 都押注表面码。
    • 

  • 实验友好（二维布局、局域相互作用）。
    • 



阈值定理
Aharonov-Ben-Or 1996、Knill-Laflamme-Zurek 1998：


陈述：若物理误差率 ppp 低于阈值 pthp_{th}pth​，则级联/表面码可使逻辑误差率趋近于零，且仅需多项式开销。


表面码阈值：


    

  • 约 0.5-1%（取决于噪声模型）。
    • 

  • 现代硬件已超过阈值。
    • 



逻辑误差率：


P_L ≈ A · (p / p_threshold)^(d/2)
    

  • ddd = 码距。
    • 

  • 增加 ddd → 指数级压低逻辑误差。
    • 



资源估算：


    

  • 达到 PL≈10−12P_L \approx 10^{-12}PL​≈10−12（典型容错要求）：
    • 

  • p=10−3p = 10^{-3}p=10−3（1% 门误差）→ d≈25d \approx 25d≈25，约 1250 物理量子比特每逻辑比特。
    • 

  • p=10−4p = 10^{-4}p=10−4 → d≈13d \approx 13d≈13，约 350 物理量子比特。
    • 



容错操作
朴素方法：


    

  • 解码 → 操作 → 重新编码。
    • 

  • 暴露逻辑态给误差。
    • 



容错门：


    

  • 直接在编码态上操作。
    • 

  • 单一故障不传播为逻辑误差。
    • 



横向门（Transversal gates）：


    

  • 对每个量子比特施加相同门。
    • 

  • 表面码支持横向克利福德门（H、S、CNOT）。
    • 

  • 但横向 T 门需要额外技巧。
    • 



魔态蒸馏（Magic state distillation）：


    

  • 用克利福德门准备并蒸馏有噪声的"魔态"。
    • 

  • 注入魔态实现 T 门。
    • 

  • 开销大（多个有噪声态 → 1 个高保真态）。
    • 



格子手术（Lattice surgery）：


    

  • 不同表面码块合并/分裂。
    • 

  • 实现逻辑 CNOT。
    • 



稳定子电路模拟
Gottesman-Knill 定理：


    

  • 仅含克利福德门的量子电路可在经典计算机上多项式时间模拟。
    • 

  • 非通用——T 门是非克利福德的关键。
    • 



意义：


    

  • 量子纠错基本模块（稳定子测量、克利福德门）可经典模拟。
    • 

  • 使大规模量子纠错模拟可行。
    • 



实验进展
早期演示：


    

  • 2001 年 IBM 核磁共振 5 量子比特码。
    • 

  • 2014 年 IBM 超导 7 量子比特码。
    • 

  • 2014 年囚禁离子 Shor 码。
    • 



2024 年 Google Willow：


    

  • 105 量子比特芯片。
    • 

  • 码距 7 表面码。
    • 

  • 演示逻辑量子比特误差低于物理量子比特（"低于阈值"）。
    • 

  • 重大里程碑。
    • 



2024 年 Quantinuum：


    

  • 56 量子比特囚禁离子。
    • 

  • 高保真度，小规模量子纠错演示。
    • 



未来路线图：


    

  • 2025-2030：100-1000 个逻辑量子比特。
    • 

  • 2030-2040：百万物理量子比特，容错计算。
    • 

  • 2040+：实际运行 Shor 算法破解 RSA-2048。
    • 



量子纠错解码器
任务：从综合征推断最可能的误差。


算法：


    

  • 最小权完美匹配（MWPM）：表面码标准方法。
    • 

  • Union-Find 解码器：更快的近似方法。
    • 

  • 神经网络解码器：研究阶段，实际应用尚不广泛。
    • 



延迟要求：


    

  • 解码必须实时完成（小于量子比特相干时间）。
    • 

  • FPGA/ASIC 实现至关重要。
    • 



魔态蒸馏
问题：T 门无法在表面码中横向实现。


解决方案：


    

  1. 准备有噪声的"魔态" ∣T⟩=(∣0⟩+eiπ/4∣1⟩)/2|T\rangle = (|0\rangle + e^{i\pi/4}|1\rangle) / \sqrt{2}∣T⟩=(∣0⟩+eiπ/4∣1⟩)/2​。
    2. 

  2. 用克利福德电路加测量，从多个有噪声态蒸馏出 1 个高保真态。
    3. 

  3. 将魔态注入逻辑量子比特实现 T 门。
    4. 



代价：


    

  • 1 个逻辑 T 门约需 10-100 倍逻辑量子比特开销。
    • 

  • 容错 Shor 算法的大部分代价来自魔态蒸馏。
    • 



量子纠错与 NISQ
不同的体制：


NISQ：


    

  • 不做量子纠错（开销太大）。
    • 

  • 误差缓解（零噪声外推、概率性误差抵消）。
    • 

  • 变分算法。
    • 



容错量子计算（FTQC）：


    

  • 开销大但电路深度无限。
    • 

  • 任意算法均可运行。
    • 



交叉点：


    

  • 当逻辑保真度超过物理保真度时，量子纠错才值得。
    • 

  • 2024 年 Google Willow 是关键里程碑。
    •

小结
量子纠错是容错量子计算的必需——将 1 个逻辑量子比特编码到多个物理量子比特中使噪声可纠。经典纠错的简单多数投票不适合量子（不可克隆 + 连续误差 + 测量扰动）。3 量子比特翻转码是教学示例（编码 ∣000⟩|000\rangle∣000⟩、∣111⟩|111\rangle∣111⟩，测量 Z1Z2Z_1Z_2Z1​Z2​ 与 Z2Z3Z_2Z_3Z2​Z3​ 综合征不破坏逻辑态）。Shor 9 量子比特码（1995）是首个完整量子码（纠正 XXX/YYY/ZZZ）——内层比特翻转 + 外层相位翻转。稳定子形式化方法（Gottesman 1997）给出系统化框架：NNN 个量子比特、(N−K)(N-K)(N−K) 个稳定子、2K2^K2K 个逻辑位、综合征测量稳定子发现误差。表面码是主流方案——二维格子、面 ZZZ + 顶点 XXX 稳定子、码距 ddd、约 2d22d^22d2 物理量子比特、阈值约 1%、逻辑误差 exp⁡(−d)\exp(-d)exp(−d) 压低，IBM/Google/AWS 押注。阈值定理证明若 p<pthp < p_{th}p<pth​ 则级联/表面码可任意压低逻辑误差，达 PL∼10−12P_L \sim 10^{-12}PL​∼10−12 需码距约 25（1% 门误差）→ 1250 物理/逻辑。容错门——横向克利福德、魔态蒸馏实现 T 门（10-100 倍开销）、格子手术实现逻辑 CNOT。Gottesman-Knill 定理表明克利福德电路可经典多项式模拟（使量子纠错模拟可行）。解码器（最小权完美匹配标准）必须实时完成（FPGA/ASIC）。2024 年 Google Willow 码距 7 表面码演示低于阈值是关键里程碑。NISQ vs 容错：NISQ 不做纠错用缓解；容错开销大但深度无限；当逻辑保真度超过物理时纠错才值得。实验里程碑——2001 核磁共振、2014 超导、2024 Willow 与 Quantinuum。路线图——2030-2040 百万逻辑量子比特、2040+ 破解 RSA-2048。一个简单的检验：你能解释为什么"表面码 1 个逻辑量子比特需要约 1000 个物理量子比特"？如果不能，阈值定理与码距缩放的关系还需巩固。量子纠错是从 NISQ 到容错量子计算的桥梁——理解它让量子计算的终极目标（通用容错）路径清晰。
