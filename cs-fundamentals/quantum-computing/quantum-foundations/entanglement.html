量子纠缠

核心概念

量子纠缠（Entanglement）是爱因斯坦 1935 年称为"幽灵般远距离作用"的现象——两个 qubit 即使分开光年级距离，测量其一立即影响另一。Bell 1964 年的不等式 + 1982 Aspect 实验证明这不是经典关联——量子纠缠是真实物理现象，违反 local realism（局域实在论）。Bell state 是最简单的纠缠态——|Φ⁺⟩ = (|00⟩ + |11⟩) / √2——测两个 qubit 总得 00 或 11，永不 01 / 10。纠缠是量子计算的核心资源——隐形传态、超密编码、QKD、量子算法都依赖它。本节介绍 Bell states 4 种形式、Bell 不等式实验、纠缠创造（H + CNOT）、quantification（concurrence、entropy）、纠缠与 LOCC（local operations + classical communication）的关系。

| Bell state | 表达 | 测量关联 | | ---------- | ---- | -------- | --------- | ------------------- | | Φ⁺ | ( | 00⟩ + | 11⟩) / √2 | 测 00 或 11，等概率 | | Φ⁻ | ( | 00⟩ - | 11⟩) / √2 | 测 00 或 11，等概率 | | Ψ⁺ | ( | 01⟩ + | 10⟩) / √2 | 测 01 或 10，等概率 | | Ψ⁻ | ( | 01⟩ - | 10⟩) / √2 | 测 01 或 10，反关联 |

纠缠的定义

Product state（不纠缠）：

  • 状态 |ψ⟩ 可写成 |a⟩ ⊗ |b⟩。
  • 测量一 qubit 不影响另一。
  • 例：|+⟩ ⊗ |0⟩ = (|00⟩ + |10⟩) / √2。

Entangled state（纠缠）：

  • 状态不可写成 product。
  • 测一影响另一。
  • 例：(|00⟩ + |11⟩) / √2。

判断纠缠（双 qubit）：

  • 写出 4×1 振幅向量 (α₀₀, α₀₁, α₁₀, α₁₁)。
  • 计算 α₀₀ · α₁₁ - α₀₁ · α₁₀。
  • 0 → product；非 0 → entangled。

创造 Bell State

电路：H + CNOT。

|0⟩ ──H──●──── ┐
            │      │ Bell state |Φ⁺⟩
|0⟩ ───────⊕── ┘

步骤：

Initial:  |00⟩
H on q0:  (|0⟩ + |1⟩) ⊗ |0⟩ / √2 = (|00⟩ + |10⟩) / √2
CNOT:     (|00⟩ + |11⟩) / √2 = |Φ⁺⟩

CNOT（control = q0, target = q1）：若 q0 = 1 翻转 q1。

EPR 思想实验
爱因斯坦、Podolsky、Rosen 1935 年提出"EPR paradox"——量子力学似乎允许"superluminal communication"（光速通信）：


Setup：


    

  • Alice 在地球，Bob 在火星。
    • 

  • 共享 Bell state |Φ⁺⟩。
    • 

  • Alice 测自己的 qubit。
    • 

  • 若 Alice 测得 0，Bob 的 qubit 立即塌缩到 |0⟩。
    • 

  • 若 Alice 测得 1，Bob 的塌缩到 |1⟩。
    • 

  • 看似 instantaneous 影响——比光速快。
    • 



EPR 结论：量子力学是 incomplete，必有"hidden variables"决定结果。


No-communication theorem：


    

  • Bob 单独测不出 Alice 是否已测——他只看到 random 50/50。
    • 

  • 必须 Alice 经经典 channel（光速限制）告诉 Bob 自己测了什么 + 结果，Bob 才能 reconcile。
    • 

  • 不能用纠缠通信——但纠缠仍是计算资源。
    • 



Bell 不等式
Bell 1964 给出可实验测试的不等式区分 quantum vs hidden variables：


CHSH 不等式（Clauser-Horne-Shimony-Holt 1969）：


|⟨A₁B₁⟩ + ⟨A₁B₂⟩ + ⟨A₂B₁⟩ - ⟨A₂B₂⟩| ≤ 2
其中 ⟨AᵢBⱼ⟩ 是测量 correlation。


Quantum violation：


    

  • 量子力学预测：可达 2√2 ≈ 2.828（Tsirelson bound）。
    • 

  • Hidden variables 严格 ≤ 2。
    • 

  • 实验测得 ~ 2.7 → 违反 hidden variables。
    • 



Aspect 1982 实验（巴黎）：


    

  • 钙原子产生纠缠光子对。
    • 

  • 快速切换 polarizer angle（防 hidden variable 通过 communication 协调）。
    • 

  • 测得 violation。
    • 

  • 2015 多个 loophole-free 实验（Hensen et al.）确认。
    • 

  • 2022 Nobel 物理奖给 Aspect / Clauser / Zeilinger。
    • 



结论：纠缠是真实的非经典现象，不是 hidden variables。


纠缠的应用
1. Quantum teleportation（隐形传态）：


    

  • Alice 想传 |ψ⟩ 给 Bob。
    • 

  • 共享 Bell pair。
    • 

  • Alice 在 |ψ⟩ 与自己的 Bell qubit 上做 Bell measurement。
    • 

  • 传 2 经典 bit 给 Bob。
    • 

  • Bob 应用对应单 qubit 门重建 |ψ⟩。
    • 

  • 注意：原 |ψ⟩ 在 Alice 处被破坏（no-cloning）。
    • 



2. Superdense coding：


    

  • 共享 Bell pair。
    • 

  • Alice 发 2 经典 bit 给 Bob 通过 1 qubit。
    • 

  • 比经典通信效率 2x。
    • 



3. Quantum Key Distribution（QKD）：


    

  • BB84 / E91 协议。
    • 

  • 用纠缠 / superposition 检测窃听。
    • 

  • 信息论安全的 key 交换。
    • 



4. 量子算法：


    

  • Shor / Grover 内部用纠缠。
    • 

  • 没有纠缠 → 经典模拟 quantum circuit polynomial → 没有量子加速。
    • 



纠缠 quantification
对纯态：


    

  • Schmidt decomposition：|ψ⟩ = Σ √(λᵢ) |aᵢ⟩|bᵢ⟩。
    • 

  • Schmidt rank > 1 → entangled。
    • 



Concurrence：


    

  • 2 qubit 纠缠度量。
    • 

  • C(|Φ⁺⟩) = 1（最大纠缠）。
    • 

  • C(product state) = 0。
    • 



Von Neumann entropy of reduced density matrix：


    

  • E(|ψ⟩) = -tr(ρ_A log ρ_A)。
    • 

  • 0（product）到 log(d)（最大）。
    • 



多 qubit 纠缠：


    

  • 复杂多。
    • 

  • W state、GHZ state 是不同 class。
    • 

  • W = (|001⟩ + |010⟩ + |100⟩) / √3。
    • 

  • GHZ = (|000⟩ + |111⟩) / √2。
    • 



Monogamy of Entanglement
重要性质：A 与 B 最大纠缠 → A 不能与 C 同时最大纠缠。


意义：


    

  • 纠缠不能"广播"。
    • 

  • QKD 安全性根源（窃听者 C 无法完全克隆 Alice-Bob 纠缠）。
    • 



退相干与纠缠
Decoherence（退相干）：


    

  • 与环境 E 纠缠 → 系统-环境复合态变 mixed。
    • 

  • Reduced density matrix on system 失去 off-diagonal terms。
    • 

  • 看起来变成经典 mixed state。
    • 



实战影响：


    

  • 量子计算机 isolate from 环境很难。
    • 

  • 纠缠态特别脆弱——双 qubit 纠缠衰减率 = 单 qubit 退相干率之和。
    • 

  • QEC 必须保护 entanglement 不被破坏。
    • 



LOCC（Local Operations + Classical Communication）
LOCC paradigm：


    

  • Alice 与 Bob 各自做 local quantum 操作。
    • 

  • 通过经典 channel 通信（光速限）。
    • 



LOCC 不能创造纠缠：


    

  • 已有的 entanglement 是 resource。
    • 

  • LOCC 可"消耗"或"重整"纠缠，不能创造。
    • 

  • 纠缠创造需要双方 qubit 物理 interaction。
    • 



Distillation：


    

  • 多 noisy entangled pair → 少 high-fidelity pair。
    • 

  • Quantum repeater 基础。
    • 



实战 Qiskit
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

qc = QuantumCircuit(2, 2)
qc.h(0)
qc.cx(0, 1)  # CNOT
qc.measure([0, 1], [0, 1])

backend = AerSimulator()
job = backend.run(qc, shots=1000)
counts = job.result().get_counts()
print(counts)  # {'00': ~500, '11': ~500}（不会出现 01 或 10）
量子互联网
Vision：


    

  • 全球纠缠分发 network。
    • 

  • Quantum repeater 让纠缠跨大陆。
    • 

  • 应用：QKD、distributed quantum computing、networked sensing。
    • 



进展：


    

  • 2017 中国"墨子号"卫星 1200 km 纠缠分发。
    • 

  • 2020 多国 metro-area network 实验。
    • 

  • 2025 商业部署还需 5-10 年。
    • 



小结
量子纠缠是爱因斯坦"幽灵般远距离作用"——双 qubit 状态不可分解为单 qubit 张量积。Bell states 4 种最简单纠缠（Φ±、Ψ±）测量完全关联。判断纠缠（双 qubit）：α₀₀ · α₁₁ - α₀₁ · α₁₀ ≠ 0。创造 Bell state——H + CNOT。EPR paradox 1935 提出 hidden variables——Bell 1964 给可测试不等式（CHSH ≤ 2 经典、≤ 2√2 量子）。Aspect 1982 实验 + 后续 loophole-free（2015）确认违反——2022 Nobel 奖。No-communication theorem：纠缠不能 superluminal 通信，但是计算资源。应用——隐形传态（破坏原 + 经典通信）、superdense coding（1 qubit 传 2 bit）、QKD（BB84/E91）、量子算法内部。Quantification——Schmidt rank、concurrence（2 qubit）、von Neumann entropy。Multi-qubit 复杂——W state vs GHZ。Monogamy——A-B 最大纠缠 → A-C 不能。退相干让纠缠衰减是工程挑战。LOCC 不能创造纠缠——只能消耗 / 重整。Distillation 让多 noisy pair → 少 high-fidelity。墨子号 2017 卫星 1200 km 纠缠分发。一个简单的检验：你能解释为什么"测 Alice 的 qubit 不能 superluminal 通信给 Bob"？如果不能，no-communication theorem 与纠缠资源观还需巩固。纠缠是量子计算的核心资源——所有量子优势最终归于纠缠 + 干涉的协同。
