测量与不可克隆定理

核心概念

测量（measurement）是量子计算与经典计算的关键区别——测量让 superposition 塌缩到 basis state，丢失原振幅信息且不可逆。No-cloning theorem（Wootters & Zurek 1982）证明任意未知量子态不能被完美复制——这与经典 bit 自由 copy 形成强对比。这两个事实是量子密码学（QKD）安全性的根源、也是量子算法设计困难的根源（不能简单"backup"中间状态）。本节介绍测量的形式化（projective measurement、POVM）、不同 basis 测量的物理意义、no-cloning theorem 证明与影响、no-deleting theorem、测量在量子算法中的角色（Bell measurement、teleportation）。

| 测量类型 | 形式 | 用途 | | ------------------- | ---------------- | -------------- | ---- | ------------ | ---- | ------------------ | | Computational basis | { | 0⟩, | 1⟩} | 默认 readout | | X basis | { | +⟩, | -⟩} | Phase 测量 | | Y basis | { | i⟩, | -i⟩} | Tomography | | Bell basis | { | Φ⁺⟩, | Φ⁻⟩, | Ψ⁺⟩, | Ψ⁻⟩} | Teleportation, BSM | | POVM | 一般 measurement | Discrimination |

Projective Measurement

形式化：测量算子 {Mₘ} 满足 Σ Mₘ†Mₘ = I（completeness）。

Computational basis measurement：

  • M₀ = |0⟩⟨0|, M₁ = |1⟩⟨1|。
  • |ψ⟩ = α|0⟩ + β|1⟩。
  • P(0) = ⟨ψ|M₀†M₀|ψ⟩ = |α|²。
  • P(1) = |β|²。
  • 测后塌缩：M₀|ψ⟩/√P(0) = |0⟩ 或 M₁|ψ⟩/√P(1) = |1⟩。

任意 basis 测量：

  • 旋转到 computational basis、测、旋转回。
  • X basis 测：先 H 应用、computational measurement、H 应用。

Bell basis measurement：

  • 把 Bell state distinguish 出来。
  • 用 CNOT + H + computational measurement 实现。

测量的不可逆性

关键性质：

  • Unitary 操作可逆——任何 unitary U 都有 U⁻¹。
  • 测量不可逆——塌缩丢失振幅信息。

实战意义：

  • 量子算法中测量必须谨慎放置——一旦测量 superposition 失去。
  • 算法设计：把"信息"用干涉浓缩到一 basis state 上，再测得正确答案。
  • 部分算法（如 phase estimation、Grover）巧妙在最后一刻测量。

Deferred measurement principle：

  • 任何中间测量可推迟到最后。
  • 只用 unitary + 最终测量等价于 unitary + intermediate measurement。
  • 简化算法分析。
No-Cloning Theorem
Wootters & Zurek 1982：


陈述：不存在 unitary U 满足对所有 |ψ⟩：


U(|ψ⟩ ⊗ |0⟩) = |ψ⟩ ⊗ |ψ⟩
即不能"复制"任意未知量子态。


证明（反证）：


假设存在 U 满足上式。对两不同态 |ψ⟩ 与 |φ⟩：


U(|ψ⟩|0⟩) = |ψ⟩|ψ⟩
U(|φ⟩|0⟩) = |φ⟩|φ⟩
取 inner product：


⟨ψ|φ⟩ · ⟨0|0⟩ = ⟨ψ|φ⟩ · ⟨ψ|φ⟩
⟨ψ|φ⟩ = (⟨ψ|φ⟩)²
只能 ⟨ψ|φ⟩ = 0 或 1。但任意两态可能有任意 inner product → 矛盾。


结论：no-cloning。


No-Cloning 的意义
1. 量子密码学安全性：


    

  • 攻击者不能 "tap & copy" quantum communication。
    • 

  • BB84 QKD 利用——任何窃听破坏量子态被检测。
    • 



2. 量子算法不能简单 backup：


    

  • 经典：可以保存 mid-state。
    • 

  • 量子：必须重新计算（用 reversible 操作）。
    • 



3. 量子隐形传态：


    

  • 不能 copy 但可"transfer"（用 Bell pair + 经典通信）。
    • 

  • 原 |ψ⟩ 在 Alice 处被破坏——保持 no-cloning。
    • 



4. Quantum repeater：


    

  • 不能像经典 amplifier 直接放大。
    • 

  • 用 entanglement swapping + distillation。
    • 



5. Quantum computing fault-tolerance：


    

  • 不能简单 N 个 backup vote。
    • 

  • 必须用 quantum error correction（surface code 等）。
    • 



No-Cloning 的"伪反例"
1. 已知态可 copy：


    

  • 若知 |ψ⟩ = |0⟩，可生成多个 |0⟩ → 但这是用经典信息生成，不是量子 cloning。
    • 



2. Orthogonal states 可 distinguish 后 copy：


    

  • 若知 |ψ⟩ ∈ {|0⟩, |1⟩}，可测后 copy。
    • 

  • 但任意 superposition 不行。
    • 



3. Approximate cloning：


    

  • 不能完美 copy，但可 imperfect copy。
    • 

  • Buzek-Hillery 1996：universal cloning machine fidelity 5/6。
    • 

  • 不完全等同 no-cloning 否定。
    • 



No-Deleting Theorem
Pati & Braunstein 2000：


不能删除 unknown 量子态副本——给 |ψ⟩|ψ⟩ 不存在 unitary 让它变 |ψ⟩|0⟩。


意义：


    

  • 量子信息不能"丢弃"（除非测量塌缩或 partial trace）。
    • 

  • 量子计算可逆性的另一面。
    • 



Bell Measurement
Bell measurement 把 2 qubit 投影到 4 个 Bell state 之一：


电路（与 Bell state preparation 反向）：


─CNOT─H─Measure─
─CNOT───Measure─
步骤：


    

  1. CNOT（control = q0, target = q1）。
    2. 

  2. H on q0。
    3. 

  3. Computational measurement on both。
    4. 

  4. 结果 (m0, m1) 对应 Bell state：
      

    • (0, 0) → |Φ⁺⟩
      • 

    • (0, 1) → |Ψ⁺⟩
      • 

    • (1, 0) → |Φ⁻⟩
      • 

    • (1, 1) → |Ψ⁻⟩
      • 

    

    5. 



应用：teleportation、entanglement swapping、superdense coding。


POVM（Positive Operator-Valued Measure）
Generalization of projective measurement：


    

  • {Eₘ}, Eₘ ≥ 0, Σ Eₘ = I。
    • 

  • 不要求正交（vs projective）。
    • 



用途：


    

  • Quantum state discrimination：从 non-orthogonal state set 中尽量识别。
    • 

  • 经典 measurement 不行——POVM 可。
    • 

  • 例：USD（Unambiguous State Discrimination）—— either definite answer or "don't know"。
    • 



实战实现：


    

  • POVM 可用 Naimark dilation 转 projective measurement on larger system。
    • 



量子隐形传态（Teleportation）
Setup：


    

  • Alice 想传 |ψ⟩ = α|0⟩ + β|1⟩ 给 Bob。
    • 

  • 共享 Bell pair (Alice 持 q1, Bob 持 q2)。
    • 



协议：


    

  1. Alice 持 |ψ⟩ (q0) 与 Bell pair 一半 (q1)。
    2. 

  2. Alice 在 q0, q1 上 Bell measurement → 2 经典 bit (m0, m1)。
    3. 

  3. Alice 经经典 channel 发 (m0, m1) 给 Bob。
    4. 

  4. Bob 根据 (m0, m1) 应用门：
      

    • (0, 0)：I。
      • 

    • (0, 1)：X。
      • 

    • (1, 0)：Z。
      • 

    • (1, 1)：XZ。
      • 

    

    5. 

  5. Bob 的 q2 现在是 |ψ⟩。
    6. 



关键：


    

  • 原 |ψ⟩ 在 Alice 处被破坏（no-cloning 保持）。
    • 

  • 需经典通信（不超光速）。
    • 

  • 用纠缠作为 resource。
    • 

  • Bell pair 用过即"消耗"。
    • 



实战 Qiskit Bell Measurement
from qiskit import QuantumCircuit

# 准备 |Phi+>
qc = QuantumCircuit(2, 2)
qc.h(0)
qc.cx(0, 1)

# Bell measurement
qc.cx(0, 1)
qc.h(0)
qc.measure([0, 1], [0, 1])
# 结果总是 (0, 0) 因为我们准备的是 |Phi+>
量子计算的"测量策略"
算法设计核心：


    

  1. 把 input 编码到 superposition。
    2. 

  2. 应用 unitary 让正确答案振幅 dominant（干涉）。
    3. 

  3. 最后测量——high probability 得正确答案。
    4. 



例：Grover 搜索。


    

  • N 个 item，one is target。
    • 

  • Initial superposition 1/√N(|0⟩ + |1⟩ + ... + |N-1⟩)。
    • 

  • Grover iteration：reflect about target、reflect about average。
    • 

  • O(√N) iteration 后 target amplitude → 1。
    • 

  • 测量 high prob 得 target。
    • 



小结
测量与 no-cloning 是量子计算的"约束"——但也是 enable security 与 algorithmic structure 的根源。Projective measurement {Mₘ} 满足 completeness Σ Mₘ†Mₘ = I——computational basis 测得 0 概率 |α|²，测后塌缩。任意 basis 测量通过先 unitary 旋转到 computational basis 实现——X basis 测先 H、Y basis 先 S† H、Bell basis 先 CNOT + H。Deferred measurement principle 让 intermediate measurement 可推迟到最后。No-cloning theorem（Wootters & Zurek 1982）——不存在 unitary 满足 U(|ψ⟩|0⟩) = |ψ⟩|ψ⟩，证明用 inner product 矛盾。意义——QKD 安全（窃听破坏 detected）、不能简单 backup mid-state、teleportation 必须破坏原态、quantum repeater 用 entanglement swapping、QEC 用 surface code。No-deleting theorem 是 cloning 的对偶。Bell measurement 投影到 4 Bell state（CNOT + H + computational）——teleportation、entanglement swapping、superdense coding 基础。POVM 是 projective generalization——非正交，用于 state discrimination（USD）。Quantum teleportation 协议——Bell measurement → 2 经典 bit → Bob 应用 I/X/Z/XZ——保持 no-cloning（原态破坏）。算法设计核心——superposition encoding + 干涉 dominant 正确答案 + 最后测量。一个简单的检验：你能解释为什么"no-cloning + Bell measurement 让 teleportation 可能但不超光速"？如果不能，no-cloning 与 quantum information transfer 的关系还需巩固。测量与 no-cloning 是量子计算"游戏规则"——理解它们是写正确量子算法的前提。
