Bloch 球

核心概念

Bloch sphere（Bloch 球）是单 qubit 状态的几何可视化——任意纯态对应球面上一点，混合态对应内部点。它把抽象的复振幅 α、β 转化为直观的 3D 几何（θ、φ 球面坐标），让单 qubit 门作用变成几何旋转——X / Y / Z 门是绕 x / y / z 轴 180° 旋转、H 是 (x+z)/√2 轴 180° 旋转。Bloch sphere 仅适用于单 qubit——双 qubit 状态空间是 ℂ⁴ 球面（4D），多 qubit 几何更复杂。本节介绍 Bloch sphere 数学（球面坐标 → 振幅）、常见状态位置、单 qubit 门的几何意义、density matrix 表示、混合态与纯度。

| 状态 | Bloch 坐标 | 振幅 | 物理意义 | | ---- | ---------- | --------------- | ------------- | ------------ | | | 0⟩ | (0, 0, 1) 北极 | (1, 0) | "spin up" | | | 1⟩ | (0, 0, -1) 南极 | (0, 1) | "spin down" | | | +⟩ | (1, 0, 0) +x | (1/√2, 1/√2) | X eigenstate | | | -⟩ | (-1, 0, 0) -x | (1/√2, -1/√2) | X eigenstate | | | i⟩ | (0, 1, 0) +y | (1/√2, i/√2) | Y eigenstate | | | -i⟩ | (0, -1, 0) -y | (1/√2, -i/√2) | Y eigenstate |

Bloch Sphere 数学

任意单 qubit 纯态（忽略 global phase）：

|ψ⟩ = cos(θ/2)|0⟩ + e^(iφ) sin(θ/2)|1⟩

球面坐标 (θ, φ)：

  • θ ∈ [0, π]：极角（北极 0、南极 π）。
  • φ ∈ [0, 2π)：方位角。

Cartesian 坐标：

  • x = sin(θ) cos(φ)
  • y = sin(θ) sin(φ)
  • z = cos(θ)

反向：

  • α = cos(θ/2)
  • β = e^(iφ) sin(θ/2)

为什么 θ/2：球面上对极点（如 |0⟩ vs |1⟩）相差 180°，但状态空间相差 90°（正交）——因子 1/2 调整。

6 个常见纯态位置

        |0⟩ (z=+1)
         |
         |
   |i⟩-——|-——|+⟩
   y=+1  |  x=+1
         |
        |1⟩ (z=-1)
  • |0⟩：北极。
  • |1⟩：南极。
  • |+⟩ = (|0⟩+|1⟩)/√2：+x 轴。
  • |-⟩ = (|0⟩-|1⟩)/√2：-x 轴。
  • |i⟩ = (|0⟩+i|1⟩)/√2：+y 轴。
  • |-i⟩ = (|0⟩-i|1⟩)/√2：-y 轴。

单 qubit 门的几何

单 qubit unitary 在 Bloch sphere 上是旋转：

X 门（Pauli X）：

  • 绕 x 轴 180° 旋转。
  • |0⟩ ↔ |1⟩，|+⟩ 不变，|-⟩ 不变。
  • 经典 NOT 门的量子推广。

Y 门：

  • 绕 y 轴 180° 旋转。

Z 门：

  • 绕 z 轴 180° 旋转。
  • |0⟩ 不变，|1⟩ → -|1⟩，|+⟩ ↔ |-⟩。

H 门（Hadamard）：

  • 绕 (x+z)/√2 轴 180° 旋转。
  • |0⟩ ↔ |+⟩，|1⟩ ↔ |-⟩。
  • 创造 superposition 的关键门。

S 门（√Z）：

  • 绕 z 轴 90° 旋转。
  • |+⟩ → |i⟩，|-⟩ → |-i⟩。

T 门（√S）：

  • 绕 z 轴 45° 旋转。
  • 与 H 一起 universal（任意单 qubit unitary 可任意精度近似）。
Rotation Gates
参数化单 qubit 旋转：


Rx(θ)：绕 x 轴 θ 角。


Rx(θ) = ⎡cos(θ/2)    -i sin(θ/2)⎤
        ⎣-i sin(θ/2)  cos(θ/2)  ⎦
Ry(θ)：绕 y 轴 θ 角。


Rz(θ)：绕 z 轴 θ 角。


任意单 qubit unitary U 可分解为：


U = e^(iα) Rz(β) Ry(γ) Rz(δ)
(Euler decomposition)。


Density Matrix
纯态用 ket 描述就够。混合态（ensemble of pure states）需要 density matrix：


ρ = Σ pᵢ |ψᵢ⟩⟨ψᵢ|
性质：


    

  • Hermitian：ρ† = ρ。
    • 

  • Positive semidefinite。
    • 

  • Trace 1：tr(ρ) = 1。
    • 



纯态特例：


    

  • ρ = |ψ⟩⟨ψ|。
    • 

  • tr(ρ²) = 1。
    • 



最大混合态：


    

  • ρ = I/2 = (|0⟩⟨0| + |1⟩⟨1|) / 2。
    • 

  • tr(ρ²) = 1/2。
    • 



Bloch Vector
Density matrix 用 Bloch vector r = (rₓ, rᵧ, r_z) 表示：


ρ = (I + rₓX + rᵧY + r_zZ) / 2
性质：


    

  • |r| = 1：纯态（球面）。
    • 

  • |r| < 1：混合态（球内部）。
    • 

  • r = 0：最大混合 I/2（球心）。
    • 



Bloch sphere 完整图像：


    

  • 球面：纯态。
    • 

  • 球内：混合态。
    • 

  • 球心：最大混合（无任何信息）。
    • 



纯度（Purity）
Purity：tr(ρ²)。


    

  • 1：纯态。
    • 

  • 1/d：最大混合态（d = Hilbert space dimension）。
    • 

  • d = 2 → 单 qubit 纯度 ∈ [1/2, 1]。
    • 



几何：


    

  • |r|² = 2 tr(ρ²) - 1。
    • 

  • 纯度高 → Bloch vector 长 → 接近球面。
    • 



退相干的几何
退相干 in Bloch sphere：


1. T₁ relaxation（amplitude damping）：


    

  • |1⟩ → |0⟩ over time。
    • 

  • Bloch vector 收缩到 z 轴 + 北极。
    • 



2. T₂ dephasing（pure dephasing）：


    

  • |+⟩ → I/2 (XY 平面)，z 不变。
    • 

  • Bloch vector 收缩到 z 轴。
    • 

  • 失去 phase 信息。
    • 



3. Depolarizing：


    

  • 各方向同时收缩。
    • 

  • Bloch vector 趋向球心。
    • 



T₂ ≤ 2T₁（一般 T₂ < T₁）。


实战：Bloch sphere 可视化
Qiskit visualization：


from qiskit.visualization import plot_bloch_vector, plot_bloch_multivector
from qiskit.quantum_info import Statevector

# 单 qubit |+>
state = Statevector.from_label('+')
plot_bloch_multivector(state)

# 任意 Bloch vector
plot_bloch_vector([1, 0, 0])  # |+>
plot_bloch_vector([0, 0, 1])  # |0>
Multi-qubit 限制
Bloch sphere 仅适用单 qubit：


    

  • 双 qubit 状态空间是 ℂ⁴ 单位球（4 维复 = 7 维实 sphere）。
    • 

  • 投影到 3D 难直观。
    • 

  • 多 qubit 状态空间维度爆炸。
    • 



Reduced density matrix：


    

  • N qubit 系统，reduce 到单 qubit 状态。
    • 

  • ρ_A = tr_B(ρ_AB)。
    • 

  • 这个单 qubit reduced state 仍可在 Bloch sphere 表示。
    • 

  • 纠缠让 reduced state mixed（即使全局 pure）。
    • 



例：Bell state |Φ⁺⟩。


    

  • 全局 pure state（Bloch sphere 不能完整表示）。
    • 

  • 单 qubit reduce → I/2（球心，最大混合）。
    • 

  • 纠缠"隐藏"在 correlation 中。
    • 



State Tomography
目的：实验测出 unknown state |ψ⟩ 或 ρ。


单 qubit tomography：


    

  • 测 X、Y、Z 三方向 expectation value。
    • 

  • 每方向 N 次重复（statistics）。
    • 

  • 重建 Bloch vector r = (⟨X⟩, ⟨Y⟩, ⟨Z⟩)。
    • 



Multi-qubit：


    

  • 测所有 Pauli string 组合（X、Y、Z、I 的张量积）。
    • 

  • 4^N - 1 个 measurement basis。
    • 

  • 数据量爆炸 → 实战仅小系统。
    • 



工程实战意义
1. 量子算法 debug：


    

  • 中间步骤 Bloch sphere 检查 state 是否预期。
    • 



2. Hardware characterization：


    

  • 测 T₁、T₂、gate fidelity。
    • 

  • 用 Bloch sphere 直观显示 noise。
    • 



3. 教学：


    

  • 直观理解单 qubit 操作。
    • 



4. 限制：


    

  • 仅单 qubit。
    • 

  • 不能直接 visualize entanglement。
    • 

  • 大系统需 reduced description。
    • 



小结
Bloch sphere 是单 qubit 状态的几何可视化——纯态对应球面点 |ψ⟩ = cos(θ/2)|0⟩ + e^(iφ) sin(θ/2)|1⟩，球面坐标 (θ, φ) 转 Cartesian (x, y, z) = (sin θ cos φ, sin θ sin φ, cos θ)。6 个常见态位置——|0⟩ 北极、|1⟩ 南极、|±⟩ ±x、|±i⟩ ±y。单 qubit 门是几何旋转——X/Y/Z 各轴 180°、H 是 (x+z)/√2 轴 180°、S 是 z 轴 90°、T 是 z 轴 45°。Rx/Ry/Rz 参数化旋转，Euler decomposition 让任意 U = e^(iα) Rz Ry Rz。Density matrix ρ 描述 mixed state，Bloch vector r = (rₓ, rᵧ, r_z) 让 ρ = (I + r·σ)/2，|r|=1 球面纯态、|r|<1 球内混合、r=0 球心最大混合。Purity = tr(ρ²)：1 纯、1/d 最大混合。退相干在 Bloch sphere——T₁ 收缩到北极、T₂ 收缩到 z 轴、depolarizing 收缩到球心。Multi-qubit 不适用 Bloch sphere——双 qubit 4D 球面，但 reduced density matrix 仍可单 qubit 表示（Bell state reduce → I/2 显示纠缠"隐藏"）。State tomography 测 X/Y/Z expectation 重建 Bloch vector，multi-qubit 4^N 个 basis 数据爆炸。Qiskit plot_bloch_multivector 可视化。工程意义——算法 debug、hardware characterization、教学，限制是仅单 qubit + 不能 visualize entanglement。一个简单的检验：你能在 Bloch sphere 上画出 H 门作用 |0⟩ 后的位置？如果不能，单 qubit 几何还需巩固。Bloch sphere 是量子计算最直观的可视化工具——理解它让单 qubit 数学变成几何直觉，是后续 multi-qubit 与算法学习的基础。
