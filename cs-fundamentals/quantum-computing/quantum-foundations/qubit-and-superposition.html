Qubit 与叠加态

核心概念

Qubit（量子比特）是量子计算的基本单位——经典 bit 取值 0 或 1，qubit 可处于 0 与 1 的叠加态（superposition）：α|0⟩ + β|1⟩，其中 α、β 是复数振幅，满足 |α|² + |β|² = 1。叠加态不是"概率混合"——是真实的物理状态，区别在于干涉（interference）。N 个 qubit 系统状态空间是 2^N 维（vs 经典 N bit 仅 N 维）——这是量子计算指数加速的数学根源。本节介绍 qubit 数学（Hilbert space、bra-ket notation）、叠加态 vs 概率混合、双 qubit 状态空间、N qubit 表示与 universal computation 限制。

| 维度 | 经典 bit | Qubit | | -------- | --------------------- | ----------------------- | ------- | -------------- | ----- | --- | | 状态 | 0 或 1 | α | 0⟩ + β | 1⟩（α, β ∈ ℂ） | | 状态空间 | {0, 1}（2 element） | 单位球面 in ℂ² | | N 位组合 | 2^N 个 discrete state | 2^N 维 Hilbert space | | 测量 | Read 即 ground truth | 塌缩到 | 0⟩ (P = | α | ²) 或 | 1⟩ | | 复制 | 自由 copy | No-cloning theorem 禁止 |

Bra-Ket Notation

Dirac 1939 引入 bra-ket 表示：

  • Ket |ψ⟩：列向量，状态。
  • Bra ⟨ψ|：行向量（共轭转置），dual。
  • Inner product ⟨φ|ψ⟩：复数。
  • Outer product |φ⟩⟨ψ|：算子（矩阵）。

计算 basis：

  • |0⟩ = (1, 0)ᵀ
  • |1⟩ = (0, 1)ᵀ

任意 qubit 状态：

|ψ⟩ = α|0⟩ + β|1⟩ = (α, β)ᵀ

满足 ⟨ψ|ψ⟩ = |α|² + |β|² = 1（normalization）。

经典概率 vs 量子叠加

经典概率 mixed state：

  • 50% 概率 0、50% 概率 1。
  • 用 random bit。
  • 测两次互独立。

量子叠加 |+⟩ = (|0⟩ + |1⟩)/√2：

  • 测量 50% 0、50% 1（看似一样）。
  • 但：在测量前 qubit 处于明确状态——不是"50% 在 0 / 50% 在 1"。
  • 干涉效应让量子算法快——经典概率没有干涉。

Mach-Zehnder interferometer 实验（光子）：

  • 单光子从 source 出发。
  • 经过 beam splitter 分两路（叠加）。
  • 经过镜子。
  • 经过第二 beam splitter 重组。
  • 关键：单光子最终 100% detector 1（不是 50% / 50%）。
  • 解释：两路振幅相干涉——一路 +1、另一路 -1，detector 2 处相消。
如果是经典概率（光子真的走 a 或 b），detector 应 50%/50%——实验结果 100%/0% 证明叠加是"真实物理状态"。


Born Rule（测量规则）
测量 qubit |ψ⟩ = α|0⟩ + β|1⟩：


    

  • P(测得 0) = |α|²
    • 

  • P(测得 1) = |β|²
    • 

  • 测量后塌缩——若测得 0，态变为 |0⟩；若 1，变为 |1⟩。
    • 



塌缩是不可逆的——失去原 superposition 信息。这就是为什么量子算法设计巧妙——必须在测量前榨出有用信息。


Multi-Qubit 系统
双 qubit basis（4 个）：


    

  • |00⟩, |01⟩, |10⟩, |11⟩
    • 



任意状态：


|ψ⟩ = α₀₀|00⟩ + α₀₁|01⟩ + α₁₀|10⟩ + α₁₁|11⟩
满足 |α₀₀|² + |α₀₁|² + |α₁₀|² + |α₁₁|² = 1。


N qubit：


    

  • 2^N 维 Hilbert space。
    • 

  • 状态用 2^N 个复振幅描述。
    • 

  • 经典模拟 N qubit 需 2^N 内存——10 qubit 1KB，50 qubit 几 PB，100 qubit 全宇宙原子。
    • 



量子计算指数加速的根：N qubit 一次操作 manipulate 2^N 振幅。


Tensor Product
多 qubit 状态用 tensor product 构造：


|0⟩ ⊗ |0⟩ = |00⟩ = (1, 0, 0, 0)ᵀ
|0⟩ ⊗ |1⟩ = |01⟩ = (0, 1, 0, 0)ᵀ
|1⟩ ⊗ |0⟩ = |10⟩ = (0, 0, 1, 0)ᵀ
|1⟩ ⊗ |1⟩ = |11⟩ = (0, 0, 0, 1)ᵀ
Product state（可分解）：


    

  • |+⟩ ⊗ |0⟩ = (|00⟩ + |10⟩) / √2
    • 



Entangled state（不可分解）：


    

  • (|00⟩ + |11⟩) / √2 = Bell state（下节展开）。
    • 

  • 不能写成 |a⟩ ⊗ |b⟩ 形式。
    • 



单 qubit 状态的几何
任意单 qubit 状态可写成（global phase 不影响测量）：


|ψ⟩ = cos(θ/2)|0⟩ + e^(iφ) sin(θ/2)|1⟩
其中 θ ∈ [0, π]、φ ∈ [0, 2π) 是 Bloch sphere 坐标（下节专门讲）。


常见状态：


    

  • |0⟩：北极。
    • 

  • |1⟩：南极。
    • 

  • |+⟩ = (|0⟩ + |1⟩)/√2：x 轴。
    • 

  • |-⟩ = (|0⟩ - |1⟩)/√2：x 轴反。
    • 

  • |i⟩ = (|0⟩ + i|1⟩)/√2：y 轴。
    • 

  • |-i⟩ = (|0⟩ - i|1⟩)/√2：y 轴反。
    • 



物理实现的 qubit
不同物理系统可作为 qubit：


1. 超导 qubit：


    

  • 超导环路 + Josephson junction。
    • 

  • IBM、Google 主流。
    • 

  • 工作温度 mK（接近绝对零度）。
    • 

  • 相干时间 ~ 100μs。
    • 



2. Trapped ion：


    

  • 离子电子能级（如 Yb⁺）。
    • 

  • IonQ、Quantinuum。
    • 

  • 室温但需精密 laser。
    • 

  • 相干时间 ~ 秒级。
    • 



3. 光子：


    

  • 光子的偏振或路径。
    • 

  • Xanadu、PsiQuantum。
    • 

  • 易传输（光纤）。
    • 



4. Neutral atom：


    

  • 中性原子（Rb、Sr）能级。
    • 

  • QuEra、Pasqal。
    • 

  • 可大规模并行。
    • 



5. Topological：


    

  • Microsoft 押注。
    • 

  • 理论上 robust 防退相干。
    • 

  • 实验未完全实现。
    • 



工程化 Qiskit 示例
Python（Qiskit）：


from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator

# 1 qubit 电路
qc = QuantumCircuit(1, 1)
qc.h(0)  # Hadamard 门：|0⟩ → (|0⟩+|1⟩)/√2
qc.measure(0, 0)

# 模拟
backend = AerSimulator()
job = backend.run(transpile(qc, backend), shots=1000)
counts = job.result().get_counts()
print(counts)  # {'0': ~500, '1': ~500}
为什么 N qubit ≠ N 经典 bit
关键 misconception："N qubit 一次操作 2^N 个值——量子计算解任何 NP 问题"——错。


正确理解：


    

  • N qubit 同时 hold 2^N 振幅。
    • 

  • 测量只得 1 个 N bit 结果。
    • 

  • 量子算法必须用干涉让"正确答案"振幅大、错答案小。
    • 

  • 不是所有问题都能这样设计——只有少数问题（factoring、search、特定 simulation）有量子加速。
    • 



BQP（Bounded-error Quantum Polynomial）：量子多项式时间可解的问题集——不等于 NP。


量子计算的本质优势
1. Indexing power：


    

  • N qubit 一次表示 2^N 状态。
    • 

  • 经典需 2^N bit。
    • 



2. 干涉：


    

  • 让"正确答案"路径相干增强。
    • 

  • 让"错答案"路径相消。
    • 

  • 经典概率没有这个机制。
    • 



3. 纠缠：


    

  • 多 qubit 关联性。
    • 

  • 让 distributed 信息处理可能。
    • 



4. 不可逆性受限：


    

  • 量子门必须 unitary（可逆）。
    • 

  • 测量是唯一不可逆操作。
    • 

  • 不同于经典电路（可任意丢 bit）。
    • 



小结
Qubit 是量子计算基本单位——状态 α|0⟩ + β|1⟩，复振幅 normalize |α|² + |β|² = 1。Bra-ket notation 是量子表示语言（ket 列向量、bra 行向量、inner / outer product）。叠加 vs 经典概率——根本区别在干涉，Mach-Zehnder 实验证明（单光子 100% detector 1 而非 50%/50%）。Born Rule——测得 0 概率 |α|²、测得 1 概率 |β|²，测量后塌缩不可逆。Multi-qubit 状态 2^N 维 Hilbert space——N qubit 一次操作 2^N 振幅是量子计算指数加速根。Tensor product 构造多 qubit 状态——product state（可分解）vs entangled state（不可分解，如 Bell state）。单 qubit 状态用 Bloch sphere 几何坐标 θ、φ。物理实现——超导（IBM/Google mK）、trapped ion（IonQ 室温）、光子（PsiQuantum）、neutral atom（QuEra）、topological（Microsoft）。Qiskit 示例展示 H 门 + 测量。N qubit ≠ N 经典 bit——一次只能测 1 个结果，量子算法必须用干涉让正确答案 dominant。BQP（量子多项式时间）≠ NP——只有少数问题有量子加速。本质优势——indexing（2^N 状态）、干涉、纠缠、unitary 限制。一个简单的检验：你能解释 |+⟩ 与 50/50 random bit 的区别？如果不能，叠加 vs 概率还需巩固。Qubit 是所有量子计算概念的起点——理解它是后续门、电路、算法、纠错的基础。
