Part I · 理论基础 (Theory)量子计算量子门与电路单 qubit 门

单 qubit 门

核心概念

单 qubit 门是 2×2 unitary 矩阵——把一个 qubit 状态变换为另一状态。最重要的单 qubit 门——X / Y / Z（Pauli 三剑客）、H（Hadamard 创造 superposition）、S（√Z）、T（√S，与 H 一起 universal）、Rx / Ry / Rz（参数化旋转）。任意单 qubit unitary 可用 H + T 任意精度近似（Solovay-Kitaev 定理 polylog 复杂度）。所有单 qubit 门必须 unitary（U†U = I）保证可逆与 normalization preservation。本节给出每个门的矩阵表示、对常见 basis 状态的作用、Bloch sphere 旋转直观、组合规则、与经典门的对比。

门 矩阵 作用 Bloch 旋转
I [[1,0],[0,1]] 不变 不动
X [[0,1],[1,0]] 翻转 |0⟩↔|1⟩ x 轴 180°
Y [[0,-i],[i,0]] 翻转 + 相位 y 轴 180°
Z [[1,0],[0,-1]] |1⟩→-|1⟩ z 轴 180°
H (1/√2)[[1,1],[1,-1]] 创造 superposition (x+z)/√2 轴 180°
S [[1,0],[0,i]] √Z z 轴 90°
T [[1,0],[0,e^(iπ/4)]] √S z 轴 45°

Pauli Gates

Pauli X（Quantum NOT）：

X = ⎡0 1⎤
    ⎣1 0⎦

X|0⟩ = |1⟩
X|1⟩ = |0⟩
X|+⟩ = |+⟩  (|+⟩ 是 X eigenstate)
X|-⟩ = -|-⟩

Pauli Y：

Y = ⎡0 -i⎤
    ⎣i  0⎦

Y|0⟩ = i|1⟩
Y|1⟩ = -i|0⟩

Pauli Z（Phase flip）：

Z = ⎡1  0⎤
    ⎣0 -1⎦

Z|0⟩ = |0⟩
Z|1⟩ = -|1⟩
Z|+⟩ = |-⟩
Z|-⟩ = |+⟩

性质：

  • X² = Y² = Z² = I（自逆）。
  • XY = iZ，YZ = iX，ZX = iY（cyclic）。
  • {X, Y, Z, I} 构成单 qubit 算子的 basis。

Hadamard Gate

H 是量子计算最重要的门：

H = (1/√2) ⎡1  1⎤
           ⎣1 -1⎦

作用：

  • H|0⟩ = (|0⟩ + |1⟩) / √2 = |+⟩
  • H|1⟩ = (|0⟩ - |1⟩) / √2 = |-⟩
  • H|+⟩ = |0⟩
  • H|-⟩ = |1⟩

意义：

  • 把 computational basis 转 X basis（vice versa）。
  • 创造 equal superposition（关键资源）。
  • 自逆：H² = I。

Tensor product H⊗N：

  • 把 N qubit |0⟩^N 变成 (1/√(2^N)) Σ_x |x⟩——所有 2^N basis state equal superposition。
  • 这是大多数量子算法第一步。

Phase Gates

S 门（Phase gate, √Z）：

S = ⎡1 0⎤
    ⎣0 i⎦

S² = Z。

T 门（π/8 gate, √S）：

T = ⎡1   0    ⎤
    ⎣0 e^(iπ/4)⎦

T² = S, T⁴ = Z。

重要：H + T 是 universal—— Solovay-Kitaev 定理给任意单 qubit unitary 用 H+T sequence 近似的多项式（polylog 1/ε）算法。

Rotation Gates
参数化旋转：


Rx(θ)：


Rx(θ) = ⎡cos(θ/2)    -i sin(θ/2)⎤
        ⎣-i sin(θ/2)  cos(θ/2)  ⎦
Ry(θ)：


Ry(θ) = ⎡cos(θ/2)  -sin(θ/2)⎤
        ⎣sin(θ/2)   cos(θ/2)⎦
Rz(θ)：


Rz(θ) = ⎡e^(-iθ/2)    0     ⎤
        ⎣0         e^(iθ/2) ⎦
关系：


    

  • Rx(π) = -iX
    • 

  • Ry(π) = -iY
    • 

  • Rz(π) = -iZ
    • 



Phase 不影响测量 → 实战可忽略 global phase。


Universal continuous：任意单 qubit unitary 可写成 Rz(α) Ry(β) Rz(γ)（Euler decomposition）。


单 qubit 门组合
Gate 序列：从右到左 apply。


|ψ_out⟩ = U_n ... U_2 U_1 |ψ_in⟩
矩阵乘法对应：


    

  • 多个门 = 矩阵相乘。
    • 

  • HZ = ?: Hadamard then Z = (1/√2)[[1,-1],[1,1]]。
    • 



例：从 |0⟩ 制备 |+⟩：


H|0⟩ = |+⟩
例：从 |0⟩ 制备 |i⟩：


SH|0⟩ = S|+⟩ = (|0⟩ + i|1⟩)/√2 = |i⟩
例：从 |+⟩ 到 |1⟩：


H |+⟩ = |0⟩
X |0⟩ = |1⟩
即 XH |+⟩ = |1⟩
单 qubit 门的物理实现
超导 qubit：


    

  • 微波脉冲驱动跃迁。
    • 

  • 长度 ns-100ns。
    • 

  • Fidelity 99.9%+。
    • 



Trapped ion：


    

  • Laser 驱动跃迁。
    • 

  • 长度 μs。
    • 

  • Fidelity 99.99%+（最佳）。
    • 



任意单 qubit 旋转：


    

  • 调 microwave / laser 频率、幅度、相位、duration。
    • 

  • 直接实现 Rx / Ry / Rz / 任意 U(2)。
    • 

  • 不需 gate decomposition。
    • 



Universal Gate Set
Discrete universal：H + T + CNOT。


    

  • 任意 unitary 可用此集合任意精度近似。
    • 



Continuous universal：


    

  • 任意单 qubit U + CNOT。
    • 

  • 实战物理实现（直接 microwave 控制）。
    • 



为什么需要 universal：


    

  • 编程 abstraction——只用几个门就能表达任意 quantum algorithm。
    • 

  • Compilation——把 high-level circuit decompose 到硬件原生 gate set。
    • 



Pauli Algebra
重要 commutator / anti-commutator：


    

  • {X, Y} = XY + YX = 0（anti-commute）。
    • 

  • [X, Y] = XY - YX = 2iZ。
    • 

  • 同样 cyclic for (Y, Z) → 2iX, (Z, X) → 2iY。
    • 



应用：


    

  • Pauli string M = X⊗Y⊗I⊗Z⊗... 是多 qubit observable。
    • 

  • VQE / QAOA 算法用 Pauli string 表示 Hamiltonian。
    • 

  • Quantum chemistry simulation 中关键。
    • 



实战 Qiskit
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

qc = QuantumCircuit(1)

# 应用 H
qc.h(0)
state = Statevector.from_instruction(qc)
print(state)  # [0.707+0j, 0.707+0j] = |+>

# Rx(pi/4)
qc.rx(3.14159/4, 0)

# T
qc.t(0)

# 完整 universal set 可用：rx, ry, rz, x, y, z, h, s, t, sdg, tdg
测量门
虽然不是 unitary，但常被画在电路中：


─U─U─Measure─
Mid-circuit measurement：


    

  • 现代 quantum computer 支持中途测量 + classical feed-forward。
    • 

  • 用于 QEC、teleportation。
    • 



单 qubit 门的常见误解
误解 1：X 门是 NOT：


    

  • 部分对——经典 sense 下是 NOT。
    • 

  • 但 X|+⟩ = |+⟩——X 在 X basis 中不是 NOT。
    • 

  • 取决于 basis。
    • 



误解 2：H 是"复制"门：


    

  • 错。H 创造 superposition，不复制。
    • 

  • No-cloning theorem 禁止任意 unknown qubit 复制。
    • 



误解 3：所有 single qubit unitary 等价：


    

  • 错。具体 angle 与 axis 决定计算能力。
    • 

  • T 门是关键——只有 H + S 不 universal（Clifford gates 经典模拟容易）。
    • 



误解 4：S² = T：


    

  • 错。S² = Z，T² = S。
    •

小结
单 qubit 门是 2×2 unitary——X / Y / Z（Pauli，自逆）、H（Hadamard 创造 superposition，自逆）、S（√Z）、T（√S，与 H universal）、Rx / Ry / Rz（参数化旋转）。Pauli 性质——X² = Y² = Z² = I, XY = iZ cyclic, anti-commute。H 把 computational basis ↔ X basis，H⊗N|0⟩^N 是所有 2^N basis state equal superposition（多算法第一步）。S = √Z, T = √S, T² = S, T⁴ = Z。Solovay-Kitaev 定理——H + T 用 polylog 长度近似任意单 qubit U。Rotation gates Rx/Ry/Rz 给参数化连续旋转，Euler decomposition U = Rz Ry Rz。Gate 序列从右到左 apply（矩阵乘法），HZ ≠ ZH（不交换）。物理实现——超导 microwave ns-100ns、trapped ion laser μs。Universal set——discrete H+T+CNOT 或 continuous 单 qubit U + CNOT。Pauli algebra anti-commutator 关键于 VQE / QAOA。Qiskit gate API（rx, ry, rz, h, s, t...）。Mid-circuit measurement 用于 QEC / teleportation。常见误解——X 不是所有 basis 的 NOT、H 不是 cloning、并非所有单 qubit gate equivalent（T 关键）、S²=Z 不是 T。与经典门对比——量子必须 unitary 可逆，用 ancilla 让经典门 reversible（Toffoli universal classical reversible）。一个简单的检验：你能解释为什么"H + S（无 T）不是 universal"？如果不能，Clifford vs non-Clifford 区别还需巩固。单 qubit 门是量子电路的"原子操作"——理解它们 + Bloch sphere 几何让单 qubit 编程变直观。
