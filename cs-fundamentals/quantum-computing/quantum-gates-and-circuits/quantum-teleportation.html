量子隐形传态

核心概念

量子隐形传态（Quantum Teleportation，Bennett 等 1993）是量子信息处理的标志性协议——Alice 用一对预先共享的 Bell pair + 2 个经典 bit 把任意量子态 |ψ⟩ 传给 Bob，原态在 Alice 处被破坏（保持 no-cloning），整个过程不超光速（需经典通信）。它不是科幻意义的"瞬移物质"——是 quantum information transfer 不是 mass transfer。Teleportation 是 quantum networking、distributed quantum computing、entanglement swapping、quantum repeater 的基础。本节给出协议详细 step-by-step、电路实现、为什么它 work、与经典通信、no-cloning、no-FTL 的关系。

步骤 操作 Alice 持有 Bob 持有
0 共享 Bell pair q1 q2
1 Alice 拿到 |ψ⟩ q0, q1 q2
2 Bell measurement on q0, q1 (m0, m1) q2 (correlated)
3 Alice 经典通信 (m0, m1) - (m0, m1)
4 Bob 应用 X^m1 Z^m0 - |ψ⟩

协议详细步骤

Setup：

  • Alice 与 Bob 共享 Bell pair |Φ⁺⟩ = (|00⟩ + |11⟩) / √2。
  • Alice 持 q1，Bob 持 q2。

Alice 的输入：

  • |ψ⟩ = α|0⟩ + β|1⟩（unknown 量子态）。
  • Alice 持 q0 = |ψ⟩。

Step 1：联合状态：

|state⟩ = (α|0⟩ + β|1⟩) ⊗ (|00⟩ + |11⟩) / √2
       = (α|000⟩ + α|011⟩ + β|100⟩ + β|111⟩) / √2

q0 是 Alice 的，q1 是 Alice 的（Bell pair 一半），q2 是 Bob 的。

Step 2：Alice CNOT(q0, q1)：

→ (α|000⟩ + α|011⟩ + β|110⟩ + β|101⟩) / √2

Step 3：Alice H on q0：

→ ½ [|0⟩(α|00⟩+α|11⟩+β|10⟩+β|01⟩) + |1⟩(α|00⟩+α|11⟩-β|10⟩-β|01⟩)]

Step 4：重组：

= ½ [|00⟩(α|0⟩+β|1⟩) + |01⟩(α|1⟩+β|0⟩) + |10⟩(α|0⟩-β|1⟩) + |11⟩(α|1⟩-β|0⟩)]

Step 5：Alice 测 q0, q1（4 种结果）：

  • (m0=0, m1=0)：q2 → α|0⟩ + β|1⟩ = |ψ⟩。Bob 直接 done。
  • (m0=0, m1=1)：q2 → α|1⟩ + β|0⟩ = X|ψ⟩。Bob apply X。
  • (m0=1, m1=0)：q2 → α|0⟩ - β|1⟩ = Z|ψ⟩。Bob apply Z。
  • (m0=1, m1=1)：q2 → α|1⟩ - β|0⟩ = XZ|ψ⟩。Bob apply ZX。

Step 6：Alice 经典通信 (m0, m1)——Bob 据此 apply correction。

Step 7：Bob 的 q2 = |ψ⟩——传态完成。

电路图
q0 |ψ⟩ ──────●──H──Measure──╗
                │              ║
q1 |Φ⁺⟩-1 ────⊕────Measure──╫═╗
                                 ║ ║
q2 |Φ⁺⟩-2 ─────────────────X─Z──╝═╝
                                ↑ ↑
                               m1 m0
为什么 work（直觉）
Bell measurement 的魔力：


    

  • Bell measurement 投影双 qubit 到 4 个 Bell state 之一。
    • 

  • 看似 Alice 测的是 q0+q1，但因 q1 与 q2 纠缠，q2 也被影响。
    • 

  • Alice 的测量结果与 Bob 的 q2 状态 deterministic correlated。
    • 



经典通信的必要：


    

  • Bob 单独看 q2：每种 Alice measurement outcome 等概率，Bob 看到 random mixed state。
    • 

  • Alice 的经典 bit 让 Bob 知道做哪种 correction。
    • 

  • 没有经典通信 → Bob 无法 reconcile → 没有 superluminal communication。
    • 



关键性质
1. No-cloning 保持：


    

  • Alice 的 q0 在 Bell measurement 后失去 |ψ⟩ 信息。
    • 

  • Bob 的 q2 获得 |ψ⟩。
    • 

  • 总数仍是 1 个 |ψ⟩——没有 cloning。
    • 



2. 不超光速：


    

  • Bob 必须等 Alice 的经典 bits（光速 limit）。
    • 

  • 没有 FTL 通信。
    • 



3. 资源消耗：


    

  • 每次 teleportation 消耗 1 Bell pair。
    • 

  • 不是 reusable——必须 fresh entanglement。
    • 



4. 距离无关：


    

  • Alice 与 Bob 距离任意大（光年级），protocol 仍 work。
    • 

  • 但需提前建立 entanglement——这是工程难点。
    • 



5. State 必须 valid：


    

  • |ψ⟩ 可以是 unknown 但必须是 valid 量子态。
    • 

  • 包括 mixed state、entangled with 别的 qubit。
    • 



实战 Qiskit
from qiskit import QuantumCircuit, ClassicalRegister, QuantumRegister

q = QuantumRegister(3, 'q')
c0 = ClassicalRegister(1, 'c0')
c1 = ClassicalRegister(1, 'c1')
qc = QuantumCircuit(q, c0, c1)

# 准备 |ψ⟩ on q[0] (随便选一个 state)
qc.rx(0.7, q[0])  # 任意 state

# 准备 Bell pair on q[1], q[2]
qc.h(q[1])
qc.cx(q[1], q[2])

qc.barrier()

# Alice's operations
qc.cx(q[0], q[1])
qc.h(q[0])

# Measure q[0], q[1]
qc.measure(q[0], c0)
qc.measure(q[1], c1)

qc.barrier()

# Bob's correction (classical control)
qc.x(q[2]).c_if(c1, 1)
qc.z(q[2]).c_if(c0, 1)

# Now q[2] should be |ψ⟩
Entanglement Swapping
Setup：


    

  • Alice 与 Bob 共享 Bell pair (q_A1, q_B1)。
    • 

  • Bob 与 Carol 共享 Bell pair (q_B2, q_C1)。
    • 

  • Alice 与 Carol 不共享 entanglement。
    • 



Goal：让 Alice 与 Carol 有 entangled pair。


协议：


    

  1. Bob 在 (q_B1, q_B2) 上做 Bell measurement。
    2. 

  2. Bob 经典通信结果给 Carol（or Alice）。
    3. 

  3. Carol（or Alice）apply correction。
    4. 

  4. (q_A1, q_C1) 现在 entangled。
    5. 



意义：


    

  • 不需要 Alice 与 Carol 直接 interaction。
    • 

  • Quantum repeater 基础——长距离 entanglement 通过链式 swapping。
    • 



Quantum Repeater
Problem：光纤损耗让 entanglement 直接分发距离 ~ 100 km 上限。


Solution：


    

  • Set up entanglement segments of 100 km each。
    • 

  • 用 entanglement swapping 串联。
    • 

  • Distillation 提升 fidelity（多 noisy pair → 少 high-fidelity）。
    • 



Quantum memory：


    

  • 必须能存储 qubit 直到 swapping 协调。
    • 

  • 当前最长 quantum memory：~ 秒到分钟（仍研究阶段）。
    • 



部署：


    

  • 中国"墨子号"卫星（2017）：1200 km 卫星 entanglement distribution。
    • 

  • 多国 metro-area network 实验。
    • 

  • 全球 quantum internet：5-10 年。
    • 



Distributed Quantum Computing
Vision：多个 quantum 处理器通过 teleportation 联合工作。


Building blocks：


    

  • Local computation：每节点 quantum 处理。
    • 

  • Inter-node teleportation：传 quantum state。
    • 

  • 经典 control：协调。
    • 



优势：


    

  • Modular scaling。
    • 

  • 不需 single 大 device。
    • 



挑战：


    

  • Inter-node fidelity loss。
    • 

  • Latency from 经典通信。
    •

Trade-off：


    

  • Teleportation 用 entanglement + cbit 传 qubit。
    • 

  • Superdense 是 reverse——用 entanglement + qubit 传 cbit。
    • 

  • 两者都 demonstrate "entanglement as resource"。
    • 



Teleportation 在 QEC 中
Code teleportation：


    

  • 把 logical qubit 从一编码 teleport 到另一编码。
    • 

  • 用 logical Bell pair。
    • 

  • Magic state distillation 用 teleportation 做 non-Clifford gate。
    • 



Lattice surgery：


    

  • Surface code 中"merge / split" patches。
    • 

  • 等价于 logical teleportation。
    • 



历史 milestones
1993：Bennett 等论文提出 protocol。


1997：Bouwmeester 等首次实验演示（光子 polarization）。


2004：原子-光子 teleportation（Innsbruck）。


2012：99 km 光子 teleportation（Canary Islands）。


2017：中国墨子号 1200 km 卫星 teleportation。


2025：实验室级 fidelity > 99%。


Common 误解
1. "传输物质 / 能量"：


    

  • 错。只传量子信息。
    • 

  • 物质 / 能量在 Alice 处仍是 Alice 的（破坏后变 unknown classical state）。
    • 



2. "瞬移"：


    

  • 错。需经典通信光速 limit。
    • 



3. "复制 |ψ⟩"：


    

  • 错。原态被破坏（no-cloning 保持）。
    • 



4. "Practical communication"：


    

  • 部分错。Teleportation 不替代经典通信传 cbit。
    • 

  • 它传 qubit—— useful for quantum computing。
    • 



小结
量子隐形传态（Bennett 1993）用 Bell pair + 2 cbit 把任意 |ψ⟩ 从 Alice 传到 Bob——原态破坏（no-cloning 保持）、不超光速（需经典通信）、消耗 Bell pair 资源。Protocol——Alice 持 |ψ⟩ + Bell pair 半边、CNOT 后 H、测 2 cbit、经典通信、Bob apply X^m1 Z^m0。4 种 measurement outcome 对应 4 种 correction（I / X / Z / XZ）。电路 Qiskit 实战展示。Entanglement swapping——Bob 做 Bell measurement on 两个 Bell pair 中间 qubit，让 Alice-Carol entangled，是 quantum repeater 基础。Quantum repeater 通过 100 km segment + swapping + distillation 突破光纤损耗 limit，墨子号 2017 实现 1200 km 卫星 distribution。Distributed quantum computing 用 teleportation 连接 modular processors。Teleportation 与 superdense coding 是对偶（前者用 ent + cbit 传 qubit、后者用 ent + qubit 传 cbit），都 demonstrate entanglement as resource。QEC 中 teleportation 用于 logical state transfer 与 magic state distillation。历史——1993 论文、1997 首次实验、2017 卫星、当前 99% fidelity。常见误解——不是物质瞬移、不是 FTL、不是 cloning、不替代经典通信。一个简单的检验：你能解释为什么"teleportation 需要经典通信但不超光速"？如果不能，no-FTL 与 entanglement 的关系还需巩固。Teleportation 是 quantum information theory 的标志性结果——把"entanglement is resource"从抽象概念变成可操作工具，是 quantum networking 与 distributed QC 的基础。
