量子电路模型

核心概念

量子电路模型（Quantum Circuit Model）是量子计算的标准编程范式——qubit 是水平线，gate 在线上从左到右 apply。它把抽象量子态变换变成具体 hardware-implementable 操作。Quantum circuit 包含 4 类元素——initialization（|0⟩^N）、unitary gates（H、CNOT、Rx 等）、measurement（塌缩到经典 bit）、classical control（feed-forward 让后续 gate 依赖前面 measurement）。本节介绍电路 notation、execution model、常见 ansatz 模式（HEA、QAOA layers、parameter-shift）、circuit depth/width tradeoff、与其他 quantum computing model（measurement-based、adiabatic、topological）的等价性。

元素 Notation 作用
Qubit wire 水平线 qubit 在时间上演化
Single-qubit gate 方块在线上 unitary 操作
Two-qubit gate 跨两线连线 CNOT, CZ etc
Measurement 仪表 symbol 塌缩 + classical bit
Classical wire 双线 经典 bit
Control 黑点 + 跨线 classical / quantum control

电路 Notation

q0: |0⟩ ──H──●──Measure──╗
              │             ║
q1: |0⟩ ──H──⊕──Measure──╫═══╗
                            ║   ║
c:                          ╚═══╩═══

约定：

  • Time flows left to right。
  • Qubit 标号 top to bottom（也有 reverse convention）。
  • Gates apply 序列：从左到右。

Execution Model

经典 quantum execution：

1. Initialize all qubits to |0⟩.
2. Apply unitary gate sequence.
3. Measure (some or all qubits).
4. Output classical bits.

Mid-circuit measurement + feed-forward：

1. Initialize.
2. Apply unitary.
3. Measure (mid-circuit).
4. Based on measurement, apply different gates.
5. Continue.
6. Final measurement.

用途：

  • QEC（syndrome extraction → correct）。
  • Teleportation（measurement → conditional gate）。
  • Magic state distillation。
  • Adaptive circuits。

Circuit Depth vs Width

Width：qubit 数（电路有多少 qubit）。

Depth：能并行执行的"layer"数——把不冲突的 gate 放同一 time step。

Total gates：width × depth 上限。

关键：

  • Width 增加：状态空间指数增大，但需要更多硬件 qubit。
  • Depth 增加：累积 noise 增多。
  • 现代 NISQ 硬件 depth 受限（~ 100-1000 gate）。
Layered Circuit 设计
Layered 结构让 hardware execution 高效：


Layer 1: 单 qubit gates on all qubits (并行)
Layer 2: 双 qubit gates on adjacent pairs (并行)
Layer 3: 单 qubit gates
Layer 4: 双 qubit gates
...
Brick wall pattern：交替的双 qubit gate layout 让所有 qubit 间接交互。


Variational Ansatz
VQE / QAOA 用 parameterized ansatz：


Hardware Efficient Ansatz (HEA)：


for layer in range(L):
    for qubit in range(N):
        apply Ry(θ_i)
    for pair in adjacent_pairs:
        apply CNOT(pair)
优势：


    

  • 用 hardware 原生 gates。
    • 

  • 浅深度。
    • 



缺点：


    

  • Trainability 问题（barren plateau）——大系统 gradient 指数小。
    • 



QAOA Ansatz：


H_initial: H ⊗ ... ⊗ H |0⟩^N
for layer in range(p):
    apply e^(-iγ H_problem)
    apply e^(-iβ H_mixer)
参数 γ_p, β_p 通过经典优化。


Trotter Decomposition
模拟时间演化 e^(-iHt) 分 small steps：


e^(-iHt) ≈ (e^(-iH₁ t/n) e^(-iH₂ t/n) ... e^(-iH_k t/n))^n
其中 H = H₁ + H₂ + ... + H_k。


误差：O((t/n)² × commutator terms)。


应用：


    

  • Quantum chemistry：模拟分子 Hamiltonian。
    • 

  • 凝聚态：模拟 Hubbard model。
    • 

  • 对量子 simulator 是核心算法。
    • 



Parameter-Shift Rule
目标：optimize 参数化电路 ⟨ψ(θ)|H|ψ(θ)⟩。


Gradient：


∂⟨H⟩/∂θ = (⟨H⟩(θ + π/2) - ⟨H⟩(θ - π/2)) / 2
意义：


    

  • Quantum 上可精确算 gradient（不像经典 finite difference）。
    • 

  • 让 VQE / QAOA 用 gradient descent。
    • 



量子计算的 5 种等价模型
1. Circuit model（这一节主题）：


    

  • gate sequence。
    • 

  • 标准 abstraction。
    • 



2. Measurement-based / One-way QC：


    

  • 大 cluster state 准备。
    • 

  • 测量序列 drive 计算。
    • 

  • Output 是最后 unmeasured qubit。
    • 



3. Adiabatic QC：


    

  • Slowly evolve from easy Hamiltonian to problem Hamiltonian。
    • 

  • D-Wave annealer 用（虽 D-Wave 不 universal）。
    • 



4. Topological QC：


    

  • Anyons braiding。
    • 

  • Microsoft 押注。
    • 

  • 理论 robust 防退相干。
    • 



5. Quantum Turing Machine：


    

  • 理论模型。
    • 

  • 与 circuit model 等价。
    • 



等价性：


    

  • Measurement-based、adiabatic、circuit 都 polynomial 等价。
    • 

  • 选择是工程实现 trade-off。
    • 



Circuit Compilation
High-level circuit → hardware native：


1. Decomposition: 任意 unitary → CNOT + 单 qubit。
2. Mapping: logical qubit → physical qubit（routing）。
3. Optimization: cancel 冗余 gate, merge rotations。
4. Native gate translation: CNOT → ECR / iSWAP（hardware specific）。
5. Pulse-level scheduling: gate → microwave pulse。
工具：


    

  • Qiskit transpiler。
    • 

  • Cirq compiler。
    • 

  • TKET（Quantinuum）。
    • 



实战 Qiskit Circuit
from qiskit import QuantumCircuit, ClassicalRegister, QuantumRegister
from qiskit_aer import AerSimulator

q = QuantumRegister(3, 'q')
c = ClassicalRegister(3, 'c')
qc = QuantumCircuit(q, c)

# 准备 |+++⟩
qc.h(q)

# Apply CNOT chain
qc.cx(q[0], q[1])
qc.cx(q[1], q[2])

# Mid-circuit measurement on q[0]
qc.measure(q[0], c[0])

# Conditional gate based on c[0]
qc.x(q[1]).c_if(c, 1)  # Apply X if c[0] == 1

# Final measurement
qc.measure(q[1], c[1])
qc.measure(q[2], c[2])

backend = AerSimulator()
result = backend.run(qc, shots=1000).result()
print(result.get_counts())
NISQ 时代的 circuit 设计
Noisy Intermediate-Scale Quantum：


    

  • ~ 50-1000 qubit。
    • 

  • No quantum error correction。
    • 

  • Limited circuit depth（~ 100-1000）。
    • 



应用 strategy：


    

  • Variational algorithms（VQE、QAOA）：浅 circuit + classical optimization。
    • 

  • Quantum simulation：模拟其他 quantum system，noise 部分容忍。
    • 

  • Sampling problems（quantum supremacy 实验）：noise OK 因为 distribution 仍 distinguishable。
    • 



Avoid in NISQ：


    

  • Shor 算法（深 circuit + many qubit）。
    • 

  • Grover 大规模（√N speedup 被 noise 吃掉）。
    • 



Fault-Tolerant 时代
FTQC（Fault-Tolerant QC）：


    

  • Logical qubit 编码为多 physical qubit。
    • 

  • Surface code threshold ~ 1%。
    • 

  • 100k-1M physical qubit → ~100-1000 logical。
    • 



支持算法：


    

  • Shor 破 RSA-2048（~ 4000 logical qubit, 数小时）。
    • 

  • 大规模 quantum simulation。
    • 

  • Grover unstructured search。
    • 



估计达成时间：2030-2040。


Hybrid 经典-量子算法
Modern paradigm：


    

  • 量子 device 跑 expensive 部分。
    • 

  • 经典 computer 协调 / 优化。
    • 

  • 例：VQE（quantum 算 expectation, classical optimize parameters）。
    • 

  • QAOA（quantum 准备 ansatz, classical optimize γ, β）。
    • 



Cloud quantum：


    

  • IBM Quantum, AWS Braket, Azure Quantum。
    • 

  • 经典 driver code 在云上调用 quantum backend。
    • 



小结
量子电路模型是量子计算标准编程范式——qubit 水平线，gate 从左到右 apply。4 类元素——initialization（|0⟩^N）、unitary gates、measurement、classical control（feed-forward）。Mid-circuit measurement + feed-forward 用于 QEC / teleportation / magic state distillation / adaptive。Width = qubit 数、depth = 并行 layer 数，total gates = width × depth。Layered structure 让 hardware execution 高效——brick wall pattern。Variational ansatz——HEA（hardware efficient）+ QAOA（problem + mixer），parameter-shift rule 让 gradient 精确。Trotter decomposition 模拟 e^(-iHt)。Quantum computing 5 种等价模型——circuit、measurement-based / one-way、adiabatic、topological、quantum Turing machine。Compilation 5 步——decomposition、mapping、optimization、native gate translation、pulse scheduling。NISQ 时代（50-1000 qubit, 浅 circuit）适合 variational + quantum simulation + sampling，不适合 Shor / 大规模 Grover。FTQC 时代（2030-2040）surface code 100k-1M physical → 100-1000 logical 支持 Shor 等。Hybrid 经典-量子（VQE/QAOA）是 modern paradigm，cloud quantum 让远程 access。一个简单的检验：你能解释 width vs depth 的 trade-off？如果不能，circuit complexity 还需巩固。Quantum circuit 是连接抽象算法与具体硬件的标准 abstraction——理解它让从 paper 到 code 到 hardware 的路径清晰。
