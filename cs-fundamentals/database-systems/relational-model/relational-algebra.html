关系代数

核心概念

关系代数是关系数据库理论的数学基础，它定义了一组对关系（表）进行操作的运算，每个运算的输入和输出都是关系。理解关系代数有助于深入掌握 SQL 查询的本质——SQL 实质上是关系代数的声明式表达。

基本运算
选择（Selection）σ
选择运算从关系中筛选出满足条件的元组（行）：


σ_age>25(Employee)
等价 SQL：


SELECT * FROM Employee WHERE age > 25;
投影（Projection）π
投影运算从关系中选取特定的属性（列）并去除重复：


π_name,salary(Employee)
等价 SQL：


SELECT DISTINCT name, salary FROM Employee;
组合运算
选择与投影可以组合使用：


π_name,salary(σ_dept='Engineering'(Employee))
等价 SQL：


SELECT DISTINCT name, salary FROM Employee WHERE dept = 'Engineering';

-- 并运算：所有员工和实习生
SELECT name FROM Employee
UNION
SELECT name FROM Intern;

-- 差运算：有员工身份但不是经理的人
SELECT emp_id FROM Employee
EXCEPT
SELECT emp_id FROM Manager;


连接运算
连接是关系代数中最重要的二元运算，它将两个关系按照某种条件组合。






连接类型
定义
SQL 关键字





笛卡尔积
两关系所有元组的全排列组合
CROSS JOIN




θ-连接
笛卡尔积后按条件 θ 过滤
JOIN ... ON




等值连接
θ-连接中条件为等号
JOIN ... ON a = b




自然连接
等值连接 + 自动匹配同名属性 + 去重复列
NATURAL JOIN




左外连接
保留左关系所有元组，右侧无匹配则补 NULL
LEFT OUTER JOIN





-- 自然连接
SELECT * FROM Employee NATURAL JOIN Department;

-- 等值连接
SELECT e.name, d.dept_name
FROM Employee e
JOIN Department d ON e.dept_id = d.dept_id;

-- 左外连接
SELECT e.name, d.dept_name
FROM Employee e
LEFT JOIN Department d ON e.dept_id = d.dept_id;


除法运算
除法运算用于解决"全称量化"问题，即找出与某个集合中所有元素都有关联的元组。


假设关系 选课(学生, 课程) 和 必修课(课程)，求选修了所有必修课的学生：


选课 ÷ 必修课
等价 SQL：


SELECT 学生
FROM 选课
GROUP BY 学生
HAVING COUNT(DISTINCT 课程) = (SELECT COUNT(*) FROM 必修课)
   AND NOT EXISTS (
       SELECT 课程 FROM 必修课
       WHERE 课程 NOT IN (
           SELECT 课程 FROM 选课 AS sc WHERE sc.学生 = 选课.学生
       )
   );


关系代数表达式优化
查询优化器在执行 SQL 前，会将其转换为关系代数表达式并进行等价变换以提升性能。






优化规则
变换
效果





选择下推
σ(R ⋈ S) → σ(R) ⋈ S
减少连接数据量




投影下推
π(R ⋈ S) → π(π(R) ⋈ π(S))
减少中间列数




选择与笛卡尔积合并
σ*θ(R × S) → R ⋈*θ S
避免全组合




选择条件分解
σ_(c1∧c2)(R) → σ_c1(σ_c2(R))
逐步过滤







小结
    

  • 关系代数是 SQL 的数学基础，每个 SQL 查询都可以表示为关系代数表达式。
    • 

  • 选择和投影是最基本的一元运算，分别过滤行和选取列。
    • 

  • 连接是最重要的二元运算，自然连接和外连接是实际中最常用的形式。
    • 

  • 除法解决"全部满足"类问题，在 SQL 中通常用 NOT EXISTS 子查询实现。
    • 

  • 查询优化器通过选择下推、投影下推等等价变换来优化关系代数表达式。
