键值存储

核心概念

键值存储（Key-Value Store）是最简单的 NoSQL 数据模型，通过唯一的键直接映射到一个值。它以极高的读写性能和水平扩展能力著称，广泛用于缓存、会话管理和实时数据处理。

小结
    

  • Redis 是功能最丰富的键值存储，支持多种数据结构、持久化和分布式集群。
    • 

  • Memcached 更简单纯粹，适合纯缓存场景，多线程模型利于多核。
    • 

  • Cache-Aside 是最常用的缓存策略，更新 DB 后删除缓存保证最终一致。
    • 

  • 缓存穿透用布隆过滤器，缓存击穿用互斥锁，缓存雪崩用随机过期时间。
    • 

  • Redis Cluster 通过 16384 个哈希槽实现数据分片，支持水平扩展。
