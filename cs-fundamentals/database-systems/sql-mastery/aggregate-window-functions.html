聚合窗口函数

聚合查询基础

聚合函数对一组行进行计算并返回单个值。配合 GROUP BY 和 HAVING，可以实现灵活的分组统计。

聚合函数 功能 示例
COUNT(*) 统计行数 订单总数
SUM(col) 求和 销售总额
AVG(col) 平均值 平均客单价
MAX(col) 最大值 最高工资
MIN(col) 最小值 最早注册时间
COUNT(DISTINCT col) 去重计数 独立客户数 
SELECT
    dept_id,
    COUNT(*)        AS emp_count,
    AVG(salary)     AS avg_salary,
    MAX(salary)     AS max_salary
FROM employee
GROUP BY dept_id
HAVING COUNT(*) >= 5
ORDER BY avg_salary DESC;

GROUP BY 注意事项

  1. SELECT 中非聚合列必须出现在 GROUP BY 中（SQL 标准要求）
  2. WHERE 在分组前过滤，HAVING 在分组后过滤
  3. GROUP BY 可以按多列分组，也可以使用表达式
-- 按年月统计销售额
SELECT
    YEAR(order_date)  AS order_year,
    MONTH(order_date) AS order_month,
    SUM(amount)       AS total_amount
FROM orders
GROUP BY YEAR(order_date), MONTH(order_date)
ORDER BY order_year, order_month;

窗口函数概述

窗口函数（Window Function）在保留每一行数据的同时，对一组相关行进行计算。与聚合函数不同，窗口函数不会将多行合并为一行。

窗口函数语法
函数名(参数) OVER (
    [PARTITION BY 分区列]
    [ORDER BY 排序列]
    [ROWS/RANGE 窗口框架]
)




子句
作用





PARTITION BY
将数据划分为独立的窗口分区




ORDER BY
定义窗口内行的排列顺序




ROWS/RANGE
定义窗口框架的上下界







排名函数




函数
说明
并列处理





ROW_NUMBER()
连续编号，无并列
1, 2, 3, 4




RANK()
有并列，跳过后续编号
1, 2, 2, 4




DENSE_RANK()
有并列，不跳过编号
1, 2, 2, 3




NTILE(n)
将行均匀分为 n 组
组号 1~n





SELECT
    name,
    dept_id,
    salary,
    ROW_NUMBER() OVER (PARTITION BY dept_id ORDER BY salary DESC) AS row_num,
    RANK()       OVER (PARTITION BY dept_id ORDER BY salary DESC) AS rank_num,
    DENSE_RANK() OVER (PARTITION BY dept_id ORDER BY salary DESC) AS dense_num
FROM employee;
典型应用：取每组 Top-N
WITH ranked AS (
    SELECT
        name, dept_id, salary,
        ROW_NUMBER() OVER (PARTITION BY dept_id ORDER BY salary DESC) AS rn
    FROM employee
)
SELECT name, dept_id, salary
FROM ranked
WHERE rn <= 3;


偏移函数
偏移函数用于访问当前行的前后行数据，常用于环比、同比计算。






函数
说明





LAG(col, n, default)
向前取第 n 行的值




LEAD(col, n, default)
向后取第 n 行的值




FIRST_VALUE(col)
窗口内第一行的值




LAST_VALUE(col)
窗口内最后一行的值





SELECT
    order_month,
    total_amount,
    LAG(total_amount, 1)  OVER (ORDER BY order_month) AS prev_month,
    total_amount - LAG(total_amount, 1) OVER (ORDER BY order_month) AS month_diff
FROM monthly_sales;


聚合窗口函数
标准聚合函数（SUM、AVG、COUNT 等）也可以作为窗口函数使用，实现累计计算和移动平均。


SELECT
    order_date,
    amount,
    SUM(amount) OVER (ORDER BY order_date) AS running_total,
    AVG(amount) OVER (ORDER BY order_date ROWS BETWEEN 6 PRECEDING AND CURRENT ROW) AS moving_avg_7d,
    COUNT(*)    OVER (PARTITION BY customer_id) AS customer_order_count
FROM orders;
窗口框架




框架定义
含义





ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
从分区起始到当前行




ROWS BETWEEN 3 PRECEDING AND CURRENT ROW
当前行及前 3 行




ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING
前一行、当前行、后一行




ROWS BETWEEN CURRENT ROW AND UNBOUNDED FOLLOWING
当前行到分区末尾





-- 累计销售额与 7 日移动平均
SELECT
    sale_date,
    daily_amount,
    SUM(daily_amount) OVER (
        ORDER BY sale_date
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS cumulative_total,
    AVG(daily_amount) OVER (
        ORDER BY sale_date
        ROWS BETWEEN 6 PRECEDING AND CURRENT ROW
    ) AS avg_7day
FROM daily_sales;


实战综合示例
-- 综合报表：部门维度的员工排名、占比、累计
SELECT
    dept_id,
    name,
    salary,
    RANK() OVER (PARTITION BY dept_id ORDER BY salary DESC) AS dept_rank,
    ROUND(salary / SUM(salary) OVER (PARTITION BY dept_id) * 100, 2) AS salary_pct,
    SUM(salary) OVER (
        PARTITION BY dept_id ORDER BY salary DESC
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS dept_cumulative
FROM employee
ORDER BY dept_id, dept_rank;


小结
    

  • GROUP BY + HAVING 是聚合分析的基础，WHERE 过滤行，HAVING 过滤组
    • 

  • 窗口函数不减少行数，在保留明细的同时提供排名、累计、偏移等计算能力
    • 

  • ROW_NUMBER / RANK / DENSE_RANK 解决排名和 Top-N 问题
    • 

  • LAG / LEAD 实现环比、同比等前后行比较
    • 

  • SUM/AVG OVER 配合窗口框架实现累计和移动平均
    • 

  • 窗口函数是现代 SQL 分析的核心能力，所有主流数据库均已支持
