存储过程与函数

核心概念

存储过程和函数是预编译并存储在数据库中的程序单元。它们封装业务逻辑，减少网络往返，提供事务控制能力，并可通过权限管理限制数据访问。

特性 存储过程（Procedure） 函数（Function）
返回值 可无返回值，可有 OUT 参数 必须返回一个值
SQL 中调用 CALL procedure_name() SELECT function_name()
事务控制 可包含 COMMIT/ROLLBACK 通常不允许事务控制
用于表达式 不能 可以（WHERE、SELECT 中）
使用场景 复杂业务流程 数据转换、计算

存储过程

基本语法（PostgreSQL）

CREATE OR REPLACE PROCEDURE transfer_funds(
    sender_id BIGINT,
    receiver_id BIGINT,
    amount DECIMAL(15, 2)
)
LANGUAGE plpgsql AS $$
DECLARE
    sender_balance DECIMAL(15, 2);
BEGIN
    SELECT balance INTO sender_balance
    FROM accounts WHERE account_id = sender_id FOR UPDATE;

    IF sender_balance < amount THEN
        RAISE EXCEPTION '余额不足：当前余额 %, 转账金额 %', sender_balance, amount;
    END IF;

    UPDATE accounts SET balance = balance - amount WHERE account_id = sender_id;
    UPDATE accounts SET balance = balance + amount WHERE account_id = receiver_id;

    INSERT INTO transaction_log (from_account, to_account, amount, txn_type)
    VALUES (sender_id, receiver_id, amount, 'transfer');

    COMMIT;
END;
$$;

CALL transfer_funds(1001, 1002, 500.00);

基本语法（MySQL）

DELIMITER //
CREATE PROCEDURE transfer_funds(
    IN sender_id BIGINT,
    IN receiver_id BIGINT,
    IN amount DECIMAL(15, 2)
)
BEGIN
    DECLARE sender_balance DECIMAL(15, 2);
    DECLARE EXIT HANDLER FOR SQLEXCEPTION
    BEGIN
        ROLLBACK;
        SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = '转账失败';
    END;

    START TRANSACTION;

    SELECT balance INTO sender_balance
    FROM accounts WHERE account_id = sender_id FOR UPDATE;

    IF sender_balance < amount THEN
        SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = '余额不足';
    END IF;

    UPDATE accounts SET balance = balance - amount WHERE account_id = sender_id;
    UPDATE accounts SET balance = balance + amount WHERE account_id = receiver_id;

    COMMIT;
END //
DELIMITER ;

函数

CREATE OR REPLACE FUNCTION calculate_discount(
    total_amount DECIMAL(10, 2),
    membership_level VARCHAR(20)
)
RETURNS DECIMAL(10, 2)
LANGUAGE plpgsql AS $$
DECLARE
    discount_rate DECIMAL(3, 2);
BEGIN
    CASE membership_level
        WHEN 'gold'     THEN discount_rate := 0.20;
        WHEN 'silver'   THEN discount_rate := 0.10;
        WHEN 'bronze'   THEN discount_rate := 0.05;
        ELSE discount_rate := 0.00;
    END CASE;

    RETURN total_amount * (1 - discount_rate);
END;
$$;

SELECT order_id, total, calculate_discount(total, 'gold') AS discounted
FROM orders;

变量与流程控制

控制结构 语法 用途
IF/ELSIF IF ... THEN ... ELSIF ... END IF 条件分支
CASE CASE ... WHEN ... THEN ... END CASE 多分支选择
LOOP LOOP ... EXIT WHEN ... END LOOP 通用循环
WHILE WHILE ... LOOP ... END LOOP 条件循环
FOR FOR i IN 1..10 LOOP ... END LOOP 计数循环
FOR (查询) FOR rec IN SELECT ... LOOP 遍历查询结果
EXCEPTION EXCEPTION WHEN ... THEN 异常处理 
CREATE OR REPLACE FUNCTION batch_update_status()
RETURNS INT
LANGUAGE plpgsql AS $$
DECLARE
    rec RECORD;
    updated_count INT := 0;
BEGIN
    FOR rec IN
        SELECT order_id FROM orders
        WHERE status = 'pending'
        AND created_at < CURRENT_DATE - INTERVAL '30 days'
    LOOP
        UPDATE orders SET status = 'expired' WHERE order_id = rec.order_id;
        updated_count := updated_count + 1;
    END LOOP;

    RETURN updated_count;
END;
$$;

游标

游标用于逐行处理查询结果，适合需要逐条处理的场景。

CREATE OR REPLACE FUNCTION process_large_dataset()
RETURNS VOID
LANGUAGE plpgsql AS $$
DECLARE
    cur CURSOR FOR
        SELECT user_id, email FROM users WHERE status = 'active';
    rec RECORD;
BEGIN
    OPEN cur;
    LOOP
        FETCH cur INTO rec;
        EXIT WHEN NOT FOUND;

        PERFORM send_notification(rec.user_id, rec.email);
    END LOOP;
    CLOSE cur;
END;
$$;
游标操作 说明 注意事项
DECLARE 声明游标及关联查询 可带参数
OPEN 打开游标，执行查询 分配资源
FETCH 获取下一行 检查 NOT FOUND
CLOSE 关闭游标，释放资源 必须关闭

动态 SQL

动态 SQL 允许在运行时构建和执行 SQL 语句。

CREATE OR REPLACE FUNCTION dynamic_search(
    table_name TEXT,
    column_name TEXT,
    search_value TEXT
)
RETURNS SETOF RECORD
LANGUAGE plpgsql AS $$
BEGIN
    RETURN QUERY EXECUTE format(
        'SELECT * FROM %I WHERE %I = $1',
        table_name, column_name
    ) USING search_value;
END;
$$;
动态 SQL 方式 安全性 说明
EXECUTE + format 高 使用 %I（标识符）和 $1（参数）
字符串拼接 低 存在 SQL 注入风险，避免使用
PREPARE/EXECUTE 高 预编译语句，适合重复执行

触发器

CREATE OR REPLACE FUNCTION audit_log_trigger()
RETURNS TRIGGER
LANGUAGE plpgsql AS $$
BEGIN
    IF TG_OP = 'INSERT' THEN
        INSERT INTO audit_log (table_name, operation, new_data, created_at)
        VALUES (TG_TABLE_NAME, 'INSERT', row_to_json(NEW), NOW());
        RETURN NEW;
    ELSIF TG_OP = 'UPDATE' THEN
        INSERT INTO audit_log (table_name, operation, old_data, new_data, created_at)
        VALUES (TG_TABLE_NAME, 'UPDATE', row_to_json(OLD), row_to_json(NEW), NOW());
        RETURN NEW;
    ELSIF TG_OP = 'DELETE' THEN
        INSERT INTO audit_log (table_name, operation, old_data, created_at)
        VALUES (TG_TABLE_NAME, 'DELETE', row_to_json(OLD), NOW());
        RETURN OLD;
    END IF;
END;
$$;

CREATE TRIGGER trg_users_audit
    AFTER INSERT OR UPDATE OR DELETE ON users
    FOR EACH ROW EXECUTE FUNCTION audit_log_trigger();

最佳实践

实践 说明
避免过长过程 单个过程不超过 200 行，大逻辑拆分
参数校验 入口处校验参数合法性
异常处理 使用 EXCEPTION 块捕获并记录错误
避免游标滥用 优先使用集合操作替代逐行处理
动态 SQL 防注入 使用参数化查询，不要字符串拼接
版本管理 存储过程纳入代码仓库版本控制
权限最小化 使用 SECURITY DEFINER 时注意权限范围

小结

    

  • 存储过程适合封装含事务控制的复杂业务流程，函数适合数据计算和转换。
    • 

  • 流程控制语句（IF、LOOP、FOR）让过程式编程成为可能。
    • 

  • 游标适合逐行处理，但应优先考虑集合操作以获得更好的性能。
    • 

  • 动态 SQL 必须使用参数化方式防止 SQL 注入。
    • 

  • 触发器是实现审计日志、数据同步等跨表逻辑的有效手段。
