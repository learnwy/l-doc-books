哈希与位图索引

核心概念

除了 B+ 树索引，数据库还提供了多种专用索引类型，针对不同的查询模式进行优化。哈希索引擅长等值查询，位图索引适合低基数列，全文索引处理文本搜索，空间索引支持地理数据查询。

索引类型 擅长场景 不适合场景 典型数据库
哈希索引 等值查询 范围查询 MySQL Memory、Redis
位图索引 低基数列 高并发写入 Oracle、PostgreSQL
全文索引 文本搜索 精确匹配 MySQL、PostgreSQL
GiST 范围/空间查询 简单等值查询 PostgreSQL
GIN 多值/全文索引 频繁更新 PostgreSQL
空间索引 地理位置查询 非空间数据 MySQL、PostGIS

哈希索引通过哈希函数将键值映射到哈希桶，实现 O(1) 的等值查找。

-- PostgreSQL：创建哈希索引
CREATE INDEX idx_hash_email ON users USING hash (email);

-- 适用场景：精确匹配
SELECT * FROM users WHERE email = 'alice@example.com';

-- 不适用：范围查询（哈希索引无效）
SELECT * FROM users WHERE email > 'a%';

位图索引
位图索引为每个不同的值维护一个位向量，每个 bit 对应表中的一行。特别适合低基数列（如性别、状态）和数据仓库场景。


status 列有三个值：active, inactive, banned

active:   1 0 1 1 0 0 1 0
inactive: 0 1 0 0 1 0 0 1
banned:   0 0 0 0 0 1 0 0
-- Oracle 创建位图索引
CREATE BITMAP INDEX idx_bmp_status ON orders(status);
CREATE BITMAP INDEX idx_bmp_region ON orders(region);

-- 位图索引的优势：多条件 AND/OR 可直接做位运算
SELECT COUNT(*) FROM orders
WHERE status = 'active' AND region = 'east';
-- active 位图 AND east 位图 → 快速得到结果

全文索引
全文索引专门用于文本搜索，支持分词、相关性排序和模糊匹配。


-- MySQL：创建全文索引
CREATE FULLTEXT INDEX idx_ft_content ON articles(title, content);

SELECT * FROM articles
WHERE MATCH(title, content) AGAINST('数据库 优化' IN NATURAL LANGUAGE MODE);

-- PostgreSQL：使用 tsvector 和 tsquery
ALTER TABLE articles ADD COLUMN search_vector tsvector;

UPDATE articles SET search_vector =
    to_tsvector('chinese', title || ' ' || content);

CREATE INDEX idx_gin_search ON articles USING gin(search_vector);

SELECT title, ts_rank(search_vector, query) AS rank
FROM articles, to_tsquery('chinese', '数据库 & 优化') query
WHERE search_vector @@ query
ORDER BY rank DESC;

GiST 与 GIN 索引
PostgreSQL 提供的两种通用索引框架，支持复杂数据类型。






索引类型
全称
适用数据类型
特点





GiST
Generalized Search Tree
范围类型、几何、全文
有损，支持最近邻




GIN
Generalized Inverted Index
数组、JSONB、全文
精确，查找快





-- GIN 索引：JSONB 查询
CREATE INDEX idx_gin_data ON events USING gin(metadata);

SELECT * FROM events WHERE metadata @> '{"type": "click"}';

-- GIN 索引：数组包含查询
CREATE INDEX idx_gin_tags ON articles USING gin(tags);

SELECT * FROM articles WHERE tags @> ARRAY['database', 'index'];

-- GiST 索引：范围查询
CREATE INDEX idx_gist_range ON reservations USING gist(during);

SELECT * FROM reservations WHERE during && '[2024-01-01, 2024-01-31]'::daterange;


空间索引
空间索引基于 R 树结构，支持地理位置和几何图形的高效查询。


-- PostGIS 空间索引
CREATE INDEX idx_gist_location ON stores USING gist(location);

-- 查找 5 公里内的商店
SELECT name, ST_Distance(location, ST_MakePoint(116.40, 39.90)::geography) AS dist
FROM stores
WHERE ST_DWithin(location, ST_MakePoint(116.40, 39.90)::geography, 5000)
ORDER BY dist;

-- MySQL 空间索引
CREATE SPATIAL INDEX idx_spatial ON stores(location);

SELECT name FROM stores
WHERE ST_Distance_Sphere(location, POINT(116.40, 39.90)) < 5000;


索引类型选择指南


小结
    

  • 哈希索引的等值查询是 O(1)，但不支持范围查询和排序。
    • 

  • 位图索引通过位运算加速多条件组合查询，适合 OLAP 场景的低基数列。
    • 

  • 全文索引支持分词和相关性排序，是文本搜索的标准方案。
    • 

  • GIN 索引适合 JSONB、数组和全文搜索，GiST 适合范围和空间数据。
    • 

  • 索引选择应根据查询模式和数据特征决定，没有万能索引。
