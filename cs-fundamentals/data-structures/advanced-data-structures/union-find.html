并查集

核心概念

并查集（Union-Find）也称不相交集合（Disjoint Set Union），是一种专门管理元素分组的数据结构。它高效地支持两种核心操作：查找（Find）——确定某个元素属于哪个集合；合并（Union）——将两个集合合并为一个。并查集的精妙之处在于，通过路径压缩和按秩合并两项优化，单次操作的均摊时间复杂度可以降至 O(α(n))O(\alpha(n))O(α(n))，其中 α\alphaα 是反阿克曼函数，在实际应用中可视为常数。

基础实现与 Find/Union 操作
并查集的底层表示非常简单：用一个数组 parent 来记录每个元素的父节点。初始状态下，每个元素的父节点指向自身，表示各自独立成集合。


class UnionFind {
  private parent: number[];
  private count: number;

  constructor(n: number) {
    this.parent = Array.from({ length: n }, (_, i) => i);
    this.count = n;
  }

  find(x: number): number {
    while (this.parent[x] !== x) {
      x = this.parent[x];
    }
    return x;
  }

  union(x: number, y: number): void {
    const rootX = this.find(x);
    const rootY = this.find(y);
    if (rootX === rootY) return;
    this.parent[rootX] = rootY;
    this.count--;
  }

  connected(x: number, y: number): boolean {
    return this.find(x) === this.find(y);
  }

  getCount(): number {
    return this.count;
  }
}
这个基础版本存在一个严重问题：在最坏情况下，树会退化为链表，使得 find 操作的时间复杂度变为 O(n)O(n)O(n)。例如，依次执行 union(0,1)、union(1,2)、union(2,3)……会形成一条从 0 到 n-1 的长链。


路径压缩优化
路径压缩（Path Compression）的思想是：在执行 find 操作时，将沿途经过的每个节点都直接指向根节点，从而将树的高度压缩到接近 1。这种优化有两种常见实现方式。


完全路径压缩（递归版）：将路径上所有节点直接连接到根。


find(x: number): number {
  if (this.parent[x] !== x) {
    this.parent[x] = this.find(this.parent[x]);
  }
  return this.parent[x];
}
路径分裂（Path Splitting）：让路径上的每个节点指向其祖父节点，每次只跳一级。


find(x: number): number {
  while (this.parent[x] !== x) {
    const next = this.parent[x];
    this.parent[x] = this.parent[next];
    x = next;
  }
  return x;
}
路径减半（Path Halving）：让路径上每隔一个节点指向其祖父节点。


find(x: number): number {
  while (this.parent[x] !== x) {
    this.parent[x] = this.parent[this.parent[x]];
    x = this.parent[x];
  }
  return x;
}
三种方式的均摊效果相同，实际工程中完全路径压缩最为常用。路径压缩后，后续对同一路径上节点的 find 操作将在 O(1)O(1)O(1) 时间内完成。


按秩合并优化
按秩合并（Union by Rank）解决的是合并时的选择问题：应该让哪棵树成为另一棵的子树？策略是始终将较矮的树挂到较高的树下，从而控制合并后树的高度增长。


class UnionFindOptimized {
  private parent: number[];
  private rank: number[];
  private count: number;

  constructor(n: number) {
    this.parent = Array.from({ length: n }, (_, i) => i);
    this.rank = new Array(n).fill(0);
    this.count = n;
  }

  find(x: number): number {
    if (this.parent[x] !== x) {
      this.parent[x] = this.find(this.parent[x]);
    }
    return this.parent[x];
  }

  union(x: number, y: number): boolean {
    const rootX = this.find(x);
    const rootY = this.find(y);
    if (rootX === rootY) return false;

    if (this.rank[rootX] < this.rank[rootY]) {
      this.parent[rootX] = rootY;
    } else if (this.rank[rootX] > this.rank[rootY]) {
      this.parent[rootY] = rootX;
    } else {
      this.parent[rootY] = rootX;
      this.rank[rootX]++;
    }

    this.count--;
    return true;
  }

  connected(x: number, y: number): boolean {
    return this.find(x) === this.find(y);
  }

  getCount(): number {
    return this.count;
  }
}
另一种变体是按集合大小合并（Union by Size），将较小的集合并入较大的集合。这种方式可以同时维护每个集合的元素数量。


class UnionFindBySize {
  private parent: number[];
  private size: number[];

  constructor(n: number) {
    this.parent = Array.from({ length: n }, (_, i) => i);
    this.size = new Array(n).fill(1);
  }

  find(x: number): number {
    if (this.parent[x] !== x) {
      this.parent[x] = this.find(this.parent[x]);
    }
    return this.parent[x];
  }

  union(x: number, y: number): boolean {
    const rootX = this.find(x);
    const rootY = this.find(y);
    if (rootX === rootY) return false;

    if (this.size[rootX] < this.size[rootY]) {
      this.parent[rootX] = rootY;
      this.size[rootY] += this.size[rootX];
    } else {
      this.parent[rootY] = rootX;
      this.size[rootX] += this.size[rootY];
    }
    return true;
  }

  getSize(x: number): number {
    return this.size[this.find(x)];
  }
}

经典应用场景
连通分量计数
给定 nnn 个节点和若干边，求图中连通分量的数量。


function countComponents(n: number, edges: [number, number][]): number {
  const uf = new UnionFindOptimized(n);
  for (const [u, v] of edges) {
    uf.union(u, v);
  }
  return uf.getCount();
}

console.log(
  countComponents(5, [
    [0, 1],
    [1, 2],
    [3, 4],
  ]),
); // 2
Kruskal 最小生成树
Kruskal 算法按边权从小到大排序，依次尝试加入每条边。若边的两端已在同一集合中，则跳过；否则合并两个集合。并查集在此过程中高效判断两端连通性。


interface Edge {
  u: number;
  v: number;
  weight: number;
}

function kruskal(n: number, edges: Edge[]): { mstWeight: number; mstEdges: Edge[] } {
  edges.sort((a, b) => a.weight - b.weight);
  const uf = new UnionFindOptimized(n);
  const mstEdges: Edge[] = [];
  let mstWeight = 0;

  for (const edge of edges) {
    if (uf.union(edge.u, edge.v)) {
      mstEdges.push(edge);
      mstWeight += edge.weight;
      if (mstEdges.length === n - 1) break;
    }
  }

  return { mstWeight, mstEdges };
}
检测无向图中的环
如果一条边的两个端点已经属于同一个集合，那么加入这条边必然形成环。


function hasCycle(n: number, edges: [number, number][]): boolean {
  const uf = new UnionFindOptimized(n);
  for (const [u, v] of edges) {
    if (uf.connected(u, v)) return true;
    uf.union(u, v);
  }
  return false;
}
二维网格中的岛屿数量
将二维网格问题转化为并查集问题：将每个陆地格子视为一个节点，相邻的陆地格子执行合并。


function numIslands(grid: string[][]): number {
  const rows = grid.length;
  const cols = grid[0].length;
  const uf = new UnionFindOptimized(rows * cols);
  let waterCount = 0;

  for (let i = 0; i < rows; i++) {
    for (let j = 0; j < cols; j++) {
      if (grid[i][j] === '0') {
        waterCount++;
        continue;
      }
      const id = i * cols + j;
      if (i + 1 < rows && grid[i + 1][j] === '1') uf.union(id, (i + 1) * cols + j);
      if (j + 1 < cols && grid[i][j + 1] === '1') uf.union(id, i * cols + j + 1);
    }
  }

  return uf.getCount() - waterCount;
}
小结
    

  • 并查集是解决动态连通性问题的最优数据结构，支持近常数时间的合并与查找
    • 

  • 路径压缩通过将节点直接连接到根节点来压缩树的高度，三种变体效果等价
    • 

  • 按秩合并通过将矮树挂到高树下来控制树高增长，可按 rank 或 size 实现
    • 

  • 两项优化组合后，单次操作的均摊时间复杂度为 O(α(n))O(\alpha(n))O(α(n))，实际应用中可视为 O(1)O(1)O(1)
    • 

  • 并查集不支持拆分操作——一旦合并，无法高效地将集合再次分开
    • 

  • 经典应用包括连通分量计数、Kruskal 最小生成树、无向图环检测和二维网格问题
