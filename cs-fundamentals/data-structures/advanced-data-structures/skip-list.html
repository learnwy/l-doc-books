跳表

核心概念

跳表（Skip List）是一种基于概率的有序数据结构，由 William Pugh 于 1990 年提出。它在有序链表的基础上增加多层索引，通过"空间换时间"的策略实现 O(log⁡n)O(\log n)O(logn) 期望时间的查找、插入和删除操作。跳表的设计哲学是：用随机化替代严格的平衡维护，以更简单的实现获得与平衡树相当的性能。

跳表的每个节点拥有若干层的前向指针。底层（Level 1）包含所有元素，形成完整的有序链表；上层逐级稀疏，高层索引节点以约 1/p1/p1/p 的概率从下层提升（通常 p=0.5p = 0.5p=0.5 或 p=0.25p = 0.25p=0.25）。

随机层数生成与概率分析
跳表的核心随机化机制是层数生成：每个新节点通过随机过程决定其层数。最基本的策略是反复抛硬币，连续出现正面的次数加一即为节点层数。


const MAX_LEVEL = 32;
const P = 0.25;

function randomLevel(): number {
  let level = 1;
  while (Math.random() < P && level < MAX_LEVEL) {
    level++;
  }
  return level;
}
当 p=0.5p = 0.5p=0.5 时，平均每个节点有 2 个前向指针（各层指针数为等比级数 1+1/2+1/4+⋯=21 + 1/2 + 1/4 + \cdots = 21+1/2+1/4+⋯=2）。当 p=0.25p = 0.25p=0.25 时，平均每个节点约 1.33 个前向指针，空间更省但索引更稀疏。


查找过程从最高层的 HEAD 出发，在每层尽可能向右走（只要下一个节点的值不超过目标），走不动时下降一层。每层期望跳过 1/p1/p1/p 个节点，共 O(log⁡1/pn)O(\log_{1/p} n)O(log1/p​n) 层，因此总比较次数为 O(log⁡n)O(\log n)O(logn)。

完整实现
interface SkipListNode<T> {
  key: number;
  value: T;
  forward: (SkipListNode<T> | null)[];
}

class SkipList<T> {
  private head: SkipListNode<T>;
  private level: number;
  private size: number;

  constructor() {
    this.head = this.createNode(-Infinity, undefined as T, MAX_LEVEL);
    this.level = 1;
    this.size = 0;
  }

  private createNode(key: number, value: T, level: number): SkipListNode<T> {
    return {
      key,
      value,
      forward: new Array(level).fill(null),
    };
  }

  search(key: number): T | undefined {
    let current = this.head;
    for (let i = this.level - 1; i >= 0; i--) {
      while (current.forward[i] !== null && current.forward[i]!.key < key) {
        current = current.forward[i]!;
      }
    }
    current = current.forward[0]!;
    if (current !== null && current.key === key) {
      return current.value;
    }
    return undefined;
  }

  insert(key: number, value: T): void {
    const update: SkipListNode<T>[] = new Array(MAX_LEVEL).fill(this.head);
    let current = this.head;

    for (let i = this.level - 1; i >= 0; i--) {
      while (current.forward[i] !== null && current.forward[i]!.key < key) {
        current = current.forward[i]!;
      }
      update[i] = current;
    }

    current = current.forward[0]!;

    if (current !== null && current.key === key) {
      current.value = value;
      return;
    }

    const newLevel = randomLevel();
    if (newLevel > this.level) {
      for (let i = this.level; i < newLevel; i++) {
        update[i] = this.head;
      }
      this.level = newLevel;
    }

    const newNode = this.createNode(key, value, newLevel);
    for (let i = 0; i < newLevel; i++) {
      newNode.forward[i] = update[i].forward[i];
      update[i].forward[i] = newNode;
    }

    this.size++;
  }

  delete(key: number): boolean {
    const update: SkipListNode<T>[] = new Array(MAX_LEVEL).fill(this.head);
    let current = this.head;

    for (let i = this.level - 1; i >= 0; i--) {
      while (current.forward[i] !== null && current.forward[i]!.key < key) {
        current = current.forward[i]!;
      }
      update[i] = current;
    }

    current = current.forward[0]!;

    if (current === null || current.key !== key) {
      return false;
    }

    for (let i = 0; i < this.level; i++) {
      if (update[i].forward[i] !== current) break;
      update[i].forward[i] = current.forward[i];
    }

    while (this.level > 1 && this.head.forward[this.level - 1] === null) {
      this.level--;
    }

    this.size--;
    return true;
  }

  rangeQuery(low: number, high: number): T[] {
    const result: T[] = [];
    let current = this.head;

    for (let i = this.level - 1; i >= 0; i--) {
      while (current.forward[i] !== null && current.forward[i]!.key < low) {
        current = current.forward[i]!;
      }
    }

    current = current.forward[0]!;
    while (current !== null && current.key <= high) {
      result.push(current.value);
      current = current.forward[0]!;
    }

    return result;
  }

  getSize(): number {
    return this.size;
  }
}
使用示例：


const sl = new SkipList<string>();
sl.insert(3, 'three');
sl.insert(6, 'six');
sl.insert(7, 'seven');
sl.insert(9, 'nine');
sl.insert(12, 'twelve');

console.log(sl.search(6)); // "six"
console.log(sl.search(8)); // undefined
console.log(sl.rangeQuery(5, 10)); // ["six", "seven", "nine"]

sl.delete(7);
console.log(sl.rangeQuery(5, 10)); // ["six", "nine"]
Redis 中的跳表实现
Redis 的有序集合（Sorted Set，ZSET）底层采用跳表实现。Redis 选择跳表而非红黑树，核心原因有三：实现更简单便于维护、范围查询天然高效、并发修改锁粒度更小。


Redis 的跳表实现有几个关键特点：


双向链表：底层链表增加了向后指针，支持反向遍历（如 ZREVRANGE 命令）。


p=0.25p = 0.25p=0.25：Redis 选择 p=1/4p = 1/4p=1/4 而非 1/21/21/2，在期望搜索时间增加不多的前提下显著减少空间开销。


最大层数 32：理论上可支持 432≈1.8×10194^{32} \approx 1.8 \times 10^{19}432≈1.8×1019 个元素。


分值+成员双排序：节点按分值排序，分值相同时按成员的字典序排序。

Redis 在跳表节点中维护了一个 span 字段，记录当前层每个前向指针跨越的节点数。通过累加搜索路径上的 span 值，可以在 O(log⁡n)O(\log n)O(logn) 时间内计算元素的排名，这是红黑树难以高效实现的操作。


小结
    

  • 跳表通过多层有序链表 + 随机化层数实现 O(log⁡n)O(\log n)O(logn) 期望时间的查找、插入和删除
    • 

  • 概率参数 ppp 控制空间与时间的权衡：p=1/2p = 1/2p=1/2 平衡两者，p=1/4p = 1/4p=1/4（Redis 选择）更省空间
    • 

  • 跳表的范围查询天然高效——找到起点后沿底层链表顺序扫描即可，无需中序遍历
    • 

  • Redis ZSET 选择跳表而非红黑树，核心优势在于实现简单、范围查询高效、并发锁粒度小
    • 

  • 跳表的期望空间复杂度为 O(n)O(n)O(n)，通过 span 字段可以扩展支持 O(log⁡n)O(\log n)O(logn) 时间的排名查询
    • 

  • 跳表是工程实践中平衡树的实用替代方案，在许多场景下以更低的实现成本获得相当的性能
