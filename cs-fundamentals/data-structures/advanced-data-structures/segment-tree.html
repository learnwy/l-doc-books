线段树

核心概念

线段树（Segment Tree）是一种基于分治思想构建的二叉树结构，专门用于解决区间查询和区间修改问题。它将一个长度为 nnn 的数组递归地划分为若干区间，每个树节点存储对应区间的聚合信息（如区间和、最大值、最小值），从而支持 O(log⁡n)O(\log n)O(logn) 时间的区间查询和更新操作。

建树与基本查询
线段树通常使用数组模拟完全二叉树，节点 iii 的左子节点为 2i2i2i，右子节点为 2i+12i+12i+1。建树过程自底向上：叶子节点存储原始数组值，内部节点存储子区间的聚合结果。


class SegmentTree {
  private tree: number[];
  private n: number;

  constructor(nums: number[]) {
    this.n = nums.length;
    this.tree = new Array(4 * this.n).fill(0);
    this.build(nums, 1, 0, this.n - 1);
  }

  private build(nums: number[], node: number, start: number, end: number): void {
    if (start === end) {
      this.tree[node] = nums[start];
      return;
    }
    const mid = Math.floor((start + end) / 2);
    this.build(nums, 2 * node, start, mid);
    this.build(nums, 2 * node + 1, mid + 1, end);
    this.tree[node] = this.tree[2 * node] + this.tree[2 * node + 1];
  }

  query(l: number, r: number): number {
    return this.queryRange(1, 0, this.n - 1, l, r);
  }

  private queryRange(node: number, start: number, end: number, l: number, r: number): number {
    if (l > end || r < start) return 0;
    if (l <= start && end <= r) return this.tree[node];
    const mid = Math.floor((start + end) / 2);
    return this.queryRange(2 * node, start, mid, l, r) + this.queryRange(2 * node + 1, mid + 1, end, l, r);
  }

  update(index: number, value: number): void {
    this.pointUpdate(1, 0, this.n - 1, index, value);
  }

  private pointUpdate(node: number, start: number, end: number, index: number, value: number): void {
    if (start === end) {
      this.tree[node] = value;
      return;
    }
    const mid = Math.floor((start + end) / 2);
    if (index <= mid) {
      this.pointUpdate(2 * node, start, mid, index, value);
    } else {
      this.pointUpdate(2 * node + 1, mid + 1, end, index, value);
    }
    this.tree[node] = this.tree[2 * node] + this.tree[2 * node + 1];
  }
}
使用示例：


const nums = [1, 2, 3, 4, 5, 6, 7, 8];
const st = new SegmentTree(nums);

console.log(st.query(0, 3)); // 10 (1+2+3+4)
console.log(st.query(2, 5)); // 18 (3+4+5+6)

st.update(3, 10);
console.log(st.query(0, 3)); // 16 (1+2+3+10)
查询过程的核心逻辑是：当查询区间完全覆盖当前节点区间时直接返回；当完全不相交时返回零值；否则递归查询左右子树并合并结果。这种分治策略保证了每层最多访问 O(1)O(1)O(1) 个节点，总时间 O(log⁡n)O(\log n)O(logn)。


懒标记与区间更新
当需要对一个区间内的所有元素执行相同的修改（如区间加值）时，朴素的逐点更新将退化为 O(nlog⁡n)O(n \log n)O(nlogn)。懒标记（Lazy Propagation）通过延迟更新解决了这一问题：将更新操作暂存在节点上，只在必要时（查询或进一步更新触及该区间）才向下传播。


class LazySegmentTree {
  private tree: number[];
  private lazy: number[];
  private n: number;

  constructor(nums: number[]) {
    this.n = nums.length;
    this.tree = new Array(4 * this.n).fill(0);
    this.lazy = new Array(4 * this.n).fill(0);
    this.build(nums, 1, 0, this.n - 1);
  }

  private build(nums: number[], node: number, start: number, end: number): void {
    if (start === end) {
      this.tree[node] = nums[start];
      return;
    }
    const mid = Math.floor((start + end) / 2);
    this.build(nums, 2 * node, start, mid);
    this.build(nums, 2 * node + 1, mid + 1, end);
    this.tree[node] = this.tree[2 * node] + this.tree[2 * node + 1];
  }

  private pushDown(node: number, start: number, end: number): void {
    if (this.lazy[node] !== 0) {
      const mid = Math.floor((start + end) / 2);
      const leftLen = mid - start + 1;
      const rightLen = end - mid;

      this.tree[2 * node] += this.lazy[node] * leftLen;
      this.tree[2 * node + 1] += this.lazy[node] * rightLen;
      this.lazy[2 * node] += this.lazy[node];
      this.lazy[2 * node + 1] += this.lazy[node];
      this.lazy[node] = 0;
    }
  }

  rangeUpdate(l: number, r: number, val: number): void {
    this.updateRange(1, 0, this.n - 1, l, r, val);
  }

  private updateRange(node: number, start: number, end: number, l: number, r: number, val: number): void {
    if (l > end || r < start) return;
    if (l <= start && end <= r) {
      this.tree[node] += val * (end - start + 1);
      this.lazy[node] += val;
      return;
    }
    this.pushDown(node, start, end);
    const mid = Math.floor((start + end) / 2);
    this.updateRange(2 * node, start, mid, l, r, val);
    this.updateRange(2 * node + 1, mid + 1, end, l, r, val);
    this.tree[node] = this.tree[2 * node] + this.tree[2 * node + 1];
  }

  query(l: number, r: number): number {
    return this.queryRange(1, 0, this.n - 1, l, r);
  }

  private queryRange(node: number, start: number, end: number, l: number, r: number): number {
    if (l > end || r < start) return 0;
    if (l <= start && end <= r) return this.tree[node];
    this.pushDown(node, start, end);
    const mid = Math.floor((start + end) / 2);
    return this.queryRange(2 * node, start, mid, l, r) + this.queryRange(2 * node + 1, mid + 1, end, l, r);
  }
}
使用示例：


const nums = [1, 2, 3, 4, 5];
const lst = new LazySegmentTree(nums);

console.log(lst.query(1, 3)); // 9 (2+3+4)

lst.rangeUpdate(1, 3, 10);
console.log(lst.query(1, 3)); // 39 (12+13+14)
console.log(lst.query(0, 4)); // 55 (1+12+13+14+5)
区间最值线段树
线段树不仅可以维护区间和，还可以维护区间最大值、最小值、最大公约数等满足结合律的聚合操作。只需修改合并逻辑即可。


class MinMaxSegmentTree {
  private maxTree: number[];
  private minTree: number[];
  private n: number;

  constructor(nums: number[]) {
    this.n = nums.length;
    this.maxTree = new Array(4 * this.n).fill(-Infinity);
    this.minTree = new Array(4 * this.n).fill(Infinity);
    this.build(nums, 1, 0, this.n - 1);
  }

  private build(nums: number[], node: number, start: number, end: number): void {
    if (start === end) {
      this.maxTree[node] = nums[start];
      this.minTree[node] = nums[start];
      return;
    }
    const mid = Math.floor((start + end) / 2);
    this.build(nums, 2 * node, start, mid);
    this.build(nums, 2 * node + 1, mid + 1, end);
    this.maxTree[node] = Math.max(this.maxTree[2 * node], this.maxTree[2 * node + 1]);
    this.minTree[node] = Math.min(this.minTree[2 * node], this.minTree[2 * node + 1]);
  }

  queryMax(l: number, r: number): number {
    return this.queryMaxRange(1, 0, this.n - 1, l, r);
  }

  private queryMaxRange(node: number, start: number, end: number, l: number, r: number): number {
    if (l > end || r < start) return -Infinity;
    if (l <= start && end <= r) return this.maxTree[node];
    const mid = Math.floor((start + end) / 2);
    return Math.max(
      this.queryMaxRange(2 * node, start, mid, l, r),
      this.queryMaxRange(2 * node + 1, mid + 1, end, l, r),
    );
  }

  queryMin(l: number, r: number): number {
    return this.queryMinRange(1, 0, this.n - 1, l, r);
  }

  private queryMinRange(node: number, start: number, end: number, l: number, r: number): number {
    if (l > end || r < start) return Infinity;
    if (l <= start && end <= r) return this.minTree[node];
    const mid = Math.floor((start + end) / 2);
    return Math.min(
      this.queryMinRange(2 * node, start, mid, l, r),
      this.queryMinRange(2 * node + 1, mid + 1, end, l, r),
    );
  }
}

动态开点与持久化
当值域极大但实际使用的节点很少时（如值域为 10910^9109 但操作数只有 10510^5105），预分配 4n4n4n 空间不可行。动态开点线段树只在需要时创建节点，用指针（或数组索引模拟指针）替代隐式下标。


class DynamicSegmentTree {
  private nodes: { left: number; right: number; sum: number }[];
  private root: number;

  constructor() {
    this.nodes = [{ left: 0, right: 0, sum: 0 }];
    this.root = this.newNode();
  }

  private newNode(): number {
    this.nodes.push({ left: 0, right: 0, sum: 0 });
    return this.nodes.length - 1;
  }

  update(node: number, start: number, end: number, index: number, val: number): void {
    if (start === end) {
      this.nodes[node].sum += val;
      return;
    }
    const mid = Math.floor((start + end) / 2);
    if (index <= mid) {
      if (this.nodes[node].left === 0) this.nodes[node].left = this.newNode();
      this.update(this.nodes[node].left, start, mid, index, val);
    } else {
      if (this.nodes[node].right === 0) this.nodes[node].right = this.newNode();
      this.update(this.nodes[node].right, mid + 1, end, index, val);
    }
    const leftSum = this.nodes[node].left ? this.nodes[this.nodes[node].left].sum : 0;
    const rightSum = this.nodes[node].right ? this.nodes[this.nodes[node].right].sum : 0;
    this.nodes[node].sum = leftSum + rightSum;
  }

  query(node: number, start: number, end: number, l: number, r: number): number {
    if (node === 0 || l > end || r < start) return 0;
    if (l <= start && end <= r) return this.nodes[node].sum;
    const mid = Math.floor((start + end) / 2);
    return this.query(this.nodes[node].left, start, mid, l, r) + this.query(this.nodes[node].right, mid + 1, end, l, r);
  }

  getRoot(): number {
    return this.root;
  }
}
小结
    

  • 线段树是解决区间查询与区间修改问题的核心数据结构，基于分治思想将数组递归地划分为子区间
    • 

  • 基础线段树支持 O(log⁡n)O(\log n)O(logn) 的单点更新和区间查询，空间开销为 O(4n)O(4n)O(4n)
    • 

  • **懒标记（Lazy Propagation）**通过延迟下推实现 O(log⁡n)O(\log n)O(logn) 的区间批量更新，是线段树最重要的优化技术
    • 

  • 线段树可以维护任何满足结合律的聚合操作，包括求和、最值、GCD、异或等
    • 

  • 动态开点技术解决了值域极大时的空间问题，按需创建节点而非预分配
    • 

  • 线段树是竞赛和工程中使用频率最高的高级数据结构之一，掌握它将为你打开区间问题的大门
