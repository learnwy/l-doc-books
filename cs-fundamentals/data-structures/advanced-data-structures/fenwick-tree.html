树状数组

核心概念

树状数组（Binary Indexed Tree，BIT），也称 Fenwick Tree，是一种利用二进制下标特性来组织数据的数组结构。它能够在 O(log⁡n)O(\log n)O(logn) 时间内完成单点更新和前缀和查询两种操作。与线段树相比，树状数组的实现更为简洁（核心代码仅需数行），常数因子更小，在适用场景下是更优的选择。

树状数组的核心秘密在于**最低有效位（lowbit）**操作：lowbit(x) = x & (-x)，它提取 xxx 的二进制表示中最低位的 1。这个操作决定了每个位置管理的区间长度：tree[i] 管理从 a[i - lowbit(i) + 1] 到 a[i] 这段区间的聚合值。

lowbit 原理与索引规律
理解树状数组的关键在于理解 lowbit 函数。对于正整数 xxx，lowbit(x) 返回 xxx 的二进制表示中最低位 1 所对应的值。


function lowbit(x: number): number {
  return x & -x;
}
计算机中负数以补码存储，-x 等价于 ~x + 1（取反加一）。x & (-x) 的结果恰好保留了 xxx 最低位的 1，其余位全部清零。

这种结构之所以高效，是因为：


    

  • 查询：从位置 iii 出发，每次减去 lowbit(i) 跳到前一个管理区间的末尾，最多跳 O(log⁡n)O(\log n)O(logn) 次即可累加出前缀和
    • 

  • 更新：从位置 iii 出发，每次加上 lowbit(i) 跳到下一个包含位置 iii 的管理节点，最多更新 O(log⁡n)O(\log n)O(logn) 个节点
    • 



基础实现：前缀和与单点更新
class BIT {
  private tree: number[];
  private n: number;

  constructor(n: number) {
    this.n = n;
    this.tree = new Array(n + 1).fill(0);
  }

  private lowbit(x: number): number {
    return x & -x;
  }

  update(i: number, delta: number): void {
    while (i <= this.n) {
      this.tree[i] += delta;
      i += this.lowbit(i);
    }
  }

  prefixSum(i: number): number {
    let sum = 0;
    while (i > 0) {
      sum += this.tree[i];
      i -= this.lowbit(i);
    }
    return sum;
  }

  rangeSum(l: number, r: number): number {
    return this.prefixSum(r) - this.prefixSum(l - 1);
  }
}
从已有数组构建树状数组有两种方式：


方式一：逐个插入，时间复杂度 O(nlog⁡n)O(n \log n)O(nlogn)。


function buildFromArray(nums: number[]): BIT {
  const bit = new BIT(nums.length);
  for (let i = 0; i < nums.length; i++) {
    bit.update(i + 1, nums[i]);
  }
  return bit;
}
方式二：线性建树，时间复杂度 O(n)O(n)O(n)。利用每个节点只需要向其直接父节点传递值的性质。


function buildLinear(nums: number[]): number[] {
  const n = nums.length;
  const tree = new Array(n + 1).fill(0);
  for (let i = 1; i <= n; i++) {
    tree[i] += nums[i - 1];
    const parent = i + (i & -i);
    if (parent <= n) {
      tree[parent] += tree[i];
    }
  }
  return tree;
}
使用示例：


const nums = [1, 2, 3, 4, 5];
const bit = buildFromArray(nums);

console.log(bit.prefixSum(3)); // 6 (1+2+3)
console.log(bit.rangeSum(2, 4)); // 9 (2+3+4)

bit.update(3, 7);
console.log(bit.prefixSum(3)); // 13 (1+2+10)
console.log(bit.rangeSum(2, 4)); // 16 (2+10+4)
差分树状数组与区间更新
标准树状数组只支持单点更新。但通过**差分（Difference Array）**技巧，可以实现区间更新 + 单点查询，甚至区间更新 + 区间查询。


区间更新 + 单点查询：维护差分数组 d[i]=a[i]−a[i−1]d[i] = a[i] - a[i-1]d[i]=a[i]−a[i−1]，则 a[i]=∑j=1id[j]a[i] = \sum_{j=1}^{i} d[j]a[i]=∑j=1i​d[j]。对区间 [l,r][l, r][l,r] 加 vvv，等价于 d[l] += v 和 d[r+1] -= v。


class BITRangeUpdate {
  private tree: number[];
  private n: number;

  constructor(n: number) {
    this.n = n;
    this.tree = new Array(n + 2).fill(0);
  }

  private lowbit(x: number): number {
    return x & -x;
  }

  private add(i: number, delta: number): void {
    while (i <= this.n) {
      this.tree[i] += delta;
      i += this.lowbit(i);
    }
  }

  rangeAdd(l: number, r: number, val: number): void {
    this.add(l, val);
    this.add(r + 1, -val);
  }

  pointQuery(i: number): number {
    let sum = 0;
    while (i > 0) {
      sum += this.tree[i];
      i -= this.lowbit(i);
    }
    return sum;
  }
}
区间更新 + 区间查询：需要维护两个树状数组。利用恒等式 ∑i=1xa[i]=∑i=1x∑j=1id[j]=(x+1)∑i=1xd[i]−∑i=1xi⋅d[i]\sum_{i=1}^{x} a[i] = \sum_{i=1}^{x} \sum_{j=1}^{i} d[j] = (x+1)\sum_{i=1}^{x} d[i] - \sum_{i=1}^{x} i \cdot d[i]∑i=1x​a[i]=∑i=1x​∑j=1i​d[j]=(x+1)∑i=1x​d[i]−∑i=1x​i⋅d[i]。


class BITRangeUpdateRangeQuery {
  private tree1: number[];
  private tree2: number[];
  private n: number;

  constructor(n: number) {
    this.n = n;
    this.tree1 = new Array(n + 2).fill(0);
    this.tree2 = new Array(n + 2).fill(0);
  }

  private lowbit(x: number): number {
    return x & -x;
  }

  private add(tree: number[], i: number, delta: number): void {
    while (i <= this.n) {
      tree[i] += delta;
      i += this.lowbit(i);
    }
  }

  private sum(tree: number[], i: number): number {
    let s = 0;
    while (i > 0) {
      s += tree[i];
      i -= this.lowbit(i);
    }
    return s;
  }

  rangeAdd(l: number, r: number, val: number): void {
    this.add(this.tree1, l, val);
    this.add(this.tree1, r + 1, -val);
    this.add(this.tree2, l, val * l);
    this.add(this.tree2, r + 1, -val * (r + 1));
  }

  prefixSum(x: number): number {
    return (x + 1) * this.sum(this.tree1, x) - this.sum(this.tree2, x);
  }

  rangeSum(l: number, r: number): number {
    return this.prefixSum(r) - this.prefixSum(l - 1);
  }
}
二维树状数组
树状数组可以自然地推广到二维，用于处理二维矩阵上的单点更新和矩形区域求和。


class BIT2D {
  private tree: number[][];
  private rows: number;
  private cols: number;

  constructor(rows: number, cols: number) {
    this.rows = rows;
    this.cols = cols;
    this.tree = Array.from({ length: rows + 1 }, () => new Array(cols + 1).fill(0));
  }

  private lowbit(x: number): number {
    return x & -x;
  }

  update(x: number, y: number, delta: number): void {
    let i = x;
    while (i <= this.rows) {
      let j = y;
      while (j <= this.cols) {
        this.tree[i][j] += delta;
        j += this.lowbit(j);
      }
      i += this.lowbit(i);
    }
  }

  prefixSum(x: number, y: number): number {
    let sum = 0;
    let i = x;
    while (i > 0) {
      let j = y;
      while (j > 0) {
        sum += this.tree[i][j];
        j -= this.lowbit(j);
      }
      i -= this.lowbit(i);
    }
    return sum;
  }

  rangeSum(x1: number, y1: number, x2: number, y2: number): number {
    return (
      this.prefixSum(x2, y2) - this.prefixSum(x1 - 1, y2) - this.prefixSum(x2, y1 - 1) + this.prefixSum(x1 - 1, y1 - 1)
    );
  }
}
矩形区域求和利用了二维容斥原理：


sum(x1,y1,x2,y2)=P(x2,y2)−P(x1−1,y2)−P(x2,y1−1)+P(x1−1,y1−1)\text{sum}(x_1, y_1, x_2, y_2) = P(x_2, y_2) - P(x_1{-}1, y_2) - P(x_2, y_1{-}1) + P(x_1{-}1, y_1{-}1)sum(x1​,y1​,x2​,y2​)=P(x2​,y2​)−P(x1​−1,y2​)−P(x2​,y1​−1)+P(x1​−1,y1​−1)
其中 P(x,y)P(x, y)P(x,y) 表示从 (1,1)(1,1)(1,1) 到 (x,y)(x, y)(x,y) 的前缀和。


二维树状数组的时间复杂度为单次更新 O(log⁡m⋅log⁡n)O(\log m \cdot \log n)O(logm⋅logn)，单次查询 O(log⁡m⋅log⁡n)O(\log m \cdot \log n)O(logm⋅logn)，空间复杂度 O(mn)O(mn)O(mn)。


小结
    

  • 树状数组通过 lowbit 运算巧妙地将数组组织成隐式树结构，支持 O(log⁡n)O(\log n)O(logn) 的前缀和查询与单点更新
    • 

  • lowbit(x) = x & (-x) 是树状数组的核心操作，决定了每个位置管理的区间长度
    • 

  • 线性建树（O(n)O(n)O(n)）优于逐个插入（O(nlog⁡n)O(n \log n)O(nlogn)），利用了父节点索引 i+lowbit(i)i + \text{lowbit}(i)i+lowbit(i) 的性质
    • 

  • 通过差分技巧，树状数组可以支持区间更新 + 单点查询，甚至区间更新 + 区间查询
    • 

  • 二维树状数组将一维思想推广到二维，配合容斥原理实现矩形区域求和
    • 

  • 相比线段树，树状数组在可适用场景下具有代码更短、常数更小的优势，是处理前缀和类问题的首选
