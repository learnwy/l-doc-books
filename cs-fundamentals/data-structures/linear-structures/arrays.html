数组与动态数组

什么是数组

数组（Array）是最基本的线性数据结构，它将相同类型的元素存储在一段连续的内存空间中。每个元素通过整数**下标（index）**进行定位，支持 O(1)O(1)O(1) 的随机访问。



数组在内存中是连续存储的，相邻元素的地址差值恰好等于单个元素的大小（如 int 类型为 4 字节）。这就是数组能实现 O(1)O(1)O(1) 随机访问的根本原因：地址 = 基地址 + 下标 × 元素大小。

静态数组
静态数组在声明时必须指定大小，之后不能增长或缩小：


const arr: number[] = new Array(5).fill(0); // 长度固定为 5
arr[0] = 10;
arr[1] = 20;
// arr 最多只能存 5 个元素
动态数组
动态数组在逻辑上与静态数组一样按下标访问，但底层会在容量不足时自动扩容（resize）：


const lst: number[] = [];
lst.push(1);
lst.push(2);
lst.push(3);
console.log(lst[0]);

为什么插入和删除是 O(n)？
在数组中间位置插入一个元素，需要将该位置及之后的所有元素向后移动一格，最坏情况下移动 nnn 个元素，因此时间复杂度为 O(n)O(n)O(n)。删除操作同理，需要将后续元素前移来填补空位。


动态数组扩容策略与均摊分析
动态数组的核心设计在于：当内部数组容量不够时，分配一块更大的新数组，将旧数据拷贝过去，再释放旧数组。


倍增策略
主流实现通常采用**倍增（doubling）**策略，即每次扩容为原来的 2 倍（或 1.5 倍）：

均摊分析（Amortized Analysis）
虽然单次扩容的拷贝代价为 O(n)O(n)O(n)，但扩容并不会每次 append 都发生。假设初始容量为 1，倍增策略下，执行 nnn 次 append 的总拷贝次数为：


1+2+4+8+⋯+n=2n−11 + 2 + 4 + 8 + \cdots + n = 2n - 11+2+4+8+⋯+n=2n−1
因此总代价为 O(n)O(n)O(n)，平均到每次操作的均摊代价为：


O(n)n=O(1)\frac{O(n)}{n} = O(1)nO(n)​=O(1)
这就是为什么我们说动态数组末尾追加的时间复杂度是均摊 O(1)O(1)O(1)。


实际语言中的动态数组
TypeScript — Array
const lst: number[] = [];
for (let i = 0; i < 20; i++) {
  lst.push(i);
  console.log(`长度: ${lst.length}, 元素: [${lst}]`);
}
TypeScript/JavaScript 的 Array 在 V8 引擎中根据元素类型和密度自动选择底层表示（SMI packed、double packed、holey 等）。扩容策略约为 2 倍增长，小数组增长更快。

使用场景与选型建议
    

  • 优先选择数组：当需要高频随机访问、数据量已知或仅在末尾增删时。
    • 

  • 避免使用数组：当需要频繁在头部或中间位置执行插入/删除操作时（此时链表更合适）。
    • 



经典应用
    

  1. 前缀和数组 —— 用 O(n)O(n)O(n) 预处理，实现 O(1)O(1)O(1) 区间求和查询。
    2. 

  2. 双指针技巧 —— 在有序数组上使用左右指针解决两数之和等问题。
    3. 

  3. 滑动窗口 —— 基于数组下标维护一个可变长度的窗口区间。
    4. 

  4. 二分查找 —— 数组有序时，利用 O(1)O(1)O(1) 随机访问实现 O(log n)O(log\,n)O(logn) 查找。
    5. 



小结
    

  • 数组是最基础的数据结构，核心优势在于连续内存布局带来的 O(1)O(1)O(1) 随机访问能力。
    • 

  • 静态数组长度固定，动态数组通过倍增扩容策略实现灵活增长，末尾追加的均摊复杂度为 O(1)O(1)O(1)。
    • 

  • 数组的劣势在于中间位置的插入和删除代价为 O(n)O(n)O(n)，因为需要移动元素来维护连续性。
    • 

  • 理解数组的内存模型与复杂度特性，是掌握更高级数据结构（如哈希表、堆、线段树等）的基础。
