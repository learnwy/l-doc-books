队列与双端队列

什么是队列

队列（Queue）是一种遵循 FIFO（First In, First Out，先进先出） 原则的线性数据结构。就像日常生活中的排队——最先到达的人最先被服务，最后到达的人最后被服务。

元素只能从**队尾（rear）进入，从队首（front）**离开，这就是 FIFO 原则的本质。

队列的实现
基于数组的简单队列
class ArrayQueue<T> {
  private data: (T | null)[];
  private front: number = 0;
  private _size: number = 0;
  private capacity: number;

  constructor(capacity: number = 10) {
    this.capacity = capacity;
    this.data = new Array<T | null>(capacity).fill(null);
  }

  enqueue(item: T): void {
    if (this._size === this.capacity) throw new Error('Queue is full');
    const rear = (this.front + this._size) % this.capacity;
    this.data[rear] = item;
    this._size++;
  }

  dequeue(): T {
    if (this.isEmpty()) throw new Error('Queue is empty');
    const item = this.data[this.front]!;
    this.data[this.front] = null;
    this.front = (this.front + 1) % this.capacity;
    this._size--;
    return item;
  }

  peek(): T {
    if (this.isEmpty()) throw new Error('Queue is empty');
    return this.data[this.front]!;
  }

  isEmpty(): boolean {
    return this._size === 0;
  }

  size(): number {
    return this._size;
  }
}


上述实现已经采用了循环数组的思想——通过取模运算 % 使索引在到达数组末尾后回绕到开头，从而避免空间浪费。




基于链表的队列
class QueueNode<T> {
  val: T;
  next: QueueNode<T> | null = null;

  constructor(val: T) {
    this.val = val;
  }
}

class LinkedQueue<T> {
  private head: QueueNode<T> | null = null;
  private tail: QueueNode<T> | null = null;
  private _size: number = 0;

  enqueue(item: T): void {
    const node = new QueueNode(item);
    if (this.tail) this.tail.next = node;
    this.tail = node;
    if (!this.head) this.head = node;
    this._size++;
  }

  dequeue(): T {
    if (this.isEmpty()) throw new Error('Queue is empty');
    const item = this.head!.val;
    this.head = this.head!.next;
    if (!this.head) this.tail = null;
    this._size--;
    return item;
  }

  peek(): T {
    if (this.isEmpty()) throw new Error('Queue is empty');
    return this.head!.val;
  }

  isEmpty(): boolean {
    return this._size === 0;
  }

  size(): number {
    return this._size;
  }
}

循环队列
循环队列（Circular Queue）是用固定大小数组实现的队列，通过将数组首尾相连形成逻辑上的"环"，解决了普通数组队列中元素出队后前端空间无法复用的问题。


核心公式：


    

  • 入队位置：rear = (front + size) % capacity
    • 

  • 出队后队首移动：front = (front + 1) % capacity
    • 

  • 判满：size == capacity
    • 

  • 判空：size == 0
    • 





💡 循环队列在操作系统的缓冲区管理中被广泛使用，例如键盘输入缓冲区、网络数据包缓冲区等。




双端队列
双端队列（Deque，Double-Ended Queue）是队列的扩展——允许在两端同时进行插入和删除操作。

双端队列是普通队列和栈的超集——如果只使用一端操作，它就是栈；如果一端入另一端出，它就是队列。


TypeScript 中的双端队列
JavaScript/TypeScript 的 Array 原生支持双端操作：


const dq: number[] = [];
dq.push(1); // 队尾入队
dq.push(2); // 队尾入队
dq.unshift(0); // 队首入队
dq.pop(); // 队尾出队
dq.shift(); // 队首出队


Array.prototype.push/pop 为 O(1)O(1)O(1)，但 unshift/shift 需要移动所有元素，为 O(n)O(n)O(n)。对于高频双端操作场景，建议使用基于链表的自定义 Deque 实现以获得两端严格 O(1)O(1)O(1) 的性能。




优先队列

优先队列最常用的实现是二叉堆（Binary Heap），在入队和出队操作上均能达到 O(log n)O(log\,n)O(logn) 的效率。详细内容请参阅 堆 章节。




以下是一个简易的优先队列示例：


const pq: [number, string][] = [];

function heapPush(heap: [number, string][], item: [number, string]): void {
  heap.push(item);
  heap.sort((a, b) => a[0] - b[0]);
}

function heapPop(heap: [number, string][]): [number, string] {
  return heap.shift()!;
}

heapPush(pq, [2, '任务B']);
heapPush(pq, [1, '任务A']);
heapPush(pq, [3, '任务C']);

console.log(heapPop(pq)); // [1, "任务A"] — 优先级最小的先出队
应用场景
广度优先搜索（BFS）
BFS 是队列最经典的应用。在遍历图或树时，队列确保按照层级顺序逐层访问节点。


function bfs(graph: Map<string, string[]>, start: string): string[] {
  const visited = new Set<string>([start]);
  const queue: string[] = [start];
  const result: string[] = [];
  while (queue.length) {
    const node = queue.shift()!;
    result.push(node);
    for (const neighbor of graph.get(node) ?? []) {
      if (!visited.has(neighbor)) {
        visited.add(neighbor);
        queue.push(neighbor);
      }
    }
  }
  return result;
}
BFS 访问顺序：1 → 2 → 3 → 4 → 5 → 6（逐层遍历）。


任务调度
操作系统的 CPU 调度、打印机任务队列等都使用队列来管理待处理任务，保证公平的先来先服务（FCFS）策略。


滑动窗口（双端队列应用）
滑动窗口最大值问题是双端队列的经典应用——维护一个单调递减的双端队列，在 O(n)O(n)O(n) 时间内求出每个窗口的最大值。


function maxSlidingWindow(nums: number[], k: number): number[] {
  const dq: number[] = [];
  const result: number[] = [];
  for (let i = 0; i < nums.length; i++) {
    while (dq.length && dq[0] < i - k + 1) {
      dq.shift();
    }
    while (dq.length && nums[dq[dq.length - 1]] < nums[i]) {
      dq.pop();
    }
    dq.push(i);
    if (i >= k - 1) {
      result.push(nums[dq[0]]);
    }
  }
  return result;
}

console.log(maxSlidingWindow([1, 3, -1, -3, 5, 3, 6, 7], 3));
// 输出: [3, 3, 5, 5, 6, 7]


双端队列中存储的是索引而非值本身，这样既能比较值的大小，又能判断元素是否已滑出窗口。

小结
    

  • 队列遵循 FIFO 原则，是 BFS、任务调度等场景的基础数据结构。
    • 

  • 循环队列通过取模运算在固定数组上实现高效的空间复用，适合缓冲区场景。
    • 

  • 双端队列支持两端操作，是队列与栈的泛化形式，滑动窗口问题中表现尤为出色。
    • 

  • 优先队列打破了 FIFO 规则，按优先级出队，底层通常由堆实现。
    • 

  • TypeScript 中可用 Array 的 push/pop/shift/unshift 模拟队列与双端队列操作，高频场景建议封装专用类以获得更清晰的语义和更稳定的性能。
