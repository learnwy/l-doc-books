链表

什么是链表

链表（Linked List）是一种线性数据结构，其中每个元素（称为节点）通过指针连接到下一个节点。与数组不同，链表中的节点在内存中不必连续存储，这使得插入和删除操作无需移动大量元素。

节点结构
链表的基本构建单元是节点（Node），每个节点至少包含两部分：


    

  • 数据域（data） —— 存储实际的数据值
    • 

  • 指针域（next / prev） —— 存储指向其他节点的引用
    • 



class ListNode<T> {
  val: T;
  next: ListNode<T> | null;

  constructor(val: T, next: ListNode<T> | null = null) {
    this.val = val;
    this.next = next;
  }
}
双向链表的节点还包含一个指向前驱节点的指针：


class DoublyListNode<T> {
  val: T;
  prev: DoublyListNode<T> | null;
  next: DoublyListNode<T> | null;

  constructor(val: T, prev: DoublyListNode<T> | null = null, next: DoublyListNode<T> | null = null) {
    this.val = val;
    this.prev = prev;
    this.next = next;
  }
}
链表的类型
单向链表（Singly Linked List）
每个节点只有一个 next 指针，指向后继节点。只能从头到尾单向遍历。


双向链表（Doubly Linked List）
每个节点同时持有 prev 和 next 两个指针，支持双向遍历。删除和在指定节点前插入时更为方便，但每个节点需要额外的指针空间。


循环链表（Circular Linked List）
尾节点的 next 指针指回头节点，形成闭环。循环链表适用于需要反复循环遍历的场景，如轮询调度、约瑟夫环问题等。




循环链表也可以是双向的——即双向循环链表，尾节点的 next 指向头节点，头节点的 prev 指向尾节点。




基本操作
插入节点
头部插入 —— 将新节点设为头节点，时间复杂度 O(1)O(1)O(1)。


function insertAtHead<T>(head: ListNode<T> | null, val: T): ListNode<T> {
  const newNode = new ListNode(val);
  newNode.next = head;
  return newNode;
}
尾部插入 —— 遍历到尾节点后追加，时间复杂度 O(n)O(n)O(n)。


function insertAtTail<T>(head: ListNode<T> | null, val: T): ListNode<T> {
  const newNode = new ListNode(val);
  if (!head) return newNode;
  let curr = head;
  while (curr.next) {
    curr = curr.next;
  }
  curr.next = newNode;
  return head;
}
指定位置插入 —— 遍历到目标位置的前驱节点，修改指针完成插入。


function insertAtIndex<T>(head: ListNode<T> | null, index: number, val: T): ListNode<T> | null {
  if (index === 0) return insertAtHead(head, val);
  let curr = head;
  for (let i = 0; i < index - 1; i++) {
    if (!curr) return head;
    curr = curr.next;
  }
  if (!curr) return head;
  const newNode = new ListNode(val, curr.next);
  curr.next = newNode;
  return head;
}
删除节点
删除头节点 —— 直接将头指针移到下一节点，时间复杂度 O(1)O(1)O(1)。


function deleteHead<T>(head: ListNode<T> | null): ListNode<T> | null {
  if (!head) return null;
  return head.next;
}
删除指定值的节点 —— 找到目标节点的前驱，修改指针跳过目标节点。


function deleteByValue<T>(head: ListNode<T> | null, val: T): ListNode<T> | null {
  const dummy = new ListNode<T>(val, head);
  let prev: ListNode<T> = dummy;
  let curr = head;
  while (curr) {
    if (curr.val === val) {
      prev.next = curr.next;
      break;
    }
    prev = curr;
    curr = curr.next;
  }
  return dummy.next;
}
搜索节点
从头节点开始逐一比较，时间复杂度 O(n)O(n)O(n)。


function search<T>(head: ListNode<T> | null, target: T): number {
  let curr = head;
  let index = 0;
  while (curr) {
    if (curr.val === target) return index;
    curr = curr.next;
    index++;
  }
  return -1;
}
反转链表
反转链表是最经典的链表操作之一，使用三指针法原地反转。


function reverse<T>(head: ListNode<T> | null): ListNode<T> | null {
  let prev: ListNode<T> | null = null;
  let curr = head;
  while (curr) {
    const nxt = curr.next;
    curr.next = prev;
    prev = curr;
    curr = nxt;
  }
  return prev;
}

常见应用场景
    

  • LRU 缓存 —— 双向链表 + 哈希表，实现 O(1)O(1)O(1) 的访问和淘汰
    • 

  • 操作系统任务调度 —— 循环链表实现轮询调度（Round-Robin）
    • 

  • 多项式运算 —— 链表存储非零项，方便合并和计算
    • 

  • 浏览器历史记录 —— 双向链表支持前进/后退导航
    • 

  • 内存管理 —— 空闲内存块通过链表管理
    • 



小结
    

  • 链表是最基础的动态数据结构，理解指针操作是掌握链表的关键。
    • 

  • 单向链表结构简单但只能单向遍历；双向链表以空间换灵活性；循环链表适合周期性场景。
    • 

  • 链表在插入和删除上优于数组，但在随机访问和缓存友好性上不如数组。
    • 

  • 实际工程中，链表常与哈希表等结构组合使用，取长补短。
    • 

  • 面试中链表题目（反转、合并、环检测、快慢指针等）是高频考点，务必熟练掌握。
