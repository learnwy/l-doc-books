栈

什么是栈

栈（Stack）是一种遵循后进先出（Last In, First Out, LIFO）原则的线性数据结构。可以将栈类比为一叠盘子：最后放上去的盘子，最先被取走。栈只允许在一端（称为栈顶）进行插入和删除操作。

核心操作

实现方式
基于数组的实现
使用动态数组作为底层存储，栈顶对应数组末尾。这是最常用的实现方式。


class ArrayStack<T> {
  private data: T[] = [];

  push(val: T): void {
    this.data.push(val);
  }

  pop(): T {
    if (this.isEmpty()) throw new Error('pop from empty stack');
    return this.data.pop()!;
  }

  peek(): T {
    if (this.isEmpty()) throw new Error('peek from empty stack');
    return this.data[this.data.length - 1];
  }

  isEmpty(): boolean {
    return this.data.length === 0;
  }

  size(): number {
    return this.data.length;
  }
}
特点：


    

  • 利用数组末尾追加/删除的 O(1)O(1)O(1) 均摊复杂度
    • 

  • 缓存友好，内存连续分布
    • 

  • 动态数组扩容时可能产生 O(n)O(n)O(n) 的单次开销，但均摊仍为 O(1)O(1)O(1)
    • 



基于链表的实现
使用单链表作为底层存储，栈顶对应链表头节点。每次 push/pop 操作都在链表头部进行。


class StackNode<T> {
  val: T;
  next: StackNode<T> | null;

  constructor(val: T, next: StackNode<T> | null = null) {
    this.val = val;
    this.next = next;
  }
}

class LinkedStack<T> {
  private head: StackNode<T> | null = null;
  private _size: number = 0;

  push(val: T): void {
    this.head = new StackNode(val, this.head);
    this._size++;
  }

  pop(): T {
    if (this.isEmpty()) throw new Error('pop from empty stack');
    const val = this.head!.val;
    this.head = this.head!.next;
    this._size--;
    return val;
  }

  peek(): T {
    if (this.isEmpty()) throw new Error('peek from empty stack');
    return this.head!.val;
  }

  isEmpty(): boolean {
    return this.head === null;
  }

  size(): number {
    return this._size;
  }
}
特点：


    

  • 每次操作严格 O(1)O(1)O(1)，无扩容开销
    • 

  • 每个节点需要额外的指针空间
    • 

  • 内存非连续分配，缓存不友好
    •

应用场景
1. 函数调用栈
程序执行函数调用时，系统使用调用栈来管理函数的上下文信息（局部变量、返回地址等）。每调用一个函数，就将其栈帧压入调用栈；函数返回时，弹出栈帧。


递归本质上就是利用调用栈来保存每一层的状态：


function factorial(n: number): number {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}
2. 括号匹配
验证一个字符串中的括号是否合法配对，是栈的经典应用。


function isValid(s: string): boolean {
  const stack: string[] = [];
  const mapping: Record<string, string> = { ')': '(', ']': '[', '}': '{' };
  for (const ch of s) {
    if (ch in mapping) {
      if (!stack.length || stack[stack.length - 1] !== mapping[ch]) return false;
      stack.pop();
    } else {
      stack.push(ch);
    }
  }
  return stack.length === 0;
}
3. 表达式求值
利用栈可以实现中缀表达式转后缀表达式（逆波兰表达式），以及后缀表达式的计算。


后缀表达式求值：遇到数字入栈，遇到运算符则弹出两个操作数进行运算并将结果入栈。


function evalRPN(tokens: string[]): number {
  const stack: number[] = [];
  const ops: Record<string, (a: number, b: number) => number> = {
    '+': (a, b) => a + b,
    '-': (a, b) => a - b,
    '*': (a, b) => a * b,
    '/': (a, b) => Math.trunc(a / b),
  };
  for (const token of tokens) {
    if (token in ops) {
      const b = stack.pop()!;
      const a = stack.pop()!;
      stack.push(ops[token](a, b));
    } else {
      stack.push(parseInt(token, 10));
    }
  }
  return stack[0];
}


示例：后缀表达式 ["3", "4", "+", "2", "*"] 对应中缀 (3 + 4) * 2 = 14。




4. 单调栈
单调栈是一种栈内元素保持单调递增或单调递减的特殊栈结构，常用于解决下一个更大/更小元素等问题。


经典问题：下一个更大元素


给定数组，对每个元素找到右侧第一个比它大的元素。


function nextGreaterElement(nums: number[]): number[] {
  const n = nums.length;
  const result = new Array<number>(n).fill(-1);
  const stack: number[] = [];
  for (let i = 0; i < n; i++) {
    while (stack.length && nums[i] > nums[stack[stack.length - 1]]) {
      const idx = stack.pop()!;
      result[idx] = nums[i];
    }
    stack.push(i);
  }
  return result;
}


输出：[4, 2, 4, -1, -1]




单调栈的时间复杂度为 O(n)O(n)O(n)，因为每个元素最多入栈和出栈各一次。

小结
    

  • 栈是遵循 LIFO 原则的线性结构，只在栈顶进行操作，所有核心操作均为 O(1)O(1)O(1)。
    • 

  • 数组实现更常用，缓存性能好；链表实现无扩容开销，每次操作严格常数时间。
    • 

  • 栈的应用极为广泛：函数调用栈是程序运行的基础，括号匹配和表达式求值是经典面试题，单调栈则是解决区间最值类问题的利器。
    • 

  • TypeScript 中可直接使用 Array 作为栈（push / pop），也可封装专用的 Stack 类以获得更清晰的语义和类型安全。
