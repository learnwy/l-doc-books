堆与优先队列

什么是堆

堆（Heap）是一种基于完全二叉树的数据结构，它满足堆性质（Heap Property）：

  • 最大堆（Max-Heap）：每个节点的值 ≥ 其所有子节点的值，根节点是全局最大值
  • 最小堆（Min-Heap）：每个节点的值 ≤ 其所有子节点的值，根节点是全局最小值


堆不要求左右子节点之间有大小关系，只要求父子之间满足堆性质。因此堆不是二叉搜索树。

由于堆是完全二叉树，可以用数组紧凑存储，无需指针。对于下标从 0 开始的数组：

核心操作
以最小堆为例说明所有操作。


插入与上浮（Insert / Sift-Up）
将新元素追加到数组末尾，然后不断与父节点比较，若比父节点小则交换，直到满足堆性质。


function siftUp(heap: number[], i: number): void {
  while (i > 0) {
    const parent = Math.floor((i - 1) / 2);
    if (heap[i] < heap[parent]) {
      [heap[i], heap[parent]] = [heap[parent], heap[i]];
      i = parent;
    } else {
      break;
    }
  }
}

function heapInsert(heap: number[], val: number): void {
  heap.push(val);
  siftUp(heap, heap.length - 1);
}
时间复杂度：O(log⁡n)O(\log n)O(logn)（最多沿着树高交换）


提取最小值与下沉（Extract-Min / Sift-Down）
取出根节点（最小值），将数组最后一个元素移到根位置，然后不断与较小的子节点比较并交换，直到满足堆性质。


function siftDown(heap: number[], i: number, size: number): void {
  while (true) {
    const left = 2 * i + 1;
    const right = 2 * i + 2;
    let smallest = i;

    if (left < size && heap[left] < heap[smallest]) smallest = left;
    if (right < size && heap[right] < heap[smallest]) smallest = right;

    if (smallest !== i) {
      [heap[i], heap[smallest]] = [heap[smallest], heap[i]];
      i = smallest;
    } else {
      break;
    }
  }
}

function heapExtractMin(heap: number[]): number {
  if (heap.length === 0) throw new Error('heap is empty');
  const minVal = heap[0];
  heap[0] = heap[heap.length - 1];
  heap.pop();
  if (heap.length > 0) siftDown(heap, 0, heap.length);
  return minVal;
}
时间复杂度：O(log⁡n)O(\log n)O(logn)

建堆（Build Heap）
自底向上建堆 — O(n)
给定一个无序数组，可以通过从最后一个非叶节点开始，对每个节点执行 sift_down 来建堆：


function buildHeap(arr: number[]): void {
  const n = arr.length;
  for (let i = Math.floor(n / 2) - 1; i >= 0; i--) {
    siftDown(arr, i, n);
  }
}
为什么是 O(n) 而不是 O(n log n)？
直觉上似乎每个节点都做了 O(log⁡n)O(\log n)O(logn) 的 sift_down，总复杂度应为 O(nlog⁡n)O(n \log n)O(nlogn)。但实际分析表明：


    

  • 高度为 hhh 的层最多有 ⌈n/2h+1⌉\lceil n / 2^{h+1} \rceil⌈n/2h+1⌉ 个节点
    • 

  • 每个节点的 sift_down 成本为 O(h)O(h)O(h)
    • 

  • 总成本为 ∑h=0⌊log⁡n⌋n2h+1⋅O(h)=O(n)∑h=0∞h2h+1=O(n)\sum_{h=0}^{\lfloor \log n \rfloor} \frac{n}{2^{h+1}} \cdot O(h) = O(n) \sum_{h=0}^{\infty} \frac{h}{2^{h+1}} = O(n)∑h=0⌊logn⌋​2h+1n​⋅O(h)=O(n)∑h=0∞​2h+1h​=O(n)
    • 





关键原因：大多数节点在底层，它们的下沉距离很短；只有少数顶部节点需要长距离下沉。




堆排序（Heap Sort）
堆排序利用堆的性质实现 O(nlog⁡n)O(n \log n)O(nlogn) 的原地排序：


    

  1. 建堆：将数组建成最大堆 — O(n)O(n)O(n)
    2. 

  2. 排序：反复将堆顶（最大值）与末尾元素交换，缩小堆的范围并执行 sift_down — O(nlog⁡n)O(n \log n)O(nlogn)
    3. 



function siftDownMax(arr: number[], i: number, size: number): void {
  while (true) {
    const left = 2 * i + 1;
    const right = 2 * i + 2;
    let largest = i;

    if (left < size && arr[left] > arr[largest]) largest = left;
    if (right < size && arr[right] > arr[largest]) largest = right;

    if (largest !== i) {
      [arr[i], arr[largest]] = [arr[largest], arr[i]];
      i = largest;
    } else {
      break;
    }
  }
}

function heapSort(arr: number[]): void {
  const n = arr.length;
  for (let i = Math.floor(n / 2) - 1; i >= 0; i--) {
    siftDownMax(arr, i, n);
  }
  for (let i = n - 1; i > 0; i--) {
    [arr[0], arr[i]] = [arr[i], arr[0]];
    siftDownMax(arr, 0, i);
  }
}

优先队列（Priority Queue）
优先队列是一种抽象数据类型，支持按优先级而非插入顺序取出元素。堆是实现优先队列最常用的底层数据结构。

典型应用
    

  • 任务调度 —— 操作系统按优先级调度进程
    • 

  • Dijkstra 最短路径算法 —— 每次取出距离最小的节点
    • 

  • Huffman 编码 —— 每次合并频率最低的两个节点
    • 

  • 合并 K 个有序链表 —— 维护大小为 K 的最小堆
    • 

  • Top-K 问题 —— 维护大小为 K 的最小堆或最大堆

实现最大堆
可以通过自定义比较函数或包装数值取反来模拟最大堆：


class MaxHeap {
  private heap = new MinHeap((a, b) => b - a);

  push(val: number): void {
    this.heap.push(val);
  }
  pop(): number {
    return this.heap.pop();
  }
  peek(): number {
    return this.heap.peek();
  }
}

const maxHeap = new MaxHeap();
for (const val of [30, 10, 20, 5]) {
  maxHeap.push(val);
}

console.log(maxHeap.pop()); // 30（最大值）
console.log(maxHeap.pop()); // 20
带优先级的任务队列
interface Task {
  priority: number;
  name: string;
}

const taskQueue = new MinHeap((a: Task, b: Task) => a.priority - b.priority);
taskQueue.push({ priority: 2, name: '写代码' });
taskQueue.push({ priority: 1, name: '修复 Bug' });
taskQueue.push({ priority: 3, name: '写文档' });

while (taskQueue.size > 0) {
  const task = taskQueue.pop();
  console.log(`优先级 ${task.priority}: ${task.name}`);
}

完整最小堆实现
class MinHeap<T = number> {
  private data: T[] = [];
  private compare: (a: T, b: T) => number;

  constructor(compare?: (a: T, b: T) => number) {
    this.compare = compare ?? ((a, b) => (a as number) - (b as number));
  }

  get size(): number {
    return this.data.length;
  }

  peek(): T {
    if (this.data.length === 0) throw new Error('heap is empty');
    return this.data[0];
  }

  push(val: T): void {
    this.data.push(val);
    this._siftUp(this.data.length - 1);
  }

  pop(): T {
    if (this.data.length === 0) throw new Error('heap is empty');
    const minVal = this.data[0];
    this.data[0] = this.data[this.data.length - 1];
    this.data.pop();
    if (this.data.length > 0) this._siftDown(0);
    return minVal;
  }

  static from(arr: number[]): MinHeap<number> {
    const heap = new MinHeap<number>();
    heap.data = [...arr];
    for (let i = Math.floor(heap.data.length / 2) - 1; i >= 0; i--) {
      heap._siftDown(i);
    }
    return heap;
  }

  private _siftUp(i: number): void {
    while (i > 0) {
      const parent = Math.floor((i - 1) / 2);
      if (this.compare(this.data[i], this.data[parent]) < 0) {
        [this.data[i], this.data[parent]] = [this.data[parent], this.data[i]];
        i = parent;
      } else {
        break;
      }
    }
  }

  private _siftDown(i: number): void {
    const size = this.data.length;
    while (true) {
      const left = 2 * i + 1;
      const right = 2 * i + 2;
      let smallest = i;

      if (left < size && this.compare(this.data[left], this.data[smallest]) < 0) smallest = left;
      if (right < size && this.compare(this.data[right], this.data[smallest]) < 0) smallest = right;

      if (smallest !== i) {
        [this.data[i], this.data[smallest]] = [this.data[smallest], this.data[i]];
        i = smallest;
      } else {
        break;
      }
    }
  }
}

const h = new MinHeap<number>();
for (const v of [30, 10, 20, 5, 15]) {
  h.push(v);
}

console.log(h.peek()); // 5
console.log(h.pop()); // 5
console.log(h.pop()); // 10
console.log(h.pop()); // 15
console.log(h.size); // 2

小结
    

  • 堆是基于完全二叉树的数据结构，分为最大堆和最小堆，核心性质是父节点始终优于子节点。
    • 

  • 堆使用数组存储，通过 parent(i) = (i-1)//2、left(i) = 2i+1、right(i) = 2i+2 三个公式定位父子关系。
    • 

  • 两个核心操作：上浮（sift-up） 用于插入，下沉（sift-down） 用于提取极值，时间复杂度均为 O(log⁡n)O(\log n)O(logn)。
    • 

  • 建堆通过自底向上的 sift_down 实现，时间复杂度为 O(n)O(n)O(n)，是堆排序和批量构建优先队列的基础。
    • 

  • 堆排序是原地排序算法，时间复杂度 O(nlog⁡n)O(n \log n)O(nlogn)，空间复杂度 O(1)O(1)O(1)，但不稳定。
    • 

  • 优先队列是堆最重要的应用场景，在操作系统调度、图算法（Dijkstra）、贪心算法等领域广泛使用。
    • 

  • TypeScript 中没有内置堆模块，可以使用自定义泛型 MinHeap<T> 类实现，通过自定义比较函数可以模拟最大堆。
    •
