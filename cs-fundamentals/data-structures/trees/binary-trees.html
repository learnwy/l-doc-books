二叉树基础

什么是树

树（Tree）是一种非线性数据结构，由节点通过边连接而成，具有层次关系。树中没有环路，任意两个节点之间有且仅有一条路径。

什么是二叉树
二叉树（Binary Tree）是一种特殊的树，每个节点最多有两个子节点，分别称为左子节点和右子节点。


class TreeNode<T> {
  value: T;
  left: TreeNode<T> | null;
  right: TreeNode<T> | null;

  constructor(value: T, left: TreeNode<T> | null = null, right: TreeNode<T> | null = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}

二叉树的类型
满二叉树（Full Binary Tree）
每个节点要么是叶节点，要么恰好有两个子节点。不存在只有一个子节点的节点。


完全二叉树（Complete Binary Tree）
除最后一层外，每一层都被完全填满，且最后一层的节点从左到右连续排列。堆（Heap）就是基于完全二叉树实现的。




完全二叉树可以用数组高效存储：对于下标 iii 的节点，左子节点下标为 2i+12i+12i+1，右子节点为 2i+22i+22i+2，父节点为 ⌊(i−1)/2⌋\lfloor(i-1)/2\rfloor⌊(i−1)/2⌋。




完美二叉树（Perfect Binary Tree）
每一层都被完全填满的二叉树。它同时是满二叉树和完全二叉树。具有 kkk 层的完美二叉树恰好有 2k−12^k - 12k−1 个节点。


退化二叉树（Degenerate / Pathological Tree）
每个节点只有一个子节点，退化为链表形态。此时树的高度等于节点数，操作复杂度退化为 O(n)O(n)O(n)。

二叉树的遍历
遍历是访问树中所有节点的系统方法。二叉树有四种经典遍历方式。


以下面这棵树为例：


前序遍历（Preorder）
访问顺序：根 → 左子树 → 右子树


上例结果：1 → 2 → 4 → 5 → 3 → 6 → 7


function preorder<T>(root: TreeNode<T> | null): T[] {
  if (!root) return [];
  return [root.value, ...preorder(root.left), ...preorder(root.right)];
}
迭代写法：


function preorderIterative<T>(root: TreeNode<T> | null): T[] {
  if (!root) return [];
  const result: T[] = [];
  const stack: TreeNode<T>[] = [root];
  while (stack.length > 0) {
    const node = stack.pop()!;
    result.push(node.value);
    if (node.right) stack.push(node.right);
    if (node.left) stack.push(node.left);
  }
  return result;
}
中序遍历（Inorder）
访问顺序：左子树 → 根 → 右子树


上例结果：4 → 2 → 5 → 1 → 6 → 3 → 7


function inorder<T>(root: TreeNode<T> | null): T[] {
  if (!root) return [];
  return [...inorder(root.left), root.value, ...inorder(root.right)];
}
迭代写法：


function inorderIterative<T>(root: TreeNode<T> | null): T[] {
  const result: T[] = [];
  const stack: TreeNode<T>[] = [];
  let curr = root;
  while (curr || stack.length > 0) {
    while (curr) {
      stack.push(curr);
      curr = curr.left;
    }
    curr = stack.pop()!;
    result.push(curr.value);
    curr = curr.right;
  }
  return result;
}


对于二叉搜索树（BST），中序遍历的结果恰好是有序序列，这一性质非常重要。




后序遍历（Postorder）
访问顺序：左子树 → 右子树 → 根


上例结果：4 → 5 → 2 → 6 → 7 → 3 → 1


function postorder<T>(root: TreeNode<T> | null): T[] {
  if (!root) return [];
  return [...postorder(root.left), ...postorder(root.right), root.value];
}
迭代写法：


function postorderIterative<T>(root: TreeNode<T> | null): T[] {
  if (!root) return [];
  const result: T[] = [];
  const stack: TreeNode<T>[] = [root];
  while (stack.length > 0) {
    const node = stack.pop()!;
    result.push(node.value);
    if (node.left) stack.push(node.left);
    if (node.right) stack.push(node.right);
  }
  return result.reverse();
}
层序遍历（Level-order）
按层从上到下、从左到右依次访问，使用队列实现。


上例结果：1 → 2 → 3 → 4 → 5 → 6 → 7


function levelOrder<T>(root: TreeNode<T> | null): T[][] {
  if (!root) return [];
  const result: T[][] = [];
  const queue: TreeNode<T>[] = [root];
  while (queue.length > 0) {
    const levelSize = queue.length;
    const level: T[] = [];
    for (let i = 0; i < levelSize; i++) {
      const node = queue.shift()!;
      level.push(node.value);
      if (node.left) queue.push(node.left);
      if (node.right) queue.push(node.right);
    }
    result.push(level);
  }
  return result;
}

构建二叉树
通过前序 + 中序，或后序 + 中序，可以唯一确定一棵二叉树。


function buildTree<T>(preorder: T[], inorder: T[]): TreeNode<T> | null {
  if (preorder.length === 0 || inorder.length === 0) return null;
  const rootVal = preorder[0];
  const root = new TreeNode(rootVal);
  const mid = inorder.indexOf(rootVal);
  root.left = buildTree(preorder.slice(1, mid + 1), inorder.slice(0, mid));
  root.right = buildTree(preorder.slice(mid + 1), inorder.slice(mid + 1));
  return root;
}
二叉树常用操作
求树的高度
function height<T>(root: TreeNode<T> | null): number {
  if (!root) return 0;
  return 1 + Math.max(height(root.left), height(root.right));
}
求节点总数
function countNodes<T>(root: TreeNode<T> | null): number {
  if (!root) return 0;
  return 1 + countNodes(root.left) + countNodes(root.right);
}
判断是否对称
function isSymmetric<T>(root: TreeNode<T> | null): boolean {
  function check(left: TreeNode<T> | null, right: TreeNode<T> | null): boolean {
    if (!left && !right) return true;
    if (!left || !right) return false;
    return left.value === right.value && check(left.left, right.right) && check(left.right, right.left);
  }
  return root ? check(root, root) : true;
}
常见应用场景
    

  • 表达式树 —— 编译器用二叉树表示算术表达式，叶节点为操作数，内部节点为运算符
    • 

  • 哈夫曼编码 —— 基于二叉树实现最优前缀编码，用于数据压缩
    • 

  • 二叉搜索树（BST） —— 支持高效查找、插入和删除
    • 

  • 堆（Heap） —— 完全二叉树实现优先队列
    • 

  • DOM 树 / 文件系统 —— 树形结构天然适合表示层次化数据
    • 



小结
    

  • 二叉树是最重要的非线性数据结构之一，是学习 BST、AVL 树、红黑树、堆等高级结构的基础。
    • 

  • 掌握树的基本术语（根、叶、深度、高度、子树等）是理解树形结构的前提。
    • 

  • 满、完全、完美、退化四种二叉树类型各有特点，直接影响操作复杂度。
    • 

  • 四种遍历方式（前序、中序、后序、层序）是树类算法题的核心工具，务必同时掌握递归和迭代写法。
    • 

  • 二叉树问题的解题思路通常可以归结为递归分解——将问题拆分为左子树和右子树的子问题分别求解。
