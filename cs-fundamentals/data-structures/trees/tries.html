字典树 Trie

什么是 Trie

Trie（发音同 "try"），又称前缀树（Prefix Tree），是一种专门用于高效存储和检索字符串的树形数据结构。与二叉搜索树不同，Trie 的每条边代表一个字符，从根节点到某个标记节点的路径拼接起来就构成一个完整的单词。

Trie 的核心思想：利用字符串之间的公共前缀来减少存储空间和查询时间。



上图展示了存储单词 apple、ape、to、ton、tone、top 的 Trie。绿色节点（✓）表示该路径构成一个完整单词。

核心操作
插入（Insert）
从根节点出发，逐字符沿着对应的边向下走。如果当前字符对应的子节点不存在，就创建一个新节点。遍历完所有字符后，将最后一个节点标记为 is_end = True。


insert(word: string): void {
  let node = this.root;
  for (const char of word) {
    if (!node.children.has(char)) {
      node.children.set(char, new TrieNode());
    }
    node = node.children.get(char)!;
  }
  node.isEnd = true;
}
查找（Search）
从根节点出发，逐字符沿着对应的边向下走。如果某个字符对应的子节点不存在，返回 False。遍历完所有字符后，检查最后一个节点的 is_end 是否为 True。


search(word: string): boolean {
  let node = this.root;
  for (const char of word) {
    if (!node.children.has(char)) return false;
    node = node.children.get(char)!;
  }
  return node.isEnd;
}
前缀查询（StartsWith）
与查找几乎相同，唯一的区别是：遍历完所有字符后不需要检查 is_end，只要路径存在即可。


startsWith(prefix: string): boolean {
  let node = this.root;
  for (const char of prefix) {
    if (!node.children.has(char)) return false;
    node = node.children.get(char)!;
  }
  return true;
}
完整实现
class TrieNode {
  children: Map<string, TrieNode> = new Map();
  isEnd: boolean = false;
}

class Trie {
  root: TrieNode = new TrieNode();

  insert(word: string): void {
    let node = this.root;
    for (const char of word) {
      if (!node.children.has(char)) {
        node.children.set(char, new TrieNode());
      }
      node = node.children.get(char)!;
    }
    node.isEnd = true;
  }

  search(word: string): boolean {
    const node = this._findNode(word);
    return node !== null && node.isEnd;
  }

  startsWith(prefix: string): boolean {
    return this._findNode(prefix) !== null;
  }

  private _findNode(prefix: string): TrieNode | null {
    let node = this.root;
    for (const char of prefix) {
      if (!node.children.has(char)) return null;
      node = node.children.get(char)!;
    }
    return node;
  }

  delete(word: string): boolean {
    const _delete = (node: TrieNode, word: string, depth: number): boolean => {
      if (depth === word.length) {
        if (!node.isEnd) return false;
        node.isEnd = false;
        return node.children.size === 0;
      }
      const char = word[depth];
      if (!node.children.has(char)) return false;
      const shouldDelete = _delete(node.children.get(char)!, word, depth + 1);
      if (shouldDelete) {
        node.children.delete(char);
        return !node.isEnd && node.children.size === 0;
      }
      return false;
    };
    _delete(this.root, word, 0);
    return true;
  }

  getAllWords(): string[] {
    const words: string[] = [];
    const dfs = (node: TrieNode, path: string[]): void => {
      if (node.isEnd) words.push(path.join(''));
      for (const [char, child] of node.children) {
        path.push(char);
        dfs(child, path);
        path.pop();
      }
    };
    dfs(this.root, []);
    return words;
  }

  autocomplete(prefix: string): string[] {
    const node = this._findNode(prefix);
    if (node === null) return [];
    const results: string[] = [];
    const dfs = (node: TrieNode, path: string[]): void => {
      if (node.isEnd) results.push(prefix + path.join(''));
      for (const [char, child] of node.children) {
        path.push(char);
        dfs(child, path);
        path.pop();
      }
    };
    dfs(node, []);
    return results;
  }
}
使用示例：


const trie = new Trie();
for (const word of ['apple', 'ape', 'to', 'ton', 'tone', 'top']) {
  trie.insert(word);
}

console.log(trie.search('apple')); // true
console.log(trie.search('app')); // false
console.log(trie.startsWith('app')); // true
console.log(trie.autocomplete('to')); // ['to', 'ton', 'tone', 'top']
console.log(trie.autocomplete('ap')); // ['ape', 'apple']

trie.delete('apple');
console.log(trie.search('apple')); // false
console.log(trie.search('ape')); // true

Trie 的最大优势在于前缀操作。当你需要频繁进行前缀匹配或自动补全时，Trie 是最佳选择。

应用场景
1. 自动补全（Autocomplete）
搜索引擎、IDE、手机输入法中的自动补全功能正是 Trie 的经典应用。用户每输入一个字符，系统在 Trie 中定位到对应的前缀节点，然后遍历其所有子树找到所有候选词。


2. 拼写检查（Spell Check）
将词典中的所有单词存入 Trie。检查用户输入的单词是否存在，若不存在则可以基于编辑距离在 Trie 中搜索近似单词作为修正建议。


3. IP 路由（最长前缀匹配）
网络路由器使用 Trie（通常是二进制 Trie）来进行最长前缀匹配（Longest Prefix Match）。路由表中的每条规则对应 Trie 中的一条路径，数据包的目标 IP 地址沿 Trie 查找最长匹配前缀来决定转发端口。


4. 词频统计与排序
在 is_end 节点上附加计数器，即可实现词频统计。利用 Trie 的有序性质（DFS 遍历自然按字典序），可以对大量字符串进行高效排序。


5. 敏感词过滤
将所有敏感词构建为 Trie，扫描用户输入文本时逐字符在 Trie 中匹配，即可实现高效的多模式字符串匹配。结合 AC 自动机（Aho-Corasick）可以进一步提升效率。


空间优化：压缩 Trie（Radix Tree）
标准 Trie 的一个问题是：当路径上存在大量只有单个子节点的节点时，会浪费空间。压缩 Trie（又称 Radix Tree 或 Patricia Trie）通过将这些单链路径合并为一条边来优化空间。


压缩 Trie 的核心规则：如果一个非根节点只有一个子节点且自身不是终止节点，就将它与子节点合并。

小结
    

  • Trie 是专为字符串设计的树形结构，利用公共前缀实现高效的插入、查找和前缀操作，时间复杂度均为 O(m)O(m)O(m)，与已存储的字符串总数无关。
    • 

  • 每个节点包含 children 映射和 is_end 标记，结构简单直观。
    • 

  • 前缀查询是 Trie 相比哈希表的核心优势，使其成为自动补全、拼写检查等场景的首选数据结构。
    • 

  • Trie 的主要缺点是空间开销大（每个节点需要维护子节点指针），可以通过压缩 Trie（Radix Tree）进行优化。
    • 

  • 在实际工程中，Trie 广泛应用于搜索引擎、网络路由、文本处理和数据库索引等领域。
    •
