树 简介

树是一种层次型的非线性数据结构，由节点和边组成，其中每个节点最多有一个父节点，但可以有多个子节点。这种自顶向下的层级关系使得树特别适合表达具有分层或递归特性的数据，例如文件系统、组织架构和语法分析。

本章涵盖五种重要的树形数据结构，从最基础的二叉树到更为专用的字典树，由浅入深地展开。

二叉树是树的最简单形态，每个节点至多拥有两个子节点。它是理解所有树形结构的出发点。二叉树的前序、中序和后序遍历是算法面试中的高频考点，也是解决许多树相关问题的基础技巧。

二叉搜索树在二叉树的基础上增加了有序性约束：左子树所有节点的值小于根节点，右子树所有节点的值大于根节点。这一性质使得查找、插入和删除操作都能在对数时间内完成。然而，当数据有序插入时，二叉搜索树可能退化为链表，性能大幅下降。

平衡树正是为了解决这一退化问题而诞生的。AVL 树和红黑树等自平衡结构通过旋转操作维持树的高度平衡，确保各项操作始终保持对数级别的时间复杂度。平衡树广泛应用于数据库索引和编程语言的标准库中。

堆是一种满足堆序性质的完全二叉树，常用于实现优先队列。最大堆保证根节点是最大值，最小堆保证根节点是最小值。堆排序和 Top-K 问题都是堆的典型应用场景。

字典树又称前缀树，是一种专门用于字符串检索的树形结构。它将字符串的公共前缀进行共享存储，在自动补全、拼写检查和 IP 路由等场景中表现出色。

本章内容较为丰富，建议你按照文档顺序逐步学习。每掌握一种树形结构，都会为理解下一种结构提供必要的铺垫。完成本章后，你将具备应对绝大多数树相关问题的能力。
