二叉搜索树

什么是二叉搜索树

二叉搜索树（Binary Search Tree，简称 BST）是一种特殊的二叉树，它对每个节点都满足以下BST 性质：

  • 左子树中所有节点的值 < 当前节点的值
  • 右子树中所有节点的值 > 当前节点的值
  • 左右子树本身也分别是二叉搜索树


上图中，根节点 8 的左子树所有值 {1, 3, 4, 6, 7} 均小于 8，右子树所有值 {10, 13, 14} 均大于 8。对任意子树递归验证，均满足 BST 性质。

最坏情况发生在树退化为链表（例如按升序依次插入 1, 2, 3, 4, 5），此时树的高度为 nnn，所有操作退化为 O(n)O(n)O(n)。这也是引入 AVL 树、红黑树等平衡 BST 的根本原因。




节点定义
class TreeNode<T> {
  value: T;
  left: TreeNode<T> | null;
  right: TreeNode<T> | null;

  constructor(value: T) {
    this.value = value;
    this.left = null;
    this.right = null;
  }
}
查找操作
从根节点开始，将目标值与当前节点比较：


    

  1. 等于当前节点 → 找到，返回
    2. 

  2. 小于当前节点 → 递归查找左子树
    3. 

  3. 大于当前节点 → 递归查找右子树
    4. 

  4. 遇到空节点 → 不存在，返回 None
    5. 



function search<T>(root: TreeNode<T> | null, target: T): TreeNode<T> | null {
  if (root === null) return null;
  if (target === root.value) return root;
  if (target < root.value) return search(root.left, target);
  return search(root.right, target);
}
迭代写法可以避免递归栈开销，在工程中更常用：


function searchIterative<T>(root: TreeNode<T> | null, target: T): TreeNode<T> | null {
  let node = root;
  while (node) {
    if (target === node.value) return node;
    if (target < node.value) node = node.left;
    else node = node.right;
  }
  return null;
}
插入操作
插入新值时，沿着查找路径走到空位置，将新节点放在该位置即可。BST 的插入始终发生在叶子节点。


function insert<T>(root: TreeNode<T> | null, val: T): TreeNode<T> {
  if (root === null) return new TreeNode(val);
  if (val < root.value) root.left = insert(root.left, val);
  else if (val > root.value) root.right = insert(root.right, val);
  return root;
}
删除操作
删除是 BST 中最复杂的操作，需要分三种情况处理：


情况一：删除叶子节点
目标节点没有子节点，直接移除即可。


情况二：删除只有一个子节点的节点
用其唯一的子节点替代被删除节点的位置。


情况三：删除有两个子节点的节点
找到其中序后继（右子树中最小的节点），用后继的值替换被删节点的值，然后递归删除后继节点。




也可以使用中序前驱（左子树中最大的节点）来替代，效果等价。




完整删除代码
function findMin<T>(node: TreeNode<T>): TreeNode<T> {
  while (node.left) node = node.left;
  return node;
}

function deleteNode<T>(root: TreeNode<T> | null, val: T): TreeNode<T> | null {
  if (root === null) return null;

  if (val < root.value) {
    root.left = deleteNode(root.left, val);
  } else if (val > root.value) {
    root.right = deleteNode(root.right, val);
  } else {
    if (root.left === null && root.right === null) return null;
    if (root.left === null) return root.right;
    if (root.right === null) return root.left;

    const successor = findMin(root.right);
    root.value = successor.value;
    root.right = deleteNode(root.right, successor.value);
  }

  return root;
}
中序遍历 — 输出有序序列
BST 有一个非常重要的性质：中序遍历（左 → 根 → 右） 的结果恰好是所有节点值的升序排列。


中序遍历结果：1 → 3 → 4 → 6 → 7 → 8 → 10 → 13 → 14 ✅ 升序


function inorder<T>(root: TreeNode<T> | null): T[] {
  if (root === null) return [];
  return [...inorder(root.left), root.value, ...inorder(root.right)];
}
迭代写法使用显式栈：


function inorderIterative<T>(root: TreeNode<T> | null): T[] {
  const result: T[] = [];
  const stack: TreeNode<T>[] = [];
  let node = root;
  while (node || stack.length > 0) {
    while (node) {
      stack.push(node);
      node = node.left;
    }
    node = stack.pop()!;
    result.push(node.value);
    node = node.right;
  }
  return result;
}
完整示例
class BST<T> {
  root: TreeNode<T> | null = null;

  insert(val: T): void {
    this.root = this._insert(this.root, val);
  }

  private _insert(node: TreeNode<T> | null, val: T): TreeNode<T> {
    if (node === null) return new TreeNode(val);
    if (val < node.value) node.left = this._insert(node.left, val);
    else if (val > node.value) node.right = this._insert(node.right, val);
    return node;
  }

  search(val: T): boolean {
    let node = this.root;
    while (node) {
      if (val === node.value) return true;
      if (val < node.value) node = node.left;
      else node = node.right;
    }
    return false;
  }

  delete(val: T): void {
    this.root = this._delete(this.root, val);
  }

  private _delete(node: TreeNode<T> | null, val: T): TreeNode<T> | null {
    if (node === null) return null;
    if (val < node.value) {
      node.left = this._delete(node.left, val);
    } else if (val > node.value) {
      node.right = this._delete(node.right, val);
    } else {
      if (node.left === null) return node.right;
      if (node.right === null) return node.left;
      let successor = node.right;
      while (successor.left) successor = successor.left;
      node.value = successor.value;
      node.right = this._delete(node.right, successor.value);
    }
    return node;
  }

  inorder(): T[] {
    const result: T[] = [];
    this._inorder(this.root, result);
    return result;
  }

  private _inorder(node: TreeNode<T> | null, result: T[]): void {
    if (node) {
      this._inorder(node.left, result);
      result.push(node.value);
      this._inorder(node.right, result);
    }
  }
}

const tree = new BST<number>();
for (const v of [8, 3, 10, 1, 6, 14, 4, 7, 13]) {
  tree.insert(v);
}

console.log(tree.inorder()); // [1, 3, 4, 6, 7, 8, 10, 13, 14]
console.log(tree.search(6)); // true
console.log(tree.search(5)); // false

tree.delete(3);
console.log(tree.inorder()); // [1, 4, 6, 7, 8, 10, 13, 14]

tree.insert(5);
console.log(tree.inorder()); // [1, 4, 5, 6, 7, 8, 10, 13, 14]
经典应用
    

  1. 有序集合与有序映射 —— 许多语言的标准库基于平衡 BST 实现（如 C++ std::set / std::map、Java TreeSet / TreeMap）。
    2. 

  2. 数据库索引 —— B 树 / B+ 树是 BST 在多路分支上的扩展，广泛用于数据库和文件系统索引。
    3. 

  3. 区间查询 —— BST 的有序性使其天然适合范围查询（查找所有在 [lo,hi][lo, hi][lo,hi] 范围内的元素）。
    4. 

  4. 中位数维护 —— 使用两棵 BST（或堆）分别维护较小和较大的一半数据，支持动态中位数查询。
    5. 



小结
    

  • BST 的核心性质是左 < 根 < 右，这使得查找、插入、删除的平均时间复杂度为 O(log⁡n)O(\log n)O(logn)。
    • 

  • 最坏情况下 BST 退化为链表，时间复杂度变为 O(n)O(n)O(n)。为解决此问题，需要引入自平衡二叉搜索树（AVL 树、红黑树等）。
    • 

  • 删除操作需分三种情况处理：叶子节点直接删除、单子节点用子节点替代、双子节点用中序后继替换后递归删除。
    • 

  • BST 的中序遍历天然产生升序序列，这是 BST 最优美的性质之一。
    • 

  • 理解 BST 是学习平衡树、B 树、线段树等高级树形数据结构的基础。
    •
