单调栈

核心概念

单调栈（Monotonic Stack）是一种在栈的基础上维护元素单调性的特殊栈结构。栈中的元素从底到顶始终保持单调递增或单调递减。当新元素入栈时，所有违反单调性的栈顶元素会被弹出，这个弹出过程恰好揭示了被弹出元素与新元素之间的某种"最近关系"。

单调栈的核心能力是在线性时间内为每个元素找到左侧或右侧第一个更大（或更小）的元素，这类问题被称为 Next Greater Element（NGE）问题。

下一个更大元素
Next Greater Element（NGE）是单调栈最经典的应用。对于数组中的每个元素，找到其右侧第一个比它大的元素。


从右向左遍历：维护一个单调递减栈（从栈底到栈顶递减）。对于当前元素，先弹出所有不大于它的栈顶元素，剩余的栈顶即为答案。


function nextGreaterElement(nums: number[]): number[] {
  const n = nums.length;
  const result = new Array(n).fill(-1);
  const stack: number[] = [];

  for (let i = n - 1; i >= 0; i--) {
    while (stack.length > 0 && stack[stack.length - 1] <= nums[i]) {
      stack.pop();
    }
    if (stack.length > 0) {
      result[i] = stack[stack.length - 1];
    }
    stack.push(nums[i]);
  }

  return result;
}

console.log(nextGreaterElement([2, 1, 2, 4, 3]));
// [4, 2, 4, -1, -1]
从左向右遍历：维护一个存储索引的单调递减栈。当新元素使某个栈顶元素出栈时，说明新元素就是该栈顶元素的下一个更大元素。


function nextGreaterElementLeftToRight(nums: number[]): number[] {
  const n = nums.length;
  const result = new Array(n).fill(-1);
  const stack: number[] = [];

  for (let i = 0; i < n; i++) {
    while (stack.length > 0 && nums[stack[stack.length - 1]] < nums[i]) {
      const idx = stack.pop()!;
      result[idx] = nums[i];
    }
    stack.push(i);
  }

  return result;
}
对于环形数组（如 LeetCode 503），技巧是将数组"复制一份"拼接在后面，用取模模拟环形遍历。


function nextGreaterElementCircular(nums: number[]): number[] {
  const n = nums.length;
  const result = new Array(n).fill(-1);
  const stack: number[] = [];

  for (let i = 2 * n - 1; i >= 0; i--) {
    const idx = i % n;
    while (stack.length > 0 && stack[stack.length - 1] <= nums[idx]) {
      stack.pop();
    }
    if (stack.length > 0) {
      result[idx] = stack[stack.length - 1];
    }
    stack.push(nums[idx]);
  }

  return result;
}

console.log(nextGreaterElementCircular([1, 2, 1]));
// [2, -1, 2]
直方图最大矩形面积
LeetCode 84：给定一组直方图柱子的高度数组，求能勾勒出的最大矩形面积。这是单调栈最经典的应用之一。


核心思路：对于每根柱子，需要找到它左右两侧第一个比它矮的柱子，从而确定以该柱子高度为限所能延伸的最大宽度。


function largestRectangleArea(heights: number[]): number {
  const n = heights.length;
  const stack: number[] = [];
  let maxArea = 0;

  for (let i = 0; i <= n; i++) {
    const currentHeight = i === n ? 0 : heights[i];

    while (stack.length > 0 && heights[stack[stack.length - 1]] > currentHeight) {
      const height = heights[stack.pop()!];
      const width = stack.length === 0 ? i : i - stack[stack.length - 1] - 1;
      maxArea = Math.max(maxArea, height * width);
    }

    stack.push(i);
  }

  return maxArea;
}

console.log(largestRectangleArea([2, 1, 5, 6, 2, 3])); // 10
在末尾添加一个高度为 0 的哨兵元素，确保所有栈中的柱子最终都会被处理。当柱子 h[j]h[j]h[j] 被弹出时，当前索引 iii 是其右边界（第一个更矮的），新的栈顶是其左边界（左侧第一个更矮的），宽度为 i−stack.top−1i - \text{stack.top} - 1i−stack.top−1。

每日温度问题
LeetCode 739：给定每日温度数组，对每一天计算需要等多少天才能迎来更暖和的温度。


function dailyTemperatures(temperatures: number[]): number[] {
  const n = temperatures.length;
  const result = new Array(n).fill(0);
  const stack: number[] = [];

  for (let i = 0; i < n; i++) {
    while (stack.length > 0 && temperatures[stack[stack.length - 1]] < temperatures[i]) {
      const prevIdx = stack.pop()!;
      result[prevIdx] = i - prevIdx;
    }
    stack.push(i);
  }

  return result;
}

console.log(dailyTemperatures([73, 74, 75, 71, 69, 72, 76, 73]));
// [1, 1, 4, 2, 1, 1, 0, 0]
股票价格跨度
LeetCode 901：设计一个 StockSpanner 类，每次调用 next(price) 返回当前价格向左看连续不超过当前价格的天数。


class StockSpanner {
  private stack: [number, number][];

  constructor() {
    this.stack = [];
  }

  next(price: number): number {
    let span = 1;
    while (this.stack.length > 0 && this.stack[this.stack.length - 1][0] <= price) {
      span += this.stack.pop()![1];
    }
    this.stack.push([price, span]);
    return span;
  }
}
接雨水问题
LeetCode 42：给定 nnn 个非负整数表示柱状图中每根柱子的宽度为 1 的条形高度，计算下雨后能接多少水。


function trap(height: number[]): number {
  const stack: number[] = [];
  let water = 0;

  for (let i = 0; i < height.length; i++) {
    while (stack.length > 0 && height[i] > height[stack[stack.length - 1]]) {
      const bottom = stack.pop()!;
      if (stack.length === 0) break;
      const left = stack[stack.length - 1];
      const width = i - left - 1;
      const boundedHeight = Math.min(height[left], height[i]) - height[bottom];
      water += width * boundedHeight;
    }
    stack.push(i);
  }

  return water;
}

console.log(trap([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1])); // 6
小结
    

  • 单调栈通过维护栈内元素的单调性，在线性时间内解决"下一个更大/更小元素"类问题
    • 

  • 找更大元素用单调递减栈，找更小元素用单调递增栈
    • 

  • 栈中通常存储索引而非值，这样既能获取值也能计算距离
    • 

  • 直方图最大矩形面积是单调栈的经典难题，核心是为每根柱子找到左右两侧第一个更矮的柱子
    • 

  • 添加哨兵元素（如末尾加 0）可以简化边界处理，确保所有栈元素最终都被处理
    • 

  • 单调栈的时间和空间复杂度均为 O(n)O(n)O(n)，每个元素最多入栈和出栈各一次
