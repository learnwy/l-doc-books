区间树

核心概念

区间树（Interval Tree）是一种专门为管理区间集合而设计的平衡二叉搜索树。给定一组区间 [lo,hi][lo, hi][lo,hi]，区间树能够高效地回答"哪些区间与给定区间重叠？"这类查询。它在日程安排冲突检测、基因组区域查询、计算几何中的线段交叉判定以及数据库的范围索引等场景中发挥着关键作用。

区间树的核心设计思想是：将每个区间作为一个节点插入 BST，以区间的左端点作为排序键，同时在每个节点上维护一个**子树最大右端点（max）**字段。这个额外信息使得搜索重叠区间时能够高效地剪枝。



每个节点存储一个区间 [lo,hi][lo, hi][lo,hi]，按 lololo 排序。max 字段记录以该节点为根的子树中所有区间的最大右端点。

区间重叠判定与搜索策略
两个区间 [alo,ahi][a_{lo}, a_{hi}][alo​,ahi​] 和 [blo,bhi][b_{lo}, b_{hi}][blo​,bhi​] 重叠的充要条件是：


alo≤bhi∧blo≤ahia_{lo} \leq b_{hi} \wedge b_{lo} \leq a_{hi}alo​≤bhi​∧blo​≤ahi​
等价地，两个区间不重叠当且仅当 ahi<bloa_{hi} < b_{lo}ahi​<blo​ 或 bhi<alob_{hi} < a_{lo}bhi​<alo​（一个完全在另一个的左边或右边）。


区间树搜索重叠区间的策略利用了 max 字段进行剪枝：


    

  1. 如果当前节点的区间与查询区间重叠，将其加入结果集
    2. 

  2. 如果左子树存在且左子树的 max >= query.lo，则左子树中可能存在重叠区间，递归搜索左子树
    3. 

  3. 否则，左子树中不可能有重叠区间（所有区间的右端点都小于 query.lo），只需搜索右子树
    4. 



这种搜索策略之所以高效，是因为当左子树的 max < query.lo 时，整棵左子树都被剪掉了——这意味着左子树中所有区间的右端点都小于查询区间的左端点，不可能与查询区间重叠。


完整实现
interface Interval {
  lo: number;
  hi: number;
}

interface IntervalNode {
  interval: Interval;
  max: number;
  left: IntervalNode | null;
  right: IntervalNode | null;
}

function createNode(interval: Interval): IntervalNode {
  return {
    interval,
    max: interval.hi,
    left: null,
    right: null,
  };
}

function insert(root: IntervalNode | null, interval: Interval): IntervalNode {
  if (root === null) {
    return createNode(interval);
  }

  if (interval.lo < root.interval.lo) {
    root.left = insert(root.left, interval);
  } else {
    root.right = insert(root.right, interval);
  }

  root.max = Math.max(root.max, interval.hi);
  return root;
}

function overlaps(a: Interval, b: Interval): boolean {
  return a.lo <= b.hi && b.lo <= a.hi;
}

function searchOverlap(root: IntervalNode | null, query: Interval): Interval | null {
  if (root === null) return null;

  if (overlaps(root.interval, query)) {
    return root.interval;
  }

  if (root.left !== null && root.left.max >= query.lo) {
    return searchOverlap(root.left, query);
  }

  return searchOverlap(root.right, query);
}

function searchAllOverlaps(root: IntervalNode | null, query: Interval, results: Interval[]): void {
  if (root === null) return;

  if (overlaps(root.interval, query)) {
    results.push(root.interval);
  }

  if (root.left !== null && root.left.max >= query.lo) {
    searchAllOverlaps(root.left, query, results);
  }

  if (root.right !== null && root.interval.lo <= query.hi) {
    searchAllOverlaps(root.right, query, results);
  }
}
使用示例：


let root: IntervalNode | null = null;
root = insert(root, { lo: 15, hi: 20 });
root = insert(root, { lo: 10, hi: 30 });
root = insert(root, { lo: 17, hi: 19 });
root = insert(root, { lo: 5, hi: 20 });
root = insert(root, { lo: 12, hi: 15 });
root = insert(root, { lo: 30, hi: 40 });

const single = searchOverlap(root, { lo: 14, hi: 16 });
console.log(single); // { lo: 15, hi: 20 }

searchAllOverlaps(root, { lo: 14, hi: 16 }, all);
console.log(all); // [{ lo: 15, hi: 20 }, { lo: 10, hi: 30 }, { lo: 5, hi: 20 }, { lo: 12, hi: 15 }]
日程安排与冲突检测
区间树最直观的应用之一是日程安排冲突检测。当添加新的日程时，检查是否与已有日程存在时间重叠。


class MyCalendar {
  private root: IntervalNode | null;

  constructor() {
    this.root = null;
  }

  book(start: number, end: number): boolean {
    const query: Interval = { lo: start, hi: end - 1 };
    const conflict = searchOverlap(this.root, query);
    if (conflict !== null) {
      return false;
    }
    this.root = insert(this.root, query);
    return true;
  }
}

const calendar = new MyCalendar();
console.log(calendar.book(10, 20)); // true
console.log(calendar.book(15, 25)); // false (与 [10,19] 重叠)
console.log(calendar.book(20, 30)); // true
会议室问题
给定一组会议的起止时间，判断一个人是否能参加所有会议（即检查是否存在任何时间冲突）。


function canAttendAllMeetings(meetings: [number, number][]): boolean {
  let root: IntervalNode | null = null;

  for (const [start, end] of meetings) {
    const interval: Interval = { lo: start, hi: end - 1 };
    if (searchOverlap(root, interval) !== null) {
      return false;
    }
    root = insert(root, interval);
  }

  return true;
}

console.log(
  canAttendAllMeetings([
    [0, 30],
    [5, 10],
    [15, 20],
  ]),
); // false
console.log(
  canAttendAllMeetings([
    [7, 10],
    [2, 4],
  ]),
); // true

扫描线算法与区间树
扫描线（Line Sweep）算法是一种将二维问题降为一维的经典技巧，它常常与区间树配合使用。基本思想是用一条垂直线从左到右扫过所有事件点，在扫描过程中用区间树动态维护活跃的区间集合。


矩形面积并：给定若干矩形，求它们的覆盖面积总和（重叠部分只算一次）。


interface Rectangle {
  x1: number;
  y1: number;
  x2: number;
  y2: number;
}

interface Event {
  x: number;
  y1: number;
  y2: number;
  type: 'start' | 'end';
}

function rectangleArea(rects: Rectangle[]): number {
  const events: Event[] = [];

  for (const r of rects) {
    events.push({ x: r.x1, y1: r.y1, y2: r.y2, type: 'start' });
    events.push({ x: r.x2, y1: r.y1, y2: r.y2, type: 'end' });
  }

  events.sort((a, b) => a.x - b.x || (a.type === 'start' ? -1 : 1));

  const activeIntervals: Interval[] = [];
  let totalArea = 0;
  let prevX = events[0].x;

  for (const event of events) {
    if (event.x !== prevX) {
      const coveredLength = computeCoveredLength(activeIntervals);
      totalArea += coveredLength * (event.x - prevX);
      prevX = event.x;
    }

    if (event.type === 'start') {
      activeIntervals.push({ lo: event.y1, hi: event.y2 });
    } else {
      const idx = activeIntervals.findIndex((iv) => iv.lo === event.y1 && iv.hi === event.y2);
      if (idx !== -1) activeIntervals.splice(idx, 1);
    }
  }

  return totalArea;
}

function computeCoveredLength(intervals: Interval[]): number {
  if (intervals.length === 0) return 0;

  const sorted = [...intervals].sort((a, b) => a.lo - b.lo);
  let total = 0;
  let currentEnd = -Infinity;

  for (const iv of sorted) {
    if (iv.lo > currentEnd) {
      total += iv.hi - iv.lo;
      currentEnd = iv.hi;
    } else if (iv.hi > currentEnd) {
      total += iv.hi - currentEnd;
      currentEnd = iv.hi;
    }
  }

  return total;
}

    • 

  • 设计关键在于每个节点维护**子树最大右端点（max）**字段，实现搜索时的高效剪枝
    • 

  • 两个区间 [alo,ahi][a_{lo}, a_{hi}][alo​,ahi​] 与 [blo,bhi][b_{lo}, b_{hi}][blo​,bhi​] 重叠的充要条件是 alo≤bhia_{lo} \leq b_{hi}alo​≤bhi​ 且 blo≤ahib_{lo} \leq a_{hi}blo​≤ahi​
    • 

  • 查询单个重叠区间为 O(log⁡n)O(\log n)O(logn)，查询所有重叠区间为 O(log⁡n+k)O(\log n + k)O(logn+k)（kkk 为结果数量）
    •

    •
