单调队列

核心概念

单调队列（Monotonic Queue）是一种在双端队列（Deque）基础上维护元素单调性的数据结构。与单调栈类似，单调队列要求队列中的元素从队头到队尾保持单调递增或单调递减。其核心能力是在均摊 O(1)O(1)O(1) 时间内维护一个滑动窗口的最大值或最小值，从而将朴素的 O(nk)O(nk)O(nk) 滑动窗口查询优化到 O(n)O(n)O(n)。

滑动窗口最大值
LeetCode 239：给定一个整数数组和滑动窗口大小 kkk，窗口从左向右滑动，每次返回窗口内的最大值。这是单调队列最经典的应用。


维护一个单调递减双端队列（队头最大）：


    

  1. 入队前清理：将队尾所有不大于当前元素的值弹出（它们不可能成为未来窗口的最大值）
    2. 

  2. 入队：当前元素从队尾入队
    3. 

  3. 过期检查：如果队头元素的索引已经不在当前窗口内，从队头弹出
    4. 

  4. 取最值：队头元素即为当前窗口的最大值
    5. 



function maxSlidingWindow(nums: number[], k: number): number[] {
  const n = nums.length;
  const result: number[] = [];
  const deque: number[] = [];

  for (let i = 0; i < n; i++) {
    while (deque.length > 0 && nums[deque[deque.length - 1]] <= nums[i]) {
      deque.pop();
    }

    deque.push(i);

    if (deque[0] <= i - k) {
      deque.shift();
    }

    if (i >= k - 1) {
      result.push(nums[deque[0]]);
    }
  }

  return result;
}

console.log(maxSlidingWindow([1, 3, -1, -3, 5, 3, 6, 7], 3));
// [3, 3, 5, 5, 6, 7]
关键观察：当一个较大的元素进入窗口时，窗口内所有比它小的旧元素永远不可能再成为最大值（因为它比它们更大且更晚离开窗口），因此可以安全移除。这就是单调队列的核心直觉。

滑动窗口最小值与双向极值
同理，维护单调递增队列（队头最小）即可求滑动窗口最小值。


function minSlidingWindow(nums: number[], k: number): number[] {
  const n = nums.length;
  const result: number[] = [];
  const deque: number[] = [];

  for (let i = 0; i < n; i++) {
    while (deque.length > 0 && nums[deque[deque.length - 1]] >= nums[i]) {
      deque.pop();
    }

    deque.push(i);

    if (deque[0] <= i - k) {
      deque.shift();
    }

    if (i >= k - 1) {
      result.push(nums[deque[0]]);
    }
  }

  return result;
}
当需要同时维护窗口的最大值和最小值时（例如求满足 max⁡−min⁡≤limit\max - \min \leq \text{limit}max−min≤limit 的最长子数组），可以同时维护两个单调队列。


function longestSubarray(nums: number[], limit: number): number {
  const maxDeque: number[] = [];
  const minDeque: number[] = [];
  let left = 0;
  let maxLen = 0;

  for (let right = 0; right < nums.length; right++) {
    while (maxDeque.length > 0 && nums[maxDeque[maxDeque.length - 1]] <= nums[right]) {
      maxDeque.pop();
    }
    while (minDeque.length > 0 && nums[minDeque[minDeque.length - 1]] >= nums[right]) {
      minDeque.pop();
    }

    maxDeque.push(right);
    minDeque.push(right);

    while (nums[maxDeque[0]] - nums[minDeque[0]] > limit) {
      left++;
      if (maxDeque[0] < left) maxDeque.shift();
      if (minDeque[0] < left) minDeque.shift();
    }

    maxLen = Math.max(maxLen, right - left + 1);
  }

  return maxLen;
}

console.log(longestSubarray([8, 2, 4, 7], 4)); // 2
console.log(longestSubarray([10, 1, 2, 4, 7, 2], 5)); // 4
动态规划中的单调队列优化
单调队列在动态规划中的一个重要应用是优化具有"有限范围决策"特征的转移方程。当 DP 转移形如：


dp[i]=min⁡j∈[i−k,i−1]{dp[j]}+cost(i)dp[i] = \min_{j \in [i-k, i-1]} \{ dp[j] \} + \text{cost}(i)dp[i]=j∈[i−k,i−1]min​{dp[j]}+cost(i)
朴素实现需要 O(k)O(k)O(k) 遍历所有决策点，单调队列将其优化到 O(1)O(1)O(1)。


跳跃游戏变体：从位置 0 出发，每次可以跳 1 到 kkk 步，每个位置有代价 cost[i]\text{cost}[i]cost[i]，求到达最后位置的最小代价。


function minCostJump(cost: number[], k: number): number {
  const n = cost.length;
  const dp = new Array(n).fill(Infinity);
  dp[0] = cost[0];
  const deque: number[] = [0];

  for (let i = 1; i < n; i++) {
    while (deque.length > 0 && deque[0] < i - k) {
      deque.shift();
    }

    dp[i] = dp[deque[0]] + cost[i];

    while (deque.length > 0 && dp[deque[deque.length - 1]] >= dp[i]) {
      deque.pop();
    }
    deque.push(i);
  }

  return dp[n - 1];
}

小结
    

  • 单调队列在双端队列基础上维护元素单调性，实现均摊 O(1)O(1)O(1) 的滑动窗口极值查询
    • 

  • 维护窗口最大值用单调递减队列，维护最小值用单调递增队列
    • 

  • 核心操作三步：队尾清理（弹出不可能成为答案的元素）→ 入队 → 队头过期检查
    • 

  • 单调队列将滑动窗口最值问题从 O(nk)O(nk)O(nk) 优化到 O(n)O(n)O(n)，每个元素最多入队出队各一次
    • 

  • 在动态规划中，单调队列可以优化具有固定范围决策窗口的转移方程
    • 

  • 同时维护两个单调队列（一增一减），可以高效解决需要同时获取窗口最大值和最小值的问题
