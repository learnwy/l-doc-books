最小生成树

什么是最小生成树

给定一个连通无向加权图 G=(V,E)G = (V, E)G=(V,E)，其**生成树（Spanning Tree）**是一棵包含图中所有顶点、且恰好有 ∣V∣−1|V| - 1∣V∣−1 条边的无环子图。最小生成树（Minimum Spanning Tree，MST）是所有生成树中边权之和最小的那棵。



MST 的关键性质：


    

  • 唯一性：如果所有边权互不相同，则 MST 唯一；如果存在相同权值的边，可能有多棵 MST，但它们的总权值相等。
    • 

  • 边数固定：MST 恰好包含 ∣V∣−1|V| - 1∣V∣−1 条边。
    • 

  • 无环：MST 是一棵树，不包含环。
    • 





切割性质（Cut Property）
切割性质是 MST 算法正确性的理论基础。


将图的顶点集 VVV 分成两个不相交的子集 SSS 和 V∖SV \setminus SV∖S，这种划分称为一个切割（Cut）。横跨切割的边称为交叉边（Crossing Edge）。


切割性质：对于图的任意切割，所有交叉边中权值最小的那条边一定属于某棵 MST。




直觉理解：如果不选择最小的交叉边，而选了一条更大的交叉边来连接两个集合，那么我们总可以用最小交叉边替换它，得到权值更小的生成树——矛盾。




图的表示
在介绍具体算法之前，先定义 TypeScript 中通用的图表示：


interface Edge {
  u: number;
  v: number;
  weight: number;
}

interface Graph {
  vertices: number;
  edges: Edge[];
  adj: Map<number, { to: number; weight: number }[]>;
}

function createGraph(vertices: number, edges: Edge[]): Graph {
  const adj = new Map<number, { to: number; weight: number }[]>();
  for (let i = 0; i < vertices; i++) {
    adj.set(i, []);
  }
  for (const { u, v, weight } of edges) {
    adj.get(u)!.push({ to: v, weight });
    adj.get(v)!.push({ to: u, weight });
  }
  return { vertices, edges, adj };
}
Kruskal 算法
核心思想
Kruskal 算法是一种贪心算法，核心策略为：


    

  1. 将所有边按权值从小到大排序
    2. 

  2. 依次考察每条边，若这条边连接的两个顶点不在同一个连通分量中，则加入 MST
    3. 

  3. 重复直到 MST 包含 ∣V∣−1|V| - 1∣V∣−1 条边
    4. 



判断"是否在同一个连通分量"使用**并查集（Union-Find）**数据结构。


并查集实现
class UnionFind {
  parent: number[];
  rank: number[];

  constructor(n: number) {
    this.parent = Array.from({ length: n }, (_, i) => i);
    this.rank = new Array(n).fill(0);
  }

  find(x: number): number {
    if (this.parent[x] !== x) {
      this.parent[x] = this.find(this.parent[x]);
    }
    return this.parent[x];
  }

  union(x: number, y: number): boolean {
    const rootX = this.find(x);
    const rootY = this.find(y);
    if (rootX === rootY) return false;

    if (this.rank[rootX] < this.rank[rootY]) {
      this.parent[rootX] = rootY;
    } else if (this.rank[rootX] > this.rank[rootY]) {
      this.parent[rootY] = rootX;
    } else {
      this.parent[rootY] = rootX;
      this.rank[rootX]++;
    }
    return true;
  }
}
Kruskal 完整实现
function kruskal(vertices: number, edges: Edge[]): { mst: Edge[]; totalWeight: number } {
  const sorted = [...edges].sort((a, b) => a.weight - b.weight);
  const uf = new UnionFind(vertices);
  const mst: Edge[] = [];
  let totalWeight = 0;

  for (const edge of sorted) {
    if (uf.union(edge.u, edge.v)) {
      mst.push(edge);
      totalWeight += edge.weight;
      if (mst.length === vertices - 1) break;
    }
  }

  return { mst, totalWeight };
}

Prim 算法
核心思想
Prim 算法同样是贪心算法，但策略不同：从一个起始顶点出发，逐步扩展已选顶点集合，每次选择连接已选集合与未选集合之间权值最小的边。


这正是切割性质的直接应用——已选顶点集与未选顶点集形成一个切割，每一步都选择最小的交叉边。


使用优先队列的实现
class MinHeap<T> {
  private heap: { key: number; value: T }[] = [];

  get size(): number {
    return this.heap.length;
  }

  push(key: number, value: T): void {
    this.heap.push({ key, value });
    this.siftUp(this.heap.length - 1);
  }

  pop(): { key: number; value: T } | undefined {
    if (this.heap.length === 0) return undefined;
    const top = this.heap[0];
    const last = this.heap.pop()!;
    if (this.heap.length > 0) {
      this.heap[0] = last;
      this.siftDown(0);
    }
    return top;
  }

  private siftUp(i: number): void {
    while (i > 0) {
      const parent = (i - 1) >> 1;
      if (this.heap[i].key < this.heap[parent].key) {
        [this.heap[i], this.heap[parent]] = [this.heap[parent], this.heap[i]];
        i = parent;
      } else break;
    }
  }

  private siftDown(i: number): void {
    const n = this.heap.length;
    while (true) {
      let smallest = i;
      const left = 2 * i + 1;
      const right = 2 * i + 2;
      if (left < n && this.heap[left].key < this.heap[smallest].key) smallest = left;
      if (right < n && this.heap[right].key < this.heap[smallest].key) smallest = right;
      if (smallest !== i) {
        [this.heap[i], this.heap[smallest]] = [this.heap[smallest], this.heap[i]];
        i = smallest;
      } else break;
    }
  }
}
Prim 完整实现
function prim(graph: Graph, start: number = 0): { mst: Edge[]; totalWeight: number } {
  const inMST = new Array(graph.vertices).fill(false);
  const mst: Edge[] = [];
  let totalWeight = 0;
  const pq = new MinHeap<{ from: number; to: number }>();

  inMST[start] = true;
  for (const { to, weight } of graph.adj.get(start)!) {
    pq.push(weight, { from: start, to });
  }

  while (pq.size > 0 && mst.length < graph.vertices - 1) {
    const {
      key: weight,
      value: { from, to },
    } = pq.pop()!;

    if (inMST[to]) continue;

    inMST[to] = true;
    mst.push({ u: from, v: to, weight });
    totalWeight += weight;

    for (const { to: next, weight: w } of graph.adj.get(to)!) {
      if (!inMST[next]) {
        pq.push(w, { from: to, to: next });
      }
    }
  }

  return { mst, totalWeight };
}

应用场景
MST 算法在实际工程中有着广泛的应用：


1. 网络设计
铺设光纤、电缆、管道等基础设施时，需要连接所有节点且总成本最低。


2. 聚类分析
将 MST 中权值最大的 k−1k-1k−1 条边删除，可以将数据分成 kkk 个簇。这是一种基于图的聚类方法（Single-Linkage Clustering）。


3. 近似算法
    

  • 旅行商问题（TSP）：MST 的权值是 TSP 最优解的下界。基于 MST 的 2-近似算法可以在多项式时间内给出不超过最优解 2 倍的解。
    • 

  • Steiner 树问题：MST 可作为 Steiner 树的近似解。
    • 



4. 图像处理
    

  • 图像分割：将像素作为图的顶点，像素间的差异作为边权，使用 MST 进行区域分割。
    • 

  • 边缘检测：利用 MST 识别图像中的显著边界。
    •

小结
    

  • **最小生成树（MST）**是连通无向加权图中边权之和最小的生成树，恰好包含 ∣V∣−1|V| - 1∣V∣−1 条边。
    • 

  • 切割性质是 MST 算法正确性的理论基础：任意切割的最小交叉边一定属于某棵 MST。
    • 

  • Kruskal 算法将所有边排序后，利用并查集逐一加入不形成环的最小边，时间复杂度 O(Elog⁡E)O(E \log E)O(ElogE)，适合稀疏图。
    • 

  • Prim 算法从一个顶点出发，用优先队列每次选择最小的交叉边来扩展树，时间复杂度 O((V+E)log⁡V)O((V+E) \log V)O((V+E)logV)，适合稠密图。
    • 

  • 两种算法产生的 MST 总权值相同（若边权唯一则 MST 唯一），选择哪种取决于图的稀疏程度和实现便捷性。
    • 

  • MST 在网络设计、聚类分析、近似算法、图像处理等领域有广泛的实际应用。
    •
