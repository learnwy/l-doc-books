拓扑排序

有向无环图（DAG）

拓扑排序的前提是图必须是一个 DAG（Directed Acyclic Graph，有向无环图）——即一个有方向、没有环路的图。

DAG 的核心特征：


    

  • 有向：每条边都有明确的方向，表示依赖或先后关系
    • 

  • 无环：不存在从任何节点出发经过若干条边又回到自身的路径
    • 

  • 如果图中存在环，则不可能进行拓扑排序，因为环中的节点互相依赖，无法确定先后顺序
    • 





DAG 在工程中极为常见：项目构建依赖、课程先修关系、任务调度流程、电子表格的单元格引用等，都是天然的 DAG 结构。




什么是拓扑排序
拓扑排序（Topological Sort）是将 DAG 中所有节点排成一个线性序列，使得对于图中每一条有向边 u→vu \to vu→v，节点 uuu 在序列中都排在节点 vvv 之前。


上图的一个合法拓扑排序为：数学基础 → 编程语言 → 数据结构 → 算法导论 → 数据库 → 人工智能


关键性质：


    

  • 拓扑排序的结果不唯一，只要满足所有边的先后约束即可
    • 

  • 当且仅当图是 DAG 时，拓扑排序才存在
    • 

  • 如果拓扑排序的结果节点数少于图的总节点数，说明图中存在环
    • 



图的表示
在实现拓扑排序之前，先定义图的邻接表表示：


type Graph = Map<string, string[]>;

function createGraph(edges: [string, string][]): Graph {
  const graph: Graph = new Map();
  for (const [u, v] of edges) {
    if (!graph.has(u)) graph.set(u, []);
    if (!graph.has(v)) graph.set(v, []);
    graph.get(u)!.push(v);
  }
  return graph;
}
Kahn 算法（BFS + 入度）
Kahn 算法是拓扑排序最直观的实现方式，基于 BFS 和 入度（in-degree） 的概念。


核心思想
节点的入度是指向该节点的边的数量。入度为 0 的节点没有任何前置依赖，可以优先处理。每次将入度为 0 的节点加入结果并移除其出边，这可能使其他节点入度变为 0，如此迭代直到所有节点处理完毕。

TypeScript 实现
function kahnTopologicalSort(graph: Graph): string[] | null {
  const inDegree: Map<string, number> = new Map();
  for (const node of graph.keys()) {
    inDegree.set(node, 0);
  }
  for (const [, neighbors] of graph) {
    for (const neighbor of neighbors) {
      inDegree.set(neighbor, (inDegree.get(neighbor) ?? 0) + 1);
    }
  }

  const queue: string[] = [];
  for (const [node, degree] of inDegree) {
    if (degree === 0) {
      queue.push(node);
    }
  }

  const result: string[] = [];
  while (queue.length > 0) {
    const node = queue.shift()!;
    result.push(node);

    for (const neighbor of graph.get(node) ?? []) {
      const newDegree = inDegree.get(neighbor)! - 1;
      inDegree.set(neighbor, newDegree);
      if (newDegree === 0) {
        queue.push(neighbor);
      }
    }
  }

  return result.length === graph.size ? result : null;
}


若函数返回 null，表示图中存在环，无法完成拓扑排序。




DFS 方法（后序反转）
除了 BFS，还可以使用 DFS（深度优先搜索） 实现拓扑排序。核心思想是：对每个节点递归访问其所有后继，当一个节点的所有后继都已处理完毕后，将该节点压入栈中。最终栈的逆序（或反转后的数组）就是拓扑排序的结果。


核心思想
DFS 方法利用了后序遍历的特性：一个节点在其所有依赖项之后才被加入栈，反转后恰好满足拓扑排序的要求。


TypeScript 实现
function dfsTopologicalSort(graph: Graph): string[] | null {
  const visited = new Set<string>();
  const visiting = new Set<string>();
  const stack: string[] = [];
  let hasCycle = false;

  function dfs(node: string): void {
    if (hasCycle) return;
    if (visiting.has(node)) {
      hasCycle = true;
      return;
    }
    if (visited.has(node)) return;

    visiting.add(node);
    for (const neighbor of graph.get(node) ?? []) {
      dfs(neighbor);
    }
    visiting.delete(node);
    visited.add(node);
    stack.push(node);
  }

  for (const node of graph.keys()) {
    if (!visited.has(node)) {
      dfs(node);
    }
  }

  if (hasCycle) return null;
  return stack.reverse();
}

当 DFS 遇到一个灰色节点时，说明从当前路径回到了正在处理的祖先节点，这就是一个环。


环检测
环检测是拓扑排序的副产品，两种算法都能自然地检测环的存在：


Kahn 算法检测环
如果算法结束后，结果中的节点数少于图的总节点数，则说明存在环——环中的节点入度永远无法降为 0。


function hasCycleKahn(graph: Graph): boolean {
  const inDegree: Map<string, number> = new Map();
  for (const node of graph.keys()) {
    inDegree.set(node, 0);
  }
  for (const [, neighbors] of graph) {
    for (const neighbor of neighbors) {
      inDegree.set(neighbor, (inDegree.get(neighbor) ?? 0) + 1);
    }
  }

  const queue: string[] = [];
  for (const [node, degree] of inDegree) {
    if (degree === 0) queue.push(node);
  }

  let processedCount = 0;
  while (queue.length > 0) {
    const node = queue.shift()!;
    processedCount++;
    for (const neighbor of graph.get(node) ?? []) {
      const newDegree = inDegree.get(neighbor)! - 1;
      inDegree.set(neighbor, newDegree);
      if (newDegree === 0) queue.push(neighbor);
    }
  }

  return processedCount !== graph.size;
}
DFS 三色标记检测环
DFS 过程中遇到灰色节点（正在递归栈中的节点）即检测到环：


function hasCycleDFS(graph: Graph): boolean {
  const visited = new Set<string>();
  const visiting = new Set<string>();

  function dfs(node: string): boolean {
    if (visiting.has(node)) return true;
    if (visited.has(node)) return false;

    visiting.add(node);
    for (const neighbor of graph.get(node) ?? []) {
      if (dfs(neighbor)) return true;
    }
    visiting.delete(node);
    visited.add(node);
    return false;
  }

  for (const node of graph.keys()) {
    if (!visited.has(node)) {
      if (dfs(node)) return true;
    }
  }
  return false;
}

应用场景
1. 任务调度
在项目管理中，某些任务必须在其他任务完成后才能开始。拓扑排序可以确定一个合法的执行顺序。


function scheduleTasksDemo(): void {
  const taskDeps: [string, string][] = [
    ['需求分析', '系统设计'],
    ['系统设计', '编码实现'],
    ['系统设计', '数据库设计'],
    ['编码实现', '单元测试'],
    ['数据库设计', '编码实现'],
    ['单元测试', '集成测试'],
    ['集成测试', '部署上线'],
  ];
  const graph = createGraph(taskDeps);
  const order = kahnTopologicalSort(graph);

  if (order) {
    console.log('任务执行顺序:');
    order.forEach((task, i) => console.log(`  ${i + 1}. ${task}`));
  } else {
    console.log('存在循环依赖，无法调度！');
  }
}
2. 构建系统（Build Systems）
像 webpack、turbo、nx 这样的构建工具，需要分析模块之间的依赖关系，按正确顺序编译或打包。如果出现循环依赖，构建工具会报错。


function analyzeBuildOrder(): void {
  const moduleDeps: [string, string][] = [
    ['utils', 'logger'],
    ['utils', 'config'],
    ['config', 'database'],
    ['logger', 'database'],
    ['database', 'api-server'],
    ['config', 'api-server'],
    ['api-server', 'app'],
  ];
  const graph = createGraph(moduleDeps);
  const buildOrder = kahnTopologicalSort(graph);

  if (buildOrder) {
    console.log('构建顺序:');
    buildOrder.forEach((mod, i) => console.log(`  [${i + 1}] 编译 ${mod}`));
  } else {
    console.log('检测到循环依赖！请检查模块引用关系。');
  }
}
3. 课程先修关系
大学选课系统中，某些课程需要先修课程作为前提。拓扑排序帮助学生规划合理的选课顺序。


function canFinishCourses(numCourses: number, prerequisites: [number, number][]): number[] | null {
  const graph: Map<number, number[]> = new Map();
  const inDegree: Map<number, number> = new Map();

  for (let i = 0; i < numCourses; i++) {
    graph.set(i, []);
    inDegree.set(i, 0);
  }

  for (const [course, prereq] of prerequisites) {
    graph.get(prereq)!.push(course);
    inDegree.set(course, inDegree.get(course)! + 1);
  }

  const queue: number[] = [];
  for (const [course, degree] of inDegree) {
    if (degree === 0) queue.push(course);
  }

  const order: number[] = [];
  while (queue.length > 0) {
    const course = queue.shift()!;
    order.push(course);
    for (const next of graph.get(course)!) {
      const newDegree = inDegree.get(next)! - 1;
      inDegree.set(next, newDegree);
      if (newDegree === 0) queue.push(next);
    }
  }

  return order.length === numCourses ? order : null;
}

const courseOrder = canFinishCourses(6, [
  [1, 0],
  [2, 0],
  [3, 1],
  [3, 2],
  [4, 3],
  [5, 4],
]);
console.log(courseOrder); // [0, 1, 2, 3, 4, 5]
4. 并行任务调度（分层拓扑排序）
Kahn 算法天然支持按层级输出拓扑排序结果，同一层的节点可以并行执行：


function parallelSchedule(graph: Graph): string[][] {
  const inDegree: Map<string, number> = new Map();
  for (const node of graph.keys()) {
    inDegree.set(node, 0);
  }
  for (const [, neighbors] of graph) {
    for (const neighbor of neighbors) {
      inDegree.set(neighbor, (inDegree.get(neighbor) ?? 0) + 1);
    }
  }

  let currentLevel: string[] = [];
  for (const [node, degree] of inDegree) {
    if (degree === 0) currentLevel.push(node);
  }

  const levels: string[][] = [];
  while (currentLevel.length > 0) {
    levels.push([...currentLevel]);
    const nextLevel: string[] = [];
    for (const node of currentLevel) {
      for (const neighbor of graph.get(node) ?? []) {
        const newDegree = inDegree.get(neighbor)! - 1;
        inDegree.set(neighbor, newDegree);
        if (newDegree === 0) nextLevel.push(neighbor);
      }
    }
    currentLevel = nextLevel;
  }

  return levels;
}

const taskGraph = createGraph([
  ['A', 'C'],
  ['A', 'D'],
  ['B', 'D'],
  ['B', 'E'],
  ['C', 'F'],
  ['D', 'F'],
  ['E', 'F'],
]);
const levels = parallelSchedule(taskGraph);
levels.forEach((level, i) => console.log(`第 ${i + 1} 轮（可并行）: ${level.join(', ')}`));

小结
    

  • 拓扑排序是 DAG（有向无环图） 独有的操作，将所有节点排成满足依赖关系的线性序列。
    • 

  • Kahn 算法基于 BFS 和入度，直观且支持分层输出，适合并行调度场景。
    • 

  • DFS 方法利用后序遍历反转，代码简洁，适合递归风格的实现。
    • 

  • 两种算法的时间和空间复杂度均为 O(V+E)O(V + E)O(V+E)，在实际工程中都是高效的选择。
    • 

  • 环检测是拓扑排序的自然副产品：Kahn 算法通过结果节点数判断，DFS 通过三色标记（灰色节点）判断。
    • 

  • 拓扑排序在任务调度、构建系统、课程先修、包管理依赖解析等场景中有着广泛的实际应用。
    •
