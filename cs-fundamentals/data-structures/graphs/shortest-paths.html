最短路径算法

什么是最短路径问题

在加权图中，最短路径问题是求从源节点到目标节点的路径，使得路径上所有边的权重之和最小。这是图论中最经典、应用最广泛的问题之一。



在上图中，从 A 到 D 的最短路径是 A → C → B → D，总权重为 2+1+3=62 + 1 + 3 = 62+1+3=6，而不是直接走 A → B → D（4+3=74 + 3 = 74+3=7）或 A → C → D（2+5=72 + 5 = 72+5=7）。




根据问题的变体，最短路径算法可以分为三大类：

Dijkstra 算法
核心思想
Dijkstra 算法是解决非负权重图上单源最短路径的经典贪心算法。它的核心思想是：


    

  1. 维护一个距离数组 dist[]，记录源点到每个节点的当前最短距离估计
    2. 

  2. 每次从未确定的节点中，选择距离最小的节点 uuu（贪心选择）
    3. 

  3. 用 uuu 的邻边去**松弛（relax）**其他节点的距离
    4. 

  4. 重复直到所有节点的最短距离都被确定
    5. 





松弛操作：如果通过节点 uuu 到达 vvv 的路径比当前已知的更短，即 dist[u]+w(u,v)<dist[v]\text{dist}[u] + w(u,v) < \text{dist}[v]dist[u]+w(u,v)<dist[v]，则更新 dist[v]\text{dist}[v]dist[v]。

优先队列优化
朴素 Dijkstra 每轮需要 O(V)O(V)O(V) 时间寻找最小距离节点，总时间为 O(V2)O(V^2)O(V2)。使用**最小堆（优先队列）**可以将"取最小值"优化为 O(log⁡V)O(\log V)O(logV)，总时间降为 O((V+E)log⁡V)O((V + E) \log V)O((V+E)logV)。


TypeScript 实现
class MinHeap<T> {
  private data: T[] = [];
  constructor(private compare: (a: T, b: T) => number) {}

  get size(): number {
    return this.data.length;
  }

  push(val: T): void {
    this.data.push(val);
    this.siftUp(this.data.length - 1);
  }

  pop(): T | undefined {
    if (this.data.length === 0) return undefined;
    const top = this.data[0];
    const last = this.data.pop()!;
    if (this.data.length > 0) {
      this.data[0] = last;
      this.siftDown(0);
    }
    return top;
  }

  private siftUp(i: number): void {
    while (i > 0) {
      const parent = (i - 1) >> 1;
      if (this.compare(this.data[i], this.data[parent]) < 0) {
        [this.data[i], this.data[parent]] = [this.data[parent], this.data[i]];
        i = parent;
      } else {
        break;
      }
    }
  }

  private siftDown(i: number): void {
    const n = this.data.length;
    while (true) {
      let smallest = i;
      const left = 2 * i + 1;
      const right = 2 * i + 2;
      if (left < n && this.compare(this.data[left], this.data[smallest]) < 0) {
        smallest = left;
      }
      if (right < n && this.compare(this.data[right], this.data[smallest]) < 0) {
        smallest = right;
      }
      if (smallest !== i) {
        [this.data[i], this.data[smallest]] = [this.data[smallest], this.data[i]];
        i = smallest;
      } else {
        break;
      }
    }
  }
}

function dijkstra(graph: Graph, src: number): { dist: number[]; prev: number[] } {
  const n = graph.length;
  const dist = Array(n).fill(Infinity);
  const prev = Array(n).fill(-1);
  dist[src] = 0;

  const heap = new MinHeap<[number, number]>((a, b) => a[0] - b[0]);
  heap.push([0, src]);

  while (heap.size > 0) {
    const [d, u] = heap.pop()!;
    if (d > dist[u]) continue;

    for (const { to: v, weight: w } of graph[u]) {
      const newDist = dist[u] + w;
      if (newDist < dist[v]) {
        dist[v] = newDist;
        prev[v] = u;
        heap.push([newDist, v]);
      }
    }
  }

  return { dist, prev };
}

function getPath(prev: number[], target: number): number[] {
  const path: number[] = [];
  for (let v = target; v !== -1; v = prev[v]) {
    path.push(v);
  }
  return path.reverse();
}

const g = createGraph(5);

⚠️ Dijkstra 算法不能处理负权边。如果图中存在负权边，贪心策略将失效——已经确定的"最短距离"可能被后续的负权边进一步缩短。




Bellman-Ford 算法
核心思想
Bellman-Ford 算法可以处理含负权边的图，同时能够检测负权环。它的核心思想是逐轮松弛：


    

  1. 对所有边进行 V−1V - 1V−1 轮松弛操作
    2. 

  2. 每一轮至少确定一个节点的最短路径
    3. 

  3. 如果第 VVV 轮仍然能松弛某条边，说明存在负权环
    4. 





为什么是 V−1V - 1V−1 轮？因为从源点到任意节点的最短路径最多包含 V−1V - 1V−1 条边。每轮松弛至少确定一条边的最终距离，所以 V−1V - 1V−1 轮后所有最短路径都已确定。

负权环检测


上图中 B → C → B 构成一个负权环（3+(−5)=−2<03 + (-5) = -2 < 03+(−5)=−2<0）。每走一圈，路径总权重减少 2，因此不存在"最短路径"——可以无限绕环使距离趋近 −∞-\infty−∞。




TypeScript 实现
interface WeightedEdge {
  from: number;
  to: number;
  weight: number;
}

function bellmanFord(
  n: number,
  edges: WeightedEdge[],
  src: number,
): { dist: number[]; prev: number[]; hasNegativeCycle: boolean } {
  const dist = Array(n).fill(Infinity);
  const prev = Array(n).fill(-1);
  dist[src] = 0;

  for (let i = 0; i < n - 1; i++) {
    let updated = false;
    for (const { from, to, weight } of edges) {
      if (dist[from] !== Infinity && dist[from] + weight < dist[to]) {
        dist[to] = dist[from] + weight;
        prev[to] = from;
        updated = true;
      }
    }
    if (!updated) break;
  }

  let hasNegativeCycle = false;
  for (const { from, to, weight } of edges) {
    if (dist[from] !== Infinity && dist[from] + weight < dist[to]) {
      hasNegativeCycle = true;
      break;
    }
  }

  return { dist, prev, hasNegativeCycle };
}
使用示例
const edges: WeightedEdge[] = [
  { from: 0, to: 1, weight: 6 },
  { from: 0, to: 2, weight: 7 },
  { from: 1, to: 2, weight: -4 },
  { from: 1, to: 3, weight: 5 },
  { from: 1, to: 4, weight: 8 },
  { from: 2, to: 3, weight: -3 },
  { from: 3, to: 1, weight: 7 },
  { from: 3, to: 4, weight: 9 },
  { from: 4, to: 3, weight: 2 },
];

const result = bellmanFord(5, edges, 0);
console.log(result.dist); // [0, 6, 2, -1, 8]
console.log(result.hasNegativeCycle); // false

Floyd-Warshall 算法
核心思想
Floyd-Warshall 算法解决全源最短路径问题——计算图中每对顶点之间的最短距离。它基于动态规划思想：


dist[i][j]=min⁡(dist[i][j], dist[i][k]+dist[k][j])\text{dist}[i][j] = \min(\text{dist}[i][j],\ \text{dist}[i][k] + \text{dist}[k][j])dist[i][j]=min(dist[i][j], dist[i][k]+dist[k][j])
逐步引入中间节点 k=0,1,2,…,V−1k = 0, 1, 2, \dots, V-1k=0,1,2,…,V−1，每次考虑"是否经过节点 kkk 能获得更短的路径"。


算法步骤图解
TypeScript 实现
function floydWarshall(
  n: number,
  edges: WeightedEdge[],
): {
  dist: number[][];
  next: number[][];
} {
  const dist: number[][] = Array.from({ length: n }, () => Array(n).fill(Infinity));
  const next: number[][] = Array.from({ length: n }, () => Array(n).fill(-1));

  for (let i = 0; i < n; i++) {
    dist[i][i] = 0;
  }

  for (const { from, to, weight } of edges) {
    dist[from][to] = weight;
    next[from][to] = to;
  }

  for (let k = 0; k < n; k++) {
    for (let i = 0; i < n; i++) {
      for (let j = 0; j < n; j++) {
        if (dist[i][k] + dist[k][j] < dist[i][j]) {
          dist[i][j] = dist[i][k] + dist[k][j];
          next[i][j] = next[i][k];
        }
      }
    }
  }

  return { dist, next };
}

function reconstructPath(next: number[][], from: number, to: number): number[] {
  if (next[from][to] === -1) return [];
  const path = [from];
  let current = from;
  while (current !== to) {
    current = next[current][to];
    path.push(current);
  }
  return path;
}
使用示例
const fwEdges: WeightedEdge[] = [
  { from: 0, to: 1, weight: 3 },
  { from: 0, to: 2, weight: 7 },
  { from: 1, to: 2, weight: 1 },
  { from: 1, to: 3, weight: 6 },
  { from: 2, to: 3, weight: 2 },
  { from: 3, to: 0, weight: 4 },
];

const { dist: fwDist, next: fwNext } = floydWarshall(4, fwEdges);

console.log(fwDist[0][3]); // 6（0→1→2→3）
console.log(reconstructPath(fwNext, 0, 3)); // [0, 1, 2, 3]

console.log(fwDist[3][2]); // 8（3→0→1→2）
console.log(reconstructPath(fwNext, 3, 2)); // [3, 0, 1, 2]
检测负权环
Floyd-Warshall 算法执行完毕后，如果 dist[i][i] < 0，则说明节点 iii 位于某个负权环上：


function hasNegativeCycleFloyd(dist: number[][]): boolean {
  for (let i = 0; i < dist.length; i++) {
    if (dist[i][i] < 0) return true;
  }
  return false;
}

小结
    

  • Dijkstra 算法是解决非负权图单源最短路径的首选，基于贪心策略和优先队列，时间复杂度为 O((V+E)log⁡V)O((V+E)\log V)O((V+E)logV)。它不能处理负权边。
    • 

  • Bellman-Ford 算法通过 V−1V-1V−1 轮逐边松弛来求解单源最短路径，支持负权边，并能检测负权环，时间复杂度为 O(V⋅E)O(V \cdot E)O(V⋅E)。
    • 

  • Floyd-Warshall 算法基于动态规划，逐步引入中间节点来更新所有顶点对的最短距离，时间复杂度为 O(V3)O(V^3)O(V3)，适合求解全源最短路径问题。
    • 

  • 选择算法时，需考虑：是否存在负权边、需要单源还是全源、图的稠密程度。三种算法互为补充，覆盖了绝大多数最短路径场景。
