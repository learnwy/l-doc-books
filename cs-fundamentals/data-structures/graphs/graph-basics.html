图的表示与遍历

什么是图

图（Graph）是一种由**顶点（Vertex）和边（Edge）**组成的非线性数据结构，用于描述事物之间的"多对多"关系。与树只有一个根且无环不同，图的任意两个顶点之间都可能存在连接，且允许形成环路。



社交网络中的好友关系、地图中的道路系统、网页之间的超链接……这些现实问题都可以用图来建模。

图的表示方法
图的存储方式直接影响算法的时间和空间效率。两种最常用的表示方法是邻接矩阵和邻接列表。


邻接矩阵（Adjacency Matrix）
用一个 n×nn \times nn×n 的二维数组 matrix 表示图，其中 matrix[i][j] 表示顶点 iii 到顶点 jjj 是否存在边（或边的权值）。

无向图的邻接矩阵是对称的，即 matrix[i][j] === matrix[j][i]。




class GraphMatrix {
  private matrix: number[][];
  private size: number;

  constructor(vertices: number) {
    this.size = vertices;
    this.matrix = Array.from({ length: vertices }, () => new Array(vertices).fill(0));
  }

  addEdge(u: number, v: number, weight: number = 1): void {
    this.matrix[u][v] = weight;
    this.matrix[v][u] = weight;
  }

  removeEdge(u: number, v: number): void {
    this.matrix[u][v] = 0;
    this.matrix[v][u] = 0;
  }

  hasEdge(u: number, v: number): boolean {
    return this.matrix[u][v] !== 0;
  }

  getNeighbors(v: number): number[] {
    const neighbors: number[] = [];
    for (let i = 0; i < this.size; i++) {
      if (this.matrix[v][i] !== 0) {
        neighbors.push(i);
      }
    }
    return neighbors;
  }

  degree(v: number): number {
    return this.getNeighbors(v).length;
  }
}
使用示例：


const g = new GraphMatrix(4);
g.addEdge(0, 1);
g.addEdge(0, 2);
g.addEdge(1, 2);
g.addEdge(1, 3);
g.addEdge(2, 3);

console.log(g.hasEdge(0, 3)); // false
console.log(g.getNeighbors(1)); // [0, 2, 3]
console.log(g.degree(1)); // 3
邻接列表（Adjacency List）
为每个顶点维护一个列表，存储与其相连的所有邻居节点。相比邻接矩阵，邻接列表在稀疏图中更节省空间。


class GraphList {
  private adjacencyList: Map<number, { node: number; weight: number }[]>;

  constructor() {
    this.adjacencyList = new Map();
  }

  addVertex(v: number): void {
    if (!this.adjacencyList.has(v)) {
      this.adjacencyList.set(v, []);
    }
  }

  addEdge(u: number, v: number, weight: number = 1): void {
    this.addVertex(u);
    this.addVertex(v);
    this.adjacencyList.get(u)!.push({ node: v, weight });
    this.adjacencyList.get(v)!.push({ node: u, weight });
  }

  removeEdge(u: number, v: number): void {
    const uList = this.adjacencyList.get(u);
    const vList = this.adjacencyList.get(v);
    if (uList) {
      this.adjacencyList.set(
        u,
        uList.filter((e) => e.node !== v),
      );
    }
    if (vList) {
      this.adjacencyList.set(
        v,
        vList.filter((e) => e.node !== u),
      );
    }
  }

  getNeighbors(v: number): { node: number; weight: number }[] {
    return this.adjacencyList.get(v) ?? [];
  }

  hasEdge(u: number, v: number): boolean {
    const neighbors = this.adjacencyList.get(u);
    return neighbors !== undefined && neighbors.some((e) => e.node === v);
  }

  degree(v: number): number {
    return this.getNeighbors(v).length;
  }

  get vertices(): number[] {
    return [...this.adjacencyList.keys()];
  }
}
使用示例：


const g = new GraphList();
g.addEdge(0, 1);
g.addEdge(0, 2);
g.addEdge(1, 2);
g.addEdge(1, 3);
g.addEdge(2, 3);

console.log(g.hasEdge(0, 3)); // false
console.log(g.getNeighbors(1)); // [{ node: 0, weight: 1 }, { node: 2, weight: 1 }, { node: 3, weight: 1 }]
console.log(g.degree(2)); // 3

实际工程中，大多数图都是稀疏的（如社交网络、路网），因此邻接列表是更常用的表示方式。




图的遍历
图的遍历是从某个顶点出发，按照特定规则系统地访问图中所有可达顶点的过程。两种基本的遍历策略是广度优先搜索（BFS）和深度优先搜索（DFS）。


与树的遍历不同，图可能存在环，因此必须使用 visited 集合记录已访问的顶点，防止无限循环。


广度优先搜索（BFS）
BFS（Breadth-First Search）从起始顶点出发，先访问所有距离为 1 的邻居，再访问距离为 2 的邻居，逐层向外扩展，使用队列实现。


BFS 遍历顺序：0 → 1 → 2 → 3 → 4 → 5


function bfs(graph: Map<number, number[]>, start: number): number[] {
  const visited = new Set<number>();
  const queue: number[] = [start];
  const result: number[] = [];

  visited.add(start);

  while (queue.length > 0) {
    const vertex = queue.shift()!;
    result.push(vertex);

    for (const neighbor of graph.get(vertex) ?? []) {
      if (!visited.has(neighbor)) {
        visited.add(neighbor);
        queue.push(neighbor);
      }
    }
  }

  return result;
}

const graph = new Map<number, number[]>();
graph.set(0, [1, 2]);
graph.set(1, [0, 3, 4]);
graph.set(2, [0, 4]);
graph.set(3, [1, 5]);
graph.set(4, [1, 2, 5]);
graph.set(5, [3, 4]);

console.log(bfs(graph, 0)); // [0, 1, 2, 3, 4, 5]
BFS 的层级遍历
在许多场景中（如求最短路径），需要按层记录遍历结果：


function bfsLevelOrder(graph: Map<number, number[]>, start: number): number[][] {
  const visited = new Set<number>();
  const queue: number[] = [start];
  const levels: number[][] = [];

  visited.add(start);

  while (queue.length > 0) {
    const levelSize = queue.length;
    const currentLevel: number[] = [];

    for (let i = 0; i < levelSize; i++) {
      const vertex = queue.shift()!;
      currentLevel.push(vertex);

      for (const neighbor of graph.get(vertex) ?? []) {
        if (!visited.has(neighbor)) {
          visited.add(neighbor);
          queue.push(neighbor);
        }
      }
    }
    levels.push(currentLevel);
  }

  return levels;
}

console.log(bfsLevelOrder(graph, 0));
// [[0], [1, 2], [3, 4], [5]]


BFS 的关键性质：从起点到任意可达顶点的 BFS 路径是最短路径（在无权图中）。这使得 BFS 天然适合求解无权图的最短路径问题。




深度优先搜索（DFS）
DFS（Depth-First Search）从起始顶点出发，沿着一条路径尽可能深入，直到无法继续，再回溯到上一个分叉点继续探索。可以使用递归或显式栈实现。


DFS 遍历顺序（一种可能的结果）：0 → 1 → 3 → 5 → 4 → 2


递归实现
function dfsRecursive(graph: Map<number, number[]>, start: number): number[] {
  const visited = new Set<number>();
  const result: number[] = [];

  function dfs(vertex: number): void {
    visited.add(vertex);
    result.push(vertex);

    for (const neighbor of graph.get(vertex) ?? []) {
      if (!visited.has(neighbor)) {
        dfs(neighbor);
      }
    }
  }

  dfs(start);
  return result;
}

console.log(dfsRecursive(graph, 0)); // [0, 1, 3, 5, 4, 2]
迭代实现（显式栈）
function dfsIterative(graph: Map<number, number[]>, start: number): number[] {
  const visited = new Set<number>();
  const stack: number[] = [start];
  const result: number[] = [];

  while (stack.length > 0) {
    const vertex = stack.pop()!;

    if (visited.has(vertex)) {
      continue;
    }

    visited.add(vertex);
    result.push(vertex);

    const neighbors = graph.get(vertex) ?? [];
    for (let i = neighbors.length - 1; i >= 0; i--) {
      if (!visited.has(neighbors[i])) {
        stack.push(neighbors[i]);
      }
    }
  }

  return result;
}

console.log(dfsIterative(graph, 0)); // [0, 1, 3, 5, 4, 2]


注意迭代版 DFS 中，邻居节点逆序入栈，这样出栈顺序就与邻接列表中的顺序一致，保证和递归版的遍历顺序相同。




处理非连通图
如果图不连通（存在孤立的连通分量），需要对所有未访问的顶点分别启动遍历：


function bfsAll(graph: Map<number, number[]>): number[][] {
  const visited = new Set<number>();
  const components: number[][] = [];

  for (const vertex of graph.keys()) {
    if (!visited.has(vertex)) {
      const component: number[] = [];
      const queue: number[] = [vertex];
      visited.add(vertex);

      while (queue.length > 0) {
        const v = queue.shift()!;
        component.push(v);

        for (const neighbor of graph.get(v) ?? []) {
          if (!visited.has(neighbor)) {
            visited.add(neighbor);
            queue.push(neighbor);
          }
        }
      }
      components.push(component);
    }
  }

  return components;
}

小结
    

  • 图是由顶点和边组成的非线性数据结构，能够描述复杂的多对多关系。
    • 

  • 图的核心分类维度包括：有向/无向、加权/无权、连通/非连通。
    • 

  • 邻接矩阵查边 O(1)O(1)O(1) 但空间 O(V2)O(V^2)O(V2)，适合稠密图；邻接列表空间 O(V+E)O(V+E)O(V+E)，适合稀疏图，是实际工程中更常用的选择。
    • 

  • BFS 使用队列逐层扩展，天然求解无权图最短路径；DFS 使用栈/递归深入探索，适合连通性检测和回溯类问题。
    • 

  • 两种遍历的时间复杂度均为 O(V+E)O(V + E)O(V+E)，图遍历时必须使用 visited 集合防止重复访问。
    • 

  • 掌握图的表示和遍历是学习最短路径（Dijkstra、Bellman-Ford）、最小生成树（Prim、Kruskal）、拓扑排序等高级图算法的基础。
