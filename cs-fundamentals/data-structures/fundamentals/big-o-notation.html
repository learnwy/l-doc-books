大O表示法

什么是大O表示法

大O表示法（Big O Notation）是描述算法渐近上界的数学符号，用于衡量算法的时间复杂度或空间复杂度如何随输入规模 n 的增长而变化。它关注的不是精确的执行时间，而是增长趋势——当输入足够大时，算法性能的变化规律。

简单来说，大O回答了一个核心问题：当数据量翻倍时，算法需要的时间/空间会怎样变化？

形式化数学定义

若存在正常数 c 和 n₀，使得对所有 n ≥ n₀，都有：

f(n) ≤ c · g(n)

则称 f(n) = O(g(n))。

其中 f(n) 是算法的实际操作次数函数，g(n) 是我们用来描述上界的函数。大O关注的是 最坏情况 下的增长量级。

常见复杂度

复杂度 名称 典型场景 n=10 n=100 n=1000
O(1) 常数时间 数组按索引访问、哈希表查找 1 1 1
O(log n) 对数时间 二分查找、平衡BST操作 3 7 10
O(n) 线性时间 遍历数组、线性搜索 10 100 1,000
O(n log n) 线性对数时间 归并排序、快速排序（平均） 33 664 9,966
O(n²) 平方时间 冒泡排序、嵌套循环 100 10,000 1,000,000
O(2ⁿ) 指数时间 子集枚举、递归斐波那契 1,024 1.27×10³⁰ ∞
O(n!) 阶乘时间 全排列、旅行商暴力解 3,628,800 ∞ ∞

增长率对比

增长速度排序（从慢到快）：


O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)


💡 在实际工程中，O(n log n) 通常是排序问题的最优解，O(n²) 及以上在大数据量时往往不可接受。




大O计算规则
规则一：丢弃常数系数
常数不影响增长趋势，大O只关心量级。


// 虽然循环了 3n 次，但复杂度仍为 O(n)
function example(arr: number[]): void {
  for (const item of arr) {
    // n 次
  }
  for (const item of arr) {
    // n 次
  }
  for (const item of arr) {
    // n 次
  }
}
// 总操作：3n → O(n)
规则二：丢弃低阶项
只保留最高阶项，因为当 n 足够大时，低阶项可以忽略。


// n² + n + 1000 → O(n²)
function example(arr: number[]): void {
  for (const i of arr) {
    // O(n)
    for (const j of arr) {
      // O(n)
    } // → O(n²)
  }
  for (const item of arr) {
    // O(n)
  }
}
// 总操作：n² + n → O(n²)
规则三：不同输入用不同变量
如果算法有多个独立输入，需要使用不同的变量表示。


// 不能简单地说 O(n²)，应该是 O(a · b)
function printPairs(listA: string[], listB: string[]): void {
  for (const a of listA) {
    // O(a)
    for (const b of listB) {
      // O(b)
      console.log(a, b); // → O(a × b)
    }
  }
}

function sequential(arr1: number[], arr2: number[]): void {
  for (const item of arr1) {
    // O(n)
  }
  for (const item of arr2) {
    // O(m)
  }
}

// 乘法：O(n × m)
function nested(arr1: number[], arr2: number[]): void {
  for (const i of arr1) {
    // O(n)
    for (const j of arr2) {
      // O(m)
    }
  }
}
实际代码示例
O(1) — 常数时间
function getFirst(arr: number[]): number {
  return arr[0];
}
无论数组有多大，只执行一次操作。


O(log n) — 对数时间
function binarySearch(arr: number[], target: number): number {
  let low = 0;
  let high = arr.length - 1;
  while (low <= high) {
    const mid = Math.floor((low + high) / 2);
    if (arr[mid] === target) {
      return mid;
    } else if (arr[mid] < target) {
      low = mid + 1;
    } else {
      high = mid - 1;
    }
  }
  return -1;
}
每次循环将搜索范围缩小一半，所以循环次数为 log₂n。


O(n) — 线性时间
function findMax(arr: number[]): number {
  let maxVal = arr[0];
  for (const item of arr) {
    if (item > maxVal) {
      maxVal = item;
    }
  }
  return maxVal;
}
需要遍历所有元素一次。


O(n log n) — 线性对数时间
function mergeSort(arr: number[]): number[] {
  if (arr.length <= 1) {
    return arr;
  }
  const mid = Math.floor(arr.length / 2);
  const left = mergeSort(arr.slice(0, mid));
  const right = mergeSort(arr.slice(mid));
  return merge(left, right);
}

function merge(left: number[], right: number[]): number[] {
  const result: number[] = [];
  let i = 0;
  let j = 0;
  while (i < left.length && j < right.length) {
    if (left[i] <= right[j]) {
      result.push(left[i]);
      i++;
    } else {
      result.push(right[j]);
      j++;
    }
  }
  result.push(...left.slice(i));
  result.push(...right.slice(j));
  return result;
}
分治递归深度为 log n，每层合并操作为 O(n)。


O(n²) — 平方时间
function bubbleSort(arr: number[]): number[] {
  const n = arr.length;
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n - i - 1; j++) {
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
      }
    }
  }
  return arr;
}
双重嵌套循环，外层 n 次 × 内层 n 次。


O(2ⁿ) — 指数时间
function fibonacci(n: number): number {
  if (n <= 1) {
    return n;
  }
  return fibonacci(n - 1) + fibonacci(n - 2);
}
每次调用产生两个子调用，形成高度为 n 的二叉递归树。


O(n!) — 阶乘时间
function permutations(arr: number[], start: number = 0): void {
  if (start === arr.length) {
    console.log(arr);
    return;
  }
  for (let i = start; i < arr.length; i++) {
    [arr[start], arr[i]] = [arr[i], arr[start]];
    permutations(arr, start + 1);
    [arr[start], arr[i]] = [arr[i], arr[start]];
  }
}
生成所有排列，n 个元素共有 n! 种排列方式。


总结




要点
说明





大O描述的是上界
表示最坏情况下的增长趋势




忽略常数和低阶项
O(3n² + 5n + 100) = O(n²)




关注最坏情况
确保算法在任何输入下都有性能保障




多输入用多变量
两个独立输入分别用不同变量表示




递归复杂度需画递归树
或使用主定理（Master Theorem）求解
