算法复杂度分析

什么是复杂度分析

复杂度分析是衡量算法效率的核心方法。它描述了算法运行所需的时间和空间资源如何随输入规模 nnn 的增长而变化，而非依赖具体硬件或编程语言。通过复杂度分析，我们可以在不实际运行代码的前提下，对不同算法的性能进行客观比较。

时间复杂度
时间复杂度用来衡量算法的执行时间随输入规模增长的变化趋势，通常用大 O 记号表示，记作 O(f(n))O(f(n))O(f(n))。


分析时间复杂度时关注以下原则：


    

  1. 只保留最高阶项 —— 3n2+5n+103n^2 + 5n + 103n2+5n+10 简化为 O(n2)O(n^2)O(n2)
    2. 

  2. 忽略常数系数 —— 5n5n5n 简化为 O(n)O(n)O(n)
    3. 

  3. 关注最坏情况 —— 除非特别说明，默认分析的是最坏情况
    4. 



常见时间复杂度示例
O(1) — 常数阶


function getFirst(arr: number[]): number {
  return arr[0];
}
无论数组多大，只需一次操作。


O(n) — 线性阶


function linearSearch(arr: number[], target: number): boolean {
  for (const item of arr) {
    if (item === target) {
      return true;
    }
  }
  return false;
}
最坏情况下需遍历整个数组。


O(n²) — 平方阶


function bubbleSort(arr: number[]): void {
  const n = arr.length;
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n - i - 1; j++) {
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
      }
    }
  }
}
两层嵌套循环，每层最多遍历 nnn 次。


O(log n) — 对数阶


function binarySearch(arr: number[], target: number): number {
  let lo = 0;
  let hi = arr.length - 1;
  while (lo <= hi) {
    const mid = Math.floor((lo + hi) / 2);
    if (arr[mid] === target) {
      return mid;
    } else if (arr[mid] < target) {
      lo = mid + 1;
    } else {
      hi = mid - 1;
    }
  }
  return -1;
}
每次将搜索范围缩小一半。


O(n log n) — 线性对数阶


归并排序、快速排序（平均情况）等高效排序算法属于此类。


空间复杂度
空间复杂度衡量算法运行过程中额外使用的内存空间随输入规模的增长趋势。

function swap(arr: number[], i: number, j: number): void {
  [arr[i], arr[j]] = [arr[j], arr[i]];
}

// O(n) 空间 — 创建辅助数组
function duplicate(arr: number[]): number[] {
  return [...arr];
}
最好、最坏与平均情况
对同一算法，不同输入可能产生截然不同的执行效率。因此我们区分三种分析场景：






分析类型
含义
线性搜索示例





最好情况 (Best Case)
输入最有利时的复杂度
目标在第一个位置：O(1)O(1)O(1)




最坏情况 (Worst Case)
输入最不利时的复杂度
目标不存在或在末尾：O(n)O(n)O(n)




平均情况 (Average Case)
所有可能输入的期望复杂度
目标等概率出现在任意位置：O(n)O(n)O(n)







在实际工程中，最坏情况最为重要，因为它决定了算法性能的下限保证。

小结
    

  • 复杂度分析是评价算法优劣的通用语言，独立于具体运行环境。
    • 

  • 时间复杂度关注操作次数的增长趋势；空间复杂度关注额外内存的增长趋势。
    • 

  • 实际选择算法时，需要在时间和空间之间进行权衡（时空权衡）。
    • 

  • 养成对每段代码进行复杂度分析的习惯，是提升算法能力的基础。
