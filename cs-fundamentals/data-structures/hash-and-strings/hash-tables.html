哈希表

什么是哈希表

哈希表（Hash Table），又称散列表，是一种基于键值对（Key-Value）存储的数据结构。它通过哈希函数（Hash Function）将键映射到数组中的某个位置（称为桶 / bucket），从而实现平均 O(1)O(1)O(1) 时间复杂度的查找、插入和删除操作。



哈希表的核心思想：用空间换时间。通过一个额外的数组和哈希函数，将按值查找的 O(n)O(n)O(n) 问题转化为按下标访问的 O(1)O(1)O(1) 问题。




哈希函数
哈希函数 h(key)h(key)h(key) 将任意键映射到一个固定范围 [0,m−1][0, m-1][0,m−1] 的整数（其中 mmm 为哈希表的容量），这个整数就是键在底层数组中的存储位置。

可以看到，键 10 和键 31 都被映射到了位置 3 —— 这就是哈希冲突（collision）。


冲突解决
哈希冲突是不可避免的（根据鸽巢原理，当键的数量大于桶的数量时，必定有多个键映射到同一桶）。解决冲突的策略主要有两大类：链地址法和开放寻址法。


链地址法（Chaining）
每个桶维护一个链表（或其他集合），所有映射到同一位置的键值对都存储在该链表中。


查找过程：先通过 h(key)h(key)h(key) 定位桶，再遍历该桶的链表查找目标键。


class HashTableChaining<K, V> {
  private capacity: number;
  private buckets: [K, V][][];
  private _size: number;

  constructor(capacity: number = 7) {
    this.capacity = capacity;
    this.buckets = Array.from({ length: capacity }, () => []);
    this._size = 0;
  }

  get size(): number {
    return this._size;
  }

  private hash(key: K): number {
    const str = String(key);
    let h = 0;
    for (let i = 0; i < str.length; i++) {
      h = (h * 31 + str.charCodeAt(i)) % this.capacity;
    }
    return h;
  }

  put(key: K, value: V): void {
    const idx = this.hash(key);
    for (const pair of this.buckets[idx]) {
      if (pair[0] === key) {
        pair[1] = value;
        return;
      }
    }
    this.buckets[idx].push([key, value]);
    this._size++;
  }

  get(key: K): V | undefined {
    const idx = this.hash(key);
    for (const pair of this.buckets[idx]) {
      if (pair[0] === key) {
        return pair[1];
      }
    }
    return undefined;
  }
}
开放寻址法（Open Addressing）
所有元素都直接存储在哈希表数组中。当发生冲突时，按照某种探测序列寻找下一个空桶。


线性探测（Linear Probing）
发生冲突时，依次检查下一个位置：


hi(key)=(h(key)+i)mod  m,i=0,1,2,…h_i(key) = (h(key) + i) \mod m, \quad i = 0, 1, 2, \dotshi​(key)=(h(key)+i)modm,i=0,1,2,…
优点：缓存友好（连续内存访问）。 缺点：容易产生聚集（clustering），即已占用的连续区域不断增长，导致后续冲突更频繁。


二次探测（Quadratic Probing）
探测间隔为二次函数，避免线性聚集：


hi(key)=(h(key)+c1⋅i+c2⋅i2)mod  mh_i(key) = (h(key) + c_1 \cdot i + c_2 \cdot i^2) \mod mhi​(key)=(h(key)+c1​⋅i+c2​⋅i2)modm
常见简化形式为 hi=(h(key)+i2)mod  mh_i = (h(key) + i^2) \mod mhi​=(h(key)+i2)modm。


双重哈希（Double Hashing）
使用第二个哈希函数计算探测步长，分布更均匀：


hi(key)=(h1(key)+i⋅h2(key))mod  mh_i(key) = (h_1(key) + i \cdot h_2(key)) \mod mhi​(key)=(h1​(key)+i⋅h2​(key))modm
其中 h2(key)≠0h_2(key) \ne 0h2​(key)=0，常取 h2(key)=q−(keymod  q)h_2(key) = q - (key \mod q)h2​(key)=q−(keymodq)，qqq 为小于 mmm 的质数。

再哈希（Rehashing）
当 α\alphaα 超过阈值时，触发再哈希：


再哈希是一次 O(n)O(n)O(n) 的操作，但由于容量翻倍，其触发频率随元素增长而降低，均摊到每次插入仍为 O(1)O(1)O(1)（与动态数组扩容的分析完全类似）。

最坏情况何时出现？ 当哈希函数退化（所有键映射到同一桶），链地址法下链表长度达到 nnn，查找退化为 O(n)O(n)O(n)。Java 8 的 HashMap 通过将长链表转化为红黑树来缓解这一问题，使最坏情况从 O(n)O(n)O(n) 降低到 O(log⁡n)O(\log n)O(logn)。


实际语言中的哈希表
TypeScript — Map
const d = new Map<string, number>();
d.set('apple', 5); // 插入 — 均摊 O(1)
d.set('banana', 12);
console.log(d.get('apple')); // 查找 — O(1)
d.delete('banana'); // 删除 — O(1)
console.log(d.has('apple')); // 成员判断 — O(1)

// Map 保持插入顺序
for (const [key, value] of d) {
  console.log(key, value);
}
TypeScript 的 Map 对象是 ES6 引入的内置哈希表实现，保证按照插入顺序迭代，支持任意类型作为键。

使用场景与选型建议
    

  • 优先选择哈希表：当需要根据键进行高频查找、插入或删除，且不要求有序性时。
    • 

  • 避免使用哈希表：当需要按键排序遍历、范围查询，或者内存非常紧张时（有序树结构更合适）。
    • 



经典应用
    

  1. 两数之和 —— 用哈希表存储已遍历元素，O(n)O(n)O(n) 时间找出目标对。
    2. 

  2. 字符频率统计 —— 统计字符串中每个字符出现的次数。
    3. 

  3. 缓存（LRU Cache） —— 哈希表 + 双向链表实现 O(1)O(1)O(1) 的缓存读写。
    4. 

  4. 去重 —— 利用哈希集合（HashSet）快速判断元素是否已存在。
    5. 

  5. 分组 —— 按特定规则将元素归类，如字母异位词分组。
    6. 



小结
    

  • 哈希表通过哈希函数将键映射到数组下标，实现平均 O(1)O(1)O(1) 的增删查操作。
    • 

  • 哈希冲突不可避免，两种主流解决方案为链地址法和开放寻址法。
    • 

  • 负载因子控制哈希表的拥挤程度，超过阈值时触发再哈希（扩容），均摊代价仍为 O(1)O(1)O(1)。
    • 

  • 最坏情况下哈希表退化为 O(n)O(n)O(n)，但良好的哈希函数和合理的负载因子可以有效避免这一问题。
    • 

  • TypeScript 中 Map 和 Record（普通对象）是最常用的哈希表实现，Map 支持任意类型键且保持插入顺序。
