工业应用 简介

本章将形式化方法从理论带入工程实践。前三章建立了形式化规约、模型检验和定理证明的理论基础，本章聚焦于这些理论如何在真实的软件和系统工程中落地。你将学习两款面向工程的形式化语言，并通过工业界的实际案例理解形式化方法在不同行业中的应用方式和价值。

TLA+ 是由 Leslie Lamport 设计的面向并发和分布式系统的形式化规约语言。本节介绍 TLA+ 的核心语法和思维模式，展示如何用 TLA+ 对分布式算法和系统架构进行建模，以及如何使用配套的 TLC 模型检验器自动验证设计的正确性。Amazon Web Services 等公司已将 TLA+ 深度应用于生产系统的设计验证中。

Alloy 是一种轻量级的形式化建模语言，以关系逻辑为基础，特别适合对软件结构和约束进行快速探索式分析。本节讲解 Alloy 的声明式建模方式、自动化分析引擎的工作原理，以及如何利用 Alloy 在设计阶段尽早发现潜在的逻辑缺陷。

工业界实践梳理形式化方法在航空航天、铁路信号、金融系统和操作系统内核等关键领域的真实应用案例。你将了解不同行业对形式化验证的需求差异、采纳过程中的实际挑战，以及形式化方法与传统测试方法如何互补协作。

建议先学习 TLA+ 和 Alloy 各自的建模思想和工具链，再通过工业界实践一节建立对形式化方法落地全景的认识。如果你正在设计分布式系统或安全关键软件，TLA+ 一节将为你提供最直接的实践指导。
