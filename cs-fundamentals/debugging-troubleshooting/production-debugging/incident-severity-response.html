线上问题分级与响应

概述

线上问题分级（Severity Classification）是生产环境故障管理的基础框架。它为不同严重程度的问题定义了标准化的响应速度、升级路径和处理流程，确保团队在压力下依然能够有序高效地协作。没有分级体系的团队要么对所有问题都"全员救火"导致疲惫，要么对严重问题反应不及时导致损失扩大。

T+45min  IC 宣布故障关闭

分级判断决策树
def classify_severity(incident):
    """根据影响评估故障级别"""

    # P0: 核心功能完全中断
    if incident.core_function_down and incident.all_users_affected:
        return "P0"

    # P0: 数据安全事件
    if incident.data_breach or incident.data_loss:
        return "P0"

    # P1: 核心功能部分降级
    if incident.core_function_degraded and incident.affected_users_percent > 20:
        return "P1"

    # P1: 收入直接受损
    if incident.revenue_impact_per_minute > 1000:
        return "P1"

    # P2: 非核心功能异常
    if incident.non_core_function_down:
        return "P2"

    # P2: 少量用户核心功能受影响
    if incident.core_function_degraded and incident.affected_users_percent < 5:
        return "P2"

    # P3: 有替代方案的问题
    if incident.workaround_available:
        return "P3"

    return "P4"

总结
线上问题分级是生产稳定性的制度保障。关键实践：建立清晰的 P0-P4 分级标准、配置合理的升级策略、指定 IC 负责协调、标准化沟通模板。好的分级体系让团队在压力下仍能理性决策，避免"所有问题都是紧急"的混乱状态。
