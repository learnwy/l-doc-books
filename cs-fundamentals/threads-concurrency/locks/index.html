Part III · 系统 (Systems)线程与并发 简介锁 简介

锁 简介

在多线程编程中，当多个线程需要访问共享资源时，如果不加以协调，就会产生数据竞争和不可预期的结果。锁是解决这一问题最直接、最经典的同步原语。它通过在任一时刻只允许一个（或有限个）线程进入临界区，来保证共享数据的一致性。

锁的概念虽然简单——"获取锁、操作数据、释放锁"——但在实际使用中却充满了微妙的取舍与陷阱。选择什么类型的锁、锁的粒度如何设定、如何避免死锁、何时该用锁而何时该用无锁方案，这些问题的答案直接决定了并发程序的正确性与性能。

本章分为三个部分系统地介绍锁。

第一部分"锁的定义与概念"建立基本认知。你将了解互斥锁、读写锁、自旋锁、递归锁等常见锁类型的定义和特征，理解它们各自的语义差异。同时，本部分还会介绍临界区、锁的公平性、可重入性等核心术语。

第二部分"锁的核心思想"探讨锁在并发系统中的设计哲学。锁的粒度（粗粒度与细粒度）如何影响吞吐量与复杂度？乐观锁与悲观锁代表了怎样不同的并发策略？锁竞争激烈时该如何优化？你将在这里建立对锁机制的系统性思考框架。

第三部分"锁的实现"将原理落实到各语言和平台的实际 API 上。你将看到 POSIX 线程库、Java 的 synchronized 与 ReentrantLock、C++ 的 std::mutex、Swift 的 os_unfair_lock 等实现方式，了解不同环境下锁的使用模式和最佳实践。

锁是并发工具箱中不可或缺的一员，但它也不是万能的。用好锁，意味着在安全性与性能之间找到恰当的平衡。本章将为你提供做出这种判断所需的全部知识。
