Part III · 系统 (Systems)线程与并发 简介线程 简介线程的定义与核心概念

线程的定义与核心概念

什么是线程

线程（Thread）是操作系统进行 CPU 调度的基本单位。一个线程是进程内部的一条执行路径，它属于某个进程，与同一进程中的其他线程共享该进程的地址空间和资源（如内存、文件句柄），但每个线程拥有自己独立的程序计数器、寄存器和栈。

简单来说：进程是资源分配的单位，线程是 CPU 调度的单位。

一个进程至少包含一个线程（主线程）。当需要并发执行多个任务时，可以在同一进程内创建多个线程，它们并行地执行不同的代码路径。


进程 (PID: 1001)
- 主线程 (TID: 1) → 处理用户界面
- 线程 2 (TID: 2)  → 后台数据加载
- 线程 3 (TID: 3)  → 网络请求处理
- 线程 4 (TID: 4)  → 日志写入

所有线程共享同一地址空间，可直接读写相同的全局变量。

线程的状态模型
线程与进程拥有相似的状态模型，但由于线程是更轻量的执行单元，其状态转换更加频繁。

线程的类型
根据线程的实现层级，线程可以分为三种主要类型：


用户级线程（User-Level Thread）
用户级线程完全在用户空间中实现和管理，操作系统内核不知道它们的存在。线程的创建、调度和切换都由用户空间的线程库完成。


内核级线程（Kernel-Level Thread）
内核级线程由操作系统内核直接管理和调度。每个线程在内核中都有对应的数据结构，线程的创建、切换和销毁都需要通过系统调用。


混合线程（Hybrid Thread）
混合线程模型结合了用户级和内核级线程的优点，将 M 个用户级线程映射到 N 个内核级线程上（M:N 模型）。

线程控制块（TCB）
与进程的 PCB 类似，每个线程也有一个线程控制块（Thread Control Block, TCB），但 TCB 的内容比 PCB 精简得多，因为线程共享了进程的大部分资源。

小结
    

  • 线程是 CPU 调度的基本单位，属于进程内部的执行路径，与同进程的其他线程共享地址空间和资源。
    • 

  • 线程与进程的核心区别：进程是资源容器，线程是执行单元；进程间强隔离，线程间弱隔离但通信高效。
    • 

  • 线程的状态模型与进程类似（新建、就绪、运行、阻塞、终止），但线程阻塞的原因更多样（锁、条件变量等）。
    • 

  • 线程按实现层级分为用户级线程（快但不能利用多核）、内核级线程（能利用多核但开销较大）和混合线程（兼顾两者优势）。
    • 

  • 每个线程拥有独立的程序计数器、寄存器和栈，但共享进程的代码段、数据段、堆和文件描述符。
    •
