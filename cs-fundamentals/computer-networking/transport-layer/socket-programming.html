Socket 编程

Socket 概述

Socket（套接字）是操作系统提供的网络通信抽象接口，它封装了底层协议栈的细节，让应用程序可以通过简单的 API 进行网络通信。Socket 是连接应用层与传输层的桥梁。

应用程序 A                              应用程序 B
    │                                       │
    ↓                                       ↓
 Socket API                             Socket API
    │                                       │
    ↓                                       ↓
 TCP/UDP                                TCP/UDP
    │                                       │
    ↓                                       ↓
   IP ──────── 网络传输 ─────────────────→ IP

TCP Socket 通信流程

服务端                                    客户端
  │                                         │
  │ socket()     创建套接字                  │
  │ bind()       绑定地址和端口              │
  │ listen()     进入监听状态                │
  │                                         │ socket()  创建套接字
  │              ← 三次握手 →                │ connect() 发起连接
  │ accept()     接受连接，返回新 socket      │
  │                                         │
  │ read/recv    ← 数据传输 →    write/send  │
  │ write/send   → 数据传输 →    read/recv   │
  │                                         │
  │ close()      ← 四次挥手 →    close()     │
  │                                         │

TCP 服务端示例（C 语言）

#include <sys/socket.h>
#include <netinet/in.h>

int main() {
    int server_fd = socket(AF_INET, SOCK_STREAM, 0);

    struct sockaddr_in addr = {
        .sin_family = AF_INET,
        .sin_addr.s_addr = INADDR_ANY,
        .sin_port = htons(8080)
    };

    bind(server_fd, (struct sockaddr*)&addr, sizeof(addr));
    listen(server_fd, 128);

    int client_fd = accept(server_fd, NULL, NULL);

    char buf[1024];
    ssize_t n = read(client_fd, buf, sizeof(buf));
    write(client_fd, buf, n);

    close(client_fd);
    close(server_fd);
    return 0;
}

UDP Socket 通信流程

服务端                                    客户端
  │                                         │
  │ socket()     创建套接字                  │
  │ bind()       绑定地址和端口              │ socket()  创建套接字
  │                                         │
  │ recvfrom()   ← 数据报 ←    sendto()     │
  │ sendto()     → 数据报 →    recvfrom()   │
  │                                         │
  │ close()                     close()      │
  │                                         │

UDP 无需 listen/accept/connect，直接通过 sendto/recvfrom 传输数据报。

阻塞 vs 非阻塞

模式 read() 行为 适用场景
阻塞 无数据时挂起线程，直到数据到达 简单场景，一连接一线程
非阻塞 无数据时立即返回 EAGAIN/EWOULDBLOCK 高并发场景 
int flags = fcntl(sockfd, F_GETFL, 0);
fcntl(sockfd, F_SETFL, flags | O_NONBLOCK);

IO 多路复用

IO 多路复用允许单个线程同时监听多个 Socket 的事件，是高并发服务器的核心技术。

select / poll / epoll / kqueue 对比

特性 select poll epoll kqueue
平台 跨平台 跨平台 Linux macOS/BSD
最大连接数 1024 (FD_SETSIZE) 无硬限制 无硬限制 无硬限制
数据结构 fd_set 位图 pollfd 数组 红黑树+就绪链表 kqueue 事件
事件触发 水平触发 水平触发 水平/边缘触发 水平/边缘触发
每次调用复杂度 O(n) O(n) O(1) O(1)
fd 拷贝 每次全量拷贝 每次全量拷贝 注册时拷贝一次 注册时拷贝一次

epoll 工作流程

int epfd = epoll_create1(0);

struct epoll_event ev;
ev.events = EPOLLIN;
ev.data.fd = listen_fd;
epoll_ctl(epfd, EPOLL_CTL_ADD, listen_fd, &ev);

struct epoll_event events[MAX_EVENTS];
while (1) {
    int nfds = epoll_wait(epfd, events, MAX_EVENTS, -1);
    for (int i = 0; i < nfds; i++) {
        if (events[i].data.fd == listen_fd) {
            int conn_fd = accept(listen_fd, NULL, NULL);
            ev.events = EPOLLIN | EPOLLET;
            ev.data.fd = conn_fd;
            epoll_ctl(epfd, EPOLL_CTL_ADD, conn_fd, &ev);
        } else {
            handle_connection(events[i].data.fd);
        }
    }
}

水平触发 vs 边缘触发

水平触发（LT - Level Triggered）：
  缓冲区有数据 → 每次 epoll_wait 都会通知
  更安全，不会丢事件

边缘触发（ET - Edge Triggered）：
  缓冲区从无数据变为有数据 → 仅通知一次
  必须一次性读完所有数据（循环 read 直到 EAGAIN）
  性能更高，但编程更复杂

经典并发模型

模型 1：一连接一线程（Thread-per-Connection）
  accept → 创建新线程 → 线程内阻塞读写
  缺点：线程数受限，上下文切换开销大

模型 2：线程池（Thread Pool）
  accept → 任务放入队列 → 线程池中的线程处理
  优化：限制线程数量

模型 3：Reactor 模式（epoll/kqueue）
  主线程 epoll_wait → 分发事件 → 工作线程处理
  典型实现：Nginx, Redis, Node.js

模型 4：Proactor 模式（IOCP）
  异步 IO 完成后回调通知
  典型实现：Windows IOCP

实战：Node.js TCP 服务器

const net = require('net');

const server = net.createServer((socket) => {
  socket.on('data', (data) => {
    const message = data.toString().trim();
    socket.write(`Echo: ${message}\n`);
  });

  socket.on('end', () => {
    console.log('Client disconnected');
  });

  socket.on('error', (err) => {
    console.error('Socket error:', err.message);
  });
});

server.listen(8080, () => {
  console.log('TCP server listening on port 8080');
});

小结

  • Socket 是应用程序进行网络通信的标准接口，支持 TCP 和 UDP 两种传输协议。
  • TCP Socket 通信遵循 socket → bind → listen → accept → read/write → close 流程。
  • IO 多路复用（epoll/kqueue）是构建高并发服务器的核心技术，支持单线程处理数万连接。
  • 边缘触发比水平触发性能更高，但要求一次读完缓冲区所有数据。
  • Reactor 模式是现代高性能服务器（Nginx、Redis、Node.js）的基础架构。
