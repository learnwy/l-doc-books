电子邮件体系概述

电子邮件是互联网最早的应用之一。邮件系统由多个协议协作完成发送、传输和接收的全过程。



    

  • MUA = Mail User Agent（邮件客户端，如 Outlook、Thunderbird）
    • 

  • MTA = Mail Transfer Agent（邮件传输代理，如 Postfix、Sendmail）
    • 

  • MDA = Mail Delivery Agent（邮件投递代理，投递到用户邮箱）
    •

FTP（文件传输协议）
FTP 使用两条 TCP 连接：控制连接（端口 21）传输命令，数据连接传输文件。


主动模式 vs 被动模式


    

  • 主动模式：服务端主动连接客户端，客户端防火墙可能阻止入站连接
    • 

  • 被动模式：客户端主动连接服务端，穿越客户端防火墙更容易
    •

小结
    

  • SMTP 负责邮件发送，POP3/IMAP 负责邮件接收，三者协作完成邮件通信全流程。
    • 

  • IMAP 支持多设备同步和服务器端管理，已成为主流的邮件接收协议。
    • 

  • SPF、DKIM、DMARC 三重机制保障邮件的来源验证和内容完整性。
    • 

  • FTP 使用双连接架构，被动模式更适合现代防火墙和 NAT 环境。
    • 

  • SFTP（基于 SSH）是 FTP 的安全替代，现代应用更倾向使用对象存储和 HTTP API。
