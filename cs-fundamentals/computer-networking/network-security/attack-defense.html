攻击与防御

网络安全威胁概览

网络攻击按照目标和手段可以分为多个类别。理解攻击原理是构建有效防御的前提。

攻击类别 目标 典型攻击
可用性攻击 使服务不可用 DDoS, SYN Flood
机密性攻击 窃取数据 中间人攻击, 嗅探
完整性攻击 篡改数据 ARP 欺骗, DNS 劫持
身份伪造 冒充合法用户 IP 欺骗, 会话劫持

DDoS 攻击

DDoS（Distributed Denial of Service）通过大量分布式节点向目标发送海量请求，耗尽目标的带宽、连接或计算资源。

DDoS 攻击类型

协议型攻击（连接耗尽）：SYN Flood → 填满半连接队列 → 无法接受新连接


应用层攻击（资源耗尽）：大量 HTTP 请求 → 耗尽 Web 服务器处理能力；慢速攻击（Slowloris）→ 占满连接池

ARP 欺骗
ARP 欺骗通过发送伪造的 ARP 响应，将攻击者的 MAC 地址与目标 IP 关联，从而截获局域网内的流量。




    

  • 正常 ARP 表：网关 192.168.1.1 → MAC: AA:BB:CC:DD:EE:FF
    • 

  • ARP 欺骗后：网关 192.168.1.1 → MAC: 11:22:33:44:55:66（攻击者 MAC）
    •

小结
    

  • DDoS 攻击从网络层到应用层都可能发生，需要多层防御体系应对。
    • 

  • 中间人攻击通过截获通信实施窃听和篡改，HTTPS 和证书验证是核心防御手段。
    • 

  • ARP 欺骗利用 ARP 协议的无认证特性，DAI 和静态绑定是有效的防御措施。
    • 

  • DNS 劫持将用户导向恶意站点，DoH/DoT 和 DNSSEC 可以保障 DNS 查询安全。
    • 

  • 安全防御需要预防、检测、响应三个维度协同配合，构建纵深防御体系。
