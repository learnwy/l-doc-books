防火墙与 IDS

防火墙概述

防火墙是网络安全的第一道防线，通过预定义的安全规则控制进出网络的流量。防火墙根据工作层级和检测方式分为多种类型。



防火墙类型
包过滤防火墙（Packet Filter）
工作在网络层（L3/L4），基于 IP 地址、端口、协议进行过滤。


规则示例：
  允许  TCP  任意来源  →  内网:80   （允许 HTTP）
  允许  TCP  任意来源  →  内网:443  （允许 HTTPS）
  拒绝  TCP  任意来源  →  内网:22   （禁止 SSH）
  拒绝  所有                        （默认拒绝）
状态防火墙（Stateful Firewall）
跟踪连接状态，只允许属于已建立连接的数据包通过。


状态表示例：
| 源 IP         | 目标 IP        | 源端口 | 目标端口 | 协议 | 状态         |
| 192.168.1.10  | 93.184.216.34  | 54321  | 443      | TCP  | ESTABLISHED  |
| 192.168.1.20  | 8.8.8.8        | 12345  | 53       | UDP  | NEW          |

入站数据包 → 检查是否匹配已有连接 → 是 → 放行
                                      否 → 检查规则 → 拒绝/允许
应用层防火墙（Application Gateway）
工作在应用层（L7），能够理解和检查应用协议内容。

iptables / nftables
iptables 基础
iptables 是 Linux 最经典的防火墙工具，基于 Netfilter 框架。


# 允许已建立的连接
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 允许 SSH
iptables -A INPUT -p tcp --dport 22 -j ACCEPT

# 允许 HTTP/HTTPS
iptables -A INPUT -p tcp --dport 80 -j ACCEPT
iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# 允许本地回环
iptables -A INPUT -i lo -j ACCEPT

# 默认拒绝所有入站
iptables -P INPUT DROP

# 查看规则
iptables -L -n -v
nftables（iptables 的继任者）
nft add table inet filter
nft add chain inet filter input { type filter hook input priority 0 \; policy drop \; }
nft add rule inet filter input ct state established,related accept
nft add rule inet filter input tcp dport { 22, 80, 443 } accept
nft add rule inet filter input iif lo accept

WAF（Web 应用防火墙）
WAF 专门保护 Web 应用，工作在 HTTP 层，能识别和阻断 SQL 注入、XSS、CSRF 等攻击。


正常请求：
  GET /api/users?id=123 → WAF 放行 → 后端服务器

恶意请求：
  GET /api/users?id=1' OR '1'='1 → WAF 拦截（SQL 注入）
  POST /comment body="<script>alert('xss')</script>" → WAF 拦截（XSS）

纵深防御架构


小结
    

  • 防火墙按工作层级分为包过滤、状态、应用层三类，NGFW 提供全栈检测能力。
    • 

  • iptables/nftables 是 Linux 系统最常用的防火墙工具，基于规则链进行流量过滤。
    • 

  • IDS 被动检测并告警，IPS 主动阻断恶意流量，两者互补使用效果最佳。
    • 

  • WAF 专注于 Web 应用安全，防御 SQL 注入、XSS 等 OWASP Top 10 攻击。
    • 

  • 纵深防御（Defense in Depth）通过多层安全措施实现全面的网络保护。
