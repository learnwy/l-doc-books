交换与 VLAN

MAC 地址

MAC（Media Access Control）地址是数据链路层的物理地址，用于在同一局域网内唯一标识网络接口。

MAC 地址格式（48 位）：
AA:BB:CC:DD:EE:FF
│        │        │
└─ OUI ──┘  └─ 设备序号 ─┘
 （厂商标识）  （厂商分配）
地址类型 示例 用途
单播地址 00:1A:2B:3C:4D:5E 发往特定设备
广播地址 FF:FF:FF:FF:FF:FF 发往所有设备
组播地址 01:00:5E:xx:xx:xx 发往一组设备 
ip link show eth0
# eth0: <BROADCAST,MULTICAST,UP> mtu 1500 ...
#     link/ether 00:1a:2b:3c:4d:5e brd ff:ff:ff:ff:ff:ff

交换机工作原理

二层交换机基于 MAC 地址表（CAM 表）进行帧转发，核心操作包括学习、转发和过滤。

交换机三大行为

① 学习（Learn）
   收到帧 → 记录源 MAC + 入端口 → 写入 MAC 地址表

② 转发（Forward）
   查 MAC 地址表 → 找到目标端口 → 从该端口发出

③ 泛洪（Flood）
   MAC 地址表中无目标 MAC → 从除入端口外的所有端口发出

MAC 地址表示例

MAC 地址 端口 VLAN 类型 老化时间
00:1A:2B:3C:4D:5E Fa0/1 10 动态 280s
00:1A:2B:3C:4D:6F Fa0/2 10 动态 150s
00:1A:2B:3C:4D:7A Fa0/5 20 静态 —

VLAN（虚拟局域网）

VLAN 将一个物理交换机逻辑划分为多个独立的广播域，实现网络隔离和安全控制。

为什么需要 VLAN

没有 VLAN（单一广播域）：
┌─────────────────────────────────────┐
│  PC1  PC2  PC3  Server1  Printer1  │  ← 所有设备在同一广播域
│  广播风暴影响所有设备                │
└─────────────────────────────────────┘

使用 VLAN（多个广播域）：
┌─── VLAN 10（研发）───┐  ┌─── VLAN 20（财务）───┐
│  PC1  PC2  PC3       │  │  PC4  PC5  Server1  │
│  广播只在本VLAN内    │  │  广播只在本VLAN内    │
└──────────────────────┘  └──────────────────────┘

VLAN 类型

类型 划分依据 优点 缺点
基于端口 交换机端口号 简单直观 移动需重新配置
基于 MAC 设备 MAC 地址 设备移动灵活 配置复杂
基于协议 网络层协议类型 协议隔离 使用较少
基于策略 组合多种条件 灵活 管理复杂

Trunk 端口用于在交换机之间传输多个 VLAN 的流量。通过在帧中插入 VLAN 标签（802.1Q）来标识帧所属的 VLAN。

STP（生成树协议）
STP 用于消除二层网络中的环路，防止广播风暴。


广播风暴问题
STP 工作过程
1. 选举根桥（Root Bridge）     → Bridge ID 最小的交换机
2. 选举根端口（Root Port）     → 每个非根桥上到根桥代价最小的端口
3. 选举指定端口（Designated）  → 每条链路上代价最小的端口
4. 阻塞其余端口（Blocking）   → 其余端口进入阻塞状态，打破环路

VLAN 间路由
不同 VLAN 之间的通信需要三层设备（路由器或三层交换机）。


单臂路由
路由器（子接口）
  │  .1q Trunk
  │
交换机
├── VLAN 10 端口 → PC1 (10.1.10.10)
└── VLAN 20 端口 → PC2 (10.1.20.10)

路由器子接口配置：
  eth0.10 → 10.1.10.1/24 (VLAN 10 网关)
  eth0.20 → 10.1.20.1/24 (VLAN 20 网关)
三层交换机 SVI


小结
    

  • MAC 地址是二层的物理地址，交换机通过 MAC 地址表实现帧的精确转发。
    • 

  • VLAN 通过逻辑隔离广播域来增强网络的安全性和性能。
    • 

  • Trunk 链路使用 802.1Q 标签在交换机之间传输多 VLAN 流量。
    • 

  • STP/RSTP 通过阻塞冗余端口消除环路，RSTP 将收敛时间缩短到秒级。
    • 

  • VLAN 间通信需要三层路由，三层交换机 SVI 方式性能最优。
    •
