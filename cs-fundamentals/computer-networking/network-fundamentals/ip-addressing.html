IP 寻址

IP 地址概述

IP 地址是网络层的逻辑地址，用于在互联网中唯一标识一个网络接口。目前互联网并行使用 IPv4 和 IPv6 两种版本。

IPv4 地址

IPv4 使用 32 位地址，通常以点分十进制表示（如 192.168.1.1）。

地址分类

类别 首位模式 网络位 地址范围 用途
A 类 0 8 位 1.0.0.0 ~ 126.255.255.255 大型网络
B 类 10 16 位 128.0.0.0 ~ 191.255.255.255 中型网络
C 类 110 24 位 192.0.0.0 ~ 223.255.255.255 小型网络
D 类 1110 — 224.0.0.0 ~ 239.255.255.255 组播
E 类 1111 — 240.0.0.0 ~ 255.255.255.255 保留/实验

私有地址范围

类别 地址范围 CIDR 表示
A 类 10.0.0.0 ~ 10.255.255.255 10.0.0.0/8
B 类 172.16.0.0 ~ 172.31.255.255 172.16.0.0/12
C 类 192.168.0.0 ~ 192.168.255.255 192.168.0.0/16

子网划分

子网划分通过借用主机位来创建更多的子网。子网掩码用于区分网络部分和主机部分。

子网划分示例

将 192.168.1.0/24 划分为 4 个子网：

原始网络：192.168.1.0/24（256 个地址）
借用 2 位主机位 → /26（每个子网 64 个地址）

子网 1: 192.168.1.0/26    → 可用主机: .1 ~ .62    （广播: .63）
子网 2: 192.168.1.64/26   → 可用主机: .65 ~ .126  （广播: .127）
子网 3: 192.168.1.128/26  → 可用主机: .129 ~ .190 （广播: .191）
子网 4: 192.168.1.192/26  → 可用主机: .193 ~ .254 （广播: .255）

快速计算公式

项目 公式
子网数 2^借用位数
每子网主机数 2^剩余主机位 - 2
块大小 256 - 子网掩码最后一个非零八位组

CIDR（无类别域间路由）

CIDR 抛弃了传统的 A/B/C 类划分，使用前缀长度（/n）灵活标识网络范围。

传统分类：192.168.1.0  子网掩码 255.255.255.0
CIDR 表示：192.168.1.0/24

路由聚合示例：
  192.168.0.0/24  ┐
  192.168.1.0/24  ├──→ 聚合为 192.168.0.0/22
  192.168.2.0/24  │
  192.168.3.0/24  ┘

CIDR 的路由聚合（超网）能显著减少路由表条目，提升路由效率。

IPv6 地址

IPv6 使用 128 位地址，以冒号分隔的十六进制表示。

完整格式：2001:0db8:0000:0000:0000:0000:0000:0001
简化格式：2001:db8::1

IPv4 与 IPv6 对比

特性 IPv4 IPv6
地址长度 32 位 128 位
地址数量 ~43 亿 ~3.4×10^38
表示方式 点分十进制 冒号十六进制
地址配置 DHCP / 手动 SLAAC / DHCPv6
NAT 广泛使用 不需要（地址充足）
IPSec 可选 内置支持
广播 支持 用组播替代

NAT（网络地址转换）

NAT 将私有 IP 地址映射为公共 IP 地址，解决 IPv4 地址不足的问题。

内网主机                NAT 设备                  互联网
192.168.1.10:5000  →  203.0.113.1:40001  →  93.184.216.34:80
192.168.1.20:6000  →  203.0.113.1:40002  →  93.184.216.34:80
192.168.1.30:7000  →  203.0.113.1:40003  →  93.184.216.34:443
NAT 类型 描述 应用场景
静态 NAT 一对一固定映射 服务器对外发布
动态 NAT 从地址池动态分配公网 IP 企业出口
PAT/NAPT 多个私有 IP 共享一个公网 IP（端口区分） 家庭路由器

DHCP（动态主机配置协议）

DHCP 自动为网络中的设备分配 IP 地址及相关配置。

客户端                         DHCP 服务器
  │  ① DHCP Discover (广播)  →     │
  │  ← ② DHCP Offer              │
  │  ③ DHCP Request (广播)  →     │
  │  ← ④ DHCP ACK                │
  │                                │
  │  [获得 IP、网关、DNS 配置]      │

地址规划实践

企业网络地址规划示例：

总部网络：10.0.0.0/8

├── 核心网络    10.0.0.0/16
│   ├── 管理 VLAN   10.0.1.0/24
│   └── 服务器区    10.0.10.0/24
├── 办公区域    10.1.0.0/16
│   ├── 研发部      10.1.1.0/24
│   ├── 市场部      10.1.2.0/24
│   └── 财务部      10.1.3.0/24
└── 分支机构    10.10.0.0/16
    ├── 北京分部    10.10.1.0/24
    └── 上海分部    10.10.2.0/24

小结

  • IPv4 使用 32 位地址，通过子网划分和 CIDR 实现灵活的地址分配。
  • NAT 和 DHCP 是 IPv4 网络中不可或缺的技术，分别解决地址短缺和自动配置问题。
  • IPv6 提供近乎无限的地址空间，内置安全和自动配置能力，是未来的方向。
  • 合理的地址规划需要考虑业务划分、安全隔离和未来扩展。
