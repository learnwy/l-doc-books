网络基础 简介

网络基础是理解整个计算机网络体系的起点。这一章将从网络分层模型出发，建立对网络通信的系统性认知。

互联网的设计哲学建立在分层架构之上。OSI 七层模型提供了理论框架，TCP/IP 四层模型则是实际运行的标准。理解这两个模型的差异与联系，是掌握后续所有协议知识的前提。

在网络层与链路层，IP 地址体系定义了设备的逻辑标识和网段划分。IPv4 和 IPv6 的地址结构、子网掩码、CIDR 表示法是网络规划的基础工具。

路由与交换构成了网络数据转发的核心机制。交换机在二层基于 MAC 地址转发帧，路由器在三层基于 IP 地址转发包。VLAN 技术实现了逻辑隔离，OSPF 和 BGP 等路由协议驱动着从局域网到全球互联网的路由决策。

掌握网络调试工具是将理论知识转化为实践能力的关键。ping、traceroute、tcpdump、Wireshark 等工具让工程师能够在真实环境中观察网络行为、定位故障并验证配置。

本章内容：

  • OSI 与 TCP/IP 模型：分层架构的设计理念与对比
  • IP 地址与子网：IPv4/IPv6 地址体系与网络划分
  • 路由与交换：L2 交换、VLAN、路由协议（OSPF/BGP）
  • 网络调试工具：ping、traceroute、tcpdump、Wireshark 等实用工具
