路由协议

路由基础

路由是将数据包从源网络传递到目标网络的过程。路由器根据路由表中的信息做出转发决策，选择到达目标网络的最优路径。

主机 A                                              主机 B
10.1.1.10  →  [路由器 R1]  →  [路由器 R2]  →  [路由器 R3]  →  10.3.1.20
               查路由表         查路由表         查路由表
               逐跳转发         逐跳转发         逐跳转发

路由表结构

路由表是路由器进行转发决策的核心数据结构。

$ ip route show
default via 192.168.1.1 dev eth0
10.0.0.0/8 via 10.1.1.1 dev eth1
172.16.0.0/12 via 10.1.1.2 dev eth2
192.168.1.0/24 dev eth0 proto kernel scope link src 192.168.1.100
字段 含义 示例
目标网络 数据包要到达的网络 10.0.0.0/8
下一跳 转发给哪个路由器 via 10.1.1.1
出接口 从哪个接口发出 dev eth1
度量值 路径的优先级/代价 metric 100
协议来源 路由条目的学习方式 proto ospf

静态路由 vs 动态路由

特性 静态路由 动态路由
配置方式 管理员手动配置 路由协议自动学习
适用规模 小型网络 / 特定路径 中大型网络
收敛速度 无收敛概念 取决于协议（秒级到分钟级）
带宽消耗 不消耗 需要交换路由信息
容错能力 需手动调整 自动感知拓扑变化
CPU/内存 几乎不消耗 需要计算资源

静态路由配置示例：

ip route add 10.2.0.0/16 via 192.168.1.1
ip route add default via 192.168.1.1

动态路由协议分类



OSPF（开放最短路径优先）
OSPF 是最广泛使用的 IGP 协议，基于 Dijkstra 最短路径算法。


OSPF 工作流程
1. 邻居发现      →  Hello 报文（组播 224.0.0.5）
2. 数据库同步    →  交换 LSA（链路状态通告）
3. 路由计算      →  SPF 算法生成最短路径树
4. 路由安装      →  最优路径写入路由表

BGP（边界网关协议）
BGP 是互联网的核心路由协议，负责在自治系统（AS）之间交换路由信息。

小结
    

  • 路由是网络通信的核心机制，路由表决定了数据包的转发路径。
    • 

  • 静态路由适合小型或特定场景，动态路由协议适合中大型网络的自动化管理。
    • 

  • OSPF 是企业网络最常用的 IGP 协议，通过区域划分实现大规模网络的高效收敛。
    • 

  • BGP 是互联网的"胶水协议"，通过 AS Path 和多属性选路实现全球路由交换。
    • 

  • 路径选择不仅取决于距离，还涉及策略、带宽、可靠性等多维度考量。
