CDN 与边缘计算

CDN 概述

CDN（Content Delivery Network）是由分布在全球各地的边缘服务器组成的网络，将内容缓存到离用户最近的节点，减少网络延迟，提升访问速度和可用性。

CDN 缓存策略
缓存命中与回源
缓存命中率计算：命中率 = 缓存命中次数 / 总请求次数 × 100%


目标：命中率 > 95%


影响命中率的因素：


    

  • 缓存容量 → 越大命中率越高
    • 

  • TTL 设置 → 越长命中率越高（但内容新鲜度下降）
    • 

  • 内容热度 → 热门内容命中率高
    • 

  • 缓存键 → 合理的缓存键设计
    •

小结
    

  • CDN 通过将内容缓存到全球边缘节点，显著降低用户访问延迟和源站负载。
    • 

  • 多级缓存架构（边缘→中间层→源站）和合理的缓存策略是 CDN 性能的关键。
    • 

  • Anycast 技术使多个 CDN 节点共享同一 IP，BGP 路由自动将请求导向最近节点。
    • 

  • 边缘计算将计算能力下沉到网络边缘，满足低延迟和实时处理的需求。
    • 

  • 边缘函数（Edge Functions）使 CDN 从纯缓存演进为可编程的边缘计算平台。
    •
