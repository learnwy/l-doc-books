Mental Model 与 Affordance

核心概念

Mental model（心智模型）是用户对系统如何工作的内部表征——好 UX 让用户 mental model 与 system conceptual model 一致；mismatch 是 UX bug 主源。Affordance（提供性）是 Don Norman 1988 Design of Everyday Things 核心概念——物体暗示自身用法（门把手暗示 pull、按钮暗示 push、滑块暗示 slide）。Signifier 是 affordance 的可见信号（按钮的凸起、滑块的轨道）——没有 signifier 的 affordance 是 hidden affordance（用户找不到）。本节介绍 mental model 形成、conceptual model（设计师的 model）vs system image（实现）vs user's mental model 三层、affordance vs signifier、constraints / mappings / feedback 四原则、modern UI 应用。

概念 定义 例子
Conceptual model 设计者心中 system 应如何工作 Figma 的 layer 模型
System image UI 实际呈现 Figma sidebar
Mental model 用户对 system 的理解 用户认为的 layer
Affordance 物体暗示用法 按钮可 push
Signifier Affordance 的可见信号 按钮凸起 + 文字
Constraint 限制可能 action 颜色按钮中只一个亮
Mapping Control 与效果对应 灶头按钮位置匹配灶
Feedback Action 后的 system 反应 按钮点击有 visual

Don Norman 的 7 stage 模型

用户与 system 交互的 7 步：

  1. Goal（"我想 X"）。
  2. Plan（"做 A、B、C"）。
  3. Specify（具体动作 detail）。
  4. Execute（执行）。
  5. Perceive（看 system 反应）。
  6. Interpret（理解反应）。
  7. Compare（与 goal 对比）。

Two gulfs（两个沟）：

  • Gulf of execution：goal 到执行难（不知怎么做）。
  • Gulf of evaluation：执行到反馈难（不知 system 在做什么）。

好 UX 缩小两 gulf：

  • 缩小 execution gulf：affordance、signifier、mapping、constraint。
  • 缩小 evaluation gulf：feedback、status visibility、error message。
Mental Model 的形成
1. 经验：


    

  • 用过类似 product。
    • 

  • "iPhone 这样工作 → Android 也应该"。
    • 



2. 比喻：


    

  • "Folder" 是 file system 比喻。
    • 

  • "Trash" 是 delete 比喻。
    • 



3. 学习：


    

  • Tutorial、help docs。
    • 

  • 但用户极少读（"users don't read"）。
    • 



4. 试错：


    

  • 大多数学习是 try → see what happens → update。
    • 



Conceptual Model vs Mental Model
Conceptual model：


    

  • 设计者心中 system 应如何工作。
    • 

  • 如：Photoshop layer = 透明叠图。
    • 

  • 通常 simplify 实现 detail。
    • 



System image：


    

  • UI 实际呈现。
    • 

  • 用户能看到的 buttons、icons、labels。
    • 



Mental model：


    

  • 用户基于 system image 推断 conceptual model。
    • 

  • 不一定 match 设计者的 conceptual model。
    • 



好设计：


    

  • Conceptual model clear + appropriate。
    • 

  • System image 明确传达 conceptual model。
    • 

  • 用户 mental model match conceptual model。
    • 



反例：


    

  • 早期 Photoshop layer 概念让初学者困惑（mental model: 单图 → reality: 多 layer 叠加）。
    • 

  • iPhone 的 Home 按钮简单 conceptual model（"回主屏"）让 4 岁孩子能用。
    • 



Affordance
Don Norman 1988 定义：


    

  • 物体的 perceived 属性 + 实际属性，决定如何使用。
    • 

  • 椅子 affords sitting。
    • 

  • 门把手 affords pulling。
    • 



Digital affordance：


    

  • 按钮 affords clicking。
    • 

  • Scrollbar affords scrolling。
    • 

  • Hyperlink affords navigation。
    • 



Signifier（Norman 后来 distinguish）：


    

  • Affordance 的可见信号。
    • 

  • 按钮的凸起 + 文字 + color。
    • 

  • 没有 signifier → affordance hidden。
    • 



例：


    

  • iPhone Home button 凹陷 → press affordance。
    • 

  • iOS 新 swipe-up 取代 Home button → 没有可见 signifier → 用户需要学。
    • 



Signifier 设计原则
1. 清晰：


    

  • 用户一眼看出"可点 / 可拖 / 可滚动"。
    • 



2. 一致：


    

  • 整 product 中相同 affordance 用相同 signifier。
    • 



3. 文化适配：


    

  • ✓ 在西方 yes，亚洲也 yes。
    • 

  • ✗ 红色在西方 wrong / 中国 lucky。
    • 



4. Discoverability：


    

  • 用户能发现可用 actions。
    • 

  • 隐藏的功能 = 不存在的功能。
    • 



Constraints
Constraints 限制可能 actions——简化决策：


1. Physical constraint：


    

  • USB plug 形状只一种插法（实战常错）。
    • 

  • USB-C 是 reversible（improvement）。
    • 



2. Logical constraint：


    

  • 选 5 个的 list 限制 ≤ 5。
    • 

  • Form validation 防 invalid input。
    • 



3. Cultural constraint：


    

  • 红绿灯 red = stop。
    • 

  • 默认 LTR 语言。
    • 



4. Semantic constraint：


    

  • 上下文限定 meaning。
    • 

  • 例：cart icon 只在电商 context。
    • 



好设计用 constraint 排除 wrong action——让 user 只能做 right thing。


Mapping
Mapping：control 与 effect 的对应关系。


好 mapping：


    

  • 灶头 4 旋钮位置匹配 4 灶头位置。
    • 

  • iPhone 音量 button 上 = 大、下 = 小。
    • 

  • Map app pinch out = zoom in。
    • 



坏 mapping：


    

  • 早期车音响 EQ slider 顺序混乱。
    • 

  • Form 中 OK / Cancel 顺序不一致（Mac vs Windows）。
    • 



Natural mapping：基于人类直觉的 mapping。


    

  • Up = more, down = less。
    • 

  • Left = past, right = future。
    • 

  • 但有 cultural 例外（RTL 语言）。
    • 



Feedback
Feedback 让用户知道 action 后 system 状态：


1. Immediate visual：


    

  • Button hover / press 状态变化。
    • 

  • Form field focus highlight。
    • 



2. Audible：


    

  • iOS keyboard click。
    • 

  • macOS error sound。
    • 



3. Haptic：


    

  • iPhone vibration on action。
    • 

  • Apple Watch tap。
    • 



4. Status / progress：


    

  • Loading spinner。
    • 

  • Progress bar。
    • 

  • "Saving..." indicator。
    • 



5. Confirmation：


    

  • "Email sent!" toast。
    • 

  • Button changes to "Sent ✓"。
    • 



关键：缺乏 feedback 让用户重复点击 / 怀疑 / 放弃。


实战 case study
Case 1：iOS Mail 的 swipe：


    

  • Affordance：行的 partial swipe reveal action。
    • 

  • Signifier：swipe 时 actions slide in from right。
    • 

  • Constraint：只能左 swipe（cultural reading direction）。
    • 

  • Mapping：archive 在 swipe 远端、delete 在 farther（更危险）。
    • 

  • Feedback：swipe 触发 buttons appear，release 触发 action。
    • 



Case 2：Reddit 的 vote：


    

  • Affordance：上 / 下 arrow。
    • 

  • Signifier：可 click。
    • 

  • Mapping：上 = upvote = approve, 下 = downvote = disapprove（natural mapping）。
    • 

  • Constraint：只能 vote 一次。
    • 

  • Feedback：vote 后 arrow 变 color + count update。
    • 



Anti-patterns
1. Hidden affordance：


    

  • 没有 signifier。
    • 

  • 用户找不到。
    • 

  • 例：iOS swipe gesture 无 hint。
    • 



2. False affordance：


    

  • 看起来可 interact 但 not。
    • 

  • 例：disabled button 看起来 enable。
    • 



3. Bad mapping：


    

  • 旋钮位置不匹配 control object。
    • 



4. No feedback：


    

  • 点击 button 无反应。
    • 

  • 用户重复点。
    • 



5. Inconsistent：


    

  • 同 action 不同 location 不同 result。
    • 



文化与跨平台
Cultural mental model：


    

  • iPhone vs Android 用户期待不同。
    • 

  • Designed for Western 不一定适合 Asia。
    • 



Generation gap：


    

  • Older users mental model based on physical metaphor。
    • 

  • Younger users 接受 new abstraction 更快。
    • 



Cross-platform：


    

  • 同 product on iOS / Android 是否完全一致？
    • 

  • Apple HIG 与 Material Design 不同——native feel 更好。
    • 



验证 mental model
1. Card sort：


    

  • 让用户分类 concept。
    • 

  • 看用户 mental model 与 designer 是否 match。
    • 



2. Think aloud：


    

  • 用户做任务 + 说出想法。
    • 

  • 暴露 mental model gap。
    • 



3. Concept inventory：


    

  • "What is X in this app?"
    • 

  • 检查用户对核心 concept 的理解。
    • 



4. Tree test：


    

  • 给 navigation tree，让用户找东西。
    • 

  • 检测 IA 是否 match。
    • 



现代 challenge
1. AI / LLM：


    

  • 用户 mental model: "AI 是 search engine"。
    • 

  • Reality: AI hallucination。
    • 

  • Mental model gap → 用户错信。
    • 



2. Spatial computing：


    

  • 没有 keyboard / mouse 物理 metaphor。
    • 

  • 新 mental model 需建立。
    • 



3. Voice：


    

  • 用户期待 conversational AI 像人。
    • 

  • Reality: limited capability。
    • 



4. Privacy：


    

  • Cookie banner、GDPR consent。
    • 

  • 用户 mental model "this is just clutter" → 都 click accept。
    • 



小结
Mental model 是用户对 system 如何工作的内部表征——好 UX 让 mental model 与 conceptual model 一致。Don Norman 7-stage 模型——goal → plan → specify → execute → perceive → interpret → compare，two gulfs（execution 不知怎么做、evaluation 不知 system 反应）。Conceptual model（设计者）vs system image（UI 呈现）vs mental model（用户推断）三层。Affordance（物体暗示用法）+ signifier（可见信号）—— hidden affordance = 用户找不到。设计原则——清晰、一致、文化适配、discoverable。Constraint（physical / logical / cultural / semantic）排除 wrong action。Mapping（control-effect 对应）—— natural mapping（up=more 等）。Feedback（visual / audible / haptic / status / confirmation）让用户知道 system 状态。Case study——iOS Mail swipe + Reddit vote 展示 affordance + signifier + mapping + constraint + feedback 综合应用。Anti-patterns——hidden affordance、false affordance、bad mapping、no feedback、inconsistent。文化与跨平台 mental model 不同——iOS vs Android、Western vs Asia、generation gap。验证 mental model——card sort、think aloud、concept inventory、tree test。现代挑战——AI 让用户 expect "search engine" 但 hallucinate、spatial computing 没物理 metaphor、voice 期待对话、privacy banner 让用户都 accept。一个简单的检验：你能识别一个 product 的 hidden affordance？如果不能，affordance vs signifier 的区别还需巩固。Mental model 与 affordance 是 HCI 的"概念基石"——理解它们让 design 决策从"我觉得好看"上升到"用户能够理解"。
