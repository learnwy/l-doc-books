Fitts's Law 与输入

核心概念

Fitts's Law（1954）是 HCI 最基础的定量规律——选目标的时间 T = a + b · log₂(D/W + 1)，其中 D 是从起点到目标的距离、W 是目标宽度（沿运动方向）。即距离越远 / 目标越小越慢。这是 iPhone Home button 放屏幕底部中央（thumb-reachable）、Windows taskbar 在屏幕边缘（infinite W in screen-edge direction）、Mac menu bar 在屏幕顶端的科学依据。Hick's Law（选项越多决策越慢）+ Steering Law（穿过 tunnel 的时间）是相关 input theory。本节给出 Fitts's Law 数学、设计应用、不同输入设备（mouse、touch、stylus、eye、voice）特点。

输入 速度 精度 适用
Mouse 中 高（pixel） Desktop primary
Touch 快 低（44pt） Mobile primary
Stylus 慢 极高 Drawing / writing
Keyboard 极快（typing） 文本 input Power user
Voice 慢（latency） 中 Hands-free
Eye gaze 极快 低 Vision Pro
Gesture 中 低 AR / VR / Tesla

Fitts's Law 数学

T = a + b · log₂(D/W + 1)
  • T：执行时间（秒）。
  • D：距离（pixel）。
  • W：目标宽度（pixel along movement direction）。
  • a, b：empirical 参数（设备 + 用户）。

关键 insight：

  • 对数关系——distance 加倍只增加 log₂(2)/log₂(D) ~ 1/log 时间。
  • W 与 D 同等重要——大目标 + 短距离最快。

ID（Index of Difficulty）：log₂(D/W + 1)。

屏幕边缘的特殊性

Edge effect：

  • Mouse 移到屏幕 edge 时被 OS clamp。
  • Edge 的 effective W = ∞（不会"过冲"）。
  • 因此 menu bar / taskbar 在 edge 极快 access。

Mac vs Windows：

  • Mac menu bar 在 screen top edge：W = ∞。
  • Windows menu bar 在 window 内部 top：W = pixel-bounded。
  • 实测 Mac menu access 比 Windows 快 ~ 30%。

Pie menu vs linear menu

Pie menu（圆形）：

  • 8 项围绕鼠标点。
  • 每项距离相等（短）。
  • W 角度大。
  • T 极短。

Linear menu：

  • 项 list down。
  • D 不一致。
  • W small (item height)。

Pie menu 实战快 ~ 15-50%——但不流行（visual unfamiliar）。

Thumb Zone（手机）

Steven Hoober 2013 研究 mobile thumb reach：

  • Easy thumb reach：屏幕下 1/3 + 中间。
  • Hard reach：屏幕上角（特别 large phone）。
  • Stretchy reach：用户调整握持 reach 上部。

iPhone Pro Max 6.7" 的 challenge：

  • Top corner 远超 thumb reach。
  • Apple 2024 Reachability gesture（swipe down）暂时 lower screen。

Design 应用：

  • 主操作放 thumb zone（底部中央）。
  • 危险操作（delete）放 hard reach（防误触）。
  • iOS 的 tab bar 在底部、Android 的 bottom navigation。
Hick's Law
T = a + b · log₂(N + 1)
    

  • T：决策时间。
    • 

  • N：选项数。
    • 

  • a, b：empirical。
    • 



意义：


    

  • 选项越多决策越慢（log）。
    • 

  • 但 information 也增多。
    • 

  • Trade-off 关键。
    • 



实战：


    

  • Menu 项数 7±2 是 sweet spot（短期记忆）。
    • 

  • Group items into categories（reduce effective N）。
    • 

  • Show recent / favorite first。
    • 



Power user vs novice：


    

  • Novice：Hick's Law 起作用，选项少快。
    • 

  • Power user：muscle memory，选项多 OK（Vim、Photoshop）。
    • 



Steering Law
Steering Law：穿过 tunnel 的时间。


T = a + b · D/W
    

  • D：tunnel 长。
    • 

  • W：tunnel 宽。
    • 



线性关系（vs Fitts 的 log）。


实战：


    

  • Hierarchical menu（穿过 submenu corridor）—— wide corridor 快。
    • 

  • Slider（穿过滑轨）。
    • 

  • 防 user accidentally 离开 menu corridor。
    • 



Mac 多级 menu 的 trick：


    

  • 用 trapezoidal "cone" 检测——angle of mouse movement 决定是 navigate 还是 leave。
    • 

  • 让 user 沿 diagonal path move 不会 accidentally 关 menu。
    • 



输入设备对比
Mouse：


    

  • 高精度（1 pixel）。
    • 

  • 间接（移到 cursor 然后 cursor 移到 target）。
    • 

  • Desktop 主流。
    • 



Touch：


    

  • 直接（手指即 cursor）。
    • 

  • 低精度（finger ~ 44pt = 8mm）。
    • 

  • Hover 不存在（vs mouse 有 hover state）。
    • 

  • 设计：button 至少 44×44 pt（Apple HIG）。
    • 



Stylus：


    

  • 直接 + 高精度。
    • 

  • 适合 drawing、writing、annotation。
    • 

  • iPad + Apple Pencil、Surface + Surface Pen。
    • 



Keyboard：


    

  • 文本 input 极快（80+ WPM trained）。
    • 

  • Shortcut（Cmd+S）power user 极快。
    • 

  • 不适 spatial selection。
    • 



Voice：


    

  • 慢（说话 + 系统 latency）。
    • 

  • Hands-free（开车、做饭）适合。
    • 

  • LLM 让 voice 更自然。
    • 



Eye gaze：


    

  • 极快移到 target。
    • 

  • 低精度（gaze jitter）。
    • 

  • Vision Pro 用 eye + pinch combination。
    • 



Gesture：


    

  • 中速 + 低精度。
    • 

  • 没有 button affordance。
    • 

  • 学习成本高。
    • 



Multimodal
Combine modality：


    

  • iPhone：touch + voice + face ID。
    • 

  • Vision Pro：eye + pinch（fastest selection method known）。
    • 

  • Tesla：voice + touch + steering wheel button。
    • 



Augmentation：


    

  • Voice + visual confirmation。
    • 

  • Gesture + haptic feedback。
    • 



Touch target 大小
Apple HIG：min 44×44 pt。


Material Design：min 48×48 dp（小 padding 不算）。


WCAG 2.2：min 24×24 px (level AA)。


实战：


    

  • Action button：44×44 minimum。
    • 

  • Spacing between targets：8 pt minimum。
    • 

  • Edge of screen：affordance with 8-12 pt margin。
    • 



快捷键 vs Touch
Power user 快捷键：


    

  • 7-30 倍快于 touch / mouse for repetitive task。
    • 

  • Cmd+C/V、Vim hjkl、Photoshop 工具切换。
    • 



但 discoverability 差：


    

  • Hidden 直到学。
    • 

  • 需要 onboarding / hint。
    • 



Hybrid：


    

  • Beginner 用 mouse / touch。
    • 

  • Power user 用 keyboard。
    • 

  • UI 显示快捷键 hint（macOS menu shows Cmd+C）。
    • 



实战设计 checklist
    

  •  主 action 在 thumb zone（mobile）/ near current cursor（desktop）。
    • 

  •  Touch target ≥ 44×44 pt。
    • 

  •  用 screen edge 给关键 navigation。
    • 

  •  Menu / list items ≤ 7±2（用 grouping if more）。
    • 

  •  Long-press、swipe、pinch 等复杂 gesture 有 fallback button。
    • 

  •  Keyboard shortcut for power user。
    • 

  •  Hover state（desktop only） vs press state（touch）。
    • 



Voice 的 Fitts equivalent
Voice 没有 spatial Fitts，但有自己的 cost：


Latency：


    

  • 听 wake word + process + response。
    • 

  • 总 ~ 1-3 seconds。
    • 

  • Touch < 0.5 second。
    • 



误识：


    

  • ASR error rate ~ 5-10%（depending on accent）。
    • 

  • 错 correction expensive。
    • 



因此 voice 适合：


    

  • Hands-busy（开车、做饭）。
    • 

  • Long input（说"set alarm for 7am" vs 5 taps）。
    • 

  • 不适合 quick selection。
    • 



实战 trade-off
Fitts vs aesthetic：


    

  • 大 button 占地方但 fast。
    • 

  • 小 button 美但 slow。
    • 

  • Spotify play button 大（核心 action）vs settings small。
    • 



Fitts vs density：


    

  • 大 button 减少 information density。
    • 

  • 平衡 frequent action 大 + rare action 小。
    • 



Edge vs accidental：


    

  • Screen edge fast access 但 mobile 容易误触（thumb 滑出 screen）。
    • 

  • iPhone gesture 边缘需特定 swipe pattern 防误触。
    • 



小结
Fitts's Law T = a + b · log₂(D/W + 1) 选目标时间——距离越远 / 目标越小越慢，对数关系。屏幕边缘 W = ∞ 让 menu bar / taskbar 极快。Pie menu 等距离让 access 比 linear menu 快 15-50%（但 unfamiliar）。Mobile thumb zone（Hoober 2013）—— easy bottom center、hard top corner、stretchy top center。iPhone Pro Max Reachability gesture 解决 large phone 问题。Hick's Law T = a + b · log₂(N+1) 决策时间——选项 7±2 sweet spot，Steering Law T = a + b · D/W 穿 tunnel 时间（线性）。输入设备——mouse 高精度间接、touch 直接低精度（44pt）、stylus 高精度 drawing、keyboard 极快 typing + shortcut、voice 慢 hands-free、eye gaze 极快低精度 (Vision Pro)、gesture 中速学习成本高。Multimodal（eye+pinch、voice+visual）综合优势。Touch target Apple 44×44, Material 48×48, WCAG 24×24。快捷键 7-30x 快但 discoverability 差，hybrid（beginner mouse, power keyboard）。Voice 自己 cost——latency 1-3s, ASR error 5-10%。设计 trade-off——Fitts vs aesthetic vs density vs edge accidental。一个简单的检验：你能解释为什么 "Mac menu bar 比 Windows menu 快"？如果不能，screen edge 的 Fitts 应用还需巩固。Fitts's Law + 输入设备特点是 UI 设计的"物理学"——让设计决策可量化，不是 subjective preference。
