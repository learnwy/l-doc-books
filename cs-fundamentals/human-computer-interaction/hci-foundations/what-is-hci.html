Part VI · 工程与交互 (Engineering & Interfaces)人机交互HCI 基础什么是 HCI

什么是 HCI

核心概念

人机交互（Human-Computer Interaction，HCI）是研究人与计算机如何 interact 的多学科领域——交叉 computer science、psychology、design、anthropology、ergonomics。它的目标不是让 UI"漂亮"，而是让软件 effective（用户能完成任务）、efficient（不浪费时间）、satisfying（用户感觉好）。从 1980 Star Xerox 第一个 GUI、1984 Macintosh 把 GUI 带给消费者、2007 iPhone 把 multitouch 带入主流，到 2024 Vision Pro 把 spatial computing 带入消费——每个 paradigm shift 背后都是 HCI 研究先驱。本节介绍 HCI 历史、范围、与 UX / UI / Service Design 的区别、研究方法论、为什么所有软件工程师都应了解。

学科 关注 与 HCI 关系
Computer Science 实现技术（algorithm, system） 提供基础设施
Psychology 人类认知 / 感知 / motor control 提供"人"理论
Design 美学、形式 提供 craft
Anthropology 文化 / 社会因素 提供 context
Ergonomics 物理 / 生理界面 提供 hardware
HCI 这些的整合 → interactive system 综合学科

HCI 历史 milestones

1945 Memex（Vannevar Bush）：

  • 假想的 "personal information system"。
  • 启发后续 hyperlink、Web。

1963 Sketchpad（Ivan Sutherland）：

  • 第一个 interactive graphical system。
  • 鼠标、icon、direct manipulation 雏形。
  • 启发 GUI。

1968 "Mother of All Demos"（Doug Engelbart）：

  • 演示鼠标、hypertext、video conferencing、collaborative editing。
  • 30 年后才成为主流。

1973 Xerox Alto：

  • 第一个 personal computer with GUI。
  • WYSIWYG、Ethernet、mouse。

1984 Macintosh：

  • GUI 进入消费市场。
  • "Computer for the rest of us"。

1990 Tim Berners-Lee Web：

  • HTTP + HTML + URL。
  • HCI 进入 networked era。

2007 iPhone：

  • Multitouch + capacitive screen。
  • Mobile-first paradigm。

2014 Oculus Rift / 2024 Vision Pro：

  • Spatial computing。
  • AR/VR 进入主流。

2022 ChatGPT：

  • Conversational AI 进入主流。
  • Natural language UI。
HCI vs UX vs UI vs Service Design
HCI：


    

  • 学术 / research-oriented。
    • 

  • 理论 + 方法论。
    • 

  • 学者 + 研究员。
    • 



UX（User Experience）：


    

  • Industry / product-oriented。
    • 

  • 整体用户体验（不仅 UI）。
    • 

  • 包括 information architecture、interaction、visual。
    • 



UI（User Interface）：


    

  • 视觉 + interaction layer。
    • 

  • 是 UX 的一部分。
    • 



Service Design：


    

  • 多 touchpoint 整体（在线 + 线下）。
    • 

  • 例：医院全流程（挂号、看诊、取药）。
    • 



Design Engineering：


    

  • UX + 技术实现 cross。
    • 

  • Code 化的 designer。
    • 



Product Design：


    

  • UX + product strategy。
    • 

  • Holistic role。
    • 



HCI 研究方法
1. Quantitative：


    

  • A/B testing。
    • 

  • Eye tracking。
    • 

  • 性能 metrics（time to task, error rate）。
    • 

  • Survey 大规模。
    • 



2. Qualitative：


    

  • User interview。
    • 

  • Ethnography。
    • 

  • Diary study。
    • 

  • Card sort。
    • 

  • Think aloud。
    • 



3. Mixed methods：


    

  • 实战通常 combine。
    • 

  • Quantitative 给 what + how much；qualitative 给 why。
    • 



4. Lab vs field：


    

  • Lab：受控环境，可比性高。
    • 

  • Field：真实环境，ecological validity 高。
    • 



为什么工程师应了解 HCI
1. UI bug = product bug：


    

  • "It works on my machine"——工程师 demo 用，与真用户 use 不同。
    • 

  • HCI 让你 anticipate 真实使用情况。
    • 



2. 大量 product 失败因 UX：


    

  • 技术上完美但用户 confused → 产品失败。
    • 

  • 例：Google Wave 2009、Microsoft Bob 1995。
    • 



3. Engineering 与 design 协作：


    

  • 用 HCI 语言讨论 design 决策。
    • 

  • 避免 "designer says X, engineer says Y" 内耗。
    • 



4. AI / LLM era：


    

  • Prompt engineering 是 conversation design。
    • 

  • 工程师必须懂 conversation flow。
    • 



5. 公正与责任：


    

  • Algorithmic decision 影响人类。
    • 

  • 工程师责任理解 user impact。
    • 



HCI 的核心 insight
1. Users 不是工程师：


    

  • 用户 mental model 与 system architecture 不同。
    • 

  • 不会"按手册"操作——会试错、放弃、找 workaround。
    • 



2. Users 不读：


    

  • 不读 instruction、tooltip、warning。
    • 

  • UI 必须 self-evident。
    • 



3. Users 是 satisficer：


    

  • 找"够好"的 solution，不是 optimal。
    • 

  • 第一个 working option 就用。
    • 



4. Users 学习 by doing：


    

  • 不读手册先试。
    • 

  • UI 必须 forgiving、support undo。
    • 



5. Context matters：


    

  • 同 UI 在不同 context（手机 vs 桌面、噪音 vs 安静）效果不同。
    • 



经典 HCI 研究
1. Don Norman Design of Everyday Things（1988）：


    

  • Affordance、signifier、feedback、constraint、mapping。
    • 

  • Why doors are confusing。
    • 

  • HCI 工程师必读。
    • 



2. Nielsen 10 Heuristics：


    

  • Visibility of system status。
    • 

  • Match between system and real world。
    • 

  • User control and freedom。
    • 

  • Consistency。
    • 

  • Error prevention。
    • 

  • Recognition rather than recall。
    • 

  • Flexibility and efficiency。
    • 

  • Aesthetic and minimalist design。
    • 

  • Error recovery。
    • 

  • Help and documentation。
    • 



3. Tog's Principles（Bruce Tognazzini）：


    

  • Anticipation、autonomy、color blindness、consistency、defaults、efficiency。
    • 



4. Apple HIG / Google Material Design / Microsoft Fluent：


    

  • Industry-standard design system guidelines。
    • 



HCI 在工业的角色
Tech companies：


    

  • Google：UX research department 1000+ people。
    • 

  • Apple：Design 是 core competency。
    • 

  • Microsoft：Inclusive Design Toolkit。
    • 

  • Facebook（Meta）：UX research at Oculus / Reality Labs。
    • 



Career paths：


    

  • UX Researcher：mixed methods user research。
    • 

  • UX Designer：interaction + visual design。
    • 

  • UX Engineer / Design Engineer：code + design hybrid。
    • 

  • Product Designer：design + product strategy。
    • 

  • Service Designer：multi-touchpoint。
    • 



关键 trade-off
Power vs simplicity：


    

  • 更多功能 → 更复杂 UI。
    • 

  • 例：Photoshop（power）vs Notes（simplicity）。
    • 



Consistency vs context：


    

  • 每场景最优 UI 可能不一致。
    • 

  • 一致性帮 transfer learning，但有时需 break。
    • 



Accessibility vs aesthetics：


    

  • 高对比 / 大字体让一些 design 受限。
    • 

  • 实战可两者兼顾（Apple 是 example）。
    • 



Speed vs error prevention：


    

  • 快 UX（如 Vim）需 expert，error 多。
    • 

  • 慢 UX（如 confirmation dialog）error 少但 slow。
    • 



现代 HCI 挑战
1. Voice + LLM：


    

  • ChatGPT 让 conversational 主流。
    • 

  • New design language。
    • 



2. Spatial computing：


    

  • AR/VR 让 3D + body-aware。
    • 

  • Vision Pro 给 baseline。
    • 



3. AI 辅助 design：


    

  • Figma AI、generative tools。
    • 

  • 设计师 role 变。
    • 



4. Inclusive / accessibility：


    

  • 法律 mandate（ADA、EAA）。
    • 

  • 1B+ disabled users。
    • 



5. Privacy / dark patterns：


    

  • Cookie banner 烦扰。
    • 

  • Dark pattern（misleading UI）法律打击。
    • 



6. Globalization：


    

  • LTR vs RTL（Arabic、Hebrew）。
    • 

  • 多语言、多文化。
    • 



实战 advice
1. Start with users：


    

  • 不是技术、不是商业——是 user need。
    • 



2. 早 prototype 早 test：


    

  • Low-fi prototype 快 + 便宜 + iterate。
    • 

  • 找 5 个用户即发现 80% problem。
    • 



3. Iterate：


    

  • 第一版总是 wrong。
    • 

  • Test → fix → test。
    • 



4. 用 metrics + qualitative：


    

  • 数据告诉 what, 用户告诉 why。
    • 



5. 与 designer 协作：


    

  • 不是"engineer implement designer's idea"。
    • 

  • 早 collaborate from concept。
    • 



小结
HCI 是研究人与计算机交互的多学科领域——交叉 CS、psychology、design、anthropology、ergonomics——目标让 software effective + efficient + satisfying。历史 milestones——1963 Sketchpad、1973 Xerox Alto、1984 Mac、1990 Web、2007 iPhone、2014 Oculus、2022 ChatGPT、2024 Vision Pro。HCI（学术）vs UX（industry 整体体验）vs UI（视觉）vs Service Design（多 touchpoint）vs Design Engineering（code+design）vs Product Design（design+strategy）。研究方法 quantitative（A/B、eye tracking、metrics）+ qualitative（interview、ethnography、diary、card sort）+ mixed，lab vs field。工程师应了解 HCI 因为——UI bug = product bug、产品失败常因 UX、与 designer 协作语言、AI/LLM era prompt 是 conversation design、algorithmic 责任。核心 insight——users 不是工程师、users 不读、users 是 satisficer、users 学习 by doing、context matters。经典——Don Norman Design of Everyday Things（affordance）、Nielsen 10 heuristics、Tog principles、Apple HIG / Material / Fluent。Career paths——UX researcher / designer / engineer / product designer / service designer。Trade-offs——power vs simplicity、consistency vs context、a11y vs aesthetics、speed vs error prevention。现代挑战——voice + LLM、spatial computing、AI 辅助、inclusive、privacy / dark pattern、globalization。实战 advice——start with users、早 prototype、iterate、metrics + qualitative、与 designer collaborate。一个简单的检验：你能解释 HCI 与 UI 的区别？如果不能，concept 边界还需巩固。HCI 是软件工程师的"另一半"知识——只懂 algorithm 不懂 user 让你写出技术上 elegant 但实战 unusable 的产品。
