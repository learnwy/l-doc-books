HCI 基础

HCI 的"概念奠基"——任何 UI 决策都应基于人类认知与感知的科学规律。本章覆盖 4 个核心理论：mental model（用户对系统如何工作的内部表征——好的设计让用户 mental model 与系统 conceptual model 一致）、affordance（物体暗示自身用法——门把手暗示 pull、按钮暗示 push）、Fitts's Law（选目标时间 = a + b log₂(D/W + 1)，距离越远 / 目标越小越慢——iPhone 屏幕底部主操作位置的科学依据）、cognitive load（人类工作记忆 7±2 chunk，过载导致 error / abandonment——决定信息架构与 progressive disclosure 设计）。学完本章你能解释为什么 iPhone Home 键放中间下方（thumb reach + Fitts）、为什么 Google search 仅一个 input 框（cognitive load 最小）、为什么物理按键比 touch screen 快（haptic affordance）、设计时如何用 Fitts 与 cognitive load 量化决策。这些是后续 design principles、patterns、accessibility 的基础。
