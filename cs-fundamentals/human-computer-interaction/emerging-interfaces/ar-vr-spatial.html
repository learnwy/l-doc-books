AR/VR 与空间计算

核心概念

AR（增强现实）让数字内容叠加在真实世界上（Pokemon Go、Apple Vision Pro 透视模式）；VR（虚拟现实）完全沉浸于数字环境（Meta Quest、PSVR2）；MR（混合现实）介于两者之间（Vision Pro 空间计算）。这些空间界面让 3D 内容 + 身体运动 + 眼动追踪成为输入方式，从根本上改变了设计范式——从 2D 屏幕到 3D 空间、从光标到注视 + 手势、从被动观看到主动探索环境。Apple Vision Pro 2024 年将空间计算带入主流，但晕动症、电池续航、重量、社会接受度仍是大规模普及的障碍。本节给出 AR/VR 设计原则、Vision Pro 范式、晕动症缓解、空间音频、与图形界面的差异。

维度 图形界面 AR/VR
显示 平面 2D 3D 空间
输入 鼠标/触控 注视 + 手势 + 语音
运动 固定视角 用户头部移动
音频 立体声 空间 3D 音频
舒适度 长时使用无碍 30 分钟 - 数小时
社交 正常 "看起来怪"

AR vs VR vs MR

VR（完全沉浸）：

  • 全数字环境。
  • 用户与物理世界隔绝。
  • Quest 3、PSVR2、Vive。
  • 应用场景：游戏、培训、治疗。

AR（叠加现实）：

  • 数字内容 + 真实世界。
  • 用户仍在物理环境中。
  • Pokemon Go（手机）、Snapchat 滤镜、Magic Leap。
  • 应用场景：导航、购物、虚拟试穿。

MR（混合）：

  • AR + VR 无缝融合。
  • 物体正确遮挡（数字物体被物理物体遮挡）。
  • Apple Vision Pro、HoloLens。

Apple 的术语"空间计算"：

  • 模糊 AR/VR/MR 边界。
  • 强调空间输入和空间内容。

Vision Pro 范式（2024）

输入方式：

  • 眼动注视：看向目标。
  • 捏合：手指捏合为"点击"。
  • 语音：听写 + Siri。
  • 没有控制器（对比 Quest）。

输出：

  • 每眼 4K micro-OLED。
  • 视频透视（非光学透视）。
  • 空间音频。

窗口范式：

  • 应用窗口漂浮在 3D 空间。
  • 用户自由排列。
  • 无限显示器。

数字化身：

  • 面部捕捉用于视频通话。
  • 让对方看到你的面部。

问题：

  • 重约 600 克。
  • 1 小时电池。
  • 3500 美元价格。
  • 2024 年仍是小众，未来会主流。

晕动症

成因：

  • 视觉与前庭（内耳平衡）感知冲突。
  • 看到运动但身体静止。
  • 约 25% 用户在 VR 中会晕动。

缓解措施：

1. 帧率：

  • 最低 90 Hz。
  • 120 Hz 更佳。
  • 低于 90 Hz 容易致晕。

2. 延迟：

  • 头部运动到画面更新 < 20 毫秒。
  • 超过 20 毫秒 → 不匹配 → 晕。

3. 不强迫移动：

  • 使用瞬移而非平滑移动。
  • 让用户掌控。

4. 静态参照物：

  • 驾驶座舱、网格。
  • 减少视觉自运动感。

5. 视野缩减：

  • 移动时减少周边视野。
  • 减少自运动感。

6. 短时使用：

  • 初期 15-30 分钟。
  • 逐渐建立耐受。

设计原则：舒适度 > 视觉保真度。

空间音频
3D 音频线索：


    

  • 声音来自特定方向。
    • 

  • HRTF（头相关传递函数）。
    • 

  • 让用户不看就知道方向。
    • 



应用：


    

  • VR 游戏：脚步声方向。
    • 

  • AR 导航：声音指示方向。
    • 

  • Vision Pro 空间音频。
    • 



实战建议：


    

  • 不要只依赖视觉线索。
    • 

  • 音频 + 视觉互相增强。
    • 



空间界面设计
1. 距离：


    

  • 手臂可达距离（30-50 厘米）vs 观看距离（1-3 米）vs 远处（背景）。
    • 

  • 交互界面放在手臂可达处。
    • 

  • 内容浏览放在观看距离。
    • 



2. 眼睛舒适度：


    

  • 界面不放太近（眼疲劳）。
    • 

  • 不放在视野边缘（眼球紧张）。
    • 

  • "舒适区"在用户正前方 1-3 米。
    • 



3. 浮动窗口：


    

  • 3D 空间中的窗口。
    • 

  • 用户自由排列。
    • 

  • 但太多会杂乱。
    • 



4. 世界锁定 vs 头部锁定：


    

  • 世界锁定：窗口在空间中固定（用户转头不跟动）。
    • 

  • 头部锁定：跟随头部移动（类似抬头显示）。
    • 

  • 世界锁定更自然适合内容。
    • 



5. 手部呈现：


    

  • 显示用户的手。
    • 

  • 让空间操作感觉自然。
    • 



眼动追踪
Vision Pro：


    

  • 眼动注视作为光标。
    • 

  • 看 + 捏合 = 点击。
    • 

  • 极快的选择速度（对比手指指向）。
    • 



优势：


    

  • 费茨定律效率极高。
    • 

  • 解放双手。
    • 



挑战：


    

  • 每位用户需校准。
    • 

  • 隐私（注视数据敏感）。
    • 

  • 眼疲劳。
    • 



设计建议：


    

  • 用于选择而非文字输入（注视不适合打字）。
    • 

  • 结合捏合确认。
    • 

  • 不要让用户长时间盯着某处（不舒适）。
    • 



手部追踪与手势
Quest 3、Vision Pro 都有手部追踪。


常见手势：


    

  • 捏合（拇指 + 食指）：选择/拖拽。
    • 

  • 张开手掌：取消。
    • 

  • 指向：射线投射。
    • 

  • 双手：缩放、旋转。
    • 



挑战：


    

  • 没有触觉反馈。
    • 

  • 手臂抬几分钟就累。
    • 

  • 手被遮挡时误检测。
    • 



设计建议：


    

  • 限制手势词汇（5-7 个）。
    • 

  • 视觉 + 音频确认。
    • 

  • 提供按钮/语音回退方案。
    • 



数字化身/虚拟形象
社交 VR：


    

  • 数字化身代表用户。
    • 

  • 肢体语言重要。
    • 



Vision Pro 虚拟形象：


    

  • 捕捉用户面部。
    • 

  • 用于 FaceTime 通话。
    • 

  • "逼真"但有恐怖谷效应。
    • 



化身自定义：


    

  • 自我表达。
    • 

  • 但匿名也有价值。
    • 



AR 应用场景
1. 导航：


    

  • AR 在真实道路上叠加方向指示。
    • 

  • Google 地图实景模式。
    • 



2. 购物：


    

  • 虚拟试穿（Snapchat AR、Warby Parker）。
    • 

  • 家具摆放预览（宜家 IKEA Place）。
    • 



3. 游戏：


    

  • Pokemon Go。
    • 

  • AR 寻宝。
    • 



4. 教育：


    

  • 3D 人体解剖（医学院）。
    • 

  • 历史遗址叠加信息。
    • 



5. 工业：


    

  • HoloLens 工厂培训。
    • 

  • 维修指令叠加。
    • 



VR 应用场景
1. 游戏：


    

  • Half-Life: Alyx。
    • 

  • Beat Saber。
    • 



2. 培训：


    

  • 手术模拟。
    • 

  • 飞行员训练。
    • 

  • 软技能（演讲训练）。
    • 



3. 治疗：


    

  • PTSD 暴露治疗。
    • 

  • 恐惧症治疗。
    • 



4. 远程办公：


    

  • 虚拟办公室。
    • 

  • 空间会议。
    • 



5. 娱乐：


    

  • VR 电影。
    • 

  • 虚拟演唱会/体验。
    • 



局限
硬件：


    

  • 重且佩戴累。
    • 

  • 电池 1-2 小时。
    • 

  • 价格高（Quest 3 500 美元、Vision Pro 3500 美元）。
    • 



内容：


    

  • 高品质游戏少。
    • 

  • 生产力内容有限。
    • 



社交：


    

  • 戴头显看起来奇怪。
    • 

  • 与周围隔绝（VR）。
    • 



健康：


    

  • 眼疲劳。
    • 

  • 晕动症。
    • 

  • 长期影响未知。
    • 



与移动端/桌面端对比
移动端：


    

  • 任意地点使用。
    • 

  • 口袋大小。
    • 

  • 触控 + 语音。
    • 



桌面端：


    

  • 生产力强。
    • 

  • 多显示器。
    • 

  • 键盘 + 鼠标。
    • 



AR/VR：


    

  • 空间感 + 沉浸感。
    • 

  • 新范式。
    • 

  • 但应用场景有限（尚不能每日佩戴）。
    • 



现代工具
Unity/Unreal：


    

  • VR/AR 引擎。
    • 

  • 偏游戏。
    • 



RealityKit/ARKit/visionOS：


    

  • Apple 生态。
    • 



ARCore/Android XR：


    

  • Google 生态。
    • 



WebXR：


    

  • 基于浏览器的 VR/AR。
    • 

  • 跨平台。
    • 



反模式
1. 直接移植 2D 界面：


    

  • 把网页应用直接放到 3D 空间。
    • 

  • 没有利用空间特性。
    • 

  • Vision Pro 早期应用的通病。
    • 



2. 默认平滑移动：


    

  • 多数用户会晕动。
    • 

  • 瞬移作为默认更安全。
    • 



3. 过多浮动窗口：


    

  • 认知过载。
    • 



4. 强迫长时间使用：


    

  • 1+ 小时会疲劳。
    • 

  • 为短时间爆发式使用设计。
    • 



5. 忽略物理安全：


    

  • VR 用户会撞到家具。
    • 

  • 必须有边界系统。
    • 



6. 无 2D 回退：


    

  • 不是每个用户都有头显。
    • 

  • AR/VR 功能应是可选的。
    • 



未来
更轻的硬件：


    

  • 眼镜形态（对比护目镜）。
    • 

  • 几年内可能实现。
    • 



更宽视野：


    

  • 接近人类视觉范围。
    • 



更好的内容：


    

  • 高品质游戏 + 生产力应用。
    • 



主流普及：


    

  • 可能 5-10 年。
    • 

  • 类似移动端（iPhone 2007 → 主流 2010）。
    • 



脑机接口：


    

  • Neuralink、Meta 神经腕带。
    • 

  • 远期的输入替代方案。
    • 



小结
AR/VR/MR 让空间输入 + 3D 内容成为新范式——VR 完全沉浸、AR 叠加现实、MR 混合融合（Vision Pro 空间计算）。Vision Pro 2024 年走向主流——眼动注视 + 捏合 + 语音，无控制器，窗口范式，但 600 克 + 1 小时电池 + 3500 美元。晕动症（25% 用户）由视觉与前庭感知冲突引起，缓解——帧率 ≥ 90Hz、延迟 < 20 毫秒、瞬移而非平滑移动、静态参照物、视野缩减、短时使用。空间音频 HRTF 3D 线索让用户不看就知道方向。空间界面设计——距离（手臂 30-50 厘米 vs 观看 1-3 米）、眼睛舒适度、浮动窗口、世界锁定 vs 头部锁定、手部呈现。眼动追踪（Vision Pro 注视 + 捏合）极快选择（费茨定律），但需校准/隐私/疲劳。手部追踪手势——捏合/张掌/指向/双手，限制 5-7 个手势 + 视觉音频确认 + 回退。数字化身用于社交 VR + Vision Pro 有恐怖谷效应。AR 场景——导航/购物/游戏/教育/工业。VR 场景——游戏/培训/治疗/远程办公/娱乐。局限——硬件重累电池贵、内容少、社交怪异、健康风险。与移动端/桌面端对比——AR/VR 空间沉浸但场景有限仍属小众。工具——Unity/Unreal、Apple RealityKit/ARKit/visionOS、ARCore/Android XR、WebXR。反模式——直接移植 2D 界面、默认平滑移动、过多浮动窗口、长时间使用、忽略物理安全、无 2D 回退。未来——更轻眼镜形态、更宽视野、更好内容、5-10 年主流、脑机接口远期。一个简单的检验：你能设计一个 AR 应用让用户不晕动吗？如果不能，空间设计还需巩固。AR/VR 是下一个十年界面的主战场——理解空间范式让设计面向未来。
