拜占庭容错

概述

拜占庭容错（Byzantine Fault Tolerance, BFT）解决的是分布式系统中最严格的故障模型——节点不仅可能宕机，还可能发送错误、矛盾甚至恶意的消息。从经典的 PBFT 算法到区块链中的 PoW/PoS 共识，拜占庭容错是构建开放网络中可信系统的基础。

拜占庭将军问题回顾

条件 说明
n 个节点 其中至多 f 个是拜占庭节点（任意行为）
目标 所有忠诚节点就同一个值达成一致
必要条件 n ≥ 3f + 1 


PBFT（Practical Byzantine Fault Tolerance）
Castro 和 Liskov 于 1999 年提出的实用拜占庭容错算法，是第一个在工程上可行的 BFT 方案。

最佳实践
    

  • 内部可信环境使用 CFT（Raft/Paxos），不要为了"安全"而过度使用 BFT
    • 

  • BFT 系统的节点数不宜过大（PBFT 建议 < 20 节点），否则 O(n²) 通信成为瓶颈
    • 

  • 区块链场景根据信任模型选择：公有链用 PoW/PoS，联盟链用 BFT
    • 

  • 关注 HotStuff 等新一代 BFT 协议，其线性消息复杂度使大规模部署可行
    • 

  • 即使使用 BFT 协议，也需要配合身份认证（PKI）防止 Sybil 攻击
