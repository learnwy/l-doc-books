Kafka 深入

概述

Apache Kafka 是一个分布式流处理平台，最初由 LinkedIn 开发，现已成为大数据和实时处理领域的事实标准。Kafka 的核心设计——分区化的持久化日志——使其在吞吐量、可扩展性和容错性上表现卓越，广泛用于日志收集、事件流、流处理管道等场景。

分区策略
class Partitioner:
    def partition(self, key, value, num_partitions):
        if key is None:
            return random.randint(0, num_partitions - 1)
        return hash(key) % num_partitions

Exactly-Once 语义
Kafka 通过幂等生产者 + 事务实现 Exactly-Once：


幂等生产者
Producer ID (PID) + Sequence Number
→ Broker 去重相同 PID + SeqNum 的消息
事务
producer = KafkaProducer(
    transactional_id="order-processor-1",
    enable_idempotence=True
)

producer.init_transactions()
try:
    producer.begin_transaction()
    producer.send("output-topic", key=key, value=result)
    producer.send_offsets_to_transaction(
        offsets={TopicPartition("input-topic", 0): OffsetAndMetadata(offset + 1)},
        group_id="my-group"
    )
    producer.commit_transaction()
except Exception:
    producer.abort_transaction()

最佳实践
    

  • 生产环境必须配置 acks=all + min.insync.replicas=2 + 3 副本
    • 

  • 分区数根据期望吞吐量计算：分区数 ≥ 期望吞吐 / 单分区吞吐
    • 

  • 消息 key 保证同一业务实体的消息有序（如订单 ID）
    • 

  • 消费者数量不超过分区数——多余的消费者会空闲
    • 

  • 新集群使用 KRaft 模式，避免 ZooKeeper 的运维复杂度
    • 

  • 监控 Consumer Lag、ISR 缩减、Under-Replicated Partitions 等关键指标
