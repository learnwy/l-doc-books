流处理框架

概述

流处理（Stream Processing）是对无界数据流进行连续、实时的计算。与批处理不同，流处理在数据到达时立即处理，延迟通常在毫秒到秒级。Apache Flink 和 Kafka Streams 是当前最主流的流处理框架，它们在语义保证、状态管理和窗口计算等方面各有特色。

批处理 vs 流处理

维度 批处理 流处理
数据集 有界（固定大小） 无界（持续到达）
延迟 分钟到小时 毫秒到秒
处理方式 全量处理后输出 逐条或微批处理
结果 一次完整结果 持续更新的结果
容错 重新运行作业 Checkpoint + 恢复
代表 MapReduce、Spark Flink、Kafka Streams

编程模型
from pyflink.datastream import StreamExecutionEnvironment
from pyflink.common import WatermarkStrategy

env = StreamExecutionEnvironment.get_execution_environment()

orders = env.from_source(
    kafka_source,
    WatermarkStrategy.for_monotonous_timestamps(),
    "orders"
)

revenue_per_minute = (
    orders
    .key_by(lambda order: order.category)
    .window(TumblingEventTimeWindows.of(Time.minutes(1)))
    .reduce(lambda a, b: a.amount + b.amount)
)

revenue_per_minute.sink_to(output_sink)
env.execute("Revenue Calculator")

最佳实践
    

  • 优先使用事件时间（Event Time）+ Watermark，保证结果的确定性
    • 

  • Flink 适合复杂流处理场景，Kafka Streams 适合 Kafka 生态内的轻量转换
    • 

  • Checkpoint 间隔根据延迟容忍度设置（通常 1-5 分钟）
    • 

  • 大状态使用 RocksDB State Backend，避免内存溢出
    • 

  • 监控背压（Backpressure），及时调整并行度
    • 

  • 迟到数据使用侧输出收集，后续批量修正
