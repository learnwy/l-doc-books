分布式链路追踪

概述

在微服务架构中，一个用户请求可能经过数十个服务。当请求变慢或失败时，定位问题根因变得极其困难。分布式链路追踪通过为每个请求分配唯一标识，串联起请求在所有服务中的调用链路，是微服务可观测性（Observability）的核心支柱之一。

OpenTelemetry
OpenTelemetry（OTel）是 CNCF 的可观测性标准，统一了追踪、指标和日志的采集：


集成示例
from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor
from opentelemetry.exporter.otlp.proto.grpc.trace_exporter import OTLPSpanExporter

provider = TracerProvider()
processor = BatchSpanProcessor(OTLPSpanExporter(endpoint="http://otel-collector:4317"))
provider.add_span_processor(processor)
trace.set_tracer_provider(provider)

tracer = trace.get_tracer(__name__)

def process_order(order_id):
    with tracer.start_as_current_span("process_order") as span:
        span.set_attribute("order.id", order_id)
        validate_order(order_id)
        charge_payment(order_id)

def validate_order(order_id):
    with tracer.start_as_current_span("validate_order"):
        pass

def charge_payment(order_id):
    with tracer.start_as_current_span("charge_payment"):
        pass


采样策略
全量采集所有请求的追踪数据成本过高，需要采样：






策略
说明
适用场景





固定比例
采集 1% 或 10% 的请求
高流量通用场景




速率限制
每秒最多采集 N 条
控制成本




自适应
根据流量动态调整比例
波动流量




尾部采样
请求完成后根据结果决定
重点采集异常请求




始终采样
采集所有请求
低流量/关键服务





from opentelemetry.sdk.trace.sampling import TraceIdRatioBased, ParentBased

sampler = ParentBased(
    root=TraceIdRatioBased(0.1)
)

指标监控（Metrics）
配合链路追踪，RED 指标（Rate、Error、Duration）是微服务监控的核心：






指标
含义
告警阈值示例





Rate
请求速率（QPS）
QPS 突降 50%




Error
错误率
错误率 > 1%




Duration
请求延迟
P99 > 500ms





# Prometheus 告警规则示例
groups:
  - name: service-alerts
    rules:
      - alert: HighErrorRate
        expr: rate(http_requests_total{status=~"5.."}[5m]) / rate(http_requests_total[5m]) > 0.01
        for: 5m
        labels:
          severity: critical


最佳实践
    

  • 使用 OpenTelemetry 作为统一的可观测性采集标准
    • 

  • 生产环境使用尾部采样——优先采集异常和慢请求
    • 

  • 为每个服务的入口和出口调用自动注入 Span
    • 

  • TraceID 透传到日志中，实现日志与追踪的关联查询
    • 

  • 建立 SLO（服务等级目标），基于 RED 指标设置告警
    • 

  • 追踪数据保留周期根据成本调整——热数据 7 天，冷数据归档
