频率分析

核心概念

频率分析（Frequency Analysis）是 9 世纪阿拉伯数学家 Al-Kindi 在 On Deciphering Cryptographic Messages 中首次系统化的密码分析方法——通过统计密文中字母 / 字母对 / 字母组的出现频率，与 plaintext 语言的已知统计分布对比，逐步还原 key。它打破了"古典密码不可破"的迷信，奠定了现代密码分析的基础。频率分析对所有保留 plaintext 统计结构的 cipher 都有效（Caesar、Vigenère、General Substitution）——而现代密码追求"密文与随机字符串不可区分"正是为了 defeat frequency analysis。

统计层次 例子 用途
单字母 E 12.7%, T 9%, A 8.2% 找 substitution map
双字母 TH 3.9%, HE 3.7% 验证 + bigram 攻击
三字母 THE 1.8%, AND 0.7% 短词识别
短词 A, I, IS, AT, OF Stop words 锚定
字母位置 单词首/尾字母 边界识别

助记：ETAOIN SHRDLU 是最频繁的 12 个字母——19 世纪铅排印刷时这是排字工最快取的字符序列。

单表 Substitution 的攻击

攻击 General Substitution Cipher（26! 的 key space）的步骤：

1. 统计密文字母频率：

ciphertext: KHOOR ZRUOG, WKLV LV D WHVW PHVVDJH WR FKHFN
            IUHTXHQFB DQDOBVLV. WKH OHWWHU H VKRXOG ...

统计得密文中 H 频率最高（约 13%），W 次之（约 9%）。

2. 假设映射：

  • H → E（密文 H 是英语 E）。
  • W → T。

3. 验证 bigram：

  • 密文 "WK" 在多处出现——若 W=T, K=H，则 "WK" → "TH"。这正是英语最常见 bigram，验证假设。

4. 短词锚定：

  • 密文中独立的 "D" → 应是 "A" 或 "I"。
  • 密文 "D" → "A"，结合 H→E、W→T 验证。

5. 反复迭代：

  • 部分 partial 解出后会暴露更多线索（如 "WKH" → "THE"）。
  • 反复细化直到全部解出。

6. Hill climbing 自动化：

  • 现代攻击用 hill climbing 算法——随机交换映射、计算解读后文本与英语 bigram 频率的距离、保留改进。
  • 通常 ~50 字符密文 + 10 秒就能 fully crack。

频率分析的局限

频率分析在以下情况失效：

1. 密文太短：

  • 短密文统计不稳定。
  • 50 字符是 minimum，500+ 更可靠。

2. plaintext 不是自然语言：

  • 加密 random key、binary data、压缩数据时频率分布平坦。
  • ASCII bytes 的频率分布不同于英语字母。

3. plaintext 经过预处理：

  • 压缩（如 gzip）让 plaintext 接近 random，频率分布平坦。
  • 这就是为什么"加密前压缩"在某些场景反而 weaken security（CRIME 攻击）。

4. 多表 substitution（Vigenère）：

  • 单字母频率分析失效（被 keyword 打散）。
  • 必须先用 Kasiski / Friedman 找 keyword 长度。

5. 现代 cipher：

  • AES、ChaCha20 输出与随机不可区分。
  • 频率分析无效。

Bigram 与 Trigram 分析

更高阶频率（n-gram）：

英语最常见 bigram（前 10）：TH 3.9%, HE 3.7%, IN 2.7%, ER 2.5%, AN 2.3%, RE 1.9%, ON 1.7%, AT 1.6%, EN 1.6%, ND 1.6%

英语最常见 trigram（前 5）：THE 1.81%, AND 0.73%, ING 0.72%, ENT 0.42%, ION 0.42%

实战：

  • 密文最常见 bigram → 大概率对应 TH。
  • 密文最常见 trigram → 大概率对应 THE。
  • 这给两个映射：H、E、T 三个字母。

短词锚定

英语短词分布特殊：

1 字母词：A, I（无第三选择）。

2 字母词：常见——OF, TO, IN, IT, IS, BE, AS, AT, SO, WE, HE, BY, OR, ON, DO, IF, ME, MY, UP, AN, GO, NO, US, AM。

3 字母词：THE, AND, FOR, ARE, BUT, NOT, YOU, ALL, ANY, CAN, HAD, HER, WAS, ONE, OUR, OUT, DAY, GET, HAS, HIM, HIS, HOW, MAN, NEW, NOW, OLD, SEE, TWO, WAY, WHO, BOY, DID, ITS, LET, PUT, SAY, SHE, TOO, USE。

把密文按空格切（如果空格保留）——密文中独立的 "X" → A 或 I；独立的 "XY" → 试 OF/TO/IS；密文中 "XYZ" → 大概率 THE。

单词模式

Pattern：把单词转成字母 distinct pattern。

  • "PEOPLE" → "ABCAEB"（P=A, E=B, O=C, L=E）。
  • "THESE" → "ABCDB"。

应用：密文中识别相同 pattern 的单词，与英语字典中相同 pattern 的单词对比，缩小可能性。

def word_pattern(word):
    mapping = {}
    pattern = []
    for ch in word.upper():
        if ch not in mapping:
            mapping[ch] = chr(ord('A') + len(mapping))
        pattern.append(mapping[ch])
    return ''.join(pattern)

# word_pattern("PEOPLE") => "ABCAEB"
不同语言的频率
不同语言频率不同：


法语：E（17.3%）、A（8.4%）、S（8.1%）、T（7.4%）、I（7.3%）。


德语：E（17.4%）、N（9.8%）、I（7.6%）、S（7.3%）、R（7.0%）。


中文（拼音）：常见 i、a、e、n、o。


密文 metadata 攻击：通过单字母频率分布形状判断 plaintext 语言——E 占 17% 是法语，E 占 12.7% 是英语。


现代密码如何 defeat 频率分析
1. Block cipher：


    

  • AES 一次加密 16 byte（128 bit）。
    • 

  • 16 byte 组合空间是 2^128——频率统计不可能。
    • 



2. CBC 模式：


    

  • 每个 block 加密结果依赖前一 block + IV。
    • 

  • 相同 plaintext 在不同位置加密结果不同。
    • 



3. CTR 模式：


    

  • 加密 counter 生成 key stream，与 plaintext XOR。
    • 

  • key stream 与随机不可区分。
    • 



4. Authenticated encryption：


    

  • AES-GCM 同时提供加密 + MAC。
    • 

  • 任何篡改被检测。
    • 



5. IND-CPA / IND-CCA 安全：


    

  • 现代密码追求"攻击者即使选择 plaintext 也无法区分密文与随机"。
    • 

  • 这是密码学的 gold standard。
    • 



频率分析的现代应用
虽然攻击现代密码无效，频率分析在现代仍有用：


1. 教学：


    

  • 密码学课的标准 exercise。
    • 

  • 让学生 internalize 密码学原则。
    • 



2. 法医：


    

  • 分析未知格式数据。
    • 

  • 文件类型识别（不同格式 byte 频率分布不同）。
    • 



3. 隐写术（steganography）：


    

  • 检测信息隐藏（hidden message 改变 byte 频率分布）。
    • 



4. 网络流量分析：


    

  • 加密流量的 metadata（包大小、时序）仍可能泄露信息。
    • 



5. CTF 比赛：


    

  • 经典 challenge category。
    • 



小结
频率分析是 Al-Kindi 9 世纪首次系统化的密码分析方法——破除"古典密码不可破"迷信。英语 ETAOIN SHRDLU 12 个字母占 73%，给单表 substitution cipher 致命弱点。攻击工作流——单字母频率初步映射、bigram（TH、HE）/ trigram（THE、AND）验证、短词（A、I、IS、THE）锚定、单词 pattern 字典 lookup、迭代细化。Hill climbing 自动化让 50 字符密文 10 秒可破。频率分析失效场景——密文太短、plaintext 非自然语言、压缩数据、多表 substitution（需先 Kasiski）、现代 cipher（与随机不可区分）。不同语言频率不同（法语 E 17.3%、德语 E 17.4%）——可用于 plaintext 语言识别。现代密码 defeat 频率分析——block cipher（2^128 组合）、CBC / CTR 模式、authenticated encryption（AES-GCM）、IND-CPA / IND-CCA 安全标准。频率分析现代应用——教学、法医、隐写检测、网络流量分析、CTF。一个简单的检验：你能在 10 分钟内手工破解一段 ~200 字符的 substitution cipher？如果不能，密码分析直觉还需训练。频率分析是密码学最重要的"为什么"——告诉我们任何保留 plaintext 统计结构的密码都不安全，迫使现代密码追求与随机不可区分。
