Vigenère Cipher 维吉尼亚密码

核心概念

Vigenère Cipher 是 16 世纪法国宫廷的密码——把多个 Caesar cipher 用一个关键词（keyword）串联起来。它在被发明后几个世纪里被称为 "le chiffre indéchiffrable"（无法破解的密码），直到 19 世纪 Babbage 与 Kasiski 各自独立发现攻击方法。Vigenère 是 polyalphabetic substitution（多表替换密码）的代表——比 Caesar 等 monoalphabetic（单表替换）安全得多，但仍不抵抗现代密码分析。理解 Vigenère 让我们看到密码学的进化逻辑——每个新一代 cipher 解决前一代的弱点（频率分析），但带来新弱点（key 长度泄露）。本节给出 Vigenère 的算法、Kasiski 攻击、信息论限制。

维度 Caesar Vigenère
类型 Monoalphabetic Polyalphabetic
Key 单字符 (k=0..25) Keyword（多字符）
Key space 26 26^n（n=keyword 长度）
频率特征 完全保留 被 key 长度打散
攻击 暴力穷举 Kasiski + Friedman

Vigenère 算法

把 keyword 重复填满与 plaintext 等长：

plaintext:  ATTACKATDAWN
keyword:    LEMONLEMONLE
ciphertext: LXFOPVEFRNHR

加密：ci = (m_i + k(i mod L)) mod 26，其中 L 是 keyword 长度。

解密：mi = (c_i - k(i mod L)) mod 26。

Vigenère Square（也称 tabula recta）是 26×26 的查表——row 是 plaintext 字母、column 是 key 字母、cell 是 ciphertext 字母。这让加解密无需数学背景就能操作。

def vigenere_encrypt(plaintext, keyword):
    result = []
    keyword = keyword.upper()
    j = 0
    for ch in plaintext.upper():
        if ch.isalpha():
            shift = ord(keyword[j % len(keyword)]) - ord('A')
            result.append(chr((ord(ch) - ord('A') + shift) % 26 + ord('A')))
            j += 1
        else:
            result.append(ch)
    return ''.join(result)

为什么 Vigenère 比 Caesar 强

Caesar 把所有 E 都映射为同一字母（如 H）——频率分析直接破解。

Vigenère 把 plaintext 中的每个 E 根据它的位置 (i mod L) 映射为不同字母——前面 12 个 E 可能映射为 12 个不同的字母（如果 L=12 且 keyword 字母都不同）。这"打散"了频率特征。

但只在密文长度 << keyword 长度时是这样。当密文长度 >> keyword 长度时（典型情况），仍能被攻破。

Kasiski Examination

1863 年 Friedrich Kasiski 发表攻击方法——基于一个关键观察：如果 plaintext 中出现重复的字母组合（如 "THE"），且重复的两次距离正好是 keyword 长度的倍数，那么密文中也会出现相同的字母组合。

例：

plaintext:  ATTACKTHEENEMYAT THE BRIDGE
keyword:    LEMONLEMONLEMONLEMONLEMON

如果 "THE" 在 plaintext 出现两次，且距离是 12（keyword 长度的倍数），那 "THE" 加密后产生相同密文片段。

Kasiski 攻击步骤：

  1. 在密文中找重复的字母组合。
  2. 计算它们之间的距离。
  3. 这些距离的最大公约数（GCD）大概率是 keyword 长度。
  4. 把密文按每 L 个字母切片，每个切片是一个独立的 Caesar cipher（同一个 key 字符）。
  5. 对每个切片单独做频率分析——分别找出每个 key 字符。
Friedman Test（Index of Coincidence）
Kasiski 需要 plaintext 有重复——不是所有 plaintext 都有。Friedman 1922 年提出更通用的方法——Index of Coincidence (IC)。


IC 定义：随机抽两个字符，它们相同的概率。


    

  • 英语 plaintext 的 IC ≈ 0.067。
    • 

  • 完全随机字符串的 IC ≈ 1/26 ≈ 0.0385。
    • 



如果把密文按每 L 个字母切片，切片的 IC：


    

  • 当 L 等于 keyword 长度时——每片是 Caesar，IC ≈ 0.067（保留英语统计）。
    • 

  • 当 L 不是 keyword 长度时——每片混合多 key，IC 接近 0.0385。
    • 



攻击：尝试 L = 1, 2, 3, ..., 找到 IC 最接近 0.067 的 L——那就是 keyword 长度。


信息论视角
Shannon 1949 年从信息论角度分析 Vigenère。Unicity Distance（唯一解距离）是攻击者需要的密文长度，使得唯一一个有意义的解出现。


公式：U ≈ H(K) / D


其中 H(K) 是 key 的熵（Vigenère 是 L · log₂(26) ≈ 4.7L bit），D 是语言的冗余（英语 ≈ 3.2 bit/char）。


例：keyword 长度 L=10 → U ≈ 47 / 3.2 ≈ 15 字符。即只需 15 字符密文就有唯一可读解。


实际攻击需要更长（约 5-10 倍），但这告诉我们 Vigenère 在密文足够长时必然不安全。


Auto-Key Vigenère
Vigenère 的一个变体——用 plaintext 自身作为后续 key。


plaintext:  ATTACKATDAWN
keyword:    LEMON           ← 初始 key
auto-key:   LEMONATTACKA    ← key 是 keyword + plaintext
ciphertext: LXFOPVTUTLAN
理论上 stronger（key 不再周期性），但仍能被攻破——因为 plaintext 不是真随机。


信息论的极限：完美保密
Shannon 证明——只有当 key 是真随机、与 plaintext 等长、只用一次时，密文才能提供 perfect secrecy（完美保密）。这就是 One-Time Pad（OTP），下节展开。


Vigenère 不是 OTP——因为 keyword 短且重复，违反了 OTP 的所有三个条件。


Vigenère 在历史中的角色
Vigenère 在 16-19 世纪被广泛使用（外交通信、军事密码），人们以为它不可破。直到：


    

  • 1854 Babbage 私下破解（未公开）。
    • 

  • 1863 Kasiski 公开方法。
    • 

  • 19-20 世纪欧洲军队仍部分使用（直到 WWI 教训）。
    • 

  • 二战 Germany 用更复杂的机械版本（如 Lorenz cipher），仍被破解。
    • 



教训："未知是否可破"≠"不可破"。密码学需要数学证明，不是 absence of public attack。


现代密码如何超越 Vigenère
现代 stream cipher（如 ChaCha20、AES-CTR mode）可以看作"超级 Vigenère"——但 key stream 是密码学伪随机序列（CSPRNG），不是周期性 keyword：


    

  • ChaCha20：用 256-bit key + 64-bit counter + 64-bit nonce 生成无限长 key stream。
    • 

  • AES-CTR：用 AES 加密 counter 生成 key stream。
    • 



key stream 的周期是 2^64+，攻击者无法识别周期性。


Vigenère 的工程教训
    

  1. Polyalphabetic > Monoalphabetic：但仍不够。
    2. 

  2. Key 周期是致命弱点：Kasiski 攻击的根本。
    3. 

  3. 真随机 key + 等长 + 只用一次：才是 unconditionally secure（OTP）。
    4. 

  4. 公开 + 学术审查：Vigenère 经过学术分析才被证伪。
    5. 



小结
Vigenère Cipher 是 polyalphabetic substitution 的代表——把多个 Caesar 用 keyword 串联，被认为"无法破解"几个世纪。算法是 ci = (m_i + k(i mod L)) mod 26。它比 Caesar 强在打散明文频率，但 keyword 周期性是致命弱点。Kasiski Examination 1863 攻击——找密文重复片段、计算距离、GCD = keyword 长度、按片切割每片做 Caesar 频率分析。Friedman Test 用 Index of Coincidence（英语 IC ≈ 0.067、随机 ≈ 0.0385）找 keyword 长度。Shannon 信息论给出 unicity distance U ≈ H(K) / D，证明 Vigenère 在足够长密文下必败。Auto-key 变体改善但仍不够。完美保密只能由 OTP 实现——真随机、等长、一次使用。Vigenère 在历史上让欧洲军队多次失败（WWI 教训）。现代 stream cipher（ChaCha20、AES-CTR）继承 Vigenère 思想但用 CSPRNG 替代 keyword，周期足够长。Vigenère 的工程教训——polyalphabetic 不够、key 周期是致命、真 OTP 才 unconditionally secure、密码必须经学术审查。一个简单的检验：你能否实现 Kasiski 攻击破解一个 100 字符 Vigenère 密文？如果不能，密码分析直觉还需训练。下一节展开频率分析的具体技术。
