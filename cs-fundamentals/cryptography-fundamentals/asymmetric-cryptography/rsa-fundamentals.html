RSA 基础

核心概念

RSA（Rivest-Shamir-Adleman 1977）是历史上第一个广泛部署的公钥密码——它解决了对称密码无法解决的 key 分发问题：双方不需要预先共享 secret，发送者用接收者公开的公钥（public key）加密，只有持有对应私钥（private key）的接收者能解密。RSA 同时支持加密与签名两种用途。它的安全性依赖大整数因式分解的困难——给一个 2048 bit 的 N，分解 N = p × q 在经典计算下不可行。但 RSA 在 quantum era（Shor 算法）会失效，长期会被 ECC 与 post-quantum 替代。本节介绍 RSA 数学基础（费马小定理、欧拉函数、模幂、CRT 加速）、加密/签名流程、为什么 2048 bit 已不再 future-proof、padding（PKCS#1 v1.5、OAEP、PSS）。

维度 对称密码（AES） RSA
Key 类型 单一 secret key (public, private) 对
Key 长度 128/256 bit 2048-4096 bit
速度 GB/s KB/s（慢 1000 倍）
用途 大数据加密 Key 交换、签名
Key 分发 难（OOB） 公钥可公开
数学基础 替换、扩散 大整数分解困难

RSA 的数学基础

1. 费马小定理：若 p 是素数，gcd(a, p) = 1，则 a^(p-1) ≡ 1 (mod p)。

2. 欧拉函数 φ(n)：与 n 互素的小于 n 的正整数个数。

  • 若 n = p × q（p, q 是不同素数）→ φ(n) = (p-1)(q-1)。

3. 欧拉定理：若 gcd(a, n) = 1，则 a^φ(n) ≡ 1 (mod n)。

4. 模逆元：给定 e，找 d 使 e · d ≡ 1 (mod φ(n))——用扩展欧几里得算法。

RSA Key 生成

1. 选两个大素数 p, q（每个约 1024 bit，n=2048 bit）。
2. 计算 n = p × q。
3. 计算 φ(n) = (p-1)(q-1)。
4. 选 e（公钥指数）使 gcd(e, φ(n)) = 1。
   常用 e = 65537（= 2^16 + 1，二进制 10000000000000001）。
5. 计算 d（私钥指数）使 e · d ≡ 1 (mod φ(n))。
6. 公钥 = (n, e)，私钥 = (n, d)。
   p, q, φ(n) 销毁。

为什么 e = 65537：

  • 二进制只有 2 个 1——加密快（少量乘法）。
  • 大于早期建议的小 e（如 3）——避免某些攻击。

RSA 加密 / 解密

加密：c = m^e mod n（用公钥）

解密：m = c^d mod n（用私钥）

正确性证明：

c^d = (m^e)^d = m^(ed) = m^(1 + k·φ(n)) (mod n)
    = m · m^(k·φ(n)) = m · (m^φ(n))^k (mod n)
    = m · 1^k = m (mod n)

依赖欧拉定理 m^φ(n) ≡ 1 (mod n)。

RSA 签名 / 验证

签名是加密的"反向"：

签名：s = m^d mod n（用私钥）

验证：m = s^e mod n（用公钥）

性质：

  • 任何人可验证（用公开公钥）。
  • 只有私钥持有者可签名。
  • 提供完整性 + 认证 + 不可否认。

RSA-OAEP（加密 padding）

Naive RSA 不安全——直接 m^e mod n 有多个问题：

  • m = 0 / 1 → c = 0 / 1。
  • 小 m 与小 e → c = m^e（无 mod）→ 直接 e-th root 还原。
  • 同 m 加密给多个公钥 → CRT 攻击。
  • 选择密文攻击。

OAEP（Optimal Asymmetric Encryption Padding，PKCS#1 v2.0）：

1. 把消息 m padding 为固定大小（n - 1 bit）。
2. 用 random seed + MGF（mask generation function）生成结构化 padding。
3. 整体作为 RSA 加密输入。

作用：

  • 让相同 m 每次加密产生不同 ciphertext（IND-CPA）。
  • 防选择密文攻击。
  • 验证 padding 防其他攻击。

实战：现代 RSA 加密永远用 OAEP。PKCS#1 v1.5（旧 padding）有 Bleichenbacher 攻击（1998）至今 ROBOT（2017）仍找到漏洞。

RSA-PSS（签名 padding）

RSA-PSS（Probabilistic Signature Scheme，PKCS#1 v2.1）：

  • 签名也需要 padding。
  • PSS 让签名 randomized——每次签同 m 产生不同签名。
  • 提供 RBC（Random Bit String）安全。

实战：现代 RSA 签名永远用 PSS。PKCS#1 v1.5 签名仍兼容但不推荐。

CRT（中国剩余定理）加速

RSA 解密 c^d mod n（n 是 2048 bit）极慢。CRT 优化把它分成两个 1024 bit 操作：

1. 分别计算 c^(d mod (p-1)) mod p 与 c^(d mod (q-1)) mod q。
2. 用 CRT 组合得 c^d mod n。

速度：约 4 倍。

风险：CRT 实现需 constant-time——否则故障注入攻击（fault attack）一次错误计算泄露私钥。

RSA 安全性

Key 长度建议（2026）：

  • 1024 bit：已破（2010 NIST 弃用）。
  • 2048 bit：当前最低建议（到 2030 仍可用）。
  • 3072 bit：新部署推荐。
  • 4096 bit：高安全 + long-term。
  • 7680 bit：等价 AES-192。
  • 15360 bit：等价 AES-256。

最大已破公开记录：

  • 2009：768 bit（学术合作 2 年）。
  • 2019：795 bit（CADO-NFS）。
  • 2020：829 bit。

实战意义：1024 bit 仅有 80 bit 等价对称强度——目前国家 actor 可破。2048 bit 给 112 bit 强度（足够当前但不 future-proof）。

RSA 的常见攻击

1. 小 e 攻击：

  • e = 3 + 短 m → c = m^3（无 mod）→ 直接 cube root。
  • 现代 e = 65537 防御。

2. 共模攻击：

  • 同 n 不同 e1, e2 加密同 m → 攻击者用扩展欧几里得算法还原 m。
  • 永远不要用同 n 给多个 e。

3. 弱 prime：

  • p, q 太接近（差小）→ Fermat factorization。
  • |p - q| 必须 ≥ √n / 2^(n/4)。

4. PRNG 共享：

  • 多个 key 因 RNG seed 重复用同一个 p → GCD 攻击。
  • 2012 研究发现互联网上 0.75% RSA key 因此被破。

5. Bleichenbacher 攻击：

  • PKCS#1 v1.5 padding oracle。
  • 现代用 OAEP 防御。

6. Side channel：

  • Timing attack（modular exponentiation）。
  • Power analysis。
  • 防御：constant-time 实现。

量子计算对 RSA 的威胁

Shor 算法（1994）：

  • Quantum computer 上多项式时间分解大整数。
  • 破 RSA。
  • 但需 fault-tolerant quantum computer ~ 4000 logical qubits（实际 ~ 百万 physical qubits）。

当前状态：

  • IBM、Google 等的 quantum computer 仅 ~ 1000 noisy qubits。
  • 仍无法破 2048 bit RSA。
  • 估计 10-20 年达到威胁规模。

Post-Quantum 准备：

  • NIST 2024 年标准化 ML-KEM（基于 lattice）等 post-quantum 算法。
  • 现代部署 hybrid（RSA + ML-KEM）transition。
  • Google Chrome 2024 年 enable post-quantum TLS。

实战 API

Python（cryptography）：

from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes, serialization

# Key 生成
private_key = rsa.generate_private_key(public_exponent=65537, key_size=2048)
public_key = private_key.public_key()

# 加密（OAEP）
ciphertext = public_key.encrypt(
    plaintext,
    padding.OAEP(mgf=padding.MGF1(algorithm=hashes.SHA256()),
                 algorithm=hashes.SHA256(), label=None)
)

# 解密
plaintext = private_key.decrypt(ciphertext, padding.OAEP(...))

# 签名（PSS）
signature = private_key.sign(
    message,
    padding.PSS(mgf=padding.MGF1(hashes.SHA256()), salt_length=padding.PSS.MAX_LENGTH),
    hashes.SHA256()
)

# 验证
public_key.verify(signature, message, padding.PSS(...), hashes.SHA256())

关键：

  • 用 OAEP 加密，PSS 签名（不用 PKCS#1 v1.5）。
  • 至少 2048 bit。
  • 永远用经过审查的库（cryptography、OpenSSL、BoringSSL）。

RSA vs ECC

ECC（Elliptic Curve Cryptography）正取代 RSA：

维度 RSA-2048 ECC-256 RSA-3072 ECC-384
等价对称 112 bit 128 bit 128 bit 192 bit
Key 大小 2048 bit 256 bit 3072 bit 384 bit
签名速度 慢 快 慢 快
验证速度 快 慢 快 慢
部署 衰退 增长 - -

ECC 在移动端 / IoT / 区块链 dominant。RSA 仍在 enterprise / legacy 主导。

小结

RSA 是历史上第一个广泛部署的公钥密码（1977 Rivest-Shamir-Adleman）。数学基础——费马小定理、欧拉函数 φ(n)、欧拉定理、模逆元。Key 生成——选大素数 p, q，n = p×q，φ(n) = (p-1)(q-1)，e = 65537，d = e⁻¹ mod φ(n)。加密 c = m^e mod n（公钥），解密 m = c^d mod n（私钥）。签名是加密反向——s = m^d（私钥），验证 m = s^e（公钥）。OAEP 加密 padding（PKCS#1 v2.0）防选择密文攻击，PSS 签名 padding（v2.1）让签名 randomized。CRT 加速解密 ~4x。Key 长度建议——2048 bit 当前最低，3072 bit 新部署，4096 bit long-term。常见攻击——小 e、共模、弱 prime、PRNG 共享、Bleichenbacher、side channel。Quantum 威胁——Shor 算法理论破 RSA，需要 ~4000 logical qubits（10-20 年），post-quantum hybrid 已部署（Chrome 2024）。实战——用 OAEP 加密 + PSS 签名 + 经过审查的库。RSA vs ECC——ECC 正取代 RSA（移动 / IoT / 区块链），RSA 仍在 enterprise / legacy。一个简单的检验：你能不查文档说出 RSA key 生成的 6 个步骤？如果不能，RSA 数学基础还需巩固。RSA 是密码学的"第一个公钥革命"——让 secure 通信不再需要预先共享 secret，奠定整个互联网安全基础设施。
