命题逻辑

核心概念

命题逻辑（Propositional Logic）是数理逻辑中最基础的形式系统，研究命题之间通过逻辑联结词组合后的真值关系。一个命题是一个能够明确判断真假的陈述句，例如"2 是偶数"为真命题，"3 > 5"为假命题。而"x > 3"不是命题，因为其真值取决于变量 x 的取值。

命题逻辑的核心在于：通过有限的逻辑联结词，将简单命题组合成复合命题，并用真值表精确刻画其真假。这与编程中的布尔表达式完全对应——每个 if 条件、每个 &&/|| 运算，本质上都是命题逻辑的实例。

真值表与联结词语义
真值表是命题逻辑中最直接的语义分析工具。对于 n 个命题变元的复合命题，真值表有 2^n 行，每行列出变元的一种赋值组合及对应的复合命题真值。


五个基本联结词中，蕴含（→） 的语义最容易被误解。p → q 仅在 p 为真且 q 为假时取假值，其他情况均为真。这意味着"假前提可以推出任何结论"——这在数学证明中被称为"空真"（vacuous truth）。


在编程中，短路求值与蕴含的关系值得关注。if (p) then q 语句中，当 p 为假时 q 根本不会执行，这恰好对应 p → q 在 p 为假时为真的语义。


const implies = (p: boolean, q: boolean): boolean => !p || q;

const biconditional = (p: boolean, q: boolean): boolean => implies(p, q) && implies(q, p);

const xor = (p: boolean, q: boolean): boolean => p !== q;
真值表的构造过程本身就是一种穷举算法，其时间复杂度为 O(2^n)。这解释了为什么 SAT（布尔可满足性）问题是 NP 完全的——当变元数量增长时，暴力枚举真值表的代价呈指数增长。


考虑复合命题 (p → q) ∧ (q → r) → (p → r) 的验证，这实际上是假言三段论的命题逻辑表达。通过构造包含 8 行的真值表，可以验证该命题在所有赋值下均为真，即它是一个永真式（重言式）。

判断一个公式是否为永真式（即有效性检验）可以通过构造完整真值表实现。但当变元数量 n 较大时，2^n 行的真值表不可接受，这时需要借助推理规则或 SAT 求解器。


逻辑等价与范式
两个命题公式在所有赋值下具有相同真值时，称它们逻辑等价，记为 P ≡ Q。逻辑等价是命题逻辑中最重要的关系之一，它允许我们在保持真值不变的前提下对公式进行变换——这与编程中的代码重构在本质上是同一思想。


核心等价律包括：


    

  • 德摩根律：¬(p ∧ q) ≡ ¬p ∨ ¬q，¬(p ∨ q) ≡ ¬p ∧ ¬q
    • 

  • 分配律：p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)
    • 

  • 吸收律：p ∨ (p ∧ q) ≡ p
    • 

  • 蕴含消去：p → q ≡ ¬p ∨ q
    • 

  • 逆否命题：p → q ≡ ¬q → ¬p
    • 



德摩根律在编程中极为常见。当需要否定一个复杂条件时：


// 原条件: !(a > 0 && b < 10)
// 德摩根变换: a <= 0 || b >= 10
const check = (a: number, b: number): boolean => a <= 0 || b >= 10;
范式是命题公式的标准化形式。析取范式（DNF）是若干合取子句的析取，合取范式（CNF）是若干析取子句的合取。任何命题公式都可以转化为等价的 DNF 或 CNF，这保证了命题逻辑的表达统一性。


CNF 在实际中尤为重要：SAT 求解器的输入标准格式就是 CNF。将任意布尔公式转化为 CNF 的过程，也是编译器中布尔表达式优化的基础步骤之一。


转化为 CNF 的基本步骤：


    

  1. 消去蕴含和等价（用 ¬ 和 ∨ 替换）
    2. 

  2. 将否定深入到原子命题（应用德摩根律）
    3. 

  3. 应用分配律将析取分配到合取上
    4. 



以 p → (q ∧ r) 为例：


    

  • 第一步：¬p ∨ (q ∧ r)（蕴含消去）
    • 

  • 第二步：(¬p ∨ q) ∧ (¬p ∨ r)（分配律）
    • 

  • 结果已是 CNF：两个析取子句的合取
    •

命题逻辑的推理规则
推理规则是从已知命题推导新命题的形式化工具。与真值表的穷举验证不同，推理规则允许我们通过局部的语法变换来得出结论，这在命题变元较多时远比真值表高效。

假言推理（Modus Ponens）是最基础也最常用的推理规则。在类型系统中，函数应用就是假言推理的实例：如果 f 的类型是 A → B（即"A 蕴含 B"），传入一个类型为 A 的参数（即"A 为真"），就得到类型为 B 的返回值（即"B 为真"）。


// Modus Ponens 在类型系统中的体现
// f: A → B（蕴含）
// x: A（前提为真）
// f(x): B（结论为真）
const modusPonens = <A, B>(f: (a: A) => B, x: A): B => f(x);
这种命题即类型、证明即程序的对应关系被称为 Curry-Howard 同构，是类型理论与逻辑学之间最深刻的联系之一。


命题逻辑在工程中的应用
命题逻辑在软件工程中的应用远比想象中广泛。以下是几个关键场景：


条件化简与分支优化：编译器在优化条件表达式时，大量使用逻辑等价律。例如将 !(a && !b) 简化为 !a || b，减少分支指令。


配置约束求解：大型系统的配置项之间存在依赖关系（"如果启用 A，则必须启用 B"），这些约束可以编码为 CNF 公式，然后用 SAT 求解器检查是否存在合法配置。Linux 内核的 Kconfig 系统就使用了类似的方法。


形式化验证：模型检查（Model Checking）将系统状态编码为命题变量，将需要验证的性质表达为命题逻辑公式，通过算法自动验证系统是否满足给定性质。


电路设计也是命题逻辑的直接应用。数字电路中的与门、或门、非门精确对应逻辑联结词 ∧、∨、¬。电路化简问题等价于布尔公式化简，卡诺图（Karnaugh Map）方法本质上就是在真值表基础上寻找最简 DNF 表达。


访问控制与权限系统中的策略判定也是命题逻辑的实例。RBAC（基于角色的访问控制）中的权限检查可以表达为：hasRole(admin) ∨ (hasRole(editor) ∧ isOwner(resource))。策略引擎在运行时对这类布尔表达式进行求值。


特性标志组合（Feature Flags）系统中，多个标志的组合条件（"A 且非 B 或 C"）构成命题逻辑公式。当标志数量增长时，确保所有组合的行为一致性就成为一个 SAT 类问题。


小结
    

  • 命题逻辑通过五个基本联结词（¬, ∧, ∨, →, ↔）构建复合命题，真值表提供穷举语义
    • 

  • 蕴含（→）的"假前提推一切"语义是初学者最常见的理解障碍
    • 

  • 逻辑等价律（尤其是德摩根律）是布尔表达式化简的核心工具
    • 

  • CNF 范式是 SAT 求解器的标准输入格式，连接了理论与工程实践
    • 

  • 推理规则提供了比真值表更高效的局部推导方法
    • 

  • Curry-Howard 同构揭示了命题逻辑与类型系统之间的深刻对应
    • 

  • 命题逻辑的应用覆盖编译优化、配置管理、形式化验证和电路设计等多个工程领域
    •
