函数

核心概念

函数（Function）是关系的一种特殊类型：集合 A 到集合 B 的函数 f: A → B 是一个关系，满足 A 中的每个元素恰好与 B 中的一个元素配对。换言之，函数是全域的（每个输入都有输出）且单值的（同一输入不会产生两个不同输出）。

函数的形式化定义为编程中的函数概念提供了严格的数学基础。编程语言中的纯函数完全符合数学函数的定义：给定相同输入，总是返回相同输出。而带副作用的"函数"（如依赖全局状态、执行 I/O）在数学意义上不是函数，因为它们违反了单值性。

单射、满射与双射
这三种函数分类在计算机科学中有着深刻的应用意义。


单射（一对一函数）保证不同的输入映射到不同的输出。在数据库中，UNIQUE 约束确保了某列上的映射是单射的。完美哈希函数是一种特殊的单射——它将 n 个键映射到 n 个不同的位置，消除了碰撞。


检验单射的方式：如果 f(a₁) = f(a₂)，则必有 a₁ = a₂。在有限集合上，如果 |A| > |B|，则 f: A → B 不可能是单射的——这是鸽巢原理的直接应用。


在密码学中，单射性至关重要。如果加密函数不是单射的（即两个不同的明文加密成相同的密文），那么解密就不可能还原出唯一的原文。因此任何实用的加密方案都必须保证加密函数对于给定密钥是单射的。


满射保证值域等于陪域——B 中的每个元素都被至少一个输入映射到。在分配问题中，满射意味着"每个目标都被分配到"。如果将学生分配到项目组，满射保证没有空组。


双射（一一对应）同时满足单射和满射，建立了两个集合间的"完美匹配"。双射的核心价值在于：


    

  1. 双射的存在证明两个集合大小相等（对有限集合）或基数相同（对无限集合）
    2. 

  2. 双射存在可逆函数 f⁻¹，使得 f⁻¹(f(x)) = x 且 f(f⁻¹(y)) = y
    3. 

  3. 加密算法必须是双射的，否则无法解密
    4. 



在 Web 开发中，URL 短链接系统就是双射的典型应用。每个长 URL 映射到唯一的短码（单射），每个短码都对应一个长 URL（满射），因此可以双向查询。Base62 编码将整数 ID 映射为短字符串，就构成了一个双射。


// 检验有限函数是否为单射
const isInjective = <A, B>(domain: A[], f: (a: A) => B): boolean => {
  const image = domain.map(f);
  return new Set(image).size === domain.length;
};

// 检验有限函数是否为满射
const isSurjective = <A, B>(domain: A[], codomain: B[], f: (a: A) => B): boolean => {
  const image = new Set(domain.map(f));
  return codomain.every((b) => image.has(b));
};
函数的复合与逆
函数复合（Composition）是从简单函数构建复杂函数的基本手段。如果 f: A → B 且 g: B → C，则 g∘f: A → C 定义为 (g∘f)(x) = g(f(x))。


函数复合的关键性质：


    

  • 结合律：(h∘g)∘f = h∘(g∘f)
    • 

  • 复合不满足交换律：g∘f ≠ f∘g（一般情况）
    • 

  • 恒等函数是复合的单位元：f∘id = id∘f = f
    • 



const compose =
  <A, B, C>(g: (b: B) => C, f: (a: A) => B): ((a: A) => C) =>
  (a: A) =>
    g(f(a));

const pipe = <T>(...fns: Array<(x: T) => T>): ((x: T) => T) => fns.reduce((acc, fn) => (x: T) => fn(acc(x)));
函数复合在函数式编程中是核心概念。管道操作（pipe）是复合的逆序表达：pipe(f, g, h) 等价于 h∘g∘f。Unix 的管道 cmd1 | cmd2 | cmd3 也是函数复合的实例。


复合保持单射性和满射性：


    

  • 如果 f 和 g 都是单射，则 g∘f 也是单射
    • 

  • 如果 f 和 g 都是满射，则 g∘f 也是满射
    • 

  • 如果 f 和 g 都是双射，则 g∘f 也是双射
    • 



这些性质在类型系统中有实际意义：如果两个类型转换都是无损的（单射），那么它们的复合也是无损的。


逆函数仅在双射时存在。f⁻¹: B → A 满足 f⁻¹∘f = id_A 且 f∘f⁻¹ = id_B。在密码学中，加密函数 E 和解密函数 D 互为逆函数：D(E(m)) = m。


对于非双射函数，可以定义左逆和右逆。左逆 g 满足 g∘f = id（撤销 f 的效果），右逆 h 满足 f∘h = id（f 可以覆盖 h 的输出）。单射有左逆，满射有右逆，双射两者都有且相等。


特殊函数与计数
地板函数（Floor）⌊x⌋ 返回不超过 x 的最大整数，天花板函数（Ceiling）⌈x⌉ 返回不小于 x 的最小整数。它们在算法分析中频繁出现：二分查找每次将问题规模缩小到 ⌊n/2⌋，分页计算需要 ⌈total/pageSize⌉ 页。


const floor = Math.floor;
const ceil = Math.ceil;

const totalPages = (total: number, pageSize: number): number => ceil(total / pageSize);

const binarySearchMid = (lo: number, hi: number): number => floor((lo + hi) / 2);
取模函数 f(x) = x mod n 将整数映射到 {0, 1, ..., n-1}。它既不是单射（多个输入映射到同一输出）也不是满射到整数集（值域受限），但如果将陪域限定为 {0, ..., n-1}，它就是满射的。取模在哈希表、循环缓冲区、密码学中都是基础操作。


函数的计数与组合数学密切相关。从 n 元集合到 m 元集合的函数总数为 mⁿ（每个输入有 m 种选择）。其中单射数为 m!/(m-n)!（当 m ≥ n），满射数可以用容斥原理计算，双射数在 m = n 时为 n!。

这些计数公式在密码学中评估密钥空间大小、在组合优化中枚举可行解时都很有用。例如，n 个元素的排列数 n! 就是 n 元集合上双射的个数。


函数还与集合的基数理论紧密相关。Cantor-Bernstein-Schröder 定理说：如果存在 A 到 B 的单射，也存在 B 到 A 的单射，则存在 A 到 B 的双射（即 |A| = |B|）。这个定理在比较无限集的大小时非常有用。


像与原像的概念在函数分析中也很重要。函数 f 下集合 S 的像 f(S) = {f(x) | x ∈ S} 是 S 中所有元素经 f 映射后的集合。原像 f⁻¹(T) = {x | f(x) ∈ T} 是映射到 T 中的所有输入元素。原像运算保持集合的并、交和补运算，这个性质在拓扑学和测度论中非常重要。


在编程中，Array.prototype.map 实现的就是像运算，Array.prototype.filter 配合条件可以实现原像运算。理解这些数学概念有助于更精确地理解高阶函数的语义。


const image = <A, B>(domain: A[], f: (a: A) => B): B[] => [...new Set(domain.map(f))];

const preimage = <A, B>(domain: A[], f: (a: A) => B, target: Set<B>): A[] => domain.filter((a) => target.has(f(a)));
小结
    

  • 函数是满足全域性和单值性的特殊关系，纯函数精确对应数学函数
    • 

  • 单射保证无碰撞，满射保证全覆盖，双射建立完美对应且可逆
    • 

  • 函数复合是函数式编程的核心操作，遵循结合律但不满足交换律
    • 

  • 逆函数仅在双射时存在，加密/解密就是互逆函数的应用
    • 

  • 从 n 元到 m 元的函数计数涉及排列、组合和容斥原理
    • 

  • 鸽巢原理可以从函数视角理解：|A| > |B| 则 A → B 不存在单射
    • 

  • 函数的形式化定义帮助我们区分纯函数和有副作用的过程
    •
