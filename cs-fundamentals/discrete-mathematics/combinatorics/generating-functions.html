生成函数

核心概念

生成函数（Generating Function）是组合数学中最强大的工具之一，它将数列转化为代数对象，使计数问题可以通过代数运算（多项式乘法、求导、积分）来求解。生成函数的核心思想是：用函数的系数来编码数列。

给定数列 a₀, a₁, a₂, ...，其普通生成函数（Ordinary Generating Function, OGF）定义为形式幂级数 A(x) = a₀ + a₁x + a₂x² + ...。这里 x 只是形式符号，不需要考虑收敛性。我们关注的是系数 aₙ（记为 [xⁿ]A(x)），而不是函数值。

对于程序员来说，生成函数的最大价值在于求解递推关系——将动态规划的状态转移方程转化为代数方程，从而得到封闭公式。

生成函数的代数运算
生成函数的强大在于：数列上的组合操作对应生成函数上的简单代数运算。


加法：如果 A(x) 编码数列 {aₙ}，B(x) 编码数列 {bₙ}，则 A(x) + B(x) 编码数列 {aₙ + bₙ}。


卷积（乘法）：A(x) × B(x) 的第 n 项系数为 cₙ = ∑ aₖ × bₙ₋ₖ（k 从 0 到 n），这就是卷积。在组合意义上，卷积对应"将两个独立选择合并"的计数。


例如，如果 A(x) 编码"选硬币的方案数"，B(x) 编码"选纸币的方案数"，则 A(x)B(x) 的 xⁿ 系数就是"凑出 n 元的总方案数"。


function multiplyPolynomials(a: number[], b: number[]): number[] {
  const result = new Array(a.length + b.length - 1).fill(0);
  for (let i = 0; i < a.length; i++) {
    for (let j = 0; j < b.length; j++) {
      result[i + j] += a[i] * b[j];
    }
  }
  return result;
}

// 零钱问题：1分、2分、5分硬币凑 n 分的方案数
// A(x) = 1 + x + x² + ... = 1/(1-x) （1分硬币）
// B(x) = 1 + x² + x⁴ + ... = 1/(1-x²) （2分硬币）
// C(x) = 1 + x⁵ + x¹⁰ + ... = 1/(1-x⁵) （5分硬币）
// 答案的生成函数 = A(x)B(x)C(x) = 1/((1-x)(1-x²)(1-x⁵))
平移：xᵏA(x) 将数列右移 k 位（前面补 k 个 0），对应递推关系中的"前面几步"。A(x)/xᵏ（忽略负次项）将数列左移 k 位。


这些运算使得递推关系可以直接翻译为代数方程。


乘法求逆：如果 A(x) = 1/(1-x)，则 (1-x)A(x) = 1，即 A(x) - xA(x) = 1。这说明数列 {aₙ} 满足 aₙ = aₙ₋₁（n ≥ 1）且 a₀ = 1，对应常数列 1, 1, 1, ...。这种"从封闭形式反推递推关系"的技巧在验证生成函数结果时很有用。


求导与积分：A'(x) = ∑ n·aₙ·xⁿ⁻¹，因此 xA'(x) 编码数列 {n·aₙ}。这在需要给数列加权时很方便——例如计算期望值 E[X] = ∑ n·P(X=n) 时，概率生成函数的导数在 x=1 处的值就是期望。


指数生成函数（EGF）A(x) = ∑ aₙ·xⁿ/n! 用于处理有标记对象的计数问题。EGF 的乘法对应"选取子集并分配标记"的操作，这在排列类问题中更为自然。例如 eˣ 的 EGF 编码了"每种大小的子集恰好有一种选法"。


求解递推关系
生成函数最实用的应用是求解线性递推关系，特别是动态规划中的状态转移方程。


斐波那契数列：F(n) = F(n-1) + F(n-2)，F(0) = 0，F(1) = 1。


设 F(x) = ∑ F(n)xⁿ。从递推关系得：


F(x) = xF(x) + x²F(x) + x


解得 F(x) = x/(1-x-x²)。通过部分分式分解：


F(x) = 1/√5 × (1/(1-φx) - 1/(1-ψx))


其中 φ = (1+√5)/2（黄金比例），ψ = (1-√5)/2。


提取 xⁿ 系数得到 Binet 公式：F(n) = (φⁿ - ψⁿ)/√5。


这个结果说明斐波那契数列以 φ ≈ 1.618 的速率指数增长。这对分析使用斐波那契数列的算法（如斐波那契堆）的复杂度至关重要。


const PHI = (1 + Math.sqrt(5)) / 2;
const PSI = (1 - Math.sqrt(5)) / 2;

const fibBinet = (n: number): number => Math.round((Math.pow(PHI, n) - Math.pow(PSI, n)) / Math.sqrt(5));

生成函数与计数问题
整数拆分是生成函数的经典应用场景。将正整数 n 表示为正整数之和（不考虑顺序）的方案数 p(n) 的生成函数为：


∏(k=1 to ∞) 1/(1-xᵏ) = 1 + x + 2x² + 3x³ + 5x⁴ + ...


每个因子 1/(1-xᵏ) = 1 + xᵏ + x²ᵏ + ... 表示数字 k 出现 0 次、1 次、2 次...的贡献。这种"每个因子编码一种选择"的结构是生成函数的标志性模式。


在编程中，整数拆分与零钱问题本质相同。动态规划的状态转移 dp[i] += dp[i-coin] 对应的就是生成函数的卷积。


快速多项式乘法：暴力多项式乘法的时间复杂度为 O(n²)，而使用快速傅里叶变换（FFT）可以在 O(n log n) 时间内完成。这在需要计算大量卷积的计数问题中非常有用。JavaScript 中可以通过 Web Audio API 的 FFT 或自行实现 Number Theoretic Transform（NTT）来加速。


function partitionCount(n: number): number {
  const dp = new Array(n + 1).fill(0);
  dp[0] = 1;
  for (let k = 1; k <= n; k++) {
    for (let i = k; i <= n; i++) {
      dp[i] += dp[i - k];
    }
  }
  return dp[n];
}
Catalan 数 Cₙ = C(2n, n)/(n+1) 的生成函数满足 C(x) = 1 + xC(x)²，解得 C(x) = (1-√(1-4x))/(2x)。Catalan 数在计算机科学中出现频率极高：n 个节点的二叉搜索树个数、合法的 n 对括号序列数、n+1 个矩阵连乘的加括号方式数，都是 Cₙ。

前几个 Catalan 数为 1, 1, 2, 5, 14, 42, 132, ...。Cₙ 的渐近估计为 Cₙ ~ 4ⁿ/(√(πn)·(n+1))，增长率约为 4ⁿ，这说明涉及 Catalan 数的暴力枚举在 n 稍大时就不可行。


function catalanNumber(n: number): number {
  const dp = new Array(n + 1).fill(0);
  dp[0] = 1;
  dp[1] = 1;
  for (let i = 2; i <= n; i++) {
    for (let j = 0; j < i; j++) {
      dp[i] += dp[j] * dp[i - 1 - j];
    }
  }
  return dp[n];
}
指数生成函数（EGF） 与普通生成函数的区别在于系数中多了 1/n! 因子。EGF 的乘法对应"将两组有标记对象合并并重新分配标记"，这在计数有标记结构（如有标记的树、排列）时更为自然。例如，eˣ 是数列 1/n! 的 EGF，而 eˣ × eˣ = e²ˣ 对应"将 n 个标记分成两组"的 2ⁿ 种方式（每个标记选择第一组或第二组）。


小结
    

  • 生成函数用函数系数编码数列，将计数问题转化为代数问题
    • 

  • 生成函数的乘法对应卷积，在组合意义上表示"合并独立选择"
    • 

  • 线性递推可以通过生成函数得到封闭公式，如斐波那契的 Binet 公式
    • 

  • 动态规划的状态转移在数学上就是生成函数的卷积操作
    • 

  • 整数拆分的生成函数是无穷乘积，每个因子编码一种数字的出现次数
    • 

  • Catalan 数通过生成函数的二次方程推导，在计算机科学中有多种组合解释
    • 

  • 生成函数是连接组合数学与代数分析的桥梁，为算法复杂度分析提供封闭公式
    • 

  • 指数生成函数处理有标记对象的计数，与普通生成函数互为补充
    • 

  • Catalan 数增长率约为 4ⁿ，其生成函数通过二次方程推导，在 CS 中出现频率极高
    • 

  • 理解生成函数能加深对动态规划本质的理解——DP 的状态转移就是卷积的离散实现
    •
