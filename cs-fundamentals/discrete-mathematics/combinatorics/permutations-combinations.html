排列与组合

核心概念

排列（Permutation）和组合（Combination）是计数问题中最核心的两个模型。排列关注有序选择——选出的元素按顺序排列；组合关注无序选择——只关心选出了哪些元素，不关心顺序。

在算法设计中，排列对应"搜索所有可能的排列顺序"（如旅行商问题），组合对应"搜索所有可能的子集"（如背包问题）。两者的计数公式决定了暴力搜索的时间复杂度，因此理解它们的数学性质对于评估算法可行性至关重要。

排列数与阶乘
排列数 P(n, r)（也写作 A(n, r)）表示从 n 个不同元素中选 r 个进行有序排列的方案数。第一个位置有 n 种选择，第二个位置有 n-1 种，...，第 r 个位置有 n-r+1 种。根据乘法原理：


P(n, r) = n × (n-1) × ... × (n-r+1) = n! / (n-r)!


阶乘 n! = n × (n-1) × ... × 2 × 1 增长极快。Stirling 近似给出了阶乘的渐近估计：n! ≈ √(2πn) × (n/e)ⁿ。这个近似在分析大规模排列问题时非常有用。

function factorial(n: number): bigint {
  let result = 1n;
  for (let i = 2n; i <= BigInt(n); i++) {
    result *= i;
  }
  return result;
}

function permutations(n: number, r: number): bigint {
  return factorial(n) / factorial(n - r);
}
全排列的生成是许多算法问题的基础。Heap 算法以 O(n!) 的最优时间生成所有排列，每次只交换两个元素。字典序排列生成按照字典顺序依次产生下一个排列，next_permutation 是 C++ STL 中的标准函数。


在实际应用中，生成排列的效率至关重要。回溯法生成排列的时间复杂度为 O(n × n!)（每个排列花 O(n) 时间输出），而 Heap 算法只需 O(n!) 时间（每个排列仅一次交换）。当 n 较大时，这个常数因子差异很显著。


function* heapPermutation<T>(arr: T[], size: number = arr.length): Generator<T[]> {
  if (size === 1) {
    yield [...arr];
    return;
  }
  for (let i = 0; i < size; i++) {
    yield* heapPermutation(arr, size - 1);
    const swapIdx = size % 2 === 0 ? i : 0;
    [arr[swapIdx], arr[size - 1]] = [arr[size - 1], arr[swapIdx]];
  }
}
组合数与二项式系数
组合数 C(n, r)（也写作 (nr)\binom{n}{r}(rn​)）表示从 n 个不同元素中选 r 个的无序选择方案数。由除法原理，C(n, r) = P(n, r) / r! = n! / (r! × (n-r)!)。


组合数有许多重要性质：


    

  • 对称性：C(n, r) = C(n, n-r)（选 r 个等于不选 n-r 个）
    • 

  • 帕斯卡恒等式：C(n, r) = C(n-1, r-1) + C(n-1, r)
    • 

  • 求和公式：∑ C(n, r) = 2ⁿ（n 个元素的子集总数）
    • 

  • 朱世杰恒等式：∑ₖ C(k, r) = C(n+1, r+1)
    • 



帕斯卡恒等式的组合解释：从 n 个元素中选 r 个，可以分为两类——包含第 n 个元素（从前 n-1 个中选 r-1 个）和不包含第 n 个元素（从前 n-1 个中选 r 个）。这直接对应递归子问题的分解。


function combinations(n: number, r: number): bigint {
  if (r > n) return 0n;
  if (r === 0 || r === n) return 1n;
  return combinations(n - 1, r - 1) + combinations(n - 1, r);
}

function combinationsDP(n: number, r: number): number {
  const dp: number[][] = Array.from({ length: n + 1 }, () => new Array(r + 1).fill(0));
  for (let i = 0; i <= n; i++) {
    dp[i][0] = 1;
    for (let j = 1; j <= Math.min(i, r); j++) {
      dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j];
    }
  }
  return dp[n][r];
}
二项式定理 (x + y)ⁿ = ∑ C(n, k) × xᵏ × yⁿ⁻ᵏ 将组合数与代数展开联系起来。当 x = y = 1 时，得到 2ⁿ = ∑ C(n, k)，即 n 个元素的子集总数。


可重复排列与组合
当允许重复选择时，计数模型有所不同：


可重复排列：每个位置有 n 种选择，共 r 个位置，方案数为 nʳ。这是密码学中密钥空间计算的基本模型——长度为 r 的密码，每位有 n 种字符选择。IP 地址空间 (256⁴ ≈ 4.3 × 10⁹) 也是可重复排列。


可重复组合：从 n 种物品中允许重复选取 r 个（不考虑顺序），方案数为 C(n+r-1, r)。这个公式可以通过"星与条"（Stars and Bars）方法推导：将 r 个相同的星用 n-1 个隔板分成 n 组，等价于从 n+r-1 个位置中选 r 个放星。


// 可重复组合：n 种物品选 r 个
const repeatedCombination = (n: number, r: number): number => combinationsDP(n + r - 1, r);

// 应用：将 r 个相同的球放入 n 个不同的盒子
const distributeIdentical = (balls: number, boxes: number): number => repeatedCombination(boxes, balls);
"星与条"方法在整数方程求解中也有重要应用。非负整数解的个数 x₁ + x₂ + ... + xₙ = r 等于 C(n+r-1, r)。这在资源分配问题中经常出现：将 r 单位资源分配给 n 个项目的方案数。


排列组合在工程中的应用
组合测试（Combinatorial Testing）基于这样的经验：大多数软件缺陷由少量参数的交互引起。两两组合（pairwise testing）通过覆盖所有参数对的组合来减少测试用例数，从 nᵏ 减少到大约 n² × k 量级。


数据库查询优化：多表 JOIN 的执行顺序有 n! 种可能。对于 10 张表，有 3,628,800 种顺序。查询优化器使用启发式方法（而非穷举）来找到近似最优的执行计划。


机器学习超参数搜索：如果有 k 个超参数，每个有 m 个候选值，网格搜索需要 mᵏ 次实验。当 k 和 m 稍大时（如 k=5, m=10），10⁵ 次实验可能不可接受。随机搜索和贝叶斯优化是对抗这种组合爆炸的方法。


API 版本兼容性：如果系统有 n 个 API 端点，每个有 m 个版本，全兼容性测试需要 mⁿ 种组合。实际中通常用兼容性矩阵和版本策略来减少需要测试的组合数。


小结
    

  • 排列关注有序选择 P(n,r)，组合关注无序选择 C(n,r)，两者通过 r! 关联
    • 

  • 阶乘增长极快，n! 在 n ≈ 15 时就达到暴力搜索的实际上限
    • 

  • 帕斯卡恒等式对应递归分解，帕斯卡三角形的每个数是上方两个数之和
    • 

  • 可重复组合 C(n+r-1, r) 通过"星与条"方法推导，等价于整数方程求解
    • 

  • 二项式定理将组合数与多项式展开联系，C(n,r) 是 (1+x)ⁿ 的系数
    • 

  • 组合爆炸是算法设计的核心挑战，组合测试和随机搜索是工程中的实用应对策略
    •
