整除性与模运算

核心概念

整除性和模运算是数论的基石，也是计算机科学中最常用的数学工具之一。整除关系定义了整数之间的"可分性"——a 整除 b（记为 a | b）当且仅当存在整数 k 使得 b = ak。模运算则将整数映射到有限范围内——a mod n 是 a 除以 n 的余数。

在编程中，模运算无处不在：哈希函数用 h(k) = k mod m 将键映射到桶；循环缓冲区用 (index + 1) mod size 实现循环；密码学中的 RSA 加密完全建立在模幂运算之上。理解模运算的数学性质，是写出正确且高效代码的基础。

最大公因数与欧几里得算法
最大公因数 gcd(a, b) 是同时整除 a 和 b 的最大正整数。最小公倍数 lcm(a, b) 是同时被 a 和 b 整除的最小正整数。两者的关系：gcd(a, b) × lcm(a, b) = a × b。


欧几里得算法（辗转相除法）基于性质 gcd(a, b) = gcd(b, a mod b) 递归计算 GCD。时间复杂度 O(log min(a, b))，是最古老且最高效的算法之一（约公元前 300 年）。


function gcd(a: number, b: number): number {
  while (b !== 0) {
    [a, b] = [b, a % b];
  }
  return a;
}

function lcm(a: number, b: number): number {
  return (a / gcd(a, b)) * b;
}
欧几里得算法的效率分析表明：最坏情况发生在输入为连续斐波那契数时（如 gcd(Fₙ, Fₙ₋₁)），此时需要约 log_φ(n) 步。这是因为斐波那契数的比值趋近于黄金比例 φ。


扩展欧几里得算法不仅计算 gcd(a, b)，还找到整数 x, y 使得 ax + by = gcd(a, b)（Bézout 等式）。这在计算模逆元时至关重要。


function extendedGcd(a: number, b: number): { gcd: number; x: number; y: number } {
  if (b === 0) return { gcd: a, x: 1, y: 0 };
  const { gcd: g, x: x1, y: y1 } = extendedGcd(b, a % b);
  return { gcd: g, x: y1, y: x1 - Math.floor(a / b) * y1 };
}
GCD 在编程中的常见应用：


    

  • 分数化简：将 a/b 化为最简分数，分子分母同除以 gcd(a, b)
    • 

  • 时间调度：两个周期为 a 和 b 的事件同时发生的周期为 lcm(a, b)
    • 

  • 数据分片：将数据均匀分到 gcd(n, m) 组中
    • 



模算术与同余
同余关系 a ≡ b (mod n) 表示 a 和 b 除以 n 的余数相同，等价于 n | (a - b)。同余关系是整数上的等价关系（自反、对称、传递），将整数划分为 n 个等价类（余数类）{0, 1, 2, ..., n-1}。


模算术保持加法和乘法的基本运算律：


    

  • (a + b) mod n = ((a mod n) + (b mod n)) mod n
    • 

  • (a × b) mod n = ((a mod n) × (b mod n)) mod n
    • 

  • (a - b) mod n = ((a mod n) - (b mod n) + n) mod n
    • 



这些性质使得大数运算可以在中间步骤取模，避免溢出。这在密码学中至关重要——RSA 中的模幂运算 aᵉ mod n 利用反复平方法（Repeated Squaring）在 O(log e) 次乘法内完成。


function modPow(base: bigint, exp: bigint, mod: bigint): bigint {
  let result = 1n;
  base = base % mod;
  while (exp > 0n) {
    if (exp % 2n === 1n) {
      result = (result * base) % mod;
    }
    exp = exp / 2n;
    base = (base * base) % mod;
  }
  return result;
}
注意：模运算不保持除法。(a / b) mod n ≠ ((a mod n) / (b mod n)) mod n。要在模运算中"除以 b"，需要乘以 b 的模逆元。


模逆元：a 的模 n 逆元是满足 a × a⁻¹ ≡ 1 (mod n) 的整数 a⁻¹。模逆元存在当且仅当 gcd(a, n) = 1。可以通过扩展欧几里得算法计算。


function modInverse(a: number, n: number): number | null {
  const { gcd: g, x } = extendedGcd(a, n);
  if (g !== 1) return null;
  return ((x % n) + n) % n;
}
素数与素性检测
素数是大于 1 且只有 1 和自身两个因子的正整数。算术基本定理说：每个大于 1 的正整数都可以唯一地（不考虑顺序）分解为素数的乘积。这个定理是整个数论的基石。


素数的分布：小于 n 的素数个数约为 n/ln(n)（素数定理）。这意味着随机选取的大整数是素数的概率约为 1/ln(n)。对于 1024 位整数，约每 710 个就有一个素数。


试除法检测素性：检查 2 到 √n 的所有整数是否整除 n。时间复杂度 O(√n)。


埃拉托斯特尼筛法（Sieve of Eratosthenes）找出 2 到 n 的所有素数，时间复杂度 O(n log log n)。


function sieve(n: number): boolean[] {
  const isPrime = new Array(n + 1).fill(true);
  isPrime[0] = isPrime[1] = false;

  for (let i = 2; i * i <= n; i++) {
    if (isPrime[i]) {
      for (let j = i * i; j <= n; j += i) {
        isPrime[j] = false;
      }
    }
  }

  return isPrime;
}

理论意义





Miller-Rabin 素性检测是实际中最常用的大数素性测试算法。它是概率性的——如果判定为合数则一定正确，如果判定为素数则有极小的错误概率（可通过多次测试降低）。密码库中生成 RSA 密钥对时使用的就是 Miller-Rabin。


模运算在工程中的应用
哈希函数：h(k) = k mod m 将键映射到 {0, ..., m-1}。选择 m 为素数可以减少碰撞——因为素数与大多数输入的 pattern 互素，分布更均匀。


循环缓冲区：用数组实现固定大小的队列，next = (current + 1) % capacity。这是操作系统、网络缓冲区和音频处理中的基本数据结构。


校验和与 CRC：循环冗余校验（CRC）利用多项式的模运算来检测数据传输中的错误。CRC-32 广泛用于网络协议和文件格式（如 ZIP、PNG）。


RSA 加密：基于大素数分解的困难性。选择两个大素数 p, q，计算 n = pq。加密 c = mᵉ mod n，解密 m = cᵈ mod n，其中 ed ≡ 1 (mod φ(n))。整个系统建立在模幂运算和模逆元之上。


小结
    

  • gcd 和 lcm 是整除性的核心工具，欧几里得算法以 O(log n) 效率计算 GCD
    • 

  • 同余关系是整数上的等价关系，将整数划分为 n 个余数类
    • 

  • 模算术保持加法和乘法，但不保持除法——除法需要模逆元
    • 

  • 模逆元存在当且仅当 gcd(a, n) = 1，可通过扩展欧几里得算法计算
    • 

  • 算术基本定理保证每个整数有唯一的素因数分解
    • 

  • 素数哈希表大小的选择利用了素数与大多数 pattern 互素的性质
    • 

  • RSA 加密完全建立在模幂运算和大素数分解的困难性之上
