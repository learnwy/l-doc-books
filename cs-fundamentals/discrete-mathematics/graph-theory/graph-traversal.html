图的遍历

核心概念

图的遍历（Graph Traversal）是从某个顶点出发，按照特定策略系统地访问图中所有可达顶点的过程。两种基本遍历策略——广度优先搜索（BFS）和深度优先搜索（DFS）——是几乎所有图算法的基础。它们不仅用于遍历本身，更是解决最短路径、连通性、拓扑排序、环检测等问题的核心工具。

BFS 按"层次"逐步探索，先访问距起点近的顶点；DFS 沿着一条路径深入到底再回溯。两者的区别在于使用的数据结构：BFS 用队列，DFS 用栈（或递归调用栈）。

广度优先搜索（BFS）
BFS 从起始顶点开始，先访问所有距离为 1 的顶点，再访问距离为 2 的顶点，以此类推。BFS 的关键性质是：在无权图中，BFS 找到的路径就是最短路径。


BFS 的实现使用队列。每次从队列取出一个顶点 u，遍历 u 的所有未访问邻居，将它们标记为已访问并加入队列。


function bfs(graph: Map<number, number[]>, start: number): Map<number, number> {
  const distance = new Map<number, number>();
  const queue: number[] = [start];
  distance.set(start, 0);

  while (queue.length > 0) {
    const u = queue.shift()!;
    for (const v of graph.get(u) ?? []) {
      if (!distance.has(v)) {
        distance.set(v, distance.get(u)! + 1);
        queue.push(v);
      }
    }
  }

  return distance;
}
BFS 的应用场景：


    

  • 最短路径（无权图）：BFS 天然计算从起点到所有顶点的最短距离
    • 

  • 层次遍历：按层访问树或图中的节点（如二叉树的层序遍历）
    • 

  • 连通性检测：从一个顶点出发 BFS 能到达的所有顶点构成一个连通分量
    • 

  • 二部图判定：BFS 中交替着色，如果发现同色邻居则不是二部图
    • 

  • 社交网络中的 N 度人脉：BFS 遍历恰好 N 层就得到 N 度人脉
    • 



在 Web 领域，BFS 最直接的应用是网页爬虫。从种子 URL 出发，将当前页面的所有链接加入队列，逐层爬取。BFS 策略保证先爬取"距离近"的页面，适合发现网站的核心结构。


深度优先搜索（DFS）
DFS 从起始顶点出发，沿着一条路径深入到无法继续前进时回溯，然后探索下一条路径。DFS 可以用递归或显式栈实现。


function dfs(graph: Map<number, number[]>, start: number, visited: Set<number> = new Set()): number[] {
  visited.add(start);
  const result = [start];

  for (const neighbor of graph.get(start) ?? []) {
    if (!visited.has(neighbor)) {
      result.push(...dfs(graph, neighbor, visited));
    }
  }

  return result;
}

回边的存在 ⟺ 图中有环。这是 DFS 环检测的理论基础。在有向图中，如果 DFS 过程中遇到一个正在访问（灰色）的顶点，就发现了一条回边，即图中存在环。


function hasCycle(graph: Map<number, number[]>, n: number): boolean {
  const WHITE = 0,
    GRAY = 1,
    BLACK = 2;
  const color = new Array(n).fill(WHITE);

  const dfsVisit = (u: number): boolean => {
    color[u] = GRAY;
    for (const v of graph.get(u) ?? []) {
      if (color[v] === GRAY) return true;
      if (color[v] === WHITE && dfsVisit(v)) return true;
    }
    color[u] = BLACK;
    return false;
  };

  for (let i = 0; i < n; i++) {
    if (color[i] === WHITE && dfsVisit(i)) return true;
  }
  return false;
}
连通性与连通分量
连通性是图论中最基本的结构性质。无向图是连通的，当且仅当任意两个顶点之间存在路径。如果图不连通，它由若干连通分量组成，每个分量是一个极大连通子图。


对无向图，一次完整的 BFS 或 DFS（从未访问的顶点重启）可以在 O(n+m) 时间内找到所有连通分量。


对有向图，连通性更复杂。强连通分量（SCC）是有向图中任意两个顶点之间都有有向路径的极大子图。Tarjan 算法和 Kosaraju 算法都能在 O(n+m) 时间内找到所有 SCC。


SCC 在工程中的应用：


    

  • 模块循环依赖检测：如果模块依赖图中存在包含 2+ 个模块的 SCC，就存在循环依赖
    • 

  • 网页排名：Google 的 PageRank 算法利用了网页链接图的 SCC 结构
    • 

  • 编译器优化：程序控制流图的 SCC 对应循环结构，用于循环优化
    • 



割点（Cut Vertex）和桥（Bridge）是连通性分析中的重要概念。删除割点后图不连通，删除桥后图不连通。在网络设计中，割点和桥代表单点故障——如果该节点或链路失效，整个网络将分裂。Tarjan 的 DFS 算法可以在 O(n+m) 时间内找到所有割点和桥。


最短路径算法
Dijkstra 算法解决非负权图的单源最短路径问题。使用优先队列（最小堆），时间复杂度 O((n+m) log n)。


Bellman-Ford 算法可以处理负权边（但不能有负权环），时间复杂度 O(nm)。它还能检测负权环的存在。


Floyd-Warshall 算法求解全源最短路径，时间复杂度 O(n³)。它与前面讨论的传递闭包（Warshall 算法）本质相同，只是将布尔运算替换为距离运算。

在 Web 开发中，路由算法（如 React Router 的路径匹配）虽然不直接使用 Dijkstra，但地图导航、CDN 路由选择、网络路由协议（OSPF 使用 Dijkstra）都是最短路径算法的直接应用。


小结
    

  • BFS 和 DFS 的时间复杂度都是 O(n+m)，区别在于遍历顺序和适用场景
    • 

  • BFS 保证无权图的最短路径，DFS 擅长回溯、环检测和拓扑分析
    • 

  • DFS 边分类中，回边的存在等价于图中有环
    • 

  • 强连通分量检测可用于模块循环依赖分析
    • 

  • 割点和桥是网络中的单点故障，Tarjan 算法可在线性时间内找到
    • 

  • Dijkstra 适用于非负权图，Bellman-Ford 处理负权边，Floyd-Warshall 求全源最短路径
    • 

  • 图遍历算法是搜索引擎爬虫、社交网络分析和网络路由的核心工具
    •
