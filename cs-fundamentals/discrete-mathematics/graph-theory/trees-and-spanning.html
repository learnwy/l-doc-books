树与生成树

核心概念

树（Tree）是图论中最重要的特殊图类——它是一个连通且无环的无向图。等价地，树可以定义为：任意两个顶点之间恰好有一条路径的图。具有 n 个顶点的树恰好有 n-1 条边。

树在计算机科学中无处不在：文件系统的目录结构、DOM 树、AST（抽象语法树）、二叉搜索树、B 树、最小生成树。树结构的核心优势在于：它以最少的边实现了全连通——去掉任何一条边就不连通，加上任何一条边就产生环。

生成树（Spanning Tree）是图 G 的一个子图，它包含 G 的所有顶点且是一棵树。任何连通图都至少有一个生成树。最小生成树（MST）是加权图中边权之和最小的生成树，在网络设计中用于找到最低成本的全连接方案。

树的性质与特征
树有许多等价的特征定义，理解它们之间的关系有助于灵活运用：


    

  • G 是连通的且有 n-1 条边
    • 

  • G 是无环的且有 n-1 条边
    • 

  • G 中任意两个顶点之间恰有一条简单路径
    • 

  • G 是连通的，但删除任何一条边后不连通
    • 

  • G 是无环的，但添加任何一条边后产生恰好一个环
    • 



根树（Rooted Tree）是指定了一个特殊顶点（根）的树。根树中，每个非根节点有唯一的父节点，从根到任意节点的路径唯一。根树的深度（高度）是根到最远叶节点的路径长度。


二叉树是每个节点最多有两个子节点的根树。满二叉树的叶节点数 = 内部节点数 + 1，具有 n 个节点的二叉树高度至少为 ⌊log₂n⌋。这些性质直接关系到基于树的数据结构（BST、堆）的性能。


interface TreeNode<T> {
  value: T;
  children: TreeNode<T>[];
}

function treeHeight<T>(node: TreeNode<T>): number {
  if (node.children.length === 0) return 0;
  return 1 + Math.max(...node.children.map(treeHeight));
}

function countLeaves<T>(node: TreeNode<T>): number {
  if (node.children.length === 0) return 1;
  return node.children.reduce((sum, child) => sum + countLeaves(child), 0);
}

function countEdges<T>(node: TreeNode<T>): number {
  return node.children.length + node.children.reduce((sum, child) => sum + countEdges(child), 0);
}
Cayley 公式：n 个有标记顶点的不同树有 nⁿ⁻² 棵。例如，3 个顶点有 3¹ = 3 棵不同的标记树，4 个顶点有 4² = 16 棵。这个公式可以通过 Prüfer 序列证明——每棵标记树唯一对应一个长度为 n-2 的序列。


Prüfer 序列的构造：反复删除标记最小的叶节点，记录其邻居，直到只剩两个节点。逆过程可以从 Prüfer 序列还原出原树。这个双射证明了标记树的数量恰好是 nⁿ⁻²（序列中每个位置有 n 种选择，共 n-2 个位置）。


树的直径是树中最长路径的长度。可以通过两次 BFS 计算：第一次从任意节点出发找到最远节点 u，第二次从 u 出发找到最远节点 v，u 到 v 的距离就是直径。这个 O(n) 算法的正确性基于树的路径唯一性。


最小生成树算法
Kruskal 算法：按边权从小到大排序，依次添加不产生环的边。使用并查集检测环。时间复杂度 O(m log m)。


function kruskalMST(
  n: number,
  edges: Array<{ u: number; v: number; weight: number }>,
): Array<{ u: number; v: number; weight: number }> {
  edges.sort((a, b) => a.weight - b.weight);
  const uf = new UnionFind(n);
  const mst: typeof edges = [];

  for (const edge of edges) {
    if (uf.find(edge.u) !== uf.find(edge.v)) {
      uf.union(edge.u, edge.v);
      mst.push(edge);
      if (mst.length === n - 1) break;
    }
  }

  return mst;
}
Prim 算法：从任意顶点开始，每次将连接"已访问"和"未访问"顶点的最小权边加入。使用优先队列（最小堆），时间复杂度 O((n+m) log n)。


两种算法的选择：Kruskal 适合稀疏图（按边操作），Prim 适合稠密图（按顶点操作）。

MST 的关键性质——切割性质（Cut Property）：对于图的任意切割（将顶点分为两组），跨越切割的最小权边一定属于某棵 MST。这是 Kruskal 和 Prim 算法正确性的理论基础。


生成树在工程中的应用
网络设计：在建设城市间的通信网络时，MST 给出了连接所有城市的最低成本方案。铺设光纤、建设公路网络都可以建模为 MST 问题。


聚类分析：Kruskal 算法的中间状态可以用于层次聚类。按边权从小到大合并，形成的森林在不同阶段对应不同粒度的聚类。删除 MST 中最长的 k-1 条边，得到 k 个簇。这种基于 MST 的聚类方法称为单链接聚类（Single-Linkage Clustering），能自然地处理非球形的簇结构。


function mstClustering(n: number, edges: Array<{ u: number; v: number; weight: number }>, k: number): number[][] {
  edges.sort((a, b) => a.weight - b.weight);
  const uf = new UnionFind(n);
  let edgesAdded = 0;

  for (const edge of edges) {
    if (uf.find(edge.u) !== uf.find(edge.v)) {
      if (edgesAdded >= n - k) break;
      uf.union(edge.u, edge.v);
      edgesAdded++;
    }
  }

  const clusters = new Map<number, number[]>();
  for (let i = 0; i < n; i++) {
    const root = uf.find(i);
    if (!clusters.has(root)) clusters.set(root, []);
    clusters.get(root)!.push(i);
  }
  return [...clusters.values()];
}
网络协议：以太网中的生成树协议（STP）用于在交换机构成的图中找到一棵生成树，避免数据包在环路中无限循环。STP 本质上是一个分布式的生成树构建算法。


增量 MST 维护：在动态场景中（边的权值变化或新边加入），需要高效更新 MST。如果添加一条新边 (u,v)，它会与 MST 中 u 到 v 的路径形成一个环。如果新边权小于环上最大边权，就用新边替换该最大边。这个操作可以用链式分解或 Euler Tour 树在 O(log n) 时间内完成。


电路设计：在 PCB 布线中，连接所有引脚的最短布线方案本质上是 Steiner 树问题（MST 的推广，允许添加中间点）。Steiner 树问题是 NP 困难的，但有良好的近似算法。


文件系统的目录结构是根树的直接应用。每个文件/目录是一个节点，父子关系定义了树的边。路径解析（从根到目标的路径查找）是树遍历的基本操作。


数据库索引中的 B 树和 B+ 树是平衡多路搜索树。B+ 树的所有数据存储在叶节点，内部节点仅存储索引键。B+ 树的高度通常为 3-4 层，即使存储数十亿条记录也只需 3-4 次磁盘 I/O 就能定位数据。


JSON/XML 解析的结果是树结构。DOM 树中的每个 HTML 元素是一个节点，父子关系对应嵌套关系。CSS 选择器的匹配过程本质上是树的模式匹配。


抽象语法树（AST）是编译器和代码分析工具的核心数据结构。源代码被解析为 AST 后，类型检查、代码优化、代码生成等后续步骤都在 AST 上进行。


决策树在机器学习中用于分类和回归。每个内部节点是一个特征判断，每个分支是判断结果，叶节点是预测值。决策树的深度直接影响模型的复杂度和过拟合风险。


小结
    

  • 树是连通无环图，n 个顶点恰好 n-1 条边，任意两点间有唯一路径
    • 

  • 树的五个等价定义从不同角度刻画了"最少边的连通图"和"最多边的无环图"
    • 

  • Cayley 公式 nⁿ⁻² 给出标记树的计数，Prüfer 序列提供了构造性证明
    • 

  • Kruskal（稀疏图）和 Prim（稠密图）是两种经典的 MST 算法
    • 

  • 切割性质是 MST 算法正确性的理论基石
    • 

  • MST 在网络设计、聚类分析和网络协议中有广泛的工程应用
    • 

  • 树结构（DOM、AST、文件系统）是软件工程中最常见的数据组织方式
    • 

  • B+树将树的高度控制在 3-4 层，是数据库索引的核心数据结构
    • 

  • 树的直径可以通过两次 BFS 在 O(n) 时间内计算，基于路径唯一性
    • 

  • 决策树、AST 和 DOM 树展示了树结构在不同领域（ML、编译器、Web）的普遍性
    •
