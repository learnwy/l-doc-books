图的基本概念

核心概念

图（Graph）是离散数学中最具应用价值的结构之一。一个图 G = (V, E) 由顶点集 V 和边集 E 组成，其中每条边连接 V 中的两个顶点。图可以用来建模任何"对象之间的关系"——社交网络中的好友关系、互联网中的链接关系、程序中的函数调用关系、城市之间的道路连接。

图论的核心在于：通过将实际问题抽象为图结构，利用图论的工具和算法来分析和求解。许多看似不同的问题（最短路径、网络流、任务调度、连通性分析）在图论框架下有统一的解法。

图的表示方法
图的数据表示方式直接影响算法的时间和空间复杂度。三种主要表示方法各有优劣。


邻接矩阵：用 n×n 的矩阵 A 表示，A[i][j] = 1（或权值）当且仅当存在从 i 到 j 的边。空间 O(n²)，查询边是否存在 O(1)，遍历某顶点的所有邻居 O(n)。适合稠密图。


邻接矩阵的一个独特优势是矩阵运算可以回答图论问题。A² 的 (i,j) 元素等于从 i 到 j 的长度为 2 的路径数。更一般地，Aᵏ 的 (i,j) 元素给出长度恰好为 k 的路径数。这在分析社交网络的 k 度关系时很有用。


邻接表：每个顶点存储一个邻居列表。空间 O(n + m)（m 为边数），遍历某顶点的所有邻居 O(deg(v))，但查询边是否存在 O(deg(v))。适合稀疏图，是最常用的表示方式。


边列表：直接存储所有边的列表。空间 O(m)，遍历所有边 O(m)，但查询特定边 O(m)。在 Kruskal 算法等需要按权值排序边的场景中使用。


interface AdjacencyList {
  vertices: number;
  edges: Map<number, number[]>;
}

const createGraph = (n: number): AdjacencyList => ({
  vertices: n,
  edges: new Map(Array.from({ length: n }, (_, i) => [i, []])),
});

const addEdge = (g: AdjacencyList, u: number, v: number): void => {
  g.edges.get(u)!.push(v);
  g.edges.get(v)!.push(u);
};

interface AdjacencyMatrix {
  vertices: number;
  matrix: number[][];
}

const createMatrixGraph = (n: number): AdjacencyMatrix => ({
  vertices: n,
  matrix: Array.from({ length: n }, () => new Array(n).fill(0)),
});

度数与握手定理
顶点的度数（Degree）是与该顶点相连的边数。在有向图中，分为入度（指向该顶点的边数）和出度（从该顶点出发的边数）。


握手定理：无向图中所有顶点的度数之和等于边数的两倍。∑ deg(v) = 2|E|。这是因为每条边贡献了两个端点的度数。


握手定理的推论：度数之和是偶数，因此度数为奇数的顶点个数必为偶数。这可以用来快速验证一个度数序列是否可能对应某个图。在网络诊断中，如果统计到的链路数与度数之和不匹配（∑deg ≠ 2m），说明拓扑数据有错误。


在有向图中，∑ in-deg(v) = ∑ out-deg(v) = |E|——每条边贡献一个出度和一个入度。


度数序列是将图中所有顶点的度数按非递增顺序排列得到的序列。Erdős–Gallai 定理给出了一个序列是否为某个简单图的度数序列的充要条件。


在实际应用中，度数分析可以揭示网络的拓扑特征。社交网络通常遵循幂律分布（少数节点有很高的度数），而网格网络的度数分布接近均匀。


function degreeStats(graph: AdjacencyList) {
  const degrees: number[] = [];
  for (let v = 0; v < graph.vertices; v++) {
    degrees.push(graph.edges.get(v)!.length);
  }
  const sum = degrees.reduce((a, b) => a + b, 0);
  const max = Math.max(...degrees);
  const avg = sum / graph.vertices;
  return { degrees, sum, max, avg, edgeCount: sum / 2 };
}
度数统计是图分析的第一步。通过 sum / 2 验证边数一致性，通过 max 和 avg 的比值判断是否存在超级节点（hub）。若 max ≫ avg，则该网络可能具有无标度（scale-free）特性。


特殊图类型
完全图 Kₙ：n 个顶点中任意两个都有边连接。边数为 C(n,2) = n(n-1)/2。K₃ 是三角形，K₄ 是四面体骨架。完全图用于表示"所有对象两两相关"的场景。完全图在算法分析中经常作为最坏情况出现。


二部图（Bipartite Graph）：顶点可以分为两组 U 和 V，所有边都连接 U 中的顶点和 V 中的顶点。判断一个图是否为二部图可以通过 BFS 着色来实现——如果能用两种颜色给所有顶点着色且相邻顶点颜色不同，则是二部图。二部图在匹配问题（任务分配、推荐系统）中有核心应用。


完全二部图 K_{m,n}：U 有 m 个顶点，V 有 n 个顶点，U 和 V 之间的所有 m×n 条边都存在。二部图的一个重要性质是它不包含奇数长度的环。


图的同构：两个图 G₁ 和 G₂ 同构意味着存在一一映射使得边关系完全对应。判断两个图是否同构是一个经典的计算复杂性问题——目前已知的最佳算法是准多项式时间的（Babai, 2015）。


正则图：每个顶点的度数都相同的图。k-正则图中每个顶点的度数为 k。Kₙ 是 (n-1)-正则图。Petersen 图是一个著名的 3-正则图。在网络设计中，正则图代表均匀连接的网络拓扑。


有向无环图（DAG）是计算机科学中最重要的图类型之一。DAG 不仅用于表示依赖关系（可进行拓扑排序），还是动态规划的基础结构——DP 的状态转移关系天然形成 DAG。编译器的数据流分析、电子表格的公式求值、Makefile 的构建顺序都基于 DAG。


平面图：能够画在平面上使得边不交叉的图。欧拉公式 V - E + F = 2（V 顶点数，E 边数，F 面数）是平面图的基本约束。由此可推出：对于简单连通平面图，E ≤ 3V - 6。这意味着 K₅ 和 K₃,₃ 不是平面图（Kuratowski 定理：一个图是平面图当且仅当它不包含 K₅ 或 K₃,₃ 的子划分）。平面图在电路板布线、地图着色等领域有直接应用。


稀疏图与稠密图的区分影响算法和数据结构的选择。边数 m 接近 n² 的为稠密图，m 接近 n 的为稀疏图。实际工程中的大多数图（社交网络、Web 链接图、代码调用图）都是稀疏图。

function isBipartite(graph: AdjacencyList): boolean {
  const color = new Map<number, number>();
  for (let start = 0; start < graph.vertices; start++) {
    if (color.has(start)) continue;
    const queue = [start];
    color.set(start, 0);
    while (queue.length > 0) {
      const u = queue.shift()!;
      for (const v of graph.edges.get(u)!) {
        if (!color.has(v)) {
          color.set(v, 1 - color.get(u)!);
          queue.push(v);
        } else if (color.get(v) === color.get(u)) {
          return false;
        }
      }
    }
  }
  return true;
}
小结
    

  • 图 G = (V, E) 是建模"对象间关系"的通用数学结构
    • 

  • 邻接表适合稀疏图（空间 O(n+m)），邻接矩阵适合稠密图（查边 O(1)）
    • 

  • 握手定理 ∑deg = 2|E| 是图论最基本的等式，用于验证图数据的一致性
    • 

  • 二部图判定可以通过 BFS 双色着色在 O(n+m) 时间内完成
    • 

  • 平面图的欧拉公式 V-E+F=2 约束了边数上限 E ≤ 3V-6
    • 

  • 图的度数分布揭示网络拓扑特征：社交网络遵循幂律，网格网络接近均匀
    • 

  • 选择正确的图表示方式是图算法效率的基础
    • 

  • 二部图判定、连通性分析、环检测是图论最基础的问题，都有 O(n+m) 的高效算法
    • 

  • 在工程实践中，大多数图是稀疏的，邻接表是默认的最佳选择
