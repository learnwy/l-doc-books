语言模型检索

核心概念

语言模型检索（Language Model for IR）是概率检索的另一个理论分支，由 Ponte 和 Croft 在 1998 年提出。与 BM25 估计 P(R|q,d)（给定查询和文档的相关概率）不同，语言模型方法为每个文档构建一个概率语言模型 M_d，然后计算查询 q 在该模型下的生成概率 P(q|M_d)。直觉上，如果一个文档的语言模型能够以高概率「生成」用户的查询，那么该文档很可能与查询相关。

查询似然模型
查询似然模型（Query Likelihood Model）假设每个文档 d 定义了一个一元语言模型（Unigram Language Model）M_d，查询 q 中的每个词项 t 的生成概率为 P(t|M_d)。假设查询词项之间独立，查询的联合生成概率为所有词项概率的乘积：P(q|M_d) = ∏ P(t|M_d)。实际计算中使用对数概率之和避免数值下溢。


文档语言模型的最大似然估计（MLE）直接使用词频：P_MLE(t|d) = tf(t,d) / |d|，其中 |d| 是文档长度。但 MLE 有一个严重问题——对于文档中未出现的词项，概率为零，导致只要查询中有一个词不在文档中，整个查询的概率就为零。这就是平滑（Smoothing）的必要性。


interface LanguageModel {
  probability(term: string): number;
  logLikelihood(query: ReadonlyArray<string>): number;
}

const createMLEModel = (termFreqs: Map<string, number>, docLength: number): LanguageModel => ({
  probability: (term) => (termFreqs.get(term) ?? 0) / docLength,
  logLikelihood: (query) =>
    query.reduce((sum, term) => {
      const p = (termFreqs.get(term) ?? 0) / docLength;
      return p > 0 ? sum + Math.log(p) : -Infinity;
    }, 0),
});

const queryLikelihoodScore = (query: ReadonlyArray<string>, docModel: LanguageModel): number =>
  docModel.logLikelihood(query);
平滑方法
平滑是语言模型检索中最关键的技术环节。平滑的核心思想是将一部分概率质量从文档中出现的词项转移到未出现的词项上，通常使用集合级别的语言模型 P(t|C) 作为背景概率。


Jelinek-Mercer 平滑（也称 JM 平滑或线性插值）使用固定权重 λ 在文档模型和集合模型之间做线性插值：P(t|d) = (1-λ) × P_MLE(t|d) + λ × P(t|C)。λ 控制平滑强度——λ 越大，越依赖集合背景模型。


Dirichlet 平滑使用伪计数方法：P(t|d) = (tf(t,d) + μ × P(t|C)) / (|d| + μ)。μ 是 Dirichlet 先验参数，控制平滑强度。与 JM 平滑不同，Dirichlet 平滑的平滑强度随文档长度自适应调整——短文档平滑更多（因为 MLE 估计不可靠），长文档平滑更少。


interface SmoothingConfig {
  readonly method: 'jelinek-mercer' | 'dirichlet' | 'absolute-discount';
  readonly lambda?: number;
  readonly mu?: number;
  readonly delta?: number;
}

const createSmoothedModel = (
  termFreqs: Map<string, number>,
  docLength: number,
  collectionModel: LanguageModel,
  config: SmoothingConfig,
): LanguageModel => {
  const probability = (term: string): number => {
    const tf = termFreqs.get(term) ?? 0;
    const pCollection = collectionModel.probability(term);
    switch (config.method) {
      case 'jelinek-mercer': {
        const lambda = config.lambda ?? 0.1;
        return (1 - lambda) * (tf / docLength) + lambda * pCollection;
      }
      case 'dirichlet': {
        const mu = config.mu ?? 2000;
        return (tf + mu * pCollection) / (docLength + mu);
      }
      case 'absolute-discount': {
        const delta = config.delta ?? 0.7;
        const uniqueTerms = termFreqs.size;
        const discounted = Math.max(tf - delta, 0) / docLength;
        const backoff = ((delta * uniqueTerms) / docLength) * pCollection;
        return discounted + backoff;
      }
    }
  };
  return {
    probability,
    logLikelihood: (query) => query.reduce((sum, term) => sum + Math.log(probability(term)), 0),
  };
};

相关模型与查询扩展
相关模型（Relevance Model，RM）是语言模型框架下的查询扩展方法。RM 的核心思想是估计一个「相关性语言模型」P(w|R)——即在与查询相关的文档中，每个词项的出现概率。RM1 通过伪相关性反馈（假设初始检索结果的前 K 个文档是相关的）来估计这个模型。


RM3 是 RM1 与原始查询的线性插值，是最常用的变体：P_RM3(w|q) = α × P(w|q) + (1-α) × P_RM1(w|q)。其中 α 控制原始查询和扩展词项的相对重要性。RM3 在许多 TREC 评测中表现优于单纯的 BM25 或语言模型检索。


interface RelevanceModel {
  estimate(query: ReadonlyArray<string>, topDocs: ReadonlyArray<ScoredDocument>, topTerms: number): Map<string, number>;
}

interface ScoredDocument {
  readonly id: string;
  readonly score: number;
  readonly termFreqs: Map<string, number>;
  readonly length: number;
}

const estimateRM1 = (
  query: ReadonlyArray<string>,
  topDocs: ReadonlyArray<ScoredDocument>,
  vocabulary: ReadonlyArray<string>,
  collectionModel: LanguageModel,
  mu: number,
): Map<string, number> => {
  const rm1 = new Map<string, number>();
  for (const word of vocabulary) {
    let prob = 0;
    for (const doc of topDocs) {
      const pWordDoc = (doc.termFreqs.get(word) ?? 0 + mu * collectionModel.probability(word)) / (doc.length + mu);
      let pQueryDoc = 0;
      for (const qTerm of query) {
        pQueryDoc += Math.log(
          ((doc.termFreqs.get(qTerm) ?? 0) + mu * collectionModel.probability(qTerm)) / (doc.length + mu),
        );
      }
      prob += Math.exp(pQueryDoc) * pWordDoc;
    }
    if (prob > 0) rm1.set(word, prob);
  }
  return normalizeDistribution(rm1);
};

const rm3Interpolation = (
  originalQuery: Map<string, number>,
  rm1: Map<string, number>,
  alpha: number,
): Map<string, number> => {
  const rm3 = new Map<string, number>();
  const allTerms = new Set([...originalQuery.keys(), ...rm1.keys()]);
  for (const term of allTerms) {
    const origWeight = originalQuery.get(term) ?? 0;
    const rm1Weight = rm1.get(term) ?? 0;
    rm3.set(term, alpha * origWeight + (1 - alpha) * rm1Weight);
  }
  return rm3;
};
小结
    

  • 语言模型检索为每个文档构建语言模型，通过查询的生成概率 P(q|M_d) 排序文档
    • 

  • 平滑是语言模型检索的关键环节，解决未出现词项概率为零的问题
    • 

  • Dirichlet 平滑通过自适应文档长度调整平滑强度，是短查询场景的最佳选择
    • 

  • JM 平滑使用固定权重插值，更适合长查询和详细描述型查询
    • 

  • 相关模型（RM3）通过伪反馈估计相关性语言模型，是语言模型框架下最有效的查询扩展方法
    • 

  • 语言模型框架的理论优雅性使其成为 IR 研究中与 BM25 并列的两大范式之一
    •
