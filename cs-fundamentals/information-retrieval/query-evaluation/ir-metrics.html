IR 评价指标

核心概念

IR 评价指标（Evaluation Metrics）是衡量信息检索系统性能的定量标准。由于「相关性」本身是主观的，IR 评价依赖于人工标注的评测数据集——对每个查询，标注者判断哪些文档是相关的（通常使用多级相关性标注）。系统的性能通过比较其返回结果与标注结果的吻合程度来度量。

精确率、召回率与 F1
精确率（Precision）和召回率（Recall）是 IR 评价最基础的两个指标。精确率衡量「返回的结果中有多少是相关的」，召回率衡量「所有相关文档中有多少被返回了」。


精确率 = |检索到的相关文档| / |检索到的文档|。召回率 = |检索到的相关文档| / |所有相关文档|。两个指标之间存在天然的权衡——提高召回率（返回更多结果）通常会降低精确率（混入更多不相关结果），反之亦然。


interface RetrievalResult {
  readonly docId: string;
  readonly rank: number;
  readonly score: number;
}

interface RelevanceJudgment {
  readonly docId: string;
  readonly relevance: number;
}

const precision = (retrieved: ReadonlyArray<RetrievalResult>, relevant: Set<string>): number => {
  const retrievedRelevant = retrieved.filter((r) => relevant.has(r.docId)).length;
  return retrieved.length > 0 ? retrievedRelevant / retrieved.length : 0;
};

const recall = (retrieved: ReadonlyArray<RetrievalResult>, relevant: Set<string>): number => {
  const retrievedRelevant = retrieved.filter((r) => relevant.has(r.docId)).length;
  return relevant.size > 0 ? retrievedRelevant / relevant.size : 0;
};

const f1Score = (p: number, r: number): number => {
  return p + r > 0 ? (2 * p * r) / (p + r) : 0;
};

const precisionAtK = (retrieved: ReadonlyArray<RetrievalResult>, relevant: Set<string>, k: number): number =>
  precision(retrieved.slice(0, k), relevant);
F1 分数是精确率和召回率的调和平均，提供了两者之间的单一综合度量。当需要在精确率和召回率之间倾斜时，可以使用 Fβ 分数——β>1 更侧重召回率（适合法律检索等不能遗漏的场景），β<1 更侧重精确率（适合推荐系统等追求精准的场景）。


MAP 与 MRR
平均精确率（Average Precision，AP）是考虑排序位置的核心指标。它在每个相关文档被召回的位置计算精确率，然后取平均。AP 的优势在于同时奖励两个特性：将相关文档排在更前面、召回更多相关文档。


MAP（Mean Average Precision）是所有查询 AP 值的平均，是 TREC 评测中最常用的主指标。


const averagePrecision = (retrieved: ReadonlyArray<RetrievalResult>, relevant: Set<string>): number => {
  let relevantCount = 0;
  let sumPrecision = 0;
  for (let i = 0; i < retrieved.length; i++) {
    if (relevant.has(retrieved[i].docId)) {
      relevantCount++;
      sumPrecision += relevantCount / (i + 1);
    }
  }
  return relevant.size > 0 ? sumPrecision / relevant.size : 0;
};

const meanAveragePrecision = (
  queryResults: ReadonlyArray<{
    retrieved: ReadonlyArray<RetrievalResult>;
    relevant: Set<string>;
  }>,
): number => {
  const aps = queryResults.map((qr) => averagePrecision(qr.retrieved, qr.relevant));
  return aps.reduce((sum, ap) => sum + ap, 0) / aps.length;
};
MRR（Mean Reciprocal Rank）是另一个常用的排序指标，它关注的是第一个相关文档出现在排序列表中的位置。Reciprocal Rank = 1 / (第一个相关文档的排名)。MRR 适合评估「找到一个好答案」的场景，如问答系统和导航型搜索。

NDCG 与多级相关性
NDCG（Normalized Discounted Cumulative Gain）是处理多级相关性标注的标准指标。与二值相关性（相关/不相关）不同，多级标注允许区分「非常相关」、「较相关」和「略微相关」，NDCG 能够在评分中反映这种差异。


DCG（Discounted Cumulative Gain）的计算：对排序列表中每个位置 i，将该位置文档的相关性得分 rel(i) 除以位置折扣 log₂(i+1)，然后累加。NDCG 是 DCG 与理想排序（IDCG）的比值，归一化到 [0, 1] 范围。


const dcg = (rankedDocs: ReadonlyArray<string>, relevanceMap: Map<string, number>, k: number): number => {
  let score = 0;
  for (let i = 0; i < Math.min(k, rankedDocs.length); i++) {
    const rel = relevanceMap.get(rankedDocs[i]) ?? 0;
    score += (Math.pow(2, rel) - 1) / Math.log2(i + 2);
  }
  return score;
};

const ndcg = (rankedDocs: ReadonlyArray<string>, relevanceMap: Map<string, number>, k: number): number => {
  const actualDCG = dcg(rankedDocs, relevanceMap, k);
  const idealRanking = [...relevanceMap.entries()].sort(([, a], [, b]) => b - a).map(([id]) => id);
  const idealDCG = dcg(idealRanking, relevanceMap, k);
  return idealDCG === 0 ? 0 : actualDCG / idealDCG;
};

const computeAllMetrics = (
  retrieved: ReadonlyArray<RetrievalResult>,
  judgments: ReadonlyArray<RelevanceJudgment>,
  k: number,
): MetricsReport => {
  const relevantSet = new Set(judgments.filter((j) => j.relevance > 0).map((j) => j.docId));
  const relevanceMap = new Map(judgments.map((j) => [j.docId, j.relevance]));
  const rankedIds = retrieved.map((r) => r.docId);
  return {
    precisionAtK: precisionAtK(retrieved, relevantSet, k),
    recallAtK: recall(retrieved.slice(0, k), relevantSet),
    ap: averagePrecision(retrieved, relevantSet),
    ndcgAtK: ndcg(rankedIds, relevanceMap, k),
    mrr: 1 / (rankedIds.findIndex((id) => relevantSet.has(id)) + 1),
  };
};
统计显著性检验
当比较两个检索系统时，仅仅比较 MAP 或 NDCG 的均值是不够的——需要通过统计检验来判断差异是否具有统计显著性。配对 t 检验和 Wilcoxon 符号秩检验是 IR 评估中最常用的两种检验方法。


配对 t 检验假设每个查询的指标差异服从正态分布。Wilcoxon 检验不做分布假设，适用于 AP 等可能不服从正态分布的指标。通常使用 p<0.05 作为显著性阈值，但在多重比较场景下需要使用 Bonferroni 校正。


Bootstrap 重采样是另一种评估置信区间的方法——从查询集中有放回地重复抽样，每次计算指标均值，最终得到指标的经验分布和置信区间。


小结
    

  • IR 评价依赖人工标注的评测数据集，通过比较系统输出与标注结果来度量性能
    • 

  • 精确率和召回率是最基础的评价指标，F1 提供两者的综合度量
    • 

  • MAP 是考虑排序位置的全面指标，同时奖励排名靠前和覆盖全面
    • 

  • NDCG 处理多级相关性标注，通过位置折扣和理想排序归一化衡量排序质量
    • 

  • MRR 关注首个相关结果的位置，适合问答和导航型搜索场景
    • 

  • 系统比较需要统计显著性检验，配对 t 检验和 Bootstrap 重采样是常用方法
    •
