向量空间模型

核心概念

向量空间模型（Vector Space Model，VSM）是信息检索领域最具影响力的检索模型之一，由 Gerard Salton 在 1970 年代提出。VSM 的核心思想是将文档和查询都表示为高维向量空间中的向量，通过向量之间的几何关系（通常是余弦相似度）来度量相关性。这一思想不仅奠定了经典 IR 的数学基础，也深刻影响了现代 Embedding 模型的设计。

文档向量化与词项加权
VSM 的第一步是将文档转换为向量表示。向量的每个维度对应词汇表中的一个词项，维度的值是该词项在文档中的权重。词项加权的目标是让权重反映词项对文档内容的重要程度。


最基本的加权方案是词频（Term Frequency，TF）——词项在文档中出现的次数。但纯粹的 TF 有明显问题：高频词（如 "the"、"is"）获得高权重但信息量低。逆文档频率（Inverse Document Frequency，IDF）通过惩罚在多数文档中出现的词项来解决这个问题。TF-IDF 是两者的组合，是 VSM 的标准加权方案。


interface VectorSpaceModel {
  readonly vocabulary: ReadonlyArray<string>;
  readonly documentVectors: Map<string, ReadonlyArray<number>>;
  readonly idf: ReadonlyArray<number>;
}

const computeTF = (term: string, document: ReadonlyArray<string>): number => {
  const count = document.filter((t) => t === term).length;
  return count > 0 ? 1 + Math.log10(count) : 0;
};

const computeIDF = (term: string, documents: ReadonlyArray<ReadonlyArray<string>>): number => {
  const df = documents.filter((doc) => doc.includes(term)).length;
  return df > 0 ? Math.log10(documents.length / df) : 0;
};

const computeTFIDF = (
  term: string,
  document: ReadonlyArray<string>,
  documents: ReadonlyArray<ReadonlyArray<string>>,
): number => {
  return computeTF(term, document) * computeIDF(term, documents);
};

const buildDocumentVector = (
  document: ReadonlyArray<string>,
  vocabulary: ReadonlyArray<string>,
  documents: ReadonlyArray<ReadonlyArray<string>>,
): ReadonlyArray<number> => {
  return vocabulary.map((term) => computeTFIDF(term, document, documents));
};
TF 的常见变体包括：原始频率（raw TF）、对数频率（1 + log tf）、归一化频率（tf / max_tf）和布尔频率（0 或 1）。对数频率是最常用的变体，它缓解了高频词项主导权重的问题——出现 100 次和 10 次的词项在重要性上的差异不应是 10 倍。

余弦相似度与文档排序
余弦相似度通过计算两个向量之间夹角的余弦值来度量它们的相似程度。取值范围在 [-1, 1] 之间，由于 TF-IDF 权重非负，实际范围是 [0, 1]。余弦值为 1 表示两个向量方向完全相同（完全相似），0 表示正交（不相关）。


余弦相似度的一个关键优势是它对向量长度不敏感——两个方向相同但长度不同的向量有相同的余弦值。这意味着文档长度不会直接影响相关性评分，避免了长文档因为词频更高而获得不公平的优势。


const cosineSimilarity = (v1: ReadonlyArray<number>, v2: ReadonlyArray<number>): number => {
  let dotProduct = 0;
  let norm1 = 0;
  let norm2 = 0;
  for (let i = 0; i < v1.length; i++) {
    dotProduct += v1[i] * v2[i];
    norm1 += v1[i] * v1[i];
    norm2 += v2[i] * v2[i];
  }
  const denominator = Math.sqrt(norm1) * Math.sqrt(norm2);
  return denominator === 0 ? 0 : dotProduct / denominator;
};

const rankDocuments = (
  queryVector: ReadonlyArray<number>,
  documentVectors: Map<string, ReadonlyArray<number>>,
  topK: number,
): ReadonlyArray<{ docId: string; score: number }> => {
  const scores = [...documentVectors.entries()].map(([docId, docVector]) => ({
    docId,
    score: cosineSimilarity(queryVector, docVector),
  }));
  return scores
    .filter((s) => s.score > 0)
    .sort((a, b) => b.score - a.score)
    .slice(0, topK);
};
相关性反馈与查询扩展
Rocchio 算法是 VSM 框架下最经典的查询优化方法。它利用用户对初始检索结果的相关性反馈（标记哪些文档相关、哪些不相关），自动修改查询向量以更接近相关文档、远离不相关文档。


Rocchio 公式为：q' = α × q + β × (相关文档向量均值) - γ × (不相关文档向量均值)。其中 α、β、γ 分别控制原始查询、正向反馈和负向反馈的影响程度。典型参数设置为 α=1, β=0.75, γ=0.15——正向反馈的权重远大于负向反馈，因为用户标记的不相关文档可能只是偶然不相关，不应过度惩罚。


interface RocchioConfig {
  readonly alpha: number;
  readonly beta: number;
  readonly gamma: number;
}

const rocchioUpdate = (
  originalQuery: ReadonlyArray<number>,
  relevantDocs: ReadonlyArray<ReadonlyArray<number>>,
  nonRelevantDocs: ReadonlyArray<ReadonlyArray<number>>,
  config: RocchioConfig,
): ReadonlyArray<number> => {
  const dim = originalQuery.length;
  const result = new Array<number>(dim).fill(0);
  const relMean = computeMeanVector(relevantDocs, dim);
  const nonRelMean = computeMeanVector(nonRelevantDocs, dim);
  for (let i = 0; i < dim; i++) {
    result[i] = config.alpha * originalQuery[i] + config.beta * relMean[i] - config.gamma * nonRelMean[i];
    result[i] = Math.max(0, result[i]);
  }
  return result;
};

const computeMeanVector = (vectors: ReadonlyArray<ReadonlyArray<number>>, dim: number): ReadonlyArray<number> => {
  if (vectors.length === 0) return new Array(dim).fill(0);
  const mean = new Array<number>(dim).fill(0);
  for (const vec of vectors) {
    for (let i = 0; i < dim; i++) mean[i] += vec[i];
  }
  return mean.map((v) => v / vectors.length);
};
伪相关性反馈（Pseudo Relevance Feedback）不需要用户参与——它假设初始检索结果中排名靠前的文档是相关的，直接将它们作为正向反馈输入 Rocchio 算法。虽然这个假设并不总是正确（查询漂移问题），但在多数情况下能够改善检索效果。


VSM 的局限与演进
VSM 的核心局限是「词袋假设」——它将文档视为词项的无序集合，丢失了词序和短语结构信息。"机器学习" 和 "学习机器" 在 VSM 中的表示完全相同。另一个局限是维度灾难——词汇表通常包含数万到数十万个词项，导致向量极其稀疏，计算效率低下。


这些局限推动了 IR 技术的两个演进方向。一是潜在语义分析（LSA / LSI），通过矩阵分解将高维稀疏向量映射到低维稠密空间，同时捕获词项之间的潜在语义关联。二是现代 Dense Retrieval，使用预训练 Transformer 模型将文本编码为低维稠密向量，从根本上解决了词汇鸿沟和维度灾难问题。

小结
    

  • 向量空间模型将文档和查询表示为高维向量，通过余弦相似度度量相关性
    • 

  • TF-IDF 是 VSM 的标准加权方案，对数 TF 和 IDF 分别从局部和全局两个维度评估词项重要性
    • 

  • 余弦相似度对向量长度不敏感，天然避免了文档长度偏置问题
    • 

  • Rocchio 算法通过相关性反馈迭代优化查询向量，伪反馈免去了用户参与
    • 

  • VSM 的词袋假设和维度灾难是其核心局限，推动了 LSA 到 Dense Retrieval 的技术演进
    • 

  • VSM 的向量化思想直接影响了现代 Embedding 模型，是理解当代语义检索的理论基础
    •
