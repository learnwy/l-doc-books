TF-IDF 权重计算

核心概念

TF-IDF（Term Frequency–Inverse Document Frequency）是信息检索中最基础也最重要的词项权重方案。其核心直觉简单而深刻：一个词在某篇文档中出现得越频繁（TF 高），同时在整个文档集合中出现得越稀少（IDF 高），那么这个词对该文档的区分能力就越强。TF-IDF 将这两个信号相乘得到最终权重，兼顾了词项在局部文档和全局语料库中的统计特征。

TF 计算变体
词频（Term Frequency）的最简单定义是词项 t 在文档 d 中的原始出现次数 f(t,d)。但原始频率存在问题：一个词出现 10 次并不意味着它比出现 1 次的词重要 10 倍。因此研究者提出了多种 TF 变体来缓解这一问题。


对数 TF 是最常用的变体：tf(t,d) = 1 + log(f(t,d))（当 f > 0 时），这使得 TF 的增长从线性变为对数级。布尔 TF 将所有非零频率视为 1，仅关注词是否出现而非频率。归一化 TF 将频率除以文档中最高频词的频率，消除文档长度的影响。


type TFScheme = 'raw' | 'log' | 'boolean' | 'augmented' | 'logAverage';

interface TFIDFConfig {
  readonly tfScheme: TFScheme;
  readonly idfScheme: 'standard' | 'smooth' | 'max' | 'probabilistic';
  readonly normalization: 'none' | 'cosine' | 'pivoted';
  readonly documentLengthAdjust: boolean;
}

function computeTF(rawFreq: number, scheme: TFScheme, maxFreq: number, avgFreq: number): number {
  switch (scheme) {
    case 'raw':
      return rawFreq;
    case 'log':
      return rawFreq > 0 ? 1 + Math.log(rawFreq) : 0;
    case 'boolean':
      return rawFreq > 0 ? 1 : 0;
    case 'augmented':
      return 0.5 + (0.5 * rawFreq) / maxFreq;
    case 'logAverage':
      return rawFreq > 0 ? (1 + Math.log(rawFreq)) / (1 + Math.log(avgFreq)) : 0;
  }
}
增强 TF（Augmented TF）公式为 0.5 + 0.5 × f(t,d) / max_t' f(t',d)，通过除以文档中最高频词的频率并加上 0.5 基线值来归一化，防止长文档因词频绝对值高而获得不合理的高权重。


IDF 计算与信息论解释
逆文档频率（Inverse Document Frequency）衡量词项在整个文档集合中的稀有程度。标准 IDF 公式为 idf(t) = log(N / df(t))，其中 N 是总文档数，df(t) 是包含词项 t 的文档数。出现在所有文档中的词（如停用词）IDF 接近 0，而仅出现在少数文档中的词 IDF 较高。


从信息论角度理解，IDF 可以视为词项 t 的自信息量（Self-Information）的近似。如果将文档集合视为概率空间，词项 t 出现的概率约为 P(t) = df(t) / N，其自信息为 -log P(t) = log(N/df(t)) = idf(t)。这意味着 IDF 高的词携带更多信息，具有更强的区分力。


type IDFScheme = 'standard' | 'smooth' | 'max' | 'probabilistic';

function computeIDF(docFreq: number, totalDocs: number, scheme: IDFScheme): number {
  switch (scheme) {
    case 'standard':
      return Math.log(totalDocs / docFreq);
    case 'smooth':
      return Math.log(1 + totalDocs / docFreq);
    case 'max':
      return Math.log(1 + Math.max(...[]) / docFreq);
    case 'probabilistic':
      return Math.max(0, Math.log((totalDocs - docFreq) / docFreq));
  }
}

interface InvertedIndexEntry {
  readonly term: string;
  readonly docFreq: number;
  readonly idf: number;
  readonly postings: ReadonlyArray<{
    docId: string;
    termFreq: number;
    positions: ReadonlyArray<number>;
  }>;
}

function buildTFIDFIndex(
  documents: ReadonlyArray<{ id: string; terms: ReadonlyArray<string> }>,
  config: TFIDFConfig,
): Map<string, InvertedIndexEntry> {
  const index = new Map<string, { docFreq: number; postings: Map<string, number[]> }>();
  const totalDocs = documents.length;

  for (const doc of documents) {
    const seen = new Set<string>();
    for (let pos = 0; pos < doc.terms.length; pos++) {
      const term = doc.terms[pos];
      if (!index.has(term)) {
        index.set(term, { docFreq: 0, postings: new Map() });
      }
      const entry = index.get(term)!;
      if (!seen.has(term)) {
        entry.docFreq++;
        seen.add(term);
      }
      if (!entry.postings.has(doc.id)) {
        entry.postings.set(doc.id, []);
      }
      entry.postings.get(doc.id)!.push(pos);
    }
  }

  const result = new Map<string, InvertedIndexEntry>();
  for (const [term, data] of index) {
    const idf = computeIDF(data.docFreq, totalDocs, config.idfScheme);
    result.set(term, {
      term,
      docFreq: data.docFreq,
      idf,
      postings: [...data.postings.entries()].map(([docId, positions]) => ({
        docId,
        termFreq: positions.length,
        positions,
      })),
    });
  }
  return result;
}
平滑 IDF（Smooth IDF）使用 log(1 + N/df(t)) 避免 df 为 0 时的除零问题，同时使 IDF 曲线更平滑。概率 IDF 使用 log((N - df(t)) / df(t))，当 df 超过 N/2 时 IDF 为负值，直接惩罚过于常见的词项。


向量空间模型中的 TF-IDF
TF-IDF 在向量空间模型（VSM）中作为文档和查询的向量表示。每篇文档 d 被表示为一个 V 维向量（V 为词表大小），第 i 维的值为词项 t_i 在 d 中的 TF-IDF 权重。查询也被转换为同样维度的向量。文档与查询的相关性通过余弦相似度计算。


余弦相似度公式为 cos(θ) = (d · q) / (|d| × |q|)，取值范围 [0, 1]。余弦相似度的关键优势在于它对向量长度归一化，使得长文档和短文档在同一尺度上比较。


interface TFIDFVector {
  readonly docId: string;
  readonly weights: ReadonlyMap<string, number>;
  readonly norm: number;
}

function computeCosineSimilarity(docVector: TFIDFVector, queryVector: TFIDFVector): number {
  let dotProduct = 0;
  for (const [term, queryWeight] of queryVector.weights) {
    const docWeight = docVector.weights.get(term) ?? 0;
    dotProduct += docWeight * queryWeight;
  }
  const denominator = docVector.norm * queryVector.norm;
  return denominator > 0 ? dotProduct / denominator : 0;
}

function vectorNorm(weights: ReadonlyMap<string, number>): number {
  let sumSquares = 0;
  for (const w of weights.values()) {
    sumSquares += w * w;
  }
  return Math.sqrt(sumSquares);
}

BM25：TF-IDF 的工程进化
BM25（Best Matching 25）是 TF-IDF 在概率检索框架下的进化版本，被认为是传统 IR 中效果最好的权重方案。BM25 引入了两个关键改进：TF 饱和（通过参数 k1 控制）和文档长度归一化（通过参数 b 控制）。


BM25 的 TF 分量为 (k1 + 1) × tf / (k1 × (1 - b + b × dl/avgdl) + tf)，其中 dl 是文档长度，avgdl 是平均文档长度。当 k1 = 0 时退化为布尔模型，k1 → ∞ 时接近原始 TF。b = 0 时不做长度归一化，b = 1 时完全按文档长度比例调整。经验值 k1 = 1.2, b = 0.75 在大多数场景下表现良好。


interface BM25Config {
  readonly k1: number;
  readonly b: number;
  readonly k3: number;
  readonly avgDocLength: number;
}

function bm25Score(
  tf: number,
  df: number,
  docLength: number,
  queryTF: number,
  totalDocs: number,
  config: BM25Config,
): number {
  const idf = Math.log((totalDocs - df + 0.5) / (df + 0.5) + 1);

  const tfNorm =
    (tf * (config.k1 + 1)) / (tf + config.k1 * (1 - config.b + (config.b * docLength) / config.avgDocLength));

  const queryTFNorm = (queryTF * (config.k3 + 1)) / (queryTF + config.k3);

  return idf * tfNorm * queryTFNorm;
}
BM25 的 IDF 分量使用 log((N - df + 0.5) / (df + 0.5) + 1)，比标准 IDF 更平滑，且保证非负。Elasticsearch 和 Lucene 从 6.0 版本起将默认相似度模型从 TF-IDF 切换为 BM25，标志着 BM25 在工业界的全面普及。


小结
    

  • TF-IDF 通过词频和逆文档频率的乘积衡量词项对文档的区分能力
    • 

  • TF 有原始、对数、布尔、增强等多种计算变体，对数 TF 最常用
    • 

  • IDF 从信息论角度衡量词项的信息量，出现越少的词 IDF 越高
    • 

  • 向量空间模型中使用 TF-IDF 向量和余弦相似度计算文档-查询相关性
    • 

  • BM25 是 TF-IDF 的概率进化版，引入 TF 饱和和文档长度归一化
    • 

  • BM25 参数 k1 = 1.2、b = 0.75 是经验最优默认值
    • 

  • 现代搜索引擎（Elasticsearch/Lucene）默认使用 BM25 而非朴素 TF-IDF
