词干提取与词形还原

核心概念

词干提取（Stemming）和词形还原（Lemmatization）是文本处理流水线中将词汇形态变体归约为统一形式的两种技术。它们的目标相同——让 running、runs、ran 映射到同一个词项——但实现方法和效果截然不同。词干提取通过规则剥离词缀得到词干（stem），速度快但可能产生非真实词汇；词形还原通过词典和词法分析得到词元（lemma），结果准确但计算成本更高。

Porter Stemmer 算法
Porter Stemmer 是最经典的英文词干提取算法，由 Martin Porter 于 1980 年提出。算法定义了 5 个步骤，每步包含一组后缀剥离规则，按顺序应用于输入词汇。规则的核心思想是基于音节数（用辅元音模式 C^m[V] 中的 m 值衡量）决定是否剥离后缀。


第一步处理复数和动词后缀：-sses → -ss（caresses → caress），-ies → -i（ponies → poni），-s → 删除（cats → cat）。第二步处理过去式和进行时：-eed → -ee（agreed → agree），-ed → 删除（plastered → plaster），-ing → 删除（motoring → motor）。后续步骤处理 -ational → -ate、-fulness → -ful 等更复杂的后缀变换。


interface StemmerRule {
  readonly suffix: string;
  readonly replacement: string;
  readonly minMeasure: number;
  readonly condition?: (stem: string) => boolean;
}

function measureConsonantVowel(word: string): number {
  const cvPattern = word
    .replace(/[aeiou]/g, 'V')
    .replace(/[^V]/g, 'C')
    .replace(/C+/g, 'C')
    .replace(/V+/g, 'V');
  const matches = cvPattern.match(/VC/g);
  return matches ? matches.length : 0;
}

function porterStep1a(word: string): string {
  if (word.endsWith('sses')) return word.slice(0, -2);
  if (word.endsWith('ies')) return word.slice(0, -2);
  if (word.endsWith('ss')) return word;
  if (word.endsWith('s')) return word.slice(0, -1);
  return word;
}

function porterStep1b(word: string): string {
  if (word.endsWith('eed')) {
    const stem = word.slice(0, -3);
    return measureConsonantVowel(stem) > 0 ? stem + 'ee' : word;
  }
  if (word.endsWith('ed')) {
    const stem = word.slice(0, -2);
    if (/[aeiou]/.test(stem)) return cleanupStep1b(stem);
    return word;
  }
  if (word.endsWith('ing')) {
    const stem = word.slice(0, -3);
    if (/[aeiou]/.test(stem)) return cleanupStep1b(stem);
    return word;
  }
  return word;
}

function cleanupStep1b(stem: string): string {
  if (stem.endsWith('at') || stem.endsWith('bl') || stem.endsWith('iz')) {
    return stem + 'e';
  }
  const last2 = stem.slice(-2);
  if (last2[0] === last2[1] && !['l', 's', 'z'].includes(last2[0])) {
    return stem.slice(0, -1);
  }
  return stem;
}
Porter Stemmer 的主要缺陷是过度归约（Over-Stemming）和归约不足（Under-Stemming）。过度归约将不相关的词映射到同一词干：organization 和 organ 都被归约为 organ。归约不足则无法将相关的词映射到同一词干：alumnus 和 alumni 因为后缀模式不同而得到不同词干。


Snowball 框架与多语言词干提取
Snowball 是 Porter 在 2001 年开发的词干提取框架，定义了一种专用的规则描述语言（Snowball language），使得为不同语言编写词干提取器变得系统化。Snowball 框架目前支持英语、法语、德语、西班牙语、意大利语、葡萄牙语、俄语等 20+ 种语言。


英语 Snowball Stemmer（也称 Porter2）相比原始 Porter 算法做了多项改进：更好地处理 -y 结尾词（happy → happi 而非原始的不稳定行为）、增加了对异常词的特殊处理、修正了若干边界条件错误。


interface SnowballStemmer {
  readonly language: string;
  stem(word: string): string;
}

interface MultilingualStemmerConfig {
  readonly stemmers: ReadonlyMap<string, SnowballStemmer>;
  readonly fallback: 'none' | 'lowercase' | 'porter';
}

function createSnowballPipeline(languages: ReadonlyArray<string>): MultilingualStemmerConfig {
  const stemmers = new Map<string, SnowballStemmer>();

  const rules: Record<string, ReadonlyArray<StemmerRule>> = {
    en: [
      { suffix: 'fulness', replacement: 'ful', minMeasure: 0 },
      { suffix: 'ational', replacement: 'ate', minMeasure: 0 },
      { suffix: 'tional', replacement: 'tion', minMeasure: 0 },
      { suffix: 'enci', replacement: 'ence', minMeasure: 0 },
      { suffix: 'anci', replacement: 'ance', minMeasure: 0 },
    ],
    de: [
      { suffix: 'ierung', replacement: '', minMeasure: 0 },
      { suffix: 'ungen', replacement: '', minMeasure: 0 },
      { suffix: 'lich', replacement: '', minMeasure: 0 },
    ],
    fr: [
      { suffix: 'issement', replacement: '', minMeasure: 0 },
      { suffix: 'ement', replacement: '', minMeasure: 0 },
      { suffix: 'ation', replacement: '', minMeasure: 0 },
    ],
  };

  for (const lang of languages) {
    stemmers.set(lang, {
      language: lang,
      stem: (word: string) => applyRules(word, rules[lang] ?? []),
    });
  }

  return { stemmers, fallback: 'lowercase' };
}

function applyRules(word: string, rules: ReadonlyArray<StemmerRule>): string {
  for (const rule of rules) {
    if (word.endsWith(rule.suffix)) {
      const stem = word.slice(0, -rule.suffix.length);
      if (measureConsonantVowel(stem) >= rule.minMeasure) {
        return stem + rule.replacement;
      }
    }
  }
  return word;
}

基于词典的词形还原
词形还原（Lemmatization）将词汇还原为其在词典中的标准形式（词元/lemma）。与词干提取不同，词形还原需要理解词汇的词性（POS）信息：better 作为形容词的词元是 good，作为副词的词元也是 well，但词干提取对两者都不做处理。


WordNet 是英语词形还原最常用的资源。WordNet Lemmatizer 根据词性标签查找词汇在 WordNet 中的基本形式：名词去复数（mice → mouse）、动词还原原形（went → go）、形容词还原原级（better → good）。


interface LemmatizerConfig {
  readonly dictionary: string;
  readonly posTagRequired: boolean;
  readonly cacheEnabled: boolean;
  readonly unknownWordStrategy: 'passthrough' | 'stem' | 'lowercase';
}

interface LemmaResult {
  readonly original: string;
  readonly lemma: string;
  readonly pos: 'noun' | 'verb' | 'adjective' | 'adverb';
  readonly confidence: number;
}

interface MorphologicalAnalyzer {
  analyze(word: string, pos: string): ReadonlyArray<LemmaResult>;
  batchAnalyze(tokens: ReadonlyArray<{ word: string; pos: string }>): ReadonlyArray<LemmaResult>;
}

function lemmatizeWithFallback(
  word: string,
  pos: string,
  dictionary: Map<string, Map<string, string>>,
  stemmer: (w: string) => string,
): string {
  const posDict = dictionary.get(pos);
  if (posDict) {
    const lemma = posDict.get(word.toLowerCase());
    if (lemma) return lemma;
  }

  const irregulars = dictionary.get('irregular');
  if (irregulars) {
    const lemma = irregulars.get(word.toLowerCase());
    if (lemma) return lemma;
  }

  return stemmer(word);
}
spaCy 的词形还原器结合了规则表和统计模型：先查找异常词表（如 am → be），再应用词缀规则，最后使用训练好的模型处理歧义情况。spaCy 对英语词形还原的准确率在 95% 以上。


IR 系统中的选择策略
在信息检索系统中，词干提取和词形还原的选择取决于系统对召回率和精确率的偏好。词干提取倾向于合并更多词汇形态，提升召回率但可能引入噪音；词形还原更保守，保持较高精确率但可能遗漏相关文档。


实验数据表明，在英语 IR 任务中，Porter Stemmer 平均提升 MAP 约 1-3%，Snowball 提升约 2-4%，词形还原提升约 1-2%。但在精确匹配需求高的场景（如法律检索、医学文献），词形还原的精确率优势更为明显。

现代 IR 系统的趋势是将词干提取和词形还原作为查询扩展的手段，而非索引时的硬处理。在索引中保留原始形态，查询时通过同义词扩展或 analyzer chain 动态引入词干/词元匹配，既保持了精确匹配能力又获得了形态变体的召回。
