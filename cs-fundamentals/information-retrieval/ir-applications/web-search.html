Web 搜索引擎

核心概念

Web 搜索引擎是信息检索技术在最大规模数据集上的工程实践。与经典 IR 系统处理的静态、有限文档集合不同，Web 搜索面临数百亿网页的动态集合、用户查询意图的多样性以及 Web 内容质量的极端异质性。Web 搜索引擎的核心创新不在于检索模型本身，而在于如何在 Web 独特的生态中有效运用和扩展经典 IR 技术。

Learning to Rank





PageRank 与链接分析
PageRank 是 Google 的核心创新之一，它利用 Web 的超链接结构来衡量页面的权威性。核心直觉是：一个被很多高质量页面链接的页面本身也是高质量的。


PageRank 的数学模型基于随机游走：假设一个随机用户在 Web 上浏览，每一步以概率 (1-d) 随机跳转到任意页面，以概率 d 沿着当前页面的出链跳转到下一个页面。经过足够多步后，用户停留在每个页面的概率就是该页面的 PageRank 值。


interface WebGraph {
  readonly pages: ReadonlyArray<string>;
  readonly outLinks: Map<string, ReadonlyArray<string>>;
  readonly inLinks: Map<string, ReadonlyArray<string>>;
}

const computePageRank = (
  graph: WebGraph,
  dampingFactor: number = 0.85,
  iterations: number = 100,
  tolerance: number = 1e-6,
): Map<string, number> => {
  const n = graph.pages.length;
  let ranks = new Map<string, number>();
  for (const page of graph.pages) {
    ranks.set(page, 1 / n);
  }
  for (let iter = 0; iter < iterations; iter++) {
    const newRanks = new Map<string, number>();
    let maxDiff = 0;
    for (const page of graph.pages) {
      const inLinks = graph.inLinks.get(page) ?? [];
      let rankSum = 0;
      for (const source of inLinks) {
        const outDegree = (graph.outLinks.get(source) ?? []).length;
        if (outDegree > 0) {
          rankSum += (ranks.get(source) ?? 0) / outDegree;
        }
      }
      const newRank = (1 - dampingFactor) / n + dampingFactor * rankSum;
      newRanks.set(page, newRank);
      maxDiff = Math.max(maxDiff, Math.abs(newRank - (ranks.get(page) ?? 0)));
    }
    ranks = newRanks;
    if (maxDiff < tolerance) break;
  }
  return ranks;
};
HITS（Hyperlink-Induced Topic Search）是另一个经典的链接分析算法，它区分了两种角色：Hub（汇聚页面，链接到很多权威页面）和 Authority（权威页面，被很多 Hub 链接）。HITS 的优势是查询相关的——它只在与查询相关的子图上计算，而 PageRank 是全局的。

Web 爬虫与文档处理
Web 爬虫（Web Crawler）是搜索引擎的数据采集组件，负责系统性地发现和下载 Web 页面。大规模爬虫面临的核心挑战包括 URL 去重（避免重复下载相同内容）、爬取优先级（优先下载高价值页面）、礼貌性（遵守 robots.txt 和合理的请求频率）以及新鲜度维护（定期重新爬取以检测内容更新）。


爬取调度策略决定了 URL 的访问顺序和频率。基于 PageRank 的调度将高 PageRank 页面优先爬取；基于变化率的调度为频繁更新的页面分配更高的重访频率。实践中通常使用两者的加权组合。


Web 文档的特殊处理包括重复检测（使用 SimHash 或 MinHash 检测近似重复页面）、垃圾页面过滤（检测 SEO 作弊、内容农场和恶意页面）和语言检测（多语言索引需要正确识别页面语言）。


interface CrawlScheduler {
  getNextURL(): Promise<CrawlURL | null>;
  reportResult(url: string, result: CrawlResult): Promise<void>;
}

interface CrawlURL {
  readonly url: string;
  readonly priority: number;
  readonly lastCrawled?: Date;
  readonly expectedChangeRate: number;
}

const computeCrawlPriority = (url: CrawlURL, pageRank: number, changeRate: number, ageHours: number): number => {
  const pageRankScore = Math.log(1 + pageRank * 1000);
  const freshnessScore = changeRate * Math.min(ageHours / 24, 10);
  return 0.6 * pageRankScore + 0.4 * freshnessScore;
};
搜索结果多样化
Web 搜索的查询通常是模糊的——"java" 可能指编程语言、咖啡或印度尼西亚的岛屿。搜索结果多样化（Search Result Diversification）的目标是让结果列表覆盖查询的不同可能意图，而非将所有位置分配给最热门的解释。


MMR（Maximal Marginal Relevance）是最基本的多样化算法——在选择下一个结果时，同时考虑与查询的相关性和与已选结果的差异性。xQuAD 和 PM-2 是更精细的方法，它们显式建模查询的多个可能意图，并确保每个意图都获得合理的结果覆盖。

小结
    

  • Web 搜索引擎在数百亿网页规模上运用和扩展经典 IR 技术，核心挑战是规模、动态性和质量异质性
    • 

  • PageRank 通过随机游走模型利用链接结构衡量页面权威性，是 Web 排序的关键信号
    • 

  • 爬虫系统通过优先级调度和变化率检测平衡页面覆盖率和索引新鲜度
    • 

  • 重复检测和垃圾过滤是保障 Web 索引质量的必要环节
    • 

  • 搜索结果多样化通过覆盖查询的多个可能意图提升用户满意度
    • 

  • 现代 Web 搜索引擎融合了链接分析、内容相关性、用户行为和时效性等数百个排序特征
