文本分类与过滤

核心概念

文本分类（Text Classification）是将文档自动归入预定义类别的任务，是信息检索系统中内容理解和组织的基础能力。在 IR 系统中，文本分类广泛应用于查询意图识别（导航型/信息型/事务型）、文档类型分类（教程/参考/问答）、垃圾邮件过滤、情感分析和主题标注。文本过滤（Text Filtering）则是分类的在线版本——对持续到达的文档流进行实时分类和路由。

特征工程与文本表示
传统文本分类的特征工程是将非结构化文本转换为结构化数值向量的过程。词袋模型（Bag of Words）是最基础的表示——每个词项对应一个特征维度，值为 TF-IDF 权重。


N-gram 特征通过捕获相邻词的共现来引入有限的词序信息。Bigram "machine learning" 和 "deep learning" 作为独立特征可以区分不同的技术主题，而单独的 "learning" 则过于泛化。


interface FeatureExtractor {
  extract(text: string): FeatureVector;
  vocabulary: ReadonlyArray<string>;
}

interface FeatureVector {
  readonly features: Map<string, number>;
  readonly norm: number;
}

const createTfidfExtractor = (
  documents: ReadonlyArray<string>,
  config: { maxFeatures: number; ngramRange: [number, number]; minDf: number },
): FeatureExtractor => {
  const vocabulary = buildVocabulary(documents, config);
  const idfValues = computeIDF(documents, vocabulary);
  return {
    vocabulary,
    extract: (text) => {
      const tokens = tokenize(text);
      const features = new Map<string, number>();
      for (const term of vocabulary) {
        const tf = tokens.filter((t) => t === term).length;
        if (tf > 0) {
          features.set(term, (1 + Math.log(tf)) * (idfValues.get(term) ?? 0));
        }
      }
      const norm = Math.sqrt([...features.values()].reduce((s, v) => s + v * v, 0));
      return { features, norm };
    },
  };
};
现代文本分类使用预训练语言模型（BERT、RoBERTa）进行文本表示。与 TF-IDF 的稀疏高维向量不同，BERT 生成的是 768 维的稠密向量，能够捕获深层语义信息。BERT 分类器在大多数文本分类基准上大幅超越了传统特征工程方法。

分类算法
朴素贝叶斯（Naive Bayes）是文本分类中最经典的算法。它基于贝叶斯定理和词项独立假设，计算每个类别生成给定文档的概率。尽管独立假设在实际中几乎不成立，朴素贝叶斯在文本分类上表现出人意料地好——特别是在训练数据较少时。


interface TextClassifier {
  train(documents: ReadonlyArray<LabeledDocument>): Promise<void>;
  predict(text: string): Promise<ReadonlyArray<Prediction>>;
}

interface LabeledDocument {
  readonly text: string;
  readonly label: string;
}

interface Prediction {
  readonly label: string;
  readonly probability: number;
}

const createNaiveBayes = (): TextClassifier => {
  let classPriors = new Map<string, number>();
  let termLikelihoods = new Map<string, Map<string, number>>();
  let vocabulary = new Set<string>();
  return {
    train: async (documents) => {
      const classCounts = new Map<string, number>();
      const classTermCounts = new Map<string, Map<string, number>>();
      for (const doc of documents) {
        classCounts.set(doc.label, (classCounts.get(doc.label) ?? 0) + 1);
        const tokens = tokenize(doc.text);
        if (!classTermCounts.has(doc.label)) classTermCounts.set(doc.label, new Map());
        const termMap = classTermCounts.get(doc.label)!;
        for (const token of tokens) {
          vocabulary.add(token);
          termMap.set(token, (termMap.get(token) ?? 0) + 1);
        }
      }
      const totalDocs = documents.length;
      for (const [label, count] of classCounts) {
        classPriors.set(label, Math.log(count / totalDocs));
        const termMap = classTermCounts.get(label)!;
        const totalTerms = [...termMap.values()].reduce((s, v) => s + v, 0);
        const likelihoods = new Map<string, number>();
        for (const term of vocabulary) {
          likelihoods.set(term, Math.log(((termMap.get(term) ?? 0) + 1) / (totalTerms + vocabulary.size)));
        }
        termLikelihoods.set(label, likelihoods);
      }
    },
    predict: async (text) => {
      const tokens = tokenize(text);
      const scores = [...classPriors.entries()].map(([label, prior]) => {
        const likelihoods = termLikelihoods.get(label)!;
        const logProb = tokens.reduce(
          (sum, token) => sum + (likelihoods.get(token) ?? Math.log(1 / (vocabulary.size + 1))),
          prior,
        );
        return { label, logProb };
      });
      const maxLogProb = Math.max(...scores.map((s) => s.logProb));
      const expSum = scores.reduce((sum, s) => sum + Math.exp(s.logProb - maxLogProb), 0);
      return scores
        .map((s) => ({ label: s.label, probability: Math.exp(s.logProb - maxLogProb) / expSum }))
        .sort((a, b) => b.probability - a.probability);
    },
  };
};
SVM（支持向量机）在高维文本特征空间中表现优异，因为文本特征通常是线性可分的。逻辑回归提供校准良好的概率输出，适合需要置信度估计的场景。BERT 微调在大多数分类任务上达到了最高准确率，但训练和推理成本更高。


信息过滤与推荐
信息过滤是文本分类的在线应用——对持续到达的文档流进行实时判断，决定是否将文档推送给用户。与批量分类不同，过滤器需要适应用户兴趣的动态变化。


协同过滤利用用户群体的行为模式进行推荐——如果两个用户过去有相似的偏好，那么一个用户喜欢的文档也可能被另一个用户喜欢。内容过滤利用文档内容特征与用户画像的匹配度来做出推荐决策。混合方法结合两者的优势。

小结
    

  • 文本分类是 IR 系统中内容理解的基础，应用于查询意图识别、文档分类和垃圾过滤
    • 

  • TF-IDF 和 N-gram 是传统特征工程的核心，BERT 的稠密向量表示在精度上全面超越
    • 

  • 朴素贝叶斯凭借简单性和训练效率在文本分类中有独特价值，SVM 在高维空间泛化良好
    • 

  • 信息过滤是分类的在线版本，需要适应用户兴趣的动态变化
    • 

  • 混合过滤方法结合内容和协同两种信号，缓解冷启动问题
    • 

  • 文本分类能力是构建智能 IR 系统（查询理解、结果过滤、个性化）的基础模块
    •
