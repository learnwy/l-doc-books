搜索引擎

需求分析

设计一个 Web 搜索引擎，用户输入关键词，系统返回最相关的网页结果。这是系统设计中复杂度最高的案例之一，涉及数据采集、索引构建、查询处理和结果排序四大核心模块。

功能需求

  • 用户输入关键词，返回相关网页列表
  • 结果按相关性排序
  • 支持分页（每页 10 条）
  • 搜索建议（自动补全）

非功能需求

维度 目标
索引网页数 100 亿
查询延迟 P99 < 500ms
查询 QPS 10 万
索引新鲜度 热门页面 < 1 小时
可用性 99.99%

URL Frontier 设计
interface URLFrontier {
  addUrl(url: string, priority: number): Promise<void>;
  getNextUrl(): Promise<string | null>;
  markCompleted(url: string): Promise<void>;
  size(): Promise<number>;
}

class PoliteFrontier implements URLFrontier {
  private queues: Map<string, PriorityQueue<URLEntry>> = new Map();
  private lastFetchTime: Map<string, number> = new Map();
  private politenessDelay = 1000;

  async addUrl(url: string, priority: number): Promise<void> {
    const host = new URL(url).hostname;
    if (!this.queues.has(host)) {
      this.queues.set(host, new PriorityQueue());
    }
    this.queues.get(host)!.push({ url, priority });
  }

  async getNextUrl(): Promise<string | null> {
    const now = Date.now();
    for (const [host, queue] of this.queues) {
      const lastFetch = this.lastFetchTime.get(host) ?? 0;
      if (now - lastFetch >= this.politenessDelay && queue.size() > 0) {
        const entry = queue.pop();
        this.lastFetchTime.set(host, now);
        return entry?.url ?? null;
      }
    }
    return null;
  }

  async markCompleted(_url: string): Promise<void> {}
  async size(): Promise<number> {
    let total = 0;
    for (const q of this.queues.values()) total += q.size();
    return total;
  }
}

interface URLEntry {
  url: string;
  priority: number;
}

class PriorityQueue<T> {
  private items: T[] = [];
  push(item: T): void {
    this.items.push(item);
  }
  pop(): T | undefined {
    return this.items.shift();
  }
  size(): number {
    return this.items.length;
  }
}
Politeness 策略确保爬虫不会过于频繁地访问同一个域名，遵守 robots.txt 规则。


内容去重
使用 SimHash 或 MinHash 对网页内容进行指纹计算，检测近似重复：


function simpleFingerprint(content: string): number {
  let hash = 0;
  for (let i = 0; i < content.length; i++) {
    hash = ((hash << 5) - hash + content.charCodeAt(i)) | 0;
  }
  return hash >>> 0;
}

class DuplicateDetector {
  private seen = new Set<number>();

  isDuplicate(content: string): boolean {
    const fp = simpleFingerprint(content);
    if (this.seen.has(fp)) return true;
    this.seen.add(fp);
    return false;
  }
}


倒排索引
倒排索引（Inverted Index）是搜索引擎的核心数据结构。它将"词 → 文档列表"的映射反转为快速查找的结构：


索引构建
interface PostingList {
  docId: string;
  termFrequency: number;
  positions: number[];
}

interface InvertedIndex {
  index: Map<string, PostingList[]>;
  documentCount: number;
}

function buildIndex(documents: Array<{ id: string; content: string }>): InvertedIndex {
  const index = new Map<string, PostingList[]>();
  let documentCount = 0;

  for (const doc of documents) {
    documentCount++;
    const tokens = tokenize(doc.content);
    const termPositions = new Map<string, number[]>();

    tokens.forEach((token, pos) => {
      if (!termPositions.has(token)) {
        termPositions.set(token, []);
      }
      termPositions.get(token)!.push(pos);
    });

    for (const [term, positions] of termPositions) {
      if (!index.has(term)) {
        index.set(term, []);
      }
      index.get(term)!.push({
        docId: doc.id,
        termFrequency: positions.length,
        positions,
      });
    }
  }

  return { index, documentCount };
}

function tokenize(text: string): string[] {
  return text.toLowerCase().split(/\s+/).filter(Boolean);
}

TF-IDF
function tfidf(termFrequency: number, documentFrequency: number, totalDocuments: number): number {
  const tf = Math.log(1 + termFrequency);
  const idf = Math.log(totalDocuments / (documentFrequency + 1));
  return tf * idf;
}
PageRank 简化模型
PageRank 通过链接关系衡量网页的"重要性"——被越多高质量页面链接的页面，其 PageRank 越高：


function pageRank(
  graph: Map<string, string[]>,
  iterations: number = 20,
  dampingFactor: number = 0.85,
): Map<string, number> {
  const nodes = [...graph.keys()];
  const n = nodes.length;
  const ranks = new Map<string, number>();

  nodes.forEach((node) => ranks.set(node, 1 / n));

  for (let i = 0; i < iterations; i++) {
    const newRanks = new Map<string, number>();
    nodes.forEach((node) => newRanks.set(node, (1 - dampingFactor) / n));

    for (const [node, outLinks] of graph) {
      const share = (ranks.get(node) ?? 0) / (outLinks.length || 1);
      for (const target of outLinks) {
        newRanks.set(target, (newRanks.get(target) ?? 0) + dampingFactor * share);
      }
    }

    for (const [node, rank] of newRanks) {
      ranks.set(node, rank);
    }
  }

  return ranks;
}
综合排序公式
interface SearchResult {
  docId: string;
  tfidfScore: number;
  pageRank: number;
  freshnessScore: number;
  userSignals: number;
}

function calculateRelevance(result: SearchResult): number {
  return result.tfidfScore * 0.3 + result.pageRank * 0.25 + result.freshnessScore * 0.2 + result.userSignals * 0.25;
}

  • 搜索引擎的核心是倒排索引——将"词→文档"映射反转为高效查找结构。

  • 网页爬虫需要处理去重、politeness 和增量爬取。
