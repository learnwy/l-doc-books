短链接服务

需求分析

设计一个类似 bit.ly 的短链接服务：用户输入一个长 URL，系统返回一个短 URL；访问短 URL 时，系统将用户重定向到原始长 URL。

功能需求

  • 给定一个长 URL，生成唯一的短 URL
  • 访问短 URL 时，301/302 重定向到原始 URL
  • 短链接可设置过期时间
  • 可选：自定义短链接别名

非功能需求

维度 目标
可用性 99.99%
读写比 100:1（读远多于写）
延迟 重定向 < 100ms
数据保留 默认 5 年

量化估算

const estimation = {
  dailyNewUrls: 1_000_000,
  readWriteRatio: 100,
  dailyReads: 100_000_000,

  writeQPS: Math.ceil(1_000_000 / 86400),
  readQPS: Math.ceil(100_000_000 / 86400),
  peakReadQPS: Math.ceil(100_000_000 / 86400) * 3,

  avgUrlSize: 500,
  dailyStorage: (1_000_000 * 500) / 1e9,
  fiveYearStorage: ((1_000_000 * 500 * 365 * 5) / 1e12).toFixed(2) + ' TB',

  totalUrls5Years: 1_000_000 * 365 * 5,
};

5 年内约 18 亿条短链接。使用 Base62 编码（a-z, A-Z, 0-9），7 个字符可表示 62^7 ≈ 3.5 万亿种组合，远超需求。

实现：计数器 + Base62
const BASE62_CHARS = '0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ';

function encodeBase62(num: number): string {
  if (num === 0) return BASE62_CHARS[0];
  let result = '';
  while (num > 0) {
    result = BASE62_CHARS[num % 62] + result;
    num = Math.floor(num / 62);
  }
  return result.padStart(7, '0');
}

function decodeBase62(str: string): number {
  let result = 0;
  for (const char of str) {
    result = result * 62 + BASE62_CHARS.indexOf(char);
  }
  return result;
}

读取流程（重定向）
301 vs 302 重定向




状态码
含义
浏览器行为
对分析的影响





301
永久重定向
缓存，后续直接访问原始 URL
无法统计后续访问量




302
临时重定向
每次都请求短链接服务
可以精确统计访问量





如果需要统计点击次数，应使用 302。

过期清理
async function cleanExpiredUrls(db: DatabaseClient): Promise<number> {
  const batchSize = 1000;
  let totalDeleted = 0;

  while (true) {
    const deleted = await db.query<number>('DELETE FROM urls WHERE expires_at < NOW() LIMIT $1 RETURNING id', [
      batchSize,
    ]);
    totalDeleted += deleted ?? 0;
    if ((deleted ?? 0) < batchSize) break;
    await new Promise((r) => setTimeout(r, 100));
  }

  return totalDeleted;
}

interface DatabaseClient {
  query<T>(sql: string, params: unknown[]): Promise<T | null>;
}


小结
    

  • 短链接服务是读密集型系统，缓存是性能的关键。
    • 

  • Base62 编码配合全局计数器是最简洁的短码生成方案。
    • 

  • 使用 302 重定向可以统计点击次数，301 可以减少服务负载。
    • 

  • 数据量增长后需要分库分表和过期数据清理机制。
