聊天系统

需求分析

设计一个类似微信/WhatsApp 的即时聊天系统，支持一对一聊天和群聊。

功能需求

  • 一对一聊天：实时发送和接收文本消息
  • 群聊：支持最多 500 人的群组
  • 在线状态：显示用户是否在线
  • 消息已读回执
  • 离线消息：用户上线后接收离线期间的消息
  • 消息历史：可以查看历史消息

非功能需求

维度 目标
日活用户 5000 万
每日消息量 200 亿条
消息延迟 < 200ms
可用性 99.99%
消息持久化 永久保存

WebSocket 连接管理
interface ConnectionRegistry {
  register(userId: string, gatewayId: string, connectionId: string): Promise<void>;
  unregister(userId: string): Promise<void>;
  lookup(userId: string): Promise<{ gatewayId: string; connectionId: string } | null>;
  isOnline(userId: string): Promise<boolean>;
}

class RedisConnectionRegistry implements ConnectionRegistry {
  constructor(private redis: RedisClient) {}

  async register(userId: string, gatewayId: string, connectionId: string): Promise<void> {
    await this.redis.hset(`conn:${userId}`, { gatewayId, connectionId });
    await this.redis.expire(`conn:${userId}`, 300);
  }

  async unregister(userId: string): Promise<void> {
    await this.redis.del(`conn:${userId}`);
  }

  async lookup(userId: string): Promise<{ gatewayId: string; connectionId: string } | null> {
    const data = await this.redis.hgetall(`conn:${userId}`);
    if (!data || !data.gatewayId) return null;
    return { gatewayId: data.gatewayId, connectionId: data.connectionId };
  }

  async isOnline(userId: string): Promise<boolean> {
    return (await this.redis.exists(`conn:${userId}`)) === 1;
  }
}

interface RedisClient {
  hset(key: string, data: Record<string, string>): Promise<void>;
  hgetall(key: string): Promise<Record<string, string> | null>;
  del(key: string): Promise<void>;
  expire(key: string, seconds: number): Promise<void>;
  exists(key: string): Promise<number>;
}

interface Message {
  messageId: string;
  conversationId: string;
  senderId: string;
  content: string;
  type: 'text' | 'image' | 'video' | 'file';
  createdAt: number;
  status: 'sent' | 'delivered' | 'read';
}

interface Conversation {
  conversationId: string;
  type: 'direct' | 'group';
  participants: string[];
  lastMessageId: string;
  lastMessageAt: number;
}
使用 Cassandra 存储消息（写入密集、时间序列查询）：


CREATE TABLE messages (
    conversation_id TEXT,
    message_id      TIMEUUID,
    sender_id       TEXT,
    content         TEXT,
    type            TEXT,
    created_at      TIMESTAMP,
    PRIMARY KEY (conversation_id, message_id)
) WITH CLUSTERING ORDER BY (message_id DESC);
分区键为 conversation_id，聚簇键为 message_id（TimeUUID，天然有序）。查询某个会话的最近 N 条消息非常高效。
