日志（Logging）
结构化日志
现代系统应该使用结构化日志（JSON 格式），而非纯文本日志：


interface LogEntry {
  timestamp: string;
  level: 'debug' | 'info' | 'warn' | 'error';
  service: string;
  traceId: string;
  spanId: string;
  message: string;
  context: Record<string, unknown>;
}

class StructuredLogger {
  private service: string;

  constructor(service: string) {
    this.service = service;
  }

  info(message: string, context: Record<string, unknown> = {}): void {
    this.write('info', message, context);
  }

  error(message: string, error: Error, context: Record<string, unknown> = {}): void {
    this.write('error', message, {
      ...context,
      errorName: error.name,
      errorMessage: error.message,
      stackTrace: error.stack,
    });
  }

  private write(level: LogEntry['level'], message: string, context: Record<string, unknown>): void {
    const entry: LogEntry = {
      timestamp: new Date().toISOString(),
      level,
      service: this.service,
      traceId: (context.traceId as string) ?? 'unknown',
      spanId: (context.spanId as string) ?? 'unknown',
      message,
      context,
    };
    console.log(JSON.stringify(entry));
  }
}

const logger = new StructuredLogger('order-service');
logger.info('Order created', { orderId: 'ord_123', userId: 'usr_456', amount: 99.99 });

interface PrometheusMetrics {
  counter: {
    description: '只增不减的累计值';
    example: 'http_requests_total';

链路追踪（Distributed Tracing）
追踪模型
interface Span {
  traceId: string;
  spanId: string;
  parentSpanId: string | null;
  operationName: string;
  serviceName: string;
  startTime: number;
  duration: number;
  tags: Record<string, string>;
  logs: Array<{ timestamp: number; message: string }>;
}

class SimpleTracer {
  createSpan(operationName: string, parentSpan?: Span): Span {
    return {
      traceId: parentSpan?.traceId ?? crypto.randomUUID(),
      spanId: crypto.randomUUID(),
      parentSpanId: parentSpan?.spanId ?? null,
      operationName,
      serviceName: 'my-service',
      startTime: Date.now(),
      duration: 0,
      tags: {},
      logs: [],
    };
  }

  finishSpan(span: Span): void {
    span.duration = Date.now() - span.startTime;
  }
}
OpenTelemetry
OpenTelemetry 是当前可观测性领域的事实标准，统一了日志、指标和追踪的采集：




小结
    

  • 日志记录离散事件，用于错误排查和审计——使用结构化日志。
    • 

  • 指标衡量系统趋势，用于告警和容量规划——关注四种黄金信号。
    • 

  • 链路追踪展示请求的跨服务路径，用于性能分析和依赖映射。
    • 

  • OpenTelemetry 正在成为可观测性的统一标准。
    • 

  • 三者结合才能提供完整的系统可见性——缺一不可。
