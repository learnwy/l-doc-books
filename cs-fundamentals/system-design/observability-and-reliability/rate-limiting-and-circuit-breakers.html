限流与熔断

限流（Rate Limiting）

限流是保护系统免受过载的第一道防线。它通过限制单位时间内的请求数量，防止恶意攻击、突发流量或 Bug 导致的请求风暴压垮系统。

常见限流算法
固定窗口计数器
class FixedWindowLimiter {
  private windowStart: number;
  private count: number;
  private limit: number;
  private windowMs: number;

  constructor(limit: number, windowMs: number) {
    this.limit = limit;
    this.windowMs = windowMs;
    this.windowStart = Date.now();
    this.count = 0;
  }

  allow(): boolean {
    const now = Date.now();
    if (now - this.windowStart >= this.windowMs) {
      this.windowStart = now;
      this.count = 0;
    }
    if (this.count < this.limit) {
      this.count++;
      return true;
    }
    return false;
  }
}
缺点：窗口边界处可能出现双倍流量（前一个窗口末尾和下一个窗口开头的请求叠加）。


滑动窗口日志
class SlidingWindowLogLimiter {
  private timestamps: number[] = [];
  private limit: number;
  private windowMs: number;

  constructor(limit: number, windowMs: number) {
    this.limit = limit;
    this.windowMs = windowMs;
  }

  allow(): boolean {
    const now = Date.now();
    this.timestamps = this.timestamps.filter((t) => now - t < this.windowMs);

    if (this.timestamps.length < this.limit) {
      this.timestamps.push(now);
      return true;
    }
    return false;
  }
}
令牌桶（Token Bucket）
class TokenBucket {
  private tokens: number;
  private capacity: number;
  private refillRate: number;
  private lastRefill: number;

  constructor(capacity: number, refillRate: number) {
    this.capacity = capacity;
    this.tokens = capacity;
    this.refillRate = refillRate;
    this.lastRefill = Date.now();
  }

  allow(tokensRequired = 1): boolean {
    this.refill();
    if (this.tokens >= tokensRequired) {
      this.tokens -= tokensRequired;
      return true;
    }
    return false;
  }

  private refill(): void {
    const now = Date.now();
    const elapsed = (now - this.lastRefill) / 1000;
    this.tokens = Math.min(this.capacity, this.tokens + elapsed * this.refillRate);
    this.lastRefill = now;
  }
}
漏桶（Leaky Bucket）
令牌桶允许突发流量（桶满时可以连续消耗），漏桶则以恒定速率处理请求，多余的请求排队等待。

分布式限流
在多实例部署中，限流状态需要在 Redis 等共享存储中集中管理：


class DistributedRateLimiter {
  private redis: RedisClient;

  constructor(redis: RedisClient) {
    this.redis = redis;
  }

  async isAllowed(key: string, limit: number, windowSec: number): Promise<boolean> {
    const redisKey = `ratelimit:${key}`;
    const current = await this.redis.incr(redisKey);

    if (current === 1) {
      await this.redis.expire(redisKey, windowSec);
    }

    return current <= limit;
  }
}

interface RedisClient {
  incr(key: string): Promise<number>;
  expire(key: string, seconds: number): Promise<void>;
}


熔断器（Circuit Breaker）
熔断器模式防止应用持续调用一个可能失败的下游服务。当故障率超过阈值时，熔断器"断开"，后续请求直接快速失败，避免资源浪费和级联故障。


type CircuitState = 'closed' | 'open' | 'half-open';

class CircuitBreaker {
  private state: CircuitState = 'closed';
  private failureCount = 0;
  private successCount = 0;
  private lastFailureTime = 0;

  constructor(
    private failureThreshold: number,
    private recoveryTimeMs: number,
    private halfOpenMaxAttempts: number,
  ) {}

  async execute<T>(fn: () => Promise<T>): Promise<T> {
    if (this.state === 'open') {
      if (Date.now() - this.lastFailureTime > this.recoveryTimeMs) {
        this.state = 'half-open';
        this.successCount = 0;
      } else {
        throw new Error('Circuit breaker is open');
      }
    }

    try {
      const result = await fn();
      this.onSuccess();
      return result;
    } catch (error) {
      this.onFailure();
      throw error;
    }
  }

  private onSuccess(): void {
    if (this.state === 'half-open') {
      this.successCount++;
      if (this.successCount >= this.halfOpenMaxAttempts) {
        this.state = 'closed';
        this.failureCount = 0;
      }
    } else {
      this.failureCount = 0;
    }
  }

  private onFailure(): void {
    this.failureCount++;
    this.lastFailureTime = Date.now();

    if (this.failureCount >= this.failureThreshold) {
      this.state = 'open';
    }
  }

  getState(): CircuitState {
    return this.state;
  }
}
使用示例
const breaker = new CircuitBreaker(5, 30000, 3);

async function callPaymentService(orderId: string): Promise<PaymentResult> {
  return breaker.execute(async () => {
    const response = await fetch(`https://payment.internal/api/charge`, {
      method: 'POST',
      body: JSON.stringify({ orderId }),
      signal: AbortSignal.timeout(5000),
    });

    if (!response.ok) throw new Error(`Payment failed: ${response.status}`);
    return response.json() as Promise<PaymentResult>;
  });
}

interface PaymentResult {
  transactionId: string;
  status: string;
}


限流 + 熔断的组合


小结
    

  • 限流是入口防护——防止流量超过系统承受能力。
    • 

  • 令牌桶是最常用的限流算法，支持突发流量。
    • 

  • 熔断器是出口防护——当下游服务故障时快速失败。
    • 

  • 限流 + 熔断 + 降级三者结合，构成系统的完整弹性防护体系。
