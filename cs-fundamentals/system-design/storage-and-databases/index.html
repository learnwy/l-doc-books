存储与数据库 简介

数据是系统的核心资产，存储方案的选择直接决定了系统的性能上限、可扩展能力和运维复杂度。没有万能的数据库——每种存储技术都有其最佳适用场景和固有限制。理解这些技术的内在原理和权衡取舍，是做出正确存储决策的关键。

第一节"关系型数据库"深入 RDBMS 的核心。从 ACID 事务保证到索引原理，从 SQL 查询优化到分库分表策略——关系型数据库依然是大多数系统的主数据存储，理解其能力边界至关重要。

第二节"NoSQL 数据库"覆盖关系型数据库之外的多种存储方案。键值存储、文档数据库、列族数据库、图数据库——每种模型针对特定的数据访问模式做了优化。我们将分析各类 NoSQL 数据库的适用场景以及与关系型数据库的选型权衡。

第三节"缓存策略"探讨如何通过缓存层来大幅提升读取性能。从本地缓存到分布式缓存，从 Cache-Aside 到 Write-Through，每种缓存策略都有其适用的读写比例和一致性要求。缓存是系统设计中最常用的性能优化手段，但也是最容易引入一致性问题的环节。

第四节"消息队列"介绍异步通信的核心基础设施。消息队列将生产者和消费者解耦，实现流量削峰、异步处理和事件驱动。Kafka、RabbitMQ、SQS 等不同产品的设计理念和适用场景将在本节详细对比。
