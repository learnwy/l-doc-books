消息队列

为什么需要消息队列

消息队列（Message Queue）是分布式系统中实现异步通信的核心基础设施。它将消息的生产者和消费者解耦，使得两端可以独立扩展、独立部署、独立故障。

  orderId: string;

  items: Array<{ productId: string; quantity: number; price: number }>;

class OrderService {
  constructor(private producer: MessageProducer) {}

  async createOrder(order: CreateOrderRequest): Promise<OrderResponse> {
    const orderId = generateId();

    await this.saveOrder(orderId, order);

    const event: OrderEvent = {
      eventId: generateId(),
      type: 'order.created',
      orderId,
      userId: order.userId,
      items: order.items,
      totalAmount: order.items.reduce((sum, i) => sum + i.price * i.quantity, 0),
      timestamp: Date.now(),
    };

    await this.producer.send('order-events', event);

    return { orderId, status: 'created' };
  }

  }
}

interface MessageProducer {
  send(topic: string, message: unknown): Promise<void>;

interface CreateOrderRequest {
  userId: string;
  items: Array<{ productId: string; quantity: number; price: number }>;

interface OrderResponse {
  orderId: string;

function generateId(): string {
  return crypto.randomUUID();

小结
    

  • 消息队列的三大价值：解耦、异步、削峰。
    • 

  • At-Least-Once 是最常用的投递语义，配合消费者幂等实现可靠处理。
    • 

  • Kafka 适合高吞吐量的事件流和日志场景。
    • 

  • RabbitMQ 适合低延迟的任务分发和 RPC 场景。
    • 

  • 消息队列引入了最终一致性——需要在系统设计中明确处理消息重复和乱序的问题。
