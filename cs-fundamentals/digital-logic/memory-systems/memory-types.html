存储器类型与层次

核心概念

存储器是数字系统中保存数据和指令的硬件设备。从处理器内部的寄存器到外部的硬盘，不同类型的存储器在速度、容量、成本和持久性之间形成了一条连续的权衡谱系。理解这条谱系——即存储层次结构（Memory Hierarchy）——是理解现代计算机性能特征的关键。

存储层次的核心矛盾是：程序员希望存储器又快又大又便宜，但物理规律决定了这三者不可兼得。快的存储器（SRAM）必须小，大的存储器（DRAM）必须慢，便宜的存储器（闪存/磁盘）更慢。存储层次通过缓存机制，利用程序的局部性原理，在用户面前制造了"又快又大"的假象。

SRAM 的结构与工作原理
SRAM（Static Random Access Memory）使用交叉耦合的反相器对存储每一位数据。标准的 6 晶体管（6T）SRAM 单元包含两个反相器形成存储环路，加上两个访问晶体管连接到位线（Bit Line）。


SRAM 的"静态"是指只要电源不断，数据就一直保持，不需要刷新——这与 DRAM 的"动态"形成对比。但 SRAM 断电后数据仍然丢失，它属于易失性存储器。


6T SRAM 的读操作：


    

  1. 将字线（Word Line）拉高，打开两个访问晶体管
    2. 

  2. 存储的值通过访问晶体管驱动位线对
    3. 

  3. 灵敏放大器检测位线对之间的微小电压差，判定存储值
    4. 



6T SRAM 的写操作：


    

  1. 将要写入的值驱动到位线对上
    2. 

  2. 拉高字线，打开访问晶体管
    3. 

  3. 位线的强驱动能力覆盖存储环路的弱保持能力，强制改写存储值
    4. 



SRAM 的优势是速度快且不需要刷新，劣势是每个单元需要 6 个晶体管，面积大。这就是为什么 SRAM 只用于缓存而非主存——成本太高。


现代处理器的 L1 缓存通常使用优化的 SRAM 变体，如 8T SRAM（分离读写端口，允许同时读写不同地址）或 SRAM 宏单元（由 EDA 工具优化版图以获得最佳面积和速度）。


SRAM 的另一个重要应用是 FPGA 中的配置存储——FPGA 的可编程互连和 LUT 内容都存储在 SRAM 中，这就是为什么 FPGA 断电后需要重新加载配置。


DRAM 的结构与刷新机制
DRAM（Dynamic Random Access Memory）每个存储单元仅由一个晶体管和一个电容（1T1C）组成——电容充电表示 1，放电表示 0。这种极简结构使 DRAM 的密度远高于 SRAM（约 4-6 倍），但也带来了两个核心问题：


读操作是破坏性的。读取时，电容上的电荷通过访问晶体管泄放到位线上。读完后电容的电荷已经丢失，因此每次读操作之后必须将数据重新写回（称为"读后回写"或"预充"）。


电容会漏电。即使不读取，电容上的电荷也会因为漏电流而逐渐消失。因此 DRAM 必须周期性地刷新（Refresh）——逐行读出并回写，典型的刷新间隔为 64ms。


DRAM 的组织结构采用行列寻址：


    

  1. 首先发送行地址（RAS，Row Address Strobe），整行数据被读入行缓冲区
    2. 

  2. 然后发送列地址（CAS，Column Address Strobe），从行缓冲区中选取特定列
    3. 



这种两步寻址减少了地址引脚数量（行地址和列地址共享引脚），但也引入了额外延迟。


DRAM 的刷新操作需要逐行进行——64ms 内刷新所有行。对于一个包含 65536 行的 DRAM 芯片，平均每微秒需要刷新一行。刷新期间该行不可访问，这引入了周期性的性能波动。分布式刷新（每隔固定时间刷新一行）比集中式刷新（一次性刷新所有行）对性能影响更小。


ECC（Error Correcting Code）内存在每 64 位数据后附加 8 位校验码，可以检测并纠正单比特错误，检测双比特错误。服务器和数据中心广泛使用 ECC 内存以保证数据可靠性。

DDR（Double Data Rate）技术在时钟的上升沿和下降沿都传输数据，使得有效数据率翻倍。DDR4 工作在 1.2V，DDR5 降至 1.1V 并引入了片上 ECC（纠错码）和更高的预取宽度。


DRAM 的组织还涉及 Bank 和 Rank 的概念：每个 DRAM 芯片内部分为多个 Bank，每个 Bank 有独立的行缓冲区和地址解码器，可以并行处理不同 Bank 的访问请求。内存条上的多个 DRAM 芯片组成一个 Rank，控制器可以在不同 Rank 之间交替访问以隐藏延迟。


对程序员而言，DRAM 的行缓冲区命中（Row Buffer Hit）和未命中直接影响内存访问延迟。当连续访问同一行的不同列时（行命中），仅需 tCL 延迟；当访问不同行时（行冲突），需要 tRP + tRCD + tCL 的完整延迟——差距可达 3 倍。这就是为什么按行遍历二维数组比按列遍历快的又一个硬件层面解释。


interface DramTiming {
  readonly tRCD: number;
  readonly tCL: number;
  readonly tRP: number;
  readonly tRAS: number;
  readonly clockMHz: number;
}

function rowHitLatency(timing: DramTiming): number {
  return timing.tCL;
}

function rowMissLatency(timing: DramTiming): number {
  return timing.tRP + timing.tRCD + timing.tCL;
}

function bandwidth(timing: DramTiming, busWidth: number, ddrMultiplier: number): number {
  return (timing.clockMHz * 1e6 * busWidth * ddrMultiplier) / 8;
}
非易失性存储器
非易失性存储器（NVM）在断电后仍能保持数据，包括闪存（Flash）、EEPROM 和新兴的 MRAM、RRAM 等。


闪存是目前最重要的非易失性存储技术。它使用浮栅晶体管（Floating Gate Transistor）——通过向浮栅注入或抽取电子来改变晶体管的阈值电压，从而表示 0 或 1。

闪存有两个关键约束：写前必须擦除（不能直接覆盖，必须先将整个块擦除为全 1，再写入）和擦写次数有限（每个单元的浮栅绝缘层会随擦写次数增加而退化）。SSD 控制器使用磨损均衡（Wear Leveling）算法将写入均匀分布到所有块，延长存储器寿命。


FTL（Flash Translation Layer）是 SSD 控制器的核心组件——它将逻辑地址映射到物理地址，实现磨损均衡、垃圾回收和坏块管理。对程序员来说，理解 FTL 的存在有助于解释为什么 SSD 的顺序写远快于随机写——顺序写可以利用预擦除的空块，随机写则频繁触发垃圾回收。


新兴非易失性存储
传统闪存之外，多种新型非易失性存储技术正在兴起，它们有望填补 DRAM 和闪存之间的性能-容量空白。


MRAM（磁阻随机存储器） 利用磁隧道结（MTJ）的电阻变化存储信息。MRAM 具有接近 SRAM 的速度、接近 DRAM 的密度和非易失性，是最有希望的通用存储技术之一。STT-MRAM（自旋转移矩 MRAM）已经在嵌入式应用中商用化。


RRAM/ReRAM（电阻式随机存储器） 通过改变金属氧化物的电阻状态来存储数据。RRAM 的优势是结构简单（可在 CMOS 逻辑上方堆叠）和高密度潜力。


3D XPoint（被 Intel 命名为 Optane） 使用相变存储（PCM）技术，性能介于 DRAM 和 NAND 闪存之间——延迟约为 DRAM 的 3-10 倍，但容量可以远大于 DRAM。虽然 Intel 已停产 Optane，但 PCM 技术的概念仍然重要。

小结
    

  • 存储层次利用局部性原理在速度、容量和成本之间取得平衡
    • 

  • SRAM 用 6 个晶体管存储一位，速度快但密度低，用于缓存
    • 

  • DRAM 用 1 个晶体管和 1 个电容存储一位，密度高但需要刷新，用于主存
    • 

  • DDR 技术通过双边沿传输翻倍数据率，代际演进持续降低电压和提高频率
    • 

  • 闪存使用浮栅晶体管实现非易失存储，但有写前擦除和寿命限制
    • 

  • SSD 控制器的 FTL 层管理地址映射和磨损均衡，影响 SSD 的性能特征
