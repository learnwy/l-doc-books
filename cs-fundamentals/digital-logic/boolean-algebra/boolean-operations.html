布尔运算与真值表

核心概念

布尔代数是数字电路设计的数学基础，它将所有值约束为两种状态——真（1）和假（0），并在此基础上定义一套完整的运算体系。1854 年乔治·布尔提出这套形式系统时，无人预见它会成为计算机科学的基石。在现代计算中，CPU 的每一条指令最终都分解为布尔运算，编译器对条件分支的优化本质上就是布尔表达式的化简。

布尔代数与普通代数的关键区别在于值域的有限性——只有 0 和 1 两个元素，这带来了很多独特的性质，比如幂等律（A · A = A）在实数代数中并不成立。

三种基本运算
布尔代数的三种基本运算——与（AND）、或（OR）、非（NOT）——是构建整个数字系统的原子操作。所有复杂的逻辑功能都可以仅用这三种运算的组合来实现。


与运算（AND） 的含义是"同时为真才为真"。它对应电路中的串联结构，只有所有开关都闭合时电流才能通过。在编程中，&& 运算符执行的就是逻辑与操作。

或运算（OR） 的含义是"至少一个为真即为真"。它对应电路中的并联结构，任一开关闭合电流就能通过。编程中的 || 运算符执行逻辑或操作。


非运算（NOT） 是唯一的一元运算，将 0 变为 1、1 变为 0。它对应电路中的反相器。编程中的 ! 运算符执行逻辑非操作。


在位运算场景下，这三种运算逐位作用于二进制数。例如在 C/TypeScript 中：


const a = 0b1100;
const b = 0b1010;
const andResult = a & b; // 0b1000 = 8
const orResult = a | b; // 0b1110 = 14
const notResult = ~a; // 按位取反（注意补码表示）
理解位运算的本质就是理解布尔运算在每个二进制位上的独立应用。


复合运算与万能门
在三种基本运算的基础上，衍生出四种重要的复合运算，它们在电路设计中有着独特的地位。


异或（XOR） 的含义是"不同为真，相同为假"，公式为 A ⊕ B = A'B + AB'。异或运算在奇偶校验、加法器进位、加密算法中广泛使用。一个关键性质是 A ⊕ A = 0，这使得 XOR 在交换变量值时无需临时变量：


let x = 5,
  y = 3;
x = x ^ y; // x = 6
y = x ^ y; // y = 5
x = x ^ y; // x = 3
与非（NAND） 和 或非（NOR） 被称为万能门，因为仅用 NAND（或仅用 NOR）就可以实现所有其他逻辑运算。这一性质在集成电路制造中具有重要意义——芯片厂只需掌握一种门电路的制造工艺即可构建任意逻辑。

布尔代数基本定律
布尔代数有一套严格的公理和定理体系，这些定律是逻辑表达式化简的理论工具。理解并熟练运用这些定律，等同于掌握了一套"逻辑重构"的方法论。


基本公理：


    

  • 交换律：A + B = B + A，A · B = B · A
    • 

  • 结合律：A + (B + C) = (A + B) + C
    • 

  • 分配律：A · (B + C) = A · B + A · C，A + B · C = (A + B) · (A + C)
    • 

  • 互补律：A + A' = 1，A · A' = 0
    • 

  • 幂等律：A + A = A，A · A = A
    • 



关键定理：


    

  • 吸收律：A + A · B = A，A · (A + B) = A
    • 

  • 冗余律：A + A' · B = A + B
    • 

  • 德摩根定律：(A · B)' = A' + B'，(A + B)' = A' · B'
    • 



德摩根定律是最重要的化简工具之一。它揭示了"与"和"或"运算在取反下的对偶关系。在编程中，这意味着 !(a && b) 等价于 !a || !b，编译器经常利用这一等价性来优化分支条件。


// 德摩根定律的编程应用
// 原始表达式
if (!(isAdmin && isActive)) {
  /* ... */
}
// 等价变换（编译器可能的优化形式）
if (!isAdmin || !isActive) {
  /* ... */
}
对偶原理也是布尔代数的重要性质：将任何有效的布尔等式中的 AND 替换为 OR、OR 替换为 AND、0 替换为 1、1 替换为 0，得到的等式仍然成立。这使得定理的数量有效地翻倍。


真值表构造与分析
真值表是验证布尔表达式的终极工具——通过穷举所有输入组合来确定输出。对于 n 个变量的函数，真值表有 2^n 行。虽然穷举法随变量增长呈指数爆炸，但对于小规模逻辑（2-6 个变量）它仍是最可靠的验证手段。


构造真值表的步骤：


    

  1. 列出所有输入变量

  2. 生成所有 2^n 种输入组合（通常按二进制递增排列）
    3. 

  3. 根据布尔表达式逐行计算输出
    4. 

  4. 标记中间变量便于检查

真值表也是电路功能规格说明的标准形式。给定真值表后可以直接写出标准与或式（SOP）或标准或与式（POS）：


    

  • SOP（积之和）：从输出为 1 的行提取最小项，用 OR 连接。上例 F = Σm(1,3,6,7)
    • 

  • POS（和之积）：从输出为 0 的行提取最大项，用 AND 连接。上例 F = ΠM(0,2,4,5)
    • 



在实际开发中，可以用程序自动生成和验证真值表：


function truthTable(n: number, fn: (...args: number[]) => number) {
  for (let i = 0; i < 1 << n; i++) {
    const bits = Array.from({ length: n }, (_, j) => (i >> (n - 1 - j)) & 1);
    const result = fn(...bits);
    console.log(`${bits.join(' ')} | ${result}`);
  }
}

truthTable(3, (a, b, c) => (a & b) | (~a & 1 & c));
小结
    

  • 布尔代数以 {0, 1} 为值域，AND、OR、NOT 为基本运算，构成数字系统的数学基础
    • 

  • NAND 和 NOR 是万能门，各自都能独立构建所有逻辑功能
    • 

  • XOR 运算在校验、加密和算术运算中有独特价值
    • 

  • 德摩根定律揭示了与/或运算在取反下的对偶性，是化简的核心工具
    • 

  • 真值表通过穷举验证提供了布尔函数的完整规格，可导出 SOP 和 POS 标准形式
    • 

  • 布尔运算直接对应编程中的逻辑运算符和位运算符，理解底层原理有助于写出更高效的条件判断
    •
