卡诺图与最小化

核心概念

卡诺图（Karnaugh Map，K-map）是莫里斯·卡诺于 1953 年提出的布尔函数图形化化简方法。它将真值表映射到二维网格上，利用人类视觉的模式识别能力来发现可以合并的最小项组。与纯代数化简相比，卡诺图提供了一种"看得见"的化简过程，对于 2-6 个变量的函数特别高效。

卡诺图的核心原理是格雷码邻接——网格中相邻的格子对应的最小项仅有一个变量不同，因此相邻格子总是可以合并消去那个变量。这把代数合并操作转化为了几何上的"画圈"操作。

二变量与三变量卡诺图
卡诺图的构造规则是：行列标签按格雷码排列（相邻标签只差一位），而非按自然二进制顺序。


二变量卡诺图是 2×2 的网格，四个格子分别对应四个最小项：


        B=0    B=1
A=0  | m₀(0) | m₁(1) |
A=1  | m₂(2) | m₃(3) |
例如 F(A,B) = Σm(0,1,3)，在图中 m₀、m₁、m₃ 填 1。可以圈出两组：{m₀,m₁} 消去 B 得 A'，{m₁,m₃} 消去 A 得 B。最简式 F = A' + B。


三变量卡诺图是 2×4 的网格：


         BC=00  BC=01  BC=11  BC=10
A=0   | m₀(0) | m₁(1) | m₃(3) | m₂(2) |
A=1   | m₄(4) | m₅(5) | m₇(7) | m₆(6) |
注意 BC 列顺序是 00、01、11、10（格雷码），不是 00、01、10、11。这保证了水平相邻格子仅有一个变量不同。


关键规则：卡诺图的边界是环绕连通的——最左列与最右列相邻，最上行与最下行相邻。


例如 F(A,B,C) = Σm(0,2,4,6)，四个格子都在 C=0 列。{m₀,m₂,m₄,m₆} 可以合并为一个四格组，消去 A 和 B，得到 F = C'。


四变量卡诺图
四变量卡诺图是 4×4 的网格，是实际工程中最常用的规格：


          CD=00  CD=01  CD=11  CD=10
AB=00  | m₀    | m₁    | m₃    | m₂    |
AB=01  | m₄    | m₅    | m₇    | m₆    |
AB=11  | m₁₂   | m₁₃   | m₁₅   | m₁₄   |
AB=10  | m₈    | m₉    | m₁₁   | m₁₀   |
四变量图中，环绕连通使得四个角格 {m₀,m₂,m₈,m₁₀} 也构成有效组——它们共同特征是 B=0, D=0，即 B'D'。


画圈规则总结：


    

  1. 每个圈必须包含 2^k 个格子（1,2,4,8,16）
    2. 

  2. 圈必须是矩形（考虑环绕）
    3. 

  3. 圈越大越好（消去的变量越多）
    4. 

  4. 每个为 1 的格子至少被一个圈覆盖
    5. 

  5. 圈的数量尽可能少
    6. 

  6. 允许圈之间重叠
    7. 



实战案例：F(A,B,C,D) = Σm(0,1,2,4,5,6,8,9,10,13)


在卡诺图中标记后，可以识别出：


    

  • 八格组 {0,1,2,4,5,6,8,9,10} 中的 {0,1,4,5,8,9,0,1} → 实际分析需要逐步画圈
    • 

  • {m₀,m₁,m₄,m₅,m₈,m₉} 是 2×3 → 不合法（非 2 的幂）
    • 

  • 正确分组：{m₀,m₁,m₄,m₅} = B'D', {m₀,m₂,m₈,m₁₀} = B'D', {m₀,m₁,m₈,m₉} = B'C', {m₄,m₅,m₁₂,m₁₃} = BC'... 需要仔细选择最少覆盖
    • 



这个例子说明了四变量卡诺图的复杂性——当为 1 的格子较多时，存在多种有效分组方案，需要选择总圈数最少的。


无关项处理与 POS 化简
卡诺图处理无关项（Don't Care）的方法极其直观：将无关项格子标记为"X"，画圈时可以选择性地包含 X 格子。如果包含某个 X 能让圈更大（从而消去更多变量），就包含它；否则忽略它。


例如 F(A,B,C,D) = Σm(1,3,7) + Σd(0,5)，在卡诺图中：


    

  • m₁, m₃, m₇ 标记为 1
    • 

  • m₀, m₅ 标记为 X
    • 

  • 其余标记为 0
    • 



若包含 X₀：{m₀,m₁} 可以合并为 A'B'（而非单独的 m₁ = A'B'C）若包含 X₅：{m₁,m₃,m₅,m₇} 可以合并为 C（四格组，消去三个变量）


最终 F = C 是最简结果——仅靠一个四格组（包含两个无关项）就覆盖了所有必须为 1 的项。


POS 形式化简也可以用卡诺图完成，方法是：对输出为 0 的格子画圈，得到 F' 的 SOP 形式，然后用德摩根定律转换为 F 的 POS 形式。或者直接圈 0 格子，每个圈对应一个最大项。

选择 SOP 还是 POS 取决于哪种形式产生更少的项。当 1 格比 0 格少时，SOP 通常更简；反之 POS 更简。


五变量与六变量扩展
五变量卡诺图可以视为两张四变量卡诺图的叠加——第五个变量 E 决定使用哪张图。E=0 时的图和 E=1 时的图在空间上"对齐"，对应位置的格子仅在 E 上不同，因此可以跨图合并。


跨图合并规则：同一位置的格子（如 m₀ 和 m₁₆）可以合并为一组。例如 {m₀, m₁₆} 表示除 E 外其他变量都为 0 的情况，合并后消去 E 得 A'B'C'D'。


六变量卡诺图可以视为四张四变量图的叠加，操作更复杂。实际上超过四变量后，卡诺图的直观性优势急剧下降，更推荐使用 EDA 工具执行自动化简。


对于程序员来说，理解卡诺图的真正价值不在于手工画圈，而在于理解以下原理：


    

  • 逻辑化简本质是识别输入空间中的规律性模式
    • 

  • 相邻编码（格雷码）使"相似"状态在物理上相邻，便于模式发现
    • 

  • 这与数据压缩、模式匹配等计算问题有深层联系
    • 



格雷码本身在工程中也有独立应用。例如旋转编码器使用格雷码而非自然二进制，因为相邻位置只有一位翻转，避免了多位同时翻转时的毛刺问题。在软件领域，格雷码常用于异步 FIFO 的读写指针传递——跨时钟域时单位变化的编码更安全。


function binaryToGray(n: number): number {
  return n ^ (n >> 1);
}

function grayToBinary(gray: number): number {
  let binary = gray;
  let mask = gray >> 1;
  while (mask > 0) {
    binary ^= mask;
    mask >>= 1;
  }
  return binary;
}

for (let i = 0; i < 16; i++) {
  const gray = binaryToGray(i);
  console.log(`${i.toString(2).padStart(4, '0')} -> ${gray.toString(2).padStart(4, '0')}`);
}
小结
    

  • 卡诺图利用格雷码邻接将代数合并转化为几何画圈，对 2-4 变量函数极为高效
    • 

  • 画圈规则：大小为 2 的幂、矩形、越大越好、数量最少、允许重叠
    • 

  • 卡诺图边界环绕连通，四角格子也可能属于同一组
    • 

  • 无关项标为 X，按需包含以获得更大的圈
    • 

  • SOP 化简圈 1 格，POS 化简圈 0 格，选择项数更少的形式
    • 

  • 超过四变量后卡诺图的直观性下降，工业实践中使用 Espresso 等算法自动化简
    •
