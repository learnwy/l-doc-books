布尔表达式化简

核心概念

布尔表达式化简是数字电路设计中从"正确"到"高效"的关键环节。一个逻辑功能可以有无数种等价表达式，但不同表达式对应的电路在门数量、传播延迟和功耗上差异巨大。化简的目标是找到满足功能要求的最简表达式——使用最少的文字（literal）和最少的运算。

化简不仅是硬件设计的核心技能，也与软件优化密切相关。编译器在处理条件分支时会执行类似的布尔优化，程序员手动优化复杂的 if-else 链本质上也是在做布尔化简。

标准形式与最小项
化简的起点是将布尔函数表达为标准形式。标准形式有两种：最小项之和（SOP）与最大项之积（POS），它们提供了从真值表到代数表达式的规范化转换路径。


最小项（Minterm） 是包含所有变量恰好出现一次的乘积项，每个变量以原变量或反变量的形式出现。n 个变量的函数恰好有 2^n 个最小项，每个最小项在真值表中恰好使一行输出为 1。

最大项（Maxterm） 是包含所有变量恰好出现一次的和项。最大项 Mᵢ 是最小项 mᵢ 的补，即 Mᵢ 在真值表中恰好使第 i 行输出为 0。


将函数写成 SOP 形式：F = Σm(输出为1的行号)，例如 F = Σm(1,3,6,7) = A'B'C + A'BC + ABC' + ABC。


将函数写成 POS 形式：F = ΠM(输出为0的行号)，例如 F = ΠM(0,2,4,5)。


SOP 和 POS 形式是等价的，选择哪种取决于哪种形式中包含更少的项，从而对应更少的逻辑门。


代数化简技巧
代数化简依赖布尔代数定律对表达式进行等价变换。虽然没有固定算法能保证找到最优解，但有一套经过验证的常用策略。


策略一：合并相邻项。如果两个乘积项只有一个变量不同，可以合并消去该变量：


AB + AB' = A(B + B') = A · 1 = A


策略二：吸收消除冗余项。利用吸收律移除被"包含"的项：


A + AB = A(1 + B) = A


策略三：添加冗余项再合并。有时需要先添加一个不改变函数值的冗余项，以创造合并机会：


A'B + AB' + AB = A'B + A(B' + B) = A'B + A = A + B


策略四：德摩根变换。将复杂的取反运算展开：


(AB + CD)' = (AB)' · (CD)' = (A' + B')(C' + D')


实际案例——化简 F = A'BC + AB'C + ABC' + ABC：


F = A'BC + AB'C + ABC' + ABC
  = A'BC + ABC + AB'C + ABC + ABC' + ABC    // 添加冗余项 ABC 两次
  = BC(A' + A) + AC(B' + B) + AB(C' + C)    // 分组提取
  = BC + AC + AB                              // 最简形式
这个化简将 4 个三变量乘积项减少为 3 个两变量乘积项，电路从 12 个输入连线减少到 6 个。


// 验证化简正确性
function verify(a: number, b: number, c: number): boolean {
  const original = (!a && b && c) || (a && !b && c) || (a && b && !c) || (a && b && c);
  const simplified = (b && c) || (a && c) || (a && b);
  return original === simplified;
}

Quine-McCluskey 算法
Quine-McCluskey（Q-M）算法是布尔化简的系统化方法，它将代数化简的"直觉"过程转化为确定性的表格操作，保证找到所有质蕴涵项并从中选出最简覆盖。


算法分为两个阶段：


阶段一：生成质蕴涵项


    

  1. 按最小项中 1 的个数分组
    2. 

  2. 比较相邻组，找出仅一位不同的项对，合并并标记差异位为"-"
    3. 

  3. 重复直到无法继续合并
    4. 

  4. 未被合并的项就是质蕴涵项
    5. 



阶段二：选择最小覆盖


    

  1. 构建质蕴涵项覆盖表
    2. 

  2. 找出必要质蕴涵项（某最小项仅被一个质蕴涵项覆盖）
    3. 

  3. 对剩余最小项选择最少的质蕴涵项完成覆盖
    4.

合并过程产生：(0,1)=00-、(0,2)=0-0、(1,5)=-01、(2,6)=-10、(5,7)=1-1、(6,7)=11-


继续合并：(0,1,2,6)=0-0/00-无法合并更多。最终通过覆盖表选出最简结果。


Q-M 算法虽然理论完美，但时间复杂度为 O(3^n/n)，对于超过 15 个变量的函数实际中并不可行。工业界使用 Espresso 等启发式算法作为替代。


无关项与不完全指定函数
实际电路设计中经常遇到某些输入组合永远不会出现的情况，这些组合对应的输出称为无关项（Don't Care），用"d"或"X"表示。无关项在化简中具有重要价值——我们可以将它们自由地指定为 0 或 1，选择能产生更简表达式的值。


典型场景：BCD 码只使用 0000-1001（十个值），1010-1111 这六个组合永远不会出现。设计 BCD 相关电路时，这六个无关项可以大幅减少所需逻辑门。


例如 F(A,B,C,D) = Σm(1,3,7) + Σd(2,5) 表示最小项 1,3,7 必须输出 1，最小项 2,5 可以灵活选择。


如果选择 d(2)=0, d(5)=1：F = Σm(1,3,5,7) = C（仅取决于 C 的值）


如果选择 d(2)=1, d(5)=0：F = Σm(1,2,3,7) = A'B + B'C


显然第一种选择产生了极简表达式，仅需一根导线而无需任何逻辑门。


在 Q-M 算法中处理无关项的方法是：在阶段一（生成质蕴涵项）中将无关项视为 1 参与合并，但在阶段二（选择覆盖）中不要求覆盖无关项。这样既利用了无关项的化简潜力，又不引入不必要的约束。


对于程序员而言，无关项的概念对应着"未定义行为"——如果某些状态在设计上不可达，就不需要为它们编写处理逻辑，这可以简化控制流。

}
上面的 BCD 七段译码器只需要处理 0-9 十个值，输入 10-15 永远不会出现，对应的输出可以是任意值。这种约束在化简时被充分利用，使得七段显示器的驱动电路比完整四位二进制译码器简单得多。


小结
    

  • 化简的本质是在保持功能等价的前提下，最小化文字数和运算符数
    • 

  • SOP 和 POS 是真值表到代数表达式的两种标准转换形式
    • 

  • 代数化简依赖经验和技巧，常用策略包括合并相邻项、吸收律和德摩根变换
    • 

  • Q-M 算法将化简过程系统化，保证找到最优解但计算复杂度高
    • 

  • 无关项是实际设计中的重要资源，合理利用可以显著减少电路复杂度
    • 

  • 化简思想在软件中同样适用——简化条件表达式、消除冗余判断都是同一思想的体现
    •
