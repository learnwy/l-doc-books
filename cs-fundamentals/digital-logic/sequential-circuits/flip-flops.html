Part I · 理论基础 (Theory)数字逻辑与电路 简介时序电路 简介触发器与锁存器

触发器与锁存器

核心概念

锁存器和触发器是时序电路的基本存储元件——它们能够"记住"一个比特的信息。锁存器对电平敏感（level-sensitive），在控制信号有效期间可以随时改变状态；触发器对边沿敏感（edge-triggered），仅在时钟信号的上升沿或下降沿改变状态。这个看似微小的区别，决定了现代同步数字系统几乎全部基于触发器而非锁存器来构建。

在 CPU 中，寄存器文件由触发器阵列构成，流水线寄存器是触发器，缓存的标签存储也依赖触发器。可以说，触发器是数字系统中数据流动的"闸门"——时钟信号每跳动一次，数据向前推进一步。

SR 锁存器与竞争问题
SR 锁存器是最基本的存储元件，由两个交叉耦合的 NOR 门（或 NAND 门）构成。S（Set）输入将输出置为 1，R（Reset）输入将输出置为 0。

S=R=1 是禁止状态——此时两个输出都被强制为 0，当 S 和 R 同时返回 0 时，最终状态取决于哪个信号先变化，这引入了不确定性。


门控 SR 锁存器增加了使能（Enable）信号：只有当 EN=1 时，S 和 R 才有效。这提供了基本的时序控制，但仍然存在 S=R=1 的禁止问题。


D 锁存器通过将 S 和 R 连接为互补（S=D, R=D'）彻底消除了禁止状态。当 EN=1 时，Q 跟随 D 的值（透明），当 EN=0 时，Q 保持不变。D 锁存器也称为透明锁存器。


边沿触发 D 触发器
D 锁存器的"透明"特性在同步设计中是个问题——当使能信号有效时，输出会跟随输入变化，使得时序分析变得困难。边沿触发的 D 触发器解决了这个问题：它仅在时钟边沿的极短时间窗口内采样输入，其余时间输出保持不变。


主从（Master-Slave）结构是实现边沿触发的经典方法：两个 D 锁存器串联，前者（主锁存器）在时钟低电平时透明，后者（从锁存器）在时钟高电平时透明。由于两者永远不同时透明，数据只在时钟上升沿从主传递到从，实现了边沿触发效果。

如果数据在建立时间窗口内发生变化，触发器可能进入亚稳态——输出在 0 和 1 之间振荡不定。亚稳态最终会解析为确定值，但解析时间不可预测。这就是为什么跨时钟域传输信号时需要使用双触发器同步器——第一个触发器可能进入亚稳态，但它有整整一个时钟周期来解析，第二个触发器采样到的就是确定值了。


interface FlipFlopTiming {
  readonly setupTime: number;
  readonly holdTime: number;
  readonly clockToQ: number;
}

function maxCombLogicDelay(clockPeriod: number, source: FlipFlopTiming, dest: FlipFlopTiming): number {
  return clockPeriod - source.clockToQ - dest.setupTime;
}

function maxClockFrequency(criticalPathDelay: number, source: FlipFlopTiming, dest: FlipFlopTiming): number {
  const minPeriod = source.clockToQ + criticalPathDelay + dest.setupTime;
  return 1 / minPeriod;
}

JK 触发器的翻转功能在构建计数器时特别有用——将 J 和 K 都接 1，每个时钟沿输出都会翻转，形成分频器（输出频率是时钟频率的一半）。


T 触发器是 JK 触发器在 J=K 时的特化版本：当 T=1 时翻转，T=0 时保持。T 触发器是计数器设计的核心元件——n 个 T 触发器级联就构成了 n 位二进制计数器。

在现代设计实践中，D 触发器因其简单性和确定性成为主流选择。JK 和 T 触发器在教学和某些特殊应用（如计数器）中仍有价值，但 EDA 工具通常以 D 触发器为基础进行综合。


触发器的异步控制
实际的触发器通常配备异步控制信号——异步置位（Preset）和异步复位（Clear），它们不依赖时钟边沿，在任何时刻都能强制设置触发器的状态。


异步复位是系统上电初始化的关键机制。处理器在上电后，所有寄存器的初始状态是不确定的，必须通过一个全局复位信号将所有触发器清零，使系统从已知状态开始工作。

工业实践中常用的策略是"异步复位、同步释放"——复位信号异步生效（确保即使没有时钟也能复位），但通过同步器释放（确保释放时不会引入亚稳态）。


在实际的 Verilog/VHDL 设计中，触发器的行为通过进程块描述。以异步复位的 D 触发器为例，关键在于敏感列表同时包含时钟边沿和复位信号边沿。这种模式已经成为 RTL 设计的标准范式。


触发器的选择和配置直接影响芯片的面积、速度和功耗。高性能设计可能使用更大的触发器（更快但占面积更多），低功耗设计可能选择低漏电触发器（更慢但静态功耗更低）。EDA 工具在综合阶段会根据时序和功耗约束自动选择最合适的触发器单元。

  • 锁存器电平敏感，触发器边沿敏感，同步设计以触发器为基础

  • D 触发器通过主从结构实现边沿触发，消除了 SR 的禁止状态和锁存器的透明性问题

  • 建立时间和保持时间约束决定了电路的最高工作频率
