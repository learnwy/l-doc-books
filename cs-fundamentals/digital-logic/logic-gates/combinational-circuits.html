组合电路设计

核心概念

组合电路是输出完全由当前输入决定的数字电路——它没有记忆，不存储任何状态。给定相同的输入，组合电路总是产生相同的输出。这与时序电路形成对比：时序电路的输出还取决于过去的输入历史（即状态）。

组合电路设计是数字系统设计的基础方法论。从需求规格（真值表或布尔表达式）出发，经过化简优化，最终映射到具体的门电路实现——这一流程与软件开发中的"需求→设计→实现"高度相似。

两级逻辑实现
两级逻辑（Two-Level Logic）是最直接的组合电路实现方法。SOP（积之和）表达式直接对应两级结构：第一级是 AND 门（计算各乘积项），第二级是 OR 门（汇总所有项）。POS 形式则是先 OR 后 AND。


两级逻辑的传播延迟是固定的——恰好两级门延迟（加上可能的反相器延迟），与函数的复杂度无关。这使得两级实现具有可预测的时序特性。


但两级实现的代价是门数可能很多。对于 n 个输入的函数，最坏情况下需要 2^n 个 AND 门和一个 2^n 输入的 OR 门。


NAND-NAND 实现是两级逻辑的工程优化形式。由于 SOP 的 AND-OR 结构可以等价转换为 NAND-NAND 结构（利用双重取反），而 NAND 门在 CMOS 中是最高效的基本门，因此实际芯片中通常使用 NAND-NAND 形式：


F = A·B + C·D
  = ((A·B + C·D)')'         // 双重取反
  = ((A·B)' · (C·D)')'      // 德摩根定律
  = NAND(NAND(A,B), NAND(C,D))
类似地，POS 的 OR-AND 结构可以转换为 NOR-NOR 形式。


多级逻辑优化
当两级逻辑的门数过多时，多级实现可以通过因式分解减少总门数，代价是增加了级数（即更长的传播延迟）。


多级优化的核心技术是因式提取（Factoring）：


F = ACE + ACF + ADE + ADF + BCE + BCF + BDE + BDF
  = (A + B)(C + D)(E + F)    // 因式分解
两级实现需要 8 个三输入 AND 门 + 1 个八输入 OR 门 = 9 个门。因式分解后只需 3 个二输入 OR 门 + 2 个二输入 AND 门 = 5 个门，但级数从 2 增加到 3-4。


在实际工程中，两级和多级之间的选择是面积-延迟权衡。EDA 工具使用技术映射算法自动寻找给定约束下的最优实现。


子表达式共享是另一种重要的多级优化。当多个输出函数包含相同的子表达式时，只需计算一次并共享结果：


F1 = AB + CD
F2 = AB + EF
// AB 只需一个 AND 门，被 F1 和 F2 共享
竞争冒险与电路测试
组合电路中的竞争冒险（Hazard） 是由于不同信号路径的延迟差异导致的输出瞬态错误。理解冒险是设计可靠数字电路的关键。


静态冒险：输出应该保持不变但出现了短暂翻转


    

  • 静态 1 冒险：输出应为 1，但出现 1→0→1 的毛刺
    • 

  • 静态 0 冒险：输出应为 0，但出现 0→1→0 的毛刺
    • 



以 F = AB + A'C 为例，当 B=C=1 且 A 从 1→0 变化时：


    

  • AB 项从 1→0（通过 A 直接到达）
    • 

  • A'C 项从 0→1（通过反相器后到达，延迟更长）
    • 

  • 在短暂的时间窗口内，两项都为 0，F 出现 1→0→1 的毛刺
    • 



消除静态冒险的方法是添加冗余项：F = AB + A'C + BC。添加的 BC 项在 A 翻转期间保持为 1，覆盖了冒险窗口。


在卡诺图上，冒险对应于相邻但未被同一圈覆盖的 1 格。添加覆盖这些相邻格对的冗余圈即可消除冒险。


电路测试与故障检测也是组合电路工程中的重要话题。制造缺陷可能导致某根导线永远为 0（固定-0 故障）或永远为 1（固定-1 故障）。测试向量（test vector）是能区分正常电路和故障电路的输入组合。


type Bit = 0 | 1;
type TestVector = Bit[];

interface FaultTest {
  input: TestVector;
  expectedOutput: Bit;
  faultFreeOutput: Bit;
  detectedFaults: string[];
}

function canDetectFault(
  normalFn: (...args: Bit[]) => Bit,
  faultyFn: (...args: Bit[]) => Bit,
  input: TestVector,
): boolean {
  return normalFn(...input) !== faultyFn(...input);
}

利用无关项化简后，段 a 的表达式可以大幅简化。七个段的电路共享输入和部分中间逻辑，通过子表达式共享进一步减少门数。


这个案例展示了组合电路设计的完整流程：功能规格（显示需求）→ 真值表 → 化简（利用无关项）→ 门电路实现 → 子表达式优化。


对于程序员而言，组合电路设计思想在软件领域有直接对应：


    

  • 真值表 → 查找表（Lookup Table），用空间换时间的优化手段
    • 

  • 布尔化简 → 条件表达式简化，减少分支判断
    • 

  • 子表达式共享 → 公共子表达式消除（CSE），编译器标准优化
    • 

  • 多级逻辑 → 函数调用层次，深度与性能的权衡
    • 



const SEVEN_SEG_TABLE: ReadonlyArray<number> = [
  0b1111110, // 0: a,b,c,d,e,f
  0b0110000, // 1: b,c
  0b1101101, // 2: a,b,d,e,g
  0b1111001, // 3: a,b,c,d,g
  0b0110011, // 4: b,c,f,g
  0b1011011, // 5: a,c,d,f,g
  0b1011111, // 6: a,c,d,e,f,g
  0b1110000, // 7: a,b,c
  0b1111111, // 8: a,b,c,d,e,f,g
  0b1111011, // 9: a,b,c,d,f,g
];

function bcdToSegments(bcd: number): number {
  if (bcd < 0 || bcd > 9) return 0;
  return SEVEN_SEG_TABLE[bcd];
}
小结
    

  • 组合电路输出完全由当前输入决定，无记忆和反馈
    • 

  • 两级逻辑（AND-OR/NAND-NAND）提供固定延迟但可能门数较多
    • 

  • 多级逻辑通过因式分解减少门数，代价是增加延迟级数
    • 

  • 竞争冒险是延迟差异导致的瞬态错误，可通过添加冗余项消除
    • 

  • 子表达式共享在多输出电路中能显著减少硬件资源
    • 

  • 设计流程从功能规格出发，经化简优化，最终映射为门电路
    •
