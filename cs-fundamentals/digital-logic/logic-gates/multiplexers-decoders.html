多路复用器与解码器

核心概念

多路复用器（Multiplexer，MUX）和解码器（Decoder）是两种最重要的中规模组合电路模块。MUX 从多个输入中选择一个输出，解码器将编码信号展开为独热码（one-hot）信号。它们不仅是实际电路设计中的常用构件，更重要的是——MUX 可以实现任意布尔函数，解码器配合 OR 门也能实现任意函数，因此它们是通用的函数实现器。

在计算机体系结构中，MUX 无处不在：ALU 的操作数选择、寄存器堆的读取、流水线的数据通路控制都依赖 MUX。解码器则在指令译码、内存地址译码和中断优先级编码中扮演核心角色。

多路复用器的结构与原理
2:1 MUX 是最小的多路复用器：当选择信号 S=0 时输出 I₀，S=1 时输出 I₁。其布尔表达式为 Y = S'·I₀ + S·I₁。


4:1 MUX 有两位选择信号 S₁S₀，表达式为 Y = S₁'S₀'·I₀ + S₁'S₀·I₁ + S₁S₀'·I₂ + S₁S₀·I₃。每个乘积项对应一个 AND 门，将选择信号的某个组合与对应数据输入相与，最后所有项通过 OR 门汇总。


用 MUX 实现任意布尔函数是一个优雅的技巧。对于 n 变量函数，使用 2^n:1 MUX，将变量接到选择线，将真值表中每行的输出值（0 或 1）接到对应的数据输入：


F(A,B,C) = Σm(1,2,6,7)
使用 8:1 MUX，S₂=A, S₁=B, S₀=C
I₀=0, I₁=1, I₂=1, I₃=0, I₄=0, I₅=0, I₆=1, I₇=1
更高效的方法是使用 2^(n-1):1 MUX：将 n-1 个变量接选择线，第 n 个变量（或其补、0、1）接数据输入。这将所需 MUX 大小减半：


F(A,B,C) = Σm(1,2,6,7)，使用 4:1 MUX，S₁=A, S₀=B
当 AB=00：F 在 C=0 时为 0，C=1 时为 1 → I₀ = C
当 AB=01：F 在 C=0 时为 1，C=1 时为 0 → I₁ = C'
当 AB=10：F 在 C=0 时为 0，C=1 时为 0 → I₂ = 0
当 AB=11：F 在 C=0 时为 1，C=1 时为 1 → I₃ = 1

内存地址译码是解码器最重要的应用之一。一个拥有 1GB 内存空间的系统可能包含多个物理存储芯片，地址的高位通过解码器产生各芯片的片选（Chip Select）信号，低位直接连接到芯片的地址线。


编码器与优先编码器
编码器是解码器的逆运算——将独热码转换回二进制编码。普通编码器要求同一时刻恰好只有一个输入有效，否则输出无意义。


优先编码器（Priority Encoder） 解决了多个输入同时有效的问题：它输出最高优先级（通常是编号最大的）有效输入的编码。

I₃ 有最高优先级——当 I₃=1 时，不论其他输入如何，输出总是 11。V 位指示是否有任何有效输入。


优先编码器在中断控制器中至关重要。当多个设备同时发出中断请求时，优先编码器确保 CPU 首先响应最高优先级的中断。


function priorityEncode(inputs: boolean[]): { code: number; valid: boolean } {
  for (let i = inputs.length - 1; i >= 0; i--) {
    if (inputs[i]) {
      return { code: i, valid: true };
    }
  }
  return { code: 0, valid: false };
}

const result = priorityEncode([false, true, false, true]);
// { code: 3, valid: true } — 最高优先级的有效输入是 index 3
三态缓冲器与总线结构
三态缓冲器（Tri-State Buffer）是构建共享总线的基础元件。它有三种输出状态：逻辑 0、逻辑 1 和高阻态（Hi-Z）。当使能信号无效时，输出呈高阻态——相当于与总线断开连接。


总线协议确保同一时刻最多只有一个三态缓冲器处于使能状态，避免总线冲突（两个驱动源同时驱动总线会导致短路）。解码器常用于生成三态缓冲器的使能信号——这将 MUX、解码器和三态缓冲器联系在了一起。


在现代计算机中，MUX 方案因为不需要高阻态而更加可靠，但三态总线在需要双向通信的场景（如 I²C 总线）中仍然广泛使用。


从软件角度来看，MUX 对应的操作就是条件选择（三元运算符或 switch-case），解码器对应的是将索引值映射为独热操作（如数组下标访问触发特定分支），优先编码器对应的是优先级队列的出队操作。理解这些硬件原语有助于理解处理器如何在微架构层面实现程序控制流。


function mux4to1<T>(inputs: [T, T, T, T], select: number): T {
  return inputs[select & 0b11];
}

function decoder2to4(input: number): [boolean, boolean, boolean, boolean] {
  const idx = input & 0b11;
  return [idx === 0, idx === 1, idx === 2, idx === 3];
}

function priorityEncoder8(inputs: boolean[]): { code: number; valid: boolean } {
  for (let i = 7; i >= 0; i--) {
    if (inputs[i]) return { code: i, valid: true };
  }
  return { code: 0, valid: false };
}
小结
    

  • MUX 是多选一元件，通过将真值表映射到数据输入可以实现任意布尔函数
    • 

  • 使用 2^(n-1):1 MUX 配合最后一个变量作数据输入，可以将所需规模减半
    • 

  • 解码器产生独热码输出，配合 OR 门可实现任意函数
    • 

  • 使能信号使解码器可以级联构建更大规模的译码网络
    • 

  • 优先编码器在多个同时有效的输入中选择最高优先级的进行编码
    • 

  • 三态缓冲器通过高阻态实现总线共享，解码器生成其使能控制信号
    •
