Web 安全基础 简介

Web 应用是现代互联网的核心载体，也是攻击者最主要的攻击面。OWASP Top 10 持续更新的漏洞清单表明，跨站脚本（XSS）、跨站请求伪造（CSRF）、注入攻击和服务端请求伪造（SSRF）始终位列最高风险的安全威胁。理解这些漏洞的原理与防御手段，是每位 Web 开发者的必备技能。

本章从四个方面系统剖析 Web 安全基础：

XSS 攻击与防御 — 跨站脚本攻击是最普遍的 Web 漏洞之一。从反射型、存储型到 DOM 型 XSS，攻击者通过注入恶意脚本窃取用户数据。防御体系包括输出编码、输入净化、CSP 策略和 HttpOnly Cookie。

CSRF 与请求伪造 — CSRF 利用浏览器自动携带 Cookie 的机制，诱导用户在已认证的站点上执行非预期操作。Token 验证、SameSite Cookie 和双重提交是三大核心防御策略。

SQL 注入与 NoSQL 注入 — 注入攻击通过篡改查询语句来绕过认证或窃取数据。参数化查询、ORM 框架和最小权限原则是防御注入的根本手段。

SSRF 与服务端攻击 — SSRF 允许攻击者通过服务端发起内部网络请求，可探测内网服务甚至读取云元数据。URL 白名单、网络隔离和请求校验是关键防护措施。

掌握这四类核心漏洞的攻防原理，你将能够在开发过程中主动识别并消除安全隐患，构建真正可信赖的 Web 应用。
