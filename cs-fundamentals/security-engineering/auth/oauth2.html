OAuth 2.0 协议详解

OAuth 2.0 概述

OAuth 2.0 是一种授权框架，允许第三方应用在不获取用户密码的情况下，代表用户访问受保护的资源。OAuth 2.0 解决的核心问题是委托授权——用户将部分权限授予第三方应用，而非共享自己的凭证。

PKCE 扩展
PKCE（Proof Key for Code Exchange）为公开客户端（SPA、移动 App）提供额外安全保护，防止授权码被截获后滥用。

小结
    

  • OAuth 2.0 是授权框架，OIDC 在其上增加了身份认证能力
    • 

  • 授权码 + PKCE 是当前所有客户端类型的推荐模式
    • 

  • Access Token 应短有效期，配合 Refresh Token 实现无感续期
    • 

  • 隐式模式和密码模式已废弃，不应在新项目中使用
    • 

  • 严格校验 redirect_uri 和使用 state 参数是防止攻击的关键
