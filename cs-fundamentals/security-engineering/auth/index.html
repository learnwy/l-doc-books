认证与授权 简介

认证（Authentication）回答"你是谁"，授权（Authorization）回答"你能做什么"。这两个概念构成了访问控制的核心。从传统的用户名密码登录，到 OAuth 2.0 委托授权，再到基于角色和属性的细粒度权限管理，现代应用的认证授权体系日趋复杂。

本章从四个维度系统梳理认证与授权的核心知识：

OAuth 2.0 协议详解 — OAuth 2.0 是当前最广泛采用的授权框架，支持授权码、客户端凭证等多种授权模式。PKCE 扩展解决了公开客户端的安全问题，OpenID Connect 在 OAuth 2.0 之上增加了身份认证层。

JWT 与 Token 安全 — JSON Web Token 以自包含、无状态的特性成为分布式系统中令牌传递的事实标准。理解其结构、签名验证、过期策略和常见安全陷阱，是正确使用 JWT 的前提。

单点登录 SSO — SSO 让用户一次登录即可访问多个关联系统。SAML、CAS 和基于 OIDC 的 SSO 各有适用场景，Session 管理和单点登出是实现中的难点。

RBAC 与权限模型 — 从基于角色的访问控制（RBAC）到基于属性的访问控制（ABAC），权限模型决定了系统的灵活性和安全性。策略引擎（如 OPA、Casbin）为复杂权限场景提供了声明式解决方案。

认证授权是安全体系的第一道防线——设计正确的认证流程和权限模型，才能在保障安全的同时提供流畅的用户体验。
