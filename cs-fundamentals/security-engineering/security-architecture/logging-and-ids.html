日志监控与入侵检测

安全日志概述

安全日志是事件检测、威胁分析和事件响应的基础。完善的日志体系使安全团队能够回答三个关键问题：发生了什么？何时发生？谁做的？

日志类型 来源 记录内容
系统日志 操作系统 登录、进程、文件操作
应用日志 Web 服务器、应用程序 请求、错误、业务操作
安全日志 WAF、IDS、防火墙 攻击检测、策略违规
审计日志 数据库、权限系统 数据访问、权限变更
网络日志 路由器、交换机、代理 流量、连接、DNS 查询

安全日志规范

必须记录的安全事件

事件类型 示例
认证事件 登录成功/失败、密码重置、MFA 验证
授权事件 权限变更、角色分配、访问拒绝
数据操作 敏感数据查询、批量导出、删除
系统变更 配置修改、部署发布、服务启停
异常行为 频繁失败、非工作时间访问、IP 异常

日志格式

字段 说明
timestamp ISO 8601 格式时间戳
level 日志级别
event_type 事件类型
actor 操作者身份
action 执行的操作
resource 目标资源
outcome 操作结果
source_ip 来源 IP
user_agent 客户端信息

日志安全要求

要求 说明
不记录密码 日志中绝不包含密码、Token 等
数据脱敏 手机号、身份证等做掩码处理
防篡改 日志写入后不可修改
集中存储 统一收集到安全日志平台
保留期限 至少保留 180 天，合规要求更长

小结
    

  • 安全日志必须记录认证、授权、数据操作、系统变更等关键事件
    • 

  • 日志中绝不包含密码和 Token，敏感信息必须脱敏处理
    • 

  • SIEM 平台提供日志集中管理、关联分析和实时告警能力
    • 

  • IDS 的检测方式应组合使用特征匹配 + 异常检测 + 威胁情报
    • 

  • 事件响应按 检测→分析→遏制→根除→恢复→复盘 六步执行
    •
