双指针

核心概念

双指针是一种利用两个指针（索引）在数组或链表上协同移动来高效解决问题的算法技巧。其核心思想是通过指针的有序移动来缩小搜索空间，将暴力枚举的 O(n2)O(n^2)O(n2) 复杂度优化到 O(n)O(n)O(n)。根据两个指针的运动方式，双指针可以分为多种模式，每种模式适用于不同类型的问题。

对撞指针
对撞指针将两个指针分别放在数组的首尾，根据条件向中间收缩。这种模式的前提通常是数组已排序或具有某种单调性，使得每次移动都能排除一部分无效解。


经典问题——两数之和（有序数组版本）：在排序数组中找到和为目标值的两个数。


function twoSum(nums: number[], target: number): [number, number] {
  let left = 0;
  let right = nums.length - 1;

  while (left < right) {
    const sum = nums[left] + nums[right];
    if (sum === target) {
      return [left, right];
    } else if (sum < target) {
      left++;
    } else {
      right--;
    }
  }

  return [-1, -1];
}
为什么对撞指针是正确的？当 sum < target 时，left 已经是当前最小值，与 right 配对都不够大，那么 left 与任何更小的 right 配对更不可能，所以 left++。反之亦然。每次移动至少排除一个候选，保证了 O(n)O(n)O(n) 的复杂度。


盛最多水的容器是对撞指针的另一个经典应用：


function maxArea(height: number[]): number {
  let left = 0;
  let right = height.length - 1;
  let maxWater = 0;

  while (left < right) {
    const water = Math.min(height[left], height[right]) * (right - left);
    maxWater = Math.max(maxWater, water);

    if (height[left] < height[right]) {
      left++;
    } else {
      right--;
    }
  }

  return maxWater;
}
移动较矮一侧的指针是贪心策略：保留较高的边界，尝试找到更高的另一边来增加面积。


快慢指针
快慢指针让两个指针从同一位置出发，以不同的速度移动。它在链表问题中应用广泛，最经典的场景是环检测和寻找中间节点。


Floyd 判圈算法：快指针每次走两步，慢指针每次走一步。如果链表有环，快指针一定会追上慢指针。


interface ListNode {
  val: number;
  next: ListNode | null;
}

function hasCycle(head: ListNode | null): boolean {
  let slow = head;
  let fast = head;

  while (fast !== null && fast.next !== null) {
    slow = slow!.next;
    fast = fast.next.next;
    if (slow === fast) return true;
  }

  return false;
}
找到环的入口节点：当快慢指针相遇后，将其中一个指针重置到头节点，然后两个指针都以步长 1 移动，再次相遇点即为环的入口。


function detectCycle(head: ListNode | null): ListNode | null {
  let slow = head;
  let fast = head;

  while (fast !== null && fast.next !== null) {
    slow = slow!.next;
    fast = fast.next.next;
    if (slow === fast) {
      let entry = head;
      while (entry !== slow) {
        entry = entry!.next;
        slow = slow!.next;
      }
      return entry;
    }
  }

  return null;
}
数学证明：设环前长度为 aaa，环长为 bbb，相遇时慢指针走了 a+ka + ka+k 步，快指针走了 2(a+k)2(a+k)2(a+k) 步。快指针多走的恰好是环的整数倍：2(a+k)−(a+k)=nb2(a+k) - (a+k) = nb2(a+k)−(a+k)=nb，即 a+k=nba+k = nba+k=nb，所以 a=nb−ka = nb - ka=nb−k。从相遇点再走 aaa 步恰好到环入口。


同向双指针与原地操作
同向双指针在数组原地修改的场景中特别有用。一个指针负责扫描，另一个指针标记有效位置。


删除排序数组中的重复项：


function removeDuplicates(nums: number[]): number {
  if (nums.length === 0) return 0;

  let slow = 0;

  for (let fast = 1; fast < nums.length; fast++) {
    if (nums[fast] !== nums[slow]) {
      slow++;
      nums[slow] = nums[fast];
    }
  }

  return slow + 1;
}
移动零到数组末尾：


function moveZeroes(nums: number[]): void {
  let slow = 0;

  for (let fast = 0; fast < nums.length; fast++) {
    if (nums[fast] !== 0) {
      [nums[slow], nums[fast]] = [nums[fast], nums[slow]];
      slow++;
    }
  }
}
这类问题的通用模式：slow 指向下一个要填入的位置，fast 扫描所有元素，满足条件就写入 slow 并推进。

三数之和与多指针扩展
三数之和问题是双指针在面试中最经典的综合应用。核心思路是：排序后固定一个数，在剩余部分使用对撞指针搜索两数之和。


function threeSum(nums: number[]): number[][] {
  nums.sort((a, b) => a - b);
  const result: number[][] = [];

  for (let i = 0; i < nums.length - 2; i++) {
    if (i > 0 && nums[i] === nums[i - 1]) continue;
    if (nums[i] > 0) break;

    let left = i + 1;
    let right = nums.length - 1;

    while (left < right) {
      const sum = nums[i] + nums[left] + nums[right];
      if (sum === 0) {
        result.push([nums[i], nums[left], nums[right]]);
        while (left < right && nums[left] === nums[left + 1]) left++;
        while (left < right && nums[right] === nums[right - 1]) right--;
        left++;
        right--;
      } else if (sum < 0) {
        left++;
      } else {
        right--;
      }
    }
  }

  return result;
}
去重是三数之和的关键难点：外层跳过相同的 nums[i]，内层找到解后跳过相同的 left 和 right。


小结
    

  • 双指针通过有序移动缩小搜索空间，将 O(n2)O(n^2)O(n2) 优化到 O(n)O(n)O(n)
    • 

  • 对撞指针适用于有序数组上的搜索问题，核心是每次移动排除无效候选
    • 

  • 快慢指针是链表问题的利器，Floyd 判圈算法是其最经典的应用
    • 

  • 同向双指针用于原地操作，slow 标记有效位置、fast 扫描全部元素
    • 

  • 三数之和展示了排序 + 固定 + 对撞的经典组合，去重是关键实现细节
    • 

  • 双指针的正确性往往依赖于单调性或有序性，使用前需确认前提条件
    •
