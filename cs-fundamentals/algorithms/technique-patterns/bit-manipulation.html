位运算

核心概念

位运算是直接对整数的二进制位进行操作的运算。由于计算机本质上以二进制存储和处理数据，位运算的执行效率极高，通常只需一个 CPU 时钟周期。在算法中，位运算不仅能实现高效的数学计算，还能巧妙地解决去重、查找、状态压缩等一系列问题。

位运算基础技巧
掌握以下基础技巧是使用位运算解题的前提。每个技巧都有直观的二进制含义。


判断奇偶：n & 1 等价于 n % 2，因为奇数的最低位一定是 1。


function isOdd(n: number): boolean {
  return (n & 1) === 1;
}
获取最低位的 1（lowbit）：n & (-n) 提取出 nnn 的二进制表示中最低位的 1。这在树状数组（Binary Indexed Tree）中是核心操作。


function lowbit(n: number): number {
  return n & -n;
}
消除最低位的 1：n & (n - 1) 将 nnn 的最低位的 1 变为 0。这个技巧可用于统计二进制中 1 的个数。


function countBits(n: number): number {
  let count = 0;
  while (n !== 0) {
    n = n & (n - 1);
    count++;
  }
  return count;
}
判断是否为 2 的幂：n > 0 && (n & (n - 1)) === 0。2 的幂在二进制中只有一个 1。

异或的神奇性质
异或运算具有一组独特的代数性质，使其成为解决"查找唯一数"类问题的利器：


    

  • 自反性：a⊕a=0a \oplus a = 0a⊕a=0
    • 

  • 恒等性：a⊕0=aa \oplus 0 = aa⊕0=a
    • 

  • 交换律：a⊕b=b⊕aa \oplus b = b \oplus aa⊕b=b⊕a
    • 

  • 结合律：(a⊕b)⊕c=a⊕(b⊕c)(a \oplus b) \oplus c = a \oplus (b \oplus c)(a⊕b)⊕c=a⊕(b⊕c)
    • 



只出现一次的数字：数组中每个元素出现两次，只有一个出现一次，找到它。


function singleNumber(nums: number[]): number {
  let result = 0;
  for (const num of nums) {
    result ^= num;
  }
  return result;
}
所有成对的数异或后互相抵消为 0，最终只剩下那个出现一次的数。时间 O(n)O(n)O(n)，空间 O(1)O(1)O(1)，比哈希表解法更优雅。


进阶——两个只出现一次的数字：


function singleNumbers(nums: number[]): [number, number] {
  let xorAll = 0;
  for (const num of nums) {
    xorAll ^= num;
  }

  const diffBit = xorAll & -xorAll;

  let a = 0;
  let b = 0;
  for (const num of nums) {
    if ((num & diffBit) === 0) {
      a ^= num;
    } else {
      b ^= num;
    }
  }

  return [a, b];
}
关键洞察：a ^ b 不为 0，说明 aaa 和 bbb 在某一位上不同。取出这个不同的位，就可以将所有数字分成两组，aaa 和 bbb 一定分在不同组，而成对的数字一定在同组。


位掩码与状态压缩
位掩码（Bitmask）用一个整数的每一位来表示一个布尔状态，从而将一组布尔值压缩到一个整数中。这在需要表示集合、子集枚举、状态记忆等场景中非常高效。


function subsets(nums: number[]): number[][] {
  const n = nums.length;
  const result: number[][] = [];

  for (let mask = 0; mask < 1 << n; mask++) {
    const subset: number[] = [];
    for (let i = 0; i < n; i++) {
      if ((mask >> i) & 1) {
        subset.push(nums[i]);
      }
    }
    result.push(subset);
  }

  return result;
}
位掩码的常用操作：


const SET_BIT = (mask: number, i: number) => mask | (1 << i);
const CLEAR_BIT = (mask: number, i: number) => mask & ~(1 << i);
const TOGGLE_BIT = (mask: number, i: number) => mask ^ (1 << i);
const CHECK_BIT = (mask: number, i: number) => (mask >> i) & 1;
const COUNT_BITS = (mask: number) => {
  let count = 0;
  let m = mask;
  while (m) {
    m &= m - 1;
    count++;
  }
  return count;
};
状态压缩动态规划示例——旅行商问题（TSP）的位掩码 DP：


function tsp(dist: number[][]): number {
  const n = dist.length;
  const ALL = (1 << n) - 1;
  const dp: number[][] = Array.from({ length: 1 << n }, () => new Array(n).fill(Infinity));

  dp[1][0] = 0;

  for (let mask = 1; mask <= ALL; mask++) {
    for (let u = 0; u < n; u++) {
      if (dp[mask][u] === Infinity) continue;
      if (!((mask >> u) & 1)) continue;

      for (let v = 0; v < n; v++) {
        if ((mask >> v) & 1) continue;
        const newMask = mask | (1 << v);
        dp[newMask][v] = Math.min(dp[newMask][v], dp[mask][u] + dist[u][v]);
      }
    }
  }

  let result = Infinity;
  for (let u = 0; u < n; u++) {
    result = Math.min(result, dp[ALL][u] + dist[u][0]);
  }

  return result;
}
实战高频位运算问题
不用加减乘除实现加法：


function add(a: number, b: number): number {
  while (b !== 0) {
    const carry = (a & b) << 1;
    a = a ^ b;
    b = carry;
  }
  return a;
}
原理：a ^ b 是不进位的加法结果，(a & b) << 1 是进位。反复计算直到没有进位。


反转二进制位：


function reverseBits(n: number): number {
  let result = 0;
  for (let i = 0; i < 32; i++) {
    result = (result << 1) | (n & 1);
    n >>>= 1;
  }
  return result >>> 0;
}
小结
    

  • 位运算直接操作二进制位，效率极高，每次操作只需一个 CPU 时钟周期
    • 

  • n & (n-1) 消除最低位的 1 和 n & (-n) 取最低位的 1 是两个最核心的技巧
    • 

  • 异或的自反性（a⊕a=0a \oplus a = 0a⊕a=0）是解决"查找唯一数"问题的关键
    • 

  • 位掩码将集合状态压缩到一个整数中，在状态压缩 DP 中不可或缺
    • 

  • 位运算可以替代加法、取模、交换等常规运算，在特定场景下实现更优性能
    • 

  • 使用位运算时需注意 JavaScript 中数字是 64 位浮点数，位运算会先转为 32 位整数
    •
