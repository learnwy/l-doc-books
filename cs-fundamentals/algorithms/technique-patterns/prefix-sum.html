前缀和与差分数组

核心概念

前缀和与差分数组是一对互逆的数组预处理技巧。前缀和将"区间求和"这一高频操作从 O(n)O(n)O(n) 优化到 O(1)O(1)O(1)，差分数组则将"区间批量修改"从 O(n)O(n)O(n) 优化到 O(1)O(1)O(1)。两者互为逆运算：对差分数组求前缀和可以还原原数组，对原数组求差分可以得到差分数组。

一维前缀和
前缀和数组 prefix[i] 存储原数组前 iii 个元素的累加和。构建后，任意区间 [l,r][l, r][l,r] 的和可以通过 prefix[r+1] - prefix[l] 在 O(1)O(1)O(1) 时间内得到。


function buildPrefixSum(arr: number[]): number[] {
  const prefix = new Array(arr.length + 1).fill(0);
  for (let i = 0; i < arr.length; i++) {
    prefix[i + 1] = prefix[i] + arr[i];
  }
  return prefix;
}

function rangeSum(prefix: number[], left: number, right: number): number {
  return prefix[right + 1] - prefix[left];
}
为什么 prefix 的长度是 n + 1？额外的 prefix[0] = 0 让我们无需对 left === 0 做特殊处理，这是一种哨兵技巧。


经典应用——和为 kkk 的子数组个数：


function subarraySum(nums: number[], k: number): number {
  const prefixCount = new Map<number, number>();
  prefixCount.set(0, 1);
  let sum = 0;
  let count = 0;

  for (const num of nums) {
    sum += num;
    if (prefixCount.has(sum - k)) {
      count += prefixCount.get(sum - k)!;
    }
    prefixCount.set(sum, (prefixCount.get(sum) ?? 0) + 1);
  }

  return count;
}
这个解法的核心洞察：如果 prefix[j] - prefix[i] === k，那么子数组 [i, j-1] 的和为 kkk。用哈希表记录每个前缀和出现的次数，就能在遍历过程中统计所有满足条件的子数组。


差分数组
差分数组是前缀和的逆运算。diff[i] = arr[i] - arr[i-1]（diff[0] = arr[0]）。差分数组的核心优势：对区间 [l,r][l, r][l,r] 的所有元素加上 valvalval，只需修改两个位置：diff[l] += val，diff[r+1] -= val。


function buildDiff(arr: number[]): number[] {
  const diff = new Array(arr.length).fill(0);
  diff[0] = arr[0];
  for (let i = 1; i < arr.length; i++) {
    diff[i] = arr[i] - arr[i - 1];
  }
  return diff;
}

function rangeAdd(diff: number[], left: number, right: number, val: number): void {
  diff[left] += val;
  if (right + 1 < diff.length) {
    diff[right + 1] -= val;
  }
}

function restoreFromDiff(diff: number[]): number[] {
  const arr = new Array(diff.length);
  arr[0] = diff[0];
  for (let i = 1; i < diff.length; i++) {
    arr[i] = arr[i - 1] + diff[i];
  }
  return arr;
}
航班预订统计是差分数组的经典应用：有 nnn 个航班，多次预订操作 [first, last, seats] 表示从第 first 到第 last 个航班各预订 seats 个座位。


function corpFlightBookings(bookings: number[][], n: number): number[] {
  const diff = new Array(n + 1).fill(0);

  for (const [first, last, seats] of bookings) {
    diff[first - 1] += seats;
    if (last < n) {
      diff[last] -= seats;
    }
  }

  const result = new Array(n);
  result[0] = diff[0];
  for (let i = 1; i < n; i++) {
    result[i] = result[i - 1] + diff[i];
  }

  return result;
}

二维前缀和
二维前缀和将一维的思想扩展到矩阵。prefix[i][j] 表示从 (0,0)(0,0)(0,0) 到 (i−1,j−1)(i-1,j-1)(i−1,j−1) 的矩形区域元素之和。利用容斥原理，可以 O(1)O(1)O(1) 查询任意矩形区域的和。


function build2DPrefix(matrix: number[][]): number[][] {
  const m = matrix.length;
  const n = matrix[0].length;
  const prefix: number[][] = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      prefix[i][j] = matrix[i - 1][j - 1] + prefix[i - 1][j] + prefix[i][j - 1] - prefix[i - 1][j - 1];
    }
  }

  return prefix;
}

function regionSum(prefix: number[][], r1: number, c1: number, r2: number, c2: number): number {
  return prefix[r2 + 1][c2 + 1] - prefix[r1][c2 + 1] - prefix[r2 + 1][c1] + prefix[r1][c1];
}

前缀和的变体应用
前缀和的思想不仅限于求和，还可以推广到其他运算：


前缀异或——用于解决"区间异或"问题：


function xorQueries(arr: number[], queries: number[][]): number[] {
  const prefix = new Array(arr.length + 1).fill(0);
  for (let i = 0; i < arr.length; i++) {
    prefix[i + 1] = prefix[i] ^ arr[i];
  }

  return queries.map(([l, r]) => prefix[r + 1] ^ prefix[l]);
}
前缀积（需要处理零的特殊情况）和前缀 GCD 也是常见变体。

小结
    

  • 前缀和将区间求和从 O(n)O(n)O(n) 优化到 O(1)O(1)O(1)，核心是预处理累加和数组
    • 

  • 差分数组将区间修改从 O(n)O(n)O(n) 优化到 O(1)O(1)O(1)，只需修改区间两端
    • 

  • 前缀和与差分互为逆运算：对差分求前缀和还原原数组，对原数组求差分得到差分数组
    • 

  • 二维前缀和利用容斥原理实现矩形区域 O(1)O(1)O(1) 查询
    • 

  • 前缀和 + 哈希表是解决"子数组和满足某条件"问题的强大组合
    • 

  • 前缀和的思想可以推广到异或、积、GCD 等其他可结合运算
