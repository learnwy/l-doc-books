滑动窗口

核心概念

滑动窗口是一种在线性数据结构（数组或字符串）上维护一个动态区间的算法技巧。它可以看作双指针的一种特殊形式：用左右两个指针定义一个"窗口"，通过右指针扩张窗口纳入新元素、左指针收缩窗口排除旧元素，从而在 O(n)O(n)O(n) 时间内解决许多子数组或子串问题。

定长滑动窗口
定长窗口的模式最为直观：窗口大小固定为 kkk，右指针每前进一步，左指针也前进一步，始终维护大小为 kkk 的区间。


求大小为 kkk 的子数组的最大平均值：


function findMaxAverage(nums: number[], k: number): number {
  let windowSum = 0;

  for (let i = 0; i < k; i++) {
    windowSum += nums[i];
  }

  let maxSum = windowSum;

  for (let i = k; i < nums.length; i++) {
    windowSum += nums[i] - nums[i - k];
    maxSum = Math.max(maxSum, windowSum);
  }

  return maxSum / k;
}
定长窗口的关键优化：每次滑动只需加入右侧新元素、减去左侧旧元素，避免重复计算窗口内的总和，将 O(nk)O(nk)O(nk) 优化到 O(n)O(n)O(n)。


判断字符串是否包含另一个字符串的异位词：


function checkInclusion(s1: string, s2: string): boolean {
  if (s1.length > s2.length) return false;

  const count = new Array(26).fill(0);
  const aCode = 'a'.charCodeAt(0);

  for (let i = 0; i < s1.length; i++) {
    count[s1.charCodeAt(i) - aCode]++;
    count[s2.charCodeAt(i) - aCode]--;
  }

  if (count.every((c) => c === 0)) return true;

  for (let i = s1.length; i < s2.length; i++) {
    count[s2.charCodeAt(i) - aCode]--;
    count[s2.charCodeAt(i - s1.length) - aCode]++;
    if (count.every((c) => c === 0)) return true;
  }

  return false;
}
变长滑动窗口
变长窗口是滑动窗口中最强大也最常考的形式。右指针不断扩张，当窗口不满足条件时左指针收缩，直到重新满足条件。这种"扩张-收缩"的模式有一套通用模板。


最长无重复字符子串：


function lengthOfLongestSubstring(s: string): number {
  const charIndex = new Map<string, number>();
  let maxLen = 0;
  let left = 0;

  for (let right = 0; right < s.length; right++) {
    const ch = s[right];
    if (charIndex.has(ch) && charIndex.get(ch)! >= left) {
      left = charIndex.get(ch)! + 1;
    }
    charIndex.set(ch, right);
    maxLen = Math.max(maxLen, right - left + 1);
  }

  return maxLen;
}
最小覆盖子串是变长窗口的高难度经典题：


function minWindow(s: string, t: string): string {
  const need = new Map<string, number>();
  for (const ch of t) {
    need.set(ch, (need.get(ch) ?? 0) + 1);
  }

  let have = 0;
  const required = need.size;
  const windowCount = new Map<string, number>();
  let result = '';
  let minLen = Infinity;
  let left = 0;

  for (let right = 0; right < s.length; right++) {
    const ch = s[right];
    windowCount.set(ch, (windowCount.get(ch) ?? 0) + 1);

    if (need.has(ch) && windowCount.get(ch) === need.get(ch)) {
      have++;
    }

    while (have === required) {
      const windowLen = right - left + 1;
      if (windowLen < minLen) {
        minLen = windowLen;
        result = s.slice(left, right + 1);
      }
      const leftCh = s[left];
      windowCount.set(leftCh, windowCount.get(leftCh)! - 1);
      if (need.has(leftCh) && windowCount.get(leftCh)! < need.get(leftCh)!) {
        have--;
      }
      left++;
    }
  }

  return result;
}

滑动窗口通用模板
绝大多数滑动窗口问题都可以套用以下模板，关键差异在于"何时收缩"和"何时更新答案"。


求最长类型（最长满足条件的子数组）：


function slidingWindowMax(arr: number[], condition: (window: Map<number, number>) => boolean): number {
  const window = new Map<number, number>();
  let left = 0;
  let maxLen = 0;

  for (let right = 0; right < arr.length; right++) {
    window.set(arr[right], (window.get(arr[right]) ?? 0) + 1);

    while (!condition(window)) {
      const leftVal = arr[left];
      window.set(leftVal, window.get(leftVal)! - 1);
      if (window.get(leftVal) === 0) window.delete(leftVal);
      left++;
    }

    maxLen = Math.max(maxLen, right - left + 1);
  }

  return maxLen;
}
求最短类型（最短满足条件的子数组）：


function slidingWindowMin(arr: number[], target: number): number {
  let left = 0;
  let sum = 0;
  let minLen = Infinity;

  for (let right = 0; right < arr.length; right++) {
    sum += arr[right];

    while (sum >= target) {
      minLen = Math.min(minLen, right - left + 1);
      sum -= arr[left];
      left++;
    }
  }

  return minLen === Infinity ? 0 : minLen;
}

滑动窗口与单调队列
当需要在滑动窗口中动态维护最大值或最小值时，单调队列（双端队列）是最佳搭档。它能在 O(1)O(1)O(1) 均摊时间内获取窗口的极值。


滑动窗口最大值：


function maxSlidingWindow(nums: number[], k: number): number[] {
  const result: number[] = [];
  const deque: number[] = [];

  for (let i = 0; i < nums.length; i++) {
    while (deque.length > 0 && deque[0] <= i - k) {
      deque.shift();
    }

    while (deque.length > 0 && nums[deque[deque.length - 1]] <= nums[i]) {
      deque.pop();
    }

    deque.push(i);

    if (i >= k - 1) {
      result.push(nums[deque[0]]);
    }
  }

  return result;
}
单调队列的维护规则：队列中存储索引，队头始终是当前窗口的最大值索引。每次加入新元素时，从队尾移除所有小于新元素的索引（它们永远不可能成为最大值）。


小结
    

  • 滑动窗口通过维护动态区间将嵌套循环优化为单次遍历，时间复杂度 O(n)O(n)O(n)
    • 

  • 定长窗口每次滑动只做增量更新，适合固定大小的统计问题
    • 

  • 变长窗口通过"扩张-收缩"模式处理最长/最短子数组问题，关键是确定收缩条件
    • 

  • 求最长在条件不满足时收缩，求最短在条件满足时收缩——这是两种模板的核心差异
    • 

  • 单调队列与滑动窗口结合可以 O(1)O(1)O(1) 维护窗口极值，是高频面试考点
    • 

  • 绝大多数滑动窗口问题可以归纳为模板，差异仅在于窗口状态的维护方式和收缩判断
