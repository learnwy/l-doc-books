多边形算法

多边形是计算几何中最常见的复合对象，许多实际问题都归结为对多边形的处理：求一块地的面积、判断鼠标点击是否落在某个区域内、计算点集的最大跨度。这一节介绍三类经典的多边形算法——用鞋带公式求面积、用射线法判断点是否在多边形内，以及用旋转卡壳求凸多边形的直径。它们都建立在前面叉积、凸包等基础之上，是计算几何从"点线"走向"区域"的关键一步。

核心概念

多边形算法围绕三个核心问题展开，它们共同建立在叉积方向判定之上：

  • 面积（鞋带公式）：把多边形分解为若干以原点为顶点的三角形，用叉积求有向面积再累加；正负自动抵消凹凸，结果符号即顶点排列方向。
  • 内外判定（射线法）：从待判点引射线，统计与多边形边的交点个数，奇数为内、偶数为外；其正确性源于每次穿越边即发生内外切换。
  • 直径（旋转卡壳）：凸多边形的最远点对必为对踵点，随平行支撑线旋转，对踵点对沿边界单调推进，可用双指针在 O(n)O(n)O(n) 内求出。
  • 共同原语：三者都反复使用叉积的符号判定——面积用其数值、内外用穿越计数、卡壳用方向比较。

常见误解：射线法遇到射线恰好穿过顶点或与边共线时会重复/遗漏计数，必须约定一致的端点归属；旋转卡壳只能作用于凸多边形，对一般多边形须先求凸包。

多边形面积与鞋带公式

求任意简单多边形的面积，最优雅的方法是鞋带公式（Shoelace Formula）。给定多边形顶点按顺序排列的坐标，公式将相邻顶点坐标交叉相乘再求和，因运算形如系鞋带而得名。其本质是把多边形分解为一系列以原点为顶点的三角形，用叉积求出每个三角形的有向面积再累加。

由于使用的是有向面积，正负会自动抵消多边形外的部分，因此公式对凸多边形和凹多边形都成立。计算结果的符号还揭示了顶点的排列方向：结果为正表示顶点按逆时针排列，为负则为顺时针。取绝对值再除以二，即得到多边形的真实面积。鞋带公式只需遍历顶点一遍，时间复杂度为 O(n)O(n)O(n)，且在整数坐标下完全精确。

点在多边形内的判定

判断一个点是否落在多边形内部，是图形交互与地理查询中的高频操作。最通用的方法是射线法（Ray Casting）：从待判定点向任意方向引一条射线，统计它与多边形各边的交点个数。若交点为奇数，点在多边形内部；若为偶数，则在外部。

其原理在于，每穿过一条边，就意味着从"内"到"外"或从"外"到"内"切换一次，奇偶性自然编码了内外关系。射线法适用于任意简单多边形，包括凹多边形。实现时最棘手的是退化情形——射线恰好穿过某个顶点，或与某条边共线，这会导致交点被重复或遗漏计数。常见处理办法是约定只统计"边的一个端点严格在射线一侧"的情形，从而消除歧义。

flowchart TD
    A["从待判点引水平射线"] --> B["遍历多边形每条边"]
    B --> C{射线是否穿过该边}
    C -->|是| D["交点计数加一"]
    C -->|否| E["跳过"]
    D --> F{计数奇偶}
    E --> F
    F -->|奇数| G["点在多边形内"]
    F -->|偶数| H["点在多边形外"]

对于凸多边形，还有更高效的方法：依次用叉积判断点是否始终位于每条边的同一侧，若是则在内部。这一方法只需一次遍历，且无需处理射线退化问题，但仅适用于凸多边形。

旋转卡壳与多边形直径

旋转卡壳（Rotating Calipers）是一种作用于凸多边形的优雅技巧，最典型的应用是求凸多边形的直径——即相距最远的两个顶点之间的距离。直观上，它如同用一对平行的卡尺夹住凸多边形，绕着多边形不断旋转，在旋转过程中考察所有可能成为最远点对的顶点组合。

其关键洞察是：最远点对必然是一对"对踵点"，即存在一对平行支撑线分别经过它们。随着卡尺旋转，对踵点对沿多边形边界单调地推进，因此可以用类似双指针的方式，让两个指针沿凸多边形顶点同向移动，无需回退。这样，在已经求得凸包的前提下，旋转卡壳只需 O(n)O(n)O(n) 时间即可找出直径，配合 O(nlog⁡n)O(n \log n)O(nlogn) 的凸包构造，整体求平面点集直径的复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

应用场景与实践要点

多边形算法在工程中应用极广。地理信息系统用鞋带公式计算地块面积、用点在多边形内判定行政区归属；游戏与图形界面用点在多边形内实现命中检测；旋转卡壳除求直径外，还可求凸多边形的最小宽度、最小外接矩形与两凸多边形间的最近距离。

实践中需牢记几条要点：处理多边形时务必明确顶点的排列方向并保持一致；尽可能使用整数坐标以保证叉积和面积计算精确；对射线法、旋转卡壳等算法，要特别小心顶点共线、重复点等退化输入。这些算法看似各自独立，实则都以叉积的方向判定和凸包为共同根基，再次印证了计算几何"基础运算决定上层算法"的特点。

小结

  • 鞋带公式用相邻顶点坐标交叉相乘求和，本质是叉积有向面积的累加，对凹凸多边形均成立且 O(n)O(n)O(n)。
  • 射线法统计射线与多边形边的交点奇偶判断点的内外，适用任意简单多边形，难点在退化情形处理。
  • 对凸多边形，可用叉积判断点是否始终在各边同侧，一次遍历即可判定内外。
  • 旋转卡壳利用对踵点的单调推进，在凸包基础上以 O(n)O(n)O(n) 求多边形直径，整体 O(nlog⁡n)O(n \log n)O(nlogn)。
  • 多边形算法广泛用于面积计算、命中检测与最近距离，均以叉积方向判定与凸包为共同根基。
