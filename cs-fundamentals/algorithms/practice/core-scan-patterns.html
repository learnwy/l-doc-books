面试扫描类模式：双指针、滑动窗口与前缀和

概述

面试中的算法题目虽然千变万化，但绝大多数可以归纳为若干经典解题模式（Pattern）。掌握这些模式后，遇到新题时只需识别出它属于哪种类型，套用对应的模板加以变化即可。整套面试模式共有六种，本文聚焦其中作用于数组/字符串的三类线性扫描模式：双指针、滑动窗口和前缀和——它们的共同点是"用一次线性扫描换取暴力解无法达到的效率"。另外三种结构类模式（单调栈、矩阵 BFS/DFS、链表技巧）见姊妹篇《面试结构类模式：单调栈、矩阵遍历与链表技巧》。

flowchart LR
    subgraph Three Linear Scan Patterns
        A["Two Pointers<br/>Two Pointers"] ~~~ B["Sliding Window<br/>Sliding Window"] ~~~ C["Prefix Sum<br/>Prefix Sum"]
    end

每种模式都提供概念说明、TypeScript 模板代码和 1-2 道经典例题，帮助你快速建立肌肉记忆。

核心概念

面试算法题的核心概念在于从题型映射到解题模式（Pattern）：

  • 模式即结构：题目千变万化，但绝大多数可归入有限几种结构——双指针、滑动窗口、前缀和、单调栈、矩阵遍历、链表技巧。识别出题目属于哪种模式，就把"从零思考"转化为"套用模板 + 局部调整"。
  • 识别信号（Trigger）：每种模式都有可识别的题型信号。例如"有序数组找两数" → 双指针；"连续子数组/子串的极值" → 滑动窗口；"多次区间求和" → 前缀和；"下一个更大元素" → 单调栈。
  • 从暴力到模式的路径：先想清楚暴力解，再看暴力解中"哪些信息被重复计算"，这些冗余正是模式要消除的对象——滑动窗口消除重复扫描，前缀和消除重复求和。
  • 复杂度目标：模式的价值在于把 O(n2)O(n^2)O(n2) 或更高降到 O(n)O(n)O(n) / O(nlog⁡n)O(n \log n)O(nlogn)。
flowchart TD
    BF["Brute force O(n^2)<br/>Redundant work"]
    BF --> Q1{"What is repeated?"}
    Q1 -->|"Repeated pairwise<br/>scanning"| A1["Two Pointers"]
    Q1 -->|"Recomputed<br/>sub-interval window"| A2["Sliding Window"]
    Q1 -->|"Repeated range sum"| A3["Prefix Sum"]
模式 一句话定位 触发信号 目标复杂度
双指针 两个游标协同遍历线性结构 有序数组、回文、原地去重 O(n)O(n)O(n)
滑动窗口 维护一个动态连续区间 最长/最短连续子数组或子串 O(n)O(n)O(n)
前缀和 预处理累积和，把区间和变 O(1) 多次区间求和查询 预处理 O(n)O(n)O(n)，查询 O(1)O(1)O(1)

常见误解：死记模板而不理解适用条件——同一模式换一种约束（如数组有负数时滑动窗口失效）就会出错；把模式识别当成"看到关键词就套"，而不验证前提是否满足。

一、双指针（Two Pointers）

概念

双指针是指在遍历线性结构时，使用两个指针协同工作来高效解决问题的技巧。根据指针的运动方式，主要分为两类：

flowchart TD
    TP["Two Pointers Two Pointers"]
    TP --> LR["Left-Right Pointers<br/>(Collision Pointers)"]
    TP --> FS["Fast-Slow Pointers"]
    LR --> LR1["Converge from both ends"]
    LR --> LR2["For sorted arrays, palindromes"]
    FS --> FS1["Two pointers move same direction, different speed"]
    FS --> FS2["For cycle detection, in-place dedup"]
类型 运动方式 典型场景
左右指针（对撞指针） 一个从头、一个从尾，向中间移动 有序数组两数之和、盛水最多的容器、回文判断
快慢指针 两个指针从同一端出发，速度不同 链表环检测、找中间节点、原地去重

模板代码

左右指针模板：

function twoPointerLeftRight(arr: number[]): void {
  let left = 0;
  let right = arr.length - 1;

  while (left < right) {
    if (/* 满足条件 */) {
      // 收集结果
      left++;
      right--;
    } else if (/* 需要更大的值 */) {
      left++;
    } else {
      right--;
    }
  }
}

快慢指针模板：

function twoPointerFastSlow(arr: number[]): number {
  let slow = 0;

  for (let fast = 0; fast < arr.length; fast++) {
    if (/* 满足条件 */) {
      arr[slow] = arr[fast];
      slow++;
    }
  }

  return slow;
}

例题 1：有序数组两数之和（LeetCode 167）

给定一个升序排列的数组 numbers 和一个目标值 target，找到两个数使它们的和等于 target，返回它们的下标（1-indexed）。

flowchart LR
    subgraph "numbers = [2, 7, 11, 15], target = 9"
        direction LR
        A["L→ 2"] ~~~ B["7"] ~~~ C["11"] ~~~ D["←R 15"]
    end
    E["2 + 15 = 17 > 9 → Rmove left"]
    F["2 + 11 = 13 > 9 → Rmove left"]
    G["2 + 7 = 9 ✅ Found!"]
    A --> E --> F --> G
function twoSum(numbers: number[], target: number): number[] {
  let left = 0;
  let right = numbers.length - 1;

  while (left < right) {
    const sum = numbers[left] + numbers[right];
    if (sum === target) {
      return [left + 1, right + 1];
    } else if (sum < target) {
      left++;
    } else {
      right--;
    }
  }

  return [-1, -1];
}

// twoSum([2, 7, 11, 15], 9) → [1, 2]
指标 值
时间复杂度 O(n)O(n)O(n)
空间复杂度 O(1)O(1)O(1)

例题 2：原地移除元素（LeetCode 27）

给定数组 nums 和值 val，原地移除所有等于 val 的元素，返回新长度。

function removeElement(nums: number[], val: number): number {
  let slow = 0;

  for (let fast = 0; fast < nums.length; fast++) {
    if (nums[fast] !== val) {
      nums[slow] = nums[fast];
      slow++;
    }
  }

  return slow;
}

// removeElement([3, 2, 2, 3], 3) → 2, nums 前两位为 [2, 2]
指标 值
时间复杂度 O(n)O(n)O(n)
空间复杂度 O(1)O(1)O(1)

二、滑动窗口（Sliding Window）

概念

滑动窗口是双指针的一种特殊应用，用于在数组/字符串中维护一个连续区间（窗口），通过右边界扩展和左边界收缩来动态调整窗口大小，从而在 O(n)O(n)O(n) 时间内解决子数组/子串问题。

flowchart LR
    subgraph "Sliding Window Process"
        direction TB
        S1[[a, b, c] d, e, f → Expand right"]
        S2[a, [b, c, d] e, f → Continue expanding"]
        S3[a, b, [c, d, e] f → Condition met, shrink left"]
        S4[a, b, c, [d, e] f → Update result"]
        S1 --> S2 --> S3 --> S4
    end

模板代码

function slidingWindow(s: string): number {
  const window = new Map<string, number>();
  let left = 0;
  let result = 0;

  for (let right = 0; right < s.length; right++) {
    const charIn = s[right];
    window.set(charIn, (window.get(charIn) ?? 0) + 1);

    while (/* 窗口需要收缩 */) {
      const charOut = s[left];
      window.set(charOut, window.get(charOut)! - 1);
      if (window.get(charOut) === 0) window.delete(charOut);
      left++;
    }

    result = Math.max(result, right - left + 1);
  }

  return result;
}

例题 1：无重复字符的最长子串（LeetCode 3）

给定一个字符串 s，找出其中不含重复字符的最长子串的长度。

flowchart LR
    subgraph "s = 'abcabcbb'"
        direction TB
        W1[[a] bcabcbb → length 1"]
        W2[[a,b] cabcbb → length 2"]
        W3[[a,b,c] abcbb → length 3"]
        W4[a [b,c,a] bcbb → Duplicate a found, shrink → length 3"]
        W5[a,b [c,a,b] cbb → length 3"]
        W1 --> W2 --> W3 --> W4 --> W5
    end
    R["Final result: 3"]
    W5 --> R
function lengthOfLongestSubstring(s: string): number {
  const window = new Set<string>();
  let left = 0;
  let maxLen = 0;

  for (let right = 0; right < s.length; right++) {
    while (window.has(s[right])) {
      window.delete(s[left]);
      left++;
    }
    window.add(s[right]);
    maxLen = Math.max(maxLen, right - left + 1);
  }

  return maxLen;
}

// lengthOfLongestSubstring("abcabcbb") → 3
// lengthOfLongestSubstring("bbbbb") → 1
// lengthOfLongestSubstring("pwwkew") → 3
指标 值
时间复杂度 O(n)O(n)O(n)
空间复杂度 O(k)O(k)O(k)，kkk 为字符集大小

例题 2：长度最小的子数组（LeetCode 209）

给定正整数数组 nums 和正整数 target，找到满足和 ≥ target 的最短连续子数组长度。

function minSubArrayLen(target: number, nums: number[]): number {
  let left = 0;
  let sum = 0;
  let minLen = Infinity;

  for (let right = 0; right < nums.length; right++) {
    sum += nums[right];

    while (sum >= target) {
      minLen = Math.min(minLen, right - left + 1);
      sum -= nums[left];
      left++;
    }
  }

  return minLen === Infinity ? 0 : minLen;
}

// minSubArrayLen(7, [2, 3, 1, 2, 4, 3]) → 2（子数组 [4,3]）
指标 值
时间复杂度 O(n)O(n)O(n)
空间复杂度 O(1)O(1)O(1)

三、前缀和（Prefix Sum）

概念

前缀和是一种预处理技巧：预先计算数组从起点到每个位置的累积和，之后就能在 O(1)O(1)O(1) 时间内求出任意区间的和。核心公式：

sum(i,j)=prefix[j+1]−prefix[i]sum(i, j) = prefix[j + 1] - prefix[i]sum(i,j)=prefix[j+1]−prefix[i]
flowchart LR
    subgraph "Original array nums"
        N0["2"] ~~~ N1["3"] ~~~ N2["1"] ~~~ N3["4"] ~~~ N4["5"]
    end
    subgraph "Prefix sum prefix"
        P0["0"] ~~~ P1["2"] ~~~ P2["5"] ~~~ P3["6"] ~~~ P4["10"] ~~~ P5["15"]
    end
    Q[sum(1,3) = prefix[4] - prefix[1] = 10 - 2 = 8"]

模板代码

function buildPrefixSum(nums: number[]): number[] {
  const prefix: number[] = new Array(nums.length + 1).fill(0);

  for (let i = 0; i < nums.length; i++) {
    prefix[i + 1] = prefix[i] + nums[i];
  }

  return prefix;
}

function rangeSum(prefix: number[], left: number, right: number): number {
  return prefix[right + 1] - prefix[left];
}

例题 1：区域和检索 - 数组不可变（LeetCode 303）

给定整数数组 nums，处理多次查询 sumRange(left, right)，返回 nums[left] 到 nums[right] 的元素和。

class NumArray {
  private prefix: number[];

  constructor(nums: number[]) {
    this.prefix = new Array(nums.length + 1).fill(0);
    for (let i = 0; i < nums.length; i++) {
      this.prefix[i + 1] = this.prefix[i] + nums[i];
    }
  }

  sumRange(left: number, right: number): number {
    return this.prefix[right + 1] - this.prefix[left];
  }
}

// const arr = new NumArray([-2, 0, 3, -5, 2, -1]);
// arr.sumRange(0, 2) → 1
// arr.sumRange(2, 5) → -1
// arr.sumRange(0, 5) → -3
指标 值
预处理时间 O(n)O(n)O(n)
单次查询时间 O(1)O(1)O(1)
空间复杂度 O(n)O(n)O(n)

例题 2：和为 K 的子数组（LeetCode 560）

给定整数数组 nums 和整数 k，统计和为 k 的连续子数组的个数。

思路：遍历时维护前缀和，用哈希表记录每个前缀和出现的次数。若当前前缀和为 currSum，则 currSum - k 出现的次数就是以当前位置结尾、和为 k 的子数组个数。

flowchart TD
    S["Traverse array, maintain currSum"]
    C{"currSum - k<br/>in hash map?"}
    S --> C
    C -->|Yes| Y["count += map.get(currSum - k)"]
    C -->|No| N["Continue"]
    Y --> U["Update map: currSum count + 1"]
    N --> U
    U --> S
function subarraySum(nums: number[], k: number): number {
  const map = new Map<number, number>();
  map.set(0, 1);
  let currSum = 0;
  let count = 0;

  for (const num of nums) {
    currSum += num;
    if (map.has(currSum - k)) {
      count += map.get(currSum - k)!;
    }
    map.set(currSum, (map.get(currSum) ?? 0) + 1);
  }

  return count;
}

// subarraySum([1, 1, 1], 2) → 2
// subarraySum([1, 2, 3], 3) → 2
指标 值
时间复杂度 O(n)O(n)O(n)
空间复杂度 O(n)O(n)O(n)

小结

  • 双指针：利用两个指针协同遍历，避免嵌套循环。左右指针用于有序数组（两数之和、盛水容器、回文判断），快慢指针用于原地操作与去重。
  • 滑动窗口：维护一个动态区间，通过右扩左缩在 O(n)O(n)O(n) 内处理子串/子数组的最优化问题；只有当边界移动具有单调性时（非负数组求和、字符计数）才成立，含负数时常需退回前缀和。
  • 前缀和：一次预处理，多次 O(1)O(1)O(1) 查询区间和；配合哈希表可处理"和为 K 的子数组"这类计数问题。
  • 三者都建立在一次线性扫描之上，区别只在于"扫描时维护什么状态"：双指针维护两个下标，滑动窗口维护一个区间及其统计量，前缀和维护一个累积值。
  • 面试时先识别模式，再套用模板，最后根据具体题目微调细节——另外三种结构类模式（单调栈、矩阵 BFS/DFS、链表技巧）见姊妹篇。
