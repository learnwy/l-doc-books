面试常见题型

概述

面试中的算法题目虽然千变万化，但绝大多数可以归纳为若干经典解题模式（Pattern）。掌握这些模式后，遇到新题时只需识别出它属于哪种类型，套用对应的模板加以变化即可。本节涵盖面试高频的六大模式：双指针、滑动窗口、前缀和、单调栈、矩阵 BFS/DFS 和 链表技巧。



每种模式都提供概念说明、TypeScript 模板代码和 1-2 道经典例题，帮助你快速建立肌肉记忆。






一、双指针（Two Pointers）
概念
双指针是指在遍历线性结构时，使用两个指针协同工作来高效解决问题的技巧。根据指针的运动方式，主要分为两类：

运动方式
典型场景





左右指针（对撞指针）
一个从头、一个从尾，向中间移动
有序数组两数之和、盛水最多的容器、回文判断




快慢指针
两个指针从同一端出发，速度不同

模板代码
左右指针模板：


function twoPointerLeftRight(arr: number[]): void {
  let left = 0;
  let right = arr.length - 1;

  while (left < right) {
    if (/* 满足条件 */) {
      // 收集结果
      left++;
      right--;
    } else if (/* 需要更大的值 */) {
      left++;
    } else {
      right--;
    }
  }
}
快慢指针模板：


function twoPointerFastSlow(arr: number[]): number {
  let slow = 0;

  for (let fast = 0; fast < arr.length; fast++) {
    if (/* 满足条件 */) {
      arr[slow] = arr[fast];
      slow++;
    }
  }

  return slow;
}
例题 1：有序数组两数之和（LeetCode 167）


给定一个升序排列的数组 numbers 和一个目标值 target，找到两个数使它们的和等于 target，返回它们的下标（1-indexed）。




function twoSum(numbers: number[], target: number): number[] {
  let left = 0;
  let right = numbers.length - 1;

  while (left < right) {
    const sum = numbers[left] + numbers[right];
    if (sum === target) {
      return [left + 1, right + 1];
    } else if (sum < target) {
      left++;
    } else {
      right--;
    }
  }

  return [-1, -1];
}

// twoSum([2, 7, 11, 15], 9) → [1, 2]

function removeElement(nums: number[], val: number): number {

二、滑动窗口（Sliding Window）
概念
滑动窗口是双指针的一种特殊应用，用于在数组/字符串中维护一个连续区间（窗口），通过右边界扩展和左边界收缩来动态调整窗口大小，从而在 O(n)O(n)O(n) 时间内解决子数组/子串问题。


模板代码
function slidingWindow(s: string): number {
  const window = new Map<string, number>();
  let left = 0;
  let result = 0;

  for (let right = 0; right < s.length; right++) {
    const charIn = s[right];
    window.set(charIn, (window.get(charIn) ?? 0) + 1);

    while (/* 窗口需要收缩 */) {
      const charOut = s[left];
      window.set(charOut, window.get(charOut)! - 1);
      if (window.get(charOut) === 0) window.delete(charOut);
      left++;
    }

    result = Math.max(result, right - left + 1);
  }

  return result;
}
例题 1：无重复字符的最长子串（LeetCode 3）


给定一个字符串 s，找出其中不含重复字符的最长子串的长度。




function lengthOfLongestSubstring(s: string): number {
  const window = new Set<string>();
  let left = 0;
  let maxLen = 0;

  for (let right = 0; right < s.length; right++) {
    while (window.has(s[right])) {
      window.delete(s[left]);
      left++;
    }
    window.add(s[right]);
    maxLen = Math.max(maxLen, right - left + 1);
  }

  return maxLen;
}

例题 2：长度最小的子数组（LeetCode 209）


给定正整数数组 nums 和正整数 target，找到满足和 ≥ target 的最短连续子数组长度。




function minSubArrayLen(target: number, nums: number[]): number {
  let left = 0;
  let sum = 0;
  let minLen = Infinity;

  for (let right = 0; right < nums.length; right++) {
    sum += nums[right];

    while (sum >= target) {
      minLen = Math.min(minLen, right - left + 1);
      sum -= nums[left];
      left++;
    }
  }

  return minLen === Infinity ? 0 : minLen;
}

三、前缀和（Prefix Sum）
概念
前缀和是一种预处理技巧：预先计算数组从起点到每个位置的累积和，之后就能在 O(1)O(1)O(1) 时间内求出任意区间的和。核心公式：


sum(i,j)=prefix[j+1]−prefix[i]sum(i, j) = prefix[j + 1] - prefix[i]sum(i,j)=prefix[j+1]−prefix[i]
模板代码
function buildPrefixSum(nums: number[]): number[] {
  const prefix: number[] = new Array(nums.length + 1).fill(0);

  for (let i = 0; i < nums.length; i++) {
    prefix[i + 1] = prefix[i] + nums[i];
  }

  return prefix;
}

function rangeSum(prefix: number[], left: number, right: number): number {
  return prefix[right + 1] - prefix[left];
}
例题 1：区域和检索 - 数组不可变（LeetCode 303）


给定整数数组 nums，处理多次查询 sumRange(left, right)，返回 nums[left] 到 nums[right] 的元素和。




class NumArray {
  private prefix: number[];

  constructor(nums: number[]) {
    this.prefix = new Array(nums.length + 1).fill(0);
    for (let i = 0; i < nums.length; i++) {
      this.prefix[i + 1] = this.prefix[i] + nums[i];
    }
  }

  sumRange(left: number, right: number): number {
    return this.prefix[right + 1] - this.prefix[left];
  }
}

例题 2：和为 K 的子数组（LeetCode 560）


给定整数数组 nums 和整数 k，统计和为 k 的连续子数组的个数。




思路：遍历时维护前缀和，用哈希表记录每个前缀和出现的次数。若当前前缀和为 currSum，则 currSum - k 出现的次数就是以当前位置结尾、和为 k 的子数组个数。


function subarraySum(nums: number[], k: number): number {
  const map = new Map<number, number>();
  map.set(0, 1);
  let currSum = 0;
  let count = 0;

  for (const num of nums) {
    currSum += num;
    if (map.has(currSum - k)) {
      count += map.get(currSum - k)!;
    }
    map.set(currSum, (map.get(currSum) ?? 0) + 1);
  }

  return count;
}

// subarraySum([1, 1, 1], 2) → 2
// subarraySum([1, 2, 3], 3) → 2

四、单调栈（Monotonic Stack）
概念
单调栈是一种特殊的栈结构，栈内元素始终保持单调递增或单调递减。它常用于解决"寻找每个元素左边/右边第一个更大/更小的元素"这类问题，将暴力的 O(n2)O(n^2)O(n2) 优化到 O(n)O(n)O(n)。


模板代码
function nextGreaterElements(nums: number[]): number[] {
  const n = nums.length;
  const result: number[] = new Array(n).fill(-1);
  const stack: number[] = [];

  for (let i = 0; i < n; i++) {
    while (stack.length > 0 && nums[i] > nums[stack[stack.length - 1]]) {
      const topIdx = stack.pop()!;
      result[topIdx] = nums[i];
    }
    stack.push(i);
  }

  return result;
}
例题 1：每日温度（LeetCode 739）


给定每日温度数组 temperatures，返回一个数组 answer，其中 answer[i] 表示从第 i 天起，需要等待几天才能遇到更高的温度。如果之后没有更高温度，则为 0。




function dailyTemperatures(temperatures: number[]): number[] {
  const n = temperatures.length;
  const answer: number[] = new Array(n).fill(0);
  const stack: number[] = [];

  for (let i = 0; i < n; i++) {
    while (stack.length > 0 && temperatures[i] > temperatures[stack[stack.length - 1]]) {
      const prevIdx = stack.pop()!;
      answer[prevIdx] = i - prevIdx;
    }
    stack.push(i);
  }

  return answer;
}

// dailyTemperatures([73, 74, 75, 71, 69, 72, 76, 73]) → [1, 1, 4, 2, 1, 1, 0, 0]

例题 2：柱状图中最大的矩形（LeetCode 84）


给定 heights 数组表示柱状图中每个柱子的高度，求柱状图中能勾勒出的最大矩形面积。




思路：对于每根柱子，找到它左边和右边第一个比它矮的柱子位置，从而确定以该柱子高度为基准能扩展的最大宽度。


function largestRectangleArea(heights: number[]): number {
  const n = heights.length;
  const stack: number[] = [];
  let maxArea = 0;

  for (let i = 0; i <= n; i++) {
    const currHeight = i === n ? 0 : heights[i];

    while (stack.length > 0 && currHeight < heights[stack[stack.length - 1]]) {
      const height = heights[stack.pop()!];
      const width = stack.length === 0 ? i : i - stack[stack.length - 1] - 1;
      maxArea = Math.max(maxArea, height * width);
    }

    stack.push(i);
  }

  return maxArea;
}

// largestRectangleArea([2, 1, 5, 6, 2, 3]) → 10

五、矩阵 BFS / DFS
概念
在二维矩阵（网格）上进行搜索是面试中极其常见的题型。DFS（深度优先搜索） 用递归或栈深入探索每条路径，BFS（广度优先搜索） 用队列按层扩展，常用于求最短路径。


模板代码
DFS 模板（矩阵连通分量）：


function dfs(grid: number[][], row: number, col: number, visited: boolean[][]): void {
  const rows = grid.length;
  const cols = grid[0].length;

  if (row < 0 || row >= rows || col < 0 || col >= cols || visited[row][col] || grid[row][col] === 0) {
    return;
  }

  visited[row][col] = true;

  const dirs = [
    [0, 1],
    [0, -1],
    [1, 0],
    [-1, 0],
  ];
  for (const [dr, dc] of dirs) {
    dfs(grid, row + dr, col + dc, visited);
  }
}
BFS 模板（矩阵最短路径）：


function bfs(grid: number[][], startRow: number, startCol: number): number {
  const rows = grid.length;
  const cols = grid[0].length;
  const visited: boolean[][] = Array.from({ length: rows }, () =>
    new Array(cols).fill(false)
  );
  const queue: [number, number, number][] = [[startRow, startCol, 0]];
  visited[startRow][startCol] = true;

  const dirs = [[0, 1], [0, -1], [1, 0], [-1, 0]];

  while (queue.length > 0) {
    const [row, col, dist] = queue.shift()!;

    if (/* 到达目标 */) return dist;

    for (const [dr, dc] of dirs) {
      const nr = row + dr;
      const nc = col + dc;
      if (
        nr >= 0 && nr < rows &&
        nc >= 0 && nc < cols &&
        !visited[nr][nc] &&
        grid[nr][nc] !== 0
      ) {
        visited[nr][nc] = true;
        queue.push([nr, nc, dist + 1]);
      }
    }
  }

  return -1;
}
例题 1：岛屿数量（LeetCode 200）


给定一个由 '1'（陆地）和 '0'（水域）组成的二维网格，计算岛屿的数量。岛屿是被水域包围、且由相邻陆地（上下左右）连接形成的区域。




function numIslands(grid: string[][]): number {
  const rows = grid.length;
  const cols = grid[0].length;
  let count = 0;

  function dfs(r: number, c: number): void {
    if (r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] === '0') {
      return;
    }
    grid[r][c] = '0';
    dfs(r + 1, c);
    dfs(r - 1, c);
    dfs(r, c + 1);
    dfs(r, c - 1);
  }

  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      if (grid[r][c] === '1') {
        count++;
        dfs(r, c);
      }
    }
  }

  return count;
}

//   ["0","0","0","1","1"]

例题 2：腐烂的橘子（LeetCode 994）— BFS 求最短时间


网格中 0 为空格，1 为新鲜橘子，2 为腐烂橘子。每分钟腐烂橘子会使相邻的新鲜橘子变腐。返回所有橘子都腐烂的最少分钟数，不可能则返回 -1。




function orangesRotting(grid: number[][]): number {
  const rows = grid.length;
  const cols = grid[0].length;
  const queue: [number, number][] = [];
  let fresh = 0;

  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      if (grid[r][c] === 2) queue.push([r, c]);
      else if (grid[r][c] === 1) fresh++;
    }
  }

  if (fresh === 0) return 0;

  const dirs = [
    [0, 1],
    [0, -1],
    [1, 0],
    [-1, 0],
  ];
  let minutes = 0;

  while (queue.length > 0 && fresh > 0) {
    const size = queue.length;
    minutes++;

    for (let i = 0; i < size; i++) {
      const [r, c] = queue.shift()!;
      for (const [dr, dc] of dirs) {
        const nr = r + dr;
        const nc = c + dc;
        if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && grid[nr][nc] === 1) {
          grid[nr][nc] = 2;
          fresh--;
          queue.push([nr, nc]);
        }
      }
    }
  }

  return fresh === 0 ? minutes : -1;
}

// orangesRotting([[2,1,1],[1,1,0],[0,1,1]]) → 4

技巧 1：反转链表（LeetCode 206）


将单链表反转。




迭代法（推荐）：


function reverseList(head: ListNode | null): ListNode | null {
  let prev: ListNode | null = null;
  let curr = head;

  while (curr !== null) {
    const next = curr.next;
    curr.next = prev;
    prev = curr;
    curr = next;
  }

  return prev;
}
核心思路：三个指针 prev、curr、next 逐步翻转每条边的指向。

技巧 2：环形链表检测（LeetCode 141 / 142）


判断链表中是否有环。如果有，找到环的入口节点。




使用 Floyd 快慢指针算法：快指针每次走 2 步，慢指针每次走 1 步。如果存在环，两者必然相遇。


判断是否有环：


function hasCycle(head: ListNode | null): boolean {
  let slow = head;
  let fast = head;

  while (fast !== null && fast.next !== null) {
    slow = slow!.next;
    fast = fast.next.next;
    if (slow === fast) return true;
  }

  return false;
}
找到环的入口：


function detectCycle(head: ListNode | null): ListNode | null {
  let slow = head;
  let fast = head;

  while (fast !== null && fast.next !== null) {
    slow = slow!.next;
    fast = fast.next.next;

    if (slow === fast) {
      let entry = head;
      while (entry !== slow) {
        entry = entry!.next;
        slow = slow!.next;
      }
      return entry;
    }
  }

  return null;
}


数学证明：设起点到环入口距离为 aaa，环入口到相遇点距离为 bbb，相遇点回到环入口距离为 ccc。快指针走 a+b+c+ba + b + c + ba+b+c+b，慢指针走 a+ba + ba+b，由 2(a+b)=a+b+c+b2(a + b) = a + b + c + b2(a+b)=a+b+c+b 得 a=ca = ca=c。因此从起点和相遇点同时出发，必在入口处相遇。

技巧 3：合并两个有序链表（LeetCode 21）


将两个升序链表合并为一个升序链表。




使用虚拟头节点（dummy node） 简化边界处理：


function mergeTwoLists(list1: ListNode | null, list2: ListNode | null): ListNode | null {
  const dummy = new ListNode(0);
  let curr = dummy;

  while (list1 !== null && list2 !== null) {
    if (list1.val <= list2.val) {
      curr.next = list1;
      list1 = list1.next;
    } else {
      curr.next = list2;
      list2 = list2.next;
    }
    curr = curr.next;
  }

  curr.next = list1 ?? list2;

  return dummy.next;
}

小结
    

  • 双指针：利用两个指针协同遍历，避免嵌套循环。左右指针用于有序数组，快慢指针用于原地操作和链表问题。
    • 

  • 滑动窗口：维护一个动态区间，通过右扩左缩在 O(n)O(n)O(n) 内处理子串/子数组的最优化问题。
    • 

  • 前缀和：一次预处理，多次 O(1)O(1)O(1) 查询区间和；配合哈希表可处理"和为 K"类问题。
    • 

  • 单调栈：在 O(n)O(n)O(n) 时间内解决"下一个更大/更小元素"问题，是柱状图面积、温度等题的核心工具。
    • 

  • 矩阵 BFS/DFS：DFS 用于连通分量探索（岛屿计数），BFS 用于最短路径/层级扩散（腐烂橘子）。
    • 

  • 链表技巧：反转（三指针迭代）、环检测（Floyd 快慢指针）、合并（虚拟头节点）是链表题的三大基石。
    • 

  • 面试时先识别模式，再套用模板，最后根据具体题目微调细节，这是高效解题的核心方法论。
