算法设计技巧总结

概述

算法设计不仅仅是背模板和套公式，更是一套系统化的思维方法。面对一道从未见过的问题，如何从零开始构建解法？如何从暴力解逐步优化到最优解？如何在面试中清晰地表达你的思路？



优秀的算法能力 = 扎实的基础知识 + 系统的解题方法论 + 大量的刻意练习。本文将帮助你建立一套完整的算法设计思维框架。






如何面对一道新问题
拿到一道全新的算法题，不要急于写代码。遵循以下四步流程，可以帮助你系统地从理解问题到构建最优解：


第一步：理解问题（Understand）
在动手之前，确保你完全理解题目。很多错误的解法都源于对题意的误解。

function twoSumBruteForce(nums: number[], target: number): number[] {
  for (let i = 0; i < nums.length; i++) {
    for (let j = i + 1; j < nums.length; j++) {
      if (nums[i] + nums[j] === target) {
        return [i, j];
      }
    }
  }
  return [];
}
// 时间复杂度：O(n²)，空间复杂度：O(1)
第四步：优化迭代（Optimize）
分析暴力解的瓶颈，运用优化技巧进行改进。


function twoSumOptimized(nums: number[], target: number): number[] {
  const map = new Map<number, number>();

  for (let i = 0; i < nums.length; i++) {
    const complement = target - nums[i];
    if (map.has(complement)) {
      return [map.get(complement)!, i];
    }
    map.set(nums[i], i);
  }

  return [];
}
// 时间复杂度：O(n)，空间复杂度：O(n)
// 优化手段：用哈希表将 O(n) 的查找降低到 O(1)


常见优化技巧
掌握以下优化技巧，可以覆盖绝大多数算法题的优化需求：


技巧一：哈希表加速查找
场景：需要频繁判断"某个元素是否存在"或"查找某个元素的位置/频率"。


原理：将 O(n)O(n)O(n) 的线性查找降低到 O(1)O(1)O(1) 的哈希查找。


function containsDuplicate(nums: number[]): boolean {
  const seen = new Set<number>();
  for (const num of nums) {
    if (seen.has(num)) return true;
    seen.add(num);
  }
  return false;
}

function groupAnagrams(strs: string[]): string[][] {
  const map = new Map<string, string[]>();
  for (const s of strs) {
    const key = s.split('').sort().join('');
    if (!map.has(key)) map.set(key, []);
    map.get(key)!.push(s);
  }
  return Array.from(map.values());
}
技巧二：预排序
场景：需要查找配对、去重、或寻找某种顺序关系。


原理：排序后可以使用二分查找（O(log⁡n)O(\log n)O(logn)）或双指针（O(n)O(n)O(n)），将暴力的 O(n2)O(n^2)O(n2) 降低。


function threeSum(nums: number[]): number[][] {
  const result: number[][] = [];
  nums.sort((a, b) => a - b);

  for (let i = 0; i < nums.length - 2; i++) {
    if (i > 0 && nums[i] === nums[i - 1]) continue;

    let left = i + 1;
    let right = nums.length - 1;

    while (left < right) {
      const sum = nums[i] + nums[left] + nums[right];
      if (sum === 0) {
        result.push([nums[i], nums[left], nums[right]]);
        while (left < right && nums[left] === nums[left + 1]) left++;
        while (left < right && nums[right] === nums[right - 1]) right--;
        left++;
        right--;
      } else if (sum < 0) {
        left++;
      } else {
        right--;
      }
    }
  }

  return result;
}
// 排序 O(n log n) + 双指针 O(n²) = O(n²)，比暴力 O(n³) 好一个量级
技巧三：预计算（前缀和 / 频率表）
场景：需要频繁查询区间和、子数组和、或元素出现频率。


原理：提前计算并存储中间结果，将每次查询从 O(n)O(n)O(n) 降到 O(1)O(1)O(1)。


function subarraySum(nums: number[], k: number): number {
  const prefixCount = new Map<number, number>();
  prefixCount.set(0, 1);

  let sum = 0;
  let count = 0;

  for (const num of nums) {
    sum += num;
    if (prefixCount.has(sum - k)) {
      count += prefixCount.get(sum - k)!;
    }
    prefixCount.set(sum, (prefixCount.get(sum) ?? 0) + 1);
  }

  return count;
}
// 前缀和 + 哈希表：O(n) 时间，O(n) 空间

function majorityElement(nums: number[]): number {
  // 方法 1：哈希表（空间换时间）—— O(n) 时间，O(n) 空间
  const count = new Map<number, number>();
  for (const num of nums) {
    count.set(num, (count.get(num) ?? 0) + 1);
    if (count.get(num)! > nums.length / 2) return num;
  }
  return -1;
}

function majorityElementOptimal(nums: number[]): number {
  // 方法 2：Boyer-Moore 投票法 —— O(n) 时间，O(1) 空间
  let candidate = nums[0];
  let votes = 0;

  for (const num of nums) {
    if (votes === 0) candidate = num;
    votes += num === candidate ? 1 : -1;
  }

  return candidate;
}
技巧五：滑动窗口
场景：连续子数组/子串问题，需要求满足某个条件的最长/最短子数组。


function lengthOfLongestSubstring(s: string): number {
  const charIndex = new Map<string, number>();
  let maxLen = 0;
  let left = 0;

  for (let right = 0; right < s.length; right++) {
    if (charIndex.has(s[right]) && charIndex.get(s[right])! >= left) {
      left = charIndex.get(s[right])! + 1;
    }
    charIndex.set(s[right], right);
    maxLen = Math.max(maxLen, right - left + 1);
  }

  return maxLen;
}
// 滑动窗口：O(n) 时间，O(min(n, m)) 空间（m 为字符集大小）

function sum(nums: number[]): number {

  for (const num of nums) total += num;
  return total;

// 模式 2：嵌套循环 → O(n²)
function pairSum(nums: number[]): number {
  let count = 0;
  for (let i = 0; i < nums.length; i++) {
    for (let j = i + 1; j < nums.length; j++) {
      count += nums[i] + nums[j];
    }
  }
  return count;
}

// 模式 3：循环内二分 → O(n log n)
function countSmaller(nums: number[], targets: number[]): number[] {
  const sorted = [...nums].sort((a, b) => a - b);
  return targets.map((t) => {
    let lo = 0,
      hi = sorted.length;
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      if (sorted[mid] < t) lo = mid + 1;
      else hi = mid;
    }
    return lo;
  });
}

// 模式 4：递归 T(n) = 2T(n/2) + O(n) → O(n log n)（主定理）
function mergeSort(arr: number[]): number[] {
  if (arr.length <= 1) return arr;
  const mid = arr.length >> 1;
  const left = mergeSort(arr.slice(0, mid));
  const right = mergeSort(arr.slice(mid));
  return merge(left, right);
}

function merge(a: number[], b: number[]): number[] {
  const result: number[] = [];
  let i = 0,
    j = 0;
  while (i < a.length && j < b.length) {
    result.push(a[i] <= b[j] ? a[i++] : b[j++]);
  }
  return result.concat(a.slice(i), b.slice(j));
}

function testWithBruteForce(): void {
  for (let trial = 0; trial < 1000; trial++) {
    const n = Math.floor(Math.random() * 20) + 1;
    const nums = Array.from({ length: n }, () => Math.floor(Math.random() * 100) - 50);

    const expected = bruteForce(nums);
    const actual = optimized(nums);

    if (expected !== actual) {
      console.log(`❌ 不一致！输入: ${JSON.stringify(nums)}`);
      console.log(`   暴力解: ${expected}, 优化解: ${actual}`);
      return;
    }
  }
  console.log('✅ 1000 组随机数据全部通过');
}

function bruteForce(nums: number[]): number {
  let maxSum = -Infinity;
  for (let i = 0; i < nums.length; i++) {
    let sum = 0;
    for (let j = i; j < nums.length; j++) {
      sum += nums[j];
      maxSum = Math.max(maxSum, sum);
    }
  }
  return maxSum;
}

function optimized(nums: number[]): number {
  let maxSum = nums[0];
  let currentSum = nums[0];
  for (let i = 1; i < nums.length; i++) {
    currentSum = Math.max(nums[i], currentSum + nums[i]);
    maxSum = Math.max(maxSum, currentSum);
  }
  return maxSum;
}

function robustSolution(nums: number[]): number {
  // 边界情况 1：空数组
  if (nums.length === 0) return 0;

  // 边界情况 2：单个元素
  if (nums.length === 1) return nums[0];

  // 边界情况 3：两个元素
  if (nums.length === 2) return Math.max(nums[0], nums[1]);

  // 主逻辑
  let prev2 = nums[0];
  let prev1 = Math.max(nums[0], nums[1]);

  for (let i = 2; i < nums.length; i++) {
    const curr = Math.max(prev1, prev2 + nums[i]);
    prev2 = prev1;
    prev1 = curr;
  }

  return prev1;
}

哪怕面试官期望最优解，先展示暴力解说明你理解了问题




大声思考
让面试官了解你的推理过程，卡住时也要说出你在想什么




主动问问题
不确定的约束条件一定要问清楚，这是加分项




善用函数抽象
将辅助逻辑封装为函数，保持主逻辑清晰




命名要有意义
left/right 比 i/j 更清晰，prefixSum 比 arr 更好




写完就测试
不要等面试官提醒，主动用测试用例验证




分析复杂度
编码完成后，主动给出时间和空间复杂度分析







小结
    

  • 解题四步法：理解问题 → 举例验证 → 暴力求解 → 优化迭代，是面对任何新问题的系统方法论。
    • 

  • 六大优化技巧：哈希表加速查找、预排序、预计算、时空权衡、双指针、滑动窗口，覆盖了绝大多数优化场景。
    • 

  • 复杂度分析：从数据规模反推可接受的复杂度，是选择算法的重要依据。
    • 

  • 系统化调试：小规模推演、对比暴力解、检查常见 Bug，比盲目修改代码高效得多。
    • 

  • 问题分类决策树：根据题目关键词和结构特征，快速定位应该使用的算法类型。
    • 

  • 面试沟通：算法面试是协作过程，先说再写、大声思考、主动测试，展示完整的工程思维。
    •
