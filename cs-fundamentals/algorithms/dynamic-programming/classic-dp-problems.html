经典DP问题

概述

动态规划的精髓在于将复杂问题拆解为相互重叠的子问题，并通过状态定义与状态转移方程高效求解。本节将深入讲解五大经典 DP 问题，它们涵盖了序列型、区间型、背包型等常见 DP 模式，是面试与竞赛的高频考点。



一、0/1 背包问题（0/1 Knapsack）
问题描述
给定 nnn 个物品，每个物品有重量 wiw_iwi​ 和价值 viv_ivi​，以及一个容量为 WWW 的背包。每个物品只能选择放入或不放入（不可分割），求在总重量不超过 WWW 的前提下，能获得的最大价值。

二维 DP 版本：


function knapsack01(weights: number[], values: number[], capacity: number): number {
  const n = weights.length;
  const dp: number[][] = Array.from({ length: n + 1 }, () => new Array(capacity + 1).fill(0));

  for (let i = 1; i <= n; i++) {
    const w = weights[i - 1];
    const v = values[i - 1];
    for (let j = 0; j <= capacity; j++) {
      dp[i][j] = dp[i - 1][j];
      if (j >= w) {
        dp[i][j] = Math.max(dp[i][j], dp[i - 1][j - w] + v);
      }
    }
  }

  return dp[n][capacity];
}
空间优化版本（一维滚动数组）：


function knapsack01Optimized(weights: number[], values: number[], capacity: number): number {
  const dp = new Array(capacity + 1).fill(0);

  for (let i = 0; i < weights.length; i++) {
    for (let j = capacity; j >= weights[i]; j--) {
      dp[j] = Math.max(dp[j], dp[j - weights[i]] + values[i]);
    }
  }

  return dp[capacity];
}


关键点：一维优化时内层循环必须从大到小遍历，以保证每个物品只被选取一次。如果从小到大遍历，则变成了完全背包问题。

二、最长公共子序列（Longest Common Subsequence, LCS）
问题描述

function longestCommonSubsequence(s: string, t: string): number {
  const m = s.length;
  const n = t.length;
  const dp: number[][] = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (s[i - 1] === t[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1] + 1;
      } else {
        dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
      }
    }
  }

  return dp[m][n];
}
如果需要输出具体的 LCS 字符串，可以通过回溯 DP 表格来还原路径：


function findLCS(s: string, t: string): string {
  const m = s.length;
  const n = t.length;
  const dp: number[][] = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (s[i - 1] === t[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1] + 1;
      } else {
        dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
      }
    }
  }

  let result = '';
  let i = m,
    j = n;
  while (i > 0 && j > 0) {
    if (s[i - 1] === t[j - 1]) {
      result = s[i - 1] + result;
      i--;
      j--;
    } else if (dp[i - 1][j] > dp[i][j - 1]) {
      i--;
    } else {
      j--;
    }
  }

  return result;
}

三、最长递增子序列（Longest Increasing Subsequence, LIS）
问题描述
给定一个整数数组 numsnumsnums，找出其中最长严格递增子序列的长度。子序列不要求连续。


例如：nums = [10, 9, 2, 5, 3, 7, 101, 18]，LIS 为 [2, 3, 7, 101]，长度为 4。


方法一：经典 DP（O(n2)O(n^2)O(n2)）

dp[i]=max⁡0≤j<i, nums[j]<nums[i](dp[j]+1)dp[i] = \max_{0 \leq j < i,\ nums[j] < nums[i]}(dp[j] + 1)dp[i]=0≤j<i, nums[j]<nums[i]max​(dp[j]+1)

TypeScript 实现
function lengthOfLIS(nums: number[]): number {
  const n = nums.length;
  if (n === 0) return 0;

  const dp = new Array(n).fill(1);

  for (let i = 1; i < n; i++) {
    for (let j = 0; j < i; j++) {
      if (nums[j] < nums[i]) {
        dp[i] = Math.max(dp[i], dp[j] + 1);
      }
    }
  }

  return Math.max(...dp);
}
方法二：贪心 + 二分查找（O(nlog⁡n)O(n \log n)O(nlogn)）
维护一个数组 tails，其中 tails[i] 表示长度为 i+1i+1i+1 的递增子序列的最小末尾元素。


TypeScript 实现
function lengthOfLISBinarySearch(nums: number[]): number {
  const tails: number[] = [];

  for (const num of nums) {
    let lo = 0;
    let hi = tails.length;

    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      if (tails[mid] < num) {
        lo = mid + 1;
      } else {
        hi = mid;
      }
    }

    tails[lo] = num;
  }

  return tails.length;
}


注意：tails 数组本身不一定是最终的 LIS 序列，它只是用于辅助计算长度。

function minDistance(s: string, t: string): number {
  const m = s.length;
  const n = t.length;
  const dp: number[][] = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));

  for (let i = 0; i <= m; i++) dp[i][0] = i;
  for (let j = 0; j <= n; j++) dp[0][j] = j;

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (s[i - 1] === t[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1];
      } else {
        dp[i][j] = 1 + Math.min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]);
      }
    }
  }

  return dp[m][n];
}
空间优化版本（两行滚动）：


function minDistanceOptimized(s: string, t: string): number {
  const m = s.length;
  const n = t.length;
  let prev = Array.from({ length: n + 1 }, (_, j) => j);
  let curr = new Array(n + 1).fill(0);

  for (let i = 1; i <= m; i++) {
    curr[0] = i;
    for (let j = 1; j <= n; j++) {
      if (s[i - 1] === t[j - 1]) {
        curr[j] = prev[j - 1];
      } else {
        curr[j] = 1 + Math.min(prev[j], curr[j - 1], prev[j - 1]);
      }
    }
    [prev, curr] = [curr, prev];
  }

  return prev[n];
}

五、零钱兑换（Coin Change）
问题描述
给定不同面额的硬币数组 coinscoinscoins 和一个总金额 amountamountamount，计算凑成该金额所需的最少硬币数。每种硬币可以无限次使用。如果无法凑成，返回 −1-1−1。


例如：coins = [1, 2, 5]，amount = 11，最少需要 3 枚硬币（5+5+15 + 5 + 15+5+1）。


状态定义
dp[i]=凑成金额 i 所需的最少硬币数dp[i] = 凑成金额\ i\ 所需的最少硬币数dp[i]=凑成金额 i 所需的最少硬币数

function coinChange(coins: number[], amount: number): number {
  const dp = new Array(amount + 1).fill(Infinity);
  dp[0] = 0;

  for (let i = 1; i <= amount; i++) {
    for (const coin of coins) {
      if (coin <= i && dp[i - coin] !== Infinity) {
        dp[i] = Math.min(dp[i], dp[i - coin] + 1);
      }
    }
  }

  return dp[amount] === Infinity ? -1 : dp[amount];
}
如果需要同时输出具体的硬币组合，可以用额外数组记录选择路径：


function coinChangeWithPath(coins: number[], amount: number): { count: number; path: number[] } {
  const dp = new Array(amount + 1).fill(Infinity);
  const choice = new Array(amount + 1).fill(-1);
  dp[0] = 0;

  for (let i = 1; i <= amount; i++) {
    for (const coin of coins) {
      if (coin <= i && dp[i - coin] + 1 < dp[i]) {
        dp[i] = dp[i - coin] + 1;
        choice[i] = coin;
      }
    }
  }

  if (dp[amount] === Infinity) return { count: -1, path: [] };

  const path: number[] = [];
  let remaining = amount;
  while (remaining > 0) {
    path.push(choice[remaining]);
    remaining -= choice[remaining];
  }

  return { count: dp[amount], path };
}

小结
    

  • 0/1 背包是最基础的背包问题，掌握其"选或不选"的思想后可以扩展到完全背包、多重背包等变体。一维空间优化时注意逆序遍历。
    • 

  • LCS 是双序列匹配的典型问题，转移方程体现了"匹配则对角线 +1，不匹配则取左/上最大值"的经典模式。
    • 

  • LIS 有 O(n2)O(n^2)O(n2) 和 O(nlog⁡n)O(n \log n)O(nlogn) 两种解法。贪心 + 二分的方法在面试中是加分项，需要理解 tails 数组的含义。
    • 

  • 编辑距离综合了插入、删除、替换三种操作，是自然语言处理（NLP）中衡量字符串相似度的重要指标。
    • 

  • 零钱兑换是完全背包的变体（每种硬币可无限使用），与 0/1 背包的区别在于内层循环的遍历方向。
    • 

  • 这五大问题的核心方法论是相通的：明确状态定义 → 推导转移方程 → 确定边界条件 → 选择遍历顺序 → 考虑空间优化。掌握这一流程，面对新的 DP 问题时便能从容应对。
    •
