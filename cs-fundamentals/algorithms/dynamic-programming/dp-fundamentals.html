动态规划基础

概述

动态规划（Dynamic Programming，简称 DP）是一种通过将复杂问题分解为重叠子问题，并存储子问题的解来避免重复计算的算法设计范式。它是解决最优化问题最强大的工具之一，广泛应用于路径规划、资源分配、字符串匹配、背包问题等场景。



动态规划的本质：用空间换时间，通过记录已求解的子问题结果，将指数级别的暴力搜索优化到多项式级别。






什么是动态规划
从暴力递归到动态规划
考虑一个经典问题：求第 nnn 个斐波那契数。


朴素递归的做法：


function fibNaive(n: number): number {
  if (n <= 1) return n;
  return fibNaive(n - 1) + fibNaive(n - 2);
}
这段代码简洁，但效率极低。调用 fibNaive(5) 时的递归树如下：


可以看到 fib(3) 被计算了 2 次，fib(2) 被计算了 3 次 —— 这就是重叠子问题。随着 nnn 增大，重复计算量呈指数增长，时间复杂度为 O(2n)O(2^n)O(2n)。


动态规划的核心思想就是：每个子问题只计算一次，将结果存储起来供后续使用。




两个关键性质
一个问题能够使用动态规划求解，必须同时满足以下两个性质：


1. 重叠子问题（Overlapping Subproblems）
在递归求解过程中，相同的子问题被多次求解。如果每个子问题只出现一次（如归并排序），则不需要动态规划，分治法就足够了。


2. 最优子结构（Optimal Substructure）
问题的最优解可以由子问题的最优解组合而成。换句话说，你可以通过先求解更小规模的问题，再组合得到原问题的最优解。


以爬楼梯为例：到达第 nnn 阶的最优方案数 = 到达第 n−1n-1n−1 阶的方案数 + 到达第 n−2n-2n−2 阶的方案数。子问题的最优解直接构成了原问题的最优解。




两种实现方式
动态规划有两种经典实现方式：记忆化搜索（自顶向下） 和 递推表格（自底向上）。


记忆化搜索（Memoization，自顶向下）
在递归的基础上，增加一个缓存（通常用 Map 或数组）来存储已计算过的子问题结果。当再次遇到同一子问题时，直接返回缓存值，不再重复计算。


function fibMemo(n: number, memo: Map<number, number> = new Map()): number {
  if (n <= 1) return n;
  if (memo.has(n)) return memo.get(n)!;

  const result = fibMemo(n - 1, memo) + fibMemo(n - 2, memo);
  memo.set(n, result);
  return result;
}

console.log(fibMemo(10)); // 55
console.log(fibMemo(40)); // 102334155（朴素递归几乎不可能在合理时间内完成）
优点：代码结构与递归一致，容易从暴力递归改造而来；只计算实际需要的子问题。


缺点：递归调用有栈开销，n 极大时可能栈溢出。


递推表格（Tabulation，自底向上）
从最小的子问题开始，逐步计算到目标问题，用循环代替递归。


function fibTab(n: number): number {
  if (n <= 1) return n;

  const dp: number[] = new Array(n + 1);
  dp[0] = 0;
  dp[1] = 1;

  for (let i = 2; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];
  }

  return dp[n];
}

console.log(fibTab(10)); // 55
console.log(fibTab(40)); // 102334155
优点：没有递归栈开销；循环结构通常更高效。


缺点：需要提前确定计算顺序；可能计算一些实际不需要的子问题。


空间优化：滚动变量
当状态转移只依赖前几个状态时，可以用常数个变量替代整个 DP 数组，将空间复杂度从 O(n)O(n)O(n) 优化到 O(1)O(1)O(1)。


function fibOptimized(n: number): number {
  if (n <= 1) return n;

  let prev2 = 0;
  let prev1 = 1;

  for (let i = 2; i <= n; i++) {
    const curr = prev1 + prev2;
    prev2 = prev1;
    prev1 = curr;
  }

  return prev1;
}

console.log(fibOptimized(10)); // 55
console.log(fibOptimized(50)); // 12586269025

例题一：斐波那契数列


求第 nnn 个斐波那契数，F(0)=0,F(1)=1,F(n)=F(n−1)+F(n−2)F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2)F(0)=0,F(1)=1,F(n)=F(n−1)+F(n−2)。

function fibonacci(n: number): number {
  if (n <= 1) return n;

  const dp: number[] = [0, 1];
  for (let i = 2; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];
  }
  return dp[n];
}

console.log(fibonacci(1)); // 1
console.log(fibonacci(10)); // 55

例题二：爬楼梯（Climbing Stairs）


你正在爬一个有 nnn 级台阶的楼梯。每次可以爬 1 级或 2 级。问有多少种不同的方法可以爬到楼顶？




套用框架：


    

  1. 状态定义：dp[i] = 到达第 iii 级台阶的方法数
    2. 

  2. 状态转移：dp[i] = dp[i - 1] + dp[i - 2]（从第 i−1i-1i−1 级跨 1 步，或从第 i−2i-2i−2 级跨 2 步）
    3. 

  3. 基础情况：dp[0] = 1（站在起点，有 1 种方式），dp[1] = 1（跨 1 步到第 1 级）
    4. 

  4. 遍历顺序：从 i=2i = 2i=2 到 nnn
    5. 



递推表格实现：


function climbStairs(n: number): number {
  if (n <= 1) return 1;

  const dp: number[] = new Array(n + 1);
  dp[0] = 1;
  dp[1] = 1;

  for (let i = 2; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];
  }

  return dp[n];
}

console.log(climbStairs(2)); // 2
console.log(climbStairs(3)); // 3
console.log(climbStairs(5)); // 8
console.log(climbStairs(10)); // 89
记忆化搜索实现：


function climbStairsMemo(n: number, memo: Map<number, number> = new Map()): number {
  if (n <= 1) return 1;
  if (memo.has(n)) return memo.get(n)!;

  const result = climbStairsMemo(n - 1, memo) + climbStairsMemo(n - 2, memo);
  memo.set(n, result);
  return result;
}

console.log(climbStairsMemo(2)); // 2
console.log(climbStairsMemo(5)); // 8
console.log(climbStairsMemo(10)); // 89
空间优化实现：


function climbStairsOptimized(n: number): number {
  if (n <= 1) return 1;

  let prev2 = 1;
  let prev1 = 1;

  for (let i = 2; i <= n; i++) {
    const curr = prev1 + prev2;
    prev2 = prev1;
    prev1 = curr;
  }

  return prev1;
}

console.log(climbStairsOptimized(2)); // 2
console.log(climbStairsOptimized(5)); // 8
console.log(climbStairsOptimized(10)); // 89

例题三：最小花费爬楼梯（Min Cost Climbing Stairs）


给定一个整数数组 cost，其中 cost[i] 表示从第 iii 级台阶向上爬的花费。你可以从第 0 级或第 1 级台阶开始爬，每次可以爬 1 或 2 级。求到达楼顶的最小花费。




套用框架：


    

  1. 状态定义：dp[i] = 到达第 iii 级台阶的最小花费
    2. 

  2. 状态转移：dp[i] = Math.min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2])
    3. 

  3. 基础情况：dp[0] = 0, dp[1] = 0（可以从第 0 级或第 1 级免费开始）
    4. 

  4. 遍历顺序：从 i=2i = 2i=2 到 nnn（nnn = cost.length，即楼顶）
    5. 



function minCostClimbingStairs(cost: number[]): number {
  const n = cost.length;
  const dp: number[] = new Array(n + 1);
  dp[0] = 0;
  dp[1] = 0;

  for (let i = 2; i <= n; i++) {
    dp[i] = Math.min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2]);
  }

  return dp[n];
}

console.log(minCostClimbingStairs([10, 15, 20])); // 15
console.log(minCostClimbingStairs([1, 100, 1, 1, 1, 100, 1, 1, 100, 1])); // 6
空间优化版本：


function minCostClimbingStairsOptimized(cost: number[]): number {
  const n = cost.length;
  let prev2 = 0;
  let prev1 = 0;

  for (let i = 2; i <= n; i++) {
    const curr = Math.min(prev1 + cost[i - 1], prev2 + cost[i - 2]);
    prev2 = prev1;
    prev1 = curr;
  }

  return prev1;
}

console.log(minCostClimbingStairsOptimized([10, 15, 20])); // 15
console.log(minCostClimbingStairsOptimized([1, 100, 1, 1, 1, 100, 1, 1, 100, 1])); // 6

小结
    

  • 动态规划是一种通过存储子问题解来避免重复计算的算法策略，适用于同时具有重叠子问题和最优子结构的问题。
    • 

  • 两种实现方式：记忆化搜索（自顶向下） 直观但有栈开销；递推表格（自底向上） 高效且易于空间优化。
    • 

  • 解题四步框架：定义状态 → 推导转移方程 → 确定基础情况 → 确定遍历顺序。
    • 

  • 优化路径：暴力递归 → 记忆化 → 递推 → 空间优化，是系统化解决 DP 问题的标准流程。
    • 

  • 斐波那契和爬楼梯是最基础的 1D DP 问题，掌握它们的完整推导过程后，可以自然地推广到更复杂的 DP 问题（如背包、子序列、区间 DP 等）。
    •
