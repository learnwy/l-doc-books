状态压缩与优化

概述

在掌握了动态规划的基本思想和经典问题之后，下一步就是学会优化。实际面试和竞赛中，朴素 DP 方案往往因为空间或时间瓶颈而无法通过，此时就需要用到各种 DP 优化技巧。本节将系统讲解五大核心优化方向：空间优化、状态压缩 DP、单调队列优化、区间 DP 以及如何根据问题特征选择合适的优化策略。



核心理念：在不改变时间复杂度的前提下压缩空间，或者利用决策的单调性降低时间复杂度。






一、空间优化（滚动数组 / 二维降一维）
核心思想
大部分二维 DP 问题中，计算 dp[i][j]dp[i][j]dp[i][j] 时只依赖于 dp[i−1][⋅]dp[i-1][\cdot]dp[i−1][⋅]（上一行）或者 dp[i][⋅]dp[i][\cdot]dp[i][⋅]（当前行已计算部分）。既然如此，就不需要保留完整的二维数组，只需保留一行或两行即可。


优化方式一：双行滚动
适用于 dp[i][j]dp[i][j]dp[i][j] 仅依赖上一行 dp[i−1][⋅]dp[i-1][\cdot]dp[i−1][⋅] 的情况（如 LCS、编辑距离）。


function lcsRolling(s: string, t: string): number {
  const m = s.length;
  const n = t.length;
  let prev = new Array(n + 1).fill(0);
  let curr = new Array(n + 1).fill(0);

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (s[i - 1] === t[j - 1]) {
        curr[j] = prev[j - 1] + 1;
      } else {
        curr[j] = Math.max(prev[j], curr[j - 1]);
      }
    }
    [prev, curr] = [curr, prev];
    curr.fill(0);
  }

  return prev[n];
}
空间从 O(m×n)O(m \times n)O(m×n) 降到 O(n)O(n)O(n)。


优化方式二：单行 + 逆序遍历
适用于 0/1 背包类问题。由于每个物品只能选一次，内层循环逆序遍历可以保证 dp[j−w]dp[j - w]dp[j−w] 取的是上一轮（未放入当前物品）的值。


function knapsack01(weights: number[], values: number[], capacity: number): number {
  const dp = new Array(capacity + 1).fill(0);

  for (let i = 0; i < weights.length; i++) {
    for (let j = capacity; j >= weights[i]; j--) {
      dp[j] = Math.max(dp[j], dp[j - weights[i]] + values[i]);
    }
  }

  return dp[capacity];
}


关键区分：0/1 背包逆序遍历，完全背包正序遍历。遍历方向的区别决定了物品能被选取一次还是无限次。




优化方式三：单变量滚动
当状态仅依赖前 1~2 个值时（如斐波那契、爬楼梯），可以只用几个变量替代整个数组，空间降至 O(1)O(1)O(1)。


function fibOptimized(n: number): number {
  if (n <= 1) return n;
  let prev2 = 0,
    prev1 = 1;
  for (let i = 2; i <= n; i++) {
    const curr = prev1 + prev2;
    prev2 = prev1;
    prev1 = curr;
  }
  return prev1;
}

二、状态压缩 DP（Bitmask DP）
核心思想
当 DP 状态中包含一个集合（哪些元素被选过 / 哪些节点已访问），而集合的大小 nnn 较小（通常 n≤20n \leq 20n≤20），可以用一个 nnn 位二进制整数来编码集合状态。这就是状态压缩。


集合{0,2,3}⇔二进制 11012=1310\text{集合} \{0, 2, 3\} \Leftrightarrow \text{二进制} \ 1101_2 = 13_{10}集合{0,2,3}⇔二进制 11012​=1310​
常用位运算速查
const n = 5;
const mask = 0b10110;

(mask >> 2) & 1; // 1 → 第 2 位已选
mask | (1 << 3); // 0b11110 → 选中第 3 位
mask & ~(1 << 1); // 0b10100 → 取消第 1 位
mask & (mask - 1); // 0b10100 → 清除最低位的 1
(1 << n) - 1; // 0b11111 → 全集掩码
经典例题：旅行商问题（TSP）
问题描述
给定 nnn 个城市和任意两个城市之间的距离矩阵 dist[i][j]dist[i][j]dist[i][j]，求从城市 0 出发，恰好访问每个城市一次后回到城市 0 的最短路径长度。


状态定义
dp[mask][i]=已访问城市集合为 mask，当前在城市 i 时的最短路径dp[mask][i] = \text{已访问城市集合为 } mask\text{，当前在城市 } i \text{ 时的最短路径}dp[mask][i]=已访问城市集合为 mask，当前在城市 i 时的最短路径
其中 maskmaskmask 是一个 nnn 位二进制数，第 kkk 位为 1 表示城市 kkk 已访问。


状态转移方程
dp[mask][i]=min⁡j∈mask, j≠i(dp[mask⊕(1≪i)][j]+dist[j][i])dp[mask][i] = \min_{j \in mask,\ j \neq i} \left( dp[mask \oplus (1 \ll i)][j] + dist[j][i] \right)dp[mask][i]=j∈mask, j=imin​(dp[mask⊕(1≪i)][j]+dist[j][i])
即：从集合 maskmaskmask 中去掉城市 iii，在城市 jjj 结束，再走到城市 iii。


DP 推导过程（4 城市为例）
TypeScript 实现
function tsp(dist: number[][]): number {
  const n = dist.length;
  const ALL = (1 << n) - 1;
  const INF = Infinity;

  const dp: number[][] = Array.from({ length: 1 << n }, () => new Array(n).fill(INF));
  dp[1][0] = 0;

  for (let mask = 1; mask <= ALL; mask++) {
    for (let u = 0; u < n; u++) {
      if (dp[mask][u] === INF) continue;
      if (!((mask >> u) & 1)) continue;

      for (let v = 0; v < n; v++) {
        if ((mask >> v) & 1) continue;
        const nextMask = mask | (1 << v);
        dp[nextMask][v] = Math.min(dp[nextMask][v], dp[mask][u] + dist[u][v]);
      }
    }
  }

  let ans = INF;
  for (let u = 1; u < n; u++) {
    ans = Math.min(ans, dp[ALL][u] + dist[u][0]);
  }

  return ans;
}

三、单调队列 / 单调栈优化（Monotonic Queue Optimization）
核心思想
当 DP 转移方程形如：


dp[i]=min⁡j∈[i−k, i−1](dp[j]+cost(j,i))dp[i] = \min_{j \in [i-k,\ i-1]} \left( dp[j] + cost(j, i) \right)dp[i]=j∈[i−k, i−1]min​(dp[j]+cost(j,i))
即在一个滑动窗口范围内取最值时，暴力枚举 jjj 需要 O(k)O(k)O(k)，使用单调队列可以将每次转移优化到均摊 O(1)O(1)O(1)。


单调队列的核心操作
经典例题：滑动窗口最大值
给定数组 numsnumsnums 和窗口大小 kkk，求每个窗口位置的最大值。


function maxSlidingWindow(nums: number[], k: number): number[] {
  const result: number[] = [];
  const deque: number[] = [];

  for (let i = 0; i < nums.length; i++) {
    while (deque.length > 0 && deque[0] < i - k + 1) {
      deque.shift();
    }

    while (deque.length > 0 && nums[deque[deque.length - 1]] <= nums[i]) {
      deque.pop();
    }

    deque.push(i);

    if (i >= k - 1) {
      result.push(nums[deque[0]]);
    }
  }

  return result;
}
经典例题：跳跃游戏（限定步长最小花费）
给定花费数组 costcostcost 和最大步长 kkk，从位置 0 出发到达位置 n−1n-1n−1，每次最多前进 kkk 步。求最小花费。


dp[i]=min⁡j∈[max⁡(0,i−k), i−1]dp[j]+cost[i]dp[i] = \min_{j \in [\max(0, i-k),\ i-1]} dp[j] + cost[i]dp[i]=j∈[max(0,i−k), i−1]min​dp[j]+cost[i]
function minCostJump(cost: number[], k: number): number {
  const n = cost.length;
  const dp = new Array(n).fill(Infinity);
  dp[0] = cost[0];

  const deque: number[] = [0];

  for (let i = 1; i < n; i++) {
    while (deque.length > 0 && deque[0] < i - k) {
      deque.shift();
    }

    dp[i] = dp[deque[0]] + cost[i];

    while (deque.length > 0 && dp[deque[deque.length - 1]] >= dp[i]) {
      deque.pop();
    }
    deque.push(i);
  }

  return dp[n - 1];
}

四、区间 DP（Interval DP）
核心思想
区间 DP 用于处理在一段区间上做最优决策的问题。特点是枚举区间的分割点，将大区间拆分为两个子区间，再合并子区间的最优解。


dp[i][j]=min⁡i≤k<j(dp[i][k]+dp[k+1][j]+merge(i,j))dp[i][j] = \min_{i \leq k < j} \left( dp[i][k] + dp[k+1][j] + \text{merge}(i, j) \right)dp[i][j]=i≤k<jmin​(dp[i][k]+dp[k+1][j]+merge(i,j))
经典例题：矩阵链乘法
给定 nnn 个矩阵的维度数组 dimsdimsdims（第 iii 个矩阵为 dims[i]×dims[i+1]dims[i] \times dims[i+1]dims[i]×dims[i+1]），求计算所有矩阵乘积的最少标量乘法次数。


状态定义
dp[i][j]=计算第 i 到第 j 个矩阵乘积的最少乘法次数dp[i][j] = \text{计算第 } i \text{ 到第 } j \text{ 个矩阵乘积的最少乘法次数}dp[i][j]=计算第 i 到第 j 个矩阵乘积的最少乘法次数
状态转移方程
dp[i][j]=min⁡i≤k<j(dp[i][k]+dp[k+1][j]+dims[i]×dims[k+1]×dims[j+1])dp[i][j] = \min_{i \leq k < j} \left( dp[i][k] + dp[k+1][j] + dims[i] \times dims[k+1] \times dims[j+1] \right)dp[i][j]=i≤k<jmin​(dp[i][k]+dp[k+1][j]+dims[i]×dims[k+1]×dims[j+1])
TypeScript 实现
function matrixChainOrder(dims: number[]): number {
  const n = dims.length - 1;
  const dp: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));

  for (let len = 2; len <= n; len++) {
    for (let i = 0; i <= n - len; i++) {
      const j = i + len - 1;
      dp[i][j] = Infinity;
      for (let k = i; k < j; k++) {
        const cost = dp[i][k] + dp[k + 1][j] + dims[i] * dims[k + 1] * dims[j + 1];
        dp[i][j] = Math.min(dp[i][j], cost);
      }
    }
  }

  return dp[0][n - 1];
}
经典例题：戳气球
给定数组 numsnumsnums，每次戳破一个气球 iii 可获得 nums[left]×nums[i]×nums[right]nums[left] \times nums[i] \times nums[right]nums[left]×nums[i]×nums[right] 枚硬币（leftleftleft 和 rightrightright 是 iii 的相邻未戳破气球）。求最大硬币数。


function maxCoins(nums: number[]): number {
  const vals = [1, ...nums, 1];
  const n = vals.length;
  const dp: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));

  for (let len = 2; len < n; len++) {
    for (let i = 0; i < n - len; i++) {
      const j = i + len;
      for (let k = i + 1; k < j; k++) {
        const coins = vals[i] * vals[k] * vals[j] + dp[i][k] + dp[k][j];
        dp[i][j] = Math.max(dp[i][j], coins);
      }
    }
  }

  return dp[0][n - 1];
}

小结
    

  • 空间优化是最基础也是最通用的 DP 优化手段。滚动数组和降维技巧几乎可以应用于所有二维 DP 问题，面试中也是必考的优化思路。关键在于理解遍历顺序与依赖方向的关系。
    • 

  • 状态压缩 DP 用位运算将集合编码为整数，适合处理排列、子集、图上路径等涉及"哪些元素已选"的问题。n≤20n \leq 20n≤20 是使用的硬性上限，超过则需要考虑其他方法。
    • 

  • 单调队列优化在转移方程涉及滑动窗口范围内的极值时发挥作用，将 O(nk)O(nk)O(nk) 降为 O(n)O(n)O(n)。掌握单调队列的三个操作（入队弹尾、出队弹首、队首查询）是关键。
    • 

  • 区间 DP 处理"区间上做最优分割"的问题，核心模式是枚举分割点，按区间长度从小到大递推。矩阵链乘和戳气球是两道标杆题目。
    • 

  • 在实际解题中，多种优化可以组合使用。例如区间 DP + 四边形不等式优化，或状态压缩 DP + 空间滚动。关键是先写出朴素 DP 解法，再根据瓶颈选择合适的优化方向。
    •
