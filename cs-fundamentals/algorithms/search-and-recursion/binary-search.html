二分查找

什么是二分查找

二分查找（Binary Search）是一种在有序数组中高效定位目标元素的搜索算法。其核心思想是：每次取搜索区间的中间元素与目标进行比较，根据比较结果将搜索范围缩小一半，从而将时间复杂度从线性搜索的 O(n)O(n)O(n) 降低到 O(log⁡n)O(\log n)O(logn)。



二分查找的前提条件是数组已排序。如果数组无序，必须先排序或考虑其他搜索方式。

基础二分查找
在有序数组中查找目标值，若存在返回下标，否则返回 −1-1−1。


function binarySearch(nums: number[], target: number): number {
  let lo = 0;
  let hi = nums.length - 1;

  while (lo <= hi) {
    const mid = lo + Math.floor((hi - lo) / 2);

    if (nums[mid] === target) {
      return mid;
    } else if (nums[mid] < target) {
      lo = mid + 1;
    } else {
      hi = mid - 1;
    }
  }

  return -1;
}

查找左边界（第一个等于 target 的位置）
当数组中存在重复元素时，基础二分查找返回的下标不确定。查找左边界可以找到目标值第一次出现的位置。


function searchLeftBound(nums: number[], target: number): number {
  let lo = 0;
  let hi = nums.length - 1;
  let result = -1;

  while (lo <= hi) {
    const mid = lo + Math.floor((hi - lo) / 2);

    if (nums[mid] === target) {
      result = mid;
      hi = mid - 1;
    } else if (nums[mid] < target) {
      lo = mid + 1;
    } else {
      hi = mid - 1;
    }
  }

  return result;
}
关键在于：当 nums[mid] === target 时，不立即返回，而是记录当前位置并继续向左收缩（hi = mid - 1），确保找到最左侧的目标。


查找右边界（最后一个等于 target 的位置）
与查找左边界对称，当找到目标时继续向右收缩。


function searchRightBound(nums: number[], target: number): number {
  let lo = 0;
  let hi = nums.length - 1;
  let result = -1;

  while (lo <= hi) {
    const mid = lo + Math.floor((hi - lo) / 2);

    if (nums[mid] === target) {
      result = mid;
      lo = mid + 1;
    } else if (nums[mid] < target) {
      lo = mid + 1;
    } else {
      hi = mid - 1;
    }
  }

  return result;
}

搜索旋转排序数组
旋转排序数组是将一个有序数组在某个位置「旋转」后的结果，例如 [4, 5, 6, 7, 0, 1, 2] 是 [0, 1, 2, 4, 5, 6, 7] 在下标 4 处旋转的结果。


核心思路：虽然整体无序，但 mid 将数组分为两段，其中必有一段是有序的。判断有序段后，决定在哪一段继续搜索。


function searchInRotated(nums: number[], target: number): number {
  let lo = 0;
  let hi = nums.length - 1;

  while (lo <= hi) {
    const mid = lo + Math.floor((hi - lo) / 2);

    if (nums[mid] === target) {
      return mid;
    }

    if (nums[lo] <= nums[mid]) {
      if (nums[lo] <= target && target < nums[mid]) {
        hi = mid - 1;
      } else {
        lo = mid + 1;
      }
    } else {
      if (nums[mid] < target && target <= nums[hi]) {
        lo = mid + 1;
      } else {
        hi = mid - 1;
      }
    }
  }

  return -1;
}

常见陷阱与易错点
1. 死循环（Off-by-One 错误）

⚠️ 切忌混用！循环条件和收缩方式必须与所选区间定义严格对应，否则会导致死循环或遗漏元素。




2. 整数溢出
// ❌ 错误写法：lo + hi 可能溢出（在其他语言中尤为严重）
const mid = Math.floor((lo + hi) / 2);

// ✅ 正确写法：避免溢出
const mid = lo + Math.floor((hi - lo) / 2);
虽然 JavaScript/TypeScript 中数字为 64 位浮点数，溢出问题不如 Java/C++ 常见，但使用安全写法是一种良好习惯。


3. 未检查前提条件
二分查找要求输入数组有序。对无序数组使用二分查找会得到错误结果且不会报错——这是一类隐蔽的逻辑 Bug。


二分查找的泛化应用
二分查找不仅适用于有序数组搜索，还可以用来解决一切具有单调性的判定问题。其本质是：在一个满足某种二段性的搜索空间上，快速定位分界点。


泛化模板
function binarySearchOnAnswer(lo: number, hi: number, check: (mid: number) => boolean): number {
  let result = -1;

  while (lo <= hi) {
    const mid = lo + Math.floor((hi - lo) / 2);

    if (check(mid)) {
      result = mid;
      lo = mid + 1;
    } else {
      hi = mid - 1;
    }
  }

  return result;
}

示例：求整数平方根
function mySqrt(x: number): number {
  let lo = 0;
  let hi = x;
  let result = 0;

  while (lo <= hi) {
    const mid = lo + Math.floor((hi - lo) / 2);

    if (mid * mid <= x) {
      result = mid;
      lo = mid + 1;
    } else {
      hi = mid - 1;
    }
  }

  return result;
}
TypeScript 实用模板汇总
// 1. 基础查找：在有序数组中查找 target，返回下标或 -1
function bsBasic(nums: number[], target: number): number {
  let lo = 0,
    hi = nums.length - 1;
  while (lo <= hi) {
    const mid = lo + ((hi - lo) >> 1);
    if (nums[mid] === target) return mid;
    if (nums[mid] < target) lo = mid + 1;
    else hi = mid - 1;
  }
  return -1;
}

// 2. 左边界：第一个 >= target 的位置（等价于 C++ lower_bound）
function lowerBound(nums: number[], target: number): number {
  let lo = 0,
    hi = nums.length;
  while (lo < hi) {
    const mid = lo + ((hi - lo) >> 1);
    if (nums[mid] < target) lo = mid + 1;
    else hi = mid;
  }
  return lo;
}

// 3. 右边界：第一个 > target 的位置（等价于 C++ upper_bound）
function upperBound(nums: number[], target: number): number {
  let lo = 0,
    hi = nums.length;
  while (lo < hi) {
    const mid = lo + ((hi - lo) >> 1);
    if (nums[mid] <= target) lo = mid + 1;
    else hi = mid;
  }
  return lo;
}


lowerBound 和 upperBound 使用左闭右开区间 [lo, hi)，循环条件为 lo < hi，收缩时 hi = mid 而非 hi = mid - 1。这与闭区间写法有本质区别，使用时务必保持一致。




小结
    

  • 二分查找的时间复杂度为 O(log⁡n)O(\log n)O(logn)，空间复杂度为 O(1)O(1)O(1)（迭代实现），是有序数据中最高效的搜索算法。
    • 

  • 掌握闭区间和左闭右开两种写法的区别，是避免 Off-by-One 错误的关键。
    • 

  • 查找左边界和右边界是处理重复元素场景的标准手段，面试中高频考察。
    • 

  • 二分查找的思想可以泛化到所有满足单调性/二段性的判定问题上，搜索空间从数组下标扩展到答案空间。
    • 

  • 搜索旋转排序数组是二分查找最经典的变体之一，核心在于判断哪一半是有序的。
