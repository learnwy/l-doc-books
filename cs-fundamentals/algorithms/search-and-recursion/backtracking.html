回溯法

什么是回溯法

回溯法（Backtracking）是一种通过逐步构建候选解并在发现当前路径不可能产生有效解时撤销上一步选择（即"回溯"）的系统性搜索算法。它本质上是对状态空间树的深度优先遍历（DFS），配合剪枝策略来避免无意义的搜索。



回溯法是暴力搜索的一种优化形式。它不会盲目遍历所有可能，而是在搜索过程中通过剪枝提前排除不可能的分支。




核心概念
状态空间树
回溯法的搜索过程可以用一棵状态空间树来表示。树的每个节点代表一个部分解的状态，每条边代表一次选择，从根节点到叶节点的路径构成一个完整的候选解。

剪枝
剪枝（Pruning）是回溯法的核心优化手段。当我们在搜索过程中发现当前路径不可能产生有效解时，立即停止对该分支的探索，回退到上一层尝试其他选择。

回溯法通用模板
回溯法的代码结构高度统一，几乎所有问题都可以套用以下框架：


function backtrack<T>(
  result: T[][],
  path: T[],
  choices: T[],
  /* 其他参数如 startIndex, target 等 */
): void {
  if (/* 满足结束条件 */) {
    result.push([...path]);
    return;
  }

  for (let i = 0; i < choices.length; i++) {
    if (/* 剪枝条件 */) continue;

    path.push(choices[i]);        // 做出选择
    backtrack(result, path, choices /* 更新参数 */);
    path.pop();                   // 撤销选择（回溯）
  }
}

经典问题
1. 全排列（Permutations）
给定一个不含重复元素的数组，返回其所有可能的排列。


function permute(nums: number[]): number[][] {
  const result: number[][] = [];
  const used = new Array<boolean>(nums.length).fill(false);

  function backtrack(path: number[]): void {
    if (path.length === nums.length) {
      result.push([...path]);
      return;
    }

    for (let i = 0; i < nums.length; i++) {
      if (used[i]) continue;

      used[i] = true;
      path.push(nums[i]);
      backtrack(path);
      path.pop();
      used[i] = false;
    }
  }

  backtrack([]);
  return result;
}
执行过程（以 [1, 2, 3] 为例）
2. 子集（Subsets）
给定一个不含重复元素的数组，返回其所有可能的子集（幂集）。


function subsets(nums: number[]): number[][] {
  const result: number[][] = [];

  function backtrack(start: number, path: number[]): void {
    result.push([...path]);

    for (let i = start; i < nums.length; i++) {
      path.push(nums[i]);
      backtrack(i + 1, path);
      path.pop();
    }
  }

  backtrack(0, []);
  return result;
}
子集问题与排列问题的关键区别在于：子集不需要用到所有元素，因此每一层递归都将当前 path 加入结果集，同时通过 start 参数保证不回头选取，避免重复。




对于 n 个元素，子集总数为 2n2^n2n（每个元素选或不选两种状态）。




3. N 皇后问题（N-Queens）
在 n×nn \times nn×n 的棋盘上放置 nnn 个皇后，使得它们互不攻击（不在同一行、同一列、同一对角线上）。


function solveNQueens(n: number): string[][] {
  const result: string[][] = [];
  const board: string[][] = Array.from({ length: n }, () => Array(n).fill('.'));

  const cols = new Set<number>();
  const diag1 = new Set<number>(); // row - col
  const diag2 = new Set<number>(); // row + col

  function backtrack(row: number): void {
    if (row === n) {
      result.push(board.map((r) => r.join('')));
      return;
    }

    for (let col = 0; col < n; col++) {
      if (cols.has(col) || diag1.has(row - col) || diag2.has(row + col)) {
        continue;
      }

      board[row][col] = 'Q';
      cols.add(col);
      diag1.add(row - col);
      diag2.add(row + col);

      backtrack(row + 1);

      board[row][col] = '.';
      cols.delete(col);
      diag1.delete(row - col);
      diag2.delete(row + col);
    }
  }

  backtrack(0);
  return result;
}
冲突检测原理
N 皇后使用三个集合进行 O(1)O(1)O(1) 冲突判断：

. Q . .      (row=0, col=1)
. . . Q      (row=1, col=3)
Q . . .      (row=2, col=0)
. . Q .      (row=3, col=2)
4. 组合总和（Combination Sum）
给定一个无重复元素的数组 candidates 和一个目标值 target，找出所有使得数字之和等于 target 的组合。每个数字可以无限次使用。


function combinationSum(candidates: number[], target: number): number[][] {
  const result: number[][] = [];
  candidates.sort((a, b) => a - b);

  function backtrack(start: number, path: number[], remaining: number): void {
    if (remaining === 0) {
      result.push([...path]);
      return;
    }

    for (let i = start; i < candidates.length; i++) {
      if (candidates[i] > remaining) break; // 剪枝：排序后后续元素更大，无需继续

      path.push(candidates[i]);
      backtrack(i, path, remaining - candidates[i]); // i 不加 1，允许重复选取
      path.pop();
    }
  }

  backtrack(0, [], target);
  return result;
}

5. 含重复元素的排列（Permutations II）
当输入数组包含重复元素时，需要在同一层级跳过相同元素以避免产生重复排列。


function permuteUnique(nums: number[]): number[][] {
  const result: number[][] = [];
  const used = new Array<boolean>(nums.length).fill(false);
  nums.sort((a, b) => a - b);

  function backtrack(path: number[]): void {
    if (path.length === nums.length) {
      result.push([...path]);
      return;
    }

    for (let i = 0; i < nums.length; i++) {
      if (used[i]) continue;
      if (i > 0 && nums[i] === nums[i - 1] && !used[i - 1]) continue;

      used[i] = true;
      path.push(nums[i]);
      backtrack(path);
      path.pop();
      used[i] = false;
    }
  }

  backtrack([]);
  return result;
}
去重的关键条件：nums[i] === nums[i - 1] && !used[i - 1]，含义是在同一层递归中，如果前一个相同值的元素还没有被选（说明它在本层已经被回溯撤销过），则跳过当前元素以避免重复。


6. 含重复元素的子集（Subsets II）
function subsetsWithDup(nums: number[]): number[][] {
  const result: number[][] = [];
  nums.sort((a, b) => a - b);

  function backtrack(start: number, path: number[]): void {
    result.push([...path]);

    for (let i = start; i < nums.length; i++) {
      if (i > start && nums[i] === nums[i - 1]) continue;

      path.push(nums[i]);
      backtrack(i + 1, path);
      path.pop();
    }
  }

  backtrack(0, []);
  return result;
}

解题思路总结
小结
    

  • 回溯法是解决穷举搜索类问题的通用框架，核心操作是「做选择 → 递归探索 → 撤销选择」。
    • 

  • 状态空间树是理解回溯过程的关键工具，所有候选解都对应树中根到叶的路径。
    • 

  • 剪枝是回溯法效率的命脉——可行性剪枝排除非法路径，对称性剪枝消除重复搜索。
    • 

  • 排列问题使用 used 数组标记已选元素；组合/子集问题使用 start 参数控制搜索起点。
    • 

  • 处理含重复元素的问题时，先排序，然后在同一层递归中跳过相同值，是标准的去重策略。
    • 

  • 回溯法的时间复杂度通常是指数级或阶乘级，适用于数据规模较小（n≤20n \leq 20n≤20）的场景。
