递归与分治

递归（Recursion）和分治（Divide and Conquer）是算法设计中最重要的两大基石。递归是一种编程技巧，通过函数调用自身来解决问题；分治是一种算法范式，将大问题拆分为结构相同的小问题，分别求解后合并结果。两者天然契合——分治算法几乎总是通过递归来实现。

Fibonacci 数列
Fibonacci 数列是递归的另一个经典例子：F(0)=0,  F(1)=1,  F(n)=F(n−1)+F(n−2)F(0) = 0,\; F(1) = 1,\; F(n) = F(n-1) + F(n-2)F(0)=0,F(1)=1,F(n)=F(n−1)+F(n−2)。


function fibNaive(n: number): number {
  if (n <= 0) return 0;
  if (n === 1) return 1;
  return fibNaive(n - 1) + fibNaive(n - 2);
}

记忆化优化
通过记忆化（Memoization）缓存已计算的结果，可将时间复杂度降至 O(n)O(n)O(n)：


function fibMemo(n: number, memo: Map<number, number> = new Map()): number {
  if (n <= 0) return 0;
  if (n === 1) return 1;
  if (memo.has(n)) return memo.get(n)!;

  const result = fibMemo(n - 1, memo) + fibMemo(n - 2, memo);
  memo.set(n, result);
  return result;
}

Fibonacci 的迭代写法
function fibIterative(n: number): number {
  if (n <= 0) return 0;
  if (n === 1) return 1;

  let prev2 = 0;
  let prev1 = 1;

  for (let i = 2; i <= n; i++) {
    const curr = prev1 + prev2;
    prev2 = prev1;
    prev1 = curr;
  }

  return prev1;
}


经验法则：如果问题是简单的线性递推（如阶乘、Fibonacci），优先使用迭代；如果问题具有天然的树状递归结构（如分治、回溯），递归往往更自然。






分治法（Divide and Conquer）
核心思想
分治法将原问题分解为若干规模更小、结构相同的子问题，递归地解决这些子问题，然后将子问题的解合并为原问题的解。

分治法的适用条件
    

  1. 可分解性：原问题可以分解为若干个规模较小的相同类型子问题
    2. 

  2. 可合并性：子问题的解可以合并为原问题的解
    3. 

  3. 子问题独立：子问题之间互不依赖（否则考虑动态规划）
    4. 

  4. 基准情形存在：存在可以直接求解的最小子问题

经典分治算法
1. 归并排序的分解过程
归并排序是分治法最经典的应用。这里我们着重展示其**分解（Split）**阶段的递归树结构：


function mergeSortSplit(arr: number[]): number[] {
  if (arr.length <= 1) return arr;

  const mid = Math.floor(arr.length / 2);
  const left = mergeSortSplit(arr.slice(0, mid));
  const right = mergeSortSplit(arr.slice(mid));

  return mergeTwoSorted(left, right);
}

function mergeTwoSorted(left: number[], right: number[]): number[] {
  const result: number[] = [];
  let i = 0;
  let j = 0;

  while (i < left.length && j < right.length) {
    if (left[i] <= right[j]) {
      result.push(left[i++]);
    } else {
      result.push(right[j++]);
    }
  }

  while (i < left.length) result.push(left[i++]);
  while (j < right.length) result.push(right[j++]);

  return result;
}

2. 最大子数组问题（分治解法）
给定一个整数数组，找出连续子数组的最大和。分治法将数组一分为二，最大子数组要么完全在左半部分，要么完全在右半部分，要么横跨中点。


function maxSubArrayDivide(nums: number[]): number {
  return maxSubHelper(nums, 0, nums.length - 1);
}

function maxSubHelper(nums: number[], lo: number, hi: number): number {
  if (lo === hi) return nums[lo];

  const mid = lo + Math.floor((hi - lo) / 2);

  const leftMax = maxSubHelper(nums, lo, mid);
  const rightMax = maxSubHelper(nums, mid + 1, hi);
  const crossMax = maxCrossingSubArray(nums, lo, mid, hi);

  return Math.max(leftMax, rightMax, crossMax);
}

function maxCrossingSubArray(nums: number[], lo: number, mid: number, hi: number): number {
  let leftSum = -Infinity;
  let sum = 0;
  for (let i = mid; i >= lo; i--) {
    sum += nums[i];
    if (sum > leftSum) leftSum = sum;
  }

  let rightSum = -Infinity;
  sum = 0;
  for (let i = mid + 1; i <= hi; i++) {
    sum += nums[i];
    if (sum > rightSum) rightSum = sum;
  }

  return leftSum + rightSum;
}

3. 幂运算（快速幂）
计算 xnx^nxn 的朴素做法需要 O(n)O(n)O(n) 次乘法，利用分治可以做到 O(log⁡n)O(\log n)O(logn)：


xn={1n=0(xn/2)2n 为偶数x⋅(x(n−1)/2)2n 为奇数x^n = \begin{cases} 1 & n = 0 \\ (x^{n/2})^2 & n \text{ 为偶数} \\ x \cdot (x^{(n-1)/2})^2 & n \text{ 为奇数} \end{cases}xn=⎩⎨⎧​1(xn/2)2x⋅(x(n−1)/2)2​n=0n 为偶数n 为奇数​
function power(x: number, n: number): number {
  if (n === 0) return 1;
  if (n < 0) return 1 / power(x, -n);

  if (n % 2 === 0) {
    const half = power(x, n / 2);
    return half * half;
  } else {
    const half = power(x, (n - 1) / 2);
    return x * half * half;
  }
}
快速幂只需 O(log⁡n)O(\log n)O(logn) 次递归调用，每次只做常数次乘法运算。


4. 汉诺塔问题
汉诺塔是递归思想的经典应用：将 nnn 个盘子从源柱移动到目标柱，每次只能移动一个盘子，且大盘不能放在小盘上面。


function hanoi(n: number, source: string, auxiliary: string, target: string): void {
  if (n === 1) {
    console.log(`${source} → ${target}`);
    return;
  }

  hanoi(n - 1, source, target, auxiliary);
  console.log(`${source} → ${target}`);
  hanoi(n - 1, auxiliary, source, target);
}
移动 nnn 个盘子的最少步数为 2n−12^n - 12n−1，递推式为 T(n)=2T(n−1)+1T(n) = 2T(n-1) + 1T(n)=2T(n−1)+1。




递归的常见优化技巧
1. 记忆化（Memoization）
缓存已计算的子问题结果，避免重复计算。前面 Fibonacci 示例中已经演示。


2. 尾递归优化
将递归调用放在函数的最后一步，使得编译器/引擎可以复用当前栈帧。虽然 TypeScript 引擎目前普遍不支持尾调用优化（TCO），但写成尾递归形式有助于理解和手动改写为迭代。


function factorialTail(n: number, acc: number = 1): number {
  if (n <= 1) return acc;
  return factorialTail(n - 1, n * acc);
}
3. 分治与剪枝结合
在分治过程中，如果某些子问题显然不会产生更优解，可以提前跳过（剪枝），减少不必要的递归调用。

小结
    

  • 递归是函数调用自身的编程技巧，必须包含基准情形防止无限递归，每次递归调用都会消耗调用栈空间。
    • 

  • 分治法是将问题分解、求解、合并的算法范式，要求子问题结构相同且相互独立。
    • 

  • 主定理提供了分析分治算法时间复杂度的快速方法：比较 log⁡ba\log_b alogb​a 与 ddd 的大小即可判定。
    • 

  • 朴素递归可能导致大量重复计算（如 Fibonacci），通过记忆化或改写为迭代可以显著优化。
    • 

  • 归并排序（O(nlog⁡n)O(n \log n)O(nlogn)）、最大子数组（O(nlog⁡n)O(n \log n)O(nlogn)）、快速幂（O(log⁡n)O(\log n)O(logn)）是分治法的三个经典应用，它们清晰地展示了分治的三步策略。
    • 

  • 理解递归与分治是掌握更高级算法（回溯、动态规划、树形问题）的重要基础。
    •
