基础排序

概述

基础排序算法是学习排序的起点。它们的核心思想直观、实现简单，虽然时间复杂度大多为 O(n2)O(n^2)O(n2)，但在小规模数据或近乎有序的数据上仍有实用价值。本节将介绍三种经典的基础排序：冒泡排序、选择排序和插入排序。



冒泡排序（Bubble Sort）
原理
冒泡排序通过反复相邻元素两两比较并交换，使较大的元素像气泡一样逐步"浮"到数组末端。每完成一轮遍历，当前未排序部分的最大值就会被放到正确位置。


排序过程可视化
以数组 [5, 3, 8, 4, 2] 为例：


TypeScript 实现
function bubbleSort(arr: number[]): number[] {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    let swapped = false;
    for (let j = 0; j < n - 1 - i; j++) {
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
        swapped = true;
      }
    }
    if (!swapped) break;
  }
  return arr;
}


加入 swapped 标志位是一种常见优化：如果某一轮没有发生任何交换，说明数组已经有序，可以提前终止。

选择排序（Selection Sort）
原理
选择排序的思路是：每一轮从未排序区间中选出最小的元素，将其与未排序区间的第一个元素交换，从而逐步扩大已排序区间。


排序过程可视化
以数组 [5, 3, 8, 4, 2] 为例：


TypeScript 实现
function selectionSort(arr: number[]): number[] {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    let minIdx = i;
    for (let j = i + 1; j < n; j++) {
      if (arr[j] < arr[minIdx]) {
        minIdx = j;
      }
    }
    if (minIdx !== i) {
      [arr[i], arr[minIdx]] = [arr[minIdx], arr[i]];
    }
  }
  return arr;
}

不稳定性说明：选择排序在交换时可能跳过中间的相等元素。例如 [5a, 5b, 2]，第一轮将 2 与 5a 交换得到 [2, 5b, 5a]，此时 5a 和 5b 的相对顺序已经改变。




注意：无论输入数据是否有序，选择排序都需要完整遍历未排序区间来寻找最小值，因此最好、最坏、平均时间复杂度均为 O(n2)O(n^2)O(n2)。






插入排序（Insertion Sort）
原理
插入排序模拟了打牌时整理手牌的过程：从左到右依次取出每个元素，将其插入到前面已排序区间的正确位置。


排序过程可视化
以数组 [5, 3, 8, 4, 2] 为例：


TypeScript 实现
function insertionSort(arr: number[]): number[] {
  const n = arr.length;
  for (let i = 1; i < n; i++) {
    const key = arr[i];
    let j = i - 1;
    while (j >= 0 && arr[j] > key) {
      arr[j + 1] = arr[j];
      j--;
    }
    arr[j + 1] = key;
  }
  return arr;
}

稳定性说明：内层循环的条件是 arr[j] > key（严格大于），当遇到相等元素时停止移动，因此相等元素的相对顺序保持不变。




插入排序在数据近乎有序时表现极佳，时间复杂度趋近 O(n)O(n)O(n)。许多高级排序算法（如 TimSort）在小规模子数组上会切换到插入排序。

如何选择
小结
    

  • 三种基础排序的平均时间复杂度均为 O(n2)O(n^2)O(n2)，空间复杂度均为 O(1)O(1)O(1)。
    • 

  • 冒泡排序通过相邻交换将最大值逐步"冒泡"到末尾，加入提前终止优化后在有序数据上可达 O(n)O(n)O(n)。
    • 

  • 选择排序每轮选出最小值放到前面，比较次数固定但交换次数最少（最多 n−1n-1n−1 次），适合写入代价高的场景。
    • 

  • 插入排序在近乎有序的数据上表现最优，是实际工程中最常被用作"兜底策略"的基础排序算法。
    • 

  • 理解这三种基础排序的原理和特性，是掌握更高效的排序算法（如归并排序、快速排序）的重要基础。
