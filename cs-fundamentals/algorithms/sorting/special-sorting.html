特殊排序

概述

前面介绍的冒泡排序、快速排序、归并排序等都属于基于比较的排序，它们通过元素之间的两两比较来确定顺序，理论下界为 O(nlog⁡n)O(n \log n)O(nlogn)。

而本节介绍的三种排序算法——计数排序、基数排序、桶排序——属于非比较排序。它们不通过比较元素大小来排序，而是利用元素本身的数值特征（如数值范围、位数、分布等）来确定元素在输出中的位置，从而在特定条件下突破 O(nlog⁡n)O(n \log n)O(nlogn) 的理论下界。



为什么非比较排序能突破 O(nlog⁡n)O(n \log n)O(nlogn)？ 因为 O(nlog⁡n)O(n \log n)O(nlogn) 的下界仅适用于基于比较的排序模型。非比较排序利用了数据的额外信息（如值域范围），不受该理论限制。






计数排序（Counting Sort）
原理
计数排序的核心思想是用数值本身作为下标：


    

  1. 找到待排序数组中的最大值 kkk，创建一个长度为 k+1k + 1k+1 的计数数组
    2. 

  2. 遍历原数组，统计每个元素出现的次数
    3. 

  3. 对计数数组做前缀和，得到每个元素在输出数组中的最终位置
    4. 

  4. 反向遍历原数组，将元素放到正确位置（保证稳定性）
    5. 



执行过程示例
以数组 [4, 2, 2, 8, 3, 3, 1] 为例：


TypeScript 实现
function countingSort(arr: number[]): number[] {
  if (arr.length <= 1) return [...arr];

  const max = Math.max(...arr);
  const min = Math.min(...arr);
  const range = max - min + 1;

  const count = new Array<number>(range).fill(0);
  const output = new Array<number>(arr.length);

  for (const val of arr) {
    count[val - min]++;
  }

  for (let i = 1; i < range; i++) {
    count[i] += count[i - 1];
  }

  for (let i = arr.length - 1; i >= 0; i--) {
    const idx = arr[i] - min;
    output[--count[idx]] = arr[i];
  }

  return output;
}

基数排序（Radix Sort）
原理
基数排序将整数按位数切割，从最低位到最高位（LSD）或从最高位到最低位（MSD），逐位使用稳定排序（通常是计数排序）进行排列。经过 ddd 轮排序后，整个数组有序。

执行过程示例（LSD）
对 [170, 45, 75, 90, 802, 24, 2, 66] 进行 LSD 基数排序：


TypeScript 实现（LSD）
function radixSort(arr: number[]): number[] {
  if (arr.length <= 1) return [...arr];

  const max = Math.max(...arr);
  let result = [...arr];

  for (let exp = 1; Math.floor(max / exp) > 0; exp *= 10) {
    result = countingSortByDigit(result, exp);
  }

  return result;
}

function countingSortByDigit(arr: number[], exp: number): number[] {
  const n = arr.length;
  const output = new Array<number>(n);
  const count = new Array<number>(10).fill(0);

  for (const val of arr) {
    const digit = Math.floor(val / exp) % 10;
    count[digit]++;
  }

  for (let i = 1; i < 10; i++) {
    count[i] += count[i - 1];
  }

  for (let i = n - 1; i >= 0; i--) {
    const digit = Math.floor(arr[i] / exp) % 10;
    output[--count[digit]] = arr[i];
  }

  return output;
}
支持负数的基数排序
上面的实现仅支持非负整数。若需支持负数，可将正负数分开处理：


function radixSortWithNegatives(arr: number[]): number[] {
  const negatives = arr.filter((x) => x < 0).map((x) => -x);
  const positives = arr.filter((x) => x >= 0);

  const sortedNeg = radixSort(negatives)
    .reverse()
    .map((x) => -x);
  const sortedPos = radixSort(positives);

  return [...sortedNeg, ...sortedPos];
}

桶排序（Bucket Sort）
原理
桶排序的核心思想是分治 + 分布：


    

  1. 根据数据的分布范围，将数据划分到有限数量的**桶（bucket）**中
    2. 

  2. 对每个桶内部分别排序（可用插入排序或其他排序）
    3. 

  3. 按桶的顺序依次合并所有桶中的元素
    4. 



执行过程示例
对 [0.42, 0.32, 0.23, 0.52, 0.25, 0.47, 0.51] 使用 5 个桶排序：


TypeScript 实现
function bucketSort(arr: number[], bucketCount: number = 10): number[] {
  if (arr.length <= 1) return [...arr];

  const min = Math.min(...arr);
  const max = Math.max(...arr);

  if (min === max) return [...arr];

  const bucketSize = (max - min + 1) / bucketCount;
  const buckets: number[][] = Array.from({ length: bucketCount }, () => []);

  for (const val of arr) {
    const idx = Math.min(Math.floor((val - min) / bucketSize), bucketCount - 1);
    buckets[idx].push(val);
  }

  for (const bucket of buckets) {
    insertionSort(bucket);
  }

  return buckets.flat();
}

function insertionSort(arr: number[]): void {
  for (let i = 1; i < arr.length; i++) {
    const key = arr[i];
    let j = i - 1;
    while (j >= 0 && arr[j] > key) {
      arr[j + 1] = arr[j];
      j--;
    }
    arr[j + 1] = key;
  }
}
浮点数桶排序（[0, 1) 区间优化版）
当数据均匀分布在 [0, 1) 区间时，桶排序可简化：


function bucketSortFloat(arr: number[]): number[] {
  const n = arr.length;
  if (n <= 1) return [...arr];

  const buckets: number[][] = Array.from({ length: n }, () => []);

  for (const val of arr) {
    const idx = Math.min(Math.floor(val * n), n - 1);
    buckets[idx].push(val);
  }

  for (const bucket of buckets) {
    insertionSort(bucket);
  }

  return buckets.flat();
}

综合示例：性能对比测试
function benchmark(name: string, sortFn: (arr: number[]) => number[], arr: number[]): void {
  const start = performance.now();
  const result = sortFn(arr);
  const elapsed = (performance.now() - start).toFixed(2);

  const isSorted = result.every((v, i, a) => i === 0 || a[i - 1] <= v);
  console.log(`${name}: ${elapsed}ms, 正确: ${isSorted}`);
}

const size = 100_000;
const maxVal = 1000;
const testData = Array.from({ length: size }, () => Math.floor(Math.random() * maxVal));

benchmark('计数排序', countingSort, testData);
benchmark('基数排序', radixSort, testData);
benchmark('桶排序', (arr) => bucketSort(arr, 100), testData);
benchmark('Array.sort', (arr) => [...arr].sort((a, b) => a - b), testData);
小结
    

  • 计数排序通过统计元素频次实现排序，时间 O(n+k)O(n + k)O(n+k)，适用于值域较小的整数数据。
    • 

  • 基数排序将数据按位拆分，逐位使用稳定排序，时间 O(d(n+k))O(d(n + k))O(d(n+k))，适用于整数或定长字符串。
    • 

  • 桶排序将数据分配到多个桶中分别排序再合并，平均时间 O(n+k)O(n + k)O(n+k)，适用于均匀分布的数据。
    • 

  • 三者均为稳定排序，但都需要额外空间，且对数据有一定前提要求。
    • 

  • 在实际工程中，应根据数据特征选择合适的排序算法：当数据满足非比较排序的前提条件时，它们的性能远优于通用的比较排序。
    •
