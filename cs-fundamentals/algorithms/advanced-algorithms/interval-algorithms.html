区间算法

核心概念

区间算法处理的是以"区间"为基本对象的一类问题——每个区间由起点和终点定义，问题要求对这些区间进行合并、插入、调度或统计等操作。区间问题在日历系统、任务调度、计算几何和数据库查询中都有广泛应用。解决区间问题的关键通常是先按某个端点排序，然后利用贪心或扫描线的思路逐一处理。

区间合并
区间合并是最基础的区间操作：给定一组可能重叠的区间，将所有重叠的区间合并为不重叠的区间。


function mergeIntervals(intervals: number[][]): number[][] {
  intervals.sort((a, b) => a[0] - b[0]);
  const merged: number[][] = [intervals[0]];

  for (let i = 1; i < intervals.length; i++) {
    const last = merged[merged.length - 1];
    const curr = intervals[i];

    if (curr[0] <= last[1]) {
      last[1] = Math.max(last[1], curr[1]);
    } else {
      merged.push(curr);
    }
  }

  return merged;
}
算法的正确性依赖于排序：按起点排序后，如果当前区间的起点小于等于上一个合并区间的终点，则两者重叠，扩展终点即可。


区间插入则是在已排序的不重叠区间列表中插入一个新区间：


function insertInterval(intervals: number[][], newInterval: number[]): number[][] {
  const result: number[][] = [];
  let i = 0;
  const n = intervals.length;

  while (i < n && intervals[i][1] < newInterval[0]) {
    result.push(intervals[i]);
    i++;
  }

  while (i < n && intervals[i][0] <= newInterval[1]) {
    newInterval[0] = Math.min(newInterval[0], intervals[i][0]);
    newInterval[1] = Math.max(newInterval[1], intervals[i][1]);
    i++;
  }
  result.push(newInterval);

  while (i < n) {
    result.push(intervals[i]);
    i++;
  }

  return result;
}
区间调度与贪心
区间调度问题的经典形式：给定一组区间，选择最多的不重叠区间。贪心策略：按终点排序，每次选终点最早的区间。


function maxNonOverlapping(intervals: number[][]): number {
  intervals.sort((a, b) => a[1] - b[1]);
  let count = 1;
  let lastEnd = intervals[0][1];

  for (let i = 1; i < intervals.length; i++) {
    if (intervals[i][0] >= lastEnd) {
      count++;
      lastEnd = intervals[i][1];
    }
  }

  return count;
}
为什么按终点排序而不是按起点？按终点排序选最早结束的区间，为后续区间留出最大空间。这是贪心正确性的关键。


移除最少区间使剩余不重叠：答案就是总数减去最大不重叠数。


function eraseOverlapIntervals(intervals: number[][]): number {
  return intervals.length - maxNonOverlapping(intervals);
}
用最少箭射爆所有气球（每个气球是一个区间，箭射在某点可以射爆所有覆盖该点的气球）：


function findMinArrowShots(points: number[][]): number {
  points.sort((a, b) => a[1] - b[1]);
  let arrows = 1;
  let arrowPos = points[0][1];

  for (let i = 1; i < points.length; i++) {
    if (points[i][0] > arrowPos) {
      arrows++;
      arrowPos = points[i][1];
    }
  }

  return arrows;
}

扫描线算法
扫描线（Sweep Line）将区间问题转化为"事件"序列：每个区间的起点是一个"开始事件"，终点是一个"结束事件"。将所有事件按时间排序后扫描，维护当前的活跃状态。


会议室问题——判断是否有时间冲突：


function canAttendMeetings(intervals: number[][]): boolean {
  intervals.sort((a, b) => a[0] - b[0]);
  for (let i = 1; i < intervals.length; i++) {
    if (intervals[i][0] < intervals[i - 1][1]) return false;
  }
  return true;
}
最少会议室数量——求最大重叠区间数：


function minMeetingRooms(intervals: number[][]): number {
  const events: [number, number][] = [];

  for (const [start, end] of intervals) {
    events.push([start, 1]);
    events.push([end, -1]);
  }

  events.sort((a, b) => a[0] - b[0] || a[1] - b[1]);

  let maxRooms = 0;
  let current = 0;

  for (const [, type] of events) {
    current += type;
    maxRooms = Math.max(maxRooms, current);
  }

  return maxRooms;
}
排序时的细节：当开始和结束事件在同一时间点时，先处理结束事件（-1 排在 1 前面），这样可以正确处理"前一个会议刚结束、后一个立刻开始"的情况。


区间覆盖问题
区间覆盖要求用最少的区间覆盖一个给定范围 [0,target][0, target][0,target]：


function minIntervalsToCover(intervals: number[][], target: number): number {
  intervals.sort((a, b) => a[0] - b[0]);
  let covered = 0;
  let count = 0;
  let i = 0;

  while (covered < target) {
    let farthest = covered;

    while (i < intervals.length && intervals[i][0] <= covered) {
      farthest = Math.max(farthest, intervals[i][1]);
      i++;
    }

    if (farthest === covered) return -1;

    covered = farthest;
    count++;
  }

  return count;
}
贪心策略：每次从所有起点不超过当前覆盖位置的区间中，选择终点最远的那个。


小结
    

  • 区间问题的第一步几乎总是排序——按起点或按终点，取决于问题类型
    • 

  • 区间合并按起点排序，贪心扩展终点；区间调度按终点排序，贪心选最早结束
    • 

  • 扫描线将区间转化为事件序列，通过扫描事件维护动态状态
    • 

  • 区间覆盖每次贪心选终点最远的区间来最大化覆盖范围
    • 

  • 排序时同一时间点的事件顺序很重要，通常结束事件在开始事件之前处理
    • 

  • 区间问题的贪心策略看似简单，但证明正确性需要理解排序带来的单调性保证
