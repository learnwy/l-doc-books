字符串匹配 KMP

核心概念

字符串匹配是在文本串 TTT 中查找模式串 PPP 出现位置的经典问题。暴力匹配在最坏情况下需要 O(nm)O(nm)O(nm) 的时间，而 KMP 算法通过预处理模式串的"前缀函数"（failure function），避免了不必要的回退，将时间复杂度降到 O(n+m)O(n+m)O(n+m)。除 KMP 外，Rabin-Karp 哈希匹配、Z 算法和 Manacher 回文算法也是常用的字符串匹配工具。

KMP 算法
KMP 的核心在于前缀函数 π[i]\pi[i]π[i]：对于模式串 PPP，π[i]\pi[i]π[i] 表示 P[0..i]P[0..i]P[0..i] 的最长真前缀后缀的长度。当匹配失败时，利用 π\piπ 数组跳转到正确位置，避免重复比较。


构建前缀函数：


function buildKMPTable(pattern: string): number[] {
  const m = pattern.length;
  const table = new Array(m).fill(0);
  let len = 0;
  let i = 1;

  while (i < m) {
    if (pattern[i] === pattern[len]) {
      len++;
      table[i] = len;
      i++;
    } else if (len > 0) {
      len = table[len - 1];
    } else {
      table[i] = 0;
      i++;
    }
  }

  return table;
}
KMP 匹配过程：


function kmpSearch(text: string, pattern: string): number[] {
  const n = text.length;
  const m = pattern.length;
  const table = buildKMPTable(pattern);
  const matches: number[] = [];
  let j = 0;

  for (let i = 0; i < n; i++) {
    while (j > 0 && text[i] !== pattern[j]) {
      j = table[j - 1];
    }

    if (text[i] === pattern[j]) {
      j++;
    }

    if (j === m) {
      matches.push(i - m + 1);
      j = table[j - 1];
    }
  }

  return matches;
}
KMP 的关键洞察：当 text[i] !== pattern[j] 时，pattern[0..j-1] 已经匹配成功。前缀函数告诉我们 pattern[0..j-1] 的最长真前缀后缀长度，跳转到该位置继续匹配，因为这个前缀已经被验证匹配了。


Rabin-Karp 哈希匹配
Rabin-Karp 算法用滚动哈希代替逐字符比较：先计算模式串的哈希值，然后在文本上滑动窗口计算子串哈希值，哈希相等时再逐字符验证。


function rabinKarp(text: string, pattern: string): number[] {
  const n = text.length;
  const m = pattern.length;
  if (m > n) return [];

  const BASE = 31;
  const MOD = 1e9 + 7;
  const matches: number[] = [];

  let patternHash = 0;
  let textHash = 0;
  let power = 1;

  for (let i = 0; i < m; i++) {
    patternHash = (patternHash * BASE + pattern.charCodeAt(i)) % MOD;
    textHash = (textHash * BASE + text.charCodeAt(i)) % MOD;
    if (i > 0) power = (power * BASE) % MOD;
  }

  for (let i = 0; i <= n - m; i++) {
    if (textHash === patternHash) {
      if (text.slice(i, i + m) === pattern) {
        matches.push(i);
      }
    }

    if (i < n - m) {
      textHash = (textHash - ((text.charCodeAt(i) * power) % MOD) + MOD) % MOD;
      textHash = (textHash * BASE + text.charCodeAt(i + m)) % MOD;
    }
  }

  return matches;
}
Rabin-Karp 的优势在于可以同时匹配多个模式串——只需要比较哈希值即可，这在多模式匹配场景（如敏感词过滤）中很有价值。


Z 算法
Z 算法构建 Z 数组：Z[i]Z[i]Z[i] 表示从位置 iii 开始的子串与整个字符串的最长公共前缀长度。Z 数组可以用 O(n)O(n)O(n) 时间构建。


function buildZArray(s: string): number[] {
  const n = s.length;
  const z = new Array(n).fill(0);
  let left = 0;
  let right = 0;

  for (let i = 1; i < n; i++) {
    if (i < right) {
      z[i] = Math.min(right - i, z[i - left]);
    }

    while (i + z[i] < n && s[z[i]] === s[i + z[i]]) {
      z[i]++;
    }

    if (i + z[i] > right) {
      left = i;
      right = i + z[i];
    }
  }

  return z;
}

function zSearch(text: string, pattern: string): number[] {
  const combined = pattern + '$' + text;
  const z = buildZArray(combined);
  const m = pattern.length;
  const matches: number[] = [];

  for (let i = m + 1; i < combined.length; i++) {
    if (z[i] === m) {
      matches.push(i - m - 1);
    }
  }

  return matches;
}
Z 算法的思路：将模式串和文本串用特殊字符拼接，然后构建 Z 数组。Z 值等于模式串长度的位置就是匹配位置。

Manacher 回文算法
Manacher 算法在 O(n)O(n)O(n) 时间内找到字符串中所有回文子串（及最长回文子串）。它在每个字符之间插入特殊字符来统一处理奇偶长度的回文。


function manacher(s: string): string {
  const t = '#' + s.split('').join('#') + '#';
  const n = t.length;
  const p = new Array(n).fill(0);
  let center = 0;
  let right = 0;

  for (let i = 0; i < n; i++) {
    if (i < right) {
      p[i] = Math.min(right - i, p[2 * center - i]);
    }

    while (i - p[i] - 1 >= 0 && i + p[i] + 1 < n && t[i - p[i] - 1] === t[i + p[i] + 1]) {
      p[i]++;
    }

    if (i + p[i] > right) {
      center = i;
      right = i + p[i];
    }
  }

  let maxLen = 0;
  let maxCenter = 0;
  for (let i = 0; i < n; i++) {
    if (p[i] > maxLen) {
      maxLen = p[i];
      maxCenter = i;
    }
  }

  const start = (maxCenter - maxLen) / 2;
  return s.slice(start, start + maxLen);
}
Manacher 算法的核心优化：利用已知回文的对称性来避免重复计算。当位置 iii 在已知最远回文边界内时，可以利用其关于中心的镜像位置的信息。


小结
    

  • KMP 通过前缀函数避免匹配失败时的无效回退，时间复杂度 O(n+m)O(n+m)O(n+m)
    • 

  • Rabin-Karp 用滚动哈希实现 O(1)O(1)O(1) 的子串哈希比较，适合多模式匹配
    • 

  • Z 算法构建 Z 数组记录最长公共前缀信息，通过拼接串技巧实现字符串匹配
    • 

  • Manacher 利用回文的对称性在 O(n)O(n)O(n) 时间内找到所有回文子串
    • 

  • KMP 适合单模式精确匹配，Rabin-Karp 适合多模式场景，Manacher 专门处理回文
    • 

  • 字符串匹配的核心思想是"不浪费已有的匹配信息"——利用预处理避免重复工作
    •
