模拟与枚举

核心概念

模拟和枚举是算法中最直观的两种策略。模拟题要求按照题目描述的规则逐步执行操作，考验代码实现的准确性和细节处理能力；枚举则系统性地遍历所有可能的解，通过条件过滤找到答案。虽然看似"暴力"，但模拟和枚举在竞赛和面试中出现频率极高，而且很多时候经过巧妙的剪枝和状态抽象后，它们就是最优解法。

    A --> C["枚举优化<br/>剪枝减少搜索空间"]
    A --> D["状态机模型<br/>用状态转移抽象模拟"]
    A --> E["矩阵模拟<br/>螺旋/旋转/游戏"]
类型 核心思路 难点 时间复杂度
纯模拟 忠实实现题意 边界条件、代码准确性 题目决定
枚举 + 剪枝 遍历所有可能 + 提前排除 找到有效的剪枝条件 优化后大幅减少

矩阵模拟

矩阵（二维数组）相关的模拟题是面试高频考点。螺旋遍历、矩阵旋转和矩阵置零都需要精确的索引控制。

螺旋矩阵——按螺旋顺序读取矩阵元素：

function spiralOrder(matrix: number[][]): number[] {
  const result: number[] = [];
  let top = 0;
  let bottom = matrix.length - 1;
  let left = 0;
  let right = matrix[0].length - 1;

  while (top <= bottom && left <= right) {
    for (let col = left; col <= right; col++) {
      result.push(matrix[top][col]);
    }
    top++;

    for (let row = top; row <= bottom; row++) {
      result.push(matrix[row][right]);
    }
    right--;

    if (top <= bottom) {
      for (let col = right; col >= left; col--) {
        result.push(matrix[bottom][col]);
      }
      bottom--;
    }

    if (left <= right) {
      for (let row = bottom; row >= top; row--) {
        result.push(matrix[row][left]);
      }
      left++;
    }
  }

  return result;
}

    A["定义四条边界: top, bottom, left, right"] --> B["→ 从左到右遍历上边"]
    B --> C["↓ 从上到下遍历右边"]
    C --> D["← 从右到左遍历下边"]

矩阵原地旋转 90 度（顺时针）：

function rotate(matrix: number[][]): void {
  const n = matrix.length;

  for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {
      [matrix[i][j], matrix[j][i]] = [matrix[j][i], matrix[i][j]];
    }
  }

  for (let i = 0; i < n; i++) {
    matrix[i].reverse();
  }
}

旋转的关键洞察：顺时针旋转 90° = 先沿主对角线转置，再水平翻转每行。

状态机模型

状态机是为模拟类问题提供清晰结构的强大工具。将问题抽象为有限个状态和状态之间的转移规则，每个输入触发一次状态转移。

买卖股票的最佳时机（含冷冻期）——用状态机建模：

function maxProfit(prices: number[]): number {
  const n = prices.length;
  if (n < 2) return 0;

  let hold = -prices[0];
  let sold = 0;
  let cooldown = 0;

  for (let i = 1; i < n; i++) {
    const prevHold = hold;
    const prevSold = sold;
    const prevCooldown = cooldown;

    hold = Math.max(prevHold, prevCooldown - prices[i]);
    sold = prevHold + prices[i];
    cooldown = Math.max(prevCooldown, prevSold);
  }

  return Math.max(sold, cooldown);
}

    A["持有 hold"] -->|"卖出"| B["已卖 sold"]
    B -->|"冷冻期"| C["冷冻 cooldown"]
    C -->|"买入"| A
    C -->|"不操作"| C
    A -->|"不操作"| A

验证字符串是否为有效数字——经典状态机问题：

function isNumber(s: string): boolean {
  type State = 'start' | 'sign' | 'integer' | 'dot' | 'decimal' | 'e' | 'eSign' | 'eInteger';

  const transitions: Record<State, Record<string, State>> = {
    start: { sign: 'sign', digit: 'integer', dot: 'dot' },
    sign: { digit: 'integer', dot: 'dot' },
    integer: { digit: 'integer', dot: 'decimal', e: 'e' },
    dot: { digit: 'decimal' },
    decimal: { digit: 'decimal', e: 'e' },
    e: { sign: 'eSign', digit: 'eInteger' },
    eSign: { digit: 'eInteger' },
    eInteger: { digit: 'eInteger' },
  };

  const acceptStates = new Set<State>(['integer', 'decimal', 'eInteger']);
  let state: State = 'start';

  for (const ch of s.trim()) {
    let type: string;
    if (ch >= '0' && ch <= '9') type = 'digit';
    else if (ch === '+' || ch === '-') type = 'sign';
    else if (ch === '.') type = 'dot';
    else if (ch === 'e' || ch === 'E') type = 'e';
    else return false;

    if (!transitions[state][type]) return false;
    state = transitions[state][type] as State;
  }

  return acceptStates.has(state);
}
问题 状态定义 转移触发 接受条件
股票买卖 持有/已卖/冷冻 每天的价格 最终不持有
有效数字 解析阶段 每个字符 终止在接受状态
自动贩卖机 金额状态 投入硬币 金额达标

枚举与剪枝优化

枚举的核心是系统性地遍历解空间，但朴素枚举往往太慢，需要通过剪枝大幅减少搜索量。

数独求解器——枚举 + 约束剪枝：

function solveSudoku(board: string[][]): void {
  const rows = Array.from({ length: 9 }, () => new Set<string>());
  const cols = Array.from({ length: 9 }, () => new Set<string>());
  const boxes = Array.from({ length: 9 }, () => new Set<string>());
  const empty: [number, number][] = [];

  for (let i = 0; i < 9; i++) {
    for (let j = 0; j < 9; j++) {
      if (board[i][j] === '.') {
        empty.push([i, j]);
      } else {
        const num = board[i][j];
        rows[i].add(num);
        cols[j].add(num);
        boxes[Math.floor(i / 3) * 3 + Math.floor(j / 3)].add(num);
      }
    }
  }

  function backtrack(idx: number): boolean {
    if (idx === empty.length) return true;

    const [r, c] = empty[idx];
    const boxIdx = Math.floor(r / 3) * 3 + Math.floor(c / 3);

    for (let num = 1; num <= 9; num++) {
      const s = String(num);
      if (rows[r].has(s) || cols[c].has(s) || boxes[boxIdx].has(s)) continue;

      board[r][c] = s;
      rows[r].add(s);
      cols[c].add(s);
      boxes[boxIdx].add(s);

      if (backtrack(idx + 1)) return true;

      board[r][c] = '.';
      rows[r].delete(s);
      cols[c].delete(s);
      boxes[boxIdx].delete(s);
    }

    return false;
  }

  backtrack(0);
}

N 皇后问题的列、对角线剪枝：

function solveNQueens(n: number): string[][] {
  const results: string[][] = [];
  const queens: number[] = [];
  const cols = new Set<number>();
  const diag1 = new Set<number>();
  const diag2 = new Set<number>();

  function backtrack(row: number): void {
    if (row === n) {
      results.push(queens.map((col) => '.'.repeat(col) + 'Q' + '.'.repeat(n - col - 1)));
      return;
    }

    for (let col = 0; col < n; col++) {
      if (cols.has(col) || diag1.has(row - col) || diag2.has(row + col)) continue;

      queens.push(col);
      cols.add(col);
      diag1.add(row - col);
      diag2.add(row + col);

      backtrack(row + 1);

      queens.pop();
      cols.delete(col);
      diag1.delete(row - col);
      diag2.delete(row + col);
    }
  }

  backtrack(0);
  return results;
}

  • 模拟题的关键是准确理解题意并正确实现每一步，边界条件是最常出错的地方
  • 螺旋遍历用四条边界控制，矩阵旋转可以分解为转置 + 翻转的组合
  • 状态机将模拟过程抽象为有限状态和转移规则，让逻辑更清晰不易出错
  • 枚举的核心优化是剪枝——通过约束条件尽早排除不可能的分支
  • 数独和 N 皇后展示了枚举 + 回溯 + 约束剪枝的经典组合
  • 模拟和枚举虽然"朴素"，但在正确性优先的场景中往往是最可靠的选择
