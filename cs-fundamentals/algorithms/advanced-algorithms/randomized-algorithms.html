随机化算法

核心概念

随机化算法通过引入随机性来打破最坏情况的确定性，在期望意义上获得更好的性能。与确定性算法不同，随机化算法的行为不完全由输入决定，还受到随机数生成的影响。这类算法分为两大类：蒙特卡洛算法（可能给出错误答案，但概率可控）和拉斯维加斯算法（一定给出正确答案，但运行时间是随机的）。

随机快速选择
快速选择（QuickSelect）是随机化算法的经典代表。它在无序数组中以期望 O(n)O(n)O(n) 的时间找到第 kkk 小的元素，是拉斯维加斯算法的典型。


function quickSelect(nums: number[], k: number): number {
  function partition(left: number, right: number): number {
    const pivotIdx = left + Math.floor(Math.random() * (right - left + 1));
    const pivot = nums[pivotIdx];
    [nums[pivotIdx], nums[right]] = [nums[right], nums[pivotIdx]];

    let storeIdx = left;
    for (let i = left; i < right; i++) {
      if (nums[i] < pivot) {
        [nums[i], nums[storeIdx]] = [nums[storeIdx], nums[i]];
        storeIdx++;
      }
    }

    [nums[storeIdx], nums[right]] = [nums[right], nums[storeIdx]];
    return storeIdx;
  }

  let left = 0;
  let right = nums.length - 1;
  const target = k - 1;

  while (left <= right) {
    const pivotIdx = partition(left, right);
    if (pivotIdx === target) return nums[pivotIdx];
    if (pivotIdx < target) left = pivotIdx + 1;
    else right = pivotIdx - 1;
  }

  return -1;
}
随机选择 pivot 是关键：如果每次都选到最小或最大的元素，退化为 O(n2)O(n^2)O(n2)。随机选择使得期望复杂度为 O(n)O(n)O(n)，因为每次期望将问题规模减半。


水塘抽样
水塘抽样（Reservoir Sampling）解决的是：从一个未知长度的数据流中等概率地抽取 kkk 个样本，且只遍历数据一次。


单样本水塘抽样——从数据流中等概率选一个：


function reservoirSampleOne(stream: Iterable<number>): number {
  let result = 0;
  let count = 0;

  for (const item of stream) {
    count++;
    if (Math.random() < 1 / count) {
      result = item;
    }
  }

  return result;
}
正确性证明：第 iii 个元素被选中的概率为 1i×ii+1×⋯×n−1n=1n\frac{1}{i} \times \frac{i}{i+1} \times \cdots \times \frac{n-1}{n} = \frac{1}{n}i1​×i+1i​×⋯×nn−1​=n1​。


kkk 样本水塘抽样：


function reservoirSampleK(stream: Iterable<number>, k: number): number[] {
  const reservoir: number[] = [];
  let count = 0;

  for (const item of stream) {
    count++;
    if (count <= k) {
      reservoir.push(item);
    } else {
      const j = Math.floor(Math.random() * count);
      if (j < k) {
        reservoir[j] = item;
      }
    }
  }

  return reservoir;
}

Fisher-Yates 洗牌算法
Fisher-Yates 洗牌（也叫 Knuth Shuffle）是唯一正确的 O(n)O(n)O(n) 随机洗牌算法，保证每种排列出现的概率完全相等。


function fisherYatesShuffle<T>(arr: T[]): T[] {
  const result = [...arr];

  for (let i = result.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [result[i], result[j]] = [result[j], result[i]];
  }

  return result;
}
为什么 Fisher-Yates 是正确的？第一步有 nnn 种选择，第二步有 n−1n-1n−1 种选择，...，总共 n!n!n! 种等概率的结果，恰好对应所有排列。


常见错误的洗牌实现（非均匀分布）：


function wrongShuffle<T>(arr: T[]): T[] {
  const result = [...arr];
  for (let i = 0; i < result.length; i++) {
    const j = Math.floor(Math.random() * result.length);
    [result[i], result[j]] = [result[j], result[i]];
  }
  return result;
}
上面的实现每步都从整个数组随机选，产生 nnn^nnn 种等概率结果，但 nnn^nnn 通常不能被 n!n!n! 整除，所以各排列的概率不均等。


蒙特卡洛方法
蒙特卡洛方法通过大量随机采样来近似计算。经典应用：用随机投点法估算 π\piπ 的值。


function estimatePi(samples: number): number {
  let insideCircle = 0;

  for (let i = 0; i < samples; i++) {
    const x = Math.random();
    const y = Math.random();
    if (x * x + y * y <= 1) {
      insideCircle++;
    }
  }

  return (4 * insideCircle) / samples;
}
在单位正方形内随机投点，落在四分之一圆内的概率为 π4\frac{\pi}{4}4π​，因此 π≈4×圆内点数总点数\pi \approx 4 \times \frac{\text{圆内点数}}{\text{总点数}}π≈4×总点数圆内点数​。


随机化素数检测（Miller-Rabin）是蒙特卡洛算法的重要应用：


function millerRabin(n: number, iterations: number = 20): boolean {
  if (n < 2) return false;
  if (n < 4) return true;
  if (n % 2 === 0) return false;

  let d = n - 1;
  let r = 0;
  while (d % 2 === 0) {
    d /= 2;
    r++;
  }

  for (let i = 0; i < iterations; i++) {
    const a = 2 + Math.floor(Math.random() * (n - 3));
    let x = Number(modPowBig(BigInt(a), BigInt(d), BigInt(n)));

    if (x === 1 || x === n - 1) continue;

    let continueOuter = false;
    for (let j = 0; j < r - 1; j++) {
      x = Number((BigInt(x) * BigInt(x)) % BigInt(n));
      if (x === n - 1) {
        continueOuter = true;
        break;
      }
    }

    if (!continueOuter) return false;
  }

  return true;
}

function modPowBig(base: bigint, exp: bigint, mod: bigint): bigint {
  let result = 1n;
  base %= mod;
  while (exp > 0n) {
    if (exp % 2n === 1n) result = (result * base) % mod;
    exp /= 2n;
    base = (base * base) % mod;
  }
  return result;
}

小结
    

  • 随机化算法分为蒙特卡洛（概率正确）和拉斯维加斯（一定正确），应对不同场景
    • 

  • 随机快速选择以期望 O(n)O(n)O(n) 找到第 kkk 小元素，随机 pivot 避免最坏情况
    • 

  • 水塘抽样在单遍遍历中等概率采样，适合数据流和内存受限的场景
    • 

  • Fisher-Yates 是唯一正确的 O(n)O(n)O(n) 洗牌算法，每步从"未选"部分随机取
    • 

  • 蒙特卡洛方法通过大量采样近似计算，增加采样数可以提高精度
    • 

  • 随机化的核心价值：用概率换取简洁性和期望性能，打破确定性最坏情况
