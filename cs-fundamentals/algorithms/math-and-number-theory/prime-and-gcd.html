质数与最大公约数

核心概念

质数和最大公约数（GCD）是数论中最基本的两个概念。质数是大于 1 且只能被 1 和自身整除的自然数，它是整数的"原子"——根据算术基本定理，任何大于 1 的整数都可以唯一地分解为质数的乘积。最大公约数则衡量两个整数的最大公因子，欧几里得算法是计算它的经典方法，已有超过两千年的历史。

质数判定与筛法
判定一个数是否为质数，最直接的方法是试除法：如果 nnn 有一个大于 n\sqrt{n}n​ 的因子 ddd，那么 n/dn/dn/d 一定小于 n\sqrt{n}n​，所以只需检查到 n\sqrt{n}n​ 即可。


function isPrime(n: number): boolean {
  if (n < 2) return false;
  if (n < 4) return true;
  if (n % 2 === 0 || n % 3 === 0) return false;

  for (let i = 5; i * i <= n; i += 6) {
    if (n % i === 0 || n % (i + 2) === 0) return false;
  }

  return true;
}
优化：所有大于 3 的质数都可以表示为 6k±16k \pm 16k±1 的形式，因此从 5 开始每次跳 6 步，只检查 iii 和 i+2i+2i+2。


当需要批量获取质数时，埃拉托斯特尼筛法（Sieve of Eratosthenes）是最高效的方法：


function sieveOfEratosthenes(n: number): boolean[] {
  const isPrime = new Array(n + 1).fill(true);
  isPrime[0] = isPrime[1] = false;

  for (let i = 2; i * i <= n; i++) {
    if (isPrime[i]) {
      for (let j = i * i; j <= n; j += i) {
        isPrime[j] = false;
      }
    }
  }

  return isPrime;
}

function getPrimes(n: number): number[] {
  const sieve = sieveOfEratosthenes(n);
  const primes: number[] = [];
  for (let i = 2; i <= n; i++) {
    if (sieve[i]) primes.push(i);
  }
  return primes;
}
为什么从 i2i^2i2 开始标记？因为 i×ki \times ki×k（k<ik < ik<i）在之前处理 kkk 时已经被标记过了。


线性筛（欧拉筛）可以达到严格 O(n)O(n)O(n) 的复杂度，确保每个合数只被其最小质因子筛掉一次：


function linearSieve(n: number): number[] {
  const primes: number[] = [];
  const isComposite = new Array(n + 1).fill(false);

  for (let i = 2; i <= n; i++) {
    if (!isComposite[i]) primes.push(i);

    for (const p of primes) {
      if (i * p > n) break;
      isComposite[i * p] = true;
      if (i % p === 0) break;
    }
  }

  return primes;
}

欧几里得算法与扩展
欧几里得算法（辗转相除法）基于一个简单而深刻的性质：gcd⁡(a,b)=gcd⁡(b,a mod b)\gcd(a, b) = \gcd(b, a \bmod b)gcd(a,b)=gcd(b,amodb)。


function gcd(a: number, b: number): number {
  while (b !== 0) {
    [a, b] = [b, a % b];
  }
  return a;
}

function lcm(a: number, b: number): number {
  return (a / gcd(a, b)) * b;
}
注意 lcm 的计算：先除再乘，避免中间结果溢出。


扩展欧几里得算法 不仅求出 gcd⁡(a,b)\gcd(a, b)gcd(a,b)，还找到满足 ax+by=gcd⁡(a,b)ax + by = \gcd(a, b)ax+by=gcd(a,b) 的整数解 (x,y)(x, y)(x,y)。这在求模逆元中至关重要。


function extGcd(a: number, b: number): [number, number, number] {
  if (b === 0) return [a, 1, 0];

  const [g, x1, y1] = extGcd(b, a % b);
  return [g, y1, x1 - Math.floor(a / b) * y1];
}
裴蜀定理（Bézout's Identity）：方程 ax+by=cax + by = cax+by=c 有整数解的充要条件是 gcd⁡(a,b)∣c\gcd(a, b) \mid cgcd(a,b)∣c。


质因数分解
算术基本定理保证每个大于 1 的整数都有唯一的质因数分解。试除法是最直接的分解方法：


function primeFactors(n: number): Map<number, number> {
  const factors = new Map<number, number>();

  for (let i = 2; i * i <= n; i++) {
    while (n % i === 0) {
      factors.set(i, (factors.get(i) ?? 0) + 1);
      n /= i;
    }
  }

  if (n > 1) {
    factors.set(n, 1);
  }

  return factors;
}
质因数分解的应用——计算约数个数：


如果 n=p1a1×p2a2×⋯×pkakn = p_1^{a_1} \times p_2^{a_2} \times \cdots \times p_k^{a_k}n=p1a1​​×p2a2​​×⋯×pkak​​，则 nnn 的约数个数为 (a1+1)(a2+1)⋯(ak+1)(a_1+1)(a_2+1)\cdots(a_k+1)(a1​+1)(a2​+1)⋯(ak​+1)。


function countDivisors(n: number): number {
  const factors = primeFactors(n);
  let count = 1;
  for (const exp of factors.values()) {
    count *= exp + 1;
  }
  return count;
}
求所有约数：


function getDivisors(n: number): number[] {
  const divisors: number[] = [];
  for (let i = 1; i * i <= n; i++) {
    if (n % i === 0) {
      divisors.push(i);
      if (i !== n / i) divisors.push(n / i);
    }
  }
  return divisors.sort((a, b) => a - b);
}
经典应用问题
统计阶乘中质因子 ppp 的个数（Legendre 公式）：


n! 中 p 的幂次=∑i=1∞⌊n/pi⌋n! \text{ 中 } p \text{ 的幂次} = \sum_{i=1}^{\infty} \lfloor n/p^i \rfloorn! 中 p 的幂次=i=1∑∞​⌊n/pi⌋
function factorialPrimePower(n: number, p: number): number {
  let count = 0;
  let power = p;
  while (power <= n) {
    count += Math.floor(n / power);
    power *= p;
  }
  return count;
}
GCD 在数组中的应用——求数组所有元素的 GCD：


function arrayGcd(nums: number[]): number {
  return nums.reduce((acc, num) => gcd(acc, num));
}
判断互质：两个数的 GCD 为 1 时互质。互质是模逆元存在的前提条件。
