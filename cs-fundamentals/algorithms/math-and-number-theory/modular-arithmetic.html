模运算

核心概念

模运算（取余运算）是处理大数计算的核心工具。在算法竞赛和密码学中，当计算结果可能极其庞大时，通常要求对一个质数（如 109+710^9 + 7109+7）取模。模运算不仅能防止整数溢出，还保持了加法、减法和乘法的运算结构，使得我们可以在取模的同时进行正确的计算。

快速幂算法
快速幂（Binary Exponentiation）利用指数的二进制分解，将 an mod ma^n \bmod manmodm 的计算从 O(n)O(n)O(n) 次乘法优化到 O(log⁡n)O(\log n)O(logn) 次。


核心思想：a13=a11012=a8×a4×a1a^{13} = a^{1101_2} = a^8 \times a^4 \times a^1a13=a11012​=a8×a4×a1。从低位到高位扫描指数的每一位，遇到 1 就累乘当前的底数。


function modPow(base: number, exp: number, mod: number): number {
  let result = 1;
  base %= mod;

  while (exp > 0) {
    if (exp % 2 === 1) {
      result = (result * base) % mod;
    }
    exp = Math.floor(exp / 2);
    base = (base * base) % mod;
  }

  return result;
}
快速幂也可以用于矩阵乘法，这是加速线性递推的关键（后续"数学问题"一节详述）。


BigInt 版本（处理大数场景）：


function modPowBig(base: bigint, exp: bigint, mod: bigint): bigint {
  let result = 1n;
  base %= mod;

  while (exp > 0n) {
    if (exp % 2n === 1n) {
      result = (result * base) % mod;
    }
    exp /= 2n;
    base = (base * base) % mod;
  }

  return result;
}
模逆元
模逆元是模运算中实现"除法"的关键。aaa 在模 mmm 下的逆元 a−1a^{-1}a−1 满足 a×a−1≡1(modm)a \times a^{-1} \equiv 1 \pmod{m}a×a−1≡1(modm)。逆元存在的充要条件是 gcd⁡(a,m)=1\gcd(a, m) = 1gcd(a,m)=1。


当 mmm 是质数时，根据费马小定理 am−1≡1(modm)a^{m-1} \equiv 1 \pmod{m}am−1≡1(modm)，所以 a−1≡am−2(modm)a^{-1} \equiv a^{m-2} \pmod{m}a−1≡am−2(modm)：


function modInverse(a: number, mod: number): number {
  return modPow(a, mod - 2, mod);
}

function modDivide(a: number, b: number, mod: number): number {
  return ((a % mod) * modInverse(b, mod)) % mod;
}
当 mmm 不是质数时，用扩展欧几里得算法求逆元：


function modInverseExtGcd(a: number, m: number): number {
  function extGcd(a: number, b: number): [number, number, number] {
    if (b === 0) return [a, 1, 0];
    const [g, x1, y1] = extGcd(b, a % b);
    return [g, y1, x1 - Math.floor(a / b) * y1];
  }

  const [g, x] = extGcd(a % m, m);
  if (g !== 1) return -1;
  return ((x % m) + m) % m;
}
预处理阶乘逆元（用于组合数计算）：


function precomputeFactorials(n: number, mod: number): [number[], number[]] {
  const fact = new Array(n + 1);
  const invFact = new Array(n + 1);

  fact[0] = 1;
  for (let i = 1; i <= n; i++) {
    fact[i] = (fact[i - 1] * i) % mod;
  }

  invFact[n] = modPow(fact[n], mod - 2, mod);
  for (let i = n - 1; i >= 0; i--) {
    invFact[i] = (invFact[i + 1] * (i + 1)) % mod;
  }

  return [fact, invFact];
}

中国剩余定理
中国剩余定理（CRT）解决的是联立同余方程组的问题：给定一组两两互质的模数 m1,m2,…,mkm_1, m_2, \ldots, m_km1​,m2​,…,mk​ 和余数 a1,a2,…,aka_1, a_2, \ldots, a_ka1​,a2​,…,ak​，求满足所有条件的最小非负整数 xxx。

⋮\vdots⋮
 


x≡ak(modmk)x \equiv a_k \pmod{m_k}x≡ak​(modmk​)
function chineseRemainderTheorem(remainders: number[], moduli: number[]): number {
  const n = remainders.length;
  const M = moduli.reduce((a, b) => a * b, 1);

  let result = 0;
  for (let i = 0; i < n; i++) {
    const Mi = M / moduli[i];
    const yi = modInverseExtGcd(Mi, moduli[i]);
    result += remainders[i] * Mi * yi;
  }

  return ((result % M) + M) % M;
}
CRT 的应用场景：当需要对多个不同模数分别计算，再合并结果时。例如 NTT（数论变换）中使用多个质数模数分别计算，再用 CRT 合并。


常见模运算陷阱与技巧
在实际编码中，模运算容易踩坑。以下是最常见的注意事项：


减法取模可能得到负数：


function modSub(a: number, b: number, mod: number): number {
  return ((a % mod) - (b % mod) + mod) % mod;
}
JavaScript 中大数乘法溢出：当两个大数相乘时，中间结果可能超过 2532^{53}253（Number 安全范围），需要使用 BigInt 或分步乘法。


function mulMod(a: number, b: number, mod: number): number {
  return Number((BigInt(a) * BigInt(b)) % BigInt(mod));
}

  • 模运算保持加、减、乘的结构，但除法需要通过模逆元实现
    • 

  • 快速幂利用二进制分解将 O(n)O(n)O(n) 次乘法优化到 O(log⁡n)O(\log n)O(logn)，是竞赛编程必备工具
    •

    •
