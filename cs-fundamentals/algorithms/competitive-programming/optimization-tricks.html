优化技巧

核心概念

在算法竞赛和工程实践中，选择正确的算法只是第一步。当正确的算法因为常数因子太大而超时，或因为内存占用过高而超限时，优化技巧就成为了决定性因素。优化主要分为三个方向：常数优化（减少每步操作的开销）、剪枝优化（减少搜索空间）和内存优化（降低空间占用）。这些技巧不改变算法的渐近复杂度，但能在实际运行中带来数倍甚至数十倍的性能提升。

常数优化
常数优化不改变算法复杂度，但通过减少每步操作的实际开销来加速。在竞赛中，一个 O(nlog⁡n)O(n \log n)O(nlogn) 的算法经过常数优化后可能比未优化的 O(n)O(n)O(n) 算法还快。


位运算替代算术运算：


const isEven = (n: number) => (n & 1) === 0;
const divideBy2 = (n: number) => n >> 1;
const multiplyBy2 = (n: number) => n << 1;
const modPowerOf2 = (n: number, k: number) => n & ((1 << k) - 1);
避免不必要的对象创建——在热循环中，对象分配和垃圾回收的开销很大：


function optimizedBFS(graph: number[][], start: number): number[] {
  const dist = new Array(graph.length).fill(-1);
  const queue = new Int32Array(graph.length);
  let head = 0;
  let tail = 0;

  dist[start] = 0;
  queue[tail++] = start;

  while (head < tail) {
    const node = queue[head++];
    for (const next of graph[node]) {
      if (dist[next] === -1) {
        dist[next] = dist[node] + 1;
        queue[tail++] = next;
      }
    }
  }

  return dist;
}
使用 TypedArray（Int32Array、Float64Array）替代普通数组，在大量数值运算中效果显著：


function sumWithTypedArray(n: number): number {
  const arr = new Int32Array(n);
  for (let i = 0; i < n; i++) arr[i] = i;

  let sum = 0;
  for (let i = 0; i < n; i++) sum += arr[i];
  return sum;
}

剪枝优化
剪枝是搜索算法中最重要的优化手段，通过提前排除不可能的分支来大幅减少搜索量。


可行性剪枝——当前路径不可能到达合法解时提前终止：


function combinationSum(candidates: number[], target: number): number[][] {
  candidates.sort((a, b) => a - b);
  const results: number[][] = [];

  function backtrack(start: number, remaining: number, path: number[]): void {
    if (remaining === 0) {
      results.push([...path]);
      return;
    }

    for (let i = start; i < candidates.length; i++) {
      if (candidates[i] > remaining) break;

      if (i > start && candidates[i] === candidates[i - 1]) continue;

      path.push(candidates[i]);
      backtrack(i + 1, remaining - candidates[i], path);
      path.pop();
    }
  }

  backtrack(0, target, []);
  return results;
}
上面的代码包含两种剪枝：排序后 candidates[i] > remaining 直接 break（可行性剪枝），以及跳过相同元素（去重剪枝）。


最优性剪枝——当前路径不可能比已知最优解更好时终止：


function tspWithPruning(dist: number[][], n: number): number {
  let bestDist = Infinity;
  const visited = new Array(n).fill(false);
  visited[0] = true;

  function backtrack(current: number, count: number, totalDist: number): void {
    if (totalDist >= bestDist) return;

    if (count === n) {
      bestDist = Math.min(bestDist, totalDist + dist[current][0]);
      return;
    }

    for (let next = 0; next < n; next++) {
      if (visited[next]) continue;

      visited[next] = true;
      backtrack(next, count + 1, totalDist + dist[current][next]);
      visited[next] = false;
    }
  }

  backtrack(0, 1, 0);
  return bestDist;
}
内存优化
内存优化在大规模数据问题中至关重要。最常用的技术是滚动数组和原地算法。


滚动数组优化 DP——很多 DP 的状态转移只依赖上一行，可以用两行替代整个二维数组：


function longestCommonSubsequence(text1: string, text2: string): number {
  const m = text1.length;
  const n = text2.length;
  let prev = new Array(n + 1).fill(0);
  let curr = new Array(n + 1).fill(0);

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (text1[i - 1] === text2[j - 1]) {
        curr[j] = prev[j - 1] + 1;
      } else {
        curr[j] = Math.max(prev[j], curr[j - 1]);
      }
    }
    [prev, curr] = [curr, prev];
    curr.fill(0);
  }

  return prev[n];
}
进一步压缩到一维数组：


function knapsack01(weights: number[], values: number[], capacity: number): number {
  const dp = new Array(capacity + 1).fill(0);

  for (let i = 0; i < weights.length; i++) {
    for (let w = capacity; w >= weights[i]; w--) {
      dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
    }
  }

  return dp[capacity];
}
注意 0/1 背包压缩到一维时必须从右向左遍历，否则同一物品会被重复使用（变成完全背包）。

输入输出优化

小结
    

  • 常数优化通过位运算、TypedArray 和减少对象创建来降低每步开销，效果 2-5 倍
    • 

  • 剪枝是搜索算法的核心优化，可行性剪枝和最优性剪枝可带来数量级的加速
    • 

  • 滚动数组将二维 DP 的空间从 O(mn)O(mn)O(mn) 降到 O(n)O(n)O(n)，关键是遍历方向正确
    • 

  • 0/1 背包压缩到一维时必须从右向左遍历，完全背包则从左向右
    • 

  • IO 优化在数据量大时效果显著，核心是减少系统调用次数
    • 

  • 优化的前提是算法正确——永远先保证正确性，再考虑性能
