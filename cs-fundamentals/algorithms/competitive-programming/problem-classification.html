题目分类体系

核心概念

题目分类体系是将算法问题按照数据结构、算法范式和问题模式进行系统化归类的方法论。建立清晰的分类能力意味着：当你看到一道新题时，能够快速将其归入已知类别，调用对应的解题模板和思维框架。这种"模式匹配"能力是竞赛高手和面试达人的核心素质，也是系统化提升算法水平最高效的途径。

按问题模式分类
同一种算法可以解决不同模式的问题，同一种模式也可以用不同算法解决。识别问题模式帮助你缩小解法范围。


const problemPatterns = [
  {
    pattern: '求最值（最大/最小）',
    subTypes: ['最长/最短子序列', '最大/最小和', '最少操作次数'],
    algorithms: ['DP', '贪心', '二分答案'],
  },
  {
    pattern: '计数（有多少种方案）',
    subTypes: ['路径计数', '组合计数', '排列计数'],
    algorithms: ['DP', '组合数学', '回溯'],
  },
  {
    pattern: '判定（是否存在/是否可能）',
    subTypes: ['路径存在性', '子集和', '图的连通性'],
    algorithms: ['DFS/BFS', 'DP', '并查集'],
  },
  {
    pattern: '构造（输出一种合法方案）',
    subTypes: ['构造序列', '构造图', '拓扑排序'],

  {

  },

"二分答案"是一种重要的问题模式——当答案具有单调性时，可以二分答案值并验证可行性：


function binarySearchAnswer(check: (mid: number) => boolean, low: number, high: number): number {
  while (low < high) {
    const mid = low + ((high - low) >> 1);
    if (check(mid)) {
      high = mid;
    } else {
      low = mid + 1;
    }
  }
  return low;
}

小结
    

  • 题目分类的三个维度：数据结构、算法范式和问题模式，从这三个角度交叉定位
    • 

  • 输入规模直接限定算法复杂度，是判断解法方向的第一线索
    • 

  • 贪心和 DP 的判断：先尝试贪心找反例，找不到就贪心，找到就转 DP
    • 

  • "二分答案"是一种常被忽视但非常强大的模式——答案有单调性时立即想到
    • 

  • 系统化刷题按主题推进，每个主题 15-30 题深度练习，优于无序刷 200 题
    • 

  • 分类能力需要大量练习才能建立——坚持在每道题完成后回顾其所属分类
    •
