文件系统结构与实现

文件系统概述

文件系统（File System）定义了数据在存储设备上的组织方式。它将连续的磁盘块抽象为文件和目录的逻辑结构，并管理空间分配、元数据维护和访问控制。



VFS（虚拟文件系统）
Linux 通过 VFS 层为所有文件系统提供统一接口。应用程序使用相同的系统调用（open/read/write）访问不同文件系统。

XFS 文件系统
XFS 由 SGI 开发，专为大文件和高并发 I/O 设计。






特性
说明





分配组（AG）
将卷划分为独立的分配组，支持并行分配




B+ 树索引
inode、空闲空间和 Extent 均使用 B+ 树




延迟分配
与 ext4 类似，写入时延迟分配




在线扩展
支持在线扩大卷（不支持缩小）




日志
仅记录元数据日志

XFS 在大文件顺序读写和高并发场景下性能优于 ext4。




Btrfs 文件系统
Btrfs（B-tree FS）是新一代写时复制（CoW）文件系统，目标是替代 ext4。

快照

子卷
在同一文件系统内创建逻辑分区




内置 RAID

小结
    

  • VFS 为所有文件系统提供统一的系统调用接口
    • 

  • ext4 是 Linux 最广泛使用的文件系统，通过 Extent 树和延迟分配优化性能
    • 

  • XFS 以分配组和 B+ 树索引实现高并发和大文件优化
    • 

  • Btrfs 引入写时复制、快照、校验和等现代特性，适合需要数据完整性的场景
    • 

  • 文件系统选择需要根据工作负载特征权衡稳定性、性能和功能
