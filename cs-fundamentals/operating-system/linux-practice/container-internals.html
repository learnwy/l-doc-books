容器技术原理

从虚拟机到容器

容器是一种轻量级的虚拟化技术。与虚拟机不同，容器共享宿主机内核，不需要运行完整的客户操作系统。

PID Namespace
容器内的进程看到的 PID 从 1 开始，但在宿主机上它只是一个普通进程。


使用 unshare 创建 Namespace
# 创建新的 PID 和 Mount Namespace
unshare --pid --mount --fork /bin/bash

# 在新的 Network Namespace 中运行
unshare --net ip addr

# 查看进程的 Namespace
ls -la /proc/$$/ns/


Cgroup（控制组）
Cgroup 限制、统计和隔离一组进程的资源使用。

Cgroup 使用示例
# 创建 cgroup（v2）
mkdir /sys/fs/cgroup/mygroup

# 限制内存为 256MB
echo "268435456" > /sys/fs/cgroup/mygroup/memory.max

# 限制 CPU 为 50%（每 100ms 中使用 50ms）
echo "50000 100000" > /sys/fs/cgroup/mygroup/cpu.max

# 将进程加入 cgroup
echo $PID > /sys/fs/cgroup/mygroup/cgroup.procs

# 查看当前内存使用
cat /sys/fs/cgroup/mygroup/memory.current

小结
    

  • 容器通过 Namespace 实现资源视图隔离，通过 Cgroup 实现资源用量限制
    • 

  • PID/Mount/Network 是最重要的三个 Namespace
    • 

  • Cgroup v2 提供统一的资源控制层级，是现代发行版的默认方案
    • 

  • OverlayFS 实现镜像分层存储，多个只读层 + 一个可写层
    • 

  • runc 是符合 OCI 标准的低级容器运行时，负责调用内核 API 创建容器
    • 

  • 容器本质上是受 Namespace 隔离和 Cgroup 限制的 Linux 进程
    •
