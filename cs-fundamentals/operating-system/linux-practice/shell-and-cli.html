Shell 与命令行工具

Shell 概述

Shell 是用户与操作系统内核之间的命令行接口。用户输入命令，Shell 解析并调用相应的程序执行。

Shell 说明
bash 最广泛使用的 Shell（GNU Bourne Again Shell）
zsh 功能丰富（Oh My Zsh 生态）
fish 用户友好（自动建议、语法高亮）
sh POSIX 标准 Shell
dash 轻量级 sh 实现（Debian/Ubuntu 默认 /bin/sh） 
# 查看当前使用的 Shell
echo $SHELL

# 查看系统可用的 Shell
cat /etc/shells

文件和目录操作

命令 功能 常用选项
ls 列出目录内容 -la（详细+隐藏）, -lh（人类可读大小）
cd 切换目录 -, ~, ..
cp 复制 -r（递归）, -p（保留属性）
mv 移动/重命名 —
rm 删除 -rf（递归强制）
mkdir 创建目录 -p（递归创建）
find 查找文件 -name, -type, -mtime, -exec
chmod 修改权限 755, u+x
chown 修改所有者 user:group

find 高级用法

# 查找 7 天内修改的 .log 文件
find /var/log -name "*.log" -mtime -7

# 查找大于 100MB 的文件
find / -size +100M -type f

# 查找并删除空目录
find . -type d -empty -delete

文本处理三剑客

grep — 文本搜索

# 递归搜索关键词
grep -rn "error" /var/log/

# 正则匹配
grep -E "^[0-9]{4}-" access.log

# 反向匹配
grep -v "DEBUG" app.log
选项 说明
-r 递归搜索
-n 显示行号
-i 忽略大小写
-v 反向匹配
-E 扩展正则
-c 统计匹配行数

sed — 流编辑器

# 替换文本
sed 's/old/new/g' file.txt

# 原地替换
sed -i 's/old/new/g' file.txt

# 删除包含 pattern 的行
sed '/pattern/d' file.txt

# 打印第 10~20 行
sed -n '10,20p' file.txt

awk — 文本分析

# 打印第 2 列
awk '{print $2}' file.txt

# 按分隔符切分
awk -F: '{print $1, $3}' /etc/passwd

# 条件过滤
awk '$3 > 1000 {print $1}' /etc/passwd

# 统计求和
awk '{sum += $1} END {print sum}' numbers.txt

管道与重定向

管道（Pipe）

管道将前一个命令的标准输出连接到下一个命令的标准输入。

# 统计连接数最多的 IP
netstat -an | grep ESTABLISHED | awk '{print $5}' | cut -d: -f1 | sort | uniq -c | sort -rn | head -10

重定向

符号 含义
> 标准输出覆盖写入文件
>> 标准输出追加写入文件
2> 标准错误覆盖写入文件
2>&1 标准错误重定向到标准输出
< 从文件读取标准输入
| 管道，连接两个命令 
# 同时保存标准输出和标准错误
command > output.log 2>&1

# 丢弃所有输出
command > /dev/null 2>&1

进程管理

命令 功能
ps aux 查看所有进程
top / htop 实时进程监控
kill PID 发送信号（默认 SIGTERM）
kill -9 PID 强制终止（SIGKILL）
nohup 忽略挂断信号运行
& 后台运行
jobs / fg / bg 作业控制

网络工具

命令 功能
curl HTTP 请求
wget 文件下载
ss Socket 统计（替代 netstat）
ip 网络配置（替代 ifconfig）
dig / nslookup DNS 查询
ping 网络连通性测试
traceroute 路由追踪
tcpdump 网络抓包 
# 查看监听端口
ss -tlnp

# 抓取 HTTP 流量
tcpdump -i eth0 port 80 -w capture.pcap

Shell 脚本基础

#!/bin/bash

# 变量
NAME="Linux"
echo "Hello, $NAME"

# 条件判断
if [ -f "/etc/passwd" ]; then
    echo "File exists"
fi

# 循环
for i in {1..5}; do
    echo "Iteration $i"
done

# 函数
greet() {
    echo "Hello, $1"
}
greet "World"

小结

  • Shell 是用户与内核之间的命令行接口，bash 是最广泛使用的实现
  • grep/sed/awk 是 Linux 文本处理三剑客，组合使用可以解决大多数文本分析需求
  • 管道和重定向是 Shell 的核心组合机制，让简单命令串联完成复杂任务
  • ss/ip/tcpdump 等网络工具是网络诊断的基本手段
  • 掌握 Shell 脚本编写能力是 Linux 系统管理和自动化的基础
