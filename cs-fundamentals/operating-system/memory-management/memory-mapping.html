内存映射与共享内存

什么是内存映射

内存映射（Memory Mapping）是将文件或设备的内容直接映射到进程虚拟地址空间的机制。映射建立后，进程可以像访问内存一样读写文件，由操作系统负责在内存和磁盘之间同步数据。



mmap 系统调用
void *mmap(void *addr, size_t length, int prot, int flags, int fd, off_t offset);
int munmap(void *addr, size_t length);

mmap 的工作流程
mmap 调用本身不读取文件内容，只是建立虚拟地址到文件的映射关系。实际的数据读取发生在首次访问时（按需分页）。

共享内存的实现
POSIX 共享内存
POSIX 共享内存基于 mmap + tmpfs 实现：


// 进程 A：创建并写入
int fd = shm_open("/my_shm", O_CREAT | O_RDWR, 0666);
ftruncate(fd, 4096);
void *ptr = mmap(NULL, 4096, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
sprintf(ptr, "Hello from A");

// 进程 B：打开并读取
int fd = shm_open("/my_shm", O_RDONLY, 0);
void *ptr = mmap(NULL, 4096, PROT_READ, MAP_SHARED, fd, 0);
printf("%s\n", (char *)ptr);  // Hello from A

注意事项




问题
说明





映射大小
必须页对齐，超出文件大小的部分填零




SIGBUS 信号
文件被截断后访问超出范围会触发




写回时机
MAP_SHARED 修改不会立即写盘，需 msync 强制同步




大页映射
MAP_HUGETLB 可减少 TLB Miss，但需要预留大页




地址空间碎片
大量小映射可能导致虚拟地址空间碎片化







小结
    

  • mmap 将文件或匿名内存直接映射到进程地址空间，避免额外的数据拷贝
    • 

  • 四种映射模式（文件/匿名 × 共享/私有）覆盖了不同的使用场景
    • 

  • mmap 建立映射时不读取数据，首次访问触发缺页中断按需加载
    • 

  • POSIX 共享内存基于 shm_open + mmap，是推荐的进程间共享内存方式
    • 

  • mmap 适合大文件随机访问和进程间通信，但需注意 SIGBUS 和写回时机
    •
