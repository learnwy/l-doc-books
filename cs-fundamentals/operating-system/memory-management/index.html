内存管理 简介

内存管理是操作系统的核心职责之一。它负责将有限的物理内存高效、安全地分配给多个并发进程，同时通过虚拟内存机制为每个进程提供独立且远大于物理内存的地址空间。

现代操作系统通过分页（Paging）机制将虚拟地址映射到物理地址，利用 TLB 加速地址转换，并在物理内存不足时通过页面置换算法将不活跃的页面换出到磁盘。内核本身也需要高效的内存分配器——伙伴系统管理大块物理页面，slab 分配器则为内核频繁创建的小对象提供快速分配。

mmap 内存映射机制打通了文件与内存的边界，既是实现共享库加载的基础，也是进程间共享内存的核心手段。理解 mmap 的四种映射模式（文件/匿名 × 共享/私有），有助于理解 Linux 进程地址空间的构成和动态链接的工作原理。

内存管理的核心挑战在于：如何在有限的物理资源上，同时满足多个进程对内存的需求，保证隔离性和安全性，并最大化内存利用率。虚拟内存、按需分页和写时复制等技术，正是操作系统在这些矛盾目标之间找到的精妙平衡。

一句话说明
