虚拟内存与分页

为什么需要虚拟内存

早期操作系统直接使用物理地址，程序之间容易互相覆盖内存，也无法运行超过物理内存大小的程序。虚拟内存通过在物理内存和进程之间增加一层地址映射，同时解决了隔离性和容量两个问题。

目标 实现方式
进程隔离 每个进程拥有独立的虚拟地址空间
地址空间扩展 虚拟空间可远大于物理内存
内存共享 不同虚拟地址可映射到同一物理页面
按需加载 页面在首次访问时才加载到物理内存

分页机制

分页（Paging）将虚拟地址空间和物理内存都划分为固定大小的块。虚拟内存中的块称为页（Page），物理内存中的块称为页帧（Frame）。

TLB（Translation Lookaside Buffer）
TLB 是页表的硬件缓存，存储最近使用的虚拟页号到物理页帧号的映射，避免每次内存访问都查页表。

缺页中断（Page Fault）
当 CPU 访问的虚拟页面不在物理内存中时，触发缺页中断。






类型
原因
处理方式





次要缺页（Minor）

直接建立映射




主要缺页（Major）

主要缺页的处理流程涉及磁盘 I/O，耗时通常在毫秒级，比内存访问慢 10 万倍以上。

小结
    

  • 虚拟内存通过地址映射实现进程隔离、地址空间扩展和按需加载
    • 

  • 分页将地址空间划分为固定大小的页，通过页表实现虚拟到物理的映射
    • 

  • 多级页表避免为未使用的地址范围分配页表，x86-64 使用四级页表
    • 

  • TLB 是页表的硬件缓存，TLB 未命中需要遍历多级页表
    • 

  • 缺页中断分为次要缺页和主要缺页，主要缺页涉及磁盘 I/O 开销极大
    •
