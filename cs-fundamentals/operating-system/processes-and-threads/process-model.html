进程概念与生命周期

什么是进程

进程（Process）是操作系统对"正在运行的程序"的抽象。一个程序存放在磁盘上只是静态的代码和数据，当它被加载到内存并开始执行时，就成为了一个进程。进程是操作系统进行资源分配和保护的基本单位。



进程控制块（PCB）
PCB（Process Control Block）是操作系统管理进程的核心数据结构，每个进程对应一个 PCB。

写时复制（Copy-on-Write）
fork() 后父子进程共享同一份物理内存页面，仅在某一方写入时才复制该页面。这避免了 fork() 时复制整个地址空间的开销。


exec() 系统调用
exec() 将当前进程的地址空间替换为新程序的代码和数据。


fork() + exec() 的组合是 Unix/Linux 创建新进程的标准模式。

小结
    

  • 进程是操作系统资源分配和保护的基本单位，由代码、数据、堆、栈和 PCB 组成
    • 

  • PCB 是内核管理进程的核心数据结构，包含 PID、状态、寄存器和调度信息
    • 

  • 进程经历 New → Ready → Running → Blocked → Terminated 的生命周期
    • 

  • 上下文切换涉及寄存器保存、TLB 刷新和 Cache 污染，耗时 1~10 微秒
    • 

  • fork() 通过写时复制创建子进程，exec() 替换地址空间运行新程序
    • 

  • 僵尸进程和孤儿进程是进程管理中需要注意的特殊情况
    •
