设备驱动与中断

I/O 设备分类

操作系统将 I/O 设备分为两大类：

类型 特征 示例
块设备（Block Device） 以固定大小的块为单位传输，可随机访问 硬盘、SSD、USB 存储
字符设备（Character Device） 以字节流为单位传输，顺序访问 键盘、鼠标、串口、终端

此外还有网络设备，它不属于传统的块/字符分类，使用独立的 Socket 接口。

设备驱动程序
设备驱动是操作系统内核中与硬件直接交互的代码模块。它将硬件操作封装为标准接口，让上层不需要关心硬件细节。

中断机制
中断（Interrupt）是硬件通知 CPU 有事件需要处理的机制。当设备完成 I/O 操作或检测到事件时，通过中断信号通知 CPU。

上半部与下半部
为了减少中断处理时间，Linux 将中断处理分为两个部分：






部分
名称
特点
职责





上半部（Top Half）
硬中断处理
快速、不可中断
确认中断、读取关键数据、调度下半部




下半部（Bottom Half）
延迟处理
可延迟、可中断
执行实际的数据处理工作

小结
    

  • 设备分为块设备和字符设备，通过不同的驱动接口管理
    • 

  • 设备驱动通过 file_operations 结构体向内核注册操作函数
    • 

  • 中断是硬件通知 CPU 的异步机制，分为上半部（快速）和下半部（延迟处理）
    • 

  • DMA 让设备直接访问内存，释放 CPU 进行其他计算
    • 

  • I/O 调度器对块设备请求进行排序和合并，SSD 场景下通常使用 none 或 mq-deadline
    •
