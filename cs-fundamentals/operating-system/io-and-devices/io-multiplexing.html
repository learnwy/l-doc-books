IO 多路复用

什么是 I/O 多路复用

I/O 多路复用（I/O Multiplexing）允许单个线程同时监控多个文件描述符（fd），当其中任意一个 fd 准备好执行 I/O 时通知应用程序。这是构建高并发网络服务器的核心技术。



select
select 是最早的 I/O 多路复用接口，POSIX 标准。


int select(int nfds, fd_set *readfds, fd_set *writefds,
           fd_set *exceptfds, struct timeval *timeout);

poll
poll 移除了 fd 数量的硬限制，使用 pollfd 数组替代位图。


int poll(struct pollfd *fds, nfds_t nfds, int timeout);

struct pollfd {
    int   fd;
    short events;   // 关注的事件
    short revents;  // 返回的事件
};




特性
说明





fd 上限
无硬限制（受系统 ulimit 限制）




fd 传递
每次调用拷贝 pollfd 数组




就绪检测
内核线性遍历




事件分离
events 和 revents 分开，无需每次重设





poll 解决了 fd 数量限制问题，但 O(n) 遍历和内存拷贝开销仍然存在。

epoll 是 Linux 特有的高性能 I/O 多路复用机制，解决了 select/poll 的所有性能问题。

小结
    

  • select 受 1024 fd 限制和 O(n) 遍历开销，适合少量 fd 的跨平台场景
    • 

  • poll 去掉了 fd 数量限制但性能问题未解决
    • 

  • epoll 通过红黑树管理 fd 和回调机制通知就绪，是 Linux 高并发的标准选择
    • 

  • kqueue 是 BSD 系统的等价方案，功能更丰富
    • 

  • ET 边缘触发性能高于 LT 水平触发，但编程复杂度更高
    • 

  • Reactor 模式是 I/O 多路复用的标准设计模式
