任务调度算法

核心概念

嵌入式实时操作系统的核心职责是确保任务在截止时间之前完成执行。任务调度算法决定了在多个就绪任务竞争 CPU 时，系统如何选择下一个执行的任务。调度算法的选择直接影响系统的实时性保证、CPU 利用率和响应延迟。

速率单调调度 RM
速率单调调度（Rate Monotonic Scheduling）是最经典的静态优先级调度算法。其核心规则是：周期越短的任务优先级越高。RM 在所有固定优先级算法中是最优的——如果一个任务集在任何固定优先级算法下可调度，那么在 RM 下也一定可调度。


可调度性判定
RM 的充分条件（Liu & Layland 界）：


U = Σ(Ci/Ti) ≤ n × (2^(1/n) - 1)

其中：
  n = 任务数量
  Ci = 任务 i 的最坏执行时间（WCET）
  Ti = 任务 i 的周期
  U = CPU 利用率

n=1: U ≤ 1.000 (100%)
n=2: U ≤ 0.828 (82.8%)
n=3: U ≤ 0.780 (78.0%)
n→∞: U ≤ ln(2) ≈ 0.693 (69.3%)

xTaskCreate(task1_handler, "Task1", 256, NULL, 3, NULL);  // 周期 10ms → 最高优先级
xTaskCreate(task2_handler, "Task2", 256, NULL, 2, NULL);  // 周期 20ms → 中优先级

void task1_handler(void *params) {
    TickType_t xLastWakeTime = xTaskGetTickCount();
    for (;;) {
        // 执行传感器采样（WCET ≤ 2ms）
        read_sensor_data();
        vTaskDelayUntil(&xLastWakeTime, pdMS_TO_TICKS(10));
    }
}
EDF 最早截止时间优先
EDF（Earliest Deadline First）是最优的动态优先级调度算法。每个调度时刻，EDF 选择绝对截止时间最近的任务执行。在单处理器上，EDF 可以调度所有利用率不超过 100% 的任务集，这是任何算法能达到的理论上限。


EDF vs RM 对比
// EDF 伪代码实现
typedef struct {
    uint32_t deadline;    // 绝对截止时间
    uint32_t period;
    uint32_t wcet;
    void (*handler)(void);
} edf_task_t;

void edf_scheduler(edf_task_t *tasks, int n) {
    while (1) {
        edf_task_t *next = NULL;
        uint32_t earliest = UINT32_MAX;

        for (int i = 0; i < n; i++) {
            if (tasks[i].deadline < earliest && is_ready(&tasks[i])) {
                earliest = tasks[i].deadline;
                next = &tasks[i];
            }
        }

        if (next) {
            execute(next);
            next->deadline += next->period;
        } else {
            idle();
        }
    }
}

优先级反转与继承
优先级反转是实时系统中最危险的调度异常：低优先级任务持有高优先级任务所需的资源，而中优先级任务抢占低优先级任务执行，间接阻塞了高优先级任务。1997 年火星探路者号任务就因优先级反转导致系统反复重启。


解决方案
// FreeRTOS 优先级继承示例
SemaphoreHandle_t mutex = xSemaphoreCreateMutex();
// FreeRTOS 的 Mutex 默认启用优先级继承

// 高优先级任务
void high_priority_task(void *params) {
    for (;;) {
        xSemaphoreTake(mutex, portMAX_DELAY);
        // 访问共享资源
        access_shared_resource();
        xSemaphoreGive(mutex);
        vTaskDelay(pdMS_TO_TICKS(10));
    }
}

小结
    

  • RM 是固定优先级调度的最优算法，规则简单（周期越短优先级越高），工业界广泛采用
    • 

  • EDF 是动态优先级调度的最优算法，可实现 100% CPU 利用率，但过载行为不可预测
    • 

  • RM 的可调度性通过 Liu & Layland 界快速判定，精确判定需要响应时间分析
    • 

  • 优先级反转是实时系统的致命隐患，必须通过优先级继承或天花板协议解决
    • 

  • 工业实践中 RM 占主导地位，EDF 更多出现在学术研究和特定高利用率场景
    • 

  • 调度算法选择需要在可预测性、CPU 利用率和实现复杂度之间权衡
    •
