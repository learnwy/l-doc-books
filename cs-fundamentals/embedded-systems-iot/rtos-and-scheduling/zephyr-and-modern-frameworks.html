Zephyr RTOS 与现代嵌入式框架

核心概念

Zephyr 是 Linux 基金会托管的开源 RTOS，由 Intel 发起，目标是成为嵌入式领域的 Linux——提供统一的硬件抽象、完整的网络协议栈和现代化的开发工具链。Zephyr 支持 600+ 种开发板和 200+ 种处理器架构，采用 Device Tree 和 Kconfig 的配置体系（借鉴自 Linux 内核），在保持实时性的同时提供了远超 FreeRTOS 的功能完整度。

Device Tree 与 Kconfig
Zephyr 使用 Device Tree（.dts/.dtsi）描述硬件，Kconfig（.conf）选择软件功能：


// Device Tree 覆盖文件 (app.overlay)
/ {
    chosen {
        zephyr,console = &usart2;
    };
};

&usart2 {
    status = "okay";
    current-speed = <115200>;
};

&i2c1 {
    status = "okay";
    clock-frequency = <I2C_BITRATE_FAST>;

    bme280@76 {
        compatible = "bosch,bme280";
        reg = <0x76>;
    };
};

&spi1 {
    status = "okay";
    cs-gpios = <&gpioa 4 GPIO_ACTIVE_LOW>;

    spi_flash: w25q128@0 {
        compatible = "jedec,spi-nor";
        reg = <0>;
        spi-max-frequency = <80000000>;
        size = <0x8000000>;
    };
};

Zephyr 应用开发
#include <zephyr/kernel.h>
#include <zephyr/device.h>
#include <zephyr/drivers/sensor.h>
#include <zephyr/logging/log.h>

LOG_MODULE_REGISTER(main, LOG_LEVEL_INF);

K_MSGQ_DEFINE(sensor_msgq, sizeof(struct sensor_value) * 2, 10, 4);

void sensor_thread(void) {
    const struct device *bme = DEVICE_DT_GET_ANY(bosch_bme280);
    if (!device_is_ready(bme)) {
        LOG_ERR("BME280 not ready");
        return;
    }

    while (1) {
        struct sensor_value temp, hum;
        sensor_sample_fetch(bme);
        sensor_channel_get(bme, SENSOR_CHAN_AMBIENT_TEMP, &temp);
        sensor_channel_get(bme, SENSOR_CHAN_HUMIDITY, &hum);

        struct sensor_value data[2] = {temp, hum};
        k_msgq_put(&sensor_msgq, data, K_MSEC(100));

        LOG_INF("Temp: %d.%06d, Hum: %d.%06d",
                temp.val1, temp.val2, hum.val1, hum.val2);
        k_sleep(K_SECONDS(5));
    }
}

K_THREAD_DEFINE(sensor_tid, 1024, sensor_thread, NULL, NULL, NULL, 5, 0, 0);

Embassy：Rust 异步嵌入式框架
Embassy 是 Rust 嵌入式生态中的异步运行时框架，将 async/await 语法引入裸机编程，无需传统 RTOS 的上下文切换开销：


#![no_std]
#![no_main]

use embassy_executor::Spawner;
use embassy_stm32::gpio::{Level, Output, Speed};
use embassy_time::{Duration, Timer};
use defmt::info;

#[embassy_executor::main]
async fn main(spawner: Spawner) {
    let p = embassy_stm32::init(Default::default());
    spawner.spawn(blink(p.PA5.into())).unwrap();
    spawner.spawn(sensor_read()).unwrap();
}

#[embassy_executor::task]
async fn blink(mut led: Output<'static>) {
    loop {
        led.set_high();
        Timer::after(Duration::from_millis(500)).await;
        led.set_low();
        Timer::after(Duration::from_millis(500)).await;
    }
}

#[embassy_executor::task]
async fn sensor_read() {
    loop {
        let temp = read_temperature().await;
        info!("Temperature: {}", temp);
        Timer::after(Duration::from_secs(5)).await;
    }
}

小结
    

  • Zephyr 是 Linux 基金会的开源 RTOS，提供 Device Tree 硬件描述和完整的网络/安全子系统
    • 

  • Device Tree 描述硬件拓扑，Kconfig 选择软件功能——两者协同实现硬件无关的应用开发
    • 

  • Zephyr 适合需要完整网络协议栈和安全认证的中大型嵌入式项目
    • 

  • Embassy 将 Rust 的 async/await 引入嵌入式，协程模型无需线程上下文切换的内存开销
    • 

  • 选择 RTOS 时需权衡：FreeRTOS（最简、最广泛）、Zephyr（最完整）、Embassy（最安全、Rust 生态）
    • 

  • 现代嵌入式框架正在从"裸机 + 简单 RTOS"向"完整平台 + 安全 + 网络"演进
    •
