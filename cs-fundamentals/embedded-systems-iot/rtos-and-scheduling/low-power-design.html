低功耗设计

核心概念

低功耗设计是电池供电和能量收集（Energy Harvesting）设备的核心需求。嵌入式系统的功耗由动态功耗（开关活动）和静态功耗（漏电流）两部分组成。通过硬件选型、时钟管理、电源域控制和软件优化的协同，可以将系统平均功耗从毫安级降低到微安甚至纳安级，实现数年的电池续航。

MCU 低功耗模式
现代 MCU 提供多级低功耗模式，在唤醒速度和功耗之间做权衡：


// STM32L4 低功耗模式
void enterSleepMode(void) {
    HAL_SuspendTick();
    HAL_PWR_EnterSLEEPMode(PWR_MAINREGULATOR_ON, PWR_SLEEPENTRY_WFI);
    HAL_ResumeTick();
}

void enterStopMode(void) {
    HAL_SuspendTick();
    __HAL_RCC_PWR_CLK_ENABLE();
    HAL_PWREx_EnterSTOP2Mode(PWR_STOPENTRY_WFI);
    SystemClock_Config();
    HAL_ResumeTick();
}

void enterStandbyMode(void) {
    __HAL_RCC_PWR_CLK_ENABLE();
    HAL_PWR_EnableWakeUpPin(PWR_WAKEUP_PIN1);
    __HAL_PWR_CLEAR_FLAG(PWR_FLAG_WU);
    HAL_PWR_EnterSTANDBYMode();
}

时钟与外设管理
// 动态时钟调整：根据负载切换频率
void setHighPerformance(void) {
    RCC_ClkInitTypeDef clkInit = {0};
    clkInit.ClockType = RCC_CLOCKTYPE_SYSCLK;
    clkInit.SYSCLKSource = RCC_SYSCLKSOURCE_PLLCLK;
    HAL_RCC_ClockConfig(&clkInit, FLASH_LATENCY_4);
}

void setLowPower(void) {
    RCC_ClkInitTypeDef clkInit = {0};
    clkInit.ClockType = RCC_CLOCKTYPE_SYSCLK;
    clkInit.SYSCLKSource = RCC_SYSCLKSOURCE_MSI;
    HAL_RCC_ClockConfig(&clkInit, FLASH_LATENCY_0);
    HAL_RCCEx_MSIRangeConfig(RCC_MSIRANGE_4);
}

// 外设时钟门控：不用的外设关掉时钟
__HAL_RCC_USART2_CLK_DISABLE();
__HAL_RCC_SPI1_CLK_DISABLE();
__HAL_RCC_ADC_CLK_DISABLE();

// GPIO 未使用引脚配置为模拟输入（最低漏电流）
GPIO_InitStruct.Pin = GPIO_PIN_All;
GPIO_InitStruct.Mode = GPIO_MODE_ANALOG;
GPIO_InitStruct.Pull = GPIO_NOPULL;
HAL_GPIO_Init(GPIOB, &GPIO_InitStruct);
无线通信功耗优化
无线通信是 IoT 设备最大的功耗消耗者。通过占空比控制和数据聚合，可以将通信功耗降低 95% 以上：


// BLE 广播间隔优化
// 广播间隔从 100ms → 1000ms，功耗降低约 10 倍
// 连接间隔从 7.5ms → 4000ms，按需唤醒

// 数据聚合策略
#define BATCH_SIZE 10
SensorData batch[BATCH_SIZE];
uint8_t batchIndex = 0;

void collectAndSend(void) {
    batch[batchIndex++] = readSensor();
    if (batchIndex >= BATCH_SIZE) {
        enableRadio();
        sendBatch(batch, BATCH_SIZE);
        disableRadio();
        batchIndex = 0;
    }
}

小结
    

  • 低功耗设计需要硬件选型、时钟管理、电源域控制和软件优化的系统性协同
    • 

  • MCU 提供多级睡眠模式，Stop 模式在 μA 级功耗和 μs 级唤醒间取得平衡
    • 

  • 未使用的 GPIO 配置为模拟输入、关闭不用的外设时钟是基础的功耗优化手段
    • 

  • 无线通信是 IoT 设备最大功耗来源，通过增大间隔和数据聚合可节省 80-95%
    • 

  • 功耗预算从电池容量和目标续航反推平均电流限制，分解到各子系统验证可行性
    • 

  • 精确的功耗测量需要 nA 级分辨率的工具（PPK2、Joulescope）
    •
