FreeRTOS 实战

核心概念

FreeRTOS 是全球使用最广泛的嵌入式实时操作系统，由 Richard Barry 创建并于 2017 年并入 Amazon Web Services。其内核代码仅约 9000 行 C 代码，在资源极度受限的 MCU 上提供了完整的多任务调度、同步通信和时间管理能力。FreeRTOS 支持 40+ 种处理器架构，是从 8 位 AVR 到 64 位 RISC-V 的通用 RTOS 选择。

    SensorData data;
    while (1) {
        data.temperature = readTemp();
        data.humidity = readHumidity();
        data.timestamp = xTaskGetTickCount();

        if (xQueueSend(dataQueue, &data, pdMS_TO_TICKS(50)) != pdTRUE) {

        }
        vTaskDelay(pdMS_TO_TICKS(200));
    }
}

void consumerTask(void *p) {
    SensorData data;
    while (1) {
        if (xQueueReceive(dataQueue, &data, portMAX_DELAY) == pdTRUE) {
            formatAndSend(&data);
        }
    }
}

Tickless 低功耗模式
FreeRTOS 的 Tickless Idle 模式在空闲时停止 SysTick 并进入低功耗状态，显著降低系统功耗：


#define configUSE_TICKLESS_IDLE  1

void vPortSuppressTicksAndSleep(TickType_t xExpectedIdleTime) {
    uint32_t sleepTicks = xExpectedIdleTime;
    HAL_SuspendTick();
    configureRTCWakeup(sleepTicks);
    HAL_PWR_EnterSLEEPMode(PWR_MAINREGULATOR_ON, PWR_SLEEPENTRY_WFI);
    HAL_ResumeTick();
    vTaskStepTick(actualSleepTicks);
}

小结
    

  • FreeRTOS 以约 9000 行核心代码提供完整的多任务调度能力，适用于从 8 位到 64 位的处理器
    • 

  • FreeRTOSConfig.h 是系统行为的控制中心，合理配置栈大小、优先级数量和堆大小至关重要
    • 

  • 生产者-消费者（队列）、事件驱动（信号量）和资源保护（互斥量）是三种核心任务设计模式
    • 

  • Tracealyzer 和 SystemView 是可视化调试 RTOS 调度行为的利器
    • 

  • Tickless Idle 通过在空闲时停止 SysTick 进入低功耗模式，显著延长电池供电设备的续航
    • 

  • 栈溢出检测（configCHECK_FOR_STACK_OVERFLOW）和运行时统计是生产系统的必备配置
    •
