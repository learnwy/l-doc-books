蓝牙与 Zigbee 协议

核心概念

蓝牙低功耗（BLE）和 Zigbee 是物联网领域最重要的短距离无线通信协议。BLE 凭借智能手机的原生支持和低功耗特性，在消费电子和可穿戴设备领域占据主导地位；Zigbee 则以自组网 Mesh 拓扑和高可靠性在智能家居和工业传感器网络中广泛部署。两者均工作在 2.4GHz ISM 频段，但在协议架构、组网能力和功耗模型上有本质差异。

BLE 协议栈与 GATT
协议分层
BLE 协议栈分为控制器层（Controller）和主机层（Host），两者通过 HCI（Host Controller Interface）通信：


// BLE GATT 服务定义示例（nRF SDK / Zephyr）
// 定义温度传感器服务
BT_GATT_SERVICE_DEFINE(temp_svc,
    BT_GATT_PRIMARY_SERVICE(BT_UUID_DECLARE_16(0x181A)),
    BT_GATT_CHARACTERISTIC(BT_UUID_DECLARE_16(0x2A6E),
        BT_GATT_CHRC_READ | BT_GATT_CHRC_NOTIFY,
        BT_GATT_PERM_READ,
        read_temperature, NULL, &temperature_value),
    BT_GATT_CCC(temp_ccc_changed, BT_GATT_PERM_READ | BT_GATT_PERM_WRITE),
);

static ssize_t read_temperature(struct bt_conn *conn,
                                const struct bt_gatt_attr *attr,
                                void *buf, uint16_t len, uint16_t offset) {
    int16_t temp = get_sensor_temperature();
    return bt_gatt_attr_read(conn, attr, buf, len, offset, &temp, sizeof(temp));
}

static void temp_ccc_changed(const struct bt_gatt_attr *attr, uint16_t value) {
    bool notify_enabled = (value == BT_GATT_CCC_NOTIFY);
    if (notify_enabled) {
        start_temperature_notification_timer();
    }
}

Zigbee Mesh 网络
网络角色与拓扑
Zigbee 网络由三种角色组成：协调器（Coordinator）负责网络创建和管理，路由器（Router）转发数据并扩展覆盖范围，终端设备（End Device）通常是电池供电的传感器。


// Zigbee 集群操作示例（Z-Stack / ZBOSS）
// 发送温度测量值
void send_temperature_report(uint8_t endpoint) {
    zb_zcl_attr_t attr_list[] = {
        {
            .id = ZB_ZCL_ATTR_TEMP_MEASUREMENT_VALUE_ID,
            .type = ZB_ZCL_ATTR_TYPE_S16,
            .access = ZB_ZCL_ATTR_ACCESS_READ_ONLY | ZB_ZCL_ATTR_ACCESS_REPORTING,
            .data_p = &measured_temperature,
        },
    };

    zb_zcl_reporting_info_t rep_info = {
        .direction = ZB_ZCL_CONFIGURE_REPORTING_SEND_REPORT,
        .ep = endpoint,
        .cluster_id = ZB_ZCL_CLUSTER_ID_TEMP_MEASUREMENT,
        .min_interval = 10,
        .max_interval = 300,
        .delta.s16 = 50,  // 温度变化 0.5°C 时上报
    };
    zb_zcl_put_reporting_info(&rep_info);
}

Matter 统一标准
Matter（原 CHIP）由 CSA（Connectivity Standards Alliance）制定，旨在统一智能家居协议碎片化问题。Matter 基于 IPv6 运行在 Wi-Fi、Thread 和 BLE 之上，提供统一的设备模型和安全框架：

小结
    

  • BLE 凭借手机原生支持和极低功耗，是消费 IoT 的首选短距离协议
    • 

  • Zigbee 的 Mesh 自组网和成熟的 ZCL 集群库使其在智能家居和工业 IoT 中保持强势地位
    • 

  • BLE 的 GATT 服务模型适合点对点数据交换，Zigbee 的路由机制适合大规模 Mesh 网络
    • 

  • Thread 协议引入原生 IPv6 支持，简化了 IoT 设备的 IP 互联
    • 

  • Matter 标准正在统一智能家居协议碎片化，底层可运行在 Wi-Fi、Thread 和 BLE 之上
    • 

  • 选型时需综合考虑手机兼容性、网络规模、功耗预算和生态成熟度
    •
