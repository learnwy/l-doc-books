LoRa 与低功耗广域网

核心概念

低功耗广域网（LPWAN）技术专为 IoT 场景设计，以极低功耗实现公里级通信距离。LoRa（Long Range）和 LoRaWAN 是 LPWAN 领域最成功的技术方案——LoRa 是物理层调制技术，LoRaWAN 是基于 LoRa 的 MAC 层协议和网络架构。与之竞争的还有 NB-IoT（蜂窝授权频段）和 Sigfox（超窄带）。LPWAN 技术的核心取舍是用带宽换距离和功耗。

LoRa 物理层
CSS 调制技术
LoRa 使用啁啾扩频（Chirp Spread Spectrum, CSS）调制，通过线性频率扫描实现高抗干扰能力。扩频因子（Spreading Factor, SF）是 LoRa 最关键的配置参数——SF 越大，通信距离越远但速率越低：


// LoRa 物理层参数配置（SX1276/SX1262）
typedef struct {
    uint32_t frequency;        // 载波频率 (Hz)
    uint8_t  spreading_factor; // 扩频因子 SF7-SF12
    uint8_t  bandwidth;        // 带宽 125/250/500 kHz
    uint8_t  coding_rate;      // 编码率 4/5-4/8
    int8_t   tx_power;         // 发射功率 (dBm)
    uint16_t preamble_length;  // 前导码长度
} lora_config_t;

lora_config_t config = {
    .frequency = 470000000,       // 470 MHz（中国 ISM 频段）
    .spreading_factor = 10,        // SF10：平衡距离与速率
    .bandwidth = 125,              // 125 kHz
    .coding_rate = 5,              // 4/5 编码率
    .tx_power = 14,                // 14 dBm
    .preamble_length = 8,
};

LoRaWAN 网络架构
星型拓扑
LoRaWAN 采用星型拓扑，终端设备直接与网关通信，网关通过 IP 网络连接到网络服务器：


设备分类
// LoRaWAN 设备入网（OTAA 方式）
#include "lora_mac.h"

static uint8_t dev_eui[] = {0x00, 0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x07};
static uint8_t app_eui[] = {0x70, 0xB3, 0xD5, 0x7E, 0xD0, 0x00, 0x00, 0x00};
static uint8_t app_key[] = {0x2B, 0x7E, 0x15, 0x16, 0x28, 0xAE, 0xD2, 0xA6,
                            0xAB, 0xF7, 0x15, 0x88, 0x09, 0xCF, 0x4F, 0x3C};

void lorawan_join(void) {
    MlmeReq_t req;
    req.Type = MLME_JOIN;
    req.Req.Join.DevEui = dev_eui;
    req.Req.Join.JoinEui = app_eui;
    req.Req.Join.NwkKey = app_key;
    req.Req.Join.Datarate = DR_3;
    LoRaMacMlmeRequest(&req);
}

// 发送传感器数据
void send_uplink(uint8_t *data, uint8_t len) {
    McpsReq_t req;
    req.Type = MCPS_CONFIRMED;  // 确认帧
    req.Req.Confirmed.fPort = 1;
    req.Req.Confirmed.fBuffer = data;
    req.Req.Confirmed.fBufferSize = len;
    req.Req.Confirmed.Datarate = DR_3;
    LoRaMacMcpsRequest(&req);
}

NB-IoT 与 LoRa 选型
NB-IoT 基于蜂窝网络基础设施，由运营商部署和维护，提供更高的可靠性和安全性；LoRa 允许用户自建网络，部署灵活且无月租费用：

小结
    

  • LoRa 使用 CSS 调制实现公里级通信，通过扩频因子 SF 在距离和速率之间权衡
    • 

  • LoRaWAN 采用星型拓扑，三类设备（A/B/C）在功耗和下行延迟之间提供不同选择
    • 

  • NB-IoT 基于蜂窝基础设施，提供更高可靠性和完整双向通信，但依赖运营商
    • 

  • LPWAN 的核心设计取舍是用极低的带宽换取超远距离和超低功耗
    • 

  • LoRa 适合自建网络、偏远地区和极低功耗场景；NB-IoT 适合城市部署和需要 QoS 保证的场景
    • 

  • 实际项目中常混合使用多种 LPWAN 技术，根据子场景特点分别选择
    •
