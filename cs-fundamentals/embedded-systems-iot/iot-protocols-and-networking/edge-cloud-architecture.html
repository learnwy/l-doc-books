边缘计算与云架构

核心概念

IoT 系统产生的数据量远超网络传输能力和云端处理能力，边缘计算（Edge Computing）将计算、存储和决策能力下沉到靠近数据源的位置，在减少延迟和带宽消耗的同时提升系统的实时性和隐私保护。IoT 云-边-端三层架构是当前工业实践的主流模式，每一层承担不同的职责。

边缘计算架构模式
数据过滤与聚合
边缘节点最基本的职责是对终端设备上报的原始数据进行过滤、聚合和压缩，减少上传到云端的数据量：


# 边缘网关数据聚合示例
import numpy as np
from collections import defaultdict

class EdgeAggregator:
    def __init__(self, window_size=60, threshold=0.5):
        self.window_size = window_size
        self.threshold = threshold
        self.buffer = defaultdict(list)

    def ingest(self, device_id, timestamp, value):
        self.buffer[device_id].append((timestamp, value))

        if len(self.buffer[device_id]) >= self.window_size:
            return self._aggregate(device_id)
        return None

    def _aggregate(self, device_id):
        data = self.buffer[device_id]
        values = [v for _, v in data]
        result = {
            "device_id": device_id,
            "start_time": data[0][0],
            "end_time": data[-1][0],
            "mean": np.mean(values),
            "max": np.max(values),
            "min": np.min(values),
            "std": np.std(values),
            "anomaly": np.std(values) > self.threshold,
        }
        self.buffer[device_id].clear()
        return result
边缘推理
在边缘部署轻量化 AI 模型，实现实时异常检测和预测，无需将原始数据上传云端：


# 边缘端 TensorFlow Lite 推理
import tflite_runtime.interpreter as tflite
import numpy as np

class EdgeInference:
    def __init__(self, model_path):
        self.interpreter = tflite.Interpreter(model_path=model_path)
        self.interpreter.allocate_tensors()
        self.input_details = self.interpreter.get_input_details()
        self.output_details = self.interpreter.get_output_details()

    def predict(self, sensor_data):
        input_data = np.array(sensor_data, dtype=np.float32).reshape(
            self.input_details[0]['shape']
        )
        self.interpreter.set_tensor(self.input_details[0]['index'], input_data)
        self.interpreter.invoke()
        output = self.interpreter.get_tensor(self.output_details[0]['index'])
        return output[0]

    def detect_anomaly(self, sensor_data, threshold=0.8):
        score = self.predict(sensor_data)
        return {"anomaly": bool(score > threshold), "confidence": float(score)}

# 云端规则引擎示例
class RuleEngine:
    def __init__(self):
        self.rules = []

    def add_rule(self, condition, action):
        self.rules.append({"condition": condition, "action": action})

    def evaluate(self, event):
        for rule in self.rules:
            if rule["condition"](event):
                rule["action"](event)

engine = RuleEngine()
engine.add_rule(
    condition=lambda e: e.get("temperature", 0) > 80,
    action=lambda e: send_alert(f"高温告警: 设备 {e['device_id']} 温度 {e['temperature']}°C")
)

小结
    

  • IoT 云-边-端三层架构将计算能力分布在数据产生的各个层级，实现延迟、带宽和隐私的最优平衡
    • 

  • 边缘计算的核心价值是数据过滤聚合（减少带宽）、实时推理（降低延迟）和隐私保护（数据不出厂）
    • 

  • TensorFlow Lite、ONNX Runtime 等轻量框架支持在边缘设备上部署 AI 模型
    • 

  • 云平台提供设备管理、规则引擎、数据存储和模型训练等全局能力
    • 

  • 边缘-云协同通过分层推理、联邦学习和模型蒸馏实现端到端智能
    • 

  • OTA（空中升级）是 IoT 系统持续演进的关键能力，需要分块传输和签名验证保障安全
    •
