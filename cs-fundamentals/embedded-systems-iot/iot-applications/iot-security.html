IoT 安全工程

核心概念

IoT 安全面临独特的挑战：设备资源受限（无法运行完整的安全栈）、物理暴露（攻击者可直接接触硬件）、规模庞大（每个薄弱点都是攻击入口）、生命周期长（需要持续安全更新）。IoT 安全需要从芯片级的硬件安全到云端的访问控制构建完整的纵深防御体系。

设备安全基础
安全启动链
安全启动（Secure Boot）确保设备只运行经过签名验证的固件，防止恶意代码注入：


// 安全启动验证流程（概念实现）
#include "mbedtls/sha256.h"
#include "mbedtls/ecdsa.h"

typedef struct {
    uint32_t magic;
    uint32_t version;
    uint32_t image_size;
    uint8_t  signature[64];  // ECDSA P-256 签名
    uint8_t  public_key_hash[32];
} firmware_header_t;

bool verify_firmware(const firmware_header_t *header,
                     const uint8_t *image, size_t size) {
    uint8_t hash[32];
    mbedtls_sha256(image, size, hash, 0);

    mbedtls_ecdsa_context ctx;
    mbedtls_ecdsa_init(&ctx);
    load_otp_public_key(&ctx);

    int ret = mbedtls_ecdsa_read_signature(&ctx,
        hash, 32, header->signature, 64);

    mbedtls_ecdsa_free(&ctx);
    return (ret == 0);
}

void boot_sequence(void) {
    firmware_header_t *header = (firmware_header_t *)FIRMWARE_START;

    if (!verify_firmware(header,
                        (uint8_t *)(FIRMWARE_START + sizeof(*header)),
                        header->image_size)) {
        enter_recovery_mode();
        return;
    }

    jump_to_application(FIRMWARE_START + sizeof(*header));
}

通信安全
TLS 与 DTLS
IoT 通信安全的基础是传输层加密。基于 TCP 的协议（MQTT）使用 TLS，基于 UDP 的协议（CoAP）使用 DTLS：


// mbedTLS 客户端 TLS 连接（MQTT over TLS）
#include "mbedtls/ssl.h"
#include "mbedtls/net_sockets.h"

int setup_tls_connection(const char *host, const char *port,
                         const char *ca_cert) {
    mbedtls_ssl_context ssl;
    mbedtls_ssl_config conf;
    mbedtls_x509_crt cacert;
    mbedtls_net_context server_fd;

    mbedtls_ssl_init(&ssl);
    mbedtls_ssl_config_init(&conf);
    mbedtls_x509_crt_init(&cacert);

    mbedtls_x509_crt_parse(&cacert, (const unsigned char *)ca_cert,
                           strlen(ca_cert) + 1);

    mbedtls_ssl_config_defaults(&conf, MBEDTLS_SSL_IS_CLIENT,
                                MBEDTLS_SSL_TRANSPORT_STREAM,
                                MBEDTLS_SSL_PRESET_DEFAULT);

    mbedtls_ssl_conf_authmode(&conf, MBEDTLS_SSL_VERIFY_REQUIRED);
    mbedtls_ssl_conf_ca_chain(&conf, &cacert, NULL);

    mbedtls_ssl_setup(&ssl, &conf);
    mbedtls_ssl_set_hostname(&ssl, host);

    mbedtls_net_connect(&server_fd, host, port, MBEDTLS_NET_PROTO_TCP);
    mbedtls_ssl_set_bio(&ssl, &server_fd,
                        mbedtls_net_send, mbedtls_net_recv, NULL);

    return mbedtls_ssl_handshake(&ssl);
}

小结
    

  • IoT 安全需要构建从芯片到云端的纵深防御体系，不能依赖单一安全措施
    • 

  • 安全启动链是设备安全的基石，确保每次启动都运行经过签名验证的固件
    • 

  • 硬件安全模块（SE、TrustZone）提供密钥的安全存储和加密运算隔离
    • 

  • TLS/DTLS 是 IoT 通信安全的标准方案，PSK 模式适合资源极度受限的设备
    • 

  • 安全 OTA 必须包含签名验证、传输加密、版本回滚保护和故障回滚机制
    • 

  • IoT 安全是持续工程，设备生命周期内需要定期评估和更新安全策略
    •
