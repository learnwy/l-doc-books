低功耗计算与能量管理

核心概念

IoT 设备通常依赖电池供电，低功耗设计是决定设备使用寿命的关键因素。功耗优化贯穿硬件选型、系统架构、固件设计和通信策略的全流程。一个典型的 IoT 传感器节点需要在纽扣电池上运行 5-10 年，这要求平均功耗控制在微安（μA）级别。理解 MCU 的功耗模型和唤醒策略是嵌入式低功耗设计的基础。

STM32 功耗管理
// STM32L4 低功耗模式配置
#include "stm32l4xx_hal.h"

void enter_stop2_mode(void) {
    __HAL_RCC_PWR_CLK_ENABLE();

    HAL_SuspendTick();

    HAL_PWREx_EnableLowPowerRunMode();

    HAL_PWR_EnterSTOPMode(PWR_LOWPOWERREGULATOR_ON, PWR_STOPENTRY_WFI);

    SystemClock_Config();
    HAL_ResumeTick();
}

void configure_rtc_wakeup(uint32_t seconds) {
    HAL_RTCEx_SetWakeUpTimer_IT(&hrtc, seconds - 1,
                                 RTC_WAKEUPCLOCK_CK_SPRE_16BITS);
}

void sensor_duty_cycle(void) {
    while (1) {
        enable_sensor_power();
        HAL_Delay(10);
        float value = read_sensor();
        disable_sensor_power();

        if (should_transmit(value)) {
            enable_radio();
            transmit_data(value);
            disable_radio();
        }

        configure_rtc_wakeup(60);
        enter_stop2_mode();
    }
}

// 动态时钟频率调整
void set_low_speed_clock(void) {
    RCC_ClkInitTypeDef clk = {0};
    clk.ClockType = RCC_CLOCKTYPE_SYSCLK;
    clk.SYSCLKSource = RCC_SYSCLKSOURCE_MSI;
    HAL_RCC_ClockConfig(&clk, FLASH_LATENCY_0);

    HAL_RCCEx_MSIRangeConfig(RCC_MSIRANGE_0);
}

void disable_unused_peripherals(void) {
    __HAL_RCC_GPIOB_CLK_DISABLE();
    __HAL_RCC_GPIOC_CLK_DISABLE();
    __HAL_RCC_SPI2_CLK_DISABLE();
    __HAL_RCC_USART2_CLK_DISABLE();
}

功耗预算与寿命估算
系统级功耗分析
功耗预算示例：CR2032 电池供电温度传感器

电池容量：CR2032 = 225 mAh（标称 3.0V）

工作周期（每 5 分钟采样一次上报）：
├── 深度睡眠：299.8s × 2μA = 0.167 mAs
├── 唤醒+初始化：5ms × 5mA = 0.025 mAs
├── 传感器采样：50ms × 10mA = 0.500 mAs
├── 无线发送：100ms × 30mA = 3.000 mAs
└── 周期总计：3.692 mAs / 300s = 12.3μA 平均

电池寿命 = 225mAh / 0.0123mA = 18,293 小时 ≈ 2.09 年

优化后（每 15 分钟上报、数据压缩）：
平均电流 = 4.4μA → 寿命 ≈ 5.8 年

小结
    

  • IoT 设备功耗优化需要从硬件、系统、软件和通信四个层面综合考虑
    • 

  • 深度睡眠模式是降低待机功耗的关键，STM32L4 的 STOP2 模式可实现 2μA 待机
    • 

  • 时钟门控和按需启用外设是最基础且有效的软件层功耗优化手段
    • 

  • 能量采集技术可以延长电池寿命甚至实现永久供电，但受限于环境条件和功率密度
    • 

  • 功耗预算是系统设计的必要步骤，需要精确计算每个工作阶段的电流消耗
    • 

  • 通信是 IoT 设备最大的功耗来源，优化传输策略（条件上报、批量发送）效果最显著
    •
