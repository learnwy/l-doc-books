中断与定时器

核心概念

中断（Interrupt）和定时器（Timer）是嵌入式系统实现实时响应的两大核心机制。中断使 MCU 能够在外部事件发生时立即暂停当前任务并执行处理程序，定时器则提供精确的时间基准——从微秒级的 PWM 波形生成到毫秒级的系统心跳。两者的协同工作构成了嵌入式实时控制的基础。

中断优先级与嵌套
ARM Cortex-M 的 NVIC 支持可编程优先级和中断嵌套。优先级分为抢占优先级（Preemption Priority）和子优先级（Sub-Priority）：


// 优先级分组配置（STM32 使用 4 位优先级）
// Group 0: 0 位抢占 / 4 位子优先级
// Group 1: 1 位抢占 / 3 位子优先级
// Group 2: 2 位抢占 / 2 位子优先级（FreeRTOS 推荐）
// Group 3: 3 位抢占 / 1 位子优先级
// Group 4: 4 位抢占 / 0 位子优先级

HAL_NVIC_SetPriorityGrouping(NVIC_PRIORITYGROUP_2);

// 抢占优先级不同 → 高优先级可以打断低优先级（嵌套）
// 抢占优先级相同 → 比较子优先级，不能嵌套，按子优先级顺序执行
HAL_NVIC_SetPriority(USART1_IRQn, 1, 0);  // 抢占1, 子优先级0
HAL_NVIC_SetPriority(TIM2_IRQn, 0, 0);    // 抢占0 → 可打断 USART1

HAL_NVIC_EnableIRQ(USART1_IRQn);
HAL_NVIC_EnableIRQ(TIM2_IRQn);

定时器工作模式
STM32 的定时器功能极其丰富，从基本计数到高级 PWM，覆盖了绝大多数实时控制需求：


// 基本定时器：周期性中断
TIM_HandleTypeDef htim6;
htim6.Instance = TIM6;
htim6.Init.Prescaler = 8400 - 1;       // 84MHz / 8400 = 10KHz
htim6.Init.Period = 10000 - 1;          // 10KHz / 10000 = 1Hz
htim6.Init.CounterMode = TIM_COUNTERMODE_UP;
HAL_TIM_Base_Init(&htim6);
HAL_TIM_Base_Start_IT(&htim6);

void TIM6_DAC_IRQHandler(void) {
    HAL_TIM_IRQHandler(&htim6);
}

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim) {
    if (htim->Instance == TIM6) {
        toggle_led();
    }
}
PWM 输出——用于电机控制、LED 调光、伺服驱动：


// TIM3 CH1 输出 1KHz PWM，占空比 50%
TIM_OC_InitTypeDef sConfigOC = {0};
htim3.Instance = TIM3;
htim3.Init.Prescaler = 84 - 1;         // 84MHz / 84 = 1MHz
htim3.Init.Period = 1000 - 1;           // 1MHz / 1000 = 1KHz
HAL_TIM_PWM_Init(&htim3);

sConfigOC.OCMode = TIM_OCMODE_PWM1;
sConfigOC.Pulse = 500;                   // 500/1000 = 50% 占空比
sConfigOC.OCPolarity = TIM_OCPOLARITY_HIGH;
HAL_TIM_PWM_ConfigChannel(&htim3, &sConfigOC, TIM_CHANNEL_1);
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);

// 动态调节占空比
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, new_duty);
输入捕获——测量外部信号的频率和脉宽：


// TIM2 CH1 输入捕获：测量脉冲宽度
volatile uint32_t rising_edge = 0;
volatile uint32_t falling_edge = 0;
volatile uint32_t pulse_width = 0;

void HAL_TIM_IC_CaptureCallback(TIM_HandleTypeDef *htim) {
    if (htim->Channel == HAL_TIM_ACTIVE_CHANNEL_1) {
        if (is_rising) {
            rising_edge = HAL_TIM_ReadCapturedValue(htim, TIM_CHANNEL_1);
            __HAL_TIM_SET_CAPTUREPOLARITY(htim, TIM_CHANNEL_1, TIM_INPUTCHANNELPOLARITY_FALLING);
            is_rising = 0;
        } else {
            falling_edge = HAL_TIM_ReadCapturedValue(htim, TIM_CHANNEL_1);
            pulse_width = falling_edge - rising_edge;
            __HAL_TIM_SET_CAPTUREPOLARITY(htim, TIM_CHANNEL_1, TIM_INPUTCHANNELPOLARITY_RISING);
            is_rising = 1;
        }
    }
}

ISR 设计最佳实践
中断服务程序的设计质量直接影响系统的实时性和可靠性：


// 推荐模式：ISR 中只设置标志，主循环处理
volatile uint8_t uart_data_ready = 0;
volatile uint8_t uart_rx_byte = 0;

void USART1_IRQHandler(void) {
    if (__HAL_UART_GET_FLAG(&huart1, UART_FLAG_RXNE)) {
        uart_rx_byte = (uint8_t)(huart1.Instance->DR);
        uart_data_ready = 1;
    }
}

int main(void) {
    while (1) {
        if (uart_data_ready) {
            uart_data_ready = 0;
            process_byte(uart_rx_byte);
        }
        __WFI();  // 等待中断，降低功耗
    }
}

看门狗定时器
看门狗（Watchdog Timer）是系统可靠性的最后防线——当软件陷入死循环或异常状态时，看门狗会触发系统复位：


// 独立看门狗（IWDG）：独立时钟，不受系统故障影响
IWDG_HandleTypeDef hiwdg;
hiwdg.Instance = IWDG;
hiwdg.Init.Prescaler = IWDG_PRESCALER_64;
hiwdg.Init.Reload = 4095;  // 超时时间 ≈ 4095 × 64 / 32000 ≈ 8.2s
HAL_IWDG_Init(&hiwdg);

while (1) {
    main_task();
    HAL_IWDG_Refresh(&hiwdg);  // 喂狗
}

小结
    

  • 中断通过 NVIC 实现优先级仲裁和嵌套，Cortex-M 的中断延迟仅 12 个时钟周期
    • 

  • 优先级分为抢占优先级和子优先级，只有抢占优先级不同才能嵌套
    • 

  • 定时器支持基本计数、PWM 输出、输入捕获、编码器模式等多种工作模式
    • 

  • ISR 设计原则：尽量短、不阻塞、共享变量用 volatile、复杂处理推迟到主循环
    • 

  • PWM 是嵌入式最常用的输出方式，输入捕获用于测量外部信号特征
    • 

  • 看门狗定时器是系统可靠性的最后保障，IWDG 独立于系统时钟更可靠
    •
