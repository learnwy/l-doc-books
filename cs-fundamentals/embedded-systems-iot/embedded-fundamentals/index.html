嵌入式基础 简介

本章建立嵌入式系统开发的底层认知框架，帮助软件工程师理解硬件与软件的交互边界。嵌入式开发与通用计算的根本区别在于资源约束和实时性要求，掌握微控制器的架构特征和底层编程技巧是进入这一领域的第一步。

本章包含四个核心主题。微控制器架构部分讲解 ARM Cortex-M 系列和 RISC-V 等主流嵌入式处理器的内部结构，包括 CPU 核心、总线矩阵、外设控制器和时钟系统的协作关系。嵌入式 C 与 Rust部分对比两种语言在嵌入式开发中的实际应用，从裸机编程、硬件抽象层设计到编译器优化选项，帮助读者选择适合项目需求的技术路线。

内存与寄存器部分深入探讨嵌入式环境下的内存模型，包括 Flash/RAM 布局、内存映射 I/O、位带操作以及链接脚本的配置方法。中断与定时器部分详解嵌入式系统中最关键的实时响应机制——中断向量表、嵌套中断控制器（NVIC）、定时器的多种工作模式以及 PWM 信号生成。

建议按顺序学习本章内容。架构知识为编程提供上下文，内存模型是理解寄存器操作的前提，而中断与定时器则是构建实时响应系统的核心工具。
