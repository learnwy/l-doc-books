微控制器体系结构

核心概念

微控制器（Microcontroller, MCU）是将处理器核心、内存、外设接口集成在单芯片上的嵌入式计算单元。与通用处理器（CPU）不同，MCU 针对实时控制和低功耗场景做了深度优化，是物联网设备、工业控制、汽车电子的核心计算元件。理解 MCU 的体系结构——特别是哈佛架构与冯诺依曼架构的差异、总线系统和外设子系统——是嵌入式开发的第一步。

ARM Cortex-M 系列
ARM Cortex-M 是嵌入式领域最广泛使用的处理器核心系列。从超低功耗的 Cortex-M0 到高性能的 Cortex-M7，覆盖了从传感器节点到复杂实时控制的全部场景。


Cortex-M 处理器流水线：


// Cortex-M3/M4 采用 3 级流水线：取指 → 解码 → 执行
// Cortex-M7 采用 6 级流水线，支持分支预测

// Thumb-2 指令集：16 位和 32 位指令混合
// 代码密度高（比 ARM 32 位指令集小 30%），适合有限的 Flash 空间

异常模型与嵌套向量中断控制器（NVIC）：


// NVIC 特性：
// - 可配置的优先级（通常 3-8 位）
// - 尾链（Tail-chaining）：连续中断无需恢复/保存上下文
// - 迟到（Late-arriving）：高优先级中断可抢占正在入栈的低优先级中断

// STM32 中断优先级配置
void configureNVIC(void) {
    NVIC_SetPriorityGrouping(3);
    NVIC_SetPriority(USART1_IRQn, NVIC_EncodePriority(3, 2, 0));
    NVIC_EnableIRQ(USART1_IRQn);
}
总线架构与内存映射
MCU 内部使用总线矩阵连接 CPU 核心、内存和外设。ARM Cortex-M 系列采用 AMBA（Advanced Microcontroller Bus Architecture）总线标准：


// STM32 的内存映射（典型 Cortex-M4）
// 0x0000_0000 - 0x0007_FFFF  Flash (512KB)
// 0x2000_0000 - 0x2001_FFFF  SRAM (128KB)
// 0x4000_0000 - 0x4000_7FFF  APB1 外设（UART, SPI, I2C, TIM2-7）
// 0x4001_0000 - 0x4001_3FFF  APB2 外设（USART1, SPI1, TIM1）
// 0x4002_0000 - 0x4002_3FFF  AHB1 外设（GPIO, DMA, RCC）
// 0xE000_0000 - 0xE00F_FFFF  系统外设（NVIC, SysTick, SCB）

// 通过内存映射访问外设寄存器
#define GPIOA_BASE    0x40020000
#define GPIOA_MODER   (*(volatile uint32_t *)(GPIOA_BASE + 0x00))
#define GPIOA_ODR     (*(volatile uint32_t *)(GPIOA_BASE + 0x14))

RISC-V 在嵌入式领域
RISC-V 是开源指令集架构（ISA），近年来在嵌入式领域快速崛起。其模块化设计允许厂商根据需求定制指令集扩展：


// RISC-V 基础指令集
// RV32I：32 位整数指令（47 条基本指令）
// RV32E：嵌入式精简版（16 个寄存器）
// 标准扩展：
// M - 整数乘除法
// A - 原子操作
// F - 单精度浮点
// D - 双精度浮点
// C - 压缩指令（16 位）
// V - 向量扩展

// 典型嵌入式 RISC-V 芯片
// ESP32-C3 (RV32IMC, WiFi + BLE, 160MHz)
// GD32VF103 (RV32IMAC, 108MHz, 兼容 STM32F103 引脚)
// CH32V (WCH 沁恒系列，低成本)

外设子系统与通信接口
MCU 的价值在于丰富的片上外设，它们通过寄存器接口与 CPU 交互：


// GPIO 配置（STM32 HAL 方式）
GPIO_InitTypeDef GPIO_InitStruct = {0};
GPIO_InitStruct.Pin = GPIO_PIN_5;
GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
GPIO_InitStruct.Pull = GPIO_NOPULL;
GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);

// UART 配置
UART_HandleTypeDef huart2;
huart2.Instance = USART2;
huart2.Init.BaudRate = 115200;
huart2.Init.WordLength = UART_WORDLENGTH_8B;
huart2.Init.StopBits = UART_STOPBITS_1;
huart2.Init.Parity = UART_PARITY_NONE;
HAL_UART_Init(&huart2);

// ADC 读取（12 位分辨率，0-3.3V）
HAL_ADC_Start(&hadc1);
HAL_ADC_PollForConversion(&hadc1, 100);
uint32_t raw = HAL_ADC_GetValue(&hadc1);
float voltage = raw * 3.3f / 4095.0f;

小结
    

  • MCU 将处理器、存储器和外设集成在单芯片上，针对实时控制和低功耗场景优化
    • 

  • ARM Cortex-M 系列从 M0（最低功耗）到 M7（最高性能）覆盖全部嵌入式场景
    • 

  • NVIC 提供高效的嵌套中断处理，支持尾链和迟到优化
    • 

  • 内存映射 IO 将外设寄存器映射到地址空间，通过指针直接访问
    • 

  • RISC-V 以开源免授权费和可定制扩展正在嵌入式领域快速崛起
    • 

  • MCU 的核心外设包括 GPIO、UART、SPI、I2C、ADC、定时器和 DMA
