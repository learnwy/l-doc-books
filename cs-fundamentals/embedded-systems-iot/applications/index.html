嵌入式系统应用与工程实践 简介

掌握处理器架构和通信协议之后，嵌入式工程师真正面临的是「把系统做出来并稳定量产」的挑战。本章聚焦应用与工程实践层面，讨论嵌入式系统如何与物理世界交互、如何选择合适的操作系统平台，以及从原型到量产过程中需要遵循的工程规范。

本章包含三篇文档。传感器与执行器接口讲解嵌入式系统与物理世界交互的桥梁，覆盖温度、湿度、加速度、光照等传感器的信号特性、接口协议与校准方法，以及执行器的驱动方式，帮助读者构建可靠的物理交互能力。嵌入式 Linux 与 Yocto介绍把 Linux 操作系统裁剪到资源受限硬件上的技术实践，对比 RTOS 与嵌入式 Linux 的差异，并重点讨论 Yocto Project 这一被 Intel、NXP、TI 等厂商广泛采用的工业级构建框架。嵌入式项目工程实践则覆盖固件架构设计、版本管理、持续集成、调试技术与生产部署的全流程最佳实践，强调嵌入式工程在硬件依赖、实时约束和现场调试方面的独特挑战。

建议先读传感器与执行器接口，建立硬件接入的基本认知；再读嵌入式 Linux 与 Yocto，理解中高端嵌入式系统的软件平台选择；最后通过嵌入式项目工程实践把视角拉到产品全生命周期，看到原型到量产路径上必须解决的工程问题。
