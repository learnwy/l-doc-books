BLE 蓝牙低功耗

核心概念

蓝牙低功耗（Bluetooth Low Energy, BLE）是蓝牙 4.0 引入的低功耗无线通信技术，专为 IoT 设备设计。与经典蓝牙（Classic Bluetooth）不同，BLE 优化了极低功耗和快速连接——设备可以在毫秒内建立连接，以微安级平均电流运行数年。BLE 是智能穿戴、信标、传感器网络和近场交互的核心连接技术。

GATT 与 ATT 属性系统
GATT（Generic Attribute Profile）是 BLE 数据交互的核心框架。数据组织为 Service → Characteristic → Descriptor 的层次结构：


// 自定义环境监测服务
// Service UUID: 0x181A (Environmental Sensing)
//   ├── Temperature Characteristic (0x2A6E)
//   │   ├── Value: int16 (0.01°C 精度)
//   │   ├── Client Characteristic Configuration Descriptor (CCCD)
//   │   └── Characteristic User Description
//   ├── Humidity Characteristic (0x2A6F)
//   │   ├── Value: uint16 (0.01% 精度)
//   │   └── CCCD
//   └── Battery Level Characteristic (0x2A19)
//       └── Value: uint8 (0-100%)
Zephyr BLE 服务定义：


BT_GATT_SERVICE_DEFINE(env_svc,
    BT_GATT_PRIMARY_SERVICE(BT_UUID_ESS),
    BT_GATT_CHARACTERISTIC(BT_UUID_TEMPERATURE,
        BT_GATT_CHRC_READ | BT_GATT_CHRC_NOTIFY,
        BT_GATT_PERM_READ,
        read_temp, NULL, &temperature),
    BT_GATT_CCC(temp_ccc_changed, BT_GATT_PERM_READ | BT_GATT_PERM_WRITE),
    BT_GATT_CHARACTERISTIC(BT_UUID_HUMIDITY,
        BT_GATT_CHRC_READ | BT_GATT_CHRC_NOTIFY,
        BT_GATT_PERM_READ,
        read_hum, NULL, &humidity),
    BT_GATT_CCC(hum_ccc_changed, BT_GATT_PERM_READ | BT_GATT_PERM_WRITE),
);

static ssize_t read_temp(struct bt_conn *conn,
    const struct bt_gatt_attr *attr, void *buf,
    uint16_t len, uint16_t offset)
{
    return bt_gatt_attr_read(conn, attr, buf, len, offset,
        &temperature, sizeof(temperature));
}

void notify_temperature(int16_t temp) {
    temperature = temp;
    bt_gatt_notify(NULL, &env_svc.attrs[1], &temperature, sizeof(temperature));
}

广播与扫描
BLE 广播是无连接的单向通信，设备通过广播包（Advertisement）发送数据。BLE 5.0 的扩展广播支持高达 254 字节的载荷：


// Zephyr BLE 广播配置
static const struct bt_data ad[] = {
    BT_DATA_BYTES(BT_DATA_FLAGS, (BT_LE_AD_GENERAL | BT_LE_AD_NO_BREDR)),
    BT_DATA_BYTES(BT_DATA_UUID16_ALL, BT_UUID_16_ENCODE(0x181A)),
    BT_DATA(BT_DATA_NAME_COMPLETE, DEVICE_NAME, sizeof(DEVICE_NAME) - 1),
};

static const struct bt_data sd[] = {
    BT_DATA(BT_DATA_MANUFACTURER_SPECIFIC, mfg_data, sizeof(mfg_data)),
};

int startAdvertising(void) {
    return bt_le_adv_start(BT_LE_ADV_CONN, ad, ARRAY_SIZE(ad), sd, ARRAY_SIZE(sd));
}

BLE 连接参数优化
连接参数直接影响功耗和吞吐量的平衡：


// 连接参数协商
struct bt_le_conn_param param = {
    .interval_min = 80,    // 100ms（80 × 1.25ms）
    .interval_max = 160,   // 200ms（160 × 1.25ms）
    .latency = 4,          // 允许跳过 4 个连接事件
    .timeout = 400,        // 5s 超时（400 × 10ms）
};
bt_conn_le_param_update(conn, &param);

小结
    

  • BLE 专为低功耗和快速连接设计，μA 级平均电流可实现数年电池续航
    • 

  • GATT 层次结构（Service→Characteristic→Descriptor）是 BLE 数据交互的核心
    • 

  • 广播是无连接单向通信，BLE 5.0 扩展广播支持 254 字节载荷
    • 

  • 连接参数（间隔、延迟、超时）直接决定功耗和响应性的平衡
    • 

  • BLE Mesh 通过多跳广播实现大规模网状网络，Relay/Friend/LPN 角色协同覆盖异构节点需求
    • 

  • BLE 5.x 的 2M PHY 提升吞吐量，Coded PHY 扩展通信距离至 400m+
    •
