LoRa 与 LPWAN

核心概念

LPWAN（Low-Power Wide-Area Network）是专为 IoT 设计的长距离低功耗广域网技术。LoRa（Long Range）是 LPWAN 领域最主流的物理层调制技术，结合 LoRaWAN 网络协议，可在数公里范围内以极低功耗传输少量数据。LPWAN 填补了 BLE（近距离）和蜂窝网络（高功耗）之间的空白，是智慧城市、农业监测、资产追踪等场景的核心连接技术。

LoRa 物理层
LoRa 使用啁啾扩频（Chirp Spread Spectrum, CSS）调制技术，通过扩频因子（Spreading Factor, SF）在数据速率和传输距离之间做权衡：


// LoRa 射频参数配置（SX1276/SX1262）
SX1276_SetChannel(868100000);           // 频率 868.1MHz (EU868)
SX1276_SetSpreadingFactor(LORA_SF7);    // 扩频因子 SF7
SX1276_SetBandwidth(LORA_BW_125);       // 带宽 125KHz
SX1276_SetCodingRate(LORA_CR_4_5);      // 编码率 4/5
SX1276_SetTxPower(14);                  // 发射功率 14dBm

// 发送数据
uint8_t payload[] = {0x01, 0x02, 0x03};
SX1276_Send(payload, sizeof(payload));

小结
    

  • LPWAN 填补了短距离（BLE/Zigbee）和蜂窝（4G/5G）之间的 IoT 连接空白
    • 

  • LoRa 使用啁啾扩频调制，SF 越高距离越远但速率越低、功耗越高
    • 

  • LoRaWAN 分为 Class A/B/C 三种设备类型，Class A 功耗最低但下行受限
    • 

  • OTAA 入网方式比 ABP 更安全，支持动态密钥协商
    • 

  • 频率规划需遵守当地 ISM 频段法规，EU868 有严格的占空比限制
    • 

  • LoRa 适合自建网络场景（农业、工厂），NB-IoT 适合城市覆盖和运营商管理场景
    •
