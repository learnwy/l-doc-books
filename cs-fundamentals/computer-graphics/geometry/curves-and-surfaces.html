曲线与曲面

核心概念

曲线与曲面是用数学函数精确描述光滑几何形状的方法。与网格的离散多边形近似不同，参数曲面提供了无限分辨率的连续表面定义，可以在任意精度下求值。CAD 软件、字体渲染、动画路径和物理模拟都依赖参数曲线和曲面。

参数曲线 C(t) 将一个参数 t ∈ [0,1] 映射为空间中的一个点。参数曲面 S(u,v) 将两个参数 (u,v) ∈ [0,1]² 映射为空间中的一个点。它们的核心思想是用控制点（Control Points）定义形状，曲线/曲面通过基函数对控制点进行加权混合。

Bézier 曲线与 de Casteljau 算法
Bézier 曲线由一组控制点 P₀, P₁, ..., Pₙ 定义，使用伯恩斯坦多项式作为基函数：


C(t) = Σᵢ Bᵢⁿ(t) × Pᵢ

伯恩斯坦基函数:
Bᵢⁿ(t) = C(n,i) × tⁱ × (1-t)^(n-i)

三次 Bézier (n=3):
C(t) = (1-t)³P₀ + 3(1-t)²tP₁ + 3(1-t)t²P₂ + t³P₃
三次 Bézier 是最常用的阶数——它用 4 个控制点提供足够的灵活性来表达各种曲线形状。


曲线从 P₀ 出发（t=0），终止于 P₃（t=1），中间控制点 P₁、P₂ 控制曲线的走向但曲线不穿过它们。P₀P₁ 的方向是曲线在起点的切线方向。


de Casteljau 算法是数值稳定的 Bézier 曲线求值方法。它通过递归地对相邻控制点进行线性插值来计算曲线上的点：


对于 n 次 Bézier 和参数 t:
第 0 层: P₀⁰ = P₀, P₁⁰ = P₁, ..., Pₙ⁰ = Pₙ
第 k 层: Pᵢᵏ = (1-t)Pᵢᵏ⁻¹ + tPᵢ₊₁ᵏ⁻¹
最终: C(t) = P₀ⁿ
de Casteljau 不仅用于求值，还自然地实现了曲线细分——算法过程中产生的中间点恰好构成两条子 Bézier 曲线的控制点。这个性质在自适应绘制（将曲线递归细分为足够平直的线段）中非常有用。


Bézier 曲线的局限在于缺乏局部控制——移动任何一个控制点都会影响整条曲线。对于长曲线，通常使用多段 Bézier 拼接，要保证拼接处的连续性。


G¹ 连续（几何连续，切线方向相同）要求相邻段的边界控制点共线；C¹ 连续（参数连续，切向量相同）进一步要求等距。


有理 Bézier 曲线通过为每个控制点添加权重 wᵢ，可以精确表示圆弧和椭圆等二次曲线。这是 NURBS 技术的基础——有理 B 样条是有理 Bézier 的推广。


在实时渲染中，Bézier 曲线最常见的应用是字体渲染。TrueType 字体使用二次 Bézier，OpenType CFF 使用三次 Bézier 定义字形轮廓。GPU 加速的字体渲染（如 Slug 库）直接在片元着色器中求解 Bézier 曲线方程来判断像素是否在字形内部，避免了预先细分为三角形。


B 样条与 NURBS
B 样条（B-Spline）通过引入节点向量（Knot Vector）解决了 Bézier 曲线缺乏局部控制的问题。移动一个控制点只影响曲线的局部区域（由节点向量决定的支撑域），并自动保证高阶连续性。


B 样条曲线:
C(t) = Σᵢ Nᵢ,ₚ(t) × Pᵢ

B 样条基函数 (Cox-de Boor 递推):
Nᵢ,₀(t) = 1 if tᵢ ≤ t < tᵢ₊₁, else 0
Nᵢ,ₚ(t) = ((t-tᵢ)/(tᵢ₊ₚ-tᵢ)) × Nᵢ,ₚ₋₁(t) + ((tᵢ₊ₚ₊₁-t)/(tᵢ₊ₚ₊₁-tᵢ₊₁)) × Nᵢ₊₁,ₚ₋₁(t)
节点向量 T = {t₀, t₁, ..., tₘ} 是一个非递减序列。节点的分布决定了曲线的参数化方式和局部性。


均匀 B 样条节点等间距分布（如 {0,1,2,3,...}），非均匀 B 样条允许不等距节点以更灵活地控制曲线参数化。


重复节点可以降低连续性——节点重复 k 次会将连续性从 C^(p-1) 降低到 C^(p-k)。


NURBS（Non-Uniform Rational B-Spline）在 B 样条基础上引入有理权重，可以精确表示圆弧、椭圆等二次曲线——这是多项式曲线无法做到的。NURBS 是 CAD 领域的工业标准。


在实时渲染中，参数曲面在提交 GPU 之前通常被曲面细分（Tessellation）为三角形网格。GPU 的硬件细分阶段可以在运行时自适应地细分参数曲面——近处细分更密，远处更稀疏，在保持视觉质量的同时减少远处的几何量。


细分曲面
细分曲面（Subdivision Surfaces）是一种通过递归细分多边形控制网格来生成光滑极限曲面的方法。它结合了多边形建模的直观性和参数曲面的光滑性，是电影和游戏角色建模的标准技术。


Catmull-Clark 细分是最广泛使用的细分方案，适用于四边形控制网格。每次细分在每个面的中心、每条边的中点插入新顶点，并按加权规则更新原有顶点的位置。


经过无限次细分，极限曲面在正则顶点处（被 4 个四边形共享的顶点）达到 C² 连续，在异常顶点处（非正则度的顶点）达到 C¹ 连续。


Catmull-Clark 一步细分规则:
面点: F = 面内所有顶点的平均
边点: E = (边两端点 + 两侧面点) / 4
顶点更新: V' = (F̄ + 2Ē + (n-3)V) / n
其中 F̄ = 相邻面点平均, Ē = 相邻边中点平均, n = 度数
Loop 细分适用于三角形网格。它的极限面在正则顶点处（度数为 6）达到 C² 连续。Loop 细分的规则类似但权重系数不同，适合三角形网格编辑工作流。


细分曲面支持折痕（Crease）标记——为特定的边或顶点设置折痕权重，控制该处的锐利程度。


权重为 0 时完全光滑，权重为 ∞（或最大整数值）时保持硬边。中间权重产生可控的半锐边效果。这使得同一个模型可以同时包含光滑区域和锐利特征。

OpenSubdiv（Pixar 开源）是工业级的细分曲面库，支持 GPU 加速的实时自适应细分，被 Pixar、迪士尼等主要工作室使用。


细分曲面与参数曲面（如 NURBS）在精度上有区别——细分曲面在异常顶点处只能达到 C¹ 连续，而 NURBS 曲面可以保证全局的高阶连续性。但细分曲面的拓扑灵活性远超 NURBS——它可以处理任意拓扑的网格（包括非四边形面和任意度数的顶点），而 NURBS 只能表示矩形参数域的曲面。这种拓扑自由度使得细分曲面在角色建模中不可替代。


在游戏引擎中，细分曲面通常以低多边形控制网格的形式存储和传输。GPU 的硬件曲面细分阶段（Tessellation Stage）或 Mesh Shader 在运行时根据相机距离和屏幕空间投影面积动态选择细分级别。这实现了内存高效（只存储控制网格）和视觉高质量（近处自动细分到光滑表面）的平衡。


自适应细分（Adaptive Tessellation）根据屏幕空间的需求在不同区域使用不同的细分级别。轮廓边缘（Silhouette Edges）和接近相机的区域需要更密的细分来保持光滑外观，而远处或正面朝向的区域可以使用更低的细分级别。这种自适应策略可以将三角形数量减少到均匀细分的 1/3 到 1/5，同时保持相同的视觉质量。


位移映射（Displacement Mapping）结合细分曲面和高度纹理来添加表面细节。控制网格经过细分后，每个细分顶点沿法线方向按高度纹理的值进行位移。这产生了真正的几何细节（与法线贴图的纯视觉模拟不同），正确的轮廓、自遮挡和阴影都能得到处理。位移映射的质量取决于细分密度——细分不够密时位移会产生锯齿状的表面。


隐式曲面与距离场
隐式曲面用一个标量函数 f(x,y,z) = 0 定义表面——函数值为零的所有点集构成曲面。与参数表示不同，隐式表示天然支持布尔运算（并集、交集、差集）和形变，且内外判定极为简单（判断 f 的符号即可）。


有符号距离场（Signed Distance Field, SDF）是一种特殊的隐式表示，其中 f(p) 等于点 p 到最近表面点的带符号距离——表面内部为负，外部为正。


SDF 有许多优良性质：梯度方向就是表面法线，射线步进（Sphere Tracing）可以安全地按 |f(p)| 的步长前进而不会穿过表面，多个 SDF 可以通过 min/max 操作组合。


Sphere Tracing 算法:
p = ray_origin
for step in 0..MAX_STEPS:
    d = SDF(p)
    if |d| < EPSILON:
        return hit at p
    p = p + ray_direction × d
return no hit
SDF 在实时渲染中用于软阴影（根据距离场中最近距离估算遮挡程度）、全局光照（Cone Tracing 在距离场中追踪）和文本渲染（用 SDF 纹理实现任意缩放的清晰字体边缘）。


Marching Cubes 是将隐式曲面转换为三角形网格的经典算法。它将空间划分为规则网格，对每个立方体单元检查 8 个角点的函数值符号，根据 256 种可能的符号组合（实际 15 种基本情况）查表生成三角形。


双重轮廓法（Dual Contouring）改进了 Marching Cubes 在尖锐特征处的表现。


Neural SDF（神经网络表示的 SDF）是近年来的热门研究方向。用多层感知机（MLP）或 Hash Grid 来隐式编码 SDF，可以用极少的参数（几 MB）表示高分辨率的三维形状。


InstantNGP（NVIDIA）使用多分辨率哈希网格将 SDF 的训练和推理速度提升了数个数量级。虽然目前主要用于神经渲染（NeRF）和 3D 重建，Neural SDF 在游戏和实时图形中的应用也开始出现。


程序化几何（Procedural Geometry）通过数学函数或规则系统生成几何形状。SDF 的代数组合（并集取 min、交集取 max、差集取 max(-f)）可以在不进行任何多边形运算的情况下实现实时的 CSG（Constructive Solid Geometry）操作。


Shadertoy 等平台上大量的实时 Demo 完全使用 SDF + Sphere Tracing 实现，无需任何三角形网格。


这种渲染方式不需要任何三角形——纯粹通过数学函数定义几何。


小结
    

  • Bézier 曲线用伯恩斯坦基函数对控制点加权混合，de Casteljau 算法提供稳定的递归求值
    • 

  • B 样条通过节点向量实现局部控制和自动连续性，NURBS 增加有理权重支持精确圆锥曲线
    • 

  • Catmull-Clark 细分将四边形控制网格递归细分为光滑极限面，正则点处 C² 连续
    • 

  • 细分曲面的折痕标记允许同一模型混合光滑和锐利特征
    • 

  • SDF 通过带符号距离定义曲面，支持高效的射线步进和布尔运算
    • 

  • Sphere Tracing 根据 SDF 值安全地步进射线，不会穿过表面
    • 

  • Marching Cubes 将隐式曲面转换为三角形网格，是体素重建的标准算法
