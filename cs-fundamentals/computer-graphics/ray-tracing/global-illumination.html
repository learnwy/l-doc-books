全局光照

核心概念

全局光照（Global Illumination, GI）是指在渲染中考虑光线在场景中多次反弹的间接照明效果。与只计算光源到表面直接照明的局部光照不同，全局光照模拟光线从一个表面反射到另一个表面的过程，产生颜色渗透（Color Bleeding）、软阴影、焦散（Caustics）等真实世界中普遍存在的光照现象。

全局光照的数学基础是渲染方程（Rendering Equation，Kajiya 1986）。它描述了表面某点在某方向上的出射辐亮度等于该点的自发光加上从所有入射方向反射的光照积分：

L_o(p, ω_o) = L_e(p, ω_o) + ∫_Ω f_r(p, ω_i, ω_o) × L_i(p, ω_i) × cos(θ_i) dω_i

其中:
L_o = 出射辐亮度
L_e = 自发光
f_r = BRDF
L_i = 入射辐亮度（来自其他表面的直接和间接光照）
cos(θ_i) = 入射角余弦
Ω = 上半球

渲染方程的递归性质（L_i 本身也满足渲染方程）使得精确求解需要无限次递归。

实际方法通过截断弹射次数或统计估计来近似。

蒙特卡洛方法是求解渲染方程最通用的数值技术——它通过随机采样入射方向来估计半球积分。每个样本生成一条光线路径，大量样本的平均值收敛于真实的积分结果。

路径追踪
路径追踪（Path Tracing）是渲染方程的蒙特卡洛求解方法。它从相机发射射线，在每个交点处根据 BRDF 的概率分布随机选择一个反弹方向，继续追踪直到达到最大弹射次数或通过俄罗斯轮盘赌（Russian Roulette）概率终止。每条完整路径对一个像素贡献一个颜色样本，大量路径的平均值收敛于渲染方程的精确解。


path_trace(ray, depth):
    if depth > MAX_DEPTH: return black

    hit = scene.intersect(ray)
    if no hit: return environment_light(ray.dir)

    Le = hit.emission

    // 俄罗斯轮盘赌终止
    survival = max(albedo.r, albedo.g, albedo.b)
    if random() > survival: return Le
    throughput_scale = 1.0 / survival

    // 随机采样反弹方向
    (wi, pdf) = sample_BRDF(hit.material, wo, hit.normal)
    Li = path_trace(Ray(hit.point, wi), depth + 1)
    brdf_value = evaluate_BRDF(hit.material, wi, wo, hit.normal)

    return Le + (brdf_value * Li * cos_theta / pdf) * throughput_scale
路径追踪的收敛速度（方差下降速率）取决于采样策略。


朴素的路径追踪（每个交点只随机选一个方向继续追踪）收敛极慢——需要数千甚至数万个样本才能得到可接受的图像。关键的方差减少技术包括：


下一事件估计（Next Event Estimation, NEE）：在每个交点处，除了随机反弹外，还直接向光源采样计算直接光照。


这对于小面积强光源（如灯泡）效果显著——纯随机反弹很难碰巧指向小光源。


多重重要性采样（Multiple Importance Sampling, MIS）：同时使用 BRDF 采样和光源采样两种策略，通过平衡启发式（Balance Heuristic）或功率启发式（Power Heuristic）对两者的估计值加权组合。


MIS 确保无论 BRDF 还是光源主导的情况都能高效采样。


双向路径追踪（Bidirectional Path Tracing, BDPT）同时从相机和光源两端构建路径，在中间连接。它对于间接照明和难以从相机端采样到的光路（如通过小窗口的光照、焦散）特别有效。


Metropolis Light Transport（MLT）是另一种高级的路径采样方法。它使用马尔可夫链蒙特卡洛（MCMC）在路径空间中"突变"已知的好路径——对已找到的高贡献路径施加微小的随机扰动来生成新路径。


MLT 擅长发现复杂的光路（如只有极细窗缝可以进入的室内间接光照），但其自适应采样的非均匀特性使得它难以用于并行 GPU 实现，主要用于离线渲染。


光子映射
光子映射（Photon Mapping）是一种两阶段的全局光照算法。第一阶段从光源发射大量光子，追踪它们在场景中的反弹路径，在每个漫反射交点处将光子存入三维数据结构（通常是 KD 树）。


第二阶段从相机渲染场景，在每个着色点通过 K 最近邻搜索收集附近的光子，用核密度估计计算间接光照。


光子映射的独特优势是处理焦散——光线穿过玻璃或经水面反射后聚焦在漫反射表面上的明亮光斑。路径追踪很难高效地采样到这种"镜面→漫反射"路径，但光子映射从光源端出发自然地产生焦散光子。在实际使用中，焦散光子图和全局光子图通常分开存储和查询——焦散光子图需要更高的密度和更小的搜索半径来保持焦散的锐利边缘。


渐进式光子映射（Progressive Photon Mapping, PPM）解决了经典光子映射的偏差问题。它通过多轮迭代，每轮发射新的光子并缩小搜索半径，在无限轮次后收敛到无偏的精确解。


PPM 的内存消耗固定（只需存储最近一轮的光子），适合处理复杂的光照场景。


渐进式光子映射流程:
第 1 轮: 从相机渲染，记录所有可见点，搜索半径 R₀
第 k 轮: 发射 N 个光子 → 更新所有可见点的辐照度估计
         缩小搜索半径: Rₖ = R₀ × (k/(k+α))^0.5
最终图像: 所有轮次的累积平均
实时全局光照方案
实时渲染中无法负担完整的路径追踪，需要各种近似和加速技术来实现可接受的间接光照效果。


屏幕空间全局光照（Screen Space Global Illumination, SSGI）从每个像素向屏幕空间发射短射线，使用深度缓冲作为近似的场景几何进行求交。它只能捕获屏幕上可见物体产生的间接光照，无法处理屏幕外物体的贡献。SSGI 的优势是完全动态且不需要预计算，但准确性有限且存在各种屏幕空间伪影。


光照探针（Light Probe）在场景中预放置或自动放置采样点，每个探针预计算或实时更新来自各方向的间接光照。


漫反射 GI 通常使用球谐函数（Spherical Harmonics, SH）编码，二阶 SH（9 个系数）足以表示低频漫反射光照。


运行时，每个表面点对最近的几个探针进行插值得到间接光照。


球谐光照计算:
irradiance(n) = Σᵢ Lᵢ × Yᵢ(n)

其中 Lᵢ = 第 i 个 SH 系数
     Yᵢ(n) = 方向 n 上的第 i 个 SH 基函数
L2 SH 使用 9 个系数 × 3 (RGB) = 27 个浮点数
Lumen（Unreal Engine 5）是当前最先进的实时 GI 系统。它使用多种技术的级联：屏幕空间追踪（近处高精度）、Mesh SDF 追踪（中距离）、全局 SDF 追踪（远距离）和辐射度缓存（Radiance Cache）。Lumen 在不使用硬件光追的情况下就能提供高质量的间接光照，有硬件光追时可以进一步提升精度。

实时光追 GI（RTGI）使用硬件加速的光线追踪发射少量间接光照射线（通常每像素 0.5-1 条），结合时空降噪器重建完整的间接光照。


这是精度最高的实时方案，但对 GPU 算力要求也最高。


烘焙光照贴图（Lightmap Baking）仍然是许多场景中不可替代的方案。它在离线阶段使用路径追踪为每个表面计算间接光照，结果存储为纹理（光照贴图）。


运行时仅需一次纹理采样即可获得高质量的间接光照——性能开销接近于零。


缺点是只适用于静态场景，动态物体需要额外的光照探针来获取间接光照。


光照贴图的 UV 展开（UV Unwrap for Lightmap）是一个独立的技术挑战。光照贴图的 UV 不同于漫反射纹理的 UV——它要求所有三角形在 UV 空间不重叠（因为每个表面点需要唯一的光照值），同时最小化 UV 空间的浪费。自动光照贴图 UV 展开通常使用贪心的图表打包算法，将网格拆分为若干连通的图表（Chart）并紧凑地排列在 UV 空间中。


辐射度传输（Precomputed Radiance Transfer, PRT）是另一种预计算方案。它将传输函数（Transfer Function）——描述表面点如何将入射光照转换为出射光照——预计算并用球谐系数存储。运行时只需将光照环境的 SH 系数与传输 SH 系数进行点积（极快的线性操作）即可得到间接光照。PRT 支持动态光照环境（如日夜变化），但不支持动态几何。


小结
    

  • 渲染方程描述了表面出射辐亮度等于自发光加入射光照的半球积分，具有递归性质
    • 

  • 路径追踪通过蒙特卡洛随机采样反弹方向求解渲染方程，大量路径收敛于精确解
    • 

  • 俄罗斯轮盘赌以与反照率成正比的概率终止路径，保持估计的无偏性
    • 

  • NEE 直接向光源采样，MIS 结合 BRDF 和光源采样，显著降低估计方差
    • 

  • 光子映射从光源端追踪光子，天然支持焦散等难以从相机端采样的光路
    • 

  • 渐进式光子映射通过多轮迭代和缩小搜索半径收敛到无偏的精确解
    • 

  • SH 光照探针用 27 个浮点数编码低频间接漫反射光照，运行时开销极低
    • 

  • Lumen 通过多种追踪技术的级联在不同距离范围提供不同精度的 GI
    • 

  • 烘焙光照贴图提供最高质量的静态 GI，PRT 支持动态光照环境
    • 

  • 实时光追 GI 结合硬件加速和时空降噪提供最高精度的动态间接光照
    •
