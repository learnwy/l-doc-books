光线追踪基础

核心概念

光线追踪（Ray Tracing）是一种通过模拟光线与场景交互来生成图像的渲染技术。其核心思想是从相机出发，向场景中每个像素发射射线，计算射线与几何体的交点和光照效果。

相比光栅化的局部处理方式，光线追踪天然支持全局光照效果——反射、折射、阴影和焦散等现象都是射线交互的自然结果。

光线追踪的基本循环：对于图像中的每个像素，从相机位置经过该像素向场景发射一条主光线（Primary Ray），找到最近的交点，然后在交点处计算着色。

着色可能需要向光源发射阴影光线（Shadow Ray）判断遮挡，向反射/折射方向发射次级光线（Secondary Ray）递归追踪。

光线追踪最初只用于离线渲染（电影、产品可视化），但随着 NVIDIA RTX 和 AMD RDNA2 引入硬件加速，实时光线追踪已进入游戏领域。当前的主流方案是混合管线——用光栅化处理主要的几何渲染，用光线追踪处理反射、阴影和间接光照。


射线-几何体求交
射线定义为 R(t) = O + t×D，其中 O 是起点，D 是方向，t > 0 是参数。射线与场景中每种几何体的求交是光线追踪的核心计算。


射线-球体求交是最简单的情况。球体中心 C、半径 r，联立方程得到关于 t 的二次方程：


|O + tD - C|² = r²
展开: (D·D)t² + 2D·(O-C)t + (O-C)·(O-C) - r² = 0

判别式 Δ = b² - 4ac
Δ < 0: 无交点
Δ = 0: 一个切点
Δ > 0: 两个交点，取较小的正 t
射线-三角形求交使用 Möller-Trumbore 算法，它同时计算交点的参数 t 和重心坐标 (u, v)，无需预计算三角形平面方程。算法通过克莱默法则求解线性方程组：


O + tD = (1-u-v)V₀ + uV₁ + vV₂

重写为: [-D, V₁-V₀, V₂-V₀] × [t, u, v]ᵀ = O - V₀

设 E₁ = V₁-V₀, E₂ = V₂-V₀, T = O-V₀
    P = D × E₂, Q = T × E₁

det = P · E₁
t = (Q · E₂) / det
u = (P · T) / det
v = (Q · D) / det

有效交点条件: t > 0, u ≥ 0, v ≥ 0, u+v ≤ 1
重心坐标 (u, v) 可以直接用于插值三角形的顶点属性（法线、UV、颜色），这与光栅化中的重心坐标功能相同。


射线-AABB 求交用于 BVH 遍历中的包围盒测试。Slab 方法计算射线与 AABB 三对平行平面的交区间 [tmin, tmax]，然后检查三个区间的交集是否非空。这个测试需要高度优化，因为在一次渲染中可能执行数十亿次。


对每个轴 i (x, y, z):
    t_near_i = (box_min_i - O_i) / D_i
    t_far_i  = (box_max_i - O_i) / D_i
    if t_near_i > t_far_i: swap

tmin = max(t_near_x, t_near_y, t_near_z)
tmax = min(t_far_x, t_far_y, t_far_z)
hit = tmax >= max(tmin, 0)
Whitted 光线追踪
Whitted 光线追踪（1980）是第一个完整的递归光线追踪算法。它在每个交点处计算：直接光照（对每个光源发射阴影光线）、镜面反射（发射反射光线递归）和折射（如果材质是透明的，发射折射光线递归），将所有贡献加权求和。


shade(point, normal, viewDir, depth):
    if depth > MAX_DEPTH: return black

    color = ambient

    for each light:
        shadowRay = Ray(point, lightDir)
        if not scene.intersect(shadowRay):
            color += diffuse + specular

    if material.reflective:
        reflectDir = reflect(viewDir, normal)
        reflectRay = Ray(point + epsilon * normal, reflectDir)
        color += material.kr * trace(reflectRay, depth + 1)

    if material.refractive:
        refractDir = refract(viewDir, normal, material.ior)
        refractRay = Ray(point - epsilon * normal, refractDir)
        color += material.kt * trace(refractRay, depth + 1)

    return color
折射方向由 Snell 定律计算：n₁ sinθ₁ = n₂ sinθ₂。当光线从光密介质进入光疏介质且入射角超过临界角时，发生全内反射——所有光线被反射而无折射。


菲涅尔方程决定了反射和折射的能量分配比例，Schlick 近似 F = F₀ + (1-F₀)(1-cosθ)⁵ 是实时渲染中的标准简化。


Whitted 光线追踪只处理理想的镜面反射和折射（"specular-to-specular" 路径），无法表现粗糙表面的模糊反射、漫反射间接光照（Color Bleeding）和焦散等效果。这些效果需要蒙特卡洛方法——路径追踪来解决。


阴影光线的一个优化是任意命中测试（Any-Hit Test）——不需要找到最近的交点，只需要知道射线是否被任何物体遮挡。这允许提前终止遍历，比最近命中测试（Closest-Hit）快得多。


对于半透明物体（如树叶、铁丝网），Any-Hit Shader 可以根据纹理的 Alpha 值决定是否接受命中。如果 Alpha 低于阈值则忽略当前交点继续追踪——这等价于光栅化中的 Alpha 测试但应用在光线追踪的上下文中。


射线标志位（Ray Flags）控制光线追踪的行为。OPAQUE 标志跳过 Any-Hit Shader 调用加速遮挡物体的处理；TERMINATE_ON_FIRST_HIT 在找到第一个交点后立即终止遍历（用于阴影测试）；CULL_BACK_FACING 剔除背面三角形。合理设置射线标志位可以显著减少不必要的着色器调用。


采样与降噪
实时光线追踪的核心挑战是每像素只能负担少量射线（通常 1-4 条），而物理上准确的光照需要大量采样才能收敛。这导致图像充满噪点。降噪（Denoising）技术通过智能滤波将低采样率的噪点图像恢复为干净的最终图像。


时空滤波利用相邻像素和历史帧的信息。空间滤波器（如联合双边滤波器）基于法线、深度和亮度的相似性从邻域像素借用采样信息。时间滤波器通过运动向量重投影历史帧数据，累积多帧的采样结果。SVGF（Spatiotemporal Variance-Guided Filtering）是实时光线追踪降噪的里程碑方案。


AI 降噪使用深度学习网络从极低采样率（如每像素 1 个样本）重建高质量图像。NVIDIA 的 OptiX AI Denoiser 和 Intel 的 Open Image Denoise 是两个主要的方案。它们接收颜色、法线和 Albedo 辅助缓冲区作为输入，利用训练好的神经网络推断去噪结果，甚至可以从 1 spp 的输入产生高质量结果。

重要性采样（Importance Sampling）是另一个减少噪点的关键技术。它根据 BRDF 或光照分布的概率密度函数（PDF）来引导射线方向——向光照贡献大的方向发射更多射线。例如对于 GGX 镜面反射，根据 NDF 的分布采样半角向量，使得大部分射线集中在高光区域。


这比均匀采样半球收敛快数个数量级。


蓝噪声（Blue Noise）采样模式相比白噪声在相同采样数下产生更均匀的空间分布，视觉上噪点更少。许多实时光追引擎使用蓝噪声纹理和 Sobol 序列等低差异序列生成时空稳定的采样模式。R2 序列（基于黄金比例的推广）是另一种优质的低差异序列，它在二维空间中产生的采样点分布比 Halton 序列更均匀。


分层采样（Stratified Sampling）将采样空间划分为等大小的子区域，每个子区域内取一个随机样本。这保证了样本在空间中的均匀分布，避免了纯随机采样可能出现的聚集现象。分层采样的方差下降速率为 O(1/N^(1+1/d))，优于纯随机采样的 O(1/N)，其中 d 是维度数。


多弹射光追与单弹射光追的区别在于性能和质量的权衡。单弹射光追只追踪一次间接反弹（如屏幕空间反射中的一条反射射线），快速但只能捕获最直接的间接光照。多弹射光追追踪完整的路径（多次反弹），产生更准确的全局光照但每像素需要更多射线。实际引擎通常对不同效果使用不同的弹射策略：反射用 1 次弹射，漫反射间接光用 1-2 次弹射，焦散可能需要专门的光子追踪。


混合渲染管线是当前游戏引擎的标准架构。光栅化用于主要的几何渲染（Primary Visibility），光线追踪用于选择性的高质量效果：RT 阴影提供精确的硬/软阴影，RT 反射替代 SSR 处理屏幕外的反射信息，RT 环境光遮蔽（RTAO）替代 SSAO 提供更准确的接触阴影，RT 全局光照提供物理准确的间接光照。每种效果可以独立启用和配置质量级别。


小结
    

  • 光线追踪从相机发射光线到场景中，天然支持精确的反射、折射和阴影
    • 

  • Möller-Trumbore 算法同时计算射线-三角形交点的参数 t 和重心坐标，是最高效的求交方法
    • 

  • Slab 方法用三对平行平面的交区间测试射线-AABB 求交，是 BVH 遍历的核心操作
    • 

  • Whitted 光追递归追踪镜面反射和折射路径，但无法处理漫反射间接光照
    • 

  • 全内反射发生在光线从光密介质以大角度入射到光疏介质时
    • 

  • 实时光追的核心挑战是低采样率下的噪点，需要时空滤波和 AI 降噪技术
    • 

  • 重要性采样根据 BRDF 分布引导射线方向，显著提升采样效率
    • 

  • 蓝噪声和低差异序列提供更均匀的采样分布，减少视觉噪点
    • 

  • 混合渲染管线用光栅化处理主要几何，用光追处理反射、阴影和间接光照
    • 

  • 多弹射和单弹射光追在精度与性能之间提供灵活的权衡选择
