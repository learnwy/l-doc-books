基于物理的渲染

核心概念

基于物理的渲染（Physically Based Rendering, PBR）是使用物理上合理的光照模型和材质描述来生成图像的方法论。与传统的经验模型不同，PBR 确保在任何光照条件下材质表现一致且可预测——金属在日光下看起来像金属，在室内光下依然像金属。

PBR 的三大基础原则：能量守恒——反射的光能不超过入射光能，表面越光滑镜面反射越强但面积越小；微表面理论——宏观表面由大量微小的完美镜面组成，粗糙度决定微表面朝向的分布；菲涅尔效应——所有物体在掠射角都呈现更强的反射。

PBR 在 2012-2014 年间被游戏行业广泛采用（Disney BRDF 论文和 Epic/EA 的 GDC 分享是里程碑事件），现在是所有主流游戏引擎和 DCC 工具的默认渲染方式。


PBR 的渲染方程基于辐射度量学（Radiometry）。表面某点在方向 ω_o 上的出射辐亮度 L_o 是对半球上所有入射方向的积分：


L_o(p, ω_o) = ∫_Ω f_r(p, ω_i, ω_o) × L_i(p, ω_i) × (n · ω_i) dω_i

其中:
f_r = BRDF（双向反射分布函数）
L_i = 入射辐亮度
n · ω_i = 余弦项（Lambert 余弦定律）
Ω = 上半球
这个积分在实时渲染中无法精确求解，需要通过各种近似和预计算来逼近。对于直接光照（点光源、方向光），积分退化为对离散光源的求和；对于间接光照（环境光），使用 IBL 等预计算技术。


Cook-Torrance BRDF
BRDF（Bidirectional Reflectance Distribution Function，双向反射分布函数）描述了表面如何将入射光反射到出射方向。Cook-Torrance 微表面 BRDF 是 PBR 中使用最广泛的镜面反射模型，它将镜面 BRDF 分解为三个物理意义明确的函数的乘积：


    

  • 法线分布函数 D（Normal Distribution Function）：描述微表面法线的统计分布
    • 

  • 菲涅尔方程 F（Fresnel）：描述不同入射角下的反射率
    • 

  • 几何遮蔽函数 G（Geometry）：描述微表面的自遮挡效应
    • 



f_r(ω_i, ω_o) = f_diffuse + f_specular

f_specular = D(h) × F(ω_o, h) × G(ω_i, ω_o, h)
             ─────────────────────────────────────
                    4 × (n · ω_i) × (n · ω_o)

其中:
D(h) = 法线分布函数 (Normal Distribution Function)
F    = 菲涅尔函数 (Fresnel)
G    = 几何遮蔽函数 (Geometry)
h    = 半角向量 = normalize(ω_i + ω_o)
法线分布函数 D 描述微表面法线朝向半角向量 h 方向的概率密度。GGX（Trowbridge-Reitz）分布是当前最常用的 NDF：


D_GGX(h) = α² / (π × ((n·h)² × (α² - 1) + 1)²)

α = roughness²（粗糙度的平方）
GGX 相比 Beckmann 分布有更长的"尾巴"——在远离高光中心的区域衰减更慢，产生更自然的高光渐变。这种长尾特性更符合真实材质的测量数据。


菲涅尔函数 F 描述反射率随入射角的变化。Schlick 近似是实时渲染的标准选择：


F_Schlick(ω_o, h) = F₀ + (1 - F₀) × (1 - (ω_o · h))⁵

F₀ = 垂直入射时的反射率
电介质: F₀ ≈ 0.04 (塑料、石头、水)
金属:   F₀ = 材质颜色 (金 = (1.0, 0.71, 0.29))
几何遮蔽函数 G 模拟微表面之间的相互遮挡。Smith 方法将遮蔽（入射方向）和阴影（出射方向）分开计算：


G_Smith(ω_i, ω_o) = G₁(ω_i) × G₁(ω_o)
G₁_GGX(ω) = (n·ω) / ((n·ω) × (1 - k) + k)
k = α² / 2 (IBL) 或 (α + 1)² / 8 (直接光照)
金属度-粗糙度工作流
PBR 有两种主流的材质参数工作流。金属度工作流（Metallic-Roughness）由 Disney/UE4 推广，使用金属度（metallic）和粗糙度（roughness）两个参数。镜面反射工作流（Specular-Glossiness）使用高光颜色（specular）和光泽度（glossiness）。


金属度工作流更简洁直观——美术只需在"金属"和"非金属"之间滑动一个参数。金属度为 0 时 F₀ 固定为 0.04，基础颜色作为漫反射色使用；金属度为 1 时没有漫反射，基础颜色作为 F₀（镜面反射颜色）使用。中间值表示过渡区域（如生锈金属表面）。


glTF 2.0 和 UE4 采用金属度工作流，Unity 同时支持两种。金属度工作流的 Base Color 纹理通常比镜面反射工作流的 Diffuse 纹理更紧凑，因为金属表面的基础颜色也编码了反射色信息。


标准 PBR 着色器的核心计算：


vec3 F0 = mix(vec3(0.04), albedo, metallic);
vec3 diffuseColor = albedo * (1.0 - metallic);

vec3 H = normalize(V + L);
float NDF = DistributionGGX(N, H, roughness);
float G = GeometrySmith(N, V, L, roughness);
vec3 F = fresnelSchlick(max(dot(H, V), 0.0), F0);

vec3 numerator = NDF * G * F;
float denominator = 4.0 * max(dot(N, V), 0.0) * max(dot(N, L), 0.0) + 0.0001;
vec3 specular = numerator / denominator;

vec3 kD = (vec3(1.0) - F) * (1.0 - metallic);
vec3 Lo = (kD * diffuseColor / PI + specular) * radiance * NdotL;
图像基础光照
图像基础光照（Image-Based Lighting, IBL）使用环境贴图作为光源，为 PBR 提供真实的间接光照。IBL 将光照积分分解为漫反射辐照度和镜面反射两部分，分别预计算。


漫反射部分使用辐照度图（Irradiance Map）——对环境贴图在半球上进行卷积，预计算每个法线方向接收的总漫反射辐照度。辐照度图分辨率很低（32×32 即可），因为漫反射变化平缓。


镜面反射部分使用 Split-Sum 近似（Epic 2013 提出）：将镜面积分拆为两个预计算项的乘积。第一项是预过滤环境贴图（Pre-filtered Environment Map），对环境贴图在不同粗糙度级别下进行重要性采样卷积，存储为 Mipmap 链——Mip 0 是镜面反射（粗糙度=0），高级 Mip 是粗糙反射。第二项是 BRDF 积分图（BRDF LUT），一个 2D 查找纹理，x 轴为 NdotV，y 轴为粗糙度，存储菲涅尔缩放系数和偏移量。


vec3 irradiance = texture(uIrradianceMap, N).rgb;
vec3 diffuse = irradiance * albedo * (1.0 - metallic);

float lod = roughness * MAX_REFLECTION_LOD;
vec3 prefilteredColor = textureLod(uPrefilterMap, R, lod).rgb;
vec2 brdfLUT = texture(uBRDFLut, vec2(NdotV, roughness)).rg;
vec3 specular = prefilteredColor * (F0 * brdfLUT.x + brdfLUT.y);

vec3 ambient = diffuse + specular;
IBL 的预计算步骤通常在离线或加载时完成。对于动态环境（如天气变化），可以使用屏幕空间反射（SSR）或实时探针（Light Probe）来补充 IBL 信息。许多引擎支持多级光照探针——全局 Cubemap 提供远距离反射，局部探针（Box Projection）提供室内等有界空间的反射校正，SSR 提供最精确的近距离反射。这三层按照精度由高到低逐级回退。


屏幕空间反射（Screen Space Reflections, SSR）通过在深度缓冲中进行光线步进来生成反射图像。它只能反射屏幕上可见的内容——当反射物体不在屏幕范围内时 SSR 会失效，需要回退到 IBL。SSR 与 IBL 的混合通常基于置信度（命中率和菲涅尔因子）来平滑过渡。


PBR 工作流中还经常使用环境遮蔽（Ambient Occlusion, AO）来增强接触阴影的真实感。AO 描述了表面上每个点被周围几何体遮蔽环境光的程度。预烘焙的 AO 贴图提供静态遮蔽信息，SSAO（Screen Space Ambient Occlusion）和 GTAO（Ground Truth AO）在屏幕空间实时计算动态遮蔽。AO 作为乘法因子应用于漫反射和部分镜面反射的间接光照分量。


多散射补偿（Multi-Scattering Compensation）是 PBR 的一个重要改进。标准的 Cook-Torrance 单散射 BRDF 在高粗糙度时会丢失大量能量——微表面之间的多次反弹被忽略了。Kulla & Conty（2017）提出了一种补偿项来恢复这部分丢失的能量，使得粗糙金属表面不再显得过暗。这个补偿项可以预计算为二维 LUT，运行时开销极小。

小结
    

  • PBR 基于能量守恒、微表面理论和菲涅尔效应三大物理原则
    • 

  • 渲染方程描述了表面出射辐亮度，实时渲染通过离散化和预计算来近似求解
    • 

  • Cook-Torrance BRDF 由法线分布（GGX）、菲涅尔（Schlick）和几何遮蔽（Smith）三个函数组成
    • 

  • GGX 的长尾特性产生更自然的高光过渡，是当前 PBR 的标准法线分布函数
    • 

  • 金属度工作流用一个参数控制金属/非金属切换，是当前最主流的 PBR 参数化方案
    • 

  • 菲涅尔效应使所有材质在掠射角呈现更强的反射，金属的 F₀ 等于其基础颜色
    • 

  • IBL 通过 Split-Sum 近似将环境光照积分分解为预过滤环境贴图和 BRDF LUT 的乘积
    • 

  • SSR 补充屏幕可见区域的镜面反射信息，与 IBL 基于置信度混合
    • 

  • 环境遮蔽作为乘法因子增强接触阴影的真实感
    • 

  • 多散射补偿恢复高粗糙度下微表面间多次反弹丢失的能量
    • 

  • PBR 保证材质在任意光照环境下表现一致，大幅简化了美术资产的制作流程
    •
