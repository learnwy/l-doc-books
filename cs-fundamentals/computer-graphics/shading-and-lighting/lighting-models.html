光照模型

核心概念

光照模型（Lighting Model）是计算机图形学中描述光与物体表面交互方式的数学模型。它决定了渲染图像中物体表面的明暗、色彩和质感。从简单的环境光到复杂的全局光照，光照模型的选择直接影响渲染的真实感和计算成本。

光照模型通常分为两大类：局部光照（Local Illumination）只考虑光源、表面和观察者之间的直接关系；全局光照（Global Illumination）还考虑光在场景中多次反弹的间接照明效果。实时渲染主要使用局部光照模型辅以各种近似技术来模拟全局效果。

Lambert 漫反射模型
Lambert 漫反射模型是最基础的光照模型，它假设光线打到表面后向所有方向均匀散射（理想漫反射），观察角度不影响表面亮度。表面的亮度仅取决于光线入射角——光线越垂直表面越亮。


数学表达式为表面法线 N 和光线方向 L 的点积：


I_diffuse = k_d × I_light × max(N · L, 0)

其中:
k_d = 漫反射系数（材质颜色）
I_light = 光源强度
N = 表面法线（单位向量）
L = 指向光源的方向（单位向量）
max() 确保背光面不产生负值亮度
Lambert 模型虽然简单，但对于哑光材质（如粉笔、粗糙墙壁）的近似效果相当好。它的局限在于无法表现镜面高光，且对粗糙表面的明暗过渡处理不够真实——实际的粗糙表面在掠射角会显得更亮（Oren-Nayar 模型修正了这一点）。


环境光（Ambient Light）通常作为常量项添加，模拟来自所有方向的间接照明：


I_ambient = k_a × I_ambient_light
这是最简化的全局光照近似，它确保场景中没有完全黑色的区域。更高级的环境光方案包括半球光照（上方天空色 + 下方地面色的线性插值）和球谐函数（Spherical Harmonics）编码的环境光。


环境光的质量直接影响非直射光区域的视觉效果。过强的常量环境光会使场景看起来"平"，缺乏对比度和深度感。在现代渲染中，常量环境光通常被更精细的间接光照技术替代——如 IBL（基于图像的光照）或预烘焙的光照探针。


自发光材质（Emissive Material）是光照模型中的特殊情况。自发光不受外部光照影响，直接为像素贡献固定的颜色值。在 HDR 渲染管线中，自发光值可以超过 1.0，与 Bloom 后处理结合产生发光效果。自发光在 PBR 工作流中通过 Emissive 贴图控制——只有标记为发光的区域才有自发光贡献。


Phong 与 Blinn-Phong 高光模型
Phong 光照模型在 Lambert 漫反射基础上增加了镜面反射（Specular Reflection）分量，模拟光滑表面的高光效果。镜面反射的强度取决于观察方向 V 与光线反射方向 R 的夹角：


R = 2(N · L)N - L
I_specular = k_s × I_light × max(R · V, 0)^n

n = 光泽度指数，值越大高光越集中
Blinn-Phong 模型用半角向量 H = normalize(L + V) 替代反射向量 R，比较 N 和 H 的夹角：


H = normalize(L + V)
I_specular = k_s × I_light × max(N · H, 0)^n
Blinn-Phong 在以下方面优于原始 Phong：计算效率更高（避免了反射向量的计算）、在掠射角的高光表现更符合物理直觉、当光源和视点都在无穷远时 H 为常量可以进一步优化。因此 Blinn-Phong 成为了 OpenGL 固定管线和早期实时渲染的标准选择。


完整的 Phong / Blinn-Phong 光照方程将三个分量组合：


I_total = I_ambient + I_diffuse + I_specular
        = k_a × I_a + k_d × I_l × max(N·L, 0) + k_s × I_l × max(N·H, 0)^n
光泽度指数 n 控制高光的大小和锐度。典型值范围：哑光塑料约 10-30，光滑金属约 100-500，镜面约 1000+。在 PBR 工作流中，这个指数被粗糙度参数替代，提供更直观的美术控制。


光源类型与衰减
实时渲染中使用多种光源类型来模拟不同的照明场景。每种光源类型有不同的数学描述和计算特性。


方向光（Directional Light）模拟无穷远处的光源（如太阳），所有光线平行，无距离衰减。它是计算最简单的光源类型，对场景中所有物体的照明方向相同。


点光源（Point Light）从一个点向所有方向均匀发射光线，光线强度随距离衰减。物理上正确的衰减遵循平方反比定律 1/d²，但在实时渲染中通常使用经验衰减公式以获得更可控的效果：


attenuation = 1.0 / (constant + linear × d + quadratic × d²)
聚光灯（Spot Light）在点光源基础上增加了方向和锥角限制。内锥角（inner cone）内的区域获得全部光照强度，内外锥角之间的区域平滑衰减，外锥角（outer cone）之外完全不受光照。锥角之间的衰减通常使用余弦插值：


theta = dot(lightDir, -spotDirection)
intensity = clamp((theta - outerCos) / (innerCos - outerCos), 0, 1)
面光源（Area Light）从一个有面积的区域发光，产生自然的软阴影和柔和的光照过渡。面光源的精确计算需要在光源表面进行积分，实时渲染中通常使用 LTC（Linearly Transformed Cosines）或其他近似方法。


现代渲染引擎通常需要处理大量光源。前向渲染（Forward Rendering）中每个物体对所有影响它的光源逐一计算光照，光源数量增加时性能线性下降。延迟渲染（Deferred Rendering）先将几何信息写入 G-Buffer（位置、法线、材质参数），再在全屏 Pass 中对每个光源进行光照计算。延迟渲染将光照计算与几何复杂度解耦，使得大量光源的场景变得可行。


分簇前向渲染（Clustered Forward Rendering）结合了两者的优点：将视锥体划分为三维的簇（Cluster），每个簇维护影响它的光源列表。着色时每个片元只需遍历所在簇中的少量光源。这种方法在透明物体渲染上优于延迟渲染（延迟渲染不支持透明物体），同时保持了多光源的高效处理。

着色频率与插值
同一个光照模型可以在不同频率下计算，产生不同的视觉效果和性能开销。


平面着色（Flat Shading）对每个三角形只计算一次光照，整个三角形呈现均匀颜色。它能清晰地看到多面体的各个面，适合低多边形风格的艺术效果，但无法表现平滑曲面。


Gouraud 着色对每个顶点计算光照，然后在三角形内部线性插值颜色值。它的计算量与顶点数成正比，比逐像素着色快得多。但 Gouraud 着色会丢失三角形内部的高光——如果高光中心在三角形内部而不在任何顶点上，高光会完全消失。


Phong 着色（注意区分 Phong 光照模型）对每个顶点的法线进行插值，在每个像素处使用插值后的法线重新计算光照。它能正确渲染三角形内部的高光，是现代实时渲染的标准着色方式。


逐像素着色在可编程着色器时代成为默认选择。但对于大量微小三角形（如高密度网格），逐顶点着色可能比逐像素着色更高效，因为片元数量远大于顶点数量。一些现代引擎在远景 LOD 中回退到顶点着色以节省 GPU 开销。


半球光照（Hemisphere Lighting）是一种比常量环境光更真实的近似。它使用两种颜色——天空色和地面色——根据法线的朝向在两者之间线性插值。法线朝上的面接收天空色，朝下的面接收地面色，中间角度平滑过渡。这种方法简单高效，在户外场景中效果显著优于单色环境光。


球谐光照（Spherical Harmonics Lighting, SH）使用球谐函数系数编码来自所有方向的光照信息。二阶球谐（9 个系数）足以精确表示低频的漫反射光照环境，存储极为紧凑。许多引擎使用球谐光照探针（Light Probe）在场景中放置采样点，运行时对相邻探针插值来获取每个物体的间接漫反射光照。


小结
    

  • Lambert 模型用法线和光线方向的余弦值计算漫反射，是所有光照模型的基础
    • 

  • Blinn-Phong 用半角向量替代反射向量计算高光，效率更高且效果更好
    • 

  • 光泽度指数控制高光大小和锐度，值越大高光越集中越锐利
    • 

  • 点光源使用距离衰减模拟真实光照，聚光灯增加锥角限制
    • 

  • 面光源产生最真实的软阴影和光照过渡，但计算成本也最高
    • 

  • 延迟渲染和分簇前向渲染解决了大量光源的效率问题
    • 

  • Phong 着色通过法线插值和逐像素光照计算获得最高质量的着色效果
    • 

  • 球谐光照用极少的系数编码低频间接光照，是轻量级全局光照近似的标准方法
    • 

  • 着色频率的选择需要在视觉质量和性能之间权衡
    • 

  • 自发光材质直接贡献颜色值不受外部光照影响，在 HDR 管线中驱动 Bloom 效果
    •
