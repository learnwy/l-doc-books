纹理映射

核心概念

纹理映射（Texture Mapping）是将二维图像"贴"到三维物体表面的技术。它是计算机图形学中表现表面细节最重要的手段——通过纹理可以在不增加几何复杂度的前提下，为物体添加丰富的颜色、凹凸、光泽和透明度等视觉信息。

纹理映射的基本原理是建立三维表面点与二维纹理图像之间的对应关系。每个顶点携带一组纹理坐标（UV 坐标），通常范围在 [0,1]。

光栅化阶段对 UV 坐标进行透视校正插值，片元着色器根据插值后的 UV 从纹理中采样颜色值。

UV 展开（UV Unwrapping）是为三维模型创建纹理坐标的过程。目标是将三维表面"展开"到二维平面上，同时最小化拉伸（Stretch）和接缝（Seam）。自动 UV 展开算法（如 ABF++、LSCM）使用共形映射或最小化角度变形的方法；手工 UV 编辑在需要精确控制纹理分布的情况下仍然必要。UV 的质量直接影响纹理的利用率和纹素密度的均匀性。

纹理过滤与采样
当纹理的分辨率与屏幕像素不完全一一对应时，需要纹理过滤（Texture Filtering）来决定如何从离散的纹素（Texel）中采样得到连续的颜色值。


最近邻过滤（Nearest）选择距离采样点最近的纹素，产生锐利但有马赛克感的效果。适用于像素风格游戏或需要精确纹素对齐的 UI。


双线性过滤（Bilinear）对采样点周围 2×2 的纹素进行加权平均，产生平滑的过渡。这是最常用的纹理过滤方式，但在观察角度倾斜时（如地面远处）会产生模糊。


三线性过滤（Trilinear）在双线性基础上，对相邻两级 Mipmap 进行插值，消除 Mipmap 级别之间的明显跳变（"Mip 带"现象）。


各向异性过滤（Anisotropic Filtering, AF）是最高质量的过滤方式。当表面相对于相机高度倾斜时，纹理在一个方向被极度压缩。


各向异性过滤沿压缩方向采样更多纹素，保持倾斜表面的纹理清晰度。8x 或 16x AF 是现代游戏的标准配置，性能开销较小但视觉提升显著。


uniform sampler2D uTexture;

void main() {
    vec4 nearest = texelFetch(uTexture, ivec2(uv * textureSize(uTexture, 0)), 0);
    vec4 filtered = texture(uTexture, uv);
    vec4 biased = texture(uTexture, uv, -1.0);
}
纹理环绕模式（Wrap Mode）控制 UV 超出 [0,1] 范围时的行为：REPEAT 循环平铺，CLAMP_TO_EDGE 钳制到边缘纹素，MIRRORED_REPEAT 镜像重复。选择正确的环绕模式对于避免纹理边缘的可见接缝至关重要。

纹理采样器在 GPU 中是专门的硬件单元（Texture Mapping Unit, TMU），与 ALU 计算单元并行工作。合理安排纹理采样指令和计算指令的交错执行，可以让 TMU 和 ALU 同时保持忙碌，最大化着色器吞吐量。


Mipmap 技术
Mipmap 是纹理的预计算多级缩小版本链。Level 0 是原始分辨率，Level 1 是半分辨率，以此类推直到 1×1。总共增加约 33% 的存储开销。


GPU 根据片元着色器中纹理坐标的偏导数（dFdx, dFdy）自动选择 Mipmap 级别。偏导数反映了屏幕空间一个像素对应纹理空间多大的区域——区域越大，说明纹理被缩小越多，应该使用更低分辨率的 Mipmap 级别。


Mipmap 解决了两个关键问题：


性能优化——远处物体使用低分辨率 Mipmap，显著减少纹理缓存未命中率。一个远处仅占几个像素的物体如果采样原始 1024×1024 纹理，会在纹理缓存中产生大量随机访问；使用 8×8 的 Mipmap 则只需访问极少的缓存行。


Mipmap 的额外存储开销仅为原始纹理的 1/3（等比级数求和），但带来的质量提升和性能优化是巨大的。


抗锯齿——不使用 Mipmap 的远处纹理会出现摩尔纹和闪烁（纹理走样）。Mipmap 相当于预先进行了低通滤波，避免了高频纹理信息的走样。


Mipmap 生成通常使用 Box 滤波器（2×2 平均），但对于法线贴图等非颜色数据，需要使用专门的滤波方法。法线贴图的 Mipmap 应该对法线进行正确的归一化平均，否则低级 Mipmap 会产生不正确的光照效果。


虚拟纹理（Virtual Texturing）是处理超大纹理的技术。类似于操作系统的虚拟内存，虚拟纹理将巨大的纹理空间（如 128K×128K）划分为小的 Tile（通常 128×128 像素），只将当前帧需要的 Tile 加载到 GPU 显存的物理纹理缓存中。通过一个间接纹理（Page Table）将虚拟 UV 映射到物理 Tile 位置。这种技术在开放世界游戏中广泛使用，允许整个地形使用一张逻辑上无缝的超大纹理。


纹理数组与无绑定纹理（Bindless Textures）是减少 Draw Call 的重要技术。传统的纹理绑定模型限制了每次绘制调用可用的纹理数量（通常 16-32 个绑定槽）。纹理数组将多张同尺寸纹理打包为一个数组资源，无绑定纹理通过 64 位句柄直接在着色器中引用任意纹理，彻底消除了绑定槽数量的限制。


立方体贴图（Cubemap）是由 6 个面组成的环境纹理，用于天空盒和反射映射。采样时使用三维方向向量而非二维 UV 坐标，GPU 自动确定命中的面并在面内进行双线性插值。立方体贴图的接缝（边和角的过渡）在早期硬件上是问题，现代 GPU 支持无缝立方体贴图过滤（Seamless Cubemap Filtering），在面边界自动采样相邻面的纹素。


3D 纹理（Volume Texture）是三维的纹素阵列，使用三维 UVW 坐标采样。它在体积渲染（如烟雾、云层）和预计算的 LUT（如色彩校正 3D LUT）中使用。3D 纹理的内存消耗与分辨率的立方成正比，因此通常使用较低的分辨率（如 64³ 或 128³）。


法线贴图与凹凸映射
法线贴图（Normal Mapping）是在不增加几何细节的情况下表现表面凹凸的核心技术。法线贴图存储每个纹素处的表面法线偏移，片元着色器使用纹理中的法线替代几何法线进行光照计算，产生凹凸的视觉效果。


法线贴图中的法线通常存储在切线空间（Tangent Space）中。切线空间以表面的切线（T）、副切线（B）和法线（N）为基向量。纹理中 RGB 值编码切线空间法线：R→X, G→Y, B→Z，从 [0,1] 映射到 [-1,1]。因此法线贴图呈现特征性的蓝紫色——大部分法线接近 (0,0,1) 即指向表面外侧。


vec3 normalMap = texture(uNormalMap, vTexCoord).rgb * 2.0 - 1.0;

mat3 TBN = mat3(vTangent, vBitangent, vNormal);
vec3 worldNormal = normalize(TBN * normalMap);
TBN 矩阵从切线空间变换到世界空间。切线向量 T 和副切线 B 通常在顶点数据中预计算并传入着色器。计算方法基于 UV 坐标的偏导数：


设三角形三个顶点的位置差 ΔP₁, ΔP₂ 和 UV 差 ΔUV₁, ΔUV₂:
T = (ΔUV₂.v × ΔP₁ - ΔUV₁.v × ΔP₂) / (ΔUV₁.u × ΔUV₂.v - ΔUV₂.u × ΔUV₁.v)
B = cross(N, T) × handedness
视差贴图（Parallax Mapping）在法线贴图基础上增加了基于高度图的 UV 偏移，产生更强的深度感。基础视差贴图只做一次偏移，效果有限；陡峭视差映射（Steep Parallax Mapping）沿视线方向步进多次直到与高度场相交，可以模拟显著的凹凸和自遮挡效果。视差遮蔽映射（Parallax Occlusion Mapping, POM）在陡峭视差基础上增加了交点精确化和自阴影计算。

纹理压缩与格式
纹理往往是 GPU 内存的最大消耗者。未压缩的 RGBA8 纹理每纹素 4 字节，一张 4096×4096 的纹理就占用 64MB。纹理压缩在保持可接受视觉质量的同时大幅减少显存占用和带宽消耗。


GPU 纹理压缩格式与 JPEG/PNG 等 CPU 压缩格式不同——它支持随机访问，GPU 可以直接从压缩数据中解码任意纹素，无需解压整张纹理。这是通过将纹理划分为固定大小的块（Block）并独立压缩每个块来实现的。


BC/DXT 系列是桌面 GPU 的标准压缩格式。BC1（DXT1）将 4×4 像素块压缩为 8 字节（4:1 压缩比），BC3（DXT5）支持独立的 Alpha 通道，BC5 用于法线贴图（两通道），BC7 提供最高质量的通用压缩。


ASTC（Adaptive Scalable Texture Compression）是移动端的主流格式，支持从 4×4 到 12×12 的可变块大小，可以在质量和压缩比之间灵活权衡。ASTC 也逐渐被桌面 GPU 支持。


Basis Universal 是一种超级压缩格式（Supercompressed），可以在运行时快速转码为目标平台的原生格式（BC/ETC/ASTC）。它非常适合需要跨平台分发的纹理资源。

在纹理资产管线中，美术通常以无损格式（PSD/PNG/EXR）工作，构建系统负责根据目标平台自动选择并压缩为合适的 GPU 格式。现代构建系统还支持自适应质量——对画面中重要的纹理使用更高质量的压缩参数，次要纹理使用更激进的压缩。纹理流式加载（Texture Streaming）进一步优化了显存使用——只加载当前帧需要的 Mipmap 级别，高分辨率的 Mip 0 级别只在相机足够接近时才加载到显存中。


纹理 Atlasing 是将多张小纹理打包到一张大纹理中的技术。它减少了渲染时的纹理绑定切换（每次切换纹理都会打断 GPU 的渲染批次）。Sprite 图集、Light Cookie 图集和 Decal 图集都是这种技术的应用。图集的 UV 需要仔细计算以避免跨纹理边界的滤波问题——通常需要在每张子纹理周围留出 padding 边框。


小结
    

  • 纹理映射通过 UV 坐标建立三维表面到二维图像的对应关系
    • 

  • 各向异性过滤在倾斜角度下保持纹理清晰，是现代渲染的标准配置
    • 

  • TMU 与 ALU 并行工作，合理交错采样和计算可最大化吞吐量
    • 

  • Mipmap 通过预计算的多级分辨率链同时解决性能和走样问题
    • 

  • 虚拟纹理将超大纹理空间按需加载，解决开放世界的纹理管理难题
    • 

  • 法线贴图在切线空间存储法线偏移，通过 TBN 矩阵变换到世界空间进行光照
    • 

  • 视差遮蔽映射通过沿视线步进高度场产生更强的凹凸和自遮挡效果
    • 

  • GPU 纹理压缩支持随机访问解码，BC7 和 ASTC 是当前最高质量的压缩格式
    • 

  • Basis Universal 实现了跨平台纹理分发的统一方案
    • 

  • 无绑定纹理消除了传统绑定槽数量的限制，是现代 GPU 资源管理的趋势
    • 

  • 立方体贴图用于环境反射和天空盒，现代 GPU 支持无缝过滤
    • 

  • 3D 纹理用于体积渲染和色彩校正 LUT，内存消耗与分辨率的立方成正比
