玛格丽特·撒切尔：国内冲突与改革

本主题聚焦撒切尔执政十一年半（1979—1990）在英国本土引爆的政治对抗：街头骚乱、税制抗命、北爱绝食与爆炸、内阁中枢决裂，以及对地方政府与公共服务的强力重塑。它不讲经济理论本身，也不讲对外战争与外交——而专注于"撒切尔主义在国内落地时撞上了谁、付出了什么代价"。

本 hub 与兄弟 hub 的分工边界

撒切尔人物库共六个 hub，分工如下。读本 hub 前先知道"什么不在这里"：

Hub 管什么 与本 hub 的边界
2_崛起之路 出身、入政、登顶党魁 1979 年上台之前的故事
3_撒切尔主义 经济与意识形态蓝图（货币主义、私有化、工会立法、矿工大罢工） 提供本 hub 冲突的政策成因；矿工大罢工归在那里
5_国内冲突与改革（本 hub） 蓝图落地引发的国内政治对抗：骚乱、人头税、北爱、内阁危机、地方/教育削权 只讲冲突事件本身，政策原理回到 hub 3
4_福克兰与外交 对外战争、冷战、欧洲、香港 北爱属"国内安全"留在本 hub；对外则在那里
6_遗产 长程历史评价与文化记忆 本 hub 讲"当时发生了什么"，遗产 hub 讲"后世如何评价"

一句话：hub 3 是"为什么这么做"，本 hub 是"做了之后炸了什么"，hub 6 是"几十年后怎么看"。

内容地图（3 章 7 篇）

  • 第一章 街头与社会对抗：1981 年内城骚乱（布里克斯顿/托克斯泰思/斯卡曼报告）、人头税与撒切尔的政治终局。
  • 第二章 北爱尔兰与安全：1981 年绝食抗议（鲍比·桑兹）、1984 年布莱顿爆炸案、1985 年《英爱协议》。
  • 第三章 权力中枢与制度重塑：1986 年韦斯特兰事件、废除 GLC / 第28条款 / 1988 教育改革法。

推荐学习路径（分人群）

  • 政治史入门读者：按"街头 → 北爱 → 中枢"顺序通读，先看戏剧性最强的人头税与绝食抗议，建立对"撒切尔式冲突"的整体感。
  • 想理解撒切尔执政风格者：直奔第三章韦斯特兰事件 + 人头税两篇——它们最集中地暴露了她后期独断、听不进警告、宁可承受代价也不"掉头"的特质，并直接通向 1990 年逼宫。
  • 关注北爱/反恐者：第二章三篇按"绝食 → 布莱顿 → 英爱协议"顺序读，可看清"强硬到顶点"与"务实让步"如何并行不悖，并接续到 hub 6 看其长程遗产。
  • 跨学科读者：每篇文末"延伸阅读与跨学科链接"会把事件接入政治学（政策失败、政治暴力、行政权、新公共管理）、社会学（社会运动、政治机会结构）与法律（平等权）等通用框架。

前置知识

  • 建议先读 3_撒切尔主义（至少"货币主义与紧缩""工会与矿工大罢工"两篇）——内城骚乱、人头税、地方削权的成因都根植于那套经济与反工会蓝图。
  • 北爱章节若不熟悉"联合派 / 民族派 / 共和军"基本格局，可在阅读时对照政治学 hub 的"政治暴力与冲突"专题。
  • 无需经济学专业背景；所有关键日期、人物、文件均经核实，并参考截至 2025—2026 年陆续解密的政府档案与最新史学评价。
