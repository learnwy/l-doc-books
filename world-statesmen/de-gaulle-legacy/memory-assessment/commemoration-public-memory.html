Part VI · 夏尔·戴高乐夏尔·戴高乐：历史影响与评价历史记忆与评价公共纪念与记忆政治

公共纪念与记忆政治

戴高乐留下的最广泛、也最日常的遗产，或许是他无处不在的名字。从巴黎戴高乐机场（Aéroport Paris-Charles-de-Gaulle）到法国海军的核动力航空母舰"戴高乐号"，从遍布全国的街道、广场到科隆贝的纪念馆，这位拒绝国葬的将军，反而获得了一种渗透进国家肌理的纪念。理解戴高乐的历史地位，必须考察这套公共记忆是如何被建构、维系并代代相传的。

核心概念

戴高乐的公共记忆并非自然形成，而是由仪式、机构、地名与教育共同建构的产物。它呈现出一个由"事件—机构—载体"构成的传承链条。

2020年"戴高乐年"：记忆的高峰

2020年构成了一个罕见的"三重周年"：戴高乐诞辰130周年、逝世50周年、以及1940年6月18日"伦敦号召"80周年。法国官方将这一年定为"戴高乐年"（Année de Gaulle），举办了贯穿全年的系列纪念活动。

这些活动的安排，本身就是一种记忆政治的编排。5月17日，马克龙总统在蒙科尔内主持1940年战役80周年纪念，强调抵抗精神；6月18日，伦敦与巴黎两地纪念"伦敦号召"，重温自由法国的起点；11月9日，纪念活动来到科隆贝双教堂村——戴高乐长眠之地，呼应逝世50周年。官方话语将戴高乐塑造为"抵抗精神、共和精神与民族精神"的三重化身，使其超越具体政绩，升华为民族团结的象征。

记忆机构与传承焦虑

随着戴高乐同时代人的日渐凋零，如何将其遗产传给没有亲历记忆的新一代，成为一项现实挑战。承担这一使命的核心机构，是戴高乐基金会（Fondation Charles de Gaulle）。基金会通过档案保存、出版资助、教育项目与纪念活动，系统地维系并传播戴高乐的形象。

值得注意的是，在2020年周年前后，竟有不下二十部新的戴高乐传记与研究问世。这一现象的双重含义耐人寻味：一方面，它显示戴高乐仍是历史学界与公众持续关注的对象，记忆并未冷却；另一方面，对"如何传承遗产"的密集讨论，本身也暴露出一种焦虑——当最后一批亲历者离去，戴高乐究竟会成为活的政治资源，还是仅仅化为教科书中的纪念雕像？

物质载体与日常记忆

戴高乐记忆的物质载体及其象征功能，可列表如下：

载体 命名/所在地 象征意义
巴黎戴高乐机场 巴黎 国家门户与国家声望的绑定
"戴高乐号"核动力航母 法国海军 与军事威望、国家独立的绑定
科隆贝纪念馆 科隆贝双教堂村 缅怀的实体空间
洛林十字架 科隆贝 戴高乐与自由法国的标志

公共记忆不仅活在仪式与著作中，更沉淀在日常生活的物质载体里。巴黎主要国际机场以戴高乐命名，法国唯一的核动力航母以"戴高乐号"为名，象征着将军与国家独立、军事威望的绑定。科隆贝的纪念馆与高达数十米的洛林十字架（戴高乐与自由法国的标志），则成为缅怀的实体空间。

这些载体的意义在于，它们把抽象的历史评价转化为可触可见的日常存在。一个法国人即便从未读过《战争回忆录》，也会在乘机、看新闻、走过街道时，反复遭遇戴高乐的名字。正是这种渗透进日常肌理的纪念，使戴高乐成为少数几个能够超越党派、被广泛共享的民族象征——这种地位，恰恰是他生前那场简朴葬礼所未曾预料的。

记忆的政治用途与争夺

公共记忆的政治化，可从其用途与遮蔽两面观察：

面向 表现
政治征用 历任总统（无论左右）借戴高乐威望为自身决策背书
意涵竞争 马克龙 2020 年强调其"团结"与"主权"，勾连欧洲战略
选择性凸显 纪念话语淡化阿尔及利亚战争、对哈基人的态度等敏感议题

公共记忆从来不是中立的缅怀，而是一种可被征用的政治资源。历任法国总统——无论左右——都曾在演说中引用戴高乐，以借其威望为自身决策背书。马克龙在2020年逝世50周年纪念中，便着力强调戴高乐的"团结"与"主权"意涵，将其与自己的欧洲战略相勾连。这种引用并非简单的致敬，而是对戴高乐遗产解释权的争夺。

与此同时，戴高乐的记忆也并非铁板一块。围绕他在阿尔及利亚战争、对哈基人的态度等敏感议题，纪念话语往往选择性地凸显某些面向、淡化另一些面向。正因如此，公共记忆既是戴高乐崇高地位的来源，也是历史学者需要保持警惕的对象——纪念活动塑造的形象，与档案揭示的复杂史实之间，始终存在需要审视的距离。

小结

  • 戴高乐的公共记忆是由仪式、机构、地名与历史书写共同建构的产物，而非自然形成。
  • 2020年"戴高乐年"是记忆高峰，依托诞辰130周年、逝世50周年、伦敦号召80周年的"三重周年"，从蒙科尔内到伦敦再到科隆贝，将其塑造为抵抗、共和与民族精神的化身。
  • 戴高乐基金会在亲历者凋零的时代承担传承使命；周年前后涌现二十余部新传记，既显示记忆未冷，也暴露传承焦虑。
  • 巴黎戴高乐机场、"戴高乐号"航母、科隆贝纪念馆与洛林十字架等物质载体，将历史评价转化为日常存在。
  • 渗透日常的纪念，使戴高乐成为超越党派、被广泛共享的民族象征——这与他拒绝国葬的简朴葬礼形成意味深长的反差。
