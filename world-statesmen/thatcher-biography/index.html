玛格丽特·撒切尔：生平与时代（总览）

玛格丽特·希尔达·撒切尔（Margaret Hilda Thatcher，1925年10月13日—2013年4月8日）是英国历史上第一位女首相，也是二十世纪在任时间最长的英国首相，自1979年5月连续执政至1990年11月，长达十一年半。她出身于林肯郡格兰瑟姆一个杂货商家庭，凭借奖学金进入牛津大学萨默维尔学院修读化学，先后做过研究化学家与出庭律师，最终在男性主导的保守党中一路攀升至权力顶峰。

撒切尔的政治生涯横跨战后英国从"共识政治"向市场化改革的剧烈转向。她任内推行的私有化、削减工会权力、控制货币供应、降低直接税等一整套政策，被合称为"撒切尔主义"（Thatcherism），深刻重塑了英国经济结构与政治议程。1982年的福克兰群岛战争与1984—1985年的矿工大罢工，是检验其领导风格的两次标志性事件；在国际舞台上，她与里根结成盎格鲁-美利坚同盟，率先判断戈尔巴乔夫"可以打交道"，并以1988年布鲁日演讲奠定英国疑欧主义的基调。1990年，"人头税"民愤与对欧立场的孤立终于侵蚀了她的党内支持，她在领袖选举第一轮未达门槛后被迫辞职。

本 hub 的定位：纵向总览，而非专题深挖

撒切尔的内容在本知识库中按"一个纵向总览 + 五个专题深挖"组织。本 hub（撒切尔·传记）是唯一一条从出生到逝世的连续时间线主轴——读者若想用一篇连贯的叙事把握她的一生，从这里入手；每一节给出关键日期、人物与转折的"骨架"，并在需要细节处指向对应的专题 hub。专题 hub 则各自就某一面向展开档案级的深度论述，同一事实只在专题 hub 完整展开，本 hub 不重复：

本 hub 章节 对应专题 hub（深挖） 分工
第一章 早年与崛起 崛起之路 本 hub 给崛起骨架；专题 hub 细写格兰瑟姆、牛津、达特福德、芬奇利各阶段
第二章·经济改革 撒切尔主义 本 hub 概述货币主义/私有化/工会；专题 hub 深挖思想源头与每项政策
第二章·福克兰与外交 福克兰与外交 本 hub 串起两场较量与冷战外交；专题 hub 还原战役与外交逐月细节
第二章·内政冲突 国内冲突与改革 本 hub 提及矿工/人头税/北爱；专题 hub 深挖骚乱、绝食、韦斯特兰
第三章 下台与遗产 历史影响与评价 本 hub 还原辞职过程与评价框架；专题 hub 深挖私有化、疑欧、史学记忆

推荐学习路径与前置

  • 前置知识：无需专业背景；了解二战后英国"福利国家/混合经济共识"与1970年代"英国病"（高通胀、罢工频仍）有助于理解她的颠覆性。
  • 入门路径（本 hub 内）：按章节顺序读即可——第一章早年与崛起 → 第二章首相生涯（经济 → 福克兰与矿工 → 外交）→ 第三章下台与评价。
  • 进阶路径：读完本 hub 任一节后，顺着该节末尾的"延伸阅读"跳到对应专题 hub，获取档案级细节。

本知识库以中立、考据的态度，依据公开档案、演讲文本与近年史学研究展开。支持者视她为拯救英国经济、重振国家信心的改革者，批评者则指责她加剧社会不平等、摧毁工业社区——本 hub 力求呈现一个复杂而真实的历史人物，并把每个关键事实落到可核验的日期、地点与文献上。
