数据分类与治理

核心概念

数据分类（Data Classification）是根据数据的敏感性、业务价值和合规要求，将数据划分为不同安全等级的过程。它是数据治理（Data Governance）的基础——只有知道哪些数据是敏感的，才能对其实施适当的保护措施。在云环境中，数据分散在对象存储、数据库、消息队列、日志系统等多种服务中，数据分类面临比传统环境更大的挑战。

数据治理涵盖数据分类、访问控制、数据质量、数据血缘、合规管理和数据生命周期管理。对于中级工程师而言，理解数据分类和基本的数据保护策略是构建合规云架构的必备知识。

敏感数据自动发现
手动识别云环境中的敏感数据几乎不可能——S3 桶中可能有数百万个对象，DynamoDB 表中可能有数十亿条记录。自动化的敏感数据发现是数据分类的第一步。


AWS Macie 是 AI 驱动的敏感数据发现服务。Macie 自动扫描 S3 桶中的数据，使用机器学习和模式匹配识别个人身份信息（PII）、财务数据、凭证和其他敏感内容。


Macie 可以识别 100+ 种敏感数据类型，包括：


    

  • PII：姓名、地址、身份证号、护照号、驾照号
    • 

  • 财务数据：信用卡号、银行账号、税号
    • 

  • 凭证：AWS Access Key、API Key、密码、Token
    • 

  • 医疗数据：ICD-10 代码、药品名称、医疗记录号
    • 

  • 自定义模式：通过正则表达式定义组织特定的敏感数据模式
    • 



import { Macie2Client, CreateClassificationJobCommand, GetFindingsCommand } from '@aws-sdk/client-macie2';

const macie = new Macie2Client({});

await macie.send(
  new CreateClassificationJobCommand({
    name: 'weekly-pii-scan',
    jobType: 'SCHEDULED',
    s3JobDefinition: {
      bucketDefinitions: [
        {
          accountId: '123456789012',
          buckets: ['customer-data-bucket', 'analytics-bucket'],
        },
      ],
      scoping: {
        includes: {
          and: [
            {
              simpleScopeTerm: {
                key: 'OBJECT_EXTENSION',
                values: ['csv', 'json', 'parquet'],
                comparator: 'EQ',
              },
            },
          ],
        },
      },
    },
    scheduleFrequencyDetails: {
      weekly: { dayOfWeek: 'MONDAY' },
    },
    managedDataIdentifierSelector: 'ALL',
  }),
);

数据生命周期管理
数据生命周期管理（Data Lifecycle Management）定义数据从创建到销毁的完整过程中，每个阶段的安全策略和存储策略。


S3 生命周期策略：自动将数据在不同存储类之间迁移，并在保留期满后自动删除。

数据保留策略：根据合规要求设置数据保留期。GDPR 要求个人数据在不再需要时删除。PCI DSS 要求交易日志至少保留 1 年（可审计 3 个月）。HIPAA 要求医疗记录至少保留 6 年。


S3 Object Lock（对象锁定）：实现 WORM（Write Once, Read Many）存储。在保留期内对象不可修改或删除，满足金融和医疗行业的合规要求。


数据丢失防护
数据丢失防护（Data Loss Prevention, DLP）是防止敏感数据未经授权泄露到组织外部的安全控制。在云环境中，DLP 需要覆盖多个数据出口：S3 公开访问、API 响应、日志输出、跨账户共享和数据导出。


S3 数据出口控制：


    

  • S3 Block Public Access：账户级和桶级两层防护，阻止通过 ACL 或桶策略设置公开访问
    • 

  • S3 Access Points：为不同的应用或团队创建独立的访问入口，每个 Access Point 有独立的 IAM 策略
    • 

  • VPC Endpoint 策略：限制通过 VPC Endpoint 只能访问指定的 S3 桶，防止数据外传到其他桶
    •

跨境数据合规
在全球化运营中，数据跨境传输面临各国数据主权法规的约束。主要法规包括：


GDPR（欧盟）：欧盟公民的个人数据只能传输到"充分保护"国家或通过标准合同条款（SCC）。违规罚款高达全球年收入的 4% 或 2000 万欧元。


中国数据安全法 + 个人信息保护法：重要数据和个人信息的跨境传输需要安全评估。关键信息基础设施运营者的数据必须在境内存储。


AWS 区域隔离：通过 SCP 和 IAM 策略限制数据只能存储在指定区域。AWS 提供中国区域（北京、宁夏）作为独立的 AWS 分区，物理和逻辑隔离于全球 AWS。


小结
    

  • 数据分类是数据治理的基础：公开 → 内部 → 机密 → 高度机密四级分类
    • 

  • AWS Macie 自动发现 S3 中的 100+ 种敏感数据类型（PII、财务、凭证）
    • 

  • 数据生命周期管理：S3 生命周期策略自动迁移存储类 + Object Lock WORM 合规
    • 

  • DLP 多层防护：Block Public Access + VPC Endpoint 策略 + Macie + CloudTrail
    • 

  • 跨境数据合规：GDPR/中国数据法要求数据驻留在指定区域
    • 

  • S3 Access Points 为不同使用方提供独立的访问控制和安全策略
    • 

  • 合规保留期：GDPR（最小化）、PCI DSS（1 年）、HIPAA（6 年）
    •
