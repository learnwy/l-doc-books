安全审计与日志

核心概念

安全审计（Security Audit）是系统化地记录、分析和评估安全相关事件的过程。在云环境中，审计日志是合规要求的基本条件，也是安全事件调查和根因分析的关键数据源。一个完善的审计体系需要回答三个核心问题：谁（Who）在什么时间（When）对什么资源（What）做了什么操作（Action），以及结果（Outcome）如何。

AWS CloudTrail 是云安全审计的核心服务，记录 AWS 账户中的所有 API 调用。结合 CloudWatch Logs、VPC Flow Logs、S3 Access Logs 和 GuardDuty，构成完整的安全审计体系。

CloudTrail 深入配置
AWS CloudTrail 记录账户中几乎所有的 API 调用，包括 AWS Management Console、AWS SDK、CLI 和其他 AWS 服务发起的调用。CloudTrail 是安全审计的基石。


Trail 配置：每个 AWS 账户有一个默认的事件历史（Event History），保留 90 天的管理事件。要长期保留和分析日志，需要创建 Trail 并配置 S3 存储。


多账户集中审计：在 AWS Organizations 中创建组织 Trail，自动收集所有成员账户的 CloudTrail 日志到安全账户的 S3 桶。这是多账户安全架构的基本配置。


import { CloudTrailClient, CreateTrailCommand, PutEventSelectorsCommand } from '@aws-sdk/client-cloudtrail';

const ct = new CloudTrailClient({});

await ct.send(
  new CreateTrailCommand({
    Name: 'organization-trail',
    S3BucketName: 'security-audit-logs-123456789012',
    S3KeyPrefix: 'cloudtrail',
    IsMultiRegionTrail: true,
    IsOrganizationTrail: true,
    EnableLogFileValidation: true,
    KmsKeyId: 'arn:aws:kms:us-east-1:123456789012:key/audit-key',
    CloudWatchLogsLogGroupArn: 'arn:aws:logs:us-east-1:123456789012:log-group:cloudtrail:*',
    CloudWatchLogsRoleArn: 'arn:aws:iam::123456789012:role/CloudTrailToCloudWatch',
  }),
);

await ct.send(
  new PutEventSelectorsCommand({
    TrailName: 'organization-trail',
    AdvancedEventSelectors: [
      {
        Name: 'S3DataEvents',
        FieldSelectors: [
          { Field: 'eventCategory', Equals: ['Data'] },
          { Field: 'resources.type', Equals: ['AWS::S3::Object'] },
          {
            Field: 'resources.ARN',
            StartsWith: ['arn:aws:s3:::sensitive-data-bucket/'],
          },
        ],
      },
    ],
  }),
);
日志完整性验证：CloudTrail 启用日志文件验证（Log File Validation）后，每小时生成一个摘要文件（Digest File），包含该小时内所有日志文件的 SHA-256 哈希。可以验证日志是否被篡改——这对于法律取证和合规审计至关重要。

Athena 日志分析
Amazon Athena 是 Serverless 的 SQL 查询引擎，可以直接查询 S3 中的 CloudTrail 日志。无需 ETL 或数据导入，按扫描的数据量计费（$5/TB）。


创建 CloudTrail 日志表：


CREATE EXTERNAL TABLE cloudtrail_logs (
    eventVersion STRING,
    userIdentity STRUCT<
        type: STRING,
        principalId: STRING,
        arn: STRING,
        accountId: STRING,
        invokedBy: STRING,
        accessKeyId: STRING,
        userName: STRING,
        sessionContext: STRUCT<
            attributes: STRUCT<mfaAuthenticated: STRING, creationDate: STRING>,
            sessionIssuer: STRUCT<type: STRING, principalId: STRING, arn: STRING, accountId: STRING, userName: STRING>
        >
    >,
    eventTime STRING,
    eventSource STRING,
    eventName STRING,
    awsRegion STRING,
    sourceIPAddress STRING,
    userAgent STRING,
    errorCode STRING,
    errorMessage STRING,
    requestParameters STRING,
    responseElements STRING,
    resources ARRAY<STRUCT<arn: STRING, accountId: STRING, type: STRING>>
)
PARTITIONED BY (region STRING, year STRING, month STRING, day STRING)
ROW FORMAT SERDE 'org.apache.hive.hcatalog.data.JsonSerDe'
LOCATION 's3://security-audit-logs/cloudtrail/AWSLogs/123456789012/'
常用安全查询：


-- 查找未使用MFA的控制台登录
SELECT eventTime, userIdentity.userName, sourceIPAddress
FROM cloudtrail_logs
WHERE eventName = 'ConsoleLogin'
  AND userIdentity.sessionContext.attributes.mfaAuthenticated = 'false'
  AND eventTime > date_add('day', -7, current_date)
ORDER BY eventTime DESC;

-- 查找异常的跨区域API调用
SELECT awsRegion, COUNT(*) as call_count, userIdentity.arn
FROM cloudtrail_logs
WHERE awsRegion NOT IN ('us-east-1', 'eu-west-1')
  AND errorCode IS NULL
GROUP BY awsRegion, userIdentity.arn
ORDER BY call_count DESC
LIMIT 20;
SIEM 集成与自动化响应
安全信息与事件管理（SIEM）系统将多个日志源的数据集中分析，通过关联规则和机器学习检测安全威胁。


AWS Security Lake 是 AWS 的安全数据湖服务。它将 CloudTrail、VPC Flow Logs、Route 53 DNS 日志、Security Hub 发现等安全数据标准化为 OCSF（Open Cybersecurity Schema Framework）格式，存储在 S3 中。支持与第三方 SIEM（Splunk、Datadog、Sumo Logic）集成。


自动化安全响应（Security Orchestration, Automation and Response, SOAR）通过预定义的 Playbook 自动响应安全事件。

审计报告与合规证明
安全审计的最终产出是审计报告和合规证明。不同的合规框架对审计报告有不同的要求。


AWS Artifact 是下载 AWS 合规报告和协议的门户。可以下载 AWS 的 SOC 1/2/3 报告、PCI DSS AOC、ISO 27001 证书、HIPAA BAA 等。这些报告证明 AWS 基础设施层面的合规性，用户需要自行证明应用层的合规性。


AWS Audit Manager 自动收集审计证据。预建框架映射（PCI DSS、SOC 2、GDPR、HIPAA 等）自动关联 AWS Config 规则、CloudTrail 事件和 Security Hub 发现到具体的合规控制项。生成可供审计师审查的证据包。

小结
    

  • CloudTrail 是安全审计的基石，记录所有 API 调用，多账户集中到安全账户
    • 

  • 启用日志文件验证（SHA-256 Digest）确保日志完整性，支持法律取证
    • 

  • 关键安全事件必须实时告警：Root 登录、IAM 变更、CloudTrail 停止
    • 

  • Athena 直接查询 S3 中的 CloudTrail 日志，无需 ETL，按扫描量计费
    • 

  • Security Lake 标准化安全数据为 OCSF 格式，支持第三方 SIEM 集成
    • 

  • 自动化响应：GuardDuty → EventBridge → Lambda（隔离/撤销/通知）
    • 

  • Audit Manager 自动收集合规证据，映射到 PCI DSS/SOC 2/GDPR 等框架
    •
