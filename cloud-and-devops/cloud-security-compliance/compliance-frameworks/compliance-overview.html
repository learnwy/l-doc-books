合规框架概述

核心概念

合规框架（Compliance Framework）是一套标准化的安全控制要求和最佳实践集合，帮助组织满足法律法规、行业标准和客户期望的安全需求。在云环境中，合规框架既是安全建设的指南，也是向客户和监管机构证明安全能力的工具。

不同的合规框架面向不同的行业和场景：GDPR 规范个人数据保护、PCI DSS 规范支付卡数据安全、HIPAA 规范医疗数据保护、SOC 2 证明服务组织的安全控制有效性、ISO 27001 提供通用的信息安全管理体系。一个组织可能需要同时满足多个框架的要求。

GDPR 与个人数据保护
GDPR（General Data Protection Regulation）是欧盟于 2018 年实施的个人数据保护法规，被认为是全球最严格的数据隐私法律。任何处理欧盟公民个人数据的组织，无论其位于何处，都必须遵守 GDPR。


GDPR 核心原则：


    

  • 合法性、公平性和透明性：数据处理必须有合法基础（同意、合同需要、法律义务等）
    • 

  • 目的限制：数据只能用于收集时声明的特定目的
    • 

  • 数据最小化：只收集实现目的所需的最少数据
    • 

  • 准确性：确保个人数据准确、最新
    • 

  • 存储限制：数据不再需要时必须删除
    • 

  • 完整性和保密性：适当的技术和组织措施保护数据安全
    •

技术合规措施：


数据加密（静态 + 传输）、访问控制（最小权限 IAM）、审计日志（CloudTrail + 数据访问日志）、数据发现（Macie 识别 PII）、同意管理（用户同意的记录和撤销）、数据保留策略（自动过期删除）。


数据处理协议（DPA）：AWS 作为数据处理者，提供 AWS GDPR Data Processing Addendum。用户作为数据控制者，仍需承担合规责任——包括确定合法处理基础、响应数据主体请求、进行数据保护影响评估（DPIA）。


PCI DSS 与支付安全
PCI DSS（Payment Card Industry Data Security Standard）是支付卡行业的全球安全标准，由 PCI 安全标准委员会制定。任何存储、处理或传输持卡人数据（Cardholder Data）的组织都必须遵守。


PCI DSS 4.0 的 12 项要求：


**持卡人数据环境（CDE）**是 PCI DSS 的核心范围概念。CDE 包括所有存储、处理或传输持卡人数据的系统和网络。缩小 CDE 范围是降低合规成本的关键策略——通过令牌化（Tokenization）将实际卡号替换为令牌，使大部分系统不接触真实卡号。

AWS PCI DSS 合规：AWS 本身通过了 PCI DSS Level 1（最高级别）认证。用户在 AWS 上构建的支付系统仍需自行满足 PCI DSS 要求。AWS 提供 PCI DSS 合规指南和快速启动参考架构。


SOC 2 与服务组织控制
SOC 2（Service Organization Control 2）是 AICPA（美国注册会计师协会）制定的服务组织安全审计标准。SaaS 公司、云服务提供商和数据处理机构通常需要 SOC 2 报告来证明其安全控制的有效性。

SOC 2 Type I vs Type II：Type I 报告评估某一时间点的控制设计是否合理。Type II 报告评估一段时间内（通常 6-12 个月）控制的实际运行有效性。Type II 比 Type I 更有价值，也更难获得。


持续合规：SOC 2 审计需要展示安全控制的持续运行效果。AWS Config + Security Hub + CloudTrail 构成了持续合规监控的基础——Config Rules 持续检测配置偏差，Security Hub 汇总安全态势，CloudTrail 记录所有操作审计。


等保 2.0 与中国网络安全
等保 2.0（网络安全等级保护 2.0）是中国网络安全法的核心实施制度。所有在中国境内运营的信息系统都必须按照其重要程度确定安全保护等级，并实施相应的安全保护措施。

等保 2.0 在等保 1.0 的基础上增加了云计算安全扩展要求、移动互联安全扩展要求、物联网安全扩展要求和工业控制系统安全扩展要求。对于云上系统，需要满足基本要求和云计算扩展要求两部分。


小结
    

  • 合规框架是安全建设的指南和对外证明安全能力的工具
    • 

  • GDPR 核心：数据主体权利（访问、删除、可携带）+ 数据最小化 + 72 小时泄露通知
    • 

  • PCI DSS 核心：缩小 CDE 范围（令牌化/外包支付）+ 12 项安全要求
    • 

  • SOC 2 核心：安全性必选 + 4 项可选标准，Type II 报告证明持续有效性
    • 

  • 等保 2.0：中国境内信息系统必须定级备案并通过测评
    • 

  • AWS 提供 Artifact 服务下载合规报告和证书
    • 

  • 多框架合规：映射共同控制项，减少重复工作
    •
