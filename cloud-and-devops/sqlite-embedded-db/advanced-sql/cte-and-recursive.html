CTE 与递归查询

公共表表达式

CTE（Common Table Expression，公共表表达式）使用 WITH 子句定义临时的命名结果集，可以在随后的 SQL 语句中引用。CTE 提升了复杂查询的可读性和可维护性。

-- 基本 CTE 语法
WITH cte_name AS (
    SELECT ...
)
SELECT * FROM cte_name;
与子查询相比，CTE 的优势在于：

多 CTE 串联
多个 CTE 可以串联使用，后面的 CTE 可以引用前面定义的 CTE：


WITH
monthly_sales AS (
    SELECT
        strftime('%Y-%m', order_date) AS month,
        SUM(amount) AS total
    FROM orders
    GROUP BY 1
),
monthly_growth AS (
    SELECT
        month,
        total,
        LAG(total) OVER (ORDER BY month) AS prev_total,
        ROUND(
            (total - LAG(total) OVER (ORDER BY month)) * 100.0
            / LAG(total) OVER (ORDER BY month),
            2
        ) AS growth_pct
    FROM monthly_sales
)
SELECT * FROM monthly_growth WHERE growth_pct IS NOT NULL;


提示： SQLite 的 CTE 默认行为是物化（materialized），即将 CTE 结果存入临时表。如果 CTE 只被引用一次，SQLite 优化器可能会选择内联展开以提升性能。






递归 CTE
WITH RECURSIVE 是处理层级数据和图遍历问题的核心工具。递归 CTE 由两部分组成：基础查询（Base Case）和递归查询（Recursive Step）。


-- 递归 CTE 基本结构
WITH RECURSIVE cte_name AS (
    -- 基础查询：产生初始行
    SELECT ...
    UNION ALL
    -- 递归查询：引用 cte_name 自身
    SELECT ... FROM cte_name WHERE ...
)
SELECT * FROM cte_name;


层级数据遍历
最经典的递归 CTE 应用是遍历树形结构：


CREATE TABLE categories (
    id        INTEGER PRIMARY KEY,
    name      TEXT NOT NULL,
    parent_id INTEGER REFERENCES categories(id)
);

INSERT INTO categories VALUES
(1, '电子产品', NULL),
(2, '手机', 1),
(3, '电脑', 1),
(4, 'iPhone', 2),
(5, 'Android', 2),
(6, '笔记本', 3),
(7, '台式机', 3),
(8, 'MacBook', 6);

-- 从根节点向下遍历整棵树
WITH RECURSIVE category_tree AS (
    SELECT id, name, parent_id, 0 AS depth, name AS path
    FROM categories
    WHERE parent_id IS NULL

    UNION ALL

    SELECT c.id, c.name, c.parent_id, ct.depth + 1,
           ct.path || ' > ' || c.name
    FROM categories c
    JOIN category_tree ct ON c.parent_id = ct.id
)
SELECT
    printf('%.*c', depth * 2, ' ') || name AS tree_view,
    path,
    depth
FROM category_tree
ORDER BY path;


图遍历与路径查找
递归 CTE 也能用于图结构的遍历：


CREATE TABLE routes (
    from_city TEXT,
    to_city   TEXT,
    distance  INTEGER
);

INSERT INTO routes VALUES
('北京', '上海', 1200), ('上海', '杭州', 180),
('杭州', '深圳', 1400), ('北京', '西安', 1100),
('西安', '成都', 700),  ('成都', '深圳', 1900);

-- 查找从北京到深圳的所有路径
WITH RECURSIVE paths AS (
    SELECT
        from_city,
        to_city,
        distance,
        from_city || ' -> ' || to_city AS route,
        1 AS hops
    FROM routes
    WHERE from_city = '北京'

    UNION ALL

    SELECT
        p.from_city,
        r.to_city,
        p.distance + r.distance,
        p.route || ' -> ' || r.to_city,
        p.hops + 1
    FROM paths p
    JOIN routes r ON p.to_city = r.from_city
    WHERE p.hops < 10
)
SELECT route, distance, hops
FROM paths
WHERE to_city = '深圳'
ORDER BY distance;


提示： 递归 CTE 必须设置终止条件（如 WHERE p.hops < 10），否则可能产生无限循环。SQLite 默认递归深度限制为 1000（可通过 SQLITE_MAX_RECURSIVE 编译选项调整）。






数列生成
递归 CTE 可以用来生成数列和日期序列：


-- 生成 1 到 100 的数列
WITH RECURSIVE nums AS (
    SELECT 1 AS n
    UNION ALL
    SELECT n + 1 FROM nums WHERE n < 100
)
SELECT n FROM nums;

-- 生成日期序列
WITH RECURSIVE dates AS (
    SELECT date('2026-01-01') AS d
    UNION ALL
    SELECT date(d, '+1 day') FROM dates WHERE d < '2026-01-31'
)
SELECT d AS date FROM dates;

-- 填充缺失日期的销售数据
WITH RECURSIVE date_range AS (
    SELECT date('2026-01-01') AS d
    UNION ALL
    SELECT date(d, '+1 day') FROM date_range WHERE d < '2026-01-07'
)
SELECT
    dr.d AS sale_date,
    COALESCE(ds.amount, 0) AS amount
FROM date_range dr
LEFT JOIN daily_sales ds ON dr.d = ds.sale_date;


CTE 在 DML 中的使用
SQLite 支持在 INSERT、UPDATE、DELETE 语句中使用 CTE：


-- CTE + INSERT
WITH new_records AS (
    SELECT id, name || ' (归档)' AS name
    FROM categories
    WHERE depth > 2
)
INSERT INTO archive_categories
SELECT * FROM new_records;

-- CTE + DELETE
WITH old_sales AS (
    SELECT rowid
    FROM daily_sales
    WHERE sale_date < date('now', '-90 days')
)
DELETE FROM daily_sales
WHERE rowid IN (SELECT rowid FROM old_sales);


小结
    

  • CTE 通过 WITH 子句定义命名临时结果集，提升查询可读性和复用性。
    • 

  • WITH RECURSIVE 由基础查询和递归查询组成，必须设置明确的终止条件。
    • 

  • 递归 CTE 是处理层级数据（树形结构）和图遍历（路径查找）的标准工具。
    • 

  • 利用递归 CTE 可以方便地生成数列和日期序列，填补数据中的缺失日期。
    • 

  • CTE 可以在 INSERT、UPDATE、DELETE 等 DML 语句中使用。
