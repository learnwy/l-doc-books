全文搜索 FTS5

FTS5 概述

FTS5（Full-Text Search 5）是 SQLite 内置的全文搜索引擎，通过虚拟表（Virtual Table）机制实现。它为文本内容建立倒排索引，支持高效的关键词检索、短语匹配、布尔查询和相关性排序。

创建 FTS5 表
-- 基本 FTS5 表
CREATE VIRTUAL TABLE articles USING fts5(
    title,
    body,
    author
);

-- 指定分词器
CREATE VIRTUAL TABLE articles_cn USING fts5(
    title,
    body,
    tokenize = 'unicode61'
);

-- 关联外部内容表（content table）
CREATE TABLE articles_data (
    id     INTEGER PRIMARY KEY,
    title  TEXT NOT NULL,
    body   TEXT NOT NULL,
    author TEXT NOT NULL
);

CREATE VIRTUAL TABLE articles_idx USING fts5(
    title,
    body,
    author,
    content = 'articles_data',
    content_rowid = 'id'
);

基本查询
-- 简单关键词搜索
SELECT * FROM articles WHERE articles MATCH 'SQLite';

-- 多关键词（隐式 AND）
SELECT * FROM articles WHERE articles MATCH 'SQLite 数据库';

-- 指定列搜索
SELECT * FROM articles WHERE articles MATCH 'title:SQLite';

-- 短语匹配（精确词序）
SELECT * FROM articles WHERE articles MATCH '"嵌入式数据库"';




查询语法
含义





word
包含该词的文档




word1 word2
同时包含两个词（AND）




word1 OR word2
包含任一词




word1 NOT word2
包含 word1 但不含 word2




"phrase match"
精确短语匹配




word*
前缀匹配




NEAR(w1 w2, n)
两词间隔不超过 n 个词




{col1 col2}: word
在指定列中搜索





-- 布尔查询
SELECT * FROM articles WHERE articles MATCH 'SQLite OR 索引';

-- NOT 查询
SELECT * FROM articles WHERE articles MATCH 'SQLite NOT WAL';

-- 前缀搜索
SELECT * FROM articles WHERE articles MATCH '数据*';

-- NEAR 查询：两个词相距不超过 5 个词
SELECT * FROM articles WHERE articles MATCH 'NEAR(SQLite 嵌入式, 5)';

-- 多列搜索
SELECT * FROM articles WHERE articles MATCH '{title body}: SQLite';


排序与相关性
FTS5 内置 bm25() 排名函数，基于 BM25 算法计算文档与查询的相关性分数：


-- 按相关性排序
SELECT
    title,
    author,
    rank
FROM articles
WHERE articles MATCH 'SQLite'
ORDER BY rank;

-- bm25() 可以为不同列指定权重
SELECT
    title,
    author,
    bm25(articles, 10.0, 1.0, 5.0) AS weighted_rank
FROM articles
WHERE articles MATCH 'SQLite'
ORDER BY weighted_rank;
bm25() 的列权重参数顺序与 CREATE VIRTUAL TABLE 中的列顺序一致。权重越高，该列的匹配对最终分数的影响越大。




提示： FTS5 的 rank 列是内置的快捷方式，等价于 bm25(table_name)。使用 ORDER BY rank 即可按默认权重排序。






高亮与摘要
-- highlight()：高亮匹配词
SELECT
    highlight(articles, 0, '<b>', '</b>') AS highlighted_title,
    highlight(articles, 1, '<b>', '</b>') AS highlighted_body
FROM articles
WHERE articles MATCH 'SQLite';

-- snippet()：生成包含匹配词的文本摘要
SELECT
    title,
    snippet(articles, 1, '<b>', '</b>', '...', 20) AS body_snippet
FROM articles
WHERE articles MATCH '索引';

辅助表与词汇表
FTS5 提供 fts5vocab 虚拟表用于查看索引的内部统计信息：


-- 创建词汇统计表
CREATE VIRTUAL TABLE articles_vocab USING fts5vocab(articles, 'row');

-- 查看所有索引词及其文档频率
SELECT term, doc AS doc_count, cnt AS total_count
FROM articles_vocab
ORDER BY doc_count DESC
LIMIT 20;

-- 按列统计
CREATE VIRTUAL TABLE articles_vocab_col USING fts5vocab(articles, 'col');

SELECT term, col, doc, cnt
FROM articles_vocab_col
WHERE col = 'title'
ORDER BY cnt DESC;


外部内容表与同步
当已有数据表且不想复制数据时，使用外部内容表模式：


CREATE TABLE docs (
    id    INTEGER PRIMARY KEY,
    title TEXT NOT NULL,
    body  TEXT NOT NULL
);

CREATE VIRTUAL TABLE docs_fts USING fts5(
    title, body,
    content = 'docs',
    content_rowid = 'id'
);

-- 使用触发器保持同步
CREATE TRIGGER docs_ai AFTER INSERT ON docs BEGIN
    INSERT INTO docs_fts(rowid, title, body)
    VALUES (new.id, new.title, new.body);
END;

CREATE TRIGGER docs_ad AFTER DELETE ON docs BEGIN
    INSERT INTO docs_fts(docs_fts, rowid, title, body)
    VALUES ('delete', old.id, old.title, old.body);
END;

CREATE TRIGGER docs_au AFTER UPDATE ON docs BEGIN
    INSERT INTO docs_fts(docs_fts, rowid, title, body)
    VALUES ('delete', old.id, old.title, old.body);
    INSERT INTO docs_fts(rowid, title, body)
    VALUES (new.id, new.title, new.body);
END;

-- 重建整个索引
INSERT INTO docs_fts(docs_fts) VALUES ('rebuild');


小结
    

  • FTS5 是 SQLite 推荐的全文搜索方案，通过虚拟表和倒排索引实现高效文本检索。
    • 

  • 查询语法支持关键词、短语、布尔运算、前缀匹配和 NEAR 邻近搜索。
    • 

  • 内置 bm25() 排名函数，支持按列设置不同权重。
    • 

  • highlight() 和 snippet() 用于生成高亮文本和搜索摘要。
    • 

  • 使用外部内容表模式避免数据复制，通过触发器保持索引同步。
    •
