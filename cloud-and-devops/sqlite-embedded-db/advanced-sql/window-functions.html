窗口函数

什么是窗口函数

窗口函数（Window Function）是一类在结果集的"窗口"上进行计算的函数。与聚合函数不同，窗口函数不会将多行合并为一行，而是为每行返回一个计算结果。SQLite 从 3.25.0 版本开始支持窗口函数。

窗口函数的基本语法：


function_name() OVER (
    [PARTITION BY column_list]
    [ORDER BY column_list]
    [frame_specification]
)




子句
作用
是否必需





PARTITION BY
将结果集分组为独立的窗口分区
否




ORDER BY
定义每个分区内行的排列顺序
视函数




frame_spec
定义当前行的计算范围（帧）
否







排名函数
排名函数用于为分区内的行分配序号或排名。


CREATE TABLE exam_scores (
    student TEXT,
    subject TEXT,
    score   INTEGER
);

INSERT INTO exam_scores VALUES
('Alice', '数学', 95), ('Alice', '英语', 88),
('Bob', '数学', 92),   ('Bob', '英语', 95),
('Carol', '数学', 95), ('Carol', '英语', 82),
('Dave', '数学', 88),  ('Dave', '英语', 90);

SELECT
    student,
    subject,
    score,
    ROW_NUMBER() OVER (PARTITION BY subject ORDER BY score DESC) AS row_num,
    RANK()       OVER (PARTITION BY subject ORDER BY score DESC) AS rank_val,
    DENSE_RANK() OVER (PARTITION BY subject ORDER BY score DESC) AS dense_rank_val
FROM exam_scores;




函数
行为
并列处理





ROW_NUMBER()
唯一递增序号
不考虑并列




RANK()
允许并列，跳过后续序号
1, 1, 3




DENSE_RANK()
允许并列，不跳过序号
1, 1, 2




NTILE(n)
将行均匀分为 n 组
返回组号





-- NTILE：将学生按成绩分为 3 档
SELECT
    student,
    score,
    NTILE(3) OVER (ORDER BY score DESC) AS tier
FROM exam_scores
WHERE subject = '数学';


值访问函数
LAG 和 LEAD 函数用于访问当前行之前或之后的行。


CREATE TABLE daily_sales (
    sale_date TEXT,
    amount    INTEGER
);

INSERT INTO daily_sales VALUES
('2026-01-01', 1000), ('2026-01-02', 1200),
('2026-01-03', 950),  ('2026-01-04', 1500),
('2026-01-05', 1100);

SELECT
    sale_date,
    amount,
    LAG(amount, 1, 0)  OVER (ORDER BY sale_date) AS prev_amount,
    LEAD(amount, 1, 0) OVER (ORDER BY sale_date) AS next_amount,
    amount - LAG(amount, 1, 0) OVER (ORDER BY sale_date) AS daily_change
FROM daily_sales;




函数
描述
参数





LAG(expr, n, default)
前第 n 行的值
n 默认 1，default 可选




LEAD(expr, n, default)
后第 n 行的值
n 默认 1，default 可选




FIRST_VALUE(expr)
窗口帧中第一行的值
无额外参数




LAST_VALUE(expr)
窗口帧中最后一行的值
无额外参数




NTH_VALUE(expr, n)
窗口帧中第 n 行的值
n 从 1 开始





-- 每个学科中的最高分和最低分
SELECT
    student,
    subject,
    score,
    FIRST_VALUE(student) OVER w AS top_student,
    LAST_VALUE(student)  OVER w AS bottom_student
FROM exam_scores
WINDOW w AS (
    PARTITION BY subject
    ORDER BY score DESC
    RANGE BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
);


提示： LAST_VALUE 的默认帧是从分区开始到当前行，而不是整个分区。如果需要整个分区的最后一个值，必须显式指定 RANGE BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING。






聚合窗口函数
所有聚合函数都可以作为窗口函数使用：


SELECT
    sale_date,
    amount,
    SUM(amount)   OVER (ORDER BY sale_date) AS running_total,
    AVG(amount)   OVER (ORDER BY sale_date) AS running_avg,
    COUNT(*)      OVER (ORDER BY sale_date) AS running_count
FROM daily_sales;


帧规范
帧规范（Frame Specification）定义了窗口函数的精确计算范围。


-- 语法
frame_type BETWEEN frame_start AND frame_end

-- frame_type: ROWS | RANGE | GROUPS
-- frame_start / frame_end:
--   UNBOUNDED PRECEDING
--   N PRECEDING
--   CURRENT ROW
--   N FOLLOWING
--   UNBOUNDED FOLLOWING
-- 3 日移动平均
SELECT
    sale_date,
    amount,
    AVG(amount) OVER (
        ORDER BY sale_date
        ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING
    ) AS moving_avg_3
FROM daily_sales;

-- 累计总和
SELECT
    sale_date,
    amount,
    SUM(amount) OVER (
        ORDER BY sale_date
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS cumulative_sum
FROM daily_sales;




帧类型
含义
适用场景





ROWS
以物理行为单位
移动平均、滑动窗口




RANGE
以值范围为单位
同值行需一起计算




GROUPS
以对等组为单位
按组滑动







WINDOW 子句
使用 WINDOW 子句可以定义命名窗口，避免重复编写相同的窗口规范：


SELECT
    student,
    subject,
    score,
    ROW_NUMBER() OVER w AS row_num,
    RANK()       OVER w AS rank_val,
    SUM(score)   OVER w AS running_sum
FROM exam_scores
WINDOW w AS (PARTITION BY subject ORDER BY score DESC);


小结
    

  • 窗口函数在不合并行的情况下对结果集进行分析计算，SQLite 3.25+ 支持。
    • 

  • 排名函数（ROW_NUMBER、RANK、DENSE_RANK）用于为分区内的行分配序号。
    • 

  • LAG/LEAD 用于访问相邻行的数据，适合计算环比变化。
    • 

  • 帧规范精确控制计算范围，ROWS 按物理行、RANGE 按值范围。
    • 

  • 使用 WINDOW 子句定义命名窗口，避免重复的窗口定义。
    •
