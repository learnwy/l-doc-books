高级 SQL 简介

SQLite 虽然以轻量著称，但在 SQL 功能支持上毫不含糊。从 3.25 版本开始引入窗口函数，到 FTS5 全文搜索引擎，SQLite 已经具备了处理复杂查询需求的全套工具。掌握这些高级特性，能让你在嵌入式场景中发挥 SQL 的全部威力，避免将本应在数据库层完成的逻辑搬到应用层。

本章覆盖四个核心主题：

窗口函数是现代 SQL 中最强大的分析工具之一。通过 ROW_NUMBER、RANK、LAG、LEAD 等函数配合 OVER 子句和帧规范，你可以在不使用子查询的情况下完成排名、累计、移动平均等复杂计算。

CTE 与递归查询让你能够编写清晰可读的多步骤查询逻辑。普通 CTE 用于替代嵌套子查询以提升可读性，而递归 CTE 则是处理层级数据（如组织结构、分类树）和图遍历问题的利器。

JSON 支持使 SQLite 能够优雅地处理半结构化数据。通过 json_extract、json_each、json_tree 等函数和 JSON Path 语法，你可以直接在 SQL 中查询和操作嵌套的 JSON 数据，避免应用层的反复解析。

全文搜索 FTS5 为 SQLite 提供了专业级的文本检索能力。它基于虚拟表机制实现，支持布尔查询、短语匹配、前缀搜索，并内置了 rank 排序、highlight 高亮和 snippet 摘要等实用功能。

建议先学习窗口函数和 CTE，因为它们是通用 SQL 技能，在任何数据库中都适用。JSON 和 FTS5 则更偏向 SQLite 的特色功能，可以根据实际需求选择深入。
