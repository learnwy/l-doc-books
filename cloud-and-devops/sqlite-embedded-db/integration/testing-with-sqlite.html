SQLite 测试

内存数据库优势

SQLite 的内存数据库（In-Memory Database）是构建高速测试环境的利器。通过将数据库完全放在内存中，消除了磁盘 I/O 开销，每个测试用例都可以在毫秒级时间内获得一个全新的数据库实例。

import Database from 'better-sqlite3';

function createTestDb(): Database.Database {
  const db = new Database(':memory:');
  db.pragma('journal_mode = WAL');
  db.pragma('foreign_keys = ON');
  return db;
}

const db = createTestDb();
db.exec(`
  CREATE TABLE users (
    id    INTEGER PRIMARY KEY AUTOINCREMENT,
    name  TEXT NOT NULL,
    email TEXT NOT NULL UNIQUE,
    age   INTEGER
  ) STRICT
`);


提示： 使用 ':memory:' 创建的数据库完全存在于内存中，连接关闭时自动销毁。每次调用 new Database(':memory:') 都创建一个全新的独立数据库实例。






测试夹具管理
测试夹具（Test Fixture）是预设的测试数据，确保测试在已知状态下运行。


interface TestFixture {
  setup: (db: Database.Database) => void;
}

const userFixtures: TestFixture = {
  setup: (db) => {
    const stmt = db.prepare('INSERT INTO users (name, email, age) VALUES (?, ?, ?)');
    stmt.run('Alice', 'alice@example.com', 30);
    stmt.run('Bob', 'bob@example.com', 25);
    stmt.run('Carol', 'carol@example.com', 35);
  },
};

function withFixtures(schema: string, fixtures: TestFixture[], testFn: (db: Database.Database) => void) {
  const db = new Database(':memory:');
  db.pragma('foreign_keys = ON');
  db.exec(schema);

  for (const fixture of fixtures) {
    fixture.setup(db);
  }

  try {
    testFn(db);
  } finally {
    db.close();
  }
}


快照与回滚
利用 SQLite 的保存点（Savepoint）可以在测试之间快速回滚，避免重建数据库：


class TestTransaction {
  private db: Database.Database;

  constructor(db: Database.Database) {
    this.db = db;
  }

  begin() {
    this.db.exec('SAVEPOINT test_savepoint');
  }

  rollback() {
    this.db.exec('ROLLBACK TO SAVEPOINT test_savepoint');
    this.db.exec('RELEASE SAVEPOINT test_savepoint');
  }
}

const db = new Database(':memory:');
db.exec('CREATE TABLE counters (id INTEGER PRIMARY KEY, value INTEGER)');
db.exec('INSERT INTO counters VALUES (1, 0)');

const tx = new TestTransaction(db);

tx.begin();
db.prepare('UPDATE counters SET value = 100 WHERE id = 1').run();
const after = db.prepare('SELECT value FROM counters WHERE id = 1').get() as { value: number };
tx.rollback();

const reset = db.prepare('SELECT value FROM counters WHERE id = 1').get() as { value: number };


数据库复制测试
对于需要从生产数据库结构生成测试环境的场景：


function cloneSchema(source: Database.Database): Database.Database {
  const target = new Database(':memory:');

  const tables = source
    .prepare("SELECT sql FROM sqlite_master WHERE type = 'table' AND sql IS NOT NULL")
    .all() as Array<{ sql: string }>;

  const indexes = source
    .prepare("SELECT sql FROM sqlite_master WHERE type = 'index' AND sql IS NOT NULL")
    .all() as Array<{ sql: string }>;

  for (const t of tables) {
    target.exec(t.sql);
  }

  for (const idx of indexes) {
    target.exec(idx.sql);
  }

  return target;
}

function createSnapshot(db: Database.Database): Buffer {
  return db.serialize();
}

function restoreSnapshot(buffer: Buffer): Database.Database {
  return new Database(buffer);
}


集成测试模式
function createTestContext() {
  const db = new Database(':memory:');
  db.pragma('journal_mode = WAL');
  db.pragma('foreign_keys = ON');

  db.exec(`
    CREATE TABLE users (
      id    INTEGER PRIMARY KEY AUTOINCREMENT,
      name  TEXT NOT NULL,
      email TEXT NOT NULL UNIQUE
    ) STRICT;

    CREATE TABLE orders (
      id      INTEGER PRIMARY KEY AUTOINCREMENT,
      user_id INTEGER NOT NULL REFERENCES users(id),
      total   REAL NOT NULL,
      status  TEXT NOT NULL DEFAULT 'pending'
    ) STRICT;
  `);

  return {
    db,
    seedUsers: (...users: Array<{ name: string; email: string }>) => {
      const stmt = db.prepare('INSERT INTO users (name, email) VALUES (?, ?)');
      return users.map((u) => stmt.run(u.name, u.email).lastInsertRowid);
    },
    seedOrders: (...orders: Array<{ userId: number; total: number }>) => {
      const stmt = db.prepare('INSERT INTO orders (user_id, total) VALUES (?, ?)');
      return orders.map((o) => stmt.run(o.userId, o.total).lastInsertRowid);
    },
    cleanup: () => db.close(),
  };
}

const ctx = createTestContext();
const [aliceId] = ctx.seedUsers({ name: 'Alice', email: 'alice@test.com' });
ctx.seedOrders({ userId: Number(aliceId), total: 99.99 });

const orders = ctx.db.prepare('SELECT * FROM orders WHERE user_id = ?').all(aliceId);

ctx.cleanup();

提示： 在并行测试中，每个测试 worker 使用独立的 :memory: 数据库是最安全的隔离方式。SQLite 的内存数据库创建极快，不会成为性能瓶颈。






小结
    

  • SQLite 内存数据库是高速测试环境的最佳选择，毫秒级创建和销毁。
    • 

  • 测试夹具模式通过工厂函数提供可复用的测试数据。
    • 

  • 使用保存点可以在测试之间快速回滚，避免重建数据库。
    • 

  • serialize() / deserialize() 支持数据库快照，适合复杂初始状态的测试。
    • 

  • 并行测试中每个 worker 使用独立的 :memory: 实例，确保完全隔离。
