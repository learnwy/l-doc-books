better-sqlite3 同步驱动

为什么选择 better-sqlite3

better-sqlite3 是 Node.js 生态中性能最高的 SQLite 驱动。与基于回调/Promise 的异步驱动（如 sqlite3）不同，better-sqlite3 采用同步 API（Synchronous API）设计，利用 N-API 直接绑定 SQLite C 库。

基本使用
import Database from 'better-sqlite3';

const db = new Database('myapp.db');

db.pragma('journal_mode = WAL');
db.pragma('synchronous = NORMAL');
db.pragma('cache_size = -64000');
db.pragma('foreign_keys = ON');

db.exec(`
  CREATE TABLE IF NOT EXISTS users (
    id    INTEGER PRIMARY KEY AUTOINCREMENT,
    name  TEXT NOT NULL,
    email TEXT NOT NULL UNIQUE,
    age   INTEGER
  ) STRICT
`);

const insert = db.prepare('INSERT INTO users (name, email, age) VALUES (?, ?, ?)');
insert.run('Alice', 'alice@example.com', 30);

const user = db.prepare('SELECT * FROM users WHERE id = ?').get(1);

const allUsers = db.prepare('SELECT * FROM users').all();

db.close();

Prepared Statements
预编译语句（Prepared Statement）将 SQL 解析和编译与参数绑定分离，既提升性能又防止 SQL 注入。


const stmt = db.prepare('SELECT * FROM users WHERE city = ? AND age > ?');

const result1 = stmt.all('北京', 25);
const result2 = stmt.all('上海', 30);

const namedStmt = db.prepare('SELECT * FROM users WHERE city = @city AND age > @minAge');
const result3 = namedStmt.all({ city: '深圳', minAge: 20 });


提示： Prepared Statement 在 better-sqlite3 中是可重复使用的。编译一次后可以多次绑定不同参数执行，避免重复解析 SQL 的开销。






事务封装
better-sqlite3 提供了优雅的 transaction() 方法来封装事务：


const insertMany = db.transaction((users: Array<{ name: string; email: string; age: number }>) => {
  const stmt = db.prepare('INSERT INTO users (name, email, age) VALUES (@name, @email, @age)');
  for (const user of users) {
    stmt.run(user);
  }
});

insertMany([
  { name: 'Bob', email: 'bob@example.com', age: 25 },
  { name: 'Carol', email: 'carol@example.com', age: 28 },
  { name: 'Dave', email: 'dave@example.com', age: 35 },
]);

const transfer = db.transaction((from: number, to: number, amount: number) => {
  const withdraw = db.prepare('UPDATE accounts SET balance = balance - ? WHERE id = ?');
  const deposit = db.prepare('UPDATE accounts SET balance = balance + ? WHERE id = ?');

  const result = withdraw.run(amount, from);
  if (result.changes === 0) throw new Error('账户不存在');

  deposit.run(amount, to);
});

transfer(1, 2, 100);
事务方法还支持嵌套（保存点）：


const outerTx = db.transaction(() => {
  db.prepare('INSERT INTO logs (msg) VALUES (?)').run('外层事务');

  const innerTx = db.transaction(() => {
    db.prepare('INSERT INTO logs (msg) VALUES (?)').run('内层事务');
  });

  innerTx();
});

outerTx();


批量操作性能
const insertBatch = db.transaction((rows: string[][]) => {
  const stmt = db.prepare('INSERT INTO data (col1, col2, col3) VALUES (?, ?, ?)');
  for (const row of rows) {
    stmt.run(...row);
  }
});

const data = Array.from({ length: 100000 }, (_, i) => [`name_${i}`, `value_${i}`, String(i)]);

insertBatch(data);

自定义函数与聚合
db.function('distance', (x1: number, y1: number, x2: number, y2: number) => {
  return Math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2);
});

db.prepare('SELECT distance(0, 0, 3, 4) AS dist').get();

db.aggregate('median', {
  start: () => [] as number[],
  step: (arr, value: number) => {
    arr.push(value);
    return arr;
  },
  result: (arr) => {
    arr.sort((a, b) => a - b);
    const mid = Math.floor(arr.length / 2);
    return arr.length % 2 ? arr[mid] : (arr[mid - 1] + arr[mid]) / 2;
  },
});

db.prepare('SELECT median(score) AS med FROM exam_scores').get();


小结
    

  • better-sqlite3 是 Node.js 中性能最优的 SQLite 驱动，采用同步 API 设计。
    • 

  • Prepared Statements 编译一次多次执行，兼顾性能和安全。
    • 

  • 使用 transaction() 封装事务，批量写入性能可提升 100 倍以上。
    • 

  • 支持自定义标量函数和聚合函数，扩展 SQL 的计算能力。
    • 

  • 连接创建时应设置好 WAL 模式、缓存大小、外键约束等关键 Pragma。
