ORM 与查询构建器

工具选型概览

Drizzle ORM
Drizzle 是一个 TypeScript-first 的轻量级 ORM，提供类型安全的 SQL 查询构建，同时保留了对原生 SQL 的完全控制。


import { sqliteTable, text, integer } from 'drizzle-orm/sqlite-core';
import { drizzle } from 'drizzle-orm/better-sqlite3';
import { eq, gt, and, sql } from 'drizzle-orm';
import Database from 'better-sqlite3';

const users = sqliteTable('users', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  name: text('name').notNull(),
  email: text('email').notNull().unique(),
  age: integer('age'),
  city: text('city'),
});

const sqlite = new Database('myapp.db');
const db = drizzle(sqlite);

const allUsers = db.select().from(users).all();

const filteredUsers = db
  .select()
  .from(users)
  .where(and(eq(users.city, '北京'), gt(users.age, 25)))
  .all();

db.insert(users)
  .values({
    name: 'Alice',
    email: 'alice@example.com',
    age: 30,
    city: '上海',
  })
  .run();

db.update(users).set({ age: 31 }).where(eq(users.id, 1)).run();

db.delete(users).where(eq(users.id, 1)).run();
Drizzle 的迁移工具：


import { migrate } from 'drizzle-orm/better-sqlite3/migrator';

migrate(db, { migrationsFolder: './drizzle' });


Kysely
Kysely 是一个纯类型安全的 SQL 查询构建器，不是 ORM。它不管理 Schema 定义或数据映射，而是专注于提供类型安全的 SQL 查询构建体验。


import { Kysely, SqliteDialect } from 'kysely';
import Database from 'better-sqlite3';

interface DB {
  users: {
    id: number;
    name: string;
    email: string;
    age: number | null;
    city: string | null;
  };
  orders: {
    id: number;
    user_id: number;
    total: number;
    status: string;
  };
}

const db = new Kysely<DB>({
  dialect: new SqliteDialect({
    database: new Database('myapp.db'),
  }),
});

const users = await db
  .selectFrom('users')
  .select(['id', 'name', 'email'])
  .where('city', '=', '北京')
  .where('age', '>', 25)
  .orderBy('name')
  .execute();

const result = await db
  .selectFrom('users')
  .innerJoin('orders', 'orders.user_id', 'users.id')
  .select(['users.name', db.fn.sum<number>('orders.total').as('total_spent')])
  .groupBy('users.name')
  .having(db.fn.sum('orders.total'), '>', 1000)
  .execute();


Prisma
Prisma 是一个全功能的 ORM，通过 Schema 文件定义数据模型，自动生成类型安全的客户端代码。


-- prisma/schema.prisma 中的模型定义（Prisma Schema Language）
-- generator client {
--   provider = "prisma-client-js"
-- }
-- datasource db {
--   provider = "sqlite"
--   url      = "file:./myapp.db"
-- }
-- model User {
--   id    Int     @id @default(autoincrement())
--   name  String
--   email String  @unique
--   age   Int?
--   city  String?
-- }
import { PrismaClient } from '@prisma/client';

const prisma = new PrismaClient();

const users = await prisma.user.findMany({
  where: {
    city: '北京',
    age: { gt: 25 },
  },
  orderBy: { name: 'asc' },
});

const user = await prisma.user.create({
  data: {
    name: 'Alice',
    email: 'alice@example.com',
    age: 30,
    city: '上海',
  },
});

const updated = await prisma.user.update({
  where: { id: 1 },
  data: { age: 31 },
});

提示： 如果你的项目高度依赖 SQLite 特有功能（JSON、FTS5、STRICT 表），Drizzle 或直接使用 better-sqlite3 是更好的选择。Prisma 的 SQLite 支持虽然完整，但对 SQLite 特有特性的支持有限。






小结
    

  • Drizzle 提供 SQL-like 的 TypeScript API，对 SQLite 特性支持最好。
    • 

  • Kysely 是纯查询构建器，bundle 最小，适合只需类型安全查询构建的场景。
    • 

  • Prisma 是全功能 ORM，关系查询能力最强，但对 SQLite 特有特性支持有限。
    • 

  • 选型核心：SQLite 特有功能需求高选 Drizzle，多数据库支持选 Prisma，极致性能选原生 SQL。
