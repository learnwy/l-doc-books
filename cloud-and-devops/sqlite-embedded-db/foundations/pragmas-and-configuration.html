Pragma 与配置

Pragma 概述

PRAGMA 是 SQLite 特有的 SQL 扩展，用于查询和修改数据库引擎的内部运行参数。Pragma 不是标准 SQL 的一部分，但它是控制 SQLite 行为的主要手段。

-- 查询类 Pragma
PRAGMA journal_mode;
PRAGMA page_size;

-- 设置类 Pragma
PRAGMA journal_mode = WAL;
PRAGMA cache_size = -64000;

Pragma 的作用范围分为两类：

作用范围 持久性 示例
数据库级 写入数据库 journal_mode, page_size
连接级 仅当前连接 cache_size, synchronous

-- 切换到 WAL 模式（推荐）
PRAGMA journal_mode = WAL;

-- 查看当前日志模式
PRAGMA journal_mode;


提示： WAL 模式是大多数应用的最佳选择。它允许读写并发，并且写入性能优于传统的回滚日志模式。切换到 WAL 后，数据库目录会多出 -wal 和 -shm 两个辅助文件。

PRAGMA synchronous = NORMAL;

PRAGMA synchronous = FULL;


缓存配置
cache_size 控制 SQLite 在内存中缓存的页面数量，对查询性能有直接影响。


-- 设置缓存为 64MB（负数表示 KB）
PRAGMA cache_size = -64000;

-- 查看当前缓存大小
PRAGMA cache_size;

-- 查看默认缓存大小（持久化设置）
PRAGMA default_cache_size;




参数值
含义
示例





正数 N
缓存 N 个页面
cache_size = 2000




负数 -N
缓存约 N KB
cache_size = -64000





mmap_size 允许 SQLite 通过内存映射方式访问数据库文件，减少系统调用开销。


-- 启用 256MB 内存映射
PRAGMA mmap_size = 268435456;

-- 禁用内存映射
PRAGMA mmap_size = 0;


提示： 内存映射在只读场景下效果最佳。对于频繁写入的场景，传统的缓存模式可能更合适，因为 mmap 的页面失效处理会增加开销。






其他关键 Pragma
-- 外键约束（默认关闭！）
PRAGMA foreign_keys = ON;

-- 自动回收空间
PRAGMA auto_vacuum = INCREMENTAL;

-- 启用递增式 vacuum
PRAGMA incremental_vacuum(100);

-- 查看数据库完整性
PRAGMA integrity_check;

-- 快速完整性检查
PRAGMA quick_check;

-- 查看表结构
PRAGMA table_info(users);

-- 查看索引列表
PRAGMA index_list(users);

-- 查看编译选项
PRAGMA compile_options;
常用配置组合推荐：


-- 生产环境推荐配置
PRAGMA journal_mode = WAL;
PRAGMA synchronous = NORMAL;
PRAGMA cache_size = -64000;
PRAGMA foreign_keys = ON;
PRAGMA busy_timeout = 5000;
PRAGMA wal_autocheckpoint = 1000;
-- 开发/测试环境配置
PRAGMA journal_mode = WAL;
PRAGMA synchronous = OFF;
PRAGMA cache_size = -128000;
PRAGMA foreign_keys = ON;
PRAGMA temp_store = MEMORY;

小结
    

  • PRAGMA 是 SQLite 配置的主要手段，分为数据库级（持久化）和连接级（仅当前连接）。
    • 

  • WAL 日志模式是大多数场景的最佳选择，提供读写并发和更优的写入性能。
    • 

  • WAL 模式下推荐 synchronous = NORMAL，在安全性和性能之间取得平衡。
    • 

  • cache_size 和 mmap_size 直接影响查询性能，应根据可用内存合理配置。
    • 

  • foreign_keys 默认关闭，需要在每个连接上手动启用。
    •
