可观测性平台架构

核心概念

可观测性平台（Observability Platform）是集中化管理指标、日志和追踪三大遥测数据的技术基础设施，为工程团队提供统一的数据采集、存储、查询和可视化能力。一个成熟的可观测性平台需要处理海量遥测数据的摄入和存储、提供低延迟的查询响应、支持灵活的数据关联分析，同时控制总体拥有成本（TCO）。

可观测性平台的架构选择通常在两个方向之间权衡：统一平台（All-in-One，如 Datadog、New Relic）提供开箱即用的完整体验但成本较高且存在供应商锁定；组合式平台（Best-of-Breed，如 Prometheus + Loki + Tempo + Grafana）提供更高的灵活性和成本控制但集成和运维复杂度更高。

OpenTelemetry 采集架构
OpenTelemetry（OTel）已成为可观测性数据采集的事实标准。OTel 提供了统一的 SDK（生成遥测数据）、Collector（收集和处理遥测数据）和协议（OTLP，传输遥测数据）。采用 OTel 标准意味着应用代码与后端存储解耦——可以在不修改应用代码的情况下切换后端平台。


OTel Collector 部署模式：


Agent 模式：在每个节点上部署一个 Collector 实例（DaemonSet），接收该节点上所有 Pod 的遥测数据。优势是数据在本节点内完成初步处理（采样、过滤），减少网络传输。


Gateway 模式：集中部署少量高配置的 Collector 实例（Deployment），所有节点的数据发送到 Gateway 进行统一处理。优势是集中化管理采样策略和数据路由。


推荐的两层架构：Agent（节点级采集 + 初步过滤）→ Gateway（集中处理 + 尾部采样 + 路由到后端）。这种架构兼顾了本地化处理的效率和集中化管理的灵活性。

存储架构与扩展性
可观测性数据的存储是平台成本的主要组成部分。不同类型的遥测数据有不同的存储特性和挑战。


指标存储：Prometheus 是最流行的指标存储，但单实例不支持水平扩展和长期存储。Grafana Mimir（Cortex 的继任者）和 Thanos 提供了 Prometheus 兼容的分布式长期存储。Mimir 支持全局查询视图（跨多个 Prometheus 实例聚合）、无限期存储（使用对象存储如 S3）和自动降采样。


日志存储：Grafana Loki 采用了"只索引标签、不索引日志内容"的架构，将存储成本降低到 Elasticsearch 的 1/10 以下。代价是全文搜索性能较低——Loki 更适合基于标签过滤后的日志查看，而非大规模全文检索。Elasticsearch 仍是全文搜索场景的首选。


追踪存储：Grafana Tempo 采用"只存储不索引"的极简架构，将追踪数据直接存储到对象存储（S3/GCS），通过 Trace ID 直接查找。这使得 Tempo 的存储成本极低，但只能通过 Trace ID 检索——不支持"查找所有包含错误的 Trace"这类搜索。TraceQL 通过流式扫描部分解决了搜索需求。

多租户与访问控制
企业级可观测性平台通常服务多个团队和业务线，需要多租户隔离和细粒度的访问控制。


数据隔离：Mimir、Loki 和 Tempo 都支持多租户模式。每个租户的数据在存储层物理隔离（不同的对象存储路径），查询时通过 HTTP Header 中的 Tenant ID 确定数据范围。这确保了团队 A 无法查询团队 B 的数据。


Grafana RBAC（Role-Based Access Control）控制用户对仪表盘、数据源和告警的访问权限。常见的角色层级包括：Viewer（只看仪表盘）、Editor（编辑仪表盘和告警）和 Admin（管理数据源和团队）。组织和文件夹级别的权限控制允许不同团队管理自己的仪表盘空间。


小结
    

  • 可观测性平台在统一平台（Datadog/New Relic）和组合式平台（LGTM Stack）之间权衡成本、灵活性和运维复杂度
    • 

  • OpenTelemetry 是数据采集的事实标准，两层 Collector 架构（Agent + Gateway）兼顾效率和灵活性
    • 

  • Mimir/Loki/Tempo 分别优化指标/日志/追踪的存储成本，共同使用对象存储（S3）作为长期存储后端
    • 

  • Loki 不索引日志内容的架构将成本降至 Elasticsearch 的 1/10，但牺牲了全文搜索性能
    • 

  • 多租户通过 Tenant ID 实现数据物理隔离，Grafana RBAC 控制仪表盘和告警的访问权限
    • 

  • 存储成本是平台 TCO 的主要组成部分，降采样和分层存储是控制成本的关键手段
    •
