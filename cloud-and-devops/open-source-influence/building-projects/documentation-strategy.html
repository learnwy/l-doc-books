文档策略

文档即产品

开源项目的文档质量直接决定了项目的采用率和贡献者活跃度。研究表明，超过 90% 的开发者认为文档质量是选择开源库的关键因素。

文档站点搭建
现代文档站点生成器让你专注于内容，自动处理主题、搜索和部署。


npx create-docusaurus@latest docs classic

cd docs
npm run start

API 文档自动生成
对于库和框架类项目，API 文档应从源码注释自动生成，确保文档与代码始终同步。


npx typedoc --entryPoints src/index.ts --out docs/api

npx typedoc --plugin typedoc-plugin-markdown --out docs/api

提示： API 文档生成应集成到 CI 流水线中，确保每次发布都自动更新文档。使用 PR 预览功能让 Review 者可以直接查看文档变更效果。






变更日志
变更日志（CHANGELOG）是用户了解版本间差异的关键文档。使用工具自动生成可以确保完整性和一致性。


npx conventional-changelog -p angular -i CHANGELOG.md -s -r 0

npx changeset add

npx changeset version

小结
    

  • 文档质量是开源项目采用率的关键决定因素，应像产品一样持续迭代。
    • 

  • Diátaxis 框架将文档分为教程、操作指南、参考和解释四种类型，各有不同写作目标。
    • 

  • 现代文档站点生成器（Docusaurus、VitePress）让你专注内容，自动处理部署和搜索。
    • 

  • API 文档应从源码注释自动生成，并集成到 CI 流水线确保与代码同步。
    • 

  • 变更日志使用 Conventional Changelog 或 Changesets 工具自动生成，确保完整性和一致性。
    •
