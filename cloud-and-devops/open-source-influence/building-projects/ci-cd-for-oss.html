开源项目的 CI/CD

持续集成的价值

持续集成（Continuous Integration, CI）是开源项目质量保障的基石。每一次提交和 PR 都经过自动化检查，确保代码库始终处于可发布状态。

提示： CI 流水线的执行速度直接影响贡献者体验。将快速检查（lint、type check）放在前面，耗时操作（集成测试）放在后面，并善用缓存和并行执行。






GitHub Actions 基础
GitHub Actions 是开源项目最常用的 CI/CD 平台，对公开仓库完全免费。


name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

permissions:
  contents: read

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm lint
      - run: pnpm typecheck

  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        node-version: [18, 20, 22]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node-version }}
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm test -- --coverage
      - uses: codecov/codecov-action@v4
        with:
          token: ${{ secrets.CODECOV_TOKEN }}


多平台与矩阵测试
开源库通常需要在多个操作系统和运行时版本上测试兼容性。


jobs:
  test:
    strategy:
      fail-fast: false
      matrix:
        os: [ubuntu-latest, macos-latest, windows-latest]
        node: [18, 20, 22]
        exclude:
          - os: windows-latest
            node: 18
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node }}
      - run: npm ci
      - run: npm test

安全与依赖管理
开源项目的供应链安全至关重要。自动化的安全扫描和依赖更新可以有效降低风险。


name: Security

on:
  schedule:
    - cron: '0 6 * * 1'
  push:
    branches: [main]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm audit --audit-level=high
      - uses: aquasecurity/trivy-action@master
        with:
          scan-type: fs
          severity: HIGH,CRITICAL
npm audit --audit-level=moderate

npx socket-security/cli scan

gh api repos/{owner}/{repo}/dependabot/alerts --jq '.[].security_advisory.summary'

PR 预览与自动化
为 PR 提供自动化预览和反馈，大幅提升 Review 效率。


name: PR Preview

on:
  pull_request:
    types: [opened, synchronize]

jobs:
  preview:
    runs-on: ubuntu-latest
    permissions:
      pull-requests: write
    steps:
      - uses: actions/checkout@v4
      - run: npm ci && npm run build
      - uses: actions/upload-artifact@v4
        with:
          name: preview
          path: dist/
      - uses: marocchino/sticky-pull-request-comment@v2
        with:
          message: |
            📦 构建成功！
            - 包大小：`$(du -sh dist | cut -f1)`
            - 文件数：`$(find dist -type f | wc -l)`


小结
    

  • CI 是开源项目质量保障的基石，每次提交都应经过自动化验证。
    • 

  • GitHub Actions 对公开仓库免费，通过矩阵策略可在多平台、多版本上并行测试。
    • 

  • 安全扫描和自动依赖更新（Dependabot/Renovate）是供应链安全的第一道防线。
    • 

  • PR 预览和自动化反馈（构建大小、覆盖率变化）大幅提升 Code Review 效率。
    • 

  • CI 流水线的速度直接影响贡献者体验，应优先执行快速检查并善用缓存。
    •
