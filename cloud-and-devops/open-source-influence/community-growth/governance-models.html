治理模型

什么是开源治理

开源治理（Governance）定义了项目中的决策机制、权力分配和冲突解决方式。随着项目规模增长，清晰的治理结构变得越来越重要。

BDFL 模型
BDFL（Benevolent Dictator For Life，终身仁慈独裁者）是最简单的治理模型。一个人拥有所有重大决策的最终裁决权。

精英制模型
精英制（Meritocracy）根据贡献的质量和数量来分配权力。持续做出高质量贡献的人自然获得更大的决策权。

## Committer 提名流程

1. 任何 PMC 成员可在私有邮件列表提名候选人
2. 提供候选人的贡献记录和提名理由
3. PMC 成员投票（72 小时投票期）
4. 获得至少 3 票赞成且无反对票即通过
5. 由提名人发送邀请邮件
6. 候选人接受后获得 Committer 权限


基金会治理
当项目规模发展到一定程度，加入开源基金会可以提供法律保护、财务管理和中立治理。

治理文档编写
无论选择哪种治理模型，都应该将治理规则文档化。


# 治理文档

## 决策流程

### 日常决策

- 由相关领域的 Maintainer 直接决定
- 通过 PR Review 流程执行

### 重大决策

- 需要 RFC 提案流程
- 核心团队成员投票
- 简单多数通过

### 争议解决

1. 相关方在 Issue 中讨论
2. 邀请其他 Maintainer 参与
3. 核心团队投票表决
4. 结果在 72 小时内公布

小结
    

  • 开源治理定义了决策机制、权力分配和冲突解决方式，是项目长期健康的基础。
    • 

  • BDFL 模型适合小型项目，决策迅速但有单点故障风险。
    • 

  • 精英制根据贡献分配权力，Apache 基金会是其最成熟的实践者。
    • 

  • 基金会提供法律保护和中立治理，适合多企业参与的大型项目。
    • 

  • 无论选择哪种模型，都应将治理规则文档化在 GOVERNANCE.md 中。
    •
