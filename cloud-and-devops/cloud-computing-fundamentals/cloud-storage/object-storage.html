对象存储

核心概念

对象存储是云计算中最基础的存储服务，以扁平化的键值结构存储和检索非结构化数据。与块存储和文件存储不同，对象存储没有目录层级概念，每个对象由唯一键（Key）、数据体（Value）和元数据（Metadata）组成。AWS S3 是对象存储的事实标准，其 API 已成为行业通用接口。

S3 存储类与生命周期管理
AWS S3 提供了多种存储类（Storage Class），每种类在访问延迟、可用性和成本之间做出不同权衡。选择合适的存储类是对象存储成本优化的关键。


S3 Standard 是默认存储类，提供毫秒级访问延迟和 99.99% 可用性。数据跨至少 3 个 AZ 存储，durability 达到 11 个 9（99.999999999%）。适合频繁访问的热数据。


S3 Intelligent-Tiering 自动根据访问模式在不同存储层之间移动数据。频繁访问层与 Standard 相同，30 天未访问的数据自动移至低频访问层（节省约 40% 成本），90 天未访问移至归档即时访问层。Intelligent-Tiering 适合访问模式不可预测的数据。


S3 Glacier 和 Glacier Deep Archive 面向长期归档数据。Glacier 的检索时间从 1-5 分钟（加急）到 3-5 小时（标准）不等。Glacier Deep Archive 的检索时间为 12 小时，但存储成本仅为 Standard 的约 1/30。适合法规要求的长期数据保留。


生命周期策略（Lifecycle Policy）自动在存储类之间转换数据或在指定时间后删除数据。典型策略是：创建后 30 天从 Standard 转换为 Standard-IA，90 天后转换为 Glacier，365 天后转换为 Glacier Deep Archive，7 年后删除。

对象存储安全与访问控制
S3 的安全机制涵盖加密、访问控制和审计三个层面。默认情况下，所有 S3 对象都是私有的，只有对象所有者才能访问。


服务端加密（SSE）是 S3 安全的基础。SSE-S3 使用 AWS 管理的密钥自动加密，无额外成本。SSE-KMS 使用 AWS KMS 管理的密钥，提供密钥使用审计和更精细的权限控制。SSE-C 允许用户提供自己的加密密钥。2023 年起 AWS 默认对所有新 S3 对象启用 SSE-S3 加密。


存储桶策略（Bucket Policy）是资源级别的访问控制。策略通过 JSON 文档定义允许或拒绝的操作、主体和条件。常见用法包括：限制特定 VPC 或 IP 范围的访问、强制要求 HTTPS 传输、要求特定加密方式、跨账户访问授权。


S3 Block Public Access 是防止数据泄露的安全护栏。它在账户级别和存储桶级别提供四项设置，可以阻止新的公开 ACL、阻止通过 ACL 获得的公开访问、阻止新的公开存储桶策略和阻止通过存储桶策略获得的公开访问。


S3 Access Points 简化了大规模存储桶的访问管理。每个 Access Point 有独立的 DNS 名称和权限策略，适合多租户场景——每个团队或应用通过独立的 Access Point 访问同一存储桶的不同前缀，无需在单一存储桶策略中管理复杂的权限规则。


高级特性与数据管理
S3 版本控制（Versioning）保留对象的所有历史版本。启用版本控制后，每次覆盖或删除操作都会创建新版本而非替换原始对象。这提供了数据恢复能力和防误删保护。结合 MFA Delete 可以防止恶意或意外的版本删除。


S3 复制功能支持跨 Region 复制（CRR）和同 Region 复制（SRR）。CRR 将对象异步复制到另一个 Region 的存储桶，用于灾备和低延迟跨区域访问。SRR 在同一 Region 内复制数据，用于日志聚合和合规数据副本。


S3 事件通知在对象创建、删除等事件发生时触发 Lambda 函数、SQS 消息或 SNS 通知。这是构建事件驱动数据处理管道的基础——例如上传图片后自动触发缩略图生成，上传日志文件后自动触发分析任务。


S3 Select 和 Glacier Select 允许使用 SQL 表达式直接查询对象内容，无需下载整个对象。对于 CSV、JSON 和 Parquet 格式的大文件，S3 Select 可以将数据传输量减少 80%，查询速度提升 400%。


S3 Transfer Acceleration 利用 CloudFront 边缘节点加速远距离上传。客户端将数据上传到最近的 Edge Location，然后通过 AWS 骨干网传输到目标存储桶。对于跨洲上传场景，加速效果可达 50-500%。


小结
    

  • 对象存储以扁平化键值结构存储非结构化数据，S3 API 已成为行业标准
    • 

  • 存储类选择（Standard/IA/Glacier）和生命周期策略是成本优化的关键，Intelligent-Tiering 适合访问模式不确定的数据
    • 

  • S3 安全包含加密（SSE-S3/KMS/C）、存储桶策略、Block Public Access 和 Access Points 多重机制
    • 

  • 版本控制和跨 Region 复制提供数据保护和灾备能力
    • 

  • 事件通知和 S3 Select 使对象存储成为数据管道的核心组件
    • 

  • Transfer Acceleration 通过边缘网络加速远距离数据上传
