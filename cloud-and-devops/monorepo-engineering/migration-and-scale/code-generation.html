代码生成

代码生成在 Monorepo 中的价值

在 Monorepo 中创建一个新包需要遵循一系列约定：目录结构、package.json 的标准字段、tsconfig.json 的正确配置、ESLint 和 Vitest 的初始化……手动完成这些步骤既繁琐又容易出错。代码生成（Code Generation）通过模板和脚手架工具将"创建新包"变成一个自动化、标准化的过程，确保每个新包都符合团队约定。



Plop 脚手架
Plop 是一个轻量级的代码生成工具，通过定义 generator 和 Handlebars 模板来创建文件：


// plopfile.ts
import type { NodePlopAPI } from 'plop';

export default function (plop: NodePlopAPI): void {
  plop.setGenerator('package', {
    description: 'Create a new shared package',
    prompts: [
      {
        type: 'input',
        name: 'name',
        message: 'Package name (without scope):',
      },
      {
        type: 'list',
        name: 'type',
        message: 'Package type:',
        choices: ['library', 'config', 'types'],
      },
      {
        type: 'confirm',
        name: 'hasReact',
        message: 'Does this package use React?',
        default: false,
      },
    ],
    actions: [
      {
        type: 'add',
        path: 'packages/{{name}}/package.json',
        templateFile: 'templates/package/package.json.hbs',
      },
      {
        type: 'add',
        path: 'packages/{{name}}/tsconfig.json',
        templateFile: 'templates/package/tsconfig.json.hbs',
      },
      {
        type: 'add',
        path: 'packages/{{name}}/src/index.ts',
        templateFile: 'templates/package/index.ts.hbs',
      },
      {
        type: 'add',
        path: 'packages/{{name}}/vitest.config.ts',
        templateFile: 'templates/package/vitest.config.ts.hbs',
      },
    ],
  });
}

Turbo Gen（Turborepo 内置）
Turborepo 从 v1.10 开始内置了代码生成功能 Turbo Gen：


// turbo/generators/config.ts
import type { PlopTypes } from '@turbo/gen';

export default function generator(plop: PlopTypes.NodePlopAPI): void {
  plop.setGenerator('package', {
    description: 'Create a new package in the monorepo',
    prompts: [
      {
        type: 'input',
        name: 'name',
        message: 'Package name:',
      },
    ],
    actions: [
      {
        type: 'add',
        path: 'packages/{{ name }}/package.json',
        templateFile: 'templates/package.json.hbs',
      },
      {
        type: 'add',
        path: 'packages/{{ name }}/src/index.ts',
        template: 'export const {{ name }} = {};',
      },
    ],
  });
}
# 使用 Turbo Gen
turbo gen


初始化后的自动化步骤
生成新包后，还需要执行一些自动化步骤确保包可用：


// scripts/post-generate.mts
import { execSync } from 'node:child_process';

function postGenerate(packageName: string): void {
  console.log(`Initializing @myorg/${packageName}...`);

  execSync('pnpm install', { stdio: 'inherit' });

  execSync(`pnpm turbo run build --filter=@myorg/${packageName}`, {
    stdio: 'inherit',
  });

  execSync(`pnpm turbo run typecheck --filter=@myorg/${packageName}`, {
    stdio: 'inherit',
  });

  console.log(`✅ @myorg/${packageName} is ready!`);
}

小结
    

  • 代码生成确保每个新包都遵循团队约定，避免手动创建导致的不一致
    • 

  • Plop 适合需要灵活定制的场景，Hygen 适合偏好零配置的团队，Turbo Gen 适合 Turborepo 用户
    • 

  • 模板应覆盖 package.json、tsconfig.json、src/index.ts 和测试配置等关键文件
    • 

  • 生成后的自动化步骤（安装依赖、构建验证）确保新包立即可用
    • 

  • 强制所有新包通过脚手架创建是保持 Monorepo 一致性的关键制度约定
    •
