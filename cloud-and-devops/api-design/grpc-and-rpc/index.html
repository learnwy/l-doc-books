gRPC 与 RPC 简介

在微服务架构中，服务间通信的效率与可靠性直接影响整体系统性能。gRPC 是 Google 开发的高性能远程过程调用框架，基于 HTTP/2 协议和 Protocol Buffers 序列化，提供了比传统 REST API 更高效的通信方式。本章系统讲解 gRPC 的核心机制与实践模式，帮助读者在合适的场景中选择和使用 RPC 通信。

本章内容概览：

gRPC 基础讲解 gRPC 的架构设计与核心特性，包括 HTTP/2 多路复用、服务定义与代码生成、四种通信模式（一元调用、服务端流、客户端流、双向流）、拦截器机制、错误处理以及 gRPC 与 REST 的选型对比。

Protobuf深入讲解 Protocol Buffers 序列化协议，涵盖消息定义语法、字段类型与编号规则、嵌套消息与枚举、向前向后兼容的演进策略、性能特征以及与 JSON 的互操作方案。

流式模式探讨 gRPC 最具特色的流式通信能力，涵盖服务端推送、实时数据同步、大文件传输、流式聚合计算等典型应用场景，以及流控制、错误传播和连接管理等工程化实践。

学习建议：建议按顺序学习三篇文档，因为 Protobuf 是 gRPC 的基础，流式模式是 gRPC 的进阶特性。如果你的团队正在进行微服务拆分或评估服务间通信方案，本章将帮助你判断 gRPC 是否适合你的场景并掌握其核心用法。
