包管理器分发

为什么需要包管理器

将 CLI 工具发布到包管理器（Package Manager）能大幅降低用户的安装门槛。用户只需一条命令即可安装、更新和卸载工具，无需手动下载、解压和配置 PATH。

包管理器 平台 安装命令 用户群体
Homebrew macOS/Linux brew install mytool 开发者
Scoop Windows scoop install mytool Windows 开发者
apt/deb Debian/Ubuntu apt install mytool Linux 服务器
yum/rpm CentOS/Fedora yum install mytool Linux 服务器
cargo install 跨平台 cargo install mytool Rust 开发者
npm install -g 跨平台 npm install -g mytool Node.js 开发者 


Homebrew Formula
Homebrew 是 macOS 和 Linux 上最流行的包管理器。发布 Homebrew formula 需要创建一个描述安装过程的 Ruby 脚本。


class Mytool < Formula
  desc "高性能命令行开发工具"
  homepage "https://github.com/myorg/mytool"
  version "1.0.0"
  license "MIT"

  on_macos do
    if Hardware::CPU.arm?
      url "https://github.com/myorg/mytool/releases/download/v1.0.0/mytool-aarch64-apple-darwin.tar.gz"
      sha256 "abc123..."
    else
      url "https://github.com/myorg/mytool/releases/download/v1.0.0/mytool-x86_64-apple-darwin.tar.gz"
      sha256 "def456..."
    end
  end

  on_linux do
    if Hardware::CPU.arm?
      url "https://github.com/myorg/mytool/releases/download/v1.0.0/mytool-aarch64-unknown-linux-musl.tar.gz"
      sha256 "ghi789..."
    else
      url "https://github.com/myorg/mytool/releases/download/v1.0.0/mytool-x86_64-unknown-linux-musl.tar.gz"
      sha256 "jkl012..."
    end
  end

  def install
    bin.install "mytool"
    generate_completions_from_executable(bin/"mytool", "completions")
  end

  test do
    assert_match "mytool", shell_output("#{bin}/mytool --version")
  end
end

Scoop Manifest
Scoop 是 Windows 上的命令行包管理器，manifest 使用 JSON 格式。


{
  "version": "1.0.0",
  "description": "高性能命令行开发工具",
  "homepage": "https://github.com/myorg/mytool",
  "license": "MIT",
  "architecture": {
    "64bit": {
      "url": "https://github.com/myorg/mytool/releases/download/v1.0.0/mytool-x86_64-pc-windows-msvc.zip",
      "hash": "sha256:abc123..."
    }
  },
  "bin": "mytool.exe",
  "checkver": {
    "github": "https://github.com/myorg/mytool"

  "autoupdate": {
    "architecture": {
      "64bit": {
        "url": "https://github.com/myorg/mytool/releases/download/v$version/mytool-x86_64-pc-windows-msvc.zip"
      }
    }
  }
}


自动化 Formula 生成
手动维护 formula 容易出错，可以通过 CI 脚本自动生成。


use std::process::Command;
use sha2::{Sha256, Digest};

struct ReleaseAsset {
    target: &'static str,
    url: String,
    sha256: String,
}

fn compute_sha256(path: &str) -> String {
    let data = std::fs::read(path).unwrap();
    let hash = Sha256::digest(&data);
    format!("{:x}", hash)
}

fn generate_formula(version: &str, assets: &[ReleaseAsset]) -> String {
    let mut formula = format!(r#"class Mytool < Formula
  desc "高性能命令行开发工具"
  homepage "https://github.com/myorg/mytool"
  version "{version}"
  license "MIT"

"#);

    for asset in assets {
        if asset.target.contains("apple-darwin") {
            let arch = if asset.target.contains("aarch64") { "arm?" } else { "intel?" };
            formula.push_str(&format!(
                r#"  on_macos do
    if Hardware::CPU.{arch}
      url "{url}"
      sha256 "{sha256}"
    end
  end

"#,
                arch = arch,
                url = asset.url,
                sha256 = asset.sha256,
            ));
        }
    }

    formula.push_str(r#"  def install
    bin.install "mytool"
  end

  test do
    assert_match "mytool", shell_output("#{bin}/mytool --version")
  end
end
"#);

    formula
}

fn main() {
    println!("Formula 生成器就绪");
}


提示： 使用 GitHub Actions 在每次 Release 后自动更新 Homebrew Tap 仓库中的 formula 文件，实现完全自动化的发布流程。






apt/yum 分发
为 Debian/Ubuntu（apt）和 CentOS/Fedora（yum）发布需要构建 .deb 和 .rpm 包。


# 使用 cargo-deb 构建 .deb 包
cargo install cargo-deb
cargo deb --target x86_64-unknown-linux-musl

# 使用 cargo-generate-rpm 构建 .rpm 包
cargo install cargo-generate-rpm
cargo build --release --target x86_64-unknown-linux-musl
cargo generate-rpm --target x86_64-unknown-linux-musl
Cargo.toml 中的 deb 配置：


[package.metadata.deb]
maintainer = "My Org <dev@myorg.com>"
copyright = "2026, My Org"
license-file = ["LICENSE", "0"]
extended-description = "高性能命令行开发工具"
section = "utility"
priority = "optional"
assets = [
    ["target/release/mytool", "usr/bin/", "755"],
    ["completions/mytool.bash", "usr/share/bash-completion/completions/mytool", "644"],
    ["man/mytool.1", "usr/share/man/man1/mytool.1", "644"],
]

小结
    

  • 包管理器分发让用户一条命令完成安装、更新和卸载
    • 

  • Homebrew formula 是 macOS 分发的标准方式，自有 Tap 适合任何项目
    • 

  • Scoop manifest 使用 JSON 格式，支持自动更新检测
    • 

  • cargo-deb 和 cargo-generate-rpm 简化了 Linux 包的构建流程
    • 

  • CI 应自动化 formula/manifest 的生成和发布，避免手动维护的遗漏
    •
