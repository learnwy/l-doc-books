Part II · 命令行与本地工具命令行工具开发 简介Node.js CLI 简介进程管理

进程管理

child_process 模块

Node.js 的 child_process 模块是执行外部命令和管理子进程的核心 API。CLI 工具经常需要调用 Git、Docker、编译器等外部工具。

import { execSync, spawn, exec } from 'node:child_process';
import { promisify } from 'node:util';

const execAsync = promisify(exec);

function runSync(command: string): string {
  try {
    return execSync(command, {
      encoding: 'utf-8',
      stdio: ['pipe', 'pipe', 'pipe'],
    }).trim();
  } catch (error) {
    const e = error as { stderr?: string; status?: number };
    throw new Error(`命令失败 (exit ${e.status}): ${e.stderr?.trim()}`);
  }
}

async function runAsync(command: string): Promise<string> {
  const { stdout, stderr } = await execAsync(command);
  if (stderr) {
    process.stderr.write(stderr);
  }
  return stdout.trim();
}

async function main(): Promise<void> {
  const branch = runSync('git rev-parse --abbrev-ref HEAD');
  console.log(`当前分支: ${branch}`);

  const status = await runAsync('git status --porcelain');
  console.log(`变更文件: ${status.split('\n').length}`);
}

main().catch(console.error);
方法 同步/异步 输出方式 适用场景
execSync 同步 返回缓冲区 简单命令，结果小
exec 异步回调 缓冲区回调 简单异步命令
spawn 异步流 流式输出 长时间运行、大输出
fork 异步 IPC 通信 Node.js 子进程

Execa：更好的进程管理

execa 是对 child_process 的高级封装，提供了 Promise API、更好的错误处理和流式操作。

import { execa, execaSync, $ } from 'execa';

async function buildProject(): Promise<void> {
  const { stdout } = await execa('node', ['--version']);
  console.log(`Node.js 版本: ${stdout}`);

  try {
    await execa('npm', ['run', 'build'], {
      stdio: 'inherit',
      cwd: process.cwd(),
    });
    console.log('✓ 构建成功');
  } catch (error) {
    const e = error as { exitCode?: number; stderr?: string };
    console.error(`✗ 构建失败 (exit ${e.exitCode})`);
    process.exit(1);
  }
}

async function gitOperations(): Promise<void> {
  const { stdout: branch } = await execa('git', ['rev-parse', '--abbrev-ref', 'HEAD']);
  const { stdout: hash } = await execa('git', ['rev-parse', '--short', 'HEAD']);
  const { stdout: status } = await execa('git', ['status', '--porcelain']);

  console.log(`分支: ${branch}`);
  console.log(`提交: ${hash}`);
  console.log(`变更: ${status.split('\n').filter(Boolean).length} 个文件`);
}

async function pipelineExample(): Promise<void> {
  const { stdout } = await $`cat package.json | grep version`;
  console.log(stdout);
}

流式输出

对于长时间运行的命令（如构建、测试），需要实时流式输出（Streaming Output）而不是等待命令完成后一次性返回。

import { spawn } from 'node:child_process';

interface RunOptions {
  command: string;
  args: string[];
  cwd?: string;
  onStdout?: (data: string) => void;
  onStderr?: (data: string) => void;
}

function runStreaming(options: RunOptions): Promise<number> {
  return new Promise((resolve, reject) => {
    const child = spawn(options.command, options.args, {
      cwd: options.cwd || process.cwd(),
      stdio: ['inherit', 'pipe', 'pipe'],
    });

    child.stdout?.on('data', (data: Buffer) => {
      const text = data.toString();
      if (options.onStdout) {
        options.onStdout(text);
      } else {
        process.stdout.write(text);
      }
    });

    child.stderr?.on('data', (data: Buffer) => {
      const text = data.toString();
      if (options.onStderr) {
        options.onStderr(text);
      } else {
        process.stderr.write(text);
      }
    });

    child.on('error', reject);
    child.on('close', (code) => resolve(code ?? 1));
  });
}

async function main(): Promise<void> {
  const exitCode = await runStreaming({
    command: 'npm',
    args: ['test'],
    onStdout: (data) => {
      process.stdout.write(`[TEST] ${data}`);
    },
  });

  if (exitCode !== 0) {
    console.error(`测试失败 (exit ${exitCode})`);
    process.exit(exitCode);
  }
}

main().catch(console.error);


信号处理
CLI 工具需要正确处理信号（Signals），特别是 SIGINT（Ctrl+C）和 SIGTERM，确保子进程也能正常退出。


function setupSignalHandlers(): void {
  let isShuttingDown = false;
  const childProcesses: Set<ReturnType<typeof import('node:child_process').spawn>> = new Set();

  function cleanup(signal: string): void {
    if (isShuttingDown) return;
    isShuttingDown = true;

    console.log(`\n收到 ${signal}，正在清理...`);

    for (const child of childProcesses) {
      child.kill('SIGTERM');
    }

    setTimeout(() => {
      for (const child of childProcesses) {
        child.kill('SIGKILL');
      }
      process.exit(1);
    }, 5000);
  }

  process.on('SIGINT', () => cleanup('SIGINT'));
  process.on('SIGTERM', () => cleanup('SIGTERM'));
}

process.on('unhandledRejection', (reason) => {
  console.error('未处理的 Promise 拒绝:', reason);
  process.exit(1);
});

process.on('uncaughtException', (error) => {
  console.error('未捕获的异常:', error);
  process.exit(1);
});

提示： 始终设置 unhandledRejection 和 uncaughtException 处理器，防止 Node.js 进程在未预期的错误中静默退出。






小结
    

  • child_process 是 Node.js 执行外部命令的核心模块，spawn 用于流式输出，execSync 用于简单同步命令
    • 

  • execa 提供了更现代的 API，自动处理编码、错误格式化和流管理
    • 

  • 长时间运行的命令应使用流式输出，避免缓冲区溢出和用户等待焦虑
    • 

  • 信号处理确保 Ctrl+C 时子进程也能正确终止，设置超时后强制 kill
    • 

  • 始终捕获 unhandledRejection 和 uncaughtException，防止进程静默退出
    •
