帮助与文档

帮助系统的层次

CLI 工具的帮助系统（Help System）是用户发现和学习功能的主要途径。一个完整的帮助体系包含多个层次，从快速查看到深入参考。

层次 触发方式 内容深度 适用场景
短帮助 -h 一行简介 + 参数列表 快速提醒
长帮助 --help 详细说明 + 示例 首次学习
Man page man mytool 完整参考文档 深入查阅
Shell 补全 Tab 键 自动补全建议 日常使用
在线文档 URL 教程 + API 参考 系统学习 


--help 自动生成
主流参数解析库都能自动生成格式化的帮助输出。在 Rust 的 clap 中，帮助信息从结构体注解和文档注释中自动提取。


use clap::{Parser, Subcommand};

/// 高性能文件搜索工具
///
/// 支持正则表达式、文件类型过滤和递归搜索。
/// 默认忽略 .gitignore 中的文件。
#[derive(Parser)]
#[command(name = "search", version, about, long_about)]
#[command(after_help = "示例:\n  search 'fn main' --type rs\n  search TODO --ignore-case\n  search '^import' src/")]
struct Cli {
    /// 搜索模式（支持正则表达式）
    pattern: String,

    /// 搜索目录（默认当前目录）
    #[arg(default_value = ".")]
    path: String,

    /// 忽略大小写
    #[arg(short, long)]
    ignore_case: bool,

    /// 限制文件类型（如 rs, ts, py）
    #[arg(short = 't', long = "type")]
    file_type: Option<String>,

    /// 显示匹配行的上下文行数
    #[arg(short = 'C', long, default_value_t = 0)]
    context: usize,

    /// 最大搜索深度
    #[arg(long)]
    max_depth: Option<usize>,

    /// 输出格式
    #[arg(long, default_value = "text", value_parser = ["text", "json", "count"])]
    format: String,

    #[command(subcommand)]
    command: Option<Commands>,
}

#[derive(Subcommand)]
enum Commands {
    /// 列出支持的文件类型
    ListTypes,
    /// 生成 shell 补全脚本
    Completions {
        /// 目标 shell 类型
        #[arg(value_parser = ["bash", "zsh", "fish", "powershell"])]
        shell: String,
    },
}

fn main() {
    let cli = Cli::parse();
    println!("搜索 '{}' 在 {}", cli.pattern, cli.path);
}

Man Pages 生成
Man pages 是 Unix 系统中的标准文档格式。clap 生态提供了 clap_mangen 用于自动生成 man pages。


// build.rs
use clap::CommandFactory;
use clap_mangen::Man;
use std::fs;

#[path = "src/cli.rs"]
mod cli;

fn main() {
    let out_dir = std::env::var("OUT_DIR").unwrap();
    let cmd = cli::Cli::command();

    let man = Man::new(cmd.clone());
    let mut buffer = Vec::new();
    man.render(&mut buffer).unwrap();

    let man_path = format!("{}/search.1", out_dir);
    fs::write(&man_path, buffer).unwrap();

    for sub in cmd.get_subcommands() {
        let mut buffer = Vec::new();
        Man::new(sub.clone()).render(&mut buffer).unwrap();
        let path = format!("{}/search-{}.1", out_dir, sub.get_name());
        fs::write(&path, buffer).unwrap();
    }
}

Shell Completions
Shell 补全（Shell Completions）让用户按 Tab 键自动补全命令、子命令和参数，极大提升日常使用效率。


use clap::{Command, Arg};
use clap_complete::{generate, shells};
use std::io;

fn build_cli() -> Command {
    Command::new("mytool")
        .version("1.0.0")
        .subcommand(Command::new("init").arg(Arg::new("name").required(true)))
        .subcommand(Command::new("build").arg(Arg::new("release").long("release")))
        .subcommand(Command::new("deploy").arg(
            Arg::new("env").long("env").value_parser(["dev", "staging", "prod"])
        ))
        .subcommand(Command::new("completions").arg(
            Arg::new("shell")
                .required(true)
                .value_parser(["bash", "zsh", "fish", "powershell"])
        ))
}

fn main() {
    let matches = build_cli().get_matches();

    if let Some(sub) = matches.subcommand_matches("completions") {
        let shell_name = sub.get_one::<String>("shell").unwrap();
        let mut cmd = build_cli();
        match shell_name.as_str() {
            "bash" => generate(shells::Bash, &mut cmd, "mytool", &mut io::stdout()),
            "zsh" => generate(shells::Zsh, &mut cmd, "mytool", &mut io::stdout()),
            "fish" => generate(shells::Fish, &mut cmd, "mytool", &mut io::stdout()),
            _ => eprintln!("不支持的 shell: {}", shell_name),
        }
    }
}
安装补全脚本的常见方式：


# Bash
mytool completions bash > ~/.local/share/bash-completion/completions/mytool

# Zsh
mytool completions zsh > ~/.zfunc/_mytool

# Fish
mytool completions fish > ~/.config/fish/completions/mytool.fish

小结
    

  • 帮助系统应分层提供：-h 快速查看、--help 详细学习、man page 完整参考
    • 

  • clap 从结构体注解和文档注释自动生成帮助输出，after_help 添加使用示例
    • 

  • clap_mangen 生成标准 man pages，clap_complete 生成 shell 补全脚本
    • 

  • Shell 补全是提升日常使用效率的最有效手段，应为主流 shell 提供补全脚本
    • 

  • 帮助信息应包含具体的使用示例，这比参数列表对新用户更有价值
    •
