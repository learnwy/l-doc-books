Service 与 Ingress

Service 概述

Kubernetes 中的 Pod IP 地址是临时的，Pod 重建后 IP 会变化。Service 为一组 Pod 提供稳定的访问入口和负载均衡，是 Kubernetes 服务发现的核心机制。

apiVersion: v1
kind: Service
metadata:
  name: api-service
spec:
  selector:
    app: api-server
  ports:
    - port: 80
      targetPort: 3000
      protocol: TCP
  type: ClusterIP

Service 类型
Kubernetes 提供四种 Service 类型，适用于不同的网络访问场景。


ClusterIP
apiVersion: v1
kind: Service
metadata:
  name: internal-api
spec:
  type: ClusterIP
  selector:
    app: api
  ports:
    - port: 80
      targetPort: 3000
NodePort
apiVersion: v1
kind: Service
metadata:
  name: web-nodeport
spec:
  type: NodePort
  selector:
    app: web
  ports:
    - port: 80
      targetPort: 8080
      nodePort: 30080
LoadBalancer
apiVersion: v1
kind: Service
metadata:
  name: web-lb
  annotations:
    service.beta.kubernetes.io/aws-load-balancer-type: nlb
spec:
  type: LoadBalancer
  selector:
    app: web
  ports:
    - port: 443
      targetPort: 8080

Ingress 资源
Ingress 提供 HTTP/HTTPS 层面的路由规则，将外部流量根据域名和路径分发到不同的 Service。


apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: app-ingress
  annotations:
    nginx.ingress.kubernetes.io/ssl-redirect: 'true'
    cert-manager.io/cluster-issuer: letsencrypt-prod
spec:
  ingressClassName: nginx
  tls:
    - hosts:
        - app.example.com
        - api.example.com
      secretName: app-tls
  rules:
    - host: app.example.com
      http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: frontend
                port:
                  number: 80
    - host: api.example.com
      http:
        paths:
          - path: /v1
            pathType: Prefix
            backend:
              service:
                name: api-v1
                port:
                  number: 80
          - path: /v2
            pathType: Prefix
            backend:
              service:
                name: api-v2
                port:
                  number: 80

网络策略
NetworkPolicy 控制 Pod 之间以及 Pod 与外部之间的网络流量，实现微服务级别的网络安全隔离。


apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: api-network-policy
spec:
  podSelector:
    matchLabels:
      app: api
  policyTypes:
    - Ingress
    - Egress
  ingress:
    - from:
        - podSelector:
            matchLabels:
              app: frontend
      ports:
        - port: 3000
  egress:
    - to:
        - podSelector:
            matchLabels:
              app: database
      ports:
        - port: 5432

小结
    

  • Service 为 Pod 提供稳定的访问入口，ClusterIP 用于内部通信，LoadBalancer 用于外部暴露。
    • 

  • Kubernetes DNS 自动为 Service 创建 DNS 记录，支持同命名空间和跨命名空间的服务发现。
    • 

  • Ingress 在 HTTP/HTTPS 层面实现基于域名和路径的流量路由，需要部署 Ingress Controller。
    • 

  • NetworkPolicy 实现 Pod 级别的网络隔离，默认无策略时所有流量放行。
    • 

  • 生产环境建议使用 Ingress + TLS 作为外部流量入口，配合 NetworkPolicy 实现零信任网络。
