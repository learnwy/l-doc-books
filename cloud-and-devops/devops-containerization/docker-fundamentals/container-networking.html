容器网络

Docker 网络模型

Docker 使用 Container Network Model（CNM）作为网络架构的核心抽象。CNM 定义了三个核心组件：沙箱（Sandbox）、端点（Endpoint）和网络（Network），为容器提供灵活的网络连接能力。





CNM 组件
实现方式

veth pair
连接沙箱与网络的虚拟接口




Network
Linux Bridge/VXLAN
一组可以互相通信的端点集合

网络驱动类型
Docker 提供多种网络驱动，适用于不同的部署场景。


bridge
默认的网络驱动，适用于单机多容器通信。


docker network create --driver bridge \
  --subnet 172.20.0.0/16 \
  --gateway 172.20.0.1 \
  my-bridge

docker run -d --name web --network my-bridge nginx:alpine
docker run -d --name api --network my-bridge node:20-alpine

docker exec web ping -c 3 api
host
容器直接使用宿主机网络栈，没有网络隔离。


docker run -d --network host nginx:alpine

ss -tlnp | grep 80
overlay
跨主机容器通信，用于 Docker Swarm 或多节点部署。


docker network create --driver overlay \
  --attachable \
  --subnet 10.0.9.0/24 \
  my-overlay

提示： 对于本地开发，推荐使用自定义 bridge 网络而非默认的 bridge 网络。自定义 bridge 网络支持容器名称自动 DNS 解析，而默认 bridge 网络只能通过 IP 地址通信。






端口映射与暴露
端口映射将容器内部端口映射到宿主机端口，使外部流量能够到达容器中的服务。


docker run -d \
  -p 8080:3000 \
  -p 127.0.0.1:9229:9229 \
  --name myapp \
  myapp:latest

docker port myapp

iptables -t nat -L -n | grep 8080




映射格式
说明





-p 8080:3000
宿主机所有接口 8080 → 容器 3000




-p 127.0.0.1:8080:3000
仅 localhost 8080 → 容器 3000




-p 8080:3000/udp
UDP 端口映射




-P
自动映射所有 EXPOSE 端口







容器 DNS 与服务发现
Docker 内置 DNS 服务器（127.0.0.11），为自定义网络中的容器提供名称解析。


docker network create app-net

docker run -d --name postgres --network app-net postgres:16-alpine
docker run -d --name redis --network app-net redis:7-alpine
docker run -d --name api --network app-net \
  -e DATABASE_URL=postgres://postgres:5432/mydb \
  -e REDIS_URL=redis://redis:6379 \
  myapi:latest

docker exec api nslookup postgres




DNS 特性
说明





自动注册

容器名解析
通过容器名称解析 IP 地址




网络别名
--network-alias 支持多个名称




轮询负载均衡
同名容器自动 DNS 轮询







提示： 在多副本部署中，可以给多个容器设置相同的 --network-alias，Docker DNS 会自动实现基于 DNS 的轮询负载均衡。这是一种简单有效的服务发现机制。






网络安全与隔离
利用 Docker 网络实现微服务间的网络隔离，遵循最小权限原则。


docker network create frontend
docker network create backend

docker run -d --name nginx --network frontend nginx:alpine
docker run -d --name api --network frontend node:20-alpine
docker network connect backend api
docker run -d --name db --network backend postgres:16-alpine

小结
    

  • Docker 网络基于 CNM 模型，通过 Sandbox、Endpoint 和 Network 三个抽象组件实现灵活的容器互联。
    • 

  • bridge 是默认驱动，适用于单机场景；overlay 支持跨主机通信；host 提供最优性能但无隔离。
    • 

  • 自定义 bridge 网络支持容器名称的自动 DNS 解析，优于默认 bridge 网络。
    • 

  • 端口映射通过 iptables NAT 规则实现，可绑定特定接口以限制访问范围。
    • 

  • 利用多网络隔离实现微服务间的最小权限访问控制。
