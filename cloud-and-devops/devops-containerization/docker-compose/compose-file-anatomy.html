Compose 文件解析

文件结构概览

Docker Compose 使用 YAML 格式的声明式配置文件描述多容器应用。从 Compose V2 开始，推荐使用 compose.yaml 作为默认文件名，取代旧的 docker-compose.yml。

name: myproject

services:
  web:
    image: nginx:alpine
    ports:
      - '8080:80'
    volumes:
      - ./html:/usr/share/nginx/html:ro
    networks:
      - frontend

  api:
    build:
      context: ./api
      dockerfile: Dockerfile
    environment:
      DATABASE_URL: postgres://user:pass@db:5432/mydb
    depends_on:
      db:
        condition: service_healthy
    networks:
      - frontend
      - backend

  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: mydb
      POSTGRES_USER: user
      POSTGRES_PASSWORD: pass
    volumes:
      - pgdata:/var/lib/postgresql/data
    healthcheck:
      test: ['CMD-SHELL', 'pg_isready -U user']
      interval: 10s
      timeout: 5s
      retries: 5
    networks:
      - backend

volumes:
  pgdata:

networks:
  frontend:
  backend:
顶级键 作用 必需
name 项目名称 否
services 定义应用的各个服务 是
networks 定义自定义网络 否
volumes 定义命名数据卷 否
configs 定义配置对象 否
secrets 定义敏感数据 否 


服务配置详解
每个 service 定义了一个容器的完整运行规格，包括镜像来源、端口映射、环境变量等。


构建配置
services:
  app:
    build:
      context: .
      dockerfile: Dockerfile.prod
      target: runtime
      args:
        NODE_ENV: production
      cache_from:
        - type=registry,ref=registry.example.com/myapp:cache
    platform: linux/amd64
资源限制
services:
  worker:
    image: myworker:latest
    deploy:
      resources:
        limits:
          cpus: '2.0'
          memory: 1G
        reservations:
          cpus: '0.5'
          memory: 256M
      replicas: 3

网络配置
Compose 自动为每个项目创建一个默认的 bridge 网络，也可以自定义网络拓扑实现服务隔离。


networks:
  frontend:
    driver: bridge
    ipam:
      config:
        - subnet: 172.28.0.0/16
  backend:
    driver: bridge
    internal: true

环境变量与配置
Compose 支持多种环境变量注入方式，满足不同场景的配置需求。


services:
  api:
    image: myapi:latest
    environment:
      - NODE_ENV=production
      - LOG_LEVEL=${LOG_LEVEL:-info}
    env_file:
      - .env
      - .env.local
变量优先级从高到低：


docker compose run -e DEBUG=1 api

docker compose --env-file .env.staging up

docker compose config

小结
    

  • Compose 文件使用 YAML 声明式语法，核心顶级键为 services、networks 和 volumes。
    • 

  • 服务配置支持 image（使用现有镜像）和 build（从 Dockerfile 构建）两种模式。
    • 

  • 网络配置通过 internal: true 可创建完全隔离的内部网络，外部流量无法到达。
    • 

  • 环境变量支持五级优先级覆盖，使用 docker compose config 验证最终配置。
    • 

  • Compose V2 推荐使用 compose.yaml 文件名和 docker compose 命令格式。
    •
