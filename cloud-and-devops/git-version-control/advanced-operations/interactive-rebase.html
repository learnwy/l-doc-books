交互式变基

什么是交互式变基

交互式变基（Interactive Rebase） 是 git rebase 的增强模式，允许你在变基过程中逐个编辑提交。它是整理提交历史最强大的工具。

git rebase -i HEAD~5

git rebase -i main

执行后 Git 会打开编辑器，列出指定范围内的所有提交：

pick a1b2c3d feat: add login page
pick e4f5g6h fix: typo in login form
pick i7j8k9l feat: add validation
pick m0n1o2p fix: validation edge case
pick q3r4s5t feat: add remember me checkbox

六种操作命令

命令 缩写 作用
pick p 保留该提交不做修改
reword r 保留提交内容，修改提交消息
edit e 暂停在该提交，允许修改内容
squash s 与前一个提交合并，保留两者的提交消息
fixup f 与前一个提交合并，丢弃该提交的消息
drop d 完全删除该提交 


Reword：修改提交消息
修改历史中某个提交的消息而不改变其内容：


git rebase -i HEAD~3
将目标提交的 pick 改为 reword：


reword a1b2c3d feat: add login page
pick e4f5g6h fix: typo in login form
pick i7j8k9l feat: add validation
保存后 Git 会打开新的编辑器让你修改该提交的消息。




提示： 只需修改提交消息时用 reword，不要手动在 todo list 中修改消息文本——那不会生效。






Edit：修改提交内容
暂停变基过程，让你修改某个历史提交的文件内容：


git rebase -i HEAD~4
pick a1b2c3d feat: add login page
edit e4f5g6h fix: typo in login form
pick i7j8k9l feat: add validation
pick m0n1o2p fix: validation edge case
Git 暂停后：


# 修改文件
vi src/login.sh

# 将修改加入暂存区
git add src/login.sh

# 修改提交（也可以用 --amend 修改消息）
git commit --amend

# 继续变基
git rebase --continue


Squash 与 Fixup：合并提交
将多个零碎提交合并为一个有意义的提交：


pick a1b2c3d feat: add login page
squash e4f5g6h fix: typo in login form
fixup i7j8k9l fix: another typo
pick m0n1o2p feat: add validation

Drop：删除提交
从历史中完全删除某个提交：


pick a1b2c3d feat: add login page
drop e4f5g6h debug: add console logs
pick i7j8k9l feat: add validation


提示： drop 某个提交可能导致后续提交产生冲突，因为后续提交可能依赖被删除提交引入的更改。






调整提交顺序
交互式变基还允许通过调整行的顺序来重排提交：


pick i7j8k9l feat: add validation
pick a1b2c3d feat: add login page
pick e4f5g6h fix: typo in login form


Autosquash 自动化
配合 --fixup 和 --squash 提交标记，自动化 squash 流程：


git commit --fixup=a1b2c3d
git commit --squash=a1b2c3d

git rebase -i --autosquash main

git config --global rebase.autosquash true
git commit -m "feat: add login page"
# 发现需要补充修改
git add src/login.sh
git commit --fixup=HEAD

# 自动 squash
git rebase -i --autosquash HEAD~3


处理变基冲突
git rebase -i HEAD~5
# 遇到冲突
vi conflicted-file.sh
git add conflicted-file.sh
git rebase --continue

git rebase --abort


小结
    

  • 交互式变基是整理提交历史的最强大工具，提供六种操作命令
    • 

  • reword 修改消息，edit 修改内容，squash/fixup 合并提交，drop 删除提交
    • 

  • autosquash 配合 --fixup 提交标记可以自动化合并流程
    • 

  • 变基过程中遇到冲突需手动解决，--abort 可安全回退到变基前的状态
    • 

  • 遵守黄金法则：不要对已推送到公共仓库的提交执行交互式变基
    •
