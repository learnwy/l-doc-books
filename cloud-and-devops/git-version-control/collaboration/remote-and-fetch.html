远程与拉取

远程仓库基础

远程仓库（Remote） 是托管在网络上的 Git 仓库副本。Git 的分布式架构允许每个开发者拥有完整的仓库副本，通过远程仓库同步变更。

git remote -v

git remote add origin https://github.com/user/repo.git
git remote add upstream https://github.com/org/repo.git

git remote rename origin old-origin
git remote remove old-origin
远程名称 惯例用途
origin 自己 fork 的仓库或主仓库
upstream 原始仓库（fork 场景）
staging 预发布环境仓库

Fetch 与 Pull

Fetch 从远程下载新数据但不合并，Pull 是 fetch + merge 的快捷方式：

git fetch origin
git fetch --all
git fetch origin main

git pull origin main
git pull --rebase origin main
git pull --ff-only origin main




命令
行为
适用场景





git fetch
仅下载，不合并
查看远程变更




git pull
fetch + merge
快速同步




git pull --rebase
fetch + rebase
保持线性历史




git pull --ff-only
仅快进合并，有分叉则失败
安全同步







提示： 推荐在团队中统一使用 git pull --rebase 或配置 pull.rebase=true，避免产生不必要的合并 commit。






Push 推送
git push origin main
git push -u origin feature/login
git push --force-with-lease origin feature/login

git push origin --delete feature/old-branch
git push origin :feature/old-branch

git push --tags
git push origin v1.0.0




选项
作用





-u / --set-upstream
设置上游跟踪关系




--force
强制推送（危险）




--force-with-lease
安全强制推送（检查远程是否有更新）




--tags
推送所有标签




--delete
删除远程分支







提示： 永远使用 --force-with-lease 替代 --force。它会检查远程分支是否被其他人更新过，防止覆盖他人的工作。






Upstream 跟踪关系
跟踪关系（Tracking） 将本地分支与远程分支关联，使 git pull 和 git push 可以省略参数：


git branch -vv

git branch --set-upstream-to=origin/main main
git branch -u origin/feature feature/login

git checkout --track origin/feature/new

git config --global push.default current


多远程仓库管理
Fork 工作流中通常需要管理多个远程：


git remote add upstream https://github.com/org/original-repo.git
git fetch upstream
git merge upstream/main
# 或
git rebase upstream/main

git push origin main
同步 fork 的完整流程：


git fetch upstream
git checkout main
git rebase upstream/main
git push origin main --force-with-lease

git checkout feature/my-work
git rebase main


远程分支清理
git remote prune origin
git fetch --prune

git config --global fetch.prune true

git branch -r
git branch -d feature/merged
git branch -D feature/abandoned




命令
作用





git remote prune origin
删除本地的失效远程跟踪分支




git fetch --prune
fetch 时同步删除失效跟踪分支




git branch -d
删除已合并的本地分支




git branch -D
强制删除本地分支







小结
    

  • Remote 是远程仓库的本地别名，origin 和 upstream 是最常见的命名惯例
    • 

  • Fetch 只下载不合并，是查看远程变更的安全方式；Pull 是 fetch + merge 的快捷方式
    • 

  • 推荐使用 git pull --rebase 保持线性历史，配置 pull.rebase=true 设为默认行为
    • 

  • Push 时使用 --force-with-lease 替代 --force，防止覆盖他人的提交
    • 

  • 定期使用 --prune 清理失效的远程跟踪分支，保持仓库整洁
    •
