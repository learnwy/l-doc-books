暂存与工作树

Git Stash 暂存

Stash（暂存） 允许你将当前工作目录和暂存区的更改临时保存起来，恢复到干净的工作状态，稍后再恢复继续工作。

git stash
git stash push -m "WIP: refactor auth module"

git stash list

git stash show -p stash@{0}

Stash 操作详解

命令 作用
git stash 暂存已跟踪文件的更改
git stash -u 同时暂存未跟踪文件
git stash -a 暂存所有文件（含 .gitignore）
git stash pop 恢复最近的 stash 并删除记录
git stash apply 恢复最近的 stash 但保留记录
git stash drop stash@{n} 删除指定 stash
git stash clear 清空所有 stash
git stash branch <name> 从 stash 创建新分支 
git stash push -m "halfway done with feature" -u
git checkout hotfix-branch
# ... 完成紧急修复 ...
git checkout feature-branch
git stash pop

从 stash 创建分支（当 stash 与当前分支冲突时特别有用）：

git stash branch new-feature stash@{0}

提示： git stash pop 在恢复失败（冲突）时不会删除 stash 记录，你需要手动解决冲突后使用 git stash drop 清理。

部分暂存

使用交互式暂存可以只保存部分文件或部分修改：

git stash push -p

git stash push -- src/auth.sh src/config.sh


Git Worktree 多工作目录
Worktree（工作树） 允许在同一个仓库下同时检出多个分支到不同的目录，避免频繁的分支切换和 stash。


git worktree add ../hotfix-work hotfix/urgent
git worktree add ../release-v2 release/v2.0

git worktree list

git worktree remove ../hotfix-work




特性
stash
worktree





工作方式
保存/恢复更改
创建独立工作目录




并行开发
不支持
支持多分支同时工作




磁盘占用
无额外占用
需要额外目录空间




适用场景
临时中断当前工作
需要长时间并行开发




对象共享
—
共享 .git 对象数据库







提示： Worktree 非常适合在修复紧急 bug 时不想丢失当前开发进度的场景，比 stash 更适合需要长时间处理的并行任务。






Git Clean 清理
git clean 用于删除工作目录中未被 Git 跟踪的文件：


git clean -n
git clean -f
git clean -fd
git clean -fx

git clean -i




选项
作用





-n
干运行，只显示将被删除的文件




-f
强制删除未跟踪文件




-d
同时删除未跟踪的目录




-x
同时删除被 .gitignore 忽略的文件




-X
只删除被 .gitignore 忽略的文件




-i
交互模式，逐个确认







提示： 执行 git clean -f 前务必先用 -n 预览，删除操作不可逆。






实战场景组合
# 场景 1：紧急切换分支
git stash push -m "WIP: feature-x" -u
git checkout hotfix/critical
# ... 修复 ...
git checkout feature-x
git stash pop

# 场景 2：并行开发两个功能
git worktree add ../feature-a feature/a
git worktree add ../feature-b feature/b
# 在两个目录中独立开发

# 场景 3：清理构建产物
git clean -fdX

# 场景 4：完全重置到干净状态
git checkout -- .
git clean -fd


小结
    

  • Stash 是临时保存工作进度的首选工具，支持部分暂存和从 stash 创建分支
    • 

  • Worktree 实现真正的并行开发，多个工作目录共享同一个 Git 对象数据库
    • 

  • Clean 用于清理未跟踪文件，-n 预览是使用前的必要步骤
    • 

  • 根据中断时长选择工具：短暂中断用 stash，长期并行用 worktree
    • 

  • 组合使用这三个工具可以在复杂的多任务场景下保持工作区的整洁有序
    •
