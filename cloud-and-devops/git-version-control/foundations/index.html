基础与原理 简介

Git 的强大源于其精巧的底层设计。理解 Git 的内部数据结构——对象数据库、有向无环图和引用系统——是从"会用 Git"迈向"精通 Git"的关键一步。本章从 Git 的核心原理出发，逐步展开分支模型、合并与变基策略，以及日常工作中不可或缺的暂存与工作树工具。

本章将带你深入四个核心主题：

Git 内部原理 — 揭开 .git 目录的面纱，理解 blob、tree、commit、tag 四种对象类型如何通过 SHA-1 哈希构成一个不可变的有向无环图，以及 HEAD、分支和标签等引用的运作机制。

分支模型 — 对比业界主流的三种分支策略：Git Flow 的多分支管理、GitHub Flow 的轻量协作，以及 Trunk-based 的持续集成模式，帮助你根据团队规模和发布节奏选择最合适的方案。

合并与变基 — 深入讲解 merge、rebase 和 squash 三种代码整合策略的原理与适用场景，以及面对合并冲突时的系统化解决方法。

暂存与工作树 — 掌握 stash 暂存、worktree 多工作目录和 clean 清理等实战技巧，在多任务并行切换时保持工作区的整洁有序。

建议从内部原理开始，理解 Git 的数据模型后再学习分支和合并策略，最后用暂存与工作树工具提升日常效率。扎实的基础将让后续章节的高级操作事半功倍。
