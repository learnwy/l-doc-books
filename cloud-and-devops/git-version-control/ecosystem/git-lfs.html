Git LFS 大文件存储

为什么需要 Git LFS

Git 的设计基于文本差异比较和快照存储，对大型二进制文件（Large Binary Files） 的处理效率很低。每次修改一个 100MB 的文件，Git 都会存储一份完整副本，导致仓库体积急剧膨胀。

文件类型 典型大小 适合 Git LFS
图片/图标 KB-MB ⚠️ 视数量
PSD/Sketch 设计稿 10-500 MB ✅
视频文件 100MB-GB ✅
ML 模型 MB-GB ✅
数据集 MB-GB ✅
编译产物 MB ✅

不使用 LFS 时，大文件带来的问题不仅仅是磁盘占用：git clone 必须下载全部历史中的所有大文件版本，即使当前工作只需要最新版本。一个累积了多次大文件变更的仓库，clone 时间可能从几秒膨胀到数十分钟。

安装与配置

brew install git-lfs
git lfs install

git lfs version

追踪文件

使用 git lfs track 指定要通过 LFS 管理的文件模式：

git lfs track "*.psd"
git lfs track "*.zip"
git lfs track "*.bin"
git lfs track "datasets/**"

cat .gitattributes
# *.psd filter=lfs diff=lfs merge=lfs -text
# *.zip filter=lfs diff=lfs merge=lfs -text

git add .gitattributes
git commit -m "chore: configure Git LFS tracking"


提示： .gitattributes 文件必须提交到仓库中，这样所有协作者才能自动使用 LFS。






工作流程
git lfs track "*.model"
git add .gitattributes
git add models/bert.model
git commit -m "feat: add BERT model"
git push origin main
LFS 指针文件内容：


version https://git-lfs.github.com/spec/v1
oid sha256:4d7a214614ab2935c943f9e0ff69d22eadbb8f32b1258daaa5e2ca24d17e2393
size 104857600




操作
命令





查看追踪模式
git lfs track




查看 LFS 文件
git lfs ls-files




查看 LFS 状态
git lfs status




拉取 LFS 文件
git lfs pull




获取不下载
git lfs fetch




取消追踪
git lfs untrack "*.psd"







迁移已有文件
将仓库中已有的大文件迁移到 LFS：


git lfs migrate import --include="*.psd,*.zip" --everything

git lfs migrate import --include="*.bin" --include-ref=main

git lfs migrate info --everything


提示： migrate import 会重写 Git 历史，操作前务必备份仓库，操作后需要 force push 并通知所有协作者。




迁移前可以使用 git lfs migrate info 分析仓库中哪些文件类型占用空间最多，帮助决定迁移范围：


git lfs migrate info --everything --top=10

LFS 与 CI/CD
CI 环境中需要注意 LFS 文件的下载：


# GitHub Actions
- uses: actions/checkout@v4
  with:
    lfs: true

# 或手动拉取
- uses: actions/checkout@v4
- run: git lfs pull
跳过 LFS 下载（不需要大文件的 CI 任务）：


GIT_LFS_SKIP_SMUDGE=1 git clone https://github.com/user/repo.git




CI 场景
LFS 配置





需要大文件（构建）
lfs: true 或 git lfs pull




不需要（lint）
GIT_LFS_SKIP_SMUDGE=1

小结
    

  • Git LFS 通过指针文件替换大型二进制文件，从根本上解决仓库膨胀问题
    • 

  • 使用 git lfs track 配置追踪模式，.gitattributes 文件必须纳入版本控制
    • 

  • git lfs migrate import 可以将已有大文件迁移到 LFS，但会重写历史
    • 

  • CI/CD 中按需配置 LFS 下载：需要大文件时启用，不需要时用 SKIP_SMUDGE 跳过
    • 

  • 关注 LFS 存储和带宽配额，大规模使用时考虑自建 LFS 服务器
    •
