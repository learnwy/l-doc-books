GUI 与工具

终端 UI 工具

对于习惯命令行的开发者，终端 UI（TUI）工具提供了介于纯命令行和图形界面之间的高效交互体验。

Lazygit

lazygit 是最流行的 Git TUI 工具，提供直观的面板式界面和丰富的键盘快捷键：

brew install lazygit

lazygit
面板 快捷键 功能
Status 1 仓库状态概览
Files 2 文件暂存/取消暂存
Branches 3 分支管理、切换、合并
Commits 4 提交历史、交互式变基
Stash 5 stash 管理 
# lazygit 常用操作
# space  - 暂存/取消暂存文件
# c      - 提交
# P      - 推送
# p      - 拉取
# r      - 在 commits 面板中进入交互式变基
# s      - squash 提交
# f      - fixup 提交
# d      - 在 files 面板中查看 diff


提示： lazygit 的交互式变基体验远优于命令行——直接在 commit 列表上按 s（squash）、f（fixup）、d（drop）即可操作。






Tig
tig 是基于 ncurses 的 Git 仓库浏览器，专注于历史浏览和代码审查：


brew install tig

tig blame src/config.sh
tig log --all
tig stash

Difftool 配置
Difftool 使用外部工具查看文件差异：


git config --global diff.tool vscode
git config --global difftool.vscode.cmd 'code --wait --diff $LOCAL $REMOTE'
git config --global difftool.prompt false

git difftool HEAD~1
git difftool main..feature

Delta 美化输出
delta 是一个 Git diff 输出美化工具，提供语法高亮和 side-by-side 视图：


brew install git-delta

git config --global core.pager delta
git config --global interactive.diffFilter 'delta --color-only'
git config --global delta.navigate true
git config --global delta.side-by-side true
git config --global delta.line-numbers true

Mergetool 配置
git config --global merge.tool vscode
git config --global mergetool.vscode.cmd 'code --wait --merge $REMOTE $LOCAL $BASE $MERGED'
git config --global mergetool.keepBackup false

git mergetool


Git Aliases
自定义别名提升效率：


git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.ci commit
git config --global alias.st status
git config --global alias.lg "log --oneline --graph --all --decorate"
git config --global alias.unstage "reset HEAD --"
git config --global alias.last "log -1 HEAD"
git config --global alias.wip "commit -am 'WIP'"
git lg

git co feature/login
git st
git wip

小结
    

  • lazygit 是功能最丰富的 Git TUI 工具，交互式变基体验尤为出色
    • 

  • tig 专注于历史浏览和 blame，轻量高效
    • 

  • gitui 使用 Rust 编写，在大仓库上性能最佳
    • 

  • delta 将 diff 输出升级为语法高亮 + side-by-side 视图，显著提升可读性
    • 

  • 善用 Git aliases 和配置 difftool/mergetool 可以大幅提升日常操作效率
