Pfizer 绩效考核体系

绩效管理框架概览

辉瑞的绩效管理体系融合了目标管理（OKR/Goal-Based）和年度评估（Annual Review）两种模式，在"科学严谨性"和"商业交付速度"之间寻找平衡。2019年Bourla就任后对绩效体系进行了改革，增加了对创新贡献和跨部门协作的权重，减少对"完美执行已知任务"的过度奖励。

年度绩效周期

Q1 目标设定
每位员工在年初与直属经理共同设定3-5个年度目标（Goals），需要满足：


    

  • 与公司战略对齐——从企业级目标逐层拆解
    • 

  • SMART原则——具体、可衡量、可达成、相关、有时限
    • 

  • 创新目标——至少1个目标涉及"做不同的事"而非"把现有事做得更好"
    • 

  • 协作目标——至少1个目标涉及跨部门合作
    • 



Q2-Q3 持续反馈
辉瑞不等到年底才评估。中间周期管理者需要：


    

  • 提供持续的书面和口头反馈
    • 

  • 识别目标偏离并及时调整
    • 

  • 记录关键成就和待改进领域
    • 



Q4 年终评估
年终评估由员工自评+经理评估+同事反馈（可选360）组成。

Calibration会议
Calibration是辉瑞绩效管理的关键环节——确保评级在跨团队层面的公平性和一致性：


Calibration流程
Calibration的核心原则
    

  1. 相对公平——同一Band内的员工被放在一起比较
    2. 

  2. 防止通胀——确保"Exceptional"不被滥用
    3. 

  3. 跨团队可比——不同经理的评分标准需对齐
    4. 

  4. 科学贡献特殊对待——重大科学突破可突破常规分布
    5. 



科学贡献与商业影响的平衡
制药企业特有的挑战是如何公平评估科学贡献和商业贡献：

辉瑞的解决方案：


    

  • 科学序列有独立的评估委员会（Scientific Review Panel）
    • 

  • 药物发现的"高质量失败"（基于正确假设的阴性结果）不算绩效不佳
    • 

  • 发表高影响力论文和获得重要专利可作为加分项
    • 

  • 科学贡献的评估周期可延长至2-3年
    •

绩效改进计划（PIP）
对于连续绩效不佳的员工，辉瑞会启动Performance Improvement Plan：


    

  • 触发条件：连续2个周期"Partially Achieves"或1次"Does Not Achieve"
    • 

  • 持续时间：通常60-90天
    • 

  • 内容：明确的改进目标、额外支持资源、定期检查点
    • 

  • 结果：通过→恢复正常评估轨道；未通过→解除合同
    • 



在辉瑞2023-2025年的成本削减期间，PIP的使用频率有所增加——这是大型企业在裁员周期中的常见做法。


绩效文化的演进方向
Bourla时代的绩效文化转型重点：


    

  1. 从"做对事"到"做新事"——提高创新权重
    2. 

  2. 从年度评估到持续反馈——缩短反馈周期
    3. 

  3. 从个人KPI到团队KR——增加协作导向
    4. 

  4. 从结果导向到行为+结果——将Purpose Blueprint价值观纳入评估
    5. 



这种转型反映了辉瑞从"执行导向"向"创新导向"的文化转变——在专利悬崖和AI时代，仅仅完成既定任务是不够的，组织需要每个层级都能贡献创新。


绩效结果与职业发展的关系
绩效评级不仅影响当年薪酬，更决定中长期职业轨迹：


    

  • 连续2年Exceptional——自动进入高潜力人才池（HiPo），获得加速发展机会
    • 

  • Exceeds稳定3年——晋升的基本条件（必要不充分）
    • 

  • 1次Partially Achieves——晋升时间线推迟12-18个月
    • 

  • 经理的绩效评级分布——直接影响其管理能力评估和自身晋升
    •
