Pfizer 职场生存指南

大企业政治的制药行业特色

辉瑞作为一家拥有约75,000名员工的全球企业，其内部政治生态既有大企业的共性（层级文化、资源竞争、信息不对称），也有制药行业的特殊性（监管驱动的保守文化、科学权威与管理权力的张力、漫长的产品周期导致的"长期博弈"心态）。

理解并导航这些政治现实，不是"办公室厚黑学"，而是在大型组织中产生实际影响力的必要技能。

裁员常态化：如何保护自己

2023年以来辉瑞持续裁员——从88,000人减至约75,000人，且77亿美元成本削减计划延续至2027年。在这种环境下，"保住工作"需要策略性思维。

裁员风险信号

信号 风险级别 应对
所在部门被标记为"非核心" 高 申请转岗到核心管线
直属经理在Calibration中影响力弱 中高 建立skip-level关系
项目属于被削减的低优先级管线 高 主动争取高优先级项目

反脆弱策略

药企监管文化的双面性
制药行业的监管密度（FDA/EMA/NMPA等）创造了一种独特的组织文化——"合规优先"：


监管文化的优势
    

  • 决策有据可依——一切都需要文档化和可追溯
    • 

  • 质量标准明确——不存在"差不多就行"
    • 

  • 风险意识强——GMP思维延伸到非制造领域
    • 



监管文化的陷阱
    

  • 过度文档化——花在写SOP和报告上的时间多于实际创新
    • 

  • 风险规避——"合规了就安全了"的心态可能扼杀创新
    • 

  • 慢决策——"再做一轮评审"可能是推迟决策的借口
    • 

  • 责任转嫁——"这不是我的approval scope"的甩锅文化
    • 



导航策略
在辉瑞这样试图"加速同时保持合规"的环境中，有效的策略是：


    

  1. 理解监管的目的而非仅遵守流程——区分哪些合规是必须的，哪些是历史遗留的过度保护
    2. 

  2. 用监管语言包装创新——将新想法表述为"风险管理的优化"而非"打破规则"
    3. 

  3. 建立与Quality/Regulatory同事的关系——他们是盟友而非障碍
    4.

内部转岗策略
辉瑞鼓励内部流动（Internal Mobility），这是在大企业中持续成长的重要路径：


    

  • 最低服务期：通常在当前岗位满18-24个月可申请
    • 

  • 经理知情权：需要告知直属经理（不需要permission）
    • 

  • 跨序列可能：Scientific→Commercial、Operations→Scientific都有先例
    • 

  • 全球机会：跨国调动有relocation package支持
    • 



转岗最佳时机
    

  • 当前项目进入低速期
    • 

  • 新的高优先级项目启动（如Metsera管线、AI转型）
    • 

  • 组织重组后出现新的岗位
    • 

  • 直属经理变动后的"重新洗牌"期
    • 



在裁员周期中逆势晋升
看似矛盾，但裁员周期也是有准备者的机会：


    

  1. 留下的人承担更多——scope自然扩大
    2. 

  2. 组织需要"稳定器"——在动荡中保持高产出的人被格外重视
    3. 

  3. 新领导需要得力下属——组织重组后的新leader需要信任的人
    4. 

  4. AI转型创造新角色——传统角色被裁减的同时，新的Digital/AI角色在创建
    5. 



心理健康与职业韧性
在辉瑞这样的高压环境中（裁员焦虑+高强度目标+监管压力），职业韧性需要有意识地培养：


    

  • 分离自我价值与绩效评级——"Achieves"不意味着你是普通人
    • 

  • 建立工作之外的identity——不要让辉瑞employee成为你唯一的身份
    • 

  • 利用EAP资源——辉瑞提供免费心理咨询（Employee Assistance Program）
    • 

  • 建立peer support网络——与信任的同事形成互助小组
    • 

  • 持续投资可迁移技能——确保你的能力在任何制药公司都有市场
    • 



裁员不是个人失败——在辉瑞13,000+人的减员中，许多优秀人才因结构性原因离开。保持职业韧性，意味着既做好"在辉瑞成功"的努力，也做好"随时可以离开"的准备。
